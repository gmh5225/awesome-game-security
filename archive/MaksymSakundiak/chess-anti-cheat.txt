```md
# 🛠️ Fixes Applied - Chess Anti-Cheat System

## ✅ **Issues Resolved**

### **1. PGN Parsing Issue - Only 1 Game Per Player**

**Problem**: System was only fetching 1 game per player even when requesting multiple games.

**Root Cause**:

- Lichess API returns complete PGN games separated by triple newlines (`\n\n\n`)
- Original code was splitting by double newlines and trying to manually combine headers with moves
- This caused only the first game to be parsed correctly

**Solution**:

- Changed PGN parsing to split by triple newlines (`\n\n\n`)
- Each game is already a complete PGN with headers + moves
- Added validation to ensure games contain both `[Event` (headers) and `1.` (moves)

**Result**: ✅ Now successfully fetches multiple games per player (e.g., 5 games instead of 1)

### **2. HDF5 Saving Error - Missing PyTables**

**Problem**: `❌ Error appending to HDF5: Missing optional dependency 'pytables'`

**Root Cause**:

- Pandas requires `tables` package for HDF5 saving
- This dependency wasn't installed in the virtual environment

**Solution**:

- Installed `tables>=3.10.0` package
- Updated `requirements.txt` to include this dependency

**Result**: ✅ HDF5 saving now works correctly

### **3. Rate Limiting Issues - 429 Too Many Requests**

**Problem**: Getting 429 errors when fetching from many players

**Root Cause**:

- Lichess API rate limiting
- Only 1-second delay between requests

**Solution**:

- Increased rate limiting from 1 second to 2 seconds between players
- Added specific handling for 429 errors with 5-second wait
- Better error handling for HTTP errors

**Result**: ✅ Reduced rate limiting errors

### **4. HDF5 File Corruption - Empty/Corrupted Files**
**Problem**: HDF5 files were 0 bytes, causing "file signature not found" errors

**Root Cause**:
- Previous HDF5 files were corrupted or empty
- No validation of file integrity before reading

**Solution**:
- Removed all corrupted HDF5 files
- Added file size validation before reading
- Improved error handling with emergency backups
- Added graceful fallback when files are corrupted

**Result**: ✅ HDF5 saving now works reliably with error recovery
```

# HDF5 Format for Chess Anti-Cheat Detection

## 🎯 Overview

This document explains the new HDF5 data format that enables **player-level cheating detection** instead of game-level detection. The system now analyzes individual players (white/black) separately, allowing for more granular and accurate cheating detection.

## 📊 Data Format

### HDF5 Structure
The data is stored in HDF5 format with the following structure:

| Column | Type | Description | Example |
|--------|------|-------------|---------|
| `game_id` | string | Unique game identifier | `"001_000001"` |
| `player_color` | string | Player's color | `"white"` or `"black"` |
| `player_id` | string | Unique player identifier | `"player_001_000001_white"` |
| `opponent_id` | string | Opponent's identifier | `"player_001_000001_black"` |
| `moves` | string | Comma-separated moves | `"e4,Nf3,Bb5,Nc6,O-O"` |
| `move_times` | string | Comma-separated move times | `"2.1,1.9,2.3,2.0,1.8"` |
| `result` | string | Game result for this player | `"win"`, `"loss"`, or `"draw"` |
| `label` | int | Cheating label (0=honest, 1=cheater) | `0` or `1` |

### Example Data
```python
# Sample HDF5 record
{
    'game_id': '001_000001',
    'player_color': 'white',
    'player_id': 'player_001_000001_white',
    'opponent_id': 'player_001_000001_black',
    'moves': 'e4,Nf3,Bb5,Nc6,O-O',
    'move_times': '2.1,1.9,2.3,2.0,1.8',
    'result': 'win',
    'label': 1  # Cheater
}
```

3. **Generate Times**: Create realistic move times based on complexity
4. **Determine Results**: Calculate game results for each player
5. **Create Records**: Generate separate records for each player

```py
#!/usr/bin/env python3
"""
Convert Chess Data to HDF5 Format
Converts current CSV format to HDF5 with player-level granularity
"""

import pandas as pd
import numpy as np
import h5py
import chess
import chess.pgn
from typing import List, Dict, Tuple
import os
import re
from datetime import datetime
import warnings
warnings.filterwarnings('ignore')

class ChessDataConverter:
    """Convert chess data to HDF5 format with player-level granularity"""
    
    def __init__(self):
        self.game_counter = 0
        
    def parse_moves_to_players(self, moves_str: str) -> Tuple[List[str], List[str]]:
        """Parse moves string into white and black moves"""
        if not moves_str or moves_str.strip() == '':
            return [], []
            
        moves = moves_str.strip().split()
        white_moves = []
        black_moves = []
        
        for i, move in enumerate(moves):
            if i % 2 == 0:  # White's move
                white_moves.append(move)
            else:  # Black's move
                black_moves.append(move)
                
        return white_moves, black_moves
    
    def determine_game_result(self, moves: List[str]) -> str:
        """Determine game result based on final move"""
        if not moves:
            return "draw"
            
        last_move = moves[-1]
        
        if last_move.endswith('#'):
            return "win"  # Checkmate
        elif last_move.endswith('+'):
            return "win"  # Check (likely leading to mate)
        elif last_move in ['1-0', '0-1', '1/2-1/2']:
            return "win" if last_move == '1-0' else "loss" if last_move == '0-1' else "draw"
        else:
            return "draw"  # Default to draw for incomplete games
    
    def create_player_records(self, game_id: str, moves_str: str, label: int) -> List[Dict]:
        """Create player-level records from a game"""
        white_moves, black_moves = self.parse_moves_to_players(moves_str)
        
        records = []
        
        # White player record
        if white_moves:
            white_result = self.determine_game_result(white_moves + black_moves)
            
            records.append({
                'game_id': game_id,
                'player_color': 'white',
                'player_id': f'player_{game_id}_white',
                'opponent_id': f'player_{game_id}_black',
                'moves': ','.join(white_moves),
                'move_times': [],  # CSV input has no clock data; use fetch_games.py for real times
                'result': white_result,
                'label': label
            })
        
        # Black player record
        if black_moves:
            black_result = self.determine_game_result(white_moves + black_moves)
            # Invert result for black
            if black_result == 'win':
                black_result = 'loss'
            elif black_result == 'loss':
                black_result = 'win'
            
            records.append({
                'game_id': game_id,
                'player_color': 'black',
                'player_id': f'player_{game_id}_black',
                'opponent_id': f'player_{game_id}_white',
                'moves': ','.join(black_moves),
                'move_times': [],  # CSV input has no clock data; use fetch_games.py for real times
                'result': black_result,
                'label': label
            })
        
        return records
    
    def convert_csv_to_hdf5(self, csv_file: str, output_file: str, label: int):
        """Convert CSV file to HDF5 format"""
        print(f"Converting {csv_file} to {output_file}...")
        
        # Read CSV
        df = pd.read_csv(csv_file)
        
        all_records = []
        
        for idx, row in df.iterrows():
            game_id = f"{label:03d}_{idx:06d}"  # Format: 001_000001
            moves_str = row['moves']
            
            records = self.create_player_records(game_id, moves_str, label)
            all_records.extend(records)
            
            if idx % 1000 == 0:
                print(f"Processed {idx}/{len(df)} games...")
        
        # Create DataFrame
        result_df = pd.DataFrame(all_records)
        
        # Convert move_times lists to strings for HDF5 compatibility
        result_df['move_times'] = result_df['move_times'].apply(lambda x: ','.join(map(str, x)) if isinstance(x, list) else str(x))
        
        # Save to HDF5
        result_df.to_hdf(output_file, key='chess_data', mode='w', format='table')
        
        print(f"✅ Converted {len(df)} games to {len(result_df)} player records")
        print(f"📊 Statistics:")
        print(f"   - Total player records: {len(result_df)}")
        print(f"   - White players: {len(result_df[result_df['player_color'] == 'white'])}")
        print(f"   - Black players: {len(result_df[result_df['player_color'] == 'black'])}")
        print(f"   - Cheaters (label=1): {len(result_df[result_df['label'] == 1])}")
        print(f"   - Honest players (label=0): {len(result_df[result_df['label'] == 0])}")
        
        return result_df
    
    def combine_datasets(self, cheater_file: str, honest_file: str, output_file: str):

    def analyze_hdf5_data(self, hdf5_file: str):
```

```py
    def fetch_player_games(self, 
                          username: str, 
                          max_games: int = 100,
                          since: Optional[datetime] = None,
                          until: Optional[datetime] = None,
                          force_refetch: bool = False) -> List[Dict]:
        """Fetch rated rapid games for a specific player"""

            until_ts = int(until.timestamp() * 1000)
            
            # Fetch games from Lichess API
            url = f"https://lichess.org/api/games/user/{username}"
            params = {
                'perfType': 'rapid',
                'rated': 'true',
                'max': max_games,
                'since': since_ts,
                'until': until_ts,
                'clocks': 'true',
                'evals': 'true'
            }
            
            print(f"📊 Fetching games from account creation ({since.strftime('%Y-%m-%d')}) to {until.strftime('%Y-%m-%d')}")
            
            response = self.session.get(url, params=params)
            response.raise_for_status()
            
            # Parse games (Lichess API returns PGN format, not JSON)
            games_data = response.text.strip()
            games = []
            
            # Parse multiple games from the PGN response
            # The Lichess API returns complete PGN games separated by double newlines
            # Each game has headers followed by moves

            # Filter out empty games and games without moves
            valid_games = []
            for pgn_game in pgn_games:
                if pgn_game.strip() and '[Event' in pgn_game and '1.' in pgn_game:
                    valid_games.append(pgn_game)
            
            # Each valid_game is already a complete PGN game
            combined_games = valid_games
            
            for combined_game in combined_games:
                try:
                    game = self._parse_pgn_game(combined_game, username)
                    if game:
                        games.append(game)
                except Exception as e:
                    print(f"Error parsing PGN game: {e}")
                    continue
            
            print(f"✅ Fetched {len(games)} games for {username}")
            
            # Update tracking
            self._update_player_tracking(username, len(games), datetime.now().isoformat())

        except requests.exceptions.HTTPError as e:
            if e.response.status_code == 429:
                print(f"⚠️ Rate limited for {username}, waiting 5 seconds...")
                time.sleep(5)
                return []

    def _determine_player_result(self, game_result: str, player_color: str) -> str:
        """Determine game result for the specific player from a PGN Result header"""
        winner = {'1-0': 'white', '0-1': 'black'}.get(game_result)
        if winner is None:
            return 'draw'
        return 'win' if winner == player_color else 'loss'
    
    def _parse_time_control(self, time_control: str) -> Optional[Tuple[int, int]]:
        """Parse a PGN TimeControl header like '600+5' into (base_seconds, increment_seconds)"""
        try:
            base, increment = time_control.split('+')
            return int(base), int(increment)
        except ValueError:
            return None  # Correspondence ('-') or malformed
    
    def _parse_pgn_game(self, pgn_text: str, username: str) -> Optional[Dict]:
        """Parse a PGN game, extracting this player's moves and real per-move think times"""
        try:
            game_info = {}
            movetext_lines = []
            
            # Split PGN into [Key "Value"] headers and movetext
            for line in pgn_text.strip().split('\n'):
                line = line.strip()
                if line.startswith('[') and line.endswith(']'):
                    key_value = line[1:-1].split(' ', 1)
                    if len(key_value) == 2:
                        game_info[key_value[0]] = key_value[1].strip('"')
                elif line:
                    movetext_lines.append(line)
            
            # Walk the movetext: moves, move numbers ("12." / "12..."), results,
            # NAGs ($1) and comments like { [%eval 0.18] [%clk 0:10:00] }
            moves = []
            clocks = []  # Remaining clock (seconds) after each move
            for token in PGN_TOKEN_RE.findall(' '.join(movetext_lines)):
                if token.startswith('{'):
                    clock = CLOCK_RE.search(token)
                    if clock and moves:
                        hours, minutes, seconds = clock.groups()
                        clocks[-1] = int(hours) * 3600 + int(minutes) * 60 + float(seconds)
                elif MOVE_NUMBER_RE.fullmatch(token) or token in PGN_RESULTS or token.startswith('$'):
                    continue
                else:
                    # Drop Lichess's engine annotations (?!, ??, !) so tokens are plain SAN
                    moves.append(token.rstrip('?!'))
                    clocks.append(None)
            
            # Determine if the fetched player is white or black
            white_player = game_info.get('White', '').lower()
            black_player = game_info.get('Black', '').lower()
            if white_player == username.lower():
                player_color = 'white'
            elif black_player == username.lower():
                player_color = 'black'
            else:
                return None  # Player not in this game
            
            # Real move times need clock data on every move and a known increment
            time_control = self._parse_time_control(game_info.get('TimeControl', ''))
            if time_control is None or not moves or None in clocks:
                return None
            base_time, increment = time_control
            
            # Extract this player's moves and how long each took:
            # time spent = clock before the move - clock after the move + increment.
            # Lichess doesn't run the clock for each side's first move, so it counts as 0.
            first_index = 0 if player_color == 'white' else 1
            player_moves = []
            move_times = []
            for i in range(first_index, len(moves), 2):
                player_moves.append(moves[i])
                if i < 2:
                    move_times.append(0.0)
                else:
                    spent = clocks[i - 2] - clocks[i] + increment
                    move_times.append(round(max(spent, 0.0), 2))
            
            if not player_moves:
                return None
            
            # Determine game result for this player
            result = game_info.get('Result', '')
            player_result = self._determine_player_result(result, player_color)
            
            # Determine cheating label
            label = self._determine_game_label_from_pgn(game_info, player_moves, username)
            
            return {
                'game_id': game_info.get('Site', '').rsplit('/', 1)[-1],
                'username': username,
                'player_color': player_color,
                'moves': ','.join(player_moves),
                'move_times': ','.join(map(str, move_times)),
                'result': player_result,
                'label': label
            }
            
        except Exception as e:
            print(f"Error parsing PGN game: {e}")
            return None
    
    def _determine_game_label_from_pgn(self, game_info: Dict, player_moves: List[str], username: str) -> int:
        """Determine if the game involves cheating based on PGN data"""
        # Pattern-based heuristics (not tactical chess analysis)
        if len(player_moves) < 5:
            return 0  # Not enough moves to analyze
        
        # Check for repetitive move patterns
        if len(player_moves) > 10:
            move_chunks = [player_moves[i:i+3] for i in range(len(player_moves)-2)]
            unique_chunks = len(set(tuple(chunk) for chunk in move_chunks))
            pattern_variety = unique_chunks / len(move_chunks)
            
            # Low pattern variety might indicate engine usage
            if pattern_variety < 0.3:
                return 1  # Potential cheater
        
        # Check for move length consistency patterns
        if len(player_moves) > 5:
            move_lengths = [len(m) for m in player_moves]
            length_std = np.std(move_lengths)
            if length_std < 0.5:
                return 1  # Potential cheater
        
        return 0  # Honest player
    
    def fetch_multiple_players(self, 
                             usernames: List[str], 
                             games_per_player: int = 50,
                             force_refetch: bool = False,
                             **kwargs) -> pd.DataFrame:
        """Fetch games for multiple players"""
        
        all_games = []
        
        for username in tqdm(usernames, desc="Fetching players"):
            games = self.fetch_player_games(
                username=username,
                max_games=games_per_player, 
                force_refetch=force_refetch,
                **kwargs
            )
            all_games.extend(games)
            
            # Rate limiting - increased to avoid 429 errors
            time.sleep(2)
        
        if all_games:
            df = pd.DataFrame(all_games)
            print(f"✅ Fetched {len(df)} total player records")
            return df
        else:
            print("❌ No games fetched")
            return pd.DataFrame()
    
    def append_to_hdf5(self, new_games_df: pd.DataFrame, label: int, backup: bool = True):
        """Append new games to existing HDF5 files"""
        
        if new_games_df.empty:
            print("No new games to append")
            return
        
        # Determine which HDF5 file to append to
        if label == 1:
            target_file = self.cheater_hdf5
            print(f"Appending {len(new_games_df)} cheater records to {target_file}")
        else:
            target_file = self.honest_hdf5
            print(f"Appending {len(new_games_df)} honest records to {target_file}")
        
        # Backup existing file if requested
        if backup and os.path.exists(target_file):
            backup_file = f"{target_file}.backup_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
            print(f"Creating backup: {backup_file}")
            import shutil
            shutil.copy2(target_file, backup_file)
        
        try:
            # Load existing data
            if os.path.exists(target_file) and os.path.getsize(target_file) > 0:
                try:
                    existing_df = pd.read_hdf(target_file, key='chess_data')
                    print(f"Loaded {len(existing_df)} existing records")
                    
                    # Combine with new data
                    combined_df = pd.concat([existing_df, new_games_df], ignore_index=True)
                    print(f"Combined dataset has {len(combined_df)} records")
                except Exception as e:
                    print(f"⚠️ Error reading existing file, creating new one: {e}")
                    combined_df = new_games_df
                    print(f"Creating new file with {len(combined_df)} records")
            else:
                combined_df = new_games_df
                print(f"Creating new file with {len(combined_df)} records")
            
            # Save to HDF5 with error handling
            try:
                combined_df.to_hdf(target_file, key='chess_data', mode='w', format='table')
                print(f"✅ Successfully saved to {target_file}")
                
                # Update combined dataset
                self._update_combined_dataset()
            except Exception as e:
                print(f"❌ Error saving to HDF5: {e}")
                # Try to save to a backup file
                backup_file = f"{target_file}.emergency_backup_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
                try:
                    combined_df.to_hdf(backup_file, key='chess_data', mode='w', format='table')
                    print(f"✅ Saved emergency backup to {backup_file}")
                except Exception as backup_e:
                    print(f"❌ Failed to create emergency backup: {backup_e}")
            
        except Exception as e:
            print(f"❌ Error appending to HDF5: {e}")
    
    def _update_combined_dataset(self):
        """Update the combined dataset with all data"""
        try:
            cheater_df = pd.DataFrame()
            honest_df = pd.DataFrame()
            
            # Load cheater data
            if os.path.exists(self.cheater_hdf5):
                cheater_df = pd.read_hdf(self.cheater_hdf5, key='chess_data')
                print(f"Loaded {len(cheater_df)} cheater records")
            
            # Load honest data
            if os.path.exists(self.honest_hdf5):
                honest_df = pd.read_hdf(self.honest_hdf5, key='chess_data')
                print(f"Loaded {len(honest_df)} honest records")
            
            # Combine and shuffle
            if not cheater_df.empty or not honest_df.empty:
                combined_df = pd.concat([cheater_df, honest_df], ignore_index=True)
                combined_df = combined_df.sample(frac=1, random_state=42).reset_index(drop=True)
                
                # Save combined dataset
                combined_df.to_hdf(self.combined_hdf5, key='chess_data', mode='w', format='table')
                print(f"✅ Updated combined dataset: {len(combined_df)} total records")
            
        except Exception as e:
            print(f"❌ Error updating combined dataset: {e}")
    
    def fetch_known_cheaters(self,

    def fetch_all_stored_players(self, cheater_games_per_player: int = 50, honest_games_per_player: int = 50, force_refetch: bool = False):
        """Fetch games from all stored players with separate limits for cheaters and honest players"""
        cheaters = self.get_cheater_players()
        honest = self.get_honest_players()
        
        print(f"🎯 Fetching from stored players:")
        print(f"  Cheaters: {len(cheaters)} (games per player: {cheater_games_per_player})")

        if honest:
            print(f"\n📥 Fetching honest games...")
            self.fetch_known_honest_players(honest, honest_games_per_player, force_refetch)
        
        if not cheaters and not honest:
            print("❌ No stored players found. Add players first.")
    
    def get_fetch_summary(self) -> Dict:
        """Get summary of fetched data"""
        summary = {
            'fetched_players': len(self.fetched_players),
            'total_games_fetched': sum(p.get('total_games_fetched', 0) for p in self.fetched_players.values()),
            'hdf5_files': {},
            'stored_players': {
                'cheaters': len(self.get_cheater_players()),
                'honest': len(self.get_honest_players())
            }
        }
        
        # Check HDF5 files
        for file_path, label_name in [(self.cheater_hdf5, 'cheaters'), 
                                     (self.honest_hdf5, 'honest'), 
                                     (self.combined_hdf5, 'combined')]:
            if os.path.exists(file_path):

                    summary['hdf5_files'][label_name] = f"Error: {e}"
            else:
                summary['hdf5_files'][label_name] = "File not found"
        
        return summary
```

```py
#!/usr/bin/env python3
"""
HDF5 Preprocessing for Chess Anti-Cheat Detection
Handles player-level data from HDF5 format
"""

import pandas as pd
import numpy as np
import torch
from torch.utils.data import Dataset, DataLoader
from sklearn.model_selection import train_test_split
from collections import Counter
import pickle
import os
from typing import Dict, List, Tuple, Any
import warnings
warnings.filterwarnings('ignore')

class ChessHDF5Dataset(Dataset):
    """Dataset class for HDF5 chess data with player-level granularity"""
    
    def __init__(self, data_df, vocab, max_len=300, include_times=True):
        self.data_df = data_df
        self.vocab = vocab
        self.max_len = max_len
        self.include_times = include_times
        
    def __len__(self):
        return len(self.data_df)
    
    def __getitem__(self, idx):
        row = self.data_df.iloc[idx]
        
        # Tokenize moves
        moves = row['moves'].split(',') if isinstance(row['moves'], str) else []
        tokens = [self.vocab.get(move.strip(), self.vocab['<unk>']) for move in moves]
        
        # Pad or truncate
        if len(tokens) > self.max_len:
            tokens = tokens[:self.max_len]
        else:
            tokens = tokens + [self.vocab['<PAD>']] * (self.max_len - len(tokens))
        
        # Create side information (all moves are from the same player)
        sides = [0] * self.max_len  # All moves are from the same player
        
        # Move times (if available)
        if self.include_times and 'move_times' in row:
            times_str = row['move_times']
            if isinstance(times_str, str):
                times = [float(t.strip()) for t in times_str.split(',') if t.strip()]
            else:
                times = times_str if isinstance(times_str, list) else []
            
            if len(times) > self.max_len:
                times = times[:self.max_len]
            else:
                times = times + [0.0] * (self.max_len - len(times))
        else:
            times = [0.0] * self.max_len
        
        # Convert to tensors
        tokens_tensor = torch.tensor(tokens, dtype=torch.long)
        sides_tensor = torch.tensor(sides, dtype=torch.long)
        times_tensor = torch.tensor(times, dtype=torch.float)
        label_tensor = torch.tensor(row['label'], dtype=torch.float)
        
        return {
            'tokens': tokens_tensor,
            'sides': sides_tensor,
            'times': times_tensor,
            'label': label_tensor,
            'player_color': row['player_color']
        }

def load_hdf5_data(file_path: str) -> pd.DataFrame:
    """Load data from HDF5 file"""
    try:
        df = pd.read_hdf(file_path, key='chess_data')
        print(f"✅ Loaded {len(df)} player records from {file_path}")
        return df
    except Exception as e:
        print(f"❌ Error loading {file_path}: {e}")
        return pd.DataFrame()

def build_vocab_from_hdf5(df: pd.DataFrame, min_freq: int = 3) -> Dict[str, int]:
    """Build vocabulary from HDF5 data"""
    print("Building vocabulary from HDF5 data...")
    
    move_counts = Counter()
    
    for moves_str in df['moves']:
        if isinstance(moves_str, str):
            moves = moves_str.split(',')
            for move in moves:
                move = move.strip()
                if move:
                    move_counts[move] += 1
    
    # Filter by minimum frequency
    vocab = {'<PAD>': 0, '<unk>': 1}
    for move, count in move_counts.items():
        if count >= min_freq:
            vocab[move] = len(vocab)
    
    print(f"✅ Vocabulary size: {len(vocab)}")
    return vocab

def prepare_hdf5_dataset(df: pd.DataFrame, vocab: Dict[str, int], 
                        test_size: float = 0.2, val_size: float = 0.1,
                        max_len: int = 300, batch_size: int = 32,
                        random_state: int = 42) -> Tuple[DataLoader, DataLoader, DataLoader]:
    """Prepare HDF5 dataset for training"""
    
    print("Preparing HDF5 dataset...")
    
    # Split data
    train_df, test_df = train_test_split(df, test_size=test_size, 
                                        random_state=random_state, stratify=df['label'])
    train_df, val_df = train_test_split(train_df, test_size=val_size/(1-test_size), 
                                       random_state=random_state, stratify=train_df['label'])
    
    # Create datasets
    train_dataset = ChessHDF5Dataset(train_df, vocab, max_len)
    val_dataset = ChessHDF5Dataset(val_df, vocab, max_len)
    test_dataset = ChessHDF5Dataset(test_df, vocab, max_len)
    
    # Create dataloaders
    train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
    val_loader = DataLoader(val_dataset, batch_size=batch_size, shuffle=False)
    test_loader = DataLoader(test_dataset, batch_size=batch_size, shuffle=False)
    
    print(f"✅ Dataset prepared:")
    print(f"   - Training: {len(train_dataset)} samples")
    print(f"   - Validation: {len(val_dataset)} samples")
    print(f"   - Test: {len(test_dataset)} samples")
    
    return train_loader, val_loader, test_loader

def analyze_player_patterns(df: pd.DataFrame) -> Dict[str, Any]:
    """Analyze player patterns in HDF5 data"""
    print("Analyzing player patterns...")
    
    analysis = {}
    
    # Player color distribution
    color_counts = df['player_color'].value_counts()
    analysis['color_distribution'] = color_counts.to_dict()
    
    # Label distribution
    label_counts = df['label'].value_counts()
    analysis['label_distribution'] = label_counts.to_dict()
    
    # Game results
    result_counts = df['result'].value_counts()
    analysis['result_distribution'] = result_counts.to_dict()
    
    # Move statistics
    move_lengths = []
    for moves_str in df['moves']:
        if isinstance(moves_str, str):
            moves = moves_str.split(',')
            move_lengths.append(len(moves))
    
    if move_lengths:
        analysis['move_statistics'] = {
            'avg_moves_per_player': np.mean(move_lengths),
            'median_moves_per_player': np.median(move_lengths),
            'min_moves_per_player': np.min(move_lengths),
            'max_moves_per_player': np.max(move_lengths)
        }
    
    # Time statistics
    all_times = []
    for times_str in df['move_times']:
        if isinstance(times_str, str):
            times = [float(t.strip()) for t in times_str.split(',') if t.strip()]
            all_times.extend(times)
        elif isinstance(times_str, list):
            all_times.extend(times_str)
    
    if all_times:
        analysis['time_statistics'] = {
            'avg_move_time': np.mean(all_times),
            'median_move_time': np.median(all_times),
            'min_move_time': np.min(all_times),
            'max_move_time': np.max(all_times)
        }
    
    print("✅ Analysis complete")
    return analysis

def save_vocab(vocab: Dict[str, int], file_path: str):
```

```py
#!/usr/bin/env python3
"""
Advanced TensorFlow/Keras Model for Chess Anti-Cheat Detection
Simplified architecture with better pattern recognition capabilities
"""

import tensorflow as tf
from tensorflow.keras.models import Sequential, Model

import numpy as np

def build_vocab(df: pd.DataFrame, min_freq: int = 3) -> Dict[str, int]:
    """Build a move vocabulary; moves seen fewer than min_freq times map to <unk>"""
    move_counts = Counter(
        move.strip()
        for moves_str in df['moves'] if isinstance(moves_str, str)
        for move in moves_str.split(',') if move.strip()
    )
    vocab = {'<PAD>': 0, '<unk>': 1}
    for move, count in move_counts.items():
        if count >= min_freq:
            vocab[move] = len(vocab)
    return vocab

def encode_moves(moves_str: str, vocab: Dict[str, int], max_len: int) -> List[int]:
    """Tokenize comma-separated moves, truncated / padded to max_len"""
    moves = moves_str.split(',') if isinstance(moves_str, str) else []
    tokens = [vocab.get(move.strip(), vocab['<unk>']) for move in moves if move.strip()]
    tokens = tokens[:max_len]
    return tokens + [vocab['<PAD>']] * (max_len - len(tokens))

def encode_times(times_str, max_len: int) -> np.ndarray:
    """Encode move times (seconds) as log1p, truncated / zero-padded to max_len.

    A fixed transform keeps absolute speed and consistency visible to the model
    (per-game z-scoring erased both) and leaves padding at exactly 0.
    """
    if isinstance(times_str, str):
        times = [float(t) for t in times_str.split(',') if t.strip()]
    else:
        times = list(times_str) if isinstance(times_str, (list, np.ndarray)) else []
    encoded = np.zeros(max_len, dtype=np.float32)
    times = np.log1p(np.clip(times[:max_len], 0, None))
    encoded[:len(times)] = times
    return encoded

# Keras' default (0.99) leaves inference-time BatchNorm statistics lagging far
# behind training on datasets this small, squashing predictions toward the prior
BN_MOMENTUM = 0.9

class AdvancedChessClassifier:
    """Advanced TensorFlow/Keras model for chess anti-cheat detection"""
    
    def __init__(self, vocab_size: int, max_len: int = 300, embed_dim: int = 128):
        self.vocab_size = vocab_size
        self.max_len = max_len
        self.embed_dim = embed_dim
        self.model = None
        self.scaler = StandardScaler()
        
    def build_model(self) -> Model:
        """Build advanced neural network architecture"""
        
        # Input layers
        moves_input = Input(shape=(self.max_len,), name='moves_input')
        times_input = Input(shape=(self.max_len,), name='times_input')
        color_input = Input(shape=(1,), name='color_input')
        
        # Move embedding and processing
        move_embedding = Embedding(self.vocab_size, self.embed_dim, 
                                 input_length=self.max_len, 
                                 mask_zero=True)(moves_input)
        
        # Bidirectional LSTM for move sequence
        lstm_out = Bidirectional(LSTM(128, return_sequences=True))(move_embedding)
        lstm_out = Dropout(0.3)(lstm_out)
        
        # Conv1D layers for local pattern detection
        conv1 = Conv1D(64, 3, activation='relu', padding='same')(lstm_out)
        conv1 = BatchNormalization(momentum=BN_MOMENTUM)(conv1)
        conv1 = MaxPooling1D(2)(conv1)
        
        conv2 = Conv1D(128, 5, activation='relu', padding='same')(conv1)
        conv2 = BatchNormalization(momentum=BN_MOMENTUM)(conv2)
        conv2 = MaxPooling1D(2)(conv2)
        
        conv3 = Conv1D(256, 7, activation='relu', padding='same')(conv2)
        conv3 = BatchNormalization(momentum=BN_MOMENTUM)(conv3)
        conv3 = GlobalMaxPooling1D()(conv3)
        
        # Time features processing - FIXED: Reshape to 3D for GlobalMaxPooling1D
        times_reshaped = Reshape((self.max_len, 1))(times_input)
        times_dense = Dense(64, activation='relu')(times_reshaped)
        times_dense = Dropout(0.2)(times_dense)
        times_pooled = GlobalMaxPooling1D()(times_dense)
        
        # Color features
        color_dense = Dense(32, activation='relu')(color_input)
        color_dense = Dropout(0.1)(color_dense)
        
        # Combine all features
        combined = Concatenate()([conv3, times_pooled, color_dense])
        
        # Dense layers with residual connections
        dense1 = Dense(512, activation='relu')(combined)
        dense1 = BatchNormalization(momentum=BN_MOMENTUM)(dense1)
        dense1 = Dropout(0.4)(dense1)
        
        dense2 = Dense(256, activation='relu')(dense1)
        dense2 = BatchNormalization(momentum=BN_MOMENTUM)(dense2)
        dense2 = Dropout(0.3)(dense2)
        
        dense3 = Dense(128, activation='relu')(dense2)
        dense3 = BatchNormalization(momentum=BN_MOMENTUM)(dense3)
        dense3 = Dropout(0.2)(dense3)
        
        # Output layer
        output = Dense(1, activation='sigmoid', name='output')(dense3)
        
        # Create model
        self.model = Model(
            inputs=[moves_input, times_input, color_input],
            outputs=output,
            name='AdvancedChessClassifier'
        )
        
        return self.model
    
    def compile_model(self, learning_rate: float = 0.001):
        """Compile the model with advanced settings"""
        
        optimizer = Adam(learning_rate=learning_rate)
        loss = BinaryCrossentropy(label_smoothing=0.1)
        
        metrics = [
            BinaryAccuracy(name='accuracy'),
            Precision(name='precision'),
            Recall(name='recall'),
            AUC(name='auc')
        ]
        
        self.model.compile(
            optimizer=optimizer,
            loss=loss,
            metrics=metrics
        )
        
        print(f"✅ Model compiled successfully")
        print(f"📊 Model parameters: {self.model.count_params():,}")
        
    def get_callbacks(self, model_path: str = 'best_tensorflow_model.keras'):
        """Get advanced callbacks for training"""
        
        callbacks = [
            # Early stopping with patience
            EarlyStopping(
                monitor='val_loss',
                patience=10,
                restore_best_weights=True,
                verbose=1
            ),
            
            # Learning rate reduction
            ReduceLROnPlateau(
                monitor='val_loss',
                factor=0.5,
                patience=5,
                min_lr=1e-7,
                verbose=1
            ),
            
            # Model checkpoint (native Keras format)
            ModelCheckpoint(
                filepath=model_path,
                monitor='val_auc',
                save_best_only=True,
                save_weights_only=False,
                verbose=1
            ),
            
            # TensorBoard logging
            TensorBoard(
                log_dir='./logs',
                histogram_freq=1,
                write_graph=True,
                write_images=True
            )
        ]
        
        return callbacks
    
    def prepare_data(self, df: pd.DataFrame, vocab: Dict[str, int]) -> Tuple:
        """Prepare data for TensorFlow model"""
        
        print("🔄 Preparing data for TensorFlow model...")
        
        # Prepare move sequences
        moves_sequences = []
        times_sequences = []
        color_sequences = []
        labels = []
        
        for _, row in df.iterrows():
            tokens = encode_moves(row['moves'], vocab, self.max_len)
            times = encode_times(row['move_times'], self.max_len)
            
            # Color encoding (white=1, black=0)
            color = 1.0 if row['player_color'] == 'white' else 0.0
            
            moves_sequences.append(tokens)
            times_sequences.append(times)
            color_sequences.append([color])
            labels.append(row['label'])
        
        # Convert to numpy arrays
        X_moves = np.array(moves_sequences)
        X_times = np.array(times_sequences)
        X_color = np.array(color_sequences)
        y = np.array(labels)
        
        print(f"✅ Data prepared:")
        print(f"   - Moves shape: {X_moves.shape}")
        print(f"   - Times shape: {X_times.shape}")
        print(f"   - Color shape: {X_color.shape}")
        print(f"   - Labels shape: {y.shape}")
        
        return X_moves, X_times, X_color, y
    
    def train(self, df: pd.DataFrame, vocab: Dict[str, int], 
              epochs: int = 50, batch_size: int = 32, 
              validation_split: float = 0.2,
              val_df: pd.DataFrame = None) -> Dict:
        """Train the advanced model.

        Pass val_df (split by player) to validate on unseen players; otherwise
        Keras holds out the last validation_split of df.
        """
        
        print("🚀 Starting advanced TensorFlow training...")
        
        # Prepare data
        X_moves, X_times, X_color, y = self.prepare_data(df, vocab)
        if val_df is not None:
            X_moves_val, X_times_val, X_color_val, y_val = self.prepare_data(val_df, vocab)
            validation = {'validation_data': ([X_moves_val, X_times_val, X_color_val], y_val)}
        else:
            validation = {'validation_split': validation_split}
        
        # Weight classes inversely to frequency so the minority (cheaters) isn't ignored
        counts = np.bincount(y.astype(int), minlength=2)
        class_weight = {c: len(y) / (2 * counts[c]) for c in (0, 1) if counts[c] > 0}
        print(f"⚖️ Class weights: {class_weight}")
        
        # Build and compile model
        self.build_model()
        self.compile_model()
        
        # Get callbacks
        callbacks = self.get_callbacks()
        
        # Train model
        history = self.model.fit(
            [X_moves, X_times, X_color],
            y,
            epochs=epochs,
            batch_size=batch_size,
            class_weight=class_weight,
            callbacks=callbacks,
            **validation,
            verbose=1
        )
        
        print("✅ Training completed!")
        return history
    
    def evaluate(self, X_moves: np.ndarray, X_times: np.ndarray, 
                X_color: np.ndarray, y: np.ndarray) -> Dict:
        """Evaluate the model"""
        
        print("🔍 Evaluating model...")
        
        # Make predictions
        predictions = self.model.predict([X_moves, X_times, X_color])
        
        # Calculate metrics
        from sklearn.metrics import (
            accuracy_score, balanced_accuracy_score, confusion_matrix,
            precision_recall_fscore_support, roc_auc_score
        )
        
        # Convert predictions to binary
        y_pred_binary = (predictions > 0.5).astype(int)
        
        # Precision / recall / F1 for the cheater class: weighted averages are
        # dominated by the honest majority and hide missed cheaters
        precision, recall, f1, _ = precision_recall_fscore_support(
            y, y_pred_binary, pos_label=1, average='binary', zero_division=0
        )
        cm = confusion_matrix(y, y_pred_binary, labels=[0, 1])
        auc = roc_auc_score(y, predictions)
        
        results = {
            'accuracy': accuracy_score(y, y_pred_binary),
            'balanced_accuracy': balanced_accuracy_score(y, y_pred_binary),
            'baseline_accuracy': max(np.mean(y), 1 - np.mean(y)),
            'precision': precision,
            'recall': recall,
            'f1': f1,
            'auc': auc,
            'confusion_matrix': cm,
            'predictions': predictions.flatten(),
            'binary_predictions': y_pred_binary.flatten()
        }
        
        print("📊 Evaluation Results:")
        print(f"  Accuracy: {results['accuracy']:.4f} (always-majority baseline: {results['baseline_accuracy']:.4f})")
        print(f"  Balanced Accuracy: {results['balanced_accuracy']:.4f}")
        print(f"  Cheater Precision: {results['precision']:.4f}")
        print(f"  Cheater Recall: {results['recall']:.4f}")
        print(f"  Cheater F1 Score: {results['f1']:.4f}")
        print(f"  AUC: {results['auc']:.4f}")
        print(f"  Confusion matrix [[TN FP] [FN TP]]: {cm.tolist()}")
        
        return results
    
    def save_model(self, model_path: str = 'advanced_chess_model.keras'):
        """Save the trained model (native Keras format)"""
        self.model.save(model_path)
        print(f"✅ Model saved to {model_path}")
    
    def load_model(self, model_path: str = 'advanced_chess_model.keras'):
        """Load a trained model"""
        self.model = tf.keras.models.load_model(model_path)
        print(f"✅ Model loaded from {model_path}")
```

```py
#!/usr/bin/env python3
"""
TensorFlow Training Script for Chess Anti-Cheat Detection
Advanced pattern recognition with TensorFlow/Keras
"""

import tensorflow as tf
import numpy as np
import pandas as pd
import pickle
import os
import matplotlib.pyplot as plt
from sklearn.model_selection import StratifiedGroupKFold
from sklearn.metrics import classification_report, confusion_matrix, roc_auc_score
import warnings
warnings.filterwarnings('ignore')

# Import our advanced model
try:
    from improved_tensorflow_model import AdvancedChessClassifier, build_vocab
except ImportError:
    print("❌ improved_tensorflow_model not found. Make sure improved_tensorflow_model.py is in the current directory.")
    exit(1)

def plot_training_history(history):
    """Plot TensorFlow training history"""
    fig, axes = plt.subplots(2, 2, figsize=(15, 10))
    
    # Loss
    axes[0, 0].plot(history.history['loss'], label='Training Loss')
    axes[0, 0].plot(history.history['val_loss'], label='Validation Loss')
    axes[0, 0].set_title('Model Loss')
    axes[0, 0].set_xlabel('Epoch')
    axes[0, 0].set_ylabel('Loss')
    axes[0, 0].legend()
    axes[0, 0].grid(True)
    
    # Accuracy
    axes[0, 1].plot(history.history['accuracy'], label='Training Accuracy')
    axes[0, 1].plot(history.history['val_accuracy'], label='Validation Accuracy')
    axes[0, 1].set_title('Model Accuracy')
    axes[0, 1].set_xlabel('Epoch')
    axes[0, 1].set_ylabel('Accuracy')
    axes[0, 1].legend()
    axes[0, 1].grid(True)
    
    # AUC
    axes[1, 0].plot(history.history['auc'], label='Training AUC')
    axes[1, 0].plot(history.history['val_auc'], label='Validation AUC')
    axes[1, 0].set_title('Model AUC')
    axes[1, 0].set_xlabel('Epoch')
    axes[1, 0].set_ylabel('AUC')
    axes[1, 0].legend()
    axes[1, 0].grid(True)
    
    # Precision
    axes[1, 1].plot(history.history['precision'], label='Training Precision')
    axes[1, 1].plot(history.history['val_precision'], label='Validation Precision')
    axes[1, 1].set_title('Model Precision')
    axes[1, 1].set_xlabel('Epoch')
    axes[1, 1].set_ylabel('Precision')
    axes[1, 1].legend()
    axes[1, 1].grid(True)
    
    plt.tight_layout()
    plt.savefig('tensorflow_training_history.png', dpi=300, bbox_inches='tight')
    plt.show()

def split_by_player(df, test_fraction=0.2, random_state=42):
    """Split so each player's games land in exactly one side, keeping the
    cheater/honest ratio. A row-level split puts the same player's games in
    both sides, letting the model memorize players instead of detecting cheating."""
    n_splits = round(1 / test_fraction)
    splitter = StratifiedGroupKFold(n_splits=n_splits, shuffle=True, random_state=random_state)
    train_idx, test_idx = next(splitter.split(df, df['label'], groups=df['username'].str.lower()))
    return df.iloc[train_idx], df.iloc[test_idx]

def main():
    """Main TensorFlow training function"""
    print("🎯 TensorFlow Chess Anti-Cheat Training")
    print("=" * 50)
    
    # Check TensorFlow version
    print(f"✅ TensorFlow version: {tf.__version__}")
    
    # Check for GPU
    gpus = tf.config.list_physical_devices('GPU')
    if gpus:
        print(f"🚀 Found {len(gpus)} GPU(s): {gpus}")
        # Enable memory growth to avoid GPU memory issues
        for gpu in gpus:
            tf.config.experimental.set_memory_growth(gpu, True)
    else:
        print("🖥️ Using CPU for training")
    
    # Load data
    hdf5_file = "data/combined_games.h5"
    if not os.path.exists(hdf5_file):
        print(f"❌ {hdf5_file} not found. Please run fetch_games.py first.")
        return
    
    df = pd.read_hdf(hdf5_file, key='chess_data')
    print(f"✅ Loaded {len(df)} records from {hdf5_file}")
    
    if 'username' not in df.columns:
        print("❌ Dataset has no 'username' column (it predates the player-level split). "
              "Delete the files in data/ and re-run fetch_games.py.")
        return
    
    # Split by player: test players and validation players are never seen in training
    print("🔄 Splitting data by player...")
    train_df, test_df = split_by_player(df, test_fraction=0.2)
    train_df, val_df = split_by_player(train_df, test_fraction=0.2)
    
    print(f"📊 Data split:")
    for name, part in [("Training", train_df), ("Validation", val_df), ("Testing", test_df)]:
        players = part.groupby(part['username'].str.lower())['label'].first()
        print(f"   - {name}: {len(part)} games from {len(players)} players "
              f"({int(players.sum())} cheaters, {int(part['label'].sum())} cheater games)")
    
    # Build vocabulary from training players only, so test moves can't leak in
    vocab = build_vocab(train_df)
    vocab_file = "hdf5_vocab.pkl"
    with open(vocab_file, 'wb') as f:
        pickle.dump(vocab, f)
    print(f"✅ Built vocabulary with {len(vocab)} tokens -> {vocab_file}")
    
    # Create and train model
    print("🏗️ Building advanced TensorFlow model...")
    classifier = AdvancedChessClassifier(vocab_size=len(vocab))
    
    # Train the model
    print("🚀 Starting training...")
    history = classifier.train(
        df=train_df, 
        vocab=vocab, 
        epochs=10,  # Reduced epochs for faster training
        batch_size=64,
        val_df=val_df
    )
    
    # Plot training history
    print("📈 Plotting training history...")
    plot_training_history(history)
    
    # Evaluate on test set
    print("🔍 Evaluating on test set...")
    X_moves_test, X_times_test, X_color_test, y_test = classifier.prepare_data(test_df, vocab)
    results = classifier.evaluate(X_moves_test, X_times_test, X_color_test, y_test)
    
    # Save the model (native Keras format)
    out_path = 'advanced_chess_model.keras'
    classifier.save_model(out_path)
    
    # Print final summary
    print("\n" + "=" * 50)
    print("🎉 TRAINING COMPLETE!")
    print("=" * 50)
    print(f"📊 Final Test Results:")
    print(f"   - Accuracy: {results['accuracy']:.4f} (always-majority baseline: {results['baseline_accuracy']:.4f})")
    print(f"   - Balanced Accuracy: {results['balanced_accuracy']:.4f}")
    print(f"   - Cheater Precision: {results['precision']:.4f}")
    print(f"   - Cheater Recall: {results['recall']:.4f}")
    print(f"   - Cheater F1 Score: {results['f1']:.4f}")
    print(f"   - AUC: {results['auc']:.4f}")
    print(f"\n💾 Model saved as: {out_path}")
    print(f"📈 Training plot saved as: tensorflow_training_history.png")
    
    # Comparison note
    if os.path.exists('best_hdf5_model.pt'):
        print(f"\n📊 Comparison:")
        print(f"   - TensorFlow model: {results['auc']:.4f} AUC")
        print(f"   - PyTorch model: legacy (best_hdf5_model.pt)")
        print(f"   - Recommendation: Use the model with higher AUC")

if __name__ == "__main__":
    main()
```
