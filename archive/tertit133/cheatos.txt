<div align="center">

# CheatOS

**Memory scanner and trainer framework for Windows x64.**

[![build](https://github.com/tertit133/cheatos/actions/workflows/build.yml/badge.svg)](https://github.com/tertit133/cheatos/actions/workflows/build.yml)
[![license](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![C++](https://img.shields.io/badge/C%2B%2B-20-00599C.svg?logo=c%2B%2B)](https://en.cppreference.com/w/cpp/20)
[![platform](https://img.shields.io/badge/platform-Windows%20x64-0078D6.svg?logo=windows)](https://learn.microsoft.com/en-us/windows/win32/memory/)

ImGui + DX11 UI (docking) * pugixml for CheatEngine .CT compatibility

</div>

> A compact Cheat-Engine-style trainer: attach to any process, scan
> memory for values, filter down across scans, freeze what you want,
> resolve pointer chains, and load/save CheatEngine tables. ~2.5k LOC
> of straight C++20 with a small set of focused modules.

## Features

- **Attach to any PID** with full RW access; process list with live filter.
- **Typed scanner** -- int8/16/32/64 signed & unsigned, float/double,
  byte patterns (`DE AD ?? EF`), ASCII and wide strings.
- **Scan ops** -- `exact`, `!=`, `>`, `>=`, `<`, `<=`, `between`,
  and the next-scan filters `changed` / `unchanged` / `increased` /
  `decreased`. Fast aligned scans or every-byte mode.
- **Freezer thread** -- rewrites pinned bookmark values ~60 Hz so game
  logic can't decrement them.
- **Pointer scanner** -- BFS over the process's pointer map, finds
  chains `*(static + o1) ... + oN` that land on a target, up to depth 6.
  Keeps only chains rooted in a module image so they survive restarts.
- **Bookmarks** -- live value column, inline rename/type-change, freeze
  toggle, pointer-path aware.
- **CheatEngine table I/O** -- load/save `.CT` XML via pugixml; works
  with existing tables for common entries.
- **ImGui docking layout** -- drag any pane, split, float; layout
  persists in `imgui.ini` next to the exe.

## Build

Prerequisites:

- Windows 10/11 x64
- Visual Studio 2022 (MSVC, x64 Native Tools) or CMake + Ninja with MSVC
- CMake 3.20+
- Git (FetchContent pulls ImGui + pugixml)

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
build\bin\Release\cheatos.exe
```

First configure pulls ~30 MB of dependencies.

## Architecture

```
src/
+-- common.h            types, Windows includes (windows.h FIRST, lesson learned)
+-- value_types.{h,cpp} typed values, parse/compare/format, byte patterns
+-- proc_attach.{h,cpp} enumerate processes, OpenProcess for VM RW
+-- mem_regions.{h,cpp} VirtualQueryEx walker (committed + readable/writable)
+-- scanner.{h,cpp}     first-scan and next-scan, chunked RPM, cancellable
+-- bookmarks.{h,cpp}   saved address list (name, type, frozen value, pointer path)
+-- freezer.{h,cpp}     ~60 Hz WPM thread that holds frozen values
+-- pointer_scan.{h,cpp} BFS pointer-path finder, rooted in MEM_IMAGE
+-- ce_table.{h,cpp}    CheatEngine .CT XML read/write (pugixml)
+-- engine.{h,cpp}      orchestrator; UI thread talks only to this class
+-- main.cpp            wWinMain
+-- ui/
    +-- theme.{h,cpp}  gray ImGui style
    +-- app.{h,cpp}    Win32 + DX11 + ImGui docking bootstrap
    +-- views.{h,cpp}  Control / Scan / Results / Bookmarks / Memory / Pointer / Log
```

The `Engine` owns a single worker thread that scans/pointer-scans run
on, so the UI thread never blocks. State (results list, pointer paths,
bookmarks) is read via thread-safe snapshot calls. The freezer is its
own thread that pulls bookmarks through a provider callback so it does
not need to co-own the list.

## Scan engine

- `enumerateRegions` walks `VirtualQueryEx` from `lpMinimumApplicationAddress`
  to `lpMaximumApplicationAddress`, keeping committed pages that match
  the access mask (`PAGE_READWRITE`, `PAGE_WRITECOPY`, ...).
- `firstScan` splits every region into 4 MiB chunks, `ReadProcessMemory`
  into a reusable buffer, then walks aligned slots applying the typed
  comparator. Cancellation is checked between chunks.
- `nextScan` filters the stored previous results in place -- one RPM per
  entry, compare against the user operand (plus the previous value for
  `changed`/`increased`/... ops).
- Match captures the current bytes so the next scan can compare against
  them without re-reading. Byte pattern + wildcard mask (`DE AD ?? EF`)
  supported via a parallel mask vector.

## Pointer scan

1. Walk every readable region, interpret each aligned 8-byte slot as a
   pointer value, keep only those pointing inside another readable
   region -- stored sorted by `dest`.
2. Starting from the target address, binary-search the pointer-map for
   `dest` in `[T - maxOff, T]`. Each hit is a one-level resolve with
   offset `T - dest`.
3. If the hit source lives in a `MEM_IMAGE` region (module), accept it
   as a final chain. Otherwise enqueue it as a new target and recurse
   up to `maxDepth`.
4. Keeps up to `maxResults` paths so huge targets don't blow the UI.

## CheatEngine .CT compatibility

`loadCheatTable` / `saveCheatTable` handle the subset that actually
matters for trainer entries:

- `<Description>`
- `<VariableType>` -- "Byte", "2 Bytes", "4 Bytes", "8 Bytes", "Float",
  "Double", "String", "Array of byte"
- `<Address>` in hex (base when there's a pointer chain)
- `<Offsets><Offset>...</Offset></Offsets>`

Scripts, groupings, and anti-cheat sections are ignored on read and
omitted on write. Round-trips are stable for every entry in that set.

#include "bookmarks.h"

namespace cheat {

BookmarkId BookmarkList::add(Bookmark b) {
    if (b.id == 0) b.id = m_next++;
    else           m_next = std::max(m_next, b.id + 1);
    m_items.push_back(std::move(b));
    return m_items.back().id;
}

bool BookmarkList::remove(BookmarkId id) {
    for (auto it = m_items.begin(); it != m_items.end(); ++it) {
        if (it->id == id) { m_items.erase(it); return true; }
    }
    return false;
}

Bookmark* BookmarkList::find(BookmarkId id) {
    for (auto& b : m_items) if (b.id == id) return &b;
    return nullptr;
}

const Bookmark* BookmarkList::find(BookmarkId id) const {
    for (const auto& b : m_items) if (b.id == id) return &b;
    return nullptr;
}

} // namespace cheat

// bookmarks.h -- the saved address list ("cheat table" entries).
//
// Each entry is a labeled address with a type and optional pinned
// value that the freezer writes back on a timer.
#pragma once

#include "common.h"
#include "value_types.h"

namespace cheat {

using BookmarkId = std::uint32_t;

struct Bookmark {
    BookmarkId  id{};
    std::string name;
    Address     address{};
    ValueType   type{ValueType::I32};
    bool        frozen{false};
    TypedValue  frozenValue;        // what the freezer writes on tick
    // Pointer path (optional). If present, the effective address is
    // resolved as *(... *(base + off[0]) ... + off[n-1]).
    std::vector<std::int32_t> pointerOffsets;
    Address     pointerBase{};
};

class BookmarkList {
public:
    BookmarkId add(Bookmark b);        // id is assigned if 0
    bool       remove(BookmarkId id);
    Bookmark*  find(BookmarkId id);
    const Bookmark* find(BookmarkId id) const;

    const std::vector<Bookmark>& list() const { return m_items; }
    std::vector<Bookmark>&       mutableList()      { return m_items; }

    void clear() { m_items.clear(); }

private:
    std::vector<Bookmark> m_items;
    BookmarkId            m_next{1};
};

} // namespace cheat

#include "ce_table.h"

#include <pugixml.hpp>

namespace cheat {

namespace {

const char* ceTypeName(ValueType t) {
    switch (t) {
        case ValueType::I8:  case ValueType::U8:  return "Byte";
        case ValueType::I16: case ValueType::U16: return "2 Bytes";
        case ValueType::I32: case ValueType::U32: return "4 Bytes";
        case ValueType::I64: case ValueType::U64: return "8 Bytes";
        case ValueType::F32: return "Float";
        case ValueType::F64: return "Double";
        case ValueType::AsciiString: return "String";
        case ValueType::WideString:  return "String";
        case ValueType::Bytes:       return "Array of byte";
    }
    return "4 Bytes";
}

ValueType ceTypeFromName(const std::string& s) {
    if (s == "Byte")               return ValueType::U8;
    if (s == "2 Bytes")            return ValueType::U16;
    if (s == "4 Bytes")            return ValueType::U32;
    if (s == "8 Bytes")            return ValueType::U64;
    if (s == "Float")              return ValueType::F32;
    if (s == "Double")             return ValueType::F64;
    if (s == "String")             return ValueType::AsciiString;
    if (s == "Array of byte")      return ValueType::Bytes;
    return ValueType::I32;
}

} // anonymous

bool saveCheatTable(const std::wstring& path,
                     const std::vector<Bookmark>& items) {
    pugi::xml_document doc;
    auto decl = doc.append_child(pugi::node_declaration);
    decl.append_attribute("version")  = "1.0";
    decl.append_attribute("encoding") = "utf-8";

    auto root = doc.append_child("CheatTable");
    root.append_attribute("CheatEngineTableVersion") = 31;
    auto entries = root.append_child("CheatEntries");

    for (const auto& b : items) {
        auto e = entries.append_child("CheatEntry");
        e.append_child("ID").text().set(static_cast<unsigned>(b.id));
        e.append_child("Description").text().set(("\"" + b.name + "\"").c_str());
        e.append_child("VariableType").text().set(ceTypeName(b.type));

        char addrBuf[32];
        std::snprintf(addrBuf, sizeof(addrBuf), "%llX",
                       static_cast<unsigned long long>(
                           b.pointerOffsets.empty() ? b.address : b.pointerBase));
        e.append_child("Address").text().set(addrBuf);

        if (!b.pointerOffsets.empty()) {
            auto offs = e.append_child("Offsets");
            for (auto o : b.pointerOffsets) {
                char ob[16];
                std::snprintf(ob, sizeof(ob), "%X", o);
                offs.append_child("Offset").text().set(ob);
            }
        }
    }

    return doc.save_file(path.c_str());
}

std::optional<std::vector<Bookmark>>
loadCheatTable(const std::wstring& path) {
    pugi::xml_document doc;
    auto res = doc.load_file(path.c_str());
    if (!res) return std::nullopt;

    auto root = doc.child("CheatTable");
    if (!root) return std::nullopt;

    std::vector<Bookmark> out;
    for (auto e : root.child("CheatEntries").children("CheatEntry")) {
        Bookmark b{};
        std::string desc = e.child_value("Description");
        if (desc.size() >= 2 && desc.front() == '"' && desc.back() == '"') {
            desc = desc.substr(1, desc.size() - 2);
        }
        b.name = std::move(desc);
        b.type = ceTypeFromName(e.child_value("VariableType"));

        const char* addrText = e.child_value("Address");
        b.address = static_cast<Address>(
            std::strtoull(addrText ? addrText : "0", nullptr, 16));

        if (auto offs = e.child("Offsets")) {
            for (auto o : offs.children("Offset")) {
                b.pointerOffsets.push_back(
                    static_cast<int>(std::strtol(o.child_value(), nullptr, 16)));
            }
            b.pointerBase = b.address;
            b.address     = 0;  // resolved live by the engine
        }

        b.frozenValue = TypedValue::zero(b.type);
        out.push_back(std::move(b));
    }
    return out;
}

} // namespace cheat

template <typename... Args>
inline std::string sfmt(const char* fmt, Args... args) {
    char buf[512];
    int n = std::snprintf(buf, sizeof(buf), fmt, args...);
    if (n < 0) return {};
    return std::string(buf, static_cast<std::size_t>(
                             std::min<int>(n, sizeof(buf) - 1)));
}

inline std::wstring utf8_to_wide(const std::string& s) {
    if (s.empty()) return {};
    int n = ::MultiByteToWideChar(CP_UTF8, 0, s.data(), (int)s.size(), nullptr, 0);
    std::wstring w(static_cast<std::size_t>(n), L'\0');
    ::MultiByteToWideChar(CP_UTF8, 0, s.data(), (int)s.size(), w.data(), n);
    return w;
}

inline std::string wide_to_utf8(const std::wstring& s) {
    if (s.empty()) return {};
    int n = ::WideCharToMultiByte(CP_UTF8, 0, s.data(), (int)s.size(),
                                   nullptr, 0, nullptr, nullptr);
    std::string u(static_cast<std::size_t>(n), '\0');
    ::WideCharToMultiByte(CP_UTF8, 0, s.data(), (int)s.size(),
                           u.data(), n, nullptr, nullptr);
    return u;
}

} // namespace cheat

#include "engine.h"

namespace cheat {

Engine::Engine() {
    m_worker = std::thread(&Engine::workerLoop, this);
}

Engine::~Engine() {
    m_workerQuit = true;
    m_taskCv.notify_all();
    if (m_worker.joinable()) m_worker.join();
    detach();
}

// ---------------------------------------------------------------------------
// Process lifecycle
// ---------------------------------------------------------------------------
bool Engine::attach(DWORD pid) {
    detach();
    HANDLE h = openForFullAccess(pid);
    if (!h) { pushLog(sfmt("[!] OpenProcess failed (pid=%lu)", pid)); return false; }
    {
        std::lock_guard<std::mutex> lk(m_mtx);
        m_process = h;
        m_pid     = pid;
    }
    pushLog(sfmt("[+] attached to pid=%lu", pid));
    return true;
}

void Engine::detach() {
    freezerStop();
    cancelScan();

    HANDLE h = nullptr;
    {
        std::lock_guard<std::mutex> lk(m_mtx);
        h = m_process;
        m_process = nullptr;
        m_pid = 0;
        m_results.clear();
        m_ptrPaths.clear();
    }
    if (h) ::CloseHandle(h);
}

std::wstring Engine::imagePath() {
    std::lock_guard<std::mutex> lk(m_mtx);
    return m_process ? processImagePath(m_process) : std::wstring{};
}

// ---------------------------------------------------------------------------
// Scanning
// ---------------------------------------------------------------------------
void Engine::startFirstScan(ScanConfig cfg) {
    if (!m_process || m_scanning.load()) return;
    m_scanCancel = false;
    m_scanning   = true;
    m_scanProgress = 0;

    enqueue([this, cfg = std::move(cfg)]() {
        auto results = m_scanner.firstScan(
            m_process, cfg, m_scanCancel,
            [this](std::size_t d, std::size_t t) {
                m_scanProgress = t ? float(d) / float(t) : 1.0f;
            });
        {
            std::lock_guard<std::mutex> lk(m_mtx);
            m_results = std::move(results);
        }
        pushLog(sfmt("[*] first scan complete: %zu hits",
                       m_results.size()));
        m_scanning = false;
    });
}

void Engine::startNextScan(ScanConfig cfg) {
    if (!m_process || m_scanning.load()) return;
    m_scanCancel = false;
    m_scanning   = true;
    m_scanProgress = 0;

    enqueue([this, cfg = std::move(cfg)]() {
        std::vector<ScanResult> prev;
        {
            std::lock_guard<std::mutex> lk(m_mtx);
            prev = m_results;
        }
        auto results = m_scanner.nextScan(
            m_process, prev, cfg, m_scanCancel,
            [this](std::size_t d, std::size_t t) {
                m_scanProgress = t ? float(d) / float(t) : 1.0f;
            });
        {
            std::lock_guard<std::mutex> lk(m_mtx);
            m_results = std::move(results);
        }
        pushLog(sfmt("[*] next scan: %zu -> %zu",
                       prev.size(), m_results.size()));
        m_scanning = false;
    });
}

void Engine::cancelScan() {
    m_scanCancel = true;
}

void Engine::resetScan() {
    cancelScan();
    std::lock_guard<std::mutex> lk(m_mtx);
    m_results.clear();
}

std::size_t Engine::resultCount() {
    std::lock_guard<std::mutex> lk(m_mtx);
    return m_results.size();
}

std::vector<ScanResult> Engine::resultsSlice(std::size_t offset,
                                               std::size_t count) {
    std::lock_guard<std::mutex> lk(m_mtx);
    if (offset >= m_results.size()) return {};
    const std::size_t end = std::min(m_results.size(), offset + count);
    return { m_results.begin() + offset, m_results.begin() + end };
}

// ---------------------------------------------------------------------------
// Bookmarks
// ---------------------------------------------------------------------------
BookmarkId Engine::addBookmark(Bookmark b) {
    std::lock_guard<std::mutex> lk(m_mtx);
    return m_bookmarks.add(std::move(b));
}

bool Engine::removeBookmark(BookmarkId id) {
    std::lock_guard<std::mutex> lk(m_mtx);
    return m_bookmarks.remove(id);
}

bool Engine::setBookmarkFreeze(BookmarkId id, bool frozen) {
    std::lock_guard<std::mutex> lk(m_mtx);
    auto* b = m_bookmarks.find(id);
    if (!b) return false;
    b->frozen = frozen;
    if (frozen && b->frozenValue.bytes.empty()) {
        b->frozenValue = TypedValue::zero(b->type);
    }
    return true;
}

bool Engine::setBookmarkValue(BookmarkId id, const TypedValue& v) {
    std::lock_guard<std::mutex> lk(m_mtx);
    auto* b = m_bookmarks.find(id);
    if (!b) return false;
    b->frozenValue = v;
    // Also push the value into the target now so the change is visible
    // immediately; the freezer takes over on the next tick.
    if (m_process && b->address) {
        SIZE_T w = 0;
        ::WriteProcessMemory(m_process,
                              reinterpret_cast<LPVOID>(b->address),
                              v.bytes.data(), v.bytes.size(), &w);
    }
    return true;
}

bool Engine::setBookmarkName(BookmarkId id, std::string name) {
    std::lock_guard<std::mutex> lk(m_mtx);
    auto* b = m_bookmarks.find(id);
    if (!b) return false;
    b->name = std::move(name);
    return true;
}

bool Engine::setBookmarkType(BookmarkId id, ValueType t) {
    std::lock_guard<std::mutex> lk(m_mtx);
    auto* b = m_bookmarks.find(id);
    if (!b) return false;
    b->type = t;
    b->frozenValue = TypedValue::zero(t);
    return true;
}

std::vector<Bookmark> Engine::bookmarks() {
    std::lock_guard<std::mutex> lk(m_mtx);
    return m_bookmarks.list();
}

TypedValue Engine::readBookmarkValue(const Bookmark& b) {
    TypedValue v = TypedValue::zero(b.type);
    if (!m_process) return v;

    Address addr = b.address;
    if (!b.pointerOffsets.empty()) {
        addr = resolvePointerPath(b);
        if (!addr) return v;
    }

    std::size_t sz = fixedSize(b.type);
    if (!sz) return v;
    v.bytes.assign(sz, 0);
    SIZE_T got = 0;
    ::ReadProcessMemory(m_process, reinterpret_cast<LPCVOID>(addr),
                         v.bytes.data(), sz, &got);
    return v;
}

Address Engine::resolvePointerPath(const Bookmark& b) {
    Address cur = b.pointerBase;
    for (std::size_t i = 0; i < b.pointerOffsets.size(); ++i) {
        Address next = 0;
        SIZE_T got = 0;
        if (!::ReadProcessMemory(m_process,
                                   reinterpret_cast<LPCVOID>(cur),
                                   &next, sizeof(next), &got) || got != sizeof(next)) {
            return 0;
        }
        cur = next + b.pointerOffsets[i];
    }
    return cur;
}

// ---------------------------------------------------------------------------
bool Engine::readMemory(Address a, void* buf, std::size_t n) {
    HANDLE p;
    { std::lock_guard<std::mutex> lk(m_mtx); p = m_process; }
    if (!p) return false;
    SIZE_T got = 0;
    return ::ReadProcessMemory(p, reinterpret_cast<LPCVOID>(a), buf, n, &got)
           && got == n;
}

bool Engine::writeMemory(Address a, const void* buf, std::size_t n) {
    HANDLE p;
    { std::lock_guard<std::mutex> lk(m_mtx); p = m_process; }
    if (!p) return false;
    DWORD oldProt = 0;
    ::VirtualProtectEx(p, reinterpret_cast<LPVOID>(a), n,
                        PAGE_READWRITE, &oldProt);
    SIZE_T w = 0;
    BOOL ok = ::WriteProcessMemory(p, reinterpret_cast<LPVOID>(a), buf, n, &w);
    if (oldProt) {
        DWORD tmp = 0;
        ::VirtualProtectEx(p, reinterpret_cast<LPVOID>(a), n, oldProt, &tmp);
    }
    return ok && w == n;
}

}

void Engine::workerLoop() {
    while (!m_workerQuit.load()) {
        std::function<void()> task;
        {
            std::unique_lock<std::mutex> lk(m_taskMtx);
            m_taskCv.wait(lk, [this]{ return !m_tasks.empty() || m_workerQuit.load(); });
            if (m_workerQuit.load() && m_tasks.empty()) break;
            task = std::move(m_tasks.front());
            m_tasks.pop();
        }
        try { task(); } catch (...) { pushLog("[!] task threw"); }
    }
}

#include "freezer.h"

namespace cheat {

Freezer::~Freezer() { stop(); }

void Freezer::start(HANDLE process, Provider provider) {
    stop();
    if (!process || !provider) return;
    m_process  = process;
    m_provider = std::move(provider);
    m_running  = true;
    m_thread   = std::thread(&Freezer::loop, this);
}

void Freezer::stop() {
    m_running = false;
    if (m_thread.joinable()) m_thread.join();
    m_process = nullptr;
}

void Freezer::loop() {
    while (m_running.load()) {
        const auto bms = m_provider ? m_provider() : std::vector<Bookmark>{};

        for (const auto& b : bms) {
            if (!b.frozen || b.frozenValue.bytes.empty()) continue;

            // Un-protect the target page just enough to write, then restore.
            // Write-only via VirtualProtectEx: if the page isn't writable
            // we can still succeed, otherwise WriteProcessMemory fails.
            DWORD oldProt = 0;
            ::VirtualProtectEx(m_process,
                                reinterpret_cast<LPVOID>(b.address),
                                b.frozenValue.bytes.size(),
                                PAGE_READWRITE, &oldProt);
            SIZE_T w = 0;
            ::WriteProcessMemory(m_process,
                                  reinterpret_cast<LPVOID>(b.address),
                                  b.frozenValue.bytes.data(),
                                  b.frozenValue.bytes.size(), &w);
            if (oldProt) {
                DWORD tmp = 0;
                ::VirtualProtectEx(m_process,
                                    reinterpret_cast<LPVOID>(b.address),
                                    b.frozenValue.bytes.size(),
                                    oldProt, &tmp);
            }
        }

        std::this_thread::sleep_for(std::chrono::milliseconds(m_tickMs.load()));
    }
}

namespace cheat {

std::vector<Region> enumerateRegions(HANDLE process, bool writableOnly) {
    std::vector<Region> out;
    if (!process) return out;

    SYSTEM_INFO si{};
    ::GetSystemInfo(&si);

    auto addr    = reinterpret_cast<Byte*>(si.lpMinimumApplicationAddress);
    auto maxAddr = reinterpret_cast<Byte*>(si.lpMaximumApplicationAddress);

    MEMORY_BASIC_INFORMATION mbi{};
    while (addr < maxAddr) {
        if (::VirtualQueryEx(process, addr, &mbi, sizeof(mbi)) != sizeof(mbi)) {
            break;
        }

        const bool committed = (mbi.State == MEM_COMMIT);
        const bool wantable  = writableOnly ? protectWritable(mbi.Protect)
                                             : protectReadable(mbi.Protect);
        if (committed && wantable) {
            Region r{};
            r.base    = reinterpret_cast<Address>(mbi.BaseAddress);
            r.size    = mbi.RegionSize;
            r.protect = mbi.Protect;
            r.type    = mbi.Type;
            out.push_back(r);
        }

        addr += mbi.RegionSize;
    }
    return out;
}

// mem_regions.h -- enumerate the debuggee's readable / writable memory
// pages. The scanner iterates these.
#pragma once

#include "common.h"

namespace cheat {

struct Region {
    Address base{};
    std::size_t size{};
    DWORD protect{};          // PAGE_* flags
    DWORD type{};             // MEM_PRIVATE / MEM_MAPPED / MEM_IMAGE
};

// Walk the process address space and return every committed region that
// is readable (and not a guard page). If `writableOnly` is true, skip
// read-only regions -- useful for scanning values the target owns,
// skipping modules' .text.
std::vector<Region> enumerateRegions(HANDLE process, bool writableOnly);

inline bool protectReadable(DWORD p) {
    const DWORD readableMask =
        PAGE_READONLY | PAGE_READWRITE | PAGE_WRITECOPY |
        PAGE_EXECUTE_READ | PAGE_EXECUTE_READWRITE | PAGE_EXECUTE_WRITECOPY;
    return (p & readableMask) != 0 && (p & PAGE_GUARD) == 0;
}

inline bool protectWritable(DWORD p) {
    const DWORD writableMask =
        PAGE_READWRITE | PAGE_WRITECOPY |
        PAGE_EXECUTE_READWRITE | PAGE_EXECUTE_WRITECOPY;
    return (p & writableMask) != 0 && (p & PAGE_GUARD) == 0;
}

} // namespace cheat

```cpp
#include "pointer_scan.h"

#include <algorithm>

namespace cheat {

namespace {

// Compact "a pointer value P was found at source slot S" record. Sorted
// by `dest` so a range lookup [T - off, T] is a single lower_bound.
struct PtrHit {
    Address dest{};     // the value we read at `src`
    Address src{};      // where that pointer lives in memory
    bool    srcIsImage{}; // src came from a MEM_IMAGE region (module)
};

// Build the hit table by walking every readable region and interpreting
// each aligned 8-byte slot as a pointer. Only slots that land inside
// another readable region are kept -- a pointer that points to nothing
// mapped is not useful for a chain.
std::vector<PtrHit> buildPtrMap(HANDLE process,
                                 const std::vector<Region>& regions,
                                 const std::atomic<bool>& cancel,
                                 PointerProgress prog) {
    std::vector<PtrHit> hits;
    hits.reserve(1 << 20);

    constexpr std::size_t kChunk = 4 * 1024 * 1024;

    // Precompute a sorted (base, end) list of valid destinations so a
    // pointer value can be checked with binary search.
    std::vector<std::pair<Address, Address>> readable;
    readable.reserve(regions.size());
    for (const auto& r : regions) {
        readable.emplace_back(r.base, r.base + r.size);
    }
    std::sort(readable.begin(), readable.end());

    auto isMapped = [&](Address a) {
        auto it = std::upper_bound(readable.begin(), readable.end(),
                                     std::make_pair(a, Address{0}));
        if (it == readable.begin()) return false;
        --it;
        return a >= it->first && a < it->second;
    };

    std::size_t totalPages = 0;
    for (const auto& r : regions) totalPages += (r.size + kChunk - 1) / kChunk;

    Bytes buf;
    buf.reserve(kChunk);

    std::size_t done = 0;
    for (const auto& reg : regions) {
        const bool srcIsImage = (reg.type == MEM_IMAGE);

        Address cursor = reg.base;
        std::size_t remain = reg.size;
        while (remain > 0) {
            if (cancel.load()) return hits;
            std::size_t take = std::min(remain, kChunk);
            buf.resize(take);
            SIZE_T got = 0;
            if (::ReadProcessMemory(process,
                                     reinterpret_cast<LPCVOID>(cursor),
                                     buf.data(), take, &got) && got >= 8) {
                const std::size_t aligned = got & ~std::size_t{7};
                for (std::size_t off = 0; off + 8 <= aligned; off += 8) {
                    Address val = 0;
                    std::memcpy(&val, buf.data() + off, 8);
                    if (val < 0x10000 || val > 0x7FFFFFFFFFFF) continue;
                    if (!isMapped(val)) continue;
                    PtrHit h{};
                    h.dest       = val;
                    h.src        = cursor + off;
                    h.srcIsImage = srcIsImage;
                    hits.push_back(h);
                }
            }
            cursor += take;
            remain -= take;
            ++done;
            if (prog && (done % 16 == 0)) prog(done, totalPages);
        }
    }
    if (prog) prog(totalPages, totalPages);
    std::sort(hits.begin(), hits.end(),
               [](const PtrHit& a, const PtrHit& b){ return a.dest < b.dest; });
    return hits;
}

// All hits whose `dest` lies in [lo, hi].
std::pair<std::size_t, std::size_t> hitsInRange(const std::vector<PtrHit>& hits,
                                                  Address lo, Address hi) {
    auto first = std::lower_bound(hits.begin(), hits.end(), lo,
                                    [](const PtrHit& h, Address v){ return h.dest < v; });
    auto last  = std::upper_bound(hits.begin(), hits.end(), hi,
                                    [](Address v, const PtrHit& h){ return v < h.dest; });
    return { static_cast<std::size_t>(first - hits.begin()),
             static_cast<std::size_t>(last  - hits.begin()) };
}

} // anonymous

std::vector<PointerPath> PointerScanner::find(HANDLE process, Address target,
                                                const PointerScanConfig& cfg,
                                                const std::atomic<bool>& cancel,
                                                PointerProgress prog) {
    std::vector<PointerPath> out;
    if (!process || !target) return out;

    // Build the pointer map once; subsequent BFS iterations are cheap.
    auto regions = enumerateRegions(process, /*writableOnly*/ false);
    auto hits    = buildPtrMap(process, regions, cancel, prog);
    if (hits.empty()) return out;

    struct QItem {
        Address          cur;
        int              depthLeft;
        std::vector<int> offsets;   // innermost first
    };

    std::vector<QItem> frontier;
    frontier.push_back({ target, cfg.maxDepth, {} });

    while (!frontier.empty()) {
        if (cancel.load() || out.size() >= cfg.maxResults) break;

        QItem q = std::move(frontier.back());
        frontier.pop_back();

        Address lo = (q.cur > (Address)cfg.maxOffset) ? q.cur - cfg.maxOffset : 0;
        Address hi = q.cur;
        auto [lb, ub] = hitsInRange(hits, lo, hi);

        for (std::size_t i = lb; i < ub; ++i) {
            if (out.size() >= cfg.maxResults) break;
            const auto& h = hits[i];
            int off = static_cast<int>(q.cur - h.dest);

            // Fresh path = [this off, then the deeper offsets we already had]
            std::vector<int> path;
            path.reserve(q.offsets.size() + 1);
            path.push_back(off);
            path.insert(path.end(), q.offsets.begin(), q.offsets.end());

            if (h.srcIsImage) {
                out.push_back({ h.src, std::move(path) });
            } else if (q.depthLeft > 1) {
                frontier.push_back({ h.src, q.depthLeft - 1, std::move(path) });
            }
        }
    }

    return out;
}

#include "scanner.h"

#include <future>

namespace cheat {

namespace {

std::size_t effectiveStride(const ScanConfig& cfg) {
    if (!cfg.fastScan) return 1;
    if (cfg.alignment > 0) return cfg.alignment;
    std::size_t sz = fixedSize(cfg.type);
    return sz ? sz : 1;
}

std::size_t itemSize(const ScanConfig& cfg) {
    std::size_t sz = fixedSize(cfg.type);
    if (sz) return sz;
    return cfg.operand.bytes.size();
}

// Scan one contiguous page / chunk in memory. Appends matches to `out`.
void scanChunk(const ScanConfig& cfg,
               Address base,
               const Byte* buf, std::size_t len,
               std::vector<ScanResult>& out) {
    const std::size_t stride = effectiveStride(cfg);
    const std::size_t sz     = itemSize(cfg);
    if (!sz || len < sz) return;

    const std::size_t limit = len - sz;
    for (std::size_t off = 0; off <= limit; off += stride) {
        const Byte* here = buf + off;
        if (cfg.operand.matches(cfg.op, here, len - off,
                                  /*prev*/ nullptr,
                                  cfg.op == ScanOp::Between ? &cfg.operand2 : nullptr)) {
            ScanResult r{};
            r.address = base + off;
            r.value.assign(here, here + sz);
            out.push_back(std::move(r));
        }
    }
}

} // anonymous

std::vector<ScanResult> Scanner::firstScan(HANDLE process,
                                             const ScanConfig& cfg,
                                             const std::atomic<bool>& cancel,
                                             ScanProgress prog) {
    std::vector<ScanResult> out;
    if (!process) return out;

    auto regions = enumerateRegions(process, cfg.writableOnly);
    if (regions.empty()) return out;

    // Chunk every region into <=4 MiB slices so we don't allocate huge
    // buffers and so we can honour cancellation promptly.
    constexpr std::size_t kChunk = 4 * 1024 * 1024;

    std::size_t totalPages = 0;
    for (const auto& r : regions) totalPages += (r.size + kChunk - 1) / kChunk;

    Bytes buf;
    buf.reserve(kChunk);

    std::size_t done = 0;
    for (const auto& reg : regions) {
        Address cursor = reg.base;
        std::size_t remain = reg.size;
        while (remain > 0) {
            if (cancel.load()) { if (prog) prog(done, totalPages); return out; }
            std::size_t take = std::min(remain, kChunk);
            buf.resize(take);
            SIZE_T got = 0;
            BOOL ok = ::ReadProcessMemory(process,
                                           reinterpret_cast<LPCVOID>(cursor),
                                           buf.data(), take, &got);
            if (ok && got >= itemSize(cfg)) {
                scanChunk(cfg, cursor, buf.data(), got, out);
            }
            cursor += take;
            remain -= take;
            ++done;
            if (prog && (done % 16 == 0)) prog(done, totalPages);
        }
    }
    if (prog) prog(totalPages, totalPages);
    return out;
}

std::vector<ScanResult> Scanner::nextScan(HANDLE process,
                                            const std::vector<ScanResult>& prev,
                                            const ScanConfig& cfg,
                                            const std::atomic<bool>& cancel,
                                            ScanProgress prog) {
    std::vector<ScanResult> out;
    if (!process) return out;

    out.reserve(prev.size() / 2);

    const std::size_t sz = itemSize(cfg);
    if (!sz) return out;

    std::size_t done = 0;
    const std::size_t total = prev.size();

    Byte here[32]{};  // enough for fixed scalars
    Bytes heapBuf;
    const std::size_t stackCap = sizeof(here);

    for (const auto& e : prev) {
        if (cancel.load()) { if (prog) prog(done, total); return out; }

        Byte* dst = (sz <= stackCap) ? here : (heapBuf.resize(sz), heapBuf.data());
        SIZE_T got = 0;
        BOOL ok = ::ReadProcessMemory(process,
                                       reinterpret_cast<LPCVOID>(e.address),
                                       dst, sz, &got);
        if (!ok || got != sz) {
            ++done;
            continue;
        }

        const Byte* prevBytes = e.value.size() == sz ? e.value.data() : nullptr;
        if (cfg.operand.matches(cfg.op, dst, sz, prevBytes,
                                  cfg.op == ScanOp::Between ? &cfg.operand2 : nullptr)) {
            ScanResult r{};
            r.address = e.address;
            r.value.assign(dst, dst + sz);
            out.push_back(std::move(r));
        }
        ++done;
        if (prog && (done % 1024 == 0)) prog(done, total);
    }
    if (prog) prog(total, total);
    return out;
}

// scanner.h -- first-scan + next-scan memory search.
//
// A first-scan walks every committed writable region, reading in large
// chunks and applying the comparator at every aligned position. A
// next-scan filters the previous result set in place. Both report progress
// through a callback and honour an atomic cancel flag so the UI can stop
// a runaway scan.
#pragma once

#include "common.h"
#include "mem_regions.h"
#include "value_types.h"

namespace cheat {

struct ScanConfig {
    ValueType  type{ValueType::I32};
    ScanOp     op{ScanOp::Exact};
    TypedValue operand;
    TypedValue operand2;        // Between upper bound (optional)
    std::size_t alignment{0};   // 0 = default (type size, min 1)
    bool       fastScan{true};  // honour alignment vs. scan every byte
    bool       writableOnly{true};
};

struct ScanResult {
    Address address{};
    Bytes   value;              // captured so next-scan can compare
};

using ScanProgress = std::function<void(std::size_t donePages,
                                          std::size_t totalPages)>;

class Scanner {
public:
    std::vector<ScanResult> firstScan(HANDLE process,
                                        const ScanConfig& cfg,
                                        const std::atomic<bool>& cancel,
                                        ScanProgress prog = {});

    std::vector<ScanResult> nextScan(HANDLE process,
                                       const std::vector<ScanResult>& prev,
                                       const ScanConfig& cfg,
                                       const std::atomic<bool>& cancel,
                                       ScanProgress prog = {});
};

} // namespace cheat

void App::run() {
    MSG msg{};
    bool done = false;
    while (!done) {
        while (::PeekMessage(&msg, nullptr, 0, 0, PM_REMOVE)) {
            ::TranslateMessage(&msg);
            ::DispatchMessage(&msg);
            if (msg.message == WM_QUIT) done = true;
        }
        if (done) break;

        if (m_resizePending) {
            dropRenderTarget();
            m_sc->ResizeBuffers(0, m_resizeW, m_resizeH, DXGI_FORMAT_UNKNOWN, 0);
            makeRenderTarget();
            m_resizePending = false;
        }
        frame();
        present();
    }
}

    if (!s) return false;

    const ValueType  vt = typeFromIndex(ui.scanType);

            ImGui::SetNextItemWidth(-1);
            ImGui::InputText("##v2", ui.scanValue2, sizeof(ui.scanValue2));
        }

        ImGui::TextDisabled("(no operand needed)");

    ImGui::Checkbox("writable only",       &ui.writableOnly);

    const bool firstOk   = opIsFirstScanValid(op);

    ImGui::BeginDisabled(scanning || !eng.isAttached() || !firstOk);
    if (ImGui::Button(hasResult ? "Restart scan" : "First scan")) {

        cfg.op            = op;
        cfg.fastScan      = ui.fastScan;
        cfg.writableOnly  = ui.writableOnly;
        if (opNeedsOperand(op)) {
            cfg.operand = TypedValue::parse(vt, ui.scanValue);
            if (op == ScanOp::Between) {
                cfg.operand2 = TypedValue::parse(vt, ui.scanValue2);
            }
        } else {
            cfg.operand = TypedValue::zero(vt);
        }
        eng.resetScan();
        eng.startFirstScan(cfg);
    }
    ImGui::EndDisabled();

    ImGui::SameLine();
    ImGui::BeginDisabled(scanning || !hasResult);
    if (ImGui::Button("Next scan")) {
        ScanConfig cfg{};
        cfg.type         = vt;
        cfg.op           = op;
        cfg.fastScan     = ui.fastScan;
        cfg.writableOnly = ui.writableOnly;
        if (opNeedsOperand(op)) {
            cfg.operand = TypedValue::parse(vt, ui.scanValue);
            if (op == ScanOp::Between) {
                cfg.operand2 = TypedValue::parse(vt, ui.scanValue2);
            }
        } else {
            cfg.operand = TypedValue::zero(vt);
        }
        eng.startNextScan(cfg);
    }
    ImGui::EndDisabled();

    ImGui::SameLine();
    ImGui::BeginDisabled(!scanning);
    if (ImGui::Button("Cancel")) eng.cancelScan();
    ImGui::EndDisabled();

    ImGui::SameLine();
    ImGui::BeginDisabled(scanning || !hasResult);
    if (ImGui::Button("Reset")) eng.resetScan();
    ImGui::EndDisabled();

    if (scanning) {
        ImGui::ProgressBar(eng.scanProgress(), ImVec2(-1, 0));
    }

namespace cheat {

std::size_t fixedSize(ValueType t) {
    switch (t) {
        case ValueType::I8:  case ValueType::U8:  return 1;
        case ValueType::I16: case ValueType::U16: return 2;
        case ValueType::I32: case ValueType::U32: case ValueType::F32: return 4;
        case ValueType::I64: case ValueType::U64: case ValueType::F64: return 8;
        default: return 0;   // Bytes / strings are variable
    }
}

bool isInteger(ValueType t) {
    switch (t) {
        case ValueType::I8:  case ValueType::U8:
        case ValueType::I16: case ValueType::U16:
        case ValueType::I32: case ValueType::U32:
        case ValueType::I64: case ValueType::U64:
            return true;
        default: return false;
    }
}

bool isFloat(ValueType t) {
    return t == ValueType::F32 || t == ValueType::F64;
}

bool isNumeric(ValueType t) { return isInteger(t) || isFloat(t); }

const char* name(ValueType t) {
    switch (t) {
        case ValueType::I8:  return "int8";
        case ValueType::U8:  return "uint8";
        case ValueType::I16: return "int16";
        case ValueType::U16: return "uint16";
        case ValueType::I32: return "int32";
        case ValueType::U32: return "uint32";
        case ValueType::I64: return "int64";
        case ValueType::U64: return "uint64";
        case ValueType::F32: return "float";
        case ValueType::F64: return "double";
        case ValueType::Bytes:       return "bytes";
        case ValueType::AsciiString: return "string";
        case ValueType::WideString:  return "wstring";
    }
    return "?";
}

TypedValue TypedValue::zero(ValueType t) {
    TypedValue v;
    v.type = t;
    std::size_t sz = fixedSize(t);
    if (sz) v.bytes.assign(sz, 0);
    return v;

namespace {

template <typename T>
TypedValue packInt(ValueType vt, long long x) {
    TypedValue v;
    v.type = vt;
    T n = static_cast<T>(x);
    v.bytes.assign(reinterpret_cast<Byte*>(&n),
                    reinterpret_cast<Byte*>(&n) + sizeof(T));
    return v;
}

template <typename T>
TypedValue packFloat(ValueType vt, double x) {
    TypedValue v;
    v.type = vt;
    T n = static_cast<T>(x);
    v.bytes.assign(reinterpret_cast<Byte*>(&n),
                    reinterpret_cast<Byte*>(&n) + sizeof(T));
    return v;
}

// Parse "DE AD BE EF" or "DE ?? BE EF" style aob patterns.
std::pair<Bytes, Bytes> parseAob(const std::string& text) {
    Bytes out, mask;
    const char* p = text.c_str();
    while (*p) {
        while (*p == ' ' || *p == '\t' || *p == ',') ++p;
        if (!*p) break;
        if (p[0] == '?' && p[1] == '?') {
            out.push_back(0);
            mask.push_back(0);
            p += 2;
        } else if (std::isxdigit(static_cast<unsigned char>(p[0])) &&
                   std::isxdigit(static_cast<unsigned char>(p[1]))) {
            char buf[3] = { p[0], p[1], 0 };
            out.push_back(static_cast<Byte>(std::strtoul(buf, nullptr, 16)));
            mask.push_back(1);
            p += 2;
        } else {
            return {{}, {}};  // malformed
        }
    }
    return { std::move(out), std::move(mask) };
}

} // anonymous

TypedValue TypedValue::parse(ValueType t, const std::string& text, bool* ok) {
    auto setOk = [&](bool v) { if (ok) *ok = v; };
    setOk(true);

    if (isInteger(t)) {
        try {
            long long x = 0;
            std::size_t pos = 0;
            if (text.rfind("0x", 0) == 0 || text.rfind("0X", 0) == 0) {
                x = std::stoll(text.substr(2), &pos, 16);
            } else {
                x = std::stoll(text, &pos, 10);
            }
            switch (t) {
                case ValueType::I8:  return packInt<std::int8_t>(t, x);
                case ValueType::U8:  return packInt<std::uint8_t>(t, x);
                case ValueType::I16: return packInt<std::int16_t>(t, x);
                case ValueType::U16: return packInt<std::uint16_t>(t, x);
                case ValueType::I32: return packInt<std::int32_t>(t, x);
                case ValueType::U32: return packInt<std::uint32_t>(t, x);
                case ValueType::I64: return packInt<std::int64_t>(t, x);
                case ValueType::U64: return packInt<std::uint64_t>(t, x);
                default: break;
            }
        } catch (...) { setOk(false); return zero(t); }
    } else if (isFloat(t)) {
        try {
            double x = std::stod(text);
            return (t == ValueType::F32) ? packFloat<float>(t, x)
                                          : packFloat<double>(t, x);
        } catch (...) { setOk(false); return zero(t); }
    } else if (t == ValueType::AsciiString) {
        TypedValue v;
        v.type = t;
        v.bytes.assign(text.begin(), text.end());
        return v;
    } else if (t == ValueType::WideString) {
        TypedValue v;
        v.type = t;
        std::wstring w = utf8_to_wide(text);
        v.bytes.assign(reinterpret_cast<const Byte*>(w.data()),
                        reinterpret_cast<const Byte*>(w.data() + w.size()));
        return v;
    } else if (t == ValueType::Bytes) {
        TypedValue v;
        v.type = t;
        auto [bs, ms] = parseAob(text);
        if (bs.empty()) { setOk(false); return v; }
        v.bytes = std::move(bs);
        v.mask  = std::move(ms);
        return v;
    }

    setOk(false);
    return zero(t);
}

std::string TypedValue::toString() const {
    auto u8  = [&](std::size_t i) { return bytes[i]; };
    auto rd  = [&](auto* p, std::size_t n) {
        if (bytes.size() < n) return false;
        std::memcpy(p, bytes.data(), n);
        return true;
    };
    char buf[64];
    switch (type) {
        case ValueType::I8:  return sfmt("%d",   (int)(std::int8_t)u8(0));
        case ValueType::U8:  return sfmt("%u",   (unsigned)u8(0));
        case ValueType::I16: { std::int16_t v;  rd(&v, 2); return sfmt("%d",  (int)v); }
        case ValueType::U16: { std::uint16_t v; rd(&v, 2); return sfmt("%u",  (unsigned)v); }
        case ValueType::I32: { std::int32_t v;  rd(&v, 4); return sfmt("%d",  (int)v); }
        case ValueType::U32: { std::uint32_t v; rd(&v, 4); return sfmt("%u",  (unsigned)v); }
        case ValueType::I64: { std::int64_t v;  rd(&v, 8); return sfmt("%lld",(long long)v); }
        case ValueType::U64: { std::uint64_t v; rd(&v, 8); return sfmt("%llu",(unsigned long long)v); }
        case ValueType::F32: { float v;         rd(&v, 4); std::snprintf(buf,sizeof(buf),"%g",v); return buf; }
        case ValueType::F64: { double v;        rd(&v, 8); std::snprintf(buf,sizeof(buf),"%g",v); return buf; }
        case ValueType::AsciiString:
            return std::string(bytes.begin(), bytes.end());
        case ValueType::WideString: {
            std::wstring w(reinterpret_cast<const wchar_t*>(bytes.data()),
                            bytes.size() / sizeof(wchar_t));
            return wide_to_utf8(w);
        }
        case ValueType::Bytes: {
            std::string s;
            for (std::size_t i = 0; i < bytes.size(); ++i) {
                if (!s.empty()) s += ' ';
                if (i < mask.size() && mask[i] == 0) s += "??";
                else s += sfmt("%02X", bytes[i]);
            }
            return s;
        }
    }
    return {};
}

namespace {

template <typename T>
bool cmpInt(ScanOp op, const Byte* a, const Byte* b, const Byte* prev) {
    T x, y;
    std::memcpy(&x, a, sizeof(T));
    std::memcpy(&y, b, sizeof(T));
    T p = 0;
    if (prev) std::memcpy(&p, prev, sizeof(T));
    switch (op) {
        case ScanOp::Exact:     return x == y;
        case ScanOp::NotEqual:  return x != y;
        case ScanOp::Greater:   return x >  y;
        case ScanOp::GreaterEq: return x >= y;
        case ScanOp::Less:      return x <  y;
        case ScanOp::LessEq:    return x <= y;
        case ScanOp::Changed:   return x != p;
        case ScanOp::Unchanged: return x == p;
        case ScanOp::Increased: return x >  p;
        case ScanOp::Decreased: return x <  p;
        default: return false;
    }
}

template <typename T>
bool cmpBetween(const Byte* a, const Byte* lo, const Byte* hi) {
    T x, l, h;
    std::memcpy(&x, a,  sizeof(T));
    std::memcpy(&l, lo, sizeof(T));
    std::memcpy(&h, hi, sizeof(T));
    if (l > h) std::swap(l, h);
    return x >= l && x <= h;
}

template <typename T>
bool cmpFloat(ScanOp op, const Byte* a, const Byte* b, const Byte* prev) {
    T x, y;
    std::memcpy(&x, a, sizeof(T));
    std::memcpy(&y, b, sizeof(T));
    T p = 0;
    if (prev) std::memcpy(&p, prev, sizeof(T));
    const T eps = static_cast<T>(0.0001);
    switch (op) {
        case ScanOp::Exact:     return std::abs(x - y) < eps;
        case ScanOp::NotEqual:  return std::abs(x - y) >= eps;
        case ScanOp::Greater:   return x >  y;
        case ScanOp::GreaterEq: return x >= y;
        case ScanOp::Less:      return x <  y;
        case ScanOp::LessEq:    return x <= y;
        case ScanOp::Changed:   return std::abs(x - p) >= eps;
        case ScanOp::Unchanged: return std::abs(x - p) <  eps;
        case ScanOp::Increased: return x >  p;
        case ScanOp::Decreased: return x <  p;
        default: return false;
    }
}

template <typename T>
bool cmpFloatBetween(const Byte* a, const Byte* lo, const Byte* hi) {
    T x, l, h;
    std::memcpy(&x, a,  sizeof(T));
    std::memcpy(&l, lo, sizeof(T));
    std::memcpy(&h, hi, sizeof(T));
    if (l > h) std::swap(l, h);
    return x >= l && x <= h;
}

} // anonymous

bool TypedValue::matches(ScanOp op,
                          const Byte* candidate, std::size_t len,
                          const Byte* prev,
                          const TypedValue* operand2) const {
    if (op == ScanOp::Unknown) return true;

    std::size_t need = fixedSize(type);
    if (need > 0 && len < need) return false;

    if (type == ValueType::Bytes) {
        if (bytes.size() > len) return false;
        for (std::size_t i = 0; i < bytes.size(); ++i) {
            if (!mask.empty() && mask[i] == 0) continue;
            if (candidate[i] != bytes[i]) return false;
        }
        return op == ScanOp::Exact;   // Bytes only supports Exact today
    }

    if (type == ValueType::AsciiString || type == ValueType::WideString) {
        if (bytes.size() > len) return false;
        if (op != ScanOp::Exact) return false;
        return std::memcmp(candidate, bytes.data(), bytes.size()) == 0;
    }

    if (op == ScanOp::Between) {
        if (!operand2 || operand2->bytes.size() < need) return false;
        switch (type) {
            case ValueType::I8:  return cmpBetween<std::int8_t>  (candidate, bytes.data(), operand2->bytes.data());
            case ValueType::U8:  return cmpBetween<std::uint8_t> (candidate, bytes.data(), operand2->bytes.data());
            case ValueType::I16: return cmpBetween<std::int16_t> (candidate, bytes.data(), operand2->bytes.data());
            case ValueType::U16: return cmpBetween<std::uint16_t>(candidate, bytes.data(), operand2->bytes.data());
            case ValueType::I32: return cmpBetween<std::int32_t> (candidate, bytes.data(), operand2->bytes.data());
            case ValueType::U32: return cmpBetween<std::uint32_t>(candidate, bytes.data(), operand2->bytes.data());
            case ValueType::I64: return cmpBetween<std::int64_t> (candidate, bytes.data(), operand2->bytes.data());
            case ValueType::U64: return cmpBetween<std::uint64_t>(candidate, bytes.data(), operand2->bytes.data());
            case ValueType::F32: return cmpFloatBetween<float>   (candidate, bytes.data(), operand2->bytes.data());
            case ValueType::F64: return cmpFloatBetween<double>  (candidate, bytes.data(), operand2->bytes.data());
            default: return false;
        }
    }

    switch (type) {
        case ValueType::I8:  return cmpInt<std::int8_t>  (op, candidate, bytes.data(), prev);
        case ValueType::U8:  return cmpInt<std::uint8_t> (op, candidate, bytes.data(), prev);
        case ValueType::I16: return cmpInt<std::int16_t> (op, candidate, bytes.data(), prev);
        case ValueType::U16: return cmpInt<std::uint16_t>(op, candidate, bytes.data(), prev);
        case ValueType::I32: return cmpInt<std::int32_t> (op, candidate, bytes.data(), prev);
        case ValueType::U32: return cmpInt<std::uint32_t>(op, candidate, bytes.data(), prev);
        case ValueType::I64: return cmpInt<std::int64_t> (op, candidate, bytes.data(), prev);
        case ValueType::U64: return cmpInt<std::uint64_t>(op, candidate, bytes.data(), prev);
        case ValueType::F32: return cmpFloat<float>      (op, candidate, bytes.data(), prev);
        case ValueType::F64: return cmpFloat<double>     (op, candidate, bytes.data(), prev);
        default: return false;
    }
}

// value_types.h -- typed scalar / string / byte-pattern values used
// across the scanner, freezer and CE-table I/O.
#pragma once

#include "common.h"

namespace cheat {

enum class ValueType {
    I8, U8, I16, U16, I32, U32, I64, U64,
    F32, F64,
    Bytes,          // "DE AD BE EF" aob-scan pattern (?? wildcard)
    AsciiString,
    WideString,
};

// Comparison a scanner applies against each candidate in memory.
// First-scan vs next-scan is a property of the scan session, not the op:
//   - Exact/Greater/Less/Between use the user-supplied operand(s).
//   - Changed/Unchanged/Increased/Decreased compare to the PREVIOUS value
//     captured by the last scan; invalid as a first-scan op.
//   - Unknown is first-scan only -- capture all values without filtering.
enum class ScanOp {
    Unknown,
    Exact,
    NotEqual,
    Greater,
    GreaterEq,
    Less,
    LessEq,
    Between,
    Changed,
    Unchanged,
    Increased,
    Decreased,
};

// Fixed byte size for integer / float types. Returns 0 for variable-length
// types (Bytes / strings).
std::size_t fixedSize(ValueType t);

bool isNumeric(ValueType t);
bool isInteger(ValueType t);
bool isFloat(ValueType t);

const char* name(ValueType t);
const char* name(ScanOp op);

struct TypedValue {
    ValueType type{ValueType::I32};
    Bytes     bytes;                    // raw storage matching `type`
    // For Bytes-scan: parallel wildcard mask, 1 = compare, 0 = wildcard.
    // Empty means no wildcards.
    Bytes     mask;

    static TypedValue zero(ValueType t);
    static TypedValue parse(ValueType t, const std::string& text,
                              bool* ok = nullptr);

    std::string toString() const;

    // Compare this value against `candidate`+`len` bytes in memory.
    // `prev` is the previously-captured bytes for next-scan ops; nullptr
    // for first-scan. `operand2` is the upper bound for Between.
    bool matches(ScanOp op,
                 const Byte* candidate, std::size_t len,
                 const Byte* prev,
                 const TypedValue* operand2) const;
};

} // namespace cheat
