```md
# Fighting System (Roblox / Luau)

A melee combat system with lag compensation, client-side prediction and a server-side anti-cheat:
M1 combos, block / parry / guard break, dashes with i-frames, a four-ability kit, ragdolls and training dummies.

- **~5,100 lines of Luau**, no external libraries
- **Lag compensation:** the server rewinds targets to what the attacker actually saw
- **Prediction:** the client plays hits immediately, the server confirms or rejects them
- **42 automated tests** in 5 specs, including an integration test of the real hit pipeline

<!-- Gameplay video: add link here -->

## Controls

| Key | Action |
|---|---|
| **M1** | Combo, the 4th hit launches |
| **F** | Block; tap right before a hit to parry |
| **Q** | Dash; sideways or back = dodge with i-frames |
| **1 / 2 / 3 / 4** | Rush Grab, Ground Slam, Barrage, Uppercut |
| **T** | Lock on to a target |
| **Shift** | Lock camera |
| **B** | Training dummy mode: idle / block / fight |

Hits chain: M1 ×4 → dash → M1 ×4 → ability → M1… (any landed non-M1 hit cancels the M1 end lag).

## The interesting parts

### Lag compensation
[`History`](src/ServerScriptService/Combat/History.luau) stores every fighter's root CFrame with the server time on each Heartbeat.
Each request carries the client's `GetServerTimeNow()` stamp; [`CombatService`](src/ServerScriptService/Combat/CombatService.luau) trusts it only within
`MaxRewind` (0.3 s), rewinds targets to that moment and runs the hit test there. The attacker's reported position is
accepted only within a tolerance that grows with speed and latency, otherwise the server's own copy is used.

### Shared hit test = prediction that agrees
[`Hitbox`](src/ReplicatedStorage/Combat/Hitbox.luau) is the same code on both sides: the server runs it against rewound positions,
the client against what it sees. The client acts immediately (animation, lunge, predicted hit effects), and predicted
hits are matched to the server's results by sequence number, so nothing plays twice.

### Anti-cheat that doesn't punish lag
[`AntiCheat`](src/ServerScriptService/Combat/AntiCheat.luau) splits responses by how sure it can be:
- **Requests** must match a schema (known action and keys, right types, finite numbers) before any handler sees them.
  Only requests an honest client can't produce earn strikes; strikes decay; too many is a kick.
- **Movement** is judged over a sliding window: actual travel vs walk speed plus credit for every burst the server approved
  (dash, rush, knockback). Too far means a snap back, never a kick, because lag can look exactly like cheating.
  A speed hacker just keeps getting pulled back and gains nothing.

### One hit pipeline
Players, abilities and dummies all go through `CombatService.ApplyHit`: block and parry from the front, posture and guard
break, hitstun, hitstop, knockback, ragdoll on launchers. An interrupted fighter's token is bumped, so pending attacks
from before the interruption are dropped.

### Procedural animation
[`Anim`](src/ReplicatedStorage/Combat/Anim.luau) builds each pose from three layers (locomotion, held states like block or stun,
one-shot moves) and drives every joint through a damped spring: shoulders and waist overshoot slightly for follow-through,
wrists and head lag behind. Hitstop freezes a rig's animation clock so a move resumes exactly where it stopped.
```

```luau
-- Procedural R15 animation (no uploaded animations).
-- Every frame each rig's pose is built from 3 layers and written to Motor6D.Transform:
--   1. locomotion: guard stance, walk / strafe / run, air, landing dip
--   2. hold: long poses driven by state (block, stunned, grabbed, ...)
--   3. shot: one-shot keyframed moves (punches, kick, dashes, abilities, hurt)
-- Each joint follows its target through a damped spring (rotation + offset): a little overshoot on
-- shoulders / waist / neck gives follow-through, wrists and head lag behind (overlap), legs stay stiff.
-- Hitstop freezes a rig's clock, so the pose holds and the shot resumes exactly where it stopped.
local Anim = {}

local rad = math.rad
local I = CFrame.identity

-- joint helper: rotations in degrees, applied Z (roll) -> X (pitch) -> Y (yaw); optional offset
local function J(x: number?, y: number?, z: number?, px: number?, py: number?, pz: number?): CFrame
	local cf = CFrame.fromEulerAnglesYXZ(rad(x or 0), rad(y or 0), rad(z or 0))
	if px or py or pz then
		cf = CFrame.new(px or 0, py or 0, pz or 0) * cf
	end
	return cf
end
Anim.J = J

local JOINTS = {
	Root = { "LowerTorso", "Root" },
	Waist = { "UpperTorso", "Waist" },
	Neck = { "Head", "Neck" },
	RShoulder = { "RightUpperArm", "RightShoulder" },
	RElbow = { "RightLowerArm", "RightElbow" },
	RWrist = { "RightHand", "RightWrist" },
	LShoulder = { "LeftUpperArm", "LeftShoulder" },
	LElbow = { "LeftLowerArm", "LeftElbow" },
	LWrist = { "LeftHand", "LeftWrist" },
	RHip = { "RightUpperLeg", "RightHip" },
	RKnee = { "RightLowerLeg", "RightKnee" },
	RAnkle = { "RightFoot", "RightAnkle" },
	LHip = { "LeftUpperLeg", "LeftHip" },
	LKnee = { "LeftLowerLeg", "LeftKnee" },
	LAnkle = { "LeftFoot", "LeftAnkle" },
}
local NAMES = {}
for name in JOINTS do
	table.insert(NAMES, name)
end

-- joint springs: { stiffness (rad/s), damping ratio }. Ratio < 1 overshoots a little (follow-through);
-- legs near 1 so feet don't slide; wrists and neck softer so they trail the arm / torso (overlap)
local SPRING = {
	Root = { 30, 0.72 }, Waist = { 26, 0.5 }, Neck = { 18, 0.45 },
	RShoulder = { 28, 0.45 }, RElbow = { 30, 0.7 }, RWrist = { 20, 0.45 },
	LShoulder = { 28, 0.45 }, LElbow = { 30, 0.7 }, LWrist = { 20, 0.45 },
	RHip = { 36, 0.95 }, RKnee = { 36, 0.95 }, RAnkle = { 30, 0.9 },
	LHip = { 36, 0.95 }, LKnee = { 36, 0.95 }, LAnkle = { 30, 0.9 },
}
local SUBSTEP = 1 / 120 -- spring integration step (stable at low fps)

local UPPER = { Waist = true, Neck = true, RShoulder = true, RElbow = true, RWrist = true, LShoulder = true, LElbow = true, LWrist = true }
local UPPER_ROOT = table.clone(UPPER)
UPPER_ROOT.Root = true
local FULL = {}
for _, n in NAMES do
	FULL[n] = true
end
local LEGS = { Root = true, RHip = true, RKnee = true, RAnkle = true, LHip = true, LKnee = true, LAnkle = true }
-- strikes: whole upper body + hips, legs at 75% so the step reads but walking still shows through
local STRIKE: { [string]: any } = table.clone(UPPER_ROOT)
for n in LEGS do
	if n ~= "Root" then
		STRIKE[n] = 0.75
	end
end
Anim.Masks = { Upper = UPPER, UpperRoot = UPPER_ROOT, Full = FULL, Legs = LEGS, Strike = STRIKE }

type Pose = { [string]: CFrame }

-- mask value: true = full weight, number = partial weight, nil = joint untouched
local function blend(a: Pose, b: Pose, w: number, mask: { [string]: any }?): Pose
	local out = table.clone(a)
	for _, n in NAMES do
		local mw = if mask then mask[n] else true
		if mw then
			local k = if mw == true then w else w * mw
			out[n] = (a[n] or I):Lerp(b[n] or I, k)
		end
	end
	return out
end

local EASE = {
	smooth = function(a) return a * a * (3 - 2 * a) end,
	out = function(a) return 1 - (1 - a) * (1 - a) * (1 - a) end, -- snaps in fast: strikes
	linear = function(a) return a end,
}

-- frames = { {time 0..1, pose, ease?}, ... }
local function sample(frames, p: number): Pose
	if p <= frames[1][1] then
		return frames[1][2]
	end
	for i = 2, #frames do
		local f1 = frames[i]
		if p <= f1[1] then
			local f0 = frames[i - 1]
			local a = (p - f0[1]) / math.max(1e-4, f1[1] - f0[1])
			return blend(f0[2], f1[2], EASE[f1[3] or "smooth"](a))
		end
	end
	return frames[#frames][2]
end

type Rig = {
	model: Model,
	humanoid: Humanoid,
	root: BasePart,
	motors: { [string]: any }, -- Motor6D or AnimationConstraint
	cur: Pose, -- current joint CFrames (spring position)
	w: { [string]: Vector3 }, -- angular velocity per joint (parent space)
	v: { [string]: Vector3 }, -- offset velocity per joint
	lastFlat: Vector3,
	leanF: number,
	leanS: number,
	clock: number,
	freezeUntil: number,
	shake: number,
	phase: number,
	speed: number,
	wasAir: boolean,
	landAt: number,
	shot: { name: string, def: any, t0: number, speed: number }?,
	hold: string?,
	holdW: number,
	lastHold: string?,
}

local rigs: { [Model]: Rig } = {}

local function findMotors(rig: Rig)
	for name, path in JOINTS do
		if not rig.motors[name] or not rig.motors[name].Parent then
			local part = rig.model:FindFirstChild(path[1])
			local m = part and part:FindFirstChild(path[2])
			-- avatar joint upgrade turns joints into kinematic AnimationConstraints; both have .Transform
			if m and (m:IsA("Motor6D") or m:IsA("AnimationConstraint")) then
				rig.motors[name] = m :: any
			end
		end
	end
end

function Anim.Register(model: Model)
	if rigs[model] then
		return
	end
	local humanoid = model:FindFirstChildOfClass("Humanoid")
	local root = model:FindFirstChild("HumanoidRootPart") :: BasePart?
	if not humanoid or not root then
		return
	end
	-- the Animator would reset the joints every frame
	local animator = humanoid:FindFirstChildOfClass("Animator")
	if animator then
		animator:Destroy()
	end
	local rig: Rig = {
		model = model, humanoid = humanoid, root = root, motors = {},
		cur = {}, w = {}, v = {}, lastFlat = Vector3.zero, leanF = 0, leanS = 0,
		clock = 0, freezeUntil = 0, shake = 0,
		phase = 0, speed = 0, wasAir = false, landAt = -10,
		shot = nil, hold = nil, holdW = 0, lastHold = nil,
	}
	findMotors(rig)
	rigs[model] = rig
end

function Anim.Unregister(model: Model)
	rigs[model] = nil
end

function Anim.Has(model: Model): boolean
	return rigs[model] ~= nil
end

---------------------------------------------------------------- locomotion

local function locomotion(rig: Rig, dt: number): Pose
	local root = rig.root
	local vel = root.AssemblyLinearVelocity
	local flat = Vector3.new(vel.X, 0, vel.Z)
	local speed = flat.Magnitude
	-- lean into acceleration (start running = tip forward, stop = rock back)
	local acc = root.CFrame:VectorToObjectSpace((flat - rig.lastFlat) / math.max(dt, 1e-3))
	rig.lastFlat = flat
	local la = math.min(1, dt * 8)
	rig.leanF += (math.clamp(-acc.Z * 0.12, -10, 10) - rig.leanF) * la
	rig.leanS += (math.clamp(acc.X * 0.08, -7, 7) - rig.leanS) * la
	rig.speed += (speed - rig.speed) * math.min(1, dt * 10)
	local k = math.clamp(rig.speed / 18, 0, 1.4)

	local fwd, side = 0, 0
	if speed > 0.5 then
		local lv = root.CFrame:VectorToObjectSpace(flat) / speed
		fwd, side = -lv.Z, lv.X
	end
	if speed > 0.5 then
		rig.phase += dt * (4 + rig.speed * 0.42)
	end
	local s, c = math.sin(rig.phase), math.cos(rig.phase)
	local t = rig.clock
	local breath = math.sin(t * 2.2)

	local air = rig.humanoid.FloorMaterial == Enum.Material.Air
	if rig.wasAir and not air then
		rig.landAt = t
	end
	rig.wasAir = air

	local pose = stanceUpper(breath)
	if air then
		pose.Root = I
		pose.RHip, pose.RKnee = J(30), J(-55)
		pose.LHip, pose.LKnee = J(-6), J(-24)
		pose.LShoulder = J(56, -12, -18)
		pose.RShoulder = J(50, 14, 18)
		return pose
	end

	-- idle legs: staggered stance with a light boxer bounce (knees pump with it)
	local bounce = (math.sin(t * 6.4) + 1) * 0.5
	local idle = {
		Root = J(0, 0, 0, 0, -0.12 - bounce * 0.07, 0),
		RHip = J(-6 + bounce * 3, 8, 4), RKnee = J(-14 - bounce * 7),
		LHip = J(12 + bounce * 3, -8, -4), LKnee = J(-12 - bounce * 7),
	}
	-- walk / strafe cycle
	local A = 38 * k
	local fx, sx = fwd * s * A, side * s * A * 0.6
	local walk = {
		Root = J(-9 * k * fwd, 8 * k * s * fwd, -5 * k * side, 0, -0.08 * k * math.abs(c), 0),
		RHip = J(fx, 0, sx), RKnee = J(-(8 + 48 * k * math.max(0, c))),
		LHip = J(-fx, 0, -sx), LKnee = J(-(8 + 48 * k * math.max(0, -c))),
	}
	local legs = blend(idle, walk, math.min(1, k * 4), LEGS)
	for kname in LEGS do
		pose[kname] = legs[kname] or I
	end
	-- arms swing against the legs, torso counter-twists, body bobs on each step
	pose.LShoulder *= J(22 * k * s * fwd)
	pose.RShoulder *= J(-22 * k * s * fwd)
	pose.Waist *= J(-4 * k * math.abs(fwd), -10 * k * s * fwd, 0)
	pose.Neck *= J(0, 8 * k * s * fwd, 0)
	pose.Root *= J(-rig.leanF, 0, -rig.leanS)

	-- landing dip
	local sinceLand = t - rig.landAt
	if sinceLand < 0.3 then
		local d = (1 - sinceLand / 0.3) ^ 2
		pose.Root = pose.Root * J(-6 * d, 0, 0, 0, -0.45 * d, 0)
		pose.RKnee *= J(-25 * d)
		pose.LKnee *= J(-25 * d)
		pose.RHip *= J(15 * d)
		pose.LHip *= J(15 * d)
	end
	return pose
end

---------------------------------------------------------------- step

-- damped spring toward target: rotation via axis-angle error, offset via plain vector spring
local function springJoint(rig: Rig, name: string, target: CFrame, dt: number, boost: number): CFrame
	local cur = rig.cur[name]
	if not cur then
		rig.cur[name], rig.w[name], rig.v[name] = target, Vector3.zero, Vector3.zero
		return target
	end
	local s = SPRING[name]
	local omega = s[1] * boost
	local k, d = omega * omega, 2 * s[2] * omega
	local w, v = rig.w[name], rig.v[name]
	local rot, pos = cur.Rotation, cur.Position
	local tRot, tPos = target.Rotation, target.Position
	local n = math.max(1, math.ceil(dt / SUBSTEP))
	local h = dt / n
	for _ = 1, n do
		local axis, angle = (tRot * rot:Inverse()):ToAxisAngle()
		if angle > math.pi then
			angle -= 2 * math.pi
		end
		w += (axis * (angle * k) - w * d) * h
		local mag = w.Magnitude
		if mag > 1e-5 then
			rot = CFrame.fromAxisAngle(w / mag, mag * h) * rot
		end
		v += ((tPos - pos) * k - v * d) * h
		pos += v * h
	end
	local out = (CFrame.new(pos) * rot):Orthonormalize()
	rig.cur[name], rig.w[name], rig.v[name] = out, w, v
	return out
end

local function stepRig(rig: Rig, dt: number, now: number)
	if not rig.model.Parent then
		return
	end
	findMotors(rig)

	-- ragdoll: physics owns the limbs. Keep the root joint neutral and restart the springs from the
	-- target pose when the body gets up (no shot left over from before)
	if rig.model:GetAttribute("Ragdoll") then
		for _, m in rig.motors do
			m.Transform = I
		end
		rig.cur, rig.w, rig.v = {}, {}, {}
		rig.shot = nil
		return
	end

	local frozen = now < rig.freezeUntil
	if frozen then
		-- hitstop: hold the pose, jitter the root if this rig is the victim
		local jitter = if rig.shake > 0 then CFrame.new((math.random() - 0.5) * rig.shake, 0, (math.random() - 0.5) * rig.shake) else I
		for name, m in rig.motors do
			local o = rig.cur[name] or I
			m.Transform = if name == "Root" then jitter * o else o
		end
		return
	end

	dt = math.min(dt, 0.1)
	rig.clock += dt
	local pose = locomotion(rig, dt)

	-- hold layer
	local holdDef = rig.hold and HOLDS[rig.hold]
	if holdDef then
		rig.lastHold = rig.hold
	end
	rig.holdW += ((if holdDef then 1 else 0) - rig.holdW) * math.min(1, dt * 16)
	local shownHold = HOLDS[rig.lastHold or ""]
	if shownHold and rig.holdW > 0.01 then
		pose = blend(pose, shownHold.pose(rig.clock), rig.holdW, shownHold.mask)
	end

	-- one-shot layer
	local shot = rig.shot
	local shotW = 0
	if shot then
		local def = shot.def
		local e = (rig.clock - shot.t0) * shot.speed
		if e >= def.dur then
			rig.shot = nil
		else
			shotW = math.min(1, e / 0.04, (def.dur - e) / 0.12)
			shotW = shotW * shotW * (3 - 2 * shotW)
			pose = blend(pose, sample(def.frames, e / def.dur), shotW, def.mask)
		end
	end

	-- springs; strikes stiffen them so the hit snaps, recovery is softer
	local boost = 1 + shotW * 1.5
	for name, m in rig.motors do
		m.Transform = springJoint(rig, name, pose[name] or I, dt, boost)
	end
end

function Anim.Step(dt: number)
	local now = os.clock()
	for model, rig in rigs do
		if model.Parent then
			stepRig(rig, dt, now)
		end
	end
end

return Anim
```

```luau
-- Shared hit test. The server runs it against rewound positions, the client runs it against what it sees.
-- Same math on both sides = the client's prediction agrees with the server almost always.
local Hitbox = {}

export type Shape = {
	Kind: string, -- "Box" | "Radius"
	Size: Vector3?,
	Offset: CFrame?,
	Radius: number?,
	Height: number?,
}

export type Target = { model: Model, pos: Vector3 }

-- does a sphere touch an oriented box
function Hitbox.BoxSphere(boxCF: CFrame, size: Vector3, pos: Vector3, r: number): boolean
	local p = boxCF:PointToObjectSpace(pos)
	local h = size * 0.5
	local closest = Vector3.new(math.clamp(p.X, -h.X, h.X), math.clamp(p.Y, -h.Y, h.Y), math.clamp(p.Z, -h.Z, h.Z))
	return (p - closest).Magnitude <= r
end

-- flat cylinder around a point (area attacks)
function Hitbox.Cylinder(center: Vector3, radius: number, height: number, pos: Vector3, r: number): boolean
	local d = pos - center
	if math.abs(d.Y) > height * 0.5 + r then
		return false
	end
	return Vector3.new(d.X, 0, d.Z).Magnitude <= radius + r
end

-- origin = attacker root CFrame (flat). Returns targets inside the shape, closest first.
function Hitbox.Find(shape: Shape, origin: CFrame, targets: { Target }, hurtRadius: number, slack: number?): { Target }
	local extra = slack or 0
	local hits = {}
	if shape.Kind == "Box" then
		local boxCF = origin * (shape.Offset or CFrame.identity)
		local size = (shape.Size :: Vector3) + Vector3.new(extra, extra, extra) * 2
		for _, t in targets do
			if Hitbox.BoxSphere(boxCF, size, t.pos, hurtRadius) then
				table.insert(hits, t)
			end
		end
	elseif shape.Kind == "Radius" then
		for _, t in targets do
			if Hitbox.Cylinder(origin.Position, (shape.Radius :: number) + extra, shape.Height :: number, t.pos, hurtRadius) then
				table.insert(hits, t)
			end
		end
	end
	local o = origin.Position
	table.sort(hits, function(a, b)
		return (a.pos - o).Magnitude < (b.pos - o).Magnitude
	end)
	return hits
end

-- yaw-only CFrame (we never want pitch on a hitbox origin)
function Hitbox.Flat(cf: CFrame): CFrame
	local look = cf.LookVector * Vector3.new(1, 0, 1)
	if look.Magnitude < 1e-3 then
		return CFrame.new(cf.Position)
	end
	return CFrame.lookAt(cf.Position, cf.Position + look.Unit)
end

return Hitbox
```

```luau
local function release(a: Fighter, v: Fighter, slam: boolean)
	if v.grabbedBy ~= a then
		return
	end
	v.grabbedBy = nil
	a.grabbing = nil
	v.model:SetAttribute("Grabbed", false)
	if v.root.Parent then
		v.root.Anchored = false
		AntiCheat.Moved(v.model) -- the server was holding the body
	end

		local cfg = Config.Abilities.GrabRush

			move = "GrabRush",
			t = Fighters.Now(),
			damage = cfg.Damage,
			stun = cfg.Stun,
			hitstop = cfg.Hitstop,

	end

-- data = { target, t, cf }
function Abilities.GrabHit(f: Fighter, data: any)
	local cfg = Config.Abilities.GrabRush
	local rush = f.rush
	if not rush or rush.token ~= f.token then
		return
	end
	local now = Fighters.Now()
	local t = CombatService.Stamp(data.t, now)
	local slack = Config.Net.TimingSlack
	if t < rush.t0 + cfg.Windup - slack or t > rush.untilT + slack then
		return
	end
	local v = Fighters.Get(data.target)
	if not v or v == f or not Fighters.Alive(v) or v.grabbedBy or v.grabbing then
		return
	end

	local latency = math.clamp(now - t, 0, Config.Net.MaxRewind)
	local origin = CombatService.Origin(f, data.cf, latency)
	local past = History.At(v.model, History.SampleTime(t, latency, now))
	if not past then
		return
	end
	local target = { { model = v.model, pos = past.Position } }
	if #Hitbox.Find(cfg.Hitbox, origin, target, Config.Fighter.HurtRadius, cfg.ReachSlack) == 0 then
		return -- too far on the server's timeline: no grab
	end
	f.rush = nil

	if t >= v.iframeStart and t <= v.iframeUntil then
		CombatService.Broadcast("Result", { a = f.model, v = v.model, move = "GrabRush", r = "Dodged" })
		return
	end
	if cfg.Armor then
		Fighters.SetArmor(f, now + cfg.Hold) -- through the slam too
	end

	Fighters.Stun(v, cfg.Hold + 0.2, now)
	Ragdoll.Stop(v.model) -- grabbed out of a ragdoll: stand up, the Grabbed hold takes over
	v.grabbedBy = f
	f.grabbing = v
	v.model:SetAttribute("Grabbed", true)
	v.root.Anchored = true -- the server holds the victim in front of the attacker
	f.actionUntil = now + cfg.Hold + 0.15
	CombatService.Broadcast("Grab", { a = f.model, v = v.model })

	local token = f.token
	task.delay(cfg.Hold, function()
		release(f, v, f.token == token)
	end)

-- one scheduled hitbox check at `hitTime` (attacker's timeline); `build` makes the HitInfo per victim
local function strikeAt(f: Fighter, shape, origin: CFrame, hitTime: number, latency: number, build: (v: Fighter) -> any)
	local token = f.token
	task.delay(math.max(0, hitTime - Fighters.Now()), function()
		if f.token ~= token or not Fighters.Alive(f) then
			return -- interrupted (stunned, parried)
		end
		local sampleT = History.SampleTime(hitTime, latency, Fighters.Now())
		for _, target in Hitbox.Find(shape, origin, CombatService.Targets(f, sampleT), Config.Fighter.HurtRadius) do
			local v = Fighters.Get(target.model)
			if v then
				CombatService.ApplyHit(f, v, build(v))
			end
		end
	end)
end

-- Barrage: rooted flurry, each hit keeps the target stunned, the last one pushes it away.
-- Hit i is matched to the client's prediction by seq + i - 1.
starters.Barrage = function(f: Fighter, cfg, t: number, now: number, data: any)
	f.actionUntil = t + cfg.Windup + (cfg.Hits - 1) * cfg.Interval + 0.15
	local latency = math.clamp(now - t, 0, Config.Net.MaxRewind)
	local origin = CombatService.Origin(f, data.cf, latency)
	local seq0 = if type(data.seq) == "number" then data.seq else nil
	for i = 1, cfg.Hits do
		local final = i == cfg.Hits
		local hitTime = t + cfg.Windup + (i - 1) * cfg.Interval
		strikeAt(f, cfg.Hitbox, origin, hitTime, latency, function()
			return {
				move = "Barrage",
				step = i,
				t = hitTime,
				damage = cfg.Damage,
				posture = cfg.Posture,
				stun = if final then cfg.FinalStun else cfg.Hitstun,
				hitstop = if final then cfg.FinalHitstop else cfg.Hitstop,
				knockback = if final then origin.LookVector * cfg.Knockback.Forward + Vector3.yAxis * cfg.Knockback.Up else nil,
				seq = seq0 and seq0 + i - 1,
			}
		end)
	end
end

	local origin = CombatService.Origin(f, data.cf, latency)
	local hitTime = t + cfg.Windup
	strikeAt(f, cfg.Hitbox, origin, hitTime, latency, function()

			t = hitTime,
			damage = cfg.Damage,
			posture = cfg.Posture,

	local id = data.id
	local cfg = type(id) == "string" and Config.Abilities[id]
	local start = cfg and starters[id]
	if not start then
		return
	end
	local now = Fighters.Now()
	local t = CombatService.Stamp(data.t, now)
	if not Fighters.CanAct(f, now) or t < (f.cooldowns[id] or 0) - Config.Net.TimingSlack then
		CombatService.Deny(f, id)
		return
	end
	f.cooldowns[id] = t + cfg.Cooldown

	for _, f in Fighters.All() do
		local v = f.grabbing
		if v and v.root.Parent and f.root.Parent then
			v.root.CFrame = Hitbox.Flat(f.root.CFrame) * CFrame.new(0, 0.4, -3.2) * CFrame.Angles(0, math.pi, 0)
		end
	end

		release(f, f.grabbing, false)
	end
	if f.grabbedBy then
		release(f.grabbedBy, f, false)
	end
	f.rush = nil
end
```

`src/ServerScriptService/Combat/AntiCheat.luau`:

```luau
-- Server-side checks for what the client controls.
--
-- 1. Requests: every remote call must match a schema (known action, known keys, right types, finite
--    numbers, short strings) before any handler sees it. Game rules (cooldowns, stun, reach, rewind)
--    are already re-checked by the handlers themselves.
-- 2. Movement: players own their character's physics (that's what makes dashes and lunges instant),
--    so a cheater can move it freely. Over a sliding window we compare how far the root really went
--    (History) with what the rules allow: walk speed + credit for every burst the server approved
--    (dash, rush, knockback). Further = speed hack / teleport -> snapped back to where it was.
--    Hanging high above the ground too long = flying -> put back on the last grounded spot.
--    A network stall (positions stop, then all the walking arrives at once) can still trip this. That
--    is deliberately NOT forgiven: from the server it looks exactly like standing still and then
--    teleporting, so forgiving it opens a teleport. The lagging player gets one rubber-band, nothing more.
-- 3. Response, split by how sure we can be:
--    - Flag: movement. Lag can look exactly like cheating, so it's only undone (snap back), logged and
--      counted ("ACFlags" attribute) for a human to look at. It never kicks: a speed hacker just keeps
--      getting pulled back and gains nothing.
--    - Strike: requests an honest client can't produce (wrong types, NaN, unknown keys). Strikes
--      decay over time, too many = kick. No bans: those need a human.
--    Everything goes to AntiCheat.Recent; warn lines are throttled per kind so a flood stays readable.
local Players = game:GetService("Players")
local ReplicatedStorage = game:GetService("ReplicatedStorage")

local Config = require(ReplicatedStorage.Combat.Config)
local Fighters = require(script.Parent.Fighters)
local History = require(script.Parent.History)

local AntiCheat = {}

type Watch = {
	model: Model?, -- character being watched (a new one resets everything)
	since: number, -- movement is only judged after this (respawn, server moved us, snap back)
	credits: { { t: number, studs: number } },
	ground: CFrame?, -- last spot standing on something
	airSince: number?,
	lastCheck: number,
	strikes: number,
	strikesAt: number,
	flags: number,
	loggedAt: { [string]: number },
}

local watches: { [Player]: Watch } = {}

AntiCheat.Recent = {} :: { { t: number, player: string, kind: string, detail: string } }
local RECENT_MAX = 50

-- where log lines go (tests swap it out to keep the Output clean)
AntiCheat.Log = function(line: string)
	warn(line)
end

local rayParams = RaycastParams.new()
rayParams.CollisionGroup = "Fighters" -- fighters don't collide with fighters, so the ray ignores bodies
rayParams.IgnoreWater = true

local function now(): number
	return workspace:GetServerTimeNow()
end

local function watchOf(p: Player): Watch
	local w = watches[p]
	if not w then
		w = {
			model = nil,
			since = now(),
			credits = {},
			ground = nil,
			airSince = nil,
			lastCheck = 0,
			strikes = 0,
			strikesAt = os.clock(),
			flags = 0,
			loggedAt = {},
		}
		watches[p] = w
	end
	return w
end

Players.PlayerRemoving:Connect(function(p)
	watches[p] = nil
end)

---------------------------------------------------------------- response

local function record(p: Player, w: Watch, kind: string, detail: string, tally: string)
	table.insert(AntiCheat.Recent, { t = now(), player = p.Name, kind = kind, detail = detail })
	if #AntiCheat.Recent > RECENT_MAX then
		table.remove(AntiCheat.Recent, 1)
	end
	local t = os.clock()
	if t - (w.loggedAt[kind] or -math.huge) >= Config.AntiCheat.LogEvery then
		w.loggedAt[kind] = t
		AntiCheat.Log(string.format("[AntiCheat] %s %s: %s (%s)", p.Name, kind, detail, tally))
	end
end

-- Suspicious, but lag can look the same: logged and counted, never punished.
function AntiCheat.Flag(p: Player, kind: string, detail: string)
	local w = watchOf(p)
	w.flags += 1
	p:SetAttribute("ACFlags", w.flags)
	record(p, w, kind, detail, "flags " .. w.flags)
end

-- Something an honest client can't do. Enough of them in a short time = kick.
function AntiCheat.Strike(p: Player, kind: string, detail: string)
	local cfg = Config.AntiCheat
	local weight = cfg.Strikes[kind]
	assert(weight, "AntiCheat.Strike: no strike weight for " .. kind .. " (use Flag for things lag can cause)")
	local w = watchOf(p)
	local t = os.clock()
	w.strikes = math.max(0, w.strikes - (t - w.strikesAt) / cfg.StrikeDecay) + weight
	w.strikesAt = t
	p:SetAttribute("ACStrikes", math.floor(w.strikes * 10 + 0.5) / 10)
	record(p, w, kind, detail, string.format("strikes %.1f / %d", w.strikes, cfg.KickAt))

	if w.strikes >= cfg.KickAt then
		p:Kick("Removed by the anti-cheat (" .. kind .. ").")
	end
end

---------------------------------------------------------------- requests

-- action -> allowed keys and their types. Keys may be missing (handlers fall back), never extra.
local SCHEMAS: { [string]: { [string]: string } } = {
	M1 = { t = "number", cf = "CFrame", seq = "number" },
	Block = { on = "boolean", t = "number" },
	Dash = { dir = "string", t = "number" },
	DashHit = { target = "Instance", t = "number", cf = "CFrame", seq = "number" },
	Ability = { id = "string", t = "number", cf = "CFrame", seq = "number" },
	GrabHit = { target = "Instance", t = "number", cf = "CFrame" },
	DummyMode = {},
}
AntiCheat.Schemas = SCHEMAS -- read-only, for tests
local MAX_KEYS = 6
local MAX_STRING = 32
local MAX_NUMBER = 1e10 -- time stamps are server unix time (~1.8e9)
local MAX_POSITION = 1e6

local function badValue(kind: string, v: any): string?
	if typeof(v) ~= kind then
		return "expected " .. kind .. ", got " .. typeof(v)
	elseif kind == "number" and (v ~= v or math.abs(v) > MAX_NUMBER) then
		return "number out of range"
	elseif kind == "string" and #v > MAX_STRING then
		return "string too long"
	elseif kind == "CFrame" then
		local pos = (v :: CFrame).Position
		if pos ~= pos or pos.Magnitude > MAX_POSITION then
			return "CFrame out of range"
		end
	end
	return nil
end

-- what is wrong with a request, nil if nothing (pure: no player, no side effects)
function AntiCheat.Validate(action: any, data: any): string?
	local schema = type(action) == "string" and SCHEMAS[action]
	local problem: string? = nil
	if not schema then
		problem = "unknown action " .. tostring(action):sub(1, MAX_STRING)
	elseif type(data) ~= "table" then
		problem = "data is " .. typeof(data)
	else
		local n = 0
		for k, v in data do
			n += 1
			local want = type(k) == "string" and schema[k]
			if n > MAX_KEYS then
				problem = "too many keys"
			elseif not want then
				problem = "unexpected key " .. tostring(k):sub(1, MAX_STRING)
			else
				local bad = badValue(want, v)
				problem = bad and (k .. ": " .. bad)
			end
			if problem then
				break
			end
		end
	end
	return problem
end

-- true if the request may go to its handler
function AntiCheat.CheckRequest(p: Player, action: any, data: any): boolean
	local problem = AntiCheat.Validate(action, data)
	if problem then
		AntiCheat.Strike(p, "BadRequest", tostring(action):sub(1, MAX_STRING) .. " - " .. problem)
		return false
	end

-- an approved burst: this character may travel `studs` further than walking, for a while
function AntiCheat.Grant(model: Model, studs: number)
	local p = Players:GetPlayerFromCharacter(model)
	if p and studs > 0 then
		table.insert(watchOf(p).credits, { t = now(), studs = studs * Config.AntiCheat.CreditScale })
	end
end

-- horizontal distance a knockback velocity carries a body: flight time from the upward part, plus a slide
function AntiCheat.KnockbackStuds(kb: Vector3): number
	local air = 2 * math.max(0, kb.Y) / workspace.Gravity
	return Vector3.new(kb.X, 0, kb.Z).Magnitude * (air + 0.4)
end

-- the server moved this character itself (dash catch, grab release): don't judge movement across it
function AntiCheat.Moved(model: Model)
	local p = Players:GetPlayerFromCharacter(model)
	if p then
		local w = watchOf(p)
		w.since = now()
		w.airSince = nil
	end
end

local function setOwner(model: Model, owner: Player?)
	for _, part in model:GetDescendants() do
		if part:IsA("BasePart") and not part.Anchored then
			pcall(part.SetNetworkOwner, part, owner)
		end
	end
end

-- Put the character back. The client owns its physics and would just overwrite a server CFrame, so the
-- server takes ownership for a moment, moves the body, then hands it back.
local function snapBack(p: Player, f: Fighters.Fighter, to: CFrame)
	local cfg = Config.AntiCheat
	local model = f.model
	setOwner(model, nil)
	model:PivotTo(to)
	f.root.AssemblyLinearVelocity = Vector3.zero
	f.root.AssemblyAngularVelocity = Vector3.zero
	task.delay(cfg.SnapHold, function()
		if model.Parent and p.Parent == Players and p.Character == model then
			setOwner(model, p)
		end
	end)
end

local function checkPlayer(p: Player, t: number)
	local cfg = Config.AntiCheat
	local char = p.Character
	local f = Fighters.Get(char)
	if not char or not f or not Fighters.Alive(f) then
		return
	end
	local w = watchOf(p)
	if w.model ~= char then
		w.model, w.since, w.credits, w.ground, w.airSince = char, t, {}, nil, nil
	end
	if t - w.lastCheck < cfg.CheckEvery then
		return
	end
	w.lastCheck = t

	local root = f.root
	local held = f.grabbedBy ~= nil or root.Anchored
	if held then
		w.since = t
	end
	if held or t < w.since then
		-- the server holds the body (grab, snap back): it decides where it is
		w.airSince = nil
		return
	end

	-- credits still usable for this window
	local credit = 0
	for i = #w.credits, 1, -1 do
		local c = w.credits[i]
		if t - c.t > cfg.Window + cfg.CreditLife then
			table.remove(w.credits, i)
		else
			credit += c.studs
		end
	end

	-- speed / teleport: horizontal travel over the last window
	local from = math.max(t - cfg.Window, w.since)
	local span = t - from
	if span >= cfg.Window * 0.5 then
		local past = History.At(char, from)
		if past then
			local moved = ((root.Position - past.Position) * Vector3.new(1, 0, 1)).Magnitude
			local allowed = Config.Fighter.WalkSpeed * cfg.SpeedSlack * span + cfg.DistSlack + credit
			if moved > allowed then
				snapBack(p, f, past)
				w.since, w.credits, w.airSince = t + cfg.SnapHold, {}, nil
				AntiCheat.Flag(p, "Speed", string.format("%.1f studs in %.2f s, allowed %.1f", moved, span, allowed))
				return
			end
		end
	end

	-- flying: high above the ground for too long
	local down = workspace:Raycast(root.Position, Vector3.new(0, -cfg.FlyHeight, 0), rayParams)
	if down then
		w.airSince = nil
		if down.Distance < 4 then
			w.ground = root.CFrame
		end
	else
		w.airSince = w.airSince or t
		if t - (w.airSince :: number) > cfg.FlyTime then
			local back = w.ground or (History.At(char, w.airSince :: number) :: CFrame)
			snapBack(p, f, back)
			w.since, w.airSince = t + cfg.SnapHold, nil
			AntiCheat.Flag(p, "Fly", string.format("airborne %.1f s more than %d studs up", cfg.FlyTime, cfg.FlyHeight))
		end
	end
end

function AntiCheat.Step(t: number)
	for _, p in Players:GetPlayers() do
		checkPlayer(p, t)
	end
end

return AntiCheat
```

```luau
-- attacker CFrame reported by the client, checked against the server copy

		return Hitbox.Flat(server)

local function fromFront(v: Fighter, a: Fighter): boolean
	local toA = (a.root.Position - v.root.Position) * Vector3.new(1, 0, 1)
	if toA.Magnitude < 0.05 then
		return true
	end
	local look = v.root.CFrame.LookVector * Vector3.new(1, 0, 1)
	return look.Unit:Dot(toA.Unit) > Config.Block.FrontDot
end

-- one place that decides what a hit does. Returns the result name.
function CombatService.ApplyHit(a: Fighter, v: Fighter, hit: HitInfo): string?
	if not Fighters.Alive(a) or not Fighters.Alive(v) then
		return nil
	end
	local now = Fighters.Now()
	local base = { a = a.model, v = v.model, move = hit.move, step = hit.step, seq = hit.seq }

	-- 1. dodge i-frames, judged at the moment the hit happened for the attacker
	if hit.t >= v.iframeStart and hit.t <= v.iframeUntil then
		base.r = "Dodged"
		CombatService.Broadcast("Result", base)
		return "Dodged"
	end

	-- 2. block / parry (front only)
	if v.blocking and not hit.unblockable and fromFront(v, a) then
		local sinceBlock = hit.t - v.blockStart
		if v.parryEligible and sinceBlock >= -Config.Net.TimingSlack and sinceBlock <= Config.Block.ParryWindow then
			Fighters.Stun(a, Config.Block.ParryStun, now)
			v.parryEligible = false -- one parry per block press
			base.r = "Parried"
			base.stun = Config.Block.ParryStun
			CombatService.Broadcast("Result", base)
			return "Parried"
		end

		Fighters.SetPosture(v, v.posture - (hit.posture or hit.damage * 3))
		v.postureHitAt = now
		if v.posture <= 0 then
			Fighters.Stun(v, Config.Block.GuardBreakStun, now)
			Fighters.SetPosture(v, Config.Block.MaxPosture)
			base.r = "GuardBreak"
			base.stun = Config.Block.GuardBreakStun
			CombatService.Broadcast("Result", base)
			return "GuardBreak"
		end
		base.r = "Blocked"
		CombatService.Broadcast("Result", base)
		return "Blocked"
	end

	local damage = math.round(hit.damage * a.damageScale * 10) / 10 -- 3 x 0.6 is 1.7999...

	-- 3. armor: a committed skill (Rush Grab) eats M1s, takes the damage and keeps going.
	-- Otherwise holding M1 in front of you beats every rush. Skills still break it.
	if hit.move == "M1" and hit.t <= v.armorUntil then
		v.humanoid:TakeDamage(damage)
		v.lastDamagedAt = now
		base.r = "Armored"
		base.dmg = damage
		base.hp = v.humanoid.Health
		CombatService.Broadcast("Result", base)
		return "Armored"
	end

	-- 4. clean hit
	v.humanoid:TakeDamage(damage)
	v.lastDamagedAt = now
	Fighters.Stun(v, hit.stun, now)

	if now - a.lastLandedAt <= Config.Fighter.ComboWindow then
		a.comboCount += 1
	else
		a.comboCount = 1
	end
	a.lastLandedAt = now

	-- combo extension: a landed dash hit / ability cancels the M1 end lag and restarts the chain
	if hit.move ~= "M1" then
		a.m1ReadyAt = math.min(a.m1ReadyAt, hit.t)
		a.comboStep = 0
	end

	-- launchers ragdoll the target for its stun; any other clean hit stands it back up (juggles, dash catch)
	if hit.knockback and hit.knockback.Y >= Config.Ragdoll.MinUp then
		Ragdoll.Start(v.model, math.max(0.2, hit.stun - Config.Ragdoll.GetUpLead))
	else
		Ragdoll.Stop(v.model)
	end

	if hit.knockback then
		CombatService.Push(v, hit.knockback)
		AntiCheat.Grant(v.model, AntiCheat.KnockbackStuds(hit.knockback)) -- players fly on their own client
	end

	base.r = "Hit"
	base.dmg = damage
	base.combo = a.comboCount
	base.hitstop = hit.hitstop
	base.kb = hit.knockback
	base.stun = hit.stun
	base.hp = v.humanoid.Health
	CombatService.Broadcast("Result", base)
	return "Hit"
end

-- data = { t, cf, seq }. Also called by the dummy with its own CFrame.
function CombatService.M1(f: Fighter, data: any)
	local now = Fighters.Now()
	local t = CombatService.Stamp(data.t, now)
	local cfg = Config.M1

	if not Fighters.CanAct(f, now) or f.blocking or t < f.m1ReadyAt - Config.Net.TimingSlack then
		CombatService.Deny(f, "M1")
		return
	end

	local step = if (t - f.lastM1 > cfg.ComboReset or f.comboStep >= cfg.Steps) then 1 else f.comboStep + 1
	f.comboStep = step
	f.lastM1 = t
	f.m1ReadyAt = t + (if step == cfg.Steps then cfg.EndLag else cfg.Interval)
	f.actionUntil = t + cfg.Windup + 0.12

	local latency = math.clamp(now - t, 0, Config.Net.MaxRewind)
	local origin = CombatService.Origin(f, data.cf, latency)
	local seq = if type(data.seq) == "number" then data.seq else nil
	CombatService.Cosmetic(f.player, "Swing", { m = f.model, step = step })

	local hitTime = t + cfg.Windup
	local token = f.token
	task.delay(math.max(0, hitTime - now), function()
		if f.token ~= token or not Fighters.Alive(f) then
			return -- got interrupted during the windup
		end
		local sampleT = History.SampleTime(hitTime, latency, Fighters.Now())
		local hits = Hitbox.Find(cfg.Hitbox, origin, CombatService.Targets(f, sampleT), Config.Fighter.HurtRadius)
		local final = step == cfg.Steps
		for _, target in hits do
			local v = Fighters.Get(target.model)
			if v then
				local kb = nil
				if final then
					kb = origin.LookVector * cfg.Knockback.Forward + Vector3.yAxis * cfg.Knockback.Up
				end
				CombatService.ApplyHit(f, v, {
					move = "M1",
					step = step,
					t = hitTime,
					damage = cfg.Damage[step],
					posture = cfg.Posture[step],
					stun = if final then cfg.FinalStun else cfg.Hitstun,
					hitstop = cfg.Hitstop[step],
					knockback = kb,
					seq = seq,
				})
			end
		end
	end)
end

-- data = { dir, t }. The client moves its own character; the server owns cooldown and i-frames.
function CombatService.Dash(f: Fighter, data: any)

	local t = CombatService.Stamp(data.t, now)
	local dir = data.dir
	if not DASH_DIRS[dir] or not Fighters.CanAct(f, now) or t < f.dashReadyAt - Config.Net.TimingSlack then
		CombatService.Deny(f, "Dash")
		return
	end
	f.dashReadyAt = t + Config.Dash.Cooldown
	Fighters.SetBlocking(f, false, t)
	local spec = if dir == "F" then Config.Dash.Front else Config.Dash.Dodge
	AntiCheat.Grant(f.model, spec.Speed * spec.Duration)
	if dir ~= "F" then
		Fighters.SetIFrames(f, t, t + Config.Dash.Dodge.IFrames)
		f.dashHit = nil
	else
		f.dashHit = { t0 = t, untilT = t + Config.Dash.Front.Duration, token = f.token }
	end

end

-- the dashing client reports running into someone; re-checked against the rewound target
-- data = { target, t, cf, seq }
function CombatService.DashHit(f: Fighter, data: any)
	local cfg = Config.Dash.Hit
	local dash = f.dashHit
	if not dash or dash.token ~= f.token then
		return
	end
	local now = Fighters.Now()
	local t = CombatService.Stamp(data.t, now)
	local slack = Config.Net.TimingSlack
	if t < dash.t0 - slack or t > dash.untilT + slack then
		return
	end
	local v = Fighters.Get(data.target)
	if not v or v == f or not Fighters.Alive(v) or v.grabbedBy then
		return
	end
	local latency = math.clamp(now - t, 0, Config.Net.MaxRewind)
	local origin = CombatService.Origin(f, data.cf, latency)
	local past = History.At(v.model, History.SampleTime(t, latency, now))
	if not past then
		return
	end
	if #Hitbox.Find(cfg.Hitbox, origin, { { model = v.model, pos = past.Position } }, Config.Fighter.HurtRadius, cfg.ReachSlack) == 0 then
		return
	end
	f.dashHit = nil -- one hit per dash
	local result = CombatService.ApplyHit(f, v, {
		move = "Dash",
		t = t,
		damage = cfg.Damage,
		posture = cfg.Posture,
		stun = cfg.Stun,
		hitstop = cfg.Hitstop,
		knockback = Vector3.zero, -- kills the target's knockback (its own client stops it for players)
		seq = if type(data.seq) == "number" then data.seq else nil,
	})
	-- catch: a launched target is already further away on the server than the attacker sees it,
	-- so put it right in front of the attacker, facing them, and stop it
	if result == "Hit" and v.root.Parent then
		local at = origin.Position + origin.LookVector * 3
		at = Vector3.new(at.X, v.root.Position.Y, at.Z)
		v.root.CFrame = CFrame.lookAt(at, Vector3.new(origin.Position.X, at.Y, origin.Position.Z))
		v.root.AssemblyLinearVelocity = Vector3.zero
		AntiCheat.Moved(v.model)
	end
end
```

```luau
			f.humanoid.WalkSpeed = 0
			if state then
				state.engageAt = nil -- react again once it's free
			end
			continue
		end

		if Dummy.Mode == "Block" then
			face(f, target.root.Position)
			if not f.blocking and Fighters.CanAct(f, now) then
				Fighters.SetBlocking(f, true, now)
				f.parryEligible = false -- a dummy in Block mode never parries
			end
		elseif Dummy.Mode == "Fight" then
			if closestDummyTo(target) ~= f then
				f.humanoid.WalkSpeed = 0
				continue
			end
			local cfg = Config.Dummy
			local dist = (target.root.Position - f.root.Position).Magnitude
			if dist > cfg.FightRange then
				f.humanoid.WalkSpeed = cfg.WalkSpeed
				f.humanoid:MoveTo(target.root.Position)
				if state then
					state.engageAt = nil
				end
			elseif state then
				f.humanoid.WalkSpeed = 0
				face(f, target.root.Position)
				state.engageAt = state.engageAt or now + cfg.Reaction
				local ready = now >= state.engageAt and now >= state.nextAttack
				if ready and Fighters.CanAct(f, now) and now >= f.m1ReadyAt then
					CombatService.M1(f, { t = now, cf = Hitbox.Flat(f.root.CFrame) })
					local finished = f.comboStep >= Config.M1.Steps
					state.nextAttack = now + (if finished then cfg.FightCooldown else Config.M1.Interval + cfg.SwingGap)
				end
			end
		end
	end
end

return Dummy
```

```luau
-- Position history for lag compensation.
-- Every Heartbeat we store each fighter's root CFrame with the server time. When a hit arrives,
-- we look up where targets were at the moment the attacker actually saw them.
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Config = require(ReplicatedStorage.Combat.Config)

local History = {}

local SIZE = 128 -- ring buffer slots (~2 s at 60 Hz, more than HistoryLength)

type Buffer = {
	root: BasePart,
	times: { number },
	cfs: { CFrame },
	head: number, -- index of the newest sample
	count: number,
}

local buffers: { [Model]: Buffer } = {}

function History.Track(model: Model, root: BasePart)
	buffers[model] = { root = root, times = table.create(SIZE, 0), cfs = table.create(SIZE, CFrame.identity), head = 0, count = 0 }
end

function History.Untrack(model: Model)
	buffers[model] = nil
end

function History.Record(now: number)
	for model, buf in buffers do
		if not buf.root.Parent then
			continue
		end
		buf.head = buf.head % SIZE + 1
		buf.times[buf.head] = now
		buf.cfs[buf.head] = buf.root.CFrame
		buf.count = math.min(buf.count + 1, SIZE)
	end
end

-- CFrame of the model's root at server time t (interpolated between samples)
function History.At(model: Model, t: number): CFrame?
	local buf = buffers[model]
	if not buf or buf.count == 0 then
		return nil
	end
	local i = buf.head
	if t >= buf.times[i] then
		return buf.root.CFrame -- newer than the last sample: use the live position
	end
	-- walk back until we find the sample pair around t
	for _ = 1, buf.count - 1 do
		local prev = (i - 2) % SIZE + 1
		local t0, t1 = buf.times[prev], buf.times[i]
		if t >= t0 then
			local alpha = if t1 > t0 then (t - t0) / (t1 - t0) else 0
			return buf.cfs[prev]:Lerp(buf.cfs[i], alpha)
		end
		i = prev
	end
	return buf.cfs[i] -- older than everything we have: oldest sample
end

-- how far back a hit may look, given the request stamp
function History.SampleTime(hitTime: number, latency: number, now: number): number
	local t = hitTime - latency - Config.Net.InterpDelay
	return math.clamp(t, now - Config.Net.MaxRewind, now)
end

return History
```

```luau
-- Ragdoll: launchers and death turn the body loose.
-- The server swaps the rig joints for ball sockets / hinges (that replicates to everyone); whoever owns
-- the body's physics puts its Humanoid into the Physics state: the server for dummies, the player's own
-- client for characters (CombatClient watches the "Ragdoll" attribute).
-- The Root joint (HumanoidRootPart -> LowerTorso) stays, so hitboxes, history and knockback keep using the root.
local Players = game:GetService("Players")

local Ragdoll = {}

-- joint -> { kind, a, b }. Ball: cone angle a, twist +-b. Hinge: angle range a..b (+ swings the limb forward).
local LIMITS = {
	Neck = { "Ball", 35, 30 },
	Waist = { "Ball", 25, 20 },
	LeftShoulder = { "Ball", 85, 50 },
	RightShoulder = { "Ball", 85, 50 },
	LeftElbow = { "Hinge", -5, 135 },
	RightElbow = { "Hinge", -5, 135 },
	LeftWrist = { "Ball", 30, 10 },
	RightWrist = { "Ball", 30, 10 },
	LeftHip = { "Ball", 55, 25 },
	RightHip = { "Ball", 55, 25 },
	LeftKnee = { "Hinge", -135, 5 },
	RightKnee = { "Hinge", -135, 5 },
	LeftAnkle = { "Ball", 25, 10 },
	RightAnkle = { "Ball", 25, 10 },
}

type Rig = {
	model: Model,
	humanoid: Humanoid,
	player: Player?,
	joints: { any }, -- Motor6D or AnimationConstraint
	constraints: { Constraint },
	parts: { [BasePart]: boolean }, -- body part -> its normal CanCollide
	on: boolean,
	untilT: number,
}

local rigs: { [Model]: Rig } = {}

local function now(): number
	return workspace:GetServerTimeNow()
end

-- the two parts a joint connects and the pivot in each part's space
local function pivotOf(j: Instance): (BasePart?, BasePart?, CFrame?, CFrame?)
	if j:IsA("AnimationConstraint") then
		local a0, a1 = j.Attachment0, j.Attachment1
		if a0 and a1 and a0.Parent and a1.Parent and a0.Parent:IsA("BasePart") and a1.Parent:IsA("BasePart") then
			return a0.Parent :: BasePart, a1.Parent :: BasePart, a0.CFrame, a1.CFrame
		end
	elseif j:IsA("Motor6D") then
		return j.Part0, j.Part1, j.C0, j.C1
	end
	return nil, nil, nil, nil
end

local function attach(part: BasePart, name: string, cf: CFrame): Attachment
	local a = Instance.new("Attachment")
	a.Name = name
	a.CFrame = cf
	a.Parent = part
	return a
end

local function build(model: Model, humanoid: Humanoid, player: Player?): Rig
	local rig: Rig = { model = model, humanoid = humanoid, player = player, joints = {}, constraints = {}, parts = {}, on = false, untilT = 0 }
	for _, j in model:GetDescendants() do
		local lim = LIMITS[j.Name]
		if not lim or not (j:IsA("Motor6D") or j:IsA("AnimationConstraint")) then
			continue
		end
		local p0, p1, c0, c1 = pivotOf(j)
		if not (p0 and p1 and c0 and c1) then
			continue
		end
		-- ball: primary axis along the hanging limb, so the rest pose is the centre of the cone
		-- hinge: primary axis = the part's X (left-right), the limb bends around it
		local rot = if lim[1] == "Ball" then CFrame.Angles(0, 0, -math.pi / 2) else CFrame.identity
		local a0 = attach(p0, "Ragdoll" .. j.Name .. "0", CFrame.new(c0.Position) * rot)
		local a1 = attach(p1, "Ragdoll" .. j.Name .. "1", CFrame.new(c1.Position) * rot)
		local c: Constraint
		if lim[1] == "Ball" then
			local b = Instance.new("BallSocketConstraint")
			b.LimitsEnabled = true
			b.UpperAngle = lim[2]
			b.TwistLimitsEnabled = true
			b.TwistLowerAngle = -lim[3]
			b.TwistUpperAngle = lim[3]
			c = b
		else
			local h = Instance.new("HingeConstraint")
			h.LimitsEnabled = true
			h.LowerAngle = lim[2]
			h.UpperAngle = lim[3]
			c = h
		end
		c.Name = "Ragdoll" .. j.Name
		c.Attachment0 = a0
		c.Attachment1 = a1
		c.Enabled = false
		c.Parent = p1
		table.insert(rig.joints, j)
		table.insert(rig.constraints, c)
	end
	-- body parts only (accessory handles stay as they are)
	for _, p in model:GetChildren() do
		if p:IsA("BasePart") and p.Name ~= "HumanoidRootPart" then
			rig.parts[p] = p.CanCollide
		end
	end
	return rig
end

local function set(rig: Rig, on: boolean)
	if rig.on == on then
		return
	end
	rig.on = on
	for _, j in rig.joints do
		j.Enabled = not on
	end
	for _, c in rig.constraints do
		c.Enabled = on
	end
	for p, normal in rig.parts do
		if p.Parent then
			p.CanCollide = if on then true else normal
		end
	end
	rig.model:SetAttribute("Ragdoll", on)

	-- loose limbs become their own assemblies: keep them with the body's owner
	local owner = rig.player
	if owner and owner.Parent ~= Players then
		owner = nil
	end
	for _, p in rig.model:GetDescendants() do
		if p:IsA("BasePart") and not p.Anchored then
			pcall(p.SetNetworkOwner, p, owner)
		end
	end

	local h = rig.humanoid
	if not rig.player and h.Health > 0 then
		h:ChangeState(if on then Enum.HumanoidStateType.Physics else Enum.HumanoidStateType.GettingUp)
	end
end

function Ragdoll.Add(model: Model, humanoid: Humanoid, player: Player?)
	if rigs[model] then
		return
	end
	rigs[model] = build(model, humanoid, player)
	model:SetAttribute("Ragdoll", false)
end

function Ragdoll.Remove(model: Model)
	rigs[model] = nil
end

function Ragdoll.Is(model: Model): boolean
	local rig = rigs[model]
	return rig ~= nil and rig.on
end

-- loose for `duration` (extends a ragdoll that is already running)
function Ragdoll.Start(model: Model, duration: number)
	local rig = rigs[model]
	if not rig then
		return
	end
	rig.untilT = math.max(if rig.on then rig.untilT else 0, now() + duration)
	set(rig, true)
end

-- stand back up right away (a non-launching hit, a grab)
function Ragdoll.Stop(model: Model)
	local rig = rigs[model]
	if rig and rig.on and rig.humanoid.Health > 0 then
		rig.untilT = 0
		set(rig, false)
	end
end

-- a loose body standing still stays balanced on its feet: tip it backwards.
-- Pushes the torso, not the root: on death Roblox disables the Root joint, so the root is loose from the body.
function Ragdoll.Topple(model: Model)
	local torso = model:FindFirstChild("UpperTorso") :: BasePart?
	if torso then
		torso.AssemblyAngularVelocity += torso.CFrame.RightVector * 5
		torso.AssemblyLinearVelocity += -torso.CFrame.LookVector * 6 + Vector3.yAxis * 4
	end
end

-- death: loose for good (players topple themselves on their client, they own the body)
function Ragdoll.Forever(model: Model)
	local rig = rigs[model]
	if rig then
		rig.untilT = math.huge
		set(rig, true)
		if not rig.player then
			Ragdoll.Topple(model)
		end
	end
end

function Ragdoll.Step(t: number)
	for model, rig in rigs do
		if not model.Parent then
			rigs[model] = nil
		elseif rig.on and t >= rig.untilT and rig.humanoid.Health > 0 then
			set(rig, false)
		end
	end
end

return Ragdoll
```

```luau
-- Tiny test runner. A spec is a ModuleScript that returns function(t) and registers tests:
--
--   return function(t)
--       t.test("clean hit deals damage", function()
--           t.eq(result, "Hit")
--           t.near(hp, 97, 0.01)
--       end)
--   end
--
-- Tests run one after another and may yield. A failing check throws; the runner catches it,
-- records the message and line, and moves on. t.cleanup(fn) runs after the current test either way,
-- t.afterAll(fn) once after the spec's last test (tear down shared fixtures).
local TestKit = {}

export type Result = { spec: string, name: string, ok: boolean, err: string? }

local function fmt(v: any): string
	if type(v) == "string" then
		return string.format("%q", v)
	end
	return tostring(v)
end

local function newContext()
	local t = { _tests = {}, _cleanups = {}, _afterAll = {} }

	function t.test(name: string, fn: () -> ())
		table.insert(t._tests, { name = name, fn = fn })
	end

	function t.cleanup(fn: () -> ())
		table.insert(t._cleanups, fn)
	end

	function t.afterAll(fn: () -> ())
		table.insert(t._afterAll, fn)
	end

	function t.ok(cond: any, msg: string?)
		if not cond then
			error(msg or "expected a truthy value", 2)
		end
	end

	function t.eq(actual: any, expected: any, msg: string?)
		if actual ~= expected then
			error(string.format("%sexpected %s, got %s", if msg then msg .. ": " else "", fmt(expected), fmt(actual)), 2)
		end
	end

	function t.near(actual: number, expected: number, eps: number, msg: string?)
		if type(actual) ~= "number" or math.abs(actual - expected) > eps then
			error(string.format("%sexpected %s +- %s, got %s", if msg then msg .. ": " else "", fmt(expected), fmt(eps), fmt(actual)), 2)
		end
	end

	return t
end

-- runs every spec ModuleScript under `folder` (sorted by name)
function TestKit.Run(folder: Instance): { Result }
	local specs = {}
	for _, m in folder:GetChildren() do
		if m:IsA("ModuleScript") then
			table.insert(specs, m)
		end
	end
	table.sort(specs, function(a, b)
		return a.Name < b.Name
	end)

	local results: { Result } = {}
	for _, m in specs do
		local t = newContext()
		local loaded, err = pcall(function()
			(require(m) :: any)(t)
		end)
		if not loaded then
			table.insert(results, { spec = m.Name, name = "(load)", ok = false, err = tostring(err) })
			continue
		end
		for _, case in t._tests do
			local ok, e = xpcall(case.fn, function(msg)
				return tostring(msg)
			end)
			for i = #t._cleanups, 1, -1 do
				local cleaned, ce = pcall(t._cleanups[i])
				if not cleaned and ok then
					ok, e = false, "cleanup: " .. tostring(ce)
				end
			end
			table.clear(t._cleanups)
			table.insert(results, { spec = m.Name, name = case.name, ok = ok, err = if ok then nil else e })
		end
		for _, fn in t._afterAll do
			local done, e = pcall(fn)
			if not done then
				table.insert(results, { spec = m.Name, name = "(afterAll)", ok = false, err = tostring(e) })
			end
		end
	end
	return results
end

-- one summary line, plus a line per failure
function TestKit.Report(results: { Result }, seconds: number): (number, number)
	local passed, failed = 0, 0
	for _, r in results do
		if r.ok then
			passed += 1
		else
			failed += 1
			warn(string.format("[Tests] FAIL %s > %s: %s", r.spec, r.name, r.err or "?"))
		end
	end
	local line = string.format("[Tests] %d passed, %d failed (%.2f s)", passed, failed, seconds)
	if failed > 0 then
		warn(line)
	else
		print(line)
	end
	return passed, failed
end

return TestKit
```

```luau
-- Visual feedback: camera shake, hit sparks, slam shockwave.
local RunService = game:GetService("RunService")
local TweenService = game:GetService("TweenService")

local Fx = {}

local ACCENT = Color3.fromRGB(255, 210, 60)
local WHITE = Color3.new(1, 1, 1)

local folder: Folder

---------------------------------------------------------------- camera shake
-- Applied after the camera update and removed at the very start of the next frame.
-- If it isn't removed first, the default camera builds on the shaken CFrame and the view drifts.

local trauma = 0
local decay = 2.5
local offset = CFrame.identity

function Fx.Shake(amount: number, decayRate: number?)
	trauma = math.min(1, trauma + amount)
	decay = decayRate or 2.5
end

-- FOV kick: + widens (speed: swings, dashes), - narrows (impact punch). Jumps in, eases back.
local fovKick = 0
local fovDecay = 8
local baseFov = 70

function Fx.Kick(amount: number, decayRate: number?)
	fovKick = math.clamp(fovKick + amount, -12, 12)
	fovDecay = decayRate or 8
end

-- camera nudge: + jolts the camera forward along its view (our hit landing), - jolts it back (we got hit)
local nudge = 0

function Fx.Nudge(amount: number)
	nudge = math.clamp(nudge + amount, -1.5, 1.5)
end

local function bindShake()
	RunService:BindToRenderStep("FxShakeReset", Enum.RenderPriority.First.Value, function()
		if offset ~= CFrame.identity then
			local cam = workspace.CurrentCamera
			cam.CFrame = cam.CFrame * offset:Inverse()
			offset = CFrame.identity
		end
	end)
	-- +2: after the default camera (+0) and the lock-on camera (+1)
	RunService:BindToRenderStep("FxShakeApply", Enum.RenderPriority.Camera.Value + 2, function(dt)
		if fovKick ~= 0 then
			fovKick -= fovKick * math.min(1, fovDecay * dt)
			if math.abs(fovKick) < 0.05 then
				fovKick = 0
			end
			workspace.CurrentCamera.FieldOfView = baseFov + fovKick
		end
		if nudge ~= 0 then
			nudge -= nudge * math.min(1, 14 * dt)
			if math.abs(nudge) < 0.01 then
				nudge = 0
			end
		end
		if trauma <= 0 and nudge == 0 then
			return
		end
		trauma = math.max(0, trauma - decay * dt)
		local a = trauma * trauma
		local t = os.clock() * 28
		offset = CFrame.new(math.noise(t, 7) * a * 0.35, math.noise(t, 11) * a * 0.35, -nudge)
			* CFrame.Angles(math.noise(t, 1) * a * 0.05, math.noise(t, 2) * a * 0.05, math.noise(t, 3) * a * 0.035)
		local cam = workspace.CurrentCamera
		cam.CFrame = cam.CFrame * offset
	end)
end

-- Style "star + shards": a short flash, crossed light bars through the hit point and glowing shards
-- thrown along the blow. Everything is neon parts + tweens (no uploaded textures), white with one accent.

local BLOCK = Color3.fromRGB(190, 215, 255)
local RED = Color3.fromRGB(255, 80, 70)

local function part(props: { [string]: any }): Part
	local p = Instance.new("Part")
	p.Anchored, p.CanCollide, p.CanQuery, p.CanTouch, p.CastShadow = true, false, false, false, false
	p.Material = Enum.Material.Neon

local function tween(inst: Instance, time: number, goal: { [string]: any }, style: Enum.EasingStyle?)
	local tw = TweenService:Create(inst, TweenInfo.new(time, style or Enum.EasingStyle.Quad, Enum.EasingDirection.Out), goal)
	tw:Play()
	if Fx.Hold then
		task.delay(time * Fx.Hold, function()
			tw:Pause()
		end)
	end
end

local function expire(inst: Instance, after: number)
	if not Fx.Hold then
		task.delay(after, inst.Destroy, inst)
	end
end

-- the blow direction plus two unit vectors spanning the plane facing it
local function basis(dir: Vector3?): (Vector3, Vector3, Vector3)
	local d = if dir and dir.Magnitude > 0.01 then dir.Unit else Vector3.zAxis
	local up = if math.abs(d.Y) > 0.9 then Vector3.xAxis else Vector3.yAxis
	local u = d:Cross(up).Unit
	local v = u:Cross(d).Unit
	return d, u, v
end

local function flash(pos: Vector3, color: Color3, size: number, time: number)
	local b = part({ Shape = Enum.PartType.Ball, Color = color, Transparency = 0.15, Size = Vector3.one * 0.4, CFrame = CFrame.new(pos) })
	tween(b, time, { Size = Vector3.one * size, Transparency = 1 })
	expire(b, time + 0.05)
end

-- star flare: crossed bars through the hit point, stretching and thinning out
local function star(pos: Vector3, dir: Vector3?, n: number, len: number, width: number, color: Color3, time: number)
	local d, u, v = basis(dir)
	local twist = math.random() * math.pi
	for i = 1, n do
		local ang = twist + i / n * math.pi
		local axis = u * math.cos(ang) + v * math.sin(ang)
		local L = if i % 2 == 1 then len else len * 0.55
		local p = part({ Color = color, Size = Vector3.new(width, width, L * 0.35), CFrame = CFrame.lookAt(pos, pos + axis, d) })
		tween(p, time, { Size = Vector3.new(0.02, 0.02, L), Transparency = 1 }, Enum.EasingStyle.Quart)
		expire(p, time + 0.05)
	end
end

-- glowing shards thrown along the blow, dropping a little
local function shards(pos: Vector3, dir: Vector3?, n: number, dist: number, color: Color3, time: number, fall: number?)
	local d, u, v = basis(dir)
	local drop = fall or 0.3
	for _ = 1, n do
		local ang = math.random() * math.pi * 2
		local out = (u * math.cos(ang) + v * math.sin(ang) + d * (0.3 + math.random() * 0.7)).Unit
		local s = dist * (0.6 + math.random() * 0.6)
		local target = pos + out * s - Vector3.yAxis * s * drop
		local p = part({ Color = color, Size = Vector3.new(0.16, 0.16, 0.8), CFrame = CFrame.lookAt(pos + out * 0.4, pos + out * 2) })
		tween(p, time, { CFrame = CFrame.lookAt(target, target + out - Vector3.yAxis * drop), Size = Vector3.new(0.05, 0.05, 0.25), Transparency = 1 })
		expire(p, time + 0.05)
	end
end

-- dir = the way the blow travels (attacker -> victim)
local STYLES = {
	Hit = function(pos, dir)
		flash(pos, WHITE, 1.6, 0.07)

	end,
	Parry = function(pos, dir)

		shards(pos, if dir then -dir else nil, 18, 6, ACCENT, 0.34)
	end,
	GuardBreak = function(pos, dir)
		flash(pos, RED, 4, 0.12)
		star(pos, dir, 4, 5, 0.2, RED, 0.18)
		shards(pos, dir, 16, 5, RED, 0.4, 0.8)
	end,
}

function Fx.Spark(pos: Vector3, kind: string, dir: Vector3?)
	local style = STYLES[kind]

	end
end

function Fx.Shockwave(pos: Vector3, radius: number)

	e.Texture = "rbxasset://textures/particles/smoke_main.dds"
	e.Color = ColorSequence.new(Color3.fromRGB(200, 200, 205))
```

```luau
		target = nil
	end
	local m = target
	if not m or not root then
		shownFor = nil
		marker.Visible = false
		return
	end
	local tr = m:FindFirstChild("HumanoidRootPart") :: BasePart
	local cfg = Config.LockOn

	-- camera: swing the default camera's view onto the target, keep its zoom; over the right shoulder
	local cam = workspace.CurrentCamera
	local focus = cam.Focus.Position
	local to = tr.Position - focus
	local dist = flatten(to).Magnitude
	if dist > 0.5 then
		local pitch = math.clamp(math.atan2(to.Y, dist) + math.rad(cfg.Pitch), math.rad(-70), math.rad(50))
		local want = flatten(to) / dist * math.cos(pitch) + Vector3.yAxis * math.sin(pitch)
		local look = cam.CFrame.LookVector:Lerp(want, 1 - math.exp(-cfg.CamTurnRate * dt))
		if look.Magnitude > 1e-3 then
			look = look.Unit
			-- zoom = distance from the pivot behind the shoulder (the default camera put us on the focus)
			local right = look:Cross(Vector3.yAxis)
			right = if right.Magnitude > 1e-3 then right.Unit else cam.CFrame.RightVector
			local shoulder = right * cfg.Shoulder
			local zoom = math.max(0.5, (cam.CFrame.Position - focus).Magnitude)
			if (cam.CFrame.Position - focus):Dot(cam.CFrame.RightVector) > cfg.Shoulder * 0.5 then
				-- last frame's shoulder offset is still in the camera: measure without it
				zoom = math.max(0.5, (cam.CFrame.Position - cam.CFrame.RightVector * cfg.Shoulder - focus).Magnitude)
			end
			local pos = focus - look * zoom + shoulder
			cam.CFrame = CFrame.lookAt(pos, pos + look)
		end
	end

	-- body: turn to face the target (not while ragdolled, grabbed, ...)
	if hooks.canTurn() then
		local fwd = flatten(root.CFrame.LookVector)
		local toT = flatten(tr.Position - root.Position)
		if toT.Magnitude > 0.3 and fwd.Magnitude > 1e-3 then
			local f = fwd.Unit:Lerp(toT.Unit, 1 - math.exp(-cfg.BodyTurnRate * dt))
			if f.Magnitude > 1e-3 then
				root.CFrame = CFrame.lookAt(root.Position, root.Position + f)
			end
		end
	end

	drawMarker(m)
end

		Parent = player:WaitForChild("PlayerGui"),

	RunService:BindToRenderStep("LockOnCamera", Enum.RenderPriority.Camera.Value + 1, step)
```

```luau
		local s = Instance.new("Sound")

		s.Parent = folder
		templates[id] = s
		table.insert(list, s)
	end
	task.spawn(ContentProvider.PreloadAsync, ContentProvider, list)

	anchor.Name = "SfxAnchor"
	anchor.Anchored, anchor.CanCollide, anchor.CanQuery, anchor.CanTouch = true, false, false, false

local function playClip(clip: Clip, parent: Instance, volume: number, pitch: number, positional: boolean)
	local template = templates[clip.id]
	if not template then
		return
	end
	local s = template:Clone()
	s.Volume = (clip.volume or 1) * volume
	s.PlaybackSpeed = (clip.pitch or 1) * pitch
	s.TimePosition = clip.start or 0
	if positional then
		s.RollOffMinDistance = 12
		s.RollOffMaxDistance = 240
	end
	s.Parent = parent
	s:Play()
	if clip.duration then
		task.delay(clip.duration, function()
			if s.Parent then
				s:Stop()
			end
		end)
	end
	if not positional then
		task.delay(4, s.Destroy, s)
	end
end

-- opts: at (Vector3 -> 3D), volume, pitch, layer (skip the anti-spam check)
function Sfx.Play(name: string, opts: { at: Vector3?, volume: number?, pitch: number?, layer: boolean? }?)
	local def = LIB[name]
	if not def or not anchor then
		return
	end
	opts = opts or {}
	local clock = os.clock()
	if not opts.layer and clock - (lastPlayed[name] or 0) < 0.04 then
		return
	end
	lastPlayed[name] = clock

	local parent: Instance = SoundService
	if opts.at then
		local att = Instance.new("Attachment")
		att.WorldPosition = opts.at
		att.Parent = anchor
		task.delay(4, att.Destroy, att)
		parent = att
	end
	-- one random detune for the whole stack, so the layers stay locked together
	local pitch = (opts.pitch or 1) * (0.96 + math.random() * 0.08)
	local volume = opts.volume or 1
	playClip(def, parent, volume, pitch, opts.at ~= nil)
	for _, layer in def.layers or {} do
		playClip(layer, parent, volume, pitch, opts.at ~= nil)
	end
end

return Sfx
```

```luau
-- every swing walks you through the target (and then you hit its back, past its block)

local function lunge(origin: CFrame, speed: number, duration: number)
	local nearest = math.huge
	for _, t in visibleTargets() do
		local rel = origin:PointToObjectSpace(t.pos)
		if rel.Z < 0 and math.abs(rel.X) < 3 then
			nearest = math.min(nearest, -rel.Z)
		end
	end
	local room = math.max(0, nearest - LUNGE_GAP)
	local v = math.min(speed, room / duration)
	if v > 0.5 then
		push(origin.LookVector * v, duration)
	end
end

	if not vRoot then
		return
	end
	local mine = a == char or v == char
	local toA = if aRoot then flat(aRoot.Position - vRoot.Position) else Vector3.zero
	local at = vRoot.Position + toA * 1.1 + Vector3.yAxis * 0.6
	local heavy = isHeavy(move, step)
	local soundAt = if mine then nil else at

	if r == "Hit" then

		-- the punch lands but doesn't stagger: short freeze on the attacker only, no hurt pose
		Anim.Freeze(a, 0.05)
		Fx.Spark(at, "Hit", -toA)
		Sfx.Play("Hit", { at = soundAt, pitch = 0.8, volume = 0.7 })
		if mine then
			Fx.Shake(0.15, 4)
		end
	elseif r == "Dodged" then
		HUD.Popup(v, "Dodge")
	end
end

-- run the shared hitbox against what we see right now and show the results immediately
local function predict(shape, origin: CFrame, move: string, step: number?, seq: number, only: Model?)
	local t = now()
	local hits = Hitbox.Find(shape, origin, visibleTargets(), Config.Fighter.HurtRadius, if only then 3 else nil)
	if #hits == 0 then
		return
	end
	predicted[seq] = {}
	for _, target in hits do
		local v = target.model
		if only and v ~= only then
			continue
		end
		local r = "Hit"
		if t <= (v:GetAttribute("IFrameUntil") or 0) then
			r = "Dodged"
		elseif v:GetAttribute("Blocking") then
			local vRoot = rootOf(v)
			if vRoot and vRoot.CFrame.LookVector:Dot(flat(origin.Position - vRoot.Position)) > Config.Block.FrontDot then
				r = "Blocked"
			end
		end
		if r == "Hit" and move == "M1" and t <= (v:GetAttribute("ArmorUntil") or 0) then
			r = "Armored" -- same order as the server: i-frames, block, armor
		end
		predicted[seq][v] = r
		feedback(char, v, r, move, step, hitstopFor(move, step))
		if r == "Hit" then
			local dmg = damageFor(move, step)
			HUD.Popup(v, tostring(dmg), isHeavy(move, step))
			bumpCombo(nil, dmg)
			landed(move)
		elseif r == "Armored" then
			HUD.Popup(v, tostring(damageFor(move, step))) -- damage, but no combo: it didn't stagger
		end
	end
	task.delay(2, function()
		predicted[seq] = nil
	end)
end

---------------------------------------------------------------- actions

local function sendBlock(on: boolean)
	S.blockSent = on
	Request:FireServer("Block", { on = on, t = now() })
end

local function tryM1()
	local t = now()
	local cfg = Config.M1
	if not canAct(t) or S.blockSent or t < S.m1ReadyAt then
		return
	end
	local step = if (t - S.lastM1 > cfg.ComboReset or S.comboStep >= cfg.Steps) then 1 else S.comboStep + 1
	S.comboStep = step
	S.lastM1 = t
	S.m1ReadyAt = t + (if step == cfg.Steps then cfg.EndLag else cfg.Interval)
	S.actionUntil = t + cfg.Windup + 0.12
	S.seq += 1
	local seq = S.seq
	local origin = Hitbox.Flat((root :: BasePart).CFrame)
	Request:FireServer("M1", { t = t, cf = origin, seq = seq })

	Anim.Play(char, "M1_" .. step)
	Fx.Kick(if step == cfg.Steps then 3 else 1.2, 9)
	Sfx.Play(if step == cfg.Steps then "SwingHeavy" else "Swing", { pitch = 1 + step * 0.04 })
	lunge(origin, cfg.Lunge, 0.12)

	local token = S.token
	task.delay(cfg.Windup, function()
		if S.token == token and alive() then
			predict(cfg.Hitbox, origin, "M1", step, seq)
		end
	end)
end

local function tryDash()
	local t = now()
	if not canAct(t) or t < S.dashReadyAt or not humanoid or not root then
		return
	end
	local md = humanoid.MoveDirection
	local world: Vector3
	local dir = "F"
	if md.Magnitude < 0.1 then
		world = flat(root.CFrame.LookVector)
	else
		world = flat(md)
		-- direction relative to the camera decides front dash vs dodge
		local cam = CFrame.lookAt(Vector3.zero, flat(workspace.CurrentCamera.CFrame.LookVector))
		local l = cam:VectorToObjectSpace(world)
		if math.abs(l.X) > math.abs(l.Z) then
			dir = if l.X > 0 then "R" else "L"
		else
			dir = if l.Z < 0 then "F" else "B"
		end
	end
	if S.blockSent then
		sendBlock(false)
	end
	S.dashReadyAt = t + Config.Dash.Cooldown
	HUD.SetCooldown("Dash", S.dashReadyAt, Config.Dash.Cooldown)
	Request:FireServer("Dash", { dir = dir, t = t })

	local spec = if dir == "F" then Config.Dash.Front else Config.Dash.Dodge
	push(world * spec.Speed, spec.Duration)
	S.dashHit = if dir == "F" then { untilT = t + spec.Duration, token = S.token } else nil
	-- animation follows where we move relative to the body, not the camera
	local rel = root.CFrame:VectorToObjectSpace(world)
	local animDir = if math.abs(rel.X) > math.abs(rel.Z) then (if rel.X > 0 then "R" else "L") else (if rel.Z < 0 then "F" else "B")
	Anim.Play(char, "Dash" .. animDir)
	Fx.Kick(if dir == "F" then 7 else 4, 6)
	Sfx.Play("Dash")
end

-- front dash: the first fighter we run into gets a short stun and the dash stops on them
local function stepDashHit(t: number)
	local d = S.dashHit
	if not d or not root then
		return
	end
	if d.token ~= S.token or t > d.untilT then
		S.dashHit = nil
		return
	end
	local cfg = Config.Dash.Hit
	local origin = Hitbox.Flat(root.CFrame)
	local hits = Hitbox.Find(cfg.Hitbox, origin, visibleTargets(), Config.Fighter.HurtRadius)
	local target = hits[1]
	if not target then
		return
	end
	S.dashHit = nil
	stopPush()
	S.seq += 1
	Request:FireServer("DashHit", { target = target.model, t = t, cf = origin, seq = S.seq })
	predict(cfg.Hitbox, origin, "Dash", nil, S.seq, target.model)
end

local function startRush(cfg, t: number)
	S.actionUntil = t + cfg.Windup + cfg.RushTime + 0.1
	S.moveLockUntil = S.actionUntil
	S.rush = { startT = t + cfg.Windup, untilT = t + cfg.Windup + cfg.RushTime, cfg = cfg, pushing = false, token = S.token }
	Anim.Play(char, "GrabRush")
	Sfx.Play("SwingHeavy", { pitch = 0.85 })
end

local function stepRush(t: number)
	local r = S.rush
	if not r or not root then
		return
	end
	if r.token ~= S.token or t > r.untilT then
		S.rush = nil
		stopPush()
		return
	end
	if t < r.startT then
		return
	end
	local origin = Hitbox.Flat(root.CFrame)
	if not r.pushing then
		r.pushing = true
		push(origin.LookVector * r.cfg.RushSpeed, r.cfg.RushTime)
		Fx.Kick(9, 5)
		Sfx.Play("Dash", { pitch = 0.9 })
	end
	local hits = Hitbox.Find(r.cfg.Hitbox, origin, visibleTargets(), Config.Fighter.HurtRadius)
	if hits[1] then
		S.rush = nil
		stopPush()
		S.grabPendingUntil = t + 0.5
		Request:FireServer("GrabHit", { target = hits[1].model, t = t, cf = origin })
		Sfx.Play("Hit", { pitch = 0.8 })
		Fx.Shake(0.2, 4)
	end
end

local function startSlam(cfg, t: number, origin: CFrame, seq: number)
	S.actionUntil = t + cfg.Windup + 0.25
	S.moveLockUntil = S.actionUntil
	Anim.Play(char, "Slam")
	Sfx.Play("SwingHeavy", { pitch = 0.7 })
	local token = S.token
	task.delay(cfg.Windup, function()
		if S.token ~= token or not alive() then
			return
		end
		Fx.Shockwave(origin.Position - Vector3.yAxis * 2.9, cfg.Hitbox.Radius)
		Sfx.Play("Boom")
		Sfx.Play("HitHeavy", { pitch = 0.6, layer = true })
		Fx.Shake(0.8, 1.8)
		Fx.Kick(-9, 5)
		Fx.Nudge(0.8)
		predict(cfg.Hitbox, origin, "GroundSlam", nil, seq)
	end)
end

-- Barrage: rooted flurry, one prediction per hit (seq, seq + 1, ...; the server numbers them the same)
local function startBarrage(cfg, t: number, origin: CFrame, seq: number)
	S.actionUntil = t + cfg.Windup + (cfg.Hits - 1) * cfg.Interval + 0.15
	S.moveLockUntil = S.actionUntil
	S.seq = seq + cfg.Hits - 1
	Anim.Play(char, "Barrage")
	local token = S.token
	for i = 1, cfg.Hits do
		task.delay(cfg.Windup + (i - 1) * cfg.Interval, function()
			if S.token ~= token or not alive() then
				return
			end
			local final = i == cfg.Hits
			Sfx.Play(if final then "SwingHeavy" else "Swing", { pitch = 1.1 + i * 0.03 })
			Fx.Kick(if final then 2.5 else 0.8, 10)
			predict(cfg.Hitbox, origin, "Barrage", i, seq + i - 1)
		end)
	end
end

local function startUppercut(cfg, t: number, origin: CFrame, seq: number)
	S.actionUntil = t + cfg.Windup + 0.3
	S.moveLockUntil = S.actionUntil
	Anim.Play(char, "Uppercut")
	Sfx.Play("SwingHeavy", { pitch = 0.95 })
	local token = S.token
	task.delay(cfg.Windup - 0.08, function()
		if S.token == token and alive() then
			lunge(Hitbox.Flat((root :: BasePart).CFrame), cfg.Lunge, 0.12)
		end
	end)
	task.delay(cfg.Windup, function()
		if S.token ~= token or not alive() then
			return
		end
		Fx.Kick(3, 7)
		predict(cfg.Hitbox, origin, "Uppercut", nil, seq)
	end)
end

local function tryAbility(id: string)
	local cfg = Config.Abilities[id]
	local t = now()
	if not cfg or not root or not canAct(t) or t < (S.cds[id] or 0) then
		return
	end
	if S.blockSent then
		sendBlock(false)
	end
	S.cds[id] = t + cfg.Cooldown
	HUD.SetCooldown(id, S.cds[id], cfg.Cooldown)
	S.seq += 1
	local origin = Hitbox.Flat(root.CFrame)
	Request:FireServer("Ability", { id = id, t = t, cf = origin, seq = S.seq })
	if id == "GrabRush" then
		startRush(cfg, t)
	elseif id == "GroundSlam" then
		startSlam(cfg, t, origin, S.seq)
	elseif id == "Barrage" then
		startBarrage(cfg, t, origin, S.seq)
	elseif id == "Uppercut" then
		startUppercut(cfg, t, origin, S.seq)
	end
end

Effect.OnClientEvent:Connect(function(kind: string, d: any)
	if kind == "Result" then
		local mineA, mineV = d.a == char, d.v == char
		local guess = mineA and d.seq and predicted[d.seq] and predicted[d.seq][d.v]
		if guess then

			if guess ~= d.r then
				feedback(d.a, d.v, d.r, d.move, d.step, d.hitstop)
			end
			if d.r == "Hit" then
				S.comboShown = d.combo

			end
		else
			feedback(d.a, d.v, d.r, d.move, d.step, d.hitstop)

				HUD.Popup(d.v, tostring(d.dmg), true)
				bumpCombo(d.combo, d.dmg)
				landed(d.move)
			elseif mineA and d.r == "Armored" then
				HUD.Popup(d.v, tostring(d.dmg))
			end
		end

		if mineV and (d.r == "Hit" or d.r == "GuardBreak") then
			interrupted()
			if d.kb then
				push(d.kb, 0.12, true)
			end
		end
		if mineA and d.r == "Parried" then
			interrupted()
		end
	elseif kind == "Grab" then
		Anim.Stop(d.v) -- the Grabbed hold takes over
		if d.a == char then
			S.grabbing = true
			S.grabPendingUntil = 0
			local hold = Config.Abilities.GrabRush.Hold
			task.delay(math.max(0, hold - 0.2), function()
				if S.grabbing then
					Anim.Play(char, "GrabSlam")
					Sfx.Play("SwingHeavy", { pitch = 0.8 })
				end
			end)
		else
			task.delay(math.max(0, Config.Abilities.GrabRush.Hold - 0.2), Anim.Play, d.a, "GrabSlam")
		end
		Sfx.Play("Hit", { at = if d.a == char or d.v == char then nil else rootOf(d.v) and (rootOf(d.v) :: BasePart).Position, pitch = 0.8 })
	elseif kind == "GrabEnd" then
		if d.a == char then
			S.grabbing = false
			S.actionUntil = now() + 0.15
		end
		if d.slam then
			local vRoot = rootOf(d.v)
			if vRoot then
				Fx.Shockwave(vRoot.Position - Vector3.yAxis * 2.5, 6)
			end
			Sfx.Play("Boom", { at = if d.a == char or d.v == char then nil else vRoot and vRoot.Position, volume = 0.7 })
		end
	elseif kind == "Denied" then
		if d.action == "M1" then
			S.comboStep = d.step or 0
		elseif d.action == "Block" then
			S.blockSent = false
			S.blockRetryAt = now() + 0.15
		elseif Config.Abilities[d.action] then
			S.cds[d.action] = 0
			HUD.SetCooldown(d.action, 0, 1)
		end
	end
end)

local tracked: { [Model]: boolean } = {}

local function track(m: Instance)
	if not m:IsA("Model") or tracked[m] then
		return
	end
	task.spawn(function()
		local h = m:WaitForChild("Humanoid", 10)
		local r = m:WaitForChild("HumanoidRootPart", 10)
		if not h or not r or not m.Parent then
			return
		end
		tracked[m] = true
		Anim.Register(m)
	end)
end

-- ragdoll landings: a loose body hitting the floor thumps. Fall speed comes from the torso's own
-- positions, so it works the same for our body, other players and dummies.
local landRay = RaycastParams.new()
landRay.CollisionGroup = "Fighters" -- fighters don't collide with fighters: the ray ignores bodies
landRay.IgnoreWater = true
local falls: { [Model]: { y: number, vy: number, quietUntil: number, armedUntil: number } } = {}

local function stepLandings(dt: number, t: number)
	if dt <= 0 then
		return
	end
	local cfg = Config.Ragdoll
	for m in tracked do
		local torso = m:FindFirstChild("UpperTorso") :: BasePart?
		local f = falls[m]
		local loose = m:GetAttribute("Ragdoll") == true
		if not torso or (not loose and (not f or t > f.armedUntil)) then
			falls[m] = nil
			continue
		end
		local y = torso.Position.Y
		if not f then
			falls[m] = { y = y, vy = 0, quietUntil = 0, armedUntil = t + cfg.LandGrace }
			continue
		end
		if loose then
			f.armedUntil = t + cfg.LandGrace
		end
		local vy = (y - f.y) / dt
		-- a fast fall that just stopped, right above the floor
		local stopped = f.vy < -cfg.LandSpeed and vy > f.vy * 0.4
		if stopped and t >= f.quietUntil and workspace:Raycast(torso.Position, Vector3.new(0, -3, 0), landRay) then
			Sfx.Play("Fall", { at = torso.Position, volume = math.clamp(-f.vy / 35, 0.5, 1.2), layer = true })
			f.quietUntil = t + cfg.LandCooldown
		end
		f.y, f.vy = y, vy
	end
end

	tracked[m] = nil
	falls[m] = nil

local function onCharacter(c: Model)
	char = c
	humanoid = c:WaitForChild("Humanoid") :: Humanoid
	root = c:WaitForChild("HumanoidRootPart") :: BasePart
	local h, r = humanoid :: Humanoid, root :: BasePart

	S.token += 1
	S.comboStep, S.actionUntil, S.moveLockUntil, S.dashReadyAt = 0, 0, 0, 0
	S.blockSent, S.rush, S.grabbing = false, nil, false
	S.cds = {}

	local att = Instance.new("Attachment")
	att.Name = "PushAttachment"
	att.Parent = r
	local lv = Instance.new("LinearVelocity")
	lv.Name = "Push"
	lv.Attachment0 = att
	lv.RelativeTo = Enum.ActuatorRelativeTo.World
	lv.ForceLimitMode = Enum.ForceLimitMode.PerAxis
	lv.MaxAxesForce = Vector3.new(1e6, 0, 1e6)
	lv.Enabled = false
	lv.Parent = r
	pushAtt, pushLV = att, lv

	-- death ragdoll (the server loosens the joints): tip the body over, it would stay balanced otherwise.
	-- Push the torso: on death the Root joint is off, the root part no longer carries the body.
	h.Died:Connect(function()
		stopPush()
		local torso = c:FindFirstChild("UpperTorso") :: BasePart?
		if torso then
			torso.AssemblyAngularVelocity += torso.CFrame.RightVector * 5
			torso.AssemblyLinearVelocity += -torso.CFrame.LookVector * 6 + Vector3.yAxis * 4
		end
	end)

	-- a fresh stun from the server interrupts whatever we were doing
	c:GetAttributeChangedSignal("StunUntil"):Connect(function()
		local v = c:GetAttribute("StunUntil") or 0
		if v > S.lastStunUntil + 0.01 and v > now() then
			interrupted()
		end
		S.lastStunUntil = v
	end)
	track(c)
end

local function stepLocal(t: number)
	if not alive() then
		return
	end
	local h = humanoid :: Humanoid
	local c = char :: Model

	-- ragdoll: the server swaps the joints, we own our humanoid so we flip its state
	local rag = ragdolled()
	local state = h:GetState()
	if rag and state ~= Enum.HumanoidStateType.Physics and state ~= Enum.HumanoidStateType.Dead then
		h:ChangeState(Enum.HumanoidStateType.Physics)
	elseif not rag and state == Enum.HumanoidStateType.Physics then
		h:ChangeState(Enum.HumanoidStateType.GettingUp)
	end

	if S.m1Held then
		tryM1()
	end

	-- block follows the key, re-sent automatically after a stun ends
	if S.blockSent and (stunned(t) or grabbed()) then
		S.blockSent = false
	end
	if S.blockHeld and not S.blockSent and t >= S.blockRetryAt and canAct(t) then
		sendBlock(true)
	end

	stepRush(t)
	stepDashHit(t)
	if S.grabPendingUntil > 0 and t > S.grabPendingUntil then
		S.grabPendingUntil = 0
	end

	-- movement rules
	local ws, jump = Config.Fighter.WalkSpeed, Config.Fighter.JumpPower
	if rag or grabbed() or S.grabbing or S.grabPendingUntil > 0 or t < S.moveLockUntil then
		ws, jump = 0, 0
	elseif stunned(t) then
		ws, jump = Config.Fighter.StunWalkSpeed, 0
	elseif S.blockSent then
		ws, jump = Config.Block.WalkSpeed, 0
	elseif t < S.actionUntil + 0.1 then
		ws, jump = Config.M1.WalkSpeed, 0
	end
	h.WalkSpeed = ws
	h.JumpPower = jump
	-- locked on: LockOn turns us to the target instead
	h.AutoRotate = not (rag or grabbed() or S.grabbing or LockOn.Target() ~= nil)

	HUD.SetPosture(c:GetAttribute("Posture") or Config.Block.MaxPosture, Config.Block.MaxPosture, S.blockSent, c)
end

-- holds come from replicated state (and our own prediction for us)
local function stepHolds(t: number)
	for m in tracked do
		local hold = nil
		local isMe = m == char
		if m:GetAttribute("Grabbed") then
			hold = "Grabbed"
		elseif (isMe and S.blockSent) or (not isMe and m:GetAttribute("Blocking")) then
			hold = "Block"
		elseif t < (m:GetAttribute("StunUntil") or 0) then
			hold = "Stunned"
		elseif isMe and (S.grabbing or S.grabPendingUntil > 0) then
			hold = "GrabHold"
		end
		Anim.Hold(m, hold)
	end
end
```
