`README.md`:

```md
# CharlyEngine 🟢>_ — mini Cheat Engine per Android (root)

> Selezioni un gioco → scansioni la memoria cercando il valore della valuta →
> la valuta cambia nel gioco → riscansioni → gli indirizzi si restringono →
> **INIETTI** il valore che vuoi (o lo **CONGELI** per sempre) e vedi i cambiamenti
> **in tempo reale nel terminale**.

Un [Cheat Engine](https://www.cheatengine.org/) minimale per Android: app Kotlin + Jetpack Compose,
core di scansione in C (NDK) eseguito come root.

⚠️ **Solo per uso legittimo:** dispositivo tuo, giochi offline/single-player.
Usarlo su giochi online viola i ToS e porta al ban dell'account; testare sistemi di terzi
senza autorizzazione è un reato (art. 615-ter c.p. in Italia).

---

## Funzioni

- 🔎 **SCANSIONA** — cerca nella memoria del gioco tutti gli indirizzi che contengono un valore
- 🔄 **RISCANSIONA** — raffina dopo un cambio della valuta nel gioco (il classico ciclo Cheat Engine)
- 💰 **INIETTA / INIETTA IN TUTTI** — scrive il valore scelto in un indirizzo o in tutti insieme
- ❄ **CONGELA / CONGELA TUTTI** — blocca il valore per sempre (riscritto ogni 250 ms)
- 💾 **Sessioni salvate** — esci dall'app e torna quando vuoi: indirizzi e congelamenti di ogni gioco restano salvati e si ripristinano da soli
- 📲 **AVVIA e aggancia** — puoi partire anche col gioco chiuso: CharlyEngine lo apre e lo aggancia appena parte
- 🖥️ **Terminale live** — registro di tutto + righe `[LIVE]` quando un valore cambia
- 📖 **Guida integrata** — procedura a 4 passi spiegata per utenti non esperti (si apre al primo avvio)
- Tipi di valore: intero, decimale, long, word, byte

## Screenshot del flusso

  scegli il      scrivi 850       cambia la valuta     💰 999999 + ❄ congelati

| Android Studio + **NDK** + CMake (SDK Manager → SDK Tools) | compilare la parte nativa |

## Come si usa — il flusso della "valuta"

1. Trova il gioco nell'elenco (se è chiuso: **▶ AVVIA**, CharlyEngine lo aggancia da solo)
2. Guarda la valuta nel gioco (es. monete = `850`), scrivi `850` e premi **SCANSIONA**
3. **Cambia la valuta nel gioco** (spendi o guadagna, es. diventa `743`)
4. Scrivi `743` e premi **RISCANSIONA** — ripeti 3-4 finché restano pochi indirizzi
5. Scrivi il valore dei sogni (es. `999999`) e premi **💰 INIETTA IN TUTTI**
6. Se il gioco riporta il valore indietro: **❄ CONGELA TUTTI**

Consigli: monete → tipo «Intero»; vite/energia → «Decimale». Se non trovi il valore,
prova ×10/×100 (il gioco mostra `850` ma salva `8500`).

## Architettura

```
┌────────────────────────────── app (Kotlin/Compose, uid app) ──────────┐
│  UI: lista app · procedura 4 passi · risultati live · terminale       │
│  SessionStore: indirizzi/congelamenti salvati per ogni gioco          │
│           │  righe di testo (stdin/stdout via `su`)                   │
└───────────┼───────────────────────────────────────────────────────────┘
            ▼
┌──────────────────── memscand (C, eseguito come root) ────────────────┐
│ ATTACH pid → legge /proc/pid/maps (solo regioni rw-p)                │
│ SCAN valore   → pread64 a blocchi di 1 MB + confronto in memoria     │
│ RESCAN valore → rilegge SOLO gli indirizzi candidati e filtra        │
│ RESTORE addrs → ricarica una sessione salvata (indirizzi validati)   │
│ WRITE addr    → pwrite64 del nuovo valore (+ verifica read-back)     │
│ FREEZE addr   → thread che riscrive il valore ogni 250 ms            │
└───────────────────────────────────────────────────────────────────────┘
```

L'eseguibile C è pacchettizzato nell'APK col trucco `libmemscand.so` (CMake
`PREFIX lib` + `SUFFIX .so`), copiato all'avvio in `/data/local/tmp` e lanciato
con `su`. Quando l'app muore, il daemon riceve EOF su stdin e si spegne da solo.

### Protocollo del daemon (per giocarci da Termux)

```
su -c /data/local/tmp/memscand
PING · HELLO · PROCS · ATTACH <pid> · REGIONS
SCAN <tipo> <valore> · RESCAN <tipo> <valore> · COUNT · RESULTS <start> <count>
READ <tipo> <addr> · WRITE <tipo> <addr> <valore>
FREEZE <tipo> <addr> <valore> · UNFREEZE <addr> · UNFREEZE_ALL
RESTORE <tipo> <addr> [<addr> …] · RESET · DETACH · QUIT
(tipi: b w d q f D)
```

Ogni risposta: righe dati opzionali + una riga finale `OK …` / `ERR …`.

`app/src/main/cpp/memscand.c`:

```c
/*
 * memscand — daemon minimale di scansione/modifica memoria (richiede root)
 *
 * Protocollo testuale su stdin/stdout: una riga per comando,
 * risposta = righe dati (opzionali) + UNA riga finale "OK ..." oppure "ERR ...".
 *
 * Comandi:
 *   HELLO
 *   PING
 *   PROCS                                  -> "pid|comm|cmdline" per ogni processo
 *   ATTACH <pid>                           -> apre /proc/pid/mem e legge le mappe
 *   REGIONS [n]                            -> elenco regioni rw-p
 *   SCAN   <tipo> <valore>                 -> prima scansione (tipo: b w d q f D)
 *   RESCAN <tipo> <valore>                 -> raffina: tiene solo gli indirizzi
 *                                             il cui valore ATTUALE == valore
 *   COUNT
 *   RESULTS <start> <count>                -> "indirizzohex|valoreattuale"
 *   READ   <tipo> <indirizzohex>
 *   WRITE  <tipo> <indirizzohex> <valore>
 *   FREEZE <tipo> <indirizzohex> <valore>  -> riscrive il valore ogni ~250 ms
 *   UNFREEZE <indirizzohex>  |  UNFREEZE_ALL
 *   RESET | DETACH | QUIT
 *
 * Tipi valore: b=int8, w=int16, d=int32, q=int64, f=float32, D=float64
 */

#define _GNU_SOURCE
#define _FILE_OFFSET_BITS 64

#include <ctype.h>
#include <dirent.h>
#include <errno.h>
#include <fcntl.h>
#include <limits.h>
#include <pthread.h>
#include <signal.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>

#define MAX_REGIONS  8192
#define MAX_MATCHES  300000
#define CHUNK_SIZE   (1u << 20)
#define MAX_FREEZES  256
#define FREEZE_US    250000

typedef struct {
    uint64_t start;
    uint64_t end;
    char     perms[5];
    char     path[384];
} Region;

static Region g_regions[MAX_REGIONS];
static int     g_nregions;
static int     g_pid   = -1;
static int     g_memfd = -1;

static uint64_t *g_matches = NULL;
static size_t    g_nmatches;
static int       g_truncated;
static char      g_last_type = 'd';

static pthread_mutex_t g_lock = PTHREAD_MUTEX_INITIALIZER;

/* ------------------------------ freeze ---------------------------------- */

typedef struct {
    uint64_t addr;
    size_t   len;
    uint8_t  bytes[8];
    int      active;
} Freeze;

static Freeze g_freezes[MAX_FREEZES];
static int    g_nfreezes;
static volatile int g_freeze_running = 0;
static pthread_t    g_freeze_thread;

static void clear_freezes(void) {
    for (int i = 0; i < g_nfreezes; i++) g_freezes[i].active = 0;
    g_nfreezes = 0;
}

static void *freeze_thread(void *arg) {
    (void)arg;
    while (g_freeze_running) {
        usleep(FREEZE_US);
        if (g_memfd < 0) continue;
        pthread_mutex_lock(&g_lock);
        for (int i = 0; i < g_nfreezes; i++) {
            if (!g_freezes[i].active) continue;
            if (pwrite64(g_memfd, g_freezes[i].bytes, g_freezes[i].len,
                         (off64_t)g_freezes[i].addr) != (ssize_t)g_freezes[i].len) {
                g_freezes[i].active = 0; /* indirizzo andato: disarmalo */
            }
        }
        pthread_mutex_unlock(&g_lock);
    }
    return NULL;
}

static void ensure_freeze_thread(void) {
    if (!g_freeze_running) {
        g_freeze_running = 1;
        pthread_create(&g_freeze_thread, NULL, freeze_thread, NULL);
    }
}

/* ------------------------------ valori ----------------------------------- */

static size_t type_size(char t) {
    switch (t) {
        case 'b': return 1;
        case 'w': return 2;
        case 'd': case 'f': return 4;
        case 'q': case 'D': return 8;
        default:  return 0;
    }
}

/* Converte "1337" / "12.5" / "0xFF" nei byte del tipo richiesto. */
static int pack_value(char t, const char *s, uint8_t *out, size_t *len) {
    char *end = NULL;
    size_t n = type_size(t);
    if (n == 0 || s == NULL || *s == '\0') return -1;
    errno = 0;
    if (t == 'f') {
        float v = strtof(s, &end);
        if (end == s) return -1;
        memcpy(out, &v, 4);
    } else if (t == 'D') {
        double v = strtod(s, &end);
        if (end == s) return -1;
        memcpy(out, &v, 8);
    } else {
        long long v = strtoll(s, &end, 0);
        if (end == s) return -1;
        switch (t) {
            case 'b':
                if (v < -128 || v > 127) return -1;
                { int8_t x = (int8_t)v;  memcpy(out, &x, 1); } break;
            case 'w':
                if (v < -32768 || v > 32767) return -1;
                { int16_t x = (int16_t)v; memcpy(out, &x, 2); } break;
            case 'd':
                if (v < INT32_MIN || v > INT32_MAX) return -1;
                { int32_t x = (int32_t)v; memcpy(out, &x, 4); } break;
            case 'q':
                { int64_t x = (int64_t)v; memcpy(out, &x, 8); } break;
        }
    }
    *len = n;
    return 0;
}

/* Legge il valore all'indirizzo e lo formatta secondo il tipo. */
static void format_at(uint64_t addr, char t, char *out, size_t outsz) {
    uint8_t tmp[8];
    size_t n = type_size(t);
    if (n == 0) { snprintf(out, outsz, "?"); return; }
    if (pread64(g_memfd, tmp, n, (off64_t)addr) != (ssize_t)n) {
        snprintf(out, outsz, "?");
        return;
    }
    switch (t) {
        case 'b': { int8_t  v; memcpy(&v, tmp, 1); snprintf(out, outsz, "%d", (int)v);  break; }
        case 'w': { int16_t v; memcpy(&v, tmp, 2); snprintf(out, outsz, "%d", (int)v);  break; }
        case 'd': { int32_t v; memcpy(&v, tmp, 4); snprintf(out, outsz, "%d", v);       break; }
        case 'q': { int64_t v; memcpy(&v, tmp, 8); snprintf(out, outsz, "%lld", (long long)v); break; }
        case 'f': { float   v; memcpy(&v, tmp, 4); snprintf(out, outsz, "%g", v);       break; }
        case 'D': { double  v; memcpy(&v, tmp, 8); snprintf(out, outsz, "%g", v);       break; }
        default:  snprintf(out, outsz, "?");
    }
}

/* ------------------------------ mappe ------------------------------------ */

static int load_regions(void) {
    char path[64];
    snprintf(path, sizeof(path), "/proc/%d/maps", g_pid);
    FILE *f = fopen(path, "r");
    if (!f) return -1;
    g_nregions = 0;
    char line[1024];
    while (fgets(line, sizeof(line), f)) {
        unsigned long a = 0, b = 0;
        char perms[8] = {0};
        char ppath[512] = {0};
        int n = sscanf(line, "%lx-%lx %4s %*s %*s %*s %511[^\n]", &a, &b, perms, ppath);
        if (n < 3) continue;
        if (perms[0] != 'r' || perms[1] != 'w') continue;   /* solo rw */
        if (b <= a) continue;
        if (strncmp(ppath, "/dev/", 5) == 0) continue;      /* device: salta */
        if (strncmp(ppath, "[vvar", 5) == 0) continue;
        if (strncmp(ppath, "[vdso", 5) == 0) continue;
        if (strncmp(ppath, "[vsyscall", 9) == 0) continue;
        if (g_nregions >= MAX_REGIONS) break;
        Region *r = &g_regions[g_nregions++];
        r->start = (uint64_t)a;
        r->end   = (uint64_t)b;
        snprintf(r->perms, sizeof(r->perms), "%s", perms);
        char *p = ppath;
        while (*p == ' ' || *p == '\t') p++;
        snprintf(r->path, sizeof(r->path), "%s", p);
    }
    fclose(f);
    return g_nregions;
}

/* ------------------------------ scansione -------------------------------- */

static void do_scan(const uint8_t *needle, size_t len) {
    g_nmatches = 0;
    g_truncated = 0;
    uint8_t *buf = malloc(CHUNK_SIZE);
    if (!buf) return;

    for (int i = 0; i < g_nregions && !g_truncated; i++) {
        Region *r = &g_regions[i];
        uint64_t size = r->end - r->start;
        uint64_t off  = 0;
        while (off < size && !g_truncated) {
            size_t want = (size - off > CHUNK_SIZE) ? CHUNK_SIZE : (size_t)(size - off);
            ssize_t got = pread64(g_memfd, buf, want, (off64_t)(r->start + off));
            if (got <= 0) break;                 /* regione illeggibile: salta */
            if (got >= (ssize_t)len) {
                uint8_t *limit = buf + got - len; /* ultimo start valido */
                for (uint8_t *p = memchr(buf, needle[0], (size_t)(limit - buf) + 1);
                     p != NULL;
                     p = memchr(p + 1, needle[0], (size_t)(limit - p))) {
                    if (memcmp(p, needle, len) == 0) {
                        if (g_nmatches < MAX_MATCHES)
                            g_matches[g_nmatches] = r->start + off + (uint64_t)(p - buf);
                        g_nmatches++;
                        if (g_nmatches >= MAX_MATCHES) { g_truncated = 1; break; }
                    }
                }
            }
            if ((uint64_t)got < want) break;      /* lettura corta: ferma la regione */
            off += (uint64_t)got;
        }
    }
    free(buf);
}

static void do_rescan(const uint8_t *needle, size_t len) {
    size_t w = 0;
    uint8_t tmp[8];
    for (size_t i = 0; i < g_nmatches; i++) {
        if (pread64(g_memfd, tmp, len, (off64_t)g_matches[i]) == (ssize_t)len &&
            memcmp(tmp, needle, len) == 0) {
            g_matches[w++] = g_matches[i];
        }
    }
    g_nmatches = w;
    g_truncated = 0;
}

/* ------------------------------ processi --------------------------------- */

static void list_procs(void) {
    DIR *d = opendir("/proc");
    if (!d) { printf("ERR opendir /proc\n"); return; }
    struct dirent *de;
    while ((de = readdir(d))) {
        if (!isdigit((unsigned char)de->d_name[0])) continue;
        int pid = atoi(de->d_name);
        char comm[128] = {0};
        char cmd[1024] = {0};
        char p[64];

        snprintf(p, sizeof(p), "/proc/%d/comm", pid);
        FILE *f = fopen(p, "r");
        if (f) {
            if (fgets(comm, sizeof(comm), f)) comm[strcspn(comm, "\n")] = 0;
            fclose(f);
        }

        snprintf(p, sizeof(p), "/proc/%d/cmdline", pid);
        int fd = open(p, O_RDONLY);
        if (fd >= 0) {
            ssize_t n = read(fd, cmd, sizeof(cmd) - 1);
            if (n > 0) {
                cmd[n] = 0;
                for (ssize_t i = 0; i < n; i++) if (cmd[i] == 0) cmd[i] = ' ';
                while (n > 0 && cmd[n - 1] == ' ') cmd[--n] = 0;
            } else {
                cmd[0] = 0;
            }
            close(fd);
        }
        if (cmd[0] == 0) continue; /* thread kernel / zombie */
        printf("%d|%s|%s\n", pid, comm, cmd);
    }
    closedir(d);
}

/* ------------------------------ dispatch --------------------------------- */

static void on_term(int sig) {
    (void)sig;
    clear_freezes();
    _exit(0);
}

static void dispatch(char *line) {
    size_t L = strlen(line);
    while (L > 0 && (line[L - 1] == '\n' || line[L - 1] == '\r')) line[--L] = 0;
    char *s = line;
    while (*s == ' ' || *s == '\t') s++;
    if (*s == 0 || *s == '#') return;

    char cmd[32] = {0};
    char a1[256] = {0}, a2[256] = {0}, a3[256] = {0};
    int ntok = sscanf(s, "%31s %255s %255s %255s", cmd, a1, a2, a3);
    if (ntok < 1) return;
    for (char *c = cmd; *c; c++) *c = (char)toupper((unsigned char)*c);

    if (strcmp(cmd, "PING") == 0) {
        printf("OK pong\n");

    } else if (strcmp(cmd, "HELLO") == 0) {
        printf("CharlyEngine daemon v0.4 — core di scansione memoria\n");
        printf("protocollo: PING PROCS ATTACH ALIVE REGIONS SCAN RESCAN COUNT RESULTS\n");
        printf("            READ WRITE FREEZE UNFREEZE RESET RESTORE DETACH QUIT\n");
        printf("tipi valore: b=int8 w=int16 d=int32 q=int64 f=float D=double\n");
        printf("OK ready\n");

    } else if (strcmp(cmd, "PROCS") == 0) {
        list_procs();
        printf("OK end\n");

    } else if (strcmp(cmd, "ALIVE") == 0) {
        /* Il processo collegato esiste ancora? (usato dal watchdog dell'app) */
        if (g_pid < 0) { printf("OK alive=0\n"); return; }
        char ap[64];
        snprintf(ap, sizeof(ap), "/proc/%d/maps", g_pid);
        FILE *af = fopen(ap, "r");
        printf("OK alive=%d\n", af != NULL);
        if (af) fclose(af);

    } else if (strcmp(cmd, "ATTACH") == 0) {
        if (ntok < 2) { printf("ERR uso: ATTACH <pid>\n"); return; }
        int pid = atoi(a1);
        if (pid <= 0) { printf("ERR pid non valido\n"); return; }
        char p[64];
        snprintf(p, sizeof(p), "/proc/%d/mem", pid);
        int fd = open(p, O_RDWR);
        if (fd < 0) {
            printf("ERR impossibile aprire %s: %s\n", p, strerror(errno));
            return;
        }
        if (g_memfd >= 0) close(g_memfd);
        g_memfd = fd;
        g_pid = pid;
        clear_freezes();
        g_nmatches = 0;
        g_truncated = 0;
        if (load_regions() < 0) {
            close(fd);
            g_memfd = -1;
            g_pid = -1;
            printf("ERR maps non leggibili\n");
            return;
        }
        printf("OK attached pid=%d regions=%d\n", pid, g_nregions);

    } else if (strcmp(cmd, "REGIONS") == 0) {
        int maxr = (ntok >= 2) ? atoi(a1) : 40;
        if (maxr <= 0) maxr = 40;
        for (int i = 0; i < g_nregions && i < maxr; i++)
            printf("%016llx-%016llx %s %s\n",
                   (unsigned long long)g_regions[i].start,
                   (unsigned long long)g_regions[i].end,
                   g_regions[i].perms, g_regions[i].path);
        printf("OK regions=%d\n", g_nregions);

    } else if (strcmp(cmd, "SCAN") == 0 || strcmp(cmd, "RESCAN") == 0) {
        if (g_memfd < 0) { printf("ERR nessun processo collegato (ATTACH)\n"); return; }
        if (ntok < 3) { printf("ERR uso: %s <tipo> <valore>\n", cmd); return; }
        char t = (char)tolower((unsigned char)a1[0]);
        uint8_t needle[8];
        size_t len = 0;
        if (pack_value(t, a2, needle, &len) != 0) {
            printf("ERR valore non valido per il tipo '%c'\n", t);
            return;
        }
        g_last_type = t;
        pthread_mutex_lock(&g_lock);
        if (strcmp(cmd, "SCAN") == 0) {
            if (load_regions() < 0) {
                pthread_mutex_unlock(&g_lock);
                printf("ERR maps non leggibili\n");
                return;
            }
            do_scan(needle, len);
        } else {
            do_rescan(needle, len);
        }
        pthread_mutex_unlock(&g_lock);
        if (g_truncated)
            printf("OK found=%zu truncated=1\n", g_nmatches);
        else
            printf("OK found=%zu\n", g_nmatches);

    } else if (strcmp(cmd, "COUNT") == 0) {
        printf("OK count=%zu\n", g_nmatches);

    } else if (strcmp(cmd, "RESULTS") == 0) {
        if (g_memfd < 0) { printf("ERR nessun processo collegato\n"); return; }
        size_t start = (ntok >= 2) ? (size_t)strtoull(a1, NULL, 0) : 0;
        size_t count = (ntok >= 3) ? (size_t)strtoull(a2, NULL, 0) : 32;
        if (count > 256) count = 256;
        char val[64];
        pthread_mutex_lock(&g_lock);
        for (size_t i = start; i < g_nmatches && i < start + count; i++) {
            format_at(g_matches[i], g_last_type, val, sizeof(val));
            printf("%llx|%s\n", (unsigned long long)g_matches[i], val);
        }
        pthread_mutex_unlock(&g_lock);
        printf("OK results=%zu\n", g_nmatches);

    } else if (strcmp(cmd, "READ") == 0) {
        if (g_memfd < 0) { printf("ERR nessun processo collegato\n"); return; }
        if (ntok < 3) { printf("ERR uso: READ <tipo> <indirizzo hex>\n"); return; }
        char t = (char)tolower((unsigned char)a1[0]);
        uint64_t addr = strtoull(a2, NULL, 16);
        char val[64];
        pthread_mutex_lock(&g_lock);
        format_at(addr, t, val, sizeof(val));
        pthread_mutex_unlock(&g_lock);
        printf("%llx|%s\n", (unsigned long long)addr, val);
        printf("OK read\n");

    } else if (strcmp(cmd, "WRITE") == 0) {
        if (g_memfd < 0) { printf("ERR nessun processo collegato\n"); return; }
        if (ntok < 4) { printf("ERR uso: WRITE <tipo> <indirizzo hex> <valore>\n"); return; }
        char t = (char)tolower((unsigned char)a1[0]);
        uint64_t addr = strtoull(a2, NULL, 16);
        uint8_t bytes[8];
        size_t len = 0;
        if (pack_value(t, a3, bytes, &len) != 0) {
            printf("ERR valore non valido\n");
            return;
        }
        pthread_mutex_lock(&g_lock);
        ssize_t w = pwrite64(g_memfd, bytes, len, (off64_t)addr);
        pthread_mutex_unlock(&g_lock);
        if (w != (ssize_t)len) {
            printf("ERR scrittura fallita: %s\n", strerror(errno));
            return;
        }
        char val[64];
        pthread_mutex_lock(&g_lock);
        format_at(addr, t, val, sizeof(val));
        pthread_mutex_unlock(&g_lock);
        printf("OK write addr=%llx value=%s\n", (unsigned long long)addr, val);

    } else if (strcmp(cmd, "FREEZE") == 0) {
        if (g_memfd < 0) { printf("ERR nessun processo collegato\n"); return; }
        if (ntok < 4) { printf("ERR uso: FREEZE <tipo> <indirizzo hex> <valore>\n"); return; }
        char t = (char)tolower((unsigned char)a1[0]);
        uint64_t addr = strtoull(a2, NULL, 16);
        uint8_t bytes[8];
        size_t len = 0;
        if (pack_value(t, a3, bytes, &len) != 0) {
            printf("ERR valore non valido\n");
            return;
        }
        int slot = -1;
        for (int i = 0; i < g_nfreezes; i++)
            if (g_freezes[i].addr == addr) { slot = i; break; }
        if (slot < 0) {
            if (g_nfreezes >= MAX_FREEZES) { printf("ERR troppi freeze\n"); return; }
            slot = g_nfreezes++;
        }
        g_freezes[slot].addr = addr;
        g_freezes[slot].len = len;
        memcpy(g_freezes[slot].bytes, bytes, 8);
        g_freezes[slot].active = 1;
        ensure_freeze_thread();
        printf("OK frozen=%d\n", g_nfreezes);

    } else if (strcmp(cmd, "UNFREEZE") == 0) {
        if (ntok < 2) { printf("ERR uso: UNFREEZE <indirizzo hex>\n"); return; }
        uint64_t addr = strtoull(a1, NULL, 16);
        for (int i = 0; i < g_nfreezes; i++)
            if (g_freezes[i].addr == addr) g_freezes[i].active = 0;
        printf("OK unfrozen\n");

    } else if (strcmp(cmd, "UNFREEZE_ALL") == 0) {
        clear_freezes();
        printf("OK unfrozen_all\n");

    } else if (strcmp(cmd, "RESTORE") == 0) {
        /* Ripristina una lista di indirizzi (sessione salvata dall'app).
         * RESTORE <tipo> <addr hex> <addr hex> ...  — gli indirizzi non più
         * leggibili (gioco riavviato) vengono scartati. */
        if (g_memfd < 0) { printf("ERR nessun processo collegato\n"); return; }
        char t = (char)tolower((unsigned char)a1[0]);
        if (type_size(t) == 0) { printf("ERR tipo non valido\n"); return; }
        g_last_type = t;
        size_t n = 0;
        char *p = strtok(s, " \t");      /* "RESTORE" */
        p = strtok(NULL, " \t");         /* tipo */
        while ((p = strtok(NULL, " \t")) != NULL) {
            uint64_t addr = strtoull(p, NULL, 16);
            if (addr == 0) continue;
            uint8_t tmp[8];
            if (pread64(g_memfd, tmp, type_size(t), (off64_t)addr) == (ssize_t)type_size(t)) {
                if (n < MAX_MATCHES) g_matches[n++] = addr;
            }
        }
        g_nmatches = n;
        g_truncated = 0;
        printf("OK restored=%zu\n", n);

    } else if (strcmp(cmd, "RESET") == 0) {
        g_nmatches = 0;
        g_truncated = 0;
        printf("OK reset\n");

    } else if (strcmp(cmd, "DETACH") == 0) {
        clear_freezes();
        g_nmatches = 0;
        g_truncated = 0;
        if (g_memfd >= 0) close(g_memfd);
        g_memfd = -1;
        g_pid = -1;
        g_nregions = 0;
        printf("OK detached\n");

    } else if (strcmp(cmd, "QUIT") == 0) {
        printf("OK bye\n");
        fflush(stdout);
        clear_freezes();
        if (g_memfd >= 0) close(g_memfd);
        exit(0);

    } else {
        printf("ERR comando sconosciuto: %s (HELP/HELLO per l'elenco)\n", cmd);
    }
}

int main(void) {
    setvbuf(stdout, NULL, _IOLBF, 8192);
    signal(SIGPIPE, SIG_IGN);
    signal(SIGTERM, on_term);
    signal(SIGINT, on_term);

    g_matches = malloc(sizeof(uint64_t) * MAX_MATCHES);
    if (!g_matches) {
        printf("ERR out of memory\n");
        return 1;
    }

    char *line = NULL;
    size_t cap = 0;
    while (getline(&line, &cap, stdin) >= 0) {
        dispatch(line);
        fflush(stdout);
    }
    /* EOF: l'app è morta → esci anche tu */
    clear_freezes();
    free(line);
    free(g_matches);
    return 0;
}

package com.memscan.app.scan

import android.content.Context
import java.io.BufferedReader
import java.io.BufferedWriter
import java.io.File
import java.io.InputStreamReader
import java.io.OutputStreamWriter

/**
 * Gestisce il daemon nativo memscand:
 *  1. copia l'eseguibile (spacciato per libreria) da nativeLibraryDir a /data/local/tmp
 *  2. lo avvia con `su` restando agganciato a stdin/stdout (protocollo a righe)
 *
 * Ogni risposta del daemon = righe dati (opzionali) + una riga finale "OK ..."/"ERR ...".
 */
class MemscanDaemon(private val context: Context) {

    data class Reply(val ok: Boolean, val status: String, val data: List<String>)

    /** Callback opzionale: riceve ogni riga per il terminale a schermo. */
    var onLog: ((String) -> Unit)? = null

    private var process: Process? = null
    private var writer: BufferedWriter? = null
    private var reader: BufferedReader? = null

    val isRunning: Boolean get() = process?.isAlive == true

    private fun log(line: String) {
        onLog?.invoke(line)
    }

    /** null = avvenuto, altrimenti messaggio d'errore. */
    fun start(): String? {
        if (isRunning) return null
        return try {
            val lib = File(context.applicationInfo.nativeLibraryDir, "libmemscand.so")
            if (!lib.exists()) {
                return "libmemscand.so non trovato in ${context.applicationInfo.nativeLibraryDir}"
            }
            log("[su] installo il daemon in /data/local/tmp …")
            val setup = RootShell.run(
                "cp \"${lib.absolutePath}\" /data/local/tmp/memscand && " +
                    "chmod 755 /data/local/tmp/memscand && echo MEMSCAN_OK"
            )
            if (!setup.contains("MEMSCAN_OK")) {
                return "Installazione del daemon fallita (root negato?). su: $setup"
            }

            val p = ProcessBuilder("su", "-c", "/data/local/tmp/memscand").start()
            process = p
            writer = BufferedWriter(OutputStreamWriter(p.outputStream))
            reader = BufferedReader(InputStreamReader(p.inputStream))

            val hello = send("HELLO")
            if (!hello.ok) return "Il daemon non risponde: ${hello.status}"
            hello.data.forEach { log(it) }
            log("[daemon] attivo, in esecuzione come root")
            null
        } catch (e: Exception) {
            "Errore avvio daemon: ${e.message}"
        }
    }

    /** Invia un comando e attende la risposta completa.
     *  quiet=true: non logga nel terminale (usato per il polling di routine). */
    @Synchronized
    fun send(cmd: String, quiet: Boolean = false): Reply {
        val w = writer ?: throw IllegalStateException("daemon non avviato")
        val r = reader ?: throw IllegalStateException("daemon non avviato")
        if (!quiet) log("> $cmd")
        w.write(cmd)
        w.newLine()
        w.flush()

        val data = mutableListOf<String>()
        var status = ""
        while (true) {
            val line = r.readLine() ?: throw IllegalStateException("daemon terminato")
            if (line.startsWith("OK") || line.startsWith("ERR")) {
                status = line
                break
            }
            data.add(line)
        }
        if (!quiet) {
            log(
                if (data.isEmpty()) "< $status"
                else "< $status  (+${data.size} righe)"
            )
        }
        return Reply(status.startsWith("OK"), status, data)
    }

    fun stop() {
        try {
            if (isRunning) send("QUIT")
        } catch (_: Exception) {
        }
        process?.destroy()
        process = null
        writer = null
        reader = null
    }
}

package com.memscan.app.scan

import java.util.concurrent.TimeUnit

/** Mini wrapper per la shell root (`su -c`). */
object RootShell {

    /** Esegue un comando come root e ne restituisce lo stdout (+stderr). */
    fun run(cmd: String, timeoutMs: Long = 20_000): String = try {
        val p = ProcessBuilder("su", "-c", cmd)
            .redirectErrorStream(true)
            .start()
        val out = p.inputStream.bufferedReader().use { it.readText() }
        p.waitFor(timeoutMs, TimeUnit.MILLISECONDS)
        out.trim()
    } catch (e: Exception) {
        "ERR: ${e.message}"
    }

    /** true se `su` esiste, funziona e siamo uid 0. */
    fun isRootAvailable(): Boolean {
        if (whichSu().isEmpty()) return false
        return run("id -u", 8_000).contains("0")
    }

    private fun whichSu(): String {
        val paths = System.getenv("PATH") ?: "/system/bin:/system/xbin:/sbin:/vendor/bin"
        for (dir in paths.split(":")) {
            val f = java.io.File(dir, "su")
            if (f.exists()) return f.absolutePath
        }
        return ""
    }
}

        pushLog("[i] «mantieni dati se il gioco si chiude»: ${if (on) "ON" else "OFF"}")
    }

    /** Rifa da capo: verifica root + avvio daemon + elenco app. */
    fun retry() {
        viewModelScope.launch {
            try {
                daemon.stop()
            } catch (_: Exception) {
            }
            _state.update {
                it.copy(rootOk = null, fatalError = null, log = emptyList(), hint = null)
            }
            bootstrap()
        }
    }

    private suspend fun bootstrap() {
        pushLog("[i] verifico l'accesso root…")
        val root = withContext(Dispatchers.IO) { RootShell.isRootAvailable() }
        _state.update { it.copy(rootOk = root) }
        if (!root) {
            pushLog("[!] nessun root: controlla l'autorizzazione in Magisk/KernelSU")
            return
        }
        pushLog("[+] root OK")
        _state.update { it.copy(hint = "Avvio del daemon root… autorizza CharlyEngine se Magisk chiede") }
        val err = withContext(Dispatchers.IO) { daemon.start() }
        if (err != null) {
            _state.update { it.copy(fatalError = err) }
            pushLog("[!] $err")
            return
        }
        loadApps()
    }

    /* -------------------------- sessioni salvate -------------------------- */

    /** Salva la sessione corrente (indirizzi + congelamenti) per il gioco collegato. */
    private fun saveSessionNow() {
        val st = _state.value
        val target = st.target ?: return
        val matches = st.results.map { SavedMatch(it.address, it.frozen, it.value) }
        SessionStore.save(
            appCtx,
            SavedSession(target.packageName, target.label, st.type.code, matches, System.currentTimeMillis())
        )
        _state.update {
            it.copy(savedCounts = it.savedCounts + (target.packageName to matches.size))
        }
    }

    private fun removeSession() {
        val pkg = _state.value.target?.packageName ?: return
        SessionStore.remove(appCtx, pkg)
        _state.update { it.copy(savedCounts = it.savedCounts - pkg) }
    }

    /** Dopo l'ATTACH: se c'è una sessione salvata su disco per questo gioco la ripristina. */
    private suspend fun maybeRestoreSession(entry: AppEntry) {
        val saved = SessionStore.load(appCtx)[entry.packageName] ?: return
        if (saved.matches.isEmpty()) return
        val savedType = ValueType.entries.firstOrNull { it.code == saved.typeCode }
            ?: ValueType.DWORD
        _state.update { it.copy(type = savedType) }
        restoreRows(saved.matches.map { MatchRow(it.address, it.value, it.frozen) })
        if (_state.value.matchCount > 0) {
            _state.update {
                it.copy(
                    hint = "💾 Sessione ripristinata (${
                        _state.value.matchCount
                    } indirizzi, ${frozen.size} congelati). Riprendi da dove eri, oppure «Reset» per ripartire."
                )
            }
        }
    }

    /** Ripristina un elenco di righe (da disco o dalla memoria durante il watchdog). */
    private suspend fun restoreRows(rows: List<MatchRow>) {
        if (rows.isEmpty()) return
        val typeCode = _state.value.type.code
        val addrArgs = rows.joinToString(" ") { it.address.toString(16) }
        val r = send("RESTORE $typeCode $addrArgs")
        val restored = r?.let {
            Regex("restored=(\\d+)").find(it.status)?.groupValues?.get(1)?.toIntOrNull()
        } ?: 0

        if (r != null && r.ok && restored > 0) {
            for (m in rows.filter { it.frozen }) {
                val fr = send("FREEZE $typeCode ${m.address.toString(16)} ${m.value}", quiet = true)
                if (fr?.ok == true) frozen.add(m.address)
            }
            _state.update { it.copy(matchCount = restored.toLong(), truncated = false) }
            pushLog("[💾] ripristinati $restored/${rows.size} indirizzi (${frozen.size} congelati)")
            loadResultsSuspend()
            startPolling()
        } else {
            _state.update {
                it.copy(
                    matchCount = 0, results = emptyList(),
                    hint = "La sessione salvata non è più valida (il gioco è stato riavviato): fai una nuova scansione"
                )
            }
            pushLog("[!] sessione non valida: rimossa")
            removeSession()
        }
    }

    fun setSearch(s: String) = _state.update { it.copy(search = s) }

    fun setValueInput(v: String) = _state.update { it.copy(valueInput = v, hint = null) }

    fun setType(t: ValueType) {
        if (t == _state.value.type) return
        viewModelScope.launch {
            send("RESET")
            frozen.clear()
            _state.update {
                it.copy(
                    type = t, matchCount = 0, truncated = false,
                    results = emptyList(), valueInput = "",
                    hint = "Tipo cambiato: rifai la scansione"

    /* --------------------------- comando base ---------------------------- */

    private suspend fun send(cmd: String, quiet: Boolean = false): MemscanDaemon.Reply? = mutex.withLock {
        if (!daemon.isRunning) {
            pushLog("[!] daemon non attivo")
            null
        } else {
            withContext(Dispatchers.IO) {
                try {
                    daemon.send(cmd, quiet)
                } catch (e: Exception) {
                    pushLog("[!] errore daemon: ${e.message}")
                    null
                }
            }
        }
    }

    /** pid corrente del package (0 se non in esecuzione), dai processi live. */
    private suspend fun pidOf(packageName: String): Int {
        val reply = send("PROCS", quiet = true) ?: return 0
        val lines = reply.data
        val exact = lines.firstOrNull {
            it.split("|", limit = 3).getOrNull(2)?.trim() == packageName
        } ?: lines.firstOrNull {
            it.split("|", limit = 3).getOrNull(2)?.trim()?.startsWith("$packageName:") == true
        }
        return exact?.split("|")?.firstOrNull()?.trim()?.toIntOrNull() ?: 0
    }

    /* ------------------------------ app list ----------------------------- */

    fun loadApps() {
        viewModelScope.launch {
            _state.update { it.copy(appsLoading = true) }

            val running = mutableMapOf<String, Int>()
            send("PROCS")?.data?.forEach { line ->
                val parts = line.split("|", limit = 3)
                if (parts.size == 3) {
                    val pid = parts[0].toIntOrNull() ?: return@forEach
                    val cmd0 = parts[2].trim().split(" ").firstOrNull() ?: ""
                    if (cmd0.isNotEmpty() && !running.containsKey(cmd0)) running[cmd0] = pid
                }
            }

            val saved = SessionStore.load(appCtx)
            val pm = appCtx.packageManager
            val me = appCtx.packageName
            val apps = withContext(Dispatchers.Default) {
                pm.getInstalledApplications(0).mapNotNull { ai ->
                    if (ai.packageName == me) return@mapNotNull null
                    if (pm.getLaunchIntentForPackage(ai.packageName) == null) return@mapNotNull null
                    val pid = running[ai.packageName]
                        ?: running.entries.firstOrNull {
                            it.key.startsWith(ai.packageName + ":")
                        }?.value ?: 0
                    AppEntry(
                        label = ai.loadLabel(pm).toString(),
                        packageName = ai.packageName,
                        icon = runCatching { ai.loadIcon(pm) }.getOrNull(),
                        pid = pid
                    )
                }.sortedWith(
                    compareByDescending<AppEntry> { it.pid > 0 }
                        .thenByDescending { (saved[it.packageName]?.matches?.size ?: 0) > 0 }
                        .thenBy { it.label.lowercase(Locale.ITALY) }
                )
            }

            val savedCounts = saved.mapValues { it.value.matches.size }
            val nRunning = apps.count { it.pid > 0 }
            _state.update {
                it.copy(apps = apps, appsLoading = false, savedCounts = savedCounts, hint = null)
            }
            pushLog("[i] ${apps.size} app · $nRunning in esecuzione · ${savedCounts.size} sessioni salvate")
        }
    }

    /**
     * Avvia un'app chiusa e la aggancia automaticamente appena il processo parte
     * (controlla ogni 1,5 s per max 30 s).
     */
    fun launchAndAttach(entry: AppEntry) {
        viewModelScope.launch {
            val intent = appCtx.packageManager.getLaunchIntentForPackage(entry.packageName)
            if (intent == null) {
                pushLog("[!] impossibile avviare ${entry.label}")
                return@launch
            }
            appCtx.startActivity(intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK))
            pushLog("[▶] avvio ${entry.label}… attesa del processo")
            _state.update { it.copy(hint = "Avvio ${entry.label}… torno qui appena parte") }

            var waited = 0
            while (waited < 30_000) {
                delay(1500)
                waited += 1500
                val pid = pidOf(entry.packageName)
                if (pid > 0) {
                    pushLog("[+] ${entry.label} è in esecuzione (pid $pid): aggancio!")
                    attach(AppEntry(entry.label, entry.packageName, entry.icon, pid))
                    return@launch
                }
            }
            _state.update {
                it.copy(hint = "${entry.label} non risulta avviato: apri il gioco e premi ⟳")
            }
            pushLog("[!] ${entry.label} non risulta in esecuzione")
        }
    }

    fun openApp(entry: AppEntry) {
        if (entry.pid > 0) {
            attach(entry)
        } else {
            launchAndAttach(entry)
        }
    }

    /* ------------------------------- attach ------------------------------ */

    fun attach(entry: AppEntry) {
        viewModelScope.launch {
            _state.update { it.copy(busy = true) }
            val ok = attachSuspend(entry, entry.pid, fromStore = true, restartWatchdog = true)
            if (ok) saveSessionNow()
            _state.update { it.copy(busy = false) }
        }
    }

    /**
     * Collega un pid. fromStore=true -> ripristina anche la sessione salvata su disco.
     * restartWatchdog=false quando siamo già DENTRO il watchdog (per non cancellarci da soli).
     */
    private suspend fun attachSuspend(
        entry: AppEntry,
        pid: Int,
        fromStore: Boolean,
        restartWatchdog: Boolean
    ): Boolean {
        val reply = send("ATTACH $pid")
        if (reply == null || !reply.ok) {
            pushLog("[!] collegamento fallito: ${reply?.status ?: "daemon non attivo"}")
            loadApps()
            return false
        }
        val regions = Regex("regions=(\\d+)").find(reply.status)
            ?.groupValues?.get(1)?.toIntOrNull() ?: 0
        frozen.clear()
        _state.update {
            it.copy(
                target = AppEntry(entry.label, entry.packageName, entry.icon, pid),
                regions = regions,
                matchCount = 0, truncated = false,
                results = emptyList(), valueInput = "", hint = null,
                watchdog = false
            )
        }
        pushLog("[+] collegato a: ${entry.label} (pid $pid, $regions regioni)")
        if (fromStore) {
            maybeRestoreSession(entry)
        }
        if (restartWatchdog) startWatchdog()
        return true
    }

    fun detach() {
        viewModelScope.launch {
            pollJob?.cancel()
            watchdogJob?.cancel()
            saveSessionNow()   // la sessione resta salvata: ci puoi tornare
            send("DETACH")
            frozen.clear()
            _state.update {
                it.copy(
                    target = null, matchCount = 0, truncated = false,
                    results = emptyList(), regions = 0, valueInput = "",
                    hint = null, watchdog = false
                )
            }
            loadApps()
        }
    }

    /* --------------------- watchdog: il gioco si chiude ------------------- */

    /**
     * Controlla ogni 2 s che il gioco sia ancora vivo. Se muore:
     * con «mantieni dati» ON -> conserva la sessione e attende la riapertura,
     * poi si ricollega da solo e ripristina indirizzi + congelamenti.
     */
    private fun startWatchdog() {
        watchdogJob?.cancel()
        watchdogJob = viewModelScope.launch {
            while (isActive) {
                delay(2000)
                val st = _state.value
                if (st.target == null || st.watchdog || st.busy) continue
                val alive = send("ALIVE", quiet = true)?.status?.contains("alive=1") == true
                if (!alive) {
                    onTargetDied()
                }
            }
        }
    }

    private suspend fun onTargetDied() {
        if (_state.value.watchdog) return   // già in attesa
        pollJob?.cancel()
        val st = _state.value
        val target = st.target ?: return

        if (!st.keepData) {
            send("DETACH", quiet = true)
            frozen.clear()
            _state.update {
                it.copy(
                    target = null, matchCount = 0, truncated = false,
                    results = emptyList(), regions = 0, valueInput = "",
                    hint = null, watchdog = false
                )
            }
            pushLog("[!] ${target.label} si è chiuso: dati azzerati (impostazione «mantieni dati» OFF)")
            loadApps()
            return
        }

        val savedRows = st.results
        _state.update { it.copy(watchdog = true, hint = null) }
        pushLog(
            "[!] ${target.label} si è chiuso: sessione conservata " +
                "(${savedRows.size} indirizzi). Attendo la riapertura…"
        )

        var waited = 0
        while (waited < 1_800_000 && _state.value.target?.packageName == target.packageName) {
            delay(2500)
            waited += 2500
            val pid = pidOf(target.packageName)
            if (pid > 0) {
                delay(1500)   // dai il tempo al gioco di avviarsi
                pushLog("[+] ${target.label} è tornato (pid $pid): ricollego e ripristino…")
                val ok = attachSuspend(target, pid, fromStore = false, restartWatchdog = false)
                if (ok) {
                    restoreRows(savedRows)
                    _state.update {
                        it.copy(
                            hint = "💾 Ricollegato dopo la riapertura: ${
                                it.matchCount
                            }/${savedRows.size} indirizzi ancora validi. " +
                                "Se sono 0, il riavvio ha spostato la memoria: rifai la scansione."
                        )
                    }
                    saveSessionNow()
                } else {
                    _state.update { it.copy(watchdog = false) }
                }
                return
            }
        }
        // attesa scaduta (30 min): torno in modalità normale, il watchdog riparte da solo
        _state.update { it.copy(watchdog = false) }
    }

    /* ------------------------------- scansioni --------------------------- */

    fun newScan() {
        val st = _state.value
        if (st.valueInput.isBlank()) {
            _state.update { it.copy(hint = "Inserisci il valore attuale della valuta") }
            return
        }
        viewModelScope.launch {
            _state.update { it.copy(busy = true, hint = null) }
            val reply = send("SCAN ${st.type.code} ${st.valueInput.trim()}")
            _state.update { it.copy(busy = false) }
            applyScanReply(reply, first = true)
        }
    }

    fun rescan() {
        val st = _state.value
        if (st.matchCount <= 0L) {
            newScan()
            return
        }
        if (st.valueInput.isBlank()) {
            _state.update { it.copy(hint = "Scrivi il NUOVO valore assunto nel gioco dopo il cambio") }
            return
        }
        viewModelScope.launch {
            _state.update { it.copy(busy = true, hint = null) }
            val reply = send("RESCAN ${st.type.code} ${st.valueInput.trim()}")
            _state.update { it.copy(busy = false) }
            applyScanReply(reply, first = false)
        }
    }

    private suspend fun applyScanReply(reply: MemscanDaemon.Reply?, first: Boolean) {
        if (reply == null) return
        pushLog("[${if (first) "SCANSIONE" else "RISCANSIONE"}] ${reply.status}")
        if (!reply.ok) {
            // il gioco è morto mentre eravamo collegati
            if (reply.status.contains("maps non leggibili") ||
                reply.status.contains("impossibile aprire")
            ) {
                onTargetDied()
                return
            }
            _state.update { it.copy(hint = reply.status.removePrefix("ERR ")) }
            return
        }
        val count = Regex("found=(\\d+)").find(reply.status)
            ?.groupValues?.get(1)?.toLongOrNull() ?: 0L
        val truncated = reply.status.contains("truncated=1")
        _state.update { it.copy(matchCount = count, truncated = truncated) }
        when {
            count == 0L -> _state.update {
                it.copy(results = emptyList(), hint = "Nessun risultato: valore sbagliato? Riprova con SCANSIONA")
            }
            count <= 64 -> {
                loadResultsSuspend()
                startPolling()
            }
            else -> _state.update {
                it.copy(
                    results = emptyList(),
                    hint = "$count indirizzi: fai cambiare la valuta nel gioco e poi RISCANSIONA col nuovo valore"
                )
            }
        }
        saveSessionNow()
    }

    fun resetScan() {
        viewModelScope.launch {
            send("RESET")
            frozen.clear()
            removeSession()
            _state.update {
                it.copy(
                    matchCount = 0, truncated = false, results = emptyList(),
                    valueInput = "", hint = "Ricerca azzerata (sessione salvata rimossa)"
                )
            }
        }
    }

    /* ------------------------------- risultati --------------------------- */

    private suspend fun loadResultsSuspend() {
        val count = _state.value.matchCount
        if (count !in 1..64) return
        // polling di routine: quiet=true, nel terminale compaiono solo i cambi [LIVE]
        val reply = send("RESULTS 0 64", quiet = true) ?: return
        if (!reply.ok) return
        val rows = reply.data.mapNotNull { line ->
            val idx = line.indexOf('|')
            if (idx <= 0) return@mapNotNull null
            val addr = line.substring(0, idx).toLongOrNull(16) ?: return@mapNotNull null
            MatchRow(addr, line.substring(idx + 1), frozen.contains(addr))
        }
        // log dei cambiamenti in tempo reale
        val old = _state.value.results
        if (old.isNotEmpty()) {
            val oldMap = old.associate { it.address to it.value }
            rows.forEach { row ->
                val prev = oldMap[row.address]
                if (prev != null && prev != row.value) {
                    pushLog("[LIVE] 0x${row.address.toString(16)}: $prev → ${row.value}")
                }
            }
        }
        _state.update { it.copy(results = rows) }
    }

    fun refreshResults() {
        viewModelScope.launch { loadResultsSuspend() }
    }

    /** Aggiorna i risultati (≤64) ogni ~800 ms: il terminale mostra i cambi live. */
    private fun startPolling() {
        pollJob?.cancel()
        pollJob = viewModelScope.launch {
            while (isActive) {
                delay(800)
                val st = _state.value
                if (!st.busy && !st.watchdog && st.target != null && st.matchCount in 1..64) {
                    loadResultsSuspend()
                }
            }
        }
    }

    /* ------------------------------- iniezione --------------------------- */

    /** Scrive il valore in TUTTI gli indirizzi trovati (copie visualizzate incluse). */
    fun injectAll(rawValue: String) {
        val st = _state.value
        val targets = st.results.filter { it.value != "?" }
        if (rawValue.isBlank() || targets.isEmpty()) return
        viewModelScope.launch {
            _state.update { it.copy(busy = true, hint = null) }
            var ok = 0
            for (row in targets) {
                val reply = send("WRITE ${st.type.code} ${row.address.toString(16)} ${rawValue.trim()}")
                if (reply != null && reply.ok) ok++
            }
            _state.update { it.copy(busy = false) }
            if (ok > 0) {
                pushLog("[💰] INIETTATO $rawValue in $ok/${targets.size} indirizzi")
            } else {
                pushLog("[!] iniezione fallita: valore non valido?")
                _state.update { it.copy(hint = "Iniezione fallita: controlla il valore scritto") }
            }
            loadResultsSuspend()
            saveSessionNow()
        }
    }

    fun writeValue(address: Long, rawValue: String) {
        viewModelScope.launch {
            _state.update { it.copy(busy = true) }
            val reply = send("WRITE ${_state.value.type.code} ${address.toString(16)} ${rawValue.trim()}")
            _state.update { it.copy(busy = false) }
            if (reply != null && reply.ok) {
                pushLog("[💰] INIETTATO ${rawValue.trim()} in 0x${address.toString(16)}")
            } else {
                pushLog("[!] scrittura fallita: ${reply?.status}")
            }
            loadResultsSuspend()
            saveSessionNow()
        }
    }

    /** Congela TUTTI gli indirizzi trovati al loro valore attuale. */
    fun freezeAll() {
        val st = _state.value
        val targets = st.results.filter { it.value != "?" }
        if (targets.isEmpty()) return
        viewModelScope.launch {
            _state.update { it.copy(busy = true) }
            var ok = 0
            for (row in targets) {
                val reply = send(
                    "FREEZE ${st.type.code} ${row.address.toString(16)} ${row.value}",
                    quiet = true
                )
                if (reply?.ok == true) {
                    frozen.add(row.address)
                    ok++
                }
            }
            _state.update { it.copy(busy = false) }
            pushLog("[❄] congelati $ok/${targets.size} indirizzi (valore fisso)")
            loadResultsSuspend()
            saveSessionNow()
        }
    }

    fun toggleFreeze(row: MatchRow) {
        viewModelScope.launch {
            val hexAddr = row.address.toString(16)
            if (row.frozen) {
                val reply = send("UNFREEZE $hexAddr")
                if (reply?.ok == true) {
                    frozen.remove(row.address)
                    pushLog("[❄] sbloccato 0x$hexAddr")
                }
            } else {
                val reply = send("FREEZE ${_state.value.type.code} $hexAddr ${row.value}")
                if (reply?.ok == true) {
                    frozen.add(row.address)
                    pushLog("[❄] congelato 0x$hexAddr = ${row.value}")
                } else {
                    pushLog("[!] freeze fallito: ${reply?.status}")
                }
            }
            loadResultsSuspend()
            saveSessionNow()
        }
    }

    fun unfreezeAll() {
        viewModelScope.launch {
            send("UNFREEZE_ALL")
            frozen.clear()
            pushLog("[❄] tutti gli indirizzi sbloccati")
            loadResultsSuspend()
            saveSessionNow()
        }
    }

    override fun onCleared() {
        saveSessionNow()
        Thread { runCatching { daemon.stop() } }.start()
        super.onCleared()
    }

package com.memscan.app.scan

import android.content.Context
import org.json.JSONArray
import org.json.JSONObject

data class SavedMatch(val address: Long, val frozen: Boolean, val value: String)

data class SavedSession(
    val packageName: String,
    val label: String,
    val typeCode: Char,
    val matches: List<SavedMatch>,
    val timestamp: Long
)

/** Persistenza leggera su SharedPreferences: una sessione per ogni app moddata. */
object SessionStore {
    private const val PREFS = "memscan_sessions"
    private const val KEY_SESSIONS = "sessions"
    private const val KEY_FIRST_RUN = "first_run_done"
    private const val KEY_KEEP_DATA = "keep_data"

    /** Impostazione: conserva la sessione anche se il gioco si chiude (default ON). */
    fun getKeepData(context: Context): Boolean =
        context.getSharedPreferences(PREFS, Context.MODE_PRIVATE)
            .getBoolean(KEY_KEEP_DATA, true)

    fun setKeepData(context: Context, on: Boolean) {
        context.getSharedPreferences(PREFS, Context.MODE_PRIVATE)
            .edit().putBoolean(KEY_KEEP_DATA, on).apply()
    }

    fun save(context: Context, s: SavedSession) {
        val prefs = context.getSharedPreferences(PREFS, Context.MODE_PRIVATE)
        val all = readAll(prefs)
        val matches = JSONArray()
        s.matches.forEach { m ->
            matches.put(
                JSONObject()
                    .put("a", m.address.toString(16))
                    .put("f", m.frozen)
                    .put("v", m.value)
            )
        }
        all.put(
            s.packageName,
            JSONObject()
                .put("label", s.label)
                .put("type", s.typeCode.toString())
                .put("ts", s.timestamp)
                .put("matches", matches)
        )
        prefs.edit().putString(KEY_SESSIONS, all.toString()).apply()
    }

    fun remove(context: Context, pkg: String) {
        val prefs = context.getSharedPreferences(PREFS, Context.MODE_PRIVATE)
        val all = readAll(prefs)
        all.remove(pkg)
        prefs.edit().putString(KEY_SESSIONS, all.toString()).apply()
    }

    fun load(context: Context): Map<String, SavedSession> {
        val prefs = context.getSharedPreferences(PREFS, Context.MODE_PRIVATE)
        val all = readAll(prefs)
        val out = mutableMapOf<String, SavedSession>()
        val keys = all.keys()
        while (keys.hasNext()) {
            val pkg = keys.next() ?: continue
            val o = runCatching { all.getJSONObject(pkg) }.getOrNull() ?: continue
            val matches = mutableListOf<SavedMatch>()
            runCatching {
                val arr = o.getJSONArray("matches")
                for (i in 0 until arr.length()) {
                    val m = arr.getJSONObject(i)
                    val addr = m.optString("a").toLongOrNull(16) ?: continue
                    matches.add(SavedMatch(addr, m.optBoolean("f", false), m.optString("v", "0")))
                }
            }
            out[pkg] = SavedSession(
                packageName = pkg,
                label = runCatching { o.getString("label") }.getOrDefault(pkg),
                typeCode = runCatching { o.getString("type").firstOrNull() }.getOrNull() ?: 'd',
                matches = matches,
                timestamp = runCatching { o.getLong("ts") }.getOrDefault(0L)
            )
        }
        return out
    }

    fun isFirstRun(context: Context): Boolean =
        !context.getSharedPreferences(PREFS, Context.MODE_PRIVATE)
            .getBoolean(KEY_FIRST_RUN, false)

    fun setFirstRunDone(context: Context) {
        context.getSharedPreferences(PREFS, Context.MODE_PRIVATE)
            .edit().putBoolean(KEY_FIRST_RUN, true).apply()
    }

    private fun readAll(prefs: android.content.SharedPreferences): JSONObject =
        runCatching { JSONObject(prefs.getString(KEY_SESSIONS, "{}") ?: "{}") }
            .getOrDefault(JSONObject())
}

/** Converte un Drawable in ImageBitmap per la UI Compose. */
fun Drawable.toBitmapOrNull(): androidx.compose.ui.graphics.ImageBitmap? = runCatching {
    if (this is BitmapDrawable) {
        bitmap.asImageBitmap()
    } else {
        val w = intrinsicWidth.coerceAtLeast(1)
        val h = intrinsicHeight.coerceAtLeast(1)
        val bmp = Bitmap.createBitmap(w, h, Bitmap.Config.ARGB_8888)
        val canvas = Canvas(bmp)
        setBounds(0, 0, canvas.width, canvas.height)
        draw(canvas)
        bmp.asImageBitmap()
    }
}.getOrNull()

                            "Gioco chiuso — dati al sicuro",
                            style = MaterialTheme.typography.labelLarge,
                            fontWeight = FontWeight.Bold,
                            color = MaterialTheme.colorScheme.onTertiaryContainer
                        )
                        Text(
                            "Sessione conservata (${state.results.size} indirizzi). Riapri il gioco quando vuoi: " +
                                "mi ricollego e ripristino tutto da solo.",
                            style = MaterialTheme.typography.bodySmall,
                            color = MaterialTheme.colorScheme.onTertiaryContainer
                        )
                    }
                }
            }
        }

        if (state.busy) {
            Spacer(Modifier.height(6.dp))
            LinearProgressIndicator(
                Modifier
                    .fillMaxWidth()
                    .padding(vertical = 2.dp),
                color = MaterialTheme.colorScheme.primary
            )
        }

        /* valore + tipo */
        Spacer(Modifier.height(10.dp))
        Row(verticalAlignment = Alignment.CenterVertically) {
            OutlinedTextField(
                value = state.valueInput,
                onValueChange = vm::setValueInput,
                modifier = Modifier.weight(1f),
                label = { Text("Valore della valuta (es. 850)") },
                singleLine = true,
                shape = RoundedCornerShape(14.dp)
            )
            Spacer(Modifier.width(8.dp))
            TypeSelector(state.type, vm::setType)
        }

        /* bottoni principali */
        Spacer(Modifier.height(10.dp))
        Row(horizontalArrangement = Arrangement.spacedBy(8.dp)) {
            ActionButton(
                text = if (state.matchCount == 0L) "SCANSIONA" else "NUOVA RICERCA",
                sub = "col valore attuale",
                emoji = "🔎",
                onClick = vm::newScan,
                enabled = !state.busy && !state.watchdog && state.valueInput.isNotBlank(),
                modifier = Modifier.weight(1f)
            )
            ActionButton(
                text = "RISCANSIONA",
                sub = "dopo il cambio nel gioco",
                emoji = "🔄",
                onClick = vm::rescan,
                enabled = !state.busy && !state.watchdog && state.matchCount > 0,
                modifier = Modifier.weight(1f),
                containerColor = MaterialTheme.colorScheme.secondary,
                contentColor = MaterialTheme.colorScheme.onSecondary
            )
        }
        TextButton(onClick = vm::resetScan, enabled = !state.busy) { Text("Reset ricerca", fontSize = 12.sp) }

        /* impostazione: mantieni i dati se il gioco si chiude */
        Row(verticalAlignment = Alignment.CenterVertically) {
            Text(
                "Mantieni i dati se il gioco si chiude",
                fontSize = 11.sp,
                color = MaterialTheme.colorScheme.onSurfaceVariant,
                modifier = Modifier.weight(1f)
            )
            Switch(
                checked = state.keepData,
                onCheckedChange = vm::setKeepData,
                modifier = Modifier.scale(0.75f)
            )
        }

        /* stato */
        Text(
            buildString {
                append("Indirizzi trovati: ")
                append(if (state.matchCount == 0L) "—" else state.matchCount)
                if (state.truncated) append(" (troppi: raffina)")
            },
            fontFamily = FontFamily.Monospace,
            fontWeight = FontWeight.Bold,
            color = if (state.matchCount in 1..64) MaterialTheme.colorScheme.primary
            else MaterialTheme.colorScheme.onSurfaceVariant,
            fontSize = 12.sp
        )
        state.hint?.let {
            Text(it, style = MaterialTheme.typography.bodySmall,
                color = MaterialTheme.colorScheme.primary)
        }

        /* pannello INIETTA */
        if (step == Step.INIETTA) {
            Spacer(Modifier.height(10.dp))
            InjectPanel(vm, state)
        }

        /* risultati */
        if (state.results.isNotEmpty()) {
            Spacer(Modifier.height(10.dp))
            Text(
                "Risultati (valori live) — tocca INIETTA su un indirizzo:",
                style = MaterialTheme.typography.bodySmall
            )
            Spacer(Modifier.height(6.dp))
            LazyColumn(
                Modifier
                    .weight(1f)
                    .fillMaxWidth(),
                verticalArrangement = Arrangement.spacedBy(6.dp)
            ) {
                items(state.results, key = { it.address }) { row ->
                    ResultRow(
                        row = row,
                        onInject = { editing = row },
                        onFreeze = { vm.toggleFreeze(row) }
                    )
                }
            }
        } else {
            Spacer(Modifier.weight(1f))
        }

        /* terminale */
        Spacer(Modifier.height(10.dp))
        Row(verticalAlignment = Alignment.CenterVertically) {
            Box(
                Modifier
                    .size(8.dp)
                    .background(MaterialTheme.colorScheme.primary, CircleShape)
            )
            Spacer(Modifier.width(6.dp))
            Text(
                "TERMINALE — registro live",
                style = MaterialTheme.typography.labelSmall,
                fontWeight = FontWeight.Bold,
                color = MaterialTheme.colorScheme.onSurfaceVariant,
                modifier = Modifier.weight(1f)
            )
            TextButton(onClick = vm::clearLog, contentPadding = PaddingValues(0.dp)) {
                Text("pulisci", fontSize = 11.sp)
            }
        }
        Spacer(Modifier.height(4.dp))
        TerminalBox(state.log, Modifier.weight(0.28f).fillMaxWidth())
    }

    editing?.let { row ->
        EditValueDialog(
            row = row,
            onConfirm = { v ->
                vm.writeValue(row.address, v)
                editing = null
            },
            onDismiss = { editing = null }
        )
    }

    if (showGuide) {
        GuideDialog { showGuide = false }
    }
}

/* ------------------------------ step bar --------------------------------- */

@Composable
private fun StepBar(current: Step) {
    Row(Modifier.fillMaxWidth(), horizontalArrangement = Arrangement.spacedBy(6.dp)) {
        Step.entries.forEach { s ->
            val active = s == current
            val done = s.n < current.n
            Surface(
                shape = RoundedCornerShape(50),
                color = when {
                    active -> MaterialTheme.colorScheme.primary
                    done -> MaterialTheme.colorScheme.secondaryContainer
                    else -> MaterialTheme.colorScheme.surface
                },
                border = if (!active)
                    androidx.compose.foundation.BorderStroke(1.dp, MaterialTheme.colorScheme.outline)
                else null,
                modifier = Modifier.weight(1f)
            ) {
                Row(
                    Modifier.padding(vertical = 7.dp),
                    horizontalArrangement = Arrangement.Center,
                    verticalAlignment = Alignment.CenterVertically
                ) {
                    Text(
                        if (done) "✓" else "${s.n}",
                        fontSize = 11.sp,
                        fontWeight = FontWeight.Bold,
                        color = when {
                            active -> MaterialTheme.colorScheme.onPrimary
                            done -> MaterialTheme.colorScheme.onSecondaryContainer
                            else -> MaterialTheme.colorScheme.onSurfaceVariant
                        }
                    )
                    Spacer(Modifier.width(4.dp))
                    Text(
                        s.title,
                        fontSize = 11.sp,
                        fontWeight = if (active) FontWeight.Bold else FontWeight.Normal,
                        color = when {
                            active -> MaterialTheme.colorScheme.onPrimary
                            done -> MaterialTheme.colorScheme.onSecondaryContainer
                            else -> MaterialTheme.colorScheme.onSurfaceVariant
                        }
                    )
                }
            }
        }
    }
}

@Composable
fun TerminalBox(lines: List<String>, modifier: Modifier = Modifier) {
    val listState = rememberLazyListState()
    LaunchedEffect(lines.size) {
        if (lines.isNotEmpty()) listState.animateScrollToItem(lines.lastIndex)
    }
    Surface(
        color = Color(0xFF05070A),
        shape = RoundedCornerShape(12.dp),
        border = androidx.compose.foundation.BorderStroke(1.dp, MaterialTheme.colorScheme.outline),
        modifier = modifier
    ) {
        SelectionContainer {
            LazyColumn(
                state = listState,
                modifier = Modifier
                    .fillMaxSize()
                    .padding(8.dp),
                verticalArrangement = Arrangement.spacedBy(2.dp)
            ) {
                items(lines.size) { i ->
                    Text(
                        lines[i],
                        fontFamily = FontFamily.Monospace,
                        fontSize = 11.sp,
                        color = Color(0xFF39D353)
                    )
                }
            }
        }
    }
}

#!/usr/bin/env python3
"""Test end-to-end del daemon memscand:
scansione -> cambio valore nel bersaglio -> rescan -> scrittura -> freeze."""
import subprocess
import sys
import time

MEMSCAN = "./memscand"
TARGET = "./test_target"


class Daemon:
    def __init__(self):
        self.p = subprocess.Popen(
            [MEMSCAN], stdin=subprocess.PIPE, stdout=subprocess.PIPE,
            text=True, bufsize=1)

    def cmd(self, line):
        self.p.stdin.write(line + "\n")
        self.p.stdin.flush()
        data = []
        while True:
            l = self.p.stdout.readline()
            if not l:
                raise RuntimeError("daemon morto")
            l = l.rstrip("\n")
            if l.startswith("OK") or l.startswith("ERR"):
                return l, data
            data.append(l)


fails = []


def check(name, cond, info=""):
    print(("PASS  " if cond else "FAIL  ") + name + ("" if cond else "  -> " + str(info)))
    if not cond:
        fails.append(name)


t = subprocess.Popen([TARGET], stdin=subprocess.PIPE, stdout=subprocess.PIPE,
                     text=True, bufsize=1)
pid_line = t.stdout.readline().strip()
assert pid_line.startswith("PID"), pid_line
tpid = int(pid_line.split()[1])
print("bersaglio pid:", tpid)

d = Daemon()

# --- base ---
st, _ = d.cmd("PING");                                   check("PING", st.startswith("OK pong"), st)
st, _ = d.cmd("PROCS");                                  check("PROCS vede il bersaglio", any(l.startswith(f"{tpid}|") for l in _), st)
st, _ = d.cmd(f"ATTACH {tpid}");                         check("ATTACH", st.startswith("OK attached"), st)
st, _ = d.cmd("ALIVE");                                  check("ALIVE (processo vivo)", st.startswith("OK alive=1"), st)
st, _ = d.cmd("SCAN d 999999999");                       check("SCAN valore assente = 0", st == "OK found=0", st)

# --- flusso monete (DWORD) ---
st, _ = d.cmd("SCAN d 13371337")
found = int(st.split("found=")[1].split()[0])
check("SCAN trova il valore", st.startswith("OK") and found >= 1, st)

t.stdin.write("c\n"); t.stdin.flush()                    # il gioco cambia la valuta
print("bersaglio:", t.stdout.readline().strip())

st, _ = d.cmd("RESCAN d 424242")
found = int(st.split("found=")[1].split()[0])
check("RESCAN dopo il cambio", st.startswith("OK") and found >= 1, st)

st, res = d.cmd("RESULTS 0 64")
check("RESULTS mostra 424242", st.startswith("OK") and any(l.endswith("|424242") for l in res), (st, res))

addrs = [int(l.split("|")[0], 16) for l in res]
for a in addrs:
    st, _2 = d.cmd(f"WRITE d {a:x} 7777777")
    check(f"WRITE 0x{a:x}", st.startswith("OK write"), st)

t.stdin.write("p\n"); t.stdin.flush()
coins = t.stdout.readline().strip()
check("il bersaglio legge 7777777", coins == "COINS 7777777", coins)

# --- freeze: il gioco prova a cambiare ma il valore resta ---
for a in addrs:
    st, _3 = d.cmd(f"FREEZE d {a:x} 7777777")
    check(f"FREEZE 0x{a:x}", st.startswith("OK frozen"), st)

t.stdin.write("c\n"); t.stdin.flush()
print("bersaglio:", t.stdout.readline().strip())
time.sleep(1.0)                                          # il thread freeze riscrive ogni 250 ms
t.stdin.write("p\n"); t.stdin.flush()
coins = t.stdout.readline().strip()
check("FREEZE mantiene il valore", coins == "COINS 7777777", coins)

st, _ = d.cmd(f"UNFREEZE {addrs[0]:x}");                 check("UNFREEZE", st.startswith("OK"), st)
st, _ = d.cmd("UNFREEZE_ALL");                           check("UNFREEZE_ALL", st.startswith("OK"), st)

# --- flusso float (vita) ---
st, _ = d.cmd("SCAN f 12.5")
check("SCAN float", st.startswith("OK") and int(st.split("found=")[1].split()[0]) >= 1, st)
t.stdin.write("h\n"); t.stdin.flush()
print("bersaglio:", t.stdout.readline().strip())
st, _ = d.cmd("RESCAN f 99.25")
check("RESCAN float", st.startswith("OK") and int(st.split("found=")[1].split()[0]) >= 1, st)
st, res = d.cmd("RESULTS 0 64")
for l in res:
    a = int(l.split("|")[0], 16)
    st, _4 = d.cmd(f"WRITE f {a:x} 3.5")
    check(f"WRITE float 0x{a:x}", st.startswith("OK write"), st)
t.stdin.write("r\n"); t.stdin.flush()
hp = t.stdout.readline().strip()
check("il bersaglio legge HP 3.50", hp == "HP 3.50", hp)

# --- RESTORE (sessione salvata) ---
st, _ = d.cmd(f"RESTORE d {addrs[0]:x}")

```c
/* Bersaglio finto per i test: "monete" (int) e "vita" (float) sullo heap. */
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

int main(void) {
    int   *coins = malloc(sizeof(int));
    float *hp    = malloc(sizeof(float));
    *coins = 13371337;
    *hp    = 12.5f;

    printf("PID %d\n", (int)getpid());
    fflush(stdout);

    char buf[64];
    while (fgets(buf, sizeof buf, stdin)) {
        if      (buf[0] == 'c') { *coins = 424242;   printf("CHANGED\n"); }
        else if (buf[0] == 'p') {                    printf("COINS %d\n",  *coins); }
        else if (buf[0] == 'h') { *hp = 99.25f;      printf("HPCHANGED\n"); }
        else if (buf[0] == 'r') {                    printf("HP %.2f\n",   *hp); }
        else if (buf[0] == 'q') break;
        else printf("?\n");
        fflush(stdout);
    }
    return 0;
}
