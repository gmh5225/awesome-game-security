# Mac 游戏库可玩性顾问｜Mac Game Library Advisor

Mac 上想玩 Windows 游戏，先别急着装兼容工具，先看这份清单。

Steam 库躺着一堆 Windows 游戏，Mac 用户常见的做法是先装个 Whisky 再一个个试，试到第四个发现卡在反作弊上，前面折腾的时间全白费。这个 skill 反过来做：先把库过一遍，哪些原生能跑、哪些靠兼容层能跑且跑得动、哪些根本别想，一次说清楚，再决定要不要动手。

Your Steam library is full of Windows games and you're on a Mac. The usual move is to install a compatibility layer and start guessing game by game — until one hits kernel-level anti-cheat and the whole afternoon is gone. This skill goes the other way around: sweep the library first, sort every title into native / runs well under a compatibility layer / not viable / not enough data, then decide whether it's worth setting anything up.

## 能力范围 / Capabilities

- **可玩性四分类**：Mac 原生、无原生但兼容效果好、兼容效果差或不可行、资料不足（标注"需实机验证"）。原生和需要兼容的分开列，不混在一张表里
- **运行效果分级**：流畅 / 基本可玩 / 勉强能跑 / 不可行。判断依据是玩家在具体机型上的实际帧率和反馈，不是"安装难不难"
- **Mod 可用性**：可用 / 部分可用 / 不可用。看的是 BepInEx、r2modman、创意工坊这些框架在兼容层下能不能跑起来，DLL 注入和 Script Extender 这类通常要单独确认
- **反作弊与启动器风险**：Easy Anti-Cheat、BattlEye、Vanguard、Ricochet 是否有 Mac 豁免；Rockstar Launcher、Ubisoft Connect、EA App 这类第三方启动器会不会拖后腿
- **相似游戏推荐**：按游玩时长和最近游玩反推偏好（不是按拥有数量），只推库里没有的、特别好评以上的、Mac 上跑得动的，并说明具体像你库里哪一款
- **安装配置**：确认之后直接协助配置兼容层（CrossOver / Whisky / GPTK）、装 Mod、处理存档路径差异

- **Four-way playability sort**: native macOS, no native build but runs well, poor or not viable, insufficient data (flagged as "needs a real-hardware test"). Native and compatibility-dependent titles never share a table
- **Performance grading**: smooth / playable / barely runs / not viable — based on reported framerates on specific Mac models, not on how hard the setup is
- **Mod availability**: works / partially works / doesn't. Whether BepInEx, r2modman or Workshop frameworks survive the compatibility layer; DLL injection and Script Extenders usually need a separate look
- **Anti-cheat and launcher risk**: whether Easy Anti-Cheat, BattlEye, Vanguard or Ricochet has a Mac exemption, and whether a Rockstar / Ubisoft / EA launcher gets in the way
- **Similar game picks**: preferences inferred from playtime and recent activity rather than library size, recommending only titles you don't own, rated Very Positive or above, and actually playable on a Mac
- **Setup help**: once you say go, it walks through compatibility-layer setup (CrossOver / Whisky / GPTK), mod installs, and the save-path differences

## 两条硬规则 / Two Hard Rules

**每次都现搜，不吃老本。** Mac 游戏兼容性变得比攻略还快，半年前的结论经常已经过期。每次检查都重新搜 Steam 商店页、AppleGamingWiki、Whisky 社区、PCGamingWiki、ProtonDB，以及 GitHub、Reddit、B 站、YouTube 上的近期实测，不依赖任何内置名单。

**免费优先，现成的优先。** 还在更新的免费兼容层（Bridgeplay、Whisky 社区分支等）、GPTK、串流、本机已装的 CrossOver 都是默认选项；推荐前先看工具最近一次发版，Whisky 原版 2025-04 已归档停更，不作首选。Parallels 这类付费方案，你不问就不提。

**Always search fresh, never from memory.** Mac compatibility rots faster than a walkthrough. Every check re-searches the Steam store page, AppleGamingWiki, the Whisky community, PCGamingWiki, ProtonDB, plus recent hands-on reports from GitHub, Reddit, Bilibili and YouTube. There is no built-in list of "known good" games.

**Free first, and use what's already installed.** Actively maintained free compatibility layers (Bridgeplay, the Whisky community fork, etc.), GPTK, game streaming and a locally installed CrossOver are all default options. Each tool's latest release is checked before it gets recommended; the original Whisky was archived in April 2025 and is no longer a first pick. Paid tools like Parallels come up only if you ask about them.

# Mac Game Library Advisor

## 目的

帮用户做三件事：

1. 检查游戏库在 Mac 上的可玩性，区分原生与需要兼容方案的游戏
2. 对需要兼容方案的游戏，评估实际运行效果和 Mod 可用性
3. 根据游戏库、游玩时长和好评率，推荐相似的优质游戏

## 核心原则

- Mac 游戏兼容性变化快，每次都搜索最新资料，不凭旧知识下结论。
- Mac 原生游戏和需要兼容方案的游戏必须分开列，不混在一起。
- 兼容方案按下方「兼容方案」一节选：免费优先、本机已装的优先，推荐前先看工具最近一次发版。
- 下载、安装、购买或改系统设置前先问用户；用户确认后可以直接动手配置。

## 用户输入

用户可能提供：Steam 游戏名列表、AppID、商店/库链接、截图、本地库缓存、游玩时长、偏好类型（肉鸽、策略、RPG、3A、多人联机等），或自然语言描述如"帮我看看 Mac 上哪些能玩"。

如果需要登录 Steam，让用户在自己的浏览器中操作。不要求用户发送密码、验证码、Cookie 或令牌。

## 工作流

### 1. 快速确认意图

不要一上来问一堆问题。先根据用户输入开始工作，缺什么再问。

核心只确认：用户要什么（只查可玩性 / 也要推荐新游戏 / 也要帮忙安装配置）。

### 2. 收集游戏库信息

尽量获取：游戏名、AppID、游玩时长、Steam 平台支持标志、评价量和好评率、类型标签。

如果无法直接读取，提示用户可以提供：公开库链接、截图、导出列表、手动贴游戏名。

### 3. 分类检查

对每个游戏，归入以下四类之一：

**A. Mac 原生支持**
Steam 显示苹果标志或官方提供 macOS 版本。简单列出即可，用户自己能看到。

**B. 无原生，但兼容效果好**
通过免费兼容层、GPTK 等方案可运行。重点标注运行效果（流畅 / 基本可玩 / 勉强能跑）和 Mod 是否可用。

**C. 无原生，兼容效果差或不可行**
因反作弊、严重兼容问题、图形 API 不支持等原因，目前在 Mac 上体验很差或无法运行。标注原因和替代建议（如串流）。

**D. 资料不足**
无可靠资料或资料矛盾，标注"需实机验证"。

### 4. 推荐新游戏（如用户需要）

见下方"相似游戏推荐"章节。

### 5. 安装配置（如用户需要）

用户确认要安装后，直接协助完成兼容层/GPTK 的配置、Mod 的安装等操作。

## 兼容资料搜索

每次都应搜索最新资料。优先来源：

1. **Steam 商店页** — 确认平台支持、AppID、评价、体积、反作弊/启动器线索
2. **AppleGamingWiki** — 兼容记录和运行效果
3. **免费兼容层的社区与兼容列表**（如 Bridgeplay 兼容列表、Whisky 社区分支）— 免费方案的兼容情况
4. **PCGamingWiki** — 启动器、反作弊、Mod、存档路径、图形 API
5. **ProtonDB** — 间接参考（Linux 可运行不等于 Mac 可运行，但能提示反作弊和图形 API 信息）
6. **macgamers.org** — CrossOver 实测报告（机型、帧率、安装方式）
7. **GitHub / Reddit / Bilibili / YouTube** — 近期玩家实测，尤其关注具体机型上的实际帧率和体验

## 兼容方案

免费优先，本机已装的优先。推荐某个工具前，先看它最近一次发版（GitHub Releases），停更的不作首选：

| 方案 | 说明 |
|---|---|
| 免费 Wine 前端 | 截至 2026-11 仍在更新的：Bridgeplay（让 Windows 游戏直接出现在 Mac 版 Steam 里，需 Apple Silicon + macOS 26+）、Whisky 社区分支 frankea/Whisky（macOS 15+，用 `brew install --cask frankea/whisky/whisky` 安装，默认的 `whisky` cask 仍是原版）、Sikarugir（Wineskin 后继，把单个游戏封装成 App）。Whisky 原版 2025-04 已归档停更，不作首选 |
| GPTK (Game Porting Toolkit) | Apple 官方底层翻译层，需手动配置 |
| PlayCover | 仅限 iOS/iPadOS 游戏，不用于 Steam Windows 游戏 |
| 串流 | 用户有 Windows PC 时可用 Steam Remote Play 等，适合反作弊网游 |
| NW.js 原生 | 见下方「NW.js 游戏专用路线」 |

CrossOver 是付费方案，本机已装有就直接用（即使显示"试用版"），复用现成工具成本最低；本机没装的 CrossOver 和 Parallels 一样，仅在用户主动询问时介绍。注意：带 Steamworks（steam_api64.dll）的 Windows 游戏需在兼容层内运行已登录的 Steam 客户端；家庭共享游戏同时只能一人启动（Shared library locked = 所有者占用，等空闲即可）。

### NW.js 游戏专用路线（RPG Maker MV/MZ 等）

判断标志：游戏目录有 `www` 文件夹 + `package.json`。这类游戏是网页应用打包成 exe，用 macOS 版 NW.js 直接运行 `www` 目录，不需要 Wine 系方案。

- 必须用 arm64 原生版 NW.js（0.82+）；Intel 旧版走 Rosetta 会约一半概率开机段错误闪退
- arm64 新版要求 `package.json` 的 `name` 非空，空字符串只会显示欢迎页
- 存档在 `www/save/`，可直接改 JSON 做数值/解锁修改

## 兼容效果评估

重点不是"安装难不难"（AI 可以协助完成配置），而是最终运行效果：

- **流畅**：运行稳定，体验接近原生
- **基本可玩**：能玩但有小问题（偶尔卡顿、部分功能缺失）
- **勉强能跑**：可以启动但体验明显受损
- **不可行**：无法运行或体验太差没有意义

搜索兼容资料时，留意玩家在具体机型上的实际帧率和体验反馈，据此判断效果等级。

## 风险因素

### 反作弊

Easy Anti-Cheat、BattlEye、Vanguard、Ricochet 等内核级反作弊通常阻断兼容层。搜索时确认是否有 Mac/Proton 豁免。

### 第三方启动器

Rockstar Launcher、Ubisoft Connect、EA App 等额外启动器会影响兼容，需标注。

### Mod 可用性

关注的是 Mod 在兼容层下能不能用，而不是安装步骤复杂不复杂（AI 可以协助配置）。

评估结果分三档：
- **可用**：Mod 框架（BepInEx、r2modman、创意工坊等）在兼容层下正常工作
- **部分可用**：基础 Mod 可以，但某些类型（DLL 注入、Script Extender 等）不行
- **不可用**：Mod 框架在兼容层下无法运行，或游戏反作弊阻止 Mod

### 手柄

如果用户提到手柄或游戏主要靠手柄操作，搜索兼容层下的手柄支持情况。

### 存档迁移

如果用户提到从 Windows 迁移存档，查 Steam Cloud 支持情况和 PCGamingWiki 存档路径。兼容层内的存档位置与 Windows 不同，需说明。

Steam 库中 language=schinese 的 depot 可用控制台 `download_depot <appid> <depotid>` 单独下载，用于获取官方中文素材或留作原始备份。

## 相似游戏推荐

### 建立用户偏好

根据游戏库分析，优先看游玩时长和最近游玩（不是拥有数量）：

- 高时长游戏的共同类型和机制
- 单人 vs 多人偏好
- 反复出现的标签（肉鸽、建造、策略、开放世界等）

### 推荐筛选条件

1. 用户尚未拥有
2. Steam 好评率高（特别好评以上）
3. 与用户高时长游戏有具体相似点
4. Mac 原生或兼容效果好
5. 标注当前价格和折扣信息

### 推荐输出要求

- 推荐理由必须具体，说明与用户库中哪些游戏相似、为什么
- 不要只写"类型相似"

## 输出格式

默认中文。

### 1. 摘要

检查了多少游戏、多少 Mac 原生、多少兼容效果好、多少不可行、最推荐先玩哪几个。

### 2. Mac 原生游戏

简单列出游戏名即可。

### 3. 可通过兼容方案运行的游戏

| 游戏名 | 兼容方案 | 运行效果 | Mod 可用性 | 备注 |
|---|---|---|---|---|

### 4. 兼容效果差或不可行

| 游戏名 | 原因 | 替代建议 |
|---|---|---|

### 5. 相似游戏推荐（如需要）

| 推荐游戏 | 推荐理由 | 相似于你的 | Mac 可玩方式 | 价格 |
|---|---|---|---|---|
