`README.md`:

```md
# NZeyMod Launcher

> Launcher untuk ROM NZeyMod (Virtual Master Android 11, identitas Pixel 5).
> Memilih ROM utuh dari penyimpanan, memverifikasi SHA-256, menyiapkan
> impor ke NZey Master, lalu meluncurkan NZey Master — tanpa Virtual Master
> premium. Menggabungkan part ROM, mengacak identitas, mengatur profil
> Magisk, dan mengganti keybox tetap tersedia.

**Status: Dalam Tahap Pengembangan — Beta Tester**

Proyek ini masih dalam tahap pengembangan. Fitur, tampilan, dan performa
dapat berubah. Laporan bug dan hasil pengujian sangat membantu pengembangan
selanjutnya.

## Penting: Launcher ini BUKAN mesin virtual

NZeyMod Launcher **bukan** pengganti Virtual Master dan **bukan** emulator
Android di dalam HP. Menjalankan Android 11 di dalam HP membutuhkan
hypervisor / emulator, dan itu tidak dapat dibangun menjadi satu APK
dalam sekali jalan. Mesin yang menjalankan ROM adalah **NZey Master**
(Virtual Master 3.2.68 remake, VIP sudah di-patch).

Yang dilakukan Launcher:

1. **Jalankan ROM (ROM utuh) — fitur utama v2** — memilih berkas ROM utuh
   (sekitar 405 MB) dari **folder mana pun di penyimpanan** melalui
   file picker. Nama berkas dan folder sumber bebas — verifikasi
   berdasarkan isi berkas (SHA-256), bukan nama berkas.
   SHA-256 dan membandingkannya dengan hash resmi
   `1d8e0031a1076b4de7192274fb156a7ab88c97f1eb3b4bf3be98adf2e65c364c`.
   Bila hash tidak cocok, impor ditolak: kemungkinan berkas corrupt,
   bukan ROM NZeyMod utuh, atau masih berupa bagian terpisah.
   Bila lolos, Launcher menyalin berkas ke folder `NZeyMod/` dan
   menampilkan langkah impor, lalu meluncurkan NZey Master.
2. **Impor di NZey Master** — buka NZey Master, tap tombol **+**, tap
   titik tiga, pilih **Import Local ROM**, pilih berkas ROM dari folder
   `NZeyMod/`, tunggu instalasi selesai, lalu jalankan VM.
3. **Gabung ROM (opsional)** — menggabungkan 5 part ROM (masing-masing
   ≤ 90 MB, total ± 405 MB) menjadi satu file utuh. Hanya diperlukan bila
   yang dimiliki masih berupa bagian terpisah, bukan ROM utuh.
4. **Acak identitas** — membuat identitas perangkat baru (Pixel 5 /
   redfin) dan menyimpan / memulihkan profil.
5. **Profil Magisk** — mengatur modul Magisk ON / OFF per profil
   (Zygisk Next, Play Integrity Fork, Shamiko, LSPosed, Tricky Store).
6. **Ganti keybox** — mengganti keybox dan memeriksa masa berlakunya.
7. **Buka NZey Master** — meluncurkan paket baru `com.kizakixd.nzeymaster`
   (hasil repackage v2.1-beta, dapat terpasang berdampingan dengan
   Virtual Master lama tanpa uninstall). Bila paket baru belum terpasang,
   Launcher mencoba paket lama `com.clone.android.dual.space` sebagai
   fallback. Bila keduanya belum terpasang, Launcher mengarahkan ke
   `NZeyMaster-nzey.apk` hasil repackage (± 139 MB, SHA-256
   `224083a8cd2920f67d9c8a67a9f6746afa62820a218d9cb5f7174760a46bb55c`).
   APK paket lama (± 145 MB, SHA-256
   `2d70516e1f7bd85ca105341b8bd13760fe7484d6b1983e0446a436253d90c602`)
   hanya dipakai sebagai fallback dan tetap memerlukan uninstall
   Virtual Master lama terlebih dahulu, karena tanda tangannya berbeda.

NZeyMod Launcher adalah aplikasi pendamping untuk ROM NZeyMod dari
repositori `KiZakiXD/nzeymod-rom` (repositori privat). ROM ini hanya
dapat dijalankan oleh mesin Virtual Master / NZey Master, bukan oleh
QEMU, Vectras, DroidVM, atau VineOS — format ROM-nya khusus Virtual
Master.

## Catatan Penting

- Keybox yang ada di repositori saat ini hanya ECDSA dan **kedaluwarsa
  28 November 2026**. Keybox pengganti perlu disiapkan sebelum tanggal
  tersebut, jika tidak Play Integrity akan bermasalah.
- Play Integrity STRONG tidak dapat dijamin di virtual machine mana pun.
  Hal ini sudah ditulis di README repositori ROM.
- Modul Magisk dan keybox **tidak ada** di dalam repositori, hanya
  daftar dan hash-nya di `docs/modules-report.md`. Launcher meminta file
  tersebut diimpor, bukan menganggap file tersebut sudah ada.
- Dua ketidakcocokan di repositori sudah diperbaiki di Launcher ini,
  lihat `docs/fixes.md`.

# NZeyMod Launcher — Build Manual

Aplikasi Android native (Java saja, tanpa Gradle, tanpa dependensi eksternal).
Paket: `com.kizakixd.nzeymodmanager`, label NZeyMod Launcher, minSdk 26,
targetSdk 34, versionCode 3, versionName 2.1-beta. Launcher v2.1-beta meluncurkan NZey Master paket baru com.kizakixd.nzeymaster (fallback paket lama).

## Prasyarat

- JDK 17 di `$HOME/opt/jdk-17*` (atau set `JAVA_HOME`)
- Android SDK di `$HOME/Android/sdk` (atau set `ANDROID_HOME`)
  - build-tools 34.0.0 (`aapt2`, `d8`, `zipalign`, `apksigner`)
  - platform `android-34` (`android.jar`)

## Build

```bash
cd ~/workspace/nzeymod-manager/android
chmod +x build-manual.sh
./build-manual.sh
```

Hasil: `app/build/manual/app-debug.apk`

## Alur pipeline

1. `aapt2 compile` — kompilasi resource (`res/`)
2. `aapt2 link` — gabung APK + hasilkan `R.java`
3. `javac` — kompilasi `MainActivity.java` + `R.java` terhadap `android.jar`
4. `d8` — ubah `.class` menjadi `classes.dex`
5. Tambah `classes.dex` ke APK, lalu `zipalign`
6. `apksigner` — tanda tangani dengan keystore debug, lalu verifikasi

## Catatan

- Tidak ada Gradle dan tidak ada Kotlin; seluruh sumber hanya memakai
  API `android.*` dan `java.*` yang tersedia di API 34.
- Karena tidak ada dependensi androidx, hasil Activity memakai
  `onActivityResult` / `startActivityForResult` (bukan
  `registerForActivityResult`, yang berasal dari androidx).
- Identitas dan profil disimpan di direktori file eksternal aplikasi,
  `Android/data/com.kizakixd.nzeymodmanager/files/NZeyMod/`.
- Aplikasi ini BUKAN mesin virtual; aplikasi ini hanya menyiapkan dan
  mengimpor ROM, lalu meluncurkan NZey Master. ROM berjalan di dalam
  NZey Master.

    /** Menghasilkan 16 karakter hex (8 byte acak) dengan SecureRandom. */
    private String randomHex(int bytes) {
        byte[] data = new byte[bytes];
        random.nextBytes(data);
        StringBuilder sb = new StringBuilder(bytes * 2);
        for (byte b : data) {
            sb.append(String.format(Locale.US, "%02x", b & 0xff));
        }
        return sb.toString();
    }

    /**
     * IMEI 15 digit: TAC (8 digit) + 6 digit acak + 1 digit pemeriksa Luhn.
     * Digit pemeriksa dihitung dengan menambahkan 0 sementara, lalu
     * menerapkan jumlah Luhn pada 15 digit tersebut.
     */
    private String generateImei() {
        String tac = IMEI_TACS[random.nextInt(IMEI_TACS.length)];
        StringBuilder base = new StringBuilder(tac);
        for (int i = 0; i < 6; i++) {
            base.append(random.nextInt(10));
        }
        int check = luhnCheckDigit(base.toString());
        return base.toString() + check;
    }

    private int luhnCheckDigit(String fourteenDigits) {
        String withZero = fourteenDigits + "0";
        int sum = 0;
        boolean doubleDigit = false;
        for (int i = withZero.length() - 1; i >= 0; i--) {
            int digit = withZero.charAt(i) - '0';
            if (doubleDigit) {
                digit *= 2;
                if (digit > 9) {
                    digit -= 9;
                }
            }
            sum += digit;
            doubleDigit = !doubleDigit;
        }
        return (10 - (sum % 10)) % 10;
    }

    /** Memeriksa apakah sebuah IMEI lengkap 15 digit lolos Luhn. */
    private static boolean isValidImei(String imei) {
        if (imei == null || imei.length() != 15) {
            return false;
        }
        int sum = 0;
        boolean doubleDigit = false;
        for (int i = imei.length() - 1; i >= 0; i--) {
            char c = imei.charAt(i);
            if (c < '0' || c > '9') {
                return false;
            }
            int digit = c - '0';
            if (doubleDigit) {
                digit *= 2;
                if (digit > 9) {
                    digit -= 9;
                }
            }
            sum += digit;
            doubleDigit = !doubleDigit;
        }
        return sum % 10 == 0;
    }

    private void refreshProfileList() {
        profileNames = new ArrayList<>();
        File dir = getProfilesDir();
        if (dir != null) {
            File[] files = dir.listFiles();
            if (files != null) {
                Arrays.sort(files, new Comparator<File>() {
                    @Override
                    public int compare(File a, File b) {
                        return a.getName().compareToIgnoreCase(b.getName());
                    }
                });
                for (File f : files) {
                    if (f.isFile() && f.getName().toLowerCase(Locale.US).endsWith(".json")) {
                        String name = f.getName();
                        profileNames.add(name.substring(0, name.length() - 5));
                    }
                }
            }
        }
        ArrayAdapter<String> adapter = new ArrayAdapter<>(
                this, android.R.layout.simple_spinner_item, profileNames);
        adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item);
        spinnerProfiles.setAdapter(adapter);
        if (profileNames.isEmpty()) {
            tvProfiles.setText(getString(R.string.no_profiles));
        } else {
            StringBuilder sb = new StringBuilder("Profil tersimpan:\n");
            for (String name : profileNames) {
                sb.append("• ").append(name).append("\n");
            }
            tvProfiles.setText(sb.toString().trim());
        }
    }

    private void verifyWholeRom() {
        if (wholeRomUri == null) {
            toast("Pilih ROM utuh terlebih dahulu");
            tvWholeRomResult.setText("GAGAL — tidak ada berkas yang dipilih.");
            return;
        }
        progressBarWholeRom.setVisibility(View.VISIBLE);
        progressBarWholeRom.setProgress(0);
        tvWholeRomProgress.setText("Menghitung SHA-256…");
        tvWholeRomResult.setText("");
        final Uri uri = wholeRomUri;
        final long total = wholeRomSize;
        final Context context = this;
        new Thread(new Runnable() {
            @Override
            public void run() {
                try {
                    MessageDigest digest = MessageDigest.getInstance("SHA-256");
                    long readTotal = 0;
                    InputStream in = null;
                    try {
                        in = context.getContentResolver().openInputStream(uri);
                        if (in == null) {
                            throw new IOException("Tidak dapat membuka berkas ROM");
                        }
                        byte[] buffer = new byte[64 * 1024];
                        int read;
                        while ((read = in.read(buffer)) != -1) {
                            digest.update(buffer, 0, read);
                            readTotal += read;
                            final int percent = total > 0
                                    ? (int) (readTotal * 100 / total) : 0;
                            final long done = readTotal;
                            runOnUiThread(new Runnable() {
                                @Override
                                public void run() {
                                    progressBarWholeRom.setProgress(percent);
                                    tvWholeRomProgress.setText("Menghitung SHA-256… "
                                            + percent + "% (" + formatSize(done) + ")");
                                }
                            });
                        }
                    } finally {
                        if (in != null) {
                            try {
                                in.close();
                            } catch (IOException ignored) {
                                // Abaikan kegagalan penutupan stream.
                            }
                        }
                    }
                    final String actualHash = bytesToHex(digest.digest());
                    final long finalSize = readTotal;
                    final boolean sizeOk = finalSize >= WHOLE_ROM_MIN_BYTES
                            && finalSize <= WHOLE_ROM_MAX_BYTES;
                    final boolean hashOk = EXPECTED_ROM_SHA256.equalsIgnoreCase(actualHash);
                    final boolean ok = sizeOk && hashOk;
                    runOnUiThread(new Runnable() {
                        @Override
                        public void run() {
                            wholeRomVerified = ok;
                            tvImportSteps.setVisibility(View.GONE);
                            progressBarWholeRom.setProgress(100);
                            tvWholeRomProgress.setText("Selesai: " + formatSize(finalSize));
                            StringBuilder sb = new StringBuilder();
                            sb.append("Nama: ").append(wholeRomName).append("\n");
                            sb.append("Ukuran: ").append(formatSize(finalSize))
                                    .append(" (").append(finalSize).append(" byte)")
                                    .append(" — diharapkan sekitar 405 MB: ")
                                    .append(sizeOk ? "sesuai" : "DI LUAR RENTANG").append("\n");
                            sb.append("SHA-256: ").append(actualHash).append("\n");
                            sb.append("Hasil: ").append(ok ? "LOLOS" : "GAGAL — impor ditolak");
                            if (!ok) {
                                sb.append("\nKemungkinan penyebab:");
                                if (!hashOk) {
                                    sb.append("\n- Berkas rusak / corrupt saat diunduh atau disalin.");
                                    sb.append("\n- Berkas ini bukan ROM NZeyMod utuh.");
                                }
                                if (wholeRomName.toLowerCase(Locale.US)
                                        .matches(".*\\.part\\d+$")) {
                                    sb.append("\n- Berkas ini masih berupa bagian ROM terpisah "
                                            + "(.part00–.part04). Gabungkan dahulu di bagian "
                                            + "Gabung ROM.");
                                }
                                if (!sizeOk) {
                                    sb.append("\n- Ukuran berkas jauh dari 405 MB: kemungkinan "
                                            + "berkas terpotong atau belum selesai diunduh.");
                                }
                                sb.append("\nJangan mengimpor berkas yang gagal verifikasi.");
                            }
                            tvWholeRomResult.setText(sb.toString());
                            toast(ok ? "ROM utuh lolos verifikasi"
                                    : "ROM utuh gagal verifikasi");
                        }
                    });
                } catch (final Exception e) {
                    runOnUiThread(new Runnable() {
                        @Override
                        public void run() {
                            tvWholeRomProgress.setText("Gagal memverifikasi");
                            tvWholeRomResult.setText("Galat: " + e.getMessage());
                            toast("Gagal memverifikasi ROM: " + e.getMessage());
                        }
                    });
                }
            }
        }).start();
    }

    private void prepareWholeRom() {
        if (wholeRomUri == null) {
            toast("Pilih ROM utuh terlebih dahulu");
            return;
        }
        if (!wholeRomVerified) {
            toast("Verifikasi ROM utuh terlebih dahulu hingga LOLOS");
            tvWholeRomResult.setText("Impor ditolak: ROM belum lolos verifikasi SHA-256. "
                    + "Tekan Verifikasi ROM Utuh terlebih dahulu.");
            return;
        }
        File dir = getNzeyModDir();
        if (dir == null) {
            toast("Penyimpanan eksternal aplikasi tidak tersedia");
            return;
        }
        final File dest = new File(dir, WHOLE_ROM_FILENAME);
        final Uri uri = wholeRomUri;
        final Context context = this;
        progressBarWholeRom.setVisibility(View.VISIBLE);
        progressBarWholeRom.setProgress(0);
        tvWholeRomProgress.setText("Menyalin ke NZeyMod/…");
        new Thread(new Runnable() {
            @Override
            public void run() {
                try {
                    MessageDigest digest = MessageDigest.getInstance("SHA-256");
                    long copied = 0;
                    InputStream in = null;
                    OutputStream out = null;
                    try {
                        in = context.getContentResolver().openInputStream(uri);
                        if (in == null) {
                            throw new IOException("Tidak dapat membuka berkas ROM");
                        }
                        out = new FileOutputStream(dest);
                        byte[] buffer = new byte[64 * 1024];
                        int read;
                        while ((read = in.read(buffer)) != -1) {
                            out.write(buffer, 0, read);
                            digest.update(buffer, 0, read);
                            copied += read;
                            final int percent = wholeRomSize > 0
                                    ? (int) (copied * 100 / wholeRomSize) : 0;
                            runOnUiThread(new Runnable() {
                                @Override
                                public void run() {
                                    progressBarWholeRom.setProgress(percent);
                                }
                            });
                        }
                        out.flush();
                    } finally {
                        if (in != null) {
                            try {
                                in.close();
                            } catch (IOException ignored) {
                                // Abaikan kegagalan penutupan stream.
                            }
                        }
                        if (out != null) {
                            try {
                                out.close();
                            } catch (IOException ignored) {
                                // Abaikan kegagalan penutupan stream.
                            }
                        }
                    }
                    final String copyHash = bytesToHex(digest.digest());
                    final long finalSize = copied;
                    final boolean ok = EXPECTED_ROM_SHA256.equalsIgnoreCase(copyHash);
                    runOnUiThread(new Runnable() {
                        @Override
                        public void run() {
                            if (!ok) {
                                tvWholeRomProgress.setText("Gagal menyiapkan");
                                tvWholeRomResult.setText("GAGAL — hash salinan tidak cocok ("
                                        + copyHash + "). Hapus salinan dan verifikasi ulang.");
                                toast("Salinan ROM gagal verifikasi");
                                return;
                            }
                            wholeRomPreparedPath = dest.getAbsolutePath();
                            tvWholeRomProgress.setText("Siap: " + formatSize(finalSize));
                            tvWholeRomResult.setText("ROM utuh disiapkan di:\n"
                                    + wholeRomPreparedPath + "\n"
                                    + "SHA-256 salinan: " + copyHash + " (LOLOS)");
                            tvImportSteps.setVisibility(View.VISIBLE);
                            toast("ROM siap diimpor ke NZey Master");
                        }
                    });
                } catch (final Exception e) {
                    runOnUiThread(new Runnable() {
                        @Override
                        public void run() {
                            tvWholeRomProgress.setText("Gagal menyiapkan");
                            tvWholeRomResult.setText("Galat: " + e.getMessage());
                            toast("Gagal menyiapkan ROM: " + e.getMessage());
                        }
                    });
                }
            }
        }).start();
    }

    private void launchNzeyMaster() {
        PackageManager pm = getPackageManager();
        // Utama: paket baru hasil repackage; fallback: paket lama.
        Intent launch = pm.getLaunchIntentForPackage(NZEY_PACKAGE);
        String usedPackage = NZEY_PACKAGE;
        if (launch == null) {
            launch = pm.getLaunchIntentForPackage(NZEY_PACKAGE_LEGACY);
            usedPackage = NZEY_PACKAGE_LEGACY;
        }
        if (launch == null) {
            tvNzeyInstalled.setText("Status pemasangan: belum terinstal. "
                    + "Pasang NZeyMaster-nzey.apk hasil repackage " + NZEY_VERSION
                    + " (139 MB, SHA-256 " + NZEY_SHA256 + "). "
                    + "Paket barunya " + NZEY_PACKAGE + ", jadi dapat terpasang "
                    + "berdampingan dengan Virtual Master lama tanpa uninstall. "
                    + "Tautan unduh di bawah ini masih mengarah ke APK paket lama "
                    + "(145 MB, SHA-256 " + NZEY_SHA256_LEGACY + ") sebagai fallback.");
            toast("NZey Master belum terpasang — pasang NZeyMaster-nzey.apk dahulu");
            return;
        }
        launch.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK);
        startActivity(launch);
        toast("Membuka NZey Master (" + usedPackage + ") — impor ROM lewat + > titik tiga > Import Local ROM");
    }

        intent.addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION);
        startActivityForResult(Intent.createChooser(intent, "Pilih bagian ROM"), REQ_PICK_PARTS);
    }

    private void pickRomOutput() {
        if (pickedPartUris.isEmpty()) {
            toast("Pilih bagian ROM terlebih dahulu");
            return;
        }
        Intent intent = new Intent(Intent.ACTION_CREATE_DOCUMENT);
        intent.addCategory(Intent.CATEGORY_OPENABLE);
        intent.setType("application/octet-stream");
        intent.putExtra(Intent.EXTRA_TITLE, "nzeymod-rom-joined.bin");
        intent.addFlags(Intent.FLAG_GRANT_WRITE_URI_PERMISSION);
        startActivityForResult(intent, REQ_PICK_OUTPUT);
    }

    @Override
    protected void onActivityResult(int requestCode, int resultCode, Intent data) {
        super.onActivityResult(requestCode, resultCode, data);
        if (resultCode != RESULT_OK || data == null) {
            return;
        }
        if (requestCode == REQ_PICK_PARTS) {
            handlePickedParts(data);
        } else if (requestCode == REQ_PICK_OUTPUT) {
            Uri output = data.getData();
            if (output != null) {
                joinRomParts(output);
            }
        } else if (requestCode == REQ_PICK_KEYBOX) {
            Uri uri = data.getData();
            if (uri != null) {
                handlePickedKeybox(uri);
            }
        } else if (requestCode == REQ_PICK_WHOLE_ROM) {
            Uri uri = data.getData();
            if (uri != null) {
                handlePickedWholeRom(uri);
            }
        }
    }

    private void handlePickedParts(Intent data) {
        List<Uri> uris = new ArrayList<>();
        ClipData clip = data.getClipData();
        if (clip != null) {
            for (int i = 0; i < clip.getItemCount(); i++) {
                Uri uri = clip.getItemAt(i).getUri();
                if (uri != null) {
                    uris.add(uri);
                }
            }
        } else if (data.getData() != null) {
            uris.add(data.getData());
        }
        if (uris.isEmpty()) {
            return;
        }
        // Urutkan berdasarkan nama tampilan agar bagian 1..5 tersusun benar.
        Collections.sort(uris, new Comparator<Uri>() {
            @Override
            public int compare(Uri a, Uri b) {
                return displayName(a).compareToIgnoreCase(displayName(b));
            }
        });
        pickedPartUris = uris;
        pickedPartNames = new ArrayList<>();
        StringBuilder sb = new StringBuilder("Bagian yang dipilih:\n");
        for (Uri uri : uris) {
            String name = displayName(uri);
            pickedPartNames.add(name);
            sb.append("• ").append(name).append("\n");
        }
        tvPartsList.setText(sb.toString().trim());
        tvRomResult.setText("");
        toast(pickedPartUris.size() + " bagian dipilih");
    }

    private String displayName(Uri uri) {
        String name = uri.getLastPathSegment();
        ContentResolver resolver = getContentResolver();
        Cursor cursor = null;
        try {
            cursor = resolver.query(uri,
                    new String[]{OpenableColumns.DISPLAY_NAME}, null, null, null);
            if (cursor != null && cursor.moveToFirst()) {
                int index = cursor.getColumnIndex(OpenableColumns.DISPLAY_NAME);
                if (index >= 0) {
                    String value = cursor.getString(index);
                    if (value != null && !value.isEmpty()) {
                        name = value;
                    }
                }
            }
        } catch (Exception ignored) {
            // Tetap memakai nama dari path bila kueri gagal.
        } finally {
            if (cursor != null) {
                cursor.close();
            }
        }
        return name == null ? "(tanpa nama)" : name;
    }

    private void joinRomParts(final Uri outputUri) {
        progressBarRom.setVisibility(View.VISIBLE);
        progressBarRom.setProgress(0);
        tvRomProgress.setText("Menggabungkan…");
        tvRomResult.setText("");
        final List<Uri> parts = new ArrayList<>(pickedPartUris);
        final Context context = this;
        new Thread(new Runnable() {
            @Override
            public void run() {
                try {
                    long totalBytes = 0;
                    for (Uri part : parts) {
                        totalBytes += contentLength(part);
                    }
                    MessageDigest digest = MessageDigest.getInstance("SHA-256");
                    long copied = 0;
                    ContentResolver resolver = context.getContentResolver();
                    OutputStream out = null;
                    try {
                        out = resolver.openOutputStream(outputUri);
                        if (out == null) {
                            throw new IOException("Tidak dapat membuka file keluaran");
                        }
                        byte[] buffer = new byte[64 * 1024];
                        for (Uri part : parts) {
                            InputStream in = null;
                            try {
                                in = resolver.openInputStream(part);
                                if (in == null) {
                                    throw new IOException(
                                            "Tidak dapat membuka bagian: " + displayName(part));
                                }
                                int read;
                                while ((read = in.read(buffer)) != -1) {
                                    out.write(buffer, 0, read);
                                    digest.update(buffer, 0, read);
                                    copied += read;
                                    final int percent = totalBytes > 0
                                            ? (int) (copied * 100 / totalBytes) : 0;
                                    final long done = copied;
                                    runOnUiThread(new Runnable() {
                                        @Override
                                        public void run() {
                                            progressBarRom.setProgress(percent);
                                            tvRomProgress.setText("Menggabungkan… "
                                                    + percent + "% ("
                                                    + formatSize(done) + ")");
                                        }
                                    });
                                }
                            } finally {
                                if (in != null) {
                                    try {
                                        in.close();
                                    } catch (IOException ignored) {
                                        // Abaikan kegagalan penutupan stream.
                                    }
                                }
                            }
                        }
                        out.flush();
                    } finally {
                        if (out != null) {
                            try {
                                out.close();
                            } catch (IOException ignored) {
                                // Abaikan kegagalan penutupan stream.
                            }
                        }
                    }
                    final String actualHash = bytesToHex(digest.digest());
                    final long finalSize = copied;
                    final boolean ok = EXPECTED_ROM_SHA256.equalsIgnoreCase(actualHash);
                    runOnUiThread(new Runnable() {
                        @Override
                        public void run() {
                            progressBarRom.setProgress(100);
                            tvRomProgress.setText("Selesai: " + formatSize(finalSize));
                            tvRomResult.setText("Ukuran: " + formatSize(finalSize)
                                    + " (" + finalSize + " byte)\n"
                                    + "SHA-256: " + actualHash + "\n"
                                    + "Hasil: " + (ok ? "Lolos" : "Gagal")
                                    + (ok ? "" : " — hash tidak cocok dengan yang diharapkan"));
                            toast(ok ? "ROM lolos verifikasi" : "ROM gagal verifikasi");
                        }
                    });
                } catch (final Exception e) {
                    runOnUiThread(new Runnable() {
                        @Override
                        public void run() {
                            tvRomProgress.setText("Gagal menggabungkan");
                            tvRomResult.setText("Galat: " + e.getMessage());
                            toast("Gagal menggabungkan ROM: " + e.getMessage());
                        }
                    });
                }
            }
        }).start();
    }

    private long contentLength(Uri uri) {
        ContentResolver resolver = getContentResolver();
        Cursor cursor = null;
        try {
            cursor = resolver.query(uri,
                    new String[]{OpenableColumns.SIZE}, null, null, null);
            if (cursor != null && cursor.moveToFirst()) {
                int index = cursor.getColumnIndex(OpenableColumns.SIZE);
                if (index >= 0) {
                    return cursor.getLong(index);
                }
            }
        } catch (Exception ignored) {
            // Ukuran tidak diketahui; progres memakai persen 0 sampai selesai.
        } finally {
            if (cursor != null) {
                cursor.close();
            }
        }
        return 0;
    }

    private void handlePickedKeybox(Uri uri) {
        String name = displayName(uri);
        if (name == null || !name.toLowerCase(Locale.US).endsWith(".xml")) {
            tvKeyboxStatus.setText("Keybox: gagal — file harus berekstensi .xml");
            toast("File keybox harus berekstensi .xml");
            return;
        }
        File dir = getNzeyModDir();
        if (dir == null) {
            toast("Penyimpanan eksternal aplikasi tidak tersedia");
            return;
        }
        try {
            String content = readTextFromUri(uri);
            if (content == null
                    || !content.toLowerCase(Locale.US).contains("keybox")) {
                tvKeyboxStatus.setText("Keybox: gagal — isi file tidak mengandung keybox");
                toast("Isi file tidak mengandung keybox");
                return;
            }
            File dest = new File(dir, "keybox.xml");
            writeTextFile(dest, content);
            tvKeyboxStatus.setText("Keybox: tersimpan di "
                    + dest.getAbsolutePath()
                    + "\nPeringatan: keybox ini hanya ECDSA dan kedaluwarsa pada 28 Nov 2026.");
            toast("Keybox disimpan");
        } catch (IOException e) {
            tvKeyboxStatus.setText("Keybox: gagal — " + e.getMessage());
            toast("Gagal membaca keybox: " + e.getMessage());
        }
    }

    private String readTextFromUri(Uri uri) throws IOException {
        InputStream in = getContentResolver().openInputStream(uri);
        if (in == null) {
            throw new IOException("Tidak dapat membuka file");
        }
        try {
            ByteArrayOutputStream out = new ByteArrayOutputStream();
            byte[] buffer = new byte[8192];
            int read;
            while ((read = in.read(buffer)) != -1) {
                out.write(buffer, 0, read);
            }
            return new String(out.toByteArray(), StandardCharsets.UTF_8);
        } finally {
            in.close();
        }
    }

    /** Mengembalikan nama paket bila terpasang, atau null bila tidak ada. */
    private String installedPackage(PackageManager pm, String pkg) {
        try {
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
                pm.getPackageInfo(pkg, PackageManager.PackageInfoFlags.of(0));
            } else {
                @SuppressWarnings("deprecation")

            }

        } catch (PackageManager.NameNotFoundException e) {
            return null;
        }
    }

    /** Mengembalikan versionName paket yang terpasang, atau "?" bila gagal. */
    private String installedVersion(PackageManager pm, String pkg) {
        try {
            PackageInfo info;
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
                info = pm.getPackageInfo(pkg, PackageManager.PackageInfoFlags.of(0));
            } else {
                @SuppressWarnings("deprecation")
                PackageInfo legacy = pm.getPackageInfo(pkg, 0);
                info = legacy;
            }
            return info.versionName == null ? "?" : info.versionName;
        } catch (PackageManager.NameNotFoundException e) {
            return "?";
        }
    }

    private void writeTextFile(File file, String content) throws IOException {
        File parent = file.getParentFile();
        if (parent != null && !parent.exists()) {
            parent.mkdirs();
        }
        FileOutputStream out = new FileOutputStream(file);
        try {
            out.write(content.getBytes(StandardCharsets.UTF_8));
            out.flush();
        } finally {
            out.close();
        }
    }

    private String readTextFile(File file) throws IOException {
        FileInputStream in = new FileInputStream(file);
        try {
            BufferedReader reader = new BufferedReader(
                    new InputStreamReader(in, StandardCharsets.UTF_8));
            StringBuilder sb = new StringBuilder();
            String line;
            while ((line = reader.readLine()) != null) {
                sb.append(line).append("\n");
            }
            return sb.toString();
        } finally {
            in.close();
        }
    }

    private static String escapeJson(String value) {
        if (value == null) {
            return "";
        }
        return value.replace("\\", "\\\\").replace("\"", "\\\"");
    }

    /** Mengambil nilai string sederhana "kunci": "nilai" dari JSON satu tingkat. */
    private static String jsonValue(String json, String key) {
        if (json == null) {
            return null;
        }
        String marker = "\"" + key + "\"";
        int keyIndex = json.indexOf(marker);
        if (keyIndex < 0) {
            return null;
        }
        int colon = json.indexOf(':', keyIndex + marker.length());
        if (colon < 0) {
            return null;
        }
        int firstQuote = json.indexOf('"', colon + 1);
        if (firstQuote < 0) {
            return null;
        }
        int secondQuote = json.indexOf('"', firstQuote + 1);
        if (secondQuote < 0) {
            return null;
        }
        return json.substring(firstQuote + 1, secondQuote);
    }

    private static String bytesToHex(byte[] bytes) {
        StringBuilder sb = new StringBuilder(bytes.length * 2);
        for (byte b : bytes) {
            sb.append(String.format(Locale.US, "%02x", b & 0xff));
        }
        return sb.toString();
    }

    private static String formatSize(long bytes) {
        if (bytes < 1024) {
            return bytes + " B";
        } else if (bytes < 1024L * 1024L) {
            return String.format(Locale.US, "%.2f KB", bytes / 1024.0);
        } else if (bytes < 1024L * 1024L * 1024L) {
            return String.format(Locale.US, "%.2f MB", bytes / (1024.0 * 1024.0));
        } else {
            return String.format(Locale.US, "%.2f GB", bytes / (1024.0 * 1024.0 * 1024.0));
        }
    }

    private void toast(String message) {
        Toast.makeText(this, message, Toast.LENGTH_SHORT).show();
    }

```sh
#!/bin/bash
# Build manual APK NZeyMod Manager tanpa Gradle (Java saja).
#
# Dipakai karena Gradle daemon di VM ini tidak bisa berkomunikasi
# (koneksi TCP loopback antar proses Java diblokir sandbox),
# sementara aapt2 / javac / d8 / apksigner berjalan lokal tanpa TCP.
# Hasilnya sama dengan ./gradlew assembleDebug: APK debug yang
# bisa diinstal. Untuk build normal di Android Studio, tetap
# pakai Gradle.
set -e
cd "$(dirname "$0")"

JAVA_HOME="${JAVA_HOME:-$(echo $HOME/opt/jdk-17*)}"
export JAVA_HOME
export PATH="$JAVA_HOME/bin:$PATH"

SDK="${ANDROID_HOME:-$HOME/Android/sdk}"
AAPT2="$SDK/build-tools/34.0.0/aapt2"
D8="$SDK/build-tools/34.0.0/d8"
ZIPALIGN="$SDK/build-tools/34.0.0/zipalign"
APKSIGNER="$SDK/build-tools/34.0.0/apksigner"
ANDROID_JAR="$SDK/platforms/android-34/android.jar"

OUT="app/build/manual"
rm -rf "$OUT"
mkdir -p "$OUT/gen" "$OUT/classes" "$OUT/dex"

echo "== 1. aapt2 compile (resources) =="
"$AAPT2" compile --dir app/src/main/res -o "$OUT/compiled.zip"

echo "== 2. aapt2 link (APK + R.java) =="
"$AAPT2" link -o "$OUT/app-unsigned.apk" \
  --manifest app/src/main/AndroidManifest.xml \
  -I "$ANDROID_JAR" \
  --java "$OUT/gen" \
  --min-sdk-version 26 --target-sdk-version 34 \
  --version-code 3 --version-name "2.1-beta" \
  --auto-add-overlay \
  "$OUT/compiled.zip"

echo "== 3. javac (Java -> class) =="
"$JAVA_HOME/bin/javac" -J-Xmx768m \
  -encoding UTF-8 \
  -source 17 -target 17 \
  -cp "$ANDROID_JAR" \
  -d "$OUT/classes" \
  app/src/main/java/com/kizakixd/nzeymodmanager/*.java \
  $(find "$OUT/gen" -name "*.java")

echo "== 4. d8 (class -> dex) =="
(cd "$OUT/classes" && "$JAVA_HOME/bin/jar" cf "../classes.jar" .)
"$D8" --lib "$ANDROID_JAR" --output "$OUT/dex" \
  "$OUT/classes.jar"

echo "== 5. tambah classes.dex ke APK =="
python3 - "$OUT/app-unsigned.apk" "$OUT/dex/classes.dex" << 'PY'
import sys, zipfile
apk, dex = sys.argv[1], sys.argv[2]
with zipfile.ZipFile(apk, "a", zipfile.ZIP_DEFLATED) as z:
    z.write(dex, "classes.dex")
print("dex ditambahkan")
PY

echo "== 6. zipalign =="
"$ZIPALIGN" -f 4 "$OUT/app-unsigned.apk" "$OUT/app-aligned.apk"

echo "== 7. keystore debug (jika belum ada) =="
if [ ! -f "$OUT/debug.keystore" ]; then
  keytool -genkeypair -keystore "$OUT/debug.keystore" \
    -alias androiddebugkey -storepass android -keypass android \
    -keyalg RSA -keysize 2048 -validity 10000 \
    -dname "CN=Android Debug,O=Android,C=US" -noprompt
fi

echo "== 8. apksigner =="
"$APKSIGNER" sign --ks "$OUT/debug.keystore" \
  --ks-pass pass:android --key-pass pass:android \
  --out "$OUT/app-debug.apk" "$OUT/app-aligned.apk"

echo "== 9. verifikasi =="
"$APKSIGNER" verify --verbose "$OUT/app-debug.apk"
"$AAPT2" dump badging "$OUT/app-debug.apk" | head -5
ls -lh "$OUT/app-debug.apk"

# Batasan — NZeyMod Launcher v2.1-beta

Dokumen ini menjelaskan batasan secara jujur, agar tidak ada klaim yang melebihi kemampuan aplikasi dan ROM.

## 1. Launcher bukan mesin virtual

NZeyMod Launcher tidak menjalankan ROM Android 11. Launcher hanya menyiapkan berkas: memilih ROM utuh dari penyimpanan, memverifikasi SHA-256, menyalinnya ke folder `NZeyMod/`, menggabungkan part ROM, membuat identitas, menyimpan profil, menyiapkan keybox, dan menampilkan daftar modul — lalu meluncurkan NZey Master. ROM hanya berjalan di dalam NZey Master (atau Virtual Master).

## 2. Play Integrity STRONG tidak dijamin

Play Integrity STRONG tidak dapat dijamin di VM mana pun. VM tidak memiliki TEE (Trusted Execution Environment) atau bootloader terkunci sendiri. Yang dapat diupayakan adalah hasil BASIC dan DEVICE, dengan keybox dan konfigurasi Play Integrity Fork yang benar.

## 3. Keybox kedaluwarsa 28 November 2026

Keybox yang digunakan saat ini hanya ECDSA dan kedaluwarsa pada 28 November 2026. Setelah tanggal tersebut, keybox harus diganti dengan keybox baru yang masih berlaku. Manager menampilkan peringatan ini pada fitur Ganti Keybox.

## 4. IMEI bersifat best-effort

Di Android 11, IMEI dibaca dari layanan telepon virtual. Penggantian properti IMEI bersifat best-effort dan tidak selalu terbaca sama oleh semua aplikasi.

## 5. Shopee melarang emulator dan VM

Shopee secara resmi melarang emulator atau VM di ketentuan layanannya. Modifikasi ini hanya menurunkan sinyal deteksi lokal. Hal ini tidak menjamin akun aman dari pembatasan atau penindakan oleh pihak aplikasi.

## 6. Modul Magisk tidak termasuk

File ZIP dan APK modul Magisk tidak ada di repositori `nzeymod-rom` dan tidak disertakan di dalam APK Manager. Daftar modul di Manager hanya berfungsi sebagai panduan versi dan sumber. Modul harus diperoleh dari sumber resmi masing-masing.

Daftar modul yang dirujuk:

- Zygisk Next v1.2.8
- Play Integrity Fork v18.4.1
- Shamiko v1.2.1
- LSPosed v1.10.1-7244
- Tricky Store v1.3.0
- Hide My Applist v3.7.0
- Clone App Pro v1.0.0 (APK milik pengguna)

## 7. Pemeriksaan di host bukan pemeriksaan di VM

Fitur Cek Kebocoran di Manager memeriksa perangkat host. Hasilnya tidak membuktikan kondisi di dalam VM. Pemeriksaan yang berlaku adalah pemeriksaan di dalam VM, melalui aplikasi NZeyMod Identity dan log `nzeymod.log`.

## 8. APK belum diuji di perangkat fisik

APK versi 2.1-beta dibangun dan diverifikasi secara statis di lingkungan pengembangan (tanda tangan, manifest, dan SHA-256). APK belum dipasang dan diuji di perangkat fisik. Pengujian di perangkat POCO X7 Pro masih diperlukan sebelum digunakan secara rutin, terutama alur impor ROM utuh ke NZey Master.

## 9. NZey Master hasil repackage belum teruji — rename package berisiko

`NZeyMaster-nzey.apk` adalah Virtual Master 3.2.68 hasil repackage: paket diubah dari `com.clone.android.dual.space` menjadi `com.kizakixd.nzeymaster` agar dapat terpasang berdampingan dengan Virtual Master lama tanpa uninstall, dan lib `armeabi-v7a` dibuang (hanya arm64 yang dipertahankan, sesuai POCO X7 Pro). String path paket lama di native lib `libkr*.so` (mis. `/data/data/com.clone.android.dual.space/vm/vm%d/fs`) di-patch ke paket baru dengan panjang berkas yang dipertahankan; tidak ada smali yang diubah, jadi patch VIP dipertahankan.

Risiko yang tersisa dan wajib dites di HP:

- Login server / cloud sync Virtual Master dapat menolak paket baru, karena server dapat memeriksa nama paket atau tanda tangan aplikasi.
- Provider / FileProvider dan Firebase / Mobile Ads memakai authority berbasis nama paket — sudah diubah di manifest, tetapi perilaku runtime-nya belum teruji.
- VM dapat gagal booting bila ada path lain yang masih mengarah ke paket lama di dalam native lib atau di dalam ROM yang diimpor.
- APK hasil repackage hanya untuk perangkat arm64 (POCO X7 Pro). Perangkat ARM 32-bit tidak dapat memakai APK ini karena lib `armeabi-v7a` sudah dibuang.
- Bila NZey Master hasil repackage gagal jalan, fallback-nya adalah APK paket lama — tetapi APK lama tetap bentrok dengan Virtual Master yang masih terpasang dan memerlukan uninstall terlebih dahulu.

Detail lengkap ada di `nzeymaster/REPACK.md` dan `nzeymaster/REMOVED.md`.

## 10. Keamanan berkas

- `identity.json` berisi identitas perangkat. Jangan dibagikan ke pihak yang tidak dipercaya.
- `keybox.xml` adalah kredensial sensitif. Jangan dibagikan dan jangan diunggah ke repositori publik.
- Simpan cadangan profil di tempat yang aman, dan hapus berkas yang sudah tidak diperlukan.

# Panduan — NZeyMod Launcher v2.1-beta

## Penting: Launcher ini BUKAN mesin virtual

NZeyMod Launcher bukan mesin virtual dan bukan emulator Android di dalam
HP. Mesin yang menjalankan ROM NZeyMod adalah **NZey Master** (Virtual
Master 3.2.68 remake, VIP sudah di-patch). Launcher menyiapkan ROM utuh
dari penyimpanan, memverifikasi SHA-256, menyalinnya ke folder `NZeyMod/`,
lalu meluncurkan NZey Master untuk diimpor lewat **Import Local ROM**.
ROM ini hanya dapat dijalankan oleh mesin Virtual Master / NZey Master.

## Perangkat yang dituju

Panduan ini ditulis untuk POCO X7 Pro sebagai perangkat host. Perangkat
host adalah perangkat tempat Launcher dan NZey Master dipasang. ROM
Android 11 berjalan di dalam VM (NZey Master), bukan langsung di perangkat
host.

## 1. Persiapan

1. Pastikan ruang kosong di perangkat host minimal 1 GB: sekitar 405 MB
   untuk ROM utuh, dan 139 MB untuk APK NZey Master hasil repackage
   (bila belum terpasang). Bila masih memakai 5 part ROM, sediakan
   sekitar 1,5 GB (405 MB untuk part, 405 MB untuk file ZIP gabungan,
   dan 139 MB untuk APK NZey Master hasil repackage).
2. Siapkan ROM utuh yang sudah dimiliki:
   `rom_11_0_0_1036_3281_M27_NZeyMod.zip` (sekitar 405 MB).
   SHA-256 yang benar adalah:
   `1d8e0031a1076b4de7192274fb156a7ab88c97f1eb3b4bf3be98adf2e65c364c`
3. Sejak v2.1-beta, Virtual Master lama **tidak perlu dihapus**: NZey
   Master hasil repackage memakai paket `com.kizakixd.nzeymaster` dan
   dapat terpasang berdampingan dengan Virtual Master lama. Ini hanya
   berlaku untuk APK hasil repackage (`NZeyMaster-nzey.apk`, 139 MB).
   APK paket lama (145 MB) tetap bentrok dan tetap memerlukan uninstall
   Virtual Master lama terlebih dahulu.
4. Pasang NZey Master hasil repackage bila belum terpasang. APK-nya
   `NZeyMaster-nzey.apk`, berukuran 139 MB (144.895.840 byte), SHA-256
   `224083a8cd2920f67d9c8a67a9f6746afa62820a218d9cb5f7174760a46bb55c`.
   Tautan / berkas rilis tercantum di Launcher bagian NZey Master.
   Launcher tidak mengunduh APK tersebut di dalam aplikasi; unduhan
   dilakukan melalui peramban / aplikasi Unduhan, lalu dipasang dari sana.

## 2. Jalankan ROM utuh (fitur utama v2)

Ini adalah cara yang dipakai bila ROM utuh sudah dimiliki. Menggabungkan
5 bagian ROM tidak diperlukan dalam cara ini.

1. Buka Launcher, masuk ke bagian **Jalankan ROM (ROM Utuh)**.
2. Tekan **Pilih ROM Utuh**, lalu cari dan pilih berkas ROM utuh dari
   folder mana pun di penyimpanan (nama berkas bebas — yang diperiksa
   adalah isi berkas melalui SHA-256, bukan namanya).
   Launcher menampilkan nama berkas dan ukurannya. Ukuran yang diterima
   adalah 380–430 MB. Bila nama berkas berakhiran `.part00` sampai
   `.part04`, itu adalah bagian ROM terpisah — gunakan bagian Gabung ROM
   di bawah, bukan cara ini.
3. Tekan **Verifikasi ROM Utuh**. Launcher menghitung SHA-256 berkas
   (405 MB membutuhkan waktu beberapa saat) dan membandingkannya dengan
   hash resmi di atas.
4. Bila hasil **LOLOS**, tekan **Siapkan untuk Impor**. Launcher menyalin
   berkas ke folder `NZeyMod/` di penyimpanan aplikasi dan menghitung
   ulang SHA-256 salinan tersebut. Bila salinan tidak cocok, hapus salinan
   dan verifikasi ulang.
5. Bila hasil **GAGAL**, impor ditolak dan Launcher menjelaskan
   kemungkinannya: berkas corrupt saat diunduh atau disalin, berkas bukan
   ROM NZeyMod utuh, masih berupa bagian terpisah, atau ukuran jauh dari
   405 MB (berkas terpotong atau belum selesai diunduh). Jangan mengimpor
   berkas yang gagal verifikasi. Periksa sumber berkas, salin atau unduh
   ulang, lalu verifikasi lagi.
6. Tekan **Buka NZey Master**. Bila NZey Master belum terpasang, Launcher
   menampilkan status belum terpasang dan tautan unduhnya.
7. Di NZey Master, lakukan impor:
   - Tap tombol **+** (Tambah).
   - Tap titik tiga (⋮).
   - Pilih **Import Local ROM**.
   - Pilih berkas `rom_11_0_0_1036_3281_M27_NZeyMod.zip` dari folder
     `NZeyMod/`.
   - Tunggu instalasi ROM selesai, lalu jalankan VM.
8. Pada boot pertama, `nzeymod.sh` memasang modul, menerapkan identitas,
   dan menulis log ke `/sdcard/NZeyMod/nzeymod.log` di dalam VM.

Di prototipe web, cara yang sama dapat dicoba: pilih ROM utuh, verifikasi
SHA-256, lalu unduh salinan dengan nama yang benar ke folder `NZeyMod/`.
Peluncuran NZey Master dari peramban tidak dapat dilakukan; langkah impor
tetap dilakukan manual di NZey Master.

## 3. Gabung ROM (opsional, bila yang dimiliki masih 5 bagian)

Langkah ini hanya diperlukan bila yang dimiliki masih berupa 5 bagian
ROM, bukan ROM utuh.

1. Buka Launcher, masuk ke bagian Gabung ROM.
2. Pilih kelima file part. Urutan file ditentukan berdasarkan nama file, dari `.part00` sampai `.part04`:
   - `rom_11_0_0_1036_3281_M27_NZeyMod.zip.part00` (90 MB)
   - `rom_11_0_0_1036_3281_M27_NZeyMod.zip.part01` (90 MB)
   - `rom_11_0_0_1036_3281_M27_NZeyMod.zip.part02` (90 MB)
   - `rom_11_0_0_1036_3281_M27_NZeyMod.zip.part03` (90 MB)
   - `rom_11_0_0_1036_3281_M27_NZeyMod.zip.part04` (44,9 MB)
3. Pilih lokasi penyimpanan untuk file hasil gabungan, dengan nama `rom_11_0_0_1036_3281_M27_NZeyMod.zip`.
4. Tunggu proses selesai. Launcher menghitung SHA-256 selama penggabungan.
5. Nilai yang benar adalah:
   `1d8e0031a1076b4de7192274fb156a7ab88c97f1eb3b4bf3be98adf2e65c364c`
6. Jika nilai tidak sesuai, jangan lanjutkan. Unduh ulang part yang rusak dan gabungkan kembali. Setelah hasil gabungan lolos, kembali ke langkah 2 di atas dan impor berkas tersebut ke NZey Master.

Perintah yang setara di Termux atau Linux, bila dilakukan manual, ada di `rom-fixes/join.sh`.

## 4. Buat identitas

1. Masuk ke bagian Acak Identitas.
2. Pilih mode operator: `random` atau salah satu operator (Telkomsel, Indosat Ooredoo, XL Axiata, AXIS, Tri, Smartfren).
3. Tekan tombol acak identitas. Launcher membuat:
   - Android ID: 16 karakter heksadesimal acak.
   - Serial: 16 karakter heksadesimal acak.
   - IMEI: diawali TAC Pixel 5 (35254410, 35482510, atau 35737210), dilanjutkan 6 digit acak, dan diakhiri digit Luhn yang valid.
   - Operator beserta kode MCCMNC-nya.
4. Simpan hasilnya. Launcher menulis `identity.json` dan `config.prop` ke folder `NZeyMod/` di penyimpanan aplikasi, dan dapat membagikannya sebagai file.
5. Untuk memakai kembali identitas yang sama di lain waktu, simpan sebagai profil dengan nama yang jelas, misalnya `shopee-bersih` atau `utama`.

## 5. Profil Magisk

- **Magisk OFF (profil bersih)**: tanpa root dan tanpa modul. Profil ini ditujukan untuk aplikasi yang sensitif terhadap root.
- **Magisk ON (profil root)**: modul dipasang di dalam VM saat boot pertama oleh `nzeymod.sh`, dari folder `/system/nzeymod/modules/`. Daftar modul:
  - Zygisk Next v1.2.8
  - Play Integrity Fork v18.4.1
  - Shamiko v1.2.1
  - LSPosed v1.10.1-7244
  - Tricky Store v1.3.0
  - Hide My Applist v3.7.0
  - Clone App Pro v1.0.0

  DenyList yang diterapkan mencakup aplikasi Shopee (`com.shopee.id`, `com.shopee.tw`, `com.shopee.ph`, `com.shopee.vn`, `com.shopee.my`, `com.shopee.sg`, `com.shopee.br`, `com.shopee.co.id`) dan `com.clone.app.pro`.

Modul-modul tersebut **tidak termasuk** di dalam APK Launcher. Unduh modul dari sumber resmi masing-masing sesuai `docs/modules-report.md` di repositori asal, lalu pastikan modul berada di dalam ROM sebelum boot pertama, atau pasang secara manual melalui aplikasi Magisk di dalam VM.

## 6. Ganti keybox

1. Siapkan file keybox XML yang baru dan masih berlaku.
2. Di Launcher, pilih file XML tersebut.
3. Launcher memeriksa bahwa file berekstensi `.xml` dan berisi data keybox, lalu menyalinnya sebagai `keybox.xml`.
4. Salin file tersebut ke `/sdcard/NZeyMod/keybox.xml` di dalam VM, lalu nyalakan ulang VM.

Keybox yang ada saat ini kedaluwarsa pada 28 November 2026. Setelah tanggal tersebut, keybox harus diganti, karena Play Integrity dapat gagal.

## 7. Pasang NZey Master dan impor ROM

1. Di bagian NZey Master pada Launcher, periksa apakah NZey Master sudah terpasang. Launcher memeriksa paket baru `com.kizakixd.nzeymaster` terlebih dahulu, lalu paket lama `com.clone.android.dual.space` sebagai fallback.
2. Jika belum, pasang `NZeyMaster-nzey.apk` hasil repackage (139 MB). Periksa SHA-256 APK bila memungkinkan:
   `224083a8cd2920f67d9c8a67a9f6746afa62820a218d9cb5f7174760a46bb55c`
   APK ini dapat terpasang berdampingan dengan Virtual Master lama — tidak perlu uninstall. APK paket lama (145 MB, SHA-256 `2d70516e1f7bd85ca105341b8bd13760fe7484d6b1983e0446a436253d90c602`) hanya fallback dan tetap memerlukan uninstall Virtual Master lama.
3. Pasang APK tersebut.
4. Impor file ZIP ROM utuh yang sudah diverifikasi ke NZey Master dengan langkah pada bagian 2 di atas.
5. Salin `identity.json`, `config.prop`, dan `keybox.xml` hasil Launcher ke folder `/sdcard/NZeyMod/` di dalam VM. Cara penyalinan berkas mengikuti fitur berbagi berkas yang disediakan NZey Master.
6. Nyalakan ulang VM. Pada boot pertama, `nzeymod.sh` memasang modul, menerapkan identitas, dan menulis log ke `/sdcard/NZeyMod/nzeymod.log` di dalam VM.

## 8. Cek kebocoran

Gunakan fitur Cek Kebocoran di dalam VM (aplikasi NZeyMod Identity) untuk pemeriksaan yang sebenarnya. Fitur Cek Kebocoran di Launcher hanya memeriksa perangkat host dan digunakan sebagai gambaran awal. Nilai yang diharapkan di dalam VM antara lain `ro.debuggable=0`, `ro.build.tags=release-keys`, dan `ro.secure=1`, serta tidak ada jejak `su` di luar Magisk.

## 9. Jika terjadi masalah

- **SHA-256 ROM tidak sesuai**: jangan impor berkas tersebut. Periksa ukuran berkas (harus sekitar 405 MB), periksa apakah berkas masih berupa bagian `.part`, lalu salin atau unduh ulang dan verifikasi lagi.
- **NZey Master tidak muncul saat ditekan Buka**: periksa apakah NZey Master sudah terpasang (bagian NZey Master di Launcher). Bila belum, unduh dan pasang terlebih dahulu.
- **Import Local ROM tidak menemukan berkas**: pastikan berkas berada di folder `NZeyMod/` dan bernama `rom_11_0_0_1036_3281_M27_NZeyMod.zip`, lalu coba pilih melalui pengelola berkas NZey Master.
- **Identitas tidak berubah setelah reboot**: periksa `nzeymod.log` di dalam VM dan pastikan `identity.json` berada di `/sdcard/NZeyMod/`.
- **Modul tidak terpasang**: pastikan folder `/system/nzeymod/modules/` berisi file modul, lalu periksa log boot pertama.
- **NZey Master tidak dapat dipasang**: bila memasang APK paket lama (145 MB), pastikan Virtual Master lama sudah dihapus, karena tanda tangan APK berbeda. Bila memasang `NZeyMaster-nzey.apk` hasil repackage (139 MB, paket `com.kizakixd.nzeymaster`), uninstall tidak diperlukan — APK ini dibuat agar dapat berdampingan dengan Virtual Master lama.
- **Play Integrity gagal**: periksa masa berlaku keybox dan konfigurasi Play Integrity Fork. STRONG tidak dapat dijamin di VM; lihat `docs/batasan.md`.

function randomHex(n) {
  var bytes = new Uint8Array(Math.ceil(n / 2));
  window.crypto.getRandomValues(bytes);
  var s = '';
  for (var i = 0; i < bytes.length; i++) s += ('0' + bytes[i].toString(16)).slice(-2);
  return s.slice(0, n);
}
function randomDigits(n) {
  var s = '';
  var arr = new Uint8Array(n);
  window.crypto.getRandomValues(arr);
  for (var i = 0; i < n; i++) s += String(arr[i] % 10);
  return s;
}
function luhnCheckDigit(base14) {
  // Hitung digit cek Luhn untuk 14 digit dasar sehingga 15 digit penuh lolos Luhn.
  var withZero = base14 + '0';
  var sum = 0;
  var doubleIt = false;
  for (var i = withZero.length - 1; i >= 0; i--) {
    var d = parseInt(withZero.charAt(i), 10);
    if (doubleIt) { d = d * 2; if (d > 9) d -= 9; }
    sum += d;
    doubleIt = !doubleIt;
  }
  return String((10 - (sum % 10)) % 10);
}
function isValidLuhn15(imei) {
  if (!/^\d{15}$/.test(imei)) return false;
  var sum = 0, doubleIt = false;
  for (var i = imei.length - 1; i >= 0; i--) {
    var d = parseInt(imei.charAt(i), 10);
    if (doubleIt) { d = d * 2; if (d > 9) d -= 9; }
    sum += d;
    doubleIt = !doubleIt;
  }
  return sum % 10 === 0;
}

function loadProfile(name) {

function parseLeakInput(text) {
  var out = { android_id: null, serial: null, imei: null, source: 'tidak diketahui' };
  if (!text || !text.trim()) return out;
  var t = text.trim();
  try {
    var obj = JSON.parse(t);
    out.android_id = obj.android_id || null;
    out.serial = obj.serial || obj.ro_serialno || null;
    out.imei = obj.imei || null;
    out.source = 'identity.json (JSON)';
    return out;
  } catch (e) { /* bukan JSON — coba sebagai config.prop */ }
  var lines = t.split(/\r?\n/);
  lines.forEach(function (line) {
    var m = line.match(/^\s*([^#=\s]+)\s*=\s*(.+?)\s*$/);
    if (!m) return;
    var k = m[1], v = m[2];
    if (k === 'android_id') out.android_id = v;
    if (k === 'ro.serialno' || k === 'serial') out.serial = v;
    if (k === 'imei') out.imei = v;
  });
  out.source = 'config.prop';
  return out;
}

}

```js
/* NZeyMod Manager — Service Worker (opsional, cache-first untuk halaman prototype). */
var CACHE_NAME = 'nzeymod-manager-v1';
var ASSETS = ['index.html', 'manifest.webmanifest'];

self.addEventListener('install', function (event) {
  event.waitUntil(
    caches.open(CACHE_NAME).then(function (cache) {
      return cache.addAll(ASSETS);
    }).catch(function () { /* abaikan bila aset belum tersedia */ })
  );
  self.skipWaiting();
});

self.addEventListener('activate', function (event) {
  event.waitUntil(
    caches.keys().then(function (keys) {
      return Promise.all(keys.filter(function (k) { return k !== CACHE_NAME; }).map(function (k) { return caches.delete(k); }));
    })
  );
  self.clients.claim();
});

self.addEventListener('fetch', function (event) {
  if (event.request.method !== 'GET') return;
  event.respondWith(
    caches.match(event.request).then(function (cached) {
      return cached || fetch(event.request).then(function (resp) {
        if (resp && resp.ok && event.request.url.indexOf(self.location.origin) === 0) {
          var copy = resp.clone();
          caches.open(CACHE_NAME).then(function (cache) { cache.put(event.request, copy); });
        }
        return resp;
      });
    }).catch(function () { return caches.match('index.html'); })
  );
});

```md
# Perbaikan ROM — NZeyMod

File di folder ini adalah versi yang diperbaiki dari file di repositori `nzeymod-rom`. File ini tidak mengubah isi ROM biner; file ini memperbaiki nama berkas, konfigurasi, dan skrip pendukung agar konsisten.

## 1. `operators.txt` — nama berkas diperbaiki

Masalah: `scripts/nzeymod.sh` membaca `$SYS/operators.txt`, tetapi file di repositori bernama `scripts/operators_id.txt`. Akibatnya, skrip tidak menemukan daftar operator.

Perbaikan: file ini bernama `operators.txt` dan berisi 6 operator dengan format `nama|numeric|alpha`:

- Telkomsel|51010|Telkomsel
- Indosat Ooredoo|51021|Indosat Ooredoo
- XL Axiata|51011|XL
- AXIS|51008|AXIS
- Tri|51089|3
- Smartfren|51009|Smartfren

Cara memakai: salin file ini menjadi `/system/nzeymod/operators.txt` di dalam ROM (atau sertakan saat repack). Aplikasi NZeyMod Identity juga memakai `/sdcard/NZeyMod/operators.txt` dengan format yang sama.

## 2. `config.prop` — kunci dipisah dengan jelas

Masalah: aplikasi NZeyMod Identity menulis kunci `identity_mode`, `keybox_path`, `randomize_on_boot`, `wipe_profiles_on_randomize`, dan `show_toast`, tetapi `nzeymod.sh` hanya membaca `operator_mode`. Kunci lain tidak berpengaruh pada skrip boot.

Perbaikan: `config.prop` di folder ini memberi komentar pada tiap kunci, yang menjelaskan kunci mana yang dibaca skrip dan mana yang hanya dipakai aplikasi. Nilai default tetap sama: `operator_mode=random`.

## 3. Identitas perangkat — gunakan `redfin`, bukan `flame`

Masalah: `props/vendor-build.prop` menulis `ro.product.board=flame` (Pixel 4), padahal seluruh identitas lain adalah Pixel 5 (`redfin`): model, device, fingerprint, dan `board` di partisi system.

Perbaikan: gunakan `redfin` secara konsisten di seluruh partisi:

- `ro.product.model=Pixel 5`
- `ro.product.device=redfin`
- `ro.product.board=redfin`
- `ro.build.fingerprint=google/redfin/redfin:11/RQ3A.211001.001/7641976:user/release-keys`

Catatan: `ro.hardware.*=master` di vendor sengaja tidak diubah. Nilai tersebut adalah nama HAL fungsional VM; menggantinya dapat membuat HAL tidak berfungsi.

## 4. `join.sh` — sama dengan skrip asal, ditambah penjelasan

`join.sh` di folder ini memiliki logika yang sama dengan `rom/join.sh` di repositori asal: menggabungkan 5 part dengan `cat`, lalu memeriksa SHA-256. Nilai SHA-256 yang benar:

`1d8e0031a1076b4de7192274fb156a7ab88c97f1eb3b4bf3be98adf2e65c364c`

Total ukuran gabungan sekitar 405 MB (90 + 90 + 90 + 90 + 44,9 MB).

## 5. Catatan perbaikan dalam bentuk patch

`nzeymod-fixed.patch` berisi perubahan yang sama dalam format patch, agar dapat ditinjau baris demi baris sebelum diterapkan ke repositori asal. Patch tersebut mencakup:

- Penambahan `operators.txt` dengan isi yang benar (pengganti nama `operators_id.txt` untuk keperluan skrip).
- Komentar penjelas di `config.prop`.
- Perbaikan `ro.product.board` dari `flame` menjadi `redfin` di `vendor-build.prop`.

## 6. Yang tidak diperbaiki di sini

- Modul Magisk (ZIP/APK) dan `keybox.xml` tidak disertakan, karena tidak ada di repositori asal dan tidak boleh dibagikan secara sembarangan. Lihat `docs/batasan.md`.
- File ROM biner tidak diubah. Perbaikan ini hanya menyangkut berkas pendukung.
