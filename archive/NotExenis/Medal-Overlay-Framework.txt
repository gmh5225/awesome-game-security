```md
# MOF — Medal Overlay Framework

A stealth overlay framework that renders through Medal.tv's whitelisted in-game overlay. Medal's overlay window is trusted by major anti-cheat systems (EAC, BattlEye, Vanguard), making it an ideal rendering surface for ESP, crosshairs, menus, and other visual overlays.

MOF patches Medal's Electron app to inject a bridge that creates a named pipe server. External processes connect over the pipe and send draw commands which render on Medal's overlay canvas — appearing as Medal itself to anti-cheat.

## Architecture

```
  Your Program (Python/C++)
       │  Named Pipe (per-machine derived name)
       ▼
  ext-host.js            ← Injected into Medal's Electron main process
       │  executeJavaScript()
       ▼
  overlay-ctrl.js        ← Runs in Medal's overlay BrowserWindow
       │  Canvas 2D + DOM
       ▼
  Medal Overlay Window   ← Whitelisted by anti-cheat
```

## Features

### Drawing Primitives
- Text (aligned, outlined, bold, custom font)
- Rectangles, filled rectangles, rounded rectangles
- Lines, circles, corner boxes
- Gradient rectangles (linear, radial, multi-stop)
- Arcs and pie slices
- Bezier curves (quadratic + cubic)
- Polygons (arbitrary points, fill + stroke)
- Text wrapping (word-break, max width, background)
- Image rendering (base64 PNG cache, spritesheet crop, rotation, opacity)

### Game Overlays
- ESP boxes (box/corner style, name, health bar, distance, info text)
- Crosshair (configurable size, gap, thickness, dot, outline)
- Snap lines, FOV circles
- Bone/skeleton rendering (joints + connections)
- Watermarks, progress bars

### Animation System
- **Fade** — smoothstep alpha transition
- **Pulse** — sine-wave alpha oscillation
- **Slide** — smoothstep position translation
- **Blink** — duty-cycle on/off
- Attachable to any draw command via `anim` property

### Interactive Menu System
- Opens with INSERT key (configurable)
- Tabs, toggles, sliders, selects, buttons, color pickers, labels, separators
- Style customization (opacity, accent color, width, font size, border radius, compact mode)
- Multi-client support (multiple programs can register menus simultaneously)
- Draggable panels, ESC to close
- Event callbacks for menu changes and actions

### Draw Layers
- All commands support a `layer` property for z-ordering
- Commands sorted by layer before rendering (default layer = 0)
- Higher layers draw on top

### Stealth
- Per-machine pipe name derived from hardware identity (not static/scannable)
- Bridge files deployed with innocuous names inside the asar
- No log files written to disk
- Helper executable cleaned up on exit
- Obfuscated global variables and DOM element IDs
- Legacy patch detection and cleanup

## Requirements

- **Medal.tv** installed (Electron 44+)
- **Node.js** 18+ (for the patcher)
- **@electron/asar**: `npm install -g @electron/asar`
- **Python 3.7+** (for Python SDK) or **C++17 + Windows SDK** (for C++ SDK)
- **.NET Framework 4.x** (for helper compilation — present on all modern Windows)

## Pipe Protocol

Communication is newline-delimited JSON over a Windows named pipe.

**Client → Bridge:**
```json
{"type": "begin_frame"}
{"type": "text", "x": 100, "y": 50, "text": "Hello", "color": 4294967295, "size": 14}
{"type": "esp", "x": 100, "y": 200, "w": 50, "h": 100, "name": "Player"}
{"type": "end_frame"}
{"type": "set_menu", "menu": {"title": "My Menu", "tabs": [...]}}
{"type": "identify", "name": "my-program"}
```

**Bridge → Client:**
```json
{"type": "welcome", "clientId": 0, "version": "4.0.0", "screen": {"width": 2560, "height": 1440}}
{"type": "menu_toggle", "open": true}
{"type": "menu_change", "id": "aim_fov", "value": 120}
```

## How It Works

1. **Patcher** extracts Medal's `app.asar`, injects `require('./ext-host')` into `main.min.js`, copies bridge files with stealth names, repacks the asar.

2. **Bridge** (`ext-host.js`) runs inside Medal's Electron main process. It discovers Medal's overlay BrowserWindow, force-shows it, injects the renderer code via `executeJavaScript()`, and creates a named pipe server for external connections.

3. **Renderer** (`overlay-ctrl.js`) runs in the overlay's renderer process. It creates a full-screen canvas and processes draw commands pushed from the bridge. When menu mode is active, it renders interactive DOM menus and captures input events.

4. **Helper** (`host-svc.cs` → `MedalOverlayHost.exe`) is a compiled C# binary that provides native Win32 functionality: mouse state polling at 120Hz and a low-level mouse hook (`WH_MOUSE_LL`) that captures clicks during menu mode so they only reach the overlay.

5. **SDKs** connect to the named pipe, send draw commands as JSON, and receive events (screen size, menu changes, hotkey state). The pipe name is derived deterministically from machine identity so both sides compute it independently.

```js
/**
 * Extension Host v4.0 - Medal overlay bridge
 */
(function () {
    'use strict';

    if (global.__extHostReady) return;
    global.__extHostReady = true;

    const net = require('net');
    const fs = require('fs');
    const path = require('path');
    const crypto = require('crypto');
    const { BrowserWindow, globalShortcut, app } = require('electron');

    // ── Pipe Name Derivation ────────────────────────────────────
    // Deterministic per-machine pipe name. Same algorithm in SDKs.

    function derivePipeName() {
        const seed = (process.env.COMPUTERNAME || '') + (process.env.USERNAME || '') + 'medal-ext-v2';
        const hash = crypto.createHash('md5').update(seed).digest('hex').slice(0, 12);
        return '\\\\.\\pipe\\MedalExtHost-' + hash;
    }

    const PIPE_NAME = derivePipeName();

    // ── File References (patcher renames these on deploy) ────────

    const RENDERER_FILE = 'mof-renderer.js';
    const HELPER_SRC_FILE = 'mof-helper.cs';
    const HELPER_EXE_NAME = 'MedalOverlayHost.exe';
    const HELPER_EXE = path.join(require('os').tmpdir(), HELPER_EXE_NAME);

    // ── Configuration ────────────────────────────────────────────

    const config = {
        menuHotkey: 'Insert',
        version: '4.0.0',
    };

    // ── Logging (console only, no file artifacts) ────────────────

    function log(msg) {
        const ts = new Date().toISOString().slice(11, 23);
        console.log(`[${ts}] ${msg}`);
    }

    function logError(msg) {
        console.error(`ERR: ${msg}`);
    }

    // ── Native Helper Compilation ─────────────────────────────────

    let helperExists = false;

    (function compileHelper() {
        try {
            const srcInAsar = path.join(__dirname, HELPER_SRC_FILE);
            const tmpSrc = path.join(require('os').tmpdir(), HELPER_SRC_FILE);

            let srcContent;
            try { srcContent = fs.readFileSync(srcInAsar, 'utf-8'); } catch(e) {
                logError('Helper source not found');
                return;
            }

            // Skip compile if exe exists and source hash matches
            if (fs.existsSync(HELPER_EXE) && fs.existsSync(tmpSrc)) {
                const existing = fs.readFileSync(tmpSrc, 'utf-8');
                if (existing === srcContent) { helperExists = true; return; }
            }

            fs.writeFileSync(tmpSrc, srcContent, 'utf-8');

            const csc = 'C:\\Windows\\Microsoft.NET\\Framework64\\v4.0.30319\\csc.exe';
            if (!fs.existsSync(csc)) {
                logError('csc.exe not found');
                return;
            }
            const { execFileSync } = require('child_process');
            execFileSync(csc, [
                '/nologo', '/optimize', '/target:exe',
                '/out:' + HELPER_EXE, tmpSrc
            ], { timeout: 10000, stdio: 'pipe', windowsHide: true });
            helperExists = true;
            log('Helper compiled');
        } catch(e) {
            logError('Helper compilation failed: ' + e.message);
            try { helperExists = fs.existsSync(HELPER_EXE); } catch(e2) {}
        }
    })();

    // ── Renderer Code Loading ────────────────────────────────────

    let rendererCode = null;
    try {
        const rendererPath = path.join(__dirname, RENDERER_FILE);
        rendererCode = fs.readFileSync(rendererPath, 'utf-8');
        log(`Renderer loaded (${rendererCode.length}b)`);
    } catch (e) {
        logError(`Renderer not found: ${e.message}`);
        rendererCode = `console.error('Renderer file not found');`;
    }

    // ── Overlay State ────────────────────────────────────────────

    let overlayWindows = [];
    let discoveryInterval = null;
    let overlaySize = { width: 0, height: 0 };

    // ── Menu State ───────────────────────────────────────────────

    let menuOpen = false;
    let clientMenus = {};

    // ── Overlay Window Discovery ─────────────────────────────────

    function findOverlayWindows() {
        const allWindows = BrowserWindow.getAllWindows();
        const found = [];

        for (const win of allWindows) {
            if (win.isDestroyed()) continue;
            let title, url;
            try {
                title = win.getTitle();
                url = win.webContents.getURL();
            } catch(e) { continue; }

            if (title === 'Medal Overlay' || (url && url.includes('overlay.min.html'))) {
                found.push({
                    window: win,
                    id: win.id,
                    rendererReady: false,
                });
            }
        }
        return found;
    }

    function injectRenderer(entry) {
        const win = entry.window;
        if (win.isDestroyed()) return;

        log(`Overlay found id=${win.id}`);

        if (!win.isVisible()) {
            try {
                win.setIgnoreMouseEvents(true, { forward: true });
                win.setSkipTaskbar(true);
                win.setAlwaysOnTop(true, 'screen-saver');
                win.showInactive();
            } catch(e) {
                logError(`Show overlay failed: ${e.message}`);
            }
        }

        try {
            const { screen } = require('electron');
            const display = screen.getPrimaryDisplay();
            const { x, y, width, height } = display.bounds;
            const currentBounds = win.getBounds();
            if (currentBounds.width !== width || currentBounds.height !== height ||
                currentBounds.x !== x || currentBounds.y !== y) {
                win.setBounds({ x, y, width, height });
                log(`Overlay resized: ${width}x${height}`);
            }
        } catch(e) {
            logError(`Resize failed: ${e.message}`);
        }

        try {
            const bounds = win.getBounds();
            overlaySize = { width: bounds.width, height: bounds.height };
        } catch(e) {}

        win.webContents.executeJavaScript(rendererCode).then(() => {
            log(`Renderer injected win=${win.id}`);
            setTimeout(() => {
                entry.rendererReady = true;
                if (!entry._inputForwarding) {
                    entry._inputForwarding = true;
                    setupInputForwarding(entry);
                }
                broadcastEvent({ type: 'overlay_ready', ...overlaySize });
            }, 1500);
        }).catch((err) => {
            logError(`Renderer inject failed: ${err.message}`);
            entry.rendererReady = true;
        });

        win.webContents.on('did-finish-load', () => {
            log(`Overlay reloaded, re-injecting`);
            entry.rendererReady = false;
            menuOpen = false;
            if (!win.isVisible()) {
                try { win.setIgnoreMouseEvents(true, { forward: true }); win.showInactive(); } catch(e) {}
            }
            win.webContents.executeJavaScript(rendererCode).then(() => {
                setTimeout(() => {
                    entry.rendererReady = true;
                    if (!entry._inputForwarding) {
                        entry._inputForwarding = true;
                        setupInputForwarding(entry);
                    }
                    pushMenusToRenderer();
                }, 1500);
            }).catch(() => { entry.rendererReady = true; });
        });

        const visCheck = setInterval(() => {
            if (win.isDestroyed()) { clearInterval(visCheck); return; }
            if (!win.isVisible() && entry.rendererReady) {
                try {
                    if (menuOpen) {
                        win.setIgnoreMouseEvents(false);
                    } else {
                        win.setIgnoreMouseEvents(true, { forward: true });
                    }
                    win.showInactive();
                } catch(e) {}
            }
            try {
                const b = win.getBounds();
                if (b.width !== overlaySize.width || b.height !== overlaySize.height) {
                    overlaySize = { width: b.width, height: b.height };
                    broadcastEvent({ type: 'resize', ...overlaySize });
                }
            } catch(e) {}
        }, 1000);

        win.on('closed', () => {
            log(`Overlay closed id=${win.id}`);
            clearInterval(visCheck);
            overlayWindows = overlayWindows.filter(e => e.id !== entry.id);
            menuOpen = false;
            broadcastEvent({ type: 'overlay_closed' });
        });
    }

    function discoverOverlays() {
        const found = findOverlayWindows();
        for (const entry of found) {
            if (!overlayWindows.find(e => e.id === entry.id)) {
                overlayWindows.push(entry);
                injectRenderer(entry);
            }
        }
    }

    discoveryInterval = setInterval(discoverOverlays, 2000);
    setTimeout(discoverOverlays, 500);

    // ── Mouse Input Forwarding ──────────────────────────────────

    let mouseForwardInterval = null;

    function startMouseForwarding() {
        if (mouseForwardInterval) return;
        if (!helperExists) {
            try { helperExists = fs.existsSync(HELPER_EXE); } catch(e) {}
        }
        if (!helperExists) {
            logError('Mouse forwarding: helper not found');
            return;
        }

        const mouseProc = require('child_process').spawn(HELPER_EXE, ['mousemon'], {
            stdio: ['pipe', 'pipe', 'ignore'],
            windowsHide: true,
        });

        let lWasDown = false, rWasDown = false;

        mouseProc.stdout.on('data', (data) => {
            if (!menuOpen) return;
            const lines = data.toString().trim().split('\n');
            const last = lines[lines.length - 1].trim().split(',');
            if (last.length < 4) return;
            const x = parseInt(last[0], 10);
            const y = parseInt(last[1], 10);
            const lDown = last[2] === '1';
            const rDown = last[3] === '1';

            for (const entry of overlayWindows) {
                if (entry.window.isDestroyed() || !entry.rendererReady) continue;
                const wc = entry.window.webContents;

                try { wc.sendInputEvent({ type: 'mouseMove', x, y }); } catch(e) {}

                if (lDown && !lWasDown) {
                    try { wc.sendInputEvent({ type: 'mouseDown', x, y, button: 'left', clickCount: 1 }); } catch(e) {}
                } else if (!lDown && lWasDown) {
                    try { wc.sendInputEvent({ type: 'mouseUp', x, y, button: 'left' }); } catch(e) {}
                }

                if (rDown && !rWasDown) {
                    try { wc.sendInputEvent({ type: 'mouseDown', x, y, button: 'right', clickCount: 1 }); } catch(e) {}
                } else if (!rDown && rWasDown) {
                    try { wc.sendInputEvent({ type: 'mouseUp', x, y, button: 'right' }); } catch(e) {}
                }
            }

            lWasDown = lDown;
            rWasDown = rDown;
        });

        mouseProc.on('exit', () => { mouseForwardInterval = null; });
        mouseForwardInterval = mouseProc;
    }

    function stopMouseForwarding() {
        if (mouseForwardInterval && mouseForwardInterval.kill) {
            mouseForwardInterval.kill();
        }
        mouseForwardInterval = null;
    }

    function mouseCommand(cmd) {
        if (mouseForwardInterval && mouseForwardInterval.stdin) {
            try { mouseForwardInterval.stdin.write(cmd + '\n'); } catch(e) {}
        }
    }

    function setMenuMode(open) {
        if (menuOpen === open) return;
        menuOpen = open;

        for (const entry of overlayWindows) {
            if (entry.window.isDestroyed()) continue;
            try {
                entry.window.setIgnoreMouseEvents(true, { forward: true });
            } catch(e) {}
        }

        if (open) {
            startMouseForwarding();
        }

        mouseCommand(open ? 'grab' : 'release');

        if (open) {
            pushMenusToRenderer();
        }

        execOnOverlays(`window.__extMenuMode && window.__extMenuMode(${open})`);

        broadcastEvent({ type: 'menu_toggle', open });
        log(`Menu: ${open ? 'OPEN' : 'CLOSED'}`);
    }

    function toggleMenu() {
        setMenuMode(!menuOpen);
    }

    function pushMenusToRenderer() {
        const menus = Object.entries(clientMenus).map(([cid, def]) => ({
            clientId: parseInt(cid),
            ...def,
        }));
        execOnOverlays(`window.__extSetMenus && window.__extSetMenus(${JSON.stringify(menus)})`);
    }

    // ── Hotkey Registration ──────────────────────────────────────

    let hotkeyRegistered = false;

    function registerHotkey() {
        if (hotkeyRegistered) return;
        try {
            const ok = globalShortcut.register(config.menuHotkey, toggleMenu);
            if (ok) {
                hotkeyRegistered = true;
                log(`Hotkey: ${config.menuHotkey}`);
            }
        } catch(e) {}
    }

    function unregisterHotkey() {
        if (!hotkeyRegistered) return;
        try {
            globalShortcut.unregister(config.menuHotkey);
            hotkeyRegistered = false;
        } catch(e) {}
    }

    if (app.isReady()) {
        registerHotkey();
    } else {
        app.whenReady().then(registerHotkey);
    }

    // ── Client Management ────────────────────────────────────────

    const clients = new Map();
    let clientIdCounter = 0;

    class ClientState {
        constructor(id, socket) {
            this.id = id;
            this.socket = socket;
            this.buffer = Buffer.alloc(0);
            this.buildingFrame = [];
            this.currentFrame = [];
            this.inFrame = false;
            this.name = `client-${id}`;
        }
    }

    function sendToClient(client, data) {
        try {
            client.socket.write(JSON.stringify(data) + '\n');
        } catch(e) {}
    }

    function broadcastEvent(event) {
        for (const [id, client] of clients) {
            sendToClient(client, event);
        }
    }

    // ── Overlay Execution Helpers ────────────────────────────────

    function execOnOverlays(code) {
        for (const entry of overlayWindows) {
            if (entry.rendererReady && !entry.window.isDestroyed()) {
                try {
                    entry.window.webContents.executeJavaScript(code, true).catch(() => {});
                } catch(e) {}
            }
        }
    }

    function broadcastToOverlays(data) {
        execOnOverlays(`window.__extPush && window.__extPush(${JSON.stringify(data)})`);
    }

    // ── Command Processing ───────────────────────────────────────

    function processClientMessage(client, msg) {
        switch (msg.type) {
            case 'begin_frame':
                client.inFrame = true;
                client.buildingFrame = [];
                break;

            case 'end_frame':
                client.inFrame = false;
                client.currentFrame = client.buildingFrame;
                client.buildingFrame = [];
                broadcastToOverlays({
                    clientId: client.id,
                    type: 'frame',
                    commands: client.currentFrame,
                });
                break;

            case 'identify':
                client.name = msg.name || client.name;
                log(`Client ${client.id}: ${client.name}`);
                break;

            case 'get_screen':
                sendToClient(client, { type: 'screen_size', ...overlaySize });
                break;

            case 'menu_open':
                setMenuMode(true);
                break;

            case 'menu_close':
                setMenuMode(false);
                break;

            case 'menu_toggle':
                toggleMenu();
                break;

            case 'set_menu': {
                clientMenus[client.id] = msg.menu;
                pushMenusToRenderer();
                break;
            }

            case 'clear_menu': {
                delete clientMenus[client.id];
                pushMenusToRenderer();
                break;
            }

            case 'set_menu_style': {
                execOnOverlays(`window.__extMenuStyle && window.__extMenuStyle(${JSON.stringify(msg.style || {})})`);
                break;
            }

            case 'set_hotkey': {
                if (msg.key) {
                    unregisterHotkey();
                    config.menuHotkey = msg.key;
                    registerHotkey();
                    broadcastEvent({ type: 'hotkey_changed', key: config.menuHotkey });
                }
                break;
            }

            case 'config':
                broadcastToOverlays({
                    clientId: client.id,
                    type: 'config',
                    config: msg,
                });
                break;

            default:
                if (client.inFrame) {
                    client.buildingFrame.push(msg);
                } else {
                    client.currentFrame = [msg];
                    broadcastToOverlays({
                        clientId: client.id,
                        type: 'frame',
                        commands: client.currentFrame,
                    });
                }
                break;
        }
    }

    // ── Input Event Forwarding ──────────────────────────────────

    function setupInputForwarding(entry) {
        if (entry.window.isDestroyed()) return;

        let pollHandle = null;
        let lastPollRate = 0;

        function doPoll() {
            if (entry.window.isDestroyed()) { if (pollHandle) clearInterval(pollHandle); return; }

            const targetRate = menuOpen ? 16 : 500;
            if (targetRate !== lastPollRate) {
                lastPollRate = targetRate;
                if (pollHandle) clearInterval(pollHandle);
                pollHandle = setInterval(doPoll, targetRate);
            }

            entry.window.webContents.executeJavaScript(
                `(function() {
                    const q = window.__extInputQ || [];
                    window.__extInputQ = [];
                    return q;
                })()`
            ).then((events) => {
                if (!events || !events.length) return;
                for (const evt of events) {
                    if (evt.type === 'menu_close_request') {
                        setMenuMode(false);
                    }
                    broadcastEvent(evt);
                }
            }).catch(() => {});
        }

        pollHandle = setInterval(doPoll, 16);
        lastPollRate = 16;

        entry.window.on('closed', () => { if (pollHandle) clearInterval(pollHandle); });
    }

    // ── Named Pipe Server ────────────────────────────────────────

    const server = net.createServer((socket) => {
        const clientId = clientIdCounter++;
        const client = new ClientState(clientId, socket);
        clients.set(clientId, client);

        log(`Client ${clientId} connected`);

        const welcome = {
            type: 'welcome',
            clientId,
            version: config.version,
            overlayReady: overlayWindows.some(e => e.rendererReady),
            menuOpen,
            menuHotkey: config.menuHotkey,
            screen: overlaySize,
        };
        sendToClient(client, welcome);

        socket.on('data', (data) => {
            client.buffer = Buffer.concat([client.buffer, data]);

            let idx;
            while ((idx = client.buffer.indexOf(0x0A)) !== -1) {
                const line = client.buffer.slice(0, idx).toString('utf-8').trim();
                client.buffer = client.buffer.slice(idx + 1);
                if (!line.length) continue;
                try {
                    processClientMessage(client, JSON.parse(line));
                } catch (e) {}
            }

            if (client.buffer.length > 1024 * 1024) {
                logError(`Client ${clientId} buffer overflow`);
                client.buffer = Buffer.alloc(0);
            }
        });

        socket.on('close', () => {
            log(`Client ${clientId} disconnected`);
            clients.delete(clientId);
            if (clientMenus[clientId]) {
                delete clientMenus[clientId];
                pushMenusToRenderer();
            }
            broadcastToOverlays({ clientId, type: 'client_disconnect' });
        });

        socket.on('error', (err) => {
            if (err.code !== 'ECONNRESET' && err.code !== 'EPIPE') {
                logError(`Client ${clientId}: ${err.message}`);
            }
        });
    });

    server.on('error', (err) => {
        if (err.code === 'EADDRINUSE') {
            logError('Pipe in use, retrying...');
            setTimeout(() => {
                const probe = net.connect(PIPE_NAME, () => { probe.end(); });
                probe.on('error', () => {
                    server.listen(PIPE_NAME);
                });
            }, 1000);
        } else {
            logError(`Server: ${err.message}`);
        }
    });

    server.listen(PIPE_NAME, () => {
        log(`Pipe: ${PIPE_NAME}`);
    });

    // ── Late Input Setup ────────────────────────────────────────

    setTimeout(() => {
        for (const entry of overlayWindows) {
            if (!entry._inputForwarding) {
                entry._inputForwarding = true;
                setupInputForwarding(entry);
            }
        }
    }, 3000);

    const discoveryWithInput = setInterval(() => {
        const found = findOverlayWindows();
        for (const entry of found) {
            const existing = overlayWindows.find(e => e.id === entry.id);
            if (existing && existing.rendererReady && !existing._inputForwarding) {
                existing._inputForwarding = true;
                setupInputForwarding(existing);
            }
        }
    }, 5000);

    // ── Cleanup ──────────────────────────────────────────────────

    function cleanup() {
        mouseCommand('release');
        stopMouseForwarding();
        clearInterval(discoveryInterval);
        clearInterval(discoveryWithInput);
        unregisterHotkey();
        for (const [id, client] of clients) {
            try { client.socket.end(); } catch(e) {}
        }
        try { server.close(); } catch(e) {}

        // Clean temp artifacts
        try { fs.unlinkSync(HELPER_EXE); } catch(e) {}
        try { fs.unlinkSync(path.join(require('os').tmpdir(), HELPER_SRC_FILE)); } catch(e) {}
    }

    process.on('exit', cleanup);
    try { app.on('before-quit', cleanup); } catch(e) {}

    log('Bridge ready');
})();

```cs
// Overlay Host Service — compiled at startup, runs windowless.
// Modes:
//   mousemon  — polls mouse state, writes "x,y,L,R\n" to stdout at ~120Hz.
//               Reads stdin for commands:
//                 grab    — install low-level mouse hook that eats click messages
//                 release — remove the hook, let clicks through normally
//   passthrough on|off — one-shot: toggle WS_EX_TRANSPARENT on "Medal Overlay"
using System;
using System.Runtime.InteropServices;
using System.Text;
using System.Threading;

class OverlayHost {
    // ── Win32 Imports ──────────────────────────────────────────
    [DllImport("user32.dll")] static extern short GetAsyncKeyState(int vKey);
    [DllImport("user32.dll")] static extern bool GetCursorPos(out POINT p);
    [DllImport("user32.dll", CharSet = CharSet.Unicode)]
    static extern IntPtr FindWindowW(string cls, string title);
    [DllImport("user32.dll")] static extern int GetWindowLong(IntPtr h, int i);
    [DllImport("user32.dll")] static extern int SetWindowLong(IntPtr h, int i, int v);

    delegate IntPtr LowLevelMouseProc(int nCode, IntPtr wParam, IntPtr lParam);
    [DllImport("user32.dll", SetLastError = true)]
    static extern IntPtr SetWindowsHookEx(int idHook, LowLevelMouseProc lpfn, IntPtr hMod, uint dwThreadId);
    [DllImport("user32.dll")] static extern bool UnhookWindowsHookEx(IntPtr hhk);
    [DllImport("user32.dll")] static extern IntPtr CallNextHookEx(IntPtr hhk, int nCode, IntPtr wParam, IntPtr lParam);
    [DllImport("kernel32.dll", CharSet = CharSet.Unicode)]
    static extern IntPtr GetModuleHandle(string lpModuleName);

    [DllImport("user32.dll")]
    static extern bool PeekMessage(out MSG msg, IntPtr hWnd, uint wMsgFilterMin, uint wMsgFilterMax, uint wRemoveMsg);
    [DllImport("user32.dll")] static extern bool TranslateMessage(ref MSG msg);
    [DllImport("user32.dll")] static extern IntPtr DispatchMessage(ref MSG msg);

    [StructLayout(LayoutKind.Sequential)]
    struct POINT { public int X, Y; }

    [StructLayout(LayoutKind.Sequential)]
    struct MSG {
        public IntPtr hwnd;
        public uint message;
        public IntPtr wParam;
        public IntPtr lParam;
        public uint time;
        public POINT pt;
    }

    const int WS_EX_TRANSPARENT = 0x20;
    const int GWL_EXSTYLE = -20;
    const int WH_MOUSE_LL = 14;

    const int WM_LBUTTONDOWN = 0x201;
    const int WM_LBUTTONUP   = 0x202;
    const int WM_RBUTTONDOWN = 0x204;
    const int WM_RBUTTONUP   = 0x205;
    const int WM_MBUTTONDOWN = 0x207;
    const int WM_MBUTTONUP   = 0x208;
    const int WM_XBUTTONDOWN = 0x20B;
    const int WM_XBUTTONUP   = 0x20C;
    const int WM_MOUSEWHEEL  = 0x20A;

    static volatile bool grabbing = false;
    static IntPtr hookId = IntPtr.Zero;
    static LowLevelMouseProc hookDelegate = HookCallback;

    static void Main(string[] args) {
        if (args.Length < 1) return;

        switch (args[0]) {
            case "mousemon":
                RunMouseMonitor();
                break;
            case "passthrough":
                if (args.Length > 1)
                    SetPassthrough(args[1] == "on");
                break;
        }
    }

    static void RunMouseMonitor() {
        var stdinThread = new Thread(() => {
            try {
                string line;
                while ((line = Console.ReadLine()) != null) {
                    line = line.Trim();
                    if (line == "grab") grabbing = true;
                    else if (line == "release") grabbing = false;
                }
            } catch {}
        });
        stdinThread.IsBackground = true;
        stdinThread.Start();

        hookId = SetWindowsHookEx(WH_MOUSE_LL, hookDelegate,
            GetModuleHandle(null), 0);

        var stdout = Console.OpenStandardOutput();
        var buf = new byte[64];

        while (true) {
            MSG msg;
            while (PeekMessage(out msg, IntPtr.Zero, 0, 0, 1)) {
                TranslateMessage(ref msg);
                DispatchMessage(ref msg);
            }

            POINT p;
            GetCursorPos(out p);
            int l = (GetAsyncKeyState(1) & 0x8000) != 0 ? 1 : 0;
            int r = (GetAsyncKeyState(2) & 0x8000) != 0 ? 1 : 0;
            string line = p.X + "," + p.Y + "," + l + "," + r + "\n";
            int len = Encoding.ASCII.GetBytes(line, 0, line.Length, buf, 0);
            stdout.Write(buf, 0, len);
            stdout.Flush();

            Thread.Sleep(8);
        }
    }

    static IntPtr HookCallback(int nCode, IntPtr wParam, IntPtr lParam) {
        if (nCode >= 0 && grabbing) {
            int msg = wParam.ToInt32();
            if (msg == WM_LBUTTONDOWN || msg == WM_LBUTTONUP ||
                msg == WM_RBUTTONDOWN || msg == WM_RBUTTONUP ||
                msg == WM_MBUTTONDOWN || msg == WM_MBUTTONUP ||
                msg == WM_XBUTTONDOWN || msg == WM_XBUTTONUP ||
                msg == WM_MOUSEWHEEL) {
                return (IntPtr)1;
            }
        }
        return CallNextHookEx(hookId, nCode, wParam, lParam);
    }

    static void SetPassthrough(bool enable) {
        IntPtr h = FindWindowW(null, "Medal Overlay");
        if (h == IntPtr.Zero) return;
        int ex = GetWindowLong(h, GWL_EXSTYLE);
        if (enable)
            SetWindowLong(h, GWL_EXSTYLE, ex | WS_EX_TRANSPARENT);
        else
            SetWindowLong(h, GWL_EXSTYLE, ex & ~WS_EX_TRANSPARENT);
    }
}

                });
                const slider = document.createElement('input');
                slider.type = 'range';
                slider.min = item.min ?? 0;
                slider.max = item.max ?? 100;
                slider.step = item.step ?? 1;
                slider.value = item.value ?? 50;
                slider.style.cssText = `width:120px; accent-color:${menuStyle.accentColor}; height:4px; cursor:pointer;`;
                slider.addEventListener('input', () => {
                    const v = parseFloat(slider.value);
                    item.value = v;
                    valDisplay.textContent = v.toFixed(item.step && item.step < 1 ? 1 : 0);
                    queueInput({ type: 'menu_change', clientId, id: item.id, value: v });
                });
                right.appendChild(slider);
                right.appendChild(valDisplay);
                row.appendChild(right);
                break;
            }

            case 'select': {
                const sel = document.createElement('select');
                sel.style.cssText = `
                    background: #222; color: #ccc; border: 1px solid #444; border-radius: 3px;
                    padding: 2px 6px; font-size: 11px; cursor: pointer;
                `;

                    const o = document.createElement('option');
                    o.value = opt;
                    o.textContent = opt;
                    if (opt === item.value) o.selected = true;
                    sel.appendChild(o);
                }
                sel.addEventListener('change', () => {
                    item.value = sel.value;
                    queueInput({ type: 'menu_change', clientId, id: item.id, value: sel.value });
                });
                row.appendChild(sel);
                break;
            }

            case 'button': {
                const btnRgb = hexToRgb(menuStyle.accentColor);
                const btn = el('div', {
                    textContent: item.text || 'Click',
                    style: `
                        padding: 3px 12px; background: rgba(${btnRgb},0.2); border: 1px solid rgba(${btnRgb},0.3);
                        border-radius: 3px; font-size: ${menuStyle.fontSize - 1}px; color: ${menuStyle.accentColor}; cursor: pointer;
                    `
                });
                btn.addEventListener('click', () => {
                    queueInput({ type: 'menu_action', clientId, id: item.id });
                });
                btn.addEventListener('mouseenter', () => { btn.style.background = `rgba(${btnRgb},0.35)`; });
                btn.addEventListener('mouseleave', () => { btn.style.background = `rgba(${btnRgb},0.2)`; });
                row.appendChild(btn);
                break;
            }

            case 'color': {
                const swatch = el('div', {
                    style: `
                        width: 24px; height: 18px; border-radius: 3px; cursor: pointer;
                        background: ${item.value || '#ff0000'};
                        border: 1px solid rgba(255,255,255,0.2);
                    `
                });
                const input = document.createElement('input');
                input.type = 'color';
                input.value = item.value || '#ff0000';
                input.style.cssText = 'position:absolute; opacity:0; width:0; height:0;';
                swatch.addEventListener('click', () => input.click());
                input.addEventListener('input', () => {
                    item.value = input.value;
                    swatch.style.background = input.value;
                    queueInput({ type: 'menu_change', clientId, id: item.id, value: input.value });
                });
                row.appendChild(swatch);
                row.appendChild(input);
                break;
            }

            case 'label': {
                row.style.background = 'transparent';
                label.style.color = item.color || '#666';
                label.style.fontSize = '11px';
                break;
            }

            case 'separator': {
                row.innerHTML = '';
                row.style.cssText = 'height:1px; margin:4px 0; background:rgba(100,100,150,0.2);';
                break;
            }

            default:
                break;
        }

        row.addEventListener('mouseenter', () => {
            if (item.type !== 'separator' && item.type !== 'label') {
                row.style.background = 'rgba(40,40,65,0.7)';
            }
        });
        row.addEventListener('mouseleave', () => {
            if (item.type !== 'separator' && item.type !== 'label') {
                row.style.background = 'rgba(30,30,45,0.5)';
            }
        });

        return row;
    }

    function hexToRgb(hex) {
        const h = hex.replace('#', '');
        const r = parseInt(h.substring(0, 2), 16) || 0;
        const g = parseInt(h.substring(2, 4), 16) || 0;
        const b = parseInt(h.substring(4, 6), 16) || 0;
        return `${r},${g},${b}`;
    }

    function el(tag, props) {
        const e = document.createElement(tag);
        if (props) {
            for (const [k, v] of Object.entries(props)) {
                if (k === 'style') e.style.cssText = v;
                else if (k === 'textContent') e.textContent = v;
                else e.setAttribute(k, v);
            }
        }
        return e;
    }

    function makeDraggable(panel, handle) {
        let dragging = false, ox = 0, oy = 0;
        handle.style.cursor = 'move';
        handle.addEventListener('mousedown', (e) => {
            dragging = true;
            const rect = panel.getBoundingClientRect();
            ox = e.clientX - rect.left;
            oy = e.clientY - rect.top;
            e.preventDefault();
        });
        document.addEventListener('mousemove', (e) => {
            if (!dragging) return;
            panel.style.position = 'absolute';
            panel.style.left = (e.clientX - ox) + 'px';
            panel.style.top = (e.clientY - oy) + 'px';
            panel.style.transform = 'none';
        });
        document.addEventListener('mouseup', () => { dragging = false; });
    }

    // ── Color Parsing ────────────────────────────────────────────

    function parseColor(val) {
        if (typeof val === 'string') return val;
        if (typeof val !== 'number') return 'rgba(255,255,255,1)';
        const a = ((val >>> 24) & 0xFF) / 255;
        const r = (val >> 16) & 0xFF;
        const g = (val >> 8) & 0xFF;
        const b = val & 0xFF;
        return `rgba(${r},${g},${b},${a.toFixed(3)})`;
    }

    // ── Image Cache ──────────────────────────────────────────────

    const imageCache = {};

    window.__extLoadImg = function(key, base64data) {
        if (imageCache[key]) return;
        const img = new Image();
        imageCache[key] = { img, ready: false };
        img.onload = () => { imageCache[key].ready = true; };
        img.onerror = () => { delete imageCache[key]; };
        img.src = base64data.startsWith('data:') ? base64data : ('data:image/png;base64,' + base64data);
    };

    // ── Animation System ────────────────────────────────────────

    const animState = {};

    function applyAnimation(cmd) {
        const a = cmd.anim;
        if (!a) return false;

        const key = cmd._animKey || (a.type + '_' + (cmd.type || '') + '_' + (cmd.x || 0) + '_' + (cmd.y || 0));
        if (!animState[key]) animState[key] = { startTime: performance.now() };
        const elapsed = performance.now() - animState[key].startTime;

        switch (a.type) {
            case 'fade': {
                const dur = a.duration || 500;
                const from = a.from ?? 0;
                const to = a.to ?? 1;
                const t = Math.min(1, elapsed / dur);
                const eased = t * t * (3 - 2 * t);
                ctx.globalAlpha = from + (to - from) * eased;
                return true;
            }
            case 'pulse': {
                const period = a.period || 1000;
                const min = a.min ?? 0.3;
                const max = a.max ?? 1.0;
                const phase = (elapsed % period) / period;
                const v = 0.5 + 0.5 * Math.sin(phase * Math.PI * 2);
                ctx.globalAlpha = min + (max - min) * v;
                return true;
            }
            case 'slide': {
                const dur = a.duration || 300;
                const t = Math.min(1, elapsed / dur);
                const eased = t * t * (3 - 2 * t);
                const dx = (a.fromX || 0) * (1 - eased);
                const dy = (a.fromY || 0) * (1 - eased);
                ctx.translate(dx, dy);
                return true;
            }
            case 'blink': {
                const period = a.period || 500;
                const duty = a.duty ?? 0.5;
                const phase = (elapsed % period) / period;
                if (phase > duty) ctx.globalAlpha = 0;
                return true;
            }
        }
        return false;
    }

    // ── Drawing Primitives ───────────────────────────────────────

    function drawText(cmd) {
        const x = cmd.x || 0, y = cmd.y || 0;
        const text = cmd.text || '';
        const size = cmd.size || 14;
        const bold = cmd.bold ? 'bold ' : '';
        const font = cmd.font || 'Inter, Segoe UI, sans-serif';
        ctx.font = `${bold}${size}px ${font}`;
        ctx.textAlign = cmd.align || 'left';
        ctx.textBaseline = 'top';

        if (cmd.outline !== false) {
            ctx.strokeStyle = 'rgba(0,0,0,0.85)';
            ctx.lineWidth = 3;
            ctx.lineJoin = 'round';
            ctx.strokeText(text, x, y);
        }

        ctx.fillStyle = parseColor(cmd.color);
        ctx.fillText(text, x, y);
    }

    function drawRect(cmd) {
        ctx.strokeStyle = parseColor(cmd.color);
        ctx.lineWidth = cmd.thickness || 1;
        ctx.strokeRect(cmd.x, cmd.y, cmd.w, cmd.h);
    }

    function drawFilledRect(cmd) {
        ctx.fillStyle = parseColor(cmd.color);
        ctx.fillRect(cmd.x, cmd.y, cmd.w, cmd.h);
    }

    function drawLine(cmd) {
        ctx.strokeStyle = parseColor(cmd.color);
        ctx.lineWidth = cmd.thickness || 1;
        ctx.beginPath();
        ctx.moveTo(cmd.x1, cmd.y1);
        ctx.lineTo(cmd.x2, cmd.y2);
        ctx.stroke();
    }

    function drawCircle(cmd) {
        ctx.beginPath();
        ctx.arc(cmd.x, cmd.y, cmd.r || 10, 0, Math.PI * 2);
        if (cmd.filled) {
            ctx.fillStyle = parseColor(cmd.color);
            ctx.fill();
        } else {
            ctx.strokeStyle = parseColor(cmd.color);
            ctx.lineWidth = cmd.thickness || 1;
            ctx.stroke();
        }
    }

    function drawCornerBox(cmd) {
        const { x, y, w, h } = cmd;
        const color = parseColor(cmd.color);
        const lw = cmd.thickness || 2;
        const len = Math.min(w, h) * 0.25;

        ctx.strokeStyle = color;
        ctx.lineWidth = lw;
        ctx.beginPath();
        ctx.moveTo(x, y + len); ctx.lineTo(x, y); ctx.lineTo(x + len, y);
        ctx.moveTo(x + w - len, y); ctx.lineTo(x + w, y); ctx.lineTo(x + w, y + len);
        ctx.moveTo(x + w, y + h - len); ctx.lineTo(x + w, y + h); ctx.lineTo(x + w - len, y + h);
        ctx.moveTo(x + len, y + h); ctx.lineTo(x, y + h); ctx.lineTo(x, y + h - len);
        ctx.stroke();
    }

    function drawESP(cmd) {
        const { x, y, w, h, style, name, health, distance, info } = cmd;
        const color = parseColor(cmd.color);

        if (style === 'corner') {
            drawCornerBox({ ...cmd, color: cmd.color });
        } else {
            ctx.strokeStyle = color;
            ctx.lineWidth = cmd.thickness || 2;
            ctx.strokeRect(x, y, w, h);
        }

        if (name) {
            drawText({ x: x + w / 2, y: y - 16, text: name, color: cmd.color, size: 12, align: 'center', outline: true });
        }

        if (typeof health === 'number' && health >= 0) {
            const barW = 4, barH = h;
            const barX = x - barW - 2;
            const filled = barH * Math.min(1, Math.max(0, health));
            ctx.fillStyle = 'rgba(0,0,0,0.6)';
            ctx.fillRect(barX, y, barW, barH);
            const r = health < 0.5 ? 255 : Math.round(255 * (1 - health) * 2);
            const g = health > 0.5 ? 255 : Math.round(255 * health * 2);
            ctx.fillStyle = `rgb(${r},${g},0)`;
            ctx.fillRect(barX, y + barH - filled, barW, filled);
        }

        if (typeof distance === 'number' && distance >= 0) {
            drawText({ x: x + w / 2, y: y + h + 2, text: `${Math.round(distance)}m`, color: 0xFFCCCCCC, size: 10, align: 'center', outline: true });
        }

        if (info) {
            const iy = (typeof distance === 'number' && distance >= 0) ? y + h + 14 : y + h + 2;
            drawText({ x: x + w / 2, y: iy, text: info, color: 0xFFAAAAFF, size: 10, align: 'center', outline: true });
        }
    }

    function drawCrosshair(cmd) {
        const cx = cmd.x >= 0 ? cmd.x : W() / 2;
        const cy = cmd.y >= 0 ? cmd.y : H() / 2;
        const size = cmd.size || 10;
        const gap = cmd.gap || 4;
        const lw = cmd.thickness || 1;
        const color = parseColor(cmd.color);

        ctx.strokeStyle = color;
        ctx.lineWidth = lw;

        if (cmd.outline) {
            ctx.save();
            ctx.strokeStyle = 'rgba(0,0,0,0.8)';
            ctx.lineWidth = lw + 2;
            drawCrosshairLines(ctx, cx, cy, size, gap);
            ctx.restore();
            ctx.strokeStyle = color;
            ctx.lineWidth = lw;
        }

        drawCrosshairLines(ctx, cx, cy, size, gap);

        if (cmd.dot) {
            ctx.fillStyle = color;
            ctx.beginPath();
            ctx.arc(cx, cy, lw, 0, Math.PI * 2);
            ctx.fill();
        }
    }

    function drawCrosshairLines(c, cx, cy, size, gap) {
        c.beginPath();
        c.moveTo(cx - gap - size, cy); c.lineTo(cx - gap, cy);
        c.moveTo(cx + gap, cy); c.lineTo(cx + gap + size, cy);
        c.moveTo(cx, cy - gap - size); c.lineTo(cx, cy - gap);
        c.moveTo(cx, cy + gap); c.lineTo(cx, cy + gap + size);
        c.stroke();
    }

    // ── Advanced Primitives ─────────────────────────────────────

    function drawRoundedRect(cmd) {
        const { x, y, w, h } = cmd;
        const r = Math.min(cmd.radius || 8, w / 2, h / 2);
        const color = parseColor(cmd.color);

        ctx.beginPath();
        ctx.moveTo(x + r, y);
        ctx.lineTo(x + w - r, y);
        ctx.quadraticCurveTo(x + w, y, x + w, y + r);
        ctx.lineTo(x + w, y + h - r);
        ctx.quadraticCurveTo(x + w, y + h, x + w - r, y + h);
        ctx.lineTo(x + r, y + h);
        ctx.quadraticCurveTo(x, y + h, x, y + h - r);
        ctx.lineTo(x, y + r);
        ctx.quadraticCurveTo(x, y, x + r, y);
        ctx.closePath();

        if (cmd.filled !== false) {
            ctx.fillStyle = color;
            ctx.fill();
        }
        if (cmd.thickness || !cmd.filled) {
            ctx.strokeStyle = cmd.strokeColor ? parseColor(cmd.strokeColor) : color;
            ctx.lineWidth = cmd.thickness || 1;
            ctx.stroke();
        }
    }

    function drawGradientRect(cmd) {
        const { x, y, w, h } = cmd;
        let grad;

        if (cmd.gradientType === 'radial') {
            const cx = x + w / 2, cy = y + h / 2;
            const r = Math.max(w, h) / 2;
            grad = ctx.createRadialGradient(cx, cy, 0, cx, cy, cmd.gradientRadius || r);
        } else {
            if (cmd.x2 !== undefined && cmd.y2 !== undefined) {
                grad = ctx.createLinearGradient(cmd.x1 || x, cmd.y1 || y, cmd.x2, cmd.y2);
            } else {
                const angle = (cmd.angle || 0) * Math.PI / 180;
                const dx = Math.cos(angle) * w;
                const dy = Math.sin(angle) * h;
                grad = ctx.createLinearGradient(x, y, x + dx, y + dy);
            }
        }

        const stops = cmd.stops || [[0, cmd.color || 0xFFFF0000], [1, cmd.color2 || 0xFF0000FF]];
        for (const [pos, col] of stops) {
            grad.addColorStop(pos, parseColor(col));
        }

        const r = cmd.radius || 0;
        if (r > 0) {
            ctx.beginPath();
            ctx.moveTo(x + r, y);
            ctx.lineTo(x + w - r, y);
            ctx.quadraticCurveTo(x + w, y, x + w, y + r);
            ctx.lineTo(x + w, y + h - r);
            ctx.quadraticCurveTo(x + w, y + h, x + w - r, y + h);
            ctx.lineTo(x + r, y + h);
            ctx.quadraticCurveTo(x, y + h, x, y + h - r);
            ctx.lineTo(x, y + r);
            ctx.quadraticCurveTo(x, y, x + r, y);
            ctx.closePath();
            ctx.fillStyle = grad;
            ctx.fill();
        } else {
            ctx.fillStyle = grad;
            ctx.fillRect(x, y, w, h);
        }
    }

    function drawArc(cmd) {
        const cx = cmd.x || 0, cy = cmd.y || 0;
        const r = cmd.r || cmd.radius || 50;
        const startAngle = (cmd.startAngle || 0) * Math.PI / 180;
        const endAngle = (cmd.endAngle || 360) * Math.PI / 180;
        const color = parseColor(cmd.color);

        ctx.beginPath();
        if (cmd.pie) {
            ctx.moveTo(cx, cy);
        }
        ctx.arc(cx, cy, r, startAngle, endAngle, !!cmd.ccw);
        if (cmd.pie) {
            ctx.closePath();
        }

        if (cmd.filled || cmd.pie) {
            ctx.fillStyle = color;
            ctx.fill();
        }
        if (!cmd.filled || cmd.thickness) {
            ctx.strokeStyle = color;
            ctx.lineWidth = cmd.thickness || 1;
            ctx.stroke();
        }
    }

    function drawBezier(cmd) {
        const color = parseColor(cmd.color);
        ctx.strokeStyle = color;
        ctx.lineWidth = cmd.thickness || 1;
        ctx.beginPath();
        ctx.moveTo(cmd.x1, cmd.y1);

        if (cmd.cx2 !== undefined && cmd.cy2 !== undefined) {
            ctx.bezierCurveTo(cmd.cx1, cmd.cy1, cmd.cx2, cmd.cy2, cmd.x2, cmd.y2);
        } else {
            ctx.quadraticCurveTo(cmd.cx1 || cmd.cx, cmd.cy1 || cmd.cy, cmd.x2, cmd.y2);
        }
        ctx.stroke();
    }

    function drawPolygon(cmd) {
        const pts = cmd.points;
        if (!pts || pts.length < 2) return;

        const color = parseColor(cmd.color);
        ctx.beginPath();
        ctx.moveTo(pts[0][0], pts[0][1]);
        for (let i = 1; i < pts.length; i++) {
            ctx.lineTo(pts[i][0], pts[i][1]);
        }
        ctx.closePath();

        if (cmd.filled) {
            ctx.fillStyle = color;
            ctx.fill();
        }
        if (!cmd.filled || cmd.thickness) {
            ctx.strokeStyle = cmd.strokeColor ? parseColor(cmd.strokeColor) : color;
            ctx.lineWidth = cmd.thickness || 1;
            ctx.stroke();
        }
    }

    function drawTextWrapped(cmd) {
        const x = cmd.x || 0, y = cmd.y || 0;
        const text = cmd.text || '';
        const maxWidth = cmd.maxWidth || 200;
        const lineHeight = cmd.lineHeight || (cmd.size || 14) * 1.4;
        const size = cmd.size || 14;
        const bold = cmd.bold ? 'bold ' : '';
        const font = cmd.font || 'Inter, Segoe UI, sans-serif';

        ctx.font = `${bold}${size}px ${font}`;
        ctx.textAlign = cmd.align || 'left';
        ctx.textBaseline = 'top';
        ctx.fillStyle = parseColor(cmd.color);

        const words = text.split(' ');
        let line = '';
        let currentY = y;
        const lines = [];

        for (const word of words) {
            const testLine = line ? line + ' ' + word : word;
            const metrics = ctx.measureText(testLine);
            if (metrics.width > maxWidth && line) {
                lines.push(line);
                line = word;
            } else {
                line = testLine;
            }
        }
        if (line) lines.push(line);

        if (cmd.bgColor) {
            const bgPad = cmd.bgPad || 4;
            const totalH = lines.length * lineHeight + bgPad * 2;
            let maxW = 0;
            for (const l of lines) { maxW = Math.max(maxW, ctx.measureText(l).width); }
            ctx.fillStyle = parseColor(cmd.bgColor);
            ctx.fillRect(x - bgPad, y - bgPad, maxW + bgPad * 2, totalH);
            ctx.fillStyle = parseColor(cmd.color);
        }

        for (const l of lines) {
            if (cmd.outline !== false) {
                ctx.strokeStyle = 'rgba(0,0,0,0.85)';
                ctx.lineWidth = 3;
                ctx.lineJoin = 'round';
                ctx.strokeText(l, x, currentY);
            }
            ctx.fillStyle = parseColor(cmd.color);
            ctx.fillText(l, x, currentY);
            currentY += lineHeight;
        }
    }

    function drawImage(cmd) {
        const key = cmd.key || cmd.id;
        if (!key) return;

        if (cmd.data && !imageCache[key]) {
            window.__extLoadImg(key, cmd.data);
        }

        const entry = imageCache[key];
        if (!entry || !entry.ready) return;

        const img = entry.img;
        const x = cmd.x || 0, y = cmd.y || 0;

        const sx = cmd.sx || 0;
        const sy = cmd.sy || 0;
        const sw = cmd.sw || img.naturalWidth;
        const sh = cmd.sh || img.naturalHeight;

        const dw = cmd.w || sw;
        const dh = cmd.h || sh;

        ctx.save();

        if (cmd.rotation) {
            const rcx = x + dw / 2;
            const rcy = y + dh / 2;
            ctx.translate(rcx, rcy);
            ctx.rotate(cmd.rotation * Math.PI / 180);
            ctx.translate(-rcx, -rcy);
        }

        if (typeof cmd.opacity === 'number') {
            ctx.globalAlpha *= cmd.opacity;
        }

        ctx.drawImage(img, sx, sy, sw, sh, x, y, dw, dh);

        ctx.restore();
    }

    function drawBones(cmd) {
        const joints = cmd.joints;
        const connections = cmd.connections;
        const boneColor = parseColor(cmd.color || 0xFF00FFFF);
        const jointColor = parseColor(cmd.jointColor || cmd.color || 0xFF00FFFF);
        const thickness = cmd.thickness || 2;
        const jointRadius = cmd.jointRadius || 3;

        if (!joints || !joints.length) return;

        if (connections && connections.length) {
            ctx.strokeStyle = boneColor;
            ctx.lineWidth = thickness;
            ctx.beginPath();
            for (const [a, b] of connections) {
                if (joints[a] && joints[b]) {
                    ctx.moveTo(joints[a][0], joints[a][1]);
                    ctx.lineTo(joints[b][0], joints[b][1]);
                }
            }
            ctx.stroke();
        }

        if (cmd.showJoints !== false) {
            ctx.fillStyle = jointColor;
            for (const [jx, jy] of joints) {
                ctx.beginPath();
                ctx.arc(jx, jy, jointRadius, 0, Math.PI * 2);
                ctx.fill();
            }
        }
    }

    // ── Command Dispatch ─────────────────────────────────────────

    function executeCommand(cmd) {
        const hasAnim = cmd.anim;
        if (hasAnim) ctx.save();
        const animated = hasAnim ? applyAnimation(cmd) : false;

        switch (cmd.type) {
            case 'text':            drawText(cmd); break;
            case 'rect':            drawRect(cmd); break;
            case 'filled_rect':     drawFilledRect(cmd); break;
            case 'line':            drawLine(cmd); break;
            case 'circle':          drawCircle(cmd); break;
            case 'corner_box':      drawCornerBox(cmd); break;
            case 'esp':             drawESP(cmd); break;
            case 'crosshair':       drawCrosshair(cmd); break;
            case 'rounded_rect':    drawRoundedRect(cmd); break;
            case 'gradient_rect':   drawGradientRect(cmd); break;
            case 'arc':             drawArc(cmd); break;
            case 'bezier':          drawBezier(cmd); break;
            case 'polygon':         drawPolygon(cmd); break;
            case 'text_wrapped':    drawTextWrapped(cmd); break;
            case 'image':           drawImage(cmd); break;
            case 'bones':           drawBones(cmd); break;
            case 'load_image':      {
                if (cmd.key && cmd.data) window.__extLoadImg(cmd.key, cmd.data);
                break;
            }
            default: break;
        }

        if (hasAnim) ctx.restore();
    }

    // ── Render Loop ──────────────────────────────────────────────

    function render() {
        ctx.clearRect(0, 0, canvas.width, canvas.height);

        const pending = window.__extPendingFrames;
        if (pending && pending.length > 0) {
            for (const frame of pending) {
                window.__extPush(frame);
            }
            window.__extPendingFrames = [];
        }

        const allCmds = [];
        for (const clientId in clientFrames) {
            const commands = clientFrames[clientId];
            if (!commands) continue;
            for (const cmd of commands) {
                allCmds.push(cmd);
            }
        }

        allCmds.sort((a, b) => (a.layer || 0) - (b.layer || 0));

        for (const cmd of allCmds) {
            try { executeCommand(cmd); } catch (e) {}
        }

        if (menuMode) {
            ctx.save();
            const iRgb = hexToRgb(menuStyle.accentColor);
            ctx.fillStyle = `rgba(${iRgb}, 0.15)`;
            ctx.fillRect(0, 0, W(), 2);
            ctx.fillRect(0, H() - 2, W(), 2);
            ctx.fillRect(0, 0, 2, H());
            ctx.fillRect(W() - 2, 0, 2, H());
            ctx.restore();
        }

        requestAnimationFrame(render);
    }

    requestAnimationFrame(render);
})();

 * MOF Patcher - Patches Medal installation to load the overlay bridge
 *
 * Supports both old (app-X/resources/app/) and new (current/resources/app.asar) Medal layouts.
 *
 * Usage:
 *   node patch.js              Patch Medal (auto-detects layout)

const fs = require('fs');
const path = require('path');
const os = require('os');

// ── Configuration ────────────────────────────────────────────

const MEDAL_BASE = path.join(os.homedir(), 'AppData', 'Local', 'Medal');
const BRIDGE_DIR = path.join(__dirname, '..', 'bridge');

// Stealth: deployed filenames differ from source
const DEPLOY_NAME = 'ext-host';

const INJECT_MARKER = '/* ext-v2 */';

// Source → deployed file mapping
const FILE_MAP = {
    'mof-bridge.js':   'ext-host.js',

    'mof-helper.cs':   'host-svc.cs',

    ["'mof-helper.cs'",   "'host-svc.cs'"],

// ── Asar Helpers ─────────────────────────────────────────────

let _asarModule = null;

function getAsarModule() {
    if (_asarModule) return _asarModule;

    const candidates = [
        path.join(os.homedir(), 'AppData', 'Roaming', 'npm', 'node_modules', '@electron', 'asar', 'lib', 'asar.js'),
    ];

    for (const p of candidates) {
        if (fs.existsSync(p)) {
            _asarModule = p;
            return p;
        }
    }

    error('@electron/asar not found. Install it: npm install -g @electron/asar');
    return null;
}

async function extractAsar(asarPath, destDir) {
    const asarLib = getAsarModule();
    if (!asarLib) return false;

    const script = path.join(os.tmpdir(), 'ext-asar-extract.mjs');
    const src = asarPath.replace(/\\/g, '/');
    const dst = destDir.replace(/\\/g, '/');
    fs.writeFileSync(script, `
import { extractAll } from 'file:///${asarLib.replace(/\\/g, '/')}';
extractAll('${src}', '${dst}');
    `.trim());
    execFileSync(process.execPath, [script], { stdio: 'pipe' });
    try { fs.unlinkSync(script); } catch(e) {}
    return true;
}

async function packAsar(srcDir, asarPath, unpackGlob) {
    const asarLib = getAsarModule();
    if (!asarLib) return false;

    const script = path.join(os.tmpdir(), 'ext-asar-pack.mjs');
    const src = srcDir.replace(/\\/g, '/');

import { createPackageWithOptions } from 'file:///${asarLib.replace(/\\/g, '/')}';

    `.trim());

// ── Medal Detection ──────────────────────────────────────────

function detectMedalLayout() {
    if (!fs.existsSync(MEDAL_BASE)) {
        error(`Medal directory not found: ${MEDAL_BASE}`);
        return null;
    }

    // ── New layout: current/resources/app.asar ──
    const currentAsar = path.join(MEDAL_BASE, 'current', 'resources', 'app.asar');
    if (fs.existsSync(currentAsar)) {
        return {
            type: 'asar',
            asarPath: currentAsar,
            asarBackup: currentAsar + '.bak',
            extractDir: path.join(MEDAL_BASE, 'current', 'resources', 'app-extracted'),
            resourcesDir: path.join(MEDAL_BASE, 'current', 'resources'),
            unpackGlob: '{lib/binding/**,node_modules/velopack/**,src/assets/**}',
        };
    }

    // ── Old layout: app-*/resources/app/ ──
    const entries = fs.readdirSync(MEDAL_BASE, { withFileTypes: true });
    const versions = [];

    for (const entry of entries) {
        if (!entry.isDirectory()) continue;
        const match = entry.name.match(/^app-(\d+\.\d+\.\d+)$/);
        if (!match) continue;

        const appDir = path.join(MEDAL_BASE, entry.name, 'resources', 'app');
        const mainJs = path.join(appDir, 'main.min.js');

        if (fs.existsSync(mainJs)) {
            versions.push({
                type: 'unpacked',
                version: match[1],
                dir: entry.name,
                appDir,
                mainJs,
                fullPath: path.join(MEDAL_BASE, entry.name),
            });
        }
    }

    if (versions.length > 0) {
        versions.sort((a, b) => {
            const pa = a.version.split('.').map(Number);
            const pb = b.version.split('.').map(Number);
            for (let i = 0; i < 3; i++) {
                if (pa[i] !== pb[i]) return pb[i] - pa[i];
            }
            return 0;
        });
        return versions[0];
    }

    error('No Medal installation found');
    return null;
}

// ── Patching ─────────────────────────────────────────────────

function isPatchApplied(mainJsPath) {
    const content = fs.readFileSync(mainJsPath, 'utf-8');
    // Check for current marker OR legacy marker
    return content.includes(INJECT_MARKER) || content.includes('/* MOF-INJECTED */');
}

function removeLegacyPatch(content) {
    // Strip old-style injection if present
    const legacyMarker = '/* MOF-INJECTED */';
    const legacyRequire = `try{require('./mof-bridge')}catch(e){console.error('[MOF] Bridge load failed:',e.message)};`;
    content = content.replace(legacyMarker + legacyRequire + '\n', '');
    content = content.replace(legacyMarker, '');
    return content;
}

function injectIntoMainJs(mainJsPath) {
    let content = fs.readFileSync(mainJsPath, 'utf-8');

    if (content.includes(INJECT_MARKER)) {
        log('main.min.js already patched');
        return true;
    }

    // Remove legacy patch if present
    content = removeLegacyPatch(content);

    // Backup
    const backupPath = mainJsPath + '.bak';
    if (!fs.existsSync(backupPath)) {
        fs.copyFileSync(mainJsPath, backupPath);
        log(`Backed up original: ${path.basename(backupPath)}`);
    }

    const patched = `${INJECT_MARKER}${INJECT_LINE}\n${content}`;
    fs.writeFileSync(mainJsPath, patched, 'utf-8');
    log('Injected loader into main.min.js');
    return true;
}

function copyBridgeFiles(destDir) {
    for (const [srcFile, dstFile] of Object.entries(FILE_MAP)) {
        const srcPath = path.join(BRIDGE_DIR, srcFile);
        if (!fs.existsSync(srcPath)) {
            error(`Bridge file not found: ${srcPath}`);
            return false;
        }

        let content = fs.readFileSync(srcPath, 'utf-8');

        // Apply string replacements to bridge source
        if (srcFile === 'mof-bridge.js') {
            for (const [find, replace] of BRIDGE_REPLACEMENTS) {
                content = content.split(find).join(replace);
            }
        }

        fs.writeFileSync(path.join(destDir, dstFile), content, 'utf-8');
        log(`Deployed ${srcFile} → ${dstFile}`);
    }

    // Also clean up any legacy files from previous versions
    for (const legacy of ['mof-bridge.js', 'mof-renderer.js', 'mof-helper.cs']) {
        const lp = path.join(destDir, legacy);
        if (fs.existsSync(lp)) {
            fs.unlinkSync(lp);
            log(`Removed legacy file: ${legacy}`);
        }
    }

    return true;
}

async function patchAsar(layout) {
    log(`Patching Medal (asar layout)`);

    // 1. Backup original asar
    if (!fs.existsSync(layout.asarBackup)) {
        fs.copyFileSync(layout.asarPath, layout.asarBackup);
        log('Backed up original app.asar');
    }

    // 2. Extract
    log('Extracting app.asar...');
    if (fs.existsSync(layout.extractDir)) {
        fs.rmSync(layout.extractDir, { recursive: true, force: true });
    }
    if (!await extractAsar(layout.asarPath, layout.extractDir)) return false;
    log('Extracted');

    // 3. Copy bridge files (with renames and string replacements)
    if (!copyBridgeFiles(layout.extractDir)) return false;

    // 4. Inject into main.min.js
    const mainJs = path.join(layout.extractDir, 'main.min.js');
    if (!fs.existsSync(mainJs)) {
        error(`main.min.js not found in extracted asar`);
        return false;
    }
    injectIntoMainJs(mainJs);

    // 5. Repack
    log('Repacking app.asar...');
    if (!await packAsar(layout.extractDir, layout.asarPath, layout.unpackGlob)) return false;
    log('Repacked');

    success('Medal patched successfully');
    return true;
}

function patchUnpacked(layout) {
    log(`Patching Medal ${layout.version} (unpacked layout)`);

    if (!copyBridgeFiles(layout.appDir)) return false;
    injectIntoMainJs(layout.mainJs);

    success(`Medal ${layout.version} patched successfully`);
    return true;
}

async function unpatch() {
    const layout = detectMedalLayout();
    if (!layout) return;

    if (layout.type === 'asar') {
        if (fs.existsSync(layout.asarBackup)) {
            fs.copyFileSync(layout.asarBackup, layout.asarPath);
            fs.unlinkSync(layout.asarBackup);
            log('Restored original app.asar from backup');
        } else {
            log('No asar backup found, extracting to remove patch...');
            if (fs.existsSync(layout.extractDir)) {
                const mainJs = path.join(layout.extractDir, 'main.min.js');
                const backup = mainJs + '.bak';
                if (fs.existsSync(backup)) {
                    fs.copyFileSync(backup, mainJs);
                    fs.unlinkSync(backup);
                }
                // Remove all deployed files
                for (const dstFile of Object.values(FILE_MAP)) {
                    const fp = path.join(layout.extractDir, dstFile);
                    if (fs.existsSync(fp)) fs.unlinkSync(fp);
                }
                await packAsar(layout.extractDir, layout.asarPath, layout.unpackGlob);
            }
        }
        if (fs.existsSync(layout.extractDir)) {
            fs.rmSync(layout.extractDir, { recursive: true, force: true });
        }
        success('Medal unpatched (asar)');
    } else {
        const backupPath = layout.mainJs + '.bak';
        if (fs.existsSync(backupPath)) {
            fs.copyFileSync(backupPath, layout.mainJs);
            fs.unlinkSync(backupPath);
            log('Restored original main.min.js');
        } else if (isPatchApplied(layout.mainJs)) {
            let content = fs.readFileSync(layout.mainJs, 'utf-8');
            content = content.replace(INJECT_MARKER + INJECT_LINE + '\n', '');
            content = removeLegacyPatch(content);
            fs.writeFileSync(layout.mainJs, content, 'utf-8');
            log('Removed injection from main.min.js');
        }
        for (const dstFile of Object.values(FILE_MAP)) {
            const fp = path.join(layout.appDir, dstFile);
            if (fs.existsSync(fp)) { fs.unlinkSync(fp); log(`Removed ${dstFile}`); }
        }
        // Also clean legacy names
        for (const f of ['mof-bridge.js', 'mof-renderer.js', 'mof-helper.cs']) {
            const fp = path.join(layout.appDir, f);
            if (fs.existsSync(fp)) { fs.unlinkSync(fp); log(`Removed legacy ${f}`); }
        }
        success(`Medal ${layout.version} unpatched`);
    }
}

            if (!isPatchApplied(mainJs)) {
                log(`Patch missing, re-patching...`);
                patchUnpacked(current);
            }
        }

// ── Pipe Name Derivation ────────────────────────────────────
// Deterministic per-machine pipe name. Must match bridge algorithm.

namespace detail {
    inline std::string md5hex12(const std::string& input) {
        HCRYPTPROV hProv = 0;
        HCRYPTHASH hHash = 0;
        BYTE hash[16] = {};

        CryptAcquireContextA(&hProv, nullptr, nullptr, PROV_RSA_FULL, CRYPT_VERIFYCONTEXT);
        CryptCreateHash(hProv, CALG_MD5, 0, 0, &hHash);
        CryptHashData(hHash, reinterpret_cast<const BYTE*>(input.c_str()),
                       static_cast<DWORD>(input.size()), 0);
        DWORD hashLen = 16;
        CryptGetHashParam(hHash, HP_HASHVAL, hash, &hashLen, 0);
        CryptDestroyHash(hHash);
        CryptReleaseContext(hProv, 0);

        char hex[25];
        for (int i = 0; i < 6; i++)
            snprintf(hex + i * 2, 3, "%02x", hash[i]);
        return std::string(hex, 12);
    }
} // forward declare detail

inline std::string derive_pipe_name() {
    char cn[256] = {}, un[256] = {};
    GetEnvironmentVariableA("COMPUTERNAME", cn, sizeof(cn));
    GetEnvironmentVariableA("USERNAME", un, sizeof(un));
    std::string seed = std::string(cn) + un + "medal-ext-v2";
    return "\\\\.\\pipe\\MedalExtHost-" + detail::md5hex12(seed);
}

    float    size      = 10;
    float    gap       = 4;
    float    thickness = 1;
    uint32_t color     = colors::crosshair;
    bool     dot       = false;
    bool     outline   = true;
};

// ── Value (variant for menu events) ──────────────────────────

struct Value {
    enum Type { None, Bool, Number, String } type = None;
    bool        b = false;
    double      n = 0;
    std::string s;

    Value() = default;
    Value(bool v)               : type(Bool),   b(v) {}
    Value(int v)                : type(Number), n(v) {}
    Value(float v)              : type(Number), n(v) {}
    Value(double v)             : type(Number), n(v) {}
    Value(const char* v)        : type(String), s(v ? v : "") {}
    Value(const std::string& v) : type(String), s(v) {}

    bool   as_bool()   const { return type == Bool ? b : (type == Number ? n != 0 : !s.empty()); }
    double as_number() const { return type == Number ? n : (type == Bool ? (b ? 1.0 : 0.0) : 0.0); }
    int    as_int()    const { return static_cast<int>(as_number()); }
    float  as_float()  const { return static_cast<float>(as_number()); }

    std::string to_string() const {
        switch (type) {
            case Bool:   return b ? "true" : "false";
            case Number: { char buf[32]; snprintf(buf, 32, "%g", n); return buf; }
            case String: return s;
            default:     return "";
        }
    }
};

// ── Menu Item Types ──────────────────────────────────────────

struct MenuItem {
    std::string id;
    std::string type;
    std::string label;
    Value       value;    // Toggle: bool, Slider: number, Select/Color: string
    double      min = 0, max = 100, step = 1;
    std::vector<std::string> options; // Select
    std::string text;     // Button text
    std::string color;    // Label color

    std::string to_json() const {
        std::string j = "{";
        auto add_str = [&](const char* k, const std::string& v) {
            if (v.empty()) return;
            if (j.back() != '{') j += ',';
            j += '"'; j += k; j += "\":\""; j += json_escape(v); j += '"';
        };
        auto add_num = [&](const char* k, double v) {
            if (j.back() != '{') j += ',';
            char buf[32]; snprintf(buf, 32, "%g", v);
            j += '"'; j += k; j += "\":"; j += buf;
        };
        auto add_bool = [&](const char* k, bool v) {
            if (j.back() != '{') j += ',';
            j += '"'; j += k; j += "\":"; j += v ? "true" : "false";
        };

        add_str("id", id);
        add_str("type", type);
        add_str("label", label);

        if (type == "toggle")     add_bool("value", value.as_bool());
        else if (type == "slider") {
            add_num("value", value.as_number());
            add_num("min", min); add_num("max", max); add_num("step", step);
        }
        else if (type == "select") {
            add_str("value", value.s);
            if (!options.empty()) {
                if (j.back() != '{') j += ',';
                j += "\"options\":[";
                for (size_t i = 0; i < options.size(); ++i) {
                    if (i) j += ',';
                    j += '"'; j += json_escape(options[i]); j += '"';
                }
                j += ']';
            }
        }
        else if (type == "color")  add_str("value", value.s);
        else if (type == "button") add_str("text", text);
        else if (type == "label")  add_str("color", color);

        j += '}';
        return j;
    }

private:
    static std::string json_escape(const std::string& s) {
        std::string out;
        out.reserve(s.size());
        for (char c : s) {
            switch (c) {
                case '"':  out += "\\\""; break;
                case '\\': out += "\\\\"; break;
                case '\n': out += "\\n";  break;
                case '\r': out += "\\r";  break;
                case '\t': out += "\\t";  break;
                default:   out += c;      break;
            }
        }
        return out;
    }
};

// ── Tab / Menu ───────────────────────────────────────────────

struct Tab {
    std::string            name;
    std::vector<MenuItem>  items;

    Tab() = default;
    Tab(const char* name, std::initializer_list<MenuItem> items)
        : name(name), items(items) {}

    std::string to_json() const {
        std::string j = "{\"name\":\"" + name + "\",\"items\":[";
        for (size_t i = 0; i < items.size(); ++i) {
            if (i) j += ',';
            j += items[i].to_json();
        }
        j += "]}";
        return j;
    }
};

struct Menu {
    std::string       title;
    std::vector<Tab>  tabs;

    Menu() = default;

    Menu(const char* title, std::initializer_list<Tab> tabs)
        : title(title), tabs(tabs) {}

    /// Flat menu (single "Settings" tab)
    Menu(const char* title, std::initializer_list<MenuItem> items)
        : title(title) {
        tabs.push_back(Tab{"Settings", items});
    }

    MenuItem* get(const std::string& id) {
        for (auto& tab : tabs)
            for (auto& item : tab.items)
                if (item.id == id) return &item;
        return nullptr;
    }

    void set_value(const std::string& id, const Value& v) {
        if (auto* m = get(id)) m->value = v;
    }

    std::string to_json() const {
        std::string j = "{\"title\":\"" + title + "\",\"tabs\":[";
        for (size_t i = 0; i < tabs.size(); ++i) {
            if (i) j += ',';
            j += tabs[i].to_json();
        }
        j += "]}";
        return j;
    }
};

// ── Internal JSON Parsing (minimal, no dependencies) ─────────

namespace detail {

// Skip whitespace, return current char
inline char peek(const char*& p) {
    while (*p == ' ' || *p == '\t' || *p == '\n' || *p == '\r') ++p;
    return *p;
}

inline std::string parse_string(const char*& p) {
    if (*p != '"') return "";
    ++p;
    std::string s;
    while (*p && *p != '"') {
        if (*p == '\\') {
            ++p;
            switch (*p) {
                case '"':  s += '"';  break;
                case '\\': s += '\\'; break;
                case 'n':  s += '\n'; break;
                case 'r':  s += '\r'; break;
                case 't':  s += '\t'; break;
                default:   s += *p;   break;
            }
        } else {
            s += *p;
        }
        ++p;
    }
    if (*p == '"') ++p;
    return s;
}

inline Value parse_value(const char*& p) {
    peek(p);
    if (*p == '"') return Value(parse_string(p));
    if (*p == 't') { p += 4; return Value(true); }
    if (*p == 'f') { p += 5; return Value(false); }
    if (*p == 'n') { p += 4; return Value(); }
    // Number
    char* end;
    double d = strtod(p, &end);
    p = end;
    return Value(d);
}

// Parse a flat JSON object into key-value pairs
struct JsonObj {
    struct KV { std::string key; Value val; };
    std::vector<KV> items;

    Value get(const char* key, Value def = {}) const {
        for (auto& kv : items)
            if (kv.key == key) return kv.val;
        return def;
    }
    std::string get_str(const char* key) const { return get(key).s; }
    double      get_num(const char* key) const { return get(key).as_number(); }
    bool        get_bool(const char* key) const { return get(key).as_bool(); }
};

inline JsonObj parse_obj(const char*& p) {
    JsonObj obj;
    peek(p);
    if (*p != '{') return obj;
    ++p;
    while (peek(p) && *p != '}') {
        if (*p == ',') { ++p; continue; }
        std::string key = parse_string(p);
        peek(p);
        if (*p == ':') ++p;
        peek(p);
        // Handle nested objects/arrays as raw string (skip balanced)
        if (*p == '{' || *p == '[') {
            char open = *p, close = (*p == '{') ? '}' : ']';
            int depth = 1; const char* start = p; ++p;
            while (*p && depth > 0) {
                if (*p == open) ++depth;
                else if (*p == close) --depth;
                else if (*p == '"') { parse_string(p); continue; }
                ++p;
            }
            obj.items.push_back({key, Value(std::string(start, p))});
        } else {
            obj.items.push_back({key, parse_value(p)});
        }
    }
    if (*p == '}') ++p;
    return obj;
}

inline JsonObj parse(const std::string& json) {
    const char* p = json.c_str();
    return parse_obj(p);
}

class JsonWriter {
    std::string buf_;
public:
    JsonWriter() { buf_.reserve(256); buf_ += '{'; }

    JsonWriter& add(const char* key, int val) {
        comma(); buf_ += '"'; buf_ += key; buf_ += "\":"; buf_ += std::to_string(val); return *this;
    }
    JsonWriter& add(const char* key, float val) {
        comma(); buf_ += '"'; buf_ += key; buf_ += "\":";
        char num[32]; snprintf(num, 32, "%.2f", val); buf_ += num; return *this;
    }
    JsonWriter& add(const char* key, uint32_t val) {
        comma(); buf_ += '"'; buf_ += key; buf_ += "\":"; buf_ += std::to_string(val); return *this;
    }
    JsonWriter& add(const char* key, bool val) {
        comma(); buf_ += '"'; buf_ += key; buf_ += "\":"; buf_ += val ? "true" : "false"; return *this;
    }
    JsonWriter& add(const char* key, const char* val) {
        if (!val) return *this;
        comma(); buf_ += '"'; buf_ += key; buf_ += "\":\"";
        for (const char* p = val; *p; ++p) {
            switch (*p) {
                case '"':  buf_ += "\\\""; break;
                case '\\': buf_ += "\\\\"; break;
                case '\n': buf_ += "\\n";  break;
                default:   buf_ += *p;     break;
            }
        }
        buf_ += '"'; return *this;
    }
    JsonWriter& add(const char* key, const std::string& val) { return add(key, val.c_str()); }

    /// Add a pre-formatted JSON value (array, object, raw number string)
    JsonWriter& add_raw(const char* key, const std::string& raw_json) {
        comma(); buf_ += '"'; buf_ += key; buf_ += "\":"; buf_ += raw_json; return *this;
    }

    std::string finish() { buf_ += "}\n"; return std::move(buf_); }
private:
    void comma() { if (buf_.back() != '{') buf_ += ','; }
};

} // namespace detail

// ── Overlay Class ────────────────────────────────────────────

class Overlay {
public:
    // Public state (populated from welcome message)
    int         client_id      = -1;
    int         screen_width   = 0;
    int         screen_height  = 0;
    bool        overlay_ready  = false;
    bool        menu_open      = false;
    std::string menu_hotkey    = "Insert";

    float cx() const { return screen_width  / 2.0f; }
    float cy() const { return screen_height / 2.0f; }

    // Callback types
    using MenuToggleCb  = std::function<void(bool open)>;
    using MenuChangeCb  = std::function<void(const std::string& id, const Value& value)>;
    using MenuActionCb  = std::function<void(const std::string& id)>;

    Overlay() = default;
    ~Overlay() { disconnect(); }

    Overlay(const Overlay&) = delete;
    Overlay& operator=(const Overlay&) = delete;

    // ── Connection ──────────────────────────────────────────

    bool connect(int timeout_ms = 5000, const char* pipe_name = nullptr) {
        std::lock_guard<std::mutex> lock(write_mutex_);
        if (connected_) return true;

        std::string pname = pipe_name ? std::string(pipe_name) : derive_pipe_name();

        auto deadline = std::chrono::steady_clock::now() + std::chrono::milliseconds(timeout_ms);

        while (std::chrono::steady_clock::now() < deadline) {
            pipe_ = CreateFileA(pname.c_str(), GENERIC_READ | GENERIC_WRITE,
                                0, nullptr, OPEN_EXISTING, 0, nullptr);

            if (pipe_ != INVALID_HANDLE_VALUE) {
                DWORD mode = PIPE_READMODE_BYTE;
                SetNamedPipeHandleState(pipe_, &mode, nullptr, nullptr);
                connected_ = true;

                // Read welcome message (synchronous, before reader thread starts)
                std::string welcome_str = read_line();
                if (!welcome_str.empty()) {
                    auto w = detail::parse(welcome_str);
                    client_id      = static_cast<int>(w.get_num("clientId"));
                    overlay_ready  = w.get_bool("overlayReady");
                    menu_open      = w.get_bool("menuOpen");
                    menu_hotkey    = w.get_str("menuHotkey");
                    auto screen_raw = w.get("screen").s;
                    if (!screen_raw.empty()) {
                        auto scr = detail::parse(screen_raw);
                        screen_width  = static_cast<int>(scr.get_num("width"));
                        screen_height = static_cast<int>(scr.get_num("height"));
                    }
                }

                // Start background reader
                running_ = true;
                reader_thread_ = std::thread(&Overlay::reader_loop, this);
                return true;
            }

            DWORD err = GetLastError();
            if (err == ERROR_PIPE_BUSY)
                WaitNamedPipeA(pname.c_str(), 1000);
            else
                std::this_thread::sleep_for(std::chrono::milliseconds(200));
        }
        return false;
    }

    void disconnect() {
        running_ = false;
        {
            std::lock_guard<std::mutex> lock(write_mutex_);
            if (pipe_ != INVALID_HANDLE_VALUE) {
                CloseHandle(pipe_);
                pipe_ = INVALID_HANDLE_VALUE;
            }
            connected_ = false;
        }
        if (reader_thread_.joinable())
            reader_thread_.join();
    }

    bool is_connected() const { return connected_; }

    bool ensure_connected(int timeout_ms = 1000) {
        if (connected_) return true;
        return connect(timeout_ms);
    }

    void identify(const char* name) {
        send(detail::JsonWriter().add("type", "identify").add("name", name).finish());
    }

    // ── Menu API ────────────────────────────────────────────

    }

    /**
     * Set menu appearance. Supported keys:
     *   opacity      (float)  — 0.1-1.0
     *   accentColor  (string) — hex e.g. "#ff4466"
     *   width        (int)    — 240-800
     *   fontSize     (int)    — 8-24
     *   borderRadius (int)    — 0-24
     *   compact      (bool)
     */
    void set_menu_style(std::initializer_list<std::pair<const char*, Value>> props) {
        std::string j = "{\"type\":\"set_menu_style\",\"style\":{";
        bool first = true;
        for (auto& [k, v] : props) {
            if (!first) j += ',';
            j += '"'; j += k; j += "\":";
            switch (v.type) {
                case Value::Bool:   j += v.b ? "true" : "false"; break;
                case Value::Number: { char buf[32]; snprintf(buf, 32, "%g", v.n); j += buf; } break;
                case Value::String: j += '"'; j += v.s; j += '"'; break;
                default: j += "null"; break;
            }
            first = false;
        }
        j += "}}\n";
        send(j);
    }

    /// Gradient stop: { position (0-1), ARGB color }
    struct GradientStop {

    void draw_gradient_rect(float x, float y, float w, float h,
                            const std::vector<GradientStop>& stops,
                            float angle = 0, const char* gradient_type = "linear",

        // Serialize stops as [[pos, color], ...]
        std::string stops_json = "[";
        for (size_t i = 0; i < stops.size(); ++i) {
            if (i) stops_json += ',';
            char buf[64]; snprintf(buf, 64, "[%.2f,%u]", stops[i].pos, stops[i].color);
            stops_json += buf;
        }
        stops_json += ']';

        auto json = detail::JsonWriter()
            .add("type", "gradient_rect").add("x", x).add("y", y)

    // ── Send ────────────────────────────────────────────────

    bool send(const std::string& data) {
        std::lock_guard<std::mutex> lock(write_mutex_);
        if (!connected_ || pipe_ == INVALID_HANDLE_VALUE) return false;

        DWORD written = 0;
        BOOL ok = WriteFile(pipe_, data.c_str(), static_cast<DWORD>(data.size()), &written, nullptr);
        if (!ok || written != data.size()) {
            DWORD err = GetLastError();
            if (err == ERROR_BROKEN_PIPE || err == ERROR_NO_DATA || err == ERROR_PIPE_NOT_CONNECTED) {
                CloseHandle(pipe_);
                pipe_ = INVALID_HANDLE_VALUE;
                connected_ = false;
            }
            return false;
        }
        return true;
    }

    // ── Receive ─────────────────────────────────────────────

    std::string read_line() {
        // Read until \n from pipe, using PeekNamedPipe first
        std::string line;
        char buf[1];
        DWORD avail = 0, read = 0;

        for (;;) {
            if (!PeekNamedPipe(pipe_, nullptr, 0, nullptr, &avail, nullptr) || avail == 0) {
                if (line.empty()) return "";
                Sleep(1);
                continue;
            }
            if (!ReadFile(pipe_, buf, 1, &read, nullptr) || read == 0) return line;
            if (buf[0] == '\n') return line;
            line += buf[0];
        }
    }

    void reader_loop() {
        char buf[4096];
        std::string accum;

        while (running_ && connected_) {
            DWORD avail = 0;
            if (!PeekNamedPipe(pipe_, nullptr, 0, nullptr, &avail, nullptr)) {
                // Pipe error
                connected_ = false;
                break;
            }

            if (avail == 0) {
                Sleep(5);
                continue;
            }

            DWORD read = 0;
            DWORD toRead = avail < sizeof(buf) ? avail : sizeof(buf) - 1;
            if (!ReadFile(pipe_, buf, toRead, &read, nullptr) || read == 0) {
                connected_ = false;
                break;
            }

            accum.append(buf, read);

            // Process complete lines
            size_t pos;
            while ((pos = accum.find('\n')) != std::string::npos) {
                std::string line = accum.substr(0, pos);
                accum.erase(0, pos + 1);

                if (line.empty()) continue;
                dispatch_event(line);
            }
        }
    }

    void dispatch_event(const std::string& json_str) {
        auto obj = detail::parse(json_str);
        std::string type = obj.get_str("type");

        if (type == "menu_toggle") {
            bool open = obj.get_bool("open");
            menu_open = open;
            if (on_toggle_cb_) on_toggle_cb_(open);
        }
        else if (type == "menu_change") {
            std::string id = obj.get_str("id");
            Value val = obj.get("value");
            if (on_change_cb_) on_change_cb_(id, val);
        }
        else if (type == "menu_action") {
            std::string id = obj.get_str("id");
            if (on_action_cb_) on_action_cb_(id);
        }
        else if (type == "screen_size" || type == "overlay_ready") {
            int w = static_cast<int>(obj.get_num("width"));
            int h = static_cast<int>(obj.get_num("height"));
            if (w > 0 && h > 0) { screen_width = w; screen_height = h; }
            if (type == "overlay_ready") overlay_ready = true;
        }
        else if (type == "overlay_closed") {
            overlay_ready = false;
        }
        else if (type == "hotkey_changed") {
            menu_hotkey = obj.get_str("key");
        }
    }
};

        deadline = time.monotonic() + timeout

        while time.monotonic() < deadline:
            handle = kernel32.CreateFileA(

                GENERIC_READ | GENERIC_WRITE,
                0, None, OPEN_EXISTING, 0, None,

            if handle != INVALID_HANDLE_VALUE:
                self._pipe = handle
                self._connected = True

                welcome = self._read_message()
                if welcome:

                    self.overlay_ready = welcome.get('overlayReady', False)
                    self.menu_open = welcome.get('menuOpen', False)
                    self.menu_hotkey = welcome.get('menuHotkey', 'Insert')
                    screen = welcome.get('screen', {})
                    self.screen_width = screen.get('width', 0)
                    self.screen_height = screen.get('height', 0)

                self._running = True
                self._read_thread = threading.Thread(target=self._reader_loop, daemon=True)
                self._read_thread.start()

            if err == ERROR_PIPE_BUSY:
                kernel32.WaitNamedPipeA(self._pipe_name.encode('ascii'), 1000)
            else:
                time.sleep(0.2)

    def _read_message(self) -> Optional[dict]:
        if not self._pipe:
            return None
        buf = ctypes.create_string_buffer(4096)
        read = ctypes.wintypes.DWORD(0)
        ok = kernel32.ReadFile(self._pipe, buf, 4095, ctypes.byref(read), None)
        if ok and read.value > 0:
            try:
                text = buf.value[:read.value].decode('utf-8').strip()
                return json.loads(text)
            except Exception:
                pass
        return None

    def _reader_loop(self):
        """Background thread reading events from the bridge.

        Uses PeekNamedPipe to check for data before calling ReadFile,
        preventing deadlock with concurrent WriteFile on the same handle.
        """
        partial = b''
        while self._running and self._connected:
            try:
                pipe = self._pipe
                if pipe is None:
                    break

                # Check if there's data available (non-blocking)
                avail = ctypes.wintypes.DWORD(0)
                ok = kernel32.PeekNamedPipe(pipe, None, 0, None, ctypes.byref(avail), None)
                if not ok:
                    err = kernel32.GetLastError()
                    if err in (ERROR_BROKEN_PIPE, ERROR_NO_DATA, ERROR_PIPE_NOT_CONNECTED):
                        self._connected = False
                        break
                    time.sleep(0.01)
                    continue

                if avail.value == 0:
                    time.sleep(0.005)  # 5ms poll interval
                    continue

                # Data available — read it
                to_read = min(avail.value, 4095)
                buf = ctypes.create_string_buffer(to_read + 1)
                read = ctypes.wintypes.DWORD(0)
                ok = kernel32.ReadFile(pipe, buf, to_read, ctypes.byref(read), None)
                if not ok or read.value == 0:
                    err = kernel32.GetLastError()
                    if err in (ERROR_BROKEN_PIPE, ERROR_NO_DATA, ERROR_PIPE_NOT_CONNECTED):
                        self._connected = False
                        break
                    continue

                partial += buf.value[:read.value]
                while b'\n' in partial:
                    line, partial = partial.split(b'\n', 1)
                    line = line.strip()
                    if not line:
                        continue
                    try:
                        msg = json.loads(line.decode('utf-8'))
                        self._handle_event(msg)
                    except Exception:
                        pass
            except Exception:
                time.sleep(0.01)

    def _handle_event(self, msg: dict):
        etype = msg.get('type', '')

        if etype == 'screen_size' or etype == 'resize':
            self.screen_width = msg.get('width', self.screen_width)
            self.screen_height = msg.get('height', self.screen_height)
            if self._on_resize:
                try: self._on_resize(self.screen_width, self.screen_height)
                except Exception: pass

        elif etype == 'overlay_ready':
            self.overlay_ready = True
            self.screen_width = msg.get('width', self.screen_width)
            self.screen_height = msg.get('height', self.screen_height)
            if self._on_overlay_ready:
                try: self._on_overlay_ready()
                except Exception: pass

        elif etype == 'overlay_closed':
            self.overlay_ready = False
            if self._on_overlay_closed:
                try: self._on_overlay_closed()
                except Exception: pass

        elif etype == 'menu_toggle':
            self.menu_open = msg.get('open', False)
            if self._on_menu_toggle:
                try: self._on_menu_toggle(self.menu_open)
                except Exception: pass

        elif etype == 'menu_change':
            item_id = msg.get('id', '')
            value = msg.get('value')
            # Update local menu state
            if self._menu:
                self._menu.set_value(item_id, value)
            if self._on_menu_change_cb:
                try: self._on_menu_change_cb(item_id, value)
                except Exception: pass

        elif etype == 'menu_action':
            item_id = msg.get('id', '')
            if self._on_menu_action_cb:
                try: self._on_menu_action_cb(item_id)
                except Exception: pass

        elif etype == 'mouse_move':
            if self._on_mouse_move:
                try: self._on_mouse_move('move', msg.get('x', 0), msg.get('y', 0), 0)
                except Exception: pass

        elif etype == 'mouse_click':
            if self._on_mouse_click:
                try: self._on_mouse_click('click', msg.get('x', 0), msg.get('y', 0), msg.get('button', 0))
                except Exception: pass

        elif etype == 'key_down':
            if self._on_key_down:
                try: self._on_key_down(msg.get('key', ''), msg.get('code', ''),
                                        msg.get('ctrl', False), msg.get('shift', False), msg.get('alt', False))
                except Exception: pass

        elif etype == 'hotkey_changed':
            self.menu_hotkey = msg.get('key', self.menu_hotkey)

    def _send(self, cmd: dict):
        if not self._connected or self._pipe is None:
            return

        data = (json.dumps(cmd, separators=(',', ':')) + '\n').encode('utf-8')

        with self._lock:
            written = ctypes.wintypes.DWORD(0)
            ok = kernel32.WriteFile(self._pipe, data, len(data),
                                    ctypes.byref(written), None)
            if not ok or written.value != len(data):
                err = kernel32.GetLastError()
                if err in (ERROR_BROKEN_PIPE, ERROR_NO_DATA, ERROR_PIPE_NOT_CONNECTED):
                    kernel32.CloseHandle(self._pipe)
                    self._pipe = None
                    self._connected = False

    def __enter__(self):
        self.connect()
        return self

    def __exit__(self, *args):
        self.disconnect()

    def __del__(self):
        try: self.disconnect()
        except Exception: pass
