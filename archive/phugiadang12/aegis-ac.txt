# Aegis AC

**A server-side behavioural anti-cheat for a multiplayer FPS, with an AI SOC analyst.**

![tests](https://img.shields.io/badge/tests-81%20passing-brightgreen)
![python](https://img.shields.io/badge/python-3.12-blue)
![frontend](https://img.shields.io/badge/dashboard-TypeScript%20%2B%20React-3178c6)
![model](https://img.shields.io/badge/AI-Claude%20(Anthropic%20SDK)-8a63d2)
![license](https://img.shields.io/badge/license-MIT-green)

Aegis AC catches cheaters from the **telemetry a game server already sees** — no kernel
driver, no reading player memory. A behavioural detector flags suspicious players, an
AI analyst investigates each flag and writes a case report, a human approves the ban,
and confirmed cheaters go out in delayed ban waves. Built and validated end to end
against synthetic cheat signatures, then packaged behind a live dashboard.

> **Why I built it.** I'm aiming at game-security / anti-cheat engineering, where the
> interesting problems sit at the intersection of **detection, applied AI, and operations**.
> Aegis is a full, honest slice of that: a telemetry pipeline, an explainable detector, an
> LLM-driven SOC analyst, and an enforcement dashboard — built the way a real team would,
> without ever shipping a real cheat.

![Aegis AC dashboard](docs/images/dashboard.jpg)

---

## Highlights

- **Server-side, privacy-preserving.** Works from position/aim/shot telemetry on trusted
  hardware — no client driver, nothing to reverse-engineer on the player's PC.
- **100% detection, 99% precision** over 160 cheaters + 480 legit players on labelled
  synthetic matches (1 false positive).
- **A honeypot that catches a human-aim wallhack.** A server-only phantom entity no
  legitimate client can see — anyone who aims at it is reading state they shouldn't have.
- **An AI SOC analyst.** A tool-using Claude agent investigates each alert and files a case
  report (category, confidence, disposition, evidence, recommendation); a human approves.
  Runs fully offline with a deterministic backend when no API key is set.
- **Live enforcement dashboard** (TypeScript + React): alert queue, 2D replay viewer,
  delayed ban waves, and Discord alerts.
- **A rule-safe live demo.** An "Inject cheater" control spawns a synthetic cheater on
  demand and shows the whole pipeline catch it — safe to run in front of anyone.
- **81 tests**, three Python packages, a typed frontend that builds clean.

## How it works

1. **Telemetry pipeline.** A game server streams one JSON event per line — joins, ticks
   (position + aim), shots, damage, kills, and the honeypot. The collector ingests over UDP
   (fast path) and HTTP, rejecting unknown fields, and stores raw events so any detector can
   replay a match. (Fixed a 27% → 0% UDP packet-loss cliff with an 8 MB receive buffer.)
2. **Red team, done safely.** Rather than run a real cheat, Aegis describes each cheat
   mathematically and emits the telemetry it would leave — labelled with ground truth. This
   is how anti-cheat teams actually develop detectors. No memory reading, no injection, no
   kernel evasion.
3. **Detection.** Each match becomes one feature row per player (peak/sustained turn rate,
   hit rate, headshot rate, honeypot shots). Explainable rules flag cheats, and every flag
   carries a human-readable reason the AI analyst later quotes.
4. **AI SOC analyst.** A Claude agent investigates each alert with read-only tools — stats
   overview, a z-score baseline vs. the lobby's clean players, the sharpest view-snaps, the
   honeypot evidence — then files a case with a recommendation. Never auto-bans.
5. **Enforcement.** The dashboard shows alerts, cases and a 2D replay; confirmed cheaters go
   into delayed ban waves (so authors can't correlate a ban to a match), and Discord pings
   the team.

### Detection results

| Feature | Cheat tell |
|---|---|
| `max_turn_rate` | aimbot snap (completes inside one tick) |
| `p95_turn_rate` + `hit_rate` | humanised aimbot |
| `hit_rate` | triggerbot / aimbot (lands almost everything) |
| `honeypot_shots` | ESP / wallhack (aimed at a server-only phantom) |

**100% detection, 99% precision** over 160 cheaters and 480 legit players. The ESP
wallhacker aims like a human and evades every aim-based rule, yet the moving honeypot
phantom still exposes it.

```powershell
python -m venv .venv ; .\.venv\Scripts\Activate.ps1
pip install -e collector -e detection -e soc-agent
pytest                                   # 81 tests
```

```powershell
uvicorn aegis_collector.app:create_app --factory --port 8000     # terminal 1
python -m aegis_collector.sim --players 8 --seconds 60            # terminal 2
```

```powershell
python -m aegis_detection.evaluate --matches 20   # score vs ground truth
```

```powershell
python -m aegis_soc --profile esp                 # investigate a match's alerts
# optional: set ANTHROPIC_API_KEY to let a Claude agent drive the investigation
```

## Safety & ethics

Aegis never ships a real cheat. The "red team" generates the telemetry *signatures* a cheat
would leave — labelled with ground truth to score the detector — with **no memory reading,
no injection, and no kernel evasion**. It targets AssaultCube (open-source) on a **private,
local server**, never commercial games or public servers. This is deliberate: a real cheat
would add nothing to the research and would violate game ToS. "I generate the signature, not
the hack" is the honest, professional way to build and prove a detector.

`collector/aegis_collector/app.py`:

```py
"""Collector service.

Telemetry arrives two ways:
- UDP datagrams of JSON lines from the patched game server (fast path)
- POST /ingest with a JSON array (handy for tests and tools)

Security note: the UDP listener has no authentication, so it binds to
127.0.0.1 by default. Only expose it on a trusted network.

Run:  uvicorn aegis_collector.app:create_app --factory --port 8000
"""

import asyncio
import logging
import os
import socket
from contextlib import asynccontextmanager
from typing import Any

from fastapi import FastAPI, HTTPException, Query, WebSocket, WebSocketDisconnect
from pydantic import ValidationError

from .schema import Event, EventAdapter
from .store import EventStore

log = logging.getLogger("aegis.collector")

MAX_BATCH = 5000
UDP_RCVBUF = 8 * 1024 * 1024


class LiveHub:
    """Fans new events out to connected WebSocket clients."""

    def __init__(self) -> None:
        self._subscribers: set[asyncio.Queue] = set()

    def subscribe(self) -> asyncio.Queue:
        q: asyncio.Queue = asyncio.Queue(maxsize=2000)
        self._subscribers.add(q)
        return q

    def unsubscribe(self, q: asyncio.Queue) -> None:
        self._subscribers.discard(q)

    def publish(self, events: list[dict[str, Any]]) -> None:
        for q in list(self._subscribers):
            for ev in events:
                try:
                    q.put_nowait(ev)
                except asyncio.QueueFull:
                    break  # slow client: drop rather than stall ingestion


class Ingestor:
    def __init__(self, store: EventStore, hub: LiveHub) -> None:
        self.store = store
        self.hub = hub
        self.accepted = 0
        self.rejected = 0

    def ingest_lines(self, data: bytes) -> int:
        events = []
        for line in data.splitlines():
            line = line.strip()
            if not line:
                continue
            try:
                events.append(EventAdapter.validate_json(line))
            except ValidationError as exc:
                self.rejected += 1
                log.debug("rejected telemetry line: %s", exc.errors()[:1])
        self.commit(events)
        return len(events)

    def commit(self, events: list[Event]) -> None:
        if not events:
            return
        self.store.add_many(events)
        self.accepted += len(events)
        self.hub.publish([e.model_dump() for e in events])


class _UdpProtocol(asyncio.DatagramProtocol):
    def __init__(self, ingestor: Ingestor) -> None:
        self.ingestor = ingestor

    def datagram_received(self, data: bytes, addr) -> None:
        try:
            self.ingestor.ingest_lines(data)
        except Exception:  # never let one bad datagram kill the listener
            log.exception("failed to ingest datagram from %s", addr)


def create_app(
    db_path: str | None = None,
    udp_host: str | None = None,
    udp_port: int | None = None,
    enable_udp: bool = True,
) -> FastAPI:
    db_path = db_path or os.getenv("AEGIS_DB", "data/aegis.db")
    udp_host = udp_host or os.getenv("AEGIS_UDP_HOST", "127.0.0.1")
    udp_port = udp_port if udp_port is not None else int(os.getenv("AEGIS_UDP_PORT", "28800"))

    store = EventStore(db_path)
    hub = LiveHub()
    ingestor = Ingestor(store, hub)

    @asynccontextmanager
    async def lifespan(app: FastAPI):
        transport = None
        if enable_udp:
            loop = asyncio.get_running_loop()
            transport, _ = await loop.create_datagram_endpoint(
                lambda: _UdpProtocol(ingestor), local_addr=(udp_host, udp_port)
            )
            # The OS default receive buffer is small (64 KB on Windows); bursts
            # of telemetry overflow it and the kernel silently drops datagrams.
            sock = transport.get_extra_info("socket")
            sock.setsockopt(socket.SOL_SOCKET, socket.SO_RCVBUF, UDP_RCVBUF)
            log.info("telemetry UDP listening on %s:%d", udp_host, udp_port)
        try:
            yield
        finally:
            if transport:
                transport.close()
            store.close()

    app = FastAPI(title="Aegis AC collector", lifespan=lifespan)
    app.state.ingestor = ingestor

    @app.get("/health")
    def health():
        return {
            "status": "ok",
            "accepted": ingestor.accepted,
            "rejected": ingestor.rejected,
            "stored": store.count(),
        }

    @app.post("/ingest")
    async def ingest(events: list[Event]):
        if len(events) > MAX_BATCH:
            raise HTTPException(413, f"batch larger than {MAX_BATCH} events")
        ingestor.commit(events)
        return {"accepted": len(events)}

    @app.get("/events")
    def events(
        limit: int = Query(100, ge=1, le=5000),
        type: str | None = None,
        match_id: str | None = None,
        actor: int | None = None,
    ):
        return store.recent(limit=limit, type=type, match_id=match_id, actor=actor)

    @app.get("/matches")
    def matches():
        return store.matches()

    @app.get("/matches/{match_id}/players")
    def players(match_id: str):
        return store.players(match_id)

    @app.websocket("/ws/live")
    async def live(ws: WebSocket):
        await ws.accept()
        q = hub.subscribe()
        try:
            while True:
                await ws.send_json(await q.get())
        except WebSocketDisconnect:
            pass
        finally:
            hub.unsubscribe(q)

    return app

```

`collector/aegis_collector/schema.py`:

```py
"""Telemetry event schema.

Every event the game server emits is one JSON object per line (JSONL).
The ``type`` field selects the event kind. Unknown fields are rejected so a
buggy or malicious sender can't smuggle extra data into storage.

Conventions
-----------
- ``ts``       server time in milliseconds since the match started
- ``match_id`` opaque id chosen by the server for one match
- ``cn``       AssaultCube "client number" — the player's slot on the server
- ``yaw``      horizontal view angle in degrees, [0, 360)
- ``pitch``    vertical view angle in degrees, [-90, 90]
"""

from typing import Annotated, Literal, Union

from pydantic import BaseModel, ConfigDict, Field, TypeAdapter


class _Strict(BaseModel):
    model_config = ConfigDict(extra="forbid", frozen=True)


class Vec3(_Strict):
    x: float
    y: float
    z: float


class _Event(_Strict):
    ts: float = Field(ge=0)
    match_id: str = Field(min_length=1, max_length=64)


class PlayerJoin(_Event):
    type: Literal["player_join"]
    cn: int = Field(ge=0, le=255)
    name: str = Field(min_length=1, max_length=32)


class PlayerLeave(_Event):
    type: Literal["player_leave"]
    cn: int = Field(ge=0, le=255)


class Spawn(_Event):
    type: Literal["spawn"]
    cn: int = Field(ge=0, le=255)
    pos: Vec3


class Tick(_Event):
    """Periodic player state: where they are and where they're looking."""

    type: Literal["tick"]
    cn: int = Field(ge=0, le=255)
    pos: Vec3
    yaw: float = Field(ge=0, lt=360)
    pitch: float = Field(ge=-90, le=90)
    alive: bool = True


class Shot(_Event):
    """A weapon was fired. ``target`` is the point the shot travelled to."""

    type: Literal["shot"]
    cn: int = Field(ge=0, le=255)
    weapon: str = Field(min_length=1, max_length=16)
    origin: Vec3
    target: Vec3


class Damage(_Event):
    type: Literal["damage"]
    attacker: int = Field(ge=0, le=255)
    target: int = Field(ge=0, le=255)
    weapon: str = Field(min_length=1, max_length=16)
    amount: int = Field(ge=0, le=1000)
    headshot: bool = False


class Kill(_Event):
    type: Literal["kill"]
    attacker: int = Field(ge=0, le=255)
    victim: int = Field(ge=0, le=255)
    weapon: str = Field(min_length=1, max_length=16)
    headshot: bool = False


class Honeypot(_Event):
    """A phantom entity the anti-cheat server places in the world but never
    sends to real clients. Only the trusted server (and so the collector) knows
    it exists, so any player who aims at or shoots it is reading game state they
    should have no access to — a near-certain wallhack/ESP tell. ``hid`` is the
    phantom's id; ``pos`` is where the server put it this tick."""

    type: Literal["honeypot"]
    hid: int = Field(ge=0, le=255)
    pos: Vec3


Event = Annotated[
    Union[PlayerJoin, PlayerLeave, Spawn, Tick, Shot, Damage, Kill, Honeypot],
    Field(discriminator="type"),
]

EventAdapter: TypeAdapter[Event] = TypeAdapter(Event)


def actor_of(event: Event) -> int | None:
    """The player who *did* the thing — used for indexing."""
    for attr in ("cn", "attacker"):
        value = getattr(event, attr, None)
        if value is not None:
            return value
    return None
```

`collector/aegis_collector/sim.py`:

```py
"""Simulated *legitimate* players, streamed to the collector over UDP.

Lets us build and test the pipeline (and later the detectors) before the real
AssaultCube server is patched. The aim model is deliberately human-like:
limited turn speed, reaction delay, overshoot noise and imperfect accuracy —
the baseline that cheats will later be compared against.

    python -m aegis_collector.sim --players 8 --seconds 60
"""

import argparse
import json
import math
import random
import socket
import time
import uuid
from collections.abc import Iterator
from typing import Any

MAP_SIZE = 256.0
MOVE_SPEED = 16.0  # units per second
FIRE_INTERVAL = 0.12  # seconds between shots (assault rifle)
WEAPON = "assault"
NAMES = ["viper", "nova", "kestrel", "rook", "ember", "drift", "onyx", "sable",
         "quill", "talon", "brick", "lumen", "moss", "pike", "rune", "wren"]


def _wrap180(deg: float) -> float:
    return (deg + 180.0) % 360.0 - 180.0


def _bearing(src: list[float], dst: list[float]) -> float:
    return math.degrees(math.atan2(dst[1] - src[1], dst[0] - src[0])) % 360.0


class SimPlayer:
    def __init__(self, cn: int, name: str, rng: random.Random):
        self.cn = cn
        self.name = name
        self.rng = rng
        # per-player "personality" so players differ from one another
        self.accuracy = rng.uniform(0.25, 0.55)
        self.turn_speed = rng.uniform(180.0, 360.0)  # deg/s when engaging
        self.reaction = max(0.12, rng.gauss(0.26, 0.04))  # seconds
        self.aim_noise = rng.uniform(0.4, 1.2)  # deg of jitter per tick
        self.respawn()

    def respawn(self) -> None:
        r = self.rng
        self.pos = [r.uniform(10, MAP_SIZE - 10), r.uniform(10, MAP_SIZE - 10), 0.0]
        self.yaw = r.uniform(0, 360)
        self.pitch = 0.0
        self.health = 100
        self.alive = True
        self.waypoint = self._new_waypoint()
        self.target: "SimPlayer | None" = None
        self.engaged_for = 0.0
        self.last_shot = -1.0

    def _new_waypoint(self) -> list[float]:
        r = self.rng
        return [r.uniform(10, MAP_SIZE - 10), r.uniform(10, MAP_SIZE - 10), 0.0]


def simulate(
    n_players: int = 8,
    seconds: float = 60.0,
    tick_hz: int = 30,
    seed: int | None = None,
    match_id: str | None = None,
) -> Iterator[list[dict[str, Any]]]:
    """Yield the events for each tick, as JSON-ready dicts."""
    rng = random.Random(seed)
    match_id = match_id or f"sim-{uuid.uuid4().hex[:8]}"
    dt = 1.0 / tick_hz
    players = [SimPlayer(cn, NAMES[cn % len(NAMES)], rng) for cn in range(n_players)]

    def base(t: float, kind: str) -> dict[str, Any]:
        return {"ts": round(t * 1000, 1), "match_id": match_id, "type": kind}

    def vec(p: list[float]) -> dict[str, float]:
        return {"x": round(p[0], 3), "y": round(p[1], 3), "z": round(p[2], 3)}

    first = []
    for p in players:
        first.append({**base(0, "player_join"), "cn": p.cn, "name": p.name})
        first.append({**base(0, "spawn"), "cn": p.cn, "pos": vec(p.pos)})
    yield first

    t = 0.0
    while t < seconds:
        t += dt
        out: list[dict[str, Any]] = []
        for p in players:
            if not p.alive:
                continue

            # --- choose / drop a target ---
            if p.target is None and rng.random() < 0.7 * dt:
                enemies = [e for e in players if e is not p and e.alive]
                if enemies:
                    p.target, p.engaged_for = rng.choice(enemies), 0.0
            if p.target is not None and (not p.target.alive or rng.random() < 0.25 * dt):
                p.target = None

            # --- movement ---
            dx, dy = p.waypoint[0] - p.pos[0], p.waypoint[1] - p.pos[1]
            dist = math.hypot(dx, dy)
            if dist < 2.0:
                p.waypoint = p._new_waypoint()
            else:
                step = min(dist, MOVE_SPEED * dt)
                p.pos[0] += dx / dist * step
                p.pos[1] += dy / dist * step

            # --- aim: humans turn at a limited speed, with a reaction delay ---
            if p.target is not None:
                p.engaged_for += dt
                desired = _bearing(p.pos, p.target.pos)
                speed = p.turn_speed if p.engaged_for > p.reaction else 60.0
            else:
                desired = _bearing(p.pos, p.waypoint)
                speed = 120.0
            diff = _wrap180(desired - p.yaw)
            turn = max(-speed * dt, min(speed * dt, diff))
            p.yaw = (p.yaw + turn + rng.gauss(0, p.aim_noise)) % 360.0
            p.pitch = max(-90.0, min(90.0, p.pitch * 0.8 + rng.gauss(0, 0.5)))

            out.append({**base(t, "tick"), "cn": p.cn, "pos": vec(p.pos),
                        "yaw": round(p.yaw, 3) % 360.0, "pitch": round(p.pitch, 3),
                        "alive": True})

            # --- shooting ---
            err = abs(_wrap180(desired - p.yaw)) if p.target else 999.0
            if p.target is not None and err < 6.0 and t - p.last_shot >= FIRE_INTERVAL:
                p.last_shot = t
                rad = math.radians(p.yaw)
                far = [p.pos[0] + math.cos(rad) * 60, p.pos[1] + math.sin(rad) * 60, p.pos[2]]
                out.append({**base(t, "shot"), "cn": p.cn, "weapon": WEAPON,
                            "origin": vec(p.pos), "target": vec(far)})

                if rng.random() < p.accuracy * (1 - err / 10):
                    victim = p.target
                    headshot = rng.random() < 0.12
                    amount = rng.randint(18, 26) * (2 if headshot else 1)
                    victim.health -= amount
                    out.append({**base(t, "damage"), "attacker": p.cn, "target": victim.cn,
                                "weapon": WEAPON, "amount": amount, "headshot": headshot})
                    if victim.health <= 0:
                        victim.alive = False
                        victim.respawn_at = t + 3.0
                        p.target = None
                        out.append({**base(t, "kill"), "attacker": p.cn, "victim": victim.cn,
                                    "weapon": WEAPON, "headshot": headshot})

        for p in players:
            if not p.alive and t >= getattr(p, "respawn_at", 0):
                p.respawn()
                out.append({**base(t, "spawn"), "cn": p.cn, "pos": vec(p.pos)})

        yield out

    yield [{**base(t, "player_leave"), "cn": p.cn} for p in players]


def _datagrams(events: list[dict[str, Any]], max_bytes: int = 8000) -> Iterator[bytes]:
    """Pack events as JSON lines into datagrams below a safe UDP size."""
    buf = b""
    for ev in events:
        line = json.dumps(ev, separators=(",", ":")).encode() + b"\n"
        if buf and len(buf) + len(line) > max_bytes:
            yield buf
            buf = b""
        buf += line
    if buf:
        yield buf


def main() -> None:
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--host", default="127.0.0.1")
    ap.add_argument("--port", type=int, default=28800)
    ap.add_argument("--players", type=int, default=8)
    ap.add_argument("--seconds", type=float, default=60.0)
    ap.add_argument("--tick-hz", type=int, default=30)
    ap.add_argument("--seed", type=int)
    ap.add_argument("--fast", action="store_true", help="don't wait in real time")
    args = ap.parse_args()

    sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    sent = 0
    start = time.perf_counter()
    for i, tick in enumerate(simulate(args.players, args.seconds, args.tick_hz, args.seed)):
        for dgram in _datagrams(tick):
            sock.sendto(dgram, (args.host, args.port))
        sent += len(tick)
        if args.fast:
            time.sleep(0.0005)  # tiny pause so the local UDP buffer doesn't overflow
        else:
            wait = start + i / args.tick_hz - time.perf_counter()
            if wait > 0:
                time.sleep(wait)
    print(f"sent {sent} events to {args.host}:{args.port}")

    main()
```

```py
"""Synthetic *cheater* telemetry — the red team, done the safe way.

We do NOT build a real cheat. Instead we generate the telemetry *signatures*
that each cheat would leave on our own local server, so the blue-team detector
has labelled data to learn from and be scored against. This is how anti-cheat
teams actually develop detectors: you describe the cheat mathematically rather
than run one against a live game.

Every generated player carries a ground-truth ``label`` so detection rate can
be measured precisely. Nothing here reads game memory, injects code, or touches
any real game — it only emits the same telemetry schema the collector ingests.

    python -m aegis_collector.sim_cheat --legit 6 --cheaters 2 --profile aimbot
"""

import argparse
import enum
import math
import random
import socket
import time
import uuid
from collections.abc import Iterator
from dataclasses import dataclass, field
from typing import Any

from .sim import (
    FIRE_INTERVAL,
    MAP_SIZE,
    MOVE_SPEED,
    WEAPON,
    SimPlayer,
    _bearing,
    _datagrams,
    _wrap180,
)


class Cheat(str, enum.Enum):
    LEGIT = "legit"
    AIMBOT = "aimbot"              # instant snap, perfect accuracy
    HUMANISED = "humanised"        # snap smoothed over a few ticks + jitter
    TRIGGERBOT = "triggerbot"      # inhuman reaction time on the trigger
    ESP = "esp"                    # tracks / pre-aims enemies with no line of sight


# A "line of sight" model. The real game has walls; our flat sim doesn't, so we
# approximate occlusion probabilistically. Legit players only react to a target
# they can see; ESP players react regardless — that difference IS the signal.
def _has_los(rng: random.Random, src, dst) -> bool:
    dist = math.hypot(dst[0] - src[0], dst[1] - src[1])
    # farther apart -> more likely a wall is in the way
    occlusion = min(0.8, dist / MAP_SIZE)
    return rng.random() > occlusion


@dataclass
class CheatPlayer:
    """Wraps the legit SimPlayer model and distorts aim/fire per cheat profile."""

    inner: SimPlayer
    cheat: Cheat
    rng: random.Random
    # humanised-aimbot snap state
    _snap_remaining: int = 0
    _snap_target_yaw: float = 0.0
    _baiting: bool = False  # ESP: committed to turning onto the phantom
    # metrics a detector could never see but we use for sanity checks
    shots_at_ghost: int = field(default=0)
    los_violations: int = field(default=0)

    @property
    def cn(self) -> int:
        return self.inner.cn

    def aim_and_fire(
        self,
        t: float,
        dt: float,
        enemies: list["CheatPlayer"],
        ghost_pos: list[float] | None,
        emit,
    ) -> None:
        p = self.inner
        # pick a target using the normal model
        if p.target is None and self.rng.random() < 0.9 * dt:
            alive = [e.inner for e in enemies if e.inner.alive]
            if alive:
                p.target = self.rng.choice(alive)
                p.engaged_for = 0.0
        if p.target is not None and not p.target.alive:
            p.target = None

        # ESP / wallhack: aim is fully HUMAN (so aim-rate and accuracy rules can't
        # catch it), but the player knows enemy positions through walls and is
        # occasionally lured into aiming at the honeypot phantom — the one tell.
        if self.cheat is Cheat.ESP:
            self._esp_tick(t, dt, ghost_pos, emit)
            return

        if p.target is None:
            return

        desired = _bearing(p.pos, p.target.pos)
        visible = _has_los(self.rng, p.pos, p.target.pos)

        if self.cheat in (Cheat.LEGIT, Cheat.TRIGGERBOT):
            # human aim: limited turn speed, only tracks what it can see
            if not visible:
                return
            p.engaged_for += dt
            speed = p.turn_speed if p.engaged_for > p.reaction else 60.0
            diff = _wrap180(desired - p.yaw)
            turn = max(-speed * dt, min(speed * dt, diff))
            p.yaw = (p.yaw + turn + self.rng.gauss(0, p.aim_noise)) % 360.0
            err = abs(_wrap180(desired - p.yaw))
            if self.cheat is Cheat.TRIGGERBOT:
                # fires the instant the crosshair crosses the enemy: ~0 reaction,
                # and lands the shot far more often than a human on a crossing
                if err < 2.0 and t - p.last_shot >= FIRE_INTERVAL * 0.5:
                    self._fire(t, emit, hit_target=p.target)
            else:
                if err < 6.0 and t - p.last_shot >= FIRE_INTERVAL:
                    hit = p.target if self.rng.random() < p.accuracy else None
                    self._fire(t, emit, hit_target=hit)

        elif self.cheat is Cheat.AIMBOT:
            # instant snap to target every tick -> angular velocity spike
            self._aim_instant(desired)
            if t - p.last_shot >= FIRE_INTERVAL:
                self._fire(t, emit, hit_target=p.target)  # near-perfect accuracy

        elif self.cheat is Cheat.HUMANISED:
            # snap, but spread over 3-5 ticks with jitter to look human-ish
            if self._snap_remaining == 0 and abs(_wrap180(desired - p.yaw)) > 15:
                self._snap_remaining = self.rng.randint(3, 5)
                self._snap_target_yaw = desired
            if self._snap_remaining > 0:
                diff = _wrap180(self._snap_target_yaw - p.yaw)
                p.yaw = (p.yaw + diff / self._snap_remaining + self.rng.gauss(0, 0.6)) % 360.0
                self._snap_remaining -= 1
            else:
                p.yaw = (desired + self.rng.gauss(0, 0.8)) % 360.0
            err = abs(_wrap180(desired - p.yaw))
            if err < 4.0 and t - p.last_shot >= FIRE_INTERVAL:
                hit = p.target if self.rng.random() < 0.85 else None
                self._fire(t, emit, hit_target=hit)

    def _esp_tick(self, t: float, dt: float, ghost_pos, emit) -> None:
        p = self.inner
        # the phantom lures the wallhacker: once tempted they commit to turning
        # onto it over a few ticks and fire — aiming at something only a cheat
        # could know is there. Sticky, so the shot actually lands.
        if not self._baiting and ghost_pos is not None and self.rng.random() < 0.02:
            self._baiting = True
        if self._baiting:
            if ghost_pos is None:
                self._baiting = False
            else:
                gdir = _bearing(p.pos, ghost_pos)
                p.engaged_for = 1.0  # full turn speed onto the bait
                self._turn_human(gdir, dt)
                if abs(_wrap180(gdir - p.yaw)) < 6.0 and t - p.last_shot >= FIRE_INTERVAL:
                    self._fire(t, emit)  # shot at the phantom — the tell
                    self.shots_at_ghost += 1
                    self._baiting = False
                return
        # normal combat, but tracking the target THROUGH walls (no LoS gate)
        if p.target is None:
            return
        tgt = p.target
        desired = _bearing(p.pos, tgt.pos)
        p.engaged_for += dt
        self._turn_human(desired, dt)
        if abs(_wrap180(desired - p.yaw)) < 6.0 and t - p.last_shot >= FIRE_INTERVAL:
            # slightly better than human because they never get surprised
            hit = tgt if self.rng.random() < min(0.9, p.accuracy + 0.25) else None
            if not _has_los(self.rng, p.pos, tgt.pos):
                self.los_violations += 1
            self._fire(t, emit, hit_target=hit)

    def _turn_human(self, desired: float, dt: float) -> None:
        p = self.inner
        speed = p.turn_speed if p.engaged_for > p.reaction else 60.0
        diff = _wrap180(desired - p.yaw)
        turn = max(-speed * dt, min(speed * dt, diff))
        p.yaw = (p.yaw + turn + self.rng.gauss(0, p.aim_noise)) % 360.0

    def _aim_instant(self, yaw: float) -> None:
        self.inner.yaw = yaw % 360.0

    def _fire(self, t: float, emit, hit_target: SimPlayer | None = None) -> None:
        p = self.inner
        p.last_shot = t
        rad = math.radians(p.yaw)
        far = [p.pos[0] + math.cos(rad) * 60, p.pos[1] + math.sin(rad) * 60, p.pos[2]]
        emit("shot", cn=p.cn, weapon=WEAPON, origin=_vec(p.pos), target=_vec(far))
        if hit_target is not None:
            headshot = self.rng.random() < (0.5 if self.cheat is Cheat.AIMBOT else 0.15)
            amount = self.rng.randint(18, 26) * (2 if headshot else 1)
            hit_target.health -= amount
            emit("damage", attacker=p.cn, target=hit_target.cn, weapon=WEAPON,
                 amount=amount, headshot=headshot)
            if hit_target.health <= 0:
                hit_target.alive = False
                hit_target.respawn_at = t + 3.0
                p.target = None
                emit("kill", attacker=p.cn, victim=hit_target.cn, weapon=WEAPON,
                     headshot=headshot)


def _vec(p: list[float]) -> dict[str, float]:
    return {"x": round(p[0], 3), "y": round(p[1], 3), "z": round(p[2], 3)}


def simulate_mixed(
    n_legit: int = 6,
    n_cheaters: int = 2,
    profile: Cheat = Cheat.AIMBOT,
    seconds: float = 60.0,
    tick_hz: int = 30,
    seed: int | None = None,
    match_id: str | None = None,
    with_ghost: bool = True,
) -> tuple[Iterator[list[dict[str, Any]]], dict[int, str]]:
    """Return (event-tick iterator, ground-truth labels by cn).

    The last ``n_cheaters`` client numbers are cheaters running ``profile``.
    """
    rng = random.Random(seed)
    match_id = match_id or f"mix-{uuid.uuid4().hex[:8]}"
    dt = 1.0 / tick_hz
    total = n_legit + n_cheaters

    players: list[CheatPlayer] = []
    labels: dict[int, str] = {}
    for cn in range(total):
        inner = SimPlayer(cn, f"p{cn:02d}", rng)
        cheat = profile if cn >= n_legit else Cheat.LEGIT
        players.append(CheatPlayer(inner, cheat, rng))
        labels[cn] = cheat.value

    def ghost_at(t: float) -> list[float] | None:
        # the phantom drifts slowly, so detecting it means tracking a moving
        # position per tick — not just "aimed at map centre"
        if not with_ghost:
            return None
        return [
            MAP_SIZE / 2 + 40 * math.sin(t * 0.3),
            MAP_SIZE / 2 + 40 * math.cos(t * 0.21),
            0.0,
        ]

    def gen() -> Iterator[list[dict[str, Any]]]:
        def base(t: float, kind: str) -> dict[str, Any]:
            return {"ts": round(t * 1000, 1), "match_id": match_id, "type": kind}

        first = []
        for cp in players:
            first.append({**base(0, "player_join"), "cn": cp.cn, "name": cp.inner.name})
            first.append({**base(0, "spawn"), "cn": cp.cn, "pos": _vec(cp.inner.pos)})
        yield first

        t = 0.0
        while t < seconds:
            t += dt
            out: list[dict[str, Any]] = []

            def emit(kind: str, **fields):
                out.append({**base(t, kind), **fields})

            ghost_pos = ghost_at(t)
            if ghost_pos is not None:
                emit("honeypot", hid=0, pos=_vec(ghost_pos))

            for cp in players:
                p = cp.inner
                if not p.alive:
                    continue
                # movement (shared legit model)
                dx, dy = p.waypoint[0] - p.pos[0], p.waypoint[1] - p.pos[1]
                dist = math.hypot(dx, dy)
                if dist < 2.0:
                    p.waypoint = p._new_waypoint()
                else:
                    step = min(dist, MOVE_SPEED * dt)
                    p.pos[0] += dx / dist * step
                    p.pos[1] += dy / dist * step

                cp.aim_and_fire(t, dt, [o for o in players if o is not cp], ghost_pos, emit)
                emit("tick", cn=p.cn, pos=_vec(p.pos),
                     yaw=round(p.yaw, 3) % 360.0, pitch=round(p.pitch, 3), alive=True)

            for cp in players:
                p = cp.inner
                if not p.alive and t >= getattr(p, "respawn_at", 0):
                    p.respawn()
                    out.append({**base(t, "spawn"), "cn": p.cn, "pos": _vec(p.pos)})
            yield out

        yield [{**base(t, "player_leave"), "cn": cp.cn} for cp in players]

    return gen(), labels


def main() -> None:
```

```py
"""SQLite event store. Raw events are kept as JSON so detectors can replay them."""

import json
import sqlite3
import threading
from pathlib import Path
from typing import Any

from .schema import Event, actor_of

_SCHEMA = """
CREATE TABLE IF NOT EXISTS events (
    id       INTEGER PRIMARY KEY AUTOINCREMENT,
    match_id TEXT    NOT NULL,
    ts       REAL    NOT NULL,
    type     TEXT    NOT NULL,
    actor    INTEGER,
    payload  TEXT    NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_events_match_ts ON events(match_id, ts);
CREATE INDEX IF NOT EXISTS idx_events_match_actor ON events(match_id, actor);
CREATE INDEX IF NOT EXISTS idx_events_type ON events(type);
"""


class EventStore:
    def __init__(self, path: str | Path):
        if str(path) != ":memory:":
            Path(path).parent.mkdir(parents=True, exist_ok=True)
        # FastAPI runs sync endpoints in worker threads, so share one
        # connection behind a lock rather than one per thread.
        self._conn = sqlite3.connect(str(path), check_same_thread=False)
        self._lock = threading.Lock()
        with self._lock:
            self._conn.execute("PRAGMA journal_mode=WAL")
            self._conn.executescript(_SCHEMA)

    def add_many(self, events: list[Event]) -> None:
        rows = [
            (e.match_id, e.ts, e.type, actor_of(e), e.model_dump_json())
            for e in events
        ]
        with self._lock, self._conn:
            self._conn.executemany(
                "INSERT INTO events (match_id, ts, type, actor, payload) VALUES (?, ?, ?, ?, ?)",
                rows,
            )

    def recent(
        self,
        limit: int = 100,
        type: str | None = None,
        match_id: str | None = None,
        actor: int | None = None,
    ) -> list[dict[str, Any]]:
        """Newest events first."""
        where, args = [], []
        for column, value in (("type", type), ("match_id", match_id), ("actor", actor)):
            if value is not None:
                where.append(f"{column} = ?")
                args.append(value)
        sql = "SELECT payload FROM events"
        if where:
            sql += " WHERE " + " AND ".join(where)
        sql += " ORDER BY id DESC LIMIT ?"
        args.append(limit)
        with self._lock:
            rows = self._conn.execute(sql, args).fetchall()
        return [json.loads(r[0]) for r in rows]

    def matches(self) -> list[dict[str, Any]]:
        with self._lock:
            rows = self._conn.execute(
                "SELECT match_id, COUNT(*), MIN(ts), MAX(ts) FROM events "
                "GROUP BY match_id ORDER BY MIN(id) DESC"
            ).fetchall()
        return [
            {"match_id": m, "events": n, "first_ts": a, "last_ts": b}
            for m, n, a, b in rows
        ]

    def players(self, match_id: str) -> list[dict[str, Any]]:
        with self._lock:
            rows = self._conn.execute(
                "SELECT payload FROM events WHERE match_id = ? "
                "AND type IN ('player_join', 'player_leave') ORDER BY id",
                (match_id,),
            ).fetchall()
        players: dict[int, dict[str, Any]] = {}
        for (payload,) in rows:
            ev = json.loads(payload)
            if ev["type"] == "player_join":
                players[ev["cn"]] = {"cn": ev["cn"], "name": ev["name"], "online": True}
            elif ev["cn"] in players:
                players[ev["cn"]]["online"] = False
        return sorted(players.values(), key=lambda p: p["cn"])

    def count(self) -> int:
        with self._lock:
            return self._conn.execute("SELECT COUNT(*) FROM events").fetchone()[0]

    def close(self) -> None:
        with self._lock:
            self._conn.close()
```

```py
"""Checks that each synthetic cheat leaves a telemetry signature distinct from
legit play. These are the ground truths the blue-team detector will be scored
against, so if a signature here is weak the detector's job is impossible."""

import math

import pytest

from aegis_collector.schema import EventAdapter
from aegis_collector.sim_cheat import Cheat, simulate_mixed


def _wrap180(deg: float) -> float:
    return (deg + 180.0) % 360.0 - 180.0


def _collect(profile, **kw):
    """Run a mixed match; return (events, labels)."""
    kw.setdefault("seconds", 40)
    kw.setdefault("seed", 11)
    ticks, labels = simulate_mixed(n_legit=6, n_cheaters=2, profile=profile, **kw)
    events = [ev for tick in ticks for ev in tick]
    return events, labels


def _max_turn_rate(events, cn, tick_hz=30):
    """Biggest single-tick angular velocity (deg/s) for one player."""
    yaws = [(e["ts"], e["yaw"]) for e in events if e["type"] == "tick" and e["cn"] == cn]
    worst = 0.0
    for (t0, y0), (t1, y1) in zip(yaws, yaws[1:]):
        dt = (t1 - t0) / 1000.0
        if dt > 0:
            worst = max(worst, abs(_wrap180(y1 - y0)) / dt)
    return worst


def test_all_generated_events_are_valid():
    events, _ = _collect(Cheat.AIMBOT)
    for ev in events:
        EventAdapter.validate_python(ev)


def test_labels_mark_last_players_as_cheaters():
    _, labels = _collect(Cheat.AIMBOT)
    assert labels[6] == "aimbot" and labels[7] == "aimbot"
    assert all(labels[cn] == "legit" for cn in range(6))


def test_aimbot_has_impossible_turn_rate():
    events, _ = _collect(Cheat.AIMBOT)
    legit = max(_max_turn_rate(events, cn) for cn in range(6))
    cheat = max(_max_turn_rate(events, cn) for cn in (6, 7))
    # aimbot snaps in one tick; a human's capped turn speed can't match it
    assert cheat > legit * 3


def test_aimbot_lands_far_more_shots():

        shots = sum(e["type"] == "shot" and e["cn"] == cn for e in events)
        hits = sum(e["type"] == "damage" and e["attacker"] == cn for e in events)
        return hits / shots if shots else 0.0

    legit = max(hit_rate(cn) for cn in range(6))
    cheat = min(hit_rate(cn) for cn in (6, 7))

def test_only_esp_players_aim_at_the_honeypot():
    """The telemetry tell the detector relies on: cheaters fire at the phantom,
    legit players (who were never told it exists) do not."""
    import math
    ANGLE = 6.0
    ticks, labels = simulate_mixed(n_legit=6, n_cheaters=2, profile=Cheat.ESP,
                                   seconds=45, seed=5)
    events = [ev for tick in ticks for ev in tick]
    ghost = {e["ts"]: (e["pos"]["x"], e["pos"]["y"])
             for e in events if e["type"] == "honeypot"}
    pos = {}
    for e in events:
        if e["type"] == "tick":
            pos.setdefault(e["ts"], {})[e["cn"]] = (e["pos"]["x"], e["pos"]["y"])
    at_ghost = {}
    for e in events:
        if e["type"] != "shot" or e["ts"] not in ghost:
            continue
        ox, oy = e["origin"]["x"], e["origin"]["y"]
        gx, gy = ghost[e["ts"]]
        aim = math.degrees(math.atan2(e["target"]["y"] - oy, e["target"]["x"] - ox))
        if abs(_wrap180(math.degrees(math.atan2(gy - oy, gx - ox)) - aim)) > ANGLE:
            continue
        enemy_near = any(
            abs(_wrap180(math.degrees(math.atan2(py - oy, px - ox)) - aim)) <= ANGLE
            for cn, (px, py) in pos.get(e["ts"], {}).items() if cn != e["cn"]
        )
        if not enemy_near:
            at_ghost[e["cn"]] = at_ghost.get(e["cn"], 0) + 1
    cheater_hits = sum(at_ghost.get(cn, 0) for cn, l in labels.items() if l != "legit")
    legit_hits = sum(at_ghost.get(cn, 0) for cn, l in labels.items() if l == "legit")
    assert cheater_hits >= 3
    assert legit_hits <= 2  # the occasional coincidence, below the flag threshold


def test_triggerbot_is_near_perfectly_accurate():
    """A triggerbot only pulls the trigger on a near-exact alignment, so it
    fires less often than a human but lands almost every shot — an
    inhuman per-shot accuracy that is its telemetry signature."""
    events, _ = _collect(Cheat.TRIGGERBOT)

    def hit_rate(cn):
        shots = sum(e["type"] == "shot" and e["cn"] == cn for e in events)
        hits = sum(e["type"] == "damage" and e["attacker"] == cn for e in events)
        return hits / shots if shots else 0.0

    legit = max(hit_rate(cn) for cn in range(6))
    cheat = min(hit_rate(cn) for cn in (6, 7))
    assert cheat > 0.95          # lands essentially everything it fires
    assert cheat > legit * 1.5   # far above any human
```

```tsx
import { useCallback, useEffect, useState } from "react";
import { api } from "./api";
import type { Alert, BanSnapshot, CaseReport, Replay } from "./api";
import { AlertsTable } from "./components/AlertsTable";
import { CasePanel } from "./components/CasePanel";
import { BanWavePanel } from "./components/BanWavePanel";
import { ReplayViewer } from "./components/ReplayViewer";
import { RedTeamPanel } from "./components/RedTeamPanel";

export function App() {
  const [alerts, setAlerts] = useState<Alert[]>([]);
  const [banwave, setBanwave] = useState<BanSnapshot | null>(null);
  const [selected, setSelected] = useState<Alert | null>(null);
  const [report, setReport] = useState<CaseReport | null>(null);
  const [replay, setReplay] = useState<Replay | null>(null);
  const [loadingCase, setLoadingCase] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const refresh = useCallback(async () => {
    try {
      const [a, b] = await Promise.all([api.alerts(), api.banwave()]);
      setAlerts(a);
      setBanwave(b);
      return a;
    } catch (e) {
      setError(String(e));
      return [];
    }
  }, []);

  useEffect(() => {
    refresh().then((a) => { if (a.length) select(a[0]); });
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, []);

  const select = useCallback(async (a: Alert) => {
    setSelected(a);
    setLoadingCase(true);
    setReport(null);
    try {
      const [c, r] = await Promise.all([
        api.case(a.match_id, a.cn),
        api.replay(a.match_id),
      ]);
      setReport(c);
      setReplay(r);
    } catch (e) {
      setError(String(e));
    } finally {
      setLoadingCase(false);
    }
  }, []);

  const inject = useCallback(async (profile: string, escalate: boolean) => {
    const res = await api.inject(profile, escalate);
    const all = await refresh();
    // jump straight to the freshly injected cheater so its case + replay show
    const fresh = all.find((a) => a.match_id === res.match_id);
    if (fresh) await select(fresh);
  }, [refresh, select]);

  const queueBan = useCallback(async () => {
    if (!selected) return;
    const snap = await api.queueBan(selected.match_id, selected.cn);
    setBanwave(snap);
    await refresh();
  }, [selected, refresh]);

  const releaseWave = useCallback(async () => {
    const snap = await api.releaseWave();
    setBanwave(snap);
    await refresh();
  }, [refresh]);

  const queued = !!selected && !!banwave?.queued.some(
    (r) => r.match_id === selected.match_id && r.cn === selected.cn
  );

  return (
    <div className="app">
      <header>
        <h1>Aegis AC <span className="sub">SOC dashboard</span></h1>
        <p>Server-side behavioural anti-cheat — live alerts, case investigation, 2D replay, ban waves.</p>
      </header>

      {error && <div className="error">API error: {error}. Is the analysis API running on :8008?</div>}

      <div className="grid">
        <aside className="col-alerts">
          <RedTeamPanel onInject={inject} />
          <AlertsTable
            alerts={alerts}
            selected={selected ? { match_id: selected.match_id, cn: selected.cn } : null}
            onSelect={select}
          />
```

```ts
// Typed client for the Aegis analysis API (aegis_soc.api).

export interface Alert {
  match_id: string;
  cn: number;
  name: string;
  suspicion: number;
  category: string | null;
  priority: "high" | "medium";
  queued_for_ban: boolean;
}

export interface MatchSummary {
  match_id: string;
  profile: string;
  players: number;
  flagged: number;
  duration_ms: number;
}

export type Disposition = "ban" | "shadow" | "monitor" | "clear";

export interface CaseReport {
  cn: number;
  name: string;
  category: string;
  confidence: number;
  disposition: Disposition;
  title: string;
  summary: string;
  evidence: string[];
  recommendation: string;
}

export interface ReplayPlayer {
  cn: number;
  name: string;
  flagged: boolean;
  category: string | null;
  suspicion: number;
}

// Compact row encodings from the API.
// trajectory point: [ts, x, y, yaw, alive]
export type TrajPoint = [number, number, number, number, number];
// shot: [cn, ts, ox, oy, tx, ty]
export type ShotRow = [number, number, number, number, number, number];
// honeypot: [ts, x, y]
export type GhostRow = [number, number, number];

export interface Replay {
  match_id: string;
  map_size: number;
  duration_ms: number;
  players: ReplayPlayer[];
  trajectories: Record<string, TrajPoint[]>;
  shots: ShotRow[];
  honeypot: GhostRow[];
}

export interface BanRecord {
  match_id: string;
  cn: number;
  name: string;
  category: string;
  confidence: number;
  queued_at: number;
  status: "queued" | "banned";
  banned_at: number | null;
}

export interface BanSnapshot {
  queued: BanRecord[];
  history: BanRecord[];
  waves_released: number;
  delay_seconds: number;
  seconds_until_due: number;
  enforcement_log: string[];
}

async function get<T>(url: string): Promise<T> {
  const r = await fetch(url);
  if (!r.ok) throw new Error(`${url} → ${r.status}`);
  return r.json() as Promise<T>;
}

async function post<T>(url: string): Promise<T> {
  const r = await fetch(url, { method: "POST" });
  if (!r.ok) throw new Error(`${url} → ${r.status}`);
  return r.json() as Promise<T>;
}

export const api = {
  alerts: () => get<Alert[]>("/api/alerts"),
  matches: () => get<MatchSummary[]>("/api/matches"),
  case: (matchId: string, cn: number) =>
    get<CaseReport>(`/api/matches/${matchId}/cases/${cn}`),
  replay: (matchId: string) => get<Replay>(`/api/matches/${matchId}/replay`),
  banwave: () => get<BanSnapshot>("/api/banwave"),
  queueBan: (matchId: string, cn: number) =>
    post<BanSnapshot>(`/api/banwave/queue/${matchId}/${cn}`),
  releaseWave: () => post<BanSnapshot & { released: BanRecord[] }>("/api/banwave/release"),
  inject: (profile: string, escalate: boolean) =>
    post<{ match_id: string; profile: string; alerts: Alert[]; escalated: boolean }>(
      `/api/redteam/inject?profile=${profile}&escalate=${escalate}`),
};
```

```tsx
function humanDelay(seconds: number): string {
  if (seconds <= 0) return "due now";
  if (seconds >= 3600) return `${(seconds / 3600).toFixed(1)}h`;
  if (seconds >= 60) return `${Math.round(seconds / 60)}m`;
  return `${Math.round(seconds)}s`;
}

export function BanWavePanel({ snapshot, onRelease }: Props) {
  if (!snapshot) return null;
  const { queued, history, waves_released, seconds_until_due, enforcement_log } = snapshot;
  return (

        <button className="release" disabled={queued.length === 0} onClick={onRelease}>
          Release wave now
        </button>
      </div>
      <p className="wave-note">
        Confirmed cheaters are banned together, not instantly — so cheat authors
        can't tell which match exposed them. Next auto-release in{" "}
        <strong>{humanDelay(seconds_until_due)}</strong>. Waves released: {waves_released}.
      </p>

      <h3>Queued <span className="count">{queued.length}</span></h3>
      <ul className="ban-list">
        {queued.map((r) => (
          <li key={`${r.match_id}:${r.cn}`}>
            <strong>{r.name}</strong> <span className="cat">{r.category}</span>

          </li>

        <>
          <h3>Enforcement log</h3>
          <pre className="log">{enforcement_log.join("\n")}</pre>
        </>
      )}
```

```tsx
import { useEffect, useRef, useState } from "react";
import type { Replay, TrajPoint } from "../api";

const SIZE = 560; // canvas px (square)
const PAD = 28;

interface Props {
  replay: Replay;
  suspectCn: number | null;
}

// Last trajectory point at or before time t.
function pointAt(traj: TrajPoint[], t: number): TrajPoint | null {
  let lo = 0;
  let found: TrajPoint | null = null;
  for (; lo < traj.length; lo++) {
    if (traj[lo][0] <= t) found = traj[lo];
    else break;
  }
  return found;
}

export function ReplayViewer({ replay, suspectCn }: Props) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const [time, setTime] = useState(0);
  const [playing, setPlaying] = useState(true);
  const raf = useRef<number>(0);
  const last = useRef<number>(0);

  // Reset to the start whenever a different match is loaded.
  useEffect(() => {
    setTime(0);
    setPlaying(true);
  }, [replay.match_id]);

  // Playback clock (4x real time so a 45s match plays in ~11s).
  useEffect(() => {
    if (!playing) return;
    last.current = performance.now();
    const tick = (now: number) => {
      const dt = (now - last.current) * 4;
      last.current = now;
      setTime((t) => (t + dt > replay.duration_ms ? 0 : t + dt));
      raf.current = requestAnimationFrame(tick);
    };
    raf.current = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf.current);
  }, [playing, replay.duration_ms]);

  // Draw.
  useEffect(() => {
    const ctx = canvasRef.current?.getContext("2d");
    if (!ctx) return;
    const S = replay.map_size;
    const scale = (SIZE - 2 * PAD) / S;
    const X = (x: number) => PAD + x * scale;
    const Y = (y: number) => PAD + (S - y) * scale; // flip so +y is up

    ctx.clearRect(0, 0, SIZE, SIZE);
    // arena
    ctx.fillStyle = "#0e1726";
    ctx.fillRect(0, 0, SIZE, SIZE);
    ctx.strokeStyle = "#24324a";
    ctx.lineWidth = 1;
    for (let g = 0; g <= 4; g++) {
      const p = PAD + ((SIZE - 2 * PAD) / 4) * g;
      ctx.beginPath(); ctx.moveTo(p, PAD); ctx.lineTo(p, SIZE - PAD); ctx.stroke();
      ctx.beginPath(); ctx.moveTo(PAD, p); ctx.lineTo(SIZE - PAD, p); ctx.stroke();
    }

    // recent shots (fading 250ms trail)
    for (const [cn, ts, ox, oy, tx, ty] of replay.shots) {
      const age = time - ts;
      if (age < 0 || age > 250) continue;
      ctx.strokeStyle = cn === suspectCn
        ? `rgba(239,68,68,${1 - age / 250})`
        : `rgba(148,163,184,${0.5 * (1 - age / 250)})`;
      ctx.lineWidth = cn === suspectCn ? 1.5 : 1;
      ctx.beginPath(); ctx.moveTo(X(ox), Y(oy)); ctx.lineTo(X(tx), Y(ty)); ctx.stroke();
    }

    // honeypot phantom (what the wallhack can "see")
    const ghost = pointAtGhost(replay.honeypot, time);
    if (ghost) {
      const pulse = 5 + 2 * Math.sin(time / 120);
      ctx.strokeStyle = "#f59e0b";
      ctx.fillStyle = "rgba(245,158,11,0.18)";
      ctx.lineWidth = 1.5;
      ctx.beginPath(); ctx.arc(X(ghost[1]), Y(ghost[2]), pulse, 0, Math.PI * 2);
      ctx.fill(); ctx.stroke();
    }

    // players
    for (const p of replay.players) {
      const traj = replay.trajectories[String(p.cn)];
      if (!traj || traj.length === 0) continue;
      const isSuspect = p.cn === suspectCn;
      const color = isSuspect ? "#ef4444" : p.flagged ? "#f59e0b" : "#38bdf8";

      // path up to now
      ctx.strokeStyle = isSuspect ? "rgba(239,68,68,0.9)" : "rgba(56,189,248,0.25)";
      ctx.lineWidth = isSuspect ? 2 : 1;
      ctx.beginPath();
      let started = false;
      for (const pt of traj) {
        if (pt[0] > time) break;
        const cx = X(pt[1]); const cy = Y(pt[2]);
        if (!started) { ctx.moveTo(cx, cy); started = true; } else ctx.lineTo(cx, cy);
      }
      ctx.stroke();

      const cur = pointAt(traj, time);
      if (!cur) continue;
      const cx = X(cur[1]); const cy = Y(cur[2]);
      // crosshair direction
      const rad = (cur[3] * Math.PI) / 180;
      ctx.strokeStyle = color;
      ctx.lineWidth = isSuspect ? 2 : 1;
      ctx.beginPath();
      ctx.moveTo(cx, cy);
      ctx.lineTo(cx + Math.cos(rad) * (isSuspect ? 22 : 14),
                 cy - Math.sin(rad) * (isSuspect ? 22 : 14));
      ctx.stroke();
      // dot
      ctx.fillStyle = color;
      ctx.beginPath(); ctx.arc(cx, cy, isSuspect ? 6 : 4, 0, Math.PI * 2); ctx.fill();
      if (isSuspect) {
        ctx.fillStyle = "#fecaca";
        ctx.font = "11px system-ui";
        ctx.fillText(p.name, cx + 8, cy - 8);
      }
    }
  }, [time, replay, suspectCn]);

  return (
    <div className="replay">
      <div className="replay-controls">
        <button onClick={() => setPlaying((p) => !p)}>
          {playing ? "⏸ Pause" : "▶ Play"}
        </button>
        <input
          type="range" min={0} max={replay.duration_ms} value={time}
          onChange={(e) => { setPlaying(false); setTime(Number(e.target.value)); }}
        />
        <span className="clock">{(time / 1000).toFixed(1)}s</span>
      </div>
      <canvas ref={canvasRef} width={SIZE} height={SIZE} className="replay-canvas" />
      <div className="legend">
        <span><i className="dot suspect" /> suspect (crosshair path)</span>
        <span><i className="dot ghost" /> honeypot phantom</span>
        <span><i className="dot clean" /> other players</span>
      </div>
    </div>
  );
}

function pointAtGhost(ghost: [number, number, number][], t: number) {
  let found: [number, number, number] | null = null;
  for (const g of ghost) {
    if (g[0] <= t) found = g; else break;
  }
  return found;
}
```

`detection/aegis_detection/evaluate.py`:

```py
"""Score the detector against the simulator's ground-truth labels.

Runs many mixed matches per cheat profile, flags players, and compares to the
known labels to produce a confusion matrix and detection rate per profile.
This is the number that goes on the CV: "catches X% of aimbots at a Y% false
positive rate on Z simulated matches."

    python -m aegis_detection.evaluate --matches 20
"""

import argparse
from collections import defaultdict
from dataclasses import dataclass

from aegis_collector.sim_cheat import Cheat, simulate_mixed

from .features import extract_features
from .rules import judge_all


@dataclass
class Tally:
    tp: int = 0  # cheater, flagged
    fp: int = 0  # legit, flagged
    tn: int = 0  # legit, not flagged
    fn: int = 0  # cheater, missed

    @property
    def detection_rate(self) -> float:
        d = self.tp + self.fn
        return self.tp / d if d else 0.0

    @property
    def precision(self) -> float:
        d = self.tp + self.fp
        return self.tp / d if d else 1.0

    @property
    def fp_rate(self) -> float:
        d = self.fp + self.tn
        return self.fp / d if d else 0.0


def evaluate(matches: int = 20, seconds: float = 45, legit: int = 6,
             cheaters: int = 2, base_seed: int = 1000) -> dict[str, Tally]:
    profiles = [c for c in Cheat if c is not Cheat.LEGIT]
    per_profile: dict[str, Tally] = defaultdict(Tally)
    overall = Tally()

    for profile in profiles:
        for m in range(matches):
            ticks, labels = simulate_mixed(
                n_legit=legit, n_cheaters=cheaters, profile=profile,
                seconds=seconds, seed=base_seed + m,
            )
            events = [ev for tick in ticks for ev in tick]
            verdicts = {v.cn: v for v in judge_all(extract_features(events))}

            for cn, label in labels.items():
                is_cheater = label != Cheat.LEGIT.value
                flagged = verdicts[cn].is_cheat if cn in verdicts else False
                t = per_profile[profile.value]
                for bucket in (t, overall):
                    if is_cheater and flagged:
                        bucket.tp += 1
                    elif is_cheater and not flagged:
                        bucket.fn += 1
                    elif not is_cheater and flagged:
                        bucket.fp += 1
                    else:
                        bucket.tn += 1

    per_profile["OVERALL"] = overall
    return per_profile


def _print(results: dict[str, Tally]) -> None:
    print(f"{'profile':<18}{'detect':>8}{'precision':>11}{'FP rate':>9}"
          f"{'TP':>5}{'FN':>4}{'FP':>4}{'TN':>5}")
    print("-" * 64)
    for name, t in results.items():
        print(f"{name:<18}{t.detection_rate*100:>7.0f}%{t.precision*100:>10.0f}%"
              f"{t.fp_rate*100:>8.0f}%{t.tp:>5}{t.fn:>4}{t.fp:>4}{t.tn:>5}")


def main() -> None:
    ap = argparse.ArgumentParser(description=__doc__)
    ap.add_argument("--matches", type=int, default=20, help="matches per profile")
    ap.add_argument("--seconds", type=float, default=45)
    args = ap.parse_args()
    _print(evaluate(matches=args.matches, seconds=args.seconds))


if __name__ == "__main__":
    main()
```

`detection/aegis_detection/features.py`:

```py
"""Feature extraction: raw telemetry events -> one feature row per player.

Everything here is computable from the exact telemetry the collector already
stores, so a detector trained on these features can run against real matches,
not just the simulator. Each feature targets a known cheat tell:

    max_turn_rate   deg/s, peak single-tick view change  -> aimbot snap
    p95_turn_rate   deg/s, sustained fast turning         -> humanised aimbot
    hit_rate        damage dealt per shot                 -> aimbot / triggerbot
    headshot_rate   headshots per hit                     -> aim assistance
    honeypot_shots  shots aimed at the server's phantom   -> ESP / wallhack
"""

import math
from collections import defaultdict
from dataclasses import dataclass, field
from typing import Any

# A view change slower than this between two ticks separated by a bigger gap is
# almost certainly a respawn teleport, not a turn — skip those pairs.
MAX_TICK_GAP_S = 0.1
# A shot whose direction lands within this of the (hidden) honeypot phantom is
# treated as fired AT the phantom — but only when no *real* enemy is within the
# same angle of the aim, so a legit player shooting an enemy who merely happens
# to be near the phantom's bearing is never counted.
HONEYPOT_ANGLE_DEG = 6.0


def _wrap180(deg: float) -> float:
    return (deg + 180.0) % 360.0 - 180.0


@dataclass
class PlayerFeatures:
    cn: int
    name: str = ""
    ticks: int = 0
    shots: int = 0
    hits: int = 0
    kills: int = 0
    deaths: int = 0
    headshots: int = 0
    max_turn_rate: float = 0.0
    p95_turn_rate: float = 0.0
    honeypot_shots: int = 0
    _turn_rates: list[float] = field(default_factory=list, repr=False)

    @property
    def hit_rate(self) -> float:
        return self.hits / self.shots if self.shots else 0.0

    @property
    def headshot_rate(self) -> float:
        return self.headshots / self.hits if self.hits else 0.0

    def as_dict(self) -> dict[str, Any]:
        return {
            "cn": self.cn, "name": self.name, "ticks": self.ticks,
            "shots": self.shots, "hits": self.hits, "kills": self.kills,
            "deaths": self.deaths,
            "hit_rate": round(self.hit_rate, 3),
            "headshot_rate": round(self.headshot_rate, 3),
            "max_turn_rate": round(self.max_turn_rate, 1),
            "p95_turn_rate": round(self.p95_turn_rate, 1),
            "honeypot_shots": self.honeypot_shots,
        }


def _percentile(values: list[float], pct: float) -> float:
    if not values:
        return 0.0
    s = sorted(values)
    k = max(0, min(len(s) - 1, int(round(pct / 100 * (len(s) - 1)))))
    return s[k]


def extract_features(events: list[dict[str, Any]]) -> dict[int, PlayerFeatures]:
    """Build a feature row per player from one match's events."""
    feats: dict[int, PlayerFeatures] = {}

    def row(cn: int) -> PlayerFeatures:
        if cn not in feats:
            feats[cn] = PlayerFeatures(cn=cn)
        return feats[cn]

    last_tick: dict[int, tuple[float, float]] = {}        # cn -> (ts_ms, yaw)
    honeypot: dict[float, tuple[float, float]] = {}       # ts_ms -> (x, y)
    positions: dict[float, dict[int, tuple[float, float]]] = defaultdict(dict)

    for ev in events:
        t = ev["type"]
        if t == "player_join":
            row(ev["cn"]).name = ev["name"]
        elif t == "tick":
            r = row(ev["cn"])
            r.ticks += 1
            positions[ev["ts"]][ev["cn"]] = (ev["pos"]["x"], ev["pos"]["y"])
            prev = last_tick.get(ev["cn"])
            if prev is not None:
                dt = (ev["ts"] - prev[0]) / 1000.0
                if 0 < dt <= MAX_TICK_GAP_S:
                    rate = abs(_wrap180(ev["yaw"] - prev[1])) / dt
                    r._turn_rates.append(rate)
                    r.max_turn_rate = max(r.max_turn_rate, rate)
            last_tick[ev["cn"]] = (ev["ts"], ev["yaw"])
        elif t == "shot":
            row(ev["cn"]).shots += 1
        elif t == "damage":
            r = row(ev["attacker"])
            r.hits += 1
            if ev.get("headshot"):
                r.headshots += 1
        elif t == "kill":
            row(ev["attacker"]).kills += 1
            row(ev["victim"]).deaths += 1
        elif t == "honeypot":
            honeypot[ev["ts"]] = (ev["pos"]["x"], ev["pos"]["y"])

    for r in feats.values():
        r.p95_turn_rate = _percentile(r._turn_rates, 95)

    _score_honeypot(events, honeypot, positions, feats)
    return feats


def _score_honeypot(events, honeypot, positions, feats) -> None:
    """Count shots a player aimed at the phantom entity. Legit clients are never
    told it exists, so aiming at it — a moving target, tracked per tick — is a
    near-certain wallhack/ESP tell. A shot only counts when the phantom is on
    the aim line AND no real enemy is, so shooting an enemy who merely happens
    to share the phantom's bearing is not mistaken for a wallhack."""
    if not honeypot:
        return
    for ev in events:
        if ev["type"] != "shot":
            continue
        ghost = honeypot.get(ev["ts"])
        if ghost is None:
            continue
        shooter = ev["cn"]
        ox, oy = ev["origin"]["x"], ev["origin"]["y"]
        aim = math.degrees(math.atan2(ev["target"]["y"] - oy, ev["target"]["x"] - ox))
        to_ghost = math.degrees(math.atan2(ghost[1] - oy, ghost[0] - ox))
        if abs(_wrap180(aim - to_ghost)) > HONEYPOT_ANGLE_DEG:
            continue
        # is a real enemy also on this aim line? then it's a normal shot
        enemy_near = any(
            abs(_wrap180(math.degrees(math.atan2(py - oy, px - ox)) - aim))
            <= HONEYPOT_ANGLE_DEG
            for cn, (px, py) in positions.get(ev["ts"], {}).items()
            if cn != shooter
        )
        if not enemy_near:
            feats[shooter].honeypot_shots += 1
```

`detection/aegis_detection/rules.py`:

```py
"""Rule-based detector.

Explainable on purpose: every flag comes with the feature that tripped it and a
human-readable reason, which is what the AI SOC analyst (Phase 4) and the replay
viewer (Phase 5) quote back. An ML model comes later and will be scored against
exactly these same labelled matches, so we can show it beats the rules.

Each rule reads a PlayerFeatures row and, if it fires, returns a Hit with a
confidence and the cheat category it points to. A player's overall suspicion is
the strongest single hit, nudged up when several independent rules agree.
"""

from dataclasses import dataclass, field

from .features import PlayerFeatures

# Minimum activity before a rate-based rule is trusted — protects players who
# barely fired from being flagged on noise.
MIN_SHOTS = 8
MIN_HITS = 6

# A human flick tops out a few hundred deg/s; an aimbot snap is an order of
# magnitude faster because it completes inside one server tick.
TURN_IMPOSSIBLE = 900.0   # deg/s -> near-certain aimbot
TURN_SUSTAINED = 500.0    # deg/s at p95 -> fast, suspicious if paired with accuracy

HIT_RATE_INHUMAN = 0.90   # lands almost everything -> triggerbot / aimbot
HIT_RATE_HIGH = 0.65      # strong, suspicious when paired with fast turning
HEADSHOT_SUSPICIOUS = 0.50
MIN_HONEYPOT_SHOTS = 3    # shots at the phantom entity -> ESP / wallhack

CHEAT_THRESHOLD = 0.60    # overall suspicion at/above this -> flagged


@dataclass
class Hit:
    rule: str
    category: str
    confidence: float
    reason: str


@dataclass
class Verdict:
    cn: int
    name: str
    suspicion: float
    is_cheat: bool
    category: str | None
    hits: list[Hit] = field(default_factory=list)

    def as_dict(self) -> dict:
        return {
            "cn": self.cn, "name": self.name,
            "suspicion": round(self.suspicion, 3),
            "is_cheat": self.is_cheat, "category": self.category,
            "reasons": [h.reason for h in self.hits],
        }


def _rules(f: PlayerFeatures) -> list[Hit]:
    hits: list[Hit] = []

    if f.max_turn_rate > TURN_IMPOSSIBLE:
        hits.append(Hit(
            "impossible_turn", "aimbot", 0.96,
            f"view snapped at {f.max_turn_rate:.0f} deg/s "
            f"(human flicks stay well under {TURN_IMPOSSIBLE:.0f})",
        ))

    if f.shots >= MIN_SHOTS and f.hit_rate >= HIT_RATE_INHUMAN:
        hits.append(Hit(
            "inhuman_accuracy", "triggerbot", 0.90,
            f"landed {f.hit_rate*100:.0f}% of {f.shots} shots",
        ))

    if (f.shots >= MIN_SHOTS and f.hit_rate >= HIT_RATE_HIGH
            and f.p95_turn_rate > TURN_SUSTAINED):
        hits.append(Hit(
            "fast_and_accurate", "humanised_aimbot", 0.80,
            f"{f.hit_rate*100:.0f}% accuracy with sustained "
            f"{f.p95_turn_rate:.0f} deg/s turns",
        ))

    if f.honeypot_shots >= MIN_HONEYPOT_SHOTS:
        hits.append(Hit(
            "honeypot", "esp", 0.95,
            f"aimed at the phantom entity {f.honeypot_shots} times — "
            f"only a wallhack can see it",
        ))

    if f.hits >= MIN_HITS and f.headshot_rate >= HEADSHOT_SUSPICIOUS:
        hits.append(Hit(
            "high_headshot", "aim_assistance", 0.45,
            f"{f.headshot_rate*100:.0f}% of hits were headshots",
        ))

    return hits


def judge(f: PlayerFeatures) -> Verdict:
    hits = sorted(_rules(f), key=lambda h: h.confidence, reverse=True)
    if not hits:
        return Verdict(f.cn, f.name, 0.0, False, None, [])

    suspicion = hits[0].confidence
    # independent corroboration raises confidence, but never past 0.99
    if len(hits) > 1:
        suspicion = min(0.99, suspicion + 0.03 * (len(hits) - 1))

    return Verdict(
        cn=f.cn, name=f.name, suspicion=suspicion,
        is_cheat=suspicion >= CHEAT_THRESHOLD,
        category=hits[0].category, hits=hits,
    )


def judge_all(feats: dict[int, PlayerFeatures]) -> list[Verdict]:
    return sorted(
        (judge(f) for f in feats.values()),
        key=lambda v: v.suspicion, reverse=True,
    )
```

```py
from aegis_collector.sim_cheat import Cheat, simulate_mixed
from aegis_detection.evaluate import evaluate
from aegis_detection.features import extract_features

def _run(profile, seed=42, seconds=45, legit=6, cheaters=2):
    ticks, labels = simulate_mixed(
        n_legit=legit, n_cheaters=cheaters, profile=profile,
        seconds=seconds, seed=seed,
    )

def test_aimbot_flagged_with_snap_reason():
    verdicts, labels = _run(Cheat.AIMBOT)
    cheats = [v for cn, v in verdicts.items() if labels[cn] == "aimbot"]
    assert cheats and all(v.is_cheat for v in cheats)
    # the explanation should name the impossible snap
    assert any("snapped" in h.reason for v in cheats for h in v.hits)


@pytest.mark.parametrize("profile", [c for c in Cheat if c is not Cheat.LEGIT])
def test_catches_every_cheat_profile(profile):
    verdicts, labels = _run(profile)
    for cn, label in labels.items():
        if label != "legit":
            assert verdicts[cn].is_cheat, f"missed {label} (cn {cn})"


@pytest.mark.parametrize("profile", [c for c in Cheat if c is not Cheat.LEGIT])
def test_no_false_positive_on_legit(profile):
    verdicts, labels = _run(profile)
    for cn, label in labels.items():
        if label == "legit":
            v = verdicts[cn]
            assert not v.is_cheat, (
                f"legit cn {cn} flagged as {v.category} "
                f"(suspicion {v.suspicion}) in a {profile.value} match"
            )


def test_pure_legit_match_has_no_flags():
    verdicts, labels = _run(Cheat.LEGIT, cheaters=0, legit=8)
    assert all(not v.is_cheat for v in verdicts.values())


def test_profile_signature_present_in_reasons():
    """The cheat's own signature must appear among a flagged player's rule hits.
    Categories can co-occur (an ESP that snap-aims also trips the aimbot rule),
    so we check the expected category is *somewhere* in the hits, not that it
    ranks first."""
    expect = {
        Cheat.AIMBOT: {"aimbot"},
        Cheat.TRIGGERBOT: {"triggerbot", "aimbot"},
        Cheat.HUMANISED: {"humanised_aimbot", "triggerbot", "aimbot"},
        Cheat.ESP: {"esp"},

    for profile, expected in expect.items():
        verdicts, labels = _run(profile)
        for cn, label in labels.items():
            if label != "legit":
                categories = {h.category for h in verdicts[cn].hits}
                assert categories & expected, (
                    f"{profile.value} cn {cn}: hits {categories} "
                    f"lack any of {expected}"
                )


def test_suspicion_never_exceeds_one():
    for profile in Cheat:
        verdicts, _ = _run(profile, cheaters=0 if profile is Cheat.LEGIT else 2)
        assert all(0.0 <= v.suspicion <= 1.0 for v in verdicts.values())


def test_evaluate_scores_high_detection_low_fp():
    results = evaluate(matches=6, seconds=40)
    overall = results["OVERALL"]
    assert overall.detection_rate >= 0.90
    assert overall.fp_rate <= 0.05
```

`soc-agent/aegis_soc/analyst.py`:

```py
"""The SOC analyst: turns a detector alert into a reviewed case report.

Two interchangeable backends:

* ``HeuristicAnalyst`` - deterministic, offline, no API key. It runs the same
  investigation tools an agent would and composes a report from the findings.
  This is what the tests and the default demo use, so the whole pipeline is
  reproducible with zero external dependencies.

* ``LLMAnalyst`` - a real tool-using agent (Anthropic SDK). It is handed the
  investigation tools and decides which evidence to gather, then emits the case
  report as a validated structured output. This is the Phase 4 headline; it is
  only imported/instantiated when the ``anthropic`` package and an API key are
  present.

``build_analyst()`` picks the LLM backend when it can and falls back to the
heuristic one otherwise, so callers never have to care which is running.
"""

import os
from typing import Protocol

from .evidence import Investigation, MatchContext
from .report import TAXONOMY, CaseReport

MODEL = "claude-opus-5-5"

SYSTEM_PROMPT = """\
You are a security operations analyst on a game anti-cheat team. A behavioural \
detector has flagged a player in a match and opened an alert. Your job is to \
investigate the alert using the tools provided and file a case report that a \
human moderator will review before any action is taken.

You never ban a player yourself - you recommend a disposition and a human \
approves it. Be rigorous and fair: flagged players are sometimes just skilled, \
and a false ban is worse than a missed cheat here.

Cheat taxonomy to classify into:
{taxonomy}

How to work:
1. Pull the suspect's overview to see the detector's rule hits.
2. Compare them to the clean cohort with the baseline tool - a z-score far \
above the lobby's normal players is strong evidence; a value merely high is not.
3. Gather the specific evidence for the suspected cheat: turn_timeline for \
aimbot snaps, honeypot for ESP/wallhack (shots at the phantom entity that no \
legitimate client can see are near-conclusive).
4. Weigh it and file one case report.

Dispositions: "ban" (near-certain), "shadow" (confident - queue for a delayed \
ban wave so cheat authors can't correlate detection), "monitor" (suspicious but \
not conclusive), "clear" (the flag doesn't hold up)."""


class Analyst(Protocol):
    def investigate(self, ctx: MatchContext, cn: int) -> CaseReport: ...


# --------------------------------------------------------------------------
# Deterministic backend
# --------------------------------------------------------------------------
def _disposition(category: str, confidence: float) -> str:
    if confidence < 0.6:
        return "clear"
    if category == "aim_assistance":
        return "monitor"
    if confidence >= 0.92:
        return "ban"
    if confidence >= 0.8:
        return "shadow"
    return "monitor"


class HeuristicAnalyst:
    """Composes a case report from the investigation tools, no LLM involved."""

    def investigate(self, ctx: MatchContext, cn: int) -> CaseReport:
        inv = Investigation(ctx)
        ov = inv.overview(cn)
        base = inv.baseline(cn)
        hp = inv.honeypot(cn)
        turns = inv.turn_timeline(cn)

        verdict = ctx.verdicts[cn]
        category = verdict.category or "inconclusive"
        confidence = verdict.suspicion
        disposition = _disposition(category, confidence)

        evidence: list[str] = [h["reason"] for h in ov["detector"]["rule_hits"]]
        if "comparisons" in base:
            worst = max(
                (c for c in base["comparisons"] if c["z_score"] != "inf"),
                key=lambda c: c["z_score"], default=None,
            )
            inf = [c for c in base["comparisons"] if c["z_score"] == "inf"]
            if inf:
                c = inf[0]
                evidence.append(
                    f"{c['metric']} of {c['suspect']} vs a clean-cohort max of "
                    f"{c['cohort_max']} - off the scale for this lobby")
            elif worst is not None and worst["z_score"] >= 2:
                evidence.append(
                    f"{worst['metric']} is {worst['z_score']} standard deviations "
                    f"above the clean cohort ({worst['suspect']} vs mean "
                    f"{worst['cohort_mean']})")
        if hp.get("blind_shots_at_phantom"):
            evidence.append(
                f"{hp['blind_shots_at_phantom']} shots at the phantom entity with "
                f"no real enemy on the aim line - impossible without a wallhack")
        if turns["sharpest_turns"] and category in ("aimbot", "humanised_aimbot"):
            fastest = turns["sharpest_turns"][0]
            evidence.append(
                f"peak view snap of {fastest['deg_per_s']} deg/s at t={fastest['ts']}ms")

        summary, recommendation = _narrative(category, confidence, disposition, ov)
        return CaseReport(
            cn=cn, name=ov["name"], category=category,
            confidence=round(confidence, 2), disposition=disposition,
            title=f"{category.replace('_', ' ')} - {ov['name']}",
            summary=summary, evidence=evidence or ["detector flag with no detail"],
            recommendation=recommendation,
        )


def _narrative(category: str, confidence: float, disposition: str, ov: dict):
    name = ov["name"]
    stats = ov["stats"]
    desc = TAXONOMY.get(category, "Unrecognised pattern.")
    summary = (
        f"{name} was flagged for {category.replace('_', ' ')}. {desc} "
        f"They landed {stats['hit_rate']*100:.0f}% of {stats['shots']} shots "
        f"with a peak turn rate of {stats['max_turn_rate']:.0f} deg/s across "
        f"{stats['kills']} kills. The pattern is {'well' if confidence >= 0.9 else 'partly'} "
        f"outside what the other players in the match produced."
    )
    actions = {
        "ban": "Approve a ban: the evidence is conclusive.",
        "shadow": "Queue for the next ban wave rather than banning now, so the "
                  "cheat author cannot tell which match exposed them.",
        "monitor": "Do not action yet - keep the player under watch and "
                   "re-evaluate across more matches.",
        "clear": "Dismiss the alert; the flag does not hold up.",
    }
    return summary, actions[disposition]


# --------------------------------------------------------------------------
# LLM backend (real tool-using agent)
# --------------------------------------------------------------------------
class LLMAnalyst:
    """A tool-using agent that investigates the alert with Claude, then files
    the case report as a validated structured output.

    Kept import-light: ``anthropic`` is imported lazily so the package works
    without it. The investigation tools are the exact same functions the
    heuristic backend calls - the model just decides which to use and how to
    weigh them.
    """

    def __init__(self, model: str = MODEL, max_iterations: int = 8, client=None):
        import anthropic  # noqa: F401  (fail fast if the SDK is missing)
        self.model = model
        self.max_iterations = max_iterations
        self._anthropic = anthropic
        self._client = client or anthropic.Anthropic()

    def _tools(self, inv: Investigation):
        """Expose the investigation methods as strict tool definitions + a
        dispatch table. Hand-written schemas keep us off the beta tool-runner
        decorator and let the final report use structured outputs."""
        defs = [
            ("roster", "List all players with the detector's suspicion score.", {}),
            ("overview", "Full stats and detector rule hits for one player.",
             {"cn": {"type": "integer"}}),
            ("baseline", "Z-score the player against the match's unflagged players.",
             {"cn": {"type": "integer"}}),
            ("turn_timeline", "The sharpest single-tick view snaps for a player.",
             {"cn": {"type": "integer"}}),
            ("honeypot", "Shots the player aimed at the hidden phantom entity.",
             {"cn": {"type": "integer"}}),
        ]
        tools = []
        for name, desc, props in defs:
            tools.append({
                "name": name, "description": desc, "strict": True,
                "input_schema": {
                    "type": "object", "properties": props,
                    "required": list(props), "additionalProperties": False,
                },
            })
        dispatch = {
            "roster": lambda **_: inv.roster(),
            "overview": lambda cn: inv.overview(cn),
            "baseline": lambda cn: inv.baseline(cn),
            "turn_timeline": lambda cn: inv.turn_timeline(cn),
            "honeypot": lambda cn: inv.honeypot(cn),
        }
        return tools, dispatch

    def investigate(self, ctx: MatchContext, cn: int) -> CaseReport:
        import json

        inv = Investigation(ctx)
        tools, dispatch = self._tools(inv)
        verdict = ctx.verdicts[cn]
        system = SYSTEM_PROMPT.format(
            taxonomy="\n".join(f"- {k}: {v}" for k, v in TAXONOMY.items()))
        messages = [{
            "role": "user",
            "content": (
                f"Alert on match {ctx.match_id}: player cn={cn} ({verdict.name}) "
                f"flagged with suspicion {verdict.suspicion:.2f}, suspected "
                f"{verdict.category}. Investigate and file a case report."
            ),
        }]

        # Investigation loop - the agent drives which tools to call.
        for _ in range(self.max_iterations):
            resp = self._client.messages.create(
                model=self.model, max_tokens=16000,
                thinking={"type": "adaptive"},
                system=system, tools=tools, messages=messages,
            )
            messages.append({"role": "assistant", "content": resp.content})
            if resp.stop_reason != "tool_use":
                break
            results = []
            for block in resp.content:
                if block.type != "tool_use":
                    continue
                try:
                    out = dispatch[block.name](**block.input)
                    results.append({"type": "tool_result", "tool_use_id": block.id,
                                    "content": json.dumps(out)})
                except Exception as exc:  # surface tool errors to the model
                    results.append({"type": "tool_result", "tool_use_id": block.id,
                                    "content": f"error: {exc}", "is_error": True})
            messages.append({"role": "user", "content": results})

        # Synthesis - force a schema-valid case report out of the findings.
        messages.append({
            "role": "user",
            "content": "File your case report now based on the evidence you gathered.",
        })
        parsed = self._client.messages.parse(
            model=self.model, max_tokens=16000,
            system=system, messages=messages, output_format=CaseReport,
        )
        report = parsed.parsed_output
        report.cn, report.name = cn, verdict.name  # trust the alert for identity
        return report


def build_analyst(prefer_llm: bool = True) -> Analyst:
    """Return the LLM analyst when the SDK and an API key are available,
    otherwise the deterministic one."""
    if prefer_llm and os.environ.get("ANTHROPIC_API_KEY"):
        try:
            return LLMAnalyst()
        except Exception:
            pass
    return HeuristicAnalyst()
```

`soc-agent/aegis_soc/api.py`:

```py
"""Analysis API for the dashboard.

Composes the whole stack behind an HTTP surface the TypeScript dashboard
consumes: detector alerts with risk scores, SOC case reports, 2D replay data,
and the delayed ban-wave queue.

For the demo it seeds itself with a spread of simulated matches on startup, so
the dashboard has something to show with a single `uvicorn` command and no game
server wired up yet. Each match is detected and (lazily) investigated once and
cached.

    uvicorn aegis_soc.api:create_app --factory --port 8008
"""

from dataclasses import dataclass, field
from typing import Any

from fastapi import FastAPI, HTTPException
from fastapi.middleware.cors import CORSMiddleware

from aegis_collector.sim import MAP_SIZE
from aegis_collector.sim_cheat import Cheat, simulate_mixed

from .analyst import Analyst, HeuristicAnalyst, build_analyst
from .enforcement import BanWave
from .evidence import MatchContext
from .notify import Notifier
from .report import CaseReport
from .triage import AlertQueue

# The matches the demo seeds on startup: (match_id, profile, n_cheaters, seed).
SEED_MATCHES = [
    ("scrim-01-esp", Cheat.ESP, 2, 5),
    ("scrim-02-aimbot", Cheat.AIMBOT, 1, 11),
    ("scrim-03-triggerbot", Cheat.TRIGGERBOT, 1, 23),
    ("scrim-04-humanised", Cheat.HUMANISED, 2, 31),
    ("scrim-05-clean", Cheat.LEGIT, 0, 40),
]


@dataclass
class MatchData:
    match_id: str
    profile: str
    events: list[dict[str, Any]]
    ctx: MatchContext
    labels: dict[int, str]
    reports: dict[int, CaseReport] = field(default_factory=dict)


class AnalysisService:
    def __init__(self, analyst: Analyst | None = None,
                 ban_delay_seconds: float = 3600.0,
                 notifier: Notifier | None = None) -> None:
        self.analyst: Analyst = analyst or HeuristicAnalyst()
        self.matches: dict[str, MatchData] = {}
        self.banwave = BanWave(delay_seconds=ban_delay_seconds)
        self.notifier = notifier or Notifier()
        self.notifications: list[dict[str, Any]] = []
        self._live_counter = 0

    def seed(self) -> None:
        for match_id, profile, n_cheat, seed in SEED_MATCHES:
            ticks, labels = simulate_mixed(
                n_legit=6, n_cheaters=n_cheat, profile=profile,
                seconds=45, seed=seed,
            )
            events = [ev for tick in ticks for ev in tick]
            ctx = MatchContext.from_events(events, match_id=match_id)
            self.matches[match_id] = MatchData(
                match_id=match_id, profile=profile.value,
                events=events, ctx=ctx, labels=labels)

    # --- queries ----------------------------------------------------------
    def _match(self, match_id: str) -> MatchData:
        md = self.matches.get(match_id)
        if md is None:
            raise HTTPException(404, f"no match {match_id}")
        return md

    def match_summaries(self) -> list[dict[str, Any]]:
        out = []
        for md in self.matches.values():
            flagged = sum(v.is_cheat for v in md.ctx.verdicts.values())
            out.append({
                "match_id": md.match_id, "profile": md.profile,
                "players": len(md.ctx.verdicts), "flagged": flagged,
                "duration_ms": max((e["ts"] for e in md.events), default=0),
            })
        return out

    def alerts(self) -> list[dict[str, Any]]:
        alerts = []
        for md in self.matches.values():
            q = AlertQueue()
            q.ingest(md.ctx)
            for a in q:
                alerts.append({
                    "match_id": md.match_id, "cn": a.cn, "name": a.name,
                    "suspicion": round(a.suspicion, 3), "category": a.category,
                    "priority": a.priority,
                    "queued_for_ban": (md.match_id, a.cn) in {
                        (r.match_id, r.cn) for r in self.banwave.queued
                    },
                })
        alerts.sort(key=lambda a: a["suspicion"], reverse=True)
        return alerts

    def case(self, match_id: str, cn: int) -> CaseReport:
        md = self._match(match_id)
        if cn not in md.ctx.verdicts:
            raise HTTPException(404, f"no player cn={cn} in {match_id}")
        if cn not in md.reports:
            md.reports[cn] = self.analyst.investigate(md.ctx, cn)
        return md.reports[cn]

    def replay(self, match_id: str) -> dict[str, Any]:
        md = self._match(match_id)
        players = {
            v.cn: {"cn": v.cn, "name": v.name, "flagged": v.is_cheat,
                   "category": v.category, "suspicion": round(v.suspicion, 3)}
            for v in md.ctx.verdicts.values()
        }
        trajectories: dict[int, list[list[float]]] = {cn: [] for cn in players}
        shots: list[list[float]] = []
        honeypot: list[list[float]] = []
        for e in md.events:
            t = e["type"]
            if t == "tick" and e["cn"] in trajectories:
                trajectories[e["cn"]].append([
                    round(e["ts"], 0), round(e["pos"]["x"], 1),
                    round(e["pos"]["y"], 1), round(e["yaw"], 1),
                    1 if e.get("alive", True) else 0,
                ])
            elif t == "shot":
                shots.append([e["cn"], round(e["ts"], 0),
                              round(e["origin"]["x"], 1), round(e["origin"]["y"], 1),
                              round(e["target"]["x"], 1), round(e["target"]["y"], 1)])
            elif t == "honeypot":
                honeypot.append([round(e["ts"], 0),
                                 round(e["pos"]["x"], 1), round(e["pos"]["y"], 1)])
        return {
            "match_id": match_id, "map_size": MAP_SIZE,
            "duration_ms": max((e["ts"] for e in md.events), default=0),
            "players": list(players.values()),
            "trajectories": {str(cn): pts for cn, pts in trajectories.items()},
            "shots": shots, "honeypot": honeypot,
        }

    # --- enforcement ------------------------------------------------------
    def queue_ban(self, match_id: str, cn: int) -> dict[str, Any]:
        report = self.case(match_id, cn)
        if report.disposition == "clear":
            raise HTTPException(400, "player was cleared; nothing to enqueue")
        self.banwave.enqueue(match_id, cn, report.name,
                             report.category, report.confidence)
        self._dispatch(report, match_id)
        return self.banwave.snapshot()

    def _dispatch(self, report: CaseReport, match_id: str) -> list[dict[str, Any]]:
        """Fan a case out to the configured chat channels (Discord, …)."""
        results = [r.__dict__ for r in self.notifier.notify(report, match_id)]
        if results:
            self.notifications.append(
                {"match_id": match_id, "cn": report.cn, "results": results})
        return results

    def inject(self, profile: str, escalate: bool = False) -> dict[str, Any]:
        """Live red team: spin up a fresh match with one synthetic cheater of
        the given profile and add it to the board, so a new alert appears on
        demand during a demo. This streams the cheat's telemetry *signature* —
        it never runs a real cheat. With ``escalate`` the cheater is queued
        straight away, which fires the chat notification (Discord)."""
        try:
            cheat = Cheat(profile)
        except ValueError:
            raise HTTPException(400, f"unknown profile '{profile}'")
        if cheat is Cheat.LEGIT:
            raise HTTPException(400, "profile must be a cheat, not 'legit'")

        self._live_counter += 1
        n_legit = 5
        cheater_cn = n_legit  # cns 0..n_legit-1 are legit, the cheater is next
        match_id = f"live-{cheat.value}-{self._live_counter}"

        # Pick a seed where only the injected cheater is flagged, so the demo
        # shows exactly one clean catch and never a coincidental false positive.
        chosen = None
        base = 9000 + self._live_counter * 50
        for seed in range(base, base + 25):
            ticks, labels = simulate_mixed(
                n_legit=n_legit, n_cheaters=1, profile=cheat, seconds=45, seed=seed)
            events = [ev for tick in ticks for ev in tick]
            ctx = MatchContext.from_events(events, match_id=match_id)
            flagged = {cn for cn, v in ctx.verdicts.items() if v.is_cheat}
            chosen = (events, ctx, labels)
            if flagged == {cheater_cn}:
                break

        events, ctx, labels = chosen
        self.matches[match_id] = MatchData(
            match_id=match_id, profile=cheat.value, events=events, ctx=ctx, labels=labels)

        q = AlertQueue()
        q.ingest(ctx)
        alerts = [{"match_id": match_id, "cn": a.cn, "name": a.name,
                   "suspicion": round(a.suspicion, 3), "category": a.category,
                   "priority": a.priority} for a in q]
        if escalate:
            for a in q:
                self.queue_ban(match_id, a.cn)  # fires the chat notification
        return {"match_id": match_id, "profile": cheat.value,
                "alerts": alerts, "escalated": escalate,
                "notified": self.notifier.configured if escalate else []}

    def notify_test(self) -> dict[str, Any]:
        """Send the highest-suspicion case to every channel, to prove wiring."""
        if not self.notifier.channels:
            raise HTTPException(400, "no notification channels configured "
                                     "(set DISCORD_WEBHOOK_URL)")
        alerts = self.alerts()
        if not alerts:
            raise HTTPException(400, "no alerts to send")
        top = alerts[0]
        report = self.case(top["match_id"], top["cn"])
        return {"sent_to": self.notifier.configured,
                "results": self._dispatch(report, top["match_id"])}


def create_app(seed: bool = True, analyst: Analyst | None = None,
               notifier: Notifier | None = None) -> FastAPI:
    service = AnalysisService(analyst=analyst or build_analyst(),
                              notifier=notifier or Notifier.from_env())
    if seed:
        service.seed()

    app = FastAPI(title="Aegis AC analysis API")
    app.state.service = service
    app.add_middleware(
        CORSMiddleware,
        allow_origins=["http://localhost:5173", "http://127.0.0.1:5173"],
        allow_methods=["*"], allow_headers=["*"],
    )

    @app.get("/api/health")
    def health():
        return {"status": "ok", "matches": len(service.matches),
                "backend": type(service.analyst).__name__}

    @app.get("/api/matches")
    def matches():
        return service.match_summaries()

    @app.get("/api/alerts")
    def alerts():
        return service.alerts()

    @app.get("/api/matches/{match_id}/cases/{cn}")
    def case(match_id: str, cn: int):
        return service.case(match_id, cn).model_dump()

    @app.get("/api/matches/{match_id}/replay")
    def replay(match_id: str):
        return service.replay(match_id)

    @app.get("/api/banwave")
    def banwave():
        return service.banwave.snapshot()

    @app.post("/api/banwave/queue/{match_id}/{cn}")
    def queue_ban(match_id: str, cn: int):
        return service.queue_ban(match_id, cn)

    @app.post("/api/banwave/release")
    def release():
        released = service.banwave.release(force=True)
        return {"released": [r.as_dict() for r in released],
                **service.banwave.snapshot()}

    @app.post("/api/redteam/inject")
    def inject(profile: str = "aimbot", escalate: bool = False):
        return service.inject(profile=profile, escalate=escalate)

    @app.get("/api/notify/status")
    def notify_status():
        return {"channels": service.notifier.configured,
                "sent": len(service.notifications)}

    @app.post("/api/notify/test")
    def notify_test():
        return service.notify_test()

    return app
```

`soc-agent/aegis_soc/enforcement.py`:

```py
"""Delayed ban waves.

Anti-cheat teams rarely ban the moment they detect a cheat. If a cheater is
kicked instantly, the cheat author knows exactly which build/feature tripped the
detector and patches it. Instead, confirmed cheaters are collected and banned in
a *wave* at a later time, so detections can't be correlated to a specific match
or cheat version. This module models that queue.

The actual "kick" is pluggable: ``LoggingKickExecutor`` just records the action
(what the demo uses), and a real deployment would drop in an executor that
issues the AssaultCube server's admin/disconnect command.
"""

import time
from dataclasses import dataclass, field
from typing import Protocol


@dataclass
class BanRecord:
    match_id: str
    cn: int
    name: str
    category: str
    confidence: float
    queued_at: float
    status: str = "queued"          # queued -> banned
    banned_at: float | None = None

    def as_dict(self) -> dict:
        return {
            "match_id": self.match_id, "cn": self.cn, "name": self.name,
            "category": self.category, "confidence": round(self.confidence, 2),
            "queued_at": self.queued_at, "status": self.status,
            "banned_at": self.banned_at,
        }


class KickExecutor(Protocol):
    def kick(self, record: BanRecord) -> str: ...


class LoggingKickExecutor:
    """Records the enforcement action instead of touching a real server."""

    def __init__(self) -> None:
        self.log: list[str] = []

    def kick(self, record: BanRecord) -> str:
        line = (f"BAN  {record.name} (cn {record.cn}) from match "
                f"{record.match_id} — {record.category} "
                f"@ {record.confidence*100:.0f}% confidence")
        self.log.append(line)
        return line


class BanWave:
    """A queue of confirmed cheaters released together on command (or once the
    delay elapses). One player per match is enqueued at most once."""

    def __init__(self, executor: KickExecutor | None = None,
                 delay_seconds: float = 3600.0, clock=time.time) -> None:
        self.executor = executor or LoggingKickExecutor()
        self.delay_seconds = delay_seconds
        self._clock = clock
        self._queue: dict[tuple[str, int], BanRecord] = {}
        self.history: list[BanRecord] = []
        self.wave_count = 0

    def enqueue(self, match_id: str, cn: int, name: str,
                category: str, confidence: float) -> BanRecord:
        key = (match_id, cn)
        rec = self._queue.get(key)
        if rec is None:
            rec = BanRecord(match_id, cn, name, category, confidence,
                            queued_at=self._clock())
            self._queue[key] = rec
        return rec

    @property
    def queued(self) -> list[BanRecord]:
        return sorted(self._queue.values(), key=lambda r: r.confidence, reverse=True)

    @property
    def seconds_until_due(self) -> float:
        if not self._queue:
            return 0.0
        oldest = min(r.queued_at for r in self._queue.values())
        return max(0.0, self.delay_seconds - (self._clock() - oldest))

    def due(self) -> bool:
        return bool(self._queue) and self.seconds_until_due <= 0.0

    def release(self, force: bool = True) -> list[BanRecord]:
        """Ban everyone currently queued. ``force=False`` only releases once the
        delay has elapsed (how a scheduler would call it)."""
        if not self._queue or (not force and not self.due()):
            return []
        released = self.queued
        now = self._clock()
        for rec in released:
            rec.status = "banned"
            rec.banned_at = now
            self.executor.kick(rec)
        self.history.extend(released)
        self._queue.clear()
        self.wave_count += 1
        return released

    def snapshot(self) -> dict:
        return {
            "queued": [r.as_dict() for r in self.queued],
            "history": [r.as_dict() for r in self.history],
            "waves_released": self.wave_count,
            "delay_seconds": self.delay_seconds,
            "seconds_until_due": round(self.seconds_until_due, 1),
            "enforcement_log": getattr(self.executor, "log", []),
        }
```

```py
"""Investigation tools over a single match's telemetry.

This is the evidence layer the SOC analyst works from. Every method is
read-only, deterministic, and returns plain JSON-able data, so it can be
exposed verbatim as a tool to an LLM agent *or* called directly by the
deterministic analyst — the agent and the offline path see exactly the same
facts.

Nothing here uses the simulator's ground-truth labels. The "clean cohort" a
suspect is compared against is defined by the detector's own verdicts (players
it did not flag), which is what a real deployment has to work with.
"""

import math
import statistics
from dataclasses import dataclass
from typing import Any

from aegis_detection.features import PlayerFeatures, extract_features
from aegis_detection.rules import Verdict, judge_all

# Metrics the baseline tool compares a suspect against the clean cohort on.
# (attribute on PlayerFeatures, human label, higher_is_more_suspicious)
_BASELINE_METRICS = [
    ("hit_rate", "hit rate", True),
    ("headshot_rate", "headshot rate", True),
    ("max_turn_rate", "peak turn rate (deg/s)", True),
    ("p95_turn_rate", "sustained turn rate (deg/s)", True),
    ("honeypot_shots", "shots at phantom entity", True),
]


def _wrap180(deg: float) -> float:
    return (deg + 180.0) % 360.0 - 180.0


@dataclass
class MatchContext:
    """Everything the analyst can see about one match."""

    match_id: str
    events: list[dict[str, Any]]
    features: dict[int, PlayerFeatures]
    verdicts: dict[int, Verdict]

    @classmethod
    def from_events(cls, events: list[dict[str, Any]], match_id: str = "match") -> "MatchContext":
        feats = extract_features(events)
        verdicts = {v.cn: v for v in judge_all(feats)}
        return cls(match_id=match_id, events=events, features=feats, verdicts=verdicts)

    def clean_cohort(self, exclude: int) -> list[PlayerFeatures]:
        """Players the detector did NOT flag — the baseline of normal play."""
        return [
            self.features[cn]
            for cn, v in self.verdicts.items()
            if cn != exclude and not v.is_cheat and self.features[cn].shots > 0
        ]


class Investigation:
    """Bound to one suspect in one match; exposes the analyst's tool surface."""

    def __init__(self, ctx: MatchContext):
        self.ctx = ctx

    # --- tool: roster -----------------------------------------------------
    def roster(self) -> dict[str, Any]:
        """List every player in the match with the detector's suspicion score,
        so you can see the suspect in the context of the lobby."""
        return {
            "match_id": self.ctx.match_id,
            "players": [
                {
                    "cn": v.cn,
                    "name": v.name,
                    "suspicion": round(v.suspicion, 2),
                    "flagged": v.is_cheat,
                    "category": v.category,
                }
                for v in sorted(self.ctx.verdicts.values(),
                                key=lambda v: v.suspicion, reverse=True)
            ],
        }

    # --- tool: overview ---------------------------------------------------
    def overview(self, cn: int) -> dict[str, Any]:
        """Full performance profile for one player plus the detector's rule
        hits. The first thing to pull on any alert."""
        f = self.ctx.features.get(cn)
        if f is None:
            return {"error": f"no player with cn={cn} in this match"}
        v = self.ctx.verdicts[cn]
        return {
            "cn": cn,
            "name": f.name,
            "stats": f.as_dict(),
            "detector": {
                "suspicion": round(v.suspicion, 3),
                "flagged": v.is_cheat,
                "top_category": v.category,
                "rule_hits": [
                    {"rule": h.rule, "category": h.category,
                     "confidence": h.confidence, "reason": h.reason}
                    for h in v.hits
                ],
            },
        }

    # --- tool: baseline ---------------------------------------------------
    def baseline(self, cn: int) -> dict[str, Any]:
        """Compare the suspect to the match's unflagged players (the clean
        cohort) on every cheat-relevant metric, as a z-score. A z-score above
        ~3 means the value is far outside what normal players in this same
        lobby produced."""
        f = self.ctx.features.get(cn)
        if f is None:
            return {"error": f"no player with cn={cn} in this match"}
        cohort = self.ctx.clean_cohort(exclude=cn)
        if len(cohort) < 2:
            return {"error": "not enough clean players to form a baseline",
                    "cohort_size": len(cohort)}

        comparisons = []
        for attr, label, _ in _BASELINE_METRICS:
            suspect = float(getattr(f, attr))
            values = [float(getattr(c, attr)) for c in cohort]
            mean = statistics.fmean(values)
            sd = statistics.pstdev(values)
            z = (suspect - mean) / sd if sd > 1e-9 else (
                math.inf if suspect > mean else 0.0)
            comparisons.append({
                "metric": label,
                "suspect": round(suspect, 3),
                "cohort_mean": round(mean, 3),
                "cohort_max": round(max(values), 3),
                "z_score": (round(z, 1) if math.isfinite(z) else "inf"),
            })
        return {"cn": cn, "cohort_size": len(cohort), "comparisons": comparisons}

    # --- tool: turn timeline ---------------------------------------------
    def turn_timeline(self, cn: int, top: int = 5) -> dict[str, Any]:
        """The sharpest view-angle changes for a player, each as deg/s with a
        timestamp. Aimbot snaps show up here as single-tick turns an order of
        magnitude faster than a human flick."""
        ticks = sorted(
            ((e["ts"], e["yaw"]) for e in self.ctx.events
             if e["type"] == "tick" and e["cn"] == cn),
            key=lambda p: p[0],
        )
        spikes = []
        for (t0, y0), (t1, y1) in zip(ticks, ticks[1:]):
            dt = (t1 - t0) / 1000.0
            if 0 < dt <= 0.1:
                spikes.append({"ts": round(t1, 1),
                               "deg_per_s": round(abs(_wrap180(y1 - y0)) / dt, 1)})
        spikes.sort(key=lambda s: s["deg_per_s"], reverse=True)
        return {"cn": cn, "sampled_ticks": len(ticks), "sharpest_turns": spikes[:top]}

    # --- tool: honeypot ---------------------------------------------------
    def honeypot(self, cn: int, limit: int = 8) -> dict[str, Any]:
        """Every shot this player aimed at the server's phantom (honeypot)
        entity — a target no legitimate client is ever told exists. Each entry
        notes whether a real enemy was also on the aim line; shots with none
        are the wallhack tell."""
        ghost = {e["ts"]: (e["pos"]["x"], e["pos"]["y"])
                 for e in self.ctx.events if e["type"] == "honeypot"}
        if not ghost:
            return {"cn": cn, "phantom_tracked": False, "shots_at_phantom": []}

        positions: dict[float, dict[int, tuple[float, float]]] = {}
        for e in self.ctx.events:
            if e["type"] == "tick":
                positions.setdefault(e["ts"], {})[e["cn"]] = (e["pos"]["x"], e["pos"]["y"])

        hits = []
        for e in self.ctx.events:
            if e["type"] != "shot" or e["cn"] != cn or e["ts"] not in ghost:
                continue
            ox, oy = e["origin"]["x"], e["origin"]["y"]
            aim = math.degrees(math.atan2(e["target"]["y"] - oy, e["target"]["x"] - ox))
            gx, gy = ghost[e["ts"]]
            off = abs(_wrap180(math.degrees(math.atan2(gy - oy, gx - ox)) - aim))
            if off > 6.0:
                continue
            enemy_near = any(
                abs(_wrap180(math.degrees(math.atan2(py - oy, px - ox)) - aim)) <= 6.0
                for other, (px, py) in positions.get(e["ts"], {}).items() if other != cn
            )
            hits.append({"ts": round(e["ts"], 1), "degrees_off_phantom": round(off, 1),
                         "real_enemy_on_line": enemy_near})
        blind = [h for h in hits if not h["real_enemy_on_line"]]
        return {
            "cn": cn,
            "phantom_tracked": True,
            "shots_at_phantom": len(hits),
            "blind_shots_at_phantom": len(blind),
            "sample": blind[:limit] or hits[:limit],
        }
```

```py
"""Push SOC case reports out to chat platforms.

When the analyst confirms a cheater, the anti-cheat team wants to know without
watching the dashboard. This module turns a ``CaseReport`` into an alert and
fans it out over pluggable channels. Discord (incoming webhook) is implemented;
the ``NotifyChannel`` protocol keeps the door open for Zalo, Slack, a Grafana
contact point, or any webhook.

No third-party SDK and no new dependency: posting is a plain HTTPS request via
the standard library, behind an injectable sender so tests never touch the
network. Webhook URLs are read from the environment and never logged.
"""

import json
import os
import urllib.request
from dataclasses import dataclass
from typing import Callable, Protocol

from .report import CaseReport

# Discord embed accent per disposition (decimal RGB).
_DISPO_COLOR = {
    "ban": 0xEF4444,
    "shadow": 0xF59E0B,
    "monitor": 0x38BDF8,
    "clear": 0x22C55E,
}

Sender = Callable[[str, dict], None]


# Discord (and its Cloudflare front) rejects requests with no real User-Agent,
# so send a generic client identifier — never anything that identifies the user.
_USER_AGENT = "AegisAC/0.1 (+anti-cheat SOC notifier)"


def _http_post(url: str, payload: dict, timeout: float = 5.0) -> None:
    data = json.dumps(payload).encode("utf-8")
    req = urllib.request.Request(
        url, data=data, method="POST",
        headers={"Content-Type": "application/json", "User-Agent": _USER_AGENT})
    with urllib.request.urlopen(req, timeout=timeout) as resp:  # noqa: S310 (https enforced by channel)
        resp.read()


@dataclass
class Notification:
    match_id: str
    cn: int
    name: str
    category: str
    confidence: float
    disposition: str
    title: str
    summary: str
    evidence: list[str]
    recommendation: str

    @classmethod
    def from_case(cls, case: CaseReport, match_id: str) -> "Notification":
        return cls(
            match_id=match_id, cn=case.cn, name=case.name, category=case.category,
            confidence=case.confidence, disposition=case.disposition,
            title=case.title, summary=case.summary, evidence=case.evidence,
            recommendation=case.recommendation,
        )


class NotifyChannel(Protocol):
    name: str
    def send(self, note: Notification) -> None: ...


class DiscordWebhook:
    """Posts a rich embed to a Discord channel via an incoming webhook."""

    name = "discord"

    def __init__(self, url: str, sender: Sender | None = None) -> None:
        if not url.startswith("https://"):
            raise ValueError("Discord webhook URL must be https")
        self.url = url
        self._send = sender or _http_post

    def build_payload(self, note: Notification) -> dict:
        evidence = "\n".join(f"• {e}" for e in note.evidence[:6]) or "—"
        return {
            "username": "Aegis AC",
            "embeds": [{
                "title": f"⚠ {note.title}",
                "description": note.summary,
                "color": _DISPO_COLOR.get(note.disposition, 0x94A3B8),
                "fields": [
                    {"name": "Player", "value": f"{note.name} (cn {note.cn})", "inline": True},
                    {"name": "Category", "value": note.category, "inline": True},
                    {"name": "Confidence", "value": f"{note.confidence*100:.0f}%", "inline": True},
                    {"name": "Disposition", "value": note.disposition.upper(), "inline": True},
                    {"name": "Match", "value": note.match_id, "inline": True},
                    {"name": "Evidence", "value": evidence[:1024], "inline": False},
                    {"name": "Recommendation", "value": note.recommendation[:1024], "inline": False},
                ],
                "footer": {"text": "Aegis AC — a human approves every ban"},
            }],
        }

    def send(self, note: Notification) -> None:
        self._send(self.url, self.build_payload(note))


class ConsoleChannel:
    """Prints the alert instead of sending it — handy for demos with no webhook."""

    name = "console"

    def __init__(self, stream=None) -> None:
        self._stream = stream

    def send(self, note: Notification) -> None:
        line = (f"[ALERT] {note.disposition.upper()} {note.name} "
                f"({note.category} {note.confidence*100:.0f}%) in {note.match_id}")
        print(line, file=self._stream)


@dataclass
class NotifyResult:
    channel: str
    ok: bool
    error: str | None = None


class Notifier:
    """Fans a case out to every configured channel; never raises on a channel
    failure, so a down webhook can't break the request that triggered it."""

    def __init__(self, channels: list[NotifyChannel] | None = None) -> None:
        self.channels = channels or []

    @property
    def configured(self) -> list[str]:
        return [c.name for c in self.channels]

    def notify(self, case: CaseReport, match_id: str) -> list[NotifyResult]:
        note = Notification.from_case(case, match_id)
        results = []
        for ch in self.channels:
            try:
                ch.send(note)
                results.append(NotifyResult(ch.name, True))
            except Exception as exc:
                results.append(NotifyResult(ch.name, False, str(exc)))
        return results

    @classmethod
    def from_env(cls) -> "Notifier":
        """Build channels from the environment:
        DISCORD_WEBHOOK_URL -> Discord; AEGIS_NOTIFY_CONSOLE=1 -> console echo."""
        channels: list[NotifyChannel] = []
        url = os.environ.get("DISCORD_WEBHOOK_URL")
        if url:
            channels.append(DiscordWebhook(url))
        if os.environ.get("AEGIS_NOTIFY_CONSOLE") == "1":
            channels.append(ConsoleChannel())
        return cls(channels)
```

```py
"""The case report - the analyst's deliverable for one alert.

A human reviewer reads this and approves or rejects the recommended action, so
it is deliberately explainable: a disposition, a confidence, the evidence that
supports it, and plain-language reasoning. It is a Pydantic model so the LLM
backend can emit it directly as a validated structured output.
"""

from typing import Literal

from pydantic import BaseModel, Field

# Disposition is intentionally conservative: the analyst never bans on its own,
# it recommends, and a human approves. "shadow" = keep playing but queue for a
# delayed ban wave (Phase 5) so cheat authors can't correlate detection.
Disposition = Literal["ban", "shadow", "monitor", "clear"]

# The cheat taxonomy the analyst classifies into.
TAXONOMY = {
    "aimbot": "Automated aim - snaps onto targets faster than a human can flick.",
    "humanised_aimbot": "Aim assist smoothed to look human, but still too accurate.",
    "triggerbot": "Auto-fires the instant the crosshair crosses an enemy.",
    "esp": "Wallhack / ESP - knows enemy positions through walls.",
    "aim_assistance": "Soft aim help; weak signal, usually monitor not ban.",
    "inconclusive": "Flagged, but the evidence does not clearly fit one category.",
}


class CaseReport(BaseModel):
    """A SOC analyst's finding on a single flagged player."""

    cn: int = Field(description="The player's connection number (server id).")
    name: str = Field(description="The player's in-game name.")
    category: str = Field(
        description="Cheat category from the taxonomy, or 'inconclusive'.")
    confidence: float = Field(
        ge=0.0, le=1.0,
        description="How sure the analyst is that this is a cheater, 0-1.")
    disposition: Disposition = Field(
        description="Recommended action: ban, shadow (queue for a ban wave), "
                    "monitor, or clear.")
    title: str = Field(description="One-line headline for the case.")
    summary: str = Field(
        description="2-4 sentences: what the player did and why it is or isn't "
                    "cheating, in plain language.")
    evidence: list[str] = Field(
        description="Concrete facts pulled from the investigation tools, each a "
                    "short bullet with numbers.")
    recommendation: str = Field(
        description="What the human reviewer should do next and why.")

    def render(self) -> str:
        """Human-readable case card for the terminal / dashboard."""
        bar = "=" * 68
        bullets = "\n".join(f"  - {e}" for e in self.evidence)
        return (
            f"{bar}\n"
            f"CASE: {self.title}\n"
            f"{bar}\n"
            f"Player      : {self.name} (cn {self.cn})\n"
            f"Category    : {self.category}\n"
            f"Confidence  : {self.confidence*100:.0f}%\n"
            f"Disposition : {self.disposition.upper()}\n"
            f"\n{self.summary}\n"
            f"\nEvidence:\n{bullets}\n"
            f"\nRecommendation:\n  {self.recommendation}\n"
            f"{bar}"
        )
```

```py
"""Alert queue and match-level triage.

Glue between the detector and the analyst: turn a match's verdicts into an
ordered alert queue, then run the analyst over each alert to produce case
reports a human can review.
"""

from dataclasses import dataclass
from typing import Any

from .analyst import Analyst, HeuristicAnalyst
from .evidence import MatchContext
from .report import CaseReport


@dataclass(order=True)
class Alert:
    # ordered so the queue pops the most suspicious first
    suspicion: float
    cn: int
    name: str
    category: str | None

    @property
    def priority(self) -> str:
        return "high" if self.suspicion >= 0.9 else "medium"


class AlertQueue:
    """The flagged players from one or more matches, highest suspicion first."""

    def __init__(self) -> None:
        self._alerts: list[Alert] = []

    def ingest(self, ctx: MatchContext) -> int:
        added = 0
        for v in ctx.verdicts.values():
            if v.is_cheat:
                self._alerts.append(Alert(v.suspicion, v.cn, v.name, v.category))
                added += 1
        self._alerts.sort(reverse=True)
        return added

    def __len__(self) -> int:
        return len(self._alerts)

    def __iter__(self):
        return iter(self._alerts)


def triage_match(
    events: list[dict[str, Any]],
    analyst: Analyst | None = None,
    match_id: str = "match",
) -> list[CaseReport]:
    """Run the full pipeline on one match: detect -> queue -> investigate."""
    analyst = analyst or HeuristicAnalyst()
    ctx = MatchContext.from_events(events, match_id=match_id)
    queue = AlertQueue()
    queue.ingest(ctx)
    return [analyst.investigate(ctx, alert.cn) for alert in queue]
```

```py
import pytest
```

```py
WEBHOOK = "https://discord.com/api/webhooks/123/abc"


def _case(**over) -> CaseReport:
    base = dict(
        cn=7, name="p07", category="esp", confidence=0.95, disposition="ban",
        title="esp - p07", summary="Wallhacked.", evidence=["aimed at the phantom 8x"],
        recommendation="Approve a ban.",
    )
    base.update(over)
    return CaseReport(**base)


class Capture:
    def __init__(self) -> None:
        self.calls: list[tuple[str, dict]] = []

    def __call__(self, url: str, payload: dict) -> None:
        self.calls.append((url, payload))


def test_discord_payload_has_embed_with_disposition_color():
    cap = Capture()
    ch = DiscordWebhook(WEBHOOK, sender=cap)
    ch.send(Notification.from_case(_case(), "scrim-01"))
    url, payload = cap.calls[0]
    assert url == WEBHOOK
    embed = payload["embeds"][0]
    assert "p07" in embed["title"] or any(f["value"].startswith("p07") for f in embed["fields"])
    assert embed["color"] == 0xEF4444  # ban -> red
    names = {f["name"] for f in embed["fields"]}
    assert {"Player", "Category", "Confidence", "Evidence", "Recommendation"} <= names


def test_disposition_changes_embed_color():
    cap = Capture()
    DiscordWebhook(WEBHOOK, sender=cap).send(
        Notification.from_case(_case(disposition="monitor"), "m"))

def test_http_post_sends_a_user_agent(monkeypatch):
    """Discord/Cloudflare 403s requests with no real User-Agent, so the raw
    sender must set one (and it must not leak anything user-identifying)."""
    import aegis_soc.notify as notify

    captured = {}

    class FakeResp:
        def __enter__(self): return self
        def __exit__(self, *a): return False
        def read(self): return b""

    def fake_urlopen(req, timeout=None):
        captured["ua"] = req.get_header("User-agent")
        captured["ct"] = req.get_header("Content-type")
        return FakeResp()

    notify._http_post("https://discord.com/api/webhooks/1/x", {"content": "hi"})
    assert captured["ua"] and "AegisAC" in captured["ua"]
```

```py
"""Tests for the AI SOC analyst.

These exercise the deterministic backend and the investigation tools end to
end, so the whole alert -> investigation -> case report pipeline is verified
with no API key and no network.
"""

import json

import pytest

from aegis_collector.sim_cheat import Cheat, simulate_mixed

from aegis_soc import (
    AlertQueue,
    HeuristicAnalyst,
    Investigation,
    MatchContext,
    build_analyst,
    triage_match,
)
from aegis_soc.report import TAXONOMY, CaseReport


def _match(profile, *, legit=6, cheaters=2, seconds=45, seed=5):
    ticks, labels = simulate_mixed(
        n_legit=legit, n_cheaters=cheaters, profile=profile,
        seconds=seconds, seed=seed,
    )
    return [ev for tick in ticks for ev in tick], labels


def _a_flagged_cn(ctx: MatchContext) -> int:
    return next(v.cn for v in ctx.verdicts.values() if v.is_cheat)


# --- investigation tools --------------------------------------------------
def test_overview_exposes_detector_rule_hits():
    events, _ = _match(Cheat.AIMBOT)
    ctx = MatchContext.from_events(events)
    cn = _a_flagged_cn(ctx)
    ov = Investigation(ctx).overview(cn)
    assert ov["cn"] == cn
    assert ov["detector"]["flagged"] is True
    assert ov["detector"]["rule_hits"], "a flagged player must carry rule hits"


def test_all_tool_outputs_are_json_serialisable():
    """The LLM backend hands these to the model as JSON, so every field must
    survive json.dumps (the z-score 'inf' sentinel is the tricky one)."""
    events, _ = _match(Cheat.ESP)
    ctx = MatchContext.from_events(events)
    inv = Investigation(ctx)
    cn = _a_flagged_cn(ctx)
    for payload in (inv.roster(), inv.overview(cn), inv.baseline(cn),
                    inv.turn_timeline(cn), inv.honeypot(cn)):
        json.dumps(payload)  # raises if anything is non-serialisable


def test_baseline_puts_cheater_far_above_the_cohort():
    events, _ = _match(Cheat.AIMBOT)
    ctx = MatchContext.from_events(events)
    cn = _a_flagged_cn(ctx)
    base = Investigation(ctx).baseline(cn)
    scores = [c["z_score"] for c in base["comparisons"]]
    # at least one metric is either off-the-scale or many sigmas out
    assert any(z == "inf" or (isinstance(z, (int, float)) and z >= 3) for z in scores)


def test_honeypot_tool_finds_blind_shots_for_esp():
    events, labels = _match(Cheat.ESP)
    ctx = MatchContext.from_events(events)
    inv = Investigation(ctx)
    cheater = _a_flagged_cn(ctx)
    hp = inv.honeypot(cheater)
    assert hp["phantom_tracked"] is True
    assert hp["blind_shots_at_phantom"] >= 1
    # a legit player should not be shooting the invisible phantom blind
    legit_cn = next(cn for cn, l in labels.items() if l == "legit")
    assert inv.honeypot(legit_cn)["blind_shots_at_phantom"] <= 2

    cn = _a_flagged_cn(ctx)

    assert turns["sharpest_turns"][0]["deg_per_s"] > 900
```
