# KozDbg profiles

Profiles are stored in `KozDbg.dp64.ini.profiles.ini`, next to the installed plugin. Open the file from **Settings > Profiles INI**.

On first launch, KozDbg creates the seven presets and migrates the existing checkbox settings. Existing profile files are preserved.

## Adding a profile

Copy an existing section and give it a unique ID. Letters, digits, underscores and hyphens are accepted; `off` is reserved for disabling the plugin.

Change the name and options, then restart x64dbg. Your profile will appear in both the Plugins menu and the settings dropdown.

```ini
[MyProfile]
Name=My custom profile
Engine=Api
Extended=0
Peb=1
RemoteDebugger=1
DebugObject=1
ThreadHiding=1
KernelDebugger=1
DriverNames=1
InvalidHandles=1
TrapFlag=1
Instrumentation=0
DebugRegisters=1
AttachProtection=0
TitanHideDevice=0
DecoderAcceleration=0
```

Use `0` to disable an option and `1` to enable it. Missing option keys default to `1`. Controls unsupported by the selected engine remain disabled in the GUI.

## Engines

| Preset | Engine | Extended |
|---|---|---|
| 331 / 340 / 350 | Api | 0 |
| 360 | ClusteredSyscalls | 0 |
| 380 | ScatteredSyscalls | 0 |
| 394 / 3101 | ScatteredSyscalls | 1 |

`Engine` selects an existing implementation. `Extended` enables the later checks.

Creating an INI profile does not add new detection handling. The implementation lives in `plugin.cpp` and the `.inl` files; new techniques require code changes and a rebuild.

## Saving and selecting

**Save & apply** writes the selected profile's checkboxes. Switching profiles discards unsaved checkbox edits. **Auto-enable** is shared across profiles.

You can also select a custom profile from the command bar:

```text
kz_profile MyProfile
```

Profile definitions remain fixed during the current debugging session. Restart x64dbg after adding profiles or changing engine settings.

The loader skips unknown engines and invalid IDs, accepts up to 128 profiles, and uses the built-in presets if no valid sections are found.

# KozDbg

**An open-source x64dbg anti-anti-debug plugin for VMProtect 3.3.x–3.10.x.**

KozDbg is built from my VMProtect research, covering the tested versions from **3.3.1 through 3.10.1**. Select the matching profile, load the protected program and continue debugging.

**No kernel driver is required.** KozDbg runs as an x64dbg plugin and handles the supported user-mode and kernel-debugger detection checks from user mode. It supports native x64 programs.

Created by **Ivan Kozlovsky** · [Website](https://ivankozlovsky.com) · [Source](https://github.com/ivanpotatoes/kozdbg)

## Supported versions

| VMProtect version | Profile | Engine |
|---|---|---|
| 3.3.1 | `331` | API interception |
| 3.4.0 | `340` | API interception |
| 3.5.0 | `350` | API interception |
| 3.6 | `360` | Clustered direct syscalls |
| 3.8.0 | `380` | Scattered direct syscalls |
| 3.9.4 | `394` | Scattered direct syscalls with extended checks |
| 3.10.1 | `3101` | Scattered direct syscalls with extended checks |

These are the specific versions researched and tested. The 3.3.x–3.10.x range describes the covered release families; it does not mean every intermediate build has been tested. Version selection is manual.

[Watch the example tests on YouTube](https://www.youtube.com/watch?v=r7Q8KtjtaA0)

## Installation

1. Download `KozDbg.dp64` from [Releases](https://github.com/ivanpotatoes/KozDbg/releases/latest), or build it using the instructions below.
2. Copy it into the `plugins` directory next to `x64dbg.exe`.
3. Start x64dbg and open **Plugins > KozDbg**.
4. Select the matching VMProtect profile and leave **Auto-enable** checked.
5. Load the protected program. At the system breakpoint, check that the log reports the profile as armed, then press **F9**. The entry breakpoint may require another **F9**.

Select the profile before starting the target. Applying it after a check has already run cannot undo that check. If arming fails, check the reported error before continuing.

When updating, close x64dbg completely before replacing the plugin. Keep your existing `KozDbg.dp64.ini` and `KozDbg.dp64.ini.profiles.ini` files.

## What it handles

The available controls depend on the selected version:

- PEB and debugger API checks.
- Remote debugger, debug object and kernel debugger queries.
- Thread hiding, driver-name checks and supported invalid-handle checks.
- Trap-flag exception delivery and saved debug registers.
- Instrumentation callback and remote-breakin protection in later profiles.
- The TitanHide device check in 3.9.4 and 3.10.1.
- Decoder acceleration for recognized packed layouts.

API addresses and syscall numbers are resolved in the running process. There are no fixed protected-code addresses, sample names or hashes used to select the target.

Native API breakpoints preserve the validated syscall identification bytes. This also addresses the packed 3.3.1 case tested with RiddleGame.

## Custom profiles

Open **Settings > Profiles INI**, copy an existing section and give it a new ID. Change the name and options, then restart x64dbg. The new profile appears in both the menu and the settings dropdown.

Profiles configure the existing engines. Adding support for a new detection technique still requires changing and rebuilding the C++ implementation.

See [PROFILES.md](PROFILES.md) for the format and an example.

## Commands

| Command | Action |
|---|---|
| `kz_settings` | Open settings |
| `kz_profile 331` | Select the 3.3.1 profile |
| `kz_profile MyProfile` | Select a custom profile |
| `kz_profile off` | Disable KozDbg |
| `kz_apply` | Apply the selected profile while paused |
| `kz_status` | Show state and hit counters |

Repeated informational messages are counted instead of printed continuously. Errors remain visible. x64dbg's own exception messages are separate.

## Building

Requirements: Windows, Visual Studio 2022 with **Desktop development with C++**, CMake 3.20 or newer, and the [x64dbg plugin SDK](https://github.com/x64dbg/x64dbg).

```powershell
cmake -S . -B ../KozDbg-build -A x64 -DX64DBG_SDK="C:/path/to/pluginsdk"
cmake --build ../KozDbg-build --config Release
```

The SDK directory must contain `_plugins.h`, `x64dbg.lib` and `x64bridge.lib`. The compiled plugin is written to `../KozDbg-build/Release/KozDbg.dp64`.

## Packed programs and limitations

Decoder acceleration handles recognized packed layouts and needs a safe hardware-breakpoint slot. If one is unavailable, the memory-guard path stays in use and startup can be slower.

Different protection options can change the code layout. Passing the supplied examples does not establish compatibility with every protected program.

KozDbg handles anti-debug checks. It does not unpack programs, devirtualize code, bypass application key checks or handle anti-VM checks.

`debug_event_status.h`:

```h
#pragma once
#include <cstdint>
// DBG_REPLY_LATER applies only to an exception belonging to this debug event.
// Never reinterpret a genuine exception or an event from a different thread.
constexpr std::uint32_t kozNormalizeContinueStatus(std::uint32_t process,std::uint32_t thread,
 std::uint32_t eventProcess,std::uint32_t eventThread,std::uint32_t eventCode,std::uint32_t status) {
 return process==eventProcess&&thread==eventThread&&eventCode>=2&&eventCode<=9&&status==0x40010001u
  ?0x00010002u:status;
}

`debug_event_tail.inl`:

```inl
// TitanEngine reaches this import after the core's debug-event callbacks and
// before Windows resumes the debuggee. This is an IAT change in the debugger
// process only; it does not alter target code or any analyst DLL breakpoint.
// The plugin is pinned before installation because another thread may already
// have fetched our call pointer when removal restores the IAT slot.
static bool moduleHardwareTail(DWORD process,DWORD thread);
#include "debug_event_status.h"
using DebugEventTailProc=BOOL(WINAPI*)(DWORD,DWORD,DWORD);
using DebugEventDataProc=DEBUG_EVENT* (__cdecl*)();
static std::atomic<DebugEventDataProc> debugEventData{nullptr};
static std::atomic<unsigned long long> debugEventStatusRepairs{0};
static std::atomic<DebugEventTailProc> debugEventTailOriginal{nullptr};
static std::atomic<unsigned> debugEventTailFrames{0};
static std::atomic<bool> debugEventTailEnabled{false};
static std::atomic_flag debugEventTailMutation=ATOMIC_FLAG_INIT;
static void* volatile* debugEventTailSlot=nullptr;
static bool debugEventTailPinned=false,debugEventTailProtectDirty=false;
static DWORD debugEventTailSavedProtection=0;
static thread_local bool debugEventTailInside=false;

static BOOL WINAPI debugEventTailContinue(DWORD process,DWORD thread,DWORD status) {
 const DWORD callerError=GetLastError();
 debugEventTailFrames.fetch_add(1,std::memory_order_acq_rel);
 const auto original=debugEventTailOriginal.load(std::memory_order_acquire);
 bool proceed=true;
 const bool nested=debugEventTailInside;
 debugEventTailInside=true;
 if(!nested&&debugEventTailEnabled.load(std::memory_order_acquire)){
  try {proceed=moduleHardwareTail(process,thread);}
  catch(...){log("ContinueDebugEvent maintenance raised an exception; refusing an unverified target resume.");proceed=false;}
  if(proceed&&status==0x40010001u){
   const auto getter=debugEventData.load(std::memory_order_acquire);
   const DEBUG_EVENT* source=getter?getter():nullptr;
   DEBUG_EVENT event{};SIZE_T received=0;
   if(source&&ReadProcessMemory(GetCurrentProcess(),source,&event,sizeof(event),&received)&&received==sizeof(event)){
    const DWORD normalized=kozNormalizeContinueStatus(process,thread,event.dwProcessId,event.dwThreadId,event.dwDebugEventCode,status);
    if(normalized!=status){
     status=normalized;
     if(debugEventStatusRepairs.fetch_add(1)==0)log("Corrected stale DBG_REPLY_LATER on a non-exception debug event; exception delivery remains unchanged.");
    }
   }
  }
 }
 debugEventTailInside=nested;
 // The original pointer remains valid after removal for an in-flight call.
 SetLastError(callerError);
 BOOL result=FALSE;
 if(proceed&&original)result=original(process,thread,status);
 else SetLastError(proceed?ERROR_INVALID_FUNCTION:ERROR_OPERATION_ABORTED);
 const DWORD returnError=GetLastError();
 debugEventTailFrames.fetch_sub(1,std::memory_order_acq_rel);
 SetLastError(returnError);
 return result;
}

static bool debugEventTailRead(duint address,void* data,size_t size) {
 SIZE_T received=0;
 return ReadProcessMemory(GetCurrentProcess(),reinterpret_cast<const void*>(address),data,size,&received)&&received==size;
}
static bool debugEventTailRange(DWORD imageSize,duint rva,size_t size) {
 return rva<imageSize&&size<=static_cast<size_t>(imageSize-rva);
}
static bool debugEventTailString(duint base,DWORD imageSize,duint rva,std::string& value) {
 value.clear();
 for(unsigned i=0;i<256;i++){
  if(!debugEventTailRange(imageSize,rva+i,1))return false;
  char c=0;if(!debugEventTailRead(base+rva+i,&c,1))return false;
  if(!c)return true;
  value.push_back(c);
 }
 return false;
}
static void* volatile* debugEventTailFindSlot(HMODULE module) {
 if(!module)return nullptr;
 const duint base=reinterpret_cast<duint>(module);
 MEMORY_BASIC_INFORMATION region{};
 if(!VirtualQuery(module,&region,sizeof(region))||region.AllocationBase!=module||region.State!=MEM_COMMIT)return nullptr;
 IMAGE_DOS_HEADER dos{};
 if(!debugEventTailRead(base,&dos,sizeof(dos))||dos.e_magic!=IMAGE_DOS_SIGNATURE||dos.e_lfanew<=0)return nullptr;
 // The NT header must be in the readable initial header region, before any
 // offsets from it are used to validate the rest of the loaded image.
 const size_t ntOffset=static_cast<size_t>(dos.e_lfanew);
 if(ntOffset>region.RegionSize||sizeof(IMAGE_NT_HEADERS64)>region.RegionSize-ntOffset)return nullptr;
 IMAGE_NT_HEADERS64 nt{};
 if(!debugEventTailRead(base+ntOffset,&nt,sizeof(nt))||nt.Signature!=IMAGE_NT_SIGNATURE||
    nt.FileHeader.Machine!=IMAGE_FILE_MACHINE_AMD64||nt.FileHeader.SizeOfOptionalHeader<sizeof(IMAGE_OPTIONAL_HEADER64)||
    nt.OptionalHeader.Magic!=IMAGE_NT_OPTIONAL_HDR64_MAGIC||nt.OptionalHeader.NumberOfRvaAndSizes<=IMAGE_DIRECTORY_ENTRY_IMPORT)return nullptr;
 const DWORD imageSize=nt.OptionalHeader.SizeOfImage;
 if(!imageSize||base>std::numeric_limits<duint>::max()-imageSize||
    nt.OptionalHeader.SizeOfHeaders>imageSize||ntOffset+sizeof(nt)>nt.OptionalHeader.SizeOfHeaders)return nullptr;
 const auto imports=nt.OptionalHeader.DataDirectory[IMAGE_DIRECTORY_ENTRY_IMPORT];
 if(!imports.VirtualAddress||imports.Size<sizeof(IMAGE_IMPORT_DESCRIPTOR)||
    !debugEventTailRange(imageSize,imports.VirtualAddress,imports.Size))return nullptr;
 const size_t descriptorCount=std::min<size_t>(imports.Size/sizeof(IMAGE_IMPORT_DESCRIPTOR),4096);
 for(size_t i=0;i<descriptorCount;i++){
  IMAGE_IMPORT_DESCRIPTOR descriptor{};
  if(!debugEventTailRead(base+imports.VirtualAddress+i*sizeof(descriptor),&descriptor,sizeof(descriptor)))return nullptr;
  if(!descriptor.Name)break;
  std::string library;
  if(!debugEventTailString(base,imageSize,descriptor.Name,library))return nullptr;
  if(_stricmp(library.c_str(),"kernel32.dll")!=0)continue;
  if(!descriptor.OriginalFirstThunk||!descriptor.FirstThunk||
     !debugEventTailRange(imageSize,descriptor.OriginalFirstThunk,sizeof(IMAGE_THUNK_DATA64))||
     !debugEventTailRange(imageSize,descriptor.FirstThunk,sizeof(void*)))return nullptr;
  const size_t count=std::min<size_t>((imageSize-descriptor.OriginalFirstThunk)/sizeof(IMAGE_THUNK_DATA64),65536);
  for(size_t j=0;j<count;j++){
   IMAGE_THUNK_DATA64 thunk{};
   if(!debugEventTailRead(base+descriptor.OriginalFirstThunk+j*sizeof(thunk),&thunk,sizeof(thunk)))return nullptr;
   if(!thunk.u1.AddressOfData)break;
   if(IMAGE_SNAP_BY_ORDINAL64(thunk.u1.Ordinal))continue;
   if(!debugEventTailRange(imageSize,thunk.u1.AddressOfData,sizeof(WORD)+1))return nullptr;
   std::string symbol;
   if(!debugEventTailString(base,imageSize,thunk.u1.AddressOfData+sizeof(WORD),symbol))return nullptr;
   if(symbol!="ContinueDebugEvent")continue;
   const duint slotRva=descriptor.FirstThunk+j*sizeof(void*);
   if(!debugEventTailRange(imageSize,slotRva,sizeof(void*))||(slotRva&(sizeof(void*)-1)))return nullptr;
   MEMORY_BASIC_INFORMATION slotRegion{};
   const auto slot=reinterpret_cast<void* volatile*>(base+slotRva);
   if(!VirtualQuery(reinterpret_cast<const void*>(base+slotRva),&slotRegion,sizeof(slotRegion))||
      slotRegion.AllocationBase!=module||slotRegion.State!=MEM_COMMIT||
      (slotRegion.Protect&(PAGE_NOACCESS|PAGE_GUARD)))return nullptr;
   return slot;
  }
 }
 return nullptr;
}
static bool debugEventTailRestoreProtection() {
 if(!debugEventTailProtectDirty)return true;
 DWORD ignored=0;
 if(!VirtualProtect(const_cast<void**>(debugEventTailSlot),sizeof(void*),debugEventTailSavedProtection,&ignored)){
  log("ContinueDebugEvent IAT page protection restore failed; cleanup remains pending.");return false;
 }
 debugEventTailProtectDirty=false;return true;
}
static bool debugEventTailSwap(void* expected,void* replacement) {
 MEMORY_BASIC_INFORMATION region{};
 if(!VirtualQuery(const_cast<void**>(debugEventTailSlot),&region,sizeof(region)))return false;
 const DWORD executable=PAGE_EXECUTE|PAGE_EXECUTE_READ|PAGE_EXECUTE_READWRITE|PAGE_EXECUTE_WRITECOPY;
 const DWORD writable=(region.Protect&executable)?PAGE_EXECUTE_READWRITE:PAGE_READWRITE;
 DWORD previousProtection=0;
 if(!VirtualProtect(const_cast<void**>(debugEventTailSlot),sizeof(void*),writable,&previousProtection))return false;
 if(!debugEventTailProtectDirty)debugEventTailSavedProtection=previousProtection;
 debugEventTailProtectDirty=true;
 void* previous=InterlockedCompareExchangePointer(debugEventTailSlot,replacement,expected);
 const bool protectedAgain=debugEventTailRestoreProtection();
 return previous==expected&&protectedAgain;
}
static bool installContinueDebugEventTail() {
 if(debugEventTailMutation.test_and_set(std::memory_order_acquire)){log("ContinueDebugEvent hook lifecycle is busy.");return false;}
 bool ok=false;
 do {
  const auto engine=GetModuleHandleW(L"TitanEngine.dll");
  const auto getter=engine?reinterpret_cast<DebugEventDataProc>(GetProcAddress(engine,"GetDebugData")):nullptr;
  if(!getter){log("Cannot resolve TitanEngine debug-event data; tail protection was not installed.");break;}
  debugEventData.store(getter,std::memory_order_release);
  const auto slot=debugEventTailFindSlot(GetModuleHandleW(L"TitanEngine.dll"));
  if(!slot){log("Cannot locate a validated TitanEngine KERNEL32!ContinueDebugEvent import; tail protection was not installed.");break;}
  const auto kernel=GetModuleHandleW(L"kernel32.dll");
  const auto expected=kernel?reinterpret_cast<DebugEventTailProc>(GetProcAddress(kernel,"ContinueDebugEvent")):nullptr;
  void* current=nullptr;
  if(!expected||!debugEventTailRead(reinterpret_cast<duint>(slot),&current,sizeof(current)))break;
  const auto own=reinterpret_cast<void*>(&debugEventTailContinue);
  if(current==own){
   if(slot!=debugEventTailSlot||debugEventTailOriginal.load(std::memory_order_acquire)!=expected){log("Unexpected ownership state for ContinueDebugEvent IAT hook.");break;}
   ok=debugEventTailRestoreProtection();debugEventTailEnabled.store(ok,std::memory_order_release);break;
  }
  if(current!=reinterpret_cast<void*>(expected)){log("ContinueDebugEvent IAT already belongs to another hook; it was not overwritten.");break;}
  if(debugEventTailSlot&&debugEventTailSlot!=slot){log("TitanEngine import mapping changed; restart x64dbg before reinstalling tail protection.");break;}
  if(!debugEventTailPinned){
   HMODULE pinned=nullptr;
   if(!GetModuleHandleExW(GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS|GET_MODULE_HANDLE_EX_FLAG_PIN,
       reinterpret_cast<LPCWSTR>(&debugEventTailFrames),&pinned)){log("Could not pin KozDbg safely; ContinueDebugEvent hook was not installed.");break;}
   debugEventTailPinned=true;
   log("KozDbg is pinned for this x64dbg lifetime to keep in-flight callback pointers valid. Restart x64dbg before replacing the plugin binary.");
  }
  debugEventTailSlot=slot;
  debugEventTailOriginal.store(expected,std::memory_order_release);
  ok=debugEventTailSwap(reinterpret_cast<void*>(expected),own);
  debugEventTailEnabled.store(ok,std::memory_order_release);
  if(!ok)log("ContinueDebugEvent hook installation incomplete or ownership changed; any installed wrapper is forwarding only until cleanup.");
 }while(false);
 debugEventTailMutation.clear(std::memory_order_release);
 return ok;
}
static bool removeContinueDebugEventTail() {
 if(debugEventTailMutation.test_and_set(std::memory_order_acquire)){log("ContinueDebugEvent hook lifecycle is busy; removal deferred.");return false;}
 debugEventTailEnabled.store(false,std::memory_order_release);
 bool ok=true;
 if(debugEventTailSlot){
  void* current=nullptr;
  const auto original=debugEventTailOriginal.load(std::memory_order_acquire);
  if(!original||!debugEventTailRead(reinterpret_cast<duint>(debugEventTailSlot),&current,sizeof(current)))ok=false;
  else if(current==reinterpret_cast<void*>(&debugEventTailContinue))ok=debugEventTailSwap(current,reinterpret_cast<void*>(original));
  else if(current==reinterpret_cast<void*>(original))ok=debugEventTailRestoreProtection();
  else{log("ContinueDebugEvent IAT ownership changed externally; refusing to overwrite the new pointer.");ok=false;}
 }
 // Keep the original function and slot identity for calls that fetched the
 // wrapper before the CAS, and for idempotent reinstallation in this process.
 if(!ok)log("ContinueDebugEvent hook cleanup incomplete; restart x64dbg before replacing KozDbg.");

 ++hits[12];logf("[KozDbg] Decoder-page syscall %p uses free DR%u; all other sites retain memory guards.\n",(void*)address,bp.slot);
 return true;
}

static bool writable(duint address,size_t size) {
 if(!address||address>std::numeric_limits<duint>::max()-size)return false;
 duint end=address+size;
 while(address<end){
  MEMORY_BASIC_INFORMATION m{};
  if(!VirtualQueryEx(DbgGetProcessHandle(),(LPCVOID)address,&m,sizeof(m))||m.State!=MEM_COMMIT||(m.Protect&PAGE_GUARD))return false;
  DWORD protection=m.Protect&0xff;
  if(protection!=PAGE_READWRITE&&protection!=PAGE_WRITECOPY&&protection!=PAGE_EXECUTE_READWRITE&&protection!=PAGE_EXECUTE_WRITECOPY)return false;
  duint next=(duint)m.BaseAddress+m.RegionSize;if(next<=address)return false;address=next;
 }
 return true;
}
static bool syscallNumber(const char* name,unsigned& number) {
 duint start=DbgValFromString(name);if(!start)return false;
 bool found=false;
 for(duint pc=start;pc<start+64;){
  BASIC_INSTRUCTION_INFO info{};DbgDisasmFastAt(pc,&info);if(info.size<=0||info.size>15)return false;
  std::array<unsigned char,5> bytes{};if(!DbgMemRead(pc,bytes.data(),bytes.size()))return false;
  if(bytes[0]==0xb8&&info.size==5){memcpy(&number,bytes.data()+1,4);found=true;}
  if(bytes[0]==0x0f&&bytes[1]==0x05){if(found)logf("[KozDbg] Live SSN %s = %X\n",name,number);return found;}
  if(bytes[0]==0xc3)return false;
  pc+=info.size;
 }
 return false;
}

static bool addGuard(duint address) {
 BRIDGEBP old{};if(DbgFunctions()->GetBridgeBp(bp_memory,address,&old)){log("Existing memory breakpoint conflicts with a syscall site.");return false;}

    !cmd("SetMemoryBreakpointCondition "+a+",0")||

    !cmd("SetMemoryBreakpointCommandCondition "+a+",1")||

  strcmp(bp.breakCondition,"0")==0&&strcmp(bp.commandCondition,"1")==0;

}
static bool preserveHardwareContext() {
 if(hardwareSyscalls.empty())return true;
 const duint address=R::GetRCX();CONTEXT context{};
 if(!read(address,context)||(context.ContextFlags&CONTEXT_DEBUG_REGISTERS)!=CONTEXT_DEBUG_REGISTERS)return true;
 for(size_t i=0;i<hardwareSyscalls.size();){
  const auto hardware=hardwareSyscalls[i];
  if(!ownedHardware(hardware.address)){log("Owned decoder breakpoint was changed or removed; pausing to avoid losing coverage.");return false;}
  const auto slot=hardware.slot;
  std::array<duint,4> dr{context.Dr0,context.Dr1,context.Dr2,context.Dr3};
  if(dr[slot]&&dr[slot]!=hardware.address){
   if(!addGuard(hardware.address)||!cmd("bphc "+hex(hardware.address)))return false;
   hardwareSyscalls.erase(hardwareSyscalls.begin()+i);
   log("Context uses a borrowed DR slot; that syscall returned to memory guarding.");continue;
  }
  const duint enableMask=duint(3)<<(slot*2),kindMask=duint(15)<<(16+slot*4);
  const duint wanted=(context.Dr7&~(enableMask|kindMask))|(duint(1)<<(slot*2));
  if(dr[slot]!=hardware.address||context.Dr7!=wanted){
   if(!write(address+offsetof(CONTEXT,Dr0)+slot*sizeof(duint),hardware.address)||!write(address+offsetof(CONTEXT,Dr7),wanted))return false;
   infof("Owned DR preserved at continuation","[KozDbg] Preserved owned DR%u across native context continuation; other slots unchanged.\n",slot);
  }
  context.Dr7=wanted;++i;
 }
 return true;
}
static bool restoreTfGuards(DWORD thread,duint exceptionAddress) {
 for(auto it=tfGuardWindows.begin();it!=tfGuardWindows.end();){
  if(it->thread!=thread||(exceptionAddress&&it->exceptionAddress!=exceptionAddress)){++it;continue;}
  for(auto site:it->sites)if(!ownedGuard(site)&&!addGuard(site))return false;
  infof("TF syscall guards restored","[KozDbg] Restored %u syscall guards after TF delivery for tid=%X\n",static_cast<unsigned>(it->sites.size()),thread);
  it=tfGuardWindows.erase(it);
 }
 return true;
}
static bool prepareTfWindow(duint returnAddress) {
 if(!advanced()||!on(7))return true;
 // The invalid-close call is immediately followed by the runtime TF probe.
 // Decode from its live return address; do not keep a sample-specific RVA.
 duint trap=0;
 for(duint pc=returnAddress;pc<returnAddress+64;){
  std::array<unsigned char,4> bytes{};if(!DbgMemRead(pc,bytes.data(),bytes.size()))return false;
  if(bytes==std::array<unsigned char,4>{0x9d,0x0f,0x31,0x90}){trap=pc+3;break;}
  BASIC_INSTRUCTION_INFO info{};DbgDisasmFastAt(pc,&info);
  if(info.size<=0||info.size>15||(info.branch&&!info.call)||bytes[0]==0xc3)return true;
  pc+=info.size;
 }
 if(!trap)return true;
 const DWORD thread=DbgGetThreadId();
 if(std::any_of(tfGuardWindows.begin(),tfGuardWindows.end(),[&](const TfGuardWindow& w){return w.thread==thread&&w.exceptionAddress==trap;}))return true;
 SYSTEM_INFO system{};GetSystemInfo(&system);
 if(!system.dwPageSize||tfGuardWindows.size()>=128)return false;
 const duint firstPage=(trap-3)/system.dwPageSize,lastPage=trap/system.dwPageSize;
 TfGuardWindow window{thread,trap,{}};
 for(auto site:guardedSites)if(site/system.dwPageSize>=firstPage&&site/system.dwPageSize<=lastPage&&ownedGuard(site))window.sites.push_back(site);
 if(window.sites.empty())return true;
 tfGuardWindows.push_back(window);
 // PAGE_GUARD's own single stepping can consume the target's TF exception.
 // Release only our syscall ranges on these pages until that real exception
 // reaches RtlDispatchException; then restore the ranges before the filter.
 for(auto site:window.sites){
  if(!cmd("bpmc "+hex(site))||ownedGuard(site))return false;
  guardedSites.erase(std::remove(guardedSites.begin(),guardedSites.end(),site),guardedSites.end());
 }
 infof("TF syscall guards released","[KozDbg] Temporarily released %u syscall guards sharing the live TF probe page; tid=%X\n",static_cast<unsigned>(window.sites.size()),thread);
 return true;
}

static bool scanSyscalls() {
 duint base=M::GetMainModuleBase();IMAGE_DOS_HEADER dos{};IMAGE_NT_HEADERS64 nt{};
 if(!base||!read(base,dos)||dos.e_magic!=IMAGE_DOS_SIGNATURE||dos.e_lfanew<=0){log("Syscall scan: cannot read a valid DOS header.");return false;}
 if(base>std::numeric_limits<duint>::max()-static_cast<duint>(dos.e_lfanew)||!read(base+dos.e_lfanew,nt)||nt.Signature!=IMAGE_NT_SIGNATURE){log("Syscall scan: invalid or unreadable NT header.");return false;}
 if(nt.FileHeader.NumberOfSections==0||nt.FileHeader.NumberOfSections>96){log("Syscall scan: invalid section count (expected 1..96).");return false;}
 const duint tableRva=static_cast<duint>(dos.e_lfanew)+sizeof(DWORD)+sizeof(IMAGE_FILE_HEADER)+nt.FileHeader.SizeOfOptionalHeader;
 const duint tableSize=static_cast<duint>(nt.FileHeader.NumberOfSections)*sizeof(IMAGE_SECTION_HEADER);
 if(base>std::numeric_limits<duint>::max()-nt.OptionalHeader.SizeOfImage||tableRva>nt.OptionalHeader.SizeOfImage||tableSize>nt.OptionalHeader.SizeOfImage-tableRva){log("Syscall scan: section table or image address range is invalid.");return false;}
 duint sections=base+tableRva;
 std::vector<std::pair<duint,duint>> codeRanges;
 bool hasUnbackedCode=false;
 for(unsigned i=0;i<nt.FileHeader.NumberOfSections;i++){
  IMAGE_SECTION_HEADER s{};
  if(!read(sections+i*sizeof(s),s)){logf("[KozDbg] Syscall scan: cannot read section header %u at %p.\n",i,(void*)(sections+i*sizeof(s)));return false;}
  if(!(s.Characteristics&IMAGE_SCN_MEM_EXECUTE))continue;
  const size_t length=s.Misc.VirtualSize;if(!length)continue;
  if(!s.SizeOfRawData)hasUnbackedCode=true;
  if(s.VirtualAddress>=nt.OptionalHeader.SizeOfImage||length>nt.OptionalHeader.SizeOfImage-s.VirtualAddress){logf("[KozDbg] Syscall scan: section %u lies outside SizeOfImage (RVA=%X size=%X).\n",i,s.VirtualAddress,s.Misc.VirtualSize);return false;}
  codeRanges.push_back({base+s.VirtualAddress,base+s.VirtualAddress+length});
  logf("[KozDbg] Scanning section %u (%.8s): %llu bytes in 1 MiB blocks.\n",i,reinterpret_cast<const char*>(s.Name),static_cast<unsigned long long>(length));
  const bool scanned=kozScanChunks(length,[&](size_t offset,unsigned char* data,size_t count){
   const duint address=base+s.VirtualAddress+offset;
   if(DbgMemRead(address,data,count))return true;
   logf("[KozDbg] Syscall scan: read failed in section %u (%.8s) at %p, block size=%llu. Scan aborted; no unreadable bytes skipped.\n",i,reinterpret_cast<const char*>(s.Name),(void*)address,static_cast<unsigned long long>(count));return false;
  },[&](size_t offset){
   if(syscallSites.size()>=2048){logf("[KozDbg] Syscall scan: candidate limit 2048 exceeded in section %u at %p; refusing unbounded instrumentation.\n",i,(void*)(base+s.VirtualAddress+offset));return false;}
   syscallSites.push_back(base+s.VirtualAddress+offset);return true;
  });
  if(!scanned)return false;
 }
 // The 3.6 native-call wrappers form dense syscall islands. Isolated 0F05
 // byte pairs in VM immediates are not instruction boundaries and must not
 // put guard stepping on arbitrary VM handlers (notably PUSHFQ handlers).
 if(profile().engine==Engine::ClusteredSyscalls){
  const auto all=syscallSites;
  syscallSites.erase(std::remove_if(syscallSites.begin(),syscallSites.end(),[&](duint site){
   return std::count_if(all.begin(),all.end(),[&](duint other){return other>=site-0x400&&other<=site+0x400;})<4;
  }),syscallSites.end());
 }else{
  // 3.8 disperses native wrappers: after SYSCALL they resume through a direct
  // call into executable image code or a PUSH-based VM transition. Recognize
  // that continuation, rather than density. Embedded displacement/immediate
  // pairs on hot VM-handler pages must not create per-instruction guard traps.
  syscallSites.erase(std::remove_if(syscallSites.begin(),syscallSites.end(),[&](duint site){
   std::array<unsigned char,5> tail{};if(!DbgMemRead(site+2,tail.data(),tail.size()))return true;
   if((tail[0]>=0x50&&tail[0]<=0x57)||tail[0]==0x68||tail[0]==0x6a||tail[0]==0x9c||
      (tail[0]==0x41&&tail[1]>=0x50&&tail[1]<=0x57))return false;
   if(tail[0]!=0xe8)return true;
   int32_t displacement=0;memcpy(&displacement,tail.data()+1,4);duint target=0;
   if(!relativeAddress(site+2,5,displacement,target))return true;
   return std::none_of(codeRanges.begin(),codeRanges.end(),[&](const auto& r){return target>=r.first&&target<r.second;});
  }),syscallSites.end());
 }
 if(syscallSites.empty()){log("No live syscall candidates were found in the main executable.");return false;}
 // Only consider images with executable content to reconstruct at runtime.
 // Unpacked runtimes can contain a dormant decoder too; keep their DR slots free.
 if(on(12)&&hasUnbackedCode){
  SYSTEM_INFO system{};GetSystemInfo(&system);std::vector<duint> visited;
  if(system.dwPageSize)for(auto site:syscallSites){
   const duint page=site/system.dwPageSize*system.dwPageSize;
   if(std::find(visited.begin(),visited.end(),page)!=visited.end())continue;
   visited.push_back(page);
   std::vector<duint> pageSites;
   for(auto candidate:syscallSites)if(candidate/system.dwPageSize==page/system.dwPageSize)pageSites.push_back(candidate);
   if(pageSites.size()>4||!rangeDecoderPage(page,system.dwPageSize))continue;
   bool complete=true;
   for(auto candidate:pageSites)if(!addHardwareSyscall(candidate)){complete=false;break;}
   if(complete){logf("[KozDbg] Decoder page %p: all %u candidates use hardware breakpoints.\n",(void*)page,static_cast<unsigned>(pageSites.size()));break;}
   // Partial coverage would leave PAGE_GUARD on the hot page anyway.
   for(const auto& hardware:hardwareSyscalls)if(ownedHardware(hardware.address)&&!cmd("bphc "+hex(hardware.address))){log("Cannot roll back partial decoder acceleration; stopping setup.");return false;}
   hardwareSyscalls.clear();log("Not enough safe hardware slots for the complete decoder page; retaining memory coverage.");
  }
 }
 for(auto site:syscallSites){
  const bool accelerated=std::any_of(hardwareSyscalls.begin(),hardwareSyscalls.end(),[&](const HardwareSyscall& h){return h.address==site;});
  if(!accelerated&&!addGuard(site)){logf("[KozDbg] Syscall scan: cannot install guard at %p; check existing breakpoints and page access.\n",(void*)site);return false;}
 }
 logf("[KozDbg] Tracking %u live SYSCALL candidates: %u memory guards, %u hardware slots; protected instructions unchanged.\n",static_cast<unsigned>(syscallSites.size()),static_cast<unsigned>(guardedSites.size()),static_cast<unsigned>(hardwareSyscalls.size()));
 return true;
}
static duint exceptionDispatcherTarget() {
 // Resolve the direct dispatch call from the exported Windows dispatcher.
 // On this x64 form RCX is EXCEPTION_RECORD*, RDX is CONTEXT* from RSP.
 duint start=DbgValFromString("ntdll:KiUserExceptionDispatcher");
 if(!start)return 0;
 for(duint pc=start;pc<start+128;){
  BASIC_INSTRUCTION_INFO info{};DbgDisasmFastAt(pc,&info);if(info.size<=0||info.size>15)return 0;
  std::array<unsigned char,5> bytes{};if(!DbgMemRead(pc,bytes.data(),bytes.size()))return 0;
  if(bytes[0]==0xe8&&info.size==5&&pc>=start+3){
   std::array<unsigned char,3> previous{};
   if(DbgMemRead(pc-3,previous.data(),3)&&previous==std::array<unsigned char,3>{0x48,0x8b,0xd4}){
    int32_t displacement=0;memcpy(&displacement,bytes.data()+1,4);duint target=0;
    if(relativeAddress(pc,5,displacement,target))return target;
   }
  }
  if(bytes[0]==0xc3)break;pc+=info.size;
 }
 return 0;
}

static bool emulateQuery(duint process,duint infoClass,duint buffer,duint size,duint returnLength,duint& result) {
 bool port=infoClass==7&&on(1),object=infoClass==0x1e&&on(2);
 if((!port&&!object)||size!=8||(buffer&7)||!writable(buffer,8)||!isSelfHandle(process,false))return false;
 // Preserve real kernel validation for invalid pointers such as ReturnLength=1.
 if(returnLength&&((returnLength&3)||!writable(returnLength,4)))return false;
 if(!write(buffer,duint(0)))return false;
 if(returnLength&&!write(returnLength,uint32_t(8)))return false;
 result=port?0:0xc0000353;
 count(port?1:2,port?"Self ProcessDebugPort -> success / zero port":"Self debug object -> STATUS_PORT_NOT_SET; ordered output/ReturnLength writes preserved");
 return true;
}

static bool watchHiddenThread(duint handle,duint infoClass,duint buffer,duint size,duint address,duint sp,duint delta) {

static bool syscallHit(int,char**) {
 if(!armed||!advanced())return true;
 duint ip=R::GetRIP(),sp=R::GetRSP();
 if(std::find(syscallSites.begin(),syscallSites.end(),ip)==syscallSites.end())return true;
 uint16_t opcode=0;if(!read(ip,opcode)||opcode!=0x050f)return true;
 unsigned ssn=R::GetEAX();duint result=0;bool handled=false;
 if(ssn==queryProcessSSN){duint returnLength=0;if(read(sp+0x28,returnLength))handled=emulateQuery(R::GetR10(),R::GetRDX(),R::GetR8(),R::GetR9(),returnLength,result);}
 else if(ssn==setThreadSSN&&on(3)&&R::GetRDX()==0x11&&R::GetR8()==0&&R::GetR9()==0&&isSelfHandle(R::GetR10(),true)){
  rememberHiddenThread(R::GetR10());
  handled=true;count(3,"Direct-syscall ThreadHideFromDebugger suppressed");
 }else if(ssn==setProcessSSN&&nullCallback(R::GetR10(),R::GetRDX(),R::GetR8(),R::GetR9())){
  handled=true;count(8,"Direct instrumentation-callback clearing suppressed");
 }
 if(extendedChecks()&&!handled){
  bool ok=true;
  if(on(3)&&ssn==queryThreadSSN)ok=watchHiddenThread(R::GetR10(),R::GetRDX(),R::GetR8(),R::GetR9(),ip+2,sp,0);
  else if(ssn==querySystemSSN){
   if(on(4)&&R::GetR10()==0x23&&R::GetR8()>=2)ok=watchReturn(ip+2,ReturnKind::Kernel,R::GetRDX(),R::GetR8(),sp,0);

static bool isSelfHandle(duint value,bool thread) {
 if(value==(thread?duint(-2):duint(-1)))return true;
 if(!value||value>=duint(-16))return false;
 HANDLE local=nullptr;
 if(!DuplicateHandle(DbgGetProcessHandle(),(HANDLE)value,GetCurrentProcess(),&local,0,FALSE,DUPLICATE_SAME_ACCESS))return false;
 DWORD pid=thread?GetProcessIdOfThread(local):GetProcessId(local);
 CloseHandle(local);
 return pid!=0&&pid==GetProcessId(DbgGetProcessHandle());
}
static DWORD selfThreadId(duint value) {
 if(value==duint(-2))return DbgGetThreadId();
 if(!value||value>=duint(-16))return 0;
 HANDLE local=nullptr;
 if(!DuplicateHandle(DbgGetProcessHandle(),(HANDLE)value,GetCurrentProcess(),&local,0,FALSE,DUPLICATE_SAME_ACCESS))return 0;
 DWORD id=GetProcessIdOfThread(local)==GetProcessId(DbgGetProcessHandle())?GetThreadId(local):0;
 CloseHandle(local);return id;
}

static bool addBP(duint addr,const std::string& action) {
 if(!addr||DbgGetBpxTypeAt(addr)!=bp_none){log("Breakpoint conflict or unresolved API; existing user breakpoints were not changed.");return false;}
 // x64dbg treats an existing NAME as a match even at a different address and
 // returns success without creating another breakpoint. One name per live PC.
 const std::string address=hex(addr);
 const std::string name="KZ_"+action+"_"+address;
 const std::string command="kz_hit "+action;
 // API bindings must not remove execute permission from an entire ntdll page.
 // Stepping a blocking syscall on that page can suspend the thread it awaits.
 // Native syscall bindings are resolved past their identifying prefix below.
 if(!cmd("bp "+address+",\""+name+"\""))return false;
 BRIDGEBP actual{};
 if(!DbgFunctions()->GetBridgeBp(bp_normal,addr,&actual)||actual.addr!=addr||strcmp(actual.name,name.c_str())!=0){
  logf("[KozDbg] Breakpoint was NOT created at %p (%s). Profile will stay inactive.\n",(void*)addr,name.c_str());
  return false;
 }
 owned.push_back(addr);
 bool configured=cmd("SetBreakpointCondition "+address+",0") &&
 cmd("SetBreakpointFastResume "+address+",0") &&
 cmd("SetBreakpointCommand "+address+",\""+command+"\"") &&
 cmd("SetBreakpointCommandCondition "+address+",1") &&
 cmd("SetBreakpointSilent "+address+",1");
 if(configured){
  actual={};
  configured=DbgFunctions()->GetBridgeBp(bp_normal,addr,&actual)&&actual.addr==addr&&actual.enabled&&
   strcmp(actual.name,name.c_str())==0&&strcmp(actual.commandText,command.c_str())==0&&
   strcmp(actual.breakCondition,"0")==0&&strcmp(actual.commandCondition,"1")==0&&!actual.fastResume&&actual.silent;
 }
 if(!configured){
  logf("[KozDbg] Breakpoint setup/readback failed at %p (%s); rolling back.\n",(void*)addr,name.c_str());
  BRIDGEBP rollback{};
  if(DbgFunctions()->GetBridgeBp(bp_normal,addr,&rollback)&&strcmp(rollback.name,name.c_str())==0)cmd("bc "+address);
  owned.pop_back();
 }
 return configured;
}
struct ApiBinding {duint address;unsigned action;};
static bool addBinding(std::vector<ApiBinding>& bindings,duint address,unsigned action) {
 if(!address)return false;
 auto existing=std::find_if(bindings.begin(),bindings.end(),[&](const ApiBinding& b){return b.address==address;});
 if(existing!=bindings.end())return existing->action==action;
 bindings.push_back({address,action});return true;
}
static bool relativeAddress(duint start,size_t length,int32_t displacement,duint& result) {
 if(start>std::numeric_limits<duint>::max()-length)return false;
 duint next=start+length;
 if(displacement<0){duint magnitude=static_cast<duint>(-static_cast<int64_t>(displacement));if(next<magnitude)return false;result=next-magnitude;}
 else {if(next>std::numeric_limits<duint>::max()-static_cast<duint>(displacement))return false;result=next+static_cast<duint>(displacement);}
 return true;
}
static duint straightLineReturn(duint entry) {
 // IsDebuggerPresent is a leaf on the supported Windows path. Decode instruction
 // boundaries instead of scanning for a C3 byte inside an immediate or using an RVA.
 duint pc=entry;
 for(unsigned instructions=0;instructions<32&&pc-entry<128;instructions++){
  BASIC_INSTRUCTION_INFO info{};DbgDisasmFastAt(pc,&info);
  if(info.size<=0||info.size>15)return 0;
  unsigned char opcode=0;if(!read(pc,opcode))return 0;
  if(opcode==0xc3&&info.size==1)return pc;
  if(info.branch||info.call||opcode==0xcc||pc>std::numeric_limits<duint>::max()-info.size)return 0;
  pc+=info.size;
 }
 return 0;
}
static bool resolveBinding(std::vector<ApiBinding>& bindings,const char* symbol,unsigned action,bool required) {
 duint address=DbgValFromString(symbol);
 if(!address){if(required)logf("[KozDbg] Cannot resolve required API: %s\n",symbol);return !required;}
 // Resolve before placing INT3 bytes. Cover code thunks as well as direct calls
 // to KernelBase; a kernel32 export need not be a PE export forwarder.
 std::vector<duint> visited;
 for(unsigned hop=0;hop<16;hop++){
  if(std::find(visited.begin(),visited.end(),address)!=visited.end())return false;
  visited.push_back(address);
  logf("[KozDbg] Resolved %s%s -> %p\n",symbol,hop?" thunk":"",(void*)address);
  std::array<unsigned char,7> code{};
  if(!DbgMemRead(address,code.data(),code.size()))return false;
  duint target=0;int32_t displacement=0;size_t offset=code[0]==0x48?1:0;
  if(code[offset]==0xff&&code[offset+1]==0x25){
   memcpy(&displacement,code.data()+offset+2,sizeof(displacement));duint slot=0;
   if(!relativeAddress(address,offset+6,displacement,slot)||!read(slot,target)||!target)return false;
  } else if(code[0]==0xe9){
   memcpy(&displacement,code.data()+1,sizeof(displacement));
   if(!relativeAddress(address,5,displacement,target))return false;
  } else if(code[0]==0xeb){
   if(!relativeAddress(address,2,static_cast<int8_t>(code[1]),target))return false;
  } else {
   // Leave forwarding thunks intact. Their INT3 byte changes the protected
   // loader's behavior even though the final implementation is also covered.
   if(action!=0){
    if(strncmp(symbol,"ntdll:Nt",8)==0){
     std::array<unsigned char,24> stub{};
     if(!DbgMemRead(address,stub.data(),stub.size()))return false;
     const std::array<unsigned char,4> prefix{0x4c,0x8b,0xd1,0xb8};
     const std::array<unsigned char,16> dispatch{0xf6,0x04,0x25,0x08,0x03,0xfe,0x7f,0x01,0x75,0x03,0x0f,0x05,0xc3,0xcd,0x2e,0xc3};
     const bool prefixOk=std::equal(prefix.begin(),prefix.end(),stub.begin());
     const bool dispatchOk=std::equal(dispatch.begin(),dispatch.end(),stub.begin()+8)||
      (stub[8]==0x0f&&stub[9]==0x05&&stub[10]==0xc3);
     if(!prefixOk||!dispatchOk){logf("[KozDbg] Unsupported native syscall stub for %s; refusing a guessed API breakpoint.\n",symbol);return false;}
     // mov r10,rcx; mov eax,SSN have no stack/argument side effects.
     // Preserve those bytes for loaders which inspect the exported stub.
     address+=8;
     logf("[KozDbg] Validated post-prefix API breakpoint %s -> %p; syscall identification bytes retained.\n",symbol,(void*)address);
    }
    return addBinding(bindings,address,action);
   }
   duint returnPc=straightLineReturn(address);
   if(!returnPc){log("Cannot locate a straight-line IsDebuggerPresent RET; refusing an unverified entry-skip fallback.");return false;}
   logf("[KozDbg] IsDebuggerPresent RET resolved from instructions -> %p\n",(void*)returnPc);
   return addBinding(bindings,returnPc,action);
  }
  address=target;
 }
 log("API thunk chain is too deep; profile was not armed.");return false;
}

static bool apply(int,char**) {
 if(DbgIsDebugging()&&DbgIsRunning()){log("Pause the target before applying a profile.");return false;}
 if(!disarm())return false;
 if(!enabled){if(DbgIsDebugging())cleanSavedBreakpoints();log("Disabled. Owned breakpoints removed.");return true;}
 if(!DbgIsDebugging()){logf("[KozDbg] %s selected; waiting for a new debug session.\n",profile().version);return true;}
 if(!installDebugEventTail()){log("Cannot install the debugger event-tail checkpoint; profile was not armed.");return false;}
 // Architecture check only: no filename, hash, image-base or RVA dependency.
 IMAGE_DOS_HEADER dos{};IMAGE_NT_HEADERS64 nt{};duint imageBase=M::GetMainModuleBase();
 if(!imageBase||!read(imageBase,dos)||dos.e_magic!=IMAGE_DOS_SIGNATURE||dos.e_lfanew<=0||
    !read(imageBase+(duint)dos.e_lfanew,nt)||nt.Signature!=IMAGE_NT_SIGNATURE||
    nt.FileHeader.Machine!=IMAGE_FILE_MACHINE_AMD64||nt.OptionalHeader.Magic!=IMAGE_NT_OPTIONAL_HDR64_MAGIC){
  log("This build supports native x64 targets only.");return false;
 }
 cleanSavedBreakpoints();
 const char* names[]={"kernel32:IsDebuggerPresent","kernel32:CheckRemoteDebuggerPresent","ntdll:NtQueryInformationProcess","ntdll:NtSetInformationThread","ntdll:NtQuerySystemInformation","ntdll:NtClose"};
 std::vector<ApiBinding> bindings;
 bool ok=true;
 for(unsigned i=0;i<6&&ok;i++){
  bool needed=i<4?on(i):(i==4?(on(4)||on(5)):on(6));
  if(advanced()&&i==2)needed=on(1)||on(2);
  if(needed)ok=resolveBinding(bindings,names[i],i,true);
 }
 if(ok&&on(0))ok=resolveBinding(bindings,"kernelbase:IsDebuggerPresent",0,false);
 if(ok&&on(1))ok=resolveBinding(bindings,"kernelbase:CheckRemoteDebuggerPresent",1,false);
 for(const auto& binding:bindings){if(!ok)break;ok=addBP(binding.address,std::to_string(binding.action));}
 if(ok){
  try {ok=advanced()?setupDirect():setupLegacyContext();}
  catch(const std::bad_alloc&){log("Arming failed: insufficient memory while preparing scan/check state.");ok=false;}
 }
 if(!ok){if(disarm())log("Arming failed; all breakpoints created by this attempt were removed.");else log("Arming failed and cleanup remains pending; stop the session before trying again.");return false;}
 armed=true;
 logf("[KozDbg] Verified %u API breakpoints by address, name and command.\n",static_cast<unsigned>(owned.size()));
 logf("[KozDbg] %s profile armed. Addresses resolved in this process; no sample-specific offsets. F9 to continue.\n",profile().version);return true;
}
static bool filterModules(const Pending& p) {
 if((int32_t)R::GetEAX()<0)return true;
 uint32_t countModules=0;
 if(!read(p.buffer,countModules)||p.size<8||countModules>(p.size-8)/0x128||countModules>65536)return false;
 std::vector<unsigned char> data((size_t)countModules*0x128);
 if(!data.empty()&&!DbgMemRead(p.buffer+8,data.data(),data.size()))return false;
 uint32_t kept=0,removed=0;
 for(uint32_t i=0;i<countModules;i++){
  auto record=data.data()+i*0x128;uint16_t offset;memcpy(&offset,record+0x26,2);
  if(offset>=256)return false;
  const char* name=(char*)record+0x28+offset;size_t room=256-offset;
  if(!memchr(name,0,room))return false;
  bool blocked=false;
  for(auto s:{"sice.sys","siwvid.sys","ntice.sys","iceext.sys","syser.sys"})if(_stricmp(name,s)==0)blocked=true;
  if(blocked){++removed;continue;}
  if(kept!=i)memmove(data.data()+kept*0x128,record,0x128);
  ++kept;
 }
 if(removed){
  std::fill(data.begin()+kept*0x128,data.end(),static_cast<unsigned char>(0));
  if(!DbgMemWrite(p.buffer+8,data.data(),data.size())||!write(p.buffer,kept))return false;
 }
 ++hits[5];infof("Module list filtered","[KozDbg] Module list: %u records, %u matching names removed.\n",countModules,removed);return true;
}
static bool watchReturn(duint address,ReturnKind kind,duint buffer,duint size,duint sp,duint stackDelta=8) {
 // Distinguish concurrent callers and recursive calls, even with the same return PC.
 if(pending.size()>=4096)return false;
 DWORD thread=DbgGetThreadId();
 if(std::any_of(pending.begin(),pending.end(),[&](const Pending& p){
  return p.address==address&&p.thread==thread&&p.stack==sp+stackDelta&&p.kind==kind&&p.buffer==buffer;
 }))return true;
 bool already=std::any_of(pending.begin(),pending.end(),[&](const Pending& p){return p.address==address;});
 if(!already&&!addBP(address,"return"))return false;
 pending.push_back({address,buffer,size,sp+stackDelta,thread,kind});return true;
}
static bool processReturn(const Pending& p) {
 if(p.kind==ReturnKind::Attach)return !R::GetEAX()||restoreAttach();
 if(p.kind==ReturnKind::Modules)return filterModules(p);
 if(p.kind==ReturnKind::Remote){
  if(!R::GetEAX())return true;
  uint32_t value=0;if(!write(p.buffer,value))return false;
  count(1,"Successful remote debugger query: output -> FALSE");return true;
 }
 if((int32_t)R::GetEAX()<0)return true;
 if(p.kind==ReturnKind::HiddenThread){
  if(std::find(hiddenThreads.begin(),hiddenThreads.end(),static_cast<DWORD>(p.size))==hiddenThreads.end())return true;
  unsigned char before=0;
  if(!read(p.buffer,before)||!write(p.buffer,static_cast<unsigned char>(1)))return false;
  ++hits[3];infof("ThreadHideFromDebugger query adjusted","[KozDbg] Successful ThreadHideFromDebugger query for tid=%X: %u -> 1; real status and ReturnLength preserved\n",static_cast<DWORD>(p.size),before);return true;
 }
 uint16_t value=0x100;if(!write(p.buffer,value))return false;
 count(4,"Successful kernel debugger query: bytes -> 00 01");return true;
}
static bool hit(int argc,char** argv) {
 if(argc<2||!armed)return true;
 bool ok=true;duint ip=R::GetRIP(),sp=R::GetRSP(),ra=0;
 if(strcmp(argv[1],"return")==0){
  auto it=std::find_if(pending.begin(),pending.end(),[&](const Pending& p){return p.address==ip&&p.thread==DbgGetThreadId()&&p.stack==sp;});
  if(it!=pending.end()){
   auto p=*it;pending.erase(it);ok=processReturn(p);
   if(std::none_of(pending.begin(),pending.end(),[&](const Pending& other){return other.address==ip;}))removeBP(ip);
  }
 } else if(read(sp,ra)) {
  int n=atoi(argv[1]);
  if(n<0||n>=static_cast<int>(apiSeen.size()))return false;
  if(apiSeen[n]++==0){
   char caller[MAX_MODULE_SIZE]{};
   if(!M::NameFromAddr(ra,caller))strcpy_s(caller,"unmapped/private");
   logf("[KozDbg] API %d hit=%u tid=%X pc=%p caller=%s:%p rsp=%p rcx=%p rdx=%p\n",
    n,apiSeen[n],DbgGetThreadId(),(void*)ip,caller,(void*)ra,(void*)sp,(void*)R::GetRCX(),(void*)R::GetRDX());
  }
  if(n<4&&(on(n)||(advanced()&&n==2&&on(1)))){
   switch(n){
    case 0:{
     // This binding is at the decoded RET, after the real PEB read. Preserve RIP
     // and RSP so the CPU performs the normal return, as in the recorded manual test.
     unsigned char opcode=0;duint before=R::GetRAX();
     ok=read(ip,opcode)&&opcode==0xc3&&R::SetRAX(0)&&R::GetRAX()==0&&R::GetRIP()==ip&&R::GetRSP()==sp;
     if(ok){++hits[0];infof("IsDebuggerPresent return adjusted","[KozDbg] IsDebuggerPresent RET: RAX %p -> 0 (readback verified), caller=%p; native RET will execute.\n",(void*)before,(void*)ra);}
     break;
    }
    case 1:if(isSelfHandle(R::GetRCX(),false)&&R::GetRDX())ok=watchReturn(ra,ReturnKind::Remote,R::GetRDX(),4,sp);break;
    case 2:if(advanced()){
     duint returnLength=0,statusValue=0;
     if(read(sp+0x28,returnLength)&&emulateQuery(R::GetRCX(),R::GetEDX(),R::GetR8(),R::GetR9(),returnLength,statusValue))ok=ret(ra,statusValue);
    }else if(R::GetEDX()==0x1e&&R::GetR9()==8&&R::GetR8()&&
      (R::GetR8()&7)==0&&isSelfHandle(R::GetRCX(),false)){
     // No successful query is executed: no real debug-object handle is leaked.
     ok=ret(ra,0xc0000353);if(ok)count(2,"Self debug object query -> STATUS_PORT_NOT_SET");
    }break;
    case 3:if(R::GetEDX()==0x11&&R::GetR8()==0&&R::GetR9()==0&&isSelfHandle(R::GetRCX(),true)){
     rememberHiddenThread(R::GetRCX());
     ok=ret(ra,0);if(ok)count(3,"ThreadHideFromDebugger suppressed");
    }break;
   }
  }
  if(n==4){
   if(on(4)&&R::GetECX()==0x23&&R::GetR8()>=2&&R::GetRDX()){
    ok=watchReturn(ra,ReturnKind::Kernel,R::GetRDX(),R::GetR8(),sp);
   } else if(on(5)&&R::GetECX()==0xb&&R::GetR8()>=8&&R::GetRDX()){
    ok=watchReturn(ra,ReturnKind::Modules,R::GetRDX(),R::GetR8(),sp);
   }
  }
  // NtClose is called inside CloseHandle, so its immediate caller is KernelBase.
  // DEADC0DE is the researched invalid-handle input, not a code address.
  if(n==5&&on(6)&&R::GetRCX()==0xdeadc0de){ok=prepareTfWindow(ra)&&ret(ra,0xc0000008);if(ok)count(6,"Invalid NtClose -> STATUS_INVALID_HANDLE without debugger exception");}
  if(n>=6&&(advanced()||(on(9)&&n>=7&&n<=9)))ok=hitDirect(n,ip,sp,ra);
 }
 if(!ok){log("An operation failed. Pausing for inspection; no automatic resume.");cmd("mov $breakpointcondition,1");}
 return ok;
}

static bool status(int,char**) {
 logf("[KozDbg] Profile: %s | armed: %s | auto-arm: %s\n",enabled?profile().version:"Disabled",armed?"yes":"no",autoArm?"yes":"no");
 const char* labels[]={"PEB/API state","Remote/debug port","Debug object","Thread hide","Kernel debugger","Module list","Invalid handle","TF delivery","Keep callback","Saved DR context","Keep remote breakin","Protect TitanHide","Decoder acceleration"};

#pragma once
#include <algorithm>
#include <cstddef>
#include <vector>

// Fixed memory use. One-byte lookahead preserves 0F 05 across block boundaries.
// Every candidate offset is visited once; sections never share lookahead bytes.
template<class Reader,class Match>
bool kozScanChunks(size_t length,Reader reader,Match match){
 constexpr size_t block=1024*1024;
 std::vector<unsigned char> bytes((std::min)(length,block+1));
 for(size_t offset=0;offset<length;){
  const size_t step=(std::min)(block,length-offset);
  const size_t count=step+(length-offset>step?1:0);
  if(!reader(offset,bytes.data(),count))return false;
  for(size_t i=0;i<step&&i+1<count;i++)
   if(bytes[i]==0x0f&&bytes[i+1]==0x05&&!match(offset+i))return false;
  offset+=step;
 }
 return true;
}
