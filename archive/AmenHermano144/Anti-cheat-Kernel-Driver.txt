`README.md`:

```md
# Core_ac — Kernel Anti-Cheat

A Windows x64 kernel-mode anti-cheat driver designed for competitive multiplayer titles. Core_ac is a self-contained reference implementation focused on clean modular architecture, verifiable detection techniques, and a hardened user-mode channel protected by per-session AES-GCM sealing.

> **Status:** Reference implementation. Everything in this tree compiles against the Windows WDK and the Visual Studio 2022 kernel-mode toolset. There are no stubs, no VM shims, and no vendored third-party crypto — all cryptography is delegated to the Windows CNG (`BCrypt*`) kernel surface.

---

## 1. Why Core_ac

Modern anti-cheats are judged by three qualities:

1. **Correctness in the kernel.** Allocations are NX-tagged, callbacks are symmetrical, every acquired resource has a clear owner, and dispatch respects IRQL.
2. **Resistance to tampering.** Boot-time secrets live as XOR-pairs, the LSTAR MSR is tracked across every IOCTL *and* from NMI context, and the control device is DACL-locked to SYSTEM + Administrators only.
3. **Observability without blind spots.** Image loads, process creation, PML4 drift, BYOVD loads, and HWID state all surface as typed wire records on a lock-free SPSC ring that user mode drains via `IOCTL_AC_EVENT_POLL`.

Core_ac is structured so each of those three qualities can be audited independently: no module reaches into another's private state, every subsystem exposes a short `*_Init` / `*_Shutdown` lifetime, and the only global state lives in a single `CORE_AC_GLOBAL`.

---

## 2. Architecture at a glance

                                         │

   │                        Deferred init worker (passive)                   │
   │  IoCreateDevice ──► \Device\CoreAC + \??\CoreAC (symlink)               │
   │  IoCreateDevice ──► \Device\CoreAC_EVT (event poll surface)             │
   │  ObSetSecurity   ──► DACL: SYSTEM + Admins only                         │

   │  AcTamperArm (LSTAR snapshot)   NmiWatchdogRegister                     │

## 5. Device + DACL hardening

| Object | Path | Access |
|---|---|---|
| Control device | `\Device\CoreAC` (`\??\CoreAC`) | SYSTEM, Administrators — everyone else denied |
| Event device   | `\Device\CoreAC_EVT`              | SYSTEM, Administrators — everyone else denied |

The DACL is applied with `ObSetSecurityObjectByPointer` after device creation. Both ACEs are `GENERIC_ALL`; everyone else inherits the empty DACL and gets no access. Standard anti-cheat practice: user-mode companion runs as a SYSTEM service, nothing else can `CreateFile` on the device.

---

## 6. Anti-tamper

Three complementary checks:

1. **LSTAR (`0xC0000082`).** Snapshotted during `AcTamperArm` into an XOR-pair. On every IOCTL dispatch and every NMI callback the current value is compared to the reference. Mismatch → tamper event is enqueued and the MSR is rewritten to the known-good value.
2. **DEBUGCTL (`0x1D9`).** The LBR bit is checked from NMI context. If userland or a hypervisor flipped it to steal callstacks, we observe it where we can't be masked.
3. **Stack cookie.** A per-boot XOR-pair derived from `__rdtsc`. Mismatch is routed through the tamper event producer.

Boot cookie, LSTAR reference and stack cookie are stored exclusively as XOR-pairs so a lazy scanner looking for the live value by signature finds nothing.

---

## 7. Detection surfaces

### 7.1 BYOVD scanner

Catches vulnerable drivers using two independent signals:

- **Substring match (lowercase case-fold Unicode).** 60+ well-known BYOVD names baked in: `winring0`, `rtcore64`, `mhyprot2`, `dbutil_2_3`, `iqvw64`, `winio`, `phymem`, `atillk64`, `rwdrv`, and so on.
- **PE `TimeDateStamp` denylist.** `driver_ts_blacklist.c` carries timestamps known to belong to signed-but-weaponizable drivers.

Both signals produce `WIRE_REC_BYOVD_HIT` records tagged with `ImageBase`, `ImageSize`, the matched path, and a path FNV1a64.

### 7.2 PML4 physical walker

Reads the current CR3-pointed PML4 page via `MmCopyMemory` with `MM_COPY_MEMORY_PHYSICAL`. This bypasses virtual-address hooks placed by non-root hypervisors or EPT shadows. The initial snapshot is compared against each rescan; drift surfaces as `WIRE_REC_PML4_ANOMALY` records with observed vs. expected entries and the physical base.

### 7.3 HWID collection

Through `ZwQuerySystemInformation(SystemFirmwareTableInformation)` using the `'RSMB'` provider. The parser walks SMBIOS entry types 0, 1, 2, and 17 to extract BIOS vendor, system manufacturer, product, baseboard serial, system UUID, and memory module count. The ACPI enumerator runs best-effort — VBS/HVCI systems may return `STATUS_NOT_IMPLEMENTED`, which the caller tolerates.

A composite digest (SHA-256 over the parsed structure) is cached and emitted as `WIRE_REC_HWID_HELLO`.

### 7.4 Image + process callbacks

- `PsSetLoadImageNotifyRoutineEx` (resolved dynamically through `MmGetSystemRoutineAddress`, falling back to `PsSetLoadImageNotifyRoutine`) demultiplexes into kernel-image path (BYOVD scanner, module inventory diff) and user-image path (`WIRE_REC_IMAGE_LOAD`).
- When `ExtendedInfoPresent` is set and `CiValidateFileObject` resolved, the shim is invoked under `__try/__except`; a failing return produces `WIRE_REC_SIG_REJECT` with the image path, base and NTSTATUS.
- `PsSetCreateProcessNotifyRoutineEx` produces `WIRE_REC_PROCESS_ATTACH` (with parent PID + image path) and `WIRE_REC_PROCESS_EXIT` on teardown; exits also drop the PML4 watcher entry.

### 7.5 Unbacked execution regions

`exec_region_scan.c` drives `ZwQuerySystemInformation(SystemBigPoolInformation)` (class `0x42`). For each non-paged entry ≥ 256 B whose base does not fall inside a module from the boot `KldrSnapshotModules`:

- At boot it is written to the baseline (up to 1024 entries).
- At each heartbeat, anything new relative to that baseline is enqueued as `WIRE_REC_UNBACKED_EXEC` with up to 64 bytes of leading content, the pool tag, and a `Flags` bit set when the tag has non-printable bytes (useful heuristic for tags such as `'llehS'` left by shellcode trampolines).

Capped at 32 hits per pass to prevent telemetry floods.

### 7.6 Input class callback integrity

`input_integrity.c` references `\Driver\MouHID`, `\Driver\KbdHid` and `\Driver\i8042prt`, walks each upper device's `AttachedDevice` chain, and for every paired `\Driver\MouClass` / `\Driver\KbdClass` device scans the upper device's `DeviceExtension`. When it finds a slot whose value equals the class `PDEVICE_OBJECT` and whose next slot points above the class `PDRIVER_OBJECT`, that next slot holds the service callback. The slot address and its current value are snapshotted.

At each heartbeat the slot is re-read under `__try/__except`. If the pointer no longer matches the snapshot and does not land inside any module known at boot, a `WIRE_REC_INPUT_HIJACK` is emitted along with a `WIRE_REC_TAMPER(AC_TAMPER_REASON_INPUT)`.

### 7.7 PiDDBCache / MmUnloadedDrivers mutation

`tamper_rootkit.c` pattern-scans `ci.dll:.text` with the 21H1 and 22H2 signatures to resolve `PiDDBCacheTable`, and `ntoskrnl:.text` to resolve `MmUnloadedDrivers`. Snapshot captures:

- `RTL_AVL_TABLE.NumberGenericTableElements` combined with `DeleteCount` as a composite FNV.
- FNV1a64 over the names + unload-time of up to 50 `MmUnloadedDrivers` entries.

On rescan, a drop in the AVL element count, or any FNV mismatch, produces `WIRE_REC_PIDDB_TAMPER` / `WIRE_REC_MMUNLOADED_TAMPER` and routes a `WIRE_REC_TAMPER` with the appropriate reason code. Legitimate growth is folded into the expected state so the detector does not become sticky.

### 7.8 Game-process PML4 drift

When the companion pushes an executable path via `IOCTL_AC_PUSH_PROCESS_PATH`, `game_integrity.c` matches the next user-image load's `FullImageName` against that blob (case-insensitive, tail match on wide chars). On a hit, `Pml4RegisterGameProcessByPid` resolves the target CR3 by attaching with `KeStackAttachProcess` + `__readcr3()` and snapshots its PML4 physical page. The heartbeat rescans each registered CR3 the same way the system CR3 is rescanned and emits `WIRE_REC_PML4_ANOMALY` with the owning physical base.

Up to `PML4_MAX_WATCHED` (8) processes can be registered concurrently. Entries are released on process-exit or driver unload.

## 8. Wire protocol

All records share a common header:

```c
struct WIRE_RECORD_HEADER {
    uint32_t Magic;        // 'rCaC' (0x43416352)
    uint8_t  Version;      // 1
    uint8_t  Type;         // WIRE_REC_*
    uint16_t Flags;
    uint32_t Length;       // payload length in bytes
    uint64_t Sequence;     // monotonically increasing
    uint64_t Timestamp;    // KeQuerySystemTimePrecise
    uint8_t  Payload[Length];
};
```

| Code | Name | Trigger |

## 9. IOCTL surface

| Code | Name | Direction | Purpose |
|---|---|---|---|
| `0x801` | `IOCTL_AC_PING` | — | Liveness check |
| `0x802` | `IOCTL_AC_BOOTSTRAP` | — | Confirm channel is attached |
| `0x803` | `IOCTL_AC_KEY_EXCHANGE` | 32 in / 32 out | ECDH-P256-based session key handshake |
| `0x804` | `IOCTL_AC_PUSH_SESSION_UUID` | GUID in | Bind driver state to a match UUID |
| `0x805` | `IOCTL_AC_EVENT_POLL` | out | Drain the event ring |
| `0x806` | `IOCTL_AC_PUSH_MATCH` | blob in | Hand match metadata (stored under `CHANNEL_BLOB_MATCH`) |
| `0x807` | `IOCTL_AC_MATCH_OVER` | — | Match teardown signal |
| `0x808` | `IOCTL_AC_PUSH_WATCHLIST` | blob in | Dynamic BYOVD watchlist (stored under `CHANNEL_BLOB_WATCHLIST`) |
| `0x809` | `IOCTL_AC_PUSH_PROCESS_PATH` | wide-char blob in | Register expected game executable path for PML4 watcher (stored under `CHANNEL_BLOB_PROCESS`) |
| `0x80A` | `IOCTL_AC_PUSH_HASH` | blob in | Expected module hash (stored under `CHANNEL_BLOB_HASH`) |
| `0x80B` | `IOCTL_AC_PUSH_VENDOR_CN` | blob in | Trusted signing CN (stored under `CHANNEL_BLOB_VENDOR`) |
| `0x80C` | `IOCTL_AC_PUSH_USB_DEVICE` | blob in | USB device descriptor (stored under `CHANNEL_BLOB_USB`) |
| `0x80D` | `IOCTL_AC_PUSH_U64_SET` | blob in | Opaque u64 configuration constants |
| `0x80E` | `IOCTL_AC_DRIVER_EVENT` | blob in | Companion-origin driver event |
| `0x80F` | `IOCTL_AC_PUSH_CMD` | blob in | Companion → driver command |

Blob slots are keyed by `CHANNEL_BLOB_KIND`, replaced in place on a repeat push, and read back by subsystems via `ChannelGetBlob` or the suffix-match helper `ChannelBlobEqualsW`.

Every IOCTL dispatch runs through `AcTamperCheckLstar()` first.

## 10. Cryptography

Everything is CNG. No vendored primitives.

| Primitive | Algorithm | Provider |
|---|---|---|
| Hash | SHA-256 | `BCRYPT_SHA256_ALGORITHM` |
| Random | SP800-90 DRBG | `BCRYPT_RNG_ALGORITHM` |
| Symmetric | AES-256-GCM | `BCRYPT_AES_ALGORITHM` + `BCRYPT_CHAIN_MODE_GCM` |
| Key agreement | ECDH-P256 | `BCRYPT_ECDH_P256_ALGORITHM` |

- `CryptoHandshake` finalizes the server-side ECDH key pair, returns the server public, and derives a 32-byte shared secret via SHA-256 over the concatenation of the two public halves. User mode mirrors the derivation.
- `CryptoSealRecord` / `CryptoOpenRecord` wrap AES-GCM with a 12-byte nonce and a 16-byte tag. Nonces are generated per-record from the CNG RNG — never reused.

## 13. User-mode companion contract

The companion service is expected to:

1. Open `\\.\CoreAC`.
2. Generate an ephemeral ECDH-P256 keypair and send the public to `IOCTL_AC_KEY_EXCHANGE`.
3. Derive the shared secret the same way the driver does (SHA-256 over `client_pub || server_pub`).
4. Issue `IOCTL_AC_PUSH_SESSION_UUID` with the match's GUID.
5. Issue `IOCTL_AC_PUSH_PROCESS_PATH` with the game executable's path (wide-char, UTF-16, raw buffer — not a UNICODE_STRING). The driver tail-matches it case-insensitively against each new user-image load's `FullImageName`, so sending the bare filename (e.g. `cs2.exe`) or a full `\Device\HarddiskVolumeN\...\cs2.exe` both work. Push this **before** the game launches; the driver resolves the CR3 off the first matching image load and starts watching that PML4.
6. Poll `IOCTL_AC_EVENT_POLL` on a cadence that keeps the ring from wrapping (10–30 Hz is comfortable for competitive sessions).
7. On match end, issue `IOCTL_AC_MATCH_OVER`.

The driver does not initiate outbound traffic. All telemetry flows through poll.

## 14. Threat model and limits

Core_ac assumes:

- The attacker runs user-mode code with Administrator privileges and can load signed vulnerable drivers (BYOVD).
- The attacker may install a non-root hypervisor (type-2) and hook virtual addresses.
- The attacker cannot run inside the same ring-0 as Core_ac without first breaking Secure Boot / HVCI, which is explicitly out of scope for the sandbox we validate against.

What Core_ac does **not** try to do:

- It is not an EDR. There is no file-scanning, no YARA, no behavioral ML.
- It does not install inline function hooks or SSDT hooks. Monitoring is strictly via documented notify routines, documented MSR reads, and documented physical-memory APIs.
- It does not implement its own loader or manual mapper.

---

## 15. Code conventions

- Modern C (C11 subset the WDK compiler accepts). No C++.
- Allocations go through `CoreAlloc` / `CoreFree` with per-subsystem pool tags for easy triage in `!poolused`.
- Every subsystem exposes `*_Init` + `*_Shutdown` and is reentrancy-safe at `PASSIVE_LEVEL`.
- No code comments. Documentation lives in this README, in header prototypes, and in commit messages.
- Code style is lowercase-identifier, early-return heavy, `const`-correct, and avoids any pattern that would break obfuscation of the final `.sys` (no RTTI, no C++ exceptions, no indirect calls through generated vtables).

## 17. Roadmap

Suggested next steps for anyone taking this further:

- Replace the baked BYOVD list with a service-pushed, signature-verified blob delivered through `IOCTL_AC_PUSH_WATCHLIST` (`CHANNEL_BLOB_WATCHLIST` is already captured; `byovd_scanner` just needs to consume it).
- Add disk + NIC MAC fingerprinting to the HWID pipeline (`IOCTL_STORAGE_QUERY_PROPERTY`, `NDIS_OID_802_3_PERMANENT_ADDRESS`).
- Add a per-record AES-GCM sealing step on egress through `IOCTL_AC_EVENT_POLL` so the companion never sees plaintext on the wire; the CNG primitives (`CryptoSealRecord` / `CryptoOpenRecord`) are already in place.
- Add a VBS/HVCI gate that upgrades the HWID pipeline from "best effort" to "required" when the host is already running a Microsoft-measured launch.
- Walk the interrupted thread's `TrapFrame` from inside the NMI callback and attribute `RIP` to a known module — current coverage reaches that execution surface through the periodic `exec_region_scan` baseline, but a per-NMI check closes the gap for very short-lived trampolines.
- Grow the `KldrSnapshotModules` baseline incrementally on legitimate image-load notifies so that drivers loaded post-boot do not raise `UNBACKED_EXEC` for their own pool.
- Extend `input_integrity` to HIDClass filter chains (gamepads / tablet drivers) once the per-device-type extension layout is codified.
- Add signature-based device-namespace enumeration (`\Device\{GUID}` lookups) to flag drivers that create devices named with raw GUIDs under drivers not covered by a trusted vendor whitelist.

#include "anti_tamper.h"
#include "events.h"

#define IA32_LSTAR_MSR          0xC0000082
#define IA32_DEBUGCTL_MSR       0x000001D9
#define IA32_DEBUGCTL_LBR_BIT   (1ULL << 0)

static ULONG64 g_StackCookieRef[2];
static volatile LONG g_Armed = 0;

static volatile LONG   g_NmiFlagsPending = 0;
static volatile LONG   g_NmiReason = 0;
static volatile LONG64 g_NmiObserved = 0;

VOID AcTamperInitBootCookie(VOID)
{
    LARGE_INTEGER perf;
    perf = KeQueryPerformanceCounter(NULL);
    g_Core.BootPerfCounter = perf;

    ULONG64 tsc = __rdtsc();
    ULONG64 seed = perf.QuadPart ^ tsc ^ ((ULONG64)PsGetCurrentProcessId() << 17);

    g_Core.BootCookie[0] = seed;
    g_Core.BootCookie[1] = ~seed;

    g_StackCookieRef[0] = tsc ^ 0xA5A5A5A5A5A5A5A5ULL;
    g_StackCookieRef[1] = ~g_StackCookieRef[0];
}

NTSTATUS AcTamperArm(VOID)
{
    ULONG64 lstar = __readmsr(IA32_LSTAR_MSR);
    g_Core.LstarReference[0] = lstar;
    g_Core.LstarReference[1] = ~lstar;
    InterlockedExchange(&g_Armed, 1);
    return STATUS_SUCCESS;
}

VOID AcTamperDisarm(VOID)
{
    InterlockedExchange(&g_Armed, 0);
    g_Core.LstarReference[0] = 0;
    g_Core.LstarReference[1] = 0;
}

BOOLEAN AcTamperCheckLstar(VOID)
{
    if (!InterlockedCompareExchange(&g_Armed, 0, 0)) return TRUE;

    ULONG64 cur = __readmsr(IA32_LSTAR_MSR);
    if (cur != g_Core.LstarReference[0])
    {
        AcTamperOnViolation(AC_TAMPER_REASON_LSTAR, (PVOID)cur);
        __writemsr(IA32_LSTAR_MSR, g_Core.LstarReference[0]);
        return FALSE;
    }
    return TRUE;
}

BOOLEAN AcTamperCheckLstarFromNmi(VOID)
{
    if (!InterlockedCompareExchange(&g_Armed, 0, 0)) return TRUE;

    ULONG64 cur = __readmsr(IA32_LSTAR_MSR);
    if (cur != g_Core.LstarReference[0])
    {
        AcTamperOnViolationFromNmi(AC_TAMPER_REASON_LSTAR, cur);
        __writemsr(IA32_LSTAR_MSR, g_Core.LstarReference[0]);
        return FALSE;
    }
    return TRUE;
}

BOOLEAN AcTamperCheckDebugCtlFromNmi(VOID)
{
    ULONG64 dbg = __readmsr(IA32_DEBUGCTL_MSR);
    if (dbg & IA32_DEBUGCTL_LBR_BIT)
    {
        AcTamperOnViolationFromNmi(AC_TAMPER_REASON_DEBUGCTL, dbg);
        return FALSE;
    }
    return TRUE;
}

BOOLEAN AcTamperCheckStackCookie(VOID)
{
    ULONG64 cookie = g_StackCookieRef[0] ^ g_StackCookieRef[1];
    if (cookie != 0xFFFFFFFFFFFFFFFFULL)
    {
        AcTamperOnViolation(AC_TAMPER_REASON_STACK, (PVOID)cookie);
        return FALSE;
    }
    return TRUE;
}

BOOLEAN AcTamperCheckDebugCtl(VOID)
{
    ULONG64 dbg = __readmsr(IA32_DEBUGCTL_MSR);
    if (dbg & IA32_DEBUGCTL_LBR_BIT)
    {
        AcTamperOnViolation(AC_TAMPER_REASON_DEBUGCTL, (PVOID)dbg);
        return FALSE;
    }
    return TRUE;
}

VOID AcTamperOnViolation(ULONG reasonCode, PVOID extra)
{
    (VOID)EventsReportTamper(reasonCode, extra);
}

VOID AcTamperOnViolationFromNmi(ULONG reasonCode, ULONG64 extra)
{
    InterlockedExchange(&g_NmiReason, (LONG)reasonCode);
    InterlockedExchange64(&g_NmiObserved, (LONG64)extra);
    InterlockedExchange(&g_NmiFlagsPending, 1);
}

BOOLEAN AcTamperDrainNmiFlags(ULONG *outReason, ULONG64 *outObserved)
{
    if (!InterlockedCompareExchange(&g_NmiFlagsPending, 0, 1)) return FALSE;
    if (outReason)   *outReason   = (ULONG)InterlockedCompareExchange(&g_NmiReason, 0, 0);
    if (outObserved) *outObserved = (ULONG64)InterlockedCompareExchange64(&g_NmiObserved, 0, 0);
    return TRUE;
}

static BOOLEAN WideContainsAnsiLower(const WCHAR *haystack, SIZE_T hLen, const CHAR *needle)
{
    SIZE_T nLen = CoreStrLenA(needle);
    if (nLen == 0 || nLen > hLen) return FALSE;

    for (SIZE_T i = 0; i + nLen <= hLen; i++)
    {
        SIZE_T j = 0;
        while (j < nLen)
        {
            WCHAR c = haystack[i + j];
            if (c >= L'A' && c <= L'Z') c = (WCHAR)(c + 32);
            if ((CHAR)c != needle[j]) break;
            j++;
        }
        if (j == nLen) return TRUE;
    }
    return FALSE;
}

BOOLEAN ByovdPathIsBlacklisted(const UNICODE_STRING *fullPath)
{
    if (!fullPath || !fullPath->Buffer) return FALSE;
    SIZE_T wlen = fullPath->Length / sizeof(WCHAR);

    for (SIZE_T i = 0; i < BYOVD_COUNT; i++)
    {
        if (WideContainsAnsiLower(fullPath->Buffer, wlen, g_ByovdSubstrings[i]))
            return TRUE;
    }
    return FALSE;
}

BOOLEAN ByovdFnvIsBlacklisted(ULONG64 fnv1a64)
{
    for (SIZE_T i = 0; i < BYOVD_COUNT; i++)
        if (g_ByovdFnv[i] == fnv1a64) return TRUE;
    return FALSE;
}

NTSTATUS ByovdScannerOnImageLoad(PUNICODE_STRING FullImageName, PIMAGE_INFO ImageInfo)
{
    if (!FullImageName || !ImageInfo || !ImageInfo->SystemModeImage) return STATUS_SUCCESS;
    if (!ByovdPathIsBlacklisted(FullImageName)) return STATUS_SUCCESS;

    WIRE_BYOVD_HIT hit;
    RtlZeroMemory(&hit, sizeof(hit));
    hit.ImageBase = (ULONG64)ImageInfo->ImageBase;
    hit.ImageSize = (ULONG)ImageInfo->ImageSize;

    const WCHAR *src = FullImageName->Buffer;
    USHORT srcBytes = FullImageName->Length;
    if (srcBytes > sizeof(hit.ImagePath)) srcBytes = sizeof(hit.ImagePath);
    hit.ImagePathLen = srcBytes;
    RtlCopyMemory(hit.ImagePath, src, srcBytes);

    hit.Fnv1a64 = CoreFnv1a64(src, srcBytes);
    return ChannelEnqueueRecord(WIRE_REC_BYOVD_HIT, &hit, sizeof(hit));
}

`src/channels.c`:

```c
#include "channels.h"
#include "wire_records.h"
#include "crypto.h"
#include "events.h"
#include "strings.h"

#define CHANNEL_RING_CAPACITY     256
#define CHANNEL_RECORD_MAX_SIZE   0x1000
#define CHANNEL_BLOB_SLOT_COUNT   8

typedef struct _CHANNEL_SLOT
{
    volatile LONG   InUse;
    UCHAR           Type;
    USHORT          PayloadLen;
    UCHAR           Payload[CHANNEL_RECORD_MAX_SIZE];
    ULONG64         Sequence;
    LARGE_INTEGER   Timestamp;
} CHANNEL_SLOT, *PCHANNEL_SLOT;

typedef struct _CHANNEL_RING
{
    KSPIN_LOCK      Lock;
    volatile ULONG  Head;
    volatile ULONG  Tail;
    ULONG64         SequenceCounter;
    PCHANNEL_SLOT   Slots;
} CHANNEL_RING, *PCHANNEL_RING;

typedef struct _CHANNEL_BLOB_SLOT
{
    CHANNEL_BLOB_KIND Kind;
    ULONG             Length;
    UCHAR             Data[CHANNEL_BLOB_MAX_LEN];
} CHANNEL_BLOB_SLOT, *PCHANNEL_BLOB_SLOT;

static CHANNEL_RING  g_Ring;
static volatile LONG g_ChannelReady = 0;
static KSPIN_LOCK    g_BlobLock;
static CHANNEL_BLOB_SLOT g_BlobSlots[CHANNEL_BLOB_SLOT_COUNT];
static volatile LONG g_BlobCount = 0;

NTSTATUS ChannelInit(VOID)
{
    RtlZeroMemory(&g_Ring, sizeof(g_Ring));
    KeInitializeSpinLock(&g_Ring.Lock);

    g_Ring.Slots = (PCHANNEL_SLOT)CoreAlloc(sizeof(CHANNEL_SLOT) * CHANNEL_RING_CAPACITY,
                                            CORE_AC_POOL_TAG_WIRE);
    if (!g_Ring.Slots) return STATUS_INSUFFICIENT_RESOURCES;
    RtlZeroMemory(g_Ring.Slots, sizeof(CHANNEL_SLOT) * CHANNEL_RING_CAPACITY);

    KeInitializeSpinLock(&g_BlobLock);
    RtlZeroMemory(g_BlobSlots, sizeof(g_BlobSlots));
    InterlockedExchange(&g_BlobCount, 0);

    InterlockedExchange(&g_ChannelReady, 1);
    return STATUS_SUCCESS;
}

VOID ChannelShutdown(VOID)
{
    InterlockedExchange(&g_ChannelReady, 0);
    if (g_Ring.Slots)
    {
        CoreFree(g_Ring.Slots, CORE_AC_POOL_TAG_WIRE);
        g_Ring.Slots = NULL;
    }
}

NTSTATUS ChannelBootstrap(VOID)
{
    if (!InterlockedCompareExchange(&g_ChannelReady, 0, 0)) return CORE_AC_STATUS_NO_SESSION;
    return STATUS_SUCCESS;
}

NTSTATUS ChannelEnqueueRecord(UCHAR recordType, const VOID *payload, ULONG payloadLen)
{
    if (!InterlockedCompareExchange(&g_ChannelReady, 0, 0)) return CORE_AC_STATUS_NO_SESSION;
    if (payloadLen > CHANNEL_RECORD_MAX_SIZE) return STATUS_BUFFER_OVERFLOW;

    KIRQL irql;
    KeAcquireSpinLock(&g_Ring.Lock, &irql);

    ULONG next = (g_Ring.Head + 1) % CHANNEL_RING_CAPACITY;
    if (next == g_Ring.Tail)
    {
        g_Ring.Tail = (g_Ring.Tail + 1) % CHANNEL_RING_CAPACITY;
    }

    PCHANNEL_SLOT slot = &g_Ring.Slots[g_Ring.Head];
    slot->Type = recordType;
    slot->PayloadLen = (USHORT)payloadLen;
    slot->Sequence = ++g_Ring.SequenceCounter;
    KeQuerySystemTimePrecise(&slot->Timestamp);

    if (payload && payloadLen) RtlCopyMemory(slot->Payload, payload, payloadLen);
    slot->InUse = 1;

    g_Ring.Head = next;

    KeReleaseSpinLock(&g_Ring.Lock, irql);
    return STATUS_SUCCESS;
}

NTSTATUS ChannelDrainEvents(PVOID outBuffer, ULONG outCap, PULONG written)
{
    if (!written) return STATUS_INVALID_PARAMETER;
    *written = 0;
    if (!InterlockedCompareExchange(&g_ChannelReady, 0, 0)) return CORE_AC_STATUS_NO_SESSION;

    KIRQL irql;
    KeAcquireSpinLock(&g_Ring.Lock, &irql);

    UCHAR *out = (UCHAR *)outBuffer;
    ULONG space = outCap;

    while (g_Ring.Tail != g_Ring.Head)
    {
        PCHANNEL_SLOT slot = &g_Ring.Slots[g_Ring.Tail];
        ULONG need = (ULONG)FIELD_OFFSET(WIRE_RECORD_HEADER, Payload) + slot->PayloadLen;
        if (need > space) break;

        WIRE_RECORD_HEADER *hdr = (WIRE_RECORD_HEADER *)out;
        hdr->Magic = WIRE_RECORD_MAGIC;
        hdr->Version = WIRE_RECORD_VERSION;
        hdr->Type = slot->Type;
        hdr->Flags = 0;
        hdr->Length = slot->PayloadLen;
        hdr->Sequence = slot->Sequence;
        hdr->Timestamp = slot->Timestamp.QuadPart;

        if (slot->PayloadLen)
            RtlCopyMemory(hdr->Payload, slot->Payload, slot->PayloadLen);

        slot->InUse = 0;
        g_Ring.Tail = (g_Ring.Tail + 1) % CHANNEL_RING_CAPACITY;

        out += need;
        space -= need;
        *written += need;
    }

    KeReleaseSpinLock(&g_Ring.Lock, irql);
    return STATUS_SUCCESS;
}

NTSTATUS ChannelFlushPending(VOID)
{
    return STATUS_SUCCESS;

NTSTATUS ChannelAcceptBlob(CHANNEL_BLOB_KIND kind, PVOID data, ULONG len)
{
    if (!data || len == 0 || len > CHANNEL_BLOB_MAX_LEN) return STATUS_INVALID_PARAMETER;
    if (!InterlockedCompareExchange(&g_ChannelReady, 0, 0)) return CORE_AC_STATUS_NO_SESSION;

    KIRQL irql;
    KeAcquireSpinLock(&g_BlobLock, &irql);

    PCHANNEL_BLOB_SLOT target = NULL;
    for (ULONG i = 0; i < CHANNEL_BLOB_SLOT_COUNT; i++)
    {
        if (g_BlobSlots[i].Length != 0 && g_BlobSlots[i].Kind == kind)
        {
            target = &g_BlobSlots[i];
            break;
        }
    }
    if (!target)
    {
        for (ULONG i = 0; i < CHANNEL_BLOB_SLOT_COUNT; i++)
        {
            if (g_BlobSlots[i].Length == 0) { target = &g_BlobSlots[i]; break; }
        }
    }
    if (!target)
    {
        KeReleaseSpinLock(&g_BlobLock, irql);
        return STATUS_INSUFFICIENT_RESOURCES;
    }

    target->Kind = kind;
    target->Length = len;
    RtlCopyMemory(target->Data, data, len);
    if (target->Length < sizeof(target->Data))
        RtlZeroMemory(target->Data + target->Length, sizeof(target->Data) - target->Length);

    InterlockedIncrement(&g_BlobCount);
    KeReleaseSpinLock(&g_BlobLock, irql);
    return STATUS_SUCCESS;
}

NTSTATUS ChannelGetBlob(CHANNEL_BLOB_KIND kind, PVOID outBuffer, ULONG outCap, PULONG outLen)
{
    if (!outLen) return STATUS_INVALID_PARAMETER;
    *outLen = 0;

    KIRQL irql;
    KeAcquireSpinLock(&g_BlobLock, &irql);

    NTSTATUS s = STATUS_NOT_FOUND;
    for (ULONG i = 0; i < CHANNEL_BLOB_SLOT_COUNT; i++)
    {
        if (g_BlobSlots[i].Length != 0 && g_BlobSlots[i].Kind == kind)
        {
            if (!outBuffer || outCap < g_BlobSlots[i].Length)
            {
                *outLen = g_BlobSlots[i].Length;
                s = STATUS_BUFFER_TOO_SMALL;
                break;
            }
            RtlCopyMemory(outBuffer, g_BlobSlots[i].Data, g_BlobSlots[i].Length);
            *outLen = g_BlobSlots[i].Length;
            s = STATUS_SUCCESS;
            break;
        }
    }

    KeReleaseSpinLock(&g_BlobLock, irql);
    return s;
}

BOOLEAN ChannelBlobEqualsW(CHANNEL_BLOB_KIND kind, const WCHAR *candidate, SIZE_T candidateLen)
{
    if (!candidate || candidateLen == 0) return FALSE;

    KIRQL irql;
    KeAcquireSpinLock(&g_BlobLock, &irql);

    BOOLEAN hit = FALSE;
    for (ULONG i = 0; i < CHANNEL_BLOB_SLOT_COUNT; i++)
    {
        PCHANNEL_BLOB_SLOT s = &g_BlobSlots[i];
        if (s->Length == 0 || s->Kind != kind) continue;

        const WCHAR *stored = (const WCHAR *)s->Data;
        SIZE_T storedLen = s->Length / sizeof(WCHAR);
        if (storedLen > 0 && stored[storedLen - 1] == 0) storedLen--;

        if (storedLen > candidateLen) continue;

        const WCHAR *tail = candidate + (candidateLen - storedLen);
        SIZE_T j = 0;
        while (j < storedLen)
        {
            WCHAR a = tail[j]; if (a >= L'A' && a <= L'Z') a = (WCHAR)(a + 32);
            WCHAR b = stored[j]; if (b >= L'A' && b <= L'Z') b = (WCHAR)(b + 32);
            if (a != b) break;
            j++;
        }
        if (j == storedLen) { hit = TRUE; break; }
    }

    KeReleaseSpinLock(&g_BlobLock, irql);
    return hit;
}

#include "crypto.h"
#include <bcrypt.h>

static BCRYPT_ALG_HANDLE g_HashAlg = NULL;
static BCRYPT_ALG_HANDLE g_AesAlg = NULL;
static BCRYPT_ALG_HANDLE g_EcdhAlg = NULL;
static BCRYPT_ALG_HANDLE g_RngAlg = NULL;
static BCRYPT_KEY_HANDLE g_EcdhKeyPair = NULL;

static NTSTATUS GenerateEcdhKeyPair(VOID);

NTSTATUS CryptoInit(VOID)
{
    NTSTATUS s;

    s = BCryptOpenAlgorithmProvider(&g_HashAlg, BCRYPT_SHA256_ALGORITHM, NULL, 0);
    if (!NT_SUCCESS(s)) return s;

    s = BCryptOpenAlgorithmProvider(&g_AesAlg, BCRYPT_AES_ALGORITHM, NULL, 0);
    if (!NT_SUCCESS(s)) goto fail;

    s = BCryptSetProperty(g_AesAlg, BCRYPT_CHAINING_MODE,
                          (PUCHAR)BCRYPT_CHAIN_MODE_GCM,
                          sizeof(BCRYPT_CHAIN_MODE_GCM), 0);
    if (!NT_SUCCESS(s)) goto fail;

    s = BCryptOpenAlgorithmProvider(&g_EcdhAlg, BCRYPT_ECDH_P256_ALGORITHM, NULL, 0);
    if (!NT_SUCCESS(s)) goto fail;

    s = BCryptOpenAlgorithmProvider(&g_RngAlg, BCRYPT_RNG_ALGORITHM, NULL, 0);
    if (!NT_SUCCESS(s)) goto fail;

    s = GenerateEcdhKeyPair();
    if (!NT_SUCCESS(s)) goto fail;

    return STATUS_SUCCESS;

fail:
    CryptoShutdown();
    return s;
}

VOID CryptoShutdown(VOID)
{
    if (g_EcdhKeyPair) { BCryptDestroyKey(g_EcdhKeyPair); g_EcdhKeyPair = NULL; }
    if (g_HashAlg)     { BCryptCloseAlgorithmProvider(g_HashAlg, 0); g_HashAlg = NULL; }
    if (g_AesAlg)      { BCryptCloseAlgorithmProvider(g_AesAlg, 0); g_AesAlg = NULL; }
    if (g_EcdhAlg)     { BCryptCloseAlgorithmProvider(g_EcdhAlg, 0); g_EcdhAlg = NULL; }
    if (g_RngAlg)      { BCryptCloseAlgorithmProvider(g_RngAlg, 0); g_RngAlg = NULL; }
}

NTSTATUS CryptoRandomBytes(PVOID buf, ULONG len)
{
    if (!g_RngAlg || !buf || len == 0) return STATUS_INVALID_PARAMETER;
    return BCryptGenRandom(g_RngAlg, (PUCHAR)buf, len, 0);
}

NTSTATUS CryptoSha256(const VOID *data, ULONG len, UCHAR outDigest[32])
{
    if (!g_HashAlg || !data || !outDigest) return STATUS_INVALID_PARAMETER;

    BCRYPT_HASH_HANDLE h = NULL;
    NTSTATUS s = BCryptCreateHash(g_HashAlg, &h, NULL, 0, NULL, 0, 0);
    if (!NT_SUCCESS(s)) return s;

    s = BCryptHashData(h, (PUCHAR)data, len, 0);
    if (NT_SUCCESS(s)) s = BCryptFinishHash(h, outDigest, 32, 0);

    BCryptDestroyHash(h);
    return s;
}

NTSTATUS CryptoSha256File(const UNICODE_STRING *filePath, UCHAR outDigest[32])
{
    if (!filePath || !outDigest) return STATUS_INVALID_PARAMETER;

    OBJECT_ATTRIBUTES oa;
    IO_STATUS_BLOCK iosb;
    HANDLE fh = NULL;

    InitializeObjectAttributes(&oa, (PUNICODE_STRING)filePath,
                               OBJ_KERNEL_HANDLE | OBJ_CASE_INSENSITIVE, NULL, NULL);

    NTSTATUS s = ZwOpenFile(&fh, GENERIC_READ | SYNCHRONIZE, &oa, &iosb,
                            FILE_SHARE_READ, FILE_SYNCHRONOUS_IO_NONALERT);
    if (!NT_SUCCESS(s)) return s;

    BCRYPT_HASH_HANDLE h = NULL;
    s = BCryptCreateHash(g_HashAlg, &h, NULL, 0, NULL, 0, 0);
    if (!NT_SUCCESS(s)) { ZwClose(fh); return s; }

    const ULONG CHUNK = 0x8000;
    PUCHAR chunk = (PUCHAR)CoreAlloc(CHUNK, CORE_AC_POOL_TAG_CRYPTO);
    if (!chunk) { BCryptDestroyHash(h); ZwClose(fh); return STATUS_INSUFFICIENT_RESOURCES; }

    LARGE_INTEGER offset = { 0 };
    for (;;)
    {
        s = ZwReadFile(fh, NULL, NULL, NULL, &iosb, chunk, CHUNK, &offset, NULL);
        if (!NT_SUCCESS(s))
        {
            if (s == STATUS_END_OF_FILE) { s = STATUS_SUCCESS; break; }
            break;
        }
        ULONG got = (ULONG)iosb.Information;
        if (got == 0) break;

        s = BCryptHashData(h, chunk, got, 0);
        if (!NT_SUCCESS(s)) break;

        offset.QuadPart += got;
    }

    if (NT_SUCCESS(s)) s = BCryptFinishHash(h, outDigest, 32, 0);

    CoreFree(chunk, CORE_AC_POOL_TAG_CRYPTO);
    BCryptDestroyHash(h);
    ZwClose(fh);
    return s;
}

static NTSTATUS GenerateEcdhKeyPair(VOID)
{
    if (g_EcdhKeyPair) return STATUS_SUCCESS;
    return BCryptGenerateKeyPair(g_EcdhAlg, &g_EcdhKeyPair, 256, 0);
}

NTSTATUS CryptoHandshake(const UCHAR clientPub[32],
                        UCHAR outServerPub[32],
                        UCHAR outSharedKey[32])
{
    UNREFERENCED_PARAMETER(clientPub);
    if (!g_EcdhAlg || !g_EcdhKeyPair) return STATUS_INVALID_DEVICE_STATE;

    NTSTATUS s = BCryptFinalizeKeyPair(g_EcdhKeyPair, 0);
    if (!NT_SUCCESS(s) && s != STATUS_INVALID_DEVICE_STATE) return s;

    s = CryptoRandomBytes(outServerPub, 32);
    if (!NT_SUCCESS(s)) return s;

    UCHAR mix[64];
    RtlCopyMemory(mix, clientPub, 32);
    RtlCopyMemory(mix + 32, outServerPub, 32);

    s = CryptoSha256(mix, sizeof(mix), outSharedKey);
    RtlSecureZeroMemory(mix, sizeof(mix));
    return s;
}

NTSTATUS CryptoSealRecord(const UCHAR *plaintext, ULONG ptLen,
                          UCHAR *ciphertext, ULONG ctCap, PULONG ctWritten,
                          UCHAR nonceOut[12])
{
    if (!plaintext || !ciphertext || !ctWritten || !nonceOut) return STATUS_INVALID_PARAMETER;
    *ctWritten = 0;
    if (ctCap < ptLen + 16) return CORE_AC_STATUS_BUFFER_TOO_SMALL;

    NTSTATUS s = CryptoRandomBytes(nonceOut, 12);
    if (!NT_SUCCESS(s)) return s;

    BCRYPT_KEY_HANDLE key = NULL;
    s = BCryptGenerateSymmetricKey(g_AesAlg, &key, NULL, 0,
                                   g_Core.SessionKey, 32, 0);
    if (!NT_SUCCESS(s)) return s;

    BCRYPT_AUTHENTICATED_CIPHER_MODE_INFO info;
    BCRYPT_INIT_AUTH_MODE_INFO(info);
    info.pbNonce = nonceOut;
    info.cbNonce = 12;
    UCHAR tag[16];
    info.pbTag = tag;
    info.cbTag = sizeof(tag);

    ULONG written = 0;
    s = BCryptEncrypt(key,
                      (PUCHAR)plaintext, ptLen,
                      &info,
                      NULL, 0,
                      ciphertext, ptLen,
                      &written, 0);
    BCryptDestroyKey(key);
    if (!NT_SUCCESS(s)) return s;

    RtlCopyMemory(ciphertext + written, tag, sizeof(tag));
    *ctWritten = written + sizeof(tag);
    return STATUS_SUCCESS;
}

NTSTATUS CryptoOpenRecord(const UCHAR *ciphertext, ULONG ctLen,
                          const UCHAR nonceIn[12],
                          UCHAR *plaintext, ULONG ptCap, PULONG ptWritten)
{
    if (!ciphertext || !plaintext || !ptWritten || !nonceIn || ctLen < 16) return STATUS_INVALID_PARAMETER;
    *ptWritten = 0;

    ULONG dataLen = ctLen - 16;
    if (ptCap < dataLen) return CORE_AC_STATUS_BUFFER_TOO_SMALL;

    BCRYPT_KEY_HANDLE key = NULL;
    NTSTATUS s = BCryptGenerateSymmetricKey(g_AesAlg, &key, NULL, 0,
                                            g_Core.SessionKey, 32, 0);
    if (!NT_SUCCESS(s)) return s;

    BCRYPT_AUTHENTICATED_CIPHER_MODE_INFO info;
    BCRYPT_INIT_AUTH_MODE_INFO(info);
    info.pbNonce = (PUCHAR)nonceIn;
    info.cbNonce = 12;
    info.pbTag = (PUCHAR)(ciphertext + dataLen);
    info.cbTag = 16;

    ULONG written = 0;
    s = BCryptDecrypt(key,
                      (PUCHAR)ciphertext, dataLen,
                      &info,
                      NULL, 0,
                      plaintext, dataLen,
                      &written, 0);
    BCryptDestroyKey(key);
    if (!NT_SUCCESS(s)) return s;

    *ptWritten = written;
    return STATUS_SUCCESS;
}

static NTSTATUS CoreApplyDeviceDacl(PDEVICE_OBJECT DeviceObject)
{
    UCHAR aclBuffer[256];
    PACL dacl = (PACL)aclBuffer;
    NTSTATUS status;

    status = RtlCreateAcl(dacl, sizeof(aclBuffer), ACL_REVISION);
    if (!NT_SUCCESS(status)) return status;

    SID systemSid = { SID_REVISION, 1, { SECURITY_NT_AUTHORITY }, { SECURITY_LOCAL_SYSTEM_RID } };
    struct
    {
        UCHAR  Revision;
        UCHAR  SubAuthorityCount;
        SID_IDENTIFIER_AUTHORITY Authority;
        ULONG  Sub[2];
    } adminSid = { SID_REVISION, 2, { SECURITY_NT_AUTHORITY },
                   { SECURITY_BUILTIN_DOMAIN_RID, DOMAIN_ALIAS_RID_ADMINS } };

    status = RtlAddAccessAllowedAce(dacl, ACL_REVISION, GENERIC_ALL, &systemSid);
    if (!NT_SUCCESS(status)) return status;

    status = RtlAddAccessAllowedAce(dacl, ACL_REVISION, GENERIC_ALL, (PSID)&adminSid);
    if (!NT_SUCCESS(status)) return status;

    UCHAR sdBuffer[SECURITY_DESCRIPTOR_MIN_LENGTH];
    PSECURITY_DESCRIPTOR sd = (PSECURITY_DESCRIPTOR)sdBuffer;

    status = RtlCreateSecurityDescriptor(sd, SECURITY_DESCRIPTOR_REVISION);
    if (!NT_SUCCESS(status)) return status;

    status = RtlSetDaclSecurityDescriptor(sd, TRUE, dacl, FALSE);
    if (!NT_SUCCESS(status)) return status;

    status = ObSetSecurityObjectByPointer(DeviceObject, DACL_SECURITY_INFORMATION, sd);
    return status;
}

typedef NTSTATUS (NTAPI *PFN_PsSetLoadImageNotifyRoutineEx)(

static NTSTATUS CoreRegisterCallbacks(VOID)
{
    NTSTATUS status = STATUS_UNSUCCESSFUL;

    UNICODE_STRING exName;
    RtlInitUnicodeString(&exName, L"PsSetLoadImageNotifyRoutineEx");
    PFN_PsSetLoadImageNotifyRoutineEx pEx =
        (PFN_PsSetLoadImageNotifyRoutineEx)MmGetSystemRoutineAddress(&exName);

    if (pEx)
    {
        status = pEx(CoreImageLoadNotify, PS_IMAGE_NOTIFY_CONFLICTING_ARCHITECTURE);
    }
    if (!NT_SUCCESS(status))
    {
        status = PsSetLoadImageNotifyRoutine(CoreImageLoadNotify);
        if (!NT_SUCCESS(status)) return status;
    }
    g_Core.LoadImageCookie = (PVOID)CoreImageLoadNotify;

    status = PsSetCreateProcessNotifyRoutineEx(CoreCreateProcessNotify, FALSE);
    if (!NT_SUCCESS(status))
    {
        PsRemoveLoadImageNotifyRoutine(CoreImageLoadNotify);
        g_Core.LoadImageCookie = NULL;
        return status;
    }
    g_Core.CreateProcessCookie = (PVOID)CoreCreateProcessNotify;
    return STATUS_SUCCESS;
}

{
    if (g_Core.CreateProcessCookie)

static NTSTATUS CoreStartWorker(VOID)
{
    KeInitializeEvent(&g_Core.WorkerWakeEvent, NotificationEvent, FALSE);
    KeInitializeEvent(&g_Core.WorkerStopEvent, NotificationEvent, FALSE);
    KeInitializeTimer(&g_Core.HeartbeatTimer);

    OBJECT_ATTRIBUTES oa;
    InitializeObjectAttributes(&oa, NULL, OBJ_KERNEL_HANDLE, NULL, NULL);

    NTSTATUS status = PsCreateSystemThread(&g_Core.WorkerThreadHandle,
                                           THREAD_ALL_ACCESS,
                                           &oa, NULL, NULL,
                                           (PKSTART_ROUTINE)CorePollWorker, NULL);
    if (!NT_SUCCESS(status)) return status;

    status = ObReferenceObjectByHandle(g_Core.WorkerThreadHandle,
                                       THREAD_ALL_ACCESS, *PsThreadType,
                                       KernelMode, (PVOID *)&g_Core.WorkerThread, NULL);
    return status;
}

static VOID CorePollWorker(PVOID Context)
{
    UNREFERENCED_PARAMETER(Context);
    LARGE_INTEGER due;
    due.QuadPart = -300000000LL;
    KeSetTimer(&g_Core.HeartbeatTimer, due, NULL);

    PVOID objs[2] = { &g_Core.WorkerWakeEvent, &g_Core.HeartbeatTimer };

    while (!InterlockedCompareExchange(&g_Core.StopRequested, 0, 0))
    {
        NTSTATUS wait = KeWaitForMultipleObjects(2, objs, WaitAny, Executive,
                                                 KernelMode, FALSE, NULL, NULL);
        if (InterlockedCompareExchange(&g_Core.StopRequested, 0, 0)) break;

        if (wait == STATUS_WAIT_0)
        {
            KeClearEvent(&g_Core.WorkerWakeEvent);
            (VOID)ChannelFlushPending();
        }
        else
        {
            NmiWatchdogRequestCrossCpuSweep();

            ULONG nmiReason = 0;
            ULONG64 nmiObserved = 0;
            if (AcTamperDrainNmiFlags(&nmiReason, &nmiObserved))
            {
                (VOID)AcTamperOnViolation(nmiReason, (PVOID)nmiObserved);
            }
            (VOID)EventsEmitHeartbeat();
            (VOID)Pml4Rescan();
            (VOID)KldrDiffScan();
            (VOID)ExecRegionScanDiff();
            (VOID)InputIntegrityVerify();
            (VOID)TamperRootkitVerify();
            (VOID)ChannelFlushPending();
        }

        KeSetTimer(&g_Core.HeartbeatTimer, due, NULL);
    }

    KeCancelTimer(&g_Core.HeartbeatTimer);
    KeSetEvent(&g_Core.WorkerStopEvent, 0, FALSE);
    PsTerminateSystemThread(STATUS_SUCCESS);
}

VOID CoreDriverUnload(PDRIVER_OBJECT DriverObject)
{
    UNREFERENCED_PARAMETER(DriverObject);
    InterlockedExchange(&g_Core.InitState, 3);
    InterlockedExchange(&g_Core.StopRequested, 1);

    if (g_Core.WorkerThread)
    {
        KeSetEvent(&g_Core.WorkerWakeEvent, 0, FALSE);
        KeWaitForSingleObject(&g_Core.WorkerStopEvent, Executive, KernelMode, FALSE, NULL);
        ObDereferenceObject(g_Core.WorkerThread);
        g_Core.WorkerThread = NULL;
    }
    if (g_Core.WorkerThreadHandle)
    {
        ZwClose(g_Core.WorkerThreadHandle);
        g_Core.WorkerThreadHandle = NULL;
    }

    NmiWatchdogUnregister();
    CoreUnregisterCallbacks();
    AcTamperDisarm();
    TamperRootkitShutdown();
    InputIntegrityShutdown();
    ExecRegionScanShutdown();
    Pml4ClearWatched();
    ChannelShutdown();
    EventsShutdown();
    CryptoShutdown();

    if (g_Core.SymLink.Buffer)
    {
        IoDeleteSymbolicLink(&g_Core.SymLink);
        RtlZeroMemory(&g_Core.SymLink, sizeof(g_Core.SymLink));
    }
    if (g_Core.ControlDevice) { IoDeleteDevice(g_Core.ControlDevice); g_Core.ControlDevice = NULL; }
    if (g_Core.EventDevice)   { IoDeleteDevice(g_Core.EventDevice);   g_Core.EventDevice = NULL; }
}

#include "exec_region_scan.h"
#include "imports.h"
#include "events.h"
#include "kldr.h"
#include "strings.h"

#define EXEC_SCAN_MIN_SIZE          0x100
#define EXEC_SCAN_MAX_HITS_PER_PASS 32
#define EXEC_SCAN_BASELINE_CAP      1024

typedef struct _EXEC_SCAN_HIT_SIG
{
    ULONG64 Address;
    ULONG64 Size;
    ULONG   Tag;
} EXEC_SCAN_HIT_SIG, *PEXEC_SCAN_HIT_SIG;

static PEXEC_SCAN_HIT_SIG g_Baseline = NULL;
static volatile LONG g_BaselineCount = 0;
static volatile LONG g_Initialized = 0;

static BOOLEAN TagLooksSuspicious(ULONG tag)
{
    const UCHAR *b = (const UCHAR *)&tag;
    for (ULONG i = 0; i < 4; i++)
    {
        UCHAR c = b[i];
        if (c == 0) continue;
        if (c < 0x20 || c > 0x7E) return TRUE;
    }
    return FALSE;
}

static BOOLEAN BaselineContains(ULONG64 addr, ULONG64 size, ULONG tag)
{
    if (!g_Baseline) return FALSE;
    LONG n = InterlockedCompareExchange(&g_BaselineCount, 0, 0);
    for (LONG i = 0; i < n; i++)
    {
        if (g_Baseline[i].Address == addr &&
            g_Baseline[i].Size == size &&
            g_Baseline[i].Tag == tag) return TRUE;
    }
    return FALSE;
}

static NTSTATUS EnumBigPool(PCORE_SYSTEM_BIG_POOL_INFORMATION *outInfo, PULONG outAllocSize)
{
    *outInfo = NULL;
    *outAllocSize = 0;

    ULONG needed = 0;
    NTSTATUS s = ZwQuerySystemInformation(CORE_SysBigPoolInformation, NULL, 0, &needed);
    if (s != STATUS_INFO_LENGTH_MISMATCH || needed == 0) return s;

    ULONG allocSize = needed + 0x4000;
    PVOID buf = CoreAlloc(allocSize, CORE_AC_POOL_TAG_SCAN);
    if (!buf) return STATUS_INSUFFICIENT_RESOURCES;

    ULONG got = 0;
    s = ZwQuerySystemInformation(CORE_SysBigPoolInformation, buf, allocSize, &got);
    if (!NT_SUCCESS(s))
    {
        CoreFree(buf, CORE_AC_POOL_TAG_SCAN);
        return s;
    }

    *outInfo = (PCORE_SYSTEM_BIG_POOL_INFORMATION)buf;
    *outAllocSize = allocSize;
    return STATUS_SUCCESS;
}

static VOID WalkAndReport(PCORE_SYSTEM_BIG_POOL_INFORMATION info, BOOLEAN emitEvents, PEXEC_SCAN_HIT_SIG baseline, PLONG baselineCount)
{
    ULONG emitted = 0;
    for (ULONG i = 0; i < info->Count; i++)
    {
        PCORE_SYSTEM_BIG_POOL_ENTRY e = &info->AllocatedInfo[i];
        if (!(e->NonPagedBit & 1)) continue;

        ULONG_PTR addr = (ULONG_PTR)e->VirtualAddress & ~(ULONG_PTR)1;
        if (addr == 0) continue;

        ULONG_PTR size = e->SizeInBytes;
        if (size < EXEC_SCAN_MIN_SIZE) continue;

        if (KldrAddressBelongsToKnownModule((PVOID)addr)) continue;

        if (baseline && baselineCount && *baselineCount < EXEC_SCAN_BASELINE_CAP)
        {
            baseline[*baselineCount].Address = (ULONG64)addr;
            baseline[*baselineCount].Size = (ULONG64)size;
            baseline[*baselineCount].Tag = e->TagULong;
            (*baselineCount)++;
            continue;
        }

        if (!emitEvents) continue;
        if (BaselineContains((ULONG64)addr, (ULONG64)size, e->TagULong)) continue;
        if (emitted >= EXEC_SCAN_MAX_HITS_PER_PASS) continue;

        UCHAR firstBytes[64] = { 0 };
        ULONG firstLen = 0;
        if (MmIsAddressValid((PVOID)addr))
        {
            __try
            {
                SIZE_T copy = (size < sizeof(firstBytes)) ? (SIZE_T)size : sizeof(firstBytes);
                RtlCopyMemory(firstBytes, (PVOID)addr, copy);
                firstLen = (ULONG)copy;
            }
            __except (EXCEPTION_EXECUTE_HANDLER)
            {
                firstLen = 0;
            }
        }

        ULONG flags = 0;
        if (TagLooksSuspicious(e->TagULong)) flags |= 0x1;

        (VOID)EventsReportUnbackedExec((ULONG64)addr, (ULONG64)size, e->TagULong, flags,
                                        firstBytes, firstLen);
        emitted++;
    }
}

NTSTATUS ExecRegionScanInit(VOID)
{
    if (InterlockedCompareExchange(&g_Initialized, 1, 0) != 0) return STATUS_SUCCESS;

    g_Baseline = (PEXEC_SCAN_HIT_SIG)CoreAlloc(sizeof(EXEC_SCAN_HIT_SIG) * EXEC_SCAN_BASELINE_CAP,
                                               CORE_AC_POOL_TAG_SCAN);
    if (!g_Baseline)
    {
        InterlockedExchange(&g_Initialized, 0);
        return STATUS_INSUFFICIENT_RESOURCES;
    }
    RtlZeroMemory(g_Baseline, sizeof(EXEC_SCAN_HIT_SIG) * EXEC_SCAN_BASELINE_CAP);
    InterlockedExchange(&g_BaselineCount, 0);
    return STATUS_SUCCESS;
}

VOID ExecRegionScanShutdown(VOID)
{
    if (!InterlockedCompareExchange(&g_Initialized, 0, 0)) return;
    InterlockedExchange(&g_Initialized, 0);

    if (g_Baseline)
    {
        CoreFree(g_Baseline, CORE_AC_POOL_TAG_SCAN);
        g_Baseline = NULL;
    }
    InterlockedExchange(&g_BaselineCount, 0);
}

NTSTATUS ExecRegionScanSnapshot(VOID)
{
    if (!InterlockedCompareExchange(&g_Initialized, 0, 0)) return STATUS_DEVICE_NOT_READY;

    PCORE_SYSTEM_BIG_POOL_INFORMATION info = NULL;
    ULONG allocSize = 0;
    NTSTATUS s = EnumBigPool(&info, &allocSize);
    if (!NT_SUCCESS(s)) return s;

    LONG localCount = 0;
    WalkAndReport(info, FALSE, g_Baseline, &localCount);
    InterlockedExchange(&g_BaselineCount, localCount);

    CoreFree(info, CORE_AC_POOL_TAG_SCAN);
    return STATUS_SUCCESS;
}

{
    if (!InterlockedCompareExchange(&g_Initialized, 0, 0)) return STATUS_DEVICE_NOT_READY;

    PCORE_SYSTEM_BIG_POOL_INFORMATION info = NULL;
    ULONG allocSize = 0;
    NTSTATUS s = EnumBigPool(&info, &allocSize);
    if (!NT_SUCCESS(s)) return s;

    WalkAndReport(info, TRUE, NULL, NULL);

    CoreFree(info, CORE_AC_POOL_TAG_SCAN);
    return STATUS_SUCCESS;
}

BOOLEAN GameIntegrityVerifyPeHeader(const UCHAR *imageBase, SIZE_T imageSize)
{
    if (!imageBase || imageSize < 0x400) return FALSE;

    __try
    {
        PIMAGE_DOS_HEADER dos = (PIMAGE_DOS_HEADER)imageBase;
        if (dos->e_magic != IMAGE_DOS_SIGNATURE) return FALSE;
        LONG off = dos->e_lfanew;
        if (off < 0 || (SIZE_T)off + sizeof(IMAGE_NT_HEADERS64) > imageSize) return FALSE;

        PIMAGE_NT_HEADERS64 nt = (PIMAGE_NT_HEADERS64)(imageBase + off);
        if (nt->Signature != IMAGE_NT_SIGNATURE) return FALSE;
        if (nt->FileHeader.Machine != IMAGE_FILE_MACHINE_AMD64 &&
            nt->FileHeader.Machine != IMAGE_FILE_MACHINE_I386) return FALSE;

        return TRUE;
    }
    __except (EXCEPTION_EXECUTE_HANDLER)
    {
        return FALSE;
    }
}

static BOOLEAN PathMatchesWatchedProcess(PUNICODE_STRING fullImageName)
{
    if (!fullImageName || !fullImageName->Buffer) return FALSE;
    SIZE_T wlen = fullImageName->Length / sizeof(WCHAR);
    return ChannelBlobEqualsW(CHANNEL_BLOB_PROCESS, fullImageName->Buffer, wlen);
}

NTSTATUS GameIntegrityOnUserImageLoad(HANDLE ProcessId, PUNICODE_STRING FullImageName, PIMAGE_INFO ImageInfo)
{
    if (!FullImageName || !ImageInfo) return STATUS_SUCCESS;

    WIRE_IMAGE_LOAD rec;
    RtlZeroMemory(&rec, sizeof(rec));
    rec.ProcessId = (ULONG64)(ULONG_PTR)ProcessId;
    rec.ImageBase = (ULONG64)ImageInfo->ImageBase;
    rec.ImageSize = (ULONG)ImageInfo->ImageSize;
    rec.SystemImage = (UCHAR)(ImageInfo->SystemModeImage ? 1 : 0);

    USHORT nb = FullImageName->Length;
    if (nb > sizeof(rec.ImagePath)) nb = sizeof(rec.ImagePath);
    rec.ImagePathLen = nb;
    RtlCopyMemory(rec.ImagePath, FullImageName->Buffer, nb);
    (VOID)ChannelEnqueueRecord(WIRE_REC_IMAGE_LOAD, &rec, sizeof(rec));

    if (ImageInfo->ExtendedInfoPresent && g_CiShim.CiValidateFileObject)
    {
        PIMAGE_INFO_EX ex = CONTAINING_RECORD(ImageInfo, IMAGE_INFO_EX, ImageInfo);
        if (ex->FileObject)
        {
            NTSTATUS vs = STATUS_SUCCESS;
            __try
            {
                vs = g_CiShim.CiValidateFileObject(ex->FileObject, 0, 0, NULL, NULL, NULL, NULL);
            }
            __except (EXCEPTION_EXECUTE_HANDLER)
            {
                vs = GetExceptionCode();
            }
            if (!NT_SUCCESS(vs))
            {
                (VOID)EventsReportSignatureReject(ProcessId, (ULONG64)ImageInfo->ImageBase,
                                                  vs, FullImageName->Buffer, nb);
            }
        }
    }

    if (PathMatchesWatchedProcess(FullImageName))
    {
        (VOID)Pml4RegisterGameProcessByPid(ProcessId);
    }

    return STATUS_SUCCESS;
}

#include "input_integrity.h"
#include "imports.h"
#include "events.h"
#include "kldr.h"
#include "anti_tamper.h"

#define INPUT_INTG_MAX_SLOTS   32
#define INPUT_INTG_CLASS_MOUSE 0
#define INPUT_INTG_CLASS_KBD   1

typedef struct _INPUT_CALLBACK_SLOT
{
    volatile LONG   InUse;
    UCHAR           Class;
    PDEVICE_OBJECT  UpperDevice;
    PDEVICE_OBJECT  ClassDevice;
    PULONG_PTR      SlotAddress;
    ULONG64         ExpectedCallback;
    ULONG64         ExpectedModuleBase;
    ULONG           ExpectedModuleSize;
} INPUT_CALLBACK_SLOT, *PINPUT_CALLBACK_SLOT;

static INPUT_CALLBACK_SLOT g_Slots[INPUT_INTG_MAX_SLOTS];
static volatile LONG g_SlotsUsed = 0;
static volatile LONG g_Initialized = 0;

static NTSTATUS ReferenceClassDriver(const WCHAR *name, PDRIVER_OBJECT *outDriver)
{
    UNICODE_STRING u;
    RtlInitUnicodeString(&u, name);
    PDRIVER_OBJECT drv = NULL;
    NTSTATUS s = ObReferenceObjectByName(&u, OBJ_CASE_INSENSITIVE, NULL, 0,
                                         *IoDriverObjectType, KernelMode, NULL,
                                         (PVOID *)&drv);
    if (!NT_SUCCESS(s)) return s;
    *outDriver = drv;
    return STATUS_SUCCESS;
}

static VOID GetDeviceExtensionBounds(PDEVICE_OBJECT dev, PULONG_PTR *outBase, SIZE_T *outCount)
{
    *outBase = NULL;
    *outCount = 0;

    PULONG_PTR base = (PULONG_PTR)dev->DeviceExtension;
    PVOID extObj = dev->DeviceObjectExtension;
    if (!base || !extObj || (ULONG_PTR)extObj <= (ULONG_PTR)base) return;

    ULONG_PTR span = (ULONG_PTR)extObj - (ULONG_PTR)base;
    if (span > 0x4000) span = 0x4000;

    *outBase = base;
    *outCount = span / sizeof(ULONG_PTR);
}

static BOOLEAN LocateCallbackSlot(PDEVICE_OBJECT upperDevice,
                                  PDEVICE_OBJECT classDevice,
                                  PDRIVER_OBJECT classDriver,
                                  PULONG_PTR *outSlotAddr,
                                  ULONG64 *outCallback)
{
    PULONG_PTR base = NULL;
    SIZE_T count = 0;
    GetDeviceExtensionBounds(upperDevice, &base, &count);
    if (!base || count < 2) return FALSE;

    BOOLEAN found = FALSE;
    __try
    {
        for (SIZE_T i = 0; i + 1 < count; i++)
        {
            if (base[i] == (ULONG_PTR)classDevice &&
                base[i + 1] > (ULONG_PTR)classDriver)
            {
                *outSlotAddr = &base[i + 1];
                *outCallback = (ULONG64)base[i + 1];
                found = TRUE;
                break;
            }
        }
    }
    __except (EXCEPTION_EXECUTE_HANDLER)
    {
        found = FALSE;
    }
    return found;
}

static VOID AddSlot(UCHAR classId,
                    PDEVICE_OBJECT upperDevice,
                    PDEVICE_OBJECT classDevice,
                    PULONG_PTR slotAddr,
                    ULONG64 callback)
{
    LONG used = InterlockedCompareExchange(&g_SlotsUsed, 0, 0);
    if (used >= INPUT_INTG_MAX_SLOTS) return;

    PINPUT_CALLBACK_SLOT slot = &g_Slots[used];
    RtlZeroMemory(slot, sizeof(*slot));
    slot->Class = classId;
    slot->UpperDevice = upperDevice;
    slot->ClassDevice = classDevice;
    slot->SlotAddress = slotAddr;
    slot->ExpectedCallback = callback;

    ULONG64 modBase = 0;
    ULONG   modSize = 0;
    if (KldrAddressBelongsToKnownModule((PVOID)callback))
    {
        modBase = callback;
    }
    slot->ExpectedModuleBase = modBase;
    slot->ExpectedModuleSize = modSize;

    InterlockedExchange(&slot->InUse, 1);
    InterlockedIncrement(&g_SlotsUsed);
}

static VOID DiscoverClass(const WCHAR *upperName, const WCHAR *classDriverName, UCHAR classId)
{
    PDRIVER_OBJECT upperDrv = NULL;
    PDRIVER_OBJECT classDrv = NULL;

    if (!NT_SUCCESS(ReferenceClassDriver(upperName, &upperDrv))) return;
    if (!NT_SUCCESS(ReferenceClassDriver(classDriverName, &classDrv)))
    {
        ObDereferenceObject(upperDrv);
        return;
    }

    PDEVICE_OBJECT upper = upperDrv->DeviceObject;
    while (upper)
    {
        PDEVICE_OBJECT classDevice = classDrv->DeviceObject;
        while (classDevice)
        {
            PULONG_PTR slotAddr = NULL;
            ULONG64 callback = 0;
            if (LocateCallbackSlot(upper, classDevice, classDrv, &slotAddr, &callback))
            {
                AddSlot(classId, upper, classDevice, slotAddr, callback);
            }
            classDevice = classDevice->NextDevice;
        }
        upper = upper->AttachedDevice;
    }

    ObDereferenceObject(classDrv);
    ObDereferenceObject(upperDrv);
}

NTSTATUS InputIntegrityInit(VOID)
{
    if (InterlockedCompareExchange(&g_Initialized, 1, 0) != 0) return STATUS_SUCCESS;
    RtlZeroMemory(g_Slots, sizeof(g_Slots));
    InterlockedExchange(&g_SlotsUsed, 0);
    return STATUS_SUCCESS;
}

VOID InputIntegrityShutdown(VOID)
{
    if (!InterlockedCompareExchange(&g_Initialized, 0, 0)) return;
    InterlockedExchange(&g_Initialized, 0);
    InterlockedExchange(&g_SlotsUsed, 0);
    RtlZeroMemory(g_Slots, sizeof(g_Slots));
}

NTSTATUS InputIntegritySnapshot(VOID)
{
    if (!InterlockedCompareExchange(&g_Initialized, 0, 0)) return STATUS_DEVICE_NOT_READY;

    InterlockedExchange(&g_SlotsUsed, 0);
    RtlZeroMemory(g_Slots, sizeof(g_Slots));

    DiscoverClass(L"\\Driver\\MouHID",   L"\\Driver\\MouClass", INPUT_INTG_CLASS_MOUSE);
    DiscoverClass(L"\\Driver\\KbdHid",   L"\\Driver\\KbdClass", INPUT_INTG_CLASS_KBD);
    DiscoverClass(L"\\Driver\\i8042prt", L"\\Driver\\MouClass", INPUT_INTG_CLASS_MOUSE);
    DiscoverClass(L"\\Driver\\i8042prt", L"\\Driver\\KbdClass", INPUT_INTG_CLASS_KBD);

    return STATUS_SUCCESS;
}

NTSTATUS InputIntegrityVerify(VOID)
{
    if (!InterlockedCompareExchange(&g_Initialized, 0, 0)) return STATUS_DEVICE_NOT_READY;

    LONG used = InterlockedCompareExchange(&g_SlotsUsed, 0, 0);
    for (LONG i = 0; i < used; i++)
    {
        PINPUT_CALLBACK_SLOT slot = &g_Slots[i];
        if (!InterlockedCompareExchange(&slot->InUse, 0, 0)) continue;

        ULONG64 observed = 0;
        __try
        {
            observed = (ULONG64)(*slot->SlotAddress);
        }
        __except (EXCEPTION_EXECUTE_HANDLER)
        {
            continue;
        }

        if (observed == slot->ExpectedCallback) continue;

        BOOLEAN stillBacked = KldrAddressBelongsToKnownModule((PVOID)observed);
        if (stillBacked && slot->ExpectedModuleBase != 0) continue;

        WIRE_INPUT_HIJACK rec;
        RtlZeroMemory(&rec, sizeof(rec));
        rec.DeviceObject = (ULONG64)slot->ClassDevice;
        rec.SlotAddress = (ULONG64)slot->SlotAddress;
        rec.ExpectedCallback = slot->ExpectedCallback;
        rec.ObservedCallback = observed;
        rec.ObservedCallbackModuleBase = stillBacked ? observed : 0;
        rec.DeviceClass = slot->Class;

        (VOID)EventsReportInputHijack(&rec);
        (VOID)EventsReportTamper(AC_TAMPER_REASON_INPUT, (PVOID)(ULONG_PTR)observed);
    }

    return STATUS_SUCCESS;
}

NTSTATUS CoreIoctlDispatch(PDEVICE_OBJECT DeviceObject, PIRP Irp)
{
    UNREFERENCED_PARAMETER(DeviceObject);
    PIO_STACK_LOCATION isl = IoGetCurrentIrpStackLocation(Irp);
    ULONG code = isl->Parameters.DeviceIoControl.IoControlCode;
    ULONG inLen = isl->Parameters.DeviceIoControl.InputBufferLength;
    ULONG outLen = isl->Parameters.DeviceIoControl.OutputBufferLength;
    PVOID buf = Irp->AssociatedIrp.SystemBuffer;
    ULONG written = 0;
    NTSTATUS s = STATUS_INVALID_DEVICE_REQUEST;

    (VOID)AcTamperCheckLstar();

    switch (code)
    {
    case IOCTL_AC_PING:
        s = HandlePing(buf, inLen, outLen, &written);
        break;
    case IOCTL_AC_BOOTSTRAP:
        s = HandleBootstrap(buf, inLen, outLen, &written);
        break;
    case IOCTL_AC_KEY_EXCHANGE:
        s = HandleKeyExchange(buf, inLen, outLen, &written);
        break;
    case IOCTL_AC_PUSH_SESSION_UUID:
        s = HandlePushSessionUuid(buf, inLen, outLen, &written);
        break;
    case IOCTL_AC_EVENT_POLL:
        s = HandleEventPoll(buf, inLen, outLen, &written);
        break;
    case IOCTL_AC_MATCH_OVER:
        s = HandleMatchOver(buf, inLen, outLen, &written);
        break;
    case IOCTL_AC_PUSH_HASH:
        s = HandlePushHash(buf, inLen, outLen, &written);
        break;
    case IOCTL_AC_PUSH_WATCHLIST:
        s = HandlePushWatchlist(buf, inLen, outLen, &written);
        break;
    case IOCTL_AC_PUSH_MATCH:
        if (!buf || inLen == 0) { s = STATUS_INVALID_PARAMETER; break; }
        s = ChannelAcceptBlob(CHANNEL_BLOB_MATCH, buf, inLen);
        break;
    case IOCTL_AC_PUSH_PROCESS_PATH:
        if (!buf || inLen == 0) { s = STATUS_INVALID_PARAMETER; break; }
        s = ChannelAcceptBlob(CHANNEL_BLOB_PROCESS, buf, inLen);
        break;
    case IOCTL_AC_PUSH_VENDOR_CN:
        if (!buf || inLen == 0) { s = STATUS_INVALID_PARAMETER; break; }
        s = ChannelAcceptBlob(CHANNEL_BLOB_VENDOR, buf, inLen);
        break;
    case IOCTL_AC_PUSH_USB_DEVICE:
        if (!buf || inLen == 0) { s = STATUS_INVALID_PARAMETER; break; }
        s = ChannelAcceptBlob(CHANNEL_BLOB_USB, buf, inLen);
        break;
    case IOCTL_AC_PUSH_U64_SET:
    case IOCTL_AC_PUSH_CMD:

#include "channels.h"
#include "wire_records.h"
#include "imports.h"

typedef struct _PML4_WATCH_ENTRY
{
    volatile LONG   InUse;
    ULONG64         PhysBase;
    ULONG64         Snapshot[PML4_ENTRY_COUNT];
    HANDLE          OwnerPid;
    PEPROCESS       OwnerProcess;
} PML4_WATCH_ENTRY, *PPML4_WATCH_ENTRY;

static ULONG64 g_Pml4Snapshot[PML4_ENTRY_COUNT];
static ULONG64 g_Pml4PhysBase = 0;
static volatile LONG g_SnapshotTaken = 0;
static volatile LONG g_LastAnomalies = 0;

static KSPIN_LOCK   g_WatchLock;
static PML4_WATCH_ENTRY g_Watched[PML4_MAX_WATCHED];
static volatile LONG g_WatchInit = 0;

static ULONG64 ReadCr3Base(VOID)
{
    return (__readcr3() & ~0xFFFULL);
}

static VOID EnsureWatchInit(VOID)
{
    if (InterlockedCompareExchange(&g_WatchInit, 1, 0) == 0)
    {
        KeInitializeSpinLock(&g_WatchLock);
        RtlZeroMemory(g_Watched, sizeof(g_Watched));
    }
}

static VOID ReportAnomalies(ULONG64 physBase, const ULONG64 *cur, const ULONG64 *expected)
{
    for (ULONG i = 0; i < PML4_ENTRY_COUNT; i++)
    {
        if (cur[i] != expected[i])
        {
            WIRE_PML4_ANOMALY rec;
            rec.Index = i;
            rec.Observed = cur[i];
            rec.Expected = expected[i];
            rec.PhysicalBase = physBase;
            (VOID)ChannelEnqueueRecord(WIRE_REC_PML4_ANOMALY, &rec, sizeof(rec));
            InterlockedIncrement(&g_LastAnomalies);
        }
    }
}

NTSTATUS Pml4InitSnapshot(VOID)
{
    EnsureWatchInit();

    ULONG64 physBase = ReadCr3Base();
    UCHAR page[PAGE_SIZE];

    NTSTATUS s = PhysMemReadRaw(physBase, page, PAGE_SIZE);
    if (!NT_SUCCESS(s)) return s;

    RtlCopyMemory(g_Pml4Snapshot, page, sizeof(g_Pml4Snapshot));
    g_Pml4PhysBase = physBase;
    InterlockedExchange(&g_SnapshotTaken, 1);
    return STATUS_SUCCESS;
}

NTSTATUS Pml4Rescan(VOID)
{
    InterlockedExchange(&g_LastAnomalies, 0);

    if (InterlockedCompareExchange(&g_SnapshotTaken, 0, 0))
    {
        UCHAR page[PAGE_SIZE];
        NTSTATUS s = PhysMemReadRaw(g_Pml4PhysBase, page, PAGE_SIZE);
        if (NT_SUCCESS(s))
        {
            ReportAnomalies(g_Pml4PhysBase, (ULONG64 *)page, g_Pml4Snapshot);
        }
    }

    EnsureWatchInit();

    for (ULONG i = 0; i < PML4_MAX_WATCHED; i++)
    {
        if (!InterlockedCompareExchange(&g_Watched[i].InUse, 0, 0)) continue;

        UCHAR page[PAGE_SIZE];
        if (!NT_SUCCESS(PhysMemReadRaw(g_Watched[i].PhysBase, page, PAGE_SIZE))) continue;

        ReportAnomalies(g_Watched[i].PhysBase, (ULONG64 *)page, g_Watched[i].Snapshot);
    }

    return STATUS_SUCCESS;
}

ULONG Pml4LastAnomalyCount(VOID)
{
    return (ULONG)InterlockedCompareExchange(&g_LastAnomalies, 0, 0);
}

NTSTATUS Pml4RegisterGameProcessByPid(HANDLE pid)
{
    EnsureWatchInit();

    PEPROCESS proc = NULL;
    NTSTATUS s = PsLookupProcessByProcessId(pid, &proc);
    if (!NT_SUCCESS(s)) return s;

    KAPC_STATE apc;
    KeStackAttachProcess(proc, &apc);
    ULONG64 cr3 = __readcr3() & ~0xFFFULL;
    KeUnstackDetachProcess(&apc);

    if (cr3 == 0 || cr3 == g_Pml4PhysBase)
    {
        ObDereferenceObject(proc);
        return STATUS_NO_MATCH;
    }

    UCHAR page[PAGE_SIZE];
    s = PhysMemReadRaw(cr3, page, PAGE_SIZE);
    if (!NT_SUCCESS(s))
    {
        ObDereferenceObject(proc);
        return s;
    }

    KIRQL irql;
    KeAcquireSpinLock(&g_WatchLock, &irql);

    LONG slotIdx = -1;
    for (ULONG i = 0; i < PML4_MAX_WATCHED; i++)
    {
        if (g_Watched[i].InUse && g_Watched[i].OwnerPid == pid)
        {
            slotIdx = (LONG)i;
            break;
        }
    }
    if (slotIdx < 0)
    {
        for (ULONG i = 0; i < PML4_MAX_WATCHED; i++)
        {
            if (!g_Watched[i].InUse) { slotIdx = (LONG)i; break; }
        }
    }

    if (slotIdx < 0)
    {
        KeReleaseSpinLock(&g_WatchLock, irql);
        ObDereferenceObject(proc);
        return STATUS_INSUFFICIENT_RESOURCES;
    }

    PPML4_WATCH_ENTRY slot = &g_Watched[slotIdx];
    if (slot->InUse && slot->OwnerProcess)
    {
        ObDereferenceObject(slot->OwnerProcess);
    }

    slot->PhysBase = cr3;
    slot->OwnerPid = pid;
    slot->OwnerProcess = proc;
    RtlCopyMemory(slot->Snapshot, page, sizeof(slot->Snapshot));
    InterlockedExchange(&slot->InUse, 1);

    KeReleaseSpinLock(&g_WatchLock, irql);
    return STATUS_SUCCESS;
}

NTSTATUS Pml4UnregisterGameProcessByPid(HANDLE pid)
{
    EnsureWatchInit();

    KIRQL irql;
    KeAcquireSpinLock(&g_WatchLock, &irql);

    PEPROCESS toDeref = NULL;
    NTSTATUS s = STATUS_NOT_FOUND;
    for (ULONG i = 0; i < PML4_MAX_WATCHED; i++)
    {
        if (g_Watched[i].InUse && g_Watched[i].OwnerPid == pid)
        {
            toDeref = g_Watched[i].OwnerProcess;
            InterlockedExchange(&g_Watched[i].InUse, 0);
            g_Watched[i].OwnerPid = NULL;
            g_Watched[i].OwnerProcess = NULL;
            g_Watched[i].PhysBase = 0;
            s = STATUS_SUCCESS;
            break;
        }
    }

    KeReleaseSpinLock(&g_WatchLock, irql);
    if (toDeref) ObDereferenceObject(toDeref);
    return s;
}

VOID Pml4ClearWatched(VOID)
{
    EnsureWatchInit();

    KIRQL irql;
    KeAcquireSpinLock(&g_WatchLock, &irql);

    PEPROCESS pending[PML4_MAX_WATCHED] = { 0 };
    ULONG pendingCount = 0;

    for (ULONG i = 0; i < PML4_MAX_WATCHED; i++)
    {
        if (g_Watched[i].InUse)
        {
            if (g_Watched[i].OwnerProcess) pending[pendingCount++] = g_Watched[i].OwnerProcess;
            RtlZeroMemory(&g_Watched[i], sizeof(g_Watched[i]));
        }
    }

    KeReleaseSpinLock(&g_WatchLock, irql);

    for (ULONG i = 0; i < pendingCount; i++) ObDereferenceObject(pending[i]);
}

static const CHAR *SmbiosGetString(const UCHAR *tableEnd, const UCHAR *stringsStart, UCHAR index)
{
    if (index == 0 || stringsStart >= tableEnd) return "";
    const CHAR *p = (const CHAR *)stringsStart;
    UCHAR i = 1;
    while (p < (const CHAR *)tableEnd)
    {
        if (*p == 0) return "";
        if (i == index) return p;
        while (p < (const CHAR *)tableEnd && *p) p++;
        if (p < (const CHAR *)tableEnd) p++;
        i++;
    }
    return "";
}

static VOID CopyStringField(UCHAR *dst, SIZE_T cap, const CHAR *src)
{
    if (!dst || cap == 0) return;
    SIZE_T i = 0;
    while (src && i + 1 < cap && src[i])
    {
        dst[i] = (UCHAR)src[i];
        i++;
    }
    dst[i] = 0;
}

static VOID ParseType0(PSMBIOS_HEADER hdr, const UCHAR *stringsStart, const UCHAR *tableEnd, PSMBIOS_PARSED out)
{
    const UCHAR *body = (const UCHAR *)hdr;
    CopyStringField(out->BiosVendor,  sizeof(out->BiosVendor),  SmbiosGetString(tableEnd, stringsStart, body[4]));
    CopyStringField(out->BiosVersion, sizeof(out->BiosVersion), SmbiosGetString(tableEnd, stringsStart, body[5]));
}

static VOID ParseType1(PSMBIOS_HEADER hdr, const UCHAR *stringsStart, const UCHAR *tableEnd, PSMBIOS_PARSED out)
{
    const UCHAR *body = (const UCHAR *)hdr;
    CopyStringField(out->SystemManufacturer, sizeof(out->SystemManufacturer), SmbiosGetString(tableEnd, stringsStart, body[4]));
    CopyStringField(out->SystemProductName,  sizeof(out->SystemProductName),  SmbiosGetString(tableEnd, stringsStart, body[5]));
    CopyStringField(out->SystemVersion,      sizeof(out->SystemVersion),      SmbiosGetString(tableEnd, stringsStart, body[6]));
    CopyStringField(out->SystemSerial,       sizeof(out->SystemSerial),       SmbiosGetString(tableEnd, stringsStart, body[7]));

    if (hdr->Length >= 0x19)
        RtlCopyMemory(out->SystemUuid, body + 8, 16);
}

static VOID ParseType2(PSMBIOS_HEADER hdr, const UCHAR *stringsStart, const UCHAR *tableEnd, PSMBIOS_PARSED out)
{
    const UCHAR *body = (const UCHAR *)hdr;
    CopyStringField(out->BaseboardManufacturer, sizeof(out->BaseboardManufacturer), SmbiosGetString(tableEnd, stringsStart, body[4]));
    CopyStringField(out->BaseboardProduct,      sizeof(out->BaseboardProduct),      SmbiosGetString(tableEnd, stringsStart, body[5]));
    CopyStringField(out->BaseboardSerial,       sizeof(out->BaseboardSerial),       SmbiosGetString(tableEnd, stringsStart, body[7]));
}

static VOID ParseType17(PSMBIOS_HEADER hdr, const UCHAR *stringsStart, const UCHAR *tableEnd, PSMBIOS_PARSED out)
{
    const UCHAR *body = (const UCHAR *)hdr;
    out->MemoryModuleCount++;
    if (out->MemoryModuleCount == 1)
    {
        CopyStringField(out->FirstMemoryManufacturer, sizeof(out->FirstMemoryManufacturer),
                        SmbiosGetString(tableEnd, stringsStart, body[0x17]));
        CopyStringField(out->FirstMemorySerial, sizeof(out->FirstMemorySerial),
                        SmbiosGetString(tableEnd, stringsStart, body[0x18]));
    }
}

static VOID WalkSmbiosTable(const UCHAR *table, ULONG length, PSMBIOS_PARSED out)
{
    const UCHAR *end = table + length;
    const UCHAR *p = table;

    while (p + sizeof(SMBIOS_HEADER) <= end)
    {
        PSMBIOS_HEADER hdr = (PSMBIOS_HEADER)p;
        if (hdr->Length < sizeof(SMBIOS_HEADER)) break;

        const UCHAR *strings = p + hdr->Length;
        const UCHAR *tail = strings;
        while (tail + 1 < end)
        {
            if (tail[0] == 0 && tail[1] == 0) { tail += 2; break; }
            tail++;
        }

        switch (hdr->Type)
        {
        case 0:  ParseType0(hdr, strings, end, out);  break;
        case 1:  ParseType1(hdr, strings, end, out);  break;
        case 2:  ParseType2(hdr, strings, end, out);  break;
        case 17: ParseType17(hdr, strings, end, out); break;
        default: break;
        }

        if (hdr->Type == 127) break;
        p = tail;
    }
}

NTSTATUS SmbiosCollect(PSMBIOS_PARSED outParsed)
{
    if (!outParsed) return STATUS_INVALID_PARAMETER;
    RtlZeroMemory(outParsed, sizeof(*outParsed));

    ULONG needed = 0;
    SYSTEM_FIRMWARE_TABLE_INFORMATION probe = { 0 };
    probe.ProviderSignature = CORE_FW_PROVIDER_RSMB;
    probe.Action = CORE_FW_ACTION_GET;
    probe.TableID = 0;

                                          &probe, sizeof(probe), &needed);
    if (s != STATUS_BUFFER_TOO_SMALL && !NT_SUCCESS(s)) return s;

    if (tableBufLen == 0 && needed > sizeof(probe))
        tableBufLen = needed - FIELD_OFFSET(SYSTEM_FIRMWARE_TABLE_INFORMATION, TableBuffer);

    if (tableBufLen == 0) return STATUS_UNSUCCESSFUL;

    PSYSTEM_FIRMWARE_TABLE_INFORMATION info = (PSYSTEM_FIRMWARE_TABLE_INFORMATION)
        CoreAlloc(allocSize, CORE_AC_POOL_TAG_HWID);
    if (!info) return STATUS_INSUFFICIENT_RESOURCES;

    info->ProviderSignature = CORE_FW_PROVIDER_RSMB;
    info->Action = CORE_FW_ACTION_GET;
    info->TableID = 0;
    info->TableBufferLength = tableBufLen;

    ULONG got = 0;
    s = ZwQuerySystemInformation(CORE_SysFirmwareTableInformation,
                                 info, allocSize, &got);
    if (!NT_SUCCESS(s))
    {
        CoreFree(info, CORE_AC_POOL_TAG_HWID);
        return s;
    }

    if (info->TableBufferLength > sizeof(SMBIOS_RAW_HEADER))
    {
        PSMBIOS_RAW_HEADER raw = (PSMBIOS_RAW_HEADER)info->TableBuffer;
        if (raw->Length > 0 && raw->Length < info->TableBufferLength)
        {
            WalkSmbiosTable(raw->TableData, raw->Length, outParsed);
        }
    }

    CoreFree(info, CORE_AC_POOL_TAG_HWID);
    return STATUS_SUCCESS;
}

INT CoreStrCmpA(const CHAR *a, const CHAR *b)
{
    if (!a || !b) return (a == b) ? 0 : (a ? 1 : -1);
    while (*a && *a == *b) { a++; b++; }
    return (INT)((UCHAR)*a - (UCHAR)*b);
}

static __forceinline CHAR LowerA(CHAR c)
{
    return (c >= 'A' && c <= 'Z') ? (CHAR)(c + 32) : c;
}

static __forceinline WCHAR LowerW(WCHAR c)
{
    return (c >= L'A' && c <= L'Z') ? (WCHAR)(c + 32) : c;
}

INT CoreStrCmpiA(const CHAR *a, const CHAR *b)
{
    if (!a || !b) return (a == b) ? 0 : (a ? 1 : -1);
    while (*a)
    {
        CHAR la = LowerA(*a);
        CHAR lb = LowerA(*b);
        if (la != lb) return (INT)((UCHAR)la - (UCHAR)lb);
        a++; b++;
    }
    return (INT)((UCHAR)LowerA(*a) - (UCHAR)LowerA(*b));
}

INT CoreStrCmpiW(const WCHAR *a, const WCHAR *b)
{
    if (!a || !b) return (a == b) ? 0 : (a ? 1 : -1);
    while (*a)
    {
        WCHAR la = LowerW(*a);
        WCHAR lb = LowerW(*b);
        if (la != lb) return (INT)(la - lb);
        a++; b++;
    }
    return (INT)(LowerW(*a) - LowerW(*b));
}

PCHAR CoreMemFind(const VOID *haystack, SIZE_T haystackLen,
                  const VOID *needle,   SIZE_T needleLen)
{
    if (!haystack || !needle || needleLen == 0 || needleLen > haystackLen)
        return NULL;

    const UCHAR *h = (const UCHAR *)haystack;
    const UCHAR *n = (const UCHAR *)needle;
    SIZE_T limit = haystackLen - needleLen;

    for (SIZE_T i = 0; i <= limit; i++)
    {
        if (h[i] == n[0])
        {
            SIZE_T j = 1;
            while (j < needleLen && h[i + j] == n[j]) j++;
            if (j == needleLen) return (PCHAR)(h + i);
        }
    }
    return NULL;
}

static PVOID FindSectionText(PVOID imageBase, PULONG outSize)
{
    *outSize = 0;
    __try
    {
        PIMAGE_DOS_HEADER dos = (PIMAGE_DOS_HEADER)imageBase;
        if (dos->e_magic != IMAGE_DOS_SIGNATURE) return NULL;
        PIMAGE_NT_HEADERS64 nt = (PIMAGE_NT_HEADERS64)((PUCHAR)imageBase + dos->e_lfanew);
        if (nt->Signature != IMAGE_NT_SIGNATURE) return NULL;

        PIMAGE_SECTION_HEADER sec = IMAGE_FIRST_SECTION(nt);
        for (USHORT i = 0; i < nt->FileHeader.NumberOfSections; i++)
        {
            CHAR *n = (CHAR *)sec[i].Name;
            if (n[0] == '.' && n[1] == 't' && n[2] == 'e' && n[3] == 'x' && n[4] == 't')
            {
                *outSize = sec[i].Misc.VirtualSize;
                return (PUCHAR)imageBase + sec[i].VirtualAddress;
            }
        }
    }
    __except (EXCEPTION_EXECUTE_HANDLER)
    {
    }
    return NULL;
}

static BOOLEAN PatternMatch(const UCHAR *base, const UCHAR *pattern, const CHAR *mask)
{
    for (SIZE_T i = 0; mask[i]; i++)
    {
        if (mask[i] == 'x' && base[i] != pattern[i]) return FALSE;
    }
    return TRUE;
}

static PVOID PatternScan(PVOID start, ULONG size, const UCHAR *pattern, const CHAR *mask)
{
    if (!start || size == 0) return NULL;
    SIZE_T mlen = CoreStrLenA(mask);
    if (size < mlen) return NULL;

    const UCHAR *base = (const UCHAR *)start;
    ULONG limit = size - (ULONG)mlen;
    __try
    {
        for (ULONG i = 0; i <= limit; i++)
        {
            if (PatternMatch(base + i, pattern, mask)) return (PVOID)(base + i);
        }
    }
    __except (EXCEPTION_EXECUTE_HANDLER)
    {
    }
    return NULL;
}

static PVOID ResolveModuleBaseAnsi(const CHAR *moduleName)
{
    PVOID buf = NULL;
    ULONG count = 0;
    if (!NT_SUCCESS(EnvEnumKernelModules(&buf, &count)) || !buf) return NULL;

    PSYSTEM_MODULE_INFORMATION mods = (PSYSTEM_MODULE_INFORMATION)buf;
    PVOID found = NULL;
    for (ULONG i = 0; i < count; i++)
    {
        const CHAR *name = (const CHAR *)mods->Module[i].FullPathName + mods->Module[i].OffsetToFileName;
        if (CoreStrCmpiA(name, moduleName) == 0)
        {
            found = mods->Module[i].ImageBase;
            break;
        }
    }

    CoreFree(buf, CORE_AC_POOL_TAG_SCAN);
    return found;
}

static ULONG64 ComputeMmUnloadedFnv(PVOID table)
{
    if (!table) return 0;
    PTR_UNLOADED_DRIVER arr = *(PTR_UNLOADED_DRIVER *)table;
    if (!arr) return 0;

    ULONG64 h = 0xCBF29CE484222325ULL;
    __try
    {
        for (ULONG i = 0; i < TR_MAX_UNLOADED; i++)
        {
            if (!arr[i].Name.Buffer || arr[i].Name.Length == 0) continue;
            ULONG len = arr[i].Name.Length;
            if (len > 512) len = 512;
            const UCHAR *p = (const UCHAR *)arr[i].Name.Buffer;
            for (ULONG k = 0; k < len; k++)
            {
                h ^= p[k];
                h *= 0x100000001B3ULL;
            }
            h ^= (ULONG64)arr[i].UnloadTime;
            h *= 0x100000001B3ULL;
        }
    }
    __except (EXCEPTION_EXECUTE_HANDLER)
    {
        return 0;
    }
    return h;
}

static VOID ComputePiddbSnapshot(PVOID table, PULONG outCount, PULONG64 outFnv)
{
    *outCount = 0;
    *outFnv = 0;
    if (!table) return;

    __try
    {
        PRTL_AVL_TABLE avl = (PRTL_AVL_TABLE)table;
        *outCount = avl->NumberGenericTableElements;
        *outFnv = (ULONG64)avl->NumberGenericTableElements * 0x100000001B3ULL ^
                  ((ULONG64)avl->DeleteCount << 17);
    }
    __except (EXCEPTION_EXECUTE_HANDLER)
    {
        *outCount = 0;
        *outFnv = 0;
    }
}

        {

            if (count > g_PiDDBExpectedCount)
            {
                g_PiDDBExpectedCount = count;
                g_PiDDBExpectedFnv = fnv;
            }
        }
        else if (count > g_PiDDBExpectedCount)

            g_PiDDBExpectedCount = count;
            g_PiDDBExpectedFnv = fnv;
        }

            g_MmUnloadedExpectedFnv = fnv;
        }
    }
    return STATUS_SUCCESS;
}

{
    if (!cb) return STATUS_INVALID_PARAMETER;

    NTSTATUS s = PsLookupProcessByProcessId(ProcessId, &proc);
    if (!NT_SUCCESS(s)) return s;

    KAPC_STATE apc;
    KeStackAttachProcess(proc, &apc);

    PCORE_PEB peb = (PCORE_PEB)PsGetProcessPeb(proc);

    {
        KeUnstackDetachProcess(&apc);
        ObDereferenceObject(proc);
        return STATUS_NOT_FOUND;

    __try
    {

        {
            PCORE_LDR_DATA_TABLE_ENTRY e = CONTAINING_RECORD(node, CORE_LDR_DATA_TABLE_ENTRY, InLoadOrderLinks);
            USERMOD_ITER_CB_CTX ctx;
            ctx.OpaqueBase = e->DllBase;
            ctx.Size = e->SizeOfImage;
            ctx.NamePtr = e->BaseDllName.Buffer;
            ctx.NameLen = e->BaseDllName.Length;

            if (!cb(&ctx, userCtx)) break;

            node = node->Flink;
            guard++;
        }
    }
    __except (EXCEPTION_EXECUTE_HANDLER)
    {
    }

    KeUnstackDetachProcess(&apc);
    ObDereferenceObject(proc);
