# Comparative Evaluation of Static Detection Methods for Unicode-Based Source Code Obfuscation

Štefan Müller and Ondrej Takáč, J. Selye University. Conference manuscript for the 8th ICRAS, 2026.

This project evaluates read-only Unicode diagnostics for Python. The original corpus has 393 files. The revision adds 461 files in separate development and evaluation partitions. The new evaluation has 375 files, including 90 controlled positives, 90 matched controls, 117 upstream Unicode-bearing files and 78 upstream ASCII files.

On the new evaluation, D1, D2, D3, D3+ and the selected Ruff rule configuration localized 64, 90, 62, 90 and 12 of the 90 positives. They alerted on 57, 3, 2, 1 and 25 of 117 upstream Unicode files, respectively. Those upstream labels are provisional. The observed D3+ versus D3 localization change is +31.1 percentage points, with an exploratory family-bootstrap interval of +23.3 to +40.0 points. The upstream interval includes zero. See [results](study/revalidated/summary.json), [audit](study/docs/audit_report.md), [limitations](study/docs/limitations.md) and the [manuscript](manuscript/final.pdf).

## Reproduce the study

Install CPython 3.14.7, create and activate a virtual environment, then run from the project root:

```text
python -m pip install -r study/requirements-revision.txt
python study/fetch.py
python study/revised_corpus.py
python -m pytest -q study
python study/run.py
python study/revalidate.py --repeats 20
python study/validate_revision.py
```

The first two data commands verify every archive and Unicode data file against the checked-in SHA-256 locks. They retrieve third-party files from the original distribution sites. The manifest generates controlled fixtures in memory and records each target interval and label. The project never imports or runs the analyzed source files. `revalidate.py` verifies the frozen implementation and generates the manifest, scan outcomes, diagnostic spans, target localization, annotation queue, tabulated results and both figure formats. An optional `--host` argument records exact hardware description for a local timing run.

The baseline replay rewrites files under `study/results`. The revision run rewrites files under `study/revalidated`. Run in a fresh checkout if you want to retain the exact distributed resource measurements. Wall-clock and memory measurements depend on the machine and process load.

# Unicode source-code detection benchmark

This package reproduces the exploratory comparison of three static detectors on CPython 3.14.7 and Unicode 16.0.0. See [protocol.md](protocol.md) for scope, metrics and resampling, and [annotations.json](annotations.json) for the annotation procedure and flagged contexts. The original plan called for independent dual annotation and confirmatory sample-size planning. This run uses a single preliminary assessment and reports exploratory estimates.

## Reproduction

From the workspace root in PowerShell, using CPython 3.14.7:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r study\requirements.lock.txt
.\.venv\Scripts\python.exe study\fetch.py
.\.venv\Scripts\python.exe -m pytest -q study
.\.venv\Scripts\python.exe study\run.py
```

`fetch.py` verifies SHA-256 hashes against `inputs.lock.json`. It downloads source archives and Unicode tables as data. No sampled source file is imported or executed. The cached archives can be regenerated from the lock and retain their upstream license files. The result files list sample identities and source ranges without reproducing third-party source. `review.py` optionally rebuilds the local context queue for independent annotation. Treat that queue as working material, since it contains escaped source snippets.

## Output files

- `results/manifest.jsonl` identifies files, release archive members, partition, reference labels, and hashes.
- `results/decisions.csv` records file-level decisions, analysis exceptions, localization and eligible-name coverage.
- `results/diagnostics.csv` records rule-level diagnostics. Character offsets use zero-based half-open intervals on LF-normalized decoded text. Line numbers are one-based.
- `results/summary.json` contains counts, contrasts, exploratory intervals and performance timings. Timings depend on host and load.
- `results/comparison.pdf` contains the vector figure and `results/comparison.png` its raster equivalent.

The terms provisional negative and alert rate reflect the available reference labels. The upstream corpus is a convenience sample with explicit Unicode enrichment. Positive fixtures represent neutral text and declarations. Measured sensitivity applies to these controlled phenomena. The package implements read-only diagnostics and provides no code transformation or patching workflow.

"""Deterministic sampling of inert fixtures and upstream Python source files."""
import ast
import gzip
from hashlib import sha256
import io
import json
from pathlib import Path
import random
import tarfile
import tokenize
import warnings

ROOT = Path(__file__).resolve().parent
SEED = 531960


def record(sample, split, cluster, kind, source, **extra):
    return {"sample": sample, "split": split, "cluster": cluster, "kind": kind,
            "source": source, **extra}


def fixtures():
    # Test files contain only neutral data and independent constant definitions.
    confusable = [("a", "\u0430"), ("e", "\u0435"), ("o", "\u03bf"),
                  ("p", "\u0440"), ("c", "\u0441"), ("x", "\u0445"),
                  ("y", "\u0443"), ("i", "\u0456"), ("s", "\u0455"),
                  ("j", "\u0458"), ("rn", "m"), ("O", "\u039f")]
    normalizing = [("K", "\u212a"), ("fi", "\ufb01"), ("A", "\uff21"),
                   ("x", "\u02e3"), ("B", "\u212c"), ("H", "\u210b"),
                   ("I", "\u2110"), ("R", "\u211b"), ("e", "\u212f"),
                   ("ff", "\ufb00"), ("\u00e9", "e\u0301"), ("n", "\u207f")]
    invisible = ["\u200b", "\u2060", "\u034f", "\u00ad", "\ufeff", "\u200d"]
    rtl = "\u05e9\u05dc\u05d5\u05dd"
    legitimate = ["café", "čaj", "Ελλάδα", "перевод", "日本語", "اللغة"]
    words = ("atlas", "lemon", "north", "maple", "violet", "cloud", "silver",
             "pearl", "cedar", "coral", "river", "amber")
    for mechanism, count in (("confusable", 12), ("nfkc", 12), ("bidi", 12), ("ignorable", 12)):
        for index in range(count):
            split = "pilot" if index < 2 else "evaluation"
            family = f"{mechanism}-{index:02}"
            word = words[index]
            if mechanism in {"confusable", "nfkc"}:
                left, right = (confusable if mechanism == "confusable" else normalizing)[index]
                if (index % 3) == 0:
                    head = f"def {word}():\n    {left}_item = 1\n"
                    indent = "    "
                else:
                    head = f"{left}_item = 1\n"
                    indent = ""
                prefix = head + indent
                marker = f"{right}_item"
                positive = prefix + f"{marker} = 2\n"
                control = prefix + f"{legitimate[index % 6]}_value = 2\n"
                if mechanism == "confusable" and index % 3 == 1:
                    control = (f"def first_{word}():\n    {left}_item = 1\n\n"
                               f"def second_{word}():\n    {marker} = 2\n")
                    if control.isascii():
                        control += "# café\n"
                plain = prefix + "other_value = 2\n"
            else:
                prefix = f"{word} = '" if index % 2 == 0 else f"{word} = 1  # "
                suffix = "'\n" if index % 2 == 0 else "\n"
                if mechanism == "bidi":
                    # Directional formatting stays inside a neutral word.
                    left, right = (("\u202e", "\u202c") if index % 3 != 0
                                   else ("\u202d", "\u202c"))
                    marker = left
                    payload = word if left == "\u202e" else rtl
                    positive = prefix + left + payload + right + suffix
                    control = prefix + "\u2067" + rtl + "\u2069" + suffix
                else:
                    marker = invisible[index % len(invisible)]
                    positive = prefix + word[:2] + marker + word[2:] + suffix
                    control = prefix + "\U0001f469\u200d\U0001f4bb" + suffix
                plain = prefix + word + suffix
            for variant, text, label in (("target", positive, 1), ("matched", control, 0), ("plain", plain, 0)):
                ast.parse(text)
                location = text.index(marker, len(prefix)) if label else None
                yield record(f"{family}/{variant}", split, family, "fixture", text,
                             label=label, mechanism=mechanism if label else None,
                             span=[location, location + len(marker)] if label else None,
                             variant=variant, context="identifier" if mechanism in {"nfkc", "confusable"}
                             else ("literal" if index % 2 == 0 else "comment"))


def natural(inputs):
    hashes = set()
    for item in inputs["projects"]:
        project = item["project"]
        archive = ROOT / "cache" / item["file"]
        with tarfile.open(fileobj=io.BytesIO(gzip.decompress(archive.read_bytes())), mode="r:") as package:
            candidates = sorted((member for member in package if member.isfile()
                                 and member.name.endswith(".py") and 25 <= member.size <= 130_000),
                                key=lambda member: member.name)
            random.Random(f"{SEED}/{project}").shuffle(candidates)
            quotas = {"unicode": 12, "ascii": 4}
            for member in candidates:
                raw = package.extractfile(member).read()
                digest = sha256(raw).hexdigest()
                if digest in hashes:
                    continue
                kind = "ascii" if raw.isascii() else "unicode"
                if quotas[kind] == 0:
                    continue
                try:
                    encoding, _ = tokenize.detect_encoding(io.BytesIO(raw).readline)
                    if encoding not in {"utf-8", "utf-8-sig"}:
                        continue
                    source = raw.decode(encoding).replace("\r\n", "\n").replace("\r", "\n")
                    if kind == "unicode" and source.isascii():
                        continue
                    with warnings.catch_warnings():
                        warnings.simplefilter("ignore", SyntaxWarning)
                        compile(source, member.name, "exec", ast.PyCF_ONLY_AST)
                except (SyntaxError, UnicodeError, ValueError):
                    continue
                hashes.add(digest)
                quotas[kind] -= 1
                relative = member.name.split("/", 1)[-1]
                yield record(f"{project}/{relative}", item["split"], project, kind, source,
                             label=None, mechanism=None, span=None, member=member.name,
                             release=item["version"], sha256=digest)
                if not any(quotas.values()):
                    break


def corpus():
    inputs = json.loads((ROOT / "inputs.lock.json").read_text(encoding="utf-8"))
    return [*fixtures(), *natural(inputs)]




if __name__ == "__main__":
    main()

"""Three read-only static detectors with a common diagnostic representation."""
import ast
from collections import defaultdict
from functools import lru_cache
import io
from itertools import accumulate
from pathlib import Path
import symtable
import token
import tokenize
import unicodedata as ud
from zipfile import ZipFile

CACHE = Path(__file__).resolve().parent / "cache"


def rows(text):
    for line in text.splitlines():
        fields = line.split("#", 1)[0].strip().split(";")
        if len(fields) >= 2:
            yield [field.strip() for field in fields]


def codepoints(value):
    limits = value.split("..")
    return range(int(limits[0], 16), int(limits[-1], 16) + 1)


@lru_cache(maxsize=1)
def tables():
    if ud.unidata_version != "16.0.0":
        raise RuntimeError("Unicode 16.0.0 is required")
    mapping = {int(source, 16): "".join(chr(int(value, 16)) for value in target.split())
               for source, target, *_ in rows((CACHE / "confusables.txt").read_text(encoding="utf-8-sig"))}
    with ZipFile(CACHE / "UCD.zip") as data:
        def properties(path):
            return rows(data.read(path).decode("utf-8"))

        def property_points(path, name):
            return frozenset(chr(value) for field, prop, *_ in properties(path) if prop == name
                             for value in codepoints(field))

        aliases = {long: short for prop, short, long, *_ in properties("PropertyValueAliases.txt")
                   if prop == "sc"}
        scripts = {value: frozenset({aliases[script]}) for field, script, *_ in properties("Scripts.txt")
                   if script not in {"Common", "Inherited", "Unknown"} for value in codepoints(field)}
        scripts.update({value: frozenset(script.split()) for field, script, *_ in properties("ScriptExtensions.txt")
                        for value in codepoints(field)})
        return (mapping, scripts, property_points("PropList.txt", "Bidi_Control"),
                property_points("DerivedCoreProperties.txt", "Default_Ignorable_Code_Point"),
                property_points("emoji/emoji-data.txt", "Extended_Pictographic"))


def skeleton(name):
    mapping, _, _, ignorable, _ = tables()
    text = "".join(char for char in ud.normalize("NFD", name) if char not in ignorable)
    return ud.normalize("NFD", text.translate(mapping))


def mixed_script(name):
    _, scripts, _, _, _ = tables()
    sets = [scripts[ord(char)] for char in name if ord(char) in scripts]
    # Script_Extensions intersection heuristic. This is not the UTS #39 restriction profile.
    return bool(sets) and not set.intersection(*(set(value) for value in sets))


def finding(rule, mechanism, start, stop):
    return (rule, mechanism, start, stop)


def raw_detector(source):
    mapping, _, bidi, ignorable, _ = tables()
    hits = set()
    for position, char in enumerate(source):
        if char.isascii():
            continue
        if char in bidi:
            hits.add(finding("character_bidi", "bidi", position, position + 1))
        elif char in ignorable:
            hits.add(finding("character_ignorable", "ignorable", position, position + 1))
        if ord(char) in mapping and mapping[ord(char)].isascii():
            hits.add(finding("character_ascii_lookalike", "confusable", position, position + 1))
        if ud.normalize("NFKC", char) != char:
            hits.add(finding("character_compatibility", "nfkc", position, position + 1))
    return hits, None


def text_findings(text, start, contextual):
    _, _, bidi, ignorable, emoji = tables()
    allowed = set()
    if contextual:
        # Recognize the common, narrowly specified RTL-isolate and pictograph cases.
        isolate = None
        for index, char in enumerate(text):
            if char in "\u2066\u2067\u2068":
                isolate = index
            elif char == "\u2069" and isolate is not None:
                body = text[isolate + 1:index]
                if (text[isolate] in "\u2067\u2068" and not any(c in bidi for c in body)
                        and any(ud.bidirectional(c) in {"R", "AL"} for c in body)):
                    allowed.update((isolate, index))
                isolate = None
        for index, char in enumerate(text[1:-1], 1):
            if char == "\u200d" and text[index - 1] in emoji and text[index + 1] in emoji:
                allowed.add(index)
    for index, char in enumerate(text):
        if index in allowed:
            continue
        if char in bidi:
            yield finding("token_bidi", "bidi", start + index, start + index + 1)
        elif char in ignorable:
            yield finding("token_ignorable", "ignorable", start + index, start + index + 1)


def token_records(source):
    lines = source.split("\n")
    starts = list(accumulate((len(line) + 1 for line in lines), initial=0))
    names = []
    text = []
    for entry in tokenize.generate_tokens(io.StringIO(source).readline):
        if entry.type not in {token.NAME, token.STRING, token.COMMENT, token.FSTRING_MIDDLE,
                              token.TSTRING_MIDDLE}:
            continue
        line, column = entry.start
        start = starts[line - 1] + column
        if entry.type == token.NAME:
            names.append((entry.string, start, line, column))
        else:
            text.append((entry.string, start))
    return names, text, lines


class ScopeIndex(ast.NodeVisitor):
    """Index ordinary name occurrences. Special and unresolved contexts remain unlinked."""

    def __init__(self, lines, table):
        self.lines = lines
        self.scope = table
        self.bindings = {}

    def locate(self, node):
        text = self.lines[node.lineno - 1]
        return node.lineno, len(text.encode("utf-8")[:node.col_offset].decode("utf-8"))

    def bind(self, node, name):
        if self.scope is None:
            return
        try:
            symbol = self.scope.lookup(name)
        except KeyError:
            return
        if self.scope.get_type() == "module" or (symbol.is_local() and not symbol.is_global()):
            self.bindings[self.locate(node)] = self.scope.get_id()

    def visit_Name(self, node):
        self.bind(node, node.id)

    def visit_arg(self, node):
        self.bind(node, node.arg)

    def visit_FunctionDef(self, node):
        parent = self.scope
        choices = [child for child in parent.get_children()
                   if child.get_name() == node.name and child.get_lineno() == node.lineno
                   and child.get_type() == "function"] if parent and not node.type_params else []
        self.scope = choices[0] if len(choices) == 1 else None
        for argument in [*node.args.posonlyargs, *node.args.args, *node.args.kwonlyargs,
                         node.args.vararg, node.args.kwarg]:
            if argument is not None:
                self.visit_arg(argument)
        for statement in node.body:
            self.visit(statement)
        self.scope = parent

    visit_AsyncFunctionDef = visit_FunctionDef

    def skip(self, node):
        return

    visit_ClassDef = visit_Lambda = visit_ListComp = visit_DictComp = visit_SetComp = visit_GeneratorExp = skip


def collisions(entries, scoped):
    groups = defaultdict(list)
    canonical = defaultdict(list)
    for name, position, scope in entries:
        if scope is None:
            continue
        nfkc = ud.normalize("NFKC", name)
        groups[scope, skeleton(name)].append((name, position, nfkc))
        canonical[scope, nfkc].append((name, position, nfkc))
        if not scoped and name != nfkc:
            yield finding("token_nfkc", "nfkc", position, position + len(name))
        if not scoped and mixed_script(name):
            yield finding("token_mixed_script", "confusable", position, position + len(name))
    for bucket in groups.values():
        if len({norm for _, _, norm in bucket}) > 1:
            if any(not name.isascii() for name, _, _ in bucket):
                for name, start, _ in bucket:
                    if not name.isascii():
                        yield finding("identifier_skeleton", "confusable", start, start + len(name))
            else:
                for name, start, _ in bucket:
                    yield finding("identifier_skeleton", "confusable", start, start + len(name))
    if scoped:
        for bucket in canonical.values():
            if len({name for name, _, _ in bucket}) > 1:
                for name, start, norm in bucket:
                    if name != norm:
                        yield finding("scope_nfkc", "nfkc", start, start + len(name))


def lexical_detector(source, *, scoped=False, contextual=False):
    names, text, lines = token_records(source)
    if scoped:
        index = ScopeIndex(lines, symtable.symtable(source, "<source>", "exec"))
        index.visit(ast.parse(source))
        entries = [(name, start, index.bindings.get((line, column))) for name, start, line, column in names]
        eligible = [(name, scope) for name, _, scope in entries if not name.isascii() and name.isidentifier()]
        coverage = (sum(scope is not None for _, scope in eligible), len(eligible))
    else:
        entries = [(name, start, 0) for name, start, _, _ in names]
        coverage = None
    hits = set(collisions(entries, scoped))
    _, _, _, ignorable, _ = tables()
    hits.update(finding("identifier_ignorable", "ignorable", start + index, start + index + 1)
                for name, start, _, _ in names for index, char in enumerate(name) if char in ignorable)
    hits.update(hit for value, start in text for hit in text_findings(value, start, contextual))
    return hits, coverage

"""Read-only experimental extension of the legacy scoped detector."""
import ast
from functools import lru_cache
from itertools import groupby
import symtable
import unicodedata as ud
from zipfile import ZipFile

from detect import (CACHE, ScopeIndex, collisions, finding, lexical_detector, mixed_script,
                    rows, tables, text_findings, token_records)


class ExtendedScope(ScopeIndex):
    def __init__(self, lines, root, names):
        super().__init__(lines, root)
        self.tokens = {}
        for line, entries in groupby(names, key=lambda entry: entry[2]):
            self.tokens[line] = list(entries)

    def visit_ClassDef(self, node):
        parent = self.scope
        choices = [child for child in parent.get_children()
                   if child.get_type() == 'class' and child.get_name() == node.name
                   and child.get_lineno() == node.lineno] if parent and not node.type_params else []
        self.scope = choices[0] if len(choices) == 1 else None
        for child in node.body:
            self.visit(child)
        self.scope = parent

    def comprehension(self, node):
        # Only explicit target bindings are linked. Evaluation context of loads is distinct.
        if self.scope is None:
            return
        scope = ('comprehension', *self.locate(node))
        for generator in node.generators:
            for target in ast.walk(generator.target):
                if isinstance(target, ast.Name) and isinstance(target.ctx, ast.Store):
                    self.bindings[self.locate(target)] = scope

    visit_ListComp = visit_DictComp = visit_SetComp = visit_GeneratorExp = comprehension

    def visit_Attribute(self, node):
        self.visit(node.value)
        if not isinstance(node.value, ast.Name):
            return
        binding = self.bindings.get(self.locate(node.value))
        if binding is None:
            return
        line = node.end_lineno
        end = len(self.lines[line-1].encode()[:node.end_col_offset].decode())
        for name, _, _, col in self.tokens.get(line, []):
            if col + len(name) == end and ud.normalize('NFKC', name) == node.attr:
                self.bindings[line, col] = ('receiver', binding, node.value.id)
                break


@lru_cache(maxsize=1)
def emoji_variations():
    with ZipFile(CACHE / 'UCD.zip') as archive:
        data = archive.read('emoji/emoji-variation-sequences.txt').decode()
    return frozenset(''.join(chr(int(cp, 16)) for cp in key.split()) for key, *_ in rows(data))


def scan(source, *, scope_plus=True, text_plus=True):
    names, text, lines = token_records(source)
    eligible = {(line, col) for name, _, line, col in names if not name.isascii() and name.isidentifier()}
    recovered = None
    try:
        index_type = ExtendedScope if scope_plus else ScopeIndex
        args = (lines, symtable.symtable(source, '<source>', 'exec'))
        index = index_type(*args, names) if scope_plus else index_type(*args)
        index.visit(ast.parse(source))
    except (SyntaxError, RecursionError) as error:
        hits, _ = lexical_detector(source, contextual=True)
        return hits, (0, len(eligible)), type(error).__name__
    entries = [(name, start, index.bindings.get((line, col))) for name, start, line, col in names]
    hits = set(collisions(entries, True))
    _, _, _, ignorable, _ = tables()
    for name, start, scope in entries:
        if scope_plus and scope is not None and mixed_script(name):
            hits.add(finding('scope_mixed_script', 'mixed', start, start+len(name)))
        hits.update(finding('identifier_ignorable', 'ignorable', start+i, start+i+1)
                    for i, char in enumerate(name) if char in ignorable)
    for text_value, start in text:
        for hit in text_findings(text_value, start, True):
            offset = hit[2]-start
            if (text_plus and hit[1] == 'ignorable' and offset > 0
                    and text_value[offset-1:offset+1] in emoji_variations()):
                continue
            hits.add(hit)
    return hits, (len(eligible & index.bindings.keys()), len(eligible)), recovered

# Upstream reference-labeling protocol

Record project, release, file identifier, SHA-256 and the relevant source range. An upstream file is provisionally benign when provenance and context support ordinary text, identifiers, language-specific formatting, test data or documentation. Examples include emoji sequences, natural RTL text and Unicode tables in published code. An ambiguous label is appropriate when a deliberate security or parser fixture overlaps a positive diagnostic target, when the surrounding use cannot be resolved, or when evidence disagrees. Preserve labels and rationale separately from detector predictions.

The annotation queue contains all alert disagreements, all shared alerts, analysis failures and a deterministic sample of agreed no-alert Unicode files. For first-pass review, use the queue without detector names or verdicts. Obtain the exact archived source from the immutable input manifest. Record the independent reviewer’s provenance, status and rationale separately. Collect the two label files before adjudication. Keep ambiguities and disagreements visible and recalculate all denominators after adjudication.

The released queue is a request for independent annotation. New upstream measurements are alert rates on files provisionally labeled from provenance, with any documented ambiguity treated in a separate sensitivity analysis. They do not establish a false-positive rate against independently verified negatives. The historical ambiguous formatter fixture remains excluded from the legacy primary negative set. For expanded data, unresolved queue entries may be assigned either label in the reported bounds. An analysis failure is its own status in every arm.

`study/docs/limitations.md`:

```md
# Interpretation and limitations

The expanded fixture suite measures localization of predefined diagnostic phenomena in neutral Python snippets. It is a fixed, exploratory holdout for this revision. Families share Unicode examples and structural patterns, so the suite cannot establish a population-level detection probability. The legacy 40/40 exact binomial example is conditional on independent trials and does not account for such dependence. The paired resampling distributions retain dependence within the recorded families and projects. They do not represent all uncertainty from project choice, common fixture design or provisional labels.

The upstream corpora were selected from released archives with Unicode enrichment and project quotas. Two holdout projects contribute ASCII but no eligible Unicode files. No independent reviewer labels were available. A detector-blind annotation queue includes alerting files and sampled no-alert files. Do not interpret its unfilled reviewer fields as negative judgments. The paper reports the historical ambiguous file separately and provides additional queue-based bounds.

D3+ can increase diagnostic counts when mixed-script or expanded scope checks expose new cases. Its superficial receiver grouping does not model object identity or dynamic attributes. The comprehension analysis links only explicit targets. Module names in other files, arbitrary nesting of semantic environments, general joining-control allowances and complete visual rendering are not implemented or evaluated. The text allowance is limited to explicitly standardized emoji variation sequences.

The Ruff arm uses a selected read-only rule configuration. Its flags address distinct warning objectives. Its output is not a textual or semantic ground truth. Runtime and traced Python allocations are compared across the four Python detectors. Ruff’s native execution and process-level memory cannot be inferred from the Python instrumentation.

# Revalidation design

The historical run is independently reproducible with `run.py`. The revised run preserves D1, D2 and D3 and adds D3+, two D3+ component ablations, the two historical D3 component ablations and Ruff 0.15.0. Ruff is invoked in isolated, read-only mode with Python 3.14 parsing, no cache, no inline suppressions and only RUF001, RUF002, RUF003 and PLE2502. Its diagnostics are mapped to confusable or bidi categories, and its code-point column convention is tested. Ruff is evaluated with identical inputs. Its batch process and native allocations are outside the Python performance comparison.

New controlled inputs are inert constant assignments, comments, strings and simple declaration contexts. Source targets and spans are recorded by the corpus generator, without calling the detector or its skeleton routine. Categories include format controls, default-ignorables, variation selectors, confusability, mixed scripts, NFKC and combining sequences. Class bodies, nested functions, comprehension targets and simple receiver attributes broaden the tested contexts. A combined case passes file localization only when every target overlaps an appropriate diagnostic. Test source is parsed but never executed. The design does not represent exploit prevalence, actual attack capability, dynamic attributes, or inter-file linkage.

Projects and fixture families are partitioned before aggregate evaluation. Two projects are used for development, and different released projects populate the holdout. Holdout rules, fixtures, project selection and analysis code are hashed before scoring. Exact original bytes and normalized text are also checked against the legacy corpus. The benchmark uses a convenience sample, some Unicode characters and structural patterns recur across families, and no near-clone screening was performed. The new cohort is an exploratory held-out suite within this revision, not a prospectively registered confirmatory sample from an operational population.

D3+ extends identifier analysis to class bindings, explicit comprehension targets and statically linked simple receivers. It adds a mixed-script diagnostic for linked names and recognizes standardized emoji text variation pairs in strings and comments. A lexical fallback is reported separately when semantic analysis fails. The component ablations keep recovery enabled. Class-name mangling, comprehensions with complex evaluation contexts, attribute aliasing, inter-project propagation and complete script-profile or shaping conformance remain outside its scope. The receiver index is syntactic and cannot infer dynamic object identity.

Report file sensitivity, all-target localization, per-category localization, matched-control alerts, provisional upstream alerts and alerts per thousand LF-based physical source lines. Unsuccessful positive scans count as misses. Rates for upstream and matched files use successful scans with failures separately recorded. The controlled confusion matrix uses construction-based reference labels. The Python runtime benchmark warms each arm, rotates order over 20 repetitions and traces Python allocations separately. Report medians, extrema, interquartile ranges, throughput and traced peak memory. Read-only scans received the same preloaded LF-normalized upstream text. Use the pinned Python and dependency versions. Host metadata and every timing repetition are in `revalidated/summary.json`.

`study/fetch.py`:

```py
"""Cache immutable upstream inputs without importing or extracting packages."""
from concurrent.futures import ThreadPoolExecutor
from hashlib import sha256
from pathlib import Path
import json
import urllib.request

ROOT = Path(__file__).resolve().parent
CACHE = ROOT / "cache"
CONFIG = json.loads((ROOT / "sources.json").read_text(encoding="utf-8"))


def download(url):
    with urllib.request.urlopen(url, timeout=60) as response:
        return response.read()


def cached(name, url, expected=None):
    path = CACHE / name
    data = path.read_bytes() if path.exists() else download(url)
    digest = sha256(data).hexdigest()
    if expected and digest != expected:
        raise ValueError(f"Digest mismatch: {name}")
    if not path.exists():
        path.write_bytes(data)
    return {"file": name, "url": url, "sha256": digest}


def resolve_project(spec, split):
    project, version = spec.split("==")
    data = json.loads(download(f"https://pypi.org/pypi/{project}/{version}/json"))
    choices = [item for item in data["urls"] if item["packagetype"] == "sdist"]
    item, = choices
    result = cached(item["filename"], item["url"], item["digests"]["sha256"])
    license_info = data["info"].get("license_expression") or data["info"].get("license")
    return {**result, "project": project, "version": version, "split": split,
            "license_metadata": (license_info or "").splitlines()[0:1]}


def main():
    CACHE.mkdir(exist_ok=True)
    lock = ROOT / "inputs.lock.json"
    if lock.exists():
        inputs = json.loads(lock.read_text(encoding="utf-8"))
        items = inputs["projects"] + list(inputs["unicode"].values())
        with ThreadPoolExecutor(max_workers=6) as pool:
            list(pool.map(lambda item: cached(item["file"], item["url"], item["sha256"]), items))
        return
    with ThreadPoolExecutor(max_workers=6) as pool:
        pending = [pool.submit(resolve_project, spec, split)
                   for split in ("pilot", "evaluation") for spec in CONFIG[split]]
        unicode = {key: pool.submit(cached, key if key.endswith(".txt") else "UCD.zip", url)
                   for key, url in CONFIG["unicode"].items()}
        inputs = {"projects": [item.result() for item in pending],
                  "unicode": {key: task.result() for key, task in unicode.items()}}
    lock.write_text(json.dumps(inputs, indent=2) + "\n", encoding="utf-8")


if __name__ == "__main__":
    main()

def replace(paragraph, text):
    runs = paragraph.runs
    for element in list(paragraph._p):
        if element.tag != qn("w:pPr") and (not runs or element is not runs[0]._r):
            paragraph._p.remove(element)
    if runs:
        runs[0].text = text
    else:
        paragraph.add_run(text)


def labeled(paragraph, label, text):
    replace(paragraph, label)
    paragraph.runs[0].bold = label == "Abstract"
    run = paragraph.add_run(" – " + text)
    run.font.name = "Times New Roman"
    run.font.size = Pt(12 if label == "Abstract" else 10)
    run.italic = label == "Keywords"


def append_cloned(anchor, model, value):
    from docx.text.paragraph import Paragraph
    new = deepcopy(model._p)
    anchor.addprevious(new)
    paragraph = Paragraph(new, model._parent)
    replace(paragraph, value)
    return paragraph


def patch(template, result, body, short):
    expected = ("1b568974625c9993c25133bf3bbcaa4597b0d4f3e523f969e608bc3c8771d85e" if short else
                "9d0d2e02f7a1f0495fbbb181e6172780a34af8095a289efc77fd35ac9d65542c")

    labeled(p[11 if short else 12], "Keywords", KEYWORDS)
    if not short:
        anchor = doc._body._body.sectPr
        table_template = deepcopy(doc.tables[0]._tbl)
        for node in list(doc._body._body):
            if node is first_section or node is anchor:
                continue
            if list(doc._body._body).index(node) > list(doc._body._body).index(first_section):
                doc._body._body.remove(node)
        for name, paragraphs in sections:
            heading = append_cloned(anchor, p[15], name)
            heading.paragraph_format.keep_with_next = True
            for idx, paragraph in enumerate(paragraphs):
                append_cloned(anchor, p[16], paragraph)
                if name == "Results" and idx == 0:
                    caption = append_cloned(anchor, p[28], "Table 1. Evaluation results by detector")
                    caption.paragraph_format.keep_with_next = True
                    from docx.table import Table
                    anchor.addprevious(table_template)
                    table = Table(table_template, doc._body)
                    if len(table.columns) != len(matrix[0]):
                        doc._body._body.remove(table_template)
                        table = doc.add_table(rows=len(matrix), cols=len(matrix[0]))
                        table.style = "Table Grid"
                    table.autofit = False
                    table.alignment = WD_TABLE_ALIGNMENT.CENTER
                    widths = [0.76, 1.31, 1.85, 1.30, 1.82]

```md
# Exploratory benchmark protocol

The unit is a UTF-8 Python file or an inert fixture parsed with CPython 3.14.7. Upstream sources are sampled from release archives by sorting candidate paths and shuffling within project using seed 531960. Include at most 12 Unicode and four ASCII files per project. Include test files and fixtures used for legitimate software testing. Deduplicate original bytes across projects and require a successful AST parse. Babel and SymPy are development projects. Fixture families with indices 0 and 1 are development cases. The remaining projects and families form the evaluation partition. The feature families and fixture design were known during implementation, so the evaluation is exploratory.

Fixture labels encode the intended diagnostic target and reference character range. Upstream files form a provisionally benign reference cohort. Review unusual formatting controls and non-ASCII identifiers in context before running aggregate evaluation. Record ambiguous files separately and provide a sensitivity check including them. A source without those features remains provisionally benign by provenance and screening. No claim of dual independent author adjudication is made.

Primary outcomes are file sensitivity on positive fixtures and the file alert rate on the upstream Unicode cohort. Localized sensitivity requires a diagnostic of the same mechanism whose half-open Unicode code-point interval overlaps the reference. Negative control cohorts comprise matched Unicode fixtures, ASCII fixtures, and upstream ASCII files. Report counts for each mechanism and cohort separately. Parser failures are reported and treated as misses for localized sensitivity. On upstream files, report the alert rate over successful scans and report any missing scans. Each deterministic detector has one operating point.

Report paired D3 minus D1 and D3 minus D2 differences in percentage points. For exploratory 95% percentile intervals, resample whole projects in the upstream cohort and whole fixture families within mechanism in the positive cohort. Use 20,000 draws and a fixed random seed. For zero-disagreement comparisons, report the observed difference and withhold a degenerate interval. Report project-equal FPR as a sensitivity check. Report separate point estimates with each of D3's two changes enabled alone. Treat study intervals as descriptions of sampling variation under the resampling model for these cohorts. No confirmatory significance or noninferiority claim is planned.

Time each detector on the same preloaded upstream inputs, with one warmup and five timed repetitions in rotated order. Measure peak traced Python allocations with tracemalloc in a separate pass. Count lines on LF-normalized input, using only literal LF as a separator. Environment, byte counts, coverage and analysis exceptions are retained. Candidate source is parsed, never executed.

def ruff_batch(items):
    all_hits = {item['sample']: (set(), None) for item in items}
    with tempfile.TemporaryDirectory(prefix='unicode_ruff_') as temp:
        files = {}
        for i, item in enumerate(items):
            path = Path(temp)/f'{i}.py'
            path.write_bytes(item['source'].encode('utf-8'))
            files[path.name] = item
        run = subprocess.run([*RUFF, '.'], cwd=temp, capture_output=True, check=False)
        if run.returncode not in (0,1):
            raise RuntimeError(run.stderr.decode(errors='replace'))
        for diag in json.loads(run.stdout):
            item = files[Path(diag['filename']).name]
            hits, error = all_hits[item['sample']]
            rule = diag['code']
            if rule in ('invalid-syntax', 'E999') or rule is None:
                all_hits[item['sample']] = (hits, 'RuffSyntaxError')
                continue
            def offset(position):
                lines = item['source'].split('\n')
                row, col = position['row'], position['column']
                return sum(len(line)+1 for line in lines[:row-1])+col-1
            start, stop = offset(diag['location']), offset(diag['end_location'])
            hits.add((rule, 'bidi' if rule == 'PLE2502' else 'confusable', start, stop))
    return all_hits


def detect(arm, source):
    if arm.startswith(('plus_', 'D3+')):
        try:
            hits, coverage, recovered = ARMS[arm](source)
            return hits, coverage, None, recovered
        except (SyntaxError, ValueError, RecursionError, tokenize.TokenError) as error:
            return set(), None, type(error).__name__, None
    (hits, coverage), failure = legacy_scan(ARMS[arm], source)
    return hits, coverage, failure, None


def score(items):
    counts = subprocess.check_output(['ruff','--version'],text=True).strip()
    assert counts == 'ruff 0.15.0', counts
    external = ruff_batch(items)
    decisions, diagnostics, local = [], [], []
    for item in items:
        source = item['source']
        for arm in (*ARMS,'Ruff'):
            if arm == 'Ruff':
                hits, failure = external[item['sample']]
                coverage, recovered = None,None
            else:
                hits, coverage, failure, recovered = detect(arm,source)
            if failure:
                hits = set()
            labels = []
            for category, mechanism, start, stop in item['targets']:
                correct = any((m == mechanism or (mechanism == 'mixed' and rule == 'token_mixed_script'))
                              and a < stop and b > start for rule,m,a,b in hits)
                labels.append(correct)
                local.append(dict(sample=item['sample'], split=item['split'], cluster=item['cluster'],
                                  method=arm, category=category, localized=correct))
            decisions.append(dict(sample=item['sample'], split=item['split'], cluster=item['cluster'],
                kind=item['kind'], label=item['label'], method=arm, alert=bool(hits), error=failure,
                fallback=recovered, localized=all(labels) if labels else None, hits=len(hits),
                lines=source.count('\n')+int(not source.endswith('\n')),
                linked=coverage[0] if coverage else None, eligible=coverage[1] if coverage else None))
            for rule, mechanism, start, stop in sorted(hits):
                assert 0 <= start < stop <= len(source), (item['sample'], arm, rule, start, stop)
                diagnostics.append(dict(sample=item['sample'],method=arm,rule=rule,mechanism=mechanism,start=start,stop=stop))
    return tuple(pd.DataFrame(x) for x in (decisions,diagnostics,local))


def ratio(values):
    return [int(values.sum()),len(values)]

            good = g[g.error.isna()]
            pos = g[g.label.eq(1)]
            neg = good[good.kind.eq('unicode') & good.label.eq(0)]
            matched = good[good.kind.isin(['controlled','fixture']) & good.label.eq(0) & ~good['sample'].str.endswith('/plain')]
            sensitive = good[good.kind.eq('unicode')]
            methods[arm] = dict(sensitivity=ratio(pos.alert), localized=ratio(pos.localized),
                matched=ratio(matched.alert), upstream=ratio(neg.alert), upstream_inclusive=ratio(sensitive.alert),
                ascii=ratio(good[good.kind.eq('ascii')].alert), failure=ratio(g.error.notna()),
                fallback=ratio(g.fallback.notna()), linkage=[int(neg.linked.sum()),int(neg.eligible.sum())],
                project_equal=float(neg.groupby('cluster').alert.mean().mean()),
                density=float(1000*neg.hits.sum()/neg.lines.sum()),
                mechanism={k:ratio(v.localized) for k,v in local[local.split.eq(split)&local.method.eq(arm)].groupby('category')})
            controlled = good[good.kind.isin(['controlled','fixture']) & good.label.eq(0)]
            methods[arm]['controlled_confusion'] = dict(
                tp=int(pos.alert.sum()), fn=int((~pos.alert).sum()),
                fp=int(controlled.alert.sum()), tn=int((~controlled.alert).sum()),
                failed_negative=int((g.error.notna() & g.kind.isin(['controlled','fixture']) & g.label.eq(0)).sum()),
            )
            if len(pos) and pos['sample'].nunique() == pos.cluster.nunique():
                ci=binomtest(int(pos.localized.sum()),len(pos)).proportion_ci()
                methods[arm]['independent_fixture_exact_illustration']=[ci.low,ci.high]
        contrasts = {}
        for a,b in combinations(SELECTED,2):
            names=[a,b]
            pair=frame[frame.method.isin(names)]
            neg=pair[pair.kind.eq('unicode')&pair.label.eq(0)&pair.error.isna()]
            pos=pair[pair.label.eq(1)]
            contrasts[f'{b}-{a}']={'upstream':paired_interval(neg,'alert',b,a),
                                    'localized':paired_interval(pos,'localized',b,a,True),
                                    'sensitivity':paired_interval(pos,'alert',b,a,True)}
        summary[split]={'methods':methods,'contrasts':contrasts,'files':frame['sample'].nunique()}
    return summary


def queue(items, frame):
    groups={key:g for key,g in frame[frame.method.isin(SELECTED)].groupby('sample')}
    ordinary, flagged = [], []
    for item in items:
        if item['kind'] != 'unicode' or item['split'] not in ('holdout','legacy_evaluation'):
            continue
        g=groups[item['sample']]
        out={k:item[k] for k in ('sample','split','cluster','sha256','release','member')}
        out.update(reviewer='',reference_label='',reason='')
        (flagged if g.alert.any() or g.error.notna().any() else ordinary).append(out)
    rng=random.Random(81732)
    selected=flagged+rng.sample(ordinary,min(len(ordinary),32))
    return pd.DataFrame(sorted(selected,key=lambda r:r['sample']))


def uncertainty_bounds(frame, review):
    """Worst-case provisional rate if queued files may be removed as non-benign."""
    results={}
    for split in ('legacy_evaluation','holdout'):
        eligible=frame[frame.split.eq(split)&frame.kind.eq('unicode')&frame.label.eq(0)&frame.error.isna()]
        results[split]={}
        for method,g in eligible.groupby('method'):
            queued=g['sample'].isin(review['sample'])
            alerts=int(g.alert.sum()); count=len(g)
            remove_alert=int((queued & g.alert).sum())
            remove_clean=int((queued & ~g.alert).sum())
            results[split][method]=dict(queue_alerts=remove_alert,queue_clean=remove_clean,
                lower=[alerts-remove_alert,count-remove_alert], upper=[alerts,count-remove_clean])
    return results


def benchmark(items, repeats, host):
    sources=[i['source'] for i in items if i['split']=='holdout' and i['kind'] in ('ascii','unicode')]
    methods=SELECTED[:-1]
    def run_batch(name):
        for source in sources:
            detect(name,source)
    for name in methods:
        run_batch(name)
    samples={name:[] for name in methods}
    for i in range(repeats):
        for name in methods[i%len(methods):]+methods[:i%len(methods)]:
            start=perf_counter();run_batch(name);samples[name].append(perf_counter()-start)
    size=sum(len(s.encode()) for s in sources)
    stats={}
    for name, times in samples.items():
        tracemalloc.start()
        try:
            run_batch(name)
            _,peak=tracemalloc.get_traced_memory()
        finally:
            tracemalloc.stop()
        median=float(np.median(times))
        stats[name]=dict(seconds=times,median=median,min=min(times),max=max(times),
                         iqr=float(np.percentile(times,75)-np.percentile(times,25)),
                         peak_bytes=peak,mib_s=size/(2**20*median))
    return dict(host=host,os=platform.platform(),python=platform.python_version(),unicode=unicodedata.unidata_version,
                files=len(sources),bytes=size,repeats=repeats,methods=stats)


def plot(result):
    data=result['holdout']
    fig,axes=plt.subplots(1,2,figsize=(7,2.3),layout='constrained')
    for ax,key,title in zip(axes,('localized','upstream'),('All targets localized','Upstream Unicode files alerted')):
        values=[data['methods'][m][key] for m in SELECTED]
        bars=ax.barh(SELECTED,[100*n/d for n,d in values],color='#335D7A')
        ax.invert_yaxis();ax.set(xlim=(0,116),xlabel='Percent',title=title)
        ax.set_xticks([0,25,50,75,100]);ax.bar_label(bars,[f'{n}/{d}' for n,d in values],padding=3)
        ax.spines[['top','right']].set_visible(False)
    for ext in ('png','pdf'):
        fig.savefig(OUT/f'holdout.{ext}',dpi=260)
    plt.close(fig)


def main():
    parser=argparse.ArgumentParser()
    parser.add_argument('--freeze',action='store_true')
    parser.add_argument('--repeats',type=int,default=20)
    parser.add_argument('--host',default='See runtime OS and Python fields')
    args=parser.parse_args()
    warnings.filterwarnings('ignore',category=SyntaxWarning)
    lock=ROOT/'revision.lock.json'
    if args.freeze:
        with lock.open('x',encoding='utf-8') as out:
            json.dump(hashes(),out,indent=2)
        return
    assert hashes()==json.loads(lock.read_text(encoding='utf-8')), 'Frozen inputs differ'
    OUT.mkdir(exist_ok=True)
    items=inputs()
    metadata=[]
    for item in items:
        row={k:v for k,v in item.items() if k!='source'}
        row.setdefault('sha256',sha256(item['source'].encode()).hexdigest())
        metadata.append(row)
    (OUT/'manifest.jsonl').write_text(''.join(json.dumps(r,ensure_ascii=True)+'\n' for r in metadata),encoding='utf-8')
    decisions,diagnostics,local=score(items)
    review=queue(items,decisions)
    for name,frame in [('decisions',decisions),('diagnostics',diagnostics),('localization',local),('adjudication_queue',review)]:
        frame.to_csv(OUT/f'{name}.csv',index=False,lineterminator='\n')
    result=summarize(decisions,local)
    plot(result)
    result['queue_sensitivity']=uncertainty_bounds(decisions,review)
    result['benchmark']=benchmark(items,args.repeats,args.host)
    (OUT/'summary.json').write_text(json.dumps(result,indent=2,allow_nan=False)+'\n',encoding='utf-8')


if __name__=='__main__':

"""Build an annotation queue independent of detector verdicts."""
from collections import Counter
import json
import unicodedata as ud

from corpus import ROOT, corpus
from detect import tables, token_records


def main():
    _, _, bidi, ignorable, _ = tables()
    counts = Counter()
    output = ROOT / "review_queue.jsonl"
    with output.open("w", encoding="utf-8", newline="\n") as target:
        for item in corpus():
            if item["kind"] != "unicode":
                continue
            source = item["source"]
            names, _, _ = token_records(source)
            unusual = bidi | ignorable
            flags = [(index + 1, [f"U+{ord(char):04X}" for char in line if char in unusual], line[:280])
                     for index, line in enumerate(source.split("\n")) if any(char in unusual for char in line)]
            names = sorted({(name, line, ud.normalize("NFKC", name)) for name, _, line, _ in names
                            if not name.isascii()})
            counts["files"] += 1
            counts["flagged"] += bool(flags or names)
            if flags or names:
                target.write(json.dumps({"sample": item["sample"], "format": flags[:12], "names": names}) + "\n")
    print(dict(counts))


if __name__ == "__main__":
    main()

    CACHE.mkdir(exist_ok=True)
    with ThreadPoolExecutor(max_workers=6) as pool:
        if LOCK.exists():
            records = json.loads(LOCK.read_text(encoding="utf-8"))["projects"]
            list(pool.map(lambda r: cached(r["file"], r["url"], r["sha256"]), records))
            return
        config = json.loads((ROOT / "revised_sources.json").read_text(encoding="utf-8"))
        jobs = [pool.submit(resolve_project, project, split) for split, projects in config.items()
                for project in projects]
        records = [job.result() for job in jobs]
    LOCK.write_text(json.dumps({"projects": records}, indent=2) + "\n", encoding="utf-8")


def pair_layout(context, first, second, family):
    layouts = {
        "module": "{first} = 1\n{second} = 2\n",
        "function": "def neutral():\n    {first} = 1\n    {second} = 2\n",
        "class": "class Neutral:\n    {first} = 1\n    {second} = 2\n",
        "nested": "def outer():\n    def inner():\n        {first} = 1\n        {second} = 2\n",
        "comprehension": "neutral = [0 for {first}, {second} in ()]\n",
        "attribute": "def neutral(obj):\n    obj.{first} = 1\n    obj.{second} = 2\n",
    }
    return f'# Controlled diagnostic family {family}\n' + layouts[context].format(first=first, second=second)


def variants(family, split, context, positive, matched, targets):
    for name, text in (("positive", positive), ("matched", matched)):
        # Parse and validate the symbol table without executing the candidate.
        ast.parse(text)
        compile(text, '<fixture>', 'exec', dont_inherit=True)
        yield record(f"{family}/{name}", split, family, 'controlled', text,
                     variant=name, label=int(name == 'positive'), context=context,
                     targets=targets if name == 'positive' else [], sha256=sha256(text.encode()).hexdigest())

                # ordinary constant assignments keep the intended source spelling unambiguous.

                    benign = '\u2067שלום\u2069'

        family = f'mixed-{i:02}'

def upstream(old):
    seen = {r['sha256'] for r in old if 'sha256' in r}
    normalized = {sha256(r['source'].encode()).digest() for r in old}
    lock = json.loads(LOCK.read_text(encoding='utf-8'))
    for item in natural(lock):
        key = sha256(item['source'].encode()).digest()
        if item['sha256'] in seen or key in normalized:
            continue
        normalized.add(key)
        item['label'] = 0
        item['review'] = 'provisional_negative'
        item['targets'] = []
        yield item

"""Run the exploratory study and write auditable results without source excerpts."""
from collections import Counter
from functools import partial
from hashlib import sha256
import json
import os
from pathlib import Path
import platform
from time import perf_counter
import tokenize
import tracemalloc
import warnings

import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from sklearn.metrics import confusion_matrix

from corpus import ROOT, corpus
from detect import lexical_detector, raw_detector, tables

DETECTORS = {
    "D1": raw_detector,
    "D2": lexical_detector,
    "D3": partial(lexical_detector, scoped=True, contextual=True),
    "scope_only": partial(lexical_detector, scoped=True),
    "text_only": partial(lexical_detector, contextual=True),
}
OUT = ROOT / "results"


def scan(method, source):
    try:
        return method(source), None
    except (SyntaxError, ValueError, tokenize.TokenError, RecursionError) as error:
        return (set(), None), type(error).__name__


def rows(items):
    diagnostics = []
    scores = []
    for item in items:
        source = item["source"]
        positive = item["label"] == 1
        for name, method in DETECTORS.items():
            (hits, coverage), error = scan(method, source)
            row = {key: value for key, value in item.items() if key not in {"source", "span"}}
            row.update(method=name, lines=source.count("\n") + int(not source.endswith("\n")),
                       n_hits=len(hits), alert=bool(hits), error=error,
                       linked=coverage[0] if coverage else None, eligible=coverage[1] if coverage else None)
            if positive:
                lower, upper = item["span"]
                row["localized"] = any(m == item["mechanism"] and start < upper and stop > lower
                                       for _, m, start, stop in hits)
            scores.append(row)
            for rule, mechanism, start, stop in sorted(hits, key=lambda hit: (hit[2], hit[3], hit[0])):
                diagnostics.append({"sample": item["sample"], "split": item["split"], "method": name,
                                    "rule": rule, "mechanism": mechanism,
                                    "line": source.count("\n", 0, start) + 1,
                                    "start": start, "stop": stop})
    return pd.DataFrame(scores), pd.DataFrame(diagnostics)


def paired_interval(frame, outcome, left, right, stratified=False):
    paired = frame.pivot(index=["sample", "cluster"], columns="method", values=outcome)
    paired = paired[[left, right]].dropna()
    difference = (paired[left].astype(int) - paired[right].astype(int)).rename("difference")
    groups = difference.groupby(level="cluster").agg(["sum", "size"])
    estimate = float(difference.mean())
    result = {"difference": estimate, "low": None, "high": None,
              "left_only": int((difference == 1).sum()), "right_only": int((difference == -1).sum()),
              "n": len(difference), "clusters": len(groups)}
    if difference.nunique() < 2 or len(groups) < 2:
        return result
    strata = list(groups.groupby(groups.index.str.rsplit("-", n=1).str[0])) if stratified else [(None, groups)]
    rng = np.random.default_rng(17324)
    numerator = np.zeros(20_000, dtype=float)
    denominator = np.zeros(20_000, dtype=float)
    for _, group in strata:
        sampled = rng.integers(len(group), size=(20_000, len(group)))
        numerator += group["sum"].to_numpy()[sampled].sum(axis=1)
        denominator += group["size"].to_numpy()[sampled].sum(axis=1)
    low, high = np.quantile(numerator / denominator, [0.025, 0.975])
    return {**result, "low": float(low), "high": float(high)}


def benchmark(items):
    sources = [item["source"] for item in items if item["split"] == "evaluation" and item["kind"] != "fixture"]
    methods = list(DETECTORS)[:3]

    def batch(name):
        for source in sources:
            scan(DETECTORS[name], source)

    timings = {name: [] for name in methods}
    for name in methods:
        batch(name)
    for repeat in range(5):
        for name in methods[repeat % 3:] + methods[:repeat % 3]:
            start = perf_counter()
            batch(name)
            timings[name].append(perf_counter() - start)
    measurements = {}
    size = sum(len(source.encode("utf-8")) for source in sources)
    for name in methods:
        tracemalloc.start()
        try:
            batch(name)
            _, peak = tracemalloc.get_traced_memory()
        finally:
            tracemalloc.stop()
        median = float(np.median(timings[name]))
        measurements[name] = {"seconds": timings[name], "median_seconds": median,
                              "peak_traced_bytes": peak, "mib_per_second": size / (1024**2 * median)}
    return {"files": len(sources), "utf8_bytes": size, "methods": measurements}


def annotate(items):
    review = json.loads((ROOT / "annotations.json").read_text(encoding="utf-8"))
    for item in items:
        if item["kind"] == "fixture":
            continue
        item["review"] = review["exceptions"].get(item["sample"], {}).get("status", "provisional_negative")
        if item["review"] == "provisional_negative":
            item["label"] = 0
    return review


def main():
    warnings.filterwarnings("ignore", category=SyntaxWarning)
    OUT.mkdir(exist_ok=True)
    tables()
    items = corpus()
    annotate(items)
    with (OUT / "manifest.jsonl").open("w", encoding="utf-8", newline="\n") as stream:
        for item in items:
            fields = {key: value for key, value in item.items() if key != "source"}
            fields.setdefault("sha256", sha256(item["source"].encode("utf-8")).hexdigest())
            stream.write(json.dumps(fields, sort_keys=True) + "\n")
    scores, diagnostics = rows(items)
    scores.to_csv(OUT / "decisions.csv", index=False)
    diagnostics.to_csv(OUT / "diagnostics.csv", index=False)
    fixture = scores[scores.kind.eq("fixture")]
    eval_scores = scores[scores.split.eq("evaluation")]
    positive = eval_scores[eval_scores.label.eq(1)]
    upstream = eval_scores[eval_scores.kind.eq("unicode") & eval_scores.label.eq(0)]
    successful = upstream[upstream.error.isna()]
    methods = {}
    for name in DETECTORS:
        def select(data):
            return data[data.method.eq(name)]

        pos = select(positive)
        neg = select(successful)
        local = pos.groupby("mechanism").localized.agg(["sum", "size"])
        controls = select(eval_scores[eval_scores.label.eq(0) & ~eval_scores.kind.eq("unicode")]).copy()
        controls["cohort"] = controls.variant.fillna(controls.kind)
        controls["scanned"] = controls.error.isna()
        ctrl_counts = controls.groupby("cohort").agg(alerts=("alert", "sum"),
                                                      scanned=("scanned", "sum"), total=("alert", "size"))
        cm = confusion_matrix([0] * len(neg) + [1] * len(pos),
                              [*neg.alert, *pos.alert], labels=[0, 1])
        evaluated = select(eval_scores)
        methods[name] = {"tp": int(pos.alert.sum()), "positive": len(pos),
                         "localized": int(pos.localized.sum()), "fp": int(neg.alert.sum()),
                         "unicode": len(neg), "fpr_project_equal": float(neg.groupby("cluster").alert.mean().mean()),
                         "unicode_all": int(select(eval_scores[eval_scores.kind.eq("unicode")]).alert.sum()),
                         "unicode_all_n": len(select(eval_scores[eval_scores.kind.eq("unicode")])),
                         "false_alerts_per_1000_lines": float(1000 * neg.n_hits.sum() / neg.lines.sum()),
                         "local_by_mechanism": local.astype(int).to_dict(orient="index"),
                         "controls": ctrl_counts.astype(int).to_dict(orient="index"), "cm": cm.tolist(),
                         "errors": int(evaluated.error.notna().sum()),
                         "linked": int(neg.linked.sum()), "eligible": int(neg.eligible.sum())}
    contrasts = {f"D3-{right}": {"fpr": paired_interval(successful, "alert", "D3", right),
                                "tpr": paired_interval(positive, "alert", "D3", right, True),
                                "localized": paired_interval(positive, "localized", "D3", right, True)}
                 for right in ("D1", "D2")}
    summary = {"methods": methods, "contrasts": contrasts, "benchmark": benchmark(items),
               "counts": dict(Counter(f"{item['split']}/{item['kind']}" for item in items)),
               "platform": platform.platform(), "python": platform.python_version(),
               "processor": os.environ.get("PROCESSOR_IDENTIFIER", platform.processor()),

        axis.spines[["top", "right"]].set_visible(False)
    figure.savefig(OUT / "comparison.pdf")
    figure.savefig(OUT / "comparison.png", dpi=240)

"""Cross-check the published outputs against frozen sample-level results."""
import argparse
import json
from pathlib import Path
from zipfile import ZipFile

from lxml import etree
import pandas as pd
from pypdf import PdfReader

from revalidate import OUT, SELECTED, hashes, summarize, uncertainty_bounds
from revised_manuscript import fraction, interval

WORD = {'w':'http://schemas.openxmlformats.org/wordprocessingml/2006/main'}


def check_manuscript(source, target, pdf):
    with ZipFile(source) as original,ZipFile(target) as revised:
        changed = {name for name in original.namelist() if original.read(name)!=revised.read(name)}
        assert changed == {'word/document.xml','word/media/image2.png'}, changed
        assert set(original.namelist()) == set(revised.namelist())
        a,b = (etree.fromstring(z.read('word/document.xml')) for z in (original,revised))
        def nodes(root, query):
            return [etree.tostring(x,method='c14n',exclusive=True) for x in root.xpath(query,namespaces=WORD)]
        block = 'w:body/w:p[position() >= 3 and position() <= 8]'
        assert nodes(a,block)==nodes(b,block)
        assert nodes(a,'.//w:sectPr')==nodes(b,'.//w:sectPr')
        tables=[]
        for table in b.xpath('w:body/w:tbl',namespaces=WORD):
            tables.append([[''.join(c.xpath('.//w:t/text()',namespaces=WORD)) for c in row.xpath('w:tc',namespaces=WORD)]
                           for row in table.xpath('w:tr',namespaces=WORD)])
        abstract=''.join(b.xpath('w:body/w:p[starts-with(string(w:r[1]/w:t), "Abstract")]/w:r/w:t/text()',namespaces=WORD))
        assert 200 <= len(abstract.split())-2 <= 250
        assert revised.read('word/media/image2.png')==(OUT/'holdout.png').read_bytes()
    doc=PdfReader(pdf)
    assert 3<=len(doc.pages)<=7
    assert all(p.extract_text().strip() for p in doc.pages)
    return tables,len(doc.pages),abstract


def main():
    parser=argparse.ArgumentParser()
    parser.add_argument('--template',type=Path)
    parser.add_argument('--docx',type=Path)
    parser.add_argument('--pdf',type=Path)
    args=parser.parse_args()
    summary=json.loads((OUT/'summary.json').read_text())
    assert hashes()==json.loads((OUT.parent/'revision.lock.json').read_text())
    decisions=pd.read_csv(OUT/'decisions.csv')
    local=pd.read_csv(OUT/'localization.csv')
    diagnostics=pd.read_csv(OUT/'diagnostics.csv')
    outcomes=decisions.set_index(['sample','method'])
    counts=diagnostics.groupby(['sample','method']).size().reindex(outcomes.index,fill_value=0)
    assert counts.eq(outcomes.hits).all()
    assert counts.gt(0).eq(outcomes.alert).all()
    recalculated=summarize(decisions,local)
    assert all(summary[key]==val for key,val in recalculated.items())
    review=pd.read_csv(OUT/'adjudication_queue.csv')
    assert summary['queue_sensitivity']==uncertainty_bounds(decisions,review)
    manifest=[json.loads(row) for row in (OUT/'manifest.jsonl').read_text().splitlines()]
    assert len(manifest)==len({row['sample'] for row in manifest})
    assert not decisions.duplicated(['sample','method']).any()
    assert set(decisions['sample'])=={row['sample'] for row in manifest}
    assert len(decisions)==9*len(manifest)
    targets={row['sample']:row['targets'] for row in manifest}
    found={(k[0],k[1]):list(g.itertuples()) for k,g in diagnostics.groupby(['sample','method']) if targets[k[0]]}
    local_lookup=local.groupby(['sample','method'],sort=False)
    for key,group in local_lookup:
        expected=[any((hit.mechanism==mechanism or (mechanism=='mixed' and hit.rule=='token_mixed_script'))
                      and hit.start < stop and hit.stop > start for hit in found.get(key,[]))
                  for _,mechanism,start,stop in targets[key[0]]]
        assert expected==group.localized.tolist()
        assert all(expected)==outcomes.loc[key,'localized']
    counts=decisions.groupby('split')['sample'].nunique().to_dict()
    print(f'Raw decisions: {len(decisions)}. Partition sizes: {counts}.')
    if args.docx is not None:
        assert args.template and args.pdf
        tables,pages,abstract=check_manuscript(args.template,args.docx,args.pdf)
        methods=summary['holdout']['methods']
        assert tables[0][1:]==[[m,*(fraction(methods[m][key]) for key in ('sensitivity','localized','upstream'))] for m in SELECTED]
        assert len(tables)==4
        assert tables[1][1:]==[[m,' / '.join(fraction(methods[m]['mechanism'][k]) for k in ('bidi','confusable','ignorable')),
                               ' / '.join(fraction(methods[m]['mechanism'][k]) for k in ('nfkc','combining','variation')),
                               fraction(methods[m]['mechanism']['mixed-script'])] for m in SELECTED]
        assert [r[1:] for r in tables[2][1:]]==[[fraction(methods[m][k]) for k in ('localized','upstream','matched')]
            for m in ('D2','scope_only','text_only','D3','plus_scope','plus_text','D3+')]
        assert tables[3][1:]==[[m,f"{r['median']:.3f} ({r['iqr']:.3f})",f"{r['min']:.3f}–{r['max']:.3f}",f"{r['peak_bytes']/2**20:.2f}"]
                               for m,r in summary['benchmark']['methods'].items()]
        for key in ('localized','upstream'):
            assert ', '.join(fraction(methods[m][key]) for m in SELECTED) in abstract
        assert interval(summary['holdout']['contrasts']['D3+-D3']['upstream']) in abstract
        print(f'Word template, author block, manuscript table and PDF verified. Pages: {pages}.')


if __name__=='__main__':
    main()
