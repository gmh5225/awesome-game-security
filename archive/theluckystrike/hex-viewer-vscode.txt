```md
# Changelog

## 0.1.0 (2026-11-08)

First release.

- Opens any file: right-click "Open in Hex Viewer", the editor title menu, or "Reopen Editor With...". Default editor for .bin, .dat, .img, .rom, .dmp and .dump.
- Files of any size: range reads, rows drawn on demand and a scroll bar that reaches the end of a 4 GB or larger file.
- Go to offset in hex, decimal or relative (Ctrl+G), with the cursor offset in the status bar.
- Find hex bytes (with ?? wildcards), text and UTF-16 text, forward and back, across the whole file.
- Copy as hex, C array, Python bytes, base64 or text.
- Data inspector: integers from 8 to 64 bits, float16/32/64, LEB128, Unix time, FILETIME, GUID, UTF-8 and UTF-16, little or big-endian.
- Byte editing in overwrite mode with undo, redo, save in place and Save As. Read-only files open as view only.
- 8 to 64 bytes per row; ASCII, Latin-1, UTF-8, UTF-16 and EBCDIC text column.
- Clear messages for empty files, files without read permission, link loops and files that change on disk while open.
```

`README.md`:

```md
# Hex Viewer & Binary Viewer, Hex Editor (Large Files)

![License MIT](https://img.shields.io/badge/license-MIT-blue)
![Works offline](https://img.shields.io/badge/network-none-green)
![Any file size](https://img.shields.io/badge/files-4%20GB%2B-orange)

Free, no sign-in, works offline. See and edit the bytes of any file in VS Code, from a 0-byte file to a 4 GB disk image, with go to offset, search, a data inspector and copy as hex, C array, Python bytes or base64.

![A PNG file open in Hex Viewer inside VS Code. Bytes 0x10 to 0x13 of the IHDR chunk are selected, and the data inspector on the right reads them as big-endian uint32 1400, the image width. The toolbar has Go to offset, Find with Hex, Text and UTF-16 modes, bytes per row, the text encoding and Copy as. The status line shows the offset, the selection, PNG image, 134.5 KB and Overwrite.](https://github.com/theluckystrike/hex-viewer-vscode/raw/HEAD/images/hex-viewer-png.png)

*Real output from VS Code 1.142 on macOS. The file is `robot-arm.png`. `scripts/e2e-vscode.mjs` installed the packaged extension in a clean VS Code profile, opened the file and saved the window through the debug port.*

- Big files open at once. Only the rows on screen are read, in 64 KB pieces. In the release check a 4 GB file opened in 0.6 s, Ctrl+End went to its last byte, and the extension host used 127 MB.
- You can get anywhere. Go to an offset in hex or decimal, or jump by `+0x100` or `-16`. Find hex bytes with `??` wildcards, text, or UTF-16 text. The status bar shows the offset of the cursor.
- Editing stays put. Type two hex digits to overwrite a byte; the cursor moves one byte and stops. Each byte is one undo step. Save writes only the changed bytes.

## Quick start

1. Install Hex Viewer.
2. Right-click any file in the Explorer and pick "Open in Hex Viewer". Files that end in `.bin`, `.dat`, `.img`, `.rom`, `.dmp` or `.dump` open in Hex Viewer when you click them.

For a file that is already open, use "Open in Hex Viewer" in the editor title menu (`...`) or the tab's right-click menu, or "Reopen Editor With...". Text files such as `.txt`, `.ts` and Intel `.hex` files still open in the text editor. "Hex Viewer: Get Started" in the Command Palette opens a short tour.

## Large files

![A 4 GB sparse file at its last row, offset 0x100000030, with LASTBYTE in the text column. The row above shows NEAR-THE-4GB-EDGE at offset 0xFFFFFFF0.](https://github.com/theluckystrike/hex-viewer-vscode/raw/HEAD/images/big-4gb-end.png)

- Local files of any size open. The extension never reads the whole file: it reads the rows you look at, and Find reads the file in 1 MB pieces.
- The scroll bar is drawn by the viewer, so it reaches the last row of a 4 GB or larger file. Drag it, use the mouse wheel, Page Up and Page Down, or Ctrl+Home and Ctrl+End.
- If the file changes on disk while it is open, the view shows the new bytes. If it got shorter, a message gives the old and new size and the view moves to the new end. Nothing crashes and nothing goes blank.
- Empty files and files you have no permission to read show a plain message instead of a blank tab.
- Files on remote and virtual file systems open up to 256 MB (setting `hexViewer.maxRemoteMB`).

## Find, go to and copy

![firmware.bin with the 6 bytes DE AD BE EF 13 37 found at offset 0x2FFFD, across a 64 KB edge. The match is highlighted in the hex and text columns and the toolbar says Match at 0x2FFFD.](https://github.com/theluckystrike/hex-viewer-vscode/raw/HEAD/images/find-across-64k.png)

| Action | Keys | Notes |
|---|---|---|
| Go to offset | Ctrl+G (Cmd+G) | `0x1F40`, `1F40h`, `8000`, `+0x100`, `-16`, `end`, `end-15`. Also the box at the left of the toolbar, and a click on the status bar. |
| Find | Ctrl+F (Cmd+F) | Hex `50 4B 03 04` with `??` for any byte, text (with Aa to ignore case) or UTF-16. Unsaved edits are found too. |
| Next, previous match | Enter, Shift+Enter, F3, Shift+F3 | The search goes on from the start after the end. Esc stops a long search. |
| Copy | Ctrl+C (Cmd+C) | Hex with spaces from the hex column (setting `hexViewer.copyFormat`), text from the text column |
| Copy as... | toolbar | Hex, hex with spaces, C array, Python bytes, base64, UTF-8 text, Latin-1 text. Up to 32 MB. |
| Select | Shift + arrows, Page Up, Page Down, Home, End; drag; Ctrl+A | |
| Switch column | Tab | Between the hex and the text column |

## Data inspector

The panel on the right reads the bytes at the cursor, or at the start of the selection, as:

- the offset in hex and decimal, binary and octal
- uint8, int8, uint16, int16, uint24, uint32, int32, uint64, int64
- float16, float32, float64
- ULEB128 and SLEB128, with their length
- Unix time (32 and 64-bit) and Windows FILETIME
- a GUID, and a UTF-8 and UTF-16 character with its code point

Click "Little-endian" to switch to big-endian. In the release check, the values at 5 offsets were the same as Python's `struct` and `uuid` modules.

## Edit bytes

![edit-me.bin after typing AB CD 12 at offset 0x10. The three edited bytes are colored and the tab shows unsaved changes.](https://github.com/theluckystrike/hex-viewer-vscode/raw/HEAD/images/edited-3-bytes.png)

- Type hex digits in the hex column, or characters in the text column, to overwrite bytes. Edited bytes are colored until you save.
- Paste hex (`4A 5B 00`, `0x4A, 0x5B` or `\x4a\x5b`) with Ctrl+V to overwrite from the cursor.
- Ctrl+Z undoes one byte, Ctrl+Shift+Z redoes, and Ctrl+S saves. Save writes only the changed bytes into the file, so it is fast on a 4 GB file. Save As writes a full copy.
- Overwrite only: bytes are not inserted or deleted, so the file size does not change.
- Read-only files open as view only. Set `hexViewer.readOnly` to turn editing off for every file.

## Display

![The same PNG in the light theme at 16 bytes per row, with the cursor on offset 0x10.](https://github.com/theluckystrike/hex-viewer-vscode/raw/HEAD/images/light-theme.png)

- 8, 16, 24, 32, 48 or 64 bytes per row.
- Text column in ASCII, Latin-1, UTF-8, UTF-16 LE, UTF-16 BE or EBCDIC (code page 037). Control bytes show as a dot or as symbols such as ␀ and ␊.
- The file type from its first bytes in the status line: PNG, JPEG, ZIP, PDF, SQLite, ELF, Mach-O, PE, Java class, WAV, WebAssembly and more.
- The editor font, the theme colors in dark and light themes, and the editor font size (or `hexViewer.fontSize`).
- Screen readers hear the offset and value of the byte under the cursor.

## Settings

| Setting | Default | What it does |
|---|---|---|
| `hexViewer.bytesPerRow` | 16 | Bytes in each row when a file opens |
| `hexViewer.encoding` | ascii | Text column encoding when a file opens |
| `hexViewer.controlChars` | dot | Show control bytes as a dot or as symbols |
| `hexViewer.uppercase` | true | 4A or 4a |
| `hexViewer.fontSize` | 0 | Font size of the byte grid; 0 uses the editor font size |
| `hexViewer.copyFormat` | hexSpaced | What Ctrl+C copies from the hex column |
| `hexViewer.littleEndian` | true | Byte order of the data inspector |
| `hexViewer.showInspector` | true | Show the data inspector when a file opens |
| `hexViewer.readOnly` | false | Turn off byte editing |
| `hexViewer.maxRemoteMB` | 256 | Largest file from a remote or virtual file system |
| `hexViewer.askForRating` | true | Ask one time for a Marketplace rating after a few days of use. Nothing is sent anywhere. |
| `hexViewer.showSupportLinks` | true | Show the small Sponsor and More free viewers links in the status line |

## Privacy and safety

The extension makes no network calls and has no telemetry. It writes to a file only when you save. The webview runs under a strict Content Security Policy (`default-src 'none'`, scripts by nonce, no remote sources) and gets bytes only from the extension host.

## Limits

- Overwrite only. Insert and delete come in a later version.
- No structure templates yet (PNG chunks, ZIP entries, ELF and PE headers).
- Copy as... works up to 32 MB, and a paste up to 16 MB.
```

```py
"""Make the sample files for the real VS Code check (scripts/e2e-vscode.mjs).

usage: python3 -I scripts/make_samples.py <dir> [--big]

Small real files of common binary types, two text files that must keep opening in the text editor,
```

```mjs
class Session {
  static async connect(url) {
    const s = new Session(); s.ws = new WebSocket(url); s.id = 0; s.pend = new Map(); s.handlers = [];
    s.ws.onmessage = e => { const m = JSON.parse(e.data); if (m.id && s.pend.has(m.id)) { s.pend.get(m.id)(m); s.pend.delete(m.id); } else if (m.method) for (const h of s.handlers) h(m); };
    await new Promise((r, j) => { s.ws.onopen = r; s.ws.onerror = j; });
    return s;
  }
  send(method, params = {}, sessionId) {
    return new Promise((r, j) => { const i = ++this.id; const t = setTimeout(() => { this.pend.delete(i); j(new Error('timeout ' + method)); }, 30000);
      this.pend.set(i, m => { clearTimeout(t); m.error ? j(new Error(method + ': ' + JSON.stringify(m.error))) : r(m.result); });
      this.ws.send(JSON.stringify({ id: i, method, params, ...(sessionId ? { sessionId } : {}) })); });
  }
  on(h) { this.handlers.push(h); }
  close() { try { this.ws.close(); } catch {} }
}
```

```js
'use strict';
// The open file and its unsaved byte edits. No vscode import, so tests run it on real files.
// Local files are read in ranges (fs read at an offset), never as a whole. Other file systems
// (remote, virtual) come in through a reader callback with a size cap set by the caller.
const fs = require('fs');
const { preparePattern, findForward, findBackward, lowerAscii } = require('./bytes');

const CHUNK = 1 << 20; // 1 MB per read while searching or saving

class FileSource {
  constructor(fsPath) { this.path = fsPath; this.fh = null; }
  async handle() {
    if (!this.fh) this.fh = await fs.promises.open(this.path, 'r');
    return this.fh;
  }
  async stat() { return fs.promises.stat(this.path); }
  async read(offset, length) {
    if (length <= 0) return new Uint8Array(0);
    const fh = await this.handle();
    const buf = Buffer.allocUnsafe(length);
    let got = 0;
    while (got < length) {
      const { bytesRead } = await fh.read(buf, got, length - got, offset + got);
      if (!bytesRead) break;
      got += bytesRead;
    }
    return new Uint8Array(buf.buffer, buf.byteOffset, got);
  }
  async writable() {
    try { await fs.promises.access(this.path, fs.constants.W_OK); return true; } catch { return false; }
  }
  async reopen() { await this.close(); }
  async close() { const fh = this.fh; this.fh = null; if (fh) try { await fh.close(); } catch {} }
}

class MemorySource {
  constructor(bytes, writeAll) { this.bytes = bytes; this.writeAll = writeAll || null; }
  async stat() { return { size: this.bytes.length }; }
  async read(offset, length) {
    const end = Math.min(this.bytes.length, offset + Math.max(0, length));
    return offset >= end ? new Uint8Array(0) : this.bytes.slice(offset, end);
  }
  async writable() { return !!this.writeAll; }
  async reopen() {}
  async close() {}
}

class HexDocument {
  /** source: FileSource or MemorySource. size: bytes at open time. */
  constructor(source, size) {
    this.source = source;
    this.size = size;
    this.edits = new Map(); // offset -> byte value that differs from (or was typed over) the file on disk
    this._sorted = null;
    this.gen = 0; // bumps on save and revert: older undo records then write values instead of dropping edits
  }

  static async openFile(fsPath) {
    const src = new FileSource(fsPath);
    const st = await src.stat();
    if (st.isDirectory && st.isDirectory()) throw Object.assign(new Error('This is a folder, not a file.'), { code: 'EISDIR' });
    await src.handle(); // fails here with EACCES when the file cannot be read
    return new HexDocument(src, st.size);
  }

  static fromBytes(bytes, writeAll) { return new HexDocument(new MemorySource(bytes, writeAll), bytes.length); }

  get isFile() { return this.source instanceof FileSource; }

  sortedEdits() {
    if (!this._sorted) this._sorted = Float64Array.from(this.edits.keys()).sort();
    return this._sorted;
  }

  /** Put the unsaved edits over bytes read from `offset`. */
  overlay(bytes, offset) {
    if (!this.edits.size || !bytes.length) return bytes;
    const keys = this.sortedEdits();
    let lo = 0, hi = keys.length;
    while (lo < hi) { const m = (lo + hi) >> 1; if (keys[m] < offset) lo = m + 1; else hi = m; }
    const end = offset + bytes.length;
    let copied = false;
    for (let i = lo; i < keys.length && keys[i] < end; i++) {
      if (!copied) { bytes = Uint8Array.from(bytes); copied = true; }
      bytes[keys[i] - offset] = this.edits.get(keys[i]);
    }
    return bytes;
  }

  /** Bytes [offset, offset+length) with edits applied. Shorter than asked when the file ends (or shrank on disk). */
  async read(offset, length) {
    const len = Math.max(0, Math.min(length, this.size - offset));
    const raw = await this.source.read(offset, len);
    return this.overlay(raw, offset);
  }

  /** Edited offsets in [offset, offset+length), for highlighting. */
  editedIn(offset, length) {
    if (!this.edits.size) return [];
    const keys = this.sortedEdits();
    let lo = 0, hi = keys.length;
    while (lo < hi) { const m = (lo + hi) >> 1; if (keys[m] < offset) lo = m + 1; else hi = m; }
    const out = [];
    for (let i = lo; i < keys.length && keys[i] < offset + length; i++) out.push(keys[i]);
    return out;
  }

  /**
   * Overwrite bytes at `offset` with `values`. Returns the undo record { offset, before, after } or null when
   * nothing changed. Bytes past the end of the file are dropped (overwrite never grows the file).
   */
  async overwrite(offset, values) {
    if (offset < 0 || offset >= this.size) return null;
    const n = Math.min(values.length, this.size - offset);
    if (n <= 0) return null;
    const before = await this.read(offset, n);
    if (before.length < n) throw new Error('The file got shorter on disk. Close and open it again before you edit.');
    const after = Uint8Array.from(values.subarray ? values.subarray(0, n) : values.slice(0, n));
    let same = true;
    for (let i = 0; i < n; i++) if (before[i] !== after[i]) { same = false; break; }
    if (same) return null;
    const prev = new Uint8Array(n);
    for (let i = 0; i < n; i++) prev[i] = this.edits.has(offset + i) ? 1 : 0;
    const rec = { offset, before: Uint8Array.from(before), after, prev, gen: this.gen };
    this.apply(rec, false);
    return rec;
  }

  /** Apply (undo = false) or roll back (undo = true) a record from overwrite(). */
  apply(rec, undo) {
    const v = undo ? rec.before : rec.after;
    // Undo in the same save generation drops the edit mark where there was none, so the byte is plain again.
    const drop = undo && rec.prev && rec.gen === this.gen;
    for (let i = 0; i < v.length; i++) {
      if (drop && !rec.prev[i]) this.edits.delete(rec.offset + i);
      else this.edits.set(rec.offset + i, v[i]);
    }
    this._sorted = null;
  }

  async writable() { return this.source.writable(); }

  /** Write the edits into the file. Local files are patched in place (only the edited bytes are written). */
  async save() {
    if (!this.edits.size) return;
    if (this.source instanceof FileSource) {
      const st = await this.source.stat();
      const keys = this.sortedEdits();
      if (keys[keys.length - 1] >= st.size) throw new Error(`The file on disk is now ${st.size} bytes, shorter than the edits. Nothing was saved.`);
      await this.source.close();
      const fh = await fs.promises.open(this.source.path, 'r+');
      try {
        for (let i = 0; i < keys.length;) {
          let j = i;
          while (j + 1 < keys.length && keys[j + 1] === keys[j] + 1 && j - i < CHUNK) j++;
          const buf = Buffer.alloc(j - i + 1);
          for (let k = i; k <= j; k++) buf[k - i] = this.edits.get(keys[k]);
          await fh.write(buf, 0, buf.length, keys[i]);
          i = j + 1;
        }
        await fh.sync();
      } finally { await fh.close(); }
    } else {
      if (!this.source.writeAll) throw new Error('This file system is read-only.');
      const all = this.overlay(await this.source.read(0, this.size), 0);
      await this.source.writeAll(all);
      this.source.bytes = all;
    }
    this.edits.clear();
    this._sorted = null;
    this.gen++;
  }

  /** Write the whole file with edits to another local path, in 1 MB pieces. */
  async saveAsFile(targetPath) {
    const tmp = targetPath + '.hexviewer-tmp';
    const fh = await fs.promises.open(tmp, 'w');
    try {
      for (let off = 0; off < this.size; off += CHUNK) {
        const b = await this.read(off, Math.min(CHUNK, this.size - off));
        if (b.length < Math.min(CHUNK, this.size - off)) throw new Error('The file got shorter while it was copied.');
        await fh.write(b, 0, b.length, off);
      }
      await fh.sync();
    } catch (e) { await fh.close(); await fs.promises.rm(tmp, { force: true }); throw e; }
    await fh.close();
    await fs.promises.rename(tmp, targetPath);
  }

  /** All bytes with edits, for non-local Save As. Callers cap the size. */
  async readAll() { return this.read(0, this.size); }

  revert() { this.edits.clear(); this._sorted = null; this.gen++; }

  /** Re-read the size from disk (after a change on disk). Returns the new size. */
  async refresh() {

  /**
   * Find `pattern` (from parsePattern) starting at `from` (forward: first match at >= from; backward: last match
   * at <= from). wrap: continue from the other end once. shouldStop(): true to cancel. progress(done, total).
   * Returns { offset } or { offset: -1, cancelled? }.
   */
  async search(pattern, from, backward, wrap, shouldStop = () => false, progress = () => {}) {
    const pp = preparePattern(pattern);
    const len = pp.len;
    const size = this.size;
    if (len > size) return { offset: -1 };
    const plain = !pp.mask;
    const needle = Buffer.from(pp.pat);
    let scanned = 0, lastReport = Date.now();
    const lower = b => { const c = Buffer.from(b); for (let i = 0; i < c.length; i++) c[i] = lowerAscii(c[i]); return c; };
    const prep = b => (pp.ic ? lower(b) : Buffer.from(b.buffer, b.byteOffset, b.length));
    const tick = async n => {
      scanned += n;
      if (Date.now() - lastReport > 250) { lastReport = Date.now(); progress(scanned, size); await new Promise(r => setImmediate(r)); }
    };
    // A wildcard pattern is checked byte by byte, so a long one on uniform data (zeros) costs up to len
    // compares per position. Scan such chunks in slices of about 4M compares and yield in between, so the
    // extension host stays responsive and a cancel takes effect within one slice.
    const slice = Math.max(1024, Math.floor((4 << 20) / len));
    const STOP = -2;
    let lastYield = Date.now();
    const sliced = async (fn, s0, end, stepBy) => {
      for (let s = s0; stepBy > 0 ? s < end : s > end; s += stepBy) {
        const i = fn(s);
        if (i >= 0) return i;
        if (Date.now() - lastYield > 30) {
          await new Promise(r => setImmediate(r)); lastYield = Date.now();
          if (shouldStop()) return STOP;
        }
      }
      return -1;
    };
    // forward over [a, b): matches starting in [a, b)
    const fwd = async (a, b) => {
      for (let pos = a; pos < b; pos += CHUNK) {
        if (shouldStop()) return { offset: -1, cancelled: true };
        const want = Math.min(CHUNK, b - pos) + len - 1;
        const buf = prep(await this.read(pos, want));
        const lim = Math.min(buf.length, (b - pos) + len - 1);
        const i = plain ? buf.subarray(0, lim).indexOf(needle) : await sliced(s => findForward(buf, pp, s, Math.min(lim, s + slice + len - 1)), 0, lim - len + 1, slice);
        if (i === STOP) return { offset: -1, cancelled: true };
        if (i >= 0 && pos + i < b) return { offset: pos + i };
        await tick(Math.min(CHUNK, b - pos));
      }
      return null;
    };
    // backward over match starts in [a, b] (inclusive b)
    const bwd = async (a, b) => {
      for (let top = b; top >= a; top -= CHUNK) {
        if (shouldStop()) return { offset: -1, cancelled: true };
        const start = Math.max(a, top - CHUNK + 1);
        const buf = prep(await this.read(start, top - start + len));
        const i = plain ? buf.lastIndexOf(needle, top - start) : await sliced(s => findBackward(buf, pp, s, Math.max(0, s - slice + 1)), top - start, -1, -slice);
        if (i === STOP) return { offset: -1, cancelled: true };
        if (i >= 0 && start + i >= a) return { offset: start + i };
        await tick(top - start + 1);
      }
      return null;
    };
    const lastStart = size - len;
    from = Math.max(0, Math.min(from, lastStart + (backward ? 0 : 1)));
    let r;
    if (!backward) {
      r = await fwd(from, lastStart + 1);
      if (!r && wrap && from > 0) { r = await fwd(0, Math.min(from + len - 1, lastStart + 1)); if (r) r.wrapped = true; }
    } else {
      r = from >= 0 ? await bwd(0, Math.min(from, lastStart)) : null;
      if (!r && wrap && from < lastStart) { r = await bwd(from + 1, lastStart); if (r) r.wrapped = true; }
    }
    progress(size, size);
    return r || { offset: -1 };
  }
```

```js
'use strict';
// Checks every message from the webview before the extension host acts on it.
const { COPY_FORMATS } = require('./bytes');

const MAX_READ = 1 << 20;          // one read request: 1 MB
const MAX_EDIT = 16 << 20;         // one paste: 16 MB
const MODES = new Set(['hex', 'text', 'utf16']);
const FORMATS = new Set(COPY_FORMATS.map(f => f[0]));
const isOff = v => Number.isSafeInteger(v) && v >= 0;

function validateWebviewMessage(m) {
  if (!m || typeof m !== 'object' || typeof m.type !== 'string') return { ok: false };
  switch (m.type) {
    case 'ready': case 'rendered': case 'cancelSearch': case 'gotoPrompt':
      return { ok: true, msg: { type: m.type } };
    case 'read':
      if (!isOff(m.offset) || !Number.isSafeInteger(m.length) || m.length < 1 || m.length > MAX_READ) return { ok: false };
      return { ok: true, msg: { type: 'read', offset: m.offset, length: m.length } };
    case 'edit': {
      if (!isOff(m.offset)) return { ok: false };
      let v = m.values;
      if (Array.isArray(v)) { if (!v.every(x => Number.isInteger(x) && x >= 0 && x <= 255)) return { ok: false }; v = Uint8Array.from(v); }
      if (!(v instanceof Uint8Array) || v.length < 1 || v.length > MAX_EDIT) return { ok: false };
      return { ok: true, msg: { type: 'edit', offset: m.offset, values: v, label: typeof m.label === 'string' ? m.label.slice(0, 40) : 'Edit' } };
    }
    case 'copy':
      if (!isOff(m.start) || !isOff(m.end) || m.end < m.start || !FORMATS.has(m.format)) return { ok: false };
      return { ok: true, msg: { type: 'copy', start: m.start, end: m.end, format: m.format } };
    case 'search':
      if (typeof m.query !== 'string' || m.query.length > 8192 || !MODES.has(m.mode) || !isOff(m.from) || !Number.isSafeInteger(m.id)) return { ok: false };
      return { ok: true, msg: { type: 'search', query: m.query, mode: m.mode, ignoreCase: !!m.ignoreCase, from: m.from, backward: !!m.backward, id: m.id } };
    case 'cursor':
      if (!isOff(m.offset) || !isOff(m.selStart) || !isOff(m.selEnd)) return { ok: false };
      return { ok: true, msg: { type: 'cursor', offset: m.offset, selStart: m.selStart, selEnd: m.selEnd } };
    case 'error':
      return { ok: true, msg: { type: 'error', message: String(m.message || '').slice(0, 500) } };
    default:
      return { ok: false };
  }
}
```

```js
/** Plain words for file system errors. */
function errorText(e) {
  const code = e && e.code;
  const m = {
    EACCES: 'You do not have permission to read this file.',
    EPERM: 'The system does not allow this file to be read.',
    ELOOP: 'This is a symbolic link that points to itself (a link loop), so there is no file to read.',
    ENOENT: 'The file does not exist (it was moved or deleted, or it is a broken link).',
    EISDIR: 'This is a folder, not a file.',
    FileNotFound: 'The file does not exist (it was moved or deleted, or it is a broken link).',
    NoPermissions: 'You do not have permission to read this file.',
  }[code];
  if (m) return `${m} (${code})`;
  const msg = (e && e.message) || String(e);
  if (/EACCES|permission/i.test(msg)) return 'You do not have permission to read this file. (' + msg + ')';
  if (/ELOOP/.test(msg)) return 'This is a symbolic link that points to itself (a link loop). (' + msg + ')';
  return msg;

class HexDoc {
  constructor(uri, hex, error) {
    this.uri = uri; this.hex = hex; this.error = error; this.panels = new Set(); this.watcher = null; this.savingUntil = 0;
  }
  post(m) { for (const p of this.panels) p.webview.postMessage(m).then(undefined, () => {}); }
  dispose() {
    if (this.watcher) this.watcher.dispose();
    if (this.hex) this.hex.dispose();
  }
}

class HexEditorProvider {
  /**
   * One provider per view type: VS Code looks up each change event's document in the store of the view type
   * that listens, so the two view types must not share an event emitter. `shared` holds the active editor
   * and the status bar item for both.
   */
  constructor(context, shared) {
    this.context = context;
    this.shared = shared;
    this._onDidChange = new vscode.EventEmitter();
    this.onDidChangeCustomDocument = this._onDidChange.event;
    context.subscriptions.push(this._onDidChange);
  }
  get active() { return this.shared.active; }
  set active(v) { this.shared.active = v; }
  get status() { return this.shared.status; }

  async openCustomDocument(uri, openContext) {
    let hex = null, error = null;
    try {
      if (uri.scheme === 'file') {
        hex = await HexDocument.openFile(uri.fsPath);
      } else {
        const stat = await vscode.workspace.fs.stat(uri);
        const capMB = settings().maxRemoteMB;
        if (stat.size > capMB * 1048576) {
          error = `This file is ${fmtSize(stat.size)}. Files on remote or virtual file systems open up to ${capMB} MB (setting hexViewer.maxRemoteMB). Local files of any size open.`;
        } else {
          const bytes = await vscode.workspace.fs.readFile(uri);
          const writable = vscode.workspace.fs.isWritableFileSystem(uri.scheme) !== false;
          hex = HexDocument.fromBytes(bytes, writable ? b => vscode.workspace.fs.writeFile(uri, b) : null);
        }
      }
    } catch (e) {
      error = errorText(e);
    }
    const doc = new HexDoc(uri, hex, error);
    if (hex && openContext && openContext.backupId) {
      try { hex.restoreBackup(Buffer.from(await vscode.workspace.fs.readFile(vscode.Uri.parse(openContext.backupId))).toString('utf8')); } catch {}
    }
    if (hex && uri.scheme === 'file') this.watch(doc);
    return doc;
  }

  watch(doc) {
    try {
      const dir = vscode.Uri.file(path.dirname(doc.uri.fsPath));
      const w = vscode.workspace.createFileSystemWatcher(new vscode.RelativePattern(dir, path.basename(doc.uri.fsPath)));
      const changed = async () => {
        if (Date.now() < doc.savingUntil) return;
        await this.reload(doc, true);
      };
      w.onDidChange(changed); w.onDidCreate(changed);
      w.onDidDelete(() => doc.post({ type: 'notice', level: 'warn', message: 'The file was deleted or moved on disk. The bytes you see may be gone.' }));
      doc.watcher = w;
    } catch {}
  }

  /** Re-read the size after a change on disk and tell the webviews. */
  async reload(doc, fromWatcher) {
    if (!doc.hex) return;
    const old = doc.hex.size;
    let size;
    try { size = await doc.hex.refresh(); } catch (e) { doc.post({ type: 'notice', level: 'error', message: errorText(e) }); return; }
    let message = '';
    if (size < old) message = `The file got shorter on disk: ${fmtSize(old)} before, ${fmtSize(size)} now. The view shows the new end of the file.`;
    else if (size > old) message = `The file grew on disk: ${fmtSize(old)} before, ${fmtSize(size)} now.`;
    else if (fromWatcher) message = 'The file changed on disk. The view shows the new bytes.';
    doc.post({ type: 'changed', size, sizeText: fmtSize(size), message });
  }

  async resolveCustomEditor(doc, panel) {
    const ctx = this.context;
    const dist = vscode.Uri.joinPath(ctx.extensionUri, 'dist');
    const media = vscode.Uri.joinPath(ctx.extensionUri, 'media');
    panel.webview.options = { enableScripts: true, localResourceRoots: [dist, media], enableCommandUris: [...commandUris('hexViewer'), 'hexViewer.goToOffset'] };
    const name = path.posix.basename(doc.uri.path);
    panel.webview.html = buildHtml({
      cspSource: panel.webview.cspSource,
      scriptUri: panel.webview.asWebviewUri(vscode.Uri.joinPath(dist, 'webview.js')).toString(),
      styleUri: panel.webview.asWebviewUri(vscode.Uri.joinPath(media, 'webview.css')).toString(),
      title: name,
      showSupportLinks: showLinks(vscode, 'hexViewer'),
    });
    doc.panels.add(panel);
    const me = { doc, panel, cursor: null };
    let disposed = false, counted = false, searchId = 0;
    const post = m => (disposed ? Promise.resolve(false) : panel.webview.postMessage(m));
    const setActive = () => { if (panel.active) { this.active = me; this.showStatus(); } else if (this.active === me) { this.active = null; this.showStatus(); } };
    panel.onDidChangeViewState(setActive);
    setActive();
    const cfgSub = vscode.workspace.onDidChangeConfiguration(e => { if (e.affectsConfiguration('hexViewer')) post({ type: 'config', settings: settings() }); });

    panel.webview.onDidReceiveMessage(async raw => {
      const v = validateWebviewMessage(raw);
      if (!v.ok) return;
      const msg = v.msg;
      try {
        if (msg.type === 'ready') {
          if (!doc.hex) { rating.failure(); await post({ type: 'init', name, error: doc.error, settings: settings() }); return; }
          const head = await doc.hex.read(0, 64);
          const writable = await doc.hex.writable();
          await post({
            type: 'init', name, size: doc.hex.size, sizeText: fmtSize(doc.hex.size), fileType: detectType(head),
            readOnly: !writable, readOnlyReason: writable ? '' : 'The file is read-only on disk.', settings: settings(),
            edited: doc.hex.editedIn(0, Number.MAX_SAFE_INTEGER).slice(0, 200000), copyFormats: COPY_FORMATS,
          });
          return;
        }
        if (!doc.hex) return;
        const hex = doc.hex;
        if (msg.type === 'read') {
          const want = Math.min(msg.length, Math.max(0, hex.size - msg.offset));
          const bytes = await hex.read(msg.offset, msg.length);
          await post({ type: 'data', offset: msg.offset, bytes, edited: hex.editedIn(msg.offset, bytes.length), size: hex.size });
          if (bytes.length < want) await this.reload(doc, false); // the file got shorter since it was opened
          return;
        }
        if (msg.type === 'rendered') { if (!counted) { counted = true; rating.success(); } return; }
        if (msg.type === 'cursor') { me.cursor = msg; if (this.active === me) this.showStatus(); return; }
        if (msg.type === 'gotoPrompt') { await vscode.commands.executeCommand('hexViewer.goToOffset'); return; }
        if (msg.type === 'error') { console.error('[hex-viewer webview]', msg.message); return; }
        if (msg.type === 'edit') {
          if (settings().readOnly || !(await hex.writable())) {
            await post({ type: 'notice', level: 'warn', message: settings().readOnly ? 'Editing is off (setting hexViewer.readOnly).' : 'This file is read-only, so it cannot be edited.' });
            return;
          }
          const rec = await hex.overwrite(msg.offset, msg.values);
          if (!rec) return;
          this.sendPatch(doc, rec.offset, rec.after.length);
          this._onDidChange.fire({
            document: doc, label: msg.label,
            undo: () => { hex.apply(rec, true); this.sendPatch(doc, rec.offset, rec.after.length); },
            redo: () => { hex.apply(rec, false); this.sendPatch(doc, rec.offset, rec.after.length); },
          });
          return;
        }
        if (msg.type === 'copy') {
          const n = Math.min(msg.end, hex.size) - msg.start;
          if (n <= 0) return;
          if (n > MAX_COPY) { await post({ type: 'notice', level: 'warn', message: `The selection is ${fmtSize(n)}. Copy works up to ${fmtSize(MAX_COPY)}.` }); return; }
          const bytes = await hex.read(msg.start, n);
          const text = formatCopy(bytes, msg.format, name.replace(/\.[^.]*$/, ''));
          await vscode.env.clipboard.writeText(text);
          const label = (COPY_FORMATS.find(f => f[0] === msg.format) || [0, msg.format])[1];
          await post({ type: 'copied', text: `Copied ${fmtInt(bytes.length)} byte${bytes.length === 1 ? '' : 's'} as ${label}.` });
          return;
        }
        if (msg.type === 'cancelSearch') { searchId = -1; return; }
        if (msg.type === 'search') {
          const p = parsePattern(msg.query, msg.mode, msg.ignoreCase);
          if (!p.ok) { await post({ type: 'searchResult', id: msg.id, offset: -1, error: p.error }); return; }
          const id = searchId = msg.id;
          const t0 = Date.now();
          const r = await hex.search(p, msg.from, msg.backward, true, () => searchId !== id || disposed,
            (done, total) => post({ type: 'searchProgress', id, done, total }));
          await post({ type: 'searchResult', id, offset: r.offset, length: p.bytes.length, wrapped: !!r.wrapped, cancelled: !!r.cancelled, ms: Date.now() - t0 });
        }
      } catch (e) {
        await post({ type: 'notice', level: 'error', message: errorText(e) });
      }
    });
    panel.onDidDispose(() => {
      disposed = true; cfgSub.dispose(); doc.panels.delete(panel);
      if (this.active === me) { this.active = null; this.showStatus(); }
    });
  }

  sendPatch(doc, offset, length) {
    // Send the changed range plus its edit marks; the webview updates its cached rows.
    doc.hex.read(offset, length).then(bytes => doc.post({ type: 'patch', offset, bytes, edited: doc.hex.editedIn(offset, length) }), () => {});
  }

  showStatus() {
    const a = this.active;
    if (!a || !a.doc.hex) { this.status.hide(); return; }
    const c = a.cursor || { offset: 0, selStart: 0, selEnd: 0 };
    const sel = c.selEnd - c.selStart;
    this.status.text = `$(go-to-file) 0x${hexOffset(c.offset, 1)} (${fmtInt(c.offset)})` + (sel > 1 ? ` · ${fmtInt(sel)} bytes selected` : '') + ` · ${fmtSize(a.doc.hex.size)}`;
    this.status.show();
  }

  async saveCustomDocument(doc) {
    if (!doc.hex) return;
    doc.savingUntil = Date.now() + 1500;
    await doc.hex.save();
    doc.savingUntil = Date.now() + 1500;
    doc.post({ type: 'saved' });
  }

  async saveCustomDocumentAs(doc, dest) {
    if (!doc.hex) return;
    if (dest.scheme === 'file') { await doc.hex.saveAsFile(dest.fsPath); return; }
    if (doc.hex.size > settings().maxRemoteMB * 1048576) throw new Error('This file is too large to save to a remote file system.');
    await vscode.workspace.fs.writeFile(dest, await doc.hex.readAll());
  }

  async revertCustomDocument(doc) {
    if (!doc.hex) return;
    doc.hex.revert();
    await doc.hex.refresh();
    doc.post({ type: 'reset', size: doc.hex.size, sizeText: fmtSize(doc.hex.size) });
  }

  async backupCustomDocument(doc, ctx) {
    const dest = ctx.destination;
    await vscode.workspace.fs.writeFile(dest, Buffer.from(doc.hex ? doc.hex.backupJson() : '{}', 'utf8'));
    return { id: dest.toString(), delete: async () => { try { await vscode.workspace.fs.delete(dest); } catch {} } };
  }
}

/** The file of the active tab, also for the "binary file" placeholder that has no text editor. */
function activeUri() {
  try {
    const tab = vscode.window.tabGroups.activeTabGroup.activeTab;
    const input = tab && tab.input;
    if (input && input.uri) return input.uri;
  } catch {}
  return vscode.window.activeTextEditor ? vscode.window.activeTextEditor.document.uri : undefined;
}

function sameFileTab(uri) {
  try {
    const key = uri.toString();
    return vscode.window.tabGroups.activeTabGroup.tabs.find(t => t.input && t.input.uri && t.input.uri.toString() === key
      && !(typeof t.input.viewType === 'string' && /^hexViewer\./.test(t.input.viewType)));
  } catch { return undefined; }
}

async function goToOffset(shared) {
  // Ctrl+G reaches here twice when both the webview and the keybinding see it; one box is enough.
  if (shared.gotoBusy) return;
  const a = shared.active;
  if (!a || !a.doc.hex) { vscode.window.showInformationMessage('Open a file in Hex Viewer first.'); return; }
  const size = a.doc.hex.size;
  const cur = (a.cursor && a.cursor.offset) || 0;
  shared.gotoBusy = true;
  let input;
  try {
    input = await vscode.window.showInputBox({
    title: 'Go to offset',
    prompt: `Hex (0x1F40), decimal (8000), relative (+0x100, -16) or "end". The file is ${fmtSize(size)}; the last byte is at 0x${hexOffset(Math.max(0, size - 1), 1)}.`,
    placeHolder: '0x' + hexOffset(cur, 1),
      validateInput: s => { const r = parseOffset(s, cur, size); return r.ok ? null : r.error; },
    });
  } finally { shared.gotoBusy = false; }
  if (input === undefined) return;
  const r = parseOffset(input, cur, size);
  if (r.ok) a.panel.webview.postMessage({ type: 'goto', offset: r.offset });
}

      supportsMultipleEditorsPerDocument: true,
      webviewOptions: { retainContextWhenHidden: true },

    vscode.commands.registerCommand('hexViewer.openWalkthrough', () =>

    vscode.commands.registerCommand('hexViewer.openWith', async (uri, uris) => {
      const list = Array.isArray(uris) && uris.length ? uris : [uri && uri.scheme ? uri : activeUri()];
      if (!list[0]) {
        const picked = await vscode.window.showOpenDialog({ canSelectMany: true, openLabel: 'Open in Hex Viewer' });
        if (picked) list.splice(0, 1, ...picked); else return;

      for (const u of list.filter(Boolean)) {
        // "Open in Hex Viewer" on a file that is open in another editor in this group replaces that tab (unless it has unsaved changes).

    vscode.commands.registerCommand('hexViewer.findNext', () => post({ type: 'findNext', backward: false })),
```

```js
'use strict';
// Builds the webview HTML. Kept free of the vscode module so tests can check the CSP.
const crypto = require('crypto');
const { footerHtml, FOOTER_CSS } = require('./support');

function escapeAttr(s) {
  return String(s).replace(/&/g, '&amp;').replace(/"/g, '&quot;').replace(/</g, '&lt;').replace(/>/g, '&gt;');
}

/**
 * @param {{cspSource:string, scriptUri:string, styleUri:string, title:string, nonce?:string, showSupportLinks?:boolean}} p
 */
function buildHtml(p) {
  const n = p.nonce || crypto.randomBytes(24).toString('base64url');
  const footer = footerHtml('hexViewer', p.showSupportLinks !== false, '');
  // No connect-src: the webview gets every byte by postMessage from the extension host. No remote origin anywhere.
  const csp = [
    "default-src 'none'", `style-src ${p.cspSource} 'nonce-${n}'`, `script-src 'nonce-${n}'`,
    `img-src ${p.cspSource} blob: data:`, `font-src ${p.cspSource}`,
  ].join('; ');
  return `<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta http-equiv="Content-Security-Policy" content="${csp}">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<link rel="stylesheet" href="${escapeAttr(p.styleUri)}">
${footer ? `<style nonce="${n}">${FOOTER_CSS}</style>` : ''}
<title>${escapeAttr(p.title)}</title>
</head>
<body>
<div id="app"><p class="loading">Opening the file...</p></div>
<template id="zovo-footer">${footer}</template>
<script nonce="${n}" src="${escapeAttr(p.scriptUri)}"></script>
</body>
</html>`;
}
```

```js
'use strict';
// Shared Zovo rating ask, v2 (factory/sprint/rating/rate.js, copied to src/rate.js in each extension).
// No network and no telemetry. State lives only in context.globalState. The one outbound action is the
// Marketplace review page, opened by the user's own click on "Rate it".
//
// Rules:
// - Ask only after the user opened 3 files without an error, on at least 2 different days.
// - "Rate it" opens the review page and ends it. "No thanks" ends it.
// - "Later" (or closing the message) asks again one time, 7 days later at the earliest.
// - At most 2 asks in all, at most 1 per window session.
// - Never after an error: no ask in a session where a file failed to open, and none for 24 hours after a failure.
// - The setting <section>.askForRating = false turns it off.
// The rules are pure functions (recordSuccess, recordFailure, decide, recordAnswer) for unit tests.

const STATE_KEY = 'zovo.rating.v2';
const OLD_KEY = 'zovo.rating.v1';
const DAY_MS = 24 * 60 * 60 * 1000;
const MIN_FILES = 3; // files opened without an error before the first ask
const MIN_DAYS = 2; // different calendar days with a success before the first ask
const LATER_DAYS = 7; // "Later" waits this long
const MAX_ASKS = 2; // asks in all
const ERROR_QUIET_MS = DAY_MS; // no ask for this long after a failure
const RATE = 'Rate it';
const LATER = 'Later';
const NEVER = 'No thanks';
// Fake clock for manual and VS Code tests: shifts "now" by this many days. Unset in normal use.
const CLOCK_ENV = 'ZOVO_RATING_CLOCK_OFFSET_DAYS';

function freshState() {
  return { count: 0, days: [], asks: 0, nextAskAt: 0, lastErrorAt: 0, done: false };
}

const num = (v, d) => (typeof v === 'number' && Number.isFinite(v) && v >= 0 ? Math.floor(v) : d);
const isDay = (d) => typeof d === 'string' && /^\d{4}-\d{2}-\d{2}$/.test(d);

function normalize(raw) {
  const s = freshState();
  if (!raw || typeof raw !== 'object') return s;
  s.count = num(raw.count, 0);
  s.days = Array.isArray(raw.days) ? [...new Set(raw.days.filter(isDay))].slice(0, MIN_DAYS) : [];
  s.asks = Math.min(MAX_ASKS, num(raw.asks, 0));
  s.nextAskAt = num(raw.nextAskAt, 0);
  s.lastErrorAt = num(raw.lastErrorAt, 0);
  s.done = raw.done === true || s.asks >= MAX_ASKS;
  return s;
}

/** Local calendar day of a timestamp, as YYYY-MM-DD. */
function dayKey(now) {
  const d = new Date(now);
  const p = (n) => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}

/** State of the v1 prompt (5 files and 2 days, "Don't ask again"): keep its answers and asks. */
function fromV1(old) {
  const s = freshState();
  if (!old || typeof old !== 'object') return s;
  s.count = num(old.count, 0);
  const first = num(old.firstUse, 0);
  if (first) s.days = [dayKey(first)];
  s.asks = Math.min(MAX_ASKS, num(old.asks, 0));
  s.done = old.done === true || s.asks >= MAX_ASKS;
  return s;
}

/** A file opened without an error. */
function recordSuccess(state, now) {
  const s = normalize(state);
  s.count += 1;
  const k = dayKey(now);
  if (!s.days.includes(k) && s.days.length < MIN_DAYS) s.days.push(k);
  return s;
}

/** A file failed to open. */
function recordFailure(state, now) {
  const s = normalize(state);
  s.lastErrorAt = Math.max(s.lastErrorAt, num(now, 0));
  return s;
}

/**
 * Should the ask show now? Call it right after recordSuccess.
 * env: { now, enabled, focused, askedThisSession, errorThisSession }
 */
function decide(state, env) {
  const s = normalize(state);
  if (s.done || !env.enabled) return false;
  if (env.askedThisSession || env.errorThisSession || env.focused === false) return false;
  if (s.asks >= MAX_ASKS) return false;
  if (s.count < MIN_FILES || s.days.length < MIN_DAYS) return false;
  if (s.lastErrorAt && env.now - s.lastErrorAt < ERROR_QUIET_MS) return false;
  return env.now >= s.nextAskAt;
}

/**
 * Apply an answer. 'shown' is saved before the message opens, so an ask is used up even if VS Code
 * quits with the message open. "Rate it" and "No thanks" end it; "Later" or no answer wait 7 days.
 */
function recordAnswer(state, answer, now) {
  const s = normalize(state);
  if (answer === 'shown') {
    s.asks += 1;
    s.nextAskAt = num(now, 0) + LATER_DAYS * DAY_MS;
  } else if (answer === RATE || answer === NEVER) {
    s.done = true;
  }
  if (s.asks >= MAX_ASKS) s.done = true;
  return s;
}

function reviewUrl(extensionId) {
  return `https://marketplace.visualstudio.com/items?itemName=${encodeURIComponent(extensionId)}&ssr=false#review-details`;
}

function messageFor(name) {
  return `Is ${name} useful? A rating helps others find it.`;
}

/** Days to add to the clock, from ZOVO_RATING_CLOCK_OFFSET_DAYS (0 to 3650), else 0. */
function clockOffsetMs(envVars) {
  const v = Number(envVars && envVars[CLOCK_ENV]);
  return Number.isFinite(v) && v > 0 && v <= 3650 ? v * DAY_MS : 0;
}

/**
 * opts: { vscode, context, extensionId, section, name, now? }
 * Returns { success(), failure() }. Call success() once per file that opened without an error,
 * failure() when a file could not be opened. Both never throw.
 */
function createRatingPrompt(opts) {
  const { vscode, context, extensionId, section, name } = opts;
  const offset = clockOffsetMs(typeof process !== 'undefined' ? process.env : null);
  const now = typeof opts.now === 'function' ? opts.now : () => Date.now() + offset;
  const store = context && context.globalState;
  const usable = !!(store && typeof store.get === 'function' && typeof store.update === 'function');
  let askedThisSession = false;
  let errorThisSession = false;
  let busy = false;
  const safe = (fn, d) => { try { return fn(); } catch { return d; } };

  function load() {
    const cur = store.get(STATE_KEY);
    if (cur && typeof cur === 'object') return normalize(cur);
    return fromV1(store.get(OLD_KEY));
  }

  const env = () => ({
    now: now(),
    enabled: safe(() => vscode.workspace.getConfiguration(section).get('askForRating', true) !== false, false),
    focused: safe(() => vscode.window.state.focused !== false, true),
    askedThisSession,
    errorThisSession,
  });

  async function ask(s, e) {
    askedThisSession = true;
    let st = recordAnswer(s, 'shown', e.now);
    await store.update(STATE_KEY, st);
    const pick = await vscode.window.showInformationMessage(messageFor(name), RATE, LATER, NEVER);
    st = recordAnswer(load(), pick, now());
    await store.update(STATE_KEY, st);
    if (pick === RATE) await vscode.env.openExternal(vscode.Uri.parse(reviewUrl(extensionId)));
  }

  async function success() {
    if (!usable) return;
    const e = env();
    const s = recordSuccess(load(), e.now);
    await store.update(STATE_KEY, s);
    if (busy || !decide(s, e)) return;
    busy = true;
    try { await ask(s, e); } finally { busy = false; }
  }

  async function failure() {
    errorThisSession = true;
    if (!usable) return;
    await store.update(STATE_KEY, recordFailure(load(), now()));
  }

  return {
    success: () => success().catch(() => {}),
    failure: () => failure().catch(() => {}),
  };
}

module.exports = {
  createRatingPrompt, decide, recordSuccess, recordFailure, recordAnswer, normalize, freshState, fromV1,
  dayKey, reviewUrl, messageFor, clockOffsetMs,
  STATE_KEY, OLD_KEY, DAY_MS, MIN_FILES, MIN_DAYS, LATER_DAYS, MAX_ASKS, ERROR_QUIET_MS, RATE, LATER, NEVER, CLOCK_ENV,
};
```

```js
/** How closely two products are used together. 0 when they are not a pair. */
function pairWeight(a, b) {
  const x = String(a || '').toLowerCase();
  const y = String(b || '').toLowerCase();
  let best = 0;
  for (const [p, q, w] of PAIRS) {
    if ((p === x && q === y) || (p === y && q === x)) best = Math.max(best, w);
  }
  return best;
}

/** Keeps the list order for products with the same weight. */
function byPair(self, list) {
  return list
    .map((p, i) => ({ p, i, w: pairWeight(self, p.id) }))
    .sort((a, b) => (b.w - a.w) || (a.i - b.i))
    .map((x) => x.p);
}

function otherProducts(selfId) {
  const self = String(selfId || '').toLowerCase();
  const notSelf = (p) => p.id.toLowerCase() !== self;
  const live = LIVE.map(([id, name, line]) => ({ id, name, line, live: true, url: marketplaceUrl(id) })).filter(notSelf);
  const queued = QUEUED.map(([id, name, line, url]) => ({ id, name, line, live: false, url })).filter(notSelf);
```

```js
}

function onData(m) {

function onPatch(m) {

function clampCursor() {
  const last = Math.max(0, S.size - 1);

function scrollToCursor(center) {
  const row = Math.floor(S.cursor / S.bpr);
  if (center) S.top = Math.max(0, Math.min(maxTop(), row - Math.floor(S.rowsVisible / 3)));
  else if (row < S.top) S.top = row;
  else if (row >= S.top + S.rowsVisible - 1) S.top = Math.min(maxTop(), row - S.rowsVisible + 2);
  render();
}

function moveTo(off, extend) {
  if (!S.size) return;
  commitPending();

  if (!extend) S.anchor = S.cursor;

  scrollToCursor(false);
  announce();

}

function gotoOffset(off, center) {
  commitPending();
  S.cursor = S.anchor = Math.max(0, Math.min(Math.max(0, S.size - 1), off));

function announce() {
  clearTimeout(S.liveTimer);

    el.live.textContent = v < 0 ? `Offset ${hexOffset(S.cursor, 1)}` : `Offset ${hexOffset(S.cursor, 1)} hex, byte ${hex2(v)}, decimal ${v}${v >= 32 && v < 127 ? ', character ' + String.fromCharCode(v) : ''}`;
  }, 250);
}

function onWheel(e) {
  e.preventDefault();
  const lines = e.deltaMode === 1 ? e.deltaY : e.deltaMode === 2 ? e.deltaY * S.rowsVisible : e.deltaY / S.rowH;
  S.wheelAcc = (S.wheelAcc || 0) + lines;
  const step = Math.trunc(S.wheelAcc);
  if (!step) return;
  S.wheelAcc -= step;
  S.top = Math.max(0, Math.min(maxTop(), S.top + step));
  scheduleRender();
}

function onTrack(e) {
  e.preventDefault();
  const H = el.track.clientHeight, th = el.thumb.offsetHeight;
  const rect = el.track.getBoundingClientRect();
  const onThumb = e.target === el.thumb;
  const grab = onThumb ? e.clientY - el.thumb.getBoundingClientRect().top : th / 2;
  const to = y => { const f = Math.max(0, Math.min(1, (y - rect.top - grab) / Math.max(1, H - th))); S.top = Math.round(f * maxTop()); scheduleRender(); };
  to(e.clientY);
  const mv = ev => to(ev.clientY);
  const up = () => { window.removeEventListener('mousemove', mv); window.removeEventListener('mouseup', up); };
  window.addEventListener('mousemove', mv); window.addEventListener('mouseup', up);
}

function cellAt(target) {
  const cell = target.closest && target.closest('.b,.c');
  if (!cell || cell.classList.contains('e') || cell.dataset.o === undefined) return null;
  const row = cell.closest('.row');

function onMouseDown(e) {
  const c = cellAt(e.target);
  if (!c) return;
  e.preventDefault();
  el.grid.focus();
  S.column = c.column;
  moveTo(c.off, e.shiftKey);

    const t = document.elementFromPoint(ev.clientX, ev.clientY);
    const d = t && cellAt(t);
    if (d && d.off !== S.cursor) { S.cursor = d.off; render(); }
    const r = el.rows.getBoundingClientRect();
    if (ev.clientY > r.bottom - 4 && S.top < maxTop()) { S.top++; S.cursor = Math.min(S.size - 1, S.cursor + S.bpr); render(); }
    if (ev.clientY < r.top + 4 && S.top > 0) { S.top--; S.cursor = Math.max(0, S.cursor - S.bpr); render(); }
  };
  const up = () => { window.removeEventListener('mousemove', mv); window.removeEventListener('mouseup', up); announce(); };
  window.addEventListener('mousemove', mv); window.addEventListener('mouseup', up);
}

function onGlobalKey(e) {
  const mod = e.ctrlKey || e.metaKey;
  if (mod && S.pendingByte && /^[szSZ]$/.test(e.key)) { commitPending(); S.nibble = 0; render(); }
  if (mod && !e.shiftKey && !e.altKey && (e.key === 'f' || e.key === 'F')) { e.preventDefault(); el.find.focus(); el.find.select(); return; }
  if (mod && !e.shiftKey && !e.altKey && (e.key === 'g' || e.key === 'G')) { e.preventDefault(); post({ type: 'gotoPrompt' }); return; }
  if (e.key === 'F3') { e.preventDefault(); runSearch(e.shiftKey); }
}

function onKey(e) {
  if (!S.size) return;
  const mod = e.ctrlKey || e.metaKey;
  const ext = e.shiftKey;
  const page = Math.max(1, S.rowsVisible - 1) * S.bpr;
  let to = null;
  switch (e.key) {
    case 'ArrowLeft': to = S.cursor - 1; break;
    case 'ArrowRight': to = S.cursor + 1; break;
    case 'ArrowUp': to = S.cursor - S.bpr; if (to < 0) to = S.cursor; break;
    case 'ArrowDown': to = S.cursor + S.bpr; if (to > S.size - 1) to = S.cursor; break;
    case 'PageUp': to = S.cursor - page; if (to < 0) to = S.cursor % S.bpr; S.top = Math.max(0, S.top - S.rowsVisible + 1); break;
    case 'PageDown': to = S.cursor + page; if (to > S.size - 1) to = S.size - 1; S.top = Math.min(maxTop(), S.top + S.rowsVisible - 1); break;
    case 'Home': to = mod ? 0 : S.cursor - (S.cursor % S.bpr); break;
    case 'End': to = mod ? S.size - 1 : Math.min(S.size - 1, S.cursor - (S.cursor % S.bpr) + S.bpr - 1); break;
    case 'Tab': e.preventDefault(); commitPending(); S.column = S.column === 'hex' ? 'text' : 'hex'; S.nibble = 0; render(); return;
    case 'Escape': S.anchor = S.cursor; S.match = null; render(); return;
  }
  if (to !== null) { e.preventDefault(); moveTo(to, ext); return; }
  if (mod && (e.key === 'a' || e.key === 'A')) { e.preventDefault(); S.anchor = 0; S.cursor = S.size - 1; render(); return; }
  if (mod || e.altKey || e.key.length !== 1) return;
  // typing overwrites
  if (S.column === 'hex') {
    if (!/^[0-9a-fA-F]$/.test(e.key)) return;
    e.preventDefault();
    if (S.readOnly) return readOnlyHint();
    const d = parseInt(e.key, 16);
    const old = byteAt(S.cursor);
    if (old < 0) return hint('That row is still loading.');
    if (S.nibble === 0) {
      // First digit: shown at once, sent with the second digit (one undo step per byte).
      S.pendingByte = { off: S.cursor, value: (d << 4) | (old & 15) };
      setLocal(S.cursor, S.pendingByte.value);
      S.nibble = 1; render();
    } else {
      const v = (old & 0xf0) | d;
      S.pendingByte = null;
      writeBytes(S.cursor, [v], 'Edit byte');
      S.nibble = 0;
      if (S.cursor < S.size - 1) moveTo(S.cursor + 1, false); else render();
    }
  } else {
    const v = byteForChar(e.key, S.encoding === 'latin1' || S.encoding === 'ebcdic' ? S.encoding : 'ascii');
    if (v < 0) return;
    e.preventDefault();
    if (S.readOnly) return readOnlyHint();
    commitPending();
    writeBytes(S.cursor, [v], 'Type text');
    if (S.cursor < S.size - 1) moveTo(S.cursor + 1, false); else render();
  }
}

function setLocal(o, v) {
  const b = S.blocks.get(Math.floor(o / BLOCK));
  if (b && o % BLOCK < b.bytes.length) { b.bytes[o % BLOCK] = v; b.edited.add(o); }
}

/** A first hex digit with no second one yet is written when the cursor leaves the byte. */
function commitPending() {
  const p = S.pendingByte;
  S.pendingByte = null;
  if (p) writeBytes(p.off, [p.value], 'Edit byte');
}

function readOnlyHint() { hint(S.readOnlyReason || 'Editing is off (setting hexViewer.readOnly).'); }

/** Write bytes now in the view and send them to the host, which keeps the undo stack. */
function writeBytes(off, values, label) {
  for (let i = 0; i < values.length; i++) {
    const o = off + i;
    const b = S.blocks.get(Math.floor(o / BLOCK));
    if (b && o % BLOCK < b.bytes.length) { b.bytes[o % BLOCK] = values[i]; b.edited.add(o); }
  }
  post({ type: 'edit', offset: off, values: Uint8Array.from(values), label });
}

function onPaste(e) {
  if (inField() || !S.size) return;

  const text = (e.clipboardData && e.clipboardData.getData('text/plain')) || '';

function runSearch(backward) {
  const q = el.find.value;
  if (!q) { el.find.focus(); return; }
  const [s0] = selRange();
  let from;
  if (backward) from = Math.max(0, (S.match ? S.match.start : S.cursor) - 1);
  else from = S.match && S.match.start === s0 ? S.match.start + 1 : S.cursor;
  if (backward && (S.match ? S.match.start : S.cursor) === 0) from = S.size; // wrap from the end

  el.findInfo.classList.remove('bad');

}
```

```md
# Copy, inspect and edit bytes

- Select: drag with the mouse, or hold Shift with the arrow keys, Page Up, Page Down, Home and End. Ctrl+A selects the whole file.
- Copy: Ctrl+C (Cmd+C) copies the selection as hex with spaces (setting `hexViewer.copyFormat`). The Copy as... menu also has hex without spaces, a C array, Python bytes, base64 and text.
- Data inspector: the panel on the right reads the bytes at the cursor as 8, 16, 24, 32 and 64-bit integers, float16, float32 and float64, ULEB128, Unix time, Windows FILETIME, a GUID and a UTF-8 or UTF-16 character. Click the byte order to switch between little-endian and big-endian.
- Edit: type hex digits in the hex column, or text in the text column, to overwrite bytes. Edited bytes are colored. Ctrl+Z undoes, Ctrl+Shift+Z redoes and Ctrl+S saves. Only the changed bytes are written, so a save on a 4 GB file is fast.
- Paste hex (`4A 5B 00`) with Ctrl+V to overwrite bytes from the cursor.
- Set `hexViewer.readOnly` to open every file as view only.
```

`walkthrough/navigate.md`:

```md
# Go to an offset and find bytes

- Ctrl+G (Cmd+G on macOS) opens "Go to offset". Type `0x1F40`, `1F40h`, `8000`, `+0x100`, `-16` or `end`. The box under the toolbar does the same.
- Ctrl+F (Cmd+F) puts the cursor in the Find box. Pick Hex, Text or UTF-16.
  - Hex: `50 4B 03 04`, `504B0304` or `0x50,0x4B`. `??` matches any byte: `DE ?? BE EF`.
  - Text: plain text, with Aa to ignore case.
- Enter finds the next match, Shift+Enter the one before. F3 and Shift+F3 work too. The search goes on from the start of the file when it reaches the end.
- The search runs on the whole file in 1 MB pieces, so a pattern that crosses a piece edge is found, and a 4 GB file does not fill the memory. Esc stops a long search.
- The status bar shows the cursor offset in hex and decimal. Click it to go to an offset.
```

```md
# Settings

| Setting | What it does |
|---|---|
| `hexViewer.bytesPerRow` | 8, 16, 24, 32, 48 or 64 bytes in each row |

| `hexViewer.copyFormat` | What Ctrl+C copies from the hex column |
| `hexViewer.littleEndian` | Byte order of the data inspector |
| `hexViewer.readOnly` | Turn off byte editing |
```
