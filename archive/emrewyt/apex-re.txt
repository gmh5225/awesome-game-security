# Contributing to Apex-RE

We welcome contributions from reverse engineers, compiler enthusiasts, and AI agent developers.

---

## Development Guidelines

1. **Zero External Dependencies:**
   All core scripts in `skills/apex-re/scripts/` must run on Python 3 standard library without requiring `pip install`.
2. **Deterministic & Cross-Platform:**
   Code must run identically across Windows, Linux, and macOS.
3. **Comprehensive Testing:**
   Any new parser, unpacker, or analysis utility must include unit tests in `tests/test_apex_scripts.py`. Run tests locally before opening a pull request:
   ```bash
   python -m unittest discover -s tests -p "test_*.py" -v
   ```
4. **Documentation Quality:**
   All documentation must follow the aesthetic standards of Apex-RE:
   - Use clean SVG icons and badges (no emojis).
   - Maintain clear Mermaid architecture diagrams.
   - Provide concrete, verified code snippets in C# (.NET 8), modern C++20, and Python.

---

## Pull Request Process

1. Fork the repository and create your branch from `main`.
2. Ensure all tests pass with zero failures.
3. Open a pull request describing the technical challenge, the methodology used, and test outputs.

## <img src="assets/icons/bolt.svg" width="20" height="20" align="center" alt="Overview" /> Overview

Most reverse engineering skills for AI agents suffer from critical limitations:
1. **Static Blindness:** They inspect static decompilation text without understanding live memory layout or dynamic state mutations.
2. **Obfuscation Paralysis:** Control Flow Flattening (OLLVM), opaque predicates, and bytecode dispatchers force models into speculative guesswork.
3. **Engine-Specific Gaps:** They lack deep heuristics for Unreal Engine reflection (`FNamePool`, `GUObjectArray`), Unity IL2CPP solution reconstruction, Godot PCK packaging, and .NET NativeAOT method tables.
4. **No Verification Loop:** They cannot mathematically prove that reconstructed C# or C++ code behaves identically to the original binary.

**Apex-RE** provides a five-layer operational methodology that equips AI agents with the diagnostic workflow of an expert reverse engineer:

```mermaid
flowchart TD
    Target["Target Binary / Memory / Game Process"] --> Layer1["Layer 1: Unified Static Triage & Consensus\n(PE32+, ELF, Mach-O, WASM, Multi-Decompiler ASTs)"]
    Target --> Layer2["Layer 2: Dynamic Memory & State Diffing\n(Snapshot Comparison, Struct Layout Synthesis, Pointer Chains)"]
    Target --> Layer3["Layer 3: Engine-Specific Deconstructors\n(Unreal 4/5 FNamePool, Unity IL2CPP to C#, Godot PCK, .NET 10, Tauri/Electron)"]

    Layer1 --> Layer4["Layer 4: Autonomous Synthesizer & Solver\n(OLLVM Unflattening, Kaitai Struct Synthesis, SMT Z3 Solving)"]
    Layer2 --> Layer4
    Layer3 --> Layer4

    Layer4 --> Layer5["Layer 5: Round-Trip Equivalence Prover\n(Compile -> 1,000 Synthetic Vectors -> Native vs Emulated Diff -> 100% Match)"]
    Layer5 --> Deliverables["Certified Deliverables:\nCompilable C# (.NET 8) / C++20, Kaitai .ksy, Memory Structs"]
```

| :--- | :--- | :--- |
| **`apex_triage.py`** | Deep Binary Triager | Parses PE32/PE32+, ELF, Mach-O, WASM. Calculates Shannon entropy, identifies W+X anomalies, extracts MSVC Rich Header build telemetry, detects packers/VMs, and fingerprints game engines & runtimes. |
| **`memory_diff.py`** | Memory State Differ | Compares two binary memory dumps (before/after action), isolates variable mutations (int8..int64, float32, float64, pointer), and synthesizes compilable C++ and C# explicit struct definitions. |
| **`sig_scan.py`** | Signature & Offset Scanner | Wildcard IDA/CE pattern search, automated x86_64 RIP-relative displacement math, and autonomous stable signature synthesis. |
| **`vm_analyzer.py`** | VM Bytecode Trace Analyzer | Deconstructs obfuscated code virtualization loops. Identifies interpreter dispatchers, strips VIP overhead, and performs backward symbolic register slicing. |
| **`kaitai_synth.py`** | Kaitai Format Synthesizer | Analyzes binary structures, packets, or save games. Identifies headers, endianness, primitive sequences, and emits valid Kaitai Struct (`.ksy`) YAML specifications. |
| **`unflatten_trace.py`**| Control Flow Unflattener | Deobfuscates OLLVM state-dispatcher loops. Eliminates the artificial switch machine and reconstructs clean linear C control flow or Mermaid diagrams. |

```ps1
# Install apex-re for Claude Code, Codex, Antigravity 2.0, Gemini CLI, Cursor.
# Usage: .\install.ps1 [-Target claude|codex|antigravity|gemini|cursor|all] [-Scope user|project]
param(
  [ValidateSet("claude", "codex", "antigravity", "gemini", "cursor", "all")][string]$Target = "all",
  [ValidateSet("user", "project")][string]$Scope = "user"
)
$ErrorActionPreference = "Stop"

$Src = Join-Path $PSScriptRoot "skills\apex-re"
if (-not (Test-Path $Src)) { throw "skill folder not found: $Src" }

function Get-Dest([string]$t) {
  if ($Scope -eq "project") {
    switch ($t) {
      "claude"      { return ".claude\skills" }
      "codex"       { return ".codex\skills" }
      "antigravity" { return ".agents\skills" }
      "gemini"      { return ".gemini\skills" }
      "cursor"      { return ".cursor\skills" }
    }
  } else {
    switch ($t) {
      "claude"      { return Join-Path $HOME ".claude\skills" }
      "codex"       { return Join-Path $HOME ".codex\skills" }
      "antigravity" { return Join-Path $HOME ".gemini\config\skills" }
      "gemini"      { return Join-Path $HOME ".gemini\skills" }
      "cursor"      { return Join-Path $HOME ".cursor\skills" }
    }
  }
}

function Install-One([string]$t) {
  $dest = Get-Dest $t
  New-Item -ItemType Directory -Force -Path $dest | Out-Null
  $target = Join-Path $dest "apex-re"
  if (Test-Path $target) { Remove-Item -Recurse -Force $target }
  Copy-Item -Recurse $Src $target
  Write-Host " [OK] Installed apex-re for $t -> $target" -ForegroundColor Green
}

if ($Target -eq "all") {
  "claude", "codex", "antigravity", "gemini", "cursor" | ForEach-Object { Install-One $_ }
} else {
  Install-One $Target
}

`install.sh`:

```sh
#!/usr/bin/env bash
# Install apex-re for Claude Code, Codex, Antigravity 2.0, Gemini CLI, Cursor.
# Usage: ./install.sh [--target claude|codex|antigravity|gemini|cursor|all] [--scope user|project]
set -euo pipefail

TARGET="all"
SCOPE="user"

while [[ $# -gt 0 ]]; do
  case "$1" in
    --target|-t) TARGET="$2"; shift 2 ;;
    --scope|-s)  SCOPE="$2";  shift 2 ;;
    *) echo "Unknown arg: $1" >&2; exit 1 ;;
  esac
done

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
SRC="${SCRIPT_DIR}/skills/apex-re"

if [[ ! -d "${SRC}" ]]; then
  echo "Error: Skill folder not found: ${SRC}" >&2
  exit 1
fi

get_dest() {
  local t="$1"
  if [[ "${SCOPE}" == "project" ]]; then
    case "$t" in
      claude)      echo ".claude/skills" ;;
      codex)       echo ".codex/skills" ;;
      antigravity) echo ".agents/skills" ;;
      gemini)      echo ".gemini/skills" ;;
      cursor)      echo ".cursor/skills" ;;
    esac
  else
    case "$t" in
      claude)      echo "${HOME}/.claude/skills" ;;
      codex)       echo "${HOME}/.codex/skills" ;;
      antigravity) echo "${HOME}/.gemini/config/skills" ;;
      gemini)      echo "${HOME}/.gemini/skills" ;;
      cursor)      echo "${HOME}/.cursor/skills" ;;
    esac
  fi
}

install_one() {
  local t="$1"
  local dest
  dest="$(get_dest "$t")"
  mkdir -p "${dest}"
  local target="${dest}/apex-re"
  rm -rf "${target}"
  cp -R "${SRC}" "${target}"
  echo " [OK] Installed apex-re for $t -> ${target}"
}

if [[ "${TARGET}" == "all" ]]; then
  for t in claude codex antigravity gemini cursor; do
    install_one "$t"
  done
else
  install_one "${TARGET}"
fi

# Apex-RE: GitHub Push & Repository Setup Automation (PowerShell)
# Usage: .\push-to-github.ps1 [-Owner "emrewyt"] [-Public]

param(
    [string]$Owner = "emrewyt",
    [string]$RepoName = "apex-re",
    [switch]$Public = $true
)

$Description = "Master-Tier Autonomous Reverse Engineering Skill for AI Agents. Covers Unreal Engine 4-5, Unity (IL2CPP), Godot, .NET 3-10 / NativeAOT, Electron, Tauri, MSVC C++, Python, VMProtect/OLLVM devirtualization, memory diffing, pattern scanning, and round-trip verification."
$Topics = @(
    "reverse-engineering",
    "ai-agent",
    "antigravity",
    "claude-code",
    "codex",
    "cursor",
    "unreal-engine",
    "unity-il2cpp",
    "godot",
    "dotnet",
    "nativeaot",
    "memory-forensics",
    "kaitai-struct",
    "ollvm-deobfuscator",
    "signature-scanner",
    "devirtualization",
    "ghidra",
    "ida-pro"
)

Write-Host "[*] Apex-RE GitHub Deployment Setup" -ForegroundColor Cyan
Write-Host "    Target: $Owner/$RepoName" -ForegroundColor Gray

# Check gh CLI
$ghCli = Get-Command gh -ErrorAction SilentlyContinue
if ($ghCli) {
    Write-Host "[+] GitHub CLI (gh) detected." -ForegroundColor Green
    $authCheck = gh auth status 2>&1
    if ($LASTEXITCODE -eq 0) {
        Write-Host "[+] GitHub CLI is authenticated." -ForegroundColor Green
        
        # Check if repo exists
        gh repo view "$Owner/$RepoName" 2>&1 | Out-Null
        if ($LASTEXITCODE -ne 0) {
            Write-Host "[*] Creating repository $Owner/$RepoName on GitHub..." -ForegroundColor Yellow
            $visibility = if ($Public) { "--public" } else { "--private" }
            gh repo create "$Owner/$RepoName" $visibility --description $Description --source . --remote origin
        } else {
            Write-Host "[+] Remote repository exists. Setting description..." -ForegroundColor Green
            gh repo edit "$Owner/$RepoName" --description $Description
        }

        # Set topics
        Write-Host "[*] Setting repository SEO topic tags..." -ForegroundColor Cyan
        foreach ($t in $Topics) {
            gh repo edit "$Owner/$RepoName" --add-topic $t

## 1. MSVC Rich Header Decoding

The MSVC Rich Header is an undocumented data structure located between the DOS header (`0x40`) and the PE header. It records every compiler tool, language frontend, and linker invocation used during the build.

### Header Structure
```text
[DOS Header: 0x00 .. 0x3F]

   └── "Rich" Marker (0x68636952) + XOR_KEY DWORD

## 2. Universal Symbol Demangling

Compilers encode function namespaces, parameter types, and calling conventions into symbol names:

### MSVC C++ (`?` Prefix)
- Example: `?CalculateDamage@PlayerEntity@@QEAAHHM@Z`
  - `?`: MSVC mangling prefix
  - `CalculateDamage`: Method name
  - `@PlayerEntity@@`: Class name
  - `QEAA`: Public member function, non-static, x64 `__fastcall`
  - `H`: Return type `int`
  - `HM`: Parameters `int, float`

### Itanium / GCC / Clang (`_Z` Prefix)
- Example: `_ZN12PlayerEntity15CalculateDamageEif`
  - `_Z`: Itanium prefix
  - `N`: Nested name (class scope)
  - `12PlayerEntity`: Class name (length 12)
  - `15CalculateDamage`: Method name (length 15)
  - `E`: End of nested scope
  - `i`: Parameter `int`
  - `f`: Parameter `float`

### Rust (`_ZN` or `$CRATE$` Prefix)
- Example: `_ZN6player12PlayerEntity15calculate_damage17h1234567890abcdefE`
  - Demangled: `player::PlayerEntity::calculate_damage::h1234567890abcdef`

# Multi-Engine Decompilation Consensus & Token-Efficient ASTs

Methodology for cross-validating decompilation outputs across Ghidra, IDA Pro, Binary Ninja, and ILSpy while preventing LLM context window starvation.

## 1. Why Single Decompilers Fail

No decompiler is universally correct. Each engine uses different intermediate representations and optimization passes:

```text
Engine Comparison
├── IDA Pro (Hex-Rays)     -> Best control flow recovery, but may over-optimize volatile pointer accesses
├── Ghidra (GhidraDecomp)  -> Strong type propagation, but produces verbose cast expressions and inverted branches
├── Binary Ninja (MLIL/HLIL)-> Exceptional SSA form and variable lifetime analysis, but occasionally struggles with complex C++ templates
└── ILSpy (ICSharpCode)     -> Unmatched C# language reconstructor, but limited to managed .NET IL
```

### The Consensus Principle
When analyzing mission-critical algorithms (crypto routines, network decoders, anti-cheat checks), an AI agent must cross-validate discrepancies using the consensus rule:

```mermaid
flowchart TD
    Binary["Target Function Machine Code"] --> Ghidra["Ghidra Output\n(Type Focus)"]
    Binary --> IDA["IDA Hex-Rays\n(Flow Focus)"]
    Binary --> Binja["Binary Ninja HLIL\n(SSA Focus)"]

    Ghidra --> Arbiter{"Consensus Arbiter\n(Discrepancy Check)"}
    IDA --> Arbiter
    Binja --> Arbiter

    Arbiter -- "All Agree" --> CleanCode["Accepted High-Level Code"]
    Arbiter -- "Disagreement Found" --> Disasm["Arbitrate with Raw Disassembly\n(Opcode & Flag Inspection)"]
    Disasm --> CleanCode
```

---

## 2. Resolving Common Decompiler Discrepancies

### 2.1 Loop Bound Discrepancies (`<` vs `<=`)
- **Symptom:** Ghidra emits `for (i = 0; i < count; i++)`, while IDA emits `for (i = 0; i <= count - 1; i++)`.
- **Arbitration Rule:** Inspect the conditional jump opcode in raw assembly:
  - `jl` / `jb` (Jump Less / Below): Strict inequality (`<`).
  - `jle` / `jbe` (Jump Less or Equal / Below or Equal): Inclusive inequality (`<=`).

### 2.2 Sign Extension vs Zero Extension
- **Symptom:** One decompiler treats an integer variable as signed (`int32_t`), another as unsigned (`uint32_t`).
- **Arbitration Rule:** Check the extension instruction:
  - `movsx` / `movsxd` / `cdqe`: Signed arithmetic.
  - `movzx` / zeroed 32-bit register write (`mov eax, ecx` clears top 32 bits): Unsigned arithmetic.

---

## 3. Preventing AI Agent Context Starvation

Raw decompiled dumps of large functions waste valuable context tokens on boilerplate setup, stack canaries, and standard prologues/epilogues.

### Two-Stage Hierarchical Representation

#### Stage 1: Abstract Function Interface (Summary Stage)
Before reading full function bodies, query only the structural summary:
```yaml
function_summary:
  address: "0x140024B10"
  symbol: "VerifyAuthenticationToken"
  calling_convention: "__fastcall"
  parameters:
    - name: "token_ptr"
      type: "const uint8_t*"
      register: "RCX"
    - name: "token_len"
      type: "uint32_t"
      register: "RDX"
  returns: "bool (RAX)"
  callees:
    - "0x140050120 (Crypto::SHA256)"
    - "0x140051890 (Memory::Compare)"
  complexity:
    basic_blocks: 14
    cyclomatic: 6
  critical_blocks:
    - id: "BB_04"
      purpose: "XOR decryption loop"

```

#### Stage 2: Selective Core Block Expansion
Only request the raw decompiled pseudocode of the specific algorithmic block identified in Stage 1:
```text

```
This reduces token consumption by over 85% while delivering 100% precision for the algorithmic core.

       uint32_t BaseSize;      // Instance size in memory
       EEType*  RelatedType;   // Base class or element type
       void*    InterfaceMap;  // Implemented interfaces

   };

## 1. The Power of Differential State Analysis

# Obfuscation & Virtual Machine Protectors: Deconstruction & Devirtualization

Master-tier reference guide for deobfuscating Control Flow Flattening (OLLVM), defeating Opaque Predicates, and devirtualizing VM-based protectors (VMProtect, Themida, Code Virtualizer, and Custom Bytecode VMs).

---

## 1. Control Flow Flattening (CFF / OLLVM)

Control Flow Flattening destroys natural programming constructs (`if`, `else`, `while`, `for`) by breaking a function into isolated basic blocks governed by an artificial central dispatcher switch statement.

```text
Original Control Flow:
[Block A] ──> [Block B] ──> [Block C]

Flattened Control Flow (OLLVM):
                  ┌──────────────────────┐
                  │ Central Dispatcher   │ ◄──────────┐
                  │ (switch (state_var)) │            │
                  └──────────┬───────────┘            │
         ┌───────────────────┼───────────────────┐    │
         ▼                   ▼                   ▼    │
  [Case 0x1A: Block A] [Case 0x2B: Block B] [Case 0x3C: Block C]
  state = 0x2B        state = 0x3C        state = EXIT
         └───────────────────┴───────────────────┴────┘
```

### 1.1 Automated Unflattening Workflow

1. **Dispatcher Identification:**
   Locate the basic block with the highest in-degree (the switch loop head) and identify the state variable register/stack slot (e.g. `DWORD PTR [rbp-0x10]`).
2. **Handler Extraction:**
   For each case of the switch, extract:
   - Case condition value (`state == 0x1A`)
   - Target basic block address
   - State transition formula (`next_state = 0x2B` or `next_state = (cond) ? 0x2B : 0x4F`)
3. **Control Flow Graph Reconstruction:**
   - Remove the dispatcher block entirely.
   - Patch the terminator of each basic block to jump directly to its true successor block:
     ```asm
     ; Obfuscated:
     mov dword ptr [rbp-0x10], 0x2B
     jmp dispatcher_head

     ; Deobfuscated Patch:
     jmp block_B
     ```
4. **Tooling:**
   Use the bundled `unflatten_trace.py` script to generate a clean C structural control flow from execution traces.

---

## 2. Opaque Predicates

An opaque predicate is a conditional statement whose outcome is mathematically fixed (always True or always False) at compile time, but whose invariance is difficult for static decompilers to determine.

### 2.1 Mathematical Patterns

| Pattern | Mathematical Invariant | Deobfuscation Action |
| :--- | :--- | :--- |
| `(x * (x + 1)) % 2 == 0` | Product of two consecutive integers is always even (True). | Eliminate False branch and dead code block. |
| `(x * x) >= 0` | Square of any signed integer is non-negative (True, assuming no overflow). | Replace branch with unconditional jump. |
| `7 * y * y - 1 == x * x` | Has no integer solutions (False). | Delete unreachable code. |

### 2.2 Symbolic Proving via Z3 / angr
When an opaque predicate depends on complex algebraic expressions, solve it symbolically with Z3:

```python
from z3 import *

x = BitVec('x', 32)
# Check if predicate can ever evaluate to False:
solver = Solver()
predicate = ((x * (x + 1)) % 2) == 0
solver.add(Not(predicate))

if solver.check() == unsat:
    print("[+] Proved mathematically: Branch is invariant (Always True). Dead code eliminated.")
```

## 3. Virtual Machine (VM) Protectors: Devirtualization

Protectors like VMProtect, Themida, and proprietary game anti-cheats convert native x86/x64 instructions into proprietary, encrypted bytecode interpreted by an embedded virtual machine.

### 3.1 Anatomy of a Bytecode Virtual Machine

```mermaid
flowchart TD
    Native["Native Caller"] --> VMEnter["VM_ENTER:\nPushes all registers, allocates VM Context Struct\nInitializes VIP (Virtual IP) & VSP (Virtual Stack Pointer)"]
    VMEnter --> Fetch["Fetch-Decode Loop:\nopcode = *VIP++\nhandler = HandlerTable[opcode ^ key]"]
    Fetch --> Dispatch["Jump to Handler Address"]
    Dispatch --> Handlers["Execute Handler Logic:\n- vAdd / vSub\n- vPush / vPop\n- vNor / vNand\n- vJmp / vJcc"]
    Handlers --> Fetch
    Handlers --> VMExit["VM_EXIT:\nRestores native registers from VM Context\nResumes native CPU execution"]
```

### 3.2 The 5-Step Devirtualization Methodology

#### Step 1: Trace the VM Execution
Run the virtualized routine under a deterministic emulator (Unicorn Engine or Qiling Framework) or instrument it with Frida. Record every basic block executed.

#### Step 2: Identify the VM Context & Registers
- Locate the pointer to the VM context structure (commonly stored in `RBP` or `R14`).
- Identify the memory slots corresponding to virtual registers (`VReg0` = `EAX`, `VReg1` = `EBX`, etc.).

#### Step 3: Extract and Symbolize Handlers
Most VMs only implement 10-20 core operations disguised through heavy polymorphism:
- Arithmetic: `vADD`, `vSUB`, `vMUL`
- Logic: `vNOR` (used to synthesize `AND`, `OR`, `NOT`, `XOR`)
- Stack: `vPUSH_IMM`, `vPUSH_REG`, `vPOP_REG`
- Memory: `vREAD_MEM`, `vWRITE_MEM`
- Control Flow: `vJMP`, `vJCC` (conditional branch)

#### Step 4: De-virtualize Bytecode into LLVM IR
Convert each decoded virtual instruction into a clean LLVM IR instruction:
- `vPUSH_REG VReg0` $\to$ `%0 = load i32, i32* %eax`
- `vADD VReg1` $\to$ `%1 = add i32 %0, %ebx`
- `vPOP_REG VReg0` $\to$ `store i32 %1, i32* %eax`

#### Step 5: Native Recompilation
Feed the recovered LLVM IR into `clang -O3` to compile a clean, native, 100% deobfuscated binary without a trace of the virtual machine.

### 1.1 Unpacking with `pyinstxtractor`

### 1.2 Fixing Missing `.pyc` Headers
`pyinstxtractor` extracts raw bytecode without the 16-byte `.pyc` header for the main script. To repair it for decompiler compatibility:
1. Open `struct.pyc` (which has a valid header) in a hex editor.
2. Copy the first 16 bytes:
   - Bytes 0..3: Python magic number (determines Python version).
   - Bytes 4..7: Bit field flags (PEP 552: 0 = timestamp-based, 1 = hash-based).
   - Bytes 8..15: Timestamp and file size, or siphash.
3. Prepend these 16 bytes to the extracted entry script before decompilation.

# Signature & Pattern Scanning Guide
## Autonomous Offset Resolution & Pattern Generation

Fixed memory offsets and function addresses break on every executable patch, recompilation, or update. Reverse engineers and automated agents rely on **Signature / Pattern Scanning** to dynamically locate target functions, structures, and global singletons at runtime.

A signature consists of a hexadecimal byte sequence interleaved with single-byte wildcards (`?` or `??`):

```text
48 8B 05 ? ? ? ? 48 85 C0 74 ? 48 8B 48 20
```

- Concrete hex pairs match exact instruction opcodes.
- `?` or `??` match any byte (typically dynamic displacements, relative branch offsets, or immediate values).

---

## 2. x86_64 RIP-Relative Displacement Mathematics

In 64-bit x86 architecture, memory operands relative to the instruction pointer (`RIP`) use a signed 32-bit displacement relative to the **next instruction**:

```text
Offset 0x1000:  48 8B 05 45 23 01 00    mov rax, [rip + 0x12345]
Offset 0x1007:  48 85 C0                test rax, rax
```

### Exact Calculation Formula
$$\text{Next RIP} = \text{MatchOffset} + \text{InstructionLength}$$
$$\text{Target RVA} = \text{Next RIP} + \text{int32}(\text{Displacement})$$
$$\text{Target VA} = \text{ImageBase} + \text{Target RVA}$$

In `sig_scan.py`:
- `disp_offset_within_match = 3` (starts at byte index 3 of the instruction)
- `instruction_length = 7`
- Displacement is read as a signed 32-bit little-endian integer (`<i`).

```bash

The tool:
1. Progressively reads instructions from the target address.

3. Tests uniqueness against the entire binary.
4. Outputs ready-to-use C++ `#define` macros and C# `.NET 8` constants.

# Round-Trip Verification & Equivalence Prover

Methodology for mathematically verifying that reconstructed high-level code behaves with 100% functional equivalence to the original compiled binary.

---

## 1. The Verification Imperative

When an AI agent reverse engineers complex logic (cryptographic ciphers, hashing, physics equations, packet decoders), subtle hallucination bugs (such as operator precedence, sign extension, off-by-one errors) can occur.

The **Round-Trip Verification Loop** eliminates guesswork by executing both the original binary slice and the reconstructed code under an identical harness with automated differential testing:

```mermaid
flowchart TD
    Target["Original Compiled Binary Function"] --> NativeSlice["Extract Isolated Machine Code Slice"]
    Reconstructed["Reconstructed C# / C++ Code"] --> Compile["Compile to Native Dynamic Library / Test Harness"]

    Vectors["Synthetic Test Vector Generator\n(1,000 Edge Cases & Randomized Inputs)"] --> ExecA["Run Native Slice under Unicorn Engine"]
    Vectors --> ExecB["Run Reconstructed Native Harness"]

    ExecA --> Comparer{"Differential Comparator\n(Byte-by-Byte Diff)"}
    ExecB --> Comparer

    Comparer -- "100% Match (0 Deltas)" --> Certified["Certified 100% Equivalent"]
    Comparer -- "Mismatch Detected" --> Debug["Isolate Faulty Vector & Pinpoint Register/Memory Delta"]
    Debug --> Reconstructed
```

---

## 2. Test Vector Generation Principles

A robust verification harness requires diverse test vectors:

1. **Boundary & Edge Values:**
   - Integers: `0`, `1`, `-1`, `0x7FFFFFFF` (`INT32_MAX`), `0x80000000` (`INT32_MIN`), `0xFFFFFFFF` (`UINT32_MAX`).
   - Floats: `0.0f`, `-0.0f`, `1.0f`, `1e-6f`, `NaN`, `+Infinity`, `-Infinity`.
   - Buffers: Empty buffer (`len = 0`), single-byte, misaligned buffers (offset by 1, 3, 5 bytes).
2. **Random Uniform Fuzz Vectors:**
   - 1,000 pseudo-random byte buffers generated with fixed seeds for deterministic reproducibility.

---

## 3. Python Verification Harness Blueprint

Below is an automated verification script blueprint comparing an original machine code slice with a reconstructed C implementation compiled via `ctypes`:

```python
import ctypes
import random
from unicorn import *
from unicorn.x86_const import *

# 1. Load compiled reconstructed function
reconstructed_lib = ctypes.CDLL("./reconstructed_code.so")
reconstructed_func = reconstructed_lib.reconstructed_algo
reconstructed_func.argtypes = [ctypes.c_uint32, ctypes.c_uint32]
reconstructed_func.restype = ctypes.c_uint32

# 2. Setup Unicorn emulator for the original native slice
ORIGINAL_CODE = bytes.fromhex("89F80FAF44240431D0C3") # native: imul eax, edx; xor eax, edx; ret
BASE_ADDR = 0x140000000
STACK_ADDR = 0x7FFF0000

def run_native_slice(val_a: int, val_b: int) -> int:
    mu = Uc(UC_ARCH_X86, UC_MODE_64)
    mu.mem_map(BASE_ADDR, 4096)
    mu.mem_map(STACK_ADDR, 4096)
    mu.mem_write(BASE_ADDR, ORIGINAL_CODE)
    mu.reg_write(UC_X86_REG_RSP, STACK_ADDR + 2048)

    # Set parameters in registers (System V AMD64: RDI, RSI)
    mu.reg_write(UC_X86_REG_RDI, val_a)
    mu.reg_write(UC_X86_REG_RSI, val_b)

    mu.emu_start(BASE_ADDR, BASE_ADDR + len(ORIGINAL_CODE))
    return mu.reg_read(UC_X86_REG_RAX) & 0xFFFFFFFF

# 3. Execute 1,000 differential test vectors
print("[*] Running 1,000 differential test vectors...")
for i in range(1000):
    val_a = random.randint(0, 0xFFFFFFFF)
    val_b = random.randint(0, 0xFFFFFFFF)

    expected = run_native_slice(val_a, val_b)
    actual = reconstructed_func(val_a, val_b)

    if expected != actual:
        raise AssertionError(f"[!] Equivalence Failure at vector {i}: args=({val_a}, {val_b}), expected=0x{expected:X}, actual=0x{actual:X}")

print("[+] Verification Succeeded: 1,000/1,000 test vectors matched with zero deltas.")
```

# Virtual Machine & Bytecode Analysis Guide
## Deconstructing Interpreted & Virtualized Execution Loops

Software protected by code virtualization (VMProtect, Themida, Code Virtualizer, or custom proprietary bytecode engines) converts native assembly into pseudo-bytecode executed by an internal software interpreter.

---

## 1. Architecture of a Virtual Machine Loop

A virtualization interpreter revolves around four architectural components:
1. **VIP (Virtual Instruction Pointer):** Dedicated register (e.g. `rsi` or `r14`) pointing to encrypted bytecode.
2. **VSP (Virtual Stack Pointer):** Dedicated register (e.g. `rbp` or `r15`) pointing to the virtual evaluation stack.
3. **VM Context:** A heap or stack structure holding mapped native CPU registers (RAX, RBX, RCX, RDX...).
4. **Dispatcher Loop:**
   ```nasm
   loc_dispatcher:
       movzx   eax, byte ptr [rsi]     ; Fetch virtual opcode
       inc     rsi                     ; Advance VIP
       jmp     qword ptr [r12 + rax*8] ; Jump to handler via jump table
   ```

---

## 2. Devirtualization Pipeline with `vm_analyzer.py`

Tracing a virtualized loop naively yields hundreds of thousands of identical dispatcher instructions. The Apex-RE devirtualization pipeline removes this noise:

```text
[Raw Execution Trace]
         │
         ▼
[Frequency Analysis] ──> Identifies Dispatcher Addresses (executed 100x more than handlers)
         │
         ▼
[Overhead Filtering] ──> Strips VIP incrementation and dispatcher jumps
         │
         ▼
[Handler Classification] ──> Labels operations (VPUSH, VPOP, VALU_ADD, VALU_XOR, VMOV)
         │
         ▼
[Backward Symbolic Slicing] ──> Isolates dependencies for target register (e.g. RAX at exit)
         │
         ▼
[Compilable Formula / C Code]
```

### Running the Analyzer

```bash

python skills/apex-re/scripts/vm_analyzer.py execution_trace.log --slice rax
```

---

## 3. Handler Pattern Signatures

| Semantic Operation | Common Handler Implementation |
| :--- | :--- |
| **`VPUSH Reg`** | `mov rax, [vm_ctx + off]; sub vsp, 8; mov [vsp], rax; jmp dispatcher` |
| **`VPUSH Imm`** | `mov rax, [vip]; add vip, 8; sub vsp, 8; mov [vsp], rax; jmp dispatcher` |
| **`VPOP Reg`** | `mov rax, [vsp]; add vsp, 8; mov [vm_ctx + off], rax; jmp dispatcher` |
| **`VALU ADD`** | `mov rax, [vsp]; add rax, [vsp+8]; add vsp, 8; mov [vsp], rax; jmp dispatcher` |
| **`VALU XOR`** | `mov rax, [vsp]; xor rax, [vsp+8]; add vsp, 8; mov [vsp], rax; jmp dispatcher` |
| **`VBRANCH`** | `test rax, rax; jz loc_false; mov vip, target_true; jmp dispatcher` |

By isolating only the arithmetic and memory writes, the underlying business logic or cryptographic calculation is recovered in clean high-level form.

```py
#!/usr/bin/env python3
"""
Apex-RE Triage Engine: Deep binary architecture, runtime & obfuscation detector.
Zero-dependency, production-grade binary triager.
Supports PE32/PE32+, ELF32/ELF64, Mach-O, WASM, Godot PCK, Unity, Unreal, .NET, Electron, Tauri, Python.
"""

import sys
import os
import struct
import math
import json
import argparse
from typing import Dict, Any, List, Optional, Tuple

def calculate_entropy(data: bytes) -> float:
    """Calculates Shannon entropy of a byte buffer (0.0 to 8.0)."""
    if not data:
        return 0.0
    entropy = 0.0
    length = len(data)
    frequencies = [0] * 256
    for b in data:
        frequencies[b] += 1
    for count in frequencies:
        if count > 0:
            p = count / length
            entropy -= p * math.log2(p)
    return round(entropy, 4)

class BinaryTriager:
    def __init__(self, file_path: str):
        self.file_path = file_path
        self.file_size = os.path.getsize(file_path) if os.path.exists(file_path) else 0
        self.results: Dict[str, Any] = {
            "file": os.path.basename(file_path),
            "size_bytes": self.file_size,
            "format": "Unknown",
            "architecture": "Unknown",
            "endianness": "little",
            "entry_point": None,
            "entropy_total": 0.0,
            "runtimes": [],
            "game_engine": None,
            "packers_and_protections": [],
            "rich_header": [],
            "anti_analysis": [],
            "sections": [],
            "anomalies": []
        }

    def analyze(self) -> Dict[str, Any]:
        if not os.path.isfile(self.file_path) or self.file_size == 0:
            self.results["format"] = "Empty or Missing File"
            return self.results

        with open(self.file_path, "rb") as f:
            header_sample = f.read(min(self.file_size, 4096))
            f.seek(0)
            full_sample = f.read(min(self.file_size, 10 * 1024 * 1024)) # Sample up to 10MB for scan

        self.results["entropy_total"] = calculate_entropy(full_sample)

        # 1. Format Detection
        if header_sample.startswith(b"MZ"):
            self._parse_pe(header_sample)
        elif header_sample.startswith(b"\x7fELF"):
            self._parse_elf(header_sample)
        elif header_sample.startswith((b"\xfe\xed\xfa\xce", b"\xfe\xed\xfa\xcf", b"\xce\xfa\xed\xfe", b"\xcf\xfa\xed\xfe", b"\xca\xfe\xba\xbe")):
            self._parse_macho(header_sample)
        elif header_sample.startswith(b"\x00asm"):
            self.results["format"] = "WebAssembly (WASM)"
            if len(header_sample) >= 8:
                version = struct.unpack("<I", header_sample[4:8])[0]
                self.results["architecture"] = f"WASM v{version}"
        elif header_sample.startswith(b"GDPC"):
            self.results["format"] = "Godot PCK Package"
            self.results["game_engine"] = "Godot"
        elif header_sample.startswith(b"UnityFS"):
            self.results["format"] = "Unity AssetBundle (UnityFS)"
            self.results["game_engine"] = "Unity"
        elif header_sample.startswith(b"PK\x03\x04"):
            self.results["format"] = "ZIP / Archive Container"

        # 2. Deep String / Symbol Signatures Scan
        self._scan_runtimes_and_engines(full_sample)

        # 3. Protection & Entropy Heuristics
        self._evaluate_protections()

        return self.results

    def _parse_pe(self, header: bytes):
        self.results["format"] = "PE (Portable Executable)"
        if len(header) < 0x40:
            return
        pe_offset = struct.unpack_from("<I", header, 0x3C)[0]
        self._parse_rich_header(header, pe_offset)
        if pe_offset + 24 > len(header):
            # Read further if pe_offset is outside 4KB
            with open(self.file_path, "rb") as f:
                f.seek(pe_offset)
                pe_sig_block = f.read(256)
        else:
            pe_sig_block = header[pe_offset:pe_offset+256]

        if not pe_sig_block.startswith(b"PE\x00\x00"):
            self.results["format"] = "MS-DOS Executable"
            return

        machine_id = struct.unpack_from("<H", pe_sig_block, 4)[0]
        num_sections = struct.unpack_from("<H", pe_sig_block, 6)[0]
        size_optional_header = struct.unpack_from("<H", pe_sig_block, 20)[0]

        arch_map = {
            0x14C: "x86 (32-bit)",
            0x8664: "x64 (AMD64 / 64-bit)",
            0xAA64: "ARM64",
            0x1C0: "ARM (Thumb)"
        }
        self.results["architecture"] = arch_map.get(machine_id, f"Unknown PE Machine (0x{machine_id:04X})")

        if size_optional_header > 0 and len(pe_sig_block) >= 24 + 2:
            magic_opt = struct.unpack_from("<H", pe_sig_block, 24)[0]
            if magic_opt == 0x10B:
                self.results["format"] = "PE32 (32-bit)"
                entry_point = struct.unpack_from("<I", pe_sig_block, 40)[0]
                self.results["entry_point"] = f"0x{entry_point:X}"
            elif magic_opt == 0x20B:
                self.results["format"] = "PE32+ (64-bit)"
                entry_point = struct.unpack_from("<I", pe_sig_block, 40)[0]
                self.results["entry_point"] = f"0x{entry_point:X}"

        # Section parsing
        sec_start = pe_offset + 24 + size_optional_header
        with open(self.file_path, "rb") as f:
            f.seek(sec_start)
            sec_data = f.read(num_sections * 40)

        for i in range(num_sections):
            offset = i * 40
            if offset + 40 > len(sec_data):
                break
            name_raw = sec_data[offset:offset+8].rstrip(b"\x00")
            name = name_raw.decode("latin1", errors="replace")
            vsize = struct.unpack_from("<I", sec_data, offset + 8)[0]
            vaddr = struct.unpack_from("<I", sec_data, offset + 12)[0]
            raw_size = struct.unpack_from("<I", sec_data, offset + 16)[0]
            raw_ptr = struct.unpack_from("<I", sec_data, offset + 20)[0]
            characteristics = struct.unpack_from("<I", sec_data, offset + 36)[0]

            sec_entropy = 0.0
            if raw_size > 0:
                if raw_ptr + raw_size > self.file_size:
                    self.results["anomalies"].append(
                        f"Section {name} raw data points beyond file boundaries (pointer 0x{raw_ptr:X}, size 0x{raw_size:X}, file size 0x{self.file_size:X})"
                    )
                else:
                    with open(self.file_path, "rb") as f:
                        f.seek(raw_ptr)
                        s_bytes = f.read(min(raw_size, 1024 * 512))
                        sec_entropy = calculate_entropy(s_bytes)

            is_executable = bool(characteristics & 0x20000000)
            is_writable = bool(characteristics & 0x80000000)

            # Detect anomalies
            if is_executable and is_writable:
                self.results["anomalies"].append(f"Section {name} is Writable and Executable (W+X) - potential unpacker / shellcode")
            if raw_size == 0 and vsize > 0x1000:
                self.results["anomalies"].append(f"Section {name} has zero disk size but {vsize} bytes virtual size")

            self.results["sections"].append({
                "name": name,
                "virtual_size": vsize,
                "virtual_address": f"0x{vaddr:X}",
                "raw_size": raw_size,
                "entropy": sec_entropy,
                "executable": is_executable,
                "writable": is_writable
            })

    def _parse_rich_header(self, header: bytes, pe_offset: int):
        """Parses MSVC Rich Header (compiler product IDs and telemetry)."""
        limit = min(pe_offset, len(header), 4096)
        stub = header[:limit]
        rich_idx = stub.find(b"Rich")
        if rich_idx == -1 or rich_idx + 8 > len(stub):
            return

        xor_key = struct.unpack_from("<I", stub, rich_idx + 4)[0]
        # Search backward for DanS xor'd with xor_key
        dans_magic = struct.pack("<I", 0x536E6144 ^ xor_key) # "DanS"
        dans_idx = stub.rfind(dans_magic, 0, rich_idx)
        if dans_idx == -1:
            return

        # Entry records are 8 bytes each between dans_idx + 16 (after padding) and rich_idx
        prod_map = {
            0x00EB: "VS2015 Resource Compiler",
            0x00FF: "VS2015 C++ Compiler",
            0x0102: "VS2017 Linker",
            0x0103: "VS2017 C++ Compiler",
            0x0104: "VS2019/VS2022 C++ Compiler",
            0x0105: "VS2019/VS2022 Linker",
            0x0107: "VS2019/VS2022 MASM",
            0x0014: "VS2010 C++ Compiler",
            0x001A: "VS2012 C++ Compiler",
            0x00DE: "VS2013 C++ Compiler"
        }

        entry_start = dans_idx + 16
        while entry_start + 8 <= rich_idx:
            comp_id_enc = struct.unpack_from("<I", stub, entry_start)[0]
            count_enc = struct.unpack_from("<I", stub, entry_start + 4)[0]
            comp_id = comp_id_enc ^ xor_key
            count = count_enc ^ xor_key

            prod_id = (comp_id >> 16) & 0xFFFF
            build_id = comp_id & 0xFFFF
            tool_name = prod_map.get(prod_id, f"Tool_0x{prod_id:04X}")

            self.results["rich_header"].append({
                "product_id": f"0x{prod_id:04X}",
                "build_id": build_id,
                "tool": tool_name,
                "count": count
            })
            entry_start += 8

        if self.results["rich_header"]:
            if "MSVC Toolchain (Rich Header Verified)" not in self.results["runtimes"]:
                self.results["runtimes"].append("MSVC Toolchain (Rich Header Verified)")

    def _parse_elf(self, header: bytes):
        self.results["format"] = "ELF (Executable and Linkable Format)"
        if len(header) < 52:
            return
        ei_class = header[4]
        ei_data = header[5]
        self.results["endianness"] = "little" if ei_data == 1 else "big"
        fmt = "<" if ei_data == 1 else ">"

        elf_machines = {
            0x03: "x86",
            0x3E: "x64 (x86_64)",
            0x28: "ARM",
            0xB7: "AArch64 (ARM64)",
            0xF3: "RISC-V"
        }

        if ei_class == 1:
            self.results["format"] = "ELF32"
            machine = struct.unpack_from(f"{fmt}H", header, 18)[0]
            entry = struct.unpack_from(f"{fmt}I", header, 24)[0]
            shoff = struct.unpack_from(f"{fmt}I", header, 32)[0]
            shentsize = struct.unpack_from(f"{fmt}H", header, 46)[0]
            shnum = struct.unpack_from(f"{fmt}H", header, 48)[0]
            shstrndx = struct.unpack_from(f"{fmt}H", header, 50)[0]
            self.results["entry_point"] = f"0x{entry:X}"
        else:
            self.results["format"] = "ELF64"
            if len(header) < 64:
                return
            machine = struct.unpack_from(f"{fmt}H", header, 18)[0]
            entry = struct.unpack_from(f"{fmt}Q", header, 24)[0]
            shoff = struct.unpack_from(f"{fmt}Q", header, 40)[0]
            shentsize = struct.unpack_from(f"{fmt}H", header, 58)[0]
            shnum = struct.unpack_from(f"{fmt}H", header, 60)[0]
            shstrndx = struct.unpack_from(f"{fmt}H", header, 62)[0]
            self.results["entry_point"] = f"0x{entry:X}"

        self.results["architecture"] = elf_machines.get(machine, f"ELF Machine 0x{machine:02X}")

        # Parse ELF Sections if present
        if shoff > 0 and shnum > 0 and shentsize > 0 and shoff + (shnum * shentsize) <= self.file_size:
            try:
                with open(self.file_path, "rb") as f:
                    f.seek(shoff)
                    sh_data = f.read(shnum * shentsize)

                    shstrtab = b""
                    if shstrndx < shnum:
                        str_offset = shstrndx * shentsize
                        if ei_class == 1 and str_offset + 24 <= len(sh_data):
                            tab_off = struct.unpack_from(f"{fmt}I", sh_data, str_offset + 16)[0]
                            tab_sz = struct.unpack_from(f"{fmt}I", sh_data, str_offset + 20)[0]
                        elif ei_class == 2 and str_offset + 40 <= len(sh_data):
                            tab_off = struct.unpack_from(f"{fmt}Q", sh_data, str_offset + 24)[0]
                            tab_sz = struct.unpack_from(f"{fmt}Q", sh_data, str_offset + 32)[0]
                        else:
                            tab_off, tab_sz = 0, 0
                        if tab_off > 0 and tab_off + tab_sz <= self.file_size:
                            f.seek(tab_off)
                            shstrtab = f.read(min(tab_sz, 64 * 1024))

                    for i in range(shnum):
                        s_off = i * shentsize
                        if ei_class == 1:
                            name_idx = struct.unpack_from(f"{fmt}I", sh_data, s_off)[0]
                            flags = struct.unpack_from(f"{fmt}I", sh_data, s_off + 8)[0]
                            vaddr = struct.unpack_from(f"{fmt}I", sh_data, s_off + 12)[0]
                            offset_p = struct.unpack_from(f"{fmt}I", sh_data, s_off + 16)[0]
                            size_p = struct.unpack_from(f"{fmt}I", sh_data, s_off + 20)[0]
                        else:
                            name_idx = struct.unpack_from(f"{fmt}I", sh_data, s_off)[0]
                            flags = struct.unpack_from(f"{fmt}Q", sh_data, s_off + 8)[0]
                            vaddr = struct.unpack_from(f"{fmt}Q", sh_data, s_off + 16)[0]
                            offset_p = struct.unpack_from(f"{fmt}Q", sh_data, s_off + 24)[0]
                            size_p = struct.unpack_from(f"{fmt}Q", sh_data, s_off + 32)[0]

                        sec_name = ""
                        if shstrtab and name_idx < len(shstrtab):
                            null_p = shstrtab.find(b"\x00", name_idx)
                            sec_name = shstrtab[name_idx:null_p if null_p != -1 else None].decode("latin1", errors="replace")
                        if not sec_name:
                            sec_name = f"elf_sec_{i}"

                        sec_entropy = 0.0
                        if size_p > 0 and offset_p + size_p <= self.file_size:
                            f.seek(offset_p)
                            sec_bytes = f.read(min(size_p, 512 * 1024))
                            sec_entropy = calculate_entropy(sec_bytes)

                        is_writable = bool(flags & 0x1) # SHF_WRITE
                        is_executable = bool(flags & 0x4) # SHF_EXECINSTR

                        if is_writable and is_executable:
                            self.results["anomalies"].append(f"ELF Section {sec_name} is Writable and Executable (W+X) - potential unpacker / shellcode")

                        self.results["sections"].append({
                            "name": sec_name,
                            "virtual_size": size_p,
                            "virtual_address": f"0x{vaddr:X}",
                            "raw_size": size_p,
                            "entropy": sec_entropy,
                            "executable": is_executable,
                            "writable": is_writable
                        })
            except Exception:
                pass

    def _parse_macho(self, header: bytes):
        self.results["format"] = "Mach-O"
        if len(header) < 8:
            return
        magic = struct.unpack(">I", header[:4])[0]

        macho_arch_map = {
            0x00000007: "x86 (32-bit)",
            0x01000007: "x64 (x86_64)",
            0x0000000C: "ARM (32-bit)",
            0x0100000C: "ARM64 (AArch64)",
            0x0200000C: "ARM64_32",
            0x00000012: "PowerPC",
            0x01000012: "PowerPC 64"
        }

        if magic in (0xFEEDFACE, 0xCEFAEDFE):
            self.results["format"] = "Mach-O 32-bit"
            endian = ">" if magic == 0xFEEDFACE else "<"
            self.results["endianness"] = "big" if endian == ">" else "little"
            cputype = struct.unpack(f"{endian}I", header[4:8])[0]
            self.results["architecture"] = macho_arch_map.get(cputype, f"Mach-O CPU 0x{cputype:08X}")
        elif magic in (0xFEEDFACF, 0xCFFAEDFE):
            self.results["format"] = "Mach-O 64-bit"
            endian = ">" if magic == 0xFEEDFACF else "<"
            self.results["endianness"] = "big" if endian == ">" else "little"
            cputype = struct.unpack(f"{endian}I", header[4:8])[0]
            self.results["architecture"] = macho_arch_map.get(cputype, f"Mach-O CPU 0x{cputype:08X}")
        elif magic in (0xCAFEBABE, 0xBEBAFECA):
            minor = struct.unpack(">H", header[4:6])[0]
            major = struct.unpack(">H", header[6:8])[0]
            if minor == 0 and 45 <= major <= 75:
                self.results["format"] = f"Java Class Bytecode (v{major}.{minor})"
                self.results["architecture"] = "JVM Bytecode"
                self.results["runtimes"].append("Java Virtual Machine (JVM)")
                return

            self.results["format"] = "Mach-O Universal (Fat Binary)"
            endian = ">" if magic == 0xCAFEBABE else "<"
            self.results["endianness"] = "big" if endian == ">" else "little"
            nfat = struct.unpack(f"{endian}I", header[4:8])[0]
            archs = []
            if nfat <= 20 and len(header) >= 8 + nfat * 20:
                for idx in range(nfat):
                    arch_off = 8 + idx * 20
                    cpu = struct.unpack(f"{endian}I", header[arch_off:arch_off+4])[0]
                    arch_name = macho_arch_map.get(cpu, f"0x{cpu:08X}")
                    archs.append(arch_name)
            self.results["architecture"] = f"Multi-Arch ({', '.join(archs)})" if archs else "Universal (Fat Binary)"

#!/usr/bin/env python3
"""
Apex-RE Kaitai Struct Synthesizer.
Analyzes proprietary binary blobs / network packets and synthesizes valid Kaitai Struct (.ksy) YAML specifications.
Zero dependencies (Python 3 standard library).
"""

import sys
import os
import struct
import math
import argparse
from typing import Dict, Any, List, Optional, Tuple

class KaitaiSynthesizer:
    def __init__(self, data: bytes, struct_id: str = "binary_payload", endian: str = "auto"):
        self.data = data
        self.struct_id = struct_id
        self.endian = self._determine_endianness(endian)
        self.fields: List[Dict[str, Any]] = []

    def _determine_endianness(self, user_endian: str) -> str:
        if user_endian in ("le", "be"):
            return user_endian
        if len(self.data) < 8:
            return "le"

        # Heuristic: inspect 32-bit values in first 16 bytes
        # In LE, small values (e.g. lengths, counts < 65536) have zeros in high bytes: [val, 0, 0, 0]
        # In BE, they have zeros in low bytes: [0, 0, 0, val]
        le_zeros = 0
        be_zeros = 0
        for off in range(0, min(len(self.data) - 4, 32), 4):
            b = self.data[off:off+4]
            if b[2] == 0 and b[3] == 0 and (b[0] != 0 or b[1] != 0):
                le_zeros += 1
            if b[0] == 0 and b[1] == 0 and (b[2] != 0 or b[3] != 0):
                be_zeros += 1
        return "le" if le_zeros >= be_zeros else "be"

    def synthesize(self) -> str:
        self.fields.clear()
        offset = 0
        total_len = len(self.data)

        # 1. Magic check (first 2-4 bytes if printable ascii)
        if total_len >= 4:
            magic_candidate = self.data[:4]
            if all(32 <= b <= 126 for b in magic_candidate):
                self.fields.append({
                    "id": "magic",
                    "type": "str",
                    "size": 4,
                    "encoding": "ASCII",
                    "doc": f"Header signature ('{magic_candidate.decode('ascii')}')",
                    "contents": f"\"{magic_candidate.decode('ascii')}\""
                })
                offset += 4
            elif magic_candidate.startswith(b"\x00") or any(magic_candidate):
                # hex bytes
                hex_list = ", ".join(f"0x{b:02x}" for b in magic_candidate)
                self.fields.append({
                    "id": "magic",
                    "contents": f"[{hex_list}]",
                    "doc": "Magic binary header bytes"
                })
                offset += 4

        field_counter = 0

        prefix = "<" if self.endian == "le" else ">"

        # Scan remaining fields
        while offset < total_len:
            rem = total_len - offset
            field_name = f"field_{field_counter:02d}"

            # Check for null-terminated string candidate
            if rem >= 4 and 32 <= self.data[offset] <= 126:
                null_pos = self.data.find(b"\x00", offset)
                if null_pos != -1 and 3 <= (null_pos - offset) <= 64:
                    s_bytes = self.data[offset:null_pos]
                    if all(32 <= b <= 126 or b in (9, 10, 13) for b in s_bytes):
                        str_val = s_bytes.decode("latin1")
                        self.fields.append({
                            "id": f"str_{field_counter:02d}",
                            "type": "strz",
                            "encoding": "UTF-8",
                            "doc": f"Null-terminated string (sample: '{str_val[:20]}')"
                        })
                        offset = null_pos + 1
                        field_counter += 1
                        continue

            # Check for float32 candidate
            if rem >= 4:
                val_f32 = struct.unpack_from(f"{prefix}f", self.data, offset)[0]
                if not math.isnan(val_f32) and not math.isinf(val_f32) and 0.0001 <= abs(val_f32) <= 1000000.0 and abs(val_f32 - round(val_f32, 2)) < 0.05:
                    self.fields.append({
                        "id": f"float_{field_counter:02d}",
                        "type": "f4",
                        "doc": f"Offset 0x{offset:04X} (float sample: {val_f32:.4f})"
                    })
                    offset += 4
                    field_counter += 1
                    continue

            # Standard primitives
            is_u64 = False
            if rem >= 8 and (offset % 8 == 0 or rem == 8):
                val_u64 = struct.unpack_from(f"{prefix}Q", self.data, offset)[0]
                # True 64-bit integer indicated by non-zero upper 32-bits (timestamps, 64-bit GUIDs, offsets)
                if val_u64 > 0xFFFFFFFF:
                    is_u64 = True
                    self.fields.append({
                        "id": f"val64_{field_counter:02d}",
                        "type": "u8",
                        "doc": f"Offset 0x{offset:04X} (uint64: {val_u64} / 0x{val_u64:X})"
                    })
                    offset += 8

            if not is_u64:
                if rem >= 4:
                    val_u32 = struct.unpack_from(f"{prefix}I", self.data, offset)[0]
                    self.fields.append({
                        "id": f"uint_{field_counter:02d}",
                        "type": "u4",
                        "doc": f"Offset 0x{offset:04X} (uint32: {val_u32} / 0x{val_u32:X})"
                    })
                    offset += 4
                elif rem >= 2:
                    val_u16 = struct.unpack_from(f"{prefix}H", self.data, offset)[0]
                    self.fields.append({
                        "id": f"word_{field_counter:02d}",
                        "type": "u2",
                        "doc": f"Offset 0x{offset:04X} (uint16: {val_u16})"
                    })
                    offset += 2
                else:
                    self.fields.append({
                        "id": f"byte_{field_counter:02d}",
                        "type": "u1",
                        "doc": f"Offset 0x{offset:04X} (raw byte: 0x{self.data[offset]:02X})"
                    })
                    offset += 1
            field_counter += 1

        # Emit Kaitai Struct YAML
        lines = []
        lines.append(f"meta:")
        lines.append(f"  id: {self.struct_id}")
        lines.append(f"  file-extension: bin")
        lines.append(f"  endian: {self.endian}")
        lines.append(f"")
        lines.append(f"doc: |")
        lines.append(f"  Synthesized specification for {self.struct_id} ({total_len} bytes)")
        lines.append(f"  Generated autonomously by Apex-RE Kaitai Synthesizer.")
        lines.append(f"")
        lines.append(f"seq:")

        for f in self.fields:
            lines.append(f"  - id: {f['id']}")
            if "contents" in f:
                lines.append(f"    contents: {f['contents']}")

#!/usr/bin/env python3
"""
Apex-RE Memory Snapshot Differ & Struct Layout Synthesizer.
Takes two memory dumps (before & after action) and extracts modified fields,
pointer updates, and generates compilable C++ and C# struct layouts.
Zero dependencies (Python 3 standard library).
"""

import sys
import os
import struct
import math
import json
import argparse
from typing import Dict, Any, List, Optional, Tuple

class MemoryDiffer:
    def __init__(self, buf_a: bytes, buf_b: bytes, base_addr: int = 0, alignment: int = 1):
        self.buf_a = buf_a
        self.buf_b = buf_b
        self.base_addr = base_addr
        self.alignment = alignment
        self.min_len = min(len(buf_a), len(buf_b))
        self.diffs: List[Dict[str, Any]] = []

    def compute_diffs(self) -> List[Dict[str, Any]]:
        self.diffs.clear()
        i = 0
        step = max(1, self.alignment)
        while i < self.min_len:
            # Check slice if alignment > 1, else single byte
            slice_end = min(i + step, self.min_len)
            if self.buf_a[i:slice_end] != self.buf_b[i:slice_end]:
                # Found difference within this aligned block; locate first differing byte
                diff_sub = next((k for k in range(slice_end - i) if self.buf_a[i + k] != self.buf_b[i + k]), 0)
                byte_a = self.buf_a[i + diff_sub]
                byte_b = self.buf_b[i + diff_sub]
                types = self._interpret_types(i)
                self.diffs.append({
                    "offset": i,
                    "address": f"0x{self.base_addr + i:X}",
                    "byte_before": byte_a,
                    "byte_after": byte_b,
                    "interpretations": types
                })
            i += step
        return self.diffs

    def _interpret_types(self, offset: int) -> Dict[str, Any]:
        interp = {}
        # 1-byte
        b_a = self.buf_a[offset]
        b_b = self.buf_b[offset]
        interp["u8"] = {"before": b_a, "after": b_b, "delta": b_b - b_a}

        # 2-byte
        if offset + 2 <= self.min_len:
            u16_a = struct.unpack_from("<H", self.buf_a, offset)[0]
            u16_b = struct.unpack_from("<H", self.buf_b, offset)[0]
            s16_a = struct.unpack_from("<h", self.buf_a, offset)[0]
            s16_b = struct.unpack_from("<h", self.buf_b, offset)[0]
            interp["u16"] = {"before": u16_a, "after": u16_b, "delta": u16_b - u16_a}
            interp["i16"] = {"before": s16_a, "after": s16_b, "delta": s16_b - s16_a}

        # 4-byte
        if offset + 4 <= self.min_len:
            u32_a = struct.unpack_from("<I", self.buf_a, offset)[0]
            u32_b = struct.unpack_from("<I", self.buf_b, offset)[0]
            s32_a = struct.unpack_from("<i", self.buf_a, offset)[0]
            s32_b = struct.unpack_from("<i", self.buf_b, offset)[0]
            f32_a = struct.unpack_from("<f", self.buf_a, offset)[0]
            f32_b = struct.unpack_from("<f", self.buf_b, offset)[0]
            interp["u32"] = {"before": u32_a, "after": u32_b, "delta": u32_b - u32_a}
            interp["i32"] = {"before": s32_a, "after": s32_b, "delta": s32_b - s32_a}
            interp["f32"] = {"before": round(f32_a, 4), "after": round(f32_b, 4), "delta": round(f32_b - f32_a, 4)}

        # 8-byte
        if offset + 8 <= self.min_len:
            u64_a = struct.unpack_from("<Q", self.buf_a, offset)[0]
            u64_b = struct.unpack_from("<Q", self.buf_b, offset)[0]
            s64_a = struct.unpack_from("<q", self.buf_a, offset)[0]
            s64_b = struct.unpack_from("<q", self.buf_b, offset)[0]
            f64_a = struct.unpack_from("<d", self.buf_a, offset)[0]
            f64_b = struct.unpack_from("<d", self.buf_b, offset)[0]
            interp["u64"] = {"before": u64_a, "after": u64_b, "delta": u64_b - u64_a}
            interp["i64"] = {"before": s64_a, "after": s64_b, "delta": s64_b - s64_a}
            interp["f64"] = {"before": round(f64_a, 6), "after": round(f64_b, 6), "delta": round(f64_b - f64_a, 6)}
            # Check if looks like 64-bit user pointer (aligned to 8 bytes, address range: 0x0000000000010000 .. 0x00007FFFFFFFFFFF)
            if offset % 8 == 0 and 0x10000 <= u64_b <= 0x7FFFFFFFFFFF:
                interp["ptr64"] = {"before": f"0x{u64_a:016X}", "after": f"0x{u64_b:016X}"}

        return interp

    def synthesize_struct(self, struct_name: str = "RecoveredState") -> Dict[str, str]:
        """Synthesizes C++ and C# struct layouts from identified field offsets."""
        cpp_lines = [f"// Auto-generated by Apex-RE Memory Synthesizer", f"#include <cstdint>", f"", f"struct {struct_name} {{"]
        cs_lines = [f"// Auto-generated by Apex-RE Memory Synthesizer", f"using System;", f"using System.Runtime.InteropServices;", f"", f"[StructLayout(LayoutKind.Explicit)]", f"public struct {struct_name}", f"{{"]

        last_offset = 0
        pad_idx = 0

        # Cluster diffs: pick most representative type (defaulting to u32 or u64 if aligned)
        clustered = []
        for d in self.diffs:
            off = d["offset"]
            types = d["interpretations"]
            chosen_type = "uint8_t"
            cs_type = "byte"
            size = 1

            has_ptr = "ptr64" in types and off % 8 == 0 and (types.get("u64", {}).get("after", 0) > 0xFFFFFFFF or types.get("u64", {}).get("before", 0) > 0xFFFFFFFF)
            has_f32 = "f32" in types and abs(types["f32"]["delta"]) > 0.0001 and not math.isnan(types["f32"]["after"]) and not math.isinf(types["f32"]["after"])
            has_i32 = "i32" in types and types["i32"]["delta"] != 0 and off % 4 == 0

            if has_ptr:
                chosen_type = "uintptr_t"
                cs_type = "IntPtr"
                size = 8
            elif has_f32 and (not has_i32 or abs(types["f32"]["after"] - round(types["f32"]["after"])) > 0.0001 or abs(types["f32"]["before"] - round(types["f32"]["before"])) > 0.0001):
                chosen_type = "float"
                cs_type = "float"
                size = 4
            elif has_i32:
                chosen_type = "int32_t"
                cs_type = "int"
                size = 4
            elif has_f32:
                chosen_type = "float"
                cs_type = "float"
                size = 4
            elif "u32" in types and off % 4 == 0:
                chosen_type = "uint32_t"
                cs_type = "uint"
                size = 4
            elif "u16" in types and off % 2 == 0:
                chosen_type = "uint16_t"
                cs_type = "ushort"
                size = 2

            clustered.append((off, chosen_type, cs_type, size, types))

        # Filter overlapping clusters
        filtered = []
        cur_end = -1
        for off, c_t, cs_t, sz, types in clustered:
            if off >= cur_end:
                filtered.append((off, c_t, cs_t, sz, types))
                cur_end = off + sz

        for off, c_t, cs_t, sz, types in filtered:
            # Padding
            if off > last_offset:
                pad_len = off - last_offset
                cpp_lines.append(f"    uint8_t _pad_{pad_idx:02X}[0x{pad_len:X}]; // 0x{last_offset:04X} -> 0x{off:04X}")
                pad_idx += 1

            field_name = f"field_0x{off:04X}"
            info = ""
            if c_t in ("int32_t", "uint32_t") and "i32" in types:
                delta = types["i32"]["delta"]
                info = f" // changed: {types['i32']['before']} -> {types['i32']['after']} (delta: {delta:+d})"
            elif c_t == "float" and "f32" in types:
                info = f" // changed: {types['f32']['before']}f -> {types['f32']['after']}f"
            elif "ptr64" in types:
                info = f" // ptr: {types['ptr64']['before']} -> {types['ptr64']['after']}"

            cpp_lines.append(f"    {c_t} {field_name};{info}")
            cs_lines.append(f"    [FieldOffset(0x{off:X})] public {cs_t} {field_name};{info}")
            last_offset = off + sz

        cpp_lines.append(f"}}; // Total covered: 0x{last_offset:X} bytes")
        cs_lines.append(f"}}")

        return {
            "cpp": "\n".join(cpp_lines),
            "csharp": "\n".join(cs_lines)
        }

#!/usr/bin/env python3
"""
Apex-RE Pattern & Wildcard Signature Scanner (sig_scan.py)
Autonomous binary pattern matching, RIP-relative displacement resolution,
and stable signature synthesis for AI coding agents.

Zero external dependencies. Python 3.8+ compatible.
"""

import sys
import os
import re
import struct
import json
from typing import List, Dict, Optional, Tuple, Any

class PatternScanner:
    """High-performance pattern scanner with wildcard and RIP-relative displacement support."""

    @staticmethod
    def parse_ida_pattern(pattern_str: str) -> Tuple[bytes, bytes]:
        """
        Parses an IDA / Cheat Engine style pattern string into (pattern_bytes, mask_bytes).
        e.g. "48 8B 05 ? ? ? ? 48 85 C0" -> pattern and mask.
        """
        tokens = pattern_str.strip().split()
        pat_list = []
        mask_list = []

        for token in tokens:
            if token in ('?', '??'):
                pat_list.append(0x00)
                mask_list.append(0x00)
            else:
                pat_list.append(int(token, 16))
                mask_list.append(0xFF)

        return bytes(pat_list), bytes(mask_list)

    @classmethod
    def scan_pattern(cls, data: bytes, pattern: bytes, mask: bytes, max_matches: int = 100) -> List[int]:
        """
        Scans a binary buffer for pattern matching the given mask.
        Returns list of integer offsets where matches occur.
        """
        pat_len = len(pattern)
        data_len = len(data)
        matches = []

        if pat_len == 0 or pat_len > data_len:
            return matches

        # Quick check optimization: first non-wildcard byte
        first_idx = 0
        while first_idx < pat_len and mask[first_idx] == 0:
            first_idx += 1

        if first_idx >= pat_len:
            # All wildcards - not allowed
            return matches

        first_byte = pattern[first_idx]
        pos = 0

        while pos <= data_len - pat_len:
            # Fast scan for first concrete byte
            found = data.find(bytes([first_byte]), pos + first_idx)
            if found == -1:
                break
            
            cand_pos = found - first_idx
            if cand_pos + pat_len > data_len:
                break

            # Compare remaining bytes with mask
            match = True
            for i in range(pat_len):
                if mask[i] != 0 and data[cand_pos + i] != pattern[i]:
                    match = False
                    break

            if match:
                matches.append(cand_pos)
                if len(matches) >= max_matches:
                    break

            pos = cand_pos + 1

        return matches

    @staticmethod
    def resolve_rip_relative(data: bytes, match_offset: int, disp_offset_within_match: int,
                             instruction_length: int, image_base: int = 0x140000000) -> Dict[str, Any]:
        """
        Calculates the target absolute Virtual Address (VA) for an x86_64 RIP-relative instruction.
        Formula: Target VA = ImageBase + MatchOffset + InstructionLength + int32(Displacement)
        """
        abs_disp_pos = match_offset + disp_offset_within_match
        if abs_disp_pos + 4 > len(data):
            return {"error": "Displacement offset out of bounds"}

        displacement = struct.unpack("<i", data[abs_disp_pos:abs_disp_pos + 4])[0]
        next_rip_offset = match_offset + instruction_length
        target_rva = next_rip_offset + displacement
        target_va = image_base + target_rva

        return {
            "match_offset": match_offset,
            "match_rva": hex(match_offset),
            "displacement": displacement,
            "target_rva": hex(target_rva),
            "target_va": hex(target_va),
            "target_rva_int": target_rva,
            "target_va_int": target_va
        }

    @staticmethod
    def synthesize_unique_signature(data: bytes, target_offset: int, max_length: int = 64,
                                   wildcard_disp: bool = True) -> Optional[Dict[str, Any]]:
        """
        Autonomously synthesizes a stable, unique IDA-style signature for code at target_offset.
        """
        data_len = len(data)
        if target_offset < 0 or target_offset >= data_len:
            return None

        # Build progressive signature
        for current_len in range(8, min(max_length + 1, data_len - target_offset)):
            candidate_bytes = data[target_offset:target_offset + current_len]
            pat_tokens = []
            mask_tokens = []

            i = 0
            while i < current_len:
                # Detect x86_64 RIP-relative MOV (48 8B 05 ?? ?? ?? ??) or CALL (E8 ?? ?? ?? ??)
                if wildcard_disp and i + 7 <= current_len and candidate_bytes[i:i+3] == b"\x48\x8B\x05":
                    pat_tokens.extend(["48", "8B", "05", "?", "?", "?", "?"])
                    mask_tokens.extend([0xFF, 0xFF, 0xFF, 0x00, 0x00, 0x00, 0x00])
                    i += 7
                elif wildcard_disp and i + 5 <= current_len and candidate_bytes[i] in (0xE8, 0xE9):
                    pat_tokens.extend([f"{candidate_bytes[i]:02X}", "?", "?", "?", "?"])
                    mask_tokens.extend([0xFF, 0x00, 0x00, 0x00, 0x00])
                    i += 5
                else:
                    pat_tokens.append(f"{candidate_bytes[i]:02X}")
                    mask_tokens.append(0xFF)
                    i += 1

            pat_str = " ".join(pat_tokens)
            p_bytes, m_bytes = PatternScanner.parse_ida_pattern(pat_str)
            matches = PatternScanner.scan_pattern(data, p_bytes, m_bytes, max_matches=2)

            if len(matches) == 1 and matches[0] == target_offset:
                return {
                    "pattern": pat_str,
                    "length": len(p_bytes),
                    "unique": True,
                    "offset": target_offset
                }

        # Non-wildcarded fallback if wildcarded was ambiguous
        for current_len in range(8, min(max_length + 1, data_len - target_offset)):
            candidate_bytes = data[target_offset:target_offset + current_len]
            pat_str = " ".join(f"{b:02X}" for b in candidate_bytes)
            p_bytes, m_bytes = PatternScanner.parse_ida_pattern(pat_str)
            matches = PatternScanner.scan_pattern(data, p_bytes, m_bytes, max_matches=2)
            if len(matches) == 1:
                return {
                    "pattern": pat_str,
                    "length": current_len,
                    "unique": True,
                    "offset": target_offset
                }

        return None

#!/usr/bin/env python3
"""
Apex-RE Control Flow Unflattening Analyzer & Trace Reconstructor.
Deobfuscates OLLVM / state-dispatcher flattened control flow graphs (CFG)
into linear execution sequences and structured C pseudocode.
Zero dependencies (Python 3 standard library).
"""

import sys
import os
import json
import re
import argparse
from typing import Dict, Any, List, Optional, Set, Tuple

class ControlFlowUnflattener:
    def __init__(self, trace_data: List[Dict[str, Any]]):
        self.raw_trace = trace_data
        self.state_handlers: Dict[int, Dict[str, Any]] = {}
        self.transitions: List[Tuple[int, int, Optional[str]]] = []
        self.entry_state: Optional[int] = None
        self.terminal_states: Set[int] = set()

    @classmethod
    def from_json(cls, json_str: str) -> "ControlFlowUnflattener":
        data = json.loads(json_str)
        if isinstance(data, dict) and "trace" in data:
            data = data["trace"]
        return cls(data)

    @classmethod
    def from_text_log(cls, text: str) -> "ControlFlowUnflattener":
        """Parses log lines with patterns like: State: 0x1 -> Block: BB_1 -> Code: 'x = 1;' -> Next: 0x2"""
        entries = []
        for line in text.splitlines():
            line = line.strip()
            if not line:
                continue

            state_m = re.search(r"state[:\s]+(0x[0-9a-fA-F]+|\d+)", line, re.IGNORECASE)
            block_m = re.search(r"block[:\s]+(\w+)", line, re.IGNORECASE)
            code_m = re.search(r"code[:\s]+['\"](.*?)['\"]", line, re.IGNORECASE)
            next_m = re.search(r"next[:\s]+(0x[0-9a-fA-F]+|\d+|exit|return)", line, re.IGNORECASE)

            if state_m:
                s_val = int(state_m.group(1), 0)
                b_name = block_m.group(1) if block_m else f"bb_{s_val}"
                code = code_m.group(1) if code_m else f"/* execute {b_name} */"
                n_val = None
                if next_m:
                    n_raw = next_m.group(1).lower()
                    if n_raw not in ("exit", "return"):
                        n_val = int(n_raw, 0)

                entries.append({
                    "state": s_val,
                    "block": b_name,
                    "code": code,
                    "next_state": n_val
                })
        return cls(entries)

    def analyze(self):
        if not self.raw_trace:
            return

        self.entry_state = self.raw_trace[0]["state"]

        for item in self.raw_trace:
            st = item["state"]
            block = item.get("block", f"bb_state_{st}")
            code = item.get("code", "")
            nxt = item.get("next_state")
            cond = item.get("condition")

            if st not in self.state_handlers:
                self.state_handlers[st] = {
                    "block": block,
                    "code": code,
                    "successors": []
                }
            
            if nxt is not None:
                self.transitions.append((st, nxt, cond))
                if nxt not in [s[0] for s in self.state_handlers[st]["successors"]]:
                    self.state_handlers[st]["successors"].append((nxt, cond))
            else:
                self.terminal_states.add(st)

    def reconstruct_c_code(self) -> str:
        """Emits clean, de-flattened structured C code."""
        lines = []
        lines.append("// Apex-RE De-obfuscated Control Flow")
        lines.append("// Dispatcher loop and artificial state variables removed")
        lines.append("")
        lines.append("void reconstructed_function() {")

        if self.entry_state is None:
            lines.append("}")
            return "\n".join(lines)

        # Collect reachable states in topological / BFS order
        reachable = []
        queue = [self.entry_state]
        visited = set()
        while queue:
            st = queue.pop(0)
            if st in visited:
                continue
            visited.add(st)
            reachable.append(st)
            handler = self.state_handlers.get(st, {})
            for nxt, _ in handler.get("successors", []):
                if nxt not in visited and nxt not in queue:
                    queue.append(nxt)

        # Include any remaining disconnected handlers
        for st in self.state_handlers:
            if st not in visited:
                reachable.append(st)

        for idx, st in enumerate(reachable):
            handler = self.state_handlers.get(st)
            if not handler:
                continue

            lines.append(f"state_0x{st:X}: // [{handler['block']}]")
            if handler["code"]:
                for c_line in handler["code"].split(";"):
                    c_line = c_line.strip()
                    if c_line:
                        lines.append(f"    {c_line};")

            successors = handler["successors"]
            if not successors:
                lines.append("    return;")
            elif len(successors) == 1:
                next_st, _ = successors[0]
                if idx + 1 < len(reachable) and reachable[idx + 1] == next_st:
                    # Natural fallthrough to next sequential block
                    pass
                else:
                    lines.append(f"    goto state_0x{next_st:X};")
            elif len(successors) == 2:
                s1, c1 = successors[0]
                s2, c2 = successors[1]
                cond_str = c1 or "condition"
                lines.append(f"    if ({cond_str}) {{")
                lines.append(f"        goto state_0x{s1:X};")
                lines.append(f"    }} else {{")
                lines.append(f"        goto state_0x{s2:X};")
                lines.append(f"    }}")
            else:
                lines.append("    switch (branch_selector) {")
                for c_idx, (s_next, c_cond) in enumerate(successors):
                    c_tag = c_cond or f"case_{c_idx}"
                    lines.append(f"        case {c_idx}: // {c_tag}")
                    lines.append(f"            goto state_0x{s_next:X};")
                lines.append("    }")

        lines.append("}")
        return "\n".join(lines)

    def generate_mermaid(self) -> str:
        """Generates Mermaid flowchart showing the recovered CFG without dispatchers."""
        lines = ["flowchart TD"]
        for st, h in self.state_handlers.items():
            b_label = f"State 0x{st:X}: {h['block']}"
            lines.append(f"    node_{st}[\"{b_label}\"]")

        for src, dst, cond in self.transitions:
            if cond:
                lines.append(f"    node_{src} -- \"{cond}\" --> node_{dst}")
            else:
                lines.append(f"    node_{src} --> node_{dst}")
        return "\n".join(lines)

def main():
    parser = argparse.ArgumentParser(description="Apex-RE Control Flow Flattening (CFF) Deobfuscator")
    parser.add_argument("input_trace", help="JSON or text log file containing state transitions")
    parser.add_argument("--format", choices=["c", "mermaid", "json"], default="c", help="Output format (default: c)")
    args = parser.parse_args()

    if not os.path.exists(args.input_trace):
        sys.stderr.write(f"Error: Trace file {args.input_trace} not found.\n")
        sys.exit(1)

    with open(args.input_trace, "r", encoding="utf-8") as f:
        content = f.read()

    try:
        unflattener = ControlFlowUnflattener.from_json(content)
    except Exception:

    if args.format == "c":
        print(unflattener.reconstruct_c_code())
    elif args.format == "mermaid":

    elif args.format == "json":

            "entry_state": unflattener.entry_state,
            "handlers": unflattener.state_handlers,
            "transitions": unflattener.transitions
        }, indent=2))

if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""
Apex-RE Virtual Machine Bytecode & Trace Analyzer (vm_analyzer.py)
Deconstructs obfuscated VM interpreter loops, filters dispatcher overhead,
classifies virtual handlers, and performs backward symbolic register slicing.

Zero external dependencies. Python 3.8+ compatible.
"""

import sys
import os
import re
import json
from typing import List, Dict, Set, Tuple, Optional, Any

class VMAnalyzer:
    """Analyzes VM execution traces, detects dispatchers, and slices semantic operations."""

    def __init__(self):
        self.trace: List[Dict[str, Any]] = []
        self.dispatcher_addresses: Set[int] = set()
        self.semantic_trace: List[Dict[str, Any]] = []

    def load_trace_json(self, json_path: str):
        with open(json_path, "r", encoding="utf-8") as f:
            data = json.load(f)
            if isinstance(data, list):
                self.trace = data
            elif isinstance(data, dict) and "trace" in data:
                self.trace = data["trace"]

    def load_trace_text(self, text_path: str):
        """
        Parses text trace format:
        0x140001000: mov rax, [rsi]
        0x140001003: add rsi, 8
        """
        self.trace = []
        with open(text_path, "r", encoding="utf-8") as f:
            for line in f:
                line = line.strip()
                if not line or line.startswith("#") or line.startswith("//"):
                    continue
                m = re.match(r"(?:0x)?([0-9a-fA-F]+)\s*[:|-]\s*(.*)", line)
                if m:
                    addr = int(m.group(1), 16)
                    insn_text = m.group(2).strip()
                    parts = insn_text.split(None, 1)
                    mnemonic = parts[0].lower() if parts else ""
                    operands = parts[1] if len(parts) > 1 else ""
                    self.trace.append({
                        "address": addr,
                        "mnemonic": mnemonic,
                        "operands": operands,
                        "raw": insn_text
                    })

    def detect_dispatcher_loop(self, min_repetitions: int = 3) -> List[int]:
        """
        Detects addresses of VM dispatchers based on execution frequency.
        VM dispatchers typically execute far more frequently than individual handlers.
        """
        freq: Dict[int, int] = {}
        for entry in self.trace:
            addr = entry.get("address", 0)
            freq[addr] = freq.get(addr, 0) + 1

        if not freq:
            return []

        max_count = max(freq.values())
        threshold = max(min_repetitions, int(max_count * 0.75))
        self.dispatcher_addresses = {addr for addr, count in freq.items() if count >= threshold}
        return sorted(list(self.dispatcher_addresses))

    def filter_dispatcher_overhead(self) -> List[Dict[str, Any]]:
        """
        Filters out dispatcher addresses and VM pointer increment overhead.
        Retains semantic body operations.
        """
        if not self.dispatcher_addresses:
            self.detect_dispatcher_loop()

        filtered = []
        for entry in self.trace:
            addr = entry.get("address", 0)
            mnem = entry.get("mnemonic", "").lower()
            ops = entry.get("operands", "").lower()

            # Skip dispatcher head instructions
            if addr in self.dispatcher_addresses:
                continue

            # Skip VM instruction pointer tracking (e.g. add rsi, 4; lodsb; inc rsi)
            if mnem in ("lodsb", "lodsd", "lodsq"):
                continue
            if mnem in ("inc", "add") and any(reg in ops for reg in ("rsi", "r14", "r15", "eip", "rip")):
                # Likely virtual instruction pointer advance
                continue

            filtered.append(entry)

        self.semantic_trace = filtered
        return filtered

    @staticmethod
    def classify_instruction(insn: Dict[str, Any]) -> str:
        """Classifies instruction into semantic VM category."""
        mnem = insn.get("mnemonic", "").lower()
        if mnem in ("add", "sub", "imul", "mul", "idiv", "div", "neg", "inc", "dec"):
            return "ARITHMETIC"
        elif mnem in ("xor", "and", "or", "not", "shl", "shr", "sar", "rol", "ror"):
            return "LOGIC"
        elif mnem in ("mov", "movzx", "movsx", "lea"):
            return "DATA_TRANSFER"
        elif mnem in ("push", "pop"):
            return "STACK"
        elif mnem in ("cmp", "test"):
            return "COMPARISON"
        elif mnem.startswith("j"):
            return "BRANCH"
        elif mnem in ("call", "ret"):
            return "CALL_RETURN"
        return "UNKNOWN"

    def backward_slice(self, target_register: str, max_depth: int = 50) -> List[Dict[str, Any]]:
        """
        Traces backward dependencies for target_register across the semantic trace.
        Extracts only instructions directly contributing to the final value.
        """
        target_reg = target_register.lower()
        active_deps: Set[str] = {target_reg}
        slice_result: List[Dict[str, Any]] = []

        # Traverse backwards
        for insn in reversed(self.semantic_trace if self.semantic_trace else self.trace):
            mnem = insn.get("mnemonic", "").lower()
            ops = [op.strip() for op in insn.get("operands", "").lower().split(",") if op.strip()]

            if not ops:
                continue

            dst = ops[0]
            # Check if destination matches any active dependency
            dst_matches = any(dep in dst for dep in active_deps)

            if dst_matches:
                slice_result.append(insn)
                # If instruction overwrites destination, we can remove it unless it's an in-place op (add/xor)
                if mnem not in ("add", "sub", "xor", "and", "or", "shl", "shr"):
                    # Remove dst from deps if it was a plain write
                    active_deps = {dep for dep in active_deps if dep not in dst}

                # Add source operands to dependencies
                for src in ops[1:]:
                    # Extract register names
                    regs = re.findall(r"\b[er]?[abcd]x|\b[er]?[sb]p|\b[er]?[sd]i|\br[89]|\br1[0-5]\b", src)
                    for r in regs:
                        active_deps.add(r)

                if len(slice_result) >= max_depth:
                    break

        slice_result.reverse()
        return slice_result

    def synthesize_expression(self, target_register: str = "rax") -> str:
        """
        Synthesizes high-level algebraic expression from backward sliced instructions.
        """
        sliced = self.backward_slice(target_register)
        if not sliced:
            return f"// No dependency chain found for {target_register}"

        lines = [f"// Semantic reconstruction for {target_register} ({len(sliced)} instructions):"]
        for insn in sliced:
            category = self.classify_instruction(insn)
            lines.append(f"    {insn.get('raw', '')};  // [{category}]")

        return "\n".join(lines)


def main():
    if len(sys.argv) < 2:
        print("Usage:")
        print("  python vm_analyzer.py <trace.json_or_txt> [--slice <reg>] [--json]")
        sys.exit(1)

    trace_file = sys.argv[1]
    if not os.path.exists(trace_file):
        print(f"Error: Trace file not found: {trace_file}", file=sys.stderr)
        sys.exit(1)

    analyzer = VMAnalyzer()
    if trace_file.endswith(".json"):
        analyzer.load_trace_json(trace_file)
    else:
        analyzer.load_trace_text(trace_file)

    dispatchers = analyzer.detect_dispatcher_loop()
    filtered = analyzer.filter_dispatcher_overhead()

    print(f"[*] Loaded trace with {len(analyzer.trace)} instructions.")
    print(f"[*] Identified {len(dispatchers)} dispatcher basic block(s): " +
          ", ".join(f"0x{a:X}" for a in dispatchers))
    print(f"[*] Retained {len(filtered)} semantic VM handler instructions.")

    target_reg = "rax"
    if "--slice" in sys.argv:
        idx = sys.argv.index("--slice")
        if idx + 1 < len(sys.argv):
            target_reg = sys.argv[idx + 1]

    expr = analyzer.synthesize_expression(target_reg)
    print("\n" + expr)

if __name__ == "__main__":
    main()

        struct.pack_into("<Q", hdr, 24, 0x400000) # entry
        struct.pack_into("<Q", hdr, 40, 64) # e_shoff at offset 64
        struct.pack_into("<H", hdr, 58, 64) # e_shentsize = 64
        struct.pack_into("<H", hdr, 60, 2)  # e_shnum = 2 sections
        struct.pack_into("<H", hdr, 62, 0)  # shstrndx = 0

        # Section 0: null section
        sec0 = bytearray(64)
        # Section 1: executable + writable section (W+X)
        sec1 = bytearray(64)
        struct.pack_into("<I", sec1, 0, 0)     # sh_name
        struct.pack_into("<I", sec1, 4, 1)     # sh_type: SHT_PROGBITS
        struct.pack_into("<Q", sec1, 8, 0x5)   # sh_flags: SHF_WRITE (0x1) | SHF_EXECINSTR (0x4)
        struct.pack_into("<Q", sec1, 16, 0x500000) # sh_addr
        struct.pack_into("<Q", sec1, 24, 192)  # sh_offset
        struct.pack_into("<Q", sec1, 32, 64)   # sh_size

        payload = b"\x90" * 64
        with open(elf_path, "wb") as f:
            f.write(hdr + sec0 + sec1 + payload)

        res = BinaryTriager(elf_path).analyze()
        self.assertEqual(len(res["sections"]), 2)
        self.assertTrue(any("W+X" in a for a in res["anomalies"]))

class TestMemoryDiff(unittest.TestCase):
    def test_memory_diffing_and_struct_synthesis(self):
        # 64 bytes memory snapshot
        buf_a = bytearray(64)
        buf_b = bytearray(64)

        # Offset 0x04: int32 changed from 100 to 250
        struct.pack_into("<i", buf_a, 0x04, 100)
        struct.pack_into("<i", buf_b, 0x04, 250)

        # Offset 0x0C: float32 changed from 1.0 to 2.5
        struct.pack_into("<f", buf_a, 0x0C, 1.0)
        struct.pack_into("<f", buf_b, 0x0C, 2.5)

        # Offset 0x18: 64-bit pointer
        struct.pack_into("<Q", buf_a, 0x18, 0x00007FF710000000)
        struct.pack_into("<Q", buf_b, 0x18, 0x00007FF720000000)

        differ = MemoryDiffer(bytes(buf_a), bytes(buf_b), base_addr=0x140000000, alignment=4)
        diffs = differ.compute_diffs()

        self.assertGreaterEqual(len(diffs), 3)

        # Check interpretations
        d_int = next(d for d in diffs if d["offset"] == 0x04)
        self.assertEqual(d_int["interpretations"]["i32"]["before"], 100)
        self.assertEqual(d_int["interpretations"]["i32"]["after"], 250)
        self.assertEqual(d_int["interpretations"]["i32"]["delta"], 150)

        # Synthesize C++ and C# structs
        structs = differ.synthesize_struct("PlayerEntity")
        self.assertIn("struct PlayerEntity {", structs["cpp"])
        self.assertIn("int32_t field_0x0004;", structs["cpp"])
        self.assertIn("float field_0x000C;", structs["cpp"])
        self.assertIn("uintptr_t field_0x0018;", structs["cpp"])
        self.assertIn("[StructLayout(LayoutKind.Explicit)]", structs["csharp"])
        self.assertIn("[FieldOffset(0x4)] public int field_0x0004;", structs["csharp"])
        self.assertIn("[FieldOffset(0xC)] public float field_0x000C;", structs["csharp"])
        self.assertIn("[FieldOffset(0x18)] public IntPtr field_0x0018;", structs["csharp"])

    def test_identical_memory_buffers(self):
        buf = b"\xAA" * 128
        differ = MemoryDiffer(buf, buf, base_addr=0x1000)
        diffs = differ.compute_diffs()
        self.assertEqual(len(diffs), 0)

class TestKaitaiSynth(unittest.TestCase):
    def test_kaitai_synthesis(self):
        # Binary data: ASCII magic "PKT1" + uint32 length + float + null-terminated string
        raw = bytearray()

        raw.extend(struct.pack("<I", 42))
        raw.extend(struct.pack("<f", 3.1415))
        raw.extend(b"HeroName\x00")
        raw.extend(b"\x01\x02\x03\x04")

        synth = KaitaiSynthesizer(bytes(raw), struct_id="packet_header", endian="le")
        ksy = synth.synthesize()

        self.assertIn("id: packet_header", ksy)
        self.assertIn("endian: le", ksy)
        self.assertIn("contents: \"PKT1\"", ksy)
        self.assertIn("type: u4", ksy)
        self.assertIn("type: f4", ksy)
        self.assertIn("type: strz", ksy)

    def test_kaitai_with_u64_and_u4(self):
        # Test distinguishing true 64-bit integer (> 0xFFFFFFFF) from two 32-bit integers
        raw = bytearray()
        raw.extend(b"TEST") # 4 bytes
        raw.extend(struct.pack("<I", 100)) # 4 bytes -> now at offset 8 (aligned to 8)
        # At offset 8: true 64-bit value: 0x00007FF710000000
        raw.extend(struct.pack("<Q", 0x00007FF710000000))
        # At offset 16: two 32-bit integers (not collapsed into 64-bit)
        raw.extend(struct.pack("<I", 500))
        raw.extend(struct.pack("<I", 600))

        synth = KaitaiSynthesizer(bytes(raw), struct_id="data_payload", endian="le")
        ksy = synth.synthesize()
        self.assertIn("type: u8", ksy)
        self.assertIn("type: u4", ksy)

class TestUnflattenTrace(unittest.TestCase):
    def test_unflattening_from_json(self):
        trace_json = json.dumps([
            {"state": 1, "block": "BB_INIT", "code": "int counter = 0", "next_state": 2},
            {"state": 2, "block": "BB_LOOP", "code": "counter += 1", "next_state": 3},
            {"state": 3, "block": "BB_CHECK", "code": "/* check */", "next_state": 4},
            {"state": 4, "block": "BB_EXIT", "code": "return counter", "next_state": None}
        ])

        unflattener = ControlFlowUnflattener.from_json(trace_json)
        unflattener.analyze()

        self.assertEqual(unflattener.entry_state, 1)
        self.assertIn(4, unflattener.terminal_states)

        c_code = unflattener.reconstruct_c_code()
        self.assertIn("void reconstructed_function()", c_code)
        self.assertIn("int counter = 0;", c_code)
        self.assertIn("counter += 1;", c_code)

        mermaid = unflattener.generate_mermaid()
        self.assertIn("flowchart TD", mermaid)
        self.assertIn("node_1", mermaid)
        self.assertIn("node_2", mermaid)

    def test_unflattening_from_text(self):
        log_text = """
        State: 0x10 -> Block: BB_START -> Code: 'x = 10;' -> Next: 0x20
        State: 0x20 -> Block: BB_END -> Code: 'return x;' -> Next: exit
        """
        unflattener = ControlFlowUnflattener.from_text_log(log_text)
        unflattener.analyze()
        self.assertEqual(unflattener.entry_state, 0x10)
        c_code = unflattener.reconstruct_c_code()
        self.assertIn("x = 10;", c_code)
        self.assertIn("return x;", c_code)

    def test_unflattening_branching_and_loops(self):
        # State machine with conditional branching and loop back-edge
        trace = [
            {"state": 10, "block": "BB_ENTRY", "code": "int i = 0;", "next_state": 20},
            {"state": 20, "block": "BB_COND", "code": "", "successors": [(30, "i < 10"), (40, "i >= 10")]},
            {"state": 30, "block": "BB_BODY", "code": "i++;", "next_state": 20}, # loop back-edge to 20
            {"state": 40, "block": "BB_DONE", "code": "return i;", "next_state": None}
        ]
        # Register in custom format
        unflattener = ControlFlowUnflattener([])
        unflattener.entry_state = 10
        unflattener.state_handlers = {
            10: {"block": "BB_ENTRY", "code": "int i = 0;", "successors": [(20, None)]},
            20: {"block": "BB_COND", "code": "", "successors": [(30, "i < 10"), (40, "i >= 10")]},
            30: {"block": "BB_BODY", "code": "i++;", "successors": [(20, None)]},
            40: {"block": "BB_DONE", "code": "return i;", "successors": []}
        }
        c_code = unflattener.reconstruct_c_code()
        # Verify labels exist
        self.assertIn("state_0x14:", c_code) # state 20
        self.assertIn("state_0x1E:", c_code) # state 30
        self.assertIn("state_0x28:", c_code) # state 40
        # Verify goto targets exist
        self.assertIn("goto state_0x1E;", c_code)
        self.assertIn("goto state_0x28;", c_code)
        self.assertIn("goto state_0x14;", c_code)

class TestPatternScanner(unittest.TestCase):
    def test_ida_pattern_parsing(self):
        pat_str = "48 8B 05 ? ? ? ? 48 85 C0"
        pat, mask = PatternScanner.parse_ida_pattern(pat_str)
        self.assertEqual(len(pat), 10)
        self.assertEqual(len(mask), 10)
        self.assertEqual(pat[0:3], b"\x48\x8B\x05")
        self.assertEqual(mask[0:3], b"\xFF\xFF\xFF")
        self.assertEqual(mask[3:7], b"\x00\x00\x00\x00") # Wildcards
        self.assertEqual(pat[7:10], b"\x48\x85\xC0")
        self.assertEqual(mask[7:10], b"\xFF\xFF\xFF")

    def test_scan_pattern_with_wildcards(self):
        # Buffer containing concrete bytes matching wildcard pattern
        data = b"\x90" * 32 + b"\x48\x8B\x05\x12\x34\x56\x78\x48\x85\xC0" + b"\xCC" * 16
        pat, mask = PatternScanner.parse_ida_pattern("48 8B 05 ? ? ? ? 48 85 C0")
        matches = PatternScanner.scan_pattern(data, pat, mask)
        self.assertEqual(len(matches), 1)
        self.assertEqual(matches[0], 32)

    def test_rip_relative_resolution(self):
        # Instruction: mov rax, [rip + 0x100] at offset 0x20
        # In x64: 48 8B 05 00 01 00 00 (7 bytes, disp at offset +3)
        data = bytearray(0x200)
        data[0x20:0x27] = b"\x48\x8B\x05" + struct.pack("<i", 0x100)
        res = PatternScanner.resolve_rip_relative(bytes(data), match_offset=0x20,
                                                  disp_offset_within_match=3,
                                                  instruction_length=7,
                                                  image_base=0x140000000)
        # Next RIP = 0x20 + 7 = 0x27
        # Target RVA = 0x27 + 0x100 = 0x127
        # Target VA = 0x140000000 + 0x127 = 0x140000127
        self.assertEqual(res["target_rva"], "0x127")
        self.assertEqual(res["target_va"], "0x140000127")

    def test_synthesize_unique_signature(self):
        # Create buffer with random-like unique pattern at offset 0x40
        data = bytearray(b"\x90" * 0x100)
        unique_bytes = b"\x48\x89\x5C\x24\x08\x57\x48\x83\xEC\x20\x48\x8B\xD9"
        data[0x40:0x40+len(unique_bytes)] = unique_bytes

        sig_info = PatternScanner.synthesize_unique_signature(bytes(data), target_offset=0x40)
        self.assertIsNotNone(sig_info)
        self.assertTrue(sig_info["unique"])
        self.assertEqual(sig_info["offset"], 0x40)
        self.assertIn("48 89 5C 24 08", sig_info["pattern"])

class TestVMAnalyzer(unittest.TestCase):
    def test_vm_dispatcher_detection_and_slicing(self):
        trace = [
            # Dispatcher loop executing multiple times
            {"address": 0x1000, "mnemonic": "mov", "operands": "rax, [rsi]", "raw": "mov rax, [rsi]"},
            {"address": 0x1003, "mnemonic": "add", "operands": "rsi, 8", "raw": "add rsi, 8"},
            {"address": 0x1007, "mnemonic": "jmp", "operands": "[table + rax*8]", "raw": "jmp [table + rax*8]"},
            # Handler 1: VPUSH
            {"address": 0x2000, "mnemonic": "mov", "operands": "rbx, 0x42", "raw": "mov rbx, 0x42"},
            # Dispatcher loop repeat
            {"address": 0x1000, "mnemonic": "mov", "operands": "rax, [rsi]", "raw": "mov rax, [rsi]"},
            {"address": 0x1003, "mnemonic": "add", "operands": "rsi, 8", "raw": "add rsi, 8"},
            {"address": 0x1007, "mnemonic": "jmp", "operands": "[table + rax*8]", "raw": "jmp [table + rax*8]"},
            # Handler 2: VALU XOR
            {"address": 0x3000, "mnemonic": "xor", "operands": "rbx, 0x55", "raw": "xor rbx, 0x55"},
            # Dispatcher loop repeat
            {"address": 0x1000, "mnemonic": "mov", "operands": "rax, [rsi]", "raw": "mov rax, [rsi]"},
            {"address": 0x1003, "mnemonic": "add", "operands": "rsi, 8", "raw": "add rsi, 8"},
            {"address": 0x1007, "mnemonic": "jmp", "operands": "[table + rax*8]", "raw": "jmp [table + rax*8]"},
            # Exit handler
            {"address": 0x4000, "mnemonic": "mov", "operands": "rax, rbx", "raw": "mov rax, rbx"}
        ]
        analyzer = VMAnalyzer()
        analyzer.trace = trace

        dispatchers = analyzer.detect_dispatcher_loop(min_repetitions=3)
        self.assertIn(0x1000, dispatchers)
        self.assertIn(0x1003, dispatchers)
        self.assertIn(0x1007, dispatchers)

        filtered = analyzer.filter_dispatcher_overhead()
        # Dispatcher instructions should be removed
        filtered_addrs = [e["address"] for e in filtered]
        self.assertNotIn(0x1000, filtered_addrs)
        self.assertIn(0x2000, filtered_addrs)
        self.assertIn(0x3000, filtered_addrs)
        self.assertIn(0x4000, filtered_addrs)

        sliced = analyzer.backward_slice("rax")
        self.assertTrue(len(sliced) >= 2)
        expr = analyzer.synthesize_expression("rax")
        self.assertIn("xor rbx, 0x55", expr)
        self.assertIn("mov rax, rbx", expr)

class TestRichHeaderAndAntiAnalysis(unittest.TestCase):
    def test_pe_rich_header_and_anti_analysis(self):
        with tempfile.NamedTemporaryFile(delete=False) as tmp:
            tmp_path = tmp.name

        try:
            # Construct PE with Rich Header
            xor_key = 0x12345678
            dos_stub = bytearray(0x100)
            dos_stub[0:2] = b"MZ"
            pe_off = 0x80
            struct.pack_into("<I", dos_stub, 0x3C, pe_off)

            # Insert DanS ... Rich block inside DOS stub
            # DanS at 0x40
            dans_enc = struct.pack("<I", 0x536E6144 ^ xor_key) # "DanS"
            dos_stub[0x40:0x44] = dans_enc
            # 3 zero dwords
            dos_stub[0x44:0x50] = struct.pack("<III", 0 ^ xor_key, 0 ^ xor_key, 0 ^ xor_key)

            # Record 1: Prod 0x0104 (VS2019/VS2022 C++), Build 31332, Count 15
            comp_id_1 = (0x0104 << 16) | 31332
            dos_stub[0x50:0x58] = struct.pack("<II", comp_id_1 ^ xor_key, 15 ^ xor_key)

            # Rich marker at 0x58
            dos_stub[0x58:0x5C] = b"Rich"
            dos_stub[0x5C:0x60] = struct.pack("<I", xor_key)

            # PE Header at 0x80
            pe_hdr = bytearray(0x80)
            pe_hdr[0:4] = b"PE\x00\x00"
            struct.pack_into("<H", pe_hdr, 4, 0x8664) # x64

            # Add payload with anti-debugging API
            payload = b"IsDebuggerPresent CheckRemoteDebuggerPresent"

            with open(tmp_path, "wb") as f:
                f.write(dos_stub[:pe_off] + pe_hdr + payload)

            triager = BinaryTriager(tmp_path)
            res = triager.analyze()

            self.assertTrue(len(res["rich_header"]) > 0)
            self.assertEqual(res["rich_header"][0]["tool"], "VS2019/VS2022 C++ Compiler")
            self.assertEqual(res["rich_header"][0]["build_id"], 31332)
            self.assertEqual(res["rich_header"][0]["count"], 15)

            self.assertIn("IsDebuggerPresent", res["anti_analysis"])
            self.assertIn("CheckRemoteDebuggerPresent", res["anti_analysis"])
        finally:
            if os.path.exists(tmp_path):
                os.remove(tmp_path)
