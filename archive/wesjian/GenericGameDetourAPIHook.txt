## Overview

DetourAPIHook is a modular API hooking framework designed to bypass game anti-cheat protections. It intercepts ~127 Windows API calls across 16 independent hook modules, providing:

- **Process/module hiding** — Invisible to anti-cheat enumeration (PEB unlinking, module list filtering, GetModuleHandle interception)
- **Anti-debug neutralization** — Defeats IsDebuggerPresent, NtQueryInformationProcess debug port checks, hardware breakpoint detection, timing-based debug detection
- **Hardware ID spoofing** — Randomized SMBIOS firmware tables, volume serial numbers, computer name, disk serial per-process
- **Network identity spoofing** — MAC address randomization, TCP/UDP connection hiding, DNS resolution blocking for protection modules
- **Memory integrity bypass** — Returns clean (unmodified) game memory to integrity scanners via NtReadVirtualMemory/ReadProcessMemory hooks
- **Cheat tool concealment** — Hides Cheat Engine, OllyDbg, x64dbg, IDA Pro, Ghidra, ReClass, Wireshark, etc. from window/registry/process/file enumeration
- **Self-protection** — 3-layer memory protection (self DLL + game exe + system DLL trampolines), PE header erasure, Hook Integrity Watchdog (auto-repair tampered hooks every 500ms)
- **Multi-instance support** — Bypasses single-instance mutex checks to allow multiple game clients
- **Service interception** — Blocks anti-cheat from starting kernel-mode driver services
- **NGS kernel bypass** — 45-second delayed hook installation avoids NGS kernel driver's initial memory scan window

## Caller Check System

The `CallerCheck` system (`caller_check.cpp`) is the core decision engine. It uses `GetModuleHandleEx(GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS)` with `_ReturnAddress()` to determine which module called a hooked API.

### Detection Logic
```
1. Hook intercepts API call
2. _ReturnAddress() → get return address from stack
3. GetModuleHandleEx(FROM_ADDRESS) → resolve to HMODULE
4. Compare HMODULE against all 30+ known protection module handles
5. If match → apply blocking/spoofing behavior
6. If no match → pass through to original API
```

### Registered Protection Modules (30+)
```
NGS/BlackCipher:  BlackCall.aes, blackcipher.aes, BlackCall64.aes, BlackCipher64.aes,
                  NGClient.aes, NGClient64.aes, NexonGuard.aes, NGMon.aes,
                  NGLog.aes, NGPatch.aes

## Architecture

```
Game Process
  |
  +-- Loads dinput8.dll (from game directory, DLL search order hijacking)
  |
  +-- dinput8.dll (our proxy)
        |
        +-- DllMain(DLL_PROCESS_ATTACH)   [t=0s]
        |     |
        |     |-- 1. UnlinkSelfFromPEB(hinstDLL)
        |     |      Removes DLL from PEB module lists
        |     |
        |     +-- 2. CreateThread(DelayedHookInstallThread)
        |            Starts 45-second countdown for NGS bypass
        |
        +-- DelayedHookInstallThread       [t=45s]
        |     |
        |     |-- 1. Sleep(45s)  — Wait for NGS initial scan
        |     |
        |     |-- 2. DetourManager::InstallAllHooks()
        |     |      Installs 16 modules (~130 API hooks)
        |     |
        |     +-- 3. ErasePEHeader(hinstDLL)
        |            Zeros DOS/PE/section headers
        |
        +-- DirectInput8Create_Proxy()
        |     Forwards to real System32\dinput8.dll
        |
        +-- DllMain(DLL_PROCESS_DETACH)
              DetourManager::RemoveAllHooks()  (reverse order)
              UnloadRealDinput8()
```

### Module Installation Order

Modules are installed in a specific order. ModuleLoading is first (to intercept protection DLL loading), SelfProtect is last (to protect after everything is set up). Removal happens in reverse order.

```
Install Order:
  1.  ModuleLoading    — Must be first: intercept duplicate DLL loading
  2.  DebugProtect     — Protect hardware breakpoint registers
  3.  AntiDetection    — Hide processes/windows/PIDs
  4.  AntiDebug        — Neutralize debugger detection
  5.  DriverComm       — Intercept driver communication IOCTLs
  6.  MemoryAccess     — Protect memory reads/queries
  7.  ProcessControl   — Intercept process/thread creation
  8.  FileSystem       — Intercept file enumeration
  9.  MacSpoof         — MAC address spoofing
  10. MultiInstance    — Multi-instance mutex bypass
  11. NetworkTable     — TCP/UDP connection hiding
  12. Registry         — Registry scan bypass
  13. Timing           — Timing attack normalization
  14. HardwareId       — Hardware ID spoofing
  15. GameSpecific     — Game-specific hooks and callbacks
  16. SelfProtect      — Must be last: protect all hooks in memory
```

### 9. MAC Address Spoofing (`hook_mac.cpp`) — 5 APIs

### 13. Timing Normalization (`hook_timing.cpp`) — 4 APIs

Normalizes timing to defeat debugger detection via execution speed measurement.

| # | API | DLL | Anti-Cheat Usage | Hook Behavior |
|---|-----|-----|-----------------|---------------|
| 1 | `QueryPerformanceCounter` | kernel32.dll | Measure time between two code points. If delta > threshold (e.g., >200ms for what should be <1ms), a debugger is single-stepping | Track last returned counter value. If delta between calls exceeds 200ms worth of ticks, clamp to 200ms. Prevents large gaps caused by debugger pausing |
| 2 | `GetTickCount` | kernel32.dll | Similar timing check with millisecond resolution | Track last tick value. Clamp delta to max 200ms per call to smooth progression |
| 3 | `GetTickCount64` | kernel32.dll | 64-bit version of GetTickCount (no 49.7-day rollover) | Same clamping logic, 64-bit arithmetic |
| 4 | `NtQueryPerformanceCounter` | ntdll.dll | Low-level performance counter query (ntdll) bypassing kernel32 hooks | Same delta clamping as QueryPerformanceCounter |

**Clamping strategy**: `max_delta = frequency * 200 / 1000` (200ms in QPC ticks). If `actual_delta > max_delta`, returned value = `last_value + max_delta`. This makes debugger stepping appear to execute at normal speed.

### 14. Hardware ID Spoofing (`hook_hardware_id.cpp`) — 7 APIs

Spoofs hardware identification to prevent hardware bans. All values are deterministic per-process.

| # | API | DLL | Anti-Cheat Usage | Hook Behavior |
|---|-----|-----|-----------------|---------------|
| 1 | `GetSystemFirmwareTable` | kernel32.dll | Read SMBIOS table (provider `'RSMB'`) to extract motherboard serial, BIOS serial, system UUID | Call real API, then randomize bytes 8-31 in returned SMBIOS data (covers serial number and UUID fields in Type 1 System Information structure). | 2 | `GetVolumeInformationA` | kernel32.dll | Read volume serial number (`lpVolumeSerialNumber` parameter) for HWID fingerprint | Call real API, then overwrite `*lpVolumeSerialNumber` with per-process random value (seeded by `PID ^ 0x564F4C53`) |

### 16. Self-Protection (`hook_self_protect.cpp`) — 4 APIs + PE Erasure + Hook Watchdog

Protects our DLL, game executable, and system DLL trampolines from tampering.

**3-Layer Memory Protection:**

| Layer | Scope | Protection | Behavior |
|:-----:|-------|------------|----------|
| 1 | **Our DLL** (`dinput8.dll`) | Block from everyone | Hard deny: `STATUS_ACCESS_DENIED` / `FALSE` |
| 2 | **Game exe** memory | Block from protection modules | Fake success: pretend write/protect change succeeded |
| 3 | **System DLL trampolines** (ntdll, kernel32, kernelbase, user32) | Block from protection modules | Fake success: prevent restoring original function bytes |

| # | API | DLL | Hook Behavior |
|---|-----|-----|---------------|
| 1 | `NtWriteVirtualMemory` | ntdll.dll | Layer 1: hard block writes to self. Layer 2+3: fake-success block writes from protection modules to game exe / system DLLs |
| 2 | `WriteProcessMemory` | kernel32.dll | Same 3-layer logic via Win32 wrapper |
| 3 | `VirtualProtectEx` | kernel32.dll | Block `PAGE_READWRITE`/`PAGE_EXECUTE_READWRITE` targeting self/game/system DLLs |
| 4 | `VirtualProtect` | kernel32.dll | Local variant, same 3-layer protection |

**PE Header Erasure** (`ErasePEHeader` function):
- Called once in `DllMain(DLL_PROCESS_ATTACH)` after all hooks are installed
- `SecureZeroMemory` over entire header region (DOS header, PE signature, COFF header, section headers)
- Anti-cheat scanning for PE signatures in loaded modules will not find ours

**Hook Integrity Watchdog** (`HookWatchdogThread`):
- Background thread started after all 16 modules are installed
- Snapshots first 16 bytes of each critical hooked function (**48 high-risk functions** registered)
- Every **500ms**, compares current bytes against snapshot
- If tampered (anti-cheat used direct syscall to restore original bytes): re-patches immediately
- `VirtualProtect` → `memcpy` snapshot → `FlushInstructionCache`
- Monitors across **5 DLLs**: ntdll (17) + kernel32 (18) + user32 (9) + ws2_32 (2) + advapi32 (2)

```
Anti-cheat attempts to unhook:
  1. VirtualProtect(ntdll page, PAGE_READWRITE)  → Blocked by Layer 3
  2. NtWriteVirtualMemory(restore original bytes) → Blocked by Layer 3
  3. Direct syscall (bypasses all user-mode hooks)  → Watchdog re-patches within 500ms
```

## dinput8.dll Proxy Injection

DetourAPIHook is built as a **dinput8.dll proxy** (DLL hijacking / DLL side-loading):

### How It Works

1. Windows searches for DLLs in the application directory first (standard DLL search order)
2. Our `dinput8.dll` is placed in the game folder — Windows loads it before the real System32 copy
3. On `DLL_PROCESS_ATTACH`:
   - Unlinks self from PEB (invisible to module enumeration)
   - Installs all 16 hook modules (120 API hooks)
   - Erases PE header from memory (invisible to memory scanners)
4. When the game calls `DirectInput8Create`:
   - Our proxy loads the real `%SystemRoot%\System32\dinput8.dll` via `LoadLibraryW`
   - Resolves real `DirectInput8Create` via `GetProcAddress`
   - Forwards the call transparently
   - Game's DirectInput functionality is completely unaffected

### Export Definition (`dinput8.def`)
```
LIBRARY "dinput8"
EXPORTS
    DirectInput8Create = DirectInput8Create_Proxy @1
```

import struct

def get_imports(path):
    with open(path, 'rb') as f:
        f.seek(0x3C)
        pe_offset = struct.unpack('<I', f.read(4))[0]
        f.seek(pe_offset)
        sig = f.read(4)
        if sig != b'PE\x00\x00':
            print('Not a PE file'); return
        machine = struct.unpack('<H', f.read(2))[0]
        num_sections = struct.unpack('<H', f.read(2))[0]
        f.read(12)
        opt_hdr_size = struct.unpack('<H', f.read(2))[0]
        f.read(2)
        opt_start = f.tell()
        magic = struct.unpack('<H', f.read(2))[0]
        is64 = (magic == 0x20b)
        if is64:
            f.seek(opt_start + 112)
        else:
            f.seek(opt_start + 96)
        import_rva = struct.unpack('<I', f.read(4))[0]
        import_size = struct.unpack('<I', f.read(4))[0]
        if import_rva == 0:
            print('No import table'); return
        f.seek(opt_start + opt_hdr_size)
        sections = []
        for i in range(num_sections):
            name = f.read(8).rstrip(b'\x00').decode('ascii', errors='ignore')
            vsize = struct.unpack('<I', f.read(4))[0]
            vaddr = struct.unpack('<I', f.read(4))[0]
            rsize = struct.unpack('<I', f.read(4))[0]
            roff = struct.unpack('<I', f.read(4))[0]
            f.read(16)
            sections.append((name, vaddr, vsize, roff, rsize))
        def rva_to_offset(rva):
            for name, va, vs, ro, rs in sections:
                if va <= rva < va + vs:
                    return ro + (rva - va)
            return None
        offset = rva_to_offset(import_rva)
        if offset is None:
            print('Cannot resolve import RVA'); return
        f.seek(offset)
        dlls = []
        while True:
            ilt_rva = struct.unpack('<I', f.read(4))[0]
            f.read(8)
            name_rva = struct.unpack('<I', f.read(4))[0]
            f.read(4)
            if name_rva == 0: break
            pos = f.tell()
            name_off = rva_to_offset(name_rva)
            if name_off:
                f.seek(name_off)
                name = b''
                while True:
                    c = f.read(1)
                    if c == b'\x00' or not c: break
                    name += c
                dlls.append(name.decode('ascii', errors='ignore'))
            f.seek(pos)
        arch = "x64" if is64 else "x86"
        print(f"Architecture: {arch}")
        print(f"Imported DLLs ({len(dlls)}):")
        for d in sorted(dlls, key=str.lower):
            print(f"  {d}")

#include <windows.h>

// ============================================================================
//  dinput8.dll Proxy / DLL Hijack Forwarder
//
//  This file implements a transparent proxy for dinput8.dll.
//  Games load dinput8.dll from their own directory first (DLL search order).
//  We place our DLL as "dinput8.dll" in the game folder, and forward the
//  real DirectInput8Create call to the system's original dinput8.dll.
//
//  On DLL_PROCESS_ATTACH, all DetourAPIHook modules are installed.
// ============================================================================

// Original dinput8.dll module handle
static HMODULE g_hRealDinput8 = NULL;

// Original DirectInput8Create function pointer
typedef HRESULT (WINAPI* DirectInput8Create_t)(
    HINSTANCE hinst, DWORD dwVersion, REFIID riidltf,
    LPVOID* ppvOut, LPVOID punkOuter
);
static DirectInput8Create_t g_pRealDirectInput8Create = NULL;

// Load the real dinput8.dll from System32
static bool LoadRealDinput8() {
    if (g_hRealDinput8) return true;

    // Build path to system dinput8.dll
    wchar_t systemDir[MAX_PATH] = { 0 };
    GetSystemDirectoryW(systemDir, MAX_PATH);

    wchar_t realPath[MAX_PATH] = { 0 };
    wsprintfW(realPath, L"%s\\dinput8.dll", systemDir);

    g_hRealDinput8 = LoadLibraryW(realPath);
    if (!g_hRealDinput8) return false;

    g_pRealDirectInput8Create = (DirectInput8Create_t)GetProcAddress(
        g_hRealDinput8, "DirectInput8Create"
    );

    return (g_pRealDirectInput8Create != NULL);
}

// Exported proxy function (forwarded via dinput8.def)
extern "C" HRESULT WINAPI DirectInput8Create_Proxy(
    HINSTANCE hinst, DWORD dwVersion, REFIID riidltf,
    LPVOID* ppvOut, LPVOID punkOuter
) {
    if (!g_pRealDirectInput8Create) {
        if (!LoadRealDinput8()) {
            return E_FAIL;
        }
    }
    return g_pRealDirectInput8Create(hinst, dwVersion, riidltf, ppvOut, punkOuter);
}

// Cleanup on unload
void UnloadRealDinput8() {
    if (g_hRealDinput8) {
        FreeLibrary(g_hRealDinput8);
        g_hRealDinput8 = NULL;
        g_pRealDirectInput8Create = NULL;
    }
}

static WCHAR g_GameExeName[MAX_PATH] = { 0 };

static const WCHAR* GetGameExeName() {
    if (g_GameExeName[0] == 0) {
        WCHAR path[MAX_PATH];
        GetModuleFileNameW(NULL, path, MAX_PATH);
        WCHAR* slash = wcsrchr(path, L'\\');
        wcscpy_s(g_GameExeName, slash ? slash + 1 : path);
    }
    return g_GameExeName;
}

// --- K32EnumProcesses ---
typedef BOOL (WINAPI* K32EnumProcesses_t)(DWORD*, DWORD, LPDWORD);
static K32EnumProcesses_t Real_K32EnumProcesses = NULL;

static BOOL WINAPI Hooked_K32EnumProcesses(DWORD* pids, DWORD cb, LPDWORD needed) {
    BOOL r = Real_K32EnumProcesses(pids, cb, needed);
    if (!r || !CallerCheck::IsFromAnyProtectionModule(_ReturnAddress())) return r;
    DWORD count = *needed / sizeof(DWORD);
    const WCHAR* gn = GetGameExeName();
    DWORD nc = 0;
    for (DWORD i = 0; i < count; i++) {
        HANDLE hp = OpenProcess(PROCESS_QUERY_INFORMATION | PROCESS_VM_READ, FALSE, pids[i]);
        bool hide = false;
        if (hp) {
            WCHAR pn[MAX_PATH] = { 0 };
            if (K32GetModuleBaseNameW(hp, NULL, pn, MAX_PATH)) {
                if (_wcsicmp(pn, gn) == 0) hide = true;
            }
            CloseHandle(hp);
        }
        if (!hide) pids[nc++] = pids[i];
    }
    *needed = nc * sizeof(DWORD);
    return TRUE;
}

static BOOL SkipSameName(HANDLE h, LPPROCESSENTRY32W e, BOOL first) {
    BOOL r = first ? Real_Process32FirstW(h, e) : Real_Process32NextW(h, e);
    const WCHAR* gn = GetGameExeName();
    while (r) {
        if (_wcsicmp(e->szExeFile, gn) != 0) return TRUE;
        r = Real_Process32NextW(h, e);
    }
    return FALSE;
}

    return SkipSameName(h, e, TRUE);

    return SkipSameName(h, e, FALSE);
}

typedef struct _MY_SYS_PROC_INFO {
    ULONG          NextEntryOffset;
    ULONG          NumberOfThreads;
    LARGE_INTEGER  Reserved[3];
    LARGE_INTEGER  CreateTime;
    LARGE_INTEGER  UserTime;
    LARGE_INTEGER  KernelTime;
    UNICODE_STRING ImageName;
    ULONG          BasePriority;
    HANDLE         UniqueProcessId;
    HANDLE         InheritedFromProcessId;
    ULONG          HandleCount;
} MY_SYS_PROC_INFO, *PMY_SYS_PROC_INFO;

typedef NTSTATUS (NTAPI* NtQuerySystemInformation_t)(ULONG, PVOID, ULONG, PULONG);
static NtQuerySystemInformation_t Real_NtQuerySystemInformation = NULL;

static NTSTATUS NTAPI Hooked_NtQuerySystemInformation(
    ULONG cls, PVOID info, ULONG len, PULONG rlen) {
    NTSTATUS st = Real_NtQuerySystemInformation(cls, info, len, rlen);
    if (st != 0 || cls != 5) return st;
    const WCHAR* gn = GetGameExeName();
    PMY_SYS_PROC_INFO prev = NULL;
    PMY_SYS_PROC_INFO cur = (PMY_SYS_PROC_INFO)info;
    while (cur) {
        bool hide = false;
        if (cur->ImageName.Buffer && cur->ImageName.Length > 0) {
            if (_wcsicmp(cur->ImageName.Buffer, gn) == 0) hide = true;
        }
        PMY_SYS_PROC_INFO nxt = cur->NextEntryOffset ?
            (PMY_SYS_PROC_INFO)((BYTE*)cur + cur->NextEntryOffset) : NULL;
        if (hide && prev) {
            prev->NextEntryOffset = cur->NextEntryOffset ?
                prev->NextEntryOffset + cur->NextEntryOffset : 0;
        } else if (!hide) {
            prev = cur;
        }
        cur = nxt;
    }
    return st;
}

typedef BOOL (WINAPI* WTSEnumerateProcessesW_t)(HANDLE, DWORD, DWORD, PWTS_PROCESS_INFOW*, DWORD*);
static WTSEnumerateProcessesW_t Real_WTSEnumerateProcessesW = NULL;

static BOOL WINAPI Hooked_WTSEnumerateProcessesW(
    HANDLE sv, DWORD res, DWORD ver, PWTS_PROCESS_INFOW* pp, DWORD* cnt) {
    BOOL r = Real_WTSEnumerateProcessesW(sv, res, ver, pp, cnt);
    if (!r || !pp || !cnt) return r;
    const WCHAR* gn = GetGameExeName();
    DWORD nc = 0;
    for (DWORD i = 0; i < *cnt; i++) {
        if ((*pp)[i].pProcessName && _wcsicmp((*pp)[i].pProcessName, gn) == 0) continue;
        if (nc != i) (*pp)[nc] = (*pp)[i];
        nc++;
    }
    *cnt = nc;
    return TRUE;
}

// ============================================================================
//  Debug Register Protection Hooks
//  Prevent protection modules from reading HW breakpoints (DR0-DR7)
// ============================================================================

// --- NtGetContextThread ---
typedef NTSTATUS (NTAPI* NtGetContextThread_t)(HANDLE ThreadHandle, PCONTEXT Context);
static NtGetContextThread_t Real_NtGetContextThread = NULL;

static NTSTATUS NTAPI Hooked_NtGetContextThread(HANDLE ThreadHandle, PCONTEXT Context) {
    NTSTATUS result = Real_NtGetContextThread(ThreadHandle, Context);

    // If request includes Debug Registers, zero out DR values
    if (result == 0 && Context && (Context->ContextFlags & CONTEXT_DEBUG_REGISTERS)) {
        Context->Dr0 = 0;
        Context->Dr1 = 0;
        Context->Dr2 = 0;
        Context->Dr3 = 0;
        Context->Dr6 = 0;
        Context->Dr7 = 0;
    }
    return result;
}

// --- NtSetContextThread ---
// Prevent protection modules from clearing our HW breakpoints
typedef NTSTATUS (NTAPI* NtSetContextThread_t)(HANDLE ThreadHandle, PCONTEXT Context);
static NtSetContextThread_t Real_NtSetContextThread = NULL;

static NTSTATUS NTAPI Hooked_NtSetContextThread(HANDLE ThreadHandle, PCONTEXT Context) {
    // If setting Debug Registers, strip that flag (protect HW breakpoints)
    if (Context && (Context->ContextFlags & CONTEXT_DEBUG_REGISTERS)) {
        Context->ContextFlags &= ~CONTEXT_DEBUG_REGISTERS;
        if (Context->ContextFlags == 0) {
            return 0; // STATUS_SUCCESS but do nothing
        }
    }
    return Real_NtSetContextThread(ThreadHandle, Context);
}

// ============================================================================
//  Install / Remove
// ============================================================================

bool InstallDebugProtectHooks() {
    HMODULE hNtdll = GetModuleHandleA("ntdll.dll");
    if (!hNtdll) return false;

    Real_NtGetContextThread = (NtGetContextThread_t)GetProcAddress(hNtdll, "NtGetContextThread");
    Real_NtSetContextThread = (NtSetContextThread_t)GetProcAddress(hNtdll, "NtSetContextThread");

    DetourTransactionBegin();
    DetourUpdateThread(GetCurrentThread());

    if (Real_NtGetContextThread) DetourAttach((PVOID*)&Real_NtGetContextThread, Hooked_NtGetContextThread);
    if (Real_NtSetContextThread) DetourAttach((PVOID*)&Real_NtSetContextThread, Hooked_NtSetContextThread);

    return (DetourTransactionCommit() == NO_ERROR);
}

bool RemoveDebugProtectHooks() {

#include "hook_driver_comm.h"
#include <windows.h>
#include <detours/detours.h>

#pragma comment(lib, "detours.lib")

// ============================================================================
//  Driver Communication Hook (1 API, multiple IOCTL interceptions)
//  Intercept DeviceIoControl to:
//  1. Block HackShield/GameGuard driver communication (IOCTL 0x80000040)
//  2. Spoof disk serial number queries (IOCTL_STORAGE_QUERY_PROPERTY)
//  3. Block anti-cheat kernel driver grant-access calls
// ============================================================================

// IOCTL constants (defined manually to avoid header dependency)
#define IOCTL_STORAGE_QUERY_PROPERTY 0x002D1400
#define IOCTL_DISK_GET_DRIVE_GEOMETRY 0x00070000
#define IOCTL_SMART_GET_VERSION      0x00074080

// Storage property query structures (minimal forward declarations)
#pragma pack(push, 1)
typedef enum _STORAGE_PROPERTY_ID_MANUAL {
    StorageDeviceProperty_Manual = 0,
    StorageAdapterProperty_Manual = 1
} STORAGE_PROPERTY_ID_MANUAL;

typedef struct _STORAGE_PROPERTY_QUERY_MANUAL {
    STORAGE_PROPERTY_ID_MANUAL PropertyId;
    DWORD QueryType;
    BYTE AdditionalParameters[1];
} STORAGE_PROPERTY_QUERY_MANUAL;

typedef struct _STORAGE_DEVICE_DESCRIPTOR_MANUAL {
    DWORD Version;
    DWORD Size;
    BYTE  DeviceType;
    BYTE  DeviceTypeModifier;
    BYTE  RemovableMedia;
    BYTE  CommandQueueing;
    DWORD VendorIdOffset;
    DWORD ProductIdOffset;
    DWORD ProductRevisionOffset;
    DWORD SerialNumberOffset;
    // ... more fields follow in actual struct
} STORAGE_DEVICE_DESCRIPTOR_MANUAL;
#pragma pack(pop)

// Per-process deterministic random for spoofed serials
static DWORD g_DriverSeed = 0;
static bool  g_DriverSeedInit = false;

static void InitDriverSeed() {
    if (g_DriverSeedInit) return;
    g_DriverSeed = GetCurrentProcessId() ^ 0x44524956; // "DRIV"
    if (g_DriverSeed == 0) g_DriverSeed = 0xDEADBEEF;
    g_DriverSeedInit = true;
}

static DWORD DriverRand(DWORD* state) {
    DWORD x = *state;
    x ^= x << 13;
    x ^= x >> 17;
    x ^= x << 5;
    *state = x;
    return x;
}

typedef BOOL (WINAPI* DeviceIoControl_t)(
    HANDLE hDevice, DWORD dwIoControlCode,
    LPVOID lpInBuffer, DWORD nInBufferSize,
    LPVOID lpOutBuffer, DWORD nOutBufferSize,
    LPDWORD lpBytesReturned, LPOVERLAPPED lpOverlapped
);

static DeviceIoControl_t Real_DeviceIoControl = NULL;

static BOOL WINAPI Hooked_DeviceIoControl(
    HANDLE hDevice, DWORD dwIoControlCode,
    LPVOID lpInBuffer, DWORD nInBufferSize,
    LPVOID lpOutBuffer, DWORD nOutBufferSize,
    LPDWORD lpBytesReturned, LPOVERLAPPED lpOverlapped
) {
    // 1. Block HackShield/GameGuard kernel driver communication
    if (dwIoControlCode == 0x80000040) {
        SetLastError(0);
        if (lpBytesReturned) *lpBytesReturned = 0;
        return TRUE;
    }

    // 2. Spoof disk serial number from IOCTL_STORAGE_QUERY_PROPERTY
    if (dwIoControlCode == IOCTL_STORAGE_QUERY_PROPERTY && lpInBuffer && lpOutBuffer) {
        STORAGE_PROPERTY_QUERY_MANUAL* query = (STORAGE_PROPERTY_QUERY_MANUAL*)lpInBuffer;
        if (query->PropertyId == StorageDeviceProperty_Manual) {
            BOOL result = Real_DeviceIoControl(hDevice, dwIoControlCode,
                lpInBuffer, nInBufferSize, lpOutBuffer, nOutBufferSize,
                lpBytesReturned, lpOverlapped);

            if (result && nOutBufferSize >= sizeof(STORAGE_DEVICE_DESCRIPTOR_MANUAL)) {
                STORAGE_DEVICE_DESCRIPTOR_MANUAL* desc =
                    (STORAGE_DEVICE_DESCRIPTOR_MANUAL*)lpOutBuffer;

                // Randomize serial number if present
                if (desc->SerialNumberOffset > 0 && desc->SerialNumberOffset < nOutBufferSize) {
                    char* serial = (char*)lpOutBuffer + desc->SerialNumberOffset;
                    InitDriverSeed();
                    DWORD s = g_DriverSeed ^ 0x53455249; // "SERI"
                    int len = 0;
                    while (serial[len] && (desc->SerialNumberOffset + len) < nOutBufferSize - 1) len++;
                    for (int i = 0; i < len; i++) {
                        serial[i] = 'A' + (DriverRand(&s) % 26);
                    }
                }
            }
            return result;
        }
    }

    return Real_DeviceIoControl(hDevice, dwIoControlCode,

    if (g_HwidInitialized) return;

    DWORD x = *state;
    x ^= x << 13;
    x ^= x >> 17;
    x ^= x << 5;

    return x;
}

// ============================================================================
//  Random MAC Generator
//  Uses xorshift PRNG, each process gets a fixed random MAC (PID+TickCount seed)
//  First byte forced to 0x02 (locally-administered, unicast)
//  Same MAC returned on every call (prevent multi-call comparison detection)
// ============================================================================

static BYTE g_SpoofedMac[6] = { 0 };
static bool g_MacGenerated = false;

static DWORD Xorshift32(DWORD* state) {
    DWORD x = *state;
    x ^= x << 13;
    x ^= x >> 17;
    x ^= x << 5;
    *state = x;
    return x;
}

static void GenerateSpoofedMac() {
    if (g_MacGenerated) return;
    DWORD seed = GetCurrentProcessId() ^ GetTickCount();
    if (seed == 0) seed = 0xDEADBEEF;
    g_SpoofedMac[0] = 0x02;
    g_SpoofedMac[1] = (BYTE)(Xorshift32(&seed) & 0xFF);
    g_SpoofedMac[2] = (BYTE)(Xorshift32(&seed) & 0xFF);
    g_SpoofedMac[3] = (BYTE)(Xorshift32(&seed) & 0xFF);
    g_SpoofedMac[4] = (BYTE)(Xorshift32(&seed) & 0xFF);
    g_SpoofedMac[5] = (BYTE)(Xorshift32(&seed) & 0xFF);
    g_MacGenerated = true;
}

static void SpoofMacBytes(BYTE* addr, DWORD len) {
    if (len != 6) return;
    GenerateSpoofedMac();
    memcpy(addr, g_SpoofedMac, 6);
}

// PermanentPhysicalAddress at +0x22C, row size = 0x690 (1680 bytes)

                mbi->Protect = PAGE_EXECUTE_READ;
            }
        }
    }
    return status;

typedef NTSTATUS (NTAPI* NtReadVirtualMemory_t)(
    HANDLE ProcessHandle, PVOID BaseAddress,
    PVOID Buffer, SIZE_T NumberOfBytesToRead, PSIZE_T NumberOfBytesRead
);
static NtReadVirtualMemory_t Real_NtReadVirtualMemory = NULL;

static NTSTATUS NTAPI Hooked_NtReadVirtualMemory(
    HANDLE ProcessHandle, PVOID BaseAddress,
    PVOID Buffer, SIZE_T NumberOfBytesToRead, PSIZE_T NumberOfBytesRead
) {
    if (CallerCheck::IsFromAnyProtectionModule(_ReturnAddress())) {
        // If reading from game module range, return clean copy
        if (g_GameModuleBase && !g_GameModuleCopy.empty()) {
            ULONG_PTR readStart = (ULONG_PTR)BaseAddress;
            ULONG_PTR modStart  = (ULONG_PTR)g_GameModuleBase;
            ULONG_PTR modEnd    = modStart + g_GameModuleSize;

            if (readStart >= modStart && readStart < modEnd) {
                SIZE_T offset = readStart - modStart;
                SIZE_T avail  = g_GameModuleSize - offset;
                SIZE_T toCopy = (NumberOfBytesToRead < avail) ? NumberOfBytesToRead : avail;

                memcpy(Buffer, g_GameModuleCopy.data() + offset, toCopy);
                if (NumberOfBytesRead) *NumberOfBytesRead = toCopy;
                return 0; // STATUS_SUCCESS
            }
        }
    }
    return Real_NtReadVirtualMemory(ProcessHandle, BaseAddress, Buffer, NumberOfBytesToRead, NumberOfBytesRead);
}

// ============================================================================

//  modules cannot discover us via PEB traversal. Supports x64 and x86.

typedef struct _MY_LDR_DATA_TABLE_ENTRY {
    LIST_ENTRY InLoadOrderLinks;
    LIST_ENTRY InMemoryOrderLinks;
    LIST_ENTRY InInitializationOrderLinks;
    PVOID      DllBase;
    PVOID      EntryPoint;
    ULONG      SizeOfImage;
    UNICODE_STRING FullDllName;
    UNICODE_STRING BaseDllName;

    L"dinput8.dll",
    L"DetourAPIHook.dll",
};
static const int g_HiddenDllCount = sizeof(g_HiddenDllNames) / sizeof(g_HiddenDllNames[0]);

static bool IsOurDllName(const wchar_t* name) {
    if (!name) return false;
    for (int i = 0; i < g_HiddenDllCount; i++) {
        if (_wcsicmp(name, g_HiddenDllNames[i]) == 0) return true;
    }
    return false;
}

static void UnlinkModuleFromPEB(HMODULE hModule) {
    if (!hModule) return;

    typedef NTSTATUS (NTAPI* NtQueryInformationProcess_t)(
        HANDLE, PROCESSINFOCLASS, PVOID, ULONG, PULONG);

    HMODULE hNtdll = GetModuleHandleA("ntdll.dll");
    if (!hNtdll) return;

    NtQueryInformationProcess_t pNtQIP =
        (NtQueryInformationProcess_t)GetProcAddress(hNtdll, "NtQueryInformationProcess");
    if (!pNtQIP) return;

    PROCESS_BASIC_INFORMATION pbi = { 0 };
    NTSTATUS status = pNtQIP(GetCurrentProcess(), ProcessBasicInformation, &pbi, sizeof(pbi), NULL);
    if (status != 0 || !pbi.PebBaseAddress) return;

    PEB* peb = pbi.PebBaseAddress;
    if (!peb->Ldr) return;

    // InLoadOrderModuleList offset in PEB_LDR_DATA:
    //   x64: +0x10 (after ULONG Length, BOOLEAN Initialized, padding, PVOID SsHandle)
    //   x86: +0x0C (after ULONG Length, BOOLEAN Initialized, PVOID SsHandle)
#ifdef _WIN64
    LIST_ENTRY* head = (LIST_ENTRY*)((BYTE*)peb->Ldr + 0x10);
#else
    LIST_ENTRY* head = (LIST_ENTRY*)((BYTE*)peb->Ldr + 0x0C);
#endif
    LIST_ENTRY* curr = head->Flink;

    while (curr != head) {
        MY_LDR_DATA_TABLE_ENTRY* entry = CONTAINING_RECORD(
            curr, MY_LDR_DATA_TABLE_ENTRY, InLoadOrderLinks);

        if (entry->DllBase == hModule) {
            // Unlink from InLoadOrder
            entry->InLoadOrderLinks.Blink->Flink = entry->InLoadOrderLinks.Flink;
            entry->InLoadOrderLinks.Flink->Blink = entry->InLoadOrderLinks.Blink;
            // Unlink from InMemoryOrder
            entry->InMemoryOrderLinks.Blink->Flink = entry->InMemoryOrderLinks.Flink;
            entry->InMemoryOrderLinks.Flink->Blink = entry->InMemoryOrderLinks.Blink;
            // Unlink from InInitializationOrder
            entry->InInitializationOrderLinks.Blink->Flink = entry->InInitializationOrderLinks.Flink;
            entry->InInitializationOrderLinks.Flink->Blink = entry->InInitializationOrderLinks.Blink;

            OutputDebugStringA("[DetourAPIHook] Module unlinked from PEB\n");
            break;
        }
        curr = curr->Flink;
    }
}

void UnlinkSelfFromPEB(HMODULE hModule) {
    g_OurModule = hModule;
    UnlinkModuleFromPEB(hModule);
}

// ============================================================================
//  Network Table Filtering Hooks (4 APIs)
//  Hide own PID connections from TCP/UDP table queries
//  Prevents protection modules from detecting game network connections
// ============================================================================

// --- GetExtendedTcpTable ---
typedef DWORD (WINAPI* GetExtendedTcpTable_t)(PVOID, PDWORD, BOOL, ULONG, TCP_TABLE_CLASS, ULONG);
static GetExtendedTcpTable_t Real_GetExtendedTcpTable = NULL;

static DWORD WINAPI Hooked_GetExtendedTcpTable(
    PVOID pTcpTable, PDWORD pdwSize, BOOL bOrder,
    ULONG ulAf, TCP_TABLE_CLASS TableClass, ULONG Reserved
) {
    DWORD result = Real_GetExtendedTcpTable(pTcpTable, pdwSize, bOrder, ulAf, TableClass, Reserved);
    if (result != NO_ERROR || !pTcpTable) return result;

    DWORD myPid = GetCurrentProcessId();

    if (TableClass == TCP_TABLE_OWNER_PID_ALL && ulAf == AF_INET) {
        MIB_TCPTABLE_OWNER_PID* table = (MIB_TCPTABLE_OWNER_PID*)pTcpTable;
        DWORD newCount = 0;
        for (DWORD i = 0; i < table->dwNumEntries; i++) {
            if (table->table[i].dwOwningPid != myPid) {
                if (newCount != i) table->table[newCount] = table->table[i];
                newCount++;
            }
        }
        table->dwNumEntries = newCount;
    }
    return result;
}

    if (TableClass == UDP_TABLE_OWNER_PID && ulAf == AF_INET) {

        DWORD newCount = 0;

            if (table->table[i].dwOwningPid != myPid) {
                if (newCount != i) table->table[newCount] = table->table[i];
                newCount++;
            }
        }
        table->dwNumEntries = newCount;
    }
    return result;
}

#include "hook_self_protect.h"
#include "caller_check.h"
#include <windows.h>
#include <Psapi.h>
#include <intrin.h>
#include <detours/detours.h>
#include <winternl.h>

#pragma comment(lib, "detours.lib")
#pragma comment(lib, "psapi.lib")
#pragma comment(lib, "advapi32.lib")

// ============================================================================
//  Self-Protection Hooks (4 APIs)
//  1. Blocks external memory modification of our DLL.
//  2. Blocks protection modules (NGS) from writing breakpoints/patches
//     into game executable memory (where our hooks live).
//  3. Blocks protection modules from restoring original bytes in
//     ntdll.dll/kernel32.dll/kernelbase.dll (where Detours JMP trampolines live).
//  Also provides PE header erasure to prevent memory dumping.
// ============================================================================

// Our DLL's memory range (set during install)
static ULONG_PTR g_SelfBase = 0;
static ULONG_PTR g_SelfEnd  = 0;

// Game executable memory range (set during install)
static ULONG_PTR g_GameBase = 0;
static ULONG_PTR g_GameEnd  = 0;

// Hooked system DLL ranges — protects Detours JMP trampolines
struct ModuleRange { ULONG_PTR base; ULONG_PTR end; };
static ModuleRange g_HookedModules[4] = { 0 }; // ntdll, kernel32, kernelbase, user32
static int g_HookedModuleCount = 0;

static void AddHookedModule(const char* name) {
    if (g_HookedModuleCount >= 4) return;
    HMODULE h = GetModuleHandleA(name);
    if (!h) return;
    MODULEINFO mi = { 0 };
    if (GetModuleInformation(GetCurrentProcess(), h, &mi, sizeof(mi))) {
        g_HookedModules[g_HookedModuleCount].base = (ULONG_PTR)mi.lpBaseOfDll;
        g_HookedModules[g_HookedModuleCount].end  = (ULONG_PTR)mi.lpBaseOfDll + mi.SizeOfImage;
        g_HookedModuleCount++;
    }
}

static bool IsTargetingSelf(PVOID address) {
    if (!g_SelfBase || !g_SelfEnd) return false;
    ULONG_PTR addr = (ULONG_PTR)address;
    return (addr >= g_SelfBase && addr < g_SelfEnd);
}

static bool IsTargetingGameModule(PVOID address) {
    if (!g_GameBase || !g_GameEnd) return false;
    ULONG_PTR addr = (ULONG_PTR)address;
    return (addr >= g_GameBase && addr < g_GameEnd);
}

// Check if address falls within ntdll/kernel32/kernelbase/user32
// where our Detours JMP trampolines are installed
static bool IsTargetingHookedModule(PVOID address) {
    ULONG_PTR addr = (ULONG_PTR)address;
    for (int i = 0; i < g_HookedModuleCount; i++) {
        if (addr >= g_HookedModules[i].base && addr < g_HookedModules[i].end)
            return true;
    }
    return false;
}

static void CalculateSelfRange() {
    HMODULE hSelf = NULL;
    // Get our own module handle via return address
    GetModuleHandleExA(
        GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS | GET_MODULE_HANDLE_EX_FLAG_UNCHANGED_REFCOUNT,
        (LPCSTR)&CalculateSelfRange,
        &hSelf
    );
    if (!hSelf) return;

    MODULEINFO mi = { 0 };
    if (GetModuleInformation(GetCurrentProcess(), hSelf, &mi, sizeof(mi))) {
        g_SelfBase = (ULONG_PTR)mi.lpBaseOfDll;
        g_SelfEnd  = g_SelfBase + mi.SizeOfImage;
    }

    // Also capture game executable range
    HMODULE hExe = GetModuleHandleA(NULL);
    if (hExe) {
        MODULEINFO exeInfo = { 0 };
        if (GetModuleInformation(GetCurrentProcess(), hExe, &exeInfo, sizeof(exeInfo))) {
            g_GameBase = (ULONG_PTR)exeInfo.lpBaseOfDll;
            g_GameEnd  = g_GameBase + exeInfo.SizeOfImage;
        }
    }

    // Register system DLLs where our Detours JMP trampolines are installed
    AddHookedModule("ntdll.dll");
    AddHookedModule("kernel32.dll");
    AddHookedModule("kernelbase.dll");
    AddHookedModule("user32.dll");
}

// ============================================================================
//  1. NtWriteVirtualMemory
//  - Block all writes targeting our DLL
//  - Block protection modules from writing to game exe (breakpoint/patch)
// ============================================================================

typedef NTSTATUS (NTAPI* NtWriteVirtualMemory_t)(
    HANDLE ProcessHandle, PVOID BaseAddress,
    PVOID Buffer, ULONG NumberOfBytesToWrite, PULONG NumberOfBytesWritten
);
static NtWriteVirtualMemory_t Real_NtWriteVirtualMemory = NULL;

static NTSTATUS NTAPI Hooked_NtWriteVirtualMemory(
    HANDLE ProcessHandle, PVOID BaseAddress,
    PVOID Buffer, ULONG NumberOfBytesToWrite, PULONG NumberOfBytesWritten
) {
    // Block writes targeting our own DLL (from anyone)
    if (IsTargetingSelf(BaseAddress)) {
        if (NumberOfBytesWritten) *NumberOfBytesWritten = 0;
        return (NTSTATUS)0xC0000022L; // STATUS_ACCESS_DENIED
    }
    // Block protection modules from writing to game exe memory
    // (NGS writes INT3 breakpoints or patches to detect/unhook our hooks)
    if ((IsTargetingGameModule(BaseAddress) || IsTargetingHookedModule(BaseAddress)) &&
        CallerCheck::IsFromAnyProtectionModule(_ReturnAddress())) {
        OutputDebugStringA("[DetourAPIHook] NtWriteVirtualMemory: blocked protection module write to protected memory\n");
        if (NumberOfBytesWritten) *NumberOfBytesWritten = NumberOfBytesToWrite;
        return 0; // STATUS_SUCCESS (pretend write succeeded)
    }
    return Real_NtWriteVirtualMemory(ProcessHandle, BaseAddress, Buffer,
                                      NumberOfBytesToWrite, NumberOfBytesWritten);
}

// ============================================================================
//  2. WriteProcessMemory
//  - Block writes to our DLL (from anyone)
//  - Block protection modules from patching game exe
// ============================================================================

typedef BOOL (WINAPI* WriteProcessMemory_t)(
    HANDLE hProcess, LPVOID lpBaseAddress,
    LPCVOID lpBuffer, SIZE_T nSize, SIZE_T* lpNumberOfBytesWritten
);
static WriteProcessMemory_t Real_WriteProcessMemory = NULL;

static BOOL WINAPI Hooked_WriteProcessMemory(
    HANDLE hProcess, LPVOID lpBaseAddress,
    LPCVOID lpBuffer, SIZE_T nSize, SIZE_T* lpNumberOfBytesWritten
) {
    // Block writes targeting our own DLL
    if (IsTargetingSelf(lpBaseAddress)) {
        SetLastError(ERROR_ACCESS_DENIED);
        return FALSE;
    }
    // Block protection modules from writing to game exe or hooked system DLL memory
    if ((IsTargetingGameModule(lpBaseAddress) || IsTargetingHookedModule(lpBaseAddress)) &&
        CallerCheck::IsFromAnyProtectionModule(_ReturnAddress())) {
        OutputDebugStringA("[DetourAPIHook] WriteProcessMemory: blocked protection module write to protected memory\n");
        if (lpNumberOfBytesWritten) *lpNumberOfBytesWritten = nSize;
        return TRUE; // Pretend success
    }
    return Real_WriteProcessMemory(hProcess, lpBaseAddress, lpBuffer, nSize, lpNumberOfBytesWritten);
}

// ============================================================================
//  3. VirtualProtectEx
//  - Block protection changes to our DLL pages
//  - Block protection modules from making game exe pages writable
//    (NGS changes PAGE_EXECUTE_READ to PAGE_EXECUTE_READWRITE to write patches)
// ============================================================================

typedef BOOL (WINAPI* VirtualProtectEx_t)(HANDLE, LPVOID, SIZE_T, DWORD, PDWORD);
static VirtualProtectEx_t Real_VirtualProtectEx = NULL;

static BOOL WINAPI Hooked_VirtualProtectEx(
    HANDLE hProcess, LPVOID lpAddress, SIZE_T dwSize,
    DWORD flNewProtect, PDWORD lpflOldProtect
) {
    // Self-protection: block writable protection on our pages
    if (IsTargetingSelf(lpAddress)) {
        if (flNewProtect == PAGE_READWRITE || flNewProtect == PAGE_EXECUTE_READWRITE) {
            if (lpflOldProtect) *lpflOldProtect = PAGE_EXECUTE_READ;
            return TRUE; // Pretend success without actually changing protection
        }
    }
    // Block protection modules from making game or hooked DLL pages writable
    if ((IsTargetingGameModule(lpAddress) || IsTargetingHookedModule(lpAddress)) &&
        CallerCheck::IsFromAnyProtectionModule(_ReturnAddress())) {
        if (flNewProtect == PAGE_READWRITE || flNewProtect == PAGE_EXECUTE_READWRITE) {
            OutputDebugStringA("[DetourAPIHook] VirtualProtectEx: blocked protection module changing protected page\n");
            if (lpflOldProtect) *lpflOldProtect = PAGE_EXECUTE_READ;
            return TRUE; // Pretend success
        }
    }
    return Real_VirtualProtectEx(hProcess, lpAddress, dwSize, flNewProtect, lpflOldProtect);
}

// ============================================================================
//  4. VirtualProtect (local variant)
// ============================================================================

typedef BOOL (WINAPI* VirtualProtect_t)(LPVOID, SIZE_T, DWORD, PDWORD);
static VirtualProtect_t Real_VirtualProtect = NULL;

static BOOL WINAPI Hooked_VirtualProtect(
    LPVOID lpAddress, SIZE_T dwSize, DWORD flNewProtect, PDWORD lpflOldProtect
) {
    if (IsTargetingSelf(lpAddress)) {
        if (flNewProtect == PAGE_READWRITE || flNewProtect == PAGE_EXECUTE_READWRITE) {
            if (lpflOldProtect) *lpflOldProtect = PAGE_EXECUTE_READ;
            return TRUE;
        }
    }
    if ((IsTargetingGameModule(lpAddress) || IsTargetingHookedModule(lpAddress)) &&
        CallerCheck::IsFromAnyProtectionModule(_ReturnAddress())) {
        if (flNewProtect == PAGE_READWRITE || flNewProtect == PAGE_EXECUTE_READWRITE) {
            OutputDebugStringA("[DetourAPIHook] VirtualProtect: blocked protection module changing protected page\n");
            if (lpflOldProtect) *lpflOldProtect = PAGE_EXECUTE_READ;
            return TRUE;
        }
    }
    return Real_VirtualProtect(lpAddress, dwSize, flNewProtect, lpflOldProtect);
}

// ============================================================================
//  PE Header Erasure
//  Zero out the DOS and PE headers in memory to prevent memory dumping
//  and make it harder for anti-cheat to identify our DLL.
// ============================================================================

void ErasePEHeader(HMODULE hModule) {
    if (!hModule) return;

    BYTE* base = (BYTE*)hModule;
    PIMAGE_DOS_HEADER dosHeader = (PIMAGE_DOS_HEADER)base;

    if (dosHeader->e_magic != IMAGE_DOS_SIGNATURE) return;

    PIMAGE_NT_HEADERS ntHeaders = (PIMAGE_NT_HEADERS)(base + dosHeader->e_lfanew);
    if (ntHeaders->Signature != IMAGE_NT_SIGNATURE) return;

    // Calculate total header size
    DWORD headerSize = ntHeaders->OptionalHeader.SizeOfHeaders;

    // Temporarily make headers writable
    DWORD oldProtect = 0;
    if (VirtualProtect(base, headerSize, PAGE_READWRITE, &oldProtect)) {
        // Zero out the entire header region
        SecureZeroMemory(base, headerSize);
        // Restore protection
        VirtualProtect(base, headerSize, oldProtect, &oldProtect);
    }
}

// ============================================================================
//  Hook Integrity Watchdog
//  Background thread that periodically checks if our Detours JMP trampolines
//  have been overwritten by anti-cheat (e.g., nProtect using direct syscalls).
//  If tampering detected, re-patches the hooked function bytes.
// ============================================================================

struct HookSnapshot {
    PVOID  address;         // Function address (e.g., ntdll!NtReadVirtualMemory)
    BYTE   hookedBytes[16]; // First 16 bytes after our hook is installed
    bool   valid;
};

static const int MAX_WATCHED_HOOKS = 64;
static HookSnapshot g_WatchedHooks[MAX_WATCHED_HOOKS] = { 0 };
static int g_WatchedHookCount = 0;
static HANDLE g_WatchdogThread = NULL;
static volatile bool g_WatchdogRunning = false;

void RegisterHookForWatchdog(PVOID funcAddress) {
    if (!funcAddress || g_WatchedHookCount >= MAX_WATCHED_HOOKS) return;

    HookSnapshot& snap = g_WatchedHooks[g_WatchedHookCount];
    snap.address = funcAddress;
    // Snapshot the current (hooked) bytes
    memcpy(snap.hookedBytes, funcAddress, 16);
    snap.valid = true;
    g_WatchedHookCount++;
}

static DWORD WINAPI HookWatchdogThread(LPVOID) {
    while (g_WatchdogRunning) {
        for (int i = 0; i < g_WatchedHookCount; i++) {
            if (!g_WatchedHooks[i].valid) continue;

            // Compare current bytes with our snapshot
            if (memcmp(g_WatchedHooks[i].address,
                       g_WatchedHooks[i].hookedBytes, 16) != 0) {
                // Hook has been tampered! Re-patch it.
                OutputDebugStringA("[DetourAPIHook] WATCHDOG: Hook tampering detected, re-patching!\n");

                DWORD oldProtect = 0;
                if (VirtualProtect(g_WatchedHooks[i].address, 16,
                                   PAGE_EXECUTE_READWRITE, &oldProtect)) {
                    memcpy(g_WatchedHooks[i].address,
                           g_WatchedHooks[i].hookedBytes, 16);
                    VirtualProtect(g_WatchedHooks[i].address, 16,
                                   oldProtect, &oldProtect);
                    FlushInstructionCache(GetCurrentProcess(),
                                          g_WatchedHooks[i].address, 16);
                }
            }
        }
        Sleep(500); // Check every 500ms
    }
    return 0;
}

void StartHookWatchdog() {
    if (g_WatchdogThread) return;
    g_WatchdogRunning = true;
    g_WatchdogThread = CreateThread(NULL, 0, HookWatchdogThread, NULL, 0, NULL);
}

void StopHookWatchdog() {
    g_WatchdogRunning = false;
    if (g_WatchdogThread) {
        WaitForSingleObject(g_WatchdogThread, 2000);
        CloseHandle(g_WatchdogThread);
        g_WatchdogThread = NULL;
    }
}

bool InstallSelfProtectHooks() {
    CalculateSelfRange();

    // === Anti-External-Termination (Safe DACL approach) ===
    // Modify process security descriptor to deny PROCESS_TERMINATE access.
    // This prevents NGM64.exe from calling TerminateProcess on us.
    // Unlike RtlSetProcessIsCritical, this does NOT cause BSOD on crash.
    {
        HANDLE hProcess = GetCurrentProcess();
        PACL pOldDacl = NULL;
        PSECURITY_DESCRIPTOR pSD = NULL;

        // Get current DACL
        if (GetSecurityInfo(hProcess, SE_KERNEL_OBJECT, DACL_SECURITY_INFORMATION,
            NULL, NULL, &pOldDacl, NULL, &pSD) == ERROR_SUCCESS) {

            // Create deny ACE for PROCESS_TERMINATE for Everyone (World SID)
            SID_IDENTIFIER_AUTHORITY worldAuth = SECURITY_WORLD_SID_AUTHORITY;
            PSID pEveryoneSid = NULL;
            if (AllocateAndInitializeSid(&worldAuth, 1, SECURITY_WORLD_RID,
                0, 0, 0, 0, 0, 0, 0, &pEveryoneSid)) {

                // PROCESS_TERMINATE = 0x0001
                EXPLICIT_ACCESS_A denyAccess = { 0 };
                denyAccess.grfAccessPermissions = PROCESS_TERMINATE;
                denyAccess.grfAccessMode = DENY_ACCESS;
                denyAccess.grfInheritance = NO_INHERITANCE;
                denyAccess.Trustee.TrusteeForm = TRUSTEE_IS_SID;
                denyAccess.Trustee.TrusteeType = TRUSTEE_IS_WELL_KNOWN_GROUP;
                denyAccess.Trustee.ptstrName = (LPSTR)pEveryoneSid;

                PACL pNewDacl = NULL;
                if (SetEntriesInAclA(1, &denyAccess, pOldDacl, &pNewDacl) == ERROR_SUCCESS) {
                    if (SetSecurityInfo(hProcess, SE_KERNEL_OBJECT, DACL_SECURITY_INFORMATION,
                        NULL, NULL, pNewDacl, NULL) == ERROR_SUCCESS) {
                        OutputDebugStringA("[DetourAPIHook] Process DACL hardened - PROCESS_TERMINATE denied\n");
                    }
                    LocalFree(pNewDacl);
                }
                FreeSid(pEveryoneSid);
            }
            if (pSD) LocalFree(pSD);
        }
    }

    HMODULE hNtdll    = GetModuleHandleA("ntdll.dll");
    HMODULE hKernel32 = GetModuleHandleA("kernel32.dll");
    if (!hNtdll || !hKernel32) return false;

    Real_NtWriteVirtualMemory = (NtWriteVirtualMemory_t)GetProcAddress(hNtdll, "NtWriteVirtualMemory");
    Real_WriteProcessMemory   = (WriteProcessMemory_t)GetProcAddress(hKernel32, "WriteProcessMemory");
    Real_VirtualProtectEx     = (VirtualProtectEx_t)GetProcAddress(hKernel32, "VirtualProtectEx");
    Real_VirtualProtect       = (VirtualProtect_t)GetProcAddress(hKernel32, "VirtualProtect");

    DetourTransactionBegin();
    DetourUpdateThread(GetCurrentThread());

    if (Real_NtWriteVirtualMemory) DetourAttach((PVOID*)&Real_NtWriteVirtualMemory, Hooked_NtWriteVirtualMemory);
    if (Real_WriteProcessMemory)   DetourAttach((PVOID*)&Real_WriteProcessMemory, Hooked_WriteProcessMemory);
    if (Real_VirtualProtectEx)     DetourAttach((PVOID*)&Real_VirtualProtectEx, Hooked_VirtualProtectEx);
    if (Real_VirtualProtect)       DetourAttach((PVOID*)&Real_VirtualProtect, Hooked_VirtualProtect);

    return (DetourTransactionCommit() == NO_ERROR);
}

    StopHookWatchdog();

    DetourTransactionBegin();
    DetourUpdateThread(GetCurrentThread());

    if (Real_NtWriteVirtualMemory) DetourDetach((PVOID*)&Real_NtWriteVirtualMemory, Hooked_NtWriteVirtualMemory);
    if (Real_WriteProcessMemory)   DetourDetach((PVOID*)&Real_WriteProcessMemory, Hooked_WriteProcessMemory);
    if (Real_VirtualProtectEx)     DetourDetach((PVOID*)&Real_VirtualProtectEx, Hooked_VirtualProtectEx);
    if (Real_VirtualProtect)       DetourDetach((PVOID*)&Real_VirtualProtect, Hooked_VirtualProtect);

    return (DetourTransactionCommit() == NO_ERROR);
}

#include "hook_timing.h"
#include <windows.h>
#include <detours/detours.h>
#include <winternl.h>

#pragma comment(lib, "detours.lib")

// ============================================================================
//  Timing Attack Prevention Hooks (4 APIs)
//  Anti-cheat uses timing measurements to detect:
//    - Debugger single-stepping (large time deltas)
//    - Speed hacks (abnormal tick progression)
//  We track a baseline and clamp deltas to prevent detection.
// ============================================================================

// Timing normalization state
static LARGE_INTEGER g_QpcBaseline = { 0 };    // First QPC value captured
static LARGE_INTEGER g_QpcLastReal = { 0 };    // Last real QPC value
static LARGE_INTEGER g_QpcLastFake = { 0 };    // Last returned (smoothed) QPC value
static DWORD         g_TickBaseline = 0;       // First tick value
static DWORD         g_TickLastReal = 0;
static DWORD         g_TickLastFake = 0;
static ULONGLONG     g_Tick64Baseline = 0;
static ULONGLONG     g_Tick64LastReal = 0;
static ULONGLONG     g_Tick64LastFake = 0;
static bool          g_TimingInitialized = false;

// Maximum allowed delta in QPC counts per call (= ~100ms at 10MHz freq)
// Anything larger is clamped (debugger pause detection bypass)
#define MAX_QPC_DELTA_FACTOR 2  // Allow 2x real speed at most
#define MAX_TICK_DELTA       200 // Max 200ms per call delta

// ============================================================================
//  1. QueryPerformanceCounter
// ============================================================================

typedef BOOL (WINAPI* QueryPerformanceCounter_t)(LARGE_INTEGER*);
static QueryPerformanceCounter_t Real_QueryPerformanceCounter = NULL;

static BOOL WINAPI Hooked_QueryPerformanceCounter(LARGE_INTEGER* lpPerformanceCount) {
    BOOL result = Real_QueryPerformanceCounter(lpPerformanceCount);
    if (!result || !lpPerformanceCount) return result;

    if (!g_TimingInitialized) {
        g_QpcBaseline = *lpPerformanceCount;
        g_QpcLastReal = *lpPerformanceCount;
        g_QpcLastFake = *lpPerformanceCount;
        g_TimingInitialized = true;
        return result;
    }

    LONGLONG realDelta = lpPerformanceCount->QuadPart - g_QpcLastReal.QuadPart;
    g_QpcLastReal = *lpPerformanceCount;

    // Clamp excessive deltas (debugger pause detection)
    if (realDelta < 0) realDelta = 0;

    // Get frequency for meaningful clamping
    LARGE_INTEGER freq;
    QueryPerformanceFrequency(&freq);
    LONGLONG maxDelta = freq.QuadPart / 5; // Max 200ms delta

    if (realDelta > maxDelta) {
        realDelta = maxDelta;
    }

    g_QpcLastFake.QuadPart += realDelta;
    *lpPerformanceCount = g_QpcLastFake;

    return result;
}

// ============================================================================
//  2. GetTickCount
// ============================================================================

typedef DWORD (WINAPI* GetTickCount_t)(void);
static GetTickCount_t Real_GetTickCount = NULL;

static DWORD WINAPI Hooked_GetTickCount(void) {
    DWORD real = Real_GetTickCount();

    if (g_TickBaseline == 0) {
        g_TickBaseline = real;
        g_TickLastReal = real;
        g_TickLastFake = real;
        return real;
    }

    DWORD realDelta = real - g_TickLastReal;
    g_TickLastReal = real;

    if (realDelta > MAX_TICK_DELTA) {
        realDelta = MAX_TICK_DELTA;
    }

    g_TickLastFake += realDelta;
    return g_TickLastFake;
}

// ============================================================================
//  3. GetTickCount64
// ============================================================================

typedef ULONGLONG (WINAPI* GetTickCount64_t)(void);
static GetTickCount64_t Real_GetTickCount64 = NULL;

static ULONGLONG WINAPI Hooked_GetTickCount64(void) {
    ULONGLONG real = Real_GetTickCount64();

    if (g_Tick64Baseline == 0) {
        g_Tick64Baseline = real;
        g_Tick64LastReal = real;

    }

    g_Tick64LastReal = real;

    if (realDelta > MAX_TICK_DELTA) {
        realDelta = MAX_TICK_DELTA;
    }

    g_Tick64LastFake += realDelta;
    return g_Tick64LastFake;
}

// ============================================================================
//  4. NtQueryPerformanceCounter (low-level)
// ============================================================================

typedef NTSTATUS (NTAPI* NtQueryPerformanceCounter_t)(PLARGE_INTEGER, PLARGE_INTEGER);
static NtQueryPerformanceCounter_t Real_NtQueryPerformanceCounter = NULL;

static NTSTATUS NTAPI Hooked_NtQueryPerformanceCounter(
    PLARGE_INTEGER PerformanceCounter, PLARGE_INTEGER PerformanceFrequency
) {
    NTSTATUS status = Real_NtQueryPerformanceCounter(PerformanceCounter, PerformanceFrequency);
    if (status == 0 && PerformanceCounter) {
        // Delegate to same smoothing logic as QueryPerformanceCounter
        Hooked_QueryPerformanceCounter(PerformanceCounter);
    }
    return status;
}

// ============================================================================
//  Install / Remove
// ============================================================================

bool InstallTimingHooks() {
    HMODULE hKernel32 = GetModuleHandleA("kernel32.dll");
    HMODULE hNtdll    = GetModuleHandleA("ntdll.dll");
    if (!hKernel32 || !hNtdll) return false;

    Real_QueryPerformanceCounter   = (QueryPerformanceCounter_t)GetProcAddress(hKernel32, "QueryPerformanceCounter");
    Real_GetTickCount              = (GetTickCount_t)GetProcAddress(hKernel32, "GetTickCount");
    Real_GetTickCount64            = (GetTickCount64_t)GetProcAddress(hKernel32, "GetTickCount64");
    Real_NtQueryPerformanceCounter = (NtQueryPerformanceCounter_t)GetProcAddress(hNtdll, "NtQueryPerformanceCounter");

    DetourTransactionBegin();
    DetourUpdateThread(GetCurrentThread());

    if (Real_QueryPerformanceCounter)   DetourAttach((PVOID*)&Real_QueryPerformanceCounter, Hooked_QueryPerformanceCounter);
    if (Real_GetTickCount)              DetourAttach((PVOID*)&Real_GetTickCount, Hooked_GetTickCount);
    if (Real_GetTickCount64)            DetourAttach((PVOID*)&Real_GetTickCount64, Hooked_GetTickCount64);
    if (Real_NtQueryPerformanceCounter) DetourAttach((PVOID*)&Real_NtQueryPerformanceCounter, Hooked_NtQueryPerformanceCounter);

    return (DetourTransactionCommit() == NO_ERROR);
}

bool RemoveTimingHooks() {
    DetourTransactionBegin();
    DetourUpdateThread(GetCurrentThread());

    if (Real_QueryPerformanceCounter)   DetourDetach((PVOID*)&Real_QueryPerformanceCounter, Hooked_QueryPerformanceCounter);
    if (Real_GetTickCount)              DetourDetach((PVOID*)&Real_GetTickCount, Hooked_GetTickCount);
    if (Real_GetTickCount64)            DetourDetach((PVOID*)&Real_GetTickCount64, Hooked_GetTickCount64);
    if (Real_NtQueryPerformanceCounter) DetourDetach((PVOID*)&Real_NtQueryPerformanceCounter, Hooked_NtQueryPerformanceCounter);

    return (DetourTransactionCommit() == NO_ERROR);
}
