`README.md`:

```md
# ◆ GameCheat Scanner

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-success)
![License](https://img.shields.io/badge/License-MIT-green)
![Status](https://img.shields.io/badge/Статус-v1.0-brightgreen)

Программа для поиска и изменения значений в памяти игры — аналог
**ArtMoney / Cheat Engine** для одиночных игр. Два ключевых отличия от
базового Cheat Engine:

1. **Многотиповый поиск по умолчанию.** Вводите одно число (например `100`),
   а «Поиск» ищет его *одновременно* как `int8/16/32/64`, `uint*`,
   `float32/64` — в little- и big-endian. В базовом Cheat Engine надо сначала
   угадать тип данных, иначе «по умолчанию ничего не находит». Здесь совпадения
   приходят со всеми правдоподобными типами сразу.

2. **Авто-отсев по методике Cheat Engine.** Если точных совпадений нет
   (значение хранится не как прямой int — float с дробью, масштабированное,
   обфусцированное), программа автоматически переходит к поиску **изменившихся**
   адресов по снимку памяти и **ранжирует** их по похожести на ваше изменение.
   Чередование «изменилось → не изменилось» сужает список до нужного адреса
   за 3–5 ходов вместо десятков.

---

## ⚖️ Этика и область применения

**Использовать ТОЛЬКО в одиночных (single-player) играх и для личных целей:**
обучение reverse-engineering, моддинг, тренировка, прохождение без гринда,
эксперименты с сохранениями.

**НЕ использовать:**
- в многопользовательских / онлайн-играх (это читерство против живых людей,
  нарушение ToS, бан-риск);
- для обхода античит-систем и защиты коммерческого ПО;
- для получения нечестного преимущества в соревновательных режимах.

Программа работает только с памятью процессов, которые вы сами выбрали на
своей машине. Она не содержит сетевой функциональности и не отправляет
данные куда-либо.

## Требования

- **Windows 10/11** для реальных игр (доступ к памяти через WinAPI).
- **Python 3.10+** для запуска из исходников или сборки .exe.
- Пакет **numpy** (для быстрого авто-отсева; без него работает медленный
  запасной режим).
- tkinter и ctypes — часть стандартной библиотеки Python, отдельная
  установка не нужна.

> На Linux/macOS реальный доступ к чужой памяти невозможен, поэтому
> программа работает в **учебном режиме** (`MockProcess`): демо-игра с
> health/ammo/gold/mana/level. Удобно изучить интерфейс и логику до запуска
> на Windows.

## Использование

### 1. Подключение

При запуске программа сама находит игровое приложение и подключается к нему
(оверлеи/анти-чит/крэш-хендлеры помечаются 🛠 и идут после настоящих игр 🎮).
Можно выбрать процесс вручную в списке — подключение происходит автоматически.
Кнопка **↻** обновляет список, галка «все процессы» показывает системные тоже.

### 2. Поиск значения

Введите текущее значение (HP=100, золото=5000 …) и нажмите **▶ Поиск**.
Программа ищет его по всем типам сразу и делает снимок памяти для авто-отсева.

### 3. Отсев — основной цикл (методика Cheat Engine)

Измените значение в игре, впишите новое и нажмите **Отсев**:

- **Точный отсев** — оставляет адреса, где значение стало равно введённому.
- Если точных нет → **авто-fallback**: программа сравнивает снимок памяти с
  текущим состоянием, находит **изменившиеся** адреса и **ранжирует** их по
  похожести на ваше изменение (масштабно-инвариантное отношение old/new —
  работает для int, float с дробью и масштабированного хранения). Наверху
  таблицы — самые вероятные.

Затем **чередуйте** (ключевой приём Cheat Engine для быстрой сходимости):

| Шаг | В игре | Поле «Значение» | Кнопка | Что происходит |
|-----|--------|-----------------|--------|----------------|
| 1 | измените значение | впишите новое | Отсев | направленный отсев (упало/выросло) |
| 2 | **не меняйте** | **оставьте пустым** | Отсев | отсев «не изменилось» — убирает тикающий шум |
| 3 | измените значение | впишите новое | Отсев | сужение направленным отсевом |
| 4 | не меняйте | пусто | Отсев | снова убрать шум |

За 3–5 таких ходов список сжимается до 1–5 адресов, и нужный почти всегда
в первой строке (благодаря ранжированию).

> «Тикающий шум» — это таймеры, счётчики кадров, RNG, сетевые буферы: они
> меняются постоянно. Направленный отсев их частично оставляет, а отсев
> «не изменилось» (когда вы значение не трогали) — гарантированно убирает,
> ведь реальный ресурс в этот момент стоит на месте.

### 4. Запись и заморозка

Выделите нужную строку → впишите новое значение → **Записать**, либо
**Заморозить** (программа переписывает значение ~20 раз/сек, так что
здоровье «не падает» и т.п.). Значения незамороженных адресов обновляются
в реальном времени. Кнопка **✕ Убрать из списка** удаляет строку.

### Учебный режим (не-Windows)

В учебном режиме внизу есть кнопки симуляции: «Урон -10», «Лечение +10»,
«Выстрел -1», «Трата -250$», «Доход +150$», «Тик шума». Нажимайте их вместо
реальных действий в игре, чтобы пройти весь цикл без запуска игры.

### Как работает авто-отсев (кратко)

1. **Baseline** — снимок всех data-регионов (`MEM_PRIVATE`/`MEM_MAPPED`,
   RW, без `EXECUTE` — куча и данные, а не код).
2. **Diff** — для каждого 4/8-байтного слота сравниваются старое и новое
   значения. Векторизовано через numpy.
3. **Один адрес = один тип** (как в Cheat Engine): сначала ищем `int32`;
   `float32` берём только для слотов, где int32 неправдоподобен, но float
   «чистый» (не денормаль, |v| в 1e-4…1e10). Так не плодятся мусорные
   float-интерпретации тех же байт.
4. **Ранжирование** — кандидаты сортируются по близости отношения old/new
   к введённому вами изменению. Масштабно-инвариантно: работает для int,
   float с дробью и масштабированного хранения (×k).
5. **Сужение** — направленный отсев (упало/выросло) в ~2× избирательнее
   «changed»; «не изменилось» убирает тикающий шум. Чередование сходится
   за 3–5 ходов.

### Многотиповый первый скан

Для введённого значения каждый включённый тип пытается упаковать его в байты
(`struct.pack`); типы, в которые значение не влезает (напр. 5000 в `int8`),
пропускаются. Затем в каждом data-регионе ищутся все вхождения каждого
паттерна через `bytes.find` в цикле. Так один запрос `100` находит и
`health=100` (int32), и `max_hp=100`, и возможные `float32=100.0` — без
угадывания типа.

## Ограничения и tips

- **Права администратора** обязательны для доступа к памяти чужого процесса.
- **Указатели/динамическая память**: после перезапуска игры адреса
  смещаются (ASLR). Для постоянных читов нужны указатели/`pointermaps`
  (это умеет Cheat Engine); здесь реализован прямой поиск по адресу,
  достаточный для сессии.
- **Шифрованные значения**: некоторые игры хранят HP не как `100`, а как
  `100 XOR ключ` или обфусцированно. Точный «Поиск» не сработает —
  используйте авто-отсев (он ищет по *характеру изменения*, а не по
  значению, и обходит простую обфускацию).
- **Скорость**: «Поиск» по большому процессу (≥1 ГБ data-памяти) занимает
  десятки секунд; прогресс виден в строке состояния и на полосе. Авто-отсев
  читает память повторно — несколько секунд, с «бегущим» индикатором.
- **Заморозка** переписывает значение ~20 раз/сек. Если игра переписывает
  чаще — может «дрожать»; для надёжности замораживайте и max-значение тоже.

"""
auto_detect.py
Автоматическое обнаружение "стандартных ресурсов" в игре (здоровье, патроны,
золото, мана, уровень, опыт, выносливость) — та самая фишка, которой
просил пользователь: "программа сама находила стандартные ресурсы".

Подход — гибрид сигнатур + diff-у снимков памяти:

1. capture_baseline() — снимок всех data-регионов (приватная RW память,
   без исполняемого кода). Хранятся сырые байты на регион.

2. Пользователь совершает действие в игре и сообщает инструменту, что
   произошло: "получил урон" (health ↓), "выстрелил" (ammo ↓), "получил
   золото" (gold ↑), и т.п. Можно указать примерную величину изменения.

3. apply_action() делает новый снимок и для каждого 4/8-байтного слота
   сравнивает old vs new. Кандидаты — адреса, где значение изменилось в
   нужном направлении, на правдоподобную величину, и лежит в правдоподобном
   диапазоне для данного ресурса. Сравнение векторизовано через numpy —
   весь кучный регион диффится за доли секунды.

4. Каждое последующее действие сужает список кандидатов (фильтруются уже
   найденные адреса). После 2-3 шагов остаются единицы.

5. classify() оценивает каждого кандидата по набору сигнатур: диапазон
   значения, предпочтительный тип, диапазон изменения, соседний паттерн
   (напр. max_health часто лежит по смещению +4 от текущего health).
   Каждому присваивается наиболее вероятная метка ресурса и confidence.

Так пользователь находит ресурсы БЕЗ знания точного значения — только по
характеру изменений, как ArtMoney "unknown initial value" + "decreased",
но сразу с автоматической классификацией, что это скорее всего health.
"""

from __future__ import annotations
import time
from dataclasses import dataclass, field
from typing import Callable

try:
    import numpy as np
    _HAS_NUMPY = True
except ImportError:  # pragma: no cover
    _HAS_NUMPY = False

from process import Region


# ---------------------------------------------------------------------------
# Сигнатуры ресурсов
# ---------------------------------------------------------------------------

@dataclass(frozen=True)
class ResourceSignature:
    name: str
    label: str                       # человекочитаемое имя
    value_range: tuple[int, int]     # правдоподобный диапазон абсолютного значения
    delta_range: tuple[int, int]     # правдоподобная величина изменения за одно действие
    preferred_types: tuple[str, ...] # типы, в которых обычно хранится
    neighbor_offset: int = 0         # смещение "парного" значения (max), 0 = нет
    neighbor_relation: str = "ge"    # как сосед относится к текущему (ge/le/eq)


SIGNATURES: dict[str, ResourceSignature] = {
    "health": ResourceSignature(
        "health", "res_health", (1, 9999), (1, 500),
        ("int32", "float32", "uint32"),
        neighbor_offset=4, neighbor_relation="ge"),
    "mana": ResourceSignature(
        "mana", "res_mana", (0, 9999), (1, 200),
        ("int32", "float32", "uint32"),
        neighbor_offset=4, neighbor_relation="ge"),
    "stamina": ResourceSignature(
        "stamina", "res_stamina", (0, 1000), (1, 100),
        ("int32", "float32", "uint32")),
    "ammo": ResourceSignature(
        "ammo", "res_ammo", (0, 9999), (1, 200),
        ("int32", "uint32"),
        neighbor_offset=4, neighbor_relation="ge"),  # max_ammo рядом
    "gold": ResourceSignature(
        "gold", "res_gold", (0, 2_000_000_000), (1, 10_000_000),
        ("int32", "uint32", "int64", "uint64")),
    "level": ResourceSignature(
        "level", "res_level", (1, 1000), (1, 1),
        ("int32", "uint32")),
    "xp": ResourceSignature(
        "xp", "res_xp", (0, 2_000_000_000), (1, 1_000_000),
        ("int32", "uint32", "int64", "uint64")),
}

# Действия пользователя: (kind, direction, default_delta_hint).
# direction: "decreased" / "increased" / "changed".
ACTIONS = {
    "took_damage":    ("health",  "decreased", "health упало (получен урон)"),
    "healed":         ("health",  "increased", "health выросло (лечение)"),
    "fired":          ("ammo",    "decreased", "ammo упало (выстрел)"),
    "reloaded":       ("ammo",    "increased", "ammo выросло (перезарядка)"),

# ---------------------------------------------------------------------------
# Кандидат
# ---------------------------------------------------------------------------

@dataclass
class Candidate:
    address: int
    type_name: str
    baseline: float | int      # значение на baseline
    current: float | int       # последнее значение
    delta: float               # величина изменения (положительная = в сторону действия)
    best_label: str = "res_unknown"      # наиболее вероятный ресурс (ключ i18n)
    confidence: int = 0        # 0..100
    scores: dict = field(default_factory=dict)  # label -> score


@dataclass
class AutoProgress:
    step: str = ""
    regions_done: int = 0
    regions_total: int = 0
    candidates: int = 0
    elapsed: float = 0.0


# ---------------------------------------------------------------------------
# Детектор
# ---------------------------------------------------------------------------

class AutoDetector:
    def __init__(self, process):
        self.proc = process
        self._baseline: dict[int, bytes] = {}     # base -> raw bytes
        self._regions: list[Region] = []
        self.candidates: list[Candidate] = []
        self._has_baseline = False
        self._action_count = 0
        self._last_kind: str | None = None

    # ------------------------------------------------------------------
    # Baseline
    # ------------------------------------------------------------------

    def capture_baseline(self, progress_cb: Callable[[AutoProgress], None] | None = None):
        """Снимок всех data-регионов. Дублирует первый шаг ArtMoney
        'unknown initial value', но только по data-памяти (без кода)."""
        self._baseline.clear()
        self._regions = [r for r in self.proc.iter_regions(data_only=True) if r.is_data]
        self.candidates.clear()
        self._has_baseline = True
        self._action_count = 0
        prog = AutoProgress(step="baseline", regions_total=len(self._regions))
        t0 = time.time()
        for i, r in enumerate(self._regions):
            # Читаем регион целиком (если очень большой — кусками по 16 МБ).
            data = bytearray()
            off = 0
            while off < r.size:
                sz = min(16 * 1024 * 1024, r.size - off)
                data += self.proc.read(r.base + off, sz)
                off += sz
            self._baseline[r.base] = bytes(data)
            prog.regions_done = i + 1
            prog.elapsed = time.time() - t0
            if progress_cb:
                progress_cb(prog)
        if progress_cb:
            progress_cb(prog)

    @property
    def has_baseline(self) -> bool:
        return self._has_baseline

    @property
    def baseline_bytes(self) -> int:
        return sum(len(b) for b in self._baseline.values())

    # ------------------------------------------------------------------
    # Применить действие (дифф / фильтр)
    # ------------------------------------------------------------------

    def apply_action(self, action_id: str, magnitude: float | None = None,
                     progress_cb: Callable[[AutoProgress], None] | None = None):
        """
        action_id — ключ из ACTIONS (напр. 'took_damage').
        magnitude — примерная величина изменения (необязательно).

        Первый вызов после baseline — полный дифф по всей памяти.
        Последующие — фильтр уже найденных кандидатов.
        """
        if action_id not in ACTIONS:
            raise ValueError(f"Неизвестное действие: {action_id}")
        kind, direction, desc = ACTIONS[action_id]
        t0 = time.time()
        prog = AutoProgress(step=desc, regions_total=len(self._baseline))
        if not self._has_baseline:
            raise RuntimeError("Сначала сделайте baseline-снимок.")

        if not self.candidates:
            # Полный дифф от baseline.
            new_cands: list[Candidate] = []
            for i, (base, old) in enumerate(self._baseline.items()):
                new = self._read_region(base, len(old))
                region_cands = self._diff_region(base, old, new, kind, direction, magnitude)
                new_cands.extend(region_cands)
                prog.regions_done = i + 1
                prog.candidates = len(new_cands)
                prog.elapsed = time.time() - t0
                if progress_cb:
                    progress_cb(prog)
            self.candidates = new_cands
        else:
            # Фильтр существующих кандидатов: перечитываем и проверяем направление.
            kept: list[Candidate] = []
            for c in self.candidates:
                cur = self._read_value(c.address, c.type_name)
                if cur is None:
                    continue
                if self._matches_direction(c.current, cur, direction, kind, magnitude):
                    delta = self._signed_delta(c.current, cur, direction)
                    c.baseline = c.current  # сдвигаем окно
                    c.current = cur
                    c.delta = delta
                    kept.append(c)
            self.candidates = kept
            prog.regions_done = len(self._baseline)
            prog.candidates = len(self.candidates)

        self._action_count += 1
        self._last_kind = kind
        self.classify(kind=kind)
        prog.candidates = len(self.candidates)
        prog.elapsed = time.time() - t0
        if progress_cb:
            progress_cb(prog)

    # ------------------------------------------------------------------
    # Внутренние: чтение и дифф
    # ------------------------------------------------------------------

    def _read_region(self, base: int, size: int) -> bytes:
        if not _HAS_NUMPY:
            # pure-python fallback — просто читаем целиком.
            off = 0
            out = bytearray()
            while off < size:
                sz = min(16 * 1024 * 1024, size - off)
                out += self.proc.read(base + off, sz)
                off += sz
            return bytes(out)
        off = 0
        out = bytearray()
        while off < size:
            sz = min(16 * 1024 * 1024, size - off)
            out += self.proc.read(base + off, sz)
            off += sz
        return bytes(out)

    def _diff_region(self, base: int, old: bytes, new: bytes,
                     kind: str | None, direction: str,
                     magnitude: float | None) -> list[Candidate]:
        """Векторизованный дифф одного региона. Возвращает кандидатов.

        Подход Cheat Engine:
        • один адрес = один тип. Сначала int32; float32 берём только для слотов,
          где int32 неправдоподобен, но float «чистый» (не денормаль, разумная
          величина). Так не плодятся мусорные float-интерпретации тех же байт
          (те самые «плавающие цифры без запятой»).
        • float-фильтр: |v| в [1e-4, 1e10] и не NaN/inf — убивает 1.4e-34, 6e23 и т.п.
        • для произвольного (custom) поиска сканируем только 4-байтные типы —
          этого хватает для ~99% игровых статов и сильно меньше шума/работы.
          8-байтные (int64/float64) — только для ресурсов, где они типичны.
        • «unchanged» на первом диффе бессмысленно (почти вся память) — пропускаем.
        """
        if not _HAS_NUMPY:
            return self._diff_region_pure(base, old, new, kind, direction, magnitude)
        if direction == "unchanged":
            return []

        sig = SIGNATURES.get(kind) if kind else None
        vrange = sig.value_range if sig else (0, 1_000_000_000)
        drange = sig.delta_range if sig else (1, 1_000_000_000)
        n = min(len(old), len(new))
        out: list[Candidate] = []

        # --- 4-байтные: int32, затем float32 (без дублей с int) ---
        n4 = (n // 4) * 4
        if n4 >= 4:
            oi = np.frombuffer(old, dtype="<i4", count=n4 // 4)
            ni = np.frombuffer(new, dtype="<i4", count=n4 // 4)
            int_mask = self._direction_mask(oi, ni, vrange, drange, direction, magnitude, is_float=False)
            out += self._candidates_from_mask(base, oi, ni, "int32", int_mask)
            of = np.frombuffer(old, dtype="<f4", count=n4 // 4)
            nf = np.frombuffer(new, dtype="<f4", count=n4 // 4)
            flt_mask = self._direction_mask(of, nf, vrange, drange, direction, magnitude, is_float=True)
            flt_mask &= ~int_mask  # не дублируем слоты, уже отданные как int32
            out += self._candidates_from_mask(base, of, nf, "float32", flt_mask)

        # --- 8-байтные: только для ресурсов с типичными int64/float64 (золото/опыт) ---
        n8 = (n // 8) * 8
        if n8 >= 8 and sig is not None and any(t in ("int64", "uint64", "float64") for t in sig.preferred_types):
            oi64 = np.frombuffer(old, dtype="<i8", count=n8 // 8)
            ni64 = np.frombuffer(new, dtype="<i8", count=n8 // 8)
            i64_mask = self._direction_mask(oi64, ni64, vrange, drange, direction, magnitude, is_float=False)
            out += self._candidates_from_mask(base, oi64, ni64, "int64", i64_mask)
            of64 = np.frombuffer(old, dtype="<f8", count=n8 // 8)
            nf64 = np.frombuffer(new, dtype="<f8", count=n8 // 8)
            f64_mask = self._direction_mask(of64, nf64, vrange, drange, direction, magnitude, is_float=True)
            f64_mask &= ~i64_mask
            out += self._candidates_from_mask(base, of64, nf64, "float64", f64_mask)
        return out

    def _direction_mask(self, old, new, vrange, drange, direction, magnitude, is_float):
        """Булева маска слотов, подошедших под направление + фильтры величины."""
        itemsize = old.dtype.itemsize
        if is_float:
            finite = np.isfinite(old) & np.isfinite(new)
            # «Чистый» float: не денормаль и разумная величина (1e-4 .. 1e10).
            flo = 1.175e-38 if itemsize == 4 else 2.225e-308   # min normal
            fhi = 1e10
            ao = np.abs(old); an = np.abs(new)
            clean = finite & (ao >= flo) & (ao <= fhi) & (an >= flo) & (an <= fhi)
        else:
            clean = np.ones(old.shape, dtype=bool)
        if direction == "decreased":
            dir_mask = (new < old) & clean
            d = (old - new).astype(np.float64)
        elif direction == "increased":
            dir_mask = (new > old) & clean
            d = (new - old).astype(np.float64)
        elif direction == "changed":
            dir_mask = (new != old) & clean
            d = np.abs(new.astype(np.float64) - old.astype(np.float64))
        else:  # unchanged — на первом диффе не используется (см. _diff_region)
            dir_mask = np.zeros(old.shape, dtype=bool)
            d = np.zeros(old.shape, dtype=np.float64)
        in_range = (
            (old.real >= vrange[0]) & (old.real <= vrange[1]) &
            (new.real >= vrange[0]) & (new.real <= vrange[1])
        )
        if magnitude is not None and magnitude > 0:
            lo = max(1, magnitude * 0.5)
            hi = magnitude * 2.0
            mag_ok = (d >= lo) & (d <= hi)
        else:
            mag_ok = (d >= drange[0]) & (d <= drange[1])
        return dir_mask & in_range & mag_ok

    def _candidates_from_mask(self, base, old, new, type_name, mask, cap=10000):
        item = old.dtype.itemsize
        is_float = "float" in type_name
        idxs = np.nonzero(mask)[0]
        if len(idxs) > cap:
            idxs = idxs[:cap]
        out: list[Candidate] = []
        for i in idxs:
            ov = float(old[i]); nv = float(new[i])
            if not is_float:
                ov = int(ov); nv = int(nv); dv = int(abs(ov - nv))
            else:
                dv = float(abs(ov - nv))
            out.append(Candidate(base + int(i) * item, type_name, ov, nv, dv))
        return out

    def _diff_region_pure(self, base, old, new, kind, direction, magnitude):
        """Медленный запасной путь без numpy (на случай её отсутствия)."""
        import struct
        if direction == "unchanged":
            return []
        sig = SIGNATURES.get(kind) if kind else None
        vrange = sig.value_range if sig else (0, 2_000_000_000)
        drange = sig.delta_range if sig else (1, 2_000_000_000)
        n = min(len(old), len(new))
        out = []
        for off in range(0, n - 3, 4):
            ov = struct.unpack_from("<i", old, off)[0]
            nv = struct.unpack_from("<i", new, off)[0]
            if ov == nv:
                continue
            if not (vrange[0] <= ov <= vrange[1] and vrange[0] <= nv <= vrange[1]):
                continue
            if direction == "decreased" and nv >= ov:
                continue
            if direction == "increased" and nv <= ov:
                continue
            d = abs(nv - ov)
            if magnitude and magnitude > 0:
                if not (magnitude * 0.5 <= d <= magnitude * 2):
                    continue
            elif not (drange[0] <= d <= drange[1]):
                continue
            out.append(Candidate(base + off, "int32", ov, nv, d))
            if len(out) > 20000:
                break
        return out

    # ------------------------------------------------------------------
    # Чтение одиночного значения (для фильтра кандидатов)
    # ------------------------------------------------------------------

    def _read_value(self, address: int, type_name: str):
        import struct
        fmts = {"int8": "<b", "uint8": "<B", "int16": "<h", "uint16": "<H",
                "int32": "<i", "uint32": "<I", "int64": "<q", "uint64": "<Q",
                "float32": "<f", "float64": "<d",
                "int16_be": ">h", "uint16_be": ">H", "int32_be": ">i",
                "uint32_be": ">I", "int64_be": ">q", "uint64_be": ">Q",
                "float32_be": ">f", "float64_be": ">d"}
        fmt = fmts.get(type_name)
        if fmt is None:
            return None
        sz = struct.calcsize(fmt)
        raw = self.proc.read(address, sz)
        if len(raw) != sz:
            return None
        try:
            return struct.unpack(fmt, raw)[0]
        except struct.error:
            return None

    def _matches_direction(self, old, cur, direction, kind, magnitude) -> bool:
        if old is None or cur is None:
            return False
        sig = SIGNATURES.get(kind) if kind else None
        vrange = sig.value_range if sig else (0, 2_000_000_000)
        if not (vrange[0] <= old <= vrange[1] and vrange[0] <= cur <= vrange[1]):
            return False
        if direction == "decreased":
            if cur >= old:
                return False
            d = old - cur
        elif direction == "increased":
            if cur <= old:
                return False
            d = cur - old
        elif direction == "unchanged":
            # Не изменилось с прошлого раза — узкий отсев тикающего шума
            # (таймеры/счётчики/RNG продолжают меняться и отсеиваются).
            return cur == old
        else:
            if cur == old:
                return False
            d = abs(cur - old)
        if magnitude and magnitude > 0:
            return magnitude * 0.5 <= d <= magnitude * 2
        drange = sig.delta_range if sig else (1, 2_000_000_000)
        return drange[0] <= d <= drange[1]

    def _signed_delta(self, old, cur, direction) -> float:
        if old is None or cur is None:
            return 0.0
        if direction == "decreased":
            return float(old - cur)
        if direction == "increased":
            return float(cur - old)
        return float(abs(cur - old))

    # ------------------------------------------------------------------
    # Классификация: проставить метку ресурса и confidence
    # ------------------------------------------------------------------

    def classify(self, kind: str | None = None):
        """Проставить каждому кандидату метку ресурса и confidence.
        kind — ресурс заявленного действия (если известен): даёт бонус +15
        совпадающей сигнатуре — пользователь сообщил намерение, это решающий
        сигнал среди структурно равных кандидатов (health/mana/ammo)."""
        use_kind = kind if kind is not None else self._last_kind
        for c in self.candidates:
            scores: dict[str, int] = {}
            for key, sig in SIGNATURES.items():
                scores[key] = self._score(c, sig, use_kind)
            # Лучший — максимальный score.
            best_key = max(scores, key=scores.get)
            best_score = scores[best_key]
            c.scores = scores
            # confidence = доля от теоретического максимума (~110, с kind-бонусом).
            c.best_label = SIGNATURES[best_key].label if best_score > 0 else "res_unknown"
            c.confidence = min(100, int(best_score * 100 / 110))
        # Сортируем: выше confidence — первыми.
        self.candidates.sort(key=lambda c: (-c.confidence, c.address))

    def _score(self, c: Candidate, sig: ResourceSignature, kind: str | None = None) -> int:
        s = 0
        # Диапазон значения (30 баллов).
        if sig.value_range[0] <= c.current <= sig.value_range[1]:
            s += 30
        # Предпочтительный тип (20).
        if c.type_name in sig.preferred_types:
            s += 20
        # Величина изменения в диапазоне (15).
        if sig.delta_range[0] <= c.delta <= sig.delta_range[1]:
            s += 15
        # Соседний паттерн: по смещению neighbor_offset лежит max-значение,
        # относящееся к текущему как ge (>=). Если сигнатура ожидает соседа,
        # а его нет — штраф -10: отличает gold/xp/level (без соседа) от
        # health/mana/ammo (с max-парой).
        if sig.neighbor_offset:
            neighbor = self._read_value(c.address + sig.neighbor_offset, "int32")
            if neighbor is not None and _relation_ok(neighbor, c.current, sig.neighbor_relation):
                s += 25
            else:
                # Попробуем как float32 (mana/health могут быть float).
                neighbor_f = self._read_value(c.address + sig.neighbor_offset, "float32")
                if neighbor_f is not None and _relation_ok(neighbor_f, c.current, sig.neighbor_relation):
                    s += 15
                else:
                    s -= 10  # ожидался max-сосед, но не подтверждён
        # Бонус за совпадение с заявленным действием (15).
        if kind is not None and kind == sig.name:
            s += 15
        # Бонус за "красивое" целое значение, не равное 0 (5).
        if isinstance(c.current, int) and c.current != 0:
            s += 5
        return s

    # ------------------------------------------------------------------
    # Публичные утилиты
    # ------------------------------------------------------------------

    def write_value(self, address: int, type_name: str, value) -> bool:
        import struct
        fmts = {"int8": "<b", "uint8": "<B", "int16": "<h", "uint16": "<H",
                "int32": "<i", "uint32": "<I", "int64": "<q", "uint64": "<Q",
                "float32": "<f", "float64": "<d"}
        fmt = fmts.get(type_name)
        if fmt is None:
            return False
        try:
            raw = struct.pack(fmt, value)
        except (struct.error, OverflowError):
            return False
        return self.proc.write(address, raw)

    def clear(self):
        self._baseline.clear()
        self.candidates.clear()
        self._has_baseline = False
        self._action_count = 0


def _relation_ok(neighbor, current, relation: str) -> bool:
    try:
        if relation == "ge":
            return neighbor >= current
        if relation == "le":
            return neighbor <= current
        if relation == "eq":
            return neighbor == current
    except TypeError:
        return False
    return False

                     args.thread.name if args.thread else "?", tb_str)

    sys.excepthook = _main_hook
    threading.excepthook = _thread_hook

"""
datatypes.py
Определения типов данных для многотипового сканера памяти.

Главная идея: пользователь вводит одно число (например 100), а сканер
одновременно ищет его как int8/16/32/64, uint*, float32/64 — в обоих
порядках байт (little-endian и big-endian). Это решает главную боль
Cheat Engine, где要先 выбрать тип данных, иначе "по умолчанию ничего не находит".
"""

import struct
from dataclasses import dataclass


@dataclass(frozen=True)
class DataType:
    name: str          # человекочитаемое имя, напр. "int32"
    fmt: str           # struct-формат с endian, напр. "<i"
    size: int          # размер в байтах
    is_float: bool     # True для float32/float64 (нужна толерантность при сравнении)

    def pack(self, value) -> bytes | None:
        """Упаковать значение в байты. None, если значение не влезает в тип."""
        try:
            return struct.pack(self.fmt, value)
        except (struct.error, OverflowError):
            return None

    def unpack(self, raw: bytes):
        """Распаковать байты в значение. None при ошибке длины."""
        if len(raw) != self.size:
            return None
        try:
            return struct.unpack(self.fmt, raw)[0]
        except struct.error:
            return None


# Полный набор типов. Для каждого целого — обе endian-варианта (LE и BE),
# потому что в редких играх/движках значения хранятся big-endian.
# signed/unsigned с одинаковым положительным значением дают одинаковые байты,
# но оба включены, чтобы декодирование в UI было корректным для диапазона.
TYPES: list[DataType] = [
    DataType("int8",       "<b", 1, False),
    DataType("uint8",      "<B", 1, False),
    DataType("int16",      "<h", 2, False),
    DataType("int16_be",   ">h", 2, False),
    DataType("uint16",     "<H", 2, False),
    DataType("uint16_be",  ">H", 2, False),
    DataType("int32",      "<i", 4, False),
    DataType("int32_be",   ">i", 4, False),
    DataType("uint32",     "<I", 4, False),
    DataType("uint32_be",  ">I", 4, False),
    DataType("int64",      "<q", 8, False),
    DataType("int64_be",   ">q", 8, False),
    DataType("uint64",     "<Q", 8, False),
    DataType("uint64_be",  ">Q", 8, False),
    DataType("float32",    "<f", 4, True),
    DataType("float32_be", ">f", 4, True),
    DataType("float64",    "<d", 8, True),
    DataType("float64_be", ">d", 8, True),
]

# Быстрый lookup по имени.
BY_NAME: dict[str, DataType] = {t.name: t for t in TYPES}

# Имена типов для UI по умолчанию (все включены).
DEFAULT_TYPE_NAMES: list[str] = [t.name for t in TYPES]

# Типы, которые разумно использовать для авто-поиска ресурсов (самые частые
# в реальных играх). Берём выровненные 4/8-байтные интерпретации.
AUTO_DETECT_TYPES: list[DataType] = [
    BY_NAME["int32"],
    BY_NAME["uint32"],
    BY_NAME["float32"],
    BY_NAME["int64"],
    BY_NAME["float64"],
]


def find_all(haystack: bytes, needle: bytes):
    """
    Генератор всех смещений needle в haystack.
    Использует bytes.find в цикле — быстрее регулярных выражений и
    byte-by-byte на CPython.
    """
    if not needle:
        return
    start = 0
    nlen = len(needle)
    while True:
        idx = haystack.find(needle, start)
        if idx == -1:
            return
        yield idx
        start = idx + 1  # +1, а не +nlen: ловим перекрытия (напр. AAAA в AAAAAA)


def values_equal(a, b, dtype: DataType, tolerance: float) -> bool:
    """Сравнение значений с учётом толерантности для float."""
    if dtype.is_float:
        if a is None or b is None:
            return False
        if tolerance > 0:
            return abs(a - b) <= tolerance
        # Без явной толерантности — точное совпадение бит (NaN-безопасно через unpack).
        return struct.pack(dtype.fmt, a) == struct.pack(dtype.fmt, b) \
            if _finite(a) and _finite(b) else (a == b)
    return a == b


def _finite(x) -> bool:
    try:
        import math
        return math.isfinite(x)
    except (TypeError, ValueError):
        return False

GAME_PATH_KEYWORDS = (
    "steam", "steamapps", "\\common\\", "epic", "epicgames", "gog", "galaxy",
    "ubisoft", "uplay", "origin", "\\ea games\\", "battle.net", "battlenet",
    "\\games\\", "\\game\\", "windowsapps", "xbox", "bethesda", "riot",
    "blizzard", "\\my games\\",
)


def _classify_proc(name: str, path: str) -> str:
    n = (name or "").lower()
    p = (path or "").lower()
    if p.startswith("c:\\windows") or n in SYSTEM_NAMES:
        return "system"
    if any(k in p for k in GAME_PATH_KEYWORDS):
        return "game"
    return "app"

HELPER_HINTS = (
    "overlay", "crash", "anticheat", "easyanticheat", "battleye", "redist",
    "setup", "unins", "bootstrap", "helper", "eosoverlay", "service",
    "webhelper", "steamerrorreport", "cef", "browser",
)


def _is_helper(name: str) -> bool:
    n = (name or "").lower()
    return any(h in n for h in HELPER_HINTS)

    def _refresh_processes(self):
        try:
            procs = list_processes_detailed()
        except Exception as e:
            _log.exception("list_processes_detailed() ошибся: %s", e)
            self.proc_combo["values"] = []
            self._set_status(tr("status_proc_list_err", e=e))
            return
        self._procs_raw = procs
        self._repopulate_combo()
        real_connected = self.proc is not None and not isinstance(self.proc, MockProcess)
        if not real_connected:
            self._auto_connect_top_game()

    def _repopulate_combo(self):
        procs = self._procs_raw
        classified = [(pid, name, path, _classify_proc(name, path)) for pid, name, path in procs]
        if not self._show_system:
            classified = [p for p in classified if p[3] != "system"]
        order = {"game": 0, "app": 1, "system": 2}
        # Игры идут первыми; среди игр — настоящие игры раньше вспомогательных
        # (оверлеи/анти-чит), потом по имени.
        classified.sort(key=lambda p: (order.get(p[3], 1),
                                       1 if (p[3] == "game" and _is_helper(p[1])) else 0,
                                       p[1].lower()))
        self._proc_list = classified
        items = []
        for pid, name, path, cls in classified:
            if cls == "game":
                mark = "🛠 " if _is_helper(name) else "🎮 "
            elif cls == "app":
                mark = "▫ "
            else:
                mark = "· "
            items.append(f"{mark}{name}  (pid {pid})")
        self.proc_combo["values"] = items
        n_games = sum(1 for p in classified if p[3] == "game" and not _is_helper(p[1]))
        n_helpers = sum(1 for p in classified if p[3] == "game" and _is_helper(p[1]))
        n_apps = sum(1 for p in classified if p[3] == "app")
        admin_txt = tr("admin_yes") if is_admin() else tr("admin_no")
        if items:
            self.proc_combo.current(0)
            self._set_status(tr("status_admin_games", admin=admin_txt, games=n_games,
                                helpers=n_helpers, apps=n_apps))
        else:
            self._set_status(tr("status_admin_no_procs", admin=admin_txt))

    def _auto_connect_top_game(self):
        # Сначала пробуем настоящую игру (не оверлей/анти-чит).
        games = [p for p in self._proc_list if p[3] == "game" and not _is_helper(p[1])]
        if not games:
            games = [p for p in self._proc_list if p[3] == "game"]
        if not games:
            return
        pid, name = games[0][0], games[0][1]
        for i, (pid2, name2, _, _) in enumerate(self._proc_list):
            if pid2 == pid and name2 == name:
                self.proc_combo.current(i)
                break
        _log.info("Авто-подключение к игре: pid=%s name=%s", pid, name)
        self._attach_selected()

    def _check_admin(self):
        if is_admin():
            self._set_pill(tr("pill_demo_admin"), C_GREEN)
        else:
            self._set_pill(tr("pill_demo_no_admin"), C_AMBER)

    def _attach_selected(self):
        if not IS_WINDOWS:
            messagebox.showinfo(tr("msg_demo_title"), tr("msg_demo_body"))
            self._attach_demo()
            return
        sel = self.proc_combo.get()
        if not sel:
            self._refresh_processes()
            sel = self.proc_combo.get()
            if not sel:
                return
        try:
            pid = int(sel.rsplit("(pid", 1)[1].strip(" )"))
        except Exception:
            messagebox.showerror(tr("msg_error"), tr("msg_pid_err"))
            return
        if pid <= 0:
            self._attach_demo()
            return
        _log.info("Попытка подключиться к pid=%s", pid)
        try:
            self.proc = open_process(pid)
        except OSError as e:
            _log.warning("OpenProcess не удался для pid=%s: %s", pid, e)
            messagebox.showerror(tr("msg_open_err_title"), tr("msg_open_err_body", e=e))
            return
        except Exception as e:
            _log.exception("Непредвиденная ошибка при открытии pid=%s: %s", pid, e)
            messagebox.showerror(tr("msg_open_err_title"), tr("msg_open_err_log", e=e))
            return
        _log.info("Подключён процесс pid=%s", pid)
        self.scanner = None
        self.detector = None
        self._mode = "exact"
        self._last_value = None
        name = sel.rsplit("(pid", 1)[0].strip().lstrip("🎮▫·🛠 ").strip()
        self._set_pill(tr("pill_connected", name=name), C_BLUE)
        self._set_status(tr("status_connected", pid=pid, name=name))

    def _run_bg(self, fn):
        if self._busy:
            messagebox.showinfo(tr("msg_busy_title"), tr("msg_busy_body"))
            return
        self._busy = True
        self._set_busy_ui(True)
        threading.Thread(target=_worker, args=(fn, self._job_queue), daemon=True).start()

    def _poll_queue(self):
        try:
            while True:
                kind, payload = self._job_queue.get_nowait()
                if kind == "progress":
                    self._on_progress(payload)
                elif kind == "done":
                    self._on_done(payload)
                elif kind == "error":
                    self._on_error(payload)
        except queue.Empty:
            pass
        self.root.after(100, self._poll_queue)

    def _on_progress(self, data: dict):
        if "msg" in data:
            self._set_status(data["msg"])
        if "matches" in data:
            cnt = data["matches"]
            if self._mode == "auto":
                self.scan_count_var.set(tr("matches_candidates", n=cnt))
            else:
                self.scan_count_var.set(tr("matches_found", n=cnt))
        # Движение полосы прогресса — только в детерминированном режиме
        # (во время отсева работает «бегущий» индикатор, полосу не трогаем).
        if not self._marquee and "regions_total" in data:
            total = data.get("regions_total", 0) or 1
            self.progress["maximum"] = total
            self.progress["value"] = data.get("regions_done", 0)

    def _marquee_on(self, text: str):
        self._marquee = True
        try:
            self.progress.config(mode="indeterminate")
            self.progress.start(12)
        except tk.TclError:
            pass
        self._set_status(text)

    def _marquee_off(self):
        try:
            self.progress.stop()
            self.progress.config(mode="determinate")
        except tk.TclError:
            pass
        self.progress["value"] = 0
        self._marquee = False

    def _on_done(self, payload):
        self._busy = False
        self._set_busy_ui(False)
        self._marquee_off()
        tag = payload[0] if isinstance(payload, tuple) else None
        if tag == "first_scan":
            self._mode = "exact"
            self._last_value = None
            self.scan_count_var.set(tr("matches_found", n=payload[1]))
            self._render_results()
            extra = tr("extra_baseline") if self.detector and self.detector.has_baseline else ""
            self._set_status(tr("status_first_done", n=payload[1], extra=extra))
        elif tag == "next_scan":

    def _do_first_scan(self):
        if not self.proc:
            messagebox.showinfo(tr("msg_no_proc_title"), tr("msg_no_proc_body"))
            return

            val = self._parse_value(self.value_var.get())
        except ValueError:
            messagebox.showerror(tr("msg_value_title"), tr("msg_value_body"))
            return

        self.frozen.clear()
        self._clear_tree(self.tree)
        self.scan_count_var.set(tr("scanning"))

        def job(on_progress):
            def cb(p: ScanProgress):
                on_progress({"regions_total": p.regions_total, "regions_done": p.regions_done,
                             "matches": p.matches,
                             "msg": tr("prog_first", done=p.regions_done, total=p.regions_total, matches=p.matches)})
            n = self.scanner.first_scan(val, progress_cb=cb)
            # Снимок всей памяти для авто-отсева (если точный даст 0).
            try:
                self._ensure_detector()
                self.detector.capture_baseline(
                    progress_cb=lambda p: on_progress({
                        "regions_total": p.regions_total, "regions_done": p.regions_done,
                        "msg": tr("prog_baseline", done=p.regions_done, total=p.regions_total)}))
            except Exception as e:
                _log.warning("baseline не собран (авто-отсев будет недоступен): %s", e)
            self._first_value = val
            return ("first_scan", n)
        self._run_bg(job)

    def _do_next_scan(self):
        if self._mode == "exact":
            if not self.scanner or not self.scanner.matches:
                messagebox.showinfo(tr("msg_no_data_title"), tr("msg_no_data_body"))
                return
            try:
                val = self._parse_value(self.value_var.get())
            except ValueError:
                messagebox.showerror(tr("msg_value_title"), tr("msg_new_value_body"))
                return
        else:  # auto — поле значения задаёт тип отсева:
            #   пусто  → «значение НЕ изменилось» (отсев тикающего шума, как в Cheat Engine)
            #   число  → направленный отсев (упало/выросло к этому значению) + ранжирование
            raw = self.value_var.get().strip()
            if not raw:
                val = None
            else:
                try:
                    val = self._parse_value(raw)
                except ValueError:
                    val = None

        # Чёткая индикация: «бегущий» индикатор + статус.
        if self._mode == "auto":
            if val is None:
                self._marquee_on(tr("prog_narrow_noise"))
            else:
                self._marquee_on(tr("prog_narrow_directed"))
        else:
            self._marquee_on(tr("prog_narrow_exact"))

        def job(on_progress):
            def cb(p):
                # AutoProgress (apply_action) несёт регионы и кандидатов;
                # ScanProgress (next_scan) — регионы и совпадения.
                rt = getattr(p, "regions_total", 0)
                rd = getattr(p, "regions_done", 0)
                cnt = getattr(p, "candidates", None)
                if cnt is None:
                    cnt = getattr(p, "matches", 0)
                if rt:
                    msg = tr("prog_narrow_cmp", done=rd, total=rt, cnt=cnt)
                else:
                    msg = tr("prog_narrow_short", cnt=cnt)
                on_progress({"matches": cnt, "msg": msg})
            if self._mode == "auto":
                if val is None:
                    # Узкий отсев: оставить только НЕ изменившиеся с прошлого раза.
                    self.detector.apply_action("custom_unchanged", progress_cb=cb)
                    return ("auto_fallback", len(self.detector.candidates), "unchanged")
                # Направленный отсев к введённому значению (в ~2× избирательнее «changed»).
                rank_old = self._last_value if self._last_value is not None else self._first_value
                rank_new = val
                direction = ("custom_dec" if (rank_old is not None and val < rank_old) else
                             "custom_inc" if (rank_old is not None and val > rank_old) else "custom_chg")
                _log.info("Отсев(auto): направление=%s (new=%r old=%r)", direction, val, rank_old)
                self.detector.apply_action(direction, progress_cb=cb)
                self._last_value = val
                self._rank_candidates(rank_old, rank_new)
                return ("auto_fallback", len(self.detector.candidates), "directed")
            n = self.scanner.next_scan(MODE_EXACT, value=val, float_tol=0.0, progress_cb=cb)
            if n > 0:
                return ("next_scan", n)
            # FALLBACK: точных нет → ищем изменившиеся адреса.
            if self.detector and self.detector.has_baseline:
                fv = self._first_value
                direction = "custom_dec" if (fv is not None and val < fv) else (
                    "custom_inc" if (fv is not None and val > fv) else "custom_chg")
                _log.info("Отсев: точных 0 → авто-fallback направление=%s (new=%r old=%r)", direction, val, fv)
                on_progress({"msg": tr("prog_narrow_fallback")})
                self.detector.apply_action(direction, progress_cb=cb)
                self._last_value = val
                self._rank_candidates(fv, val)
                return ("auto_fallback", len(self.detector.candidates), "directed")
            return ("next_scan", 0)
        self._run_bg(job)

    def _rank_candidates(self, old_target, new_target):
        """Отсортировать авто-кандидатов по похожести на изменение значения пользователя.

        У настоящего ресурса old→new повторяет введённое (770→387). Отношение
        old/new масштабно-инвариантно: работает и для int, и для float с дробью,
        и для масштабированного хранения (×k). Шум такого отношения почти не имеет.
        Наверх таблицы всплывают самые вероятные адреса."""
        cs = self.detector.candidates if self.detector else []
        if not cs or old_target is None or new_target is None:
            return
        try:
            nt = float(new_target)
            ot = float(old_target)
            if nt <= 0 or ot <= 0:
                return
            log_tr = math.log(ot / nt)
        except (TypeError, ValueError, ZeroDivisionError):
            return
        def score(c):
            o, n = c.baseline, c.current
            try:
                of, nf = float(o), float(n)
            except (TypeError, ValueError):
                return (3, 9e9)
            # Правдоподобие величины: положительные, не указатели/не гигантские.
            plausible = (0 < of < 1e8 and 0 < nf < 1e8)
            if not plausible or nf <= 0 or of <= 0:
                return (2, 9e9)
            # Расстояние по логарифму отношения (масштабно-инвариантно).
            try:
                dr = abs(math.log(of / nf) - log_tr)
            except (ValueError, ZeroDivisionError):
                dr = 9e9
            return (0, dr)
        try:
            cs.sort(key=score)
        except Exception:
            _log.exception("Ранжирование кандидатов не удалось.")

def _worker(fn, q):
    try:
        result = fn(on_progress=lambda d: q.put(("progress", d)))
        q.put(("done", result))
    except Exception as e:
        q.put(("error", repr(e)))


def _fmt(v) -> str:
    if v is None:
        return "—"
    if isinstance(v, float):
        if v == int(v) and abs(v) < 1e15:
            return f"{int(v)}"
        return f"{v:.4g}"
    return str(v)

_current: str | None = None


def detect_lang() -> str:
    """Определить язык: сохранённый выбор → системная локаль → 'en'."""
    global _current
    if _current is not None:
        return _current
    s = _load_saved()
    if s and s in _T:
        _current = s
        return s
    loc = ""
    try:
        loc = (_locale.getdefaultlocale()[0] or "").lower()
    except Exception:
        loc = ""
    if not loc:
        loc = (os.environ.get("LANG", "") or "").lower()
    loc = loc.replace("-", "_")
    for code in LANG_CODES:
        if loc.startswith(code):
            _current = code
            return code
    _current = "en"
    return "en"


def _load_saved() -> str | None:
    try:
        if _LANG_FILE.exists():
            v = _LANG_FILE.read_text(encoding="utf-8").strip().lower()
            return v if v in _T else None
    except Exception:
        return None
    return None


def save_lang(code: str) -> None:
    try:
        _LANG_FILE.write_text(code, encoding="utf-8")
    except Exception:
        pass


def set_lang(code: str) -> None:
    global _current
    _current = code if code in _T else "en"
    save_lang(_current)


def current_lang() -> str:
    if _current is None:
        detect_lang()
    return _current or "en"


def tr(key: str, **kw) -> str:
    """Перевести ключ. Fallback: текущий → en → сам ключ."""
    code = current_lang()
    tbl = _T.get(code, _T["en"])
    s = tbl.get(key)
    if s is None:
        s = _T["en"].get(key, key)
    if kw:
        try:
            return s.format(**kw)
        except Exception:
            return s
    return s

"""

def is_admin() -> bool:

    if not IS_WINDOWS:

    try:
        return bool(ctypes.windll.shell32.IsUserAnAdmin())

        return False

    size: int          # размер в байтах
    protect: int       # текущая защита (PAGE_*)
    state: int         # MEM_COMMIT / MEM_FREE / MEM_RESERVE
    mtype: int         # MEM_IMAGE / MEM_MAPPED / MEM_PRIVATE

    @property
    def readable(self) -> bool:
        """Можно ли читать. Игнорируем GUARD-страницы (читать нельзя)."""
        if self.state != MEM_COMMIT:
            return False
        if self.protect & PAGE_GUARD:
            return False
        return self.protect in (
            PAGE_READONLY, PAGE_READWRITE, PAGE_WRITECOPY,
            PAGE_EXECUTE_READ, PAGE_EXECUTE_READWRITE, PAGE_EXECUTE_WRITECOPY,
        )

    @property
    def writable(self) -> bool:
        if self.state != MEM_COMMIT:
            return False
        return self.protect in (PAGE_READWRITE, PAGE_WRITECOPY,
                                PAGE_EXECUTE_READWRITE, PAGE_EXECUTE_WRITECOPY)

    @property
    def is_data(self) -> bool:
        """
        Пригодно для поиска игровых значений: приватная (куча) или
        отображённая RW память, но НЕ исполняемый код (MEM_IMAGE с EXECUTE).
        Код сканировать бессмысленно — там инструкции, не данные; это
        ускоряет скан в десятки раз и убирает шум.
        """
        if not self.readable:
            return False
        if self.protect & PAGE_GUARD:
            return False
        # Исполняемые регионы пропускаем.
        if self.protect in (PAGE_EXECUTE, PAGE_EXECUTE_READ,
                            PAGE_EXECUTE_READWRITE, PAGE_EXECUTE_WRITECOPY):
            return False
        # MEM_IMAGE = загруженная DLL/exe (код + .rdata); данные игры
        # почти всегда в MEM_PRIVATE (куча) или MEM_MAPPED (файлы сохранений).
        return self.mtype in (MEM_PRIVATE, MEM_MAPPED, 0)

# Права доступа к процессу: чтение + запись + запрос информации + операция
# (нужна для VirtualProtectEx при записи в read-only регионы).
PROCESS_ACCESS = (0x0400   # PROCESS_QUERY_INFORMATION
                  | 0x1000  # PROCESS_QUERY_LIMITED_INFORMATION
                  | 0x0010  # PROCESS_VM_READ
                  | 0x0020  # PROCESS_VM_WRITE
                  | 0x0008)  # PROCESS_VM_OPERATION


if IS_WINDOWS:
    k32 = ctypes.WinDLL("kernel32", use_last_error=True)

    # MEMORY_BASIC_INFORMATION имеет разный размер на x86/x64; на x64
    # добавлено поле PartitionId. Делаем архитектурно-зависимое определение.
    if ctypes.sizeof(ctypes.c_void_p) == 8:
        class MEMORY_BASIC_INFORMATION(ctypes.Structure):
            _fields_ = [
                ("BaseAddress", ctypes.c_void_p),
                ("AllocationBase", ctypes.c_void_p),
                ("AllocationProtect", wintypes.DWORD),
                ("PartitionId", wintypes.WORD),
                ("RegionSize", ctypes.c_size_t),
                ("State", wintypes.DWORD),
                ("Protect", wintypes.DWORD),
                ("Type", wintypes.DWORD),
            ]
    else:
        class MEMORY_BASIC_INFORMATION(ctypes.Structure):
            _fields_ = [
                ("BaseAddress", ctypes.c_void_p),
                ("AllocationBase", ctypes.c_void_p),
                ("AllocationProtect", wintypes.DWORD),
                ("RegionSize", ctypes.c_size_t),
                ("State", wintypes.DWORD),
                ("Protect", wintypes.DWORD),
                ("Type", wintypes.DWORD),
            ]

    TH32CS_SNAPPROCESS = 0x00000002

    class PROCESSENTRY32W(ctypes.Structure):
        _fields_ = [
            ("dwSize", wintypes.DWORD),
            ("cntUsage", wintypes.DWORD),
            ("th32ProcessID", wintypes.DWORD),
            ("th32DefaultHeapID", ctypes.c_void_p),
            ("th32ModuleID", wintypes.DWORD),
            ("cntThreads", wintypes.DWORD),
            ("th32ParentProcessID", wintypes.DWORD),
            ("pcPriClassBase", ctypes.c_long),
            ("dwFlags", wintypes.DWORD),
            ("szExeFile", ctypes.c_wchar * 260),
        ]

    def _list_processes_toolhelp() -> list[tuple[int, str]]:
        """Перечисление процессов через ToolHelp32 (CreateToolhelp32Snapshot)."""
        k32.CreateToolhelp32Snapshot.restype = wintypes.HANDLE
        k32.CreateToolhelp32Snapshot.argtypes = [wintypes.DWORD, wintypes.DWORD]
        k32.Process32FirstW.argtypes = [wintypes.HANDLE, ctypes.POINTER(PROCESSENTRY32W)]
        k32.Process32FirstW.restype = wintypes.BOOL
        k32.Process32NextW.argtypes = [wintypes.HANDLE, ctypes.POINTER(PROCESSENTRY32W)]
        k32.Process32NextW.restype = wintypes.BOOL

        snap = k32.CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0)
        # CreateToolhelp32Snapshot при ошибке возвращает INVALID_HANDLE_VALUE
        # (-1), а не NULL. c_void_p (HANDLE) отдаёт беззнаковое значение,
        # поэтому сравниваем с 2^(битwidth)-1, а не только с 0/None.
        INVALID_HANDLE = (1 << (8 * ctypes.sizeof(ctypes.c_void_p))) - 1
        if not snap or int(snap) == INVALID_HANDLE:
            err = ctypes.get_last_error()
            _log.warning("Toolhelp: CreateToolhelp32Snapshot не удался (err=%s)", err)
            return []
        out: list[tuple[int, str]] = []
        pe = PROCESSENTRY32W()
        pe.dwSize = ctypes.sizeof(PROCESSENTRY32W)
        try:
            if k32.Process32FirstW(snap, ctypes.byref(pe)):
                while True:
                    out.append((int(pe.th32ProcessID), pe.szExeFile))
                    if not k32.Process32NextW(snap, ctypes.byref(pe)):
                        break
        finally:
            k32.CloseHandle(snap)
        out.sort(key=lambda x: x[1].lower())
        _log.info("Toolhelp: найдено процессов: %d", len(out))
        return out

    def _list_processes_psapi() -> list[tuple[int, str]]:
        """Запасной метод: EnumProcesses (Psapi) + QueryFullProcessImageNameW.
        Работает, если ToolHelp32 по какой-то причине вернул пусто. Имена
        получаем через QueryFullProcessImageNameW с правами
        PROCESS_QUERY_LIMITED_INFORMATION (доступно без админа для большинства
        процессов)."""
        try:
            psapi = ctypes.WinDLL("psapi.dll", use_last_error=True)
        except OSError as e:
            _log.warning("Psapi: не удалось загрузить psapi.dll: %s", e)
            return []
        k32.OpenProcess.restype = wintypes.HANDLE
        k32.OpenProcess.argtypes = [wintypes.DWORD, wintypes.BOOL, wintypes.DWORD]

        psapi.EnumProcesses.restype = wintypes.BOOL
        psapi.EnumProcesses.argtypes = [ctypes.POINTER(wintypes.DWORD),
                                        wintypes.DWORD,
                                        ctypes.POINTER(wintypes.DWORD)]
        arr = (wintypes.DWORD * 2048)()
        needed = wintypes.DWORD(0)
        if not psapi.EnumProcesses(arr, ctypes.sizeof(arr), ctypes.byref(needed)):
            _log.warning("Psapi: EnumProcesses не удался (err=%s)", ctypes.get_last_error())
            return []
        count = needed.value // ctypes.sizeof(wintypes.DWORD)
        _log.info("Psapi: EnumProcesses вернул %d pid", count)

        # QueryFullProcessImageNameW(handle, flags=0, buf, &size)
        psapi.QueryFullProcessImageNameW.restype = wintypes.BOOL
        psapi.QueryFullProcessImageNameW.argtypes = [wintypes.HANDLE, wintypes.DWORD,
                                                     ctypes.c_wchar_p,
                                                     ctypes.POINTER(wintypes.DWORD)]
        PROCESS_QUERY_LIMITED = 0x1000
        out: list[tuple[int, str]] = []
        buf = ctypes.create_unicode_buffer(260)
        for i in range(count):
            pid = int(arr[i])
            if pid == 0:
                continue
            h = k32.OpenProcess(PROCESS_QUERY_LIMITED, False, pid)
            if not h:
                # Не удалось открыть — покажем хотя бы pid, чтобы пользователь
                # мог опознать игру по номеру в диспетчере задач.
                out.append((pid, f"<pid {pid}>"))
                continue
            try:
                size = wintypes.DWORD(260)
                if psapi.QueryFullProcessImageNameW(h, 0, buf, ctypes.byref(size)):
                    name = buf.value.rsplit("\\", 1)[-1]
                    out.append((pid, name))
                else:
                    out.append((pid, f"<pid {pid}>"))
            finally:
                k32.CloseHandle(h)
        out.sort(key=lambda x: x[1].lower())
        _log.info("Psapi: собрано процессов с именами: %d", len(out))
        return out

    def list_processes() -> list[tuple[int, str]]:
        """Вернуть [(pid, имя_exe), ...], отсортировано по имени.
        Сначала ToolHelp32, при пустом результате — запасной Psapi."""
        out = _list_processes_toolhelp()
        if out:
            return out
        _log.warning("Toolhelp дал пусто — пробуем запасной метод Psapi")
        out = _list_processes_psapi()
        if out:
            return out
        _log.error("Оба метода перечисления процессов вернули пустой список. "
                   "Возможно, программа запущена без прав администратора в "
                   "ограниченной среде.")
        return []

    def list_processes_detailed() -> list[tuple[int, str, str]]:
        """[(pid, имя_exe, полный_путь)] — для классификации игр по пути.
        Перечисляет pid через list_processes(), путь берёт через
        QueryFullProcessImageNameW. Эта функция на Vista+ экспортируется
        kernel32.dll (не psapi!); на старых сборках — K32QueryFullProcessImageNameW
        в psapi. Если путь получить не удалось — пустая строка (классификация
        тогда по имени). Один сбой пути на pid НЕ валит весь список."""
        base = list_processes()
        # QueryFullProcessImageNameW живёт в kernel32 на современных Windows.
        try:
            kdll = ctypes.WinDLL("kernel32", use_last_error=True)
        except OSError:
            return [(pid, name, "") for pid, name in base]
        qfn = getattr(kdll, "QueryFullProcessImageNameW", None)
        if qfn is None:
            # Запасной вариант: K32-префикс в psapi (старые SDK).
            try:
                p2 = ctypes.WinDLL("psapi.dll", use_last_error=True)
                qfn = getattr(p2, "K32QueryFullProcessImageNameW", None)
            except OSError:
                qfn = None
        if qfn is None:
            # Пути недоступны — вернём список без путей (фильтр игр по имени).
            return [(pid, name, "") for pid, name in base]
        qfn.restype = wintypes.BOOL
        qfn.argtypes = [wintypes.HANDLE, wintypes.DWORD, ctypes.c_wchar_p,
                        ctypes.POINTER(wintypes.DWORD)]
        kdll.OpenProcess.restype = wintypes.HANDLE
        kdll.OpenProcess.argtypes = [wintypes.DWORD, wintypes.BOOL, wintypes.DWORD]
        PROCESS_QUERY_LIMITED = 0x1000
        buf = ctypes.create_unicode_buffer(1024)
        out: list[tuple[int, str, str]] = []
        for pid, name in base:
            path = ""
            if pid > 0:
                try:
                    h = kdll.OpenProcess(PROCESS_QUERY_LIMITED, False, pid)
                except OSError:
                    h = 0
                if h:
                    try:
                        size = wintypes.DWORD(1024)
                        if qfn(h, 0, buf, ctypes.byref(size)):
                            path = buf.value
                    finally:
                        kdll.CloseHandle(h)
            out.append((pid, name, path))
        return out

else:
    def list_processes() -> list[tuple[int, str]]:
        """На не-Windows возвращаем только demo-процесс."""
        return [(-1, "DemoGame.exe (учебный режим)")]

    def list_processes_detailed() -> list[tuple[int, str, str]]:
        """На не-Windows возвращаем только demo-процесс."""
        return [(-1, "DemoGame.exe (учебный режим)", "")]

class WindowsProcess:
    """Реальный доступ к памяти процесса через WinAPI."""

    def __init__(self, pid: int):
        if not IS_WINDOWS:
            raise RuntimeError("WindowsProcess можно использовать только на Windows.")
        k32.OpenProcess.restype = wintypes.HANDLE
        k32.OpenProcess.argtypes = [wintypes.DWORD, wintypes.BOOL, wintypes.DWORD]
        self.handle = k32.OpenProcess(PROCESS_ACCESS, False, pid)
        if not self.handle:
            err = ctypes.get_last_error()
            raise OSError(f"OpenProcess failed (pid={pid}). Код ошибки Win32: {err}. "
                          f"Запустите программу от имени администратора.")
        self.pid = pid

    def close(self):
        if getattr(self, "handle", None):
            k32.CloseHandle(self.handle)
            self.handle = None

    def __del__(self):
        try:
            self.close()
        except Exception:
            pass

    def iter_regions(self, data_only: bool = True) -> Iterator[Region]:
        """Перебор регионов виртуальной памяти. data_only=True — только данные."""
        k32.VirtualQueryEx.argtypes = [wintypes.HANDLE, ctypes.c_void_p,
                                       ctypes.POINTER(MEMORY_BASIC_INFORMATION), ctypes.c_size_t]
        k32.VirtualQueryEx.restype = ctypes.c_size_t
        mbi = MEMORY_BASIC_INFORMATION()
        addr = 0
        max_addr = 0x7FFFFFFFFFFF if ctypes.sizeof(ctypes.c_void_p) == 8 else 0xFFFFFFFF
        while addr < max_addr:
            ret = k32.VirtualQueryEx(self.handle, ctypes.c_void_p(addr),
                                     ctypes.byref(mbi), ctypes.sizeof(mbi))
            if ret == 0:
                break
            region = Region(int(mbi.BaseAddress or 0), int(mbi.RegionSize),
                            int(mbi.Protect), int(mbi.State), int(mbi.Type))
            if (not data_only) or region.is_data:
                yield region
            # Следующий регион сразу за текущим.
            next_addr = int(mbi.BaseAddress or 0) + int(mbi.RegionSize)
            if next_addr <= addr:
                break  # защита от зацикливания
            addr = next_addr

    def read(self, address: int, size: int) -> bytes:
        """Прочитать size байт по адресу. Возвращает bytes (пусто при ошибке)."""
        k32.ReadProcessMemory.argtypes = [wintypes.HANDLE, ctypes.c_void_p,
                                          ctypes.c_void_p, ctypes.c_size_t,
                                          ctypes.POINTER(ctypes.c_size_t)]
        k32.ReadProcessMemory.restype = wintypes.BOOL
        buf = (ctypes.c_char * size)()
        read = ctypes.c_size_t(0)
        ok = k32.ReadProcessMemory(self.handle, ctypes.c_void_p(address),
                                   buf, size, ctypes.byref(read))
        if not ok:
            return b""
        return bytes(buf[:read.value])

    def write(self, address: int, data: bytes) -> bool:
        """Записать data по адресу. При необходимости снимает защиту через
        VirtualProtectEx и возвращает её обратно."""
        k32.WriteProcessMemory.argtypes = [wintypes.HANDLE, ctypes.c_void_p,
                                           ctypes.c_void_p, ctypes.c_size_t,
                                           ctypes.POINTER(ctypes.c_size_t)]
        k32.WriteProcessMemory.restype = wintypes.BOOL
        k32.VirtualProtectEx.argtypes = [wintypes.HANDLE, ctypes.c_void_p, ctypes.c_size_t,
                                         wintypes.DWORD, ctypes.POINTER(wintypes.DWORD)]
        k32.VirtualProtectEx.restype = wintypes.BOOL
        size = len(data)
        if size == 0:
            return True
        buf = (ctypes.c_char * size).from_buffer_copy(data)
        old = wintypes.DWORD(0)
        # Пытаемся сделать страницу RW на время записи.
        protected = k32.VirtualProtectEx(self.handle, ctypes.c_void_p(address),
                                         size, PAGE_READWRITE, ctypes.byref(old))
        written = ctypes.c_size_t(0)
        ok = k32.WriteProcessMemory(self.handle, ctypes.c_void_p(address),
                                    buf, size, ctypes.byref(written))
        if protected:
            # Возвращаем исходную защиту.
            tmp = wintypes.DWORD(0)
            k32.VirtualProtectEx(self.handle, ctypes.c_void_p(address),
                                 size, old.value, ctypes.byref(tmp))
        return bool(ok and written.value == size)

# Mock Process (demo/тест/UI-предпросмотр) — работает на любой ОС

import struct
import random


class MockProcess:
    """
    Фейковый процесс с предсказуемой игровой памятью. Нужен, чтобы:
      1. Тестировать сканер и авто-поиск без реальной игры (здесь, на Linux).
      2. Дать пользователю prewiew UI до запуска программы в бою.
      3. Служить учебным материалом.

    Карта памяти (все RW, MEM_PRIVATE, выровнено):
      0x00100000: player struct
        +0x00  health   int32   = 100
        +0x04  max_hp   int32   = 100
        +0x08  mana     float32 = 50.0
        +0x0C  level    int32   = 1
      0x00101000: inventory
        +0x00  gold     int32   = 5000
        +0x04  ammo     int32   = 30
        +0x08  max_ammo int32   = 30
      0x00200000: "куча шума" — массив случайных меняющихся значений,
                   чтобы авто-поиск имел реалистичный фон для фильтрации.
    """

    PLAYER_BASE = 0x00100000
    PLAYER_SIZE = 0x1000
    INV_BASE = 0x00101000
    INV_SIZE = 0x1000
    NOISE_BASE = 0x00200000
    NOISE_SIZE = 0x10000  # 64 КБ шума

    def __init__(self):
        self.pid = -1
        self._mem: dict[int, bytearray] = {}
        self._regions: list[Region] = []
        self._noise_rng = random.Random(12345)
        self._reset()

    def _reset(self):
        # Три региона: игрок, инвентарь, шум.
        self._mem = {
            self.PLAYER_BASE: bytearray(self.PLAYER_SIZE),
            self.INV_BASE: bytearray(self.INV_SIZE),
            self.NOISE_BASE: bytearray(self.NOISE_SIZE),
        }
        self._regions = [
            Region(self.PLAYER_BASE, self.PLAYER_SIZE, PAGE_READWRITE, MEM_COMMIT, MEM_PRIVATE),
            Region(self.INV_BASE, self.INV_SIZE, PAGE_READWRITE, MEM_COMMIT, MEM_PRIVATE),
            Region(self.NOISE_BASE, self.NOISE_SIZE, PAGE_READWRITE, MEM_COMMIT, MEM_PRIVATE),
        ]
        p = self._mem[self.PLAYER_BASE]
        struct.pack_into("<i", p, 0x00, 100)     # health
        struct.pack_into("<i", p, 0x04, 100)     # max_hp
        struct.pack_into("<f", p, 0x08, 50.0)    # mana
        struct.pack_into("<i", p, 0x0C, 1)       # level
        iv = self._mem[self.INV_BASE]
        struct.pack_into("<i", iv, 0x00, 5000)   # gold
        struct.pack_into("<i", iv, 0x04, 30)     # ammo
        struct.pack_into("<i", iv, 0x08, 30)     # max_ammo
        self._refresh_noise()

    def _refresh_noise(self):
        """Заполнить шумовый регион случайными int32 (некоторые совпадут
        с искомыми значениями — реалистичный фон для сканера)."""
        n = self._mem[self.NOISE_BASE]
        for off in range(0, self.NOISE_SIZE - 4, 4):
            # Подкидываем значения, близкие к игровым, чтобы создать ложные
            # кандидаты — так авто-поиск имеет смысл фильтровать.
            pick = self._noise_rng.choice([
                self._noise_rng.randint(0, 10000),
                self._noise_rng.randint(0, 100),
                self._noise_rng.randint(0, 100000),
                int(self._noise_rng.uniform(0, 100)),  # иногда как float-биты
            ])
            struct.pack_into("<i", n, off, pick)

    # --- Симуляция игровых действий (для demo кнопок в UI) ---

    def simulate_damage(self, amount: int = 10):
        """Игрок получил урон: health -= amount."""
        p = self._mem[self.PLAYER_BASE]
        hp = struct.unpack_from("<i", p, 0x00)[0]
        hp = max(0, hp - amount)
        struct.pack_into("<i", p, 0x00, hp)

    def simulate_heal(self, amount: int = 10):
        p = self._mem[self.PLAYER_BASE]
        hp = struct.unpack_from("<i", p, 0x00)[0]
        max_hp = struct.unpack_from("<i", p, 0x04)[0]
        hp = min(max_hp, hp + amount)
        struct.pack_into("<i", p, 0x00, hp)

    def simulate_shoot(self, shots: int = 1):
        p = self._mem[self.INV_BASE]
        ammo = struct.unpack_from("<i", p, 0x04)[0]
        ammo = max(0, ammo - shots)
        struct.pack_into("<i", p, 0x04, ammo)

    def simulate_reload(self):
        p = self._mem[self.INV_BASE]
        max_a = struct.unpack_from("<i", p, 0x08)[0]
        struct.pack_into("<i", p, 0x04, max_a)

    def simulate_spend_gold(self, amount: int = 250):
        p = self._mem[self.INV_BASE]
        g = struct.unpack_from("<i", p, 0x00)[0]
        g = max(0, g - amount)
        struct.pack_into("<i", p, 0x00, g)

    def simulate_earn_gold(self, amount: int = 150):
        p = self._mem[self.INV_BASE]
        g = struct.unpack_from("<i", p, 0x00)[0]
        g += amount
        struct.pack_into("<i", p, 0x00, g)

    def simulate_tick(self):
        """Лёгкое дрожание шума — имитирует живой процесс (другие счётчики
        меняются, пока игрок стоит). Реальные игровые значения не трогаем."""
        n = self._mem[self.NOISE_BASE]
        # Меняем ~2% позиций шума.
        count = self.NOISE_SIZE // 4 // 50
        for _ in range(count):
            off = self._noise_rng.randrange(0, self.NOISE_SIZE - 4) & ~3
            val = self._noise_rng.randint(0, 10000)
            struct.pack_into("<i", n, off, val)

    # --- Интерфейс, совместимый с WindowsProcess ---

    def close(self):
        pass

    def iter_regions(self, data_only: bool = True) -> Iterator[Region]:
        for r in self._regions:
            if (not data_only) or r.is_data:
                yield r

    def read(self, address: int, size: int) -> bytes:
        for base, mem in self._mem.items():
            if base <= address < base + len(mem):
                off = address - base
                end = min(off + size, len(mem))
                return bytes(mem[off:end])
        return b""

    def write(self, address: int, data: bytes) -> bool:
        for base, mem in self._mem.items():
            if base <= address < base + len(mem):
                off = address - base
                end = min(off + len(data), len(mem))
                mem[off:end] = data[:end - off]
                return True
        return False

def open_process(pid: int):
    """
    Открыть процесс по pid. На Windows — WindowsProcess.
    pid == -1 (или не-Windows) — учебный MockProcess.
    """
    if pid == -1 or not IS_WINDOWS:
        return MockProcess()
    return WindowsProcess(pid)

`scanner.py`:

```py
"""
scanner.py
Мульти-тип сканер памяти — сердце программы.

Главная фишка (то, чего нет в базовом Cheat Engine "из коробки"):
пользователь вводит ОДНО число, а first_scan() одновременно ищет его как
int8/16/32/64, uint*, float32/64 — в little- и big-endian. Совпадения
приходят со всеми типами сразу, поэтому "по умолчанию ничего не находит"
больше не случается из-за неправильно угаданного типа.

next_scan() фильтрует уже найденные адреса по новому значению или по
характеру изменения (точное / изменилось / не изменилось / выросло / упало /
+дельта / -дельта), перечитывая память только в найденных точках.
"""

from __future__ import annotations
import time
import logging
from dataclasses import dataclass, field
from typing import Callable

from datatypes import TYPES, BY_NAME, DataType, find_all, values_equal
from process import Region

_log = logging.getLogger("gamecheat")

# Режимы next_scan. "scan_value" — требуется новое значение.
MODE_EXACT = "exact"                # равно значению
MODE_INCREASED = "increased"        # стало больше
MODE_DECREASED = "decreased"        # стало меньше
MODE_CHANGED = "changed"            # изменилось (любое)
MODE_UNCHANGED = "unchanged"        # не изменилось
MODE_INCREASED_BY = "increased_by"  # выросло ровно на delta
MODE_DECREASED_BY = "decreased_by"  # упало ровно на delta

MODES_NEED_VALUE = {MODE_EXACT, MODE_INCREASED_BY, MODE_DECREASED_BY}

# Читать регионы кусками не более 16 МБ, чтобы не плодить огромные buffers.
CHUNK = 16 * 1024 * 1024


@dataclass
class Match:
    address: int
    type_name: str
    value: float | int   # последнее известное значение (для отображения/сравнения)

    def __lt__(self, other):
        return (self.address, self.type_name) < (other.address, other.type_name)


@dataclass
class ScanProgress:
    regions_done: int = 0
    regions_total: int = 0
    bytes_done: int = 0
    bytes_total: int = 0
    matches: int = 0
    elapsed: float = 0.0


class Scanner:
    """Мульти-тип сканер по одному процессу."""

    def __init__(self, process, enabled_type_names: list[str] | None = None):
        self.proc = process
        names = enabled_type_names or [t.name for t in TYPES]
        # Сохраняем только валидные имена типов, в порядке TYPES.
        valid = {t.name for t in TYPES}
        self.enabled = [BY_NAME[n] for n in names if n in valid]
        if not self.enabled:
            self.enabled = list(TYPES)
        self.matches: list[Match] = []
        self._has_scan = False

    # ------------------------------------------------------------------
    # Утилиты
    # ------------------------------------------------------------------

    def _collect_regions(self) -> list[Region]:
        return [r for r in self.proc.iter_regions(data_only=True) if r.is_data]

    def _patterns_for_value(self, value) -> list[tuple[DataType, bytes]]:
        """Для значения вернуть [(dtype, bytes), ...] по всем включённым типам,
        где значение влезает в тип. Дубликаты байтов (напр. int32 LE == uint32 LE
        для положительных) оставляем — тип нужен для корректной интерпретации."""
        out = []
        for dt in self.enabled:
            raw = dt.pack(value)
            if raw is not None:
                out.append((dt, raw))
        return out

    # ------------------------------------------------------------------
    # Первый скан
    # ------------------------------------------------------------------

    def first_scan(self, value, progress_cb: Callable[[ScanProgress], None] | None = None,
                   float_tol: float = 0.0) -> int:
        """
        Найти value во всех читаемых data-регионах по всем включённым типам.

        Для float-типов с float_tol>0: ищем не точное совпадение битов, а
        ближайшее значение в пределах tol. Простейшая реализация — перебор
        int-представлений вокруг; для первого скана обычно хватает точного
        поиска, толерантность важнее на next_scan. Здесь float_tol используется
        только чтобы пропустить float-типы при tol==0? Нет — float всегда
        ищется точно по битам; tol применяется в next_scan.

        Возвращает количество найденных совпадений.
        """
        self.matches.clear()
        self._has_scan = True
        t0 = time.time()
        regions = self._collect_regions()
        total_bytes = sum(min(r.size, 1 << 30) for r in regions)  # ограничим прогресс
        prog = ScanProgress(regions_total=len(regions), bytes_total=total_bytes)
        patterns = self._patterns_for_value(value)
        _log.info("first_scan: значение=%r, включённых типов=%d, паттернов=%d (%s), регионов=%d, байт=%.1f МБ",
                  value, len(self.enabled), len(patterns),
                  ", ".join(dt.name for dt, _ in patterns), len(regions),
                  total_bytes / (1024 * 1024))
        if not patterns:
            if progress_cb:
                prog.elapsed = time.time() - t0
                progress_cb(prog)
            return 0

        for r in regions:
            region_base = r.base
            rsize = r.size
            off = 0
            while off < rsize:
                sz = min(CHUNK, rsize - off)
                data = self.proc.read(region_base + off, sz)
                if data:
                    for dt, raw in patterns:
                        plen = len(raw)
                        if plen > len(data):
                            continue
                        for idx in find_all(data, raw):
                            addr = region_base + off + idx
                            self.matches.append(Match(addr, dt.name, value))
                off += sz
                prog.bytes_done += sz
            prog.regions_done += 1
            prog.matches = len(self.matches)
            prog.elapsed = time.time() - t0
            if progress_cb:
                progress_cb(prog)
        prog.matches = len(self.matches)
        prog.elapsed = time.time() - t0
        if progress_cb:
            progress_cb(prog)
        _log.info("first_scan: ИТОГО совпадений=%d (%.2f с). Примеры: %s",
                  len(self.matches), prog.elapsed,
                  [(hex(m.address), m.type_name) for m in self.matches[:5]])
        return len(self.matches)

    # ------------------------------------------------------------------
    # Следующий скан (фильтрация)
    # ------------------------------------------------------------------

    def next_scan(self, mode: str, value=None, delta=None,
                  float_tol: float = 0.0,
                  progress_cb: Callable[[ScanProgress], None] | None = None) -> int:
        """
        Отфильтровать текущие совпадения по новому состоянию памяти.

        mode: один из MODE_*.
        value: новое значение (для MODE_EXACT).
        delta: величина изменения (для MODE_INCREASED_BY / DECREASED_BY).
        float_tol: допуска для float-сравнения (для MODE_EXACT).

        Возвращает новое число совпадений.
        """
        if not self._has_scan:
            raise RuntimeError("Сначала выполните первый скан.")
        t0 = time.time()
        _log.info("next_scan: режим=%s, значение=%r, delta=%r, tol=%s, входных совпадений=%d",
                  mode, value, delta, float_tol, len(self.matches))
        prog = ScanProgress(regions_total=1, bytes_total=len(self.matches))
        kept: list[Match] = []
        read_none = 0          # адресов, которые не удалось перечитать
        dropped_val = 0        # адресов, прочитанных, но не подошедших по условию
        dropped_samples: list = []   # несколько примеров отброшенных (для диагностики)
        for i, m in enumerate(self.matches):
            dt = BY_NAME[m.type_name]
            raw = self.proc.read(m.address, dt.size)
            cur = dt.unpack(raw) if raw else None
            keep = False
            if cur is None:
                # Память стала нечитаемой/освобождена — отбрасываем.
                keep = False
                read_none += 1
            elif mode == MODE_EXACT:
                keep = values_equal(cur, value, dt, float_tol)
            elif mode == MODE_CHANGED:
                keep = not values_equal(cur, m.value, dt, float_tol)
            elif mode == MODE_UNCHANGED:
                keep = values_equal(cur, m.value, dt, float_tol)
            elif mode == MODE_INCREASED:
                keep = _safe_gt(cur, m.value)
            elif mode == MODE_DECREASED:
                keep = _safe_lt(cur, m.value)
            elif mode == MODE_INCREASED_BY:
                keep = _safe_eq_delta(cur, m.value, delta, sign=+1, tol=float_tol)
            elif mode == MODE_DECREASED_BY:
                keep = _safe_eq_delta(cur, m.value, delta, sign=-1, tol=float_tol)
            else:
                raise ValueError(f"Неизвестный режим скана: {mode}")
            if keep:
                kept.append(Match(m.address, m.type_name, cur))
            elif cur is not None:
                dropped_val += 1
                if len(dropped_samples) < 5:
                    dropped_samples.append((hex(m.address), m.type_name,
                                            "было", m.value, "стало", cur))
            if progress_cb and (i % 2000 == 0):
                prog.regions_done = 0
                prog.bytes_done = i
                prog.matches = len(kept)
                prog.elapsed = time.time() - t0
                progress_cb(prog)
        self.matches = kept
        prog.matches = len(self.matches)
        prog.bytes_done = len(self.matches)
        prog.elapsed = time.time() - t0
        if progress_cb:
            progress_cb(prog)
        _log.info("next_scan: ИТОГО оставлено=%d из %d. Не перечитано(read=None)=%d, "
                  "отброшено по условию=%d. Примеры отброшенных: %s",
                  len(self.matches), len(self.matches) + read_none + dropped_val,
                  read_none, dropped_val, dropped_samples)
        return len(self.matches)

    # ------------------------------------------------------------------
    # Запись значения в адрес (для "заморозки" и редактирования)
    # ------------------------------------------------------------------

    def write_value(self, address: int, type_name: str, value) -> bool:
        dt = BY_NAME.get(type_name)
        if dt is None:
            return False
        raw = dt.pack(value)
        if raw is None:
            return False
        return self.proc.write(address, raw)

    def read_value(self, address: int, type_name: str):
        dt = BY_NAME.get(type_name)
        if dt is None:
            return None
        raw = self.proc.read(address, dt.size)
        if not raw:
            return None
        return dt.unpack(raw)

    def clear(self):
        self.matches.clear()
        self._has_scan = False

    @property
    def count(self) -> int:
        return len(self.matches)


def _safe_gt(a, b) -> bool:
    try:
        return a > b
    except TypeError:
        return False


def _safe_lt(a, b) -> bool:
    try:
        return a < b
    except TypeError:
        return False


def _safe_eq_delta(cur, old, delta, sign: int, tol: float) -> bool:
    """cur == old + sign*delta (с толерантностью для float)."""
    if cur is None or old is None or delta is None:
        return False
    target = old + sign * delta
    try:
        return abs(cur - target) <= max(tol, 1e-9 * max(abs(target), 1))
    except TypeError:
        return False
