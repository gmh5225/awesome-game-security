`README.md`:

```md
# FaceOff

Keep FACEIT's kernel anti-cheat off when you're not playing, and turn it back on before your next match.

<p align="center">
  <img src="docs/screenshot.png" width="431" alt="FaceOff window: anti-cheat turned on, waiting for a restart">
</p>

## Why

FACEIT installs a kernel driver (`FACEIT_AC.sys`) that loads every time Windows starts, whether you play that day or not. Kernel code has full access to your PC. FACEIT's tray icon can unload the driver, but it [comes back on the next boot](https://support.faceit.com/hc/en-us/articles/9394666828188-What-is-FACEIT-Anti-cheat-and-how-does-it-work). FaceOff keeps it off until you decide otherwise.

## Use it

1. Download `FaceOff.exe` from [Releases](../../releases). It's a single 110 KB file with nothing to install, and it runs on Windows 10 and 11.
2. Run it and allow admin access. Changing services needs it.
3. **Turn on → restart → Open anti-cheat → play → Turn off → restart.**

FACEIT only accepts a driver that loaded during startup, so both directions need a restart. FaceOff tells you when and asks before restarting.

**"Windows protected your PC"?** The exe isn't code-signed. Click **More info → Run anyway**. Releases are built by [GitHub Actions](.github/workflows/build.yml) from this repo, and each one ships with a `SHA256SUMS.txt`.

## What it changes

| | Turn off | Turn on |
|---|---|---|
| Driver `faceit` | Disabled | Loads with Windows |
| Service `FACEITService` | Disabled | Manual |
| `faceitclient.exe`, `FACEIT.exe` | Closed (tick *Keep FACEIT app open* to leave the app running) | — |

That's all. It doesn't touch FACEIT's files, makes no network connections and doesn't run at startup. FaceOff saves the original settings in `FaceOff.state` next to the exe.

## Command line

```
FaceOff.exe --status
FaceOff.exe --disable [--keep-app] [--reboot]
FaceOff.exe --enable  [--reboot]
```

Exit codes: `0` ok, `1` error, `2` restart needed.

No exe? [`scripts/faceit-off.bat`](scripts/faceit-off.bat) and [`scripts/faceit-on.bat`](scripts/faceit-on.bat) do the same thing. Run them as admin.

## Build

```
dotnet build src/FaceOff/FaceOff.csproj -c Release

`scripts/faceit-off.bat`:

```bat
@echo off
:: FaceOff fallback script: disable FACEIT anti-cheat so it does not load at boot.
:: Run as administrator. A restart is usually needed to unload the kernel driver.

net session >nul 2>&1
if errorlevel 1 (
    echo [ERROR] Run this script as administrator: right-click ^> Run as administrator.
    pause
    exit /b 1
)

echo Closing FACEIT (anti-cheat client and app)...
taskkill /IM faceitclient.exe /F /T >nul 2>&1
:: To keep the FACEIT app open, add "::" at the start of the next line.
taskkill /IM FACEIT.exe /F /T >nul 2>&1

echo Disabling FACEITService...
sc config FACEITService start= disabled
net stop FACEITService >nul 2>&1

echo Disabling faceit kernel driver...
sc config faceit start= disabled
net stop faceit >nul 2>&1

echo.
sc query faceit | find "RUNNING" >nul
if errorlevel 1 (
    echo [OK] FACEIT is off and will not load at boot.
) else (
    echo [OK] FACEIT is disabled, but the driver is still loaded.
    echo      Restart Windows to unload it.
)
pause
```

`src/FaceOff/AntiCheatClient.cs`:

```cs
using System;
using System.Diagnostics;
using System.IO;
using Microsoft.Win32;

namespace FaceOff
{
    /// <summary>Finds and opens FACEIT's anti-cheat tray client (faceitclient.exe).</summary>
    internal static class AntiCheatClient
    {
        /// <summary>
        /// The client sits next to faceitservice.exe, so its folder comes from the service's
        /// registered path instead of a hardcoded install location. Null if not found.
        /// </summary>
        public static string FindPath()
        {
            using (var key = Registry.LocalMachine.OpenSubKey(@"SYSTEM\CurrentControlSet\Services\" + Targets.Service))
            {
                var image = key?.GetValue("ImagePath") as string;
                if (string.IsNullOrWhiteSpace(image)) return null;

                image = Environment.ExpandEnvironmentVariables(image.Trim());
                // ImagePath is usually quoted and may carry arguments: "C:\...\faceitservice.exe" -x
                if (image.StartsWith("\""))
                    image = image.Substring(1, image.IndexOf('"', 1) - 1);

                var dir = Path.GetDirectoryName(image);
                if (dir == null) return null;
                var path = Path.Combine(dir, Targets.AntiCheatProcesses[0] + ".exe");
                return File.Exists(path) ? path : null;
            }
        }

        public static ServiceInfo Query()
        {
            var running = Process.GetProcessesByName(Targets.AntiCheatProcesses[0]);
            foreach (var p in running) p.Dispose();
            return new ServiceInfo
            {
                Name = Targets.AntiCheatProcesses[0],
                Installed = FindPath() != null,
                Running = running.Length > 0,
            };
        }

        /// <summary>
        /// Opens the client through Explorer so it runs with the user's normal rights rather than
        /// inheriting FaceOff's admin token. If the client needs admin, it asks for it itself.
        /// </summary>
        public static void Open()
        {
            var path = FindPath() ?? throw new FileNotFoundException("FACEIT anti-cheat client not found.");
            Process.Start(new ProcessStartInfo("explorer.exe", "\"" + path + "\"") { UseShellExecute = false });
        }
    }
}
```

```cs
using System;
using System.Runtime.InteropServices;
using System.Security.Principal;

namespace FaceOff
{
    internal static class Program
    {
        const int ExitOk = 0, ExitError = 1, ExitRebootRequired = 2;

        [STAThread]
        static int Main(string[] args)
        {
            if (args.Length == 0)
            {
                var app = new App();
                app.InitializeComponent();
                return app.Run(new MainWindow());
            }
            return RunCli(args);
        }

        static int RunCli(string[] args)
        {
            // WinExe has no console of its own: borrow the caller's, or open one and keep it visible.
            bool ownConsole = !AttachConsole(ATTACH_PARENT_PROCESS);
            if (ownConsole) AllocConsole();
            Console.SetOut(new System.IO.StreamWriter(Console.OpenStandardOutput()) { AutoFlush = true });
            Console.WriteLine();

            int code;
            try { code = Execute(args); }
            catch (Exception e)
            {
                Console.WriteLine("Error: " + e.Message);
                code = ExitError;
            }

            if (ownConsole)
            {
                Console.WriteLine("\nPress any key to close.");
                Console.ReadKey(true);
            }
            return code;
        }

        static int Execute(string[] args)
        {
            string command = args[0].ToLowerInvariant();
            bool reboot = Array.Exists(args, a => a.Equals("--reboot", StringComparison.OrdinalIgnoreCase));
            bool keepApp = Array.Exists(args, a => a.Equals("--keep-app", StringComparison.OrdinalIgnoreCase));

            if (command == "--help" || command == "-h" || command == "/?")
            {
                PrintHelp();
                return ExitOk;
            }
            if (!IsAdmin())
            {
                Console.WriteLine("FaceOff must run as administrator.");
                return ExitError;
            }

            var toggler = new Toggler(StateStore.Default());
            Result result;
            switch (command)
            {
                case "--status":
                    PrintStatus(toggler.GetStatus());
                    return ExitOk;
                case "--disable":
                    result = toggler.Disable(keepApp);
                    break;
                case "--enable":
                    result = toggler.Enable();
                    break;
                default:
                    Console.WriteLine("Unknown option: " + args[0]);
                    PrintHelp();
                    return ExitError;
            }

            foreach (var line in result.Log) Console.WriteLine("  " + line);
            Console.WriteLine();
            PrintStatus(toggler.GetStatus());

            if (!result.RebootRequired) return ExitOk;
            if (reboot)
            {
                Console.WriteLine("Restarting in 5 seconds...");
                Toggler.Reboot();
                return ExitOk;
            }
            Console.WriteLine("Restart Windows to finish (or run again with --reboot).");
            return ExitRebootRequired;
        }

        static void PrintStatus(Status status)
        {
            Console.WriteLine("FACEIT anti-cheat: " + Describe(status.State));
            foreach (var s in new[] { status.Driver, status.Service })
                Console.WriteLine(s.Installed
                    ? $"  {s.Name,-14} {(s.Running ? "running" : "stopped"),-8} start={s.StartType}"
                    : $"  {s.Name,-14} not installed");
        }

        public static string Describe(AntiCheatState state)
        {
            switch (state)
            {
                case AntiCheatState.On: return "ON";
                case AntiCheatState.Off: return "OFF";
                case AntiCheatState.OnAfterRestart: return "ON AFTER RESTART";
                case AntiCheatState.OffAfterRestart: return "OFF AFTER RESTART";
                default: return "NOT INSTALLED";
            }
        }

        static void PrintHelp()
        {
            Console.WriteLine("FaceOff - turn FACEIT's kernel anti-cheat off when you're not playing.");
            Console.WriteLine();
            Console.WriteLine("  FaceOff.exe                     open the window");
            Console.WriteLine("  FaceOff.exe --status            show driver and service state");
            Console.WriteLine("  FaceOff.exe --disable [--keep-app] [--reboot]");
            Console.WriteLine("                                  close FACEIT, stop the anti-cheat, keep it from loading at boot");
            Console.WriteLine("                                  --keep-app leaves the FACEIT app running");
            Console.WriteLine("  FaceOff.exe --enable  [--reboot]  restore FACEIT's original configuration");
            Console.WriteLine();
            Console.WriteLine("Exit codes: 0 ok, 1 error, 2 restart required.");
        }

        static bool IsAdmin()
        {
            using (var identity = WindowsIdentity.GetCurrent())
                return new WindowsPrincipal(identity).IsInRole(WindowsBuiltInRole.Administrator);
        }

        const int ATTACH_PARENT_PROCESS = -1;
        [DllImport("kernel32.dll")] static extern bool AttachConsole(int processId);
        [DllImport("kernel32.dll")] static extern bool AllocConsole();
    }
```

```cs
using System;
using System.ComponentModel;
using System.Runtime.InteropServices;
using System.ServiceProcess;

namespace FaceOff
{
    /// <summary>Mirrors the SERVICE_*_START values used by the Service Control Manager.</summary>
    internal enum StartType : uint
    {
        Boot = 0,
        System = 1,
        Auto = 2,
        Demand = 3,
        Disabled = 4,
    }

    internal sealed class ServiceInfo
    {
        public string Name;
        public bool Installed;
        public StartType StartType;
        public bool Running;
    }

    /// <summary>Thin wrapper over the Service Control Manager. Works for services and kernel drivers.</summary>
    internal static class ServiceControl
    {
        public static ServiceInfo Query(string name)
        {
            var info = new ServiceInfo { Name = name };
            try
            {
                using (var sc = new ServiceController(name))
                {
                    var status = sc.Status; // throws if the service doesn't exist
                    info.Installed = true;
                    info.Running = status != ServiceControllerStatus.Stopped;
                    info.StartType = (StartType)(uint)sc.StartType;
                }
            }
            catch (InvalidOperationException)
            {
                info.Installed = false;
            }
            return info;
        }

        public static void SetStartType(string name, StartType startType)
        {
            IntPtr scm = OpenSCManager(null, null, SC_MANAGER_CONNECT);
            if (scm == IntPtr.Zero) throw new Win32Exception();
            try
            {
                IntPtr svc = OpenService(scm, name, SERVICE_CHANGE_CONFIG);
                if (svc == IntPtr.Zero) throw new Win32Exception();
                try
                {
                    if (!ChangeServiceConfig(svc, SERVICE_NO_CHANGE, (uint)startType, SERVICE_NO_CHANGE,
                            null, null, IntPtr.Zero, null, null, null, null))
                        throw new Win32Exception();
                }
                finally { CloseServiceHandle(svc); }
            }
            finally { CloseServiceHandle(scm); }
        }

        /// <summary>Returns true if the service is stopped afterwards.</summary>
        public static bool TryStop(string name, TimeSpan timeout)
        {
            try
            {
                using (var sc = new ServiceController(name))
                {
                    if (sc.Status == ServiceControllerStatus.Stopped) return true;
                    if (sc.Status != ServiceControllerStatus.StopPending) sc.Stop();
                    sc.WaitForStatus(ServiceControllerStatus.Stopped, timeout);
                    return true;
                }
            }
            catch (Exception e) when (e is InvalidOperationException || e is System.ServiceProcess.TimeoutException)
            {
                // Kernel anti-cheat drivers usually refuse to unload while Windows is running.
                return false;
            }
        }

        const uint SC_MANAGER_CONNECT = 0x0001;
        const uint SERVICE_CHANGE_CONFIG = 0x0002;
        const uint SERVICE_NO_CHANGE = 0xFFFFFFFF;

        [DllImport("advapi32.dll", SetLastError = true, CharSet = CharSet.Unicode)]
        static extern IntPtr OpenSCManager(string machineName, string databaseName, uint desiredAccess);

        [DllImport("advapi32.dll", SetLastError = true, CharSet = CharSet.Unicode)]
        static extern IntPtr OpenService(IntPtr scManager, string serviceName, uint desiredAccess);

        [DllImport("advapi32.dll", SetLastError = true, CharSet = CharSet.Unicode)]
        static extern bool ChangeServiceConfig(IntPtr service, uint serviceType, uint startType, uint errorControl,
            string binaryPathName, string loadOrderGroup, IntPtr tagId, string dependencies,
            string serviceStartName, string password, string displayName);

        [DllImport("advapi32.dll", SetLastError = true)]
        static extern bool CloseServiceHandle(IntPtr handle);
    }
}
```

```cs
using System;
using System.Collections.Generic;
using System.IO;

namespace FaceOff
{
    /// <summary>
    /// Remembers each target's original start type so "Turn on" restores exactly what FACEIT
    /// installed. Plain "name=value" lines in FaceOff.state next to the exe (portable, readable).
    /// </summary>
    internal sealed class StateStore
    {
        readonly string _path;
        readonly Dictionary<string, StartType> _original = new Dictionary<string, StartType>(StringComparer.OrdinalIgnoreCase);

        public StateStore(string path)
        {
            _path = path;
            if (!File.Exists(path)) return;
            foreach (var line in File.ReadAllLines(path))
            {
                var parts = line.Split(new[] { '=' }, 2);
                if (parts.Length != 2) continue;
                string key = parts[0].Trim(), raw = parts[1].Trim();
                if (key.Equals(KeepAppKey, StringComparison.OrdinalIgnoreCase))
                    KeepApp = raw.Equals("true", StringComparison.OrdinalIgnoreCase);
                else if (key.Equals(TurnedOffKey, StringComparison.OrdinalIgnoreCase))
                {
                    if (long.TryParse(raw, out var ticks)) TurnedOffUtc = new DateTime(ticks, DateTimeKind.Utc);
                }
                else if (Enum.TryParse(raw, true, out StartType value) && value != StartType.Disabled)
                    _original[key] = value;
            }
        }

        public static StateStore Default()
        {
            var dir = AppDomain.CurrentDomain.BaseDirectory;
            return new StateStore(Path.Combine(dir, "FaceOff.state"));
        }

        /// <summary>Records the start type unless it is Disabled (that would be our own change, not the original).</summary>
        public void Remember(string name, StartType current)
        {
            if (current == StartType.Disabled) return;
            _original[name] = current;
        }

        public bool TryGet(string name, out StartType value) => _original.TryGetValue(name, out value);

        const string KeepAppKey = "KeepApp";

        /// <summary>Window setting: leave the FACEIT app running when turning off. Off by default.</summary>
        public bool KeepApp { get; set; }

        const string TurnedOffKey = "TurnedOffUtc";

        /// <summary>When Turn off last ran. Until Windows restarts after this, a clean restart is suggested.</summary>
        public DateTime? TurnedOffUtc { get; set; }

        public void Save()
        {
            var lines = new List<string> { "# FaceOff: original start types, restored by \"Turn on\"." };
            foreach (var kv in _original) lines.Add(kv.Key + "=" + kv.Value);
            lines.Add(KeepAppKey + "=" + (KeepApp ? "true" : "false"));
            if (TurnedOffUtc.HasValue) lines.Add(TurnedOffKey + "=" + TurnedOffUtc.Value.Ticks);
            File.WriteAllLines(_path, lines);
        }
    }
}
```

```cs
using System;
using System.Collections.Generic;
using System.Diagnostics;

namespace FaceOff
{
    internal enum AntiCheatState
    {
        NotInstalled,
        On,
        /// <summary>Set to load at boot, but not loaded yet: FACEIT works after the next restart.</summary>
        OnAfterRestart,
        /// <summary>Kept from loading at boot, but still loaded until the next restart.</summary>
        OffAfterRestart,
        Off,
    }

    internal sealed class Status
    {
        public ServiceInfo Driver;
        public ServiceInfo Service;
        /// <summary>The anti-cheat tray client (a process, not a service). Shown, never part of State.</summary>
        public ServiceInfo Client;

        public AntiCheatState State
        {
            get
            {
                if (!Driver.Installed && !Service.Installed) return AntiCheatState.NotInstalled;
                // The driver decides: FACEIT runs only when it loads at boot.
                if (LoadsAtBoot(Driver.StartType))
                    return Driver.Running ? AntiCheatState.On : AntiCheatState.OnAfterRestart;
                return Driver.Running || Service.Running ? AntiCheatState.OffAfterRestart : AntiCheatState.Off;
            }
        }

        public static bool LoadsAtBoot(StartType t) => t == StartType.Boot || t == StartType.System;
    }

    internal sealed class Result
    {
        public bool RebootRequired;
        public readonly List<string> Log = new List<string>();
    }

    /// <summary>The only place that changes anything. Shared by the window and the CLI.</summary>
    internal sealed class Toggler
    {
        // Only the upper bound: waiting ends as soon as the service has stopped.
        static readonly TimeSpan Timeout = TimeSpan.FromSeconds(15);
        readonly StateStore _store;

        public Toggler(StateStore store) { _store = store; }

        public Status GetStatus() => new Status
        {
            Driver = ServiceControl.Query(Targets.Driver),
            Service = ServiceControl.Query(Targets.Service),
            Client = AntiCheatClient.Query(),
        };

        public Result Disable(bool keepApp)
        {
            var result = new Result();
            var status = GetStatus();
            if (status.State == AntiCheatState.NotInstalled)
                throw new InvalidOperationException("FACEIT anti-cheat is not installed.");

            // 1. Remember how FACEIT was configured before we touch anything.
            // A driver that doesn't load at boot isn't FACEIT's own setting, so it's not worth keeping.
            if (status.Driver.Installed && Status.LoadsAtBoot(status.Driver.StartType))
                _store.Remember(status.Driver.Name, status.Driver.StartType);
            if (status.Service.Installed)
                _store.Remember(status.Service.Name, status.Service.StartType);
            _store.TurnedOffUtc = DateTime.UtcNow;
            _store.Save();

            // 2. Close the anti-cheat client first, otherwise it can restart the service.
            CloseProcesses(Targets.AntiCheatProcesses, result);
            if (!keepApp) CloseProcesses(Targets.AppProcesses, result);

            // 3. Service before driver: the service depends on the driver being loaded.
            foreach (var s in new[] { status.Service, status.Driver })
            {
                if (!s.Installed) continue;
                ServiceControl.SetStartType(s.Name, StartType.Disabled);
                result.Log.Add($"{s.Name}: start type -> Disabled");

                result.Log.Add(ServiceControl.TryStop(s.Name, Timeout)
                    ? $"{s.Name}: stopped"
                    : $"{s.Name}: didn't stop yet");
            }

            // 4. Judge by what is actually loaded now, not by how each stop call went.
            var after = GetStatus();
            result.RebootRequired = after.Driver.Running || after.Service.Running;
            result.Log.Add(result.RebootRequired
                ? "Driver still loaded: restart Windows to unload it"
                : "Driver unloaded. Restart anyway for a clean start");
            return result;
        }

        public Result Enable()
        {
            var result = new Result();
            _store.TurnedOffUtc = null;
            _store.Save();
            var status = GetStatus();
            if (status.State == AntiCheatState.NotInstalled)
                throw new InvalidOperationException("FACEIT anti-cheat is not installed.");

            // Only start types change here. FACEIT won't accept a driver started after boot,
            // so the driver loads on the next restart and the client starts the service itself.
            if (status.Driver.Installed)
            {
                var driver = _store.TryGet(status.Driver.Name, out var saved) && Status.LoadsAtBoot(saved)
                    ? saved : Targets.DriverDefault;
                ServiceControl.SetStartType(status.Driver.Name, driver);
                result.Log.Add($"{status.Driver.Name}: start type -> {driver}");
            }
            if (status.Service.Installed)
            {
                var service = _store.TryGet(status.Service.Name, out var saved) ? saved : Targets.ServiceDefault;
                ServiceControl.SetStartType(status.Service.Name, service);
                result.Log.Add($"{status.Service.Name}: start type -> {service}");
            }

            if (status.Driver.Installed && !status.Driver.Running)
            {
                result.Log.Add($"{status.Driver.Name}: loads on the next restart");
                result.RebootRequired = true;
            }
            return result;
        }

        /// <summary>Asks each process to close like a normal Exit, and forces it only if it doesn't within 3 seconds.</summary>
        static void CloseProcesses(string[] names, Result result)
        {
            foreach (var name in names)
                foreach (var p in Process.GetProcessesByName(name))
                    using (p)
                    {
                        try
                        {
                            int pid = p.Id;
                            if (p.CloseMainWindow() && p.WaitForExit(3000))
                                result.Log.Add($"Closed {name}.exe (PID {pid})");
                            else
                            {
                                p.Kill();
                                p.WaitForExit(5000);
                                result.Log.Add($"Force-closed {name}.exe (PID {pid})");
                            }
                        }
                        catch (Exception e) { result.Log.Add($"Could not close {name}.exe: {e.Message}"); }
                    }
        }

        /// <summary>True if Turn off ran and Windows hasn't restarted since.</summary>
        public bool CleanRestartPending =>
            _store.TurnedOffUtc.HasValue && LastBootUtc < _store.TurnedOffUtc.Value;

        static DateTime LastBootUtc => DateTime.UtcNow - TimeSpan.FromMilliseconds(GetTickCount64());

        [System.Runtime.InteropServices.DllImport("kernel32.dll")]
        static extern ulong GetTickCount64();

        public static void Reboot()
        {
            Process.Start(new ProcessStartInfo("shutdown.exe", "/r /t 5 /c \"FaceOff: restarting to apply FACEIT anti-cheat changes.\"")
            {
                UseShellExecute = false,
                CreateNoWindow = true,
            });
        }
    }
}
```
