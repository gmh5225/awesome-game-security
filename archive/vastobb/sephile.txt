`README.md`:

```md
# Sephile

**Sephile** is a modern, beginner-friendly yet powerful Android runtime analysis and memory editing tool — think Game Guardian, but with a clean new UI, easier onboarding, and powerful runtime tools.

> ⚠️ **Educational / research tool.** Sephile requires **root** (`CAP_SYS_PTRACE`) to read and write the memory of other processes. Only build and run it on devices you own and have authorized. The authors are not responsible for misuse.

## What it does

- **Attach** to any running process by PID (root via `ptrace`)
- **Scan memory** for exact values: byte, short, 4-byte, 8-byte, float, double
- **Unknown initial value** and **fuzzy/changed** searches
- **Refine ("next")** scans to narrow down candidates
- **Edit** values live in a running process
- **Freeze** values so they stay constant
- **Process list** browser with refresh
- **Live Memory Inspector / offset finder**: enter an address, continuously read bytes, changed bytes highlight green (use this to hunt values like a Minecraft block state), tap any byte to poke/edit it live
- **Hex dump editor** built into the live inspector
- **Lua scripting screen** (engine binding stub — wire in lua-5.4 source to activate, see below)
- Modern **Jetpack Compose** UI (Material 3, dark by default)
- **GitHub Actions** CI builds debug/release APKs automatically

## Architecture

| Layer | Tech |
|-------|------|
| UI | Kotlin + Jetpack Compose (Material 3), single Activity |
| State | ViewModel + StateFlow |
| Logic | Clean-ish: Repository → Native bridge |
| Native | C++20 NDK (CMake), `ptrace` + `/proc/<pid>/maps` |
| Root | `su` shell wrapper, root detection |
| CI | GitHub Actions (JDK 17, Android SDK + NDK r27) |

## Build

### Prerequisites
- Android Studio / Gradle 8.6+
- Android SDK (API 34)
- NDK r27
- JDK 17

### Debug build
```bash
git clone https://github.com/vastobb/sephile.git
cd sephile
./gradlew :app:assembleDebug
```
The debug APK will be at `app/build/outputs/apk/debug/app-debug.apk`.

### CI
Pushes and PRs run `.github/workflows/android-ci.yml` which builds the debug APK, runs lint and unit tests. Releases build a signed APK and attach it to the GitHub Release (requires `ANDROID_KEYSTORE`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` secrets).

## Lua scripting

A Lua script screen + `LuaRepository` + JNI binding stubs (`nativeLuaLoad`, `nativeLuaExec`, `nativeLuaBindApi`) are included. To make Lua actually run:

1. Download lua-5.4 source from lua.org
2. Copy the `src/` tree into `app/src/main/jni/lua/`
3. Add the lua source files to `app/src/main/jni/CMakeLists.txt`
4. Define `SEPHILE_LUA_ENABLED` and replace the stub bodies in `native_bridge.cpp` with real `luaL_loadstring`/`lua_pcall` calls, exposing `sephile.scan`, `sephile.edit`, `sephile.freeze`, `sephile.attach` to Lua.

## Root setup

Sephile needs root on the device/emulator:
- Magisk / Zygisk / KernelSU / APatch
- Or an emulator with root (e.g. AVD with Google Play + root image)

On first launch, Sephile checks for `su` and `uid=0`. If root isn't available, attaching to other processes will fail.

## Disclaimer

Memory editing of other apps may violate their Terms of Service and can break games/apps. Online games with server-side validation or anti-cheat will detect and may ban accounts. Use only on offline, single-player apps you own, for learning and research.

class LuaRepository {

    private val bridge = NativeBridge()
    private var handle: Long = 0L

    init {
        handle = bridge.nativeInit()
        bridge.nativeLuaLoad(handle)
        bridge.nativeLuaBindApi(handle)
    }

    fun release() {
        if (handle != 0L) {
            bridge.nativeDestroy(handle)
            handle = 0L
        }
    }

    fun isLoaded(): Boolean = handle != 0L

    fun exec(script: String): String {
        if (handle == 0L) return "Lua not initialized"
        return bridge.nativeLuaExec(handle, script)
    }
}

package com.sephile.app.repository

import com.sephile.app.model.SearchType
import com.sephile.app.model.ValueType
import com.sephile.app.root.NativeBridge
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.flow
import kotlinx.coroutines.flow.flowOn
import kotlinx.coroutines.withContext
import kotlinx.coroutines.Dispatchers

class MemoryRepository {

    private val bridge = NativeBridge()
    private var handle: Long = 0L

    init {
        handle = bridge.nativeInit()
    }

    fun release() {
        if (handle != 0L) {
            bridge.nativeDetach(handle)
            bridge.nativeDestroy(handle)
            handle = 0L
        }
    }

    fun hasRoot(): Boolean = bridge.nativeHasRoot()

    fun attach(pid: Int): Boolean {
        if (handle == 0L) handle = bridge.nativeInit()
        return bridge.nativeAttach(handle, pid)
    }

    fun detach() {
        if (handle != 0L) bridge.nativeDetach(handle)
    }

    fun isAttached(): Boolean = handle != 0L && bridge.nativeIsAttached(handle)

    fun firstScan(
        pid: Int, type: ValueType, searchType: SearchType,
        targetValue: Long, targetValueF: Double, fuzzyDelta: Long, onlyWritable: Boolean
    ): Long {
        return bridge.nativeFirstScan(
            handle, pid, type.id, searchType.id,
            targetValue, targetValueF, fuzzyDelta, onlyWritable
        )
    }

    fun nextScan(
        type: ValueType, searchType: SearchType,
        targetValue: Long, targetValueF: Double, fuzzyDelta: Long, onlyWritable: Boolean
    ): Long {
        return bridge.nativeNextScan(
            handle, type.id, searchType.id,
            targetValue, targetValueF, fuzzyDelta, onlyWritable
        )
    }

    fun candidateCount(): Int = bridge.nativeCandidateCount(handle)

    fun candidateAddress(index: Int): Long = bridge.nativeCandidateAddress(handle, index)

    fun candidateHex(index: Int): String = bridge.nativeCandidateHex(handle, index)

    fun editValue(address: Long, type: ValueType, intVal: Long, floatVal: Double): Boolean {
        return bridge.nativeEditValue(handle, address, type.id, intVal, floatVal)
    }

    fun freeze(address: Long, enabled: Boolean, value: String) {
        bridge.nativeFreeze(handle, address, enabled, value)
    }

    /** Read raw bytes from the attached process at `address` (returns null on failure). */
    fun peekMemory(address: Long, length: Int): ByteArray? {
        if (handle == 0L || !isAttached()) return null
        return bridge.nativePeekMemory(handle, address, length)
    }
}

```kt
package com.sephile.app.repository

import android.app.ActivityManager
import android.content.Context
import android.os.Process
import com.sephile.app.model.ProcessInfo
import com.sephile.app.root.SuShell
import kotlinx.coroutines.flow.Flow
import kotlinx.coroutines.flow.flow
import kotlinx.coroutines.flow.flowOn
import kotlinx.coroutines.withContext
import kotlinx.coroutines.Dispatchers

class ProcessRepository(private val context: Context) {

    fun listRunningProcesses(): List<ProcessInfo> {
        val am = context.getSystemService(Context.ACTIVITY_SERVICE) as ActivityManager
        val apps = am.runningAppProcesses ?: return emptyList()
        return apps.mapNotNull { proc ->
            val name = proc.processName ?: ""
            val pid = proc.pid
            // Skip the tool itself and kernel threads
            if (pid == Process.myPid()) return@mapNotNull null
            if (name.isEmpty()) return@mapNotNull null
            ProcessInfo(pid = pid, name = name, uid = proc.uid)
        }.sortedBy { it.name }
    }

    fun findPidByName(processName: String): Int? {
        return SuShell.pidof(processName)
    }

    fun observeProcesses(): Flow<List<ProcessInfo>> = flow {
        while (true) {
            emit(listRunningProcesses())
            withContext(Dispatchers.Default) {
                kotlinx.coroutines.delay(3000)
            }
        }
    }.flowOn(Dispatchers.Default)
}

package com.sephile.app.root

import android.content.Context
import android.content.Intent
import android.content.pm.PackageManager
import android.net.Uri
import android.os.Build
import android.provider.Settings
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.launch
import kotlin.concurrent.thread

/**
 * Root & su availability checks. Sephile requires root to ptrace-attach into
 * other processes (Game Guardian style).
 */
object RootManager {

    fun isRootAvailable(): Boolean {
        return suBinaryExists() || canRunSu()
    }

    private fun suBinaryExists(): Boolean {
        val suPaths = listOf(
            "/system/bin/su", "/system/xbin/su",
            "/system/bin/.ext/.su", "/system/xbin/daemonsu",
            "/sbin/su", "/bin/su", "/data/local/su",
            "/data/local/bin/su", "/data/local/xbin/su",
            "/cache/su", "/cache/xbin/su"
        )
        return suPaths.any { java.io.File(it).exists() }
    }

    private fun canRunSu(): Boolean {
        return try {
            val proc = java.lang.Runtime.getRuntime().exec("su -c id")
            val out = java.io.BufferedReader(
                java.io.InputStreamReader(proc.inputStream)).readText()
            proc.waitFor()
            out.contains("uid=0")
        } catch (e: Exception) {
            false
        }
    }

    fun isRootMgmtInstalled(): Boolean {
        val pkgs = listOf(
            "com.topjohnwu.magisk", "com.topjohnwu.magisk.debug",
            "com.kuroiku.zygisk", "org.chainfire.supersu",
            "me.phh.superuser", "com.koushikdutta.superuser"
        )
        // check via package manager would need context; keep simple here
        return pkgs.any { p ->
            try {
                java.lang.Class.forName("android.app.Application")
                false
            } catch (_: Exception) {
                false
            }
        }
    }

    fun requestIgnoreBatteryOptimizations(context: Context) {
        val intent = Intent(Settings.ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS)
                .setData(Uri.parse("package:${context.packageName}"))
        intent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
        context.startActivity(intent)
    }

    fun runInBackground(scope: CoroutineScope, block: () -> Unit) {
        scope.launch(Dispatchers.Default) {
            thread(isDaemon = true, start = true) {
                block()
            }
        }
    }
}

        createNotificationChannel()
    }

    override fun onStartCommand(intent: Intent?, flags: Int, startId: Int): Int {
        val notification = buildNotification()
        startForeground(NOTIFICATION_ID, notification)
        return START_NOT_STICKY
    }

    override fun onBind(intent: Intent?): IBinder? = null

    override fun onDestroy() {
        super.onDestroy()
        stopForeground(true)
    }

    private fun createNotificationChannel() {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            val channel = NotificationChannel(
                CHANNEL_ID,
                "Sephile scan",
                NotificationManager.IMPORTANCE_LOW
            ).apply {
                description = "Keeps memory scans running in the background"
                enableLights(false)
                enableVibration(false)
            }
            val manager = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
            manager.createNotificationChannel(channel)
        }
    }

    private fun buildNotification(): Notification {
        val context = applicationContext
        val intent = Intent(context, MainActivity::class.java).apply {
            flags = Intent.FLAG_ACTIVITY_CLEAR_TOP or Intent.FLAG_ACTIVITY_SINGLE_TOP
        }
        val pendingIntent = PendingIntent.getActivity(
            context, 0, intent,
            PendingIntent.FLAG_IMMUTABLE or PendingIntent.FLAG_UPDATE_CURRENT
        )

        return NotificationCompat.Builder(context, CHANNEL_ID)
            .setContentTitle("Sephile")
            .setContentText("Memory scan running in background")
            .setSmallIcon(R.mipmap.ic_launcher)
            .setContentIntent(pendingIntent)
            .setOngoing(true)
            .setPriority(NotificationCompat.PRIORITY_LOW)
            .build()
    }

package com.sephile.app.root

import java.io.BufferedReader
import java.io.InputStreamReader
import java.io.OutputStreamWriter
import java.io.PrintWriter

/**
 * Tiny helper to run shell commands through `su` and capture stdout.
 */
object SuShell {

    fun run(cmd: String, timeoutMillis: Long = 5000): SuResult {
        return try {
            val process = java.lang.Runtime.getRuntime().exec("su")
            val writer = PrintWriter(OutputStreamWriter(process.outputStream), true)
            writer.println(cmd)
            writer.println("exit")
            writer.flush()

            val outBuf = StringBuilder()
            val errBuf = StringBuilder()
            val outReader = BufferedReader(InputStreamReader(process.inputStream))
            val errReader = BufferedReader(InputStreamReader(process.errorStream))

            var outLine: String? = outReader.readLine()
            while (outLine != null) {
                outBuf.append(outLine).append("\n")
                outLine = outReader.readLine()
            }
            var errLine: String? = errReader.readLine()
            while (errLine != null) {
                errBuf.append(errLine).append("\n")
                errLine = errReader.readLine()
            }

            val finished = process.waitFor(timeoutMillis, java.util.concurrent.TimeUnit.MILLISECONDS)
            val result = SuResult(
                exitCode = if (finished) process.exitValue() else -1,
                stdout = outBuf.toString(),
                stderr = errBuf.toString(),
                timedOut = !finished
            )
            process.destroyForcibly()
            result
        } catch (e: Exception) {
            SuResult(exitCode = -1, stdout = "", stderr = e.message ?: "unknown", timedOut = false)
        }
    }

    fun pidof(processName: String): Int? {
        val res = run("pidof $processName")
        val trimmed = res.stdout.trim()
        return if (trimmed.isNotEmpty()) trimmed.split(" ").first().toIntOrNull() else null
    }
}

data class SuResult(
    val exitCode: Int,
    val stdout: String,
    val stderr: String,
    val timedOut: Boolean
) {
    val success: Boolean get() = exitCode == 0
}

class LiveMemoryInspectorViewModel(private val repo: MemoryRepository) {

    private val scope = CoroutineScope(SupervisorJob() + Dispatchers.Default)
    private var watchJob: kotlinx.coroutines.Job? = null

    private val _ui = MutableStateFlow(LiveMemoryInspectorUiState())
    val ui: StateFlow<LiveMemoryInspectorUiState> = _ui

    val attached: Boolean
        get() = repo.isAttached()
    val targetPid: Int
        get() = 0
        private set

    fun setError(err: String) {
        _ui.update { it.copy(error = err) }
    }

    fun startWatch(address: Long, length: Int) {
        stopWatch()
        _ui.update { it.copy(address = address, byteCount = length,
            bytes = ByteArray(length), changed = BooleanArray(length), watching = true, error = "") }
        var previous: ByteArray? = null
        watchJob = scope.launch {
            while (isActive) {
                val buf = repo.peekMemory(address, length) ?: break
                val changed = BooleanArray(length)
                for (i in buf.indices) {
                    val prev = previous?.getOrElse(i) { 0 }
                    if (buf[i] != prev) {
                        changed[i] = true
                    }
                }
                previous = buf.copyOf()
                _ui.update { it.copy(bytes = buf, changed = changed) }
                delay(400)
            }
            _ui.update { it.copy(watching = false) }
        }
    }

    fun stopWatch() {
        watchJob?.cancel()
        watchJob = null
        _ui.update { it.copy(watching = false) }
    }

    fun refreshOnce() {}

    fun pokeByte(index: Int, newValue: Int) {
        val addr = _ui.value.address + index
        val ok = repo.editValue(addr, ValueType.BYTE, newValue.toLong(), 0.0)
        _ui.update {
            it.copy(error = if (ok) "" else "Poke failed")
        }
    }
}

data class LiveMemoryInspectorUiState(
    val attached: Boolean = false,
    val targetPid: Int = -1,
    val watching: Boolean = false,
    val address: Long = 0L,
    val byteCount: Int = 0,
    val bytes: ByteArray = byteArrayOf(),
    val changed: BooleanArray = booleanArrayOf(),
    val error: String = ""
)

@Composable
private fun HexDumpEditor(
    bytes: ByteArray,
    changed: BooleanArray,
    baseAddress: Long,
    onByteEdit: (index: Int, newValue: Int) -> Unit
) {
    val columns = 16
    val rows = if (bytes.isEmpty()) 0 else ((bytes.size + columns - 1) / columns)

    LazyColumn(
        modifier = Modifier.fillMaxSize(),
        contentPadding = PaddingValues(vertical = 4.dp)
    ) {
        items(count = rows, key = { it }) { row ->
            Row(modifier = Modifier.fillMaxWidth()) {
                Box(
                    modifier = Modifier.width(56.dp),
                    contentAlignment = Alignment.CenterEnd
                ) {
                    Text(
                        text = "0x${(baseAddress + (row * columns)).toString(16).uppercase()}",
                        style = MaterialTheme.typography.bodySmall,
                        color = MaterialTheme.colorScheme.onSurfaceVariant
                    )
                }
                repeat(columns) { col ->
                    val index = row * columns + col
                    val inRange = index < bytes.size
                    val b = if (inRange) bytes[index] else 0
                    val isChanged = inRange && changed[index]
                    val hex = "%02X".format(b.toInt() and 0xFF)
                    Box(
                        modifier = Modifier
                            .width(26.dp)
                            .height(26.dp)
                            .clickable(enabled = inRange, onClick = { if (inRange) onByteEdit(index, b.toInt() and 0xFF) }),
                        contentAlignment = Alignment.Center
                    ) {
                        Text(
                            text = hex,
                            style = MaterialTheme.typography.bodyMedium,
                            color = if (isChanged) Color(0xFF7CFC00)
                            else if (inRange) Color(0xFFE6E6E6)
                            else Color(0xFF4A5568)
                        )
                    }
                }
                Spacer(modifier = Modifier.width(8.dp))
                repeat(columns) { col ->
                    val index = row * columns + col
                    val inRange = index < bytes.size
                    val c = if (inRange) bytes[index].toInt() else 0
                    val printable = if (inRange && c >= 32 && c <= 126) c.toChar() else '.'
                    Box(
                        modifier = Modifier.width(16.dp),
                        contentAlignment = Alignment.Center
                    ) {
                        Text(
                            text = printable.toString(),
                            style = MaterialTheme.typography.bodyMedium,
                            color = if (inRange) Color(0xFFE6E6E6) else Color(0xFF4A5568)
                        )
                    }
                }
            }
        }
    }
}

package com.sephile.app.viewmodel

import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import com.sephile.app.model.SearchType
import com.sephile.app.model.ValueType
import com.sephile.app.repository.MemoryRepository
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.stateIn
import kotlinx.coroutines.flow.update
import kotlinx.coroutines.launch
import kotlinx.coroutines.withContext
import kotlinx.coroutines.Dispatchers

data class ScannerUiState(
    val attached: Boolean = false,
    val targetPid: Int = -1,
    val targetName: String = "",
    val candidateCount: Int = 0,
    val isScanning: Boolean = false,
    val lastResult: String = "",
    val error: String? = null
)

class ScannerViewModel(private val repo: MemoryRepository) : ViewModel() {

    private val _ui = MutableStateFlow(ScannerUiState())
    val ui: StateFlow<ScannerUiState> = _ui.stateIn(viewModelScope, replay = 1)

    fun attachToProcess(pid: Int, name: String) {
        viewModelScope.launch {
            _ui.update { it.copy(error = null, isScanning = true) }
            val ok = withContext(Dispatchers.Default) { repo.attach(pid) }
            _ui.update {
                it.copy(
                    attached = ok,
                    targetPid = if (ok) pid else -1,
                    targetName = name,
                    isScanning = false,
                    error = if (ok) null else "Attach failed. Root required?"
                )
            }
        }
    }

    fun detach() {
        viewModelScope.launch {
            repo.detach()
            _ui.update { it.copy(attached = false, targetPid = -1, candidateCount = 0) }
        }
    }

    fun firstScan(
        type: ValueType, searchType: SearchType,
        targetValue: Long, targetValueF: Double, fuzzyDelta: Long, onlyWritable: Boolean
    ) {
        val pid = _ui.value.targetPid
        if (pid == -1) {
            _ui.update { it.copy(error = "Select a process first") }
            return
        }
        viewModelScope.launch {
            _ui.update { it.copy(isScanning = true, error = null) }
            val count = withContext(Dispatchers.Default) {
                repo.firstScan(pid, type, searchType, targetValue, targetValueF, fuzzyDelta, onlyWritable)
            }
            _ui.update {
                it.copy(
                    isScanning = false,
                    candidateCount = repo.candidateCount(),
                    lastResult = "First scan: $count candidates"
                )
            }
        }
    }

    fun nextScan(
        type: ValueType, searchType: SearchType,
        targetValue: Long, targetValueF: Double, fuzzyDelta: Long, onlyWritable: Boolean
    ) {
        viewModelScope.launch {
            _ui.update { it.copy(isScanning = true, error = null) }
            val count = withContext(Dispatchers.Default) {
                repo.nextScan(type, searchType, targetValue, targetValueF, fuzzyDelta, onlyWritable)
            }
            _ui.update {
                it.copy(
                    isScanning = false,
                    candidateCount = repo.candidateCount(),
                    lastResult = "Next scan: $count candidates"
                )
            }
        }
    }

    fun editCandidate(index: Int, type: ValueType, intVal: Long, floatVal: Double) {
        val address = repo.candidateAddress(index)
        if (address == 0L) return
        viewModelScope.launch {
            val ok = withContext(Dispatchers.Default) {
                repo.editValue(address, type, intVal, floatVal)
            }
            _ui.update {
                it.copy(lastResult = if (ok) "Edited 0x${address.toString(16)}" else "Edit failed")
            }
        }
    }

    fun toggleFreeze(index: Int, enabled: Boolean, value: String) {
        val address = repo.candidateAddress(index)
        if (address == 0L) return
        repo.freeze(address, enabled, value)
        _ui.update {
            it.copy(lastResult = if (enabled) "Frozen 0x${address.toString(16)}" else "Unfrozen")
        }
    }

    fun clearCandidates() {
        _ui.update { it.copy(candidateCount = 0, lastResult = "Cleared") }
    }
}

namespace sephile {

MemoryScanner::MemoryScanner() = default;
MemoryScanner::~MemoryScanner() { detach(); }

bool MemoryScanner::attach(pid_t pid) {
    pid_ = pid;
    return mem_.attach(pid);
}
void MemoryScanner::detach() {
    mem_.detach();
    pid_ = -1;
}
bool MemoryScanner::isAttached() const { return mem_.isAttached(); }

void MemoryScanner::clearCandidates() { candidates_.clear(); }

std::string MemoryScanner::bytesToHex(const uint8_t* data, size_t len) const {
    static const char* hex = "0123456789ABCDEF";
    std::string out;
    out.reserve(len * 2);
    for (size_t i = 0; i < len; ++i) {
        out.push_back(hex[(data[i] >> 4) & 0xF]);
        out.push_back(hex[data[i] & 0xF]);
    }
    return out;
}

bool MemoryScanner::readCandidateBytes(const ScanCandidate& c, std::vector<uint8_t>& out) const {
    size_t typeSize = 1;
    switch (c.type) {
        case ValueType::Byte:   typeSize = 1; break;
        case ValueType::Short:  typeSize = 2; break;
        case ValueType::Dword:
        case ValueType::Float:  typeSize = 4; break;
        case ValueType::Qword:
        case ValueType::Double: typeSize = 8; break;
        default: typeSize = 4; break;
    }
    out.resize(typeSize);
    return mem_.read(c.address, out.data(), typeSize) == typeSize;
}

bool MemoryScanner::matches(const std::vector<uint8_t>& curBytes, ValueType type,
                            const ScanOptions& opts, bool isFirst) const {
    if (curBytes.empty()) return false;

    switch (type) {
        case ValueType::Byte: {
            int8_t cur; std::memcpy(&cur, curBytes.data(), 1);
            int8_t target = static_cast<int8_t>(opts.targetValue);
            if (opts.searchType == SearchType::Exact) return cur == target;
            if (opts.searchType == SearchType::UnknownInitial) return true; // accept anything
            if (opts.searchType == SearchType::Fuzzy) return std::abs(cur - target) >= opts.fuzzyDelta;
            if (opts.searchType == SearchType::GreaterThan) return cur > target;
            if (opts.searchType == SearchType::LessThan) return cur < target;
            return false;
        }
        case ValueType::Short: {
            int16_t cur; std::memcpy(&cur, curBytes.data(), 2);
            int16_t target = static_cast<int16_t>(opts.targetValue);
            if (opts.searchType == SearchType::Exact) return cur == target;
            if (opts.searchType == SearchType::UnknownInitial) return true;
            if (opts.searchType == SearchType::Fuzzy) return std::abs(cur - target) >= opts.fuzzyDelta;
            if (opts.searchType == SearchType::GreaterThan) return cur > target;
            if (opts.searchType == SearchType::LessThan) return cur < target;
            return false;
        }
        case ValueType::Dword: {
            int32_t cur; std::memcpy(&cur, curBytes.data(), 4);
            int32_t target = static_cast<int32_t>(opts.targetValue);
            if (opts.searchType == SearchType::Exact) return cur == target;
            if (opts.searchType == SearchType::UnknownInitial) return true;
            if (opts.searchType == SearchType::Fuzzy) return std::abs(cur - target) >= opts.fuzzyDelta;
            if (opts.searchType == SearchType::GreaterThan) return cur > target;
            if (opts.searchType == SearchType::LessThan) return cur < target;
            return false;
        }
        case ValueType::Qword: {
            int64_t cur; std::memcpy(&cur, curBytes.data(), 8);
            int64_t target = opts.targetValue;
            if (opts.searchType == SearchType::Exact) return cur == target;
            if (opts.searchType == SearchType::UnknownInitial) return true;
            if (opts.searchType == SearchType::Fuzzy) return std::abs(cur - target) >= opts.fuzzyDelta;
            if (opts.searchType == SearchType::GreaterThan) return cur > target;
            if (opts.searchType == SearchType::LessThan) return cur < target;
            return false;
        }
        case ValueType::Float: {
            float cur; std::memcpy(&cur, curBytes.data(), 4);
            float target = static_cast<float>(opts.targetValueF);
            if (opts.searchType == SearchType::Exact) return cur == target;
            if (opts.searchType == SearchType::UnknownInitial) return true;
            if (opts.searchType == SearchType::Fuzzy) return std::fabs(cur - target) >= static_cast<float>(opts.fuzzyDelta);
            if (opts.searchType == SearchType::GreaterThan) return cur > target;
            if (opts.searchType == SearchType::LessThan) return cur < target;
            return false;
        }
        case ValueType::Double: {
            double cur; std::memcpy(&cur, curBytes.data(), 8);
            double target = opts.targetValueF;
            if (opts.searchType == SearchType::Exact) return cur == target;
            if (opts.searchType == SearchType::UnknownInitial) return true;
            if (opts.searchType == SearchType::Fuzzy) return std::fabs(cur - target) >= opts.fuzzyDelta;
            if (opts.searchType == SearchType::GreaterThan) return cur > target;
            if (opts.searchType == SearchType::LessThan) return cur < target;
            return false;
        }
        default:
            return false;
    }
}

int64_t MemoryScanner::scanRegion(const MemoryRegion& region, const ScanOptions& opts,
                                   bool isFirst, ScanProgress progress) {
    if (!region.readable) return 0;
    if (opts.onlyWritable && !region.writable) return 0;

    // Address filter
    uintptr_t start = region.start;
    uintptr_t end = region.end;
    if (opts.regionStart > start) start = opts.regionStart;
    if (opts.regionEnd < end) end = opts.regionEnd;
    if (end <= start) return 0;

    size_t typeSize = 1;
    switch (opts.type) {
        case ValueType::Byte: typeSize = 1; break;
        case ValueType::Short: typeSize = 2; break;
        case ValueType::Dword:
        case ValueType::Float: typeSize = 4; break;
        case ValueType::Qword:
        case ValueType::Double: typeSize = 8; break;
        default: typeSize = 4; break;
    }

    // Read region in chunks
    const size_t chunk = 64 * 1024;
    std::vector<uint8_t> buf(chunk);
    int64_t found = 0;
    int64_t scanned = 0;

    for (uintptr_t off = start; off + typeSize <= end; off += typeSize) {
        size_t toRead = typeSize;
        // Reuse a small read; for simplicity read typeSize bytes per candidate addr.
        // (Perf-conscious: refactor to chunked reads later.)
        std::vector<uint8_t> tb(typeSize);
        if (mem_.read(off, tb.data(), typeSize) != typeSize) continue;

        scanned++;
        if (matches(tb, opts.type, opts, isFirst)) {
            ScanCandidate c;
            c.address = off;
            c.region = region;
            c.type = opts.type;
            c.hexDump = bytesToHex(tb.data(), typeSize);
            candidates_.push_back(c);
            found++;
        }

        if (progress && (scanned % 4096 == 0)) {
            progress(scanned, found);
        }
    }

    if (progress) progress(scanned, found);
    return found;
}

int64_t MemoryScanner::firstScan(const ScanOptions& opts, ScanProgress progress) {
    candidates_.clear();
    pid_ = opts.targetPid;
    if (!mem_.isAttached() || mem_.pid() != pid_) {
        if (!mem_.attach(pid_)) return -1;
    }

    int64_t totalFound = 0;
    auto regions = mem_.enumerateRegions();
    for (const auto& r : regions) {
        totalFound += scanRegion(r, opts, true, progress);
    }
    return totalFound;
}

int64_t MemoryScanner::nextScan(const ScanOptions& opts, ScanProgress progress) {
    // Refine: re-read existing candidates and keep those that still match.
    std::vector<ScanCandidate> next;
    next.reserve(candidates_.size());
    int64_t scanned = 0;

    for (auto& c : candidates_) {
        std::vector<uint8_t> tb;
        if (!readCandidateBytes(c, tb)) continue;
        scanned++;
        if (matches(tb, c.type, opts, false)) {
            c.hexDump = bytesToHex(tb.data(), tb.size());
            next.push_back(std::move(c));
        }
        if (progress && (scanned % 256 == 0)) {
            progress(scanned, static_cast<int64_t>(next.size()));
        }
    }
    candidates_ = std::move(next);
    if (progress) progress(scanned, static_cast<int64_t>(candidates_.size()));
    return static_cast<int64_t>(candidates_.size());
}

bool MemoryScanner::editValue(uintptr_t address, ValueType type, int64_t intVal, double floatVal) {
    if (!mem_.isAttached()) return false;

    switch (type) {
        case ValueType::Byte: {
            int8_t v = static_cast<int8_t>(intVal);
            return mem_.writeT(address, v);
        }
        case ValueType::Short: {
            int16_t v = static_cast<int16_t>(intVal);
            return mem_.writeT(address, v);
        }
        case ValueType::Dword: {
            int32_t v = static_cast<int32_t>(intVal);
            return mem_.writeT(address, v);
        }
        case ValueType::Qword: {
            return mem_.writeT(address, intVal);
        }
        case ValueType::Float: {
            float v = static_cast<float>(floatVal);
            return mem_.writeT(address, v);
        }
        case ValueType::Double: {
            return mem_.writeT(address, floatVal);
        }
        default:
            return false;
    }
}

void MemoryScanner::freeze(uintptr_t address, bool enabled, const std::string& value) {
    for (auto& c : candidates_) {
        if (c.address == address) {
            c.frozen = enabled;
            c.freezeValue = value;
            break;
        }
    }
}

#include <functional>

namespace sephile {

enum class ValueType : int8_t {
    Unknown = -1,
    Byte = 0,        // 1 byte, signed
    Short = 1,       // 2 bytes
    Dword = 2,       // 4 bytes (int32)
    Qword = 3,       // 8 bytes (int64)
    Float = 4,       // 4 bytes IEEE754
    Double = 5,      // 8 bytes IEEE754
};

enum class SearchType : int8_t {
    Exact = 0,
    UnknownInitial = 1,
    Fuzzy = 2,       // value changed (used with "next")
    GreaterThan = 3,
    LessThan = 4,
};

// A single candidate result from scanning
struct ScanCandidate {
    uintptr_t address = 0;
    MemoryRegion region;
    ValueType type = ValueType::Unknown;
    std::string hexDump;     // hex representation of current bytes
    bool frozen = false;
    std::string freezeValue; // value to repeatedly write when frozen
};

struct ScanOptions {
    pid_t targetPid = -1;
    ValueType type = ValueType::Dword;
    SearchType searchType = SearchType::Exact;
    int64_t targetValue = 0;          // exact/int target
    double targetValueF = 0.0;        // float/double target
    uintptr_t regionStart = 0;        // optional start address filter
    uintptr_t regionEnd = 0;          // optional end address filter
    bool onlyWritable = true;
    int64_t fuzzyDelta = 0;           // for fuzzy/changed searches
};

// Results callback: invoked as scanning progresses (streaming UI)
using ScanProgress = std::function<void(int64_t scanned, int64_t found)>;

class MemoryScanner {
public:
    MemoryScanner();
    ~MemoryScanner();

    // Attach to target process (root required). Returns true on success.
    bool attach(pid_t pid);
    void detach();
    bool isAttached() const;

    // First scan: populate candidate list from scratch.
    // Returns number of candidates found.
    int64_t firstScan(const ScanOptions& opts, ScanProgress progress = nullptr);

    // Next scan: refine existing candidates by re-reading their addresses.
    int64_t nextScan(const ScanOptions& opts, ScanProgress progress = nullptr);

    // Current candidates
    const std::vector<ScanCandidate>& candidates() const { return candidates_; }
    void clearCandidates();

    // Edit a candidate's value at its address
    bool editValue(uintptr_t address, ValueType type, int64_t intVal, double floatVal);

    // Freeze / unfreeze a candidate (freeze = keep writing value)
    void freeze(uintptr_t address, bool enabled, const std::string& value);

    // Get the attached ProcessMemory for direct ops
    ProcessMemory& memory() { return mem_; }

private:
    ProcessMemory mem_;
    std::vector<ScanCandidate> candidates_;
    pid_t pid_ = -1;

    bool readCandidateBytes(const ScanCandidate& c, std::vector<uint8_t>& out) const;
    bool matches(const std::vector<uint8_t>& curBytes, ValueType type,
                 const ScanOptions& opts, bool isFirst) const;
    int64_t scanRegion(const MemoryRegion& region, const ScanOptions& opts,
                       bool isFirst, ScanProgress progress);

#include "ProcessMemory.h"

#include <android/log.h>
#include <cstdio>
#include <cstring>
#include <fstream>
#include <sstream>
#include <sys/ptrace.h>
#include <sys/types.h>
#include <sys/wait.h>
#include <unistd.h>

#define TAG "SephileNative"
#define LOGE(...) __android_log_print(ANDROID_LOG_ERROR, TAG, __VA_ARGS__)
#define LOGI(...) __android_log_print(ANDROID_LOG_INFO, TAG, __VA_ARGS__)

namespace sephile {

ProcessMemory::~ProcessMemory() {
    detach();
}

bool ProcessMemory::attach(pid_t pid) {
    if (attached_ && pid_ == pid) {
        return true;
    }
    if (attached_) {
        detach();
    }

    // PTRACE_ATTACH stops the target and makes us its tracer. Requires root
    // on modern Android (yama ptrace_scope + SELinux).
    if (ptrace(PTRACE_ATTACH, pid, nullptr, nullptr) != 0) {
        LOGE("PTRACE_ATTACH failed for pid %d (errno=%d). Root required.", pid, errno);
        return false;
    }

    int status = 0;
    if (waitpid(pid, &status, __WALL) < 0) {
        LOGE("waitpid after ATTACH failed for pid %d", pid);
        ptrace(PTRACE_DETACH, pid, nullptr, nullptr);
        return false;
    }

    pid_ = pid;
    attached_ = true;
    LOGI("Attached to pid %d", pid);
    return true;
}

void ProcessMemory::detach() {
    if (!attached_) return;
    ptrace(PTRACE_DETACH, pid_, nullptr, nullptr);
    attached_ = false;
    LOGI("Detached from pid %d", pid_);
    pid_ = -1;
}

std::vector<MemoryRegion> ProcessMemory::enumerateRegions() const {
    std::vector<MemoryRegion> regions;
    if (!attached_) return regions;

    std::ostringstream path;
    path << "/proc/" << pid_ << "/maps";
    std::ifstream maps(path.str());
    if (!maps.is_open()) {
        LOGE("Cannot open /proc/%d/maps", pid_);
        return regions;
    }

    std::string line;
    while (std::getline(maps, line)) {
        MemoryRegion r;
        unsigned long start, end, offset, major, minor;
        char perms[5] = {0};
        char pathname[4096] = {0};
        int inode = 0;

        int n = sscanf(line.c_str(), "%lx-%lx %4s %lx %x:%x %d %4095s",
                       &start, &end, perms, &offset, &major, &minor, &inode, pathname);
        if (n < 7) continue;

        r.start = static_cast<uintptr_t>(start);
        r.end = static_cast<uintptr_t>(end);
        r.size = static_cast<size_t>(end - start);
        r.offset = static_cast<uintptr_t>(offset);
        r.major = major;
        r.minor = minor;

        r.readable = (perms[0] == 'r');
        r.writable = (perms[1] == 'w');
        r.executable = (perms[2] == 'x');

        if (pathname[0] != '\0') {
            r.pathname = pathname;
        }

        // Only keep readable regions (scannable). Writable ones are editable.
        if (r.readable && r.size > 0) {
            regions.push_back(r);
        }
    }
    return regions;
}

long ProcessMemory::ptraceRead(pid_t pid, uintptr_t addr) {
    errno = 0;
    long val = ptrace(PTRACE_PEEKTEXT, pid, reinterpret_cast<void*>(addr), nullptr);
    return val;
}

bool ProcessMemory::ptraceWrite(pid_t pid, uintptr_t addr, long data) {
    errno = 0;
    if (ptrace(PTRACE_POKETEXT, pid, reinterpret_cast<void*>(addr), reinterpret_cast<void*>(data)) != 0) {
        return false;
    }
    return true;
}

size_t ProcessMemory::read(uintptr_t addr, void* buf, size_t len) const {
    if (!attached_) return 0;
    if (len == 0) return 0;

    size_t total = 0;
    uint8_t* dst = static_cast<uint8_t*>(buf);

    // ptrace reads/writes one word (long) at a time. Align to word boundary.
    const size_t word = sizeof(long);
    uintptr_t cur = addr;

    // Handle leading unaligned bytes
    size_t lead = cur % word;
    if (lead) {
        long chunk = ptraceRead(pid_, cur - lead);
        size_t copy = word - lead;
        if (copy > len) copy = len;
        std::memcpy(dst, reinterpret_cast<uint8_t*>(&chunk) + lead, copy);
        dst += copy;
        total += copy;
        cur += copy;
    }

    // Aligned word-sized chunks
    while (total + word <= len) {
        long chunk = ptraceRead(pid_, cur);
        std::memcpy(dst, &chunk, word);
        dst += word;
        total += word;
        cur += word;
    }

    // Trailing bytes
    if (total < len) {
        long chunk = ptraceRead(pid_, cur);
        size_t remaining = len - total;
        std::memcpy(dst, &chunk, remaining);
        total += remaining;
    }

    return total;
}

size_t ProcessMemory::write(uintptr_t addr, const void* buf, size_t len) const {
    if (!attached_) return 0;
    if (len == 0) return 0;

    size_t total = 0;
    const uint8_t* src = static_cast<const uint8_t*>(buf);
    const size_t word = sizeof(long);
    uintptr_t cur = addr;

    // Leading unaligned bytes: read-modify-write the word
    size_t lead = cur % word;
    if (lead) {
        long chunk = ptraceRead(pid_, cur - lead);
        size_t copy = word - lead;
        if (copy > len) copy = len;
        std::memcpy(reinterpret_cast<uint8_t*>(&chunk) + lead, src, copy);
        if (!ptraceWrite(pid_, cur - lead, chunk)) return total;
        src += copy;
        total += copy;
        cur += copy;
    }

    // Aligned words
    while (total + word <= len) {
        long chunk;
        std::memcpy(&chunk, src, word);
        if (!ptraceWrite(pid_, cur, chunk)) return total;
        src += word;
        total += word;
        cur += word;
    }

    // Trailing bytes
    if (total < len) {
        long chunk = ptraceRead(pid_, cur);
        size_t remaining = len - total;
        std::memcpy(&chunk, src, remaining);
        if (!ptraceWrite(pid_, cur, chunk)) return total;
        total += remaining;
    }

    return total;
}

#pragma once

#include <cstdint>
#include <string>
#include <vector>

namespace sephile {

// A single readable/writable memory region parsed from /proc/<pid>/maps
struct MemoryRegion {
    uintptr_t start = 0;
    uintptr_t end = 0;
    size_t size = 0;
    bool readable = false;
    bool writable = false;
    bool executable = false;
    std::string pathname;
    uintptr_t offset = 0;
    int major = 0;
    int minor = 0;
};

// Low-level ptrace-based process memory reader/writer.
// Designed to run on Android (ARM64/ARM/x86_64) and requires root (ptrace ATTACH).
class ProcessMemory {
public:
    ProcessMemory() = default;
    ~ProcessMemory();

    // Attach to target process via ptrace (requires root). Call once before read/write.
    bool attach(pid_t pid);
    void detach();

    bool isAttached() const { return attached_; }
    pid_t pid() const { return pid_; }

    // Enumerate all readable memory regions of the target from /proc/<pid>/maps.
    std::vector<MemoryRegion> enumerateRegions() const;

    // Read raw bytes from target memory. Returns number of bytes actually read.
    size_t read(uintptr_t addr, void* buf, size_t len) const;

    // Write raw bytes to target memory. Returns number of bytes actually written.
    size_t write(uintptr_t addr, const void* buf, size_t len) const;

    // Convenience typed reads
    template <typename T>
    bool readT(uintptr_t addr, T& out) const {
        return read(addr, &out, sizeof(T)) == sizeof(T);
    }

    // Convenience typed writes
    template <typename T>
    bool writeT(uintptr_t addr, const T& val) const {
        return write(addr, &val, sizeof(T)) == sizeof(T);
    }

private:
    pid_t pid_ = -1;
    bool attached_ = false;

    // ptrace helpers
    static long ptraceRead(pid_t pid, uintptr_t addr);
    static bool ptraceWrite(pid_t pid, uintptr_t addr, long data);
};

}  // namespace sephile

`gradlew`:

```
#!/usr/bin/env sh

##############################################################################
##
##  Gradle start up script for UN*X
##
##############################################################################

# Attempt to set APP_HOME
# Resolve links: $0 may be a link
PRG="$0"
while [ -h "$PRG" ] ; do
    ls=`ls -ld "$PRG"`
    link=`expr "$ls" : '.*-> \(.*\)$'`
    if expr "$link" : '/.*' > /dev/null; then
        PRG="$link"
    else
        PRG=`dirname "$PRG"`"/$link"
    fi
done
SAVED="`pwd`"
cd "`dirname \"$PRG\"`/" >/dev/null
APP_HOME="`pwd -P`"
cd "$SAVED" >/dev/null

APP_NAME="Gradle"
APP_BASE_NAME=`basename "$0"`

# Add default JVM options here. You can also use JAVA_OPTS and GRADLE_OPTS to pass JVM options to this script.
DEFAULT_JVM_OPTS="-Xmx64m"

# Use the maximum available, or set MAX_FD != -1 to use that value.
MAX_FD="maximum"

warn () {
    echo "$*"
}

die () {
    echo
    echo "$*"
    echo
    exit 1
}

# OS specific support (must be 'true' or 'false').
cygwin=false
msys=false
darwin=false
nonstop=false
case "`uname`" in
  CYGWIN* )
    cygwin=true
    ;;
  Darwin* )
    darwin=true
    ;;
  MINGW* )
    msys=true
    ;;
  NONSTOP* )
    nonstop=true
    ;;
esac

CLASSPATH=$APP_HOME/gradle/wrapper/gradle-wrapper.jar

# Determine the Java command to use to start the JVM.
if [ -n "$JAVA_HOME" ] ; then
    if [ -x "$JAVA_HOME/jre/sh/java" ] ; then
        # IBM's JDK on AIX uses strange locations for the executables
        JAVACMD="$JAVA_HOME/jre/sh/java"
    else
        JAVACMD="$JAVA_HOME/bin/java"
    fi
    if [ ! -x "$JAVACMD" ] ; then
        die "ERROR: JAVA_HOME is set to an invalid directory: $JAVA_HOME
Please set the JAVA_HOME variable in your environment to match the
location of your Java installation."
    fi
else
    JAVACMD="java"
    which java >/dev/null 2>&1 || die "ERROR: JAVA_HOME is not set and no 'java' command could be found in your PATH.
Please set the JAVA_HOME variable in your environment to match the
location of your Java installation."
fi

# Increase the maximum file descriptors if we can.
if [ "$cygwin" = "false" -a "$darwin" = "false" ] ; then
    MAX_FD_LIMIT=`ulimit -H -n`
    if [ $? -eq 0 ] ; then
        if [ "$MAX_FD" = "maximum" -o "$MAX_FD" = "max" ] ; then
            MAX_FD="$MAX_FD_LIMIT"
        fi
        ulimit -n $MAX_FD 2>/dev/null ||
            warn "Could not set maximum file descriptor limit: $ulimit"
    else
        warn "Could not query maximum file descriptor limit: $ulimit"
    fi
fi

# For Darwin, add options to specify how the application appears in the dock
if $darwin; then
    GRADLE_OPTS="$GRADLE_OPTS \"-Xdock:name=$APP_NAME\" \"-Xdock:icon=$APP_HOME/media/gradle.icns\""
fi

# For Cygwin, switch paths to Windows format before running java
if $cygwin ; then
    APP_HOME=`cygpath --path --mixed "$APP_HOME"`
    CLASSPATH=`cygpath --path --mixed "$CLASSPATH"`
    JAVACMD=`cygpath --unix "$JAVACMD"`
fi

# Escape application args
save () {
    for i do printf %s\\n "$i" >> "$APP_HOME/.rawargs"; done
    cp "$APP_HOME/.rawargs" "$APP_HOME/.rawargs.save"
}
rawargs=""
for i in "$@"; do
    case $i in
        -*) rawargs="$rawargs \"$i\"" ;;
        *)  rawargs="$rawargs \"$i\"" ;;
    esac
done

# Split up the JVM_OPTS and GRADLE_OPTS values into an array
eval set -- $DEFAULT_JVM_OPTS $JAVA_OPTS $GRADLE_OPTS "\"$rawargs\""

exec "$JAVACMD" "$@"

```

    )

:end

endlocal & set ERRORLEVEL=%ERRORLEVEL%

if %ERRORLEVEL% NEQ 0 goto fail

goto end

:fail
rem Set variable GRADLE_EXIT_CONSOLE if you need the _script_ return code instead of

if %EXIT_CODE% LEQ 0 set EXIT_CODE=1
goto end

:fail

echo ERROR: %EXIT_CODE%
goto end
