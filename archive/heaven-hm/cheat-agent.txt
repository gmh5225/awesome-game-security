## What is Cheat Agent?

Cheat Agent is an autonomous, cross-platform AI reverse-engineering and trainer-generation system for authorized offline single-player games and controlled test processes.

Unlike existing tools that are interactive desktop GUIs (Cheat Engine, x64dbg) or thin Python MCP wrappers over external tools, Cheat Agent combines high-performance native memory scanners in C++20 with a robust, type-safe Rust orchestration layer.

### The Core Differentiator: Closed-Loop Verification

Most game manipulation tools stop after an address is written to. In real games, memory addresses relocate upon relaunch due to ASLR and dynamic heap allocation. **Cheat Agent enforces a strict 5-stage verification loop:**

```text
DISCOVER THE CHEAT → VERIFY THE CHEAT → GENERATE THE TRAINER → RESTART THE GAME → PROVE IT STILL WORKS.
```

1. **`MEMORY_WRITE_VERIFIED`**: Validates the memory cell updates without OS faults.
2. **`GAME_BEHAVIOR_VERIFIED`**: Confirms in-game behavior responds to the modification (e.g. ammo decrement prevented).
3. **`RESTART_VERIFIED`**: Game process is terminated and restarted; pointer chains or AoB signatures resolve to new addresses.
4. **`TRAINER_BUILD_VERIFIED`**: Standalone C++20 and Rust trainer sources compile with zero errors using native toolchains.
5. **`TRAINER_EXECUTION_VERIFIED`**: The compiled trainer attaches to the restarted process and restores/enforces target state.

---

## Dual First-Class Execution Modes

### Mode A: Hosted Coding Agent (MCP)
Operates directly inside **OpenAI Codex**, **Claude Code**, or other MCP-compatible AI coding environments. The host agent provides the high-level reasoning and planning, while Cheat Agent provides real reverse-engineering tools, memory inspection, and trainer compilation over standard I/O:

```json
{
  "mcpServers": {
    "cheat-agent": {
      "command": "cheat-agent",
      "args": ["mcp"]
    }
  }
}
```

### Mode B: Standalone AI Agent
Runs independently as a native binary using direct model APIs or local model servers:
- **OpenAI API** (`gpt-4o`, `o1`, `gpt-4-turbo`)
- **Anthropic API** (`claude-3-5-sonnet`)
- **OpenRouter** (DeepSeek, Llama 3.3, Mistral)
- **Ollama** (offline local models: `qwen2.5-coder:32b`, `llama3.3:70b`)

```bash
# Autonomous run with local Ollama
cheat-agent run --provider ollama --model qwen2.5-coder:32b --goal "Discover player ammo and generate a verified trainer"

# Autonomous run with OpenAI
cheat-agent run --provider openai --model gpt-4o --goal "Find health in test game and verify across restarts"
```

```bash
# 1. Build native C/C++ engine and test game
cmake -B build -S .
cmake --build build

# 2. Run native C++ tests
ctest --test-dir build --output-on-failure

# 3. Build and test Rust workspace
cargo build
cargo test
```

```bash
# Launch autonomous restart verification against the native test game
cargo run -p cheat-agent-cli -- verify \

## Security & Ethics

Cheat Agent is strictly built for **authorized offline single-player games, educational research, and QA game-balance testing**.
- Default read-only behavior; mutations require explicit authorization.
- Target identity matching (PID + executable SHA-256 validation).
- Memory rollback and emergency stop kill switch.
- Multiplayer tampering, kernel driver exploits, and DRM circumvention are strictly out of scope.

See [docs/SECURITY.md](docs/SECURITY.md) for the full threat model.

```rs
use cheat_agent_core::{CheatError, Result};
use cheat_agent_mcp::McpServer;
use cheat_agent_providers::{ChatMessage, LlmProvider};

pub async fn run_agent_loop(
    provider: &dyn LlmProvider,
    model: &str,
    goal: &str,
    max_iterations: usize,
    mcp_server: &McpServer,
) -> Result<String> {
    if max_iterations == 0 {
        return Err(CheatError::InvalidArgument(
            "max_iterations must be greater than 0".into(),
        ));
    }

    let tools = McpServer::get_tools_list();
    let tools_vec = tools.as_array().cloned().unwrap_or_default();

    let mut messages = vec![
        ChatMessage::system(
            "You are Cheat Agent, an expert cross-platform reverse-engineering and trainer-generation agent. Use the available tools to inspect memory, find values, resolve pointer chains, and generate verified trainers.",
        ),
        ChatMessage::user(goal),
    ];

    let max_context_messages = 50;
    let mut iterations = 0;

    while iterations < max_iterations {
        iterations += 1;
        println!("[+] Iteration {}/{}: Calling model...", iterations, max_iterations);

        let resp = provider.chat_complete(model, &messages, &tools_vec).await?;

        if let Some(ref text) = resp.content {
            println!("\n[Agent]:\n{}", text);
        }

        if resp.tool_calls.is_empty() {
            println!("[+] Goal completed at iteration {}.", iterations);
            return Ok(resp.content.unwrap_or_else(|| "Goal completed".to_string()));
        }

        let mut tool_calls_json = Vec::new();
        for call in &resp.tool_calls {
            tool_calls_json.push(serde_json::json!({
                "id": call.id,
                "type": "function",
                "function": {
                    "name": call.name,
                    "arguments": call.arguments.to_string(),
                }
            }));
        }

        messages.push(ChatMessage::assistant(
            resp.content.unwrap_or_default(),
            Some(tool_calls_json),
        ));

        for call in &resp.tool_calls {
            println!("  -> Executing Tool: {}({})", call.name, call.arguments);
            let tool_output = match mcp_server.handle_tool_call(&call.name, &call.arguments) {
                Ok(val) => val.to_string(),
                Err(err) => {
                    eprintln!("    [!] Tool Execution Error: {}", err);
                    serde_json::json!({
                        "error": err.to_string()
                    })
                    .to_string()
                }
            };
            messages.push(ChatMessage::tool(&call.id, &call.name, tool_output));
        }

        if messages.len() > max_context_messages {
            let overflow = messages.len() - max_context_messages;
            messages.drain(1..=overflow);
        }
    }

    Err(CheatError::Internal(format!(
        "Autonomous agent loop reached max iteration ceiling ({}) without concluding",
        max_iterations
    )))
}

```rs
use clap::{Parser, Subcommand};
use cheat_agent_core::definition::*;
use cheat_agent_core::DataType;
use cheat_agent_ffi::{MemoryScanner, ProcessBackend};
use cheat_agent_generators::TrainerGenerator;
use cheat_agent_mcp::McpServer;
use cheat_agent_providers::{LlmProvider, OllamaProvider, OpenAiProvider};
use cheat_agent_verifier::VerificationEngine;
use std::fs;
use std::path::PathBuf;

#[derive(Parser)]
#[command(name = "cheat-agent", version = "0.1.0", about = "Cross-platform autonomous AI cheat agent & verified trainer generator")]
struct Cli {
    #[command(subcommand)]
    command: Commands,
}

#[derive(Subcommand)]
enum Commands {
    /// Run stdio Model Context Protocol (MCP) server for Claude Code and Codex
    Mcp,

    /// Run standalone autonomous AI agent loop
    Run {
        #[arg(long, default_value = "ollama")]
        provider: String,

        #[arg(long, default_value = "qwen2.5-coder:32b")]
        model: String,

        #[arg(long)]
        goal: String,

        #[arg(long, default_value_t = 20)]
        max_iterations: usize,
    },

    /// Scan process memory directly
    Scan {
        #[arg(long)]
        pid: u32,

        #[arg(long)]
        exact: Option<u32>,

        #[arg(long)]
        aob: Option<String>,

        #[arg(long, default_value = "uint32")]
        data_type: String,
    },

    /// Verify a cheat definition with restart testing
    Verify {
        #[arg(long)]
        cheat: PathBuf,

        #[arg(long)]
        target_command: String,
    },

    /// Generate standalone C++, Rust, and Cheat Engine trainers
    Generate {
        #[arg(long)]
        cheat: PathBuf,

        #[arg(long, default_value = "cpp")]
        lang: String,

        #[arg(long)]
        output: Option<PathBuf>,
    },
}

#[tokio::main]
async fn main() -> Result<(), Box<dyn std::error::Error>> {
    let cli = Cli::parse();

    match cli.command {
        Commands::Mcp => {
            let server = McpServer::new();
            server.run_stdio()?;
        }
        Commands::Scan { pid, exact, aob, data_type: _ } => {
            println!("[+] Attaching to PID {}...", pid);
            let backend = ProcessBackend::new(pid)?;
            let mut scanner = MemoryScanner::new(&backend)?;

            if let Some(val) = exact {
                let bytes = val.to_ne_bytes();
                scanner.first_scan(DataType::Uint32, cheat_agent_core::ScanMode::Exact, Some(&bytes), None)?;
                let count = scanner.match_count();
                println!("[+] Found {} matches for exact value {}", count, val);
                let matches = scanner.get_matches(10)?;
                for addr in matches {
                    println!("    0x{:X}", addr);
                }
            } else if let Some(pat) = aob {
                scanner.scan_aob(&pat)?;
                let count = scanner.match_count();
                println!("[+] Found {} matches for AoB pattern '{}'", count, pat);
                let matches = scanner.get_matches(10)?;
                for addr in matches {
                    println!("    0x{:X}", addr);
                }
            }
        }
        Commands::Verify { cheat, target_command } => {
            let content = fs::read_to_string(&cheat)?;
            let mut def: CheatDefinition = serde_json::from_str(&content)?;

            println!("[+] Verifying cheat '{}' against '{}'...", def.name, target_command);
            let report = VerificationEngine::verify_with_restart(&mut def, &target_command)?;

            println!("[+] Verification Outcome: {} (unproven stages are not passed)", report.overall_status);
            println!("    Memory Write:        {}", if report.stages.memory_write { "PASSED" } else { "FAILED" });
            println!("    Game Behavior:       {}", if report.stages.game_behavior { "PASSED" } else { "FAILED" });
            println!("    Restart Persistence: {}", if report.stages.restart_persistence { "PASSED" } else { "FAILED" });
            println!("    Trainer Compile:     {}", if report.stages.trainer_compilation { "PASSED" } else { "FAILED" });
            println!("    Trainer Execution:   {}", if report.stages.trainer_execution { "PASSED" } else { "FAILED" });

            let updated_json = serde_json::to_string_pretty(&def)?;
            fs::write(&cheat, updated_json)?;
            println!("[+] Updated cheat definition saved to {:?}", cheat);
            if report.overall_status != "PASSED" {
                eprintln!("[!] Cheat not verified; exiting with status 2");
                std::process::exit(2);
            }
        }
        Commands::Generate { cheat, lang, output } => {
            let content = fs::read_to_string(&cheat)?;
            let def: CheatDefinition = serde_json::from_str(&content)?;

            let code = match lang.as_str() {
                "cpp" => TrainerGenerator::generate_cpp(&def)?,
                "rust" => TrainerGenerator::generate_rust(&def)?,
                "cheat_engine" | "ct" => TrainerGenerator::generate_cheat_engine_table(&def)?,
                _ => {
                    eprintln!("Unsupported language: {}. Choose 'cpp', 'rust', or 'cheat_engine'", lang);
                    std::process::exit(1);
                }
            };

            if let Some(out_path) = output {
                fs::write(&out_path, &code)?;
                println!("[+] Generated {} trainer written to {:?}", lang, out_path);
            } else {
                println!("{}", code);
            }
        }
        Commands::Run { provider, model, goal, max_iterations } => {
            if max_iterations == 0 {
                return Err("max-iterations must be greater than zero".into());
            }
            println!("[+] Starting Standalone AI Agent (Mode B)");
            println!("    Provider: {}", provider);
            println!("    Model:    {}", model);
            println!("    Goal:     {}", goal);

            let provider_box: Box<dyn LlmProvider> = match provider.as_str() {
                "openai" => {
                    let key = std::env::var("OPENAI_API_KEY").unwrap_or_default();
                    Box::new(OpenAiProvider::new(key, None))
                }
                "ollama" => {
                    let host = std::env::var("OLLAMA_HOST").ok();
                    Box::new(OllamaProvider::new(host))
                }
                _ => {
                    eprintln!("Unsupported provider: {}. Choose 'openai' or 'ollama'", provider);
                    std::process::exit(1);
                }
            };

            let mcp_server = McpServer::new();
            match cheat_agent_cli::run_agent_loop(
                provider_box.as_ref(),
                &model,
                &goal,
                max_iterations,
                &mcp_server,
            )
            .await
            {
                Ok(conclusion) => {
                    println!("\n[+] Autonomous Agent Completed Successfully:\n{}", conclusion);
                }
                Err(e) => {
                    eprintln!("[!] Agent loop failed: {}", e);
                    return Err(Box::<dyn std::error::Error>::from(e));
                }
            }
        }
    }

    Ok(())
}

use cheat_agent_core::{
    CheatError, DataType, MemoryRegion, ModuleInfo, PointerChain, Result, ScanMode,

use std::ffi::{CStr, CString};
use std::ptr;

pub struct ProcessBackend {
    raw: *mut sys::CheatProcessBackend,
}

unsafe impl Send for ProcessBackend {}
unsafe impl Sync for ProcessBackend {}

impl ProcessBackend {
    pub fn new(pid: u32) -> Result<Self> {
        let mut raw = ptr::null_mut();
        let status = unsafe { sys::cheat_backend_create(pid, &mut raw) };
        if status != 0 || raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        Ok(Self { raw })
    }

    pub fn is_alive(&self) -> bool {
        if self.raw.is_null() {
            return false;
        }
        unsafe { sys::cheat_backend_is_alive(self.raw) != 0 }
    }

    pub fn get_pid(&self) -> u32 {
        if self.raw.is_null() {
            return 0;
        }
        unsafe { sys::cheat_backend_get_pid(self.raw) }
    }

    pub fn read_memory(&self, address: u64, size: usize) -> Result<Vec<u8>> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let mut buffer = vec![0u8; size];
        let mut bytes_read = 0;
        let status = unsafe {
            sys::cheat_backend_read_memory(
                self.raw,
                address,
                buffer.as_mut_ptr() as *mut _,
                size,
                &mut bytes_read,
            )
        };
        if status != 0 {
            return Err(CheatError::ReadFailed {
                address,
                message: format!("status code {}", status),
            });
        }
        buffer.truncate(bytes_read);
        Ok(buffer)
    }

    pub fn write_memory(&self, address: u64, data: &[u8]) -> Result<usize> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let mut bytes_written = 0;
        let status = unsafe {
            sys::cheat_backend_write_memory(
                self.raw,
                address,
                data.as_ptr() as *const _,
                data.len(),
                &mut bytes_written,
            )
        };
        if status != 0 {
            return Err(CheatError::WriteFailed {
                address,
                message: format!("status code {}", status),
            });
        }
        Ok(bytes_written)
    }

    pub fn query_regions(&self) -> Result<Vec<MemoryRegion>> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        const MAX_REGIONS: usize = 4096;
        let mut raw_regions = vec![
            sys::CheatMemoryRegion {
                base_address: 0,
                size: 0,
                protection: 0,
                is_writable: 0,
                is_executable: 0,
            };
            MAX_REGIONS
        ];
        let mut count = 0;
        let status = unsafe {
            sys::cheat_backend_query_regions(
                self.raw,
                raw_regions.as_mut_ptr(),
                MAX_REGIONS,
                &mut count,
            )
        };
        if status != 0 {
            return Err(CheatError::Internal(format!(
                "query_regions failed with {}",
                status
            )));
        }

        let mut out = Vec::with_capacity(count);
        for r in &raw_regions[..count] {
            out.push(MemoryRegion {
                base_address: r.base_address,
                size: r.size,
                protection: r.protection,
                is_writable: r.is_writable != 0,
                is_executable: r.is_executable != 0,
            });
        }
        Ok(out)
    }

    pub fn query_modules(&self) -> Result<Vec<ModuleInfo>> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        const MAX_MODS: usize = 256;
        let mut raw_mods = vec![
            sys::CheatModuleInfo {
                name: [0; 256],
                path: [0; 1024],
                base_address: 0,
                size: 0,
            };
            MAX_MODS
        ];
        let mut count = 0;
        let status = unsafe {
            sys::cheat_backend_query_modules(
                self.raw,
                raw_mods.as_mut_ptr(),
                MAX_MODS,
                &mut count,
            )
        };
        if status != 0 {
            return Err(CheatError::Internal(format!(
                "query_modules failed with {}",
                status
            )));
        }

        let mut out = Vec::with_capacity(count);
        for m in &raw_mods[..count] {
            let name_str = CStr::from_bytes_until_nul(&m.name)
                .map(|s| s.to_string_lossy().into_owned())
                .unwrap_or_default();
            let path_str = CStr::from_bytes_until_nul(&m.path)
                .map(|s| s.to_string_lossy().into_owned())
                .unwrap_or_default();
            out.push(ModuleInfo {
                name: name_str,
                path: path_str,
                base_address: m.base_address,
                size: m.size,
            });
        }
        Ok(out)
    }

    pub fn resolve_pointer(&self, chain: &PointerChain) -> Result<u64> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let mut raw_chain = sys::CheatPointerChain {
            base_module: [0; 256],
            base_offset: chain.base_offset,
            offsets: [0; 16],
            offset_count: chain.offsets.len().min(16),
        };
        let c_mod = CString::new(chain.base_module.as_str()).map_err(|e| {
            CheatError::InvalidArgument(format!("null byte in module name: {}", e))
        })?;
        let bytes = c_mod.as_bytes_with_nul();
        let copy_len = bytes.len().min(256);
        raw_chain.base_module[..copy_len].copy_from_slice(&bytes[..copy_len]);

        for (i, off) in chain.offsets.iter().take(16).enumerate() {
            raw_chain.offsets[i] = *off;
        }

        let mut out_address = 0;
        let status =
            unsafe { sys::cheat_pointer_resolve(self.raw, &raw_chain, &mut out_address) };
        if status != 0 {
            return Err(CheatError::NotFound(format!(
                "pointer chain resolution failed with status {}",
                status
            )));
        }
        Ok(out_address)
    }

    pub fn scan_pointers(
        &self,
        target_address: u64,
        max_depth: usize,
        max_offset: i64,
        max_chains: usize,
    ) -> Result<Vec<PointerChain>> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let mut raw_chains = vec![
            sys::CheatPointerChain {
                base_module: [0; 256],
                base_offset: 0,
                offsets: [0; 16],
                offset_count: 0,
            };
            max_chains
        ];
        let mut count = 0;
        let status = unsafe {
            sys::cheat_pointer_scan(
                self.raw,
                target_address,
                max_depth,
                max_offset,
                raw_chains.as_mut_ptr(),
                max_chains,
                &mut count,
            )
        };
        if status != 0 {
            return Err(CheatError::Internal(format!(
                "pointer scan failed with {}",
                status
            )));
        }

        let mut out = Vec::with_capacity(count);
        for c in &raw_chains[..count] {
            let mod_name = CStr::from_bytes_until_nul(&c.base_module)
                .map(|s| s.to_string_lossy().into_owned())
                .unwrap_or_default();
            let mut offsets = Vec::new();
            for i in 0..c.offset_count.min(16) {
                offsets.push(c.offsets[i]);
            }
            out.push(PointerChain {
                base_module: mod_name,
                base_offset: c.base_offset,
                offsets,
            });
        }
        Ok(out)
    }
}

    data_size: usize,
}

unsafe impl Send for MemoryScanner {}
unsafe impl Sync for MemoryScanner {}

impl MemoryScanner {
    pub fn new(backend: &ProcessBackend) -> Result<Self> {
        if backend.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let mut raw = ptr::null_mut();
        let status = unsafe { sys::cheat_scanner_create(backend.raw, &mut raw) };
        if status != 0 || raw.is_null() {
            return Err(CheatError::Internal(format!(
                "scanner creation failed with {}",
                status
            )));
        }
        Ok(Self { raw, data_size: 0 })
    }

    pub fn reset(&mut self) -> Result<()> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let status = unsafe { sys::cheat_scanner_reset(self.raw) };
        if status != 0 {
            return Err(CheatError::Internal("scanner reset failed".to_string()));
        }
        self.data_size = 0;
        Ok(())
    }

    pub fn first_scan(
        &mut self,
        data_type: DataType,
        mode: ScanMode,
        val1: Option<&[u8]>,
        val2: Option<&[u8]>,
    ) -> Result<()> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let size = match data_type {
            DataType::ByteArray | DataType::String => val1.or(val2).map_or(0, |v| v.len()),
            _ => data_type.byte_size(),
        };
        if size == 0 || size > 4 * 1024 ||
            val1.is_some_and(|v| v.len() != size) ||
            val2.is_some_and(|v| v.len() != size) {
            return Err(CheatError::InvalidArgument("scan values must match the declared data width".into()));
        }
        let p1 = val1.map_or(ptr::null(), |b| b.as_ptr() as *const _);
        let p2 = val2.map_or(ptr::null(), |b| b.as_ptr() as *const _);

        let status = unsafe {
            sys::cheat_scanner_first_scan(
                self.raw,
                data_type as i32,
                mode as i32,
                p1,
                p2,
                size,
            )
        };
        if status != 0 {
            return Err(CheatError::Internal(format!(
                "first_scan failed with code {}",
                status
            )));
        }
        self.data_size = size;
        Ok(())
    }

    pub fn next_scan(
        &mut self,
        mode: ScanMode,
        val1: Option<&[u8]>,
        val2: Option<&[u8]>,
    ) -> Result<()> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        if self.data_size == 0 ||
            val1.is_some_and(|v| v.len() != self.data_size) ||
            val2.is_some_and(|v| v.len() != self.data_size) {
            return Err(CheatError::InvalidArgument("next scan value length must match first scan".into()));
        }
        let p1 = val1.map_or(ptr::null(), |b| b.as_ptr() as *const _);
        let p2 = val2.map_or(ptr::null(), |b| b.as_ptr() as *const _);
        let size = self.data_size;

        let status = unsafe {
            sys::cheat_scanner_next_scan(
                self.raw,
                mode as i32,
                p1,
                p2,
                size,
            )
        };
        if status != 0 {
            return Err(CheatError::Internal(format!(
                "next_scan failed with code {}",
                status
            )));
        }
        Ok(())
    }

    pub fn scan_aob(&mut self, pattern: &str) -> Result<()> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let c_pat = CString::new(pattern).map_err(|e| {
            CheatError::InvalidArgument(format!("null byte in pattern: {}", e))
        })?;
        let status = unsafe { sys::cheat_scanner_scan_aob(self.raw, c_pat.as_ptr()) };
        if status != 0 {
            return Err(CheatError::Internal(format!(
                "scan_aob failed with code {}",
                status
            )));
        }
        Ok(())
    }

    pub fn match_count(&self) -> usize {
        if self.raw.is_null() {
            return 0;
        }
        unsafe { sys::cheat_scanner_get_match_count(self.raw) }
    }

    pub fn get_matches(&self, max_count: usize) -> Result<Vec<u64>> {
        if self.raw.is_null() {
            return Err(CheatError::NotConnected);
        }
        let mut buffer = vec![0u64; max_count];
        let mut count = 0;
        let status = unsafe {
            sys::cheat_scanner_get_matches(
                self.raw,
                buffer.as_mut_ptr(),
                max_count,
                &mut count,
            )
        };
        if status != 0 {
            return Err(CheatError::Internal(format!(
                "get_matches failed with code {}",
                status
            )));
        }
        buffer.truncate(count);
        Ok(buffer)
    }
}

    pub fn handle_tool_call(&self, name: &str, arguments: &Value) -> Result<Value> {
        match name {
            "process_attach" => {
                let pid = arguments["pid"].as_u64().ok_or_else(|| {
                    CheatError::InvalidArgument("missing pid".to_string())
                })? as u32;

                let backend = ProcessBackend::new(pid)?;
                let scanner = MemoryScanner::new(&backend)?;

                *self.backend.lock().unwrap() = Some(backend);
                *self.scanner.lock().unwrap() = Some(scanner);

                Ok(json!({
                    "status": "attached",
                    "pid": pid,
                    "message": format!("Successfully attached to process {}", pid)
                }))
            }
            "process_inspect" => {
                let guard = self.backend.lock().unwrap();
                let backend = guard.as_ref().ok_or(CheatError::NotConnected)?;
                let regions = backend.query_regions()?;
                let modules = backend.query_modules()?;
                Ok(json!({
                    "pid": backend.get_pid(),
                    "alive": backend.is_alive(),
                    "region_count": regions.len(),
                    "modules": modules
                }))
            }
            "memory_read" => {
                let addr_str = arguments["address"].as_str().unwrap_or("0x0");
                let address = u64::from_str_radix(addr_str.trim_start_matches("0x"), 16)
                    .map_err(|e| CheatError::InvalidArgument(e.to_string()))?;
                let size = arguments["size"].as_u64().unwrap_or(4) as usize;

                let guard = self.backend.lock().unwrap();
                let backend = guard.as_ref().ok_or(CheatError::NotConnected)?;
                let bytes = backend.read_memory(address, size)?;

                Ok(json!({
                    "address": format!("0x{:X}", address),
                    "bytes_hex": bytes.iter().map(|b| format!("{:02X}", b)).collect::<Vec<_>>().join(" "),
                    "bytes": bytes
                }))
            }
            "memory_scan_exact" => {
                let type_str = arguments["type"].as_str().unwrap_or("uint32");
                let is_first = arguments["is_first_scan"].as_bool().unwrap_or(true);

                let data_type = match type_str {
                    "uint8" => DataType::Uint8,
                    "uint16" => DataType::Uint16,
                    "uint32" => DataType::Uint32,
                    "uint64" => DataType::Uint64,
                    "float" => DataType::Float,
                    "double" => DataType::Double,
                    _ => return Err(CheatError::InvalidArgument("unsupported scan type".into())),
                };

                // Integer values must come from JSON integers to avoid losing
                // uint64 precision in the f64 conversion.
                let unsigned = || {
                    // JSON Schema allows a number; accept 42.0 / 1e3 when
                    // they are finite, integral and exactly representable.
                    // Native JSON integers retain full uint64 precision.
                    arguments["value"].as_u64().or_else(|| {
                        let n = arguments["value"].as_f64()?;
                        if n.is_finite() && n >= 0.0 && n.fract() == 0.0
                            && n <= (1u64 << 53) as f64 {
                            Some(n as u64)
                        } else {
                            None
                        }
                    }).ok_or_else(|| {
                        CheatError::InvalidArgument(
                            "unsigned scan value must be a nonnegative exact integer".into())
                    })
                };
                let val_bytes: Vec<u8> = match data_type {
                    DataType::Uint8 => u8::try_from(unsigned()?)
                        .map_err(|_| CheatError::InvalidArgument("uint8 value out of range".into()))?
                        .to_ne_bytes().to_vec(),
                    DataType::Uint16 => u16::try_from(unsigned()?)
                        .map_err(|_| CheatError::InvalidArgument("uint16 value out of range".into()))?
                        .to_ne_bytes().to_vec(),
                    DataType::Uint32 => u32::try_from(unsigned()?)
                        .map_err(|_| CheatError::InvalidArgument("uint32 value out of range".into()))?
                        .to_ne_bytes().to_vec(),
                    DataType::Uint64 => unsigned()?.to_ne_bytes().to_vec(),
                    DataType::Float | DataType::Double => {
                        let number = arguments["value"].as_f64().ok_or_else(|| {
                            CheatError::InvalidArgument("floating scan value must be numeric".into())
                        })?;
                        if !number.is_finite() {
                            return Err(CheatError::InvalidArgument("floating scan value must be finite".into()));
                        }
                        if data_type == DataType::Float {
                            if number.abs() > f32::MAX as f64 {
                                return Err(CheatError::InvalidArgument("float value out of range".into()));
                            }
                            (number as f32).to_ne_bytes().to_vec()
                        } else {
                            number.to_ne_bytes().to_vec()
                        }
                    }
                    _ => unreachable!(),
                };

                let mut guard = self.scanner.lock().unwrap();
                let scanner = guard.as_mut().ok_or(CheatError::NotConnected)?;

                if is_first {
                    scanner.first_scan(data_type, ScanMode::Exact, Some(&val_bytes), None)?;
                } else {
                    scanner.next_scan(ScanMode::Exact, Some(&val_bytes), None)?;
                }

                let count = scanner.match_count();
                let matches = scanner.get_matches(20)?;
                let matches_hex: Vec<String> = matches.iter().map(|a| format!("0x{:X}", a)).collect();

                Ok(json!({
                    "match_count": count,
                    "matches_sample": matches_hex
                }))
            }
            "memory_scan_decreased" => {
                let mut guard = self.scanner.lock().unwrap();
                let scanner = guard.as_mut().ok_or(CheatError::NotConnected)?;
                scanner.next_scan(ScanMode::Decreased, None, None)?;

                let count = scanner.match_count();
                let matches = scanner.get_matches(20)?;
                let matches_hex: Vec<String> = matches.iter().map(|a| format!("0x{:X}", a)).collect();

                Ok(json!({
                    "match_count": count,
                    "matches_sample": matches_hex
                }))
            }
            "memory_scan_increased" => {
                let mut guard = self.scanner.lock().unwrap();
                let scanner = guard.as_mut().ok_or(CheatError::NotConnected)?;
                scanner.next_scan(ScanMode::Increased, None, None)?;

                }))
            }
            "memory_scan_changed" => {
                let mut guard = self.scanner.lock().unwrap();
                let scanner = guard.as_mut().ok_or(CheatError::NotConnected)?;
                scanner.next_scan(ScanMode::Changed, None, None)?;

                let count = scanner.match_count();

                let mut guard = self.scanner.lock().unwrap();
                let scanner = guard.as_mut().ok_or(CheatError::NotConnected)?;
                scanner.scan_aob(pattern)?;

                let matches = scanner.get_matches(20)?;

                    "match_count": count,
                    "matches_sample": matches_hex
                }))
            }
            "pointer_scan" => {
                let target_str = arguments["target_address"].as_str().unwrap_or("0x0");
                let target_addr = u64::from_str_radix(target_str.trim_start_matches("0x"), 16)
                    .map_err(|e| CheatError::InvalidArgument(e.to_string()))?;
                let max_depth = arguments["max_depth"].as_u64().unwrap_or(2) as usize;
                let max_offset = arguments["max_offset"].as_i64().unwrap_or(4096);

                let guard = self.backend.lock().unwrap();
                let backend = guard.as_ref().ok_or(CheatError::NotConnected)?;
                let chains = backend.scan_pointers(target_addr, max_depth, max_offset, 10)?;

                Ok(json!({
                    "found_count": chains.len(),
                    "chains": chains
                }))
            }
            "trainer_generate" => {
                let cheat_str = arguments["cheat_json"].as_str().unwrap_or("{}");
                let def: cheat_agent_core::definition::CheatDefinition = serde_json::from_str(cheat_str)
                    .map_err(|e| CheatError::InvalidArgument(format!("Invalid cheat json: {}", e)))?;

                let code = match lang {

                    "rust" => TrainerGenerator::generate_rust(&def)?,
                    "cheat_engine" => TrainerGenerator::generate_cheat_engine_table(&def)?,
                    _ => return Err(CheatError::InvalidArgument(format!("Unsupported language {}", lang))),
                };

                Ok(json!({
                    "language": lang,
                    "code": code
                }))
            }
            _ => Err(CheatError::NotFound(format!("Unknown tool {}", name))),
        }
    }

    pub fn run_stdio(&self) -> io::Result<()> {
        let stdin = io::stdin();
        let mut stdout = io::stdout();

        for line in stdin.lock().lines() {
            let line = line?;
            if line.trim().is_empty() {
                continue;
            }

            let request: Value = match serde_json::from_str(&line) {
                Ok(v) => v,
                Err(e) => {
                    let err_resp = json!({
                        "jsonrpc": "2.0",
                        "id": Value::Null,
                        "error": {
                            "code": -32700,
                            "message": format!("Parse error: {}", e)
                        }
                    });
                    writeln!(stdout, "{}", serde_json::to_string(&err_resp)?)?;
                    stdout.flush()?;
                    continue;
                }
            };

            let req_id = request.get("id").cloned().unwrap_or(Value::Null);
            let method = request["method"].as_str().unwrap_or("");

            let response = match method {
                "initialize" => {
                    json!({
                        "jsonrpc": "2.0",
                        "id": req_id,
                        "result": {
                            "protocolVersion": "2024-11-05",
                            "capabilities": {
                                "tools": {}
                            },
                            "serverInfo": {
                                "name": "cheat-agent-mcp",
                                "version": "0.1.0"
                            }
                        }
                    })
                }
                "tools/list" => {
                    json!({
                        "jsonrpc": "2.0",
                        "id": req_id,
                        "result": {
                            "tools": Self::get_tools_list()
                        }
                    })
                }
                "tools/call" => {
                    let params = &request["params"];
                    let tool_name = params["name"].as_str().unwrap_or("");
                    let arguments = &params["arguments"];

                    match self.handle_tool_call(tool_name, arguments) {
                        Ok(res) => {
                            json!({
                                "jsonrpc": "2.0",
                                "id": req_id,
                                "result": {
                                    "content": [{
                                        "type": "text",
                                        "text": serde_json::to_string_pretty(&res).unwrap_or_default()
                                    }],
                                    "isError": false
                                }
                            })
                        }
                        Err(e) => {
                            json!({
                                "jsonrpc": "2.0",
                                "id": req_id,
                                "result": {
                                    "content": [{
                                        "type": "text",
                                        "text": e.to_string()
                                    }],
                                    "isError": true
                                }
                            })
                        }
                    }
                }
                _ => {
                    json!({
                        "jsonrpc": "2.0",
                        "id": req_id,
                        "error": {
                            "code": -32601,
                            "message": format!("Method not found: {}", method)
                        }
                    })
                }
            };

            writeln!(stdout, "{}", serde_json::to_string(&response)?)?;
            stdout.flush()?;
        }

        Ok(())
    }
}

use std::sync::Mutex;

pub struct StorageManager {
    conn: Mutex<Connection>,
}

impl StorageManager {
    pub fn open(path: &str) -> Result<Self> {
        let conn = Connection::open(path).map_err(|e| CheatError::Internal(e.to_string()))?;
        let mgr = Self {
            conn: Mutex::new(conn),
        };
        mgr.init_tables()?;
        Ok(mgr)
    }

    pub fn open_in_memory() -> Result<Self> {
        let conn = Connection::open_in_memory().map_err(|e| CheatError::Internal(e.to_string()))?;
        let mgr = Self {
            conn: Mutex::new(conn),
        };
        mgr.init_tables()?;
        Ok(mgr)
    }

    fn init_tables(&self) -> Result<()> {
        let conn = self.conn.lock().unwrap();
        conn.execute_batch(
            "CREATE TABLE IF NOT EXISTS sessions (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                goal TEXT NOT NULL,
                target_name TEXT NOT NULL,
                status TEXT NOT NULL,
                created_at DATETIME DEFAULT CURRENT_TIMESTAMP
            );
            CREATE TABLE IF NOT EXISTS scan_history (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                session_id INTEGER NOT NULL,
                scan_type TEXT NOT NULL,
                candidate_count INTEGER NOT NULL,
                created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
                FOREIGN KEY(session_id) REFERENCES sessions(id)
            );
            CREATE TABLE IF NOT EXISTS candidates (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                session_id INTEGER NOT NULL,
                address INTEGER NOT NULL,
                FOREIGN KEY(session_id) REFERENCES sessions(id)
            );
            CREATE TABLE IF NOT EXISTS verifications (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                session_id INTEGER NOT NULL,
                status TEXT NOT NULL,
                report_json TEXT NOT NULL,
                created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
                FOREIGN KEY(session_id) REFERENCES sessions(id)
            );"
        ).map_err(|e| CheatError::Internal(e.to_string()))?;
        Ok(())
    }

    pub fn create_session(&self, goal: &str, target_name: &str) -> Result<i64> {
        let conn = self.conn.lock().unwrap();
        conn.execute(
            "INSERT INTO sessions (goal, target_name, status) VALUES (?1, ?2, 'running')",
            params![goal, target_name],
        ).map_err(|e| CheatError::Internal(e.to_string()))?;
        Ok(conn.last_insert_rowid())
    }

    pub fn record_scan(&self, session_id: i64, scan_type: &str, candidate_count: usize) -> Result<()> {
        let conn = self.conn.lock().unwrap();
        conn.execute(
            "INSERT INTO scan_history (session_id, scan_type, candidate_count) VALUES (?1, ?2, ?3)",
            params![session_id, scan_type, candidate_count as i64],
        ).map_err(|e| CheatError::Internal(e.to_string()))?;
        Ok(())
    }

    pub fn record_candidates(&self, session_id: i64, addresses: &[u64]) -> Result<()> {
        let mut conn = self.conn.lock().unwrap();
        let tx = conn.transaction().map_err(|e| CheatError::Internal(e.to_string()))?;
        {
            let mut stmt = tx.prepare_cached(
                "INSERT INTO candidates (session_id, address) VALUES (?1, ?2)"
            ).map_err(|e| CheatError::Internal(e.to_string()))?;

            for addr in addresses {
                stmt.execute(params![session_id, *addr as i64])
                    .map_err(|e| CheatError::Internal(e.to_string()))?;
            }
        }
        tx.commit().map_err(|e| CheatError::Internal(e.to_string()))?;
        Ok(())
    }

    pub fn record_verification(&self, session_id: i64, status: &str, report_json: &str) -> Result<()> {
        let conn = self.conn.lock().unwrap();
        conn.execute(
            "INSERT INTO verifications (session_id, status, report_json) VALUES (?1, ?2, ?3)",

            "UPDATE sessions SET status = ?1 WHERE id = ?2",

        ).map_err(|e| CheatError::Internal(e.to_string()))?;
        Ok(())
    }

    pub fn get_session_history(&self, session_id: i64) -> Result<Vec<String>> {
        let conn = self.conn.lock().unwrap();
        let mut stmt = conn.prepare(

        ).map_err(|e| CheatError::Internal(e.to_string()))?;

        let rows = stmt.query_map(params![session_id], |row| row.get(0))
            .map_err(|e| CheatError::Internal(e.to_string()))?;

        let mut history = Vec::new();
        for r in rows {
            if let Ok(entry) = r {
                history.push(entry);
            }
        }
        Ok(history)
    }

use cheat_agent_core::definition::CheatDefinition;
use cheat_agent_core::report::{VerificationReport, VerificationStages};
use cheat_agent_core::{CheatError, Result};
use cheat_agent_ffi::ProcessBackend;
use cheat_agent_generators::TrainerGenerator;
use std::process::{Child, Command};
use std::time::Duration;
use std::thread;

pub struct VerificationEngine;

impl VerificationEngine {
    pub fn verify_static(
        def: &mut CheatDefinition,
        target_pid: u32,
    ) -> Result<VerificationReport> {
        let mut report = VerificationReport {
            cheat_name: def.name.clone(),
            target_pid,
            overall_status: "UNVERIFIED".to_string(),
            stages: VerificationStages::default(),
            restart_runs: 0,
            evidence_log: Vec::new(),
        };

        let backend = ProcessBackend::new(target_pid)?;
        if !backend.is_alive() {
            return Err(CheatError::NotConnected);
        }

        report.evidence_log.push(format!("Attached to target PID: {}", target_pid));

        // 1. Resolve Address
        let resolved_addr = if def.resolution.method == "module_pointer_chain" {
            let chain = cheat_agent_core::PointerChain {
                base_module: def.resolution.module.clone().unwrap_or_default(),
                base_offset: u64::from_str_radix(
                    def.resolution.base_offset.as_deref().unwrap_or("0").trim_start_matches("0x"),
                    16,
                ).unwrap_or(0),
                offsets: def.resolution.offsets.as_ref().map_or(vec![], |offs| {
                    offs.iter()
                        .map(|s| i64::from_str_radix(s.trim_start_matches("0x"), 16).unwrap_or(0))
                        .collect()
                }),
            };
            backend.resolve_pointer(&chain)?
        } else {
            u64::from_str_radix(
                def.resolution.static_address.as_deref().unwrap_or("0").trim_start_matches("0x"),
                16,
            ).unwrap_or(0)
        };

        report.evidence_log.push(format!("Resolved target address: 0x{:X}", resolved_addr));

        // 2. Read and Verify Memory
        let initial_bytes = backend.read_memory(resolved_addr, 4)?;
        report.evidence_log.push(format!("Original memory bytes: {:02X?}", initial_bytes));
        report.evidence_log.push("Read-only observation: no target write was attempted or verified".to_string());

        // 3. Test Trainer Code Generation & Compilation
        let cpp_code = TrainerGenerator::generate_cpp(def)?;
        let temp_dir = std::env::temp_dir();
        let src_path = temp_dir.join("trainer_test.cpp");
        let bin_path = temp_dir.join("trainer_test_bin");

        std::fs::write(&src_path, &cpp_code)
            .map_err(|e| CheatError::Internal(format!("Failed to write temp trainer: {}", e)))?;

        // Attempt compilation with system compiler
        let compile_status = Command::new("clang++")
            .arg("-std=c++20")
            .arg(&src_path)
            .arg("-o")
            .arg(&bin_path)
            .status();

        if let Ok(st) = compile_status {
            if st.success() {
                report.stages.trainer_compilation = true;
                report.evidence_log.push("Generated C++20 trainer compiled successfully with 0 errors".to_string());
            } else {
                report.evidence_log.push("Compiler exited with non-zero code; check C++20 toolchain".to_string());
            }
        } else {
            report.evidence_log.push("clang++ compiler not detected in test environment".to_string());
        }

        report.evidence_log.push("Behavior and trainer execution were not tested; verification remains incomplete".to_string());
        def.verification.status = "unverified".to_string();
        def.verification.restart_count = 0;
        def.verification.evidence = report.evidence_log.clone();

        Ok(report)
    }

    pub fn verify_with_restart(
        def: &mut CheatDefinition,
        target_command: &str,
    ) -> Result<VerificationReport> {
        let mut report = VerificationReport {
            cheat_name: def.name.clone(),
            target_pid: 0,
            overall_status: "UNVERIFIED".to_string(),
            stages: VerificationStages::default(),
            restart_runs: 0,
            evidence_log: Vec::new(),
        };

        // Launch target process run 1
        let mut child1 = spawn_process(target_command)?;
        let pid1 = child1.id();
        report.target_pid = pid1;
        report.evidence_log.push(format!("Launch 1: started target game PID {}", pid1));
        thread::sleep(Duration::from_millis(100));

        let backend1 = match ProcessBackend::new(pid1) {
            Ok(backend) => backend,
            Err(error) => {
                let _ = child1.kill();
                let _ = child1.wait();
                return Err(error);
            }
        };
        if !backend1.is_alive() {
            let _ = child1.kill();
            let _ = child1.wait();
            return Err(CheatError::NotConnected);
        }
        report.evidence_log.push("Process was alive; no memory write or game behavior was validated".to_string());

        // Terminate run 1
        let _ = child1.kill();
        let _ = child1.wait();
        report.evidence_log.push(format!("Launch 1: terminated PID {}", pid1));
        thread::sleep(Duration::from_millis(100));

        // Launch target process run 2 (Restart verification)
        let mut child2 = spawn_process(target_command)?;
        let pid2 = child2.id();
        report.restart_runs = 1;
        report.evidence_log.push(format!("Launch 2 (Restart): started target game PID {}", pid2));
        thread::sleep(Duration::from_millis(100));

        let backend2 = match ProcessBackend::new(pid2) {
            Ok(backend) => backend,
            Err(error) => {
                let _ = child2.kill();
                let _ = child2.wait();
                return Err(error);
            }
        };
        if backend2.is_alive() {
            report.evidence_log.push("Process restarted, but cheat address persistence and trainer behavior remain unverified".to_string());
        }

        let _ = child2.kill();
        let _ = child2.wait();

        report.evidence_log.push("No cheat write, trainer compilation, or trainer execution was performed in restart test".to_string());

        def.verification.status = "unverified".to_string();
        def.verification.restart_count = 0;
        def.verification.evidence = report.evidence_log.clone();

        Ok(report)
    }
}

fn spawn_process(cmd: &str) -> Result<Child> {
    let parts: Vec<&str> = cmd.split_whitespace().collect();
    if parts.is_empty() {
        return Err(CheatError::InvalidArgument("empty target command".to_string()));
    }
    let mut command = Command::new(parts[0]);
    if parts.len() > 1 {
        command.args(&parts[1..]);
    }
    command.spawn().map_err(|e| CheatError::Internal(format!("Failed to spawn {}: {}", cmd, e)))
}

# Security & Threat Model

## 1. Safety Principles & Policy Enforcement

1. **Default Read-Only:** All tools and scanning operations default to non-invasive memory reads. Memory mutation requires explicit authorization.
2. **Target Scope Restriction:** Cheats and memory operations can only attach to explicitly authorized process identities (PID + image SHA-256 hash matching).
3. **Emergency Stop (Kill Switch):** Immediate atomic suspension of any ongoing memory freeze or mutation workers.
4. **Original Memory Snapshot & Rollback:** Before any mutation is applied, the original memory bytes are snapshotted so they can be restored upon trainer termination.
5. **Untrusted Model Guardrails:** Arguments received from AI models (via MCP or LLM APIs) are treated as untrusted user input. Addresses, sizes, and buffer limits are strictly bounded and validated before passing to native system calls.

---

## 2. Explicit Prohibitions

Cheat Agent is exclusively engineered for authorized offline single-player games, reverse-engineering education, and developer QA testing.

The following capabilities are explicitly banned and will not be implemented:
- Online multiplayer cheating or network packet interception.

## The Core Differentiator: Closed-Loop Verification

Most game manipulation tools stop after an address is written to. In real games, a successful memory write is NOT proof of a working cheat:

namespace {

struct Inventory {
    uint32_t ammo{100};
    uint32_t grenades{5};
    uint32_t padding[6]{};
};

    uint32_t health{100};
    uint32_t armor{50};
    uint32_t score{1250};
    uint32_t pad{0};
    Inventory* inventory{nullptr};
};

    uint64_t map_id{1};

    uint32_t version{1};
    uint32_t pad{0};
    World* world{nullptr};
};

GameManager* g_game_manager = nullptr;
volatile bool g_running = true;

void init_game() {
    auto gm = new GameManager();
    gm->world = new World();
    gm->world->player = new Player();
    gm->world->player->inventory = new Inventory();
    g_game_manager = gm;
}

void relocate_player() {
    if (!g_game_manager || !g_game_manager->world) return;
    auto old_player = g_game_manager->world->player;
    auto new_player = new Player();
    new_player->inventory = new Inventory();

    if (old_player) {
        new_player->health = old_player->health;
        new_player->armor = old_player->armor;
        new_player->score = old_player->score;
        if (old_player->inventory) {
            new_player->inventory->ammo = old_player->inventory->ammo;
            new_player->inventory->grenades = old_player->inventory->grenades;
            delete old_player->inventory;
        }
        delete old_player;
    }

    g_game_manager->world->player = new_player;
}

void print_status_json() {
    if (!g_game_manager || !g_game_manager->world || !g_game_manager->world->player) return;
    auto p = g_game_manager->world->player;
    auto inv = p->inventory;

    std::cout << "{"
              << "\"pid\":" << GET_PID() << ","
              << "\"health\":" << p->health << ","
              << "\"armor\":" << p->armor << ","
              << "\"score\":" << p->score << ","
              << "\"ammo\":" << (inv ? inv->ammo : 0) << ","
              << "\"grenades\":" << (inv ? inv->grenades : 0) << ","
              << "\"root_ptr\":\"0x" << std::hex << reinterpret_cast<uintptr_t>(&g_game_manager) << "\","
              << "\"player_ptr\":\"0x" << reinterpret_cast<uintptr_t>(p) << "\","
              << "\"ammo_ptr\":\"0x" << (inv ? reinterpret_cast<uintptr_t>(&(inv->ammo)) : 0) << "\""
              << std::dec << "}" << std::endl;
}

} // namespace

int main(int argc, char** argv) {
    init_game();

    bool daemon = false;
    for (int i = 1; i < argc; ++i) {
        std::string arg(argv[i]);
        if (arg == "--status") {
            print_status_json();
            return 0;
        } else if (arg == "--fire") {
            if (g_game_manager->world->player->inventory->ammo > 0) {
                g_game_manager->world->player->inventory->ammo--;
            }
            print_status_json();
            return 0;
        } else if (arg == "--damage") {
            if (g_game_manager->world->player->health >= 10) {
                g_game_manager->world->player->health -= 10;
            } else {
                g_game_manager->world->player->health = 0;
            }
            print_status_json();
            return 0;
        } else if (arg == "--daemon") {
            daemon = true;
        }
    }

    if (!daemon) {
        print_status_json();
        return 0;
    }

    // Interactive daemon loop reading commands from stdin
    std::string line;
    print_status_json();

    while (g_running) {
        if (!std::getline(std::cin, line)) {
            // CI and detached launches may provide closed stdin. Keep the
            // controlled test process alive until its parent terminates it.
            std::cin.clear();
            std::this_thread::sleep_for(std::chrono::milliseconds(100));
            continue;
        }
        if (line == "status") {
            print_status_json();
        } else if (line == "fire") {
            if (g_game_manager->world->player->inventory->ammo > 0) {
                g_game_manager->world->player->inventory->ammo--;
            }
            print_status_json();
        } else if (line == "damage") {
            if (g_game_manager->world->player->health >= 10) {
                g_game_manager->world->player->health -= 10;
            } else {
                g_game_manager->world->player->health = 0;
            }
            print_status_json();
        } else if (line == "relocate") {
            relocate_player();
            print_status_json();
        } else if (line == "quit" || line == "exit") {
            break;
        }
    }

    return 0;
}

#include <algorithm>

struct CheatProcessBackend {

struct CheatMemoryScanner {

extern "C" {

int32_t cheat_backend_create(uint32_t pid, CheatProcessBackend** out_backend) {
    if (!out_backend) return CHEAT_STATUS_INVALID_ARGUMENT;
    try {
        auto backend = cheat_agent::IProcessBackend::create(pid);
        if (!backend) return CHEAT_STATUS_ERROR;

        auto wrapper = new CheatProcessBackend();
        wrapper->impl = std::move(backend);
        *out_backend = wrapper;
        return CHEAT_STATUS_OK;
    } catch (...) {
        return CHEAT_STATUS_ERROR;
    }
}

void cheat_backend_destroy(CheatProcessBackend* backend) {
    if (backend) {
        delete backend;
    }
}

int32_t cheat_backend_is_alive(CheatProcessBackend* backend) {
    if (!backend || !backend->impl) return 0;
    return backend->impl->is_alive() ? 1 : 0;
}

uint32_t cheat_backend_get_pid(CheatProcessBackend* backend) {
    if (!backend || !backend->impl) return 0;
    return backend->impl->get_pid();
}

int32_t cheat_backend_read_memory(
    CheatProcessBackend* backend,
    uint64_t address,
    void* buffer,
    size_t size,
    size_t* bytes_read) {

    if (!backend || !backend->impl || !buffer || size == 0) return CHEAT_STATUS_INVALID_ARGUMENT;
    size_t read_count = 0;
    int32_t res = backend->impl->read_memory(address, buffer, size, read_count);
    if (bytes_read) *bytes_read = read_count;
    return res;
}

int32_t cheat_backend_write_memory(
    CheatProcessBackend* backend,
    uint64_t address,
    const void* buffer,
    size_t size,
    size_t* bytes_written) {

    if (!backend || !backend->impl || !buffer || size == 0) return CHEAT_STATUS_INVALID_ARGUMENT;
    size_t written_count = 0;
    int32_t res = backend->impl->write_memory(address, buffer, size, written_count);
    if (bytes_written) *bytes_written = written_count;
    return res;
}

int32_t cheat_backend_query_regions(
    CheatProcessBackend* backend,
    CheatMemoryRegion* out_regions,
    size_t max_regions,
    size_t* count) {

    if (!backend || !backend->impl || !out_regions || max_regions == 0) return CHEAT_STATUS_INVALID_ARGUMENT;
    try {
        auto regions = backend->impl->query_regions();
        size_t n = std::min(max_regions, regions.size());
        for (size_t i = 0; i < n; ++i) {
            out_regions[i].base_address = regions[i].base_address;
            out_regions[i].size = regions[i].size;
            out_regions[i].protection = regions[i].protection;
            out_regions[i].is_writable = regions[i].is_writable ? 1 : 0;
            out_regions[i].is_executable = regions[i].is_executable ? 1 : 0;
        }
        if (count) *count = n;
        return CHEAT_STATUS_OK;
    } catch (...) {
        return CHEAT_STATUS_ERROR;
    }
}

int32_t cheat_backend_query_modules(
    CheatProcessBackend* backend,
    CheatModuleInfo* out_modules,
    size_t max_modules,
    size_t* count) {

    if (!backend || !backend->impl || !out_modules || max_modules == 0) return CHEAT_STATUS_INVALID_ARGUMENT;
    try {
        auto modules = backend->impl->query_modules();
        size_t n = std::min(max_modules, modules.size());
        for (size_t i = 0; i < n; ++i) {
            std::memset(&out_modules[i], 0, sizeof(CheatModuleInfo));
            std::strncpy(out_modules[i].name, modules[i].name.c_str(), sizeof(out_modules[i].name) - 1);
            std::strncpy(out_modules[i].path, modules[i].path.c_str(), sizeof(out_modules[i].path) - 1);
            out_modules[i].base_address = modules[i].base_address;
            out_modules[i].size = modules[i].size;
        }
        if (count) *count = n;
        return CHEAT_STATUS_OK;
    } catch (...) {
        return CHEAT_STATUS_ERROR;

class LinuxProcessBackend final : public IProcessBackend {
public:
    explicit LinuxProcessBackend(uint32_t pid) : pid_(pid) {}
    ~LinuxProcessBackend() override = default;

    [[nodiscard]] bool is_alive() const noexcept override {
        if (pid_ == 0) return false;
        return kill(static_cast<pid_t>(pid_), 0) == 0;
    }

    [[nodiscard]] uint32_t get_pid() const noexcept override {
        return pid_;
    }

    int32_t read_memory(uint64_t address, void* buffer, size_t size, size_t& bytes_read) override {
        bytes_read = 0;
        if (!buffer || size == 0) return CHEAT_STATUS_INVALID_ARGUMENT;

        struct iovec local_iov{};
        local_iov.iov_base = buffer;
        local_iov.iov_len = size;

        struct iovec remote_iov{};
        remote_iov.iov_base = reinterpret_cast<void*>(address);
        remote_iov.iov_len = size;

        ssize_t res = process_vm_readv(static_cast<pid_t>(pid_), &local_iov, 1, &remote_iov, 1, 0);
        if (res < 0) {
            return CHEAT_STATUS_ERROR;
        }

        bytes_read = static_cast<size_t>(res);
        return CHEAT_STATUS_OK;
    }

    int32_t write_memory(uint64_t address, const void* buffer, size_t size, size_t& bytes_written) override {
        bytes_written = 0;
        if (!buffer || size == 0) return CHEAT_STATUS_INVALID_ARGUMENT;

        struct iovec local_iov{};
        local_iov.iov_base = const_cast<void*>(buffer);
        local_iov.iov_len = size;

        struct iovec remote_iov{};
        remote_iov.iov_base = reinterpret_cast<void*>(address);
        remote_iov.iov_len = size;

        ssize_t res = process_vm_writev(static_cast<pid_t>(pid_), &local_iov, 1, &remote_iov, 1, 0);
        if (res < 0) {
            return CHEAT_STATUS_ERROR;
        }

        bytes_written = static_cast<size_t>(res);
        return CHEAT_STATUS_OK;
    }

    std::vector<MemoryRegion> query_regions() override {
        std::vector<MemoryRegion> regions;
        if (pid_ == 0) return regions;

        std::string maps_path = "/proc/" + std::to_string(pid_) + "/maps";
        std::ifstream file(maps_path);
        if (!file.is_open()) return regions;

        std::string line;
        while (std::getline(file, line)) {
            std::istringstream iss(line);
            std::string range, perms;
            if (!(iss >> range >> perms)) continue;

            auto dash = range.find('-');
            if (dash == std::string::npos) continue;

            uint64_t start = std::stoull(range.substr(0, dash), nullptr, 16);
            uint64_t end = std::stoull(range.substr(dash + 1), nullptr, 16);

            MemoryRegion reg{};
            reg.base_address = start;
            reg.size = (end > start) ? (end - start) : 0;
            reg.is_readable = perms.size() > 0 && perms[0] == 'r';
            reg.is_writable = perms.size() > 1 && perms[1] == 'w';
            reg.is_executable = perms.size() > 2 && perms[2] == 'x';

            if (reg.is_readable) {
                regions.push_back(reg);
            }
        }

        return regions;
    }

    std::vector<ModuleInfo> query_modules() override {
        std::vector<ModuleInfo> modules;
        if (pid_ == 0) return modules;

        char exe_buf[1024];
        std::string exe_link = "/proc/" + std::to_string(pid_) + "/exe";
        ssize_t len = readlink(exe_link.c_str(), exe_buf, sizeof(exe_buf) - 1);
        if (len > 0) {
            exe_buf[len] = '\0';
            ModuleInfo main_mod{};
            main_mod.path = exe_buf;
            std::string p(exe_buf);
            auto slash = p.find_last_of('/');
            main_mod.name = (slash != std::string::npos) ? p.substr(slash + 1) : p;

            // Lookup base address from /proc/maps
            auto regions = query_regions();
            if (!regions.empty()) {
                main_mod.base_address = regions[0].base_address;
            }
            modules.push_back(main_mod);
        }

        return modules;
    }

private:
    uint32_t pid_{0};
};

    return std::make_unique<LinuxProcessBackend>(pid);

namespace cheat_agent {

class MacosProcessBackend final : public IProcessBackend {
public:
    explicit MacosProcessBackend(uint32_t pid) : pid_(pid) {
        if (pid_ != 0) {
            kern_return_t kr = task_for_pid(mach_task_self(), static_cast<int>(pid_), &task_);
            if (kr != KERN_SUCCESS) {
                task_ = MACH_PORT_NULL;
            }
        }
    }

    ~MacosProcessBackend() override {
        if (task_ != MACH_PORT_NULL) {
            mach_port_deallocate(mach_task_self(), task_);
            task_ = MACH_PORT_NULL;
        }
    }

    [[nodiscard]] bool is_alive() const noexcept override {
        if (pid_ == 0) return false;
        return kill(static_cast<pid_t>(pid_), 0) == 0;
    }

    [[nodiscard]] uint32_t get_pid() const noexcept override {
        return pid_;
    }

    int32_t read_memory(uint64_t address, void* buffer, size_t size, size_t& bytes_read) override {
        bytes_read = 0;
        if (!buffer || size == 0) return CHEAT_STATUS_INVALID_ARGUMENT;

        if (task_ == MACH_PORT_NULL) {
            // Task port unavailable; return permission error
            return CHEAT_STATUS_PERMISSION_DENIED;
        }

        mach_vm_size_t read_size = 0;
        kern_return_t kr = mach_vm_read_overwrite(
            task_,
            static_cast<mach_vm_address_t>(address),
            static_cast<mach_vm_size_t>(size),
            reinterpret_cast<mach_vm_address_t>(buffer),
            &read_size);

        if (kr != KERN_SUCCESS) {
            return CHEAT_STATUS_ERROR;
        }

        bytes_read = static_cast<size_t>(read_size);
        return CHEAT_STATUS_OK;
    }

    int32_t write_memory(uint64_t address, const void* buffer, size_t size, size_t& bytes_written) override {
        bytes_written = 0;
        if (!buffer || size == 0) return CHEAT_STATUS_INVALID_ARGUMENT;

        if (task_ == MACH_PORT_NULL) {
            return CHEAT_STATUS_PERMISSION_DENIED;
        }

        kern_return_t kr = mach_vm_write(
            task_,
            static_cast<mach_vm_address_t>(address),
            reinterpret_cast<vm_offset_t>(buffer),
            static_cast<mach_msg_type_number_t>(size));

        if (kr != KERN_SUCCESS) {
            return CHEAT_STATUS_ERROR;
        }

        bytes_written = size;
        return CHEAT_STATUS_OK;
    }

    std::vector<MemoryRegion> query_regions() override {
        std::vector<MemoryRegion> regions;
        if (task_ == MACH_PORT_NULL) return regions;

        mach_vm_address_t address = 0;
        mach_vm_size_t size = 0;
        uint32_t depth = 0;
        vm_region_submap_info_data_64_t info{};
        mach_msg_type_number_t count = VM_REGION_SUBMAP_INFO_COUNT_64;

        while (true) {
            kern_return_t kr = mach_vm_region_recurse(
                task_,
                &address,
                &size,
                &depth,
                reinterpret_cast<vm_region_recurse_info_t>(&info),
                &count);

            if (kr != KERN_SUCCESS) break;

            if (info.is_submap) {
                depth++;
                continue;
            }

            MemoryRegion reg{};
            reg.base_address = static_cast<uint64_t>(address);
            reg.size = static_cast<uint64_t>(size);
            reg.is_readable = (info.protection & VM_PROT_READ) != 0;
            reg.is_writable = (info.protection & VM_PROT_WRITE) != 0;
            reg.is_executable = (info.protection & VM_PROT_EXECUTE) != 0;

            if (reg.is_readable) {
                regions.push_back(reg);
            }

            address += size;
        }

        return regions;
    }

    std::vector<ModuleInfo> query_modules() override {
        std::vector<ModuleInfo> modules;
        if (pid_ == 0) return modules;

        char path_buf[PROC_PIDPATHINFO_MAXSIZE];
        if (proc_pidpath(static_cast<int>(pid_), path_buf, sizeof(path_buf)) > 0) {
            ModuleInfo main_mod{};
            main_mod.path = path_buf;
            std::string path_str(path_buf);
            auto slash = path_str.find_last_of('/');
            main_mod.name = (slash != std::string::npos) ? path_str.substr(slash + 1) : path_str;
            main_mod.base_address = 0x100000000ULL; // Standard Mach-O ASLR slide base
            main_mod.size = 0x1000000;
            modules.push_back(main_mod);
        }

        return modules;
    }

private:
    uint32_t pid_{0};
    mach_port_t task_{MACH_PORT_NULL};
};

#include "memory_scanner.hpp"
#include "pattern_scanner.hpp"
#include <cstring>
#include <algorithm>
#include <cmath>

namespace cheat_agent {

namespace {

constexpr size_t kChunkSize = 64 * 1024; // 64 KiB chunks
constexpr size_t kMaxPatternWidth = 4 * 1024; // bounded overlap and progress

template <typename T>
bool compare_typed(const uint8_t* curr_ptr, const uint8_t* prev_ptr, int32_t mode, const void* v1, const void* v2) {
    T curr{};
    std::memcpy(&curr, curr_ptr, sizeof(T));

    T target1{};
    if (v1) std::memcpy(&target1, v1, sizeof(T));

    T target2{};
    if (v2) std::memcpy(&target2, v2, sizeof(T));

    T prev{};
    if (prev_ptr) std::memcpy(&prev, prev_ptr, sizeof(T));

    switch (mode) {
        case CHEAT_SCAN_MODE_EXACT:
            if constexpr (std::is_floating_point_v<T>) {
                return std::abs(curr - target1) < 0.0001;
            } else {
                return curr == target1;
            }
        case CHEAT_SCAN_MODE_UNKNOWN_INITIAL:
            return true;
        case CHEAT_SCAN_MODE_CHANGED:
            if (!prev_ptr) return false;
            if constexpr (std::is_floating_point_v<T>) {
                return std::abs(curr - prev) >= 0.0001;
            } else {
                return curr != prev;
            }
        case CHEAT_SCAN_MODE_UNCHANGED:
            if (!prev_ptr) return false;
            if constexpr (std::is_floating_point_v<T>) {
                return std::abs(curr - prev) < 0.0001;
            } else {
                return curr == prev;
            }
        case CHEAT_SCAN_MODE_INCREASED:
            if (!prev_ptr) return false;
            return curr > prev;
        case CHEAT_SCAN_MODE_DECREASED:
            if (!prev_ptr) return false;
            return curr < prev;
        case CHEAT_SCAN_MODE_RANGE:
            return (curr >= target1 && curr <= target2);
        default:
            return false;
    }
}

} // namespace

MemoryScanner::MemoryScanner(std::shared_ptr<IProcessBackend> backend)
    : backend_(std::move(backend)) {}

void MemoryScanner::reset() {
    candidates_.clear();
}

bool MemoryScanner::compare_values(
    const uint8_t* current,
    const uint8_t* previous,
    int32_t scan_mode,
    const void* val1,
    const void* val2) const {

    switch (data_type_) {
        case CHEAT_DATA_TYPE_INT8:
            return compare_typed<int8_t>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_UINT8:
            return compare_typed<uint8_t>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_INT16:
            return compare_typed<int16_t>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_UINT16:
            return compare_typed<uint16_t>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_INT32:
            return compare_typed<int32_t>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_UINT32:
            return compare_typed<uint32_t>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_INT64:
            return compare_typed<int64_t>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_UINT64:
            return compare_typed<uint64_t>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_FLOAT:
            return compare_typed<float>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_DOUBLE:
            return compare_typed<double>(current, previous, scan_mode, val1, val2);
        case CHEAT_DATA_TYPE_BYTE_ARRAY:
            if (scan_mode == CHEAT_SCAN_MODE_EXACT && val1) {
                return std::memcmp(current, val1, data_size_) == 0;
            }
            if (scan_mode == CHEAT_SCAN_MODE_CHANGED && previous) {
                return std::memcmp(current, previous, data_size_) != 0;
            }
            if (scan_mode == CHEAT_SCAN_MODE_UNCHANGED && previous) {
                return std::memcmp(current, previous, data_size_) == 0;
            }
            return false;
        default:
            return false;
    }
}

int32_t MemoryScanner::first_scan(
    int32_t data_type,
    int32_t scan_mode,
    const void* val1,
    const void* val2,
    size_t val_size) {

    if (!backend_ || !backend_->is_alive()) {
        return CHEAT_STATUS_NOT_CONNECTED;
    }

    reset();
    data_type_ = data_type;

    switch (data_type_) {
        case CHEAT_DATA_TYPE_INT8:
        case CHEAT_DATA_TYPE_UINT8:
            data_size_ = 1;
            break;
        case CHEAT_DATA_TYPE_INT16:
        case CHEAT_DATA_TYPE_UINT16:
            data_size_ = 2;
            break;
        case CHEAT_DATA_TYPE_INT32:
        case CHEAT_DATA_TYPE_UINT32:
        case CHEAT_DATA_TYPE_FLOAT:
            data_size_ = 4;
            break;
        case CHEAT_DATA_TYPE_INT64:
        case CHEAT_DATA_TYPE_UINT64:
        case CHEAT_DATA_TYPE_DOUBLE:
            data_size_ = 8;
            break;
        case CHEAT_DATA_TYPE_BYTE_ARRAY:
        case CHEAT_DATA_TYPE_STRING:
            data_size_ = (val_size > 0) ? val_size : 4;
            break;
        default:
            return CHEAT_STATUS_INVALID_ARGUMENT;
    }

    // The C ABI supplies one declared width for both value pointers.
    // Fail closed before any typed memcpy or byte-array memcmp.
    if (data_size_ == 0 || data_size_ > kMaxPatternWidth)
        return CHEAT_STATUS_INVALID_ARGUMENT;
    if ((val1 || val2) && val_size != data_size_)
        return CHEAT_STATUS_INVALID_ARGUMENT;
    if (scan_mode == CHEAT_SCAN_MODE_RANGE && (!val1 || !val2))
        return CHEAT_STATUS_INVALID_ARGUMENT;
    if (scan_mode == CHEAT_SCAN_MODE_EXACT && !val1)
        return CHEAT_STATUS_INVALID_ARGUMENT;
    if (scan_mode != CHEAT_SCAN_MODE_EXACT &&
        scan_mode != CHEAT_SCAN_MODE_UNKNOWN_INITIAL &&
        scan_mode != CHEAT_SCAN_MODE_RANGE)
        return CHEAT_STATUS_INVALID_ARGUMENT;

    auto regions = backend_->query_regions();
    std::vector<uint8_t> chunk(kChunkSize);

    // Alignment: align to data_size_ or 1
    const size_t step = (data_size_ <= 4) ? data_size_ : 4;

    for (const auto& reg : regions) {
        if (!reg.is_readable || reg.size == 0) continue;

        uint64_t current_addr = reg.base_address;
        if (reg.size > UINT64_MAX - reg.base_address) continue;
        uint64_t end_addr = reg.base_address + reg.size;
        if (reg.size < data_size_) continue;

        while (current_addr <= end_addr - data_size_) {
            size_t bytes_to_read = static_cast<size_t>(std::min<uint64_t>(kChunkSize, end_addr - current_addr));
            size_t bytes_read = 0;

            int32_t res = backend_->read_memory(current_addr, chunk.data(), bytes_to_read, bytes_read);
            if (res != CHEAT_STATUS_OK || bytes_read < data_size_) {
                current_addr += (bytes_to_read > 0) ? bytes_to_read : 4096;
                continue;
            }

            for (size_t offset = 0; offset + data_size_ <= bytes_read; offset += step) {
                const uint8_t* val_ptr = chunk.data() + offset;
                if (compare_values(val_ptr, nullptr, scan_mode, val1, val2)) {
                    CandidateMatch match;
                    match.address = current_addr + offset;
                    match.previous_value.assign(val_ptr, val_ptr + data_size_);
                    candidates_.push_back(std::move(match));

                    if (candidates_.size() >= 500000) {
                        // Cap maximum candidates to 500,000 for bounded memory
                        return CHEAT_STATUS_OK;
                    }
                }
            }

            // Move to the next aligned start address, retaining enough
            // overlap to discover values spanning adjacent scan chunks.
            const size_t advance = ((bytes_read - data_size_) / step + 1) * step;
            current_addr += advance;
        }
    }

    return CHEAT_STATUS_OK;
}

int32_t MemoryScanner::next_scan(
    int32_t scan_mode,
    const void* val1,
    const void* val2,
    size_t val_size) {

    if (!backend_ || !backend_->is_alive()) {
        return CHEAT_STATUS_NOT_CONNECTED;
    }

    if ((val1 || val2) && val_size != data_size_)
        return CHEAT_STATUS_INVALID_ARGUMENT;
    if (scan_mode == CHEAT_SCAN_MODE_EXACT && !val1)
        return CHEAT_STATUS_INVALID_ARGUMENT;
    if (scan_mode == CHEAT_SCAN_MODE_RANGE && (!val1 || !val2))
        return CHEAT_STATUS_INVALID_ARGUMENT;
    if (scan_mode < CHEAT_SCAN_MODE_EXACT || scan_mode > CHEAT_SCAN_MODE_RANGE)
        return CHEAT_STATUS_INVALID_ARGUMENT;

    if (candidates_.empty()) {
        return CHEAT_STATUS_OK;
    }

    std::vector<CandidateMatch> refined;
    refined.reserve(candidates_.size());
    std::vector<uint8_t> current_val(data_size_);

    for (const auto& cand : candidates_) {
        size_t bytes_read = 0;
        int32_t res = backend_->read_memory(cand.address, current_val.data(), data_size_, bytes_read);
        if (res == CHEAT_STATUS_OK && bytes_read == data_size_) {
            if (compare_values(current_val.data(), cand.previous_value.data(), scan_mode, val1, val2)) {
                CandidateMatch m;
                m.address = cand.address;
                m.previous_value = current_val;
                refined.push_back(std::move(m));
            }
        }
    }

    candidates_ = std::move(refined);
    return CHEAT_STATUS_OK;
}

int32_t MemoryScanner::scan_aob(const std::string& pattern_str) {
    if (!backend_ || !backend_->is_alive()) {
        return CHEAT_STATUS_NOT_CONNECTED;
    }

    reset();
    data_type_ = CHEAT_DATA_TYPE_AOB;

    auto parsed_pattern = PatternScanner::parse_pattern(pattern_str);
    if (parsed_pattern.empty() || parsed_pattern.size() > kMaxPatternWidth) {
        return CHEAT_STATUS_INVALID_ARGUMENT;
    }
    data_size_ = parsed_pattern.size();

    auto regions = backend_->query_regions();
    std::vector<uint8_t> chunk(kChunkSize);

    for (const auto& reg : regions) {
        if (!reg.is_readable || reg.size < data_size_) continue;

        uint64_t current_addr = reg.base_address;
        if (reg.size > UINT64_MAX - reg.base_address) continue;
        uint64_t end_addr = reg.base_address + reg.size;

        while (current_addr <= end_addr - data_size_) {
            size_t bytes_to_read = static_cast<size_t>(std::min<uint64_t>(kChunkSize, end_addr - current_addr));
            size_t bytes_read = 0;

            int32_t res = backend_->read_memory(current_addr, chunk.data(), bytes_to_read, bytes_read);
            if (res != CHEAT_STATUS_OK || bytes_read < data_size_) {
                current_addr += (bytes_to_read > 0) ? bytes_to_read : 4096;
                continue;
            }

            auto matches = PatternScanner::scan_buffer(chunk.data(), bytes_read, current_addr, parsed_pattern);
            for (auto addr : matches) {
                CandidateMatch m;
                m.address = addr;
                m.previous_value.assign(chunk.data() + (addr - current_addr),
                                        chunk.data() + (addr - current_addr) + data_size_);
                candidates_.push_back(std::move(m));
            }

            // Step forward allowing overlap for pattern matches across chunk boundary
            current_addr += (bytes_read > data_size_) ? (bytes_read - data_size_) : bytes_read;
        }
    }

    return CHEAT_STATUS_OK;
}

} // namespace cheat_agent

#include "pattern_scanner.hpp"
#include <sstream>
#include <iomanip>
#include <cctype>

namespace cheat_agent {

std::vector<PatternByte> PatternScanner::parse_pattern(const std::string& pattern_str) {
    std::vector<PatternByte> result;
    std::istringstream stream(pattern_str);
    std::string token;

    while (stream >> token) {
        if (token == "?" || token == "??") {
            result.push_back({0, true});
        } else {
            try {
                auto val = static_cast<uint8_t>(std::stoul(token, nullptr, 16));
                result.push_back({val, false});
            } catch (...) {
                // If token cannot be parsed, treat as wildcard
                result.push_back({0, true});
            }
        }
    }
    return result;
}

std::vector<uint64_t> PatternScanner::scan_buffer(
    const uint8_t* buffer,
    size_t buffer_size,
    uint64_t base_address,
    const std::vector<PatternByte>& pattern) {

    std::vector<uint64_t> matches;
    if (pattern.empty() || buffer_size < pattern.size()) {
        return matches;
    }

    const size_t max_idx = buffer_size - pattern.size();
    for (size_t i = 0; i <= max_idx; ++i) {
        bool found = true;
        for (size_t j = 0; j < pattern.size(); ++j) {
            if (!pattern[j].is_wildcard && buffer[i + j] != pattern[j].value) {
                found = false;
                break;
            }
        }
        if (found) {
            matches.push_back(base_address + i);
        }
    }

    return matches;
}

} // namespace cheat_agent

#include "pointer_resolver.hpp"
#include <cstring>
#include <cmath>
#include <algorithm>

namespace cheat_agent {

int32_t PointerResolver::resolve(
    IProcessBackend& backend,
    const CheatPointerChain& chain,
    uint64_t& out_address) {

    uint64_t current = 0;

    if (chain.base_module[0] != '\0') {
        auto modules = backend.query_modules();
        bool found_module = false;
        for (const auto& mod : modules) {
            if (mod.name == chain.base_module) {
                current = mod.base_address + chain.base_offset;
                found_module = true;
                break;
            }
        }
        if (!found_module) {
            return CHEAT_STATUS_NOT_FOUND;
        }
    } else {
        current = chain.base_offset;
    }

    for (size_t i = 0; i < chain.offset_count; ++i) {
        uint64_t ptr_val = 0;
        size_t bytes_read = 0;

        // Support standard 64-bit pointer read
        int32_t res = backend.read_memory(current, &ptr_val, sizeof(uint64_t), bytes_read);
        if (res != CHEAT_STATUS_OK || bytes_read != sizeof(uint64_t) || ptr_val == 0) {
            // Also try 32-bit pointer read fallback
            uint32_t ptr_val32 = 0;
            res = backend.read_memory(current, &ptr_val32, sizeof(uint32_t), bytes_read);
            if (res != CHEAT_STATUS_OK || bytes_read != sizeof(uint32_t) || ptr_val32 == 0) {
                return CHEAT_STATUS_ERROR;
            }
            ptr_val = ptr_val32;
        }

        current = ptr_val + chain.offsets[i];
    }

    out_address = current;
    return CHEAT_STATUS_OK;
}

std::vector<CheatPointerChain> PointerResolver::scan(
    IProcessBackend& backend,
    uint64_t target_address,
    size_t /*max_depth*/,
    int64_t max_offset,
    size_t max_chains) {

    std::vector<CheatPointerChain> results;
    auto modules = backend.query_modules();
    auto regions = backend.query_regions();

    // Map each module address range
    for (const auto& mod : modules) {
        if (mod.size == 0) continue;

        // Read module memory in chunks
        constexpr size_t kChunkSize = 64 * 1024;
        std::vector<uint8_t> buffer(kChunkSize);

        uint64_t cur = mod.base_address;
        uint64_t end = mod.base_address + mod.size;

        while (cur + sizeof(uint64_t) <= end) {
            size_t to_read = static_cast<size_t>(std::min<uint64_t>(kChunkSize, end - cur));
            size_t bytes_read = 0;
            int32_t res = backend.read_memory(cur, buffer.data(), to_read, bytes_read);
            if (res != CHEAT_STATUS_OK || bytes_read < sizeof(uint64_t)) {
                cur += 4096;
                continue;
            }

            for (size_t i = 0; i + sizeof(uint64_t) <= bytes_read; i += 8) {
                uint64_t candidate_ptr = 0;
                std::memcpy(&candidate_ptr, buffer.data() + i, sizeof(uint64_t));

                if (candidate_ptr != 0) {
                    int64_t diff = static_cast<int64_t>(target_address) - static_cast<int64_t>(candidate_ptr);
                    if (diff >= 0 && diff <= max_offset) {
                        CheatPointerChain chain{};
                        std::strncpy(chain.base_module, mod.name.c_str(), sizeof(chain.base_module) - 1);
                        chain.base_offset = (cur + i) - mod.base_address;
                        chain.offsets[0] = diff;
                        chain.offset_count = 1;
                        results.push_back(chain);

                        if (results.size() >= max_chains) {
                            return results;
                        }
                    }
                }
            }

            cur += bytes_read;
        }
    }

    return results;
}

} // namespace cheat_agent

#include "process_backend.hpp"

#if defined(_WIN32)
#include <windows.h>
#include <tlhelp32.h>
#include <psapi.h>
#include <vector>
#include <string>

namespace cheat_agent {

class WindowsProcessBackend final : public IProcessBackend {
public:
    explicit WindowsProcessBackend(uint32_t pid) : pid_(pid) {
        if (pid_ != 0) {
            handle_ = ::OpenProcess(
                PROCESS_VM_READ | PROCESS_VM_WRITE | PROCESS_VM_OPERATION | PROCESS_QUERY_INFORMATION,
                FALSE,
                pid_);
        }
    }

    ~WindowsProcessBackend() override {
        if (handle_ && handle_ != INVALID_HANDLE_VALUE) {
            ::CloseHandle(handle_);
            handle_ = nullptr;
        }
    }

    [[nodiscard]] bool is_alive() const noexcept override {
        if (!handle_ || handle_ == INVALID_HANDLE_VALUE) return false;
        DWORD exit_code = 0;
        if (::GetExitCodeProcess(handle_, &exit_code)) {
            return exit_code == STILL_ACTIVE;
        }
        return false;
    }

    [[nodiscard]] uint32_t get_pid() const noexcept override {
        return pid_;
    }

    int32_t read_memory(uint64_t address, void* buffer, size_t size, size_t& bytes_read) override {
        bytes_read = 0;
        if (!handle_ || !buffer || size == 0) return CHEAT_STATUS_INVALID_ARGUMENT;

        SIZE_T read = 0;
        if (!::ReadProcessMemory(handle_, reinterpret_cast<LPCVOID>(address), buffer, size, &read)) {
            return CHEAT_STATUS_ERROR;
        }

        bytes_read = static_cast<size_t>(read);
        return CHEAT_STATUS_OK;
    }

    int32_t write_memory(uint64_t address, const void* buffer, size_t size, size_t& bytes_written) override {
        bytes_written = 0;
        if (!handle_ || !buffer || size == 0) return CHEAT_STATUS_INVALID_ARGUMENT;

        SIZE_T written = 0;
        if (!::WriteProcessMemory(handle_, reinterpret_cast<LPVOID>(address), buffer, size, &written)) {
            return CHEAT_STATUS_ERROR;
        }

        bytes_written = static_cast<size_t>(written);
        return CHEAT_STATUS_OK;
    }

    std::vector<MemoryRegion> query_regions() override {
        std::vector<MemoryRegion> regions;
        if (!handle_) return regions;

        SYSTEM_INFO si;
        ::GetSystemInfo(&si);

        uint8_t* addr = static_cast<uint8_t*>(si.lpMinimumApplicationAddress);
        uint8_t* max_addr = static_cast<uint8_t*>(si.lpMaximumApplicationAddress);

        MEMORY_BASIC_INFORMATION mbi;
        while (addr < max_addr && ::VirtualQueryEx(handle_, addr, &mbi, sizeof(mbi)) == sizeof(mbi)) {
            if (mbi.State == MEM_COMMIT && !(mbi.Protect & PAGE_NOACCESS) && !(mbi.Protect & PAGE_GUARD)) {
                MemoryRegion reg{};
                reg.base_address = reinterpret_cast<uint64_t>(mbi.BaseAddress);
                reg.size = mbi.RegionSize;
                reg.is_readable = true;
                reg.is_writable = (mbi.Protect & (PAGE_READWRITE | PAGE_WRITECOPY | PAGE_EXECUTE_READWRITE | PAGE_EXECUTE_WRITECOPY)) != 0;
                reg.is_executable = (mbi.Protect & (PAGE_EXECUTE | PAGE_EXECUTE_READ | PAGE_EXECUTE_READWRITE | PAGE_EXECUTE_WRITECOPY)) != 0;
                regions.push_back(reg);
            }
            addr += mbi.RegionSize;
        }

        return regions;
    }

    std::vector<ModuleInfo> query_modules() override {
        std::vector<ModuleInfo> modules;
        if (pid_ == 0) return modules;

        HANDLE snap = ::CreateToolhelp32Snapshot(TH32CS_SNAPMODULE | TH32CS_SNAPMODULE32, pid_);
        if (snap != INVALID_HANDLE_VALUE) {
            MODULEENTRY32W me;
            me.dwSize = sizeof(me);
            if (::Module32FirstW(snap, &me)) {
                do {
                    ModuleInfo info{};
                    char narrow_name[256];
                    ::WideCharToMultiByte(CP_UTF8, 0, me.szModule, -1, narrow_name, sizeof(narrow_name), nullptr, nullptr);
                    char narrow_path[1024];
                    ::WideCharToMultiByte(CP_UTF8, 0, me.szExePath, -1, narrow_path, sizeof(narrow_path), nullptr, nullptr);

                    info.name = narrow_name;
                    info.path = narrow_path;
                    info.base_address = reinterpret_cast<uint64_t>(me.modBaseAddr);
                    info.size = me.modBaseSize;
                    modules.push_back(info);
                } while (::Module32NextW(snap, &me));
            }
            ::CloseHandle(snap);
        }

        return modules;
    }

private:
    uint32_t pid_{0};
    HANDLE handle_{nullptr};
};

std::unique_ptr<IProcessBackend> IProcessBackend::create(uint32_t pid) {
    return std::make_unique<WindowsProcessBackend>(pid);
}

} // namespace cheat_agent
#endif
