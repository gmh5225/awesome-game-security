# StarCraft II for Android — Static Recompilation Toolkit

**FR :** Ce dépôt fournit les **outils et la méthode** pour recompiler statiquement un moteur de jeu x86-32 vers ARM64 natif (Android / Apple Silicon), en s'appuyant sur la vague de recompilation statique assistée par IA de 2026 (pcrecomp). La démonstration cible est StarCraft II (Wings of Liberty, 2010) sur Android — mais **ce dépôt ne contient AUCUN code du jeu ni aucun asset**.

**EN:** This repository provides the **tooling and methodology** to statically recompile an x86-32 game engine to native ARM64 (Android / Apple Silicon), building on the 2026 AI-assisted static recompilation wave (pcrecomp). The showcase target is StarCraft II (Wings of Liberty, 2010) on Android — but **this repository contains NO game code and NO assets**.

| `tools/mpq/` | **MPQ extract & list (StormLib), hardened against the partial-block EOF trap**: `SFileReadFile` returns FALSE + `ERROR_HANDLE_EOF` *with bytes read* on a final partial read — the naive `while (SFileReadFile(...) && nb > 0)` loop silently truncates any non-multiple of the 64 KiB buffer and empties anything smaller. `mpqget` = size-checked extraction (rc 0 ⟺ total == catalog size), `mpqlist` = full `(listfile)` read + `--tailles` catalog sizes. / **Extraction & listing MPQ (StormLib), durcis contre le piège EOF de bloc partiel** : `SFileReadFile` rend FALSE + `ERROR_HANDLE_EOF` *avec des octets lus* sur la dernière lecture partielle — la boucle naïve `while (SFileReadFile(...) && nb > 0)` tronque silencieusement tout non-multiple du tampon 64 KiB et vide tout fichier plus petit. `mpqget` = extraction à taille vérifiée, `mpqlist` = lecture complète du `(listfile)` + `--tailles` (tailles du catalogue). |
| `tools/pcrecomp-closure/` | **Incremental closure extension for pcrecomp**: lifts only the functions missing from an existing lifted closure (roots + recursive direct-dispatch targets in `.text`), no global relift; self-contained PE32 reader. / **Extension incrémentale de closure** : ne lifte que les fonctions manquantes (racines + cibles directes récursives), sans relift global. |

| `scripts/video-transcode.sh` | **Local cinematic transcoder for hardware video decode**: turns the `.ogv` (Theora) files of *your own* install into H.264 Baseline `.mp4` siblings (or a parallel tree), one H.264 frame per Theora packet so frame *n* stays frame *n*; consumed by the runtime's optional AMediaCodec path (`SC2_VIDEO_AMC=1`). / **Transcodeur local des cinématiques pour le décodage vidéo matériel** : convertit les `.ogv` de *votre* installation en `.mp4` H.264 Baseline, une image par paquet Theora. |
| `docs/METHOD.md` | The end-to-end methodology: PE analysis → lift (CPU-struct model) → host runtime → headless Vulkan backend → per-function differential testing. / La méthodologie de bout en bout. |

# Method: AI-assisted static recompilation of an x86-32 game to native ARM64

This document describes the end-to-end methodology we validated on a 2010
DirectX 9 title (15.7 MB x86-32 executable, 86,650 discovered functions).
It assumes you work **on your own legitimate copy of the game**; every derived
artifact is generated locally on your machine.

## 1. Inventory and extraction (over your own copy)
- Identify the disc/archive formats. 2010 Blizzard installers use
  stream-encrypted MPQ (`.MPQE`); the decryption keys are published by the
  publisher itself (see StormLib's `FileStream.cpp`, STREAM_PROVIDER_MPQE).
  [StormLib](https://github.com/ladislav-zezula/StormLib) (OSS) reads them
  via the `mpqe-file:` prefix.
- Inventory every file (type, size, hash) before touching anything.

## 2. Static analysis
- Import the executable into Ghidra headless (bounded memory: `Xmx12g` +
  cgroup). Triage mechanically (cheap models / scripts): entry point, CRT,
  import table, string table, section map.
- Build the boot map: entry → CRT init → WinMain → fiber/game-main → the
  game's own staged init. Names like "Must run from the launcher" tell you
  exactly where the launch-chain checks live.

## 3. Lift to portable C (CPU-struct model)
- Use [pcrecomp](https://github.com/sp00nznet/pcrecomp)'s pipeline:
  `pe_analyze` → `disasm32` (recursive descent) → `lift32_cpu`.
- The CPU-struct model (explicit `CPU *c` state, all memory accesses through
  `rd*/wr*` helpers) is **reentrant and multi-thread friendly** — this is the
  single most important architectural choice for later parallelism.
- Expect ~1 line of C per byte of machine code for large titles (86k functions
  → ~400 MB of C here). Compile it as a normal host program: the same source
  builds on x86-64 Linux, Apple Silicon macOS, and aarch64 Android.

## 4. Host runtime ("fake Win32")
- Implement what the engine actually calls: fibers (host `ucontext` or
  threads), a 32-bit handle table, TLS/TEB, the import table (IAT) with
  traced stubs, file layer over your extracted install, MPQ access via
  StormLib.
- **Key trick for hosts without fixed low mappings (macOS/Android)**: reserve
  one anonymous host region for the whole guest address space and make every
  guest-VA access go through a single relocatable macro (`GPTR(va) = base +
  va`). Because the CPU-struct model funnels ALL memory accesses through one
  pair of helpers, this is a ~30-line change.

## 5. Rendering: D3D9 → Vulkan headless first
- Start with a **headless Vulkan device** (Lavapipe on CI/dev machines):
  implement the IDirect3D9/Device9 surface the engine traces (Clear,
  BeginScene/EndScene, Present) and dump the backbuffer to PPM after frames.
  "921,600 non-black pixels" is a milestone you can actually measure.
- Then translate the game's real shaders offline (dump the shader cache from
  the data files, translate bytecode → GLSL → SPIR-V, embed as built-ins —
  the NFSU2-recompiled approach), and light up real draws.

## 6. The oracle: per-function differential testing (this toolkit)
- `runner-difftest.c`: links every lifted function (X-macro table), takes a
  binary state blob (GPRs, flags, x87, SSE, guest memory windows) on stdin,
  executes ONE function, dumps the resulting state.
- `difftest-sc2.py`: generates seeded random states, replays the ORIGINAL
  bytes of the same function in **Unicorn** (the hardware reference) until
  the frame's `ret`, simulating the return so ESP matches the lifted model;
  diffs every register, the arithmetic flags, and every byte Unicorn wrote.
- Functions whose flow leaves `.text` (import calls) are skipped by design —
  deterministic comparisons only.
- Run it as a continuous campaign (one report JSON per batch); classify the
  failures (convention artifacts vs real semantic divergences) and bisect the
  real ones per-instruction.
- Known convention artifacts to mask: DF is not modelled by the runtime;
  AF after fcompi diverges benignly; only compare CF/PF/ZF/SF/OF (0x8C5).

## 7. Android packaging
- Cross-compile the runtime with the NDK (aarch64-linux-android, clang),
  link `libvulkan.so`, wrap in a NativeActivity (minSdk 26, arm64-v8a),
  full-screen landscape. Ship the data via `adb push` to app storage; point
  the file layer at it (one environment variable).
- Touch → mouse for v1; gamepad/DeX later. Keep the exit path clean (your
  runtime should dump its BILAN/summary on quit — invaluable for field logs).

## 8. Cadence and supervision
- Two heavyweight agent sessions in parallel max per machine; a heartbeat
  cron that wakes when NOTHING advances (idle-stable is a stall, not peace);
  a written coordination bus between agent sessions; milestones posted with
  proof (trace excerpts, pixel counts, byte-exact rates).
- Lessons from the public wave (Heumann, NFSU2): the oracle comes BEFORE the
  volume; throwing away bad code is cheaper than fixing it; correctness
  outranks productivity.

# Android Porting Kit (bionic) — fibres & arena-delta helpers

Original support code for running a **statically recompiled x86 game runtime**
inside an Android app process (NDK r28, arm64-v8a). Generic: no game content.

| File | Role |
|---|---|
| `sc2_ucontext_aarch64.S` + `sc2_ucontext.c` + `sc2_ucontext_offsets.h` | User-space context switching (makecontext/swapcontext equivalents) for **bionic**, which ships no `<ucontext.h>`: assembly save/restore of callee-saved regs + stack pivot, driven by a `ucontext_t`-layout struct. Used to host the recomp runtime's fibers on Android. |
| `cpu_delta.cmake` | CMake function that **generates at configure time** a patched copy of the recomp runtime's `cpu.h` whose 32-bit atomics (`lock xadd`, `lock cmpxchg`, `xchg`) go through the guest-pointer macro (`GPTR`) instead of raw addresses — required as soon as the guest arena is *relocated* (delta mode) instead of fixed-mapped. Self-checking: warns if the expected 3 patch sites are not found. |
| `sc2_vk_presente.c` + `sc2_vk_presente.h` | **GPU swapchain presenter**: link-time interposition (`--wrap=dlsym`) on the Vulkan loader that adds `VK_KHR_surface` + `VK_KHR_android_surface` (phone) / `VK_KHR_xcb_surface` (headless bench) to the instance, creates a swapchain on the app's `ANativeWindow` with its own present queue, and blits the engine's back buffer into it (GPU scaling, aspect-ratio preserved, black bars, FIFO). Emits `[VKP]` logcat diagnostics. No game content, no engine code touched — pure Vulkan glue. |

## Note: `VK_KHR_push_descriptor` on emulators

The D3D9→Vulkan backend's *real-draw* path currently requires
`VK_KHR_push_descriptor`. Desktop Lavapipe (Mesa ≥ 22) and Adreno GPUs expose it;
**neither emulator GPU does** (SwiftShader software *and* host-Apple-M4 through
the emulator's Vulkan translation layer both omit it), so on an emulator the
engine falls back to a degenerate pipeline and the screen stays black while the
engine itself runs fine. A classic-descriptor fallback (pool + sets + updates)
is the known fix. Verified on an Android 14 arm64 emulator (Apple M4 host):
engine boots to the game main loop, 1,800+ frames presented, game data streamed.


## Why "delta mode"?

The recompiled runtime expects its guest memory at a fixed virtual address. A
fixed mapping is impossible inside an Android app process (the ART heap and
ASLR occupy the low 4 GB), so the arena is allocated anywhere **4 GB-aligned**
and every guest access goes through `GPTR(x) = (uint8_t*)(x) + g_host_delta`.
`cpu_delta.cmake` exists because the stock atomics bypassed that macro.

# cpu_delta.cmake — copie de recomp-sc2/runtime/cpu.h dont les atomiques respectent g_hote_delta
# (passe 7a). Le fichier d'origine n'est PAS modifié (zone de la passe 5d) : la copie est générée
# dans le dossier de build et incluse de force APRÈS sc2_lifted.h ; sa garde PCRECOMP_CPU_H rend
# l'#include "cpu.h" des sources sans effet.
#
# Défaut corrigé : atomic_xadd32 / atomic_cmpxchg32 / atomic_xchg32 (lock xadd, lock cmpxchg, xchg)
# déréférencent la VA invitée BRUTE — (volatile uint32_t *)(uintptr_t)a — au lieu de GPTR(a).
# Juste tant que g_hote_delta = 0 (Linux, arène à adresse fixe) ; faux dès que la zone invitée est
# décalée (macOS, Android). Quand la passe 5d l'aura corrigé en amont, 0 remplacement : copie
# identique, rien à retirer.
function(sc2_cpu_delta R SORTIE)
    set(src "${R}/runtime/cpu.h")
    set_property(DIRECTORY APPEND PROPERTY CMAKE_CONFIGURE_DEPENDS "${src}")
    file(READ "${src}" t)
    string(REPLACE "(volatile uint32_t *)(uintptr_t)a" "(volatile uint32_t *)GPTR(a)" p "${t}")
    string(LENGTH "${t}" l0)
    string(REGEX MATCHALL "volatile uint32_t \\*\\)GPTR\\(a\\)" n "${p}")
    list(LENGTH n nb)
    file(MAKE_DIRECTORY "${CMAKE_BINARY_DIR}/cpu-delta")
    file(WRITE "${CMAKE_BINARY_DIR}/cpu-delta/cpu.h.tmp" "/* GÉNÉRÉ par android/cmake/cpu_delta.cmake depuis ${src} — ne pas éditer */\n${p}")
    file(COPY_FILE "${CMAKE_BINARY_DIR}/cpu-delta/cpu.h.tmp" "${CMAKE_BINARY_DIR}/cpu-delta/cpu.h" ONLY_IF_DIFFERENT)
    message(STATUS "cpu.h delta-propre : ${nb} atomique(s) sur GPTR (attendu 3) → ${CMAKE_BINARY_DIR}/cpu-delta/cpu.h")
    if(NOT nb EQUAL 3)
        message(WARNING "cpu.h : ${nb} atomiques GPTR au lieu de 3 — vérifier runtime/cpu.h (forme changée ?)")
    endif()
    set(${SORTIE} "${CMAKE_BINARY_DIR}/cpu-delta/cpu.h" PARENT_SCOPE)
endfunction()

#include <stddef.h>
#include <stdint.h>
#include "compat/sc2_android_compat.h"
#include "sc2_ucontext_offsets.h"

_Static_assert(offsetof(ucontext_t, uc_link) == UC_LINK, "uc_link");
_Static_assert(offsetof(ucontext_t, uc_mcontext.regs) == UC_REGS, "regs");
_Static_assert(offsetof(ucontext_t, uc_mcontext.sp) == UC_SP, "sp");
_Static_assert(offsetof(ucontext_t, uc_mcontext.pc) == UC_PC, "pc");
_Static_assert(offsetof(ucontext_t, uc_mcontext.__reserved) == UC_FPR, "__reserved");

void sc2_ucontext_fin(void);

/* Comme la glibc : la fonction démarre sur uc_stack avec au plus 8 arguments entiers (x0..x7) ;
 * à son retour, sc2_ucontext_fin reprend uc_link (ou termine le processus). */
void makecontext(ucontext_t *ucp, void (*fn)(void), int argc, ...)
{
    uintptr_t sp = ((uintptr_t)ucp->uc_stack.ss_sp + ucp->uc_stack.ss_size) & ~(uintptr_t)15;
    va_list ap;
    va_start(ap, argc);
    for (int i = 0; i < argc && i < 8; i++) ucp->uc_mcontext.regs[i] = va_arg(ap, uint64_t);
    va_end(ap);
    ucp->uc_mcontext.regs[19] = (uint64_t)(uintptr_t)ucp->uc_link;
    ucp->uc_mcontext.regs[29] = 0;                               /* fin de la chaîne de cadres */
    ucp->uc_mcontext.regs[30] = (uint64_t)(uintptr_t)sc2_ucontext_fin;
    ucp->uc_mcontext.sp = sp;
    ucp->uc_mcontext.pc = (uint64_t)(uintptr_t)fn;
}

/* sc2_ucontext_aarch64.S — getcontext / setcontext / swapcontext pour bionic AArch64 (passe 7a).
 *
 * Bionic n'en fournit aucune ; runtime/win32_compat.c (fibres Win32) en a besoin. Seul l'état

 * appel de fonction, l'appelant a déjà rangé le reste. Le masque de signaux n'est PAS commuté
 * (il est le même pour toutes les fibres d'un thread ; économise un appel système par
 * SwitchToFiber). x18 (registre plate-forme, shadow call stack) n'est jamais touché.
 */
#include "sc2_ucontext_offsets.h"

    .text
    .p2align 4

/* Range l'état callee-saved de l'appelant dans le contexte x0 ; reprise = retour de l'appel avec 0. */
.macro SAUVER
    stp x19, x20, [x0, #UC_REGS + 19*8]
    stp x21, x22, [x0, #UC_REGS + 21*8]
    stp x23, x24, [x0, #UC_REGS + 23*8]
    stp x25, x26, [x0, #UC_REGS + 25*8]
    stp x27, x28, [x0, #UC_REGS + 27*8]
    stp x29, x30, [x0, #UC_REGS + 29*8]
    str xzr,      [x0, #UC_REGS + 0]       /* x0 à la reprise : 0 */
    mov x9, sp
    str x9,       [x0, #UC_SP]
    str x30,      [x0, #UC_PC]             /* reprise : juste après l'appel */
    add x10, x0, #UC_FPR                   /* stp : décalage immédiat ≤ 504 */
    stp d8,  d9,  [x10, #0]
    stp d10, d11, [x10, #16]
    stp d12, d13, [x10, #32]
    stp d14, d15, [x10, #48]
.endm

    .globl getcontext
    .type  getcontext, %function
getcontext:
    SAUVER
    mov x0, #0
    ret
    .size getcontext, . - getcontext

    .globl setcontext
    .type  setcontext, %function
setcontext:
    mov x9, x0
    add x10, x9, #UC_FPR
    ldp d8,  d9,  [x10, #0]
    ldp d10, d11, [x10, #16]
    ldp d12, d13, [x10, #32]
    ldp d14, d15, [x10, #48]
    ldp x19, x20, [x9, #UC_REGS + 19*8]
    ldp x21, x22, [x9, #UC_REGS + 21*8]
    ldp x23, x24, [x9, #UC_REGS + 23*8]
    ldp x25, x26, [x9, #UC_REGS + 25*8]
    ldp x27, x28, [x9, #UC_REGS + 27*8]
    ldp x29, x30, [x9, #UC_REGS + 29*8]
    ldr x10,      [x9, #UC_SP]
    mov sp, x10
    ldr x16,      [x9, #UC_PC]
    ldp x0, x1,   [x9, #UC_REGS + 0]       /* arguments posés par makecontext (x0..x7) */
    ldp x2, x3,   [x9, #UC_REGS + 16]
    ldp x4, x5,   [x9, #UC_REGS + 32]
    ldp x6, x7,   [x9, #UC_REGS + 48]
    br  x16
    .size setcontext, . - setcontext

    .globl swapcontext
    .type  swapcontext, %function
swapcontext:
    SAUVER
    mov x0, x1
    b   setcontext
    .size swapcontext, . - swapcontext

/* Retour de la fonction d'un contexte makecontext : x19 = uc_link (posé par makecontext). */
    .globl sc2_ucontext_fin
    .hidden sc2_ucontext_fin
    .type  sc2_ucontext_fin, %function
sc2_ucontext_fin:
    cbz x19, 1f
    mov x0, x19
    b   setcontext
1:  mov x0, #0
    bl  exit                               /* comme la glibc : uc_link NULL → fin du processus */
    brk #0
    .size sc2_ucontext_fin, . - sc2_ucontext_fin

    .section .note.GNU-stack, "", %progbits

 * (SC2_SWAPCHAIN, option CMake) et active (SC2_SWAPCHAIN=1 dans l'environnement). Le backend
 * D3D9→Vulkan (recomp-sc2/runtime/sc2_d3d9v.c, hors de la zone de cette passe) n'est PAS modifié :
 * on s'insère entre lui et le chargeur Vulkan.
 *
 *   --wrap=dlsym       dlsym(lib, "vkGetInstanceProcAddr") rend notre gipa, qui interpose :
 *     vkCreateInstance   + VK_KHR_surface + VK_KHR_android_surface (téléphone) / VK_KHR_xcb_surface (banc, Xvfb)

static VKAPI_ATTR VkResult VKAPI_CALL m_CreateInstance(const VkInstanceCreateInfo *ci, const VkAllocationCallbacks *al,
                                                       VkInstance *out)
{
    PFN_vkEnumerateInstanceExtensionProperties enumi =
        (PFN_vkEnumerateInstanceExtensionProperties)r_gipa(NULL, "vkEnumerateInstanceExtensionProperties");
    VkExtensionProperties e[128]; uint32_t n = 128;
    if (!enumi || enumi(NULL, &n, e) < 0) n = 0;
    const char *ext[64]; uint32_t k = 0;
    for (uint32_t i = 0; i < ci->enabledExtensionCount && k < 60; i++) ext[k++] = ci->ppEnabledExtensionNames[i];
    int ok = ext_presente(e, n, VK_KHR_SURFACE_EXTENSION_NAME) && ext_presente(e, n, EXT_SURFACE_PLATEFORME);
    if (!ok) {
        char l[1024] = ""; size_t o = 0;
        for (uint32_t i = 0; i < n && o < sizeof l - 80; i++) o += (size_t)snprintf(l + o, sizeof l - o, " %s", e[i].extensionName);
        sc2_log("[VKP] instance : %s et/ou %s absentes du chargeur — swapchain indisponible (annoncées :%s)",
                VK_KHR_SURFACE_EXTENSION_NAME, EXT_SURFACE_PLATEFORME, l);
    }
    if (ok) { ext[k++] = VK_KHR_SURFACE_EXTENSION_NAME; ext[k++] = EXT_SURFACE_PLATEFORME; }
    VkInstanceCreateInfo c2 = *ci; c2.enabledExtensionCount = k; c2.ppEnabledExtensionNames = ext;
    VkResult r = r_CreateInstance(&c2, al, out);
    if (r && ok) { sc2_log("[VKP] instance refusée avec les extensions de surface (%d) : sans swapchain", (int)r); ok = 0;
                   r = r_CreateInstance(ci, al, out); }
    if (!r && ok) {
        P.inst = *out; P.inst_ok = 1;
#define CHG_I(f) p_##f = (PFN_##f)r_gipa(P.inst, #f);
        VKI(CHG_I)
#ifdef __ANDROID__
        p_vkCreateAndroidSurfaceKHR = (PFN_vkCreateAndroidSurfaceKHR)r_gipa(P.inst, "vkCreateAndroidSurfaceKHR");
#else

}

static VKAPI_ATTR VkResult VKAPI_CALL m_CreateDevice(VkPhysicalDevice pd, const VkDeviceCreateInfo *ci,
                                                     const VkAllocationCallbacks *al, VkDevice *out)
{
    if (!P.inst_ok || ci->queueCreateInfoCount != 1) return r_CreateDevice(pd, ci, al, out);
    VkExtensionProperties e[512]; uint32_t n = 512;
    if (p_vkEnumerateDeviceExtensionProperties(pd, NULL, &n, e) < 0) n = 0;
    if (!ext_presente(e, n, VK_KHR_SWAPCHAIN_EXTENSION_NAME)) {
        sc2_log("[VKP] device sans %s : présentation par copie CPU", VK_KHR_SWAPCHAIN_EXTENSION_NAME);
        return r_CreateDevice(pd, ci, al, out);
    }
    const char *ext[64]; uint32_t k = 0;
    for (uint32_t i = 0; i < ci->enabledExtensionCount && k < 63; i++) ext[k++] = ci->ppEnabledExtensionNames[i];
    ext[k++] = VK_KHR_SWAPCHAIN_EXTENSION_NAME;
    VkDeviceQueueCreateInfo q = ci->pQueueCreateInfos[0];
    VkQueueFamilyProperties qp[16]; uint32_t nq = 16;
    p_vkGetPhysicalDeviceQueueFamilyProperties(pd, &nq, qp);
    static const float prio[2] = { 1.f, 1.f };
    int deux = q.queueCount == 1 && q.queueFamilyIndex < nq && qp[q.queueFamilyIndex].queueCount >= 2;
    if (deux) { q.queueCount = 2; q.pQueuePriorities = prio; }
    VkDeviceCreateInfo c2 = *ci; c2.enabledExtensionCount = k; c2.ppEnabledExtensionNames = ext; c2.pQueueCreateInfos = &q;
    VkResult r = r_CreateDevice(pd, &c2, al, out);
    if (r) { sc2_log("[VKP] device refusé avec %s (%d) : copie CPU", VK_KHR_SWAPCHAIN_EXTENSION_NAME, (int)r);
             return r_CreateDevice(pd, ci, al, out); }
    P.pd = pd; P.dev = *out; P.qf = q.queueFamilyIndex; P.file_propre = deux;
#define CHG_D(f) p_##f = (PFN_##f)r_gdpa(P.dev, #f);
    VKD(CHG_D)
    p_vkGetDeviceQueue(P.dev, P.qf, deux ? 1 : 0, &P.q);
    VkCommandPoolCreateInfo pci = { .sType = VK_STRUCTURE_TYPE_COMMAND_POOL_CREATE_INFO,
                                    .flags = VK_COMMAND_POOL_CREATE_RESET_COMMAND_BUFFER_BIT, .queueFamilyIndex = P.qf };
    VkSemaphoreCreateInfo sci = { .sType = VK_STRUCTURE_TYPE_SEMAPHORE_CREATE_INFO };
    VkFenceCreateInfo fci = { .sType = VK_STRUCTURE_TYPE_FENCE_CREATE_INFO };
    if (p_vkCreateCommandPool(P.dev, &pci, NULL, &P.pool) || p_vkCreateSemaphore(P.dev, &sci, NULL, &P.acq) ||
        p_vkCreateSemaphore(P.dev, &sci, NULL, &P.fin) || p_vkCreateFence(P.dev, &fci, NULL, &P.fence)) return r;
    VkCommandBufferAllocateInfo ai = { .sType = VK_STRUCTURE_TYPE_COMMAND_BUFFER_ALLOCATE_INFO, .commandPool = P.pool,
                                       .level = VK_COMMAND_BUFFER_LEVEL_PRIMARY, .commandBufferCount = 1 };
    if (p_vkAllocateCommandBuffers(P.dev, &ai, &P.cb)) return r;
    P.dev_ok = 1;
    sc2_log("[VKP] device : %s ajoutée ; file de présentation %s (famille %u)", VK_KHR_SWAPCHAIN_EXTENSION_NAME,
            deux ? "PROPRE (n°1)" : "PARTAGÉE avec le backend (famille à une seule file)", P.qf);
    return r;
}

}
static VKAPI_ATTR void VKAPI_CALL m_DestroyImage(VkDevice d, VkImage img, const VkAllocationCallbacks *al)

}

void *__real_dlsym(void *h, const char *nom);

{
    void *f = __real_dlsym(h, nom);
    if (!f || !nom || strcmp(nom, "vkGetInstanceProcAddr")) return f;
    const char *e = getenv("SC2_SWAPCHAIN");

    const char *k = getenv("SC2_SWAPCHAIN_CONTROLE");
    P.controle = k && *k == '1';
    if (!P.voulu) return f;
    r_gipa = (PFN_vkGetInstanceProcAddr)f;

}

int __real_d3dv_cible(uint64_t cle, uint32_t w, uint32_t h, uint32_t fmt, int profondeur);

    int id = __real_d3dv_cible(cle, w, h, fmt, profondeur);
    /* une texture créée par un autre fil entre-temps n'aurait pas les dimensions de la cible */
    if (id >= 0 && id < 256 && !profondeur && P.derniere && P.derniere_w == w && P.derniere_h == h) {
        P.c[id].img = P.derniere; P.c[id].w = w; P.c[id].h = h; P.c[id].fmt = P.derniere_fmt;
    }
    return id;
}

int sc2v_actif(void) { return P.voulu && P.inst_ok && P.dev_ok; }

static void swapchain_liberer(void)      /* sous g_mu */
{
    if (P.q) p_vkQueueWaitIdle(P.q);
    if (P.sc) { p_vkDestroySwapchainKHR(P.dev, P.sc, NULL); P.sc = VK_NULL_HANDLE; }
    P.nimg = 0;
}
static void surface_liberer(void)        /* sous g_mu */
{
    swapchain_liberer();
    if (P.surf) { p_vkDestroySurfaceKHR(P.inst, P.surf, NULL); P.surf = VK_NULL_HANDLE; }
}

void sc2v_fenetre(void *fenetre, uint32_t w, uint32_t h)
{
    pthread_mutex_lock(&g_mu);
    if (P.inst_ok && P.dev_ok) surface_liberer();       /* l'ancienne fenêtre n'est plus utilisable */
    P.fenetre = fenetre; P.fw = w; P.fh = h; P.fenetre_changee = 1;
    pthread_mutex_unlock(&g_mu);
}

static int surface_creer(void)           /* sous g_mu */
{
    VkResult r;
#ifdef __ANDROID__
    VkAndroidSurfaceCreateInfoKHR si = { .sType = VK_STRUCTURE_TYPE_ANDROID_SURFACE_CREATE_INFO_KHR,
                                         .window = (ANativeWindow *)P.fenetre };
    r = p_vkCreateAndroidSurfaceKHR ? p_vkCreateAndroidSurfaceKHR(P.inst, &si, NULL, &P.surf) : VK_ERROR_EXTENSION_NOT_PRESENT;
#else
    if (!g_xcb) {                                         /* fenêtre X de P.fw × P.fh sur $DISPLAY */
        void *x = dlopen("libxcb.so.1", RTLD_NOW);
        xcb_connection_t *(*conn)(const char *, int *) = x ? dlsym(x, "xcb_connect") : NULL;
        if (!conn) { sc2_log("[VKP] libxcb.so.1 introuvable"); return -1; }
        const void *(*setup)(xcb_connection_t *) = dlsym(x, "xcb_get_setup");
        xcb_screen_iterator_t (*racines)(const void *) = dlsym(x, "xcb_setup_roots_iterator");
        uint32_t (*nid)(xcb_connection_t *) = dlsym(x, "xcb_generate_id");
        xcb_void_cookie_t (*creer)(xcb_connection_t *, uint8_t, uint32_t, uint32_t, int16_t, int16_t, uint16_t, uint16_t,
                                   uint16_t, uint16_t, uint32_t, uint32_t, const void *) = dlsym(x, "xcb_create_window");
        xcb_void_cookie_t (*montrer)(xcb_connection_t *, uint32_t) = dlsym(x, "xcb_map_window");
        int (*vider)(xcb_connection_t *) = dlsym(x, "xcb_flush");
        int (*erreur)(xcb_connection_t *) = dlsym(x, "xcb_connection_has_error");
        int ecran = 0;
        xcb_connection_t *c = conn(NULL, &ecran);
        if (!c || erreur(c)) { sc2_log("[VKP] xcb_connect(DISPLAY=%s) : échec", getenv("DISPLAY") ? getenv("DISPLAY") : "(vide)"); return -1; }
        xcb_screen_t *sc = racines(setup(c)).data;
        g_xwin = nid(c);
        creer(c, 0, g_xwin, sc->root, 0, 0, (uint16_t)P.fw, (uint16_t)P.fh, 0, 1, sc->root_visual, 0, NULL);
        montrer(c, g_xwin); vider(c);
        g_xcb = c;
        sc2_log("[VKP] banc : fenêtre X 0x%X de %ux%u sur DISPLAY=%s (écran %ux%u)", g_xwin, P.fw, P.fh,
                getenv("DISPLAY"), sc->width_in_pixels, sc->height_in_pixels);
    }
    sc2_VkXcbSurfaceCreateInfoKHR si = { .sType = (VkStructureType)1000005000 /* XCB_SURFACE_CREATE_INFO_KHR */,
                                         .connection = g_xcb, .window = g_xwin };
    r = p_vkCreateXcbSurfaceKHR ? p_vkCreateXcbSurfaceKHR(P.inst, &si, NULL, &P.surf) : VK_ERROR_EXTENSION_NOT_PRESENT;
#endif
    if (r) { sc2_log("[VKP] création de la surface : échec %d", (int)r); P.surf = VK_NULL_HANDLE; return -1; }
    VkBool32 ok = 0;
    p_vkGetPhysicalDeviceSurfaceSupportKHR(P.pd, P.qf, P.surf, &ok);
    if (!ok) { sc2_log("[VKP] la famille %u ne peut pas présenter sur cette surface", P.qf); surface_liberer(); return -1; }
    return 0;
}

static int swapchain_creer(void)         /* sous g_mu */
{
    VkSurfaceCapabilitiesKHR cap;
    if (p_vkGetPhysicalDeviceSurfaceCapabilitiesKHR(P.pd, P.surf, &cap)) return -1;
    VkExtent2D e = cap.currentExtent;
    if (e.width == 0xFFFFFFFFu) { e.width = P.fw ? P.fw : 1280; e.height = P.fh ? P.fh : 720; }
    if (!e.width || !e.height) return -1;                 /* fenêtre réduite */
    VkSurfaceFormatKHR f[32]; uint32_t nf = 32;
    p_vkGetPhysicalDeviceSurfaceFormatsKHR(P.pd, P.surf, &nf, f);
    VkSurfaceFormatKHR choix = nf ? f[0] : (VkSurfaceFormatKHR){ VK_FORMAT_R8G8B8A8_UNORM, VK_COLOR_SPACE_SRGB_NONLINEAR_KHR };
    for (uint32_t i = 0; i < nf; i++)                    /* UNORM : le back buffer D3D9 n'est pas sRGB */
        if (f[i].format == VK_FORMAT_R8G8B8A8_UNORM || f[i].format == VK_FORMAT_B8G8R8A8_UNORM) { choix = f[i]; break; }
    VkImageUsageFlags u = VK_IMAGE_USAGE_TRANSFER_DST_BIT;
    if (P.controle && (cap.supportedUsageFlags & VK_IMAGE_USAGE_TRANSFER_SRC_BIT)) u |= VK_IMAGE_USAGE_TRANSFER_SRC_BIT;
    if (!(cap.supportedUsageFlags & VK_IMAGE_USAGE_TRANSFER_DST_BIT)) { sc2_log("[VKP] swapchain sans TRANSFER_DST"); return -1; }
    uint32_t n = cap.minImageCount + 1;
    if (cap.maxImageCount && n > cap.maxImageCount) n = cap.maxImageCount;
    VkCompositeAlphaFlagBitsKHR ca = VK_COMPOSITE_ALPHA_OPAQUE_BIT_KHR;
    if (!(cap.supportedCompositeAlpha & ca)) ca = VK_COMPOSITE_ALPHA_INHERIT_BIT_KHR;
    /* Rotation laissée au compositeur (IDENTITY) : l'image n'a pas à être tournée par nous. */
    VkSurfaceTransformFlagBitsKHR tr = (cap.supportedTransforms & VK_SURFACE_TRANSFORM_IDENTITY_BIT_KHR)
                                       ? VK_SURFACE_TRANSFORM_IDENTITY_BIT_KHR : cap.currentTransform;
    VkSwapchainCreateInfoKHR ci = { .sType = VK_STRUCTURE_TYPE_SWAPCHAIN_CREATE_INFO_KHR, .surface = P.surf,
        .minImageCount = n, .imageFormat = choix.format, .imageColorSpace = choix.colorSpace, .imageExtent = e,
        .imageArrayLayers = 1, .imageUsage = u, .imageSharingMode = VK_SHARING_MODE_EXCLUSIVE, .preTransform = tr,
        .compositeAlpha = ca, .presentMode = VK_PRESENT_MODE_FIFO_KHR, .clipped = VK_TRUE, .oldSwapchain = P.sc };
    VkSwapchainKHR sc;
    VkResult r = p_vkCreateSwapchainKHR(P.dev, &ci, NULL, &sc);
    if (P.sc) p_vkDestroySwapchainKHR(P.dev, P.sc, NULL);
    P.sc = VK_NULL_HANDLE;
    if (r) { sc2_log("[VKP] vkCreateSwapchainKHR : échec %d", (int)r); return -1; }
    P.sc = sc; P.ext = e; P.sfmt = choix.format;
    P.nimg = 8; p_vkGetSwapchainImagesKHR(P.dev, P.sc, &P.nimg, P.img);
    P.a_refaire = 0;
    sc2_log("[VKP] swapchain %ux%u, format %d, %u images, FIFO", e.width, e.height, (int)choix.format, P.nimg);
    return 0;
}

static void barriere_img(VkImage img, VkImageLayout de, VkImageLayout vers, VkAccessFlags sa, VkAccessFlags da)
{
    VkImageMemoryBarrier b = { .sType = VK_STRUCTURE_TYPE_IMAGE_MEMORY_BARRIER, .srcAccessMask = sa, .dstAccessMask = da,
        .oldLayout = de, .newLayout = vers, .srcQueueFamilyIndex = VK_QUEUE_FAMILY_IGNORED,
        .dstQueueFamilyIndex = VK_QUEUE_FAMILY_IGNORED, .image = img,
        .subresourceRange = { VK_IMAGE_ASPECT_COLOR_BIT, 0, 1, 0, 1 } };
    p_vkCmdPipelineBarrier(P.cb, VK_PIPELINE_STAGE_ALL_COMMANDS_BIT, VK_PIPELINE_STAGE_ALL_COMMANDS_BIT, 0, 0, NULL, 0, NULL, 1, &b);
}

/* Banc : tampon de relecture de l'image de swapchain (contrôle du blit et des bandes). */
static int relecture_prete(VkDeviceSize taille)
{
    if (P.rbt >= taille) return 0;
    VkBufferCreateInfo bi = { .sType = VK_STRUCTURE_TYPE_BUFFER_CREATE_INFO, .size = taille,
                              .usage = VK_BUFFER_USAGE_TRANSFER_DST_BIT };
    if (p_vkCreateBuffer(P.dev, &bi, NULL, &P.rb)) return -1;
    VkMemoryRequirements mr; p_vkGetBufferMemoryRequirements(P.dev, P.rb, &mr);
    VkPhysicalDeviceMemoryProperties mp; p_vkGetPhysicalDeviceMemoryProperties(P.pd, &mp);
    uint32_t t = 0;
    for (; t < mp.memoryTypeCount; t++)
        if ((mr.memoryTypeBits & (1u << t)) && (mp.memoryTypes[t].propertyFlags & (VK_MEMORY_PROPERTY_HOST_VISIBLE_BIT |
            VK_MEMORY_PROPERTY_HOST_COHERENT_BIT)) == (VK_MEMORY_PROPERTY_HOST_VISIBLE_BIT | VK_MEMORY_PROPERTY_HOST_COHERENT_BIT)) break;
    VkMemoryAllocateInfo ai = { .sType = VK_STRUCTURE_TYPE_MEMORY_ALLOCATE_INFO, .allocationSize = mr.size, .memoryTypeIndex = t };
    if (t == mp.memoryTypeCount || p_vkAllocateMemory(P.dev, &ai, NULL, &P.rbm)) return -1;
    p_vkBindBufferMemory(P.dev, P.rb, P.rbm, 0);
    p_vkMapMemory(P.dev, P.rbm, 0, taille, 0, &P.rbp);
    P.rbt = taille;
    return 0;
}

int sc2v_presenter(int id, unsigned n)
{
    if (!sc2v_actif() || id < 0 || id >= 256 || !P.c[id].img) return -1;
    pthread_mutex_lock(&g_mu);
    int rc = -1;
    static VkFormat verifie; static int blit_ok;
    if (verifie != P.c[id].fmt) {                            /* le blit exige BLIT_SRC sur le format du back buffer */
        VkFormatProperties fp; p_vkGetPhysicalDeviceFormatProperties(P.pd, P.c[id].fmt, &fp);
        blit_ok = !!(fp.optimalTilingFeatures & VK_FORMAT_FEATURE_BLIT_SRC_BIT);
        verifie = P.c[id].fmt;
        if (!blit_ok) sc2_log("[VKP] format %d du back buffer sans BLIT_SRC : copie CPU", (int)verifie);
    }
    if (!blit_ok) goto fin;
    if (!P.fenetre && !P.fw) goto fin;                       /* pas de fenêtre : rien à présenter */
    if (!P.surf && surface_creer()) goto fin;
    if ((!P.sc || P.a_refaire) && swapchain_creer()) goto fin;

    uint32_t k;
    VkResult r = p_vkAcquireNextImageKHR(P.dev, P.sc, 1000000000ull, P.acq, VK_NULL_HANDLE, &k);
    if (r == VK_ERROR_OUT_OF_DATE_KHR) { P.a_refaire = 1; goto fin; }
    if (r && r != VK_SUBOPTIMAL_KHR) { sc2_log("[VKP] vkAcquireNextImageKHR : %d", (int)r); goto fin; }
    if (r == VK_SUBOPTIMAL_KHR) P.a_refaire = 1;

    /* rectangle de destination : rapport du back buffer conservé, centré (bandes noires) */
    uint32_t sw = P.c[id].w, sh = P.c[id].h, dw = P.ext.width, dh = P.ext.height, rw, rh;
    if ((uint64_t)dw * sh >= (uint64_t)dh * sw) { rh = dh; rw = (uint32_t)((uint64_t)sw * dh / sh); }
    else { rw = dw; rh = (uint32_t)((uint64_t)sh * dw / sw); }
    int32_t ox = (int32_t)(dw - rw) / 2, oy = (int32_t)(dh - rh) / 2;

    VkImage dst = P.img[k];
    p_vkResetCommandBuffer(P.cb, 0);
    VkCommandBufferBeginInfo bi = { .sType = VK_STRUCTURE_TYPE_COMMAND_BUFFER_BEGIN_INFO,
                                    .flags = VK_COMMAND_BUFFER_USAGE_ONE_TIME_SUBMIT_BIT };
    p_vkBeginCommandBuffer(P.cb, &bi);
    barriere_img(dst, VK_IMAGE_LAYOUT_UNDEFINED, VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL, 0, VK_ACCESS_TRANSFER_WRITE_BIT);
    VkClearColorValue noir = { .float32 = { 0, 0, 0, 1 } };
    VkImageSubresourceRange sr = { VK_IMAGE_ASPECT_COLOR_BIT, 0, 1, 0, 1 };
    p_vkCmdClearColorImage(P.cb, dst, VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL, &noir, 1, &sr);
    barriere_img(dst, VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL, VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL,
                 VK_ACCESS_TRANSFER_WRITE_BIT, VK_ACCESS_TRANSFER_WRITE_BIT);
    VkImageBlit bl = { .srcSubresource = { VK_IMAGE_ASPECT_COLOR_BIT, 0, 0, 1 },
                       .srcOffsets = { { 0, 0, 0 }, { (int32_t)sw, (int32_t)sh, 1 } },
                       .dstSubresource = { VK_IMAGE_ASPECT_COLOR_BIT, 0, 0, 1 },
                       .dstOffsets = { { ox, oy, 0 }, { ox + (int32_t)rw, oy + (int32_t)rh, 1 } } };
    /* Le back buffer est en GENERAL (backend 5c/5d) et le backend a attendu sa file : lisible. */
    p_vkCmdBlitImage(P.cb, P.c[id].img, VK_IMAGE_LAYOUT_GENERAL, dst, VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL, 1, &bl, VK_FILTER_LINEAR);
    /* mêmes frames que les PPM du backend (1, 10, 100, 200…) : comparaison canal par canal */
    int relire = P.controle && (n == 1 || n == 10 || n % 100 == 0) && !relecture_prete((VkDeviceSize)dw * dh * 4);
    if (relire) {
        barriere_img(dst, VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL, VK_IMAGE_LAYOUT_TRANSFER_SRC_OPTIMAL,
                     VK_ACCESS_TRANSFER_WRITE_BIT, VK_ACCESS_TRANSFER_READ_BIT);
        VkBufferImageCopy bc = { .imageSubresource = { VK_IMAGE_ASPECT_COLOR_BIT, 0, 0, 1 }, .imageExtent = { dw, dh, 1 } };
        p_vkCmdCopyImageToBuffer(P.cb, dst, VK_IMAGE_LAYOUT_TRANSFER_SRC_OPTIMAL, P.rb, 1, &bc);
        barriere_img(dst, VK_IMAGE_LAYOUT_TRANSFER_SRC_OPTIMAL, VK_IMAGE_LAYOUT_PRESENT_SRC_KHR, VK_ACCESS_TRANSFER_READ_BIT, 0);
    } else
        barriere_img(dst, VK_IMAGE_LAYOUT_TRANSFER_DST_OPTIMAL, VK_IMAGE_LAYOUT_PRESENT_SRC_KHR, VK_ACCESS_TRANSFER_WRITE_BIT, 0);
    p_vkEndCommandBuffer(P.cb);

    VkPipelineStageFlags ps = VK_PIPELINE_STAGE_TRANSFER_BIT;
    VkSubmitInfo si = { .sType = VK_STRUCTURE_TYPE_SUBMIT_INFO, .waitSemaphoreCount = 1, .pWaitSemaphores = &P.acq,
                        .pWaitDstStageMask = &ps, .commandBufferCount = 1, .pCommandBuffers = &P.cb,
                        .signalSemaphoreCount = 1, .pSignalSemaphores = &P.fin };
    p_vkResetFences(P.dev, 1, &P.fence);
    if ((r = p_vkQueueSubmit(P.q, 1, &si, P.fence))) { sc2_log("[VKP] vkQueueSubmit : %d", (int)r); goto fin; }
    VkPresentInfoKHR pi = { .sType = VK_STRUCTURE_TYPE_PRESENT_INFO_KHR, .waitSemaphoreCount = 1, .pWaitSemaphores = &P.fin,
                            .swapchainCount = 1, .pSwapchains = &P.sc, .pImageIndices = &k };
    r = p_vkQueuePresentKHR(P.q, &pi);
    /* le blit doit avoir lu le back buffer avant que le backend ne le réécrive */
    p_vkWaitForFences(P.dev, 1, &P.fence, VK_TRUE, 2000000000ull);
    if (r == VK_ERROR_OUT_OF_DATE_KHR || r == VK_SUBOPTIMAL_KHR) P.a_refaire = 1;
    else if (r) { sc2_log("[VKP] vkQueuePresentKHR : %d", (int)r); goto fin; }
    P.presentes++;
    if (P.presentes == 1) sc2_log("[VKP] 1re frame présentée par la swapchain (back buffer %ux%u → %ux%u en (%d, %d), image %ux%u)",
                                  sw, sh, rw, rh, ox, oy, dw, dh);
    if (relire) {
        /* moyennes R, G, B de l'image (rectangle du blit) et des bandes : contrôle du banc. Ordre des
         * octets selon le format de la swapchain (B8G8R8A8 : B, G, R). */
        const uint8_t *p = P.rbp; uint64_t sc[3] = { 0, 0, 0 }, sb = 0, ni = 0, nb = 0;
        int bgr = P.sfmt == VK_FORMAT_B8G8R8A8_UNORM || P.sfmt == VK_FORMAT_B8G8R8A8_SRGB;
        for (uint32_t y = 0; y < dh; y += 2) for (uint32_t x = 0; x < dw; x += 2) {
            const uint8_t *q = p + ((size_t)y * dw + x) * 4;
            int dedans = (int32_t)x >= ox && x < (uint32_t)ox + rw && (int32_t)y >= oy && y < (uint32_t)oy + rh;
            if (dedans) { sc[0] += q[bgr ? 2 : 0]; sc[1] += q[1]; sc[2] += q[bgr ? 0 : 2]; ni++; }
            else { sb += q[0] + q[1] + q[2]; nb++; }
        }
        sc2_log("[VKP] contrôle frame n°%u : image de swapchain %ux%u, moyenne RGB de l'image %.2f %.2f %.2f, bandes %.2f (%s)",
                n, dw, dh, ni ? (double)sc[0] / ni : 0, ni ? (double)sc[1] / ni : 0, ni ? (double)sc[2] / ni : 0,
                nb ? (double)sb / (3.0 * nb) : 0, nb ? "bandes présentes" : "pas de bandes");
    }
    rc = 0;
fin:
    if (rc) P.echecs++;
    pthread_mutex_unlock(&g_mu);
    return rc;
}

void sc2v_bilan(char *o, size_t cap)
{
    snprintf(o, cap, "swapchain %s : %llu frames présentées par le GPU, %llu repli(s) sur la copie CPU",
             sc2v_actif() ? "active" : P.voulu ? "DEMANDÉE mais indisponible" : "inactive",
             (unsigned long long)P.presentes, (unsigned long long)P.echecs);
}

#!/usr/bin/env python3
"""extraire-audio-imports.py — inventaire des imports AUDIO de SC2.exe et table C de l'API FMOD Ex (passe 5e).

    scripts/extraire-audio-imports.py <sc2_imports.h> <sortie.h> [--tsv <inventaire.tsv>]

SC2.exe (build 15405) joue son son par FMOD Ex 4.28.08 (fmodex_4_28_08.dll) : 129 imports,
pour l'essentiel des méthodes C++ décorées MSVC (« ?init@System@FMOD@@QAG?AW4FMOD_RESULT@@HIPAX@Z »,
QAG = public __stdcall : `this` est le 1er argument sur la pile, l'appelé dépile). Le script
décode chaque nom décoré pour en tirer, sans aucun en-tête FMOD :
  - le nombre de MOTS de 32 bits à dépiler (this compris ; double = 2 mots) ;
  - la nature de chaque paramètre : valeur ('v'), double ('d'), pointeur d'entrée ('p'),
    pointeur de SORTIE vers un scalaire ('o', octets écrits), pointeur de sortie vers un objet
    FMOD ('O' : Sound**, Channel**…), chaîne ('s'), rappel ('f').
Le runtime (runtime/sc2_audio_fmod.c) s'en sert pour un FMOD sûr par défaut : chaque sortie
reçoit une valeur neutre ou un objet neuf, chaque appel est compté — avant les méthodes réelles.
Les imports DSOUND (par ordinal) et WINMM (mixer) sont listés dans l'inventaire.
"""
import re, sys

PRIM4 = set('CDEFGHIJKM')


class Lecteur:
    def __init__(self, s):
        self.s, self.i, self.backrefs = s, 0, []

    def c(self):
        return self.s[self.i]

    def nom(self):                              # fragments jusqu'à '@' final
        parts = []
        while self.c() != '@':
            if self.c().isdigit():
                parts.append(f'#{self.c()}'); self.i += 1
            else:
                j = self.s.index('@', self.i); parts.append(self.s[self.i:j]); self.i = j + 1
        self.i += 1
        return '::'.join(reversed(parts))

    def type(self):
        """→ (genre, taille, détail). genre : v valeur, d double, p pointeur, X void, F fonction."""
        d = self.i
        c = self.c()
        if c.isdigit():                         # référence arrière à un type d'argument
            self.i += 1
            return self.backrefs[int(c)]
        if c == 'X':
            self.i += 1; return ('X', 0, 'void')
        if c in PRIM4:
            self.i += 1; return ('v', 4, {'M': 'float', 'H': 'int', 'I': 'unsigned', 'D': 'char', 'C': 'signed char',
                                          'E': 'unsigned char', 'F': 'short', 'G': 'unsigned short'}.get(c, c))
        if c in 'NO':
            self.i += 1; return ('d', 8, 'double')
        if c == '_':
            k = self.s[self.i + 1]; self.i += 2
            return ('v', 8, 'int64') if k in 'JK' else ('v', 4, {'N': 'bool', 'W': 'wchar_t'}.get(k, '_' + k))
        if c == '?' and self.s[self.i + 1] == 'A':
            self.i += 2; return self.type()
        if c == 'W':
            self.i += 2                         # W4
            n = self.nom(); return ('v', 4, 'enum ' + n)
        if c in 'UV':
            self.i += 1; n = self.nom(); return ('v', 4, 'struct ' + n)
        if c in 'PQRS':
            if self.s[self.i + 1] == '6':       # pointeur de fonction
                self.i += 3                     # P6 + convention
                self.type()                     # retour
                self.params()                   # arguments, jusqu'à Z
                t = ('f', 4, 'rappel')
            else:
                cv = self.s[self.i + 1]; self.i += 2
                cible = self.type()
                t = ('p', 4, ('const ' if cv == 'B' else '') + cible[2] + '*', cible)
            if self.i - d > 1:
                self._ref(t)
            return t
        raise ValueError(f'type inconnu {c!r} dans {self.s} @ {self.i}')

    def _ref(self, t):
        if len(self.backrefs) < 10:
            self.backrefs.append(t)

    def params(self):
        if self.c() == 'X':
            self.i += 2 if self.s[self.i + 1] == 'Z' else 1
            return []
        out = []
        while self.c() != '@' and self.c() != 'Z':
            d = self.i
            t = self.type()
            if self.i - d > 1 and t not in self.backrefs and t[0] != 'p' and t[0] != 'f':
                self._ref(t)
            out.append(t)
        self.i += 1                             # '@' (puis 'Z') ou 'Z'
        if self.i < len(self.s) and self.s[self.i] == 'Z':
            self.i += 1
        return out


def nature(t):
    g = t[0]
    if g == 'd': return 'd'
    if g == 'f': return 'f'
    if g != 'p': return 'v'
    cible = t[3]
    if t[2] in ('const char*', 'const wchar_t*'):
        return 's'
    if t[2].startswith('const '):
        return 'p'
    if cible[0] == 'p' and cible[3][2].startswith('struct '):
        return 'O'                              # Sound**, Channel**… : objet FMOD rendu
    if cible[0] in 'vd' and not cible[2].startswith('struct') and cible[2] not in ('char', 'wchar_t'):
        return 'o'                              # int* float* bool* enum* : scalaire rendu
    return 'p'                                  # tampon, structure, void* : entrée/sortie à traiter au cas par cas


def decoder(nom):
    m = re.match(r'\?(\w+)@(\w+)@FMOD@@QAG\?AW4FMOD_RESULT@@(.*)$', nom)
    if not m:
        m2 = re.match(r'_(\w+)@(\d+)$', nom)
        if m2:
            return m2.group(1), '', int(m2.group(2)) // 4, 'v' * (int(m2.group(2)) // 4), []
        return None
    meth, cls, reste = m.groups()
    L = Lecteur(reste)
    ps = L.params()
    mots = 1 + sum(2 if p[0] == 'd' else 1 for p in ps)
    nat = ''.join(nature(p) for p in ps)
    return f'{cls}::{meth}', cls, mots, nat, ps


def main():
    src, out = sys.argv[1], sys.argv[2]
    tsv = sys.argv[sys.argv.index('--tsv') + 1] if '--tsv' in sys.argv else None
    imports = re.findall(r'X\(0x([0-9A-F]+)u, "([^"]+)", "([^"]+)"\)', open(src).read())
    lignes, table = [], []
    for va, dll, nom in imports:
        d = dll.lower()
        if not (d.startswith('fmodex') or d == 'dsound.dll' or d == 'winmm.dll'):
            continue
        if d.startswith('fmodex'):
            r = decoder(nom)
            if r is None:
                raise SystemExit(f'nom non décodé : {nom}')
            court, cls, mots, nat, ps = r
            table.append((nom, court, mots, nat))
            sig = ', '.join(p[2] for p in ps)
            lignes.append(f'0x{va}\t{dll}\t{court}({sig})\t{mots}\t{nat}\t{nom}')
        else:
            lignes.append(f'0x{va}\t{dll}\t{nom}\t\t\t{nom}')
    with open(out, 'w') as f:
        f.write('/* sc2_audio_fmod_table.h — GÉNÉRÉ par scripts/extraire-audio-imports.py (passe 5e) : ne pas éditer.\n'
                ' * Les imports fmodex_4_28_08.dll de SC2.exe, décodés depuis leurs noms décorés MSVC :\n'
                ' *   mots   = mots de 32 bits dépilés par l\'appelé (stdcall ; `this` compris)\n'
                ' *   nature = un caractère par paramètre (après this) : v valeur, d double, p pointeur\n'
                ' *            d\'entrée, s chaîne, f rappel, o sortie scalaire, O sortie objet FMOD */\n')
        f.write(f'#define SC2_FMOD_NB {len(table)}\n')
        f.write('static const struct { const char *nom, *court; int mots; const char *nature; } SC2_FMOD[SC2_FMOD_NB] = {\n')
        for nom, court, mots, nat in table:

        f.write('};\n')
        f.write('/* un trampoline par import : le dispatcher d\'imports ne transmet pas leur identité */\n')

        with open(tsv, 'w') as f:
            f.write('iat\tdll\tsignature décodée\tmots\tnature\tnom décoré\n' + '\n'.join(lignes) + '\n')
    print(f'{len(table)} imports FMOD décodés, {len(lignes) - len(table)} DSOUND/WINMM → {out}')

#!/usr/bin/env python3
"""extraire-audio-stats.py — vérification d'un WAV produit par SC2_AUDIO_DUMP (passe 5e).

    scripts/extraire-audio-stats.py <fichier.wav> [--secondes]

Rend : format, durée, taille, échantillons non nuls, crête, saturations (|x| = 32767),
entropie de Shannon des ÉCHANTILLONS 16 bits (bits/échantillon : 0 pour un silence parfait),
entropie des octets du fichier, et (option) l'énergie RMS par seconde — un son réel n'est
ni un aplat ni un bruit uniforme.
"""
import math, struct, sys
from collections import Counter


def main():
    p = sys.argv[1]
    d = open(p, 'rb').read()
    if d[:4] != b'RIFF' or d[8:16] != b'WAVEfmt ':
        print('pas un WAV RIFF'); sys.exit(1)
    fmt, nch, rate, _, _, bits = struct.unpack_from('<HHIIHH', d, 20)
    data = d[44:44 + struct.unpack_from('<I', d, 40)[0]]
    n = len(data) // 2
    s = struct.unpack(f'<{n}h', data[:2 * n])
    nz = sum(1 for x in s if x)
    crete = max((abs(x) for x in s), default=0)
    sat = sum(1 for x in s if abs(x) >= 32767)

    def entropie(c, total):
        return max(0.0, -sum(v / total * math.log2(v / total) for v in c.values())) if total else 0.0
    h_ech = entropie(Counter(s), n)
    h_oct = entropie(Counter(d), len(d))
    print(f'{p}')
    print(f'  format {fmt} (1 = PCM), {nch} canaux, {rate} Hz, {bits} bits ; durée {n / nch / rate:.2f} s ; {len(d)} octets')
    print(f'  échantillons non nuls {nz} / {n} ({100 * nz / max(n, 1):.1f} %) ; crête {crete} ; saturés {sat}')
    print(f'  entropie : échantillons {h_ech:.3f} bits, octets du fichier {h_oct:.3f} bits/octet')
    if '--secondes' in sys.argv:
        par = rate * nch
        lig = []
        for k in range(0, n, par):
            b = s[k:k + par]
            rms = math.sqrt(sum(x * x for x in b) / len(b)) if b else 0
            lig.append(f'{k // par:3d}s {rms:7.0f}')
        print('  RMS par seconde :')
        for i in range(0, len(lig), 6):
            print('    ' + '   '.join(lig[i:i + 6]))


if __name__ == '__main__':
    main()

# D3D9 Shader Bytecode → SPIR-V (offline translator)

Generic toolchain to translate **Direct3D 9 shader model 2.0/3.0 bytecode** into
**SPIR-V**, offline. Written for a static-recompilation project; contains no game
content — it operates on data each user supplies from their own copy.

## Components

| File | Role |
|---|---|
| `d3d9sm.py` | SM2/3 bytecode decoder: version, instructions, dcl/def/defi/defb, source/dest parameters (mask, swizzle, modifiers, relative addressing), CTAB. |
| `d3d9-vers-spirv.py` | Full translator: bytecode → GLSL 450 → `glslangValidator` → `spirv-val` → embedded SPIR-V table indexed by FNV-1a 64 of the bytecode. |
| `extraire-shaders.py` | Extractor for precompiled shader caches: scans any blob for `vs_/ps_` version tokens, validates instruction-by-instruction, dedupes by hash, emits an index TSV. |
| `ppm-blocs.py` | PPM frame metric: 16×16 block averages, counts distinct blocks (render-regression detector). |
| `ppm2png.py` | PPM (P6) → PNG in pure stdlib (`zlib` + `struct`, optional brightness gain) — dependency-free proof captures from bench runs. |

## Usage

```sh
# 1) extract distinct bytecodes from a precompiled shader cache blob
python3 extraire-shaders.py <cache.bin> out-dir/

# 2) translate every dumped shader and build the embedded table
python3 d3d9-vers-spirv.py out-dir/boot out-dir/sc2_shaders_spv.h --glsl /tmp/glsl

# 3) measure a rendered frame (how many distinct 16x16 blocks?)
python3 ppm-blocs.py frame_00010.ppm
```

Dependencies: Python 3 (stdlib only) + `glslangValidator` (glslang-tools) +
`spirv-val` (spirv-tools).

## Proven results (on our own copy, headless Vulkan/Lavapipe)

- 75,797 distinct bytecodes extracted from a 141 MB precompiled cache (91% of the
  full cache decoded to GLSL);
- 202/202 boot shaders translated and **validated by `spirv-val`**;
- 5,771 real draws executed with those SPIR-V modules — the game's title screen
  renders on the recompiled runtime (2,570 distinct 16×16 blocks on frame 10 vs
  1 flat black before).

#!/usr/bin/env python3
"""d3d9-vers-spirv.py — traduction HORS-LIGNE des shaders D3D9 (SM 2.x/3.0) de SC2 en SPIR-V (passe 5d).

    scripts/d3d9-vers-spirv.py <dossier de .bin> <sortie.h> [--glsl <dossier>] [--liste hash,…]

Chaque bytecode (vs_<hash>.bin / ps_<hash>.bin, hash = FNV-1a 64 du bytecode, celui du
runtime) → GLSL 450 → glslangValidator -V → spirv-val. Les traductions VALIDÉES sont
embarquées dans <sortie.h> (table SC2_SHADERS_SPV, clé = hash), avec leurs métadonnées
d'interface. Une instruction non gérée (prédicats, call/label, boucles loop…) → shader
NON traduit, listé dans le rapport : le runtime garde alors le draw « lumière ».

Interface commune (doit rester alignée sur runtime/sc2_d3d9v.c) :
  set 0 binding 0  UBO constantes VS : vec4 c[256] ; ivec4 i[16] ; ivec4 b[16]   (std140)
  set 0 binding 1  UBO constantes PS : même structure
  set 0 binding 2+n  sampler n du PS (2D / cube / 3D selon dcl)
  push constants   VS : vec4 hp (correction demi-pixel D3D9, 1/L, 1/H) ;
                   PS (offset 16) : vec4 at (test alpha : actif, fonction D3DCMP, référence)
  entrées VS       location = n° du registre v ; (usage, index) dans les métadonnées
  varyings         location fixe par (usage, index) : color i → i, texcoord i → 2+i, fog → 10,
                   normal → 11, tangent → 12, binormal → 13, autres → 14 ; le VS les déclare
                   TOUTES (16, à zéro par défaut) pour que tout PS trouve ses entrées.
  y : gl_Position.y inversé (repère Vulkan) ; z D3D9 [0,1] = Vulkan.
"""
import hashlib, os, struct, subprocess, sys, tempfile

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import d3d9sm as sm

NVARY = 16


def slot_varying(usage, idx):
    u = sm.USAGES[usage] if usage < len(sm.USAGES) else ''
    if u == 'color':
        return idx if idx < 2 else None
    if u == 'texcoord':
        return 2 + idx if idx < 8 else None
    return {'fog': 10, 'normal': 11, 'tangent': 12, 'binormal': 13}.get(u, 14)


class NonGere(Exception):
    pass


class Traducteur:
    def __init__(self, code):
        self.ps, self.ver, self.ins, self.com = sm.decoder(code)
        if self.ver[0] < 2:
            raise NonGere('SM1')
        self.defs = {}           # c n → vec4 littéral
        self.defi, self.defb = {}, {}
        self.entrees = []        # VS : (reg, usage, idx) ; PS : (reg, usage, idx)
        self.sorties = {}        # VS SM3 : reg o → (usage, idx)
        self.samplers = {}       # n → 2 / 3 / 4
        self.temps, self.lignes = set(), []
        self.utilise_a0 = False
        self.entrees_t = []
        self.indent = 1

    # ---- noms --------------------------------------------------------------
    def reg(self, p, ecriture=False):
        t, n = p.type, p.num
        if t == sm.TEMP:
            self.temps.add(n); return f'r{n}'
        if t == sm.INPUT:
            return f'v{n}'
        if t == sm.CONST:
            if p.rel is not None:
                self.utilise_a0 = True
                rc = 'xyzw'[p.rel.swz & 3]
                base = 'aL' if p.rel.type == sm.LOOP else f'a{p.rel.num}.{rc}'
                return f'K.c[clamp({base} + {n}, 0, 255)]'
            if n in self.defs and not ecriture:
                return f'k{n}'
            return f'K.c[{n}]'
        if t == sm.ADDR:
            if self.ps:
                if self.ver[0] >= 3:
                    raise NonGere('registre t en ps_3')
                return f't{n}'                          # ps_2_x : coordonnées de texture n
            self.utilise_a0 = True; return f'a{n}'
        if t == sm.RASTOUT:
            if n == 0: return 'oPos'
            raise NonGere('oFog/oPts')
        if t == sm.ATTROUT:
            return f'ov[{n}]'                       # SM2 oD n → color n
        if t == sm.OUTPUT:
            if self.ver[0] >= 3:
                return f'o{n}'
            return f'ov[{2 + n}]'                   # SM2 oT n → texcoord n
        if t == sm.COLOROUT:
            return f'oC{n}'
        if t == sm.DEPTHOUT:
            return 'oDepth'
        if t == sm.MISC:
            if n == 0: return 'vPos'
            if n == 1: return 'vFace'
        if t == sm.CONSTINT:
            return f'K.i[{n}]' if n not in self.defi else f'ki{n}'
        if t == sm.CONSTBOOL:
            return f'K.b[{n}]' if n not in self.defb else f'kb{n}'
        if t == sm.LOOP:
            return 'aL'
        if t == sm.SAMPLER:
            return f's{n}'
        raise NonGere(f'registre type {t}')

    def source(self, s, scalaire=False):
        r = self.reg(s)
        if s.type in (sm.CONSTINT,):
            r = f'vec4({r})'
        elif s.type == sm.MISC and s.num == 1:
            r = 'vec4(vFace)'
        elif s.type == sm.ADDR or s.type == sm.LOOP:
            r = f'vec4({r})'
        sw = ''.join('xyzw'[(s.swz >> (2 * k)) & 3] for k in range(4))
        e = r if sw == 'xyzw' else f'{r}.{sw}'
        m = s.smod
        e = {0: e, 1: f'(-{e})', 2: f'({e} - 0.5)', 3: f'(-({e} - 0.5))', 4: f'({e} * 2.0 - 1.0)',
             5: f'(-({e} * 2.0 - 1.0))', 6: f'(1.0 - {e})', 7: f'({e} * 2.0)', 8: f'(-({e} * 2.0))',
             11: f'abs({e})', 12: f'(-abs({e}))'}.get(m)
        if e is None:
            raise NonGere(f'modificateur de source {m}')
        return f'({e}).x' if scalaire else e

    def ecrire(self, d, expr, vec=True):
        """d ← expr (vec4), masque, saturation."""
        m = sm.masque(d.mask)
        if d.mod & 1:
            expr = f'clamp({expr}, 0.0, 1.0)'
        if d.shift:
            sh = d.shift if d.shift < 8 else d.shift - 16
            expr = f'({expr}) * {2.0 ** sh}'
        nom = self.reg(d, ecriture=True)
        if d.type == sm.ADDR and not self.ps:
            self.ligne(f'{nom}.{m} = ivec4(floor(({expr}) + 0.5)).{m};')
            return
        if nom == 'oDepth':
            self.ligne(f'gl_FragDepth = ({expr}).x;'); return
        self.ligne(f'{nom}.{m} = ({expr}).{m};')

    def ligne(self, t):
        self.lignes.append('    ' * self.indent + t)

    # ---- instructions -------------------------------------------------------
    def traduire(self):
        for i in self.ins:
            op, n = i.op, i.name
            if i.pred is not None:
                raise NonGere('instruction prédiquée')
            if op == 31:
                self.dcl(i); continue
            if op == 81:
                self.defs[i.dst.num] = i.extra; continue
            if op == 48:
                self.defi[i.dst.num] = i.extra; continue
            if op == 47:
                self.defb[i.dst.num] = i.extra; continue
            if op == 0:
                continue
            S = [self.source(s) for s in i.srcs]
            x = lambda k: self.source(i.srcs[k], scalaire=True)
            if n == 'mov': e = S[0]
            elif n == 'add': e = f'{S[0]} + {S[1]}'
            elif n == 'sub': e = f'{S[0]} - {S[1]}'
            elif n == 'mul': e = f'{S[0]} * {S[1]}'
            elif n == 'mad': e = f'{S[0]} * {S[1]} + {S[2]}'
            elif n == 'min': e = f'min({S[0]}, {S[1]})'
            elif n == 'max': e = f'max({S[0]}, {S[1]})'
            elif n == 'rcp': e = f'vec4(1.0 / {x(0)})'
            elif n == 'rsq': e = f'vec4(inversesqrt(abs({x(0)})))'
            elif n == 'exp' or n == 'expp': e = f'vec4(exp2({x(0)}))'
            elif n == 'log' or n == 'logp': e = f'vec4(log2(abs({x(0)})))'
            elif n == 'pow': e = f'vec4(pow(abs({x(0)}), {x(1)}))'
            elif n == 'dp3': e = f'vec4(dot(({S[0]}).xyz, ({S[1]}).xyz))'
            elif n == 'dp4': e = f'vec4(dot({S[0]}, {S[1]}))'
            elif n == 'dp2add': e = f'vec4(dot(({S[0]}).xy, ({S[1]}).xy) + {x(2)})'
            elif n == 'slt': e = f'vec4(lessThan({S[0]}, {S[1]}))'
            elif n == 'sge': e = f'vec4(greaterThanEqual({S[0]}, {S[1]}))'
            elif n == 'lrp': e = f'mix({S[2]}, {S[1]}, {S[0]})'
            elif n == 'frc': e = f'fract({S[0]})'
            elif n == 'abs': e = f'abs({S[0]})'
            elif n == 'sgn': e = f'sign({S[0]})'
            elif n == 'crs': e = f'vec4(cross(({S[0]}).xyz, ({S[1]}).xyz), 0.0)'
            elif n == 'nrm':
                e = f'vec4(normalize(({S[0]}).xyz), ({S[0]}).w * inversesqrt(dot(({S[0]}).xyz, ({S[0]}).xyz)))'
            elif n == 'sincos': e = f'vec4(cos({x(0)}), sin({x(0)}), 0.0, 0.0)'
            elif n == 'cmp': e = f'mix({S[2]}, {S[1]}, greaterThanEqual({S[0]}, vec4(0.0)))'
            elif n == 'cnd': e = f'mix({S[2]}, {S[1]}, greaterThan({S[0]}, vec4(0.5)))'
            elif n == 'dsx': e = f'dFdx({S[0]})'
            elif n == 'dsy': e = f'dFdy({S[0]})'
            elif n == 'lit':
                a = S[0]
                e = (f'vec4(1.0, max(({a}).x, 0.0), (({a}).x > 0.0 ? pow(max(({a}).y, 0.0), clamp(({a}).w, -127.9961, 127.9961)) : 0.0), 1.0)')
            elif n == 'dst': e = f'vec4(1.0, ({S[0]}).y * ({S[1]}).y, ({S[0]}).z, ({S[1]}).w)'
            elif n in ('m4x4', 'm4x3', 'm3x4', 'm3x3', 'm3x2'):
                lig = int(n[3]); dim = int(n[1])
                c0 = i.srcs[1]
                comps = []
                for k in range(lig):
                    q = sm.Param(); q.type, q.num, q.swz, q.smod, q.rel = c0.type, c0.num + k, 0xE4, 0, c0.rel
                    q.mask, q.mod, q.shift = 0xF, 0, 0
                    rk = self.source(q)
                    comps.append(f'dot(({S[0]}).{"xyzw"[:dim]}, ({rk}).{"xyzw"[:dim]})')
                comps += ['0.0'] * (4 - lig)
                e = f'vec4({", ".join(comps)})'
            elif n == 'mova':
                self.ecrire(i.dst, S[0]); continue
            elif n in ('texld', 'texldl', 'texldd'):
                self.texld(i, S); continue
            elif n == 'texkill':
                self.ligne(f'if (any(lessThan(({S[0]}).xyz, vec3(0.0)))) discard;'); continue
            elif n == 'if':
                self.ligne(f'if ({self.reg(i.srcs[0])} != 0) {{'); self.indent += 1; continue
            elif n == 'ifc':
                cmp = {1: '>', 2: '==', 3: '>=', 4: '<', 5: '!=', 6: '<='}[i.ctrl & 7]
                self.ligne(f'if ({x(0)} {cmp} {x(1)}) {{'); self.indent += 1; continue
            elif n == 'else':
                self.indent -= 1; self.ligne('} else {'); self.indent += 1; continue
            elif n == 'endif' or n == 'endrep' or n == 'endloop':
                self.indent -= 1; self.ligne('}'); continue
            elif n == 'rep':
                k = len(self.lignes)
                self.ligne(f'for (int rep{k} = 0; rep{k} < {self.reg(i.srcs[0])}.x; rep{k}++) {{'); self.indent += 1; continue
            elif n == 'break':
                self.ligne('break;'); continue
            elif n == 'breakc':
                cmp = {1: '>', 2: '==', 3: '>=', 4: '<', 5: '!=', 6: '<='}[i.ctrl & 7]
                self.ligne(f'if ({x(0)} {cmp} {x(1)}) break;'); continue
            else:
                raise NonGere(f'instruction {n}')
            self.ecrire(i.dst, e)

    def texld(self, i, S):
        if i.name == 'texld':
            coord, smp = S[0], i.srcs[1]
        elif i.name == 'texldl':
            coord, smp = S[0], i.srcs[1]
        else:
            coord, smp = S[0], i.srcs[1]
        if smp.type != sm.SAMPLER:
            raise NonGere('texld sans sampler')
        sn = smp.num
        dim = self.samplers.get(sn, 2)
        cc = {2: 'xy', 3: 'xyz', 4: 'xyz'}[dim]
        sw = ''.join('xyzw'[(smp.swz >> (2 * k)) & 3] for k in range(4))
        if i.name == 'texld':
            if i.ctrl == 1:                     # texldp
                e = f'textureProj(s{sn}, ({coord}).{cc}w)' if dim == 2 else f'texture(s{sn}, ({coord}).{cc} / ({coord}).w)'
            elif i.ctrl == 2:                   # texldb
                e = f'texture(s{sn}, ({coord}).{cc}, ({coord}).w)'
            else:
                e = f'texture(s{sn}, ({coord}).{cc})'
        elif i.name == 'texldl':
            e = f'textureLod(s{sn}, ({coord}).{cc}, ({coord}).w)'
        else:
            e = f'textureGrad(s{sn}, ({coord}).{cc}, ({S[2]}).{cc}, ({S[3]}).{cc})'
        if sw != 'xyzw':
            e = f'({e}).{sw}'
        self.ecrire(i.dst, e)

    def dcl(self, i):
        d, u = i.dst, i.extra
        if d.type == sm.SAMPLER:
            self.samplers[d.num] = {2: 2, 3: 3, 4: 4}.get((u >> 27) & 0xF, 2)
        elif d.type == sm.INPUT:
            self.entrees.append((d.num, u & 0x1F, (u >> 16) & 0xF))
        elif d.type == sm.OUTPUT and not self.ps:
            self.sorties[d.num] = (u & 0x1F, (u >> 16) & 0xF)
        elif d.type == sm.ADDR and self.ps:
            self.entrees_t.append(d.num)            # ps_2_x : dcl t n → texcoord n

    # ---- assemblage GLSL ----------------------------------------------------
    def regs_utilises(self, typ):
        r = set()
        for i in self.ins:
            if i.op == 31:
                continue
            for p in ([i.dst] if i.dst is not None else []) + list(i.srcs):
                if p.type == typ:
                    r.add(p.num)
        return r

    def glsl(self):
        self.traduire()
        declares = {reg for reg, _, _ in self.entrees}
        for n in sorted(self.regs_utilises(sm.INPUT) - declares):     # lus sans dcl
            if self.ps and self.ver[0] < 3:
                self.entrees.append((n, 10, n))                       # ps_2 : v n = color n
            else:
                raise NonGere(f'v{n} lu sans dcl')
        if not self.ps and self.ver[0] >= 3:
            for n in self.regs_utilises(sm.OUTPUT) - set(self.sorties):
                self.sorties_locales = getattr(self, 'sorties_locales', set()) | {n}
        tete = ['#version 450', '// traduit de D3D9 ' + ('ps' if self.ps else 'vs') + f'_{self.ver[0]}_{self.ver[1]} par scripts/d3d9-vers-spirv.py',
                f'layout(set = 0, binding = {1 if self.ps else 0}, std140) uniform Consts {{ vec4 c[256]; ivec4 i[16]; ivec4 b[16]; }} K;']
        corps = []
        if self.ps:
            tete.append('layout(push_constant) uniform PC { layout(offset = 16) vec4 at; } pc;')
            for n, dim in sorted(self.samplers.items()):
                t = {2: 'sampler2D', 3: 'samplerCube', 4: 'sampler3D'}[dim]
                tete.append(f'layout(set = 0, binding = {2 + n}) uniform {t} s{n};')
            vus = set()
            for reg, us, ix in self.entrees:
                if self.ver[0] >= 3:
                    sl = slot_varying(us, ix)
                else:                               # ps_2 : v n = color n
                    sl = reg
                if sl is None or sl in vus:
                    raise NonGere('varying d’entrée hors table')
                vus.add(sl)
                tete.append(f'layout(location = {sl}) in vec4 v{reg};')
            for n in self.entrees_t:
                if 2 + n in vus:
                    raise NonGere('varying t en double')
                vus.add(2 + n)
                tete.append(f'layout(location = {2 + n}) in vec4 t{n};')
            couts = sorted({i.dst.num for i in self.ins if i.dst is not None and i.dst.type == sm.COLOROUT})
            for k in couts:
                tete.append(f'layout(location = {k}) out vec4 oC{k};')
            if any(i.dst is not None and i.dst.type == sm.MISC for i in self.ins) or 'vPos' in ' '.join(self.lignes):
                pass
            corps.append('    vec4 vPos = vec4(gl_FragCoord.xy - 0.5, 0.0, 0.0); float vFace = gl_FrontFacing ? 1.0 : -1.0;')
            for k in couts:
                corps.append(f'    oC{k} = vec4(0.0);')
        else:
            tete.append('layout(push_constant) uniform PC { vec4 hp; } pc;')
            for reg, us, ix in self.entrees:
                tete.append(f'layout(location = {reg}) in vec4 v{reg};')
            tete.append(f'layout(location = 0) out vec4 ov[{NVARY}];')
            corps.append(f'    for (int k = 0; k < {NVARY}; k++) ov[k] = vec4(0.0);')
            corps.append('    vec4 oPos = vec4(0.0, 0.0, 0.0, 1.0);')
            if self.ver[0] >= 3:
                for reg in sorted(set(self.sorties) | getattr(self, 'sorties_locales', set())):

def fnv1a64(b):
    h = 0xCBF29CE484222325
    for x in b:
        h ^= x
        h = (h * 0x100000001B3) & 0xFFFFFFFFFFFFFFFF
    return h

"""d3d9sm.py — décodeur du bytecode des shaders Direct3D 9 (SM 2.x / 3.0), passe 5d.

Format (référence : documentation publique « D3D9 shader bytecode / token format »,
d3d9types.h) :
  version     0xFFFE_MMmm (vertex) / 0xFFFF_MMmm (pixel)
  instruction bits 0-15 opcode, 16-23 contrôles (texld : 1 = p, 2 = b ; ifc/setp :
              comparaison), 24-27 longueur en jetons (SM2+), 28 prédiqué
  destination bit 31, n° bits 0-10, type bits 28-30 | (11-12) << 3, masque 16-19,
              modificateur 20-23 (1 sat, 2 pp, 4 centroid), décalage 24-27
  source      n° 0-10, type idem, adressage relatif bit 13 (+1 jeton en SM3),
              swizzle 16-23, modificateur 24-27
  commentaire 0xFFFE + longueur (bits 16-30) ; fin 0x0000FFFF
"""
import struct

OPS = {
    0: 'nop', 1: 'mov', 2: 'add', 3: 'sub', 4: 'mad', 5: 'mul', 6: 'rcp', 7: 'rsq', 8: 'dp3', 9: 'dp4',
    10: 'min', 11: 'max', 12: 'slt', 13: 'sge', 14: 'exp', 15: 'log', 16: 'lit', 17: 'dst', 18: 'lrp',
    19: 'frc', 20: 'm4x4', 21: 'm4x3', 22: 'm3x4', 23: 'm3x3', 24: 'm3x2', 25: 'call', 26: 'callnz',
    27: 'loop', 28: 'ret', 29: 'endloop', 30: 'label', 31: 'dcl', 32: 'pow', 33: 'crs', 34: 'sgn',
    35: 'abs', 36: 'nrm', 37: 'sincos', 38: 'rep', 39: 'endrep', 40: 'if', 41: 'ifc', 42: 'else',
    43: 'endif', 44: 'break', 45: 'breakc', 46: 'mova', 47: 'defb', 48: 'defi', 64: 'texcoord',
    65: 'texkill', 66: 'texld', 78: 'expp', 79: 'logp', 80: 'cnd', 81: 'def', 88: 'cmp', 90: 'dp2add',
    91: 'dsx', 92: 'dsy', 93: 'texldd', 94: 'setp', 95: 'texldl', 96: 'breakp',
}
# registres
TEMP, INPUT, CONST, ADDR, RASTOUT, ATTROUT, OUTPUT, CONSTINT, COLOROUT, DEPTHOUT, SAMPLER = range(11)
CONSTBOOL, LOOP, MISC, PRED = 14, 15, 17, 19
USAGES = ['position', 'blendweight', 'blendindices', 'normal', 'psize', 'texcoord', 'tangent',
          'binormal', 'tessfactor', 'positiont', 'color', 'fog', 'depth', 'sample']


class Param:
    __slots__ = ('type', 'num', 'mask', 'mod', 'shift', 'swz', 'smod', 'rel')

    def __repr__(self):
        return f'{self.type}:{self.num}'


def reg_type(t):
    return ((t >> 28) & 7) | (((t >> 11) & 3) << 3)


def dest(t):
    p = Param()
    p.type, p.num = reg_type(t), t & 0x7FF
    p.mask, p.mod, p.shift = (t >> 16) & 0xF, (t >> 20) & 0xF, (t >> 24) & 0xF
    p.swz, p.smod, p.rel = 0xE4, 0, None
    return p


def src(t):
    p = Param()
    p.type, p.num = reg_type(t), t & 0x7FF
    p.swz, p.smod = (t >> 16) & 0xFF, (t >> 24) & 0xF
    p.mask, p.mod, p.shift, p.rel = 0xF, 0, 0, None
    return p


class Instr:
    __slots__ = ('op', 'name', 'ctrl', 'dst', 'srcs', 'extra', 'pred')

    def __init__(self, op, ctrl):
        self.op, self.name, self.ctrl = op, OPS.get(op, f'op{op}'), ctrl
        self.dst, self.srcs, self.extra, self.pred = None, [], None, None


def longueur(d, off=0):
    """Taille en octets du bytecode commençant à off (fin comprise), ou 0 s'il est invalide."""
    if off + 4 > len(d):
        return 0
    v = struct.unpack_from('<I', d, off)[0]
    if (v & 0xFFFE0000) != 0xFFFE0000 or ((v >> 8) & 0xFF) not in (2, 3) or (v & 0xFF) > 1:
        return 0
    i = off + 4
    while i + 4 <= len(d) and i - off < 262144:
        t = struct.unpack_from('<I', d, i)[0]
        if t == 0x0000FFFF:
            return i + 4 - off
        if (t & 0xFFFF) == 0xFFFE:
            i += 4 * (1 + ((t >> 16) & 0x7FFF))
            continue
        op = t & 0xFFFF
        if op not in OPS:
            return 0
        i += 4 * (1 + ((t >> 24) & 0xF))
    return 0


def decoder(code):
    """→ (ps: bool, version (maj, min), [Instr], commentaires [bytes])."""
    w = struct.unpack_from(f'<{len(code) // 4}I', code)
    v = w[0]
    ps = (v >> 16) == 0xFFFF
    ver = ((v >> 8) & 0xFF, v & 0xFF)
    out, comments, i = [], [], 1
    while i < len(w):
        t = w[i]
        if t == 0x0000FFFF:
            break
        if (t & 0xFFFF) == 0xFFFE:
            n = (t >> 16) & 0x7FFF
            comments.append(struct.pack(f'<{n}I', *w[i + 1:i + 1 + n]))
            i += 1 + n
            continue
        op, ln = t & 0xFFFF, (t >> 24) & 0xF
        ins = Instr(op, (t >> 16) & 0xFF)
        args = list(w[i + 1:i + 1 + ln])
        i += 1 + ln
        if t & (1 << 28):                       # prédiqué : le registre p suit la destination
            pass
        if op == 31:                            # dcl : jeton d'usage puis destination
            ins.extra = args[0]
            ins.dst = dest(args[1])
        elif op in (81, 48):                    # def / defi
            ins.dst = dest(args[0])
            ins.extra = struct.unpack('<4f' if op == 81 else '<4i', struct.pack('<4I', *args[1:5]))
        elif op == 47:                          # defb
            ins.dst = dest(args[0])
            ins.extra = args[1]
        else:
            j = 0
            has_dst = op not in (25, 26, 27, 28, 29, 30, 38, 39, 40, 41, 42, 43, 44, 45, 96, 0, 65) or op == 65
            if op == 65:                        # texkill : un seul paramètre, traité en source
                has_dst = False
            if has_dst and args:
                ins.dst = dest(args[0])
                j = 1
                if ins.dst.type == PRED and False:
                    pass
            if t & (1 << 28) and j < len(args):
                ins.pred = src(args[j]); j += 1
            while j < len(args):
                p = src(args[j]); j += 1
                if (args[j - 1] >> 13) & 1 and j < len(args) and (args[j] >> 31) & 1:
                    p.rel = src(args[j]); j += 1
                ins.srcs.append(p)
        out.append(ins)
    return ps, ver, out, comments


def ctab(comments):
    """Table de constantes (commentaire CTAB) → [(nom, regset, index, nb)]."""
    for c in comments:
        if c[:4] != b'CTAB':
            continue
        b = c[4:]
        try:
            size, creator, version, nconst, cinfo, flags, target = struct.unpack_from('<7I', b, 0)
            res = []
            for k in range(nconst):
                name, regset, regidx, regcount, _res, typeinfo, defval = struct.unpack_from('<IHHHHII', b, cinfo + 20 * k)
                nm = b[name:b.index(b'\0', name)].decode('latin-1')
                res.append((nm, regset, regidx, regcount))
            return res
        except (struct.error, ValueError):
            return []
    return []


def nom_reg(p, ps):
    t, n = p.type, p.num
    return {TEMP: f'r{n}', INPUT: f'v{n}', CONST: f'c{n}', ADDR: (f't{n}' if ps else f'a{n}'),
            RASTOUT: ['oPos', 'oFog', 'oPts'][n] if n < 3 else f'ro{n}', ATTROUT: f'oD{n}',
            OUTPUT: (f'o{n}'), CONSTINT: f'i{n}', COLOROUT: f'oC{n}', DEPTHOUT: 'oDepth',
            SAMPLER: f's{n}', CONSTBOOL: f'b{n}', LOOP: 'aL', MISC: ['vPos', 'vFace'][n] if n < 2 else f'misc{n}',
            PRED: f'p{n}'}.get(t, f'?{t}:{n}')


def desassembler(code):
    ps, ver, ins, com = decoder(code)
    lignes = [f"{'ps' if ps else 'vs'}_{ver[0]}_{ver[1]}"]
    for i in ins:
        if i.op == 31:
            u = i.extra
            if i.dst.type == SAMPLER:
                lignes.append(f'dcl_{["?", "?", "2d", "cube", "volume"][(u >> 27) & 0xF] if ((u >> 27) & 0xF) < 5 else "?"} {nom_reg(i.dst, ps)}')
            else:
                us = USAGES[u & 0x1F] if (u & 0x1F) < len(USAGES) else f'u{u & 0x1F}'
                lignes.append(f'dcl_{us}{(u >> 16) & 0xF} {nom_reg(i.dst, ps)}.{masque(i.dst.mask)}')
            continue
        if i.op in (81, 48):
            lignes.append(f'{i.name} {nom_reg(i.dst, ps)}, {", ".join(f"{x:g}" for x in i.extra)}')
            continue
        parts = []
        if i.dst is not None:
            sat = '_sat' if i.dst.mod & 1 else ''
            parts.append(f'{nom_reg(i.dst, ps)}.{masque(i.dst.mask)}')
            nm = i.name + sat
        else:
            nm = i.name
        for s in i.srcs:
            parts.append(fmt_src(s, ps))
        lignes.append(f'{nm} {", ".join(parts)}')
    return '\n'.join(lignes)


def masque(m):
    return ''.join(c for k, c in enumerate('xyzw') if m & (1 << k)) or 'xyzw'


def swz_str(s):
    t = ''.join('xyzw'[(s >> (2 * k)) & 3] for k in range(4))
    return '' if t == 'xyzw' else '.' + t


def fmt_src(s, ps):
    r = nom_reg(s, ps)
    if s.rel is not None:
        r = f'{r[0]}[{nom_reg(s.rel, ps)}{swz_str(s.rel.swz)[:2]} + {s.num}]'
    r += swz_str(s.swz)
    mods = {1: '-{}', 2: '{}_bias', 3: '-{}_bias', 4: '{}_bx2', 5: '-{}_bx2', 6: '1-{}', 7: '{}_x2',
            8: '-{}_x2', 9: '{}_dz', 10: '{}_dw', 11: '{}_abs', 12: '-{}_abs', 13: '!{}'}
    return mods.get(s.smod, '{}').format(r)

#!/usr/bin/env python3
"""extraire-shaders.py — extrait les shaders D3D9 du cache de SC2 (passe 5d).

    scripts/extraire-shaders.py <baselineCache.bin> <dossier> [--boot <dossier de dump runtime>]

Le cache `Versions/Shaders14513/baselineCache.bin` (141 Mo, lu au boot depuis la passe 6a)
contient les bytecodes D3D9 précompilés de toutes les variantes de shaders du jeu. Son
conteneur (en-tête « DMSER », enregistrements non alignés) n'est pas décodé ici : on
cherche chaque jeton de version vs/ps 2.x/3.0 (0xFFFE02xx, 0xFFFE0300, 0xFFFF02xx,
0xFFFF0300) à toute position, puis on VALIDE le bytecode jeton par jeton jusqu'à
0x0000FFFF (opcodes connus, longueurs d'instruction cohérentes) — d3d9sm.longueur().

Sortie :
  <dossier>/cache/{vs,ps}_<hash>.bin   bytecodes distincts (hash = FNV-1a 64, celui du runtime)
  <dossier>/index-cache.tsv            hash, type, version, octets, 1er offset, occurrences, instructions
  --boot <dump>  (dump du runtime : SC2_SHADERS_DUMP=<dump> ./recomp-sc2) : copie dans
  <dossier>/boot/ les shaders créés par le boot et vérifie qu'ils viennent bien du cache.
"""
import os, re, shutil, struct, sys

sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))
import d3d9sm as sm


def fnv1a64(b):
    h = 0xCBF29CE484222325
    for x in b:
        h ^= x
        h = (h * 0x100000001B3) & 0xFFFFFFFFFFFFFFFF
    return h


def main():
    if len(sys.argv) < 3:
        print(__doc__); sys.exit(2)
    cache, out = sys.argv[1], sys.argv[2]
    d = open(cache, 'rb').read()
    os.makedirs(os.path.join(out, 'cache'), exist_ok=True)
    motif = re.compile(rb'[\x00\x01][\x02\x03]\xfe\xff|[\x00\x01][\x02\x03]\xff\xff', re.S)
    vus, cand = {}, 0
    for m in motif.finditer(d):
        cand += 1
        off = m.start()
        n = sm.longueur(d, off)
        if not n:
            continue
        code = d[off:off + n]
        h = fnv1a64(code)
        if h in vus:
            vus[h][1] += 1
            continue
        ps = code[2:4] == b'\xff\xff'
        ver = (code[1], code[0])
        try:
            ninstr = len(sm.decoder(code)[2])
        except (struct.error, IndexError):
            continue
        vus[h] = [off, 1, ps, ver, n, ninstr]
        with open(os.path.join(out, 'cache', f"{'ps' if ps else 'vs'}_{h:016x}.bin"), 'wb') as f:
            f.write(code)
    with open(os.path.join(out, 'index-cache.tsv'), 'w') as f:
        f.write('hash\ttype\tversion\toctets\toffset\toccurrences\tinstructions\n')
        for h, (off, occ, ps, ver, n, ni) in sorted(vus.items(), key=lambda kv: kv[1][0]):
            f.write(f"{h:016x}\t{'ps' if ps else 'vs'}\t{ver[0]}_{ver[1]}\t{n}\t{off}\t{occ}\t{ni}\n")
    nps = sum(1 for v in vus.values() if v[2])
    print(f'{cache} : {len(d)} octets, {cand} jetons de version candidats, '
          f'{len(vus)} bytecodes distincts valides ({nps} PS, {len(vus) - nps} VS)')
    if '--boot' in sys.argv:
        dump = sys.argv[sys.argv.index('--boot') + 1]
        os.makedirs(os.path.join(out, 'boot'), exist_ok=True)
        dans, hors = 0, []
        for fn in sorted(os.listdir(dump)):
            if not fn.endswith('.bin'):
                continue
            h = int(fn[3:19], 16)
            shutil.copy(os.path.join(dump, fn), os.path.join(out, 'boot', fn))
            if h in vus:
                dans += 1
            else:
                hors.append(fn)
        print(f'boot : {dans + len(hors)} shaders créés par le jeu, {dans} présents dans le cache, '
              f'{len(hors)} absents : {" ".join(hors)}')

#!/usr/bin/env python3
"""ppm-blocs.py — statistiques par blocs 16×16 de PPM (P6) : géométrie/texture ou aplat ? (passe 5d)

    scripts/ppm-blocs.py [--avant <dossier>] <dossier ou fichiers .ppm>…

Par image : moyenne RGB, nombre de blocs 16×16 (80×45 en 1280×720), blocs non noirs
(moyenne > 1/255), luminance des blocs (min / max / écart-type), nombre de moyennes de
blocs DISTINCTES (arrondies à l'entier) — un aplat uniforme en a 1. Avec --avant, chaque
image est comparée à son homonyme : blocs dont la moyenne a changé de plus de 2/255.
"""
import os, sys


def lire(p):
    d = open(p, 'rb').read()
    parts, i = [], 0
    while len(parts) < 4:
        while d[i:i + 1].isspace():
            i += 1
        j = i
        while not d[j:j + 1].isspace():
            j += 1
        parts.append(d[i:j]); i = j
    i += 1
    w, h = int(parts[1]), int(parts[2])
    return w, h, d[i:i + w * h * 3]


def blocs(p, t=16):
    w, h, px = lire(p)
    res = []
    for by in range(h // t):
        for bx in range(w // t):
            s = [0, 0, 0]
            for y in range(by * t, by * t + t):
                o = (y * w + bx * t) * 3
                ligne = px[o:o + 3 * t]
                s[0] += sum(ligne[0::3]); s[1] += sum(ligne[1::3]); s[2] += sum(ligne[2::3])
            res.append(tuple(v / (t * t) for v in s))
    moy = tuple(sum(px[k::3]) / (w * h) for k in range(3))
    return w, h, moy, res


def stats(p):
    w, h, moy, bl = blocs(p)
    lum = [0.2126 * r + 0.7152 * g + 0.0722 * b for r, g, b in bl]
    m = sum(lum) / len(lum)
    et = (sum((x - m) ** 2 for x in lum) / len(lum)) ** 0.5
    nn = sum(1 for r, g, b in bl if max(r, g, b) > 1)
    dist = len({(round(r), round(g), round(b)) for r, g, b in bl})
    return moy, bl, lum, et, nn, dist


def fichiers(args):
    out = []

#!/usr/bin/env python3
"""difftest-sc2.py — oracle par fonction pour le recomp SC2 (kit 3e pilier M4).

Pour chaque fonction lifftée : exécute les OCTETS ORIGINAUX dans Unicorn
(référence matérielle) et la version lifftée via runner-difftest, avec le MÊME
état initial (GPR/flags/x87/SSE/mémoire, généré de façon seedée), puis compare
chaque champ architectural. Ne soumet au runner que les fonctions dont le flux
Unicorn reste dans .text (aucun import exécuté -> déterminisme garanti).

Usage: difftest-sc2.py --exe SC2.exe --liste recomp_sc2_list.h --runner runner-difftest \
                       [--debut 0] [--n 200] [--seed 1] [--json rapport.json]
"""
import argparse, json, os, random, struct, subprocess, sys, tempfile

from unicorn import Uc, UC_ARCH_X86, UC_MODE_32
from unicorn import UC_HOOK_CODE, UC_HOOK_MEM_INVALID, UC_HOOK_MEM_WRITE
from unicorn import x86_const as X
import capstone

# (aucune adresse du jeu en dur : .text est détecté via l ImageBase du PE)
BUDGET_INSTR = 200_000           # garde-fou anti-boucle infinie

REGS = ["eax", "ecx", "edx", "ebx", "esp", "ebp", "esi", "edi"]

def lire_sections(path):
    """Retourne (dict nom -> VA ABSOLUE, fin .text absolue, octets du fichier).
    Les VA du header PE sont RELATIVES à ImageBase — on rebase tout."""
    data = open(path, "rb").read()
    e_lfanew = struct.unpack_from("<I", data, 0x3C)[0]
    nsec, opt_size = struct.unpack_from("<H", data, e_lfanew + 6)[0], struct.unpack_from("<H", data, e_lfanew + 20)[0]
    image_base = struct.unpack_from("<I", data, e_lfanew + 24 + 28)[0]
    sec_off = e_lfanew + 24 + opt_size
    sections = {}
    fin_texte = 0
    for i in range(nsec):
        off = sec_off + i * 40
        nom = data[off:off+8].rstrip(b"\0").decode()
        vsize, va, rsize, roff = struct.unpack_from("<IIII", data, off + 8)
        sections[nom] = (image_base + va, vsize, rsize, roff)
        if nom == ".text":
            fin_texte = image_base + va + vsize
    return sections, fin_texte, data

def octets_fonction(data, sections, va, taille):
    _, _, _, roff = sections[".text"]
    base_va, _, _, _ = sections[".text"]
    off = roff + (va - base_va)
    return data[off:off + taille]

def adresses_liftees(chemin_liste):
    lst = []
    for ligne in open(chemin_liste):
        ligne = ligne.strip()
        if ligne.startswith("X("):
            lst.append(int(ligne[2:10], 16))
    return sorted(lst)

def gen_etat(seed, adresses):
    """État déterministe : GPR variés (adresses valides pointant dans la zone),
    flags aléatoires, x87/SSE remplis, fenêtres mémoire scratch/stack."""
    r = random.Random(seed)
    SCRATCH = 0x01000000   # 1 Mo de données jouets
    STACK = 0x00700000     # pile sous l'image
    gpr = {nom: r.getrandbits(32) for nom in REGS}
    gpr["esp"] = STACK + 0x40000 - r.getrandbits(12)   # pile alignée-ish
    gpr["ebp"] = gpr["esp"] + 0x100
    # pointeurs plausibles dans les registres: mixer hasard pur et adresses
    for nom in ("esi", "edi", "ebx"):
        if r.random() < 0.7:
            gpr[nom] = SCRATCH + r.randrange(0x1000) * 4
    eflags = 0x202 | (r.getrandbits(16) & 0x0FD5)  # bits fixes + hasard masqué
    fenetres = [(SCRATCH, r.randbytes(0x8000)), (STACK + 0x20000, r.randbytes(0x20000))]
    return gpr, eflags, fenetres, SCRATCH, STACK

class ResultatUnicorn:
    __slots__ = ("ok", "sorti_du_texte", "budget", "gpr", "eflags", "mem", "x87", "xmm", "ecrits")

def executer_unicorn(uc_data, sections, fin_texte, addr, taille, gpr, eflags, fenetres, adresses_set, base_texte):
    res = ResultatUnicorn()
    res.ok = res.sorti_du_texte = res.budget = False
    try:
        uc = Uc(UC_ARCH_X86, UC_MODE_32)
        uc.mem_map(0x00400000, 0x1800000)   # 24 Mo sous les 4 Go (image + scratch + pile jouets)
        # mapper l'image : copier tout .text tel quel (appels internes possibles)
        base_va, vsize, rsize, roff = sections[".text"]
        uc.mem_write(base_va, uc_data[roff:roff + rsize])
        for va, octets in fenetres:
            uc.mem_write(va & ~0xFFFFF, b"\xCC" * 0x1000)  # marquage de page piochable
            uc.mem_write(va, octets)
        for i, nom in enumerate(REGS):
            uc.reg_write(getattr(X, f"UC_X86_REG_{nom.upper()}"), gpr[nom])
        uc.reg_write(X.UC_X86_REG_EFLAGS, eflags)

        retour = gpr["esp"]
        esp0 = gpr["esp"]
        compte = [0]
        ecrits = set()   # VA des octets ÉCRITS pendant l'exécution (seuls ceux-là sont comparés)
        def hook_write(uc2, acc, adresse, taille_i, valeur, _):
            for k in range(adresse, adresse + taille_i):
                ecrits.add(k)
        uc.hook_add(UC_HOOK_MEM_WRITE, hook_write)
        def hook_code(uc2, adresse, taille_i, _):
            compte[0] += 1
            if compte[0] > BUDGET_INSTR:
                res.budget = True
                uc2.emu_stop()
                return
            if adresse < base_texte or adresse >= fin_texte:
                res.sorti_du_texte = True
                uc2.emu_stop()
                return
            # ret de NOTRE cadre (C3/C2 avec pile revenue) = fin de fonction.
            # On SIMULE le ret (esp += 4 + imm) pour que la comparaison avec le
            # runner (qui exécute le ret modélisé) soit stricte.
            if taille_i in (1, 3):
                op = uc2.mem_read(adresse, 1)[0]
                if op in (0xC3, 0xC2) and uc2.reg_read(X.UC_X86_REG_ESP) >= esp0:
                    imm = 0
                    if op == 0xC2:
                        imm = int.from_bytes(uc2.mem_read(adresse + 1, 2), "little")
                    uc2.reg_write(X.UC_X86_REG_ESP, uc2.reg_read(X.UC_X86_REG_ESP) + 4 + imm)
                    uc2.emu_stop()
        uc.hook_add(UC_HOOK_CODE, hook_code)

        # exécuter jusqu'au ret du cadre (intercepté ci-dessus), via intercept du ret:
        def hook_mem_invalid(uc2, acc, adresse, taille_i, valeur, _):
            res.sorti_du_texte = True   # mémoire hors zone = dépendance externe
            return False
        uc.hook_add(UC_HOOK_MEM_INVALID, hook_mem_invalid)

        uc.emu_start(addr, 0, count=BUDGET_INSTR + 1)
        if res.sorti_du_texte or res.budget:
            return res
        res.gpr = {nom: uc.reg_read(getattr(X, f"UC_X86_REG_{nom.upper()}")) for nom in REGS}
        res.eflags = uc.reg_read(X.UC_X86_REG_EFLAGS)
        res.mem = {va: bytes(uc.mem_read(va, len(o))) for va, o in fenetres}
        res.ecrits = ecrits
        # st/xmm : Unicorn ne montre st qu'en 80 bits -> comparaison x87 en v2
        res.x87 = None
        res.xmm = None
        res.ok = True
        return res
    except Exception as e:
        res.sorti_du_texte = True   # exception = flux non maîtrisé -> skip
        return res

def executer_runner(runner, gpr, eflags, fenetres, addr):
    SCRATCH, STACK = fenetres[0][0], fenetres[1][0]
    blob = bytearray()
    blob += struct.pack("<I", 0x31305444) + struct.pack("<II", addr, eflags)
    for nom in REGS:
        blob += struct.pack("<I", gpr[nom])
    blob += struct.pack("<i", 0)          # fpu_top neutre
    blob += struct.pack("<8d", *([0.0] * 8))
    blob += struct.pack("<I", 0)          # fpu_sw
    blob += bytes(128)                    # xmm neutres
    blob += struct.pack("<I", len(fenetres))
    for va, octets in fenetres:
        blob += struct.pack("<II", va, len(octets)) + octets
    probes = [(va, len(o)) for va, o in fenetres]
    blob += struct.pack("<I", len(probes))
    for va, ln in probes:
        blob += struct.pack("<II", va, ln)
    with tempfile.NamedTemporaryFile(delete=False) as f:
        f.write(blob); chemin = f.name
    try:
        p = subprocess.run([runner, chemin], capture_output=True, timeout=60)
        if p.returncode != 0:
            return None
        d = p.stdout
        if len(d) < 8 or struct.unpack_from("<I", d, 0)[0] != 0x31305444:
            return None
        off = 8
        gpr2 = {}
        for i, nom in enumerate(REGS):
            gpr2[nom] = struct.unpack_from("<I", d, off)[0]; off += 4
        ef2 = struct.unpack_from("<I", d, off)[0]; off += 4
        mem2 = {}
        for va, ln in probes:
            off += 8
            mem2[va] = d[off:off + ln]; off += ln
        return {"gpr": gpr2, "eflags": ef2, "mem": mem2}
    finally:
        os.unlink(chemin)

def comparer(u_gpr, r_gpr, u_ef, r_ef, u_mem, r_mem, ecrits=None):
    diffs = []
    for nom in REGS:
        if u_gpr[nom] != r_gpr[nom]:
            diffs.append(f"{nom}: u={u_gpr[nom]:08X} r={r_gpr[nom]:08X}")
    # masque : CF PF ZF SF OF (AF exclu : divergence bénigne documentée du
    # modèle fcompi ; DF non modélisé par le runtime)
    masque = 0x8C5
    if (u_ef & masque) != (r_ef & masque):
        diffs.append(f"eflags: u={u_ef & masque:04X} r={r_ef & masque:04X}")
    for va in u_mem:
        if ecrits is None:
            if u_mem[va] != r_mem[va]:
                nb = sum(1 for a, b in zip(u_mem[va], r_mem[va]) if a != b)
                diffs.append(f"mem@{va:08X}: {nb} octets differents")
        else:
            nb = 0
            for i in range(len(u_mem[va])):
                if (va + i) in ecrits and u_mem[va][i] != r_mem[va][i]:
                    nb += 1
            if nb:
                diffs.append(f"mem@{va:08X}: {nb}/{len(u_mem[va])} octets ECRITS divergents")
    return diffs

/* runner-difftest.c — exécute UNE fonction lifftée avec un état injecté, pour le
 * difftest par fonction (kit 3e pilier M4, 14/10/2026).
 * Entrée : argv[1] = fichier d'état binaire (DT01). Sortie : état final sur stdout.
 * La zone hôte couvre tout l'espace 32 bits (4 Go NORESERVE) : TOUTE VA est valide.
 * Aucun stub Win32 n'est exécuté ici : le harnais Python ne soumet que des
 * fonctions dont l'arbre d'appels reste dans .text (détection Unicorn amont). */
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdint.h>
#include <sys/mman.h>
#include "cpu.h"
#include "sc2_host.h"

/* Table addr → fonction lifftée, générée depuis la liste canonique.
 * recomp_sc2_list.h définit la macro LIFTED_FUNCS(X) — on l'inclut pour la
 * définition, puis on l'INSTANCIE dans l'initialiseur (pattern X-macro). */
#include "recomp_sc2_list.h"
typedef void (*RecompFn)(CPU *);
/* prototypes des fonctions lifftées (définies dans recomp_*.c) */
#define X_PROTO(a) void L_##a(CPU *c);
LIFTED_FUNCS(X_PROTO)
#undef X_PROTO
typedef struct { uint32_t addr; RecompFn fn; } Entree;
#define X(a) { 0x##a, L_##a },
static Entree g_table[] = {
    LIFTED_FUNCS(X)
};
#undef X
#define N_TABLE (sizeof g_table / sizeof g_table[0])

static void *lire_exacte(FILE *f, void *p, size_t n) {
    return fread(p, 1, n, f) == n ? p : NULL;
}
#define LIRE(f, champ) lire_exacte((f), &(champ), sizeof (champ))

int main(int argc, char **argv)
{
    if (argc < 2) { fprintf(stderr, "usage: %s etat.bin\n", argv[0]); return 2; }
    FILE *in = fopen(argv[1], "rb");
    if (!in) { perror("fopen etat"); return 2; }

    uint32_t magic; if (!LIRE(in, magic) || magic != 0x31305444u /* "DT01" LE */) {
        fprintf(stderr, "magic invalide\n"); return 2; }

    /* Zone hôte 4 Go, delta = base (VA == offset dans la zone) */
    void *zone = mmap(NULL, 0x100000000ull, PROT_READ | PROT_WRITE,
                      MAP_PRIVATE | MAP_ANONYMOUS | MAP_NORESERVE, -1, 0);
    if (zone == MAP_FAILED) { perror("mmap zone 4G"); return 2; }
    g_hote_delta = (uintptr_t)zone;   /* GPTR(va) = zone + va, tout l'espace 32 bits */

    CPU c; memset(&c, 0, sizeof c);
    uint32_t addr, eflags;
    if (!LIRE(in, addr) || !LIRE(in, eflags)) return 2;
    uint32_t *gpr[8] = { &c.eax, &c.ecx, &c.edx, &c.ebx, &c.esp, &c.ebp, &c.esi, &c.edi };
    for (int i = 0; i < 8; i++) if (!LIRE(in, *gpr[i])) return 2;
    if (!LIRE(in, c.fpu_top)) return 2;
    for (int i = 0; i < 8; i++) if (!LIRE(in, c.st[i])) return 2;
    if (!LIRE(in, c.fpu_sw)) return 2;
    for (int i = 0; i < 8; i++) if (!lire_exacte(in, c.xmm[i].u8, 16)) return 2;
    eflags_unpack(&c, eflags);

    /* fenêtres mémoire à poser */
    uint32_t n_fenetres;
    if (!LIRE(in, n_fenetres)) return 2;
    for (uint32_t i = 0; i < n_fenetres; i++) {
        uint32_t va, len;
        if (!LIRE(in, va) || !LIRE(in, len)) return 2;
        if (!lire_exacte(in, GPTR(va), len)) return 2;
    }
    /* adresses à relire après exécution (une à la fois) */
    uint32_t n_probes;
    if (!LIRE(in, n_probes)) return 2;

    /* recherche de la fonction */
    RecompFn fn = NULL;
    for (size_t i = 0; i < N_TABLE; i++)
        if (g_table[i].addr == addr) { fn = g_table[i].fn; break; }
    if (!fn) { fprintf(stderr, "fonction %08X absente de la table\n", addr); return 3; }

    fn(&c);   /* exécution */

    /* sortie : même format, sans fenêtres posées — juste les probes */
    FILE *out = stdout;
    uint32_t magic_out = 0x31305444u;
    fwrite(&magic_out, 4, 1, out);
    uint32_t ok = 1; fwrite(&ok, 4, 1, out);
    for (int i = 0; i < 8; i++) fwrite(gpr[i], 4, 1, out);
    uint32_t ef = eflags_pack(&c); fwrite(&ef, 4, 1, out);
    fwrite(&c.fpu_top, 4, 1, out);
    fwrite(c.st, 8, 8, out);
    fwrite(&c.fpu_sw, 4, 1, out);
    for (int i = 0; i < 8; i++) fwrite(c.xmm[i].u8, 16, 1, out);
    for (uint32_t i = 0; i < n_probes; i++) {
        uint32_t va, len;
        if (!LIRE(in, va) || !LIRE(in, len)) return 2;
        fwrite(&va, 4, 1, out); fwrite(&len, 4, 1, out);
        fwrite(GPTR(va), 1, len, out);
    }
    fclose(in); fclose(out);
    return 0;
}

# MPQ extraction tools (StormLib) — and the partial-block EOF trap

**FR :** Deux petits outils C++ pour extraire (`mpqget`) et lister (`mpqlist`) une archive MPQ,
via [StormLib](https://github.com/ladislav-zezula/StormLib). Le point intéressant est le **piège
documenté** : `SFileReadFile` rend **FALSE + `ERROR_HANDLE_EOF` alors même qu'il a lu des octets**
(`nb > 0`) sur la dernière lecture partielle d'un fichier — comportement voulu de StormLib
(SFileReadFile.cpp : *« If the read operation succeeded, but not full number of bytes was read,
set the last error to ERROR_HANDLE_EOF »*). La boucle naïve
`while (SFileReadFile(...) && nb > 0)` jette donc le dernier bloc partiel :

- tout fichier **non multiple** du tampon (64 KiB) sort tronqué au multiple inférieur ;
- tout fichier **plus petit** que le tampon sort **vide** (0 octet) ;
- les multiples **exacts** du tampon sortent intacts — d'où un défaut discret qui peut survivre
  des semaines (vécu : des extractions fausses pendant une journée entière, le source était
  corrigé mais le binaire déployé jamais recompilé).

`mpqget` écrit **tous** les octets lus, ne s'arrête qu'à la fin réelle, toute autre erreur est
fatale, et le total doit égaler la taille du catalogue (`rc 0` ⟺ extraction complète, sinon
`rc 1` et la sortie est supprimée). `mpqlist` lit le `(listfile)` en entier (même correctif),
retire les `CR` du CRLF, et ajoute `--tailles` (taille du catalogue par entrée — pratique pour
préparer des bancs de contrôle d'extraction).

**EN :** Two small C++ tools to extract (`mpqget`) and list (`mpqlist`) an MPQ archive, via
[StormLib](https://github.com/ladislav-zezula/StormLib). The interesting part is the **documented
trap**: `SFileReadFile` returns **FALSE + `ERROR_HANDLE_EOF` even though it did read bytes**
(`nb > 0`) on a file's final partial read — intended StormLib behaviour. A naive
`while (SFileReadFile(...) && nb > 0)` loop therefore drops the last partial block: any file
**not a multiple** of the 64 KiB buffer comes out truncated to the lower multiple; anything
**smaller** than the buffer comes out **empty**; **exact** multiples come out intact — a quiet
defect that can survive for weeks (lived: a full day of wrong extractions from a fixed source
whose deployed binary had never been recompiled).

`mpqget` always writes every byte read, stops only at the true end, treats any other error as
fatal, and requires the total to equal the catalog size (`rc 0` ⟺ complete extraction, else
`rc 1` with the output removed). `mpqlist` reads the whole `(listfile)` (same fix), strips CRLF,
and adds `--tailles` (catalog size per entry — handy to prepare extraction control benches).

**Second piège — le plafond de listfile silencieux (FR).** `mpqlist` lisait le `(listfile)`
dans un accumulate plafonné à 2 Mio (« règle streaming »). Or le listfile d'un gros MPQ
d'installer dépasse 4 Mio : le listing sortait **tronqué à moitié sans aucun signal** — des
archives entières semblaient « absentes du média ». Le plafond est désormais 256 Mo et la
troncature n'est plus jamais silencieuse : plafond atteint sans EOF ⇒ message sur stderr +
exit 3, listing incomplet refusé.

**EN:** `mpqlist` used to read the `(listfile)` into a 2 MiB-capped buffer ("streaming rule").
A large installer MPQ's listfile exceeds 4 MiB, so listings came out **truncated to half,
silently** — whole archives looked "absent from the media". The cap is now 256 MiB and
truncation is never silent: cap reached before EOF ⇒ stderr message + exit 3, incomplete
listing refused.

// mpqget — extrait un fichier d'une archive MPQ/MPQE via StormLib
// Chantier SC2 Partout (Reverso-SC2). Usage : mpqget <archive-avec-prefixe> <nom-interne> <destination>
// Streaming par tampon 64 Ko (règle incident n°3 : jamais de lecture complète en mémoire).
// rc 0 : octets extraits = taille du catalogue MPQ ; sinon rc 1 et aucune sortie (fichier partiel supprimé).
// Construction (binaire HORS git, dans tools/ — à refaire après toute modification de ce source :
// le défaut du dernier bloc partiel a survécu une journée dans un tools/mpqget jamais recompilé) :
//   g++ -O2 -Wall -o tools/mpqget mpqget.cpp -I ~/tools/StormLib/src -L ~/tools/StormLib/build -lstorm -ltomcrypt -ltommath -lz -lbz2
#include <cstdio>
#include <cstring>
#include "StormLib.h"

int main(int argc, char** argv) {
    if (argc < 4) { fprintf(stderr, "usage: %s <archive> <nom-interne-mpq> <destination>\n", argv[0]); return 2; }
    HANDLE hMpq = NULL;
    if (!SFileOpenArchive(argv[1], 0, MPQ_OPEN_READ_ONLY, &hMpq)) {
        fprintf(stderr, "SFileOpenArchive echec, err=%u\n", (unsigned)SErrGetLastError());
        return 1;
    }
    HANDLE hFile = NULL;
    if (!SFileOpenFileEx(hMpq, argv[2], 0, &hFile)) {
        fprintf(stderr, "SFileOpenFileEx echec [%s], err=%u\n", argv[2], (unsigned)SErrGetLastError());
        SFileCloseArchive(hMpq);
        return 1;
    }
    FILE* out = fopen(argv[3], "wb");
    if (!out) { fprintf(stderr, "fopen echec [%s]\n", argv[3]); SFileCloseFile(hFile); SFileCloseArchive(hMpq); return 1; }
    char buf[65536]; DWORD nb = 0; unsigned long long total = 0;
    DWORD haut = 0, bas = SFileGetFileSize(hFile, &haut);
    unsigned long long attendu = ((unsigned long long)haut << 32) | bas;   /* taille du catalogue MPQ */
    // SFileReadFile rend FALSE + ERROR_HANDLE_EOF quand il lit MOINS que demandé, nb > 0 COMPRIS
    // (StormLib SFileReadFile.cpp : « If the read operation succeeded, but not full number of bytes
    // was read, set the last error to ERROR_HANDLE_EOF »). L'ancienne boucle
    // « while (SFileReadFile(...) && nb > 0) » sortait donc AVANT d'écrire le dernier bloc partiel :
    // un fichier de 130 743 octets n'en rendait que 65 536 ; plus petit que le tampon → 0 octet
    // (le binaire tools/mpqget en était resté là : source corrigé, binaire jamais recompilé).
    // Ici : on écrit TOUJOURS les nb octets lus, on ne s'arrête qu'à la fin réelle (nb = 0, ou
    // ERROR_HANDLE_EOF), toute autre erreur est fatale, et le total doit égaler la taille du catalogue.
    int erreur = 0;
    for (;;) {
        bool ok = SFileReadFile(hFile, buf, sizeof(buf), &nb, NULL);
        DWORD err = ok ? ERROR_SUCCESS : SErrGetLastError();
        if (nb && fwrite(buf, 1, nb, out) != nb) { fprintf(stderr, "fwrite echec\n"); erreur = 1; break; }
        total += nb;
        if (!ok && err != ERROR_HANDLE_EOF) { fprintf(stderr, "SFileReadFile echec apres %llu octets, err=%u\n", total, (unsigned)err); erreur = 1; break; }
        if (!ok || nb == 0) break;
    }
    fclose(out);
    SFileCloseFile(hFile);
    SFileCloseArchive(hMpq);
    if (!erreur && total != attendu) {
        fprintf(stderr, "taille incoherente : %llu octets extraits, %llu annonces par le catalogue\n", total, attendu);
        erreur = 1;
    }
    if (erreur) { remove(argv[3]); return 1; }
    printf("%llu octets extraits -> %s (catalogue : %llu)\n", total, argv[3], attendu);
    return 0;
}

// mpqlist — liste le contenu d'une archive MPQ/MPQE via StormLib
// Chantier SC2 Partout (Reverso-SC2). Usage : mpqlist <archive> [--tailles]
// --tailles : chaque ligne devient « <taille du catalogue MPQ>\t<nom> » (SFileGetFileSize ; « - » si
// l'entrée du listfile n'existe pas dans l'archive). Sans option : noms seuls, comme avant.
// Lecture du (listfile) interne en accumulate borné (256 Mo max, règle streaming ;
// troncature au plafond = exit 3 BRUYANT, jamais silencieuse),
// fallback sur l'énumération SFileFind*.
// Construction (binaire HORS git, dans tools/ — à refaire après toute modification de ce source :
// le défaut du dernier bloc partiel a survécu une journée dans un tools/mpqlist jamais recompilé) :
//   g++ -O2 -Wall -o tools/mpqlist mpqlist.cpp -I ~/tools/StormLib/src -L ~/tools/StormLib/build -lstorm -ltomcrypt -ltommath -lz -lbz2
#include <cstdio>
#include <cstring>
#include <string>
#include "StormLib.h"

int main(int argc, char** argv) {
    if (argc < 2) { fprintf(stderr, "usage: %s <archive> [--tailles]\n", argv[0]); return 2; }
    bool tailles = argc > 2 && !strcmp(argv[2], "--tailles");
    HANDLE hMpq = NULL;
    if (!SFileOpenArchive(argv[1], 0, MPQ_OPEN_READ_ONLY, &hMpq)) {
        fprintf(stderr, "SFileOpenArchive echec, err=%u\n", (unsigned)SErrGetLastError());
        return 1;
    }
    printf("# archive ouverte : %s\n", argv[1]);

    HANDLE hList = NULL;
    if (SFileOpenFileEx(hMpq, "(listfile)", 0, &hList)) {
        std::string acc; char buf[65536]; DWORD nb = 0;
        // Même défaut que l'ancien mpqget : « while (SFileReadFile(...) && nb > 0) » abandonnait le
        // dernier bloc PARTIEL (SFileReadFile rend FALSE + ERROR_HANDLE_EOF avec nb > 0) — un grand
        // listfile de 809 851 octets n'était lu que sur 786 432 (12 × 64 Kio) : entrées de la fin perdues.
        const size_t PLAFOND_LISTFILE = 256u*1024*1024; // 256 Mo — le listfile d'un gros MPQ d'installer dépasse 4 Mio : l'ancien plafond 2 Mio tronquait le listing à MOITIÉ sans aucun signal.
        bool eof_listfile = false;
        while (acc.size() < PLAFOND_LISTFILE) {
            bool ok = SFileReadFile(hList, buf, sizeof(buf), &nb, NULL);
            acc.append(buf, nb);
            if (!ok || nb == 0) { eof_listfile = true; break; }
        }
        if (!eof_listfile) {
            fprintf(stderr, "# ATTENTION : (listfile) TRONQUÉ — plafond %zu octets atteint sans EOF ; listing incomplet REFUSÉ (exit 3)\n", PLAFOND_LISTFILE);
            SFileCloseFile(hList);
            SFileCloseArchive(hMpq);
            return 3;
        }
        SFileCloseFile(hList);
        printf("# (listfile) : %zu octets\n", acc.size());
        size_t debut = 0, lignes = 0;
        while (debut < acc.size()) {
            size_t fin = acc.find('\n', debut);
            if (fin == std::string::npos) fin = acc.size();
            if (fin > debut && acc[fin - 1] == '\r') acc[fin - 1] = '\0';
            if (fin > debut) {
                acc[fin] = '\0';
                const char *nom = acc.c_str() + debut;
                if (tailles) {
                    HANDLE hf = NULL;
                    if (*nom && SFileOpenFileEx(hMpq, nom, 0, &hf)) {
                        DWORD haut = 0, bas = SFileGetFileSize(hf, &haut);
                        printf("%llu\t%s\n", ((unsigned long long)haut << 32) | bas, nom);
                        SFileCloseFile(hf);
                    } else printf("-\t%s\n", nom);
                } else printf("%s\n", nom);
                lignes++;
            }
            debut = fin + 1;
        }
        printf("# %zu entrees listees\n", lignes);
    } else {
        printf("# pas de (listfile) lisible, err=%u — enumeration\n", (unsigned)SErrGetLastError());
        SFILE_FIND_DATA fd; memset(&fd, 0, sizeof(fd));
        HANDLE hFind = SFileFindFirstFile(hMpq, "*", &fd, NULL);
        if (hFind) {
            int n = 0;
            do { if (tailles) printf("%u\t%s\n", fd.dwFileSize, fd.cFileName); else printf("%s\n", fd.cFileName); n++; }
            while (SFileFindNextFile(hFind, &fd));
            SFileFindClose(hFind);
            printf("# %d entrees\n", n);
        } else {
            printf("# enumeration impossible, err=%u\n", (unsigned)SErrGetLastError());
        }
    }
    SFileCloseArchive(hMpq);
    return 0;
}

# pcrecomp-atomics — atomic x86 → C lifting (xchg with memory, lock RMW, cmpxchg8b)

Generic patch for the pcrecomp static-recompilation toolchain: it teaches the
x86 lifter to emit C atomics (`__atomic_*` builtins) instead of plain
load/store pairs for the instructions whose hardware semantics are atomic:

- `xchg` with a memory operand (8/16/32-bit) — atomic with or without `lock`;
- `lock add|sub|and|or|xor|inc|dec` — read-modify-write, flags computed from
  the old value;
- `lock xadd` and `cmpxchg` 8/16-bit;
- `cmpxchg8b` — 64-bit compare-and-swap (previously a TODO).

The runtime side gains a single `GPTR(va)` macro (host pointer for a guest
address — identity by default; a host that maps the guest at an offset
defines its own before including `cpu.h`).

**Generic by construction**: the patch carries no address, offset, symbol or
any other constant of any specific binary — it applies to any pcrecomp
userland-lifting workload.
md5 of the patch: `191282f52defbf3a5c14e1e2596864dc`.

## Apply

    patch -p1 -d <your-pcrecomp-checkout> < pcrecomp-atomics.patch

Then re-lift your target and diff the generated C: only the sites listed
above should change. Validate with your usual differential harness before
trusting a re-lift (we check equivalence against a hardware-reference
emulator on both x86-64 and aarch64 hosts — 20/20 on every function touched).

# pcrecomp-closure — extend an existing lifted closure without a global relift

Generic, engine-agnostic (zero game constant, zero address, no game file shipped).

**EN:** A whole-program lift with pcrecomp's `lift32_cpu` produces a closure: every function reachable from the
roots it was given. When the runtime later hits a function outside that closure (a `RECOMP_TODO`, an indirect target
discovered at run time), relifting the whole program is slow and churns every generated file. `closure-plus.py`
lifts only what is missing: starting from the roots you pass, it lifts each function, scans the generated C for
direct `dispatch(c, 0x…u)` targets, and recurses into every target that lies in `.text` and is not already in your
known list. Function extent = bounded descent of local jumps (stops at `ret`/`jmp`/`int3`/`ud2`, 16 KiB cap); the
PE base relocations are fed to the lifter so absolute addresses stay relocatable. A function the lifter refuses
becomes a `RECOMP_TODO` stub instead of aborting the run.

**FR :** Un lift global avec `lift32_cpu` (pcrecomp) produit une closure : toutes les fonctions atteignables depuis
ses racines. Quand le runtime tombe ensuite sur une fonction hors closure, relifter tout le programme est lent et
modifie tous les fichiers générés. `closure-plus.py` ne lifte que le manquant : depuis les racines données, il lifte
chaque fonction, relève dans le C produit les cibles directes `dispatch(c, 0x…u)` et descend récursivement dans
chacune si elle est dans `.text` et absente de la liste connue. Une fonction refusée par le lifter devient un
stub `RECOMP_TODO` au lieu d'interrompre le run.

"""closure-plus.py — complète une closure liftée EXISTANTE (pcrecomp, lift32_cpu) avec des racines manquantes,
sans relift global.

Pour chaque racine (et, récursivement, chaque cible directe de dispatch absente de la liste connue et située dans
.text) : étendue par descente bornée des sauts locaux, relocations du PE, lift par le lift32_cpu donné. Sortie : un
fichier C (les fonctions neuves) et, sur stdout, la liste des VA ajoutées.

  closure-plus.py [--include H]... [--known-re RE] <dossier tools/lift> <image.exe> <liste connue> <sortie.c> <racine hex>…

  <dossier tools/lift>  celui qui contient lift32_cpu.py (pcrecomp)
  <image.exe>           VOTRE image PE32 (jamais distribuée ; lue localement)
  <liste connue>        fichier texte des fonctions déjà liftées : toute VA capturée par --known-re
                        (défaut : X(XXXXXXXX), la X-macro de liste de pcrecomp) ; « - » = aucune
  --include H           en-tête ajouté au fichier C (répétable ; défaut : cpu.h)
"""
import argparse, importlib, re, struct, sys

DISPATCH_RE = re.compile(r"dispatch(?:_jmp)?\(c, (?:GVA\()?0x([0-9A-Fa-f]{8})u")


class PE:
    """Lecteur PE32 minimal : en-têtes, sections, lecture par VA, relocations HIGHLOW."""
    def __init__(self, path):
        r = self.raw = open(path, "rb").read()
        fh = struct.unpack_from("<I", r, 0x3C)[0] + 4
        assert r[fh - 4:fh] == b"PE\0\0", "signature PE absente"
        nsec, opt_size = struct.unpack_from("<H", r, fh + 2)[0], struct.unpack_from("<H", r, fh + 16)[0]
        oh = fh + 20

**FR:** `grep -n 'm\[4\] == "h"' lift32_cpu.py` — toute occurrence = le bug est présent.

## Application

    git apply pcrecomp-movhps.patch

Patch applies to the stock pcrecomp lifter; zero constants of any particular
binary (fully generic). Verified per-function against a hardware-reference
emulator (Unicorn) before/after; unaffected encodings (`movhlps`/`movlhps`,
register-to-register) unchanged.
