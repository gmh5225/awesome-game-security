# holo-emu

Userspace emulation of the `usrdrv017964` interface used by
`hololive-Dreams.exe`. The runtime consists of:

- `loader.exe` — finds the game's multi-process startup chain and injects
  `Emulator.dll`.
- `Emulator.dll` — emulates the device protocol, service state, registry key,
  symbolic link, and loaded-driver metadata.
- `usrdrv017964.sys` — read only as PE/image data for the exact integrity
  transform. It is never installed or loaded as a kernel driver.
- `test_client.exe` — exercises the protocol and all emulated discovery
  surfaces without launching the game.

The current implementation is x64 and targets the version 1.0.0 game/driver
pair used during reverse engineering.

## Runtime bundle

Keep these files together:

```text
Emulator.dll
loader.exe
test_client.exe
usrdrv017964.sys
```

`Emulator.dll` now locates its log and driver image relative to itself, so the
bundle can be moved to another Windows machine or exposed to Wine through any
drive mapping. `SHA256SUMS.txt` in `dist` records the release hashes.

## Build on Windows

Requirements:

- Visual Studio with the x64 C++ toolchain
- PowerShell
- `libMinHook.x64.lib` and `MinHook.h` from this source tree

Run:

```powershell
.\build.ps1
```

The script builds into `build`, runs the self-test with the real service key
forcibly bypassed, and publishes a portable bundle into `dist`.

## Windows VM test

Copy the four runtime files to one directory in the VM. No service entry is
required.

```powershell
.\test_client.exe
.\loader.exe --check
.\run-windows.ps1
```

Leave the loader open and start the game normally. For a detailed file,
registry, service, and module trace:

```powershell
.\run-windows.ps1 -Trace
```

The log is written beside `Emulator.dll`.

Use the same Windows binaries; do not build a native Linux shared library.
The loader and game must run in the same Wine prefix.

## Static-analysis result

Your walk-back is correct. I verified the uploaded sample directly and do **not** find the attacker-selected `EPROCESS` read/OR/AND-NOT primitive associated with the other LOLDriver analysis.

**Sample**

* SHA-256: `d3851e1cb3fcb85526e68fa9991dbaffef51a77b2a3b0d627d0e83095bac6f58`
* Size: 31,408 bytes
* Architecture: x64 native Windows driver
* Preferred image base: `0x140000000`
* Entry point: `0x1400011A0`
* Device: `\Device\Htsysm6321`
* Symlink: `\DosDevices\Htsysm6321`
* User-mode path: `\\.\Htsysm6321`

The file contains an embedded Microsoft Windows Hardware Compatibility Publisher certificate chain. I have not independently completed the Authenticode digest and timestamp verification, so I would describe it as **containing that signature material**, not yet as cryptographically verified.

The best overall classification is:

> **A vulnerable process-handle protection and code-integrity attestation driver, not an arbitrary kernel-write driver.**

An official Steam notice for *hololive Dreams* separately identifies `usrdrv017964.sys` as an application security-protection component. That attribution fits the observed design, although it does not prove this particular hash is harmless. ([Steam Store][1])

---

# 1. The `ObRegisterCallbacks` path

Registration happens in `0x140002280`, with the call to the import thunk at `0x1400023D0`.

The constructed registration is:

| Field                  |                             Value |
| ---------------------- | --------------------------------: |
| Object type            |                  `*PsProcessType` |
| Operations             | `3` — handle create and duplicate |
| Pre-operation routine  |                     `0x140001DF0` |
| Post-operation routine |                     `0x140001D30` |
| Registration context   |                            `NULL` |
| Operation count        |                               `1` |
| Altitude               |              Begins with `88180.` |

It registers only for **process objects**, not thread objects. The callback is globally installed, but that does not mean it filters every process: the pre-operation routine first looks up the target PID in the driver's own table. Microsoft’s callback structures use the operation registration to select the object type and handle-create/duplicate operations. ([Microsoft Learn][2])

## Pre-operation callback behavior

A close representation of `0x140001DF0` is:

```c
OB_PREOP_CALLBACK_STATUS ProcessHandlePre(
    void *RegistrationContext,
    POB_PRE_OPERATION_INFORMATION info)
{
    lock(global_mutex);

    if (info->Flags & OB_PRE_OPERATION_KERNEL_HANDLE)
        goto allow;

    uint32_t target_pid =
        (uint32_t)PsGetProcessId((PEPROCESS)info->Object);

    SLOT *r = FindPidSlot(target_pid);

    if (r == NULL || r->active == 0)
        goto allow;

    if (info->Operation != OB_OPERATION_HANDLE_CREATE &&
        info->Operation != OB_OPERATION_HANDLE_DUPLICATE)
        goto allow;

    ACCESS_MASK *desired =
        &info->Parameters->CreateHandleInformation.DesiredAccess;

    if ((*desired & 0x3A) == 0)
        goto allow;

    uint32_t caller_pid = (uint32_t)PsGetCurrentProcessId();

    if (caller_pid == target_pid)
        goto allow;

    /*
     * enabled == 0 means monitor/log only.
     */
    if (r->enabled == 0) {
        LogCaller(r, caller_pid, TELEMETRY_PROTECTION_DISABLED);
        goto allow;
    }

    if (CallerPidInFiveEntryAllowlist(r, caller_pid))
        goto allowed_and_log;

    PEPROCESS caller = IoGetCurrentProcess();
    uint32_t caller_parent =
        (uint32_t)PsGetProcessInheritedFromUniqueProcessId(caller);
    const char *caller_name = PsGetProcessImageFileName(caller);

    /*
     * This is not a three-entry OR list.
     * All three stored values must equal caller_parent.
     */
    if (r->parent_pid[0] == caller_parent &&
        r->parent_pid[1] == caller_parent &&
        r->parent_pid[2] == caller_parent)
        goto allowed_and_log;

    if (TrustedImagePathException(
            r, caller_name, caller_parent, global_path))
        goto allowed_and_log;

    *desired &= ~0x3A;
    RememberPendingPostOperationCaller(r, caller_pid);
    goto allow;

allowed_and_log:
    LogCaller(r, caller_pid, 0);

allow:
    unlock(global_mutex);
    return OB_PREOP_SUCCESS;
}
```

The important answer to your original concern is therefore:

> **It is target-selective, not blanket filtering.**

A target process is affected only when:

1. Its PID has a live table slot.
2. Its slot's `+0x05` active byte is set.
3. The attempted operation creates or duplicates a process handle.
4. The requested mask includes at least one bit from `0x3A`.

The callback always returns success. It does not reject the handle operation outright; it mutates `DesiredAccess`.

## Exact stripped rights

`0x3A` is:

|    Bit | Process right           |
| -----: | ----------------------- |
| `0x02` | `PROCESS_CREATE_THREAD` |
| `0x08` | `PROCESS_VM_OPERATION`  |
| `0x10` | `PROCESS_VM_READ`       |
| `0x20` | `PROCESS_VM_WRITE`      |

Those are the central rights used for remote memory inspection/modification and common injection workflows. Microsoft’s process-access documentation assigns those exact values; remote-thread workflows also require a combination of process and VM rights. ([Microsoft Learn][3])

It does **not** strip, among others:

* `PROCESS_TERMINATE`
* `PROCESS_DUP_HANDLE`
* `PROCESS_QUERY_INFORMATION`
* `PROCESS_QUERY_LIMITED_INFORMATION`
* `PROCESS_SUSPEND_RESUME`

Existing handles are not retroactively changed. The callback acts only when a handle is created or duplicated.

## Caller exceptions

The stripping path is skipped for:

* Kernel handles.
* The target opening itself.
* Any of five PIDs stored at record offset `+0x08`.
* A caller whose inherited-parent PID equals **all three** DWORDs at `+0x1C`, `+0x20`, and `+0x24`.
* Certain process-name and full-path combinations.

The decoded trusted basenames are:

```text
svchost.exe
csrss.exe
lsass.exe
conhost.exe
```

For all four, the driver obtains the caller's full image path through:

```c
ZwQueryInformationProcess(
    ZwCurrentProcess(),
    ProcessImageFileName,  // 0x1B
    ...
);
```

It uppercases that path and compares it against:

```text
GLOBAL_REGISTERED_PATH + "\" + caller_basename
```

`svchost.exe` has an additional requirement: its inherited-parent PID must equal the DWORD at record offset `+0x28`.

For `csrss.exe`, `lsass.exe`, and `conhost.exe`, the full-path match is sufficient.

# 2. Internal process record

There are **100 records**, each `0x70` bytes, starting at `0x140006FE0`.

```c
struct PROCESS_RECORD {
    uint32_t pid;                    // +0x00
    uint8_t  enabled;                // +0x04
    uint8_t  active;                 // +0x05
    uint8_t  padding_06[2];

    uint32_t trusted_pid[5];         // +0x08 ... +0x1B
    uint32_t parent_pid[3];          // +0x1C ... +0x27
    uint32_t svchost_parent_pid;     // +0x28

    uint32_t telemetry[12];          // +0x2C ... +0x5B
    uint32_t pending_post_pid[3];    // +0x5C ... +0x67
    uint32_t postop_anomaly_pid;     // +0x68

    uint16_t authentication_state;   // +0x6C
    uint8_t  padding_6E[2];
};                                  // sizeof == 0x70
```

Relevant globals:

| Address       | Purpose                      |
| ------------- | ---------------------------- |
| `0x140006080` | Live-record count            |
| `0x140006088` | `ObRegisterCallbacks` handle |
| `0x140006FA0` | Global guarded mutex         |
| `0x140006FE0` | 100-entry record table       |
| `0x140009BA0` | Global registered path       |

`IRP_MJ_CREATE` at `0x140002EB0` inserts the current PID. A second open from the same PID fails rather than sharing the record.

`IRP_MJ_CLEANUP` at `0x140002E60` removes the record associated with the **current PID**. When the table count reaches zero, the object callback is unregistered.

That cleanup design matters because it is PID-context based rather than tied to the original file object owner.

# 3. Revised IOCTL map

There are **12 controls**, not 11. All use `METHOD_BUFFERED`, and their encoded access field is `FILE_ANY_ACCESS`.

The driver's per-PID protocol has three states:

* **State 0:** newly opened, not authenticated.
* **State 1:** authenticated.
* **State 2:** failed authentication; calls are rejected until cleanup/reopen.

| IOCTL        | Input / Output | Confirmed behavior                                                                                                       | State  |
| ------------ | -------------: | ------------------------------------------------------------------------------------------------------------------------ | ------ |
| `0xAA023800` |  `>=0x208 / 0` | Copies a 260-WCHAR path into the global path; sets current record `enabled=1`, `active=1`; registers callbacks if needed | 1      |
| `0xAA023804` |        `0 / 0` | Clears current record `enabled` at `+0x04`; protection becomes telemetry-only                                            | 1      |
| `0xAA023808` |        `0 / 0` | Sets current record `enabled=1`                                                                                          | 1      |
| `0xAA02380C` |     `0x14 / 0` | Copies **five DWORD PIDs** into `+0x08`                                                                                  | 1      |
| `0xAA023810` |     `0x0C / 0` | Copies three DWORD parent-PID values into `+0x1C`                                                                        | 1      |
| `0xAA023814` |     `0x04 / 0` | Writes the special `svchost.exe` parent PID at `+0x28`                                                                   | 1      |
| `0xAA023818` |     `0 / 0x30` | Returns and clears the 12 telemetry DWORDs, merging post-op anomaly state                                                | 1      |
| `0xAA02381C` |     `0 / 0x04` | Returns `0x44C`                                                                                                          | 0 or 1 |
| `0xAA023820` |     `0 / 0x08` | Returns a saved kernel return address from the dispatch routine's stack                                                  | 1      |
| `0xAA023824` |     `0 / 0x10` | Returns an 8-byte PID-derived token field and the relocated driver image base                                            | 0 or 1 |
| `0xAA023828` |     `0x04 / 0` | Authentication response; success moves state 0→1, failure moves state 0→2                                                | 0 only |
| `0xAA02382C` |  `0x08 / 0x04` | Computes a custom 32-bit transform over a driver-relative memory range                                                   | 1      |

## Corrections to the earlier map

The material changes are:

1. `0x3804` and `0x3808` are explicit **disable** and **enable** operations. `0x3808` does not consume a one-byte input.
2. `0x380C` accepts `0x14` bytes—five PIDs—not 16 bytes.
3. `0x3820` exists and leaks a kernel return address.
4. `0x3828` exists and performs the authentication transition.
5. `0x382C` takes `{signed_offset, length}` and returns a 32-bit integrity transform. It does not return the computed address.

`0x44C`, decimal 1100, is consistent with the file resource version `1.1.0.0`, although the code itself only establishes that it is a fixed protocol/build value.

---

# 4. Authentication and integrity protocol

`0x3824` calls the PID token function at `0x140001BF4`. The low 32 bits are derived through the 16-round function at `0x1400031AC`; the second QWORD is the driver's relocated image base.

`0x3828` then:

1. Recomputes the current PID token.
2. Selects one of four transform implementations according to approximately:

```c
variant = (current_pid >> 2) & 3;
```

3. Transforms the token.
4. Compares the result against the caller's four-byte response.

The four transform implementations begin at:

```text
0x1400035F0
0x140003760
0x1400038D0
0x140003A40
```

Those transforms also incorporate a `0x200`-byte window around their kernel call site. That strongly suggests an anti-hook or code-integrity purpose: the expected answer depends both on supplied data and on the driver's own live code bytes.

This is an attestation/challenge mechanism, not a durable authorization secret. The pre-auth protocol deliberately returns the relocation base and PID token, while the algorithms are present in the binary.

---

# 5. Post-operation callback and telemetry

`0x140001D30` is not another access-control path. It correlates operations previously modified by the pre-op callback.

For an active, enabled target:

1. It looks for the current caller PID in the three pending slots at `+0x5C`.
2. It examines the resulting granted-access mask.
3. If any `0x3A` bit remains, it records the PID at `+0x68`.
4. It clears the matching pending slot.

`0x3818` then folds this into the 12 telemetry entries.

The high bits appear to mean:

| Bit | Meaning                                                        |
| --: | -------------------------------------------------------------- |
|  31 | Caller observed while enforcement was disabled                 |
|  30 | Post-operation access still contained a forbidden `0x3A` right |
|  29 | Twelve-entry telemetry array overflowed                        |

The remaining bits hold the PID.

So `0x3818` is better described as a **consume-and-clear event queue**, not a read of the full per-process record.

---

# 6. Security findings

## A. Pre-auth driver-base disclosure

`0x3824` returns the driver's relocated image base before authentication.

That is intentionally part of the attestation protocol, but it still defeats KASLR for this module. It also makes exploiting any module-relative defect, including `0x382C`, materially easier.

## B. Authenticated kernel return-address disclosure

`0x3820` returns:

```asm
mov rax, [rbp+0x38]
mov [SystemBuffer], rax
```

At the dispatch routine's entry:

```text
rbp = original_rsp - 0x38
```

Therefore:

```text
[rbp+0x38] == [original_rsp] == saved return address
```

Under a normal call path this is a live pointer into `ntoskrnl` or an I/O/verifier wrapper. It is consequently a stronger kernel KASLR disclosure than the driver-base value from `0x3824`.

It is gated by authentication, but the authentication protocol should not be treated as a cryptographic privilege boundary.

## C. `0x382C` has a definite out-of-bounds read bug

The validator at `0x140002CF0` is effectively:

```c
int64_t  offset = (int32_t)input->offset;
uint32_t length = input->length;
uint32_t end     = (uint32_t)offset + length;  // wraps at 32 bits

if (end > 0x4220)
    reject;

if ((uint32_t)offset < 0x18F0 && end >= 0x18F0)
    reject;

uint8_t *ptr = DriverImageBase + offset;
return Transform(ptr, length);
```

There are two related problems:

* The end calculation is only 32 bits and may wrap.
* The offset is sign-extended for pointer arithmetic but compared as unsigned in the boundary test.

A small concrete case is:

```text
offset = -4        // 0xFFFFFFFC
length = 4
end    = 0         // wraps
ptr    = ImageBase - 4
```

That request passes both checks and causes the selected transform to read one DWORD immediately before the loaded image.

This is at least:

* A likely kernel denial-of-service primitive when the preceding page is unmapped.
* A memory-dependent checksum oracle when the memory is mapped.
* An out-of-bounds kernel read by definition.

I would **not yet call it an arbitrary raw kernel read**. The caller receives a custom 32-bit transform, not the original bytes, and longer negative offsets force the transform to process the intervening range. Determining whether the four-byte case can be efficiently inverted would require formal emulation of all four transform variants and their call-site mixing.

## D. The trusted-path design is globally mutable

The path supplied through `0x3800` is global, not per protected record.

Consequently, any authenticated client capable of issuing `0x3800` can replace the trust root used for all protected processes. The callback then trusts binaries named:

```text
csrss.exe
lsass.exe
conhost.exe
```

when their full path equals the attacker-selected global directory plus that basename. `svchost.exe` adds the parent-PID condition, but the other three do not.

Conceptually, this makes the whitelist bypassable by an authenticated client that can:

1. Replace the global directory.
2. Run a process with one of the trusted basenames from that directory.
3. Open protected targets from that process.

The guarded mutex prevents concurrent corruption; it does not provide caller authorization.

## E. Device ACL is the decisive missing fact

The driver creates a named device with `IoCreateDevice` and does not import or call `IoCreateDeviceSecure`. All IOCTLs encode `FILE_ANY_ACCESS`.

That does **not** by itself establish that ordinary users can open the device. The effective security descriptor may be supplied by the service's INF or registry configuration. Microsoft documents that named device security is normally established through the INF, and `IoCreateDeviceSecure` is used when the security descriptor cannot be supplied that way. ([Microsoft Learn][4])

Therefore the risk splits sharply:

* **Administrator/SYSTEM-only device:** vulnerabilities remain real but are lower-value local issues.
* **Standard-user-openable device:** the KASLR disclosures, path-trust weakness, table exhaustion, and `0x382C` kernel crash become substantially more serious.

## F. PID-only trust and lifecycle

All identity and trust decisions use raw PIDs. I found no process-creation-time check and no retained `EPROCESS` reference.

That creates two plausible lifecycle weaknesses:

* A stale trusted PID may later refer to a different process after PID reuse.
* Cleanup removes the slot for the process executing `IRP_MJ_CLEANUP`, not necessarily the process that originally opened the file object. A duplicated or inherited device handle could therefore leave a stale original slot.

The second point is a static inference rather than a demonstrated exploit. The lack of any process-exit notification callback makes stale-state handling more concerning.

The fixed 100-record table also permits simple concurrent-open exhaustion if unprivileged callers can access the device.

# 7. Effect on debuggers, GlassPane-style tools, and AV

The practical behavior is:

| Situation                                         | Result                                                  |
| ------------------------------------------------- | ------------------------------------------------------- |
| Target PID is not in the driver's table           | No effect                                               |
| Target has a slot but `active` at `+0x05` is zero | No effect                                               |
| Target is active but `enabled` at `+0x04` is zero | Handle unchanged; caller logged                         |
| Target is active and enabled                      | `0x3A` removed unless caller qualifies for an exception |
| Handle already existed before protection          | Not retroactively modified                              |
| Kernel handle                                     | Bypassed                                                |
| Thread-object handle                              | Not covered by this registration                        |

A user-mode tool requesting process memory rights against a protected target will receive a handle without:

```text
PROCESS_VM_READ
PROCESS_VM_WRITE
PROCESS_VM_OPERATION
PROCESS_CREATE_THREAD
```

So memory viewing, patching, remote allocation, and common injection workflows will fail or become incomplete.

A query-only tool may continue working because query rights are not removed. A kernel component using kernel handles is outside this filter. The driver is therefore specifically anti-debug/anti-tamper rather than a blanket “deny all process access” mechanism.

**Your correction holds up.** I independently traced the uploaded sample and found no attacker-selected `EPROCESS` read/OR/AND-NOT path.

This driver is a **process-handle protection and self-integrity attestation component**. It protects explicitly enrolled processes by modifying access masks during process-handle creation and duplication. It also contains real vulnerabilities—but they are different from the old LOLDrivers primitive.

The official Steam page for *hololive Dreams* identifies `usrdrv017964.sys` as part of the game's security-protection component. That attribution aligns with the binary’s anti-tamper design, but the publisher’s claim that it is safe is not a substitute for auditing its kernel attack surface. ([Steam Store][1])

## What it actually does

The `ObRegisterCallbacks` registration is:

| Field                   | Value                       |
| ----------------------- | --------------------------- |
| Object type             | `PsProcessType`             |
| Operations              | Handle create and duplicate |
| Pre-operation callback  | `0x140001DF0`               |
| Post-operation callback | `0x140001D30`               |
| Altitude                | `88180.66332211`            |
| Thread callbacks        | None                        |

The callback is globally registered, but its enforcement is **target-selective**. It only alters a handle when:

1. The target PID has a live record in the driver’s 100-entry table.
2. The record’s `active` byte is set.
3. The operation creates or duplicates a process handle.
4. It is not a kernel handle.
5. The requested rights contain at least one bit from `0x3A`.
6. The caller does not satisfy an allow rule.

When all those conditions are met, it performs:

```c
DesiredAccess &= ~0x3A;
```

That removes:

```text
PROCESS_CREATE_THREAD  0x0002
PROCESS_VM_OPERATION   0x0008
PROCESS_VM_READ        0x0010
PROCESS_VM_WRITE       0x0020
```

Those values correspond to remote thread creation and process-memory operations. The callback does not reject the open—it lets the operation continue with reduced rights. ([Microsoft Learn][2])

Consequently:

* An unenrolled target is unaffected.
* Existing handles are unaffected.
* Kernel handles are bypassed.
* Thread-object handles are unaffected.
* Query-only process access can continue working.
* User-mode debuggers and scanners opening the target after protection may lose memory access.
* The driver does not blanket-strip access against every process.

## Corrected IOCTL surface

There are **12 IOCTLs**, not 11:

| IOCTL        | Input / output | Purpose                                                                  |
| ------------ | -------------: | ------------------------------------------------------------------------ |
| `0xAA023800` |  `>=0x208 / 0` | Sets global trusted path, activates current process, registers callbacks |
| `0xAA023804` |        `0 / 0` | Disables enforcement; telemetry remains active                           |
| `0xAA023808` |        `0 / 0` | Re-enables enforcement                                                   |
| `0xAA02380C` |     `0x14 / 0` | Sets five trusted caller PIDs                                            |
| `0xAA023810` |     `0x0C / 0` | Sets three parent-PID values                                             |
| `0xAA023814` |        `4 / 0` | Sets special `svchost.exe` parent PID                                    |
| `0xAA023818` |     `0 / 0x30` | Consumes and clears 12 telemetry entries                                 |
| `0xAA02381C` |        `0 / 4` | Returns fixed value `0x44C`                                              |
| `0xAA023820` |        `0 / 8` | Returns a saved kernel return address                                    |

The per-process authentication state is:

```text

1 = authenticated

```

Before authentication, the caller can use the version query, PID-token/base query, and authentication-response operation.

## Trusted caller logic

The callback bypasses stripping for:

* The protected process itself.
* Any of five configured PIDs.
* A caller whose inherited-parent PID equals all three values at offsets `+0x1C`, `+0x20`, and `+0x24`.
* Several trusted executable-name and path combinations.

The decoded trusted names are:

```text
svchost.exe
csrss.exe
lsass.exe
conhost.exe
```

The driver queries the caller’s full image path and compares it against:

```text
GLOBAL_TRUSTED_DIRECTORY + "\" + trusted_basename
```

For `svchost.exe`, the caller’s inherited parent must also match the special DWORD at `+0x28`.

For `csrss.exe`, `lsass.exe`, and `conhost.exe`, the full-path match is sufficient.

### `0x382C`: definite out-of-bounds kernel read

The range check behaves approximately as:

```c
int64_t offset = (int32_t)input->offset;
uint32_t length = input->length;

uint32_t end = (uint32_t)offset + length;  // 32-bit wrap

if (end > 0x4220)
    reject;

if ((uint32_t)offset < 0x18F0 && end >= 0x18F0)
    reject;

uint8_t *address = DriverImageBase + offset; // sign-extended
return IntegrityTransform(address, length);
```

A concrete accepted case is:

```text
offset = -4
length = 4

checked end     = 0 due to 32-bit wrap
effective range = DriverImageBase - 4 through DriverImageBase - 1
```

The validator treats the offset as unsigned during part of the bounds check but sign-extends it for pointer construction.

That gives the authenticated caller an **out-of-bounds kernel read through a custom checksum transform**. It can plausibly:

* Crash the machine when the traversed memory is unmapped.
* Produce a memory-dependent checksum when it is mapped.
* Access data before or beyond the intended driver range using other wrapped combinations.

I am not calling this a raw arbitrary-read primitive because the returned value is a code-dependent 32-bit transform, not the original bytes. I also found no proof that it yields privilege escalation by itself.

### Pointer disclosures

`0x3824` returns the relocated driver base before authentication.

`0x3820` reads `[rbp+0x38]`; based on the dispatcher prologue, that is the saved return address from the original stack frame. Under a normal path, it is a pointer into kernel, I/O-manager, or verifier code.

The second disclosure is authentication-gated, but the authentication algorithm is an attestation mechanism embedded in the companion protocol—not a strong principal-authentication boundary.

### Global trusted-directory weakness

`0x3800` writes a **single global path**, not a path contained in the caller’s process record.

That means one authenticated client can alter the trusted-directory basis used for every protected process. Because the `csrss.exe`, `lsass.exe`, and `conhost.exe` exceptions rely on that mutable directory plus basename, an authenticated client can plausibly:

1. Replace the global trusted directory.
2. Run a process from that directory using one of the trusted basenames.
3. Open protected processes without losing `0x3A` rights.

That is a direct bypass of the driver’s protection policy, although not inherently a Windows privilege escalation.

### PID and cleanup weaknesses

The driver trusts raw PID values without:

* A process creation timestamp.
* A retained `EPROCESS` reference.
* A process-exit callback.
* File-object-bound ownership information.

This introduces PID-reuse risk.

Additionally, `IRP_MJ_CLEANUP` removes the record for the PID currently executing cleanup, rather than tracking the process that originally created the file object. A device handle inherited or duplicated into another process could therefore clean the wrong PID—or leave the original record stale.

### Record-clearing bug

When removing a process record, the routine does not clear:

```text
+0x5C  pending_post_pid[0]
+0x60  pending_post_pid[1]
+0x64  pending_post_pid[2]
+0x68  postop_anomaly_pid
```

A later process receiving that slot can inherit stale post-operation state, causing false telemetry and reducing the effective three-entry correlation capacity.

### Unsafe name-collision recovery

If `IoCreateDevice` reports that `\Device\Htsysm6321` already exists, the driver:

1. Calls `IoGetDeviceObjectPointer` on the existing name.
2. Calls `IoDeleteDevice` on the returned device object.
3. Retries its own device creation.

That device may belong to another driver. Deleting a device object the current driver does not own is unsafe.

The associated file-object reference also appears never to be released. Microsoft documents that the file object returned by `IoGetDeviceObjectPointer` must eventually be dereferenced. ([Microsoft Learn][3])

## The unresolved severity multiplier: device ACL

The driver uses `IoCreateDevice`, not `IoCreateDeviceSecure`, and all IOCTLs encode `FILE_ANY_ACCESS`.

This still does **not** prove that an ordinary user can open `\\.\Htsysm6321`. For named devices created with `IoCreateDevice`, Windows expects the security descriptor to be supplied by the INF; otherwise a secure-device creation routine should be used. ([Microsoft Learn][4])

Therefore:

* **Admin/SYSTEM-only ACL:** mostly hardening, anti-tamper-bypass, information-leak, and robustness issues.
* **Standard-user-accessible ACL:** meaningful local attack surface, including module-base disclosure, potential table exhaustion, and—after reproducing authentication—the kernel-pointer disclosure and OOB checksum read.

The INF or service installation package is the next decisive artifact.

## What the sidecar is

```text
File:   hololive-Dreams.exe._
Size:   735,920 bytes
SHA-256:
22ae3c2e8abdd28143cd39c7d9125e0e896ba0f2e6d498eda6e82d6af2cdfd03
```

It is not a conventional PE. It is a custom encrypted payload consumed by the small launcher in `hololive-Dreams.exe`. This explains why searching the installed EXE and DLL files for `Htsysm6321` or the IOCTL values returned nothing.

The earlier handle capture independently confirms that the resulting `hololive-Dreams.exe` process owns a read/write handle to `\Device\Htsysm6321`.

## Unpacking progress

The sidecar uses multiple nested protection layers:

1. A `KONN`-marked outer loader.
2. Several small embedded PE-like transform modules.
3. AES-family block transforms.
4. Per-stage rotating-XOR transforms.
5. A custom Huffman/LZ decompressor.
6. Dynamically generated callbacks and exception handlers.
7. Anti-debugging and virtual-machine probes.
8. A later process-launch and process-mapping stage.

The first loaded sidecar stage is mapped around RVA `0xA7000`, with an initial protected entry point around `0xA8C00`.

I have reconstructed and passed the following stages:

```text
Outer KONN descriptor
First encrypted region
Four embedded transform modules
Two encrypted template regions
Four generated callback fragments
Nested integrity/hash stage
Exception/single-step stage
Anti-debug stage
0x576C-byte process-loader stage
```

## The important recovered stage

A decompressed `0x576C`-byte payload is installed at RVA `0xAD280`. Its resolved APIs include:

```text
CreateProcessW
ResumeThread
GetThreadContext
SetThreadContext
WriteProcessMemory
VirtualProtectEx
NtUnmapViewOfSection
MapViewOfFile
CreateFileMappingA
GetExitCodeProcess
NtTerminateProcess
NtQueryInformationProcess
DbgUiRemoteBreakin
IsDebuggerPresent
CheckRemoteDebuggerPresent
NtQuerySecurityObject
NtSetSecurityObject
RtlGetDaclSecurityDescriptor
```

That combination strongly indicates a **suspended-process replacement or image-remapping loader**, with anti-debug checks and security-descriptor manipulation.

In plain terms, the small launcher does not contain the final game/security client on disk. It reconstructs a native loader, starts or remaps another process image, and only then exposes the code that communicates with the kernel driver. This is why ordinary strings and static import searches missed the client.

This behavior is consistent with a commercial anti-tamper wrapper. It is also behavior that deserves scrutiny because it is intentionally indistinguishable from common process-hollowing machinery at the API level.

## Current blocking layer

The next descriptor is:

```text
Encrypted source RVA:  0xB2A0C
```

The stage derives:

```text

Rotating-XOR key:        0x646A4362
```

Before applying that rotating-XOR and the known decompressor, it invokes an AES-like block transform at RVA `0xC4A60`.

The selected configuration is the `0xF4`-byte structure at RVA:

```text
0xFD1F6
```

Its layout begins:

```text
00 01 0E 00 ...
```

and is followed by exactly 240 bytes of key material—the same size as an AES-256 expanded round-key schedule. The routine performs a 16-byte-block transform through the function at `0xC58C0`, using large AES-style lookup tables.

What remains incomplete is reproducing the exact mode around that AES primitive. It is not a simple direct AES-CBC call with either of the two static keys recovered from earlier layers. The wrapper appears to combine the block result with the source data in a custom feedback or keystream construction.

## What the launcher does

The outer `hololive-Dreams.exe` wrapper:

1. Obtains its own executable path.
2. Appends `._`.
3. Opens `hololive-Dreams.exe._`.
4. Creates a file mapping.
5. Maps the sidecar into memory.
6. Decodes a `KONN`-marked descriptor.
7. Decrypts and maps the next runtime layer.

The primary decoded descriptor is:

| Field                       |        Value |
| --------------------------- | -----------: |
| Marker                      |       `KONN` |
| Seed                        | `0x7C231879` |
| Wrapper entry RVA           |     `0x1B5C` |
| Sidecar source offset       |      `0x4E0` |
| Runtime destination RVA     |    `0xA7000` |
| Runtime payload size        |    `0x3E3C0` |
| Initially encrypted portion |     `0x3C00` |
| Recovered OEP RVA           |    `0xA8C00` |

The first `0x3C00` bytes use a stateful DWORD transform; the remaining `0x3A7C0` bytes are copied into the reconstructed image.

The reconstructed configuration contains **four encrypted callback blocks**:

| Variant | Descriptor |     Block | Packed size | Expanded size |  Callback |
| ------: | ---------: | --------: | ----------: | ------------: | --------: |

```ps1
$root = $PSScriptRoot

$distDir = Join-Path $root "dist"

    throw "Visual Studio C++ Build Tools were not found."
}

$vcvars = Join-Path $installation "VC\Auxiliary\Build\vcvars64.bat"

$compile = @(

) -join " && "

& cmd.exe /d /c $compile
if ($LASTEXITCODE -ne 0) {
    throw "Native build failed with exit code $LASTEXITCODE."
}

if (-not $SkipTests) {
    $previousDll = $env:HOLO_EMU_DLL
    $previousLog = $env:HOLO_EMU_LOG
    $previousDriver = $env:HOLO_EMU_DRIVER_IMAGE
    $previousVirtual = $env:HOLO_EMU_FORCE_VIRTUAL_SERVICE
    try {
        $env:HOLO_EMU_DLL = Join-Path $buildDir "Emulator.dll"
        $env:HOLO_EMU_LOG = Join-Path $buildDir "self-test.log"
        $env:HOLO_EMU_DRIVER_IMAGE =
            Join-Path $root "usrdrv017964.sys"
        $env:HOLO_EMU_FORCE_VIRTUAL_SERVICE = "1"
        & (Join-Path $buildDir "test_client.exe")
        if ($LASTEXITCODE -ne 0) {
            throw "Self-test failed with exit code $LASTEXITCODE."
        }
        & (Join-Path $buildDir "loader.exe") --check
        if ($LASTEXITCODE -ne 0) {
            throw "Loader configuration check failed with exit code $LASTEXITCODE."

        -Destination (Join-Path $distDir $name) -Force
}

foreach ($name in "README.md", "run-windows.ps1",

        -Destination (Join-Path $distDir $name) -Force
```

```c
/*
 * emulator.c
 *
 * Usermode emulator for the kernel driver usrdrv017964.sys
 * (device \Device\Htsysm6321, opened from usermode as \\.\Htsysm6321).
 *
 * Protocol source: REfindings.txt
 *   - 12 IOCTLs 0xAA023800..0xAA02382C, all METHOD_BUFFERED / FILE_ANY_ACCESS
 *   - per-process auth states: 0 = unauthenticated, 1 = authenticated,
 *     2 = failed (locked until cleanup/reopen)
 *   - state 0 may use: 0x381C (version), 0x3824 (token+base), 0x3828 (auth)
 *   - state 1 may use everything except 0x3828
 *   - IRP_MJ_CREATE inserts a record for the caller PID; a second open from
 *     the same PID fails. IRP_MJ_CLEANUP removes the caller's record.
 *
 * The PID token and the 0x382C/auth integrity transforms are byte-exact
 * reimplementations of the driver's algorithms (recovered by static
 * disassembly of usrdrv017964.sys; see the "exact crypto" section). All
 * absolute-address inputs use EMU_FAKE_DRIVER_BASE, the same base reported
 * via 0x3824, keeping client-side recomputation consistent. The 0x3828
 * response is still accepted unconditionally, but the expected value is
 * computed and logged for verification.
 *
 * The .sys bytes (loaded from an override, next to this DLL, or the runtime's
 * Windows system directory)
 * back the transform's image reads; offsets outside the image (including
 * the negative-offset OOB case, REfindings 6.C) use a deterministic
 * synthetic byte stream and never read real OOB memory.
 *
 * Launch sequencing (learned from Event Viewer / emulator.log):
 *   - The launcher installs and starts the "usrdrv017964" service via the
 *     SCM before opening the device. With the service disabled,
 *     StartServiceW fails and the game exits silently. The advapi32
 *     service APIs and NtLoadDriver are therefore hooked and faked
 *     (service present + RUNNING, driver "loaded").
 *   - Caller-requested suspended children are still injected only from
 *     NtResumeThread, after the parent has finished hollowing them.
 *   - Normally-running game children are temporarily created suspended,
 *     injected before any child code executes, and then released. This
 *     closes the missing-driver race without touching a hollowing window.
 */

static BOOL EmuEnvironmentFlag(const char* name) {
    char value[16];
    DWORD length = GetEnvironmentVariableA(name, value, ARRAYSIZE(value));
    if (!length || length >= ARRAYSIZE(value)) return FALSE;
    return _stricmp(value, "0") != 0 &&
           _stricmp(value, "false") != 0 &&
           _stricmp(value, "off") != 0 &&
           _stricmp(value, "no") != 0;
}

static void EmuInitializeConfiguration(void) {
    DWORD length = GetEnvironmentVariableA(
        "HOLO_EMU_LOG", g_LogPath, ARRAYSIZE(g_LogPath));
    if (!length || length >= ARRAYSIZE(g_LogPath)) {
        char* slash;
        length = GetModuleFileNameA(
            g_hModule, g_LogPath, ARRAYSIZE(g_LogPath));
        if (!length || length >= ARRAYSIZE(g_LogPath)) {
            strcpy_s(g_LogPath, ARRAYSIZE(g_LogPath), "emulator.log");
        } else {
            slash = strrchr(g_LogPath, '\\');
            if (!slash) slash = strrchr(g_LogPath, '/');
            if (slash) {
                strcpy_s(slash + 1,
                         ARRAYSIZE(g_LogPath) -
                             (SIZE_T)(slash + 1 - g_LogPath),
                         "emulator.log");
            } else {
                strcpy_s(g_LogPath, ARRAYSIZE(g_LogPath), "emulator.log");
            }
        }
    }
    g_TraceEnabled = EmuEnvironmentFlag("HOLO_EMU_TRACE");
    g_ForceVirtualService =
        EmuEnvironmentFlag("HOLO_EMU_FORCE_VIRTUAL_SERVICE");
}

void LogMessage(const char* format, ...) {
    FILE* f;
    fopen_s(&f, g_LogPath, "a");
    if (f) {
        fprintf(f, "[%llu pid=%lu tid=%lu] ",
                (unsigned long long)(GetTickCount64() / 1000),
                GetCurrentProcessId(),
                GetCurrentThreadId());
        va_list args; va_start(args, format); vfprintf(f, format, args); va_end(args);
        fprintf(f, "\n"); fclose(f);
    }
}

static void EmuLogAddress(const char* label, const void* address) {
    HMODULE module = NULL;
    if (address &&
        GetModuleHandleExA(GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS |
                           GET_MODULE_HANDLE_EX_FLAG_UNCHANGED_REFCOUNT,
                           (LPCSTR)address, &module) &&
        module) {
        char modulePath[MAX_PATH];
        char* moduleName;
        GetModuleFileNameA(module, modulePath, MAX_PATH);
        moduleName = strrchr(modulePath, '\\');
        LogMessage("[Emu] %s %s+0x%llX", label,
                   moduleName ? moduleName + 1 : modulePath,
                   (unsigned long long)((ULONG_PTR)address -
                                        (ULONG_PTR)module));
    } else {
        LogMessage("[Emu] %s %p (unbacked)", label, address);
    }
}

static LONG CALLBACK EmuCrashObserver(PEXCEPTION_POINTERS pointers) {
    PEXCEPTION_RECORD record;
    PCONTEXT context;
    ULONG_PTR accessType = 0;
    ULONG_PTR accessAddress = 0;
    ULONG_PTR* stack;
    MEMORY_BASIC_INFORMATION mbi;
    SIZE_T readableBytes = 0;
    SIZE_T i;

    if (!pointers || !pointers->ExceptionRecord || !pointers->ContextRecord)
        return EXCEPTION_CONTINUE_SEARCH;

    record = pointers->ExceptionRecord;
    context = pointers->ContextRecord;
    if (record->ExceptionCode != EXCEPTION_ACCESS_VIOLATION &&
        record->ExceptionCode != EXCEPTION_ILLEGAL_INSTRUCTION &&
        record->ExceptionCode != EXCEPTION_STACK_OVERFLOW)
        return EXCEPTION_CONTINUE_SEARCH;
    if (InterlockedCompareExchange(&g_CrashLogged, 1, 0) != 0)
        return EXCEPTION_CONTINUE_SEARCH;

    if (record->ExceptionCode == EXCEPTION_ACCESS_VIOLATION &&
        record->NumberParameters >= 2) {
        accessType = record->ExceptionInformation[0];
        accessAddress = record->ExceptionInformation[1];
    }

    LogMessage("[Emu] CRASH code=0x%08lX flags=0x%08lX "
               "access_type=%llu access_address=%p RIP=%p RSP=%p "
               "RBP=%p rsp_align=%llu",
               (ULONG)record->ExceptionCode,
               (ULONG)record->ExceptionFlags,
               (unsigned long long)accessType,
               (void*)accessAddress,
               (void*)context->Rip,
               (void*)context->Rsp,
               (void*)context->Rbp,
               (unsigned long long)(context->Rsp & 0xFULL));
    LogMessage("[Emu]   registers: RAX=%p RBX=%p RCX=%p RDX=%p "
               "RSI=%p RDI=%p",
               (void*)context->Rax, (void*)context->Rbx,
               (void*)context->Rcx, (void*)context->Rdx,
               (void*)context->Rsi, (void*)context->Rdi);
    LogMessage("[Emu]   registers: R8=%p R9=%p R10=%p R11=%p "
               "R12=%p R13=%p R14=%p R15=%p",
               (void*)context->R8,  (void*)context->R9,
               (void*)context->R10, (void*)context->R11,
               (void*)context->R12, (void*)context->R13,
               (void*)context->R14, (void*)context->R15);
    EmuLogAddress("crash site:", (void*)context->Rip);

    stack = (ULONG_PTR*)context->Rsp;
    if (VirtualQuery(stack, &mbi, sizeof(mbi)) == sizeof(mbi) &&
        mbi.State == MEM_COMMIT &&
        !(mbi.Protect & (PAGE_NOACCESS | PAGE_GUARD))) {
        readableBytes = (SIZE_T)((ULONG_PTR)mbi.BaseAddress +
                                 mbi.RegionSize -
                                 (ULONG_PTR)stack);
        if (readableBytes > 0x400)
            readableBytes = 0x400;
    }

    for (i = 0; i < readableBytes / sizeof(ULONG_PTR); i++) {
        ULONG_PTR candidate = stack[i];
        HMODULE module = NULL;
        if (candidate &&
            GetModuleHandleExA(GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS |
                               GET_MODULE_HANDLE_EX_FLAG_UNCHANGED_REFCOUNT,
                               (LPCSTR)candidate, &module) &&
            module) {
            char modulePath[MAX_PATH];
            char* moduleName;
            GetModuleFileNameA(module, modulePath, MAX_PATH);
            moduleName = strrchr(modulePath, '\\');
            LogMessage("[Emu]   crash stack +0x%03llX: %s+0x%llX",
                       (unsigned long long)(i * sizeof(ULONG_PTR)),
                       moduleName ? moduleName + 1 : modulePath,
                       (unsigned long long)(candidate -
                                            (ULONG_PTR)module));
        }
    }

    return EXCEPTION_CONTINUE_SEARCH;
}

/* ================= name matching ================= */

/* Case-insensitive bounded substring match for "htsysm6321".
 * Matches \\.\Htsysm6321, \??\Htsysm6321 and path-suffixed opens such as
 * \\.\Htsysm6321\probe (the driver does not set FILE_DEVICE_SECURE_OPEN and
 * its create handler ignores FileName - REfindings "new static finding"). */
static BOOL EmuNameMatchesBuf(const WCHAR* buf, SIZE_T chars) {
    static const WCHAR needle[] = L"htsysm6321";
    const SIZE_T nlen = 10;
    SIZE_T i, j;
    if (!buf) return FALSE;
    for (i = 0; i + nlen <= chars; i++) {
        for (j = 0; j < nlen; j++) {
            WCHAR c = buf[i + j];
            if (c >= L'A' && c <= L'Z') c = (WCHAR)(c + 32);
            if (c != needle[j]) break;
        }
        if (j == nlen) return TRUE;
    }
    return FALSE;
}

static BOOL EmuNameMatches(const WCHAR* s) {
    return s && EmuNameMatchesBuf(s, wcslen(s));
}

static BOOL EmuWideContainsCI(const WCHAR* buf, SIZE_T chars,
                              const WCHAR* needle) {
    SIZE_T i, j, nlen;
    if (!buf || !needle) return FALSE;
    nlen = wcslen(needle);
    if (!nlen || chars < nlen) return FALSE;
    for (i = 0; i + nlen <= chars; i++) {
        for (j = 0; j < nlen; j++) {
            WCHAR a = buf[i + j];
            WCHAR b = needle[j];
            if (a >= L'A' && a <= L'Z') a = (WCHAR)(a + 32);
            if (b >= L'A' && b <= L'Z') b = (WCHAR)(b + 32);
            if (a != b) break;
        }
        if (j == nlen) return TRUE;
    }
    return FALSE;
}

static BOOL EmuWideEndsWithCI(const WCHAR* buf, SIZE_T chars,
                              const WCHAR* suffix) {
    SIZE_T suffixChars;
    if (!buf || !suffix) return FALSE;
    suffixChars = wcslen(suffix);
    if (chars < suffixChars) return FALSE;
    return _wcsnicmp(buf + chars - suffixChars,
                     suffix, suffixChars) == 0;
}

/*
 * Keep the in-process disk trace focused enough that LogMessage's own file
 * writes cannot recurse. These patterns cover the driver binary, device
 * name, driver-store metadata, and any alternate .sys dependency.
 */
static BOOL EmuInterestingDiskNameBuf(const WCHAR* buf, SIZE_T chars) {
    return EmuWideContainsCI(buf, chars, L"usrdrv017964") ||
           EmuWideContainsCI(buf, chars, L"htsysm6321") ||
           EmuWideEndsWithCI(buf, chars, L".sys") ||
           EmuWideEndsWithCI(buf, chars, L".cat") ||
           EmuWideEndsWithCI(buf, chars, L".inf");
}

static BOOL EmuInterestingDiskName(const WCHAR* s) {
    return s && EmuInterestingDiskNameBuf(s, wcslen(s));
}

static void EmuLogNativeDiskProbe(const char* api,
                                  POBJECT_ATTRIBUTES attributes,
                                  NTSTATUS status,
                                  void* caller) {
    WCHAR path[512];
    SIZE_T chars;
    if (!g_TraceEnabled || !attributes || !attributes->ObjectName ||
        !attributes->ObjectName->Buffer)
        return;
    chars = attributes->ObjectName->Length / sizeof(WCHAR);
    if (!EmuInterestingDiskNameBuf(attributes->ObjectName->Buffer, chars))
        return;
    if (chars >= ARRAYSIZE(path)) chars = ARRAYSIZE(path) - 1;
    memcpy(path, attributes->ObjectName->Buffer, chars * sizeof(WCHAR));
    path[chars] = L'\0';
    LogMessage("[Trace] disk %s(\"%ls\") -> 0x%08lX",
               api, path, (ULONG)status);
    EmuLogAddress("disk probe caller:", caller);
}

static BOOL EmuIsFakeHandle(HANDLE h) {
    return h == EMU_FAKE_HANDLE_VALUE;
}

/* ================= exact crypto (recovered from the .sys) =================
 * Byte-exact reimplementation of the driver's transform algorithms,
 * reverse engineered from usrdrv017964.sys:
 *
 *   0x1400031AC  PidToken16Rounds: 16 rounds of the bit-network mixer
 *                over (pid ^ seed[.data 0x60E8]).
 *   0x1400030F8  helper_30F8: bit-permutation network; when dl != 0 it adds
 *                two sub-gadget mixing rounds (gadget table 0x32F0).
 *   0x1400035F0..0x140003A40  four transform variants. Each:
 *                1) dword rotate-mix over the 0x200-byte window around its
 *                   caller's return address, then over the data buffer
 *                   (ebx ^= ptr_low32 when n > 1);
 *                2) if depth != 0: recursively call variant
 *                   [(hash ^ sel) & 3] with (depth-1, sel=hash, no data);
 *                3) three rounds of the 16 phase-3 gadgets (0x2500 table),
 *                   each a 5-round sub-gadget loop (table 0x31F0).
 *   The dispatch (0x1400033F0) calls variant[(pid>>2)&3] with
 *   (depth=2, sel=0) for both 0x3828 (data = 4-byte PID token) and
 *   0x382C (data = image bytes at the requested signed offset).
 *
 * Sub-gadget semantics (validated against the live client + Unicorn):
 *   "mov rdx,[rsp]" loads the gadget's own return address FIRST, so the
 *   final "xor eax,edx" mixes low32(call_site), never the inherited edx.
 *   The inherited edx is only consumed by helper_30F8's "test dl,dl"
 *   (always true from the variants' "mov dl,1"; false from PidToken).
 *   Verified: expected auth value == live client response (0x6490B336).
 */

/* Byte source for image reads: real .sys bytes when available, otherwise a
 * synthetic function of the signed driver-relative offset. Never reads
 * outside our own buffers, even for the negative-offset OOB requests the
 * real validator accepts (REfindings 6.C). */
static UCHAR EmuDriverByte(LONGLONG off) {
    if (g_SysBytes && off >= 0) {
        ULONGLONG rva = (ULONGLONG)off;
        int i;

        /* PE headers are mapped byte-for-byte at RVA zero. */
        if (rva < g_SysHeadersSize && rva < g_SysBytesSize)
            return g_SysBytes[rva];

        for (i = 0; i < g_SectionCount; i++) {
            if (rva >= g_Sections[i].vaStart && rva < g_Sections[i].vaEnd) {
                ULONGLONG delta = rva - g_Sections[i].vaStart;
                ULONGLONG raw = (ULONGLONG)g_Sections[i].rawStart + delta;
                if (delta < g_Sections[i].rawSize && raw < g_SysBytesSize)
                    return g_SysBytes[raw];
                /* A section's virtual tail is zero-filled by the PE loader. */
                return 0;
            }
        }

        /* Gaps between mapped headers/sections are zero-filled, not random. */
        if (rva < g_SysImageSize)
            return 0;
    }
    {
        ULONG64 x = (ULONG64)off * 0x9E3779B97F4A7C15ULL;
        x ^= x >> 29; x *= 0xBF58476D1CE4E5B9ULL; x ^= x >> 32;
        return (UCHAR)x;
    }
}

static ULONG32 EmuImageDword(LONGLONG rva) {
    return (ULONG32)EmuDriverByte(rva) |
           ((ULONG32)EmuDriverByte(rva + 1) << 8) |
           ((ULONG32)EmuDriverByte(rva + 2) << 16) |
           ((ULONG32)EmuDriverByte(rva + 3) << 24);
}

/* sub-gadget (table 0x31F0, 32 entries):
 * eax = image_byte[ret + delta] ^ cl ^ low32(BASE + ret) */
static ULONG32 EmuG10(int idx, LONG callRetRva, ULONG32 cl) {
    static const signed char deltas[32] = {
        0x16, -0x2E, -0x72, 0x4A, -0x0B, -0x4F, 0x6D, 0x29,
        -0x2C, -0x70, 0x4C, 0x08, -0x4D, 0x6F, 0x2B, -0x19,
        -0x6E, 0x4E, 0x0A, -0x3A, 0x71, 0x2D, -0x17, -0x5B,
        0x50, 0x0C, -0x38, -0x7C, 0x2F, -0x15, -0x59, 0x63
    };
    return (ULONG32)EmuDriverByte(callRetRva + (LONG)deltas[idx]) ^ cl ^
           (ULONG32)(EMU_FAKE_DRIVER_BASE + (ULONG32)callRetRva);
}

/* helper_30F8 bit network (pure part) */
static ULONG32 EmuBitNet(ULONG32 x) {
    ULONG32 edi = 0;
    ULONG32 r8  = ((x & 3) << 1) | (x >> 31);
    ULONG32 c   = ((x & 1) << 2) | (x >> 30);
    ULONG32 cl;
    if (r8 - 1 <= 3) edi = 1;
    if (c - 1 <= 3)  edi |= 0x80000000u;
    for (cl = 1; cl < 0x1F; cl++) {
        ULONG32 v = (x >> (cl - 1)) & 7;
        if (v - 1 <= 3) edi |= (1u << cl);
    }
    return edi;
}

/* helper_30F8: with gadgets=1, the dl-flag gadget rounds (table 0x32F0) */
static ULONG32 EmuMix30F8(ULONG32 x, int gadgets) {
    ULONG32 edi = EmuBitNet(x);
    if (gadgets) {
        edi ^= EmuG10(16 + (int)(edi & 0xF), 0x3185, edi & 0xFF);
        edi ^= EmuG10(16 + (int)(edi & 0xF), 0x319A, edi & 0xFF);
    }
    return edi;
}

/* phase-3 gadget (table 0x2500, 16 entries): 5-round sub-gadget loop */
static ULONG32 EmuP3Gadget(int k, ULONG32 input) {
    static const ULONG32 start_xor[16] = {
        0x88322991u, 0u,          0x19D89909u, 0u,
        0x3DB3D670u, 0u,          0xCF5A45E8u, 0u,
        0xF335834Fu, 0u,          0x84DBF2C7u, 0u,
        0xA8B7302Eu, 0u,          0x3A5D9FA6u, 0u
    };
    static const ULONG32 round_xor[16] = {
        0x1A66F780u, 0x633A2F3Cu, 0xAC0D66F8u, 0xF4E09EB4u,
        0xCFE8A45Fu, 0x18BBDC1Bu, 0x618F13D7u, 0xAA624B93u,
        0x856A513Eu, 0xCE3D88FAu, 0x1710C0B6u, 0x5FE3F872u,
        0x3AEBFE1Du, 0x83BF35D9u, 0xCC926D95u, 0x1565A551u
    };
    static const ULONG32 end_xor[16] = {
        0u,          0xF56EFD2Bu, 0u,          0x87156CA3u,
        0u,          0xAAF0AA0Au, 0u,          0x3C971982u,
        0u,          0x607256E9u, 0u,          0xF218C661u,
        0u,          0x15F403C8u, 0u,          0xA79A7340u
    };
    static const LONG sub_ret[16] = {
        0x2546, 0x25B1, 0x2627, 0x2691, 0x2706, 0x2771, 0x27E7, 0x2851,
        0x28C6, 0x2931, 0x29A7, 0x2A11, 0x2A86, 0x2AF1, 0x2B67, 0x2BD1
    };
    ULONG32 v = input ^ start_xor[k];
    int r;
    for (r = 0; r < 5; r++) {
        ULONG32 b = (r == (k & 3)) ? (v ^ round_xor[k]) : v;
        v = EmuG10((int)(b & 0x1F), sub_ret[k], b & 0xFF) ^ b;
    }
    return v ^ end_xor[k];
}

/* a transform input buffer: kind 0 = driver image bytes at signed RVA,
 * kind 1 = raw bytes (used for the 4-byte PID token in 0x3828) */
typedef struct _EMU_BUF {
    int          kind;
    LONGLONG     rva;
    ULONG32      abs32; /* low32 of the absolute buffer address (n > 1 ptr xor) */
    const UCHAR* bytes;
    ULONG32      len;
} EMU_BUF;

static ULONG32 EmuDwordMix(const EMU_BUF* b) {
    ULONG32 n = b->len >> 2;
    ULONG32 init, rol_, ror_, ebx, i;
    if (n == 0) return 0;
    init = ((n >> 10) ^ n) & 0xF;
    rol_ = init; ror_ = init; ebx = n;
    for (i = 0; i < n; i++) {
        ULONG32 d = (b->kind == 0) ? EmuImageDword(b->rva + (LONGLONG)i * 4)
                                   : *(const ULONG32*)(b->bytes + i * 4);
        ebx += _rotl(d, (int)rol_);
        ebx += _rotr(d, (int)ror_);
        rol_ = (rol_ + 1 < 0x17) ? rol_ + 1 : 0;
        ror_ = (ror_ + 1 < 0x1D) ? ror_ + 1 : 0;
    }
    if (n > 1) ebx ^= b->abs32;
    return ebx;
}

static ULONG32 EmuVariant(int v, ULONG32 depth, ULONG32 sel, const EMU_BUF* data, LONG callerRetRva) {
    static const ULONG32 seed_const[4] = { 0xA4443C76u, 0xED177432u, 0x35EAABEEu, 0x7EBDE3AAu };
    static const ULONG32 xor_const[4]  = { 0x5CF6D162u, 0x85C4293Eu, 0x9D8784DAu, 0xC70ADC96u };
    static const LONG chain_ret[4]     = { 0x36FF, 0x386D, 0x39DD, 0x3B4D };
    EMU_BUF win;
    LONG winRva = (callerRetRva & ~3L) - 0x100;
    ULONG32 edi = 0, ebx;
    int i;

    win.kind = 0; win.rva = winRva;
    win.abs32 = (ULONG32)(EMU_FAKE_DRIVER_BASE + (ULONG32)winRva);
    win.bytes = NULL; win.len = 0x200;
    edi ^= EmuDwordMix(&win);
    if (data) edi ^= EmuDwordMix(data);

    if (depth) {
        int idx = (int)((edi ^ sel) & 3);
        edi ^= EmuVariant(idx, depth - 1, edi, NULL, chain_ret[v]);
    }

    ebx = EmuMix30F8(seed_const[v], 1) ^ xor_const[v];
    for (i = 0; i < 3; i++)
        ebx ^= EmuP3Gadget((int)(ebx & 0xF), ebx);
    return ebx ^ edi;
}

/* dispatch-level transform: variant[(pid>>2)&3](depth=2, sel=0, data) */
static ULONG32 EmuRunTransform(const EMU_BUF* data) {
    ULONG32 pid = GetCurrentProcessId();
    int v = (int)((pid >> 2) & 3);
    return EmuVariant(v, 2, 0, data, 0x3584);
}

/* exact PidToken16Rounds: 16 bit-network rounds over (pid ^ seed).
 * The seed dword at .data 0x60E8 is 0 in the file and is only ever fed to
 * this token, which the client treats as opaque. */
static ULONG32 EmuPidToken16Rounds(ULONG32 pid) {
    ULONG32 x = pid; /* ^ seed (0) */
    int i;
    for (i = 0; i < 16; i++)
        x = EmuMix30F8(x, 0); /* token rounds run with dl = 0: no gadgets */
    return x;
}

static ULONG64 EmuCurrentPidToken(void) {
    return (ULONG64)EmuPidToken16Rounds(GetCurrentProcessId());
}

static ULONG32 EmuIntegrityTransform(LONGLONG off, ULONG32 len) {
    EMU_BUF data;
    data.kind  = 0;
    data.rva   = off;
    data.abs32 = (ULONG32)(EMU_FAKE_DRIVER_BASE + off);
    data.bytes = NULL;
    data.len   = len;
    return EmuRunTransform(&data);
}

/* expected value for 0x3828: variant over the 4-byte recomputed PID token */
static ULONG32 EmuAuthExpected(void) {
    ULONG32 token = EmuPidToken16Rounds(GetCurrentProcessId());
    EMU_BUF data;
    data.kind  = 1;
    data.rva   = 0;
    data.abs32 = 0; /* unused: n == 1 skips the ptr xor */
    data.bytes = (const UCHAR*)&token;
    data.len   = 4;
    return EmuRunTransform(&data);
}

static void EmuLoadSysBytes(void) {
    WCHAR path[MAX_PATH];
    DWORD len;
    HANDLE hFile = INVALID_HANDLE_VALUE;

    len = GetEnvironmentVariableW(
        L"HOLO_EMU_DRIVER_IMAGE", path, ARRAYSIZE(path));
    if (len && len < ARRAYSIZE(path)) {
        hFile = CreateFileW(path, GENERIC_READ, FILE_SHARE_READ, NULL,
                            OPEN_EXISTING, FILE_ATTRIBUTE_NORMAL, NULL);
    }

    if (hFile == INVALID_HANDLE_VALUE) {
        len = GetModuleFileNameW(g_hModule, path, ARRAYSIZE(path));
    }
    if (hFile == INVALID_HANDLE_VALUE && len && len < ARRAYSIZE(path)) {
        WCHAR* slash = wcsrchr(path, L'\\');
        if (!slash) slash = wcsrchr(path, L'/');
        if (slash) {
            wcscpy_s(slash + 1,
                     (size_t)(path + ARRAYSIZE(path) - (slash + 1)),
                     L"usrdrv017964.sys");
            hFile = CreateFileW(path, GENERIC_READ, FILE_SHARE_READ, NULL, OPEN_EXISTING, FILE_ATTRIBUTE_NORMAL, NULL);
        }
    }
    if (hFile == INVALID_HANDLE_VALUE) {
        len = GetSystemDirectoryW(path, ARRAYSIZE(path));
        if (len && len < ARRAYSIZE(path) - 20) {
            if (path[len - 1] != L'\\') path[len++] = L'\\';
            wcscpy_s(path + len, ARRAYSIZE(path) - len,
                     L"usrdrv017964.sys");
            hFile = CreateFileW(path, GENERIC_READ, FILE_SHARE_READ, NULL,
                                OPEN_EXISTING, FILE_ATTRIBUTE_NORMAL, NULL);
        }
    }
    if (hFile == INVALID_HANDLE_VALUE) {
        LogMessage("[Emu] ERROR: usrdrv017964.sys was not found. Place it "
                   "beside Emulator.dll or set HOLO_EMU_DRIVER_IMAGE.");
        return;
    }
    {
        LARGE_INTEGER sz;
        GetFileSizeEx(hFile, &sz);
        if (sz.QuadPart > 0 && sz.QuadPart < (LONGLONG)(64 * 1024 * 1024)) {
            g_SysBytes = (PUCHAR)HeapAlloc(GetProcessHeap(), 0, (SIZE_T)sz.QuadPart);
            if (g_SysBytes) {
                DWORD rd = 0;
                if (ReadFile(hFile, g_SysBytes, (DWORD)sz.QuadPart, &rd, NULL)) {
                    g_SysBytesSize = rd;
                    /* build RVA -> raw section map for EmuDriverByte */
                    if (rd >= sizeof(IMAGE_DOS_HEADER) && ((PIMAGE_DOS_HEADER)g_SysBytes)->e_magic == IMAGE_DOS_SIGNATURE) {
                        PIMAGE_NT_HEADERS64 nt = (PIMAGE_NT_HEADERS64)(g_SysBytes + ((PIMAGE_DOS_HEADER)g_SysBytes)->e_lfanew);
                        if ((ULONG_PTR)nt - (ULONG_PTR)g_SysBytes + sizeof(IMAGE_NT_HEADERS64) <= rd && nt->Signature == IMAGE_NT_SIGNATURE) {
                            PIMAGE_SECTION_HEADER sec = IMAGE_FIRST_SECTION(nt);
                            int i, n = nt->FileHeader.NumberOfSections;
                            g_SysImageSize = nt->OptionalHeader.SizeOfImage;
                            g_SysHeadersSize = nt->OptionalHeader.SizeOfHeaders;
                            if (n > 32) n = 32;
                            for (i = 0; i < n; i++) {
                                ULONG32 mappedSize = sec[i].Misc.VirtualSize;
                                if (mappedSize < sec[i].SizeOfRawData)
                                    mappedSize = sec[i].SizeOfRawData;
                                g_Sections[i].vaStart  = sec[i].VirtualAddress;
                                g_Sections[i].vaEnd    = sec[i].VirtualAddress + mappedSize;
                                g_Sections[i].rawStart = sec[i].PointerToRawData;
                                g_Sections[i].rawSize  = sec[i].SizeOfRawData;
                            }
                            g_SectionCount = n;
                        }
                    }
                    LogMessage("[Emu] loaded %llu bytes from \"%ls\" for "
                               "0x382C (%d sections, image size 0x%lX)",
                               (unsigned long long)rd, path,
                               g_SectionCount, g_SysImageSize);
                } else {
                    HeapFree(GetProcessHeap(), 0, g_SysBytes);
                    g_SysBytes = NULL;
                }
            }
        }
    }
    CloseHandle(hFile);
}

/* ================= emulation core ================= */

static void EmuResetRecord(void) {
    /* driver: IRP_MJ_CREATE inserts a fresh, mostly-zeroed record */
    g_State.auth_state         = 0;
    g_State.enabled            = 0;
    g_State.active             = 0;
    ZeroMemory(g_State.trusted_pid, sizeof(g_State.trusted_pid));
    ZeroMemory(g_State.parent_pid, sizeof(g_State.parent_pid));
    g_State.svchost_parent_pid = 0;
    ZeroMemory(g_State.telemetry, sizeof(g_State.telemetry));
    /* global_path intentionally survives cleanup/reopen (REfindings 6.D) */
}

static HANDLE EmuOpenDevice(void) {
    EnterCriticalSection(&g_Lock);
    if (g_State.handle_open) {
        /* driver: a second open from the same PID fails (REfindings section 2) */
        LeaveCriticalSection(&g_Lock);
        LogMessage("[Emu] CREATE: second open from same PID rejected");
        SetLastError(ERROR_ACCESS_DENIED);
        return INVALID_HANDLE_VALUE;
    }
    EmuResetRecord();
    g_State.handle_open = TRUE;
    LeaveCriticalSection(&g_Lock);
    LogMessage("[Emu] CREATE: device opened (fake handle, state=0)");
    return EMU_FAKE_HANDLE_VALUE;
}

static void EmuCloseDevice(void) {
    EnterCriticalSection(&g_Lock);
    /* driver: IRP_MJ_CLEANUP removes the caller's record */
    g_State.handle_open = FALSE;
    EmuResetRecord();
    LeaveCriticalSection(&g_Lock);
    LogMessage("[Emu] CLEANUP: record removed");
}

static NTSTATUS EmuWriteOut(PVOID outBuf, ULONG outSize, ULONG need, const void* src, ULONG_PTR* info) {
    if (outSize < need || !outBuf) return STATUS_BUFFER_TOO_SMALL;
    memcpy(outBuf, src, need);
    *info = need;
    return STATUS_SUCCESS;
}

/* Per-IOCTL state gate, REfindings section 3:
 *   state 0: 0x381C, 0x3824, 0x3828 only
 *   state 1: everything except 0x3828
 *   state 2: nothing */
static NTSTATUS EmuCheckState(ULONG code) {
    UINT16 s = g_State.auth_state;
    if (s == 2) return STATUS_ACCESS_DENIED;
    if (s == 0) {
        if (code == IOCTL_GET_VERSION || code == IOCTL_GET_TOKEN_BASE || code == IOCTL_AUTH_RESPONSE)
            return STATUS_SUCCESS;
        return STATUS_ACCESS_DENIED;
    }
    if (code == IOCTL_AUTH_RESPONSE) return STATUS_ACCESS_DENIED;
    return STATUS_SUCCESS;
}

static NTSTATUS EmuDispatch(ULONG code, PVOID inBuf, ULONG inSize, PVOID outBuf, ULONG outSize, ULONG_PTR* info) {
    NTSTATUS st;
    *info = 0;

    EnterCriticalSection(&g_Lock);
    st = EmuCheckState(code);
    if (!NT_SUCCESS(st)) {
        UINT16 curState = g_State.auth_state;
        LeaveCriticalSection(&g_Lock);
        LogMessage("[Emu] IOCTL %-28s REJECTED by state gate (state=%u)", EmuIoctlName(code), curState);
        return st;
    }

    switch (code) {
    case IOCTL_GET_VERSION: {
        ULONG32 v = EMU_PROTOCOL_VERSION;
        st = EmuWriteOut(outBuf, outSize, 4, &v, info);
        break;
    }
    case IOCTL_GET_TOKEN_BASE: {
        struct { ULONG64 token; ULONG64 base; } r;
        r.token = EmuCurrentPidToken();
        r.base  = EMU_FAKE_DRIVER_BASE;
        st = EmuWriteOut(outBuf, outSize, 0x10, &r, info);
        if (NT_SUCCESS(st))
            LogMessage("[Emu]   token=0x%016llX base=0x%016llX", r.token, r.base);
        break;
    }
    case IOCTL_AUTH_RESPONSE: {
        ULONG32 response = 0;
        ULONG32 expected;
        if (inSize < 4 || !inBuf) { st = STATUS_BUFFER_TOO_SMALL; break; }
        response = *(ULONG32*)inBuf;
        /* The driver compares Variant[(pid>>2)&3](depth=2, sel=0, token)
         * against the caller's response (match -> state 1, miss -> state 2).
         * The exact algorithm is now reimplemented, so compute and log the
         * expected value; we still accept unconditionally while the port is
         * being validated against the live client. */
        expected = EmuAuthExpected();
        g_State.auth_state = 1;
        LogMessage("[Emu]   auth response=0x%08lX expected=0x%08lX %s (state 0->1)",
                   response, expected, (response == expected) ? "MATCH" : "MISMATCH");
        st = STATUS_SUCCESS;
        break;
    }
    case IOCTL_REG_PATH: {
        if (inSize < 0x208 || !inBuf) { st = STATUS_BUFFER_TOO_SMALL; break; }
        memcpy(g_State.global_path, inBuf, 0x208);
        g_State.global_path[259] = L'\0';
        g_State.enabled = 1;
        g_State.active  = 1;
        LogMessage("[Emu]   registered path \"%ls\", enabled=1 active=1", g_State.global_path);
        st = STATUS_SUCCESS;
        break;
    }
    case IOCTL_DISABLE_ENF:
        g_State.enabled = 0;
        st = STATUS_SUCCESS;
        break;
    case IOCTL_ENABLE_ENF:
        g_State.enabled = 1;
        st = STATUS_SUCCESS;
        break;
    case IOCTL_SET_TRUSTED5:
        if (inSize < 0x14 || !inBuf) { st = STATUS_BUFFER_TOO_SMALL; break; }
        memcpy(g_State.trusted_pid, inBuf, 0x14);
        LogMessage("[Emu]   trusted pids: %lu %lu %lu %lu %lu",
                   g_State.trusted_pid[0], g_State.trusted_pid[1], g_State.trusted_pid[2],
                   g_State.trusted_pid[3], g_State.trusted_pid[4]);
        st = STATUS_SUCCESS;
        break;
    case IOCTL_SET_PARENTS3:
        if (inSize < 0x0C || !inBuf) { st = STATUS_BUFFER_TOO_SMALL; break; }
        memcpy(g_State.parent_pid, inBuf, 0x0C);
        st = STATUS_SUCCESS;
        break;
    case IOCTL_SET_SVC_PARENT:
        if (inSize < 4 || !inBuf) { st = STATUS_BUFFER_TOO_SMALL; break; }
        g_State.svchost_parent_pid = *(ULONG32*)inBuf;
        st = STATUS_SUCCESS;
        break;
    case IOCTL_GET_TELEMETRY:
        /* consume-and-clear event queue (REfindings section 5). No real
         * ObRegisterCallbacks exist in usermode, so this stays zeroed. */
        st = EmuWriteOut(outBuf, outSize, 0x30, g_State.telemetry, info);
        ZeroMemory(g_State.telemetry, sizeof(g_State.telemetry));
        break;
    case IOCTL_GET_RETADDR: {
        ULONG64 addr = EMU_FAKE_RETURN_ADDR;
        st = EmuWriteOut(outBuf, outSize, 8, &addr, info);
        break;
    }
    case IOCTL_INTEGRITY: {
        LONG   offset;
        ULONG  length;
        ULONG  end;
        ULONG32 result;
        if (inSize < 8 || !inBuf) { st = STATUS_BUFFER_TOO_SMALL; break; }
        /* copy inputs first: the client wrapper aliases in/out buffers */
        offset = *(LONG*)inBuf;
        length = *(ULONG*)((PUCHAR)inBuf + 4);

        /* faithful validator from REfindings 6.C, including the 32-bit wrap */
        end = (ULONG)offset + length;
        if (end > EMU_DRIVER_IMAGE_LIMIT) { st = STATUS_INVALID_PARAMETER; break; }
        if ((ULONG)offset < EMU_DRIVER_OOB_BOUNDARY && end >= EMU_DRIVER_OOB_BOUNDARY) { st = STATUS_INVALID_PARAMETER; break; }

        if (length > EMU_MAX_TRANSFORM_LEN) {
            LogMessage("[Emu]   0x382C length 0x%lX exceeds emulation cap; clamping (deviation)", length);
            length = EMU_MAX_TRANSFORM_LEN;
        }
        result = EmuIntegrityTransform((LONGLONG)offset, length);
        LogMessage("[Emu]   0x382C request offset=0x%08lX (%ld) "
                   "length=0x%lX -> 0x%08lX%s",
                   (ULONG)offset, offset, length, result,
                   (offset < 0) ? " (OOB case)" : "");
        st = EmuWriteOut(outBuf, outSize, 4, &result, info);
        break;
    }
    default:
        st = STATUS_INVALID_DEVICE_REQUEST;
        break;
    }

    LeaveCriticalSection(&g_Lock);

    if (code != IOCTL_GET_TELEMETRY || g_TraceEnabled) {
        LogMessage("[Emu] IOCTL %-28s in=%lu out=%lu -> 0x%08lX "
                   "(info=%llu)",
                   EmuIoctlName(code), inSize, outSize, (ULONG)st,
                   (unsigned long long)*info);
    }
    return st;
}

static DWORD EmuStatusToWin32(NTSTATUS st) {
    switch (st) {
    case STATUS_INVALID_PARAMETER:      return ERROR_INVALID_PARAMETER;
    case STATUS_ACCESS_DENIED:          return ERROR_ACCESS_DENIED;
    case STATUS_BUFFER_TOO_SMALL:       return ERROR_INSUFFICIENT_BUFFER;
    case STATUS_INVALID_DEVICE_REQUEST: return ERROR_INVALID_FUNCTION;
    default:                            return ERROR_GEN_FAILURE;
    }
}

/* ================= service-control fakes =================
 * The launcher installs and starts the "usrdrv017964" kernel service
 * before opening the device. With the driver deliberately absent (service
 * disabled), StartServiceW fails and the game exits silently. These hooks
 * make the SCM view of that one service look present and running, and make
 * a direct NtLoadDriver of the service key "succeed". All other services
 * pass through untouched.
 */

#define EMU_FAKE_SC_HANDLE ((SC_HANDLE)(ULONG_PTR)0x1757CA11)
static BOOL g_SvcRunning = FALSE;

static BOOL EmuSvcNameMatchesW(const WCHAR* s) {
    static const WCHAR needle[] = L"usrdrv017964";
    const SIZE_T nlen = 12;
    SIZE_T i, j, chars;
    if (!s) return FALSE;
    chars = wcslen(s);
    for (i = 0; i + nlen <= chars; i++) {
        for (j = 0; j < nlen; j++) {
            WCHAR c = s[i + j];
            if (c >= L'A' && c <= L'Z') c = (WCHAR)(c + 32);
            if (c != needle[j]) break;
        }
        if (j == nlen) return TRUE;
    }
    return FALSE;
}

static BOOL EmuSvcNameMatchesA(const char* s) {
    static const char needle[] = "usrdrv017964";
    const SIZE_T nlen = 12;
    SIZE_T i, j, chars;
    if (!s) return FALSE;
    chars = strlen(s);
    for (i = 0; i + nlen <= chars; i++) {
        for (j = 0; j < nlen; j++) {
            char c = s[i + j];
            if (c >= 'A' && c <= 'Z') c = (char)(c + 32);
            if (c != needle[j]) break;
        }
        if (j == nlen) return TRUE;
    }
    return FALSE;
}

/* ================= gate-hunting instrumentation =================
 * None of the SCM/device hooks fired in the last test, so the launch gate
 * sits elsewhere. This block (a) fakes the remaining plausible "is the
 * driver loaded" checks (NtOpenFile on the device, symlink object,
 * SystemModuleInformation entry, service-key Start value) and (b) logs
 * the exact call site of any process exit so the failing gate can be
 * identified even if none of the fakes match it.
 */

static void EmuLogExitSite(const char* api, unsigned code, void* retaddr) {
    HMODULE hm = NULL;
    if (retaddr && GetModuleHandleExA(GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS | GET_MODULE_HANDLE_EX_FLAG_UNCHANGED_REFCOUNT,
                                      (LPCSTR)retaddr, &hm) && hm) {
        char modname[MAX_PATH];
        GetModuleFileNameA(hm, modname, MAX_PATH);
        char* base = strrchr(modname, '\\');
        LogMessage("[Emu] %s(code=0x%X) from %s+0x%llX", api, code,
                   base ? base + 1 : modname, (unsigned long long)((ULONG_PTR)retaddr - (ULONG_PTR)hm));
    } else {
        LogMessage("[Emu] %s(code=0x%X) from unbacked address %p", api, code, retaddr);
    }

    /*
     * Record one complete exit stack per process. The immediate caller of
     * RtlExitUserProcess is normally only the Kernel32 ExitProcess wrapper;
     * the earlier logger therefore hid the game/launcher frame that made
     * the decision to exit.
     */
    if (InterlockedCompareExchange(&g_ExitStackLogged, 1, 0) == 0) {
        PVOID frames[16];
        USHORT count = CaptureStackBackTrace(1, 16, frames, NULL);
        USHORT i;
        LogMessage("[Emu] first process-exit stack (%u frames):", count);
        for (i = 0; i < count; i++) {
            HMODULE frameModule = NULL;
            if (frames[i] &&
                GetModuleHandleExA(GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS |
                                   GET_MODULE_HANDLE_EX_FLAG_UNCHANGED_REFCOUNT,
                                   (LPCSTR)frames[i], &frameModule) &&
                frameModule) {
                char modulePath[MAX_PATH];
                char* moduleName;
                GetModuleFileNameA(frameModule, modulePath, MAX_PATH);
                moduleName = strrchr(modulePath, '\\');
                LogMessage("[Emu]   #%u %s+0x%llX", i,
                           moduleName ? moduleName + 1 : modulePath,
                           (unsigned long long)((ULONG_PTR)frames[i] -
                                                (ULONG_PTR)frameModule));
            } else {
                LogMessage("[Emu]   #%u %p (unbacked)", i, frames[i]);
            }
        }
    }
}

static void NTAPI HookedRtlExitUserProcess(NTSTATUS status) {
    EmuLogExitSite("RtlExitUserProcess", (unsigned)status, _ReturnAddress());
    OriginalRtlExitUserProcess(status);
}

static NTSTATUS NTAPI HookedNtOpenFile(PHANDLE FileHandle, ACCESS_MASK DesiredAccess, POBJECT_ATTRIBUTES ObjectAttributes, PIO_STATUS_BLOCK IoStatusBlock, ULONG ShareAccess, ULONG OpenOptions) {
    NTSTATUS st;

                            IoStatusBlock, ShareAccess, OpenOptions);

}

/* --- loaded-driver list: append a fake usrdrv017964 module entry ---
 * SYSTEM_MODULE (x64): Reserved[2](16) Base@16 Size@24 Flags@28 Index@32
 * Unknown@34 LoadCount@36 ModuleNameOffset@38 ImageName[256]@40 = 296 */
#define EMU_SYSMOD_ENTRY_SIZE 296
static ULONG64 g_QsiClassLogged[8];

static void EmuFillSystemModuleEntry(char* entry, ULONG loadIndex) {
    static const char full[] =
        "\\SystemRoot\\System32\\usrdrv017964.sys";
    ULONG imageSize = g_SysImageSize ? g_SysImageSize : 0xF000;
    ZeroMemory(entry, EMU_SYSMOD_ENTRY_SIZE);
    *(ULONG64*)(entry + 16) = EMU_FAKE_DRIVER_BASE;
    *(ULONG*)(entry + 24)   = imageSize;
    *(USHORT*)(entry + 32)  = (USHORT)loadIndex;
    *(USHORT*)(entry + 36)  = 1;
    *(USHORT*)(entry + 38)  =
        (USHORT)(sizeof("\\SystemRoot\\System32\\") - 1);
    memcpy(entry + 40, full, sizeof(full));
}

static NTSTATUS NTAPI HookedNtQuerySystemInformation(ULONG SystemInformationClass, PVOID SystemInformation, ULONG SystemInformationLength, PULONG ReturnLength) {
    void* caller = _ReturnAddress();
    NTSTATUS st = OriginalNtQuerySystemInformation(SystemInformationClass, SystemInformation, SystemInformationLength, ReturnLength);

    if (SystemInformationClass == 0x0B) { /* SystemModuleInformation */
        ULONG returned = ReturnLength ? *ReturnLength : 0;
        if (g_TraceEnabled) {
            LogMessage("[Trace] modules NtQuerySystemInformation(0x0B, "
                       "buffer=%lu) -> 0x%08lX return=%lu",
                       SystemInformationLength, (ULONG)st, returned);
            EmuLogAddress("module-list probe caller:", caller);
        }
        if (NT_SUCCESS(st) && SystemInformation) {
            ULONG count = *(ULONG*)SystemInformation;
            ULONG need  = 8 + (count + 1) * EMU_SYSMOD_ENTRY_SIZE;
            if (need <= SystemInformationLength) {
                char* entry = (char*)SystemInformation + 8 + (SIZE_T)count * EMU_SYSMOD_ENTRY_SIZE;
                ULONG imageSize = g_SysImageSize ? g_SysImageSize : 0xF000;
                EmuFillSystemModuleEntry(entry, count);
                *(ULONG*)SystemInformation = count + 1;
                if (ReturnLength) *ReturnLength = need;
                LogMessage("[Emu] SystemModuleInformation: appended fake "
                           "usrdrv017964 entry (%lu modules, base=%p, "
                           "size=0x%lX)",
                           count + 1, (void*)EMU_FAKE_DRIVER_BASE, imageSize);
                return STATUS_SUCCESS;
            }
            if (ReturnLength) *ReturnLength = need;
            LogMessage("[Emu] SystemModuleInformation buffer too small for fake entry (%lu < %lu); asking caller to grow", SystemInformationLength, need);
            return STATUS_INFO_LENGTH_MISMATCH;
        }
        if (st == STATUS_INFO_LENGTH_MISMATCH && ReturnLength) {
            if (*ReturnLength)
                *ReturnLength += EMU_SYSMOD_ENTRY_SIZE;
            else
                *ReturnLength = 8 + EMU_SYSMOD_ENTRY_SIZE;
            LogMessage("[Emu] SystemModuleInformation real list needs %lu; padded requirement for fake entry", *ReturnLength);
            return st;
        }

        /*
         * Wine versions differ in their implementation of class 0x0B.
         * When the host cannot provide a kernel-module list at all, return
         * a minimal valid list containing the emulated driver.
         */
        {
            ULONG need = 8 + EMU_SYSMOD_ENTRY_SIZE;
            if (ReturnLength) *ReturnLength = need;
            if (!SystemInformation || SystemInformationLength < need)
                return STATUS_INFO_LENGTH_MISMATCH;
            ZeroMemory(SystemInformation, need);
            *(ULONG*)SystemInformation = 1;
            EmuFillSystemModuleEntry((char*)SystemInformation + 8, 0);
            LogMessage("[Emu] SystemModuleInformation host fallback: "
                       "returned fake-only module list (host status=0x%08lX)",
                       (ULONG)st);
            return STATUS_SUCCESS;
        }
    }

    /* log each other info class once, for visibility */
    if (g_TraceEnabled && SystemInformationClass < 512) {
        ULONG64* word = &g_QsiClassLogged[SystemInformationClass >> 6];
        ULONG64 bit = 1ULL << (SystemInformationClass & 63);
        if (!(*word & bit)) {
            *word |= bit;
            LogMessage("[Emu] NtQuerySystemInformation class 0x%lX (first use)", SystemInformationClass);
        }
    }
    return st;
}

/* --- service registry key: complete fake for clean Windows/Wine prefixes ---
 *
 * Win32's registry layer expects an actual kernel handle and may inspect it
 * before issuing NtQueryValueKey. If the real service key is absent, open a
 * harmless HKLM\Software carrier and associate that handle with our virtual
 * service data. This works on Windows and Wine without creating any key.
 */
#define EMU_MAX_TRACKED_KEYS 16
static HANDLE g_UsrdrvKeys[EMU_MAX_TRACKED_KEYS];

static void EmuTrackKey(HANDLE handle) {
    int i;
    EnterCriticalSection(&g_Lock);
    for (i = 0; i < EMU_MAX_TRACKED_KEYS; i++) {
        if (!g_UsrdrvKeys[i]) {
            g_UsrdrvKeys[i] = handle;
            break;
        }
    }
    LeaveCriticalSection(&g_Lock);
}

static BOOL EmuIsTrackedKey(HANDLE handle) {
    int i;
    BOOL found = FALSE;
    EnterCriticalSection(&g_Lock);
    for (i = 0; i < EMU_MAX_TRACKED_KEYS; i++) {
        if (g_UsrdrvKeys[i] == handle) {
            found = TRUE;
            break;
        }
    }
    LeaveCriticalSection(&g_Lock);
    return found;
}

static void EmuUntrackKey(HANDLE handle) {
    int i;
    EnterCriticalSection(&g_Lock);
    for (i = 0; i < EMU_MAX_TRACKED_KEYS; i++) {
        if (g_UsrdrvKeys[i] == handle)
            g_UsrdrvKeys[i] = NULL;
    }
    LeaveCriticalSection(&g_Lock);
}

static void EmuCopyUnicodeString(PUNICODE_STRING source,
                                 WCHAR* destination,
                                 SIZE_T destinationChars) {
    SIZE_T chars = 0;
    if (!destination || !destinationChars) return;
    if (source && source->Buffer) {
        chars = source->Length / sizeof(WCHAR);
        if (chars >= destinationChars) chars = destinationChars - 1;
        memcpy(destination, source->Buffer, chars * sizeof(WCHAR));
    }
    destination[chars] = L'\0';
}

static BOOL EmuIsUsrdrvKeyAttributes(POBJECT_ATTRIBUTES attributes) {
    if (!attributes) return FALSE;
    return attributes->ObjectName &&
           attributes->ObjectName->Buffer &&
           EmuWideContainsCI(
               attributes->ObjectName->Buffer,
               attributes->ObjectName->Length / sizeof(WCHAR),
               L"usrdrv017964");
}

static NTSTATUS EmuOpenRegistryCarrier(PHANDLE keyHandle) {
    static WCHAR carrierPath[] = L"\\Registry\\Machine\\Software";
    UNICODE_STRING name;
    OBJECT_ATTRIBUTES attributes;
    name.Buffer = carrierPath;
    name.Length = (USHORT)(sizeof(carrierPath) - sizeof(WCHAR));
    name.MaximumLength = sizeof(carrierPath);
    ZeroMemory(&attributes, sizeof(attributes));
    attributes.Length = sizeof(attributes);
    attributes.ObjectName = &name;
    attributes.Attributes = 0x40; /* OBJ_CASE_INSENSITIVE */
    return OriginalNtOpenKey(keyHandle, KEY_READ, &attributes);
}

static NTSTATUS NTAPI HookedNtOpenKey(
    PHANDLE KeyHandle, ACCESS_MASK DesiredAccess,
    POBJECT_ATTRIBUTES ObjectAttributes) {
    if (EmuIsUsrdrvKeyAttributes(ObjectAttributes)) {
        WCHAR name[512];
        NTSTATUS st;
        BOOL carrier = g_ForceVirtualService;
        if (carrier) {
            st = EmuOpenRegistryCarrier(KeyHandle);
        } else {
            st = OriginalNtOpenKey(
                KeyHandle, DesiredAccess, ObjectAttributes);
            if (!NT_SUCCESS(st)) {
                st = EmuOpenRegistryCarrier(KeyHandle);
                carrier = TRUE;
            }
        }
        if (!NT_SUCCESS(st)) return st;
        EmuCopyUnicodeString(ObjectAttributes->ObjectName, name,
                             ARRAYSIZE(name));
        EmuTrackKey(*KeyHandle);
        LogMessage("[Emu] NtOpenKey(\"%ls\") -> emulated service key%s",
                   name, carrier ? " (carrier handle)" : "");
        return STATUS_SUCCESS;
    }
    return OriginalNtOpenKey(KeyHandle, DesiredAccess, ObjectAttributes);
}

    ULONG DataLength;
    ULONG NameLength;

} EMU_KVFI;

    ULONG NameLength;

    LARGE_INTEGER LastWriteTime;

    ULONG ClassLength;

typedef struct _EMU_REG_VALUE {
    const WCHAR* name;
    ULONG type;
    const BYTE* data;
    ULONG dataLength;
} EMU_REG_VALUE;

static const ULONG g_RegStart = SERVICE_DEMAND_START;
static const ULONG g_RegType = SERVICE_KERNEL_DRIVER;
static const ULONG g_RegErrorControl = SERVICE_ERROR_NORMAL;
static const WCHAR g_RegImagePath[] =
    L"\\??\\C:\\Windows\\System32\\usrdrv017964.sys";
static const WCHAR g_RegDisplayName[] = L"usrdrv017964";

static BOOL EmuRegistryValueAt(ULONG index, EMU_REG_VALUE* value) {
    static const WCHAR startName[] = L"Start";
    static const WCHAR typeName[] = L"Type";
    static const WCHAR errorName[] = L"ErrorControl";
    static const WCHAR imageName[] = L"ImagePath";
    static const WCHAR displayName[] = L"DisplayName";
    if (!value) return FALSE;
    switch (index) {
    case 0:
        value->name = startName;
        value->type = REG_DWORD;
        value->data = (const BYTE*)&g_RegStart;
        value->dataLength = sizeof(g_RegStart);
        return TRUE;
    case 1:
        value->name = typeName;
        value->type = REG_DWORD;
        value->data = (const BYTE*)&g_RegType;
        value->dataLength = sizeof(g_RegType);
        return TRUE;
    case 2:
        value->name = errorName;
        value->type = REG_DWORD;
        value->data = (const BYTE*)&g_RegErrorControl;
        value->dataLength = sizeof(g_RegErrorControl);
        return TRUE;
    case 3:
        value->name = imageName;
        value->type = REG_EXPAND_SZ;
        value->data = (const BYTE*)g_RegImagePath;
        value->dataLength = sizeof(g_RegImagePath);
        return TRUE;
    case 4:
        value->name = displayName;
        value->type = REG_SZ;
        value->data = (const BYTE*)g_RegDisplayName;
        value->dataLength = sizeof(g_RegDisplayName);
        return TRUE;
    default:
        return FALSE;
    }
}

static BOOL EmuRegistryValueByName(
    PUNICODE_STRING valueName, EMU_REG_VALUE* value) {
    WCHAR name[64];
    ULONG i;
    EmuCopyUnicodeString(valueName, name, ARRAYSIZE(name));
    for (i = 0; EmuRegistryValueAt(i, value); i++) {
        if (_wcsicmp(name, value->name) == 0) return TRUE;
    }
    return FALSE;
}

static NTSTATUS EmuFillRegistryValueInformation(
    const EMU_REG_VALUE* value, ULONG infoClass, PVOID information,
    ULONG length, PULONG resultLength) {
    ULONG nameBytes = (ULONG)(wcslen(value->name) * sizeof(WCHAR));
    ULONG required;
    if (infoClass == 0) { /* KeyValueBasicInformation */
        EMU_KVBI* out;
        required = FIELD_OFFSET(EMU_KVBI, Name) + nameBytes;
        if (resultLength) *resultLength = required;
        if (!information || length < required) return STATUS_BUFFER_TOO_SMALL;
        out = (EMU_KVBI*)information;
        ZeroMemory(out, required);
        out->Type = value->type;
        out->NameLength = nameBytes;
        memcpy(out->Name, value->name, nameBytes);
        return STATUS_SUCCESS;
    }
    if (infoClass == 1 || infoClass == 3) {
        EMU_KVFI* out;
        ULONG alignment = infoClass == 3 ? 8 : 4;
        ULONG dataOffset =
            (FIELD_OFFSET(EMU_KVFI, Name) + nameBytes + alignment - 1) &
            ~(alignment - 1);
        required = dataOffset + value->dataLength;
        if (resultLength) *resultLength = required;
        if (!information || length < required) return STATUS_BUFFER_TOO_SMALL;
        out = (EMU_KVFI*)information;
        ZeroMemory(out, required);
        out->Type = value->type;
        out->DataOffset = dataOffset;
        out->DataLength = value->dataLength;
        out->NameLength = nameBytes;
        memcpy(out->Name, value->name, nameBytes);
        memcpy((BYTE*)out + dataOffset, value->data, value->dataLength);
        return STATUS_SUCCESS;
    }
    if (infoClass == 2 || infoClass == 4) {
        EMU_KVPI* out;
        required = FIELD_OFFSET(EMU_KVPI, Data) + value->dataLength;
        if (resultLength) *resultLength = required;
        if (!information || length < required) return STATUS_BUFFER_TOO_SMALL;
        out = (EMU_KVPI*)information;
        ZeroMemory(out, required);
        out->Type = value->type;
        out->DataLength = value->dataLength;
        memcpy(out->Data, value->data, value->dataLength);
        return STATUS_SUCCESS;
    }
    if (resultLength) *resultLength = 0;
    return STATUS_INVALID_PARAMETER;
}

static NTSTATUS NTAPI HookedNtQueryValueKey(
    HANDLE KeyHandle, PUNICODE_STRING ValueName,
    ULONG KeyValueInformationClass, PVOID KeyValueInformation,
    ULONG Length, PULONG ResultLength) {
    EMU_REG_VALUE value;
    NTSTATUS st;
    if (!EmuIsTrackedKey(KeyHandle))
        return OriginalNtQueryValueKey(
            KeyHandle, ValueName, KeyValueInformationClass,
            KeyValueInformation, Length, ResultLength);
    if (!EmuRegistryValueByName(ValueName, &value)) {
        if (ResultLength) *ResultLength = 0;
        return STATUS_OBJECT_NAME_NOT_FOUND;
    }
    st = EmuFillRegistryValueInformation(
        &value, KeyValueInformationClass, KeyValueInformation,
        Length, ResultLength);
    if (g_TraceEnabled)
        LogMessage("[Trace] registry query \"%ls\" class=%lu -> 0x%08lX",
                   value.name, KeyValueInformationClass, (ULONG)st);
    return st;
}

static NTSTATUS NTAPI HookedNtQueryKey(
    HANDLE KeyHandle, ULONG KeyInformationClass, PVOID KeyInformation,
    ULONG Length, PULONG ResultLength) {
    static const WCHAR leaf[] = L"usrdrv017964";
    static const WCHAR full[] =
        L"\\REGISTRY\\MACHINE\\SYSTEM\\CurrentControlSet\\Services\\"
        L"usrdrv017964";
    ULONG nameBytes;
    ULONG required;
    if (!EmuIsTrackedKey(KeyHandle))
        return OriginalNtQueryKey(
            KeyHandle, KeyInformationClass, KeyInformation,
            Length, ResultLength);
    if (KeyInformationClass == 0) { /* KeyBasicInformation */
        EMU_KBI* out;
        nameBytes = sizeof(leaf) - sizeof(WCHAR);
        required = FIELD_OFFSET(EMU_KBI, Name) + nameBytes;
        if (ResultLength) *ResultLength = required;
        if (!KeyInformation || Length < required)
            return STATUS_BUFFER_TOO_SMALL;
        out = (EMU_KBI*)KeyInformation;
        ZeroMemory(out, required);
        out->NameLength = nameBytes;
        memcpy(out->Name, leaf, nameBytes);
        return STATUS_SUCCESS;
    }
    if (KeyInformationClass == 2) { /* KeyFullInformation */
        EMU_KFI* out;
        required = FIELD_OFFSET(EMU_KFI, Class);
        if (ResultLength) *ResultLength = required;
        if (!KeyInformation || Length < required)
            return STATUS_BUFFER_TOO_SMALL;
        out = (EMU_KFI*)KeyInformation;
        ZeroMemory(out, required);
        out->Values = 5;
        out->MaxValueNameLen = sizeof(L"ErrorControl") - sizeof(WCHAR);
        out->MaxValueDataLen = sizeof(g_RegImagePath);
        return STATUS_SUCCESS;
    }
    if (KeyInformationClass == 3) { /* KeyNameInformation */
        EMU_KNI* out;
        nameBytes = sizeof(full) - sizeof(WCHAR);
        required = FIELD_OFFSET(EMU_KNI, Name) + nameBytes;
        if (ResultLength) *ResultLength = required;
        if (!KeyInformation || Length < required)
            return STATUS_BUFFER_TOO_SMALL;
        out = (EMU_KNI*)KeyInformation;
        ZeroMemory(out, required);
        out->NameLength = nameBytes;
        memcpy(out->Name, full, nameBytes);
        return STATUS_SUCCESS;
    }
    if (ResultLength) *ResultLength = 0;
    return STATUS_INVALID_PARAMETER;
}

static NTSTATUS NTAPI HookedNtEnumerateValueKey(
    HANDLE KeyHandle, ULONG Index, ULONG KeyValueInformationClass,
    PVOID KeyValueInformation, ULONG Length, PULONG ResultLength) {
    EMU_REG_VALUE value;
    if (!EmuIsTrackedKey(KeyHandle))
        return OriginalNtEnumerateValueKey(
            KeyHandle, Index, KeyValueInformationClass,

        &value, KeyValueInformationClass, KeyValueInformation,
        Length, ResultLength);
}

/* --- symlink-object existence check --- */
static NTSTATUS NTAPI HookedNtOpenSymbolicLinkObject(PHANDLE LinkHandle, ACCESS_MASK DesiredAccess, POBJECT_ATTRIBUTES ObjectAttributes) {
    if (ObjectAttributes && ObjectAttributes->ObjectName &&
        EmuNameMatchesBuf(ObjectAttributes->ObjectName->Buffer, ObjectAttributes->ObjectName->Length / sizeof(WCHAR))) {
        LogMessage("[Emu] NtOpenSymbolicLinkObject(\"%ls\") -> fake handle", ObjectAttributes->ObjectName->Buffer);
        *LinkHandle = EMU_FAKE_SYMLINK_HANDLE;
        return STATUS_SUCCESS;
    }
    return OriginalNtOpenSymbolicLinkObject(LinkHandle, DesiredAccess, ObjectAttributes);
}

static NTSTATUS NTAPI HookedNtQuerySymbolicLinkObject(HANDLE LinkHandle, PUNICODE_STRING LinkTarget, PULONG ReturnedLength) {
    if (LinkHandle == EMU_FAKE_SYMLINK_HANDLE) {
        static const WCHAR target[] = L"\\Device\\Htsysm6321";
        ULONG bytes = (ULONG)(sizeof(target) - sizeof(WCHAR));
        if (!LinkTarget || LinkTarget->MaximumLength < bytes + sizeof(WCHAR)) {
            if (ReturnedLength) *ReturnedLength = bytes;
            return STATUS_BUFFER_TOO_SMALL;
        }
        memcpy(LinkTarget->Buffer, target, bytes + sizeof(WCHAR));
        LinkTarget->Length = (USHORT)bytes;
        if (ReturnedLength) *ReturnedLength = bytes;
        LogMessage("[Emu] NtQuerySymbolicLinkObject(fake) -> \"%ls\"", target);
        return STATUS_SUCCESS;
    }
    return OriginalNtQuerySymbolicLinkObject(LinkHandle, LinkTarget, ReturnedLength);
}

/* ================= hollowing-chain injection =================
 * The launcher hollows several generations of hololive-Dreams.exe
 * (parent -> suspended child -> remap -> ResumeThread, repeatedly).
 * ResumeThread is the exact moment the next generation's image is final
 * while its main thread is still suspended: the perfect, safe moment to
 * load this DLL into that child. Each injected generation installs the
 * same hook, so the whole chain is covered automatically.
 */

static DWORD g_InjectedPids[32];
static int   g_InjectedPidCount = 0;

static BOOL EmuAlreadyInjected(DWORD pid) {
    int i; BOOL found = FALSE;
    EnterCriticalSection(&g_Lock);
    for (i = 0; i < g_InjectedPidCount; i++) if (g_InjectedPids[i] == pid) { found = TRUE; break; }
    LeaveCriticalSection(&g_Lock);
    return found;
}

static void EmuRememberInjected(DWORD pid) {
    EnterCriticalSection(&g_Lock);
    if (g_InjectedPidCount < 32) g_InjectedPids[g_InjectedPidCount++] = pid;
    LeaveCriticalSection(&g_Lock);
}

static BOOL EmuIsGameImage(DWORD pid) {
    WCHAR path[MAX_PATH];
    DWORD sz = MAX_PATH;
    HANDLE h = OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, FALSE, pid);
    const WCHAR* base;
    BOOL ok;
    if (!h) return FALSE;
    ok = QueryFullProcessImageNameW(h, 0, path, &sz);
    CloseHandle(h);
    if (!ok) return FALSE;
    base = wcsrchr(path, L'\\');
    base = base ? base + 1 : path;
    return _wcsicmp(base, L"hololive-Dreams.exe") == 0;
}

static BOOL EmuIsDirectChild(DWORD pid) {
    PROCESSENTRY32W pe;
    HANDLE snapshot;
    BOOL isDirectChild = FALSE;

    pe.dwSize = sizeof(pe);
    snapshot = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0);
    if (snapshot == INVALID_HANDLE_VALUE) return FALSE;

    if (Process32FirstW(snapshot, &pe)) {
        do {
            if (pe.th32ProcessID == pid) {
                isDirectChild =
                    (pe.th32ParentProcessID == GetCurrentProcessId());
                break;
            }
        } while (Process32NextW(snapshot, &pe));
    }

    CloseHandle(snapshot);
    return isDirectChild;
}

static BOOL EmuContainsGameExe(const WCHAR* text) {
    static const WCHAR needle[] = L"hololive-Dreams.exe";
    SIZE_T needleChars = ARRAYSIZE(needle) - 1;

    if (!text) return FALSE;
    while (*text) {
        if (_wcsnicmp(text, needle, needleChars) == 0) return TRUE;
        text++;
    }
    return FALSE;
}

static BOOL EmuUnicodeContainsGameExe(const UNICODE_STRING* text) {
    static const WCHAR needle[] = L"hololive-Dreams.exe";
    USHORT textChars;
    USHORT needleChars = (USHORT)(ARRAYSIZE(needle) - 1);
    USHORT i;

    if (!text || !text->Buffer) return FALSE;
    textChars = text->Length / sizeof(WCHAR);
    if (textChars < needleChars) return FALSE;
    for (i = 0; i + needleChars <= textChars; i++) {
        if (_wcsnicmp(text->Buffer + i, needle, needleChars) == 0)
            return TRUE;
    }
    return FALSE;
}

static ULONG_PTR EmuFindRemoteModuleBase(
    DWORD pid, const char* moduleName) {
    MODULEENTRY32 entry;
    HANDLE snapshot;
    ULONG_PTR base = 0;
    entry.dwSize = sizeof(entry);
    snapshot = CreateToolhelp32Snapshot(
        TH32CS_SNAPMODULE | TH32CS_SNAPMODULE32, pid);
    if (snapshot == INVALID_HANDLE_VALUE) return 0;
    if (Module32First(snapshot, &entry)) {
        do {
            if (_stricmp(entry.szModule, moduleName) == 0) {
                base = (ULONG_PTR)entry.modBaseAddr;
                break;
            }
        } while (Module32Next(snapshot, &entry));
    }
    CloseHandle(snapshot);
    return base;
}

static LPTHREAD_START_ROUTINE EmuRemoteLoadLibraryAddress(DWORD pid) {
    HMODULE localKernel32 = GetModuleHandleA("kernel32.dll");
    HMODULE localProcedureModule = NULL;
    FARPROC localLoadLibrary =
        localKernel32 ? GetProcAddress(localKernel32, "LoadLibraryA") : NULL;
    ULONG_PTR remoteProcedureModule;
    char modulePath[MAX_PATH];
    const char* moduleName;
    if (!localKernel32 || !localLoadLibrary) return NULL;
    if (!GetModuleHandleExA(
            GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS |
                GET_MODULE_HANDLE_EX_FLAG_UNCHANGED_REFCOUNT,
            (LPCSTR)localLoadLibrary, &localProcedureModule) ||
        !GetModuleFileNameA(
            localProcedureModule, modulePath, ARRAYSIZE(modulePath))) {
        localProcedureModule = localKernel32;
        strcpy_s(modulePath, ARRAYSIZE(modulePath), "kernel32.dll");
    }
    moduleName = strrchr(modulePath, '\\');
    if (!moduleName) moduleName = strrchr(modulePath, '/');
    moduleName = moduleName ? moduleName + 1 : modulePath;
    remoteProcedureModule =
        EmuFindRemoteModuleBase(pid, moduleName);
    if (!remoteProcedureModule) {
        if (g_TraceEnabled)
            LogMessage("[Trace] remote %s not enumerable in PID %lu; "
                       "using shared LoadLibraryA address",
                       moduleName, pid);
        return (LPTHREAD_START_ROUTINE)localLoadLibrary;
    }
    return (LPTHREAD_START_ROUTINE)(
        remoteProcedureModule +
        ((ULONG_PTR)localLoadLibrary -
         (ULONG_PTR)localProcedureModule));
}

static void EmuInjectIntoProcess(DWORD pid) {
    char dllPath[MAX_PATH];
    SIZE_T pathSize;
    HANDLE hProcess, hThread;
    LPVOID remote;
    LPTHREAD_START_ROUTINE remoteLoadLibrary;

    GetModuleFileNameA(g_hModule, dllPath, MAX_PATH);
    pathSize = strlen(dllPath) + 1;

    hProcess = OpenProcess(PROCESS_CREATE_THREAD | PROCESS_VM_OPERATION | PROCESS_VM_WRITE | PROCESS_QUERY_INFORMATION, FALSE, pid);
    if (!hProcess) {
        LogMessage("[Emu]   inject into PID %lu: OpenProcess failed (%lu)", pid, GetLastError());
        return;
    }
    remote = VirtualAllocEx(hProcess, NULL, pathSize, MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);
    if (remote) {
        remoteLoadLibrary = EmuRemoteLoadLibraryAddress(pid);
        if (!remoteLoadLibrary ||
            !WriteProcessMemory(
                hProcess, remote, dllPath, pathSize, NULL)) {
            LogMessage("[Emu]   inject into PID %lu: failed to prepare "
                       "remote LoadLibrary (%lu)", pid, GetLastError());
            VirtualFreeEx(hProcess, remote, 0, MEM_RELEASE);
            CloseHandle(hProcess);
            return;
        }
        hThread = CreateRemoteThread(
            hProcess, NULL, 0, remoteLoadLibrary, remote, 0, NULL);
        if (hThread) {
            /* child main thread is still suspended; LoadLibrary is safe */
            DWORD wait = WaitForSingleObject(hThread, 5000);
            CloseHandle(hThread);
            if (wait == WAIT_OBJECT_0)
                LogMessage("[Emu]   injected into PID %lu", pid);
            else
                LogMessage("[Emu]   inject into PID %lu: LoadLibrary "
                           "thread timed out", pid);
        } else {
            LogMessage("[Emu]   inject into PID %lu: CreateRemoteThread failed (%lu)", pid, GetLastError());
        }
        VirtualFreeEx(hProcess, remote, 0, MEM_RELEASE);
    }
    CloseHandle(hProcess);
}

static BOOL WINAPI HookedCreateProcessW(
    LPCWSTR lpApplicationName,
    LPWSTR lpCommandLine,
    LPSECURITY_ATTRIBUTES lpProcessAttributes,
    LPSECURITY_ATTRIBUTES lpThreadAttributes,
    BOOL bInheritHandles,
    DWORD dwCreationFlags,
    LPVOID lpEnvironment,
    LPCWSTR lpCurrentDirectory,
    LPSTARTUPINFOW lpStartupInfo,
    LPPROCESS_INFORMATION lpProcessInformation)
{
    BOOL isGameChild =
        EmuContainsGameExe(lpApplicationName) ||
        EmuContainsGameExe(lpCommandLine);
    BOOL callerRequestedSuspended =
        (dwCreationFlags & CREATE_SUSPENDED) != 0;
    DWORD effectiveFlags = dwCreationFlags;
    BOOL ok;

    /*
     * Hold a normally-running game child at its initial entry point. A
     * caller-managed suspended child is left alone because the parent may
     * still intend to replace its image before NtResumeThread.
     */
    if (isGameChild && !callerRequestedSuspended) {
        effectiveFlags |= CREATE_SUSPENDED;
        LogMessage("[Emu] CreateProcessW: temporarily suspending game child "
                   "for pre-entry injection");
    }

    ok = OriginalCreateProcessW(
        lpApplicationName,
        lpCommandLine,
        lpProcessAttributes,
        lpThreadAttributes,
        bInheritHandles,
        effectiveFlags,
        lpEnvironment,
        lpCurrentDirectory,
        lpStartupInfo,
        lpProcessInformation);

    if (ok && isGameChild && !callerRequestedSuspended &&
        lpProcessInformation && lpProcessInformation->hThread) {
        DWORD childPid = lpProcessInformation->dwProcessId;
        LogMessage("[Emu] CreateProcessW: game child PID %lu created "
                   "suspended; injecting before entry", childPid);
        EmuRememberInjected(childPid);
        EmuInjectIntoProcess(childPid);
        if (ResumeThread(lpProcessInformation->hThread) == (DWORD)-1) {
            LogMessage("[Emu] CreateProcessW: failed to release game child "
                       "PID %lu (%lu)", childPid, GetLastError());
        } else {
            LogMessage("[Emu] CreateProcessW: game child PID %lu released",
                       childPid);
        }
    }

    return ok;
}

static NTSTATUS NTAPI HookedNtCreateUserProcess(
    PHANDLE ProcessHandle,
    PHANDLE ThreadHandle,
    ACCESS_MASK ProcessDesiredAccess,
    ACCESS_MASK ThreadDesiredAccess,
    POBJECT_ATTRIBUTES ProcessObjectAttributes,
    POBJECT_ATTRIBUTES ThreadObjectAttributes,
    ULONG ProcessFlags,
    ULONG ThreadFlags,
    PRTL_USER_PROCESS_PARAMETERS ProcessParameters,
    PVOID CreateInfo,
    PVOID AttributeList)
{
    BOOL isGameChild = ProcessParameters &&
        (EmuUnicodeContainsGameExe(&ProcessParameters->ImagePathName) ||
         EmuUnicodeContainsGameExe(&ProcessParameters->CommandLine));
    BOOL callerRequestedSuspended = (ThreadFlags & 1) != 0;
    ULONG effectiveThreadFlags = ThreadFlags;
    NTSTATUS status;

    if (isGameChild && !callerRequestedSuspended) {
        effectiveThreadFlags |= 1; /* THREAD_CREATE_FLAGS_CREATE_SUSPENDED */
        LogMessage("[Emu] NtCreateUserProcess: temporarily suspending game "
                   "child for pre-entry injection");
    }

    status = OriginalNtCreateUserProcess(
        ProcessHandle,
        ThreadHandle,
        ProcessDesiredAccess,
        ThreadDesiredAccess,
        ProcessObjectAttributes,
        ThreadObjectAttributes,
        ProcessFlags,
        effectiveThreadFlags,
        ProcessParameters,
        CreateInfo,
        AttributeList);

    if (NT_SUCCESS(status) && isGameChild && !callerRequestedSuspended &&
        ProcessHandle && *ProcessHandle && ThreadHandle && *ThreadHandle) {
        DWORD childPid = GetProcessId(*ProcessHandle);
        LogMessage("[Emu] NtCreateUserProcess: game child PID %lu created "
                   "suspended; injecting before entry", childPid);
        EmuRememberInjected(childPid);
        EmuInjectIntoProcess(childPid);
        if (ResumeThread(*ThreadHandle) == (DWORD)-1) {
            LogMessage("[Emu] NtCreateUserProcess: failed to release game "
                       "child PID %lu (%lu)", childPid, GetLastError());
        } else {
            LogMessage("[Emu] NtCreateUserProcess: game child PID %lu "
                       "released", childPid);
        }
    }

    return status;
}

static NTSTATUS NTAPI HookedNtResumeThread(HANDLE ThreadHandle, PULONG SuspendCount) {
    DWORD pid = ThreadHandle ? GetProcessIdOfThread(ThreadHandle) : 0;
    if (pid && pid != GetCurrentProcessId() && !EmuAlreadyInjected(pid)) {
        BOOL gameImage = EmuIsGameImage(pid);
        BOOL directChild = gameImage ? FALSE : EmuIsDirectChild(pid);
        if (gameImage || directChild) {
            if (!gameImage) {
                LogMessage("[Emu] NtResumeThread: PID %lu image name is not "
                           "ready; accepting direct-child fallback", pid);
            }
            LogMessage("[Emu] NtResumeThread: game child PID %lu resuming; injecting before release", pid);
            EmuRememberInjected(pid);
            EmuInjectIntoProcess(pid);
        } else {
            LogMessage("[Emu] NtResumeThread: cross-process PID %lu was not "
                       "recognized as a game/direct child", pid);
        }
    }
    return OriginalNtResumeThread(ThreadHandle, SuspendCount);
}

static void EmuInstallHook(void* target, void* detour, void** original, const char* name) {
    MH_STATUS status;
    if (!target) {
        LogMessage("[Emu] hook target %s not found", name);
        return;
    }
    status = MH_CreateHook(target, detour, original);
    if (status != MH_OK) {
        LogMessage("[Emu] MH_CreateHook failed for %s: %s (%d)",
                   name, MH_StatusToString(status), (int)status);
    }
}

    (void)lpReserved;
    if (ul_reason_for_call == DLL_PROCESS_ATTACH) {
        HMODULE hKernelBase, hNtdll, hAdvapi32;

        g_hModule = hModule;
        EmuInitializeConfiguration();
        DisableThreadLibraryCalls(hModule);
        AddVectoredExceptionHandler(1, EmuCrashObserver);
        InitializeCriticalSection(&g_Lock);
        ZeroMemory(&g_State, sizeof(g_State));
        /* Every injected generation must observe the emulated driver as
         * already loaded, even if that process never called StartService. */

            LogMessage("[Emu] MH_Initialize failed");

}
```

```c
#include <stdio.h>
#include <tlhelp32.h>

typedef LONG(NTAPI *pNtCreateThreadEx)(
    OUT PHANDLE hThread,
    IN ACCESS_MASK DesiredAccess,
    IN LPVOID ObjectAttributes,
    IN HANDLE ProcessHandle,
    IN LPTHREAD_START_ROUTINE lpStartAddress,
    IN LPVOID lpParameter,
    IN BOOL CreateSuspended,
    IN ULONG StackZeroBits,
    IN ULONG SizeOfStackCommit,
    IN ULONG SizeOfStackReserve,
    OUT LPVOID lpBytesBuffer

/*
 * ThreadSuspendCount (information class 35) is available on the Windows
 * versions supported by the game. Query it dynamically so the external
 * loader can distinguish a child that is still suspended for process
 * hollowing from a child that has already been released and is safe to
 * inject.
 */
typedef LONG(NTAPI *pNtQueryInformationThread)(
    HANDLE ThreadHandle,
    ULONG ThreadInformationClass,
    PVOID ThreadInformation,
    ULONG ThreadInformationLength,
    PULONG ReturnLength

BOOL EnableDebugPrivilege() {
    HANDLE hToken;
    TOKEN_PRIVILEGES tkp;
    if (!OpenProcessToken(GetCurrentProcess(), TOKEN_ADJUST_PRIVILEGES | TOKEN_QUERY, &hToken)) return FALSE;
    LookupPrivilegeValueA(NULL, SE_DEBUG_NAME, &tkp.Privileges[0].Luid);
    tkp.PrivilegeCount = 1;
    tkp.Privileges[0].Attributes = SE_PRIVILEGE_ENABLED;
    AdjustTokenPrivileges(hToken, FALSE, &tkp, sizeof(tkp), NULL, NULL);
    CloseHandle(hToken);
    return TRUE;
}

static BOOL IsProcessSuspended(DWORD pid, BOOL* stateKnown) {
    pNtQueryInformationThread NtQueryInformationThread;
    THREADENTRY32 te32;
    HANDLE hSnap;
    BOOL sawQuery = FALSE;
    BOOL suspended = FALSE;

    *stateKnown = FALSE;
    NtQueryInformationThread = (pNtQueryInformationThread)GetProcAddress(
        GetModuleHandleA("ntdll.dll"), "NtQueryInformationThread");
    if (!NtQueryInformationThread) return FALSE;

    te32.dwSize = sizeof(te32);
    hSnap = CreateToolhelp32Snapshot(TH32CS_SNAPTHREAD, 0);
    if (hSnap == INVALID_HANDLE_VALUE) return FALSE;

    if (Thread32First(hSnap, &te32)) {
        do {
            HANDLE hThread;
            ULONG suspendCount = 0;
            LONG status;

            if (te32.th32OwnerProcessID != pid) continue;
            hThread = OpenThread(THREAD_QUERY_LIMITED_INFORMATION, FALSE,
                                 te32.th32ThreadID);
            if (!hThread) continue;

            status = NtQueryInformationThread(
                hThread,
                35, /* ThreadSuspendCount */
                &suspendCount,
                sizeof(suspendCount),
                NULL);
            CloseHandle(hThread);

            if (status >= 0) {
                sawQuery = TRUE;
                if (suspendCount != 0) {
                    suspended = TRUE;
                    break;
                }
            }
        } while (Thread32Next(hSnap, &te32));
    }

    CloseHandle(hSnap);
    *stateKnown = sawQuery;
    return suspended;
}

#define EMU_READY_COOKIE 0x484F4C4F454D5531ULL

static ULONG_PTR FindRemoteModuleBase(
    DWORD pid, const char* moduleName) {
    MODULEENTRY32 me;
    HANDLE snapshot;
    ULONG_PTR moduleBase = 0;

    me.dwSize = sizeof(me);
    snapshot = CreateToolhelp32Snapshot(
        TH32CS_SNAPMODULE | TH32CS_SNAPMODULE32, pid);
    if (snapshot == INVALID_HANDLE_VALUE) return FALSE;

    if (Module32First(snapshot, &me)) {
        do {
            if (_stricmp(me.szModule, moduleName) == 0) {
                moduleBase = (ULONG_PTR)me.modBaseAddr;
                break;
            }
        } while (Module32Next(snapshot, &me));
    }

    CloseHandle(snapshot);
    return moduleBase;
}

static ULONG_PTR FindEmulatorBase(DWORD pid) {
    return FindRemoteModuleBase(pid, "Emulator.dll");
}

static BOOL IsEmulatorReady(
    DWORD pid,
    ULONG_PTR remoteModuleBase,
    const char* dllPath)
{
    static SIZE_T cookieRva = 0;
    static BOOL cookieRvaResolved = FALSE;
    HANDLE hProcess;
    ULONGLONG remoteCookie = 0;
    SIZE_T bytesRead = 0;

    if (!remoteModuleBase) return FALSE;

    if (!cookieRvaResolved) {
        HMODULE localImage = LoadLibraryExA(
            dllPath, NULL, DONT_RESOLVE_DLL_REFERENCES);
        if (localImage) {
            const void* localCookie = GetProcAddress(
                localImage, "g_EmulatorReadyCookie");
            if (localCookie) {
                cookieRva =
                    (SIZE_T)((ULONG_PTR)localCookie -
                             (ULONG_PTR)localImage);
            }
            FreeLibrary(localImage);
        }
        cookieRvaResolved = TRUE;
    }

    if (!cookieRva) return FALSE;
    hProcess = OpenProcess(
        PROCESS_QUERY_LIMITED_INFORMATION | PROCESS_VM_READ, FALSE, pid);
    if (!hProcess) return FALSE;
    if (!ReadProcessMemory(
            hProcess,
            (LPCVOID)(remoteModuleBase + cookieRva),
            &remoteCookie,
            sizeof(remoteCookie),
            &bytesRead)) {
        CloseHandle(hProcess);
        return FALSE;
    }
    CloseHandle(hProcess);
    return bytesRead == sizeof(remoteCookie) &&
           remoteCookie == EMU_READY_COOKIE;
}

BOOL InjectDLL(DWORD pid, const char* dllPath) {
    SIZE_T pathSize;
    SIZE_T written = 0;
    LPVOID pRemoteDllPath;
    HMODULE hKernel32;
    HMODULE hLoadLibraryModule = NULL;
    LPTHREAD_START_ROUTINE pLoadLibrary;
    ULONG_PTR remoteLoadLibraryModule;
    FARPROC localLoadLibrary;
    char loadLibraryModulePath[MAX_PATH];
    const char* loadLibraryModuleName;
    HMODULE hNtdll;
    pNtCreateThreadEx NtCreateThreadEx;
    HANDLE hProcess;

    EnableDebugPrivilege();

    hProcess = OpenProcess(
        PROCESS_CREATE_THREAD | PROCESS_QUERY_INFORMATION |
        PROCESS_VM_OPERATION | PROCESS_VM_WRITE | PROCESS_VM_READ,
        FALSE, pid);
    if (!hProcess) {
        printf("[-] OpenProcess failed: %d\n", GetLastError());
        return FALSE;
    }

    pathSize = strlen(dllPath) + 1;
    pRemoteDllPath = VirtualAllocEx(
        hProcess, NULL, pathSize, MEM_COMMIT | MEM_RESERVE, PAGE_READWRITE);
    if (!pRemoteDllPath ||
        !WriteProcessMemory(hProcess, pRemoteDllPath, dllPath, pathSize,
                            &written) ||
        written != pathSize) {
        printf("[-] Failed to prepare remote DLL path: %d\n", GetLastError());
        if (pRemoteDllPath)
            VirtualFreeEx(hProcess, pRemoteDllPath, 0, MEM_RELEASE);
        CloseHandle(hProcess);
        return FALSE;
    }

    hKernel32 = GetModuleHandleA("kernel32.dll");
    localLoadLibrary = hKernel32
        ? GetProcAddress(hKernel32, "LoadLibraryA")
        : NULL;
    if (!localLoadLibrary) {
        printf("[-] LoadLibraryA is unavailable in this runtime.\n");
        VirtualFreeEx(hProcess, pRemoteDllPath, 0, MEM_RELEASE);
        CloseHandle(hProcess);
        return FALSE;
    }
    if (!GetModuleHandleExA(
            GET_MODULE_HANDLE_EX_FLAG_FROM_ADDRESS |
                GET_MODULE_HANDLE_EX_FLAG_UNCHANGED_REFCOUNT,
            (LPCSTR)localLoadLibrary, &hLoadLibraryModule) ||
        !GetModuleFileNameA(
            hLoadLibraryModule, loadLibraryModulePath,
            ARRAYSIZE(loadLibraryModulePath))) {
        hLoadLibraryModule = hKernel32;
        strcpy_s(loadLibraryModulePath,
                 ARRAYSIZE(loadLibraryModulePath), "kernel32.dll");
    }
    loadLibraryModuleName = strrchr(loadLibraryModulePath, '\\');
    if (!loadLibraryModuleName)
        loadLibraryModuleName = strrchr(loadLibraryModulePath, '/');
    loadLibraryModuleName = loadLibraryModuleName
        ? loadLibraryModuleName + 1
        : loadLibraryModulePath;
    remoteLoadLibraryModule =
        FindRemoteModuleBase(pid, loadLibraryModuleName);
    if (remoteLoadLibraryModule) {
        pLoadLibrary = (LPTHREAD_START_ROUTINE)(
            remoteLoadLibraryModule +
            ((ULONG_PTR)localLoadLibrary -
             (ULONG_PTR)hLoadLibraryModule));
    } else {
        /*
         * Suspended Windows/Wine children do not always expose their module
         * list yet. Both runtimes normally share the system-DLL mapping, so
         * retain the proven address as a compatibility fallback.
         */
        pLoadLibrary = (LPTHREAD_START_ROUTINE)localLoadLibrary;
        printf("[*] Remote %s is not enumerable yet; using the shared "
               "LoadLibraryA address.\n", loadLibraryModuleName);
    }

    // Load ntdll to get NtCreateThreadEx
    hNtdll = GetModuleHandleA("ntdll.dll");
    NtCreateThreadEx = (pNtCreateThreadEx)GetProcAddress(
        hNtdll, "NtCreateThreadEx");

    if (NtCreateThreadEx) {
        HANDLE hThread = NULL;
        DWORD waitResult;
        DWORD loadResult = 0;
        // Stealthy thread creation
        LONG status = NtCreateThreadEx(
            &hThread, THREAD_ALL_ACCESS, NULL, hProcess, pLoadLibrary,
            pRemoteDllPath, FALSE, 0, 0, 0, NULL);
        if (hThread) {
            waitResult = WaitForSingleObject(hThread, 5000);
            if (waitResult == WAIT_OBJECT_0)
                GetExitCodeThread(hThread, &loadResult);
            CloseHandle(hThread);
            if (waitResult == WAIT_OBJECT_0 && loadResult != 0) {
                VirtualFreeEx(hProcess, pRemoteDllPath, 0, MEM_RELEASE);
                CloseHandle(hProcess);
                printf("[+] Injection successful (NtCreateThreadEx, "
                       "LoadLibrary=0x%08lX)!\n", loadResult);
                return TRUE;
            }
            if (waitResult == WAIT_TIMEOUT) {
                printf("[-] NtCreateThreadEx LoadLibrary timed out.\n");
                CloseHandle(hProcess);
                return FALSE;
            }
            printf("[-] NtCreateThreadEx ran, but LoadLibrary returned "
                   "NULL.\n");
        } else {
            printf("[-] NtCreateThreadEx failed: Status 0x%X\n", status);
        }
    }

    // Fallback to standard CreateRemoteThread if NtCreateThreadEx fails
    printf("[*] Falling back to CreateRemoteThread...\n");
    HANDLE hThread = CreateRemoteThread(
        hProcess, NULL, 0, pLoadLibrary, pRemoteDllPath, 0, NULL);
    if (hThread) {
        DWORD waitResult = WaitForSingleObject(hThread, 5000);
        DWORD loadResult = 0;
        if (waitResult == WAIT_OBJECT_0)
            GetExitCodeThread(hThread, &loadResult);
        CloseHandle(hThread);
        if (waitResult == WAIT_OBJECT_0 && loadResult != 0) {
            VirtualFreeEx(hProcess, pRemoteDllPath, 0, MEM_RELEASE);
            CloseHandle(hProcess);
            printf("[+] Injection successful (CreateRemoteThread, "
                   "LoadLibrary=0x%08lX)!\n", loadResult);
            return TRUE;
        }
        if (waitResult == WAIT_TIMEOUT) {
            printf("[-] CreateRemoteThread LoadLibrary timed out.\n");
            CloseHandle(hProcess);
            return FALSE;
        }
        printf("[-] CreateRemoteThread ran, but LoadLibrary returned NULL.\n");
    }

    printf("[-] CreateRemoteThread failed: %d\n", GetLastError());
    VirtualFreeEx(hProcess, pRemoteDllPath, 0, MEM_RELEASE);
    CloseHandle(hProcess);
    return FALSE;
}

/*
 * Injection timing matters with this game:
 *  - The process Steam starts (parented by steam.exe/steamwebhelper) self-
 *    unpacks in place; it is safe to inject right away.
 *  - The sidecar then hollows several GENERATIONS of hololive-Dreams.exe
 *    (suspended child -> remap -> ResumeThread, recursively). Injecting
 *    during the hollowing window corrupts the unpack, so children are
 *    primarily covered by Emulator.dll's own NtResumeThread hook, which
 *    injects each child at the exact moment its parent releases it.
 *  - This loader only fast-injects root processes. Game-parented children
 *    get a slow fallback injection (>= 3 s old) in case the resume-chain
 *    misses one (e.g. a child created already-running).
 */
typedef struct _CANDIDATE {
    DWORD     pid;
    DWORD     parentPid;
    unsigned  generation;
    ULONGLONG firstSeen;
    ULONGLONG lastAttempt;
    BOOL      injected;
    BOOL      waitReported;
} CANDIDATE;

#define MAX_CANDIDATES 32
#define CHILD_MIN_AGE_MS   3000
#define SUSPENDED_CHILD_GRACE_MS 50
#define RETRY_INTERVAL_MS  2000

int main(int argc, char** argv) {
    char targetExe[MAX_PATH] = "hololive-Dreams.exe";
    char configuredDllPath[MAX_PATH];
    char absoluteDllPath[MAX_PATH];
    DWORD length;
    HMODULE ntdll = GetModuleHandleA("ntdll.dll");
    FARPROC wineVersion = ntdll
        ? GetProcAddress(ntdll, "wine_get_version")
        : NULL;

    length = GetEnvironmentVariableA(
        "HOLO_EMU_TARGET", targetExe, ARRAYSIZE(targetExe));
    if (length >= ARRAYSIZE(targetExe))
        strcpy_s(targetExe, ARRAYSIZE(targetExe),
                 "hololive-Dreams.exe");

    length = GetEnvironmentVariableA(
        "HOLO_EMU_DLL", configuredDllPath,
        ARRAYSIZE(configuredDllPath));
    if (length && length < ARRAYSIZE(configuredDllPath)) {
        if (!GetFullPathNameA(
                configuredDllPath, ARRAYSIZE(absoluteDllPath),
                absoluteDllPath, NULL)) {
            printf("[-] Could not resolve HOLO_EMU_DLL=\"%s\".\n",
                   configuredDllPath);
            return 1;
        }
    } else {
        char* slash;
        length = GetModuleFileNameA(
            NULL, absoluteDllPath, ARRAYSIZE(absoluteDllPath));
        if (!length || length >= ARRAYSIZE(absoluteDllPath)) {
            printf("[-] Could not determine loader.exe's directory.\n");
            return 1;
        }
        slash = strrchr(absoluteDllPath, '\\');
        if (!slash) slash = strrchr(absoluteDllPath, '/');
        if (!slash) {
            printf("[-] loader.exe has no resolvable parent directory.\n");
            return 1;
        }
        strcpy_s(slash + 1,
                 ARRAYSIZE(absoluteDllPath) -
                     (SIZE_T)(slash + 1 - absoluteDllPath),
                 "Emulator.dll");
    }

    if (GetFileAttributesA(absoluteDllPath) == INVALID_FILE_ATTRIBUTES) {
        printf("[-] Emulator.dll was not found at %s\n",
               absoluteDllPath);
        return 1;
    }

    if (argc > 1 &&
        (_stricmp(argv[1], "--check") == 0 ||
         _stricmp(argv[1], "-c") == 0)) {
        printf("[+] Configuration check passed.\n");
        printf("[+] Runtime: %s\n",
               wineVersion ? "Wine/Proton" : "Windows");
        printf("[+] Target: %s\n", targetExe);
        printf("[+] Emulator: %s\n", absoluteDllPath);
        return 0;
    }

    printf("[*] Auto-Hunter active. Continuously hunting for %s...\n", targetExe);
    printf("[*] Runtime: %s\n",
           wineVersion ? "Wine/Proton" : "Windows");
    printf("[*] Emulator: %s\n", absoluteDllPath);
    printf("[*] (Press Ctrl+C to stop)\n\n");

    CANDIDATE cands[MAX_CANDIDATES] = {0};
    int candCount = 0;

    while (1) {
        PROCESSENTRY32 pe32;
        pe32.dwSize = sizeof(PROCESSENTRY32);
        HANDLE hSnap = CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0);
        if (hSnap == INVALID_HANDLE_VALUE) { Sleep(50); continue; }

        ULONGLONG now = GetTickCount64();
        BOOL seen[MAX_CANDIDATES] = {0};

        if (Process32First(hSnap, &pe32)) {
            do {
                if (_stricmp(pe32.szExeFile, targetExe) != 0) continue;

                /* find or register candidate */
                int idx = -1;
                for (int i = 0; i < candCount; i++) {
                    if (cands[i].pid == pe32.th32ProcessID) { idx = i; break; }
                }
                if (idx < 0 && candCount < MAX_CANDIDATES) {
                    unsigned generation = 0;
                    for (int i = 0; i < candCount; i++) {
                        if (cands[i].pid == pe32.th32ParentProcessID) {
                            generation = cands[i].generation + 1;
                            break;
                        }
                    }
                    idx = candCount++;
                    cands[idx].pid         = pe32.th32ProcessID;
                    cands[idx].parentPid   = pe32.th32ParentProcessID;
                    cands[idx].generation  = generation;
                    cands[idx].firstSeen   = now;
                    cands[idx].lastAttempt = 0;
                    cands[idx].injected    = FALSE;
                    cands[idx].waitReported = FALSE;
                    printf("[+] Found %s! PID: %d (parent PID: %d, "
                           "generation: %u)\n", targetExe,
                           pe32.th32ProcessID, pe32.th32ParentProcessID,
                           generation);
                }
                if (idx < 0 || cands[idx].injected) continue;
                seen[idx] = TRUE;

                /* is this process parented by another hololive-Dreams.exe? */
                BOOL parentIsGame = FALSE;
                for (int i = 0; i < candCount; i++) {
                    if (cands[i].pid == cands[idx].parentPid) { parentIsGame = TRUE; break; }
                }

                if (parentIsGame && cands[idx].generation < 2) {
                    /*
                     * A suspended child may still be in the middle of being
                     * hollowed, so never inject into it from this watcher.
                     * Once its threads are no longer suspended, its runtime
                     * image is committed and immediate injection is safe.
                     *
                     * This also covers children created already-running:
                     * there is no NtResumeThread call for Emulator.dll to
                     * intercept, and the old fixed three-second delay let the
                     * missing-driver gate kill them before fallback injection.
                     */
                    ULONGLONG age = now - cands[idx].firstSeen;
                    BOOL stateKnown = FALSE;
                    BOOL suspended = IsProcessSuspended(cands[idx].pid,
                                                        &stateKnown);
                    if (stateKnown && suspended &&
                        age < SUSPENDED_CHILD_GRACE_MS) {
                        if (!cands[idx].waitReported) {
                            printf("[*] PID %d is suspended; allowing up to "
                                   "%d ms for hollowing before pre-release "
                                   "injection.\n", cands[idx].pid,
                                   SUSPENDED_CHILD_GRACE_MS);
                            cands[idx].waitReported = TRUE;
                        }
                        continue;
                    }
                    if (stateKnown && suspended) {
                        printf("[*] PID %d remained suspended past the "
                               "hollowing grace period; injecting before "
                               "release.\n", cands[idx].pid);
                    }
                    if (!stateKnown && age < CHILD_MIN_AGE_MS) continue;

                    if (stateKnown && age < CHILD_MIN_AGE_MS) {
                        printf("[*] PID %d is already running; bypassing the "
                               "slow child fallback.\n", cands[idx].pid);
                    }
                } else if (parentIsGame) {
                    /*
                     * The recovered final-stage launcher creates generation
                     * two without CREATE_SUSPENDED and reaches its driver
                     * gate in under one polling interval. Inject immediately;
                     * waiting on the transient startup suspend count loses
                     * that race.
                     */
                    printf("[*] PID %d is final-stage generation %u; "
                           "injecting immediately.\n",
                           cands[idx].pid, cands[idx].generation);
                }

                if (now - cands[idx].lastAttempt < RETRY_INTERVAL_MS) continue;
                cands[idx].lastAttempt = now;

                {
                    ULONG_PTR emulatorBase =
                        FindEmulatorBase(cands[idx].pid);
                    if (emulatorBase &&
                        IsEmulatorReady(
                            cands[idx].pid,
                            emulatorBase,
                            absoluteDllPath)) {
                        printf("[+] Emulator.dll is initialized in PID %d "
                               "(ready cookie verified).\n\n",
                               cands[idx].pid);
                        cands[idx].injected = TRUE;
                        continue;
                    }
                    if (emulatorBase) {
                        printf("[*] Emulator.dll is visible but not initialized "
                               "in PID %d; synchronizing through LoadLibrary.\n",
                               cands[idx].pid);
                    }
                }

                printf("[*] Injecting %s into PID %d...\n", absoluteDllPath, cands[idx].pid);
                if (InjectDLL(cands[idx].pid, absoluteDllPath)) {
                    printf("[+] Injection successful!\n\n");
                    cands[idx].injected = TRUE;
                } else {
                    printf("[-] Injection failed (will retry).\n\n");
                }
            } while (Process32Next(hSnap, &pe32));
        }
        CloseHandle(hSnap);

        /* prune dead PIDs so the table can be reused across launches */
        for (int i = 0; i < candCount; i++) {
            if (cands[i].injected || seen[i]) {
                HANDLE h = OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, FALSE, cands[i].pid);
                if (!h) {
                    cands[i] = cands[candCount - 1];
                    candCount--;
                    i--;
                } else {
                    CloseHandle(h);
                }
            }
        }

        Sleep(1);
    }

    return 0;
}
```

```c
    printf("pid=%lu\n", GetCurrentProcessId());

    if (GetEnvironmentVariableA(
            "HOLO_EMU_DLL", dllPath, ARRAYSIZE(dllPath)) >=
        ARRAYSIZE(dllPath))
        strcpy_s(dllPath, ARRAYSIZE(dllPath), "Emulator.dll");
    dll = LoadLibraryA(dllPath);
    CHECK(dll != NULL, "LoadLibraryA(emulator)");
    if (!dll) return 1;
    {
        volatile uint64_t* readyCookie =
            (volatile uint64_t*)GetProcAddress(
                dll, "g_EmulatorReadyCookie");
        CHECK(readyCookie != NULL && *readyCookie == EMU_READY_COOKIE,
              "Emulator.dll readiness cookie is published");
    }

    /* ---- disk/device/service/registry visibility ---- */
    {
        WCHAR target[64];
        DWORD chars = QueryDosDeviceW(L"Htsysm6321", target,
                                      ARRAYSIZE(target));
        CHECK(chars != 0 && _wcsicmp(target, L"\\Device\\Htsysm6321") == 0,
              "QueryDosDeviceW sees the emulated device link");
    }
    {
        WCHAR driverPath[MAX_PATH];
        DWORD driverChars = GetEnvironmentVariableW(
            L"HOLO_EMU_DRIVER_IMAGE", driverPath, ARRAYSIZE(driverPath));
        if (!driverChars || driverChars >= ARRAYSIZE(driverPath)) {
            WCHAR* slash;
            driverChars = GetModuleFileNameW(
                dll, driverPath, ARRAYSIZE(driverPath));
            slash = driverChars ? wcsrchr(driverPath, L'\\') : NULL;
            if (!slash && driverChars)
                slash = wcsrchr(driverPath, L'/');
            if (slash)
                wcscpy_s(
                    slash + 1,
                    ARRAYSIZE(driverPath) -
                        (SIZE_T)(slash + 1 - driverPath),
                    L"usrdrv017964.sys");
        }
        CHECK(driverChars &&
              GetFileAttributesW(driverPath) != INVALID_FILE_ATTRIBUTES,
              "portable driver-image metadata probe succeeds");
    }
    {
        HKEY key = NULL;
        DWORD start = 0, type = 0, bytes = sizeof(start);
        LONG opened = RegOpenKeyExW(
            HKEY_LOCAL_MACHINE,
            L"SYSTEM\\CurrentControlSet\\Services\\usrdrv017964",
            0, KEY_QUERY_VALUE, &key);
        LONG queried = opened == ERROR_SUCCESS
            ? RegQueryValueExW(key, L"Start", NULL, &type,
                               (LPBYTE)&start, &bytes)
            : opened;
        CHECK(queried == ERROR_SUCCESS && type == REG_DWORD &&
              start == SERVICE_DEMAND_START,
              "registry service key is emulated as demand-start");
        if (opened == ERROR_SUCCESS) {
            WCHAR imagePath[260];
            DWORD imageBytes = sizeof(imagePath);
            DWORD valueCount = 0;
            LONG imageResult = RegQueryValueExW(
                key, L"ImagePath", NULL, &type,
                (LPBYTE)imagePath, &imageBytes);
            CHECK(imageResult == ERROR_SUCCESS &&
                  (type == REG_SZ || type == REG_EXPAND_SZ) &&
                  wcsstr(imagePath, L"usrdrv017964.sys") != NULL,
                  "registry ImagePath is available without a real key");
            while (valueCount < 16) {
                WCHAR valueName[64];
                DWORD valueChars = ARRAYSIZE(valueName);
                LONG enumResult = RegEnumValueW(
                    key, valueCount, valueName, &valueChars,
                    NULL, NULL, NULL, NULL);
                if (enumResult == ERROR_NO_MORE_ITEMS) break;
                if (enumResult != ERROR_SUCCESS) {
                    valueCount = 0;
                    break;
                }
                valueCount++;
            }
            CHECK(valueCount == 5,
                  "registry value enumeration exposes the complete service");
        }
        if (key) RegCloseKey(key);
    }
    {
        SC_HANDLE manager = OpenSCManagerW(
            NULL, NULL, SC_MANAGER_CONNECT);
        SC_HANDLE service = manager
            ? OpenServiceW(manager, L"usrdrv017964",
                           SERVICE_QUERY_STATUS | SERVICE_QUERY_CONFIG)
            : NULL;
        SERVICE_STATUS_PROCESS status;
        DWORD needed = 0;
        ZeroMemory(&status, sizeof(status));
        BOOL statusOk = service && QueryServiceStatusEx(
            service, SC_STATUS_PROCESS_INFO, (LPBYTE)&status,
            sizeof(status), &needed);
        CHECK(statusOk && status.dwServiceType == SERVICE_KERNEL_DRIVER &&
              status.dwCurrentState == SERVICE_RUNNING,
              "SCM status reports the emulated driver running");
        if (service) {
            DWORD configBytes = 0;
            LPQUERY_SERVICE_CONFIGW config;
            QueryServiceConfigW(service, NULL, 0, &configBytes);
            config = (LPQUERY_SERVICE_CONFIGW)HeapAlloc(
                GetProcessHeap(), HEAP_ZERO_MEMORY, configBytes);
            CHECK(config && QueryServiceConfigW(
                      service, config, configBytes, &configBytes) &&
                  config->dwServiceType == SERVICE_KERNEL_DRIVER &&
                  config->dwStartType == SERVICE_DEMAND_START,
                  "SCM configuration describes the emulated driver");
            if (config) HeapFree(GetProcessHeap(), 0, config);
            CloseServiceHandle(service);
        }
        if (manager) CloseServiceHandle(manager);
    }
    {
        pNtQuerySystemInformation querySystemInformation =
            (pNtQuerySystemInformation)GetProcAddress(
                GetModuleHandleA("ntdll.dll"),
                "NtQuerySystemInformation");
        ULONG bytes = 1024 * 1024;
        BYTE* modules = (BYTE*)HeapAlloc(
            GetProcessHeap(), HEAP_ZERO_MEMORY, bytes);
        NTSTATUS status = querySystemInformation
            ? querySystemInformation(0x0B, modules, bytes, &bytes)
            : (NTSTATUS)0xC0000002L;
        BOOL found = FALSE;
        if (status >= 0 && modules) {
            ULONG i, count = *(ULONG*)modules;
            for (i = 0; i < count; i++) {
                BYTE* entry = modules + 8 +
                              (SIZE_T)i * TEST_SYSMOD_ENTRY_SIZE;
                const char* path = (const char*)entry + 40;
                if (strstr(path, "usrdrv017964.sys")) {
                    found = *(ULONG*)(entry + 24) == 0xF000;
                    break;
                }
            }
        }
        CHECK(found, "loaded-module view contains the full-size fake driver");
        if (modules) HeapFree(GetProcessHeap(), 0, modules);
    }

    /*
     * Exercise the race-free child propagation path. The marker in this
     * otherwise ordinary command line makes the emulator treat it as a game
     * child: CreateProcessW must hold it, inject Emulator.dll, and release it.
     */
    {
        STARTUPINFOW si;
        PROCESS_INFORMATION pi;
        WCHAR selfPath[MAX_PATH];
        WCHAR cmd[MAX_PATH + 64];
        DWORD childExit = STILL_ACTIVE;
        BOOL created;

        GetModuleFileNameW(NULL, selfPath, ARRAYSIZE(selfPath));
        swprintf_s(
            cmd, ARRAYSIZE(cmd),
            L"\"%ls\" --child-check hololive-Dreams.exe", selfPath);
        ZeroMemory(&si, sizeof(si));
        ZeroMemory(&pi, sizeof(pi));
        si.cb = sizeof(si);
        created = CreateProcessW(
            selfPath,
            cmd,
            NULL,
            NULL,
            FALSE,
            CREATE_NO_WINDOW,
            NULL,
            NULL,
            &si,
            &pi);
        CHECK(created, "CreateProcessW pre-entry propagation smoke test");
        if (created) {
            WaitForSingleObject(pi.hProcess, 10000);
            GetExitCodeProcess(pi.hProcess, &childExit);
            CHECK(childExit == 0,
                  "pre-entry child verifies Emulator.dll readiness");
            CloseHandle(pi.hThread);
            CloseHandle(pi.hProcess);
        }
    }

    /* ---- open ---- */
    h = OpenDevice();
    CHECK(h != INVALID_HANDLE_VALUE, "CreateFileW(\\\\.\\Htsysm6321) succeeds without driver");
    if (h == INVALID_HANDLE_VALUE) return 1;

    /* ---- state 0: version allowed ---- */
    {
        ULONG32 ver = 0;
        CHECK(Ioctl(h, IOCTL_GET_VERSION, NULL, 0, &ver, 4, &ret) && ret == 4 && ver == 0x44C,
              "0x381C GET_VERSION returns 0x44C pre-auth");
    }

    /* ---- state 0: register-path must be rejected ---- */
    {
        WCHAR path[260];
        memset(path, 0, sizeof(path));
        CHECK(!Ioctl(h, IOCTL_REG_PATH, path, 0x208, NULL, 0, &ret),
              "0x3800 REGISTER_PATH rejected before auth (state 0)");
    }

    /* ---- state 0: token + base ---- */
    {
        struct { uint64_t token; uint64_t base; } tb;
        memset(&tb, 0, sizeof(tb));
        CHECK(Ioctl(h, IOCTL_GET_TOKEN_BASE, NULL, 0, &tb, 0x10, &ret) && ret == 0x10,
              "0x3824 GET_TOKEN_BASE succeeds pre-auth");
        printf("       token=0x%016llX base=0x%016llX\n",
               (unsigned long long)tb.token, (unsigned long long)tb.base);
        CHECK(tb.base != 0, "0x3824 base is nonzero");
    }

    /* ---- auth ---- */
    {
        ULONG32 response = 0xDEADBEEF; /* emulator accepts any response, logs it */
        CHECK(Ioctl(h, IOCTL_AUTH_RESPONSE, &response, 4, NULL, 0, &ret),
              "0x3828 AUTH_RESPONSE accepted (state 0->1)");
    }

    /* ---- state 1: register path ---- */
    {
        WCHAR path[260];
        memset(path, 0, sizeof(path));
        wcscpy_s(path, 260, L"C:\\Windows\\System32");
        CHECK(Ioctl(h, IOCTL_REG_PATH, path, 0x208, NULL, 0, &ret),
              "0x3800 REGISTER_PATH succeeds post-auth");
    }

    /* ---- state 1: auth must now be rejected ---- */
    {
        ULONG32 response = 0;
        CHECK(!Ioctl(h, IOCTL_AUTH_RESPONSE, &response, 4, NULL, 0, &ret),
              "0x3828 rejected in state 1");
    }

    /* ---- PID configuration IOCTLs ---- */
    {
        ULONG32 five[5] = { 4, 8, 15, 16, 23 };
        ULONG32 three[3] = { 42, 42, 42 };
        ULONG32 svc = 108;
        CHECK(Ioctl(h, IOCTL_SET_TRUSTED5, five, 0x14, NULL, 0, &ret),  "0x380C SET_TRUSTED_PIDS");
        CHECK(Ioctl(h, IOCTL_SET_PARENTS3, three, 0x0C, NULL, 0, &ret), "0x3810 SET_PARENT_PIDS");
        CHECK(Ioctl(h, IOCTL_SET_SVC_PARENT, &svc, 4, NULL, 0, &ret),   "0x3814 SET_SVCHOST_PARENT");
        CHECK(Ioctl(h, IOCTL_DISABLE_ENF, NULL, 0, NULL, 0, &ret),      "0x3804 DISABLE_ENFORCEMENT");
        CHECK(Ioctl(h, IOCTL_ENABLE_ENF, NULL, 0, NULL, 0, &ret),       "0x3808 ENABLE_ENFORCEMENT");
    }

    /* ---- telemetry ---- */
    {
        ULONG32 telem[12];
        memset(telem, 0xAA, sizeof(telem));
        CHECK(Ioctl(h, IOCTL_GET_TELEMETRY, NULL, 0, telem, 0x30, &ret) && ret == 0x30,
              "0x3818 GET_TELEMETRY returns 0x30 bytes");
        {
            int i, allzero = 1;
            for (i = 0; i < 12; i++) if (telem[i]) allzero = 0;
            CHECK(allzero, "0x3818 telemetry is zeroed (no usermode callbacks)");
        }
    }

    /* ---- return address leak ---- */
    {
        uint64_t addr = 0;
        CHECK(Ioctl(h, IOCTL_GET_RETADDR, NULL, 0, &addr, 8, &ret) && ret == 8 && addr != 0,
              "0x3820 GET_RETURN_ADDRESS returns nonzero kernel-looking address");
        printf("       addr=0x%016llX\n", (unsigned long long)addr);
    }

    /* ---- integrity transform: normal range ---- */
    {
        struct { LONG offset; ULONG length; } req;
        ULONG32 result = 0;
        req.offset = 0x100; req.length = 0x40;
        CHECK(Ioctl(h, IOCTL_INTEGRITY, &req, 8, &result, 4, &ret) && ret == 4,
              "0x382C INTEGRITY normal range");
        printf("       transform(0x100,0x40)=0x%08lX\n", result);
    }

    /* ---- integrity transform: documented OOB case (offset=-4, length=4) ---- */
    {
        struct { LONG offset; ULONG length; } req;
        ULONG32 result = 0;
        req.offset = -4; req.length = 4; /* end wraps to 0 -> passes both checks */
        CHECK(Ioctl(h, IOCTL_INTEGRITY, &req, 8, &result, 4, &ret) && ret == 4,
              "0x382C INTEGRITY negative-offset OOB case emulated safely");
        printf("       transform(-4,4)=0x%08lX\n", result);
    }

    /* ---- integrity transform: crossing 0x18F0 boundary must be rejected ---- */
    {
        struct { LONG offset; ULONG length; } req;
        ULONG32 result = 0;
        req.offset = 0x18F0 - 4; req.length = 8; /* crosses forbidden boundary */
        CHECK(!Ioctl(h, IOCTL_INTEGRITY, &req, 8, &result, 4, &ret),
              "0x382C crossing 0x18F0 boundary rejected");
    }

    /* ---- integrity transform: end beyond 0x4220 must be rejected ---- */
    {
        struct { LONG offset; ULONG length; } req;
        ULONG32 result = 0;
        req.offset = 0x421C; req.length = 8; /* end = 0x4224 > 0x4220 */
        CHECK(!Ioctl(h, IOCTL_INTEGRITY, &req, 8, &result, 4, &ret),
              "0x382C end > 0x4220 rejected");
    }

    /* ---- determinism check ---- */
    {
        struct { LONG offset; ULONG length; } req;
        ULONG32 r1 = 0, r2 = 0;
        req.offset = 0x1000; req.length = 0x200;
        Ioctl(h, IOCTL_INTEGRITY, &req, 8, &r1, 4, &ret);
        Ioctl(h, IOCTL_INTEGRITY, &req, 8, &r2, 4, &ret);
        CHECK(r1 == r2, "0x382C transform is deterministic");
        printf("       transform(0x1000,0x200)=0x%08lX\n", r1);
    }

    /* ---- unknown IOCTL rejected ---- */
    CHECK(!Ioctl(h, 0xAA023900, NULL, 0, NULL, 0, &ret), "unknown IOCTL rejected");

    /* ---- native path: NtDeviceIoControlFile on fake handle ---- */
    {
        pNtDeviceIoControlFile NtDeviceIoControlFile =
            (pNtDeviceIoControlFile)GetProcAddress(GetModuleHandleA("ntdll.dll"), "NtDeviceIoControlFile");
        IO_STATUS_BLOCK iosb;
        ULONG32 ver = 0;
        NTSTATUS st = NtDeviceIoControlFile(h, NULL, NULL, NULL, &iosb, IOCTL_GET_VERSION, NULL, 0, &ver, 4);
        CHECK(st == 0 && ver == 0x44C, "NtDeviceIoControlFile(0x381C) works on fake handle");
    }

    /* ---- second open from same PID fails (driver semantics) ---- */
    {
        HANDLE h2 = OpenDevice();
        CHECK(h2 == INVALID_HANDLE_VALUE, "second open from same PID rejected");
    }

    /* ---- cleanup + reopen resets auth state ---- */
    CHECK(CloseHandle(h), "CloseHandle(fake) succeeds");
    h = OpenDevice();
    CHECK(h != INVALID_HANDLE_VALUE, "reopen after close succeeds");
    {
        WCHAR path[260];
        memset(path, 0, sizeof(path));
        CHECK(!Ioctl(h, IOCTL_REG_PATH, path, 0x208, NULL, 0, &ret),
              "state reset to 0 after reopen (0x3800 rejected again)");
    }
    {
        ULONG32 ver = 0;
        CHECK(Ioctl(h, IOCTL_GET_VERSION, NULL, 0, &ver, 4, &ret) && ver == 0x44C,
              "0x381C works again after reopen");
    }
    CloseHandle(h);

    printf("\n=== %s ===\n", g_fail ? "FAILURES PRESENT" : "ALL TESTS PASSED");
    return g_fail ? 1 : 0;
}
```
