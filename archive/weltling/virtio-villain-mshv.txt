`README.md`:

```md
# MSHV UAPI suite

Linux MSHV UAPI tests for partition lifecycle and virtual processor operations.
The suite uses
[Virtio Villain](https://github.com/weltling/virtio-villain)
to run a selected Linux kernel beneath nested Hyper-V through
[Cloud Hypervisor](https://github.com/cloud-hypervisor/cloud-hypervisor)
or [OpenVMM](https://github.com/microsoft/openvmm).
It targets x86-64 parent partitions and child partitions without
isolation.

## Quick start

Use an x86-64 Linux host with working MSHV support for Cloud Hypervisor or
KVM with nested VMX/SVM enabled for OpenVMM. Your user must have read and
write access to `/dev/mshv` or `/dev/kvm` respectively. After changing
device group membership, start a fresh login session. Each test VM uses
two vCPUs and 2 GiB RAM.

Have the following inputs available before starting.

- A current [Virtio Villain](https://github.com/weltling/virtio-villain)
  checkout.
- A compatible VMM executable and its UEFI firmware. Choose either
  [Cloud Hypervisor with MSHV](#cloud-hypervisor-with-mshv) or
  [OpenVMM with KVM](#openvmm-with-kvm) as described below.
- A local Linux source tree with MSHV root partition support, or an existing
  compatible x86-64 `bzImage`.
- The matching [ESP components](#esp-components) in a readable directory.
  `make esp` obtains these files from public Azure Linux RPMs.

Rust and Cargo are needed only if building the VMM.

### 1. Install build and image tools

On Azure Linux, install the native build dependencies and image tools.
The static C library is required to link the test executable.

```sh
sudo tdnf install gcc glibc-devel glibc-static make binutils python3 \
  flex bison bc elfutils-libelf-devel openssl-devel zlib-devel dwarves \
  util-linux dosfstools mtools tar gzip libarchive
```

### 2. Select the framework checkout

Run the remaining commands from this repository's root. Replace the example
paths with your checkouts.

```sh
cd /path/to/virtio-villain-mshv
```

Select the VMM and its firmware in step 4.

Keep the framework in a sibling `virtio-villain` directory.

### 3. Build the appliance and kernel

Prepare the boot files, then build the executable, initramfs and selected
kernel. Kernel sources must already be available locally.

```sh
make -j init initramfs kernel esp openvmm-firmware MSHV_SOURCE=/path/to/linux
./run --list
```

The default kernel config is `Microsoft/configs/x86/mshv_defconfig` under
`MSHV_SOURCE`. Kconfig adapts this base config to the source tree and local
toolchain. Each changed value is reported with its effective value.
Required appliance options remain strict, including MSHV root partition
support, EFI handover, initramfs support and the serial console.
These requirements are layered from `kernel/common.config` and
`kernel/x86_64.config`.
If using an existing kernel, omit `kernel` and `MSHV_SOURCE`
from the build command. Add `--kernel /path/to/bzImage` to each run command.
An ELF `vmlinux` image cannot be used for this boot path.

Nested testing can hang the outer host. A process timeout cannot recover
that host. Use external recovery for unattended runs.

### 4. Select a VMM and run

```sh
./run --vmm /path/to/openvmm --offline --console --timeout 180 ML0001
```

## VMM backends

Both backends use the same test executable, initramfs, MSHV kernel and
ESP components. They differ in the host hypervisor interface and UEFI
firmware.

| Requirement | Cloud Hypervisor | OpenVMM |
| --- | --- | --- |
| Host interface | `/dev/mshv` | `/dev/kvm` with nested VMX/SVM |
| VMM build | MSHV backend with nested Hyper-V support | KVM backend with `--nested-virt` |
| UEFI firmware | Cloud Hypervisor `CLOUDHV.fd` or compatible firmware | OpenVMM `MSVM.fd` |
| Boot component RPMs | All five packages listed below | All five packages listed below |

### Cloud Hypervisor with MSHV

Use a Cloud Hypervisor executable built with its `mshv` feature and
support for nested Hyper-V. The host must provide `/dev/mshv` with read
and write access for your user. Ordinary nested VMX/SVM support alone is
not enough for this backend.
See the
[Cloud Hypervisor MSHV guide](https://github.com/cloud-hypervisor/cloud-hypervisor/blob/main/docs/mshv.md).

Obtain `CLOUDHV.fd` from the
[Cloud Hypervisor edk2 releases](https://github.com/cloud-hypervisor/edk2/releases).
This firmware is separate from the ESP component RPMs.

```sh
./run --vmm /path/to/cloud-hypervisor --firmware /path/to/CLOUDHV.fd --offline --console --timeout 180 ML0001
./run --vmm /path/to/cloud-hypervisor --firmware /path/to/CLOUDHV.fd --offline --timeout 180
```

`--vmm` can be omitted when the correct `cloud-hypervisor` executable
is on `PATH`. Without an explicit firmware path, Cloud Hypervisor uses
the [firmware selection](#firmware) described below.

### OpenVMM with KVM

Use an OpenVMM build that supports `--nested-virt` on KVM and its matching
`MSVM.fd` UEFI firmware. The host must provide `/dev/kvm` with read and
write access for your user and have nested VMX/SVM enabled. It does not
need `/dev/mshv`.

The runner places the PCIe root complex on segment 1. This avoids the
Hyper-V assumption that x86 PCI configuration space on segment 0 is
accessible through CF8/CFC I/O ports.

Cloud Hypervisor firmware is not interchangeable with OpenVMM firmware.
Obtain the public MSVM firmware with `make openvmm-firmware`.
This downloads and verifies the
[mu_msvm x64 VS2022 release archive](https://github.com/microsoft/mu_msvm/releases/download/v26.0.22/RELEASE-X64-VS2022-artifacts.tar.gz)
and extracts `FV/MSVM.fd` to `target/openvmm-firmware/MSVM.fd`.
OpenVMM uses this prepared image by default and does not use the
Cloud Hypervisor firmware download.

```sh
make openvmm-firmware

./run --vmm /path/to/openvmm --offline --console --timeout 180 ML0001
./run --vmm /path/to/openvmm --offline --timeout 180
```

For either backend, the first command runs one lifecycle test with live
console output. The second runs all tests without live VM output.
Both retain complete logs and use local firmware without network access.
The GRUB boot path requires `CONFIG_EFI_STUB=y` and
`CONFIG_EFI_HANDOVER_PROTOCOL=y` in the selected kernel.

The runner selects OpenVMM when the executable name contains `openvmm`.
Use `--backend openvmm` for a renamed executable or `--backend ch` to force
Cloud Hypervisor. `--vmm PATH` selects the executable for one run.
Both backends boot the generated ESP disk through UEFI and capture the
serial console.

## Boot inputs

### ESP components

`make esp` downloads pinned Azure Linux 3.0 RPMs, verifies their SHA256
and extracts the boot files under `target/mshv-boot-inputs/esp`.
Repeated calls reuse verified local files. No repositories are configured
and no packages are installed. Extraction requires `bsdtar`, supplied by
`libarchive` on Azure Linux.

The runner uses this local directory by default and never fetches boot
components. `--esp PATH` selects another local directory.
With `--build-dir custom`, the default is `custom/mshv-boot-inputs/esp`.
Prepare it with `make esp TARGET=custom`. Missing or invalid inputs are
errors, not download triggers. Help and test listing need no boot files.

Paths below are relative to the boot component directory and must match
the filename case shown.

| RPM | Files used by the suite | CH | OpenVMM |
| --- | --- | --- | --- |
| `shim` | `EFI/BOOT/bootx64.efi`, `EFI/BOOT/mmx64.efi` | Required | Required |
| `grub2-efi-binary` | `EFI/BOOT/grubx64.efi` | Required | Required |
| `hvloader` | `HvLoader.efi` | Required | Required |
| `mshv-bootloader-lx` | `lxhvloader.dll` | Required | Required |
| `mshv` | `Windows/System32/hvix64.exe`, `Windows/System32/hvax64.exe`, `Windows/System32/kdstub.dll` | Required | Required |

Keep `mshv` and `mshv-bootloader-lx` at the same version and release.
Both CPU vendor hypervisor binaries are required.
`mshv-kd` is not needed because `mshv` supplies `kdstub.dll`.

Shim and GRUB are requirements of the current shared boot image, not
intrinsic OpenVMM requirements. The suite generates its own boot
configuration. The RPMs are only extracted, not installed on the host.
VMM executables, firmware and the Linux kernel are separate inputs.

The MSHV RPMs are proprietary and their terms require an active Microsoft
Azure agreement. Review the extracted license files under
`target/mshv-boot-inputs/esp/licenses` before use.

Cloud Hypervisor execution with this component set has not been checked.

### Firmware

For Cloud Hypervisor, without `--firmware`, the runner prefers the installed
`/usr/share/cloud-hypervisor/CLOUDHV_EFI.fd`. If that file is absent, it
downloads `CLOUDHV.fd` from the latest
[Cloud Hypervisor edk2 release](https://github.com/cloud-hypervisor/edk2/releases/latest)
and verifies the published SHA256. An unreadable or invalid installed file
is an error, not a download trigger.

Use `--firmware PATH` to select a local file explicitly. `--offline`
forbids network access and permits installed firmware or the last verified
cached release. The cache is under
`target/virtio-villain/firmware` in the suite directory.
Online fallback checks for the latest release. Download failures do not
silently select an older version.

OpenVMM uses `openvmm-firmware/MSVM.fd` under the selected build output
by default. Use `--firmware PATH` to select another local `MSVM.fd`.
The installed Cloud Hypervisor firmware and its download cache are not
used by the OpenVMM backend.

Run `make openvmm-firmware` to obtain the pinned public firmware described
in [OpenVMM setup](#openvmm-with-kvm). The archive and extracted firmware
are verified with SHA256 before reuse. No firmware is fetched during an
OpenVMM run.
Use `make openvmm-firmware TARGET=custom` for a different build output,
then run with `--build-dir custom`.
`make clean` removes these downloaded inputs along with other build output.

All boot inputs must be nonempty readable regular files. Preflight checks
their formats before launching tests. These checks do not establish
provenance or guarantee that a component set will boot together.

### Shared boot image

The first run builds one 130 MiB boot disk under `target/boot/INPUT_HASH/`. Every test and repetition boots that disk read only. Later runs reuse it when the kernel, initramfs, ESP components, firmware and boot configuration are unchanged.

Changed boot inputs create a new cache entry without replacing images used by other runs. `--build-dir` changes the cache root. Per test results retain logs and small launch metadata files that reference the shared image, not copies of the disk or firmware.

Build the initramfs with the current sibling framework checkout. The shared image requires its SMBIOS startup support and `CONFIG_DMI=y` and `CONFIG_DMIID=y` in the kernel.

## Build options

The suite currently builds and runs x86_64 appliances only.
`kernel/aarch64.config` provides an ARM64 fragment for kernel configuration
preparation. It requires 4 KiB pages for MSHV and selects the PL011 console.
It does not enable ARM64 appliance builds or execution.

`make init` builds the static test executable. `make initramfs` builds and
packages it as `/init` and is the default target. `mshv` and
`mshv-initramfs` are aliases for `initramfs`. These targets do not require a
kernel source tree.

`make kernel` requires `MSHV_SOURCE`. It accepts modified source trees and
source archives without Git metadata. The runner uses the image from the
last successful kernel build for the selected output root, unless
`--kernel PATH` overrides it. Execution never builds or downloads a kernel
implicitly.

Default build outputs are under this suite directory.

| Output | Purpose |
| --- | --- |
| `target/init` | Static test executable |
| `target/initramfs.cpio.gz` | Test initramfs |
| `target/kernel/images/bzImage-x86_64` | Kernel used by the nested boot path |
| `target/kernel/images/vmlinux-x86_64` | ELF kernel image, not a boot input for this suite |

Use `TARGET=custom` when building and `--build-dir custom` when running to
select matching outputs. Relative output roots are resolved from the suite
directory.

```sh
make -j init initramfs kernel esp openvmm-firmware MSHV_SOURCE=/path/to/linux TARGET=custom
./run --build-dir custom --timeout 180 ML0001
```

`./run --build ML0001` rebuilds the executable and initramfs before
execution, but not the kernel. Explicit `--binary` and `--initramfs`
overrides cannot be combined with `--build`.

The same build targets are available from the framework directory with
`make SUITE=/path/to/virtio-villain-mshv initramfs` or
`make SUITE=/path/to/virtio-villain-mshv kernel MSHV_SOURCE=/path/to/linux`.
Use `make help` for all suite build variables.

### Custom kernel configs

`KERNEL_CONFIGS` is an ordered, space separated list of config files and
fragments. A nonempty list replaces the default MSHV config. Later files
override earlier values. Relative paths are resolved from the suite directory.
Explicit custom configs are checked strictly. The build fails if Kconfig
cannot retain a requested value. A full config from another toolchain may
contain generated compiler versions or unavailable features that need
updating.

```sh
make kernel MSHV_SOURCE=/path/to/linux \
  KERNEL_CONFIGS="/path/base.config /path/extra.config" \
  KERNEL_ARGS="--output /path/custom-kernel"
```

`KERNEL_ARGS` adds generic kernel builder options after the standard
arguments. Use a new output directory when changing the source, config or
toolchain. The builder rejects changed inputs in an existing output
directory. Set `V=1` to print build commands.

Kernel builds use `RUSTC=false` by default. For a compatible configuration
requiring Rust, pass `RUSTC=rustc` or another compiler command to Make.
Use `../virtio-villain/build-kernel --help` for all kernel builder options.

Custom configurations must include MSHV root partition support and the
features needed to boot the test initramfs. These include `CONFIG_MSHV_ROOT=y`,
`CONFIG_HYPERV=y`, `CONFIG_HYPERV_VMBUS=y`, `CONFIG_BLK_DEV_INITRD=y`,
`CONFIG_RD_GZIP=y`, `CONFIG_DEVTMPFS=y`, `CONFIG_PROC_FS=y`,
`CONFIG_SYSFS=y`, `CONFIG_BINFMT_ELF=y`, `CONFIG_DMI=y`, `CONFIG_DMIID=y`
and the serial console.

### Cleanup

`make clean` removes the entire selected `TARGET` directory, including
kernel builds, downloaded boot inputs, caches and saved results.

## Running tests

Use `./run --list` to list test IDs and descriptions without building.
IDs have a category prefix and four digits and can be supplied in any
letter case. Rebuild after adding or changing tests.

| Prefix | Category | Sources |
| --- | --- | --- |
| ML | Partition lifecycle and related operations | [tests/ml](./tests/ml) |
| MR | Virtual processor registers and state | [tests/mr](./tests/mr) |

Omitting IDs runs all tests. Each test and repetition gets a fresh VM.
The suite boots nested Hyper-V before Linux so that the test kernel can
create child partitions. Direct Linux boot and device node presence alone
do not establish the required parent partition privileges.

```sh
./run --timeout 180 --repeat 3 ML0001 MR0001 MR0003
```

| Option | Effect |
| --- | --- |
| `--vmm PATH` | Select Cloud Hypervisor or OpenVMM instead of the default `cloud-hypervisor` command |
| `--backend auto\|ch\|openvmm` | Override backend detection from the executable name |
| `--firmware PATH` | Override the selected local UEFI firmware |
| `--esp PATH` | Override the local boot component directory prepared by `make esp` |
| `--kernel PATH` | Select an existing x86-64 `bzImage` |
| `--initramfs PATH` | Select a separate test initramfs |
| `--console`, `-c` | Show live VM output while retaining complete logs |
| `--jobs N`, `-j N` | Limit concurrent VMs, with one as the default |
| `--repeat N` | Repeat the selected tests |
| `--timeout SECONDS` | Set the per test deadline, with 120 seconds as the default |
| `--output PATH` | Use a new diagnostics and runtime artifact directory |
| `--control EXECUTABLE` | Select an external watchdog and recovery control |

Console mode runs one VM at a time regardless of `--jobs`.
Use `./run --help` for all options. From the framework directory, use
`./run --suite /path/to/virtio-villain-mshv` with the same options.

Reports, console logs and launch metadata are retained under `target/results/TIMESTAMP-ID/` by default. `--build-dir` changes the build root and default results location. `--output` selects an explicit new directory instead. `results.json` includes individual verdicts, image hashes, launch arguments and artifact paths. Failed runs also retain diagnostics. Shared boot images remain under the build root.

No external recovery control is supplied by this repository. The control
must survive a hang of the outer host, not merely terminate the VMM.
See the framework's [suite documentation](https://github.com/weltling/virtio-villain/blob/main/docs/suites.md)
for the control interface.

Exit status 0 means the executed tests passed. Status 1 means an assertion
or cleanup failed. Status 2 means infrastructure failed. Missing required
privileges, interfaces or boot results cannot produce a pass or an optional
skip.

/* SPDX-License-Identifier: Apache-2.0 */
#include <cpuid.h>

#include "lib/mshv.h"

int mshv_preflight(void)
{
    unsigned a, b, c, d;
    __cpuid(VV_X86_CPUID_FEATURES, a, b, c, d);
    if (!(c & HYPERV_HYPERVISOR_PRESENT_BIT)) {
        printf("mshv-infra expected Hyper-V parent partition, no hypervisor CPUID bit\n");
        return -1;
    }
    __cpuid(HYPERV_CPUID_VENDOR_AND_MAX_FUNCTIONS, a, b, c, d);
    if (a < HYPERV_CPUID_FEATURES) {
        printf("mshv-infra Hyper-V feature leaf unavailable: max=0x%x\n", a);
        return -1;
    }
    __cpuid(HYPERV_CPUID_INTERFACE, a, b, c, d);
    if (a != VV_HYPERV_INTERFACE_HV1_SIGNATURE) {
        printf("mshv-infra expected Hv#1 CPUID interface signature=0x%x, actual=0x%x\n",
               VV_HYPERV_INTERFACE_HV1_SIGNATURE, a);
        return -1;
    }
    __cpuid(HYPERV_CPUID_FEATURES, a, b, c, d);
    printf("mshv-prerequisite CPUID.%08x EBX=0x%08x\n", HYPERV_CPUID_FEATURES, b);
    if (!(b & HV_CREATE_PARTITIONS) || (b & HV_ISOLATION)) {
        printf("mshv-infra requires CreatePartitions (HV_CREATE_PARTITIONS) without HV_ISOLATION\n");
        return -1;
    }
    struct mshv_fixture f = {.device = -1, .partition = -1, .vp = -1};
    test_result_t result = mshv_create(&f);

def _read_at(stream, offset, size, description):
    stream.seek(offset)
    data = stream.read(size)
    if len(data) != size:
        raise ValueError(f"Truncated {description}: expected {size} bytes, got {len(data)}")
    return data


def _validate_pe(stream, size):
    dos = _read_at(stream, 0, PE_DOS_HEADER_SIZE, "PE DOS header")
    if dos[:2] != b"MZ":
        raise ValueError(f"Expected MZ DOS signature, got {dos[:2]!r}")
    pe_offset = struct.unpack_from("<I", dos, PE_DOS_LFANEW_OFFSET)[0]
    if pe_offset < PE_DOS_HEADER_SIZE:
        raise ValueError(f"Invalid PE header offset {pe_offset}")
    signature = _read_at(stream, pe_offset, len(PE_SIGNATURE), "PE signature")
    if signature != PE_SIGNATURE:
        raise ValueError(f"Expected PE/COFF signature {PE_SIGNATURE!r}, got {signature!r}")
    coff = _read_at(stream, pe_offset + len(PE_SIGNATURE), PE_COFF_HEADER.size, "COFF header")
    machine, sections, _, _, _, optional_size, characteristics = PE_COFF_HEADER.unpack(coff)
    if machine != PE_MACHINE_AMD64:
        raise ValueError(f"Expected AMD64 PE machine 0x{PE_MACHINE_AMD64:x}, got 0x{machine:x}")
    if not characteristics & PE_CHARACTERISTIC_EXECUTABLE_IMAGE:
        raise ValueError("PE/COFF image lacks IMAGE_FILE_EXECUTABLE_IMAGE")
    if optional_size < PE32_PLUS_MIN_HEADER_SIZE:
        raise ValueError(f"Truncated PE32+ optional header size {optional_size}")
    optional_offset = pe_offset + len(PE_SIGNATURE) + PE_COFF_HEADER.size
    optional = _read_at(stream, optional_offset, optional_size, "PE32+ optional header")
    magic = struct.unpack_from("<H", optional)[0]
    if magic != PE32_PLUS_MAGIC:
        raise ValueError(f"Expected PE32+ magic 0x{PE32_PLUS_MAGIC:x}, got 0x{magic:x}")
    section_offset = optional_offset + optional_size
    if not sections or section_offset + sections * PE_SECTION_HEADER.size > size:
        raise ValueError("Missing or truncated PE section table")
    for index in range(sections):
        section = PE_SECTION_HEADER.unpack(_read_at(
            stream, section_offset + index * PE_SECTION_HEADER.size,
            PE_SECTION_HEADER.size, "PE section header"))
        raw_size, raw_offset = section[3:5]
        if raw_size and raw_offset + raw_size > size:
            raise ValueError(f"Truncated PE section {index}: data extends beyond the file")


def _validate_firmware(stream, size):
    if _read_at(stream, 0, min(4, size), "firmware signature") == b"\x7fELF":
        header = ELF64_HEADER.unpack(_read_at(stream, 0, ELF64_HEADER.size, "ELF64 header"))
        ident, file_type, machine, _, _, phoff, _, _, ehsize, phsize, phcount, _, _, _ = header
        # The installed ELF64 firmware uses an EM_386 entry before entering long mode.
        if (not ident.startswith(ELF64_LE_IDENT)
                or machine not in (ELF_MACHINE_I386, ELF_MACHINE_X86_64)):
            raise ValueError("Expected little endian ELF64 firmware for x86")
        if file_type not in (ELF_ET_EXEC, ELF_ET_DYN) or ehsize != ELF64_HEADER.size:
            raise ValueError("Invalid executable ELF firmware header")
        if (not phcount or phsize != ELF64_PROGRAM_HEADER.size
                or phoff + phsize * phcount > size):
            raise ValueError("Missing or truncated ELF firmware program headers")
        loadable = False
        for index in range(phcount):
            segment = ELF64_PROGRAM_HEADER.unpack(_read_at(
                stream, phoff + index * phsize, phsize, "ELF program header"))
            kind, _, offset, _, _, file_size, memory_size, _ = segment
            if kind == ELF_PT_LOAD:
                if file_size > memory_size or offset + file_size > size:
                    raise ValueError(f"Invalid ELF load segment {index}")
                loadable |= file_size > 0
        if not loadable:
            raise ValueError("ELF firmware has no loadable data")
    for offset in range(0, size, VALIDATION_CHUNK_SIZE):
        block = _read_at(stream, offset, min(
            VALIDATION_CHUNK_SIZE + len(UEFI_FV_SIGNATURE) - 1, size - offset), "firmware data")
        start = 0
        while (position := block.find(UEFI_FV_SIGNATURE, start)) >= 0:
            start = position + len(UEFI_FV_SIGNATURE)
            base = offset + position - UEFI_FV_SIGNATURE_OFFSET
            if base < 0 or base + UEFI_FV_HEADER.size > size:
                continue
            header = UEFI_FV_HEADER.unpack(_read_at(
                stream, base, UEFI_FV_HEADER.size, "UEFI firmware volume header"))
            _, _, length, _, _, header_length, _, _, _, revision = header
            if (revision != UEFI_FV_REVISION or header_length < UEFI_FV_HEADER.size
                    or header_length % 2 or header_length > length or base + length > size):
                continue
            data = _read_at(stream, base, header_length, "UEFI firmware volume checksum")
            if sum(struct.unpack(f"<{header_length // 2}H", data)) & 0xFFFF == 0:
                return
    raise ValueError("No UEFI firmware volume with a valid signature, length and header checksum")


def _validate_kernel(stream, size):
    boot_flag = _read_at(stream, LINUX_BOOT_FLAG_OFFSET, len(LINUX_BOOT_FLAG), "bzImage boot flag")
    setup = _read_at(stream, LINUX_SETUP_SIGNATURE_OFFSET,
                     len(LINUX_SETUP_SIGNATURE), "bzImage setup signature")
    if boot_flag != LINUX_BOOT_FLAG or setup != LINUX_SETUP_SIGNATURE:
        raise ValueError("Expected x86 bzImage boot flag and HdrS signature, not vmlinux ELF")


def _validate_initramfs(stream, size):
    with gzip.GzipFile(fileobj=stream) as archive:
        header = archive.read(NEWC_HEADER_SIZE)
        if (len(header) != NEWC_HEADER_SIZE or header[:6] not in (b"070701", b"070702")
                or any(byte not in b"0123456789abcdefABCDEF" for byte in header[6:])):
            raise ValueError("Expected a gzip compressed newc initramfs header")
        # Reading to EOF makes gzip verify the trailer and CRC.
        while archive.read(VALIDATION_CHUNK_SIZE):
            pass


def validate_boot_inputs(kernel, initramfs, esp, firmware=FIRMWARE):
    checks = [
        ("bzImage kernel", kernel, _validate_kernel),
        ("gzip/newc initramfs", initramfs, _validate_initramfs),
        ("UEFI firmware", firmware, _validate_firmware),
        *(("x86-64 PE/COFF boot component", esp / name, _validate_pe)
          for name in ESP_COMPONENTS.values()),
    ]
    errors = []
    for kind, path, validate in checks:
        try:
            info = path.stat()
            if not stat.S_ISREG(info.st_mode) or not info.st_size:
                raise ValueError("Expected a nonempty regular file")
            with path.open("rb") as stream:
                validate(stream, info.st_size)
        except (OSError, ValueError, EOFError, struct.error, zlib.error) as error:
            errors.append(f"{kind} {path}: {error}")
    for tool in IMAGE_TOOLS:
        if not shutil.which(tool):
            errors.append(f"Missing image construction tool: {tool}")
    if errors:
        raise RuntimeError("Boot input preflight failed:\n  " + "\n  ".join(errors))

            shutil.copyfileobj(source, destination)

def _verify_shared_image(output, expected):
    try:
        manifest = json.loads((output / "manifest.json").read_text())
        actual = {name: metadata["sha256"] for name, metadata in manifest["files"].items()}
        valid = (
            manifest["cmdline"] == expected["cmdline"] and actual == expected["files"]
            and manifest["firmware_sha256"] == expected["firmware_sha256"]
            and (output / "grub.cfg").read_text() == expected["grub"]
            and sha256(output / "firmware.fd") == expected["firmware_sha256"]
            and sha256(output / "boot.img") == manifest["disk_sha256"])
    except (OSError, ValueError, KeyError, TypeError, AttributeError) as error:
        raise RuntimeError(f"Cannot verify shared boot image {output}: {error}") from error
    if not valid:
        raise RuntimeError(f"Shared boot image verification failed: {output}")


def prepare_image(cache, kernel, initramfs, esp, firmware):
    sources = {
        **{name: esp / source for name, source in ESP_COMPONENTS.items()},
        "boot/vmlinuz": kernel,
        "boot/initramfs.cpio.gz": initramfs,
    }
    expected = {
        "cmdline": SHARED_CMDLINE,
        "grub": grub_config(SHARED_CMDLINE),
        "files": {name: sha256(path) for name, path in sources.items()},
        "firmware_sha256": sha256(firmware),
    }
    key = hashlib.sha256(json.dumps(expected, sort_keys=True).encode()).hexdigest()
    cache.mkdir(parents=True, exist_ok=True)
    output = cache / key
    with (cache / ".lock").open("a+b") as lock:
        fcntl.flock(lock, fcntl.LOCK_EX)
        if not output.exists():
            with tempfile.TemporaryDirectory(prefix=".prepare-", dir=cache) as temporary:
                prepared = Path(temporary) / "image"
                build_image(prepared, kernel, initramfs, SHARED_CMDLINE, esp, firmware)
                if ({name: sha256(path) for name, path in sources.items()} != expected["files"]
                        or sha256(firmware) != expected["firmware_sha256"]):
                    raise RuntimeError("Boot inputs changed during shared image preparation")
                _verify_shared_image(prepared, expected)
                prepared.rename(output)
        else:
            _verify_shared_image(output, expected)
    return output / "boot.img"

        fcntl.flock(lock, fcntl.LOCK_EX)

            manifest = json.loads((esp / "manifest.json").read_text())
            if (not isinstance(manifest, dict) or manifest.get("packages") != PACKAGES
                    or not isinstance(manifest.get("files"), dict)
                    or set(manifest["files"]) != set(FILES)):
                raise RuntimeError(f"Boot component metadata does not match pinned RPMs: {esp}")
            for name in FILES:
                verify(esp / name, manifest["files"][name])
            return esp

        if not shutil.which("bsdtar"):
            raise RuntimeError("Missing RPM extraction tool: bsdtar")
        cache = output / "rpms"
        cache.mkdir(exist_ok=True)
        packages = [download(name, digest, cache) for name, digest in PACKAGES.items()]
        with tempfile.TemporaryDirectory(prefix=".extract-", dir=output) as temporary:
            root = Path(temporary)
            for package in packages:
                subprocess.run(["bsdtar", "-xf", str(package), "-C", str(root)], check=True)
            prepared = root / "boot/efi"
            for name in ESP_COMPONENTS.values():
                path = prepared / name
                with path.open("rb") as stream:
                    _validate_pe(stream, path.stat().st_size)
            shutil.copytree(root / "usr/share/licenses", prepared / "licenses")
            (prepared / "manifest.json").write_text(json.dumps({
                "packages": PACKAGES,
                "files": {name: sha256(prepared / name) for name in FILES},
            }, indent=2) + "\n")
            if esp.exists():
                if (not esp.is_dir() or esp.is_symlink()
                        or any(path.is_symlink() for path in esp.rglob("*"))):
                    raise RuntimeError(
                        f"Existing ESP must be a directory without symbolic links: {esp}")
                for name in FILES:
                    path = esp / name
                    if path.exists() or name in ESP_COMPONENTS.values():
                        verify(path, sha256(prepared / name))
                for name in FILES:
                    path = esp / name
                    if not path.exists():
                        path.parent.mkdir(parents=True, exist_ok=True)
                        shutil.copyfile(prepared / name, path)
                (prepared / "manifest.json").replace(esp / "manifest.json")
            else:
                prepared.rename(esp)
    return esp

    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--output", type=Path, required=True,

ARCHIVE_NAME = "RELEASE-X64-VS2022-artifacts.tar.gz"
ARCHIVE_URL = (
    "https://github.com/microsoft/mu_msvm/releases/download/v26.0.22/" + ARCHIVE_NAME)
ARCHIVE_SHA256 = "e5a2477ee3e730a7310b24a43068f89129e9b82b183f0a5901fcc1d206c577b7"
FIRMWARE_SHA256 = "660899fafe7fb955de6ebe5ed2135430dffd845841c6e07ad19774ccf273e9a3"


def fetch(output):
    output = Path(output).resolve()
    output.mkdir(parents=True, exist_ok=True)
    firmware = output / "MSVM.fd"
    with (output / ".lock").open("a+b") as lock:
        fcntl.flock(lock, fcntl.LOCK_EX)
        if firmware.exists():
            verify(firmware, FIRMWARE_SHA256)
            return firmware
        package = download(ARCHIVE_NAME, ARCHIVE_SHA256, output, url=ARCHIVE_URL)
        with tempfile.TemporaryDirectory(prefix=".extract-", dir=output) as temporary:
            staged = Path(temporary) / "MSVM.fd"
            with tarfile.open(package, "r:gz") as archive:
                member = archive.getmember("./FV/MSVM.fd")
                if not member.isfile():
                    raise RuntimeError(f"Expected a regular firmware file in {package}: FV/MSVM.fd")
                source = archive.extractfile(member)
                if source is None:
                    raise RuntimeError(f"Cannot read firmware from {package}: FV/MSVM.fd")
                with source, staged.open("wb") as stream:
                    shutil.copyfileobj(source, stream)
            verify(staged, FIRMWARE_SHA256)
            with staged.open("rb") as stream:
                _validate_firmware(stream, staged.stat().st_size)
            staged.replace(firmware)
    return firmware

    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--output", type=Path, required=True,

test_result_t mshv_expect_ioctl(int fd, unsigned long request, void *arg,
                              const char *operation, int expected_errno)
{
    errno = 0;
    int rc = ioctl(fd, request, arg);
    int actual_errno = errno;
    if ((expected_errno == 0 && rc != 0) ||
        (expected_errno != 0 && (rc != -1 || actual_errno != expected_errno)))
        TFAIL("%s: expected rc=%d errno=%d (%s), actual rc=%d errno=%d (%s)",
              operation, expected_errno ? -1 : 0, expected_errno,
              strerror(expected_errno), rc, actual_errno, strerror(actual_errno));
    return TEST_PASS;
}

test_result_t mshv_close(int *fd, const char *operation)
{
    if (*fd < 0)
        return TEST_PASS;
    int owned = *fd;
    *fd = -1;
    if (close(owned) != 0)
        TFAIL("%s: close(%d) expected 0, actual -1 errno=%d (%s)",
              operation, owned, errno, strerror(errno));
    return TEST_PASS;
}

        result = TEST_FAIL;
    if (mshv_close(&f->partition, "cleanup partition") != TEST_PASS)
        result = TEST_FAIL;
    if (mshv_close(&f->device, "cleanup device") != TEST_PASS)
        result = TEST_FAIL;
    return result;
}

test_result_t mshv_check_fd(int fd, const char *operation, ...)
{
    int actual_errno = errno;
    int flags = -1;
    if (fd >= 0) {
        flags = fcntl(fd, F_GETFD);
        actual_errno = flags < 0 ? errno : 0;
    }
    if (flags >= 0 && (flags & FD_CLOEXEC))
        return TEST_PASS;
    printf("vv-fail %s:%d: ", __FILE__, __LINE__);
    va_list args;
    va_start(args, operation);
    vprintf(operation, args);
    va_end(args);
    if (fd < 0)
        printf(": expected resource fd >= 0, actual %d errno=%d (%s)\n",
               fd, actual_errno, strerror(actual_errno));
    else
        printf(": fd=%d expected F_GETFD with FD_CLOEXEC, actual %d errno=%d\n",
               fd, flags, actual_errno);
    fflush(stdout);
    return TEST_FAIL;
}

test_result_t mshv_create(struct mshv_fixture *f)
{
    struct mshv_create_partition partition = {
        .pt_flags = VV_MSHV_PARTITION_FLAGS_NONE,
        .pt_isolation = MSHV_PT_ISOLATION_NONE,
    };

    f->device = open("/dev/mshv", O_RDWR | O_CLOEXEC);

    f->partition = ioctl(f->device, MSHV_CREATE_PARTITION, &partition);
    if (mshv_check_fd(f->partition,
                      "MSHV_CREATE_PARTITION flags=0x%" PRIx64 " isolation=0x%" PRIx64,
                      (uint64_t)partition.pt_flags, (uint64_t)partition.pt_isolation) != TEST_PASS)
        return TEST_FAIL;
    if (mshv_expect_ioctl(f->partition, MSHV_INITIALIZE_PARTITION, NULL,
                          "MSHV_INITIALIZE_PARTITION", 0) != TEST_PASS)
        return TEST_FAIL;
    f->vp = ioctl(f->partition, MSHV_CREATE_VP, &vp);
    return mshv_check_fd(f->vp, "MSHV_CREATE_VP index=%u", vp.vp_index);

/* SPDX-License-Identifier: Apache-2.0 */
/*
 * Shared general purpose register (GPR) checks.
 * Use RAX, RCX, RDX, RBX with distinct seed-derived values. Poison receive
 * slots before GET, then require exact lower 64-bit values and register names.
 * Separate SET and GET checks allow observation without overwriting state.
 * The upper half of each 128-bit ABI value slot is not asserted for GPRs.
 * Also require unchanged request count, padding and array pointer, plus zero
 * must-be-zero (MBZ) association fields. Both IOCTLs must return zero.
 * These checks exercise register access, not virtual processor execution.
 */
#include <inttypes.h>
#include <string.h>

#include "lib/mshv.h"

static test_result_t access_gprs(struct mshv_fixture *f, unsigned count,
                                 uint64_t seed, unsigned long request)
{
    const uint32_t names[] = {VV_RAX, VV_RCX, VV_RDX, VV_RBX};
    enum { REGISTER_COUNT = sizeof(names) / sizeof(names[0]) };
    struct hv_register_assoc regs[REGISTER_COUNT] = {0};
    struct mshv_vp_registers args = {.count = count, .regs = regs};
    uint64_t expected[REGISTER_COUNT];
    const char *operation = request == MSHV_SET_VP_REGISTERS ? "SET" : "GET";

    if (count == 0 || count > REGISTER_COUNT)
        TFAIL("internal register count: expected 1..%u, actual %u",
              (unsigned)REGISTER_COUNT, count);
    for (unsigned i = 0; i < count; ++i) {
        regs[i].name = names[i];
        expected[i] = seed ^ (VV_GPR_REGISTER_STRIDE * i);
        if (request == MSHV_SET_VP_REGISTERS)
            regs[i].value.reg64 = expected[i];
        else
            memset(&regs[i].value, 0xa5, sizeof(regs[i].value));
    }
    if (mshv_expect_ioctl(f->vp, request, &args,
                          request == MSHV_SET_VP_REGISTERS ?
                          "MSHV_SET_VP_REGISTERS GPRs" : "MSHV_GET_VP_REGISTERS GPRs",
                          0) != TEST_PASS)
        return TEST_FAIL;
    if (args.count != count || args.padding != 0 || args.regs != regs)
        TFAIL("%s fd=%d register envelope changed: expected count=%u padding=0 regs=%p, "
              "actual count=%u padding=%u regs=%p",
              operation, f->vp, count, (void *)regs, args.count,
              args.padding, (void *)args.regs);
    for (unsigned i = 0; i < count; ++i) {
        if (regs[i].name != names[i] || regs[i].reserved1 || regs[i].reserved2)
            TFAIL("%s fd=%d association %u: expected name=0x%x and MBZ fields; "
                  "actual name=0x%x reserved1=0x%x reserved2=0x%" PRIx64,
                  operation, f->vp, i, names[i], regs[i].name,
                  regs[i].reserved1, regs[i].reserved2);
        if (regs[i].value.reg64 != expected[i])
            TFAIL("%s fd=%d register 0x%x: expected 0x%016" PRIx64 ", actual 0x%016" PRIx64,
                  operation, f->vp, names[i], expected[i], regs[i].value.reg64);
    }
    return TEST_PASS;
}

test_result_t mshv_set_gprs(struct mshv_fixture *f, unsigned count, uint64_t seed)
{
    return access_gprs(f, count, seed, MSHV_SET_VP_REGISTERS);
}

test_result_t mshv_check_gprs(struct mshv_fixture *f, unsigned count, uint64_t seed)
{
    return access_gprs(f, count, seed, MSHV_GET_VP_REGISTERS);
}

test_result_t mshv_roundtrip(struct mshv_fixture *f, unsigned count, uint64_t seed)
{
    if (mshv_set_gprs(f, count, seed) != TEST_PASS)
        return TEST_FAIL;
    return mshv_check_gprs(f, count, seed);
}

static int allocate(int type, int index, int owner)
{
    assert(next_fd < 4096);
    int fd = next_fd++;
    types[fd] = type;
    indices[fd] = index;
    owners[fd] = owner;
    ++open_fds;
    return fd;
}

{
    assert(!strcmp(path, "/dev/mshv"));
    assert(flags == (O_RDWR | O_CLOEXEC));
    if (++opens == fail_open_at) {
        errno = EACCES;
        return -1;

        errno = EMFILE;
        return -1;

static int mock_fcntl(int fd, int command)
{

    if (++fd_checks == fail_fd_at) {
        errno = EBADF;
        return -1;

    if (fd_flags < 0)
        errno = EBADF;

static int mock_close(int fd)
{
    assert(types[fd]);
    if (types[fd] != 1) {
        struct mock_partition *partition = &partitions[owners[fd]];
        assert(references > 0 && partition->references > 0);
        --references;
        if (--partition->references == 0) {
            memset(partition, 0, sizeof(*partition));
            for (unsigned i = 0; break_release &&
                 i < sizeof(partitions) / sizeof(partitions[0]); ++i) {
                if (partitions[i].references) {
                    partitions[i].broken = 1;
                    ++release_breaks;
                }
            }
            if (corrupt_release) {
                for (unsigned i = 0; i < sizeof(partitions) / sizeof(partitions[0]); ++i) {
                    if (partitions[i].references) {
                        partitions[i].values[0][0] ^= 1;
                        ++release_corruptions;
                    }
                }
            }
        }
    }
    types[fd] = 0;
    --open_fds;
    ++closes;
    if (close_failure || closes == fail_close_at) {
        close_failure = 0;
        errno = EINTR;
        return -1;
    }
    return 0;
}

static int mock_ioctl(int fd, unsigned long request, void *arg)
{
    if (fd < 0 || fd >= (int)(sizeof(types) / sizeof(types[0])) || !types[fd])
        return reject(EBADF);
    if (++calls == fail_at)
        return reject(EIO);
    if (types[fd] != 1 && partitions[owners[fd]].broken)
        return reject(EIO);

    if (types[fd] == 1) {
        if (!is_device_request(request))
            return reject(ENOTTY);
        if (request == MSHV_CREATE_PARTITION) {
            struct mshv_create_partition *args = arg;
            if (!args)
                return reject(EFAULT);
            if ((args->pt_flags & ~MSHV_PT_FLAGS_MASK) ||
                args->pt_isolation >= MSHV_PT_ISOLATION_COUNT)
                return reject(EINVAL);
            if (mock_limit.rlim_cur == 0 && unexpected_creation != 1) {
                ++partition_rejections;
                if (damage_unwind == 1)
                    partitions[0].values[0][0] ^= 1;
                return reject(EMFILE);
            }
            unsigned owner = 0;
            while (owner < sizeof(partitions) / sizeof(partitions[0]) &&
                   partitions[owner].references)
                ++owner;
            assert(owner < sizeof(partitions) / sizeof(partitions[0]));
            partitions[owner].references = 1;
            partitions[owner].initialized = 0;
            ++references;
            return allocate(2, 0, owner);
        }
        if (request == MSHV_ROOT_HVCALL) {
            if (!arg)
                return reject(EFAULT);
            return 0;
        }
        return reject(ENOTTY);
    }

    if (types[fd] == 2) {
        if (!is_partition_request(request))
            return reject(ENOTTY);
        if (is_snp_partition_request(request))
            return reject(EOPNOTSUPP);
        if (request == MSHV_INITIALIZE_PARTITION) {
            partitions[owners[fd]].initialized = 1;
            return 0;
        }
        if (request == MSHV_CREATE_VP) {
            struct mshv_create_vp *args = arg;
            if (!args)
                return reject(EFAULT);
            if (!partitions[owners[fd]].initialized)
                return reject(EIO);
            if (args->vp_index >= 256)
                return reject(EINVAL);
            struct mock_partition *partition = &partitions[owners[fd]];
            assert(args->vp_index < 2);
            if (partition->vp_created[args->vp_index])
                return reject(EEXIST);
            if (mock_limit.rlim_cur == 0 && unexpected_creation != 2) {
                ++vp_rejections;
                if (damage_unwind == 2)
                    partitions[0].values[0][0] ^= 1;
                if (retain_failed_vp)
                    partition->vp_created[args->vp_index] = 1;
                return reject(EMFILE);
            }
            partition->vp_created[args->vp_index] = 1;
            ++partition->references;
            ++references;
            return allocate(3, args->vp_index, owners[fd]);
        }
        if (request == MSHV_SET_GUEST_MEMORY) {
            if (!arg)
                return reject(EFAULT);
            struct mshv_user_mem_region *m = arg;
            if (!m->size || (m->size % 4096) || (m->userspace_addr % 4096) || (m->flags & ~0x07))
                return reject(EINVAL);
            return 0;
        }
        if (request == MSHV_IRQFD) {
            if (!arg)
                return reject(EFAULT);
            struct mshv_user_irqfd *irq = arg;
            if (irq->flags & ~0x03)
                return reject(EINVAL);
            if (irq->fd < 0)
                return reject(EBADF);
            return 0;
        }
        if (request == MSHV_IOEVENTFD) {
            if (!arg)
                return reject(EFAULT);
            struct mshv_user_ioeventfd *io = arg;
            if (io->flags & ~0x07)
                return reject(EINVAL);
            if (io->len != 1 && io->len != 2 && io->len != 4 && io->len != 8)
                return reject(EINVAL);
            return 0;
        }
        if (!arg && request != MSHV_SCRUB_PARTITION)
            return reject(EFAULT);
        return 0;
    }

    assert(types[fd] == 3);
    if (!is_vp_request(request))
        return reject(ENOTTY);
    if (request == MSHV_GET_VP_STATE || request == MSHV_SET_VP_STATE) {
        if (!arg)
            return reject(EFAULT);
        struct mshv_get_set_vp_state *s = arg;
        if (s->type >= 5 || !s->buf_sz || (s->buf_sz % 4096) || (s->buf_ptr % 4096))
            return reject(EINVAL);
        return 0;
    }
    if (request == MSHV_GET_VP_CPUID_VALUES) {
        if (!arg)
            return reject(EFAULT);
        return 0;
    }
    if (request == MSHV_GET_VP_REGISTERS || request == MSHV_SET_VP_REGISTERS) {
        struct mshv_vp_registers *args = arg;
        if (!args)
            return reject(EFAULT);
        if (args->count > MSHV_VP_MAX_REGISTERS)
            return reject(EINVAL);
        if (!args->regs)
            return reject(EFAULT);
        struct mock_partition *partition = &partitions[shared_registers ? 0 : owners[fd]];
        for (unsigned i = 0; i < args->count; ++i) {
            struct hv_register_assoc *reg = &args->regs[i];
            if (request == MSHV_SET_VP_REGISTERS &&
                (reg->name == VV_EXPLICIT_SUSPEND || reg->name == VV_INTERCEPT_SUSPEND))
                return reject(EINVAL);
            assert(reg->name >= VV_RAX && reg->name <= VV_RBX);
            unsigned n = reg->name - VV_RAX;
            if (request == MSHV_SET_VP_REGISTERS)
                partition->values[indices[fd]][n] = reg->value.reg64;
            else
                reg->value.reg64 = partition->values[indices[fd]][n] ^ corrupt_read;
        }
        return 0;
    }
    if (!arg && request != MSHV_RUN_VP)
        return reject(EFAULT);
    return 0;
}

            targets |= VV_IOCTL_DEVICE;

            targets |= VV_IOCTL_PARTITION;
        if (is_vp_request(entry->request))

        assert(_IOC_TYPE(entry->request) == MSHV_IOCTL);

        }
        int expected = EFAULT;
        if (is_snp_partition_request(entry->request))
            expected = EOPNOTSUPP;
        if (entry->request == MSHV_INITIALIZE_PARTITION ||
            entry->request == MSHV_SCRUB_PARTITION || entry->request == MSHV_RUN_VP)
            expected = 0;
        assert(entry->null_errno == expected);

        for (size_t j = 0; j < sizeof(all_targets) / sizeof(all_targets[0]); ++j) {

/*
 * ML0006 - Partition teardown concurrent with another partition's VP access.
 *
 * Keep partition B and its VP zero alive in the main thread. A worker thread
 * runs 64 lifecycles of partition A, each also using VP zero. Each A cycle
 * performs a four GPR roundtrip, then alternates VP-first teardown with
 * closing both parents before a final check through the VP.
 *
 * The main thread repeatedly checks B's current four GPR values, writes a
 * new pattern and checks it again until the worker finishes. Each A cycle
 * starts only after B completes another iteration, so all cycles overlap
 * B's register access. After joining the worker, B is checked again before
 * any further write. Any failure stops both threads and fails the test.
 *
 * This runs both threads in one appliance kernel. Scheduling remains
 * nondeterministic. Descriptor closure does not prove complete hypervisor
 * resource reclamation.
 */
#include <pthread.h>
#include <sched.h>
#include <stdatomic.h>
#include <stdbool.h>
#include <string.h>

#include "lib/mshv.h"

enum {
    CONCURRENT_CYCLES = 64,
    CONCURRENT_REGISTERS = 4,
};

struct churn {
    pthread_barrier_t start;
    atomic_bool stop;
    atomic_bool done;
    atomic_uint cycles;
    atomic_uint b_iterations;
    test_result_t result;
};

static void *churn_partitions(void *arg)
{
    struct churn *w = arg;
    struct mshv_fixture a;
    test_result_t result = TEST_FAIL;
    unsigned seen = 0;
    mshv_init_context(&a);

    pthread_barrier_wait(&w->start);
    for (unsigned i = 0; i < CONCURRENT_CYCLES; ++i) {
        while (atomic_load(&w->b_iterations) == seen && !atomic_load(&w->stop))
            sched_yield();
        if (atomic_load(&w->stop))
            break;
        seen = atomic_load(&w->b_iterations);
        uint64_t seed = VV_GPR_SEED_ASCENDING ^ ((uint64_t)(i + 1) << 40);
        printf("mshv-concurrency A cycle %u/%u create with VP index=0, close %s\n",
               i + 1, (unsigned)CONCURRENT_CYCLES, i % 2 ? "parents first" : "VP first");
        if (mshv_create(&a) != TEST_PASS ||
            mshv_roundtrip(&a, CONCURRENT_REGISTERS, seed) != TEST_PASS)
            goto out;
        if (i % 2) {
            if (mshv_close(&a.device, "close A device before partition") != TEST_PASS ||
                mshv_close(&a.partition, "close A partition before VP") != TEST_PASS ||
                mshv_check_gprs(&a, CONCURRENT_REGISTERS, seed) != TEST_PASS)
                goto out;
        }
        if (mshv_cleanup(&a) != TEST_PASS)
            goto out;
        atomic_store(&w->cycles, i + 1);
    }
    result = TEST_PASS;
out:
    if (mshv_cleanup(&a) != TEST_PASS)
        result = TEST_FAIL;
    w->result = result;
    atomic_store(&w->done, true);
    return NULL;
}

static test_result_t concurrent_teardown(struct mshv_fixture *b)
{
    struct churn w = {.result = TEST_FAIL};
    pthread_t thread;
    test_result_t result = TEST_FAIL;
    uint64_t seed = VV_GPR_SEED_DESCENDING;

    printf("mshv-concurrency create persistent B with VP index=0\n");
    if (mshv_create(b) != TEST_PASS ||
        mshv_roundtrip(b, CONCURRENT_REGISTERS, seed) != TEST_PASS)
        return TEST_FAIL;
    int rc = pthread_barrier_init(&w.start, NULL, 2);
    if (rc != 0)
        TFAIL("pthread_barrier_init count=2: expected 0, actual %d (%s)", rc, strerror(rc));
    rc = pthread_create(&thread, NULL, churn_partitions, &w);
    if (rc != 0) {
        pthread_barrier_destroy(&w.start);
        TFAIL("pthread_create A worker: expected 0, actual %d (%s)", rc, strerror(rc));
    }
    pthread_barrier_wait(&w.start);
    while (!atomic_load(&w.done)) {
        unsigned iteration = atomic_load(&w.b_iterations);
        if (mshv_check_gprs(b, CONCURRENT_REGISTERS, seed) != TEST_PASS)
            goto stop;
        seed = VV_GPR_SEED_DESCENDING ^ ((uint64_t)(iteration + 1) << 32);
        if (mshv_set_gprs(b, CONCURRENT_REGISTERS, seed) != TEST_PASS ||
            mshv_check_gprs(b, CONCURRENT_REGISTERS, seed) != TEST_PASS)
            goto stop;
        atomic_store(&w.b_iterations, iteration + 1);
    }
    result = TEST_PASS;
stop:
    atomic_store(&w.stop, true);
    rc = pthread_join(thread, NULL);
    if (rc != 0) {
        printf("vv-fail %s:%d: pthread_join A worker: expected 0, actual %d (%s)\n",
               __FILE__, __LINE__, rc, strerror(rc));
        return TEST_FAIL;
    }
    pthread_barrier_destroy(&w.start);
    unsigned cycles = atomic_load(&w.cycles);
    printf("mshv-concurrency A completed %u/%u cycles, B completed %u iterations\n",
           cycles, (unsigned)CONCURRENT_CYCLES, atomic_load(&w.b_iterations));
    if (result != TEST_PASS || w.result != TEST_PASS)
        return TEST_FAIL;
    if (cycles != CONCURRENT_CYCLES)
        TFAIL("A worker cycles: expected %u, actual %u", (unsigned)CONCURRENT_CYCLES, cycles);
    printf("mshv-concurrency check B after A worker exit\n");
    if (mshv_check_gprs(b, CONCURRENT_REGISTERS, seed) != TEST_PASS)
        return TEST_FAIL;
    return mshv_roundtrip(b, CONCURRENT_REGISTERS, seed ^ VV_GPR_LOW32_MASK);
}

    if (mshv_expect_ioctl(f->vp, MSHV_SET_VP_STATE, &unaligned_sz,
                          "MSHV_SET_VP_STATE unaligned size", EINVAL) != TEST_PASS)
        return TEST_FAIL;

    /* Unaligned buffer pointer must return EINVAL */
    if (mshv_expect_ioctl(f->vp, MSHV_GET_VP_STATE, &unaligned_ptr,
                          "MSHV_GET_VP_STATE unaligned pointer", EINVAL) != TEST_PASS)
        return TEST_FAIL;
    if (mshv_expect_ioctl(f->vp, MSHV_SET_VP_STATE, &unaligned_ptr,
                          "MSHV_SET_VP_STATE unaligned pointer", EINVAL) != TEST_PASS)
        return TEST_FAIL;

    return mshv_roundtrip(f, 4, VV_GPR_SEED_VP_STATE);
}
