## ⚡ Overview

**AstroxAC** is an enterprise-grade, high-performance anti-cheat developed specifically as a native **GeyserMC Extension** (`dev.lyy.astrox.*`). 

Traditional Bukkit/Spigot anti-cheats suffer from packet translation latency, coordinate quantization, and loss of sub-tick Bedrock telemetry. AstroxAC intercepts raw Bedrock UDP packets directly at the Netty channel layer before Java translation, delivering sub-millisecond detection precision with **zero main-thread server tick lag**.

---

## 🚀 Key Architectural Advantages

```
                     TRADITIONAL SPIGOT/BUKKIT ANTI-CHEAT
Bedrock Client ──(RakNet UDP)──► [ GeyserMC ] ──(Java Translation)──► [ Spigot / Paper ] ──► [ Anti-Cheat ]
                                     │                                      │
                         - Coordinate Quantization              - Main Server Thread Delay
                         - Packet Dropping / Bundling           - Loss of Raw Bedrock Flags
                         - Velocity Interpolation               - Inaccurate Hitbox Modeling

             ═════════════════════════════════════════════════════════════════

                     ASTROX-AC GEYSER EXTENSION PIPELINE
Bedrock Client ──(RakNet UDP)──► [ Astrox Packet Interceptor ] ──► [ Geyser Engine ] ──► [ Java Server ]
                                                │
                                    - Raw PlayerAuthInputPacket
                                    - Exact InputMode & DeviceOS
                                    - Exact Sub-Tick clientTick
                                    - Zero Main-Thread CPU Overhead
```

- **Zero Main-Thread Tick Overhead**: Runs directly inside Geyser’s asynchronous Netty worker threads.
- **Bedrock-Native Kinematics**: Exact 0.60m step-height calculation, eliminating false flags on slabs and stairs.
- **Hardware InputMode Awareness**: Scales reach interaction cones dynamically ($3.05\text{m}$ for Mouse/Keyboard vs $3.85\text{m}$ for Mobile Touch).
- **Latency Backtracking**: Sub-tick raymarching against a 1000ms rolling ring buffer of historical entity positions interpolated at:
  $$t_{\text{target}} = t_{\text{now}} - \frac{\text{ping}}{2} - 50\text{ms}$$
- **Leaky-Bucket Clock**: Token-bucket accumulator ($B = 8, \tau = 50\text{ms}$) absorbing UDP packet bundling bursts without false positives.
- **Network Gateway Firewall**: Blocks malformed crasher packets (e.g. `LevelSoundEventPacket` NaN/infinite coordinates) before reaching server state machines.

## 🛠️ Installation & Setup

1. Build the project or download the latest release:
   ```bash
   mvn clean package
   ```
2. Drop `astrox-ac-2.0.0.jar` into your Geyser `extensions/` directory:
   - **Standalone**: `extensions/`
   - **Spigot / Paper**: `plugins/Geyser-Spigot/extensions/`
   - **Velocity**: `plugins/Geyser-Velocity/extensions/`
   - **BungeeCord**: `plugins/Geyser-BungeeCord/extensions/`
   - **Fabric**: `config/Geyser-Fabric/extensions/`
3. Start or restart your server / Geyser instance.
4. Customize configuration in `extensions/AstroxAC/config.yml`.

package dev.lyy.astrox;

import dev.lyy.astrox.action.ActionManager;
import dev.lyy.astrox.action.DiscordWebhookDispatcher;
import dev.lyy.astrox.action.SetbackHandler;
import dev.lyy.astrox.api.AstroxAPI;
import dev.lyy.astrox.command.AstroxCommand;
import dev.lyy.astrox.config.ConfigManager;
import dev.lyy.astrox.network.AstroxChannelInitializer;
import dev.lyy.astrox.session.BedrockPlayerSession;
import dev.lyy.astrox.session.SessionManager;
import org.geysermc.event.subscribe.Subscribe;
import org.geysermc.geyser.api.connection.GeyserConnection;
import org.geysermc.geyser.api.event.bedrock.SessionDisconnectEvent;
import org.geysermc.geyser.api.event.bedrock.SessionInitializeEvent;
import org.geysermc.geyser.api.event.bedrock.SessionJoinEvent;
import org.geysermc.geyser.api.event.lifecycle.GeyserDefineCommandsEvent;
import org.geysermc.geyser.api.event.lifecycle.GeyserPostInitializeEvent;
import org.geysermc.geyser.api.event.lifecycle.GeyserShutdownEvent;
import org.geysermc.geyser.api.extension.Extension;

public class AstroxExtension implements Extension {
    private static AstroxExtension instance;

    private ConfigManager configManager;
    private SessionManager sessionManager;
    private ActionManager actionManager;
    private SetbackHandler setbackHandler;
    private DiscordWebhookDispatcher webhookDispatcher;
    private AstroxCommand commandHandler;

    public static AstroxExtension getInstance() {
        return instance;
    }

    @Subscribe
    public void onPostInitialize(GeyserPostInitializeEvent event) {
        instance = this;
        long startTime = System.currentTimeMillis();

        this.configManager = new ConfigManager(this);
        this.configManager.loadConfig();

        this.sessionManager = new SessionManager(this);
        this.actionManager = new ActionManager(this);
        this.setbackHandler = new SetbackHandler(this);
        this.webhookDispatcher = new DiscordWebhookDispatcher(this);
        this.commandHandler = new AstroxCommand(this);

        AstroxAPI.init(this);

        // Register platform-native /astrox command bridge if running on Spigot/Paper/Purpur
        dev.lyy.astrox.command.BukkitCommandBridge.register(this, this.commandHandler);

        logger().info("§b[AstroxAC] §aEnterprise Bedrock Anti-Cheat Extension v" + description().version() + " enabled in " + (System.currentTimeMillis() - startTime) + "ms.");
    }

    @Subscribe
    public void onShutdown(GeyserShutdownEvent event) {
        if (webhookDispatcher != null) {
            webhookDispatcher.shutdown();
        }
        logger().info("§b[AstroxAC] §7Extension disabled.");
    }

    @Subscribe
    public void onSessionInitialize(SessionInitializeEvent event) {
        GeyserConnection connection = event.connection();
        if (connection != null) {
            BedrockPlayerSession session = sessionManager.createSession(connection);
            AstroxChannelInitializer.inject(this, session);
        }
    }

    @Subscribe
    public void onSessionJoin(SessionJoinEvent event) {
        GeyserConnection connection = event.connection();
        if (connection != null) {
            BedrockPlayerSession session = sessionManager.getSession(connection.xuid());
            if (session == null) {
                session = sessionManager.createSession(connection);
            }
            AstroxChannelInitializer.inject(this, session);
        }
    }

    @Subscribe
    public void onSessionDisconnect(SessionDisconnectEvent event) {
        GeyserConnection connection = event.connection();
        if (connection != null) {
            sessionManager.removeSession(connection);
        }
    }

    @Subscribe
    public void onDefineCommands(GeyserDefineCommandsEvent event) {
        if (commandHandler != null) {
            commandHandler.register(event);
        }
    }

    public ConfigManager getConfigManager() {
        return configManager;
    }

    public SessionManager getSessionManager() {
        return sessionManager;
    }

    public ActionManager getActionManager() {
        return actionManager;
    }

    public SetbackHandler getSetbackHandler() {
        return setbackHandler;
    }

    public DiscordWebhookDispatcher getWebhookDispatcher() {
        return webhookDispatcher;
    }

    public boolean isDebug() {
        return configManager != null && configManager.isDebug();
    }
}

package dev.lyy.astrox.action;

import dev.lyy.astrox.AstroxExtension;
import dev.lyy.astrox.api.CheckType;
import dev.lyy.astrox.config.ActionConfig;
import dev.lyy.astrox.config.CheckConfig;
import dev.lyy.astrox.session.BedrockPlayerSession;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;

public class ActionManager {
    private final AstroxExtension extension;
    private final Map<String, LastActionState> actionHistory = new ConcurrentHashMap<>();

    private static class LastActionState {
        double lastScore;
        long lastTimestamp;

        LastActionState(double lastScore, long lastTimestamp) {
            this.lastScore = lastScore;
            this.lastTimestamp = lastTimestamp;
        }
    }

    public ActionManager(AstroxExtension extension) {
        this.extension = extension;
    }

    public void cleanupSession(String xuid) {
        if (xuid == null) return;
        actionHistory.keySet().removeIf(key -> key.startsWith(xuid + ":"));
    }

    public void processViolation(BedrockPlayerSession session, CheckType checkType, double activeScore, double addedScore, String details) {
        CheckConfig config = extension.getConfigManager().getCheckConfig(checkType);
        if (config == null) return;

        double cumulativeScore = session.getViolationTracker(checkType).getCumulativeScore();
        long now = System.currentTimeMillis();

        // Check configured actions
        for (ActionConfig action : config.getActions().values()) {
            String key = session.getXuid() + ":" + checkType.name() + ":" + action.getName();
            LastActionState state = actionHistory.get(key);

            boolean shouldExecute = false;
            if (state == null) {
                if (activeScore >= action.getExecutionThreshold()) {
                    shouldExecute = true;
                }
            } else {
                double scoreDiff = cumulativeScore - state.lastScore;
                double timeDiffSec = (now - state.lastTimestamp) / 1000.0;
                if (scoreDiff >= action.getRepetitionThreshold() && timeDiffSec >= action.getRepetitionDelay()) {
                    shouldExecute = true;
                }
            }

            if (shouldExecute) {
                actionHistory.put(key, new LastActionState(cumulativeScore, now));
                executeAction(session, checkType, action, activeScore);
            }
        }

        // Webhook dispatch
        if (extension.getConfigManager().isWebhookEnabled() && activeScore >= extension.getConfigManager().getWebhookMinAlertVl()) {
            extension.getWebhookDispatcher().sendAlert(session, checkType, addedScore, activeScore, details);
        }
    }

    private void executeAction(BedrockPlayerSession session, CheckType checkType, ActionConfig action, double score) {
        if (action.getMessage() != null && !action.getMessage().isBlank()) {
            String formattedMsg = action.getMessage()
                .replace("%player%", session.getUsername())
                .replace("%check%", checkType.getFriendlyName())
                .replace("%score%", String.format("%.1f", score))
                .replace("%ping%", String.valueOf(session.getPing()));

            broadcastStaffAlert(formattedMsg);
        }

        if (action.getCommand() != null && !action.getCommand().isBlank()) {
            String cmd = action.getCommand()
                .replace("%player%", session.getUsername())
                .replace("%check%", checkType.getFriendlyName())
                .replace("%score%", String.format("%.1f", score))
                .replace("%ping%", String.valueOf(session.getPing()));

            extension.logger().info("[ACTION COMMAND] " + cmd);
        }
    }

    private void broadcastStaffAlert(String message) {
        // Log to console
        extension.logger().info("[ALERT] " + message.replaceAll("&[0-9a-fk-or]", ""));

        // Broadcast to players with alert permissions connected via Geyser
        String perm = extension.getConfigManager().getAlertPermission();
        for (BedrockPlayerSession s : extension.getSessionManager().getAllSessions()) {
            if (s.getConnection() != null && (perm == null || perm.isBlank() || s.getConnection().hasPermission(perm))) {
                try {
                    s.getConnection().sendMessage(message);
                } catch (Throwable ignored) {}
            }
        }
    }
}

package dev.lyy.astrox.action;

import dev.lyy.astrox.AstroxExtension;
import dev.lyy.astrox.session.BedrockPlayerSession;
import dev.lyy.astrox.util.Vector3d;
import org.cloudburstmc.math.vector.Vector3f;
import org.cloudburstmc.protocol.bedrock.packet.BedrockPacket;
import org.cloudburstmc.protocol.bedrock.packet.MovePlayerPacket;

import java.lang.reflect.Method;

/**
 * Handles packet-level rubberbanding and position setbacks directly over the Bedrock protocol.
 */
public class SetbackHandler {
    private final AstroxExtension extension;

    public SetbackHandler(AstroxExtension extension) {
        this.extension = extension;
    }

    public void executeSetback(BedrockPlayerSession session) {
        if (session == null || session.getConnection() == null) return;

        Vector3d setbackPos = session.lastValidPosition;
        if (setbackPos.lengthSquared() < 0.1) {
            setbackPos = session.previousPosition;
        }

        try {
            long entityId = session.getRuntimeEntityId() > 0 ? session.getRuntimeEntityId() : 1L;

            MovePlayerPacket movePacket = new MovePlayerPacket();
            movePacket.setRuntimeEntityId(entityId);
            movePacket.setPosition(Vector3f.from((float) setbackPos.x, (float) setbackPos.y, (float) setbackPos.z));
            movePacket.setRotation(Vector3f.from(session.pitch, session.yaw, session.headYaw));
            movePacket.setMode(MovePlayerPacket.Mode.TELEPORT);
            movePacket.setOnGround(true);
            movePacket.setRidingRuntimeEntityId(0);
            movePacket.setTick(session.clientTick);

            sendDownstreamPacket(session.getConnection(), movePacket);

            session.recordTeleport();
            session.currentPosition.set(setbackPos);

            if (extension.isDebug()) {
                extension.logger().info("[SETBACK] Executed setback for " + session.getUsername() + " to " + setbackPos);
            }
        } catch (Throwable t) {
            extension.logger().warning("Failed to dispatch setback packet to " + session.getUsername() + ": " + t.getMessage());
        }
    }

    private void sendDownstreamPacket(Object connection, BedrockPacket packet) {
        if (connection == null || packet == null) return;

        // Try direct sendDownstreamPacket or sendUpstreamPacket on GeyserSession
        try {
            Method sendDownstream = connection.getClass().getMethod("sendDownstreamPacket", BedrockPacket.class);
            sendDownstream.invoke(connection, packet);
            return;
        } catch (Throwable ignored) {}

        try {
            Method sendUpstream = connection.getClass().getMethod("sendUpstreamPacket", BedrockPacket.class);
            sendUpstream.invoke(connection, packet);
            return;
        } catch (Throwable ignored) {}

        try {
            Method getBedrockSession = connection.getClass().getMethod("getBedrockSession");
            Object bedrockSession = getBedrockSession.invoke(connection);
            if (bedrockSession != null) {
                Method sendPacket = bedrockSession.getClass().getMethod("sendPacket", BedrockPacket.class);
                sendPacket.invoke(bedrockSession, packet);
                return;
            }
        } catch (Throwable ignored) {}

        try {
            Method sendPacket = connection.getClass().getMethod("sendPacket", BedrockPacket.class);
            sendPacket.invoke(connection, packet);
        } catch (Throwable ignored) {}
    }
}

package dev.lyy.astrox.check;

import dev.lyy.astrox.AstroxExtension;
import dev.lyy.astrox.api.CheckType;
import dev.lyy.astrox.api.event.AstroxViolationEvent;
import dev.lyy.astrox.config.CheckConfig;
import dev.lyy.astrox.config.ConfigManager;
import dev.lyy.astrox.session.BedrockPlayerSession;

/**
 * Base template for all Astrox cheat detection heuristics.
 */
public abstract class AbstractCheck {
    protected final CheckType checkType;
    protected final BedrockPlayerSession session;

    public AbstractCheck(CheckType checkType, BedrockPlayerSession session) {
        this.checkType = checkType;
        this.session = session;
    }

    public CheckType getCheckType() {
        return checkType;
    }

    public BedrockPlayerSession getSession() {
        return session;
    }

    /**
     * Flags a violation. Returns TRUE if the packet should be ALLOWED, or FALSE if it should be DROPPED/CANCELLED.
     */
    public boolean flag(double score, String debugDetails) {
        AstroxExtension ext = session.getExtension();
        ConfigManager configManager = ext.getConfigManager();
        CheckConfig config = configManager.getCheckConfig(checkType);

        if (config == null || !config.isEnabled()) {
            return true;
        }

        // Join grace period
        long elapsedSinceJoin = System.currentTimeMillis() - session.getJoinTimestamp();
        if (elapsedSinceJoin < configManager.getJoinGracePeriodMs()) {
            return true;
        }

        // Max ping filter
        if (configManager.getMaxPingMs() > 0 && session.getPing() > configManager.getMaxPingMs()) {
            return true;
        }

        // Add to violation tracker
        session.getViolationTracker(checkType).addViolation(score, config);
        double activeScore = session.getViolationTracker(checkType).getActiveScore(config);

        // Fire AstroxViolationEvent
        AstroxViolationEvent event = new AstroxViolationEvent(
            session.getConnection(), checkType, score, activeScore, session.getPing(), debugDetails
        );

        if (ext.isDebug()) {
            ext.logger().info("[DEBUG] " + session.getUsername() + " flagged " + checkType.getFriendlyName() + " (Score: " + String.format("%.2f", score) + ", Active: " + String.format("%.2f", activeScore) + ") Info: " + debugDetails);
        }

        // Dispatch action manager
        ext.getActionManager().processViolation(session, checkType, activeScore, score, debugDetails);

        // Mitigation: Cancel packet or trigger setback
        boolean allowPacket = true;
        if (config.isCancelPacket() && activeScore >= config.getBlockThreshold()) {
            allowPacket = false;
        }

        if (config.isSetback() && activeScore >= config.getBlockThreshold()) {
            ext.getSetbackHandler().executeSetback(session);
        }

        return allowPacket;
    }
}

        if (newPitch < -90.05f || newPitch > 90.05f) {

        // 3. Angular Derivation Acceleration (Sudden acceleration spike > 80 deg)

        this.lastDeltaYaw = deltaYaw;

        if (angularAccel > 95.0f) {
            return flag(3.0, "Impossible Angular Acceleration: " + String.format("%.1f", angularAccel) + "°/tick");

/**
 * Validates 3D raymarching line-of-sight against sub-tick historical entity positions.
 */
public class HitboxBacktrackCheck extends AbstractCheck {
    public HitboxBacktrackCheck(BedrockPlayerSession session) {
        super(CheckType.HITBOX_BACKTRACK, session);
    }

    public boolean processAttack(BedrockPlayerSession targetSession) {
        if (targetSession == null) return true;

        long now = System.currentTimeMillis();
        // Estimated timestamp when the client perceived the target
        long clientPerceptionTime = now - (session.getPing() / 2) - 50L;

        BacktrackHistory history = targetSession.getBacktrackHistory();
        BoundingBox3D targetBox = history.getInterpolatedBox(clientPerceptionTime);
        if (targetBox == null) {
            targetBox = targetSession.getBoundingBox();
        }

        // Ray from attacker's eye
        double eyeX = session.currentPosition.x;
        double eyeY = session.currentPosition.y + session.getEyeHeight();
        double eyeZ = session.currentPosition.z;

        Ray3D lookRay = Ray3D.fromPitchYaw(eyeX, eyeY, eyeZ, session.pitch, session.yaw);

        // Expand target box by tolerance
        BoundingBox3D expandedBox = targetBox.copy().expand(0.18, 0.18, 0.18);
        double hitDist = expandedBox.calculateRayIntersection(lookRay, 6.0);

        if (hitDist < 0.0) {
            double centerDist = targetBox.getClosestPointDistance(eyeX, eyeY, eyeZ);
            if (centerDist > 1.2) {
                return flag(3.0, "Ray Missed Backtrack AABB (CenterDist=" + String.format("%.2f", centerDist) + "m, Ping=" + session.getPing() + "ms)");
            }
        }

        return true;
    }
}

/**
 * Validates combat interaction distances with device InputMode-aware tolerance (Touch vs Mouse vs Gamepad).
 */
public class ReachCheck extends AbstractCheck {
    public ReachCheck(BedrockPlayerSession session) {
        super(CheckType.REACH, session);
    }

    public boolean processAttack(BoundingBox3D targetBox, double targetX, double targetY, double targetZ) {
        if (targetBox == null) return true;

        CheckConfig config = session.getExtension().getConfigManager().getCheckConfig(checkType);
        InputMode mode = session.getInputTracker().getInputMode();

        double maxReach;
        if (mode == InputMode.TOUCH) {
            maxReach = config != null ? config.getDouble("touch-reach-max", BedrockPhysics.TOUCH_REACH_LIMIT) : BedrockPhysics.TOUCH_REACH_LIMIT;
        } else if (mode == InputMode.GAMEPAD || mode == InputMode.MOTION_CONTROLLER) {
            maxReach = config != null ? config.getDouble("controller-reach-max", BedrockPhysics.CONTROLLER_REACH_LIMIT) : BedrockPhysics.CONTROLLER_REACH_LIMIT;
        } else {
            maxReach = config != null ? config.getDouble("mouse-reach-max", BedrockPhysics.MOUSE_REACH_LIMIT) : BedrockPhysics.MOUSE_REACH_LIMIT;
        }

        double eyeX = session.currentPosition.x;
        double eyeY = session.currentPosition.y + session.getEyeHeight();
        double eyeZ = session.currentPosition.z;

        double dist = targetBox.getClosestPointDistance(eyeX, eyeY, eyeZ);

        if (dist > maxReach) {
            double score = (dist - maxReach) * 8.0;
            return flag(score, "Reach=" + String.format("%.3f", dist) + " > Max=" + String.format("%.3f", maxReach) + " (Mode=" + mode + ")");

        return true;
    }

import dev.lyy.astrox.api.CheckType;
import dev.lyy.astrox.check.AbstractCheck;
import dev.lyy.astrox.session.BedrockPlayerSession;

/**
 * Validates block breaking progression ticks and prevents instant nuker/break cheats.
 */
public class FastBreakCheck extends AbstractCheck {
    private long startBreakTime = 0L;

    public FastBreakCheck(BedrockPlayerSession session) {
        super(CheckType.FAST_BREAK, session);
    }

    public void startBreaking() {
        this.startBreakTime = System.currentTimeMillis();
    }

    public boolean completeBreaking() {
        long now = System.currentTimeMillis();
        long breakDuration = now - startBreakTime;

        // In Bedrock, instabreak blocks (torches, flowers, slime) and creative mining break in <= 50ms without START_BREAK
        // Only flag if a sustained block break was started but completed abnormally fast (< 35ms)

/**
 * Validates Bedrock horizontal kinematics, friction, sprint-jumping, and analog movement vectors.
 */
public class HorizontalSpeedCheck extends AbstractCheck {
    private double expectedSpeed = BedrockPhysics.BASE_WALK_SPEED;

    public HorizontalSpeedCheck(BedrockPlayerSession session) {
        super(CheckType.HORIZONTAL_SPEED, session);
    }

    public boolean processMovement(double dx, double dz, boolean onGround) {
        if (session.inVehicle || session.isGliding || session.isTeleportExempt()) {
            expectedSpeed = BedrockPhysics.BASE_WALK_SPEED;
            return true;
        }

        double deltaXZ = FastMath.hypot(dx, dz);

        // Base Speed with Stance Multipliers
        double baseSpeed = BedrockPhysics.BASE_WALK_SPEED;
        if (session.isSprinting) {
            baseSpeed *= BedrockPhysics.SPRINT_MULTIPLIER;
        }
        if (session.isSneaking) {
            baseSpeed *= BedrockPhysics.SNEAK_MULTIPLIER;
        }

        // Potion Modifiers (Speed Effect ID: 1, Slowness: 2)
        int speedAmp = session.getPotionAmplifier(1);
        if (speedAmp >= 0) {
            baseSpeed *= (1.0 + (speedAmp + 1) * 0.20);
        }
        int slowAmp = session.getPotionAmplifier(2);
        if (slowAmp >= 0) {
            baseSpeed *= Math.max(0.0, 1.0 - (slowAmp + 1) * 0.15);
        }

        double friction;
        double acceleration;

        if (session.isSwimming) {
            friction = BedrockPhysics.WATER_DRAG;
            acceleration = 0.025;
        } else if (onGround) {
            double slipperiness = BedrockPhysics.DEFAULT_SLIPPERINESS;
            friction = BedrockPhysics.calculateGroundFriction(slipperiness);
            acceleration = BedrockPhysics.calculateGroundAcceleration(baseSpeed, slipperiness);
        } else {
            friction = BedrockPhysics.HORIZONTAL_AIR_DRAG;
            acceleration = 0.026;
            // Jump takeoff boost
            if (session.prevOnGround && session.isSprinting) {
                acceleration += BedrockPhysics.SPRINT_JUMP_BOOST;
            }
        }

        // Knockback velocity incorporation
        double velocityBoost = session.consumeVelocity();
        expectedSpeed += velocityBoost;

        // Coordinate float precision tolerance buffer
        double coordTolerance = 0.008 + (FastMath.hypot(session.currentPosition.x, session.currentPosition.z) / 4_000_000.0);
        double maxAllowed = Math.max(expectedSpeed + coordTolerance, (expectedSpeed + acceleration) * friction + coordTolerance + 0.01);

        boolean allowed = true;
        if (deltaXZ > maxAllowed && !session.isExplosionExempt()) {
            double violationScore = Math.sqrt(deltaXZ - maxAllowed) * 8.0;
            allowed = flag(violationScore, "DeltaXZ=" + String.format("%.4f", deltaXZ) + " > Max=" + String.format("%.4f", maxAllowed) + " (Exp=" + String.format("%.4f", expectedSpeed) + ")");
        } else {
            session.lastValidPosition.set(session.currentPosition);
        }

        expectedSpeed = (expectedSpeed + acceleration) * friction;
        expectedSpeed = Math.max(expectedSpeed, 0.18);
        return allowed;
    }

public class VerticalFlightCheck extends AbstractCheck {
    private double expectedMotionY = 0.0;

    public VerticalFlightCheck(BedrockPlayerSession session) {
        super(CheckType.VERTICAL_FLIGHT, session);
    }

    public boolean processMovement(double deltaY, boolean onGround) {
        if (session.inVehicle || session.isGliding || session.isTeleportExempt()) {
            expectedMotionY = 0.0;
            return true;
        }

        boolean allowed = true;
        int jumpBoost = session.getPotionAmplifier(8); // Jump Boost ID: 8
        double maxJump = BedrockPhysics.calculateJumpVelocity(jumpBoost);

        if (onGround) {
            if (deltaY > 0.0) {
                // Bedrock allows direct 0.60m step-up without jumping on slabs/stairs
                double maxAllowedUp = Math.max(BedrockPhysics.BEDROCK_STEP_HEIGHT + 0.02, maxJump + 0.05);

                if (deltaY > maxAllowedUp && !session.isExplosionExempt()) {
                    double score = Math.abs(deltaY - maxAllowedUp) * 6.0;
                    allowed = flag(score, "Ground DeltaY=" + String.format("%.4f", deltaY) + " > Max=" + String.format("%.4f", maxAllowedUp));
                } else {
                    expectedMotionY = deltaY;
                }
            } else {
                expectedMotionY = 0.0;
            }
        } else {
            // Ground-to-Air Takeoff Transition
            if (session.prevOnGround) {
                expectedMotionY = Math.max(deltaY, maxJump);
            }

            // Air Phase Gravity
            double gravity = BedrockPhysics.GRAVITY;
            int slowFalling = session.getPotionAmplifier(28); // Slow Falling ID: 28
            if (slowFalling >= 0) {
                gravity = 0.01;
            }

            int levitation = session.getPotionAmplifier(25); // Levitation ID: 25
            if (levitation >= 0) {
                expectedMotionY = (levitation + 1) * 0.05;
            } else {
                expectedMotionY = (expectedMotionY - gravity) * BedrockPhysics.VERTICAL_DRAG;
                expectedMotionY = Math.max(expectedMotionY, -BedrockPhysics.TERMINAL_VELOCITY);
            }

            // Flag if ascending in air without jump or levitation, or hovering unnaturally
            double tolerance = 0.08;
            if (deltaY > (expectedMotionY + tolerance) && !session.isExplosionExempt()) {
                if (expectedMotionY < 0.0 && deltaY >= -0.005) {
                    double score = Math.abs(deltaY - expectedMotionY) * 4.0;
                    allowed = flag(score, "Air Hover/Fly DeltaY=" + String.format("%.4f", deltaY) + " Exp=" + String.format("%.4f", expectedMotionY));
                }
            }
        }

        return allowed;
    }
}

    }

    public boolean processAuthInput(PlayerAuthInputPacket packet) {
        double x = packet.getPosition().getX();
        double y = packet.getPosition().getY();
        double z = packet.getPosition().getZ();
        float pitch = packet.getRotation().getX();
        float yaw = packet.getRotation().getY();

        // 1. Check Finiteness (Anti-Crasher)
        if (!FastMath.isFinite(x) || !FastMath.isFinite(y) || !FastMath.isFinite(z) ||
            !FastMath.isFinite(pitch) || !FastMath.isFinite(yaw)) {

        if (Math.abs(x) > 30_000_000.0 || Math.abs(z) > 30_000_000.0 || Math.abs(y) > 4000.0) {
            return flag(20.0, "Out-of-bounds coordinates (Y=" + y + ")");
        }

        // 3. Pitch Out-of-range
        if (Math.abs(pitch) > 90.05f) {
            return flag(10.0, "Illegal Pitch: " + pitch);
        }

        // 4. Client Tick Decrement / Manipulation
        long tick = packet.getTick();
        if (session.lastClientTick > 0 && tick < session.lastClientTick && (session.lastClientTick - tick) < 100000L) {
            return flag(5.0, "ClientTick Regressed: " + tick + " < " + session.lastClientTick);

        if (flags.contains(PlayerAuthInputData.START_SPRINTING) && flags.contains(PlayerAuthInputData.START_SNEAKING)) {

    }

 * Absorbs UDP packet bundling bursts up to 8 packets without false flagging.
 */
public class LeakyBucketTimerCheck extends AbstractCheck {
    private static final int BUCKET_CAPACITY = 8;
    private static final double LEAK_RATE_MS = 50.0; // 1 token every 50ms (20 TPS)

    private double balance = 0.0;
    private long lastLeakTimestamp = 0L;

    public LeakyBucketTimerCheck(BedrockPlayerSession session) {

        this.lastLeakTimestamp = System.currentTimeMillis();
    }

        long now = System.currentTimeMillis();
        long elapsed = now - lastLeakTimestamp;
        this.lastLeakTimestamp = now;

        if (session.isTeleportExempt()) {
            this.balance = 0.0;
            return true;
        }

        // Leak tokens based on real time elapsed
        double leaked = elapsed / LEAK_RATE_MS;
        this.balance = Math.max(0.0, this.balance - leaked);

        // Add 1 token for incoming input packet
        this.balance += 1.0;

        // Check overflow
        if (this.balance > BUCKET_CAPACITY) {
            double overflow = this.balance - BUCKET_CAPACITY;
            this.balance = BUCKET_CAPACITY;
            return flag(overflow * 2.0, "Timer Burst Overflow: Balance=" + String.format("%.2f", this.balance) + " (Elapsed=" + elapsed + "ms)");
        }

        return true;
    }

import dev.lyy.astrox.util.FastMath;
import dev.lyy.astrox.util.Vector3d;

/**
 * Axis-Aligned Bounding Box (AABB) with zero-allocation geometric intersection routines.
 */
public class BoundingBox3D {
    public double minX;
    public double minY;
    public double minZ;
    public double maxX;
    public double maxY;
    public double maxZ;

    public BoundingBox3D() {
        this(0, 0, 0, 0, 0, 0);
    }

    public BoundingBox3D(double minX, double minY, double minZ, double maxX, double maxY, double maxZ) {
        this.minX = minX;
        this.minY = minY;
        this.minZ = minZ;
        this.maxX = maxX;
        this.maxY = maxY;
        this.maxZ = maxZ;
    }

    public BoundingBox3D set(double minX, double minY, double minZ, double maxX, double maxY, double maxZ) {
        this.minX = minX;
        this.minY = minY;
        this.minZ = minZ;
        this.maxX = maxX;
        this.maxY = maxY;
        this.maxZ = maxZ;
        return this;
    }

    public BoundingBox3D setFromCenterAndSize(double cx, double cy, double cz, double width, double height) {
        double halfW = width * 0.5;
        this.minX = cx - halfW;
        this.minY = cy;
        this.minZ = cz - halfW;
        this.maxX = cx + halfW;
        this.maxY = cy + height;
        this.maxZ = cz + halfW;
        return this;
    }

    public BoundingBox3D expand(double dx, double dy, double dz) {
        this.minX -= dx;
        this.minY -= dy;
        this.minZ -= dz;
        this.maxX += dx;
        this.maxY += dy;
        this.maxZ += dz;
        return this;
    }

    public double getClosestPointDistanceSquared(double px, double py, double pz) {
        double cx = FastMath.clamp(px, minX, maxX);
        double cy = FastMath.clamp(py, minY, maxY);
        double cz = FastMath.clamp(pz, minZ, maxZ);
        double dx = px - cx;
        double dy = py - cy;
        double dz = pz - cz;
        return dx * dx + dy * dy + dz * dz;
    }

    public double getClosestPointDistance(double px, double py, double pz) {
        return Math.sqrt(getClosestPointDistanceSquared(px, py, pz));
    }

    public boolean contains(double x, double y, double z) {
        return x >= minX && x <= maxX && y >= minY && y <= maxY && z >= minZ && z <= maxZ;
    }

    public boolean intersects(BoundingBox3D other) {
        return this.minX <= other.maxX && this.maxX >= other.minX &&
               this.minY <= other.maxY && this.maxY >= other.minY &&
               this.minZ <= other.maxZ && this.maxZ >= other.minZ;
    }

    /**
     * Fast Slab Ray-AABB intersection test. Returns distance or -1 if no hit.
     */
    public double calculateRayIntersection(Ray3D ray, double maxDistance) {
        double tMin = 0.0;
        double tMax = maxDistance;

        // X axis
        if (Math.abs(ray.direction.x) < FastMath.EPSILON) {
            if (ray.origin.x < minX || ray.origin.x > maxX) return -1.0;
        } else {
            double invD = 1.0 / ray.direction.x;
            double t1 = (minX - ray.origin.x) * invD;
            double t2 = (maxX - ray.origin.x) * invD;
            if (t1 > t2) { double tmp = t1; t1 = t2; t2 = tmp; }
            tMin = Math.max(tMin, t1);
            tMax = Math.min(tMax, t2);
            if (tMin > tMax) return -1.0;
        }

        // Y axis
        if (Math.abs(ray.direction.y) < FastMath.EPSILON) {
            if (ray.origin.y < minY || ray.origin.y > maxY) return -1.0;
        } else {
            double invD = 1.0 / ray.direction.y;
            double t1 = (minY - ray.origin.y) * invD;
            double t2 = (maxY - ray.origin.y) * invD;
            if (t1 > t2) { double tmp = t1; t1 = t2; t2 = tmp; }
            tMin = Math.max(tMin, t1);
            tMax = Math.min(tMax, t2);
            if (tMin > tMax) return -1.0;
        }

        // Z axis
        if (Math.abs(ray.direction.z) < FastMath.EPSILON) {
            if (ray.origin.z < minZ || ray.origin.z > maxZ) return -1.0;
        } else {
            double invD = 1.0 / ray.direction.z;
            double t1 = (minZ - ray.origin.z) * invD;
            double t2 = (maxZ - ray.origin.z) * invD;
            if (t1 > t2) { double tmp = t1; t1 = t2; t2 = tmp; }
            tMin = Math.max(tMin, t1);
            tMax = Math.min(tMax, t2);
            if (tMin > tMax) return -1.0;
        }

        if (tMin <= tMax && tMax >= 0.0) {
            return tMin >= 0.0 ? tMin : tMax;
        }
        return -1.0;
    }

    public BoundingBox3D copy() {
        return new BoundingBox3D(minX, minY, minZ, maxX, maxY, maxZ);
    }
}

package dev.lyy.astrox.collision;

import dev.lyy.astrox.util.FastMath;
import dev.lyy.astrox.util.Vector3d;

/**
 * 3D Ray Representation for raymarching, line-of-sight calculation, and reach validation.
 */
public class Ray3D {
    public final Vector3d origin = new Vector3d();
    public final Vector3d direction = new Vector3d();

    public Ray3D() {}

    public Ray3D(double ox, double oy, double oz, double dx, double dy, double dz) {
        this.origin.set(ox, oy, oz);
        this.direction.set(dx, dy, dz).normalize();
    }

    public Ray3D set(double ox, double oy, double oz, double dx, double dy, double dz) {
        this.origin.set(ox, oy, oz);
        this.direction.set(dx, dy, dz).normalize();
        return this;
    }

    public static Ray3D fromPitchYaw(double ox, double oy, double oz, float pitch, float yaw) {
        double pitchRad = pitch * FastMath.TO_RADIANS;
        double yawRad = yaw * FastMath.TO_RADIANS;

        double cosPitch = Math.cos(pitchRad);
        double dx = -Math.sin(yawRad) * cosPitch;
        double dy = -Math.sin(pitchRad);
        double dz = Math.cos(yawRad) * cosPitch;

        return new Ray3D(ox, oy, oz, dx, dy, dz);
    }

    public Vector3d getPointAtDistance(double distance) {
        return new Vector3d(
            origin.x + direction.x * distance,
            origin.y + direction.y * distance,
            origin.z + direction.z * distance
        );
    }

public final class AstroxChannelInitializer {
    private AstroxChannelInitializer() {}

    public static void inject(AstroxExtension extension, BedrockPlayerSession session) {
        GeyserConnection connection = session.getConnection();
        if (connection == null) return;

        try {
            Channel channel = extractNettyChannel(connection);
            if (channel != null && channel.pipeline() != null) {
                ChannelPipeline pipeline = channel.pipeline();
                String handlerName = "astrox_packet_interceptor";

                if (pipeline.get(handlerName) != null) {
                    pipeline.remove(handlerName);
                }

                // Add interceptor at the front of the inbound pipeline
                pipeline.addBefore(pipeline.firstContext().name(), handlerName, new AstroxPacketInterceptor(extension, session));

                if (extension.isDebug()) {
                    extension.logger().info("[NETTY] Injected AstroxPacketInterceptor into pipeline for " + session.getUsername());
                }
            }
        } catch (Throwable t) {
            extension.logger().warning("Could not inject Netty pipeline directly for " + session.getUsername() + ": " + t.getMessage());
        }
    }

    private static Channel extractNettyChannel(Object connection) {
        try {
            // Check getBedrockSession() or getUpstream() on GeyserSession
            Method getBedrockSession = connection.getClass().getMethod("getBedrockSession");
            Object bedrockSession = getBedrockSession.invoke(connection);
            if (bedrockSession != null) {
                Method getChannel = bedrockSession.getClass().getMethod("getChannel");
                return (Channel) getChannel.invoke(bedrockSession);
            }
        } catch (Throwable ignored) {
            try {
                // Alternative path via getUpstream()
                Method getUpstream = connection.getClass().getMethod("getUpstream");
                Object upstream = getUpstream.invoke(connection);
                if (upstream != null) {
                    Method getSession = upstream.getClass().getMethod("getSession");
                    Object bedrockSession = getSession.invoke(upstream);
                    if (bedrockSession != null) {
                        Method getChannel = bedrockSession.getClass().getMethod("getChannel");
                        return (Channel) getChannel.invoke(bedrockSession);
                    }
                }
            } catch (Throwable ignored2) {}
        }
        return null;

import dev.lyy.astrox.network.firewall.CrasherFirewall;
import dev.lyy.astrox.session.BedrockPlayerSession;
import dev.lyy.astrox.util.BedrockPhysics;
import io.netty.channel.ChannelHandlerContext;
import io.netty.channel.ChannelInboundHandlerAdapter;
import org.cloudburstmc.math.vector.Vector3f;
import org.cloudburstmc.protocol.bedrock.data.PlayerActionType;
import org.cloudburstmc.protocol.bedrock.data.PlayerAuthInputData;
import org.cloudburstmc.protocol.bedrock.data.entity.EntityEventType;
import org.cloudburstmc.protocol.bedrock.data.inventory.transaction.InventoryTransactionType;
import org.cloudburstmc.protocol.bedrock.packet.*;

import java.util.Set;

/**
 * Netty Inbound Packet Interceptor inspecting raw Bedrock packets at zero latency before Geyser translation.
 */
public class AstroxPacketInterceptor extends ChannelInboundHandlerAdapter {
    private final AstroxExtension extension;
    private final BedrockPlayerSession session;

    public AstroxPacketInterceptor(AstroxExtension extension, BedrockPlayerSession session) {
        this.extension = extension;
        this.session = session;
    }

    @Override
    public void channelRead(ChannelHandlerContext ctx, Object msg) throws Exception {
        if (!(msg instanceof BedrockPacket)) {
            super.channelRead(ctx, msg);
            return;
        }

        BedrockPacket packet = (BedrockPacket) msg;

        // 1. Gateway Anti-Crasher Firewall
        if (!CrasherFirewall.isSafe(packet)) {
            if (extension.isDebug()) {
                extension.logger().warning("[FIREWALL] Dropped malformed crasher packet from " + session.getUsername() + ": " + packet.getClass().getSimpleName());
            }
            return; // Drop packet
        }

        boolean allow = processPacket(packet);
        if (allow) {
            super.channelRead(ctx, msg);
        } else {
            if (extension.isDebug()) {
                extension.logger().info("[CANCELLED] Packet " + packet.getClass().getSimpleName() + " cancelled for " + session.getUsername());
            }
        }
    }

    private boolean processPacket(BedrockPacket packet) {
        if (packet instanceof PlayerAuthInputPacket) {
            return handleAuthInput((PlayerAuthInputPacket) packet);
        } else if (packet instanceof MovePlayerPacket) {
            return handleMovePlayer((MovePlayerPacket) packet);
        } else if (packet instanceof InventoryTransactionPacket) {
            return handleInventoryTransaction((InventoryTransactionPacket) packet);
        } else if (packet instanceof PlayerActionPacket) {
            return handlePlayerAction((PlayerActionPacket) packet);
        } else if (packet instanceof AnimatePacket) {
            return handleAnimate((AnimatePacket) packet);
        } else if (packet instanceof MobEquipmentPacket) {
            return handleMobEquipment((MobEquipmentPacket) packet);
        } else if (packet instanceof MobEffectPacket) {
            return handleMobEffect((MobEffectPacket) packet);
        } else if (packet instanceof EntityEventPacket) {
            return handleEntityEvent((EntityEventPacket) packet);
        } else if (packet instanceof SetEntityLinkPacket) {
            return handleSetEntityLink((SetEntityLinkPacket) packet);
        } else if (packet instanceof InteractPacket) {
            return handleInteract((InteractPacket) packet);
        }

        return true;
    }

    private boolean handleAuthInput(PlayerAuthInputPacket packet) {
        // BadPackets Check
        BadPacketsCheck badPackets = (BadPacketsCheck) session.getCheck(CheckType.BAD_PACKETS);
        if (badPackets != null && !badPackets.processAuthInput(packet)) {
            return false;
        }

        // LeakyBucket Timer Check
        LeakyBucketTimerCheck timer = (LeakyBucketTimerCheck) session.getCheck(CheckType.TIMER);
        if (timer != null && !timer.processPacket()) {
            return false;
        }

        // Device Spoof Check
        DeviceSpoofCheck deviceSpoof = (DeviceSpoofCheck) session.getCheck(CheckType.DEVICE_SPOOF);
        if (deviceSpoof != null && packet.getMotion() != null) {
            deviceSpoof.processInput(packet.getInputMode(), packet.getMotion().getX(), packet.getMotion().getY());
        }

        Vector3f pos = packet.getPosition();
        Vector3f rot = packet.getRotation();
        Set<PlayerAuthInputData> inputData = packet.getInputData();

        // Update Session State
        session.previousPosition.set(session.currentPosition);
        session.currentPosition.set(pos.getX(), pos.getY(), pos.getZ());
        if (packet.getDelta() != null) {
            session.deltaPosition.set(packet.getDelta().getX(), packet.getDelta().getY(), packet.getDelta().getZ());
        }

        session.prevPitch = session.pitch;
        session.prevYaw = session.yaw;
        session.pitch = rot.getX();
        session.yaw = rot.getY();
        session.headYaw = rot.getZ();

        session.prevOnGround = session.onGround;
        session.onGround = inputData.contains(PlayerAuthInputData.JUMP_DOWN) || (packet.getDelta() != null && packet.getDelta().getY() == 0.0f);
        session.isSprinting = inputData.contains(PlayerAuthInputData.SPRINTING) || inputData.contains(PlayerAuthInputData.START_SPRINTING);
        session.isSneaking = inputData.contains(PlayerAuthInputData.SNEAKING) || inputData.contains(PlayerAuthInputData.START_SNEAKING);
        session.isJumping = inputData.contains(PlayerAuthInputData.START_JUMPING) || inputData.contains(PlayerAuthInputData.JUMPING);
        session.isGliding = inputData.contains(PlayerAuthInputData.START_GLIDING) || session.isGliding;
        if (inputData.contains(PlayerAuthInputData.STOP_GLIDING)) session.isGliding = false;
        session.isSwimming = inputData.contains(PlayerAuthInputData.START_SWIMMING) || session.isSwimming;
        if (inputData.contains(PlayerAuthInputData.STOP_SWIMMING)) session.isSwimming = false;

        session.lastClientTick = session.clientTick;
        session.clientTick = packet.getTick();
        session.lastPacketTime = System.currentTimeMillis();

        float motionX = packet.getMotion() != null ? packet.getMotion().getX() : 0.0f;
        float motionZ = packet.getMotion() != null ? packet.getMotion().getY() : 0.0f;
        session.getInputTracker().updateInput(packet.getInputMode(), motionX, motionZ, inputData);

        // Record Backtrack Snapshot
        session.getBacktrackHistory().recordSnapshot(
            pos.getX(), pos.getY(), pos.getZ(), rot.getX(), rot.getY(),
            packet.getTick(), BedrockPhysics.PLAYER_WIDTH, session.getBoundingHeight()
        );

        double dx = session.currentPosition.x - session.previousPosition.x;
        double dy = session.currentPosition.y - session.previousPosition.y;
        double dz = session.currentPosition.z - session.previousPosition.z;

        // Execute Movement Checks
        HorizontalSpeedCheck speedCheck = (HorizontalSpeedCheck) session.getCheck(CheckType.HORIZONTAL_SPEED);
        if (speedCheck != null && !speedCheck.processMovement(dx, dz, session.onGround)) {
            return false;
        }

        VerticalFlightCheck flightCheck = (VerticalFlightCheck) session.getCheck(CheckType.VERTICAL_FLIGHT);
        if (flightCheck != null && !flightCheck.processMovement(dy, session.onGround)) {
            return false;
        }

        ElytraAerodynamicCheck elytraCheck = (ElytraAerodynamicCheck) session.getCheck(CheckType.ELYTRA_AERODYNAMIC);
        if (elytraCheck != null && !elytraCheck.processMovement(dx, dy, dz)) {
            return false;
        }

        PhaseCheck phaseCheck = (PhaseCheck) session.getCheck(CheckType.PHASE);
        if (phaseCheck != null && !phaseCheck.processMovement(session.previousPosition.x, session.previousPosition.y, session.previousPosition.z, session.currentPosition.x, session.currentPosition.y, session.currentPosition.z)) {
            return false;
        }

        BoatMovementCheck boatCheck = (BoatMovementCheck) session.getCheck(CheckType.BOAT_MOVEMENT);
        if (boatCheck != null && !boatCheck.processMovement(dx, dy, dz)) {
            return false;
        }

        return true;
    }

    private boolean handleMovePlayer(MovePlayerPacket packet) {
        if (session.getRuntimeEntityId() <= 0 && packet.getRuntimeEntityId() > 0) {
            session.setRuntimeEntityId(packet.getRuntimeEntityId());
        }

        if (packet.getMode() == MovePlayerPacket.Mode.TELEPORT || packet.getMode() == MovePlayerPacket.Mode.RESPAWN) {
            session.recordTeleport();
        }
        return true;
    }

    private boolean handleInventoryTransaction(InventoryTransactionPacket packet) {
        InventoryTransactionType type = packet.getTransactionType();

        // Combat Attack Transaction
        if (type == InventoryTransactionType.ITEM_USE_ON_ENTITY && packet.getActionType() == 1) { // 1 = Attack
            long targetRuntimeId = packet.getRuntimeEntityId();

            // Autoclicker Check (with deduplication)
            AutoclickerCheck autoclicker = (AutoclickerCheck) session.getCheck(CheckType.AUTOCLICKER);
            if (autoclicker != null && !autoclicker.processClick()) {
                return false;
            }

            // Angle Check
            AngleCheck angle = (AngleCheck) session.getCheck(CheckType.ANGLE);
            if (angle != null && !angle.processRotation(session.pitch, session.yaw)) {
                return false;
            }

            // Find Target Session with direct runtime ID mapping
            BedrockPlayerSession targetSession = extension.getSessionManager().getSessionByRuntimeId(targetRuntimeId);
            if (targetSession == null) {
                for (BedrockPlayerSession s : extension.getSessionManager().getAllSessions()) {
                    if (s.getConnection() != null && !s.equals(session)) {
                        targetSession = s;
                        break;
                    }
                }
            }

            if (targetSession != null) {
                ReachCheck reach = (ReachCheck) session.getCheck(CheckType.REACH);
                if (reach != null && !reach.processAttack(targetSession.getBoundingBox(), targetSession.currentPosition.x, targetSession.currentPosition.y, targetSession.currentPosition.z)) {
                    return false;
                }

                HitboxBacktrackCheck backtrack = (HitboxBacktrackCheck) session.getCheck(CheckType.HITBOX_BACKTRACK);
                if (backtrack != null && !backtrack.processAttack(targetSession)) {
                    return false;
                }
            }
        }

        // Block Place Transaction
        if (type == InventoryTransactionType.ITEM_USE && packet.getActionType() == 0) { // 0 = Place Block
            FastPlaceCheck fastPlace = (FastPlaceCheck) session.getCheck(CheckType.FAST_PLACE);
            if (fastPlace != null && !fastPlace.processBlockPlace()) {
                return false;
            }
        }

        return true;
    }

    private boolean handlePlayerAction(PlayerActionPacket packet) {
        if (session.getRuntimeEntityId() <= 0 && packet.getRuntimeEntityId() > 0) {
            session.setRuntimeEntityId(packet.getRuntimeEntityId());
        }

        PlayerActionType action = packet.getAction();
        if (action == PlayerActionType.START_BREAK) {
            FastBreakCheck fastBreak = (FastBreakCheck) session.getCheck(CheckType.FAST_BREAK);
            if (fastBreak != null) fastBreak.startBreaking();
        } else if (action == PlayerActionType.STOP_BREAK) {
            FastBreakCheck fastBreak = (FastBreakCheck) session.getCheck(CheckType.FAST_BREAK);
            if (fastBreak != null && !fastBreak.completeBreaking()) {
                return false;
            }
        } else if (action == PlayerActionType.START_GLIDE) {
            session.isGliding = true;
        } else if (action == PlayerActionType.STOP_GLIDE) {
            session.isGliding = false;
        } else if (action == PlayerActionType.RESPAWN) {
            session.recordTeleport();
        }
        return true;
    }

    private boolean handleAnimate(AnimatePacket packet) {
        if (packet.getAction() == AnimatePacket.Action.SWING_ARM) {
            AutoclickerCheck autoclicker = (AutoclickerCheck) session.getCheck(CheckType.AUTOCLICKER);
            if (autoclicker != null) {
                autoclicker.processClick();
            }
        }
        return true;
    }

    private boolean handleMobEquipment(MobEquipmentPacket packet) {
        if (packet.getContainerId() == 119) { // Offhand slot container
            AutoTotemCheck autoTotem = (AutoTotemCheck) session.getCheck(CheckType.AUTO_TOTEM);
            if (autoTotem != null && !autoTotem.processOffhandSwap()) {
                return false;
            }
        }
        return true;
    }

    private boolean handleMobEffect(MobEffectPacket packet) {
        if (packet.getEvent() == MobEffectPacket.Event.ADD || packet.getEvent() == MobEffectPacket.Event.MODIFY) {
            session.setPotionAmplifier(packet.getEffectId(), packet.getAmplifier());
        } else if (packet.getEvent() == MobEffectPacket.Event.REMOVE) {
            session.setPotionAmplifier(packet.getEffectId(), -1);
        }
        return true;
    }

    private boolean handleEntityEvent(EntityEventPacket packet) {
        if (packet.getType() == EntityEventType.HURT) {
            session.recordDamage();
        }
        return true;
    }

    private boolean handleSetEntityLink(SetEntityLinkPacket packet) {
        if (packet.getEntityLink() != null) {
            session.inVehicle = packet.getEntityLink().getType() == org.cloudburstmc.protocol.bedrock.data.entity.EntityLinkData.Type.RIDER;
        }
        return true;
    }

    private boolean handleInteract(InteractPacket packet) {
        if (packet.getAction() == InteractPacket.Action.OPEN_INVENTORY) {
            // Player opened inventory
        }
        return true;
    }

package dev.lyy.astrox.network.firewall;

import dev.lyy.astrox.util.FastMath;
import org.cloudburstmc.math.vector.Vector3f;
import org.cloudburstmc.protocol.bedrock.packet.BedrockPacket;
import org.cloudburstmc.protocol.bedrock.packet.CommandRequestPacket;
import org.cloudburstmc.protocol.bedrock.packet.LevelSoundEventPacket;

/**
 * Firewall filtering malformed crasher packets, NaN coordinates, and packet floods at the network gateway.
 */
public final class CrasherFirewall {
    private CrasherFirewall() {}

    public static boolean isSafe(BedrockPacket packet) {
        if (packet == null) return false;

        // LevelSoundEvent Packet Crasher Protection
        if (packet instanceof LevelSoundEventPacket) {
            LevelSoundEventPacket sound = (LevelSoundEventPacket) packet;
            Vector3f pos = sound.getPosition();
            if (pos == null || !FastMath.isFinite(pos.getX()) || !FastMath.isFinite(pos.getY()) || !FastMath.isFinite(pos.getZ())) {
                return false;
            }
            if (Math.abs(pos.getX()) > 30_000_000.0 || Math.abs(pos.getY()) > 5000.0 || Math.abs(pos.getZ()) > 30_000_000.0) {
                return false;
            }
            if (sound.getSound() == null) {
                return false;
            }
        }

        // Command Overflow Crasher Protection
        if (packet instanceof CommandRequestPacket) {
            CommandRequestPacket cmd = (CommandRequestPacket) packet;
            String command = cmd.getCommand();
            if (command != null && command.length() > 512) {
                return false;
            }
        }

        return true;
    }
}

package dev.lyy.astrox.session.data;

import dev.lyy.astrox.collision.BoundingBox3D;
import dev.lyy.astrox.util.FastMath;
import dev.lyy.astrox.util.Vector3d;

import java.util.ArrayDeque;
import java.util.Deque;

/**
 * 1000ms rolling circular history of spatial position and bounding box snapshots for latency backtracking.
 */
public class BacktrackHistory {
    private static final int MAX_SNAPSHOTS = 40; // 2000ms at 20 ticks
    private final Deque<PositionSnapshot> snapshots = new ArrayDeque<>(MAX_SNAPSHOTS);

    public static class PositionSnapshot {
        public final double x, y, z;
        public final float pitch, yaw;
        public final long timestamp;
        public final long clientTick;
        public final BoundingBox3D boundingBox;

        public PositionSnapshot(double x, double y, double z, float pitch, float yaw, long timestamp, long clientTick, double width, double height) {
            this.x = x;
            this.y = y;
            this.z = z;
            this.pitch = pitch;
            this.yaw = yaw;
            this.timestamp = timestamp;
            this.clientTick = clientTick;
            this.boundingBox = new BoundingBox3D().setFromCenterAndSize(x, y, z, width, height);
        }
    }

    public synchronized void recordSnapshot(double x, double y, double z, float pitch, float yaw, long clientTick, double width, double height) {
        long now = System.currentTimeMillis();
        snapshots.addLast(new PositionSnapshot(x, y, z, pitch, yaw, now, clientTick, width, height));

        // Expire snapshots older than 1200ms
        while (snapshots.size() > 1) {
            PositionSnapshot first = snapshots.peekFirst();
            if ((now - first.timestamp) > 1200L || snapshots.size() > MAX_SNAPSHOTS) {
                snapshots.removeFirst();
            } else {
                break;
            }
        }
    }

    /**
     * Interpolates the closest bounding box for a target at a specific past timestamp.
     */
    public synchronized BoundingBox3D getInterpolatedBox(long targetTimestamp) {
        if (snapshots.isEmpty()) return null;
        if (snapshots.size() == 1) return snapshots.peekFirst().boundingBox.copy();

        PositionSnapshot prev = null;
        for (PositionSnapshot curr : snapshots) {
            if (curr.timestamp >= targetTimestamp) {
                if (prev == null) return curr.boundingBox.copy();

                // Linear interpolation factor
                double total = curr.timestamp - prev.timestamp;
                double progress = total > 0 ? FastMath.clamp((double) (targetTimestamp - prev.timestamp) / total, 0.0, 1.0) : 0.0;

                double ix = prev.x + (curr.x - prev.x) * progress;
                double iy = prev.y + (curr.y - prev.y) * progress;
                double iz = prev.z + (curr.z - prev.z) * progress;

                double width = curr.boundingBox.maxX - curr.boundingBox.minX;
                double height = curr.boundingBox.maxY - curr.boundingBox.minY;

                return new BoundingBox3D().setFromCenterAndSize(ix, iy, iz, width, height);
            }
            prev = curr;
        }

        return snapshots.peekLast().boundingBox.copy();
    }
}

package dev.lyy.astrox.session.data;

import org.cloudburstmc.protocol.bedrock.data.InputMode;
import org.cloudburstmc.protocol.bedrock.data.PlayerAuthInputData;

import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Set;

/**
 * Thread-safe tracking of hardware input mode, analog movement curves, click entropy, and input action bitsets.
 */
public class InputTracker {
    private volatile InputMode inputMode = InputMode.MOUSE;
    private volatile float analogX = 0.0f;
    private volatile float analogZ = 0.0f;
    private volatile Set<PlayerAuthInputData> lastInputFlags = Set.of();

    // Click Statistics
    private final Deque<Long> clickTimestamps = new ArrayDeque<>();
    private final Deque<Long> attackIntervals = new ArrayDeque<>();
    private long lastAttackTime = 0L;
    private long lastClickTick = -1L;

    public synchronized void updateInput(InputMode mode, float analogX, float analogZ, Set<PlayerAuthInputData> inputFlags) {
        if (mode != null) {
            this.inputMode = mode;
        }
        this.analogX = analogX;
        this.analogZ = analogZ;
        this.lastInputFlags = inputFlags;
    }

    public synchronized boolean recordClick(long clientTick) {
        // Prevent double-counting when both AnimatePacket and InventoryTransactionPacket arrive in same tick
        if (clientTick > 0 && clientTick == lastClickTick) {
            return false;
        }
        this.lastClickTick = clientTick;

        long now = System.currentTimeMillis();
        clickTimestamps.addLast(now);

        if (lastAttackTime > 0) {
            long delta = now - lastAttackTime;
            if (delta < 1000L) {
                attackIntervals.addLast(delta);
                if (attackIntervals.size() > 40) {
                    attackIntervals.removeFirst();
                }
            }
        }
        lastAttackTime = now;

        // Expire clicks older than 1000ms
        while (!clickTimestamps.isEmpty() && (now - clickTimestamps.peekFirst()) > 1000L) {
            clickTimestamps.removeFirst();
        }
        return true;
    }

    public synchronized double getCPS() {
        long now = System.currentTimeMillis();
        while (!clickTimestamps.isEmpty() && (now - clickTimestamps.peekFirst()) > 1000L) {
            clickTimestamps.removeFirst();
        }
        return clickTimestamps.size();
    }

    public synchronized double calculateIntervalStandardDeviation() {
        if (attackIntervals.size() < 10) return 10.0;

        double sum = 0.0;
        for (long interval : attackIntervals) {
            sum += interval;
        }
        double mean = sum / attackIntervals.size();

        double varianceSum = 0.0;
        for (long interval : attackIntervals) {
            double diff = interval - mean;
            varianceSum += diff * diff;
        }
        return Math.sqrt(varianceSum / attackIntervals.size());
    }

    public InputMode getInputMode() {
        return inputMode;
    }

    public float getAnalogX() {
        return analogX;
    }

    public float getAnalogZ() {
        return analogZ;
    }

    public Set<PlayerAuthInputData> getLastInputFlags() {
        return lastInputFlags;
    }

    public boolean hasFlag(PlayerAuthInputData flag) {
        return lastInputFlags != null && lastInputFlags.contains(flag);
    }
}

package dev.lyy.astrox.session.data;

import dev.lyy.astrox.api.CheckType;
import dev.lyy.astrox.config.CheckConfig;

import java.util.ArrayDeque;
import java.util.Deque;

public class ViolationTracker {
    private final CheckType checkType;
    private final Deque<ViolationEntry> history = new ArrayDeque<>();
    private double cumulativeScore = 0.0;

    public static class ViolationEntry {
        public final double score;
        public final long timestamp;

        public ViolationEntry(double score, long timestamp) {
            this.score = score;
            this.timestamp = timestamp;
        }
    }

    public ViolationTracker(CheckType checkType) {
        this.checkType = checkType;
    }

    public synchronized void addViolation(double score, CheckConfig config) {
        long now = System.currentTimeMillis();
        history.addLast(new ViolationEntry(score, now));
        cumulativeScore += score;
        purgeExpired(now, config);
    }

    public synchronized double getActiveScore(CheckConfig config) {
        long now = System.currentTimeMillis();
        purgeExpired(now, config);
        double total = 0.0;
        for (ViolationEntry entry : history) {
            total += entry.score;
        }
        return total;
    }

    public synchronized double getCumulativeScore() {
        return cumulativeScore;
    }

    public synchronized void reset() {
        history.clear();
        cumulativeScore = 0.0;
    }

    private void purgeExpired(long now, CheckConfig config) {
        if (config == null || config.getViolationExpiration() <= 0.0) return;
        long maxAgeMs = (long) (config.getViolationExpiration() * 1000.0);

        while (!history.isEmpty()) {
            ViolationEntry first = history.peekFirst();
            if ((now - first.timestamp) >= maxAgeMs) {
                history.removeFirst();
            } else {
                break;
            }
        }
    }
}

/**

 */
public final class FastMath {
    public static final double EPSILON = 1.0E-5;
    public static final double TO_RADIANS = Math.PI / 180.0;
    public static final double TO_DEGREES = 180.0 / Math.PI;

    private FastMath() {}

    public static double hypot(double x, double z) {
        return Math.sqrt(x * x + z * z);
    }

    public static double distanceSquared(double x1, double y1, double z1, double x2, double y2, double z2) {
        double dx = x2 - x1;
        double dy = y2 - y1;
        double dz = z2 - z1;
        return dx * dx + dy * dy + dz * dz;
    }

    public static double distance(double x1, double y1, double z1, double x2, double y2, double z2) {
        return Math.sqrt(distanceSquared(x1, y1, z1, x2, y2, z2));
    }

    public static double clamp(double value, double min, double max) {
        return value < min ? min : Math.min(value, max);
    }

    public static float clamp(float value, float min, float max) {
        return value < min ? min : Math.min(value, max);
    }

    public static int clamp(int value, int min, int max) {
        return value < min ? min : Math.min(value, max);
    }

    public static double wrapDegrees(double value) {
        double angle = value % 360.0;
        if (angle >= 180.0) {
            angle -= 360.0;
        }
        if (angle < -180.0) {
            angle += 360.0;
        }
        return angle;
    }

    public static float wrapDegrees(float value) {
        float angle = value % 360.0F;
        if (angle >= 180.0F) {
            angle -= 360.0F;
        }
        if (angle < -180.0F) {
            angle += 360.0F;
        }
        return angle;
    }

    public static double angleDifference(double a, double b) {
        return Math.abs(wrapDegrees(a - b));
    }

    public static boolean isFinite(double d) {
        return !Double.isNaN(d) && !Double.isInfinite(d);
    }

    public static boolean isFinite(float f) {
        return !Float.isNaN(f) && !Float.isInfinite(f);
    }

package dev.lyy.astrox.util;

import java.util.Objects;

/**
 * Mutable high-performance 3D vector for zero-allocation mathematical transformations.
 */
public class Vector3d {
    public double x;
    public double y;
    public double z;

    public Vector3d() {
        this(0.0, 0.0, 0.0);
    }

    public Vector3d(double x, double y, double z) {
        this.x = x;
        this.y = y;
        this.z = z;
    }

    public Vector3d set(double x, double y, double z) {
        this.x = x;
        this.y = y;
        this.z = z;
        return this;
    }

    public Vector3d set(Vector3d other) {
        this.x = other.x;
        this.y = other.y;
        this.z = other.z;
        return this;
    }

    public Vector3d add(double dx, double dy, double dz) {
        this.x += dx;
        this.y += dy;
        this.z += dz;
        return this;
    }

    public Vector3d subtract(double dx, double dy, double dz) {
        this.x -= dx;
        this.y -= dy;
        this.z -= dz;
        return this;
    }

    public Vector3d multiply(double scalar) {
        this.x *= scalar;
        this.y *= scalar;
        this.z *= scalar;
        return this;
    }

    public double lengthSquared() {
        return x * x + y * y + z * z;
    }

    public double length() {
        return Math.sqrt(lengthSquared());
    }

    public double horizontalLengthSquared() {
        return x * x + z * z;
    }

    public double horizontalLength() {
        return Math.sqrt(horizontalLengthSquared());
    }

    public double distanceSquared(Vector3d other) {
        double dx = this.x - other.x;
        double dy = this.y - other.y;
        double dz = this.z - other.z;
        return dx * dx + dy * dy + dz * dz;
    }

    public double distance(Vector3d other) {
        return Math.sqrt(distanceSquared(other));
    }

    public Vector3d normalize() {
        double len = length();
        if (len > FastMath.EPSILON) {
            this.x /= len;
            this.y /= len;
            this.z /= len;
        }
        return this;
    }

    public double dot(Vector3d other) {
        return this.x * other.x + this.y * other.y + this.z * other.z;
    }

    public Vector3d copy() {
        return new Vector3d(x, y, z);
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Vector3d vector3d = (Vector3d) o;
        return Double.compare(vector3d.x, x) == 0 &&
               Double.compare(vector3d.y, y) == 0 &&
               Double.compare(vector3d.z, z) == 0;
    }

    @Override
    public int hashCode() {
        return Objects.hash(x, y, z);
    }

    @Override
    public String toString() {
        return "Vector3d{" + "x=" + x + ", y=" + y + ", z=" + z + '}';
    }
}
