## Key Features Implemented

### ✅ Phase 1: Platform Auto-Detection
- Tries BattleNet first (via decryption functions)
- Falls back to GamePass (direct memory reads)
- Logs detected platform name in console output
- Validates offsets for detected platform

### ✅ Phase 1: Address Caching
- Caches: ClientBase, BoneBase, ClientActive, LocalPlayer
- Reduces memory reads for performance
- Cache validity check before use
- Automatic invalidation on shutdown

### ✅ Phase 1: Comprehensive Logging
- `LogInfo()` - Information messages
- `LogError()` - Error messages with context
- `LogWarning()` - Warning messages
- All prefixed with `[MemoryReader]` for easy filtering

### ✅ Phase 1: Decryption Functions
- `DecryptClientInfo()` - Decrypt encrypted client info pointer (WIRED)
- `DecryptClientBase()` - Decrypt encrypted client base 16 cases (WIRED)
- `DecryptBoneBase()` - Placeholder (needs adapter implementation)
- `DecryptClientActive()` - Placeholder (needs adapter implementation)
- `DecryptCmdTextArray()` - Placeholder (needs adapter implementation)

### ✅ Phase 2: DMA Hardware Abstraction
- `DMAInterface` - Abstract base for all DMA implementations
- `PCILeechDMA` - Real hardware via LeechCore API
  - Supports PCIe FPGA devices
  - Configurable device path
  - Full read/write support
  - LeechCore library integration
- `MockDMA` - Test mode without hardware
  - Generates realistic test data
  - Perfect for development/debugging
  - No dependencies on physical hardware
- `DMAFactory` - Simple factory pattern
  - `CreateDMA(true)` → MockDMA
  - `CreateDMA(false)` → PCILeechDMA

#pragma once
#include <cstdint>
#include <string>

/**
 * Abstract DMA Interface - Platform agnostic memory read/write
 * Implementations: PCILeech, Mock (for testing)
 */
class DMAInterface {
public:
    virtual ~DMAInterface() = default;
    
    /**
     * Initialize DMA connection
     * @return true if successful
     */
    virtual bool Initialize() = 0;
    
    /**
     * Cleanup and close DMA connection
     */
    virtual void Shutdown() = 0;
    
    /**
     * Check if DMA is connected and ready
     * @return true if ready
     */
    virtual bool IsConnected() const = 0;
    
    /**
     * Read memory from target system
     * @param address Physical or virtual address to read from
     * @param buffer Output buffer
     * @param size Number of bytes to read
     * @return true if read successful
     */
    virtual bool ReadMemory(uintptr_t address, void* buffer, size_t size) = 0;
    
    /**
     * Write memory to target system
     * @param address Physical or virtual address to write to
     * @param buffer Input buffer
     * @param size Number of bytes to write
     * @return true if write successful
     */
    virtual bool WriteMemory(uintptr_t address, const void* buffer, size_t size) = 0;
    
    /**
     * Get device name/identifier
     * @return Device name string
     */
    virtual std::string GetDeviceName() const = 0;
};

```h
#pragma once

namespace bnet {

constexpr auto client_info_encrypted_slot = 0xF0294A8; // raw qword consumed by decrypt_client_info

inline uintptr_t decrypt_client_info()
{
	const uint64_t mb = base;
	uint64_t rax = mb, rbx = mb, rcx = mb, rdx = mb, rdi = mb, rsi = mb, r8 = mb, r9 = mb, r10 = mb, r11 = mb, r12 = mb, r13 = mb, r14 = mb, r15 = mb;
	rbx = memory::read<uintptr_t>(base + 0xF0294A8);
	if(!rbx)
		return rbx;
	rdx= ~memory::peb; 		//mov rdx, gs:[rax]
	rax = rbx; 		//mov rax, rbx
	rax >>= 0x18; 		//shr rax, 0x18
	rcx = 0; 		//and rcx, 0xFFFFFFFFC0000000
	rax ^= rbx; 		//xor rax, rbx
	rcx = _rotl64(rcx, 0x10); 		//rol rcx, 0x10
	rcx ^= memory::read<uintptr_t>(base + 0xDD8BF79); 		//xor rcx, [0x0000000009C71F8D]
	rbx = rax; 		//mov rbx, rax
	rbx >>= 0x30; 		//shr rbx, 0x30
	rcx = ~rcx; 		//not rcx
	rbx ^= rax; 		//xor rbx, rax
	rax = 0x233F5F4AE79533B1; 		//mov rax, 0x233F5F4AE79533B1
	rbx *= rax; 		//imul rbx, rax
	rax = 0x4FF2ED27F19D575D; 		//mov rax, 0x4FF2ED27F19D575D
	rbx -= rdx; 		//sub rbx, rdx
	rbx += rax; 		//add rbx, rax
	rbx ^= r9; 		//xor rbx, r9
	rbx *= memory::read<uintptr_t>(rcx + 0x19); 		//imul rbx, [rcx+0x19]

struct Vector3D {
    float x, y, z;

    Vector3D() : x(0.0f), y(0.0f), z(0.0f) {}
    Vector3D(float x, float y, float z) : x(x), y(y), z(z) {}

    // Vector operations
    Vector3D operator+(const Vector3D& other) const {
        return Vector3D(x + other.x, y + other.y, z + other.z);
    }

    Vector3D operator-(const Vector3D& other) const {
        return Vector3D(x - other.x, y - other.y, z - other.z);
    }

    Vector3D operator*(float scalar) const {
        return Vector3D(x * scalar, y * scalar, z * scalar);
    }

    // Distance calculation
    float Distance(const Vector3D& other) const {
        float dx = x - other.x;
        float dy = y - other.y;
        float dz = z - other.z;
        return std::sqrt(dx * dx + dy * dy + dz * dz);
    }

    // Magnitude
    float Length() const {
        return std::sqrt(x * x + y * y + z * z);
    }

    // Normalize
    Vector3D Normalized() const {
        float len = Length();
        if (len == 0.0f) return Vector3D(0, 0, 0);
        return Vector3D(x / len, y / len, z / len);
    }

    // Dot product
    float Dot(const Vector3D& other) const {
        return x * other.x + y * other.y + z * other.z;
    }
};

struct Vector2D {
    float x, y;

    Vector2D() : x(0.0f), y(0.0f) {}

    }

# Offset Discovery Guide

This guide explains how to find Call of Duty memory offsets for LuminaryDMA.

## Overview

Call of Duty stores all game data (player positions, health, etc.) in the game process's memory. To read this data via DMA, we need to find the memory addresses where this data is stored.

Offsets change with each game update, so you'll need to re-discover them periodically.

## Tools Required

1. **Cheat Engine** (Local analysis)
   - Download: https://www.cheatengine.org/
   - Used to find offsets on the game machine

2. **x64dbg or IDA Pro** (Reverse engineering)
   - Used for pattern scanning and structure analysis

3. **DMA Analysis Tools**
   - Memory access via DMA device (KMBox, etc.)

## Step 1: Find Player Base Address

### Using Cheat Engine

1. Open Cheat Engine on the **game machine**
2. Attach to `cod.exe` process
3. Start a game and get to gameplay
4. In Cheat Engine:
   - Set "Scan Type" to "All"
   - Set data type to "Float" (since positions are floats)
   - Enter your character's X coordinate (approximately)
   - Click "First Scan"
5. Move your character and scan for the new position
6. Repeat until you narrow down to the address
7. Note the address (e.g., `0x140000000 + 0x1234`)

### Typical Pattern

```
cod.exe + 0x5AB0000 (Base address of player array)
cod.exe + 0x5AB0000 + 0x100 (Offset to player 1)
cod.exe + 0x5AB0000 + 0x100 + 0x40 (Player X position)
cod.exe + 0x5AB0000 + 0x100 + 0x44 (Player Y position)
cod.exe + 0x5AB0000 + 0x100 + 0x48 (Player Z position)
```

## Step 2: Find Health Offset

1. Use Cheat Engine to find your health value (usually int32)
2. Take damage and rescan
3. Heal and rescan
4. Narrow down to exact offset
5. Note the offset relative to your base position

```
Position X: +0x40
Position Y: +0x44
Position Z: +0x48
Health: +0x5C (example)

```

   ```

);
