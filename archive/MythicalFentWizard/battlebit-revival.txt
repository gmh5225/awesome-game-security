`CLIENT-GUIDE.md`:

```md
# Joining a BattleBit Revival cluster

This is the client box. It logs you in to someone's cluster and starts the game.

---

## First time

1. Run **Start Client.bat**.
2. Fill in:
   - **Your name** - what other players see. 2-20 characters.
   - **Account password** - at least 8 characters, must contain a number.
   - **Master server** - the IP the server owner gave you.
   - **Cluster password** - only if they set one. Otherwise leave blank.
3. Press **Start**, then **Launch Client**.
4. Pick the server in the browser and join.

Your account is created the first time you log in. **Remember the password** - there is
no reset. If you lose it the owner has to delete your account, and your progress goes
with it.

---

## Your account is per cluster

Each server owner runs their own master, with its own accounts and its own progression.
The same name on a different cluster is a different account with separate progress. Two
people on the same cluster cannot share a name.

---

## The anti-cheat guard

The **Enable anti-cheat guard** checkbox is off unless you tick it.

With it on, the launcher watches your machine while you play and reports to the server
if it finds things cheats need: memory editors running, DLLs injected into the game, a
debugger attached. It also sends a hashed id of your PC so a ban can cover the machine
rather than just the name.

Worth knowing:

- Only a **hash** is sent. The raw details never leave your PC and are never stored.
- The hash is deliberately **not** tied to one server, so it is the same value on every
  cluster that sees it.
- The guard never blocks or bans anything on your machine. It only reports; the server
  decides.
- A single detection never bans you. It takes several of the same thing.

Some servers set `anticheat-require-guard`, in which case you cannot log in without
ticking it. That is the owner's choice, and it is shown in the error if you are refused.

If you have debugging or memory tools installed for unrelated reasons, say so to the
owner before enabling it - those are exactly what the guard looks for.

---

## Common problems

| message | what to do |
|---|---|
| `Wrong password for that name on this master server` | That name is taken on this cluster with a different password. Pick another, or ask the owner to clear it. |
| `Password must contain at least one number` | 8+ characters with a digit. |
| `Banned from this master server` | Talk to the owner. Bans are per cluster. |
| `requires the launcher's anti-cheat guard` | Tick the guard box. |
| `Could not reach the master server` | Wrong address, or their server is down. Check the IP. |
| `BUILDS DON'T MATCH` in the browser | You and the server are on different BattleBit versions. |

**Stuck on "Connecting to server and synchronizing"** - usually the server's problem, not
yours. Tell the owner and point them at their `TROUBLESHOOTING.md`.

**The game verified or updated its files** - re-run `patch_auth.ps1`, or the client will
not be able to join.

```

```cs
using System.Diagnostics;
using System.Runtime.InteropServices;
using System.Security.Cryptography;
using System.Security.Cryptography.X509Certificates;
using System.Text.Json;
using MasterServer;

namespace Launcher;

/// What the guard looks for, in guard.json beside the launcher. Signatures go stale, so
/// this is a file a server owner maintains rather than something baked into the build.
public sealed class GuardConfig
{
    /// Process names (without .exe, case-insensitive) that count as a detection. Ships
    /// with general-purpose memory editors and debuggers, which is what most anti-cheat
    /// flags - not because they are cheats, but because they are how cheats are built
    /// and used. Owners who develop on their gaming machine will want to prune this.
    public List<string> FlaggedProcesses { get; set; } =
    [
        "cheatengine-x86_64",
        "cheatengine-i386",
        "x64dbg",
        "x32dbg",
        "ollydbg",
        "ida64",
        "processhacker",
    ];

    /// Directories whose DLLs are expected inside the game process. Anything loaded from
    /// elsewhere AND unsigned is treated as injected.
    public List<string> TrustedModuleRoots { get; set; } =
    [
        @"C:\Windows\System32",
        @"C:\Windows\SysWOW64",
        @"C:\Windows\WinSxS",
    ];

    /// Module file names to never flag, for overlays and capture tools that legitimately
    /// inject (Discord, Steam, GPU vendors, OBS).
    public List<string> IgnoredModules { get; set; } =
    [
        "gameoverlayrenderer64.dll",
        "discordhook64.dll",
        "nvcamera64.dll",
        "obs-hook64.dll",
        "rtsshooks64.dll",
    ];

    /// SHA-256 of GameAssembly.dll that this cluster considers good. This project patches
    /// that file, so leave empty unless you have populated it with YOUR patched hash -
    /// the matching detector is off by default on the master for the same reason.
    public List<string> KnownGoodGameHashes { get; set; } = [];

    public int ScanIntervalSeconds { get; set; } = 60;

    /// Grace period after the game starts, so modules still loading are not reported.
    public int StartupGraceSeconds { get; set; } = 30;

    public static GuardConfig LoadOrCreate(string path)
    {
        try
        {
            if (File.Exists(path))
                return JsonSerializer.Deserialize<GuardConfig>(File.ReadAllText(path)) ?? new GuardConfig();
        }
        catch { }

        var fresh = new GuardConfig();
        try
        {
            File.WriteAllText(path, JsonSerializer.Serialize(
                fresh, new JsonSerializerOptions { WriteIndented = true }));
        }
        catch { }
        return fresh;
    }
}

/// Client-side half of the anti-cheat: it looks for things only visible on this machine
/// and reports them to the master server, which decides what to do. It never bans and
/// never blocks anything locally - all authority stays server-side.
///
/// This runs in user space, so anyone able to patch the launcher can remove it. It
/// raises the bar; it is not a wall. The master's RequireGuard setting is what makes
/// skipping it cost something.
public sealed class Guard
{
    [DllImport("kernel32.dll", SetLastError = true)]
    [return: MarshalAs(UnmanagedType.Bool)]
    static extern bool CheckRemoteDebuggerPresent(IntPtr hProcess,
        [MarshalAs(UnmanagedType.Bool)] ref bool isDebuggerPresent);

    readonly MasterConfig _cfg;
    readonly GuardConfig _guard;
    readonly string _session;
    readonly Action<string> _log;
    readonly Func<Process?> _gameProcess;
    CancellationTokenSource? _cts;

    /// Findings already reported WITHIN THE CURRENT SCAN, so two processes with the
    /// same name do not double-report. It is deliberately cleared every scan: the
    /// master bans on repeated reports, so a persistent cheat must keep being reported
    /// or it could never cross the threshold.
    readonly HashSet<string> _reported = [];

    public Guard(MasterConfig cfg, GuardConfig guard, string session,
                 Func<Process?> gameProcess, Action<string> log)
    {
        _cfg = cfg;
        _guard = guard;
        _session = session;
        _gameProcess = gameProcess;
        _log = log;
    }

    public void Start()
    {
        _cts = new CancellationTokenSource();
        var token = _cts.Token;
        _ = Task.Run(async () =>
        {
            try
            {
                await Task.Delay(TimeSpan.FromSeconds(_guard.StartupGraceSeconds), token);
                while (!token.IsCancellationRequested)
                {
                    await ScanOnce(token);
                    await Task.Delay(TimeSpan.FromSeconds(_guard.ScanIntervalSeconds), token);
                }
            }
            catch (OperationCanceledException) { }
            catch (Exception ex) { _log($"Guard stopped: {ex.Message}"); }
        }, token);
    }

    public void Stop()
    {
        _cts?.Cancel();
        _cts = null;
        _reported.Clear();
    }

    async Task ScanOnce(CancellationToken token)
    {
        _reported.Clear();
        foreach (var (signature, detail) in Collect())
        {
            if (token.IsCancellationRequested) return;
            if (!_reported.Add(signature + "|" + detail)) continue;   // already sent
            _log($"Guard: {signature} - {detail}");
            await Report(signature, detail, token);
        }
    }

    /// Every detector in one pass. Each yields (signature, detail); the signature must
    /// match a key in the master's anticheat.json so the owner can switch it off.
    IEnumerable<(string Signature, string Detail)> Collect()
    {
        var game = _gameProcess();

        // 1. Memory editors and debuggers running anywhere on the machine.
        foreach (var name in FlaggedProcessNames())
            yield return ("known-cheat-process", name);

        if (game is null || game.HasExited) yield break;

        // 2. A debugger attached to the game itself.
        if (IsDebuggerAttached(game))
            yield return ("debugger-attached", $"debugger on pid {game.Id}");

        // 3. DLLs inside the game process that are neither from a trusted location nor
        //    signed. Overlays are the usual false positive, hence IgnoredModules.
        foreach (var module in SuspiciousModules(game))
            yield return ("injected-module", module);

        // 4. GameAssembly.dll changed from what this cluster expects. Off unless the
        //    owner has filled in KnownGoodGameHashes, because we patch it ourselves.
        if (_guard.KnownGoodGameHashes.Count > 0 && GameAssemblyHash(game) is { } hash
            && !_guard.KnownGoodGameHashes.Contains(hash, StringComparer.OrdinalIgnoreCase))
            yield return ("game-file-modified", $"GameAssembly.dll sha256 {hash[..16]}...");
    }

    IEnumerable<string> FlaggedProcessNames()
    {
        Process[] all;
        try { all = Process.GetProcesses(); }
        catch { yield break; }

        foreach (var p in all)
        {
            string name;
            try { name = p.ProcessName; } catch { continue; }
            if (_guard.FlaggedProcesses.Any(f => string.Equals(f, name, StringComparison.OrdinalIgnoreCase)))
                yield return name;
        }
    }

    static bool IsDebuggerAttached(Process game)
    {
        try
        {
            var present = false;
            return CheckRemoteDebuggerPresent(game.Handle, ref present) && present;
        }
        catch { return false; }   // access denied is not evidence of anything
    }

    IEnumerable<string> SuspiciousModules(Process game)
    {
        // Both of these throw Win32Exception on access denied, and MainModule also
        // throws while the process is still starting - neither is evidence of anything,
        // and an unhandled throw here would kill the whole scan loop.
        string gameDir;
        ProcessModuleCollection modules;
        try
        {
            gameDir = Path.GetDirectoryName(game.MainModule?.FileName ?? "") ?? "";
            modules = game.Modules;
        }
        catch { yield break; }

        foreach (ProcessModule module in modules)
        {
            string path, file;
            try { path = module.FileName; file = Path.GetFileName(path); }
            catch { continue; }

            if (_guard.IgnoredModules.Contains(file, StringComparer.OrdinalIgnoreCase)) continue;
            if (gameDir.Length > 0 && path.StartsWith(gameDir, StringComparison.OrdinalIgnoreCase)) continue;
            if (_guard.TrustedModuleRoots.Any(r => path.StartsWith(r, StringComparison.OrdinalIgnoreCase))) continue;
            if (IsSigned(path)) continue;

            yield return $"{file} ({path})";
        }
    }

    static bool IsSigned(string path)
    {
        // CreateFromSignedFile is obsolete, but its replacement loads certificate FILES -
        // there is no modern API for pulling the Authenticode signature out of a PE,
        // which is exactly what is needed here.
#pragma warning disable SYSLIB0057
        try { X509Certificate.CreateFromSignedFile(path); return true; }
        catch { return false; }
#pragma warning restore SYSLIB0057
    }

    static string? GameAssemblyHash(Process game)
    {
        try
        {
            var dir = Path.GetDirectoryName(game.MainModule?.FileName ?? "");
            if (dir is null) return null;
            var dll = Path.Combine(dir, "GameAssembly.dll");
            if (!File.Exists(dll)) return null;
            using var stream = File.OpenRead(dll);
            return Convert.ToHexString(SHA256.HashData(stream)).ToLowerInvariant();
        }
        catch { return null; }
    }

    async Task Report(string signature, string detail, CancellationToken token)
    {
        var result = await MasterClient.ReportAsync(_cfg, _session, signature, detail, token);
        if (result.Banned)
            _log($"Guard: the master server banned this account for {signature}.");
        else if (result.Error is { Length: > 0 })
            _log($"Guard: report failed - {result.Error}");
    }
}
```

```cs
using System.Net.NetworkInformation;
using System.Security.Cryptography;
using System.Text;

namespace Launcher;

/// Builds a stable fingerprint for this machine so a ban can cover the hardware and not
/// just the account.
///
/// Two deliberate decisions:
///  - The raw components never leave this machine and are never stored anywhere. Only
///    the hash is sent, and only at login.
///  - The hash is NOT salted per master server. A salt would make the value meaningless
///    to anyone importing an exported ban list, which is the whole point of sharing one.
///    The trade-off is that it is a stable cross-server identifier, so treat it as
///    personal data: it identifies a machine across every cluster that sees it.
///
/// Hardware ids are spoofable. This slows down ban evasion; it does not prevent it.
public static class HardwareId
{
    /// Returns the hex SHA-256 of the machine fingerprint, or null if nothing stable
    /// could be read - in which case bans fall back to the account name alone.
    public static string? Compute()
    {
        var parts = new List<string>();

        // Windows installation GUID: stable across reboots, changes on reinstall.
        try
        {
            using var key = Microsoft.Win32.Registry.LocalMachine.OpenSubKey(
                @"SOFTWARE\Microsoft\Cryptography");
            if (key?.GetValue("MachineGuid") is string guid && guid.Length > 0)
                parts.Add("guid:" + guid);
        }
        catch { }

        // MAC of the first physical, non-virtual adapter. Loopback and tunnels are
        // skipped, and so are the usual virtual adapters, which otherwise make the
        // fingerprint change when Hyper-V or a VPN is installed.
        try
        {
            var mac = NetworkInterface.GetAllNetworkInterfaces()
                .Where(n => n.NetworkInterfaceType is NetworkInterfaceType.Ethernet
                                                    or NetworkInterfaceType.Wireless80211)
                .Where(n => !n.Description.Contains("virtual", StringComparison.OrdinalIgnoreCase)
                            && !n.Description.Contains("vmware", StringComparison.OrdinalIgnoreCase)
                            && !n.Description.Contains("hyper-v", StringComparison.OrdinalIgnoreCase))
                .Select(n => n.GetPhysicalAddress().ToString())
                .FirstOrDefault(a => a is { Length: > 0 });
            if (mac is { Length: > 0 }) parts.Add("mac:" + mac);
        }
        catch { }

        if (parts.Count == 0) return null;

        var hash = SHA256.HashData(Encoding.UTF8.GetBytes(string.Join("|", parts)));
        return Convert.ToHexString(hash).ToLowerInvariant();
    }
}
```

```cs
using System.Net;
using System.Net.Sockets;
using System.Text;
using MasterServer;

namespace Launcher;

/// The game binary has 127.0.0.1:29300 baked in, so a remote master is only reachable
/// by listening on loopback here and relaying onward, attaching the cluster password.
public class LocalProxy
{
    readonly MasterConfig _cfg;
    readonly Action<string> _log;
    CancellationTokenSource? _cts;

    /// Handed out by the master server at login. Attached to every relayed request so
    /// the master knows which account this player is, rather than taking a name on
    /// trust.
    public string? SessionToken { get; init; }

    public LocalProxy(MasterConfig cfg, Action<string> log)
    {
        _cfg = cfg;
        _log = log;
    }

    public void Start()
    {
        _cts = new CancellationTokenSource();
        _ = Listen(_cfg.HttpPort, RelayHttp, _cts.Token);
        _ = Listen(_cfg.RegistryPort, RelayRegistry, _cts.Token);
        _log($"Proxy listening on 127.0.0.1:{_cfg.HttpPort} and :{_cfg.RegistryPort}");
        _log($"Forwarding to {_cfg.MasterHost}");
    }

    public void Stop()
    {
        _cts?.Cancel();
        _log("Proxy stopped");
    }

    async Task Listen(int port, Func<TcpClient, Task> handler, CancellationToken ct)
    {
        TcpListener listener;
        try
        {
            listener = new TcpListener(IPAddress.Loopback, port);
            listener.Start();
        }
        catch (SocketException ex)
        {
            _log($"Cannot listen on {port}: {ex.Message}");
            return;
        }

        try
        {
            while (!ct.IsCancellationRequested)
            {
                var client = await listener.AcceptTcpClientAsync(ct);
                _ = SafeHandle(client, handler);
            }
        }
        catch (OperationCanceledException) { }
        finally { listener.Stop(); }
    }

    async Task SafeHandle(TcpClient client, Func<TcpClient, Task> handler)
    {
        try { await handler(client); }
        catch (Exception ex) { _log($"Proxy relay error: {ex.GetType().Name}: {ex.Message}"); }
        finally { client.Close(); }
    }

    // ==================== Registry port ====================

    async Task RelayRegistry(TcpClient local)
    {
        local.NoDelay = true;
        using var remote = new TcpClient();
        await remote.ConnectAsync(_cfg.MasterHost, _cfg.RegistryPort);
        remote.NoDelay = true;

        var rs = remote.GetStream();
        await rs.WriteAsync(Encoding.ASCII.GetBytes(
            $"{MasterServerHost.AuthMagic}\n{_cfg.Password}\n"));
        await rs.FlushAsync();

        var reply = new byte[8];
        int n = await rs.ReadAsync(reply);
        var text = Encoding.ASCII.GetString(reply, 0, Math.Max(n, 0));
        if (!text.StartsWith("OK", StringComparison.Ordinal))
        {
            _log("Master server rejected the cluster password.");
            return;
        }

        var ls = local.GetStream();
        await Task.WhenAny(ls.CopyToAsync(rs), rs.CopyToAsync(ls));
    }

    // ==================== HTTP port ====================

    async Task RelayHttp(TcpClient local)
    {
        local.NoDelay = true;
        var ls = local.GetStream();

        var head = await ReadHeaders(ls);
        if (head == null) return;

        int contentLength = 0;
        var kept = new List<string>();
        var lines = head.Split("\r\n", StringSplitOptions.None);

        foreach (var line in lines)
        {
            if (line.Length == 0) continue;
            if (line.StartsWith("Content-Length:", StringComparison.OrdinalIgnoreCase))
                int.TryParse(line[15..].Trim(), out contentLength);
            // Replaced below: the response is piped until close, so keep-alive must be off.
            if (line.StartsWith("Connection:", StringComparison.OrdinalIgnoreCase)) continue;
            if (line.StartsWith("X-Revival-Auth:", StringComparison.OrdinalIgnoreCase)) continue;
            if (line.StartsWith("X-Revival-Player:", StringComparison.OrdinalIgnoreCase)) continue;
            if (line.StartsWith("X-Revival-Session:", StringComparison.OrdinalIgnoreCase)) continue;
            kept.Add(line);
        }

        kept.Add("Connection: close");
        if (_cfg.Password.Length > 0)
            kept.Add($"X-Revival-Auth: {_cfg.Password}");
        if (_cfg.PlayerName.Length > 0)
            kept.Add($"X-Revival-Player: {_cfg.PlayerName}");
        if (SessionToken is { Length: > 0 })
            kept.Add($"X-Revival-Session: {SessionToken}");

        using var remote = new TcpClient();
        await remote.ConnectAsync(_cfg.MasterHost, _cfg.HttpPort);
        remote.NoDelay = true;
        var rs = remote.GetStream();

        await rs.WriteAsync(Encoding.ASCII.GetBytes(string.Join("\r\n", kept) + "\r\n\r\n"));

        if (contentLength > 0)
        {
            var body = new byte[contentLength];
            int got = 0;
            while (got < contentLength)
            {
                int r = await ls.ReadAsync(body.AsMemory(got, contentLength - got));
                if (r == 0) break;
                got += r;
            }
            await rs.WriteAsync(body.AsMemory(0, got));
        }
        await rs.FlushAsync();

        await rs.CopyToAsync(ls);
    }

    static async Task<string?> ReadHeaders(NetworkStream stream)
    {
        var sb = new StringBuilder();
        var one = new byte[1];
        while (sb.Length < 16384)
        {
            if (await stream.ReadAsync(one, 0, 1) == 0) return null;
            sb.Append((char)one[0]);
            if (sb.Length >= 4 &&
                sb[^4] == '\r' && sb[^3] == '\n' && sb[^2] == '\r' && sb[^1] == '\n')
                return sb.ToString(0, sb.Length - 4);
        }
        return sb.ToString();
    }
}
```

```cs
using System.Collections.Concurrent;
using System.Security.Cryptography;
using System.Text.Json;

namespace MasterServer;

/// Password and name rules, kept here so the launcher and the master server agree on
/// what they accept. The launcher checks these before it bothers contacting the master,
/// but the master checks them again - a client is free to skip its own validation.
public static class AccountRules
{
    public const int MinPasswordLength = 8;
    public const int MaxPasswordLength = 72;
    public const int MinNameLength = 2;
    public const int MaxNameLength = 20;

    /// Symbols allowed in a password, on top of ASCII letters and digits. Anything
    /// outside this set is rejected rather than silently stripped, so what the player
    /// types is exactly what gets hashed.
    public const string PasswordSymbols = "!@#$%^&*()-_=+[]{}:;,.?/~";

    public static bool IsAllowedPasswordChar(char c) =>
        char.IsAsciiLetterOrDigit(c) || PasswordSymbols.Contains(c);

    public static bool IsAllowedNameChar(char c) =>
        char.IsAsciiLetterOrDigit(c) || c == '_' || c == '-' || c == '.' || c == ' ';

    /// Null when the password is acceptable, otherwise the reason to show the player.
    public static string? ValidatePassword(string? password)
    {
        if (string.IsNullOrEmpty(password))
            return "Enter an account password.";
        if (password.Length < MinPasswordLength)
            return $"Password must be at least {MinPasswordLength} characters.";
        if (password.Length > MaxPasswordLength)
            return $"Password must be at most {MaxPasswordLength} characters.";
        if (!password.Any(char.IsAsciiDigit))
            return "Password must contain at least one number.";

        var bad = password.Where(c => !IsAllowedPasswordChar(c)).Distinct().ToArray();
        if (bad.Length > 0)
        {
            // Name the offending characters, but describe whitespace and control codes
            // instead of printing them, since printing tells the player nothing.
            var shown = bad.Select(c => c switch
            {
                ' ' => "space",
                '\t' => "tab",
                _ => char.IsControl(c) ? $"U+{(int)c:X4}" : c.ToString(),
            });
            return "Password cannot contain: " + string.Join(" ", shown);
        }
        return null;
    }

    public static string? ValidateName(string? name)
    {
        name = name?.Trim();
        if (string.IsNullOrEmpty(name))
            return "Enter a player name.";
        if (name.Length < MinNameLength)
            return $"Name must be at least {MinNameLength} characters.";
        if (name.Length > MaxNameLength)
            return $"Name must be at most {MaxNameLength} characters.";
        if (name.Any(c => !IsAllowedNameChar(c)))
            return "Name may only contain letters, numbers, spaces, and _ - .";
        return null;
    }

    /// The key an account is stored under: case-insensitive, so "Ethan" and "ethan" are
    /// the same account and cannot be used to impersonate one another.
    public static string NormalizeName(string name) => name.Trim().ToLowerInvariant();
}

/// A player's saved progress on this master server, in the shape the game server's
/// PlayerStats reader expects. The variable-length sections stay opaque blobs because
/// the master never needs to interpret them, only hand them back unchanged.
public sealed class ProgressRecord
{
    public uint[] Params { get; set; } = new uint[(int)ProgressField.Count];
    public byte[] ToolsProgess { get; set; } = [];
    public byte[] Achievements { get; set; } = [];
    public byte[] Selections { get; set; } = [];
    public byte[] Inventory { get; set; } = [];
    public ulong Role { get; set; }
}

public sealed class Account
{
    public string Name { get; set; } = "";
    public byte[] Salt { get; set; } = [];
    public byte[] Hash { get; set; } = [];
    public int Iterations { get; set; }
    public DateTime Created { get; set; }
    public DateTime LastSeen { get; set; }
    public bool IsBanned { get; set; }
    public ProgressRecord Progress { get; set; } = new();
}

/// Per-master-server account store. The file sits next to the master server executable,
/// so every master server keeps its own accounts and its own progress: the same player
/// name on two different masters is two unrelated accounts.
public sealed class AccountStore
{
    const int Iterations = 210_000;   // PBKDF2-HMAC-SHA256
    const int SaltSize = 16;
    const int HashSize = 32;

    readonly string _path;
    readonly ProgressionConfig _progression;
    readonly object _gate = new();
    readonly Dictionary<string, Account> _accounts = new();

    /// Short-lived tokens handed out at login. Without one, anyone could claim any
    /// account just by setting the player-name header, which would make the password
    /// pointless. In memory only - a restart simply means logging in again.
    readonly ConcurrentDictionary<string, string> _sessions = new();

    public AccountStore(string path, ProgressionConfig progression)
    {
        _path = path;
        _progression = progression;
        try
        {
            if (File.Exists(path))
            {
                var loaded = JsonSerializer.Deserialize<List<Account>>(File.ReadAllText(path));
                foreach (var a in loaded ?? [])
                    _accounts[AccountRules.NormalizeName(a.Name)] = a;
            }
        }
        catch { /* a corrupt store starts empty rather than refusing to boot */ }
    }

    public string FilePath => _path;
    public ProgressionConfig Progression => _progression;
    public int Count { get { lock (_gate) return _accounts.Count; } }

    /// Verify an existing account or create it on first use. Returns null on success,
    /// handing back a session token, or the reason to show the player.
    public string? Login(string name, string password, out string? sessionToken, out Account? account)
    {
        sessionToken = null;
        account = null;

        var nameError = AccountRules.ValidateName(name);
        if (nameError != null) return nameError;
        var passwordError = AccountRules.ValidatePassword(password);
        if (passwordError != null) return passwordError;

        name = name.Trim();
        var key = AccountRules.NormalizeName(name);

        lock (_gate)
        {
            if (_accounts.TryGetValue(key, out var existing))
            {
                var attempt = Hash(password, existing.Salt, existing.Iterations);
                if (!CryptographicOperations.FixedTimeEquals(attempt, existing.Hash))
                    return "Wrong password for that name on this master server.";
                if (existing.IsBanned)
                    return "That account is banned on this master server.";

                existing.LastSeen = DateTime.UtcNow;
                existing.Name = name;    // keep the capitalisation last logged in with
                account = existing;
            }
            else
            {
                var salt = RandomNumberGenerator.GetBytes(SaltSize);
                account = new Account
                {
                    Name = name,
                    Salt = salt,
                    Hash = Hash(password, salt, Iterations),
                    Iterations = Iterations,
                    Created = DateTime.UtcNow,
                    LastSeen = DateTime.UtcNow,
                    // A new player is an ordinary level-zero player, plus whatever head
                    // start this master server is configured to give.
                    Progress = _progression.NewPlayerProgress(),
                };
                _accounts[key] = account;
            }
            SaveLocked();
        }

        sessionToken = Convert.ToBase64String(RandomNumberGenerator.GetBytes(32));
        _sessions[sessionToken] = key;
        return null;
    }

    /// Resolve a session token handed back by the launcher to its account.
    public Account? FromSession(string? token)
    {
        if (string.IsNullOrEmpty(token) || !_sessions.TryGetValue(token, out var key))
            return null;
        lock (_gate) return _accounts.GetValueOrDefault(key);
    }

    public Account? ByName(string? name)
    {
        if (string.IsNullOrEmpty(name)) return null;
        lock (_gate) return _accounts.GetValueOrDefault(AccountRules.NormalizeName(name));
    }

    public void StoreProgress(string name, ProgressRecord progress)
    {
        lock (_gate)
        {
            if (!_accounts.TryGetValue(AccountRules.NormalizeName(name), out var a)) return;
            // Scale what was earned this round before banking it, so the server owner's
            // growth rates apply without rewriting history.
            _progression.ApplyGrowth(a.Progress, progress);
            a.Progress = progress;
            a.LastSeen = DateTime.UtcNow;
            SaveLocked();
        }
    }

    static byte[] Hash(string password, byte[] salt, int iterations) =>
        Rfc2898DeriveBytes.Pbkdf2(password, salt, iterations, HashAlgorithmName.SHA256, HashSize);

    void SaveLocked()
    {
        try
        {
            // Write beside the target and move into place, so an interrupted save cannot
            // leave everyone's progress truncated.
            var tmp = _path + ".tmp";
            File.WriteAllText(tmp, JsonSerializer.Serialize(
                _accounts.Values.ToList(), new JsonSerializerOptions { WriteIndented = true }));
            File.Move(tmp, _path, overwrite: true);
        }
        catch { }
    }
}
```

```cs
using System.Collections.Concurrent;
using System.Text.Json;

namespace MasterServer;

/// Anti-cheat settings for THIS master server, in anticheat.json beside the account
/// store. Off by default: a server owner opts in, and can turn individual detectors off
/// without disabling the rest.
public sealed class AntiCheatConfig
{
    public bool Enabled { get; set; }

    /// Refuse logins from launchers that are not running the guard. Only meaningful
    /// with Enabled; a determined cheater can patch the launcher, so this raises the
    /// bar rather than closing the door.
    public bool RequireGuard { get; set; }

    /// Per-detector toggles. A detector reporting a signature that is switched off here
    /// is recorded but never counts toward a ban.
    public Dictionary<string, bool> Detectors { get; set; } = new()
    {
        ["known-cheat-process"] = true,
        ["injected-module"] = true,
        ["debugger-attached"] = true,
        ["game-file-modified"] = false,   // see GameIntegrity below
    };

    /// How many reports of the SAME signature, from the same player, inside the window
    /// before a ban is issued. One report is never enough - a single detection can be a
    /// false positive from an overlay or a security product.
    public int ReportsToBan { get; set; } = 3;
    public int ReportWindowMinutes { get; set; } = 30;

    /// Ban the hardware id as well as the account. Hardware ids are spoofable, so this
    /// slows down ban evasion rather than preventing it.
    public bool BanByHardwareId { get; set; } = true;

    /// Imported ban lists land in a pending file for review instead of taking effect.
    /// Leave this false: a shared list is a false-positive amplifier, and one bad
    /// detector on someone else's cluster should not silently ban your players.
    public bool AutoApplyImportedBans { get; set; }

    /// Minimum confidence an imported entry must carry to be considered at all.
    public int MinimumImportConfidence { get; set; } = 80;

    public static AntiCheatConfig LoadOrCreate(string path)
    {
        try
        {
            if (File.Exists(path))
                return JsonSerializer.Deserialize<AntiCheatConfig>(File.ReadAllText(path))
                       ?? new AntiCheatConfig();
        }
        catch { }

        var fresh = new AntiCheatConfig();
        try
        {
            File.WriteAllText(path, JsonSerializer.Serialize(
                fresh, new JsonSerializerOptions { WriteIndented = true }));
        }
        catch { }
        return fresh;
    }

    public bool DetectorEnabled(string signature) =>
        Detectors.TryGetValue(signature, out var on) && on;

    public string Describe() => Enabled
        ? $"ON, {Detectors.Count(d => d.Value)}/{Detectors.Count} detectors, " +
          $"{ReportsToBan} reports in {ReportWindowMinutes}m to ban"
        : "OFF";
}

/// One ban. Carries its evidence so that a server owner importing someone else's list
/// can judge it rather than trust it blindly.
public sealed class BanEntry
{
    /// SHA-256 of the machine's hardware fingerprint, deliberately UNSALTED so that an
    /// exported list is meaningful on another cluster. The raw components never leave
    /// the player's machine and are never stored.
    public string? HardwareId { get; set; }

    public string? Account { get; set; }
    public ulong SteamId { get; set; }

    public string Signature { get; set; } = "";
    public string Reason { get; set; } = "";
    public string Evidence { get; set; } = "";
    public int Confidence { get; set; } = 100;

    /// Cluster that issued it, so an imported entry can be traced back.
    public string IssuedBy { get; set; } = "";
    public DateTime IssuedAt { get; set; } = DateTime.UtcNow;

    public bool Matches(string? hardwareId, string? account, ulong steamId) =>
        (HardwareId is { Length: > 0 } h && h == hardwareId)
        || (Account is { Length: > 0 } a && account is { Length: > 0 } b
            && string.Equals(a, b, StringComparison.OrdinalIgnoreCase))
        || (SteamId != 0 && SteamId == steamId);
}

/// Per-master-server ban list. Like accounts and progression, it lives beside the
/// executable, so every master keeps its own bans - nothing is shared unless the owner
/// explicitly exports and someone else explicitly imports.
public sealed class BanStore
{
    readonly string _path;
    readonly string _pendingPath;
    readonly string _cluster;
    readonly AntiCheatConfig _config;
    readonly object _gate = new();
    readonly List<BanEntry> _bans = [];

    public BanStore(string path, string cluster, AntiCheatConfig config)
    {
        _path = path;
        _pendingPath = Path.ChangeExtension(path, ".pending.json");
        _cluster = cluster;
        _config = config;
        try
        {
            if (File.Exists(path))
                _bans = JsonSerializer.Deserialize<List<BanEntry>>(File.ReadAllText(path)) ?? [];
        }
        catch { }
    }

    public string FilePath => _path;
    public string PendingPath => _pendingPath;
    public int Count { get { lock (_gate) return _bans.Count; } }

    public BanEntry? Find(string? hardwareId, string? account, ulong steamId = 0)
    {
        lock (_gate)
            return _bans.FirstOrDefault(b => b.Matches(hardwareId, account, steamId));
    }

    public void Ban(BanEntry entry)
    {
        if (entry.IssuedBy.Length == 0) entry.IssuedBy = _cluster;
        if (!_config.BanByHardwareId) entry.HardwareId = null;

        lock (_gate)
        {
            if (_bans.Any(b => b.Matches(entry.HardwareId, entry.Account, entry.SteamId)))
                return;
            _bans.Add(entry);
            SaveLocked(_path, _bans);
        }
    }

    public bool Unban(string accountOrHardwareId)
    {
        lock (_gate)
        {
            var removed = _bans.RemoveAll(b =>
                string.Equals(b.Account, accountOrHardwareId, StringComparison.OrdinalIgnoreCase)
                || b.HardwareId == accountOrHardwareId);
            if (removed > 0) SaveLocked(_path, _bans);
            return removed > 0;
        }
    }

    public List<BanEntry> All() { lock (_gate) return [.. _bans]; }

    /// Merge someone else's list. Entries below the configured confidence are dropped,
    /// duplicates are skipped, and unless AutoApplyImportedBans is set they are written
    /// to a pending file for the owner to review rather than taking effect.
    public (int applied, int pending, int skipped) Import(IEnumerable<BanEntry> incoming)
    {
        int applied = 0, pending = 0, skipped = 0;
        var held = new List<BanEntry>();

        lock (_gate)
        {
            foreach (var entry in incoming)
            {
                if (entry.Confidence < _config.MinimumImportConfidence
                    || _bans.Any(b => b.Matches(entry.HardwareId, entry.Account, entry.SteamId)))
                {
                    skipped++;
                    continue;
                }

                if (_config.AutoApplyImportedBans)
                {
                    _bans.Add(entry);
                    applied++;
                }
                else
                {
                    held.Add(entry);
                    pending++;
                }
            }

            if (applied > 0) SaveLocked(_path, _bans);
            if (held.Count > 0)
            {
                try
                {
                    var existing = File.Exists(_pendingPath)
                        ? JsonSerializer.Deserialize<List<BanEntry>>(File.ReadAllText(_pendingPath)) ?? []
                        : [];
                    existing.AddRange(held);
                    SaveLocked(_pendingPath, existing);
                }
                catch { }
            }
        }
        return (applied, pending, skipped);
    }

    static void SaveLocked(string path, object data)
    {
        try
        {
            var tmp = path + ".tmp";
            File.WriteAllText(tmp, JsonSerializer.Serialize(
                data, new JsonSerializerOptions { WriteIndented = true }));
            File.Move(tmp, path, overwrite: true);
        }
        catch { }
    }
}

/// Counts detector reports per player so a single hit never bans anyone. Reports older
/// than the window fall out, so unrelated detections spread over a long session do not
/// accumulate into a ban.
public sealed class DetectionTracker
{
    readonly record struct Key(string Player, string Signature);

    readonly AntiCheatConfig _config;
    readonly ConcurrentDictionary<Key, List<DateTime>> _hits = new();

    public DetectionTracker(AntiCheatConfig config) => _config = config;

    /// Records a report and says whether it has now crossed the ban threshold.
    public bool Record(string player, string signature, out int count)
    {
        var key = new Key(player, signature);
        var cutoff = DateTime.UtcNow.AddMinutes(-_config.ReportWindowMinutes);

        var times = _hits.GetOrAdd(key, _ => []);
        lock (times)
        {
            times.RemoveAll(t => t < cutoff);
            times.Add(DateTime.UtcNow);
            count = times.Count;
            return count >= _config.ReportsToBan;
        }
    }

    public void Clear(string player)
    {
        foreach (var key in _hits.Keys.Where(k => k.Player == player))
            _hits.TryRemove(key, out _);
    }
}
```

```cs
namespace MasterServer;

/// What the master server answers a login with. Lives next to the endpoint that

public sealed record LoginResult(

    string? Error = null,
    string? Name = null,
    string? Session = null,
    string? Cluster = null);

/// Outcome of a guard report. The master decides whether it counts and whether it
/// crosses the ban threshold; the launcher only relays.
public sealed record ReportResult(
    bool Ok,
    bool Counted = false,
    int Count = 0,
    bool Banned = false,
    string? Error = null);

/// The launcher's side of the master server's own (non-game) endpoints.
public static class MasterClient
{
    static readonly HttpClient Http = new() { Timeout = TimeSpan.FromSeconds(20) };

    /// Log in to a master server, creating the account if this is the first time this
    /// name has been used there. The password never goes to disk on either side: the
    /// master keeps only a PBKDF2 hash.
    public static async Task<LoginResult> LoginAsync(
        MasterConfig cfg, string name, string password,
        string? hardwareId = null, bool guard = false, CancellationToken ct = default)
    {
        var url = $"http://{cfg.MasterHost}:{cfg.HttpPort}/_revival/login";
        try
        {
            using var request = new HttpRequestMessage(HttpMethod.Post, url)
            {
                Content = JsonContent.Create(new { name, password, hardwareId, guard }),
            };
            if (cfg.Password.Length > 0)
                request.Headers.Add("X-Revival-Auth", cfg.Password);

            using var response = await Http.SendAsync(request, ct);

            // A cluster-password failure is rejected by the middleware before the login
            // endpoint runs, so it comes back as a status code rather than JSON.
            if (response.StatusCode == System.Net.HttpStatusCode.Unauthorized ||
                response.StatusCode == System.Net.HttpStatusCode.Forbidden)
                return new LoginResult(false, "Wrong cluster password for that master server.");

            var result = await response.Content.ReadFromJsonAsync<LoginResult>(cancellationToken: ct);
            return result ?? new LoginResult(false, "The master server sent an empty reply.");
        }
        catch (OperationCanceledException) when (!ct.IsCancellationRequested)
        {
            return new LoginResult(false, $"The master server at {cfg.MasterHost} did not answer in time.");
        }
        catch (Exception ex)
        {
            return new LoginResult(false, $"Could not reach the master server at {cfg.MasterHost}:{cfg.HttpPort} - {ex.Message}");
        }
    }

    /// Send one guard finding to the master server. Failures are non-fatal: a report
    /// that does not arrive means a detection is missed, not that the game should stop.
    public static async Task<ReportResult> ReportAsync(
        MasterConfig cfg, string session, string signature, string detail,
        CancellationToken ct = default)
    {
        var url = $"http://{cfg.MasterHost}:{cfg.HttpPort}/_revival/guard/report";
        try
        {
            using var request = new HttpRequestMessage(HttpMethod.Post, url)
            {
                Content = JsonContent.Create(new { session, signature, detail }),
            };
            if (cfg.Password.Length > 0)
                request.Headers.Add("X-Revival-Auth", cfg.Password);

            using var response = await Http.SendAsync(request, ct);
            if (!response.IsSuccessStatusCode)
                return new ReportResult(false, Error: $"master replied {(int)response.StatusCode}");

            return await response.Content.ReadFromJsonAsync<ReportResult>(cancellationToken: ct)
                   ?? new ReportResult(false, Error: "empty reply");
        }
        catch (Exception ex) { return new ReportResult(false, Error: ex.Message); }
    }
}
```

```cs
using System.Buffers.Binary;
using System.Collections.Concurrent;
using System.Net;
using System.Net.Sockets;
using System.Security.Cryptography;
using System.Text;
using Microsoft.AspNetCore.Builder;
using Microsoft.AspNetCore.Http;

namespace MasterServer;

public static class MasterServerHost
{
    /// Prelude a proxy sends on the registry port before relaying game bytes.
    public const string AuthMagic = "REVIVAL1";

    public static readonly ConcurrentDictionary<string, GameServerInfo> Servers = new();

    static Action<string> _log = _ => { };
    static MasterConfig _cfg = new();

    /// Established by sweeping all 256 values: only 0x01 keeps the connection alive.
    /// (The Community API's Accepted=2 belongs to a different protocol.)
    public const byte Accepted = 0x01;

    /// Diagnostic: fill the Accepted body with its own byte offsets, so any value the
    /// game echoes into its log reveals which offset that field lives at.
    public static bool ProbeOffsets;

    /// Accounts and saved progress for THIS master server. Each master keeps its own
    /// file, so the same player name on two masters is two unrelated accounts with
    /// separate progress.
    static AccountStore _accounts = null!;

    /// Session of the account logged in on this machine. When the launcher hosts the
    /// master itself there is no proxy to attach a session header - the master owns
    /// those ports already - so loopback requests without one are attributed to this
    /// account instead.
    public static string? LocalSession { get; set; }

    /// Builds this master server's account store and progression rules, once. Exposed
    /// so a launcher hosting the master can check credentials BEFORE starting it:
    /// starting the server and tearing it down on a bad password left the ports bound
    /// but no longer accepting, which hung the next game server forever on
    /// "Connecting to master server".
    public static AccountStore EnsureAccounts()
    {
        if (_accounts != null) return _accounts;
        var dataDir = Path.GetDirectoryName(Environment.ProcessPath) ?? ".";
        var progression = ProgressionConfig.LoadOrCreate(Path.Combine(dataDir, "progression.json"));
        _accounts = new AccountStore(Path.Combine(dataDir, "accounts.json"), progression);

        AntiCheat = AntiCheatConfig.LoadOrCreate(Path.Combine(dataDir, "anticheat.json"));
        Bans = new BanStore(Path.Combine(dataDir, "bans.json"), _cfg.ClusterName, AntiCheat);
        Detections = new DetectionTracker(AntiCheat);
        return _accounts;
    }

    /// Anti-cheat is per master server and entirely opt-in; with it off, none of the
    /// reporting or banning below does anything.
    public static AntiCheatConfig AntiCheat { get; private set; } = new();
    public static BanStore Bans { get; private set; } = null!;
    static DetectionTracker Detections = null!;

    public static async Task RunAsync(MasterConfig cfg, Action<string> log,
                                      CancellationToken ct = default, ServerProperties? props = null)
    {
        _cfg = cfg;
        _log = log;

        var bind = cfg.HostMaster ? IPAddress.Any : IPAddress.Loopback;
        log($"Master server starting on {bind}:{cfg.HttpPort} (HTTP) and :{cfg.RegistryPort} (registry)");
        log(cfg.Password.Length > 0 ? "Password protection: ON" : "Password protection: OFF (open cluster)");

        var accounts = EnsureAccounts();

        // server.properties is the owner-facing file, so it wins over the json files
        // it overlaps with - those keep the settings it does not expose.
        if (props != null)
        {
            props.ApplyTo(AntiCheat);
            props.ApplyTo(accounts.Progression);
            log($"Settings loaded from {props.FilePath}");
        }
        log($"Progression: {accounts.Progression.Describe()} (edit progression.json to change it)");
        log($"Accounts: {accounts.Count} known, stored in {accounts.FilePath}");
        log(cfg.RequireAccounts
            ? "Account login: REQUIRED (players log in through the launcher)"
            : "Account login: optional");
        log($"Anti-cheat: {AntiCheat.Describe()}");
        log($"Bans: {Bans.Count} on this master, stored in {Bans.FilePath}");

        var httpApp = WebApplication.CreateBuilder().Build();
        httpApp.Urls.Clear();
        httpApp.Urls.Add($"http://{bind}:{cfg.HttpPort}");
        httpApp.Use(AuthMiddleware);
        httpApp.MapGet("/_revival/cluster", GetClusterListing);
        // The default fallback pattern is {*path:nonfile}, which skips anything with a file
        // extension — that 404s the .txt/.lang localization fetches.
        httpApp.MapFallback("{*path}", HandleGameRequest);

        await Task.WhenAll(
            httpApp.RunAsync(ct),
            RunRegistryListener(bind, cfg.RegistryPort, ct));
    }

    // ==================== Auth ====================

    static async Task AuthMiddleware(HttpContext ctx, RequestDelegate next)
    {
        // Traffic from this machine is the host's own game talking directly to the
        // master it is hosting; it has no way to attach the password.
        if (_cfg.Password.Length > 0 && !IsLoopback(ctx.Connection.RemoteIpAddress))
        {
            var supplied = ctx.Request.Headers["X-Revival-Auth"].ToString();
            if (!FixedTimeEquals(supplied, _cfg.Password))
            {
                _log($"HTTP {ctx.Request.Path} REJECTED (bad password) from {ctx.Connection.RemoteIpAddress}");
                ctx.Response.StatusCode = 401;
                return;
            }
        }
        await next(ctx);
    }

    static bool IsLoopback(IPAddress? addr) =>
        addr != null && (IPAddress.IsLoopback(addr) ||
                         (addr.IsIPv4MappedToIPv6 && IPAddress.IsLoopback(addr.MapToIPv4())));

    /// Compares without leaking length or content through timing.
    static bool FixedTimeEquals(string a, string b)
    {
        var ba = Encoding.UTF8.GetBytes(a);
        var bb = Encoding.UTF8.GetBytes(b);
        return CryptographicOperations.FixedTimeEquals(
            SHA256.HashData(ba), SHA256.HashData(bb));
    }

    // ==================== HTTP ====================

    static Task GetClusterListing(HttpContext ctx)
    {
        var rows = Servers.Values.Select(s => new
        {
            s.EndPoint, s.ServerName, s.MapName, s.GameMode,
            s.Port, s.CurrentPlayers, s.MaxPlayers, s.Version,
            UptimeSeconds = (int)(DateTime.UtcNow - s.ConnectedAt).TotalSeconds,
        });
        var players = PlayerNames.Select(kv => new { SteamId = kv.Key.ToString(), Name = kv.Value });
        return ctx.Response.WriteAsJsonAsync(new { _cfg.ClusterName, Servers = rows, Players = players });
    }

    /// The master's own API, kept apart from the game's request protocol.
    static async Task HandleRevivalApi(HttpContext ctx)
    {
        var path = ctx.Request.Path.Value ?? "";
        var post = HttpMethods.IsPost(ctx.Request.Method);

        if (path.EndsWith("/login", StringComparison.OrdinalIgnoreCase) && post)
        {
            await HandleLogin(ctx);
            return;
        }
        if (path.EndsWith("/guard/report", StringComparison.OrdinalIgnoreCase) && post)
        {
            await HandleGuardReport(ctx);
            return;
        }
        if (path.EndsWith("/bans/export", StringComparison.OrdinalIgnoreCase))
        {
            await ctx.Response.WriteAsJsonAsync(new
            {
                cluster = _cfg.ClusterName,
                exportedAt = DateTime.UtcNow,
                bans = Bans.All(),
            });
            return;
        }
        if (path.EndsWith("/bans/import", StringComparison.OrdinalIgnoreCase) && post)
        {
            await HandleBanImport(ctx);
            return;
        }
        ctx.Response.StatusCode = 404;
    }

    record LoginRequest(string? Name, string? Password, string? HardwareId, bool Guard = false);
    record GuardReport(string? Session, string? Signature, string? Detail, int Confidence = 100);
    record BanImport(List<BanEntry>? Bans);

    /// Last hardware id seen for an account, so a ban can cover the machine as well as
    /// the name. Only the hash ever reaches here; the launcher never sends raw
    /// identifiers.
    static readonly ConcurrentDictionary<string, string> HardwareIds = new();

    /// The launcher's guard reporting something it found on the player's machine.
    /// Reports accumulate: one detection never bans anyone, because overlays and
    /// security products do produce false positives.
    static async Task HandleGuardReport(HttpContext ctx)
    {
        if (!AntiCheat.Enabled) { ctx.Response.StatusCode = 404; return; }

        GuardReport? req;
        try { req = await ctx.Request.ReadFromJsonAsync<GuardReport>(); }
        catch { req = null; }

        if (req?.Signature is not { Length: > 0 })
        {
            ctx.Response.StatusCode = 400;
            await ctx.Response.WriteAsJsonAsync(new { ok = false, error = "Malformed report." });
            return;
        }

        var account = _accounts.FromSession(req.Session);
        if (account is null)
        {
            ctx.Response.StatusCode = 401;
            await ctx.Response.WriteAsJsonAsync(new { ok = false, error = "Not logged in." });
            return;
        }

        // A detector the owner switched off is still logged, but never counts toward a
        // ban - that way turning one off is a policy change, not a blind spot.
        if (!AntiCheat.DetectorEnabled(req.Signature))
        {
            _log($"guard: {account.Name} reported {req.Signature} (detector off, not counted)");
            await ctx.Response.WriteAsJsonAsync(new { ok = true, counted = false });
            return;
        }

        var crossed = Detections.Record(account.Name, req.Signature, out var count);
        _log($"guard: {account.Name} {req.Signature} [{count}/{AntiCheat.ReportsToBan}] {req.Detail}");

        if (crossed)
        {
            Bans.Ban(new BanEntry
            {
                HardwareId = HardwareIds.GetValueOrDefault(account.Name),
                Account = account.Name,
                Signature = req.Signature,
                Reason = $"{req.Signature} detected {count} times in {AntiCheat.ReportWindowMinutes}m",
                Evidence = req.Detail ?? "",
                Confidence = req.Confidence,
            });
            Detections.Clear(account.Name);
            _log($"BAN issued: \"{account.Name}\" for {req.Signature}");
        }

        await ctx.Response.WriteAsJsonAsync(new { ok = true, counted = true, count, banned = crossed });
    }

    /// Merge a ban list exported by another server owner. By default entries land in a
    /// pending file rather than taking effect - see AntiCheatConfig.AutoApplyImportedBans.
    static async Task HandleBanImport(HttpContext ctx)
    {
        BanImport? req;
        try { req = await ctx.Request.ReadFromJsonAsync<BanImport>(); }
        catch { req = null; }

        if (req?.Bans is null)
        {
            ctx.Response.StatusCode = 400;
            await ctx.Response.WriteAsJsonAsync(new { ok = false, error = "Malformed ban list." });
            return;
        }

        var (applied, pending, skipped) = Bans.Import(req.Bans);
        _log($"ban import: {applied} applied, {pending} pending review, {skipped} skipped");
        await ctx.Response.WriteAsJsonAsync(new
        {
            ok = true, applied, pending, skipped,
            pendingFile = pending > 0 ? Bans.PendingPath : null,
        });
    }

    /// Called by the launcher before it starts the game: creates the account on first
    /// use, or checks the password against the existing one. Hands back a session token
    /// the launcher passes on every game request, so a name cannot simply be claimed by
    /// setting a header.
    static async Task HandleLogin(HttpContext ctx)
    {
        LoginRequest? req;
        try { req = await ctx.Request.ReadFromJsonAsync<LoginRequest>(); }
        catch { req = null; }

        if (req is null)
        {
            ctx.Response.StatusCode = 400;
            await ctx.Response.WriteAsJsonAsync(new { ok = false, error = "Malformed login request." });
            return;
        }

        // A ban is checked before the password, so a banned machine cannot probe for
        // valid account names.
        if (AntiCheat.Enabled && Bans.Find(req.HardwareId, req.Name) is { } ban)
        {
            _log($"login refused for \"{req.Name}\": banned ({ban.Signature}, by {ban.IssuedBy})");
            await ctx.Response.WriteAsJsonAsync(new
            {
                ok = false,
                error = $"Banned from this master server: {ban.Reason}",
            });
            return;
        }

        if (AntiCheat.Enabled && AntiCheat.RequireGuard && !req.Guard)
        {
            await ctx.Response.WriteAsJsonAsync(new
            {
                ok = false,
                error = "This master server requires the launcher's anti-cheat guard to be enabled.",
            });
            return;
        }

        var error = _accounts.Login(req.Name ?? "", req.Password ?? "", out var session, out var account);
        if (error != null || account is null)
        {
            // Logs that a login was refused, never which half was wrong or the password.
            _log($"login refused for \"{req.Name}\": {error}");
            await ctx.Response.WriteAsJsonAsync(new { ok = false, error });
            return;
        }

        if (req.HardwareId is { Length: > 0 })
            HardwareIds[account.Name] = req.HardwareId;

        _log($"login ok: \"{account.Name}\" ({_accounts.Count} accounts on this master)");
        await ctx.Response.WriteAsJsonAsync(new
        {
            ok = true,
            name = account.Name,
            session,
            cluster = _cfg.ClusterName,
        });
    }

    static async Task HandleGameRequest(HttpContext ctx)
    {
        // Our own control endpoints are dispatched here rather than with MapPost: the
        // catch-all fallback below wins over an explicit POST route, so a MapPost for
        // /_revival/login never ran and every login came back as a game reply. This runs
        // before the body is read, since HandleLogin parses the body itself.
        if (ctx.Request.Path.StartsWithSegments("/_revival"))
        {
            await HandleRevivalApi(ctx);
            return;
        }

        var body = await ReadBody(ctx);
        var q = ctx.Request.QueryString.HasValue ? ctx.Request.QueryString.Value : "";
        _log($"HTTP {ctx.Request.Method} {ctx.Request.Path}{q} body={body.Length}b");

        // Requests begin with the caller's steamId, so a request carrying the launcher's
        // session token ties that Steam account to a Revival account.
        ulong? caller = body.Length >= 8 ? BinaryPrimitives.ReadUInt64LittleEndian(body) : null;
        var session = ctx.Request.Headers["X-Revival-Session"].ToString();
        if (session.Length == 0 && IsLoopback(ctx.Connection.RemoteIpAddress))
            session = LocalSession ?? "";
        var loggedIn = _accounts.FromSession(session);
        if (caller is ulong id)
        {
            if (loggedIn != null)
                BindPlayer(id, loggedIn);
            else if (!_cfg.RequireAccounts)
            {
                // Open master: fall back to whatever name the launcher asked for.
                var chosen = ctx.Request.Headers["X-Revival-Player"].ToString();
                if (chosen.Length > 0) RegisterPlayerName(id, chosen);
            }
        }
        if (body.Length > 0)
        {
            _log($"  hex:   {Hex(body, 192)}{(body.Length > 192 ? "..." : "")}");
            _log($"  ascii: {Ascii(body, 192)}");
        }
        ctx.Response.ContentType = "application/octet-stream";

        // Localization is fetched as plain files, not as the binary request protocol.
        var path = ctx.Request.Path.Value ?? "";
        if (path.EndsWith(".txt", StringComparison.OrdinalIgnoreCase) ||
            path.EndsWith(".lang", StringComparison.OrdinalIgnoreCase))
        {
            await ServeLanguageFile(ctx, path);
            return;
        }

        // Every response starts with the int32 result code. Leaving it zero is Fail, which
        // is what made the client retry each endpoint forever.
        byte[] reply;
        if (ctx.Request.Path.StartsWithSegments("/Tokens"))
        {
            // The token is the client's way in, so a missing account login has to be
            // refused here - everything downstream assumes a valid token.
            if (_cfg.RequireAccounts && loggedIn is null)
            {
                _log("  no account session on the token request -> BadToken " +
                     "(launch through the Revival launcher and log in)");
                reply = BuildTokenReply(BadToken);
            }
            else
            {
                reply = BuildTokenReply();
            }
        }
        else if (ctx.Request.Path.Value?.Contains("GetServerList", StringComparison.OrdinalIgnoreCase) == true)
        {
            reply = BuildServerListReply();
        }
        else if (ctx.Request.Path.Value?.Contains("GetPingServers", StringComparison.OrdinalIgnoreCase) == true)
        {
            reply = BuildPingServersReply();
        }
        else if (ctx.Request.Path.Value?.Contains("GetServerHandshakeToken", StringComparison.OrdinalIgnoreCase) == true)
        {
            reply = BuildServerKeyReply(body);
        }
        else
        {
            reply = new byte[ReplyBytes];
            BinaryPrimitives.WriteInt32LittleEndian(reply, Success);
        }

        await ctx.Response.Body.WriteAsync(reply);
        _log($"  <- replied {reply.Length}b: {Hex(reply, 160)}");
    }

    /// Response codes are shared with the request enum; Fail=0 was what made the client
    /// report "Database is unavailable now."
    public const byte Fail = 0;
    public const byte Success = 1;
    public const byte BadToken = 3;

    /// int32 result code, then mServerToken, mServerTokenAliveUntilMs, mServerTokenBuild.
    /// Measured, not deduced: a 25-byte reply with a 1-byte code sends the client back to
    /// looping on GetToken, while this 28-byte form carries it through the whole flow.
    static byte[] BuildTokenReply(byte result = Success)
    {
        // Proven from the client's own log: it printed the token as 0x4956414C01000000,
        // which is this reply read as a ulong at offset 1 — so the result code is ONE
        // byte. Writing it as int32 shifts aliveUntil and build into garbage, which is
        // why ServerBuildID came back changing between requests.
        // Offsets read back out of the client's own log: it printed our token verbatim
        // from offset 1, printed "alive for" as a denormal float matching bytes 10-13,
        // and printed ServerBuildID=417 matching bytes 14+. So lifetime is a FLOAT at 10
        // (not the int64 the field name suggests) and build is a ulong at 14.
        var p = new byte[64];
        p[0] = result;
        if (result != Success)
            return p;   // no token to hand out; the client reads the code and stops
        BinaryPrimitives.WriteUInt64LittleEndian(p.AsSpan(1), IssuedToken);
        BinaryPrimitives.WriteSingleLittleEndian(p.AsSpan(9), TokenLifetimeSeconds);
        BinaryPrimitives.WriteUInt64LittleEndian(p.AsSpan(13), ServerBuild);
        return p;
    }

    /// Reported both as the token's build and on every server list entry, so the two
    /// always agree.
    public const ulong ServerBuild = 0;

    /// How long the client should consider its token valid. A near-zero value here is
    /// what produced "Our token expired" immediately after every fetch.
    public const float TokenLifetimeSeconds = 86400f;

    public const ulong IssuedToken = 0x5245564956414C01;

    /// The game ships English.lang next to the executable but still fetches localization
    /// over HTTP, so serve the local file rather than inventing one.
    static async Task ServeLanguageFile(HttpContext ctx, string path)
    {
        ctx.Response.ContentType = "text/plain; charset=utf-8";
        var name = Path.GetFileName(path);

        if (name.Equals("Languages.txt", StringComparison.OrdinalIgnoreCase))
        {
            var names = Directory.Exists(GameRoot)
                ? Directory.GetFiles(GameRoot, "*.lang").Select(Path.GetFileNameWithoutExtension).ToList()
                : ["English"];
            var body = string.Join("\n", names!);
            _log($"  <- Languages.txt: {body.Replace("\n", ", ")}");
            await ctx.Response.WriteAsync(body);
            return;
        }

        var file = Path.Combine(GameRoot ?? ".", name);
        if (File.Exists(file))
        {
            _log($"  <- {name} ({new FileInfo(file).Length}b from disk)");
            await ctx.Response.SendFileAsync(file);
        }
        else
        {
            _log($"  <- {name} NOT FOUND at {file}");
            ctx.Response.StatusCode = 404;
        }
    }

    /// Walks up from the running executable to the folder holding BattleBit.exe.
    static readonly string? GameRoot = FindGameRoot();

    static string? FindGameRoot()
    {
        var dir = AppContext.BaseDirectory;
        for (int i = 0; i < 8 && dir != null; i++)
        {
            if (File.Exists(Path.Combine(dir, "BattleBit.exe"))) return dir;
            dir = Path.GetDirectoryName(dir.TrimEnd(Path.DirectorySeparatorChar));
        }
        return null;
    }

    /// The client takes this as (DateTime, List&lt;entry&gt;).
    static byte[] BuildServerListReply()
    {
        var rows = Servers.Values.ToList();
        var ms = new MemoryStream();
        var w = new BinaryWriter(ms);
        // The code is a single byte: the client reads the token at offset 1, so writing it
        // as int32 shifts the whole body by three bytes.
        w.Write(Success);               // byte result
        w.Write(DateTime.UtcNow.Ticks); // DateTime is serialised as ticks
        w.Write(rows.Count);            // entry count
        foreach (var s in rows)
            WriteServerEntry(w, s);
        return ms.ToArray();
    }

    /// The client calls this as GetPublicKeyForGameServer(IPEndPoint, ...) before joining;
    /// the request carries steamId, token, then the server's IP and port. The reply is the
    /// key struct: two ulongs plus two ints.
    static byte[] BuildServerKeyReply(byte[] request)
    {
        ulong lo = 0, hi = 0;
        if (request.Length >= 22)
        {
            var ip = new IPAddress(BinaryPrimitives.ReadUInt32LittleEndian(request.AsSpan(16)));
            ushort port = BinaryPrimitives.ReadUInt16LittleEndian(request.AsSpan(20));
            // Fall back to the sole registered server: the advertised port may be the
            // capture port rather than the server's real one.
            var match = Servers.Values.FirstOrDefault(s => s.Port == port)
                        ?? (Servers.Count == 1 ? Servers.Values.First() : null);
            if (match != null) { lo = match.KeyLow; hi = match.KeyHigh; }
            _log($"  key request for {ip}:{port} -> {(match != null ? "matched" : "NO SERVER")}");
        }

        // Layout taken from the client's parser (<GetPublicKeyForGameServer>b__0):
        // it checks the outer result code == 1, then reads a SECOND status byte off the
        // stream which must also be 1, and only then reads the two key ulongs plus a
        // trailing byte. Omitting that status byte makes it read the first key byte
        // instead, fail the == 1 test, hand back a zeroed key, and never cache it —
        // which surfaces as "NoResponse" because the join then silently times out.
        var p = new byte[64];
        p[0] = Success;   // outer result code
        p[1] = 1;         // inner status the callback requires
        BinaryPrimitives.WriteUInt64LittleEndian(p.AsSpan(2), lo);
        BinaryPrimitives.WriteUInt64LittleEndian(p.AsSpan(10), hi);
        p[18] = 0;        // trailing byte read into the struct's last field
        return p;
    }

    /// RequestPingServers hands the client a Dictionary&lt;Region, List&lt;IPAddress&gt;&gt;.
    /// An empty one makes it throw IndexOutOfRange picking the first address for its own
    /// region, and that exception lands mid-startup, taking the localization fetch with
    /// it — so every region gets an entry.
    static byte[] BuildPingServersReply()
    {
        // Format from the client's parser (<RequestPingServers>b__0): after the result
        // code it loops WHILE at least one byte remains, reading
        //   byte region, byte count, then count x uint32 addresses.
        // There is no outer entry count, so the body must END exactly after the last
        // entry: any trailing padding is re-read as region 0 / count 0 and produces
        // "in ping servers: Developer_Server added twice", then IndexOutOfRange.
        // Only one entry: the client also indexes ping servers BY ADDRESS, so repeating
        // 127.0.0.1 across regions throws "An item with the same key has already been
        // added. Key: 127.0.0.1".
        var region = (byte)(Servers.Values.FirstOrDefault()?.Region ?? DefaultRegion);
        var ms = new MemoryStream();
        var w = new BinaryWriter(ms);
        w.Write(Success);
        w.Write(region);                                         // key
        w.Write((byte)1);                                        // one address
        w.Write(BinaryPrimitives.ReadUInt32LittleEndian(IPAddress.Loopback.GetAddressBytes()));
        return ms.ToArray();
    }

    /// Europe_Central, from the region enum in the dump.
    const byte DefaultRegion = 10;

    // ==================== Player names ====================

    /// steamId -> the name this player is listed under on the cluster.
    static readonly ConcurrentDictionary<ulong, string> PlayerNames = new();

    /// steamId -> the Revival account that logged in from it. Account names are unique
    /// per master server, so these never need the numeric-prefix treatment below: a
    /// second player cannot take a name without the first player's password.
    static readonly ConcurrentDictionary<ulong, string> PlayerAccounts = new();

    static void BindPlayer(ulong steamId, Account account)
    {
        if (PlayerAccounts.TryGetValue(steamId, out var current) && current == account.Name)
            return;
        PlayerAccounts[steamId] = account.Name;
        PlayerNames[steamId] = account.Name;
        _log($"account bound: {steamId} -> \"{account.Name}\"");
    }

    static Account? AccountFor(ulong steamId) =>
        PlayerAccounts.TryGetValue(steamId, out var name) ? _accounts.ByName(name) : null;

    /// Registers the launcher-chosen name for a player. Two people using the same name
    /// are told apart by a numeric prefix ("2ethan", "3ethan") rather than being
    /// rejected, so nobody is blocked from joining by someone else's choice.
    public static string RegisterPlayerName(ulong steamId, string requested)
    {
        requested = requested.Trim();
        if (requested.Length == 0) return PlayerNames.TryGetValue(steamId, out var cur) ? cur : "";

        if (PlayerNames.TryGetValue(steamId, out var existing) &&
            StripPrefix(existing) == requested)
            return existing;   // same player reconnecting, keep their established name

        var name = requested;
        for (int n = 2; PlayerNames.Any(kv => kv.Key != steamId && kv.Value == name); n++)
            name = $"{n}{requested}";

        PlayerNames[steamId] = name;
        _log($"player name: {steamId} -> \"{name}\"");
        return name;
    }

    static string StripPrefix(string name)
    {
        int i = 0;
        while (i < name.Length && char.IsDigit(name[i])) i++;
        return name[i..];
    }

    /// Field order follows the entry class's offsets (TypeDefIndex 7354); enums sit on
    /// 4-byte boundaries there, so they are written as int32.
    static void WriteServerEntry(BinaryWriter w, GameServerInfo s)
    {
        var ip = s.Address is { } a && !a.IsIPv4MappedToIPv6 ? a : IPAddress.Loopback;
        if (ip.IsIPv4MappedToIPv6) ip = ip.MapToIPv4();

        // Probe mode labels every field so a screenshot of the browser row shows which
        // slot each one actually feeds.
        bool p = ProbeOffsets;

        w.Write(p ? 111111 : 0);                                  // 0x10 int
        // IPAddress(uint) takes the LOW byte as the first octet, so 127.0.0.1 must go out
        // as 0x0100007F. Writing it big-endian sends 1.0.0.127 and the client's join
        // attempt dies with "NoResponse".
        w.Write(BinaryPrimitives.ReadUInt32LittleEndian(ip.GetAddressBytes())); // 0x14 uint ip
        // Advertising a port we listen on ourselves makes the client send its real
        // Game_Hail to us, which is the only way to see the true join packet layout.
        w.Write((ushort)(CapturePort > 0 ? CapturePort : s.Port)); // 0x18 ushort port
        // Probe: the version goes in every string slot at once. If "BUILDS DON'T MATCH"
        // clears, one of these three is the build/version field the client compares.
        var ver = s.Version ?? "Production 2.2.5 Hotfix";
        // 0x20 is the build/version string the browser compares. Found by elimination:
        // putting the version in all three slots cleared "BUILDS DON'T MATCH", while
        // 0x50 alone and 0x40 alone did not.
        WriteString(w, ver);                                      // 0x20 string version
        w.Write((byte)(p ? 11 : s.CurrentPlayers));               // 0x28 byte
        w.Write((byte)(p ? 22 : 0));                              // 0x29 byte
        w.Write((byte)(p ? 33 : (s.MaxPlayers > 0 ? s.MaxPlayers : 254))); // 0x2A byte
        w.Write((byte)(p ? 44 : s.MapSize));                      // 0x2B byte map size
        w.Write(p ? 1 : 0);                                       // 0x2C None/Restarting/NewServer
        w.Write(p ? 2 : 0);                                       // 0x30 enum
        w.Write(p ? 3 : GameModeId(s.GameMode));                  // 0x34 game mode
        w.Write(p ? 4 : s.Hz);                                    // 0x38 tickrate
        WriteString(w, p ? "NAME40" : s.ServerName ?? "Revival"); // 0x40 string
        w.Write(p ? 5 : 0);                                       // 0x48 Casual=0 / Hardcore=1
        w.Write(p ? 6 : 0);                                       // 0x4C Day=0 / Night=1
        WriteString(w, p ? "MAP50" : s.MapName ?? "Azagor");      // 0x50 string
        w.Write((byte)(p ? 55 : 0));                              // 0x58 byte
        w.Write(p ? 7 : s.Region);                                // 0x5C region (Europe_Central=10)
        w.Write((byte)(p ? 66 : 0));                              // 0x60 byte
        w.Write((byte)(p ? 77 : 0));                              // 0x61 byte
        w.Write((byte)(p ? 88 : 0));                              // 0x62 byte
        w.Write((byte)(p ? 99 : 0));                              // 0x63 flags: None=0, IsOfficial=1
        w.Write(p ? 222222 : 0);                                  // 0x64 anti-cheat: NoAntiCheat=0
        w.Write(true);                                            // 0x68 bool
        w.Write(p ? 123f : 0f);                                   // 0x6C float
    }

    /// Game mode enum from the dump: Null=0, TDM=1, AAS=2, RUSH=3, CONQ=4, DOMI=5,
    /// ELI=6, INFCONQ=7, FRONTLINE=8. The Hail carries the name, not the id.
    static int GameModeId(string? mode) => mode?.ToUpperInvariant() switch
    {
        "TDM" => 1,
        "AAS" => 2,
        "RUSH" => 3,
        "CONQ" => 4,
        "DOMI" => 5,
        "ELI" => 6,
        "INFCONQ" => 7,
        "FRONTLINE" => 8,
        _ => 1,
    };

    static void WriteString(BinaryWriter w, string value)
    {
        var b = Encoding.UTF8.GetBytes(value);
        w.Write((ushort)b.Length);
        w.Write(b);
    }

    /// Fallback size for endpoints whose layout is not known yet.
    public static int ReplyBytes = 256;

    /// Diagnostic: advertise this port instead of the server's real one, so the client's
    /// join packet arrives at a socket we control and can be dumped.
    public static int CapturePort;

    // ==================== Registry port (game servers) ====================

    static async Task RunRegistryListener(IPAddress bind, int port, CancellationToken ct)
    {
        var listener = new TcpListener(bind, port);
        listener.Start();
        _log($"Registry listener up on {bind}:{port}");

        try
        {
            while (!ct.IsCancellationRequested)
            {
                var client = await listener.AcceptTcpClientAsync(ct);
                _ = HandleRegistryClient(client);
            }
        }
        catch (OperationCanceledException) { }
        finally
        {
            // Releasing the socket matters: left bound, a game server's connect still
            // succeeds and then nothing ever accepts it, so it hangs indefinitely.
            listener.Stop();
            _log("Registry listener stopped");
        }
    }

    static async Task HandleRegistryClient(TcpClient client)
    {
        var ep = client.Client.RemoteEndPoint?.ToString() ?? "unknown";
        var id = $"gs_{ep}";
        try
        {
            client.NoDelay = true;
            var stream = client.GetStream();

            var head = await ReadHeader(stream);
            if (head == null) return;

            // A proxy announces itself with the auth prelude; the game sends an HTTP upgrade.
            if (head.StartsWith(AuthMagic, StringComparison.Ordinal))
            {
                var parts = head.Split('\n');
                var supplied = parts.Length > 1 ? parts[1] : "";
                if (_cfg.Password.Length > 0 && !FixedTimeEquals(supplied, _cfg.Password))
                {
                    _log($"REGISTRY {ep} REJECTED (bad password)");
                    await stream.WriteAsync("DENIED\n"u8.ToArray());
                    return;
                }
                await stream.WriteAsync("OK\n"u8.ToArray());
                await stream.FlushAsync();
                _log($"REGISTRY {ep} proxy authenticated");

                head = await ReadHeader(stream);
                if (head == null) return;
            }
            else if (_cfg.Password.Length > 0 &&
                     !IsLoopback((client.Client.RemoteEndPoint as IPEndPoint)?.Address))
            {
                _log($"REGISTRY {ep} REJECTED (no auth prelude on a protected cluster)");
                return;
            }

            if (!head.StartsWith("GET ", StringComparison.Ordinal))
            {
                _log($"REGISTRY {ep} unexpected opening bytes, closing");
                return;
            }

            var wsKey = ExtractHeader(head, "Sec-WebSocket-Key");
            if (wsKey == null) { _log($"REGISTRY {ep} no Sec-WebSocket-Key"); return; }

            var accept = Convert.ToBase64String(SHA1.HashData(
                Encoding.UTF8.GetBytes(wsKey + "258EAFA5-E914-47DA-95CA-5AB0DC85B11B")));
            await stream.WriteAsync(Encoding.ASCII.GetBytes(
                "HTTP/1.1 101 Switching Protocols\r\nUpgrade: websocket\r\n" +
                $"Connection: Upgrade\r\nSec-WebSocket-Accept: {accept}\r\n\r\n"));
            await stream.FlushAsync();

            var info = new GameServerInfo
            {
                EndPoint = ep,
                ConnectedAt = DateTime.UtcNow,
                Address = (client.Client.RemoteEndPoint as IPEndPoint)?.Address,
            };
            Servers[id] = info;
            _log($"REGISTRY {ep} upgraded; awaiting Hail");

            await PumpPackets(stream, info, ep);
        }
        catch (Exception ex)
        {
            _log($"REGISTRY {ep} error: {ex.GetType().Name}: {ex.Message}");
        }
        finally
        {
            Servers.TryRemove(id, out _);
            _log($"REGISTRY {ep} disconnected. Cluster size: {Servers.Count}");
            client.Close();
        }
    }

    /// After the upgrade the game speaks raw uint32-LE length-prefixed packets.
    static async Task PumpPackets(NetworkStream stream, GameServerInfo info, string ep)
    {
        var lenBuf = new byte[4];
        while (true)
        {
            if (await ReadExact(stream, lenBuf, 4) < 4) { _log($"REGISTRY {ep} EOF"); return; }
            uint len = BinaryPrimitives.ReadUInt32LittleEndian(lenBuf);

            // The game sends an empty packet every 5s as a keepalive. Treating that as
            // an error is what was tearing down every accepted connection.
            if (len == 0)
            {
                info.LastHeartbeat = DateTime.UtcNow;
                _log($"REGISTRY {ep} heartbeat");
                await SendPacket(stream, []);
                continue;
            }
            if (len > 1 << 20) { _log($"REGISTRY {ep} bad packet length {len}"); return; }

            var data = new byte[len];
            if (await ReadExact(stream, data, (int)len) < len) { _log($"REGISTRY {ep} truncated packet"); return; }

            _log($"REGISTRY {ep} packet type=0x{data[0]:X2} len={len}");
            if (len <= 192) _log($"  hex: {Hex(data, 192)}");

            await Dispatch(stream, info, ep, data);
        }
    }

    /// 24 bytes: Accepted, then the server's address as the master sees it (its "NAT IP",
    /// offset found by probing). The remaining 19 bytes are not yet identified; zeros work.
    static byte[] BuildAccepted(GameServerInfo info)
    {
        var p = new byte[24];
        p[0] = Accepted;
        var ip = info.Address ?? IPAddress.Loopback;
        if (ip.IsIPv4MappedToIPv6) ip = ip.MapToIPv4();
        if (ip.AddressFamily == System.Net.Sockets.AddressFamily.InterNetwork)
            ip.GetAddressBytes().CopyTo(p, 1);

        // Clients ask the master for this server's public key before joining
        // (GetPublicKeyForGameServer), and the key is two ulongs. The remaining 19 bytes
        // here are the only channel the master has to hand the server a key, so mint one
        // per session and give the same pair out to joining clients.
        BinaryPrimitives.WriteUInt64LittleEndian(p.AsSpan(5), info.KeyLow);
        BinaryPrimitives.WriteUInt64LittleEndian(p.AsSpan(13), info.KeyHigh);
        return p;
    }

    /// After the Hail handshake the server switches to a sequenced message stream:
    ///     uint64 sequence, byte type, payload
    /// These are the game's own master-protocol names and values (TypeDefIndex 7347).
    /// The master's reply echoes both the sequence and the request's type byte, which is
    /// why the answer to Hail is 0x01 and not any separate "accepted" code.
    enum MasterPacket : byte
    {
        Ping = 0,
        Hail = 1,
        DisconnectRequest = 2,
        GetIntervalStats = 3,
        InsertLog = 4,
        GetPlayerStats = 5,
        JoinPlayerToServer = 6,
        LeavePlayerFromServer = 7,
        SaveStatsAndLeavePlayerFromServer = 8,
        SaveStatsAndLeavePlayerFromServerBatched = 9,
        FlagPlayerByAntiCheat = 10,
        UpdateGameInfo = 11,
        UpdatePlayerInfo = 12,
        UpdateServerPhysicalStateInfo = 13,
        UpdateServerBrowserStateInfo = 14,
        UpdatePlayingModeratorCount = 15,
        UpdatePlayingContentCreatorCount = 16,
        UploadGameStatistics = 17,
        GetClanInfo = 18,
        LogError = 19,
        RequestToTransfer = 20,
        GetBlackwhiteListedWords = 21,
        RecordChatFilterDetection = 22,
        GetCommandQueue = 23,
        LogFast = 24,
        GetWeeklyChallenge = 25,
    }

    /// Dispatch modelled on BattleBitAPI's ServerListener.mExecutePackage: one branch per
    /// packet type, each reading its own fields.
    static async Task Dispatch(NetworkStream stream, GameServerInfo info, string ep, byte[] data)
    {
        // Hail is the only packet outside the sequenced stream, and it is always first.
        if (!info.Hailed)
        {
            info.Hailed = true;
            await HandleHail(stream, info, data);
            return;
        }

        if (data.Length < 9)
        {
            _log($"  runt packet ({data.Length}b): {Hex(data)}");
            return;
        }

        ulong sequence = BinaryPrimitives.ReadUInt64LittleEndian(data);
        var type = (MasterPacket)data[8];
        var payload = data.AsSpan(9);

        switch (type)
        {
            // The server sits in WaitingStatsFromMasterServer and drops the joining
            // player after 6000ms if this goes unanswered.
            case MasterPacket.GetPlayerStats when payload.Length >= 8:
            {
                var steamId = BinaryPrimitives.ReadUInt64LittleEndian(payload);
                var account = AccountFor(steamId);
                var who = account?.Name ?? DisplayName(steamId);
                var progress = account?.Progress ?? _accounts.Progression.NewPlayerProgress();
                var reply = BuildStatsReply(sequence, steamId, who, progress,
                                            account?.IsBanned ?? false);
                await SendPacket(stream, reply);
                _log($"  seq {sequence} GetPlayerStats {steamId} -> stats as \"{who}\" " +
                     $"({reply.Length}b, {progress.Params.Length} progress params" +
                     $"{(account is null ? ", no account yet" : "")})");
                break;
            }

            // Progress comes back when a player leaves, in the same layout we send it.
            case MasterPacket.SaveStatsAndLeavePlayerFromServer:
            {
                var record = PlayerStats.TryRead(new PacketReader(payload.ToArray()), out var sid);
                var name = PlayerAccounts.GetValueOrDefault(sid);
                _log($"  seq {sequence} {type} REFERENCE LAYOUT ({payload.Length}b): " +
                     $"{Hex(payload.ToArray(), 4096)}");
                if (record is null)
                    _log($"  seq {sequence} {type}: stats did not parse ({payload.Length}b)");
                else if (name is null)
                    _log($"  seq {sequence} {type}: no account for {sid}, progress dropped");
                else
                {
                    _accounts.StoreProgress(name, record);
                    _log($"  seq {sequence} {type}: saved progress for \"{name}\" " +
                         $"({record.Params.Length} params)");
                }
                break;
            }

            default:
                _log($"  seq {sequence} {type} (0x{data[8]:X2}) {payload.Length}b: {Hex(payload.ToArray())}");
                break;
        }
    }

    static async Task HandleHail(NetworkStream stream, GameServerInfo info, byte[] data)
    {
        ParseHail(data, info);
        _log($"  hail: port={info.Port} hz={info.Hz} region={info.Region} " +
             $"version=\"{info.Version}\" map=\"{info.MapName}\" name=\"{info.ServerName}\"");

        var accepted = BuildAccepted(info);
        if (ProbeOffsets)
            for (int i = 1; i < accepted.Length; i++) accepted[i] = (byte)i;

        await SendPacket(stream, accepted);
        _log($"  -> sent Accepted (NAT IP {info.Address}): {Hex(accepted)}");
    }

    /// The name the game server will show for this player. Registered by the launcher
    /// when the client authenticates, so it is the name the player typed rather than
    /// anything Steam supplied.
    static string DisplayName(ulong steamId) =>
        PlayerNames.TryGetValue(steamId, out var n) ? n : "Player";

    /// A reply to a sequenced request echoes the sequence and the request's type byte.
    /// This is load-bearing: dropping the sequence makes the server ignore the reply and
    /// re-send GetPlayerStats every 10.7s until it gives up at WaitingStatsFromMasterServer,
    /// so the join fails outright. That 10.7s is the retry interval, NOT a timeout before
    /// the server continues - do not read a gap of that length as "the reply was ignored".
    ///
    /// There is no envelope around the stats themselves: the handler at RVA 0x24479E0
    /// allocates a PlayerStats and reads straight into it, so the payload is the blob
    /// and nothing else.
    static byte[] BuildStatsReply(
        ulong sequence, ulong steamId, string username, ProgressRecord progress, bool isBanned)
    {
        var w = new PacketWriter();
        w.Write(sequence);
        w.Write((byte)MasterPacket.GetPlayerStats);
        PlayerStats.Write(w, steamId, username, progress, isBanned);

        // The username is the last field, and the game's string reader returns NULL
        // rather than throwing when fewer bytes remain than the length prefix claims
        // (RVA 0x236BC70: "cmp eax,2 / jl ret-null" then "cmp edx,ebp / jl ret-null").
        // An exactly-sized body therefore loses the name silently, which is what left
        // the player unnamed in game while everything else parsed. The same trap already
        // bit the token and key replies, so pad the tail.
        w.WriteRaw(new byte[64]);
        return w.ToArray();
    }

    static void ParseHail(byte[] d, GameServerInfo info)
    {
        if (d.Length < 23) return;
        info.Port = BinaryPrimitives.ReadUInt16LittleEndian(d.AsSpan(5));
        info.MapSize = d[9];
        info.Hz = d[17];
        info.Region = d[18];

        int off = 23;
        if (TryReadString(d, ref off, out var version)) info.Version = version;
        if (TryReadString(d, ref off, out var map)) info.MapName = map;
        if (TryReadString(d, ref off, out var name)) info.ServerName = name;
    }

    static async Task SendPacket(NetworkStream stream, byte[] payload)
    {
        var wire = new byte[4 + payload.Length];
        BinaryPrimitives.WriteUInt32LittleEndian(wire, (uint)payload.Length);
        payload.CopyTo(wire, 4);
        await stream.WriteAsync(wire);
        await stream.FlushAsync();
    }

    // ==================== Helpers ====================

    static async Task<string?> ReadHeader(NetworkStream stream)
    {
        var sb = new StringBuilder();
        var one = new byte[1];
        while (sb.Length < 8192)
        {
            if (await stream.ReadAsync(one, 0, 1) == 0) return sb.Length > 0 ? sb.ToString() : null;
            sb.Append((char)one[0]);
            var s = sb.ToString();
            if (s.EndsWith("\r\n\r\n", StringComparison.Ordinal)) return s;
            // The auth prelude is two newline-terminated lines.
            if (s.StartsWith(AuthMagic, StringComparison.Ordinal) && s.Count(c => c == '\n') >= 2) return s;
        }
        return sb.ToString();
    }

    static string? ExtractHeader(string request, string name)
    {
        foreach (var line in request.Split('\n'))
        {
            var t = line.Trim();
            if (t.StartsWith(name + ":", StringComparison.OrdinalIgnoreCase))
                return t[(name.Length + 1)..].Trim();
        }
        return null;
    }

    static bool TryReadString(byte[] data, ref int offset, out string result)
    {
        result = "";
        if (offset + 2 > data.Length) return false;
        ushort len = BinaryPrimitives.ReadUInt16LittleEndian(data.AsSpan(offset));
        offset += 2;
        if (len == 0 || offset + len > data.Length) return false;
        result = Encoding.UTF8.GetString(data, offset, len);
        offset += len;
        return true;
    }

    static async Task<int> ReadExact(Stream stream, byte[] buffer, int count)
    {
        int total = 0;
        while (total < count)
        {
            int read = await stream.ReadAsync(buffer, total, count - total);
            if (read == 0) return total;
            total += read;
        }
        return total;
    }

    static async Task<byte[]> ReadBody(HttpContext ctx)
    {
        using var ms = new MemoryStream();
        await ctx.Request.Body.CopyToAsync(ms);
        return ms.ToArray();
    }

    static string Hex(byte[] data, int max = int.MaxValue) =>
        BitConverter.ToString(data, 0, Math.Min(data.Length, max)).Replace("-", "");

    static string Ascii(byte[] data, int max)
    {
        var sb = new StringBuilder();
        foreach (var b in data.AsSpan(0, Math.Min(data.Length, max)))
            sb.Append(b >= 32 && b <= 126 ? (char)b : '.');
        return sb.ToString();
    }
}
```

```cs
namespace MasterServer;

/// Index of each uint in PlayerProgess's wire block. The order is the field declaration
/// order of PlayerStats.PlayerProgess, which is what the game's reader walks: verified
/// against the struct offsets, where the last three written are 0x114 TotalScore,
/// 0x118 AmmoSupplied and 0x11C WeeklyChallengeCompleted.
public enum ProgressField
{
    KillCount = 0, LeaderKills, AssaultKills, MedicKills, EngineerKills, SupportKills,
    ReconKills, DeathCount, WinCount, LoseCount, FriendlyShots, FriendlyKills, Revived,
    RevivedTeamMates, Assists, Prestige, Rank, EXP, ShotsFired, ShotsHit, Headshots,
    ObjectivesComplated, HealedHPs, RoadKills, Suicides, VehiclesDestroyed,
    VehicleHPRepaired, LongestKill, PlayTimeSeconds, LeaderPlayTime, AssaultPlayTime,
    MedicPlayTime, EngineerPlayTime, SupportPlayTime, ReconPlayTime, LeaderScore,
    AssaultScore, MedicScore, EngineerScore, SupportScore, ReconScore, TotalScore,
    AmmoSupplied, WeeklyChallengeCompleted,

    /// Not a field - the number of them, and what PlayerProgess declares as its count.
    Count,
}

public static class ProgressFieldExtensions
{
    public static uint Get(this ProgressRecord r, ProgressField field)
    {
        var i = (int)field;
        return i >= 0 && i < r.Params.Length ? r.Params[i] : 0;
    }

    public static void Set(this ProgressRecord r, ProgressField field, uint value)
    {
        var i = (int)field;
        if (i >= 0 && i < r.Params.Length) r.Params[i] = value;
    }

/// Per-master-server progression rules, in progression.json beside the account store so
/// a server owner can tune their cluster without touching the code. A brand new player
/// is an ordinary level-zero player under these rules; the defaults are all neutral, so
/// an untouched file behaves exactly like vanilla progression.
public sealed class ProgressionConfig
{
    /// What a newly created account starts with.
    public uint StartingRank { get; set; }
    public uint StartingPrestige { get; set; }
    public uint StartingExp { get; set; }

    /// Starting score for each class, which is what the game derives class level from.
    /// Keys are the six classes; anything else is ignored.
    public Dictionary<string, uint> StartingClassScore { get; set; } = new()
    {
        ["Leader"] = 0,
        ["Assault"] = 0,
        ["Medic"] = 0,
        ["Engineer"] = 0,
        ["Support"] = 0,
        ["Recon"] = 0,
    };

    /// Rate of growth. Everything a player earns in a round is scaled by these before
    /// being banked, so 2.0 is double XP. 1.0 is vanilla.
    public double XpMultiplier { get; set; } = 1.0;
    public double ScoreMultiplier { get; set; } = 1.0;

    static readonly (string Name, ProgressField Field)[] ClassScores =
    [
        ("Leader", ProgressField.LeaderScore),
        ("Assault", ProgressField.AssaultScore),
        ("Medic", ProgressField.MedicScore),
        ("Engineer", ProgressField.EngineerScore),
        ("Support", ProgressField.SupportScore),
        ("Recon", ProgressField.ReconScore),
    ];

    /// The progress a brand new account begins with: a normal level-zero player, plus
    /// whatever head start the server owner configured.
    public ProgressRecord NewPlayerProgress()
    {
        var record = new ProgressRecord();
        record.Set(ProgressField.Rank, StartingRank);
        record.Set(ProgressField.Prestige, StartingPrestige);
        record.Set(ProgressField.EXP, StartingExp);
        foreach (var (name, field) in ClassScores)
            if (StartingClassScore.TryGetValue(name, out var score))
                record.Set(field, score);
        return record;
    }

    /// Scale what the player earned this round before it is banked. Called with the
    /// progress as it was when they joined and as the game server handed it back, and
    /// rewrites the earned fields in place.
    public void ApplyGrowth(ProgressRecord before, ProgressRecord earned)
    {
        Scale(before, earned, ProgressField.EXP, XpMultiplier);
        Scale(before, earned, ProgressField.TotalScore, ScoreMultiplier);
        foreach (var (_, field) in ClassScores)
            Scale(before, earned, field, ScoreMultiplier);
    }

    static void Scale(ProgressRecord before, ProgressRecord earned, ProgressField field, double multiplier)
    {
        if (Math.Abs(multiplier - 1.0) < 0.0001) return;

        var old = before.Get(field);
        var now = earned.Get(field);
        if (now <= old) return;    // nothing earned, or the server reset it

        // Scale only the delta, so a multiplier change never retroactively inflates or
        // destroys progress someone already had.
        var scaled = (double)old + (now - old) * Math.Max(0, multiplier);
        earned.Set(field, scaled >= uint.MaxValue ? uint.MaxValue : (uint)scaled);
    }

    public static ProgressionConfig LoadOrCreate(string path)
    {
        try
        {
            if (File.Exists(path))
                return JsonSerializer.Deserialize<ProgressionConfig>(File.ReadAllText(path))
                       ?? new ProgressionConfig();
        }
        catch { /* a broken file falls back to vanilla rather than refusing to boot */ }

        var fresh = new ProgressionConfig();
        try
        {
            File.WriteAllText(path, JsonSerializer.Serialize(
                fresh, new JsonSerializerOptions { WriteIndented = true }));
        }
        catch { }
        return fresh;
    }

    public string Describe() =>
        $"rank {StartingRank}, prestige {StartingPrestige}, exp {StartingExp}, " +
        $"xp x{XpMultiplier:0.##}, score x{ScoreMultiplier:0.##}";
}
```

```cs
using System.Buffers.Binary;
using System.Text;

namespace MasterServer;

/// Writer matching the game's own serialisation conventions, modelled on
/// BattleBitAPI's Common.Serialization.Stream: little-endian throughout, strings as a
/// ushort byte-length prefix followed by UTF-8.
public sealed class PacketWriter
{
    readonly MemoryStream _ms = new();

    public PacketWriter Write(byte v) { _ms.WriteByte(v); return this; }
    public PacketWriter Write(bool v) { _ms.WriteByte(v ? (byte)1 : (byte)0); return this; }

    public PacketWriter Write(ushort v)
    {
        Span<byte> b = stackalloc byte[2];
        BinaryPrimitives.WriteUInt16LittleEndian(b, v);
        _ms.Write(b);
        return this;
    }

    public PacketWriter Write(uint v)
    {
        Span<byte> b = stackalloc byte[4];
        BinaryPrimitives.WriteUInt32LittleEndian(b, v);
        _ms.Write(b);
        return this;
    }

    public PacketWriter Write(int v) => Write((uint)v);

    public PacketWriter Write(ulong v)
    {
        Span<byte> b = stackalloc byte[8];
        BinaryPrimitives.WriteUInt64LittleEndian(b, v);
        _ms.Write(b);
        return this;
    }

    public PacketWriter Write(long v) => Write((ulong)v);

    public PacketWriter Write(float v)
    {
        Span<byte> b = stackalloc byte[4];
        BinaryPrimitives.WriteSingleLittleEndian(b, v);
        _ms.Write(b);
        return this;
    }

    public PacketWriter Write(string value)
    {
        var bytes = Encoding.UTF8.GetBytes(value);
        Write((ushort)bytes.Length);
        _ms.Write(bytes);
        return this;
    }

    /// A ushort-length-prefixed blob, the shape PlayerStats uses for its
    /// ToolProgress / Achievements / Selections arrays.
    public PacketWriter WriteBlob(ReadOnlySpan<byte> data)
    {
        Write((ushort)data.Length);
        _ms.Write(data);
        return this;
    }

    /// Raw bytes with no length prefix, for trailing padding.
    public PacketWriter WriteRaw(ReadOnlySpan<byte> data)
    {
        _ms.Write(data);
        return this;
    }

    public byte[] ToArray() => _ms.ToArray();
    public int Length => (int)_ms.Length;
}

/// PlayerStats as the game server reads it, derived from
/// PlayerStats::ReadFrom_MasterServer_GameServerSide (RVA 0x12A2A70) and its five
/// sub-readers. The server blocks in WaitingStatsFromMasterServer for 6000ms waiting
/// for this, so the layout has to match field for field.
///
/// Every variable-length block is self-describing, which is what makes a minimal reply
/// safe: PlayerProgess writes a param count and the reader seeks past exactly that many
/// uints, and each collection writes a byte count the reader uses as a read limit.
public static class PlayerStats
{
    /// Count of uint fields PlayerProgess declares after SteamID (KillCount through
    /// WeeklyChallengeCompleted). The reader seeks to start + count*4 when it is done,
    /// so a short count is honoured rather than desyncing the stream.
    public const uint ProgressParamCount = (uint)ProgressField.Count;

    /// Offset scan alignment: 0, 1 or 2; any negative value disables it.
    public const int ScanShift = 1;

    public const string ScanLabels =
        "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789";

    public static void Write(
        PacketWriter w,
        ulong steamId,
        string username,
        ProgressRecord progress,
        bool isBanned = false,
        bool isTimedout = false)
    {
        // PlayerProgess. The declared count is whatever we actually write, since the
        // reader seeks to start + count*4 when it finishes.
        w.Write(steamId);
        w.Write((uint)progress.Params.Length);
        foreach (var value in progress.Params)
            w.Write(value);

        w.WriteBlob(progress.ToolsProgess);    // body 188 - dictionary, 10 bytes/entry
        w.WriteBlob(progress.Achievements);    // body 190 - HashSet<uint>, 4 bytes/entry
        w.WriteBlob(progress.Selections);      // body 192 - raw Data byte[]
        w.WriteBlob(progress.Inventory);       // body 194 - HashSet<string>

        w.Write(false);         // body 196 - Clan.hasClan; false stops the clan reader
        w.Write(isBanned);      // body 197
        w.Write(isTimedout);    // body 198
        w.Write((ushort)0);     // body 199 - weekly challenge block length
        w.Write(progress.Role); // body 201

        // body 209 - MasterServerUsername, the name shown in game.
        //
        // MEASURED, not inferred. The game's stream buffer holds the WHOLE packet
        // including the 9-byte header (uint64 sequence + byte type) that this master
        // strips before parsing, so the two sides disagree about where offset zero is.
        // A labelled-slot probe read at forced buffer position 218 and returned the
        // label sitting at body 209, proving the prefix is exactly 9.
        //
        // The NameReadPosition patch in patch_auth.ps1 forces the read cursor to buffer
        // 218 immediately before this string is read, so this offset is authoritative
        // and no longer depends on the chain of field widths ahead of it.
        w.Write(username);
    }

    /// Parse the same layout back out of a packet the game server sent us, which is how
    /// progress gets saved. PlayerStats::WriteTo_MasterServer_GameServerSide (RVA
    /// 0x12A2F50) writes the fields in exactly the order the reader consumes them, so
    /// one layout serves both directions.
    ///
    /// Returns null if the packet does not parse, rather than throwing into the
    /// connection loop: a malformed save is worth logging and dropping, not worth
    /// tearing down a working registry connection over.
    public static ProgressRecord? TryRead(PacketReader r, out ulong steamId)
    {
        steamId = 0;
        try
        {
            steamId = r.ReadUInt64();
            var count = r.ReadUInt32();
            if (count > 4096) return null;          // nonsense length, bail out

            var record = new ProgressRecord { Params = new uint[count] };
            for (uint i = 0; i < count; i++)
                record.Params[i] = r.ReadUInt32();

            record.ToolsProgess = r.ReadBlob();
            record.Achievements = r.ReadBlob();
            record.Selections = r.ReadBlob();
            record.Inventory = r.ReadBlob();

            if (r.ReadBool())                       // Clan.hasClan
            {
                r.ReadBool();                       // clan fields we do not keep
                r.Skip(1);
            }

            r.ReadBool();                           // isBanned, decided by the master
            r.ReadBool();                           // isTimedout
            if (r.ReadUInt16() != 0) return record;  // a challenge body we do not parse
            record.Role = r.ReadUInt64();
            return record;
        }
        catch (Exception)
        {
            return null;
        }
    }
}

/// Bounds-checked counterpart to PacketWriter. Every read past the end throws, which
/// callers turn into "this packet did not parse" rather than letting it escape.
public sealed class PacketReader(ReadOnlyMemory<byte> data)
{
    readonly ReadOnlyMemory<byte> _data = data;
    int _pos;

    public int Remaining => _data.Length - _pos;

    ReadOnlySpan<byte> Take(int count)
    {
        if (count < 0 || Remaining < count)
            throw new EndOfStreamException($"needed {count} bytes, {Remaining} left");
        var span = _data.Span.Slice(_pos, count);
        _pos += count;
        return span;
    }

    public void Skip(int count) => Take(count);
    public bool ReadBool() => Take(1)[0] != 0;
    public byte ReadByte() => Take(1)[0];
    public ushort ReadUInt16() => BinaryPrimitives.ReadUInt16LittleEndian(Take(2));
    public uint ReadUInt32() => BinaryPrimitives.ReadUInt32LittleEndian(Take(4));
    public ulong ReadUInt64() => BinaryPrimitives.ReadUInt64LittleEndian(Take(8));

    /// A ushort-length-prefixed blob, the shape every variable-length PlayerStats
    /// section uses.
    public byte[] ReadBlob() => Take(ReadUInt16()).ToArray();

    public string ReadString() => Encoding.UTF8.GetString(Take(ReadUInt16()));
}
```

```cs
using System.Globalization;
using System.Text;

namespace MasterServer;

/// Everything a server owner sets, in one plain key=value file next to the server
/// executable. Deliberately not JSON: this is the file people edit by hand, so it keeps
/// its comments and tolerates being half-filled-in.
///
/// Unknown keys are preserved on save, and anything missing falls back to the default,
/// so a properties file from an older build still loads.
public sealed class ServerProperties
{
    readonly Dictionary<string, string> _values = new(StringComparer.OrdinalIgnoreCase);
    readonly string _path;

    ServerProperties(string path) => _path = path;

    public string FilePath => _path;

    public static ServerProperties LoadOrCreate(string path)
    {
        var props = new ServerProperties(path);
        if (!File.Exists(path))
        {
            try { File.WriteAllText(path, Template); } catch { }
        }

        try
        {
            foreach (var raw in File.ReadAllLines(path))
            {
                var line = raw.Trim();
                if (line.Length == 0 || line[0] is '#' or '!') continue;
                var eq = line.IndexOf('=');
                if (eq <= 0) continue;
                props._values[line[..eq].Trim()] = line[(eq + 1)..].Trim();
            }
        }
        catch { }
        return props;
    }

    public string Get(string key, string fallback = "") =>
        _values.TryGetValue(key, out var v) && v.Length > 0 ? v : fallback;

    public int GetInt(string key, int fallback) =>
        int.TryParse(Get(key), NumberStyles.Integer, CultureInfo.InvariantCulture, out var v) ? v : fallback;

    public double GetDouble(string key, double fallback) =>
        double.TryParse(Get(key), NumberStyles.Float, CultureInfo.InvariantCulture, out var v) ? v : fallback;

    public bool GetBool(string key, bool fallback) =>
        bool.TryParse(Get(key), out var v) ? v : fallback;

    // ==================== Mapping onto the running config ====================

    public MasterConfig ToMasterConfig() => new()
    {
        MasterHost = "127.0.0.1",
        ClusterName = Get("cluster-name", "Revival Cluster"),
        HttpPort = GetInt("master-http-port", 29300),
        RegistryPort = GetInt("master-registry-port", 29301),
        Password = Get("cluster-password"),
        RequireAccounts = GetBool("require-accounts", true),
        HostMaster = true,
    };

    public void ApplyTo(AntiCheatConfig ac)
    {
        ac.Enabled = GetBool("anticheat-enabled", ac.Enabled);
        ac.RequireGuard = GetBool("anticheat-require-guard", ac.RequireGuard);
        ac.ReportsToBan = GetInt("anticheat-reports-to-ban", ac.ReportsToBan);
        ac.ReportWindowMinutes = GetInt("anticheat-window-minutes", ac.ReportWindowMinutes);
        ac.BanByHardwareId = GetBool("anticheat-ban-by-hardware-id", ac.BanByHardwareId);
        ac.AutoApplyImportedBans = GetBool("anticheat-auto-apply-imported-bans", ac.AutoApplyImportedBans);
        ac.MinimumImportConfidence = GetInt("anticheat-minimum-import-confidence", ac.MinimumImportConfidence);
    }

    public void ApplyTo(ProgressionConfig p)
    {
        p.StartingRank = (uint)Math.Max(0, GetInt("progression-starting-rank", (int)p.StartingRank));
        p.StartingPrestige = (uint)Math.Max(0, GetInt("progression-starting-prestige", (int)p.StartingPrestige));
        p.StartingExp = (uint)Math.Max(0, GetInt("progression-starting-exp", (int)p.StartingExp));
        p.XpMultiplier = GetDouble("progression-xp-multiplier", p.XpMultiplier);
        p.ScoreMultiplier = GetDouble("progression-score-multiplier", p.ScoreMultiplier);
    }

    /// The command line for BattleBit.exe in dedicated-server mode. Only flags the
    /// binary actually parses are emitted - anything else is silently ignored by the
    /// game, which makes typos hard to spot.
    public string GameServerArguments(string logFile)
    {
        var sb = new StringBuilder("-batchmode -nographics");
        sb.Append($" -Port={GetInt("server-port", 30000)}");
        sb.Append($" -Hz={GetInt("server-hz", 60)}");
        sb.Append($" -AntiCheat={Get("game-anticheat", "None")}");
        sb.Append($" -MaxPing={GetInt("max-ping", 999)}");
        sb.Append($" -VoxelMode={GetBool("voxel-mode", false).ToString().ToLowerInvariant()}");
        sb.Append($" -Name={Get("server-name", "RevivalServer")}");

        var firstMap = Get("first-map");
        if (firstMap.Length > 0) sb.Append($" -FirstMap={firstMap}");
        var firstGamemode = Get("first-gamemode");
        if (firstGamemode.Length > 0) sb.Append($" -FirstGamemode={firstGamemode}");
        var size = Get("fixed-size");
        if (size.Length > 0) sb.Append($" -FixedSize={size}");
        if (!GetBool("save-stats", true)) sb.Append(" -SaveStats=false");

        sb.Append($" -logFile \"{logFile}\"");
        return sb.ToString();
    }

    /// Console commands to send once the server is up, newest-first in the file order.
    public IEnumerable<string> StartupCommands()
    {
        var size = Get("server-size");
        if (size.Length > 0) yield return $"setsize {size}";

        var bots = GetInt("bots-per-team", 0);
        if (bots > 0)
        {
            yield return $"join bot a {bots}";
            yield return $"join bot b {bots}";
        }

        if (GetBool("auto-forcestart", false)) yield return "forcestart";

        foreach (var extra in Get("startup-commands").Split(';', StringSplitOptions.RemoveEmptyEntries))
            if (extra.Trim().Length > 0) yield return extra.Trim();
    }

    public const string Template = """
        # ============================================================
        #  BattleBit Revival - server.properties
        #
        #  Edit, save, restart the server. Lines starting with # are
        #  comments. Anything left blank falls back to the default.
        #  See SERVER-GUIDE.md for what each of these does.
        # ============================================================

        # ---------- Cluster (your master server) ----------
        # The name players see for your cluster.
        cluster-name=Revival Cluster
        # Ports the master listens on. Players connect to master-http-port.
        master-http-port=29300
        master-registry-port=29301
        # Leave blank for an open cluster, or set a password players must enter.
        cluster-password=
        # Require players to log in with an account before they can get a token.
        require-accounts=true

        # ---------- Game server ----------
        # BattleBit ships no Linux dedicated server, so on Linux this box runs the
        # master only: accounts, bans, progression and the server browser. Windows
        # machines then run game servers that register to it. Leave blank to decide
        # automatically (on = Windows, off = anything else).
        run-game-server=
        # Where BattleBit.exe lives. Blank means "look in the folders above this one",
        # which is right if you unzipped this inside your BattleBit install.
        game-path=
        server-name=RevivalServer
        server-port=30000
        # Tick rate: 30-240. Higher is smoother and costs more CPU and bandwidth.
        server-hz=60
        # tiny=8v8, small=16v16, medium=32v32, ultra=127v127
        server-size=tiny
        # Reject players above this ping. 999 disables it.
        max-ping=999
        # The game's own anti-cheat: None, EAC or FaceIt. Leave None for a private cluster.
        game-anticheat=None
        voxel-mode=false
        # Optional starting map and mode, e.g. Azagor / TDM. Blank lets the game choose.
        first-map=
        first-gamemode=
        # Set false to stop the server asking the master to save player stats.
        save-stats=true

        # ---------- Startup ----------
        # Start the round without waiting for the minimum player count. Handy for testing.
        auto-forcestart=false
        # Bots added to each team on startup. 0 for none.
        bots-per-team=0
        # Extra console commands, separated by semicolons. e.g. set fps 60;kick all
        startup-commands=

        # ---------- Anti-cheat (optional, off by default) ----------
        # See SERVER-GUIDE.md. This is the server-side system; the client-side guard
        # is opt-in by each player unless anticheat-require-guard is true.
        anticheat-enabled=false

        anticheat-require-guard=false

        anticheat-reports-to-ban=3
        anticheat-window-minutes=30
        # Ban the machine as well as the account. Hardware ids are spoofable.
        anticheat-ban-by-hardware-id=true

        anticheat-auto-apply-imported-bans=false
        anticheat-minimum-import-confidence=80

        # What a brand new player starts with on this cluster.
        progression-starting-rank=0
        progression-starting-prestige=0
        progression-starting-exp=0

        progression-xp-multiplier=1.0
        progression-score-multiplier=1.0

        """;
```

```md
## Game files are not in this repo

`GameAssembly.dll` and `global-metadata.dat` are BattleBit's, and a patched copy is still

reason. They remove dead master-server auth gates, fix a crash on a missing player name,
```

```
## Features

- **Your own cluster** - optional cluster password, your own server browser listing.
- **Accounts per master** - name + password, PBKDF2-SHA256 hashed, never stored in plain
  text. The same name on another cluster is a different account.
- **Progression you control** - starting rank, prestige and XP, plus XP and score
  multipliers. Multipliers apply to what is *earned*, so changing them never
  retroactively alters existing progress.
- **Optional anti-cheat** - server-side authority with an opt-in client guard, threshold
  based so one detection never bans, hardware-id bans, and export/import so owners can
  share lists (imports wait for review by default).
- **Server console** - `forcestart`, bots, size, tick rate, kick, announce.

## Protocol notes

The wire protocol was reverse-engineered from the shipped binary. A few things that cost
real time and are worth knowing if you work on this:

- The registry channel on 29301 does an HTTP WebSocket upgrade handshake and then speaks
  **raw `uint32`-LE length-prefixed binary** - no WebSocket framing.
- After the Hail, every server to master message is `uint64 sequence` + `byte type` +
  payload. Replies echo both. Dropping the sequence breaks the join entirely.
- The master's reply to a request echoes the **request's type byte**; there is no
  separate "accepted" code.
- The game's stream buffer includes the 9-byte packet header that this master strips
  before parsing, so absolute offsets differ by 9 between the two sides.
```

```cs
using System.Diagnostics;
using MasterServer;

namespace RevivalServer;

/// Headless server box: reads server.properties, hosts the master, starts the game
/// server, and gives the operator a console to type commands into. Everything a server
/// owner needs and nothing a player does - no UI, no client launching, runs fine on a
/// box with no desktop.
static class Program
{
    static readonly string Dir = Path.GetDirectoryName(Environment.ProcessPath) ?? ".";
    static readonly string LogPath = Path.Combine(Dir, "server_console.log");
    static Process? _game;

    static async Task<int> Main(string[] args)
    {
        Console.Title = "BattleBit Revival Server";
        var propsPath = Path.Combine(Dir, "server.properties");

        // --init just writes the settings file and exits, so the packaged box ships with
        // one to edit rather than only creating it on first run.
        if (args.Any(a => a.Equals("--init", StringComparison.OrdinalIgnoreCase)))
        {
            File.WriteAllText(propsPath, ServerProperties.Template);
            Console.WriteLine($"Wrote {propsPath}");
            return 0;
        }

        var props = ServerProperties.LoadOrCreate(propsPath);

        Log("BattleBit Revival - server");
        Log($"Settings: {props.FilePath}");

        // The game is Windows-only, so elsewhere this box hosts the master alone and
        // Windows machines run the game servers that register to it.
        var runGame = props.GetBool("run-game-server", OperatingSystem.IsWindows());
        string? gameRoot = null;

        if (runGame)
        {
            gameRoot = ResolveGameRoot(props);
            if (gameRoot is null)
            {
                Log("");
                Log("Could not find BattleBit.exe.");
                Log("Set game-path in server.properties to your BattleBit folder, e.g.");
                Log(@"  game-path=C:\SteamLibrary\steamapps\common\BattleBit Remastered");
                Log("");
                Log("Or set run-game-server=false to host only the master here.");
                Log("See TROUBLESHOOTING.md. Press Enter to close.");
                Console.ReadLine();
                return 1;
            }
            Log($"Game: {gameRoot}");

            // The game server reads eula.txt from its working directory and refuses to
            // accept players until it says True, silently except in its own log.
            EnsureEula(gameRoot);
        }
        else
        {
            Log("Master-only mode: hosting accounts, bans, progression and the browser.");
            Log("Game servers run on Windows and register to this master.");
        }

        var cfg = props.ToMasterConfig();
        using var cts = new CancellationTokenSource();
        Console.CancelKeyPress += (_, e) => { e.Cancel = true; cts.Cancel(); };

        var master = Task.Run(async () =>
        {
            try { await MasterServerHost.RunAsync(cfg, Log, cts.Token, props); }
            catch (OperationCanceledException) { }
            catch (Exception ex) { Log($"Master server stopped: {ex.Message}"); }
        });

        if (gameRoot is not null)
        {
            // Give the master its ports before the game server tries to register.
            await Task.Delay(1500);
            if (!StartGameServer(props, gameRoot)) { cts.Cancel(); return 1; }
            await SendStartupCommands(props, cts.Token);
        }

        Log("");
        Log(gameRoot is null
            ? "Master is up. Point your game servers at this machine."
            : "Server is up. Type console commands here, or 'help' for the common ones.");
        Log("Ctrl+C or 'stop' shuts everything down.");
        Log("");

        await ConsoleLoop(cts);

        cts.Cancel();
        StopGameServer();
        await Task.WhenAny(master, Task.Delay(5000));
        Log("Stopped.");
        return 0;
    }

    // ==================== Game server ====================

    static string? ResolveGameRoot(ServerProperties props)
    {
        var configured = props.Get("game-path");
        if (configured.Length > 0)
            return File.Exists(Path.Combine(configured, "BattleBit.exe")) ? configured : null;

        var dir = Dir;
        for (int i = 0; i < 8 && dir is not null; i++)
        {
            if (File.Exists(Path.Combine(dir, "BattleBit.exe"))) return dir;
            dir = Path.GetDirectoryName(dir.TrimEnd(Path.DirectorySeparatorChar));
        }
        return null;
    }

    static void EnsureEula(string gameRoot)
    {
        var eula = Path.Combine(gameRoot, "eula.txt");
        try
        {
            if (File.Exists(eula)
                && File.ReadAllText(eula).Contains("=false", StringComparison.OrdinalIgnoreCase))
            {
                Log("eula.txt is not accepted - the server would refuse every player.");
                Log("Read https://agreements.battlebit.cloud/GameServerTos.pdf, then set");
                Log("  Accept EULA & TOS=True   in eula.txt");
            }
        }
        catch { }
    }

    static bool StartGameServer(ServerProperties props, string gameRoot)
    {
        var logFile = Path.Combine(Dir, "game_server.log");
        var args = props.GameServerArguments(logFile);
        Log($"Starting game server: {args}");
        try
        {
            _game = Process.Start(new ProcessStartInfo
            {
                FileName = Path.Combine(gameRoot, "BattleBit.exe"),
                Arguments = args,
                WorkingDirectory = gameRoot,
                UseShellExecute = false,
                RedirectStandardInput = true,   // UnityConsole reads commands from here
            });
            return _game != null;
        }
        catch (Exception ex)
        {
            Log($"Could not start the game server: {ex.Message}");
            return false;
        }
    }

    static void StopGameServer()
    {
        try
        {
            if (_game is { HasExited: false })
            {
                Send("stop");
                if (!_game.WaitForExit(5000)) _game.Kill(entireProcessTree: true);
            }
        }
        catch { }
    }

    /// Writes a line to the game server's stdin. UnityConsole picks it up with
    /// Console.ReadLine and hands it to ServerHandler.OnConsoleCommand.
    static bool Send(string command)
    {
        if (_game is null || _game.HasExited) return false;
        try
        {
            _game.StandardInput.WriteLine(command);
            _game.StandardInput.Flush();
            return true;
        }
        catch { return false; }
    }

    static async Task SendStartupCommands(ServerProperties props, CancellationToken ct)
    {
        var commands = props.StartupCommands().ToList();
        if (commands.Count == 0) return;

        // The game has to finish loading its map before it will accept commands.
        Log("Waiting for the game server to come up before sending startup commands...");
        await Task.Delay(TimeSpan.FromSeconds(props.GetInt("startup-command-delay", 25)), ct);

        foreach (var command in commands)
        {
            if (ct.IsCancellationRequested) return;
            Log($"> {command}");
            Send(command);
            await Task.Delay(500, ct);
        }
    }

    // ==================== Operator console ====================

    static async Task ConsoleLoop(CancellationTokenSource cts)
    {
        while (!cts.IsCancellationRequested)
        {
            var line = await Task.Run(Console.ReadLine);
            if (line is null) { await Task.Delay(500); continue; }

            var command = line.Trim();
            if (command.Length == 0) continue;

            switch (command.ToLowerInvariant())
            {
                case "stop":
                case "quit":
                case "exit":
                    return;

                case "help":
                    PrintHelp();
                    continue;

                case "status":
                    Log(_game is { HasExited: false }
                        ? $"Game server running (pid {_game.Id}). Master on the configured ports."
                        : "Game server is NOT running.");
                    continue;
            }

            if (!Send(command))
                Log(_game is null
                    ? "Master-only mode - there is no game server here to send that to."
                    : "Game server is not running - cannot send that.");
        }
    }

    static void PrintHelp()
    {
        Log("");
        Log("  forcestart            start the round without waiting for players");
        Log("  join bot a 5          add 5 bots to team A (b for team B)");
        Log("  remove bot            remove bots");
        Log("  setsize tiny          tiny | small | medium | ultra");
        Log("  set fps 60            server tick rate");
        Log("  kick all              kick everyone");
        Log("  announce <text>       message to all players");
        Log("  status                is the game server alive");
        Log("  stop                  shut down the server and the master");
        Log("");
        Log("  Anything else is passed straight to the game server console.");
        Log("");
    }

    static void Log(string message)
    {
        var line = message.Length == 0 ? "" : $"{DateTime.Now:HH:mm:ss} {message}";
        Console.WriteLine(line);
        try { File.AppendAllText(LogPath, line + Environment.NewLine); } catch { }
    }
}
```

```md
This is the server box. It hosts **your own master server** (the thing that lists
servers and holds player accounts) and runs **a game server** alongside it. Players

You do not need the official BattleBit servers for any of this. Your cluster is yours.

|---|---|
| `forcestart` | Start the round immediately. |
| `join bot a 5` | Add 5 bots to team A (`b` for team B). |
| `remove bot` | Remove bots. |
| `setsize tiny` | `tiny` / `small` / `medium` / `ultra`. |
| `set fps 60` | Change tick rate live. |
| `kick all` | Kick everyone. |
| `announce <text>` | Message every player. |
| `status` | Is the game server alive. |
| `stop` | Shut down the game server and the master. |

Anything not in that list is passed straight through to the game's own console.

---

## Accounts and progression

Players create an account the first time they log in to your cluster. Name and password,
at least 8 characters with a number in it.

Accounts are **per cluster**. The same name on someone else's server is a different
account with different progress. Passwords are stored as PBKDF2-SHA256 hashes, never in
plain text.

Progress lives in `accounts.json`. To wipe a player, delete their entry. To wipe the
cluster, delete the file.

---

## Anti-cheat

Off by default. Turn it on with `anticheat-enabled=true`.

It has two halves:

- **Server side** - always the authority. Holds the ban list, counts detections, decides
  who gets banned. Players cannot influence it.
- **Client side (the guard)** - optional, opt-in by each player in their launcher. It
  reports things only visible on their machine: memory editors running, DLLs injected
  into the game, a debugger attached.

A single detection never bans anyone. It takes `anticheat-reports-to-ban` reports of the
same thing inside `anticheat-window-minutes`, because overlays and security software do
produce false positives.

| key | what it does |
|---|---|
| `anticheat-enabled` | Master switch. |
| `anticheat-require-guard` | Refuse logins from players who have not enabled the guard. |
| `anticheat-reports-to-ban` | Default 3. |
| `anticheat-window-minutes` | Default 30. |
| `anticheat-ban-by-hardware-id` | Ban the machine as well as the account. |

### Sharing ban lists

Export your bans:

    http://localhost:29300/_revival/bans/export

Import someone else's by POSTing that JSON to `/_revival/bans/import`.

By default imported bans land in `bans.pending.json` for you to read **before** they take
effect. Set `anticheat-auto-apply-imported-bans=true` only for sources you genuinely
trust: a shared list is a false-positive amplifier, and one bad detector on someone
else's cluster should not silently ban your players.

Entries below `anticheat-minimum-import-confidence` are dropped outright.

### What it will not do

The guard runs in user space. Anyone able to patch it can remove it, and hardware ids can
be spoofed. `anticheat-require-guard` means *no guard, no token, no join*, which raises
the bar - it does not close the door. Catching a determined cheater needs kernel-level
anti-cheat, which this is not.

---

## Networking

| port | protocol | who connects |
|---|---|---|
| `29300` | TCP | players (master server) |
| `29301` | TCP | your game servers |
| `30000` | UDP | players (game traffic) |
| `30001` | UDP | the game server also binds `server-port + 1` |

Forward those to the machine running the server, and allow them through the firewall.

**Bandwidth is the real limit, not CPU.** At 60Hz each player needs roughly
0.7 Mbps **upstream** from your server. A 32v32 server wants ~45 Mbps up; a full 127v127
wants well over 100 Mbps. Home connections rarely have that, which is why big servers
live on a VPS. Your own 8v8 testing is fine at home.

CPU wants **single-thread speed** rather than core count - the simulation loop is largely
single-threaded. Allow 6-8 GB RAM for a big server.

| `bans.json` | Your ban list. |
| `bans.pending.json` | Imported bans waiting for your review. |
```

```md
# Troubleshooting

Every problem in here is one that actually happened while building this, with the real
cause rather than a guess.

**Read the logs first.** Most of these announce themselves clearly in one of:

| log | what it covers |
|---|---|
| `server_console.log` | The server box: master startup, logins, bans, packets. |
| `game_server.log` | Unity's log for the game server. Crashes and exceptions. |

## Server sits forever on "Connecting to master server"

The master's port is bound but nothing is accepting on it.

Almost always: the master was started, then stopped, and the listening socket was never
released - so the game server's connection succeeds at the TCP level and then nothing
ever services it. It hangs with nothing in any log, which is what makes it confusing.

**Fix:** stop everything, confirm nothing is still listening, start again.

```
netstat -ano | findstr "29300 29301"
```

If something is listed and the server box is not running, kill that process.

A failed login used to leave the master in exactly this half-dead state. That is fixed,
but the symptom is worth recognising if you ever see it again.

---

## Players cannot see your server in the browser

Work down this list:

1. **Is the game server registered?** `server_console.log` should contain a `hail:` line
   with your server name. No hail means the game server never reached the master.
2. **Build mismatch.** The browser shows `BUILDS DON'T MATCH` and refuses to join if the
   version string differs. Everyone must be on the same BattleBit build.
3. **Ports.** `29300` and `29301` TCP forwarded and allowed through the firewall.
4. **Wrong address.** Players need your **public** IP, not `127.0.0.1`. Check with
   whatismyip. On the same LAN, use the LAN IP.

---

## "EULA is not accepted"

The game server reads `eula.txt` **from its working directory**, which is your BattleBit
folder - not the server box folder. Open it and set:

```
Accept EULA & TOS=True
```

Symptom if you miss it: the server runs, registers, looks completely fine, and silently
refuses every player.

---

## Round never starts / "Waiting for 2 players"

The game server waits for a minimum player count. For solo testing:

- Type `forcestart` in the server window, or
- Set `auto-forcestart=true` in `server.properties`, or
- Add bots: `join bot a 1`

There is no minimum-players setting in the game to lower - `forcestart` is the way.

---

## Player cannot log in

| message | cause |
|---|---|
| `Wrong password for that name on this master server` | That account exists with a different password. Accounts are per cluster. Pick another name, or delete the entry from `accounts.json`. |
| `Password must contain at least one number` | Rules are 8+ characters with a digit. |
| `Banned from this master server` | See below. |
| `requires the launcher's anti-cheat guard` | `anticheat-require-guard=true`. The player ticks the guard box in their launcher. |
| `Could not reach the master server` | Wrong IP, port not open, or the server is not running. |

**Forgot a password?** There is no recovery by design. Delete that account's entry from
`accounts.json` and let them create it again. They lose their progress.

---

## Someone was banned by mistake

Open `bans.json`, delete the entry, restart the server.

Then raise `anticheat-reports-to-ban` or switch off the detector that fired. Each entry
records which detector caused it and what it saw, so you can tell which.

A false positive usually means a legitimate overlay or security tool. Add its DLL to
`IgnoredModules` in the player's `guard.json`, or its process name out of
`FlaggedProcesses`.

**If you develop on the same machine you play on**, prune `FlaggedProcesses` - it ships
flagging debuggers and memory editors like x64dbg and Cheat Engine, which are normal
tools to have installed.

---

## Imported bans did nothing

That is the default. They wait in `bans.pending.json` for you to read them. Set
`anticheat-auto-apply-imported-bans=true` if you trust the source.

Entries below `anticheat-minimum-import-confidence` (default 80) are dropped and never
reach the pending file.

---

## The game crashes when a player joins

Check the **gameplay log** in your BattleBit folder (newest by modified time) for a
`NullReferenceException`. The known one is in `OnClientConnecting`, caused by a null
player name, and is already patched by `patch_auth.ps1`.

If you reinstalled or verified game files, the patches were overwritten. Re-run:

```
patch_auth.ps1
```

It is safe to run repeatedly - it reports `already patched` for anything still in place.

---

## Tab/scoreboard is very laggy

Usually a player count far higher than the server is actually running - the scoreboard is
rendering hundreds of rows. Check that progression values are sane in `accounts.json`;
absurd stat values can push the UI into rendering a full 127v127 scoreboard.

---

## Player name shows as a long number

A known limitation. If the master cannot deliver a name, the UI falls back to the raw
player id. Check that the player logged in through the launcher - without a session the
master has no name to send.

---

## Starting over

| to reset | delete |
|---|---|
| one player's progress | their entry in `accounts.json` |
| all accounts and progress | `accounts.json` |
| all bans | `bans.json` and `bans.pending.json` |
| all settings | `server.properties`, `anticheat.json`, `progression.json` |

They are all recreated with defaults on the next start. Back up `accounts.json` first -
it is the only file holding anything you cannot regenerate.
```

```ps1
# Listens on the port the master advertises in place of the real one, so the client's
# genuine Game_Hail join packet lands here and can be dumped byte for byte.
# Run this, then click the server in the browser.

# Well clear of the game server: it binds Port AND Port+1, so 30001 kills its startup.
$port = 31500
$out  = Join-Path $PSScriptRoot "join_capture.txt"
"=== listening on UDP $port ===" | Set-Content $out

$udp = New-Object System.Net.Sockets.UdpClient $port
$udp.Client.ReceiveTimeout = 900000   # 15 min: must outlive client startup + your click
$ep  = New-Object System.Net.IPEndPoint ([System.Net.IPAddress]::Any), 0

Write-Output "Listening on UDP $port. Click the server in the browser now."
Write-Output "Writing to $out"

for ($n = 1; $n -le 12; $n++) {
    try { $data = $udp.Receive([ref]$ep) }
    catch { Write-Output "timeout - stopping"; break }

    $hex = ($data | ForEach-Object { $_.ToString('X2') }) -join ' '
    $asc = -join ($data | ForEach-Object { if ($_ -ge 32 -and $_ -le 126) { [char]$_ } else { '.' } })

    $type = $data[0]
    $name = switch ($type) {
        127 {"Game_Hail"} 128 {"Browser_ServerInfoRequest"} 129 {"Browser_PingRequest"}
        240 {"MTUDiscovery_Request"} 251 {"SlotReserving_ReserveSlot"} default {"type $type"}
    }

    $msg = "[$n] from $ep  len=$($data.Length)  $name"
    Write-Output $msg
    Add-Content $out $msg
    Add-Content $out "hex:   $hex"
    Add-Content $out "ascii: $asc"
    Add-Content $out ""
}
$udp.Close()
Write-Output "done - see $out"
```

`patch_auth.ps1`:

```ps1
# Makes the client stop gating on master-server auth state.
# These are static bool property getters; each is replaced with a constant return.
#   b0 01 c3 = mov al,1 ; ret   (true)
#   31 c0 c3 = xor eax,eax; ret (false)
# Offsets are file offsets from Il2CppDumper for build "Production 2.2.5 Hotfix".
# Restore with: copy GameAssembly.dll.orig over GameAssembly.dll

$dll = "G:\SteamLibrary\steamapps\common\BattleBit Revival\GameAssembly.dll"

$ret_true  = [byte[]](0xB0, 0x01, 0xC3)
$ret_false = [byte[]](0x31, 0xC0, 0xC3)

# The bool getters all start with the same class-init prologue.
$getterPrologue = [byte[]](0x48, 0x83, 0xEC, 0x28, 0x80, 0x3D)

# The server-key validator is a full function, so it has its own prologue:
#   mov [rsp+10],rdx ; push rbp ; push rdi ; push r13 ; push r14 ; push r15
$validatorPrologue = [byte[]](0x48, 0x89, 0x54, 0x24, 0x10, 0x55, 0x57, 0x41, 0x55)

$patches = @(
    @{ Name = "get_HasToken";                Offset = 0x13B4AF0; Bytes = $ret_true;  Expect = $getterPrologue },
    @{ Name = "get_IsAccountNew";            Offset = 0x13B4B50; Bytes = $ret_false; Expect = $getterPrologue },
    @{ Name = "get_IsSteamDown";             Offset = 0x13B4CB0; Bytes = $ret_false; Expect = $getterPrologue },
    @{ Name = "get_FamilyShareNotSupported"; Offset = 0x13B4A90; Bytes = $ret_false; Expect = $getterPrologue },
    @{ Name = "get_UnableToRetriveTicket";   Offset = 0x13B4E10; Bytes = $ret_false; Expect = $getterPrologue },

    # Server-key check, used by BOTH sides (client and server share this binary).
    # Original does Aes.Create(), transforms the 16-byte key, BitConverter.ToUInt64 and
    # compares against a challenge ulong. We cannot reproduce that without the mode, IV
    # and plaintext, so the gate is removed and access control lives in the master server
    # instead (password-gated cluster, and it is the only source of server listings).
    @{ Name = "ServerKeyValidator (AES)";    Offset = 0x11D1100; Bytes = $ret_true;  Expect = $validatorPrologue },

    # Rich-text tag stripper (RVA 0x2D761D0), called on the player name from
    # Networking.ServerHandler+<OnClientConnecting>. It throws NullReferenceException on
    # a null string, which kills the connection coroutine and fails every join with
    # NoResponse. The name comes from PlayerStats.MasterServerUsername (offset 0x58),
    # which is null whenever the server takes the path that skips the master-server
    # stats request.
    #
    # The null branch is redirected from the throw helper (0x2D76350) to the loop exit
    # (0x2D762EE). The static StringBuilder is already cleared by that point, so a null
    # name now yields an empty string instead of an exception.
    #   0F 84 F0 00 00 00 = je 0x2D76350 (throw)
    #   0F 84 8E 00 00 00 = je 0x2D762EE (loop exit)
    # String reads from the master server (RVA 0x236BC70) bounds-check the read position
    # against a limit field at [stream+0x20] rather than the buffer length, and that
    # field is not valid on an incoming registry stream - so EVERY string the master
    # sends is dropped, silently, by returning null instead of throwing. The sibling
    # readers (bool/u16/u32/u64) check [array+0x18] instead, which is why numeric stats
    # arrive correctly and only strings vanish.
    #
    # Both guards are short jumps to the return-null path; NOPing them lets the read
    # proceed. The array-bounds checks immediately after (cmp against [rbx+0x18]) are
    # left intact, and the master pads every reply, so there is always data present.
    #   7C 4D = jl ret_null  (limit - readPos < 2)
    #   7C 2E = jl ret_null  (remaining < declared length)
    @{ Name = "ReadString limit guard"; Offset = 0x236AE95
       Bytes  = [byte[]](0x90, 0x90)
       Expect = [byte[]](0x7C, 0x4D) },
    @{ Name = "ReadString length guard"; Offset = 0x236AEB4
       Bytes  = [byte[]](0x90, 0x90)
       Expect = [byte[]](0x7C, 0x2E) },

    # Force the player-name read to a known position.
    #
    # ReadFrom_MasterServer_GameServerSide reads the username LAST, after a chain of
    # sub-readers whose widths all verify individually but whose total does not land
    # where it should: an exhaustive scan showed the cursor is nowhere in payload
    # 188-800, so something upstream moves it unpredictably. Rather than keep guessing
    # which field, this overwrites the Role read (8 bytes we do not use) with an
    # instruction that sets the stream's read position immediately before the string
    # is read.
    #
    # The value is 218, not 209: the stream buffer holds the WHOLE packet including
    # the 9-byte header (uint64 sequence + type byte), which the dispatcher has
    # already consumed, so the body starts at buffer position 9. The master writes
    # the name at body offset 209, i.e. buffer 218. Being 9 short is why every
    # offset tried from the master side missed.
    #
    #   original: xor edx,edx / mov rcx,rbx / call ReadUInt64 / xor edx,edx / mov [rbp+50],rax
    #   patched : mov dword ptr [rbx+24], 209 / xor edx,edx / nop padding
    #
    # rbx holds the stream and [rbx+0x24] is its read cursor (confirmed across every
    # reader helper). The xor edx,edx is preserved because ReadString takes it as its
    # second argument. Role is left at its constructed default of 0.
    @{ Name = "NameReadPosition"; Offset = 0x12A1DE2
       Bytes  = [byte[]](0xC7, 0x43, 0x24, 0xDA, 0x00, 0x00, 0x00,
                         0x33, 0xD2,
                         0x90, 0x90, 0x90, 0x90, 0x90, 0x90, 0x90)
       Expect = [byte[]](0x33, 0xD2, 0x48, 0x8B, 0xCB, 0xE8, 0xF4, 0x70, 0x0C, 0x01,
                         0x33, 0xD2, 0x48, 0x89, 0x45, 0x50) },

    @{ Name = "NameSanitizer null guard"; Offset = 0x2D7545A
       Bytes  = [byte[]](0x0F, 0x84, 0x8E, 0x00, 0x00, 0x00)
       Expect = [byte[]](0x0F, 0x84, 0xF0, 0x00, 0x00, 0x00) }
)

if (-not (Test-Path "$dll.orig")) {
    Copy-Item $dll "$dll.orig"
    Write-Output "saved backup -> GameAssembly.dll.orig"
}

$d = [System.IO.File]::ReadAllBytes($dll)
$applied = 0

foreach ($p in $patches) {
    $off = $p.Offset
    $expect = $p.Expect
    $actual = $d[$off..($off + $expect.Length - 1)]
    $matches = -not (Compare-Object $actual $expect -SyncWindow 0)

    # Compared against the replacement, so a patch that is not a constant-return
    # prologue is still recognised as already applied.
    $current = $d[$off..($off + $p.Bytes.Length - 1)]
    $isPatched = -not (Compare-Object $current $p.Bytes -SyncWindow 0)

    if ($matches) {
        for ($i = 0; $i -lt $p.Bytes.Length; $i++) { $d[$off + $i] = $p.Bytes[$i] }
        $verb = if ($p.Bytes[0] -eq 0xB0) { "returns true" }
                elseif ($p.Bytes[0] -eq 0x31) { "returns false" }
                else { "branch redirected" }
        "patched {0,-30} @0x{1:X7} -> {2}" -f $p.Name, $off, $verb
        $applied++
    }
    elseif ($isPatched) {
        "already patched {0,-22} @0x{1:X7}" -f $p.Name, $off
    }
    else {
        "SKIPPED {0,-29} @0x{1:X7} unexpected bytes - wrong build?" -f $p.Name, $off
    }
}

if ($applied -gt 0) {
    [System.IO.File]::WriteAllBytes($dll, $d)
    Write-Output ""
    Write-Output "$applied patch(es) written to GameAssembly.dll"
} else {
    Write-Output ""
    Write-Output "nothing to do"
}

```

`patch_gameassembly.py`:

```py
"""Make a COPY of BattleBit's GameAssembly.dll skip the client-side Easy Anti-Cheat check.
Build: Production 2.2.5 Hotfix. Two AntiCheatManager checks (state ok / client ready) are made to return true.
Usage: python patch_gameassembly.py <in GameAssembly.dll> <out GameAssembly.dll>"""
import sys
PATCHES = [  # (file offset, expected original bytes, new bytes)
    (0xdf2f30, bytes.fromhex('40534883ec20803daf9d4803'), bytes.fromhex('b001c3')),  # AntiCheatManager state check
    (0xdf10c0, bytes.fromhex('4883ec28803d22bc48030075'), bytes.fromhex('b001c3')),  # AntiCheatManager client-ready check
]
src, dst = sys.argv[1], sys.argv[2]
d = bytearray(open(src, 'rb').read())
```

`patch_metadata.py`:

```py
import struct, sys
ORIG_API = b'https://api.battlebit.cloud/'
ORIG_GS = b'ws://server.battlebit.cloud/GameServers'
def patch(src, dst, api=b'http://127.0.0.1:29300/', gs=b'ws://127.0.0.1:29301/GameServers'):
    d = bytearray(open(src, 'rb').read())
    h = struct.unpack_from('<66I', d, 0)
    lit_off, lit_size, data_off = h[2], h[3], h[4]
    todo = {ORIG_API: api, ORIG_GS: gs}
    for k in range(lit_size // 8):
        ln, di = struct.unpack_from('<Ii', d, lit_off + 8 * k)
        s = bytes(d[data_off + di:data_off + di + ln])
        if s in todo:
            new = todo.pop(s)
            d[data_off + di:data_off + di + ln] = new + b'\0' * (ln - len(new))
            struct.pack_into('<I', d, lit_off + 8 * k, len(new))
            print(f'literal {k}: {s.decode()} -> {new.decode()}')
    if todo: raise SystemExit(f'not found: {list(todo)}')
    open(dst, 'wb').write(d)
if __name__ == '__main__':
    a = sys.argv[1:]; patch(a[0], a[1], *(x.encode() for x in a[2:4]))
```
