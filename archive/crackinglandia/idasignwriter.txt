`README.md`:

```md
# IDA SigWriter

Plugin para IDA Pro que genera patrones de código a partir de la selección del
usuario, con GUI acoplable, wildcards opcionales y exportación a varios formatos.

Hay dos versiones con la misma funcionalidad:

| Versión | IDA | Qt | Ubicación |
|---|---|---|---|
| 8.2 | IDA Pro 8.2 | PyQt5 | `idasigwriter_plugin.py` + `idasigwriter/` |
| 9.3+ | IDA Pro 9.3 en adelante | PySide6 (Qt 6) | `ida93/SigWriter/` |

Para binarios **.NET** (bytecode CIL) hay un plugin aparte, también para 8.2 y
9.3+, en [`dotnet/`](dotnet/README.md). Cada plugin se activa solo en su tipo de
base de datos, así que pueden instalarse juntos.

## Screenhost

![](./screenshots/idasignwriter.png)

## Instalación

Directorio de plugins: `<IDA>/plugins` o el de usuario
(`%APPDATA%\Hex-Rays\IDA Pro\plugins` / `~/.idapro/plugins`).

**IDA 8.2** — copia:

```
idasigwriter_plugin.py
idasigwriter/           (la carpeta completa)
```

**IDA 9.3+** — copia la carpeta completa `ida93/SigWriter/` (la que contiene
`ida-plugin.json`):

```
plugins/SigWriter/ida-plugin.json
plugins/SigWriter/sigwriter_entry.py
plugins/SigWriter/sigwriter9/
```

Ninguna requiere dependencias externas (PyQt5 / PySide6 vienen con IDA). Si las
dos versiones de IDA comparten el directorio de plugins de usuario, puedes tener
ambas instaladas: la versión 8.2 se desactiva sola en IDA 9.x sin importar PyQt5
(así no aparece el diálogo del shim de PyQt5).

## Uso

1. Selecciona código en *IDA View* (o bytes en *Hex View*).
2. Click derecho → **Generar patron (SigWriter)...**, pulsa **Ctrl+Alt+S**,
   o usa *Edit → Plugins → SigWriter*.
   Si no hay selección se usa el elemento bajo el cursor.

La ventana tiene:

- **Rango**: inicio/fin editables (Enter para aplicar), *Selección actual*,
  *Función actual* y *Único desde el cursor* (agrega instrucciones hasta que el
  patrón coincida en un único lugar de la base de datos, máx. 256 bytes).
- **Wildcards**: interruptor general *Permitir wildcards* y reglas automáticas:
  destinos de saltos/calls, referencias a memoria global (incl. RIP-relative),
  inmediatos que son direcciones, todos los inmediatos, desplazamientos
  `[reg+disp]`, bytes con relocaciones (fixups) e instrucción completa cuando el
  procesador no informa dónde está el operando (ARM/MIPS, etc.).
- **Rejilla de bytes**: una fila por instrucción. *Click* en un byte alterna su
  wildcard manualmente (naranja = automático, violeta = manual, verde = forzado
  fijo). *Doble click* en la dirección salta a ella.
- **Exportar**:
  | Formato | Ejemplo |
  |---|---|
  | Standalone IDA | `E8 ? ? ? ? 48 8B 05 ? ? ? ?` |
  | Standalone x64dbg/CE | `E8 ?? ?? ?? ?? 48 8B 05 ?? ?? ?? ??` |
  | Standalone sin wildcards | `E8 10 20 30 40 48 8B 05 01 02 03 04` |
  | Array C/C++ | `const unsigned char pattern[] = {...};` + máscara `"x????xxx"`, bitmap y estilo `"\x48\x8B"` |
  | Regla YARA | `rule pattern { strings: $pattern = { E8 ?? ... } condition: $pattern }` |
  | Patrón YARA (checkbox *Solo patron*) | `{ E8 ?? ?? ?? ?? 48 8B 05 }` |
  | Blob binario | `.bin` (wildcards = 0x00) + `.mask` (0xFF fijo / 0x00 wildcard) si hay wildcards |

  Botones: *Copiar*, *Guardar...*, *Imprimir en Output* y *Buscar coincidencias*
  (lista hasta 100 direcciones en la ventana Output).

Notas:
- YARA (regla y *Solo patrón*): 28 bytes por fila y como máximo 20 filas por
  string (560 bytes). Si el patrón es más largo se divide en `$pattern_p1`,
  `$pattern_p2`, ... y la condición exige que cada pedazo esté en su offset
  exacto respecto de `$pattern_p1` (`$pattern_p2 at @pattern_p1[i] + 560`).
- YARA no admite hex strings que empiecen o terminen en wildcard, así que se
  recortan (se indica en `meta`). El nombre de la regla/variable se sanea.
- Si *Permitir wildcards* está desactivado, todos los formatos usan los bytes exactos.
```

```
## Diferencias 8.2 → 9.3+

Verificadas contra las fuentes oficiales de IDAPython 9.3.0 y 9.5.0
(github.com/HexRaysSA/ida-sdk):

| 8.2 | 9.3+ |
|---|---|
| PyQt5 (`sip`) | PySide6 (`shiboken6`); `TWidgetToQtPythonWidget` |
| `bin_search(start, end, image, mask, step, flags)` | eliminado → `ida_bytes.find_bytes(bytes, start, range_end=, mask=, flags=)` |
| `BWN_DUMP` | `BWN_HEXVIEW` |
| `plugin_t` + `PLUGIN_KEEP` | `PLUGIN_MULTI` + `plugmod_t` |
| plugin suelto | carpeta con `ida-plugin.json` |

`ida_fixup.fixup_data_t`.
```

`dotnet/README.md`:

```md
# SigWriter .NET

Versión de SigWriter para binarios **.NET**. Genera patrones del bytecode CIL
(MSIL) seleccionado en IDA, con la misma GUI y los mismos formatos de exportación
que el plugin x86: IDA, x64dbg, sin wildcards, C/C++, YARA (regla o solo patrón),
blob binario, búsqueda de coincidencias y "Único desde el cursor".

Es un plugin aparte. Cada plugin se activa solo en su tipo de base de datos
(`ida_idp.ph_get_id() == PLFM_NET`), así que pueden instalarse juntos y comparten
el atajo **Ctrl+Alt+S** sin conflicto.

## Instalación

| IDA | Copiar a `plugins/` |
|---|---|
| 8.2 | `ida82/idasigwriter_net_plugin.py` + `ida82/idasigwriter_net/` |
| 9.3+ | la carpeta `ida93/SigWriterNet/` completa (contiene `ida-plugin.json`) |

Uso: selecciona IL en *IDA View* → click derecho → **Generar patron .NET
(SigWriter)...**, o Ctrl+Alt+S, o *Edit → Plugins → SigWriter .NET*.

## Wildcards automáticos

El decodificador es propio (`cil.py`) y sigue ECMA-335 Partición III. No depende
de los mnemónicos de IDA. Cada byte de operando se clasifica:

| Opción | Operandos | Por defecto |
|---|---|---|
| Tokens de metadatos | `call`, `callvirt`, `newobj`, `ldfld`, `stfld`, `ldsfld`, `box`, `castclass`, `ldtoken`, `calli`, `constrained.`… | ✔ |
| Tokens de strings | `ldstr` (`0x70xxxxxx`) | ✔ |
| Conservar la tabla del token | deja fijo el byte alto del token (`06` MethodDef, `0A` MemberRef, `04` Field, `01` TypeRef, `02` TypeDef, `1B` TypeSpec, `2B` MethodSpec, `70` String) y solo pone wildcard en el RID | ✔ |
| Offsets de saltos | `br`, `brtrue`, `beq`, `leave` (cortos y largos) | ✔ |
| Tabla de switch | destinos de `switch`; el número de casos queda fijo porque determina el largo | ✔ |
| Índices de locals/args | `ldloc.s`, `stloc.s`, `ldarg.s`, `ldloca`, `starg`… | ✘ |
| Constantes | `ldc.i4.s`, `ldc.i4`, `ldc.i8`, `ldc.r4`, `ldc.r8`, flags de `unaligned.`/`no.` | ✘ |

Ejemplo (`call` a un MethodDef, `ldstr`, `br.s`):

```
28 ?? ?? ?? 06    72 ?? ?? ?? 70    2B ??
```

Los opcodes de 2 bytes (`FE xx`: `ceq`, `ldftn`, `initobj`, `constrained.`…)
conservan los dos bytes. Los bytes que IDA no marca como código (cabeceras de
método, datos) se copian tal cual, sin wildcards automáticos. Como en el plugin
x86, cualquier byte se puede alternar a mano con un click.

Con todas las opciones activadas y "Conservar la tabla del token" desactivada,
el resultado equivale al del script original `dotnet_rule_creator.py`: opcode
fijo y todo el operando con wildcard.

## Validación

- Tabla de 219 opcodes generada de `src/coreclr/inc/opcode.def` (dotnet/runtime),
  más `no.` (`FE 19`), que está en ECMA-335 III.2.2 pero CoreCLR marca como no usado.
- Comparado contra el decodificador independiente **dncil** (Mandiant) sobre
  todos los métodos de Newtonsoft.Json 13.0.3: 4 092 métodos y 99 662
  instrucciones, con 0 diferencias en opcode, largo y operandos.
- `tests/il_samples.json` contiene 3 métodos reales de esa assembly (MIT) con
  los valores esperados de dncil, así los tests no necesitan dncil.
```

`dotnet/ida82/idasigwriter_net/cil.py`:

```py
"""
CIL (ECMA-335 / .NET IL bytecode) decoder used to build signatures.

Pure Python, no IDA imports, so it can be unit-tested outside IDA and is
shared verbatim by the IDA 8.2 and IDA 9.3+ .NET plugins.

Sources:
  * ECMA-335 6th ed., Partition III "CIL Instruction Set" (encodings and
    operand formats; all operands are little-endian).
  * dotnet/runtime src/coreclr/inc/opcode.def (master opcode table); the
    OPCODES table below was generated from it, plus `no.` (FE 19), which is
    in ECMA-335 III.2.2 but marked unused by CoreCLR.

Encoding: one-byte opcodes 0x00-0xE0, two-byte opcodes 0xFE xx.
"""

import struct

# Operand formats (System.Reflection.Emit.OperandType names).
InlineNone = "InlineNone"                     # no operand
ShortInlineI = "ShortInlineI"                 # int8 (also unaligned./no. flags)
ShortInlineVar = "ShortInlineVar"             # uint8 arg/local index
ShortInlineBrTarget = "ShortInlineBrTarget"   # int8 branch offset
ShortInlineR = "ShortInlineR"                 # float32
InlineVar = "InlineVar"                       # uint16 arg/local index
InlineI = "InlineI"                           # int32
InlineBrTarget = "InlineBrTarget"             # int32 branch offset
InlineI8 = "InlineI8"                         # int64
InlineR = "InlineR"                           # float64
InlineMethod = "InlineMethod"                 # metadata token
InlineField = "InlineField"                   # metadata token
InlineType = "InlineType"                     # metadata token
InlineTok = "InlineTok"                       # metadata token (type/method/field)
InlineSig = "InlineSig"                       # StandAloneSig token (calli)
InlineString = "InlineString"                 # user-string token (0x70xxxxxx)
InlineSwitch = "InlineSwitch"                 # uint32 N + N * int32 offsets

OPERAND_SIZE = {
    InlineNone: 0,
    ShortInlineI: 1, ShortInlineVar: 1, ShortInlineBrTarget: 1,
    InlineVar: 2,
    InlineI: 4, InlineBrTarget: 4, ShortInlineR: 4,
    InlineMethod: 4, InlineField: 4, InlineType: 4, InlineTok: 4,
    InlineSig: 4, InlineString: 4,
    InlineI8: 8, InlineR: 8,
    # InlineSwitch is variable: 4 + 4 * N
}

# Field kinds produced by the decoder; each maps to a wildcard option.
F_TOKEN = "token"                 # Method/Field/Type/Tok/Sig tokens
F_STRING = "string"               # ldstr user-string token
F_BRANCH = "branch"               # br*, leave* offsets
F_SWITCH_COUNT = "switch_count"   # N in switch (never wildcarded)
F_SWITCH_TARGET = "switch_target"
F_VAR = "var"                     # ldarg/ldloc/... indices
F_IMM = "imm"                     # ldc.* constants, unaligned./no. flags

_KIND_OF = {
    InlineMethod: F_TOKEN, InlineField: F_TOKEN, InlineType: F_TOKEN,
    InlineTok: F_TOKEN, InlineSig: F_TOKEN,
    InlineString: F_STRING,
    ShortInlineBrTarget: F_BRANCH, InlineBrTarget: F_BRANCH,
    ShortInlineVar: F_VAR, InlineVar: F_VAR,
    ShortInlineI: F_IMM, InlineI: F_IMM, InlineI8: F_IMM,
    ShortInlineR: F_IMM, InlineR: F_IMM,
}

class Field(object):
    """An operand field inside an instruction: [offset, offset+size)."""

    __slots__ = ("kind", "offset", "size")

    def __init__(self, kind, offset, size):
        self.kind = kind
        self.offset = offset
        self.size = size

    def __repr__(self):
        return "Field(%s, %d, %d)" % (self.kind, self.offset, self.size)


class Instruction(object):
    __slots__ = ("opcode", "name", "operand_type", "opcode_size", "size",
                 "fields", "operand")

    def __init__(self, opcode, name, operand_type, opcode_size, size, fields,
                 operand):
        self.opcode = opcode
        self.name = name
        self.operand_type = operand_type
        self.opcode_size = opcode_size   # 1 or 2 (0xFE prefix)
        self.size = size                 # total size in bytes
        self.fields = fields             # [Field]
        self.operand = operand           # decoded value (int/float/list) or None

    def __repr__(self):
        return "Instruction(%s, size=%d)" % (self.name, self.size)

    def text(self):
        """Simple ildasm-like rendering (used when IDA gives no text)."""
        op, t = self.operand, self.operand_type
        if op is None:
            return self.name
        if t in (InlineMethod, InlineField, InlineType, InlineTok, InlineSig,
                 InlineString):
            table = TOKEN_TABLES.get(op >> 24, "table 0x%02X" % (op >> 24))
            return "%s 0x%08X  // %s" % (self.name, op, table)
        if t == InlineSwitch:
            return "%s (%s)" % (self.name, ", ".join("%+d" % x for x in op))
        if t in (ShortInlineBrTarget, InlineBrTarget):
            return "%s %+d" % (self.name, op)
        return "%s %r" % (self.name, op)


def decode(data, offset=0):
    """
    Decode one CIL instruction from `data` (bytes) at `offset`.
    Returns an Instruction, or None for an unknown opcode or truncated data.
    """
    if offset >= len(data):
        return None
    b0 = data[offset]
    if b0 == 0xFE:
        if offset + 1 >= len(data):
            return None
        code, opsz = 0xFE00 | data[offset + 1], 2
    else:
        code, opsz = b0, 1
    entry = OPCODES.get(code)
    if entry is None:
        return None
    name, otype = entry
    pos = offset + opsz

    if otype == InlineSwitch:
        if pos + 4 > len(data):
            return None
        (n,) = struct.unpack_from("<I", data, pos)
        size = opsz + 4 + 4 * n
        if offset + size > len(data):
            return None
        targets = list(struct.unpack_from("<%di" % n, data, pos + 4)) if n else []
        fields = [Field(F_SWITCH_COUNT, opsz, 4)]
        fields += [Field(F_SWITCH_TARGET, opsz + 4 + 4 * i, 4) for i in range(n)]
        return Instruction(code, name, otype, opsz, size, fields, targets)

    osz = OPERAND_SIZE[otype]
    size = opsz + osz
    if offset + size > len(data):
        return None
    if osz == 0:
        return Instruction(code, name, otype, opsz, size, [], None)
    raw = data[pos:pos + osz]
    if otype == ShortInlineR:
        val = struct.unpack("<f", raw)[0]
    elif otype == InlineR:
        val = struct.unpack("<d", raw)[0]
    elif otype in (ShortInlineI, ShortInlineBrTarget):
        val = struct.unpack("<b", raw)[0]
    elif otype == ShortInlineVar:
        val = raw[0]
    elif otype == InlineVar:
        val = struct.unpack("<H", raw)[0]
    elif otype in (InlineI, InlineBrTarget):
        val = struct.unpack("<i", raw)[0]
    elif otype == InlineI8:
        val = struct.unpack("<q", raw)[0]
    else:  # tokens
        val = struct.unpack("<I", raw)[0]
    return Instruction(code, name, otype, opsz, size,
                       [Field(_KIND_OF[otype], opsz, osz)], val)


class CilWildcardOptions(object):
    """Which operand kinds are wildcarded automatically."""

    def __init__(self):
        self.enabled = True
        self.tokens = True            # method/field/type/tok/sig tokens
        self.strings = True           # ldstr tokens
        self.keep_token_table = True  # keep the token's table byte (MSB)
        self.branches = True          # branch / leave offsets
        self.switch_targets = True    # switch jump table
        self.vars = False             # arg / local indices
        self.immediates = False       # ldc.* constants


def auto_mask(insn, opts):
    """Per-byte wildcard mask (list of bool, len == insn.size)."""
    mask = [False] * insn.size
    if not opts.enabled:
        return mask
    for f in insn.fields:
        k = f.kind
        if k == F_TOKEN:
            want = opts.tokens
        elif k == F_STRING:
            want = opts.strings
        elif k == F_BRANCH:
            want = opts.branches
        elif k == F_SWITCH_TARGET:
            want = opts.switch_targets
        elif k == F_VAR:
            want = opts.vars
        elif k == F_IMM:
            want = opts.immediates
        else:   # F_SWITCH_COUNT: the count fixes the instruction length
            want = False
        if not want:
            continue
        size = f.size
        if k in (F_TOKEN, F_STRING) and opts.keep_token_table:
            size = 3   # little-endian: RID in bytes 0-2, table id in byte 3
        for i in range(f.offset, f.offset + size):
            mask[i] = True
    return mask
```

```py
def _hexdump(data, base, width=16):
    lines = []
    for i in range(0, len(data), width):
        chunk = data[i:i + width]
        hx = " ".join("%02X" % b for b in chunk)
        asc = "".join(chr(b) if 32 <= b < 127 else "." for b in chunk)
        lines.append("%08X  %-*s  %s" % (base + i, width * 3 - 1, hx, asc))
    return "\n".join(lines)
```

```py
def _read_bytes(ea, size):
    data = ida_bytes.get_bytes(ea, size)
    values, unloaded = [], []
    for i in range(size):
        if data is not None and i < len(data) and ida_bytes.is_loaded(ea + i):
            values.append(data[i])
            unloaded.append(False)
        else:
            values.append(0)
            unloaded.append(True)
    return values, unloaded

def _add_rows(sel, ea, offset, size, text, is_code):
    """Append `size` bytes as one or more rows of at most ROW_SIZE bytes."""
    first = True
    for off in range(0, size, ROW_SIZE):
        n = min(ROW_SIZE, size - off)
        sel.rows.append(Row(ea + off, offset + off, n,
                            text if first else "    (cont.)", is_code))
        first = False


def analyze_range(start, end, opts):
    """Build a Selection (bytes + automatic wildcards + rows) for [start, end)."""
    sel = Selection(start, end)
    values, unloaded = _read_bytes(start, end - start)
    data = bytes(bytearray(values))
    sel.values = values
    sel.auto_wild = list(unloaded)

    ea = start
    while ea < end:
        off = ea - start
        flags = ida_bytes.get_flags(ea)
        item_end = ida_bytes.get_item_end(ea)
        if item_end <= ea:
            item_end = ea + 1

        insn = None
        if ida_bytes.is_code(flags) and ida_bytes.is_head(flags):
            insn = cil.decode(data, off)

        if insn is not None:
            mask = cil.auto_mask(insn, opts)
            for i, m in enumerate(mask):
                if m:
                    sel.auto_wild[off + i] = True
            text = _disasm_text(ea) or insn.text()
            if item_end - ea != insn.size:
                # IDA and ECMA-335 disagree on the length: trust the spec,
                # but make it visible.
                text += "  [IDA: %d bytes, CIL: %d]" % (item_end - ea, insn.size)
            _add_rows(sel, ea, off, insn.size, text, True)
            ea += insn.size
            continue

        # Data, method headers, unknown opcodes or an instruction cut by the
        # end of the range: raw bytes, no automatic wildcards.
        chunk_end = min(item_end, end)
        head = ida_bytes.get_item_head(ea)
        if head == ea:
            text = _disasm_text(ea)
        else:
            text = "(+0x%X in item at 0x%X)" % (ea - head, head)
        if ida_bytes.is_code(flags) and head == ea:
            if item_end > end:
                text += "  [truncated]"
            else:
                text += "  [CIL no reconocido]"
        _add_rows(sel, ea, off, chunk_end - ea, text, False)
        ea = chunk_end
    return sel

    return (ida_bytes.BIN_SEARCH_FORWARD

def _find_next(ea, max_ea, image, wild):
    if hasattr(ida_bytes, "find_bytes"):
        # IDA 9.x: the (image, mask, step, flags) bin_search overload is gone.
        mask = bytes(bytearray(0x00 if w else 0xFF for w in wild))
        return ida_bytes.find_bytes(image, ea, range_end=max_ea, mask=mask,
                                    flags=_search_flags())
    # IDA 8.x: mask uses 1 = defined / 0 = wildcard (a leading 0xFF would
    # be read as "all bytes defined").
    mask = bytes(bytearray(0 if w else 1 for w in wild))
    return ida_bytes.bin_search(ea, max_ea, image, mask,
                                ida_bytes.BIN_SEARCH_FORWARD, _search_flags())


def find_matches(pattern, limit=100):
    """Return the list of addresses (up to `limit`) where `pattern` matches."""
    if len(pattern) == 0:
        return []
    p, lead = pattern.trimmed()
    if len(p) == 0:
        return []
    image = bytes(bytearray(p.masked_values()))
    min_ea, max_ea = db_bounds()
    results = []
    ea = min_ea
    while len(results) < limit:
        ea = _find_next(ea, max_ea, image, p.wild)
        if ea == BADADDR or ea is None:
            break
        results.append(ea - lead)
        ea += 1
    return results


def auto_unique(start, opts, max_len=256):
    """
    Grow a pattern instruction by instruction starting at `start` until it
    matches exactly one location. Returns (end, match_count).
    """
    ea = ida_bytes.get_item_head(start)
    end = ea
    count = 0
    ida_kernwin.show_wait_box("Buscando patron unico...")
    try:
        while end - ea < max_len:
            if ida_kernwin.user_cancelled():
                break
            nxt = ida_bytes.get_item_end(end)
            if nxt <= end:
                nxt = end + 1
            end = nxt
            sel = analyze_range(ea, end, opts)
            p = Pattern(sel.values, sel.auto_wild if opts.enabled else None, ea)
            if len(p.trimmed()[0]) == 0:
                continue
            count = len(find_matches(p, limit=2))
            if count == 1:
```

```py
"""
Pure-Python pattern model and exporters.

This module does not import anything from IDA, so it can be unit-tested
outside of IDA (see tests/test_pattern.py).
"""

import re

__all__ = [
    "Pattern",
    "fmt_ida",
    "fmt_double_qmark",
    "fmt_raw",
    "fmt_code_style",
    "fmt_c_array",
    "fmt_yara",
    "fmt_yara_string",
    "fmt_blob",
    "parse_pattern",
    "sanitize_identifier",
]


class Pattern(object):
    """A byte pattern: a list of byte values plus a per-byte wildcard flag."""

    def __init__(self, values, wild=None, start_ea=None):
        self.values = [int(v) & 0xFF for v in values]
        if wild is None:
            wild = [False] * len(self.values)
        if len(wild) != len(self.values):
            raise ValueError("values/wild length mismatch")
        self.wild = [bool(w) for w in wild]
        self.start_ea = start_ea

    def __len__(self):
        return len(self.values)

    def __eq__(self, other):
        return (isinstance(other, Pattern)
                and self.values == other.values
                and self.wild == other.wild)

    def __repr__(self):
        return "Pattern(%r)" % fmt_double_qmark(self)

    @property
    def wildcard_count(self):
        return sum(1 for w in self.wild if w)

    def without_wildcards(self):
        return Pattern(self.values, None, self.start_ea)

    def masked_values(self, fill=0x00):
        """Byte values with every wildcard replaced by `fill`."""
        return [fill if w else v for v, w in zip(self.values, self.wild)]

    def trimmed(self):
        """
        Return (pattern, leading_trim) with leading/trailing wildcards
        removed. `leading_trim` is the number of bytes dropped at the start.
        """
        lo, hi = 0, len(self.values)
        while lo < hi and self.wild[lo]:
            lo += 1
        while hi > lo and self.wild[hi - 1]:
            hi -= 1
        start = None if self.start_ea is None else self.start_ea + lo
        return Pattern(self.values[lo:hi], self.wild[lo:hi], start), lo

# Standalone text formats
# ---------------------------------------------------------------------------
def _fmt_tokens(pattern, wildcard_token, use_wildcards=True):
    out = []
    for v, w in zip(pattern.values, pattern.wild):
        out.append(wildcard_token if (w and use_wildcards) else "%02X" % v)
    return " ".join(out)


def fmt_ida(pattern, use_wildcards=True):
    """IDA / SigMaker style: `48 8B 05 ? ? ? ?`."""
    return _fmt_tokens(pattern, "?", use_wildcards)


def fmt_double_qmark(pattern, use_wildcards=True):
    """x64dbg / Cheat Engine / YARA-like style: `48 8B 05 ?? ?? ?? ??`."""
    return _fmt_tokens(pattern, "??", use_wildcards)


def fmt_raw(pattern):
    """Exact bytes, no wildcards at all: `48 8B 05 10 20 30 40`."""
    return _fmt_tokens(pattern, "", use_wildcards=False)


def fmt_code_style(pattern, use_wildcards=True):
    """
    Code style used by most C/C++ scanners:
    ("\\x48\\x8B\\x05\\x00", "xxx?")
    """
    data = "".join("\\x%02X" % v for v in pattern.masked_values()) \
        if use_wildcards else "".join("\\x%02X" % v for v in pattern.values)
    if use_wildcards:
        mask = "".join("?" if w else "x" for w in pattern.wild)
    else:
        mask = "x" * len(pattern)
    return data, mask

def sanitize_identifier(name, default="pattern"):
    name = _IDENT_RE.sub("_", (name or "").strip())
    if not name:
        name = default
    if name[0].isdigit():
        name = "_" + name
    return name[:128]


def fmt_c_array(pattern, name="pattern", use_wildcards=True, per_line=16):
    name = sanitize_identifier(name)
    has_wild = use_wildcards and pattern.wildcard_count > 0
    values = pattern.masked_values() if has_wild else pattern.values
    n = len(values)

    lines = []
    header = "// %d bytes" % n
    if has_wild:
        header += ", %d wildcards" % pattern.wildcard_count
    if pattern.start_ea is not None:
        header += ", generated from 0x%X" % pattern.start_ea
    lines.append(header)
    lines.append("// %s" % (fmt_ida(pattern) if has_wild else fmt_raw(pattern)))

    lines.append("const unsigned char %s[%d] = {" % (name, n))
    for i in range(0, n, per_line):
        chunk = ", ".join("0x%02X" % v for v in values[i:i + per_line])
        lines.append("    " + chunk + ("," if i + per_line < n else ""))
    lines.append("};")

    if has_wild:
        mask = "".join("?" if w else "x" for w in pattern.wild)
        lines.append("const char %s_mask[%d] = \"%s\";" % (name, n + 1, mask))
        lines.append("")
        lines.append("// Wildcard bitmap (1 = must match, 0 = wildcard)")
        lines.append("const unsigned char %s_bitmap[%d] = {" % (name, n))
        bits = [0 if w else 1 for w in pattern.wild]
        for i in range(0, n, per_line):
            chunk = ", ".join(str(b) for b in bits[i:i + per_line])
            lines.append("    " + chunk + ("," if i + per_line < n else ""))
        lines.append("};")

    data, mask = fmt_code_style(pattern, has_wild)
    lines.append("")
    lines.append("// Code style")
    lines.append("// \"%s\", \"%s\"" % (data, mask))
    return "\n".join(lines) + "\n"

# YARA

def _yara_escape(s):
    return str(s).replace("\\", "\\\\").replace("\"", "\\\"").replace("\n", " ")


# Layout limits for YARA hex strings: bytes per row, and rows per string.
# Longer patterns are split into $pattern_p1, $pattern_p2, ...
YARA_COLUMNS = 28
YARA_MAX_ROWS = 20


def _yara_trimmed(pattern, use_wildcards):
    """
    YARA does not accept hex strings that begin or end with a wildcard, so
    leading/trailing wildcards are trimmed. Returns (pattern, leading_trim).
    Raises ValueError if nothing is left after trimming.
    """
    p = pattern if use_wildcards else pattern.without_wildcards()
    p, lead = p.trimmed()
    if len(p) == 0:
        raise ValueError("The pattern contains only wildcards; "
                         "YARA needs at least one concrete byte.")
    return p, lead


def _yara_pieces(p, columns, max_rows):
    """
    Split an already-trimmed pattern into pieces of at most columns*max_rows
    bytes. Each piece is trimmed again (a piece cannot start or end with a
    wildcard either). Returns [(offset_in_p, piece)]; pieces made only of
    wildcards are dropped.
    """
    size = columns * max_rows
    pieces = []
    for off in range(0, len(p), size):
        chunk = Pattern(p.values[off:off + size], p.wild[off:off + size])
        chunk, lead = chunk.trimmed()
        if len(chunk):
            pieces.append((off + lead, chunk))
    return pieces


def _yara_hex_block(piece, columns, indent):
    """`{ .. }` on one line if it fits in a row, else one row per line."""
    tokens = ["??" if w else "%02X" % v for v, w in zip(piece.values, piece.wild)]
    rows = [" ".join(tokens[i:i + columns]) for i in range(0, len(tokens), columns)]
    if len(rows) == 1:
        return ["{ %s }" % rows[0]]
    return ["{"] + [indent + "    " + r for r in rows] + [indent + "}"]


def _yara_strings(p, columns, max_rows, indent):
    """Lines declaring $pattern (or $pattern_p1..N). Returns (lines, pieces)."""
    pieces = _yara_pieces(p, columns, max_rows)
    lines = []
    if len(pieces) == 1:
        block = _yara_hex_block(pieces[0][1], columns, indent)
        lines.append(indent + "$pattern = " + block[0])
        lines.extend(block[1:])
        return lines, pieces
    base = pieces[0][0]
    for k, (off, piece) in enumerate(pieces, 1):
        block = _yara_hex_block(piece, columns, indent)
        lines.append(indent + "// offset +%d (0x%X), %d bytes"
                     % (off - base, off - base, len(piece)))
        lines.append(indent + "$pattern_p%d = %s" % (k, block[0]))
        lines.extend(block[1:])
    return lines, pieces


def fmt_yara_string(pattern, use_wildcards=True,
                    columns=YARA_COLUMNS, max_rows=YARA_MAX_ROWS):
    """
    Only the YARA hex string(s), without the rule: `{ E8 ?? ?? 48 8B }`.
    Patterns longer than columns*max_rows bytes are emitted as
    `$pattern_p1 = {...}`, `$pattern_p2 = {...}`, ...
    """
    p, _ = _yara_trimmed(pattern, use_wildcards)
    lines, pieces = _yara_strings(p, columns, max_rows, "")
    if len(pieces) == 1:
        lines[0] = lines[0][len("$pattern = "):]
    return "\n".join(lines)


def fmt_yara(pattern, rule_name="pattern", use_wildcards=True, meta=None,
             columns=YARA_COLUMNS, max_rows=YARA_MAX_ROWS):
    """Build a complete YARA rule (see _yara_trimmed for trimming rules)."""
    rule_name = sanitize_identifier(rule_name, "pattern")
    p, lead = _yara_trimmed(pattern, use_wildcards)
    string_lines, pieces = _yara_strings(p, columns, max_rows, " " * 8)

    out = ["rule %s" % rule_name, "{"]
    meta_items = list((meta or {}).items())
    if p.start_ea is not None:
        meta_items.append(("address", "0x%X" % p.start_ea))
    if lead:
        meta_items.append(("note", "%d leading wildcard byte(s) trimmed" % lead))
    if len(pieces) > 1:
        meta_items.append(("pieces", "%d pieces of up to %d bytes, %d bytes total"
                           % (len(pieces), columns * max_rows, len(p))))
    if meta_items:
        out.append("    meta:")
        for k, v in meta_items:
            out.append("        %s = \"%s\"" % (sanitize_identifier(k, "key"),
                                                _yara_escape(v)))
    out.append("    strings:")
    out.extend(string_lines)
    out.append("    condition:")
    if len(pieces) == 1:
        out.append("        $pattern")
    else:
        # Every piece must appear at its exact offset from $pattern_p1.
        base = pieces[0][0]
        conds = ["$pattern_p%d at @pattern_p1[i] + %d" % (k, off - base)
                 for k, (off, _) in enumerate(pieces, 1) if k > 1]
        out.append("        for any i in (1..#pattern_p1) : (")
        for j, c in enumerate(conds):
            out.append("            " + c + (" and" if j + 1 < len(conds) else ""))
        out.append("        )")
    out.append("}")
    return "\n".join(out) + "\n"


# ---------------------------------------------------------------------------
# Binary blob
# ---------------------------------------------------------------------------
def fmt_blob(pattern, use_wildcards=True, fill=0x00):
    """
    Return (data, mask). `mask` is None when there are no wildcards,
    otherwise it has one byte per pattern byte: 0xFF = must match,
    0x00 = wildcard. Wildcarded bytes in `data` are replaced by `fill`.
    """
    if not use_wildcards or pattern.wildcard_count == 0:
        return bytes(bytearray(pattern.values)), None
    data = bytes(bytearray(pattern.masked_values(fill)))
    mask = bytes(bytearray(0x00 if w else 0xFF for w in pattern.wild))
    return data, mask


# ---------------------------------------------------------------------------
# Parsing (accepts "48 8B ? ??", "488B??", "\x48\x8B" + mask is not handled)
# ---------------------------------------------------------------------------
def parse_pattern(text):
    tokens = text.replace(",", " ").split()
    values, wild = [], []
    for tok in tokens:
        if tok in ("?", "??"):
            values.append(0)
            wild.append(True)
            continue
        if tok.lower().startswith("0x"):
            tok = tok[2:]
        if len(tok) % 2:
            raise ValueError("Invalid token: %r" % tok)
        for i in range(0, len(tok), 2):
            pair = tok[i:i + 2]
            if pair == "??":
                values.append(0)
                wild.append(True)
            else:
                values.append(int(pair, 16))
                wild.append(False)
    return Pattern(values, wild)
```

```py
class Field(object):
    """An operand field inside an instruction: [offset, offset+size)."""

    __slots__ = ("kind", "offset", "size")

    def __init__(self, kind, offset, size):
        self.kind = kind
        self.offset = offset
        self.size = size

    def __repr__(self):
        return "Field(%s, %d, %d)" % (self.kind, self.offset, self.size)


class Instruction(object):
    __slots__ = ("opcode", "name", "operand_type", "opcode_size", "size",
                 "fields", "operand")

    def __init__(self, opcode, name, operand_type, opcode_size, size, fields,
                 operand):
        self.opcode = opcode
        self.name = name
        self.operand_type = operand_type
        self.opcode_size = opcode_size   # 1 or 2 (0xFE prefix)
        self.size = size                 # total size in bytes
        self.fields = fields             # [Field]
        self.operand = operand           # decoded value (int/float/list) or None

    def __repr__(self):
        return "Instruction(%s, size=%d)" % (self.name, self.size)

    def text(self):
        """Simple ildasm-like rendering (used when IDA gives no text)."""
        op, t = self.operand, self.operand_type
        if op is None:
            return self.name
        if t in (InlineMethod, InlineField, InlineType, InlineTok, InlineSig,
                 InlineString):
            table = TOKEN_TABLES.get(op >> 24, "table 0x%02X" % (op >> 24))
            return "%s 0x%08X  // %s" % (self.name, op, table)
        if t == InlineSwitch:
            return "%s (%s)" % (self.name, ", ".join("%+d" % x for x in op))
        if t in (ShortInlineBrTarget, InlineBrTarget):
            return "%s %+d" % (self.name, op)
        return "%s %r" % (self.name, op)


def decode(data, offset=0):
    """
    Decode one CIL instruction from `data` (bytes) at `offset`.
    Returns an Instruction, or None for an unknown opcode or truncated data.
    """
    if offset >= len(data):
        return None
    b0 = data[offset]
    if b0 == 0xFE:
        if offset + 1 >= len(data):
            return None
        code, opsz = 0xFE00 | data[offset + 1], 2
    else:
        code, opsz = b0, 1
    entry = OPCODES.get(code)
    if entry is None:
        return None
    name, otype = entry
    pos = offset + opsz

    if otype == InlineSwitch:
        if pos + 4 > len(data):
            return None
        (n,) = struct.unpack_from("<I", data, pos)
        size = opsz + 4 + 4 * n
        if offset + size > len(data):
            return None
        targets = list(struct.unpack_from("<%di" % n, data, pos + 4)) if n else []
        fields = [Field(F_SWITCH_COUNT, opsz, 4)]
        fields += [Field(F_SWITCH_TARGET, opsz + 4 + 4 * i, 4) for i in range(n)]
        return Instruction(code, name, otype, opsz, size, fields, targets)

    osz = OPERAND_SIZE[otype]
    size = opsz + osz
    if offset + size > len(data):
        return None
    if osz == 0:
        return Instruction(code, name, otype, opsz, size, [], None)
    raw = data[pos:pos + osz]
    if otype == ShortInlineR:
        val = struct.unpack("<f", raw)[0]
    elif otype == InlineR:
        val = struct.unpack("<d", raw)[0]
    elif otype in (ShortInlineI, ShortInlineBrTarget):
        val = struct.unpack("<b", raw)[0]
    elif otype == ShortInlineVar:
        val = raw[0]
    elif otype == InlineVar:
        val = struct.unpack("<H", raw)[0]
    elif otype in (InlineI, InlineBrTarget):
        val = struct.unpack("<i", raw)[0]
    elif otype == InlineI8:
        val = struct.unpack("<q", raw)[0]
    else:  # tokens
        val = struct.unpack("<I", raw)[0]
    return Instruction(code, name, otype, opsz, size,
                       [Field(_KIND_OF[otype], opsz, osz)], val)


class CilWildcardOptions(object):
    """Which operand kinds are wildcarded automatically."""

    def __init__(self):
        self.enabled = True
        self.tokens = True            # method/field/type/tok/sig tokens
        self.strings = True           # ldstr tokens
        self.keep_token_table = True  # keep the token's table byte (MSB)
        self.branches = True          # branch / leave offsets
        self.switch_targets = True    # switch jump table
        self.vars = False             # arg / local indices
        self.immediates = False       # ldc.* constants


def auto_mask(insn, opts):
    """Per-byte wildcard mask (list of bool, len == insn.size)."""
    mask = [False] * insn.size
    if not opts.enabled:
        return mask
    for f in insn.fields:
        k = f.kind
        if k == F_TOKEN:
            want = opts.tokens
        elif k == F_STRING:
            want = opts.strings
        elif k == F_BRANCH:
            want = opts.branches
        elif k == F_SWITCH_TARGET:
            want = opts.switch_targets
        elif k == F_VAR:
            want = opts.vars
        elif k == F_IMM:
            want = opts.immediates
        else:   # F_SWITCH_COUNT: the count fixes the instruction length
            want = False
        if not want:
            continue
        size = f.size
        if k in (F_TOKEN, F_STRING) and opts.keep_token_table:
            size = 3   # little-endian: RID in bytes 0-2, table id in byte 3
        for i in range(f.offset, f.offset + size):
            mask[i] = True
    return mask
```

```py
            return
        try:
            if blob is not None:
                data, mask = blob
                with open(path, "wb") as f:
                    f.write(data)

                    with open(os.path.splitext(path)[0] + ".mask", "wb") as f:

        except (IOError, OSError) as e:
            ida_kernwin.warning("No se pudo guardar: %s" % e)
            return
        self.lbl_status.setText("Guardado en %s" % path)

        for ea in matches:
            print("    0x%X" % ea)
        self.lbl_status.setText("%s coincidencia(s)%s" %
                                (desc, " - UNICO" if n == 1 else " (ver Output)"))


def _hexdump(data, base, width=16):
    lines = []
    for i in range(0, len(data), width):
        chunk = data[i:i + width]
        hx = " ".join("%02X" % b for b in chunk)
        asc = "".join(chr(b) if 32 <= b < 127 else "." for b in chunk)
        lines.append("%08X  %-*s  %s" % (base + i, width * 3 - 1, hx, asc))
    return "\n".join(lines)
```

```py
"""
IDA-side logic for .NET (CLI) databases: reads the IL bytes, decodes them
with our own ECMA-335 decoder (cil.py) and computes which bytes should be

class Row(object):
    """One row of the byte grid: an instruction (or part of it) or data."""

    __slots__ = ("ea", "offset", "size", "text", "is_code")

    data = ida_bytes.get_bytes(ea, size)
    values, unloaded = [], []
    for i in range(size):
        if data is not None and i < len(data) and ida_bytes.is_loaded(ea + i):
            values.append(data[i])
            unloaded.append(False)
        else:
            values.append(0)
            unloaded.append(True)
    return values, unloaded

def _add_rows(sel, ea, offset, size, text, is_code):
    """Append `size` bytes as one or more rows of at most ROW_SIZE bytes."""
    first = True
    for off in range(0, size, ROW_SIZE):
        n = min(ROW_SIZE, size - off)
        sel.rows.append(Row(ea + off, offset + off, n,
                            text if first else "    (cont.)", is_code))
        first = False


def analyze_range(start, end, opts):
    """Build a Selection (bytes + automatic wildcards + rows) for [start, end)."""
    sel = Selection(start, end)
    values, unloaded = _read_bytes(start, end - start)
    data = bytes(bytearray(values))
    sel.values = values
    sel.auto_wild = list(unloaded)

    ea = start
    while ea < end:
        off = ea - start
        flags = ida_bytes.get_flags(ea)
        item_end = ida_bytes.get_item_end(ea)
        if item_end <= ea:
            item_end = ea + 1

        insn = None
        if ida_bytes.is_code(flags) and ida_bytes.is_head(flags):
            insn = cil.decode(data, off)

        if insn is not None:
            mask = cil.auto_mask(insn, opts)
            for i, m in enumerate(mask):
                if m:
                    sel.auto_wild[off + i] = True
            text = _disasm_text(ea) or insn.text()
            if item_end - ea != insn.size:
                # IDA and ECMA-335 disagree on the length: trust the spec,
                # but make it visible.
                text += "  [IDA: %d bytes, CIL: %d]" % (item_end - ea, insn.size)
            _add_rows(sel, ea, off, insn.size, text, True)
            ea += insn.size
            continue

        # Data, method headers, unknown opcodes or an instruction cut by the
        # end of the range: raw bytes, no automatic wildcards.
        chunk_end = min(item_end, end)
        head = ida_bytes.get_item_head(ea)
        if head == ea:
            text = _disasm_text(ea)
        else:
            text = "(+0x%X in item at 0x%X)" % (ea - head, head)
        if ida_bytes.is_code(flags) and head == ea:
            if item_end > end:
                text += "  [truncated]"
            else:
                text += "  [CIL no reconocido]"
        _add_rows(sel, ea, off, chunk_end - ea, text, False)
        ea = chunk_end
    return sel

def _search_flags():
    return (ida_bytes.BIN_SEARCH_FORWARD
            | getattr(ida_bytes, "BIN_SEARCH_CASE", 0)
            | ida_bytes.BIN_SEARCH_NOBREAK
            | ida_bytes.BIN_SEARCH_NOSHOW)


def _find_next(ea, max_ea, image, wild):
    if hasattr(ida_bytes, "find_bytes"):
        # IDA 9.x: the (image, mask, step, flags) bin_search overload is gone.
        mask = bytes(bytearray(0x00 if w else 0xFF for w in wild))
        return ida_bytes.find_bytes(image, ea, range_end=max_ea, mask=mask,
                                    flags=_search_flags())
    # IDA 8.x: mask uses 1 = defined / 0 = wildcard (a leading 0xFF would
    # be read as "all bytes defined").
    mask = bytes(bytearray(0 if w else 1 for w in wild))
    return ida_bytes.bin_search(ea, max_ea, image, mask,
                                ida_bytes.BIN_SEARCH_FORWARD, _search_flags())


def find_matches(pattern, limit=100):
    """Return the list of addresses (up to `limit`) where `pattern` matches."""
    if len(pattern) == 0:
        return []
    p, lead = pattern.trimmed()
    if len(p) == 0:
        return []
    image = bytes(bytearray(p.masked_values()))
    min_ea, max_ea = db_bounds()
    results = []
    ea = min_ea
    while len(results) < limit:
        ea = _find_next(ea, max_ea, image, p.wild)
        if ea == BADADDR or ea is None:
            break
        results.append(ea - lead)
        ea += 1
    return results


def auto_unique(start, opts, max_len=256):
    """
    Grow a pattern instruction by instruction starting at `start` until it
    matches exactly one location. Returns (end, match_count).
    """
    ea = ida_bytes.get_item_head(start)
    end = ea
    count = 0
    ida_kernwin.show_wait_box("Buscando patron unico...")
    try:
        while end - ea < max_len:
            if ida_kernwin.user_cancelled():
                break
            nxt = ida_bytes.get_item_end(end)
            if nxt <= end:
                nxt = end + 1
            end = nxt
            sel = analyze_range(ea, end, opts)
            p = Pattern(sel.values, sel.auto_wild if opts.enabled else None, ea)
            if len(p.trimmed()[0]) == 0:
                continue
            count = len(find_matches(p, limit=2))
            if count == 1:
                break
    finally:
        ida_kernwin.hide_wait_box()
    return end, count
```

```py
"""
Pure-Python pattern model and exporters.

This module does not import anything from IDA, so it can be unit-tested
outside of IDA (see tests/test_pattern.py).
"""

import re

__all__ = [
    "Pattern",
    "fmt_ida",
    "fmt_double_qmark",
    "fmt_raw",
    "fmt_code_style",
    "fmt_c_array",
    "fmt_yara",
    "fmt_yara_string",
    "fmt_blob",
    "parse_pattern",
    "sanitize_identifier",
]


class Pattern(object):
    """A byte pattern: a list of byte values plus a per-byte wildcard flag."""

    def __init__(self, values, wild=None, start_ea=None):
        self.values = [int(v) & 0xFF for v in values]
        if wild is None:
            wild = [False] * len(self.values)
        if len(wild) != len(self.values):
            raise ValueError("values/wild length mismatch")
        self.wild = [bool(w) for w in wild]
        self.start_ea = start_ea

    def __len__(self):
        return len(self.values)

    def __eq__(self, other):
        return (isinstance(other, Pattern)
                and self.values == other.values
                and self.wild == other.wild)

    def __repr__(self):
        return "Pattern(%r)" % fmt_double_qmark(self)

    @property
    def wildcard_count(self):
        return sum(1 for w in self.wild if w)

    def without_wildcards(self):
        return Pattern(self.values, None, self.start_ea)

    def masked_values(self, fill=0x00):
        """Byte values with every wildcard replaced by `fill`."""
        return [fill if w else v for v, w in zip(self.values, self.wild)]

    def trimmed(self):
        """
        Return (pattern, leading_trim) with leading/trailing wildcards
        removed. `leading_trim` is the number of bytes dropped at the start.
        """
        lo, hi = 0, len(self.values)
        while lo < hi and self.wild[lo]:
            lo += 1
        while hi > lo and self.wild[hi - 1]:
            hi -= 1
        start = None if self.start_ea is None else self.start_ea + lo
        return Pattern(self.values[lo:hi], self.wild[lo:hi], start), lo


# ---------------------------------------------------------------------------
# Standalone text formats
# ---------------------------------------------------------------------------
def _fmt_tokens(pattern, wildcard_token, use_wildcards=True):
    out = []
    for v, w in zip(pattern.values, pattern.wild):
        out.append(wildcard_token if (w and use_wildcards) else "%02X" % v)
    return " ".join(out)


def fmt_ida(pattern, use_wildcards=True):
    """IDA / SigMaker style: `48 8B 05 ? ? ? ?`."""
    return _fmt_tokens(pattern, "?", use_wildcards)


def fmt_double_qmark(pattern, use_wildcards=True):
    """x64dbg / Cheat Engine / YARA-like style: `48 8B 05 ?? ?? ?? ??`."""
    return _fmt_tokens(pattern, "??", use_wildcards)


def fmt_raw(pattern):
    """Exact bytes, no wildcards at all: `48 8B 05 10 20 30 40`."""
    return _fmt_tokens(pattern, "", use_wildcards=False)


def fmt_code_style(pattern, use_wildcards=True):
    """
    Code style used by most C/C++ scanners:
    ("\\x48\\x8B\\x05\\x00", "xxx?")
    """
    data = "".join("\\x%02X" % v for v in pattern.masked_values()) \
        if use_wildcards else "".join("\\x%02X" % v for v in pattern.values)
    if use_wildcards:
        mask = "".join("?" if w else "x" for w in pattern.wild)
    else:
        mask = "x" * len(pattern)
    return data, mask

_IDENT_RE = re.compile(r"[^A-Za-z0-9_]")


def sanitize_identifier(name, default="pattern"):
    name = _IDENT_RE.sub("_", (name or "").strip())
    if not name:
        name = default
    if name[0].isdigit():
        name = "_" + name
    return name[:128]


def fmt_c_array(pattern, name="pattern", use_wildcards=True, per_line=16):
    name = sanitize_identifier(name)
    has_wild = use_wildcards and pattern.wildcard_count > 0
    values = pattern.masked_values() if has_wild else pattern.values
    n = len(values)

    lines = []
    header = "// %d bytes" % n
    if has_wild:
        header += ", %d wildcards" % pattern.wildcard_count
    if pattern.start_ea is not None:
        header += ", generated from 0x%X" % pattern.start_ea
    lines.append(header)
    lines.append("// %s" % (fmt_ida(pattern) if has_wild else fmt_raw(pattern)))

    lines.append("const unsigned char %s[%d] = {" % (name, n))
    for i in range(0, n, per_line):
        chunk = ", ".join("0x%02X" % v for v in values[i:i + per_line])
        lines.append("    " + chunk + ("," if i + per_line < n else ""))
    lines.append("};")

    if has_wild:
        mask = "".join("?" if w else "x" for w in pattern.wild)
        lines.append("const char %s_mask[%d] = \"%s\";" % (name, n + 1, mask))
        lines.append("")
        lines.append("// Wildcard bitmap (1 = must match, 0 = wildcard)")
        lines.append("const unsigned char %s_bitmap[%d] = {" % (name, n))
        bits = [0 if w else 1 for w in pattern.wild]
        for i in range(0, n, per_line):
            chunk = ", ".join(str(b) for b in bits[i:i + per_line])
            lines.append("    " + chunk + ("," if i + per_line < n else ""))
        lines.append("};")

    data, mask = fmt_code_style(pattern, has_wild)
    lines.append("")
    lines.append("// Code style")
    lines.append("// \"%s\", \"%s\"" % (data, mask))
    return "\n".join(lines) + "\n"


# ---------------------------------------------------------------------------
# YARA
# ---------------------------------------------------------------------------
def _yara_escape(s):
    return str(s).replace("\\", "\\\\").replace("\"", "\\\"").replace("\n", " ")


# Layout limits for YARA hex strings: bytes per row, and rows per string.
# Longer patterns are split into $pattern_p1, $pattern_p2, ...
YARA_COLUMNS = 28
YARA_MAX_ROWS = 20


def _yara_trimmed(pattern, use_wildcards):
    """
    YARA does not accept hex strings that begin or end with a wildcard, so
    leading/trailing wildcards are trimmed. Returns (pattern, leading_trim).
    Raises ValueError if nothing is left after trimming.
    """
    p = pattern if use_wildcards else pattern.without_wildcards()
    p, lead = p.trimmed()
    if len(p) == 0:
        raise ValueError("The pattern contains only wildcards; "
                         "YARA needs at least one concrete byte.")
    return p, lead


def _yara_pieces(p, columns, max_rows):
    """
    Split an already-trimmed pattern into pieces of at most columns*max_rows
    bytes. Each piece is trimmed again (a piece cannot start or end with a
    wildcard either). Returns [(offset_in_p, piece)]; pieces made only of
    wildcards are dropped.
    """
    size = columns * max_rows
    pieces = []
    for off in range(0, len(p), size):
        chunk = Pattern(p.values[off:off + size], p.wild[off:off + size])
        chunk, lead = chunk.trimmed()
        if len(chunk):
            pieces.append((off + lead, chunk))
    return pieces


def _yara_hex_block(piece, columns, indent):
    """`{ .. }` on one line if it fits in a row, else one row per line."""
    tokens = ["??" if w else "%02X" % v for v, w in zip(piece.values, piece.wild)]
    rows = [" ".join(tokens[i:i + columns]) for i in range(0, len(tokens), columns)]
    if len(rows) == 1:
        return ["{ %s }" % rows[0]]
    return ["{"] + [indent + "    " + r for r in rows] + [indent + "}"]


def _yara_strings(p, columns, max_rows, indent):
    """Lines declaring $pattern (or $pattern_p1..N). Returns (lines, pieces)."""
    pieces = _yara_pieces(p, columns, max_rows)
    lines = []
    if len(pieces) == 1:
        block = _yara_hex_block(pieces[0][1], columns, indent)
        lines.append(indent + "$pattern = " + block[0])
        lines.extend(block[1:])
        return lines, pieces
    base = pieces[0][0]
    for k, (off, piece) in enumerate(pieces, 1):
        block = _yara_hex_block(piece, columns, indent)
        lines.append(indent + "// offset +%d (0x%X), %d bytes"
                     % (off - base, off - base, len(piece)))
        lines.append(indent + "$pattern_p%d = %s" % (k, block[0]))
        lines.extend(block[1:])
    return lines, pieces


def fmt_yara_string(pattern, use_wildcards=True,
                    columns=YARA_COLUMNS, max_rows=YARA_MAX_ROWS):
    """
    Only the YARA hex string(s), without the rule: `{ E8 ?? ?? 48 8B }`.
    Patterns longer than columns*max_rows bytes are emitted as
    `$pattern_p1 = {...}`, `$pattern_p2 = {...}`, ...
    """
    p, _ = _yara_trimmed(pattern, use_wildcards)
    lines, pieces = _yara_strings(p, columns, max_rows, "")
    if len(pieces) == 1:
        lines[0] = lines[0][len("$pattern = "):]
    return "\n".join(lines)


def fmt_yara(pattern, rule_name="pattern", use_wildcards=True, meta=None,
             columns=YARA_COLUMNS, max_rows=YARA_MAX_ROWS):
    """Build a complete YARA rule (see _yara_trimmed for trimming rules)."""
    rule_name = sanitize_identifier(rule_name, "pattern")
    p, lead = _yara_trimmed(pattern, use_wildcards)
    string_lines, pieces = _yara_strings(p, columns, max_rows, " " * 8)

    out = ["rule %s" % rule_name, "{"]
    meta_items = list((meta or {}).items())
    if p.start_ea is not None:
        meta_items.append(("address", "0x%X" % p.start_ea))
    if lead:
        meta_items.append(("note", "%d leading wildcard byte(s) trimmed" % lead))
    if len(pieces) > 1:
        meta_items.append(("pieces", "%d pieces of up to %d bytes, %d bytes total"
                           % (len(pieces), columns * max_rows, len(p))))
    if meta_items:
        out.append("    meta:")
        for k, v in meta_items:
            out.append("        %s = \"%s\"" % (sanitize_identifier(k, "key"),
                                                _yara_escape(v)))
    out.append("    strings:")
    out.extend(string_lines)
    out.append("    condition:")
    if len(pieces) == 1:
        out.append("        $pattern")
    else:
        # Every piece must appear at its exact offset from $pattern_p1.
        base = pieces[0][0]
        conds = ["$pattern_p%d at @pattern_p1[i] + %d" % (k, off - base)
                 for k, (off, _) in enumerate(pieces, 1) if k > 1]
        out.append("        for any i in (1..#pattern_p1) : (")
        for j, c in enumerate(conds):
            out.append("            " + c + (" and" if j + 1 < len(conds) else ""))
        out.append("        )")
    out.append("}")
    return "\n".join(out) + "\n"


# ---------------------------------------------------------------------------
# Binary blob
# ---------------------------------------------------------------------------
def fmt_blob(pattern, use_wildcards=True, fill=0x00):
    """
    Return (data, mask). `mask` is None when there are no wildcards,
    otherwise it has one byte per pattern byte: 0xFF = must match,
    0x00 = wildcard. Wildcarded bytes in `data` are replaced by `fill`.
    """
    if not use_wildcards or pattern.wildcard_count == 0:
        return bytes(bytearray(pattern.values)), None
    data = bytes(bytearray(pattern.masked_values(fill)))
    mask = bytes(bytearray(0x00 if w else 0xFF for w in pattern.wild))
    return data, mask


# ---------------------------------------------------------------------------
# Parsing (accepts "48 8B ? ??", "488B??", "\x48\x8B" + mask is not handled)
# ---------------------------------------------------------------------------
def parse_pattern(text):
    tokens = text.replace(",", " ").split()
    values, wild = [], []
    for tok in tokens:
        if tok in ("?", "??"):
            values.append(0)
            wild.append(True)
            continue
        if tok.lower().startswith("0x"):
            tok = tok[2:]
        if len(tok) % 2:
            raise ValueError("Invalid token: %r" % tok)
        for i in range(0, len(tok), 2):
            pair = tok[i:i + 2]
            if pair == "??":
                values.append(0)
                wild.append(True)
            else:
                values.append(int(pair, 16))
                wild.append(False)
    return Pattern(values, wild)
```

```py
                  "readonly.", "refanytype", "sizeof", "tail.", "volatile."):
            self.assertIn(n, two_byte)
        self.assertEqual(len(two_byte), 28)

    def test_operand_formats(self):
        cases = [
            ("00", "nop", 1),
            ("FE01", "ceq", 2),
            ("0E05", "ldarg.s", 2),
            ("FE090100", "ldarg", 4),
            ("1F2A", "ldc.i4.s", 2),
            ("2039300000", "ldc.i4", 5),
            ("210100000000000000", "ldc.i8", 9),
            ("220000803F", "ldc.r4", 5),
            ("23000000000000F03F", "ldc.r8", 9),
            ("2B05", "br.s", 2),
            ("38FBFFFFFF", "br", 5),
            ("280100000A", "call", 5),
            ("724D000070", "ldstr", 5),
            ("D029000001", "ldtoken", 5),
            ("2901000011", "calli", 5),
            ("FE1611000002", "constrained.", 6),
            ("FE1201", "unaligned.", 3),
            ("FE1901", "no.", 3),
            ("DE0A", "leave.s", 2),
        ]
        for hx, name, size in cases:
            insn = cil.decode(bytes.fromhex(hx))
            self.assertIsNotNone(insn, hx)
            self.assertEqual((insn.name, insn.size), (name, size), hx)
        self.assertEqual(cil.decode(bytes.fromhex("2039300000")).operand, 12345)
        self.assertEqual(cil.decode(bytes.fromhex("23000000000000F03F")).operand, 1.0)
        self.assertEqual(cil.decode(bytes.fromhex("38FBFFFFFF")).operand, -5)

    def test_switch(self):
        insn = cil.decode(bytes.fromhex("45 02000000 05000000 F6FFFFFF"))
        self.assertEqual((insn.name, insn.size, insn.operand), ("switch", 13, [5, -10]))
        self.assertEqual(cil.decode(bytes.fromhex("45 00000000")).size, 5)

    def test_invalid(self):
        self.assertIsNone(cil.decode(bytes.fromhex("FE08")))        # unused
        self.assertIsNone(cil.decode(bytes.fromhex("24")))          # unused
        self.assertIsNone(cil.decode(bytes.fromhex("FE")))          # truncated prefix
        self.assertIsNone(cil.decode(bytes.fromhex("2801000A")))    # truncated token
        self.assertIsNone(cil.decode(bytes.fromhex("45 05000000"))) # truncated switch
        self.assertIsNone(cil.decode(b""))

    def test_offset_argument(self):
        insn = cil.decode(bytes.fromhex("00 00 2B05"), 2)
        self.assertEqual((insn.name, insn.size), ("br.s", 2))

class MaskTests(unittest.TestCase):
    def test_defaults(self):
        self.assertEqual(mask_of("280100000A"), "x???x")      # call: keep table byte
        self.assertEqual(mask_of("724D000070"), "x???x")      # ldstr
        self.assertEqual(mask_of("FE1611000002"), "xx???x")   # 2-byte opcode + token
        self.assertEqual(mask_of("2B05"), "x?")               # br.s
        self.assertEqual(mask_of("38FBFFFFFF"), "x????")      # br
        self.assertEqual(mask_of("0E05"), "xx")               # vars off by default
        self.assertEqual(mask_of("2039300000"), "xxxxx")      # immediates off by default
        self.assertEqual(mask_of("45 02000000 05000000 F6FFFFFF"),
                         "x" + "xxxx" + "????" * 2)           # switch: count kept
        self.assertEqual(mask_of("FE01"), "xx")

    def test_options(self):
        self.assertEqual(mask_of("280100000A", keep_token_table=False), "x????")
        self.assertEqual(mask_of("280100000A", tokens=False), "xxxxx")
        self.assertEqual(mask_of("724D000070", strings=False), "xxxxx")
        self.assertEqual(mask_of("0E05", vars=True), "x?")
        self.assertEqual(mask_of("FE090100", vars=True), "xx??")
        self.assertEqual(mask_of("2039300000", immediates=True), "x????")
        self.assertEqual(mask_of("2B05", branches=False), "xx")
        self.assertEqual(mask_of("280100000A", enabled=False), "xxxxx")

    def test_reference_script_equivalent(self):
        # Every option on + no table byte == original script (opcode kept,
        # every operand byte wildcarded), except that the switch count is kept.
        everything = dict(tokens=True, strings=True, keep_token_table=False,
                          branches=True, switch_targets=True, vars=True,
                          immediates=True)
        for hx, op_len in (("280100000A", 1), ("FE090100", 2), ("1F2A", 1),

            self.assertEqual(m, "x" * op_len + "?" * (len(m) - op_len), hx)
```

```py
        for r, row in enumerate(self.sel.rows):

            it.setData(USER_ROLE, row.ea)
            t.setItem(r, COL_ADDR, it)

            for j in range(MAX_GRID_BYTES):

                if cell is None:
                    continue
                i = cell.data(USER_ROLE)
                self._paint_cell(cell, i)

        cell.setText("??" if wild else "%02X" % self.sel.values[i])
        if not self.opts.enabled:

            cell.setBackground(COLOR_MANUAL if wild else COLOR_FORCED)
        elif wild:

            cell.setData(Qt.ItemDataRole.BackgroundRole, None)

            cell.setForeground(QtGui.QColor(0, 0, 0))
        else:
            cell.setData(Qt.ItemDataRole.ForegroundRole, None)

    def _render(self):
        """Return (text_preview, blob_tuple_or_None)."""
        p = self.current_pattern()
        if p is None:
            return "", None

        fid = self._format_id()
        name = sanitize_identifier(self.ed_name.text(), "pattern")
        if fid == FMT_IDA:
            return fmt_ida(p, use_wc), None
        if fid == FMT_QQ:
            return fmt_double_qmark(p, use_wc), None
        if fid == FMT_RAW:
            return fmt_raw(p), None
        if fid == FMT_C:
            return fmt_c_array(p, name, use_wc), None
        if fid == FMT_YARA and self.cb_yara_only.isChecked():
            try:
                return fmt_yara_string(p, use_wc), None
            except ValueError as e:
                return "// Error: %s" % e, None
        if fid == FMT_YARA:
            meta = {"generator": "IDA " + TITLE}
            try:
                import ida_nalt
                root = ida_nalt.get_root_filename()
                if root:
                    meta["sample"] = root
                md5 = ida_nalt.retrieve_input_file_md5()
                if md5:
                    meta["md5"] = md5.hex()
            except Exception:
                pass
            try:
                return fmt_yara(p, name, use_wc, meta), None
            except ValueError as e:
                return "// Error: %s" % e, None
        if fid == FMT_BLOB:
            data, mask = fmt_blob(p, use_wc)
            lines = ["Blob binario: %d bytes" % len(data)]
            if mask is not None:
                lines.append("Contiene %d wildcards: se escriben como 0x00 y se genera "
                             "ademas un archivo .mask (0xFF = fijo, 0x00 = wildcard)."
                             % p.wildcard_count)
            lines.append("")
            lines.append(_hexdump(data, p.start_ea or 0))
            if mask is not None:
                lines.append("")
                lines.append("Mask:")
                lines.append(_hexdump(mask, p.start_ea or 0))
            return "\n".join(lines), (data, mask)
        return "", None

    def _sync_option_widgets(self):

def _hexdump(data, base, width=16):
    lines = []
    for i in range(0, len(data), width):
        chunk = data[i:i + width]
        hx = " ".join("%02X" % b for b in chunk)
        asc = "".join(chr(b) if 32 <= b < 127 else "." for b in chunk)
        lines.append("%08X  %-*s  %s" % (base + i, width * 3 - 1, hx, asc))
    return "\n".join(lines)
```

```py
def _looks_like_address(value):
    if value < MIN_ADDRESS_IMM:
        return False
    return ida_segment.getseg(value) is not None


def _operand_wanted(insn, n, op, flags, opts):
    t = op.type
    if t in (ida_ua.o_near, ida_ua.o_far):
        return opts.branches
    if t == ida_ua.o_mem:
        return opts.memory
    if t == ida_ua.o_displ:
        if opts.displacements:
            return True
        # [reg*4 + table] style: the displacement is really a global address
        return opts.memory and (ida_bytes.is_off(flags, n)
                                or _looks_like_address(op.addr))
    if t == ida_ua.o_imm:
        if opts.all_imm:
            return True
        return opts.address_imm and (ida_bytes.is_off(flags, n)
                                     or _looks_like_address(op.value))
    return False


def _insn_auto_mask(insn, opts):
    size = insn.size
    mask = [False] * size
    flags = ida_bytes.get_flags(insn.ea)

    ops = []
    for n in range(UA_MAXOP):
        try:
            op = insn.ops[n]
        except (IndexError, KeyError):
            break
        if op.type == ida_ua.o_void:
            break
        ops.append((n, op))

    # Field boundaries inside the instruction (start of every operand field).
    boundaries = {size}
    for _, op in ops:
        if op.offb:
            boundaries.add(op.offb)
        if op.offo:
            boundaries.add(op.offo)

    for n, op in ops:
        if not _operand_wanted(insn, n, op, flags, opts):
            continue
        offsets = [o for o in (op.offb, op.offo) if 0 < o < size]
        if not offsets:
            # Processor does not tell where the operand lives (typical on
            # fixed-width RISC ISAs): optionally wildcard the whole insn.
            if opts.whole_insn_fallback:
                mask = [True] * size
            continue
        for off in offsets:
            nxt = min(b for b in boundaries if b > off)
            for i in range(off, nxt):
                mask[i] = True
    return mask


def _apply_fixups(sel, opts):
    if ida_fixup is None or not opts.fixups:
        return
    start, end = sel.start, sel.end
    ptr_size = _ptr_size()
    try:
        if ida_fixup.exists_fixup(start):
            ea = start
        else:
            ea = ida_fixup.get_next_fixup_ea(start)
        # A fixup that starts right before the range can still cover it.
        prev = ida_fixup.get_prev_fixup_ea(start)
        candidates = []
        if prev != BADADDR and start - prev < 8:
            candidates.append(prev)
        while ea != BADADDR and ea < end:
            candidates.append(ea)
            ea = ida_fixup.get_next_fixup_ea(ea)
        for fea in candidates:
            fd = ida_fixup.fixup_data_t()
            if not fd.get(fea):
                continue
            try:
                fsize = fd.calc_size()
            except Exception:
                fsize = ptr_size
            if fsize <= 0:
                fsize = ptr_size
            for a in range(fea, fea + fsize):
                if start <= a < end:
                    sel.auto_wild[a - start] = True
    except Exception as e:  # never let fixup quirks break the plugin
        print("[SigWriter] fixup scan failed: %s" % e)


def analyze_range(start, end, opts):
    """Build a Selection (bytes + automatic wildcards + rows) for [start, end)."""
    sel = Selection(start, end)
    ea = start
    while ea < end:
        flags = ida_bytes.get_flags(ea)
        row_start = len(sel.values)

        insn = None
        if ida_bytes.is_code(flags) and ida_bytes.is_head(flags):
            insn = ida_ua.insn_t()
            if ida_ua.decode_insn(insn, ea) <= 0:
                insn = None

        if insn is not None and ea + insn.size <= end:
            size = insn.size
            values, unloaded = _read_bytes(ea, size)
            if opts.enabled:
                mask = _insn_auto_mask(insn, opts)
            else:
                mask = [False] * size
            sel.values.extend(values)
            sel.auto_wild.extend(m or u for m, u in zip(mask, unloaded))
            sel.rows.append(Row(ea, row_start, size, _disasm_text(ea), True))
            ea += size
            continue

        # Data, unknown bytes, or an instruction cut by the range end.
        item_end = ida_bytes.get_item_end(ea)
        if item_end <= ea:
            item_end = ea + 1
        chunk_end = min(item_end, end, ea + DATA_ROW_SIZE)
        size = chunk_end - ea
        values, unloaded = _read_bytes(ea, size)
        sel.values.extend(values)
        sel.auto_wild.extend(unloaded)
        head = ida_bytes.get_item_head(ea)
        if head == ea:
            text = _disasm_text(ea)
        else:
            text = "(+0x%X in item at 0x%X)" % (ea - head, head)
        if insn is not None or (ida_bytes.is_code(flags) and head != ea):
            text += "  [truncated]"
        sel.rows.append(Row(ea, row_start, size, text, False))
        ea = chunk_end

    if opts.enabled:
        _apply_fixups(sel, opts)
    return sel

def _search_flags():
    # BIN_SEARCH_CASE: find_bytes() is case-insensitive by default; we want
    # raw byte comparison.
    return (ida_bytes.BIN_SEARCH_FORWARD
            | ida_bytes.BIN_SEARCH_CASE
            | ida_bytes.BIN_SEARCH_NOBREAK
            | ida_bytes.BIN_SEARCH_NOSHOW)


def _find_next(ea, max_ea, image, mask):
    """
    One forward search. IDA 9.x removed the (image, mask, step, flags)
    overload of bin_search; find_bytes() builds the compiled pattern for us.
    Mask bytes are 0xFF (must match) / 0x00 (wildcard), which is valid
    both with and without BIN_SEARCH_BITMASK.
    """
    return ida_bytes.find_bytes(image, ea, range_end=max_ea, mask=mask,
                                flags=_search_flags())


def find_matches(pattern, limit=100):
    """Return the list of addresses (up to `limit`) where `pattern` matches."""
    if len(pattern) == 0:
        return []
    p, lead = pattern.trimmed()
    if len(p) == 0:
        return []
    image = bytes(bytearray(p.masked_values()))
    mask = bytes(bytearray(0x00 if w else 0xFF for w in p.wild))

    min_ea, max_ea = db_bounds()
    results = []
    ea = min_ea
    while len(results) < limit:
        ea = _find_next(ea, max_ea, image, mask)
        if ea == BADADDR or ea is None:
            break
        results.append(ea - lead)
        ea += 1
    return results


def auto_unique(start, opts, max_len=256):
    """
    Grow a pattern instruction by instruction starting at `start` until it
    matches exactly one location. Returns (end, match_count).
    """
    ea = ida_bytes.get_item_head(start)
    end = ea
    count = 0
    ida_kernwin.show_wait_box("Buscando patron unico...")
    try:
        while end - ea < max_len:
            if ida_kernwin.user_cancelled():
                break
            nxt = ida_bytes.get_item_end(end)
            if nxt <= end:
                nxt = end + 1
            end = nxt
            sel = analyze_range(ea, end, opts)
            p = Pattern(sel.values, sel.auto_wild if opts.enabled else None, ea)
            if len(p.trimmed()[0]) == 0:
                continue
            count = len(find_matches(p, limit=2))
            if count == 1:
                break
    finally:
        ida_kernwin.hide_wait_box()
    return end, count
```

```py
"""
Pure-Python pattern model and exporters.

This module does not import anything from IDA, so it can be unit-tested
outside of IDA (see tests/test_pattern.py).
"""

import re

__all__ = [
    "Pattern",
    "fmt_ida",
    "fmt_double_qmark",
    "fmt_raw",
    "fmt_code_style",
    "fmt_c_array",
    "fmt_yara",
    "fmt_yara_string",
    "fmt_blob",
    "parse_pattern",
    "sanitize_identifier",
]


class Pattern(object):
    """A byte pattern: a list of byte values plus a per-byte wildcard flag."""

    def __init__(self, values, wild=None, start_ea=None):
        self.values = [int(v) & 0xFF for v in values]
        if wild is None:
            wild = [False] * len(self.values)
        if len(wild) != len(self.values):
            raise ValueError("values/wild length mismatch")
        self.wild = [bool(w) for w in wild]
        self.start_ea = start_ea

    def __len__(self):
        return len(self.values)

    def __eq__(self, other):
        return (isinstance(other, Pattern)
                and self.values == other.values
                and self.wild == other.wild)

    def __repr__(self):
        return "Pattern(%r)" % fmt_double_qmark(self)

    @property
    def wildcard_count(self):
        return sum(1 for w in self.wild if w)

    def without_wildcards(self):
        return Pattern(self.values, None, self.start_ea)

    def masked_values(self, fill=0x00):
        """Byte values with every wildcard replaced by `fill`."""
        return [fill if w else v for v, w in zip(self.values, self.wild)]

    def trimmed(self):
        """
        Return (pattern, leading_trim) with leading/trailing wildcards
        removed. `leading_trim` is the number of bytes dropped at the start.
        """
        lo, hi = 0, len(self.values)
        while lo < hi and self.wild[lo]:
            lo += 1
        while hi > lo and self.wild[hi - 1]:
            hi -= 1
        start = None if self.start_ea is None else self.start_ea + lo
        return Pattern(self.values[lo:hi], self.wild[lo:hi], start), lo

# Standalone text formats
# ---------------------------------------------------------------------------
def _fmt_tokens(pattern, wildcard_token, use_wildcards=True):
    out = []
    for v, w in zip(pattern.values, pattern.wild):
        out.append(wildcard_token if (w and use_wildcards) else "%02X" % v)
    return " ".join(out)


def fmt_ida(pattern, use_wildcards=True):
    """IDA / SigMaker style: `48 8B 05 ? ? ? ?`."""
    return _fmt_tokens(pattern, "?", use_wildcards)


def fmt_double_qmark(pattern, use_wildcards=True):
    """x64dbg / Cheat Engine / YARA-like style: `48 8B 05 ?? ?? ?? ??`."""
    return _fmt_tokens(pattern, "??", use_wildcards)


def fmt_raw(pattern):
    """Exact bytes, no wildcards at all: `48 8B 05 10 20 30 40`."""
    return _fmt_tokens(pattern, "", use_wildcards=False)


def fmt_code_style(pattern, use_wildcards=True):
    """
    Code style used by most C/C++ scanners:
    ("\\x48\\x8B\\x05\\x00", "xxx?")
    """
    data = "".join("\\x%02X" % v for v in pattern.masked_values()) \
        if use_wildcards else "".join("\\x%02X" % v for v in pattern.values)
    if use_wildcards:
        mask = "".join("?" if w else "x" for w in pattern.wild)
    else:
        mask = "x" * len(pattern)
    return data, mask

# C / C++
# ---------------------------------------------------------------------------
_IDENT_RE = re.compile(r"[^A-Za-z0-9_]")


def sanitize_identifier(name, default="pattern"):
    name = _IDENT_RE.sub("_", (name or "").strip())
    if not name:
        name = default
    if name[0].isdigit():
        name = "_" + name
    return name[:128]


def fmt_c_array(pattern, name="pattern", use_wildcards=True, per_line=16):
    name = sanitize_identifier(name)
    has_wild = use_wildcards and pattern.wildcard_count > 0
    values = pattern.masked_values() if has_wild else pattern.values
    n = len(values)

    lines = []
    header = "// %d bytes" % n
    if has_wild:
        header += ", %d wildcards" % pattern.wildcard_count
    if pattern.start_ea is not None:
        header += ", generated from 0x%X" % pattern.start_ea
    lines.append(header)
    lines.append("// %s" % (fmt_ida(pattern) if has_wild else fmt_raw(pattern)))

    lines.append("const unsigned char %s[%d] = {" % (name, n))
    for i in range(0, n, per_line):
        chunk = ", ".join("0x%02X" % v for v in values[i:i + per_line])
        lines.append("    " + chunk + ("," if i + per_line < n else ""))
    lines.append("};")

    if has_wild:
        mask = "".join("?" if w else "x" for w in pattern.wild)
        lines.append("const char %s_mask[%d] = \"%s\";" % (name, n + 1, mask))
        lines.append("")
        lines.append("// Wildcard bitmap (1 = must match, 0 = wildcard)")
        lines.append("const unsigned char %s_bitmap[%d] = {" % (name, n))
        bits = [0 if w else 1 for w in pattern.wild]
        for i in range(0, n, per_line):
            chunk = ", ".join(str(b) for b in bits[i:i + per_line])
            lines.append("    " + chunk + ("," if i + per_line < n else ""))
        lines.append("};")

    data, mask = fmt_code_style(pattern, has_wild)
    lines.append("")
    lines.append("// Code style")
    lines.append("// \"%s\", \"%s\"" % (data, mask))
    return "\n".join(lines) + "\n"

# YARA
# ---------------------------------------------------------------------------
def _yara_escape(s):
    return str(s).replace("\\", "\\\\").replace("\"", "\\\"").replace("\n", " ")


# Layout limits for YARA hex strings: bytes per row, and rows per string.
# Longer patterns are split into $pattern_p1, $pattern_p2, ...
YARA_COLUMNS = 28
YARA_MAX_ROWS = 20


def _yara_trimmed(pattern, use_wildcards):
    """
    YARA does not accept hex strings that begin or end with a wildcard, so
    leading/trailing wildcards are trimmed. Returns (pattern, leading_trim).
    Raises ValueError if nothing is left after trimming.
    """
    p = pattern if use_wildcards else pattern.without_wildcards()
    p, lead = p.trimmed()
    if len(p) == 0:
        raise ValueError("The pattern contains only wildcards; "
                         "YARA needs at least one concrete byte.")
    return p, lead


def _yara_pieces(p, columns, max_rows):
    """
    Split an already-trimmed pattern into pieces of at most columns*max_rows
    bytes. Each piece is trimmed again (a piece cannot start or end with a
    wildcard either). Returns [(offset_in_p, piece)]; pieces made only of
    wildcards are dropped.
    """
    size = columns * max_rows
    pieces = []
    for off in range(0, len(p), size):
        chunk = Pattern(p.values[off:off + size], p.wild[off:off + size])
        chunk, lead = chunk.trimmed()
        if len(chunk):
            pieces.append((off + lead, chunk))
    return pieces


def _yara_hex_block(piece, columns, indent):
    """`{ .. }` on one line if it fits in a row, else one row per line."""
    tokens = ["??" if w else "%02X" % v for v, w in zip(piece.values, piece.wild)]
    rows = [" ".join(tokens[i:i + columns]) for i in range(0, len(tokens), columns)]
    if len(rows) == 1:
        return ["{ %s }" % rows[0]]
    return ["{"] + [indent + "    " + r for r in rows] + [indent + "}"]


def _yara_strings(p, columns, max_rows, indent):
    """Lines declaring $pattern (or $pattern_p1..N). Returns (lines, pieces)."""
    pieces = _yara_pieces(p, columns, max_rows)
    lines = []
    if len(pieces) == 1:
        block = _yara_hex_block(pieces[0][1], columns, indent)
        lines.append(indent + "$pattern = " + block[0])
        lines.extend(block[1:])
        return lines, pieces
    base = pieces[0][0]
    for k, (off, piece) in enumerate(pieces, 1):
        block = _yara_hex_block(piece, columns, indent)
        lines.append(indent + "// offset +%d (0x%X), %d bytes"
                     % (off - base, off - base, len(piece)))
        lines.append(indent + "$pattern_p%d = %s" % (k, block[0]))
        lines.extend(block[1:])
    return lines, pieces


def fmt_yara_string(pattern, use_wildcards=True,
                    columns=YARA_COLUMNS, max_rows=YARA_MAX_ROWS):
    """
    Only the YARA hex string(s), without the rule: `{ E8 ?? ?? 48 8B }`.
    Patterns longer than columns*max_rows bytes are emitted as
    `$pattern_p1 = {...}`, `$pattern_p2 = {...}`, ...
    """
    p, _ = _yara_trimmed(pattern, use_wildcards)
    lines, pieces = _yara_strings(p, columns, max_rows, "")
    if len(pieces) == 1:
        lines[0] = lines[0][len("$pattern = "):]
    return "\n".join(lines)


def fmt_yara(pattern, rule_name="pattern", use_wildcards=True, meta=None,
             columns=YARA_COLUMNS, max_rows=YARA_MAX_ROWS):
    """Build a complete YARA rule (see _yara_trimmed for trimming rules)."""
    rule_name = sanitize_identifier(rule_name, "pattern")
    p, lead = _yara_trimmed(pattern, use_wildcards)
    string_lines, pieces = _yara_strings(p, columns, max_rows, " " * 8)

    out = ["rule %s" % rule_name, "{"]
    meta_items = list((meta or {}).items())
    if p.start_ea is not None:
        meta_items.append(("address", "0x%X" % p.start_ea))
    if lead:
        meta_items.append(("note", "%d leading wildcard byte(s) trimmed" % lead))
    if len(pieces) > 1:
        meta_items.append(("pieces", "%d pieces of up to %d bytes, %d bytes total"
                           % (len(pieces), columns * max_rows, len(p))))
    if meta_items:
        out.append("    meta:")
        for k, v in meta_items:
            out.append("        %s = \"%s\"" % (sanitize_identifier(k, "key"),
                                                _yara_escape(v)))
    out.append("    strings:")
    out.extend(string_lines)
    out.append("    condition:")
    if len(pieces) == 1:
        out.append("        $pattern")
    else:
        # Every piece must appear at its exact offset from $pattern_p1.
        base = pieces[0][0]
        conds = ["$pattern_p%d at @pattern_p1[i] + %d" % (k, off - base)
                 for k, (off, _) in enumerate(pieces, 1) if k > 1]
        out.append("        for any i in (1..#pattern_p1) : (")
        for j, c in enumerate(conds):
            out.append("            " + c + (" and" if j + 1 < len(conds) else ""))
        out.append("        )")
    out.append("}")
    return "\n".join(out) + "\n"


# ---------------------------------------------------------------------------
# Binary blob
# ---------------------------------------------------------------------------
def fmt_blob(pattern, use_wildcards=True, fill=0x00):
    """
    Return (data, mask). `mask` is None when there are no wildcards,
    otherwise it has one byte per pattern byte: 0xFF = must match,
    0x00 = wildcard. Wildcarded bytes in `data` are replaced by `fill`.
    """
    if not use_wildcards or pattern.wildcard_count == 0:
        return bytes(bytearray(pattern.values)), None
    data = bytes(bytearray(pattern.masked_values(fill)))
    mask = bytes(bytearray(0x00 if w else 0xFF for w in pattern.wild))
    return data, mask


# ---------------------------------------------------------------------------
# Parsing (accepts "48 8B ? ??", "488B??", "\x48\x8B" + mask is not handled)
# ---------------------------------------------------------------------------
def parse_pattern(text):
    tokens = text.replace(",", " ").split()
    values, wild = [], []
    for tok in tokens:
        if tok in ("?", "??"):
            values.append(0)
            wild.append(True)
            continue
        if tok.lower().startswith("0x"):
            tok = tok[2:]
        if len(tok) % 2:
            raise ValueError("Invalid token: %r" % tok)
        for i in range(0, len(tok), 2):
            pair = tok[i:i + 2]
            if pair == "??":
                values.append(0)
                wild.append(True)
            else:
                values.append(int(pair, 16))
                wild.append(False)
    return Pattern(values, wild)
```

```py
def _hexdump(data, base, width=16):
    lines = []
    for i in range(0, len(data), width):
        chunk = data[i:i + width]
        hx = " ".join("%02X" % b for b in chunk)
        asc = "".join(chr(b) if 32 <= b < 127 else "." for b in chunk)
        lines.append("%08X  %-*s  %s" % (base + i, width * 3 - 1, hx, asc))
    return "\n".join(lines)
```

```py
def _looks_like_address(value):
    if value < MIN_ADDRESS_IMM:
        return False
    return ida_segment.getseg(value) is not None


def _operand_wanted(insn, n, op, flags, opts):
    t = op.type
    if t in (ida_ua.o_near, ida_ua.o_far):
        return opts.branches
    if t == ida_ua.o_mem:
        return opts.memory
    if t == ida_ua.o_displ:
        if opts.displacements:
            return True
        # [reg*4 + table] style: the displacement is really a global address
        return opts.memory and (ida_bytes.is_off(flags, n)
                                or _looks_like_address(op.addr))
    if t == ida_ua.o_imm:
        if opts.all_imm:
            return True
        return opts.address_imm and (ida_bytes.is_off(flags, n)
                                     or _looks_like_address(op.value))
    return False


def _insn_auto_mask(insn, opts):
    size = insn.size
    mask = [False] * size
    flags = ida_bytes.get_flags(insn.ea)

    ops = []
    for n in range(UA_MAXOP):
        try:
            op = insn.ops[n]
        except (IndexError, KeyError):
            break
        if op.type == ida_ua.o_void:
            break
        ops.append((n, op))

    # Field boundaries inside the instruction (start of every operand field).
    boundaries = {size}
    for _, op in ops:
        if op.offb:
            boundaries.add(op.offb)
        if op.offo:
            boundaries.add(op.offo)

    for n, op in ops:
        if not _operand_wanted(insn, n, op, flags, opts):
            continue
        offsets = [o for o in (op.offb, op.offo) if 0 < o < size]
        if not offsets:
            # Processor does not tell where the operand lives (typical on
            # fixed-width RISC ISAs): optionally wildcard the whole insn.
            if opts.whole_insn_fallback:
                mask = [True] * size
            continue
        for off in offsets:
            nxt = min(b for b in boundaries if b > off)
            for i in range(off, nxt):
                mask[i] = True
    return mask


def _apply_fixups(sel, opts):
    if ida_fixup is None or not opts.fixups:
        return
    start, end = sel.start, sel.end
    ptr_size = _ptr_size()
    try:
        if ida_fixup.exists_fixup(start):
            ea = start
        else:
            ea = ida_fixup.get_next_fixup_ea(start)
        # A fixup that starts right before the range can still cover it.
        prev = ida_fixup.get_prev_fixup_ea(start)
        candidates = []
        if prev != BADADDR and start - prev < 8:
            candidates.append(prev)
        while ea != BADADDR and ea < end:
            candidates.append(ea)
            ea = ida_fixup.get_next_fixup_ea(ea)
        for fea in candidates:
            fd = ida_fixup.fixup_data_t()
            if not fd.get(fea):
                continue
            try:
                fsize = fd.calc_size()
            except Exception:
                fsize = ptr_size
            if fsize <= 0:
                fsize = ptr_size
            for a in range(fea, fea + fsize):
                if start <= a < end:
                    sel.auto_wild[a - start] = True
    except Exception as e:  # never let fixup quirks break the plugin
        print("[SigWriter] fixup scan failed: %s" % e)


def analyze_range(start, end, opts):
    """Build a Selection (bytes + automatic wildcards + rows) for [start, end)."""
    sel = Selection(start, end)
    ea = start
    while ea < end:
        flags = ida_bytes.get_flags(ea)
        row_start = len(sel.values)

        insn = None
        if ida_bytes.is_code(flags) and ida_bytes.is_head(flags):
            insn = ida_ua.insn_t()
            if ida_ua.decode_insn(insn, ea) <= 0:
                insn = None

        if insn is not None and ea + insn.size <= end:
            size = insn.size
            values, unloaded = _read_bytes(ea, size)
            if opts.enabled:
                mask = _insn_auto_mask(insn, opts)
            else:
                mask = [False] * size
            sel.values.extend(values)
            sel.auto_wild.extend(m or u for m, u in zip(mask, unloaded))
            sel.rows.append(Row(ea, row_start, size, _disasm_text(ea), True))
            ea += size
            continue

        # Data, unknown bytes, or an instruction cut by the range end.
        item_end = ida_bytes.get_item_end(ea)
        if item_end <= ea:
            item_end = ea + 1
        chunk_end = min(item_end, end, ea + DATA_ROW_SIZE)
        size = chunk_end - ea
        values, unloaded = _read_bytes(ea, size)
        sel.values.extend(values)
        sel.auto_wild.extend(unloaded)
        head = ida_bytes.get_item_head(ea)
        if head == ea:
            text = _disasm_text(ea)
        else:
            text = "(+0x%X in item at 0x%X)" % (ea - head, head)
        if insn is not None or (ida_bytes.is_code(flags) and head != ea):
            text += "  [truncated]"
        sel.rows.append(Row(ea, row_start, size, text, False))
        ea = chunk_end

    if opts.enabled:
        _apply_fixups(sel, opts)
    return sel

def _search_flags():
    return (ida_bytes.BIN_SEARCH_FORWARD
            | ida_bytes.BIN_SEARCH_NOBREAK
            | ida_bytes.BIN_SEARCH_NOSHOW)


def _find_next(ea, max_ea, image, mask, pattern_text):
    """One forward search. Uses the IDA 8.x byte-image overload of
    bin_search and falls back to the compiled-pattern one."""
    try:
        return ida_bytes.bin_search(ea, max_ea, image, mask,
                                    ida_bytes.BIN_SEARCH_FORWARD,
                                    _search_flags())
    except (TypeError, NotImplementedError):
        # SWIG overload mismatch (other IDA versions)
        pass
    pats = ida_bytes.compiled_binpat_vec_t()
    ida_bytes.parse_binpat_str(pats, ea, pattern_text, 16)
    res = ida_bytes.bin_search(ea, max_ea, pats, _search_flags())
    if isinstance(res, (tuple, list)):
        res = res[0]
    return res


def find_matches(pattern, limit=100):
    """Return the list of addresses (up to `limit`) where `pattern` matches."""
    if len(pattern) == 0:
        return []
    p, lead = pattern.trimmed()
    if len(p) == 0:
        return []
    image = bytes(bytearray(p.masked_values()))
    mask = bytes(bytearray(0 if w else 1 for w in p.wild))
    text = " ".join("?" if w else "%02X" % v for v, w in zip(p.values, p.wild))

    min_ea, max_ea = db_bounds()
    results = []
    ea = min_ea
    while len(results) < limit:
        ea = _find_next(ea, max_ea, image, mask, text)
        if ea == BADADDR or ea is None:
            break
        results.append(ea - lead)
        ea += 1
    return results


def auto_unique(start, opts, max_len=256):
    """
    Grow a pattern instruction by instruction starting at `start` until it
    matches exactly one location. Returns (end, match_count).
    """
    ea = ida_bytes.get_item_head(start)
    end = ea
    count = 0
    ida_kernwin.show_wait_box("Buscando patron unico...")
    try:
        while end - ea < max_len:
            if ida_kernwin.user_cancelled():
                break
            nxt = ida_bytes.get_item_end(end)
            if nxt <= end:
                nxt = end + 1
            end = nxt
            sel = analyze_range(ea, end, opts)
            p = Pattern(sel.values, sel.auto_wild if opts.enabled else None, ea)
            if len(p.trimmed()[0]) == 0:
                continue
            count = len(find_matches(p, limit=2))
            if count == 1:
                break
    finally:
        ida_kernwin.hide_wait_box()
    return end, count
```

```py
"""
Pure-Python pattern model and exporters.

This module does not import anything from IDA, so it can be unit-tested
outside of IDA (see tests/test_pattern.py).
"""

import re

__all__ = [
    "Pattern",
    "fmt_ida",
    "fmt_double_qmark",
    "fmt_raw",
    "fmt_code_style",
    "fmt_c_array",
    "fmt_yara",
    "fmt_yara_string",
    "fmt_blob",
    "parse_pattern",
    "sanitize_identifier",
]


class Pattern(object):
    """A byte pattern: a list of byte values plus a per-byte wildcard flag."""

    def __init__(self, values, wild=None, start_ea=None):
        self.values = [int(v) & 0xFF for v in values]
        if wild is None:
            wild = [False] * len(self.values)
        if len(wild) != len(self.values):
            raise ValueError("values/wild length mismatch")
        self.wild = [bool(w) for w in wild]
        self.start_ea = start_ea

    def __len__(self):
        return len(self.values)

    def __eq__(self, other):
        return (isinstance(other, Pattern)
                and self.values == other.values
                and self.wild == other.wild)

    def __repr__(self):
        return "Pattern(%r)" % fmt_double_qmark(self)

    @property
    def wildcard_count(self):
        return sum(1 for w in self.wild if w)

    def without_wildcards(self):
        return Pattern(self.values, None, self.start_ea)

    def masked_values(self, fill=0x00):
        """Byte values with every wildcard replaced by `fill`."""
        return [fill if w else v for v, w in zip(self.values, self.wild)]

    def trimmed(self):
        """
        Return (pattern, leading_trim) with leading/trailing wildcards
        removed. `leading_trim` is the number of bytes dropped at the start.
        """
        lo, hi = 0, len(self.values)
        while lo < hi and self.wild[lo]:
            lo += 1
        while hi > lo and self.wild[hi - 1]:
            hi -= 1
        start = None if self.start_ea is None else self.start_ea + lo
        return Pattern(self.values[lo:hi], self.wild[lo:hi], start), lo

def _fmt_tokens(pattern, wildcard_token, use_wildcards=True):
    out = []
    for v, w in zip(pattern.values, pattern.wild):
        out.append(wildcard_token if (w and use_wildcards) else "%02X" % v)
    return " ".join(out)


def fmt_ida(pattern, use_wildcards=True):
    """IDA / SigMaker style: `48 8B 05 ? ? ? ?`."""
    return _fmt_tokens(pattern, "?", use_wildcards)


def fmt_double_qmark(pattern, use_wildcards=True):
    """x64dbg / Cheat Engine / YARA-like style: `48 8B 05 ?? ?? ?? ??`."""
    return _fmt_tokens(pattern, "??", use_wildcards)


def fmt_raw(pattern):
    """Exact bytes, no wildcards at all: `48 8B 05 10 20 30 40`."""
    return _fmt_tokens(pattern, "", use_wildcards=False)


def fmt_code_style(pattern, use_wildcards=True):
    """
    Code style used by most C/C++ scanners:
    ("\\x48\\x8B\\x05\\x00", "xxx?")
    """
    data = "".join("\\x%02X" % v for v in pattern.masked_values()) \
        if use_wildcards else "".join("\\x%02X" % v for v in pattern.values)
    if use_wildcards:
        mask = "".join("?" if w else "x" for w in pattern.wild)
    else:
        mask = "x" * len(pattern)
    return data, mask


# ---------------------------------------------------------------------------
# C / C++
# ---------------------------------------------------------------------------
_IDENT_RE = re.compile(r"[^A-Za-z0-9_]")


def sanitize_identifier(name, default="pattern"):
    name = _IDENT_RE.sub("_", (name or "").strip())
    if not name:
        name = default
    if name[0].isdigit():
        name = "_" + name
    return name[:128]


def fmt_c_array(pattern, name="pattern", use_wildcards=True, per_line=16):
    name = sanitize_identifier(name)
    has_wild = use_wildcards and pattern.wildcard_count > 0
    values = pattern.masked_values() if has_wild else pattern.values
    n = len(values)

    lines = []
    header = "// %d bytes" % n
    if has_wild:
        header += ", %d wildcards" % pattern.wildcard_count
    if pattern.start_ea is not None:
        header += ", generated from 0x%X" % pattern.start_ea
    lines.append(header)
    lines.append("// %s" % (fmt_ida(pattern) if has_wild else fmt_raw(pattern)))

    lines.append("const unsigned char %s[%d] = {" % (name, n))
    for i in range(0, n, per_line):
        chunk = ", ".join("0x%02X" % v for v in values[i:i + per_line])
        lines.append("    " + chunk + ("," if i + per_line < n else ""))
    lines.append("};")

    if has_wild:
        mask = "".join("?" if w else "x" for w in pattern.wild)
        lines.append("const char %s_mask[%d] = \"%s\";" % (name, n + 1, mask))
        lines.append("")
        lines.append("// Wildcard bitmap (1 = must match, 0 = wildcard)")
        lines.append("const unsigned char %s_bitmap[%d] = {" % (name, n))
        bits = [0 if w else 1 for w in pattern.wild]
        for i in range(0, n, per_line):
            chunk = ", ".join(str(b) for b in bits[i:i + per_line])
            lines.append("    " + chunk + ("," if i + per_line < n else ""))
        lines.append("};")

    data, mask = fmt_code_style(pattern, has_wild)
    lines.append("")
    lines.append("// Code style")
    lines.append("// \"%s\", \"%s\"" % (data, mask))
    return "\n".join(lines) + "\n"


# ---------------------------------------------------------------------------
# YARA
# ---------------------------------------------------------------------------
def _yara_escape(s):
    return str(s).replace("\\", "\\\\").replace("\"", "\\\"").replace("\n", " ")


# Layout limits for YARA hex strings: bytes per row, and rows per string.
# Longer patterns are split into $pattern_p1, $pattern_p2, ...
YARA_COLUMNS = 28
YARA_MAX_ROWS = 20


def _yara_trimmed(pattern, use_wildcards):
    """
    YARA does not accept hex strings that begin or end with a wildcard, so
    leading/trailing wildcards are trimmed. Returns (pattern, leading_trim).
    Raises ValueError if nothing is left after trimming.
    """
    p = pattern if use_wildcards else pattern.without_wildcards()
    p, lead = p.trimmed()
    if len(p) == 0:
        raise ValueError("The pattern contains only wildcards; "
                         "YARA needs at least one concrete byte.")
    return p, lead


def _yara_pieces(p, columns, max_rows):
    """
    Split an already-trimmed pattern into pieces of at most columns*max_rows
    bytes. Each piece is trimmed again (a piece cannot start or end with a
    wildcard either). Returns [(offset_in_p, piece)]; pieces made only of
    wildcards are dropped.
    """
    size = columns * max_rows
    pieces = []
    for off in range(0, len(p), size):
        chunk = Pattern(p.values[off:off + size], p.wild[off:off + size])
        chunk, lead = chunk.trimmed()
        if len(chunk):
            pieces.append((off + lead, chunk))
    return pieces


def _yara_hex_block(piece, columns, indent):
    """`{ .. }` on one line if it fits in a row, else one row per line."""
    tokens = ["??" if w else "%02X" % v for v, w in zip(piece.values, piece.wild)]
    rows = [" ".join(tokens[i:i + columns]) for i in range(0, len(tokens), columns)]
    if len(rows) == 1:
        return ["{ %s }" % rows[0]]
    return ["{"] + [indent + "    " + r for r in rows] + [indent + "}"]


def _yara_strings(p, columns, max_rows, indent):
    """Lines declaring $pattern (or $pattern_p1..N). Returns (lines, pieces)."""
    pieces = _yara_pieces(p, columns, max_rows)
    lines = []
    if len(pieces) == 1:
        block = _yara_hex_block(pieces[0][1], columns, indent)
        lines.append(indent + "$pattern = " + block[0])
        lines.extend(block[1:])
        return lines, pieces
    base = pieces[0][0]
    for k, (off, piece) in enumerate(pieces, 1):
        block = _yara_hex_block(piece, columns, indent)
        lines.append(indent + "// offset +%d (0x%X), %d bytes"
                     % (off - base, off - base, len(piece)))
        lines.append(indent + "$pattern_p%d = %s" % (k, block[0]))
        lines.extend(block[1:])
    return lines, pieces


def fmt_yara_string(pattern, use_wildcards=True,
                    columns=YARA_COLUMNS, max_rows=YARA_MAX_ROWS):
    """
    Only the YARA hex string(s), without the rule: `{ E8 ?? ?? 48 8B }`.
    Patterns longer than columns*max_rows bytes are emitted as
    `$pattern_p1 = {...}`, `$pattern_p2 = {...}`, ...
    """
    p, _ = _yara_trimmed(pattern, use_wildcards)
    lines, pieces = _yara_strings(p, columns, max_rows, "")
    if len(pieces) == 1:
        lines[0] = lines[0][len("$pattern = "):]
    return "\n".join(lines)


def fmt_yara(pattern, rule_name="pattern", use_wildcards=True, meta=None,
             columns=YARA_COLUMNS, max_rows=YARA_MAX_ROWS):
    """Build a complete YARA rule (see _yara_trimmed for trimming rules)."""
    rule_name = sanitize_identifier(rule_name, "pattern")
    p, lead = _yara_trimmed(pattern, use_wildcards)
    string_lines, pieces = _yara_strings(p, columns, max_rows, " " * 8)

    out = ["rule %s" % rule_name, "{"]
    meta_items = list((meta or {}).items())
    if p.start_ea is not None:
        meta_items.append(("address", "0x%X" % p.start_ea))
    if lead:
        meta_items.append(("note", "%d leading wildcard byte(s) trimmed" % lead))
    if len(pieces) > 1:
        meta_items.append(("pieces", "%d pieces of up to %d bytes, %d bytes total"
                           % (len(pieces), columns * max_rows, len(p))))
    if meta_items:
        out.append("    meta:")
        for k, v in meta_items:
            out.append("        %s = \"%s\"" % (sanitize_identifier(k, "key"),
                                                _yara_escape(v)))
    out.append("    strings:")
    out.extend(string_lines)
    out.append("    condition:")
    if len(pieces) == 1:
        out.append("        $pattern")
    else:
        # Every piece must appear at its exact offset from $pattern_p1.
        base = pieces[0][0]
        conds = ["$pattern_p%d at @pattern_p1[i] + %d" % (k, off - base)
                 for k, (off, _) in enumerate(pieces, 1) if k > 1]
        out.append("        for any i in (1..#pattern_p1) : (")
        for j, c in enumerate(conds):
            out.append("            " + c + (" and" if j + 1 < len(conds) else ""))
        out.append("        )")
    out.append("}")
    return "\n".join(out) + "\n"


# ---------------------------------------------------------------------------
# Binary blob
# ---------------------------------------------------------------------------
def fmt_blob(pattern, use_wildcards=True, fill=0x00):
    """
    Return (data, mask). `mask` is None when there are no wildcards,
    otherwise it has one byte per pattern byte: 0xFF = must match,
    0x00 = wildcard. Wildcarded bytes in `data` are replaced by `fill`.
    """
    if not use_wildcards or pattern.wildcard_count == 0:
        return bytes(bytearray(pattern.values)), None
    data = bytes(bytearray(pattern.masked_values(fill)))
    mask = bytes(bytearray(0x00 if w else 0xFF for w in pattern.wild))
    return data, mask


# ---------------------------------------------------------------------------
# Parsing (accepts "48 8B ? ??", "488B??", "\x48\x8B" + mask is not handled)
# ---------------------------------------------------------------------------
def parse_pattern(text):
    tokens = text.replace(",", " ").split()
    values, wild = [], []
    for tok in tokens:
        if tok in ("?", "??"):
            values.append(0)
            wild.append(True)
            continue
        if tok.lower().startswith("0x"):
            tok = tok[2:]
        if len(tok) % 2:
            raise ValueError("Invalid token: %r" % tok)
        for i in range(0, len(tok), 2):
            pair = tok[i:i + 2]
            if pair == "??":
                values.append(0)
                wild.append(True)
            else:
                values.append(int(pair, 16))
                wild.append(False)
    return Pattern(values, wild)
```

```py
    help = "Selecciona codigo en IDA View y usa el menu contextual o %s" % PLUGIN_HOTKEY

        self.hooks = None

            self.hooks = None

                self.form.range = rng
            self.form.show()
        else:
            self.form.show()
            if rng:
                self.form.set_range(*rng)

    return SigWriterPlugin()
```

```py
        self.assertEqual(fmt_double_qmark(self.p), "E8 ?? ?? ?? ?? 48 8B 05 ?? ?? ?? ??")

        self.assertIn("const unsigned char my_sig[12]", out)
        self.assertIn('my_sig_mask[13] = "x????xxx????"', out)
        exact = fmt_c_array(self.p, "s", use_wildcards=False)

        self.assertIn("{ 02 }", out2)
```
