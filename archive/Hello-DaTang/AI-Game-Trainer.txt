```md
# Developer guide for AI Game Trainer

Goal: a user-approved, reusable, local-first trainer. The first milestone is a Windows Python UI and CE Bridge integration; native Tauri/React is deferred until the CE feedback loop works on real machines.

## Local test
- python -m unittest discover -s tests -v
- python -m compileall -q trainer
- On Windows, py -m pip install -r requirements-windows.txt and py -m trainer

## Contract with CE
- Dependency: miscusi-peek/cheatengine-mcp-bridge pinned at 6bd7ce90479250a9b4b75e7944df9c105ecb2572.
- Named pipe: \\.\pipe\CE_MCP_Bridge_v99; request/response: little-endian uint32 length then UTF-8 JSON-RPC.
- IMPORTANT: Lua v12 accepts filename for load_table/save_table, and process_id_or_name for open_process. Docs use other names in places.
- IMPORTANT: set_memory_record_value in Lua v12 ignores freeze. For active/inactive use a vetted evaluate_lua snippet with a numeric record ID already returned by CE.
- The repository does not vendor/redistribute upstream code. bootstrap.ps1 checks out upstream under ignored vendor/.

## Safety and robustness
- Do not enable kernel, DBVM, anti-cheat evasion, or online multiplayer modifications.
- Never accept arbitrary Lua, shell commands, or bridge method names from the HTTP client.
- Bind HTTP to loopback and verify Host/Origin.
- A saved feature must be associated with one exact game executable; refuse ambiguous multiple matching processes.
- Never assume a runtime memory address persists across restarts. Preserve CE .CT structures, verify target and record before mutation; if invalid, fail closed.
- Do not leak secrets, save games or generated CT tables into Git.
- Tests must run without Cheat Engine; use a fake CE bridge.
- Favor Windows D: drive for checkout and dev tools when documenting local installation.
```

```md
# AI Game Trainer

## 免安装下载（Windows x64）

**优先推荐 [GitHub Releases](https://github.com/Hello-DaTang/AI-Game-Trainer/releases)**：下载 AI-Game-Trainer-Windows-x64.zip → 完整解压 → 双击 AI-Game-Trainer.exe，即可打开本地控制台，无须在电脑上安装 Python、Git、Node.js、Rust 或 pip。

ZIP 包内包含 CE-Bridge/ce_mcp_bridge.lua，仍需单独安装 Cheat Engine 并手动加载 Lua Bridge。详见 ZIP 内的《使用说明.md》。本版本仍是修改记录持久化 MVP，**没有内嵌 Codex 对话 Agent**。

在 Cheat Engine + AI 的探索阶段制作修改功能，验证满意后保存为游戏专属按钮。下次进入单机游戏，直接点击按钮即可调用已经保存的 CE 修改记录。

> **当前版本：0.1.3，开发验证版。** 已实现游戏库、CE Bridge 探活、从 CE 捕获地址列表记录、将整张 CE 表保存为 .CT、重新载入后开启/关闭指定记录、SQLite 持久化、本地网页控制台。**尚未集成内置自然语言聊天或 Codex SDK，已提供 Windows 免 Python 便携包，但仍未提供 Tauri 安装包。** Agent 可以在外部 Codex + CE MCP 中探索，再把结果导入本软件。不能保证任何游戏中的修改成功或跨版本稳定。

## 不用学习 CE 的一键实测（v0.1.3）

启动 CE 并加载 Lua Bridge 后，打开本程序页面，点击 **「开始一键实测」**。软件会自动运行随包测试进程、由 CE 读取数值 123、改写为 777、再次读取确认、恢复成 123 后退出。不会操作你添加的真实游戏，也不需要手动做内存扫描。

通过说明基础内存读写通路正常，**不能代表 AI 自动探索或 CT 复用已验证**。

## 架构

- Windows Cheat Engine 7.x，加载上游 Lua Bridge（版本 12.0.0 / wire v99）。
- Python 3.10+ 标准库 HTTP 服务与 SQLite：不用 Node/Rust 就能运行第一阶段 UI。
- 本地管理页面：127.0.0.1:8765；数据库位于 %LOCALAPPDATA%\AI-Game-Trainer\trainer.sqlite3；CE 表位于其 tables 目录。
- 默认 Windows Named Pipe；可切换到仅监听 127.0.0.1 的 TCP Relay。
- 上游 CE Bridge **不在此仓库中复制**，通过脚本固定版本下载到 vendor/。

## Windows 从零开始（建议装在 D: 盘）

先确保安装 **Git、Python 3.10 或更新版本，以及 Cheat Engine**。使用 PowerShell：

~~~powershell
Set-Location D:\
git clone https://github.com/Hello-DaTang/AI-Game-Trainer.git
Set-Location .\AI-Game-Trainer
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap.ps1
py -m pip install -r requirements-windows.txt
~~~

然后按顺序：

1. 启动 Cheat Engine（本阶段**不要启动 DBVM/内核工具**）。
2. CE 顶部菜单选择 File → Execute Script，加载 vendor\cheatengine-mcp-bridge\MCP_Server\ce_mcp_bridge.lua。正确加载后 Lua 日志包含 CE_MCP_Bridge_v99。若该菜单不存在，可在 CE Table → Show Cheat Table Lua Script 中执行 dofile 的完整绝对路径（使用双中括号 Lua 字符串）。
3. 启动你的离线单机游戏，在 CE 中通过进程列表**附加到这个游戏的 EXE**。
4. 在 PowerShell 执行：

~~~powershell
py -m trainer
~~~

浏览器会自动打开 http://127.0.0.1:8765 。若没有自动打开，手动访问该地址。

### 第一次保存一个按钮

1. 在浏览器添加游戏，填入游戏进程文件名，例如 mygame.exe。
2. 在 CE 中完成扫描/分析；验证成功后在 CE 地址列表创建一个唯一描述的记录（例如 Player Stamina）。对于开关功能，建议使用带 [ENABLE]/[DISABLE] 的 Auto Assembler 记录。
3. 回到浏览器：读取 CE 记录 → 选择记录 → 给按钮命名 → 保存。
4. 此时软件把 CE 当前表全部保存为 CT 文件，并在 SQLite 中登记按钮。需要保存第二个按钮时请先加载**原来的 CT**，在原表中增加记录后再保存；软件会拒绝删除已登记记录的覆盖操作。
5. 关闭游戏并重启。再启动游戏、CE 与 Bridge 后，在网页点击按钮；软件检查目标进程，重载 CT，并切换对应 CE MemoryRecord 的 Active 状态。

**重要区别：** 按钮的关闭表示取消 CE 记录的激活/冻结。它**不保证**已更改的金币、存档或游戏机制完全复原；具体取决于 CT 脚本的 Disable 实现。保存了错误的绝对地址不会自动变成稳定指针，必须在 CE 中采用可靠指针链、AOB 或其他经验证的定位技术。

### 与 Codex Agent 配合

可以在原生 Windows Codex CLI 中另外配置 CE MCP（对应 bootstrap 下载的同一份脚本）：

~~~toml
[mcp_servers.cheatengine]
command = "python"
args = ['D:\AI-Game-Trainer\vendor\cheatengine-mcp-bridge\MCP_Server\mcp_cheatengine.py']
~~~

上面的盘符路径仅是示例，需要替换为实际绝对路径。安装该 MCP 的依赖：

~~~powershell
py -m pip install -r .\vendor\cheatengine-mcp-bridge\MCP_Server\requirements.txt
~~~

你可让 Codex 在允许的本地测试进程上探索，并把经验证的逻辑保存成 CE 地址列表记录。**目前对话仍在 Codex 外部进行**；这不是嵌入式 AI 聊天。若 Codex 在 WSL 中运行，请按照上游 README 的 TCP Relay 方案；Windows 命名管道不能直接跨 WSL 访问。

### 可选 TCP Relay

用上游的 ce_tcp_relay.py（Windows）监听 loopback：

~~~powershell
py .\vendor\cheatengine-mcp-bridge\MCP_Server\ce_tcp_relay.py --host 127.0.0.1 --port 9876
$env:TRAINER_CE_TRANSPORT = "tcp"
py -m trainer
~~~

不要将 TCP Relay 绑定到公网或不可信网络接口，它能控制 Cheat Engine。

## 当前限制及风险

- 仅用于你有权限修改的**本地离线单机程序**。不提供反作弊绕过、联机游戏服务器数值修改或内核隐藏能力。
- 页面按钮需要 CE 和 Lua Bridge 处于运行状态。无 CE 时仍能打开页面及查看已保存的按钮。
- 只能在发现唯一匹配 EXE 的进程时运行，且首次切换会加载整张保存的 CT，可能覆盖 CE 当前未保存的表。
- 同一张表内的记录描述必须唯一；不要将运行时绝对内存地址当成永久有效的标识。
- 此版本不会自动识别游戏更新或修复失效的指针/AOB。跨重启持久化的是 CT 和功能定义，**不是成功修改的承诺**。
- 上游 CE Bridge v12 的底层脚本具有 Lua 执行能力，所以仅加载可信任的 CT 与 Lua 文件；定期备份游戏存档。
- 默认服务仅在 127.0.0.1 上监听；不会将任何训练数据/游戏内存发往云端。
```

```c
/* Harmless local fixture for the AI Game Trainer CE read/write smoke test.
 * No injection, drivers, persistence, networking or external game interaction.
 * Built into Tools/AITrainerDemo.exe with MSVC /MT for a standalone runtime.
 */
#define WIN32_LEAN_AND_MEAN
#include <windows.h>
#include <stdint.h>
#include <stdio.h>
#include <wchar.h>

static volatile LONG g_demo_number = 123;

int wmain(int argc, wchar_t **argv)
{
    FILE *out = NULL;
    if (argc != 3 || wcscmp(argv[1], L"--ready-file") != 0) {
        return 2;
    }
    if (_wfopen_s(&out, argv[2], L"wb") != 0 || out == NULL) {
        return 3;
    }
    fprintf(out, "{\"pid\":%lu,\"address\":\"0x%llX\"}",
            (unsigned long)GetCurrentProcessId(),
            (unsigned long long)(uintptr_t)&g_demo_number);
    fclose(out);

    /* Refer to the volatile number so the compiler retains the symbol. */
    while (1) {
        if (g_demo_number == -1) {
            return 0;
        }
        Sleep(100);
    }
}
```

`tests/test_bridge.py`:

```py
import json
import socket
import struct
import threading
import unittest

from trainer.bridge import CEBridge, BridgeError


class BridgeTests(unittest.TestCase):
    def _exchange(self, response):
        listener = socket.socket()
        listener.bind(("127.0.0.1", 0))
        listener.listen(1)
        port = listener.getsockname()[1]
        captured = []

        def server():
            try:
                conn, _ = listener.accept()
                with conn:
                    def exact(n):
                        chunks = []
                        while n:
                            piece = conn.recv(n)
                            if not piece:
                                raise EOFError()
                            chunks.append(piece)
                            n -= len(piece)
                        return b"".join(chunks)
                    length = struct.unpack("<I", exact(4))[0]
                    captured.append(json.loads(exact(length)))
                    payload = json.dumps(response).encode()
                    conn.sendall(struct.pack("<I", len(payload)) + payload)
            finally:
                listener.close()

        worker = threading.Thread(target=server, daemon=True)
        worker.start()
        try:
            return CEBridge(transport="tcp", port=port).call("ping"), captured
        finally:
            worker.join(timeout=3)

    def test_tcp_json_rpc_framing(self):
        reply, calls = self._exchange({"jsonrpc": "2.0", "result": {"success": True, "version": "12.0.0"}, "id": 1})
        self.assertEqual(reply["version"], "12.0.0")
        self.assertEqual(calls[0]["method"], "ping")

    def test_bridge_error_is_not_reported_successfully(self):
        with self.assertRaises(BridgeError):
            self._exchange({"jsonrpc": "2.0", "result": {"success": False, "error": "Not attached"}, "id": 1})


if __name__ == "__main__":
    unittest.main()
```

```py
"""Small direct client for miscusi-peek/cheatengine-mcp-bridge v12.

Wire format: little-endian uint32 payload length + JSON-RPC 2.0 bytes.
No arbitrary command endpoint is exposed to HTTP clients.
"""
from __future__ import annotations

import json
import os
import socket
import struct

PIPE_NAME = r"\\.\pipe\CE_MCP_Bridge_v99"
MAX_REPLY = 8 * 1024 * 1024


class BridgeError(RuntimeError):
    """The CE bridge is unavailable or returned an error."""


def _read_socket(sock: socket.socket, count: int) -> bytes:
    pieces = []
    while count:
        data = sock.recv(count)
        if not data:
            raise BridgeError("CE bridge closed the connection")
        pieces.append(data)
        count -= len(data)
    return b"".join(pieces)


class CEBridge:
    """One connection per request; avoids sharing a named-pipe handle across threads."""

    def __init__(self, transport: str | None = None, port: int | None = None):
        self.transport = transport or os.environ.get(
            "TRAINER_CE_TRANSPORT", "pipe" if os.name == "nt" else "tcp"
        )
        self.port = int(port or os.environ.get("TRAINER_CE_PORT", "9876"))
        if self.transport not in ("pipe", "tcp"):
            raise ValueError("TRAINER_CE_TRANSPORT must be pipe or tcp")
        if not 1 <= self.port <= 65535:
            raise ValueError("Invalid CE relay port")
        if self.transport == "pipe" and os.name != "nt":
            raise ValueError("Named pipes require Windows")

    def call(self, method: str, params: dict | None = None) -> dict:
        payload = json.dumps(
            {"jsonrpc": "2.0", "method": method, "params": params or {}, "id": 1},
            ensure_ascii=False,
        ).encode("utf-8")
        request = struct.pack("<I", len(payload)) + payload
        try:
            if self.transport == "tcp":
                with socket.create_connection(("127.0.0.1", self.port), timeout=5) as sock:
                    sock.settimeout(8)
                    sock.sendall(request)
                    length = struct.unpack("<I", _read_socket(sock, 4))[0]
                    if length > MAX_REPLY:
                        raise BridgeError("CE bridge response exceeds size limit")
                    raw = _read_socket(sock, length)
            else:
                raw = self._pipe_exchange(request)
            result = json.loads(raw)
        except BridgeError:
            raise
        except (OSError, ValueError, json.JSONDecodeError) as exc:
            raise BridgeError("Cannot communicate with CE Bridge: " + str(exc)) from exc
        if not isinstance(result, dict):
            raise BridgeError("Invalid CE bridge response")
        if "error" in result:
            raise BridgeError(str(result["error"]))
        value = result.get("result", result)
        if not isinstance(value, dict):
            raise BridgeError("Invalid CE bridge result")
        if value.get("success") is False:
            raise BridgeError(str(value.get("error", "CE command failed")))
        return value

    @staticmethod
    def _pipe_exchange(request: bytes) -> bytes:
        try:
            import win32file
        except ImportError as exc:
            raise BridgeError("Install Windows dependencies: py -m pip install -r requirements-windows.txt") from exc
        handle = None
        try:
            handle = win32file.CreateFile(
                PIPE_NAME,
                win32file.GENERIC_READ | win32file.GENERIC_WRITE,
                0, None, win32file.OPEN_EXISTING, 0, None,
            )
            # Keep the two writes used by upstream v12 (header, then JSON body).
            win32file.WriteFile(handle, request[:4])
            win32file.WriteFile(handle, request[4:])
            length_bytes = CEBridge._read_pipe(handle, 4, win32file)
            length = struct.unpack("<I", length_bytes)[0]
            if length > MAX_REPLY:
                raise BridgeError("CE bridge response exceeds size limit")
            return CEBridge._read_pipe(handle, length, win32file)
        finally:
            if handle is not None:
                win32file.CloseHandle(handle)

    @staticmethod
    def _read_pipe(handle, length: int, win32file) -> bytes:
        output = bytearray()
        while len(output) < length:
            _, part = win32file.ReadFile(handle, length - len(output))
            if not part:
                raise BridgeError("CE pipe disconnected")
            output.extend(part)
        return bytes(output)
```

```py
Never writes to the user's game or an arbitrary executable. The demo process

class DiagnosticError(RuntimeError):
    """Local demo target or CE test failed."""


def demo_exe_path() -> Path:
    if getattr(sys, "frozen", False):
        return Path(sys.executable).resolve().parent / "Tools" / "AITrainerDemo.exe"
    return Path(__file__).resolve().parents[1] / "bin" / "AITrainerDemo.exe"


def verify_memory_roundtrip(bridge, pid: int, address: str) -> dict:
    """Attach to our freshly spawned process; test and restore a DWORD."""
    bridge.call("open_process", {"process_id_or_name": pid})
    info = bridge.call("get_opened_process_id")
    if int(info.get("process_id", 0)) != pid:
        raise DiagnosticError("Cheat Engine 未能附加到自动测试进程")

    args = {"address": address, "type": "dword"}
    original = bridge.call("read_integer", args).get("value")
    if original != 123:
        raise DiagnosticError(f"测试初始值不正确：期望 123，得到 {original!r}")

    changed_value = 777
    try:
        bridge.call("write_integer", {**args, "value": changed_value})
        actual = bridge.call("read_integer", args).get("value")
        if actual != changed_value:
            raise DiagnosticError(
                f"内存写入校验未通过：期望 {changed_value}，得到 {actual!r}"
            )
    finally:
        # The only target is the throwaway process created by this diagnostic.
        bridge.call("write_integer", {**args, "value": original})

    restored = bridge.call("read_integer", args).get("value")
    if restored != original:
        raise DiagnosticError("内存原值恢复失败")
    return {"initial": original, "changed": changed_value, "restored": restored}


def run_selftest(bridge, target: Path | None = None) -> dict:
    """Use the bundled demo process. No game/CT database is modified."""
    if os.name != "nt":
        raise DiagnosticError("一键 CE 实测仅支持 Windows")

    except BridgeError:
        # Fresh CE session with no process attached is expected.
        pass

    result = {}
    warnings = []
    with tempfile.TemporaryDirectory(prefix="ai-trainer-demo-") as folder:
        ready_file = Path(folder) / "ready.json"
        flags = getattr(subprocess, "CREATE_NO_WINDOW", 0)
        process = subprocess.Popen(
            [str(binary), "--ready-file", str(ready_file)],
            stdin=subprocess.DEVNULL,
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
            creationflags=flags,
        )
        try:
            deadline = time.monotonic() + 8.0
            while not ready_file.is_file():
                if process.poll() is not None:
                    raise DiagnosticError("测试进程启动失败，退出码：" + str(process.returncode))
                if time.monotonic() >= deadline:
                    raise DiagnosticError("等待自动测试进程启动超时")
```

```py
        self.store = Store(self.data_dir / "trainer.sqlite3")
        self.bridge = bridge or CEBridge()
        self._lock = threading.RLock()
        self._loaded = None
        self._states = {}

    def table_path(self, game_id: str) -> Path:
        self.store.game(game_id)
        return (self.data_dir / "tables" / (game_id + ".CT")).resolve()

    def snapshot(self) -> dict:
        games = self.store.games()
        return {
            "games": [
                {**game, "features": [
                    {**feature, "enabled": bool(self._states.get(feature["id"], False))}
                    for feature in self.store.features(game["id"])
                ],
                 "has_table": self.table_path(game["id"]).is_file()}
                for game in games
            ],
            "data_dir": str(self.data_dir),
        }

    def selftest(self) -> dict:
        with self._lock:
            return run_selftest(self.bridge)

    def status(self) -> dict:
        try:
            reply = self.bridge.call("ping")
            return {"connected": True, "version": reply.get("version"), "message": reply.get("message")}
        except BridgeError as exc:
            return {"connected": False, "message": str(exc)}

    def _target_pid(self, game: dict) -> int:
        result = self.bridge.call("get_process_list")
        matches = [
            p for p in result.get("processes", [])
            if str(p.get("name", "")).casefold().rsplit("\\", 1)[-1].casefold()
            == game["exe"].casefold()
        ]
        if not matches:
            raise StoreError("未检测到 " + game["exe"] + "，请先启动对应的单机游戏")
        if len(matches) != 1:
            raise StoreError("发现同名进程多于一个；当前版本禁止自动选择进程")
        return int(matches[0]["pid"])

    def _attached_to(self, pid: int):
        result = self.bridge.call("get_opened_process_id")
        if int(result.get("process_id", 0)) != pid:
            raise StoreError("Cheat Engine 当前连接的不是该游戏，请在 CE 中先选择正确进程")

    def _records(self):
        result = self.bridge.call("get_address_list", {"offset": 0, "limit": 1000})
        if int(result.get("total", len(result.get("records", [])))) > 1000:
            raise StoreError("CE 表超过 1000 条记录；当前版本不支持自动匹配")
        return result.get("records", [])

    def records(self, game_id: str):
        with self._lock:
            game = self.store.game(game_id)
            self._attached_to(self._target_pid(game))
            return [
                {"id": r.get("id"), "description": r.get("description"),
                 "enabled": bool(r.get("enabled"))}
                for r in self._records() if r.get("description")
            ]

    def capture(self, game_id: str, title: str, description: str) -> dict:
        """Save the entire current CE table after validating all referenced records."""
        with self._lock:
            game = self.store.game(game_id)
            self._attached_to(self._target_pid(game))
            records = self._records()
            descriptions = [r.get("description") for r in records]
            if descriptions.count(description) != 1:
                raise StoreError("CE 表中必须有且仅有一条同名记录：" + description)
            for saved in self.store.features(game_id):
                if descriptions.count(saved["record_description"]) != 1:
                    raise StoreError("CE 当前表缺少已保存功能：" + saved["record_description"] + "；请先加载旧表再追加")
            if any(f["record_description"] == description for f in self.store.features(game_id)):
                raise StoreError("这条 CE 记录已经保存过")
            if not title.strip() or len(title.strip()) > 128:
                raise StoreError("功能名称需要 1–128 个字符")
            target = self.table_path(game_id)
            staging = target.with_name(target.stem + ".pending.CT")
            try:
                self.bridge.call("save_table", {"filename": str(staging)})
                if not staging.is_file() or staging.stat().st_size == 0:
                    raise StoreError("CE 没有生成有效 CT 文件")
                staging.replace(target)
                new_feature = self.store.add_feature(game_id, title, description)
            finally:
                staging.unlink(missing_ok=True)
            self._loaded = None
            self._states.clear()
            return new_feature

    def toggle(self, feature_id: str, enabled: bool):
        if type(enabled) is not bool:
            raise StoreError("enabled 必须为 true 或 false")
        with self._lock:
            feature = self.store.feature(feature_id)
            game = self.store.game(feature["game_id"])
            path = self.table_path(game["id"])
            if not path.is_file():
                raise StoreError("此游戏尚未保存 CT 文件")
            pid = self._target_pid(game)
            table_key = (game["id"], pid, path.stat().st_mtime_ns)
            if self._loaded != table_key:
                self._states.clear()
                self.bridge.call("open_process", {"process_id_or_name": pid})
                self._attached_to(pid)
                self.bridge.call("load_table", {"filename": str(path), "merge": False})
                self._loaded = table_key
            else:
                self._attached_to(pid)
            matches = [r for r in self._records() if r.get("description") == feature["record_description"]]
            if len(matches) != 1:
                raise StoreError("CT 中找不到唯一对应的记录，请检查游戏更新及 CT 文件")
            record_id = int(matches[0]["id"])
            if record_id < 0 or record_id > 2**31 - 1:
                raise StoreError("无效的 CE 记录 ID")
            # Lua expression contains only a checked integer, never raw client input.
            expression = (
                "local r=getAddressList():getMemoryRecordByID(" + str(record_id) + "); "
                "if not r then error('record not found') end; "
                "r.Active=" + ("true" if enabled else "false") + "; "
                "return tostring(r.Active)"
            )
            self.bridge.call("evaluate_lua", {"code": expression})
            actual = self.bridge.call("get_memory_record", {"id": record_id}).get("record", {})
            if bool(actual.get("enabled")) != enabled:
                raise BridgeError("CE 未能切换记录状态；按钮状态未更新")
            self._states[feature_id] = enabled
            return {"feature_id": feature_id, "enabled": enabled, "process_id": pid}
```

```js
  const options = payload === undefined ? {} : {

  return result;
}
```

```py
"""Durable game and trainer feature metadata, separated from runtime state."""
from __future__ import annotations

import sqlite3
from contextlib import contextmanager
import uuid
from pathlib import Path


class StoreError(ValueError):
    pass


def _as_dict(row):
    return dict(row) if row is not None else None


class Store:
    def __init__(self, path: Path):
        self.path = Path(path)
        self.path.parent.mkdir(parents=True, exist_ok=True)
        with self._connect() as db:
            db.executescript("""
                CREATE TABLE IF NOT EXISTS games (
                    id TEXT PRIMARY KEY,
                    name TEXT NOT NULL,
                    exe TEXT NOT NULL COLLATE NOCASE UNIQUE,
                    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
                );
                CREATE TABLE IF NOT EXISTS features (
                    id TEXT PRIMARY KEY,
                    game_id TEXT NOT NULL REFERENCES games(id) ON DELETE CASCADE,
                    title TEXT NOT NULL,
                    record_description TEXT NOT NULL,
                    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP,
                    UNIQUE(game_id, record_description)
                );
            """)

    @contextmanager
    def _connect(self):
        db = sqlite3.connect(self.path, timeout=10)
        try:
            db.row_factory = sqlite3.Row
            db.execute("PRAGMA foreign_keys = ON")
            db.execute("PRAGMA busy_timeout = 10000")
            with db:
                yield db
        finally:
            db.close()

    def add_game(self, name: str, exe: str):
        name, exe = name.strip(), exe.strip()
        if not name or len(name) > 128:
            raise StoreError("游戏名称需要 1–128 个字符")
        if not exe or len(exe) > 255 or "/" in exe or "\\" in exe or not exe.lower().endswith(".exe"):
            raise StoreError("请输入游戏进程文件名，例如 game.exe（不能是完整路径）")
        item_id = uuid.uuid4().hex
        try:
            with self._connect() as db:
                db.execute("INSERT INTO games(id, name, exe) VALUES(?, ?, ?)", (item_id, name, exe))
        except sqlite3.IntegrityError as exc:
            raise StoreError("此 EXE 已经添加到游戏库") from exc
        return self.game(item_id)

    def game(self, game_id: str):
        with self._connect() as db:
            row = db.execute("SELECT * FROM games WHERE id = ?", (game_id,)).fetchone()
        if not row:
            raise StoreError("未找到游戏")
        return _as_dict(row)

    def games(self):
        with self._connect() as db:
            rows = db.execute("SELECT * FROM games ORDER BY created_at, rowid").fetchall()
        return list(map(_as_dict, rows))

    def add_feature(self, game_id: str, title: str, record_description: str):
        title, record_description = title.strip(), record_description.strip()
        self.game(game_id)
        if not title or len(title) > 128 or not record_description or len(record_description) > 255:
            raise StoreError("请提供功能名称与准确的 CE 记录描述")
        item_id = uuid.uuid4().hex
        try:
            with self._connect() as db:
                db.execute(
                    "INSERT INTO features(id, game_id, title, record_description) VALUES(?, ?, ?, ?)",
                    (item_id, game_id, title, record_description),
                )
        except sqlite3.IntegrityError as exc:
            raise StoreError("该 CE 记录已经保存为按钮") from exc
        return self.feature(item_id)

    def feature(self, feature_id: str):
        with self._connect() as db:
            row = db.execute("SELECT * FROM features WHERE id = ?", (feature_id,)).fetchone()
        if not row:
            raise StoreError("未找到修改功能")
        return _as_dict(row)

    def features(self, game_id: str):
        with self._connect() as db:
            rows = db.execute(
                "SELECT * FROM features WHERE game_id = ? ORDER BY created_at, rowid",
                (game_id,),
            ).fetchall()
        return list(map(_as_dict, rows))
```

```py
"""Localhost-only HTTP UI. The browser never supplies raw CE commands or Lua."""
from __future__ import annotations

import json
import mimetypes
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from urllib.parse import parse_qs, urlsplit

from .bridge import BridgeError
from .diagnostics import DiagnosticError
from .service import TrainerService
from .store import StoreError

STATIC = Path(__file__).with_name("static")
MAX_BODY = 64 * 1024


def make_handler(service: TrainerService):
    class Handler(BaseHTTPRequestHandler):
        server_version = "AITrainer/0.1"

        def _headers(self, status: int, content_type: str):
            self.send_response(status)
            self.send_header("Content-Type", content_type)
            self.send_header("Cache-Control", "no-store")
            self.send_header("X-Content-Type-Options", "nosniff")
            self.send_header("X-Frame-Options", "DENY")
            self.send_header("Referrer-Policy", "no-referrer")
            self.send_header(
                "Content-Security-Policy",
                "default-src 'none'; script-src 'self'; style-src 'self'; "
                "connect-src 'self'; img-src 'self'; base-uri 'none'; form-action 'self'",
            )

        def _json(self, status, payload):
            body = json.dumps(payload, ensure_ascii=False).encode("utf-8")
            self._headers(status, "application/json; charset=utf-8")
            self.send_header("Content-Length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)

        def _same_origin(self):
            allowed = {"127.0.0.1:" + str(self.server.server_port),
                       "localhost:" + str(self.server.server_port)}
            if self.headers.get("Host", "") not in allowed:
                return False
            origin = self.headers.get("Origin")
            return origin is None or origin in {"http://" + x for x in allowed}

        def _route(self, path, payload):
            if path == "/api/games":
                return service.store.add_game(payload["name"], payload["exe"])
            if path == "/api/features/capture":
                return service.capture(
                    payload["game_id"], payload["title"], payload["record_description"]
                )
            if path == "/api/diagnostics/self-test":
                return service.selftest()
            if path == "/api/features/toggle":
                return service.toggle(payload["feature_id"], payload["enabled"])
            raise StoreError("未知操作")

        def do_GET(self):
            if not self._same_origin():
                return self._json(403, {"error": "Invalid host or origin"})
            parsed = urlsplit(self.path)
            try:
                if parsed.path == "/api/state":
                    return self._json(200, service.snapshot())
                if parsed.path == "/api/bridge":
                    return self._json(200, service.status())
                if parsed.path == "/api/records":
                    game_id = parse_qs(parsed.query).get("game_id", [""])[0]
                    return self._json(200, {"records": service.records(game_id)})
                if parsed.path == "/api/health":
                    return self._json(200, {"ok": True})
                assets = {"/": "index.html", "/app.js": "app.js", "/style.css": "style.css"}
                filename = assets.get(parsed.path)
                if filename:
                    data = (STATIC / filename).read_bytes()
                    mime = {"index.html": "text/html", "app.js": "application/javascript",
                            "style.css": "text/css"}[filename]
                    self._headers(200, mime + "; charset=utf-8")
                    self.send_header("Content-Length", str(len(data)))
                    self.end_headers()
                    self.wfile.write(data)
                    return
                return self._json(404, {"error": "Not found"})
            except (StoreError, DiagnosticError, ValueError, KeyError, TypeError) as exc:
                return self._json(400, {"error": str(exc)})
            except BridgeError as exc:
                return self._json(502, {"error": str(exc)})

        def do_POST(self):
            if not self._same_origin():
                return self._json(403, {"error": "Invalid host or origin"})
            if self.headers.get("Content-Type", "").split(";")[0].strip() != "application/json":
                return self._json(415, {"error": "Expected application/json"})
            try:
                size = int(self.headers.get("Content-Length", "-1"))
                if size < 0 or size > MAX_BODY:
                    return self._json(413, {"error": "Invalid request size"})
                payload = json.loads(self.rfile.read(size))
                if not isinstance(payload, dict):
                    raise ValueError("JSON body must be an object")
                result = self._route(urlsplit(self.path).path, payload)
                return self._json(200, result)
            except (StoreError, DiagnosticError, ValueError, KeyError, TypeError) as exc:
                return self._json(400, {"error": str(exc)})
            except BridgeError as exc:
                return self._json(502, {"error": str(exc)})

    return Handler


def serve(service: TrainerService, port: int = 8765):
    server = ThreadingHTTPServer(("127.0.0.1", port), make_handler(service))
    print("AI Game Trainer ready: http://127.0.0.1:" + str(server.server_port))
    return server
```
