# Исследование читов и план проверок античита

Обновлено: 2026-11-12. Назначение: исследование и тестирование на собственном плейсе или с разрешения владельца. Этот файл — журнал обнаруженных техник и задач, а не список уже работающих обходов в нашем клиенте.

## Статусы

- **Изучено в исходниках** — поведение видно в указанном публичном коде; его актуальность не проверена.
- **В нашем клиенте** — функциональность есть в модулях клиента; тестирование ещё необходимо.
- **Не проверено** — не проводили проверку в Codex или на текущей версии Roblox и античита плейса.
- **Защита не реализована** — рекомендации пока не означают наличие защиты в игре.

Ни один из изученных источников не доказывает работающий обход защиты платформы Roblox в 2026 году. Название «Bypass» или заявление автора не являются доказательством. Не запускаем чужие скрипты без проверки.

## Реестр эксплойтов и тестов для античита

### Speed и air jump: источники и что именно проверяем

- [Redline, beta.lua, фиксированный коммит](https://github.com/topitbopit/Redline/blob/7766d6fc8acbcb8068f674649246ec6a306d1bdf/beta.lua) содержит варианты speed через WalkSpeed, CFrame и скорость, а также air jump через изменение состояния или вертикальной скорости. В исходнике есть и другие механизмы; наши режимы **не являются полной копией Redline**. Его заявления об обходах не подтверждены тестом. Redline архивирован и распространяется под GPL-3.0; исходный код не копировался.
- [Infinite Yield, фиксированный исходник](https://github.com/EdgeIY/infiniteyield/blob/268826bc9ec64e80f56f0ecbc073a4d58c96f889/source) содержит изменение WalkSpeed и повторные запросы прыжка. В том же коде есть локальный перехват чтения WalkSpeed; аналогичный тест локального чтения добавлен в `src/bypass`; см. раздел ниже. Выводы основаны на статическом чтении, исходники не запускались.
- Наши тесты движения написаны отдельно; начинаются выключенными, имеют настройки и необязательные бинды. WalkSpeed восстанавливается условно, если значение не изменилось после нашей последней записи; CFrame и Velocity не откатывают уже совершённое движение. При респавне тесты сбрасываются. Репликация зависит от игры и сетевого владения. Синтаксис и поведение на макетах проверены, в реальном плейсе и Codex — **нет**.

### Что делать на сервере

1. Для скорости оценивать **серверно наблюдаемое горизонтальное перемещение** за интервалы времени, а не полагаться на клиентский WalkSpeed или один локальный обработчик. Сравнивать с допустимым пределом для конкретного состояния игры; учитывать ускорение, сетевые задержки, рывки, транспорт, платформы и разрешённые телепорты. Для сглаживания всплесков рассмотреть накопление превышений, откалиброванное на честных сессиях. [Roblox: network ownership и validation](https://create.roblox.com/docs/scripting/security/network-ownership).
2. Для air jump проверять серверно наблюдаемую вертикальную траекторию и допустимые источники импульса; отдельно разрешать игровые двойные прыжки, трамплины, отбрасывание, лестницы, падение и подвижные платформы. Одной клиентской проверке состояния Humanoid доверять нельзя. Порогов для этого плейса пока нет.
3. В закрытой тестовой копии сравнить обычную ходьбу, легальный спринт, каждый режим Speed, штатный прыжок, каждый режим Air jump, респавн и выключение; повторить при разных задержках и на движущейся платформе. Для каждого случая записать серверную траекторию, режим, настройки, версию, сетевые условия, обнаружение, предотвращение и ложные срабатывания.
4. При сомнении сначала логировать и безопасно возвращать к последней допустимой позиции, а не банить за один сигнал. Тестирование и калибровка обязательны. [Roblox: серверное обнаружение](https://create.roblox.com/docs/scripting/security/server-side-detection).

**Важно:** этот раздел — план и клиентские эксперименты, не доказанная совместимость или обход и не готовый античит. Другие исследованные техники описаны ниже с отдельными статусами.

## 1. Подавление клиентского сообщения о нарушении

**Пример:** [Da Hood AntiCheatBypass.lua](https://github.com/Stefanuk12/ROBLOX/blob/master/Games/Da%20Hood/AntiCheatBypass.lua).

**Что видно в исходнике:** обработчик перехватывает исходящие вызовы и не отправляет определённые сообщения с флагами клиентской проверки. Это код, привязанный к конкретному плейсу и его `MainEvent`, а не универсальный метод.

**Риск:** клиентский античит может заметить нарушение, но сервер не получит сигнал; сервер не должен считать отсутствие сигнала подтверждением честности.

**Что делать на сервере:** самостоятельно проверять состояние и допустимость действий. Клиентские сигналы использовать только как вспомогательные, не как единственное основание для наказания.

**Тест:** сравнить серверную регистрацию недопустимого перемещения, когда клиентская проверка активна и когда её сигнал не приходит. Ожидаем, что нарушение будет зафиксировано сервером в обоих случаях.

**Статус:** в `src/bypass` добавлен тест подавления явно указанного RemoteEvent и флага; только для разрешённого PlaceId. Не проверено в игре; защита не реализована.

## 2. Отключение клиентских обработчиков изменений

**Пример:** [Redline, beta.lua, фиксированный коммит](https://github.com/topitbopit/Redline/blob/7766d6fc8acbcb8068f674649246ec6a306d1bdf/beta.lua).

**Что видно в исходнике:** функция `disablecons` перечисляет соединения сигнала и отключает некоторые локальные обработчики. В режиме телепорта через препятствие она применяется к локальным сигналам изменения позиции персонажа, затем обработчики восстанавливаются.

**Риск:** античит, который зависит от конкретного локального обработчика изменения позиции, может перестать получать события. Это не доказывает влияние на серверные обработчики.

**Что делать на сервере:** анализировать изменения серверно наблюдаемой позиции и допустимые перемещения независимо от клиентских обработчиков. Учитывать легальные телепорты, транспорт, лаг и механику игры.

**Тест:** на своей тестовой карте сравнить обычную ходьбу, разрешённый телепорт и неразрешённое перемещение; убедиться, что пропажа локального сигнала не отключает серверную проверку.

**Статус:** в модулях клиента есть watcher test для экспериментального отключения заданных локальных обработчиков. По умолчанию список имён пуст, необходимы поддержка executor и конфигурация; в Codex и игре не проверено. Серверная защита не реализована. Redline архивирован и прекращён в 2023 году.

## 3. Noclip и перемещение через препятствия

**Пример:** [Redline, beta.lua](https://github.com/topitbopit/Redline/blob/7766d6fc8acbcb8068f674649246ec6a306d1bdf/beta.lua), раздел `Noclip`.

**Что видно в исходнике:** режим Standard меняет локальную коллизию частей персонажа; режим Teleport пытается перемещать персонажа через препятствие. Комментированный в файле режим Bypass не следует считать действующим кодом.

**Риск:** при неподходящей серверной модели движения персонаж может оказаться за препятствием, не пройдя допустимый маршрут. Результат зависит от репликации, network ownership и устройства плейса.

**Что делать на сервере:** проверять допустимость траектории между серверными наблюдениями относительно статической геометрии и использовать ограничения движения, согласованные с игровыми механиками. Рассмотреть [server authority](https://create.roblox.com/docs/projects/server-authority), если она подходит проекту. При сомнении возвращать к последней допустимой позиции, а не банить автоматически.

**Тест:** статичная стена, тонкая стена, дверь, легальный телепорт, движущаяся платформа и сетевые задержки. Проверить, не блокируются ли честные игроки.

**Статус:** в модулях клиента добавлен локальный noclip, без режима Teleport; не проверено в Codex или игре; серверная защита не реализована.

## 4. ESP на основе реплицированных данных

**Пример:** [Exunys ESP-Script](https://github.com/Exunys/ESP-Script/blob/main/ESP.lua).

**Что видно в исходнике:** скрипт читает данные других персонажей, преобразует координаты головы в экранные и локально рисует надписи. Это функция чита, не доказанный обход конкретной защиты.

**Риск:** клиент может показать то, что уже получил, даже если интерфейс игры это не показывает. Сервер напрямую не видит локальный оверлей.

**Что делать:** минимизировать передачу ненужной чувствительной информации, где это технически возможно; продумать механику видимости и сетевую модель. Одной серверной проверкой попаданий нельзя надёжно определить ESP.

**Тест:** проверить, какие координаты и данные противника клиент получает за стеной, на дистанции и вне области интереса. Не считать отсутствие ESP доказательством, что данные не доступны другим способам.

**Статус:** способ изучен; в модулях клиента есть самостоятельно реализованные Highlight и 2D-оверлей с настройками; не проверено в игре; защита не реализована.

## 5. Aimbot и скрытая помощь при прицеливании

**Пример:** [Redline, beta.lua](https://github.com/topitbopit/Redline/blob/7766d6fc8acbcb8068f674649246ec6a306d1bdf/beta.lua), раздел `Aimbot`.

**Что видно в исходнике:** присутствуют режимы наведения через камеру и мышь, фильтры цели, захват и предсказание. Это помощь в прицеливании, не доказательство обхода защиты платформы.

**Риск:** корректный с точки зрения сервера выстрел может быть направлен с помощью клиента. Одна проверка луча не отличает помощь при прицеливании от честного попадания.

**Что делать:** серверно проверять геометрию выстрела и состояние оружия; собирать последовательности событий для калиброванных поведенческих сигналов (например, динамика наведения и повторяемость реакции). Сигналы рассматривать в совокупности, с учётом задержки, мастерства игрока и особенностей оружия. Не банить только по одному признаку.

**Тест:** сравнить наш тестовый клиент и честные сессии разных игроков; оценить ложные срабатывания, условия и объём данных. Не считать статистическую аномалию доказательством сама по себе.

**Статус:** в модулях клиента есть простой camera aimbot, не копия Redline; не проверено; защита не реализована.

## 6. Подделка параметров и частоты выстрела

**Источник:** [Roblox: защита границы клиент—сервер](https://create.roblox.com/docs/scripting/security/client-server-boundary), разделы Weapon targeting и Rate limiting. Это модель угроз из документации, а не утверждение о возможностях конкретного чита.

**Риск:** сервер доверяет клиенту цель, урон, патроны, дистанцию или частоту выстрела.

**Что делать:** хранить боезапас, скорострельность, состояние оружия и урон на сервере; проверять типы и конечность чисел, происхождение выстрела, допустимую дистанцию, команду, живого противника и препятствия; ограничивать частоту запросов. Учитывать сетевую задержку и легальные игровые состояния.

**Тест:** отправить в тестовом плейсе неправильные данные, события чаще допустимого, выстрел без патронов и заявленное попадание через статическую стену. Сервер должен отклонять недопустимое, а легальные выстрелы с задержкой — принимать.

**Статус:** угроза по документации; у нас не реализовано; не проверено; защита не реализована.

## Следующие шаги

1. Получить архитектуру оружия: серверные скрипты выстрела, обработчики RemoteEvent и устройство персонажей.
2. Настроить закрытую тестовую копию и журналирование сессий, версий, результатов и сетевых условий.
3. Провести испытания из пунктов выше; отдельно записать «обнаружено», «предотвращено», «ложное срабатывание» и доказательства.
4. При изменениях платформы повторять проверки. Ничего не отмечать как закрытое до теста и проверки регрессий.

## Aimbot V3 и Open Aimbot — исследование наведения

- [Exunys/Aimbot-V3](https://github.com/Exunys/Aimbot-V3) — открытый aim-lock; проверенный [коммит от 2026-10-04](https://github.com/Exunys/Aimbot-V3/commit/a710f210aa795e667f484942ab8952977341f2dd). В [исходнике](https://github.com/Exunys/Aimbot-V3/blob/a710f210aa795e667f484942ab8952977341f2dd/src/Aimbot.lua) есть wall check с `GetPartsObscuringTarget`, отсев команды и живых целей, camera/mouse режимы. Проект CC0; README просит указать автора. Сам по себе недавний коммит не подтверждает работоспособность со всеми играми или Codex.
- [Open Aimbot, исследованный исходник](https://github.com/Sezemi/Aimbot-Universal/blob/268d642b57f66aafc66ae44fe19f7f3988509ed5/source.lua) — старый форк, последний проверенный коммит от 2024-10-12. В коде есть режим Silent, перехватывающий определённые обращения к `Mouse.Hit` и `Mouse.Target`. Название Detection Bypasses в README — заявление автора; исследованный фрагмент не доказывает обход защиты Roblox или серверного античита.

**Адаптация в модулях клиента:** самостоятельно написанная проверка видимости по мотивам Aimbot V3 и экспериментальный режим подмены `Mouse.Hit`/`Mouse.Target` по мотивам Open Aimbot. Это не копия исходников. Silent активен только при включённом aimbot, активном назначенном триггере (по умолчанию ПКМ, Hold), закрытом меню и подходящих функциях executor. Он не меняет серверную логику и не помогает играм, которые не используют эти поля мыши. Hook после выключения/cleanup остаётся установленным, но его логика неактивна до конца сессии. Код не проверен в Codex или плейсе.

**Для защиты:** сервер проверяет выстрелы, боезапас, частоту и геометрию, не доверяя клиентской цели; тестирует выстрелы через статическую стену и неподходящую дистанцию. Если выстрел геометрически допустим, сам по себе этот метод нельзя надёжно отличить от честного наведения. Калибровать поведенческие сигналы на серии данных, не банить по одному признаку.

## Установка и запуск

Для сетевого запуска нужен публичный репозиторий и executor с `game:HttpGet` и `loadstring`. Скрипт скачивает модули из ветки `main`, поэтому при запуске используется её текущее содержимое:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/BonzeD/deadline_cheat_testAnticheat/main/loader.lua"))()
```

Настройки профилей остаются в локальной папке `DeadlineTest`; для них нужны файловые функции executor. Если `makefolder` не поддерживается, создай папку вручную. Сетевой запуск ещё не проверен в Roblox/Codex. Альтернатива — скачать репозиторий, распаковать его и поместить папку с `main.lua` и `src` в workspace executor под именем `DeadlineTest`. Не публикуй токены и не добавляй их в скрипт.

Если executor поддерживает `readfile` и `loadstring`, запуск:

```lua
loadstring(readfile("DeadlineTest/main.lua"))()
```

При локальном запуске загрузчик читает модули из этой папки. Для другого имени до запуска укажи `getgenv().DeadlineRoot = "имя_папки"` и измени путь к `main.lua`. Возможности файловой системы отличаются между версиями executor и платформами; поддержка именно твоего Codex **не проверена**. Если `readfile` или папка недоступны, локальный запуск не заработает. Изменения в GitHub нужно заново скачать в локальную папку.

## Управление

- **Right Shift** — открыть или скрыть меню; клавиша зарезервирована, чтобы окно всегда можно было вернуть. Окно можно перетаскивать за заголовок.
- Во вкладке **BINDS** у каждого действия есть кнопка клавиши и кнопка **MODE: Toggle / Hold**. Нажми на клавишу, затем нужную кнопку клавиатуры или мыши. **Escape** удаляет бинд; конфликтующее старое назначение снимается.
- **Toggle** переключает функцию каждым нажатием. **Hold** включает функцию на время удержания и выключает после отпускания. При выборе Hold функция сначала выключается; при открытии меню, потере фокуса или вводе текста удерживаемые функции выключаются. Если executor не поддерживает нужную функцию, удержание её не включит.
- У **Aim trigger** режим синхронизирован с **AIM → Activation**: Hold — удерживать для наведения, Toggle — включать и выключать наведение нажатием. Это отдельно от **Toggle aimbot**, который управляет главным выключателем аима. Right Shift для меню остаётся переключателем.
- Прежние функциональные бинды F6–F11 удалены. Изначально назначены только Right Shift для меню и ПКМ для активации прицеливания. Их назначение не запускает функцию при открытом меню.
- Во вкладке **AIM** включи **Aimbot**, назначь **Aim activation key**, закрой меню и удерживай эту клавишу. **Toggle aimbot** в BINDS — другая клавиша: она только включает/выключает саму функцию. Режим **Toggle** вместо удержания включает и выключает прицеливание нажатием. Открытие меню или потеря фокуса сбрасывает активацию.
- Основные функции при запуске выключены. Профили автоматически не загружаются, но их ручная загрузка может включить сохранённые функции.
- Язык: **CONFIGS → Language**. Основные названия переведены на украинский; часть пояснений и технических сообщений остаётся на английском. Язык сохраняется в профиле.
- Настройки и бинды можно сохранить вручную во вкладке **CONFIGS** и потом загрузить. Автозагрузка не включена.

## Интерфейс и курсор

Оформление — собственная реализация по мотивам [Abysall Hub](https://github.com/bocaj111004/Abysall/blob/66d4192d00d9b824a304b654bc2d2eb89c3b372b/Components/Interface.luau) и его оболочки [Obsidian](https://github.com/deividcomsono/Obsidian/tree/679459720d76be014159f80de3ced858b6a1d7ea): две колонки групп, тёмные панели и синий акцент. Это не точная копия и не сама библиотека Obsidian; сторонние скрипты интерфейса по сети не загружаются.

Right Shift открывает меню. При открытом меню **Right Ctrl** переключает режимы «камера» и «курсор»: в режиме камеры меню остаётся видимым, но перестаёт принудительно управлять мышью; нажми Right Ctrl снова для работы с меню. Поведение зависит от игры и пока не проверено в Roblox. Пока оно открыто, клиент пытается освободить и показать курсор, затем восстановить последнее замеченное состояние мыши при закрытии или cleanup. Если игра непрерывно перехватывает мышь, поведение может отличаться. Если правая кнопка удерживалась при открытии меню, затем была отпущена, скрипт старается не восстанавливать устаревшую блокировку LockCurrentPosition; LockCenter для вида от первого лица сохраняется. В режиме Hold дополнительно проверяется физическое состояние клавиши, если событие отпускания потерялось. Это не имитирует нажатия или отпускания мыши. Меню размещается в `gethui`, затем при возможности в CoreGui, иначе в PlayerGui; выставляется высокий DisplayOrder и при поддержке executor включается `OnTopOfCoreBlur`. Это попытка, а **не гарантия** отображения или кликов поверх системного Esc-меню Roblox, окон других программ или во всех версиях Codex. Если Esc перекрывает меню, сначала закрой Esc, затем нажми Right Shift.

## Конфиги

Во вкладке **CONFIGS** введи имя из латинских букв, цифр, дефиса или `_` (до 32 символов), нажми **SAVE**, позже — **LOAD**. Повторное сохранение перезаписывает профиль с тем же именем. **REFRESH** показывает список при поддержке `listfiles`; если его нет, введи известное имя вручную. Нужны `readfile` и `writefile`; корректность загрузки для Codex пока не проверена. Файлы находятся рядом с `main.lua`, например `DeadlineTest/config_default.json`. **Перед заменой папки проекта сохрани файлы `config_*.json`**, иначе они будут удалены вместе со старой папкой.

Хранятся бинды и их режимы Hold / Toggle, доступные ползунки, списки выбора и обычные логические настройки, включая визуальные режимы. Режимы, требующие установки хуков или отдельной проверки возможностей executor (**Silent Aim, Trigger Bot, Auto Jump**), а также активное состояние экспериментов движения и bypass не сохраняются как включённые. Их нужно включить вручную. Параметры allowlist и пути remote тоже не входят в конфиг. Для старых профилей без режимов биндов используется Toggle; режим Aim trigger сохраняется отдельно в AimMode. При загрузке функции с режимом Hold выключаются до удержания клавиши. JSON проверяется перед применением; конфиг не исполняется как код.

## Прицеливание

AIM содержит выбор части персонажа (Head, HumanoidRootPart, UpperTorso, Torso), радиус FOV относительно центра экрана, видимый круг, плавность реакции (Response: меньше — плавнее), максимальную дистанцию, оценку упреждения в секундах, удержание цели, фильтры команды и препятствий, а также Hold / Toggle. Подходящая цель должна быть живым игроком с Head, Humanoid и выбранной частью; названия частей и команды зависят от устройства игры. Упреждение — простое умножение текущей скорости на время, не баллистическая модель.

Silent aim экспериментален, зависит от функций executor и только от игр, которые читают `Mouse.Hit` / `Mouse.Target`; серверные проверки он не отключает. Перехват после выключения остаётся установленным, но неактивным до завершения сессии. Если в той же игровой сессии был установлен хук старой версией клиента, перезапусти сессию: старый хук повторно используется и может игнорировать упреждение.

Дополнительно можно выбрать приоритет подходящих целей: ближайшая к центру экрана, ближайшая по дистанции или с минимальным текущим здоровьем. Смещение по высоте задаётся в studs. Sticky target сохраняет выбранную цель до тех пор, пока она подходит фильтрам, даже при смене приоритета.

## Дополнительные функции — EXTRAS

Все новые переключатели выключены при запуске. Бинды назначаются в **BINDS** и могут сохраняться в профиле; профиль загружается вручную.

- **Auto jump** повторно отправляет локальный запрос на прыжок, когда персонаж стоит на земле; есть интервал и опция «только при движении». При открытом меню, вводе текста, потере фокуса или респавне не работает; после респавна отключается. Влияние зависит от физики и правил игры.
- **Trigger bot** нажимает левую кнопку, когда курсор находится на персонаже другого живого игрока. Есть задержка удержания цели, интервал между кликами, максимальная дистанция, фильтр команды и режим активации: `Aim` — только при активном Aim trigger, `Always` — пока функция включена. При открытом меню, потере фокуса и вводе текста не стреляет; при респавне выключается. Использует `mouse.Target` и executor-функцию `mouse1click`: если последней нет, не включится. Это не интеграция с оружием или гарантия совместимости.
- **Crosshair** — экранный прицел в центре: Cross, Dot или Cross+Dot, регулируемые длина, промежуток, толщина, оттенок, прозрачность и вращение. Это оверлей, а не изменение разброса оружия.
- **Fullbright** — локальная яркость и Ambient; ползунок яркости. **No fog** меняет локальный FogEnd, но не обещает убрать Atmosphere или эффекты конкретных игр.
- **Camera FOV** — локально задаёт поле зрения камеры; есть ползунок. Может конфликтовать с прицеливанием и зумом оружия.

Изменения освещения и FOV восстанавливаются при выключении или cleanup, если свойство всё ещё равно последнему установленному значению. Когда игра меняет значение во время работы, модуль старается сохранить это изменение; не гарантируется совместимость с другими скриптами. При изменении камеры прежняя восстанавливается по тому же правилу. Это не обход античита.

## ESP

Экранные элементы ESP переиспользуются для того же персонажа при временном скрытии фильтрами; при выходе игрока, смене персонажа или очистке клиента они удаляются. Если все 2D-элементы выключены, расчёт габаритов пропускается. Это уменьшает лишнюю работу, но не гарантирует отсутствие лагов.

ESP при выключении очищает свои объекты, а при повторном включении создаёт их заново. Ошибка периодического сканирования не должна навсегда остановить цикл; конкретную причину ошибки в игре ещё нужно проверить.

**ESP STYLE → Skeleton** показывает приблизительные линии между центрами частей стандартных R6/R15, с регулируемой толщиной. Для нестандартных персонажей возможны пропуски; это не точное отображение суставов.

Открой **ESP** для включения и фильтров, **ESP STYLE** — для внешнего вида. **Your team** автоматически показывает команду текущего игрока. **Team checker** показывает число остальных игроков: A — союзники, E — противники, N — нейтральные / неизвестные. Если у тебя нет активной Roblox Team или игрок нейтрален, его принадлежность трактуется как неизвестная, не как враг. Для игр с собственной системой команд эти сведения могут не совпадать с игровыми.

- Отдельные переключатели союзников, врагов и нейтральных, проверка живых, видимости и максимальной дистанции; эти настройки не меняют командный фильтр аимбота.
- Подсветка персонажа: обводка и заливка, только обводка, только заливка или выключена; цвет и прозрачность обводки и заливки, режим за стенами или только без препятствий.
- 2D-рамка: полная, угловая или выключена, с настройкой толщины и длины углов; линии от верхней, центральной или нижней части экрана. Цвет: по отношению (отдельно регулируемый оттенок союзника, врага и нейтрального), по Roblox TeamColor, здоровью или радужный.
- Отдельно включаются подписи имени (DisplayName или Username), команды, расстояния, здоровья и экипированного Tool, а также полоска здоровья слева или справа. Размер текста и прозрачность оверлея настраиваются.
- **Scan interval** регулирует интервал проверки игроков, фильтров, надписей и габаритов. Экранные координаты обновляются в рендере с пределом **2D refresh cap** (по умолчанию 60 в секунду); сохранённые габариты следуют за перемещением персонажа, а его поза и поворот уточняются при следующем сканировании. Это может повысить нагрузку при большом числе игроков; плавность и FPS нужно проверять в игре. Настройки можно вручную сохранить в профиле **CONFIGS**.

Режим **Highlight depth = Occluded** скрывает за стеной только Highlight. Рамки, подписи и линии — экранные элементы, поэтому для скрытия *всего* ESP за стенами включи **Visible only**. Рамки приблизительно строятся по габаритам модели, включая аксессуары; они скрываются, если модель пересекает плоскость камеры или оказывается вне экрана. Нет гарантии поддержки нестандартных персонажей и команд.

## Тесты движения / эксплойты

Во вкладке **TOOLS** есть **Speed test** и **Air jump**. Оба по умолчанию выключены; во вкладке **BINDS** им можно назначить свои клавиши. Выбирать и изменять режимы можно независимо от ESP и аимбота.

- Speed test: `WalkSpeed` многократно задаёт локальное значение Humanoid; `CFrame` добавляет перемещение вдоль направления движения (поверх обычного); `Velocity` задаёт горизонтальную скорость при движении, сохраняя вертикальную. **Speed amount** — studs/s: в CFrame это дополнительное смещение в секунду, в двух других режимах — устанавливаемое значение. Скорость по умолчанию — 40.
- Air jump: при запросе прыжка режим `State` просит Humanoid перейти в Jumping, а `Velocity` задаёт вертикальную скорость и сохраняет горизонтальные составляющие. Интервал между запросами ограничен 0,15 с. Доступны выбор режима и ползунок Jump velocity. При открытом меню и вводе текста срабатывание отключено.
- При смене режима или выключении WalkSpeed восстанавливается только если его текущее значение всё ещё совпадает с последним установленным нами; это не гарантирует сохранение изменений игры во время активного теста. После CFrame/Velocity прежняя позиция и скорость не откатываются. При респавне оба теста выключаются; cleanup отключает их и очищает обработчики.

-- Aimbot module. Only operates on client state.
return function(ctx)
local Players, localPlayer, settings, env = ctx.Players, ctx.localPlayer, ctx.settings, ctx.env
local function isTarget(player)
    if player == localPlayer then return false end
    if settings.TeamCheck and localPlayer.Team ~= nil and player.Team == localPlayer.Team then
        return false
    end
    local character = player.Character
    local humanoid = character and character:FindFirstChildOfClass("Humanoid")
    local head = character and character:FindFirstChild("Head")
    return character ~= nil and humanoid ~= nil and humanoid.Health > 0 and head ~= nil
end

-- Visibility check inspired by Exunys/Aimbot-V3 (CC0; credit: Exunys).
-- If the query fails, do not treat the target as visible.
local function hasLineOfSight(camera, targetPart)
    if not settings.WallCheck then return true end
    local ignored = {targetPart.Parent}
    if localPlayer.Character then table.insert(ignored, localPlayer.Character) end
    local ok, obstacles = pcall(function()
        return camera:GetPartsObscuringTarget({targetPart.Position}, ignored)
    end)
    return ok and #obstacles == 0
end

-- Options inspired by Exunys/Aimbot-V3; implementation written for this test client.
local lockedPlayer = nil
local function candidateFor(camera, player)
    if not isTarget(player) then return nil end
    local part = player.Character:FindFirstChild(settings.AimPart)
    if not part or not part:IsA("BasePart") then return nil end
    local worldDistance = (part.Position - camera.CFrame.Position).Magnitude
    if worldDistance > settings.MaxDistance then return nil end
    local point, visible = camera:WorldToViewportPoint(part.Position)
    if not visible or point.Z <= 0 or not hasLineOfSight(camera, part) then return nil end
    local distance = (Vector2.new(point.X, point.Y) - camera.ViewportSize / 2).Magnitude
    if distance > settings.AimRadius then return nil end
    local human = player.Character:FindFirstChildOfClass("Humanoid")
    return part, distance, worldDistance, human.Health
end
local function findTarget(camera)
    if settings.StickyTarget and lockedPlayer then
        local part = candidateFor(camera, lockedPlayer)
        if part then return part end
    end
    lockedPlayer = nil
    local bestPart, bestScore = nil, math.huge
    for _, player in ipairs(Players:GetPlayers()) do
        local part, distance, worldDistance, health = candidateFor(camera, player)
        local score = settings.AimPriority == "Distance" and worldDistance or settings.AimPriority == "Health" and health or distance
        if part and score < bestScore then
            bestPart, bestScore, lockedPlayer = part, score, player
        end
    end
    return bestPart
end

-- Mouse.Hit / Mouse.Target interception is experimental, not an anti-cheat bypass guarantee.
-- Once installed, the executor hook stays in place but becomes inert on disable/cleanup.
-- Reuse a single hook on rerun; do not overwrite another script's later hook.
local silentState = env.DeadlineSilentAimHook
local function installSilentHook()
    if silentState and silentState.installed then
        silentState.position = silentState.position or Vector3.new()
        return true
    end
    if type(hookmetamethod) ~= "function" or type(newcclosure) ~= "function" or type(checkcaller) ~= "function" then
        return false
    end
    local candidate = {active = false, target = nil, position = Vector3.new(), mouse = localPlayer:GetMouse()}
    local oldIndex
    local ok, result = pcall(function()
        oldIndex = hookmetamethod(game, "__index", newcclosure(function(object, key)
            local target = candidate.target
            if candidate.active and target and target.Parent and object == candidate.mouse and not checkcaller() then
                if key == "Hit" then return target.CFrame + (candidate.position - target.Position) end
                if key == "Target" then return target end
            end
            return oldIndex(object, key)
        end))
        return oldIndex
    end)
    if not ok or type(result) ~= "function" then return false end
    candidate.installed = true
    silentState = candidate
    env.DeadlineSilentAimHook = candidate
    return true
end

end

    if speedState and speedState.installed then return true end
    if not supported(false) then return false end
    local state = {active = false}
    local previous
    local ok, result = pcall(function()
        previous = hookmetamethod(game, "__index", newcclosure(function(object, key)
            if state.active and object == state.humanoid and (key == "WalkSpeed" or key == "walkSpeed") and not checkcaller() then
                return state.value
            end
            return previous(object, key)
        end))
        return previous
    end)
    if not ok or type(result) ~= "function" then return false end
    state.installed = true; speedState = state; env.DeadlineSpeedSpoofHook = state

end

    if not supported(true) then return false end
    local state = {active = false}

    local ok, result = pcall(function()
        previous = hookmetamethod(game, "__namecall", newcclosure(function(object, ...)
            if state.active and object == state.remote and not checkcaller()
                and getnamecallmethod() == "FireServer" and select(1, ...) == state.flag then
                state.blocked = state.blocked + 1
                return nil
            end

            node = node:FindFirstChild(part)

-- Local JSON profiles. No code execution; names never escape the project directory.
return function(ctx, root)
local settings = ctx.settings
local numeric, choices = {}, {}
local excluded = {SilentAim=true, TriggerEnabled=true, AutoJumpEnabled=true}
local function number(key, min, max) numeric[key] = {min,max} end
local function choice(key, options) choices[key] = options end
local function validName(name)
    return type(name)=="string" and #name>=1 and #name<=32 and name:match("^[A-Za-z0-9_%-]+$") ~= nil
end
local function path(name)
    assert(validName(name), "Use 1-32 letters, numbers, _ or - for the profile name")
    return root .. "/config_" .. name .. ".json"
end
local function allowedBool(key)
    return type(settings[key]) == "boolean" and not excluded[key]
end
local function validValue(key,value)
    if allowedBool(key) then return type(value)=="boolean" end
    if numeric[key] then
        return type(value)=="number" and value==value and value>=numeric[key][1] and value<=numeric[key][2]
    end
    if choices[key] then
        if type(value)~="string" then return false end
        for _, option in ipairs(choices[key]) do if option==value then return true end end
    end
    return false
end
local function encodeBind(value)
    if value==nil then return false end
    if value == Enum.UserInputType.MouseButton1 or value == Enum.UserInputType.MouseButton2 or value == Enum.UserInputType.MouseButton3 then
        return {kind="mouse", name=value.Name}
    end
    return {kind="key",name=value.Name}
end
local function decodeBind(value)
    if value==false then return nil, true end
    if type(value)~="table" or type(value.name)~="string" or #value.name>64 then return nil,false end
    if value.kind=="mouse" then
        if value.name~="MouseButton1" and value.name~="MouseButton2" and value.name~="MouseButton3" then return nil,false end
        return Enum.UserInputType[value.name], true
    end
    if value.kind=="key" and value.name~="RightShift" and value.name~="Escape" and value.name~="Unknown" then
        local ok, item=pcall(function() return Enum.KeyCode[value.name] end)
        if ok and item then return item,true end
    end
    return nil,false
end
local function save(name, binds, bindingKeys, modes)
    assert(type(writefile)=="function", "writefile unavailable")
    local output={version=1,settings={},binds={},bindModes={}}
    for key,value in pairs(settings) do if validValue(key,value) then output.settings[key]=value end end
    for _,key in ipairs(bindingKeys) do
        output.binds[key]=encodeBind(binds[key])
        if key~="Trigger" then output.bindModes[key]=(modes and modes[key]) or "Toggle" end
    end
    local json=game:GetService("HttpService"):JSONEncode(output)
    writefile(path(name),json)
end
local function load(name, binds, bindingKeys, modes)
    assert(type(readfile)=="function", "readfile unavailable")
    local data=readfile(path(name))
    assert(type(data)=="string" and #data<=65536, "Invalid profile size")
    local payload=game:GetService("HttpService"):JSONDecode(data)
    assert(type(payload)=="table" and payload.version==1 and type(payload.settings)=="table" and type(payload.binds)=="table", "Invalid profile format")
    -- Validate the complete profile before making any changes.
    local nextValues, nextBinds, nextModes, used = {}, {}, {}, {}
    assert(payload.bindModes==nil or type(payload.bindModes)=="table", "Invalid binding modes")
    for key,value in pairs(payload.settings) do
        assert(validValue(key,value), "Invalid setting: " .. tostring(key))
        nextValues[key]=value
    end
    for _,key in ipairs(bindingKeys) do
        local value=payload.binds[key]
        assert(value~=nil,"Missing binding: " .. key)
        local item,ok=decodeBind(value); assert(ok,"Invalid binding: " .. key)
        if item then assert(not used[item],"Duplicate binding: " .. key); used[item]=true end
        nextBinds[key]=item or false
        if key~="Trigger" then
            local mode=(payload.bindModes and payload.bindModes[key]) or "Toggle"
            assert(mode=="Toggle" or mode=="Hold", "Invalid binding mode: " .. key)
            nextModes[key]=mode
        end
    end
    for key,value in pairs(nextValues) do settings[key]=value end
    for _,key in ipairs(bindingKeys) do
        binds[key]=nextBinds[key] or nil
        if modes and key~="Trigger" then modes[key]=nextModes[key] end
    end
end
local function list()
    if type(listfiles)~="function" then return nil,"listfiles unavailable; enter a name manually" end
    local ok, files=pcall(listfiles,root)
    if not ok or type(files)~="table" then return nil,"Cannot list profiles; enter a name manually" end
    local names={}
    for _,full in ipairs(files) do
        local leaf=tostring(full):match("([^/\\]+)$") or ""
        local name=leaf:match("^config_([A-Za-z0-9_%-]+)%.json$")
        if validName(name) then names[#names+1]=name end
    end
    table.sort(names)
    return names
end
return {number=number, choice=choice, save=save, load=load, list=list}
end

-- Scan expensive model bounds at the configured interval; move the cached world-space
-- corners with the root each frame. Pose and rotation update on the next scan.
local function cacheBounds(e, anchor)
    local ok, cf, size = pcall(function() return e.character:GetBoundingBox() end)
    if not ok or not cf or not size then e.corners = nil; return end
    local corners = {}
    for _, x in ipairs({-1, 1}) do
        for _, y in ipairs({-1, 1}) do
            for _, z in ipairs({-1, 1}) do
                corners[#corners + 1] = cf:PointToWorldSpace(Vector3.new(size.X*x/2,size.Y*y/2,size.Z*z/2))
            end
        end
    end
    e.corners, e.anchor, e.anchorAtScan = corners, anchor, anchor.Position
end
local function projectedBounds(camera, e)
    if not e.corners or not e.anchor or not e.anchorAtScan then return nil end
    local delta = e.anchor.Position - e.anchorAtScan
    local minX, minY, maxX, maxY = math.huge, math.huge, -math.huge, -math.huge
    for _, corner in ipairs(e.corners) do
        local point = camera:WorldToViewportPoint(corner + delta)
        if point.Z <= 0 then return nil end
        minX, minY = math.min(minX,point.X), math.min(minY,point.Y)
        maxX, maxY = math.max(maxX,point.X), math.max(maxY,point.Y)
    end
    local viewport = camera.ViewportSize
    if maxX < 0 or maxY < 0 or minX > viewport.X or minY > viewport.Y then return nil end
    minX, minY = math.max(-viewport.X,minX), math.max(-viewport.Y,minY)
    maxX, maxY = math.min(viewport.X*2,maxX), math.min(viewport.Y*2,maxY)
    return minX, minY, math.max(2,maxX-minX), math.max(2,maxY-minY)
end
local function updateBox(e, width, height, color)
    local style, t = settings.ESPBoxStyle, settings.ESPBoxThickness
    local horizontal = style == "Corners" and width * settings.ESPCornerSize or width
    local vertical = style == "Corners" and height * settings.ESPCornerSize or height
    local line = e.lines
    -- Style is refreshed during the scan; only geometry changes in render.
    -- Four pairs of corner strokes; in Full mode they overlap to create four edges.
    local spec = {
        {0,0,horizontal,t}, {0,0,t,vertical}, {width-horizontal,0,horizontal,t}, {width-t,0,t,vertical},
        {0,height-t,horizontal,t}, {0,height-vertical,t,vertical},
        {width-horizontal,height-t,horizontal,t}, {width-t,height-vertical,t,vertical},
    }
    for i, coords in ipairs(spec) do
        line[i].Position = UDim2.fromOffset(coords[1],coords[2])
        line[i].Size = UDim2.fromOffset(coords[3],coords[4])
    end
end

-- Approximate R6/R15 skeleton built from part centres, not joint attachments.
return function(parent)
    local edges = {
        {'Head','UpperTorso'}, {'UpperTorso','LowerTorso'},
        {'UpperTorso','LeftUpperArm'}, {'LeftUpperArm','LeftLowerArm'}, {'LeftLowerArm','LeftHand'},
        {'UpperTorso','RightUpperArm'}, {'RightUpperArm','RightLowerArm'}, {'RightLowerArm','RightHand'},
        {'LowerTorso','LeftUpperLeg'}, {'LeftUpperLeg','LeftLowerLeg'}, {'LeftLowerLeg','LeftFoot'},
        {'LowerTorso','RightUpperLeg'}, {'RightUpperLeg','RightLowerLeg'}, {'RightLowerLeg','RightFoot'},
    }
    local r6 = {{'Head','Torso'},{'Torso','Left Arm'},{'Torso','Right Arm'},{'Torso','Left Leg'},{'Torso','Right Leg'}}
    local lines, pairsOfParts = {}, {}
    local function hide() for _,line in ipairs(lines) do line.Visible=false end end
    local function scan(character)
        local selected=character:FindFirstChild('UpperTorso') and edges or r6
        pairsOfParts={}
        for i,pair in ipairs(selected) do
            local a,b=character:FindFirstChild(pair[1]),character:FindFirstChild(pair[2])
            if not lines[i] then
                    local line=Instance.new('Frame');line.Name='SkeletonLine';line.AnchorPoint=Vector2.new(0.5,0.5)
                    line.BorderSizePixel=0;line.Visible=false;line.Parent=parent;lines[i]=line
            end
            if a and b and a:IsA('BasePart') and b:IsA('BasePart') then pairsOfParts[i]={a,b} end
        end
        hide()
    end
    local function render(camera,color,thickness,transparency)
        for i,line in ipairs(lines) do
            local pair=pairsOfParts[i]
            if pair then
                local a, aOn=camera:WorldToViewportPoint(pair[1].Position)
                local b, bOn=camera:WorldToViewportPoint(pair[2].Position)
                line.Visible=aOn and bOn and a.Z>0 and b.Z>0
                if line.Visible then
                    local dx,dy=b.X-a.X,b.Y-a.Y
                    line.Position=UDim2.fromOffset((a.X+b.X)/2,(a.Y+b.Y)/2)
                    line.Size=UDim2.fromOffset(math.sqrt(dx*dx+dy*dy),thickness)
                    line.Rotation=math.deg(math.atan2(dy,dx));line.BackgroundColor3=color;line.BackgroundTransparency=transparency
                end
            else line.Visible=false end
        end
    end
    return {scan=scan,render=render,hide=hide,destroy=function() for _,line in ipairs(lines) do line:Destroy() end end}

-- Noclip: disable character collisions locally; server-side checks may reject movement.
local function restoreCollision()
    for part, wasCollidable in pairs(originalCollision) do
        pcall(function() if part.Parent then part.CanCollide = wasCollidable end end)
    end
    table.clear(originalCollision)
end

local function stepNoclip()
    if not noclip then return end
    local character = localPlayer.Character
    if not character then return end
    for _, part in ipairs(character:GetDescendants()) do
        if part:IsA("BasePart") then
            if originalCollision[part] == nil then originalCollision[part] = part.CanCollide end
            part.CanCollide = false
        end
    end
end

-- Watcher test: experiment with specifically allowlisted client-side signal callbacks.
-- getconnections and callback environment inspection are executor-specific.
-- This cannot disable server handlers or bypass Roblox platform security.
local function restoreWatchers()
    for _, connection in ipairs(disabledWatchers) do
        pcall(function() connection:Enable() end)
    end
    table.clear(disabledWatchers)
end

local function disableNamedWatchers(character)
    if type(getconnections) ~= "function" then
        warn("Watcher test unavailable: executor does not expose getconnections")
        return false
    end
    if #settings.WatcherScriptNames == 0 then
        warn("Watcher test not enabled: WatcherScriptNames is empty")
        return false
    end
    local root = character and character:FindFirstChild("HumanoidRootPart")
    if not root then warn("Watcher test: HumanoidRootPart not found") return false end
    local signals = {root.Changed, root:GetPropertyChangedSignal("CFrame")}
    local count = 0
    for _, signal in ipairs(signals) do
        local ok, list = pcall(getconnections, signal)
        if ok and type(list) == "table" then
            for _, connection in ipairs(list) do
                pcall(function()
                    local callback = connection.Function
                    if type(callback) ~= "function" or connection.Enabled ~= true then return end
                    local scope = getfenv(callback)
                    local scriptObject = scope and scope.script
                    if typeof(scriptObject) ~= "Instance" or not scriptObject:IsA("LocalScript") then return end
                    if not table.find(settings.WatcherScriptNames, scriptObject.Name) then return end
                    connection:Disable()
                    table.insert(disabledWatchers, connection)
                    count = count + 1
                end)
            end
        end
    end
    print("Watcher test: disabled matching local callbacks:", count)
    return count > 0
end

local function toggleNoclip()
    noclip = not noclip
    if not noclip then restoreCollision() end
    ctx.setStatus("Noclip " .. (noclip and "enabled" or "disabled"))
end

            ctx.setStatus("No matching accessible watchers found. See console.")
        end
    end
end

    end,

return function(ctx)
local player, input, settings = ctx.localPlayer, ctx.UserInputService, ctx.settings
local speedEnabled, jumpEnabled = false, false
local modifiedHumanoid, originalSpeed, lastSet = nil, nil, nil
local lastJump = -math.huge

local function restoreSpeed()
    if modifiedHumanoid then
        -- Avoid overwriting an intervening game change when the value no longer matches ours.
        pcall(function()
            if modifiedHumanoid.Parent and modifiedHumanoid.WalkSpeed == lastSet then
                modifiedHumanoid.WalkSpeed = originalSpeed
            end
        end)
    end
    modifiedHumanoid, originalSpeed, lastSet = nil, nil, nil
end
local function characterParts()
    local character = player.Character
    if not character then return end
    local humanoid = character:FindFirstChildOfClass("Humanoid")
    local root = character:FindFirstChild("HumanoidRootPart")
    if not humanoid or humanoid.Health <= 0 or not root or not root:IsA("BasePart") then return end
    return humanoid, root
end
local function step(dt)
    if not ctx.running or not speedEnabled then return end
    local humanoid, root = characterParts()
    if not humanoid then restoreSpeed(); return end
    if modifiedHumanoid and (modifiedHumanoid ~= humanoid or settings.MovementMode ~= "WalkSpeed") then
        restoreSpeed()
    end
    if settings.MovementMode == "WalkSpeed" then
        if not modifiedHumanoid then modifiedHumanoid, originalSpeed = humanoid, humanoid.WalkSpeed end
        humanoid.WalkSpeed = settings.MovementSpeed
        lastSet = settings.MovementSpeed
    elseif settings.MovementMode == "CFrame" then
        -- Additional horizontal displacement per second, on top of normal movement.
        root.CFrame = root.CFrame + humanoid.MoveDirection * (settings.MovementSpeed * math.clamp(dt, 0, 0.1))
    elseif settings.MovementMode == "Velocity" then
        -- Set horizontal velocity only when movement is requested; preserve vertical motion.
        local direction, velocity = humanoid.MoveDirection, root.AssemblyLinearVelocity
        if direction.Magnitude > 0.01 then
            root.AssemblyLinearVelocity = Vector3.new(direction.X * settings.MovementSpeed, velocity.Y, direction.Z * settings.MovementSpeed)
        end
    end
end
local function toggleSpeed()
    speedEnabled = not speedEnabled
    if not speedEnabled then restoreSpeed() end
    ctx.setStatus("Speed experiment " .. (speedEnabled and "enabled" or "disabled"))
end
local function toggleJump()
    jumpEnabled = not jumpEnabled
    lastJump = -math.huge
    ctx.setStatus("Air jump experiment " .. (jumpEnabled and "enabled" or "disabled"))
end
local function onJump()
    if not ctx.running or not jumpEnabled or (ctx.UI and ctx.UI.isMenuVisible()) or input:GetFocusedTextBox() then return end
    local now = os.clock()
    if now - lastJump < 0.15 then return end
    local humanoid, root = characterParts()
    if not humanoid then return end
    lastJump = now
    if settings.AirJumpMode == "State" then
        humanoid:ChangeState(Enum.HumanoidStateType.Jumping)
    else
        local velocity = root.AssemblyLinearVelocity
        root.AssemblyLinearVelocity = Vector3.new(velocity.X, settings.AirJumpVelocity, velocity.Z)
    end
end
ctx.connections[#ctx.connections + 1] = input.JumpRequest:Connect(onJump)
local function reset()
    speedEnabled, jumpEnabled = false, false
    lastJump = -math.huge
    restoreSpeed()
end
return {
    step = step, toggleSpeed = toggleSpeed, toggleJump = toggleJump,
    isSpeed = function() return speedEnabled end, isJump = function() return jumpEnabled end,
    modeChanged = restoreSpeed,
    respawn = function() reset(); ctx.setStatus("Movement experiments reset on respawn.") end,
    cleanup = reset,
}
end

    if not hit then return nil end
    for _, other in ipairs(players:GetPlayers()) do
        if other ~= player and other.Character and hit:IsDescendantOf(other.Character) then
            local human = other.Character:FindFirstChildOfClass("Humanoid")

        end
    end

-- Per-action bind modes. Hold is momentary; Toggle changes on each press.
return function(input, actions, getters, modes)
local held={}
local function setEnabled(name, desired)
    local getter,action=getters[name],actions[name]
    if not getter or not action then return false end
    if getter()~=desired then action() end
    return getter()==desired
end
local function release(name)
    if not held[name] then return end
    held[name]=nil
    setEnabled(name,false)
end
local function releaseAll()
    local names={};for name in pairs(held) do names[#names+1]=name end
    for _,name in ipairs(names) do release(name) end
end
local function press(name, key)
    if not actions[name] or not getters[name] then return end
    if modes[name]=="Hold" then
        if held[name] then return end
        if setEnabled(name,true) then held[name]={key=key,started=os.clock()} end
    else actions[name]() end
end
local function inputEnded(key)
    local names={}
    for name,record in pairs(held) do if record.key==key then names[#names+1]=name end end
    for _,name in ipairs(names) do release(name) end
end
local function step()
    local names={}
    for name,record in pairs(held) do
        if os.clock()-record.started>0.15 then
            local key=record.key
            local mouse=key==Enum.UserInputType.MouseButton1 or key==Enum.UserInputType.MouseButton2 or key==Enum.UserInputType.MouseButton3
            local ok,down
            if mouse and type(input.IsMouseButtonPressed)=="function" then
                ok,down=pcall(function() return input:IsMouseButtonPressed(key) end)
            elseif not mouse and type(input.IsKeyDown)=="function" then
                ok,down=pcall(function() return input:IsKeyDown(key) end)
            end
            if ok and down==false then names[#names+1]=name end
        end
    end
    for _,name in ipairs(names) do release(name) end
end
local function setMode(name,mode)
    assert(actions[name] and getters[name] and (mode=="Toggle" or mode=="Hold"),"Invalid binding mode")
    release(name); modes[name]=mode
    -- Selecting Hold makes its feature inactive until the key is held.
    if mode=="Hold" then setEnabled(name,false) end
end
return {press=press,inputEnded=inputEnded,step=step,releaseAll=releaseAll,setMode=setMode}
end

-- Local cursor override, active only while the menu is open.
return function(ctx)
local input=ctx.UserInputService
local open=false
local cameraControl=false
local savedBehavior,savedIcon
local sawRightButton=false
local function rightButtonDown()
    if type(input.IsMouseButtonPressed)~="function" then return nil end
    local ok, value=pcall(function() return input:IsMouseButtonPressed(Enum.UserInputType.MouseButton2) end)
    if ok and type(value)=="boolean" then return value end
    return nil
end
local function setOpen(value)
    if value==open then return end
    if value then
        savedBehavior,savedIcon=input.MouseBehavior,input.MouseIconEnabled
        sawRightButton = rightButtonDown()==true
        cameraControl=false
        open=true
    else
        open=false
        if cameraControl then cameraControl=false; return end
        -- LockCurrentPosition may be a stale RMB-drag lock if the user released
        -- RMB while our cursor override was active. Never fake input events.
        local behavior=savedBehavior
        if behavior==Enum.MouseBehavior.LockCurrentPosition and sawRightButton and rightButtonDown()==false then
            behavior=Enum.MouseBehavior.Default
        end
        pcall(function() if input.MouseBehavior==Enum.MouseBehavior.Default then input.MouseBehavior=behavior end end)
        pcall(function() if input.MouseIconEnabled==true then input.MouseIconEnabled=savedIcon end end)
    end
end
local function setCameraControl(value)
    if not open or value==cameraControl then return end
    if value then
        -- Release only properties that still contain our cursor override.
        local behavior=savedBehavior
        if behavior==Enum.MouseBehavior.LockCurrentPosition and sawRightButton and rightButtonDown()==false then
            behavior=Enum.MouseBehavior.Default
        end
        pcall(function() if input.MouseBehavior==Enum.MouseBehavior.Default then input.MouseBehavior=behavior end end)
        pcall(function() if input.MouseIconEnabled==true then input.MouseIconEnabled=savedIcon end end)
        cameraControl=true
    else
        savedBehavior,savedIcon=input.MouseBehavior,input.MouseIconEnabled
        sawRightButton=rightButtonDown()==true
        cameraControl=false
    end
end
local function step()
    if not open or cameraControl then return end
    if rightButtonDown()==true then sawRightButton=true end
    -- Preserve the most recent game-side changes where observable.
    pcall(function()
        if input.MouseBehavior~=Enum.MouseBehavior.Default then savedBehavior=input.MouseBehavior end
        if input.MouseIconEnabled~=true then savedIcon=input.MouseIconEnabled end
        input.MouseBehavior=Enum.MouseBehavior.Default
        input.MouseIconEnabled=true
    end)
end
return {setOpen=setOpen,step=step,setCameraControl=setCameraControl,
    isCameraControl=function() return cameraControl end,cleanup=function() setOpen(false) end}
