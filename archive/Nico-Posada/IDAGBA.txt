# IDAGBA

**A loader and plugin for Game Boy Advance (GBA) ROMs in IDA Pro**

[![IDA Pro 9.1+](https://img.shields.io/badge/IDA%20Pro-9.1%2B-2f81f7)](https://hex-rays.com/ida-pro) [![Python 3.11+](https://img.shields.io/badge/python-3.11%2B-3776ab?logo=python&logoColor=white)](https://www.python.org/) [![License: MIT](https://img.shields.io/badge/license-MIT-3fb950)](LICENSE)

</div>


## Overview

IDAGBA is a loader and decompiler plugin for Game Boy Advance ROMs that fills this in when you load a file:

- The console's memory map
- A name for every I/O register
- The startup code, followed all the way to `main`
- The RAM contents that the startup code copies out of the ROM
- Library functions, recognized by signature
- BIOS calls, shown as ordinary function calls
- Calls through stubs, shown as calls to the function they reach

## A quick before and after

![main decompiled by stock IDA and with IDAGBA](docs/img/main.png)

**Left**: IDA alone, with the ROM loaded as a raw ARM binary at `0x08000000` and the entry point marked as code by hand.

**Right**: the same file opened with IDAGBA and no manual work to find main.

// Built with devkitARM r68 and libgba, from devkitPro's `template` example.
#include <gba.h>
#include <stdio.h>

// Runs from IWRAM so it gets copied to there at startup
IWRAM_CODE __attribute__((noinline)) void fade_in(void) {
	for (int level = 16; level >= 0; level--) {
		VBlankIntrWait();
		REG_BLDY = level;
	}
}

int main(void) {
	irqInit();
	irqEnable(IRQ_VBLANK);

	consoleDemoInit();
	iprintf("\x1b[9;9HHello, IDA!");

	REG_BLDCNT = 0x00C1;
	fade_in();
	while (1) {
		VBlankIntrWait();
		REG_BLDY = (REG_KEYINPUT & KEY_A) ? 0 : 8;
	}
}
```

## What it does

### Finds `main`

IDAGBA is able to recognize devkitARM's startup code, name its parts, and then jump to the real `main` automatically.

![Where the cursor is after loading: stock IDA at the first byte of the ROM, IDAGBA at main](docs/img/landing.png)

### Builds the memory map

Stock IDA doesn't know anything about the address space, so IDAGBA recreates the whole thing from scratch.

![The Segments window in stock IDA and with IDAGBA](docs/img/segments.png)

### Labels the I/O registers

There are 99 I/O registers. IDAGBA names them all, gives them types, and gives them a short description following information from [GBATEK](https://problemkaputt.de/gbatek.htm).

![The start of the I/O segment](docs/img/io.png)

### Initializes RAM

IDAGBA recognizes the startup routines that initialize RAM, works out what they copy where, and does the same copies while loading.

![irqInit storing an interrupt handler that lives in RAM, in stock IDA and with IDAGBA](docs/img/irq.png)

![The interrupt handler in the IWRAM segment](docs/img/iwram.png)

### Handles call stubs

Thumb code will often call far functions through a small stub. Stock IDA will only show you a call to the stub where it thinks the real call is a function arg, so IDAGBA installs a lifter to show you the call directly to avoid all of that.

![The call to fade_in and what it leads to, decompiled by stock IDA and with IDAGBA](docs/img/stubs.png)

### Loads FLIRT signatures

The plugin ships signatures for the two common toolchains GBA software is built with.

| Toolchain | Used for | Libraries covered |
| --- | --- | --- |
| devkitARM | homebrew | libgcc, newlib, libgba, libtonc, maxmod |
| agbcc, the compiler from Nintendo's SDK | commercial games | libgcc, libc |

![The Functions window in stock IDA and with IDAGBA](docs/img/functions.png)

### Turns BIOS calls into function calls

The normal decompiler shows a BIOS call as inline assembly, but IDAGBA installs a lifter that turns them into typed calls to make your decomps much nicer.

![libgba's CpuFastSet wrapper in stock IDA and with IDAGBA](docs/img/bios.png)

### Also

- **Multiboot images**, the programs a GBA receives over the link cable, are detected and loaded at `0x02000000`.
- **The cartridge header** is labeled: title, game code, maker code, checksum.
- **Palette and sprite memory** are typed, so the decompiler shows `GBA_PALETTE.BG_PALETTE[3]` instead of an address.
- **ROMs with a missing or damaged logo** still load.

It needs IDA Pro 9.1 or newer and Python 3.11 or newer. The BIOS call feature also needs the ARM decompiler.

## Usage

1. Open the ROM in IDA.
2. The load dialog offers one of these formats. Leave it selected and press OK.

   | Format | Offered for |
   | --- | --- |
   | Nintendo Game Boy Advance ROM (ARM7TDMI) | cartridges with a valid header |
   | Nintendo Game Boy Advance ROM (homebrew or damaged header) | `.gba` and `.agb` files whose logo is missing or wrong |
   | Nintendo Game Boy Advance multiboot image (EWRAM) | multiboot images |

3. When the analysis finishes, the cursor is on `main`. Press <kbd>F5</kbd>.

The Output window says what was found:

```
[GBA] GBA cartridge: 55668 bytes at 0x08000000
[GBA] Title: 'hello'
[GBA] Stock devkitARM startup found at 0x080000e0!
[GBA] GBA_DATA_LMA: 0x0800c038 -> 0x0300034c, 0x1934 bytes
[GBA] GBA_IWRAM_LMA: 0x0800bf68 -> 0x03000000, 0xd0 bytes
[GBA] Post-analysis pass: 1 veneer calls, 1 IRQ handlers, 3 BIOS calls
```

The automated parsing and jumping to `main` only happens if the ROM uses devkitARM. Even if the ROM you want to analyze doesn't use it, the rest of the features will still work fine.

`idagba/arm.py`:

```py
"""Thumb state helpers. They use the raw SDK because ida_domain has no segment register API (booooo)."""

from __future__ import annotations

from typing import TYPE_CHECKING

import ida_allins
import ida_idp
import ida_segregs

from idagba.bios import decode_swi_number
from idagba.errors import require

if TYPE_CHECKING:
    from ida_domain import Database
    from ida_ua import insn_t


def thumb_state(ea: int) -> int:
    return ida_segregs.get_sreg(ea, ida_idp.str2reg('T'))


def set_thumb(ea: int, thumb: int) -> None:
    # the T segment register is 0 for ARM and 1 for Thumb
    register = ida_idp.str2reg('T')
    require(
        register >= 0,
        'ARM processor does not expose T state',
    )
    require(
        ida_segregs.split_sreg_range(ea, register, thumb, ida_segregs.SR_auto),
        f'Cannot establish T={thumb} at {ea:#x}',
    )


def swi_number(db: Database, insn: insn_t) -> int | None:
    """BIOS call number of an SVC instruction, or None for anything else."""
    if insn.itype != ida_allins.ARM_svc:
        return None

    operand = db.instructions.get_operand(insn, 0)
    return None if operand is None else decode_swi_number(operand.get_value(), thumb=thumb_state(insn.ea) == 1)

def decode_swi_number(value: int, *, thumb: bool) -> int:
    # thumb keeps the number in 8 bits, arm in bits 16-23
    return value & 0xFF if thumb else (value >> 16) & 0xFF

`idagba/crt0.py`:

```py
"""Finds devkitARM's startup code (crt0) in an image and reads what it says about the image.

The general flow of what happens here is:
1. find_crt0 follows the entry branches to the startup code.
2. Crt0.pool reads the literal pool after it.
3. recover_startup checks the pool against the image.

If anything looks wrong, recovery fails and the loader leaves RAM empty and main unnamed.
"""

from __future__ import annotations

import struct
from dataclasses import dataclass, field
from typing import TYPE_CHECKING, ClassVar

from idagba.errors import LoadError, require
from idagba.hardware import BASE_EWRAM, BASE_IWRAM, BASE_ROM0, SIZE_EWRAM, SIZE_IWRAM
from idagba.rom import HEADER_SIZE, arm_branch_target

if TYPE_CHECKING:
    from collections.abc import Sequence


@dataclass(frozen=True, slots=True)
class StartupCopy:
    """A section the startup copies from the image into RAM."""

    name: str
    source: int
    destination: int
    size: int


@dataclass(frozen=True, slots=True)
class StartupRecovery:
    """What the startup code says about its image."""

    base: int

    # addresses of the startup code and its ClearMem helper
    start: int
    clear_mem: int
    copies: tuple[StartupCopy, ...]

    # pointers with the thumb flag in bit 0
    constructors: int
    main: int

    # image ranges that are already known
    reserved: tuple[tuple[int, int], ...]


@dataclass(frozen=True, slots=True)
class StartupRecoveryFailure:
    reason: str


def recover_startup(rom: bytes, base: int = BASE_ROM0) -> StartupRecovery | StartupRecoveryFailure:
    """Recover the startup of an image loaded at base, or return why it failed."""
    crt0 = find_crt0(rom)
    if isinstance(crt0, StartupRecoveryFailure):
        return crt0

    try:
        return _recover(crt0, base)
    except LoadError as exc:
        return StartupRecoveryFailure(str(exc))


def _recover(crt0: Crt0, base: int) -> StartupRecovery:
    pool = crt0.pool()
    if pool is None:
        msg = 'startup literal pool leaves the input'
        raise LoadError(msg)

    # must be linked for this load address
    require(pool.text_start == base, 'startup is not linked for this image base')
    image = (base, base + len(crt0.rom))
    start = base + crt0.offset

    # the header, the startup code and the entry branches are already known, so nothing else can use them
    reserved = [
        (base, base + HEADER_SIZE),
        (start, base + crt0.pool_offset + LiteralPool.FORMAT.size),
        *((base + branch, base + branch + 4) for branch in crt0.entry_branches),
    ]
    copies = _copies(pool)

    # the copy sources are known too
    reserved += _check_copies(copies, image, reserved)
    for name, pointer in (('__libc_init_array', pool.libc_init_array), ('main', pool.main)):
        require(code_pointer(pointer, image, copies, reserved), f'invalid {name} code pointer {pointer:#x}')

    return StartupRecovery(
        base=base,
        start=start,
        clear_mem=base + crt0.clear_mem,
        copies=tuple(copies),
        constructors=pool.libc_init_array,
        main=pool.main,
        reserved=tuple(reserved),
    )


@dataclass(frozen=True, slots=True)
class LiteralPool:
    """The literal pool after the startup code. Each field is a linker symbol the code loads."""

    # Layout order taken from the `ldr rX, =symbol` loads in
    # https://github.com/devkitPro/devkitarm-crtls/blob/333d62c/gba_crt0.s#L65-L183
    sp_irq: int
    sp_usr: int
    text_start: int
    end: int
    bss_start: int
    bss_end: int
    sbss_start: int
    sbss_end: int
    data_lma: int
    data_start: int
    data_end: int
    iwram_lma: int
    iwram_start: int
    iwram_end: int
    load_stop_iwram0: int
    load_start_iwram0: int
    iwram_overlay_start: int
    ewram_lma: int
    ewram_start: int
    ewram_end: int
    fake_heap_end: int
    eheap_end: int
    libc_init_array: int
    main: int

    FORMAT: ClassVar[struct.Struct] = struct.Struct('<24I')


@dataclass(frozen=True, slots=True)
class Crt0:
    """The startup code found in an image."""

    rom: bytes = field(repr=False)

    # file offsets of the startup code, its ClearMem helper and the literal pool
    offset: int
    clear_mem: int
    pool_offset: int

    # file offsets of the branches that lead from the file start to the code
    entry_branches: tuple[int, ...]

    # the assembled startup code and the offset of ClearMem in it
    REVISIONS: ClassVar[tuple[tuple[bytes, int], ...]] = (
        (
            # https://github.com/devkitPro/devkitarm-crtls/blob/333d62c/gba_crt0.s#L58-L253
            # ^ (current)
            bytes.fromhex("""
                01 03 A0 E3 08 02 80 E5 12 00 A0 E3 00 F0 29 E1
                B8 D0 9F E5 1F 00 A0 E3 00 F0 29 E1 B0 D0 9F E5
                01 00 8F E2 10 FF 2F E1 2B 48 40 01 0B D2 78 46
                40 01 0D D3 02 22 12 06 28 4B 9B 1A 16 1C 91 00
                00 F0 3D F8 30 47 40 21 09 03 C8 01 00 F0 2C F8
                23 48 24 49 09 1A 00 F0 27 F8 23 48 23 49 09 1A
                00 F0 22 F8 22 49 23 4A 23 4C 00 F0 27 F8 23 49
                23 4A 24 4C 00 F0 22 F8 23 4A 24 49 53 1A 02 D0
                23 4A 00 F0 1C F8 23 49 23 4A 24 4C 00 F0 16 F8
                23 49 24 48 08 60 24 4B 00 F0 0F F8 00 20 00 21
                22 4B 00 F0 0A F8 00 DF 03 22 89 18 91 43 03 D0
                00 22 04 C0 04 39 FC D1 70 47 18 47 A3 1A 03 20
                1B 18 83 43 03 D0 01 C9 01 C2 04 3B FB D1 70 47
            """),
            0xA8,
        ),
        (
            # https://github.com/devkitPro/devkitarm-crtls/blob/eac1e8c/gba_crt0.s#L58-L250
            # ^ (no SoftReset after main)
            bytes.fromhex("""
                01 03 A0 E3 08 02 80 E5 12 00 A0 E3 00 F0 29 E1
                B8 D0 9F E5 1F 00 A0 E3 00 F0 29 E1 B0 D0 9F E5
                01 00 8F E2 10 FF 2F E1 2B 48 40 01 0B D2 78 46
                40 01 0D D3 02 22 12 06 28 4B 9B 1A 16 1C 91 00
                00 F0 3C F8 30 47 40 21 09 03 C8 01 00 F0 2B F8
                23 48 24 49 09 1A 00 F0 26 F8 23 48 23 49 09 1A
                00 F0 21 F8 22 49 23 4A 23 4C 00 F0 26 F8 23 49
                23 4A 24 4C 00 F0 21 F8 23 4A 24 49 53 1A 02 D0
                23 4A 00 F0 1B F8 23 49 23 4A 24 4C 00 F0 15 F8
                23 49 24 48 08 60 24 4B 00 F0 0E F8 00 20 00 21
                22 4B 00 F0 09 F8 03 22 89 18 91 43 03 D0 00 22
                04 C0 04 39 FC D1 70 47 18 47 A3 1A 03 20 1B 18
                83 43 03 D0 01 C9 01 C2 04 3B FB D1 70 47 C0 46
            """),
            0xA6,
        ),
    )

    @classmethod
    def at(cls, rom: bytes, offset: int, entry_branches: tuple[int, ...]) -> Crt0 | None:
        """The startup code at a file offset, if it is there."""
        for code, clear_mem in cls.REVISIONS:
            if rom.startswith(code, offset):
                return cls(rom, offset, offset + clear_mem, offset + len(code), entry_branches)

        return None

    def pool(self) -> LiteralPool | None:
        """The literal pool after the code, or None when the file ends inside it."""
        if self.pool_offset + LiteralPool.FORMAT.size > len(self.rom):
            return None

        return LiteralPool(*LiteralPool.FORMAT.unpack_from(self.rom, self.pool_offset))


def find_crt0(rom: bytes) -> Crt0 | StartupRecoveryFailure:
    """Follow the ARM branches from the file start to the startup code."""
    max_branches = 4
    offset = 0
    branches = []
    while True:
        if offset in branches or offset % 4 or not 0 <= offset <= len(rom) - 4:
            return StartupRecoveryFailure('entry branch chain loops, is unaligned, or leaves the input')

        crt0 = Crt0.at(rom, offset, tuple(branches)) if offset >= HEADER_SIZE else None
        if crt0:
            return crt0

        if len(branches) == max_branches:
            return StartupRecoveryFailure(f'no stock crt0 within {max_branches} entry branches')

        target = arm_branch_target(struct.unpack_from('<I', rom, offset)[0], offset)
        if target is None or target < HEADER_SIZE:
            return StartupRecoveryFailure('entry chain does not reach the stock crt0 template')

        branches.append(offset)
        offset = target


def _overlaps(a: tuple[int, int], b: tuple[int, int]) -> bool:
    return a[0] < b[1] and b[0] < a[1]


def _within(inner: tuple[int, int], outer: tuple[int, int]) -> bool:
    return outer[0] <= inner[0] and inner[1] <= outer[1]


def _copies(pool: LiteralPool) -> list[StartupCopy]:
    """The sections the startup copies into RAM. Empty ones and ones copied onto themselves are left out."""

    # https://github.com/devkitPro/devkitarm-crtls/blob/333d62c/gba_crt0.s#L130-L163
    copies = [
        _copy(
            'GBA_DATA_LMA',
            pool.data_lma,
            pool.data_start,
            pool.data_end - pool.data_start,
        ),
        _copy(
            'GBA_IWRAM_LMA',
            pool.iwram_lma,
            pool.iwram_start,
            pool.iwram_end - pool.iwram_start,
        ),
        _copy(
            'GBA_EWRAM_LMA',
            pool.ewram_lma,
            pool.ewram_start,
            pool.ewram_end - pool.ewram_start,
        ),
        _copy(
            'GBA_IWRAM0_LMA',
            pool.load_start_iwram0,
            pool.iwram_overlay_start,
            pool.load_stop_iwram0 - pool.load_start_iwram0,
        ),
    ]

    # a section linked where it is loaded is copied onto itself, as .ewram is in a multiboot image
    return [copy for copy in copies if copy.size and copy.source != copy.destination]


def _copy(name: str, source: int, destination: int, size: int) -> StartupCopy:
    require(size >= 0, f'{name}: section ends before it starts')

    # CopyMem rounds the length up to a whole word.
    return StartupCopy(name, source, destination, (size + 3) & ~3)


def _check_copies(
    copies: Sequence[StartupCopy], image: tuple[int, int], reserved: Sequence[tuple[int, int]]
) -> list[tuple[int, int]]:
    """Check every copy and return their source ranges."""
    ewram = (BASE_EWRAM, BASE_EWRAM + SIZE_EWRAM)
    iwram = (BASE_IWRAM, BASE_IWRAM + SIZE_IWRAM)
    sources, destinations = [], []
    for copy in copies:
        source = (copy.source, copy.source + copy.size)
        destination = (copy.destination, copy.destination + copy.size)

        # some sanity checks
        require(
            copy.source % 4 == copy.destination % 4 == 0,
            f'{copy.name}: unaligned copy',
        )
        require(
            _within(source, image),
            f'{copy.name}: source leaves input',
        )
        require(
            _within(destination, ewram) or _within(destination, iwram),
            f'{copy.name}: destination leaves canonical RAM',
        )

        # a multiboot image is itself loaded into EWRAM
        require(
            not _overlaps(destination, image),
            f'{copy.name}: destination overlaps the loaded image',
        )
        require(
            not any(_overlaps(source, span) for span in (*reserved, *sources)),
            f'{copy.name}: source overlaps startup, literal, or another source',
        )
        require(
            not any(_overlaps(destination, span) for span in destinations),
            f'{copy.name}: overlapping destinations',
        )

        sources.append(source)
        destinations.append(destination)

    return sources


def code_pointer(
    pointer: int, image: tuple[int, int], copies: Sequence[StartupCopy], reserved: Sequence[tuple[int, int]]
) -> bool:
    """Whether a pointer can lead to code. Bit 0 of the pointer is the Thumb flag."""
    address = pointer & ~1
    width = 2 if pointer & 1 else 4
    if address % width:
        return False

    instruction = (address, address + width)

    # a pointer into the image must miss the known ranges
    if _within(instruction, (image[0] + HEADER_SIZE, image[1])):
        return not any(_overlaps(instruction, span) for span in reserved)

    # any other pointer must land in a RAM copy
    return any(_within(instruction, (copy.destination, copy.destination + copy.size)) for copy in copies)

"""Puts the loader file where IDA looks for loaders.

Implementation idea mostly taken from https://github.com/williballenthin/idawilli/tree/master/plugins/vtloader

Surely if an IDA employee does it this way then it's ok to do :clueless:
(if anyone at hexrays is reading this, pls add proper loader support to hcli)
"""

from __future__ import annotations

import shutil
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from pathlib import Path


def install_loader_link(loaders_dir: Path, target: Path) -> Path:
    """Link target into loaders_dir, or copy it where symlinks are not allowed.

    Raises:
        FileExistsError: a file with that name exists and is not ours.
        OSError: the link or the copy could not be created.
    """
    link = loaders_dir / target.name
    loaders_dir.mkdir(parents=True, exist_ok=True)
    if link.is_symlink():
        if link.resolve() == target.resolve():
            return link

        # loader stub is stale, delete it
        link.unlink()
    elif link.exists():
        if _first_line(link) != _first_line(target):
            msg = f'{link} exists and was not installed by idagba'
            raise FileExistsError(msg)

        if link.read_bytes() == target.read_bytes():
            return link

        # we have an outdated copy, delete it
        link.unlink()

    try:
        link.symlink_to(target)
    except OSError:  # Windows without Developer Mode or administrator rights
        shutil.copyfile(target, link)

    return link


def _first_line(path: Path) -> str:
    with path.open(encoding='utf-8') as file:
        return file.readline()

"""Decompiler hooks that show BIOS calls and calls through stubs as normal calls.

BIOS calls
Off: __asm { SVC 0xC }
On:  SWI_CpuFastSet(src, dst, mode)

Calls through a linker veneer
Off: sub_8017890(dst, 0, 12)
On:  sub_30013B8(dst, 0, 12)

Calls through a bx rN helper
Off: sub_80015B2(a, b, sub_3000024) => a3(a1, a2)
On:  sub_3000024(a, b)
"""

from __future__ import annotations

from typing import TYPE_CHECKING

import ida_allins
import ida_funcs
import ida_hexrays
import ida_idaapi
import ida_idp
from ida_domain import Database
from ida_domain.microcode import MicroBlockArray, MicrocodeFilter, MicrocodeLifter, MicroOpcode, reg2mreg
from ida_domain.operands import RegisterOperand

from idagba import arm
from idagba.bios import BIOS_PROTOTYPES

if TYPE_CHECKING:
    from ida_funcs import func_t
    from ida_hexrays import codegen_t, mba_t

_installed: tuple[_BiosCalls, _VeneerCalls] | None = None


def install() -> bool:
    """Install the hooks for the open database. Returns False when there is no decompiler."""
    global _installed
    if _installed:
        return True

    if not ida_hexrays.init_hexrays_plugin():
        return False

    db = Database.open()
    bios, veneers = _BiosCalls(db), _VeneerCalls(db)
    bios.install()
    veneers.hook()
    _installed = bios, veneers

    # drop pseudocode that was made without the hooks
    ida_hexrays.clear_cached_cfuncs()
    return True


def uninstall() -> None:
    global _installed
    if _installed is None:
        return

    bios, veneers = _installed
    bios.uninstall()
    veneers.unhook()
    _installed = None

    # drop pseudocode that was made with the hooks
    ida_hexrays.clear_cached_cfuncs()


class _BiosCalls(MicrocodeLifter):
    def __init__(self, db: Database) -> None:
        super().__init__()
        self.db = db
        self.prototypes = {number: _Prototype(declaration) for number, declaration in BIOS_PROTOTYPES.items()}

    def match(self, cdg: codegen_t) -> bool:
        return arm.swi_number(self.db, cdg.insn) in self.prototypes

    def apply(self, cdg: codegen_t) -> int:
        number = arm.swi_number(self.db, cdg.insn)
        if number is None:  # match() already ruled this out
            return ida_hexrays.MERR_INSN

        return self.prototypes[number].apply(cdg)


class _Prototype(MicrocodeFilter):
    """The prototype of one BIOS call."""

    def __init__(self, declaration: str) -> None:
        super().__init__()

        # a call clobbers r0-r3 unless its prototype says otherwise, as in libtonc
        if '__spoils' not in declaration:
            declaration = declaration.replace('__usercall', '__usercall __spoils<R0,R1,R2,R3>', 1)

        if not self.init(declaration):
            msg = f'Cannot parse BIOS call prototype: {declaration}'
            raise ValueError(msg)

    def match(self, cdg: codegen_t) -> bool:
        # _BiosCalls already matched the instruction
        return True


# TODO(2026-11-19): This hooks Hex-Rays directly because ida_domain's DecompilerHooks is slow and makes IDA print a
# TypeError on every decompilation. Update to use ida_domain's wrapper when that's fixed.
class _VeneerCalls(ida_hexrays.Hexrays_Hooks):
    """Point each call that goes through a stub at the code the stub reaches."""

    def __init__(self, db: Database) -> None:
        super().__init__()
        self.db = db

    def microcode(self, mba: mba_t) -> int:
        # runs on the fresh microcode of a function, before the decompiler looks at its calls
        for insn in MicroBlockArray(mba).instructions():
            # only calls and jumps to a fixed address
            callee = insn.l.global_address
            if callee is None or insn.opcode not in (MicroOpcode.CALL, MicroOpcode.GOTO):
                continue

            target = self._behind_thunks(callee)
            if insn.opcode == MicroOpcode.GOTO:
                # only retarget a jump that lands on a function, so it decompiles as a tail call
                if target != callee and self._function(target) is not None:
                    insn.l.set_global_addr(target, insn.l.size)

                continue

            register = self._bx_register(target)
            if register is not None:
                # make it an indirect call through rN, which the decompiler resolves itself
                insn.opcode = MicroOpcode.ICALL

                # icall takes the segment in l and the target in r
                insn.l.set_register(reg2mreg(ida_idp.str2reg('CS')), 2)
                insn.r.set_register(reg2mreg(register), 4)
            elif target != callee:
                # point the call at the end of the thunk chain
                insn.l.set_global_addr(target, insn.l.size)

        return ida_hexrays.MERR_OK

    def _behind_thunks(self, ea: int) -> int:
        """Follow the thunks from ea to the code they end at."""
        seen = set()
        while ea not in seen:
            seen.add(ea)
            function = self._function(ea)

            # TODO(2026-11-19): db.functions.get_flags raises on IDA 9.5's FUNC_OVERSIZED,
            # so update to ida_domain's wrapper when that's fixed
            if function is None or not function.flags & ida_funcs.FUNC_THUNK:
                break

            # this returns a (target, pointer address) pair, though its type stub says int
            target, _ = ida_funcs.calc_thunk_func_target(function)  # ty: ignore[not-iterable]
            if target == ida_idaapi.BADADDR:
                break

            ea = target

        return ea

    def _bx_register(self, ea: int) -> int | None:
        """The register rN when the function at ea is only `bx rN`, like libgcc's _call_via_rN."""
        function = self._function(ea)
        insn = self.db.instructions.get_at(ea) if function is not None else None

        # the whole function must be the one bx instruction
        if function is None or insn is None or insn.itype != ida_allins.ARM_bx or ea + insn.size != function.end_ea:
            return None

        operand = self.db.instructions.get_operand(insn, 0)

        # bx lr is a return and bx pc a mode switch, so neither is a call
        if not isinstance(operand, RegisterOperand) or operand.register_number >= ida_idp.str2reg('SP'):
            return None

        return operand.register_number

    def _function(self, ea: int) -> func_t | None:
        """The function that starts at ea, if there is one."""
        function = self.db.functions.get_at(ea) if self.db.is_valid_ea(ea) else None
        return function if function is not None and function.start_ea == ea else None

def load_file(li: loader_input_t, neflags: int, format_name: str) -> int:
    try:
        # prereqs
        require(
            not neflags & ida_loader.NEF_RELOAD and neflags & ida_loader.NEF_FIRST,
            'IDAGBA only a does first-file loads, reloads/additional loads are not supported',
        )
        require(
            format_name in (FORMAT, RELAXED_FORMAT, MB_FORMAT),
            'Unsupported selected format',
        )

        # initial file opening
        multiboot = format_name == MB_FORMAT
        size = li.size()
        require(
            HEADER_SIZE <= size <= (SIZE_EWRAM if multiboot else SIZE_ROM0),
            'Image size must be 192 bytes through 32 MiB (256 KiB for multiboot)',
        )
        li.seek(0)
        rom = li.read(size)
        require(len(rom) == size, 'Short cartridge read')

        # getting rom information
        # only the extension of the name matters here (hardcoded names below dont matter)
        expected = recognize(rom, size, 'input.mb' if multiboot else 'input.gba')
        require(expected == format_name, 'Header does not match the selected recognition path')
        image = Image(rom, BASE_EWRAM if multiboot else BASE_ROM0)
        facts = header_facts(image)
        require(ida_idp.set_processor_type('ARM:ARM7TDMI', ida_idp.SETPROC_LOADER), 'Cannot select ARM7TDMI processor')

        # thumb-1 compilers also use BL for long intra-function jumps
        ida_idp.process_config_directive('ARM_DISABLE_BL_JUMPS = NO')

        # set 32bit-le
        ida_ida.inf_set_app_bitness(32)
        ida_ida.inf_set_be(False)  # noqa: FBT003

        # set up the db
        db = Database.open()
        require(not ida_ida.inf_is_be() and db.bitness == 32, 'Cannot establish 32-bit little-endian addressing')
        _setup_database(Annotator(db, image), li, facts)
    except (LoadError, IdaDomainError) as exc:
        error(f'Load failed: {exc}')
        return 0

    return 1


def _setup_database(annotator: Annotator, li: loader_input_t, facts: HeaderFacts) -> None:
    # create all the regions/segments
    db, image = annotator.db, annotator.image
    map_image(db, li, image)

    # label things like I/O registers, struct defs, etc
    annotator.hardware()

    # do things like the IWRAM copies and whatnot
    recovery = recover_startup(image.rom, image.base)
    apply_recovery(annotator, recovery)

    # the "report" that gets logged in the console and noted by the entrypoint
    annotator.report(facts, recovery)

    seed_analysis(annotator, recovery)
    _plan_signatures()
    schedule_post_analysis(db, image, recovery)


def _plan_signatures() -> None:
    """Queue the FLIRT signatures in sig/. IDA applies them during analysis."""

        if not ida_funcs.plan_to_apply_idasgn(str(sig)):
            warn(f'Cannot apply FLIRT signature {sig.name}')

from __future__ import annotations

from typing import TYPE_CHECKING

import ida_allins

from idagba import arm

from idagba.errors import LoadError, require

_pending: PostAnalysis | None = None


def schedule_post_analysis(db: Database, image: Image, recovery: StartupRecovery | StartupRecoveryFailure) -> None:
    global _pending
    recovered = isinstance(recovery, StartupRecovery)
    copies = recovery.copies if recovered else ()

    # without a startup only the header is known data
    reserved = recovery.reserved if recovered else ((image.base, image.base + HEADER_SIZE),)
    _pending = PostAnalysis(db, (image.base, image.end), copies, reserved)
    _pending.hook()
    require(_pending.is_hooked, 'Cannot schedule post-analysis passes')


class PostAnalysis(DatabaseHooks):
    """Runs the passes each time IDA's analysis queue empties, until a pass finds nothing new."""

    MAX_PASSES = 4

    def __init__(
        self,
        db: Database,
        image: tuple[int, int],
        copies: Sequence[StartupCopy],
        reserved: Sequence[tuple[int, int]],
    ) -> None:
        super().__init__()
        self.db, self.image, self.copies, self.reserved = db, image, copies, reserved
        self.passes = 0

    def auto_empty(self) -> None:
        # called when IDA's analysis queue is empty
        global _pending
        self.passes += 1
        try:
            found = self._run_pass()
        except (LoadError, IdaDomainError) as exc:
            warn(f'Post-analysis stopped: {exc}')
            found = 0

        # Stop after MAX_PASSES passes even when they keep finding code.
        if not found or self.passes >= self.MAX_PASSES:
            self.unhook()
            _pending = None

    def closebase(self) -> None:
        global _pending
        self.unhook()
        _pending = None

    def _run_pass(self) -> int:
        """Run one pass and return how many new code references it added."""
        swis = self._annotate_swis()
        branches = self._resolve_veneers()
        handlers = self._resolve_irq_handlers()
        log(f'Post-analysis pass: {branches} veneer calls, {handlers} IRQ handlers, {swis} BIOS calls')
        return branches + handlers

    def _annotate_swis(self) -> int:
        db = self.db
        count = 0

        # Every pass rescans all analyzed instructions.
        for function_ea in self._function_starts():
            function = db.functions.get_at(function_ea)
            if function is None:
                continue

            for insn in list(db.functions.get_instructions(function)):
                ea = insn.ea
                if not db.bytes.is_code_at(ea):
                    continue

                number = arm.swi_number(db, insn)
                if number is None or db.comments.get_at(ea):
                    continue

                if number < len(BIOS_CALL_NAMES):
                    count += db.comments.set_at(ea, f'BIOS SWI {number:#04x} {BIOS_CALL_NAMES[number]}')

        return count

    def _resolve_veneers(self) -> int:
        """Link calls through Thumb bx veneers to their targets.

        Several callers share one veneer, so each call site is resolved on its own.
        """
        db = self.db
        count = 0
        for ea in self._function_starts():
            function = db.functions.get_at(ea)
            first = self._decode(ea) if arm.thumb_state(ea) == 1 else None
            if function is None or first is None:
                continue

            # a veneer is bx rN, or ldr rN then bx rN
            branch = first if first.itype == ida_allins.ARM_bx else self._decode(ea + first.size)
            if branch is None or branch.itype != ida_allins.ARM_bx or branch.ea + branch.size != function.end_ea:
                continue

            target = db.instructions.get_operand(branch, 0)
            if not isinstance(target, RegisterOperand):
                continue

            # for a lone bx, the caller loads rN right before the call
            for call in list(db.xrefs.calls_to_ea(ea)):
                load = first if branch is not first else self._decode(db.heads.get_previous(call))
                if branch is first and (
                    load is None
                    or load.ea + load.size != call
                    or self._function_start(load.ea) != self._function_start(call)
                ):
                    continue

                pointer = self._literal(load, target.register_number)
                if pointer is not None:
                    count += self._link_call(call, pointer)

        return count

    def _literal(self, load: insn_t | None, reg: int) -> int | None:
        """The value that `ldr reg, =literal` loads, if its pool is in the image or a RAM copy."""
        db = self.db
        if load is None or load.itype != ida_allins.ARM_ldr:
            return None

        destination = db.instructions.get_operand(load, 0)
        source = db.instructions.get_operand(load, 1)
        if (
            not isinstance(destination, RegisterOperand)
            or destination.register_number != reg
            or not isinstance(source, MemoryOperand)
            or not source.is_direct_memory()
        ):
            return None

        pool = source.get_address()
        if pool is None or (
            pool % 4
            or not (
                self.image[0] <= pool <= self.image[1] - 4
                or any(c.destination <= pool <= c.destination + c.size - 4 for c in self.copies)
            )
        ):
            return None

        return db.bytes.get_dword_at(pool, allow_uninitialized=True)

    def _link_call(self, site: int, pointer: int) -> bool:
        """Add a call reference from site to the pointer's target. Returns True when it is new."""
        db = self.db
        address = self._claim(site, pointer)
        if address is None:
            return False

        # Keep the actual branch-to-veneer call as well as its proven callee.
        require(db.xrefs.add_code_ref(site, address, XrefType.CALL_NEAR), f'Cannot add resolved call at {site:#x}')
        if not db.comments.get_at(site):
            db.comments.set_at(site, f'Literal/BX veneer resolves to {address:#010x}')

        return True

    def _resolve_irq_handlers(self) -> int:
        """Find the handlers that code stores into the BIOS IRQ vector."""
        db = self.db
        count = 0

        # The BIOS IRQ handler pointer, at its own address and through the IWRAM mirror.
        for vector in (BASE_IWRAM + 0x7FFC, BASE_IWRAM_MIRROR + 0x7FFC):
            for load in self._vector_loads(vector):
                function = db.functions.get_at(load)
                if function is None:
                    continue

                ea = load
                # Only the eight instructions after the vector load are checked.
                for _ in range(8):
                    following = db.heads.get_next(ea)
                    if following is None or following >= function.end_ea:
                        break

                    ea = following
                    insn = self._decode(ea)
                    if insn is None:
                        break

                    handler = self._stored_handler(insn, vector)
                    if handler is not None:
                        count += self._install_irq_handler(ea, handler)

        return count

    def _vector_loads(self, vector: int) -> set[int]:
        """Instructions that refer to the vector, directly or through a literal pool."""
        db = self.db
        loads = set()
        for xref in db.xrefs.to_ea(vector):
            if db.bytes.is_code_at(xref.from_ea):
                loads.add(xref.from_ea)
            else:
                loads.update(pool.from_ea for pool in db.xrefs.to_ea(xref.from_ea) if db.bytes.is_code_at(pool.from_ea))

        return loads

    def _stored_handler(self, insn: insn_t, vector: int) -> int | None:
        """The handler address that a `str` instruction writes to the vector, if it does."""
        db = self.db
        if insn.itype != ida_allins.ARM_str:
            return None

        stored = db.instructions.get_operand(insn, 0)
        address = db.instructions.get_operand(insn, 1)
        if (
            not isinstance(address, MemoryOperand)
            or address.type != OperandType.DISPLACEMENT
            or not isinstance(stored, RegisterOperand)
        ):
            return None

        phrase, displacement = address.get_phrase_number(), address.get_displacement()
        if phrase is None or displacement is None:
            return None

        # base + displacement must be the vector
        target = ida_regfinder.find_reg_value(insn.ea, phrase)
        if target is None or (target + displacement) & 0xFFFFFFFF != vector:
            return None

        handler = ida_regfinder.find_reg_value(insn.ea, stored.register_number)
        return None if handler is None or handler % 4 else handler

    def _install_irq_handler(self, site: int, handler: int) -> bool:
        """Name the handler and reference it from site. Returns True when it is new."""
        db = self.db
        if self._claim(site, handler) is None:
            return False

        if not db.bytes.has_user_name_at(handler):
            db.names.set_name(handler, 'GBA_IrqMain', SetNameFlags.NOWARN | SetNameFlags.FORCE)

        require(db.xrefs.add_data_ref(site, handler, XrefType.OFFSET), f'Cannot reference IRQ handler from {site:#x}')
        if not db.comments.get_at(site):
            db.comments.set_at(site, f'Installs ARM BIOS IRQ handler {handler:#010x}')

        return True

    def _claim(self, site: int, pointer: int) -> int | None:
        """Schedule code at the pointer's target and return its address, or None when nothing is new."""
        db = self.db
        address = pointer & ~1
        if not code_pointer(pointer, self.image, self.copies, self.reserved) or any(
            xref.from_ea == site for xref in db.xrefs.to_ea(address)
        ):
            return None

        # don't turn data into code
        if db.bytes.is_data_at(address) or db.bytes.is_tail_at(address):
            return None

        # existing code must match the thumb bit
        if db.bytes.is_code_at(address):
            if arm.thumb_state(address) != pointer & 1:
                return None
        else:
            arm.set_thumb(address, pointer & 1)

        db.auto_analysis.schedule_function(address)
        return address

    def _decode(self, ea: int | None) -> insn_t | None:
        db = self.db
        if ea is None or not db.is_valid_ea(ea) or not db.bytes.is_code_at(ea):
            return None

        return db.instructions.get_at(ea)

    def _function_start(self, ea: int) -> int | None:
        function = self.db.functions.get_at(ea)
        return function.start_ea if function else None

    def _function_starts(self) -> list[int]:
        return [function.start_ea for function in self.db.functions.get_all()]

from __future__ import annotations

from typing import TYPE_CHECKING

from ida_domain.comments import CommentKind
from ida_domain.names import SetNameFlags
from ida_domain.types import TypeApplyFlags

from idagba.crt0 import StartupRecovery, StartupRecoveryFailure
from idagba.errors import require
from idagba.hardware import (

    BASE_IWRAM,
    BASE_IWRAM_MIRROR,
    BASE_OAM,
    BASE_PALETTE_RAM,
    HEADER_FIELDS,
    REGISTERS,
    SIZE_OAM,
    SIZE_PALETTE_RAM,
    WORKSPACE,
)
from idagba.logging import log, warn

if TYPE_CHECKING:
    from ida_domain import Database

    from idagba.hardware import HardwareAnnotation
    from idagba.rom import HeaderFacts, Image


class Annotator:
    """Names, types and comments things in the database of one image."""

    def __init__(self, db: Database, image: Image) -> None:
        self.db, self.image = db, image

    def name(self, ea: int, text: str) -> None:
        db = self.db
        existing = db.names.get_at(ea)
        if existing == text:
            return

        # keep a name that was set by hand
        if existing and db.bytes.has_user_name_at(ea):
            warn(f'Retaining existing name {existing} at {ea:#x}; requested {text}')
            return

        require(db.names.set_name(ea, text, SetNameFlags.NOWARN), f'Cannot name {ea:#x} {text}')

    def comment(self, ea: int, text: str) -> None:
        # repeatable comments also show up wherever the address is used
        require(self.db.comments.set_at(ea, text, CommentKind.REPEATABLE), f'Cannot annotate {ea:#x}')

    def data(self, ea: int, size: int, width: int, text: str, *, declaration: str | None = None) -> None:
        db = self.db

        # size bytes of data, in items of width bytes
        create = {1: db.bytes.create_byte_at, 2: db.bytes.create_word_at, 4: db.bytes.create_dword_at}[width]
        require(create(ea, size // width), f'Cannot create {size}-byte data at {ea:#x}')

        # a definite type is one IDA will not replace with a guess
        if declaration:
            require(
                db.types.apply_declaration_at(ea, declaration, TypeApplyFlags.DEFINITE), f'Cannot apply type at {ea:#x}'
            )

        self.name(ea, text)

    def apply(self, annotation: HardwareAnnotation, base: int, suffix: str = '') -> None:
        """Create one entry of a hardware table at base."""
        ea = base + annotation.offset
        self.data(ea, annotation.size, annotation.width, annotation.name + suffix, declaration=annotation.declaration)
        if annotation.comment:
            self.comment(ea, annotation.comment)

    def hardware(self) -> None:
        self._header()
        self._cartridge_ports()
        self._video_memory()
        self._io_registers()
        self._bios_workspace()

    def _header(self) -> None:
        base = self.image.base

        # label the header in every view
        for view, suffix in self.image.views:
            for annotation in HEADER_FIELDS:
                self.apply(annotation, view, suffix)

        # two extra bytes the BIOS fills in
        if self.image.multiboot:
            for offset, field in ((0xC4, 'GBA_MB_BOOT_MODE'), (0xC5, 'GBA_MB_SLAVE_ID')):
                self.data(base + offset, 1, 1, field, declaration='volatile unsigned char value;')

    def _cartridge_ports(self) -> None:
        rom, base = self.image.rom, self.image.base

        # carts with a GPIO port keep these six header bytes zero
        # https://mgba-emu.github.io/gbatek/#gbacartioportgpio
        if not self.image.multiboot and len(rom) >= 0xCA and not any(rom[0xC4:0xCA]):
            for offset, port in ((0xC4, 'GBA_GPIO_DATA'), (0xC6, 'GBA_GPIO_DIRECTION'), (0xC8, 'GBA_GPIO_CONTROL')):
                self.data(base + offset, 2, 2, port, declaration='volatile unsigned short value;')

        # the EEPROM is read and written through one port
        eeprom = self.db.segments.get_by_name('EEPROM')
        if eeprom:
            self.data(eeprom.start_ea, 2, 2, 'GBA_EEPROM', declaration='volatile unsigned short value;')

    def _video_memory(self) -> None:
        # types for the palette and the sprite table (OAM)
        decls = """
            struct GBA_PaletteRAM {
                unsigned short BG_PALETTE[256];
                unsigned short OBJ_PALETTE[256];
            };

            struct GBA_OAMEntry {
                unsigned short attr0;
                unsigned short attr1;
                unsigned short attr2;
                short affine;
            };

            struct GBA_OAM {
                struct GBA_OAMEntry obj[128];
            };
        """

        # add them to the database
        require(
            self.db.types.parse_declarations(
                None,  # ty: ignore[invalid-argument-type]  # None selects the database's local library
                decls,
            )
            == 0,
            'Cannot define GBA palette/OAM types',
        )

        self.data(BASE_PALETTE_RAM, SIZE_PALETTE_RAM, 2, 'GBA_PALETTE', declaration='struct GBA_PaletteRAM value;')
        self.comment(BASE_PALETTE_RAM, 'BG colors, then OBJ colors at 0x05000200. Each color is 15-bit BGR.')
        self.data(BASE_OAM, SIZE_OAM, 2, 'GBA_OAM', declaration='struct GBA_OAM value;')
        self.comment(BASE_OAM, '128 sprites. The affine fields of every four sprites hold one affine matrix.')

    def _io_registers(self) -> None:
        # one typed, named and commented item per register
        scalar = {1: 'unsigned char', 2: 'unsigned short', 4: 'unsigned int'}
        for register in REGISTERS:
            ea = BASE_IO + register.offset

            # volatile makes the decompiler keep every read and write
            array = f'[{register.count}]' if register.count > 1 else ''
            declaration = f'volatile {scalar[register.width]} value{array};'
            self.data(ea, register.width * register.count, register.width, register.name, declaration=declaration)
            self.comment(ea, register.access_description)

    def _bios_workspace(self) -> None:
        # BIOS variables, also through the IWRAM mirror
        for workspace_base, suffix in ((BASE_IWRAM, ''), (BASE_IWRAM_MIRROR, '_MIRROR')):
            for annotation in WORKSPACE:
                self.apply(annotation, workspace_base, suffix)

    def report(self, facts: HeaderFacts, recovery: StartupRecovery | StartupRecoveryFailure) -> None:
        base = self.image.base
        kind = 'multiboot image' if self.image.multiboot else 'cartridge'

        # bytes without the b prefix
        def brepr(s: bytes) -> str:
            return repr(s)[1:]

        lines = [
            f'GBA {kind}: {facts.size} bytes at {base:#010x}',
            'Title: ' + brepr(facts.title.strip(b'\0')),
            'Game: ' + brepr(facts.game_code.rstrip(b'\0')),
            'Maker: ' + brepr(facts.maker),
        ]

        # these are usually zero, so only show them when set
        if facts.unit:
            lines.append(f'Unit: {facts.unit:#x}')

        if facts.device:
            lines.append(f'Device: {facts.device:#x}')

        if facts.version:
            lines.append(f'Version: {facts.version}')

        if facts.reserved1.strip(b'\0') or facts.reserved2.strip(b'\0'):
            lines.append(f'Non-null reserved bytes: {brepr(facts.reserved1)} + {brepr(facts.reserved2)}')

        if facts.save_markers:
            lines.append('Save SDK clues (advisory only): ' + (', '.join(facts.save_markers) or 'none'))

        lines += [f'Warning: {warning}' for warning in facts.warnings]

        # add the comments to the entry point before adding the sloppy dkA comments
        self.comment(base, '\n'.join(lines))

        if isinstance(recovery, StartupRecoveryFailure):
            lines.append(f'Startup recovery not applied: {recovery.reason}')
        else:
            lines.append(f'Stock devkitARM startup found at {recovery.start:#010x}!')
            lines.extend(
                f'{copy.name}: {copy.source:#010x} -> {copy.destination:#010x}, {copy.size:#x} bytes'
                for copy in recovery.copies
            )

        # log everything to the console
        for line in lines:
            log(line)

from __future__ import annotations

from dataclasses import dataclass, replace

import ida_loader

    size: int
    permissions: SegmentPermissions
    segment_class: PredefinedClass
    comment: str | None = None

    @property
    def end(self) -> int:
        return self.start + self.size


RX = SegmentPermissions.READ | SegmentPermissions.EXEC
RW = SegmentPermissions.READ | SegmentPermissions.WRITE
RWX = RW | SegmentPermissions.EXEC
CODE = PredefinedClass.CODE
DATA = PredefinedClass.DATA

# the regions every image has
REGIONS = (
    MemoryRegion('BIOS', hw.BASE_BIOS, hw.SIZE_BIOS, RX, CODE),
    MemoryRegion('EWRAM', hw.BASE_EWRAM, hw.SIZE_EWRAM, RWX, DATA),
    MemoryRegion('IWRAM', hw.BASE_IWRAM, hw.SIZE_IWRAM, RWX, DATA),
    MemoryRegion('IWRAM_BIOS_MIRROR', hw.BASE_IO - 0x100, 0x100, RW, DATA, 'Static copy of the end of IWRAM.'),
    # 0x804 so the segment reaches REG_MEMCNT at 0x800
    MemoryRegion('IO', hw.BASE_IO, 0x804, RW, DATA),
    MemoryRegion('PALETTE', hw.BASE_PALETTE_RAM, hw.SIZE_PALETTE_RAM, RW, DATA),
    MemoryRegion('VRAM', hw.BASE_VRAM, hw.SIZE_VRAM, RW, DATA),
    MemoryRegion('OAM', hw.BASE_OAM, hw.SIZE_OAM, RW, DATA),
)
SAVE = MemoryRegion(
    'SAVE', hw.BASE_SRAM, 0x10000, RW, DATA, 'SRAM or Flash, if the cart has one. The chip is not detected.'
)

# a cartridge up to 16 MiB shows its EEPROM in this whole region, a larger one only in the last 0x100 bytes
# https://mgba-emu.github.io/gbatek/#gbacartbackupeeprom
EEPROM = MemoryRegion(
    'EEPROM',
    hw.BASE_ROM2_EX,
    hw.BASE_SRAM - hw.BASE_ROM2_EX,
    RW,
    DATA,
    'Serial EEPROM port, if the cart has one.',
)
EEPROM_LARGE_ROM = replace(EEPROM, start=hw.BASE_SRAM - 0x100, size=0x100)


def map_image(db: Database, li: loader_input_t, image: Image) -> None:
    # make the empty segments
    for region in _regions(image):
        _create(db, region)

    # load the file into every view of the image
    size = len(image.rom)
    for view, _ in image.views:
        # only the load address is patchable, the other views are static copies
        patchable = ida_loader.FILEREG_PATCHABLE if view == image.base else 0
        require(
            li.file2base(0, view, view + size, patchable),  # ty: ignore[invalid-argument-type]
            f'Cannot map image at {view:#x}',
        )


def _regions(image: Image) -> list[MemoryRegion]:
    regions = [*REGIONS]
    if not image.multiboot:
        size = len(image.rom)
        note = f'Static copy of ROM at {hw.BASE_ROM0:#010x}.'

        # the mirrors are DATA so FLIRT does not match the library code in them again
        regions += (
            MemoryRegion('ROM' + suffix, view, size, RX, DATA if suffix else CODE, note if suffix else None)
            for view, suffix in image.views
        )

        # the EEPROM goes in the first of its two places that the ROM does not cover
        for eeprom in (EEPROM, EEPROM_LARGE_ROM):
            if hw.BASE_ROM2 + size <= eeprom.start:
                regions.append(eeprom)
                break

    regions.append(SAVE)
    return regions


def _create(db: Database, region: MemoryRegion) -> None:
    # no segment registers, sparse storage, no analysis yet
    flags = AddSegmentFlags.NOSREG | AddSegmentFlags.SPARSE | AddSegmentFlags.NOAA
    segment = db.segments.add(0, region.start, region.end, region.name, region.segment_class, flags)
    if segment is None:
        msg = f'Cannot create segment {region.name}'
        raise LoadError(msg)

    # setting the addressing mode makes IDA analyze the segment, so skip it when it is already 32-bit
    if db.segments.get_bitness(segment) != 32:
        db.segments.set_addressing_mode(segment, AddressingMode.BIT32)

    # set_permissions changes the object and update() saves it
    db.segments.set_permissions(segment, region.permissions)
    segment.update()
    if region.comment:
        db.segments.set_comment(segment, region.comment, repeatable=True)

    # final sanity check
    _check(db, region)


def _check(db: Database, region: MemoryRegion) -> None:
    """Raise unless the segment was created as the region describes."""
    segment = db.segments.get_at(region.start)
    require(
        segment is not None
        and segment.start_ea == region.start
        and segment.end_ea == region.end
        and segment.perm == region.permissions
        and db.segments.get_class(segment) == region.segment_class.value
        and db.segments.get_bitness(segment) == 32,
        f'Segment {region.name} does not have the required extent, permissions, class, or bitness',
    )


__all__ = ['MemoryRegion', 'map_image']

"""Applies the startup recovery to the database and tells IDA where the code starts."""

from __future__ import annotations

from typing import TYPE_CHECKING

import ida_funcs
import ida_ida
from ida_domain.xrefs import XrefType

from idagba.arm import set_thumb
from idagba.crt0 import StartupRecovery, StartupRecoveryFailure
from idagba.errors import require

if TYPE_CHECKING:
    from idagba.loader.annotate import Annotator


def apply_recovery(annotator: Annotator, recovery: StartupRecovery | StartupRecoveryFailure) -> None:
    if isinstance(recovery, StartupRecoveryFailure):
        return

    rom = annotator.image.rom
    for copy in recovery.copies:
        source, dest, size = copy.source, copy.destination, copy.size
        offset = source - recovery.base

        # do the startup's copy into RAM
        annotator.db.bytes.set_bytes_at(dest, rom[offset : offset + size])

        # label the source as data
        annotator.data(source, size, 1, copy.name)
        annotator.comment(source, f'Stock crt0 copy: {source:#010x} -> {dest:#010x}, {size:#x} bytes')


def seed_analysis(annotator: Annotator, recovery: StartupRecovery | StartupRecoveryFailure) -> None:
    _seed_entry(annotator)
    if isinstance(recovery, StartupRecovery):
        _seed_helpers(annotator, recovery)
        _seed_calls(annotator, recovery)


def _seed_entry(annotator: Annotator) -> None:
    db, image = annotator.db, annotator.image
    entry = image.entry

    # entry runs in ARM state
    set_thumb(entry, 0)

    # register it as the entry point
    require(ida_ida.inf_set_start_cs(0) and ida_ida.inf_set_start_ea(entry), 'Cannot establish flat entry address')
    db.start_ip = entry
    require(
        db.entries.add(entry, 'GBA_MB_ENTRY' if image.multiboot else 'GBA_ROM_ENTRY', make_code=True),
        'Cannot add image entry',
    )
    db.auto_analysis.schedule_function(entry)

    # name the branch target
    target = image.entry_target
    if target is not None:
        annotator.name(target, 'GBA_STARTUP')


def _seed_helpers(annotator: Annotator, recovery: StartupRecovery) -> None:
    """Name the helper routines after the startup code and make them functions."""
    db = annotator.db
    start = recovery.start
    set_thumb(start, 0)

    # startup enters Thumb state after ten ARM instructions (4 bytes for each insn)
    set_thumb(start + (4 * 10), 1)

    # the helpers linked here end up at these offsets from ClearMem once assembled
    # https://github.com/devkitPro/devkitarm-crtls/blob/333d62c/gba_crt0.s#L194-L253
    helpers = recovery.clear_mem
    for delta, routine in ((0, 'GBA_ClearMem'), (0x12, 'GBA_BxR3'), (0x14, 'GBA_CopyMemChk')):
        address = helpers + delta
        set_thumb(address, 1)
        annotator.name(address, routine)

        # CopyMemChk falls through into CopyMem, so they are one function
        if delta == 0x14:
            require(
                db.instructions.create(address) == 2,
                'Cannot decode CopyMemChk',
            )
            require(
                ida_funcs.add_func(address, helpers + 0x28),
                'Cannot establish CopyMemChk with its CopyMem interior entry',
            )

        db.auto_analysis.schedule_function(address)

    # CopyMem is a second entry into it
    annotator.name(helpers + 0x16, 'GBA_CopyMem')


def _seed_calls(annotator: Annotator, recovery: StartupRecovery) -> None:
    """Name the two routines the startup calls through r3 and link the calls to them."""
    db = annotator.db
    start = recovery.start

    # the two `bl _blx_r3_stub` calls linked here end up at these offsets from start_vector once assembled
    # https://github.com/devkitPro/devkitarm-crtls/blob/333d62c/gba_crt0.s#L176-L184
    for pointer, routine, callsite in (
        (recovery.constructors, '__libc_init_array', 0x98),
        (recovery.main, 'main', 0xA2),
    ):
        # bit 0 is the thumb flag
        address = pointer & ~1
        set_thumb(address, pointer & 1)
        annotator.name(address, routine)
        db.auto_analysis.schedule_function(address)

        # link the bx r3 call to its target
        require(
            db.instructions.create(start + callsite) == 4,
            f'Cannot decode proven Thumb callsite at {start + callsite:#x}',
        )
        require(
            db.xrefs.add_code_ref(start + callsite, address, XrefType.CALL_NEAR),
            f'Cannot add proven startup call to {routine}',
        )

```py
"""Decides whether a file is a GBA cartridge, a multiboot image, or neither."""

from __future__ import annotations

import struct
from typing import Protocol

from idagba.crt0 import Crt0, find_crt0
from idagba.hardware import BASE_EWRAM, BASE_ROM0, SIZE_EWRAM, SIZE_ROM0
from idagba.rom import HEADER_SIZE, entry_target, logo_matches

FORMAT = 'Nintendo Game Boy Advance ROM (ARM7TDMI)'
RELAXED_FORMAT = 'Nintendo Game Boy Advance ROM (homebrew or damaged header)'
MB_FORMAT = 'Nintendo Game Boy Advance multiboot image (EWRAM)'
FORMAT_MARKER = 'Game Boy Advance'


class LoaderInput(Protocol):
    """The part of IDA's loader_input_t that recognition reads."""

    def read(self, size: int = -1, /) -> bytes: ...
    def seek(self, offset: int, whence: int = 0, /) -> int: ...
    def tell(self) -> int: ...
    def size(self) -> int: ...


def accept_file(li: LoaderInput, filename: str) -> dict[str, str | int] | int:
    position = li.tell()
    try:
        li.seek(0)
        size = li.size()

        # multiboot checks need the whole image (max 256 KiB)
        fmt = recognize(li.read(min(size, SIZE_EWRAM)), size, filename)

        # 1 accepts the file and 0x8000 (ACCEPT_FIRST) lists the format first
        return (
            {'format': fmt, 'processor': 'ARM:ARM7TDMI', 'options': 1 if fmt == RELAXED_FORMAT else 0x8001}
            if fmt
            else 0
        )
    finally:
        # other loaders read this stream too
        li.seek(position)


def recognize(data: bytes | bytearray, size: int, filename: str) -> str | None:
    """Return the format name of an image, or None. A multiboot check needs the whole image in data."""
    if not HEADER_SIZE <= size <= SIZE_ROM0 or len(data) < HEADER_SIZE:
        return None

    # like mGBA, allow a missing 0x96 byte only when the logo is all zero (an unfixed header)
    # https://github.com/mgba-emu/mgba/blob/cfef853/src/gba/gba.c#L728-L745
    if data[0xB2] != 0x96 and any(data[4:0xA0]):
        return None

    name = str(filename).lower()
    logo = logo_matches(data)

    # check multiboot first since it has a cartridge header too
    fits_ewram = 0xC4 <= size <= SIZE_EWRAM and len(data) >= size
    if fits_ewram and (name.endswith('.mb') or looks_multiboot(bytes(data[:size]))):
        # without the logo, a known extension and a valid entry branch are enough
        named = name.endswith(('.mb', '.gba', '.agb'))
        valid = logo or (named and entry_target(data, size, BASE_EWRAM, HEADER_SIZE) is not None)
        return MB_FORMAT if valid else None

    if logo:
        return FORMAT

    # no logo, but a valid entry branch
    if name.endswith(('.gba', '.agb')) and entry_target(data, size) is not None:
        return RELAXED_FORMAT

    return None


def looks_multiboot(image: bytes) -> bool:
    # the startup code says where the image was linked to run
    crt0 = find_crt0(image)
    if isinstance(crt0, Crt0):
        pool = crt0.pool()
        return pool is not None and pool.text_start == BASE_EWRAM

    # otherwise guess from the addresses the code uses
    return _literal_vote(image)


def _literal_vote(image: bytes) -> bool:
    """Whether the code after the header uses EWRAM addresses and not cartridge ones."""
    # same counting rule as mGBA's GBAIsMB, without its entry branch checks
    # https://github.com/mgba-emu/mgba/blob/cfef853/src/gba/gba.c#L791-L844
    # a tiny cartridge that uses EWRAM addresses early can be taken for multiboot
    ewram = cartridge = 0
    scanned_words = 128
    for offset in range(HEADER_SIZE, min(len(image) - 3, HEADER_SIZE + scanned_words * 4), 4):
        word = struct.unpack_from('<I', image, offset)[0]
        candidates = [word]

        # the literal an `ldr rX, [pc, #imm]` loads is a candidate too
        if word & 0x0F7F0000 == 0x051F0000:
            imm = word & 0xFFF
            literal = offset + 8 + (imm if word & 0x00800000 else -imm)
            if 0 <= literal <= len(image) - 4:
                candidates.append(struct.unpack_from('<I', image, literal)[0])

        # count the addresses in the first 128 KiB of each region
        for value in candidates:
            ewram += value & ~0x1FFFF == BASE_EWRAM
            cartridge += value & ~0x1FFFF == BASE_ROM0

    return ewram > 0 and cartridge < 2

"""ROM header/general binary information classes/helpers"""

from __future__ import annotations

import re
import struct
from dataclasses import dataclass, field

from idagba.hardware import BASE_EWRAM, BASE_ROM0, BASE_ROM1, BASE_ROM2

HEADER_SIZE = 0xC0


@dataclass(frozen=True, slots=True)
class Image:
    """Information about the loaded ROM image."""

    rom: bytes = field(repr=False)
    base: int = BASE_ROM0

    @property
    def multiboot(self) -> bool:
        return self.base == BASE_EWRAM

    @property
    def end(self) -> int:
        return self.base + len(self.rom)

    @property
    def entry(self) -> int:
        """Where execution starts on the given ROM."""
        return self.base + (HEADER_SIZE if self.multiboot else 0)

    @property
    def entry_target(self) -> int | None:
        return entry_target(self.rom, len(self.rom), self.base, self.entry - self.base)

    @property
    def views(self) -> tuple[tuple[int, str], ...]:
        """The address and name suffix of every place the image shows up in memory."""
        if self.multiboot:
            return ((self.base, ''),)

        # GBATEK: the cartridge answers at three addresses that differ only in bus wait state.
        return ((BASE_ROM0, ''), (BASE_ROM1, '_WS1'), (BASE_ROM2, '_WS2'))


@dataclass(frozen=True, slots=True)
class HeaderFacts:
    """The header fields, as read from the image."""

    size: int
    title: bytes
    game_code: bytes
    maker: bytes
    unit: int
    device: int
    version: int
    entry_word: int
    logo_valid: bool
    fixed: int
    reserved1: bytes
    reserved2: bytes
    checksum_stored: int
    checksum_computed: int
    save_markers: tuple[str, ...]
    warnings: tuple[str, ...]


def header_facts(image: Image) -> HeaderFacts:
    rom, base = image.rom, image.base
    entry = image.entry - base

    # https://mgba-emu.github.io/gbatek/#0bdh---complement-check-1-byte
    checksum = (-sum(rom[0xA0:0xBD]) - 0x19) & 0xFF

    warnings = []
    if rom[0xB2] != 0x96:
        warnings.append(f'fixed header byte is {rom[0xB2]:#04x}, not 0x96 (unfixed header)')

    if checksum != rom[0xBD]:
        warnings.append(f'header checksum mismatch: stored {rom[0xBD]:#04x}, computed {checksum:#04x}')

    if not logo_matches(rom):
        warnings.append('Nintendo logo is damaged or nonstandard')

    if rom[0xB3]:
        warnings.append(f'got unexpected unit code at offset 0xB3: {rom[0xB3]:#x}')

    if any(rom[0xB5:0xBC]) or any(rom[0xBE:0xC0]):
        warnings.append('nonzero reserved header bytes')

    if image.entry_target is None:
        warnings.append('unusual or out-of-payload ARM entry instruction, none was recorded...')

    return HeaderFacts(
        size=len(rom),
        title=bytes(rom[0xA0:0xAC]),
        game_code=bytes(rom[0xAC:0xB0]),
        maker=bytes(rom[0xB0:0xB2]),
        unit=rom[0xB3],
        device=rom[0xB4],
        version=rom[0xBC],
        entry_word=struct.unpack_from('<I', rom, entry)[0],
        logo_valid=logo_matches(rom),
        fixed=rom[0xB2],
        reserved1=bytes(rom[0xB5:0xBC]),
        reserved2=bytes(rom[0xBE:0xC0]),
        checksum_stored=rom[0xBD],
        checksum_computed=checksum,
        save_markers=tuple(
            sorted({m.decode('ascii') for m in re.findall(rb'(?:EEPROM|SRAM(?:_F)?|FLASH(?:512|1M)?)_V[0-9]{3}', rom)})
        ),
        warnings=tuple(warnings),
    )


def entry_target(image: bytes | bytearray, size: int, base: int = BASE_ROM0, at: int = 0) -> int | None:
    target = arm_branch_target(struct.unpack_from('<I', image, at)[0], base + at)
    return target if target is not None and base + HEADER_SIZE <= target <= base + size - 4 else None


def logo_matches(header: bytes | bytearray) -> bool:
    if len(header) < HEADER_SIZE:
        return False

    expected = bytearray.fromhex("""
        24 ff ae 51 69 9a a2 21 3d 84 82 0a 84 e4 09 ad
        11 24 8b 98 c0 81 7f 21 a3 52 be 19 93 09 ce 20
        10 46 4a 4a f8 27 31 ec 58 c7 e8 33 82 e3 ce bf
        85 f4 df 94 ce 4b 09 c1 94 56 8a c0 13 72 a7 fc
        9f 84 4d 73 a3 ca 9a 61 58 97 a3 27 fc 03 98 76
        23 1d c7 61 03 04 ae 56 bf 38 84 00 40 a7 0e fd
        ff 52 fe 03 6f 95 30 f1 97 fb c0 85 60 d6 80 25
        a9 63 be 03 01 4e 38 e2 f9 a2 34 ff bb 3e 03 44
        78 00 90 cb 88 11 3a 94 65 c0 7c 63 87 f0 3c af
        d6 25 e4 8b 38 0a ac 72 21 d4 f8 07
    """)
    logo = bytearray(header[4:0xA0])

    # ignore the flag bits inside the logo
    for offset, mask in ((0x9C, 0x84), (0x9E, 0x03)):
        logo[offset - 4] &= ~mask & 0xFF
        expected[offset - 4] &= ~mask & 0xFF

    return logo == expected


def arm_branch_target(word: int, ea: int) -> int | None:
    # only an unconditional ARM branch (b)
    if word & 0xFF000000 != 0xEA000000:
        return None

    imm = word & 0xFFFFFF
    if imm & 0x800000:
        imm -= 0x1000000

    return ea + 8 + (imm << 2)

def _branch(source: int, target: int) -> int:
    delta = target - source - 8
    assert delta % 4 == 0
    assert -(1 << 25) <= delta < (1 << 25)
    return 0xEA000000 | ((delta >> 2) & 0xFFFFFF)


def _finish_header(rom: bytearray, entry: int = 0x080000C0) -> None:
    struct.pack_into('<I', rom, 0, _branch(BASE, entry))
    rom[4:0xA0] = LOGO
    rom[0xA0:0xAC] = b'SYNTHETIC\0\0\0'
    rom[0xAC:0xB0] = b'TEST'
    rom[0xB0:0xB2] = b'01'
    rom[0xB2] = 0x96
    rom[0xB3:0xBC] = b'\0' * 9
    rom[0xBC] = 0
    rom[0xBD] = (-sum(rom[0xA0:0xBD]) - 0x19) & 0xFF
    rom[0xBE:0xC0] = b'\0\0'


def make_synthetic(thumb: tuple[int, ...] = THUMB_TEMPLATE) -> tuple[bytes, dict[int, int]]:
    """A cartridge with the startup code at 0x240 and a small Thumb main."""
    rom = bytearray(0x1000)
    start = BASE + 0x240
    _finish_header(rom, BASE + 0x220)
    struct.pack_into('<I', rom, 0x220, _branch(BASE + 0x220, start))
    for index, word in enumerate(ARM_TEMPLATE):
        struct.pack_into('<I', rom, 0x240 + index * 4, word)

    for index, halfword in enumerate(thumb):
        struct.pack_into('<H', rom, 0x268 + index * 2, halfword)

    # The assembler emits the pool right behind the code: one word per load, in order of first use.
    literal_offsets = {}
    for index, instruction_offset in enumerate(sorted(LOAD_VALUES)):
        instruction = 0x240 + instruction_offset
        literal = 0x240 + 0xD0 + index * 4
        literal_offsets[instruction_offset] = literal
        struct.pack_into('<I', rom, literal, LOAD_VALUES[instruction_offset])
        if instruction_offset in (0x10, 0x1C):
            immediate = struct.unpack_from('<I', rom, instruction)[0] & 0xFFF
            assert instruction + 8 + immediate == literal
        else:
            immediate = struct.unpack_from('<H', rom, instruction)[0] & 0xFF
            assert ((instruction + 4) & ~3) + immediate * 4 == literal

    # Thumb main: poll VCOUNT, mutate initialized RAM, call copied ARM, read WS1 ROM.
    main_halfwords = (
        0xB500, 0x4B09, 0x8818, 0x289F, 0xD9FC, 0x4B08, 0x6818, 0x3001,
        0x6018, 0xF000, 0xF805, 0x4906, 0x6809, 0x1840, 0xBD00, 0x46C0,
        0x4B04, 0x4718,
    )  # fmt: skip
    for index, halfword in enumerate(main_halfwords):
        struct.pack_into('<H', rom, 0x700 + index * 2, halfword)

    struct.pack_into('<IIII', rom, 0x728, 0x04000006, 0x03002000, 0x0A000880, 0x03000100)
    struct.pack_into('<H', rom, 0x780, 0x4770)  # constructor dispatcher fixture
    struct.pack_into('<II', rom, 0x800, 0xE2800001, 0xE12FFF1E)
    rom[0x840:0x84C] = struct.pack('<III', 5, 0xB5F0B082, 0x47702000)
    rom[0x860:0x868] = b'EWRAM!!\0'
    rom[0x870:0x878] = b'OVERLAY0'
    struct.pack_into('<I', rom, 0x880, 0x12345678)
    return bytes(rom), literal_offsets


def make_long_jump() -> bytes:
    """A function that uses a Thumb BL as a long jump inside itself."""
    rom = bytearray(make_synthetic()[0])
    rom[0x700:0x738] = bytes(0x38)

    struct.pack_into('<4H', rom, 0xF20, 0x9800, 0x3001, 0xB004, 0xBD10)

def make_multiboot() -> bytes:
    """The same image linked for EWRAM, as a multiboot image."""
    rom, literals = make_synthetic()
    rom = bytearray(rom)
    struct.pack_into('<I', rom, 0xC0, _branch(BASE + 0xC0, BASE + 0x220))
    for literal in literals.values():
        value = struct.unpack_from('<I', rom, literal)[0]
        if value & 0xFF000000 == BASE:
            struct.pack_into('<I', rom, literal, value - BASE + MB_BASE)

    # The EWRAM section is linked where it is loaded, so crt0 copies it onto itself.
    struct.pack_into('<I', rom, literals[0x88], MB_BASE + 0x860)
    struct.pack_into('<I', rom, literals[0x8A], MB_BASE + 0x868)
    struct.pack_into('<I', rom, 0x730, MB_BASE + 0x880)
    return bytes(rom)

def make_indirect() -> bytes:
    """ARM main that stores an IRQ handler, calls a Thumb function through bx and makes a BIOS call.

    The Thumb function returns the quotient plus the remainder of BIOS Div. A second Thumb routine at
    0x960 calls Halt.
    """
    rom, literals = make_synthetic()
    rom = bytearray(rom)
    struct.pack_into('<I', rom, literals[0xA0], BASE + 0x700)
    rom[0x700:0x740] = bytes(0x40)
    struct.pack_into(
        '<8I',
        rom,
        0x700,
        0xE59F1018,  # ldr r1, =0x03007FFC
        0xE59F0018,  # ldr r0, =ARM handler
        0xE5810000,  # str r0, [r1]
        0xE59F2014,  # ldr r2, =Thumb function | 1
        0xE1A0E00F,  # mov lr, pc
        0xE12FFF12,  # bx r2
        0xEF050000,  # swi 0x050000 (VBlankIntrWait)
        0xE12FFF1E,  # bx lr
    )
    struct.pack_into('<3I', rom, 0x720, 0x03007FFC, BASE + 0x900, BASE + 0x941)
    struct.pack_into('<I', rom, 0x900, 0xE12FFF1E)
    struct.pack_into('<3H', rom, 0x940, 0xDF06, 0x1840, 0x4770)  # svc 6; adds r0, r0, r1; bx lr
    struct.pack_into('<3H', rom, 0x960, 0xDF02, 0x3001, 0x4770)  # svc 2; adds r0, #1; bx lr
    return bytes(rom)


def make_veneers() -> bytes:
    """Thumb main that calls ARM code in IWRAM through a linker veneer and a Thumb routine through bx r3.

    The Thumb routine also leaves through the veneer, as a tail jump.
    """
    rom = bytearray(make_synthetic()[0])
    rom[0x700:0x780] = bytes(0x80)
    struct.pack_into(
        '<10H',
        rom,
        0x700,

    return bytes(rom)

    patched = bytearray(rom)

@pytest.fixture
def load(tmp_path: Path) -> Loader:
    """Load ROM bytes with the loader and yield the database once analysis is done."""

    @contextmanager
    def _load(name: str, data: bytes, file_type: str | None = FORMAT) -> Generator[Database, None, None]:
        if file_type and ida_domain.__ida_version__ < Version('9.2'):
            pytest.skip('idalib before IDA 9.2 exits on the -T switch that selects a loader')

        source = tmp_path / f'{name}.gba'
        source.write_bytes(data)
        log = tmp_path / f'{name}.log'
        options = IdaCommandOptions(
            auto_analysis=True,
            output_database=str(tmp_path / f'{name}.i64'),
            log_file=str(log),
            file_type=file_type,
        )
        try:
            db = Database.open(str(source), args=options, save_on_close=False)
        except DatabaseError as exc:
            pytest.fail(f'{exc}\nIDA log:\n{log.read_text(errors="replace") if log.exists() else ""}')

        with db:
            db.auto_analysis.wait()
            yield db

    return _load


def segment(db: Database, ea: int, name: str, start: int, end: int) -> segment_t:
    found = db.segments.get_at(ea)
    assert found is not None
    assert (found.start_ea, found.end_ea) == (start, end)
    assert db.segments.get_name(found) == name
    return found


def bytes_at(db: Database, ea: int, size: int) -> bytes:
    data = db.bytes.get_bytes_at(ea, size)
    assert data is not None
    assert len(data) == size
    return data


def named(db: Database, ea: int, expected: str) -> None:
    assert db.names.get_at(ea) == expected, (hex(ea), db.names.get_at(ea), expected)


def unloaded(db: Database, ea: int) -> bool:
    return not db.is_valid_ea(ea) or not db.bytes.is_value_initialized_at(ea)


def regular_comment(db: Database, ea: int) -> str | None:
    info = db.comments.get_at(ea)
    return info.comment if info else None


def repeatable_comment(db: Database, ea: int) -> str:
    info = db.comments.get_at(ea, CommentKind.REPEATABLE)
    if info:
        return info.comment

    function = db.functions.get_at(ea)
    return db.functions.get_comment(function, repeatable=True) if function else ''


def has_xref(db: Database, source: int, destination: int, kind: XrefType | None = None) -> bool:
    return any(xref.from_ea == source and (kind is None or xref.type == kind) for xref in db.xrefs.to_ea(destination))


def thumb(ea: int) -> int:
    return ida_segregs.get_sreg(ea, ida_idp.str2reg('T'))


def function_start(db: Database, ea: int) -> int | None:
    function = db.functions.get_at(ea)
    return function.start_ea if function else None


def type_text(db: Database, ea: int) -> str:
    applied = db.types.get_at(ea)
    assert applied is not None, hex(ea)
    return str(applied)


def show_instructions(db: Database, *addresses: int) -> None:
    for ea in addresses:
        assert db.bytes.get_disassembly_at(ea), hex(ea)


def decompile(db: Database, ea: int) -> PseudocodeFunction:
    """Decompile, or skip the rest of the test when the IDA license has no 32-bit ARM decompiler."""
    try:
        return db.pseudocode.decompile(ea)
    except PseudocodeError as exc:
        if 'LICENSE' in str(exc):
            pytest.skip(f'no ARM decompiler license; the checks before this point passed ({exc})')

        raise


def check_entry(db: Database, *, multiboot: bool = False) -> None:
    entry = MB_BASE + 0xC0 if multiboot else BASE
    named(db, entry, 'GBA_MB_ENTRY' if multiboot else 'GBA_ROM_ENTRY')
    assert thumb(entry) == 0


def subexpressions(expr: PseudocodeExpression) -> Iterator[PseudocodeExpression]:
    yield expr
    for child in (expr.x, expr.y, expr.z):
        if child is not None:
            yield from subexpressions(child)

    for arg in expr.call_args or ():
        yield from subexpressions(arg.expression)


def contains_object(item: PseudocodeExpression | PseudocodeInstruction, address: int) -> bool:
    expressions = subexpressions(item) if isinstance(item, PseudocodeExpression) else item.walk_expressions()
    return any(expr.obj_ea == address for expr in expressions)


def hardware_loop(cfunc: PseudocodeFunction) -> bool:
    """Whether some loop reads VCOUNT in its condition, directly or through a variable set in its body."""
    for loop in cfunc.find_loops():
        details = loop.while_details or loop.do_details or loop.for_details
        assert details is not None
        used = {expr.variable_index for expr in subexpressions(details.condition) if expr.op == Op.VAR}
        loaded = {
            expr.x.variable_index
            for expr in details.body.walk_expressions()
            if expr.op == Op.ASG
            and expr.x is not None
            and expr.x.op == Op.VAR
            and expr.y is not None
            and contains_object(expr.y, VCOUNT)
        }
        if contains_object(details.condition, VCOUNT) or used & loaded:
            return True

    return False


def ram_write(cfunc: PseudocodeFunction, address: int) -> bool:
    return any(
        expr.op in (Op.ASG, Op.ASG_ADD, Op.PREINC, Op.POSTINC)
        and expr.x is not None
        and contains_object(expr.x, address)
        for expr in cfunc.walk_expressions()
    )


def palette_writes(cfunc: PseudocodeFunction) -> dict[tuple[int | None, int], int]:
    writes = {}
    for expr in cfunc.walk_expressions():
        target, value = expr.x, expr.y
        if expr.op != Op.ASG or target is None or value is None or target.op != Op.IDX:
            continue

        member, index = target.x, target.y
        if member is None or index is None or member.op != Op.MEMREF or member.x is None:
            continue

        if member.x.obj_ea == 0x05000000 and index.number is not None and value.number is not None:
            writes[member.member_offset, index.number.value] = value.number.value

    return writes


def helper_calls(cfunc: PseudocodeFunction) -> tuple[list[tuple[str | None, int]], int]:
    calls = [
        (expr.x.helper_name, len(expr.call_args or ()))
        for expr in cfunc.walk_expressions()
        if expr.op == Op.CALL and expr.x is not None and expr.x.op == Op.HELPER
    ]
    return calls, sum(insn.op == InsnOp.ASM for insn in cfunc.walk_instructions())


def call_targets(cfunc: PseudocodeFunction) -> list[int]:
    """Addresses of the functions the pseudocode calls by name, sorted."""
    return sorted(
        target
        for expr in cfunc.walk_expressions()
        if expr.op == Op.CALL and expr.x is not None and (target := expr.x.obj_ea) is not None
    )


@pytest.mark.parametrize('file_type', [FORMAT, None], ids=['explicit', 'auto'])
def test_synthetic(load: Loader, file_type: str | None):
    original, _ = make_synthetic()
    with load('synthetic', original, file_type) as db:
        check_entry(db)
        size = 0x1000
        for base, name in ((0x08000000, 'ROM'), (0x0A000000, 'ROM_WS1'), (0x0C000000, 'ROM_WS2')):
            segment(db, base, name, base, base + size)

        for ea, name, start, end in (
            (0, 'BIOS', 0, 0x4000),
            (0x02000000, 'EWRAM', 0x02000000, 0x02040000),
            (0x03000000, 'IWRAM', 0x03000000, 0x03008000),
            (0x03FFFF00, 'IWRAM_BIOS_MIRROR', 0x03FFFF00, 0x04000000),
            (0x04000000, 'IO', 0x04000000, 0x04000804),
            (0x05000000, 'PALETTE', 0x05000000, 0x05000400),
            (0x06000000, 'VRAM', 0x06000000, 0x06018000),
            (0x07000000, 'OAM', 0x07000000, 0x07000400),
            (0x0E000000, 'SAVE', 0x0E000000, 0x0E010000),
        ):
            segment(db, ea, name, start, end)

        assert ida_ida.inf_get_start_ea() == BASE
        assert db.start_ip == BASE
        rx = SegmentPermissions.READ | SegmentPermissions.EXEC
        rw = SegmentPermissions.READ | SegmentPermissions.WRITE
        for ea, permissions, kind in (
            (BASE, rx, ida_segment.SEG_CODE),
            (0x02000000, rw | SegmentPermissions.EXEC, ida_segment.SEG_DATA),
            (0x04000000, rw, ida_segment.SEG_DATA),
            (0, rx, ida_segment.SEG_CODE),
            (0x0E000000, rw, ida_segment.SEG_DATA),
        ):
            found = db.segments.get_at(ea)
            assert found is not None
            assert found.perm == permissions, hex(ea)
            assert found.type == kind, hex(ea)

        show_instructions(db, BASE, 0x08000220, 0x08000240, 0x08000268, 0x08000700, 0x03000100)
        assert bytes_at(db, BASE, size) == original
        assert bytes_at(db, 0x0A000000, size) == original
        assert bytes_at(db, 0x0C000000, size) == original
        assert unloaded(db, BASE + size)
        assert unloaded(db, 0x0A000000 + size)
        assert bytes_at(db, 0x03000100, 8) == original[0x800:0x808]
        assert bytes_at(db, 0x03002000, 12) == original[0x840:0x84C]
        assert bytes_at(db, 0x02000100, 8) == original[0x860:0x868]
        assert bytes_at(db, 0x03002100, 8) == original[0x870:0x878]
        assert db.bytes.is_code_at(0x03000100)
        for ea in (0x03001000, 0x02001000, 0x04000010, 0x0E000000, 0, 0x05000000, 0x06000000, 0x07000000):
            assert unloaded(db, ea), hex(ea)

        assert not db.bytes.is_code_at(BASE + 4)
        assert not db.bytes.is_code_at(BASE + 0x800)
        assert not db.bytes.is_code_at(0x03002004), 'Prologue-looking data became code'
        for offset, suffix, item_size in (
            (0x04, 'LOGO', 156),
            (0xA0, 'TITLE', 12),
            (0xAC, 'GAME_CODE', 4),
            (0xB0, 'MAKER_CODE', 2),
            (0xB2, 'FIXED', 1),
            (0xB3, 'UNIT_CODE', 1),
            (0xB4, 'DEVICE_TYPE', 1),
            (0xB5, 'RESERVED1', 7),
            (0xBC, 'VERSION', 1),
            (0xBD, 'CHECKSUM', 1),
            (0xBE, 'RESERVED2', 2),
        ):
            named(db, BASE + offset, 'GBA_HDR_' + suffix)
            assert db.bytes.get_data_size_at(BASE + offset) == item_size

        named(db, 0x0A000000 + 0xA0, 'GBA_HDR_TITLE_WS1')
        for source, destination, lma_name in (
            (0x08000800, 0x03000100, 'GBA_DATA_LMA'),
            (0x08000840, 0x03002000, 'GBA_IWRAM_LMA'),
            (0x08000860, 0x02000100, 'GBA_EWRAM_LMA'),
            (0x08000870, 0x03002100, 'GBA_IWRAM0_LMA'),
        ):
            named(db, source, lma_name)
            provenance = repeatable_comment(db, source)
            assert f'{source:#010x}' in provenance
            assert f'{destination:#010x}' in provenance
            assert not repeatable_comment(db, destination)

        named(db, 0x0C000000 + 0xA0, 'GBA_HDR_TITLE_WS2')
        assert db.functions.get_at(0x0A000000) is None
        assert db.functions.get_at(0x0C000000) is None
        assert not any(0x0A000000 <= f.start_ea < 0x0E000000 for f in db.functions.get_all()), 'ROM views analyzed'

        for ea, name in (
            (0x08000220, 'GBA_STARTUP'),
            (0x08000700, 'main'),
            (0x080002E8, 'GBA_ClearMem'),
            (0x080002FA, 'GBA_BxR3'),
            (0x08000780, '__libc_init_array'),
            (0x080002FC, 'GBA_CopyMemChk'),
            (0x080002FE, 'GBA_CopyMem'),
        ):
            named(db, ea, name)

        assert thumb(0x08000240) == 0
        assert thumb(0x08000268) == 1
        for ea in (0x080002E8, 0x080002FA, 0x080002FC):
            assert thumb(ea) == 1
            assert function_start(db, ea) == ea

        assert thumb(0x08000700) == 1
        assert thumb(0x08000780) == 1
        assert thumb(0x03000100) == 0
        assert db.functions.get_at(0x08000700) is not None
        assert function_start(db, 0x080002FC) == 0x080002FC
        assert function_start(db, 0x080002FE) == 0x080002FC
        assert db.functions.get_at(0x03000100) is not None
        assert has_xref(db, 0x080002D8, 0x08000780)
        assert has_xref(db, 0x080002E2, 0x08000700)
        assert has_xref(db, 0x08000720, 0x03000100)
        assert has_xref(db, 0x08000730, 0x0A000880)

        for ea, name, item_size in (
            (0x04000006, 'REG_VCOUNT', 2),
            (0x04000084, 'REG_SOUNDCNT_X', 2),
            (0x04000090, 'REG_WAVE_RAM', 16),
            (0x040000A0, 'REG_FIFO_A', 4),
            (0x040000A4, 'REG_FIFO_B', 4),
            (0x04000120, 'REG_SIOMULTI0', 2),
            (0x04000122, 'REG_SIOMULTI1', 2),
            (0x0400012A, 'REG_SIOMLT_SEND', 2),
            (0x04000300, 'REG_POSTFLG', 1),
            (0x04000301, 'REG_HALTCNT', 1),
            (0x04000800, 'REG_MEMCNT', 4),
        ):
            named(db, ea, name)
            assert db.bytes.get_data_size_at(ea) == item_size, (name, db.bytes.get_data_size_at(ea))

        assert 'volatile' in type_text(db, 0x04000090)
        assert 'volatile' in type_text(db, 0x04000006)
        for ea, name, item_size in (
            (0x03007FF0, 'GBA_SOUND_BUFFER', 4),
            (0x03007FF8, 'GBA_IRQ_FLAGS', 2),
            (0x03007FFA, 'GBA_SOFT_RESET_FLAG', 1),
            (0x03007FFC, 'GBA_IRQ_HANDLER', 4),
            (0x03FFFFF0, 'GBA_SOUND_BUFFER_MIRROR', 4),
            (0x03FFFFF8, 'GBA_IRQ_FLAGS_MIRROR', 2),
            (0x03FFFFFA, 'GBA_SOFT_RESET_FLAG_MIRROR', 1),
            (0x03FFFFFC, 'GBA_IRQ_HANDLER_MIRROR', 4),
        ):
            named(db, ea, name)
            assert db.bytes.get_data_size_at(ea) == item_size

        irq_type = type_text(db, 0x03007FFC)
        assert 'volatile' in irq_type
        assert '(' in irq_type
        for ea, name in (
            (0x080000C4, 'GBA_GPIO_DATA'),
            (0x080000C6, 'GBA_GPIO_DIRECTION'),
            (0x080000C8, 'GBA_GPIO_CONTROL'),
            (0x0D000000, 'GBA_EEPROM'),
        ):
            named(db, ea, name)
            assert db.bytes.get_data_size_at(ea) == 2
            assert 'volatile' in type_text(db, ea)

        segment(db, 0x0D000000, 'EEPROM', 0x0D000000, 0x0E000000)
        named(db, 0x07000000, 'GBA_OAM')
        assert db.heads.bounds(0x07000000)[1] == 0x07000400
        assert regular_comment(db, 0x080002E6) == 'BIOS SWI 0x00 SoftReset'

        main = decompile(db, 0x08000700)
        decompile(db, 0x03000100)
        assert hardware_loop(main), 'Loop no longer polls VCOUNT on each iteration'
        assert ram_write(main, 0x03002000), 'Initialized RAM was incorrectly folded as constant'


def test_crt0_without_soft_reset(load: Loader):
    rom, _ = make_synthetic(THUMB_TEMPLATE_NO_RESET)
    with load('no_reset', rom) as db:
        for ea, name in (
            (0x08000700, 'main'),
            (0x080002E6, 'GBA_ClearMem'),
            (0x080002F8, 'GBA_BxR3'),
            (0x080002FA, 'GBA_CopyMemChk'),
            (0x080002FC, 'GBA_CopyMem'),
        ):
            named(db, ea, name)

        for ea in (0x080002E6, 0x080002F8, 0x080002FA):
            assert thumb(ea) == 1
            assert function_start(db, ea) == ea

        assert function_start(db, 0x080002FC) == 0x080002FA
        assert has_xref(db, 0x080002E2, 0x08000700)


def test_palette(load: Loader):
    with load('palette', make_palette()) as db:
        check_entry(db)
        palette = db.types.get_by_name('GBA_PaletteRAM')
        assert palette is not None
        assert db.types.get_details(palette).size == 0x400
        # Inspect each member while the generator still owns the udt_type_data_t its tinfo_t points into.
        # The raw tinfo_t calls return by value; ida_domain's element-type helper fails on IDA 9.2.
        members = [
            (member.name, member.offset, member.type.get_array_nelems(), member.type.get_array_element().is_uint16())
            for member in db.types.get_udt_members(palette)
        ]

        assert members == [('BG_PALETTE', 0, 256, True), ('OBJ_PALETTE', 0x200, 256, True)]

        named(db, 0x05000000, 'GBA_PALETTE')
        applied = db.types.get_at(0x05000000)
        assert applied is not None
        assert db.types.get_details(applied).name == 'GBA_PaletteRAM'
        assert db.heads.bounds(0x05000000)[1] == 0x05000400
        assert all(unloaded(db, ea) for ea in range(0x05000000, 0x05000400))
        found = db.segments.get_at(0x05000000)
        assert found is not None
        assert found.perm == SegmentPermissions.READ | SegmentPermissions.WRITE
        assert found.type == ida_segment.SEG_DATA
        writes = palette_writes(decompile(db, 0x08000700))
        assert writes == {(0, 0): 20903, (0, 241): 0x7FFF, (0x200, 0): 0x7FFF, (0x200, 255): 0x7FFF}, writes

def test_indirect(load: Loader):
    with load('indirect', make_indirect()) as db:
        check_entry(db)
        show_instructions(db, 0x08000700, 0x08000714, 0x08000718, 0x08000900, 0x08000940)
        assert thumb(0x08000700) == 0
        assert function_start(db, 0x08000700) == 0x08000700
        assert has_xref(db, 0x08000714, 0x08000940, XrefType.CALL_NEAR)
        assert thumb(0x08000940) == 1
        assert function_start(db, 0x08000940) == 0x08000940
        named(db, 0x08000900, 'GBA_IrqMain')
        assert thumb(0x08000900) == 0
        assert function_start(db, 0x08000900) == 0x08000900
        assert has_xref(db, 0x08000708, 0x08000900)
        assert regular_comment(db, 0x08000718) == 'BIOS SWI 0x05 VBlankIntrWait'

        # The plugin installs the lifter; BIOS calls must be helper calls, not __asm.
        # The remainder comes back in R1, the high half of SWI_Div's R1:R0 result.
        for ea, expected in (
            (0x08000700, [('SWI_VBlankIntrWait', 0)]),
            (0x08000940, [('SWI_Div', 2), ('HIDWORD', 1)]),
        ):
            calls, asm = helper_calls(decompile(db, ea))
            assert calls == expected, (hex(ea), calls)
            assert not asm, hex(ea)

        # Halt leaves every register unchanged, so r0 stays live from entry and remains an argument.
        ida_segregs.split_sreg_range(0x08000960, ida_idp.str2reg('T'), 1, ida_segregs.SR_user)
        assert db.functions.create(0x08000960)
        cfunc = decompile(db, 0x08000960)
        calls, asm = helper_calls(cfunc)
        assert calls == [('SWI_Halt', 0)]
        assert not asm
        function_type = cfunc.get_func_type()
        assert function_type is not None
        assert db.types.get_func_argument_count(function_type) == 1, str(cfunc)


def test_veneer_calls(load: Loader):
    with load('veneers', make_veneers()) as db:
        check_entry(db)
        # IDA makes each stub a function of its own: the helper, the two halves of the veneer, the routine.
        for ea in (0x08000720, 0x08000730, 0x08000734, 0x08000740):
            assert function_start(db, ea) == ea

        # The lifter shows every call at the code it reaches instead of at the stub in between.
        assert call_targets(decompile(db, 0x08000700)) == [0x03000100, 0x08000740]
        assert call_targets(decompile(db, 0x08000740)) == [0x03000100]


def test_real(load: Loader):
    if not REAL_ROM.is_file():
        pytest.skip(f'{REAL_ROM} is missing; set IDAGBA_REAL_ROM')

    source = REAL_ROM.read_bytes()
    assert hashlib.sha256(source).hexdigest() == REAL_SHA256
    with load('real', source) as db:
        check_entry(db)
        size = 170740
        for base, name in ((0x08000000, 'ROM'), (0x0A000000, 'ROM_WS1'), (0x0C000000, 'ROM_WS2')):
            segment(db, base, name, base, base + size)
