```md
# Changelog

## 0.1.0 — 2026-08-16

First public release.

### Scanning
- WebAssembly memory capture via hooks on `instantiate`, `instantiateStreaming`,
  `new Instance` and `new Memory`, plus a throttled global sweep for Emscripten
  modules created before the hooks landed.
- Exact / greater / less / between / unknown-initial-value first scans.
- Narrowing: changed, unchanged, increased, decreased, increased by N, decreased by N.
- All-types scan across `i8 · i16 · i32 · i64 · f32 · f64`, each result carrying its
  own type; lanes that cannot represent the value are pruned.
- Aligned fast path over typed arrays, unaligned byte-by-byte path via `DataView`.
- Chunked and cancellable, with progress reporting.
- Aborts loudly if WASM memory grows mid-scan instead of returning a partial result.
- Result cap of 4,000,000 addresses, reported rather than silently truncated.

### Editing
- Read, write and 60 Hz freeze on any address.
- Address list with per-row type, description and live values.

### Time control
- Virtual clock rescaling `performance.now`, `Date.now`, `requestAnimationFrame`
  timestamps and timer delays.
- 0.25x-8x presets, free slider, pause and single-frame step.
- Pure pass-through until the speed is changed, so normal browsing is unaffected.

### Targeting
- Frame-level target selection for games embedded in cross-origin iframes.
- Live region polling with automatic fallback to whichever frame holds the memory.
- Every tab is listed and labelled, including tabs with no agent or discarded by Chrome.
- 1.5s probe timeout so one hung tab can no longer block target discovery.

### Diagnostics
- Live panel readout of engine, fps, clock reads, shared memory and timer activity,
  explaining why time control is or is not taking effect.

### Testing
- 33 assertions running the scan engine against a synthetic 4 MB `WebAssembly.Memory`.
```

# WebCheat

**A Cheat Engine for browser games — as a Chrome extension.**

Scan the game's WebAssembly memory, find the address behind a value, edit it, freeze it,
and speed up or slow down time. No local server, no debug flags, no attaching a debugger.

## What it is

Unity, Godot and Emscripten WebGL games keep their entire game state inside a single
`WebAssembly.Memory` — one flat `ArrayBuffer`. That buffer is the exact browser equivalent
of the process RAM that Cheat Engine scans.

WebCheat hooks WebAssembly before the game instantiates, keeps a reference to that memory,
and gives you the classic scan → narrow → edit → freeze workflow against it.

**Zero dependencies. Zero build step. Nothing runs outside the browser.**

## Features

| | |
|---|---|
| **Value scanning** | Exact, greater, less, between, unknown-initial-value |
| **Narrowing** | Changed, unchanged, increased, decreased, increased by N, decreased by N |
| **All-types scan** | Scan `i8 · i16 · i32 · i64 · f32 · f64` simultaneously; each result carries its own type |
| **Smart lane pruning** | Type lanes that cannot represent your value are skipped — typing `300` never scans `i8` |
| **Aligned + unaligned** | Fast typed-array path, or byte-by-byte for packed structs |
| **Write & freeze** | Edit any address; freeze rewrites it at 60 Hz so the game can't take it back |
| **Time control** | 0.25×–8× speed, pause, single-frame step — via a virtual clock |
| **iframe aware** | Targets individual frames, so games embedded cross-origin work |
| **Live diagnostics** | Tells you *why* something isn't working instead of failing silently |

## Install

Not on the Chrome Web Store — load it unpacked:

```bash
git clone https://github.com/hasaneyldrm/webcheat.git
```

1. Open `chrome://extensions`
2. Enable **Developer mode** (top right)
3. Click **Load unpacked** → select the cloned folder
4. Pin the extension to your toolbar

> **Then reload the game tab once.** WebAssembly hooks must be installed *before* the game
> creates its memory, so the agent runs at `document_start`. Tabs that were already open have
> no agent yet. The panel's **Reload tab** button does this for you.

## Quick start

Find and lock a coin counter in about a minute:

1. Click the **WebCheat** icon — a panel window opens
2. Pick your tab from the dropdown (`[WASM]` means memory was found)
3. Read the value off the screen — say coins = `100`. Type it, hit **First Scan**
4. Play until the value changes — say coins = `250`. Type it, hit **Next Scan**
5. Repeat until one address remains
6. **Double-click** the row → it drops into the Address List
7. Type a new value in its **Value** cell → written straight to memory
8. Tick **Freeze** → the game can no longer change it

**Don't know the value?** (a health bar with no number, a hidden timer)

1. Value type **All**, scan type **Unknown initial value** → **First Scan** (takes a snapshot)
2. Let the value change in game
3. **Next Scan** → **Increased** / **Decreased** / **Changed**
4. Repeat 3–4 times

### Picking a value type

| Looking for | Try |
|---|---|
| Score, coins, level, ammo, lives | `i32` |
| Health bar, speed, timers, positions | `f32` |
| No idea | **All (every type)** |
| Found nothing at all | Turn **Aligned scan** off — slower, but catches packed structs |

> In **All** mode the same address can appear under several types. The low two bytes of an
> `i32` holding `4242` also read as `i16` `4242`. Cheat Engine behaves identically — narrowing
> clears the duplicates.

### Time control

A virtual clock rescales `performance.now`, `Date.now`, `requestAnimationFrame` timestamps
and `setTimeout`/`setInterval` delays.

- **0.25×–8×** presets or a free slider
- **Pause** — speed 0, delta time 0, the game freezes
- **Frame step** — while paused, advance the clock by exactly one frame (16.67 ms)

Games that derive movement from delta time genuinely run faster. Fixed-timestep loops respond
less, since their simulation step is constant by design.

> While the speed has **never been changed**, the clock is a pure pass-through. This is
> deliberate: the extension injects into `<all_urls>`, and normal browsing must be untouched.

## How it works

```mermaid
flowchart TD
    P["Panel — the Cheat Engine window<br/>(extension page)"]
    SW["Service worker<br/>routing + target discovery"]
    B["bridge — ISOLATED world<br/>content script"]
    A["agent — MAIN world<br/>WASM hooks · scanner · freezer · clock"]
    M[("WebAssembly.Memory<br/>the game's RAM")]

    P <-->|chrome.runtime| SW
    SW <-->|"tabs.sendMessage(tabId, frameId)"| B
    B <-->|window.postMessage| A
    A <-->|read / write| M
```

**Why the two content-script worlds:** patching `WebAssembly.instantiate` requires running in
the page's own JS realm (`MAIN`), but that realm has no access to `chrome.*` APIs. A second
script in the `ISOLATED` world relays messages between them.

**Why scanning happens in the page:** a Unity heap is routinely 256 MB–1 GB. Shipping that
across the message channel every scan would be absurd. The agent scans in place and returns
only matching offsets plus one page of results.

**What gets hooked:** `WebAssembly.instantiate`, `instantiateStreaming`, `new WebAssembly.Instance`,
`new WebAssembly.Memory`, plus a throttled sweep of globals to catch Emscripten modules
(`Module.HEAPU8`, `unityInstance.Module.wasmMemory`) that were created before the hooks landed.

**Growth safety:** WASM memory can grow mid-scan, which detaches the old `ArrayBuffer`.
The scanner re-acquires the live buffer every chunk and aborts loudly rather than silently
returning a half-scanned result.

## WebCheat vs Cheat Engine

| | WebCheat | Cheat Engine |
|---|---|---|
| Target | Browser tabs / iframes | Native OS processes |
| Attach | Pick a tab, no debugger | Pick a process |
| Memory model | `WebAssembly.Memory` buffer | Process virtual memory |
| Value scan + narrowing | ✅ | ✅ |
| All-types scan | ✅ | ✅ |
| Write / freeze | ✅ | ✅ |
| Speedhack | ✅ virtual clock | ✅ |
| Pointer scan | ❌ *(planned)* | ✅ |
| AOB / string scan | ❌ *(planned)* | ✅ |
| Disassembler / debugger | ❌ | ✅ |
| Lua scripting | ❌ | ✅ |

WebCheat is deliberately the small end of that table: the scan-and-edit loop, done well, for
the web.

## Troubleshooting

The tab dropdown labels every tab so you always know where you stand:

| Label | Meaning | Fix |
|---|---|---|
| `[WASM]` | Agent present, memory found | Ready — scan away |
| *(none)* | Agent present, no memory yet | Game is still loading; the panel keeps polling |
| `[agent yok]` | Content script never injected | Hit **Reload tab** |
| `[askıda]` | Chrome discarded the tab | Visit the tab once, then **Refresh** |

The **diagnostics line** under Time Control explains speed problems directly:

| It says | Meaning |
|---|---|
| `render döngüsü: 60 fps · saat okuma: 14.203` | Healthy — speed control will work |
| `bu frame'de çalışan bir oyun döngüsü yok` | Wrong frame selected |
| `oyun saati hiç okumuyor` | Fixed-timestep game; speed can't affect it |
| `paylaşımlı bellek (pthread)` | Game loop lives in a Worker — scanning works, time control can't reach it |

## Limitations & roadmap

- **No pointer scan.** Addresses shift on every page load, so you rescan each session. This is
  the single biggest gap versus Cheat Engine and the top roadmap item.
- **No AOB / string scan.** Numeric types only.
- **Pure-JS games aren't scannable.** Phaser, PixiJS and plain-canvas games keep state on the JS
  heap, not in WASM linear memory. A JS object scanner is planned. If the panel reports no
  memory, the game is probably pure JS.
- **Result cap: 4,000,000 addresses.** Exceeding it stops the scan and warns you — it never
  truncates silently.
- **Mixed 64-bit precision.** Single-type `i64`/`u64` scans keep full BigInt precision. In
  **All** mode, mixed lanes share one numeric table, so `i64` values above 2⁵³ lose precision.
  Pick a single type if that matters.
- **Workers are out of reach.** Content scripts don't run in Web Workers, so pthread-based
  builds that drive their loop from a worker won't respond to time control.

WebCheat is a development and analysis tool: for testing your own games, balancing them
quickly, and inspecting client-side state.

Using it to gain an advantage in someone else's multiplayer game or on a leaderboard breaks
that platform's terms of service. That's on you, and it's not what this is for.

## Hızlı başlangıç

Bir coin sayacını bulup kilitlemek yaklaşık bir dakika:

1. **WebCheat** ikonuna bas — panel penceresi açılır
2. Açılır listeden sekmeni seç (`[WASM]` = bellek bulundu demek)
3. Değeri ekrandan oku — diyelim coin = `100`. Yaz, **İlk Tarama**'ya bas
4. Değer değişene kadar oyna — diyelim coin = `250`. Yaz, **Sonraki Tarama**
5. Tek adres kalana kadar tekrarla
6. Satıra **çift tıkla** → Adres Listesi'ne düşer
7. **Değer** hücresine yeni sayıyı yaz → doğrudan belleğe yazılır
8. **Dondur**'u işaretle → oyun artık değiştiremez

**Değeri bilmiyorsan?** (sayısı olmayan can barı, gizli sayaç)

1. Değer tipi **Hepsi**, tarama tipi **Bilinmeyen başlangıç değeri** → **İlk Tarama** (snapshot alır)
2. Oyunda değerin değişmesini sağla
3. **Sonraki Tarama** → **Arttı** / **Azaldı** / **Değişti**
4. 3–4 kez tekrarla

### Tip seçimi

| Aradığın | Dene |
|---|---|
| Skor, coin, level, mermi, can sayısı | `i32` |
| Can barı, hız, süre, pozisyon | `f32` |
| Hiçbir fikrin yok | **Hepsi (tüm tipler)** |
| Hiçbir şey bulamadın | **Hizalı tarama**'yı kapat — yavaş ama paketlenmiş struct'ları yakalar |

> **Hepsi** modunda aynı adres birden fazla tiple çıkabilir. `4242` tutan bir `i32`'nin alt iki
> baytı `i16` olarak da `4242` eder. Cheat Engine de aynen böyle davranır — daraltma tekrarları eler.

### Zaman kontrolü

Sanal saat `performance.now`, `Date.now`, `requestAnimationFrame` timestamp'lerini ve
`setTimeout`/`setInterval` gecikmelerini ölçekler.

- **0.25×–8×** hazır kademeler veya serbest slider
- **Duraklat** — hız 0, delta time 0, oyun donar
- **Kare İlerlet** — duraklatılmışken saati tam bir kare (16.67 ms) iter

Hareketi delta time'dan türeten oyunlar gerçekten hızlanır. Sabit adımlı döngüler daha az
tepki verir, çünkü simülasyon adımları tasarım gereği sabittir.

> Hız **hiç değiştirilmediği sürece** saat tamamen pass-through kalır. Bu bilinçli: uzantı
> `<all_urls>`'e enjekte oluyor ve normal gezinmenin etkilenmemesi gerekiyor.

## Sınırlar ve yol haritası

- **Pointer scan yok.** Adresler her sayfa yüklemesinde kayar, her seansta yeniden tararsın.
  Cheat Engine'e göre en büyük eksik ve yol haritasının ilk maddesi.
- **AOB / string taraması yok.** Sadece sayısal tipler.
- **Saf JS oyunlar taranamıyor.** Phaser, PixiJS ve düz canvas oyunları durumu WASM lineer
  belleğinde değil JS heap'inde tutar. JS obje tarayıcısı planlanıyor. Panel "bellek yok"
  diyorsa oyun muhtemelen saf JS.
- **Sonuç tavanı: 4.000.000 adres.** Aşılırsa tarama durur ve uyarır — asla sessizce kırpmaz.
- **Karışık 64-bit hassasiyeti.** Tek tipli `i64`/`u64` taramaları tam BigInt hassasiyetini
  korur. **Hepsi** modunda karışık şeritler tek bir sayısal tabloyu paylaşır, bu yüzden 2⁵³
  üstündeki `i64` değerleri hassasiyet kaybeder. Önemliyse tek tip seç.
- **Worker'lara ulaşılamıyor.** Content script'ler Web Worker'da çalışmaz; döngüsünü worker'dan
  süren pthread build'leri zaman kontrolüne tepki vermez.

uzantıyı yenile. Lütfen `node test/engine.test.mjs`'i yeşil tut ve tarama motorunda
değiştirdiğin her şey için assertion ekle.

```js
/**
 * WebCheat agent — MAIN world.
 *
 * Sayfanin kendi JS realm'inde calisir. Uc isi var:
 *   1. WebAssembly.Memory nesnelerini yakalamak (oyunun "RAM"i)
 *   2. O bellek uzerinde Cheat Engine tarzi tarama / yazma / dondurma
 *   3. Sanal saat ile oyunu hizlandirmak / yavaslatmak / duraklatmak
 *
 * document_start'ta yuklenmesi sart: WebAssembly hook'lari oyun instantiate
 * etmeden once takilmali. Sayfa zaten acikken uzanti kurulduysa bir kez
 * reload gerekir.
 */
(function () {
  'use strict';

  if (window.__WCE__) return;

  /* --------------------------------------------------------------------- *
   * Orijinal referanslar — kendi hook'larimizdan etkilenmemek icin
   * --------------------------------------------------------------------- */
  var O = {
    now: performance.now.bind(performance),
    dateNow: Date.now.bind(Date),
    raf: window.requestAnimationFrame && window.requestAnimationFrame.bind(window),
    caf: window.cancelAnimationFrame && window.cancelAnimationFrame.bind(window),
    setTimeout: window.setTimeout.bind(window),
    clearTimeout: window.clearTimeout.bind(window),
    setInterval: window.setInterval.bind(window),
    clearInterval: window.clearInterval.bind(window)
  };

  /* --------------------------------------------------------------------- *
   * Deger tipleri
   * --------------------------------------------------------------------- */
  var TYPES = {
    i8:  { size: 1, arr: Int8Array,    big: false, get: function (d, o) { return d.getInt8(o); },        set: function (d, o, v) { d.setInt8(o, v); } },
    u8:  { size: 1, arr: Uint8Array,   big: false, get: function (d, o) { return d.getUint8(o); },       set: function (d, o, v) { d.setUint8(o, v); } },
    i16: { size: 2, arr: Int16Array,   big: false, get: function (d, o) { return d.getInt16(o, true); }, set: function (d, o, v) { d.setInt16(o, v, true); } },
    u16: { size: 2, arr: Uint16Array,  big: false, get: function (d, o) { return d.getUint16(o, true); },set: function (d, o, v) { d.setUint16(o, v, true); } },
    i32: { size: 4, arr: Int32Array,   big: false, get: function (d, o) { return d.getInt32(o, true); }, set: function (d, o, v) { d.setInt32(o, v, true); } },
    u32: { size: 4, arr: Uint32Array,  big: false, get: function (d, o) { return d.getUint32(o, true); },set: function (d, o, v) { d.setUint32(o, v, true); } },
    f32: { size: 4, arr: Float32Array, big: false, get: function (d, o) { return d.getFloat32(o, true); },set: function (d, o, v) { d.setFloat32(o, v, true); } },
    f64: { size: 8, arr: Float64Array, big: false, get: function (d, o) { return d.getFloat64(o, true); },set: function (d, o, v) { d.setFloat64(o, v, true); } },
    i64: { size: 8, arr: BigInt64Array,  big: true, get: function (d, o) { return d.getBigInt64(o, true); }, set: function (d, o, v) { d.setBigInt64(o, v, true); } },
    u64: { size: 8, arr: BigUint64Array, big: true, get: function (d, o) { return d.getBigUint64(o, true); },set: function (d, o, v) { d.setBigUint64(o, v, true); } }
  };

  function parseValue(type, raw) {
    var t = TYPES[type];
    if (!t) throw new Error('bilinmeyen tip: ' + type);
    if (t.big) return BigInt(String(raw).trim());
    var n = Number(raw);
    if (!isFinite(n)) throw new Error('gecersiz sayi: ' + raw);
    return n;
  }

  // JSON'a BigInt gonderemiyoruz — string'e ceviriyoruz.
  function outValue(v) { return typeof v === 'bigint' ? v.toString() : v; }

  /* --------------------------------------------------------------------- *
   * Bolgeler (regions) — taranabilir bellek alanlari
   * --------------------------------------------------------------------- */
  var regions = [];
  var regionSeq = 0;
  var OrigMemory = window.WebAssembly && window.WebAssembly.Memory;

  function addWasmMemory(mem, label) {
    if (!OrigMemory || !(mem instanceof OrigMemory)) return;
    for (var i = 0; i < regions.length; i++) if (regions[i].memory === mem) return;
    regions.push({
      id: 'wasm:' + (regionSeq++),
      kind: 'wasm',
      label: label || 'WebAssembly.Memory',
      memory: mem,
      buffer: function () { return mem.buffer; }
    });
  }

  function addBufferRegion(buf, label) {
    if (!(buf instanceof ArrayBuffer)) return;
    for (var i = 0; i < regions.length; i++) if (regions[i].kind === 'buffer' && regions[i].buffer() === buf) return;
    regions.push({
      id: 'buf:' + (regionSeq++),
      kind: 'buffer',
      label: label || 'ArrayBuffer',
      memory: null,
      buffer: function () { return buf; }
    });
  }

  function getRegion(id) {
    for (var i = 0; i < regions.length; i++) if (regions[i].id === id) return regions[i];
    throw new Error('bolge bulunamadi: ' + id);
  }

  /* --------------------------------------------------------------------- *
   * WebAssembly hook'lari
   * --------------------------------------------------------------------- */
  (function hookWasm() {
    var WA = window.WebAssembly;
    if (!WA) return;

    function harvest(result, importObject) {
      try {
        var im = importObject && importObject.env && importObject.env.memory;
        if (im) addWasmMemory(im, 'imports.env.memory');
      } catch (e) { /* import objesi exotic olabilir */ }
      try {
        var inst = result && result.instance ? result.instance : result;
        var ex = inst && inst.exports;
        if (ex) {
          for (var k in ex) {
            try { if (ex[k] instanceof OrigMemory) addWasmMemory(ex[k], 'exports.' + k); } catch (e2) {}
          }
        }
      } catch (e3) {}
    }

    try {
      WA.Memory = new Proxy(OrigMemory, {
        construct: function (target, args) {
          var m = Reflect.construct(target, args);
          addWasmMemory(m, 'new WebAssembly.Memory');
          return m;
        }
      });
    } catch (e) {}

    try {
      var OrigInstance = WA.Instance;
      WA.Instance = new Proxy(OrigInstance, {
        construct: function (target, args) {
          var i = Reflect.construct(target, args);
          harvest(i, args[1]);
          return i;
        }
      });
    } catch (e) {}

    ['instantiate', 'instantiateStreaming'].forEach(function (name) {
      var orig = WA[name];
      if (typeof orig !== 'function') return;
      WA[name] = function () {
        var args = arguments;
        var p = orig.apply(this, args);
        if (p && typeof p.then === 'function') {
          return p.then(function (r) { harvest(r, args[1]); return r; });
        }
        return p;
      };
    });
  })();

  /**
   * Gec kesif: hook'lardan kacan Emscripten/Unity modullerini yakala.
   * (uzanti sayfa yuklendikten sonra kurulduysa bu devreye girer)
   */
  var lastSweep = 0;
  function sweepGlobals() {
    // Her "hello"da global gezmek pahali: sekme listesi tum frame'leri
    // yokluyor ve YouTube gibi sayfalarda binlerce global var.
    var t0 = O.now();
    if (t0 - lastSweep < 1500) return;
    lastSweep = t0;

    var seen = 0;
    var names;
    try { names = Object.getOwnPropertyNames(window); } catch (e) { return; }
    for (var i = 0; i < names.length && seen < 4000; i++) {
      seen++;
      var v;
      try { v = window[names[i]]; } catch (e) { continue; }
      if (!v || typeof v !== 'object') continue;
      try {
        if (v.wasmMemory instanceof OrigMemory) addWasmMemory(v.wasmMemory, names[i] + '.wasmMemory');
        if (v.HEAPU8 && v.HEAPU8.buffer instanceof ArrayBuffer) addBufferRegion(v.HEAPU8.buffer, names[i] + '.HEAPU8');
        if (v.Module) {
          if (v.Module.wasmMemory instanceof OrigMemory) addWasmMemory(v.Module.wasmMemory, names[i] + '.Module.wasmMemory');
          if (v.Module.HEAPU8 && v.Module.HEAPU8.buffer instanceof ArrayBuffer) addBufferRegion(v.Module.HEAPU8.buffer, names[i] + '.Module.HEAPU8');
        }
      } catch (e) { /* getter patlayabilir */ }
    }
  }

  function listRegions() {
    sweepGlobals();
    return regions.map(function (r) {
      var size = 0, shared = false;
      try {
        var b = r.buffer();
        size = b.byteLength;
        shared = typeof SharedArrayBuffer !== 'undefined' && b instanceof SharedArrayBuffer;
      } catch (e) {}
      return { id: r.id, kind: r.kind, label: r.label, size: size, shared: shared };
    });
  }

  /** Sayfada hangi oyun motoru var — teshis icin. */
  function detectEngine() {
    var hits = [];
    var probes = [
      ['Unity', 'unityInstance'], ['Unity', 'UnityLoader'], ['Unity', 'createUnityInstance'],
      ['Emscripten', 'Module'], ['Godot', 'Godot'], ['Godot', 'Engine'],
      ['Cocos', 'cc'], ['Phaser', 'Phaser'], ['PixiJS', 'PIXI'],
      ['Construct', 'C3'], ['Three.js', 'THREE'], ['PlayCanvas', 'pc']
    ];
    for (var i = 0; i < probes.length; i++) {
      try { if (window[probes[i][1]] != null && hits.indexOf(probes[i][0]) < 0) hits.push(probes[i][0]); } catch (e) {}
    }
    return hits;
  }

  /* --------------------------------------------------------------------- *
   * Tarama motoru
   * --------------------------------------------------------------------- */
  var MAX_RESULTS = 4000000;   // ~16 MB offset tablosu
  var SLICE = 4000000;         // tik basina islenecek slot sayisi

  var scan = null;   // aktif tarama state'i
  var job = null;    // calisan tarama isi

  /**
   * "Hepsi" taramasinda denenen tipler — CE'nin "All" deger tipinin karsiligi.
   * u8/u16/u32 bilerek yok: ayni bit deseni zaten i8/i16/i32 ile yakalanir,
   * sadece isaret yorumu degisir. Lane sayisini iki katina cikarmaya degmez.
   */
  var MULTI_TYPES = ['i8', 'i16', 'i32', 'i64', 'f32', 'f64'];

  var INT_RANGE = {
    i8: [-128, 127], u8: [0, 255],
    i16: [-32768, 32767], u16: [0, 65535],
    i32: [-2147483648, 2147483647], u32: [0, 4294967295]
  };

  /** Deger bu tipte temsil edilebilir mi? "Hepsi" modunda bos lane elemek icin. */
  function fitsType(typeName, raw) {
    var s = String(raw == null ? '' : raw).trim();
    if (s === '') return false;
    if (typeName === 'f32' || typeName === 'f64') return isFinite(Number(s));
    if (!/^-?\d+$/.test(s)) return false;           // ondalik sayi tam sayi tipine girmez
    var t = TYPES[typeName];
    if (t.big) {
      try {
        var bv = BigInt(s);
        return typeName === 'u64'
          ? (bv >= BigInt(0) && bv < (BigInt(1) << BigInt(64)))
          : (bv >= -(BigInt(1) << BigInt(63)) && bv < (BigInt(1) << BigInt(63)));
      } catch (e) { return false; }
    }
    var r = INT_RANGE[typeName];
    var n = Number(s);
    return !r || (n >= r[0] && n <= r[1]);
  }

  /**
   * Tarama state'i. Sonuclar "lane"lere bolunur: lane i'nin sonuclari
   * offs[laneEnd[i-1] .. laneEnd[i]) araligindadir ve types[i] tipindedir.
   * Tek tipli taramada tek lane var; "Hepsi"nde tip basina bir lane.
   */
  function freshScan(regionId, types, aligned, multi) {
    return {
      region: regionId,
      types: types,        // lane tip adlari
      multi: !!multi,
      aligned: aligned !== false,
      mode: 'none',        // 'none' | 'all' | 'list'
      offs: null,          // Uint32Array — eslesen byte offsetleri
      laneEnd: [],         // her lane'in offs icindeki bitis indeksi
      count: 0,
      prevNum: null,       // Float64Array — onceki degerler
      prevBig: null,       // tek tipli 64-bit taramada tam hassasiyet
      snap: null,          // 'all' modunda tam bellek kopyasi
      truncated: false
    };
  }

  function typeAt(i) {
    for (var L = 0; L < scan.laneEnd.length; L++) if (i < scan.laneEnd[L]) return scan.types[L];
    return scan.types[scan.types.length - 1];
  }

  function prevAt(i) {
    if (scan.prevBig) return scan.prevBig[i];
    return scan.prevNum ? scan.prevNum[i] : undefined;
  }

  /** BigInt ile Number'i karsilastiramayiz; karisik lane'lerde sayiya indir. */
  function cmpVal(v) { return typeof v === 'bigint' ? Number(v) : v; }

  function storePrev(values, n) {
    var src = values.slice(0, n);
    var single = scan.types.length === 1 ? TYPES[scan.types[0]] : null;
    if (single && single.big) {
      scan.prevBig = scan.types[0] === 'u64' ? BigUint64Array.from(src) : BigInt64Array.from(src);
      scan.prevNum = null;
    } else {
      scan.prevBig = null;
      scan.prevNum = Float64Array.from(src.map(Number));
    }
  }

  // Buyuyebilen Uint32Array
  function Grow() {
    this.buf = new Uint32Array(1 << 16);
    this.n = 0;
  }
  Grow.prototype.push = function (v) {
    if (this.n === this.buf.length) {
      if (this.n >= MAX_RESULTS) return false;
      var next = new Uint32Array(Math.min(this.buf.length * 2, MAX_RESULTS));
      next.set(this.buf);
      this.buf = next;
    }
    this.buf[this.n++] = v;
    return true;
  };
  Grow.prototype.done = function () { return this.buf.subarray(0, this.n); };

  function yieldTick() {
    return new Promise(function (res) { O.setTimeout(res, 0); });
  }

  function makePredicate(op, a, b) {
    switch (op) {
      case 'eq':        return function (c) { return c === a; };
      case 'ne':        return function (c) { return c !== a; };
      case 'gt':        return function (c) { return c > a; };
      case 'lt':        return function (c) { return c < a; };
      case 'gte':       return function (c) { return c >= a; };
      case 'lte':       return function (c) { return c <= a; };
      case 'between':   return function (c) { return c >= a && c <= b; };
      case 'changed':   return function (c, p) { return c !== p; };
      case 'unchanged': return function (c, p) { return c === p; };
      case 'inc':       return function (c, p) { return c > p; };
      case 'dec':       return function (c, p) { return c < p; };
      case 'incBy':     return function (c, p) { return c - p === a; };
      case 'decBy':     return function (c, p) { return p - c === a; };
      default: throw new Error('bilinmeyen karsilastirma: ' + op);
    }
  }

  var NEEDS_PREV = { changed: 1, unchanged: 1, inc: 1, dec: 1, incBy: 1, decBy: 1 };

  function startJob(total) {
    job = { total: total, done: 0, found: 0, running: true, error: null, cancel: false };
    return job;
  }

  function slotCount(byteLen, typeName, aligned) {
    var t = TYPES[typeName];
    var step = aligned ? t.size : 1;
    return Math.max(0, Math.floor((byteLen - t.size) / step) + 1);
  }

  /** Ilk tarama. type='all' ise tum tipler ayri lane olarak taranir. */
  async function firstScan(opts) {
    var region = getRegion(opts.region);
    var aligned = opts.aligned !== false;
    var multi = opts.type === 'all';
    var types = multi ? MULTI_TYPES.slice() : [opts.type];
    for (var ti = 0; ti < types.length; ti++) {
      if (!TYPES[types[ti]]) throw new Error('bilinmeyen tip: ' + types[ti]);
    }

    scan = freshScan(opts.region, types, aligned, multi);
    var byteLen = region.buffer().byteLength;

    // --- Bilinmeyen deger: adres listesi tutmak yerine tam kopya al ---
    if (opts.cmp === 'unknown') {
      var j0 = startJob(byteLen);
      var snap = new Uint8Array(byteLen);
      var CH = 8 << 20;
      for (var off = 0; off < byteLen; off += CH) {
        if (j0.cancel) { j0.running = false; return; }
        // WASM bellegi tarama sirasinda buyurse eski ArrayBuffer detach olur.
        // Sessizce yarim snapshot almaktansa acikca patla.
        var live = region.buffer();
        if (live.byteLength < byteLen) throw new Error('bellek tarama sirasinda yeniden boyutlandi — tekrar tara');
        var end0 = Math.min(off + CH, byteLen);
        snap.set(new Uint8Array(live, off, end0 - off), off);
        j0.done = end0;
        await yieldTick();
      }
      scan.mode = 'all';
      scan.snap = snap;
      scan.count = types.reduce(function (s, tn) { return s + slotCount(byteLen, tn, aligned); }, 0);
      j0.found = scan.count;
      j0.running = false;
      return;
    }

    // --- Degerli ilk tarama ---
    var cmp = opts.cmp || 'eq';
    // Degeri temsil edemeyen tipleri lane listesinden dusur: 300 yazdiysan
    // i8'i taramanin anlami yok, 57.5 yazdiysan tam sayi tiplerinin.
    var lanes = types.filter(function (tn) {
      if (!fitsType(tn, opts.value)) return false;
      if (cmp === 'between' && !fitsType(tn, opts.value2)) return false;
      return true;
    });
    if (!lanes.length) throw new Error('"' + opts.value + '" secili tip(ler)de temsil edilemiyor');
    scan.types = lanes;

    var totalSlots = lanes.reduce(function (s, tn) { return s + slotCount(byteLen, tn, aligned); }, 0);
    var j = startJob(totalSlots);
    var out = new Grow();
    var prev = [];
    var base = 0;

    for (var li = 0; li < lanes.length; li++) {
      if (j.cancel || scan.truncated) { scan.laneEnd.push(out.n); continue; }

      var tn = lanes[li];
      var t = TYPES[tn];
      var a = parseValue(tn, opts.value);
      var b = cmp === 'between' ? parseValue(tn, opts.value2) : null;
      var pred = makePredicate(cmp, a, b);
      var slots = slotCount(byteLen, tn, aligned);

      if (aligned) {
        // Hizli yol: dogrudan typed array uzerinde gez
        var i = 0;
        while (i < slots) {
          if (j.cancel) break;
          var view = new t.arr(region.buffer());
          var end2 = Math.min(i + SLICE, Math.min(slots, view.length));
          for (; i < end2; i++) {
            if (pred(view[i])) {
              if (!out.push(i * t.size)) { scan.truncated = true; break; }
              prev.push(view[i]);
            }
          }
          j.done = base + i;
          j.found = out.n;
          if (scan.truncated) break;
          await yieldTick();
        }
      } else {
        // Hizalanmamis yol: DataView, byte byte
        var k = 0;
        while (k < slots) {
          if (j.cancel) break;
          var dv = new DataView(region.buffer());
          var end3 = Math.min(k + SLICE, slots);
          for (; k < end3; k++) {
            var v2 = t.get(dv, k);
            if (pred(v2)) {
              if (!out.push(k)) { scan.truncated = true; break; }
              prev.push(v2);
            }
          }
          j.done = base + k;
          j.found = out.n;
          if (scan.truncated) break;
          await yieldTick();
        }
      }

      scan.laneEnd.push(out.n);
      base += slots;
    }

    scan.mode = 'list';
    scan.offs = out.done();
    scan.count = out.n;
    storePrev(prev, out.n);
    j.done = j.total;
    j.found = scan.count;
    j.running = false;
  }

  /** Sonraki tarama — mevcut sonuc kumesini daraltir, lane yapisini korur. */
  async function nextScan(opts) {
    if (!scan || scan.mode === 'none') throw new Error('once ilk taramayi yap');
    var region = getRegion(scan.region);
    var cmp = opts.cmp || 'eq';
    var usesPrev = !!NEEDS_PREV[cmp];
    var wantsValue = !usesPrev || cmp === 'incBy' || cmp === 'decBy';
    var hasValue = opts.value != null && opts.value !== '';
    if (wantsValue && !hasValue) throw new Error('bu karsilastirma icin deger gerekli');

    var lanes = scan.types;
    var out = new Grow();
    var prev = [];
    var laneEnd = [];
    var exactPrev = !!scan.prevBig;   // tek tipli 64-bit: BigInt karsilastirmasi

    /** Lane bu degeri temsil edemiyorsa hic taramaya girme. */
    function laneUsable(tn) {
      if (!hasValue) return true;
      if (!wantsValue) return true;
      if (!fitsType(tn, opts.value)) return false;
      if (cmp === 'between' && !fitsType(tn, opts.value2)) return false;
      return true;
    }

    function laneCmp(tn) {
      var a = hasValue && wantsValue ? parseValue(tn, opts.value) : null;
      var b = cmp === 'between' && opts.value2 ? parseValue(tn, opts.value2) : null;
      return makePredicate(cmp, a, b);
    }

    if (scan.mode === 'all') {
      // Snapshot'a karsi tam tarama — sonuc artik seyrek bir liste olur
      var byteLen = region.buffer().byteLength;
      var snapView = new DataView(scan.snap.buffer);
      var totalSlots = lanes.reduce(function (s, tn) { return s + slotCount(byteLen, tn, scan.aligned); }, 0);
      var j = startJob(totalSlots);
      var base = 0;

      for (var li = 0; li < lanes.length; li++) {
        var tn = lanes[li];
        var t = TYPES[tn];
        var slots = slotCount(byteLen, tn, scan.aligned);

        if (j.cancel || scan.truncated || !laneUsable(tn)) {
          laneEnd.push(out.n);
          base += slots;
          continue;
        }

        var pred = laneCmp(tn);
        var step = scan.aligned ? t.size : 1;
        var i = 0;
        while (i < slots) {
          if (j.cancel) break;
          var dv = new DataView(region.buffer());
          var end = Math.min(i + SLICE, slots);
          for (; i < end; i++) {
            var off = i * step;
            if (off + t.size > scan.snap.length || off + t.size > dv.byteLength) continue;
            var cur = t.get(dv, off);
            var old = t.get(snapView, off);
            if (pred(cur, old)) {
              if (!out.push(off)) { scan.truncated = true; break; }
              prev.push(cur);
            }
          }
          j.done = base + i;
          j.found = out.n;
          if (scan.truncated) break;
          await yieldTick();
        }
        laneEnd.push(out.n);
        base += slots;
      }

      scan.snap = null; // artik gerek yok, RAM'i birak
      j.done = j.total;
      j.found = out.n;
      j.running = false;
    } else {
      // Liste modu — sadece mevcut adresleri, kendi lane tipiyle kontrol et
      var j2 = startJob(scan.count);
      var start = 0;

      for (var li2 = 0; li2 < lanes.length; li2++) {
        var tn2 = lanes[li2];
        var t2 = TYPES[tn2];
        var laneStop = scan.laneEnd[li2] != null ? scan.laneEnd[li2] : scan.count;

        if (j2.cancel || !laneUsable(tn2)) {
          j2.done = laneStop;
          laneEnd.push(out.n);
          start = laneStop;
          continue;
        }

        var pred2 = laneCmp(tn2);
        var n = start;
        while (n < laneStop) {
          if (j2.cancel) break;
          var dv2 = new DataView(region.buffer());
          var lim = dv2.byteLength;
          var end2 = Math.min(n + SLICE, laneStop);
          for (; n < end2; n++) {
            var off2 = scan.offs[n];
            if (off2 + t2.size > lim) continue;
            var cur2 = t2.get(dv2, off2);
            var p = usesPrev ? prevAt(n) : undefined;
            // prev sayisal tutuluyorsa BigInt tarafi da sayiya indirilmeli
            var c2 = exactPrev ? cur2 : cmpVal(cur2);
            if (pred2(c2, p)) {
              out.push(off2);
              prev.push(cur2);
            }
          }
          j2.done = n;
          j2.found = out.n;
          await yieldTick();
        }
        laneEnd.push(out.n);
        start = laneStop;
      }

      j2.done = j2.total;
      j2.found = out.n;
      j2.running = false;
    }

    scan.mode = 'list';
    scan.offs = out.done();
    scan.laneEnd = laneEnd;
    scan.count = out.n;
    storePrev(prev, out.n);
  }

  /** Lane basina sonuc sayisi — "hangi tipte kac tane" ozeti icin. */
  function laneCounts() {
    var out = {};
    var start = 0;
    for (var i = 0; i < scan.types.length; i++) {
      var stop = scan.laneEnd[i] != null ? scan.laneEnd[i] : start;
      if (stop > start) out[scan.types[i]] = stop - start;
      start = stop;
    }
    return out;
  }

  function scanResults(offset, limit) {
    if (!scan || scan.mode !== 'list') {
      return {
        total: scan ? scan.count : 0, rows: [], mode: scan ? scan.mode : 'none',
        multi: scan ? scan.multi : false, byType: {}
      };
    }
    var region = getRegion(scan.region);
    var dv = new DataView(region.buffer());
    var rows = [];
    var end = Math.min(offset + limit, scan.count);
    for (var i = offset; i < end; i++) {
      var tn = typeAt(i);
      var t = TYPES[tn];
      var off = scan.offs[i];
      var cur = null;
      try { if (off + t.size <= dv.byteLength) cur = t.get(dv, off); } catch (e) {}
      rows.push({
        addr: off,
        type: tn,
        value: outValue(cur),
        prev: outValue(prevAt(i))
      });
    }
    return {
      total: scan.count, rows: rows, mode: scan.mode, truncated: scan.truncated,
      multi: scan.multi, types: scan.types, byType: laneCounts(), region: scan.region
    };
  }

  /* --------------------------------------------------------------------- *
   * Okuma / yazma / dondurma
   * --------------------------------------------------------------------- */
  function readAddr(regionId, addr, type) {
    var region = getRegion(regionId);
    var t = TYPES[type];
    var dv = new DataView(region.buffer());
    if (addr < 0 || addr + t.size > dv.byteLength) return null;
    return t.get(dv, addr);
  }

  function writeAddr(regionId, addr, type, value) {
    var region = getRegion(regionId);
    var t = TYPES[type];
    var dv = new DataView(region.buffer());
    if (addr < 0 || addr + t.size > dv.byteLength) throw new Error('adres bellek disinda');
    t.set(dv, addr, parseValue(type, value));
    return true;
  }

  // Dondurulan adresler
  var frozen = Object.create(null);
  var freezeSeq = 0;
  var freezeTimer = null;

  function freezeTick() {
    for (var k in frozen) {
      var f = frozen[k];
      try { writeAddr(f.region, f.addr, f.type, f.value); } catch (e) { /* bellek buyumus/kucumus olabilir */ }
    }
  }

  function setFreeze(entry) {
    var id = entry.id || ('f' + (freezeSeq++));
    frozen[id] = { id: id, region: entry.region, addr: entry.addr, type: entry.type, value: entry.value };
    if (!freezeTimer) freezeTimer = O.setInterval(freezeTick, 16);
    return id;
  }

  function clearFreeze(id) {
    delete frozen[id];
    var any = false;
    for (var k in frozen) { any = true; break; }
    if (!any && freezeTimer) { O.clearInterval(freezeTimer); freezeTimer = null; }
    return true;
  }

  /* --------------------------------------------------------------------- *
   * Sanal saat — hizlandirma / yavaslatma / duraklatma
   * --------------------------------------------------------------------- *
   * Oyunlar delta time'i performance.now()/rAF timestamp'inden hesaplar.
   * Sanal saati hizli akitirsak simulasyon da hizlanir. Kod tarafinda
   * "1 kare = 1 kare" kaldigi icin fizik bozulmaz, sadece dt buyur.
   */
  var Clock = {
    speed: 1,
    // Uzanti <all_urls>'e enjekte oluyor. Hiz hic degistirilmediyse saat
    // TAMAMEN pass-through kalir — gezdigin hicbir sayfa etkilenmez.
    dirty: false,
    _rBase: O.now(),
    _vBase: O.now(),
    _dBase: O.dateNow(),
    _at: function (real) { return this._vBase + (real - this._rBase) * this.speed; },
    now: function () { return this.dirty ? this._at(O.now()) : O.now(); },
    dateNow: function () {
      return this.dirty ? this._dBase + (O.now() - this._rBase) * this.speed : O.dateNow();
    },
    setSpeed: function (s) {
      var real = O.now();
      // Ilk sapmada sanal saati o anki gercek zamandan baslat
      var v = this.dirty ? this._at(real) : real;
      var d = this.dirty ? this._dBase + (real - this._rBase) * this.speed : O.dateNow();
      this._vBase = v;
      this._dBase = d;
      this._rBase = real;
      this.speed = Math.max(0, Number(s) || 0);
      if (this.speed !== 1) this.dirty = true;
    },
    step: function (ms) {
      if (!this.dirty) return;
      this._vBase += ms;
      this._dBase += ms;
    }
  };

  /**
   * Teshis sayaclari. "Hiz calismiyor" dedigimizde sebebi bunlar soyler:
   * oyun dongusu bu frame'de mi, saati kimden okuyor, kac fps.
   */
  var stats = { now: 0, dateNow: 0, raf: 0, timeout: 0, interval: 0, rafWindow: [] };

  (function hookClock() {
    try {
      Object.defineProperty(performance, 'now', {
        configurable: true, writable: true,
        value: function now() { stats.now++; return Clock.now(); }
      });
    } catch (e) {}

    try {
      Date.now = function now() { stats.dateNow++; return Math.floor(Clock.dateNow()); };
    } catch (e) {}

    if (O.raf) {
      window.requestAnimationFrame = function (cb) {
        return O.raf(function (ts) {
          stats.raf++;
          var real = O.now();
          stats.rafWindow.push(real);
          while (stats.rafWindow.length && real - stats.rafWindow[0] > 1000) stats.rafWindow.shift();
          cb(Clock.dirty ? Clock.now() : ts);
        });
      };
    }

    // Zamanlayicilari hiza gore olcekle: 2x hizda 1000ms -> 500ms
    function scale(delay) {
      var d = Number(delay) || 0;
      if (!Clock.dirty || Clock.speed <= 0) return d;
      return d / Clock.speed;
    }
    window.setTimeout = function (fn, delay) {
      stats.timeout++;
      var rest = Array.prototype.slice.call(arguments, 2);
      return O.setTimeout.apply(window, [fn, scale(delay)].concat(rest));
    };
    window.setInterval = function (fn, delay) {
      stats.interval++;
      var rest = Array.prototype.slice.call(arguments, 2);
      return O.setInterval.apply(window, [fn, scale(delay)].concat(rest));
    };
  })();

  /* --------------------------------------------------------------------- *
   * RPC
   * --------------------------------------------------------------------- */
  /**
   * Taramayi arka planda baslatir; hata progress() uzerinden geri doner.
   *
   * Onceden .catch icinde "if (job)" vardi: ilk taramada henuz job olmadigi
   * icin (orn. "deger bu tipte temsil edilemiyor") hata hicbir yere yazilmadan
   * kayboluyor, panel sonsuza kadar bos sonuc gosteriyordu. Simdi cagriyla
   * birlikte bir job olusuyor, hata her durumda bir yere dusuyor.
   */
  function launch(fn, args) {
    if (job && job.running) throw new Error('tarama zaten calisiyor');
    job = { total: 0, done: 0, found: 0, running: true, error: null, cancel: false };
    Promise.resolve()
      .then(function () { return fn(args); })
      .catch(function (e) {
        if (!job) job = { total: 0, done: 0, found: 0, running: false, error: null, cancel: false };
        job.error = String(e && e.message || e);
        job.running = false;
      });
    return { started: true };
  }

  var HANDLERS = {
    hello: function () {
      return {
        ok: true,
        url: location.href,
        title: document.title || '',
        top: window.top === window,
        regions: listRegions(),
        speed: Clock.speed
      };
    },
    regions: function () { return listRegions(); },

    firstScan: function (a) { return launch(firstScan, a); },
    nextScan: function (a) { return launch(nextScan, a); },
    cancelScan: function () { if (job) job.cancel = true; return { ok: true }; },
    progress: function () {
      return job
        ? { running: job.running, done: job.done, total: job.total, found: job.found, error: job.error }
        : { running: false, done: 0, total: 0, found: 0, error: null };
    },
    reset: function () { scan = null; job = null; return { ok: true }; },
    results: function (a) { return scanResults(a.offset || 0, Math.min(a.limit || 200, 1000)); },

    read: function (a) { return { value: outValue(readAddr(a.region, a.addr, a.type)) }; },
    readMany: function (a) {
      return (a.items || []).map(function (it) {
        var v = null;
        try { v = readAddr(it.region, it.addr, it.type); } catch (e) {}
        return { key: it.key, value: outValue(v) };
      });
    },
    write: function (a) { return { ok: writeAddr(a.region, a.addr, a.type, a.value) }; },

    freeze: function (a) { return { id: setFreeze(a) }; },
    unfreeze: function (a) { return { ok: clearFreeze(a.id) }; },

    setSpeed: function (a) { Clock.setSpeed(a.speed); return { speed: Clock.speed }; },
    step: function (a) { Clock.step(Number(a.ms) || 16.6667); return { ok: true }; },
    clock: function () { return { speed: Clock.speed, now: Clock.now() }; },

    diag: function () {
      var regs = listRegions();
      return {
        speed: Clock.speed,
        dirty: Clock.dirty,
        fps: stats.rafWindow.length,
        raf: stats.raf,
        nowReads: stats.now,
        dateReads: stats.dateNow,
        timers: stats.timeout + stats.interval,
        engines: detectEngine(),
        regions: regs.length,
        shared: regs.some(function (r) { return r.shared; }),
        crossOriginIsolated: !!window.crossOriginIsolated,
        workers: typeof Worker !== 'undefined'
      };
    }
  };

  function rpc(payloadJson) {
    var req;
    try { req = JSON.parse(payloadJson); } catch (e) { return { error: 'gecersiz istek' }; }
    var h = HANDLERS[req.cmd];
    if (!h) return { error: 'bilinmeyen komut: ' + req.cmd };
    try {
      return { result: h(req.args || {}) };
    } catch (e) {
      return { error: String(e && e.message || e) };
    }
  }

  window.__WCE__ = { rpc: rpc, version: 1 };

  /* --------------------------------------------------------------------- *
   * Bridge (ISOLATED world) ile kopru
   * --------------------------------------------------------------------- */
  window.addEventListener('message', function (ev) {
    if (ev.source !== window) return;
    var d = ev.data;
    if (!d || d.__wce !== 'req') return;
    var res = rpc(d.payload);
    window.postMessage({ __wce: 'res', id: d.id, response: res }, '*');
  });
})();
```

```js
/**
 * Tek bir frame'e RPC gonder.
 *
 * timeoutMs sart: askiya alinmis / donmus / servis worker'i olmeyen sekmelerde
 * sendMessage ne yanit doner ne de lastError set eder — sonsuza kadar asili
 * kalir. Tek bir bozuk sekme butun sekme listesini kilitliyordu.
 */
function rpc(tabId, frameId, payload, timeoutMs = 0) {
  return new Promise((resolve) => {
    let settled = false;
    const done = (v) => { if (!settled) { settled = true; resolve(v); } };

    if (timeoutMs > 0) setTimeout(() => done({ error: 'zaman asimi' }), timeoutMs);

    try {
      chrome.tabs.sendMessage(tabId, { __wce: 'rpc', payload }, { frameId }, (res) => {
        if (chrome.runtime.lastError) done({ error: chrome.runtime.lastError.message });
        else done(res || { error: 'bos yanit' });
      });
    } catch (e) {
      done({ error: String(e && e.message || e) });
    }
  });
}

const PROBE_TIMEOUT = 1500;

/**
 * Taranabilir hedefleri listele.
 *
 * Agent'i OLMAYAN sekmeleri de listeye koyuyoruz. Sebep: kullanicinin oyun
 * sekmesi cogu zaman uzanti kurulmadan/yenilenmeden once acilmis oluyor, o
 * sekmede content script yok. Onceden bu sekmeler listeden tamamen dusuyor ve
 * "sekmeyi bulamiyor" gibi gorunuyordu. Simdi gorunuyorlar, "agent yok"
 * isaretiyle — panel de yanina "Sekmeyi Yenile" diyor.
 */
async function listTargets() {
  const tabs = await chrome.tabs.query({});

  const results = await Promise.all(tabs.map(async (tab) => {
    if (!tab.id || !tab.url || !/^https?:/.test(tab.url)) return null;

    const base = {
      tabId: tab.id,
      title: tab.title || tab.url,
      url: tab.url,
      discarded: !!tab.discarded,
      frames: [],
      hasAgent: false,
      hasMemory: false
    };

    // Uykuya alinmis sekmeyi uyandirmayalim — listede "askida" olarak gecsin
    if (tab.discarded) return base;

    let frames = [];
    try {
      frames = (await chrome.webNavigation.getAllFrames({ tabId: tab.id })) || [];
    } catch (e) {
      frames = [{ frameId: 0, url: tab.url }];
    }

    const live = (await Promise.all(frames.map(async (fr) => {
      const res = await rpc(tab.id, fr.frameId, { cmd: 'hello' }, PROBE_TIMEOUT);
      if (!res || res.error || !res.result) return null;
      return {
        frameId: fr.frameId,
        url: res.result.url || fr.url,
        top: !!res.result.top,
        regions: res.result.regions || [],
        speed: res.result.speed
      };
    }))).filter(Boolean);

    live.sort((a, b) => (b.regions.length - a.regions.length) || (a.frameId - b.frameId));
    base.frames = live;
    base.hasAgent = live.length > 0;
    base.hasMemory = live.some((f) => f.regions.length > 0);
    return base;
  }));

  const out = results.filter(Boolean);
  // WASM'li sekmeler once, sonra agent'i olanlar, en sona olmayanlar
  out.sort((a, b) =>
    (b.hasMemory - a.hasMemory) ||
    (b.hasAgent - a.hasAgent) ||
    (a.tabId - b.tabId)
  );
  return out;
}

chrome.runtime.onMessage.addListener((msg, sender, sendResponse) => {
  if (!msg || msg.__wcePanel !== true) return;

  (async () => {
    try {
      switch (msg.op) {
        case 'listTargets':
          sendResponse({ result: await listTargets() });
          break;
        case 'rpc':
          // Panel hicbir zaman sonsuza kadar beklemesin
          sendResponse(await rpc(msg.tabId, msg.frameId, msg.payload, 20000));
          break;
        case 'reload':
          await chrome.tabs.reload(msg.tabId);
          sendResponse({ result: { ok: true } });
          break;
        default:
          sendResponse({ error: 'bilinmeyen op: ' + msg.op });
      }
    } catch (e) {
      sendResponse({ error: String(e && e.message || e) });
    }
  })();

  return true; // async
});
```

```js
/**
 * WebCheat bridge — ISOLATED world.
 *
 * MAIN world'deki agent chrome.* API'lerine erisemez, uzanti sayfasi da
 * sayfanin JS realm'ine giremez. Bu dosya ikisini birbirine baglar:
 *
 *   panel --(chrome.runtime)--> service worker --(tabs.sendMessage)--> bridge
 *   bridge --(window.postMessage)--> agent --(window.postMessage)--> bridge
 */
(function () {
  'use strict';

  var pending = Object.create(null);
  var seq = 0;

  window.addEventListener('message', function (ev) {
    if (ev.source !== window) return;
    var d = ev.data;
    if (!d || d.__wce !== 'res') return;
    var p = pending[d.id];
    if (!p) return;
    delete pending[d.id];
    clearTimeout(p.timer);
    p.resolve(d.response);
  });

  function callAgent(payload) {
    return new Promise(function (resolve) {
      var id = ++seq;
      pending[id] = {
        resolve: resolve,
        timer: setTimeout(function () {
          delete pending[id];
          resolve({ error: 'agent yanit vermedi (sayfayi yenile)' });
        }, 15000)
      };
      window.postMessage({ __wce: 'req', id: id, payload: JSON.stringify(payload) }, '*');
    });
  }

  chrome.runtime.onMessage.addListener(function (msg, sender, sendResponse) {
    if (!msg || msg.__wce !== 'rpc') return;
    callAgent(msg.payload).then(sendResponse);
    return true; // async yanit
  });
})();
```

```js
/**
 * WebCheat panel — CE penceresi.
 * Hedef sekmeyi/frame'i secer, agent'a RPC atar, sonuclari gosterir.
 */
'use strict';

const $ = (id) => document.getElementById(id);

/* ------------------------------------------------------------------ *
 * Durum
 * ------------------------------------------------------------------ */
const state = {
  targets: [],
  tabId: null,
  frameId: null,
  regionId: null,
  scanning: false,
  hasResults: false,
  speed: 1,
  prevSpeed: 1,
  regionPoll: null,
  list: [],        // adres listesi: {key, desc, region, addr, type, value, frozen, freezeId}
  keySeq: 0
};

const FIRST_CMPS = [
  ['eq', 'Tam deger'],
  ['unknown', 'Bilinmeyen baslangic degeri'],
  ['gt', 'Buyuktur'],
  ['lt', 'Kucuktur'],
  ['between', 'Arasinda']
];

const NEXT_CMPS = [
  ['eq', 'Tam deger'],
  ['changed', 'Degisti'],
  ['unchanged', 'Degismedi'],
  ['inc', 'Artti'],
  ['dec', 'Azaldi'],
  ['incBy', 'Su kadar artti'],
  ['decBy', 'Su kadar azaldi'],
  ['gt', 'Buyuktur'],
  ['lt', 'Kucuktur'],
  ['between', 'Arasinda']
];

const NO_VALUE = new Set(['unknown', 'changed', 'unchanged', 'inc', 'dec']);

/* ------------------------------------------------------------------ *
 * Mesajlasma
 * ------------------------------------------------------------------ */
function bg(msg) {
  return new Promise((resolve) => {
    chrome.runtime.sendMessage({ __wcePanel: true, ...msg }, (res) => {
      if (chrome.runtime.lastError) resolve({ error: chrome.runtime.lastError.message });
      else resolve(res || { error: 'bos yanit' });
    });
  });
}

async function rpc(cmd, args = {}) {
  if (state.tabId === null || state.frameId === null) return { error: 'hedef secilmedi' };
  return bg({ op: 'rpc', tabId: state.tabId, frameId: state.frameId, payload: { cmd, args } });
}

/** Secili frame'i degil, belirtilen frame'i sorgular. */
async function rpcFrame(frameId, cmd, args = {}) {
  if (state.tabId === null) return { error: 'sekme secilmedi' };
  return bg({ op: 'rpc', tabId: state.tabId, frameId, payload: { cmd, args } });
}

function toast(msg, ms = 3200) {
  const t = $('toast');
  t.textContent = msg;
  t.classList.remove('hidden');
  clearTimeout(toast._t);
  toast._t = setTimeout(() => t.classList.add('hidden'), ms);
}

function setStatus(text, cls) {
  $('statusText').textContent = text;
  const dot = $('dot');
  dot.className = 'dot' + (cls ? ' ' + cls : '');
}

/* ------------------------------------------------------------------ *
 * Hedef secimi
 * ------------------------------------------------------------------ */
async function refreshTargets() {
  setStatus('sekmeler taraniyor...', 'busy');
  const res = await bg({ op: 'listTargets' });
  if (res.error) { setStatus('hata: ' + res.error); return; }

  state.targets = res.result || [];
  const tabSel = $('tabSel');
  const keepTab = state.tabId;
  tabSel.textContent = '';

  if (!state.targets.length) {
    tabSel.append(new Option('— agent yuklu sekme yok —', ''));
    $('frameSel').textContent = '';
    setStatus('sekme bulunamadi');
    toast('Oyunun sekmesini bir kez yenile (uzanti kurulmadan once acilmis sayfalarda agent yok).', 6000);
    return;
  }

  for (const t of state.targets) {
    const mark = t.hasMemory ? '[WASM] '
      : t.discarded ? '[askida] '
      : t.hasAgent ? ''
      : '[agent yok] ';
    const label = mark + (t.title.length > 54 ? t.title.slice(0, 54) + '…' : t.title);
    tabSel.append(new Option(label, String(t.tabId)));
  }

  const found = state.targets.find((t) => t.tabId === keepTab);
  const pick = found || state.targets[0];
  tabSel.value = String(pick.tabId);
  selectTab(pick.tabId);
}

function selectTab(tabId) {
  state.tabId = tabId;
  clearTimeout(state.regionPoll);
  const tab = state.targets.find((t) => t.tabId === tabId);
  const frameSel = $('frameSel');
  const regionSel = $('regionSel');
  frameSel.textContent = '';
  if (!tab) return;

  // Agent yok: content script bu sekmeye hic enjekte olmamis (sekme uzanti
  // kurulmadan/yenilenmeden once acilmis). Kullaniciya ne yapacagini soyle.
  if (!tab.frames.length) {
    state.frameId = null;
    state.regionId = null;
    frameSel.append(new Option(tab.discarded ? '— sekme askida —' : '— agent yok —', ''));
    regionSel.textContent = '';
    regionSel.append(new Option('— agent yok —', ''));
    setStatus(tab.discarded ? 'sekme askida' : 'agent yok', '');
    toast(tab.discarded
      ? 'Bu sekme Chrome tarafindan uykuya alinmis. Sekmeye bir gecip geri gel, sonra Yenile.'
      : 'Bu sekmede agent yok. "Sekmeyi Yenile"ye bas — hook\'lar oyun yuklenmeden once takilmali.', 6000);
    return;
  }

  for (const f of tab.frames) {
    const n = f.regions.length;
    const where = f.top ? 'ana sayfa' : 'iframe #' + f.frameId;
    const url = f.url.length > 52 ? f.url.slice(0, 52) + '…' : f.url;
    frameSel.append(new Option(`${where} — ${url}${n ? `  (${n} bellek)` : ''}`, String(f.frameId)));
  }

  const best = tab.frames[0];
  frameSel.value = String(best.frameId);
  selectFrame(best.frameId);
}

/**
 * Frame secildiginde bolgeleri CANLI sorar — listTargets sirasindaki
 * onbellege guvenmez. Oyun WASM'ini gec olusturdugunda (Playables'ta
 * normal) onbellek "bellek yok" der ve panel bir daha kendine gelmez.
 */
async function selectFrame(frameId) {
  state.frameId = frameId;
  state.regionId = null;
  clearTimeout(state.regionPoll);

  const regionSel = $('regionSel');
  regionSel.textContent = '';
  regionSel.append(new Option('— sorgulaniyor… —', ''));
  setStatus('bellek araniyor…', 'busy');

  await pollRegions(0);
}

/** Bellek cikana kadar birkac saniye yeniden dener (oyun yukleniyor olabilir). */
async function pollRegions(attempt) {
  const askedFrame = state.frameId;
  const res = await rpc('regions');
  if (state.frameId !== askedFrame) return;   // kullanici arada frame degistirdi

  const regionSel = $('regionSel');
  const regions = (!res.error && res.result) || [];

  if (!regions.length) {
    regionSel.textContent = '';
    regionSel.append(new Option('— bellek bulunamadi —', ''));
    state.regionId = null;
    // 3 denemede cikmadiysa: diger frame'leri canli yokla, WASM'i olana atla.
    // Playables'ta oyun ic iframe'de calisiyor; kullaniciyi elle aratmayalim.
    if (attempt === 3) {
      const better = await findFrameWithMemory();
      if (better !== null && better !== state.frameId) {
        $('frameSel').value = String(better);
        toast('Oyun ' + (better === 0 ? 'ana sayfada' : 'iframe #' + better + '\'de') + ' bulundu, oraya gecildi.', 3500);
        selectFrame(better);
        return;
      }
    }

    if (attempt < 20) {
      setStatus(`bellek araniyor… (${attempt + 1})`, 'busy');
      state.regionPoll = setTimeout(() => pollRegions(attempt + 1), 1000);
    } else {
      setStatus('bellek yok', '');
      toast('Bu frame\'de WASM bellegi yok. Oyun saf JS olabilir ya da baska bir iframe\'de.', 5000);
    }
    return;
  }

  const keep = state.regionId;
  regionSel.textContent = '';
  for (const r of regions) {
    const tag = r.shared ? ' [paylasimli]' : '';
    regionSel.append(new Option(`${r.label} — ${fmtBytes(r.size)}${tag}`, r.id));
  }
  regionSel.value = regions.some((r) => r.id === keep) ? keep : regions[0].id;
  state.regionId = regionSel.value;
  setStatus(`bagli — ${regions.length} bellek`, 'on');

  if (regions.some((r) => r.shared)) {
    toast('Bellek paylasimli (pthread). Oyun dongusu bir Worker\'da calisiyor olabilir — ' +
          'tarama calisir ama zaman kontrolu etkisiz kalabilir.', 7000);
  }
}

/** Sekmenin tum frame'lerini canli yoklar, WASM bellegi olan ilkini doner. */
async function findFrameWithMemory() {
  const tab = state.targets.find((t) => t.tabId === state.tabId);
  if (!tab) return null;

  const probes = await Promise.all(tab.frames.map(async (f) => {
    const res = await rpcFrame(f.frameId, 'regions');
    const n = (!res.error && res.result) ? res.result.length : 0;
    return { frameId: f.frameId, n };
  }));

  const hit = probes.filter((p) => p.n > 0).sort((a, b) => b.n - a.n)[0];
  return hit ? hit.frameId : null;
}

function fmtBytes(n) {
  if (!n) return '0 B';
  const u = ['B', 'KB', 'MB', 'GB'];
  const i = Math.min(Math.floor(Math.log(n) / Math.log(1024)), u.length - 1);
  return (n / Math.pow(1024, i)).toFixed(i ? 1 : 0) + ' ' + u[i];
}

/* ------------------------------------------------------------------ *
 * Tarama
 * ------------------------------------------------------------------ */
function fillCmp(list) {
  const sel = $('cmpSel');
  const keep = sel.value;
  sel.textContent = '';
  for (const [v, label] of list) sel.append(new Option(label, v));
  if (list.some(([v]) => v === keep)) sel.value = keep;
  onCmpChange();
}

function onCmpChange() {
  const cmp = $('cmpSel').value;
  $('valInput').disabled = NO_VALUE.has(cmp);
  $('val2Wrap').classList.toggle('hidden', cmp !== 'between');
}

async function doScan(kind) {
  if (!state.regionId) { toast('Once taranacak bir bellek sec.'); return; }
  const cmp = $('cmpSel').value;
  const args = {
    region: state.regionId,
    type: $('typeSel').value,
    aligned: $('alignedChk').checked,
    cmp,
    value: $('valInput').value,
    value2: $('val2Input').value
  };

  if (!NO_VALUE.has(cmp) && args.value.trim() === '') { toast('Deger gir.'); return; }

  const res = await rpc(kind, args);
  if (res.error) { toast('Hata: ' + res.error); return; }

  state.scanning = true;
  setScanUI(true);
  pollProgress();
}

function setScanUI(busy) {
  $('firstBtn').disabled = busy;
  $('nextBtn').disabled = busy || !state.hasResults;
  $('newBtn').disabled = busy;
  $('cancelBtn').classList.toggle('hidden', !busy);
  setStatus(busy ? 'taraniyor...' : 'bagli', busy ? 'busy' : 'on');
}

async function pollProgress() {
  const res = await rpc('progress');
  if (res.error) { state.scanning = false; setScanUI(false); toast('Hata: ' + res.error); return; }
  const p = res.result;

  const pct = p.total ? Math.min(100, (p.done / p.total) * 100) : 0;
  $('progBar').style.width = pct + '%';
  $('foundText').innerHTML = `Bulunan: <b>${p.found.toLocaleString('tr-TR')}</b>` +
    (p.running ? ` — %${pct.toFixed(0)}` : '');

  if (p.error) {
    state.scanning = false;
    setScanUI(false);
    toast('Tarama hatasi: ' + p.error);
    return;
  }

  if (p.running) { setTimeout(pollProgress, 150); return; }

  state.scanning = false;
  $('progBar').style.width = '100%';
  await loadResults();
  setScanUI(false);
}

async function loadResults() {
  const res = await rpc('results', { offset: 0, limit: 300 });
  if (res.error) { toast('Hata: ' + res.error); return; }
  const r = res.result;

  state.hasResults = r.total > 0 || r.mode === 'all';
  $('nextBtn').disabled = !state.hasResults;
  fillCmp(state.hasResults ? NEXT_CMPS : FIRST_CMPS);

  const body = $('resBody');
  body.textContent = '';

async function toggleFreeze(e, on) {
  if (on) {
    const res = await rpc('freeze', { id: e.freezeId, region: e.region, addr: e.addr, type: e.type, value: e.value });
    if (res.error) { toast('Dondurulamadi: ' + res.error); return; }
    e.freezeId = res.result.id;
    e.frozen = true;
  } else {
    if (e.freezeId) await rpc('unfreeze', { id: e.freezeId });
    e.frozen = false;
    e.freezeId = null;
  }
}

async function refreshListValues() {
  if (!state.list.length || state.tabId === null) return;
  const items = state.list
    .filter((e) => !e.frozen)
    .map((e) => ({ key: e.key, region: e.region, addr: e.addr, type: e.type }));
  if (!items.length) return;

  const res = await rpc('readMany', { items });
  if (res.error || !res.result) return;

  const focused = document.activeElement;
  for (const row of res.result) {
    if (row.value == null) continue;
    const e = state.list.find((o) => o.key === row.key);
    if (!e) continue;
    e.value = String(row.value);
    const input = document.querySelector(`#listBody input[data-key="${row.key}"]`);
    if (input && input !== focused) input.value = e.value;
  }
}
```
