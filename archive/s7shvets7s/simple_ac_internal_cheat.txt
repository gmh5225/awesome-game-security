## About the Project

**Simple AssaultCube Internal Cheat** is an educational internal modification for the open-source game **AssaultCube**.

The project was created to explore low-level C++ development and fundamental reverse-engineering concepts in a controlled environment. It demonstrates interaction with a running process, runtime memory structures, multi-level pointers, function hooking, DirectX rendering integration, and the development of an in-process graphical interface.

The application is implemented as an **x86 dynamic-link library** loaded into the local AssaultCube process. Once loaded, it provides an interactive overlay built with **Dear ImGui**.

> [!IMPORTANT]
> This repository is intended for studying C++, Windows internals and reverse engineering in a locally controlled, offline environment. It is not intended for competitive or multiplayer use.

## ✨ Features

### Aimbot

* Configurable target selection
* Adjustable aiming behaviour
* Runtime activation and deactivation through the overlay
* Interaction with player and entity data stored in game memory

### ESP

* Displays information about game entities
* Demonstrates world-to-screen coordinate conversion
* Uses the game entity list and rendering data
* Integrated with the internal overlay

### Player Parameters

The project provides experimental controls for modifying locally stored player values, including:

* Health
* Armor
* Ammunition
* Field of view
* Other runtime parameters

### ImGui Overlay

* Interactive in-process menu
* Feature toggles and configuration controls
* Tab-based interface
* Runtime settings management
* Menu visibility controlled with the `Delete` key

## 🔬 How It Works

At a high level, the project follows this lifecycle:

1. The DLL is loaded into a locally running AssaultCube process.
2. `DllMain` starts the project initialization routine.
3. Required game modules and runtime addresses are resolved.
4. Rendering functions are hooked using Microsoft Detours.
5. Dear ImGui is initialized inside the game rendering context.
6. Feature modules read or modify local runtime data.
7. The overlay exposes feature configuration and status controls.
8. The `Delete` key toggles the menu.

The exact offsets are version-dependent. Updating the game may require updating values stored in the `offsets` module.

## 🚀 Building the Project

### Requirements

* Windows
* Visual Studio 2022
* Desktop development with C++ workload
* ISO C++20 support
* x86 build tools
* Dear ImGui source files
* Microsoft Detours
* vcpkg
* A locally controlled AssaultCube installation

### 1. Clone the repository

```bash
git clone https://github.com/s7shvets7s/simple_ac_internal_cheat.git
cd simple_ac_internal_cheat
```

### 2. Add Dear ImGui

Create the following directory in the project root:

```text
external/imgui/
```

Add the required Dear ImGui header and source files to that directory and include them in the Visual Studio project.

Expected structure:

```text
external/
└── imgui/
    ├── imgui.cpp
    ├── imgui.h
    ├── imgui_draw.cpp
    ├── imgui_tables.cpp
    ├── imgui_widgets.cpp
    └── required backend files
```

### 3. Install Detours

Install Microsoft Detours through vcpkg and connect the vcpkg installation to Visual Studio.

```bash
vcpkg install detours:x86-windows
vcpkg integrate install
```

### 4. Configure Visual Studio

1. Open `simple_ac_internal_cheat.sln`.
2. Select the `Release` configuration.
3. Select the `x86` platform.
4. Set the language standard to **ISO C++20 (`/std:c++20`)**.
5. Verify the ImGui and Detours include paths.
6. Build the solution.

```text
Build → Build Solution
```

The resulting DLL will be generated in the configured Visual Studio output directory.

## 🧪 Local Testing

Use the project only with a locally controlled AssaultCube installation and preferably in an offline game with bots.

For a controlled local demonstration:

1. Build the project using the `Release | x86` configuration.
2. Start the compatible AssaultCube version.
3. Load the compiled DLL into the local `ac_client.exe` process using an appropriate development or debugging loader.
4. Press `Delete` to open or close the overlay.
5. Enable the required experimental features through the menu.

> [!WARNING]
> Do not use this project in public multiplayer matches or against other players. Game modifications may violate server rules or the game's terms of service.

## ⚠️ Limitations

* The project targets a specific x86 version of AssaultCube.
* Memory addresses and offsets may stop working after a game update.
* The implementation is an educational prototype rather than production-quality software.
* Some feature logic may require additional validation and refactoring.
* The project does not include an automatic offset scanner.
* Compatibility with other games or architectures is not supported.
* No attempt is made to bypass anti-cheat systems.

void aim::aimbot()
{	
	if (Settings::Aimbot::drawFovCircle and Settings::Aimbot::checkInFov)
		ImGui::GetBackgroundDrawList()->AddCircle(ImVec2(centerScreenPos.x, centerScreenPos.y),
			Settings::Aimbot::fov, IM_COL32(255, 255, 255, 128), 100);
	if (!(GetAsyncKeyState(VK_SHIFT) & 0x8000) or !Settings::Aimbot::enabled) {
		curAimTime = 0;
		lastAimTime = clock();
		curTarget = nullptr;
		return;
	}
		
	


	
	Player* target = getNearestEntityWS2();
	if (!target)
		return;
	if (target!=curTarget) {
		curAimTime = 0;
		lastAimTime = clock();
		curTarget = target;
	}
	clock_t now = clock();
	curAimTime += static_cast<float>(now - lastAimTime) / CLOCKS_PER_SEC;
	lastAimTime = now;
	float percent = min(curAimTime / Settings::Aimbot::smoothingAmount, 1.0);

	Vec3 targetAngle = CalcAngle(localPlayerPtr->pos, target->pos);
	targetAngle.x += 90;
	vec3 currentAngle = { localPlayerPtr->yaw,localPlayerPtr->pitch,0 };
	if (Settings::Aimbot::smoothing) {
		if (percent >= 1) {
			curAimTime = 0;
			percent = 1;
		}
		smoothAngel(currentAngle, targetAngle, percent);
		std::cout << "smooth" << std::endl;
	}
	else {
		currentAngle = targetAngle;

	}
	localPlayerPtr->yaw = currentAngle.x;
	localPlayerPtr->pitch = currentAngle.y;
}

void ESP::drawESP()
{	
	if (!Settings::ESP::enabled)
		return;
	bool teammate = false;
	Player* player = nullptr;
	for (int i = 1; i < numPlayers; i++) {
		player = players->players[i];
		if (player->health > 100 or player->health < 0)
			continue;
		teammate = player->team == localPlayerPtr->team;
		if (teammate and !Settings::ESP::drawTeam)
			continue;
		vec3 headPos = { player->o.x,player->o.y,player->o.z };
		vec3 feetPos = { player->o.x,player->o.y,player->o.z- player->eyeHeight };
		vec3 headScreenPose = OpenGLWorldToScreen(headPos);
		vec3 feetScreenPose = OpenGLWorldToScreen(feetPos);
		

		float height = abs(headScreenPose.y - feetScreenPose.y);
		float width = height / 2;
		ImVec2 topLeft = ImVec2(feetScreenPose.x - width, headScreenPose.y);
		ImVec2 topRight= ImVec2(feetScreenPose.x + width, headScreenPose.y);
		ImVec2 bottomLeft = ImVec2(feetScreenPose.x - width, feetScreenPose.y);
		ImVec2 bottomRight = ImVec2(feetScreenPose.x + width, feetScreenPose.y);

		ImColor currColor = teammate ? *Settings::ESP::enemyColor : *Settings::ESP::mateColor;

		ImGui::GetBackgroundDrawList()->AddQuad(topLeft, bottomLeft, bottomRight, topRight, currColor, 1.0f);
	
		//drawScallingBar(bottomLeft.x - 5, -width / 2, bottomLeft.y, bottomLeft.x - 5, topRight.y, 1,100, ImColor(255,0,0,255));
		drawScalingBarVertical(bottomLeft.x - 5 - width / 2, bottomLeft.y, bottomLeft.x - 5, topRight.y, 1, ImVec4(0, 1, 0, 1), player->health, 100);
		drawCenterText(player->name, feetScreenPose.x, feetScreenPose.y);
	}

}

// Calculates clip coordinates based on OpenGL's model-view-projection matrix and converts them to screen space
bool OpenGLWorldToScreen(vec3 pos, vec3& screen, const float matrix[16], int windowWidth, int windowHeight)
{
    Vec4 clipCoords;

    clipCoords.x = pos.x * matrix[0] + pos.y * matrix[4] + pos.z * matrix[8] + matrix[12];
    clipCoords.y = pos.x * matrix[1] + pos.y * matrix[5] + pos.z * matrix[9] + matrix[13];
    clipCoords.z = pos.x * matrix[2] + pos.y * matrix[6] + pos.z * matrix[10] + matrix[14];
    clipCoords.w = pos.x * matrix[3] + pos.y * matrix[7] + pos.z * matrix[11] + matrix[15];

    if (clipCoords.w < 0.1f) {
        return false;
    }

    vec3 NDC{ clipCoords.x / clipCoords.w, clipCoords.y / clipCoords.w, clipCoords.z / clipCoords.w };

    screen.x = (windowWidth / 2.0f) * (NDC.x + 1.0f);
    screen.y = (windowHeight / 2.0f) * (1.0f - NDC.y); // Y is inverted in screen space

    return true;
}

// Similar function for DirectX with column-major matrices
bool DirectXWorldToScreen(vec3 pos, vec3& screen, const float matrix[16], int windowWidth, int windowHeight)
{
    Vec4 clipCoords;

    clipCoords.x = pos.x * matrix[0] + pos.y * matrix[1] + pos.z * matrix[2] + matrix[3];
    clipCoords.y = pos.x * matrix[4] + pos.y * matrix[5] + pos.z * matrix[6] + matrix[7];
    clipCoords.z = pos.x * matrix[8] + pos.y * matrix[9] + pos.z * matrix[10] + matrix[11];
    clipCoords.w = pos.x * matrix[12] + pos.y * matrix[13] + pos.z * matrix[14] + matrix[15];

    if (clipCoords.w < 0.1f) {
        return false;
    }

    vec3 NDC{ clipCoords.x / clipCoords.w, clipCoords.y / clipCoords.w, clipCoords.z / clipCoords.w };

    screen.x = (windowWidth / 2.0f) * (NDC.x + 1.0f);
    screen.y = (windowHeight / 2.0f) * (1.0f - NDC.y);

    return true;
}

// Gets the angle of a ray from origin to target // InvertPitch means looking up leads to negative pitch
Vec3 CalcAngle(const Vec3& origin, const Vec3& target, bool invertYaw, bool invertPitch)
{
    Vec3 results{ 0.0f, 0.0f, 0.0f };
    Vec3 delta = target - origin; // Get the difference between the two vectors

    float distance = origin.Distance(target);
    if (distance == 0.0f) // Prevent division by zero
        return results;

    float yawSign = invertYaw ? -1.0f : 1.0f;
    float pitchSign = invertPitch ? -1.0f : 1.0f;

    results.x = yawSign * RadiansToDegrees(atan2f(delta.y, delta.x));
    results.y = pitchSign * RadiansToDegrees(asinf((delta.z) / distance));
    return results;
}

Vec3 DegreesToRadians(const Vec3& vec)
{
    return Vec3{ DegreesToRadians(vec.x), DegreesToRadians(vec.y), DegreesToRadians(vec.z) };
}

}

}

void Vector3::NormalizeAngle(float yawMin, float yawMax, float pitchMin, float pitchMax)
{
    // Wrap yaw (x) to [yawMin, yawMax] (e.g., [-180, 180])
    while (x > yawMax)
        x -= (yawMax - yawMin);
    while (x < yawMin)
        x += (yawMax - yawMin);

    // Wrap pitch (y) to [pitchMin, pitchMax] (e.g., [-89, 89])
    while (y > pitchMax)
        y -= (pitchMax - pitchMin);
    while (y < pitchMin)
        y += (pitchMax - pitchMin);
}

std::string Vector3::ToString()
{
    return std::format("{} {} {}", x, y, z);
}
