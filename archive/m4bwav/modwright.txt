```md
# Learnings

- L-001 `strong-baseline` (2026-11-21): on fake installs the bare model already stops at anti-cheat, reads BepInEx logs and recommends UE4SS. The skill's gain is routing and repeatability: a hash manifest with `restore --verify` instead of an ad hoc sha256sum file, a stale-log check, and exit codes a calling agent can act on.
- L-002 `proof-skips-decompile-hint` (2026-11-21): with the skill, the errored-mod eval reported the MissingMethodException but did not suggest decompiling to find the new signature. Candidate edit for step 7 if it repeats.
- L-003 `check-the-loader-is-live` (2026-11-21): a game can ship a mod folder, a mod menu and a whole C# modding API while loading nothing. People Playground build 26411268 (1.28) registers only `LuaModLoader`, an `EmptyModLoader` stub, so its Mods page says "No mods found" for a valid C# mod. Before writing a mod, decompile (`ilspycmd -p`) and grep for where loaders are registered (`AddLoader(`), not just for the API.
- L-004 `saves-can-disable-behaviour` (2026-11-21): deserialisation hooks can switch a part off for good. People Playground's `TeslaCoilBehaviour.OnAfterDeserialise` sets `unfit = true`, and copy/paste, flip-paste, drag-duplicate and contraption spawns all go through `ObjectStateConverter`, so a saved or pasted Tesla Coil never opens the portal. Grep `OnAfterDeserialise` for the parts a contraption depends on before promising a Workshop contraption works.
```

`README.md`:

```md
# modwright

![modwright banner](.github/images/banner.jpg)

Mod any PC game safely and prove the mod works. A Claude Code plugin with one skill and a standard-library script.

- Finds the engine and runtime (Unity Mono or IL2CPP, Unreal, Godot, GameMaker, Source and more) and the loader to use.
- Stops at anti-cheat (EAC, BattlEye, Vanguard...): no injection, no memory patching, no online cheats.
- Backs up saves and every file it will touch with SHA-256 hashes, and restores or verifies them later.
- Decompiles before naming a patch target, never guesses a method name.
- Proves a mod loaded from the loader log (BepInEx, MelonLoader, UE4SS, UMM), and flags errors and stale logs.
- Prepares a Steam Workshop VDF or Thunderstore manifest without uploading.

Not for Minecraft (minewright), Roblox (roblox-agent) or MADNESS Project Nexus (madnesswright).

## Install

In Claude Code:

```
/plugin marketplace add m4bwav/modwright
/plugin install modwright@modwright
```

Or copy `skills/modwright` into your own plugin. Needs Python 3.9+ (standard library only).

## Use

Ask in plain words: "mod this game", "which mod loader should I use", "back up my saves before modding", "did my mod load", "upload my mod to the Workshop". The script runs on its own too. Every command prints JSON except `scan`, which prints `key: value` lines unless given `--json`; exit codes are 0 ok, 1 check failed, 2 anti-cheat (stop), 3 bad input.

```
python skills/modwright/scripts/mw.py scan "C:/Games/MyGame" [--json]
python skills/modwright/scripts/mw.py backup backups/1 "C:/Users/me/AppData/LocalLow/Co/Game" --build 123456
python skills/modwright/scripts/mw.py restore backups/1 --verify
python skills/modwright/scripts/mw.py proof "C:/Games/MyGame" --mod CoolMod [--log path/to/loader.log]
python skills/modwright/scripts/mw.py publish-prep thunderstore mymod --version 1.0.0 --title CoolMod
python skills/modwright/scripts/mw.py publish-prep workshop mymod --appid 480 --changenote "First" --visibility 2
```

`publish-prep` also takes `--item`, `--preview`, `--description`, `--url` and repeated `--dep`. The Workshop VDF is written next to the folder, as `mymod.workshop.vdf`.

Full documentation, with every command's options and verified output: the [wiki](https://github.com/m4bwav/modwright/wiki).

## License

MIT. See [LICENSE](LICENSE).
```

```md
# modwright scope (session 1, 2026-11-21)

Source: [research note](../research/2026-11-21-modding-landscape.md).

## Position
universal-modder (MIT, ~9K stars) already does "mod any game" playbooks plus art. modwright does not clone it. It is the verification and safety layer any game mod needs, generalised from madnesswright.

## Build (in order)
1. `mw.py scan <install>`: engine (Unity mono/IL2CPP, Unreal, Godot, other), anti-cheat (EAC, BattlEye files), installed loader, recommended loader; JSON out. Stdlib only.
2. `mw.py backup|restore`: saves and touched game files with SHA-256 manifest and the game build id.
3. `mw.py proof <install> --mod NAME`: reads the loader log (BepInEx LogOutput.log, MelonLoader Latest.log, UE4SS.log) and says loaded / errored / not seen.
4. `mw.py publish-prep`: Workshop VDF (change notes required), Thunderstore manifest; never uploads without a go.
```

```md
## 4. Hosts and upload automation

- **Steam Workshop** [known]: `steamcmd +login <user> +workshop_build_item item.vdf +quit`. VDF keys:
  `appid`, `publishedfileid` (0 = new item), `contentfolder`, `previewfile`, `visibility` (0 public,
  1 friends, 2 private, 3 unlisted), `title`, `description`, `changenote`. It only works if the game
  allows Workshop uploads through steamcmd. Many games ship their own uploader instead (madnesswright uses the game's own).
  It needs the user's Steam login and Steam Guard, so the agent prepares the VDF and the user runs or approves it.
  A new uploader must accept the Workshop legal agreement once in a browser.
- **Nexus Mods** [web]: the Upload API is in open beta for **updating existing mods** (new file versions) with
  per-user API keys, plus an official GitHub Action. There is no full create flow yet, so mod pages are
  still created by hand. https://www.nexusmods.com/spaceengineers/news/15454 (the date was not visible in results;
  check the Nexus API docs before codifying).
- **Thunderstore** [web]: `dotnet tool install -g tcli`. Config is `thunderstore.toml` ([package], [build],
  [publish] communities). Run `tcli build`, then `tcli publish --token` or set `TCLI_AUTH_TOKEN` (a service-account
  token from the team settings). `--file` publishes a prebuilt zip. A package needs manifest.json, a 256x256 icon.png and
  README.md. https://github.com/thunderstore-io/thunderstore-cli , https://www.nuget.org/packages/tcli
- **mod.io** [web]: REST `POST /games/{game}/mods/{mod}/files` (multipart; large files use a multipart session
  with 50 MiB parts). Writes need an OAuth2 access token, and the user must be a team manager or admin on the mod.
  Content falls under the mod.io Terms of Use. https://docs.mod.io/restapi/docs/add-modfile
- **CurseForge** [web]: an author API token (X-Api-Token header) from the API Tokens page, then
  `POST https://<game>.curseforge.com/api/projects/{id}/upload-file` as multipart (metadata JSON + file). It
  returns the file id. Mostly Minecraft and WoW (Minecraft goes to minewright).
  https://support.curseforge.com/support/solutions/articles/9000197321-curseforge-api
- Terms on automated upload: every host above offers token-based author uploads, so scripted uploads
  of the user's own mods are allowed. None permits scraping or re-uploading other people's mods. Policy for
  modwright: build the package and the exact command, and publish only on the user's explicit go-ahead
  (registry publishing always needs the owner's OK).

## 5. Safety and legality [known unless marked]

- **Anti-cheat**: EAC, BattlEye, Vanguard, Ricochet, nProtect, mhyprot. Injecting DLLs (the winhttp/
  version.dll proxies that BepInEx, MelonLoader and UE4SS use) into a protected game can trigger
  **permanent account bans**, in some titles even offline. The skill must detect `EasyAntiCheat/`,
  `BattlEye/` and the like, and refuse loader injection unless the game documents an offline or modded mode
  (for example Elden Ring's EAC-off offline launch used by Seamless Co-op). Never mod competitive
  multiplayer clients. Multiplayer is limited to server-side or officially supported modding.
- **EULA**: most EULAs forbid reverse engineering but tolerate single-player mods. Publishers vary
  (Take-Two/Rockstar and Nintendo are hostile; Bethesda, Paradox and Factorio are friendly). The interop exception
  (DMCA 1201(f), EU Software Directive art. 6) is narrow. Never redistribute game assets or
  decompiled code in a mod package. Ship patches and the user's own assets only.
- **Defender/AV**: proxy DLLs (winhttp.dll, version.dll, dwmapi.dll, dinput8.dll) and
  doorstop loaders are often flagged as false-positive trojans. Advise downloading loaders
  only from official GitHub releases and checking the hash, and adding a narrow folder exclusion only if the user
  chooses to. Never disable Defender globally.
- **Backups**: before any change, copy the saves (Steam: `<userdata>/<id>/<appid>/remote`, Unity:
  `%USERPROFILE%/AppData/LocalLow/<Company>/<Game>`, UE: `%LOCALAPPDATA%/<Game>/Saved/SaveGames`,
  Documents/My Games). Record vanilla file hashes so an uninstall restores the game exactly. Steam
  "Verify integrity" is the last resort. Rule: don't walk AppData beyond the one game's
  save folder without approval.
- Game updates break mods: patches change the IL2CPP metadata and UE versions. Record the game build id
  (Steam `appmanifest_<appid>.acf` buildid) with each recipe.

## Scope recommendations

1. **Set modwright apart from universal-modder instead of cloning it.** Read its repo first. Position modwright
   as the verification-and-safety layer: `mw.py scan` (engine, runtime, anti-cheat gate, loader
   pick), backup and restore with hashes, and per-loader log checks that prove a mod loaded. Skip AI art
   generation (artwright, pixelwright and polywright already cover it).
2. **Cover the loaders with the widest reach first**: BepInEx 5/6 (+Harmony), MelonLoader,
   UE4SS (+pak), and official data/Lua mod folders. Route Minecraft to minewright and Roblox to
   roblox-agent, and keep madnesswright as the first per-game recipe file (recipes/<game>.md).
3. **Publishing is prepare-then-ask**: generate the Workshop VDF, Thunderstore toml/manifest, Nexus
   update-API call and mod.io/CurseForge payloads, and run them only on the user's explicit go-ahead. Hard-refuse
   games protected by anti-cheat in multiplayer.
```

```md
# Modwright

The safety and proof layer every game mod needs. A mod is done only when a loader log line names it and the owner has seen it work in game.

`MW` means `python "<this folder>/scripts/mw.py"` (Python 3.9+, stdlib). Commands print JSON. Exit 0 ok, 1 check failed, 2 anti-cheat (stop), 3 bad input.

## Route first

- Minecraft (Forge, Fabric, NeoForge): minewright. Roblox: roblox-agent. MADNESS Project Nexus: madnesswright (the worked per-game recipe this skill generalises).
- Textures, sprites, models for the mod: artwright, pixelwright, polywright.

## Steps

1. **Find the install and the branch.** Steam: `steamapps/common/<Game>`, build id in `steamapps/appmanifest_<appid>.acf` (`buildid`); note a beta branch. Mods break on updates, so record the build.
2. **Scan.** `MW scan "<install>"`. Exit 2 means anti-cheat (EAC, BattlEye, Vanguard...): stop. No DLL proxy, injection or memory patching; only the game's official mod route, offline or single player, and say why. Online multiplayer cheats are refused outright.
3. **Legality.** Read the EULA or mod policy before shipping anything: modding for personal use is usually tolerated; redistributing game assets or code is not. Ship patches and your own files, never the game's DLLs or ripped assets.
4. **Back up before touching anything.** `MW backup <out> <savesdir> <file-you-will-touch>... --build <buildid>`. `MW restore <out> --verify` shows what changed; `MW restore <out>` puts it back. Saves often live outside the install (`%USERPROFILE%/AppData/LocalLow/<Company>/<Game>`, `Documents/My Games`); find them first.
5. **Decompile before naming a patch target.** Never guess a class or method name. Unity Mono: ILSpy/dnSpyEx on `<Game>_Data/Managed/Assembly-CSharp.dll`. IL2CPP: Il2CppDumper or Cpp2IL first. Unreal: FModel, UE4SS header dump. Godot: gdsdecomp. Quote the signature you patch.
6. **Loader.** Take `recommended_loader` from the scan. BepInEx 5 for Unity Mono, BepInEx 6 or MelonLoader for IL2CPP, UE4SS (plus pak mods in `Content/Paks/~mods`) for Unreal, Harmony alone when the game has its own loader. Pin the loader version in the mod's README.
7. **Prove it loaded.** Have the owner run the game, then `MW proof "<install>" --mod <Name>`. `loaded` needs a log line naming the mod; `errored` shows the lines; `not-seen` or `no-log` means it did not load, whatever the build said. A log over a day old is stale. Then ask what they saw in game.
8. **Publish only on a go.** `MW publish-prep workshop <folder> --appid N --changenote "..."` writes a VDF (`--item` to update, visibility 2 private by default); `MW publish-prep thunderstore <folder> --version 1.0.0 --title Name` writes `manifest.json` and lists missing `icon.png`/`README.md`. The upload itself (steamcmd login, `tcli publish`, Nexus, mod.io) needs the owner's account and explicit go-ahead.

## Rules

- No claim of "works" without step 7.
- Restore the backup before telling the owner to verify the game files through Steam; never delete saves.
- One mod change per test run, so a failing log points at one thing.

## Maintenance

Evergreen unit at the repository root: `evergreen.json`, RESEARCH.md, CHANGELOG.md, LEARNINGS.md, TESTS.md (evals in `evals/`). Refresh every 30 days; check volatile loader facts against their docs before relying on them.
```

```py
def _entries(root, depth=4):
    names, rels = set(), []
    for dirpath, dirs, files in os.walk(root):
        rel = Path(dirpath).relative_to(root)
        if len(rel.parts) >= depth:
            dirs[:] = []
        for n in dirs + files:
            names.add(n.lower())
            rels.append((rel / n).as_posix().lower())
    return names, rels


def scan(install):
    root = Path(install)
    names, rels = _entries(root)

    def has(n):
        return n.lower() in names

    def ext(*e):
        return any(n.endswith(e) for n in names)

    engine, runtime = "unknown", None
    if has("unityplayer.dll") or any(r.endswith("_data") and "/" not in r for r in rels):
        engine = "Unity"
        if has("gameassembly.dll") or has("global-metadata.dat"):
            runtime = "IL2CPP"
        elif has("assembly-csharp.dll"):
            runtime = "Mono"
    elif ext("-shipping.exe", ".utoc") or any(r.endswith(".pak") and "content/paks" in r for r in rels):
        engine = "Unreal"
    elif ext(".pck"):
        engine = "Godot"
    elif has("data.win"):
        engine = "GameMaker"
    elif ext(".rpa") or has("renpy"):
        engine = "Ren'Py"
    elif any(n.startswith(("rpg_", "rmmz_")) and n.endswith(".js") for n in names):
        engine = "RPG Maker MV/MZ"
    elif has("gameinfo.txt") or ext(".vpk"):
        engine = "Source"
    elif ext(".esm", ".ba2", ".bsa"):
        engine = "Bethesda Creation"
    elif has("fna.dll") or has("monogame.framework.dll") or ext(".xnb"):
        engine = "XNA/FNA/MonoGame"
    elif has(".minecraft") or (ext(".jar") and has("versions")):
        engine = "Minecraft"

    anticheat = sorted({v for k, v in ANTICHEAT.items() if has(k)})
    loaders = []
    for p, name in LOADERS:
        if (root / p).exists() and name not in loaders:
            loaders.append(name)
    notes = []
    if anticheat:
        notes.append("Anti-cheat present: stop. No injection or memory patching; "
                     "only official mod routes, single-player or offline.")
    if not loaders:
        notes.append("No mod loader installed yet. Back up saves before installing one.")
    return {
        "install": str(root), "engine": engine, "runtime": runtime, "anticheat": anticheat,
        "loaders_installed": loaders,
        "recommended_loader": RECOMMEND.get((engine, runtime), "unknown: inspect by hand"),
        "loader_logs": [LOGS[x] for x in loaders if x in LOGS], "notes": notes,
    }


def _sha(p):
    h = hashlib.sha256()
    with open(p, "rb") as f:
        for b in iter(lambda: f.read(1 << 20), b""):
            h.update(b)
    return h.hexdigest()


def backup(out, paths, build=None):
    """Copy each path (file or dir) into out/files/<n>/ and write a hash manifest."""
    out = Path(out)
    if out.exists() and any(out.iterdir()):
        raise ValueError(f"backup folder not empty: {out}")
    items = []
    for i, src in enumerate(paths):
        src = Path(src).resolve()
        if not src.exists():
            raise ValueError(f"missing: {src}")
        files = [src] if src.is_file() else sorted(p for p in src.rglob("*") if p.is_file())
        base = src.parent if src.is_file() else src
        for f in files:
            rel = f.relative_to(base).as_posix()
            dst = out / "files" / str(i) / rel
            dst.parent.mkdir(parents=True, exist_ok=True)
            shutil.copy2(f, dst)
            items.append({"slot": i, "rel": rel, "sha256": _sha(f), "size": f.stat().st_size})
    sources = [str(Path(p).resolve()) for p in paths]
    man = {"made": time.strftime("%Y-%m-%dT%H:%M:%S"), "build": build,
           "sources": sources, "kinds": ["file" if Path(p).is_file() else "dir" for p in sources],
           "files": items}
    (out / "manifest.json").write_text(json.dumps(man, indent=1), encoding="utf-8")
    return {"backup": str(out), "files": len(items), "build": build}


def restore(bdir, verify_only=False):
    bdir = Path(bdir)
    man = json.loads((bdir / "manifest.json").read_text(encoding="utf-8"))
    bad, changed, restored = [], [], 0
    for it in man["files"]:
        copy = bdir / "files" / str(it["slot"]) / it["rel"]
        if not copy.is_file() or _sha(copy) != it["sha256"]:
            bad.append(it["rel"])
            continue
        src = Path(man["sources"][it["slot"]])
        live = (src.parent if man["kinds"][it["slot"]] == "file" else src) / it["rel"]
        if not live.is_file() or _sha(live) != it["sha256"]:
            changed.append(live.as_posix())
            if not verify_only:
                live.parent.mkdir(parents=True, exist_ok=True)
                shutil.copy2(copy, live)
                restored += 1
    return {"backup_ok": not bad, "corrupt_in_backup": bad,
            "live_differs": changed, "restored": restored, "build": man.get("build")}


LOAD_LINES = [r"Loading \[{m}", r"Starting Lua mod '{m}'", r"Mod '{m}' loaded",
              r"\b{m}\b.*\b(loaded|initiali[sz]ed|by )", r"^\s*\d+\)\s*{m}\b", r"Melon.*{m}"]
ERR_RE = r"(error|exception|failed|could not load).*{m}|{m}.*(error|exception|failed)"


def proof(install, mod, log=None):
    root = Path(install)
    logs = [Path(log)] if log else []
    if not logs:
        for rel in ("BepInEx/LogOutput.log", "MelonLoader/Latest.log", "UnityModManager/Log.txt",
                    "ue4ss/UE4SS.log", "UE4SS.log", "Mods/mods.log", "logs/latest.log"):
            logs += [p for p in root.rglob(rel.split("/")[-1]) if p.as_posix().endswith(rel)][:1]
    logs = [p for p in logs if p.is_file()]
    if not logs:
        return {"mod": mod, "verdict": "no-log", "logs": [],
                "note": "No loader log found. Run the game once with the loader, or pass --log."}
    # whole-identifier match: "Missing" must not hit "MissingMethodException" or "Other.Missing"
    m = r"(?<![\w.])" + re.escape(mod) + r"(?![\w])"
    hits, errs = [], []
    for p in logs:
        for line in p.read_text(encoding="utf-8", errors="replace").splitlines():
            if re.search(ERR_RE.format(m=m), line, re.I):
                errs.append(line.strip()[:200])
            elif any(re.search(x.format(m=m), line, re.I) for x in LOAD_LINES):
                hits.append(line.strip()[:200])
    age = min(time.time() - p.stat().st_mtime for p in logs)
    verdict = "errored" if errs else "loaded" if hits else "not-seen"
    r = {"mod": mod, "verdict": verdict, "logs": [str(p) for p in logs],
         "load_lines": hits[:5], "error_lines": errs[:5], "log_age_hours": round(age / 3600, 1)}
    if age > 86400:
        r["note"] = "Log is over a day old: run the game again before trusting it."
    return r


def publish_prep(kind, folder, **kw):
    folder = Path(folder).resolve()
    if kind == "workshop":
        if not kw.get("changenote"):
            raise ValueError("--changenote is required for a Workshop item")
        q = lambda s: str(s).replace("\\", "/").replace('"', "'")  # noqa: E731
        vals = {"appid": kw["appid"], "publishedfileid": kw.get("item") or "0",
                "contentfolder": str(folder), "previewfile": kw.get("preview") or "",
                "visibility": kw.get("visibility") or "2", "title": kw.get("title") or folder.name,
                "description": kw.get("description") or "", "changenote": kw["changenote"]}
        body = "".join(f'\t"{k}"\t\t"{q(v)}"\n' for k, v in vals.items())
        out = folder.parent / f"{folder.name}.workshop.vdf"
        out.write_text('"workshopitem"\n{\n' + body + "}\n", encoding="utf-8")
        cmd = f'steamcmd +login <user> +workshop_build_item "{out.as_posix()}" +quit'
    elif kind == "thunderstore":
        ver = kw.get("version") or ""
        if not re.fullmatch(r"\d+\.\d+\.\d+", ver):
            raise ValueError("--version must be MAJOR.MINOR.PATCH")
        name = kw.get("title") or folder.name
        if not re.fullmatch(r"[A-Za-z0-9_]+", name):
            raise ValueError("Thunderstore name: letters, digits, underscore only")
        man = {"name": name, "version_number": ver, "website_url": kw.get("url") or "",
               "description": (kw.get("description") or "")[:250], "dependencies": kw.get("deps") or []}
        out = folder / "manifest.json"
        out.write_text(json.dumps(man, indent=2), encoding="utf-8")
        missing = [f for f in ("icon.png", "README.md") if not (folder / f).is_file()]
        cmd = "tcli build, then tcli publish (needs TCLI_AUTH_TOKEN)"
        if missing:
            return {"wrote": str(out), "missing": missing, "next": cmd,
                    "note": "Thunderstore also needs a 256x256 icon.png and README.md."}
    else:
        raise ValueError(f"unknown kind: {kind}")
    return {"wrote": str(out), "next": cmd,
            "note": "Prepared only. Upload needs the owner's login and explicit go-ahead."}


def main(argv=None):
    ap = argparse.ArgumentParser(prog="mw.py", description=__doc__.splitlines()[0])
    sub = ap.add_subparsers(dest="cmd", required=True)
    s = sub.add_parser("scan", help="identify engine, runtime, anti-cheat and loaders")
    s.add_argument("install")
    s.add_argument("--json", action="store_true")
    b = sub.add_parser("backup", help="copy saves/game files with a hash manifest")
    b.add_argument("out")
    b.add_argument("paths", nargs="+")
    b.add_argument("--build", help="game build id (Steam buildid) to record")
    r = sub.add_parser("restore", help="restore a backup, or --verify only")
    r.add_argument("backup")
    r.add_argument("--verify", action="store_true")
    p = sub.add_parser("proof", help="did the loader log the mod?")
    p.add_argument("install")
    p.add_argument("--mod", required=True)
    p.add_argument("--log")
    q = sub.add_parser("publish-prep", help="write a Workshop VDF or Thunderstore manifest")
    q.add_argument("kind", choices=["workshop", "thunderstore"])
    q.add_argument("folder")
    for o in ("appid", "item", "preview", "visibility", "title", "description",
              "changenote", "version", "url"):
        q.add_argument("--" + o)
    q.add_argument("--dep", action="append", dest="deps")
    a = ap.parse_args(argv)
    try:
        if a.cmd == "backup":
            return _out(backup(a.out, a.paths, a.build), 0)
        if a.cmd == "restore":
            res = restore(a.backup, a.verify)
            return _out(res, 0 if res["backup_ok"] and (not a.verify or not res["live_differs"]) else 1)
        if a.cmd == "proof":
            res = proof(a.install, a.mod, a.log)
            return _out(res, 0 if res["verdict"] == "loaded" else 1)
        if a.cmd == "publish-prep":
            if a.kind == "workshop" and not a.appid:
                raise ValueError("--appid is required")
            kw = {k: v for k, v in vars(a).items() if k not in ("cmd", "kind", "folder")}
            return _out(publish_prep(a.kind, a.folder, **kw), 0)
    except (ValueError, OSError, KeyError) as e:
        print(json.dumps({"error": str(e)}), file=sys.stderr)
        return 3
    if not Path(a.install).is_dir():
        print(f"not a directory: {a.install}", file=sys.stderr)
        return 3
    r = scan(a.install)
    if a.json:
        print(json.dumps(r, indent=2))
    else:
        for k in ("engine", "runtime", "anticheat", "loaders_installed",
                  "recommended_loader", "loader_logs", "notes"):
            print(f"{k}: {r[k]}")
    return 2 if r["anticheat"] else 0


def _out(res, code):
    print(json.dumps(res, indent=2))
    return code


if __name__ == "__main__":
    sys.exit(main())
```
