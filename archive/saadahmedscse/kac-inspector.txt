# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-12

First public release.

### Added

- Detection of 43 known kernel anti-cheat drivers from the kernel module list, the Service
  Control Manager and the driver store, plus a name heuristic for unlisted ones.
- Live state for each driver: running, loaded, pending, stopped, orphaned or stale, with
  companion user-mode services.
- Answer-first report: verdict, a card per detection, and a coverage strip of every
  signature.
- Animated progress bar while scanning, and an arrow-key menu to scan again or exit.
- Automatic elevation through UAC, with a standard-user fallback.
- `NO_COLOR` and `KAC_ASCII` support; plain output when piped.

[1.0.0]: https://github.com/saadahmedscse/kac-inspector/releases/tag/v1.0.0

# Contributing to KAC Inspector

Thanks for helping. Contributions of every size are welcome, and the most useful one is
usually the smallest: a missing or misnamed anti-cheat driver.

By participating you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Adding or fixing a signature

Every known anti-cheat is one entry in [`src/signatures.rs`](src/signatures.rs):

```rust
sig!(
    "Riot Vanguard",
    "Riot Games",
    "VALORANT, League of Legends, TFT, 2XKO",
    ["vgk.sys"],
    ["vgk"],
    ["vgc"]
),
```

The fields are, in order: name, vendor, notable games, driver file patterns, kernel
service-name patterns, and companion user-mode service patterns. Patterns are
case-insensitive and support `*` and `?`.

In the pull request, say where the driver name comes from: a vendor page, a game's install
folder, `sc query type= driver` output, LOLDrivers, or similar. Signatures without a source
are hard to verify.

If you would rather not write code, open a
[new signature issue](https://github.com/saadahmedscse/kac-inspector/issues/new/choose)
with the same information.

## Reporting a bug

Open an [issue](https://github.com/saadahmedscse/kac-inspector/issues/new/choose) with your
Windows version, the KAC Inspector version, whether it ran as administrator, and what you
expected to see. Security problems go through [SECURITY.md](SECURITY.md) instead.

## Working on the code

You need Windows and [Rust](https://rustup.rs) 1.89 or newer.

```bat
cargo build
cargo test
cargo clippy
```

Before opening a pull request:

- `cargo test` passes and `cargo clippy` shows no warnings (the crate enables
  `clippy::pedantic`).
- `cargo fmt` has been run.
- All Windows API calls stay in `src/sys.rs`, which is the only place `unsafe` is allowed.
- The output keeps to the existing palette in `src/style.rs`, and every Unicode glyph has an
  ASCII fallback.

### Layout

| File | What it holds |
|---|---|
| `src/main.rs` | Elevation, the scan loop, and the order of the steps |
| `src/sys.rs` | Every Windows API call |
| `src/signatures.rs` | The anti-cheat database |
| `src/scan.rs` | Matching collected data against the database |
| `src/render.rs` | The report layout |
| `src/loader.rs` | The progress bar |
| `src/menu.rs` | The end-of-scan menu |
| `src/style.rs` | Colours and glyphs |

## Releases

Releases are cut from `master`: bump the version in `Cargo.toml`, add an entry to
[CHANGELOG.md](CHANGELOG.md), tag `vX.Y.Z`, and attach the release build of the executable.

# KAC Inspector

**Kernel anti-cheat inspector for Windows.** One command tells you which kernel-mode anti-cheat
drivers are on your machine, which of them are live in the kernel right now, and which are
leftovers from games you uninstalled long ago.

It reads the answer straight from Windows. It does not install anything, change anything, or
talk to the network.

## What it reports

For each of the 43 known kernel anti-cheats, KAC Inspector checks three places:

- **The kernel module list** (`EnumDeviceDrivers`): what is actually mapped in kernel memory.
- **The Service Control Manager**: every registered kernel driver service and its companion
  user-mode service, with start type and state.
- **The driver store** (`%SystemRoot%\System32\drivers`): the `.sys` files on disk.

Each driver it finds gets one of these states:

| State | Meaning |
|---|---|
| `running` | Loaded in the kernel, and its service is running |
| `loaded` | In kernel memory, with no running service entry |
| `pending` | Its service is starting or stopping |
| `stopped` | Installed and idle |
| `orphaned` | The service is registered but its `.sys` file is gone |
| `stale` | A `.sys` file left on disk with no service |

Drivers that are not in the database but describe themselves as an anti-cheat (for example
"game guard" or "anti-cheat" in their name or description) are reported too, marked as
matched by name.

The report leads with the verdict (**kernel clean**, or how many anti-cheats are live), then a
card per detection, then a coverage strip showing all 43 signatures at a glance.

## Download

Grab `kac-inspector-v1.0.0-windows-x64.exe` from the
[latest release](https://github.com/saadahmedscse/kac-inspector/releases/latest) and run it.
It asks for administrator rights through UAC; recent Windows builds only reveal the kernel
module list to an elevated process. If you decline, it still runs and reports what it can
see from the Service Control Manager.

When the scan finishes, use <kbd>↑</kbd> <kbd>↓</kbd> and <kbd>Enter</kbd> to scan again or
exit (<kbd>Esc</kbd> also exits).

# Security Policy

## Supported versions

Only the latest release receives fixes.

| Version | Supported |
|---|---|
| 1.x | Yes |

## What KAC Inspector does

Knowing what the program touches helps judge whether something is a vulnerability:

- It runs elevated (through UAC) so it can read the kernel module list, and enables
  `SeDebugPrivilege` in its own process token for that purpose only.
- It only **reads**: the kernel module list, the Service Control Manager's service
  configuration, and the file names in `%SystemRoot%\System32\drivers`.
- It never loads, stops, modifies or deletes a driver or service, writes no files, and makes
  no network connections.

Anything that makes it do more than that, such as running code it should not, writing to the
system, or being tricked by a crafted service entry or file name, is a security issue.

## Reporting a vulnerability

**Please do not open a public issue for a security problem.**

Report it privately through GitHub:
[Security → Report a vulnerability](https://github.com/saadahmedscse/kac-inspector/security/advisories/new).

Include the Windows version, the KAC Inspector version, and the steps to reproduce. You can
expect an acknowledgement within 7 days. Once a fix is released, the advisory is published
with credit to the reporter unless you prefer to stay anonymous.

## Antivirus warnings

The release binary is not code-signed. Because it requests administrator rights and queries
kernel drivers, some antivirus products may flag it heuristically. Every release lists the
SHA-256 of its executable, and you can always build it yourself from source with
`build.bat`.

//! The loader: one progress bar for the whole scan, filling an eighth of a column at a time,
//! with dbsloop's travelling dot and the source being read beside it.
//!
//! **Each source is held on screen for at least [`MIN_VISIBLE`]** — the scan itself takes
//! milliseconds and would otherwise flash past as a single frame.

use std::io::Write as _;
use std::sync::{Arc, Mutex};
use std::thread;
use std::time::{Duration, Instant};

use crate::style::{self, Hue, paint};

/// How often the bar is redrawn.
const TICK: Duration = Duration::from_millis(30);

/// How long one spinner frame stays on screen (four ticks).
const FRAME_TICKS: usize = 4;

/// The shortest time a source stays on screen when animation is on.
const MIN_VISIBLE: Duration = Duration::from_millis(360);

/// Width of the bar between its caps.
pub const BAR: usize = 60;

fn frames() -> &'static [&'static str] {
    if style::unicode() {
        &[
            "\u{25cf}\u{2219}\u{2219}",
            "\u{2219}\u{25cf}\u{2219}",
            "\u{2219}\u{2219}\u{25cf}",
            "\u{2219}\u{25cf}\u{2219}",
        ]
    } else {
        &["o..", ".o.", "..o", ".o."]
    }
}

/// The bar `width` columns wide, filled to `fraction`: the filled part and the track.
#[must_use]
#[allow(
    clippy::cast_possible_truncation,
    clippy::cast_sign_loss,
    clippy::cast_precision_loss
)]
pub fn bar(fraction: f64, width: usize) -> (String, String) {
    let fraction = fraction.clamp(0.0, 1.0);
    if !style::unicode() {
        let full = ((fraction * width as f64).round() as usize).min(width);
        return ("#".repeat(full), ".".repeat(width - full));
    }
    // Eighths of a column across the whole bar, so the remainder picks a partial block.
    let eighths = (fraction * (width * 8) as f64).round() as usize;
    let full = (eighths / 8).min(width);
    let part = u32::try_from(eighths % 8).unwrap_or(0);
    let mut filled = "\u{2588}".repeat(full);
    let mut empty = width - full;
    if part > 0 && full < width {
        filled.push(char::from_u32(0x2588 - (8 - part)).unwrap_or('\u{2588}'));
        empty -= 1;
    }
    (filled, "\u{2591}".repeat(empty))
}

/// `Scan   ▕██████░░░░▏  ` — everything up to the text after the bar.
fn bar_line(fraction: f64) -> String {
    let (filled, track) = bar(fraction, BAR);
    format!(
        "  {}{}{}{}{}  ",
        paint(Hue::Dim, "Scan   "),
        paint(Hue::Dim, style::glyph("\u{2595}", "[")),
        paint(Hue::Brand, &filled),
        paint(Hue::Faint, &track),
        paint(Hue::Dim, style::glyph("\u{258f}", "]")),
    )
}

struct State {
    done: usize,
    label: String,
    stop: bool,
}

/// The scan's progress, drawn on one line rewritten in place.
pub struct Progress {
    total: usize,
    state: Arc<Mutex<State>>,
    thread: Option<thread::JoinHandle<()>>,
}

impl Progress {
    /// Start the bar for `total` sources. Without animation nothing is drawn until
    /// [`Progress::finish`].
    pub fn start(animate: bool, total: usize) -> Self {
        let state = Arc::new(Mutex::new(State {
            done: 0,
            label: String::new(),
            stop: false,
        }));
        let thread = animate.then(|| {
            let state = Arc::clone(&state);
            thread::spawn(move || ticker(&state, total))
        });
        Self {
            total,
            state,
            thread,
        }
    }

    /// Read one source under the bar.
    pub fn step<T>(&mut self, label: &str, work: impl FnOnce() -> T) -> T {
        let started = Instant::now();
        if let Ok(mut s) = self.state.lock() {
            label.clone_into(&mut s.label);
        }
        let value = work();
        if self.thread.is_some()
            && let Some(rest) = MIN_VISIBLE.checked_sub(started.elapsed())
        {
            thread::sleep(rest);
        }
        if let Ok(mut s) = self.state.lock() {
            s.done += 1;
        }
        value
    }

    /// Settle into the full bar and how long it took.
    pub fn finish(mut self, seconds: f64) {
        // The ticker clears its own line on the way out, so there is nothing to erase here.
        if let Some(handle) = self.thread.take() {
            if let Ok(mut s) = self.state.lock() {
                s.stop = true;
            }
            let _ = handle.join();
        }
        println!(
            "{}{}",
            bar_line(1.0),
            paint(
                Hue::Dim,
                &format!("{0} of {0} sources  \u{00b7}  {seconds:.2} s", self.total)
            ),
        );
    }
}

#[allow(clippy::cast_precision_loss)]
fn ticker(state: &Mutex<State>, total: usize) {
    let mut out = std::io::stdout();
    let _ = write!(out, "\x1b[?25l");
    let mut shown = 0.0_f64;
    let mut tick = 0_usize;
    loop {
        let (done, label, stop) = match state.lock() {
            Ok(s) => (s.done, s.label.clone(), s.stop),
            Err(_) => return,
        };
        if stop {
            let _ = write!(out, "\r\x1b[2K\x1b[?25h");
            let _ = out.flush();
            return;
        }
        // Ease toward the next boundary so the bar keeps moving while a source is read.
        let target = (done as f64 + 0.8) / total as f64;
        shown += (target - shown) * 0.18;
        let frame = frames()[(tick / FRAME_TICKS) % frames().len()];
        let _ = write!(
            out,
            "\r{}{}{}\x1b[K",
            bar_line(shown),
            paint(
                Hue::Dim,
                &format!("{} of {total} sources  \u{00b7}  ", done.min(total))
            ),
            format_args!("{} {}", paint(Hue::Text, &label), paint(Hue::Brand, frame)),
        );
        let _ = out.flush();
        tick += 1;
        thread::sleep(TICK);
    }
}

#[cfg(test)]
mod tests {
    use super::{bar, frames};

    #[test]
    fn every_frame_is_three_columns() {
        for frame in frames() {
            assert_eq!(frame.chars().count(), 3);
        }
    }

    #[test]
    fn a_bar_is_always_exactly_as_wide_as_asked() {

            for step in 0..=20 {
                let (filled, empty) = bar(f64::from(step) / 20.0, width);
                assert_eq!(filled.chars().count() + empty.chars().count(), width);
            }
        }
    }
}

//! KAC Inspector - Kernel Anti-Cheat Inspector.
//!
//! Detects known kernel-mode anti-cheat drivers and reports their live state
//! (RUNNING / LOADED / STOPPED / ORPHANED / STALE) straight from the kernel module list, the
//! Service Control Manager and the drivers folder. A Rust port of `KAC_Query.bat`.

#![cfg(windows)]

mod loader;
mod menu;
mod render;
mod scan;
mod signatures;
mod style;
mod sys;

use std::io::IsTerminal as _;
use std::time::Instant;

use loader::Progress;

/// Passed to the elevated copy so it never tries to elevate again.
const ELEVATED_FLAG: &str = "--elevated";

fn main() {
    let relaunched = std::env::args().any(|a| a == ELEVATED_FLAG);

    // ---- Self-elevate to Administrator, like the bat's `fltmc || runas` dance.
    let admin = sys::is_elevated();
    if !admin && !relaunched {
        println!("  Requesting administrator privileges...");
        if sys::relaunch_elevated(ELEVATED_FLAG) {
            return;
        }
    }

    let vt = sys::prepare_console("KAC Inspector - Kernel Anti-Cheat Inspector");
    let terminal = std::io::stdout().is_terminal();
    let colour = terminal && vt && std::env::var_os("NO_COLOR").is_none();
    style::init(style::Caps {
        colour,
        truecolor: colour,
        unicode: std::env::var_os("KAC_ASCII").is_none(),
    });
    let animate = colour;
    let interactive = terminal && std::io::stdin().is_terminal();

    loop {
        scan(animate, admin);
        // Not a console to ask in (piped, redirected): one scan and done, like a CLI tool.
        if !interactive || menu::ask() == menu::Choice::Exit {
            break;
        }
        let _ = crossterm::execute!(
            std::io::stdout(),
            crossterm::terminal::Clear(crossterm::terminal::ClearType::All),
            crossterm::terminal::Clear(crossterm::terminal::ClearType::Purge),
            crossterm::cursor::MoveTo(0, 0),
        );
    }
}

/// One full pass: header, collection under the progress bar, matching, report.
fn scan(animate: bool, admin: bool) {
    let clock = Instant::now();
    let width = sys::console_width().map_or(104, |w| w.saturating_sub(4).clamp(80, 104));
    let page = render::Page { width };
    page.header();

    let mut progress = Progress::start(animate, 5);

    let modules = progress.step("Kernel modules", || {
        sys::enable_debug_privilege();
        sys::kernel_modules()
    });
    let kernel_ok = !modules.is_empty();
    let drivers = progress.step("Driver services", sys::driver_services);
    let services = progress.step("Companion services", sys::user_services);
    let disk_dir = sys::drivers_dir();
    let disk = progress.step("Driver store", || {
        std::fs::read_dir(&disk_dir)
            .into_iter()
            .flatten()
            .flatten()
            .filter(|e| e.file_type().is_ok_and(|t| t.is_file()))
            .map(|e| e.file_name().to_string_lossy().into_owned())
            .filter(|n| n.to_lowercase().ends_with(".sys"))
            .collect::<Vec<_>>()
    });
    let report = progress.step("Signatures", || {
        scan::run(
            &modules,
            &drivers,
            &services,
            &disk,
            &disk_dir.to_string_lossy(),
            &sys::system_root(),
        )
    });
    progress.finish(clock.elapsed().as_secs_f64());

    page.report(&report, kernel_ok);
    let host = std::env::var("COMPUTERNAME").unwrap_or_default();
    page.footer(&host, &sys::os_caption(), admin, &sys::local_time());
}

//! The question at the end of a scan, drawn the way dbsloop draws a list: an orange `›`
//! beside the highlighted item, the arrow keys to move it, Enter to choose.

use std::io::{Write as _, stdout};

use crossterm::cursor::{Hide, MoveToColumn, MoveUp, Show};
use crossterm::event::{Event, KeyCode, KeyEventKind, KeyModifiers, read};
use crossterm::execute;
use crossterm::terminal::{Clear, ClearType, disable_raw_mode, enable_raw_mode};

use crate::style::{Hue, bold, g, paint};

/// What the user picked.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Choice {
    ScanAgain,
    Exit,
}

const ITEMS: [(Choice, &str); 2] = [(Choice::ScanAgain, "Scan again"), (Choice::Exit, "Exit")];

/// Lines the menu occupies below the question (the items and the help line), redrawn in
/// place on every key.
const HEIGHT: u16 = 3;

/// Puts the terminal back however the menu is left.
struct Raw;

impl Raw {
    fn enter() -> std::io::Result<Self> {
        enable_raw_mode()?;
        let _ = execute!(stdout(), Hide);
        Ok(Self)
    }
}

impl Drop for Raw {
    fn drop(&mut self) {
        let _ = execute!(stdout(), Show);
        let _ = disable_raw_mode();
    }
}

fn draw(here: usize) {
    let mut out = stdout();
    for (index, (_, label)) in ITEMS.iter().enumerate() {
        let line = if index == here {
            format!(
                "  {} {}",
                paint(Hue::Brand, g::here()),
                bold(Hue::Brand, label)
            )
        } else {
            format!("    {}", paint(Hue::Text, label))
        };
        let _ = write!(out, "{line}\x1b[K\r\n");
    }
    let help = format!(
        "{} move  {dot}  enter select  {dot}  esc quit",
        g::arrows(),
        dot = g::mid()
    );
    let _ = write!(out, "  {}\x1b[K\r\n", paint(Hue::Dim, &help));
    let _ = out.flush();
}

/// Ask what to do next. Anything that cannot be read is taken as Exit.
#[must_use]
pub fn ask() -> Choice {
    println!();
    println!(
        "  {} {}",
        paint(Hue::Brand, "?"),
        paint(Hue::Text, "What next?")
    );

    let Ok(raw) = Raw::enter() else {
        return Choice::Exit;
    };
    let mut here = 0;
    draw(here);

    let choice = loop {
        let Ok(event) = read() else {
            break Choice::Exit;
        };
        let Event::Key(key) = event else { continue };
        if key.kind != KeyEventKind::Press {
            continue;
        }
        match key.code {
            KeyCode::Up => here = (here + ITEMS.len() - 1) % ITEMS.len(),
            KeyCode::Down | KeyCode::Tab => here = (here + 1) % ITEMS.len(),
            KeyCode::Char('1') => break Choice::ScanAgain,
            KeyCode::Enter => break ITEMS[here].0,
            KeyCode::Char('2') | KeyCode::Esc => break Choice::Exit,
            KeyCode::Char('c') if key.modifiers.contains(KeyModifiers::CONTROL) => {
                break Choice::Exit;
            }
            _ => continue,
        }
        let _ = execute!(stdout(), MoveUp(HEIGHT), MoveToColumn(0));
        draw(here);
    };

    // Settle the list into the answer, the way an answered prompt reads in dbsloop.
    let _ = execute!(
        stdout(),
        MoveUp(HEIGHT),
        MoveToColumn(0),
        Clear(ClearType::FromCursorDown)
    );
    drop(raw);
    let label = ITEMS
        .iter()
        .find(|(c, _)| *c == choice)
        .map_or("Exit", |(_, l)| *l);
    println!("  {} {}", paint(Hue::Dim, g::mid()), paint(Hue::Ok, label));
    choice
}

struct Line {

    cols: usize,

impl Line {
    fn new() -> Self {
        Self {

            cols: 0,
        }
    }
    fn put(mut self, hue: Hue, text: &str) -> Self {
        self.text.push_str(&paint(hue, text));
        self.cols += text.chars().count();
        self
    }
    fn strong(mut self, hue: Hue, text: &str) -> Self {
        self.text.push_str(&bold(hue, text));
        self.cols += text.chars().count();
        self
    }
    /// Push `right` to the far edge of a `width`-column line.
    fn right(mut self, width: usize, right: &Line) -> Self {
        let gap = width.saturating_sub(self.cols + right.cols).max(2);
        self.text.push_str(&" ".repeat(gap));
        self.text.push_str(right.text.trim_start_matches("  "));
        self.cols += gap + right.cols;
        self
    }

        println!("{}", self.text);
    }
}

//! Matching: the kernel module list, the driver services and the drivers folder against the
//! signature database, then a name heuristic for anything else that calls itself an
//! anti-cheat. A straight port of the matching block in `KAC_Query.bat`.

use std::path::Path;

use crate::signatures::{DB, HEURISTIC, Signature};
use crate::sys::{Driver, Module, Service};

/// The live state of one driver.
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub enum Status {
    /// Loaded, and the service is running.
    Running,
    /// In kernel memory, with no running SCM entry.
    Loaded,
    /// The service is starting or stopping.
    Pending,
    /// Installed and idle.
    Stopped,
    /// The service is registered but its `.sys` is gone.
    Orphaned,
    /// A `.sys` left on disk with no service.
    Stale,
}

impl Status {
    #[must_use]
    pub const fn word(self) -> &'static str {
        match self {
            Self::Running => "running",
            Self::Loaded => "loaded",
            Self::Pending => "pending",
            Self::Stopped => "stopped",
            Self::Orphaned => "orphaned",
            Self::Stale => "stale",
        }
    }

    /// Is it in the kernel (or on its way in) right now?
    #[must_use]
    pub const fn live(self) -> bool {
        matches!(self, Self::Running | Self::Loaded | Self::Pending)
    }
}

/// One anti-cheat driver found on this system.
#[derive(Debug)]
pub struct Finding {
    pub name: String,
    pub vendor: String,
    pub games: String,
    pub file: String,
    pub path: Option<String>,
    pub service: String,
    pub start: String,
    pub status: Status,
    pub companions: Vec<Service>,
    /// The signature it matched, as an index into [`DB`]; `None` for the heuristic.
    pub sig: Option<usize>,
}

/// Everything the scan turned up.
pub struct Report {
    pub findings: Vec<Finding>,
    pub absent: Vec<&'static Signature>,
}

/// Case-insensitive wildcard match, `*` and `?`, like PowerShell's `-like`.
#[must_use]
pub fn like(value: &str, pattern: &str) -> bool {
    let v: Vec<char> = value.to_lowercase().chars().collect();
    let p: Vec<char> = pattern.to_lowercase().chars().collect();
    let (mut vi, mut pi) = (0, 0);
    let mut star: Option<(usize, usize)> = None;
    while vi < v.len() {
        if pi < p.len() && (p[pi] == '?' || p[pi] == v[vi]) {
            vi += 1;
            pi += 1;
        } else if pi < p.len() && p[pi] == '*' {
            star = Some((pi, vi));
            pi += 1;
        } else if let Some((sp, sv)) = star {
            pi = sp + 1;
            vi = sv + 1;
            star = Some((sp, sv + 1));
        } else {
            return false;
        }
    }
    p[pi..].iter().all(|&c| c == '*')
}

fn like_any(value: &str, patterns: &[&str]) -> bool {
    !value.is_empty() && patterns.iter().any(|p| like(value, p))
}

/// Turn an SCM or kernel path into a normal file path.
#[must_use]
pub fn resolve_path(raw: &str, root: &str) -> Option<String> {
    let mut p = raw.trim().trim_matches('"').to_owned();
    if p.is_empty() {
        return None;
    }
    if let Some(rest) = p.strip_prefix(r"\??\") {
        p = String::from(rest);
    }
    let lower = p.to_lowercase();
    if lower.starts_with(r"\systemroot\") {
        p = format!(r"{root}\{}", &p[r"\systemroot\".len()..]);
    } else if lower.starts_with(r"%systemroot%\") {
        p = format!(r"{root}\{}", &p[r"%systemroot%\".len()..]);
    } else if lower.starts_with(r"system32\") {
        p = format!(r"{root}\{p}");
    }
    Some(p)
}

fn leaf(path: &str) -> &str {
    path.rsplit(['\\', '/']).next().unwrap_or(path)
}

fn exists(path: Option<&String>) -> bool {
    path.is_some_and(|p| Path::new(p).exists())
}

fn heuristic(text: &str) -> bool {
    let squashed: String = text
        .to_lowercase()
        .chars()
        .filter(|c| !c.is_whitespace() && *c != '_' && *c != '-')
        .collect();
    HEURISTIC.iter().any(|word| squashed.contains(word))
}

/// One driver instance being assembled for a signature.
struct Instance<'a> {
    key: String,
    file: String,
    path: Option<String>,
    svc: Option<&'a Driver>,
    loaded: bool,
    on_disk: bool,
}

impl Instance<'_> {
    fn status(&self) -> Status {
        let state = self.svc.map_or("", |d| d.state);
        if self.loaded && state == "Running" {
            Status::Running
        } else if self.loaded {
            Status::Loaded
        } else if state == "Running" {
            Status::Running
        } else if state.ends_with("Pending") {
            Status::Pending
        } else if self.svc.is_some() && self.on_disk {
            Status::Stopped
        } else if self.svc.is_some() {
            Status::Orphaned
        } else {
            Status::Stale
        }
    }
}

/// Match everything that was collected.
#[must_use]
pub fn run(
    modules: &[Module],
    drivers: &[Driver],
    services: &[Service],
    disk: &[String],
    disk_dir: &str,
    root: &str,
) -> Report {
    let mut claimed: Vec<String> = Vec::new();
    let mut findings = Vec::new();
    let mut absent = Vec::new();

    let driver_file = |d: &Driver| -> (Option<String>, String) {
        let path = resolve_path(&d.path, root);
        let base = path
            .as_deref()
            .map_or_else(|| format!("{}.sys", d.name), |p| leaf(p).to_owned());
        (path, base)
    };

    for (index, sig) in DB.iter().enumerate() {
        let mut inst: Vec<Instance> = Vec::new();

        for d in drivers {
            let (path, base) = driver_file(d);
            if like_any(&base, sig.drivers) || like_any(&d.name, sig.services) {
                let key = base.to_lowercase();
                let on_disk = exists(path.as_ref());
                let fresh = Instance {
                    key: key.clone(),
                    file: base,
                    path,
                    svc: Some(d),
                    loaded: false,
                    on_disk,
                };
                match inst.iter_mut().find(|i| i.key == key) {
                    Some(old) if old.svc.is_some_and(|s| s.state == "Running") => {}
                    Some(old) => *old = fresh,
                    None => inst.push(fresh),
                }
            }
        }

        for m in modules {
            let key = m.base.to_lowercase();
            let known = inst.iter().any(|i| i.key == key);
            if like_any(&m.base, sig.drivers) || known {
                if !known {
                    inst.push(Instance {
                        key: key.clone(),
                        file: m.base.clone(),
                        path: resolve_path(&m.path, root),
                        svc: None,
                        loaded: false,
                        on_disk: false,
                    });
                }
                if let Some(i) = inst.iter_mut().find(|i| i.key == key) {
                    i.loaded = true;
                    if i.path.is_none() {
                        i.path = resolve_path(&m.path, root);
                    }
                }
            }
        }

        for name in disk {
            if like_any(name, sig.drivers) {
                let key = name.to_lowercase();
                let full = format!(r"{disk_dir}\{name}");
                if let Some(i) = inst.iter_mut().find(|i| i.key == key) {
                    i.on_disk = true;
                    i.path.get_or_insert(full);
                } else {
                    inst.push(Instance {
                        key,
                        file: name.clone(),
                        path: Some(full),
                        svc: None,
                        loaded: false,
                        on_disk: true,
                    });
                }
            }
        }

        if inst.is_empty() {
            absent.push(sig);
            continue;
        }
        let companions: Vec<Service> = services
            .iter()
            .filter(|s| like_any(&s.name, sig.companions))
            .cloned()
            .collect();
        for i in inst {
            claimed.push(i.key.clone());
            if let Some(svc) = i.svc {
                claimed.push(format!("svc:{}", svc.name.to_lowercase()));
            }
            findings.push(Finding {
                name: sig.name.to_owned(),
                vendor: sig.vendor.to_owned(),
                games: sig.games.to_owned(),
                status: i.status(),
                file: i.file,
                path: i.path,
                service: i.svc.map_or_else(|| "-".to_owned(), |d| d.name.clone()),
                start: i.svc.map_or("-", |d| d.start).to_owned(),
                companions: companions.clone(),
                sig: Some(index),
            });
        }
    }

    // -- Heuristic sweep: anything else that calls itself an anti-cheat.
    let is_claimed = |claimed: &[String], key: &str| claimed.iter().any(|c| c == key);
    for d in drivers {
        if is_claimed(&claimed, &format!("svc:{}", d.name.to_lowercase())) {
            continue;
        }
        let (path, base) = driver_file(d);
        if is_claimed(&claimed, &base.to_lowercase()) {
            continue;
        }
        let text = format!(
            "{} {} {} {}",
            d.name,
            d.display,
            d.description,
            path.as_deref().unwrap_or("")
        );
        if heuristic(&text) {
            let i = Instance {
                key: base.to_lowercase(),
                on_disk: exists(path.as_ref()),
                loaded: modules.iter().any(|m| m.base.eq_ignore_ascii_case(&base)),
                file: base,
                path,
                svc: Some(d),
            };
            claimed.push(i.key.clone());
            findings.push(Finding {
                name: d.display.clone(),
                vendor: "Unknown".to_owned(),
                games: "Matched by name heuristic".to_owned(),
                status: i.status(),
                file: i.file,
                path: i.path,
                service: d.name.clone(),
                start: d.start.to_owned(),
                companions: Vec::new(),
                sig: None,
            });
        }
    }
    for m in modules {
        if is_claimed(&claimed, &m.base.to_lowercase()) {
            continue;
        }
        if heuristic(&format!("{} {}", m.base, m.path)) {
            findings.push(Finding {
                name: m.base.clone(),
                vendor: "Unknown".to_owned(),
                games: "Matched by name heuristic".to_owned(),
                file: m.base.clone(),
                path: resolve_path(&m.path, root),
                service: "-".to_owned(),
                start: "-".to_owned(),
                status: Status::Loaded,
                companions: Vec::new(),
                sig: None,
            });
        }
    }

    findings.sort_by(|a, b| a.status.cmp(&b.status).then_with(|| a.name.cmp(&b.name)));
    Report { findings, absent }
}

//! The palette, the marks and the glyphs.
//!
//! **dbsloop's six colours, plus a faint grey for empty space.** Orange is the brand and the thing happening now,
//! green is a thing that is fine, amber is a thing to know about, red is a thing that is
//! wrong, grey is a label rather than the value it labels. A seventh hue would need a
//! seventh meaning.
//!
//! Colour is off when standard output is not a console or `NO_COLOR` is set, and the glyphs
//! fall back to ASCII when `KAC_ASCII` is set, so a redirected report stays readable.

use std::sync::OnceLock;

/// One of the six, by what it is for rather than by what it looks like.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Hue {
    /// The wordmark, headings, the thing happening now.
    Brand,
    /// Ordinary content.
    Text,
    /// A label, a path, a help line.
    Dim,
    /// Fine.
    Ok,
    /// Worth knowing about.
    Warn,
    /// Wrong, or live in the kernel.
    Bad,
    /// Barely there: an empty bar track, a signature that was not found.
    Faint,
}

impl Hue {
    /// The exact colour, dbsloop's twenty-four bits.
    const fn rgb(self) -> (u8, u8, u8) {
        match self {
            Self::Brand => (0xD9, 0x77, 0x57),
            Self::Text => (0xE0, 0xDC, 0xD6),
            Self::Dim => (0x8C, 0x84, 0x7C),
            Self::Ok => (0x6F, 0xBF, 0x8A),
            Self::Warn => (0xE0, 0xB2, 0x56),
            Self::Bad => (0xE8, 0x70, 0x6A),
            Self::Faint => (0x4A, 0x44, 0x40),
        }
    }

    /// The nearest colour in the 256-colour cube.
    const fn cube(self) -> u8 {
        match self {
            Self::Brand => 173,
            Self::Text => 253,
            Self::Dim => 245,
            Self::Ok => 72,
            Self::Warn => 179,
            Self::Bad => 167,
            Self::Faint => 238,
        }
    }
}

/// How this process may paint, decided once at startup.
#[derive(Debug, Clone, Copy)]
pub struct Caps {
    pub colour: bool,
    pub truecolor: bool,
    pub unicode: bool,
}

static CAPS: OnceLock<Caps> = OnceLock::new();

/// Fix the capabilities for the rest of the run. Later calls are ignored.
pub fn init(caps: Caps) {
    let _ = CAPS.set(caps);
}

fn caps() -> Caps {
    *CAPS.get_or_init(|| Caps {
        colour: false,
        truecolor: false,
        unicode: true,
    })
}

/// True when colour escapes are written at all.
#[must_use]
pub fn colour_on() -> bool {
    caps().colour
}

fn open(hue: Hue, bold: bool) -> String {
    let weight = if bold { "1;" } else { "" };
    if caps().truecolor {
        let (r, g, b) = hue.rgb();
        format!("\x1b[{weight}38;2;{r};{g};{b}m")
    } else {
        format!("\x1b[{weight}38;5;{}m", hue.cube())
    }
}

/// Wrap `text` in `hue` and close it again.
#[must_use]
pub fn paint(hue: Hue, text: &str) -> String {
    if !colour_on() || text.is_empty() {
        return text.to_owned();
    }
    format!("{}{text}\x1b[0m", open(hue, false))
}

/// Wrap `text` in `hue`, bold.
#[must_use]
pub fn bold(hue: Hue, text: &str) -> String {
    if !colour_on() || text.is_empty() {
        return text.to_owned();
    }
    format!("{}{text}\x1b[0m", open(hue, true))
}

/// Fit `text` into exactly `width` columns: truncated with an ellipsis, or padded.
#[must_use]
pub fn fit(text: &str, width: usize) -> String {
    let count = text.chars().count();
    if count > width {
        let mut cut: String = text.chars().take(width.saturating_sub(1)).collect();
        cut.push_str(g::ellipsis());
        cut
    } else {
        format!("{text}{}", " ".repeat(width - count))
    }
}

fn wide(text: &str) -> Vec<u16> {
    text.encode_utf16().chain(std::iter::once(0)).collect()
}

/// Read a NUL-terminated UTF-16 string. A null pointer reads as empty.
///
/// # Safety
/// `text` must be null or point at a NUL-terminated UTF-16 string.
unsafe fn from_wide(text: *const u16) -> String {
    if text.is_null() {
        return String::new();
    }
    let mut len = 0;
    // SAFETY: the caller promises a terminator; we stop at it.
    unsafe {
        while *text.add(len) != 0 {
            len += 1;
        }
        String::from_utf16_lossy(std::slice::from_raw_parts(text, len))
    }
}

/// Turn on ANSI escapes and UTF-8 for this console, set its title, and make Ctrl+C give the
/// cursor back. Returns whether escapes will be honoured.
pub fn prepare_console(title: &str) -> bool {
    unsafe extern "system" fn on_break(_kind: u32) -> i32 {
        print!("\x1b[0m\x1b[?25h");
        0
    }

    let title = wide(title);
    // SAFETY: plain console calls on our own handles with valid buffers.
    unsafe {
        SetConsoleOutputCP(65001);
        SetConsoleTitleW(title.as_ptr());
        SetConsoleCtrlHandler(Some(on_break), 1);
        let out = GetStdHandle(STD_OUTPUT_HANDLE);
        let mut mode: CONSOLE_MODE = 0;
        if GetConsoleMode(out, &raw mut mode) == 0 {
            return false;
        }
        SetConsoleMode(out, mode | ENABLE_VIRTUAL_TERMINAL_PROCESSING) != 0
    }
}

/// The visible width of the console window, if there is one.
#[must_use]
pub fn console_width() -> Option<usize> {
    // SAFETY: the struct is plain data and the handle is our own.
    unsafe {
        let mut info: CONSOLE_SCREEN_BUFFER_INFO = std::mem::zeroed();
        if GetConsoleScreenBufferInfo(GetStdHandle(STD_OUTPUT_HANDLE), &raw mut info) == 0 {
            return None;
        }
        usize::try_from(info.srWindow.Right - info.srWindow.Left + 1).ok()
    }
}

// ----------------------------------------------------------------- privilege

fn process_token(access: u32) -> Option<HANDLE> {
    let mut token: HANDLE = ptr::null_mut();
    // SAFETY: the out pointer is a local.
    let ok = unsafe { OpenProcessToken(GetCurrentProcess(), access, &raw mut token) };
    (ok != 0).then_some(token)
}

/// Is this process running elevated?
#[must_use]
pub fn is_elevated() -> bool {
    let Some(token) = process_token(TOKEN_QUERY) else {
        return false;
    };
    let mut elevation = TOKEN_ELEVATION { TokenIsElevated: 0 };
    let mut size = 0;
    // SAFETY: the buffer is exactly a TOKEN_ELEVATION and the token is ours to close.
    unsafe {
        let ok = GetTokenInformation(
            token,
            TokenElevation,
            (&raw mut elevation).cast(),
            u32::try_from(size_of::<TOKEN_ELEVATION>()).unwrap_or(0),
            &raw mut size,
        );
        CloseHandle(token);
        ok != 0 && elevation.TokenIsElevated != 0
    }
}

/// Enable `SeDebugPrivilege`, which recent Windows builds require before
/// `EnumDeviceDrivers` will hand out kernel addresses.
pub fn enable_debug_privilege() -> bool {
    let Some(token) = process_token(TOKEN_ADJUST_PRIVILEGES | TOKEN_QUERY) else {
        return false;
    };
    let name = wide("SeDebugPrivilege");
    // SAFETY: every pointer is to a local, and the token is closed on the way out.
    unsafe {
        let mut luid = LUID {
            LowPart: 0,
            HighPart: 0,
        };
        let mut ok = LookupPrivilegeValueW(ptr::null(), name.as_ptr(), &raw mut luid) != 0;
        if ok {
            let privileges = TOKEN_PRIVILEGES {
                PrivilegeCount: 1,
                Privileges: [LUID_AND_ATTRIBUTES {
                    Luid: luid,
                    Attributes: SE_PRIVILEGE_ENABLED,
                }],
            };
            ok = AdjustTokenPrivileges(
                token,
                0,
                &raw const privileges,
                0,
                ptr::null_mut(),
                ptr::null_mut(),
            ) != 0
                && GetLastError() == 0;
        }
        CloseHandle(token);
        ok
    }
}

/// Relaunch this executable elevated through UAC with `args`. True when the new process
/// was started, false when the user declined or it could not be launched.
#[must_use]
pub fn relaunch_elevated(args: &str) -> bool {
    let Ok(exe) = std::env::current_exe() else {
        return false;
    };
    let verb = wide("runas");
    let file = wide(&exe.to_string_lossy());
    let params = wide(args);
    // SAFETY: all strings are NUL-terminated locals.
    let code = unsafe {
        ShellExecuteW(
            ptr::null_mut(),
            verb.as_ptr(),
            file.as_ptr(),
            params.as_ptr(),
            ptr::null(),
            SW_SHOWNORMAL,
        )
    };
    code as usize > 32
}

// ------------------------------------------------------------ kernel modules

/// Every module mapped in kernel memory.
#[must_use]
pub fn kernel_modules() -> Vec<Module> {
    let mut list = Vec::new();
    let mut addresses: Vec<*mut c_void> = vec![ptr::null_mut(); 4096];
    let mut needed = 0u32;

    // SAFETY: the buffer size passed is the buffer's size in bytes.
    unsafe {
        let bytes = |v: &Vec<*mut c_void>| {
            u32::try_from(v.len() * size_of::<*mut c_void>()).unwrap_or(u32::MAX)
        };
        if EnumDeviceDrivers(addresses.as_mut_ptr(), bytes(&addresses), &raw mut needed) == 0 {
            return list;
        }
        let mut count = needed as usize / size_of::<*mut c_void>();
        if count > addresses.len() {
            addresses = vec![ptr::null_mut(); count + 64];
            if EnumDeviceDrivers(addresses.as_mut_ptr(), bytes(&addresses), &raw mut needed) == 0 {
                return list;
            }
            count = (needed as usize / size_of::<*mut c_void>()).min(addresses.len());
        }

        let mut base = [0u16; 260];
        let mut file = [0u16; 1024];
        for &address in &addresses[..count] {
            if address.is_null() {
                continue;
            }
            let n = GetDeviceDriverBaseNameW(address, base.as_mut_ptr(), 260);
            if n == 0 {
                continue;
            }
            let f = GetDeviceDriverFileNameW(address, file.as_mut_ptr(), 1024);
            list.push(Module {
                base: String::from_utf16_lossy(&base[..n as usize]),
                path: String::from_utf16_lossy(&file[..f as usize]),
            });
        }
    }
    list
}

// ------------------------------------------------------- service control manager

struct Scm(SC_HANDLE);

impl Scm {
    fn open() -> Option<Self> {
        // SAFETY: null machine and database mean the local SCM.
        let handle = unsafe {
            OpenSCManagerW(
                ptr::null(),
                ptr::null(),
                SC_MANAGER_CONNECT | SC_MANAGER_ENUMERATE_SERVICE,
            )
        };
        (!handle.is_null()).then_some(Self(handle))
    }

    /// `(name, display name, current state)` for every service of `kind`.
    fn enumerate(&self, kind: u32) -> Vec<(String, String, u32)> {
        let mut out = Vec::new();
        // u64 storage keeps the entries aligned.
        let mut buffer: Vec<u64> = vec![0; 8 * 1024];
        let mut resume = 0u32;
        loop {
            let mut needed = 0u32;
            let mut returned = 0u32;
            // SAFETY: the buffer and its length agree; entries are read only up to `returned`.
            unsafe {
                let ok = EnumServicesStatusExW(
                    self.0,
                    SC_ENUM_PROCESS_INFO,
                    kind,
                    SERVICE_STATE_ALL,
                    buffer.as_mut_ptr().cast(),
                    u32::try_from(buffer.len() * 8).unwrap_or(u32::MAX),
                    &raw mut needed,
                    &raw mut returned,
                    &raw mut resume,
                    ptr::null(),
                );
                let more = ok == 0 && GetLastError() == ERROR_MORE_DATA;
                if ok == 0 && !more {
                    break;
                }
                let entries = buffer.as_ptr().cast::<ENUM_SERVICE_STATUS_PROCESSW>();
                for i in 0..returned as usize {
                    let entry = &*entries.add(i);
                    out.push((
                        from_wide(entry.lpServiceName),
                        from_wide(entry.lpDisplayName),
                        entry.ServiceStatusProcess.dwCurrentState,
                    ));
                }
                if !more {
                    break;
                }
                if needed as usize > buffer.len() * 8 {
                    buffer = vec![0; (needed as usize).div_ceil(8)];
                }
            }
        }
        out
    }

    /// `(binary path, start type, description)` for one service.
    fn config(&self, name: &str) -> (String, u32, String) {
        let name = wide(name);
        // SAFETY: buffers are sized from the first call's answer and outlive every read.
        unsafe {
            let service = OpenServiceW(self.0, name.as_ptr(), SERVICE_QUERY_CONFIG);
            if service.is_null() {
                return (String::new(), u32::MAX, String::new());
            }
            let mut path = String::new();
            let mut start = u32::MAX;
            let mut description = String::new();

            let mut needed = 0u32;
            QueryServiceConfigW(service, ptr::null_mut(), 0, &raw mut needed);
            if GetLastError() == ERROR_INSUFFICIENT_BUFFER && needed > 0 {
                // u64 storage keeps the struct aligned.
                let mut buffer = vec![0u64; (needed as usize).div_ceil(8)];
                let config = buffer.as_mut_ptr().cast::<QUERY_SERVICE_CONFIGW>();
                if QueryServiceConfigW(service, config, needed, &raw mut needed) != 0 {
                    path = from_wide((*config).lpBinaryPathName);
                    start = (*config).dwStartType;
                }
            }

            needed = 0;
            QueryServiceConfig2W(
                service,
                SERVICE_CONFIG_DESCRIPTION,
                ptr::null_mut(),
                0,
                &raw mut needed,
            );
            if GetLastError() == ERROR_INSUFFICIENT_BUFFER && needed > 0 {
                let mut buffer = vec![0u64; (needed as usize).div_ceil(8)];
                let info = buffer.as_mut_ptr().cast::<SERVICE_DESCRIPTIONW>();
                if QueryServiceConfig2W(
                    service,
                    SERVICE_CONFIG_DESCRIPTION,
                    info.cast(),
                    needed,
                    &raw mut needed,
                ) != 0
                {
                    description = from_wide((*info).lpDescription);
                }
            }

            CloseServiceHandle(service);
            (path, start, description)
        }
    }
}

impl Drop for Scm {
    fn drop(&mut self) {
        // SAFETY: the handle came from OpenSCManagerW and is closed once.
        unsafe {
            CloseServiceHandle(self.0);
        }
    }
}

/// Every kernel and file-system driver service, the way `sc query type= driver` lists them.
#[must_use]
pub fn driver_services() -> Vec<Driver> {
    let Some(scm) = Scm::open() else {
        return Vec::new();
    };
    scm.enumerate(SERVICE_DRIVER)
        .into_iter()
        .map(|(name, display, state)| {
            let (path, start, description) = scm.config(&name);
            Driver {
                name,
                display,
                description,
                path,
                start: start_name(start),
                state: state_name(state),
            }
        })
        .collect()
}

/// Every user-mode service.
#[must_use]
pub fn user_services() -> Vec<Service> {
    let Some(scm) = Scm::open() else {
        return Vec::new();
    };
    scm.enumerate(SERVICE_WIN32)
        .into_iter()
        .map(|(name, _, state)| Service {
            name,
            state: state_name(state),
        })
        .collect()
}

fn registry_string(key: &str, value: &str) -> Option<String> {
    let key = wide(key);
    let value = wide(value);
    let mut buffer = [0u16; 256];
    let mut size = u32::try_from(size_of_val(&buffer)).unwrap_or(0);
    // SAFETY: the buffer and its size in bytes agree.
    let status = unsafe {
        RegGetValueW(
            HKEY_LOCAL_MACHINE,
            key.as_ptr(),
            value.as_ptr(),
            RRF_RT_REG_SZ,
            ptr::null_mut(),
            buffer.as_mut_ptr().cast(),
            &raw mut size,
        )
    };
    if status != 0 {
        return None;
    }
    let chars = (size as usize / 2).saturating_sub(1).min(buffer.len());
    Some(String::from_utf16_lossy(&buffer[..chars]))
}

/// "Windows 11 Enterprise (26200)".
#[must_use]
pub fn os_caption() -> String {
    const KEY: &str = r"SOFTWARE\Microsoft\Windows NT\CurrentVersion";
    let mut product = registry_string(KEY, "ProductName").unwrap_or_else(|| "Windows".to_owned());
    let build = registry_string(KEY, "CurrentBuildNumber").unwrap_or_default();
    // Windows 11 still calls itself Windows 10 in ProductName; the build number does not lie.
    if build.parse::<u32>().is_ok_and(|b| b >= 22000) {
        product = product.replace("Windows 10", "Windows 11");
    }
    if build.is_empty() {
        product
    } else {
        format!("{product} {build}")
    }
}

/// The local wall-clock time, `yyyy-mm-dd hh:mm:ss`.
#[must_use]
pub fn local_time() -> String {
    // SAFETY: SYSTEMTIME is plain data filled in by the call.
    let t: SYSTEMTIME = unsafe {
        let mut t = std::mem::zeroed();
        GetLocalTime(&raw mut t);
        t
    };
    format!(
        "{:04}-{:02}-{:02} {:02}:{:02}:{:02}",
        t.wYear, t.wMonth, t.wDay, t.wHour, t.wMinute, t.wSecond
    )
}
