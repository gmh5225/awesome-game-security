`ARCHITECTURE.md`:

```md
# Architecture

## Rules (do not break these)

1. **Checks never register Bukkit listeners or packet listeners.** Only classes in `listener/` do that.
2. **There is one dispatch path:** listener, then update the shared tracker state *once*, then build an
   immutable update object, then `PlayerData.handleX(update)`, then the checks that implement the matching
   handler interface.
3. **Checks never receive Bukkit `Event` objects.** They receive the plugin's own update records (`MoveUpdate`,
   `AttackUpdate`, ...), so the input source can later change from Bukkit events to packets
   without touching any check.
4. **Every player gets their own instance of every check.** A check keeps its state in plain instance
   fields. No `Map<UUID, ...>` inside checks.
5. **A check only detects and calls `flag(debug)`.** It never kicks, bans, broadcasts or runs commands.
   That is all `ViolationHandler`'s job.
6. **Exemptions are handled centrally** in `PlayerData` / `ExemptionManager`, never duplicated across checks.
7. **Thread safety:** check logic must be pure computation on the plugin's own data. Any Bukkit API call with
   side effects (kick, dispatch command, send message) is scheduled onto the main thread by
   `ViolationHandler` (through `util/MainThread`).
8. **Adding a new check means:** one new class annotated with `@CheckInfo`, implementing one or more handler
   interfaces, plus one line in `CheckRegistry`. Nothing else should need to change.

## Dispatch flow

```
PlayerMoveEvent ──► MovementListener
                      │ exemptions().refresh(player)        (live states: game mode, flight, elytra, ...)
                      │ movement().process(from, to, tick)  (tracker updated once, world scanned once)
                      ▼
                    MoveUpdate (immutable record)
                      │
                      ▼
                    PlayerData.handleMove(update) ──► each active MovementHandler check (own try/catch)
                      │
                      ▼
                    exemptions().consumeMove()          (ends move limited exemptions, such as teleports)

VehicleMoveEvent ──► MovementListener ──► movement().processVehicleMove(...)   (riders get no move event)

PrePlayerAttackEntityEvent ──► CombatListener          (real attacks only, not plugin damage)
                      │ combat().process(target, now, tick)
                      ▼
                    AttackUpdate ──► PlayerData.handleAttack(update) ──► each CombatHandler check

Scheduler, every tick ──► PlayerDataManager.tick() ──► refresh exemptions, PlayerData.handleTick()
Scheduler, every 20 ticks ──► PlayerDataManager.secondTick() ──► permission cache, debug session permission,
                                                                  VL decay, saved VL pruning

Check.flag(debug)
  │ ignored if disabled, exempt for the check's category, or bypass
  ▼
Violation (record) ──► ViolationHandler.handle
                         ├─ main thread: AlertManager (rate limited, staff with alerts on)
                         ├─ main thread, next tick: PunishmentManager (commands of crossed thresholds)
                         └─ log thread:  ViolationLog (bounded queue, rotated violations.log)
```

Punishments always run on a later tick: a kick fires `PlayerQuitEvent` at once, and must not drop the player's
data while their checks are still running. Once a player quits, their `PlayerData` is marked removed: dispatch
stops and later flags are discarded.

## Player lifecycle

`PlayerDataManager.create` (join, or plugin enable for players already online) builds the data, applies the join
exemption and restores the VL saved when the player last left, minus the decay they would have had online.
`remove` (quit) marks the data removed and saves the VL. Saved VL is forgotten once fully decayed, or after
30 minutes.

## Packages

| Package         | Contents                                                                     |
|-----------------|------------------------------------------------------------------------------|
| `check`         | `Check` base class, `@CheckInfo`, `CheckCategory`, `CheckRegistry`           |
| `check.handler` | `MovementHandler`, `CombatHandler`, `TickHandler`                            |
| `check.impl`    | the checks                                                                   |
| `data`          | `PlayerData`, `PlayerDataManager`, `ExemptionManager`, `ExemptType`          |
| `data.tracker`  | `MovementTracker`, `CombatTracker`: shared state, updated once per event     |
| `update`        | immutable inputs of the checks (`MoveUpdate`, `AttackUpdate`, `Vec3`, `Box`) |
| `listener`      | the only Bukkit listeners                                                    |
| `violation`     | `Violation`, `ViolationHandler`, `AlertManager`, `PunishmentManager`         |
| `config`        | `PluginConfig`, `CheckConfig` records, `ConfigManager` (reload)              |
| `command`       | `/ac`                                                                        |
| `util`          | `MathUtil` (pure), `LocationUtil` (world queries, main thread), `MainThread` |

## Exemptions

`ExemptionManager` combines timed exemptions (join, teleport, velocity, world change, game mode change) with
live ones (creative/spectator, flying, gliding, vehicle, swimming, riptide). Live states are snapshotted on the
main thread before every move and every tick, and each keeps a short grace period after it ends.

- Teleports and respawns exempt only the next few moves (at most 1 second), so chained ender pearls do not keep a
  player exempt.
- Velocity (`PlayerVelocityEvent`, and Paper's `EntityKnockbackEvent` for explosion and wind charge knockback,
  which sends no velocity event) exempts for an estimate of how long that velocity lasts: airtime plus ground
  friction plus latency, between 250 ms and 3 s.

Each `CheckCategory` maps to a set of exemptions: movement and player checks honour all of them, combat checks
only join, teleport, world change and game mode (otherwise every hit taken would exempt the attacker).

## Error isolation

`PlayerData` calls each check in its own try/catch. A check that throws is logged once with its id and stack
trace, then turned off for that player only. The others keep running.

## Moving to packets (phase 7)

Only listeners and trackers change: a packet listener builds the same `MoveUpdate`. If a check would have to
change, the update record is missing something; fix the record instead. Packet listeners run off the main
thread, so world reads (`LocationUtil`), `ExemptionManager.refresh` and check state (`vl`, `buffer`) need
revisiting against rule 7.

`README.md`:

```md
# AntiCheat

A small, modular anticheat core for Paper 26.3 (Java 25). It ships three conservative reference checks (`SpeedA`,
`FlyA`, `ReachA`) and a framework that makes adding more checks a one class job.

See [ARCHITECTURE.md](ARCHITECTURE.md) for the design rules every contribution must follow.

## Build

```sh
./gradlew build
```

The plugin jar is written to `build/libs/AntiCheat-<version>.jar`. The build also runs the unit tests (JUnit 5) in
`src/test`.

Requirements: nothing to install. Gradle downloads a Java 25 toolchain if none is found.

## Run a test server

```sh
./gradlew runServer
```

This downloads Paper 26.3, starts it in `run/` with the plugin installed and the EULA accepted.
Join on `localhost:25565`, then `op` yourself from the console.

Useful in game:

| Command                                    | What it does                                                         |
|--------------------------------------------|----------------------------------------------------------------------|
| `/ac`                                      | Clickable help                                                       |
| `/ac alerts`                               | Toggle your own alerts (on by default with `anticheat.alerts`)       |
| `/ac info <player>`                        | Show VL, buffer and state of every check for that player             |
| `/ac debug <player>`                       | Clickable menu of that player's checks, click one to toggle it       |
| `/ac debug <player> <checkId>`             | Toggle streaming that check's per-move values and flags to you       |
| `/ac debug <player> <category\|all>`       | Start every check in that category (or all), again to stop them      |
| `/ac debug <player> off`                   | Stop debugging that player                                           |
| `/ac debug`                                | List who you are debugging, with stop buttons                        |
| `/ac debug stop-all`                       | Stop all your debug streams                                          |
| `/ac reload`                               | Re-read `config.yml` and update enabled flags without rejoining      |

`/ac` is a Brigadier command: tab shows every check with its description, `<player>` accepts selectors
such as `@s`, and a wrong check name gets a clear error. You can watch several checks at once,
and several staff members can debug the same player independently. While you have at least one debug stream
open you are not punished (you still flag, alert and get logged), so you can test cheats on yourself with `@s`.
A threshold you cross meanwhile runs on your next flag after you stop, if your VL is still above it.
Debugging needs `anticheat.debug`, and losing it closes your sessions within a second. Only players and the
console can debug.

`/ac reload` keeps the previous config when `config.yml` has a YAML error, and lists problems such as unknown
check ids or values of the wrong type.

To see a check fire without a cheat client, cheat with vanilla tools the checks do not account for, for example
`/attribute @s minecraft:movement_speed base set 0.3` for `SpeedA` (the check uses vanilla base speed plus the
Speed effect, not the attribute). `FlyA` and `ReachA` need a modified client, or `/ac debug` to watch the
values they compute while you play normally.

Violations are appended to `run/plugins/AntiCheat/violations.log`, rotated to `violations.log.1` to `.3` every 10 MB.

A player's VL is kept when they leave and restored when they rejoin (minus the decay they would have had
online), so relogging does not reset it. It is not kept across a server restart.

## Permissions

| Permission          | Default | Meaning                                                    |
|---------------------|---------|------------------------------------------------------------|
| `anticheat.command` | op      | Use `/ac`                                                  |
| `anticheat.debug`   | op      | Use `/ac debug` (not punished while a session is open)     |
| `anticheat.alerts`  | op      | Receive alerts                                             |
| `anticheat.bypass`  | false   | Never flagged                                              |

## Configuration

`plugins/AntiCheat/config.yml` is generated on first start with comments. Per check:

```yaml
checks:
  SpeedA:
    enabled: true
    punishments:
      10: "kick %player% Unfair advantage"   # runs once each time the VL goes past 10
```

A check without a section is enabled and never punishes. Check ids are not case sensitive, and thresholds must be
1 or more.

## How to add a new check

1. Create one class under `check/impl/<category>/`, annotated with `@CheckInfo`, extending `Check` and
   implementing one or more handler interfaces (`MovementHandler`, `CombatHandler`, `TickHandler`).
2. Add one line to `CheckRegistry.defaults()`.
3. Optionally add a section to `config.yml` (punishments).

Nothing else changes: no listener, no registration, no map of players. Every player gets their own instance,
so plain fields are per-player state.

Complete example, a check that flags players who jump higher than vanilla allows:

```java
package me.raph.anticheat.check.impl.movement;

import java.util.Locale;
import me.raph.anticheat.check.Check;
import me.raph.anticheat.check.CheckCategory;
import me.raph.anticheat.check.CheckInfo;
import me.raph.anticheat.check.handler.MovementHandler;
import me.raph.anticheat.data.PlayerData;
import me.raph.anticheat.update.MoveUpdate;

@CheckInfo(name = "Jump", type = "A", category = CheckCategory.MOVEMENT,
        description = "Jumps higher than vanilla", experimental = true)
public final class JumpA extends Check implements MovementHandler {

    /** Vanilla jump velocity, plus 0.1 per Jump Boost level. */
    private static final double JUMP_VELOCITY = 0.42;

    public JumpA(PlayerData data) {
        super(data);
    }

    @Override
    public void handleMove(MoveUpdate update) {
        // Only the move that leaves the ground, and never while exempt (teleport, velocity, flight...).
        if (isExempt() || !update.lastOnGround() || update.onGround() || update.deltaY() <= 0) {
            return;
        }
        double limit = JUMP_VELOCITY + 0.1 * update.environment().jumpBoostLevel() + 0.01;
        if (isDebugging()) {
            debug(String.format(Locale.ROOT, "dy=%.4f limit=%.4f", update.deltaY(), limit));
        }

        if (update.deltaY() > limit && update.environment().ticksSinceStep() > 10) {
            if (increaseBuffer(1.0)) {
                flag(String.format(Locale.ROOT, "dy=%.3f limit=%.3f", update.deltaY(), limit));
            }
        } else {
            decreaseBuffer(0.25);
        }
    }
}
```

Then in `CheckRegistry`:

```java
return new CheckRegistry(List.of(
        SpeedA::new,
        FlyA::new,
        ReachA::new,
        JumpA::new
));
```

Its id is `JumpA` (name + type): that is the `config.yml` key and the name used by `/ac debug`.

Tips:

- Need data that is not in the update record? Add a field to `MoveUpdate` / `AttackUpdate` and fill it in the
  tracker or listener. Never read Bukkit state from a check.
- Call `isExempt()` first so the buffer does not fill while the player is exempt.
- Use the buffer for anything noisy. Prefer missing a cheater over flagging a legit player.
- `flag()` only reports. Kicking and banning are configured as punishments.

    for arg do

              -*)   false ;;                            # don't mess with options #(
              /?*)  t=${arg#/} t=/${t%%/*}              # looks like a POSIX filepath
                    [ -e "$t" ] ;;                      #(
              *)    false ;;
            esac
        then
            arg=$( cygpath --path --ignore --mixed "$arg" )
        fi
        # Roll the args list around exactly as many times as the number of
        # args, so each arg winds up back in the position where it started, but
        # possibly modified.
        #
        # NB: a `for` loop captures its iteration list before it begins, so
        # changing the positional parameters here affects neither the number of
        # iterations, nor the values presented in `arg`.
        shift                   # remove old arg
        set -- "$@" "$arg"      # push replacement arg
    done
fi

DEFAULT_JVM_OPTS='"-Xmx64m" "-Xms64m"'

#   * DEFAULT_JVM_OPTS, JAVA_OPTS, and optsEnvironmentVar are not allowed to contain shell fragments,
#     and any embedded shellness will be escaped.
#   * For example: A user cannot expect ${Hostname} to be expanded, as it is an environment variable and will be
#     treated as '${Hostname}' itself on the command line.

set -- \
        "-Dorg.gradle.appname=$APP_BASE_NAME" \

# Use "xargs" to parse quoted args.
#
# With -n1 it outputs one arg per line, with the quotes and backslashes removed.
#
# In Bash we could simply go:
#
#   readarray ARGS < <( xargs -n1 <<<"$var" ) &&
#   set -- "${ARGS[@]}" "$@"
#
# but POSIX shell has neither arrays nor command substitution, so instead we
# post-process each arg (as a line of input to sed) to backslash-escape any
# character that might be a shell metacharacter, then use eval to reverse
# that process (while maintaining the separation between arguments), and wrap
# the whole thing up as a single "set" statement.
#
# This will of course break if any of these variables contains a newline or
# an unmatched quote.
#

eval "set -- $(
        printf '%s\n' "$DEFAULT_JVM_OPTS $JAVA_OPTS $GRADLE_OPTS" |
        xargs -n1 |
        sed ' s~[^-[:alnum:]+,./:=@_]~\\&~g; ' |
        tr '\n' ' '

package me.raph.anticheat;

import io.papermc.paper.plugin.lifecycle.event.types.LifecycleEvents;
import me.raph.anticheat.check.CheckRegistry;
import me.raph.anticheat.command.AntiCheatCommand;
import me.raph.anticheat.config.ConfigManager;
import me.raph.anticheat.data.PlayerDataManager;
import me.raph.anticheat.listener.CombatListener;
import me.raph.anticheat.listener.ConnectionListener;
import me.raph.anticheat.listener.ExemptionListener;
import me.raph.anticheat.listener.MovementListener;
import me.raph.anticheat.violation.AlertManager;

import org.bukkit.entity.Player;
import org.bukkit.plugin.PluginManager;
import org.bukkit.plugin.java.JavaPlugin;

/**
 * Plugin entry point. Only builds and wires the managers, no logic lives here.
 */
public final class AntiCheatPlugin extends JavaPlugin {

    private PlayerDataManager dataManager;
    private ViolationHandler violationHandler;

    @Override
    public void onEnable() {
        CheckRegistry registry = CheckRegistry.defaults();
        ConfigManager config = new ConfigManager(this, registry.ids());
        AlertManager alerts = new AlertManager(this, config::get);
        PunishmentManager punishments = new PunishmentManager(this, config::get,
                uuid -> dataManager != null && dataManager.isDebugViewer(uuid));
        violationHandler = new ViolationHandler(this, config::get, alerts, punishments);
        dataManager = new PlayerDataManager(this, config::get, violationHandler::handle, registry);

        PluginManager plugins = getServer().getPluginManager();
        plugins.registerEvents(new ConnectionListener(dataManager, alerts, punishments), this);
        plugins.registerEvents(new MovementListener(dataManager), this);
        plugins.registerEvents(new CombatListener(dataManager), this);
        plugins.registerEvents(new ExemptionListener(dataManager), this);

        AntiCheatCommand command = new AntiCheatCommand(dataManager, alerts, config);
        getLifecycleManager().registerEventHandler(LifecycleEvents.COMMANDS,
                event -> event.registrar().register(command.build(), "AntiCheat management command"));

        // Players already online after a reload.
        for (Player player : getServer().getOnlinePlayers()) {
            dataManager.create(player);
        }

        getServer().getScheduler().runTaskTimer(this, dataManager::tick, 1L, 1L);
        getServer().getScheduler().runTaskTimer(this, dataManager::secondTick, 20L, 20L);
    }

    @Override
    public void onDisable() {
        if (violationHandler != null) {
            violationHandler.shutdown();
        }
        if (dataManager != null) {
            dataManager.clear();
        }
    }
}

package me.raph.anticheat.check;

import me.raph.anticheat.data.PlayerData;
import me.raph.anticheat.violation.Violation;

import java.util.Objects;

/**
 * Base class of every check.
 *
 * <h2>How to write a check</h2>
 * <ol>
 *   <li>Create a {@code final} class extending {@code Check}, annotated with {@link CheckInfo}.</li>
 *   <li>Implement one or more handler interfaces ({@link me.raph.anticheat.check.handler.MovementHandler},
 *       {@link me.raph.anticheat.check.handler.CombatHandler}, {@link me.raph.anticheat.check.handler.TickHandler}).
 *       The framework finds them with {@code instanceof}, no registration needed.</li>
 *   <li>Add a public constructor taking a {@link PlayerData} and calling {@code super(data)}.</li>
 *   <li>Add one line to {@link CheckRegistry#defaults()}.</li>
 * </ol>
 *
 * <h2>Rules</h2>
 * <ul>
 *   <li>One instance exists per player, so keep per-player state in plain instance fields.
 *       Never use a {@code Map<UUID, ...>} inside a check.</li>
 *   <li>Only use the data in the update records and in {@link PlayerData}. Never call Bukkit APIs
 *       with side effects, and never register listeners.</li>
 *   <li>Only detect. Call {@link #flag(String)} when the player cheats; kicking, alerting and logging
 *       are done by the violation pipeline.</li>
 *   <li>Exemptions are handled centrally. Call {@link #isExempt()} to skip work (and avoid filling the
 *       buffer) while the player is exempt; {@link #flag(String)} also ignores flags while exempt.</li>
 *   <li>Prefer missed detections over false flags. Use the buffer for anything that can be noisy.</li>
 * </ul>
 */
public abstract class Check {

    private final PlayerData data;
    private final CheckInfo info;
    private final String id;

    // TODO(decision): vl and buffer are plain fields because all dispatch currently happens on the
    // main thread. If dispatch moves to packet threads (phase 7), make them thread-confined or atomic.
    private double vl;
    private double buffer;
    private volatile boolean enabled;
    private volatile boolean failed;

    /**
     * @param data the player this instance belongs to
     * @throws IllegalStateException if the subclass has no {@link CheckInfo} annotation
     */
    protected Check(PlayerData data) {
        this.data = Objects.requireNonNull(data, "data");
        this.info = infoOf(getClass());
        this.id = info.name() + info.type();
        this.enabled = data.config().check(id).enabled();
    }

    public static String idOf(Class<? extends Check> type) {
        CheckInfo info = infoOf(type);
        return info.name() + info.type();
    }

    private static CheckInfo infoOf(Class<?> type) {
        CheckInfo annotation = type.getAnnotation(CheckInfo.class);
        if (annotation == null) {
            throw new IllegalStateException(type.getName() + " is missing the @CheckInfo annotation");
        }
        return annotation;
    }

    /**
     * Adds to the buffer, capped at {@code maxBuffer * 2}.
     *
     * @return {@code true} when the buffer is now above {@link CheckInfo#maxBuffer()}
     */
    protected final boolean increaseBuffer(double amount) {
        buffer = Math.min(info.maxBuffer() * 2.0, buffer + amount);
        return buffer > info.maxBuffer();
    }

    /**
     * Removes from the buffer, never going below zero.
     */
    protected final void decreaseBuffer(double amount) {
        buffer = Math.max(0.0, buffer - amount);
    }

    /**
     * Reports a violation. Does nothing if the check is disabled, the player is exempt for this
     * check's category, or the player has the {@code anticheat.bypass} permission. Otherwise the
     * VL goes up by one and a {@link Violation} goes to the violation pipeline.
     *
     * @param debug short explanation with the values that caused the flag, shown in alerts and logs
     */
    protected final void flag(String debug) {
        if (!enabled) {
            return;
        }
        if (isExempt()) {
            debug("flag ignored (exempt): " + debug);
            return;
        }
        if (data.hasBypass()) {
            debug("flag ignored (bypass): " + debug);
            return;
        }
        double previousVl = vl;
        vl += 1.0;
        debug("FLAG x" + vl + ": " + debug);
        data.reportViolation(new Violation(
                data.uuid(),
                data.name(),
                id,
                info.category(),
                info.experimental(),
                previousVl,
                vl,
                debug,
                System.currentTimeMillis()));
    }

    /**
     * Sends a debug line to whoever runs {@code /ac debug <player> <thisCheckId>}. Cheap when nobody
     * is debugging, but avoid building expensive strings on every update anyway.
     */
    protected final void debug(String message) {
        data.debug(this, message);
    }

    /**
     * Whether someone is debugging this check on this player. Use it to skip building debug strings.
     */
    protected final boolean isDebugging() {
        return data.isDebugging(this);
    }

    /**
     * Whether the player is currently exempt for this check's category.
     */
    protected final boolean isExempt() {
        return data.exemptions().isExempt(info.category());
    }

    /**
     * The player this check instance belongs to.
     */
    protected final PlayerData data() {
        return data;
    }

    /**
     * Lowers the VL by {@code amount}, never going below zero. Called by the decay task.
     */
    public final void decayVl(double amount) {
        vl = Math.max(0.0, vl - amount);
    }

    public final void restoreVl(double restored) {
        vl = Math.max(0.0, restored);
    }

    /**
     * {@code name + type}, for example {@code "SpeedA"}. Used as config key and in the UI.
     */
    public final String id() {
        return id;
    }

    public final CheckInfo info() {
        return info;
    }

    public final double vl() {
        return vl;
    }

    public final double buffer() {
        return buffer;
    }

    public final boolean isEnabled() {
        return enabled;
    }

    /**
     * Called on config reload.
     */
    public final void setEnabled(boolean enabled) {
        this.enabled = enabled;
    }

    /**
     * Whether this instance was turned off after throwing an exception.
     */
    public final boolean hasFailed() {
        return failed;
    }

    /**
     * Turns this instance off for the rest of the session. Called by {@link PlayerData} after an exception.
     */
    public final void markFailed() {
        this.failed = true;
    }

    /**
     * Whether updates should be dispatched to this instance.
     */
    public final boolean isActive() {
        return enabled && !failed;
    }
}

package me.raph.anticheat.check;

import java.lang.annotation.*;

/**
 * Describes a check. Every concrete {@link Check} subclass must carry this annotation,
 * otherwise its constructor throws {@link IllegalStateException}.
 *
 * <p>The check id is {@code name + type}, for example {@code @CheckInfo(name = "Speed", type = "A")}
 * gives the id {@code "SpeedA"}. The id is the key under {@code checks:} in {@code config.yml}
 * and the name shown in alerts and commands, so keep it stable once released.
 *
 * <pre>{@code
 * @CheckInfo(name = "Speed", category = CheckCategory.MOVEMENT,
 *            description = "Horizontal speed on the ground")
 * public final class SpeedA extends Check implements MovementHandler { ... }
 * }</pre>
 */
@Documented
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.TYPE)
public @interface CheckInfo {

    /**
     * Name of the check family, for example {@code "Speed"}.
     */
    String name();

    /**
     * Variant letter inside the family, for example {@code "A"}, {@code "B"}.
     */
    String type() default "A";

    /**
     * Category, which also selects the exemptions that apply.
     */
    CheckCategory category();

    /**
     * One line, human readable explanation of what the check detects.
     */
    String description();

    /**
     * Buffer threshold. {@link Check#increaseBuffer(double)} returns {@code true} once the buffer
     * goes above this value. The buffer itself is capped at twice this value.
     */
    double maxBuffer() default 5.0;

    /**
     * Experimental checks still alert, but never trigger punishments.
     */
    boolean experimental() default false;
}

package me.raph.anticheat.check;

import me.raph.anticheat.check.impl.combat.ReachA;
import me.raph.anticheat.check.impl.movement.FlyA;
import me.raph.anticheat.check.impl.movement.SpeedA;
import me.raph.anticheat.data.PlayerData;

import java.util.ArrayList;
import java.util.Collections;
import java.util.HashSet;
import java.util.List;
import java.util.Locale;
import java.util.Set;
import java.util.function.Function;

/**
 * The list of every check. Each entry builds one check instance for one player.
 */
public final class CheckRegistry {

    private final List<Entry> entries;
    private final List<String> ids;

    CheckRegistry(List<Entry> entries) {
        this.entries = List.copyOf(entries);
        List<String> ids = new ArrayList<>(entries.size());
        Set<String> seen = new HashSet<>();
        for (Entry entry : this.entries) {
            String id = Check.idOf(entry.type());
            if (!seen.add(id.toLowerCase(Locale.ROOT))) {
                throw new IllegalStateException("Two checks share the id " + id);
            }
            ids.add(id);
        }
        this.ids = List.copyOf(ids);
    }

    /**
     * All checks shipped with the plugin. Add one line here per new check.
     */
    public static CheckRegistry defaults() {
        return new CheckRegistry(List.of(
                entry(SpeedA.class, SpeedA::new),
                entry(FlyA.class, FlyA::new),
                entry(ReachA.class, ReachA::new)
        ));
    }

    public static <T extends Check> Entry entry(Class<T> type, Function<PlayerData, T> factory) {
        return new Entry(type, factory);
    }

    /**
     * Builds a fresh instance of every check for {@code data}.
     */
    public List<Check> create(PlayerData data) {
        List<Check> checks = new ArrayList<>(entries.size());
        for (Entry entry : entries) {
            checks.add(entry.factory().apply(data));
        }
        return Collections.unmodifiableList(checks);
    }

    public List<String> ids() {
        return ids;
    }

    public List<Entry> entries() {
        return entries;
    }

    public record Entry(Class<? extends Check> type, Function<PlayerData, ? extends Check> factory) {
    }
}

package me.raph.anticheat.check.impl.combat;

import me.raph.anticheat.check.Check;
import me.raph.anticheat.check.CheckCategory;
import me.raph.anticheat.check.CheckInfo;
import me.raph.anticheat.check.handler.CombatHandler;
import me.raph.anticheat.data.PlayerData;
import me.raph.anticheat.update.AttackUpdate;
import me.raph.anticheat.update.Box;
import me.raph.anticheat.util.MathUtil;

import java.util.Locale;

/**
 * Melee attacks from further away than survival reach.
 *
 * <p>Measures from the attacker's eye to the closest point of the target's hitbox (grown by
 * {@value #HITBOX_EXPAND}, as the client does). The server sees the target slightly ahead of what the
 * attacker saw, so the limit grows with how fast both moved and with the attacker's ping. Creative and
 * spectator players are exempt through the central exemptions.
 */
@CheckInfo(name = "Reach", category = CheckCategory.COMBAT, description = "Attacks from too far away")
public final class ReachA extends Check implements CombatHandler {

    private static final double MAX_REACH = 3.1;
    private static final double HITBOX_EXPAND = 0.1;
    /**
     * Ping above this is treated as this, so very laggy players cannot get an unlimited allowance.
     */
    private static final int MAX_PING_MS = 500;
    private static final double MS_PER_TICK = 50.0;
    /**
     * The client draws other entities a couple of ticks behind their real position.
     */
    private static final double INTERPOLATION_TICKS = 2.0;

    private static final double BUFFER_DECAY = 0.5;

    public ReachA(PlayerData data) {
        super(data);
    }

    @Override
    public void handleAttack(AttackUpdate update) {
        if (isExempt()) {
            return;
        }
        Box box = update.targetBox().expand(HITBOX_EXPAND);
        double distance = MathUtil.distanceToBox(
                update.attackerEye().x(), update.attackerEye().y(), update.attackerEye().z(),
                box.minX(), box.minY(), box.minZ(), box.maxX(), box.maxY(), box.maxZ());

        double pingTicks = Math.min(update.attackerPingMs(), MAX_PING_MS) / MS_PER_TICK;
        double allowance = update.attackerMovement() + update.targetMovement() * (pingTicks + INTERPOLATION_TICKS);
        double limit = MAX_REACH + allowance;

        if (isDebugging()) {
            debug(String.format(Locale.ROOT, "distance=%.3f limit=%.3f ping=%d buffer=%.2f",
                    distance, limit, update.attackerPingMs(), buffer()));
        }

        if (distance > limit) {
            if (increaseBuffer(1.0)) {
                flag(String.format(Locale.ROOT, "distance=%.3f limit=%.3f ping=%d",
                        distance, limit, update.attackerPingMs()));
            }
        } else {
            decreaseBuffer(BUFFER_DECAY);
        }
    }

package me.raph.anticheat.check.impl.movement;

import me.raph.anticheat.check.Check;
import me.raph.anticheat.check.CheckCategory;
import me.raph.anticheat.check.CheckInfo;
import me.raph.anticheat.check.handler.MovementHandler;
import me.raph.anticheat.data.PlayerData;
import me.raph.anticheat.update.MoveUpdate;

import java.util.Locale;

/**
 * Vertical movement in the air that does not follow gravity.
 *
 * <p>After more than {@value #MIN_AIR_TICKS} moves in the air, vanilla vertical speed follows
 * {@code nextDeltaY = (lastDeltaY - 0.08) * 0.98} exactly. This check flags when the actual move is far
 * from that prediction, or when the player keeps hovering or rising without slowing down. Anything that
 * changes vertical physics (liquids, ladders, cobwebs, effects, slime, ceilings) is skipped, and the
 * buffer needs several bad moves in a row.
 */
@CheckInfo(name = "Fly", category = CheckCategory.MOVEMENT, description = "Moves in the air against gravity")
public final class FlyA extends Check implements MovementHandler {

    private static final int MIN_AIR_TICKS = 10;
    private static final double GRAVITY = 0.08;
    private static final double DRAG = 0.98;
    /**
     * Vanilla zeroes tiny motion.
     */
    private static final double MIN_MOTION = 0.003;
    private static final double GRAVITY_TOLERANCE = 0.05;

    /**
     * Moves in a row hovering or rising without slowing down before it counts as a failure.
     */
    private static final int HOVER_MOVES = 5;
    /**
     * A legit rise slows by about 0.08 per move; slowing by less than this counts as hovering.
     */
    private static final double HOVER_DECELERATION = 0.04;

    /**
     * Moves after leaving a liquid, climbable or cobweb, or after Slow Falling, before checking again.
     */
    private static final int BLOCK_GRACE = 10;
    /**
     * Levitation leaves upward motion behind for a while.
     */
    private static final int LEVITATION_GRACE = 20;
    /**
     * Hitting a ceiling cuts the vertical motion.
     */
    private static final int CEILING_GRACE = 2;

    private static final double BUFFER_DECAY = 0.25;

    private int hoverMoves;

    public FlyA(PlayerData data) {
        super(data);
    }

    /**
     * Anything around the player that legitimately changes vertical movement.
     */
    private static boolean hasOtherPhysics(MoveUpdate update) {
        MoveUpdate.Environment env = update.environment();
        return env.ticksSinceLiquid() <= BLOCK_GRACE
                || env.ticksSinceClimbable() <= BLOCK_GRACE
                || env.ticksSinceWeb() <= BLOCK_GRACE
                || env.ticksSinceSlowFalling() <= BLOCK_GRACE
                || env.ticksSinceLevitation() <= LEVITATION_GRACE
                || env.ticksSinceCeiling() <= CEILING_GRACE
                // Bounced off a slime block or bed at the start of this air time.
                || env.ticksSinceBounce() <= update.airTicks() + 1;
    }

    @Override
    public void handleMove(MoveUpdate update) {
        if (isExempt() || update.onGround() || update.airTicks() <= MIN_AIR_TICKS || hasOtherPhysics(update)) {
            hoverMoves = 0;
            decreaseBuffer(BUFFER_DECAY);
            return;
        }

        double predicted = (update.lastDeltaY() - GRAVITY) * DRAG;
        if (Math.abs(predicted) < MIN_MOTION) {
            predicted = 0.0;
        }
        double offset = update.deltaY() - predicted;
        boolean gravityFail = Math.abs(offset) > GRAVITY_TOLERANCE;

        boolean hovering = update.deltaY() >= 0.0 && update.deltaY() > update.lastDeltaY() - HOVER_DECELERATION;
        hoverMoves = hovering ? hoverMoves + 1 : 0;
        boolean hoverFail = hoverMoves >= HOVER_MOVES;

        if (isDebugging()) {
            debug(String.format(Locale.ROOT, "dy=%.4f predicted=%.4f offset=%.4f air=%d hover=%d buffer=%.2f",
                    update.deltaY(), predicted, offset, update.airTicks(), hoverMoves, buffer()));
        }

        if (gravityFail || hoverFail) {
            if (increaseBuffer(1.0)) {
                flag(String.format(Locale.ROOT, "dy=%.3f predicted=%.3f air=%d hover=%d",
                        update.deltaY(), predicted, update.airTicks(), hoverMoves));
            }
        } else {
            decreaseBuffer(BUFFER_DECAY);
        }
    }
}

package me.raph.anticheat.check.impl.movement;

import me.raph.anticheat.check.Check;
import me.raph.anticheat.check.CheckCategory;
import me.raph.anticheat.check.CheckInfo;
import me.raph.anticheat.check.handler.MovementHandler;
import me.raph.anticheat.data.PlayerData;
import me.raph.anticheat.update.MoveUpdate;

import java.util.Locale;

/**
 * Horizontal speed while walking on the ground.
 *
 * <p>Only moves that start and end on the ground (server side) are checked, so jumps and falls are
 * ignored. The limit is the vanilla sprinting speed, raised for Speed effects and multiplied by generous
 * allowances for situations that legitimately go faster. The buffer means one fast move never flags,
 * only a run of them.
 */
@CheckInfo(name = "Speed", category = CheckCategory.MOVEMENT, description = "Moves faster than possible on the ground")
public final class SpeedA extends Check implements MovementHandler {

    /**
     * Vanilla sprinting speed on a normal block, in blocks per move (5.612 m/s). Walking is 0.2158; the
     * sprint value is always used because the sprint state comes from the client.
     */
    private static final double BASE_SPEED = 0.28634;
    /**
     * Each Speed level adds 20 % movement speed.
     */
    private static final double SPEED_PER_LEVEL = 0.2;

    /**
     * Momentum from a jump is still there during the first ground moves after landing.
     */
    private static final int LANDING_MOVES = 6;
    private static final double LANDING_ALLOWANCE = 1.45;
    /**
     * Ice keeps momentum for a long time and sprint jumping on it goes much faster.
     */
    private static final int ICE_MOVES = 40;
    private static final double ICE_ALLOWANCE = 2.6;
    /**
     * Soul Speed boots make soul sand and soul soil faster, up to about +60 %.
     */
    private static final int SOUL_SAND_MOVES = 20;
    private static final double SOUL_SAND_ALLOWANCE = 1.7;
    /**
     * Running up stairs and slabs is a series of tiny jumps, each with the jump boost.
     */
    private static final int STEP_MOVES = 10;
    private static final double STEP_ALLOWANCE = 1.5;
    /**
     * Jumping under a low ceiling ("head hitters") repeats the jump boost every few moves.
     */
    private static final int CEILING_MOVES = 10;
    private static final double CEILING_ALLOWANCE = 1.5;

    private static final double BUFFER_DECAY = 0.1;

    public SpeedA(PlayerData data) {
        super(data);
    }

    private static double limit(MoveUpdate update) {
        MoveUpdate.Environment env = update.environment();
        double limit = BASE_SPEED * (1.0 + SPEED_PER_LEVEL * env.speedLevel());
        if (update.groundTicks() <= LANDING_MOVES) {
            limit *= LANDING_ALLOWANCE;
        }
        if (env.ticksSinceIce() <= ICE_MOVES) {
            limit *= ICE_ALLOWANCE;
        }
        if (env.ticksSinceSoulSand() <= SOUL_SAND_MOVES) {
            limit *= SOUL_SAND_ALLOWANCE;
        }
        if (env.ticksSinceStep() <= STEP_MOVES) {
            limit *= STEP_ALLOWANCE;
        }
        if (env.ticksSinceCeiling() <= CEILING_MOVES) {
            limit *= CEILING_ALLOWANCE;
        }
        return limit;
    }

    @Override
    public void handleMove(MoveUpdate update) {
        if (isExempt() || !update.onGround() || !update.lastOnGround()) {
            return;
        }
        double limit = limit(update);
        double speed = update.deltaXZ();

        if (isDebugging()) {
            debug(String.format(Locale.ROOT, "speed=%.4f limit=%.4f groundTicks=%d buffer=%.2f",
                    speed, limit, update.groundTicks(), buffer()));
        }

        if (speed > limit) {
            if (increaseBuffer(1.0)) {
                flag(String.format(Locale.ROOT, "speed=%.6f limit=%.6f", speed, limit));
            }
        } else {
            decreaseBuffer(BUFFER_DECAY);
        }
    }
}

    public static final String PERMISSION = Permissions.COMMAND;

            MessageComponentSerializer.message().serialize(Component.text("That player is not tracked by the anticheat.")));

            MessageComponentSerializer.message().serialize(Component.text(

    private final AlertManager alerts;

        this.dataManager = dataManager;

    // ---------------------------------------------------------------- tree

    public LiteralCommandNode<CommandSourceStack> build() {
        return Commands.literal(LABEL)
                .requires(source -> source.getSender().hasPermission(PERMISSION))
                .executes(ctx -> help(ctx.getSource().getSender()))
                .then(Commands.literal("help")
                        .executes(ctx -> help(ctx.getSource().getSender())))
                .then(Commands.literal("alerts")
                        .executes(ctx -> alerts(ctx.getSource().getSender())))
                .then(Commands.literal("info")
                        .then(Commands.argument("player", ArgumentTypes.player())
                                .executes(ctx -> info(ctx.getSource().getSender(), target(ctx)))))
                .then(Commands.literal("debug")
                        .requires(source -> source.getSender().hasPermission(Permissions.DEBUG))
                        .executes(ctx -> debugStatus(ctx.getSource().getSender()))
                        .then(Commands.literal(STOP_ALL)
                                .executes(ctx -> debugStopAll(ctx.getSource().getSender())))

    private int reload(CommandSender sender) {

            for (String warning : warnings) {

    /**
     * {@code /ac debug <player> <target>}. A check id toggles that check. A category or {@code all}
     * starts every matching check, or stops them if they were all already on. {@code off} stops everything.
     */
    private int debugToggle(CommandSender sender, PlayerData data, String target) throws CommandSyntaxException {
        if (target.equalsIgnoreCase(OFF)) {
            boolean was = data.stopDebug(sender);
            sender.sendMessage(Component.text(was ? "Stopped debugging " + data.name() + "."
                    : "You were not debugging " + data.name() + ".", was ? NamedTextColor.YELLOW : NamedTextColor.GRAY));
            return Command.SINGLE_SUCCESS;
        }
        List<Check> selected = resolveTargets(data, target);
        if (selected.isEmpty()) {
            throw UNKNOWN_TARGET.create(target);
        }
        if (PlayerData.viewerKey(sender) == null) {
            sender.sendMessage(Component.text("Only players and the server console can debug.", NamedTextColor.RED));
            return 0;
        }
        List<String> watched = data.debuggedBy(sender);
        boolean wasDebugging = sender instanceof Player player && dataManager.isDebugViewer(player.getUniqueId());
        boolean allOn = selected.stream().allMatch(check -> watched.contains(check.id()));
        for (Check check : selected) {
            if (allOn) {
                data.stopDebug(sender, check);
            } else {
                data.startDebug(sender, check);
            }
        }
        String what = selected.size() == 1 ? selected.getFirst().id() : selected.size() + " checks";
        sender.sendMessage(Component.text(allOn ? "Stopped " : "Debugging ", allOn ? NamedTextColor.YELLOW : NamedTextColor.GREEN)
                                    .append(Component.text(what, NamedTextColor.AQUA))
                                    .append(Component.text(" on " + data.name() + ".", allOn ? NamedTextColor.YELLOW : NamedTextColor.GREEN)));
        if (!allOn && !wasDebugging && sender instanceof Player) {
            sender.sendMessage(Component.text(" You will not be punished while you are debugging.", NamedTextColor.DARK_GRAY));
        }
        sendWatching(sender, data);
        return Command.SINGLE_SUCCESS;
    }

                               .clickEvent(ClickEvent.runCommand(debugCommand(data, id))));
        }
        sender.sendMessage(Component.text(" Watching: ", NamedTextColor.GRAY)
                                    .append(Component.join(JoinConfiguration.commas(true), parts))
                                    .append(Component.space())
                                    .append(button("menu", NamedTextColor.YELLOW, "Open the check menu",
                                            debugCommand(data)))
                                    .append(Component.space())
                                    .append(button("stop", NamedTextColor.RED, "Stop debugging " + data.name(),

    /**
     * Checks selected by {@code target}: one check id, a category name, or {@code all}. Case insensitive.
     */
    static List<Check> resolveTargets(PlayerData data, String target) {
        if (target.equalsIgnoreCase(ALL)) {
            return data.checks();
        }
        Check single = data.check(target);
        if (single != null) {
            return List.of(single);
        }
        List<Check> result = new ArrayList<>();
        for (Check check : data.checks()) {
            if (categoryName(check.info().category()).equalsIgnoreCase(target)) {
                result.add(check);
            }
        }
        return result;
    }

    // ---------------------------------------------------------------- suggestions

    /**
     * Suggests check ids, categories, {@code all} and {@code off} for the player typed before, with a
     * tooltip saying what each one does and whether it is already on. Prefix matches first; if none,
     * anything containing the typed text, so {@code "reach"} or {@code "fly"} still find their check.
     */
    private CompletableFuture<Suggestions> suggestDebugTargets(CommandContext<CommandSourceStack> ctx,
                                                               SuggestionsBuilder builder) {
        PlayerData data = suggestionTarget(ctx);
        if (data == null) {
            return builder.buildFuture();
        }
        CommandSender sender = ctx.getSource().getSender();
        List<String> watched = data.debuggedBy(sender);

        Map<String, Component> options = new LinkedHashMap<>();
        for (Check check : data.checks()) {
            boolean on = watched.contains(check.id());
            options.put(check.id(), Component.text(check.info().description()
                    + (on ? "  (debugging, run to stop)" : "")));
        }
        for (Map.Entry<CheckCategory, List<Check>> group : byCategory(data.checks()).entrySet()) {
            options.put(categoryName(group.getKey()), Component.text("Every " + categoryName(group.getKey()) + " check: "
                    + String.join(", ", group.getValue().stream().map(Check::id).toList())));
        }
        options.put(ALL, Component.text("Every check (" + data.checks().size() + ")"));
        if (!watched.isEmpty()) {
            options.put(OFF, Component.text("Stop debugging " + data.name() + " (" + String.join(", ", watched) + ")"));
        }

        String typed = builder.getRemainingLowerCase();
        boolean anyPrefix = options.keySet().stream().anyMatch(o -> o.toLowerCase(Locale.ROOT).startsWith(typed));
        for (Map.Entry<String, Component> option : options.entrySet()) {
            String lower = option.getKey().toLowerCase(Locale.ROOT);
            if (anyPrefix ? lower.startsWith(typed) : lower.contains(typed)) {
                builder.suggest(option.getKey(), MessageComponentSerializer.message().serialize(option.getValue()));
            }
        }
        return builder.buildFuture();
    }

    /**
     * The player typed before the check argument, or {@code null} if it does not resolve (yet).
     */
    private @Nullable PlayerData suggestionTarget(CommandContext<CommandSourceStack> ctx) {
        try {
            List<Player> players = ctx.getArgument("player", PlayerSelectorArgumentResolver.class).resolve(ctx.getSource());
            return players.isEmpty() ? null : dataManager.get(players.getFirst());
        } catch (CommandSyntaxException | IllegalArgumentException e) {
            return null;
        }
    }

    // ---------------------------------------------------------------- helpers

    static String debugCommand(PlayerData data, String... arguments) {
        StringBuilder command = new StringBuilder("/").append(LABEL).append(" debug ").append(data.uuid());
        for (String argument : arguments) {
            command.append(' ').append(argument);
        }
        return command.toString();
    }

    private static Map<CheckCategory, List<Check>> byCategory(List<Check> checks) {
        Map<CheckCategory, List<Check>> groups = new LinkedHashMap<>();
        for (Check check : checks) {
            groups.computeIfAbsent(check.info().category(), k -> new ArrayList<>()).add(check);
        }
        return groups;
    }

    static String categoryName(CheckCategory category) {
        return category.name().toLowerCase(Locale.ROOT);
    }

    private static String stateOf(Check check) {
        return check.hasFailed() ? "failed" : check.isEnabled() ? "enabled" : "disabled in config";
    }

    private static TextComponent button(String text, NamedTextColor color, String hover, String command) {
        return Component.text("[" + text + "]", color)
                        .hoverEvent(HoverEvent.showText(Component.text(hover)))
                        .clickEvent(ClickEvent.runCommand(command));
    }
}

/**
 * Holds the current {@link PluginConfig} and rebuilds it from disk on reload.
 */
public final class ConfigManager {

    private static final String FILE_NAME = "config.yml";

    private final JavaPlugin plugin;
    private final List<String> knownChecks;
    private volatile PluginConfig current;
    private volatile List<String> lastWarnings = List.of();

    public ConfigManager(JavaPlugin plugin, Collection<String> knownChecks) {
        this.plugin = plugin;
        this.knownChecks = List.copyOf(knownChecks);
        PluginConfig loaded;
        try {
            loaded = read();
        } catch (ConfigException e) {
            plugin.getSLF4JLogger().error("{} Using the built-in defaults until it is fixed and /ac reload is run.",
                    e.getMessage());
            loaded = parse(bundledDefaults());
        }
        this.current = loaded;
    }

    /**
     * Re-reads {@code config.yml}. Main thread only.
     */
    public PluginConfig reload() throws ConfigException {
        PluginConfig loaded = read();
        current = loaded;
        return loaded;
    }

    public PluginConfig get() {
        return current;
    }

    public List<String> lastWarnings() {
        return lastWarnings;
    }

    private PluginConfig read() throws ConfigException {
        plugin.saveDefaultConfig();
        File file = new File(plugin.getDataFolder(), FILE_NAME);
        YamlConfiguration yaml = new YamlConfiguration();
        try {
            yaml.load(file);
        } catch (IOException | InvalidConfigurationException e) {
            throw new ConfigException(FILE_NAME + " could not be loaded: " + firstLines(e.getMessage()), e);
        }
        yaml.setDefaults(bundledDefaults());
        return parse(yaml);
    }

    private PluginConfig parse(YamlConfiguration yaml) {
        List<String> warnings = new ArrayList<>();
        PluginConfig config = PluginConfig.load(yaml, warnings, knownChecks);
        for (String warning : warnings) {
            plugin.getSLF4JLogger().warn("{}: {}", FILE_NAME, warning);
        }
        lastWarnings = List.copyOf(warnings);
        return config;
    }

    private YamlConfiguration bundledDefaults() {
        InputStream stream = plugin.getResource(FILE_NAME);
        if (stream == null) {
            return new YamlConfiguration();
        }
        try (Reader reader = new InputStreamReader(stream, StandardCharsets.UTF_8)) {
            return YamlConfiguration.loadConfiguration(reader);
        } catch (IOException e) {
            return new YamlConfiguration();
        }
    }

    private static String firstLines(String message) {
        if (message == null) {
            return "unknown error";
        }
        String[] lines = message.strip().split("\\R");
        if (lines.length <= 3) {
            return String.join(" ", lines);
        }
        return String.join(" ", lines[0], lines[1], lines[2]) + " ...";
    }

    public static final class ConfigException extends Exception {

        public ConfigException(String message, Throwable cause) {
            super(message, cause);
        }
    }
}

package me.raph.anticheat.config;

import org.bukkit.configuration.ConfigurationSection;

import java.util.*;

/**
 * Typed, immutable view of {@code config.yml}. A new instance is built on every reload.
 *
 * @param alertFormat          alert message with {@code &} colour codes and {@code %player%},
 *                             {@code %check%}, {@code %vl%}, {@code %debug%} placeholders
 * @param alertCooldownMs      minimum time between two alerts for the same player and check
 * @param decayIntervalSeconds how often VL decays
 * @param decayAmount          VL removed from every check at each decay
 * @param logToFile            whether violations are appended to {@code violations.log}
 * @param checks               per-check settings by check id
 */
public record PluginConfig(
        String alertFormat,
        long alertCooldownMs,
        int decayIntervalSeconds,
        double decayAmount,
        boolean logToFile,
        Map<String, CheckConfig> checks
) {

    public static final String DEFAULT_ALERT_FORMAT = "&c[AC] &f%player% &7failed &c%check% &7(x%vl%) &8%debug%";

    public PluginConfig {
        Map<String, CheckConfig> lowerCase = new HashMap<>();
        checks.forEach((id, check) -> lowerCase.put(key(id), check));
        checks = Map.copyOf(lowerCase);
    }

    /**
     * Built-in defaults with no per-check settings. Mostly for tests.
     */
    public static PluginConfig defaults() {
        return new PluginConfig(DEFAULT_ALERT_FORMAT, 500L, 1, 0.25, true, Map.of());
    }

    /**
     * Reads the root section of {@code config.yml}. Invalid entries are logged and skipped.
     */
    public static PluginConfig load(ConfigurationSection root, List<String> warnings, Collection<String> knownChecks) {
        String format = string(root, "alerts.format", DEFAULT_ALERT_FORMAT, warnings);
        long cooldown = Math.max(0L, number(root, "alerts.cooldown-ms", 500L, warnings).longValue());
        int interval = Math.max(1, number(root, "violation-decay.interval-seconds", 1, warnings).intValue());
        double amount = Math.max(0.0, number(root, "violation-decay.amount", 0.25, warnings).doubleValue());
        boolean logToFile = bool(root, "logging.file", true, warnings);

        Set<String> known = new HashSet<>();
        for (String id : knownChecks) {
            known.add(key(id));
        }

        Map<String, CheckConfig> checks = new HashMap<>();
        ConfigurationSection checksSection = root.getConfigurationSection("checks");
        if (checksSection != null) {
            for (String checkId : checksSection.getKeys(false)) {
                ConfigurationSection section = checksSection.getConfigurationSection(checkId);
                if (section == null) {
                    warnings.add("Ignoring checks." + checkId + ": expected a section");
                    continue;
                }
                if (!known.isEmpty() && !known.contains(key(checkId))) {
                    warnings.add("Ignoring checks." + checkId + ": no such check. Known checks: "
                            + String.join(", ", knownChecks));
                    continue;
                }
                if (checks.containsKey(key(checkId))) {
                    warnings.add("Ignoring checks." + checkId + ": this check is already configured above"
                            + " (check ids are not case sensitive)");
                    continue;
                }
                checks.put(key(checkId), loadCheck(checkId, section, warnings));
            }
        }
        return new PluginConfig(format, cooldown, interval, amount, logToFile, checks);
    }

    private static CheckConfig loadCheck(String checkId, ConfigurationSection section, List<String> warnings) {
        boolean enabled = bool(section, "enabled", true, warnings);
        TreeMap<Integer, List<String>> punishments = new TreeMap<>();
        ConfigurationSection punishSection = section.getConfigurationSection("punishments");
        if (punishSection == null && section.isSet("punishments")) {
            warnings.add("Ignoring checks." + checkId + ".punishments: expected a section of 'VL: command'");
        }
        if (punishSection != null) {
            for (String key : punishSection.getKeys(false)) {
                String where = "checks." + checkId + ".punishments." + key;
                int threshold;
                try {
                    threshold = Integer.parseInt(key.trim());
                } catch (NumberFormatException e) {
                    warnings.add("Ignoring " + where + ": the key must be a whole VL number");
                    continue;
                }
                if (threshold < 1) {
                    warnings.add("Ignoring " + where + ": the threshold must be 1 or more");
                    continue;
                }
                // Accept a single command or a list of commands.
                List<String> commands = new ArrayList<>();
                if (punishSection.isList(key)) {
                    for (String command : punishSection.getStringList(key)) {
                        if (!command.isBlank()) {
                            commands.add(command);
                        }
                    }
                } else if (punishSection.isString(key)) {
                    String command = punishSection.getString(key, "");
                    if (!command.isBlank()) {
                        commands.add(command);
                    }
                } else {
                    warnings.add("Ignoring " + where + ": expected a command or a list of commands");
                    continue;
                }
                if (commands.isEmpty()) {
                    warnings.add("Ignoring " + where + ": no command");
                    continue;
                }
                punishments.put(threshold, commands);
            }
        }
        return new CheckConfig(enabled, punishments);
    }

    private static String path(ConfigurationSection section, String path) {
        String parent = section.getCurrentPath();
        return parent == null || parent.isEmpty() ? path : parent + "." + path;
    }

    private static boolean bool(ConfigurationSection section, String path, boolean def, List<String> warnings) {
        Object value = section.get(path);
        if (value == null) {
            return def;
        }
        if (value instanceof Boolean b) {
            return b;
        }
        warnings.add(path(section, path) + ": expected true or false without quotes, got '" + value + "'. Using " + def);
        return def;
    }

    private static Number number(ConfigurationSection section, String path, Number def, List<String> warnings) {
        Object value = section.get(path);
        if (value == null) {
            return def;
        }
        if (value instanceof Number n) {
            return n;
        }
        warnings.add(path(section, path) + ": expected a number without quotes, got '" + value + "'. Using " + def);
        return def;
    }

    private static String string(ConfigurationSection section, String path, String def, List<String> warnings) {
        Object value = section.get(path);
        if (value == null) {
            return def;
        }
        if (value instanceof String s) {
            return s;
        }
        warnings.add(path(section, path) + ": expected text, got '" + value + "'. Using the default");
        return def;
    }

    private static String key(String checkId) {
        return checkId.toLowerCase(Locale.ROOT);
    }

    /**
     * Settings of {@code checkId}, or {@link CheckConfig#DEFAULT} when it has no section.
     */
    public CheckConfig check(String checkId) {
        return checks.getOrDefault(key(checkId), CheckConfig.DEFAULT);
    }
}

package me.raph.anticheat.data;

import me.raph.anticheat.check.CheckCategory;
import org.bukkit.GameMode;
import org.bukkit.entity.Player;

import java.util.EnumSet;
import java.util.Set;
import java.util.concurrent.atomic.AtomicIntegerArray;
import java.util.concurrent.atomic.AtomicLongArray;

/**
 * Per-player exemptions. Lives inside {@link PlayerData}. The only place that decides whether a player is
 * exempt, so checks never duplicate this logic.
 *
 * <p>Thread safety: timed exemptions are stored atomically. Live states are snapshotted by
 * {@link #refresh(Player)}, which must run on the main thread (the move listener and the tick task call it),
 * so queries never touch Bukkit.
 */
public final class ExemptionManager {

    private static final ExemptType[] ALL = ExemptType.values();

    // TODO(decision): combat checks ignore movement related exemptions (velocity, flight, elytra, vehicle,
    // swimming, riptide). Otherwise every hit taken would exempt the attacker from reach checks.
    private static final Set<ExemptType> COMBAT = EnumSet.of(
            ExemptType.JOIN, ExemptType.TELEPORT, ExemptType.WORLD_CHANGE, ExemptType.GAMEMODE);

    /**
     * Epoch millis until which each type is exempt, indexed by ordinal.
     */
    private final AtomicLongArray expiry = new AtomicLongArray(ALL.length);

    private final AtomicIntegerArray movesLeft = new AtomicIntegerArray(ALL.length);

    /**
     * Bit set (by ordinal) of the live states seen at the last refresh.
     */
    private volatile int live;

    /**
     * Exempts the player for {@code type} during {@code millis} from now. Never shortens an existing exemption.
     */
    public void exempt(ExemptType type, long millis) {
        long until = System.currentTimeMillis() + millis;
        expiry.accumulateAndGet(type.ordinal(), until, Math::max);
    }

    public void exemptForMoves(ExemptType type, int moves, long maxMillis) {
        exempt(type, maxMillis);
        movesLeft.accumulateAndGet(type.ordinal(), moves, Math::max);
    }

    public void consumeMove() {
        for (int i = 0; i < ALL.length; i++) {
            if (movesLeft.get(i) > 0 && movesLeft.decrementAndGet(i) == 0) {
                expiry.set(i, 0L);
            }
        }
    }

    /**
     * Whether the player is exempt for at least one of {@code types}.
     */
    public boolean isExempt(ExemptType... types) {
        long now = System.currentTimeMillis();
        int liveBits = live;
        for (ExemptType type : types) {
            if (isExempt(type, now, liveBits)) {
                return true;
            }
        }
        return false;
    }

    /**
     * Whether the player is exempt for any reason at all.
     */
    public boolean isExemptAny() {
        return isExempt(ALL);
    }

    /**
     * Whether checks of {@code category} should ignore this player right now.
     */
    public boolean isExempt(CheckCategory category) {
        return switch (category) {
            case COMBAT -> {
                long now = System.currentTimeMillis();
                int liveBits = live;
                for (ExemptType type : COMBAT) {
                    if (isExempt(type, now, liveBits)) {
                        yield true;
                    }
                }
                yield false;
            }
            case MOVEMENT, PLAYER -> isExemptAny();
        };
    }

    /**
     * Snapshots the live states (game mode, flight, gliding, vehicle, swimming, riptide). Main thread only.
     * Each active live state also refreshes its timed grace period.
     */
    public void refresh(Player player) {
        GameMode mode = player.getGameMode();
        int bits = 0;
        bits |= liveBit(ExemptType.GAMEMODE, mode == GameMode.CREATIVE || mode == GameMode.SPECTATOR);
        bits |= liveBit(ExemptType.FLIGHT, player.isFlying());
        bits |= liveBit(ExemptType.ELYTRA, player.isGliding());
        bits |= liveBit(ExemptType.VEHICLE, player.isInsideVehicle());
        bits |= liveBit(ExemptType.SWIMMING, player.isSwimming());
        bits |= liveBit(ExemptType.RIPTIDE, player.isRiptiding());
        live = bits;
    }

    private int liveBit(ExemptType type, boolean active) {
        if (!active) {
            return 0;
        }
        exempt(type, type.liveGraceMillis());
        return 1 << type.ordinal();
    }

    private boolean isExempt(ExemptType type, long now, int liveBits) {
        return (liveBits & (1 << type.ordinal())) != 0 || expiry.get(type.ordinal()) > now;
    }
}

/**
 * Everything the anticheat knows about one online player: trackers, exemptions and their own instance
 * of every check. Created on join, dropped on quit.
 *
 * <p>The {@code handleX} methods are the only way updates reach checks. Each check runs inside its own
 * try/catch: a check that throws is logged once and turned off for this player, the others keep running.
 */
public final class PlayerData {

    private final Player player;
    private final UUID uuid;
    private final String name;
    private final Plugin plugin;
    private final Supplier<PluginConfig> config;
    private final Consumer<Violation> violationSink;

    private final MovementTracker movement;
    private final CombatTracker combat = new CombatTracker();
    private final ExemptionManager exemptions = new ExemptionManager();

    private final List<Check> checks;
    private final List<MovementHandler> movementHandlers;
    private final List<CombatHandler> combatHandlers;
    private final List<TickHandler> tickHandlers;

    public static final UUID CONSOLE = new UUID(0L, 0L);

    private volatile boolean bypass;
    private volatile boolean removed;
    /**
     * Viewer to the ids of the checks they are debugging on this player.
     */
    private final Map<UUID, Set<String>> debugViewers = new ConcurrentHashMap<>();

    /**
     * @param player        the player
     * @param plugin        owning plugin, used for logging and scheduling
     * @param config        current config, read again on every use so reloads apply
     * @param violationSink receives every violation, normally {@code ViolationHandler::handle}
     * @param registry      builds this player's checks
     */
    public PlayerData(Player player, Plugin plugin, Supplier<PluginConfig> config,
                      Consumer<Violation> violationSink, CheckRegistry registry) {
        this.player = Objects.requireNonNull(player, "player");
        this.uuid = player.getUniqueId();
        this.name = player.getName();
        this.plugin = Objects.requireNonNull(plugin, "plugin");
        this.config = Objects.requireNonNull(config, "config");
        this.violationSink = Objects.requireNonNull(violationSink, "violationSink");
        this.movement = new MovementTracker(player);

        this.checks = registry.create(this);
        List<MovementHandler> movement = new ArrayList<>();
        List<CombatHandler> combat = new ArrayList<>();
        List<TickHandler> tick = new ArrayList<>();
        for (Check check : checks) {
            if (check instanceof MovementHandler handler) {
                movement.add(handler);
            }
            if (check instanceof CombatHandler handler) {
                combat.add(handler);
            }
            if (check instanceof TickHandler handler) {
                tick.add(handler);
            }
        }
        this.movementHandlers = List.copyOf(movement);
        this.combatHandlers = List.copyOf(combat);
        this.tickHandlers = List.copyOf(tick);
    }

    // ---------------------------------------------------------------- dispatch

    /**
     * Sends a move to every active {@link MovementHandler}.
     */
    public void handleMove(MoveUpdate update) {
        for (MovementHandler handler : movementHandlers) {
            Check check = (Check) handler;
            if (removed) {
                return;
            }
            if (!check.isActive()) {
                continue;
            }
            try {
                handler.handleMove(update);
            } catch (Throwable t) {
                fail(check, t);
            }
        }
    }

    /**
     * Sends an attack to every active {@link CombatHandler}.
     */
    public void handleAttack(AttackUpdate update) {
        for (CombatHandler handler : combatHandlers) {
            Check check = (Check) handler;
            if (removed) {
                return;
            }
            if (!check.isActive()) {
                continue;
            }
            try {
                handler.handleAttack(update);
            } catch (Throwable t) {
                fail(check, t);
            }
        }
    }

    /**
     * Ticks every active {@link TickHandler}.
     */
    public void handleTick() {
        for (TickHandler handler : tickHandlers) {
            Check check = (Check) handler;
            if (removed) {
                return;
            }
            if (!check.isActive()) {
                continue;
            }
            try {
                handler.handleTick();
            } catch (Throwable t) {
                fail(check, t);
            }
        }
    }

    private void fail(Check check, Throwable t) {
        if (t instanceof VirtualMachineError error) {
            throw error;
        }
        check.markFailed();
        plugin.getSLF4JLogger().error("Check {} threw an exception for {}, it is now disabled for this player",
                check.id(), name, t);
    }

    // ---------------------------------------------------------------- violations and debug

    /**
     * Called by {@link Check#flag(String)}.
     */
    public void reportViolation(Violation violation) {
        if (removed) {
            return;
        }
        violationSink.accept(violation);
    }

    /**
     * Whether someone is debugging {@code check} on this player. Cheap when nobody is.
     */
    public boolean isDebugging(Check check) {
        if (debugViewers.isEmpty()) {
            return false;
        }
        for (Set<String> watched : debugViewers.values()) {
            if (watched.contains(check.id())) {
                return true;
            }
        }
        return false;
    }

    /**
     * Called by {@link Check#debug(String)}. Forwards the line to everyone debugging that check.
     * A player debugging themselves gets the line without their own name.
     */
    public void debug(Check check, String message) {
        if (debugViewers.isEmpty()) {
            return;
        }
        Server server = plugin.getServer();
        if (server == null) {
            return;
        }
        Component named = null;
        Component self = null;
        for (Map.Entry<UUID, Set<String>> entry : debugViewers.entrySet()) {
            if (!entry.getValue().contains(check.id())) {
                continue;
            }
            CommandSender viewer = resolveViewer(server, entry.getKey());
            if (viewer == null) {
                continue;
            }
            Component line;
            if (entry.getKey().equals(uuid)) {
                if (self == null) {
                    self = debugLine("[" + check.id() + "] ", message);
                }
                line = self;
            } else {
                if (named == null) {
                    named = debugLine("[" + check.id() + " " + name + "] ", message);
                }
                line = named;
            }
            MainThread.run(plugin, () -> viewer.sendMessage(line));
        }
    }

    private static @Nullable CommandSender resolveViewer(Server server, UUID key) {
        return key.equals(CONSOLE) ? server.getConsoleSender() : server.getPlayer(key);
    }

    public static @Nullable UUID viewerKey(CommandSender sender) {
        if (sender instanceof Player player) {
            return player.getUniqueId();
        }
        if (sender instanceof ConsoleCommandSender) {
            return CONSOLE;
        }
        return null;
    }

    private static Component debugLine(String prefix, String message) {
        return Component.text(prefix, NamedTextColor.DARK_AQUA).append(Component.text(message, NamedTextColor.GRAY));
    }

    /**
     * The ids of the checks {@code viewer} is debugging on this player, in check order. Empty if none.
     */
    public List<String> debuggedBy(CommandSender viewer) {
        UUID key = viewerKey(viewer);
        Set<String> watched = key == null ? null : debugViewers.get(key);
        if (watched == null || watched.isEmpty()) {
            return List.of();
        }
        List<String> result = new ArrayList<>();
        for (Check check : checks) {
            if (watched.contains(check.id())) {
                result.add(check.id());
            }
        }
        return result;
    }

    /**
     * Streams the debug lines of {@code check} to {@code viewer}, on top of what they already watch.
     */
    public boolean startDebug(CommandSender viewer, Check check) {
        UUID key = viewerKey(viewer);
        if (key == null || removed) {
            return false;
        }
        debugViewers.computeIfAbsent(key, k -> ConcurrentHashMap.newKeySet()).add(check.id());
        return true;
    }

    /**
     * Stops streaming {@code check} to {@code viewer}. Other checks they watch keep streaming.
     */
    public void stopDebug(CommandSender viewer, Check check) {
        UUID key = viewerKey(viewer);
        if (key == null) {
            return;
        }
        debugViewers.computeIfPresent(key, (k, watched) -> {
            watched.remove(check.id());
            return watched.isEmpty() ? null : watched;
        });
    }

    /**
     * Whether the player with this UUID is debugging at least one check on this player.
     */
    public boolean hasDebugViewer(UUID viewerId) {
        return debugViewers.containsKey(viewerId);
    }

    /**
     * Stops every debug stream {@code viewer} has on this player (for example on quit).
     *
     * @return whether {@code viewer} was debugging anything
     */
    public boolean stopDebug(CommandSender viewer) {
        UUID key = viewerKey(viewer);
        return key != null && stopDebug(key);
    }

    public boolean stopDebug(UUID viewerKey) {
        return debugViewers.remove(viewerKey) != null;
    }

    /**
     * Re-reads the bypass permission. Main thread only.
     */
    public void refreshPermissions() {
        bypass = player.hasPermission(Permissions.BYPASS);
        if (debugViewers.isEmpty()) {
            return;
        }
        Server server = plugin.getServer();
        if (server == null) {
            return;
        }
        debugViewers.keySet().removeIf(key -> {
            if (key.equals(CONSOLE)) {
                return false;
            }
            Player viewer = server.getPlayer(key);
            return viewer == null || !viewer.hasPermission(Permissions.DEBUG);
        });
    }

    void markRemoved() {
        removed = true;
        debugViewers.clear();
    }

    public boolean isRemoved() {
        return removed;
    }

    // ---------------------------------------------------------------- state

    /**

    public void applyConfig(PluginConfig newConfig) {

    }

    }

import me.raph.anticheat.check.Check;
import me.raph.anticheat.check.CheckRegistry;
import me.raph.anticheat.config.PluginConfig;
import me.raph.anticheat.violation.Violation;
import org.bukkit.entity.Player;
import org.bukkit.plugin.Plugin;
import org.jspecify.annotations.Nullable;

import java.util.Collection;
import java.util.Collections;

import java.util.function.LongSupplier;
import java.util.function.Supplier;

/**
 * Owns the {@link PlayerData} of every online player.
 */
public final class PlayerDataManager {

    public static final long JOIN_EXEMPT_MS = 3000L;

    static final long SAVED_VL_RETENTION_MS = 30L * 60L * 1000L;

    private final Map<UUID, PlayerData> players = new ConcurrentHashMap<>();
    private final Map<UUID, SavedVl> savedVl = new ConcurrentHashMap<>();
    private final Plugin plugin;
    private final Supplier<PluginConfig> config;
    private final Consumer<Violation> violationSink;
    private final CheckRegistry registry;
    private final LongSupplier clock;

    private int secondsSinceDecay;

    public PlayerDataManager(Plugin plugin, Supplier<PluginConfig> config,
                             Consumer<Violation> violationSink, CheckRegistry registry) {
        this(plugin, config, violationSink, registry, System::currentTimeMillis);
    }

    PlayerDataManager(Plugin plugin, Supplier<PluginConfig> config,
                      Consumer<Violation> violationSink, CheckRegistry registry, LongSupplier clock) {
        this.plugin = plugin;
        this.config = config;
        this.violationSink = violationSink;
        this.registry = registry;
        this.clock = clock;
    }

    static double offlineDecay(long elapsedMs, PluginConfig config) {
        double intervals = Math.max(0L, elapsedMs) / 1000.0 / config.decayIntervalSeconds();
        return Math.floor(intervals) * config.decayAmount();
    }

    /**
     * Creates (or replaces) the data of {@code player}. Main thread only.
     */
    public PlayerData create(Player player) {
        PlayerData data = new PlayerData(player, plugin, config, violationSink, registry);
        data.refreshPermissions();
        data.exemptions().refresh(player);
        data.exemptions().exempt(ExemptType.JOIN, JOIN_EXEMPT_MS);
        restoreVl(data);
        PlayerData previous = players.put(player.getUniqueId(), data);
        if (previous != null) {
            previous.markRemoved();
        }
        // TODO(decision): logged at info so leaks are easy to spot while testing; lower to debug once stable.
        plugin.getSLF4JLogger().info("Created data for {} ({} tracked)", player.getName(), players.size());
        return data;
    }

    /**
     * Drops the data of {@code player}.
     */
    public void remove(Player player) {
        PlayerData data = players.remove(player.getUniqueId());
        if (data != null) {
            data.markRemoved();
            Map<String, Double> vl = data.vlSnapshot();
            if (!vl.isEmpty()) {
                savedVl.put(data.uuid(), new SavedVl(Map.copyOf(vl), clock.getAsLong()));
            }
        }
        plugin.getSLF4JLogger().info("Removed data for {} ({} tracked)", player.getName(), players.size());
    }

    private void restoreVl(PlayerData data) {
        SavedVl saved = savedVl.remove(data.uuid());
        if (saved == null) {
            return;
        }
        double decayed = offlineDecay(clock.getAsLong() - saved.savedAt(), config.get());
        for (Map.Entry<String, Double> entry : saved.vl().entrySet()) {
            Check check = data.check(entry.getKey());
            if (check != null) {
                check.restoreVl(entry.getValue() - decayed);
            }
        }
    }

    public @Nullable PlayerData get(Player player) {
        return players.get(player.getUniqueId());
    }

    public @Nullable PlayerData get(UUID uuid) {
        return players.get(uuid);
    }

    public Collection<PlayerData> all() {
        return Collections.unmodifiableCollection(players.values());
    }

    /**
     * Whether the player with this UUID is running {@code /ac debug} on anyone, themselves included.
     * Such players are never punished, see {@link me.raph.anticheat.violation.PunishmentManager}.
     */
    public boolean isDebugViewer(UUID viewerId) {
        for (PlayerData data : players.values()) {
            if (data.hasDebugViewer(viewerId)) {
                return true;
            }
        }
        return false;
    }

    public int size() {
        return players.size();
    }

    int savedVlCount() {
        return savedVl.size();
    }

    public void clear() {
        for (PlayerData data : players.values()) {
            data.markRemoved();
        }
        players.clear();
        savedVl.clear();
    }

    /**
     * Called every tick: refreshes live exemptions, then dispatches the tick to the checks. Main thread only.
     */
    public void tick() {
        for (PlayerData data : players.values()) {
            data.exemptions().refresh(data.player());
            data.handleTick();
        }
    }

    /**
     * Called every second: refreshes cached permissions and runs VL decay at the configured interval. Main thread only.
     */
    public void secondTick() {
        PluginConfig current = config.get();
        boolean decay = ++secondsSinceDecay >= current.decayIntervalSeconds();
        if (decay) {
            secondsSinceDecay = 0;
        }
        for (PlayerData data : players.values()) {
            data.refreshPermissions();
            if (decay) {
                data.decay(current.decayAmount());
            }
        }
        pruneSavedVl(current);
    }

    void pruneSavedVl(PluginConfig current) {
        long now = clock.getAsLong();
        savedVl.values().removeIf(saved -> {
            long elapsed = now - saved.savedAt();
            if (elapsed >= SAVED_VL_RETENTION_MS) {
                return true;
            }
            double decayed = offlineDecay(elapsed, current);
            return saved.vl().values().stream().allMatch(vl -> vl - decayed <= 0.0);
        });
    }

    private record SavedVl(Map<String, Double> vl, long savedAt) {
    }
}

import java.util.UUID;

/**
 * Shared combat state of one player. Updated exactly once per attack by the combat listener.
 */
public final class CombatTracker {

    private long lastAttackTime;
    private UUID lastTarget;
    private int attacksThisTick;
    private int lastAttackTick = Integer.MIN_VALUE;
    private long timeSinceLastAttack = Long.MAX_VALUE;

    /**
     * Records one attack.
     *
     * @param target     attacked entity
     * @param now        current epoch millis
     * @param serverTick current server tick number
     */
    public void process(UUID target, long now, int serverTick) {
        timeSinceLastAttack = lastAttackTime == 0L ? Long.MAX_VALUE : now - lastAttackTime;
        lastAttackTime = now;
        lastTarget = target;
        if (serverTick != lastAttackTick) {
            attacksThisTick = 0;
            lastAttackTick = serverTick;
        }
        attacksThisTick++;
    }

    /**
     * Epoch millis of the last attack, 0 if none yet.
     */
    public long lastAttackTime() {
        return lastAttackTime;
    }

    /**
     * Milliseconds between the last two attacks, {@link Long#MAX_VALUE} after the first one.
     */
    public long timeSinceLastAttack() {
        return timeSinceLastAttack;
    }

    public UUID lastTarget() {
        return lastTarget;
    }

    /**
     * Attacks during the tick of the last attack, including it.
     */
    public int attacksThisTick() {
        return attacksThisTick;
    }
}

import me.raph.anticheat.update.MoveUpdate;

/**
 * Shared movement state of one player. Updated exactly once per move by the movement listener,
 * then turned into an immutable {@link MoveUpdate} for the checks.
 *
 * <p>Main thread only: {@link #process(Location, Location)} reads the world and the player's effects.
 */
public final class MovementTracker {

    /**
     * Value of a {@code ticksSince*} counter that never happened (or long ago).
     */
    public static final int NEVER = 10_000;

    public static final double DEFAULT_MOVEMENT_SPEED = 0.1;

    private static final int RECENT_MOVE_TICKS = 2;

    private final Player player;

    private Vec3 lastPosition;
    private Vec3 position;

    private double deltaX;
    private double deltaY;
    private double deltaZ;
    private double deltaXZ;
    private double lastDeltaXZ;
    private double lastDeltaY;

    // Start "on ground" so the first move after joining does not look like a long fall.
    private boolean onGround = true;
    private boolean lastOnGround = true;
    private boolean clientOnGround = true;

    private int airTicks;
    private int groundTicks;

    private int lastMoveTick = Integer.MIN_VALUE / 2;
    private double vehicleMoveLength;
    private int lastVehicleMoveTick = Integer.MIN_VALUE / 2;

    private int ticksSinceLevitation = NEVER;
    private int ticksSinceSlowFalling = NEVER;
    private int ticksSinceIce = NEVER;
    private int ticksSinceSoulSand = NEVER;
    private int ticksSinceStep = NEVER;
    private int ticksSinceLiquid = NEVER;
    private int ticksSinceClimbable = NEVER;
    private int ticksSinceWeb = NEVER;
    private int ticksSinceBounce = NEVER;
    private int ticksSinceCeiling = NEVER;

    public MovementTracker(Player player) {
        this.player = player;
    }

    private static int since(int previous, boolean now) {
        return now ? 0 : Math.min(previous + 1, NEVER);
    }

    /**
     * Updates the state with one move and returns the snapshot for the checks.
     *
     * @param from position before the move
     * @param to   position after the move
     */
    @SuppressWarnings("deprecation") // Player#isOnGround is client controlled; kept on purpose as clientOnGround only.
    public MoveUpdate process(Location from, Location to, int serverTick) {
        lastMoveTick = serverTick;
        World world = to.getWorld();
        double width = player.getWidth();
        double height = player.getHeight();

        lastPosition = Vec3.of(from);
        position = Vec3.of(to);

        lastDeltaXZ = deltaXZ;
        lastDeltaY = deltaY;
        deltaX = to.getX() - from.getX();
        deltaY = to.getY() - from.getY();
        deltaZ = to.getZ() - from.getZ();
        deltaXZ = MathUtil.hypot(deltaX, deltaZ);

        lastOnGround = onGround;
        onGround = LocationUtil.isOnGround(world, to, width);
        clientOnGround = player.isOnGround();
        if (onGround) {
            groundTicks++;
            airTicks = 0;
        } else {
            airTicks++;
            groundTicks = 0;
        }

        LocationUtil.Surroundings around = LocationUtil.scan(world, to, width, height);
        boolean liquid = around.liquid() || player.isInWater() || player.isInLava() || player.isInBubbleColumn();
        boolean climbable = around.climbable() || player.isClimbing();
        boolean web = around.web() || player.isInPowderedSnow();

        ticksSinceLevitation = since(ticksSinceLevitation, player.hasPotionEffect(PotionEffectType.LEVITATION));
        ticksSinceSlowFalling = since(ticksSinceSlowFalling, player.hasPotionEffect(PotionEffectType.SLOW_FALLING));
        ticksSinceIce = since(ticksSinceIce, around.ice());
        ticksSinceSoulSand = since(ticksSinceSoulSand, around.soulSand());
        ticksSinceStep = since(ticksSinceStep, around.step());
        ticksSinceLiquid = since(ticksSinceLiquid, liquid);
        ticksSinceClimbable = since(ticksSinceClimbable, climbable);
        ticksSinceWeb = since(ticksSinceWeb, web);
        ticksSinceBounce = since(ticksSinceBounce, around.bounce());
        ticksSinceCeiling = since(ticksSinceCeiling, LocationUtil.isHeadBlocked(world, to, width, height));

        MoveUpdate.Environment environment = new MoveUpdate.Environment(
                level(PotionEffectType.SPEED),
                level(PotionEffectType.JUMP_BOOST),
                ticksSinceLevitation,
                ticksSinceSlowFalling,
                ticksSinceIce,
                ticksSinceSoulSand,
                ticksSinceStep,
                ticksSinceLiquid,
                ticksSinceClimbable,
                ticksSinceWeb,
                ticksSinceBounce,
                ticksSinceCeiling,
                movementSpeed());

        return new MoveUpdate(lastPosition, position,
                deltaX, deltaY, deltaZ, deltaXZ, lastDeltaXZ, lastDeltaY,
                onGround, lastOnGround, clientOnGround,
                airTicks, groundTicks, environment);
    }

    public void processVehicleMove(double length, int serverTick) {
        vehicleMoveLength = length;
        lastVehicleMoveTick = serverTick;
    }

    public double recentMoveLength(int serverTick) {
        return serverTick - lastMoveTick <= RECENT_MOVE_TICKS ? MathUtil.length(deltaX, deltaY, deltaZ) : 0.0;
    }

    public double recentVehicleMoveLength(int serverTick) {
        return serverTick - lastVehicleMoveTick <= RECENT_MOVE_TICKS ? vehicleMoveLength : 0.0;
    }

    public int ticksSinceMove(int serverTick) {
        return Math.max(0, serverTick - lastMoveTick);
    }

    private double movementSpeed() {
        AttributeInstance attribute = player.getAttribute(Attribute.MOVEMENT_SPEED);
        return attribute == null ? DEFAULT_MOVEMENT_SPEED : attribute.getValue();
    }

    private int level(PotionEffectType type) {
        PotionEffect effect = player.getPotionEffect(type);
        return effect == null ? 0 : effect.getAmplifier() + 1;
    }

    public Vec3 lastPosition() {
        return lastPosition;
    }

    public Vec3 position() {
        return position;
    }

    public double deltaX() {
        return deltaX;
    }

    public double deltaY() {
        return deltaY;
    }

    public double deltaZ() {
        return deltaZ;
    }

    public double deltaXZ() {
        return deltaXZ;
    }

    public double lastDeltaXZ() {
        return lastDeltaXZ;
    }

    public double lastDeltaY() {
        return lastDeltaY;
    }

    public boolean onGround() {
        return onGround;
    }

    public boolean lastOnGround() {
        return lastOnGround;
    }

    public boolean clientOnGround() {
        return clientOnGround;
    }

        return airTicks;
    }

        return groundTicks;
    }
}

package me.raph.anticheat.listener;

import io.papermc.paper.event.player.PrePlayerAttackEntityEvent;
import me.raph.anticheat.data.PlayerData;
import me.raph.anticheat.data.PlayerDataManager;
import me.raph.anticheat.data.tracker.CombatTracker;
import me.raph.anticheat.data.tracker.MovementTracker;
import me.raph.anticheat.update.AttackUpdate;
import me.raph.anticheat.update.Box;
import me.raph.anticheat.update.Vec3;
import me.raph.anticheat.util.MathUtil;
import org.bukkit.Location;
import org.bukkit.attribute.Attribute;
import org.bukkit.attribute.AttributeInstance;
import org.bukkit.entity.Entity;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.EventPriority;
import org.bukkit.event.Listener;
import org.bukkit.util.Vector;
import org.jspecify.annotations.Nullable;

/**
 * Turns melee attacks by players into {@link AttackUpdate}s.
 */
public final class CombatListener implements Listener {

    private static final double DEFAULT_REACH = 3.0;

    private final PlayerDataManager dataManager;

    public CombatListener(PlayerDataManager dataManager) {
        this.dataManager = dataManager;
    }

    private static double recentMovement(Player player, PlayerData data, int tick) {
        MovementTracker movement = data.movement();
        return player.isInsideVehicle() ? movement.recentVehicleMoveLength(tick) : movement.recentMoveLength(tick);
    }

    private static double reach(Player player) {
        AttributeInstance attribute = player.getAttribute(Attribute.ENTITY_INTERACTION_RANGE);
        return attribute == null ? DEFAULT_REACH : attribute.getValue();
    }

    // TODO(decision): cancelled attacks (protected regions, PvP off) are still checked, because the
    // client did send the hit and a reach cheat is still a reach cheat.
    @EventHandler(priority = EventPriority.MONITOR)
    public void onAttack(PrePlayerAttackEntityEvent event) {
        if (!event.willAttack()) {
            return;
        }
        Player attacker = event.getPlayer();
        PlayerData data = dataManager.get(attacker);
        if (data == null) {
            return;
        }
        Entity target = event.getAttacked();
        int tick = attacker.getServer().getCurrentTick();

        CombatTracker combat = data.combat();
        combat.process(target.getUniqueId(), System.currentTimeMillis(), tick);

        Location eye = attacker.getEyeLocation();
        Box box = Box.of(target.getBoundingBox());
        double distance = MathUtil.distanceToBox(eye.getX(), eye.getY(), eye.getZ(),
                box.minX(), box.minY(), box.minZ(), box.maxX(), box.maxY(), box.maxZ());

        data.handleAttack(new AttackUpdate(
                Vec3.of(eye),
                target.getUniqueId(),
                box,
                distance,
                combat.timeSinceLastAttack(),
                combat.attacksThisTick(),
                attacker.getPing(),
                recentMovement(attacker, data, tick),
                targetMovement(target, tick),
                reach(attacker)));
    }

    private double targetMovement(Entity target, int tick) {
        Player controller = target instanceof Player player ? player : playerPassenger(target);
        if (controller != null) {
            PlayerData controllerData = dataManager.get(controller);
            if (controllerData != null) {
                return recentMovement(controller, controllerData, tick);
            }
        }
        // Horizontal only: a mob standing still still reports a small downward (gravity) velocity.
        Vector velocity = target.getVelocity();
        return MathUtil.hypot(velocity.getX(), velocity.getZ());
    }

    private static @Nullable Player playerPassenger(Entity vehicle) {
        for (Entity passenger : vehicle.getPassengers()) {
            if (passenger instanceof Player player) {
                return player;
            }
        }
        return null;
    }

/**
 * Sets timed exemptions for events that move the player without them asking for it.
 */
public final class ExemptionListener implements Listener {

    static final int TELEPORT_MOVES = 3;
    private static final long TELEPORT_MAX_MS = 1000L;
    private static final long GAMEMODE_MS = 1000L;
    private static final long WORLD_CHANGE_MS = 1000L;

    static final long VELOCITY_MIN_MS = 250L;
    static final long VELOCITY_MAX_MS = 3000L;
    private static final int VELOCITY_MAX_PING_MS = 500;
    private static final int VELOCITY_SLACK_TICKS = 3;
    private static final int SIMULATION_LIMIT_TICKS = 60;
    private static final double GRAVITY = 0.08;
    private static final double VERTICAL_DRAG = 0.98;
    private static final double AIR_FRICTION = 0.91;
    private static final double GROUND_FRICTION = 0.6 * 0.91;
    private static final double HORIZONTAL_SETTLED = 0.1;

    private final PlayerDataManager dataManager;

    public ExemptionListener(PlayerDataManager dataManager) {
        this.dataManager = dataManager;
    }

    static long velocityExemptMillis(double vx, double vy, double vz, int pingMs) {
        double horizontal = MathUtil.hypot(vx, vz);
        int ticks = 0;
        if (vy > 0.0) {
            double y = 0.0;
            double motionY = vy;
            while (ticks < SIMULATION_LIMIT_TICKS) {
                y += motionY;
                motionY = (motionY - GRAVITY) * VERTICAL_DRAG;
                horizontal *= AIR_FRICTION;
                ticks++;
                if (y <= 0.0) {
                    break;
                }
            }
        }
        while (horizontal > HORIZONTAL_SETTLED && ticks < SIMULATION_LIMIT_TICKS) {
            horizontal *= GROUND_FRICTION;
            ticks++;
        }
        long millis = (ticks + VELOCITY_SLACK_TICKS) * 50L + Math.clamp(pingMs, 0, VELOCITY_MAX_PING_MS);
        return Math.clamp(millis, VELOCITY_MIN_MS, VELOCITY_MAX_MS);
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onTeleport(PlayerTeleportEvent event) {
        exemptTeleport(event.getPlayer());
    }

    @EventHandler(priority = EventPriority.MONITOR)
    public void onRespawn(PlayerRespawnEvent event) {
        exemptTeleport(event.getPlayer());
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onVelocity(PlayerVelocityEvent event) {
        exemptVelocity(event.getPlayer(), event.getVelocity());
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onKnockback(EntityKnockbackEvent event) {
        if (event.getEntity() instanceof Player player) {
            exemptVelocity(player, event.getKnockback());
        }
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onGameModeChange(PlayerGameModeChangeEvent event) {
        exempt(event.getPlayer(), ExemptType.GAMEMODE, GAMEMODE_MS);
    }

    @EventHandler(priority = EventPriority.MONITOR)
    public void onWorldChange(PlayerChangedWorldEvent event) {
        exempt(event.getPlayer(), ExemptType.WORLD_CHANGE, WORLD_CHANGE_MS);
    }

    private void exemptTeleport(Player player) {
        PlayerData data = dataManager.get(player);
        if (data != null) {
            data.exemptions().exemptForMoves(ExemptType.TELEPORT, TELEPORT_MOVES, TELEPORT_MAX_MS);
        }
    }

    private void exemptVelocity(Player player, Vector velocity) {
        exempt(player, ExemptType.VELOCITY,
                velocityExemptMillis(velocity.getX(), velocity.getY(), velocity.getZ(), player.getPing()));
    }

    private void exempt(Player player, ExemptType type, long millis) {
        PlayerData data = dataManager.get(player);
        if (data != null) {
            data.exemptions().exempt(type, millis);
        }
    }
}

/**
 * Turns Bukkit move events into {@link MoveUpdate}s.
 *
 * <p>Note: Paper only fires {@link PlayerMoveEvent} once the player moved more than about 0.06 blocks
 * (or turned more than 10 degrees) since the last event, so very slow moves are merged together.
 * A packet based listener (phase 7) removes that limitation without changing any check.
 */
public final class MovementListener implements Listener {

    private final PlayerDataManager dataManager;

    public MovementListener(PlayerDataManager dataManager) {
        this.dataManager = dataManager;
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onMove(PlayerMoveEvent event) {
        // TODO(decision): rotation only events carry no movement, so they are not passed to checks.
        if (!event.hasChangedPosition()) {
            return;
        }
        Player player = event.getPlayer();
        PlayerData data = dataManager.get(player);
        if (data == null) {
            return;
        }
        data.exemptions().refresh(player);
        MoveUpdate update = data.movement().process(event.getFrom(), event.getTo(), Bukkit.getCurrentTick());
        data.handleMove(update);
        data.exemptions().consumeMove();
    }

    @EventHandler(priority = EventPriority.MONITOR)
    public void onVehicleMove(VehicleMoveEvent event) {
        Location from = event.getFrom();
        Location to = event.getTo();
        if (from.getWorld() != to.getWorld()) {
            return;
        }
        double length = from.distance(to);
        int tick = Bukkit.getCurrentTick();
        for (Entity passenger : event.getVehicle().getPassengers()) {
            if (passenger instanceof Player player) {
                PlayerData data = dataManager.get(player);
                if (data != null) {
                    data.movement().processVehicleMove(length, tick);
                }
            }
        }
    }
}

package me.raph.anticheat.util;

import org.bukkit.Location;
import org.bukkit.Material;
import org.bukkit.Tag;
import org.bukkit.World;
import org.bukkit.block.Block;
import org.bukkit.block.data.BlockData;
import org.bukkit.block.data.Waterlogged;
import org.bukkit.util.BoundingBox;

/**
 * World queries used by the trackers. Main thread only: these read blocks.
 */
public final class LocationUtil {

    /**
     * How far below the feet the ground probe reaches.
     */
    private static final double GROUND_PROBE = 0.03;
    /**
     * Shrinks probes horizontally so blocks the player is only touching from the side do not count.
     */
    private static final double SKIN = 0.001;
    /**
     * Horizontal reach of the body scan (liquids, climbables, cobwebs, honey).
     */
    private static final double BODY_EXPAND = 0.1;
    /**
     * Horizontal reach of the stairs and slab scan.
     */
    private static final double STEP_EXPAND = 0.3;

    private LocationUtil() {
    }

    /**
     * Server side ground check: is there block or hard entity (boat, shulker) collision right under the
     * player's feet? Does not trust the client and does not load chunks.
     */
    public static boolean isOnGround(World world, Location at, double width) {
        double half = width / 2.0 - SKIN;
        BoundingBox probe = new BoundingBox(
                at.getX() - half, at.getY() - GROUND_PROBE, at.getZ() - half,
                at.getX() + half, at.getY(), at.getZ() + half);
        return world.hasCollisionsIn(probe);
    }

    /**
     * Is there collision right above the player's head?
     */
    public static boolean isHeadBlocked(World world, Location at, double width, double height) {
        double half = width / 2.0 - SKIN;
        double top = at.getY() + height;
        BoundingBox probe = new BoundingBox(
                at.getX() - half, top, at.getZ() - half,
                at.getX() + half, top + GROUND_PROBE, at.getZ() + half);
        return world.hasCollisionsIn(probe);
    }

    /**
     * Scans the blocks around the player. Unloaded chunks are skipped.
     */
    public static Surroundings scan(World world, Location at, double width, double height) {
        double x = at.getX();
        double y = at.getY();
        double z = at.getZ();
        double half = width / 2.0;

        // Row of blocks the player stands on (also catches slabs and beds, whose top is below y).
        int feetY = floor(y - 0.5);
        int bodyMinY = floor(y);
        int bodyMaxY = floor(y + height - SKIN);

        boolean ice = false;
        boolean soulSand = false;
        boolean step = false;
        boolean liquid = false;
        boolean climbable = false;
        boolean web = false;
        boolean bounce = false;

        for (int bx = floor(x - half - STEP_EXPAND); bx <= floor(x + half + STEP_EXPAND); bx++) {
            for (int bz = floor(z - half - STEP_EXPAND); bz <= floor(z + half + STEP_EXPAND); bz++) {
                if (!world.isChunkLoaded(bx >> 4, bz >> 4)) {
                    continue;
                }
                boolean underFeet = overlaps(bx, x - half + SKIN, x + half - SKIN)
                        && overlaps(bz, z - half + SKIN, z + half - SKIN);
                boolean nearBody = overlaps(bx, x - half - BODY_EXPAND, x + half + BODY_EXPAND)
                        && overlaps(bz, z - half - BODY_EXPAND, z + half + BODY_EXPAND);

                for (int by = feetY; by <= bodyMaxY; by++) {
                    Block block = world.getBlockAt(bx, by, bz);
                    Material type = block.getType();
                    if (type.isAir()) {
                        continue;
                    }
                    // When standing on a slab or bed the feet row is also the lowest body row.
                    boolean feetRow = by == feetY;
                    boolean inBody = by >= bodyMinY;

                    if (Tag.STAIRS.isTagged(type) || Tag.SLABS.isTagged(type)) {
                        step = true;
                    }
                    if (feetRow && underFeet) {
                        ice |= Tag.ICE.isTagged(type);
                        soulSand |= type == Material.SOUL_SAND || type == Material.SOUL_SOIL;
                        bounce |= type == Material.SLIME_BLOCK || Tag.BEDS.isTagged(type);
                    }
                    if (!nearBody) {
                        continue;
                    }
                    if (inBody && isLiquid(block, type)) {
                        liquid = true;
                    }
                    if ((inBody || underFeet) && Tag.CLIMBABLE.isTagged(type)) {
                        climbable = true;
                    }
                    if ((inBody || underFeet) && isWeb(type)) {
                        web = true;
                    }
                }
            }
        }
        return new Surroundings(ice, soulSand, step, liquid, climbable, web, bounce);
    }

    private static boolean isLiquid(Block block, Material type) {
        if (type == Material.WATER || type == Material.LAVA || type == Material.BUBBLE_COLUMN
                || type == Material.KELP || type == Material.KELP_PLANT
                || type == Material.SEAGRASS || type == Material.TALL_SEAGRASS) {
            return true;
        }
        BlockData data = block.getBlockData();
        return data instanceof Waterlogged waterlogged && waterlogged.isWaterlogged();
    }

    private static boolean isWeb(Material type) {
        return type == Material.COBWEB || type == Material.POWDER_SNOW
                || type == Material.SWEET_BERRY_BUSH || type == Material.HONEY_BLOCK;
    }

    /**
     * Does the block cell {@code [cell, cell + 1)} overlap {@code [min, max]}?
     */
    private static boolean overlaps(int cell, double min, double max) {
        return cell + 1 > min && cell <= max;
    }

    private static int floor(double value) {
        return (int) Math.floor(value);
    }

    /**
     * Blocks that change movement physics around a player standing at {@code at}.
     *
     * @param ice       ice of any kind under the feet
     * @param soulSand  soul sand or soul soil under the feet
     * @param step      stairs or slabs under or next to the player
     * @param liquid    water, lava, bubble column or a waterlogged block in the body
     * @param climbable ladder, vine, scaffolding or other climbable in the body or under the feet
     * @param web       cobweb, powder snow, sweet berry bush or honey block in or next to the body or under the feet
     * @param bounce    slime block or bed under the feet
     */
    public record Surroundings(boolean ice, boolean soulSand, boolean step, boolean liquid,
                               boolean climbable, boolean web, boolean bounce) {
    }
}

/**
 * Small pure math helpers. No Bukkit types, so everything here is unit tested.
 */
public final class MathUtil {

    private MathUtil() {
    }

    /**
     * Length of the horizontal vector {@code (x, z)}.
     */
    public static double hypot(double x, double z) {
        return Math.sqrt(x * x + z * z);
    }

    /**
     * Length of the vector {@code (x, y, z)}.
     */
    public static double length(double x, double y, double z) {
        return Math.sqrt(x * x + y * y + z * z);
    }

    public static double clamp(double value, double min, double max) {
        return Math.max(min, Math.min(max, value));
    }

    /**
     * Distance from point {@code p} to the closest point of the box. 0 when the point is inside the box.
     */
    public static double distanceToBox(double px, double py, double pz,
                                       double minX, double minY, double minZ,
                                       double maxX, double maxY, double maxZ) {
        double dx = px - clamp(px, minX, maxX);
        double dy = py - clamp(py, minY, maxY);
        double dz = pz - clamp(pz, minZ, maxZ);
        return length(dx, dy, dz);
    }
}

        long now = System.currentTimeMillis();
        Map<String, Long> perCheck = plugin.getServer().getPlayer(violation.playerId()) != null
                ? lastAlert.computeIfAbsent(violation.playerId(), id -> new ConcurrentHashMap<>())
                : lastAlert.get(violation.playerId());
        if (perCheck != null) {
            Long last = perCheck.get(violation.checkId());
            if (last != null && now - last < current.alertCooldownMs()) {
                return;
            }
            perCheck.put(violation.checkId(), now);
        }

        Component message = LEGACY.deserialize(format(current.alertFormat(), violation));
        for (Player staff : plugin.getServer().getOnlinePlayers()) {
            if (staff.hasPermission(PERMISSION) && !alertsOff.contains(staff.getUniqueId())) {
                staff.sendMessage(message);
            }
        }
    }

    /**
     * Toggles alerts for {@code staff}. Returns {@code true} when alerts are now on.
     */
    public boolean toggle(UUID staff) {
        if (alertsOff.remove(staff)) {
            return true;
        }
        alertsOff.add(staff);
        return false;
    }

    /**
     * Drops the rate limit state of a player who left.
     */
    public void forget(UUID player) {
        lastAlert.remove(player);
    }
}

```java
package me.raph.anticheat.violation;

import me.raph.anticheat.config.PluginConfig;
import org.bukkit.command.CommandSender;
import org.bukkit.plugin.Plugin;

import java.util.Collections;
import java.util.List;
import java.util.Map;
import java.util.NavigableMap;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;
import java.util.function.Predicate;
import java.util.function.Supplier;

/**
 * Runs the configured console commands when a check's VL crosses a threshold.
 *
 * <p>Players for which {@code exempt} returns {@code true} (staff running {@code /ac debug}) are never
 * punished; their violations still alert and get logged.
 */
public final class PunishmentManager {

    private final Plugin plugin;
    private final Supplier<PluginConfig> config;
    private final Predicate<UUID> exempt;
    private final Map<UUID, Map<String, Double>> owed = new ConcurrentHashMap<>();

    /**
     * @param exempt players that must never be punished right now, tested on every crossed threshold
     */
    public PunishmentManager(Plugin plugin, Supplier<PluginConfig> config, Predicate<UUID> exempt) {
        this.plugin = plugin;
        this.config = config;
        this.exempt = exempt;
    }

    /**
     * Thresholds {@code t} with {@code previousVl < t <= vl}, that is the ones this violation went past.
     */
    static <T> NavigableMap<Integer, T> crossedThresholds(NavigableMap<Integer, T> thresholds,
                                                          double previousVl, double vl) {
        int from = (int) Math.floor(previousVl);
        int to = (int) Math.floor(vl);
        if (thresholds.isEmpty() || to <= from) {
            return Collections.emptyNavigableMap();
        }
        return thresholds.subMap(from, false, to, true);
    }

    <T> NavigableMap<Integer, T> due(Violation violation, NavigableMap<Integer, T> thresholds, boolean exempt) {
        UUID player = violation.playerId();
        String check = violation.checkId();
        if (exempt) {
            if (!crossedThresholds(thresholds, violation.previousVl(), violation.vl()).isEmpty()) {
                owed.computeIfAbsent(player, id -> new ConcurrentHashMap<>())
                    .merge(check, violation.previousVl(), Math::min);
            }
            return Collections.emptyNavigableMap();
        }
        double from = violation.previousVl();
        Map<String, Double> playerOwed = owed.get(player);
        if (playerOwed != null) {
            Double owedFrom = playerOwed.remove(check);
            if (owedFrom != null) {
                from = Math.min(from, owedFrom);
            }
            if (playerOwed.isEmpty()) {
                owed.remove(player, playerOwed);
            }
        }
        return crossedThresholds(thresholds, from, violation.vl());
    }

    /**
     * Runs the commands of every threshold crossed by {@code violation}. Main thread only.
     */
    public void handle(Violation violation) {
        if (violation.experimental()) {
            return; // Experimental checks only alert.
        }
        NavigableMap<Integer, List<String>> thresholds = config.get().check(violation.checkId()).punishments();
        if (thresholds.isEmpty()) {
            return;
        }
        boolean isExempt = exempt.test(violation.playerId());
        NavigableMap<Integer, List<String>> due = due(violation, thresholds, isExempt);
        if (isExempt && !crossedThresholds(thresholds, violation.previousVl(), violation.vl()).isEmpty()) {
            plugin.getSLF4JLogger().info("Not punishing {} for {} at vl {} yet: they are using /ac debug",
                    violation.playerName(), violation.checkId(), AlertManager.formatVl(violation.vl()));
        }
        if (due.isEmpty()) {
            return;
        }
        CommandSender console = plugin.getServer().getConsoleSender();
        for (List<String> commands : due.values()) {
            for (String command : commands) {
                String resolved = command
                        .replace("%player%", violation.playerName())
                        .replace("%check%", violation.checkId())
                        .replace("%vl%", AlertManager.formatVl(violation.vl()));
                try {
                    plugin.getServer().dispatchCommand(console, resolved);
                } catch (RuntimeException e) {
                    plugin.getSLF4JLogger().error("Punishment command failed: {}", resolved, e);
                }
            }
        }
    }

    public void forget(UUID player) {
        owed.remove(player);
    }
}

package me.raph.anticheat.violation;

import me.raph.anticheat.config.PluginConfig;
import me.raph.anticheat.util.MainThread;
import org.bukkit.plugin.Plugin;

import java.time.Instant;
import java.time.ZoneId;
import java.time.format.DateTimeFormatter;
import java.util.Locale;
import java.util.function.Supplier;

/**
 * Single entry point for every violation: alert, then punish (both on the main thread),
 * then append a line to {@code violations.log} on a background thread.
 *
 * <p>Safe to call from any thread.
 */
public final class ViolationHandler {

    private static final DateTimeFormatter TIME = DateTimeFormatter.ISO_OFFSET_DATE_TIME.withZone(ZoneId.systemDefault());
    private static final long SHUTDOWN_TIMEOUT_MS = 2000L;

    private final Plugin plugin;
    private final Supplier<PluginConfig> config;
    private final AlertManager alerts;
    private final PunishmentManager punishments;
    private final ViolationLog log;

    public ViolationHandler(Plugin plugin, Supplier<PluginConfig> config,
                            AlertManager alerts, PunishmentManager punishments) {
        this.plugin = plugin;
        this.config = config;
        this.alerts = alerts;
        this.punishments = punishments;
        this.log = new ViolationLog(plugin.getDataFolder().toPath().resolve("violations.log"), plugin.getSLF4JLogger());
    }

    static String format(Violation v) {
        return String.format(Locale.ROOT, "%s %s (%s) %s%s vl=%.2f %s%n",
                TIME.format(Instant.ofEpochMilli(v.timestamp())),
                v.playerName(),
                v.playerId(),
                v.checkId(),
                v.experimental() ? " [experimental]" : "",
                v.vl(),
                v.debug().replace('\n', ' ').replace('\r', ' '));
    }

    public void handle(Violation violation) {
        MainThread.run(plugin, () -> alerts.alert(violation));
        MainThread.runNextTick(plugin, () -> punishments.handle(violation));
        if (config.get().logToFile()) {
            log.append(format(violation));
        }
    }

    /**
     * Flushes pending log lines. Call from {@code onDisable}.
     */
    public void shutdown() {
        log.close(SHUTDOWN_TIMEOUT_MS);
    }
}

package me.raph.anticheat.violation;

import org.slf4j.Logger;

import java.io.BufferedWriter;
import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.nio.file.StandardOpenOption;
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.BlockingQueue;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicLong;

final class ViolationLog {

    static final int MAX_QUEUED_LINES = 10_000;
    static final long MAX_FILE_BYTES = 10L * 1024L * 1024L;
    static final int KEPT_FILES = 3;

    private final Path file;
    private final Logger logger;
    private final long maxFileBytes;
    private final BlockingQueue<String> queue = new ArrayBlockingQueue<>(MAX_QUEUED_LINES);
    private final AtomicLong dropped = new AtomicLong();
    private final Thread thread;
    private volatile boolean running = true;

    private BufferedWriter writer;
    private long size;

    ViolationLog(Path file, Logger logger) {
        this(file, logger, MAX_FILE_BYTES);
    }

    ViolationLog(Path file, Logger logger, long maxFileBytes) {
        this.file = file;
        this.logger = logger;
        this.maxFileBytes = maxFileBytes;
        this.thread = new Thread(this::run, "AntiCheat-ViolationLog");
        this.thread.setDaemon(true);
        this.thread.start();
    }

    void append(String line) {
        if (!running) {
            return;
        }
        if (!queue.offer(line)) {
            dropped.incrementAndGet();
        }
    }

    void close(long timeoutMillis) {
        running = false;
        try {
            thread.join(timeoutMillis);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
        if (thread.isAlive()) {
            logger.warn("Some violation log lines were not written before shutdown");
        }
    }

    private void run() {
        try {
            while (running || !queue.isEmpty()) {
                String line = queue.poll(250, TimeUnit.MILLISECONDS);
                if (line == null) {
                    reportDropped();
                    continue;
                }
                write(line);
                while ((line = queue.poll()) != null) {
                    write(line);
                }
                flush();
            }
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        } finally {
            reportDropped();
            closeWriter();
        }
    }

    private void write(String line) {
        try {
            if (writer == null) {
                open();
            }
            writer.write(line);
            size += line.getBytes(StandardCharsets.UTF_8).length;
            if (size >= maxFileBytes) {
                rotate();
            }
        } catch (IOException e) {
            logger.error("Could not write to {}", file, e);
            closeWriter();
        }
    }

    private void open() throws IOException {
        Files.createDirectories(file.getParent());
        writer = Files.newBufferedWriter(file, StandardCharsets.UTF_8,
                StandardOpenOption.CREATE, StandardOpenOption.APPEND);
        size = Files.size(file);
    }

    private void rotate() throws IOException {
        closeWriter();
        for (int i = KEPT_FILES - 1; i >= 1; i--) {
            Path older = rotated(i);
            if (Files.exists(older)) {
                Files.move(older, rotated(i + 1), StandardCopyOption.REPLACE_EXISTING);
            }
        }
        Files.move(file, rotated(1), StandardCopyOption.REPLACE_EXISTING);
    }

    private Path rotated(int index) {
        return file.resolveSibling(file.getFileName() + "." + index);
    }

    private void flush() {
        if (writer == null) {
            return;
        }
        try {
            writer.flush();
        } catch (IOException e) {
            logger.error("Could not write to {}", file, e);
            closeWriter();
        }
    }

    private void closeWriter() {
        if (writer == null) {
            return;
        }
        try {
            writer.close();
        } catch (IOException e) {
            logger.error("Could not close {}", file, e);
        }
        writer = null;
    }

    private void reportDropped() {
        long count = dropped.getAndSet(0L);
        if (count > 0) {
            logger.warn("Dropped {} violation log lines: the log file could not keep up", count);
        }
    }
}

            return 0L;
        }
        if (type == int.class) {
            return 0;

    void writesLinesInOrderAndFlushesOnClose() throws IOException {

        ViolationLog log = new ViolationLog(file, NOPLogger.NOP_LOGGER);
        log.append("a\n");
        log.append("b\n");
        log.close(5000);

    }

    void appendAfterCloseIsIgnored() throws IOException {
        Path file = dir.resolve("violations.log");
        ViolationLog log = new ViolationLog(file, NOPLogger.NOP_LOGGER);
        log.append("a\n");
        log.close(5000);
        log.append("late\n");
        assertEquals(List.of("a"), Files.readAllLines(file));
    }

    @Test
    void rotatesWhenTheFileGetsTooBig() throws IOException {
        Path file = dir.resolve("violations.log");
        ViolationLog log = new ViolationLog(file, NOPLogger.NOP_LOGGER, 10);
        for (int i = 0; i < 5; i++) {
            log.append("line-" + i + "\n");
        }
        log.close(5000);
        assertEquals(List.of("line-4"), Files.readAllLines(file));
        assertEquals(List.of("line-2", "line-3"), Files.readAllLines(dir.resolve("violations.log.1")));
        assertEquals(List.of("line-0", "line-1"), Files.readAllLines(dir.resolve("violations.log.2")));
