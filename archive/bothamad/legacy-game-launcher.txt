```md
# Changelog

All notable changes to Legacy Game Launcher. Versions match the GitHub release tags (`vX.Y.Z`).
Earlier versions (0.1–0.4.3) were built before the project was on GitHub; their changes are listed here
and included in the first GitHub release.

## 0.5.0 - 2026-11-15
- **Fixes tab**: one-click *Download & apply* / *Remove* for dinputto8 (DirectInput crash fix), dgVoodoo2 and DXVK.
  Downloads come only from each project's own GitHub release, are checked against GitHub's published SHA-256,
  kept in `%LocalAppData%\LegacyGameLauncher\tools`, and installed with backup and undo.
- **Check for updates**: the launcher checks its GitHub releases at start-up and from the sidebar button, and can
  download (SHA-256 verified), swap in and restart into the new version.
- Project now on GitHub, with a changelog per release.

## 0.4.3
- A crash inside an input/graphics/audio DLL no longer triggers the misleading "SafeDisc loader may not have run" note.

## 0.4.2
- Live tester labels controllers that HidHide hides from games.

## 0.4.1
- **Live controller tester** (Controllers tab): buttons, axes (X/Y/Z/Rx/Ry/Rz) and D-pad exactly as DirectInput games
  see them, with PS4 / Xbox button names.

## 0.4.0
- **New Windows 11 Fluent UI** (WPF-UI): Mica window, library sidebar, header with an always-visible Launch button,
  single-row tabs, card sections, light/dark following Windows.

## 0.3.1
- **Disc image mounting**: per-game .iso, mount before launch / unmount after (Windows' built-in mounting, read-only, no admin).
- SafeDiscLoader2 log check no longer reports a failure after a clean run.

## 0.3.0
- **SafeDiscLoader2 cooperation** (a loader the user installed): Auto / On / Off per game; no compatibility layers
  (existing ones removed, undoable); CPU limit/priority opt-in; follows child processes such as `~e5.0001.exe`;
  loader-log check replaces the generic DRM message.
- Every game now starts with its exe folder as working directory.

## 0.2.1
- Direct3D version is taken from the game exe first (installer DLLs no longer confuse it).
- Detection of modified (copy-protection-removed) executables - detection only.

## 0.2.0
- Research-based profiles for Rugby 08 and Cricket 07 (sources listed).
- Direct3D 8 wrapper support (dgVoodoo2 `D3D8.dll`, DXVK 2.4+).
- dinputto8 input-wrapper option; crash advice from the event log's faulting module.
- Binary `.pro` resolution editor; text-encoding fix.

## 0.1.0
- First version: game library with profile detection, DirectX/VC++ dependency checker, compatibility layers,
  CPU affinity/priority, graphics wrapper install with backup, config scanner/editor, controller detection,
  launch diagnostics with event-log entries, change journal with undo, copy-protection detection (detection only).
```

```md
# Rugby 08 and Cricket 07: research notes (November 2026)

The automated fetches were blocked by PCGamingWiki, the EA forums and Vogons, so these notes rely
on search-result summaries of those pages, GitHub projects and community forums. Each fact below
is labelled with how solid it is. The launcher checks the things it can (Direct3D version, input
API, copy-protection markers) against your actual exe instead of trusting the profile.

## Cricket 07 (HB Studios / EA Canada, 2006)

| Fact | Confidence | Source |
|---|---|---|
| Exe is `Cricket07.exe` in `C:\Program Files (x86)\EA SPORTS\EA SPORTS(TM) Cricket 07\` | **Confirmed** | Your crash report; cricket07-browser project |
| **Direct3D 8** (not 9), shaders vs/ps 1.1 | High | github.com/Dhaiwat10/cricket07-browser |
| Input through **legacy DirectInput (`dinput.dll`)**, audio through DirectSound | High | cricket07-browser; Hybrid Analysis strings; your crash in DINPUT.dll |
| Settings in a **binary** profile: `%USERPROFILE%\Documents\EA SPORTS(TM) Cricket 07\<user-id>.pro` | High | PCGamingWiki; planetcricket/megacricketstudio guides |
| Retail disc uses **SafeDisc 4**, which can't run on Windows 10/11 (secdrv.sys disabled) | High | PCGamingWiki; GameCopyWorld; cricket07-browser |
| Fixes reported to work: Windows 7 compatibility mode, run as admin, dgVoodoo2 (some graphical glitches). dxwrapper crashed for one user. Windows 10 worked but Windows 11 crashed for another. | Anecdotal | megacricketstudio; Vogons; EA Forums |
| Widescreen only through a community mod (retrobone/EACricketWidescreenFix) | High | GitHub; PCGamingWiki |
| No official DRM-free or digital re-release | As far as found | EA Forums / no store listing found |

## Rugby 08 (HB Studios, 2007)

| Fact | Confidence | Source |
|---|---|---|
| Exe is `Rugby08.exe` under `Program Files\EA SPORTS\…` | High | Several install listings |
| **Direct3D 8** | Medium (inferred) | The PCGamingWiki community widescreen fix uses dgVoodoo2's `d3d8.dll` |
| Same engine family as Cricket 07 | Medium | Same developer and era |
| Settings in a **binary** `.pro` profile in `Documents\EA SPORTS(TM) Rugby 08\` (forums write "EA SPORTS™ Rugby 08") | High | therugbyforum.com resolution threads |
| Resolution stored as two **little-endian 16-bit values, width then height** (1024x768 = `00 04 00 03`, 1920x1080 = `80 07 38 04`). The offset differs between profiles (users report 636, 638 and 658). Changing display options in the game can reset it to 1024x768. | High | therugbyforum.com (several users confirmed) |
| Listed as using **SafeDisc** (version not given) | Medium | PCGamingWiki SafeDisc page |
| Freezes at the start-up screen, sometimes caused by antivirus | Anecdotal | therugbyforum.com |

## Changes made to the launcher from this research

- **Direct3D 8 wrapper support.** The wrapper now installs `d3d8.dll` for Direct3D 8 games
  (dgVoodoo2 `MS\x86\D3D8.dll`; for DXVK 2.4+, `x32\d3d8.dll` plus `d3d9.dll`). Before, it only
  installed `d3d9.dll`, which these games never load.
- **dinputto8 option** on the Controllers tab, for legacy-DirectInput crashes. You download it yourself; it's copied with backup and restore.
- **Crash advice** taken from the event log's "Faulting module name", for example DINPUT.dll → unplug HID devices, then try dinputto8.
- **`.pro` resolution editor.** It searches the binary profile for a known resolution pair and edits only
  when there's exactly one match. The original is backed up and can be undone.
- Profiles now have the confirmed exe and folder names and list their sources.
  The CPU-core limit is kept as a precaution and is marked as not sourced. Priority is back to Normal.

## Assumed and not found

Registry keys for either game, any official patch for Windows 10/11, and any confirmed CPU-core
or high-refresh-rate problem specific to these games.
```

```cs
using System.Windows;
using LegacyGameLauncher.Services;

namespace LegacyGameLauncher;

public partial class App : Application
{
    protected override void OnStartup(StartupEventArgs e)
    {
        // Elevated helper modes: do one approved job, no UI, then exit.
        if (e.Args.Length == 3 && e.Args[0] == "--fileops")
        {
            Shutdown(FileOpRunner.RunHelper(e.Args[1], e.Args[2]));
            return;
        }
        if (e.Args.Length == 3 && e.Args[0] == "--launch")
        {
            Shutdown(GameProcess.RunLaunchHelper(e.Args[1], e.Args[2]));
            return;
        }

        base.OnStartup(e);
        AppPaths.Ensure();
        // Staged config copies are only needed until they've been copied into place.
        foreach (var f in Directory.EnumerateFiles(AppPaths.Staging))
            try { if (File.GetLastWriteTime(f) < DateTime.Now.AddDays(-1)) File.Delete(f); } catch { }
        ProfileCatalog.Load();
        ProfileCatalog.ExportExamples();
        DispatcherUnhandledException += (_, ex) =>
        {
            MessageBox.Show(ex.Exception.ToString(), "Unexpected error", MessageBoxButton.OK, MessageBoxImage.Error);
            ex.Handled = true;
        };
        new MainWindow().Show();
    }
}
```

```cs
using System.Text;
using System.Windows;
using System.Windows.Controls;
using LegacyGameLauncher.Models;
using LegacyGameLauncher.Services;
using Microsoft.Win32;

namespace LegacyGameLauncher;

public partial class MainWindow
{
    // ------------------------------------------------------------------ 3. Compatibility

    void LoadCompatUi()
    {
        if (_g == null) return;
        var c = _g.Compat;
        OsModeBox.SelectedIndex = Math.Max(0, Array.FindIndex(OsLabels, o => o.Value == c.OsMode));
        FsoBox.IsChecked = c.DisableFullscreenOptimizations; DpiBox.IsChecked = c.HighDpiAware; AdminBox.IsChecked = c.RunAsAdmin;
        Color16Box.IsChecked = c.ReducedColor16; Res640Box.IsChecked = c.Res640x480; ThemesBox.IsChecked = c.DisableThemes;
        var coreIdx = c.CoreLimit <= 0 ? 0 : CoreBox.Items.IndexOf($"{c.CoreLimit} core{(c.CoreLimit > 1 ? "s" : "")}");
        CoreBox.SelectedIndex = Math.Max(0, coreIdx);
        PriorityBox.SelectedItem = Priorities.Contains(c.Priority) ? c.Priority : "Normal";
        ArgsBox.Text = c.Arguments;
        _loadingLoaderUi = true;
        LoaderBox.SelectedIndex = c.SafeDiscLoader switch { "On" => 1, "Off" => 2, _ => 0 };
        _loadingLoaderUi = false;
        LoaderCpuBox.IsChecked = c.CpuSettingsWithLoader;
        UpdateLoaderHint();
        IsoBox.Text = c.DiscImagePath; IsoMountBox.IsChecked = c.MountDiscImage; IsoUnmountBox.IsChecked = c.UnmountAfterExit;
        UpdateIsoStatus();
        CompatStatus.Text = $"Current HKCU value: {CompatLayers.ReadHkcu(_g.ExePath) ?? "(none)"}";
    }

    bool _loadingLoaderUi;

    void LoaderBox_Changed(object sender, SelectionChangedEventArgs e)
    {
        if (_g == null || _loadingLoaderUi) return;
        _g.Compat.SafeDiscLoader = LoaderMode();
        Save(); UpdateLoaderHint(); RenderOverview();
    }

    string LoaderMode() => LoaderBox.SelectedIndex switch { 1 => "On", 2 => "Off", _ => "Auto" };

    bool LoaderActive(GameEntry g) => SafeDiscLoaderSupport.IsActive(g.Compat, _loader);

    void ReadCompatUi()
    {
        if (_g == null) return;
        var c = _g.Compat;
        c.OsMode = OsLabels[Math.Max(0, OsModeBox.SelectedIndex)].Value;
        c.DisableFullscreenOptimizations = FsoBox.IsChecked == true; c.HighDpiAware = DpiBox.IsChecked == true; c.RunAsAdmin = AdminBox.IsChecked == true;
        c.ReducedColor16 = Color16Box.IsChecked == true; c.Res640x480 = Res640Box.IsChecked == true; c.DisableThemes = ThemesBox.IsChecked == true;
        var core = CoreBox.SelectedItem as string ?? "";
        c.CoreLimit = int.TryParse(core.Split(' ')[0], out var n) ? n : 0;
        c.Priority = PriorityBox.SelectedItem as string ?? "Normal";
        c.Arguments = ArgsBox.Text.Trim();
        c.SafeDiscLoader = LoaderMode();
        c.CpuSettingsWithLoader = LoaderCpuBox.IsChecked == true;
        ReadIsoUi();
    }

    void ReadIsoUi()
    {
        if (_g == null) return;
        _g.Compat.DiscImagePath = IsoBox.Text.Trim().Trim('"');
        _g.Compat.MountDiscImage = IsoMountBox.IsChecked == true;
        _g.Compat.UnmountAfterExit = IsoUnmountBox.IsChecked == true;
    }

    void UpdateIsoStatus()
    {
        if (_g == null) return;
        var iso = _g.Compat.DiscImagePath;
        if (string.IsNullOrWhiteSpace(iso)) { IsoStatus.Text = "No disc image set. Only needed if the game (or your loader setup) wants the disc in a drive."; return; }
        if (!File.Exists(iso)) { IsoStatus.Text = "✗ File not found."; return; }
        var d = DiscImage.MountedDrive(iso);
        IsoStatus.Text = d != null ? $"Mounted as {d} ({SafeLabel(d)})." : "Not mounted.";
    }

    static string SafeLabel(string drive) { try { return new DriveInfo(drive).VolumeLabel; } catch { return "?"; } }

    void IsoOption_Click(object sender, RoutedEventArgs e) { ReadIsoUi(); Save(); }
    void IsoBox_LostFocus(object sender, RoutedEventArgs e) { ReadIsoUi(); Save(); UpdateIsoStatus(); }

    void IsoBrowse_Click(object sender, RoutedEventArgs e)
    {
        if (_g == null) return;
        var dlg = new OpenFileDialog { Title = "Select the disc image of your game disc", Filter = "Disc images (*.iso)|*.iso|All files (*.*)|*.*" };
        if (dlg.ShowDialog(this) != true) return;
        IsoBox.Text = dlg.FileName;
        if (IsoMountBox.IsChecked != true) IsoMountBox.IsChecked = true;
        ReadIsoUi(); Save(); UpdateIsoStatus();
    }

    async void IsoMount_Click(object sender, RoutedEventArgs e)
    {
        if (_g == null) return;
        ReadIsoUi(); Save();
        var iso = _g.Compat.DiscImagePath;
        try
        {
            IsoStatus.Text = "Mounting…";
            var (drive, now) = await Task.Run(() => DiscImage.Mount(iso));
            IsoStatus.Text = now ? $"✓ Mounted as {drive} ({SafeLabel(drive)})." : $"Already mounted as {drive}.";
        }
        catch (Exception ex) { IsoStatus.Text = "✗ " + ex.Message; }
    }

    async void IsoUnmount_Click(object sender, RoutedEventArgs e)
    {
        if (_g == null) return;
        ReadIsoUi();
        var iso = _g.Compat.DiscImagePath;
        try { await Task.Run(() => DiscImage.Unmount(iso)); IsoStatus.Text = "✓ Unmounted."; }
        catch (Exception ex) { IsoStatus.Text = "✗ " + ex.Message; }
    }

    /// <summary>Mounts the game's disc image before launch if configured. Returns the image path if the launcher mounted it now.</summary>
    async Task<string?> MountForLaunch(GameEntry g)
    {
        var iso = g.Compat.DiscImagePath;
        if (!g.Compat.MountDiscImage || string.IsNullOrWhiteSpace(iso)) return null;
        try
        {
            var (drive, now) = await Task.Run(() => DiscImage.Mount(iso));
            Log(now ? $"Disc image mounted as {drive} ({SafeLabel(drive)}): {iso}" : $"Disc image already mounted as {drive} ({SafeLabel(drive)}) - left as it is.");
            return now ? iso : null;
        }
        catch (Exception ex)
        {
            Log($"WARNING: could not mount the disc image ({ex.Message}). Launching anyway.");
            return null;
        }
    }

    void CompatRecommended_Click(object sender, RoutedEventArgs e)
    {
        if (_g == null) return;
        if (Profile == null) { CompatStatus.Text = "No profile for this game - generic suggestion loaded: Disable fullscreen optimisations + High DPI aware + 4 cores."; _g.Compat = new CompatSettings { DisableFullscreenOptimizations = true, HighDpiAware = true, CoreLimit = 4 }; }
        else
        {
            var old = _g.Compat;
            _g.Compat = Profile.Recommended.Clone();
            // Per-machine choices aren't part of a profile's recommendation - keep them.
            _g.Compat.SafeDiscLoader = old.SafeDiscLoader; _g.Compat.CpuSettingsWithLoader = old.CpuSettingsWithLoader;
            _g.Compat.DiscImagePath = old.DiscImagePath; _g.Compat.MountDiscImage = old.MountDiscImage; _g.Compat.UnmountAfterExit = old.UnmountAfterExit;
        }
        LoadCompatUi();
        if (LoaderActive(_g)) CompatStatus.Text += "\nSafeDisc loader is active: the layers below won't be written and the CPU limit/priority won't be applied when you launch (tick the option to apply CPU settings anyway).";
        CompatStatus.Text += "\nRecommended values loaded - press 'Save & apply' to write them.";
    }

    void CompatApply_Click(object sender, RoutedEventArgs e)
    {
        if (_g == null) return;
        ReadCompatUi();
        try
        {
            if (LoaderActive(_g))
            {
                var removed = CompatLayers.Clear(_g);
                Save(); LoadChanges(); RenderOverview(); UpdateLoaderHint();
                CompatStatus.Text = "Saved. SafeDisc loader is active, so no compatibility layers are written for this exe" +
                                    (removed != null ? $" (removed \"{removed}\"; Undo restores the original)." : ".") +
                                    "\nSet the loader option to Off if you really want layers with this game.";
                return;
            }
            var v = CompatLayers.Apply(_g);
            Save();

    async Task PatchBinaryResolution()
    {
        if (_g == null || _cfg == null) return;
        int w = Int(CfgW.Text), h = Int(CfgH.Text);
        if (w == 0 || h == 0) { ConfigDetected.Text = "Enter both width and height."; return; }
        var bytes = File.ReadAllBytes(_cfg.Path);
        var matches = ConfigScanner.FindResolutionPairs(bytes);
        if (matches.Count != 1) { ConfigDetected.Text = $"✗ Need exactly one stored resolution to edit safely; found {matches.Count}. Nothing changed."; return; }
        var m = matches[0];
        if (MessageBox.Show(this, $"Change the resolution stored in\n{_cfg.Path}\nfrom {m.Width}x{m.Height} to {w}x{h} (4 bytes at offset 0x{m.Offset:X})?\n\n" +
                                  "The original file is backed up first. Changing display options in the game afterwards may reset it.",
                            "Edit binary profile", MessageBoxButton.YesNo) != MessageBoxResult.Yes) return;
        var staged = Path.Combine(AppPaths.Staging, $"{Guid.NewGuid():N}-{_cfg.Name}");
        File.WriteAllBytes(staged, ConfigScanner.WithResolution(bytes, m.Offset, w, h));
        var ops = new List<FileOp>();
        var rec = ChangeJournal.PlanPlaceFile(_g, "config", staged, _cfg.Path, ops, $"Resolution {m.Width}x{m.Height} -> {w}x{h} in {_cfg.Name}");
        var (ok, err) = await FileOpRunner.RunAsync(ops, $"Edit the resolution in {_cfg.Path}", this);
        if (!ok) { ConfigDetected.Text = "✗ " + err; return; }
        if (rec != null) _g.Changes.Add(rec);
        Save(); LoadChanges();
        ConfigEditor.Text = "Binary file - shown read-only (first 1 KB):\n\n" + ConfigScanner.HexPreview(_cfg.Path);
        ConfigDetected.Text = $"✓ Resolution set to {w}x{h} in {_cfg.Name} (original backed up; 'Undo config edits' restores it). " +
                              "If the game can't display this mode, combine it with dgVoodoo2 or undo.";
    }

    async void Launch_Click(object sender, RoutedEventArgs e)
    {
        if (_g == null) return;
        var g = _g;
        if (!File.Exists(g.ExePath)) { MessageBox.Show(this, "The exe no longer exists."); return; }
        LaunchButton.IsEnabled = false;
        TabHost.SelectedIndex = TabHost.Items.Count - 2; // "Launch log"
        LaunchLog.Clear(); _launchLines.Clear();
        string? mountedIso = null;
        try
        {
            ReadCompatUi(); ReadWrapperUi();
            Log($"Preparing {g.DisplayName}");
            // Re-check the folder: the user may have installed or removed the loader since the game was selected.
            _loader = SafeDiscLoaderSupport.Detect(g.ExePath);
            bool loader = LoaderActive(g);
            if (loader)
            {
                Log($"SafeDisc loader mode: {g.Compat.SafeDiscLoader} → active ({(_loader.Detected ? _loader.Evidence : "forced On; loader not detected")}).");
                var removed = CompatLayers.Clear(g);
                Save(); LoadChanges();
                Log(removed != null
                    ? $"Compatibility layers (HKCU): removed \"{removed}\" - layers stop the loader from loading. The original value is in the change journal (Undo restores it)."
                    : "Compatibility layers (HKCU): none (not written while the SafeDisc loader is active).");
            }
            else
            {
                if (_loader.Detected) Log("SafeDisc loader found but loader mode is Off - launching normally.");
                var layers = CompatLayers.Apply(g);
                Save(); LoadChanges();
                Log($"Compatibility layers (HKCU): {layers ?? "(none)"}");
            }
            var hklm = CompatLayers.ReadHklm(g.ExePath);
            if (hklm != null) Log($"Compatibility layers (HKLM, set outside this app - not changed): {hklm}");

            Log($"Game graphics API: Direct3D {(GfxApi == "d3d8" ? "8" : "9")}");
            var wrapDlls = g.Wrapper.InstalledDlls.Count > 0 ? g.Wrapper.InstalledDlls : new List<string> { "d3d9.dll" };
            var missingDlls = wrapDlls.Where(d => !File.Exists(Path.Combine(g.GameDir, d))).ToList();
            if (g.Wrapper.Installed)
                Log(missingDlls.Count == 0
                    ? $"Graphics wrapper: {g.Wrapper.InstalledKind} ({string.Join(" + ", wrapDlls)} present in game folder)"
                    : $"WARNING: {g.Wrapper.InstalledKind} is recorded as installed but {string.Join(", ", missingDlls)} is missing from the game folder.");
            else
            {
                var foreign = new[] { "d3d8.dll", "d3d9.dll", "ddraw.dll", "dinput.dll", "dinput8.dll" }.Where(d => File.Exists(Path.Combine(g.GameDir, d))).ToList();
                Log(foreign.Count > 0 ? $"Note: {string.Join(", ", foreign)} in the game folder were not installed by this launcher (another wrapper or mod)." : "Graphics wrapper: none");
            }
            if (g.Input.Installed) Log($"Input wrapper: {(g.Input.InstalledKind == "" ? "x360ce" : g.Input.InstalledKind)}");

            if (_deps?.HasBlockingIssue == true)
            {
                var missing = string.Join(", ", _deps.Rows.Where(r => r.UsedByGame && !r.Present).Select(r => r.Dll));
                Log("Missing dependencies: " + missing);
                if (MessageBox.Show(this, $"These DLLs the game uses are missing:\n{missing}\n\nThe game will probably fail. Launch anyway?", "Missing dependencies",
                                    MessageBoxButton.YesNo, MessageBoxImage.Warning) != MessageBoxResult.Yes) { Log("Launch cancelled."); return; }
            }

            bool cpu = !loader || g.Compat.CpuSettingsWithLoader;
            if (!cpu && (g.Compat.CoreLimit > 0 || g.Compat.Priority != "Normal"))
                Log($"CPU limit ({(g.Compat.CoreLimit == 0 ? "none" : g.Compat.CoreLimit + " cores")}) and priority ({g.Compat.Priority}) skipped while the SafeDisc loader is active (opt in on the Compatibility tab).");
            var req = new LaunchRequest
            {
                ExePath = g.ExePath, Arguments = g.Compat.Arguments, WorkingDirectory = g.GameDir,
                AffinityMask = cpu ? CompatLayers.AffinityMask(g.Compat.CoreLimit) : 0, Priority = cpu ? g.Compat.Priority : "Normal",
            };
            mountedIso = await MountForLaunch(g);
            var launchStarted = DateTime.Now;
            bool needsAdmin = (g.Compat.RunAsAdmin || _scan?.Exe.ManifestRequiresAdmin == true) && !Environment.IsPrivilegedProcess;
            LaunchResult res;
            if (needsAdmin) res = await LaunchElevated(req, g.Compat.RunAsAdmin ? "RUNASADMIN is enabled for this game" : "the game's exe requests administrator rights");
            else
            {
                LaunchState.Text = "Game running… (this window keeps logging until the game and any child processes exit)";
                res = await Task.Run(() => GameProcess.Run(req, s => Dispatcher.Invoke(() => Log(s))));
                if (!res.Started && res.Win32Error == GameProcess.ERROR_ELEVATION_REQUIRED)
                {
                    Log("Windows says this exe requires elevation.");
                    res = await LaunchElevated(req, "Windows reported that the game requires administrator rights");
                }
            }
            await FinishLaunch(g, res, loader ? _loader : null, launchStarted);
        }
        catch (Exception ex) { Log("ERROR: " + ex); }
        finally
        {
            if (mountedIso != null && g.Compat.UnmountAfterExit)
            {
                try { await Task.Run(() => DiscImage.Unmount(mountedIso)); Log("Disc image unmounted (the launcher had mounted it)."); }
                catch (Exception ex) { Log("Could not unmount the disc image: " + ex.Message); }
            }
            UpdateIsoStatus();
            LaunchButton.IsEnabled = true;
            LaunchState.Text = "Ready.";
        }
    }

    async Task<LaunchResult> LaunchElevated(LaunchRequest req, string why)
    {
        var ok = MessageBox.Show(this, $"The game needs administrator rights ({why}).\n\nThe launcher will start a small elevated helper that starts the game " +
                                       "with your CPU/priority settings and reports back when it exits. The launcher itself stays non-admin.\n\nContinue?",
                                 "Admin rights needed", MessageBoxButton.YesNo, MessageBoxImage.Warning);
        if (ok != MessageBoxResult.Yes) return new LaunchResult { Error = "Cancelled - admin permission not granted." };
        Log("Starting via elevated helper…");
        LaunchState.Text = "Game running (elevated)…";
        return await GameProcess.RunElevatedAsync(req);
    }

    async Task FinishLaunch(GameEntry g, LaunchResult res, LoaderInfo? loader, DateTime launchStarted)
    {
        var rec = new LaunchRecord { Started = res.Started ? res.StartedLocal : DateTime.Now, Ended = res.AllExitedLocal, ExitCode = res.ExitCode };
        if (!res.Started)
        {
            Log($"FAILED TO START: {res.Error} (Win32 error {res.Win32Error})");
            rec.Summary = "failed to start: " + res.Error;
        }
        else
        {
            Log($"Elevated: {res.Elevated}. Affinity: {res.AffinityResult}. Priority: {res.PriorityResult}.");
            if (res.ProcessTree.Count > 0) Log("Process tree: " + string.Join(", ", res.ProcessTree));
            var mainTime = (res.MainExitedLocal ?? DateTime.Now) - res.StartedLocal;
            var totalTime = (res.AllExitedLocal ?? res.MainExitedLocal ?? DateTime.Now) - res.StartedLocal;
            // When child processes carried on (SafeDisc's helper, or a game that relaunches itself), the main exe's early
            // exit is expected; judge the session by how long the whole tree ran.
            var runTime = res.ChildrenOutlivedMain ? totalTime : mainTime;
            if (!string.IsNullOrEmpty(res.WorkingDirectory)) Log($"Working directory: {res.WorkingDirectory}");
            if (res.ChildrenOutlivedMain)
                Log($"Main exe exited after {mainTime.TotalSeconds:0.0}s with {ExitCodes.Describe((uint)(res.ExitCode ?? 0))} while its child processes kept running" +
                    $"{(loader != null ? " (expected with SafeDisc)" : "")}; the game tree ran {totalTime.TotalSeconds:0.0}s in total.");
            else
                Log($"Exit code: {ExitCodes.Describe((uint)(res.ExitCode ?? 0))} after {runTime.TotalSeconds:0.0}s");
            if (res.ExitCode != 0) Log($"Crash/exit time: {res.MainExitedLocal:yyyy-MM-dd HH:mm:ss}");
            Log("Waiting a few seconds for Windows Error Reporting to write event log entries…");
            await Task.Delay(3000);
            var events = await Task.Run(() => Diagnostics.EventLogErrors(Path.GetFileName(g.ExePath), res.StartedLocal));
            Log(events.Count == 0 ? "Event log: no application errors for this exe during the session." : $"Event log: {events.Count} entr{(events.Count == 1 ? "y" : "ies")}:");
            foreach (var ev in events) Log("  " + ev);
            foreach (var a in Diagnostics.CrashAdvice(events, g)) Log("SUGGESTION: " + a);
            if (loader != null)
            {
                // The loader's own log is the reliable signal here; the generic DRM guess would be a false alarm.
                bool ok = (res.ExitCode == 0 || res.ChildrenOutlivedMain) && totalTime > TimeSpan.FromSeconds(15) && events.Count == 0;
                // A crash inside an input/graphics/audio DLL happens in the game's own start-up code, i.e. after the
                // disc check - then the loader isn't the suspect and "may not have run" would send you the wrong way.
                var lateModule = new[] { "dinput.dll", "dinput8.dll", "xinput", "d3d8.dll", "d3d9.dll", "dsound.dll", "nvd3dum", "atidxx", "igdumd" }
                    .FirstOrDefault(m => events.Any(ev => ev.Contains("Faulting module name: " + m, StringComparison.OrdinalIgnoreCase)));
                if (!ok && lateModule != null)
                    Log($"SafeDisc loader: not the likely cause - the crash is in {lateModule}, which the game only loads after its start-up checks. Follow the suggestion above.");
                else
                    foreach (var l in SafeDiscLoaderSupport.PostLaunchReport(loader, launchStarted, ok)) Log(l);
            }
            else
            {
                var drmHint = DrmDetector.PostLaunchHint(_drm, runTime, res.ExitCode);
                bool mainFailed = res.ExitCode != 0 && !res.ChildrenOutlivedMain;
                if (drmHint != null && (mainFailed || runTime < TimeSpan.FromSeconds(20)))
                    Log((_drm.Any(d => d.Scheme == DrmDetector.ModifiedScheme) ? "MODIFIED EXE: " : "POSSIBLE DRM FAILURE: ") + drmHint);
            }
            rec.Summary = res.ChildrenOutlivedMain
                ? $"main exe exit {ExitCodes.Describe((uint)(res.ExitCode ?? 0))} after {mainTime.TotalSeconds:0}s, game tree ran {totalTime.TotalSeconds:0}s"
                : $"exit {ExitCodes.Describe((uint)(res.ExitCode ?? 0))}, ran {runTime.TotalSeconds:0}s";
        }
        rec.Report = BuildReport(g);
        g.Launches.Add(rec);
        if (g.Launches.Count > 30) g.Launches.RemoveAt(0);
        Save(); LoadHistory();

        sb.AppendLine();
        sb.AppendLine($"Game: {g.DisplayName}");
        sb.AppendLine($"Exe: {g.ExePath}");
        sb.AppendLine($"Arch: {_scan?.Exe.ArchName}   SHA-256: {g.Sha256}");
        sb.AppendLine($"Profile: {Profile?.Name ?? "none"} ({g.DetectionNote})");
        sb.AppendLine();
        sb.AppendLine("-- Active fixes --");
        sb.AppendLine($"Compat layers (HKCU): {CompatLayers.ReadHkcu(g.ExePath) ?? "(none)"}");
        var hklm = CompatLayers.ReadHklm(g.ExePath);
        if (hklm != null) sb.AppendLine($"Compat layers (HKLM): {hklm}");
        sb.AppendLine($"CPU limit: {(g.Compat.CoreLimit == 0 ? "none" : g.Compat.CoreLimit + " cores")}, priority: {g.Compat.Priority}, args: \"{g.Compat.Arguments}\"");
        sb.AppendLine($"SafeDisc loader: mode {g.Compat.SafeDiscLoader}, {(_loader.Detected ? "detected (" + _loader.Evidence + ")" : "not detected")}, " +
                      $"{(LoaderActive(g) ? "active" + (g.Compat.CpuSettingsWithLoader ? ", CPU settings applied" : ", CPU settings skipped") : "inactive")}");
        if (!string.IsNullOrWhiteSpace(g.Compat.DiscImagePath))
            sb.AppendLine($"Disc image: {g.Compat.DiscImagePath} (mount before launch: {g.Compat.MountDiscImage}, unmount after: {g.Compat.UnmountAfterExit})");
        var w = g.Wrapper;
        sb.AppendLine(w.Installed
            ? $"Graphics wrapper: {w.InstalledKind} - res {(w.ForcedWidth > 0 ? $"{w.ForcedWidth}x{w.ForcedHeight}" : "unforced")}, refresh cap {w.RefreshCap}, windowed {w.Windowed}, borderless {w.Borderless}, vsync {w.VSync}, fps limit {w.FpsLimit}"
            : "Graphics wrapper: none");
        sb.AppendLine($"Input wrapper: {(g.Input.Installed ? (g.Input.InstalledKind == "" ? "x360ce" : g.Input.InstalledKind) : "none")}");
        sb.AppendLine($"Graphics API: Direct3D {(GfxApi == "d3d8" ? "8" : "9")}; input API: {(_scan == null ? "?" : ControllerService.GameInputApi(_scan.Referenced, Profile, out _))}");
        sb.AppendLine($"Journaled changes: {g.Changes.Count}");
        sb.AppendLine();
        sb.AppendLine("-- Dependencies --");
        if (_deps == null) sb.AppendLine("(not checked)");
        else
        {
            var bad = _deps.Rows.Where(r => r.UsedByGame && !r.Present).Select(r => r.Dll).ToList();
            sb.AppendLine(bad.Count == 0 ? "All referenced legacy DLLs present." : "MISSING: " + string.Join(", ", bad));
            sb.AppendLine("Referenced by game: " + string.Join(", ", _scan?.Referenced.OrderBy(x => x) ?? Enumerable.Empty<string>()));
        }
        sb.AppendLine();
        sb.AppendLine("-- Copy protection --");
        sb.AppendLine(_drm.Count == 0 ? "none detected" : string.Join("\n", _drm.Select(d => $"{d.Scheme}: {d.Evidence}")));
        sb.AppendLine();
        sb.AppendLine("-- Launch log --");
        foreach (var l in _launchLines) sb.AppendLine(l);
        return sb.ToString();
    }
```

```cs
    /// <summary>Uses the cached copy, or asks and downloads the latest release.</summary>
    async Task<string?> EnsureTool(ToolSpec t)
    {
        if (ToolDownloader.Cached(t) is { } c)
        {
            FixLogLine($"Using downloaded {t.Name} {c.Manifest.Tag} (SHA-256 {c.Manifest.Sha256[..12]}…).");
            return ToolDownloader.InstallRoot(t, c.Folder);
        }
        FixLogLine($"Checking the latest {t.Name} release on github.com/{t.Repo}…");
        var rel = await ToolDownloader.LatestAsync(t);
        var ok = MessageBox.Show(this,
            $"Download {t.Name} {rel.Tag}?\n\nFile: {rel.AssetName} ({rel.Size / 1024.0 / 1024.0:0.0} MB)\nFrom: github.com/{t.Repo} (official release, {rel.Published:yyyy-MM-dd})\n" +

            "Download fix", MessageBoxButton.YesNo, MessageBoxImage.Question);
        if (ok != MessageBoxResult.Yes) { FixLogLine("Download cancelled."); return null; }
        var progress = new Progress<string>(s => { FixLogLine(s); LaunchState.Text = s; });
        var folder = await ToolDownloader.DownloadAsync(t, rel, progress);
        return ToolDownloader.InstallRoot(t, folder);

            }
        }
        catch (Exception ex) { FixLogLine("✗ " + ex.Message); }
```

```cs
        }

    void RenderTester()
    {
        if (_tester == null) return;
        var pads = _tester.Pads;
        if (pads.Count == 0) return;
        if (_padViews.Count == 0) TesterPanel.Children.Clear();

        foreach (var pad in pads)
        {
            if (!_padViews.TryGetValue(pad.Handle, out var view))
            {
                view = BuildPadView(pad);
                _padViews[pad.Handle] = view;
            }
            foreach (var a in pad.Axes)
            {
                if (!view.Axes.TryGetValue((a.Page, a.Usage), out var ui)) continue;
                if (a.IsHat) { ui.Text.Text = a.HatText; continue; }
                ui.Bar.Value = a.Value * 100;
                ui.Text.Text = $"{a.Value * 100:0}%  (raw {a.Raw})";
            }
            foreach (var (n, b) in view.Buttons)
            {
                bool on = pad.Pressed.Contains(n);
                b.Background = on ? (Brush)FindResource("AccentFillColorDefaultBrush") : (Brush)FindResource("ControlFillColorSecondaryBrush");
                ((TextBlock)b.Child).Foreground = on ? (Brush)FindResource("TextOnAccentFillColorPrimaryBrush") : (Brush)FindResource("TextFillColorPrimaryBrush");
            }
            view.Status.Text = pad.Pressed.Count == 0
                ? "Pressed: none"
                : "Pressed: " + string.Join(", ", pad.Pressed.OrderBy(x => x).Select(x => "Button " + x + KnownButton(pad.Name, x)));
        }

    static string KnownButton(string padName, int n)
    {
        bool ps = padName.Contains("Wireless Controller", StringComparison.OrdinalIgnoreCase) || padName.Contains("DualShock", StringComparison.OrdinalIgnoreCase) || padName.Contains("DualSense", StringComparison.OrdinalIgnoreCase);
        bool xbox = padName.Contains("Xbox", StringComparison.OrdinalIgnoreCase) || padName.Contains("XINPUT", StringComparison.OrdinalIgnoreCase);
        string? label = ps ? n switch { 1 => "Square", 2 => "Cross", 3 => "Circle", 4 => "Triangle", 5 => "L1", 6 => "R1", 7 => "L2", 8 => "R2", 9 => "Share", 10 => "Options", 11 => "L3", 12 => "R3", 13 => "PS", 14 => "Touchpad", _ => null }
                      : xbox ? n switch { 1 => "A", 2 => "B", 3 => "X", 4 => "Y", 5 => "LB", 6 => "RB", 7 => "Back", 8 => "Start", 9 => "LS", 10 => "RS", _ => null }
                      : null;
        return label == null ? "" : $" ({label})";
    }

    {
        var view = new PadView();
```

```cs
/// <summary>Sidebar: version, "Check for updates", and the update banner.</summary>

    {
        UpdateService.CleanupOld();
        VersionText.Text = $"Version {UpdateService.Current}";
        // Quiet check shortly after start; failures (offline etc.) are ignored.
        Loaded += async (_, _) => { await Task.Delay(1500); await CheckForUpdates(quiet: true); };

    async Task CheckForUpdates(bool quiet)
    {
        try
        {
            if (!quiet) VersionText.Text = "Checking…";
            var u = await UpdateService.CheckAsync();
            VersionText.Text = $"Version {UpdateService.Current}";
            if (u.IsNewer)
            {
                _update = u;
                UpdateText.Text = $"Version {u.Latest} is available (you have {UpdateService.Current}).";
                UpdateBanner.Visibility = Visibility.Visible;
                if (!quiet && !string.IsNullOrWhiteSpace(u.Notes))
                    MessageBox.Show(this, $"What's new in {u.Tag}:\n\n{Shorten(u.Notes, 1500)}", "Update available", MessageBoxButton.OK, MessageBoxImage.Information);
            }
            else if (!quiet)
                MessageBox.Show(this, $"You have the latest version ({UpdateService.Current}).", "No update", MessageBoxButton.OK, MessageBoxImage.Information);
        }
        catch (Exception ex)
        {
            VersionText.Text = $"Version {UpdateService.Current}";
            if (!quiet) MessageBox.Show(this, "Couldn't check for updates: " + ex.Message, "Update check", MessageBoxButton.OK, MessageBoxImage.Warning);
        }
    }

    static string Shorten(string s, int max) => s.Length <= max ? s : s[..max] + "…";

    async void CheckUpdates_Click(object sender, RoutedEventArgs e) => await CheckForUpdates(quiet: false);

                            "Update", MessageBoxButton.YesNo, MessageBoxImage.Question) != MessageBoxResult.Yes) return;
        UpdateNowButton.IsEnabled = false;
        try
        {
            var exe = await UpdateService.DownloadAndSwapAsync(_update, new Progress<string>(s => UpdateText.Text = s));
            UpdateService.Restart(exe);
        }
        catch (Exception ex)
        {
            UpdateText.Text = "Update failed: " + ex.Message;
            UpdateNowButton.IsEnabled = true;
```

```cs
    void AddGame_Click(object sender, RoutedEventArgs e)
    {
        var dlg = new OpenFileDialog { Filter = "Game executable (*.exe)|*.exe", Title = "Select the game's .exe" };
        if (dlg.ShowDialog(this) != true) return;
        var exe = dlg.FileName;
        var existing = _lib.Games.FirstOrDefault(g => g.ExePath.Equals(exe, StringComparison.OrdinalIgnoreCase));
        if (existing != null) { GameList.SelectedItem = existing; return; }

        var pe = PeReader.Read(exe);
        if (!pe.IsValid) { MessageBox.Show(this, "That file is not a Windows executable: " + pe.Error); return; }
        string sha;
        try { sha = GameDetector.Sha256Of(exe); } catch (Exception ex) { MessageBox.Show(this, "Cannot read the exe: " + ex.Message); return; }
        var (profile, note) = GameDetector.Detect(exe, sha);
        var g = new GameEntry
        {
            ExePath = exe, Sha256 = sha, ProfileId = profile?.Id, DetectionNote = note,
            DisplayName = profile?.Name ?? FileVersionName(exe) ?? Path.GetFileNameWithoutExtension(exe),
        };
        if (profile != null)
        {
            // Pre-fill (not applied until you press Save & apply / Launch).
            g.Compat = profile.Recommended.Clone();
            CopyWrapperNumbers(profile.RecommendedWrapper, g.Wrapper);
        }
        _lib.Games.Add(g);
        Save();
        _g = g;
        RefreshList();
        GameList.SelectedItem = g;
    }

    static string? FileVersionName(string exe)
    {
        try { var v = FileVersionInfo.GetVersionInfo(exe); return string.IsNullOrWhiteSpace(v.ProductName) ? null : v.ProductName.Trim(); } catch { return null; }
    }

    static void CopyWrapperNumbers(WrapperSettings from, WrapperSettings to)
    {
        to.RefreshCap = from.RefreshCap; to.VSync = from.VSync; to.FpsLimit = from.FpsLimit;
        to.Windowed = from.Windowed; to.Borderless = from.Borderless;
        to.ForcedWidth = from.ForcedWidth; to.ForcedHeight = from.ForcedHeight;
        if (!to.Installed && from.Kind != "None") to.Kind = from.Kind;
    }

    async void RemoveGame_Click(object sender, RoutedEventArgs e)
    {
        if (_g == null) return;
        if (_g.Changes.Count > 0)
        {
            var r = MessageBox.Show(this, $"The launcher still has {_g.Changes.Count} active change(s) for {_g.DisplayName} (compat layers / wrapper files / config edits).\n\n" +
                                          "Yes = undo them all first, then remove.\nNo = remove from the library but leave the changes in place.\nCancel = keep the game.",
                                    "Remove game", MessageBoxButton.YesNoCancel, MessageBoxImage.Question);
            if (r == MessageBoxResult.Cancel) return;
            if (r == MessageBoxResult.Yes)
            {
                var (ok, log) = await ChangeJournal.UndoAsync(_g, null, this);
                if (!ok) { MessageBox.Show(this, "Undo failed - game kept in the library.\n\n" + log); Save(); return; }
            }
        }
        _lib.Games.Remove(_g);
        _g = null;
        Save();
        RefreshList();
        if (_lib.Games.Count > 0) GameList.SelectedIndex = 0;
    }

        PadGrid.ItemsSource = null; PadAdvice.Text = "";

        if (!File.Exists(g.ExePath))
        {
            OverviewText.Text = $"The exe no longer exists:\n{g.ExePath}\n\nRemove the game and add it again from its new location.";
            return;
        }
        try
        {
            var exe = g.ExePath;
            var prof = Profile;
            var (scan, drm, loader) = await Task.Run(() => { var s = GameScan.Run(exe); return (s, DrmDetector.Scan(exe, s.Exe, s.ExeLowerText, prof), SafeDiscLoaderSupport.Detect(exe)); });
            if (version != _loadVersion) return;
            _scan = scan; _drm = drm; _loader = loader;
            UpdateLoaderHint();
            RunDependencyCheck();
            RenderOverview();
            FixLog.Clear();
            UpdateFixStatus();
            UpdateWrapperSourceInfo();
        }
        catch (Exception ex) { OverviewText.Text = "Could not inspect the exe: " + ex.Message; }
    }

    void RenderOverview()
    {
        if (_g == null || _scan == null) return;
        var p = Profile;
        var sb = new StringBuilder();
        sb.AppendLine($"Executable : {_g.ExePath}");
        sb.AppendLine($"Architecture: {_scan.Exe.ArchName}{(_scan.Exe.Is32Bit ? "  - wrappers will use x86 DLLs; system DLLs come from SysWOW64" : "")}");
        sb.AppendLine($"SHA-256    : {_g.Sha256}");
        sb.AppendLine($"Profile    : {(p?.Name ?? "none")} - {_g.DetectionNote}");
        try
        {
            var current = GameDetector.Sha256Of(_g.ExePath);
            if (!current.Equals(_g.Sha256, StringComparison.OrdinalIgnoreCase))
                sb.AppendLine($"NOTE: the exe changed since it was added (patched?). New SHA-256: {current}");
        }
        catch { }
        var pf = Environment.GetFolderPath(Environment.SpecialFolder.ProgramFilesX86);
        var pf64 = Environment.GetFolderPath(Environment.SpecialFolder.ProgramFiles);
        if (_g.ExePath.StartsWith(pf, StringComparison.OrdinalIgnoreCase) || _g.ExePath.StartsWith(pf64, StringComparison.OrdinalIgnoreCase))
            sb.AppendLine("Location   : under Program Files - installing wrappers/editing files there will ask for admin; the game's own writes may be redirected to VirtualStore.");
        if (_scan.Exe.ManifestRequiresAdmin) sb.AppendLine("Manifest   : the exe itself requests administrator rights (launch will ask for UAC).");
        sb.AppendLine($"Imports    : {string.Join(", ", _scan.Exe.Imports.DefaultIfEmpty("(none readable - exe may be packed/protected)"))}");
        sb.AppendLine($"Compat (HKCU): {CompatLayers.ReadHkcu(_g.ExePath) ?? "(none)"}");
        var hklm = CompatLayers.ReadHklm(_g.ExePath);
        if (hklm != null) sb.AppendLine($"Compat (HKLM, all users - set by Windows/installer): {hklm}");
        sb.AppendLine($"Wrapper    : {(_g.Wrapper.Installed ? _g.Wrapper.InstalledKind + " installed" : "none installed")}");
        sb.AppendLine($"Graphics   : Direct3D {(GfxApi == "d3d8" ? "8" : "9")}{(WrapperManager.GraphicsApi(_scan, out var sure) != "" && !sure ? " (not certain - no unambiguous d3d8/d3d9 reference found)" : "")}");
        sb.AppendLine($"Input API  : {ControllerService.GameInputApi(_scan.Referenced, p, out _)}");
        if (p != null)
        {
            sb.AppendLine(); sb.AppendLine(p.Notes);
            if (p.Sources.Count > 0) { sb.AppendLine(); sb.AppendLine("Profile sources:"); foreach (var s in p.Sources) sb.AppendLine("  " + s); }
        }
        OverviewText.Text = sb.ToString();

        DrmText.Text = _drm.Count == 0
            ? "No known copy-protection markers found in the exe or game folder."
            : string.Join("\n\n", _drm.Select(d => $"{d.Scheme}  (evidence: {d.Evidence})\n{d.Impact}")) + (p != null && p.DrmNotes.Length > 0 ? "\n\n" + p.DrmNotes : "");
        if (_loader.Detected)
            DrmText.Text = $"SafeDiscLoader2 found ({_loader.Evidence}).\nLauncher mode: {_g.Compat.SafeDiscLoader} → " +
                           $"{(SafeDiscLoaderSupport.IsActive(_g.Compat, _loader) ? "loader-friendly launch (no compatibility layers, game-folder working directory, no CPU/priority changes unless you opt in)" : "normal launch (loader mode is Off)")}." +
                           "\nThe launcher only cooperates with this loader; it does not install, configure or change it.\n\n" + DrmText.Text;
    }

                          (active ? "\nActive: compatibility layers are removed for this exe at launch and CPU limit/priority are skipped unless ticked below." : "");
    }

        var used = _deps.Rows.Count(r => r.UsedByGame);
        var head = _deps.HasBlockingIssue ? "⚠ Missing DLLs this game needs." : $"✓ All {used} legacy runtime DLLs this game references are present.";
        DepAdvice.Text = head + (_deps.Advice.Count > 0 ? "\n" + string.Join("\n", _deps.Advice.Select(a => "• " + a)) : "") +

    }

    async void RunDxSetup_Click(object sender, RoutedEventArgs e)
    {
        MessageBox.Show(this, "1. Download directx_Jun2010_redist.exe from Microsoft (the 'Open DirectX June 2010 download' button).\n" +
                              "2. Run it and extract to an empty folder.\n3. Select DXSETUP.exe from that folder in the next dialog.\n\n" +
                              "Windows will ask for admin rights - DXSETUP installs into System32/SysWOW64.", "Install DirectX June 2010 runtime");
        var dlg = new OpenFileDialog { Filter = "DXSETUP.exe|DXSETUP.exe", Title = "Select DXSETUP.exe from the extracted June 2010 redistributable" };
        if (dlg.ShowDialog(this) != true) return;
        try
        {
#pragma warning disable SYSLIB0057
            var cert = System.Security.Cryptography.X509Certificates.X509Certificate.CreateFromSignedFile(dlg.FileName);
#pragma warning restore SYSLIB0057
            if (!cert.Subject.Contains("Microsoft Corporation"))
            {
                MessageBox.Show(this, "That file is not signed by Microsoft - not running it.\nSigner: " + cert.Subject); return;
            }
        }
        catch { MessageBox.Show(this, "That file has no valid digital signature - not running it."); return; }
        try
        {
            using var p = Process.Start(new ProcessStartInfo(dlg.FileName) { UseShellExecute = true, WorkingDirectory = Path.GetDirectoryName(dlg.FileName)! });
            if (p != null) await p.WaitForExitAsync();
        }
        catch (System.ComponentModel.Win32Exception ex) when (ex.NativeErrorCode == 1223) { return; }
        RunDependencyCheck();
    }
```

```cs
namespace LegacyGameLauncher.Models;

/// <summary>Built-in or user-supplied description of a known game.</summary>
public sealed class GameProfile
{
    public string Id { get; set; } = "";
    public string Name { get; set; } = "";
    /// <summary>Executable file names that identify the game (case-insensitive).</summary>
    public List<string> ExeNames { get; set; } = new();
    /// <summary>Known SHA-256 hashes of the game executable (exact match = highest confidence).</summary>
    public List<string> Sha256 { get; set; } = new();
    /// <summary>Substrings searched in the exe's ProductName / FileDescription version info.</summary>
    public List<string> ProductNameContains { get; set; } = new();
    /// <summary>Substrings searched in the install folder name (lowest confidence).</summary>
    public List<string> FolderNameContains { get; set; } = new();
    /// <summary>Folder names to look for under Documents / AppData / LocalAppData / VirtualStore.</summary>
    public List<string> ConfigFolderNames { get; set; } = new();
    /// <summary>Registry keys (e.g. HKLM\SOFTWARE\WOW6432Node\EA SPORTS\Rugby 08) to show in the config view.</summary>
    public List<string> RegistryKeys { get; set; } = new();
    public CompatSettings Recommended { get; set; } = new();
    public WrapperSettings RecommendedWrapper { get; set; } = new();
    public string InputApiHint { get; set; } = "";
    public string Notes { get; set; } = "";
    public string DrmNotes { get; set; } = "";
    /// <summary>Where the profile's facts come from (shown in the Overview).</summary>
    public List<string> Sources { get; set; } = new();
    public bool BuiltIn { get; set; }
}

public sealed class CompatSettings
{
    /// <summary>"", WIN7RTM, VISTASP2, WINXPSP3, WIN8RTM ...</summary>
    public string OsMode { get; set; } = "";
    /// <summary>DISABLEDXMAXIMIZEDWINDOWEDMODE (= "Disable fullscreen optimisations").</summary>
    public bool DisableFullscreenOptimizations { get; set; }
    public bool HighDpiAware { get; set; }
    public bool RunAsAdmin { get; set; }
    public bool ReducedColor16 { get; set; }
    public bool Res640x480 { get; set; }
    public bool DisableThemes { get; set; }
    /// <summary>0 = no limit, otherwise number of logical CPUs the game may use.</summary>
    public int CoreLimit { get; set; }
    /// <summary>Normal, AboveNormal, High, BelowNormal.</summary>
    public string Priority { get; set; } = "Normal";
    public string Arguments { get; set; } = "";
    /// <summary>
    /// SafeDisc loader mode: "Auto" (use loader behaviour when SafeDiscLoader2's version.dll is found next to the exe),
    /// "On" (always), "Off" (never). The launcher only cooperates with a loader the user installed; it never installs one.
    /// </summary>
    public string SafeDiscLoader { get; set; } = "Auto";
    /// <summary>When the SafeDisc loader is active, CPU limit and priority are skipped unless this is ticked.</summary>
    public bool CpuSettingsWithLoader { get; set; }
    /// <summary>Disc image (.iso) of the user's own game disc, mounted read-only before launch when MountDiscImage is on.</summary>
    public string DiscImagePath { get; set; } = "";
    public bool MountDiscImage { get; set; }
    /// <summary>Unmount after the game exits - only if the launcher mounted it (an image you mounted yourself is left alone).</summary>
    public bool UnmountAfterExit { get; set; } = true;

    public CompatSettings Clone() => (CompatSettings)MemberwiseClone();
}

public sealed class WrapperSettings
{
    /// <summary>None, dgVoodoo2, DXVK.</summary>
    public string Kind { get; set; } = "None";
    public string SourceFolder { get; set; } = "";
    public bool Installed { get; set; }
    public string InstalledKind { get; set; } = "";
    /// <summary>DLL names placed in the game folder (e.g. d3d8.dll, or d3d8.dll + d3d9.dll for DXVK).</summary>
    public List<string> InstalledDlls { get; set; } = new();
    public int ForcedWidth { get; set; }
    public int ForcedHeight { get; set; }
    public int RefreshCap { get; set; } = 60;
    public bool Windowed { get; set; }
    public bool Borderless { get; set; }
    public bool VSync { get; set; } = true;
    public int FpsLimit { get; set; }
}

public sealed class InputWrapperSettings
{
    /// <summary>x360ce (DirectInput pad -> XInput game) or dinputto8 (DirectInput 1-7 game -> DirectInput 8).</summary>
    public string Kind { get; set; } = "x360ce";
    public string SourceFolder { get; set; } = "";
    public bool Installed { get; set; }
    public string InstalledKind { get; set; } = "";
}

/// <summary>One reversible change the launcher made. Used for backup/restore and "Undo".</summary>
public sealed class ChangeRecord
{
    public DateTime When { get; set; } = DateTime.Now;
    /// <summary>compat, wrapper, input, config</summary>
    public string Group { get; set; } = "";
    /// <summary>Registry, FileAdded, FileReplaced</summary>
    public string Kind { get; set; } = "";
    public string Target { get; set; } = "";
    public string? RegistryName { get; set; }
    public bool PreviousExisted { get; set; }
    public string? PreviousValue { get; set; }
    public string? BackupPath { get; set; }
    public string Description { get; set; } = "";

    public override string ToString() => $"[{Group}] {When:yyyy-MM-dd HH:mm}  {Description}";
}

public sealed class LaunchRecord
{
    public DateTime Started { get; set; }
    public DateTime? Ended { get; set; }
    public long? ExitCode { get; set; }
    public string Summary { get; set; } = "";
    public string Report { get; set; } = "";
    public override string ToString() => $"{Started:yyyy-MM-dd HH:mm:ss}  {Summary}";
}

public sealed class GameEntry
{
    public Guid Id { get; set; } = Guid.NewGuid();
    public string ExePath { get; set; } = "";
    public string DisplayName { get; set; } = "";
    public string? ProfileId { get; set; }
    public string DetectionNote { get; set; } = "";
    public string Sha256 { get; set; } = "";
    public CompatSettings Compat { get; set; } = new();
    public WrapperSettings Wrapper { get; set; } = new();
    public InputWrapperSettings Input { get; set; } = new();
    public List<ChangeRecord> Changes { get; set; } = new();
    public List<LaunchRecord> Launches { get; set; } = new();

    public string GameDir => Path.GetDirectoryName(ExePath) ?? "";
    public override string ToString() => DisplayName;
}

public sealed class LibraryData
{
    public int Version { get; set; } = 1;
    public List<GameEntry> Games { get; set; } = new();
}
```

```cs
using System.Text;
using System.Text.RegularExpressions;

namespace LegacyGameLauncher.Services;

public sealed class PeInfo
{
    public bool IsValid { get; set; }
    public string? Error { get; set; }
    public ushort Machine { get; set; }
    public List<string> Imports { get; } = new();
    public List<string> SectionNames { get; } = new();
    public bool ManifestRequiresAdmin { get; set; }

    public bool Is32Bit => Machine == 0x014C;
    public bool Is64Bit => Machine == 0x8664;
    public string ArchName => Machine switch
    {
        0x014C => "x86 (32-bit)",
        0x8664 => "x64 (64-bit)",
        0xAA64 => "ARM64",
        _ => IsValid ? $"unknown (0x{Machine:X4})" : "not a valid PE file",
    };
}

/// <summary>Minimal PE reader: architecture, import table, section names, and a manifest elevation hint.</summary>
public static class PeReader
{
    public static PeInfo Read(string path)
    {
        try { return Parse(File.ReadAllBytes(path)); }
        catch (Exception ex) { return new PeInfo { Error = ex.Message }; }
    }

    /// <summary>Reads just enough of the header to get the machine type (cheap; for DLL validation).</summary>
    public static ushort ReadMachine(string path)
    {
        using var fs = File.OpenRead(path);
        var head = new byte[4096];
        int n = fs.Read(head, 0, head.Length);
        if (n < 0x40 || head[0] != 'M' || head[1] != 'Z') return 0;
        int pe = BitConverter.ToInt32(head, 0x3C);
        if (pe < 0 || pe + 6 > n) return 0;
        if (BitConverter.ToUInt32(head, pe) != 0x00004550) return 0;
        return BitConverter.ToUInt16(head, pe + 4);
    }

    public static PeInfo Parse(byte[] d)
    {
        var info = new PeInfo();
        try
        {
            if (d.Length < 0x40 || d[0] != 'M' || d[1] != 'Z') { info.Error = "No MZ header"; return info; }
            int pe = BitConverter.ToInt32(d, 0x3C);
            if (pe <= 0 || pe + 24 > d.Length || BitConverter.ToUInt32(d, pe) != 0x00004550) { info.Error = "No PE header"; return info; }
            info.Machine = BitConverter.ToUInt16(d, pe + 4);
            int nSec = BitConverter.ToUInt16(d, pe + 6);
            int optSize = BitConverter.ToUInt16(d, pe + 20);
            int opt = pe + 24;
            ushort magic = BitConverter.ToUInt16(d, opt);
            int dataDirs = magic == 0x20B ? opt + 112 : opt + 96;
            int secTable = opt + optSize;
            info.IsValid = true;

            var sections = new List<(uint va, uint vsize, uint raw, uint rawSize)>();
            for (int i = 0; i < nSec && secTable + i * 40 + 40 <= d.Length; i++)
            {
                int s = secTable + i * 40;
                info.SectionNames.Add(Encoding.ASCII.GetString(d, s, 8).TrimEnd('\0'));
                sections.Add((BitConverter.ToUInt32(d, s + 12), BitConverter.ToUInt32(d, s + 8),
                              BitConverter.ToUInt32(d, s + 20), BitConverter.ToUInt32(d, s + 16)));
            }

            int RvaToOffset(uint rva)
            {
                foreach (var (va, vsize, raw, rawSize) in sections)
                {
                    uint size = Math.Max(vsize, rawSize);
                    if (rva >= va && rva < va + size) return (int)(rva - va + raw);
                }
                return -1;
            }

            uint importRva = BitConverter.ToUInt32(d, dataDirs + 8);
            int off = importRva == 0 ? -1 : RvaToOffset(importRva);
            for (int i = 0; off > 0 && i < 512 && off + 20 <= d.Length; i++, off += 20)
            {
                uint nameRva = BitConverter.ToUInt32(d, off + 12);
                if (nameRva == 0 && BitConverter.ToUInt32(d, off) == 0) break;
                int no = RvaToOffset(nameRva);
                if (no <= 0 || no >= d.Length) continue;
                int end = Array.IndexOf(d, (byte)0, no, Math.Min(260, d.Length - no));
                if (end > no) info.Imports.Add(Encoding.ASCII.GetString(d, no, end - no).ToLowerInvariant());
            }

            info.ManifestRequiresAdmin = d.AsSpan().IndexOf("requireAdministrator"u8) >= 0;
        }
        catch (Exception ex) { info.Error = ex.Message; }
        return info;
    }
}

/// <summary>Finds DLL names referenced as strings inside binaries (catches LoadLibrary use and packed imports).</summary>
public static class BinaryScan
{
    static readonly Regex DllRef = new(
        @"(d3dx9_\d{2}|d3dx10_\d{2}|d3dcompiler_\d{2}|xinput1_\d|xinput9_1_0|xaudio2_\d|x3daudio1_\d|xactengine\d_\d{1,2}|dinput8?|msvcr\d{2,3}|msvcp\d{2,3}|openal32|dplayx|binkw32|d3d9|d3d8|ddraw)\.dll",
        RegexOptions.Compiled);

    public static string ToLowerLatin1(byte[] data)
    {
        var copy = new byte[data.Length];
        for (int i = 0; i < data.Length; i++)
        {
            byte b = data[i];
            copy[i] = b is >= (byte)'A' and <= (byte)'Z' ? (byte)(b + 32) : b;
        }
        return Encoding.Latin1.GetString(copy);
    }

    public static HashSet<string> ReferencedDlls(string lowerText)
    {
        var set = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
        foreach (Match m in DllRef.Matches(lowerText)) set.Add(m.Value);
        return set;
    }
}

/// <summary>Everything we learn about a game's binaries in one pass.</summary>
public sealed class GameScan
{
    public PeInfo Exe { get; init; } = new();
    public HashSet<string> Referenced { get; } = new(StringComparer.OrdinalIgnoreCase);
    /// <summary>DLLs referenced by the main exe only (installer/helper DLLs in the folder can mention other APIs).</summary>
    public HashSet<string> ExeReferenced { get; } = new(StringComparer.OrdinalIgnoreCase);
    public string ExeLowerText { get; init; } = "";
    public List<string> ScannedFiles { get; } = new();

    public static GameScan Run(string exePath)
    {
        var bytes = File.ReadAllBytes(exePath);
        var lower = BinaryScan.ToLowerLatin1(bytes);
        var scan = new GameScan { Exe = PeReader.Parse(bytes), ExeLowerText = lower };
        foreach (var i in scan.Exe.Imports) scan.ExeReferenced.Add(i);
        foreach (var r in BinaryScan.ReferencedDlls(lower)) scan.ExeReferenced.Add(r);
        scan.Referenced.UnionWith(scan.ExeReferenced);
        scan.ScannedFiles.Add(Path.GetFileName(exePath));

        // Engine DLLs next to the exe often import d3dx9/xinput themselves.
        var dir = Path.GetDirectoryName(exePath)!;
        foreach (var f in Directory.EnumerateFiles(dir, "*.dll").Take(80))
        {
            try
            {
                var fi = new FileInfo(f);
                if (fi.Length > 40_000_000) continue;
                var b = File.ReadAllBytes(f);
                var pe = PeReader.Parse(b);
                foreach (var i in pe.Imports) scan.Referenced.Add(i);
                foreach (var r in BinaryScan.ReferencedDlls(BinaryScan.ToLowerLatin1(b))) scan.Referenced.Add(r);
                scan.ScannedFiles.Add(fi.Name);
            }
            catch { }
        }
        // Don't count DLLs that just reference themselves / ship in the game folder as "needs system copy" here;
        // DependencyChecker decides that.
        return scan;
    }
}
```

```cs
using System.Windows;
using LegacyGameLauncher.Models;
using Microsoft.Win32;

namespace LegacyGameLauncher.Services;

/// <summary>
/// Records the ORIGINAL state of everything the launcher touches (first change wins), so any group of
/// changes - or all of them - can be reverted exactly.
/// </summary>
public static class ChangeJournal
{
    public static bool HasFileRecord(GameEntry g, string target) =>
        g.Changes.Any(c => c.Kind != "Registry" && c.Target.Equals(target, StringComparison.OrdinalIgnoreCase));

    public static string NewBackupPath(GameEntry g, string target)
    {
        var dir = Path.Combine(AppPaths.Backups, g.Id.ToString("N"), DateTime.Now.ToString("yyyyMMdd-HHmmss"));
        Directory.CreateDirectory(dir);
        return Path.Combine(dir, Path.GetFileName(target));
    }

    /// <summary>
    /// Adds ops that place <paramref name="source"/> at <paramref name="target"/>, backing up any original first,
    /// and returns the journal record to commit if the ops succeed (null if the target is already journaled).
    /// </summary>
    public static ChangeRecord? PlanPlaceFile(GameEntry g, string group, string source, string target, List<FileOp> ops, string description)
    {
        ChangeRecord? rec = null;
        if (!HasFileRecord(g, target))
        {
            if (File.Exists(target))
            {
                var backup = NewBackupPath(g, target);
                ops.Add(new FileOp { Op = "Copy", Source = target, Target = backup });
                rec = new ChangeRecord { Group = group, Kind = "FileReplaced", Target = target, BackupPath = backup, PreviousExisted = true, Description = description + " (original backed up)" };
            }
            else rec = new ChangeRecord { Group = group, Kind = "FileAdded", Target = target, Description = description };
        }
        ops.Add(new FileOp { Op = "Copy", Source = source, Target = target });
        return rec;
    }

    public static void RecordRegistryOnce(GameEntry g, string group, string hiveKey, string name, string? previous, string description)
    {
        if (g.Changes.Any(c => c.Kind == "Registry" && c.Target == hiveKey && c.RegistryName == name)) return;
        g.Changes.Add(new ChangeRecord
        {
            Group = group, Kind = "Registry", Target = hiveKey, RegistryName = name,
            PreviousExisted = previous != null, PreviousValue = previous, Description = description,
        });
    }

    /// <summary>Reverts records of one group (or all when group is null). Returns a human-readable log.</summary>
    public static async Task<(bool Ok, string Log)> UndoAsync(GameEntry g, string? group, Window? owner)
    {
        var records = g.Changes.Where(c => group == null || c.Group == group).Reverse().ToList();
        if (records.Count == 0) return (true, "Nothing to undo.");
        var log = new List<string>();

        // Registry (HKCU only - no elevation needed).
        foreach (var r in records.Where(r => r.Kind == "Registry"))
        {
            try
            {
                using var key = Registry.CurrentUser.CreateSubKey(r.Target.Replace(@"HKCU\", ""), true);
                if (r.PreviousExisted) key.SetValue(r.RegistryName!, r.PreviousValue ?? "");
                else key.DeleteValue(r.RegistryName!, false);
                log.Add($"Restored registry {r.Target}\\{r.RegistryName} -> {(r.PreviousExisted ? r.PreviousValue : "(removed)")}");
                g.Changes.Remove(r);
            }
            catch (Exception ex) { log.Add($"FAILED registry {r.RegistryName}: {ex.Message}"); }
        }

        var fileRecs = records.Where(r => r.Kind != "Registry").ToList();
        var ops = new List<FileOp>();
        foreach (var r in fileRecs)
        {
            if (r.Kind == "FileReplaced" && r.BackupPath != null)
            {
                if (!File.Exists(r.BackupPath)) { log.Add($"WARNING backup missing for {r.Target}: {r.BackupPath}"); continue; }
                ops.Add(new FileOp { Op = "Copy", Source = r.BackupPath, Target = r.Target });
            }
            else if (r.Kind == "FileAdded") ops.Add(new FileOp { Op = "Delete", Target = r.Target });
        }
        if (ops.Count > 0)
        {
            var (ok, err) = await FileOpRunner.RunAsync(ops, $"Undo {(group ?? "all")} changes for {g.DisplayName}", owner);
            if (!ok) { log.Add("File restore failed: " + err); return (false, string.Join("\n", log)); }
        }
        foreach (var r in fileRecs)
        {
            log.Add(r.Kind == "FileAdded" ? $"Removed {r.Target}" : $"Restored original {r.Target}");
            g.Changes.Remove(r);
        }
        if (group is null or "wrapper") { g.Wrapper.Installed = false; g.Wrapper.InstalledKind = ""; g.Wrapper.InstalledDlls.Clear(); }
        if (group is null or "input") { g.Input.Installed = false; g.Input.InstalledKind = ""; }
        return (true, string.Join("\n", log));
    }
}
```

```cs
using LegacyGameLauncher.Models;
using Microsoft.Win32;

namespace LegacyGameLauncher.Services;

/// <summary>
/// Windows compatibility layers via the documented per-user key
/// HKCU\Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers (value name = full exe path).
/// This is exactly what the exe's Properties > Compatibility tab writes.
/// </summary>
public static class CompatLayers
{
    public const string SubKey = @"Software\Microsoft\Windows NT\CurrentVersion\AppCompatFlags\Layers";
    public const string HkcuKey = @"HKCU\" + SubKey;

    public static readonly string[] OsModes = { "", "WIN7RTM", "WIN8RTM", "VISTASP2", "VISTASP1", "VISTARTM", "WINXPSP3", "WINXPSP2", "WIN98", "WIN95" };

    static readonly string[] Managed = OsModes.Where(m => m != "")
        .Concat(new[] { "DISABLEDXMAXIMIZEDWINDOWEDMODE", "HIGHDPIAWARE", "RUNASADMIN", "16BITCOLOR", "256COLOR", "640X480", "DISABLETHEMES" })
        .ToArray();

    public static string? ReadHkcu(string exe)
    {
        using var k = Registry.CurrentUser.OpenSubKey(SubKey);
        return k?.GetValue(exe) as string;
    }

    public static string? ReadHklm(string exe)
    {
        using var hk = RegistryKey.OpenBaseKey(RegistryHive.LocalMachine, RegistryView.Registry64);
        using var k = hk.OpenSubKey(SubKey);
        return k?.GetValue(exe) as string;
    }

    static List<string> Tokens(string? value) =>
        (value ?? "").Split(' ', StringSplitOptions.RemoveEmptyEntries).Where(t => t != "~" && t != "$" && t != "#").ToList();

    public static List<string> FlagsFor(CompatSettings s)
    {
        var f = new List<string>();
        if (!string.IsNullOrEmpty(s.OsMode)) f.Add(s.OsMode);
        if (s.DisableFullscreenOptimizations) f.Add("DISABLEDXMAXIMIZEDWINDOWEDMODE");
        if (s.HighDpiAware) f.Add("HIGHDPIAWARE");
        if (s.RunAsAdmin) f.Add("RUNASADMIN");
        if (s.ReducedColor16) f.Add("16BITCOLOR");
        if (s.Res640x480) f.Add("640X480");
        if (s.DisableThemes) f.Add("DISABLETHEMES");
        return f;
    }

    /// <summary>Builds the new value, keeping any flags we don't manage (e.g. set by Windows or by hand).</summary>
    public static string? BuildValue(string? existing, CompatSettings s)
    {
        var keep = Tokens(existing).Where(t => !Managed.Contains(t, StringComparer.OrdinalIgnoreCase)).ToList();
        var all = keep.Concat(FlagsFor(s)).Distinct(StringComparer.OrdinalIgnoreCase).ToList();
        // "~" prefix = flags apply on Windows 8+ (what the Compatibility tab writes).
        return all.Count == 0 ? null : "~ " + string.Join(" ", all);
    }

    /// <summary>Writes the layers for the game. Returns the value now in effect.</summary>
    public static string? Apply(GameEntry g)
    {
        var existing = ReadHkcu(g.ExePath);
        var next = BuildValue(existing, g.Compat);
        if (string.Equals(existing, next, StringComparison.Ordinal)) return existing;
        ChangeJournal.RecordRegistryOnce(g, "compat", HkcuKey, g.ExePath, existing, "Windows compatibility layers for " + Path.GetFileName(g.ExePath));
        using var k = Registry.CurrentUser.CreateSubKey(SubKey, true);
        if (next == null) k.DeleteValue(g.ExePath, false);
        else k.SetValue(g.ExePath, next, RegistryValueKind.String);
        return next;
    }

    /// <summary>
    /// Removes the per-user layers value for the exe (used when a SafeDisc loader is active: any layer makes the
    /// shim engine load the system version.dll first). The old value is journaled, so "Undo" restores it. HKLM is untouched.
    /// Returns the removed value, or null if there was none.
    /// </summary>
    public static string? Clear(GameEntry g)
    {
        var existing = ReadHkcu(g.ExePath);
        if (existing == null) return null;
        ChangeJournal.RecordRegistryOnce(g, "compat", HkcuKey, g.ExePath, existing, "Windows compatibility layers for " + Path.GetFileName(g.ExePath));
        using var k = Registry.CurrentUser.CreateSubKey(SubKey, true);
        k.DeleteValue(g.ExePath, false);
        return existing;
    }

    /// <summary>Mask of logical processors for a core limit. Prefers one logical CPU per physical core (even indexes) when SMT is likely.</summary>
    public static long AffinityMask(int coreLimit)
    {
        int n = Environment.ProcessorCount;
        if (coreLimit <= 0 || coreLimit >= n) return 0;
        long mask = 0;
        bool spread = n >= coreLimit * 2;
        for (int i = 0, cpu = 0; i < coreLimit && cpu < Math.Min(n, 32); i++, cpu += spread ? 2 : 1)
            mask |= 1L << cpu;
        return mask;
    }
}
```

```cs
/// <summary>
/// Finds likely config files instead of assuming fixed paths: install folder, VirtualStore redirection,
/// Documents / AppData / LocalAppData (incl. EA Sports and My Games subfolders), and keyword-matched folders.
/// </summary>
public static class ConfigScanner
{
    static readonly HashSet<string> TextExt = new(StringComparer.OrdinalIgnoreCase) { ".ini", ".cfg", ".txt", ".xml", ".conf", ".opt", ".set", ".json", ".prf" };
    static readonly string[] Hot = { "config", "option", "setting", "video", "display", "graphic", "pref", "setup", "user", "profile" };
    static readonly string[] Managed = { "dgvoodoo.conf", "dxvk.conf", "x360ce.ini" };

    public static List<ConfigCandidate> Scan(GameEntry g, GameProfile? p)
    {
        var docs = Environment.GetFolderPath(Environment.SpecialFolder.MyDocuments);
        var roaming = Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData);
        var local = Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData);
        var results = new Dictionary<string, ConfigCandidate>(StringComparer.OrdinalIgnoreCase);

        void AddDir(string dir, string label, int depth, bool installFolder)
        {
            if (!Directory.Exists(dir)) return;
            try
            {
                foreach (var f in Directory.EnumerateFiles(dir, "*", new EnumerationOptions { RecurseSubdirectories = depth > 0, MaxRecursionDepth = depth, IgnoreInaccessible = true }))
                {
                    var fi = new FileInfo(f);
                    bool textExt = TextExt.Contains(fi.Extension);
                    if (installFolder && !textExt) continue;           // game data archives are not configs
                    if (fi.Length > (textExt ? 1_000_000 : 256_000)) continue;
                    if (results.ContainsKey(f)) continue;
                    var name = fi.Name.ToLowerInvariant();
                    int score = Hot.Count(h => name.Contains(h)) * 10 + (installFolder ? 0 : 5) + (textExt ? 3 : 0);
                    if (fi.Extension.Equals(".pro", StringComparison.OrdinalIgnoreCase)) score += 25; // EA Sports / HB Studios profile (holds the resolution)
                    if (fi.LastWriteTime > DateTime.Now.AddDays(-30)) score += 2;
                    results[f] = new ConfigCandidate
                    {
                        Path = f, Size = fi.Length, Modified = fi.LastWriteTime, Score = score, IsText = LooksText(f),
                        Location = label + (Managed.Contains(name) ? " (managed by launcher)" : ""),
                    };
                }
            }
            catch { }
        }

        AddDir(g.GameDir, "install folder", 2, true);

        // UAC file virtualization: a 32-bit game without a manifest that writes into Program Files is silently redirected here.
        var root = Path.GetPathRoot(g.GameDir) ?? "";
        var virtualStore = Path.Combine(local, "VirtualStore", g.GameDir[root.Length..]);
        AddDir(virtualStore, "VirtualStore (redirected writes)", 3, false);

        var names = new List<string>(p?.ConfigFolderNames ?? new());
        names.Add(Path.GetFileName(g.GameDir));
        names.Add(g.DisplayName);
        foreach (var n in names.Where(n => !string.IsNullOrWhiteSpace(n)).Distinct(StringComparer.OrdinalIgnoreCase))
        {
            foreach (var (baseDir, label) in new[] { (docs, "Documents"), (Path.Combine(docs, "EA Sports"), "Documents\\EA Sports"),
                                                       (Path.Combine(docs, "My Games"), "Documents\\My Games"), (roaming, "AppData\\Roaming"),
                                                       (Path.Combine(roaming, "EA Sports"), "AppData\\Roaming\\EA Sports"), (local, "AppData\\Local"),
                                                       (Path.Combine(local, "EA Sports"), "AppData\\Local\\EA Sports") })
                AddDir(Path.Combine(baseDir, n), label, 3, false);
        }

        // Keyword search one level deep for folders we didn't predict.
        var keywords = (p?.FolderNameContains ?? new()).Append(Path.GetFileName(g.GameDir)).Where(k => k.Length >= 4).Distinct().ToList();
        foreach (var baseDir in new[] { docs, Path.Combine(docs, "EA Sports"), Path.Combine(docs, "My Games"), roaming, local, Path.Combine(local, "EA Sports") })
        {
            if (!Directory.Exists(baseDir)) continue;
            try
            {
                foreach (var d in Directory.EnumerateDirectories(baseDir))
                    if (keywords.Any(k => Path.GetFileName(d).Contains(k, StringComparison.OrdinalIgnoreCase)))
                        AddDir(d, "keyword match: " + Path.GetFileName(baseDir), 3, false);
            }
            catch { }
        }

        return results.Values.OrderByDescending(c => c.Score).ThenByDescending(c => c.Modified).ToList();
    }

    public static List<RegistryValueRow> ScanRegistry(GameProfile? p, string gameFolderName)
    {
        var rows = new List<RegistryValueRow>();
        var keys = new List<string>(p?.RegistryKeys ?? new());
        // Keyword search under the usual publisher keys (32-bit games use the WOW6432Node view).
        foreach (var parent in new[] { @"HKLM\SOFTWARE\WOW6432Node\EA SPORTS", @"HKLM\SOFTWARE\WOW6432Node\Electronic Arts", @"HKLM\SOFTWARE\WOW6432Node\Electronic Arts\EA SPORTS",
                                       @"HKCU\Software\EA SPORTS", @"HKCU\Software\Electronic Arts", @"HKCU\Software\Classes\VirtualStore\MACHINE\SOFTWARE\WOW6432Node\EA SPORTS" })
        {
            using var k = Open(parent);
            if (k == null) continue;
            foreach (var sub in k.GetSubKeyNames())
                if (sub.Contains(gameFolderName, StringComparison.OrdinalIgnoreCase) ||
                    (p?.FolderNameContains ?? new()).Any(f => sub.Contains(f, StringComparison.OrdinalIgnoreCase)))
                    keys.Add(parent + "\\" + sub);
        }
        foreach (var key in keys.Distinct(StringComparer.OrdinalIgnoreCase))
        {
            using var k = Open(key);
            if (k == null) continue;
            foreach (var n in k.GetValueNames())
                rows.Add(new RegistryValueRow { Key = key, Name = n == "" ? "(Default)" : n, Value = Format(k.GetValue(n)) });
            foreach (var sub in k.GetSubKeyNames().Take(20))
            {
                using var sk = k.OpenSubKey(sub);
                if (sk == null) continue;
                foreach (var n in sk.GetValueNames())
                    rows.Add(new RegistryValueRow { Key = key + "\\" + sub, Name = n == "" ? "(Default)" : n, Value = Format(sk.GetValue(n)) });
            }
        }
        return rows;
    }

    static string Format(object? v) => v switch
    {
        byte[] b => BitConverter.ToString(b.Take(32).ToArray()) + (b.Length > 32 ? "…" : ""),
        string[] a => string.Join(" | ", a),
        null => "",
        _ => v.ToString() ?? "",
    };

    static RegistryKey? Open(string path)
    {
        var hive = path.StartsWith("HKLM", StringComparison.OrdinalIgnoreCase)
            ? RegistryKey.OpenBaseKey(RegistryHive.LocalMachine, RegistryView.Registry64)
            : RegistryKey.OpenBaseKey(RegistryHive.CurrentUser, RegistryView.Registry64);
        var sub = path[(path.IndexOf('\\') + 1)..];
        try { return hive.OpenSubKey(sub); } catch { return null; }
    }

    public static bool LooksText(string path)
    {
        try
        {
            using var fs = File.OpenRead(path);
            var buf = new byte[Math.Min(4096, fs.Length)];
            int n = fs.Read(buf, 0, buf.Length);
            if (n >= 2 && ((buf[0] == 0xFF && buf[1] == 0xFE) || (buf[0] == 0xFE && buf[1] == 0xFF))) return true; // UTF-16 BOM
            int bad = 0;
            for (int i = 0; i < n; i++) if (buf[i] == 0 || (buf[i] < 9) || (buf[i] > 13 && buf[i] < 32)) bad++;
            return n == 0 || bad * 20 < n;
        }
        catch { return false; }
    }

    public static (string Text, Encoding Encoding) ReadText(string path)
    {
        using var sr = new StreamReader(path, Encoding.Latin1, detectEncodingFromByteOrderMarks: true);
        var text = sr.ReadToEnd();
        return (text, sr.CurrentEncoding);
    }

    public static string HexPreview(string path, int max = 1024)
    {
        var bytes = File.ReadAllBytes(path).Take(max).ToArray();
        var sb = new StringBuilder();
        for (int i = 0; i < bytes.Length; i += 16)
        {
            var chunk = bytes.Skip(i).Take(16).ToArray();
            sb.Append($"{i:X6}  {BitConverter.ToString(chunk).Replace('-', ' '),-48}  ");
            sb.AppendLine(new string(chunk.Select(b => b is >= 32 and < 127 ? (char)b : '.').ToArray()));
        }
        return sb.ToString();
    }

    // ---- Binary profiles (.pro) --------------------------------------------------------------
    // Community-documented for Rugby 08 and Cricket 07: the resolution is two little-endian 16-bit values,
    // width then height (e.g. 1024x768 = 00 04 00 03). The offset differs between profiles, so we search.

    static readonly (int W, int H)[] CommonResolutions =
    {
        (640, 480), (800, 600), (1024, 768), (1152, 864), (1280, 720), (1280, 768), (1280, 800), (1280, 960), (1280, 1024),
        (1360, 768), (1366, 768), (1400, 1050), (1440, 900), (1600, 900), (1600, 1200), (1680, 1050), (1920, 1080),
        (1920, 1200), (2560, 1080), (2560, 1440), (2560, 1600), (3440, 1440), (3840, 2160),
    };

    public sealed record ResolutionMatch(int Offset, int Width, int Height)
    {
        public override string ToString() => $"offset 0x{Offset:X} ({Offset}): {Width}x{Height}";
    }

    public static List<ResolutionMatch> FindResolutionPairs(byte[] d)
    {
        var list = new List<ResolutionMatch>();
        for (int i = 0; i + 4 <= d.Length; i++)
        {
            int w = d[i] | d[i + 1] << 8, h = d[i + 2] | d[i + 3] << 8;
            if (CommonResolutions.Contains((w, h))) list.Add(new ResolutionMatch(i, w, h));
        }
        return list;
    }

    public static byte[] WithResolution(byte[] d, int offset, int w, int h)
    {
        if (w is <= 0 or > 0xFFFF || h is <= 0 or > 0xFFFF) throw new ArgumentOutOfRangeException(nameof(w), "Resolution out of range.");
        var copy = (byte[])d.Clone();
        copy[offset] = (byte)(w & 0xFF); copy[offset + 1] = (byte)(w >> 8);
        copy[offset + 2] = (byte)(h & 0xFF); copy[offset + 3] = (byte)(h >> 8);
        return copy;
    }

    static readonly Regex KeyLine = new(@"^\s*(?<key>[^=:;#\[\]\r\n]*?(width|height|resx|resy|xres|yres|res_x|res_y|screenx|screeny|resolution|windowed|fullscreen|full_screen|refresh|vsync)[^=:;#\r\n]*?)\s*[=:]\s*(?<val>[^\r\n]*)$",
        RegexOptions.IgnoreCase | RegexOptions.Multiline | RegexOptions.Compiled);
    static readonly Regex XmlElem = new(@"<(?<key>\w*(width|height|windowed|fullscreen|refresh|resolution)\w*)>(?<val>[^<]*)</\k<key>>",
        RegexOptions.IgnoreCase | RegexOptions.Compiled);

    public static List<DetectedSetting> DetectSettings(string text)
    {
        var list = new List<DetectedSetting>();
        foreach (Match m in KeyLine.Matches(text))
            list.Add(new DetectedSetting { Line = LineOf(text, m.Index), Key = m.Groups["key"].Value.Trim(), Value = m.Groups["val"].Value.Trim() });
        foreach (Match m in XmlElem.Matches(text))
            list.Add(new DetectedSetting { Line = LineOf(text, m.Index), Key = "<" + m.Groups["key"].Value + ">", Value = m.Groups["val"].Value });
        return list;
    }

    static int LineOf(string text, int index) => text.AsSpan(0, index).Count('\n') + 1;

    /// <summary>Rewrites recognised resolution/windowed keys. Returns the new text and what was changed.</summary>
    public static (string Text, List<string> Changes) ApplyQuickSettings(string text, int width, int height, bool? windowed)
    {
        var changes = new List<string>();
        string Classify(string key)
        {
            var k = key.ToLowerInvariant().Replace(" ", "");
            if (k.Contains("windowed")) return "windowed";
            if (k.Contains("fullscreen") || k.Contains("full_screen")) return "fullscreen";
            if (k.Contains("refresh")) return "";
            if (k.Contains("resolution")) return "resolution";
            if (k.Contains("width") || k.Contains("resx") || k.Contains("xres") || k.Contains("res_x") || k.Contains("screenx")) return "width";
            if (k.Contains("height") || k.Contains("resy") || k.Contains("yres") || k.Contains("res_y") || k.Contains("screeny")) return "height";
            return "";
        }
        string Bool(string old, bool v)
        {
            var o = old.Trim().ToLowerInvariant();
            if (o is "true" or "false") return v ? "true" : "false";
            if (o is "yes" or "no") return v ? "yes" : "no";
            return v ? "1" : "0";
        }
        string? NewValue(string kind, string old) => kind switch
        {
            "width" when width > 0 => width.ToString(),
            "height" when height > 0 => height.ToString(),
            "resolution" when width > 0 && height > 0 && Regex.IsMatch(old, @"\d+\s*[xX*,]\s*\d+") =>
                Regex.Replace(old, @"(\d+)(\s*[xX*,]\s*)(\d+)", $"{width}${{2}}{height}"),
            "windowed" when windowed != null => Bool(old, windowed.Value),
            "fullscreen" when windowed != null => Bool(old, !windowed.Value),
            _ => null,
        };

        text = KeyLine.Replace(text, m =>
        {
            var key = m.Groups["key"].Value; var old = m.Groups["val"].Value;
            var nv = NewValue(Classify(key), old);
            if (nv == null || nv == old.Trim()) return m.Value;
            changes.Add($"{key.Trim()}: {old.Trim()} -> {nv}");
            var g = m.Groups["val"];
            return m.Value[..(g.Index - m.Index)] + nv;
        });
        text = XmlElem.Replace(text, m =>
        {
            var key = m.Groups["key"].Value; var old = m.Groups["val"].Value;
            var nv = NewValue(Classify(key), old);
            if (nv == null || nv == old.Trim()) return m.Value;
            changes.Add($"<{key}>: {old} -> {nv}");
            return $"<{key}>{nv}</{key}>";
        });
        return (text, changes);
    }
}
```

```cs
public sealed class DependencyRow
{
    public string Dll { get; set; } = "";
    public string Package { get; set; } = "";
    public bool Present { get; set; }
    public string Where { get; set; } = "";
    public bool UsedByGame { get; set; }
    public string Status => Present ? "OK" : UsedByGame ? "MISSING - needed by this game" : "missing (not referenced by this game)";
}

public sealed class DependencyReport
{
    public List<DependencyRow> Rows { get; } = new();
    public List<string> Advice { get; } = new();
    public bool HasBlockingIssue => Rows.Any(r => r.UsedByGame && !r.Present);
}

/// <summary>
/// Checks the legacy runtimes 2006-2008 games expect. Only *detects* and links to official Microsoft installers;
/// no Microsoft DLLs are bundled or copied.
/// </summary>
public static class DependencyChecker
{
    public const string DirectXJune2010Url = "https://www.microsoft.com/en-us/download/details.aspx?id=8109";
    public const string VcRedistUrl = "https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist";
    public const string OpenAlUrl = "https://www.openal.org/downloads/";

    const string DxPkg = "DirectX End-User Runtime (June 2010)";

    static IEnumerable<string> DirectXDlls()
    {
        for (int i = 24; i <= 43; i++) yield return $"d3dx9_{i}.dll";
        yield return "d3dcompiler_43.dll";
        for (int i = 1; i <= 3; i++) yield return $"xinput1_{i}.dll";
        for (int i = 0; i <= 7; i++) yield return $"xaudio2_{i}.dll";
        for (int i = 0; i <= 7; i++) yield return $"x3daudio1_{i}.dll";
        for (int i = 0; i <= 7; i++) yield return $"xactengine3_{i}.dll";
    }

    /// <param name="is32BitGame">x86 games load from SysWOW64, x64 games from System32.</param>
    public static DependencyReport Check(string gameDir, bool is32BitGame, ISet<string> referenced)
    {
        var report = new DependencyReport();
        var sysDir = is32BitGame
            ? Environment.GetFolderPath(Environment.SpecialFolder.SystemX86)   // C:\Windows\SysWOW64
            : Environment.GetFolderPath(Environment.SpecialFolder.System);
        string sysLabel = is32BitGame ? "SysWOW64" : "System32";

        (bool, string) Locate(string dll)
        {
            if (File.Exists(Path.Combine(gameDir, dll))) return (true, "game folder");
            if (File.Exists(Path.Combine(sysDir, dll))) return (true, sysLabel);
            return (false, "");
        }

        foreach (var dll in DirectXDlls())
        {
            var (ok, where) = Locate(dll);
            report.Rows.Add(new DependencyRow { Dll = dll, Package = DxPkg, Present = ok, Where = where, UsedByGame = referenced.Contains(dll) });
        }

        // Anything the game references that isn't in our list but matches DirectX-family names (e.g. xactengine2_x).
        foreach (var dll in referenced.Where(r => (r.StartsWith("d3dx") || r.StartsWith("xact") || r.StartsWith("xaudio") || r.StartsWith("x3daudio") || r.StartsWith("xinput1_"))
                                                && report.Rows.All(x => !x.Dll.Equals(r, StringComparison.OrdinalIgnoreCase))))
        {
            var (ok, where) = Locate(dll);
            report.Rows.Add(new DependencyRow { Dll = dll, Package = DxPkg, Present = ok, Where = where, UsedByGame = true });
        }

        // Visual C++ 2005 / 2008 runtimes live in WinSxS, not System32.
        foreach (var (dll, ver, label) in new[] { ("msvcr80.dll", "vc80", "Visual C++ 2005 x86 Redistributable"),
                                                   ("msvcp80.dll", "vc80", "Visual C++ 2005 x86 Redistributable"),
                                                   ("msvcr90.dll", "vc90", "Visual C++ 2008 x86 Redistributable"),
                                                   ("msvcp90.dll", "vc90", "Visual C++ 2008 x86 Redistributable") })
        {
            if (!referenced.Contains(dll)) continue;
            bool inGame = File.Exists(Path.Combine(gameDir, dll));
            bool inSxs = false;
            try
            {
                var sxs = Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.Windows), "WinSxS");
                var prefix = (is32BitGame ? "x86" : "amd64") + $"_microsoft.{ver}.crt_";
                inSxs = Directory.EnumerateDirectories(sxs, prefix + "*").Any();
            }
            catch { }
            report.Rows.Add(new DependencyRow { Dll = dll, Package = label, Present = inGame || inSxs, Where = inGame ? "game folder" : inSxs ? "WinSxS" : "", UsedByGame = true });
        }

        foreach (var dll in new[] { "msvcr71.dll", "msvcp71.dll", "msvcr70.dll" })
        {
            if (!referenced.Contains(dll)) continue;
            var (ok, where) = Locate(dll);
            report.Rows.Add(new DependencyRow { Dll = dll, Package = "Visual C++ .NET 2003 runtime (usually shipped in the game folder)", Present = ok, Where = where, UsedByGame = true });
        }

        if (referenced.Contains("openal32.dll"))
        {
            var (ok, where) = Locate("openal32.dll");
            report.Rows.Add(new DependencyRow { Dll = "openal32.dll", Package = "OpenAL (Creative) runtime", Present = ok, Where = where, UsedByGame = true });
        }

        if (referenced.Contains("dplayx.dll"))
            report.Advice.Add("The game references DirectPlay (dplayx.dll). If multiplayer or startup fails, enable it in " +
                              "'Turn Windows features on or off' > Legacy Components > DirectPlay (needs admin; Windows may offer this automatically).");

        var missingDx = report.Rows.Where(r => r.Package == DxPkg && !r.Present).ToList();
        if (missingDx.Any(r => r.UsedByGame))
            report.Advice.Add($"Install the official {DxPkg}: download directx_Jun2010_redist.exe from Microsoft, extract it to a folder, " +
                              "then run DXSETUP.exe from that folder (or use the 'Run DXSETUP.exe' button). It adds the legacy DLLs alongside modern DirectX and is safe on Windows 11.");
        else if (missingDx.Count > 0)
            report.Advice.Add($"{missingDx.Count} legacy DirectX DLLs are missing but this game does not appear to reference them. " +
                              "Installing the June 2010 runtime is still harmless and recommended if the game crashes on start (some references are hidden in packed/protected exes).");
        if (report.Rows.Any(r => r.Package.StartsWith("Visual C++ 200") && !r.Present))
            report.Advice.Add("Install the matching x86 Visual C++ Redistributable from Microsoft's 'Latest supported Visual C++ Redistributable downloads' page (older versions are listed further down that page).");
        if (report.Rows.Any(r => r.Dll == "openal32.dll" && !r.Present))
            report.Advice.Add("Install the OpenAL runtime (oalinst.exe) - it is usually on the game disc too.");
        return report;
    }
```

```cs
using System.ComponentModel;
using System.Runtime.InteropServices;
using System.Text;

namespace LegacyGameLauncher.Services;

/// <summary>
/// Mounts and unmounts a disc image (.iso) the user owns, with Windows' own virtual-disk API - the same thing
/// Explorer's "Mount" does. Read-only; no extra drivers. Nothing about the image or any copy protection is changed.
/// </summary>
public static class DiscImage
{
    [StructLayout(LayoutKind.Sequential)]
    struct VIRTUAL_STORAGE_TYPE { public uint DeviceId; public Guid VendorId; }

    const uint VIRTUAL_STORAGE_TYPE_DEVICE_ISO = 1;
    static readonly Guid VendorMicrosoft = new("EC984AEC-A0F9-47e9-901F-71415A66345B");
    const uint VIRTUAL_DISK_ACCESS_READ = 0x000d0000;
    const uint VIRTUAL_DISK_ACCESS_ATTACH_RO = 0x00010000;
    const uint VIRTUAL_DISK_ACCESS_DETACH = 0x00040000;
    const uint VIRTUAL_DISK_ACCESS_GET_INFO = 0x00080000;
    const uint ATTACH_READ_ONLY = 0x1, ATTACH_PERMANENT_LIFETIME = 0x4;

    [DllImport("virtdisk.dll", CharSet = CharSet.Unicode)]
    static extern int OpenVirtualDisk(ref VIRTUAL_STORAGE_TYPE type, string path, uint access, uint flags, IntPtr parameters, out IntPtr handle);
    [DllImport("virtdisk.dll")]
    static extern int AttachVirtualDisk(IntPtr handle, IntPtr securityDescriptor, uint flags, uint providerFlags, IntPtr parameters, IntPtr overlapped);
    [DllImport("virtdisk.dll")]
    static extern int DetachVirtualDisk(IntPtr handle, uint flags, uint providerFlags);
    [DllImport("virtdisk.dll", CharSet = CharSet.Unicode)]
    static extern int GetVirtualDiskPhysicalPath(IntPtr handle, ref int size, StringBuilder path);
    [DllImport("kernel32.dll", SetLastError = true)] static extern bool CloseHandle(IntPtr h);
    [DllImport("kernel32.dll", CharSet = CharSet.Unicode, SetLastError = true)]
    static extern uint QueryDosDeviceW(string device, StringBuilder target, int max);

    static IntPtr Open(string iso, uint access)
    {
        var t = new VIRTUAL_STORAGE_TYPE { DeviceId = VIRTUAL_STORAGE_TYPE_DEVICE_ISO, VendorId = VendorMicrosoft };
        int rc = OpenVirtualDisk(ref t, iso, access, 0, IntPtr.Zero, out var h);
        if (rc != 0) throw new Win32Exception(rc, $"Could not open the disc image: {new Win32Exception(rc).Message}");
        return h;
    }

    /// <summary>Drive letter ("D:") of the image if it is mounted, else null.</summary>
    public static string? MountedDrive(string iso)
    {
        IntPtr h;
        try { h = Open(iso, VIRTUAL_DISK_ACCESS_GET_INFO); } catch { return null; }
        try
        {
            int size = 520; var sb = new StringBuilder(260);
            if (GetVirtualDiskPhysicalPath(h, ref size, sb) != 0) return null; // not attached
            return DriveForDevice(sb.ToString());
        }
        finally { CloseHandle(h); }
    }

    /// <summary>Mounts read-only (unless already mounted). Returns (drive, mountedNow).</summary>
    public static (string Drive, bool MountedNow) Mount(string iso, int waitMs = 10000)
    {
        if (!File.Exists(iso)) throw new FileNotFoundException("Disc image not found.", iso);
        var existing = MountedDrive(iso);
        if (existing != null) return (existing, false);

        var h = Open(iso, VIRTUAL_DISK_ACCESS_ATTACH_RO | VIRTUAL_DISK_ACCESS_GET_INFO);
        try
        {
            int rc = AttachVirtualDisk(h, IntPtr.Zero, ATTACH_READ_ONLY | ATTACH_PERMANENT_LIFETIME, 0, IntPtr.Zero, IntPtr.Zero);
            if (rc != 0) throw new Win32Exception(rc, $"Windows could not mount the image: {new Win32Exception(rc).Message}");
        }
        finally { CloseHandle(h); }

        // The drive letter appears a moment after attaching.
        var until = DateTime.Now.AddMilliseconds(waitMs);
        while (DateTime.Now < until)
        {
            var d = MountedDrive(iso);
            if (d != null && Directory.Exists(d + "\\")) return (d, true);
            Thread.Sleep(250);
        }
        return (MountedDrive(iso) ?? "(no drive letter)", true);
    }

    public static void Unmount(string iso)
    {
        var h = Open(iso, VIRTUAL_DISK_ACCESS_DETACH);
        try
        {
            int rc = DetachVirtualDisk(h, 0, 0);
            if (rc != 0) throw new Win32Exception(rc, $"Could not unmount the image: {new Win32Exception(rc).Message}");
        }
        finally { CloseHandle(h); }
    }

    /// <summary>\\.\CDROM1 → the drive letter whose DOS device is \Device\CdRom1.</summary>
    static string? DriveForDevice(string physical)
    {
        var name = physical.Replace(@"\\.\", "", StringComparison.Ordinal);
        foreach (var di in DriveInfo.GetDrives())
        {
            if (di.DriveType != DriveType.CDRom) continue;
            var letter = di.Name.TrimEnd('\\');
            var sb = new StringBuilder(260);
            if (QueryDosDeviceW(letter, sb, sb.Capacity) == 0) continue;
            if (sb.ToString().EndsWith("\\" + name, StringComparison.OrdinalIgnoreCase)) return letter;
        }
        return null;
    }
}
```

```cs
public sealed class DrmFinding
{
    public string Scheme { get; set; } = "";
    public string Evidence { get; set; } = "";
    public string Impact { get; set; } = "";
}

/// <summary>
/// DETECTION ONLY. Identifies copy-protection schemes so the user can be told clearly why a game might
/// not start. This class never modifies, removes or bypasses any protection.
/// </summary>
public static class DrmDetector
{
    const string SafeDiscImpact =
        "SafeDisc relies on the secdrv.sys driver, which Microsoft disabled on Windows 10 and 11 for security reasons. " +
        "A SafeDisc disc check cannot run on this PC. The only supported fixes are an official publisher patch that " +
        "removes the disc check, or an official digital/re-release of the game.";
    const string SecuRomImpact =
        "SecuROM disc checks often fail on Windows 10/11 (modern or virtual drives, missing driver behaviour). " +
        "Try: the original disc in a physical optical drive, closing virtual-drive software, and the publisher's latest official patch. " +
        "If it still fails, look for an official digital/re-release.";
    const string StarForceImpact =
        "StarForce installs kernel drivers that are not supported on Windows 10/11. Many publishers released official " +
        "patches removing StarForce - check the publisher's support site.";

    public const string ModifiedScheme = "Modified executable";
    const string ModifiedImpact =
        "This exe does not look like the original retail release: its copy protection has been removed. That is fine if it came " +
        "from an official publisher patch; if it came from a third-party 'no-CD' tool, this launcher cannot vouch for it and " +
        "will not help work around copy protection. Third-party modified exes from that era " +
        "are a common cause of crashes (and an unsigned tool from an unknown source can carry malware - scan it). " +
        "Supported options: reinstall from your original disc and apply only the publisher's official patches, or use an " +
        "official digital/DRM-free re-release if one exists. Note that the original SafeDisc exe itself cannot run on Windows 10/11.";

    // File names used by well-known 'no-CD' release groups / tools. Detection only.
    static readonly System.Text.RegularExpressions.Regex CrackToolName = new(
        @"^(rld|razor|rzr|reloaded|fairlight|flt|deviance|class)[-_ ].*\.(exe|dll)$|(no-?cd|nodvd|crack)",
        System.Text.RegularExpressions.RegexOptions.IgnoreCase);

    public static List<DrmFinding> Scan(string exePath, PeInfo pe, string exeLowerText, Models.GameProfile? profile = null)
    {
        var findings = new List<DrmFinding>();
        void Add(string scheme, string evidence, string impact)
        {
            var existing = findings.FirstOrDefault(f => f.Scheme == scheme);
            if (existing != null) existing.Evidence += "; " + evidence;
            else findings.Add(new DrmFinding { Scheme = scheme, Evidence = evidence, Impact = impact });
        }

        foreach (var s in pe.SectionNames.Select(s => s.ToLowerInvariant()))
        {
            if (s is ".securom" or ".cms_t" or ".cms_d") Add("SecuROM", $"exe section '{s}'", SecuRomImpact);
            if (s.StartsWith("stxt")) Add("SafeDisc", $"exe section '{s}'", SafeDiscImpact);
            if (s.StartsWith(".sforce")) Add("StarForce", $"exe section '{s}'", StarForceImpact);
            if (s == ".bind") Add("Steam DRM stub", "exe section '.bind'", "Requires the Steam client to be running and signed in; normally works on Windows 11.");
        }

        if (exeLowerText.Contains("securom")) Add("SecuROM", "'SecuROM' string in exe", SecuRomImpact);
        if (exeLowerText.Contains("bog_ *90.0&!!")) Add("SafeDisc", "SafeDisc signature in exe", SafeDiscImpact);
        if (exeLowerText.Contains("protected by starforce"))Add("StarForce", "StarForce string in exe", StarForceImpact);

        var dir = Path.GetDirectoryName(exePath)!;
        var fileMarkers = new (string file, string scheme, string impact)[]
        {
            ("secdrv.sys", "SafeDisc", SafeDiscImpact), ("drvmgt.dll", "SafeDisc", SafeDiscImpact),
            ("dplayerx.dll", "SafeDisc", SafeDiscImpact), ("clcd32.dll", "SafeDisc", SafeDiscImpact),
            ("clokspl.exe", "SafeDisc", SafeDiscImpact), ("00000001.tmp", "SafeDisc", SafeDiscImpact),
            ("paul.dll", "SecuROM", SecuRomImpact), ("protect.dll", "StarForce", StarForceImpact),
            ("protect.exe", "StarForce", StarForceImpact),
        };
        try
        {
            foreach (var f in Directory.EnumerateFiles(dir))
            {
                var name = Path.GetFileName(f).ToLowerInvariant();
                foreach (var (file, scheme, impact) in fileMarkers)
                    if (name == file) Add(scheme, $"file '{Path.GetFileName(f)}' in game folder", impact);
                if (name.EndsWith(".icd")) Add("SafeDisc", $"file '{Path.GetFileName(f)}' (SafeDisc .icd main executable)", SafeDiscImpact);
                if (CrackToolName.IsMatch(name)) Add(ModifiedScheme, $"file '{Path.GetFileName(f)}' in game folder (name used by a 'no-CD' release group)", ModifiedImpact);
            }
        }
        catch { }

        // The profile says the retail exe is SafeDisc-wrapped, but this exe has no SafeDisc sections.
        bool profileSafeDisc = profile?.DrmNotes.Contains("SafeDisc", StringComparison.OrdinalIgnoreCase) == true;
        bool hasStxt = pe.SectionNames.Any(s => s.StartsWith("stxt", StringComparison.OrdinalIgnoreCase));
        if (profileSafeDisc && !hasStxt && pe.SectionNames.Count > 0)
            Add(ModifiedScheme, "the retail exe is SafeDisc-protected, but this exe has no SafeDisc (stxt*) sections" +
                (exeLowerText.Contains("bog_") ? " although SafeDisc marker text remains" : ""), ModifiedImpact);

        // A modified exe makes the SafeDisc finding from leftover strings misleading - report the modification instead.
        if (findings.Any(f => f.Scheme == ModifiedScheme) && !hasStxt)
            findings.RemoveAll(f => f.Scheme == "SafeDisc" && !f.Evidence.Contains("section"));
        return findings;
    }

    /// <summary>After a failed launch, is DRM a plausible cause?</summary>
    public static string? PostLaunchHint(List<DrmFinding> findings, TimeSpan runTime, long? exitCode)
    {
        if (findings.Count == 0) return null;
        if (runTime > TimeSpan.FromSeconds(45) && exitCode == 0) return null;
        if (findings.Any(f => f.Scheme == ModifiedScheme))
            return $"The game crashed after {runTime.TotalSeconds:0}s, and its exe has been modified by a third-party tool (see Overview). " +
                   "Crashes from such exes can't be fixed reliably by compatibility settings, and this launcher won't work around copy protection. " +
                   "Supported route: reinstall from the original disc with official patches only, or an official re-release.";
        var schemes = string.Join(", ", findings.Select(f => f.Scheme).Distinct());
        return $"The game exited after {runTime.TotalSeconds:0}s and copy protection ({schemes}) was detected. " +
               "A quick exit, a 'please insert the correct disc' message, or a silent exit is typical of a failed DRM check. " +
               "This launcher will not bypass DRM. Options: original disc in a physical drive; the publisher's official patch; " +
               "an official digital/DRM-free re-release (none is known for EA's Rugby 08 / Cricket 07 at the time of writing).";
    }
}
```

```cs
using System.ComponentModel;
using System.Diagnostics;
using System.Security.Cryptography;
using System.Text.Json;
using System.Windows;

namespace LegacyGameLauncher.Services;

public sealed class FileOp
{
    /// <summary>Copy (Source -> Target, overwrite) or Delete (Target, if it exists). Both are idempotent.</summary>
    public string Op { get; set; } = "";
    public string Source { get; set; } = "";
    public string Target { get; set; } = "";
    public override string ToString() => Op == "Copy" ? $"Copy  {Source}\n   -> {Target}" : $"Delete {Target}";
}

/// <summary>
/// Runs file operations as the current user; if a target folder (e.g. Program Files) is not writable,
/// explains why and runs the same operations once in an elevated copy of this exe ("--fileops").
/// </summary>
public static class FileOpRunner
{
    public static void Execute(IEnumerable<FileOp> ops)
    {
        var winDir = Environment.GetFolderPath(Environment.SpecialFolder.Windows);
        foreach (var op in ops)
        {
            var target = Path.GetFullPath(op.Target);
            if (target.StartsWith(winDir + "\\", StringComparison.OrdinalIgnoreCase))
                throw new InvalidOperationException($"Refusing to modify a Windows system path: {target}");
            switch (op.Op)
            {
                case "Copy":
                    Directory.CreateDirectory(Path.GetDirectoryName(target)!);
                    File.Copy(op.Source, target, true);
                    break;
                case "Delete":
                    if (File.Exists(target)) File.Delete(target);
                    break;
                default: throw new InvalidOperationException("Unknown op " + op.Op);
            }
        }
    }

    static bool CanWrite(string dir)
    {
        try
        {
            Directory.CreateDirectory(dir);
            var probe = Path.Combine(dir, $".lgl-probe-{Guid.NewGuid():N}.tmp");
            File.WriteAllText(probe, "");
            File.Delete(probe);
            return true;
        }
        catch { return false; }
    }

    public static async Task<(bool Ok, string Error)> RunAsync(List<FileOp> ops, string reason, Window? owner)
    {
        if (ops.Count == 0) return (true, "");
        var dirs = ops.Select(o => Path.GetDirectoryName(Path.GetFullPath(o.Target))!).Distinct(StringComparer.OrdinalIgnoreCase);
        bool needsAdmin = dirs.Any(d => !CanWrite(d));
        if (!needsAdmin)
        {
            try { Execute(ops); return (true, ""); }
            catch (UnauthorizedAccessException) { needsAdmin = true; }
            catch (Exception ex) { return (false, ex.Message); }
        }

        var preview = string.Join("\n", ops.Take(8).Select(o => "• " + o)) + (ops.Count > 8 ? $"\n• … and {ops.Count - 8} more" : "");
        var msg = $"Administrator permission is needed for this action:\n\n{reason}\n\n" +
                  "The game folder is protected by Windows (typically because it is under Program Files). " +
                  "The launcher will start a short-lived elevated helper that performs only these file operations and then exits:\n\n" +
                  preview + "\n\nContinue? (Windows will show a UAC prompt.)";
        var answer = owner != null
            ? MessageBox.Show(owner, msg, "Admin rights needed", MessageBoxButton.YesNo, MessageBoxImage.Warning)
            : MessageBox.Show(msg, "Admin rights needed", MessageBoxButton.YesNo, MessageBoxImage.Warning);
        if (answer != MessageBoxResult.Yes) return (false, "Cancelled - admin permission was not granted.");

        AppPaths.Ensure();
        var file = Path.Combine(AppPaths.Staging, $"ops-{Guid.NewGuid():N}.json");
        var bytes = JsonSerializer.SerializeToUtf8Bytes(ops, Json.Options);
        File.WriteAllBytes(file, bytes);
        var hash = Convert.ToHexString(SHA256.HashData(bytes));
        var resultFile = file + ".result";
        try
        {
            var psi = new ProcessStartInfo(Environment.ProcessPath!)
            {
                UseShellExecute = true,
                Verb = "runas",
                ArgumentList = { "--fileops", file, hash },
            };
            using var p = Process.Start(psi)!;
            await p.WaitForExitAsync();
            var err = File.Exists(resultFile) ? File.ReadAllText(resultFile) : "";
            return p.ExitCode == 0 ? (true, "") : (false, string.IsNullOrEmpty(err) ? $"Elevated helper failed (exit {p.ExitCode})." : err);
        }
        catch (Win32Exception ex) when (ex.NativeErrorCode == 1223)
        {
```

```cs
/// <summary>
/// Starts the game SUSPENDED, applies CPU affinity + priority before any game code runs (so engines that size
/// thread pools from the core count see the limit), puts it in a job object to follow child processes, then resumes.
/// </summary>
public static class GameProcess
{
    const uint CREATE_SUSPENDED = 0x4;
    const uint INFINITE_WAIT_SLICE = 2000;
    public const int ERROR_ELEVATION_REQUIRED = 740;

    [StructLayout(LayoutKind.Sequential, CharSet = CharSet.Unicode)]
    struct STARTUPINFO
    {
        public int cb; public string? lpReserved, lpDesktop, lpTitle;
        public int dwX, dwY, dwXSize, dwYSize, dwXCountChars, dwYCountChars, dwFillAttribute, dwFlags;
        public short wShowWindow, cbReserved2; public IntPtr lpReserved2, hStdInput, hStdOutput, hStdError;
    }
    [StructLayout(LayoutKind.Sequential)]
    struct PROCESS_INFORMATION { public IntPtr hProcess, hThread; public int dwProcessId, dwThreadId; }

    [DllImport("kernel32.dll", SetLastError = true, CharSet = CharSet.Unicode)]
    static extern bool CreateProcessW(string? app, StringBuilder cmd, IntPtr pa, IntPtr ta, bool inherit, uint flags, IntPtr env, string? cwd, ref STARTUPINFO si, out PROCESS_INFORMATION pi);
    [DllImport("kernel32.dll", SetLastError = true)] static extern bool SetProcessAffinityMask(IntPtr h, UIntPtr mask);
    [DllImport("kernel32.dll", SetLastError = true)] static extern bool SetPriorityClass(IntPtr h, uint cls);
    [DllImport("kernel32.dll", SetLastError = true)] static extern uint ResumeThread(IntPtr h);
    [DllImport("kernel32.dll", SetLastError = true)] static extern bool CloseHandle(IntPtr h);
    [DllImport("kernel32.dll", SetLastError = true)] static extern uint WaitForSingleObject(IntPtr h, uint ms);

    [DllImport("kernel32.dll", SetLastError = true)] static extern bool QueryInformationJobObject(IntPtr job, int cls, IntPtr info, int len, IntPtr ret);
    [DllImport("kernel32.dll", SetLastError = true)] static extern bool TerminateProcess(IntPtr h, uint code);

    static uint PriorityClass(string p) => p switch
    {
        "BelowNormal" => 0x4000, "AboveNormal" => 0x8000, "High" => 0x80, _ => 0x20,
    };

    public static LaunchResult Run(LaunchRequest r, Action<string>? log = null)
    {
        var res = new LaunchResult { Elevated = Environment.IsPrivilegedProcess };
        var si = new STARTUPINFO { cb = Marshal.SizeOf<STARTUPINFO>() };
        var cmd = new StringBuilder($"\"{r.ExePath}\" {r.Arguments}".TrimEnd());
        // Always start in the exe's own folder: many old games (and loaders such as SafeDiscLoader2) open files by relative path.
        var cwd = string.IsNullOrWhiteSpace(r.WorkingDirectory) ? Path.GetDirectoryName(r.ExePath) : r.WorkingDirectory;
        res.WorkingDirectory = cwd ?? "";
        if (!CreateProcessW(r.ExePath, cmd, IntPtr.Zero, IntPtr.Zero, false, CREATE_SUSPENDED, IntPtr.Zero, cwd, ref si, out var pi))
        {
            res.Win32Error = Marshal.GetLastWin32Error();
            res.Error = new Win32Exception(res.Win32Error).Message;
            return res;
        }
        res.Started = true;
        res.Pid = pi.dwProcessId;
        res.StartedLocal = DateTime.Now;

        var job = CreateJobObjectW(IntPtr.Zero, null);
        bool inJob = job != IntPtr.Zero && AssignProcessToJobObject(job, pi.hProcess);

        if (r.AffinityMask != 0)
        {
            res.AffinityResult = SetProcessAffinityMask(pi.hProcess, (UIntPtr)(ulong)r.AffinityMask)
                ? $"applied mask 0x{r.AffinityMask:X} ({BitOps(r.AffinityMask)} logical CPUs: {CpuList(r.AffinityMask)}) before start; child processes inherit it"
                : $"FAILED ({new Win32Exception(Marshal.GetLastWin32Error()).Message})";
        }
        if (r.Priority != "Normal")
        {
            res.PriorityResult = SetPriorityClass(pi.hProcess, PriorityClass(r.Priority))
                ? r.Priority : $"FAILED to set {r.Priority} ({new Win32Exception(Marshal.GetLastWin32Error()).Message})";
        }

        ResumeThread(pi.hThread);
        CloseHandle(pi.hThread);
        log?.Invoke($"Started PID {pi.dwProcessId} in \"{cwd}\". Affinity: {res.AffinityResult}. Priority: {res.PriorityResult}.");

        // Follow the whole process tree two ways: the job object, and parent-PID links (catches children that
        // broke away from the job, e.g. SafeDisc's ~e5.0001.exe helper in %TEMP%).
        var seen = new HashSet<string>();
        var tree = new HashSet<int> { pi.dwProcessId };
        var startTimes = new Dictionary<int, DateTime>();
        void Note(int pid)
        {
            try
            {
                using var p = Process.GetProcessById(pid);
                if (!startTimes.ContainsKey(pid)) startTimes[pid] = p.StartTime;
                var label = $"{p.ProcessName}.exe (PID {pid})";
                if (seen.Add(label)) log?.Invoke($"Process in game tree: {label}");
            }
            catch { }
        }
        List<int> Alive()
        {
            var alive = new List<int>();
            if (inJob) foreach (var pid in JobPids(job)) { tree.Add(pid); }
            foreach (var (pid, parent) in ProcessParents())
                if (tree.Contains(parent)) tree.Add(pid);
            foreach (var pid in tree)
            {
                if (pid == pi.dwProcessId && res.MainExitedLocal == null) continue;
                try
                {
                    using var p = Process.GetProcessById(pid);
                    // Guard against PID reuse: only count a process started after the launch.
                    if (p.StartTime >= res.StartedLocal.AddSeconds(-1) && !p.HasExited) { alive.Add(pid); Note(pid); }
                }
                catch { }
            }
            return alive;
        }

        while (WaitForSingleObject(pi.hProcess, INFINITE_WAIT_SLICE) != 0) Alive();
        GetExitCodeProcess(pi.hProcess, out var code);
        res.ExitCode = code;
        res.MainExitedLocal = DateTime.Now;
        CloseHandle(pi.hProcess);
        log?.Invoke($"Main process exited with code {ExitCodes.Describe(code)} after {(res.MainExitedLocal.Value - res.StartedLocal).TotalSeconds:0.0}s.");

        // Some games (and SafeDisc) start a second process and exit the first; keep following until everything is gone.
        var left = Alive();
        if (left.Count > 0)
        {
            res.ChildrenOutlivedMain = true;
            log?.Invoke($"{left.Count} child process(es) still running - following them.");
            while (left.Count > 0) { Thread.Sleep(1000); left = Alive(); }
        }
        res.AllExitedLocal = DateTime.Now;
        res.ProcessTree = seen.ToList();
        if (job != IntPtr.Zero) CloseHandle(job);
        return res;
    }

    [StructLayout(LayoutKind.Sequential, CharSet = CharSet.Unicode)]
    struct PROCESSENTRY32W
    {
        public int dwSize, cntUsage, th32ProcessID; public IntPtr th32DefaultHeapID; public int th32ModuleID, cntThreads, th32ParentProcessID, pcPriClassBase, dwFlags;
        [MarshalAs(UnmanagedType.ByValTStr, SizeConst = 260)] public string szExeFile;
    }
    [DllImport("kernel32.dll", SetLastError = true)] static extern IntPtr CreateToolhelp32Snapshot(uint flags, int pid);
    [DllImport("kernel32.dll", SetLastError = true, CharSet = CharSet.Unicode)] static extern bool Process32FirstW(IntPtr snap, ref PROCESSENTRY32W e);
    [DllImport("kernel32.dll", SetLastError = true, CharSet = CharSet.Unicode)] static extern bool Process32NextW(IntPtr snap, ref PROCESSENTRY32W e);

    /// <summary>(pid, parent pid) for every running process. Repeated until no new descendants appear.</summary>
    static List<(int Pid, int Parent)> ProcessParents()
    {
        var list = new List<(int, int)>();
        var snap = CreateToolhelp32Snapshot(0x2 /* TH32CS_SNAPPROCESS */, 0);
        if (snap == IntPtr.Zero || snap == new IntPtr(-1)) return list;
        try
        {
            var e = new PROCESSENTRY32W { dwSize = Marshal.SizeOf<PROCESSENTRY32W>() };
            if (Process32FirstW(snap, ref e))
                do list.Add((e.th32ProcessID, e.th32ParentProcessID)); while (Process32NextW(snap, ref e));
        }
        finally { CloseHandle(snap); }
        // Order so parents come before children: a few passes in Alive() are cheaper than sorting by tree depth.
        return list.Concat(list).Concat(list).ToList();
    }

    static List<int> JobPids(IntPtr job)
    {
        const int JobObjectBasicProcessIdList = 3;
        int size = 8 + 256 * IntPtr.Size;
        var buf = Marshal.AllocHGlobal(size);
        try
        {
            if (!QueryInformationJobObject(job, JobObjectBasicProcessIdList, buf, size, IntPtr.Zero)) return new();
            int count = Marshal.ReadInt32(buf, 4);
            var list = new List<int>();
            for (int i = 0; i < count; i++) list.Add((int)Marshal.ReadIntPtr(buf, 8 + i * IntPtr.Size));
            return list;
        }
        finally { Marshal.FreeHGlobal(buf); }
    }

    static int BitOps(long m) => System.Numerics.BitOperations.PopCount((ulong)m);
    static string CpuList(long m) => string.Join(",", Enumerable.Range(0, 64).Where(i => ((m >> i) & 1) != 0));

    /// <summary>Starts the game through an elevated copy of this exe (only when the game needs admin).</summary>
    public static async Task<LaunchResult> RunElevatedAsync(LaunchRequest r)
    {
        AppPaths.Ensure();
        var file = Path.Combine(AppPaths.Staging, $"launch-{Guid.NewGuid():N}.json");
        var bytes = JsonSerializer.SerializeToUtf8Bytes(r, Json.Options);
        File.WriteAllBytes(file, bytes);
        var hash = Convert.ToHexString(SHA256.HashData(bytes));
        try
        {
            var psi = new ProcessStartInfo(Environment.ProcessPath!) { UseShellExecute = true, Verb = "runas", ArgumentList = { "--launch", file, hash } };
            using var p = Process.Start(psi)!;
            await p.WaitForExitAsync();
            var resFile = file + ".result";
            if (File.Exists(resFile))
                return JsonSerializer.Deserialize<LaunchResult>(File.ReadAllText(resFile), Json.Options) ?? new LaunchResult { Error = "Empty result" };
            return new LaunchResult { Error = $"Elevated helper exited with {p.ExitCode} without a result." };
        }
        catch (Win32Exception ex) when (ex.NativeErrorCode == 1223)
        {
            return new LaunchResult { Error = "Cancelled at the UAC prompt." };
        }
        finally
        {
            try { File.Delete(file); File.Delete(file + ".result"); } catch { }
        }
    }

    public static int RunLaunchHelper(string file, string expectedHash)
```

```cs
using System.Runtime.InteropServices;
using System.Text;
using System.Windows.Interop;

namespace LegacyGameLauncher.Services;

public sealed class PadAxis
{
    public ushort Page, Usage;
    public string Name = "";
    public double Value;          // 0..1 (0.5 = centre for sticks)
    public long Raw;
    public bool IsHat;
    public string HatText = "centre";
}

public sealed class PadState
{
    public IntPtr Handle;
    public string Name = "HID game controller";
    public int ButtonCount;
    public HashSet<int> Pressed = new();
    public List<PadAxis> Axes = new();
    public DateTime LastReport;
}

/// <summary>
/// Live view of game controllers through Windows Raw Input + the HID parser. Axis and button names come from the
/// HID usages (X, Y, Z, Rx, Ry, Rz, Button N), which are exactly the names DirectInput games see - so this shows
/// what an old DirectInput game like Rugby 08 gets from the pad. Read-only; nothing is sent to the device.
/// </summary>
public sealed class RawGamepadMonitor : IDisposable
{
    const int WM_INPUT = 0x00FF;
    const uint RIDEV_INPUTSINK = 0x100, RIDEV_REMOVE = 0x1;
    const uint RID_INPUT = 0x10000003, RIM_TYPEHID = 2;
    const uint RIDI_PREPARSEDDATA = 0x20000005, RIDI_DEVICENAME = 0x20000007;
    const int HidP_Input = 0;
    const int HIDP_STATUS_SUCCESS = 0x00110000;

    [StructLayout(LayoutKind.Sequential)]
    struct RAWINPUTDEVICE { public ushort UsagePage, Usage; public uint Flags; public IntPtr Target; }

    [DllImport("user32.dll", SetLastError = true)] static extern bool RegisterRawInputDevices(RAWINPUTDEVICE[] d, uint n, uint size);
    [DllImport("user32.dll")] static extern uint GetRawInputData(IntPtr h, uint cmd, IntPtr data, ref uint size, uint headerSize);
    [DllImport("user32.dll", CharSet = CharSet.Unicode)] static extern uint GetRawInputDeviceInfoW(IntPtr dev, uint cmd, IntPtr data, ref uint size);
    [DllImport("hid.dll")] static extern int HidP_GetCaps(IntPtr pp, byte[] caps);
    [DllImport("hid.dll")] static extern int HidP_GetValueCaps(int type, byte[] caps, ref ushort len, IntPtr pp);
    [DllImport("hid.dll")] static extern int HidP_GetButtonCaps(int type, byte[] caps, ref ushort len, IntPtr pp);
    [DllImport("hid.dll")] static extern int HidP_GetUsages(int type, ushort page, ushort link, ushort[] list, ref uint len, IntPtr pp, byte[] report, uint reportLen);
    [DllImport("hid.dll")] static extern int HidP_GetUsageValue(int type, ushort page, ushort link, ushort usage, out uint value, IntPtr pp, byte[] report, uint reportLen);
    [DllImport("hid.dll")] static extern uint HidP_MaxUsageListLength(int type, ushort page, IntPtr pp);
    [DllImport("hid.dll", CharSet = CharSet.Unicode)] static extern bool HidD_GetProductString(IntPtr h, StringBuilder buf, int bytes);
    [DllImport("kernel32.dll", CharSet = CharSet.Unicode, SetLastError = true)]
    static extern IntPtr CreateFileW(string name, uint access, uint share, IntPtr sa, uint disposition, uint flags, IntPtr template);
    [DllImport("kernel32.dll")] static extern bool CloseHandle(IntPtr h);

    sealed class ValueCap { public ushort Page, Usage, Link, BitSize; public int Min, Max; }

    sealed class Device
    {
        public PadState State = new();
        public IntPtr Preparsed;
        public List<ValueCap> Values = new();
        public ushort ButtonLink;
        public uint MaxButtons;
    }

    readonly Dictionary<IntPtr, Device> _devices = new();
    HwndSource? _source;

    public IReadOnlyList<PadState> Pads => _devices.Values.Select(d => d.State).OrderBy(s => s.Name).ToList();

    public void Start(System.Windows.Window window)
    {
        var helper = new WindowInteropHelper(window);
        _source = HwndSource.FromHwnd(helper.Handle);
        _source.AddHook(Hook);
        var devs = new[]
        {
            new RAWINPUTDEVICE { UsagePage = 1, Usage = 4, Flags = RIDEV_INPUTSINK, Target = helper.Handle }, // joystick
            new RAWINPUTDEVICE { UsagePage = 1, Usage = 5, Flags = RIDEV_INPUTSINK, Target = helper.Handle }, // gamepad
            new RAWINPUTDEVICE { UsagePage = 1, Usage = 8, Flags = RIDEV_INPUTSINK, Target = helper.Handle }, // multi-axis
        };
        if (!RegisterRawInputDevices(devs, (uint)devs.Length, (uint)Marshal.SizeOf<RAWINPUTDEVICE>()))
            throw new InvalidOperationException("Windows refused raw input registration (error " + Marshal.GetLastWin32Error() + ").");
    }

    public void Stop()
    {
        var devs = new[]
        {
            new RAWINPUTDEVICE { UsagePage = 1, Usage = 4, Flags = RIDEV_REMOVE },
            new RAWINPUTDEVICE { UsagePage = 1, Usage = 5, Flags = RIDEV_REMOVE },
            new RAWINPUTDEVICE { UsagePage = 1, Usage = 8, Flags = RIDEV_REMOVE },
        };
        RegisterRawInputDevices(devs, (uint)devs.Length, (uint)Marshal.SizeOf<RAWINPUTDEVICE>());
        _source?.RemoveHook(Hook);
        _source = null;
        foreach (var d in _devices.Values) if (d.Preparsed != IntPtr.Zero) Marshal.FreeHGlobal(d.Preparsed);
        _devices.Clear();
    }

    public void Dispose() => Stop();

    IntPtr Hook(IntPtr hwnd, int msg, IntPtr wParam, IntPtr lParam, ref bool handled)
    {
        if (msg == WM_INPUT) { try { OnInput(lParam); } catch { } }
        return IntPtr.Zero;
    }

    void OnInput(IntPtr hRaw)
    {
        int header = 8 + 2 * IntPtr.Size;
        uint size = 0;
        GetRawInputData(hRaw, RID_INPUT, IntPtr.Zero, ref size, (uint)header);
        if (size == 0) return;
        var buf = Marshal.AllocHGlobal((int)size);
        try
        {
            if (GetRawInputData(hRaw, RID_INPUT, buf, ref size, (uint)header) != size) return;
            if ((uint)Marshal.ReadInt32(buf, 0) != RIM_TYPEHID) return;
            var hDevice = Marshal.ReadIntPtr(buf, 8);
            int sizeHid = Marshal.ReadInt32(buf, header);
            int count = Marshal.ReadInt32(buf, header + 4);
            if (sizeHid <= 0 || count <= 0) return;
            var dev = GetDevice(hDevice);
            if (dev == null) return;
            // Use the latest report in the batch.
            var report = new byte[sizeHid];
            Marshal.Copy(buf + header + 8 + (count - 1) * sizeHid, report, 0, sizeHid);
            Parse(dev, report);
        }
        finally { Marshal.FreeHGlobal(buf); }
    }

    Device? GetDevice(IntPtr h)
    {
        if (_devices.TryGetValue(h, out var d)) return d;
        uint size = 0;
        GetRawInputDeviceInfoW(h, RIDI_PREPARSEDDATA, IntPtr.Zero, ref size);
        if (size == 0) return null;
        var pp = Marshal.AllocHGlobal((int)size);
        if (GetRawInputDeviceInfoW(h, RIDI_PREPARSEDDATA, pp, ref size) == unchecked((uint)-1)) { Marshal.FreeHGlobal(pp); return null; }

        d = new Device { Preparsed = pp, State = { Handle = h } };
        var caps = new byte[64];
        if (HidP_GetCaps(pp, caps) != HIDP_STATUS_SUCCESS) { Marshal.FreeHGlobal(pp); return null; }
        ushort nButtonCaps = BitConverter.ToUInt16(caps, 46), nValueCaps = BitConverter.ToUInt16(caps, 48);

        if (nButtonCaps > 0)
        {
            var bc = new byte[72 * nButtonCaps];
            if (HidP_GetButtonCaps(HidP_Input, bc, ref nButtonCaps, pp) == HIDP_STATUS_SUCCESS)
                for (int i = 0; i < nButtonCaps; i++)
                {
                    int o = i * 72;
                    if (BitConverter.ToUInt16(bc, o) != 9) continue; // Button page
                    d.ButtonLink = BitConverter.ToUInt16(bc, o + 6);
                    bool range = bc[o + 12] != 0;
                    int max = range ? BitConverter.ToUInt16(bc, o + 58) : BitConverter.ToUInt16(bc, o + 56);
                    d.State.ButtonCount = Math.Max(d.State.ButtonCount, max);
                }
            d.MaxButtons = HidP_MaxUsageListLength(HidP_Input, 9, pp);
        }
        if (nValueCaps > 0)
        {
            var vc = new byte[72 * nValueCaps];
            if (HidP_GetValueCaps(HidP_Input, vc, ref nValueCaps, pp) == HIDP_STATUS_SUCCESS)
                for (int i = 0; i < nValueCaps; i++)
                {
                    int o = i * 72;
                    ushort page = BitConverter.ToUInt16(vc, o);
                    if (page >= 0xFF00) continue; // vendor-specific (e.g. DS4 motion/touch data)
                    bool range = vc[o + 12] != 0;
                    ushort uMin = BitConverter.ToUInt16(vc, o + 56), uMax = range ? BitConverter.ToUInt16(vc, o + 58) : uMin;
                    for (ushort u = uMin; u <= uMax; u++)
                    {
                        var cap = new ValueCap
                        {
                            Page = page, Usage = u, Link = BitConverter.ToUInt16(vc, o + 6), BitSize = BitConverter.ToUInt16(vc, o + 18),
                            Min = BitConverter.ToInt32(vc, o + 40), Max = BitConverter.ToInt32(vc, o + 44),
                        };
                        if (cap.Max < cap.Min || (cap.Min == 0 && cap.Max == -1)) { cap.Min = 0; cap.Max = (int)Math.Min(int.MaxValue, (1L << Math.Min((int)cap.BitSize, 31)) - 1); }
                        if (d.Values.Any(v => v.Page == page && v.Usage == u)) continue;
                        d.Values.Add(cap);
                        d.State.Axes.Add(new PadAxis { Page = page, Usage = u, Name = UsageName(page, u), IsHat = page == 1 && u == 0x39 });
                    }
                }
        }
        // Order like DirectInput: X, Y, Z, Rx, Ry, Rz, sliders, then hat.
        d.State.Axes = d.State.Axes.OrderBy(a => a.IsHat).ThenBy(a => a.Page).ThenBy(a => a.Usage).ToList();
        // If the device can't be opened by path, something (usually HidHide via DS4Windows) is hiding it from
        // normal access - DirectInput games then won't see it, even though Raw Input still shows its data here.
        d.State.Name = ProductName(h) ?? "HID game controller (hidden from games - e.g. by HidHide; shown here via Raw Input only)";
        _devices[h] = d;
        return d;
    }

    void Parse(Device d, byte[] report)
    {
        var s = d.State;
        s.LastReport = DateTime.Now;
        if (d.MaxButtons > 0)
        {
            var list = new ushort[d.MaxButtons];
            uint len = d.MaxButtons;
            s.Pressed.Clear();
            if (HidP_GetUsages(HidP_Input, 9, 0, list, ref len, d.Preparsed, report, (uint)report.Length) == HIDP_STATUS_SUCCESS)
                for (int i = 0; i < len; i++) s.Pressed.Add(list[i]);
        }
        foreach (var cap in d.Values)
        {
            if (HidP_GetUsageValue(HidP_Input, cap.Page, 0, cap.Usage, out var raw, d.Preparsed, report, (uint)report.Length) != HIDP_STATUS_SUCCESS) continue;
            var axis = s.Axes.First(a => a.Page == cap.Page && a.Usage == cap.Usage);
            long v = raw;
            if (cap.Min < 0 && cap.BitSize is > 0 and < 32 && (v & (1L << (cap.BitSize - 1))) != 0) v -= 1L << cap.BitSize; // sign-extend
            axis.Raw = v;
            if (axis.IsHat)
            {
                int steps = cap.Max - cap.Min + 1;
                axis.HatText = v < cap.Min || v > cap.Max ? "centre" : HatName((int)(v - cap.Min), steps);
                axis.Value = 0;
            }
            else axis.Value = cap.Max == cap.Min ? 0 : Math.Clamp((v - cap.Min) / (double)(cap.Max - cap.Min), 0, 1);
        }
    }

    static string HatName(int pos, int steps)
    {
        string[] eight = { "up", "up-right", "right", "down-right", "down", "down-left", "left", "up-left" };
        if (steps == 8) return eight[pos];
        if (steps == 4) return new[] { "up", "right", "down", "left" }[pos];
        return pos.ToString();
    }

    public static string UsageName(ushort page, ushort usage) => (page, usage) switch
    {
        (1, 0x30) => "X", (1, 0x31) => "Y", (1, 0x32) => "Z",
        (1, 0x33) => "Rx", (1, 0x34) => "Ry", (1, 0x35) => "Rz",
        (1, 0x36) => "Slider", (1, 0x37) => "Dial", (1, 0x38) => "Wheel", (1, 0x39) => "Hat (D-pad)",
        (2, 0xC4) => "Accelerator", (2, 0xC5) => "Brake",
        _ => $"Page {page:X2} usage {usage:X2}",
    };

    static string? ProductName(IntPtr hDevice)
    {
        uint chars = 0;
        GetRawInputDeviceInfoW(hDevice, RIDI_DEVICENAME, IntPtr.Zero, ref chars);
        if (chars == 0) return null;
        var buf = Marshal.AllocHGlobal((int)chars * 2);
        try
        {
            if (GetRawInputDeviceInfoW(hDevice, RIDI_DEVICENAME, buf, ref chars) == unchecked((uint)-1)) return null;
            var path = Marshal.PtrToStringUni(buf);
            if (string.IsNullOrEmpty(path)) return null;
            var h = CreateFileW(path, 0, 3, IntPtr.Zero, 3, 0, IntPtr.Zero);
            if (h == new IntPtr(-1)) return null;
            try
            {
                var sb = new StringBuilder(128);
                return HidD_GetProductString(h, sb, sb.Capacity * 2) && sb.Length > 0 ? sb.ToString() : null;
            }
            finally { CloseHandle(h); }
        }
        finally { Marshal.FreeHGlobal(buf); }
    }
```

```cs
    public string DllPath { get; set; } = "";

/// <summary>
/// Cooperates with a SafeDiscLoader2 install the user already placed next to the game (a version.dll proxy plus
/// version.json). DETECTION AND LAUNCH HYGIENE ONLY: the launcher never installs, configures or modifies the loader,
/// the game exe or its copy protection. It only avoids things that break the loader (compat layers, wrong working
/// directory) and reads the loader's own log afterwards.
/// </summary>
public static class SafeDiscLoaderSupport
{
    static readonly string[] Markers = { "SafeDiscLoader", "version-proxy" };

    public static LoaderInfo Detect(string exePath)
    {
        var dir = Path.GetDirectoryName(exePath) ?? "";
        var info = new LoaderInfo { DllPath = Path.Combine(dir, "version.dll"), LogPath = Path.Combine(dir, "version.log.txt") };
        if (!File.Exists(info.DllPath)) return info;

        var evidence = new List<string> { "version.dll next to the exe" };
        bool confirmed = false;
        try
        {
            var text = Encoding.Latin1.GetString(File.ReadAllBytes(info.DllPath));
            foreach (var m in Markers)
                if (text.Contains(m, StringComparison.OrdinalIgnoreCase)) { evidence.Add($"'{m}' text in version.dll"); confirmed = true; }
        }
        catch { }

        var cfg = Path.Combine(dir, "version.json");
        if (File.Exists(cfg))
        {
            info.ConfigPath = cfg;
            evidence.Add("version.json beside it");
            confirmed = true;
            try
            {
                using var doc = JsonDocument.Parse(File.ReadAllText(cfg), new JsonDocumentOptions { AllowTrailingCommas = true, CommentHandling = JsonCommentHandling.Skip });
                var root = doc.RootElement;
                if (root.TryGetProperty("logfile", out var lf) && lf.ValueKind == JsonValueKind.String && !string.IsNullOrWhiteSpace(lf.GetString()))
                {
                    var name = lf.GetString()!;
                    info.LogPath = Path.IsPathRooted(name) ? name : Path.Combine(dir, name);
                }
                if (root.TryGetProperty("logging", out var lg) && (lg.ValueKind == JsonValueKind.False)) info.LoggingEnabled = false;
                if (root.TryGetProperty("exefile", out var ef) && ef.ValueKind == JsonValueKind.String &&
                    !string.Equals(ef.GetString(), Path.GetFileName(exePath), StringComparison.OrdinalIgnoreCase))
                    evidence.Add($"note: version.json names \"{ef.GetString()}\", not {Path.GetFileName(exePath)}");
            }
            catch (Exception ex) { evidence.Add("version.json could not be read: " + ex.Message); }
        }

        // A bare version.dll without markers or version.json (e.g. a stray copy of the system DLL) is not treated as a loader;
        // the user can still force loader mode with the "On" setting.
        info.Detected = confirmed;
        info.Evidence = string.Join("; ", evidence) + (confirmed ? "" : " (no loader markers found)");
        return info;
    }

    /// <summary>Resolves the per-game Auto/On/Off setting.</summary>
    public static bool IsActive(CompatSettings c, LoaderInfo info) => c.SafeDiscLoader switch
    {
        "On" => true,
        "Off" => false,
        _ => info.Detected,
    };

    /// <summary>After launch: did the loader write its log during this run? Returns log lines for the launch log.</summary>
    /// <param name="gameLooksOk">The game ran and ended without a crash (clean exit, no error events, not a quick exit).</param>
    public static List<string> PostLaunchReport(LoaderInfo info, DateTime launchStartedLocal, bool gameLooksOk = false)
    {
        var lines = new List<string>();
        if (!info.LoggingEnabled)
        {
            lines.Add("SAFEDISC LOADER: logging is turned off in version.json (\"logging\": false), so the launcher can't confirm the loader ran.");
            return lines;
        }
        var fi = new FileInfo(info.LogPath);
        if (!fi.Exists || fi.LastWriteTime < launchStartedLocal.AddSeconds(-2))
        {
            // Seen on working runs of Cricket 07 (double-clicked and from the launcher): the game reached its menu but
            // the log was not rewritten. So a missing update only points at the loader when the game also failed.
            if (gameLooksOk)
            {
                lines.Add($"SafeDisc loader: {Path.GetFileName(info.LogPath)} was not updated during this launch, but the game ran and exited cleanly, " +
                          "so it got past the disc check. (This loader doesn't always rewrite its log.)");
                return lines;
            }
            lines.Add($"SAFEDISC LOADER MAY NOT HAVE RUN: the game failed and {Path.GetFileName(info.LogPath)} was {(fi.Exists ? $"not updated (last written {fi.LastWriteTime:yyyy-MM-dd HH:mm:ss})" : "not created")} during this launch. " +
                      "Usual causes: the game was started with a different working directory, a compatibility layer loaded the system version.dll first, " +
                      "or antivirus blocked/quarantined version.dll.");
            return lines;
        }
        lines.Add($"SafeDisc loader ran: {Path.GetFileName(info.LogPath)} updated at {fi.LastWriteTime:HH:mm:ss}. Last 20 lines:");
        foreach (var l in Tail(info.LogPath, 20)) lines.Add("  | " + l);
        return lines;
    }

    static IEnumerable<string> Tail(string path, int n)
    {
        try
        {
            using var fs = new FileStream(path, FileMode.Open, FileAccess.Read, FileShare.ReadWrite | FileShare.Delete);
            long start = Math.Max(0, fs.Length - 64 * 1024);
            fs.Seek(start, SeekOrigin.Begin);
            using var sr = new StreamReader(fs, Encoding.Latin1);
            var all = sr.ReadToEnd().Split('\n').Select(l => l.TrimEnd('\r')).ToList();
            if (start > 0 && all.Count > 0) all.RemoveAt(0); // partial first line
            while (all.Count > 0 && all[^1].Length == 0) all.RemoveAt(all.Count - 1);
            return all.Skip(Math.Max(0, all.Count - n)).ToList();
        }
        catch (Exception ex) { return new[] { "(could not read log: " + ex.Message + ")" }; }
    }
```

```cs
    public static (GameProfile? Profile, string Note) Detect(string exePath, string sha256)
    {
        var exeName = Path.GetFileName(exePath);
        var profiles = ProfileCatalog.Profiles;

        var byHash = profiles.FirstOrDefault(p => p.Sha256.Any(h => h.Equals(sha256, StringComparison.OrdinalIgnoreCase)));
        if (byHash != null) return (byHash, "Exact match by SHA-256 hash (high confidence).");

        var byName = profiles.FirstOrDefault(p => p.ExeNames.Any(n => n.Equals(exeName, StringComparison.OrdinalIgnoreCase)));
        if (byName != null) return (byName, $"Matched by executable name \"{exeName}\" (medium confidence; hash not in profile).");

        try
        {
            var vi = System.Diagnostics.FileVersionInfo.GetVersionInfo(exePath);
            var text = $"{vi.ProductName} | {vi.FileDescription}";
            var byVer = profiles.FirstOrDefault(p => p.ProductNameContains.Any(s => text.Contains(s, StringComparison.OrdinalIgnoreCase)));
            if (byVer != null) return (byVer, $"Matched by version info \"{text.Trim(' ', '|')}\" (medium confidence).");
        }
        catch { }

        var folder = Path.GetFileName(Path.GetDirectoryName(exePath) ?? "") ?? "";
        var byFolder = profiles.FirstOrDefault(p => p.FolderNameContains.Any(s => folder.Contains(s, StringComparison.OrdinalIgnoreCase)));
        if (byFolder != null) return (byFolder, $"Matched by install folder name \"{folder}\" (LOW confidence - check this is the game's main exe).");

        return (null, "No built-in profile matched. Generic settings are available; you can add a profile JSON for this game.");
    }
```

```cs
/// <summary>
/// Downloads open-source / freeware game fixes (never Microsoft DLLs, never anything that touches copy protection)
/// from the projects' own GitHub releases into %LocalAppData%\LegacyGameLauncher\tools, verifies each file
/// against the SHA-256 that GitHub publishes for it, and extracts it safely. Installing into a game folder is

public static class ToolDownloader

    public static readonly ToolSpec Dinputto8 = new("dinputto8", "dinputto8", "elishacloud/dinputto8",
        new Regex(@"^dinput\.dll$", RegexOptions.IgnoreCase), "zlib licence",

    static readonly HttpClient Http = CreateClient();
    static HttpClient CreateClient()
    {
        var c = new HttpClient { Timeout = TimeSpan.FromMinutes(5) };
        c.DefaultRequestHeaders.UserAgent.ParseAdd("LegacyGameLauncher/1.0");
        c.DefaultRequestHeaders.Accept.ParseAdd("application/vnd.github+json");
        return c;

    /// <summary>Latest release info from api.github.com (no download yet).</summary>
    public static async Task<ToolRelease> LatestAsync(ToolSpec t, CancellationToken ct = default)
    {
        using var doc = JsonDocument.Parse(await Http.GetStringAsync($"https://api.github.com/repos/{t.Repo}/releases/latest", ct));
        var root = doc.RootElement;
        foreach (var a in root.GetProperty("assets").EnumerateArray())
        {
            var name = a.GetProperty("name").GetString() ?? "";
            if (!t.Asset.IsMatch(name)) continue;
            var url = a.GetProperty("browser_download_url").GetString() ?? "";
            // Only accept downloads that come from the project's own GitHub release.
            if (!url.StartsWith($"https://github.com/{t.Repo}/releases/download/", StringComparison.OrdinalIgnoreCase))
                throw new InvalidOperationException("Unexpected download location: " + url);
            string? sha = null;
            if (a.TryGetProperty("digest", out var dg) && dg.ValueKind == JsonValueKind.String && dg.GetString()!.StartsWith("sha256:"))
                sha = dg.GetString()!["sha256:".Length..];
            return new ToolRelease
            {
                Tag = root.GetProperty("tag_name").GetString() ?? "?", AssetName = name, Url = url,
                Size = a.GetProperty("size").GetInt64(), Sha256 = sha,
                Published = root.TryGetProperty("published_at", out var p) && p.TryGetDateTime(out var d) ? d : default,
            };
        }
        throw new InvalidOperationException($"The latest {t.Name} release has no file matching the expected name.");
    }

    /// <summary>The folder of an already-downloaded copy, or null.</summary>
    public static (string Folder, ToolManifest Manifest)? Cached(ToolSpec t)
    {
        var dir = Path.Combine(Root, t.Id);
        if (!Directory.Exists(dir)) return null;
        foreach (var sub in Directory.EnumerateDirectories(dir).OrderByDescending(Directory.GetCreationTime))
        {
            var mf = Path.Combine(sub, "manifest.json");
            if (!File.Exists(mf)) continue;
            try
            {
                var m = JsonSerializer.Deserialize<ToolManifest>(File.ReadAllText(mf), Json.Options);
                if (m != null) return (Path.Combine(sub, "files"), m);
            }
            catch { }
        }
        return null;
    }

    /// <summary>Downloads, verifies and extracts. Returns the folder that holds the tool's files.</summary>
    public static async Task<string> DownloadAsync(ToolSpec t, ToolRelease r, IProgress<string>? progress = null, CancellationToken ct = default)
    {
        var safeTag = string.Concat(r.Tag.Select(c => Path.GetInvalidFileNameChars().Contains(c) ? '_' : c));
        var dir = Path.Combine(Root, t.Id, safeTag);
        var files = Path.Combine(dir, "files");
        if (Directory.Exists(dir)) Directory.Delete(dir, true);
        Directory.CreateDirectory(files);

        var archive = Path.Combine(dir, r.AssetName);
        progress?.Report($"Downloading {r.AssetName} ({r.Size / 1024.0 / 1024.0:0.0} MB) from github.com/{t.Repo}…");
        using (var resp = await Http.GetAsync(r.Url, HttpCompletionOption.ResponseHeadersRead, ct))
        {
            resp.EnsureSuccessStatusCode();
            await using var src = await resp.Content.ReadAsStreamAsync(ct);
            await using var dst = File.Create(archive);
            var buf = new byte[81920]; long done = 0; int n; var last = DateTime.MinValue;
            while ((n = await src.ReadAsync(buf, ct)) > 0)
            {
                await dst.WriteAsync(buf.AsMemory(0, n), ct);
                done += n;
                if (DateTime.Now - last > TimeSpan.FromMilliseconds(300) && r.Size > 0) { progress?.Report($"Downloading {r.AssetName}: {done * 100 / r.Size}%"); last = DateTime.Now; }
            }
        }

        string actual;
        await using (var fs = File.OpenRead(archive)) actual = Convert.ToHexString(await SHA256.HashDataAsync(fs, ct)).ToLowerInvariant();
        if (r.Sha256 != null && !actual.Equals(r.Sha256, StringComparison.OrdinalIgnoreCase))
        {
            Directory.Delete(dir, true);
            throw new InvalidOperationException($"Checksum mismatch for {r.AssetName} - the download was discarded. Expected {r.Sha256}, got {actual}.");
        }
        progress?.Report(r.Sha256 != null ? "Checksum verified against GitHub's SHA-256." : "GitHub published no checksum for this file; recorded the SHA-256 locally.");

        if (r.AssetName.EndsWith(".zip", StringComparison.OrdinalIgnoreCase)) ExtractZip(archive, files);
        else if (r.AssetName.EndsWith(".tar.gz", StringComparison.OrdinalIgnoreCase)) await ExtractTarGzAsync(archive, files, ct);
        else File.Copy(archive, Path.Combine(files, r.AssetName));
        File.Delete(archive);

        var manifest = new ToolManifest { Id = t.Id, Tag = r.Tag, Source = r.Url, Sha256 = actual, Downloaded = DateTime.Now };
        File.WriteAllText(Path.Combine(dir, "manifest.json"), JsonSerializer.Serialize(manifest, Json.Options));
        progress?.Report($"{t.Name} {r.Tag} ready.");
        return files;
    }

    static string SafeTarget(string root, string entry)
    {
        var full = Path.GetFullPath(Path.Combine(root, entry));
        if (!full.StartsWith(Path.GetFullPath(root) + Path.DirectorySeparatorChar, StringComparison.OrdinalIgnoreCase))
            throw new InvalidOperationException("Archive entry points outside the extraction folder: " + entry);
        return full;
    }

    static void ExtractZip(string zip, string dest)
    {
        using var z = ZipFile.OpenRead(zip);
        foreach (var e in z.Entries)
        {
            var target = SafeTarget(dest, e.FullName);
            if (e.FullName.EndsWith('/') || e.FullName.EndsWith('\\')) { Directory.CreateDirectory(target); continue; }
            Directory.CreateDirectory(Path.GetDirectoryName(target)!);
            e.ExtractToFile(target, true);
        }
    }

    static async Task ExtractTarGzAsync(string file, string dest, CancellationToken ct)
    {
        await using var fs = File.OpenRead(file);
        await using var gz = new GZipStream(fs, CompressionMode.Decompress);
        using var tar = new TarReader(gz);
        TarEntry? e;
        while ((e = await tar.GetNextEntryAsync(cancellationToken: ct)) != null)
        {
            if (e.EntryType is not (TarEntryType.RegularFile or TarEntryType.V7RegularFile or TarEntryType.Directory)) continue; // no links
            var target = SafeTarget(dest, e.Name);
            if (e.EntryType == TarEntryType.Directory) { Directory.CreateDirectory(target); continue; }
            Directory.CreateDirectory(Path.GetDirectoryName(target)!);
            await e.ExtractToFileAsync(target, true, ct);
        }
    }

    /// <summary>The folder inside an extracted tool that the installers expect (e.g. the one holding MS\ or x32\).</summary>
    public static string InstallRoot(ToolSpec t, string files)
    {
        string? marker = t.Id switch { "dgvoodoo2" => "MS", "dxvk" => "x32", _ => null };
        if (marker == null) return files;
        if (Directory.Exists(Path.Combine(files, marker))) return files;
        var hit = Directory.EnumerateDirectories(files, marker, SearchOption.AllDirectories).FirstOrDefault();
        return hit != null ? Path.GetDirectoryName(hit)! : files;
    }
}
```

```cs
/// <summary>
/// Checks this app's own public GitHub releases for a newer version and updates in place: downloads
/// LegacyGameLauncher.exe from the release, verifies GitHub's SHA-256, swaps it with the running exe
/// (a running exe can be renamed, not overwritten) and restarts.
/// </summary>
public static class UpdateService
{
    public const string AssetName = "LegacyGameLauncher.exe";

    public static string Repo =>
        Assembly.GetExecutingAssembly().GetCustomAttributes<AssemblyMetadataAttribute>().FirstOrDefault(a => a.Key == "UpdateRepo")?.Value ?? "";

    public static Version Current
    {
        get
        {
            var v = Assembly.GetExecutingAssembly().GetName().Version ?? new Version(0, 0);
            return new Version(v.Major, v.Minor, Math.Max(0, v.Build));
        }
    }

    static readonly HttpClient Http = Create();
    static HttpClient Create()
    {
        var c = new HttpClient { Timeout = TimeSpan.FromMinutes(5) };
        c.DefaultRequestHeaders.UserAgent.ParseAdd("LegacyGameLauncher/" + Current);
        c.DefaultRequestHeaders.Accept.ParseAdd("application/vnd.github+json");
        return c;
    }

    static Version ParseTag(string tag)
    {
        var s = tag.TrimStart('v', 'V').Split('-', '+')[0];
        return Version.TryParse(s, out var v) ? new Version(v.Major, v.Minor, Math.Max(0, v.Build)) : new Version(0, 0);
    }

    public static async Task<UpdateInfo> CheckAsync(CancellationToken ct = default)
    {
        if (string.IsNullOrWhiteSpace(Repo)) throw new InvalidOperationException("This build has no update repository configured.");
        using var doc = JsonDocument.Parse(await Http.GetStringAsync($"https://api.github.com/repos/{Repo}/releases/latest", ct));
        var root = doc.RootElement;
        var info = new UpdateInfo
        {
            Tag = root.GetProperty("tag_name").GetString() ?? "",
            Notes = root.TryGetProperty("body", out var b) ? b.GetString() ?? "" : "",
            PageUrl = root.TryGetProperty("html_url", out var h) ? h.GetString() ?? "" : "",
        };
        info.Latest = ParseTag(info.Tag);
        foreach (var a in root.GetProperty("assets").EnumerateArray())
        {
            if (!string.Equals(a.GetProperty("name").GetString(), AssetName, StringComparison.OrdinalIgnoreCase)) continue;
            info.Url = a.GetProperty("browser_download_url").GetString() ?? "";
            info.Size = a.GetProperty("size").GetInt64();
            if (a.TryGetProperty("digest", out var d) && d.ValueKind == JsonValueKind.String && d.GetString()!.StartsWith("sha256:"))
                info.Sha256 = d.GetString()!["sha256:".Length..];
        }
        if (info.Url.Length > 0 && !info.Url.StartsWith($"https://github.com/{Repo}/releases/download/", StringComparison.OrdinalIgnoreCase))
            throw new InvalidOperationException("Unexpected download location: " + info.Url);
        return info;
    }

    /// <summary>Downloads and swaps in the new exe. Returns the path to start; the caller restarts the app.</summary>
    public static async Task<string> DownloadAndSwapAsync(UpdateInfo u, IProgress<string>? progress = null, CancellationToken ct = default)
    {
        if (u.Url.Length == 0) throw new InvalidOperationException($"Release {u.Tag} has no {AssetName} attached.");
        var exe = Environment.ProcessPath ?? throw new InvalidOperationException("Cannot find the running exe.");
        var dir = Path.GetDirectoryName(exe)!;
        var tmp = Path.Combine(dir, AssetName + ".download");
        try { File.WriteAllText(tmp, ""); File.Delete(tmp); }
        catch { throw new InvalidOperationException($"The launcher's folder ({dir}) isn't writable. Download {u.Tag} from {u.PageUrl} and replace the exe by hand."); }

        progress?.Report($"Downloading {u.Tag} ({u.Size / 1024.0 / 1024.0:0.0} MB)…");
        using (var resp = await Http.GetAsync(u.Url, HttpCompletionOption.ResponseHeadersRead, ct))
        {
            resp.EnsureSuccessStatusCode();
            await using var src = await resp.Content.ReadAsStreamAsync(ct);
            await using var dst = File.Create(tmp);
            var buf = new byte[81920]; long done = 0; int n; var last = DateTime.MinValue;
            while ((n = await src.ReadAsync(buf, ct)) > 0)
            {
                await dst.WriteAsync(buf.AsMemory(0, n), ct); done += n;
                if (u.Size > 0 && DateTime.Now - last > TimeSpan.FromMilliseconds(300)) { progress?.Report($"Downloading {u.Tag}: {done * 100 / u.Size}%"); last = DateTime.Now; }
            }
        }
        string actual;
        await using (var fs = File.OpenRead(tmp)) actual = Convert.ToHexString(await SHA256.HashDataAsync(fs, ct));
        if (u.Sha256 != null && !actual.Equals(u.Sha256, StringComparison.OrdinalIgnoreCase))
        {
            File.Delete(tmp);
            throw new InvalidOperationException("Checksum mismatch - the update was discarded.");
        }
        if (PeReader.ReadMachine(tmp) != 0x8664) { File.Delete(tmp); throw new InvalidOperationException("The downloaded file isn't a 64-bit Windows exe - discarded."); }

        var old = exe + ".old";
        if (File.Exists(old)) File.Delete(old);
        File.Move(exe, old);           // allowed while running
        File.Move(tmp, exe);
        progress?.Report($"Installed {u.Tag}. Restarting…");
        return exe;
    }

    public static void Restart(string exe)
    {
        Process.Start(new ProcessStartInfo(exe) { UseShellExecute = true });
        System.Windows.Application.Current.Shutdown();
    }

    /// <summary>Removes the previous version left behind by an update.</summary>
    public static void CleanupOld()
    {
        try { var old = Environment.ProcessPath + ".old"; if (File.Exists(old)) File.Delete(old); } catch { }
    }
}
```

```cs
using System.Text;
using System.Windows;
using LegacyGameLauncher.Models;

namespace LegacyGameLauncher.Services;

/// <summary>Line-preserving INI editor (comments and ordering survive).</summary>
public sealed class IniDocument
{
    readonly List<string> _lines;
    public IniDocument(string text) => _lines = text.Replace("\r\n", "\n").Split('\n').ToList();
    public override string ToString() => string.Join("\r\n", _lines);

    /// <summary>Sets key in [section]; if not there, in any section that has it. Returns false if the key doesn't exist anywhere.</summary>
    public bool Set(string section, string key, string value)
    {
        int idx = Find(section, key);
        if (idx < 0) idx = Find(null, key);
        if (idx < 0) return false;
        var line = _lines[idx];
        int eq = line.IndexOf('=');
        _lines[idx] = line[..(eq + 1)] + " " + value;
        return true;
    }

    int Find(string? section, string key)
    {
        string? current = null;
        for (int i = 0; i < _lines.Count; i++)
        {
            var t = _lines[i].Trim();
            if (t.StartsWith('[') && t.EndsWith(']')) { current = t[1..^1].Trim(); continue; }
            if (t.StartsWith(';') || t.StartsWith('#')) continue;
            int eq = t.IndexOf('=');
            if (eq <= 0) continue;
            if (!t[..eq].Trim().Equals(key, StringComparison.OrdinalIgnoreCase)) continue;
            if (section == null || string.Equals(current, section, StringComparison.OrdinalIgnoreCase)) return i;
        }
        return -1;
    }
}

public sealed class WrapperSource
{
    /// <summary>(source path, file name to create in the game folder)</summary>
    public List<(string Source, string Name)> Files { get; } = new();
    public string? ConfigTemplate { get; set; }
    public string Description { get; set; } = "";
}

/// <summary>
/// Installs a user-downloaded dgVoodoo2 or DXVK d3d8.dll / d3d9.dll (matching the game's Direct3D version) into a game folder with backup/restore.
/// Picks the DLL that matches the GAME's architecture (x86 for these games), never the launcher's.
/// </summary>
public static class WrapperManager
{
    /// <summary>
    /// "d3d8" or "d3d9". The main exe decides when it names exactly one of them; folder DLLs
    /// (e.g. EAInstall.dll, which mentions both) are only a fallback. "d3d9" if still ambiguous.
    /// </summary>
    public static string GraphicsApi(GameScan scan, out bool certain)
    {
        var fromExe = GraphicsApi((ISet<string>)scan.ExeReferenced, out certain);
        return certain ? fromExe : GraphicsApi((ISet<string>)scan.Referenced, out certain);
    }

    public static string GraphicsApi(ISet<string> referenced, out bool certain)
    {
        bool d8 = referenced.Contains("d3d8.dll"), d9 = referenced.Contains("d3d9.dll");
        certain = d8 ^ d9;
        return d8 && !d9 ? "d3d8" : "d3d9";
    }

    static string FindDll(string kind, string folder, bool game32, string dll)
    {
        string[] candidates = kind switch
        {
            "dgVoodoo2" => game32
                ? new[] { $@"MS\x86\{dll}", $@"x86\{dll}", dll }
                : new[] { $@"MS\x64\{dll}", $@"x64\{dll}", dll },
            "DXVK" => game32 ? new[] { $@"x32\{dll}", dll } : new[] { $@"x64\{dll}", dll },
            _ => throw new InvalidOperationException("Choose dgVoodoo2 or DXVK."),
        };
        ushort want = game32 ? (ushort)0x014C : (ushort)0x8664;
        var wrongArch = new List<string>();
        foreach (var rel in candidates)
        {
            var p = Path.Combine(folder, rel);
            if (!File.Exists(p)) continue;
            var m = PeReader.ReadMachine(p);
            if (m == want) return p;
            wrongArch.Add($"{rel} is {(m == 0x8664 ? "x64" : m == 0x014C ? "x86" : "unknown")}");
        }
        var hint = kind == "dgVoodoo2" ? $@"Expected MS\{(game32 ? "x86" : "x64")}\{dll} inside the extracted dgVoodoo2 zip."
                 : dll.StartsWith("d3d8", StringComparison.OrdinalIgnoreCase) ? @"Direct3D 8 support needs DXVK 2.4 or newer (x32\d3d8.dll)."
                 : $@"Expected {(game32 ? "x32" : "x64")}\{dll} inside the extracted DXVK archive.";
        throw new InvalidOperationException($"No {(game32 ? "32-bit (x86)" : "64-bit")} {dll} found. {hint}" +
            (wrongArch.Count > 0 ? " Found but wrong architecture: " + string.Join(", ", wrongArch) : ""));
    }

    /// <summary>Finds the wrapper DLL(s) matching the game's Direct3D version AND architecture.</summary>
    public static WrapperSource Locate(string kind, string folder, bool game32, string api = "d3d9")
    {
        if (!Directory.Exists(folder)) throw new InvalidOperationException("Wrapper folder does not exist.");
        var src = new WrapperSource();
        var main = api == "d3d8" ? "d3d8.dll" : "d3d9.dll";
        src.Files.Add((FindDll(kind, folder, game32, main), main));
        // DXVK implements D3D8 on top of its own D3D9, so both DLLs must sit next to the game.
        if (kind == "DXVK" && api == "d3d8") src.Files.Add((FindDll(kind, folder, game32, "d3d9.dll"), "d3d9.dll"));
        if (kind == "dgVoodoo2")
            src.ConfigTemplate = new[] { "dgVoodoo.conf", @"..\..\dgVoodoo.conf", @"..\dgVoodoo.conf" }
                .Select(c => Path.GetFullPath(Path.Combine(Path.GetDirectoryName(src.Files[0].Source)!, c))).FirstOrDefault(File.Exists);
        src.Description = $"{kind} for Direct3D {(api == "d3d8" ? "8" : "9")} ({(game32 ? "x86" : "x64")}): " +
                          string.Join(" + ", src.Files.Select(f => Path.GetRelativePath(folder, f.Source)));
        return src;
    }

    /// <summary>Builds the config text. Returns notes about settings that couldn't be applied.</summary>
    public static (string Text, List<string> Notes) BuildConfig(string kind, WrapperSettings s, string? template)
    {
        var notes = new List<string>();
        if (kind == "DXVK")
        {
            var sb = new StringBuilder();
            sb.AppendLine("# Managed by Legacy Game Launcher - removed/restored automatically on uninstall.");
            sb.AppendLine($"d3d9.presentInterval = {(s.VSync ? 1 : 0)}");
            if (s.FpsLimit > 0) sb.AppendLine($"d3d9.maxFrameRate = {s.FpsLimit}");
            if (s.ForcedWidth > 0 || s.Windowed || s.Borderless || s.RefreshCap > 0)
                notes.Add("DXVK cannot force resolution, refresh rate or windowed mode - use dgVoodoo2 for those, or set them in the game's own config.");
            return (sb.ToString(), notes);
        }

        if (template == null)
        {
            notes.Add("No dgVoodoo.conf template found next to the dgVoodoo2 files, so dgVoodoo2 defaults will be used. " +
                      "Run dgVoodooCpl.exe once in the dgVoodoo2 folder to create one, then reinstall.");
            return ("", notes);
        }
        var ini = new IniDocument(File.ReadAllText(template));
        void Set(string sec, string key, string val, string what)
        {
            if (!ini.Set(sec, key, val)) notes.Add($"'{key}' not found in this dgVoodoo2 version's config - set {what} in dgVoodooCpl instead.");
        }
        bool windowed = s.Windowed || s.Borderless;
        Set("General", "FullScreenMode", windowed ? "false" : "true", "windowed mode");
        if (s.Borderless) Set("General", "WindowedAttributes", "borderless, fullscreensize", "borderless window");
        else ini.Set("General", "WindowedAttributes", "");
        if (s.ForcedWidth > 0 && s.ForcedHeight > 0)
            Set("DirectX", "Resolution", s.RefreshCap > 0 ? $"h:{s.ForcedWidth}, v:{s.ForcedHeight}, r:{s.RefreshCap}" : $"h:{s.ForcedWidth}, v:{s.ForcedHeight}", "the resolution");
        else
        {
            ini.Set("DirectX", "Resolution", "unforced");
            if (s.RefreshCap > 0)
                notes.Add("dgVoodoo2 applies a refresh-rate cap together with a forced resolution. Set a forced width/height to make the 60 Hz cap take effect " +
                          "(or set your desktop to 60 Hz).");
        }
        Set("DirectX", "ForceVerticalSync", s.VSync ? "true" : "false", "VSync");
        if (s.FpsLimit > 0) Set("GeneralExt", "FPSLimit", s.FpsLimit.ToString(), "the FPS limit");
        ini.Set("DirectX", "dgVoodooWatermark", "false");
        return (ini.ToString(), notes);
    }

    public static async Task<(bool Ok, string Log)> InstallAsync(GameEntry g, bool game32, string api, Window? owner)
    {
        var w = g.Wrapper;
        if (w.Installed && w.InstalledKind != w.Kind)
            return (false, $"{w.InstalledKind} is currently installed. Remove it first, then install {w.Kind}.");
        var src = Locate(w.Kind, w.SourceFolder, game32, api);
        var log = new List<string> { "Source: " + src.Description };
        var ops = new List<FileOp>();
        var recs = new List<ChangeRecord?>();

        foreach (var (source, name) in src.Files)
            recs.Add(ChangeJournal.PlanPlaceFile(g, "wrapper", source, Path.Combine(g.GameDir, name), ops, $"{w.Kind} {name}"));

        var confName = w.Kind == "DXVK" ? "dxvk.conf" : "dgVoodoo.conf";
        var (text, notes) = BuildConfig(w.Kind, w, src.ConfigTemplate);
        log.AddRange(notes.Select(n => "Note: " + n));
        if (text.Length > 0)
        {
            AppPaths.Ensure();
            var staged = Path.Combine(AppPaths.Staging, $"{Guid.NewGuid():N}-{confName}");
            File.WriteAllText(staged, text);
            recs.Add(ChangeJournal.PlanPlaceFile(g, "wrapper", staged, Path.Combine(g.GameDir, confName), ops, $"{w.Kind} {confName}"));
        }

        var dllNames = string.Join(" + ", src.Files.Select(f => f.Name));
        var (ok, err) = await FileOpRunner.RunAsync(ops, $"Install {w.Kind} ({dllNames} + {confName}) into the game folder.", owner);
        if (!ok) return (false, string.Join("\n", log.Append("FAILED: " + err)));
        foreach (var r in recs.Where(r => r != null)) g.Changes.Add(r!);
        w.Installed = true;
        w.InstalledKind = w.Kind;
        w.InstalledDlls = src.Files.Select(f => f.Name).ToList();
        log.Add($"Installed into {g.GameDir}. Originals (if any) are backed up under {AppPaths.Backups}.");
        if (w.Kind == "DXVK") log.Add("DXVK needs a Vulkan-capable GPU and driver.");
        return (true, string.Join("\n", log));
    }
}
```

## Why this exists

Games from 2006-2008 were written for Windows XP and Vista. On Windows 11 they tend to crash at start-up,
misread modern controllers, run at the wrong resolution, flicker on high-refresh monitors or fall over when you
alt-tab. The fixes are known - compatibility flags, a graphics wrapper, a DirectInput wrapper, the right config
tweak - but they're scattered across old forum threads and easy to get wrong.

Legacy Game Launcher puts them in one place: it **inspects the game**, tells you what's wrong, applies the fixes
**with a backup**, launches the game, and **reads the crash report** if it still fails. Everything it changes
can be undone with one click.

## Games it's built for

| | **EA Sports Cricket 07** | **EA Sports Rugby 08** |
|---|---|---|
| Developer / year | HB Studios / EA Canada, 2006 | HB Studios, 2007 |
| Executable | `Cricket07.exe` | `Rugby08.exe` |
| Graphics | Direct3D 8 | Direct3D 8 |
| Controller input | Legacy DirectInput 7 (`dinput.dll`) | Legacy DirectInput 7 (`dinput.dll`) |

Both share the same engine and the same Windows 11 problems, so the built-in profiles for them come with

**Other games:** add any 32-bit (or 64-bit) Windows game's `.exe`. The launcher detects its Direct3D version,
input API, runtimes and copy protection from the exe itself and offers the same tools. You can add your own

| Problem | Cause | Fix in the launcher |
|---|---|---|
| Crash a few seconds after start, crash report names **`DINPUT.dll`** | Old DirectInput 7 code trips over modern controllers / HID devices | **Fixes → dinputto8 → Download & apply** |
| **PS4 / PS5 pad**: pause does nothing, **right stick** (sidestep) doesn't work | DirectInput sees the PlayStation layout (right stick on Z/Rz, Options = button 10); these games expect the Xbox 360 layout | Run [DS4Windows](https://github.com/Ryochan7/DS4Windows) (Xbox 360 emulation) and hide the real pad with HidHide; check with **Controllers → Live tester** |

| Stuck at 1024×768 / wrong resolution | Resolution is stored in the binary `.pro` profile | **Game config → Scan**, then set the resolution (backed up first) |
| Crash on alt-tab, or you want windowed / borderless | Exclusive full-screen Direct3D 8 | **Fixes → dgVoodoo2**, tick *Windowed* / *Borderless* on the Graphics tab |
| Missing `d3dx9_xx.dll` / `xinput1_3.dll` etc. | June 2010 DirectX runtime not installed | **Overview → Legacy runtime dependencies** links to Microsoft's installer |
| "Please insert the correct disc", or the game exits silently | Copy protection - SafeDisc's driver is disabled on Windows 10/11 | Shown on **Overview → Copy protection**. The launcher explains it but **never bypasses it** |

## Safe by design

- **No copy-protection workarounds.** SafeDisc / SecuROM / StarForce are detected and explained, never patched,
  removed or bypassed. If a SafeDisc loader you installed yourself is present, the launcher only avoids breaking it.
- **No admin rights** for the launcher. When an action needs them (e.g. writing into `Program Files`) it asks for
  that one action, through a short-lived copy of itself that runs only the request fixed before the UAC prompt.
- **No Microsoft DLLs** are bundled or downloaded - it links to Microsoft's own installers.
- **Verified downloads** - fixes and updates come only from the projects' own GitHub releases and are checked
  against GitHub's SHA-256 before use.
- **No telemetry.** The only network calls are to `api.github.com` / `github.com` for update checks and fixes you
  choose to download.

## Updating

The launcher checks for a new release a moment after it starts. When one is available a banner appears in the
sidebar - press **Update now**. You can also press **Check for updates** at any time. What changed in each
version is in the release notes and in [CHANGELOG.md](CHANGELOG.md).

Put a `*.json` profile in `%LocalAppData%\LegacyGameLauncher\profiles\` (the built-in profiles are exported
there as `example-*.json.txt` to copy). A profile with the same `Id` as a built-in one replaces it. Add your exe's
SHA-256 (shown on the Overview tab) for an exact match. Pull requests with profiles for more games are welcome.
