# Fairplay Arena

![CI](https://github.com/fairplay/arena/actions/workflows/ci.yml/badge.svg)
![Coverage](https://img.shields.io/badge/coverage-%E2%89%A585%25-brightgreen)

Measured line coverage: **89.6%** (JaCoCo, `./mvnw verify`, 71 tests); the build fails below 85%.

Fairplay Arena is the stateless REST backend that stores the source of truth for the Fairplay anti-cheat platform: player accounts, match results, a Redis-backed global leaderboard, moderation actions (`FLAG`, `BAN`, `CLEAR`, `NOTE`) backed by an append-only PostgreSQL audit log, and ban appeals. It is a single Java 21 / Spring Boot 4.1 service backed by PostgreSQL 17 and Redis 7.

## Architecture

```text
  Players (HTTP) ─────────┐
  Moderators (HTTP) ──────┼──► Fairplay Arena (Spring Boot 4.1 / REST + JWT)
  Service clients (HTTP) ─┘         │                         │
                                    ▼                         ▼
                              PostgreSQL 17              Redis 7 (ZSET)
                         (source of truth,          (O(log N) leaderboard
                          append-only audit log)     & rank lookups)
```

## Design Decisions

- **Pure state machine (`AccountStateMachine`):** Keeping account transition rules in a dependency-free Java class allows exhaustive unit testing across all 35 `(action, status)` pairs without Spring or database overhead, while guaranteeing every status change goes through one contract.
- **Database-enforced audit log:** Flyway migration `V2__audit_log_append_only.sql` attaches a `BEFORE UPDATE OR DELETE` PostgreSQL trigger to `moderation_actions`, so even an application bug cannot rewrite or erase moderation history.
- **Confidence guardrail:** Automated `SERVICE` accounts (seeded as `judge-agent` and `telemetry-sim`) are blocked at the service layer from issuing `BAN` actions without a `confidence` score of at least `0.80` (`422 CONFIDENCE_REQUIRED` / `CONFIDENCE_TOO_LOW`), ensuring uncertain cases must be routed through `FLAG` or `NOTE` with `requiresHumanReview = true`.
- **Post-commit Redis sync & atomic rebuild:** Rating changes and ban removals publish Spring application events handled via `@TransactionalEventListener(phase = AFTER_COMMIT)`, preventing rolled-back transactions from leaking into Redis. On startup mismatches, `LeaderboardRebuilder` streams eligible players via keyset pagination into a temporary ZSET and swaps it with `RENAME`.
- **Ordered pessimistic locking for matches:** `POST /matches` sorts participant UUIDs before issuing `SELECT ... FOR UPDATE` (`ORDER BY id`), eliminating deadlocks when concurrent matches share overlapping players, while `externalId` uniqueness makes retries idempotent (`200 OK`).
- **Refresh-token reuse detection:** Refresh tokens are stored as SHA-256 hashes and rotated on each use. Presenting an already-revoked token triggers `REQUIRES_NEW` revocation of all active refresh tokens for that player and returns `401 REFRESH_TOKEN_REUSED`.

## Benchmark

Method (`benchmark/rank-lookup.js`):
1. Seed 1,000,000 players (`scripts/seed-1m-players.sql`) with ratings distributed across 500..2499 (~500 ties per rating) and restart Arena so `LeaderboardRebuilder` populates Redis.
2. Export 10,000 sampled player IDs to `benchmark/player-ids.json`.
3. Run `k6 run -e SOURCE=db benchmark/rank-lookup.js` and `k6 run -e SOURCE=redis benchmark/rank-lookup.js` (15s warmup at 50 VUs, 60s measure at 200 VUs), three times each, reporting the last run alongside `arena_leaderboard_rank_lookup_seconds` from `/actuator/prometheus`.

| Source | p50 | p95 | p99 | Throughput | Notes |
| --- | --- | --- | --- | --- | --- |
| `db` (PostgreSQL `COUNT(*) + 1`) | 15.62 s | 18.01 s | 29.39 s | 12.6 req/s | 2 of 1,127 requests failed (0.17%) |
| `redis` (`ZREVRANK`) | 33.07 ms | 63.53 ms | 90.21 ms | 5,764 req/s | 0 of 432,474 requests failed |

k6 `{phase:measure}` results (200 VUs for 60 s, after a 15 s warm-up at 50 VUs). Each source was run three times; the table shows the third run, because the full summaries of the first two runs were not captured. The Redis path was about 280x faster at p95 and served about 460x the throughput of the DB path. The `db` run misses the script's 2 s p95 sanity threshold, as expected for a `COUNT(*)` over 1,000,000 rows.

Server-side cross-check (`arena_leaderboard_rank_lookup_seconds`, cumulative over all runs on this stack, histogram upper bounds):

| Source | Requests | Mean | p50 | p95 | p99 |
| --- | --- | --- | --- | --- | --- |
| `db` | 3,466 | 1.54 s | <= 1.79 s | <= 2.51 s | <= 2.86 s |
| `redis` | 1,249,847 | 2.9 ms | <= 2.8 ms | <= 5.6 ms | <= 8.4 ms |

The server-side `db` time (about 1.5 s) is far below the k6 latency (about 15 s). The timer starts after the transaction has acquired its connection, so it excludes time spent waiting for one of the 20 Hikari connections while 200 virtual users compete for them. k6 includes that queueing plus network and HTTP overhead.

**Environment:** AMD Ryzen 5 3600 (6 cores / 12 threads), 15.9 GB RAM, Windows 11, Docker Desktop 29.7.2 with 12 vCPUs and 8 GB RAM available to the engine and no per-container limits. Arena, PostgreSQL 17 (default configuration), Redis 7 and the k6 container (`grafana/k6`, run on the compose network) all shared that one Docker VM, so the load generator competed with the services for CPU. The dataset was 1,000,001 players (1,000,000 seeded plus one smoke-test account) across 2,000 distinct ratings. Redis was rebuilt from PostgreSQL at startup in 22.6 s.

## What I'd Do Next

- Add per-IP and per-account rate limiting on authentication and appeal endpoints.
- Replace in-memory post-commit Redis event listeners with a transactional outbox table for guaranteed delivery across crashes.
- Publish moderation and match domain events to a message broker such as Kafka, so other services can consume them instead of polling the API.

```
# hash string like Java String::hashCode
hash_string() {
  str="${1:-}" h=0

    char="${str%"${str#?}"}"

    str="${str#?}"

'') MVNW_USERNAME='' MVNW_PASSWORD='' ;;
has-password) [ -n "${MVNW_USERNAME-}" ] || MVNW_USERNAME='' MVNW_PASSWORD='' ;;
esac

  verbose "Found wget ... using wget"
  wget ${__MVNW_QUIET_WGET:+"$__MVNW_QUIET_WGET"} "$distributionUrl" -O "$TMP_DOWNLOAD_DIR/$distributionUrlName" || die "wget: Failed to fetch $distributionUrl"

  curl ${__MVNW_QUIET_CURL:+"$__MVNW_QUIET_CURL"} -f -L -o "$TMP_DOWNLOAD_DIR/$distributionUrlName" "$distributionUrl" || die "curl: Failed to fetch $distributionUrl"

  verbose "Falling back to use Java to download"
  javaSource="$TMP_DOWNLOAD_DIR/Downloader.java"
  targetZip="$TMP_DOWNLOAD_DIR/$distributionUrlName"
  cat >"$javaSource" <<-END
	public class Downloader extends java.net.Authenticator
	{
	  protected java.net.PasswordAuthentication getPasswordAuthentication()
	  {
	    return new java.net.PasswordAuthentication( System.getenv( "MVNW_USERNAME" ), System.getenv( "MVNW_PASSWORD" ).toCharArray() );
	  }
	  public static void main( String[] args ) throws Exception
	  {
	    setDefault( new Downloader() );
	    java.nio.file.Files.copy( java.net.URI.create( args[0] ).toURL().openStream(), java.nio.file.Paths.get( args[1] ).toAbsolutePath().normalize() );
	  }
	}
	END
  # For Cygwin/MinGW, switch paths to Windows format before running javac and java
  verbose " - Compiling Downloader.java ..."
  "$(native_path "$JAVACCMD")" "$(native_path "$javaSource")" || die "Failed to compile Downloader.java"
  verbose " - Running Downloader.java ..."
  "$(native_path "$JAVACMD")" -cp "$(native_path "$TMP_DOWNLOAD_DIR")" Downloader "$distributionUrl" "$(native_path "$targetZip")"
fi

# If specified, validate the SHA-256 sum of the Maven distribution zip file
if [ -n "${distributionSha256Sum-}" ]; then
  distributionSha256Result=false
  if [ "$MVN_CMD" = mvnd.sh ]; then
    echo "Checksum validation is not supported for maven-mvnd." >&2
    echo "Please disable validation by removing 'distributionSha256Sum' from your maven-wrapper.properties." >&2
    exit 1
  elif command -v sha256sum >/dev/null; then
    if echo "$distributionSha256Sum  $TMP_DOWNLOAD_DIR/$distributionUrlName" | sha256sum -c - >/dev/null 2>&1; then
      distributionSha256Result=true
    fi
  elif command -v shasum >/dev/null; then
    if echo "$distributionSha256Sum  $TMP_DOWNLOAD_DIR/$distributionUrlName" | shasum -a 256 -c >/dev/null 2>&1; then
      distributionSha256Result=true
    fi
  else
    echo "Checksum validation was requested but neither 'sha256sum' or 'shasum' are available." >&2
    echo "Please install either command, or disable validation by removing 'distributionSha256Sum' from your maven-wrapper.properties." >&2
    exit 1
  fi
  if [ $distributionSha256Result = false ]; then
    echo "Error: Failed to validate Maven distribution SHA-256, your Maven distribution might be compromised." >&2
    echo "If you updated your Maven version, you need to update the specified distributionSha256Sum property." >&2
    exit 1
  fi
fi

# unzip and move
if command -v unzip >/dev/null; then
  unzip ${__MVNW_QUIET_UNZIP:+"$__MVNW_QUIET_UNZIP"} "$TMP_DOWNLOAD_DIR/$distributionUrlName" -d "$TMP_DOWNLOAD_DIR" || die "failed to unzip"
else
  tar xzf${__MVNW_QUIET_TAR:+"$__MVNW_QUIET_TAR"} "$TMP_DOWNLOAD_DIR/$distributionUrlName" -C "$TMP_DOWNLOAD_DIR" || die "failed to untar"
fi

# Find the actual extracted directory name (handles snapshots where filename != directory name)
actualDistributionDir=""

# First try the expected directory name (for regular distributions)
if [ -d "$TMP_DOWNLOAD_DIR/$distributionUrlNameMain" ]; then
  if [ -f "$TMP_DOWNLOAD_DIR/$distributionUrlNameMain/bin/$MVN_CMD" ]; then
    actualDistributionDir="$distributionUrlNameMain"
  fi
fi

# If not found, search for any directory with the Maven executable (for snapshots)
if [ -z "$actualDistributionDir" ]; then
  # enable globbing to iterate over items
  set +f
  for dir in "$TMP_DOWNLOAD_DIR"/*; do
    if [ -d "$dir" ]; then
      if [ -f "$dir/bin/$MVN_CMD" ]; then
        actualDistributionDir="$(basename "$dir")"
        break
      fi
    fi
  done
  set -f
fi

if [ -z "$actualDistributionDir" ]; then
  verbose "Contents of $TMP_DOWNLOAD_DIR:"
  verbose "$(ls -la "$TMP_DOWNLOAD_DIR")"
  die "Could not find Maven distribution directory in extracted archive"
fi

verbose "Found extracted Maven distribution directory: $actualDistributionDir"
printf %s\\n "$distributionUrl" >"$TMP_DOWNLOAD_DIR/$actualDistributionDir/mvnw.url"
mv -- "$TMP_DOWNLOAD_DIR/$actualDistributionDir" "$MAVEN_HOME" || [ -d "$MAVEN_HOME" ] || die "fail to move MAVEN_HOME"

clean || :
exec_maven "$@"
```

```java
package dev.fairplay.arena.appeal;

import dev.fairplay.arena.moderation.ModerationAction;
import dev.fairplay.arena.player.Player;
import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.EnumType;
import jakarta.persistence.Enumerated;
import jakarta.persistence.FetchType;
import jakarta.persistence.Id;
import jakarta.persistence.JoinColumn;
import jakarta.persistence.ManyToOne;
import jakarta.persistence.Table;
import jakarta.persistence.Version;
import lombok.AccessLevel;
import lombok.Getter;
import lombok.NoArgsConstructor;
import lombok.Setter;

import java.time.Instant;
import java.util.UUID;

@Entity
@Table(name = "appeals")
@Getter
@Setter
@NoArgsConstructor(access = AccessLevel.PROTECTED)
public class Appeal {

    @Id
    private UUID id;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "player_id", nullable = false)
    private Player player;

    @ManyToOne(fetch = FetchType.LAZY, optional = false)
    @JoinColumn(name = "ban_action_id", nullable = false, unique = true)
    private ModerationAction banAction;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 16)
    private AppealStatus status;

    @Column(nullable = false, length = 2000)
    private String statement;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "decided_by")
    private Player decidedBy;

    @Column(name = "decision_note", length = 1000)
    private String decisionNote;

    @Column(name = "created_at", nullable = false)
    private Instant createdAt;

    @Column(name = "decided_at")
    private Instant decidedAt;

    @Version
    @Column(nullable = false)
    private Long version;

    public Appeal(
            UUID id,
            Player player,
            ModerationAction banAction,
            AppealStatus status,
            String statement,
            Instant createdAt) {
        this.id = id;
        this.player = player;
        this.banAction = banAction;
        this.status = status;
        this.statement = statement;
        this.createdAt = createdAt;
    }
}
```

```java
package dev.fairplay.arena.appeal;

import dev.fairplay.arena.appeal.dto.AppealResponse;
import dev.fairplay.arena.appeal.dto.DecideAppealRequest;
import dev.fairplay.arena.appeal.dto.SubmitAppealRequest;
import dev.fairplay.arena.common.error.ApiException;
import dev.fairplay.arena.common.error.ErrorCode;
import dev.fairplay.arena.common.web.PageResponse;
import dev.fairplay.arena.leaderboard.LeaderboardEvents.RatingChanged;
import dev.fairplay.arena.moderation.AccountStateMachine;
import dev.fairplay.arena.moderation.AccountStatus;
import dev.fairplay.arena.moderation.ActionSource;
import dev.fairplay.arena.moderation.ModerationAction;
import dev.fairplay.arena.moderation.ModerationActionRepository;
import dev.fairplay.arena.moderation.ModerationActionType;
import dev.fairplay.arena.player.Player;
import dev.fairplay.arena.player.PlayerRepository;
import io.micrometer.core.instrument.MeterRegistry;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.ApplicationEventPublisher;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.PageRequest;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.Clock;
import java.time.Instant;
import java.util.UUID;

@Slf4j
@Service
public class AppealService {

    private final AccountStateMachine stateMachine = new AccountStateMachine();
    private final AppealRepository appealRepository;
    private final PlayerRepository playerRepository;
    private final ModerationActionRepository moderationActionRepository;
    private final ApplicationEventPublisher eventPublisher;
    private final Clock clock;
    private final MeterRegistry meterRegistry;

    public AppealService(
            AppealRepository appealRepository,
            PlayerRepository playerRepository,
            ModerationActionRepository moderationActionRepository,
            ApplicationEventPublisher eventPublisher,
            Clock clock,
            MeterRegistry meterRegistry) {
        this.appealRepository = appealRepository;
        this.playerRepository = playerRepository;
        this.moderationActionRepository = moderationActionRepository;
        this.eventPublisher = eventPublisher;
        this.clock = clock;
        this.meterRegistry = meterRegistry;
    }

    @Transactional
    public AppealResponse submitAppeal(UUID playerId, SubmitAppealRequest request) {
        Player player = playerRepository.findById(playerId)
                .orElseThrow(() -> new ApiException(ErrorCode.PLAYER_NOT_FOUND, "Player not found: " + playerId));

        if (player.getStatus() != AccountStatus.BANNED) {
            throw new ApiException(ErrorCode.APPEAL_NOT_ALLOWED, "Only BANNED players may submit an appeal");
        }

        ModerationAction banAction = moderationActionRepository
                .findFirstByPlayerIdAndActionOrderByCreatedAtDesc(playerId, ModerationActionType.BAN)
                .orElseThrow(() -> new ApiException(ErrorCode.APPEAL_NOT_ALLOWED, "No ban action found for player"));

        if (appealRepository.existsByBanActionId(banAction.getId())) {
            throw new ApiException(ErrorCode.APPEAL_ALREADY_EXISTS, "This ban has already been appealed");
        }

        Instant now = Instant.now(clock);
        AccountStatus from = player.getStatus();
        AccountStatus to = stateMachine.next(from, ModerationActionType.APPEAL_SUBMITTED);

        Appeal appeal = appealRepository.save(new Appeal(
                UUID.randomUUID(),
                player,
                banAction,
                AppealStatus.PENDING,
                request.statement(),
                now));

        player.setStatus(to);
        player.setStatusChangedAt(now);
        player.setUpdatedAt(now);

        moderationActionRepository.save(new ModerationAction(
                UUID.randomUUID(),
                player,
                ModerationActionType.APPEAL_SUBMITTED,
                from,
                to,
                player,
                ActionSource.HUMAN,
                "Appeal submitted",
                null,
                null,
                false,
                now));

        meterRegistry.counter(
                "arena.moderation.actions",
                "action", ModerationActionType.APPEAL_SUBMITTED.name(),
                "source", ActionSource.HUMAN.name()).increment();

        log.info("Moderation action {} on player {} ({} -> {}) source={} actor={}",
                ModerationActionType.APPEAL_SUBMITTED, player.getId(), from, to, ActionSource.HUMAN, player.getUsername());

        return toResponse(appeal);
    }

    @Transactional(readOnly = true)
    public PageResponse<AppealResponse> listAppeals(AppealStatus status, int page, int size) {
        Page<AppealResponse> results = appealRepository
                .findByStatusOrderByCreatedAtAsc(status, PageRequest.of(page, size))
                .map(AppealService::toResponse);
        return PageResponse.from(results);
    }

    @Transactional
    public AppealResponse decideAppeal(UUID appealId, DecideAppealRequest request, UUID moderatorId) {
        Appeal appeal = appealRepository.findByIdWithDetails(appealId)
                .orElseThrow(() -> new ApiException(ErrorCode.APPEAL_NOT_FOUND, "Appeal not found: " + appealId));

        if (appeal.getStatus() != AppealStatus.PENDING) {
            throw new ApiException(ErrorCode.APPEAL_ALREADY_DECIDED, "Appeal has already been decided");
        }

        Player moderator = playerRepository.findById(moderatorId)
                .orElseThrow(() -> new ApiException(ErrorCode.UNAUTHENTICATED, "Moderator not found"));
        Player player = appeal.getPlayer();

        Instant now = Instant.now(clock);
        AppealStatus newAppealStatus = request.decision() == AppealDecision.UPHOLD
                ? AppealStatus.UPHELD
                : AppealStatus.OVERTURNED;
        ModerationActionType actionType = request.decision() == AppealDecision.UPHOLD
                ? ModerationActionType.APPEAL_UPHELD
                : ModerationActionType.APPEAL_OVERTURNED;

        AccountStatus from = player.getStatus();
        AccountStatus to = stateMachine.next(from, actionType);

        appeal.setStatus(newAppealStatus);
        appeal.setDecidedBy(moderator);
        appeal.setDecisionNote(request.note());
        appeal.setDecidedAt(now);

        player.setStatus(to);
        player.setStatusChangedAt(now);
        player.setUpdatedAt(now);

        moderationActionRepository.save(new ModerationAction(
                UUID.randomUUID(),
                player,
                actionType,
                from,
                to,
                moderator,
                ActionSource.HUMAN,
                request.note(),
                null,
                null,
                false,
                now));

        if (to == AccountStatus.REINSTATED) {
            eventPublisher.publishEvent(new RatingChanged(player.getId(), player.getRating()));
        }

        meterRegistry.counter(
                "arena.moderation.actions",
                "action", actionType.name(),
                "source", ActionSource.HUMAN.name()).increment();
        meterRegistry.counter(
                "arena.appeals.decided",
                "decision", request.decision().name()).increment();

        log.info("Moderation action {} on player {} ({} -> {}) source={} actor={}",
                actionType, player.getId(), from, to, ActionSource.HUMAN, moderator.getUsername());

        return toResponse(appeal);
    }

    private static AppealResponse toResponse(Appeal appeal) {
        return new AppealResponse(
                appeal.getId(),
                appeal.getPlayer().getId(),
                appeal.getPlayer().getUsername(),
                appeal.getBanAction().getId(),
                appeal.getStatus(),
                appeal.getStatement(),
                appeal.getCreatedAt(),
                appeal.getDecidedBy() != null ? appeal.getDecidedBy().getId() : null,
                appeal.getDecisionNote(),
                appeal.getDecidedAt());
    }
}
```

```java
package dev.fairplay.arena.auth;

import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.moderation.AccountStatus;
import dev.fairplay.arena.player.Player;
import dev.fairplay.arena.player.PlayerRepository;
import dev.fairplay.arena.player.Role;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

import java.time.Clock;
import java.time.Instant;
import java.util.UUID;

@Component
public class AccountSeeder implements ApplicationRunner {

    private final PlayerRepository playerRepository;
    private final PasswordEncoder passwordEncoder;
    private final ArenaProperties props;
    private final Clock clock;

    public AccountSeeder(
            PlayerRepository playerRepository,
            PasswordEncoder passwordEncoder,
            ArenaProperties props,
            Clock clock) {
        this.playerRepository = playerRepository;
        this.passwordEncoder = passwordEncoder;
        this.props = props;
        this.clock = clock;
    }

    @Override
    @Transactional
    public void run(ApplicationArguments args) {
        ArenaProperties.AccountCredential mod = props.accounts().moderator();
        seedIfMissing(mod.username(), mod.password(), Role.MODERATOR);
        for (ArenaProperties.AccountCredential service : props.accounts().services()) {
            seedIfMissing(service.username(), service.password(), Role.SERVICE);
        }
    }

    private void seedIfMissing(String username, String rawPassword, Role role) {
        if (playerRepository.existsByUsernameIgnoreCase(username)) {
            return;
        }
        Instant now = Instant.now(clock);
        Player account = new Player(
                UUID.randomUUID(),
                username,
                username + "@fairplay.local",
                passwordEncoder.encode(rawPassword),
                role,
                AccountStatus.ACTIVE,
                null,
                null,
                0,
                now);
        playerRepository.save(account);
    }
}
```

```java
package dev.fairplay.arena.auth;

import dev.fairplay.arena.auth.dto.LoginRequest;
import dev.fairplay.arena.auth.dto.RefreshRequest;
import dev.fairplay.arena.auth.dto.RegisterRequest;
import dev.fairplay.arena.auth.dto.TokenResponse;
import dev.fairplay.arena.common.error.ApiException;
import dev.fairplay.arena.common.error.ErrorCode;
import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.leaderboard.LeaderboardEvents.RatingChanged;
import dev.fairplay.arena.moderation.AccountStatus;
import dev.fairplay.arena.player.Player;
import dev.fairplay.arena.player.PlayerRepository;
import dev.fairplay.arena.player.PlayerService;
import dev.fairplay.arena.player.Role;
import dev.fairplay.arena.player.dto.PlayerDetailResponse;
import org.springframework.context.ApplicationEventPublisher;
import org.springframework.security.crypto.password.PasswordEncoder;
import org.springframework.stereotype.Service;
import org.springframework.transaction.PlatformTransactionManager;
import org.springframework.transaction.TransactionDefinition;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.transaction.support.TransactionTemplate;

import java.time.Clock;
import java.time.Instant;
import java.util.UUID;

@Service
public class AuthService {

    private final PlayerRepository playerRepository;
    private final RefreshTokenRepository refreshTokenRepository;
    private final PasswordEncoder passwordEncoder;
    private final TokenService tokenService;
    private final PlayerService playerService;
    private final ApplicationEventPublisher eventPublisher;
    private final ArenaProperties props;
    private final Clock clock;
    private final TransactionTemplate requiresNewTx;

    public AuthService(
            PlayerRepository playerRepository,
            RefreshTokenRepository refreshTokenRepository,
            PasswordEncoder passwordEncoder,
            TokenService tokenService,
            PlayerService playerService,
            ApplicationEventPublisher eventPublisher,
            ArenaProperties props,
            Clock clock,
            PlatformTransactionManager txManager) {
        this.playerRepository = playerRepository;
        this.refreshTokenRepository = refreshTokenRepository;
        this.passwordEncoder = passwordEncoder;
        this.tokenService = tokenService;
        this.playerService = playerService;
        this.eventPublisher = eventPublisher;
        this.props = props;
        this.clock = clock;
        this.requiresNewTx = new TransactionTemplate(txManager);
        this.requiresNewTx.setPropagationBehavior(TransactionDefinition.PROPAGATION_REQUIRES_NEW);
    }

    @Transactional
    public PlayerDetailResponse register(RegisterRequest request) {
        if (playerRepository.existsByUsernameIgnoreCase(request.username())) {
            throw new ApiException(ErrorCode.USERNAME_TAKEN, "Username is already taken");
        }
        if (playerRepository.existsByEmailIgnoreCase(request.email())) {
            throw new ApiException(ErrorCode.EMAIL_TAKEN, "Email is already taken");
        }
        Instant now = Instant.now(clock);
        Player player = new Player(
                UUID.randomUUID(),
                request.username(),
                request.email(),
                passwordEncoder.encode(request.password()),
                Role.PLAYER,
                AccountStatus.ACTIVE,
                request.displayName(),
                request.country(),
                props.rating().initial(),
                now);
        playerRepository.saveAndFlush(player);
        eventPublisher.publishEvent(new RatingChanged(player.getId(), player.getRating()));
        return playerService.toDetail(player, true);
    }

    @Transactional
    public TokenResponse login(LoginRequest request) {
        Player player = playerRepository.findByUsernameIgnoreCase(request.username())
                .orElseThrow(() -> new ApiException(ErrorCode.INVALID_CREDENTIALS, "Invalid username or password"));
        if (!passwordEncoder.matches(request.password(), player.getPasswordHash())) {
            throw new ApiException(ErrorCode.INVALID_CREDENTIALS, "Invalid username or password");
        }
        return issueTokenPair(player);
    }

    @Transactional
    public TokenResponse refresh(RefreshRequest request) {
        String hash = tokenService.hashRefreshToken(request.refreshToken());
        RefreshToken existing = refreshTokenRepository.findByTokenHash(hash)
                .orElseThrow(() -> new ApiException(ErrorCode.INVALID_REFRESH_TOKEN, "Invalid refresh token"));

        Instant now = Instant.now(clock);
        // Expiry is checked before reuse: an expired token is a plain INVALID_REFRESH_TOKEN and must
        // not trigger the mass revocation that a replayed (revoked but unexpired) token does.
        if (!existing.getExpiresAt().isAfter(now)) {
            throw new ApiException(ErrorCode.INVALID_REFRESH_TOKEN, "Refresh token expired");
        }
        if (existing.getRevokedAt() != null) {
            UUID playerId = existing.getPlayer().getId();
            requiresNewTx.executeWithoutResult(status ->
                    refreshTokenRepository.revokeAllActiveForPlayer(playerId, now));
            throw new ApiException(ErrorCode.REFRESH_TOKEN_REUSED, "Refresh token was already used");
        }

        UUID replacementId = UUID.randomUUID();
        String newRawRefresh = tokenService.generateRefreshToken();
        Instant refreshExpiresAt = tokenService.refreshTokenExpiresAt();
        RefreshToken replacement = new RefreshToken(
                replacementId,
                existing.getPlayer(),
                tokenService.hashRefreshToken(newRawRefresh),
                refreshExpiresAt,
                now);
        refreshTokenRepository.save(replacement);

        existing.setRevokedAt(now);
        existing.setReplacedBy(replacementId);

        TokenService.AccessToken accessToken = tokenService.issueAccessToken(existing.getPlayer());
        return new TokenResponse(
                "Bearer",
                accessToken.value(),
                accessToken.expiresAt(),
                newRawRefresh,
                refreshExpiresAt);
    }

    private TokenResponse issueTokenPair(Player player) {
        Instant now = Instant.now(clock);
        String rawRefresh = tokenService.generateRefreshToken();
        Instant refreshExpiresAt = tokenService.refreshTokenExpiresAt();
        RefreshToken refreshToken = new RefreshToken(
                UUID.randomUUID(),
                player,
                tokenService.hashRefreshToken(rawRefresh),
                refreshExpiresAt,
                now);
        refreshTokenRepository.save(refreshToken);

        TokenService.AccessToken accessToken = tokenService.issueAccessToken(player);
        return new TokenResponse(
                "Bearer",
                accessToken.value(),
                accessToken.expiresAt(),
                rawRefresh,
                refreshExpiresAt);
    }
}
```

```java
package dev.fairplay.arena.auth;

import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.player.Player;
import org.springframework.security.oauth2.jose.jws.MacAlgorithm;
import org.springframework.security.oauth2.jwt.JwsHeader;
import org.springframework.security.oauth2.jwt.JwtClaimsSet;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtEncoderParameters;
import org.springframework.stereotype.Service;

import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.security.SecureRandom;
import java.time.Clock;
import java.time.Instant;
import java.util.Base64;
import java.util.HexFormat;
import java.util.List;

@Service
public class TokenService {

    public record AccessToken(String value, Instant expiresAt) {}

    private static final SecureRandom SECURE_RANDOM = new SecureRandom();
    private static final Base64.Encoder BASE64_URL = Base64.getUrlEncoder().withoutPadding();

    private final JwtEncoder jwtEncoder;
    private final ArenaProperties props;
    private final Clock clock;

    public TokenService(JwtEncoder jwtEncoder, ArenaProperties props, Clock clock) {
        this.jwtEncoder = jwtEncoder;
        this.props = props;
        this.clock = clock;
    }

    public AccessToken issueAccessToken(Player player) {
        Instant now = Instant.now(clock);
        Instant expiresAt = now.plus(props.jwt().accessTokenTtl());
        JwtClaimsSet claims = JwtClaimsSet.builder()
                .issuer(props.jwt().issuer())
                .subject(player.getId().toString())
                .issuedAt(now)
                .expiresAt(expiresAt)
                .claim("username", player.getUsername())
                .claim("roles", List.of(player.getRole().name()))
                .claim("typ", "access")
                .build();
        JwsHeader header = JwsHeader.with(MacAlgorithm.HS256).build();
        String token = jwtEncoder.encode(JwtEncoderParameters.from(header, claims)).getTokenValue();
        return new AccessToken(token, expiresAt);
    }

    public String generateRefreshToken() {
        byte[] bytes = new byte[32];
        SECURE_RANDOM.nextBytes(bytes);
        return BASE64_URL.encodeToString(bytes);
    }

    public Instant refreshTokenExpiresAt() {
        return Instant.now(clock).plus(props.jwt().refreshTokenTtl());
    }

    public String hashRefreshToken(String rawToken) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            byte[] hashed = digest.digest(rawToken.getBytes(StandardCharsets.UTF_8));
            return HexFormat.of().formatHex(hashed);
        } catch (NoSuchAlgorithmException e) {
            throw new IllegalStateException("SHA-256 unavailable", e);
        }
    }
}
```

```java
package dev.fairplay.arena.common.error;

import jakarta.servlet.http.HttpServletRequest;
import jakarta.validation.ConstraintViolationException;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.TypeMismatchException;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.http.HttpHeaders;
import org.springframework.http.HttpStatusCode;
import org.springframework.http.MediaType;
import org.springframework.http.ProblemDetail;
import org.springframework.http.ResponseEntity;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.orm.ObjectOptimisticLockingFailureException;
import org.springframework.security.access.AccessDeniedException;
import org.springframework.web.HttpRequestMethodNotSupportedException;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.MissingServletRequestParameterException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;
import org.springframework.web.context.request.ServletWebRequest;
import org.springframework.web.context.request.WebRequest;
import org.springframework.web.method.annotation.HandlerMethodValidationException;
import org.springframework.web.servlet.mvc.method.annotation.ResponseEntityExceptionHandler;
import org.springframework.web.servlet.resource.NoResourceFoundException;

import java.net.URI;
import java.util.ArrayList;
import java.util.List;

@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler extends ResponseEntityExceptionHandler {

    private static final MediaType PROBLEM_JSON = MediaType.APPLICATION_PROBLEM_JSON;

    public record ValidationError(String field, String message) {}

    @ExceptionHandler(ApiException.class)
    ResponseEntity<ProblemDetail> handleApiException(ApiException ex, HttpServletRequest request) {
        ProblemDetail problem = buildProblem(ex.getErrorCode(), ex.getMessage(), request.getRequestURI());
        return ResponseEntity.status(ex.getErrorCode().getStatus())
                .contentType(PROBLEM_JSON)
                .body(problem);
    }

    @ExceptionHandler(AccessDeniedException.class)
    ResponseEntity<ProblemDetail> handleAccessDenied(AccessDeniedException ex, HttpServletRequest request) {
        ProblemDetail problem = buildProblem(ErrorCode.FORBIDDEN, "Access is denied", request.getRequestURI());
        return ResponseEntity.status(ErrorCode.FORBIDDEN.getStatus())
                .contentType(PROBLEM_JSON)
                .body(problem);
    }

    @ExceptionHandler(ConstraintViolationException.class)
    ResponseEntity<ProblemDetail> handleConstraintViolation(ConstraintViolationException ex, HttpServletRequest request) {
        List<ValidationError> errors = ex.getConstraintViolations().stream()
                .map(v -> {
                    String path = v.getPropertyPath().toString();
                    int dot = path.lastIndexOf('.');
                    String field = dot >= 0 ? path.substring(dot + 1) : path;
                    return new ValidationError(field, v.getMessage());
                })
                .toList();
        ProblemDetail problem = buildProblem(ErrorCode.VALIDATION_FAILED, "Request validation failed", request.getRequestURI());
        problem.setProperty("errors", errors);
        return ResponseEntity.badRequest().contentType(PROBLEM_JSON).body(problem);
    }

    @ExceptionHandler(ObjectOptimisticLockingFailureException.class)
    ResponseEntity<ProblemDetail> handleOptimisticLock(ObjectOptimisticLockingFailureException ex, HttpServletRequest request) {
        ProblemDetail problem = buildProblem(
                ErrorCode.CONCURRENT_MODIFICATION,
                "Resource was modified concurrently; please retry",
                request.getRequestURI());
        return ResponseEntity.status(ErrorCode.CONCURRENT_MODIFICATION.getStatus())
                .contentType(PROBLEM_JSON)
                .body(problem);
    }

    @ExceptionHandler(DataIntegrityViolationException.class)
    ResponseEntity<ProblemDetail> handleDataIntegrity(DataIntegrityViolationException ex, HttpServletRequest request) {
        String message = ex.getMostSpecificCause() != null ? ex.getMostSpecificCause().getMessage() : ex.getMessage();
        if (message != null && message.contains("ux_players_username_lower")) {
            ProblemDetail problem = buildProblem(ErrorCode.USERNAME_TAKEN, "Username is already taken", request.getRequestURI());
            return ResponseEntity.status(ErrorCode.USERNAME_TAKEN.getStatus()).contentType(PROBLEM_JSON).body(problem);
        }
        if (message != null && message.contains("ux_players_email_lower")) {
            ProblemDetail problem = buildProblem(ErrorCode.EMAIL_TAKEN, "Email is already taken", request.getRequestURI());
            return ResponseEntity.status(ErrorCode.EMAIL_TAKEN.getStatus()).contentType(PROBLEM_JSON).body(problem);
        }
        log.error("Unexpected data integrity violation", ex);
        ProblemDetail problem = buildProblem(ErrorCode.INTERNAL_ERROR, "Unexpected error", request.getRequestURI());
        return ResponseEntity.internalServerError().contentType(PROBLEM_JSON).body(problem);
    }

    @ExceptionHandler(Exception.class)
    ResponseEntity<ProblemDetail> handleUnexpected(Exception ex, HttpServletRequest request) {
        log.error("Unhandled exception", ex);
        ProblemDetail problem = buildProblem(ErrorCode.INTERNAL_ERROR, "Unexpected error", request.getRequestURI());
        return ResponseEntity.internalServerError().contentType(PROBLEM_JSON).body(problem);
    }

    @Override
    protected ResponseEntity<Object> handleMethodArgumentNotValid(
            MethodArgumentNotValidException ex,
            HttpHeaders headers,
            HttpStatusCode status,
            WebRequest request) {
        List<ValidationError> errors = new ArrayList<>();
        ex.getBindingResult().getFieldErrors()
                .forEach(err -> errors.add(new ValidationError(err.getField(), err.getDefaultMessage())));
        ex.getBindingResult().getGlobalErrors()
                .forEach(err -> errors.add(new ValidationError(err.getObjectName(), err.getDefaultMessage())));
        ProblemDetail problem = buildProblem(ErrorCode.VALIDATION_FAILED, "Request validation failed", extractUri(request));
        problem.setProperty("errors", errors);
        return ResponseEntity.badRequest().contentType(PROBLEM_JSON).body(problem);
    }

    @Override
    protected ResponseEntity<Object> handleHandlerMethodValidationException(
            HandlerMethodValidationException ex,
            HttpHeaders headers,
            HttpStatusCode status,
            WebRequest request) {
        List<ValidationError> errors = new ArrayList<>();
        ex.getParameterValidationResults().forEach(result -> {
            String param = result.getMethodParameter().getParameterName();
            String field = param != null ? param : "parameter";
            result.getResolvableErrors().forEach(err ->
                    errors.add(new ValidationError(field, err.getDefaultMessage())));
        });
        ProblemDetail problem = buildProblem(ErrorCode.VALIDATION_FAILED, "Request validation failed", extractUri(request));
        problem.setProperty("errors", errors);
        return ResponseEntity.badRequest().contentType(PROBLEM_JSON).body(problem);
    }

    @Override
    protected ResponseEntity<Object> handleHttpMessageNotReadable(
            HttpMessageNotReadableException ex,
            HttpHeaders headers,
            HttpStatusCode status,
            WebRequest request) {
        ProblemDetail problem = buildProblem(
                ErrorCode.MALFORMED_REQUEST,
                "Malformed JSON request body",
                extractUri(request));
        return ResponseEntity.badRequest().contentType(PROBLEM_JSON).body(problem);
    }

    @Override
    protected ResponseEntity<Object> handleTypeMismatch(
            TypeMismatchException ex,
            HttpHeaders headers,
            HttpStatusCode status,
            WebRequest request) {
        String field = ex.getPropertyName() != null ? ex.getPropertyName() : "parameter";
        ProblemDetail problem = buildProblem(
                ErrorCode.VALIDATION_FAILED,
                "Invalid value for parameter '" + field + "'",
                extractUri(request));
        problem.setProperty("errors", List.of(new ValidationError(field, "invalid value")));
        return ResponseEntity.badRequest().contentType(PROBLEM_JSON).body(problem);
    }

    @Override
    protected ResponseEntity<Object> handleMissingServletRequestParameter(
            MissingServletRequestParameterException ex,
            HttpHeaders headers,
            HttpStatusCode status,
            WebRequest request) {
        ProblemDetail problem = buildProblem(
                ErrorCode.VALIDATION_FAILED,
                "Missing required parameter '" + ex.getParameterName() + "'",
                extractUri(request));
        problem.setProperty("errors", List.of(new ValidationError(ex.getParameterName(), "is required")));
        return ResponseEntity.badRequest().contentType(PROBLEM_JSON).body(problem);
    }

    @Override
    protected ResponseEntity<Object> handleNoResourceFoundException(
            NoResourceFoundException ex,
            HttpHeaders headers,
            HttpStatusCode status,
            WebRequest request) {
        ProblemDetail problem = buildProblem(ErrorCode.NOT_FOUND, "Resource not found", extractUri(request));
        return ResponseEntity.status(ErrorCode.NOT_FOUND.getStatus()).contentType(PROBLEM_JSON).body(problem);
    }

    @Override
    protected ResponseEntity<Object> handleHttpRequestMethodNotSupported(
            HttpRequestMethodNotSupportedException ex,
            HttpHeaders headers,
            HttpStatusCode status,
            WebRequest request) {
        ProblemDetail problem = buildProblem(ErrorCode.METHOD_NOT_ALLOWED, ex.getMessage(), extractUri(request));
        return ResponseEntity.status(ErrorCode.METHOD_NOT_ALLOWED.getStatus()).contentType(PROBLEM_JSON).body(problem);
    }

    @Override
    protected ResponseEntity<Object> handleExceptionInternal(
            Exception ex,
            Object body,
            HttpHeaders headers,
            HttpStatusCode statusCode,
            WebRequest request) {
        ErrorCode code = statusCode.is4xxClientError() ? ErrorCode.VALIDATION_FAILED : ErrorCode.INTERNAL_ERROR;
        String detail = statusCode.is4xxClientError() ? ex.getMessage() : "Unexpected error";
        if (statusCode.is5xxServerError()) {
            log.error("Internal Spring MVC exception", ex);
        }
        ProblemDetail problem = buildProblem(code, detail, extractUri(request));
        problem.setStatus(statusCode.value());
        return ResponseEntity.status(statusCode).contentType(PROBLEM_JSON).body(problem);
    }

    static ProblemDetail buildProblem(ErrorCode errorCode, String detail, String instanceUri) {
        ProblemDetail problem = ProblemDetail.forStatusAndDetail(errorCode.getStatus(), detail);
        problem.setType(errorCode.typeUri());
        problem.setTitle(errorCode.getTitle());
        if (instanceUri != null && !instanceUri.isBlank()) {
            problem.setInstance(URI.create(instanceUri));
        }
        problem.setProperty("code", errorCode.name());
        return problem;
    }

    private static String extractUri(WebRequest request) {
        if (request instanceof ServletWebRequest swr) {
            return swr.getRequest().getRequestURI();
        }
        return null;
    }
}
```

```java
import javax.crypto.spec.SecretKeySpec;

@Configuration
public class JwtConfig {

    SecretKey jwtSecretKey(ArenaProperties props) {
        byte[] bytes = props.jwt().secret().getBytes(StandardCharsets.UTF_8);
        return new SecretKeySpec(bytes, "HmacSHA256");
    }

    @Bean
    JwtEncoder jwtEncoder(SecretKey key) {
        return new NimbusJwtEncoder(new ImmutableSecret<>(key));
    }

    @Bean
    JwtDecoder jwtDecoder(SecretKey key, ArenaProperties props) {
        NimbusJwtDecoder decoder = NimbusJwtDecoder.withSecretKey(key)
                .macAlgorithm(MacAlgorithm.HS256)
                .build();
        OAuth2TokenValidator<Jwt> accessOnly = jwt ->
                "access".equals(jwt.getClaimAsString("typ"))
                        ? OAuth2TokenValidatorResult.success()
                        : OAuth2TokenValidatorResult.failure(
                                new OAuth2Error("invalid_token", "Not an access token", null));
        decoder.setJwtValidator(new DelegatingOAuth2TokenValidator<>(
                JwtValidators.createDefaultWithIssuer(props.jwt().issuer()),
                accessOnly));
        return decoder;
    }

    @Bean
    JwtAuthenticationConverter jwtAuthenticationConverter() {
        JwtGrantedAuthoritiesConverter authorities = new JwtGrantedAuthoritiesConverter();
        authorities.setAuthoritiesClaimName("roles");
        authorities.setAuthorityPrefix("ROLE_");
        JwtAuthenticationConverter converter = new JwtAuthenticationConverter();
        converter.setJwtGrantedAuthoritiesConverter(authorities);
        return converter;
    }
}
```

```java
package dev.fairplay.arena.leaderboard;

import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.moderation.AccountStatus;
import dev.fairplay.arena.player.PlayerRepository;
import lombok.extern.slf4j.Slf4j;
import org.springframework.boot.context.event.ApplicationReadyEvent;
import org.springframework.context.event.EventListener;
import org.springframework.data.redis.core.RedisCallback;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Component;

import java.nio.charset.StandardCharsets;
import java.util.List;
import java.util.Set;
import java.util.UUID;

@Slf4j
@Component
public class LeaderboardRebuilder {

    private static final Set<AccountStatus> ELIGIBLE_STATUSES =
            Set.of(AccountStatus.ACTIVE, AccountStatus.FLAGGED, AccountStatus.REINSTATED);

    private record RankedRow(UUID id, int rating) {}

    private final PlayerRepository playerRepository;
    private final JdbcClient jdbcClient;
    private final StringRedisTemplate redisTemplate;
    private final String leaderboardKey;
    private final boolean rebuildOnStartup;
    private final int batchSize;

    public LeaderboardRebuilder(
            PlayerRepository playerRepository,
            JdbcClient jdbcClient,
            StringRedisTemplate redisTemplate,
            ArenaProperties props) {
        this.playerRepository = playerRepository;
        this.jdbcClient = jdbcClient;
        this.redisTemplate = redisTemplate;
        this.leaderboardKey = props.leaderboard().key();
        this.rebuildOnStartup = props.leaderboard().rebuildOnStartup();
        this.batchSize = props.leaderboard().rebuildBatchSize();
    }

    @EventListener(ApplicationReadyEvent.class)
    public void onApplicationReady() {
        if (rebuildOnStartup) {
            rebuild();
        }
    }

    public void rebuild() {
        long startNanos = System.nanoTime();
        long eligibleCount = playerRepository.countEligibleForLeaderboard(ELIGIBLE_STATUSES);
        Long currentSize = redisTemplate.opsForZSet().zCard(leaderboardKey);
        if (currentSize != null && currentSize == eligibleCount) {
            log.info("Skipping leaderboard rebuild; Redis ZCARD {} matches eligible player count {}",
                    currentSize, eligibleCount);
            return;
        }

        String tempKey = leaderboardKey + ":rebuild";
        redisTemplate.delete(tempKey);

        if (eligibleCount == 0) {
            redisTemplate.delete(leaderboardKey);
            long durationMs = (System.nanoTime() - startNanos) / 1_000_000;
            log.info("Leaderboard rebuilt with 0 members in {} ms", durationMs);
            return;
        }

        byte[] tempKeyBytes = tempKey.getBytes(StandardCharsets.UTF_8);
        UUID lastId = null;
        long loaded = 0;

        while (true) {
            List<RankedRow> batch = fetchBatch(lastId);
            if (batch.isEmpty()) {
                break;
            }
            redisTemplate.executePipelined((RedisCallback<Object>) connection -> {
                for (RankedRow row : batch) {
                    connection.zSetCommands().zAdd(
                            tempKeyBytes,
                            row.rating(),
                            row.id().toString().getBytes(StandardCharsets.UTF_8));
                }
                return null;
            });
            loaded += batch.size();
            lastId = batch.getLast().id();
            if (batch.size() < batchSize) {
                break;
            }
        }

        redisTemplate.rename(tempKey, leaderboardKey);
        long durationMs = (System.nanoTime() - startNanos) / 1_000_000;
        log.info("Leaderboard rebuilt with {} members in {} ms", loaded, durationMs);
    }

    private List<RankedRow> fetchBatch(UUID lastId) {
        if (lastId == null) {
            return jdbcClient.sql("""
                    SELECT id, rating
                    FROM players
                    WHERE role = 'PLAYER'
                      AND status IN ('ACTIVE', 'FLAGGED', 'REINSTATED')
                    ORDER BY id ASC
                    LIMIT :limit
                    """)
                    .param("limit", batchSize)
                    .query((rs, rowNum) -> new RankedRow(
                            rs.getObject("id", UUID.class),
                            rs.getInt("rating")))
                    .list();
        }
        return jdbcClient.sql("""
                SELECT id, rating
                FROM players
                WHERE role = 'PLAYER'
                  AND status IN ('ACTIVE', 'FLAGGED', 'REINSTATED')
                  AND id > :lastId
                ORDER BY id ASC
                LIMIT :limit
                """)
                .param("lastId", lastId)
                .param("limit", batchSize)
                .query((rs, rowNum) -> new RankedRow(
                        rs.getObject("id", UUID.class),
                        rs.getInt("rating")))
                .list();
    }
}
```

```java
package dev.fairplay.arena.leaderboard;

import dev.fairplay.arena.common.error.ApiException;
import dev.fairplay.arena.common.error.ErrorCode;
import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.leaderboard.dto.LeaderboardEntry;
import dev.fairplay.arena.leaderboard.dto.LeaderboardPage;
import dev.fairplay.arena.leaderboard.dto.PlayerRankResponse;
import dev.fairplay.arena.moderation.AccountStatus;
import dev.fairplay.arena.player.Player;
import dev.fairplay.arena.player.PlayerRepository;
import io.micrometer.core.instrument.Gauge;
import io.micrometer.core.instrument.MeterRegistry;
import io.micrometer.core.instrument.Timer;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.data.redis.core.ZSetOperations.TypedTuple;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.UUID;
import java.util.function.Function;
import java.util.stream.Collectors;

@Service
public class LeaderboardService {

    private static final Set<AccountStatus> ELIGIBLE_STATUSES =
            Set.of(AccountStatus.ACTIVE, AccountStatus.FLAGGED, AccountStatus.REINSTATED);

    private final StringRedisTemplate redisTemplate;
    private final PlayerRepository playerRepository;
    private final JdbcClient jdbcClient;
    private final String leaderboardKey;
    private final MeterRegistry meterRegistry;
    private final Timer redisLookupTimer;
    private final Timer dbLookupTimer;

    public LeaderboardService(
            StringRedisTemplate redisTemplate,
            PlayerRepository playerRepository,
            JdbcClient jdbcClient,
            ArenaProperties props,
            MeterRegistry meterRegistry) {
        this.redisTemplate = redisTemplate;
        this.playerRepository = playerRepository;
        this.jdbcClient = jdbcClient;
        this.leaderboardKey = props.leaderboard().key();
        this.meterRegistry = meterRegistry;
        this.redisLookupTimer = Timer.builder("arena.leaderboard.rank.lookup")
                .tag("source", "redis")
                .register(meterRegistry);
        this.dbLookupTimer = Timer.builder("arena.leaderboard.rank.lookup")
                .tag("source", "db")
                .register(meterRegistry);
        Gauge.builder("arena.leaderboard.size", this, LeaderboardService::currentLeaderboardSize)
                .description("Current number of ranked players in Redis")
                .register(meterRegistry);
    }

    @Transactional(readOnly = true)
    public LeaderboardPage getLeaderboard(int offset, int limit) {
        Long zCard = redisTemplate.opsForZSet().zCard(leaderboardKey);
        long total = zCard != null ? zCard : 0L;

        Set<TypedTuple<String>> tuples = redisTemplate.opsForZSet()
                .reverseRangeWithScores(leaderboardKey, offset, (long) offset + limit - 1);
        if (tuples == null || tuples.isEmpty()) {
            return new LeaderboardPage(total, offset, limit, List.of());
        }

        List<UUID> orderedIds = new ArrayList<>(tuples.size());
        List<Integer> scores = new ArrayList<>(tuples.size());
        for (TypedTuple<String> tuple : tuples) {
            if (tuple.getValue() != null && tuple.getScore() != null) {
                orderedIds.add(UUID.fromString(tuple.getValue()));
                scores.add((int) Math.round(tuple.getScore()));
            }
        }

        Map<UUID, Player> playersById = playerRepository.findAllById(orderedIds).stream()
                .collect(Collectors.toMap(Player::getId, Function.identity()));

        List<LeaderboardEntry> entries = new ArrayList<>(orderedIds.size());
        for (int i = 0; i < orderedIds.size(); i++) {
            UUID playerId = orderedIds.get(i);
            Player player = playersById.get(playerId);
            if (player != null) {
                entries.add(new LeaderboardEntry(
                        offset + i + 1,
                        playerId,
                        player.getUsername(),
                        player.getDisplayName(),
                        scores.get(i)));
            }
        }
        return new LeaderboardPage(total, offset, limit, entries);
    }

    @Transactional(readOnly = true)
    public PlayerRankResponse getPlayerRank(UUID playerId, String source) {
        if (!"redis".equals(source) && !"db".equals(source)) {
            throw new ApiException(ErrorCode.VALIDATION_FAILED, "source must be 'redis' or 'db'");
        }
        Timer timer = "redis".equals(source) ? redisLookupTimer : dbLookupTimer;
        Timer.Sample sample = Timer.start(meterRegistry);
        try {
            return "redis".equals(source) ? lookupFromRedis(playerId) : lookupFromDb(playerId);
        } finally {
            sample.stop(timer);
        }
    }

    private PlayerRankResponse lookupFromRedis(UUID playerId) {
        Player player = playerRepository.findById(playerId)
                .filter(Player::isEligibleForMatchAndRanking)
                .orElseThrow(() -> new ApiException(ErrorCode.PLAYER_NOT_RANKED, "Player is not ranked: " + playerId));

        String member = playerId.toString();
        Long zeroBasedRank = redisTemplate.opsForZSet().reverseRank(leaderboardKey, member);
        Double score = redisTemplate.opsForZSet().score(leaderboardKey, member);
        Long zCard = redisTemplate.opsForZSet().zCard(leaderboardKey);

        if (zeroBasedRank == null || score == null || zCard == null) {
            throw new ApiException(ErrorCode.PLAYER_NOT_RANKED, "Player is not ranked: " + playerId);
        }
        return new PlayerRankResponse(
                playerId,
                player.getUsername(),
                (int) Math.round(score),
                zeroBasedRank + 1,
                zCard,
                "redis");
    }

    private PlayerRankResponse lookupFromDb(UUID playerId) {
        Player player = playerRepository.findById(playerId)
                .filter(Player::isEligibleForMatchAndRanking)
                .orElseThrow(() -> new ApiException(ErrorCode.PLAYER_NOT_RANKED, "Player is not ranked: " + playerId));

        Long rank = jdbcClient.sql("""
                SELECT COUNT(*) + 1
                FROM players p
                WHERE p.role = 'PLAYER'
                  AND p.status IN ('ACTIVE', 'FLAGGED', 'REINSTATED')
                  AND (p.rating > :rating
                       OR (p.rating = :rating AND (p.id::text COLLATE "C") > :idText))
                """)
                .param("rating", player.getRating())
                .param("idText", playerId.toString())
                .query(Long.class)
                .single();

        long totalRanked = playerRepository.countEligibleForLeaderboard(ELIGIBLE_STATUSES);
        return new PlayerRankResponse(
                playerId,
                player.getUsername(),
                player.getRating(),
                rank,
                totalRanked,
                "db");
    }

    private double currentLeaderboardSize() {
        try {
            Long size = redisTemplate.opsForZSet().zCard(leaderboardKey);
            return size != null ? size.doubleValue() : 0.0;
        } catch (Exception ex) {
            return 0.0;
        }
    }
}
```

```java
package dev.fairplay.arena.leaderboard;

import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.leaderboard.LeaderboardEvents.RatingChanged;
import dev.fairplay.arena.leaderboard.LeaderboardEvents.RemovedFromLeaderboard;
import io.micrometer.core.instrument.Counter;
import io.micrometer.core.instrument.MeterRegistry;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Component;
import org.springframework.transaction.event.TransactionPhase;
import org.springframework.transaction.event.TransactionalEventListener;

@Slf4j
@Component
public class LeaderboardSync {

    private final StringRedisTemplate redisTemplate;
    private final String leaderboardKey;
    private final Counter syncFailures;

    public LeaderboardSync(
            StringRedisTemplate redisTemplate,
            ArenaProperties props,
            MeterRegistry meterRegistry) {
        this.redisTemplate = redisTemplate;
        this.leaderboardKey = props.leaderboard().key();
        this.syncFailures = Counter.builder("arena.leaderboard.sync.failures")
                .description("Number of failed post-commit Redis leaderboard sync operations")
                .register(meterRegistry);
    }

    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void onRatingChanged(RatingChanged event) {
        try {
            redisTemplate.opsForZSet().add(
                    leaderboardKey,
                    event.playerId().toString(),
                    event.rating());
        } catch (Exception ex) {
            syncFailures.increment();
            log.warn("Failed to sync rating change to Redis for player {}", event.playerId(), ex);
        }
    }

    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void onRemovedFromLeaderboard(RemovedFromLeaderboard event) {
        try {
            redisTemplate.opsForZSet().remove(leaderboardKey, event.playerId().toString());
        } catch (Exception ex) {
            syncFailures.increment();
            log.warn("Failed to remove player {} from Redis leaderboard", event.playerId(), ex);
        }
    }
}
```

```java
package dev.fairplay.arena.leaderboard;

public final class RatingCalculator {

    public static final int DEFAULT_MAX_DELTA = 30;

    private RatingCalculator() {}

    public static int delta(int participantCount, int placement) {
        return delta(participantCount, placement, DEFAULT_MAX_DELTA);
    }

    public static int delta(int participantCount, int placement, int maxDelta) {
        if (participantCount < 2) {
            throw new IllegalArgumentException("participantCount must be at least 2");
        }
        if (placement < 1 || placement > participantCount) {
            throw new IllegalArgumentException("placement must be between 1 and " + participantCount);
        }
        double numerator = participantCount + 1.0 - (2.0 * placement);
        double denominator = participantCount - 1.0;
        return (int) Math.round(maxDelta * (numerator / denominator));
    }

    public static int applyDelta(int currentRating, int delta) {
        return Math.max(0, currentRating + delta);
    }
}
```

```java
package dev.fairplay.arena.match;

import dev.fairplay.arena.common.error.ApiException;
import dev.fairplay.arena.common.error.ErrorCode;
import dev.fairplay.arena.common.web.PageResponse;
import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.leaderboard.LeaderboardEvents.RatingChanged;
import dev.fairplay.arena.leaderboard.RatingCalculator;
import dev.fairplay.arena.match.dto.MatchResponse;
import dev.fairplay.arena.match.dto.ParticipantRequest;
import dev.fairplay.arena.match.dto.ParticipantResponse;
import dev.fairplay.arena.match.dto.PlayerMatchResponse;
import dev.fairplay.arena.match.dto.RecordMatchRequest;
import dev.fairplay.arena.player.Player;
import dev.fairplay.arena.player.PlayerRepository;
import io.micrometer.core.instrument.Counter;
import io.micrometer.core.instrument.MeterRegistry;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.ApplicationEventPublisher;
import org.springframework.dao.DataIntegrityViolationException;
import org.springframework.data.domain.PageRequest;
import org.springframework.stereotype.Service;
import org.springframework.transaction.PlatformTransactionManager;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.transaction.support.TransactionTemplate;

import java.time.Clock;
import java.time.Instant;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.HashSet;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.Set;
import java.util.UUID;
import java.util.function.Function;
import java.util.stream.Collectors;

@Slf4j
@Service
public class MatchService {

    public record RecordResult(MatchResponse match, boolean created) {}

    private final MatchRepository matchRepository;
    private final MatchParticipantRepository participantRepository;
    private final PlayerRepository playerRepository;
    private final ApplicationEventPublisher eventPublisher;
    private final ArenaProperties props;
    private final Clock clock;
    private final Counter matchesRecorded;
    private final TransactionTemplate recordTx;

    public MatchService(
            MatchRepository matchRepository,
            MatchParticipantRepository participantRepository,
            PlayerRepository playerRepository,
            ApplicationEventPublisher eventPublisher,
            ArenaProperties props,
            Clock clock,
            MeterRegistry meterRegistry,
            PlatformTransactionManager txManager) {
        this.matchRepository = matchRepository;
        this.participantRepository = participantRepository;
        this.playerRepository = playerRepository;
        this.eventPublisher = eventPublisher;
        this.props = props;
        this.clock = clock;
        this.recordTx = new TransactionTemplate(txManager);
        this.matchesRecorded = Counter.builder("arena.matches.recorded")
                .description("Number of matches recorded")
                .register(meterRegistry);
    }

    /**
     * Records a match in one transaction. Retries with the same {@code externalId} are idempotent.
     *
     * <p>Two concurrent requests with the same {@code externalId} can both pass the existence
     * check inside the transaction; the loser then violates the unique constraint on
     * {@code matches.external_id} when it flushes. PostgreSQL aborts that transaction, so the replay
     * lookup must happen after it has rolled back. The transaction is therefore driven by a
     * {@link TransactionTemplate} (not {@code @Transactional}) so the violation can be caught outside it
     * and answered with the winner's match (200) instead of a 500.
     */
    public RecordResult recordMatch(RecordMatchRequest request, UUID recorderId) {
        try {
            return recordTx.execute(status -> doRecordMatch(request, recorderId));
        } catch (DataIntegrityViolationException ex) {
            Optional<Match> winner = matchRepository.findByExternalId(request.externalId());
            if (winner.isPresent()) {
                return new RecordResult(toResponse(winner.get()), false);
            }
            throw ex;
        }
    }

    private RecordResult doRecordMatch(RecordMatchRequest request, UUID recorderId) {
        validateRequest(request);

        Optional<Match> existing = matchRepository.findByExternalId(request.externalId());
        if (existing.isPresent()) {
            return new RecordResult(toResponse(existing.get()), false);
        }

        List<UUID> sortedIds = request.participants().stream()
                .map(ParticipantRequest::playerId)
                .sorted()
                .toList();

        List<Player> lockedPlayers = playerRepository.findAllByIdInForUpdate(sortedIds);
        if (lockedPlayers.size() != sortedIds.size()) {
            Set<UUID> foundIds = lockedPlayers.stream().map(Player::getId).collect(Collectors.toSet());
            List<UUID> missing = sortedIds.stream().filter(id -> !foundIds.contains(id)).toList();
            throw new ApiException(ErrorCode.PLAYER_NOT_FOUND, "Unknown player IDs: " + missing);
        }

        List<UUID> ineligible = lockedPlayers.stream()
                .filter(p -> !p.isEligibleForMatchAndRanking())
                .map(Player::getId)
                .toList();
        if (!ineligible.isEmpty()) {
            throw new ApiException(ErrorCode.PLAYER_NOT_ELIGIBLE, "Players not eligible for match: " + ineligible);
        }

        Map<UUID, Player> playersById = lockedPlayers.stream()
                .collect(Collectors.toMap(Player::getId, Function.identity()));

        Instant now = Instant.now(clock);
        Player recorder = playerRepository.getReferenceById(recorderId);
        Match match = new Match(
                UUID.randomUUID(),
                request.externalId(),
                request.gameMode(),
                request.mapName(),
                request.startedAt(),
                request.endedAt(),
                recorder,
                now);
        matchRepository.saveAndFlush(match);

        int participantCount = request.participants().size();
        int maxDelta = props.rating().maxDelta();
        List<MatchParticipant> savedParticipants = new ArrayList<>(participantCount);

        for (ParticipantRequest pReq : request.participants()) {
            Player player = playersById.get(pReq.playerId());
            int ratingBefore = player.getRating();
            int delta = RatingCalculator.delta(participantCount, pReq.placement(), maxDelta);
            int ratingAfter = RatingCalculator.applyDelta(ratingBefore, delta);

            player.setRating(ratingAfter);
            player.setMatchesPlayed(player.getMatchesPlayed() + 1);
            player.setTotalKills(player.getTotalKills() + pReq.kills());
            player.setTotalDeaths(player.getTotalDeaths() + pReq.deaths());
            player.setTotalHeadshots(player.getTotalHeadshots() + pReq.headshots());
            player.setTotalShotsFired(player.getTotalShotsFired() + pReq.shotsFired());
            player.setTotalShotsHit(player.getTotalShotsHit() + pReq.shotsHit());
            player.setSumReactionMs(player.getSumReactionMs() + pReq.avgReactionMs());
            player.setUpdatedAt(now);

            MatchParticipant mp = new MatchParticipant(
                    match,
                    player,
                    pReq.placement(),
                    pReq.kills(),
                    pReq.deaths(),
                    pReq.headshots(),
                    pReq.shotsFired(),
                    pReq.shotsHit(),
                    pReq.avgReactionMs(),
                    ratingBefore,
                    ratingAfter);
            savedParticipants.add(mp);
            eventPublisher.publishEvent(new RatingChanged(player.getId(), ratingAfter));
        }
        participantRepository.saveAll(savedParticipants);

        matchesRecorded.increment();
        log.info("Recorded match {} with {} participants", match.getId(), participantCount);

        List<ParticipantResponse> participantResponses = savedParticipants.stream()
                .sorted(Comparator.comparingInt(MatchParticipant::getPlacement))
                .map(MatchService::toParticipantResponse)
                .toList();
        return new RecordResult(
                new MatchResponse(
                        match.getId(),
                        match.getExternalId(),
                        match.getGameMode(),
                        match.getMapName(),
                        match.getStartedAt(),
                        match.getEndedAt(),
                        participantResponses),
                true);
    }

    @Transactional(readOnly = true)
    public MatchResponse getMatch(UUID matchId) {
        Match match = matchRepository.findById(matchId)
                .orElseThrow(() -> new ApiException(ErrorCode.MATCH_NOT_FOUND, "Match not found: " + matchId));
        return toResponse(match);
    }

    @Transactional(readOnly = true)
    public PageResponse<PlayerMatchResponse> getPlayerMatches(UUID playerId, int page, int size) {
        if (!playerRepository.existsById(playerId)) {
            throw new ApiException(ErrorCode.PLAYER_NOT_FOUND, "Player not found: " + playerId);
        }
        return PageResponse.from(participantRepository.findPlayerMatches(playerId, PageRequest.of(page, size)));
    }

    private MatchResponse toResponse(Match match) {
        List<ParticipantResponse> participants = participantRepository
                .findByMatchIdWithPlayerOrderByPlacement(match.getId())
                .stream()
                .map(MatchService::toParticipantResponse)
                .toList();
        return new MatchResponse(
                match.getId(),
                match.getExternalId(),
                match.getGameMode(),
                match.getMapName(),
                match.getStartedAt(),
                match.getEndedAt(),
                participants);
    }

    private static ParticipantResponse toParticipantResponse(MatchParticipant mp) {
        return new ParticipantResponse(
                mp.getPlayer().getId(),
                mp.getPlayer().getUsername(),
                mp.getPlacement(),
                mp.getKills(),
                mp.getDeaths(),
                mp.getHeadshots(),
                mp.getShotsFired(),
                mp.getShotsHit(),
                mp.getAvgReactionMs(),
                mp.getRatingBefore(),
                mp.getRatingAfter());
    }

    private static void validateRequest(RecordMatchRequest request) {
        if (!request.endedAt().isAfter(request.startedAt())) {
            throw new ApiException(ErrorCode.VALIDATION_FAILED, "endedAt must be after startedAt");
        }
        int n = request.participants().size();
        Set<UUID> seenPlayers = new HashSet<>(n);
        Set<Integer> seenPlacements = new HashSet<>(n);
        for (ParticipantRequest p : request.participants()) {
            if (!seenPlayers.add(p.playerId())) {
                throw new ApiException(ErrorCode.VALIDATION_FAILED, "Duplicate playerId: " + p.playerId());
            }
            if (p.placement() < 1 || p.placement() > n || !seenPlacements.add(p.placement())) {
                throw new ApiException(
                        ErrorCode.VALIDATION_FAILED,
                        "Placements must form the exact set 1.." + n);
            }
            if (p.headshots() > p.kills()) {
                throw new ApiException(
                        ErrorCode.VALIDATION_FAILED,
                        "headshots cannot exceed kills for player " + p.playerId());
            }
            if (p.shotsHit() > p.shotsFired()) {
                throw new ApiException(
                        ErrorCode.VALIDATION_FAILED,
                        "shotsHit cannot exceed shotsFired for player " + p.playerId());
            }
        }
    }
}
```

```java
package dev.fairplay.arena.moderation;

import dev.fairplay.arena.common.error.ApiException;
import dev.fairplay.arena.common.error.ErrorCode;

import java.util.EnumMap;
import java.util.EnumSet;
import java.util.Map;
import java.util.Set;

public class AccountStateMachine {

    private static final Map<ModerationActionType, Set<AccountStatus>> ALLOWED_FROM =
            new EnumMap<>(ModerationActionType.class);

    private static final Map<ModerationActionType, AccountStatus> TARGETS =
            new EnumMap<>(ModerationActionType.class);

    static {
        ALLOWED_FROM.put(ModerationActionType.FLAG, EnumSet.of(AccountStatus.ACTIVE, AccountStatus.REINSTATED));
        ALLOWED_FROM.put(ModerationActionType.BAN, EnumSet.of(AccountStatus.ACTIVE, AccountStatus.FLAGGED, AccountStatus.REINSTATED));
        ALLOWED_FROM.put(ModerationActionType.CLEAR, EnumSet.of(AccountStatus.FLAGGED));
        ALLOWED_FROM.put(ModerationActionType.NOTE, EnumSet.allOf(AccountStatus.class));
        ALLOWED_FROM.put(ModerationActionType.APPEAL_SUBMITTED, EnumSet.of(AccountStatus.BANNED));
        ALLOWED_FROM.put(ModerationActionType.APPEAL_UPHELD, EnumSet.of(AccountStatus.APPEALED));
        ALLOWED_FROM.put(ModerationActionType.APPEAL_OVERTURNED, EnumSet.of(AccountStatus.APPEALED));

        TARGETS.put(ModerationActionType.FLAG, AccountStatus.FLAGGED);
        TARGETS.put(ModerationActionType.BAN, AccountStatus.BANNED);
        TARGETS.put(ModerationActionType.CLEAR, AccountStatus.ACTIVE);
        TARGETS.put(ModerationActionType.APPEAL_SUBMITTED, AccountStatus.APPEALED);
        TARGETS.put(ModerationActionType.APPEAL_UPHELD, AccountStatus.BANNED);
        TARGETS.put(ModerationActionType.APPEAL_OVERTURNED, AccountStatus.REINSTATED);
    }

    public AccountStatus next(AccountStatus current, ModerationActionType action) {
        if (current == null || action == null) {
            throw new ApiException(
                    ErrorCode.INVALID_STATE_TRANSITION,
                    "Cannot apply " + action + " to a player in status " + current);
        }
        Set<AccountStatus> allowed = ALLOWED_FROM.get(action);
        if (allowed == null || !allowed.contains(current)) {
            throw new ApiException(
                    ErrorCode.INVALID_STATE_TRANSITION,
                    "Cannot apply " + action + " to a player in status " + current);
        }
        if (action == ModerationActionType.NOTE) {
            return current;
        }
        return TARGETS.get(action);
    }
}
```

```java
package dev.fairplay.arena.moderation;

import dev.fairplay.arena.common.web.PageResponse;
import dev.fairplay.arena.moderation.dto.QueueItemResponse;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.stereotype.Repository;

import java.util.List;
import java.util.UUID;

@Repository
public class ModerationQueueQuery {

    private static final String QUEUE_SQL = """
            SELECT p.id, p.username, p.rating, p.status_changed_at,
                   a.id AS action_id, a.action, a.source, a.reason, a.confidence,
                   a.requires_human_review, a.created_at AS action_at
            FROM players p
            JOIN LATERAL (
                SELECT * FROM moderation_actions m
                WHERE m.player_id = p.id
                ORDER BY m.created_at DESC
                LIMIT 1
            ) a ON TRUE
            WHERE p.status = 'FLAGGED'
              AND (:humanReviewOnly = FALSE OR a.requires_human_review)
            ORDER BY p.status_changed_at ASC, p.id ASC
            LIMIT :size OFFSET :offset
            """;

    private static final String COUNT_SQL = """
            SELECT COUNT(*)
            FROM players p
            JOIN LATERAL (
                SELECT * FROM moderation_actions m
                WHERE m.player_id = p.id
                ORDER BY m.created_at DESC
                LIMIT 1
            ) a ON TRUE
            WHERE p.status = 'FLAGGED'
              AND (:humanReviewOnly = FALSE OR a.requires_human_review)
            """;

    private final JdbcClient jdbcClient;

    public ModerationQueueQuery(JdbcClient jdbcClient) {
        this.jdbcClient = jdbcClient;
    }

    public PageResponse<QueueItemResponse> fetchQueue(boolean humanReviewOnly, int page, int size) {
        long offset = (long) page * size;
        long total = jdbcClient.sql(COUNT_SQL)
                .param("humanReviewOnly", humanReviewOnly)
                .query(Long.class)
                .single();

        List<QueueItemResponse> items = jdbcClient.sql(QUEUE_SQL)
                .param("humanReviewOnly", humanReviewOnly)
                .param("size", size)
                .param("offset", offset)
                .query((rs, rowNum) -> new QueueItemResponse(
                        rs.getObject("id", UUID.class),
                        rs.getString("username"),
                        rs.getInt("rating"),
                        rs.getTimestamp("status_changed_at").toInstant(),
                        new QueueItemResponse.LatestAction(
                                rs.getObject("action_id", UUID.class),
                                ModerationActionType.valueOf(rs.getString("action")),
                                ActionSource.valueOf(rs.getString("source")),
                                rs.getString("reason"),
                                rs.getBigDecimal("confidence"),
                                rs.getBoolean("requires_human_review"),
                                rs.getTimestamp("action_at").toInstant())))
                .list();

        int totalPages = total == 0 ? 0 : (int) Math.ceil((double) total / size);
        return new PageResponse<>(items, page, size, total, totalPages);
    }
}
```

```java
package dev.fairplay.arena.moderation;

import dev.fairplay.arena.common.error.ApiException;
import dev.fairplay.arena.common.error.ErrorCode;
import dev.fairplay.arena.common.web.PageResponse;
import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.leaderboard.LeaderboardEvents.RemovedFromLeaderboard;
import dev.fairplay.arena.moderation.dto.ModerationActionRequest;
import dev.fairplay.arena.moderation.dto.ModerationActionResponse;
import dev.fairplay.arena.moderation.dto.QueueItemResponse;
import dev.fairplay.arena.player.Player;
import dev.fairplay.arena.player.PlayerRepository;
import dev.fairplay.arena.player.Role;
import io.micrometer.core.instrument.MeterRegistry;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.ApplicationEventPublisher;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.PageRequest;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;
import tools.jackson.core.type.TypeReference;
import tools.jackson.databind.json.JsonMapper;

import java.time.Clock;
import java.time.Instant;
import java.util.EnumSet;
import java.util.List;
import java.util.Set;
import java.util.UUID;

@Slf4j
@Service
public class ModerationService {

    private static final Set<ModerationActionType> DIRECT_ACTIONS = EnumSet.of(
            ModerationActionType.FLAG,
            ModerationActionType.BAN,
            ModerationActionType.CLEAR,
            ModerationActionType.NOTE);

    private static final TypeReference<List<String>> STRING_LIST_TYPE = new TypeReference<>() {};

    private final AccountStateMachine stateMachine = new AccountStateMachine();
    private final PlayerRepository playerRepository;
    private final ModerationActionRepository moderationActionRepository;
    private final ModerationQueueQuery moderationQueueQuery;
    private final ApplicationEventPublisher eventPublisher;
    private final ArenaProperties props;
    private final JsonMapper jsonMapper;
    private final Clock clock;
    private final MeterRegistry meterRegistry;

    public ModerationService(
            PlayerRepository playerRepository,
            ModerationActionRepository moderationActionRepository,
            ModerationQueueQuery moderationQueueQuery,
            ApplicationEventPublisher eventPublisher,
            ArenaProperties props,
            JsonMapper jsonMapper,
            Clock clock,
            MeterRegistry meterRegistry) {
        this.playerRepository = playerRepository;
        this.moderationActionRepository = moderationActionRepository;
        this.moderationQueueQuery = moderationQueueQuery;
        this.eventPublisher = eventPublisher;
        this.props = props;
        this.jsonMapper = jsonMapper;
        this.clock = clock;
        this.meterRegistry = meterRegistry;
    }

    @Transactional
    public ModerationActionResponse applyAction(
            UUID targetPlayerId,
            ModerationActionRequest request,
            UUID actorId) {
        if (!DIRECT_ACTIONS.contains(request.action())) {
            throw new ApiException(
                    ErrorCode.VALIDATION_FAILED,
                    "Action " + request.action() + " cannot be applied via this endpoint");
        }

        Player actor = playerRepository.findById(actorId)
                .orElseThrow(() -> new ApiException(ErrorCode.UNAUTHENTICATED, "Actor not found"));

        enforceGuardrails(actor, request);

        Player target = playerRepository.findById(targetPlayerId)
                .orElseThrow(() -> new ApiException(ErrorCode.PLAYER_NOT_FOUND, "Player not found: " + targetPlayerId));
        if (target.getRole() != Role.PLAYER) {
            throw new ApiException(ErrorCode.TARGET_NOT_A_PLAYER, "Target account is not a player: " + targetPlayerId);
        }

        AccountStatus from = target.getStatus();
        AccountStatus to = stateMachine.next(from, request.action());
        Instant now = Instant.now(clock);

        if (to != from) {
            target.setStatus(to);
            target.setStatusChangedAt(now);
            target.setUpdatedAt(now);
        }

        String evidenceJson = serializeEvidence(request.evidence());
        boolean requiresHumanReview = Boolean.TRUE.equals(request.requiresHumanReview());

        ModerationAction saved = moderationActionRepository.save(new ModerationAction(
                UUID.randomUUID(),
                target,
                request.action(),
                from,
                to,
                actor,
                request.source(),
                request.reason(),
                evidenceJson,
                request.confidence(),
                requiresHumanReview,
                now));

        if (to == AccountStatus.BANNED && from != AccountStatus.BANNED) {
            eventPublisher.publishEvent(new RemovedFromLeaderboard(target.getId()));
        }

        meterRegistry.counter(
                "arena.moderation.actions",
                "action", request.action().name(),
                "source", request.source().name()).increment();

        log.info("Moderation action {} on player {} ({} -> {}) source={} actor={}",
                request.action(), target.getId(), from, to, request.source(), actor.getUsername());

        return toResponse(saved, target.getId(), actor.getUsername(), request.evidence());
    }

    @Transactional(readOnly = true)
    public PageResponse<QueueItemResponse> getQueue(boolean humanReviewOnly, int page, int size) {
        return moderationQueueQuery.fetchQueue(humanReviewOnly, page, size);
    }

    @Transactional(readOnly = true)
    public PageResponse<ModerationActionResponse> getHistory(UUID playerId, int page, int size) {
        if (!playerRepository.existsById(playerId)) {
            throw new ApiException(ErrorCode.PLAYER_NOT_FOUND, "Player not found: " + playerId);
        }
        Page<ModerationActionResponse> results = moderationActionRepository
                .findHistoryByPlayerId(playerId, PageRequest.of(page, size))
                .map(a -> toResponse(a, playerId, a.getActor().getUsername(), deserializeEvidence(a.getEvidenceJson())));
        return PageResponse.from(results);
    }

    private void enforceGuardrails(Player actor, ModerationActionRequest request) {
        if (actor.getRole() == Role.MODERATOR) {
            if (request.source() != ActionSource.HUMAN) {
                throw new ApiException(ErrorCode.INVALID_SOURCE, "Moderators must use source HUMAN");
            }
        } else if (actor.getRole() == Role.SERVICE) {
            if (request.source() != ActionSource.TELEMETRY && request.source() != ActionSource.JUDGE) {
                throw new ApiException(ErrorCode.INVALID_SOURCE, "Service accounts must use TELEMETRY or JUDGE");
            }
            if (request.action() == ModerationActionType.BAN) {
                if (request.confidence() == null) {
                    throw new ApiException(ErrorCode.CONFIDENCE_REQUIRED, "Service BAN requires confidence");
                }
                if (request.confidence().compareTo(props.moderation().serviceBanMinConfidence()) < 0) {
                    throw new ApiException(
                            ErrorCode.CONFIDENCE_TOO_LOW,
                            "Service BAN confidence must be at least " + props.moderation().serviceBanMinConfidence());
                }
            }
        } else {
            throw new ApiException(ErrorCode.FORBIDDEN, "Insufficient permissions");
        }
    }

    private String serializeEvidence(List<String> evidence) {
        if (evidence == null) {
            return null;
        }
        return jsonMapper.writeValueAsString(evidence);
    }

    private List<String> deserializeEvidence(String evidenceJson) {
        if (evidenceJson == null) {
            return null;
        }
        return jsonMapper.readValue(evidenceJson, STRING_LIST_TYPE);
    }

    private ModerationActionResponse toResponse(
            ModerationAction action,
            UUID playerId,
            String actorUsername,
            List<String> evidence) {
        return new ModerationActionResponse(
                action.getId(),
                playerId,
                action.getAction(),
                action.getFromStatus(),
                action.getToStatus(),
                action.getSource(),
                actorUsername,
                action.getReason(),
                evidence,
                action.getConfidence(),
                action.isRequiresHumanReview(),
                action.getCreatedAt());
    }
}
```

```java
package dev.fairplay.arena.player;

import dev.fairplay.arena.common.error.ApiException;
import dev.fairplay.arena.common.error.ErrorCode;
import dev.fairplay.arena.common.web.PageResponse;
import dev.fairplay.arena.moderation.AccountStatus;
import dev.fairplay.arena.player.dto.PlayerDetailResponse;
import dev.fairplay.arena.player.dto.PlayerPercentiles;
import dev.fairplay.arena.player.dto.PlayerStats;
import dev.fairplay.arena.player.dto.PlayerSummaryResponse;
import dev.fairplay.arena.player.dto.UpdateProfileRequest;
import org.springframework.data.domain.Page;
import org.springframework.data.domain.PageRequest;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.time.Clock;
import java.time.Instant;
import java.util.Locale;
import java.util.UUID;

@Service
public class PlayerService {

    private final PlayerRepository playerRepository;
    private final PlayerMapper playerMapper;
    private final StatDistributionService statDistributionService;
    private final Clock clock;

    public PlayerService(
            PlayerRepository playerRepository,
            PlayerMapper playerMapper,
            StatDistributionService statDistributionService,
            Clock clock) {
        this.playerRepository = playerRepository;
        this.playerMapper = playerMapper;
        this.statDistributionService = statDistributionService;
        this.clock = clock;
    }

    @Transactional(readOnly = true)
    public PlayerDetailResponse getMe(UUID playerId) {
        Player player = findOrThrow(playerId);
        return toDetail(player, true);
    }

    @Transactional
    public PlayerDetailResponse updateMe(UUID playerId, UpdateProfileRequest request) {
        Player player = findOrThrow(playerId);
        if (player.getStatus() == AccountStatus.BANNED || player.getStatus() == AccountStatus.APPEALED) {
            throw new ApiException(ErrorCode.ACCOUNT_SUSPENDED, "Suspended accounts cannot update their profile");
        }
        boolean changed = false;
        if (request.displayName() != null) {
            player.setDisplayName(request.displayName());
            changed = true;
        }
        if (request.country() != null) {
            player.setCountry(request.country());
            changed = true;
        }
        if (changed) {
            player.setUpdatedAt(Instant.now(clock));
        }
        return toDetail(player, true);
    }

    @Transactional(readOnly = true)
    public PlayerDetailResponse getById(UUID id) {
        Player player = findOrThrow(id);
        return toDetail(player, false);
    }

    @Transactional(readOnly = true)
    public PageResponse<PlayerSummaryResponse> search(String query, AccountStatus status, int page, int size) {
        String escapedPrefix = null;
        if (query != null && !query.isBlank()) {
            escapedPrefix = query.toLowerCase(Locale.ROOT)
                    .replace("!", "!!")
                    .replace("%", "!%")
                    .replace("_", "!_");
        }
        Page<PlayerSummaryResponse> results = playerRepository
                .searchPlayers(escapedPrefix, status, PageRequest.of(page, size))
                .map(playerMapper::toSummary);
        return PageResponse.from(results);
    }

    public PlayerDetailResponse toDetail(Player player, boolean includeEmail) {
        PlayerStats stats = computeStats(player);
        PlayerPercentiles percentiles = player.getRole() == Role.PLAYER
                ? statDistributionService.percentilesFor(
                        player.getMatchesPlayed(),
                        stats.headshotRate(),
                        stats.accuracy(),
                        stats.avgReactionMs())
                : null;
        return playerMapper.toDetail(
                player,
                includeEmail ? player.getEmail() : null,
                stats,
                percentiles);
    }

    public static PlayerStats computeStats(Player player) {
        long kills = player.getTotalKills();
        long deaths = player.getTotalDeaths();
        double kdRatio = round4((double) kills / Math.max(deaths, 1L));
        double headshotRate = kills == 0 ? 0.0 : round4((double) player.getTotalHeadshots() / kills);
        long shotsFired = player.getTotalShotsFired();
        double accuracy = shotsFired == 0 ? 0.0 : round4((double) player.getTotalShotsHit() / shotsFired);
        Integer avgReactionMs = player.getMatchesPlayed() == 0
                ? null
                : (int) (player.getSumReactionMs() / player.getMatchesPlayed());
        return new PlayerStats(kills, deaths, kdRatio, headshotRate, accuracy, avgReactionMs);
    }

    private Player findOrThrow(UUID id) {
        return playerRepository.findById(id)
                .orElseThrow(() -> new ApiException(ErrorCode.PLAYER_NOT_FOUND, "Player not found: " + id));
    }

    private static double round4(double value) {
        return BigDecimal.valueOf(value).setScale(4, RoundingMode.HALF_UP).doubleValue();
    }
}
```

```java
package dev.fairplay.arena.player;

import dev.fairplay.arena.config.ArenaProperties;
import dev.fairplay.arena.player.dto.PlayerPercentiles;
import lombok.extern.slf4j.Slf4j;
import org.springframework.boot.context.event.ApplicationReadyEvent;
import org.springframework.context.event.EventListener;
import org.springframework.jdbc.core.simple.JdbcClient;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Service;

import java.sql.Array;
import java.sql.SQLException;
import java.util.Optional;
import java.util.concurrent.atomic.AtomicReference;

@Slf4j
@Service
public class StatDistributionService {

    public record Distribution(double[] headshotRate, double[] accuracy, double[] reactionMs) {}

    private static final double[] PERCENTILE_POINTS = buildPercentilePoints();
    private static final String PERCENTILE_SQL_TEMPLATE = """
            SELECT percentile_cont(:points) WITHIN GROUP (ORDER BY %s)
            FROM players
            WHERE role = 'PLAYER'
              AND status NOT IN ('BANNED', 'APPEALED')
              AND matches_played >= :minMatches
            """;

    private final JdbcClient jdbcClient;
    private final int minMatchesForPercentiles;
    private final AtomicReference<Distribution> current = new AtomicReference<>();

    public StatDistributionService(JdbcClient jdbcClient, ArenaProperties props) {
        this.jdbcClient = jdbcClient;
        this.minMatchesForPercentiles = props.stats().minMatchesForPercentiles();
    }

    @EventListener(ApplicationReadyEvent.class)
    @Scheduled(fixedDelayString = "${arena.stats.refresh-interval}")
    public void refresh() {
        double[] hs = queryPercentiles(
                "CASE WHEN total_kills = 0 THEN 0.0 ELSE total_headshots::double precision / total_kills END");
        double[] acc = queryPercentiles(
                "CASE WHEN total_shots_fired = 0 THEN 0.0 ELSE total_shots_hit::double precision / total_shots_fired END");
        double[] react = queryPercentiles(
                "sum_reaction_ms::double precision / matches_played");

        if (hs == null || acc == null || react == null) {
            current.set(null);
            return;
        }
        current.set(new Distribution(hs, acc, react));
    }

    public PlayerPercentiles percentilesFor(
            int matchesPlayed,
            double headshotRate,
            double accuracy,
            Integer avgReactionMs) {
        Distribution dist = current.get();
        if (dist == null || matchesPlayed < minMatchesForPercentiles || avgReactionMs == null) {
            return null;
        }
        int hsPct = percentile(dist.headshotRate(), headshotRate);
        int accPct = percentile(dist.accuracy(), accuracy);
        int reactionSpeed = 100 - percentile(dist.reactionMs(), avgReactionMs.doubleValue());
        return new PlayerPercentiles(hsPct, accPct, reactionSpeed);
    }

    public void setDistributionForTest(Distribution distribution) {
        current.set(distribution);
    }

    static int percentile(double[] cutPoints, double value) {
        int lo = 0;
        int hi = cutPoints.length;
        while (lo < hi) {
            int mid = (lo + hi) >>> 1;
            if (cutPoints[mid] <= value) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        return Math.clamp(lo - 1, 0, 100);
    }

    private double[] queryPercentiles(String orderExpr) {
        String sql = PERCENTILE_SQL_TEMPLATE.formatted(orderExpr);
        // percentile_cont returns NULL when no player is eligible (for example an empty database at first
        // startup). JdbcClient rejects a null ResultSetExtractor result, which would crash the app on
        // ApplicationReadyEvent, so the extractor returns an Optional and "no distribution yet" is
        // represented by null percentiles.
        return jdbcClient.sql(sql)
                .param("points", PERCENTILE_POINTS)
                .param("minMatches", minMatchesForPercentiles)
                .query(rs -> {
                    if (!rs.next()) {
                        return Optional.<double[]>empty();
                    }
                    Array sqlArray = rs.getArray(1);
                    if (sqlArray == null) {
                        return Optional.<double[]>empty();
                    }
                    try {
                        Object raw = sqlArray.getArray();
                        if (!(raw instanceof Object[] elements) || elements.length == 0) {
                            return Optional.<double[]>empty();
                        }
                        double[] result = new double[elements.length];
                        for (int i = 0; i < elements.length; i++) {
                            if (elements[i] == null) {
                                return Optional.<double[]>empty();
                            }
                            result[i] = ((Number) elements[i]).doubleValue();
                        }
                        return Optional.of(result);
                    } finally {
                        try {
                            sqlArray.free();
                        } catch (SQLException ignored) {
                            // Ignore driver cleanup failure
                        }
                    }
                })
                .orElse(null);
    }

    private static double[] buildPercentilePoints() {
        double[] points = new double[101];
        for (int i = 0; i <= 100; i++) {
            points[i] = i / 100.0;
        }
        return points;
    }
}
```

```java
import com.nimbusds.jose.jwk.source.ImmutableSecret;
import dev.fairplay.arena.config.ArenaProperties;

import org.springframework.security.oauth2.jwt.Jwt;
import org.springframework.security.oauth2.jwt.JwtEncoder;
import org.springframework.security.oauth2.jwt.JwtTimestampValidator;
import org.springframework.security.oauth2.jwt.NimbusJwtDecoder;
import org.springframework.security.oauth2.jwt.NimbusJwtEncoder;

import javax.crypto.SecretKey;
import javax.crypto.spec.SecretKeySpec;
import java.math.BigDecimal;
import java.nio.charset.StandardCharsets;
import java.time.Clock;
import java.time.Duration;
import java.time.Instant;
import java.time.ZoneOffset;
import java.util.List;
import java.util.UUID;

import static org.assertj.core.api.Assertions.assertThat;

class TokenServiceTest {

    private static final String SECRET = "test-secret-that-is-at-least-32-chars-long";
    private static final Instant FIXED_NOW = Instant.parse("2026-11-17T10:00:00Z");

    @Test
    void issuesAccessTokenWithExpectedClaimsHeaderAndExpiryFromClock() {
        SecretKey key = new SecretKeySpec(SECRET.getBytes(StandardCharsets.UTF_8), "HmacSHA256");
        JwtEncoder encoder = new NimbusJwtEncoder(new ImmutableSecret<>(key));
        Clock clock = Clock.fixed(FIXED_NOW, ZoneOffset.UTC);

        // The token is issued with a fixed clock, so the decoder must check expiry against the same
        // clock. Otherwise the test only passes within 15 minutes of FIXED_NOW (the default
        // validator uses the real time).
        NimbusJwtDecoder decoder = NimbusJwtDecoder.withSecretKey(key).macAlgorithm(MacAlgorithm.HS256).build();
        JwtTimestampValidator timestampValidator = new JwtTimestampValidator(Duration.ZERO);
        timestampValidator.setClock(clock);
        decoder.setJwtValidator(timestampValidator);

        ArenaProperties props = new ArenaProperties(
                new ArenaProperties.Jwt(SECRET, "fairplay-arena", Duration.ofMinutes(15), Duration.ofDays(7)),
                new ArenaProperties.Rating(1000, 30),
                new ArenaProperties.Leaderboard("leaderboard:global", true, 10000),
                new ArenaProperties.Stats(5, Duration.ofSeconds(60)),
                new ArenaProperties.Moderation(new BigDecimal("0.80")),
                new ArenaProperties.Accounts(
                        new ArenaProperties.AccountCredential("mod-admin", "test"),
                        List.of(new ArenaProperties.AccountCredential("telemetry-sim", "test"))));

        TokenService tokenService = new TokenService(encoder, props, clock);

        UUID playerId = UUID.randomUUID();
        Player player = new Player(
                playerId,
                "neo_42",
                "neo@example.com",
                "hash",
                Role.PLAYER,
                AccountStatus.ACTIVE,
                "Neo",
                "IN",
                1000,
                FIXED_NOW);

        TokenService.AccessToken issued = tokenService.issueAccessToken(player);
        assertThat(issued.expiresAt()).isEqualTo(FIXED_NOW.plus(Duration.ofMinutes(15)));

        Jwt decoded = decoder.decode(issued.value());
        assertThat(decoded.getHeaders()).containsEntry("alg", "HS256");
        assertThat(decoded.getClaimAsString("iss")).isEqualTo("fairplay-arena");
        assertThat(decoded.getSubject()).isEqualTo(playerId.toString());
        assertThat(decoded.getIssuedAt()).isEqualTo(FIXED_NOW);
        assertThat(decoded.getExpiresAt()).isEqualTo(FIXED_NOW.plus(Duration.ofMinutes(15)));
        assertThat(decoded.getClaimAsString("username")).isEqualTo("neo_42");
        assertThat(decoded.getClaimAsStringList("roles")).containsExactly("PLAYER");
        assertThat(decoded.getClaimAsString("typ")).isEqualTo("access");
    }

    @Test
    void generates43CharBase64UrlRefreshTokenAndSha256HexHash() {
        SecretKey key = new SecretKeySpec(SECRET.getBytes(StandardCharsets.UTF_8), "HmacSHA256");
        JwtEncoder encoder = new NimbusJwtEncoder(new ImmutableSecret<>(key));
        ArenaProperties props = new ArenaProperties(

                new ArenaProperties.Leaderboard("leaderboard:global", true, 10000),

        String refreshToken = tokenService.generateRefreshToken();

        String hash = tokenService.hashRefreshToken(refreshToken);
        assertThat(hash).matches("^[0-9a-f]{64}$");

    }
```

```java
package dev.fairplay.arena.moderation;

import dev.fairplay.arena.common.error.ApiException;
import dev.fairplay.arena.common.error.ErrorCode;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

class AccountStateMachineTest {

    private final AccountStateMachine stateMachine = new AccountStateMachine();

    record TransitionCase(AccountStatus from, ModerationActionType action, AccountStatus expectedTo) {}

    private static final Map<TransitionCaseKey, AccountStatus> VALID_TRANSITIONS = Map.ofEntries(
            Map.entry(new TransitionCaseKey(AccountStatus.ACTIVE, ModerationActionType.FLAG), AccountStatus.FLAGGED),
            Map.entry(new TransitionCaseKey(AccountStatus.REINSTATED, ModerationActionType.FLAG), AccountStatus.FLAGGED),
            Map.entry(new TransitionCaseKey(AccountStatus.ACTIVE, ModerationActionType.BAN), AccountStatus.BANNED),
            Map.entry(new TransitionCaseKey(AccountStatus.FLAGGED, ModerationActionType.BAN), AccountStatus.BANNED),
            Map.entry(new TransitionCaseKey(AccountStatus.REINSTATED, ModerationActionType.BAN), AccountStatus.BANNED),
            Map.entry(new TransitionCaseKey(AccountStatus.FLAGGED, ModerationActionType.CLEAR), AccountStatus.ACTIVE),
            Map.entry(new TransitionCaseKey(AccountStatus.ACTIVE, ModerationActionType.NOTE), AccountStatus.ACTIVE),
            Map.entry(new TransitionCaseKey(AccountStatus.FLAGGED, ModerationActionType.NOTE), AccountStatus.FLAGGED),
            Map.entry(new TransitionCaseKey(AccountStatus.BANNED, ModerationActionType.NOTE), AccountStatus.BANNED),
            Map.entry(new TransitionCaseKey(AccountStatus.APPEALED, ModerationActionType.NOTE), AccountStatus.APPEALED),
            Map.entry(new TransitionCaseKey(AccountStatus.REINSTATED, ModerationActionType.NOTE), AccountStatus.REINSTATED),
            Map.entry(new TransitionCaseKey(AccountStatus.BANNED, ModerationActionType.APPEAL_SUBMITTED), AccountStatus.APPEALED),
            Map.entry(new TransitionCaseKey(AccountStatus.APPEALED, ModerationActionType.APPEAL_UPHELD), AccountStatus.BANNED),
            Map.entry(new TransitionCaseKey(AccountStatus.APPEALED, ModerationActionType.APPEAL_OVERTURNED), AccountStatus.REINSTATED)
    );

    private record TransitionCaseKey(AccountStatus from, ModerationActionType action) {}

    static Stream<TransitionCase> allPairs() {
        return Stream.of(AccountStatus.values())
                .flatMap(status -> Stream.of(ModerationActionType.values())
                        .map(action -> new TransitionCase(
                                status,
                                action,
                                VALID_TRANSITIONS.get(new TransitionCaseKey(status, action)))));
    }

    @ParameterizedTest(name = "{0}")
    @MethodSource("allPairs")
    void testsAll35ActionStatusPairs(TransitionCase tc) {
        if (tc.expectedTo() != null) {
            assertThat(stateMachine.next(tc.from(), tc.action())).isEqualTo(tc.expectedTo());
        } else {
            assertThatThrownBy(() -> stateMachine.next(tc.from(), tc.action()))
                    .isInstanceOf(ApiException.class)
                    .satisfies(ex -> assertThat(((ApiException) ex).getErrorCode())
                            .isEqualTo(ErrorCode.INVALID_STATE_TRANSITION));
        }
    }
}
```

```java
    void parallelBansGiveExactlyOneSuccessAndOneConflict() throws Exception {
        Player mod = data.moderator();
        Player judge = data.service("judge-agent");
        Player target = data.player("race_player");

        CountDownLatch ready = new CountDownLatch(2);
        CountDownLatch start = new CountDownLatch(1);

        try (ExecutorService pool = Executors.newFixedThreadPool(2)) {
            Future<Throwable> f1 = pool.submit(() -> {
                ready.countDown();
                start.await();
                try {
                    moderationService.applyAction(
                            target.getId(),
                            new ModerationActionRequest(
                                    ModerationActionType.BAN,
                                    ActionSource.HUMAN,
                                    "Manual ban",
                                    null,
                                    null,
                                    false),
                            mod.getId());
                    return null;
                } catch (Throwable t) {
                    return t;
                }
            });

            Future<Throwable> f2 = pool.submit(() -> {
                ready.countDown();
                start.await();
                try {
                    moderationService.applyAction(
                            target.getId(),
                            new ModerationActionRequest(
                                    ModerationActionType.BAN,
                                    ActionSource.JUDGE,
                                    "Judge ban",
                                    List.of("evidence"),
                                    new BigDecimal("0.95"),
                                    false),
                            judge.getId());
                    return null;
                } catch (Throwable t) {
                    return t;
                }
            });

            ready.await();
            start.countDown();

            Throwable t1 = f1.get();
            Throwable t2 = f2.get();

            List<Throwable> failures = List.of(t1 == null ? new NoError() : t1, t2 == null ? new NoError() : t2)
                    .stream()
                    .filter(t -> !(t instanceof NoError))
                    .toList();

            assertThat(failures).hasSize(1);
            Throwable conflict = failures.getFirst();
            assertThat(conflict).satisfiesAnyOf(
                    ex -> assertThat(ex).isInstanceOf(ObjectOptimisticLockingFailureException.class),
                    ex -> assertThat(ex).isInstanceOf(ApiException.class));
        }
    }

    private static final class NoError extends Throwable {}
}
```

```java
class StatDistributionServiceTest {

    private static StatDistributionService newService() {
        ArenaProperties props = new ArenaProperties(
                new ArenaProperties.Jwt("test-secret-that-is-at-least-32-chars-long", "fairplay-arena",
                        Duration.ofMinutes(15), Duration.ofDays(7)),
                new ArenaProperties.Rating(1000, 30),
                new ArenaProperties.Leaderboard("leaderboard:global", true, 10000),
                new ArenaProperties.Stats(5, Duration.ofSeconds(60)),
                new ArenaProperties.Moderation(new BigDecimal("0.80")),
                new ArenaProperties.Accounts(
                        new ArenaProperties.AccountCredential("mod-admin", "test"),
                        List.of(new ArenaProperties.AccountCredential("telemetry-sim", "test"))));
        return new StatDistributionService(mock(JdbcClient.class), props);
    }

    @Test
    void returnsNullWhenUnderMinMatchesOrDistributionNotReady() {
        StatDistributionService service = newService();
        assertThat(service.percentilesFor(10, 0.5, 0.3, 200)).isNull();

        double[] linear = linearCuts(0.0, 1.0);
        service.setDistributionForTest(new StatDistributionService.Distribution(linear, linear, linearCuts(100.0, 100.0)));
        assertThat(service.percentilesFor(4, 0.5, 0.3, 200)).isNull();
    }

    @Test
    void looksUpEdgesBetweenCutPointsAndInvertsReactionSpeed() {
        StatDistributionService service = newService();
        double[] hsCuts = linearCuts(0.0, 0.01);       // 0.00 .. 1.00
        double[] accCuts = linearCuts(0.10, 0.005);    // 0.10 .. 0.60
        double[] reactCuts = linearCuts(100.0, 2.0);   // 100 .. 300 ms
        service.setDistributionForTest(new StatDistributionService.Distribution(hsCuts, accCuts, reactCuts));

        // At minimum edge (and below minimum)
        PlayerPercentiles minEdge = service.percentilesFor(5, 0.0, 0.05, 90);
        assertThat(minEdge).isEqualTo(new PlayerPercentiles(0, 0, 100));

        // Between cut points: 0.504 -> 51 cuts <= 0.504 -> index 50; 0.352 -> 51 cuts <= 0.352 -> index 50; 201ms -> 51 cuts <= 201 -> index 50 -> speed 50
        PlayerPercentiles mid = service.percentilesFor(10, 0.504, 0.352, 201);
        assertThat(mid).isEqualTo(new PlayerPercentiles(50, 50, 50));

        // At maximum edge (and above maximum)
        PlayerPercentiles maxEdge = service.percentilesFor(10, 1.5, 0.60, 350);
        assertThat(maxEdge).isEqualTo(new PlayerPercentiles(100, 100, 0));
    }

    private static double[] linearCuts(double start, double step) {
        double[] cuts = new double[101];
        for (int i = 0; i <= 100; i++) {
            cuts[i] = start + i * step;
        }
        return cuts;
    }
}
```
