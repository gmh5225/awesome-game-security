# Toxido Anti Cheat

Minecraft istemcisine **mod kurmadan**, JVM Attach API ile baglanan istemci tarafli
anticheat sistemi. Bu depo **Faz 1**'i icerir: Minecraft'i bulma, Java agent'i
oyun JVM'ine yukleme, agent el sikismasi, oturum yasam dongusu, HMAC korumali
API ve Discord kanal yonetimi.

> Faz 2'de instrumentation tabanli gercek kontrol katmani eklenecek. Faz 1'de
> agent henuz oyun icini denetlemez; yalnizca baglanti ve oturum altyapisini
> dogrular.

## Mimari

```
Minecraft JVM (javaw.exe)
        ^  attach + agent yukleme
        |
ac-app (terminal + arka plan servisi) --HMAC HTTPS--> backend (FastAPI)
        ^  loopback IPC (port + token)          |
        |                                       +--> SQLite
   ac-agent.jar                                 +--> discord.py bot
                                                +--> Now/ ve Log/ kategorileri
```

- **ac-app**: Acilista blok `TOXIDO` logosu ve Matrix yagmuru gosteren bir
  terminal ekrani cizer. Enter'a basinca ekran kapanir, anticheat servisi
  arka planda calismaya devam eder. Servis Minecraft JVM'ini
  `VirtualMachine.list()` ile bulur, agent'i yukler, agent ile loopback
  uzerinden konusur, API oturumunu baslatir ve kalp atisi gonderir. Tek
  seferliktir; oyun kapaninca oturumu bitirir ve yeniden baglanmaz.
- **ac-agent**: Oyun JVM'ine dinamik olarak yuklenen Java agent. Uygulamaya
  `hello` gonderir, `hello_ack` alir ve 5 saniyede bir kalp atisi yollar.
- **backend**: FastAPI + `discord.py` + SQLite. Oturum baslatma/bitirme,
  zaman asimi denetimi ve Discord kanal yasam dongusunden sorumludur.

## Oturum yasam dongusu

1. Uygulama Minecraft JVM'ini bulur (vanilla, Fabric, Quilt, Forge, NeoForge).
2. Agent'i yukler; agent loopback'e baglanip token ile el sikisir.
3. Uygulama API'ye `POST /api/v1/session/start` gonderir.
4. Backend `Now/<mcname>` kanalini olusturur ve oturumu `active` yazar.
5. Uygulama 5 saniyede bir `POST /heartbeat` gonderir.
6. Oyun kapanirsa `POST /end` cagrilir; kanal `Log/<mcname>-<n>` olarak
   arsivlenir. `n`, ayni oyuncunun onceki kayitlarinin maksimumunun bir
   fazlasidir.
7. Agent 20 saniye sessiz kalirsa uygulama oturumu `agent_silent` ile bitirir.
   Backend 45 saniye heartbeat alamazsa oturumu `heartbeat_timeout` ile kapatir.

Her oturum bagimsizdir; ayni oyuncunun sonraki oturumu yeni bir `Now/<mcname>`
kanali acar.

## API ve guvenlik

- Tum yazma istekleri HMAC-SHA256 ile imzalanir:
  `timestamp + "." + nonce + "." + body`.
- Basliklar: `X-AC-Key`, `X-AC-Timestamp`, `X-AC-Nonce`, `X-AC-Signature`.
- Zaman damgasi ±300 saniye, nonce tek kullanimlik (10 dakika onbellek).
- Oturum token'i yalnizca heartbeat/end icin `Authorization: Bearer` olarak
  gonderilir; veritabaninda SHA-256 ozeti tutulur.
- `GET /dl` (ve `GET /download/40x1d0AC.exe`) `static/40x1d0AC.exe` dosyasini
  indirir; baska bir yol icin `DOWNLOAD_PATH` kullanilabilir.
- Uretimde HTTPS zorunludur (Caddy / Let's Encrypt onerilir).

package dev.toxido.anticheat.agent;

import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.net.InetAddress;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.concurrent.atomic.AtomicBoolean;
import java.util.concurrent.atomic.AtomicInteger;

/**
 * Ajan tarafindaki IPC istemcisi: uygulamanin actigi loopback portuna baglanir,
 * el sikismasi yapar ve duzenli kalp atisi gonderir.
 */
public final class AgentClient implements Runnable {
    private final int port;
    private final String token;
    private final AtomicBoolean running = new AtomicBoolean(true);
    private final AtomicInteger heartbeatStarted = new AtomicInteger(0);

    private volatile BufferedWriter out;

    public AgentClient(int port, String token) {
        this.port = port;
        this.token = token;
    }

    @Override
    public void run() {
        Socket connected = connect();
        if (connected == null) {
            AgentMain.log("Uygulamaya baglanilamadi (port=" + port + ")");
            return;
        }

        try (Socket socket = connected;
             BufferedReader in = new BufferedReader(
                 new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8))) {

            this.out = new BufferedWriter(
                new OutputStreamWriter(socket.getOutputStream(), StandardCharsets.UTF_8));

            sendHello();

            String line;
            while ((line = in.readLine()) != null) {
                if (line.contains("\"type\":\"ping\"")) {
                    send("{\"type\":\"pong\"}");
                } else if (line.contains("\"type\":\"hello_ack\"")) {
                    startHeartbeat();
                }
            }
        } catch (Exception exception) {
            AgentMain.log("Baglanti kapandi: " + exception.getMessage());
        } finally {
            running.set(false);
        }
    }

    private Socket connect() {
        for (int attempt = 0; attempt < 20 && running.get(); attempt++) {
            try {
                return new Socket(InetAddress.getLoopbackAddress(), port);
            } catch (Exception exception) {
                sleep(500);
            }
        }
        return null;
    }

    private void sendHello() {
        String hello = "{\"type\":\"hello\",\"token\":\"" + escape(token) + "\",\"pid\":"
            + ProcessHandle.current().pid()
            + ",\"agentVersion\":\"" + AgentMain.VERSION + "\"}";
        send(hello);
        AgentMain.log("El sikismasi gonderildi.");
    }

    private void startHeartbeat() {
        if (heartbeatStarted.compareAndSet(0, 1)) {
            AgentMain.log("El sikismasi kabul edildi; kalp atisi basliyor.");
            Thread thread = new Thread(this::heartbeatLoop, "toxido-ac-agent-heartbeat");
            thread.setDaemon(true);
            thread.start();
        }
    }

    private void heartbeatLoop() {
        while (running.get()) {
            send("{\"type\":\"heartbeat\",\"ts\":" + System.currentTimeMillis() + "}");
            sleep(5000);
        }
    }

    private synchronized void send(String json) {
        if (out == null) {
            return;
        }
        try {
            out.write(json);
            out.newLine();
            out.flush();
        } catch (Exception exception) {
            running.set(false);
        }
    }

    private static void sleep(long millis) {
        try {
            Thread.sleep(millis);
        } catch (InterruptedException exception) {
            Thread.currentThread().interrupt();
        }
    }

    private static String escape(String value) {
        return value.replace("\\", "\\\\").replace("\"", "\\\"");
    }
}

    }

        Map<String, String> options = parse(args);
        int port = Integer.parseInt(options.getOrDefault("port", "0"));
        String token = options.getOrDefault("token", "");

        thread.setDaemon(true);

        // Faz 2: instrumentation uzerinden sinif enstrumantasyonu ve

                options.put(part.substring(0, separator), part.substring(separator + 1));
            }
        }

package dev.toxido.anticheat.app;

import com.google.gson.JsonObject;
import com.google.gson.JsonParser;

import java.io.BufferedReader;
import java.io.BufferedWriter;
import java.io.Closeable;
import java.io.InputStreamReader;
import java.io.OutputStreamWriter;
import java.net.InetAddress;
import java.net.ServerSocket;
import java.net.Socket;
import java.nio.charset.StandardCharsets;
import java.util.UUID;
import java.util.concurrent.atomic.AtomicBoolean;

/**
 * Ajan ile uygulama arasindaki loopback IPC koprusu.
 * Uygulama sunucu tarafini acar; ajan baglanip el sikismasi yapar.
 */
public final class AgentBridge implements Closeable {
    public interface Listener {
        void onAgentReady();
        void onHeartbeat();
        void onDisconnected(String reason);
    }

    private final ServerSocket server;
    private final String token = UUID.randomUUID().toString();
    private final AtomicBoolean closed = new AtomicBoolean(false);
    private final AtomicBoolean disconnected = new AtomicBoolean(false);

    private volatile Socket socket;
    private volatile BufferedWriter out;
    private volatile Listener listener;

    public AgentBridge() throws Exception {
        this.server = new ServerSocket(0, 1, InetAddress.getLoopbackAddress());
    }

    public int port() {
        return server.getLocalPort();
    }

    public String token() {
        return token;
    }

    public void start(Listener listener) {
        this.listener = listener;
        Thread thread = new Thread(this::acceptLoop, "toxido-ac-bridge");
        thread.setDaemon(true);
        thread.start();
    }

    private void acceptLoop() {
        while (!closed.get()) {
            try {
                Socket candidate = server.accept();
                if (handle(candidate)) {
                    return;
                }
            } catch (Exception exception) {
                if (!closed.get()) {
                    notifyDisconnected("agent_connection_error");
                }
                return;
            }
        }
    }

    private boolean handle(Socket candidate) {
        Listener current = this.listener;
        try {
            candidate.setSoTimeout(30_000);
            BufferedReader in = new BufferedReader(
                new InputStreamReader(candidate.getInputStream(), StandardCharsets.UTF_8));
            BufferedWriter writer = new BufferedWriter(
                new OutputStreamWriter(candidate.getOutputStream(), StandardCharsets.UTF_8));

            String helloLine = in.readLine();
            if (helloLine == null) {
                closeQuietly(candidate);
                return false;
            }

            JsonObject hello = JsonParser.parseString(helloLine).getAsJsonObject();
            if (!"hello".equals(hello.get("type").getAsString())
                || !token.equals(hello.get("token").getAsString())) {
                closeQuietly(candidate);
                return false;
            }

            this.socket = candidate;
            this.out = writer;
            send("{\"type\":\"hello_ack\"}");

            if (current != null) {
                current.onAgentReady();
            }

            String line;
            while ((line = in.readLine()) != null) {
                JsonObject message = JsonParser.parseString(line).getAsJsonObject();
                String type = message.get("type").getAsString();
                if ("heartbeat".equals(type) && current != null) {
                    current.onHeartbeat();
                }
            }

            notifyDisconnected("agent_disconnected");
            return true;
        } catch (Exception exception) {
            closeQuietly(candidate);
            notifyDisconnected("agent_error");
            return true;
        }
    }

    public synchronized void send(String json) {
        if (out == null) {
            return;
        }
        try {
            out.write(json);
            out.newLine();
            out.flush();
        } catch (Exception ignored) {
            // Kopru kapanirken yazma hatasi normaldir.
        }
    }

    private void notifyDisconnected(String reason) {
        if (disconnected.compareAndSet(false, true)) {
            Listener current = this.listener;
            if (current != null) {
                current.onDisconnected(reason);
            }
        }
    }

    @Override
    public void close() {
        closed.set(true);
        closeQuietly(socket);
        try {
            server.close();
        } catch (Exception ignored) {
            // Zaten kapali olabilir.
        }
        notifyDisconnected("bridge_closed");
    }

    private static void closeQuietly(Socket socket) {
        if (socket != null) {
            try {
                socket.close();
            } catch (Exception ignored) {
                // Yoksay.
            }
        }
    }
}

package dev.toxido.anticheat.app;

import com.google.gson.Gson;
import com.google.gson.JsonObject;
import com.google.gson.JsonParser;

import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.io.IOException;
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.time.Duration;
import java.util.HexFormat;
import java.util.UUID;

/**
 * VPS API istemcisi. Her istegi HMAC-SHA256 ile imzalar.
 */
public final class ApiClient {
    public static final class ApiException extends Exception {
        private final int status;

        public ApiException(int status, String body) {
            super("API " + status + ": " + body);
            this.status = status;
        }

        public int status() {
            return status;
        }
    }

    public record StartResult(
        String sessionId,
        String token,
        int heartbeatIntervalMs,
        Long channelId
    ) {
    }

    private final Config config;
    private final HttpClient http;
    private final Gson gson = new Gson();

    public ApiClient(Config config) {
        this.config = config;
        this.http = HttpClient.newBuilder()
            .version(HttpClient.Version.HTTP_1_1)
            .connectTimeout(Duration.ofSeconds(10))
            .build();
    }

    public StartResult startSession(MinecraftProcess minecraft, String startedAt) throws Exception {
        JsonObject body = new JsonObject();
        body.addProperty("mc_name", minecraft.username());
        body.addProperty("mc_uuid", minecraft.uuid());
        body.addProperty("mc_version", minecraft.version());
        body.addProperty("agent_version", config.agentVersion);
        body.addProperty("device_id", config.deviceId());
        body.addProperty("started_at", startedAt);

        JsonObject response = post("/api/v1/session/start", gson.toJson(body), null, false);
        Long channelId = null;
        if (response.has("channel_id") && !response.get("channel_id").isJsonNull()) {
            channelId = response.get("channel_id").getAsLong();
        }
        int interval = response.has("heartbeat_interval_ms")
            ? response.get("heartbeat_interval_ms").getAsInt()
            : 5000;

        return new StartResult(
            response.get("session_id").getAsString(),
            response.get("token").getAsString(),
            interval,
            channelId
        );
    }

    public void heartbeat(String sessionId, String token) throws Exception {
        JsonObject body = new JsonObject();
        body.addProperty("session_id", sessionId);
        post("/api/v1/session/heartbeat", gson.toJson(body), token, true);
    }

    public void endSession(String sessionId, String token, String reason) throws Exception {
        JsonObject body = new JsonObject();
        body.addProperty("session_id", sessionId);
        body.addProperty("reason", reason);
        post("/api/v1/session/end", gson.toJson(body), token, true);
    }

    private JsonObject post(
        String path,
        String body,
        String bearer,
        boolean retryOnIoError
    ) throws Exception {
        int attempts = retryOnIoError ? 2 : 1;
        IOException lastIoError = null;

        for (int attempt = 1; attempt <= attempts; attempt++) {
            String timestamp = Long.toString(System.currentTimeMillis());
            String nonce = UUID.randomUUID().toString();
            String signature = sign(timestamp + "." + nonce + "." + body);

            HttpRequest.Builder builder = HttpRequest.newBuilder(
                    URI.create(config.apiBaseUrl + path))
                .timeout(Duration.ofSeconds(15))
                .header("Content-Type", "application/json")
                .header("X-AC-Key", config.apiKey)
                .header("X-AC-Timestamp", timestamp)
                .header("X-AC-Nonce", nonce)
                .header("X-AC-Signature", signature)
                .POST(HttpRequest.BodyPublishers.ofString(body, StandardCharsets.UTF_8));

            if (bearer != null) {
                builder.header("Authorization", "Bearer " + bearer);
            }

            try {
                HttpResponse<String> response = http.send(
                    builder.build(),
                    HttpResponse.BodyHandlers.ofString(StandardCharsets.UTF_8)
                );

                if (response.statusCode() / 100 != 2) {
                    throw new ApiException(response.statusCode(), response.body());
                }

                return JsonParser.parseString(response.body()).getAsJsonObject();
            } catch (IOException exception) {
                lastIoError = exception;
                if (attempt < attempts) {
                    try {
                        Thread.sleep(250);
                    } catch (InterruptedException interrupted) {
                        Thread.currentThread().interrupt();
                        throw exception;
                    }
                }
            }
        }

        throw lastIoError;
    }

    private String sign(String payload) throws Exception {
        Mac mac = Mac.getInstance("HmacSHA256");
        mac.init(new SecretKeySpec(
            config.apiSecret.getBytes(StandardCharsets.UTF_8), "HmacSHA256"));
        return HexFormat.of().formatHex(
            mac.doFinal(payload.getBytes(StandardCharsets.UTF_8)));
    }
}

```java
package dev.toxido.anticheat.app;

import java.nio.file.Path;
import java.time.Instant;
import java.util.concurrent.CountDownLatch;
import java.util.concurrent.Executors;
import java.util.concurrent.ScheduledExecutorService;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicBoolean;
import java.util.concurrent.atomic.AtomicLong;
import java.util.concurrent.atomic.AtomicReference;

/**
 * Faz 1 akisi:
 * Minecraft bekle -> ilk oturuma attach ol -> ajan el sikismasi -> API oturumu ->
 * kalp atisi -> oyun kapaninca bitir. Tek seferlik; yeniden baglanmaz.
 */
public final class AppController implements Runnable, AgentBridge.Listener {
    private final Config config;
    private final Reporter reporter;
    private final ApiClient api;

    private final AtomicBoolean stopped = new AtomicBoolean(false);
    private final AtomicBoolean ending = new AtomicBoolean(false);
    private final AtomicLong lastAgentHeartbeat = new AtomicLong(0);
    private final AtomicReference<String> endReason = new AtomicReference<>("unknown");
    private final CountDownLatch agentReady = new CountDownLatch(1);
    private final CountDownLatch sessionEnded = new CountDownLatch(1);

    private volatile AgentBridge bridge;
    private volatile String sessionId;
    private volatile String sessionToken;
    private volatile long minecraftPid;
    private volatile ScheduledExecutorService scheduler;

    public AppController(Config config, Reporter reporter) {
        this.config = config;
        this.reporter = reporter;
        this.api = new ApiClient(config);
    }

    @Override
    public void run() {
        reporter.status("Minecraft bekleniyor...", "Minecraft acilinca otomatik baglanacak.");
        reporter.log("Toxido AC " + config.agentVersion + " basladi.");

        MinecraftProcess minecraft = null;
        while (!stopped.get() && minecraft == null) {
            minecraft = MinecraftProcess.find().orElse(null);
            if (minecraft == null) {
                sleep(1000);
            }
        }

        if (minecraft == null) {
            return;
        }

        minecraftPid = minecraft.pid();
        reporter.status(
            "Minecraft bulundu",
            minecraft.username() + " • " + safe(minecraft.version())
        );
        reporter.log("Minecraft PID " + minecraft.pid() + " (" + minecraft.username() + ")");

        try {
            connect(minecraft);
        } catch (Exception exception) {
            reporter.log("HATA: " + exception.getMessage());
            if ("unknown".equals(endReason.get())) {
                endReason.set("attach_failed");
            }
        } finally {
            cleanup();
        }

        reporter.status(
            "Oturum kapandi",
            "Sebep: " + endReason.get() + ". Yeni oturum icin uygulamayi yeniden acin."
        );
        reporter.log("Oturum kapandi: " + endReason.get());
    }

    private void connect(MinecraftProcess minecraft) throws Exception {
        Path agentJar = config.resolveAgentJar();
        reporter.log("Ajan: " + agentJar);

        bridge = new AgentBridge();
        bridge.start(this);

        reporter.status("Baglaniyor...", "Ajan yukleniyor (PID " + minecraft.pid() + ")");
        String agentArgs = "port=" + bridge.port() + ";token=" + bridge.token();
        AttachService.loadAgent(minecraft.pid(), agentJar, agentArgs);

        if (!agentReady.await(config.attachTimeoutMs, TimeUnit.MILLISECONDS)) {
            throw new IllegalStateException(
                "Ajan " + config.attachTimeoutMs + " ms icinde baglanmadi");
        }
        reporter.log("Ajan baglandi.");

        ApiClient.StartResult start = api.startSession(minecraft, Instant.now().toString());
        this.sessionId = start.sessionId();
        this.sessionToken = start.token();

        reporter.status(
            "Oturum acik",
            minecraft.username() + " • " + safe(minecraft.version())
                + " • Discord kanali: " + (start.channelId() == null ? "-" : start.channelId())
        );
        reporter.log("Oturum: " + start.sessionId());
        reporter.log("Discord kanal id: " + start.channelId());

        lastAgentHeartbeat.set(System.currentTimeMillis());
        startScheduler();
        watchMinecraftProcess(minecraft);

        sessionEnded.await();
    }

    private void startScheduler() {
        scheduler = Executors.newSingleThreadScheduledExecutor(runnable -> {
            Thread thread = new Thread(runnable, "toxido-ac-heartbeat");
            thread.setDaemon(true);
            return thread;
        });

        int interval = config.heartbeatIntervalMs;
        scheduler.scheduleAtFixedRate(() -> {
            try {
                if (sessionId != null && sessionToken != null) {
                    api.heartbeat(sessionId, sessionToken);
                }
            } catch (ApiClient.ApiException exception) {
                if (exception.status() == 409 && ending.get()) {
                    return;
                }
                reporter.log("Heartbeat hatasi: " + exception.getMessage());
            } catch (Exception exception) {
                reporter.log("Heartbeat hatasi: " + exception.getMessage());
            }
        }, interval, interval, TimeUnit.MILLISECONDS);

        scheduler.scheduleAtFixedRate(() -> {
            long last = lastAgentHeartbeat.get();
            if (last > 0 && System.currentTimeMillis() - last > config.agentTimeoutMs) {
                triggerEnd("agent_silent");
            }
        }, 5, 5, TimeUnit.SECONDS);
    }

    private void watchMinecraftProcess(MinecraftProcess minecraft) {
        ProcessHandle.of(minecraft.pid()).ifPresentOrElse(
            handle -> handle.onExit().thenRun(() -> triggerEnd("game_closed")),
            () -> triggerEnd("game_closed")
        );
    }

    public void triggerEnd(String reason) {
        if (!ending.compareAndSet(false, true)) {
            return;
        }

        stopped.set(true);
        endReason.set(reason);
        reporter.log("Oturum bitiriliyor: " + reason);

        ScheduledExecutorService currentScheduler = scheduler;
        if (currentScheduler != null) {
            currentScheduler.shutdownNow();
        }

        if (sessionId != null && sessionToken != null) {
            try {
                api.endSession(sessionId, sessionToken, reason);
            } catch (Exception exception) {
                reporter.log("End istegi hatasi: " + exception.getMessage());
            }
        }

        cleanup();
        sessionEnded.countDown();
    }

    @Override
    public void onAgentReady() {
        lastAgentHeartbeat.set(System.currentTimeMillis());
        reporter.log("Ajan el sikismasi tamam.");
        agentReady.countDown();
    }

    @Override
    public void onHeartbeat() {
        lastAgentHeartbeat.set(System.currentTimeMillis());
    }

    @Override
    public void onDisconnected(String reason) {
        if (sessionId == null) {
            return;
        }

        String effectiveReason = reason;
        if (("agent_disconnected".equals(reason) || "agent_error".equals(reason))
            && minecraftPid > 0) {
            // Oyun kapanirken ajan soketi once kopabilir; kisa bir kontrolle
            // bunu normal oyun kapanisi olarak siniflandir.
            sleep(500);
            if (!ProcessHandle.of(minecraftPid)
                .map(ProcessHandle::isAlive)
                .orElse(false)) {
                effectiveReason = "game_closed";
            }
        }

        triggerEnd(effectiveReason);
    }

    private void cleanup() {
        AgentBridge currentBridge = bridge;
        if (currentBridge != null) {
            currentBridge.close();
        }

        ScheduledExecutorService currentScheduler = scheduler;
        if (currentScheduler != null) {
            currentScheduler.shutdownNow();
        }
    }

    private static void sleep(long millis) {
        try {
            Thread.sleep(millis);
        } catch (InterruptedException exception) {
            Thread.currentThread().interrupt();
        }
    }

    private static String safe(String value) {
        return value == null || value.isBlank() ? "?" : value;
    }

                widths[glyph] = Math.max(widths[glyph], line.length());

                    line.append(" ".repeat(spacing));

                line.append(part);
                line.append(" ".repeat(widths[glyph] - part.length()));
            }

            "ac-agent/target/ac-agent.jar",
            "../ac-agent/target/ac-agent.jar",
            "ac-agent.jar"
        };
        for (String candidate : candidates) {
            Path path = Path.of(candidate).toAbsolutePath().normalize();
            if (Files.exists(path)) {
                return path;
            }
        }

            Path appDirectory = Path.of(
                Config.class.getProtectionDomain().getCodeSource().getLocation().toURI()
            ).getParent();
            Path nextToJar = appDirectory.resolve("ac-agent.jar");
            if (Files.exists(nextToJar)) {
                return nextToJar;

            Path inRepository = appDirectory.resolve("../ac-agent/target/ac-agent.jar").normalize();
            if (Files.exists(inRepository)) {
                return inRepository;
            }

            // Asagidaki hata daha aciklayici.

 * boyutlari tespit eder ve Jansi ile sanal terminali etkinlestirir.
 */
final class ConsoleOutput implements AutoCloseable {
    private static final Pattern CODE_PAGE = Pattern.compile("(\\d{3,5})");

    private final PrintStream out;
    private final boolean unicode;
    private final int width;
    private final int height;
    private final AnsiColors colors;
    private final int originalCodePage;
    private final boolean jansiInstalled;
    private boolean closed;

    private ConsoleOutput(
        PrintStream out,
        boolean unicode,
        int width,
        int height,
        AnsiColors colors,
        int originalCodePage,
        boolean jansiInstalled
    ) {
        this.out = out;
        this.unicode = unicode;
        this.width = width;
        this.height = height;
        this.colors = colors;
        this.originalCodePage = originalCodePage;
        this.jansiInstalled = jansiInstalled;
    }

    static ConsoleOutput open() {
        boolean jansiInstalled = false;
        try {
            AnsiConsole.systemInstall();
            jansiInstalled = true;
        } catch (Throwable ignored) {
            // Jansi olmadan duz ANSI ile devam edilir.
        }

        AnsiColors colors = AnsiColors.Colors16;
        try {
            AnsiPrintStream jansiOut = AnsiConsole.out();
            if (jansiOut != null && jansiOut.getColors() != null) {
                colors = jansiOut.getColors();
            }
        } catch (Throwable ignored) {
            // Renk modu tespit edilemezse 16 renk kullanilir.
        }

        int originalCodePage = isWindows() ? queryCodePage() : 65001;
        int currentCodePage = originalCodePage;
        if (isWindows() && originalCodePage != 65001) {
            setCodePage(65001);
            currentCodePage = queryCodePage();
        }

        boolean unicode = currentCodePage == 65001 || stdoutIsUtf8();
        int width = detectWidth();
        int height = detectHeight();

        PrintStream utf8 = new PrintStream(
            new FileOutputStream(FileDescriptor.out), true, StandardCharsets.UTF_8);

        return new ConsoleOutput(
            utf8, unicode, width, height, colors, originalCodePage, jansiInstalled);
    }

    PrintStream out() {
        return out;
    }

    boolean unicode() {
        return unicode;
    }

    int width() {
        return width;
    }

    int height() {
        return height;
    }

    AnsiColors colors() {
        return colors;
    }

    @Override
    public void close() {
        if (closed) {
            return;
        }
        closed = true;
        try {
            out.flush();
        } catch (Exception ignored) {
            // Konsol kapanmis olabilir.
        }
        if (isWindows() && originalCodePage > 0 && originalCodePage != 65001) {
            setCodePage(originalCodePage);
        }
        if (jansiInstalled) {
            try {
                AnsiConsole.systemUninstall();
            } catch (Throwable ignored) {
                // Jansi kurulu degildiyse yoksay.
            }
        }
    }

    private static int detectWidth() {
        int width = 0;
        try {
            width = AnsiConsole.getTerminalWidth();
        } catch (Throwable ignored) {
            // Asagidaki ortam degiskenlerine bakilir.
        }
        if (width <= 0) {
            width = intEnv("COLUMNS");
        }
        if (width <= 0) {
            width = 100;
        }
        return clamp(width, 24, 160);
    }

    private static int detectHeight() {
        int height = intEnv("LINES");
        if (height <= 0) {
            height = 30;
        }
        return clamp(height, 16, 50);
    }

    private static int intEnv(String name) {
        String value = System.getenv(name);
        if (value == null || value.isBlank()) {
            return 0;
        }
        try {
            return Integer.parseInt(value.trim());
        } catch (NumberFormatException ignored) {
            return 0;
        }
    }

    private static int queryCodePage() {
        try {
            ProcessBuilder builder = new ProcessBuilder("cmd.exe", "/c", "chcp");
            builder.redirectErrorStream(true);
            Process process = builder.start();
            byte[] bytes = process.getInputStream().readAllBytes();
            process.waitFor(2, TimeUnit.SECONDS);
            Matcher matcher = CODE_PAGE.matcher(new String(bytes, StandardCharsets.ISO_8859_1));
            int codePage = 0;
            while (matcher.find()) {
                codePage = Integer.parseInt(matcher.group(1));
            }
            return codePage;
        } catch (Exception ignored) {
            return 0;
        }
    }

    private static void setCodePage(int codePage) {
        try {
            ProcessBuilder builder = new ProcessBuilder(
                "cmd.exe", "/c", "chcp", Integer.toString(codePage));
            builder.redirectOutput(ProcessBuilder.Redirect.DISCARD);
            builder.redirectErrorStream(true);
            Process process = builder.start();
            process.waitFor(3, TimeUnit.SECONDS);
        } catch (Exception ignored) {
            // Kod sayfasi degistirilemezse ASCII logoya dusulur.
        }
    }

    private static boolean stdoutIsUtf8() {
        String encoding = System.getProperty("stdout.encoding", "");
        if (encoding.isBlank()) {
            encoding = System.getProperty("sun.stdout.encoding", "");
        }
        return encoding.toLowerCase(Locale.ROOT).replace("-", "").contains("utf8");
    }

    private static boolean isWindows() {
        return System.getProperty("os.name", "")
            .toLowerCase(Locale.ROOT)
            .contains("win");
    }

    private static int clamp(int value, int minimum, int maximum) {
        return Math.max(minimum, Math.min(maximum, value));
    }
}

package dev.toxido.anticheat.app;

import com.sun.tools.attach.VirtualMachine;
import com.sun.tools.attach.VirtualMachineDescriptor;

import java.util.Locale;
import java.util.Objects;
import java.util.Optional;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * Calisan Minecraft istemcisini (Java Edition) temsil eder.
 *
 * Tespit icin ProcessHandle yerine JVM Attach API'nin VirtualMachine.list()
 * kullanilir; Windows'ta ProcessHandle harici sureclerin komut satirini
 * vermedigi icin bu yol daha guvenilirdir. Boylece sadece attach edilebilir
 * JVM'ler listelenir ve modlu istemciler de gorulebilir.
 */
public record MinecraftProcess(
    long pid,
    String username,
    String uuid,
    String version,
    String displayName
) {
    private static final Pattern USERNAME_PATTERN =
        Pattern.compile("--username\\s+(?:\"([^\"]*)\"|(\\S+))");
    private static final Pattern UUID_PATTERN =
        Pattern.compile("--uuid\\s+(?:\"([^\"]*)\"|(\\S+))");
    private static final Pattern VERSION_PATTERN =
        Pattern.compile("--version\\s+(?:\"([^\"]*)\"|(\\S+))");

    private static final String[] KNOWN_MAIN_CLASSES = {
        "net.minecraft.client.main.main",
        "net.fabricmc.loader.impl.launch.knot.knotclient",
        "org.quiltmc.loader.impl.launch.knot.knotclient",
        "cpw.mods.bootstraplauncher.bootstraplauncher",
        "net.neoforged.bootstrap.bootstraplauncher",
        "net.minecraftforge.bootstrap.forgebootstrap"
    };

    public static Optional<MinecraftProcess> find() {
        try {
            long selfPid = ProcessHandle.current().pid();
            return VirtualMachine.list().stream()
                .filter(descriptor -> !Long.toString(selfPid).equals(descriptor.id()))
                .filter(descriptor -> isMinecraft(descriptor.displayName()))
                .map(descriptor -> parse(descriptor))
                .filter(Objects::nonNull)
                .findFirst();
        } catch (Exception exception) {
            return Optional.empty();
        }
    }

    private static boolean isMinecraft(String displayName) {
        if (displayName == null || displayName.isBlank()) {
            return false;
        }
        String lower = displayName.toLowerCase(Locale.ROOT);
        for (String mainClass : KNOWN_MAIN_CLASSES) {
            if (lower.contains(mainClass)) {
                return true;
            }
        }
        // Jar uzerinden baslatilan istemciler icin yedek kontrol.
        return lower.contains("--username") && lower.contains("--version");
    }

    private static MinecraftProcess parse(VirtualMachineDescriptor descriptor) {
        String displayName = descriptor.displayName();
        String username = value(displayName, USERNAME_PATTERN);
        if (username == null || username.isBlank()) {
            return null;
        }
        try {
            return new MinecraftProcess(
                Long.parseLong(descriptor.id()),
                username,
                value(displayName, UUID_PATTERN),
                value(displayName, VERSION_PATTERN),
                displayName
            );
        } catch (NumberFormatException exception) {
            return null;
        }
    }

    private static String value(String displayName, Pattern pattern) {
        Matcher matcher = pattern.matcher(displayName);
        if (!matcher.find()) {
            return null;
        }
        return matcher.group(1) != null ? matcher.group(1) : matcher.group(2);
    }
}

    }

    public static ServiceLock acquire() throws IOException {
        Path path = LogReporter.appDataDirectory().resolve("service.lock");
        Files.createDirectories(path.getParent());

        FileChannel channel = FileChannel.open(
            path,
            StandardOpenOption.CREATE,
            StandardOpenOption.WRITE
        );

        try {
            FileLock lock = channel.tryLock();
            if (lock == null) {
                channel.close();
                return null;
            }
            return new ServiceLock(channel, lock);
        } catch (OverlappingFileLockException exception) {
            channel.close();
            return null;
        }
    }

    @Override
    public void close() {
        try {
            lock.release();
        } catch (IOException ignored) {
            // Kilit zaten birakilmis olabilir.
        }
        try {
            channel.close();
        } catch (IOException ignored) {
            // Kanal zaten kapanmis olabilir.
        }
    }
}

    private static final class SideOrb {
        private final int centerColumn;
        private final int centerRow;
        private final int radiusX;
        private final int radiusY;
        private final int phaseOffset;
        private final int direction;
        private final int[][] points;

        private SideOrb(
            int centerColumn,
            int centerRow,
            int radiusX,
            int radiusY,
            int phaseOffset,
            int direction
        ) {
            this.centerColumn = centerColumn;
            this.centerRow = centerRow;
            this.radiusX = radiusX;
            this.radiusY = radiusY;
            this.phaseOffset = phaseOffset;
            this.direction = direction;
            this.points = buildPoints();
        }

        private int[][] buildPoints() {
            List<int[]> found = new ArrayList<>();
            boolean[][] seen = new boolean[radiusY * 2 + 1][radiusX * 2 + 1];
            for (int step = 0; step < 120; step++) {
                double angle = Math.PI * 2.0 * step / 120.0;
                int x = (int) Math.round(radiusX * Math.cos(angle));
                int y = (int) Math.round(radiusY * Math.sin(angle));
                int row = y + radiusY;
                int column = x + radiusX;
                if (!seen[row][column]) {
                    seen[row][column] = true;
                    found.add(new int[] {x, y});
                }
            }
            return found.toArray(new int[0][]);
        }

        private void draw(PrintStream out, Palette palette, long elapsedMs) {
            int count = points.length;
            if (count == 0) {
                return;
            }
            int step = (int) (elapsedMs / 75L);
            int head = Math.floorMod(step * direction + phaseOffset, count);

            for (int index = 0; index < count; index++) {
                int distance = Math.floorMod(direction * (head - index), count);
                char glyph;
                String color;
                if (distance == 0) {
                    glyph = '●';
                    color = palette.scan();
                } else if (distance <= 2) {
                    glyph = '•';
                    color = palette.rain(3);
                } else if (distance <= 5) {
                    glyph = '·';
                    color = palette.rain(2);
                } else {
                    glyph = '○';
                    color = palette.ghost();
                }
                out.print(cursor(
                    centerRow + points[index][1],
                    centerColumn + points[index][0])
                    + color
                    + glyph
                    + palette.foregroundReset());
            }
        }
    }

    private static final class Rain {
        private final int width;
        private final int height;
        private final char[][] chars;
        private final byte[][] shades;
        private final byte[][] previous;
        private final Column[] columns;
        private final Random random = new Random();

        private Rain(int width, int height) {
            this.width = width;
            this.height = height;
            this.chars = new char[height][width];
            this.shades = new byte[height][width];
            this.previous = new byte[height][width];
            this.columns = new Column[width];
            for (int column = 0; column < width; column++) {
                this.columns[column] = new Column();
                reset(this.columns[column], true);
            }
        }

        private void update() {
            for (int row = 0; row < height; row++) {
                System.arraycopy(shades[row], 0, previous[row], 0, width);
            }

            for (int column = 0; column < width; column++) {
                Column state = columns[column];
                state.head += state.speed;
                if (state.head - state.length > height + 2) {
                    reset(state, false);
                }

                for (int row = 0; row < height; row++) {
                    double distance = state.head - row;
                    int shade = 0;
                    if (distance >= 0 && distance < state.length) {
                        shade = 4 - (int) (distance * 4.0 / state.length);
                        if (shade < 1) {
                            shade = 1;
                        }
                    }

                    if (shade > 0 && shades[row][column] == 0) {
                        chars[row][column] = randomGlyph();
                    } else if (shade == 0) {
                        chars[row][column] = ' ';
                    }
                    shades[row][column] = (byte) shade;
                }
            }
        }

        private void render(PrintStream out, Palette palette, int top, int left) {
            for (int row = 0; row < height; row++) {
                int runStart = -1;
                int runShade = -1;
                StringBuilder run = new StringBuilder();

                for (int column = 0; column < width; column++) {
                    int shade = shades[row][column];
                    if (shade != previous[row][column]) {
                        if (runStart >= 0
                            && column == runStart + run.length()
                            && shade == runShade) {
                            run.append(chars[row][column]);
                        } else {
                            flush(out, palette, top + row, left + runStart, runShade, run);
                            runStart = column;
                            runShade = shade;
                            run.setLength(0);
                            run.append(chars[row][column]);
                        }
                    } else {
                        flush(out, palette, top + row, left + runStart, runShade, run);
                        runStart = -1;
                        run.setLength(0);
                    }
                }

                flush(out, palette, top + row, left + runStart, runShade, run);
            }
        }

        private static void flush(
            PrintStream out,
            Palette palette,
            int row,
            int column,
            int shade,
            StringBuilder run
        ) {
            if (column < 0 || run.length() == 0) {
                return;
            }
            String color = shade == 0 ? palette.background() : palette.rain(shade);
            out.print(cursor(row, column)
                + color
                + run
                + palette.foregroundReset());
        }

        private void reset(Column column, boolean initial) {
            if (initial) {
                if (random.nextBoolean()) {
                    column.head = random.nextDouble() * height;
                } else {
                    column.head = -random.nextDouble() * height * 0.7 - 1;
                }
            } else {
                column.head = -1 - random.nextInt(Math.max(1, height / 2));
            }
            column.speed = 0.45 + random.nextDouble() * 0.85;
            column.length = 7 + random.nextInt(12);
        }

        private char randomGlyph() {
            return MATRIX_GLYPHS.charAt(random.nextInt(MATRIX_GLYPHS.length()));
        }

        private static final class Column {
            private double head;
            private double speed;
            private int length;
        }
    }
}

public final class TerminalSplash {
    private final AtomicBoolean running = new AtomicBoolean(true);
    private final LogReporter launcherLog =
        new LogReporter(LogReporter.appDataDirectory().resolve("launcher.log"));
    private final boolean preview;

    public void run() {
        ConsoleOutput output = ConsoleOutput.open();
        console = output;

        SplashScreen splash = new SplashScreen(output);
        screen = splash;

        Runtime.getRuntime().addShutdownHook(
            new Thread(this::restore, "toxido-ac-restore"));

        try {
            splash.start();
            startInput();
            if (!preview) {
                startService();
            }

            while (running.get()) {
                String error = serviceError;
                if (error != null) {
                    splash.setError(error);
                }
                splash.render();
                Thread.sleep(45L);
            }
        } catch (InterruptedException exception) {
            Thread.currentThread().interrupt();
        } finally {
            restore();
        }
    }

    private void startInput() {
        Thread input = new Thread(() -> {
            try {
                while (running.get()) {
                    int value = System.in.read();
                    if (value == -1) {
                        running.set(false);
                        return;
                    }
                    if (value == '\n' || value == '\r') {
                        running.set(false);
                        return;
                    }
                }
            } catch (IOException ignored) {
                // Konsol yoksa pencere kapanana kadar devam edilir.
            }
        }, "toxido-ac-input");
        input.setDaemon(true);
        input.start();
    }

    private void startService() {
        try {
            Path appPath = locateAppPath();
            Path javaHome = Path.of(System.getProperty("java.home"));
            Path java = javaHome.resolve("bin").resolve(isWindows() ? "javaw.exe" : "java");
            if (!Files.exists(java)) {
                java = javaHome.resolve("bin").resolve("java");
            }
            if (!Files.exists(java)) {
                throw new IOException("Java calistirilabilir dosyasi bulunamadi: " + java);
            }

            List<String> command = new ArrayList<>();
            command.add(java.toString());

from __future__ import annotations

import json
from datetime import datetime, timezone
from pathlib import Path
from typing import Any

import aiosqlite


def utcnow_iso() -> str:
    return datetime.now(timezone.utc).isoformat(timespec="seconds")


SCHEMA = """
CREATE TABLE IF NOT EXISTS sessions (
    id TEXT PRIMARY KEY,
    token_hash TEXT NOT NULL,
    mc_name TEXT NOT NULL,
    base_name TEXT NOT NULL,
    mc_uuid TEXT,
    mc_version TEXT,
    agent_version TEXT,
    device_id TEXT,
    status TEXT NOT NULL,
    channel_id INTEGER,
    channel_name TEXT,
    log_index INTEGER,
    started_at TEXT NOT NULL,
    last_seen_at TEXT NOT NULL,
    ended_at TEXT,
    end_reason TEXT,
    error TEXT
);

CREATE INDEX IF NOT EXISTS idx_sessions_status ON sessions(status);
CREATE INDEX IF NOT EXISTS idx_sessions_base ON sessions(base_name);

CREATE TABLE IF NOT EXISTS events (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id TEXT NOT NULL,
    type TEXT NOT NULL,
    payload TEXT,
    created_at TEXT NOT NULL,
    FOREIGN KEY(session_id) REFERENCES sessions(id)
);
"""


class Database:
    def __init__(self, path: Path) -> None:
        self.path = path
        self.conn: aiosqlite.Connection | None = None

    async def connect(self) -> None:
        self.path.parent.mkdir(parents=True, exist_ok=True)
        self.conn = await aiosqlite.connect(self.path)
        self.conn.row_factory = aiosqlite.Row
        await self.conn.execute("PRAGMA journal_mode=WAL")
        await self.conn.execute("PRAGMA foreign_keys=ON")
        await self.conn.executescript(SCHEMA)
        await self.conn.commit()

    async def close(self) -> None:
        if self.conn is not None:
            await self.conn.close()
            self.conn = None

    async def create_session(self, data: dict[str, Any]) -> None:
        assert self.conn is not None
        await self.conn.execute(
            """
            INSERT INTO sessions
                (id, token_hash, mc_name, base_name, mc_uuid, mc_version,
                 agent_version, device_id, status, started_at, last_seen_at)
            VALUES (?, ?, ?, ?, ?, ?, ?, ?, 'active', ?, ?)
            """,
            (
                data["id"],
                data["token_hash"],
                data["mc_name"],
                data["base_name"],
                data.get("mc_uuid"),
                data.get("mc_version"),
                data.get("agent_version"),
                data.get("device_id"),
                data["started_at"],
                data["last_seen_at"],
            ),
        )
        await self.conn.commit()

    async def get_session(self, session_id: str) -> aiosqlite.Row | None:
        assert self.conn is not None
        async with self.conn.execute(
            "SELECT * FROM sessions WHERE id = ?", (session_id,)
        ) as cursor:
            return await cursor.fetchone()

    async def active_sessions(self) -> list[aiosqlite.Row]:
        assert self.conn is not None
        async with self.conn.execute(
            "SELECT * FROM sessions WHERE status = 'active'"
        ) as cursor:
            return list(await cursor.fetchall())

    async def active_sessions_for_name(self, mc_name: str) -> list[aiosqlite.Row]:
        assert self.conn is not None
        async with self.conn.execute(
            """
            SELECT * FROM sessions
             WHERE status = 'active' AND lower(mc_name) = lower(?)
             ORDER BY started_at DESC
            """,
            (mc_name,),
        ) as cursor:
            return list(await cursor.fetchall())

    async def reuse_session(
        self,
        session_id: str,
        token_hash_value: str,
        data: dict[str, Any],
        when: str,
    ) -> None:
        assert self.conn is not None
        await self.conn.execute(
            """
            UPDATE sessions
               SET token_hash = ?, mc_uuid = ?, mc_version = ?,
                   agent_version = ?, device_id = ?, last_seen_at = ?
             WHERE id = ? AND status = 'active'
            """,
            (
                token_hash_value,
                data.get("mc_uuid"),
                data.get("mc_version"),
                data.get("agent_version"),
                data.get("device_id"),
                when,
                session_id,
            ),
        )
        await self.conn.commit()

    async def touch(self, session_id: str, when: str) -> None:
        assert self.conn is not None
        await self.conn.execute(
            "UPDATE sessions SET last_seen_at = ? WHERE id = ? AND status = 'active'",
            (when, session_id),
        )
        await self.conn.commit()

    async def finish_if_active(
        self, session_id: str, status: str, reason: str, when: str
    ) -> bool:
        assert self.conn is not None
        cursor = await self.conn.execute(
            """
            UPDATE sessions
               SET status = ?, end_reason = ?, ended_at = ?
             WHERE id = ? AND status = 'active'
            """,
            (status, reason, when, session_id),
        )
        await self.conn.commit()
        return cursor.rowcount == 1

    async def set_channel(
        self, session_id: str, channel_id: int, channel_name: str
    ) -> None:
        assert self.conn is not None
        await self.conn.execute(
            "UPDATE sessions SET channel_id = ?, channel_name = ? WHERE id = ?",
            (channel_id, channel_name, session_id),
        )
        await self.conn.commit()

    async def set_log_index(
        self, session_id: str, log_index: int, channel_name: str
    ) -> None:
        assert self.conn is not None
        await self.conn.execute(
            "UPDATE sessions SET log_index = ?, channel_name = ? WHERE id = ?",
            (log_index, channel_name, session_id),
        )
        await self.conn.commit()

    async def set_error(self, session_id: str, error: str) -> None:
        assert self.conn is not None
        await self.conn.execute(
            "UPDATE sessions SET error = ? WHERE id = ?", (error, session_id)
        )
        await self.conn.commit()

    async def next_log_index(self, base_name: str) -> int:
        assert self.conn is not None
        async with self.conn.execute(
            "SELECT COALESCE(MAX(log_index), 0) AS m FROM sessions WHERE base_name = ?",
            (base_name,),
        ) as cursor:
            row = await cursor.fetchone()
        return int(row["m"]) + 1

    async def record_event(
        self, session_id: str, event_type: str, payload: dict | None
    ) -> None:
        assert self.conn is not None
        await self.conn.execute(
            "INSERT INTO events (session_id, type, payload, created_at) VALUES (?, ?, ?, ?)",
            (session_id, event_type, json.dumps(payload or {}, ensure_ascii=False), utcnow_iso()),
        )
        await self.conn.commit()

async def _timeout_loop(app: FastAPI) -> None:
    settings = app.state.settings
    database: Database = app.state.db
    channels: ChannelManager = app.state.channels

    while True:
        await asyncio.sleep(10)
        try:
            rows = await database.active_sessions()
            now = datetime.now(timezone.utc)
            for row in rows:
                last_seen = datetime.fromisoformat(row["last_seen_at"])
                if last_seen.tzinfo is None:
                    last_seen = last_seen.replace(tzinfo=timezone.utc)
                idle = (now - last_seen).total_seconds()
                if idle <= settings.heartbeat_timeout_seconds:
                    continue

                won = await database.finish_if_active(
                    row["id"], "lost", "heartbeat_timeout", utcnow_iso()
                )
                if not won:

                log_index = await database.next_log_index(row["base_name"])
                try:
                    name = await channels.archive_session_channel(
                        dict(row), log_index, "heartbeat_timeout"
                    )
                    await database.set_log_index(row["id"], log_index, name)
                except Exception:
                    log.exception("Timeout arsivleme hatasi: %s", row["id"])

                log.warning(
                    "Oturum zaman asimi: %s (%s) %.0f sn",
                    row["id"],
                    row["mc_name"],
                    idle,

    database = _db(request)
    row = await database.get_session(session_id)
    if row is None:
        raise HTTPException(status_code=404, detail="Oturum bulunamadi")

    header = request.headers.get("Authorization", "")
    if not header.startswith("Bearer "):
        raise HTTPException(status_code=401, detail="Oturum token'i gerekli")

@router.post("/heartbeat")
async def heartbeat(payload: HeartbeatRequest, request: Request) -> dict:
    row = await _authenticate(request, payload.session_id)
    if row["status"] != "active":
        raise HTTPException(status_code=409, detail="Oturum aktif degil")
    await _db(request).touch(payload.session_id, utcnow_iso())
    return {"ok": True}


@router.post("/end")
async def end_session(payload: SessionEndRequest, request: Request) -> dict:
    row = await _authenticate(request, payload.session_id)
    database = _db(request)

    if row["status"] != "active":
        return {"ok": True, "already_closed": True}

    won = await database.finish_if_active(
        payload.session_id, "ended", payload.reason, utcnow_iso()
    )
    if not won:
        return {"ok": True, "already_closed": True}

    log_index = await database.next_log_index(row["base_name"])
    try:
        name = await _channels(request).archive_session_channel(
            dict(row), log_index, payload.reason
        )
        await database.set_log_index(payload.session_id, log_index, name)
    except Exception:
        log.exception("Kanal arsivlenemedi: %s", payload.session_id)

    log.info(
        "Oturum kapandi: %s sebep=%s log=%s-%s",
        payload.session_id,
        payload.reason,
        row["base_name"],
        log_index,
    )
    return {"ok": True, "log_index": log_index}


@router.post("/event")
async def session_event(payload: EventRequest, request: Request) -> dict:
    await _authenticate(request, payload.session_id)
    await _db(request).record_event(payload.session_id, payload.type, payload.payload)
    return {"ok": True}

```py
from __future__ import annotations

import hashlib
import hmac
import secrets
import time

from fastapi import Depends, HTTPException, Request

from .config import Settings, get_settings

# nonce -> timestamp(ms). Kucuk bir bellek ici replay korumasi.
_seen_nonces: dict[str, int] = {}


def new_session_token() -> str:
    return secrets.token_urlsafe(32)


def token_hash(token: str) -> str:
    return hashlib.sha256(token.encode("utf-8")).hexdigest()


def _cleanup_nonces(now_ms: int) -> None:
    cutoff = now_ms - 600_000
    for nonce, seen_at in list(_seen_nonces.items()):
        if seen_at < cutoff:
            del _seen_nonces[nonce]


async def verify_hmac(
    request: Request, settings: Settings = Depends(get_settings)
) -> None:
    body = await request.body()

    key = request.headers.get("X-AC-Key", "").strip()
    timestamp = request.headers.get("X-AC-Timestamp", "").strip()
    nonce = request.headers.get("X-AC-Nonce", "").strip()
    signature = request.headers.get("X-AC-Signature", "").strip()

    if not all((key, timestamp, nonce, signature)):
        raise HTTPException(status_code=401, detail="Imza basliklari eksik")

    if not hmac.compare_digest(key, settings.api_key):
        raise HTTPException(status_code=401, detail="Gecersiz API anahtari")

    try:
        ts_ms = int(timestamp)
    except ValueError:
        raise HTTPException(status_code=401, detail="Gecersiz timestamp")

    now_ms = int(time.time() * 1000)
    if abs(now_ms - ts_ms) > 300_000:
        raise HTTPException(status_code=401, detail="Timestamp suresi dolmus")

    _cleanup_nonces(now_ms)
    if nonce in _seen_nonces:
        raise HTTPException(status_code=401, detail="Replay tespit edildi")
    _seen_nonces[nonce] = now_ms

    payload = f"{timestamp}.{nonce}.".encode("utf-8") + body
    expected = hmac.new(
        settings.api_secret.encode("utf-8"), payload, hashlib.sha256
    ).hexdigest()

    if not hmac.compare_digest(expected, signature.lower()):
        raise HTTPException(status_code=401, detail="Gecersiz imza")

def post(
    path: str,
    body: bytes,
    token: str | None = None,
    *,
    secret: str = API_SECRET,
    nonce: str | None = None,
    timestamp: str | None = None,
) -> tuple[int, dict]:
    ts = timestamp or str(int(time.time() * 1000))
    nc = nonce or str(uuid4())
    signature = hmac.new(
        secret.encode("utf-8"),
        f"{ts}.{nc}.".encode("utf-8") + body,
        hashlib.sha256,

        "Content-Type": "application/json",
        "X-AC-Key": API_KEY,
        "X-AC-Timestamp": ts,
        "X-AC-Nonce": nc,
        "X-AC-Signature": signature,
    }

        headers["Authorization"] = f"Bearer {token}"

    request = urllib.request.Request(
        f"{BASE_URL}{path}", data=body, headers=headers, method="POST"

public final class ProcessScan {

            .filter(ProcessHandle::isAlive)
            .forEach(handle -> {

            });
