`README.md`:

```md
# droid-arsenal

Índice completo: `INDEX.md`.

Toolkit reprodutível para análise e modificação de apps Android no device próprio, com
**interferência mínima**: nada de patch de APK, nada em `/system`, Frida só quando necessário.
Entrada única: `bin/dops`. Por app, só um arquivo em `targets/`.

## Instalação

```bash
bootstrap/install.sh          # venv com frida + mitmproxy, checagens
export PATH="$PWD/bin:$PATH"
dops doctor
```

Requisitos: `ponte` (preferido) ou `adb` com root; device com KernelSU/Magisk; LSPosed 2.x e
FKIAB 1.8.1 para a parte de billing.

## Comandos

```bash
dops doctor                     # transporte, root, SELinux, LSPosed, FKIAB, mitmproxy
dops recon com.exemplo.app      # engine, APKs, libs, prefs, paths de save
dops backup com.exemplo.app     # tar internal+external + sha256 (state/backups)
dops restore com.exemplo.app state/backups/foo.tar.gz

dops mem scan 18000 --type int64 --package com.exemplo.app   # passthrough agm
dops save sniff caminho/save.bin
dops il2cpp dump com.exemplo.app   # pull APK(s) + Il2CppDumper; --apks a.apk,b.apk reusa locais
# Il2CppDumper: coloque em ~/.local/share/droid-arsenal/Il2CppDumper/ ou exporte DOPS_IL2CPP_DUMPER

dops iap status com.exemplo.app
dops iap scope  com.exemplo.app [--remove]
dops iap receipts com.exemplo.app [--clean | --clone <produto> --count N]
dops iap script com.exemplo.app --loader loader.js [--payload b.js]

dops lsposed status | modules
dops lsposed scope com.fuck.iab com.exemplo.app [--remove]
dops lsposed scope-db com.fuck.iab com.exemplo.app [--remove] [--reboot]

dops mitm enable com.exemplo.app [--host h] [--port 8080] [--dry-run]
dops mitm disable
dops mitm ca [--install]

dops evidence com.exemplo.app [--seconds N] [--tag label]
dops hook run script.js com.exemplo.app [--spawn] [--seconds N]

dops recipe list
dops recipe run iap-mitm --target com.exemplo.app [--dry-run]
dops cleanup                    # mitm off + frida off + SELinux enforcing
```

## Alvos (`targets/<nome>.toml`)

A única parte específica por app:

```toml
package = "com.exemplo.app"
uid = 10478                       # opcional
save_paths = ["/sdcard/Android/data/{package}/files"]
receipt_prefs = "/data/data/{package}/shared_prefs/fuck.iab.xml"

[mitm]
hosts = ["validador.exemplo.com"]
match_path = "/verify"
patch = { result = 1 }
```

`--target` aceita o nome do arquivo (ex.: `cat-gunner`) ou o próprio package (procura
`<pkg>.toml`, `<pkg-com-hifens>.toml`, `<último-segmento>.toml`).

## Receitas

`recipes/*.toml` encadeiam verbos com `{target}`. `--dry-run` mostra a sequência.

## Runbooks

`runbooks/` cobre recon, save, memória, FKIAB, MITM e rollback. Metodologia genérica:
veja `runbooks/recon.md` e `runbooks/save.md`; casos de referência em `targets/`.

## Segurança e rollback

- `cleanup` remove iptables do MITM, mata frida-server e volta SELinux para `Enforcing`.
- CA de usuário e módulo LSPosed ficam instalados (reutilizáveis); remova manualmente se quiser.
- Backups têm sha256; restaure com `dops restore`.
- `state/` e segredos ficam fora do git.

## Validação (2026-11-24)

Validado ao vivo (device Android 16, root via KernelSU): `doctor` (5 s), `recon` (6 s), `backup`, `restore` ponta a ponta
(sentinel restaurado), `save sniff`, `iap status` (5 s)/`scripts`, `mem` passthrough,
`mitm enable/disable` com dispatcher SNI, `evidence`, `cleanup`, recipe real (`recon-save`),
`hook run` (frida-server attach), `lsposed scope-db` (add/remove no `modules_config.db`),
10 testes unitários (inclui parser SNI). Forge do addon validado com mitmproxy reverse + curl
(`result:1` no corpo). `lsposed scope` via lspctl é **impossível em build user** (exige ADB root
real); use `scope-db` + reboot. MITM no alvo Cat Gunner: handshake recusado mesmo com CA no system
store (init+zygote) → gate por app registrado em `runbooks/iap-mitm.md`.

Não exercitado: aplicação do escopo LSPosed pós-reboot, sucesso do MITM em app que confie na CA.

## Limites conhecidos

- MITM depende de o app aceitar CA (usuário+módulo de trust ou sistema) e não ter pinning.
- Metadata IL2CPP cifrada (PGL Armor) impede dump estático; use recon por runtime/string-xref.
- Consumíveis com validação server-side só passam com MITM/patch; `NonConsumable` costuma
  conceder localmente (ver skill `cat-gunner-ops`).

#!/usr/bin/env python3
"""dops — droid arsenal CLI: recon, backup, memory, saves, IAP, LSPosed, MITM, evidence."""
from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(ROOT))

from lib import backup, doctor, evidence, hook, iap, il2cpp, lsposed, mem, mitm, recon, recipe, save, util  # noqa: E402


def cfg_for(pkg: str) -> dict:
    for cand in (pkg, pkg.replace(".", "-"), pkg.split(".")[-1].lower()):
        try:
            return util.target(cand)
        except util.DopsError:
            continue
    return {"package": pkg}


def main() -> int:
    ap = argparse.ArgumentParser(prog="dops", description="Android app hacking toolkit (minimal device interference)")
    ap.add_argument("--json", action="store_true", help="machine-readable output")
    sub = ap.add_subparsers(dest="cmd", required=True)

    sub.add_parser("doctor", help="environment/device readiness")

    p = sub.add_parser("recon", help="package recon")
    p.add_argument("pkg")

    p = sub.add_parser("backup", help="backup app internal+external data")
    p.add_argument("pkg")
    p.add_argument("--name")

    p = sub.add_parser("restore", help="restore a backup archive")
    p.add_argument("pkg")
    p.add_argument("archive", type=Path)

    p = sub.add_parser("backups", help="list backups")
    p.add_argument("pkg", nargs="?")

    p = sub.add_parser("mem", help="memory scan/edit (agm passthrough)")
    p.add_argument("args", nargs=argparse.REMAINDER)

    p = sub.add_parser("iap", help="FKIAB billing emulation")
    isub = p.add_subparsers(dest="iap_cmd", required=True)
    for name in ("status", "scope", "receipts", "script"):
        s = isub.add_parser(name)
        s.add_argument("pkg")
        if name == "scope":
            s.add_argument("--remove", action="store_true")
        if name == "receipts":
            s.add_argument("--clean", action="store_true")
            s.add_argument("--clone")
            s.add_argument("--count", type=int, default=1)
        if name == "script":
            s.add_argument("--loader", type=Path)
            s.add_argument("--payload", type=Path)
            s.add_argument("--remove", action="store_true")

    p = sub.add_parser("lsposed", help="LSPosed control via lspctl")
    lsub = p.add_subparsers(dest="ls_cmd", required=True)
    lsub.add_parser("status")
    lsub.add_parser("modules")
    s = lsub.add_parser("scope")
    s.add_argument("module")
    s.add_argument("pkg")
    s.add_argument("--remove", action="store_true")
    s = lsub.add_parser("scope-db")
    s.add_argument("module")
    s.add_argument("pkg")
    s.add_argument("--remove", action="store_true")
    s.add_argument("--reboot", action="store_true")

    p = sub.add_parser("mitm", help="TLS interception for one app/host")
    msub = p.add_subparsers(dest="mitm_cmd", required=True)
    s = msub.add_parser("enable")
    s.add_argument("pkg")
    s.add_argument("--host")
    s.add_argument("--port", type=int, default=8080)
    s.add_argument("--dry-run", action="store_true")
    msub.add_parser("disable")
    s = msub.add_parser("ca")
    s.add_argument("--install", action="store_true")
    s.add_argument("--system", action="store_true")
    s.add_argument("--unmount", action="store_true")

    p = sub.add_parser("save", help="save file sniffing")
    ssub = p.add_subparsers(dest="save_cmd", required=True)
    s = ssub.add_parser("sniff")
    s.add_argument("path", type=Path)

    p = sub.add_parser("il2cpp", help="dump IL2CPP metadata/libs")
    isub = p.add_subparsers(dest="il_cmd", required=True)
    s = isub.add_parser("dump")
    s.add_argument("pkg")
    s.add_argument("--apks", help="lista de APKs locais (vírgula) para pular o pull")
    s.add_argument("--force-pull", action="store_true")

    p = sub.add_parser("evidence", help="logcat+screenshot+files bundle")
    p.add_argument("pkg")
    p.add_argument("--seconds", type=int, default=0)
    p.add_argument("--tag", default="")

    p = sub.add_parser("hook", help="run a Frida script")
    hsub = p.add_subparsers(dest="hook_cmd", required=True)
    s = hsub.add_parser("run")
    s.add_argument("script", type=Path)
    s.add_argument("pkg")
    s.add_argument("--spawn", action="store_true")
    s.add_argument("--seconds", type=int, default=0)
    s.add_argument("--host")

    p = sub.add_parser("recipe", help="declarative recipes")
    rsub = p.add_subparsers(dest="rec_cmd", required=True)
    rsub.add_parser("list")
    s = rsub.add_parser("run")
    s.add_argument("name")
    s.add_argument("--target")
    s.add_argument("--dry-run", action="store_true")

    sub.add_parser("cleanup", help="stop mitm/frida and restore SELinux")
    sub.add_parser("version", help="toolkit version (git describe)")

    a = ap.parse_args()

    if a.cmd == "doctor":
        info = doctor.collect()
        print(json.dumps(info, indent=1) if a.json else doctor.render(info))
        return 0

    if a.cmd == "recon":
        cfg = cfg_for(a.pkg)
        pkg = cfg.get("package", a.pkg)
        info = recon.recon(pkg, cfg)
        print(json.dumps(info, indent=1) if a.json else recon.render(info))
        return 0

    if a.cmd == "backup":
        cfg = cfg_for(a.pkg)
        pkg = cfg.get("package", a.pkg)
        dest = backup.backup(pkg, cfg, a.name)
        print(dest)
        return 0

    if a.cmd == "restore":
        backup.restore(cfg_for(a.pkg).get("package", a.pkg), a.archive)
        print("restored", a.archive)
        return 0

    if a.cmd == "backups":
        print("\n".join(backup.list_backups(a.pkg)) or "none")
        return 0

    if a.cmd == "mem":
        return mem.agm(a.args)

    if a.cmd == "iap":
        cfg = cfg_for(a.pkg)
        pkg = cfg.get("package", a.pkg)
        if a.iap_cmd == "status":
            st = iap.status(pkg)
            scope_txt = st["scope"] if "scope_error" not in st else f"(indisponível: {st['scope_error'].splitlines()[0]})"
            print(json.dumps(st, indent=1) if a.json else
                  f"installed={st['installed']} uid={st.get('uid')} injected={st['injected']} "
                  f"scope={scope_txt} scripts={st['scripts']} receipts={len(st['receipts'])}")
            for r in st["receipts"]:
                print("  ", r["productId"], r["orderId"])
            return 0
        if a.iap_cmd == "scope":
            print(iap.scope_remove(pkg) if a.remove else iap.scope_add(pkg))
            return 0
        if a.iap_cmd == "receipts":
            if a.clean:
                iap.clean_receipts(pkg, cfg)
                print("cleaned")
                return 0
            if a.clone:
                print(iap.clone_receipts(pkg, cfg, a.clone, a.count))
                return 0
            for r in iap.receipts(pkg, cfg):
                print(r["productId"], r["orderId"], r["purchaseTime"])
            return 0
        if a.iap_cmd == "script":
            if a.remove:
                print(iap.remove_script(pkg))
            else:
                if not a.loader:
                    raise util.DopsError("--loader required (or use --remove)")
                print(iap.install_script(pkg, a.loader, a.payload))
            return 0

    if a.cmd == "lsposed":
        if a.ls_cmd == "status":
            print(lsposed.status())
            return 0
        if a.ls_cmd == "modules":
            print("\n".join(lsposed.modules()))
            return 0
        if a.ls_cmd == "scope":
            print(lsposed.scope_remove(a.module, a.pkg) if a.remove else lsposed.scope_add(a.module, a.pkg))
            return 0
        if a.ls_cmd == "scope-db":
            print(lsposed.scope_db(a.module, a.pkg, add=not a.remove, reboot=a.reboot))
            return 0

    if a.cmd == "mitm":
        if a.mitm_cmd == "enable":
            cfg = cfg_for(a.pkg)
            pkg = cfg.get("package", a.pkg)
            print(json.dumps(mitm.enable(pkg, cfg, a.host, a.port, a.dry_run), indent=1))
            return 0
        if a.mitm_cmd == "disable":
            print(json.dumps(mitm.disable(), indent=1))
            return 0
        if a.mitm_cmd == "ca":
            if a.unmount:
                print(json.dumps(mitm.unmount_ca_system(), indent=1))
            elif a.system:
                print(json.dumps(mitm.install_ca_system(), indent=1))
            else:
                print(json.dumps(mitm.install_ca() if a.install else mitm.ca_info(), indent=1))
            return 0

    if a.cmd == "il2cpp":
        cfg = cfg_for(a.pkg)
        pkg = cfg.get("package", a.pkg)
        apks = [Path(x) for x in a.apks.split(",") if x] if a.apks else None
        print(json.dumps(il2cpp.dump(pkg, cfg, apks, a.force_pull), indent=1))
        return 0

    if a.cmd == "save":
        info = save.sniff(a.path)
        print(json.dumps(info, indent=1) if a.json else save.render(info))
        return 0

    if a.cmd == "evidence":
        cfg = cfg_for(a.pkg)
        print(evidence.capture(cfg.get("package", a.pkg), cfg, a.seconds, a.tag))
        return 0

    if a.cmd == "hook":
        return hook.run(a.script, a.pkg, a.spawn, a.seconds, a.host)

    if a.cmd == "recipe":
        if a.rec_cmd == "list":
            print("\n".join(recipe.listing()))
            return 0
        return recipe.run(a.name, a.target, a.dry_run)

    if a.cmd == "version":
        import subprocess

        print(subprocess.run(["git", "-C", str(ROOT), "describe", "--always", "--dirty"],
                             capture_output=True, text=True).stdout.strip() or "unknown")
        return 0

    if a.cmd == "cleanup":
        print(json.dumps(mitm.disable(), indent=1))
        try:
            util.dev("kill -9 $(pidof .fs) 2>/dev/null; setenforce 1; getenforce", timeout=30)
        except util.DopsError:
            pass
        print("cleanup done")
        return 0

    return 2


if __name__ == "__main__":
    try:
        raise SystemExit(main())
    except util.DopsError as e:
        print(f"erro: {e}", file=sys.stderr)
        raise SystemExit(1)
    except KeyboardInterrupt:
        raise SystemExit(130)

`lib/backup.py`:

```py
"""Backup/restore app data (internal + external) with checksums."""
from __future__ import annotations

import hashlib
import tarfile
import time
from pathlib import Path

from . import util

BACKUPS = util.STATE / "backups"


def _sha256(path: Path) -> str:
    h = hashlib.sha256()
    with open(path, "rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def backup(pkg: str, cfg: dict | None = None, name: str | None = None) -> Path:
    cfg = cfg or {}
    BACKUPS.mkdir(parents=True, exist_ok=True)
    stamp = time.strftime("%Y%m%dT%H%M%SZ", time.gmtime())
    dest = BACKUPS / (name or f"{pkg}-{stamp}.tar.gz")
    if dest.suffix != ".gz":
        dest = dest.with_name(dest.name + ".tar.gz")
    tmp = f"/sdcard/Download/.dops-backup-{pkg}.tar"
    paths = [f"/data/data/{pkg}", f"/sdcard/Android/data/{pkg}"]
    paths += [util.expand(p, {"package": pkg}) for p in cfg.get("save_paths", [])]
    existing = " ".join(p for p in paths if _exists(p))
    util.dev(f"tar -czf {util.shell_quote(tmp)} {existing} 2>/dev/null || true", timeout=180)
    util.dev_pull(tmp, dest)
    util.dev(f"rm -f {util.shell_quote(tmp)}")
    meta = dest.with_suffix(dest.suffix + ".sha256")
    meta.write_text(_sha256(dest) + "\n")
    return dest


def restore(pkg: str, archive: Path) -> None:
    if not archive.exists():
        raise util.DopsError(f"archive not found: {archive}")
    remote = f"/sdcard/Download/.dops-restore-{pkg}.tar.gz"
    util.dev_push(archive, remote)
    # tar rc=1 means warnings only (changed/vanished files); rc>=2 is an error
    util.dev(f"tar -xf {util.shell_quote(remote)} -C / 2>/dev/null; rc=$?; rm -f {util.shell_quote(remote)}; test $rc -le 1", timeout=180)
def list_backups(pkg: str | None = None) -> list[str]:

#!/usr/bin/env python3
"""Attach or spawn the target and load a Frida script; prints messages."""
from __future__ import annotations

import argparse
import os
import sys
import time

try:
    import frida
except ImportError:
    sys.exit("frida python package missing (install in DOPS_PY venv)")


def main() -> None:
    ap = argparse.ArgumentParser()
    ap.add_argument("script")
    ap.add_argument("package")
    ap.add_argument("--spawn", action="store_true")
    ap.add_argument("--seconds", type=int, default=0)
    ap.add_argument("--host", default=os.environ.get("FRIDA_HOST", "127.0.0.1:27042"))
    a = ap.parse_args()

    dev = frida.get_device_manager().add_remote_device(a.host)
    if a.spawn:
        pid = dev.spawn([a.package])
        session = dev.attach(pid)
        dev.resume(pid)
    else:
        app = next((x for x in dev.enumerate_applications() if x.identifier == a.package), None)
        if app:
            pid = app.pid
        else:
            tail = a.package.split(".")[-1].lower()
            pid = next((p.pid for p in dev.enumerate_processes()
                        if p.name.lower() == tail or tail in p.name.lower()), None)
        if not pid:
            sys.exit(f"process not found for {a.package}")
        session = dev.attach(pid)
    src = open(a.script).read()
    script = session.create_script(src)
    script.on("message", lambda m, d: print(m.get("payload", m), flush=True))
    script.load()
    print(f"[hookrun] attached pid={pid}", flush=True)
    try:
        if a.seconds:
            time.sleep(a.seconds)
        else:
            while True:
                time.sleep(1)
    except KeyboardInterrupt:
        pass
    finally:
        session.detach()


if __name__ == "__main__":
    main()

def _extract(apk: Path, dest: Path) -> tuple[Path | None, Path | None]:
    meta = lib = None
    with zipfile.ZipFile(apk) as z:
        for name in z.namelist():
            if name.endswith("assets/bin/Data/Managed/Metadata/global-metadata.dat"):
                meta = dest / "global-metadata.dat"
                meta.write_bytes(z.read(name))
            elif name.endswith("lib/arm64-v8a/libil2cpp.so"):
                lib = dest / "libil2cpp.so"
                lib.write_bytes(z.read(name))
    return meta, lib


def dump(pkg: str, cfg: dict | None = None, apks: list[Path] | None = None, force_pull: bool = False) -> dict:
    cfg = cfg or {}
    work = util.STATE / "il2cpp" / pkg
    work.mkdir(parents=True, exist_ok=True)
    local_apks: list[Path] = []
    if apks:
        local_apks = apks
    elif force_pull or not any(work.glob("*.apk")):
        for i, remote in enumerate(_device_apks(pkg)):
            dest = work / f"apk{i}-{remote.split('/')[-1]}"
            util.dev_pull(remote, dest)
            local_apks.append(dest)
    else:
        local_apks = sorted(work.glob("*.apk"))
    meta = lib = None
    for apk in local_apks:
        m, l = _extract(apk, work)
        meta = meta or m
        lib = lib or l
    if cfg.get("dump_meta") and not meta:
        meta = Path(cfg["dump_meta"])
    if cfg.get("dump_lib") and not lib:
        lib = Path(cfg["dump_lib"])
    if not meta or not lib:
        raise util.DopsError("global-metadata.dat ou libil2cpp.so não encontrados nos APKs")
    if not DUMPER.exists():
        raise util.DopsError(f"Il2CppDumper não encontrado em {DUMPER} (defina DOPS_IL2CPP_DUMPER)")
    outdir = work / "dump"
    env = dict(os.environ, DOTNET_ROLL_FORWARD="LatestMajor")
    proc = subprocess.run(
        ["dotnet", str(DUMPER), str(lib), str(meta), str(outdir)],
        env=env, capture_output=True, text=True, timeout=900,
    )
    found = list(outdir.glob("dump.cs")) or list(work.glob("dump.cs"))
    # dumper antigo ignora o diretório e escreve no cwd; normaliza
    if not found:
        for cand in (Path.cwd() / "dump.cs", DUMPER.parent / "dump.cs"):
            if cand.exists():
                outdir.mkdir(parents=True, exist_ok=True)
                cand.replace(outdir / "dump.cs")
                found = [outdir / "dump.cs"]
                break
    if not found:
        raise util.DopsError(
            "dump falhou (metadata cifrada/protegida?).\n"
            + (proc.stdout or "")[-500:] + (proc.stderr or "")[-500:]
        )
    return {"dump": str(found[0]), "metadata": str(meta), "libil2cpp": str(lib),
            "outdir": str(outdir), "apks": [str(p) for p in local_apks]}

from __future__ import annotations

import shlex
import subprocess
import sys
import tomllib
from pathlib import Path

from . import util

def load(name: str) -> dict:
    path = RECIPES / f"{name}.toml"

        raise util.DopsError(f"recipe not found: {path}")
    with open(path, "rb") as f:
        return tomllib.load(f)


def run(name: str, target: str | None = None, dry_run: bool = False) -> int:
    rec = load(name)
    rc = 0
    for step in rec.get("steps", []):
        argv = [str(x).format(target=target or "", package=target or "") for x in step]
        argv = [a for a in argv if a != ""]
        print("+ dops " + " ".join(shlex.quote(a) for a in argv))
        if dry_run:
            continue
        p = subprocess.run([sys.executable, str(util.HOME / "bin" / "dops"), *argv])
        if p.returncode != 0:
            rc = p.returncode
            print(f"! step failed: {argv}")
            if rec.get("stop_on_error", True):
                break
    return rc


def listing() -> list[str]:
    if not RECIPES.exists():
        return []
    return sorted(p.stem for p in RECIPES.glob("*.toml"))

def recon(pkg: str, cfg: dict | None = None) -> dict:
    cfg = cfg or {}
    paths = [f"/data/data/{pkg}", f"/data/data/{pkg}/files", f"/data/data/{pkg}/shared_prefs",
             f"/sdcard/Android/data/{pkg}/files"]
    cmd = "; ".join([
        f"echo '@@META'; dumpsys package {pkg} | grep -E 'versionName|versionCode|firstInstallTime|lastUpdateTime'",
        f"echo '@@UID'; dumpsys package {pkg} | grep -oE '(appId|userId)=[0-9]+' | head -1",
        f"echo '@@APK'; pm path {pkg}",
        f"echo '@@LIBS'; ls /data/app/*/{pkg}-*/lib/*/*.so 2>/dev/null | xargs -n1 basename 2>/dev/null",
        "echo '@@LS0'; ls -la " + paths[0] + " 2>/dev/null",
        "echo '@@LS1'; ls -la " + paths[1] + " 2>/dev/null",
        "echo '@@LS2'; ls -la " + paths[2] + " 2>/dev/null",
        "echo '@@LS3'; ls -la " + paths[3] + " 2>/dev/null",
    ])
    raw = util.dev(cmd, timeout=120)
    sec: dict[str, list[str]] = {}
    cur = None
    for line in raw.splitlines():
        if line.startswith("@@"):
            cur = line[2:].strip()
            sec[cur] = []
        elif cur:
            sec[cur].append(line)
    info: dict = {"package": pkg, "meta": [l.strip() for l in sec.get("META", []) if l.strip()],
                  "apks": [l.split(":", 1)[1].strip() for l in sec.get("APK", []) if l.startswith("package:")],
                  "native_libs": sorted({l.strip() for l in sec.get("LIBS", []) if l.strip()})}
    m = re.search(r"=(\d+)", "\n".join(sec.get("UID", [])))
    info["uid"] = int(m.group(1)) if m else None

    for i, key in enumerate(("data", "data_files", "prefs", "external")):
        info[key] = [l.strip() for l in sec.get(f"LS{i}", []) if l.strip()]
    info["save_paths"] = [util.expand(p, {"package": pkg}) for p in cfg.get("save_paths", [])]

"""Save-file sniffing: identify common Unity/Android save containers without game-specific code."""
from __future__ import annotations

import base64
import binascii
import math
from pathlib import Path


def entropy(data: bytes) -> float:
    if not data:
        return 0.0
    freq = [0] * 256
    for b in data:
        freq[b] += 1
    n = len(data)
    return -sum((c / n) * math.log2(c / n) for c in freq if c)


def sniff(path: Path) -> dict:
    data = path.read_bytes()
    info: dict = {"path": str(path), "size": len(data), "head": data[:16].hex(), "entropy": round(entropy(data[:4096]), 2)}
    if data.lstrip().startswith((b"{", b"[")):
        info.update(format="json", editable=True)
        return info
    if data.startswith(b"ENC1"):
        body = data[5:]
        info.update(format="actk-obscuredfile", editable=False)
        try:
            raw = base64.b64decode(body, validate=False)
            info.update(cipher_len=len(raw), block_aligned=(len(raw) % 16 == 0), cipher_entropy=round(entropy(raw[:4096]), 2))
        except binascii.Error:
            info["note"] = "payload not base64"
        info["hint"] = "ACTK ObscuredFile (AES); capture key/IV via runtime hook antes de editar"
        return info
    if data[:4] in (b"\x1f\x8b\x08\x00",) or data[:2] == b"\x1f\x8b":
        info.update(format="gzip", editable=True)
        return info
    try:
        raw = base64.b64decode(b"".join(data.split()), validate=True)
        info.update(format="base64", decoded_len=len(raw), decoded_entropy=round(entropy(raw[:4096]), 2))
        return info
    except binascii.Error:
        pass
    if info["entropy"] < 6.5:
        info.update(format="binary-low-entropy", hint="testar XOR de 1 byte / header fixo")
    else:
        info.update(format="binary-encrypted", hint="AES/DES provável; hook no primitivo de crypto")
    return info


def render(info: dict) -> str:
    lines = [f"file    : {info['path']} ({info['size']} B, entropy {info['entropy']})",
             f"format  : {info['format']}"]
    for k in ("cipher_len", "block_aligned", "decoded_len", "decoded_entropy", "cipher_entropy"):
        if k in info:
            lines.append(f"{k:8}: {info[k]}")
    if info.get("hint"):
        lines.append("hint    : " + info["hint"])
    return "\n".join(lines)

class DopsError(RuntimeError):

def which(name: str) -> str | None:
    return shutil.which(name)


def run(argv: list[str], timeout: int = 120, input: bytes | None = None) -> subprocess.CompletedProcess:
    return subprocess.run(argv, capture_output=True, timeout=timeout, input=input)


def out(argv: list[str], timeout: int = 120) -> str:
    p = run(argv, timeout)
    if p.returncode != 0:
        raise DopsError(f"{argv[0]} rc={p.returncode}: {p.stderr.decode(errors='replace')[:400]}")
    return p.stdout.decode(errors="replace")


def ponte_ok() -> bool:
    return which("ponte") is not None and run(["ponte", "status"], timeout=25).returncode == 0


def adb_ok() -> bool:
    return which("adb") is not None and run(["adb", "shell", "true"], timeout=15).returncode == 0


def dev(cmd: str, timeout: int = 120, root: bool = True) -> str:
    """Run a shell command on the device. Root shell when possible."""
    if ponte_ok():
        argv = ["ponte", "root", "--", cmd]
    elif which("adb"):
        argv = ["adb", "shell", ("su -c " + cmd) if root else cmd]
    else:
        raise DopsError("no device transport (ponte/adb)")
    p = run(argv, timeout)
    if p.returncode != 0:
        detail = (p.stdout + p.stderr).decode(errors="replace").strip()
        raise DopsError(f"device cmd failed rc={p.returncode}: {detail[:400]}")
    return p.stdout.decode(errors="replace")


def shell_quote(s: str) -> str:
    return "'" + s.replace("'", "'\\''") + "'"


def adb_device() -> bool:
    if not which("adb"):
        return False
    p = run(["adb", "devices"], timeout=15)
    return b"\tdevice" in p.stdout


def dev_pull(remote: str, local: Path) -> None:
    """Copy a device file to host (adb pull when available, else root-safe temp path)."""
    local.parent.mkdir(parents=True, exist_ok=True)
    if adb_device():
        p = run(["adb", "pull", remote, str(local)], timeout=300)
        if p.returncode == 0 and local.exists() and local.stat().st_size > 0:
            return
    tmp = f"/sdcard/Download/.dops-{os.getpid()}-{local.name}"
    dev(f"cat {shell_quote(remote)} > {shell_quote(tmp)}")
    if which("ponte"):
        run(["ponte", "pull", tmp, str(local)])
    else:
        run(["adb", "pull", tmp, str(local)])
    dev(f"rm -f {shell_quote(tmp)}")
    if not local.exists() or local.stat().st_size == 0:
        raise DopsError(f"pull failed: {remote}")


def dev_push(local: Path, remote: str) -> None:
    if adb_device():
        p = run(["adb", "push", str(local), remote], timeout=300)
        if p.returncode == 0:

    tmp = f"/sdcard/Download/.dops-{os.getpid()}-{local.name}"
    if which("ponte"):
        run(["ponte", "push", str(local), tmp])
    else:
        run(["adb", "push", str(local), tmp])
    dev(f"cat {shell_quote(tmp)} > {shell_quote(remote)}")
    dev(f"rm -f {shell_quote(tmp)}")

`mitm/addon.py`:

```py
"""mitmproxy addon: log requests and rewrite a matched JSON response.

Env:
  DOPS_RULES   path to rules JSON: {"host": "...", "match_path": "...", "patch": {...}}
  DOPS_LOG     append request/response log
  DOPS_CAPTURE_ONLY=1  never rewrite, only log
"""
from __future__ import annotations

import json
import os
import time


def _load_rules() -> dict:
    path = os.environ.get("DOPS_RULES")
    if not path or not os.path.exists(path):
        return {"host": "", "match_path": "", "patch": {"result": 1}}
    with open(path) as f:
        return json.load(f)


def _log(line: str) -> None:
    path = os.environ.get("DOPS_LOG")
    if not path:
        return
    with open(path, "a") as f:
        f.write(f"{time.time():.3f} {line}\n")


def patched_body(rules: dict, original: bytes | None) -> bytes:
    """Build the forged body; keeps original JSON fields when parseable."""
    try:
        base = json.loads(original) if original else {}
        if not isinstance(base, dict):
            base = {}
    except Exception:  # noqa: BLE001
        base = {}
    base.update(rules.get("patch") or {"result": 1})
    return json.dumps(base, separators=(",", ":")).encode()


def matches(rules: dict, host: str, path: str) -> bool:
    want_host = rules.get("host") or ""
    want_path = rules.get("match_path") or ""
    return (not want_host or want_host in host) and (not want_path or want_path in path)


def response(flow) -> None:  # noqa: ANN001 - mitmproxy hook
    rules = _load_rules()
    host = flow.request.pretty_host
    _log(f"REQ {flow.request.method} https://{host}{flow.request.path}")
    if not matches(rules, host, flow.request.path):
        return
    original = getattr(flow.response, "content", None) if flow.response else None
    _log(f"RESP {getattr(flow.response, 'status_code', '?')} {original[:300]!r}" if original else "RESP empty")
    if os.environ.get("DOPS_CAPTURE_ONLY") == "1":
        return
    from mitmproxy import http  # imported lazily so the module is unit-testable

    flow.response = http.Response.make(
        200,
        patched_body(rules, original),
        {"Content-Type": "application/json; charset=utf-8"},
    )
    _log("PATCHED " + patched_body(rules, original).decode())

```

`mitm/dispatch.py`:

```py
"""SNI dispatcher: TLS passthrough for everything except the configured host.

iptables redirects the app's 443 to this listener. We peek the ClientHello SNI:
- target host -> relay to mitmproxy reverse (which terminates TLS with our CA)
- anything else -> raw TCP passthrough to the real host (no interception, no breakage)

Env: DOPS_DISPATCH = {"listen": 0, "mitm": 8081, "targets": ["host", ...], "log": "path"}
"""
from __future__ import annotations

import asyncio
import json
import os
import ssl
import struct
import time

CFG = json.loads(os.environ.get("DOPS_DISPATCH", "{}"))
LOG = CFG.get("log")


def log(msg: str) -> None:
    line = f"{time.time():.3f} {msg}"
    print(line, flush=True)
    if LOG:
        with open(LOG, "a") as f:
            f.write(line + "\n")


def parse_sni(data: bytes) -> str | None:
    try:
        if len(data) < 5 or data[0] != 0x16:  # handshake record
            return None
        p = 5
        if data[p] != 1:  # ClientHello
            return None
        p += 4  # handshake header
        p += 2 + 32  # version + random
        sid = data[p]
        p += 1 + sid
        cs = struct.unpack("!H", data[p:p + 2])[0]
        p += 2 + cs
        comp = data[p]
        p += 1 + comp
        if p + 2 > len(data):
            return None
        ext_total = struct.unpack("!H", data[p:p + 2])[0]
        p += 2
        end = min(len(data), p + ext_total)
        while p + 4 <= end:
            et, el = struct.unpack("!HH", data[p:p + 4])
            p += 4
            if et == 0 and p + el <= end:
                # server_name list
                q = p + 2
                while q + 3 <= p + el:
                    nt = data[q]
                    nl = struct.unpack("!H", data[q + 1:q + 3])[0]
                    if nt == 0:
                        return data[q + 3:q + 3 + nl].decode("ascii", "ignore")
                    q += 3 + nl
            p += el
    except Exception:  # noqa: BLE001
        return None
    return None


async def relay(a: asyncio.StreamReader, b: asyncio.StreamWriter) -> None:
    try:
        while data := await a.read(65536):
            b.write(data)
            await b.drain()
    except Exception:  # noqa: BLE001
        pass
    finally:
        try:
            b.close()
        except Exception:  # noqa: BLE001
            pass


async def handle(reader: asyncio.StreamReader, writer: asyncio.StreamWriter):
    targets = set(CFG.get("targets", []))
    try:
        head = await asyncio.wait_for(reader.read(8192), timeout=5)
    except Exception:  # noqa: BLE001
        writer.close()
        return
    if not head:
        writer.close()
        return
    sni = parse_sni(head)
    if sni is None:
        log("HEAD " + head[:24].hex())
    target = bool(sni and any(t == sni or sni.endswith("." + t) for t in targets))
    log(f"SNI={sni} target={target}")
    try:
        if target:
            up_r, up_w = await asyncio.open_connection("127.0.0.1", CFG["mitm"])
        else:
            if not sni:
                writer.close()
                return
            up_r, up_w = await asyncio.open_connection(sni, 443, ssl=None)
        up_w.write(head)
        await up_w.drain()
    except Exception as e:  # noqa: BLE001
        log(f"upstream ERR {e}")
        writer.close()
        return
    await asyncio.gather(relay(reader, up_w), relay(up_r, writer))


async def main() -> None:
    server = await asyncio.start_server(handle, "0.0.0.0", int(CFG["listen"]))
    log(f"dispatch listening {CFG['listen']} targets={CFG.get('targets')} mitm=127.0.0.1:{CFG['mitm']}")
    async with server:
        await server.serve_forever()


if __name__ == "__main__":
    asyncio.run(main())

```

Como funciona:

- `iptables -t nat OUTPUT --dport 443 -m owner --uid-owner <uid> -j REDIRECT --to-ports 8080`
  só para o app alvo.
- `adb reverse tcp:8080 tcp:8080` leva o tráfego ao mitmproxy no host.
- mitmproxy em `reverse:https://<host>` apresenta cert do host e encaminha para o real.
- `mitm/addon.py` casa host/path do `targets/<alvo>.toml` e aplica `patch` no JSON
  (ex.: `result=1`). `DOPS_CAPTURE_ONLY=1` só loga.

(`${SYS_STORE}` bind mount), app reiniciado → `Client TLS handshake failed ... tlsv1 alert access denied`.
Conclusão: esse app **não usa a store do sistema** (CA embutida no Unity) ou faz pinning nativo.
Sem hook/patch nativo, MITM não passa; pare e vá para codec/patch do cliente.

Forge validado localmente: mitmproxy reverse + addon + `curl --cacert` → corpo reescrito com
`result:1` (log `PATCHED`). O que falta é o app confiar na CA.

Gates:

1. Handshake falhou → o app não confia na CA (módulo de trust só cobre Java?) ou há pinning.
2. Nada aparece no log → o app ignora proxy/redirect (lib própria); revise a regra/uid.
3. Sucesso não concede → schema diferente; itere `patch` (campos `items`, `expires`, etc.).
4. Anti-tamper: não use Frida/memory patch nessa sessão; `dops cleanup` ao final.

`runbooks/server-validated-iap.md`:

```md
# IAP validado no servidor (cliente burlável por hook)

Para jogos em que o grant **não** vem do Google Play, mas de um hit do backend do jogo
(ex.: `CServerHits.ValidateShopPurchaseHit` / `EHit.ValidatePurchaseRequest`). FakeBinder sozinho
só faz o preço virar `$0.00`; o servidor recusa o token fake e o cliente reverte (aqui:
`EErrorState 15 = InvalidPurchaseValidation`, popup “Erro de conexão (ID:15)”, rollback no restart).

## Classificar antes

1. `dops il2cpp dump <pkg>` → `dump.cs`; procure `ValidateShopPurchase`, `PurchaseResponse`,
   `CShop`, `CPurchasing`.
2. Fluxo típico: `CPurchasing.BuyProductId` → billing → `CServerHits.ValidateXHit(EProductId,
   token, onSuccess, onError)` → backend responde `CValidateXResponse { rewards, error, ... }`
   → `CShop.ValidatePurchaseServer(response, ...)` aplica os rewards.
3. Se o reward está na resposta do servidor, não existe “recibo válido local”: a rota é
   **forjar a resposta no cliente** (hook) ou patch de código.

## Rota: hook da validação (frida-il2cpp-bridge)

```ts
Il2Cpp.perform(() => {
  Il2Cpp.installExceptionListener("all");      // abort vira stack de C# útil
  const hits = findClass("Zombero.CServerHits");
  const m = hits.method("ValidateShopPurchaseHit");
  m.implementation = function (...args) {
    const pid = args[0], cb = args[2] as Il2Cpp.Object;
    const resp = buildValidateResponse(pid);   // preencher TODOS os campos aninhados
    cb.method("Invoke").invoke(resp);          // executar na thread do hit
  };
});
```

Construção da resposta (lições):

- `Cls.alloc()` + `field("...").value = ...`; **enums** via `obj.handle.add(0x11).writeU8(valor)`
  (setter de enum lança “expected a pointer”).
- Preencher **arrays vazios e objetos aninhados** que o cliente percorre:
  `remainingAds` (`CTransportRemainingAd[]`), `modificatedQuests`, `nextQueuedRewards`,
  `champions`/`boosters`/`rewards` (`CTransportRewardData`). Campo nulo = `NullReferenceException`
  em `CLocalInfoRemainingAds.Replace` / `CShop.ValidatePurchaseServer`.
- `error = EErrorState.Ok (1)` (raw write, 0x11 no `CHitResponseBase`).
- Rewards: `CValidatePurchaseResponse.rewards` (`CTransportReward`) → `.reward`
  (`CTransportRewardData`: softCurrency/hardCurrency/energy/holyWater/luckyWheelSpins/...).

## “abort was called” não é ABI

`abort was called` do bridge = **exceção C#** na chamada. Use
`Il2Cpp.installExceptionListener("all")` e leia o stack; itere preenchendo campos até o callback
completar. Só depois disso investigue thread (`csproto` de delegate: `method_ptr@0x10`,
`invoke_impl@0x18`, `m_target@0x20`, `method_code@0x40`).

Se invocar o delegate continuar inviável, hooke o **dispatch interno**
(`CIncomingDataPreparer.DecodeIncomingHit` / lambda de `CServerClient.AddHit`) e substitua o
`SHitWrapper` antes de o jogo chamar `onSuccess` sozinho.

## Pegadinhas do alvo

- Transação pendente no servidor: todo boot revalida e mostra ID15; limpar prefs do app não
  resolve se o servidor guarda o estado. Conta nova (dados limpos) evita o pendente.
- Moeda é espelhada no servidor; `GameGuardian`/scan de memória falha com valores obscured.
- Protocolo binário próprio (`CClientSocket`/`CInPacket`, `ICrypt`): MITM HTTPS não se aplica.
- ACTK: Frida só na sessão; prefira o hook mínimo e não deixe scripts residentes.
- `Task.FromResult`/delegates: não fabricar Task; chame o callback com objeto completo.

## Alternativas (ordem)

1. Hook da validação com resposta fabricada (acima) — menor diff.
2. Hook do dispatch interno (`DecodeIncomingHit`) — evita delegate externo.
3. Patch inline do call-site de sucesso (maior risco de integridade).
4. MITM **só** se a validação for HTTP(S) JSON (não é o caso de socket binário).

```

#!/usr/bin/env python3
"""agm - android game mod: scripted memory scan/edit over Frida (rooted device).

Session model: a JSON state file keyed by target package, holding the last scan
result set so refinement passes work across CLI invocations.

  agm scan <value> [--type int32] [--package PKG] [--pid PID]
  agm next <value> [--mode eq|gt|lt|changed|unchanged]
  agm list [--max N] [--read]
  agm write <index|addr> <value>
  agm freeze <index|addr> <value>       (re-apply loop in this process)
  agm reset
"""
import argparse
import json
import os
import struct
import sys
import time

import frida

HOST = os.environ.get("AGM_HOST", "127.0.0.1:27042")
STATE_DIR = os.environ.get("AGM_STATE", os.path.expanduser("~/.local/state/droid-arsenal/agm"))

TYPES = {"int8": 1, "int16": 2, "int32": 4, "int64": 8, "float": 4, "double": 8}

AGENT = r"""
const TYPES = {int8:1,int16:2,int32:4,int64:8,float:4,double:8};

function ranges() {
  return Process.enumerateRanges('rw-').filter(r => {
    if (r.size < 4096 || r.size > 2 * 1024 * 1024 * 1024) return false;
    if (!r.file) return true;
    // device/graphics mappings block or crash on large reads
    return !/^\/(dev|dmabuf|memfd|system\/lib64\/libGLES|system\/vendor\/lib64\/libGLES)/.test(r.file);
  });
}

function patternFor(value, type) {
  const buf = new ArrayBuffer(8);
  const dv = new DataView(buf);
  switch (type) {
    case 'int8': dv.setInt8(0, value); return hexEncode(buf, 1);
    case 'int16': dv.setInt16(0, value, true); return hexEncode(buf, 2);
    case 'int32': dv.setInt32(0, value, true); return hexEncode(buf, 4);
    case 'int64': dv.setBigInt64(0, BigInt(value), true); return hexEncode(buf, 8);
    case 'float': dv.setFloat32(0, value, true); return hexEncode(buf, 4);
    case 'double': dv.setFloat64(0, value, true); return hexEncode(buf, 8);
  }
}

function hexEncode(buf, n) {
  const b = new Uint8Array(buf, 0, n);
  let s = '';
  for (let i = 0; i < n; i++) s += (b[i] < 16 ? '0' : '') + b[i].toString(16);
  return s;
}

function readAt(addr, type) {
  try {
    switch (type) {
      case 'int8': return addr.readS8();
      case 'int16': return addr.readS16();
      case 'int32': return addr.readS32();
      case 'int64': return addr.readS64().valueOf();
      case 'float': return addr.readFloat();
      case 'double': return addr.readDouble();
    }
  } catch (e) { return null; }
  return null;
}

function writeAt(addr, type, value) {
  try {
    switch (type) {
      case 'int8': addr.writeS8(value); break;
      case 'int16': addr.writeS16(value); break;
      case 'int32': addr.writeS32(value); break;
      case 'int64': addr.writeS64(value); break;
      case 'float': addr.writeFloat(value); break;
      case 'double': addr.writeDouble(value); break;
    }
    return true;
  } catch (e) { return false; }
}

function scan(value, type, limit) {
  const pattern = patternFor(value, type);
  const out = [];
  const CHUNK = 32 * 1024 * 1024;
  for (const r of ranges()) {
    const touches = r.size <= CHUNK ? [r] :
      Array.from({ length: Math.ceil(r.size / CHUNK) }, (_, i) => ({
        base: r.base.add(i * CHUNK), size: Math.min(CHUNK, r.size - i * CHUNK),
      }));
    for (const piece of touches) {
      let found;
      try { found = Memory.scanSync(piece.base, piece.size, pattern); } catch (e) { found = []; }
      for (const m of found) {
        out.push(m.address);
        if (out.length >= limit) return out.map(a => a.toString());
      }
    }
  }
  return out.map(a => a.toString());
}

rpc.exports = {
  ranges() { return ranges().map(r => [r.base.toString(), r.size]); },
  scan: scan,
  read(addr, type) { const v = readAt(ptr(addr), type); return v === null ? null : (typeof v === 'number' ? v : String(v)); },
  readMany(addrs, type) { return addrs.map(a => { const v = readAt(ptr(a), type); return v === null ? null : v; }); },
  write(addr, type, value) { return writeAt(ptr(addr), type, value); },
  writeMany(addrs, type, value) { return addrs.map(a => writeAt(ptr(a), type, value)); },
};
"""


def current_key(explicit):
    if explicit:
        return explicit
    try:
        with open(os.path.join(STATE_DIR, "_current")) as f:
            return f.read().strip() or "default"
    except Exception:
        return "default"


def state_path(key):
    os.makedirs(STATE_DIR, exist_ok=True)
    return os.path.join(STATE_DIR, key.replace("/", "_") + ".json")


def load_state(key):
    try:
        with open(state_path(key)) as f:
            return json.load(f)
    except Exception:
        return {"pid": None, "package": None, "type": None, "value": None, "addrs": []}


def save_state(key, st):
    os.makedirs(STATE_DIR, exist_ok=True)
    with open(state_path(key), "w") as f:
        json.dump(st, f)
    with open(os.path.join(STATE_DIR, "_current"), "w") as f:
        f.write(key)


def pick_target(args, st):
    dev = frida.get_device_manager().add_remote_device(HOST)
    if args.pid:
        return dev, args.pid
    if args.package:
        for p in dev.enumerate_processes():
            if p.name == args.package:
                return dev, p.pid
        for a in dev.enumerate_applications():
            if a.identifier == args.package:
                if a.pid:
                    return dev, a.pid
                pid = dev.spawn([a.identifier])
                time.sleep(1.0)
                return dev, pid
        sys.exit(f"agm: package {args.package} not running and not launchable")
    if st.get("pid"):
        return dev, st["pid"]
    sys.exit("agm: no target (--pid or --package or previous scan)")


def attach(args, st):
    key = args.package or st.get("package") or str(args.pid)
    st["package"] = args.package or st.get("package")
    dev, pid = pick_target(args, st)
    st["pid"] = pid
    session = dev.attach(pid)
    script = session.create_script(AGENT)
    script.load()
    return script.exports_sync, st, pid


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("cmd", choices=["scan", "next", "list", "write", "freeze", "reset", "ranges", "read"])
    ap.add_argument("args", nargs="*")
    ap.add_argument("--type", default=None, choices=list(TYPES))
    ap.add_argument("--package")
    ap.add_argument("--pid", type=int)
    ap.add_argument("--mode", default="eq", choices=["eq", "gt", "lt", "changed", "unchanged"])
    ap.add_argument("--max", type=int, default=5000)
    a = ap.parse_args()

    key = current_key(a.package); st = load_state(key)
    if a.cmd == "reset":
        st = {"pid": None, "package": key, "type": None, "value": None, "addrs": []}
        save_state(key, st)
        print("reset")
        return

    if a.cmd == "ranges":
        ex, st, pid = attach(a, st)
        save_state(key, st)
        print(f"pid={pid} rw-ranges={len(ex.ranges())}")
        return

    typ = a.type or st.get("type") or "int32"

    if a.cmd == "scan":
        val = float(a.args[0]) if typ in ("float", "double") else int(a.args[0], 0)
        ex, st, pid = attach(a, st)
        addrs = ex.scan(val, typ, a.max)
        st.update(type=typ, value=val, addrs=addrs, pid=pid)
        save_state(key, st)
        print(f"pid={pid} type={typ} value={val} hits={len(addrs)}{' (capped)' if len(addrs) >= a.max else ''}")
        for i, ad in enumerate(addrs[:20]):
            print(f"  [{i}] {ad}")
        return

    if a.cmd == "next":
        val = float(a.args[0]) if typ in ("float", "double") else int(a.args[0], 0)
        addrs = st.get("addrs") or []
        if not addrs:
            sys.exit("agm: empty result set; run scan first")
        ex, st, pid = attach(a, st)
        vals = ex.readMany(addrs, typ)
        keep = []
        for ad, cur in zip(addrs, vals):
            if cur is None:
                continue
            ok = {
                "eq": cur == val, "gt": cur > val, "lt": cur < val,
                "changed": cur != st.get("value"), "unchanged": cur == st.get("value"),
            }[a.mode]
            if ok:
                keep.append(ad)
        st.update(value=val, addrs=keep, type=typ, pid=pid)
        save_state(key, st)
        print(f"mode={a.mode} value={val} remaining={len(keep)}/{len(addrs)}")
        for i, ad in enumerate(keep[:20]):
            print(f"  [{i}] {ad}")
        return

    if a.cmd == "list":
        addrs = st.get("addrs") or []
        print(f"pid={st.get('pid')} type={st.get('type')} value={st.get('value')} count={len(addrs)}")
        if a.args and a.args[0] == "--read" or getattr(a, "read", False):
            pass
        for i, ad in enumerate(addrs[: a.max]):
            print(f"  [{i}] {ad}")
        return

    if a.cmd == "read":
        addrs = [x.strip() for x in a.args] or (st.get("addrs") or [])[: a.max]
        ex, st, pid = attach(a, st)
        save_state(key, st)
        for ad, v in zip(addrs, ex.readMany(addrs, typ)):
            print(f"{ad} = {v}")
        return

    if a.cmd in ("write", "freeze"):
        target, val = a.args[0], a.args[1]
        addrs = st.get("addrs") or []
        if target.isdigit() and int(target) < len(addrs):
            targets = [addrs[int(target)]]
        elif target.startswith("all"):
            targets = addrs
        else:
            targets = [target]
        v = float(val) if typ in ("float", "double") else int(val, 0)
        ex, st, pid = attach(a, st)
        save_state(key, st)
        res = ex.writeMany(targets, typ, v)
        print(f"write {typ}={v} -> {sum(res)}/{len(targets)} ok")
        if a.cmd == "freeze":
            print("freezing (Ctrl-C to stop)")
            try:
                while True:
                    ex.writeMany(targets, typ, v)
                    time.sleep(0.25)
            except KeyboardInterrupt:
                print("unfrozen")


if __name__ == "__main__":
    main()
