```md
# 流星存档管理器

`local.lx.offline.game`（Unity + 内置 Python 服务器的单机测试版）的独立安卓存档工具，作者 **Null993**。
管理范围是游戏私有目录下 `files/server/work/local_server/` 的整组进度文件；游戏程序、运行环境、设备激活信息不参与迁移。

## 功能

- **当前存档**：读取正在使用的游戏进度，显示角色资料（等级、经验、元宝、银两、体力、生涯点、兵器谱星数、背包、通关数），一键创建完整备份。
- **存档库**：每份备份有独立 ID 与名称／备注，可改名、删除、查看完整文件清单和还原。
- **新建存档**：先自动备份当前全部进度，再切换到初始角色。新角色不继承旧档装备、技能、关卡和兑换记录。
- **导入导出**：多选存档打包为一个 ZIP；导入只加入存档库，同名并存，不覆盖当前游戏档。
- **Root 门禁**：启动时只读检测设备是否已 Root、用的是哪个管理器（Magisk／KernelSU／ReSukiSU／APatch／SuperSU 等）。已 Root 但未授权时，页面会给出“请求 Root 授权”按钮并自动发起一次请求，Root 管理器弹窗里允许后自动继续；未 Root 的设备不提供任何功能。

## 存档范围与兼容策略

已核对最新游戏包 `.603`：角色模板、六个进度文件和关键格式保持兼容，v0.2.0 补充修炼与实例数据校验、预览及官方转移保护。详见 [兼容性核对](docs/compatibility-603.md)。

- 范围由 `app/assets/profile.json` 声明，写入前核对游戏当前的进度文件清单。出现新增、改名或无法识别的进度文件时，备份照常保存全部字节，但**阻止切换**并说明原因。
- 每份备份记录完整文件清单、缺失项（`○ 文件原本不存在`）、格式标识和 SHA-256。还原前先完整备份当前进度，写入失败或进程中断会回滚整组旧文件。
- 兼容性按存档结构校验（`schema`、字段类型、数值范围），不绑定游戏版本号；版本升级只要格式兼容即可继续使用。
- 兵器谱星数为存档 `weapon_bonds` 各级别之和，与游戏“武库 → 兵器谱 → 总星数”一致。

## v0.2.0

- 适配 `.603` 的内功、化神、心法、饰品和随从原生数据，预览新增修炼概况；完整备份、还原和新建仍处理全部进度。
- 排除运行环境覆盖层内已知程序／配置，仍保留并阻止自动切换未知新增进度。
- 官方 `no_backup/save-move.json` 或 `.bak` 存在时阻止交叉读取、切换和恢复；不迁移激活信息和官方转移令牌。
- 关于页新增“检查更新”，读取 [最新正式 Release](https://github.com/Null993/LX-SaveManager/releases/latest)，验证包名、版本及原签名后通过 Root 覆盖安装，保留本机存档库。
- 工具 ZIP 不是官方 `.lxsave`，不替代游戏的换机验证；联网帮派状态仍由游戏服务器维护。

发布仓库：[Null993/LX-SaveManager](https://github.com/Null993/LX-SaveManager)。作者 **Null993**。

## 构建

需要 JDK 17、Android SDK（build-tools 36.0.0、platform android-35）；不使用 Gradle 联网下载。

```bash
python tools/build.py            # dist/LX-SaveManager-v0.2.0.apk（正式签名）
python tools/build.py --debug    # 附带 DeviceSelfTest / PreviewActivity 的调试包
python tools/test.py             # 主机回归测试（真实 POSIX 文件事务）
python tools/verify_release.py   # 校验签名、版本、资源一致性
python tools/ui_check.py <serial># 真机界面审计：6 个页面 × 3 档字号
```

## 签名

正式包使用 `.keys/savemanager-release.p12`（PKCS12，RSA 3072，自签名 `CN=Null993 LX Save Manager`）。
签名密钥与 `build/`、`dist/` 均在 `.gitignore` 中，**不进入版本库**；换机或重装系统前请另行备份该文件，否则后续版本无法覆盖安装。

## 注意

卸载管理器会删除本机存档库（含自动备份）。重要存档请导出 ZIP 到文档目录后再卸载。

package local.lx.savemanager;

import org.json.*;
import java.io.*;
import java.util.*;
import java.util.zip.*;
import java.nio.charset.StandardCharsets;

/** Portable multi-save ZIP; hashes and complete scope are checked before publication. */
public final class Archives {
    private Archives() {}
    public static void exportZip(Library library,Collection<String> ids,OutputStream output,String gamePackage) throws Exception {
        if(ids.isEmpty())throw new IOException("请先选择要导出的存档。");if(ids.size()>1024)throw new IOException("每个 ZIP 最多 1024 份存档，请分批导出。");JSONArray rows=new JSONArray();Map<String,Snapshot> snapshots=new LinkedHashMap<>();
        long bytes=0;for(String id:ids){Snapshot s=library.read(id);for(byte[] b:s.data.values())bytes+=b.length;if(bytes>FilesEx.TOTAL_LIMIT)throw new IOException("单个 ZIP 的原始数据最多 256 MiB，请分批导出。");JSONObject metadata=library.metadata(id);rows.put(metadata);snapshots.put(id,s);}
        JSONObject manifest=new JSONObject().put("format","lx-save-manager").put("version",1).put("game_package",gamePackage).put("exported_at",System.currentTimeMillis()).put("saves",rows);
        byte[] manifestBytes=FilesEx.bytes(manifest);int entries=1;for(Snapshot s:snapshots.values())entries+=s.data.size();if(manifestBytes.length>8*1024*1024||bytes+manifestBytes.length>FilesEx.TOTAL_LIMIT||entries>20000)throw new IOException("导出清单或总数据过大，请分批导出。");
        try(ZipOutputStream zip=new ZipOutputStream(output,StandardCharsets.UTF_8)){
            put(zip,"manifest.json",manifestBytes);for(Map.Entry<String,Snapshot> row:snapshots.entrySet())for(Map.Entry<String,byte[]> f:row.getValue().data.entrySet())put(zip,"saves/"+row.getKey()+"/files/"+f.getKey(),f.getValue());
        }
    }
    private static void put(ZipOutputStream zip,String name,byte[] data) throws Exception {zip.putNextEntry(new ZipEntry(name));zip.write(data);zip.closeEntry();}
    public static List<JSONObject> importZip(Library library,InputStream input,File cache,String gamePackage) throws Exception {
        File temp=new File(cache,"import-"+Library.id());if(!temp.mkdirs())throw new IOException("无法建立导入临时目录。");
        try{
            Set<String> seen=new HashSet<>();long total=0;
            try(ZipInputStream zip=new ZipInputStream(input,StandardCharsets.UTF_8)){
                ZipEntry entry;while((entry=zip.getNextEntry())!=null){
                    String name=entry.getName();if(entry.isDirectory()){String path=name.endsWith("/")?name.substring(0,name.length()-1):name;if(!FilesEx.path(path))throw new IOException("ZIP 含不安全路径。");continue;}
                    if(!FilesEx.path(name)||!seen.add(name)||seen.size()>20000)throw new IOException("ZIP 含非法路径、重复文件或过多条目。");
                    if(!name.equals("manifest.json")&&!name.matches("saves/[a-f0-9-]{36}/files/.+"))throw new IOException("ZIP 包含清单外的文件。");
                    int limit=name.equals("manifest.json")?8*1024*1024:FilesEx.FILE_LIMIT;
                    File file=FilesEx.child(temp,name);File parent=file.getParentFile();if(!parent.isDirectory()&&!parent.mkdirs())throw new IOException("无法建立导入目录。");
                    try(FileOutputStream out=new FileOutputStream(file)){byte[] b=new byte[8192];int n,size=0;while((n=zip.read(b))!=-1){size+=n;total+=n;if(size>limit||total>FilesEx.TOTAL_LIMIT)throw new IOException("ZIP 解压数据超过上限。");out.write(b,0,n);}out.getFD().sync();}zip.closeEntry();
                }
            }
            JSONObject manifest=FilesEx.json(FilesEx.read(new File(temp,"manifest.json")));

    private byte[] exec(String[] command,int timeout) throws IOException {
        Process process;
        try{process=new ProcessBuilder(command).start();}
        catch(IOException e){throw new Denied("需要 Root 权限才能使用流星存档管理器。请在 Root 管理器中允许本应用。",e);}
        ExecutorService readers=Executors.newFixedThreadPool(2);
        Future<byte[]> out=readers.submit(()->FilesEx.read(process.getInputStream(),384*1024*1024));
        Future<byte[]> err=readers.submit(()->FilesEx.read(process.getErrorStream(),1024*1024));
        try{
            if(!process.waitFor(timeout,TimeUnit.MILLISECONDS)){process.destroyForcibly();throw new IOException("Root 操作超时，请确认授权状态。");}
            byte[] stdout=out.get(5,TimeUnit.SECONDS),stderr=err.get(5,TimeUnit.SECONDS);
            if(process.exitValue()!=0)throw new IOException("Root 操作失败："+new String(stderr,StandardCharsets.UTF_8).trim());return stdout;
        }catch(InterruptedException|ExecutionException|TimeoutException e){throw new IOException("读取 Root 输出失败。",e);}
        finally{process.destroy();readers.shutdownNow();}
    }

        return last=new Device(rooted,manager,pkg,detail);
    }

from pathlib import Path
import argparse
import os
import shutil
import subprocess
import zipfile
import re

ROOT = Path(__file__).resolve().parents[1]
VERSION = '0.2.0'


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument('--debug', action='store_true')
    parser.add_argument('--version',default=VERSION)
    parser.add_argument('--version-code',type=int,default=6)
    args = parser.parse_args()
    if not re.fullmatch(r'[0-9]+\.[0-9]+\.[0-9]+',args.version) or args.version_code<1:
        parser.error('A numeric version and positive version code are required')
    sdk = Path(os.environ.get('ANDROID_HOME', Path.home() / 'AppData/Local/Android/Sdk'))
    jdk = Path(os.environ.get('LX_MANAGER_JDK', Path.home() / '.jdks/microsoft-jdk-17.0.16'))
    if not (jdk / 'bin/javac.exe').exists():
        jdk = next(jdk.glob('jdk-*'))
    bt = sdk / 'build-tools/36.0.0'
    android = sdk / 'platforms/android-35/android.jar'
    build = ROOT / 'build' / ('debug' if args.debug else 'release')
    build.mkdir(parents=True, exist_ok=True)
    classes = build / 'classes'
    assert classes.resolve().is_relative_to((ROOT / 'build').resolve())
    if classes.exists():
        shutil.rmtree(classes)
    classes.mkdir()
    generated = build / 'generated'
    generated.mkdir(exist_ok=True)
    env = dict(os.environ, JAVA_HOME=str(jdk))
    env['PATH'] = str(jdk / 'bin') + os.pathsep + env.get('PATH', '')
    def run(*cmd):
        subprocess.run(list(map(str, cmd)), check=True, cwd=ROOT, env=env)
    run(bt / 'aapt2.exe', 'compile', '--dir', ROOT / 'app/res', '-o', build / 'resources.zip')
    manifest = (ROOT / 'app/AndroidManifest.xml').read_text('utf8')
    if args.debug:
        manifest = manifest.replace('<application ', '<application android:debuggable="true" ')
        manifest = manifest.replace('</application>', '<activity android:name=".PreviewActivity" android:exported="true" /><activity android:name=".DeviceSelfTest" android:exported="true" /></application>')
    (build / 'AndroidManifest.xml').write_text(manifest, 'utf8')
    run(bt / 'aapt2.exe', 'link', '-I', android, '--manifest', build / 'AndroidManifest.xml', '-A', ROOT / 'app/assets',
        '--java', generated, '--version-code', args.version_code, '--version-name', args.version, '-o', build / 'unsigned.apk', build / 'resources.zip')
    sources = list((ROOT / 'app/src').rglob('*.java')) + list(generated.rglob('*.java'))
    if args.debug:
        sources += list((ROOT / 'tests/device').rglob('*.java'))
    run(jdk / 'bin/javac.exe', '-encoding', 'UTF-8', '--release', '8', '-classpath', android, '-d', classes, *sources)
    with zipfile.ZipFile(build / 'classes.jar', 'w') as jar:
        for file in classes.rglob('*.class'):
            jar.write(file, file.relative_to(classes).as_posix())
    run(jdk / 'bin/java.exe', '-cp', bt / 'lib/d8.jar', 'com.android.tools.r8.D8', '--lib', android,
        '--min-api', '26', '--output', build, build / 'classes.jar')
    with zipfile.ZipFile(build / 'unsigned.apk', 'a', compression=zipfile.ZIP_DEFLATED) as apk:
        apk.write(build / 'classes.dex', 'classes.dex')
    run(bt / 'zipalign.exe', '-f', '4', build / 'unsigned.apk', build / 'aligned.apk')
    key = ROOT / '.keys/savemanager-release.p12'
    key.parent.mkdir(exist_ok=True)
    if not key.exists():
        run(jdk / 'bin/keytool.exe', '-genkeypair', '-keystore', key, '-storetype', 'PKCS12',
            '-storepass', 'lx-manager-local-build', '-keypass', 'lx-manager-local-build', '-alias', 'lx-manager',
            '-keyalg', 'RSA', '-keysize', '3072', '-validity', '3650', '-dname', 'CN=Null993 LX Save Manager')
    output = ROOT / 'dist' / ('LX-SaveManager-debug.apk' if args.debug else f'LX-SaveManager-v{args.version}.apk')
    output.parent.mkdir(exist_ok=True)
    run(jdk / 'bin/java.exe', '-jar', bt / 'lib/apksigner.jar', 'sign', '--ks', key,
        '--ks-pass', 'pass:lx-manager-local-build', '--out', output, build / 'aligned.apk')
    run(jdk / 'bin/java.exe', '-jar', bt / 'lib/apksigner.jar', 'verify', '--verbose', output)
    print(f'Built {output} ({output.stat().st_size:,} bytes)')


if __name__ == '__main__':
    main()

    parser = argparse.ArgumentParser()
    parser.add_argument('device')
    parser.add_argument('--scales', default='1.0,1.5,2.0')
    args = parser.parse_args()
    output = ROOT / 'dist/verification/ui' / args.device
    output.mkdir(parents=True, exist_ok=True)

    def adb(*cmd, check=True):
        return subprocess.run(['adb', '-s', args.device, *map(str, cmd)], check=check, capture_output=True).stdout

    def screen():
        value = adb('shell', 'wm', 'size').decode().strip().splitlines()
        width, height = map(int, re.findall(r'(\d+)x(\d+)', value[-1])[0])
        return width, height

    def nodes():
        adb('shell', 'uiautomator', 'dump', '/sdcard/lx-manager-check.xml')
        data = adb('exec-out', 'cat', '/sdcard/lx-manager-check.xml')
        return list(ET.fromstring(data).iter('node')), data

    def box(node):
        return tuple(map(int, re.findall(r'\d+', node.get('bounds'))))

    def tap(node):
        x1, y1, x2, y2 = box(node)
        adb('shell', 'input', 'tap', (x1 + x2) // 2, (y1 + y2) // 2)

    def scroll_to(match, tries=8):
        """Scroll the page body until the wanted node is on screen and tappable."""
        width, height = screen()
        for _ in range(tries):
            ns, _ = nodes()
            for n in ns:
                if match(n) and n.get('enabled') == 'true':
                    x1, y1, x2, y2 = box(n)
                    if y1 >= 0 and y2 <= height:
                        return n
            adb('shell', 'input', 'swipe', width // 2, int(height * .62), width // 2, int(height * .38), 320)
            time.sleep(.3)
        raise AssertionError('target node is not reachable by scrolling')

    def by_text(value):
        return lambda n: n.get('text') == value

    def by_desc(value):
        return lambda n: n.get('content-desc') == value

    def screenshot(name):
        b = adb('exec-out', 'screencap', '-p')
        start = b.find(b'\x89PNG\r\n\x1a\n')
        assert start >= 0
        (output / (name + '.png')).write_bytes(b[start:])

    def boot(page, scale, gate=None):
        adb('shell', 'run-as', PACKAGE, 'mkdir', '-p', 'files')
        subprocess.run(['adb', '-s', args.device, 'shell', 'run-as', PACKAGE, 'tee', 'files/preview-font.txt'],
                       input=scale.encode(), capture_output=True, check=True)
        adb('shell', 'run-as', PACKAGE, 'rm', '-f', 'files/layout-audit.json')
        extra = ['--es', 'gate', gate] if gate else []
        adb('shell', 'am', 'start', '-W', '-S', '-n', PACKAGE + '/.PreviewActivity', '--ei', 'page', page,
            '--ef', 'font_scale', scale, '--ez', 'sandbox_preview', 'true', *extra)
        for _ in range(40):
            raw = adb('shell', 'run-as', PACKAGE, 'cat', 'files/layout-audit.json', check=False)
            try:
                result = json.loads(raw)
                if abs(result['font_scale'] - float(scale)) < .01:
                    return result
            except (ValueError, KeyError):
                pass
            time.sleep(.15)
        raise AssertionError('preview did not produce layout audit')

    def check_navigation():
        width, height = screen()
        ns, _ = nodes()
        nav = [n for n in ns if n.get('content-desc', '').startswith('导航：')]
        assert len(nav) == 5, [n.get('content-desc') for n in nav]
        for item in nav:
            x1, y1, x2, y2 = box(item)
            assert item.get('enabled') == 'true'
            assert y2 <= height, ('navigation cut by screen bottom', item.get('content-desc'), y2, height)
            labels = [n for n in ns if n.get('text') and box(n)[0] >= x1 and box(n)[2] <= x2]
            texts = [n.get('text') for n in labels]
            assert texts, ('navigation item has no visible label', item.get('content-desc'))
            for n in labels:
                assert box(n)[3] <= y2, ('navigation label clipped', n.get('text'), box(n), y2)

    checks = []

            ns, xml = nodes()
            texts = [n.get('text', '') for n in ns]
            assert not result['issues'], result

    assert ' KB' in text or ' B' in text
