`README.md`:

```md
# SAC — Super Anti Cheat

Серверный алгоритмический античит для **Counter-Strike 2**, работающий поверх
[Metamod:Source](https://www.sourcemm.net/) и [CounterStrikeSharp](https://docs.cssharp.dev/).

> **SAC 1.0** — текущая, полностью алгоритмическая версия, без использования ИИ/LLM.
> Дальнейшее развитие проекта: **SACnet** (закрытая сеть доверенных игроков) и **SAC 2.0** (SAC 1.0 + ИИ) ведутся отдельно.
> Плагин работает автономно на CS2-сервере — внешние интеграции (например, Telegram-бот) не используются.

## Возможности

- **17 алгоритмических модулей детекции**: Aimbot, Aimlock, SilentAim, InhumanAccuracy,
  IrregularBehavior, AutoStrafe, Bhop, Hyperscroll, Nulls, AntiAim, DllInjection,
  DeSubticking, DoubleTap, InvalidCvar, InvalidInput, NameChanger, SubtickSpam.
- **Система жалоб** через внутриигровую команду `!sac_report` (игровое меню выбора цели и причины).
- **Массовая проверка сервера**: при 3 уникальных жалобах на одного игрока за 10 минут
  все модули временно ужесточают чувствительность в 2 раза на 3 минуты.
- **Система из 4 прогрессивных предупреждений**: попытки 1–2 — простое убийство (slay),
  попытка 3 — обнуление игрового баланса + slay, попытка 4 — бан на 168 часов и кик.
  Счётчик сохраняется между сессиями (`warnings.json`) и сбрасывается после 10 "чистых" раундов.
- **Показательное устранение читера ботом «SAC»** (`SacKillService`) — доступно как отдельная
  демонстративная механика для активных, ещё не забаненных читеров.
- **Поведение забаненных игроков**: могут зайти на сервер и выбрать команду, но автоматически
  убиваются в начале каждого раунда, пока действует временный бан (`bans.json`).
- **Режим "шизофрении"**: психологическое давление на читера перед финальным баном
  (фейковые сообщения, фейковые уведомления SAC, фейковый VAC-экран, ослепление,
  сброс оружия, заморозка, фейковые игроки, "невидимые ловушки").
- **Окно согласия на сбор данных** при подключении — отказ ведёт к кику с обратным отсчётом.
- **Подсказка о команде жалобы** в начале каждого раунда.
- **Автобан и отмена матча** в Competitive/Premier/Wingman при финальном (4-м) предупреждении.
- **SACnet**: реестр доверенных игроков с пожизненным баном за измену сети.
- **Запись демок матча** через SourceTV (`tv_record`/`tv_stoprecord`), привязанных к метаданным матча.
- **Сбор анонимизированного датасета** игровых событий (SteamID хешируется SHA-256,
  ники заменяются), включая отдельные персональные логи по каждому игроку.

## Требования

- CS2 Dedicated Server
- [Metamod:Source](https://www.sourcemm.net/downloads/) (последняя версия под CS2)
- [CounterStrikeSharp](https://github.com/roflmuffin/CounterStrikeSharp) v1.0.305+
- .NET SDK 8.0 (для сборки)

## Установка

1. Соберите проект (см. раздел «Сборка») или скачайте готовую сборку.
2. Скопируйте содержимое `bin/Release/net8.0/` (включая `SAC.dll` и папку `Config/`)
   в `game/csgo/addons/counterstrikesharp/plugins/SAC/`.
3. Отредактируйте `Config/sac_config.json` — обязательно смените `salt` на случайную
   строку из 32 символов.
4. Перезапустите сервер или выполните `css_plugins reload SAC`.

## Сборка

```bash
git clone https://github.com/<your-org>/SAC-AntiCheat.git
cd SAC-AntiCheat
dotnet restore
dotnet build -c Release
```

Готовая сборка появится в `SAC/bin/Release/net8.0/SAC.dll`.

## Система прогрессивных предупреждений

При срабатывании любого модуля детекции игроку не выносится мгновенный бан — вместо этого
применяется последовательность из 4 попыток (`WarningCounterService`):

1. **Попытка 1/4** — центральная табличка с предупреждением + простое убийство (`slay`).
2. **Попытка 2/4** — аналогично попытке 1.
3. **Попытка 3/4** — обнуление баланса в игровом магазине + `slay`.
4. **Попытка 4/4** — бан на `ban_duration_hours` часов (по умолчанию 168), кик с сервера,
   отмена матча в соревновательном режиме.

Счётчик хранится в `warnings.json` и сбрасывается, если игрок отыграл `warning_reset_after_clean_rounds`
раундов подряд без единого срабатывания детекторов.

## Датасет

SteamID никогда не хранится в открытом виде — только SHA-256 хеш с солью из конфигурации.
Формат — JSONL, ротация файлов по дням (`ГГГГ-ММ-ДД.jsonl`). Записи демок матчей (SourceTV)
привязываются к соответствующему `dataset/meta/match_<id>.json` через поле `demo_file`.

using Newtonsoft.Json;

namespace SAC.Config
{
    /// <summary>
    /// Конфигурация плагина SAC, загружаемая из Config/sac_config.json.
    /// </summary>
    public class SacConfig
    {
        [JsonProperty("salt")]
        public string Salt { get; set; } = "CHANGE_ME_TO_RANDOM_32_CHARS";

        [JsonProperty("http_port")]
        public int HttpPort { get; set; } = 27016;

        [JsonProperty("reports_for_masscheck")]
        public int ReportsForMassCheck { get; set; } = 3;

        [JsonProperty("report_window_seconds")]
        public int ReportWindowSeconds { get; set; } = 600;

        [JsonProperty("aimbot_max_angular_velocity")]
        public float AimbotMaxAngularVelocity { get; set; } = 1200f;

        [JsonProperty("aimbot_preshot_window")]
        public float AimbotPreshotWindow { get; set; } = 0.2f;

        [JsonProperty("bhop_timing_tolerance")]
        public float BhopTimingTolerance { get; set; } = 0.02f;

        [JsonProperty("inhuman_accuracy_threshold")]
        public float InhumanAccuracyThreshold { get; set; } = 0.8f;

        [JsonProperty("competitive_game_modes")]
        public int[] CompetitiveGameModes { get; set; } = new[] { 1, 2 };

        [JsonProperty("warning_attempts_before_ban")]
        public int WarningAttemptsBeforeBan { get; set; } = 4;

        [JsonProperty("warning_reset_after_clean_rounds")]
        public int WarningResetAfterCleanRounds { get; set; } = 10;

        [JsonProperty("ban_duration_hours")]
        public int BanDurationHours { get; set; } = 168;

        [JsonProperty("demo_recording_enabled")]
        public bool DemoRecordingEnabled { get; set; } = true;

        [JsonProperty("demo_folder")]
        public string DemoFolder { get; set; } = "dataset/demos";

        [JsonProperty("consent_required")]
        public bool ConsentRequired { get; set; } = true;

        [JsonProperty("consent_kick_delay_seconds")]
        public int ConsentKickDelaySeconds { get; set; } = 5;

        [JsonProperty("tip_message_enabled")]
        public bool TipMessageEnabled { get; set; } = true;

        /// <summary>
        /// Загружает конфигурацию из файла. Если файл отсутствует — создаёт со значениями по умолчанию.
        /// </summary>
        public static SacConfig Load(string path)
        {
            if (!File.Exists(path))
            {
                var def = new SacConfig();
                File.WriteAllText(path, JsonConvert.SerializeObject(def, Formatting.Indented));
                return def;
            }

            var json = File.ReadAllText(path);
            return JsonConvert.DeserializeObject<SacConfig>(json) ?? new SacConfig();
        }
    }
}

`SAC/Modules/AimbotModule.cs`:

```cs
using CounterStrikeSharp.API.Core;
using CounterStrikeSharp.API.Modules.Events;
using CounterStrikeSharp.API.Modules.Utils;
using SAC.Config;

namespace SAC.Modules
{
    /// <summary>
    /// Детектирует резкие рывки прицела ("снап-аим"), сравнивая угол обзора
    /// незадолго до выстрела с углом обзора в момент выстрела.
    /// </summary>
    public class AimbotModule : IModule
    {
        public string Name => "Aimbot";

        private readonly SacConfig _config;
        private readonly Action<CCSPlayerController, string, string> _onDetected;
        private readonly Dictionary<ulong, RollingHistory<AngleSnapshot>> _history = new();
        private float _multiplier = 1.0f;

        private const int HistoryCapacity = 32;

        public AimbotModule(SacConfig config, Action<CCSPlayerController, string, string> onDetected)
        {
            _config = config;
            _onDetected = onDetected;
        }

        public void SetSensitivityMultiplier(float multiplier) => _multiplier = multiplier;

        public void OnRoundStart() => _history.Clear();

        /// <summary>
        /// Должен вызываться каждый серверный тик из SACPlugin для накопления истории углов.
        /// </summary>
        public void RecordAngle(CCSPlayerController player)
        {
            if (player.PlayerPawn?.Value == null) return;

            var steamId = player.SteamID;
            var angle = player.PlayerPawn.Value.EyeAngles;
            var now = Server.CurrentTime;

            if (!_history.TryGetValue(steamId, out var hist))
            {
                hist = new RollingHistory<AngleSnapshot>(HistoryCapacity);
                _history[steamId] = hist;
            }

            hist.Add(new AngleSnapshot(now, angle));
        }

        public void OnWeaponFire(CCSPlayerController player, EventWeaponFire @event)
        {
            if (!_history.TryGetValue(player.SteamID, out var hist) || hist.Items.Count < 2) return;

            var now = Server.CurrentTime;
            var preShotWindow = _config.AimbotPreshotWindow;

            // Ищем снимок, максимально близкий к началу окна "до выстрела"
            AngleSnapshot? beforeShot = null;
            foreach (var snap in hist.Items)
            {
                if (now - snap.Timestamp >= preShotWindow)
                {
                    beforeShot = snap;
                }
            }

            if (beforeShot == null) return;

            var lastSnap = hist.Items[^1];
            var angularVelocity = AngleMath.AngularVelocity(beforeShot.Value, lastSnap);
            var threshold = _config.AimbotMaxAngularVelocity * _multiplier;

            if (angularVelocity >= threshold)
            {
                _onDetected(player, Name,
                    $"Резкий рывок прицела перед выстрелом: {angularVelocity:F0}°/с (порог {threshold:F0}°/с)");
            }
        }

        public void OnPlayerHurt(CCSPlayerController victim, CCSPlayerController attacker, EventPlayerHurt @event)
        {
            // Основная логика Aimbot строится вокруг выстрела, урон здесь дополнительно не анализируется.
        }
    }
}

`SAC/Modules/AimlockModule.cs`:

```cs
using CounterStrikeSharp.API.Core;
using CounterStrikeSharp.API.Modules.Events;
using SAC.Config;

namespace SAC.Modules
{
    /// <summary>
    /// Детектирует "аимлок" — аномально точное удержание прицела на движущейся цели
    /// на протяжении длительного времени.
    /// </summary>
    public class AimlockModule : IModule
    {
        public string Name => "Aimlock";

        private readonly SacConfig _config;
        private readonly Action<CCSPlayerController, string, string> _onDetected;

        // Для каждого атакующего храним, сколько секунд подряд его прицел
        // удерживает крайне малое отклонение от цели, и время начала слежения.
        private readonly Dictionary<ulong, (ulong targetSteamId, double lockStartedAt, float minDeltaSum, int samples)> _tracking = new();

        private float _multiplier = 1.0f;
        private const float MaxDeltaDegrees = 1.5f; // максимальное отклонение прицела от цели, считающееся "точным слежением"
        private const double RequiredLockSeconds = 1.0;

        public AimlockModule(SacConfig config, Action<CCSPlayerController, string, string> onDetected)
        {
            _config = config;
            _onDetected = onDetected;
        }

        /// </summary>

            var now = Server.CurrentTime;
            var steamId = attacker.SteamID;

            {
                _tracking.Remove(steamId);
                return;

            {
                _tracking[steamId] = (target.SteamID, now, angleDeltaToTarget, 1);
                return;

            state.samples += 1;
            _tracking[steamId] = state;

            if (lockedDuration >= RequiredLockSeconds)
            {
                var avgDelta = state.minDeltaSum / state.samples;
                _onDetected(attacker, Name,
                    $"Аномально точное сопровождение цели {lockedDuration:F1} с подряд (ср. отклонение {avgDelta:F2}°)");

            }
        }

        /// <summary>
        /// Вызывается каждый тик из SACPlugin для игроков, находящихся в воздухе.
        /// </summary>
        public void RecordAirMovement(CCSPlayerController player, MovementSnapshot snapshot)
        {
            var steamId = player.SteamID;

            if (snapshot.OnGround)
            {
                if (_airHistory.TryGetValue(steamId, out var landedHist) && landedHist.Items.Count > 10)
                {
                    AnalyzeStability(player, landedHist);
                }
                _airHistory.Remove(steamId);
                return;
            }

            if (!_airHistory.TryGetValue(steamId, out var hist))
            {
                hist = new RollingHistory<MovementSnapshot>(HistoryCapacity);
                _airHistory[steamId] = hist;
            }

            hist.Add(snapshot);
        }

        private void AnalyzeStability(CCSPlayerController player, RollingHistory<MovementSnapshot> hist)
        {
            var speeds = hist.Items.Select(s => Math.Sqrt(s.Velocity.X * s.Velocity.X + s.Velocity.Y * s.Velocity.Y)).ToList();
            var mean = speeds.Average();
            if (mean < 50) return; // слишком медленное движение, не показательно

            var variance = speeds.Sum(s => (s - mean) * (s - mean)) / speeds.Count;
            var relativeVariance = variance / (mean * mean);

            var threshold = MaxSpeedVarianceRatio * _multiplier;

            if (relativeVariance <= threshold)
            {
                _onDetected(player, Name,
                    $"Аномально стабильное сохранение скорости в воздухе: отн. дисперсия {relativeVariance:F4} (порог {threshold:F4})");
            }
        }

using CounterStrikeSharp.API.Modules.Utils;

namespace SAC.Modules
{
    /// <summary>
    /// Снимок положения прицела игрока в конкретный момент времени.
    /// Используется модулями AimbotModule, AimlockModule, AntiAimModule и др.
    /// для анализа истории движения прицела.
    /// </summary>
    public readonly struct AngleSnapshot
    {
        public readonly double Timestamp;
        public readonly QAngle Angle;

        public AngleSnapshot(double timestamp, QAngle angle)
        {
            Timestamp = timestamp;
            Angle = angle;
        }
    }

    /// <summary>
    /// Снимок скорости и положения игрока для анализа движения (bhop, autostrafe, nulls).
    /// </summary>
    public readonly struct MovementSnapshot
    {
        public readonly double Timestamp;
        public readonly Vector Velocity;
        public readonly bool OnGround;
        public readonly bool JumpPressed;

        public MovementSnapshot(double timestamp, Vector velocity, bool onGround, bool jumpPressed)
        {
            Timestamp = timestamp;
            Velocity = velocity;
            OnGround = onGround;
            JumpPressed = jumpPressed;
        }
    }

    /// <summary>
    /// Скользящая история фиксированного размера для хранения снимков по каждому игроку.
    /// </summary>
    public class RollingHistory<T>
    {
        private readonly List<T> _items = new();
        private readonly int _capacity;

        public RollingHistory(int capacity)
        {
            _capacity = capacity;
        }

        public IReadOnlyList<T> Items => _items;

        public void Add(T item)
        {
            _items.Add(item);
            if (_items.Count > _capacity)
            {
                _items.RemoveAt(0);
            }
        }

        public void Clear() => _items.Clear();
    }

    /// <summary>
    /// Вспомогательные математические функции для расчёта углов обзора.
    /// </summary>
    public static class AngleMath
    {
        /// <summary>
        /// Считает кратчайшую угловую разницу между двумя углами в градусах (с учётом перехода через 180/-180).
        /// </summary>
        public static float DeltaDegrees(float a, float b)
        {
            float diff = (a - b) % 360f;
            if (diff > 180f) diff -= 360f;
            if (diff < -180f) diff += 360f;
            return Math.Abs(diff);
        }

        /// <summary>
        /// Суммарная угловая скорость (yaw + pitch) между двумя снимками, градусов в секунду.
        /// </summary>
        public static float AngularVelocity(AngleSnapshot from, AngleSnapshot to)
        {
            double dt = to.Timestamp - from.Timestamp;
            if (dt <= 0.0001) return 0f;

            float dYaw = DeltaDegrees(to.Angle.Y, from.Angle.Y);
            float dPitch = DeltaDegrees(to.Angle.X, from.Angle.X);
            float dist = MathF.Sqrt(dYaw * dYaw + dPitch * dPitch);

            return (float)(dist / dt);
        }
    }
}

        private readonly Dictionary<ulong, (bool left, bool right, double lastSwitchTime)> _lastState = new();
        private float _multiplier = 1.0f;

        private const int RequiredSamples = 10;
        private const double MaxIntervalStdDevSeconds = 0.01;

        public NullsModule(SacConfig config, Action<CCSPlayerController, string, string> onDetected)
        {
            _config = config;
            _onDetected = onDetected;

        public void SetSensitivityMultiplier(float multiplier) => _multiplier = multiplier;

        {
            _switchIntervals.Clear();
            _lastState.Clear();
        }

        public void OnWeaponFire(CCSPlayerController player, EventWeaponFire @event)
        {
        }

        public void OnPlayerHurt(CCSPlayerController victim, CCSPlayerController attacker, EventPlayerHurt @event)
        {
        }

        /// <summary>
        /// Вызывается каждый тик из SACPlugin с текущим состоянием клавиш движения влево/вправо.
        /// </summary>
        public void OnMoveInput(CCSPlayerController player, bool moveLeft, bool moveRight)
        {
            var steamId = player.SteamID;
            var now = Server.CurrentTime;

            if (!_lastState.TryGetValue(steamId, out var last))
            {
                _lastState[steamId] = (moveLeft, moveRight, now);
                return;
            }

            // Одновременное противоположное направление — явный признак "nulls"
            bool switched = (last.left != moveLeft) || (last.right != moveRight);
            if (!switched)
            {
                return;
            }

            var interval = now - last.lastSwitchTime;
            _lastState[steamId] = (moveLeft, moveRight, now);

            if (!_switchIntervals.TryGetValue(steamId, out var hist))
            {
                hist = new RollingHistory<double>(RequiredSamples);
                _switchIntervals[steamId] = hist;
            }
            hist.Add(interval);

            if (hist.Items.Count < RequiredSamples) return;

            var mean = hist.Items.Average();
            var variance = hist.Items.Sum(v => (v - mean) * (v - mean)) / hist.Items.Count;
            var stdDev = Math.Sqrt(variance);

            var threshold = MaxIntervalStdDevSeconds * _multiplier;

            if (stdDev <= threshold && mean < 0.3)
            {
                _onDetected(player, Name,
                    $"Стабильные машинные переключения направления движения: ст.откл. {stdDev * 1000:F1} мс (порог {threshold * 1000:F1} мс)");
                hist.Clear();
            }
        }
    }

        public override void Load(bool hotReload)
        {
            var configPath = Path.Combine(ModuleDirectory, "Config", "sac_config.json");
            _config = SacConfig.Load(configPath);

            ChatService = new ChatService();
            DataCollector = new DataCollector(ModuleDirectory, _config.Salt);
            SACnetRegistry = new SACnetRegistry(ModuleDirectory, ChatService);
            BanService = new BanService(ModuleDirectory, _config, ChatService, DataCollector, SACnetRegistry);
            WarningService = new WarningService();
            WarningCounterService = new WarningCounterService(ModuleDirectory, _config, BanService, DataCollector);
            SchizophreniaService = new SchizophreniaService();
            SacKillService = new SacKillService();
            ConsentService = new ConsentService(_config);

            InitializeModules();

            MassCheckService = new MassCheckService(ChatService, Modules);
            ReportService = new ReportService(_config, ChatService, MassCheckService);

            RegisterListeners();

            if (_config.DemoRecordingEnabled)
            {
                Server.ExecuteCommand("tv_enable 1");
                Server.ExecuteCommand("tv_autorecord 1");
            }

            if (hotReload)
            {
                CurrentMatchId = GenerateMatchId();
            }
        }

        public override void Unload(bool hotReload)
        {
            if (_demoRecordingActive)
            {
                Server.ExecuteCommand("tv_stoprecord");
            }
        }

        /// <summary>
        /// Обрабатывает обнаружение чита любым модулем: сначала показывает эффекты режима
        /// шизофрении и показательное устранение ботом SAC, затем передаёт управление
        /// в систему прогрессивных предупреждений (4 попытки перед окончательным баном).
        /// </summary>
        private void OnCheatDetected(CCSPlayerController player, string moduleName, string reason)
        {
            if (player?.IsValid != true) return;

            // Забаненные игроки не участвуют в детекции повторно — они уже отбывают бан.
            if (BanService.IsBanned(player.SteamID)) return;

            Server.PrintToConsole($"[SAC] Модуль {moduleName} обнаружил нарушение у {player.PlayerName}: {reason}");

            var attempt = WarningCounterService.RegisterDetection(player, moduleName, reason);

            // Показательный эффект — только для по-настоящему активных читеров, ещё не забаненных.
            if (attempt < _config.WarningAttemptsBeforeBan)
            {
                SchizophreniaService.Start(player);
            }
        }

        private void InitializeModules()
        {
            Action<CCSPlayerController, string, string> onDetected = OnCheatDetected;

            Modules = new List<IModule>
            {
                new AimbotModule(_config, onDetected),
                new AimlockModule(_config, onDetected),
                new SilentAimModule(_config, onDetected),
                new InhumanAccuracyModule(_config, onDetected),
                new IrregularBehaviorModule(_config, onDetected),
                new AutoStrafeModule(_config, onDetected),
                new BhopModule(_config, onDetected),
                new HyperscrollModule(_config, onDetected),
                new NullsModule(_config, onDetected),
                new AntiAimModule(_config, onDetected),
                new DllInjectionModule(_config, onDetected),
                new DeSubtickingModule(_config, onDetected),
                new DoubleTapModule(_config, onDetected),
                new InvalidCvarModule(_config, onDetected),
                new InvalidInputModule(_config, onDetected),

        private HookResult OnPlayerConnectFull(EventPlayerConnectFull @event, GameEventInfo info)
        {
            var player = @event.Userid;
            if (player?.IsValid != true || player.IsBot) return HookResult.Continue;

            WarningService.ShowWarningIfNeeded(player);

            if (BanService.IsBanned(player.SteamID))
            {
                player.PrintToCenterHtml(
                    "<font color='red' size='22'>Ваш аккаунт находится в SAC блокировке на этом сервере!</font><br/>" +
                    "<font color='white' size='16'>В начале раунда, вы будете автоматически убиты!</font>");
            }
            else
            {
                ConsentService.RequestConsent(player);
            }

            return HookResult.Continue;
        }

        private HookResult OnPlayerDisconnect(EventPlayerDisconnect @event, GameEventInfo info)
        {
            var player = @event.Userid;
            if (player?.IsValid == true)
            {
                ConsentService.ClearOnDisconnect(player.SteamID);
            }

            var connectedCount = Utilities.GetPlayers().Count(p => p is { IsValid: true, IsBot: false });
            WarningService.ResetIfServerEmpty(connectedCount - 1);
            return HookResult.Continue;
        }

        private HookResult OnRoundStart(EventRoundStart @event, GameEventInfo info)
        {
            if (string.IsNullOrEmpty(CurrentMatchId))
            {
                CurrentMatchId = GenerateMatchId();

                var players = Utilities.GetPlayers().Where(p => p is { IsValid: true, IsBot: false }).ToList();

                string? demoFile = null;
                if (_config.DemoRecordingEnabled)
                {
                    var demoName = $"{CurrentMatchId}_{DateTime.UtcNow:yyyy-MM-dd_HHmmss}";
                    demoFile = $"{_config.DemoFolder}/{demoName}.dem";
                    Server.ExecuteCommand($"tv_record {_config.DemoFolder}/{demoName}");
                    _demoRecordingActive = true;
                }

                DataCollector.SaveMatchMeta(CurrentMatchId, Server.MapName, players, demoFile);
            }

            foreach (var module in Modules)
            {
                module.OnRoundStart();
            }

            WarningCounterService.OnRoundStart();

            ChatService.PrintCheckStart();
            ChatService.PrintMatchId(CurrentMatchId);

            if (_config.TipMessageEnabled)
            {
                ChatService.PrintTip();
            }

            return HookResult.Continue;
        }

        private HookResult OnRoundEnd(EventRoundEnd @event, GameEventInfo info)
        {
            return HookResult.Continue;
        }

        private HookResult OnWeaponFire(EventWeaponFire @event, GameEventInfo info)
        {
            var player = @event.Userid;
            if (player?.IsValid != true) return HookResult.Continue;

            foreach (var module in Modules)
            {
                module.OnWeaponFire(player, @event);
            }

            return HookResult.Continue;
        }

        private HookResult OnPlayerHurt(EventPlayerHurt @event, GameEventInfo info)
        {
            var victim = @event.Userid;
            var attacker = @event.Attacker;

            if (victim?.IsValid != true || attacker?.IsValid != true) return HookResult.Continue;

            foreach (var module in Modules)
            {
                module.OnPlayerHurt(victim, attacker, @event);
            }

            return HookResult.Continue;
        }

        private HookResult OnPlayerDeath(EventPlayerDeath @event, GameEventInfo info)
        {
            return HookResult.Continue;
        }

        private HookResult OnPlayerSpawn(EventPlayerSpawn @event, GameEventInfo info)
        {
            var player = @event.Userid;
            if (player?.IsValid != true || player.IsBot) return HookResult.Continue;

            // Забаненный игрок может выбрать команду, но в начале каждого раунда его убивают.
            if (BanService.IsBanned(player.SteamID))
            {
                var pawn = player.PlayerPawn?.Value;
                if (pawn != null && pawn.IsValid)
                {
                    pawn.CommitSuicide(false, true);
                }
                else
                {
                    Server.ExecuteCommand($"slay {player.UserId}");
                }
                return HookResult.Continue;
            }

            var nameChangerModule = Modules.OfType<NameChangerModule>().FirstOrDefault();
            nameChangerModule?.CheckNameChange(player);

            return HookResult.Continue;
        }

        /// <summary>
        /// Генерирует случайный 8-символьный ID матча из безопасного алфавита
        /// (без визуально похожих символов вроде 0/O, 1/I).
        /// </summary>
        private string GenerateMatchId()
        {
            var chars = new char[8];
            for (int i = 0; i < 8; i++)
            {
                chars[i] = MatchIdAlphabet[_random.Next(MatchIdAlphabet.Length)];
            }
            return new string(chars);
        }
    }

using CounterStrikeSharp.API;
using CounterStrikeSharp.API.Core;
using CounterStrikeSharp.API.Modules.Cvars;
using CounterStrikeSharp.API.Modules.Menu;
using Newtonsoft.Json;
using SAC.Config;

namespace SAC.Services
{
    /// <summary>
    /// Запись о бане игрока, хранится в bans.json.
    /// </summary>
    public class BanRecord
    {
        [JsonProperty("steamid")]
        public string SteamId { get; set; } = string.Empty;

        [JsonProperty("banned_at")]
        public DateTime BannedAt { get; set; }

        [JsonProperty("expires_at")]
        public DateTime? ExpiresAt { get; set; }

        [JsonProperty("reason")]
        public string Reason { get; set; } = string.Empty;

        [JsonProperty("permanent")]
        public bool Permanent { get; set; }
    }

    /// <summary>
    /// Отвечает за бан обнаруженного читера, отмену соревновательного матча
    /// и предоставление доступа к апелляции.
    /// </summary>
    public class BanService
    {
        private readonly SacConfig _config;
        private readonly ChatService _chatService;
        private readonly DataCollector _dataCollector;
        private readonly SACnetRegistry _sacnetRegistry;
        private readonly string _bansFilePath;
        private readonly object _bansLock = new();
        private Dictionary<ulong, BanRecord> _bans = new();

        private const string EvidenceBaseUrl = "https://your-sac-server.com/evidence";

        public BanService(string pluginBaseDirectory, SacConfig config, ChatService chatService, DataCollector dataCollector, SACnetRegistry sacnetRegistry)
        {
            _config = config;
            _chatService = chatService;
            _dataCollector = dataCollector;
            _sacnetRegistry = sacnetRegistry;
            _bansFilePath = Path.Combine(pluginBaseDirectory, "bans.json");
            LoadBans();
        }

        private void LoadBans()
        {
            lock (_bansLock)
            {
                if (!File.Exists(_bansFilePath))
                {
                    _bans = new Dictionary<ulong, BanRecord>();
                    SaveBans();
                    return;
                }

                var json = File.ReadAllText(_bansFilePath);
                var list = JsonConvert.DeserializeObject<List<BanRecord>>(json) ?? new List<BanRecord>();
                _bans = list
                    .Where(b => ulong.TryParse(b.SteamId, out _))
                    .ToDictionary(b => ulong.Parse(b.SteamId), b => b);
            }
        }

        private void SaveBans()
        {
            lock (_bansLock)
            {
                var json = JsonConvert.SerializeObject(_bans.Values.ToList(), Formatting.Indented);
                File.WriteAllText(_bansFilePath, json);
            }
        }

        /// <summary>
        /// Проверяет, забанен ли игрок в данный момент. Автоматически снимает истёкшие временные баны.
        /// </summary>
        public bool IsBanned(ulong steamId)
        {
            lock (_bansLock)
            {
                if (!_bans.TryGetValue(steamId, out var ban)) return false;

                if (!ban.Permanent && ban.ExpiresAt.HasValue && ban.ExpiresAt.Value <= DateTime.UtcNow)
                {
                    _bans.Remove(steamId);
                    SaveBans();
                    return false;
                }

                return true;
            }
        }

        /// <summary>
        /// Возвращает запись о бане игрока, если он забанен, иначе null.
        /// </summary>
        public BanRecord? GetBan(ulong steamId)
        {
            lock (_bansLock)
            {
                return _bans.TryGetValue(steamId, out var ban) ? ban : null;
            }
        }

        /// <summary>
        /// Банит игрока на указанное количество часов (используется системой прогрессивных предупреждений).
        /// Дополнительно логирует в датасет и отменяет соревновательный матч при необходимости.
        /// </summary>
        public void BanTemporary(ulong steamId, int hours, string reason)
        {
            lock (_bansLock)
            {
                var record = new BanRecord
                {
                    SteamId = steamId.ToString(),
                    BannedAt = DateTime.UtcNow,
                    ExpiresAt = DateTime.UtcNow.AddHours(hours),
                    Reason = reason,
                    Permanent = false
                };

                _bans[steamId] = record;
                SaveBans();
            }

            var player = Utilities.GetPlayers().FirstOrDefault(p => p.IsValid && p.SteamID == steamId);
            var wasSacnetMember = _sacnetRegistry.IsMember(steamId);

            if (wasSacnetMember)
            {
                _sacnetRegistry.PermanentlyBan(steamId, reason);
            }

            if (player != null)
            {
                _dataCollector.MarkAsCheater(player, reason, wasSacnetMember);
                _chatService.PrintDetection(player.PlayerName, reason);
            }

            if (IsCompetitiveMode())
            {
                _chatService.PrintMatchCancelled();
                _chatService.PrintMatchCancelledHud();
                CancelMatch();
            }
        }

        /// <summary>
        /// Основная точка входа при обнаружении чита: банит игрока, логирует в датасет,
        /// исключает из SACnet при необходимости и отменяет соревновательный матч.
        /// </summary>
        public void BanAndCancelMatch(CCSPlayerController cheater, string reason)
        {
            var wasSacnetMember = _sacnetRegistry.IsMember(cheater.SteamID);

            if (wasSacnetMember)
            {
                _sacnetRegistry.PermanentlyBan(cheater.SteamID, reason);
            }

            _dataCollector.MarkAsCheater(cheater, reason, wasSacnetMember);

            _chatService.PrintDetection(cheater.PlayerName, reason);
            Server.PrintToChatAll($"[SAC] Данные игрока {cheater.PlayerName} добавлены в датасет для обучения SAC 2.0.");

            Server.ExecuteCommand($"kickid {cheater.UserId} \"[SAC] Обнаружен чит: {reason}\"");

            if (IsCompetitiveMode())
            {
                _chatService.PrintMatchCancelled();
                _chatService.PrintMatchCancelledHud();
                CancelMatch();
            }
        }

        /// <summary>
        /// Проверяет, является ли текущий режим соревновательным (game_type 0, game_mode 1 или 2).
        /// </summary>
        public bool IsCompetitiveMode()
        {
            var gameTypeCvar = ConVar.Find("game_type");
            var gameModeCvar = ConVar.Find("game_mode");

            if (gameTypeCvar == null || gameModeCvar == null) return false;

            var gameType = gameTypeCvar.GetPrimitiveValue<int>();
            var gameMode = gameModeCvar.GetPrimitiveValue<int>();

            return gameType == 0 && _config.CompetitiveGameModes.Contains(gameMode);
        }

        /// <summary>
        /// Отменяет текущий матч: перезапускает варм-ап и рестартует игру.
        /// </summary>
        public void CancelMatch()
        {
            Server.ExecuteCommand("mp_warmup_start");
            Server.ExecuteCommand("mp_warmup_pausetimer 1");
            Server.ExecuteCommand("mp_restartgame 1");
        }

        /// <summary>
        /// Открывает меню апелляции для забаненного игрока (доступно, например, через отдельный веб-интерфейс).
        /// </summary>
        public void OpenAppealMenu(CCSPlayerController player)
        {
            var menu = new CenterHtmlMenu("Апелляция SAC");

            menu.AddMenuOption("📥 Скачать доказательства", (p, option) =>
            {
                var url = $"{EvidenceBaseUrl}/{p.SteamID}.zip";
                p.PrintToChat($"[SAC] Ссылка на доказательства: {url}");
            });

            menu.AddMenuOption("📝 Подать апелляцию", (p, option) =>
            {
                p.PrintToChat("[SAC] Для подачи апелляции обратитесь в Telegram-бот SAC командой /appeal.");
            });

            MenuManager.OpenCenterHtmlMenu(null, player, menu);
        }
    }
}

using CounterStrikeSharp.API;
using CounterStrikeSharp.API.Core;
using CounterStrikeSharp.API.Modules.Menu;
using CounterStrikeSharp.API.Modules.Timers;
using SAC.Config;

namespace SAC.Services
{
    /// <summary>
    /// Показывает игроку окно согласия на сбор логов/видео для обучения SAC/SACnet
    /// сразу после подключения, до выбора команды. При отказе — кикает с обратным отсчётом.
    /// </summary>
    public class ConsentService
    {
        private readonly SacConfig _config;
        private readonly HashSet<ulong> _declinedThisSession = new();
        private readonly HashSet<ulong> _consentedThisSession = new();

        private const string ConsentText =
            "Продолжая играть на этом сервере, вы принимаете то,<br/>" +
            "что логи/видео вашей игры будут собираться для обучения<br/>" +
            "наших дальнейших античитов семейства SAC и SACnet!";

        public ConsentService(SacConfig config)
        {
            _config = config;
        }

        /// <summary>
        /// Показывает окно согласия игроку, если он ещё не согласился/не отказался в этой сессии подключения.
        /// </summary>
        public void RequestConsent(CCSPlayerController player)
        {
            if (!_config.ConsentRequired)
            {
                _consentedThisSession.Add(player.SteamID);
                return;
            }

            var menu = new CenterHtmlMenu("Соглашение SAC");
            menu.AddMenuOption("Согласиться", (p, option) => OnConsentAccepted(p));
            menu.AddMenuOption("Отказать", (p, option) => OnConsentDeclined(p));

            player.PrintToCenterHtml(ConsentText);
            MenuManager.OpenCenterHtmlMenu(null, player, menu);
        }

        /// <summary>
        /// Проверяет, отказался ли игрок от согласия (используется, чтобы не пускать его дальше).
        /// </summary>
        public bool HasDeclined(ulong steamId) => _declinedThisSession.Contains(steamId);

        public bool HasConsented(ulong steamId) => _consentedThisSession.Contains(steamId);

        /// <summary>
        /// Сбрасывает состояние согласия при отключении игрока — при переподключении окно покажется снова.
        /// </summary>
        public void ClearOnDisconnect(ulong steamId)
        {
            _declinedThisSession.Remove(steamId);
            _consentedThisSession.Remove(steamId);
        }

        private void OnConsentAccepted(CCSPlayerController player)
        {
            _consentedThisSession.Add(player.SteamID);
        }

        private void OnConsentDeclined(CCSPlayerController player)
        {
            _declinedThisSession.Add(player.SteamID);

            var secondsLeft = _config.ConsentKickDelaySeconds;
            ShowCountdown(player, secondsLeft);

            var ticksLeft = secondsLeft;
            var steamId = player.SteamID;
            Timer? countdownTimer = null;

            countdownTimer = Server.AddTimer(1.0f, () =>
            {
                ticksLeft -= 1;

                var current = Utilities.GetPlayers().FirstOrDefault(p => p.IsValid && p.SteamID == steamId);
                if (current == null)
                {
                    countdownTimer?.Kill();
                    return;
                }

                if (ticksLeft <= 0)
                {

        /// Хеширует SteamID игрока солью SHA-256, возвращает первые 12 hex-символов.

        {
            using var sha256 = SHA256.Create();
            var bytes = Encoding.UTF8.GetBytes($"{steamId}:{_salt}");
            var hash = sha256.ComputeHash(bytes);
            var hex = Convert.ToHexString(hash).ToLowerInvariant();
            return hex[..12];

        {
            if (_anonNameCache.TryGetValue(steamId, out var cached)) return cached;

            var hash = HashSteamId(steamId);
            var shortId = hash[..4];

            return anon;
        }

        private readonly object _lock = new();

        {
            _config = config;
            _chatService = chatService;
            _massCheckService = massCheckService;

        /// Регистрирует жалобу от указанного источника. Источник задаётся строкой вида

        {
            lock (_lock)
            {
                var now = DateTime.UtcNow;

                if (!_reports.TryGetValue(targetSteamId, out var entry) ||
                    (now - entry.windowStart).TotalSeconds > _config.ReportWindowSeconds)
                {
                    entry = (new HashSet<string>(), now, targetName);
                }

                entry.sources.Add(sourceId);
                entry.targetName = targetName;
                _reports[targetSteamId] = entry;

                _chatService.PrintReportReceived(targetName);

                if (entry.sources.Count >= _config.ReportsForMassCheck)
                {
                    _massCheckService.Trigger(targetSteamId, targetName);
                    _reports.Remove(targetSteamId);
                }
            }
        }

                return _members.ContainsKey(steamId) && !_members[steamId].IsBanned;
            }
        }

using CounterStrikeSharp.API;
using CounterStrikeSharp.API.Core;
using CounterStrikeSharp.API.Modules.Utils;

namespace SAC.Services
{
    /// <summary>
    /// Реализует показательную механику устранения активного читера: позади него спавнится
    /// неуязвимый бот с ником "SAC", принадлежащий враждебной команде, который мгновенно
    /// убивает читера выстрелом в голову и через 0.5 секунды исчезает.
    /// Используется только для ещё не забаненных, активных читеров.
    /// </summary>
    public class SacKillService
    {
        private const string BotName = "SAC";
        private const float SpawnOffsetUnits = 50f;
        private const float BotLifetimeSeconds = 0.5f;

        /// <summary>
        /// Выполняет показательное убийство читера ботом "SAC".
        /// </summary>
        public void ExecuteSacKill(CCSPlayerController cheater)
        {
            var pawn = cheater.PlayerPawn?.Value;
            if (pawn == null || !pawn.IsValid || pawn.AbsOrigin == null) return;

            var origin = pawn.AbsOrigin;
            var angle = pawn.EyeAngles;

            // Смещение позиции спавна бота назад от направления взгляда читера.
            var yawRadians = angle.Y * MathF.PI / 180f;
            var back = new Vector(
                origin.X - MathF.Cos(yawRadians) * SpawnOffsetUnits,
                origin.Y - MathF.Sin(yawRadians) * SpawnOffsetUnits,
                origin.Z
            );

            var hostileTeam = cheater.TeamNum == (byte)CsTeam.Terrorist
                ? CsTeam.CounterTerrorist
                : CsTeam.Terrorist;

            var bot = SpawnSacBot(back, angle, hostileTeam);
            if (bot == null) return;

            // Мгновенное убийство читера выстрелом в голову от лица бота.
            KillCheaterAsHeadshot(cheater, bot);

            // Бот исчезает через 0.5 секунды после устранения читера.
            Server.AddTimer(BotLifetimeSeconds, () =>
            {
                RemoveSacBot(bot);
            });
        }

        /// <summary>
        /// Создаёт неуязвимого бота-исполнителя с именем "SAC" на указанной позиции.
        /// Фактическое создание управляемого ботом CCSPlayerController выполняется через
        /// консольные команды сервера (bot_add) с последующей телепортацией и переименованием,
        /// так как прямое создание валидного player-агента через CreateEntityByName не поддерживается
        /// публичным API CounterStrikeSharp.
        /// </summary>
        private CCSPlayerController? SpawnSacBot(Vector position, QAngle angle, CsTeam team)
        {
            var teamCommand = team == CsTeam.Terrorist ? "bot_add_t" : "bot_add_ct";
            Server.ExecuteCommand(teamCommand);

            // Бот появляется в конце списка игроков — берём последнего подключённого бота.
            var bot = Utilities.GetPlayers()
                .Where(p => p is { IsValid: true, IsBot: true })
                .OrderByDescending(p => p.UserId)
                .FirstOrDefault();

            if (bot?.PlayerPawn?.Value == null) return null;

            bot.PlayerName = BotName;
            Utilities.SetStateChanged(bot, "CCSPlayerController", "m_iszPlayerName");

            var botPawn = bot.PlayerPawn.Value;
            botPawn.Teleport(position, angle, new Vector(0, 0, 0));

            // Неуязвимость бота на время демонстрации.
            botPawn.TakesDamage = false;

            return bot;
        }

        /// <summary>
        /// Мгновенно "убивает" читера от лица бота, эмулируя точный выстрел в голову.
        /// </summary>
        private void KillCheaterAsHeadshot(CCSPlayerController cheater, CCSPlayerController bot)
        {
            var pawn = cheater.PlayerPawn?.Value;
            if (pawn == null || !pawn.IsValid) return;

            pawn.CommitSuicide(false, true);
            Server.PrintToChatAll($"SAC убил {cheater.PlayerName} (headshot)");
        }

        private void RemoveSacBot(CCSPlayerController bot)
        {
            if (bot?.IsValid != true) return;
            Server.ExecuteCommand($"kickid {bot.UserId} \"SAC bot despawn\"");
        }
    }
}

                ShowFakeChatMessage(target);
            }
            else if (roll < FakeVacScreenChance + FakeNotificationChance + FakeChatChance + FakePlayerChance)
            {
                SpawnFakePlayer(target);
            }
            else if (roll < FakeVacScreenChance + FakeNotificationChance + FakeChatChance + FakePlayerChance + InvisibleTrapChance)
            {
                TriggerInvisibleTrap(target);
            }
        }

        /// <summary>
        /// Создаёт иллюзию присутствия постороннего игрока в поле зрения читера — бота с моделью
        /// игрока, который на секунду появляется неподалёку и тут же исчезает.
        /// ВНИМАНИЕ: публичный API CounterStrikeSharp не предоставляет штатного способа скрыть
        /// сущность от всех клиентов, кроме одного (это требует хука CheckTransmit на уровне
        /// движка/Metamod). Реализация ниже создаёт бота-статиста через bot_add и максимально
        /// быстро его удаляет, минимизируя, но не гарантированно исключая, видимость другими игроками.
        /// Для полноценной эксклюзивной видимости используйте нативный transmit-хук отдельно.
        /// </summary>
        private void SpawnFakePlayer(CCSPlayerController target)
        {
            var pawn = target.PlayerPawn?.Value;
            if (pawn?.AbsOrigin == null) return;

            var angle = pawn.EyeAngles;
            var yawRadians = (angle.Y + 90f) * MathF.PI / 180f;
            var spawnPos = new Vector(
                pawn.AbsOrigin.X + MathF.Cos(yawRadians) * 150f,
                pawn.AbsOrigin.Y + MathF.Sin(yawRadians) * 150f,
                pawn.AbsOrigin.Z
            );

            Server.ExecuteCommand(target.TeamNum == (byte)CsTeam.Terrorist ? "bot_add_ct" : "bot_add_t");

            var fakePlayer = Utilities.GetPlayers()
                .Where(p => p is { IsValid: true, IsBot: true })
                .OrderByDescending(p => p.UserId)
                .FirstOrDefault();

            if (fakePlayer?.PlayerPawn?.Value == null) return;

            fakePlayer.PlayerPawn.Value.Teleport(spawnPos, angle, new Vector(0, 0, 0));
            _spawnedFakePlayers.Add(fakePlayer);

            Server.AddTimer(1.5f, () =>
            {
                if (fakePlayer.IsValid)
                {
                    Server.ExecuteCommand($"kickid {fakePlayer.UserId} \"SAC schizo fake player despawn\"");
                }
                _spawnedFakePlayers.Remove(fakePlayer);
            });
        }

        /// <summary>
        /// Имитирует срабатывание "невидимой ловушки" — эффект, замечаемый только читером
        /// (звук/тряска экрана рядом), намекающий, что за ним постоянно наблюдают.
        /// Полноценные trigger_multiple с эксклюзивной видимостью требуют серверной карты
        /// с заранее размещёнными точками — здесь эффект эмулируется через уведомление и лёгкую тряску камеры.
        /// </summary>
        private void TriggerInvisibleTrap(CCSPlayerController target)
        {
            target.PrintToChat("[SAC] *щелчок* ...");
            target.ExecuteClientCommand("play sounds/ui/counter_beep.vsnd");
        }

        private void CleanupFakePlayers()
        {
            foreach (var fake in _spawnedFakePlayers.ToList())
            {
                if (fake.IsValid)
                {
                    Server.ExecuteCommand($"kickid {fake.UserId} \"SAC schizo fake player despawn\"");
                }
            }
            _spawnedFakePlayers.Clear();
        }

        private void ShowFakeChatMessage(CCSPlayerController target)
        {
            var phrase = FakeChatPhrases[_random.Next(FakeChatPhrases.Length)];
            var fakeAuthors = Utilities.GetPlayers()
                .Where(p => p is { IsValid: true, IsBot: false } && p.SteamID != target.SteamID)
                .ToList();

            var authorName = fakeAuthors.Count > 0
                ? fakeAuthors[_random.Next(fakeAuthors.Count)].PlayerName
                : "Игрок";

            target.PrintToChat($"{authorName}: {phrase}");
        }

        private void ShowFakeNotification(CCSPlayerController target)
        {
            var message = FakeSacNotifications[_random.Next(FakeSacNotifications.Length)];
            target.PrintToChat(message);
        }

        private void ShowFakeVacScreen(CCSPlayerController target)
        {
            target.PrintToCenterHtml(FakeVacBanHtml);
            Blind(target, 3.0f);
        }

        /// <summary>
        /// Кратковременно ослепляет игрока белой вспышкой экрана (только для него самого).
        /// </summary>
        private void Blind(CCSPlayerController target, float durationSeconds)
        {
            if (target.Connected != PlayerConnectedState.PlayerConnected) return;

            var fade = new CUserMessageFade();
            fade.SetDuration((ushort)(durationSeconds * 1000));
            fade.SetHoldTime((ushort)(durationSeconds * 1000));
            fade.SetFlags(0x0001 | 0x0002); // FFADE_IN | FFADE_OUT
            fade.SetColor(0xFFFFFFFF);

            fade.Send(new[] { target });
        }

        private void DropAllWeapons(CCSPlayerController target)
        {
            var pawn = target.PlayerPawn?.Value;
            if (pawn?.WeaponServices?.MyWeapons == null) return;

            // Перебираем все виды оружия игрока и выбрасываем (роняем) каждое из них на землю.
            var weapons = pawn.WeaponServices.MyWeapons
                .Select(handle => handle.Value)
                .Where(weapon => weapon != null)
                .ToList();

            foreach (var weapon in weapons)
            {
                pawn.Weapon_Drop(weapon!);
            }
        }

        private void Freeze(CCSPlayerController target, int seconds)
        {
            var pawn = target.PlayerPawn?.Value;
            if (pawn == null) return;

            const uint FL_FROZEN = 1 << 5;
            pawn.Flags = (uint)pawn.Flags | FL_FROZEN;

            Server.AddTimer(seconds, () =>
            {
                var currentPawn = target?.PlayerPawn?.Value;
                if (currentPawn != null)
                {
                    currentPawn.Flags = (uint)currentPawn.Flags & ~FL_FROZEN;
                }
            });
        }
    }
}

using CounterStrikeSharp.API;
using CounterStrikeSharp.API.Core;
using Newtonsoft.Json;
using SAC.Config;

namespace SAC.Services
{
    /// <summary>
    /// Запись счётчика предупреждений одного игрока, хранится в warnings.json.
    /// </summary>
    public class WarningRecord
    {
        [JsonProperty("steamid")]
        public ulong SteamId { get; set; }

        [JsonProperty("attempts")]
        public int Attempts { get; set; }

        [JsonProperty("rounds_since_last_detection")]
        public int RoundsSinceLastDetection { get; set; }
    }

    /// <summary>
    /// Реализует систему из 4 прогрессивных предупреждений читеру перед окончательным баном:
    /// попытки 1-2 — простое убийство (slay), попытка 3 — обнуление баланса + slay,
    /// попытка 4 — бан на 168 часов и кик. Счётчик сохраняется между сессиями в warnings.json
    /// и сбрасывается после N "чистых" раундов без единого срабатывания детекторов.
    /// </summary>
    public class WarningCounterService
    {
        private readonly SacConfig _config;
        private readonly BanService _banService;
        private readonly DataCollector _dataCollector;
        private readonly string _filePath;
        private readonly object _lock = new();

        private Dictionary<ulong, WarningRecord> _records = new();

        public WarningCounterService(string pluginBaseDirectory, SacConfig config, BanService banService, DataCollector dataCollector)
        {
            _config = config;
            _banService = banService;
            _dataCollector = dataCollector;
            _filePath = Path.Combine(pluginBaseDirectory, "warnings.json");
            Load();
        }

        public void Load()
        {
            lock (_lock)
            {
                if (!File.Exists(_filePath))
                {
                    _records = new Dictionary<ulong, WarningRecord>();
                    Save();
                    return;
                }

                var json = File.ReadAllText(_filePath);
                var list = JsonConvert.DeserializeObject<List<WarningRecord>>(json) ?? new List<WarningRecord>();
                _records = list.ToDictionary(r => r.SteamId, r => r);
            }
        }

        public void Save()
        {
            lock (_lock)
            {
                var json = JsonConvert.SerializeObject(_records.Values.ToList(), Formatting.Indented);
                File.WriteAllText(_filePath, json);
            }
        }

        /// <summary>
        /// Регистрирует срабатывание детектора у игрока и применяет соответствующую попытке реакцию.
        /// Возвращает номер применённой попытки (1-4).
        /// </summary>
        public int RegisterDetection(CCSPlayerController player, string moduleName, string reason)
        {
            lock (_lock)
            {
                var steamId = player.SteamID;
                if (!_records.TryGetValue(steamId, out var record))
                {
                    record = new WarningRecord { SteamId = steamId, Attempts = 0, RoundsSinceLastDetection = 0 };
                    _records[steamId] = record;
                }

                record.Attempts = Math.Min(record.Attempts + 1, _config.WarningAttemptsBeforeBan);
                record.RoundsSinceLastDetection = 0;

                ApplyAttempt(player, record.Attempts, moduleName, reason);
                LogAttempt(player, record.Attempts, moduleName, reason);

                Save();
                return record.Attempts;
            }
        }

        private void ApplyAttempt(CCSPlayerController player, int attempt, string moduleName, string reason)
        {
            var max = _config.WarningAttemptsBeforeBan;

            switch (attempt)
            {
                case 1:
                    ShowWarningHtml(player, 1, max);
                    SlayPlayer(player);
                    break;

                case 2:
                    ShowWarningHtml(player, 2, max);
                    SlayPlayer(player);
                    break;

                case 3:
                    ShowWarningHtml(player, 3, max);
                    ZeroOutBalance(player);
                    SlayPlayer(player);
                    break;

                default: // 4-я и последующие попытки — окончательный бан
                    ShowFinalWarningHtml(player, max);
                    SlayPlayer(player);
                    _banService.BanTemporary(player.SteamID, _config.BanDurationHours,
                        $"Cheat detected after {max} warnings ({moduleName}: {reason})");
                    Server.ExecuteCommand($"kickid {player.UserId} \"[SAC] Вы забанены на {_config.BanDurationHours} часов\"");
                    break;
            }
        }

        private void ShowWarningHtml(CCSPlayerController player, int attempt, int max)
        {
            var html = "<font color='red' size='24'>У вас обнаружен чит!</font><br/>" +
                        "<font color='white' size='18'>Пожалуйста выключите его!</font><br/>" +
                        $"<font color='yellow' size='16'>Попытка {attempt}/{max}</font>";
            player.PrintToCenterHtml(html);
        }

        private void ShowFinalWarningHtml(CCSPlayerController player, int max)
        {
            var html = "<font color='red' size='24'>У вас обнаружен чит!</font><br/>" +
                        $"<font color='white' size='18'>Вы будете забанены на {_config.BanDurationHours} часов!</font><br/>" +
                        $"<font color='yellow' size='16'>Попытка {max}/{max}</font>";
            player.PrintToCenterHtml(html);
        }

        private void SlayPlayer(CCSPlayerController player)
        {
            var pawn = player.PlayerPawn?.Value;
            if (pawn != null && pawn.IsValid)
            {
                pawn.CommitSuicide(false, true);
            }
            else
            {
                Server.ExecuteCommand($"slay {player.UserId}");
            }
        }

        private void ZeroOutBalance(CCSPlayerController player)
        {
            var moneyServices = player.InGameMoneyServices;
            if (moneyServices == null) return;

            moneyServices.Account = 0;
            moneyServices.TotalMoneyEarned = 0;
            Utilities.SetStateChanged(player, "CCSPlayerController", "m_pInGameMoneyServices");
        }

        private void LogAttempt(CCSPlayerController player, int attempt, string moduleName, string reason)
        {
            var record = new
            {
                attempt,
                module = moduleName,
                reason
            };

            _dataCollector.LogWarning(player, record);
        }

        /// <summary>
        /// Вызывается в начале каждого раунда: увеличивает счётчик "чистых" раундов у всех
        /// игроков с накопленными попытками и сбрасывает их при достижении порога.
        /// </summary>
        public void OnRoundStart()
        {
            lock (_lock)
            {
                var changed = false;

                foreach (var record in _records.Values.Where(r => r.Attempts > 0))
                {
                    record.RoundsSinceLastDetection += 1;
                    if (record.RoundsSinceLastDetection >= _config.WarningResetAfterCleanRounds)
                    {
                        record.Attempts = 0;
                        record.RoundsSinceLastDetection = 0;
                    }
                    changed = true;
                }

                if (changed)
                {
                    Save();
                }
            }
        }
    }
}

    /// <summary>

        private const string WarningHtml =
            "<font class='fontSize-l' color='orange'>⚠ SAC ⚠</font><br>" +
            "<font class='fontSize-sm' color='#DDDDDD'>" +
            "Этот сервер использует античит SAC.<br>" +

            if (_warnedPlayers.Contains(player.SteamID)) return;

        /// </summary>
        public void ResetIfServerEmpty(int currentPlayerCount)
        {
            if (currentPlayerCount <= 0)
            {
                _warnedPlayers.Clear();
            }
        }
    }
