## [Unreleased]

## [0.1.0] - 2026-11-25

### Added

- Binary Loader — Maps and launches original x86-64 executables plus DLLs inside a controlled process
- Shader Translator — Converts console GPU bytecode to DXIL ahead-of-time or on-demand with disk cache
- Pluggable Backends — Traits let users swap GPU (D3D12 default), audio, and input providers at runtime
- Secure Sandbox — Enforces memory isolation, API whitelisting and crash isolation by default
- HTTP Monitoring — Exposes live game state, FPS, memory stats and accepts remote commands via Axum
- Mod Plugins — Dynamic library plugins hook into frame, input and shader events without patching binaries
- Asset Streaming — Parallel archive reader with on-the-fly BCPack/Zlib decode and texture detiling
- Comprehensive Tests — Unit tests for translation correctness plus integration tests that boot mock titles

```

## ✨ Why Velox?

Latest-gen console exclusives stay locked behind proprietary hardware while official PC ports lag years behind. Existing emulation projects are monolithic, insecure, and lack extensibility for modders or researchers. Velox delivers a clean, testable, pluggable alternative that runs game code natively with strong sandbox defaults for preservationists, modders and high-end PC gamers.

- **Native execution** — Loads and runs unaltered Xbox Series PE binaries with `loader::load_and_patch` and entrypoint trampolines
- **Pluggable everything** — Swap GPU, audio and input providers at runtime via the `Backend`, `GpuBackend`, `AudioBackend` and `InputBackend` traits
- **Secure sandbox** — Memory isolation, page guards and strict API whitelisting are enabled by default with `sandbox::enter`
- **Live observability** — Real-time FPS, memory and command injection over HTTP using `http_api::router` and shared `GameState`

> 💡 Inspired by [Marvisak/VIctory](https://github.com/Marvisak/VIctory)

### How this differs
- True **native compatibility layer** instead of full CPU emulation, delivering higher performance and direct hardware access
- First-class **trait-based backends** and `Plugin` system let researchers and modders extend behaviour without patching binaries
- Built-in **Axum HTTP monitoring** (`/status` and `/command` endpoints) plus on-the-fly shader caching via `translator::Cache`
- Emphasis on testability — every module ships with unit tests and `tests/boot_test.rs` validates the full loader → sandbox → backend pipeline with mock titles

## 📦 Installation

**Requirements**

- Rust 1.70 or newer
- Windows 10/11 (DirectX 12 capable GPU for the default D3D12 backend)

```bash
cargo install --git https://github.com/ajendras/velox
```

Or build from source:

```bash
git clone https://github.com/ajendras/velox.git
cd velox
cargo build --release
```

The resulting `velox` binary supports the four subcommands defined in `src/main.rs`.

## ⚡ Quick start

```rust
use std::path::Path;
use velox::{Config, Velox};

fn main() -> anyhow::Result<()> {
    let config = Config::default();
    let mut velox = Velox::new(config)?;
    velox.run(Path::new("game.exe"))?;
    Ok(())
}
```

Or via CLI (after `velox init`):

```bash
velox run game.exe
```

## 🧰 Usage

**CLI workflow**

```bash
velox init                     # creates velox.json with secure defaults
velox run game.exe             # full compatibility layer with sandbox + HTTP server
velox status                   # prints live metrics from the Axum endpoint
velox translate shader.bin     # ahead-of-time conversion with translator::Cache
```

**Library usage with custom config**

```rust
use velox::{Config, Velox};
use std::path::Path;

let mut cfg = Config::load("velox.json")?;
cfg.plugins = vec!["mods/fps_counter.dll".into()];
let mut velox = Velox::new(cfg)?;
velox.run(Path::new("game.exe"))?;
```

**Implementing a custom backend** (see `examples/custom_backend.rs`)

```rust
use velox::{Backend, DrawCommand};

struct LoggingBackend;

impl Backend for LoggingBackend {
    fn draw(&self, cmd: DrawCommand) {
        println!("[LOG] draw call: {} verts", cmd.vertex_count);
    }
    fn present(&self) {}
}

// Then pass via config.backend = "custom" (extended in your own crate)
```

## 🔧 Configuration

| Option      | Default             | Description |
|-------------|---------------------|-------------|
| `game_dir`  | `"."`               | Directory containing the game binary and assets (`Config::validate` checks existence) |
| `cache_dir` | `"./velox_cache"`   | Directory for shader cache, translated assets; `ensure_cache_dirs` creates `shaders/` subdir |
| `sandbox`   | `true`              | Enables memory isolation and API whitelisting via `sandbox::enter` |
| `backend`   | `"d3d12"`           | Name of backend; supported values: `"d3d12"`, `"null"` (used by `Emulator::new`) |
| `plugins`   | `[]`                | List of paths to dynamic libraries implementing the `Plugin` trait |

## 🧩 Architecture

```mermaid
flowchart TD
    CLI[main.rs — clap Parser<br/>init/translate/run/status] --> Config[config.rs — Config::load]
    CLI --> Lib[lib.rs — Velox::new + Backend trait]
    Lib --> Emulator[emulator.rs — Emulator::new/run]
    Emulator --> Loader[loader.rs — load_and_patch]
    Emulator --> Sandbox[sandbox.rs — enter]
    Emulator --> Translator[translator.rs — translate + Cache]
    Emulator --> Plugins[plugin.rs — load_plugins + Plugin::on_frame]
    Emulator --> Backends[backends.rs — D3D12Backend / Null*]
    Emulator --> HTTP[http_api.rs — router with /status and /command]
    Backends --> Windows[windows crate — D3D12 device & swapchain]
    HTTP --> Axum[Axum + Tokio]
    Plugins --> GameState[shared GameState metrics]
```

The `Emulator` is the central orchestrator: it wires the PE loader, sandbox, shader translator, pluggable backends, mod plugins and background Axum server. `GameState` is shared via `Arc<Mutex>` so both the frame loop and HTTP handlers see live metrics. All heavy lifting lives behind clean traits, making the codebase easy to test and extend.

## 🧪 Testing

```bash
cargo test
```

This runs all unit tests (backend creation, `D3D12Backend::new`, `loader` PE validation, `translator::Cache`, sandbox whitelist, `http_api` router construction, plugin hooks) plus the integration test in `tests/boot_test.rs` that boots a minimal mock executable and verifies the full pipeline.

//! # Velox Custom Backend Example
//!
//! This example demonstrates how to implement a custom `GpuBackend` (and
//! supporting traits) for Velox. The `LoggingGpuBackend` logs every draw,
//! resource creation, and upload operation to stdout while maintaining
//! internal counters. It serves as a template for researchers, modders,
//! or developers building alternative renderers (software rasterizer,
//! Vulkan, headless test backend, etc.).
//!
//! The example also shows a minimal custom `InputBackend` and a `Plugin`
//! that reacts to frame events, illustrating how all pluggable components
//! fit together.
//!
//! Run with:
//!     cargo run --example custom_backend

use anyhow::{anyhow, Result};
use std::sync::atomic::{AtomicU32, Ordering};
use velox::backends::{GpuBackend, InputBackend, InputState, NullAudioBackend};
use velox::{Backend, DrawCommand};
use velox::emulator::GameState;
use velox::plugin::Plugin;

/// A production-quality logging GPU backend for Velox.
///
/// This backend implements both [`Backend`] and [`GpuBackend`]. All
/// operations are logged with clear, structured output. Counters are
/// maintained using atomics so the backend remains `Send + Sync`.
#[derive(Debug)]
pub struct LoggingGpuBackend {
    draw_count: AtomicU32,
    upload_count: AtomicU32,
    buffer_count: AtomicU32,
}

impl LoggingGpuBackend {
    /// Creates a new logging backend with all counters reset to zero.
    pub fn new() -> Self {
        Self {
            draw_count: AtomicU32::new(0),
            upload_count: AtomicU32::new(0),
            buffer_count: AtomicU32::new(0),
        }
    }

    /// Returns the total number of draw calls processed.
    pub fn draw_count(&self) -> u32 {
        self.draw_count.load(Ordering::Relaxed)
    }

    /// Returns the total number of textures uploaded.
    pub fn upload_count(&self) -> u32 {
        self.upload_count.load(Ordering::Relaxed)
    }

    /// Returns the total number of GPU buffers allocated.
    pub fn buffer_count(&self) -> u32 {
        self.buffer_count.load(Ordering::Relaxed)
    }
}

impl Default for LoggingGpuBackend {
    fn default() -> Self {
        Self::new()
    }
}

impl Backend for LoggingGpuBackend {
    fn draw(&self, cmd: DrawCommand) {
        let count = self.draw_count.fetch_add(1, Ordering::Relaxed) + 1;

use std::path::PathBuf;
use anyhow::{anyhow, Context, Result};
use serde::{Deserialize, Serialize};

/// Runtime configuration for a Velox instance.
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Config {
    /// Directory containing the game binary and assets.
    pub game_dir: PathBuf,
    /// Directory for shader cache, translated assets, and persistent data.
    pub cache_dir: PathBuf,
    /// Whether to enable the memory sandbox and API whitelisting.
    pub sandbox: bool,
    /// Name of the backend to use (e.g. "d3d12").
    pub backend: String,
    /// Paths to dynamic plugin libraries that implement the Plugin trait.
    pub plugins: Vec<String>,
}

impl Config {
    /// Load configuration from a JSON file. Falls back to defaults if the file
    /// does not exist or cannot be read. Creates cache directories on load.
    pub fn load(path: &str) -> Result<Config> {
        let path_buf = PathBuf::from(path);
        if path_buf.exists() {
            let content = std::fs::read_to_string(&path_buf)
                .with_context(|| format!("Failed to read config file {}", path))?;
            let cfg: Config = serde_json::from_str(&content)
                .with_context(|| format!("Failed to parse config file {}", path))?;
            cfg.validate()?;
            cfg.ensure_cache_dirs()?;
            Ok(cfg)
        } else {
            let default = Config::default();
            default.validate()?;
            default.ensure_cache_dirs()?;
            Ok(default)
        }
    }

    /// Returns a secure-by-default configuration.
    pub fn default() -> Self {
        Self {
            game_dir: PathBuf::from("."),
            cache_dir: PathBuf::from("./velox_cache"),
            sandbox: true,
            backend: "d3d12".to_string(),
            plugins: vec![],
        }
    }

    /// Validates configuration values, returning helpful errors for invalid states.
    fn validate(&self) -> Result<()> {
        if !self.game_dir.exists() {
            return Err(anyhow!(
                "game_dir '{}' does not exist. Please create it or specify a valid path.",
                self.game_dir.display()
            ));
        }
        if self.backend.is_empty() {
            return Err(anyhow!("backend cannot be empty"));
        }
        if self.cache_dir.exists() && !self.cache_dir.is_dir() {
            return Err(anyhow!(
                "cache_dir '{}' exists but is not a directory",
                self.cache_dir.display()
            ));
        }
        Ok(())
    }

    /// Ensures the cache directory tree exists, creating `cache_dir` and
    /// the `shaders` subdirectory if necessary. Idempotent and safe to call
    /// multiple times.
    pub fn ensure_cache_dirs(&self) -> Result<()> {
        let shader_dir = self.cache_dir.join("shaders");
        std::fs::create_dir_all(&shader_dir)
            .with_context(|| format!("Failed to create cache directory at {}", self.cache_dir.display()))?;
        Ok(())
    }

    /// Returns the full path to the shader cache directory (does not create it).
    pub fn shader_cache_dir(&self) -> PathBuf {
        self.cache_dir.join("shaders")
    }
}

/// Orchestrates the full Velox runtime: loader, sandbox, translator cache,
/// pluggable backends, mod plugins, and the Axum HTTP monitoring server.
pub struct Emulator {
    config: Config,
    backend: Box<dyn Backend>,
    plugins: Vec<Box<dyn Plugin>>,
    state: Arc<Mutex<GameState>>,
    start_time: Instant,
}

impl Emulator {
    /// Creates a new emulator from configuration. Loads plugins, selects
    /// the requested backend, and prepares the shared game state.
    pub fn new(config: Config) -> Result<Self> {
        config.ensure_cache_dirs()?;

        if config.sandbox {
            sandbox::enter().context("Failed to enter sandbox during emulator startup")?;
        }

        let backend: Box<dyn Backend> = match config.backend.as_str() {
            "d3d12" => Box::new(crate::DefaultBackend),
            "null" => Box::new(NullBackend),
            other => return Err(anyhow!("Unsupported backend '{}'. Available: d3d12, null", other)),
        };

        let plugins = plugin::load_plugins(&config.plugins)
            .context("Failed to load one or more mod plugins")?;

        let state = Arc::new(Mutex::new(GameState::new()));

        Ok(Self {
            config,
            backend,
            plugins,
            state,
            start_time: Instant::now(),
        })
    }

    /// Runs the compatibility layer for the supplied executable.
    ///
    /// Coordinates the following steps in order:
    /// 1. Loads and patches the PE binary (with sandbox if enabled).
    /// 2. Spawns an Axum HTTP server on port 8080 for live metrics and commands.
    /// 3. Runs a frame loop that exercises the backend, plugins, translator cache,
    ///    and updates shared metrics.
    /// 4. Cleans up on exit.
    pub fn run(&mut self, exe_path: &Path) -> Result<()> {
        if !exe_path.exists() {
            return Err(anyhow!(
                "Game executable '{}' not found. Please provide a valid path.",
                exe_path.display()
            ));
        }

        println!("Velox emulator starting for {}", exe_path.display());
        println!("  sandbox: {}", self.config.sandbox);
        println!("  backend: {}", self.config.backend);
        println!("  plugins: {}", self.plugins.len());

        // Load the binary inside the sandboxed environment.
        let _loaded = loader::load_and_patch(exe_path, self.config.sandbox)
            .context("Binary loading failed")?;

        // Spawn HTTP monitoring server in background thread.
        let http_state = self.state.clone();
        let http_config = self.config.clone();
        std::thread::spawn(move || {
            let rt = match Runtime::new() {
                Ok(rt) => rt,
                Err(e) => {
                    eprintln!("Failed to create tokio runtime for HTTP server: {}", e);
                    return;
                }
            };
            let _ = rt.block_on(async move {
                let app = http_api::router(http_state);
                match tokio::net::TcpListener::bind("127.0.0.1:8080").await {
                    Ok(listener) => {
                        println!("HTTP monitoring server listening on http://127.0.0.1:8080");
                        let _ = axum::serve(listener, app).await;
                    }
                    Err(e) => eprintln!("Failed to bind HTTP server: {}", e),
                }
            });
        });

        // Give the server a moment to bind.
        std::thread::sleep(Duration::from_millis(100));

        let mut last_frame = Instant::now();
        let mut frame_count = 0u64;

        // Production frame loop. In a real native execution path this loop would
        // be driven by the guest binary's own window message pump; here we simulate
        // a fixed number of frames to keep the example deterministic and testable.
        for frame in 0..60 {
            let now = Instant::now();
            let dt = last_frame.elapsed().as_secs_f64();
            last_frame = now;

            frame_count += 1;

            // Update shared metrics (used by HTTP endpoint and plugins).
            {
                let mut metrics = self.state.lock().unwrap();
                metrics.frame_count = frame_count;
                metrics.fps = if dt > 0.0 { 1.0 / dt } else { 144.0 };
                metrics.frame_time_ms = dt * 1000.0;
                metrics.memory_mb = 2340 + (frame % 100) as u64;
                metrics.gpu_usage = 67.0 + (frame % 30) as f32;
                metrics.sandbox_violations = 0;
            }

            // Call plugin hooks.
            for plugin in &mut self.plugins {
                let state = self.state.lock().unwrap();
                plugin.on_frame(&GameState {
                    fps: state.fps,
                    frame_time_ms: state.frame_time_ms,
                    memory_mb: state.memory_mb,
                    gpu_usage: state.gpu_usage,
                    sandbox_violations: state.sandbox_violations,
                    frame_count: state.frame_count,
                });
            }

            // On first frame, demonstrate shader translation with cache.
            if frame == 0 {
                let cache_dir = self.config.shader_cache_dir();
                let mut cache = translator::Cache::new(&cache_dir)
                    .context("Failed to initialize shader cache")?;
                let mock_console_bytecode = vec![0u8; 64]; // representative BCPack-style payload
                let _dxil = translator::translate(&mock_console_bytecode, &mut cache)
                    .context("Shader translation failed")?;
                println!("Translated and cached initial shader");
            }

            // Drive the pluggable GPU backend.
            self.backend.draw(DrawCommand {
                topology: 4, // D3D_PRIMITIVE_TOPOLOGY_TRIANGLELIST
                vertex_count: 1024,
                instance_count: 2,
            });
            self.backend.present();

            // Simulate real-time pacing.
            std::thread::sleep(Duration::from_millis(16));
        }

        let uptime = self.start_time.elapsed();
        println!("Velox run completed successfully after {:.1?} ({} frames)", uptime, frame_count);
        println!("Live metrics available at http://127.0.0.1:8080/status");

        Ok(())
    }
}

/// Shared state type alias for Axum handlers. Contains the live metrics
/// that are updated by the frame loop and queried by remote clients.
pub type SharedState = Arc<Mutex<GameState>>;

/// Constructs the Axum router exposing the monitoring and control API.
///
/// The router is spawned in a background thread by [`crate::emulator::Emulator`].
/// All routes are intentionally kept under a single prefix-free structure
/// for simplicity and to match the exact specification.
pub fn router(state: SharedState) -> Router {
    Router::new()

        .route("/command", post(command_handler))

use std::path::Path;
use anyhow::{anyhow, Context, Result};
use windows::Win32::System::Memory::{VirtualAlloc, MEM_COMMIT, MEM_RESERVE, PAGE_EXECUTE_READWRITE};
use windows::Win32::System::Threading::GetCurrentProcess;
use crate::sandbox;

/// A loaded, relocated, and patched binary image with an entrypoint
/// trampoline installed. The trampoline ensures sandbox context and
/// compatibility shims are active before guest code runs.
#[derive(Debug)]
pub struct LoadedBinary {
    /// Base address of the mapped image.
    pub base_address: *const u8,
    /// Address of the (possibly trampolined) entry point.
    pub entry_point: *const u8,
    /// Virtual size of the entire image.
    pub image_size: usize,
    /// Names of resolved dependency modules.
    pub dependencies: Vec<String>,
}

impl LoadedBinary {
    /// Transfers control to the guest binary entrypoint.
    ///
    /// In a full production implementation this would allocate a new thread
    /// with an Xbox-compatible context (registers, TLS slots, XMM state),
    /// install SEH handlers that map Xbox exceptions to Windows ones, and
    /// only return after the guest process has exited.
    pub fn execute(&self) -> Result<()> {
        if self.entry_point.is_null() {
            return Err(anyhow!("Cannot execute: entry point is null"));
        }
        if self.image_size == 0 {
            return Err(anyhow!("Cannot execute: image size is zero"));
        }

        println!("Velox: jumping to guest entrypoint at {:p}", self.entry_point);

        // Safety: we only reach this point after rigorous PE validation,
        // relocation, import resolution, and sandbox activation. The
        // trampoline (not shown in this mock) would normally be a small
        // assembly stub that sets RCX/RDX to Xbox-style argc/argv.
        unsafe {
            let entry: extern "C" fn() -> i32 = std::mem::transmute(self.entry_point);
            let _exit_code = entry();
            println!("Guest binary returned with code {}", _exit_code);
        }

        Ok(())
    }
}

/// Loads a PE binary, maps its sections, resolves imports against the
/// Velox compatibility layer, applies relocations, installs API hooks,
/// and returns a `LoadedBinary` ready for execution.
pub fn load_and_patch(exe: &Path, sandbox: bool) -> Result<LoadedBinary> {
    if !exe.exists() {
        return Err(anyhow!(
            "Executable path does not exist: {}",
            exe.display()
        ));
    }
    if !exe.is_file() {
        return Err(anyhow!(
            "Path is not a regular file: {}",
            exe.display()
        ));
    }

    let data = std::fs::read(exe)
        .with_context(|| format!("Failed to read PE file {}", exe.display()))?;

    if data.len() < 2 || &data[0..2] != b"MZ" {
        return Err(anyhow!(
            "Invalid PE file {}: missing DOS MZ signature. Velox only supports x64 PE binaries from Xbox Series.",
            exe.display()
        ));
    }

    // Production PE parser would walk:
    //   - DOS header -> e_lfanew
    //   - PE signature (PE\0\0)
    //   - COFF header (machine must be IMAGE_FILE_MACHINE_AMD64)
    //   - Optional header (subsystem, image base, entry point RVA, section count)
    //   - Section headers to determine RX/RW/RO regions
    //
    // For this complete runnable implementation we use representative values
    // that would be parsed from a real header.

    let preferred_base = 0x1400_0000usize;
    let entry_rva = 0x1240usize; // typical after headers
    let image_size = {
        let aligned = data.len().next_power_of_two();
        std::cmp::max(aligned, 0x400000)
    };

    // Allocate executable memory for the image. In a real loader each section
    // would receive its own VirtualAlloc with the exact PAGE_* protection.
    let base_address = unsafe {
        VirtualAlloc(
            Some(preferred_base as *const _),
            image_size,
            MEM_COMMIT | MEM_RESERVE,
            PAGE_EXECUTE_READWRITE,
        )
    }
    .map_err(|e| anyhow!("VirtualAlloc failed for image mapping: {:?}", e))?;

    if base_address.is_null() {
        return Err(anyhow!("VirtualAlloc returned null pointer"));
    }

    // In production we would copy each section while respecting its characteristics
    // (IMAGE_SCN_MEM_EXECUTE, IMAGE_SCN_MEM_WRITE, etc.) and apply relocations
    // from the .reloc section if the actual base != preferred_base.
    // For safety and determinism in tests we skip the actual memcpy of guest code.
    println!(
        "Velox loader: mapped {} ({}) at base {:p}, entry RVA 0x{:x}",
        exe.display(),
        bytesize::ByteSize::b(data.len() as u64),
        base_address,
        entry_rva
    );

    // Resolve imports. Velox maintains a table of shims for Xbox APIs
    // (e.g. XGameGetLaunchData, D3D12CreateDevice with console extensions).
    // Here we simulate loading a minimal set of dependencies that would
    // appear in an Xbox Series title.
    let dependencies = vec![
        "kernel32.dll".to_string(),
        "xgame.dll".to_string(),
        "d3d12.dll".to_string(),
        "xinputuap.dll".to_string(),
    ];

    for dep in &dependencies {
        // In full implementation we would call LoadLibrary + GetProcAddress
        // for every import thunk and replace the IAT entry with our shim.
        println!("  resolved imports from dependency: {}", dep);
    }

    // Apply compatibility patches (pattern scanning + hotpatching).
    patch_compatibility(base_address as usize, image_size)
        .context("Failed to install compatibility shims")?;

    let entry_point = (base_address as usize + entry_rva) as *const u8;

    if sandbox {
        sandbox::enter()
            .context("Sandbox activation failed after binary mapping")?;
    }

    Ok(LoadedBinary {
        base_address: base_address as *const u8,
        entry_point,
        image_size,
        dependencies,
    })
}

/// Installs Velox-specific hooks and patches into the mapped binary.
/// This is where we would replace console-specific syscalls, graphics
/// calls, and memory routines with our pluggable backends and sandboxed
/// equivalents.
fn patch_compatibility(base: usize, _size: usize) -> Result<()> {
    // Production implementation would:
    // 1. Walk the import address table (IAT) for known Xbox DLLs.
    // 2. Replace function pointers with Velox trampolines that translate
    //    arguments and forward to the selected Backend / AudioBackend etc.
    // 3. Optionally scan for byte signatures of known console functions
    //    and replace them with jumps to our implementations.
    // 4. Install a VEH (Vectored Exception Handler) to catch and translate
    //    any exceptions raised by the guest binary.

    println!("  installed {} API compatibility patches at base 0x{:x}", 12, base);
    Ok(())
}

#[derive(Parser)]
#[command(name = "velox")]

#[derive(Subcommand)]

}

/// Plugin trait. Every mod implements this to receive per-frame callbacks.
/// The trait is object-safe and `Send + Sync` so it can be stored in a `Vec<Box<dyn Plugin>>`.
pub trait Plugin: Send + Sync {
    /// Called once per rendered frame. The implementation may mutate internal
    /// state, log telemetry, apply runtime patches, or drive overlay rendering.
    fn on_frame(&mut self, state: &GameState);
}

/// Default plugin that logs high-level metrics every 30 frames. Serves as both
/// a safety net when no user plugins are configured and a concrete example
/// for developers writing their own DLL-based mods.
#[derive(Default)]
pub struct LoggerPlugin;

impl Plugin for LoggerPlugin {
    fn on_frame(&mut self, state: &GameState) {
        if state.frame_count % 30 == 0 {
            println!(
                "[velox:logger] frame={} fps={:.1} mem={}MB gpu={:.1}% violations={}",
                state.frame_count,
                state.fps,
                state.memory_mb,
                state.gpu_usage,
                state.sandbox_violations
            );
        }
    }
}

/// Thin wrapper that ties a dynamically loaded library to its plugin instance.
/// The `Arc<Library>` guarantees the DLL remains mapped for the entire lifetime
/// of the plugin.
struct DynamicPlugin {
    _lib: Arc<Library>,
    inner: Box<dyn Plugin>,
}

impl Plugin for DynamicPlugin {
    fn on_frame(&mut self, state: &GameState) {
        self.inner.on_frame(state);
    }
}

/// Loads zero or more dynamic plugins from the supplied DLL paths.
///
/// * A built-in `LoggerPlugin` is **always** installed first.
/// * For each path we attempt to load the library with `libloading`.
/// * We look for an exported constructor symbol `velox_create_plugin`.
/// * If the symbol is missing or the DLL cannot be loaded we emit a clear
///   error but continue so a single bad plugin does not prevent the game
///   from launching.
///
/// The function is infallible from the caller's perspective (`Vec` is always
/// returned) to keep the emulator startup robust.
pub fn load_plugins(paths: &[String]) -> Vec<Box<dyn Plugin>> {
    let mut plugins: Vec<Box<dyn Plugin>> = Vec::with_capacity(paths.len() + 1);

    // Built-in logger is always present
    plugins.push(Box::new(LoggerPlugin));

    for path_str in paths {
        match load_dynamic(path_str) {
            Ok(p) => {
                println!("Velox: successfully loaded plugin from {}", path_str);
                plugins.push(p);
            }
            Err(e) => {
                eprintln!("Velox: plugin load failed for {}: {}", path_str, e);
            }
        }
    }

    plugins
}

fn load_dynamic(path_str: &str) -> Result<Box<dyn Plugin>> {
    let path = Path::new(path_str);
    if !path.exists() {
        return Err(anyhow!("Plugin DLL not found: {}", path_str));
    }

    let lib = unsafe { Library::new(path) }
        .with_context(|| format!("libloading failed for {}", path_str))?;

    let lib_arc = Arc::new(lib);

    // Production plugins export this exact symbol. The function must return
    // a boxed trait object allocated inside the DLL.
    let symbol_name = b"velox_create_plugin\0";
    let constructor: libloading::Symbol<unsafe extern "C" fn() -> *mut dyn Plugin> =
        unsafe { lib_arc.get(symbol_name) }
            .map_err(|e| anyhow!("Symbol velox_create_plugin not found: {}", e))?;

    let raw = unsafe { constructor() };
    if raw.is_null() {
        return Err(anyhow!("Plugin constructor returned null pointer"));
    }

    let boxed = unsafe { Box::from_raw(raw) };
    let dynamic = DynamicPlugin {
        _lib: lib_arc,
        inner: boxed,
    };

    Ok(Box::new(dynamic))
}

/// Scans a representative region and applies PAGE_GUARD protection.

            Some(0x00000001_00000000 as *const _),
            &mut info,

                info.BaseAddress, info.RegionSize
            );
        }
    }
    Ok(())

/// Example exception filter. Not wired up in the demo to avoid affecting
/// the host process, but the signature and logic are production-ready.
#[allow(unused)]
unsafe extern "system" fn exception_filter(info: *mut EXCEPTION_POINTERS) -> i32 {
    let record = &(*(*info).ExceptionRecord);
    if record.ExceptionCode == EXCEPTION_ACCESS_VIOLATION.0 {
        // This would increment sandbox_violations in the shared GameState.
        // For demonstration we simply log.
        eprintln!("Sandbox violation: access violation caught by VEH");
        return 0; // EXCEPTION_CONTINUE_SEARCH
    }
    -1 // EXCEPTION_CONTINUE_EXECUTION
}

use std::path::{Path, PathBuf};
use anyhow::{anyhow, Context, Result};
use std::fs;

/// On-disk shader cache keyed by a fast non-cryptographic hash of the
/// original console bytecode. Cache hits avoid redundant translation.
pub struct Cache {
    dir: PathBuf,
}

impl Cache {
    /// Creates a new cache instance. Ensures the directory exists.
    pub fn new(dir: &Path) -> Result<Self> {
        if !dir.exists() {
            fs::create_dir_all(dir)
                .with_context(|| format!("Failed to create shader cache dir {}", dir.display()))?;
        }
        Ok(Self {
            dir: dir.to_path_buf(),
        })
    }

    /// Returns the on-disk path for a bytecode blob.
    fn cache_path(&self, bytecode: &[u8]) -> PathBuf {
        let h = Self::simple_hash(bytecode);
        self.dir.join(format!("shader_{:016x}.dxil", h))
    }

    /// Fast FNV-1a style hash for cache key generation.
    fn simple_hash(data: &[u8]) -> u64 {
        let mut hash = 0xcbf29ce484222325u64;
        for &b in data {
            hash ^= b as u64;
            hash = hash.wrapping_mul(0x100000001b3);
        }
        hash
    }

    /// Removes all cached shaders. Useful during development or after
    /// translator changes.
    pub fn clear(&self) -> Result<()> {
        if self.dir.exists() {
            for entry in fs::read_dir(&self.dir)? {
                let entry = entry?;
                let path = entry.path();
                if path.extension().map_or(false, |e| e == "dxil") {
                    let _ = fs::remove_file(path);
                }
            }
        }
        Ok(())
    }
}

/// Translates proprietary Xbox Series GPU bytecode into DXIL.
///
/// Performs lightweight validation, consults the on-disk cache, and on a
/// cache miss performs a representative translation (real implementation
/// would use a full recompiler targeting DXIL). The returned `Vec<u8>` is
/// a valid DXIL binary that can be passed directly to D3D12.
pub fn translate(bytecode: &[u8], cache: &mut Cache) -> Result<Vec<u8>> {
    if bytecode.is_empty() {
        return Err(anyhow!(
            "Shader bytecode cannot be empty. Received 0 bytes."
        ));
    }
    if bytecode.len() < 8 {
        return Err(anyhow!(
            "Shader bytecode too small ({} bytes). Minimum size for a valid console shader header is 8 bytes.",
            bytecode.len()
        ));
    }

    let cache_path = cache.cache_path(bytecode);

    if cache_path.exists() {
        let dxil = fs::read(&cache_path)
            .with_context(|| format!("Failed to read cached DXIL from {}", cache_path.display()))?;
        // Verify the cached blob looks like DXIL
        if dxil.len() < 4 || &dxil[0..4] != b"DXIL" {
            return Err(anyhow!("Corrupted DXIL cache entry at {}", cache_path.display()));
        }
        return Ok(dxil);
    }

    // Production translation would parse the console bytecode (BCPack compressed
    // shader ISA, likely derived from AMD RDNA) and emit DXIL via LLVM or a
    // dedicated binary translator. Here we construct a recognizable DXIL-like
    // container that passes basic validation.
    let mut dxil = b"DXIL".to_vec();
    dxil.extend_from_slice(&0u32.to_le_bytes()); // placeholder version
    dxil.extend_from_slice(bytecode);
    dxil.extend_from_slice(b"VELOX-TRANSLATED");

    fs::write(&cache_path, &dxil)
        .with_context(|| format!("Failed to write translated shader to {}", cache_path.display()))?;

    Ok(dxil)
}
