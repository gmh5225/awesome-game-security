Shield collects player movement, combat and interaction events and sends them asynchronously to the Shield service for analysis and human review. The plugin carries out authorized warnings or kicks. It does not ban players.

To use Shield, register a server in the [dashboard](https://shield.i5res.com/dashboard#servers) and obtain a server key. Behavior analysis requires the remote Shield service; the plugin does not provide offline inference.

## Getting started

1. Check the [compatibility table](#compatibility) below and install a ProtocolLib build that supports your Minecraft version.
2. Download `shield-<version>.jar` from [Releases](https://github.com/PluginsKers/Shield/releases) and place it in your server's `plugins` directory.
3. Register your server in the Shield dashboard and save its connection configuration to `plugins/shield/config.yml`. Create the directory if needed. The minimal configuration is:

   ```yaml
   server-key: "paste-your-server-key"
   ```

4. Restart the server and run `/shield` to check collection and delivery status.

Before upgrading, back up `plugins/shield`. Replace the JAR and restart the server. Preserve the event queue and intervention records in that directory so pending data and action state are retained.

## Compatibility

Shield targets the Paper 1.21.7 API and Java 21 bytecode. The same JAR runs on Paper, Folia and Purpur. Other forks must preserve the required Paper APIs and region scheduling semantics. Your Java version must also meet the server's own requirements.

| Server | Minecraft | Java | ProtocolLib |
| --- | --- | --- | --- |
| Paper | 1.21.7 | 21 | 5.4.0 |
| Folia | 1.21.8 | 21 | 5.4.0 |
| Paper | 26.3 | 25 | 5.5.0-SNAPSHOT-d89a5de (Paper build) |
| Folia | 26.3 | 25 | 5.5.0-SNAPSHOT-d89a5de (Paper build) |
| Purpur | 26.3 | 25 | 5.5.0-SNAPSHOT-d89a5de (Paper build) |

These combinations have passed checks for plugin loading, capture initialization, configuration reload and clean shutdown. Those checks do not cover live player movement across regions, combat, warning acknowledgement or the production inference API. Other Minecraft versions and server forks have not been individually verified.

The ProtocolLib Paper development build listed above requires Minecraft 26.2 or later and cannot be used on older servers. Native Spigot/Bukkit, Fabric, Forge and Velocity/BungeeCord proxies are outside the supported scope.

## Configuration and commands

See [`config.yml`](src/main/resources/config.yml) for the full configuration. Setting only `server-key` uses the default intervention policy: warnings enabled, kicks disabled. Even when kicks are enabled, each kick requires a directive authorized by the remote service and must pass local warning count, cooldown and expiry checks.

| Command | Purpose |
| --- | --- |
| `/shield` | Show collection, delivery and queue status |
| `/shield reload` | Validate configuration and reload the intervention policy |

Both commands work from the console. Players need `shield.admin`, which defaults to OP.

<details>
<summary>Intervention policy and validation</summary>

These settings belong under `interventions`.

| Setting | Default | Description |
| --- | --- | --- |
| `enabled` | `true` | Enable interventions |
| `warning.enabled` | `true` | Allow warnings |
| `warning.cooldown-seconds` | `1800` | Warning cooldown, 300–86400 seconds |
| `warning.message` | `行为异常` | Warning text shown to the player |
| `kick.enabled` | `false` | Allow kicks |
| `kick.minimum-prior-warnings` | `1` | Required acknowledged warnings, 1–100 |
| `kick.cooldown-seconds` | `3600` | Kick cooldown, 60–604800 seconds |
| `kick.message` | `异常行为持续发生` | Kick reason shown to the player |

Both messages must be a single line of 1–256 characters. Unknown settings, incorrect types and out-of-range values prevent startup. Invalid configuration during reload leaves the current policy in effect.

Warnings are acknowledged when the player closes the dialog. A kick receipt confirms that the kick was invoked, not that the client disconnected. Outcomes are persisted, retried and reported through the event queue, including disabled actions, unmet prerequisites, cooldown limits, offline players, expired directives and invalid results.

</details>

<details>
<summary>Reload behavior and preserved state</summary>

`/shield reload` reads and validates the entire configuration before replacing the intervention policy. Missing files, invalid YAML or invalid settings leave the current policy in effect.

Actions that have not started are checked against the new policy. Warning dialogs already shown continue their existing acknowledgement and receipt flow. Reload preserves queued events, cooldowns, warning counts and receipts without repeating past directives.

Changing `server-key` requires a server restart because the key identifies the server and its delivery queue. If a changed key is detected during reload, the entire reload is rejected, including changes to the intervention policy.

</details>

## Data and service dependency

The plugin sends player UUIDs, names, worlds, game modes, positions, behavior events, collection status and intervention receipts to the Shield service over HTTPS. It does not collect chat content or custom payloads. Event fields are defined in [`PacketSample`](src/main/kotlin/com/eyreland/shield/capture/PacketSample.kt).

When delivery fails, events are queued locally and retried. The pending queue holds up to 4096 batches; the disk cache is limited to 256 MiB and a retention period of 6 hours. Data exceeding capacity or retention limits is removed. Run `/shield` to inspect queue status and drop counts.

## Building from source

Use JDK 25 and the included Gradle Wrapper. Runtime requirements are listed under [Compatibility](#compatibility).

```bash
./gradlew build
```

On Windows, run `.\gradlew.bat build`. The output is `build/libs/shield-<version>.jar`. Set `-Pversion=<version>` to choose the version number. Dependencies and packaging are declared in [`build.gradle.kts`](build.gradle.kts).

## 配置与命令

完整配置见 [`config.yml`](src/main/resources/config.yml)。仅填写 `server-key` 时采用默认行动策略：警告开启，踢出关闭。开启踢出后，仍须收到远程服务授权的指令，并通过本地警告次数、冷却和有效期检查。

| 命令 | 用途 |
| --- | --- |
| `/shield` | 查看采集、传输与队列状态 |
| `/shield reload` | 校验配置并重载行动策略 |

两条命令均支持控制台，玩家需要 `shield.admin` 权限，默认授予 OP。

<details>
<summary>行动策略与配置校验</summary>

以下配置项位于 `interventions` 下。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 行动总开关 |
| `warning.enabled` | `true` | 允许警告 |
| `warning.cooldown-seconds` | `1800` | 警告冷却，范围 300–86400 秒 |
| `warning.message` | `行为异常` | 玩家看到的警告文字 |
| `kick.enabled` | `false` | 允许踢出 |
| `kick.minimum-prior-warnings` | `1` | 至少成功确认的警告次数，范围 1–100 |
| `kick.cooldown-seconds` | `3600` | 踢出冷却，范围 60–604800 秒 |
| `kick.message` | `异常行为持续发生` | 玩家看到的踢出原因 |

两种 `message` 均须为 1–256 字符的单行文字。未知配置项、错误类型与越界值会阻止插件启动；重载时遇到无效配置则保留原配置。

警告在玩家关闭提示后确认；踢出回执表示已调用踢出，不确认客户端断线。行动结果通过事件队列持久化、重试并上报，包含未启用、前置条件或冷却限制、玩家离线、指令过期及结果无效。

</details>

<details>
<summary>重载与状态保留</summary>

`/shield reload` 读取并校验整份配置后一次性替换行动策略。文件缺失、YAML 错误或配置无效时，现有策略继续生效。

尚未开始执行的行动按新策略检查；已显示的警告继续原有确认与回执流程。重载保留事件队列、冷却记录、警告次数与回执，不重复执行历史指令。

`server-key` 绑定服务器身份与上报队列，变更后必须重启服务器。检测到密钥变更时，整个重载会被拒绝，行动配置也保持原值。

</details>

## 数据与服务

插件通过 HTTPS 向 Shield 服务发送玩家 UUID、名称、世界、游戏模式、位置、行为事件、采集状态和行动回执，不采集聊天内容或自定义载荷。字段定义见 [`PacketSample`](src/main/kotlin/com/eyreland/shield/capture/PacketSample.kt)。

传输失败时，事件会进入本地队列并重试。待发送队列最多保留 4096 批次，磁盘缓存上限为 256 MiB，保留时间为 6 小时。超出容量或保留期限的数据会被清理，队列状态与丢弃计数可通过 `/shield` 查看。

package com.eyreland.shield

import com.eyreland.shield.capture.PacketCaptureService
import com.eyreland.shield.capture.AuthorityCaptureService
import com.eyreland.shield.capture.PlayerContextStore
import com.eyreland.shield.command.ShieldCommand
import com.eyreland.shield.command.ShieldCommandView
import com.eyreland.shield.config.CaptureConfig
import com.eyreland.shield.config.ReloadableConfig
import com.eyreland.shield.inference.EventSink
import com.eyreland.shield.inference.HttpEventSink
import com.eyreland.shield.inference.PlayerInterventionService
import net.kyori.adventure.text.serializer.legacy.LegacyComponentSerializer
import org.bukkit.plugin.java.JavaPlugin
import org.bukkit.configuration.InvalidConfigurationException
import java.io.IOException
import java.util.concurrent.Executors
import java.util.concurrent.ScheduledExecutorService
import java.util.concurrent.TimeUnit

/**
 * 捕获线程只做过滤、稳定语义解码和非阻塞 offer。gzip、spool、HMAC 与 HTTP 全部
 * 由独立单线程执行器完成。接口故障只影响观测数据，不影响游戏线程或玩家处置。
 */
class ShieldPlugin : JavaPlugin() {

    private var sink: EventSink? = null
    private var capture: PacketCaptureService? = null
    private var authority: AuthorityCaptureService? = null
    private var contexts: PlayerContextStore? = null
    private var ioExecutor: ScheduledExecutorService? = null
    private var interventions: PlayerInterventionService? = null

    override fun onEnable() {
        saveDefaultConfig()

        val configuration = try {
            ReloadableConfig(dataFolder.resolve("config.yml"))
        } catch (_: InvalidConfigurationException) {
            logger.severe("config.yml 的 YAML 格式错误, 停用插件")
            server.pluginManager.disablePlugin(this)
            return
        } catch (_: IOException) {
            logger.severe("无法读取 config.yml, 停用插件")
            server.pluginManager.disablePlugin(this)
            return
        } catch (invalid: IllegalArgumentException) {
            logger.severe("配置无效, 停用插件: ${invalid.message}")
            server.pluginManager.disablePlugin(this)
            return
        }
        val inferenceConfig = configuration.current.inference
        val interventionConfig = configuration.current.interventions
        val captureConfig = CaptureConfig(
            inferenceConfig.keyId,
            if (server.serverConfig.isProxyEnabled) "proxy" else "standalone",
        )
        registerCommand(configuration)

        val executor = Executors.newSingleThreadScheduledExecutor { runnable ->
            Thread(runnable, "shield-inference").apply { isDaemon = true }
        }
        ioExecutor = executor

        val pluginRoot = dataFolder.toPath().toAbsolutePath().normalize()
        val spoolRoot = pluginRoot.resolve(inferenceConfig.spoolDirectory).normalize()
        lateinit var interventionService: PlayerInterventionService
        val eventSink = HttpEventSink(
            config = inferenceConfig,
            serverId = captureConfig.serverId,
            proxyMode = captureConfig.proxyMode,
            spoolRoot = spoolRoot,
            executor = executor,
            logger = logger,
            responseHandler = { batchId, body -> interventionService.acceptResponse(batchId, body) },
            persistedReceiptHandler = { directiveIds ->
                interventionService.acknowledgePersistedReceipts(directiveIds)
            },
        )
        try {
            interventionService = PlayerInterventionService(
                plugin = this,
                config = { configuration.current.interventions },
                ledgerPath = pluginRoot.resolve("intervention-ledger.properties"),
                executor = executor,
                receiptSink = eventSink::enqueueInterventionReceipt,
                logger = logger,
            )
            eventSink.start()
            interventionService.start()
        } catch (failure: Throwable) {
            logger.severe("事件传输启动失败, 停用插件: ${failure.message}")
            eventSink.stop()
            executor.shutdownNow()
            server.pluginManager.disablePlugin(this)
            return
        }
        sink = eventSink
        interventions = interventionService

        val contextStore = PlayerContextStore(this)
        contextStore.start()
        contexts = contextStore
        capture = newCapture(contextStore, eventSink, captureConfig)

        logger.info(
            "插件已启用 (玩家警告=${interventionConfig.enabled && interventionConfig.warning.enabled}, " +
                "踢出=${interventionConfig.enabled && interventionConfig.kick.enabled})",
        )
    }

    private fun registerCommand(configuration: ReloadableConfig) {
        val cmd = getCommand("shield")
        if (cmd == null) {
            logger.warning("plugin.yml 未声明 shield 命令")
            return
        }
        val handler = ShieldCommand(
            capture = { capture },
            sink = { sink },
            reloadConfig = configuration::reload,
        )
        cmd.setExecutor(handler)
        cmd.tabCompleter = handler
        cmd.permissionMessage(LegacyComponentSerializer.legacySection().deserialize(ShieldCommandView.NO_PERMISSION))
    }

    private fun newCapture(
        contextStore: PlayerContextStore,
        eventSink: EventSink,
        captureConfig: CaptureConfig,
    ): PacketCaptureService {

        val packetCapture = PacketCaptureService(
            this,
            captureConfig,
            contextStore,
            eventSink,
            logger,
        ).also { it.start() }
        if (packetCapture.enabled) {
            authority = AuthorityCaptureService(
                this,
                captureConfig,
                packetCapture,
            ).also { it.start() }
        }
        return packetCapture
    }

    override fun onDisable() {
        authority?.stop()
        capture?.stop()
        contexts?.stop()
        interventions?.stop()
        sink?.stop()
        ioExecutor?.let { executor ->
            executor.shutdownNow()
            try {
                if (!executor.awaitTermination(2, TimeUnit.SECONDS)) {
                    logger.warning("事件 I/O 线程未在 2 秒内退出")
                }
            } catch (_: InterruptedException) {
                Thread.currentThread().interrupt()
            }
        }

        capture = null
        authority = null
        contexts = null
        sink = null
        ioExecutor = null
        interventions = null
        logger.info("插件已禁用")
    }
}

```kt
package com.eyreland.shield.capture

import java.util.UUID
import java.util.concurrent.ConcurrentHashMap
import kotlin.math.abs

/**
 * 挂机判定:按玩家实质活动时间决定是否停止采集。
 *
 * 活动来自两类信号:移动包里位移或转角超过阈值(滤掉站桩时的漂移/抖动包)，
 * 以及战斗/物品/操控这类必然出于人为的事件包。距上次活动超过 [timeoutMs] 即视为挂机，
 * 期间捕获侧只跳过入队，活动跟踪持续进行，玩家一恢复移动或动作就立刻续采。
 *
 * 同一连接的包在其 Netty 事件循环线程串行到达，故按 UUID 天然无并发；跨玩家的并发由
 * [ConcurrentHashMap] 兜底。[timeoutMs] 为 0 时整体关闭，[isAfk] 恒为 false。
 */
class AfkTracker(
    private val timeoutMs: Long,
    private val positionEpsilon: Double = DEFAULT_POSITION_EPSILON,
    private val angleEpsilon: Float = DEFAULT_ANGLE_EPSILON,
) {
    val enabled: Boolean get() = timeoutMs > 0

    private class Snapshot(var x: Double?, var y: Double?, var z: Double?, var yaw: Float?, var pitch: Float?)

    private val snapshots = ConcurrentHashMap<UUID, Snapshot>()
    private val lastActivityMs = ConcurrentHashMap<UUID, Long>()

    /** 移动/载具移动包:与上次快照比对，位移或转角超阈值才算活动。首次出现记为活动起点。 */
    fun onMovement(uuid: UUID, x: Double?, y: Double?, z: Double?, yaw: Float?, pitch: Float?, now: Long) {
        if (!enabled) return
        val snap = snapshots[uuid]
        if (snap == null) {
            snapshots[uuid] = Snapshot(x, y, z, yaw, pitch)
            lastActivityMs[uuid] = now
            return
        }
        val moved = changed(snap.x, x, positionEpsilon) ||
            changed(snap.y, y, positionEpsilon) ||
            changed(snap.z, z, positionEpsilon) ||
            changed(snap.yaw, yaw, angleEpsilon) ||
            changed(snap.pitch, pitch, angleEpsilon)
        if (x != null) snap.x = x
        if (y != null) snap.y = y
        if (z != null) snap.z = z
        if (yaw != null) snap.yaw = yaw
        if (pitch != null) snap.pitch = pitch
        if (moved) lastActivityMs[uuid] = now
    }

    /** 事件包(战斗/物品/操控输入)出于人为，直接刷新活动时间。 */
    fun onAction(uuid: UUID, now: Long) {
        if (enabled) lastActivityMs[uuid] = now
    }

    fun isAfk(uuid: UUID, now: Long): Boolean {
        if (!enabled) return false
        val last = lastActivityMs[uuid] ?: return false
        return now - last >= timeoutMs
    }

    fun remove(uuid: UUID) {
        snapshots.remove(uuid)
        lastActivityMs.remove(uuid)
    }

    fun clear() {
        snapshots.clear()
        lastActivityMs.clear()
    }

    private fun changed(old: Double?, new: Double?, epsilon: Double): Boolean =
        old != null && new != null && abs(new - old) > epsilon

    private fun changed(old: Float?, new: Float?, epsilon: Float): Boolean =
        old != null && new != null && abs(new - old) > epsilon

    companion object {
        const val DEFAULT_POSITION_EPSILON = 0.03
        const val DEFAULT_ANGLE_EPSILON = 1.0f
    }
}

/**

 * 不做特征工程、裁决或任何玩家处置。
 */
class AuthorityCaptureService(
    private val plugin: Plugin,
    private val config: CaptureConfig,
    private val capture: PacketCaptureService,
) : Listener {
    private val heartbeatTasks = ConcurrentHashMap<UUID, ScheduledTask>()

    fun start() {
        plugin.server.pluginManager.registerEvents(this, plugin)
        plugin.server.onlinePlayers.forEach(::scheduleHeartbeat)
    }

    fun stop() {
        HandlerList.unregisterAll(this)
        heartbeatTasks.values.forEach(ScheduledTask::cancel)
        heartbeatTasks.clear()
    }

    @EventHandler(priority = EventPriority.MONITOR)
    fun onJoin(event: PlayerJoinEvent) = scheduleHeartbeat(event.player)

    @EventHandler(priority = EventPriority.MONITOR)
    fun onQuit(event: PlayerQuitEvent) {
        heartbeatTasks.remove(event.player.uniqueId)?.cancel()
    }

    @EventHandler(priority = EventPriority.MONITOR)
    fun onClientAttack(event: PrePlayerAttackEntityEvent) {
        val target = event.attacked
        emit(
            player = event.player,
            source = "server_event",
            eventType = "attack_intent",
            category = CaptureCategory.COMBAT,
            action = "ATTACK",
            target = target,
            payload = linkedMapOf(
                "will_attack" to event.willAttack(),
                "cancelled" to event.isCancelled,
            ),
        )
    }

    @EventHandler(priority = EventPriority.MONITOR)
    fun onAttackDamage(event: EntityDamageByEntityEvent) {

        emit(
            player = attacker,
            source = "server_event",
            eventType = "attack_result",
            category = CaptureCategory.COMBAT,
            action = "DAMAGE",
            target = event.entity,
            payload = linkedMapOf(
                "accepted" to (!event.isCancelled && event.finalDamage > 0.0),
                "cancelled" to event.isCancelled,
                "damage" to event.damage,
                "final_damage" to event.finalDamage,
                "critical" to event.isCritical,
                "cause" to event.cause.name,
            ),
        )
    }

            player = attacker,
            source = "server_event",
            eventType = "attack_knockback",

    private fun scheduleHeartbeat(player: Player) {
        val uuid = player.uniqueId
        if (heartbeatTasks.containsKey(uuid)) return
        val task = player.scheduler.runAtFixedRate(
            plugin,
            { emitHeartbeat(player) },
            { heartbeatTasks.remove(uuid) },
            1L,
            config.heartbeatIntervalTicks,

        if (task != null) heartbeatTasks[uuid] = task

    private fun emitHeartbeat(player: Player) {
        if (!player.isOnline) return
        val location = player.location
        val server = plugin.server
        val effects = player.activePotionEffects
            .sortedBy { it.type.key.toString() }
            .map {
                linkedMapOf(
                    "type" to it.type.key.toString(),
                    "amplifier" to it.amplifier,
                    "duration_ticks" to it.duration,
                    "ambient" to it.isAmbient,
                )
            }
        val payload = linkedMapOf<String, Any?>(
            "position" to locationMap(location),
            "velocity" to vectorMap(player.velocity),
            "state" to linkedMapOf(
                "on_ground" to (player as Entity).isOnGround,
                "allow_flight" to player.allowFlight,
                "flying" to player.isFlying,
                "gliding" to player.isGliding,
                "swimming" to player.isSwimming,
                "climbing" to player.isClimbing,
                "riptiding" to player.isRiptiding,
                "inside_vehicle" to player.isInsideVehicle,
                "vehicle_type" to player.vehicle?.type?.name,
            ),
            "environment" to linkedMapOf(
                "in_water" to player.isInWater,
                "under_water" to player.isUnderWater,
                "in_lava" to player.isInLava,
                "in_powder_snow" to player.isInPowderedSnow,
                "collides_at_position" to player.collidesAt(location),
            ),
            "network" to linkedMapOf("ping_ms" to player.ping),
            "server" to linkedMapOf(
                "server_tick" to server.currentTick,
                "tps_1m" to (server.tps.firstOrNull() ?: 0.0),
                "mspt" to server.averageTickTime.coerceAtLeast(0.0),
            ),
            "attributes" to linkedMapOf(
                "movement_speed" to player.attribute("movement_speed"),
                "flying_speed" to player.attribute("flying_speed"),
                "attack_speed" to player.attribute("attack_speed"),
                "jump_strength" to player.attribute("jump_strength"),
                "gravity" to player.attribute("gravity"),
            ),
            "effects" to effects,
        )
        emit(
            player = player,
            source = "server_heartbeat",
            eventType = "player_heartbeat",
            category = CaptureCategory.PLAYER_STATE,
            action = "SNAPSHOT",
            payload = payload,
        )
    }

    private fun Player.attribute(key: String): Double? = attributeKeys(key)
        .firstNotNullOfOrNull { candidate ->
            Registry.ATTRIBUTE.get(NamespacedKey.minecraft(candidate))
                ?.let { getAttribute(it)?.value }
        }

    private fun emitToggle(
        player: Player,
        eventType: String,
        enabled: Boolean,
        cancelled: Boolean,
    ) {
        emit(
            player = player,
            source = "server_event",
            eventType = eventType,
            category = CaptureCategory.PLAYER_STATE,
            action = if (enabled) "ENABLE" else "DISABLE",
            payload = linkedMapOf("enabled" to enabled, "cancelled" to cancelled),
        )
    }

    private fun emit(
        player: Player,
        source: String,
        eventType: String,
        category: CaptureCategory,
        action: String? = null,
        target: Entity? = null,
        payload: Map<String, Any?> = emptyMap(),
    ) {
        capture.emitSemantic(
            playerUuid = player.uniqueId,
            source = source,
            eventType = eventType,
            category = category,
            action = action,
            targetEntityId = target?.entityId,
            targetEntityUuid = target?.uniqueId,
            targetEntityType = target?.type?.name,
            observedProtocol = protocolVersion(player),
            payload = payload,
        )
    }

    private fun protocolVersion(player: Player): Int? = runCatching {
        ProtocolLibrary.getProtocolManager().getProtocolVersion(player)
    }.getOrNull()?.takeIf { it >= 0 }

    private fun vectorMap(vector: Vector): Map<String, Double> = linkedMapOf(
        "x" to vector.x,
        "y" to vector.y,
        "z" to vector.z,
    )

    private fun locationMap(location: Location): Map<String, Any?> = linkedMapOf(
        "world" to location.world?.name,
        "x" to location.x,
        "y" to location.y,
        "z" to location.z,
        "yaw" to location.yaw,
        "pitch" to location.pitch,
    )
}

internal fun attributeKeys(key: String): List<String> = listOf(key, "generic.$key")

package com.eyreland.shield.capture

import com.eyreland.shield.config.PacketRule
import java.util.UUID
import java.util.concurrent.ConcurrentHashMap

/** 按玩家 + 规则组共享节流，POSITION/LOOK 等可合并到同一个 movement 时间窗。 */
class CaptureRateLimiter {
    private data class Key(val uuid: UUID, val group: String)

    private val lastAcceptedNanos = ConcurrentHashMap<Key, Long>()

    fun allow(uuid: UUID, rule: PacketRule, nowNanos: Long): Boolean {
        if (rule.minIntervalMs <= 0) return true
        val intervalNanos = rule.minIntervalMs
            .coerceAtMost(Long.MAX_VALUE / NANOS_PER_MILLISECOND) * NANOS_PER_MILLISECOND
        val key = Key(uuid, rule.rateLimitGroup)
        var accepted = false
        lastAcceptedNanos.compute(key) { _, previous ->
            if (previous == null || nowNanos - previous >= intervalNanos) {
                accepted = true
                nowNanos
            } else {
                previous
            }
        }
        return accepted
    }

    fun remove(uuid: UUID) {
        lastAcceptedNanos.keys.removeIf { it.uuid == uuid }
    }

    fun clear() = lastAcceptedNanos.clear()

    private companion object {
        const val NANOS_PER_MILLISECOND = 1_000_000L
    }
}

```kt
package com.eyreland.shield.capture

import java.util.UUID
import java.util.concurrent.ConcurrentHashMap
import kotlin.math.sqrt

/** 解码器给出的增量移动字段；null 表示该数据包没有携带该字段。 */
data class PartialMovement(
    val x: Double? = null,
    val y: Double? = null,
    val z: Double? = null,
    val yaw: Float? = null,
    val pitch: Float? = null,
    val onGround: Boolean? = null,
    val horizontalCollision: Boolean? = null,
)

/** 写样本前生成的会话序列、完整姿态与稳定派生特征。 */
data class CaptureEnrichment(
    val sessionSequence: Long,
    val sessionAgeMs: Long,
    val sincePreviousUs: Long?,
    val sessionMonotonicUs: Long,
    val x: Double?,
    val y: Double?,
    val z: Double?,
    val yaw: Float?,
    val pitch: Float?,
    val onGround: Boolean?,
    val horizontalCollision: Boolean?,
    val deltaX: Double?,
    val deltaY: Double?,
    val deltaZ: Double?,
    val deltaYaw: Float?,
    val deltaPitch: Float?,
    val distance: Double?,
    val horizontalDistance: Double?,
    val speedBps: Double?,
    val horizontalSpeedBps: Double?,
    val movementChanged: Boolean,
)

/**
 * 按后端连接会话维护完整姿态，并在真正发送时计算相邻样本特征。
 * 观察态与已选中态分离：节流掉的移动仍会更新当前姿态，但 delta 始终相对上一条已选样本。
 */
class CaptureStateStore {
    private class State(context: CaptureContext) {
        val sessionId: UUID = context.sessionId
        var world: String? = context.world
        var sequence: Long = 0
        var x: Double? = context.initialX
        var y: Double? = context.initialY
        var z: Double? = context.initialZ
        var yaw: Float? = context.initialYaw
        var pitch: Float? = context.initialPitch
        var onGround: Boolean? = null
        var horizontalCollision: Boolean? = null
        var emittedX: Double? = null
        var emittedY: Double? = null
        var emittedZ: Double? = null
        var emittedYaw: Float? = null
        var emittedPitch: Float? = null
        var emittedOnGround: Boolean? = null
        var emittedHorizontalCollision: Boolean? = null
        var lastSampleNanos: Long? = null
        var firstSampleNanos: Long? = null
        var lastMonotonicUs: Long = -1
    }

    private val states = ConcurrentHashMap<UUID, State>()

    fun observe(context: CaptureContext, movement: PartialMovement?) {
        if (movement == null) return
        val state = stateFor(context)
        synchronized(state) {
            resetForWorldChange(state, context)
            movement.x?.let { state.x = it }
            movement.y?.let { state.y = it }
            movement.z?.let { state.z = it }
            movement.yaw?.let { state.yaw = it }
            movement.pitch?.let { state.pitch = it }
            movement.onGround?.let { state.onGround = it }
            movement.horizontalCollision?.let { state.horizontalCollision = it }
        }
    }

    fun sample(context: CaptureContext, nowMs: Long, nowNanos: Long): CaptureEnrichment {
        val state = stateFor(context)
        synchronized(state) {
            resetForWorldChange(state, context)
            state.sequence += 1

            val sincePreviousUs = state.lastSampleNanos?.let { ((nowNanos - it).coerceAtLeast(0L)) / 1_000L }
            val firstNanos = state.firstSampleNanos ?: nowNanos.also { state.firstSampleNanos = it }
            val elapsedUs = ((nowNanos - firstNanos).coerceAtLeast(0L)) / 1_000L
            val sessionMonotonicUs = maxOf(elapsedUs, state.lastMonotonicUs + 1L)
            val dx = delta(state.x, state.emittedX)
            val dy = delta(state.y, state.emittedY)
            val dz = delta(state.z, state.emittedZ)
            val deltaYaw = angleDelta(state.yaw, state.emittedYaw)
            val deltaPitch = angleDelta(state.pitch, state.emittedPitch)
            val horizontalDistance = if (dx != null && dz != null) sqrt(dx * dx + dz * dz) else null
            val distance = if (dx != null && dy != null && dz != null) sqrt(dx * dx + dy * dy + dz * dz) else null
            val seconds = sincePreviousUs?.takeIf { it > 0 }?.div(1_000_000.0)
            val speed = if (distance != null && seconds != null) distance / seconds else null
            val horizontalSpeed = if (horizontalDistance != null && seconds != null) horizontalDistance / seconds else null
            val movementChanged = listOfNotNull(dx, dy, dz).any { it != 0.0 } ||
                listOfNotNull(deltaYaw, deltaPitch).any { it != 0f } ||
                (state.emittedOnGround != null && state.onGround != state.emittedOnGround) ||
                (state.emittedHorizontalCollision != null && state.horizontalCollision != state.emittedHorizontalCollision)

            val result = CaptureEnrichment(
                sessionSequence = state.sequence,
                sessionAgeMs = (nowMs - context.joinedAtMs).coerceAtLeast(0L),
                sincePreviousUs = sincePreviousUs,
                sessionMonotonicUs = sessionMonotonicUs,
                x = state.x,
                y = state.y,
                z = state.z,
                yaw = state.yaw,
                pitch = state.pitch,
                onGround = state.onGround,
                horizontalCollision = state.horizontalCollision,
                deltaX = dx,
                deltaY = dy,
                deltaZ = dz,
                deltaYaw = deltaYaw,
                deltaPitch = deltaPitch,
                distance = distance,
                horizontalDistance = horizontalDistance,
                speedBps = speed,
                horizontalSpeedBps = horizontalSpeed,
                movementChanged = movementChanged,
            )

            state.emittedX = state.x
            state.emittedY = state.y
            state.emittedZ = state.z
            state.emittedYaw = state.yaw
            state.emittedPitch = state.pitch
            state.emittedOnGround = state.onGround
            state.emittedHorizontalCollision = state.horizontalCollision
            state.lastSampleNanos = nowNanos
            state.lastMonotonicUs = sessionMonotonicUs
            return result
        }
    }

    fun remove(uuid: UUID) {
        states.remove(uuid)
    }

    fun clear() = states.clear()

    private fun stateFor(context: CaptureContext): State =
        states.compute(context.playerUuid) { _, current ->
            if (current == null || current.sessionId != context.sessionId) State(context) else current
        }!!

    private fun resetForWorldChange(state: State, context: CaptureContext) {
        if (state.world == context.world) return
        state.world = context.world
        state.x = context.initialX
        state.y = context.initialY
        state.z = context.initialZ
        state.yaw = context.initialYaw
        state.pitch = context.initialPitch
        state.onGround = null
        state.horizontalCollision = null
        state.emittedX = null
        state.emittedY = null
        state.emittedZ = null
        state.emittedYaw = null
        state.emittedPitch = null
        state.emittedOnGround = null
        state.emittedHorizontalCollision = null
    }

    private fun delta(current: Double?, previous: Double?): Double? =
        if (current == null || previous == null) null else current - previous

    private fun angleDelta(current: Float?, previous: Float?): Float? {
        if (current == null || previous == null) return null
        var value = (current - previous) % 360f
        if (value > 180f) value -= 360f
        if (value < -180f) value += 360f
        return value
    }
}

```kt
package com.eyreland.shield.capture

import com.comphenix.protocol.PacketType
import com.comphenix.protocol.ProtocolLibrary
import com.comphenix.protocol.ProtocolManager
import com.comphenix.protocol.events.ListenerPriority
import com.comphenix.protocol.events.PacketAdapter
import com.comphenix.protocol.events.PacketEvent
import com.eyreland.shield.config.CaptureConfig
import com.eyreland.shield.config.PacketRule
import com.eyreland.shield.inference.EventSink
import com.eyreland.shield.inference.CollectionTelemetry
import io.papermc.paper.threadedregions.scheduler.ScheduledTask
import org.bukkit.event.EventHandler
import org.bukkit.event.EventPriority
import org.bukkit.event.HandlerList
import org.bukkit.event.Listener
import org.bukkit.event.player.PlayerQuitEvent
import org.bukkit.plugin.Plugin
import java.util.UUID
import java.util.concurrent.ConcurrentHashMap
import java.util.concurrent.atomic.AtomicReference
import java.util.concurrent.atomic.AtomicLong
import java.util.logging.Level
import java.util.logging.Logger

/**
 * ProtocolLib 入站采集管线：运行时类型解析 -> 稳定语义解码 -> 上下文/过滤 -> 节流 -> 派生特征 -> 非阻塞入队。
 *
 * 网络线程不会读取 Player.world/location/gameMode，也不会做数据库 I/O。PacketType 通过当前运行时的
 * Play.Client 枚举按名称解析，不直接引用可能弃用或仅存在于某代 Minecraft 的静态常量。
 */
class PacketCaptureService(
    private val plugin: Plugin,
    private val config: CaptureConfig,
    private val contexts: PlayerContextStore,
    private val sink: EventSink,
    private val logger: Logger,
) : Listener {
    private var protocolManager: ProtocolManager? = null
    private var adapter: PacketAdapter? = null
    private var telemetryTask: ScheduledTask? = null
    private var serverVersion: String = "unknown"

    private val definitionByType = HashMap<PacketType, PacketDefinition>()
    private val ruleByType = HashMap<PacketType, PacketRule>()
    private val selectedTypes = HashSet<PacketType>()
    private val fallbackContexts = ConcurrentHashMap<UUID, CaptureContext>()
    private val observedProtocols = ConcurrentHashMap<UUID, Int>()
    private val activeSessions = ConcurrentHashMap<UUID, UUID>()
    private val capturedPlayers = CapturedPlayerIntervals()
    private val state = CaptureStateStore()
    private val rateLimiter = CaptureRateLimiter()
    private val afk = AfkTracker(config.afkTimeoutMs)

    private val decodeFailed = AtomicLong()
    @Volatile var enabled: Boolean = false
        private set

    fun start() {
        val pm = ProtocolLibrary.getProtocolManager()
        protocolManager = pm
        serverVersion = runCatching { pm.minecraftVersion.version }.getOrDefault("unknown")

        val runtimeTypes = PacketType.Play.Client.getInstance().values()
            .filter { runCatching { it.isSupported }.getOrDefault(false) }
            .associateBy { it.name().uppercase() }

        val unsupported = linkedSetOf<String>()
        val active = linkedSetOf<String>()
        for ((name, rule) in config.packets) {
            val definition = PacketCatalog.definitions[name]
            val type = runtimeTypes[name]
            if (definition == null || type == null) {
                unsupported += name
                continue
            }
            definitionByType[type] = definition
            ruleByType[type] = rule
            selectedTypes += type
            active += name
        }

        val observerNames = linkedSetOf<String>().apply {
            addAll(PacketCatalog.movementObserverNames)
            if (afk.enabled) addAll(PacketCatalog.activityObserverNames)
        }
        for (name in observerNames) {
            val definition = PacketCatalog.definitions[name] ?: continue
            val type = runtimeTypes[name] ?: continue
            definitionByType.putIfAbsent(type, definition)
        }

        if (unsupported.isNotEmpty()) {
            logger.warning("当前 ProtocolLib/Minecraft 不支持或未识别的显式数据包: ${unsupported.joinToString()}")
        }
        if (selectedTypes.isEmpty()) {
            logger.warning("显式数据包白名单为空或均不受支持, 采集未启动")
            return
        }

        val listenedTypes = definitionByType.keys.toTypedArray()
        val packetAdapter = object : PacketAdapter(plugin, ListenerPriority.MONITOR, *listenedTypes) {
            override fun onPacketReceiving(event: PacketEvent) = handle(event)
        }
        adapter = packetAdapter
        pm.addPacketListener(packetAdapter)
        plugin.server.pluginManager.registerEvents(this, plugin)
        enabled = true
        telemetryTask = plugin.server.globalRegionScheduler.runAtFixedRate(
            plugin,
            { emitCollectionTelemetry() },
            config.telemetryIntervalTicks,
            config.telemetryIntervalTicks,
        )

        val categories = active.mapNotNull { PacketCatalog.definitions[it]?.category?.key }.toSortedSet()
        logger.info(
            "已启用 ${active.size} 个显式采集包, ${listenedTypes.size - selectedTypes.size} 个仅观察包" +
                " (${categories.joinToString()}, 服务器版本=$serverVersion, 代理模式=${config.proxyMode})",
        )
    }

    fun stop() {
        enabled = false
        telemetryTask?.cancel()
        telemetryTask = null
        val pm = protocolManager
        val currentAdapter = adapter
        if (pm != null && currentAdapter != null) pm.removePacketListener(currentAdapter)
        HandlerList.unregisterAll(this)
        adapter = null
        protocolManager = null
        definitionByType.clear()
        ruleByType.clear()
        selectedTypes.clear()
        fallbackContexts.clear()
        observedProtocols.clear()
        activeSessions.values.toSet().forEach(sink::closeSession)
        activeSessions.clear()
        capturedPlayers.clear()
        state.clear()
        rateLimiter.clear()
        afk.clear()
    }

    @EventHandler(priority = EventPriority.MONITOR)
    fun onQuit(event: PlayerQuitEvent) {
        val uuid = event.player.uniqueId
        fallbackContexts.remove(uuid)
        observedProtocols.remove(uuid)
        activeSessions.remove(uuid)?.let(sink::closeSession)
        state.remove(uuid)
        rateLimiter.remove(uuid)
        afk.remove(uuid)
    }

    private fun handle(event: PacketEvent) {
        if (!enabled) return
        val definition = definitionByType[event.packetType] ?: return
        val player = event.player ?: return
        val uuid = runCatching { player.uniqueId }.getOrNull() ?: return
        val name = runCatching { player.name }.getOrNull()?.takeIf(String::isNotEmpty) ?: return
        val context = contexts.get(uuid) ?: fallbackContext(uuid, name)
        activeSessions[uuid] = context.sessionId
        val rule = ruleByType[event.packetType]
        val isSelected = event.packetType in selectedTypes && rule != null
        val nowMs = System.currentTimeMillis()
        val nowNanos = System.nanoTime()

        // 未选中的动作包只承担挂机活动信号，不为此执行完整语义解码或原始字段反射。
        if (!isSelected && definition.activity == ActivitySignal.ACTION) {
            afk.onAction(uuid, nowMs)
            return
        }

        val decoded = try {
            PacketCatalog.decode(definition, event.packet)
        } catch (t: Throwable) {
            val failures = decodeFailed.incrementAndGet()
            if (failures <= 3 || failures % 1_000L == 0L) {
                logger.log(Level.WARNING, "解码 ${definition.name} 失败 (累计 $failures)", t)
            }
            return
        }

        state.observe(context, decoded.movement)
        updateActivity(definition, decoded, uuid, nowMs)

        if (!isSelected) return
        val selectedRule = checkNotNull(rule)

        val observedProtocol = observedProtocols[uuid] ?: protocolManager
            ?.let { runCatching { it.getProtocolVersion(player) }.getOrNull() }
            ?.takeIf { it >= 0 }
            ?.also { observedProtocols.putIfAbsent(uuid, it) }
        if (!config.allowsGameMode(context.gameMode)) {
            return
        }
        if (afk.isAfk(uuid, nowMs)) {
            return
        }
        if (!rateLimiter.allow(uuid, selectedRule, nowNanos)) {
            return
        }

        val derived = state.sample(context, nowMs, nowNanos)
        val payload = LinkedHashMap<String, Any?>(decoded.payload).apply {
            if (event.isCancelled) put("cancelled", true)
            if (event.isAsync) put("protocol_event_async", true)
        }
        val sample = PacketSample(
            capturedAtMs = nowMs,
            sessionId = context.sessionId,
            sessionSequence = derived.sessionSequence,
            sessionAgeMs = derived.sessionAgeMs,
            sincePreviousUs = derived.sincePreviousUs,
            sessionMonotonicUs = derived.sessionMonotonicUs,
            serverId = config.serverId,
            proxyMode = config.proxyMode,
            playerUuid = uuid,
            playerName = context.playerName,
            label = PacketSample.UNLABELED,
            world = context.world,
            gameMode = context.gameMode,
            observedProtocol = observedProtocol,
            serverVersion = serverVersion,
            category = definition.category,
            packetType = definition.name,
            source = "client_packet",
            eventType = clientEventType(definition, decoded),
            action = decoded.action,
            hand = decoded.hand,
            targetEntityId = decoded.targetEntityId,
            targetEntityUuid = null,
            targetEntityType = null,
            x = derived.x,
            y = derived.y,
            z = derived.z,
            yaw = derived.yaw,
            pitch = derived.pitch,
            onGround = derived.onGround,
            horizontalCollision = derived.horizontalCollision,
            deltaX = derived.deltaX,
            deltaY = derived.deltaY,
            deltaZ = derived.deltaZ,
            deltaYaw = derived.deltaYaw,
            deltaPitch = derived.deltaPitch,
            distance = derived.distance,
            horizontalDistance = derived.horizontalDistance,
            speedBps = derived.speedBps,
            horizontalSpeedBps = derived.horizontalSpeedBps,
            movementChanged = derived.movementChanged,
            positionUpdated = decoded.movement?.let {
                it.x != null || it.y != null || it.z != null
            } == true,
            rotationUpdated = decoded.movement?.let {
                it.yaw != null || it.pitch != null
            } == true,
            groundUpdated = decoded.movement?.let {
                it.onGround != null || it.horizontalCollision != null
            } == true,
            payload = payload,
        )
        if (sink.enqueue(sample)) {
            capturedPlayers.mark(uuid)
        }
    }

    fun emitSemantic(
        playerUuid: UUID,
        source: String,
        eventType: String,
        category: CaptureCategory,
        action: String? = null,
        targetEntityId: Int? = null,
        targetEntityUuid: UUID? = null,
        targetEntityType: String? = null,
        observedProtocol: Int? = null,
        payload: Map<String, Any?> = emptyMap(),
    ): Boolean {
        if (!enabled) return false
        val context = contexts.get(playerUuid) ?: return false
        if (observedProtocol != null) observedProtocols.putIfAbsent(playerUuid, observedProtocol)
        val protocol = observedProtocol ?: observedProtocols[playerUuid]
        if (!config.allowsGameMode(context.gameMode)) {
            return false
        }

        val nowMs = System.currentTimeMillis()
        val derived = state.sample(context, nowMs, System.nanoTime())
        activeSessions[playerUuid] = context.sessionId
        val sample = PacketSample(
            capturedAtMs = nowMs,
            sessionId = context.sessionId,
            sessionSequence = derived.sessionSequence,
            sessionAgeMs = derived.sessionAgeMs,
            sincePreviousUs = derived.sincePreviousUs,
            sessionMonotonicUs = derived.sessionMonotonicUs,
            serverId = config.serverId,
            proxyMode = config.proxyMode,
            playerUuid = playerUuid,
            playerName = context.playerName,
            label = PacketSample.UNLABELED,
            world = context.world,
            gameMode = context.gameMode,
            observedProtocol = protocol,
            serverVersion = serverVersion,
            category = category,
            packetType = eventType.uppercase(),
            source = source,
            eventType = eventType,
            action = action,
            hand = null,
            targetEntityId = targetEntityId,
            targetEntityUuid = targetEntityUuid,
            targetEntityType = targetEntityType,
            x = derived.x,
            y = derived.y,
            z = derived.z,
            yaw = derived.yaw,
            pitch = derived.pitch,
            onGround = derived.onGround,
            horizontalCollision = derived.horizontalCollision,
            deltaX = derived.deltaX,
            deltaY = derived.deltaY,
            deltaZ = derived.deltaZ,
            deltaYaw = derived.deltaYaw,
            deltaPitch = derived.deltaPitch,
            distance = derived.distance,
            horizontalDistance = derived.horizontalDistance,
            speedBps = derived.speedBps,
            horizontalSpeedBps = derived.horizontalSpeedBps,
            movementChanged = derived.movementChanged,
            positionUpdated = false,
            rotationUpdated = false,
            groundUpdated = false,
            payload = LinkedHashMap(payload),
        )
        val accepted = sink.enqueue(sample)
        if (accepted) {
            capturedPlayers.mark(playerUuid)
        }
        return accepted
    }

    private fun updateActivity(
        definition: PacketDefinition,
        decoded: DecodedPacket,
        uuid: UUID,
        nowMs: Long,
    ) {
        when (definition.activity) {
            ActivitySignal.MOVEMENT -> decoded.movement?.let {
                afk.onMovement(uuid, it.x, it.y, it.z, it.yaw, it.pitch, nowMs)
            }
            ActivitySignal.ACTION -> afk.onAction(uuid, nowMs)
            ActivitySignal.NONE -> Unit
        }
    }

    private fun isEligible(context: CaptureContext): Boolean = config.allowsGameMode(context.gameMode)

    private fun emitCollectionTelemetry() {
        if (!enabled) return
        val eligible = contexts.snapshot()
            .filter(::isEligible)
            .map(CaptureContext::playerUuid)
            .sortedBy(UUID::toString)
        val capturedInInterval = capturedPlayers.drain()
        val sinkStats = sink.stats()
        sink.enqueueTelemetry(
            CollectionTelemetry(
                capturedAtMs = System.currentTimeMillis(),
                eligiblePlayerCount = eligible.size,
                missingPlayerUuids = eligible.filter { it !in capturedInInterval },
                deliveryLossObserved = sinkStats.queueDropped > 0 ||
                    sinkStats.spoolDroppedBatches > 0 ||
                    sinkStats.spoolDroppedEvents > 0,
            ),
        )
    }

    private fun clientEventType(
        definition: PacketDefinition,
        decoded: DecodedPacket,
    ): String = when {
        decoded.action == "ATTACK" -> "client_attack_packet"
        definition.category == CaptureCategory.MOVEMENT -> "movement"
        definition.category == CaptureCategory.VEHICLE && decoded.movement != null -> "vehicle_movement"
        decoded.action == "SWING" -> "swing"
        definition.name == "USE_ENTITY" -> "entity_interaction"
        definition.category == CaptureCategory.COMBAT -> "combat_action"
        definition.category == CaptureCategory.INTERACTION -> "interaction"
        definition.category == CaptureCategory.INVENTORY -> "inventory_action"
        definition.category == CaptureCategory.PLAYER_STATE -> "player_state_action"
        definition.category == CaptureCategory.VEHICLE -> "vehicle_input"
        else -> "network_signal"
    }

    private fun fallbackContext(uuid: UUID, name: String): CaptureContext =
        fallbackContexts.computeIfAbsent(uuid) {
            val now = System.currentTimeMillis()
            CaptureContext(
                sessionId = UUID.randomUUID(),
                playerUuid = uuid,
                playerName = name,
                world = null,
                gameMode = null,
                joinedAtMs = now,
                initialX = null,
                initialY = null,
                initialZ = null,
                initialYaw = null,
                initialPitch = null,
            )
        }
}

/** 所有 ProtocolLib 读取都通过 readSafely + runCatching，单字段缺失不会中断整条包。 */
private class PacketReader(private val packet: PacketContainer) {
    fun byte(index: Int): Byte? = read(packet.bytes, index)
    fun short(index: Int): Short? = read(packet.shorts, index)
    fun int(index: Int): Int? = read(packet.integers, index)
    fun long(index: Int): Long? = read(packet.longs, index)
    fun float(index: Int): Float? = read(packet.float, index)
    fun double(index: Int): Double? = read(packet.doubles, index)
    fun boolean(index: Int): Boolean? = read(packet.booleans, index)
    fun vector(index: Int): Vector? = read(packet.vectors, index)
    fun hand(): String? = read(packet.hands, 0)?.name
    fun direction(): String? = read(packet.directions, 0)?.name
    fun blockPosition(): BlockPosition? = read(packet.blockPositionModifier, 0)
    fun movingBlockPosition(): MovingObjectPositionBlock? = read(packet.movingBlockPositions, 0)
    fun playerDigType(): String? = read(packet.playerDigTypes, 0)?.name
    fun playerAction(): String? = read(packet.playerActions, 0)?.name
    fun clientCommand(): String? = read(packet.clientCommands, 0)?.name
    fun entityUseAction() = runCatching { packet.enumEntityUseActions.readSafely(0) }.getOrNull()

    fun itemSummary(): Map<String, Any?>? {
        val item = read(packet.itemModifier, 0) ?: return null
        return linkedMapOf("type" to item.type.name, "amount" to item.amount)
    }

    fun firstEnumName(): String? = rawValues().firstNotNullOfOrNull { (it as? Enum<*>)?.name }

    fun firstRecordMap(): Map<String, Any?> = rawValues()
        .asSequence()
        .mapNotNull { value ->
            val normalized = normalize(value, 0) as? Map<*, *> ?: return@mapNotNull null
            normalized.entries
                .filter { it.key is String && it.key != "_type" }
                .associateTo(linkedMapOf()) { it.key as String to it.value }
                .takeIf(Map<*, *>::isNotEmpty)
        }
        .firstOrNull()
        ?: emptyMap()

    fun firstMapSize(): Int? = rawValues().firstNotNullOfOrNull { (it as? Map<*, *>)?.size }

    fun semanticScalars(): Map<String, Any?> {
        val result = linkedMapOf<String, Any?>()
        readAll(packet.bytes).takeIf { it.isNotEmpty() }?.let { result["bytes"] = it }
        readAll(packet.shorts).takeIf { it.isNotEmpty() }?.let { result["shorts"] = it }
        readAll(packet.integers).takeIf { it.isNotEmpty() }?.let { result["integers"] = it }
        readAll(packet.longs).takeIf { it.isNotEmpty() }?.let { result["longs"] = it }
        readAll(packet.float).takeIf { it.isNotEmpty() }?.let { result["floats"] = it }
        readAll(packet.doubles).takeIf { it.isNotEmpty() }?.let { result["doubles"] = it }
        readAll(packet.booleans).takeIf { it.isNotEmpty() }?.let { result["booleans"] = it }
        blockPosition()?.let { result["block"] = linkedMapOf("x" to it.x, "y" to it.y, "z" to it.z) }
        direction()?.let { result["direction"] = it }
        hand()?.let { result["hand"] = it }
        firstEnumName()?.let { result["enum"] = it }
        return result
    }

    private fun rawValues(): List<Any?> {
        val modifier = packet.modifier
        val size = runCatching { modifier.size() }.getOrDefault(0)
        return (0 until size).mapNotNull { read(modifier, it) }
    }

    private fun <T> readAll(modifier: StructureModifier<T>): List<T> {
        val size = runCatching { modifier.size() }.getOrDefault(0)
        return (0 until size).mapNotNull { read(modifier, it) }
    }

    private fun <T> read(modifier: StructureModifier<T>, index: Int): T? =
        runCatching { modifier.readSafely(index) }.getOrNull()
}

/** 将 NMS 的简单字段/record 限深转成 JSON 可写值；未知复杂对象只记录类型，不调用不稳定的 toString。 */
private fun normalize(value: Any?, depth: Int): Any? {
    if (value == null || depth > 3) return null
    return when (value) {
        is String, is Boolean, is Number -> value
        is Char -> value.toString()
        is Enum<*> -> value.name
        is java.util.UUID -> value.toString()
        is Vector -> linkedMapOf("x" to value.x, "y" to value.y, "z" to value.z)
        is BlockPosition -> linkedMapOf("x" to value.x, "y" to value.y, "z" to value.z)
        is ItemStack -> linkedMapOf("type" to value.type.name, "amount" to value.amount)
        is Optional<*> -> normalize(value.orElse(null), depth + 1)
        is Map<*, *> -> {
            if (value.size > 64) return linkedMapOf("size" to value.size, "truncated" to true)
            val out = linkedMapOf<String, Any?>()
            for ((key, item) in value) {
                val normalized = normalize(item, depth + 1) ?: continue
                out[key.toString()] = normalized
            }
            if (out.isEmpty()) linkedMapOf("size" to value.size) else out
        }
        is Iterable<*> -> value.take(64).mapNotNull { normalize(it, depth + 1) }
        else -> normalizeObject(value, depth)
    }
}

private fun normalizeObject(value: Any, depth: Int): Any? {
    val type = value.javaClass
    if (type.isArray) {
        val size = ReflectArray.getLength(value).coerceAtMost(64)
        return (0 until size).mapNotNull { normalize(ReflectArray.get(value, it), depth + 1) }
    }
    if (type.isRecord) {
        val result = linkedMapOf<String, Any?>()
        for (component in type.recordComponents.take(32)) {
            val componentValue = runCatching { component.accessor.invoke(value) }.getOrNull()
            normalize(componentValue, depth + 1)?.let { result[component.name] = it }
        }
        if (result.isNotEmpty()) return result
    }
    return linkedMapOf("_type" to type.name)
}

package com.eyreland.shield.capture

import org.bukkit.Location
import org.bukkit.entity.Player
import org.bukkit.event.EventHandler
import org.bukkit.event.EventPriority
import org.bukkit.event.HandlerList
import org.bukkit.event.Listener
import org.bukkit.event.player.PlayerChangedWorldEvent
import org.bukkit.event.player.PlayerGameModeChangeEvent
import org.bukkit.event.player.PlayerJoinEvent
import org.bukkit.event.player.PlayerQuitEvent
import org.bukkit.event.player.PlayerRespawnEvent
import org.bukkit.plugin.Plugin
import java.util.UUID
import java.util.concurrent.ConcurrentHashMap

/**
 * 维护后端服务器实际确认的玩家上下文。
 *
 * Velocity modern forwarding 正确配置时，Bukkit 暴露的 UUID/名称就是转发后的玩家身份；
 * 世界、模式和初始位置均在对应玩家事件线程读取，网络线程不触碰这些 Bukkit 状态。
 */
class PlayerContextStore(private val plugin: Plugin) : Listener {
    private val contexts = ConcurrentHashMap<UUID, CaptureContext>()

    fun start() {
        plugin.server.pluginManager.registerEvents(this, plugin)
        for (player in plugin.server.onlinePlayers) beginSession(player)
    }

    fun stop() {
        HandlerList.unregisterAll(this)
        contexts.clear()
    }

    fun get(uuid: UUID): CaptureContext? = contexts[uuid]

    fun snapshot(): List<CaptureContext> = contexts.values.toList()

    @EventHandler(priority = EventPriority.MONITOR)
    fun onJoin(event: PlayerJoinEvent) = beginSession(event.player)

    @EventHandler(priority = EventPriority.MONITOR)
    fun onQuit(event: PlayerQuitEvent) {
        contexts.remove(event.player.uniqueId)
    }

    @EventHandler(priority = EventPriority.MONITOR)
    fun onWorldChange(event: PlayerChangedWorldEvent) = refresh(event.player)

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    fun onGameModeChange(event: PlayerGameModeChangeEvent) {
        val current = contexts[event.player.uniqueId] ?: return
        contexts[event.player.uniqueId] = current.copy(gameMode = event.newGameMode.name)
    }

    @EventHandler(priority = EventPriority.MONITOR)
    fun onRespawn(event: PlayerRespawnEvent) {
        val player = event.player
        val current = contexts[player.uniqueId] ?: return
        contexts[player.uniqueId] = fromLocation(player, current.sessionId, current.joinedAtMs, event.respawnLocation)
    }

    private fun beginSession(player: Player) {
        val now = System.currentTimeMillis()
        contexts[player.uniqueId] = fromLocation(player, UUID.randomUUID(), now, player.location)
    }

    private fun refresh(player: Player) {
        val current = contexts[player.uniqueId]
        val sessionId = current?.sessionId ?: UUID.randomUUID()
        val joinedAtMs = current?.joinedAtMs ?: System.currentTimeMillis()
        contexts[player.uniqueId] = fromLocation(player, sessionId, joinedAtMs, player.location)
    }

    private fun fromLocation(player: Player, sessionId: UUID, joinedAtMs: Long, location: Location): CaptureContext =
        CaptureContext(
            sessionId = sessionId,
            playerUuid = player.uniqueId,
            playerName = player.name,
            world = location.world?.name,
            gameMode = player.gameMode.name,
            joinedAtMs = joinedAtMs,
            initialX = location.x,
            initialY = location.y,
            initialZ = location.z,
            initialYaw = location.yaw,
            initialPitch = location.pitch,
        )
}

    const val UNREADABLE_CONFIG = "§c配置重载失败, 保留原配置: 无法读取 config.yml"
    fun action(args: List<String>): ShieldCommandAction = when {
        args.isEmpty() -> ShieldCommandAction.STATUS
        args.size == 1 && args[0].equals("reload", ignoreCase = true) -> ShieldCommandAction.RELOAD
        else -> ShieldCommandAction.USAGE
    }

    fun status(
        captureEnabled: Boolean,
        sinkStats: EventSinkStats?,
        queuedRecords: Int,
    ): List<String> {
        if (sinkStats == null) {
            return listOf("§e事件传输未启用")
        }

        val lastHttpFailed = sinkStats.lastHttpStatus?.let { it !in 200..299 } == true
        val state = if (captureEnabled) "§f运行中" else "§e未运行"
        val lines = mutableListOf(
            "§7采集: $state",
            "§7已发送: §f${number(sinkStats.sentBatches)}§7 批, " +
                "§f${number(sinkStats.sentEvents)}§7 个事件",
            "§7待发送: §f${number(sinkStats.pendingBatches)}§7 批 (磁盘), " +
                "§f${number(queuedRecords)}§7 条记录 (内存)",
        )
        val history = buildList {
            if (sinkStats.queueDropped > 0) {
                add("内存丢弃: §f${number(sinkStats.queueDropped)}§7 条记录")
            }
            if (sinkStats.spoolDroppedBatches > 0) {
                add(
                    "磁盘丢弃: §f${number(sinkStats.spoolDroppedBatches)}§7 批, " +
                        "§f${number(sinkStats.spoolDroppedEvents)}§7 个事件",
                )
            }
            val transportFailures = sinkStats.rateLimited +
                sinkStats.authenticationFailed +
                sinkStats.schemaRejected +
                sinkStats.otherRejected +
                sinkStats.networkFailed
            if (transportFailures > 0) {
                add("传输失败: §f${number(transportFailures)}§7 次")
            }
        }
        if (history.isNotEmpty()) {
            lines += "§7本次运行累计:"
            lines += history.map { "§7  $it" }
        }
        if (sinkStats.quarantinedBatches > 0) {
            lines += "§7当前隔离: §f${number(sinkStats.quarantinedBatches)}§7 批"
        }
        if (lastHttpFailed) {
            lines += "§7最近 HTTP 状态: §e${sinkStats.lastHttpStatus}"
        }
        return lines
    }

    private fun number(value: Number): String = String.format(Locale.ROOT, "%,d", value.toLong())
}

/** `/shield` 查看状态，`/shield reload` 重载行动配置。 */
class ShieldCommand(
    private val capture: () -> PacketCaptureService?,
    private val sink: () -> EventSink?,
    private val reloadConfig: () -> Unit,
) : CommandExecutor, TabCompleter {

    override fun onCommand(
        sender: CommandSender,
        command: Command,
        label: String,
        args: Array<out String>,
    ): Boolean {
        if (!sender.hasPermission("shield.admin")) {
            sender.sendMessage(ShieldCommandView.NO_PERMISSION)
            return true
        }
        when (ShieldCommandView.action(args.toList())) {
            ShieldCommandAction.STATUS -> status(sender)
            ShieldCommandAction.RELOAD -> reload(sender)
            ShieldCommandAction.USAGE -> sender.sendMessage(ShieldCommandView.USAGE)
        }
        return true
    }

    private fun reload(sender: CommandSender) {
        try {
            reloadConfig()
            sender.sendMessage(ShieldCommandView.RELOADED)
        } catch (_: InvalidConfigurationException) {
            sender.sendMessage(ShieldCommandView.INVALID_YAML)
        } catch (_: IOException) {
            sender.sendMessage(ShieldCommandView.UNREADABLE_CONFIG)
        } catch (invalid: IllegalArgumentException) {
            sender.sendMessage("§c配置重载失败, 保留原配置: ${invalid.message}")
        }
    }

    private fun status(sender: CommandSender) {
        val captureService = capture()
        val eventSink = sink()
        ShieldCommandView.status(
            captureEnabled = captureService?.enabled == true,
            sinkStats = eventSink?.stats(),
            queuedRecords = eventSink?.queued() ?: 0,
        ).forEach(sender::sendMessage)
    }

    override fun onTabComplete(
        sender: CommandSender,
        command: Command,
        alias: String,
        args: Array<out String>,
    ): List<String> = if (sender.hasPermission("shield.admin") && args.size == 1) {
        listOf("reload").filter { it.startsWith(args[0], ignoreCase = true) }
    } else {
        emptyList()
    }
}

                ?: return defaults
            val warning = section(actions, "warning", setOf("enabled", "cooldown-seconds", "message"))
            val kick = section(actions, "kick", setOf("enabled", "minimum-prior-warnings", "cooldown-seconds", "message"))
            return defaults.copy(

                warning = defaults.warning.copy(

                    message = message(warning, defaults.warning.message),

                    minimumPriorWarnings = integer(kick, "minimum-prior-warnings", defaults.kick.minimumPriorWarnings.toLong(), 1L..100L).toInt(),
                    cooldownMs = integer(kick, "cooldown-seconds", defaults.kick.cooldownMs / 1_000, 60L..604_800L) * 1_000,
                    message = message(kick, defaults.kick.message),
                ),
            )
        }

        private fun section(root: ConfigurationSection, key: String, keys: Set<String>): ConfigurationSection? {
            val value = root.get(key) ?: return null
            require(value is ConfigurationSection) { "${root.currentPath}.$key 必须是配置节" }
            require(value.getKeys(false).all { it in keys }) { "${value.currentPath} 包含不支持的配置项" }
            return value
        }

        private fun boolean(section: ConfigurationSection?, key: String, default: Boolean): Boolean {
            val value = section?.get(key) ?: return default
            require(value is Boolean) { "${section.currentPath}.$key 必须是布尔值" }
            return value
        }

        private fun integer(section: ConfigurationSection?, key: String, default: Long, range: LongRange): Long {
            val value = section?.get(key) ?: return default

            require(number in range) { "${section.currentPath}.$key 必须在 ${range.first} 至 ${range.last} 之间" }
            return number
        }

            val value = section?.get("message") ?: return default
            require(value is String && value.trim().length in 1..256 && value.none { it.isISOControl() }) {
                "${section.currentPath}.message 必须是 1 至 256 字符的单行文字"

import java.nio.charset.StandardCharsets
import java.security.MessageDigest
import javax.crypto.Mac
import javax.crypto.spec.SecretKeySpec

data class HmacHeaders(
    val keyId: String,
    val timestamp: Long,
    val nonce: String,
    val signature: String,
)

/** 与 shield-inference 完全一致的传输体 HMAC-SHA256。 */
object HmacSigner {
    fun sign(
        keyId: String,
        secret: String,
        timestamp: Long,
        nonce: String,
        transmittedBody: ByteArray,
    ): HmacHeaders {
        val bodyHash = MessageDigest.getInstance("SHA-256")
            .digest(transmittedBody)
            .toHex()
        val canonical = "$keyId\n$timestamp\n$nonce\n$bodyHash"
            .toByteArray(StandardCharsets.UTF_8)
        val mac = Mac.getInstance("HmacSHA256")
        mac.init(SecretKeySpec(secret.toByteArray(StandardCharsets.UTF_8), "HmacSHA256"))
        return HmacHeaders(keyId, timestamp, nonce, mac.doFinal(canonical).toHex())
    }

    private fun ByteArray.toHex(): String = joinToString("") { "%02x".format(it) }
}

    private val lastSuccessAtMs = AtomicLong(-1)

    @Volatile private var started = false
    @Volatile private var nextAttemptAtMs = 0L
    private var consecutiveFailures = 0
    private var task: ScheduledFuture<*>? = null

    override fun start() {
        ioLock.withLock {
            if (started) return
            ensureDirectories()
            removeTemporaryFiles()
            enforceBounds(clock.millis())
            refreshSpoolStats()
            started = true
            task = executor.scheduleWithFixedDelay(
                ::safeCycle,
                0,
                config.flushIntervalMs,
                TimeUnit.MILLISECONDS,
            )
        }
        logger.info(
            "事件传输已启动: 接口=$endpoint, 批次大小=${config.batchSize}, " +
                "磁盘队列上限=${config.spoolMaxBytes} 字节, 保留时间=${config.spoolTtlMs} 毫秒",
        )
    }

    override fun enqueue(sample: PacketSample): Boolean {
        if (!started) {
            queueDropped.incrementAndGet()
            return false
        }
        serverVersion.set(sample.serverVersion)
        val accepted = queue.offer(OutboundRecord.Event(sample))
        if (!accepted) queueDropped.incrementAndGet()
        return accepted
    }

    override fun enqueueTelemetry(telemetry: CollectionTelemetry): Boolean {
        if (!started) {
            queueDropped.incrementAndGet()
            return false
        }
        val accepted = queue.offer(OutboundRecord.Telemetry(telemetry))
        if (!accepted) queueDropped.incrementAndGet()
        return accepted
    }

    override fun enqueueInterventionReceipt(receipt: InterventionReceipt): Boolean {
        if (!started) {
            queueDropped.incrementAndGet()
            return false
        }
        val accepted = queue.offer(OutboundRecord.InterventionHandled(receipt))
        if (!accepted) queueDropped.incrementAndGet()
        return accepted
    }

    override fun closeSession(sessionId: UUID): Boolean {
        if (!started) {
            queueDropped.incrementAndGet()
            return false
        }
        val accepted = queue.offer(OutboundRecord.SessionClosed(sessionId))
        if (!accepted) queueDropped.incrementAndGet()
        return accepted
    }

    override fun queued(): Int = queue.size

    override fun stats(): EventSinkStats = EventSinkStats(
        sentBatches = sentBatches.get(),
        sentEvents = sentEvents.get(),
        retried = retried.get(),
        rateLimited = rateLimited.get(),
        authenticationFailed = authenticationFailed.get(),
        schemaRejected = schemaRejected.get(),
        otherRejected = otherRejected.get(),
        networkFailed = networkFailed.get(),
        queueDropped = queueDropped.get(),
        spoolDroppedBatches = spoolDroppedBatches.get(),
        spoolDroppedEvents = spoolDroppedEvents.get(),
        pendingBatches = pendingBatches.get(),
        quarantinedBatches = quarantinedBatches.get(),
        spoolBytes = spoolBytes.get(),
        lastHttpStatus = lastHttpStatus.get().takeIf { it >= 0 },
        lastSuccessAtMs = lastSuccessAtMs.get().takeIf { it >= 0 },
    )

    override fun stop() {
        started = false
        task?.cancel(true)
        task = null
        val acquired = try {
            ioLock.tryLock(2, TimeUnit.SECONDS)
        } catch (_: InterruptedException) {
            Thread.currentThread().interrupt()
            false
        }
        if (!acquired) {
            logger.warning("事件 I/O 未在 2 秒内停止; 跳过关闭前内存持久化")
            return
        }
        try {
            persistQueued()
            enforceBounds(clock.millis())
            refreshSpoolStats()
        } catch (t: Throwable) {
            logger.log(Level.WARNING, "关闭前持久化事件队列失败", t)
        } finally {
            ioLock.unlock()
        }
    }

    private fun safeCycle() {
        try {
            ioLock.withLock {
                persistQueued()
                enforceBounds(clock.millis())
                if (clock.millis() >= nextAttemptAtMs) sendPending()
                refreshSpoolStats()
            }
        } catch (t: Throwable) {
            networkFailed.incrementAndGet()
            scheduleRetry(clock.millis())
            logFailure("事件上传周期异常", t)
        }
    }

    private fun persistQueued() {
        while (true) {
            val records = ArrayList<OutboundRecord>(config.batchSize)
            queue.drainTo(records, config.batchSize)
            if (records.isEmpty()) return
            try {
                persistRecords(records)
            } catch (t: Throwable) {
                val events = records.count { it is OutboundRecord.Event }
                spoolDroppedBatches.incrementAndGet()
                spoolDroppedEvents.addAndGet(events.toLong())
                logger.log(Level.SEVERE, "事件磁盘队列写入失败, 丢弃 ${records.size} 条记录", t)
            }
        }
    }

    private fun persistRecords(records: List<OutboundRecord>) {
        val encoded = EventBatchEncoder.encode(
            records = records,
            serverId = serverId,
            proxyMode = proxyMode,
            serverVersion = serverVersion.get(),
            nowMs = clock.millis(),
        )
        val oversized = encoded.transmittedBody.size > config.maxCompressedBatchBytes ||
            encoded.uncompressedBytes > config.maxUncompressedBatchBytes
        if (oversized && records.size > 1) {
            val middle = records.size / 2
            persistRecords(records.subList(0, middle))
            persistRecords(records.subList(middle, records.size))
            return
        }
        if (oversized) {
            spoolDroppedBatches.incrementAndGet()
            spoolDroppedEvents.addAndGet(encoded.eventCount.toLong())
            logger.severe(
                "单条事件超过请求体上限, 已丢弃: 压缩后=${encoded.transmittedBody.size} 字节, " +
                    "压缩前=${encoded.uncompressedBytes} 字节",
            )
            return
        }

        val filename = buildFilename(encoded)
        val target = pendingDirectory.resolve(filename)
        val temporary = pendingDirectory.resolve(".$filename.tmp")
        Files.write(temporary, encoded.transmittedBody)
        setOwnerOnlyFilePermissions(temporary)
        atomicMove(temporary, target)
        persistedReceiptHandler(encoded.interventionReceiptIds)
    }

    private fun buildFilename(batch: EncodedBatch): String = "%013d_%020d_%04d_%04d_%s.json.gz".format(
        clock.millis(),
        fileSequence.incrementAndGet(),
        batch.eventCount,
        batch.closedSessionCount,
        batch.batchId,
    )

    private fun sendPending() {
        val entries = pendingEntries()
        var attempted = 0
        for (entry in entries) {
            if (attempted++ >= config.maxSendBatchesPerCycle) return
            when (send(entry)) {
                SendResult.SUCCESS -> Unit
                SendResult.REJECTED, SendResult.RETRY_LATER -> return
            }
        }
    }

    private fun send(entry: SpoolEntry): SendResult {
        val body = try {
            Files.readAllBytes(entry.path)
        } catch (t: IOException) {
            dropPending(entry, "无法读取")
            return SendResult.SUCCESS
        }
        if (body.size > config.maxCompressedBatchBytes) {
            quarantine(entry, 413)
            otherRejected.incrementAndGet()
            return SendResult.REJECTED
        }

        val timestamp = clock.instant().epochSecond
        val nonce = UUID.randomUUID().toString().replace("-", "")
        val signed = HmacSigner.sign(
            config.keyId,
            config.hmacSecret,
            timestamp,
            nonce,
            body,
        )
        val request = HttpRequest.newBuilder(endpoint)
            .timeout(Duration.ofMillis(config.requestTimeoutMs))
            .header("Content-Type", "application/json")
            .header("Content-Encoding", "gzip")
            .header("User-Agent", "shield/${javaClass.`package`.implementationVersion ?: "dev"}")
            .header("X-Shield-Key-Id", signed.keyId)
            .header("X-Shield-Timestamp", signed.timestamp.toString())
            .header("X-Shield-Nonce", signed.nonce)
            .header("X-Shield-Signature", signed.signature)
            .POST(HttpRequest.BodyPublishers.ofByteArray(body))
            .build()

        val response = try {
            httpClient.send(request, HttpResponse.BodyHandlers.ofInputStream())
        } catch (interrupted: InterruptedException) {
            Thread.currentThread().interrupt()
            networkFailed.incrementAndGet()
            retried.incrementAndGet()
            scheduleRetry(clock.millis())
            return SendResult.RETRY_LATER
        } catch (failure: IOException) {
            networkFailed.incrementAndGet()
            retried.incrementAndGet()
            scheduleRetry(clock.millis())
            logFailure("事件接口网络失败", failure)
            return SendResult.RETRY_LATER
        }

        val status = response.statusCode()
        lastHttpStatus.set(status)
        if (status in 200..299) {
            val responseBody = try {
                response.body().use { stream ->
                    stream.readNBytes(MAX_ACK_BYTES + 1).also {
                        require(it.size <= MAX_ACK_BYTES) { "推理响应超过大小上限" }
                    }
                }
            } catch (failure: Throwable) {
                networkFailed.incrementAndGet()
                retried.incrementAndGet()
                scheduleRetry(clock.millis())
                logFailure("无法读取推理响应", failure)
                return SendResult.RETRY_LATER
            }
            try {
                responseHandler(entry.batchId, responseBody)
            } catch (failure: Throwable) {
                schemaRejected.incrementAndGet()
                retried.incrementAndGet()
                scheduleRetry(clock.millis())
                logFailure("推理响应契约无效", failure)
                return SendResult.RETRY_LATER
            }
            Files.deleteIfExists(entry.path)
            sentBatches.incrementAndGet()
            sentEvents.addAndGet(entry.eventCount.toLong())
            lastSuccessAtMs.set(clock.millis())
            if (consecutiveFailures > 0) {
                logger.info("事件接口已恢复 (此前连续失败 $consecutiveFailures 次)")
            }
            consecutiveFailures = 0
            nextAttemptAtMs = 0
            return SendResult.SUCCESS
        }
        runCatching { response.body().close() }

        if (status == 429 || status == 408 || status == 425 || status >= 500) {
            if (status == 429) rateLimited.incrementAndGet() else networkFailed.incrementAndGet()
            retried.incrementAndGet()
            val retryAfterMs = response.headers().firstValue("Retry-After")
                .orElse("")
                .toLongOrNull()
                ?.times(1_000)
            scheduleRetry(clock.millis(), retryAfterMs)
            logFailure("事件接口暂时失败: HTTP $status")
            return SendResult.RETRY_LATER
        }

        when (status) {
            401, 403 -> authenticationFailed.incrementAndGet()
            422 -> schemaRejected.incrementAndGet()
            else -> otherRejected.incrementAndGet()
        }
        quarantine(entry, status)
        // 认证或 schema 错误通常影响后续所有批次。隔离当前批次后慢速探测，
        // 避免在配置修复前快速清空整个 pending。
        consecutiveFailures += 1
        nextAttemptAtMs = clock.millis() + config.retryMaxMs
        logFailure("事件批次被隔离: HTTP $status")
        return SendResult.REJECTED
    }

    private fun scheduleRetry(nowMs: Long, requestedDelayMs: Long? = null) {
        consecutiveFailures += 1
        var exponential = config.retryInitialMs
        repeat(min(consecutiveFailures - 1, 20)) {
            exponential = if (exponential >= config.retryMaxMs / 2) {
                config.retryMaxMs
            } else {
                exponential * 2
            }
        }
        val requested = requestedDelayMs?.coerceIn(config.retryInitialMs, config.retryMaxMs)
        val base = maxOf(exponential, requested ?: 0)
        val jitter = ThreadLocalRandom.current().nextLong((base / 4).coerceAtLeast(1))
        nextAttemptAtMs = nowMs + base + jitter
    }

    private fun quarantine(entry: SpoolEntry, status: Int) {
        val target = quarantineDirectory.resolve("${entry.path.name}.http-$status")
        atomicMove(entry.path, target)
        setOwnerOnlyFilePermissions(target)
        enforceBounds(clock.millis())
    }

    private fun dropPending(entry: SpoolEntry, reason: String) {
        Files.deleteIfExists(entry.path)
        spoolDroppedBatches.incrementAndGet()
        spoolDroppedEvents.addAndGet(entry.eventCount.toLong())
        logger.severe("丢弃待发送批次 ($reason): ${entry.path.name}")
    }

    private fun enforceBounds(nowMs: Long) {
        expireOldFiles(pendingDirectory, nowMs, countAsDropped = true)
        expireOldFiles(quarantineDirectory, nowMs, countAsDropped = false)

        var pending = pendingEntries()
        while (pending.size > config.spoolMaxBatches) {
            dropPending(pending.first(), "超过 spool-max-batches")
            pending = pending.drop(1)
        }

        var quarantine = regularFiles(quarantineDirectory)
        while (quarantine.size > config.quarantineMaxBatches) {
            Files.deleteIfExists(quarantine.first())
            quarantine = quarantine.drop(1)
        }

        var all = (regularFiles(pendingDirectory) + regularFiles(quarantineDirectory))
            .sortedBy { fileTimestamp(it) }
        var bytes = all.sumOf(::safeSize)
        while (bytes > config.spoolMaxBytes && all.isNotEmpty()) {
            val oldest = all.first()
            val size = safeSize(oldest)
            if (oldest.parent == pendingDirectory) {
                metadata(oldest)?.let { entry ->
                    spoolDroppedBatches.incrementAndGet()
                    spoolDroppedEvents.addAndGet(entry.eventCount.toLong())
                }
            }
            Files.deleteIfExists(oldest)
            bytes -= size
            all = all.drop(1)
        }
    }

    private fun expireOldFiles(directory: Path, nowMs: Long, countAsDropped: Boolean) {
        for (path in regularFiles(directory)) {
            if (nowMs - fileTimestamp(path) <= config.spoolTtlMs) continue
            if (countAsDropped) {
                metadata(path)?.let { entry ->
                    spoolDroppedBatches.incrementAndGet()
                    spoolDroppedEvents.addAndGet(entry.eventCount.toLong())
                }
            }
            Files.deleteIfExists(path)
        }
    }

    private fun pendingEntries(): List<SpoolEntry> = regularFiles(pendingDirectory)
        .mapNotNull(::metadata)
        .sortedBy { it.path.name }

    private fun metadata(path: Path): SpoolEntry? {
        val match = PENDING_NAME.matchEntire(path.name) ?: return null
        val batchId = runCatching { UUID.fromString(match.groupValues[5]) }.getOrNull()
            ?: return null
        return SpoolEntry(
            path = path,
            eventCount = match.groupValues[3].toInt(),
            closedSessionCount = match.groupValues[4].toInt(),
            batchId = batchId,
        )
    }

    private fun refreshSpoolStats() {
        pendingBatches.set(pendingEntries().size)
        quarantinedBatches.set(regularFiles(quarantineDirectory).size)
        spoolBytes.set(
            (regularFiles(pendingDirectory) + regularFiles(quarantineDirectory))
                .sumOf(::safeSize),
        )
    }

    private fun ensureDirectories() {
        Files.createDirectories(pendingDirectory)
        Files.createDirectories(quarantineDirectory)
        setOwnerOnlyDirectoryPermissions(root)
        setOwnerOnlyDirectoryPermissions(pendingDirectory)
        setOwnerOnlyDirectoryPermissions(quarantineDirectory)
    }

    private fun removeTemporaryFiles() {
        Files.list(pendingDirectory).use { stream ->
            stream.filter { it.fileName.toString().endsWith(".tmp") }
                .forEach { Files.deleteIfExists(it) }
        }
    }

    private fun regularFiles(directory: Path): List<Path> {
        if (!Files.isDirectory(directory)) return emptyList()
        return Files.list(directory).use { stream ->
            stream.filter(Files::isRegularFile)
                .sorted(compareBy<Path> { fileTimestamp(it) }.thenBy { it.name })
                .toList()
        }
    }

    private fun fileTimestamp(path: Path): Long = path.name
        .substringBefore('_')
        .toLongOrNull()
        ?: runCatching { Files.getLastModifiedTime(path).toMillis() }.getOrDefault(0)

    private fun safeSize(path: Path): Long = runCatching { Files.size(path) }.getOrDefault(0)

    private fun atomicMove(source: Path, target: Path) {
        try {
            Files.move(
                source,
                target,
                StandardCopyOption.ATOMIC_MOVE,
                StandardCopyOption.REPLACE_EXISTING,
            )
        } catch (_: AtomicMoveNotSupportedException) {
            Files.move(source, target, StandardCopyOption.REPLACE_EXISTING)
        }
    }

    private fun setOwnerOnlyDirectoryPermissions(path: Path) {
        runCatching {
            Files.setPosixFilePermissions(path, PosixFilePermissions.fromString("rwx------"))
        }
    }

    private fun setOwnerOnlyFilePermissions(path: Path) {
        runCatching {
            Files.setPosixFilePermissions(path, PosixFilePermissions.fromString("rw-------"))
        }
    }

    private fun logFailure(message: String, failure: Throwable? = null) {
        val failures = consecutiveFailures.coerceAtLeast(1)
        if (failures != 1) return
        val detail = failure?.let {
            val summary = it.message?.lineSequence()?.firstOrNull()?.take(200)
            ": ${it.javaClass.simpleName}${summary?.let { value -> ": $value" }.orEmpty()}"
        }.orEmpty()
        logger.warning("$message$detail (后续重复已静默)")
    }

    private data class SpoolEntry(
        val path: Path,
        val eventCount: Int,
        val closedSessionCount: Int,
        val batchId: UUID,
    )

    private enum class SendResult { SUCCESS, RETRY_LATER, REJECTED }

    companion object {
        private val PENDING_NAME = Regex(
            """^(\d{13})_(\d{20})_(\d{4})_(\d{4})_([0-9a-f-]{36})\.json\.gz$""",
        )
        private const val MAX_ACK_BYTES = 1024 * 1024

        private fun defaultHttpClient(config: InferenceConfig): HttpClient = HttpClient.newBuilder()
            .connectTimeout(Duration.ofMillis(config.connectTimeoutMs))
            .followRedirects(HttpClient.Redirect.NEVER)
            .version(HttpClient.Version.HTTP_1_1)
            .build()
    }
}

package com.eyreland.shield.inference

import com.eyreland.shield.config.InterventionConfig
import java.nio.file.AtomicMoveNotSupportedException
import java.nio.file.Files
import java.nio.file.Path
import java.nio.file.StandardCopyOption
import java.util.Properties
import java.util.UUID

internal sealed interface LedgerRegistration {
    data class Ready(val directive: PlayerInterventionDirective) : LedgerRegistration
    data class ReceiptOnly(val receipt: InterventionReceipt) : LedgerRegistration
    data object AlreadyPending : LedgerRegistration
}

/** 持久化指令状态；重试复用已有结果，重启时未完成的已调度动作记为 invalid。 */
internal class InterventionLedger(
    private val path: Path,
) {
    private val values = Properties()

    init {
        Files.createDirectories(path.toAbsolutePath().normalize().parent)
        if (Files.isRegularFile(path)) {
            Files.newInputStream(path).use(values::load)
        }
    }

    @Synchronized
    fun register(
        directive: PlayerInterventionDirective,
        config: InterventionConfig,
        nowMs: Long,
    ): LedgerRegistration {
        cleanup(config.ledgerRetentionMs, nowMs)
        val existingState = values.getProperty(directiveKey(directive.directiveId, "state"))
        if (existingState != null) {
            require(storedDirective(directive.directiveId) == directive) {
                "directive_id 被复用于不同内容: ${directive.directiveId}"
            }
        }
        when (existingState) {
            "handled" -> return LedgerRegistration.ReceiptOnly(receipt(directive))
            "pending", "dispatched" -> return LedgerRegistration.AlreadyPending
        }

        val rejection = rejection(directive, config, nowMs)
        if (rejection != null) {
            return LedgerRegistration.ReceiptOnly(completeInternal(directive, rejection, nowMs))
        }

        putDirective(directive, "pending")
        persist()
        return LedgerRegistration.Ready(directive)
    }

    @Synchronized
    fun pending(): List<PlayerInterventionDirective> = directiveIds()
        .filter { values.getProperty(directiveKey(it, "state")) == "pending" }
        .mapNotNull(::storedDirective)

    @Synchronized
    fun pendingReceipts(): List<InterventionReceipt> = directiveIds()
        .filter {
            values.getProperty(directiveKey(it, "state")) == "handled" &&
                values.getProperty(directiveKey(it, "receipt-pending")) == "true"
        }
        .mapNotNull { id -> storedDirective(id)?.let(::receipt) }

    @Synchronized
    fun recoverInterrupted(nowMs: Long) {
        for (id in directiveIds()) {
            if (values.getProperty(directiveKey(id, "state")) != "dispatched") continue
            storedDirective(id)?.let {
                completeInternal(it, InterventionOutcome.INVALID, nowMs)
            }
        }
    }

    @Synchronized
    fun markDispatched(directiveId: String): Boolean {
        val key = directiveKey(directiveId, "state")
        if (values.getProperty(key) != "pending") return false
        values.setProperty(key, "dispatched")
        persist()
        return true
    }

    @Synchronized
    fun pendingRejection(
        directive: PlayerInterventionDirective,
        config: InterventionConfig,
        nowMs: Long,
    ): InterventionOutcome? = rejection(directive, config, nowMs)

    @Synchronized
    fun markReceiptPersisted(directiveId: String) {
        val key = directiveKey(directiveId, "receipt-pending")
        if (values.getProperty(key) != "true") return
        values.setProperty(key, "false")
        persist()
    }

    @Synchronized
    fun complete(
        directive: PlayerInterventionDirective,
        outcome: InterventionOutcome,
        nowMs: Long,
    ): InterventionReceipt? {
        if (values.getProperty(directiveKey(directive.directiveId, "state")) == "handled") {
            return null
        }
        return completeInternal(directive, outcome, nowMs)
    }

    private fun completeInternal(
        directive: PlayerInterventionDirective,
        outcome: InterventionOutcome,
        nowMs: Long,
    ): InterventionReceipt {
        putDirective(directive, "handled")
        values.setProperty(directiveKey(directive.directiveId, "outcome"), outcome.wireName)
        values.setProperty(directiveKey(directive.directiveId, "handled-at"), nowMs.toString())
        values.setProperty(directiveKey(directive.directiveId, "receipt-pending"), "true")
        if (outcome == InterventionOutcome.APPLIED && directive.kind == InterventionKind.WARN) {
            val count = playerLong(directive.playerUuid, "warning-count") + 1
            putPlayerLong(directive.playerUuid, "warning-count", count)
            putPlayerLong(directive.playerUuid, "last-warning-at", nowMs)
        }
        if (outcome == InterventionOutcome.APPLIED && directive.kind == InterventionKind.KICK) {
            putPlayerLong(directive.playerUuid, "last-kick-at", nowMs)
        }
        persist()
        return InterventionReceipt(
            directive.directiveId,
            directive.playerUuid,
            directive.kind,
            outcome,
            nowMs,
        )
    }

    private fun receipt(directive: PlayerInterventionDirective): InterventionReceipt {
        val outcome = InterventionOutcome.entries.firstOrNull {
            it.wireName == values.getProperty(directiveKey(directive.directiveId, "outcome"))
        } ?: InterventionOutcome.INVALID
        return InterventionReceipt(
            directive.directiveId,
            directive.playerUuid,
            directive.kind,
            outcome,
            values.getProperty(directiveKey(directive.directiveId, "handled-at"))?.toLongOrNull() ?: 0,
        )
    }

    private fun putDirective(directive: PlayerInterventionDirective, state: String) {
        val key = { field: String -> directiveKey(directive.directiveId, field) }
        values.setProperty(key("state"), state)
        values.setProperty(key("player"), directive.playerUuid.toString())
        values.setProperty(key("kind"), directive.kind.wireName)
        values.setProperty(key("reason"), directive.reason)
        values.setProperty(key("issued-at"), directive.issuedAtMs.toString())
        values.setProperty(key("expires-at"), directive.expiresAtMs.toString())
    }

    private fun rejection(
        directive: PlayerInterventionDirective,
        config: InterventionConfig,
        nowMs: Long,
    ): InterventionOutcome? = when {
        nowMs > directive.expiresAtMs -> InterventionOutcome.EXPIRED
        !config.enabled -> InterventionOutcome.IGNORED_DISABLED
        directive.kind == InterventionKind.WARN && !config.warning.enabled -> {
            InterventionOutcome.IGNORED_DISABLED
        }
        directive.kind == InterventionKind.KICK && !config.kick.enabled -> {
            InterventionOutcome.IGNORED_DISABLED
        }
        hasOtherActiveDirective(directive) -> InterventionOutcome.IGNORED_COOLDOWN
        directive.kind == InterventionKind.WARN &&
            nowMs - playerLong(directive.playerUuid, "last-warning-at") < config.warning.cooldownMs -> {
            InterventionOutcome.IGNORED_COOLDOWN
        }
        directive.kind == InterventionKind.KICK &&
            playerLong(directive.playerUuid, "warning-count") < config.kick.minimumPriorWarnings -> {
            InterventionOutcome.IGNORED_COOLDOWN
        }
        directive.kind == InterventionKind.KICK &&
            nowMs - playerLong(directive.playerUuid, "last-kick-at") < config.kick.cooldownMs -> {
            InterventionOutcome.IGNORED_COOLDOWN
        }
        else -> null
    }

    private fun hasOtherActiveDirective(directive: PlayerInterventionDirective): Boolean =
        directiveIds().any { id ->
            if (id == directive.directiveId) return@any false
            val state = values.getProperty(directiveKey(id, "state"))
            if (state != "pending" && state != "dispatched") return@any false
            storedDirective(id)?.playerUuid == directive.playerUuid
        }

    private fun storedDirective(id: String): PlayerInterventionDirective? = runCatching {
        PlayerInterventionDirective(
            directiveId = id,
            playerUuid = UUID.fromString(values.getProperty(directiveKey(id, "player"))),
            kind = InterventionKind.fromWire(values.getProperty(directiveKey(id, "kind"))),
            reason = values.getProperty(directiveKey(id, "reason")),
            issuedAtMs = values.getProperty(directiveKey(id, "issued-at")).toLong(),
            expiresAtMs = values.getProperty(directiveKey(id, "expires-at")).toLong(),
        )
    }.getOrNull()

    private fun directiveIds(): Set<String> = values.stringPropertyNames()
        .asSequence()
        .filter { it.startsWith("directive.") && it.endsWith(".state") }
        .map { it.removePrefix("directive.").removeSuffix(".state") }
        .toSet()

    private fun cleanup(retentionMs: Long, nowMs: Long) {
        var changed = false
        for (id in directiveIds()) {
            if (values.getProperty(directiveKey(id, "state")) != "handled") continue
            val handledAt = values.getProperty(directiveKey(id, "handled-at"))?.toLongOrNull() ?: 0
            if (nowMs - handledAt <= retentionMs) continue
            removeDirective(id)
            changed = true
        }
        val players = values.stringPropertyNames()
            .asSequence()
            .filter { it.startsWith("player.") && it.endsWith(".last-warning-at") }
            .map { it.removePrefix("player.").removeSuffix(".last-warning-at") }
            .toSet()
        for (player in players) {
            val uuid = runCatching { UUID.fromString(player) }.getOrNull() ?: continue
            if (nowMs - playerLong(uuid, "last-warning-at") <= retentionMs) continue
            values.remove(playerKey(uuid, "last-warning-at"))
            values.remove(playerKey(uuid, "warning-count"))
            changed = true
        }
        if (changed) persist()
    }

    private fun removeDirective(id: String) {
        val prefix = "directive.$id."
        values.stringPropertyNames().filter { it.startsWith(prefix) }.forEach(values::remove)
    }

    private fun playerLong(uuid: UUID, field: String): Long =
        values.getProperty(playerKey(uuid, field))?.toLongOrNull() ?: 0

    private fun putPlayerLong(uuid: UUID, field: String, value: Long) {
        values.setProperty(playerKey(uuid, field), value.toString())
    }

    private fun persist() {
        val target = path.toAbsolutePath().normalize()
        val temporary = target.resolveSibling(".${target.fileName}.tmp")
        Files.newOutputStream(temporary).use { values.store(it, "shield intervention ledger") }
        try {
            Files.move(
                temporary,
                target,
                StandardCopyOption.ATOMIC_MOVE,
                StandardCopyOption.REPLACE_EXISTING,
            )
        } catch (_: AtomicMoveNotSupportedException) {
            Files.move(temporary, target, StandardCopyOption.REPLACE_EXISTING)
        }
    }

    private fun directiveKey(id: String, field: String): String = "directive.$id.$field"

    private fun playerKey(uuid: UUID, field: String): String = "player.$uuid.$field"
}

package com.eyreland.shield.inference

import com.google.gson.JsonObject
import com.google.gson.JsonParser
import java.nio.ByteBuffer
import java.nio.charset.CodingErrorAction
import java.nio.charset.StandardCharsets
import java.util.UUID

enum class InterventionKind(val wireName: String) {
    WARN("warn"),
    KICK("kick"),
    ;

    companion object {
        fun fromWire(value: String): InterventionKind = entries.firstOrNull { it.wireName == value }
            ?: throw IllegalArgumentException("不支持的干预类型: $value")
    }
}

enum class InterventionOutcome(val wireName: String) {
    APPLIED("applied"),
    IGNORED_DISABLED("ignored_disabled"),
    IGNORED_COOLDOWN("ignored_cooldown"),
    PLAYER_OFFLINE("player_offline"),
    EXPIRED("expired"),
    INVALID("invalid"),
}

data class PlayerInterventionDirective(
    val directiveId: String,
    val playerUuid: UUID,
    val kind: InterventionKind,
    val reason: String,
    val issuedAtMs: Long,
    val expiresAtMs: Long,
)

data class InterventionReceipt(
    val directiveId: String,
    val playerUuid: UUID,
    val kind: InterventionKind,
    val outcome: InterventionOutcome,
    val handledAtMs: Long,
)

internal object InferenceAckDecoder {
    private const val MAX_DIRECTIVES = 1_000
    private val identifier = Regex("^[A-Za-z0-9][A-Za-z0-9._:-]{0,127}$")
    private val unsignedInteger = Regex("^(0|[1-9][0-9]*)$")

    fun decode(
        body: ByteArray,
        expectedBatchId: UUID? = null,
    ): List<PlayerInterventionDirective> {
        if (body.isEmpty()) return emptyList()
        val root = runCatching {
            val text = StandardCharsets.UTF_8.newDecoder()
                .onMalformedInput(CodingErrorAction.REPORT)
                .onUnmappableCharacter(CodingErrorAction.REPORT)
                .decode(ByteBuffer.wrap(body))
                .toString()
            JsonParser.parseString(text).asJsonObject
        }.getOrElse { throw IllegalArgumentException("推理响应不是合法 JSON 对象", it) }
        val element = root.get("player_interventions") ?: return emptyList()
        require(element.isJsonArray) { "player_interventions 必须是数组" }
        val values = element.asJsonArray
        require(values.size() <= MAX_DIRECTIVES) {
            "单次响应干预指令不得超过 $MAX_DIRECTIVES 条"
        }
        if (values.size() > 0) {
            require(root.optionalString("schema_version") == "shield.events.ack.v2") {
                "干预指令只允许出现在 shield.events.ack.v2 响应"
            }
            if (expectedBatchId != null) {
                val responseBatchId = runCatching {
                    UUID.fromString(root.requiredString("batch_id"))
                }.getOrElse { throw IllegalArgumentException("响应 batch_id 格式无效", it) }
                require(responseBatchId == expectedBatchId) {
                    "推理响应 batch_id 与请求不一致"
                }
            }
        }
        val directives = values.map { value -> decodeDirective(value.asJsonObject) }
        require(directives.map { it.directiveId }.toSet().size == directives.size) {
            "player_interventions 存在重复 directive_id"
        }
        return directives
    }

    private fun decodeDirective(value: JsonObject): PlayerInterventionDirective {
        val directiveId = value.requiredString("directive_id")
        require(identifier.matches(directiveId)) { "directive_id 格式无效" }
        val playerUuid = runCatching { UUID.fromString(value.requiredString("player_uuid")) }
            .getOrElse { throw IllegalArgumentException("player_uuid 格式无效", it) }
        val kind = InterventionKind.fromWire(value.requiredString("kind"))
        val reason = value.requiredString("reason")
        require(reason.length in 1..128) { "reason 长度必须在 1..128" }
        val issuedAtMs = value.requiredLong("issued_at_ms")
        val expiresAtMs = value.requiredLong("expires_at_ms")
        require(issuedAtMs >= 0 && expiresAtMs > issuedAtMs) { "干预指令时间范围无效" }
        return PlayerInterventionDirective(
            directiveId,
            playerUuid,
            kind,
            reason,
            issuedAtMs,
            expiresAtMs,
        )
    }

    private fun JsonObject.requiredString(name: String): String {
        val element = get(name)
        require(element != null && element.isJsonPrimitive && element.asJsonPrimitive.isString) {
            "$name 必须是字符串"
        }
        return element.asString
    }

    private fun JsonObject.optionalString(name: String): String? {
        val element = get(name) ?: return null
        require(element.isJsonPrimitive && element.asJsonPrimitive.isString) {
            "$name 必须是字符串"
        }
        return element.asString
    }

    private fun JsonObject.requiredLong(name: String): Long {
        val element = get(name)
        require(element != null && element.isJsonPrimitive && element.asJsonPrimitive.isNumber) {
            "$name 必须是整数"
        }
        require(unsignedInteger.matches(element.asString)) { "$name 必须是非负十进制整数" }
        return runCatching { element.asLong }
            .getOrElse { throw IllegalArgumentException("$name 必须是整数", it) }
    }
}

```kt
package com.eyreland.shield.inference

import java.lang.reflect.Array as ReflectArray

/** 事件协议使用的小型 JSON 编码器；输入已在捕获解码阶段限制为简单值。 */
object JsonEncoder {
    fun encode(value: Any?): String = buildString { appendValue(value) }

    private fun StringBuilder.appendValue(value: Any?) {
        when (value) {
            null -> append("null")
            is String -> appendQuoted(value)
            is Char -> appendQuoted(value.toString())
            is Boolean -> append(if (value) "true" else "false")
            is Byte, is Short, is Int, is Long -> append(value.toString())
            is Float -> if (value.isFinite()) append(value) else append("null")
            is Double -> if (value.isFinite()) append(value) else append("null")
            is Number -> append(value.toString())
            is Map<*, *> -> appendMap(value)
            is Iterable<*> -> appendIterable(value)
            else -> {
                if (value.javaClass.isArray) appendArray(value) else appendQuoted(value.toString())
            }
        }
    }

    private fun StringBuilder.appendMap(value: Map<*, *>) {
        append('{')
        var first = true
        for ((key, item) in value) {
            if (!first) append(',')
            first = false
            appendQuoted(key.toString())
            append(':')
            appendValue(item)
        }
        append('}')
    }

    private fun StringBuilder.appendIterable(value: Iterable<*>) {
        append('[')
        var first = true
        for (item in value) {
            if (!first) append(',')
            first = false
            appendValue(item)
        }
        append(']')
    }

    private fun StringBuilder.appendArray(value: Any) {
        append('[')
        val length = ReflectArray.getLength(value)
        for (index in 0 until length) {
            if (index > 0) append(',')
            appendValue(ReflectArray.get(value, index))
        }
        append(']')
    }

    private fun StringBuilder.appendQuoted(value: String) {
        append('"')
        for (char in value) {
            when (char) {
                '"' -> append("\\\"")
                '\\' -> append("\\\\")
                '\b' -> append("\\b")
                '\u000C' -> append("\\f")
                '\n' -> append("\\n")
                '\r' -> append("\\r")
                '\t' -> append("\\t")
                else -> if (char.code < 0x20) append("\\u%04x".format(char.code)) else append(char)
            }
        }
        append('"')
    }
}

```kt
package com.eyreland.shield.inference

import com.eyreland.shield.config.InterventionConfig
import io.papermc.paper.dialog.Dialog
import io.papermc.paper.registry.data.dialog.ActionButton
import io.papermc.paper.registry.data.dialog.DialogBase
import io.papermc.paper.registry.data.dialog.action.DialogAction
import io.papermc.paper.registry.data.dialog.body.DialogBody
import io.papermc.paper.registry.data.dialog.type.DialogType
import net.kyori.adventure.text.Component
import net.kyori.adventure.text.event.ClickCallback
import org.bukkit.entity.Player
import org.bukkit.plugin.Plugin
import java.nio.file.Path
import java.time.Clock
import java.time.Duration
import java.util.UUID
import java.util.concurrent.RejectedExecutionException
import java.util.concurrent.ScheduledExecutorService
import java.util.concurrent.TimeUnit
import java.util.concurrent.atomic.AtomicBoolean
import java.util.logging.Level
import java.util.logging.Logger

class PlayerInterventionService(
    private val plugin: Plugin,
    private val config: () -> InterventionConfig,
    ledgerPath: Path,
    private val executor: ScheduledExecutorService,
    private val receiptSink: (InterventionReceipt) -> Boolean,
    private val logger: Logger,
    private val clock: Clock = Clock.systemUTC(),
) {
    private val ledger = InterventionLedger(ledgerPath)
    private val receiptRetryScheduled = AtomicBoolean()

    @Volatile private var started = false

    fun start() {
        started = true
        ledger.recoverInterrupted(clock.millis())
        retryPendingReceipts()
        ledger.pending().forEach(::dispatch)
    }

    fun stop() {
        started = false
    }

    fun acceptResponse(batchId: UUID, body: ByteArray) {
        accept(InferenceAckDecoder.decode(body, batchId))
    }

    fun acknowledgePersistedReceipts(directiveIds: List<String>) {
        directiveIds.forEach(ledger::markReceiptPersisted)
    }

    internal fun accept(directives: List<PlayerInterventionDirective>) {
        for (directive in directives) {
            when (val registration = ledger.register(directive, config(), clock.millis())) {
                LedgerRegistration.AlreadyPending -> Unit
                is LedgerRegistration.Ready -> dispatch(registration.directive)
                is LedgerRegistration.ReceiptOnly -> enqueueReceipt(registration.receipt)
            }
        }
    }

    private fun dispatch(directive: PlayerInterventionDirective) {
        if (!started) return
        if (clock.millis() > directive.expiresAtMs) {
            finish(directive, InterventionOutcome.EXPIRED)
            return
        }
        if (!ledger.markDispatched(directive.directiveId)) return
        runCatching {
            plugin.server.globalRegionScheduler.run(plugin) {
                if (!started) return@run
                val player = plugin.server.getPlayer(directive.playerUuid)
                if (player == null || !player.isOnline) {
                    finish(directive, InterventionOutcome.PLAYER_OFFLINE)
                    return@run
                }
                player.scheduler.run(
                    plugin,
                    { apply(player, directive) },
                    { finish(directive, InterventionOutcome.PLAYER_OFFLINE) },
                ) ?: finish(directive, InterventionOutcome.PLAYER_OFFLINE)
            }
        }.onFailure {
            logger.log(Level.WARNING, "无法调度玩家干预: ${directive.directiveId}", it)
            finish(directive, InterventionOutcome.INVALID)
        }
    }

    private fun apply(player: Player, directive: PlayerInterventionDirective) {
        if (!started) return
        val current = config()
        try {
            val rejection = ledger.pendingRejection(directive, current, clock.millis())
            if (rejection != null) {
                finish(directive, rejection)
                return
            }
            when (directive.kind) {
                InterventionKind.WARN -> showWarningDialog(player, directive, current)
                InterventionKind.KICK -> {
                    player.kick(kickComponent(current))
                    finish(directive, InterventionOutcome.APPLIED)
                }
            }
        } catch (failure: Throwable) {
            logger.log(Level.WARNING, "执行玩家干预失败: ${directive.directiveId}", failure)
            finish(directive, InterventionOutcome.INVALID)
        }
    }

    private fun showWarningDialog(
        player: Player,
        directive: PlayerInterventionDirective,
        current: InterventionConfig,
    ) {
        val nowMs = clock.millis()
        val remainingMs = directive.expiresAtMs - nowMs
        if (remainingMs <= 0) {
            finish(directive, InterventionOutcome.EXPIRED, nowMs)
            return
        }
        val closeAction = DialogAction.customClick(
            { _, _ ->
                val handledAtMs = clock.millis()
                finish(
                    directive,
                    if (handledAtMs <= directive.expiresAtMs) {
                        InterventionOutcome.APPLIED
                    } else {
                        InterventionOutcome.EXPIRED
                    },
                    handledAtMs,
                )
            },
            ClickCallback.Options.builder()
                .uses(1)
                .lifetime(Duration.ofMillis(remainingMs))
                .build(),
        )
        val dialog = Dialog.create { factory ->
            factory.empty()
                .base(
                    DialogBase.builder(warningTitle())
                        .canCloseWithEscape(false)
                        .afterAction(DialogBase.DialogAfterAction.CLOSE)
                        .body(
                            listOf(
                                DialogBody.plainMessage(
                                    Component.text(current.warning.message),
                                ),
                            ),
                        )
                        .build(),
                )
                .type(
                    DialogType.notice(
                        ActionButton.builder(Component.text("关闭"))
                            .action(closeAction)
                            .build(),
                    ),
                )
        }
        executor.schedule(
            { finish(directive, InterventionOutcome.EXPIRED, clock.millis()) },
            remainingMs,
            TimeUnit.MILLISECONDS,
        )
        player.showDialog(dialog)
    }

    private fun finish(
        directive: PlayerInterventionDirective,
        outcome: InterventionOutcome,
        handledAtMs: Long = clock.millis(),
    ) {
        if (!started) return
        runCatching {
            executor.execute {
                if (!started) return@execute
                ledger.complete(directive, outcome, handledAtMs)?.let(::enqueueReceipt)
            }
        }.onFailure {
            logger.log(Level.WARNING, "无法提交玩家干预回执: ${directive.directiveId}", it)
        }
    }

    private fun enqueueReceipt(receipt: InterventionReceipt) {
        if (receiptSink(receipt)) return
        logger.warning("玩家干预回执队列已满, 稍后重试: ${receipt.directiveId}")
        scheduleReceiptRetry()
    }

    private fun retryPendingReceipts() {
        for (receipt in ledger.pendingReceipts()) {
            if (receiptSink(receipt)) continue
            logger.warning("玩家干预回执队列仍满, 稍后重试: ${receipt.directiveId}")
            scheduleReceiptRetry()
            return
        }
    }

    private fun scheduleReceiptRetry() {
        if (!started || !receiptRetryScheduled.compareAndSet(false, true)) return
        try {
            executor.schedule(
                {
                    receiptRetryScheduled.set(false)
                    if (started) retryPendingReceipts()
                },
                1,
                TimeUnit.SECONDS,
            )
        } catch (rejected: RejectedExecutionException) {
            receiptRetryScheduled.set(false)
            if (started) logger.log(Level.WARNING, "无法调度玩家干预回执重试", rejected)
        }
    }

    internal companion object {
        fun warningTitle(): Component = Component.text("行为提示")

        fun kickComponent(config: InterventionConfig): Component = Component.text(config.kick.message)
    }
}

        afk.onMovement(uuid, 0.0, 64.0, 0.0, 0f, 0f, 0)

        assertFalse(afk.isAfk(uuid, 118_000))
        assertTrue(afk.isAfk(uuid, 119_001))

        afk.onMovement(uuid, 0.01, 64.0, 0.005, 0f, 0f, 30_000)

                "hasPermission" -> allowed()
                "sendMessage" -> { messages += args[0] as String; null }
                else -> error("Unexpected sender call: ${method.name}")
            }
        } as CommandSender

        val now = 1_900_000_000_000
        val kick = directive("kick-first", now, InterventionKind.KICK)

    @Test

            set("interventions.kick.enabled", true)
        })
        val now = 1_900_000_000_000
        val ledger = InterventionLedger(temporaryDirectory.resolve("kick-ready.properties"))

        ledger.complete(warning, InterventionOutcome.APPLIED, now)

        assertIs<LedgerRegistration.Ready>(ledger.register(kick, config, now + 1))
        ledger.complete(kick, InterventionOutcome.APPLIED, now + 2)

    @Test

        val task = proxy<ScheduledTask> { name, _ -> error("Unexpected task call: $name") }
        var retiredCallback: Runnable? = null
        val entityScheduler = proxy<EntityScheduler> { name, args ->
            check(name == "run")
            if (alreadyRetired) null else {
                retiredCallback = args[2] as Runnable
                task
            }
        }
        val globalScheduler = proxy<GlobalRegionScheduler> { name, args ->
            check(name == "run")
            @Suppress("UNCHECKED_CAST")
            callbacks.addLast(args[1] as Consumer<ScheduledTask>)
            task
        }
        val player = proxy<Player> { name, _ ->
            when (name) {
                "isOnline" -> true
                "getScheduler" -> entityScheduler
                else -> error("Unexpected player call: $name")
            }
        }
        val server = proxy<Server> { name, _ ->
            when (name) {
                "getGlobalRegionScheduler" -> globalScheduler
                "getPlayer" -> player
                else -> error("Unexpected server call: $name")

            server

            executor.submit {}.get(5, TimeUnit.SECONDS)

            assertEquals(listOf(InterventionOutcome.PLAYER_OFFLINE), receipts.map { it.outcome })
            val persisted = InterventionLedger(ledgerPath)
            assertEquals(emptyList(), persisted.pending())
            assertEquals(receipts.toList(), persisted.pendingReceipts())
            service.accept(listOf(directive))
            assertEquals(0, callbacks.size)

            executor.shutdownNow()

    @Test
    fun `queued actions use new policy while warnings cooldown and receipt dedupe survive reload`() {
        val file = temporaryDirectory.resolve("config.yml").toFile()
        fun writePolicy(enabled: Boolean, minimumWarnings: Int = 1) {
            file.writeText("""
                server-key: shd_00000000-0000-0000-0000-000000000001.${"a".repeat(64)}
                interventions:
                  kick:
                    enabled: $enabled
                    minimum-prior-warnings: $minimumWarnings
                    message: "重载后的踢出提示"
            """.trimIndent())
        }
        writePolicy(true)
        val config = ReloadableConfig(file)
        val now = 1_900_000_000_000L
        val playerId = UUID.fromString("00000000-0000-0000-0000-000000000010")
        fun kick(id: String) = PlayerInterventionDirective(id, playerId, InterventionKind.KICK, "test", now, now + 60_000)
        val ledgerPath = temporaryDirectory.resolve("ledger.properties")
        InterventionLedger(ledgerPath).apply {
            val warning = kick("warning").copy(kind = InterventionKind.WARN)
            complete(warning, InterventionOutcome.APPLIED, now - 1_000)
            markReceiptPersisted(warning.directiveId)
        }

        val callbacks = ArrayDeque<Consumer<ScheduledTask>>()
        val kicks = mutableListOf<Component>()
        val task = proxy<ScheduledTask> { name, _ -> error("Unexpected task call: $name") }
        fun schedule(name: String, args: Array<out Any?>): Any {
            check(name == "run")
            @Suppress("UNCHECKED_CAST")
            callbacks.addLast(args[1] as Consumer<ScheduledTask>)
            return task
        }
        val entityScheduler = proxy<EntityScheduler>(::schedule)
        val globalScheduler = proxy<GlobalRegionScheduler>(::schedule)
        val player = proxy<Player> { name, args ->
            when (name) {
                "isOnline" -> true
                "getScheduler" -> entityScheduler
                "kick" -> { kicks += args[0] as Component; null }
                else -> error("Unexpected player call: $name")
            }
        }
        val server = proxy<Server> { name, _ ->
            when (name) {
                "getGlobalRegionScheduler" -> globalScheduler
                "getPlayer" -> player
                else -> error("Unexpected server call: $name")
            }
        }
        val plugin = proxy<Plugin> { name, _ ->
            check(name == "getServer")
            server
        }
        val receipts = CopyOnWriteArrayList<InterventionReceipt>()
        val executor = Executors.newSingleThreadScheduledExecutor()
        val service = PlayerInterventionService(
            plugin, { config.current.interventions }, ledgerPath, executor,
            { receipts += it; true }, Logger.getAnonymousLogger(),
            Clock.fixed(Instant.ofEpochMilli(now), ZoneOffset.UTC),
        )
        fun drainReceipts() = executor.submit {}.get(5, TimeUnit.SECONDS)
        try {
            service.start()
            service.accept(listOf(kick("disabled-after-dispatch")))
            callbacks.removeFirst().accept(task)
            writePolicy(false)
            config.reload()
            callbacks.removeFirst().accept(task)
            drainReceipts()
            assertEquals(InterventionOutcome.IGNORED_DISABLED, receipts.last().outcome)
            assertEquals(0, kicks.size)

            writePolicy(true, minimumWarnings = 2)
            config.reload()
            service.accept(listOf(kick("two-warnings-required")))
            assertEquals(InterventionOutcome.IGNORED_COOLDOWN, receipts.last().outcome)
            assertEquals(0, callbacks.size)

            writePolicy(true)
            config.reload()
            val accepted = kick("accepted")
            service.accept(listOf(accepted))
            callbacks.removeFirst().accept(task)
            callbacks.removeFirst().accept(task)
            drainReceipts()
            assertEquals(InterventionOutcome.APPLIED, receipts.last().outcome)
            assertEquals(listOf(PlayerInterventionService.kickComponent(config.current.interventions)), kicks)

            config.reload()
            service.accept(listOf(accepted, kick("cooldown")))
            assertEquals(listOf(InterventionOutcome.APPLIED, InterventionOutcome.IGNORED_COOLDOWN), receipts.takeLast(2).map { it.outcome })
            assertEquals(1, kicks.size)

        } finally {
            service.stop()
            executor.shutdownNow()
        }
    }

    private inline fun <reified T> proxy(crossinline call: (String, Array<out Any?>) -> Any?): T =
