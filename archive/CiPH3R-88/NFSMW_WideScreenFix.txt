`README.md`:

```md
# NFSMW WideScreen Fix

A lightweight, modern widescreen plugin for **Need for Speed: Most Wanted (2005) v1.3**, built from the ground up with clean C++ and reverse engineering in IDA Pro.

---

## Features

### 🖥️ Display & Resolution
* **In-Game Resolution Picker:** Dynamically enumerates all monitor display modes directly into the in-game Video Options menu with seamless runtime switching.
* **Windowed & Borderless Modes:** Supports Fullscreen, Borderless, Bordered, Resizable, and Borderless Fullscreen Stretched modes.

### 🎯 FOV & HUD
* **Hor+ Camera FOV:** Automatically calculates and applies correct field of view for any aspect ratio.
* **Aspect-Correct HUD:** Fixes HUD stretching and moves HUD elements to widescreen screen edges.

### 🎬 Movies & FMVs
* **Widescreen FMV Scaling:** Options to zoom/fill 16:9 or maintain aspect ratio with clean pillarboxing.
* **Full-Color Range Videos:** Custom YUV lookup table expansion restores deep blacks and full color vibrancy (0–255) instead of washed-out limited range (16–235).

### 🔊 Audio
* **High-Spec Audio:** Forces the audio mixer to run at full CD quality (44,100 Hz) by default, bypassing 22,050 Hz low-spec fallbacks.

### 🏎️ Graphics & Visuals
* **Dynamic Shadows:** Customizable shadow map resolution (up to 16384), auto-scaling based on aspect ratio, increased shadow LOD detail, and tunnel/bridge disappearance fix.
* **NOS Trail:** Option to toggle NOS trails on/off or fine-tune trail length and origin offsets.
* **Motion Blur:** In-game motion blur toggle.

### ⚙️ Physics & Miscellaneous
* **High-Precision SimRate:** Decoupled 200 Hz physics simulation ticker for high refresh rate monitors.
* **Skip Intro:** Bypasses startup logos and intro movies.
* **Windows Cursor Toggle:** Optional hardware Windows OS cursor in menus without software cursor latency or stretching.
* **Portable Saves & Registry:** Redirects game settings from Windows Registry into a local file and supports custom save game folders.
* **Mod Compatibility:** Works out of the box with **X360Stuff** and **Sunset Mod** with automatic conflict resolution.

---

## Installation

1. Copy `NFSMW_WideScreenFix.asi` and `NFSMW_WideScreenFix.ini` into your game's `scripts/` folder (requires an ASI Loader like `dinput8.dll`).
2. Configure settings inside `NFSMW_WideScreenFix.ini` to your preference.

---

## Configuration Overview

| Section | Key Settings |
| :--- | :--- |
| `[DISPLAY]` | `ResX`, `ResY`, `WindowMode` (0 = Fullscreen, 1 = Borderless, etc.) |
| `[HUD]` | `FixHUD`, `WideScreenHUD`, `WS_MWSPLASHBACK` |
| `[MOVIES]` | `WideScreenMovie` (1 = Fill 16:9, 2 = Aspect Correct) |
| `[GRAPHICS]`| `MotionBlur`, `ConsoleGamma` |
| `[SHADOW]` | `ShadowsRes`, `ShadowsFix`, `ImproveShadowLOD`, `AutoScaleShadowsRes`, `ShadowMapTextureFormat` |
| `[MISC]` | `SkipIntro`, `SimRate`, `WriteSettingsToFile`, `CustomUserFilesDirectoryInGameDir`, `Win Cursor` |
| `[NOS TRAIL]`| `NosTrail`, `NOSTrailLength`, `NOSTrailPositionScalar` |
```

```h
#pragma once
#ifndef NFSMW_WIDESCREENFIX_CAMERAFOV_H
#define NFSMW_WIDESCREENFIX_CAMERAFOV_H

#include "MemoryTools.h"
#include "Resolution.h"
#include "Config.h"

namespace CameraFOV {
    // Engine Viewport IDs from eView::BuildProjectionMatrix (sub_6CF400)
    enum eViewID : uint32_t {
        VIEW_MAIN = 1,
        VIEW_SECONDARY = 2,
        VIEW_REARVIEW_MIRROR = 3,
        VIEW_REFLECTION = 4,
        VIEW_PIP = 5
    };

    inline float s_Hor3DScale = 1.0f;
    inline float s_Ver3DScale = 1.0f;
    inline float s_MirrorScale = 0.40f;

    // Direct operand overrides for eView::BuildProjectionMatrix (0x006CF400)
    inline float s_HorProjectionScale = 1.0f;    // Replaces operand at 0x006CF568 (vanilla 1.0f)
    inline float s_FovAngleMultiplier = 0.423f;   // Replaces operand at 0x006CF57A (vanilla 0.5f)
    inline float s_VerProjectionDivisor = 1.0f;  // Replaces operand at 0x006CF5DE (vanilla 1.0f)

    // Shadow frustum culling multiplier in sub_6C9570 (vanilla 1.1f at 0x006C9655)
    inline float s_ShadowDistanceMultiplier = 10.0f;

    inline const uintptr_t RET_006CF4F6 = 0x006CF4F6;
    inline const uintptr_t RET_006E465A = 0x006E465A;
    inline const uintptr_t RET_006E47EC = 0x006E47EC;

    inline void __cdecl ComputeProjectionScales(uint32_t viewID) {
        float aspect = Resolution::g_CurrentAspectRatio;
        if (aspect <= 0.0f) {
            aspect = 4.0f / 3.0f;
        }

        s_Ver3DScale = 1.0f;
        // Direct3D squash correction: preserves 1:1 pixel aspect ratio while maintaining vertical framing
        s_Hor3DScale = 1.273f / aspect;

        if (viewID == VIEW_MAIN || viewID == VIEW_REFLECTION) {
            s_HorProjectionScale = s_Hor3DScale;
            s_FovAngleMultiplier = 0.423f;
            s_VerProjectionDivisor = 1.0f;
        }
        else {
            s_HorProjectionScale = 1.0f;
            s_FovAngleMultiplier = 0.5f;
            s_VerProjectionDivisor = 1.0f;
        }
    }

    __declspec(naked) inline void Hook_BuildProjectionMatrix() {
        __asm {
            push ecx
            push edx
            push ecx
            call ComputeProjectionScales
            add esp, 4
            pop edx
            pop ecx

            mov eax, dword ptr[edi + 0x60] // eView->ViewportParams

            cmp ecx, VIEW_REARVIEW_MIRROR
            je lbl_mirror
            fld dword ptr[s_Ver3DScale]
            jmp lbl_ret

            lbl_mirror :
            fld dword ptr[s_MirrorScale]

                lbl_ret :
                jmp dword ptr[RET_006CF4F6]
        }
    }

    __declspec(naked) inline void Hook_ShadowCameraMatrix1() {
        __asm {
            fld dword ptr[s_Ver3DScale]
            jmp dword ptr[RET_006E465A]
        }
    }

    __declspec(naked) inline void Hook_ShadowCameraMatrix2() {
        __asm {
            mov dword ptr[esp + 0x14], ecx
            fld dword ptr[s_Ver3DScale]
            jmp dword ptr[RET_006E47EC]
        }
    }

    inline void UpdateFOVScale(int width, int height) {
        float aspect = static_cast<float>(width) / static_cast<float>(height);
        if (aspect <= 0.0f) {
            aspect = 4.0f / 3.0f;
        }
        constexpr float baseAspect = 4.0f / 3.0f;

        s_Hor3DScale = 1.273f / aspect;

        // 1. eViewPlatInterface canvas virtual width (vanilla 640.0f): flt_8AE8F8
        MemoryTools::Write<float>(0x008AE8F8, 480.0f * aspect);

        // 2. FacePixelation UV scale X in arrest cutscenes (vanilla 1.0/640.0f): flt_8AFA08
        MemoryTools::Write<float>(0x008AFA08, (1.0f / 640.0f) * (baseAspect / aspect));
    }

    inline void Init(bool fixFOV = true) {
        if (!fixFOV) return;

        UpdateFOVScale(Resolution::g_CurrentWidth, Resolution::g_CurrentHeight);
        Resolution::RegisterOnResChange(UpdateFOVScale);

        // Hook eView::BuildProjectionMatrix in sub_6CF400 (5 bytes JMP + 7 NOPs)
        MemoryTools::MakeJMP(0x006CF4EA, reinterpret_cast<uintptr_t>(Hook_BuildProjectionMatrix), 7);

        // Redirect projection matrix scaling float operands
        MemoryTools::Write<float*>(0x006CF568, &s_HorProjectionScale);
        MemoryTools::Write<float*>(0x006CF57A, &s_FovAngleMultiplier);
        MemoryTools::Write<float*>(0x006CF5DE, &s_VerProjectionDivisor);

        // ShadowMap frustum culling distance in sub_6C9570 (vanilla 1.1f at 0x006C9655)
        MemoryTools::Write<float*>(0x006C9655, &s_ShadowDistanceMultiplier);

        // ShadowMap::BuildCameraMatrix hooks (sub_6E44C0)
        MemoryTools::MakeJMP(0x006E4652, reinterpret_cast<uintptr_t>(Hook_ShadowCameraMatrix1), 3);
        MemoryTools::MakeNOP(0x006E4668, 4);

        MemoryTools::MakeJMP(0x006E47E4, reinterpret_cast<uintptr_t>(Hook_ShadowCameraMatrix2), 3);
        MemoryTools::MakeNOP(0x006E47EC, 4);

        // ShadowMap camera horizontal FOV scaling
        MemoryTools::Write<float*>(0x006E46B2, &s_Hor3DScale);
        MemoryTools::Write<float*>(0x006E4832, &s_Hor3DScale);
    }
}

#endif // NFSMW_WIDESCREENFIX_CAMERAFOV_H
```

```h
#pragma once
#ifndef NFSMW_WIDESCREENFIX_CONFIG_H
#define NFSMW_WIDESCREENFIX_CONFIG_H

#include <windows.h>
#include <string>
#include <filesystem>

struct Settings {
    // DISPLAY
    int ResX = 0;
    int ResY = 0;
    int WindowMode = 0; // 0 = Fullscreen | 1 = Borderless | 2 = Border | 3 = Resizable Border | 4 = Borderless Fullscreen | 5 = Borderless Fullscreen Stretched

    // GRAPHICS
    int MotionBlur = 1; // 0 = Off, 1 = On

    // HUD
    int FixHUD = 1;
    int WideScreenHUD = 0;
    int WS_MWSPLASHBACK = 0;
    bool X360StuffInstalled = false;
    bool SunSetInstalled = false;

    // MOVIES
    int WideScreenMovie = 1; // 0 = Off, 1 = Zoom/Fill 16:9, 2 = Fit with Pillarboxes

    // SHADOW
    int ShadowsRes = 2048;
    int ShadowsFix = 1;
    int ImproveShadowLOD = 1;
    int AutoScaleShadowsRes = 1;
    int ShadowMapTextureFormat = 0;
    int ForceSharpShadows = 0;

    // NOSTRAIL
    int NosTrail = 1;
    float NOSTrailLength = 0.0f;
    float NOSTrailPositionScalar = 0.0f;

    // MISC
    int SkipIntro = 0;
    int SimRate = 0; // 0 = Off, 1 = On (200 Hz Decoupled Physics)
    int WriteSettingsToFile = 0;
    int WinCursor = 0; // 0 = Off (default, block Windows cursor), 1 = On (allow Windows cursor)
    std::string CustomUserFilesDirectoryInGameDir = "";

    std::filesystem::path IniPath;
    std::filesystem::path GamePath;

    void Load() {
        char exePath[MAX_PATH] = { 0 };
        GetModuleFileNameA(NULL, exePath, MAX_PATH);
        GamePath = std::filesystem::path(exePath).parent_path();
        IniPath = GamePath / "scripts" / "NFSMW_WideScreenFix.ini";
        if (!std::filesystem::exists(IniPath)) {
            IniPath = GamePath / "NFSMW_WideScreenFix.ini";
        }

        std::string iniStr = IniPath.string();

        ResX = GetPrivateProfileIntA("DISPLAY", "ResX", 0, iniStr.c_str());
        ResY = GetPrivateProfileIntA("DISPLAY", "ResY", 0, iniStr.c_str());
        WindowMode = GetPrivateProfileIntA("DISPLAY", "WindowMode", -1, iniStr.c_str());
        if (WindowMode == -1) {
            WindowMode = GetPrivateProfileIntA("MISC", "WindowedMode", -1, iniStr.c_str());
            if (WindowMode == -1) {
                WindowMode = GetPrivateProfileIntA("DISPLAY", "Windowed", 0, iniStr.c_str());
            }
        }

        MotionBlur = GetPrivateProfileIntA("GRAPHICS", "MotionBlur", 1, iniStr.c_str());
        FixHUD = GetPrivateProfileIntA("HUD", "FixHUD", 1, iniStr.c_str());
        WideScreenHUD = GetPrivateProfileIntA("HUD", "WideScreenHUD", 0, iniStr.c_str());
        WS_MWSPLASHBACK = GetPrivateProfileIntA("HUD", "WS_MWSPLASHBACK", 0, iniStr.c_str());

        WideScreenMovie = GetPrivateProfileIntA("MOVIES", "WideScreenMovie", 1, iniStr.c_str());

        // SHADOW
        ShadowsRes = GetPrivateProfileIntA("SHADOW", "ShadowsRes", 2048, iniStr.c_str());
        ShadowsFix = GetPrivateProfileIntA("SHADOW", "ShadowsFix", 1, iniStr.c_str());
        ImproveShadowLOD = GetPrivateProfileIntA("SHADOW", "ImproveShadowLOD", 1, iniStr.c_str());
        AutoScaleShadowsRes = GetPrivateProfileIntA("SHADOW", "AutoScaleShadowsRes", 1, iniStr.c_str());
        ShadowMapTextureFormat = GetPrivateProfileIntA("SHADOW", "ShadowMapTextureFormat", 0, iniStr.c_str());
        ForceSharpShadows = GetPrivateProfileIntA("SHADOW", "ForceSharpShadows", 0, iniStr.c_str());

        // NOSTRAIL (support both [NOSTRAIL] and [NOS TRAIL])
        NosTrail = GetPrivateProfileIntA("NOSTRAIL", "NosTrail", -1, iniStr.c_str());
        if (NosTrail == -1) NosTrail = GetPrivateProfileIntA("NOS TRAIL", "NosTrail", 1, iniStr.c_str());

        char nosLenBuf[64] = { 0 };
        GetPrivateProfileStringA("NOSTRAIL", "NOSTrailLength", "", nosLenBuf, sizeof(nosLenBuf), iniStr.c_str());
        if (!nosLenBuf[0]) GetPrivateProfileStringA("NOS TRAIL", "NOSTrailLength", "0", nosLenBuf, sizeof(nosLenBuf), iniStr.c_str());
        NOSTrailLength = static_cast<float>(atof(nosLenBuf));
        if (NOSTrailLength < 0.0f) NOSTrailLength = 0.0f;

        char nosPosBuf[64] = { 0 };
        GetPrivateProfileStringA("NOSTRAIL", "NOSTrailPositionScalar", "", nosPosBuf, sizeof(nosPosBuf), iniStr.c_str());
        if (!nosPosBuf[0]) GetPrivateProfileStringA("NOS TRAIL", "NOSTrailPositionScalar", "0.0", nosPosBuf, sizeof(nosPosBuf), iniStr.c_str());
        NOSTrailPositionScalar = static_cast<float>(atof(nosPosBuf));
        if (NOSTrailPositionScalar < 0.0f) NOSTrailPositionScalar = 0.0f;

        // Toru's X360Stuff applies HUD aspect correction, widescreen placement,
        // and entirely replaces the shadow map rendering pipeline.
        X360StuffInstalled = std::filesystem::exists(GamePath / "scripts" / "X360Stuff.asi");

        // Sunset mod provides its own in-game Motion Blur video option and custom particle shaders.
        SunSetInstalled = std::filesystem::exists(GamePath / "scripts" / "SunSet.asi");

        SkipIntro = GetPrivateProfileIntA("MISC", "SkipIntro", 0, iniStr.c_str());
        SimRate = GetPrivateProfileIntA("MISC", "SimRate", 0, iniStr.c_str());
        WriteSettingsToFile = GetPrivateProfileIntA("MISC", "WriteSettingsToFile", 0, iniStr.c_str());
        WinCursor = GetPrivateProfileIntA("MISC", "WinCursor", 0, iniStr.c_str());
        if (!WinCursor) {
            WinCursor = GetPrivateProfileIntA("MISC", "Win Cursor", 0, iniStr.c_str());
        }

        char userDirBuf[MAX_PATH] = { 0 };
        GetPrivateProfileStringA("MISC", "CustomUserFilesDirectoryInGameDir", "0", userDirBuf, MAX_PATH, iniStr.c_str());
        std::string userDir = userDirBuf;
        auto semi = userDir.find(';');
        if (semi != std::string::npos) userDir = userDir.substr(0, semi);
        auto hash = userDir.find('#');
        if (hash != std::string::npos) userDir = userDir.substr(0, hash);
        while (!userDir.empty() && (userDir.back() == ' ' || userDir.back() == '\t' || userDir.back() == '\r' || userDir.back() == '\n')) {
            userDir.pop_back();
        }
        while (!userDir.empty() && (userDir.front() == ' ' || userDir.front() == '\t')) {
            userDir.erase(userDir.begin());
        }
        if (userDir == "0") {
            userDir.clear();
        }
        CustomUserFilesDirectoryInGameDir = userDir;
    }
};

inline Settings g_Config;

#endif // NFSMW_WIDESCREENFIX_CONFIG_H
```

```h
#pragma once
#ifndef NFSMW_WIDESCREENFIX_HIGHSPECAUDIO_H
#define NFSMW_WIDESCREENFIX_HIGHSPECAUDIO_H

#include <cstdint>
#include "MemoryTools.h"

namespace HighSpecAudio {
    // Verified from IDA: sub_4C40C0 (Audio system initialization)
    // In vanilla speed.exe, Low/Medium PerformanceLevel checks fall through to 0x004C41EF:
    //   mov dword ptr [g_PC_SampleRate], 22050  (bytes: C7 05 50 E6 8E 00 22 56 00 00)
    // Overwriting the immediate operand at 0x004C41F5 from 22050 (0x00005622) to 44100 (0x0000AC44)
    // forces the audio mixer to run at full CD quality (44.1 kHz) by default.
    constexpr uintptr_t ADDR_SAMPLE_RATE_FALLBACK = 0x004C41F5;
    constexpr uint32_t HIGH_SPEC_SAMPLE_RATE      = 44100;

    inline void Init() {
        MemoryTools::Write<uint32_t>(ADDR_SAMPLE_RATE_FALLBACK, HIGH_SPEC_SAMPLE_RATE);
    }
}

#endif // NFSMW_WIDESCREENFIX_HIGHSPECAUDIO_H
```

```h
#pragma once
#ifndef NFSMW_WIDESCREENFIX_HUDFIX_H
#define NFSMW_WIDESCREENFIX_HUDFIX_H

#include "MemoryTools.h"
#include "Resolution.h"
#include "Config.h"
#include <cmath>
#include <unordered_map>

namespace HudFix {
    inline float s_HudMatrixScaleX = 1.0f;
    inline float s_HudScaleX = 0.003125f; // flt_8AF9A4 (vanilla: 2.0f / 640.0f)
    inline float s_FEHudPosX = 320.0f;    // flt_894B40 (vanilla: 320.0f)

    // Verified from IDA: SplashScreen::SplashScreen (0x005A3030) and package string at 0x008A0114
    inline void InitWideScreenSplash(bool enabled) {
        if (!enabled) return;

        // 1. NOP the jz short loc_5A30A2 at 0x005A3080 in SplashScreen::SplashScreen
        MemoryTools::MakeNOP(0x005A3080, 2);

        // 2. Overwrite the package name in .rdata at 0x008A0114
        constexpr char kwsSplashName[] = "WS_MW_LS_Splash.fng";
        MemoryTools::WriteBytes(0x008A0114, kwsSplashName, sizeof(kwsSplashName));

        // 3. Set prompt text hash to "CLICK to continue" (PC) at 0x005A313D
        MemoryTools::Write<uint32_t>(0x005A313D, 0xC4DF3FF2);

        // 4. Force GetSplashScreenPackageName() to return widescreen splash
        MemoryTools::Write<uint8_t>(0x005705EC, 0xEB);
    }

    inline bool s_WideScreenHUD = false;
    inline float s_WideScreenHUDOffset = 0.0f;

    namespace WideScreenHUD {
        // Native FEng Engine API functions in speed.exe
        using FEngFindObjectFn = void*(__cdecl*)(const char* packageName, unsigned int objectHash);
        using FEngGetCenterFn  = void(__cdecl*)(void* object, float* outX, float* outY);
        using FEngSetCenterFn  = void(__cdecl*)(void* object, float x, float y);
        using QueuePackageMessageFn = void(__fastcall*)(void* instance, void* edx, int messageHash, const char* packageName, int a4);
        using SetWideScreenModeFn   = char(__thiscall*)(void* instance);

        inline const auto FEngFindObject = reinterpret_cast<FEngFindObjectFn>(0x00524850);
        inline const auto FEngGetCenter  = reinterpret_cast<FEngGetCenterFn>(0x00524EE0);
        inline const auto FEngSetCenter  = reinterpret_cast<FEngSetCenterFn>(0x00525050);

        inline QueuePackageMessageFn s_OriginalQueuePackageMessage = nullptr;
        inline SetWideScreenModeFn   s_OriginalSetWideScreenMode   = nullptr;

        inline std::unordered_map<void*, std::pair<float, float>> s_OriginalCenters;

        struct MinimapOriginalPositions {
            float localX;
            float childX[5];
        };
        inline std::unordered_map<void*, MinimapOriginalPositions> s_MinimapOriginalPositions;
        inline bool s_Installed = false;

        // Moves FEng HUD groups to the widescreen screen borders
        inline void ApplyGroupOffset(const char* packageName) {
            if (!packageName) return;

            constexpr unsigned int LEFT_GROUP  = 0x1603009E; // Minimap group
            constexpr unsigned int RIGHT_GROUP = 0x5D0101F1; // Tachometer / Speedometer group

            void* left  = FEngFindObject(packageName, LEFT_GROUP);
            void* right = FEngFindObject(packageName, RIGHT_GROUP);

            auto move = [](void* object, float delta) {
                if (!object) return;
                auto it = s_OriginalCenters.find(object);
                if (it == s_OriginalCenters.end()) {
                    float x = 0.0f, y = 0.0f;
                    FEngGetCenter(object, &x, &y);
                    it = s_OriginalCenters.emplace(object, std::make_pair(x, y)).first;
                }
                FEngSetCenter(object, it->second.first + delta, it->second.second);
            };

            move(left, -s_WideScreenHUDOffset);
            move(right, s_WideScreenHUDOffset);
        }

        inline void __fastcall QueuePackageMessageHook(void* instance, void* edx,
            int messageHash, const char* packageName, int a4) {
            if (s_OriginalQueuePackageMessage) {
                s_OriginalQueuePackageMessage(instance, edx, messageHash, packageName, a4);
            }
            ApplyGroupOffset(packageName);
        }

        inline char __fastcall SetWideScreenModeHook(void* instance, void* edx) {
            char result = s_OriginalSetWideScreenMode ? s_OriginalSetWideScreenMode(instance) : 0;
            return result;
        }

        // Native Minimap::AdjustForWidescreen (0x005678A0) dynamic displacement
        inline int __fastcall AdjustMinimapForWidescreen(
            void* minimap, void* edx, char isWidescreen) {
            if (!minimap) return 0;

            const float offset = isWidescreen ? -s_WideScreenHUDOffset : s_WideScreenHUDOffset;

            if (!s_MinimapOriginalPositions.empty() &&
                s_MinimapOriginalPositions.begin()->first != minimap) {
                s_MinimapOriginalPositions.clear();
            }

            MemoryTools::Write<float>(0x0091CF04, isWidescreen ? -s_WideScreenHUDOffset : 0.0f);
            MemoryTools::Write<float>(0x0091CF0C, isWidescreen ? -0.9375f : 0.9375f);

            constexpr int childOffsets[5] = { 60, 64, 68, 72, 144 };
            auto it = s_MinimapOriginalPositions.find(minimap);
            if (it == s_MinimapOriginalPositions.end()) {
                MinimapOriginalPositions original{};
                original.localX = *reinterpret_cast<float*>(
                    reinterpret_cast<uint8_t*>(minimap) + 184);

                for (int i = 0; i < 5; ++i) {
                    void* child = *reinterpret_cast<void**>(
                        reinterpret_cast<uint8_t*>(minimap) + childOffsets[i]);
                    if (!child) return 0;
                    void* data = *reinterpret_cast<void**>(
                        reinterpret_cast<uint8_t*>(child) + 44);
                    if (!data) return 0;
                    original.childX[i] = *reinterpret_cast<float*>(
                        reinterpret_cast<uint8_t*>(data) + 28);
                }
                it = s_MinimapOriginalPositions.emplace(minimap, original).first;
            }

            const auto& original = it->second;
            MemoryTools::Write<float>(
                reinterpret_cast<uintptr_t>(minimap) + 184,
                original.localX + offset);

            for (int i = 0; i < 5; ++i) {
                void* child = *reinterpret_cast<void**>(
                    reinterpret_cast<uint8_t*>(minimap) + childOffsets[i]);
                if (!child) continue;
                void* data = *reinterpret_cast<void**>(
                    reinterpret_cast<uint8_t*>(child) + 44);
                if (!data) continue;
                MemoryTools::Write<float>(
                    reinterpret_cast<uintptr_t>(data) + 28,
                    original.childX[i] + offset);
            }

            void* lastChild = *reinterpret_cast<void**>(
                reinterpret_cast<uint8_t*>(minimap) + 144);
            if (lastChild) {
```

```h
    inline uintptr_t PatternScan(const char* patternStr, size_t matchIndex = 0, uintptr_t base = 0x00400000, size_t size = 0x500000) {
        std::vector<uint8_t> bytes;
        std::vector<bool> mask;

        const char* p = patternStr;
        while (*p) {
            while (*p == ' ') p++;
            if (!*p) break;
            if (*p == '?') {
                bytes.push_back(0);
                mask.push_back(false);
                p++;
                if (*p == '?') p++;
            } else {
                char byteStr[3] = { p[0], p[1], 0 };
                bytes.push_back(static_cast<uint8_t>(strtoul(byteStr, nullptr, 16)));
                mask.push_back(true);
                p += 2;
            }
        }

        if (bytes.empty()) return 0;

        uint8_t* pStart = reinterpret_cast<uint8_t*>(base);
        size_t currentMatch = 0;
        for (size_t i = 0; i <= size - bytes.size(); ++i) {
            bool match = true;
            for (size_t j = 0; j < bytes.size(); ++j) {
                if (mask[j] && pStart[i + j] != bytes[j]) {
                    match = false;
                    break;
                }
            }
            if (match) {
                if (currentMatch == matchIndex) {
                    return reinterpret_cast<uintptr_t>(pStart + i);
                }
                currentMatch++;
            }
        }
        return 0;
    }
    inline bool Unprotect(uintptr_t address, size_t size, DWORD& oldProtect) {
        return VirtualProtect(reinterpret_cast<void*>(address), size, PAGE_EXECUTE_READWRITE, &oldProtect) != FALSE;
    }

    inline void RestoreProtect(uintptr_t address, size_t size, DWORD oldProtect) {
        DWORD temp;
        VirtualProtect(reinterpret_cast<void*>(address), size, oldProtect, &temp);
    }

    inline void Write(uintptr_t address, const T& value) {
        DWORD oldProtect;

        *reinterpret_cast<T*>(address) = value;
        RestoreProtect(address, sizeof(T), oldProtect);
    }

    inline void MakeNOP(uintptr_t address, size_t count = 1) {
        DWORD oldProtect;
        Unprotect(address, count, oldProtect);
        std::memset(reinterpret_cast<void*>(address), 0x90, count);
        RestoreProtect(address, count, oldProtect);
    }

    inline void MakeCALL(uintptr_t from, uintptr_t to, size_t nops = 0) {
        DWORD oldProtect;
        size_t total = 5 + nops;
        Unprotect(from, total, oldProtect);
        *reinterpret_cast<uint8_t*>(from) = 0xE8; // CALL rel32
        *reinterpret_cast<int32_t*>(from + 1) = static_cast<int32_t>(to - (from + 5));
        if (nops > 0) {
            std::memset(reinterpret_cast<void*>(from + 5), 0x90, nops);
        }
        RestoreProtect(from, total, oldProtect);
    }

    inline void MakeJMP(uintptr_t from, uintptr_t to, size_t nops = 0) {

    }
```

```h
    // Full color range (0-255) LUT calculation from Toru
    struct RgbMap {
        uint16_t R;
        uint16_t G;
        uint16_t B;
        uint16_t A;
    };

    inline void MoviePlayerCalcYuvLut(uintptr_t Y, uintptr_t U, uintptr_t V) {
        auto* y_table = reinterpret_cast<RgbMap*>(Y);
        auto* u_table = reinterpret_cast<RgbMap*>(U);
        auto* v_table = reinterpret_cast<RgbMap*>(V);

        for (int i = 0; i < 256; i++) {
            y_table[i].R = (std::min)(static_cast<uint16_t>((std::max)(i - 16, 0) * (255.0 / 219.0)), static_cast<uint16_t>(255));
            y_table[i].G = (std::min)(static_cast<uint16_t>((std::max)(i - 16, 0) * (255.0 / 219.0)), static_cast<uint16_t>(255));
            y_table[i].B = (std::min)(static_cast<uint16_t>((std::max)(i - 16, 0) * (255.0 / 219.0)), static_cast<uint16_t>(255));
            y_table[i].A = 0xFF;

            u_table[i].R = static_cast<uint16_t>(((i / 255.0) - 0.5) * (+1.7720 * (255.0 / 224.0)) * 255.0);
            u_table[i].G = static_cast<uint16_t>(((i / 255.0) - 0.5) * (-0.3441 * (255.0 / 224.0)) * 255.0);
            u_table[i].B = 0;
            u_table[i].A = 0;

            v_table[i].R = 0;
            v_table[i].G = static_cast<uint16_t>(((i / 255.0) - 0.5) * (-0.7141 * (255.0 / 224.0)) * 255.0);
            v_table[i].B = static_cast<uint16_t>(((i / 255.0) - 0.5) * (+1.4020 * (255.0 / 224.0)) * 255.0);
            v_table[i].A = 0;
        }
    }

    inline void __cdecl Hooked_CalcYuvLut() {
        MoviePlayerCalcYuvLut(ADDR_Y_TABLE, ADDR_U_TABLE, ADDR_V_TABLE);
        *reinterpret_cast<uint32_t*>(ADDR_FLAG_YUV_RESET) = 0;
    }

    inline void Init(int mode, bool x360StuffInstalled = false) {
        if (!x360StuffInstalled) {
            // Hook YUV LUT generator (sub_7F996A) to generate full-color range tables (0-255)
            // instead of vanilla limited range (16-235).
            MemoryTools::MakeJMP(ADDR_CALC_YUV_LUT, reinterpret_cast<uintptr_t>(Hooked_CalcYuvLut));

            // Pre-calculate tables right away
            Hooked_CalcYuvLut();
        }

        if (mode <= 0 || x360StuffInstalled) return;

        constexpr float kAspectFactor = (4.0f / 3.0f) / (16.0f / 9.0f); // 0.75f
        constexpr float kScaled = 0.5f / kAspectFactor;                 // ~0.6666667f

        if (mode == 1) {
            // Mode 1: Fill 16:9 screen (zoom/crop letterbox)
            MemoryTools::Write<float>(ADDR_MOVIE_QUAD_Y2,  kScaled);
            MemoryTools::Write<float>(ADDR_MOVIE_QUAD_X2,  kScaled);
            MemoryTools::Write<float>(ADDR_MOVIE_QUAD_Y1, -kScaled);
            MemoryTools::Write<float>(ADDR_MOVIE_QUAD_X1, -kScaled);
        } else if (mode == 2) {
            // Mode 2: Aspect ratio correct (preserve height, scale width to prevent stretch)
            MemoryTools::Write<float>(ADDR_MOVIE_QUAD_Y2,  0.5f);
            MemoryTools::Write<float>(ADDR_MOVIE_QUAD_X2,  kScaled);
            MemoryTools::Write<float>(ADDR_MOVIE_QUAD_Y1, -0.5f);
            MemoryTools::Write<float>(ADDR_MOVIE_QUAD_X1, -kScaled);
        }
    }
}
```

```h
    constexpr uintptr_t ADDR_NOS_TRAIL_TEST   = 0x00744FB7; // 85 C0 (test eax, eax)
    constexpr uintptr_t ADDR_NOS_TRAIL_LENGTH = 0x00745038; // 8 bytes: EB 06 8D 9B 00 00 00 00
    constexpr uintptr_t ADDR_NOS_TRAIL_CALL   = 0x007450E8; // call CarRenderInfo::RenderFlaresOnCar

        float x, y, z;
    };

    struct bVector4 {
        float x, y, z, w;
    };

        bVector4 v0;
        bVector4 v1;
        bVector4 v2;
        bVector4 v3;
    };

    inline float s_NOSTrailLength = 0.0f;
    inline float s_NOSTrailPositionScalar = 0.0f;

    // Hook at 0x00745038: scales delta vector in [esp+30h], [esp+34h], [esp+38h]
    __declspec(naked) inline void Hook_NOSTrailLength() {
        __asm {
            // [esp+4] is the return address pushed by call
            fld dword ptr [esp + 0x30 + 4]
            fmul ds:[s_NOSTrailLength]
            fstp dword ptr [esp + 0x30 + 4]

            fld dword ptr [esp + 0x34 + 4]
            fmul ds:[s_NOSTrailLength]
            fstp dword ptr [esp + 0x34 + 4]

            fld dword ptr [esp + 0x38 + 4]
            fmul ds:[s_NOSTrailLength]
            fstp dword ptr [esp + 0x38 + 4]

            xor eax, eax
            ret
        }
    }

    using PFN_RenderFlaresOnCar = void(__thiscall*)(void* thisCarRenderInfo, void* pView, bVector3* pPosition, bMatrix4* pBodyMatrix, int flag1, int flag2, int flag3);
    inline PFN_RenderFlaresOnCar s_OrigRenderFlaresOnCar = nullptr;

    inline void __fastcall Hook_RenderFlaresOnCar(void* thisCarRenderInfo, void* dummyEdx, void* pView, bVector3* pPosition, bMatrix4* pBodyMatrix, int flag1, int flag2, int flag3) {
        if (s_NOSTrailPositionScalar <= 0.0f || !pBodyMatrix || !s_OrigRenderFlaresOnCar) {
            if (s_OrigRenderFlaresOnCar) {
                s_OrigRenderFlaresOnCar(thisCarRenderInfo, pView, pPosition, pBodyMatrix, flag1, flag2, flag3);
            }
            return;
        }

        bMatrix4 adjustedMatrix = *pBodyMatrix;

        float posScale = 1.0f + s_NOSTrailPositionScalar;

        adjustedMatrix.v0.x *= posScale;
        adjustedMatrix.v0.y *= posScale;
        adjustedMatrix.v0.z *= posScale;

        adjustedMatrix.v2.x *= posScale;
        adjustedMatrix.v2.y *= posScale;

        s_OrigRenderFlaresOnCar(thisCarRenderInfo, pView, pPosition, &adjustedMatrix, flag1, flag2, flag3);
    }

        }
```

```h
    inline void EnumerateResolutions(int initialResX, int initialResY) {
        std::vector<Mode> modes;
        DEVMODEA dm = { 0 };
        dm.dmSize = sizeof(dm);

        DEVMODEA dmCurrent = { 0 };
        dmCurrent.dmSize = sizeof(dmCurrent);
        int desktopHz = 60;
        if (EnumDisplaySettingsA(NULL, ENUM_CURRENT_SETTINGS, &dmCurrent) && dmCurrent.dmDisplayFrequency > 0) {
            desktopHz = static_cast<int>(dmCurrent.dmDisplayFrequency);
        }

        for (DWORD i = 0; EnumDisplaySettingsA(NULL, i, &dm); ++i) {
            if (dm.dmBitsPerPel != 32) continue;
            if (dm.dmPelsWidth < 640 || dm.dmPelsHeight < 480) continue;
            modes.push_back({ static_cast<int>(dm.dmPelsWidth), static_cast<int>(dm.dmPelsHeight), static_cast<int>(dm.dmDisplayFrequency) });
        }

        // Sort: width asc, height asc, refresh rate desc (highest refresh rate first)
        std::sort(modes.begin(), modes.end(), [](const Mode& a, const Mode& b) {
            if (a.width != b.width) return a.width < b.width;
            if (a.height != b.height) return a.height < b.height;
            return a.refreshRate > b.refreshRate;
        });

        // Deduplicate resolutions, preserving highest refresh rate
        auto it = std::unique(modes.begin(), modes.end(), [](const Mode& a, const Mode& b) {
            return a.width == b.width && a.height == b.height;
        });
        modes.erase(it, modes.end());

        // Sort by width asc, height asc
        std::sort(modes.begin(), modes.end(), [](const Mode& a, const Mode& b) {
            if (a.width != b.width) return a.width < b.width;
            return a.height < b.height;
        });

        if (modes.empty()) {
            modes.push_back({ 1920, 1080, desktopHz });
        }

        g_ResolutionList.clear();
        g_ResolutionLabels.clear();
        g_ResolutionHashes.clear();
        g_SupportedModes.clear();
        g_SupportedRefreshRates.clear();


        for (const auto& m : modes) {
            g_ResolutionList.push_back(m);
            std::string label = std::to_string(m.width) + "x" + std::to_string(m.height);
            std::string hashStr = "OPT_VO_PC_RES_" + std::to_string(m.width) + "X" + std::to_string(m.height);
            int hash = static_cast<int>(StringHash(hashStr.c_str()));

            g_ResolutionLabels[hash] = label;
            g_ResolutionHashes.push_back(hash);
            g_SupportedModes.push_back(1);
            g_SupportedRefreshRates.push_back(m.refreshRate);
        }

        // Determine target starting resolution
        int targetW = initialResX;
        int targetH = initialResY;
        if (targetW <= 0 || targetH <= 0) {
            targetW = GetSystemMetrics(SM_CXSCREEN);
            targetH = GetSystemMetrics(SM_CYSCREEN);
        }

        g_ActiveResIndex = -1;
        for (size_t i = 0; i < g_ResolutionList.size(); ++i) {
            if (g_ResolutionList[i].width == targetW && g_ResolutionList[i].height == targetH) {
                g_ActiveResIndex = static_cast<int>(i);
                break;
            }
        }

        if (g_ActiveResIndex == -1) {
            Mode m{ targetW, targetH, desktopHz };
            g_ResolutionList.push_back(m);
            std::string label = std::to_string(m.width) + "x" + std::to_string(m.height);
            std::string hashStr = "OPT_VO_PC_RES_" + std::to_string(m.width) + "X" + std::to_string(m.height);
            int hash = static_cast<int>(StringHash(hashStr.c_str()));

            g_ResolutionLabels[hash] = label;
            g_ResolutionHashes.push_back(hash);
            g_SupportedModes.push_back(1);
            g_SupportedRefreshRates.push_back(desktopHz);
            g_ActiveResIndex = static_cast<int>(g_ResolutionList.size() - 1);
        }

        g_CurrentWidth = g_ResolutionList[g_ActiveResIndex].width;
        g_CurrentHeight = g_ResolutionList[g_ActiveResIndex].height;
        g_CurrentAspectRatio = static_cast<float>(g_CurrentWidth) / static_cast<float>(g_CurrentHeight);
    }

    inline DWORD GetPackedActiveRes() {
        if (g_ActiveResIndex >= 0 && g_ActiveResIndex < static_cast<int>(g_ResolutionList.size())) {
            int w = g_ResolutionList[g_ActiveResIndex].width;
            int h = g_ResolutionList[g_ActiveResIndex].height;
            return (static_cast<DWORD>(w) << 16) | (static_cast<DWORD>(h) & 0xFFFF) | 0x80000000;
        }
        return 0;
    }

    // Converts g_RacingResolution index or packed resolution format into width & height
    inline void __stdcall GetResolutionHook(int* outWidth, int* outHeight) {
        if (!outWidth || !outHeight) return;

        int idx = *reinterpret_cast<int*>(0x0090181C); // g_RacingResolution

        if (idx & 0x80000000) {
            int w = (idx & 0x7FFF0000) >> 16;
            int h = idx & 0xFFFF;
            int found = -1;
            for (size_t i = 0; i < g_ResolutionList.size(); ++i) {
                if (g_ResolutionList[i].width == w && g_ResolutionList[i].height == h) {
                    found = static_cast<int>(i);
                    break;
                }
            }
            idx = (found != -1) ? found : g_ActiveResIndex;
            *reinterpret_cast<int*>(0x0090181C) = idx;
        }

        if (idx < 0 || idx >= static_cast<int>(g_ResolutionList.size())) {
            idx = g_ActiveResIndex;
            *reinterpret_cast<int*>(0x0090181C) = idx;
        }

        g_ActiveResIndex = idx;
        *outWidth = g_ResolutionList[idx].width;
        *outHeight = g_ResolutionList[idx].height;
        g_CurrentWidth = *outWidth;
        g_CurrentHeight = *outHeight;
        g_CurrentAspectRatio = static_cast<float>(*outWidth) / static_cast<float>(*outHeight);

        if (g_WindowMode > 0) {
            HWND hWnd = *reinterpret_cast<HWND*>(0x00982BF4);

            if (hWnd) {

                    int curH = cr.bottom - cr.top;

        }

    // Handles resolution cycling in the in-game Video Options menu
    inline void __fastcall VOScreenResolution_Act_Hook(void* pThis, void* edx, int a2, int actionId) {
        uintptr_t* pDALManager = *reinterpret_cast<uintptr_t**>(0x0091CA20);
        if (!pDALManager) return;

        int* pCurrentIndex = reinterpret_cast<int*>(*reinterpret_cast<uintptr_t*>(pDALManager) + 108);
        int currentIndex = *pCurrentIndex;

        constexpr int ACTION_DECREMENT = static_cast<int>(0x9120409E);
        constexpr int ACTION_INCREMENT = static_cast<int>(0xB5971BF1);

        int delta = 0;
        bool changed = false;

        if (actionId == ACTION_DECREMENT) {
            delta = -1;
            changed = true;
        } else if (actionId == ACTION_INCREMENT) {
            delta = 1;
            changed = true;
        }

        if (changed) {
            int count = static_cast<int>(g_ResolutionList.size());
            do {
                currentIndex += delta;
                if (currentIndex < 0) currentIndex = count - 1;
                else if (currentIndex >= count) currentIndex = 0;
            } while (!g_SupportedModes[currentIndex]);

            *pCurrentIndex = currentIndex;
        }

        // Mark widget modified: m_bModified at offset 42 (0x2A)
        reinterpret_cast<uint8_t*>(pThis)[42] = 1;
        uintptr_t* vtable = *reinterpret_cast<uintptr_t**>(pThis);

        // Virtual method 14 (offset 0x38): NotifyAction(actionId)
        using NotifyFn = void(__thiscall*)(void*, int);
        reinterpret_cast<NotifyFn>(vtable[14])(pThis, actionId);

        // Virtual method 3 (offset 0x0C): Draw()
        using UpdateFn = void(__thiscall*)(void*);
        reinterpret_cast<UpdateFn>(vtable[3])(pThis);
    }

    inline void __fastcall Hook_IncScreenRes(void* pThis, void* edx, int a2, int actionId) {
```

```h
    inline void UpdateShadowsRes(float aspectRatio) {
        if (s_BaseResolution == 0) return;

        uint32_t resval = s_BaseResolution;
        if (resval > 16384) resval = 16384;
        if (resval < 512) resval = 512;

        uint32_t resX = resval;
        if (s_AutoScale) {
            float newShadowX = static_cast<float>(resval) * (aspectRatio / (4.0f / 3.0f));
            resX = static_cast<uint32_t>(newShadowX);
        }

        MemoryTools::Write<uint32_t>(ADDR_SHADOW_RES_X_MOV,   resX);
        MemoryTools::Write<uint32_t>(ADDR_SHADOW_RES_X_PUSH1, resX);
        MemoryTools::Write<uint32_t>(ADDR_SHADOW_RES_X_PUSH2, resX);
        MemoryTools::Write<uint32_t>(ADDR_SHADOW_RES_X_PUSH3, resX);

        // Patch Height (Y) operands
        MemoryTools::Write<uint32_t>(ADDR_SHADOW_RES_Y_MOV,   resY);
        MemoryTools::Write<uint32_t>(ADDR_SHADOW_RES_Y_PUSH1, resY);
        MemoryTools::Write<uint32_t>(ADDR_SHADOW_RES_Y_PUSH2, resY);
        MemoryTools::Write<uint32_t>(ADDR_SHADOW_RES_Y_PUSH3, resY);

        if (resX > resval) resval = resX;

        // Calculate dynamic depth bias scaling
        if (s_ActiveMode == 2 && !s_ForceSharpShadows) {
            s_DepthBias = static_cast<float>(MemoryTools::Read<int32_t>(ADDR_VANILLA_DEPTH_BIAS)) * (static_cast<float>(resval) / 1024.0f);
            s_DepthBiasSlope = MemoryTools::Read<float>(ADDR_VANILLA_DEPTH_SLOPE) * (static_cast<float>(resval) / 1024.0f);

            s_DepthBias = static_cast<float>(MemoryTools::Read<int32_t>(ADDR_VANILLA_DEPTH_BIAS)) * (static_cast<float>(resval) / 3072.0f);

            MemoryTools::Write<uint8_t>(ADDR_CHECK_DEV_D24S8_PUSH + 1, static_cast<uint8_t>(chosenFormat & 0xFF));

            s_ActiveMode = 1;

            MemoryTools::MakeJMP(ADDR_CREATE_FORMAT_CHECK, ADDR_CREATE_FOURCC_BRANCH);
            MemoryTools::Write<uint32_t>(ADDR_CREATE_FOURCC_PUSH + 1, chosenFormat);

    inline void Init(int shadowsRes, int shadowsFix, int improveShadowLOD, int autoScaleShadowsRes, int shadowMapTextureFormat, int forceSharpShadows) {
        // 1. Dynamic Shadows Disappearing Fix (Tunnels / Bridges)
        if (shadowsFix != 0) {
            // NOP the jump at 0x006DE377 so shadow fading is always bypassed
            MemoryTools::MakeNOP(ADDR_SHADOW_FADE_JNZ, 2);
            // Write 0.0f as immediate float to keep flt_982BA8 at 0 (full visibility)
            MemoryTools::Write<float>(ADDR_SHADOW_FADE_FLOAT, 0.0f);
            // Soften dynamic ambient car shadow from 110.0f to 60.0f
            MemoryTools::Write<float>(ADDR_CAR_SHADOW_OPACITY, 60.0f);
        }

        // 2. Texture Format (Auto / INTZ / D24S8 / etc.)
        s_ConfigFormat = shadowMapTextureFormat;
        s_ForceSharpShadows = (forceSharpShadows != 0);
        ApplyTextureFormat(shadowMapTextureFormat);

        // 3. Dynamic Shadow Resolution & Auto-Scale
        s_BaseResolution = (shadowsRes > 0) ? static_cast<uint32_t>(shadowsRes) : 2048;
        s_AutoScale = (autoScaleShadowsRes != 0);

        if (shadowsRes > 0) {
            // Hook depth bias in sub_6E54E0:
            // Convert 'fild dword ptr [0x00901AC0]' (DB 05 ...) into 'fld dword ptr [&s_DepthBias]' (D9 05 ...)
            uint8_t fldOpcode[2] = { 0xD9, 0x05 };
            MemoryTools::WriteBytes(ADDR_DEPTH_BIAS_INST, fldOpcode, 2);
            MemoryTools::Write<const float*>(ADDR_DEPTH_BIAS_INST + 2, &s_DepthBias);

            // Redirect 'mov edx, [0x00901ABC]' to read from &s_DepthBiasSlope
            MemoryTools::Write<const float*>(ADDR_DEPTH_BIAS_SLOPE + 2, &s_DepthBiasSlope);

            // Register callback with Resolution system so resolution / aspect changes update shadow dimensions
            Resolution::RegisterOnResChange(OnResolutionChange);

            // Initial resolution update
            UpdateShadowsRes(Resolution::g_CurrentAspectRatio);
        }

        // 4. Force Sharp Shadows (Stencil technique override on INTZ/DF16/DF24)
        if (!g_Config.X360StuffInstalled && forceSharpShadows != 0) {
            // sub eax, 3 -> sub eax, 2
            MemoryTools::Write<uint8_t>(ADDR_FORCE_SHARP_SUB + 2, 2);
        }

        // 5. Improve Shadow Level of Detail (LOD)
        if (improveShadowLOD != 0) {
            // Disable shadow LOD distance culling: push 200h -> push 0
            MemoryTools::Write<uint32_t>(ADDR_SHADOW_LOD_CULL, 0x00000000);
            // Enable high-detail geometry flags in shadow pass: push 4100h -> push 6102h
            MemoryTools::Write<uint32_t>(ADDR_SHADOW_LOD_DETAIL, 0x00006102);
        }
```

```h
    constexpr uintptr_t RET_SKIP_MOVIES_CHECK  = 0x005596A4;

    inline uint32_t s_OriginalValue = 0;

        __asm {
            mov eax, [ADDR_SKIP_MOVIES_FLAG]
            cmp s_SkipCounter, 3
            jge restore_flag

            jne set_flag
            mov edx, [eax]
            mov s_OriginalValue, edx

            mov dword ptr [eax], 1
            inc s_SkipCounter
            jmp finish

            mov edx, s_OriginalValue
            mov [eax], edx

            mov eax, [eax]
            test eax, eax
            jmp RET_SKIP_MOVIES_CHECK
        }
    }
```

```h
        for (const auto& e : entries) {
            DWORD oldProtect;
            PROC* pEntry = reinterpret_cast<PROC*>(e.addr);
            MemoryTools::Unprotect(e.addr, sizeof(PROC), oldProtect);
            *pEntry = e.hookFunc;
            MemoryTools::RestoreProtect(e.addr, sizeof(PROC), oldProtect);
        }
    }
}

#endif // NFSMW_WIDESCREENFIX_USERSETTINGS_H
```
