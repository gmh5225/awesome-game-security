Modular anti-cheat plugin for Survival / Economy / Crystal & Anchor PvP servers.
Package `com.paimc.anticheat` · Java 21 · Gradle (Kotlin DSL) · Paper-first, Folia + Spigot/Bukkit paths included · MC 1.21.1 – 1.21.11 (targeted).

## STATUS - read this first

| Item | State |
|---|---|
| Stage 1 (core) + all checks listed below | implemented |
| Built against the real Paper API | 1.0.0 was built by the project owner with Gradle 8.14.3. **1.0.1 was only syntax / type-checked by the author** (no Paper API in the authoring sandbox): build it and report any error. |
| Tested on a real server | partly: one Paper 1.21.11 server, tested with a cheat client. fly, boat-fly, anchor-sequence and anchor-switch were seen flagging. crystal, auto-totem, kill-aura, reach, speed and fast-xp are **not verified** against real cheats. |
| Folia / Spigot | code paths exist, **untested** |
| Gradle wrapper | included (`./gradlew build`) |

## Changes in 1.0.1
* **Fix:** a KICK crossed together with a TEMPBAN/BAN (typical after rejoining with a high VL) no longer swallows the ban. Only the most severe removal runs.
* **New: total VL.** The sum of the VL of every check is tracked per player and has its own threshold list (`total-thresholds` in `punishments.yml`, pseudo check id `total`). It is evaluated after every flag, decays with the per-check VL, shows in `/paiac vl`, in alert logs and as the `{total}` placeholder in `messages.yml` `alert`.
* After a rejoin, alerts/setbacks already triggered are not replayed (`PunishmentManager.seed`).
* New reason placeholder `{last-check}` (the check that flagged last). `docs/punishments-enforce.example.yml` is a full ENFORCE ladder for every check plus the total thresholds.

## Build (compile-only, no extra plugins needed)

```bash
# needs JDK 21 (Termux: pkg install openjdk-21)
./gradlew build                            # -> build/libs/PaiAC-1.0.1.jar
./gradlew test
```

Dependencies: only `paper-api:1.21.1-R0.1-SNAPSHOT` (`compileOnly`). No PacketEvents/ProtocolLib; SQLite JDBC is the driver already bundled in Paper/Spigot (loaded reflectively; without it PaiAC runs in memory-only mode).

## What is implemented

| Check id | Idea |
|---|---|
| `fly` | gravity prediction `(vy-0.08)*0.98`, one-sided, server-side ground detection |
| `speed` | cap from the player's movement-speed attribute (sprint/potions included) with air/ice/soul-speed multipliers |
| `boat-fly` | boats hovering/rising without support, surface-based speed caps |
| `reach` | eye→hitbox distance with ping + target-speed compensation |
| `kill-aura` | needs ≥2 signals on one hit: ray miss, target switch, aim snap, invalid state, no line of sight |
| `auto-clicker` | CPS cap (strong) + cadence regularity (weak), mining swings skipped |
| `crystal-macro` | place→hit cycle mean / regularity / instant-burst / rate, selectable **profiles**, **baseline-collection** calibration mode |
| `anchor-charge` `anchor-sequence` `anchor-switch` | place→glowstone→switch→explode timing |
| `auto-totem` | pop→off-hand refill time and consistency |
| `fast-xp` | experience bottles thrown faster than the vanilla rate; excess throws are cancelled |
| anti-xray | **not a Java check**: native Paper/Spigot anti-xray is only *read and reported*; example config in `xray/paper-world-defaults.example.yml` |

Infrastructure: per-check buffer/threshold/cooldown/min-evidence, VL with decay, evidence in SQLite (bounded async queue), alerts, threshold punishments (**DETECTION_ONLY by default**, dry-run logging, `auto-ban-enabled` second switch, duplicate-punishment guard), own ban list, TPS/ping lag gating, per-check exception isolation + auto-disable, config validation + versioned migration with backup, `/paiac` command.

## Safety defaults
* `enforcement-mode: DETECTION_ONLY` – nothing is ever done to players until you switch to `ENFORCE`.
* BAN/TEMPBAN additionally need `auto-ban-enabled: true`.
* Crystal/anchor/totem thresholds are **uncalibrated starting points**. Use `crystal.macro.baseline-collection: true` first, see `docs/CALIBRATION.md`.

## Commands & permissions
`/paiac help|status|checks|compat|profile|alerts|vl|reset|exempt|unexempt|ban|unban|bans|debug|reload`
Permissions: `paiac.command`, `paiac.admin`, `paiac.view`, `paiac.alerts`, `paiac.bypass`, `paiac.bypass.<check-id>`.

More: `docs/ARCHITECTURE.md`, `docs/COMPATIBILITY.md`, `docs/CALIBRATION.md`.

`docs/ARCHITECTURE.md`:

```md
# Architecture

```
PaiAC (JavaPlugin)
 ├─ platform/   PlatformInfo (Folia/Paper/Spigot + MC version), SchedulerAdapter (Bukkit | Folia), TpsMonitor
 ├─ config/     ConfigManager (versioned migration + backup), Settings, CheckSettings (validated)
 ├─ player/     PlayerState, PlayerStateManager, MovementTracker -> MoveData (shared environment + exemptions)
 ├─ checks/     Check (buffer/threshold/cooldown), CheckManager (dispatch, timing, error isolation)
 │    combat/ movement/ crystal/ anchor/ inventory/ xray/(diagnostics only)
 ├─ violation/  ViolationManager (VL + lag gating), EvidenceManager, AlertManager
 ├─ punishment/ PunishmentManager (thresholds, dry-run), BanManager (own ban list)
 ├─ storage/    StorageService (SQLite, single writer thread, bounded queue)
 ├─ packet/     PacketAdapter + NoopPacketAdapter (no packet library is used)
 ├─ listener/   CheckListener (events -> checks), ConnectionListener (join/quit/ban)
 └─ commands/   /paiac
```

Flow: Bukkit event → `CheckListener` → `CheckManager.dispatch` → `Check.onXxx` → `fail()` (buffer ≥ threshold, evidence ≥ min-evidence, cooldown) →
`ViolationManager.flag` (bypass, TPS/ping gate, VL) → `EvidenceManager` + `AlertManager` + `PunishmentManager.evaluate`.

Threading: checks run on the thread that fires the event (region thread on Folia) and only touch that player's `PlayerState`. Shared maps are concurrent. VL decay/autosave run async and touch only `PlayerState` maps. Kick/setback/ban kicks go through `SchedulerAdapter.runForPlayer`/`teleport`. Folia-only classes are never loaded on other platforms.

Decision: no PacketEvents/ProtocolLib. Everything is derived from Bukkit events; the consequences (tick-quantised timing, no raw rotation/packet order) are listed by `/paiac compat`.

`docs/CALIBRATION.md`:

```md
# Calibrating crystal / anchor / totem thresholds

1. Keep `enforcement-mode: DETECTION_ONLY` (default).
2. Crystal: set `crystal.macro.baseline-collection: true` in `checks/crystal.yml`, `/paiac reload`. While on, nothing is flagged; every `sample-size` cycles a row goes to table `baselines` (`metric`=profile, `v1`=mean cycle ms, `v2`=stddev ms, `v3`=cycles/s, `ping`).
3. Look at your best legitimate players: pick `competitive_ht1` or edit `custom` so limits sit clearly above them, then turn baseline-collection off.
4. Run with the default dry-run punishments for a few days and read `/paiac vl <player>`, alerts and table `punishments` (`dry`=1 rows).
5. Only then consider `ENFORCE`, starting with ALERT/CANCEL_ACTION/SETBACK; keep `auto-ban-enabled: false` until you trust the numbers.

Timing notes: events are processed on the tick loop (50 ms resolution); lag (TPS < 18, ping jitter > 80 ms) makes the timing checks skip instead of guessing.

# Compatibility

Compiled against Paper API 1.21.1 (oldest target). Version-fragile lookups (attributes, enchantments, entity types) are resolved by namespaced key / name so renames between 1.21.1 and 1.21.11 do not cause `NoSuchFieldError`.

| Platform | Status |
|---|---|
| Paper 1.21.1 – 1.21.11 | targeted, **untested** |
| Folia 1.21.x | scheduler path implemented, **untested**; `folia-supported: true` is declared |
| Spigot / Bukkit | main-thread scheduler path; Paper-only API is not called on this path, **untested** |
| Outside 1.21.1–1.21.11 | loads with a warning, behaviour unverified |

Known API assumptions to verify on first build/run: `Registry.ATTRIBUTE` key names (`generic.movement_speed` / `movement_speed`, `player.entity_interaction_range` / `entity_interaction_range`), `Player#getPing`, `Block#isPassable`, `Player#getScheduler` (Folia only).

Without a packet library: no sub-tick click timing, no packet ordering, no client on-ground flag, no raw rotation packets.

import com.paimc.anticheat.PaiAC;

/**
 * Base class of every detection. A check only receives events through the hooks below (dispatched by
 * {@link CheckManager} with timing + exception isolation) and reports through {@link #fail}/{@link #pass}.
 * Buffer, evidence counting, cooldown and VL are handled here so individual checks stay small.
 */
public abstract class Check {
    protected final PaiAC plugin;
    private final String id;
    private final String category;
    private final String file;
    private final String path;
    private final String description;
    private volatile CheckSettings settings = CheckSettings.disabled();
    private volatile boolean faulted;
    private final CheckStats stats = new CheckStats();

    protected Check(PaiAC plugin, String id, String category, String file, String path, String description) {
        this.plugin = plugin;
        this.id = id;
        this.category = category;
        this.file = file;
        this.path = path;
        this.description = description;
    }

    public final String id() { return id; }
    public final String category() { return category; }
    public final String file() { return file; }
    public final String path() { return path; }
    public final String description() { return description; }
    public final CheckSettings settings() { return settings; }
    public final CheckStats stats() { return stats; }
    public final boolean faulted() { return faulted; }
    public final void fault() { faulted = true; }

    public final void applySettings(CheckSettings s) {
        this.settings = s;
        this.faulted = false;
        onReload();
    }

    public final boolean enabled() {
        return settings.enabled && !faulted;
    }

    protected void onReload() {}

    /** Honest statement of what this check cannot see without packets. Shown in /paiac checks. */
    public String limitations() { return ""; }

    // ------------------------------------------------------------ event hooks (all optional)
    public void onMove(PlayerState s, MoveData m) {}
    public void onVehicleMove(PlayerState s, VehicleMoveEvent e, Player driver) {}
    public void onAttack(PlayerState s, Player p, EntityDamageByEntityEvent e) {}
    public void onSwing(PlayerState s, Player p) {}
    public void onInteract(PlayerState s, Player p, PlayerInteractEvent e) {}
    public void onBlockPlace(PlayerState s, Player p, BlockPlaceEvent e) {}
    public void onHeldChange(PlayerState s, Player p, PlayerItemHeldEvent e) {}
    public void onSwapHands(PlayerState s, Player p, PlayerSwapHandItemsEvent e) {}
    public void onInventoryClick(PlayerState s, Player p, InventoryClickEvent e) {}
    public void onTotemPop(PlayerState s, Player p, EntityResurrectEvent e) {}
    public void onProjectileLaunch(PlayerState s, Player p, ProjectileLaunchEvent e) {}

    // ------------------------------------------------------------ flag helpers
    protected final void fail(PlayerState s, double observed, double expected, String details) {
        failWeighted(s, 1.0, observed, expected, details);
    }

    protected final void failWeighted(PlayerState s, double weight, double observed, double expected, String details) {
        CheckSettings cs = settings;
        if (!cs.enabled) return;
        CheckData d = s.data(id);
        long now = System.currentTimeMillis();
        d.lastTouchMs = now;
        d.buffer = Math.min(cs.bufferLimit, d.buffer + weight);
        d.evidence++;
        if (cs.debug || plugin.debugEnabled()) {
            plugin.getLogger().info("[debug] " + id + " " + s.name + " buffer=" + Colors.fmt(d.buffer)
                    + " obs=" + Colors.fmt(observed) + " exp=" + Colors.fmt(expected) + " " + details);
        }
        if (d.buffer >= cs.threshold && d.evidence >= cs.minEvidence && now - d.lastFlagMs >= cs.cooldownMs) {
            d.lastFlagMs = now;
            plugin.violations().flag(this, s, observed, expected, details);
        }
    }

    protected final void pass(PlayerState s) {
        CheckData d = s.peek(id);
        if (d == null || d.buffer <= 0) return;
        d.buffer = Math.max(0, d.buffer - settings.bufferDecay);
        if (d.buffer <= 0) {
            d.buffer = 0;
            if (settings.resetOnClean) d.evidence = 0;
        }
    }

    protected final void resetBuffer(PlayerState s) {
        CheckData d = s.peek(id);
        if (d != null) {
            d.buffer = 0;
            d.evidence = 0;
        }
    }
}

package com.paimc.anticheat.checks;

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.config.ConfigManager;
import com.paimc.anticheat.player.PlayerState;

import java.util.ArrayList;
import java.util.Collections;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.function.Consumer;

/** Registry + dispatcher. A throwing check is isolated and auto-disabled after repeated errors. */
public final class CheckManager {
    private static final int MAX_ERRORS = 25;

    private final PaiAC plugin;
    private final Map<String, Check> byId = new LinkedHashMap<>();
    private final List<Check> list = new ArrayList<>();

    public CheckManager(PaiAC plugin) {
        this.plugin = plugin;
    }

    public void register(Check c) {
        if (byId.putIfAbsent(c.id(), c) != null) throw new IllegalStateException("duplicate check id " + c.id());
        list.add(c);
    }

    public void applyConfig(ConfigManager cfg) {
        for (Check c : list) c.applySettings(cfg.checkSettings(c.file(), c.path(), c.id()));
    }

    public Check get(String id) { return byId.get(id); }

    public List<Check> all() { return Collections.unmodifiableList(list); }

    public void dispatch(PlayerState s, Consumer<Check> action) {
        if (s.isExempt(System.currentTimeMillis())) return;
        for (int i = 0, n = list.size(); i < n; i++) {
            Check c = list.get(i);
            if (!c.enabled()) continue;
            long t0 = System.nanoTime();
            try {
                action.accept(c);
            } catch (Throwable t) {
                onError(c, t);
            } finally {
                c.stats().record(System.nanoTime() - t0);
            }
        }
    }

    private void onError(Check c, Throwable t) {
        c.stats().errors.increment();
        long n = c.stats().errors.sum();
        if (n <= 3) plugin.getLogger().log(java.util.logging.Level.WARNING, "Check '" + c.id() + "' threw an exception (isolated)", t);
        if (n >= MAX_ERRORS && !c.faulted()) {
            c.fault();
            plugin.getLogger().severe("Check '" + c.id() + "' disabled after " + n + " errors. Run /paiac reload after fixing the cause.");
        }
    }
}

package com.paimc.anticheat.checks;

import java.util.concurrent.atomic.AtomicLong;
import java.util.concurrent.atomic.LongAdder;

public final class CheckStats {
    public final LongAdder calls = new LongAdder();
    public final LongAdder totalNs = new LongAdder();
    public final LongAdder flags = new LongAdder();
    public final LongAdder errors = new LongAdder();
    public final LongAdder lagSkips = new LongAdder();
    public final AtomicLong maxNs = new AtomicLong();

    public void record(long ns) {
        calls.increment();
        totalNs.add(ns);
        long prev;
        while (ns > (prev = maxNs.get())) {
            if (maxNs.compareAndSet(prev, ns)) break;
        }
    }

    public double avgMicros() {
        long c = calls.sum();
        return c == 0 ? 0 : totalNs.sum() / 1000.0 / c;
    }
}

package com.paimc.anticheat.checks.anchor;

import com.paimc.anticheat.player.PlayerState;
import com.paimc.anticheat.util.DoubleRing;
import org.bukkit.Material;
import org.bukkit.World;
import org.bukkit.block.Block;
import org.bukkit.block.data.type.RespawnAnchor;
import org.bukkit.entity.Player;
import org.bukkit.event.block.Action;
import org.bukkit.event.player.PlayerInteractEvent;
import org.bukkit.inventory.EquipmentSlot;
import org.bukkit.inventory.ItemStack;

/** Shared timeline of anchor actions. Updated by the listener AFTER the checks ran, so checks see previous values. */
public final class AnchorData {
    public long placeNs;
    public long chargeNs;
    public long lastSlotNs;
    public final DoubleRing slotIntervalsMs = new DoubleRing(8);

    public static AnchorData of(PlayerState s) {
        return s.attachment("anchor-data", AnchorData::new);
    }

    public static AnchorAction classify(Player p, PlayerInteractEvent e) {
        if (e.getAction() != Action.RIGHT_CLICK_BLOCK) return AnchorAction.NONE;
        Block b = e.getClickedBlock();
        if (b == null || b.getType() != Material.RESPAWN_ANCHOR) return AnchorAction.NONE;
        int charges = charges(b);
        ItemStack it = e.getItem();
        if (it != null && it.getType() == Material.GLOWSTONE) {
            return charges < 4 ? AnchorAction.CHARGE : AnchorAction.NONE;
        }
        if (e.getHand() != EquipmentSlot.HAND) return AnchorAction.NONE;
        if (p.getInventory().getItemInOffHand().getType() == Material.GLOWSTONE && charges < 4) return AnchorAction.NONE;
        if (b.getWorld().getEnvironment() == World.Environment.NETHER) return AnchorAction.NONE;
        return charges > 0 ? AnchorAction.EXPLODE : AnchorAction.NONE;
    }

    private static int charges(Block b) {
        return b.getBlockData() instanceof RespawnAnchor ra ? ra.getCharges() : 0;
    }

    public void afterInteract(AnchorAction a) {
        long now = System.nanoTime();
        if (a == AnchorAction.CHARGE) chargeNs = now;
        else if (a == AnchorAction.EXPLODE) {
            chargeNs = 0;
            placeNs = 0;
        }
    }

    public void afterPlace() { placeNs = System.nanoTime(); }

    public void afterHeld() {
        long now = System.nanoTime();
        if (lastSlotNs != 0) {
            double ms = (now - lastSlotNs) / 1.0E6;
            if (ms < 2000) slotIntervalsMs.add(ms);
            else slotIntervalsMs.clear();
        }
        lastSlotNs = now;
    }
}

package com.paimc.anticheat.checks.combat;

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.checks.Check;
import com.paimc.anticheat.config.CheckSettings;
import com.paimc.anticheat.player.PlayerState;
import com.paimc.anticheat.util.DoubleRing;
import org.bukkit.block.Block;
import org.bukkit.entity.Player;

import java.util.ArrayDeque;

/**
 * Swing-rate analysis. Swings are timestamped when the server processes them (tick-quantised), so the hard
 * CPS cap is the strong signal and low-variance cadence only a supporting one. Block mining swings are skipped.
 */
public final class AutoClickerCheck extends Check {
    private static final class Data {
        final ArrayDeque<Long> times = new ArrayDeque<>();
        final DoubleRing intervals = new DoubleRing(64);
        long last;
    }

    public AutoClickerCheck(PaiAC plugin) {
        super(plugin, "auto-clicker", "combat", "combat", "combat.auto-clicker",
                "Click rate above the human limit, or inhumanly regular cadence");
    }

    @Override
    public String limitations() {
        return "Tick-quantised timestamps: cannot see sub-tick jitter; mining detection uses a target-block ray, so swings against a nearby wall while fighting are ignored only while 'digging' is set.";
    }

    @Override
    public void onSwing(PlayerState s, Player p) {
        if (s.digging) {
            Block b = p.getTargetBlockExact(6);
            if (b != null && !b.getType().isAir()) return; // mining: not a combat click
            s.digging = false;
        }
        CheckSettings cs = settings();
        Data d = s.attachment("auto-clicker", Data::new);
        long now = System.currentTimeMillis();

        d.times.addLast(now);
        while (!d.times.isEmpty() && d.times.peekFirst() < now - 1000) d.times.pollFirst();
        if (d.last != 0) {
            long iv = now - d.last;
            if (iv >= 2000) d.intervals.clear();
            else d.intervals.add(iv);
        }
        d.last = now;

        boolean jitter = s.pingJitter() > cs.dbl("max-ping-jitter-ms", 80);
        int cps = d.times.size();
        double maxCps = cs.dbl("max-cps", 22);
        int score = 0;
        StringBuilder why = new StringBuilder();

        if (cps > maxCps && !jitter) {
            score += 2;
            why.append("cps=").append(cps);
        }
        if (!jitter && d.intervals.size() >= cs.integer("min-samples", 30)) {
            double mean = d.intervals.mean();
            double std = d.intervals.stdDev();
            if (mean < cs.dbl("variance-mean-limit-ms", 120) && std < cs.dbl("min-stddev-ms", 14)) {
                score += 1;
                if (why.length() > 0) why.append(' ');
                why.append("stddev=").append(String.format("%.1f", std)).append("ms mean=").append(String.format("%.0f", mean)).append("ms");
            }
        }
        if (score >= 2) fail(s, cps, maxCps, why.toString());
        else if (score == 0) pass(s);
    }
}

            return;
        }
        CheckSettings cs = settings();
        Data d = s.attachment("kill-aura", Data::new);
        long now = System.currentTimeMillis();
        long nowNs = System.nanoTime();

        Location eyeLoc = p.getEyeLocation();
        Vector eye = eyeLoc.toVector();
        BoundingBox tb = target.getBoundingBox();
        Vector center = new Vector(tb.getCenterX(), tb.getCenterY(), tb.getCenterZ());
        Vector toCenter = center.clone().subtract(eye);

        int score = 0;
        List<String> sig = new ArrayList<>(4);

        // 1) look ray vs hitbox over the most recent rotation samples
        float[] yaws = new float[4];
        float[] pitches = new float[4];
        int n = s.rotationSamples(nowNs, cs.lng("ray-sample-window-ms", 200) * 1_000_000L, yaws, pitches);
        if (n > 0) {
            double reach = cs.dbl("ray-max-distance", 6.0);
            BoundingBox expanded = tb.clone().expand(cs.dbl("ray-tolerance", 0.25));
            boolean anyHit = false;
            for (int i = 0; i < n && !anyHit; i++) {
                if (expanded.rayTrace(eye, Geometry.direction(yaws[i], pitches[i]), reach) != null) anyHit = true;
            }
            if (!anyHit) {
                score++;
                sig.add("ray-miss");
            }
        }

        // 2) switching between widely separated targets faster than a human can aim
        Vector dir = toCenter.clone().normalize();
        UUID tid = target.getUniqueId();
        if (d.lastTarget != null && !d.lastTarget.equals(tid) && d.lastDir != null
                && now - d.lastAttackMs <= cs.lng("switch-window-ms", 120)) {
            double ang = Geometry.angleDeg(d.lastDir, dir);
            if (ang >= cs.dbl("switch-angle-degrees", 70)) {
                score++;
                sig.add("target-switch " + (int) ang + "deg");
            }
        }
        d.lastTarget = tid;
        d.lastAttackMs = now;
        d.lastDir = dir;

        // 3) large rotation snap followed by an on-target hit
        if (n >= 2) {
            double maxDelta = 0;
            for (int i = 0; i + 1 < n; i++) {
                maxDelta = Math.max(maxDelta, Math.abs(Geometry.wrapDegrees(yaws[i] - yaws[i + 1])));
            }
            double aimErr = Geometry.angleDeg(Geometry.direction(yaws[0], pitches[0]), toCenter);
            if (maxDelta >= cs.dbl("snap-degrees", 100) && aimErr <= cs.dbl("snap-hit-angle-degrees", 10)) {
                score++;
                sig.add("snap " + (int) maxDelta + "deg");
            }
        }

        // 4) impossible state (counts double)
        InventoryType open = p.getOpenInventory().getType();
        if (p.isSleeping() || p.isDead() || (open != InventoryType.CRAFTING && open != InventoryType.CREATIVE)) {
            score += 2;
            sig.add("invalid-state " + open);
        }

        // 5) no line of sight (optional, can be noisy near thin geometry, hence just one signal)
        if (cs.bool("check-line-of-sight", true) && !p.hasLineOfSight(target)) {
            score++;
            sig.add("no-line-of-sight");
        }

        int required = Math.max(1, cs.integer("required-signals", 2));
        if (score >= required) fail(s, score, required, String.join(",", sig));
        else pass(s);
    }
}

/** Eye-to-hitbox distance of melee hits, with ping and target-speed compensation. */
public final class ReachCheck extends Check {
    public ReachCheck(PaiAC plugin) {
        super(plugin, "reach", "combat", "combat", "combat.reach",
                "Melee hit from farther than the allowed distance to the target hitbox");
    }

    @Override
    public String limitations() {
        return "Uses the server-side position of both players (no position history): compensation is estimated from ping and target speed.";
    }

    @Override
    public void onAttack(PlayerState s, Player p, EntityDamageByEntityEvent e) {
        if (s.shouldCancel(id())) e.setCancelled(true);
        if (e.getCause() != DamageCause.ENTITY_ATTACK) return;
        GameMode gm = p.getGameMode();
        if (gm == GameMode.CREATIVE || gm == GameMode.SPECTATOR) {
            pass(s);
            return;
        }
        Entity t = e.getEntity();
        if (!t.getWorld().equals(p.getWorld())) return;

        CheckSettings cs = settings();
        double base = cs.dbl("max-reach", 3.0);
        double attr = CompatUtil.attributeValue(p, 0, "player.entity_interaction_range", "entity_interaction_range");
        if (attr > base) base = attr;

        BoundingBox box = t.getBoundingBox();
        Location eye = p.getEyeLocation();
        double dist = Geometry.distanceToBox(eye.getX(), eye.getY(), eye.getZ(), box);

        int ping = CompatUtil.ping(p);
        double speed = targetSpeed(t);
        double comp = Math.min(ping, cs.dbl("ping-cap-ms", 300)) / 50.0 * speed * cs.dbl("ping-compensation-factor", 1.0);
        comp = Math.min(comp, cs.dbl("max-compensation", 1.0));
        double allowed = base + cs.dbl("base-tolerance", 0.4) + comp;

        double hard = cs.dbl("hard-cancel-distance", 0.0);
        if (hard > 0 && dist > hard) e.setCancelled(true);

        if (dist > allowed) {
            fail(s, dist, allowed, "target=" + t.getType() + " ping=" + ping + " comp=" + String.format("%.2f", comp));
        } else {
            pass(s);
        }
    }

    private double targetSpeed(Entity t) {
        if (t instanceof Player tp) {
            PlayerState ts = plugin.states().get(tp.getUniqueId());
            return ts == null ? 0 : ts.lastDh;
        }
        return t.getVelocity().length();
    }
}

package com.paimc.anticheat.checks.crystal;

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.checks.Check;
import com.paimc.anticheat.config.CheckSettings;
import com.paimc.anticheat.player.PlayerState;
import com.paimc.anticheat.util.CompatUtil;
import com.paimc.anticheat.util.DoubleRing;
import org.bukkit.Location;
import org.bukkit.Material;
import org.bukkit.block.Block;
import org.bukkit.configuration.file.YamlConfiguration;
import org.bukkit.entity.Entity;
import org.bukkit.entity.Player;
import org.bukkit.event.block.Action;
import org.bukkit.event.entity.EntityDamageByEntityEvent;
import org.bukkit.event.player.PlayerInteractEvent;
import org.bukkit.inventory.ItemStack;

/**
 * Measures place -> hit cycles of end crystals (obsidian/bedrock base). Signals: mean cycle too short,
 * cycles too regular, bursts of "instant" cycles, sustained rate above the profile limit.
 * Thresholds come from a selectable profile and MUST be calibrated per server (see baseline-collection).
 */
public final class CrystalMacroCheck extends Check {
    private static final int SLOTS = 6;
    private static final int WINDOW = 32;

    private static final class Data {
        final long[] key = new long[SLOTS];
        final long[] placeNs = new long[SLOTS];
        int idx;
        final DoubleRing cycleMs = new DoubleRing(WINDOW);
        final DoubleRing hitMs = new DoubleRing(WINDOW);
        long lastHitMs;
    }

    public CrystalMacroCheck(PaiAC plugin) {
        super(plugin, "crystal-macro", "crystal", "crystal", "crystal.macro",
                "Crystal place->hit cycles faster / more regular than a human can sustain");
    }

    @Override
    public String limitations() {
        return "Server-side event timing only (tick-quantised, no packet order). Default profiles are UNCALIBRATED starting points: "
                + "run in baseline-collection mode on your own players first.";
    }

    private double prof(String key, double def) {
        YamlConfiguration c = plugin.config().checkFile("crystal");
        String name = c.getString("crystal.profile", "conservative");
        return c.getDouble("crystal.profiles." + name + "." + key, def);
    }

    public String profileName() {
        return plugin.config().checkFile("crystal").getString("crystal.profile", "conservative");
    }

    private static long pack(int x, int y, int z) {
        return (((long) x & 0x3FFFFFFL) << 38) | (((long) z & 0x3FFFFFFL) << 12) | ((long) y & 0xFFFL);
    }

    @Override
    public void onInteract(PlayerState s, Player p, PlayerInteractEvent e) {
        if (e.getAction() != Action.RIGHT_CLICK_BLOCK) return;
        ItemStack it = e.getItem();
        Block b = e.getClickedBlock();
        if (it == null || b == null || it.getType() != Material.END_CRYSTAL) return;
        if (b.getType() != Material.OBSIDIAN && b.getType() != Material.BEDROCK) return;
        Data d = s.attachment("crystal-macro", Data::new);
        d.key[d.idx] = pack(b.getX(), b.getY(), b.getZ());
        d.placeNs[d.idx] = System.nanoTime();
        d.idx = (d.idx + 1) % SLOTS;
    }

    @Override
    public void onAttack(PlayerState s, Player p, EntityDamageByEntityEvent e) {
        Entity ent = e.getEntity();
        if (!CompatUtil.isCrystal(ent)) return;
        if (s.shouldCancel(id())) e.setCancelled(true);

        Data d = s.attachment("crystal-macro", Data::new);
        Location l = ent.getLocation();
        long k = pack(l.getBlockX(), l.getBlockY() - 1, l.getBlockZ());
        int found = -1;
        for (int i = 0; i < SLOTS; i++) {
            if (d.placeNs[i] != 0 && d.key[i] == k) {
                found = i;
                break;
            }
        }
        if (found < 0) return; // not a crystal this player just placed

        long nowNs = System.nanoTime();
        long nowMs = System.currentTimeMillis();
        double cycle = (nowNs - d.placeNs[found]) / 1.0E6;
        d.placeNs[found] = 0;
        d.key[found] = 0;

        CheckSettings cs = settings();
        if (d.lastHitMs != 0 && nowMs - d.lastHitMs > cs.lng("window-reset-ms", 2000)) {
            d.cycleMs.clear();
            d.hitMs.clear();
        }
        d.lastHitMs = nowMs;
        d.cycleMs.add(cycle);
        d.hitMs.add(nowMs);

        int n = Math.min(cs.integer("sample-size", 10), WINDOW);
        if (d.cycleMs.size() < n) return;

        double sum = 0;
        int instant = 0;
        int from = d.cycleMs.size() - n;
        double instantMs = prof("instant-cycle-ms", 10);
        for (int i = from; i < d.cycleMs.size(); i++) {
            double c = d.cycleMs.get(i);
            sum += c;
            if (c <= instantMs) instant++;
        }
        double mean = sum / n;
        double var = 0;
        for (int i = from; i < d.cycleMs.size(); i++) {
            double c = d.cycleMs.get(i) - mean;
            var += c * c;
        }
        double std = Math.sqrt(var / n);
        double windowMs = d.hitMs.get(d.hitMs.size() - 1) - d.hitMs.get(from);
        double cps = windowMs <= 0 ? 999 : (n - 1) / (windowMs / 1000.0);
        int ping = CompatUtil.ping(p);

        if (cs.bool("baseline-collection", false)) {
            plugin.storage().insertBaseline(s.uuid, id(), profileName(), mean, std, cps, ping);
            d.cycleMs.clear();
            d.hitMs.clear();
            return; // calibration mode never flags
        }
        boolean dbg = cs.debug || plugin.debugEnabled();
        if (s.pingJitter() > cs.dbl("max-ping-jitter-ms", 80) || plugin.tps().tps() < 18.0) { // unreliable timing
            if (dbg) plugin.getLogger().info("[debug] crystal-macro " + s.name + " skipped: ping jitter " + (int) s.pingJitter() + "ms / tps " + String.format("%.1f", plugin.tps().tps()));
            return;
        }

        int score = 0;
        StringBuilder why = new StringBuilder();
        if (mean < prof("min-mean-cycle-ms", 60)) { score++; why.append("fast-mean "); }
        if (std < prof("min-stddev-ms", 3) && mean < prof("consistency-mean-limit-ms", 200)) { score++; why.append("too-regular "); }
        if (instant >= prof("max-instant-cycles", 4)) { score++; why.append("instant-burst "); }
        if (cps > prof("max-cps", 14)) { score += 2; why.append("rate "); }

        String details = "profile=" + profileName() + " mean=" + String.format("%.1f", mean) + "ms std=" + String.format("%.1f", std)
                + "ms cps=" + String.format("%.1f", cps) + " instant=" + instant + " [" + why.toString().trim() + "]";
        if (dbg) plugin.getLogger().info("[debug] crystal-macro " + s.name + " score=" + score + "/" + Math.max(1, cs.integer("required-signals", 2)) + " " + details);
        if (score >= Math.max(1, cs.integer("required-signals", 2))) fail(s, cps, prof("max-cps", 14), details);
        else pass(s);
    }
}

        if (e.getClick() == ClickType.SWAP_OFFHAND && isTotem(e.getCurrentItem())) toOffhand = true;
        else if (e.getClickedInventory() == p.getInventory() && e.getSlot() == 40 && isTotem(e.getCursor())) toOffhand = true;

        d.pending = false;

        d.refillMs.add(ms);

        double min = cs.dbl("min-refill-ms", 80);
        int ping = CompatUtil.ping(p);
        if (ms < min) {
            failWeighted(s, 2.0, ms, min, "refill " + String.format("%.0f", ms) + "ms ping=" + ping);
            return;
        }
        int need = cs.integer("min-samples", 4);
        if (d.refillMs.size() >= need) {
            double mean = d.refillMs.mean();
            double std = d.refillMs.stdDev();
            if (mean < cs.dbl("consistency-mean-limit-ms", 300) && std < cs.dbl("min-stddev-ms", 15)) {
                fail(s, std, cs.dbl("min-stddev-ms", 15), "consistent refill mean=" + String.format("%.0f", mean) + "ms std=" + String.format("%.1f", std) + "ms");
                return;
            }
        }
        pass(s);
    }

    private static boolean isTotem(ItemStack it) {
        return it != null && it.getType() == Material.TOTEM_OF_UNDYING;
    }

import com.paimc.anticheat.PaiAC;

/**
 * Experience bottles thrown faster than the vanilla right-click rate (one every 4 ticks = 200 ms).
 * Protects, not only detects: excess throws are cancelled immediately (cancel-excess), so the exploit
 * is blocked even while punishments are in DETECTION_ONLY.
 */
public final class FastXpBottleCheck extends Check {
    private static final class Data {
        final ArrayDeque<Long> times = new ArrayDeque<>();
        long last;
    }

    public FastXpBottleCheck(PaiAC plugin) {
        super(plugin, "fast-xp", "inventory", "inventory", "inventory.fast-xp",
                "Experience bottles thrown faster than the vanilla use rate");
    }

    @Override
    public String limitations() {
        return "Rate limit only: legit lag bursts can occasionally lose one throw (cancelled bottle is not consumed). Other fast-use exploits (bow, food) are not covered.";
    }

    @Override
    public void onProjectileLaunch(PlayerState s, Player p, ProjectileLaunchEvent e) {
        String t = e.getEntity().getType().name();
        if (!t.contains("EXPERIENCE_BOTTLE") && !t.contains("EXP_BOTTLE")) return;

        CheckSettings cs = settings();
        Data d = s.attachment("fast-xp", Data::new);
        long now = System.currentTimeMillis();
        long window = cs.lng("window-ms", 1000);
        int max = cs.integer("max-per-window", 6);
        long minGap = cs.lng("min-gap-ms", 100);

        while (!d.times.isEmpty() && d.times.peekFirst() < now - window) d.times.pollFirst();
        long prevLast = d.last;
        d.times.addLast(now);
        d.last = now;

        boolean burst = prevLast != 0 && now - prevLast < minGap;
        boolean over = d.times.size() > max;
        if (burst || over) {
            if (cs.bool("cancel-excess", true)) {
                e.setCancelled(true);
                d.times.pollLast(); // the cancelled throw must not count against the next legit one
                d.last = prevLast;
            }
            fail(s, d.times.size() + (burst ? 1 : 0), max,
                    (burst ? "gap=" + (now - prevLast) + "ms<" + minGap + "ms " : "") + "throws/window=" + (d.times.size() + 1));
        } else {
            pass(s);
        }
    }
}

    public void onVehicleMove(PlayerState s, VehicleMoveEvent e, Player driver) {

        long now = System.currentTimeMillis();
        Data d = s.attachment("boat-fly", Data::new);
        long nowNs = System.nanoTime();
        int ticks = d.lastNs == 0 ? 1 : (int) Math.max(1, Math.min(10, Math.round((nowNs - d.lastNs) / 50_000_000.0)));
        d.lastNs = nowNs;

        if (now - s.lastTeleportMs < 2000 || now - s.lastVelocityMs < 1500 || now - s.lastExplosionMs < 2000
                || now - s.lastVehicleMs < 500) {
            d.airTicks = 0;
            return;
        }
        Location from = e.getFrom();
        Location to = e.getTo();
        World w = to.getWorld();
        if (w == null || !w.isChunkLoaded(to.getBlockX() >> 4, to.getBlockZ() >> 4)) return;

        CheckSettings cs = settings();
        double dy = to.getY() - from.getY();
        double dh = Math.hypot(to.getX() - from.getX(), to.getZ() - from.getZ());

        int bx = to.getBlockX(), bz = to.getBlockZ();
        Material feet = w.getBlockAt(bx, (int) Math.floor(to.getY()), bz).getType();
        Block belowB = w.getBlockAt(bx, (int) Math.floor(to.getY() - 0.1), bz);
        Material below = belowB.getType();
        boolean supported = MaterialSets.LIQUIDS.contains(feet) || MaterialSets.LIQUIDS.contains(below) || !belowB.isPassable();

        if (!supported) {
            d.airTicks++;
            int minAir = cs.integer("min-air-ticks", 6);
            double hover = cs.dbl("max-hover-dy", -0.02);
            if (d.airTicks >= minAir && dy > hover) {
                fail(s, dy, hover, "airTicks=" + d.airTicks + " dy=" + Colors.fmt(dy));
            } else {
                pass(s);
            }
            return;
        }
        d.airTicks = 0;

        double cap;
        if (below == Material.BLUE_ICE) cap = cs.dbl("blue-ice-cap-per-tick", 4.2);
        else if (MaterialSets.ICE.contains(below)) cap = cs.dbl("ice-cap-per-tick", 2.5);
        else cap = cs.dbl("default-cap-per-tick", 0.7);
        double tol = cs.dbl("tolerance", 1.15);
        double perTick = dh / ticks;
        if (perTick > cap * tol) fail(s, perTick, cap * tol, "surface=" + below + " ticks=" + ticks);
        else pass(s);
    }

            return;
        }
        if (m.ticks > 1) { // skipped ticks: the prediction chain is broken
            d.airTicks = 0;
            d.prevDy = m.dy;
            return;
        }
        if (m.nearGround) {
            d.airTicks = 0;
            d.prevDy = m.dy;
            pass(s);
            return;
        }
        Player p = s.player();
        if (p == null) return;
        CheckSettings cs = settings();
        double tol = cs.dbl("tolerance", 0.05);
        d.airTicks++;

        if (d.airTicks == 1) {
            PotionEffect jb = p.getPotionEffect(PotionEffectType.JUMP_BOOST);
            int amp = jb == null ? 0 : jb.getAmplifier() + 1;
            double maxUp = 0.42 + 0.1 * amp + tol;
            d.prevDy = m.dy;
            if (m.dy > maxUp && !entitySupport(p)) fail(s, m.dy, maxUp, "leave-ground dy=" + Colors.fmt(m.dy));
            else pass(s);
            return;
        }

        double expected = (d.prevDy - 0.08) * 0.98;
        double diff = m.dy - expected;
        d.prevDy = m.dy;
        if (diff > tol) {
            if (entitySupport(p)) {
                d.airTicks = 0;
                return;
            }
            fail(s, m.dy, expected, "airTicks=" + d.airTicks + " diff=" + Colors.fmt(diff));
        } else {
            pass(s);
        }
    }

    private static boolean entitySupport(Player p) {
        for (Entity e : p.getNearbyEntities(0.9, 1.8, 0.9)) {
            String n = e.getType().name();
            if (n.contains("BOAT") || n.contains("RAFT") || n.contains("MINECART") || n.contains("SHULKER")) return true;
        }
        return false;
    }

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.checks.Check;
import com.paimc.anticheat.config.CheckSettings;
import com.paimc.anticheat.player.MoveData;

import com.paimc.anticheat.util.Colors;
import com.paimc.anticheat.util.CompatUtil;
import org.bukkit.entity.Player;

/**
 * Horizontal speed cap derived from the player's movement-speed attribute (which already includes sprint,
 * Speed/Slowness and soul-speed modifiers). 0.1 attribute == 0.2158 blocks/tick walking.
 */
public final class SpeedCheck extends Check {
    private static final double ATTR_TO_BLOCKS_PER_TICK = 2.1585;

    public SpeedCheck(PaiAC plugin) {
        super(plugin, "speed", "movement", "movement", "movement.speed",
                "Horizontal speed above what the movement-speed attribute allows");
    }

    @Override
    public String limitations() {
        return "Cap is attribute-based with generous air/ice multipliers; strafe/air-control exploits that stay under the cap are not detected.";
    }

    @Override
    public void onMove(PlayerState s, MoveData m) {
        if (m.positionless) return;
        CheckSettings cs = settings();
        if (m.exempt != null || m.ticks > cs.integer("max-ticks", 4)) {
            pass(s);
            return;
        }
        Player p = s.player();
        if (p == null) return;
        long now = System.currentTimeMillis();

        double attr = CompatUtil.attributeValue(p, 0.1, "generic.movement_speed", "movement_speed");
        double walkRatio = p.getWalkSpeed() / 0.2;
        attr = Math.max(attr, 0.1 * walkRatio);
        double cap = attr * ATTR_TO_BLOCKS_PER_TICK;

        if (m.inLiquid) {
            cap = Math.max(cap, cs.dbl("liquid-cap-per-tick", 0.45));
        } else {
            if (!m.nearGround) cap *= cs.dbl("air-multiplier", 2.2);
            if (m.onIce || now - s.lastIceMs < 500) cap *= cs.dbl("ice-multiplier", 2.5);
            if (m.onSoul || now - s.lastSoulMs < 500) cap *= cs.dbl("soul-speed-multiplier", 2.0);
        }

        double tps = plugin.tps().tps();
        double tol = cs.dbl("tolerance", 1.10) * (1.0 + Math.max(0, 20.0 - tps) * 0.03);
        double allowed = cap * tol * m.ticks;
        if (m.dh > allowed) {
            fail(s, m.dh / m.ticks, cap * tol,
                    "ticks=" + m.ticks + " air=" + !m.nearGround + " liquid=" + m.inLiquid + " dh=" + Colors.fmt(m.dh));
        } else {
            pass(s);
        }
    }
}

import com.paimc.anticheat.PaiAC;
import org.bukkit.World;

/**
 * X-ray is NOT detected by a Java check. It is handled by the server's native anti-xray (Paper
 * {@code anticheat.anti-xray}, Spigot {@code anti-xray}), which stops ore data reaching the client at all.
 * This class only READS those files and reports the effective state; it never modifies server configuration.
 */
public final class XrayDiagnostics {
    private final PaiAC plugin;

    public XrayDiagnostics(PaiAC plugin) {
        this.plugin = plugin;
    }

    public List<String> report() {
        List<String> out = new ArrayList<>();
        if (!plugin.config().checkFile("xray").getBoolean("xray.diagnostics.enabled", true)) {
            out.add("Anti-Xray diagnostics disabled in checks/xray.yml");
            return out;
        }
        File root = new File(".");
        File paperDefaults = firstExisting(new File(root, "config/paper-world-defaults.yml"),
                new File(plugin.getServer().getWorldContainer(), "config/paper-world-defaults.yml"));
        if (paperDefaults != null) {
            YamlConfiguration d = load(paperDefaults);
            out.add("Paper defaults: " + describe(d, "anticheat.anti-xray"));
            for (World w : plugin.getServer().getWorlds()) {
                File wf = new File(w.getWorldFolder(), "paper-world.yml");
                if (!wf.exists()) continue;
                YamlConfiguration wc = load(wf);
                if (wc.contains("anticheat.anti-xray")) {
                    out.add("World '" + w.getName() + "' override: " + describe(wc, "anticheat.anti-xray"));
                }
            }
        } else {
            File spigot = firstExisting(new File(root, "spigot.yml"));
            if (spigot != null) {
                out.add("Spigot (world-settings.default): " + describe(load(spigot), "world-settings.default.anti-xray"));
            } else {
                out.add("No paper-world-defaults.yml / spigot.yml found: cannot verify anti-xray.");
            }
        }
        if (plugin.config().checkFile("xray").getBoolean("xray.diagnostics.warn-if-disabled", true)
                && out.stream().anyMatch(l -> l.contains("enabled=false"))) {
            out.add("WARNING: anti-xray is disabled somewhere. See xray/paper-world-defaults.example.yml in the PaiAC plugin folder.");
        }
        return out;
    }

    private static String describe(YamlConfiguration c, String base) {
        boolean enabled = c.getBoolean(base + ".enabled", false);
        return "enabled=" + enabled + " engine-mode=" + c.get(base + ".engine-mode", "?")
                + " max-block-height=" + c.get(base + ".max-block-height", "?")
                + " hidden-blocks=" + c.getStringList(base + ".hidden-blocks").size()
                + " replacement-blocks=" + c.getStringList(base + ".replacement-blocks").size();
    }

    private static YamlConfiguration load(File f) {
        try {
            return YamlConfiguration.loadConfiguration(f);
        } catch (Throwable t) {
            return new YamlConfiguration();
        }
    }

    private static File firstExisting(File... files) {
        for (File f : files) if (f.isFile()) return f;
        return null;
    }

import com.paimc.anticheat.PaiAC;
import org.bukkit.configuration.ConfigurationSection;
import org.bukkit.configuration.InvalidConfigurationException;
import org.bukkit.configuration.file.YamlConfiguration;

import java.io.File;
import java.io.IOException;
import java.io.InputStreamReader;
import java.io.Reader;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.StandardCopyOption;
import java.text.SimpleDateFormat;
import java.util.ArrayList;
import java.util.Date;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * Loads every YAML file. A broken file never aborts startup: the bundled defaults are used in memory
 * and the user's file is left untouched. Older files are backed up, then missing keys are merged in.
 */
public final class ConfigManager {
    public static final String[] ROOT_FILES = {"config.yml", "messages.yml", "punishments.yml"};
    public static final String[] CHECK_FILES = {"combat", "crystal", "anchor", "inventory", "movement", "xray"};

    private final PaiAC plugin;
    private final List<String> warnings = new ArrayList<>();
    private final Map<String, YamlConfiguration> files = new HashMap<>();
    private Settings settings;

    public ConfigManager(PaiAC plugin) {
        this.plugin = plugin;
    }

    public void load() {
        warnings.clear();
        files.clear();
        for (String f : ROOT_FILES) files.put(f, loadFile(f));
        for (String f : CHECK_FILES) files.put("checks/" + f + ".yml", loadFile("checks/" + f + ".yml"));
        settings = Settings.from(files.get("config.yml"));
    }

    public Settings settings() { return settings; }

    public YamlConfiguration punishments() { return files.get("punishments.yml"); }

    public YamlConfiguration checkFile(String name) { return files.get("checks/" + name + ".yml"); }

    public String msg(String key, String def) {
        YamlConfiguration m = files.get("messages.yml");
        return m == null ? def : m.getString(key, def);
    }

    public CheckSettings checkSettings(String file, String path, String id) {
        YamlConfiguration cfg = checkFile(file);
        ConfigurationSection s = cfg == null ? null : cfg.getConfigurationSection(path);
        return CheckSettings.from(id, s, warnings);
    }

    public List<String> drainWarnings() {
        List<String> copy = new ArrayList<>(warnings);
        warnings.clear();
        return copy;
    }

    public void warn(String w) { warnings.add(w); }

    private YamlConfiguration loadFile(String path) {
        YamlConfiguration bundled = loadBundled(path);
        File f = new File(plugin.getDataFolder(), path);
        if (!f.exists()) {
            try {
                plugin.saveResource(path, false);
            } catch (IllegalArgumentException ex) {
                warnings.add(path + ": bundled resource missing from jar (" + ex.getMessage() + ")");
                return bundled;
            }
        }
        YamlConfiguration cfg = new YamlConfiguration();
        try {
            cfg.load(f);
        } catch (IOException | InvalidConfigurationException ex) {
            plugin.getLogger().severe(path + " could not be parsed, using bundled defaults (file left untouched): " + ex.getMessage());
            warnings.add(path + ": INVALID YAML, defaults in use. Fix the file and run /paiac reload.");
            return bundled;
        }

        int fileVersion = cfg.getInt("config-version", 0);
        int bundledVersion = bundled.getInt("config-version", 1);
        List<String> missing = new ArrayList<>();
        for (String key : bundled.getKeys(true)) {
            if (bundled.isConfigurationSection(key)) continue;
            if (!cfg.contains(key, true)) missing.add(key);
        }

        if (fileVersion < bundledVersion) {
            if (backup(f)) {
                for (String key : missing) cfg.set(key, bundled.get(key));
                cfg.set("config-version", bundledVersion);
                try {
                    cfg.save(f);
                    plugin.getLogger().info(path + " migrated v" + fileVersion + " -> v" + bundledVersion
                            + " (" + missing.size() + " keys added, backup created).");
                } catch (IOException ex) {
                    warnings.add(path + ": migration could not be saved: " + ex.getMessage());
                }
            } else {
                warnings.add(path + ": backup failed, migration skipped; defaults used for missing keys.");
            }
        } else if (fileVersion > bundledVersion) {
            warnings.add(path + ": config-version " + fileVersion + " is newer than this plugin supports (" + bundledVersion + ").");
        } else if (!missing.isEmpty()) {
            warnings.add(path + ": " + missing.size() + " key(s) missing, defaults used (e.g. " + missing.get(0) + ").");
        }
        cfg.setDefaults(bundled);
        return cfg;
    }

    private YamlConfiguration loadBundled(String path) {
        YamlConfiguration y = new YamlConfiguration();
        try (var in = plugin.getResource(path)) {
            if (in == null) return y;
            try (Reader r = new InputStreamReader(in, StandardCharsets.UTF_8)) {
                y.load(r);
            }
        } catch (IOException | InvalidConfigurationException ex) {
            plugin.getLogger().severe("Bundled " + path + " is unreadable: " + ex.getMessage());
        }
        return y;
    }

    private boolean backup(File f) {
        try {
            String stamp = new SimpleDateFormat("yyyyMMdd-HHmmss").format(new Date());
            File bak = new File(f.getParentFile(), f.getName() + ".bak-" + stamp);
            Files.copy(f.toPath(), bak.toPath(), StandardCopyOption.REPLACE_EXISTING);
            return true;
        } catch (IOException ex) {
            plugin.getLogger().warning("Could not back up " + f.getName() + ": " + ex.getMessage());
            return false;
        }
    }
}

        if (s.isExempt(nowMs)) {

            return;

        if (m == null) return;

import org.bukkit.Bukkit;
import org.bukkit.Location;
import org.bukkit.entity.Player;
import org.bukkit.plugin.Plugin;
import org.bukkit.scheduler.BukkitTask;

public final class BukkitSchedulerAdapter implements SchedulerAdapter {
    private final Plugin plugin;

    public BukkitSchedulerAdapter(Plugin plugin) {
        this.plugin = plugin;
    }

    @Override public boolean isFolia() { return false; }

    @Override
    public Task runGlobalRepeating(Runnable r, long delay, long period) {
        BukkitTask t = Bukkit.getScheduler().runTaskTimer(plugin, r, Math.max(1, delay), Math.max(1, period));
        return t::cancel;
    }

    @Override

        }

package com.paimc.anticheat.platform;

/** Estimates TPS from the spacing of a 20-tick global task; works on Spigot, Paper and Folia alike. */
public final class TpsMonitor {
    private volatile double tps = 20.0;
    private long lastNs;

    public void start(SchedulerAdapter scheduler) {
        scheduler.runGlobalRepeating(this::sample, 20, 20);
    }

    private void sample() {
        long now = System.nanoTime();
        if (lastNs != 0) {
            double ms = (now - lastNs) / 1.0E6;
            double v = Math.min(20.0, 20.0 * 1000.0 / Math.max(ms, 1.0));
            tps = tps * 0.5 + v * 0.5;
        }
        lastNs = now;
    }

    public double tps() {
        return Math.min(20.0, tps);
    }
}

package com.paimc.anticheat.player;

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.util.CompatUtil;
import com.paimc.anticheat.util.MaterialSets;
import org.bukkit.GameMode;
import org.bukkit.Location;
import org.bukkit.Material;
import org.bukkit.World;
import org.bukkit.block.Block;
import org.bukkit.entity.Player;
import org.bukkit.event.player.PlayerMoveEvent;
import org.bukkit.potion.PotionEffectType;

/** Builds {@link MoveData} (environment + exemptions) once per move so every movement check shares it. */
public final class MovementTracker {
    private final PaiAC plugin;

    public MovementTracker(PaiAC plugin) {
        this.plugin = plugin;
    }

    public MoveData process(Player p, PlayerState s, PlayerMoveEvent e) {
        Location to = e.getTo();
        Location from = e.getFrom();
        if (to == null || to.getWorld() == null) return null;
        long nowNs = System.nanoTime();
        long nowMs = System.currentTimeMillis();

        MoveData m = new MoveData();
        m.world = to.getWorld();
        m.fromX = from.getX(); m.fromY = from.getY(); m.fromZ = from.getZ();
        m.toX = to.getX(); m.toY = to.getY(); m.toZ = to.getZ();
        m.dx = m.toX - m.fromX; m.dy = m.toY - m.fromY; m.dz = m.toZ - m.fromZ;
        m.dh = Math.hypot(m.dx, m.dz);
        m.yaw = to.getYaw();
        m.pitch = to.getPitch();
        m.positionless = m.dx == 0 && m.dy == 0 && m.dz == 0;

        s.pushRotation(m.yaw, m.pitch, nowNs);
        s.samplePing(CompatUtil.ping(p), nowMs);

        if (m.positionless) return m;

        m.ticks = s.lastMoveNs == 0 ? 1 : (int) Math.max(1, Math.min(20, Math.round((nowNs - s.lastMoveNs) / 50_000_000.0)));
        if (!s.hasLast) m.exempt = "first-move";

        scanEnvironment(m, s, nowMs);
        if (m.exempt == null) m.exempt = exemptionReason(p, s, nowMs);
        return m;
    }

    /** Updates the "previous move" fields. Call after all checks ran. */
    public void finish(PlayerState s, MoveData m) {
        if (m == null || m.positionless) return;
        s.hasLast = true;
        s.lastMoveNs = System.nanoTime();
        s.lastDh = m.dh;
        s.lastDy = m.dy;
        if (m.nearGround && m.exempt == null) {
            s.safeLocation = new Location(m.world, m.toX, m.toY, m.toZ, m.yaw, m.pitch);
        }
    }

    private void scanEnvironment(MoveData m, PlayerState s, long nowMs) {
        World w = m.world;
        int bx = floor(m.toX), by = floor(m.toY), bz = floor(m.toZ);
        double[] cxs = {m.toX - 0.31, m.toX + 0.31};
        double[] czs = {m.toZ - 0.31, m.toZ + 0.31};

        for (double cx : cxs) {
            for (double cz : czs) {
                if (!w.isChunkLoaded(floor(cx) >> 4, floor(cz) >> 4)) {
                    m.exempt = "unloaded-chunk";
                    return;
                }
            }
        }

        Material feet = type(w, bx, by, bz);
        Material mid = type(w, bx, floor(m.toY + 0.9), bz);
        m.inLiquid = MaterialSets.LIQUIDS.contains(feet) || MaterialSets.LIQUIDS.contains(mid) || waterlogged(w, bx, by, bz);
        m.climbing = MaterialSets.CLIMBABLE.contains(feet) || MaterialSets.CLIMBABLE.contains(mid);
        m.slowing = MaterialSets.SLOWING.contains(feet) || MaterialSets.SLOWING.contains(mid);

        double frac = m.toY - Math.floor(m.toY);
        for (double cx : cxs) {
            for (double cz : czs) {
                int gx = floor(cx), gz = floor(cz);
                Block under = w.getBlockAt(gx, floor(m.toY - 0.2), gz);
                Material um = under.getType();
                if (!under.isPassable()) m.nearGround = true;
                if (MaterialSets.BOUNCY.contains(um)) m.bouncy = true;
                if (MaterialSets.ICE.contains(um)) m.onIce = true;
                if (MaterialSets.SOUL.contains(um)) m.onSoul = true;
                if (!m.nearGround) {
                    Material below2 = type(w, gx, floor(m.toY - 1.2), gz);
                    if (MaterialSets.isTallCollision(below2) && frac > 0.3 && frac < 0.7) m.nearGround = true;
                }
            }
        }
        if (!m.nearGround) {
            Block feetBlock = w.getBlockAt(bx, by, bz);
            // e.g. lily pad / carpet / snow layer: collidable block that the feet are inside of
            if (!feetBlock.isPassable() && frac < 0.3) m.nearGround = true;
        }
        if (m.bouncy) s.lastBounceMs = nowMs;
        if (m.onIce) s.lastIceMs = nowMs;
        if (m.onSoul) s.lastSoulMs = nowMs;
    }

    private String exemptionReason(Player p, PlayerState s, long now) {
        var cfg = plugin.config().checkFile("movement");
        GameMode gm = p.getGameMode();
        if (gm == GameMode.CREATIVE || gm == GameMode.SPECTATOR) return "gamemode";
        if (p.getAllowFlight() || p.isFlying()) return "flight";
        if (p.isGliding()) return "elytra";
        if (p.isRiptiding()) return "riptide";
        if (p.isInsideVehicle()) return "vehicle";
        if (p.isDead()) return "dead";
        if (p.hasPotionEffect(PotionEffectType.LEVITATION)) return "levitation";
        if (p.hasPotionEffect(PotionEffectType.SLOW_FALLING)) return "slow-falling";

        if (within(now, s.lastTeleportMs, cfg.getInt("exemptions.after-teleport-ticks", 20))) return "teleport";
        if (within(now, s.lastVelocityMs, cfg.getInt("exemptions.after-velocity-ticks", 30))) return "velocity";
        if (within(now, s.lastExplosionMs, cfg.getInt("exemptions.after-explosion-ticks", 40))) return "explosion";
        if (within(now, s.lastDamageMs, cfg.getInt("exemptions.after-damage-ticks", 15))) return "damage";
        if (within(now, s.lastGamemodeMs, cfg.getInt("exemptions.after-gamemode-change-ticks", 40))) return "gamemode-change";
        if (within(now, s.lastVehicleMs, cfg.getInt("exemptions.after-vehicle-ticks", 20))) return "vehicle-exit";
        if (within(now, s.lastGlideMs, cfg.getInt("exemptions.after-glide-ticks", 40))) return "glide-end";
        if (within(now, s.lastRiptideMs, cfg.getInt("exemptions.after-riptide-ticks", 40))) return "riptide-end";
        if (within(now, s.lastBounceMs, cfg.getInt("exemptions.after-bounce-ticks", 40))) return "bounce";
        if (within(now, s.lastFlightToggleMs, cfg.getInt("exemptions.after-flight-toggle-ticks", 60))) return "flight-toggle";
        if (within(now, s.lastWorldChangeMs, cfg.getInt("exemptions.after-world-change-ticks", 40))) return "world-change";
        if (now - s.joinMs < cfg.getInt("exemptions.after-join-ticks", 60) * 50L) return "join";
        return null;
    }

    private static boolean within(long now, long ts, int ticks) {
        return ts > 0 && now - ts <= ticks * 50L;
    }

    private static int floor(double v) { return (int) Math.floor(v); }

    private static Material type(World w, int x, int y, int z) {
        if (y < w.getMinHeight() || y >= w.getMaxHeight()) return Material.AIR;
        return w.getBlockAt(x, y, z).getType();
    }

    private static boolean waterlogged(World w, int x, int y, int z) {
        if (y < w.getMinHeight() || y >= w.getMaxHeight()) return false;
        return w.getBlockAt(x, y, z).getBlockData() instanceof org.bukkit.block.data.Waterlogged wl && wl.isWaterlogged();
    }
}

package com.paimc.anticheat.player;

import com.paimc.anticheat.util.DoubleRing;
import org.bukkit.Location;
import org.bukkit.entity.Player;

import java.util.ArrayDeque;
import java.util.HashMap;
import java.util.Map;
import java.util.Set;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;
import java.util.function.Supplier;

/** Everything PaiAC remembers about one online player. */
public final class PlayerState {
    public final UUID uuid;
    public volatile String name;
    public final long joinMs = System.currentTimeMillis();

    private volatile Player player;
    private final ConcurrentHashMap<String, CheckData> checkData = new ConcurrentHashMap<>();
    private final ConcurrentHashMap<String, Double> vl = new ConcurrentHashMap<>();
    private final ConcurrentHashMap<String, Long> cancelUntil = new ConcurrentHashMap<>();
    private final ConcurrentHashMap<String, Object> attachments = new ConcurrentHashMap<>();
    public final Set<String> firedPunishments = ConcurrentHashMap.newKeySet();
    public final ArrayDeque<String> recentEvidence = new ArrayDeque<>();

    public volatile long exemptUntilMs;
    public volatile boolean alertsEnabled;
    public volatile boolean bypassAll;
    public volatile long permCheckMs;
    public volatile long lastPunishMs;
    public volatile long verboseUntilMs;

    // ---- movement tracking (written by the player's own thread)
    public boolean hasLast;
    public double lastDh, lastDy;
    public long lastMoveNs;
    public volatile Location safeLocation;

    // ---- timestamps (ms) of events that legitimately change movement
    public volatile long lastTeleportMs, lastVelocityMs, lastDamageMs, lastExplosionMs, lastGamemodeMs;
    public volatile long lastVehicleMs, lastGlideMs, lastRiptideMs, lastBounceMs, lastFlightToggleMs;
    public volatile long lastIceMs, lastSoulMs, lastWorldChangeMs;
    public volatile long lastBlockDamageMs, lastAttackMs;
    public volatile boolean digging;

    // ---- diagnostics (/paiac inspect)
    public volatile String lastExempt = "no move seen yet";
    public volatile long lastMoveSeenMs;
    public volatile long moveEvents;

    // ---- rotation history (newest at index rotIdx)
    private final float[] yawHist = new float[4];
    private final float[] pitchHist = new float[4];
    private final long[] rotNs = new long[4];
    private int rotIdx = -1;
    private int rotCount;

    private final DoubleRing pings = new DoubleRing(10);
    private long lastPingSampleMs;

    public PlayerState(UUID uuid, String name) {
        this.uuid = uuid;
        this.name = name;
    }

    public Player player() { return player; }

    public void setPlayer(Player p) { this.player = p; }

    // ---------------- violations
    public double vl(String checkId) { return vl.getOrDefault(checkId, 0.0); }

    public double addVl(String checkId, double delta, double max) {
        return vl.merge(checkId, Math.min(max, delta), (a, b) -> Math.min(max, a + b));
    }

    public void setVl(String checkId, double value) {
        if (value <= 0) vl.remove(checkId);
        else vl.put(checkId, value);
    }

    public double totalVl() {
        double t = 0;
        for (double v : vl.values()) t += v;
        return t;
    }

    public Map<String, Double> vlSnapshot() { return new HashMap<>(vl); }

    public void clearVl() { vl.clear(); firedPunishments.clear(); }

    public void clearVl(String checkId) {
        vl.remove(checkId);
        firedPunishments.removeIf(k -> k.startsWith(checkId + "#"));
    }

    /** Merge VLs loaded from storage: keep the larger value so live flags are never lost. */
    public void restoreVl(Map<String, Double> loaded) {
        loaded.forEach((k, v) -> vl.merge(k, v, Math::max));
    }

    // ---------------- per-check data
    public CheckData data(String checkId) { return checkData.computeIfAbsent(checkId, k -> new CheckData()); }

    public CheckData peek(String checkId) { return checkData.get(checkId); }

    @SuppressWarnings("unchecked")
    public <T> T attachment(String key, Supplier<T> factory) {
        return (T) attachments.computeIfAbsent(key, k -> factory.get());
    }

    public void pruneIdle(long nowMs, long retentionMs) {
        checkData.entrySet().removeIf(e -> nowMs - e.getValue().lastTouchMs > retentionMs);
    }

    // ---------------- action cancelling
    public void cancelActions(String checkId, long untilMs) { cancelUntil.put(checkId, untilMs); }

    public boolean shouldCancel(String checkId) {
        Long u = cancelUntil.get(checkId);
        if (u == null) return false;
        if (System.currentTimeMillis() > u) {
            cancelUntil.remove(checkId);
            return false;
        }
        return true;
    }

    public boolean isExempt(long nowMs) { return bypassAll || nowMs < exemptUntilMs; }

    // ---------------- rotation history
    public void pushRotation(float yaw, float pitch, long ns) {
        rotIdx = (rotIdx + 1) % yawHist.length;
        yawHist[rotIdx] = yaw;
        pitchHist[rotIdx] = pitch;
        rotNs[rotIdx] = ns;
        if (rotCount < yawHist.length) rotCount++;
    }

    /**
     * Copies recent rotation samples (newest first) not older than windowNs into the output arrays.
     * @return number of samples copied
     */
    public int rotationSamples(long nowNs, long windowNs, float[] yawOut, float[] pitchOut) {
        int n = 0;
        for (int i = 0; i < rotCount && n < yawOut.length; i++) {
            int idx = ((rotIdx - i) % yawHist.length + yawHist.length) % yawHist.length;
            if (nowNs - rotNs[idx] > windowNs) break;
            yawOut[n] = yawHist[idx];
            pitchOut[n] = pitchHist[idx];
            n++;
        }
        return n;
    }

    // ---------------- ping
    public void samplePing(int ping, long nowMs) {
        if (nowMs - lastPingSampleMs < 1000) return;
        lastPingSampleMs = nowMs;
        pings.add(ping);
    }

    /** Max minus min of the recent ping samples (ms). */
    public double pingJitter() {
        return pings.size() < 3 ? 0 : pings.max() - pings.min();
    }
}

package com.paimc.anticheat.player;

import com.paimc.anticheat.PaiAC;
import org.bukkit.entity.Player;

import java.util.Collection;
import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

public final class PlayerStateManager {
    private final PaiAC plugin;
    private final Map<UUID, PlayerState> states = new ConcurrentHashMap<>();

    public PlayerStateManager(PaiAC plugin) {
        this.plugin = plugin;
    }

    public PlayerState get(UUID id) { return states.get(id); }

    public PlayerState getOrCreate(Player p) {
        PlayerState s = states.get(p.getUniqueId());
        if (s != null) {
            s.setPlayer(p);
            return s;
        }
        return states.computeIfAbsent(p.getUniqueId(), id -> {
            PlayerState ns = new PlayerState(id, p.getName());
            ns.setPlayer(p);
            ns.alertsEnabled = plugin.settings().alertsDefaultOn;
            plugin.storage().loadViolations(id).thenAccept(map -> {
                ns.restoreVl(map);
                plugin.punishments().seed(ns);
            });
            return ns;
        });
    }

    public void remove(UUID id) {
        PlayerState s = states.remove(id);
        if (s != null) {
            plugin.storage().saveViolations(id, s.vlSnapshot());
            s.setPlayer(null);
        }
    }

    public Collection<PlayerState> all() { return states.values(); }

    public void saveAll() {
        for (PlayerState s : states.values()) plugin.storage().saveViolations(s.uuid, s.vlSnapshot());
    }

    public void clear() { states.clear(); }
}

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.storage.BanEntry;
import com.paimc.anticheat.util.Colors;

/** PaiAC's own ban list (independent of vanilla/other plugins), cached in memory and persisted by StorageService. */
public final class BanManager {
    private final PaiAC plugin;
    private final Map<UUID, BanEntry> bans = new ConcurrentHashMap<>();

    public BanManager(PaiAC plugin) {
        this.plugin = plugin;
    }

    public void load() {
        bans.clear();
        for (BanEntry b : plugin.storage().loadActiveBansBlocking()) {
            if (!b.isExpired(System.currentTimeMillis())) bans.put(b.uuid(), b);
        }

        BanEntry b = bans.get(id);
        if (b == null) return null;
        if (b.isExpired(System.currentTimeMillis())) {
            bans.remove(id);
            plugin.storage().deactivateBan(id);
            return null;
        }
        return b;
    }

    public void ban(BanEntry b) {
        bans.put(b.uuid(), b);
        plugin.storage().upsertBan(b);
    }

    public boolean unban(UUID id) {
        BanEntry removed = bans.remove(id);
        if (removed != null) plugin.storage().deactivateBan(id);
        return removed != null;
    }

    public UUID findByName(String name) {
        for (BanEntry b : bans.values()) if (b.name() != null && b.name().equalsIgnoreCase(name)) return b.uuid();
        return null;
    }

    public Collection<BanEntry> list() {
        List<BanEntry> out = new ArrayList<>();
        for (UUID id : new ArrayList<>(bans.keySet())) {
            BanEntry b = active(id);
            if (b != null) out.add(b);
        }
        return out;
    }

    public String screen(BanEntry b) {
        String expires = b.expires() == -1 ? "never" : Durations.format(Math.max(0, b.expires() - System.currentTimeMillis())) + " left";
        String t = plugin.config().msg("ban-screen", "&cYou are banned by PaiAC.\n&7Reason: &f{reason}\n&7Expires: &f{expires}");
        return Colors.color(t.replace("{reason}", String.valueOf(b.reason())).replace("{expires}", expires));
    }
}

import java.util.Locale;

public enum PunishAction {
    ALERT, LOG, CANCEL_ACTION, SETBACK, KICK, TEMPBAN, BAN;

    public static PunishAction parse(String s) {
        if (s == null) return null;
        try {
            return valueOf(s.trim().toUpperCase(Locale.ROOT));
        } catch (IllegalArgumentException e) {
            return null;
        }
    }

    /** Actions that only make sense (and are only executed) in ENFORCE mode. */
    public boolean needsEnforcement() {
        return this != ALERT && this != LOG;
    }

    public boolean isBan() {
        return this == BAN || this == TEMPBAN;
    }
}

```java
package com.paimc.anticheat.punishment;

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.player.PlayerState;
import com.paimc.anticheat.storage.BanEntry;
import com.paimc.anticheat.storage.PunishmentRecord;
import com.paimc.anticheat.util.Colors;
import com.paimc.anticheat.util.Durations;
import org.bukkit.Location;
import org.bukkit.configuration.ConfigurationSection;
import org.bukkit.configuration.file.YamlConfiguration;
import org.bukkit.entity.Player;

import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Locale;
import java.util.Map;
import java.util.UUID;

/**
 * Threshold-driven punishments. DETECTION_ONLY (default) never touches a player: destructive actions are
 * recorded as dry-runs so staff can calibrate thresholds before switching to ENFORCE.
 */
public final class PunishmentManager {
    public record Threshold(double vl, PunishAction action, boolean enabled, double repeatEvery,
                            long durationMs, String reason) {}

    /** Pseudo check id of the combined VL (sum of every check). */
    public static final String TOTAL_ID = "total";

    private final PaiAC plugin;
    private volatile boolean enforce;
    private volatile boolean autoBan;
    private volatile long cancelMs = 1500;
    private volatile long guardMs = 3000;
    private volatile List<Threshold> defaults = List.of();
    private volatile Map<String, List<Threshold>> perCheck = Map.of();
    private volatile List<Threshold> totalThresholds = List.of();

    public PunishmentManager(PaiAC plugin) {
        this.plugin = plugin;
    }

    public boolean enforcing() { return enforce; }

    public boolean autoBanEnabled() { return autoBan; }

    public void reload() {
        YamlConfiguration c = plugin.config().punishments();
        String mode = c.getString("enforcement-mode", "DETECTION_ONLY").toUpperCase(Locale.ROOT);
        if (!mode.equals("DETECTION_ONLY") && !mode.equals("ENFORCE")) {
            plugin.config().warn("punishments.yml: enforcement-mode '" + mode + "' invalid, using DETECTION_ONLY");
            mode = "DETECTION_ONLY";
        }
        enforce = mode.equals("ENFORCE");
        autoBan = c.getBoolean("auto-ban-enabled", false);
        cancelMs = Math.max(100, c.getLong("cancel-duration-ms", 1500));
        guardMs = Math.max(0, c.getLong("duplicate-guard-ms", 3000));
        defaults = parseList(c.getMapList("default-thresholds"), "default-thresholds");
        totalThresholds = parseList(c.getMapList("total-thresholds"), "total-thresholds");

        Map<String, List<Threshold>> map = new HashMap<>();
        ConfigurationSection cs = c.getConfigurationSection("checks");
        if (cs != null) {
            for (String id : cs.getKeys(false)) {
                map.put(id, parseList(cs.getMapList(id + ".thresholds"), "checks." + id));
            }
        }
        perCheck = map;
    }

    private List<Threshold> parseList(List<Map<?, ?>> raw, String where) {
        List<Threshold> out = new ArrayList<>();
        int i = 0;
        for (Map<?, ?> m : raw) {
            i++;
            Object vlO = m.get("vl");
            PunishAction a = PunishAction.parse(String.valueOf(m.get("action")));
            if (!(vlO instanceof Number) || a == null || ((Number) vlO).doubleValue() <= 0) {
                plugin.config().warn("punishments.yml " + where + " entry #" + i + " invalid (needs vl > 0 and a valid action), skipped.");
                continue;
            }
            boolean enabled = !(m.get("enabled") instanceof Boolean b) || b;
            double repeat = m.get("repeat-every") instanceof Number n ? Math.max(0, n.doubleValue()) : 0;
            long dur = -1;
            if (a == PunishAction.TEMPBAN) {
                try {
                    dur = Durations.parse(String.valueOf(m.get("duration")));
                } catch (IllegalArgumentException ex) {
                    plugin.config().warn("punishments.yml " + where + " entry #" + i + ": bad duration, entry skipped.");
                    continue;
                }
            }
            Object r = m.get("reason");
            out.add(new Threshold(((Number) vlO).doubleValue(), a, enabled, repeat, dur,
                    r == null ? "Suspicious behaviour detected ({check})" : String.valueOf(r)));
        }
        return out;
    }

    /**
     * Evaluates the thresholds of the check that just flagged AND the combined (total) thresholds.
     * Non-removal actions run immediately. Among all removal actions (KICK / TEMPBAN / BAN) crossed
     * together only the most severe one runs, so a KICK can never swallow a TEMPBAN or BAN.
     */
    public void evaluate(PlayerState s, String flaggedCheck, double checkVl) {
        Pending best = scan(s, flaggedCheck, checkVl, flaggedCheck, null);
        best = scan(s, TOTAL_ID, s.totalVl(), flaggedCheck, best);
        if (best == null) return;
        if (System.currentTimeMillis() - s.lastPunishMs < guardMs) {
            s.firedPunishments.remove(best.key()); // too soon after another removal: retry on the next flag
            return;
        }
        execute(s, best.owner(), best.t(), best.vl(), flaggedCheck);
    }

    private record Pending(Threshold t, String key, String owner, double vl) {}

    private Pending scan(PlayerState s, String owner, double vl, String flaggedCheck, Pending best) {
        List<Threshold> list = listFor(owner);
        for (int i = 0; i < list.size(); i++) {
            Threshold t = list.get(i);
            if (!t.enabled() || vl < t.vl()) continue;
            String key = key(owner, i, t, vl);
            if (!s.firedPunishments.add(key)) continue;
            if (isRemoval(t.action())) {
                if (best == null || severity(t) > severity(best.t())) best = new Pending(t, key, owner, vl);
            } else {
                execute(s, owner, t, vl, flaggedCheck);
            }
        }
        return best;
    }

    private static String key(String owner, int index, Threshold t, double vl) {
        int bucket = t.repeatEvery() > 0 ? (int) ((vl - t.vl()) / t.repeatEvery()) : 0;
        return owner + "#" + index + "#" + bucket;
    }

    private List<Threshold> listFor(String owner) {
        return TOTAL_ID.equals(owner) ? totalThresholds : perCheck.getOrDefault(owner, defaults);
    }

    private static boolean isRemoval(PunishAction a) {
        return a == PunishAction.KICK || a.isBan();
    }

    private static long severity(Threshold t) {
        return switch (t.action()) {
            case KICK -> 1L;
            case TEMPBAN -> 10L + Math.max(0, t.durationMs()) / 1000L;
            case BAN -> Long.MAX_VALUE / 2;
            default -> 0L;
        };
    }

    /** After a rejoin: do not replay alerts/setbacks already triggered; removal thresholds stay armed. */
    public void seed(PlayerState s) {
        for (Map.Entry<String, Double> e : s.vlSnapshot().entrySet()) seedOwner(s, e.getKey(), e.getValue());
        seedOwner(s, TOTAL_ID, s.totalVl());
    }

    private void seedOwner(PlayerState s, String owner, double vl) {
        List<Threshold> list = listFor(owner);
        for (int i = 0; i < list.size(); i++) {
            Threshold t = list.get(i);
            if (!t.enabled() || isRemoval(t.action()) || vl < t.vl()) continue;
            s.firedPunishments.add(key(owner, i, t, vl));
        }
    }

    /** Re-arms thresholds of one owner (a check id or TOTAL_ID) once its VL dropped below them. */
    public void onDecay(PlayerState s, String owner, double newVl) {
        if (s.firedPunishments.isEmpty()) return;
        List<Threshold> list = listFor(owner);
        for (int i = 0; i < list.size(); i++) {
            if (newVl < list.get(i).vl()) {
                String prefix = owner + "#" + i + "#";
                s.firedPunishments.removeIf(k -> k.startsWith(prefix));
            }
        }
    }

    private void execute(PlayerState s, String owner, Threshold t, double vl, String flaggedCheck) {
        long now = System.currentTimeMillis();
        PunishAction a = t.action();
        String reason = t.reason().replace("{check}", owner).replace("{last-check}", flaggedCheck)
                .replace("{vl}", String.format(Locale.ROOT, "%.1f", vl));
        boolean banAllowed = !a.isBan() || autoBan;
        boolean real = (!a.needsEnforcement() || enforce) && banAllowed;
        String checkId = owner;

        long expires = a == PunishAction.TEMPBAN ? now + t.durationMs() : -1;
        if (!(real && a.isBan())) { // real bans are recorded by applyBan()
            plugin.storage().insertPunishment(new PunishmentRecord(now, s.uuid, s.name, checkId, a.name(), reason, vl, expires, !real, "PaiAC"));
        }

        if (!real) {
            String why = !enforce ? "DETECTION_ONLY" : "auto-ban-enabled is false";
            plugin.alerts().notice("&e[dry-run: " + why + "] &fwould " + a + " &f" + s.name + " &7(" + checkId + ", vl " + String.format(Locale.ROOT, "%.1f", vl) + ")");
            return;
        }

        Player p = s.player();
        switch (a) {
            case ALERT -> plugin.alerts().notice("&f" + s.name + " &7reached threshold &c" + checkId + " &7vl " + String.format(Locale.ROOT, "%.1f", vl));
            case LOG -> {
                s.verboseUntilMs = now + 600_000L;
                plugin.alerts().notice("&7Verbose evidence enabled for &f" + s.name + " &7(10 min)");
            }
            case CANCEL_ACTION -> {
                s.cancelActions(TOTAL_ID.equals(owner) ? flaggedCheck : owner, now + cancelMs);
                plugin.alerts().notice("&7Cancelling &f" + checkId + " &7actions of &f" + s.name + " &7for " + cancelMs + "ms");
            }
            case SETBACK -> {
                Location safe = s.safeLocation;
                if (p != null && safe != null && safe.getWorld() != null && safe.getWorld().equals(p.getWorld())) {
                    plugin.scheduler().teleport(p, safe.clone());
                    plugin.alerts().notice("&7Setback &f" + s.name + " &7(" + checkId + ")");
                }
            }
            case KICK -> {
                s.lastPunishMs = now;
                kick(p, plugin.config().msg("kick-screen", "&cRemoved by PaiAC.\n&7Reason: &f{reason}").replace("{reason}", reason));
                plugin.alerts().notice("&cKicked &f" + s.name + " &7(" + reason + ")");
            }
            case TEMPBAN, BAN -> {
                s.lastPunishMs = now;
                applyBan(s.uuid, s.name, reason, a == PunishAction.BAN ? -1 : t.durationMs(), "PaiAC", p);
            }
        }
    }

    /** Used by automatic punishments and by /paiac ban (explicit staff command, ignores enforcement mode). */
    public void applyBan(UUID id, String name, String reason, long durationMs, String by, Player online) {
        long now = System.currentTimeMillis();
        BanEntry b = new BanEntry(id, name, reason, now, durationMs < 0 ? -1 : now + durationMs, by);
        plugin.bans().ban(b);
        plugin.storage().insertPunishment(new PunishmentRecord(now, id, name, "manual", durationMs < 0 ? "BAN" : "TEMPBAN",
                reason, 0, b.expires(), false, by));
        plugin.alerts().notice("&cBanned &f" + name + " &7(" + (durationMs < 0 ? "permanent" : Durations.format(durationMs)) + ", " + reason + ")");
        if (online != null) kick(online, plugin.bans().screen(b));
    }

    public void kick(Player p, String message) {
        if (p == null) return;
        String colored = Colors.color(message);
        plugin.scheduler().runForPlayer(p, () -> p.kickPlayer(colored));
    }
}

package com.paimc.anticheat.storage;

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.config.Settings;

import java.io.File;
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.RejectedExecutionException;
import java.util.concurrent.ThreadPoolExecutor;
import java.util.concurrent.TimeUnit;
import java.util.concurrent.atomic.AtomicLong;

/**
 * SQLite persistence. The JDBC driver ships with Spigot/Paper, so it is loaded reflectively; when it is
 * missing PaiAC keeps running with in-memory state only. All SQL runs on one dedicated thread; the queue
 * is bounded and overflow is dropped (and counted) so a slow disk can never stall the game.
 */
public final class StorageService {
    private final PaiAC plugin;
    private Connection conn;
    private ThreadPoolExecutor exec;
    private boolean available;
    private boolean async = true;
    private final AtomicLong dropped = new AtomicLong();

    public StorageService(PaiAC plugin) {
        this.plugin = plugin;
    }

    public boolean available() { return available; }

    public long dropped() { return dropped.get(); }

    public void init(Settings s) {
        this.async = s.asyncStorage;
        try {
            Class.forName("org.sqlite.JDBC");
        } catch (ClassNotFoundException e) {
            plugin.getLogger().warning("SQLite driver (org.sqlite.JDBC) not found: running WITHOUT persistence "
                    + "(violations, evidence and bans live in memory only).");
            return;
        }
        try {
            File db = new File(plugin.getDataFolder(), s.storageFile);
            if (db.getParentFile() != null) db.getParentFile().mkdirs();
            conn = DriverManager.getConnection("jdbc:sqlite:" + db.getAbsolutePath());
            try (Statement st = conn.createStatement()) {
                st.execute("PRAGMA journal_mode=WAL");
                st.execute("PRAGMA synchronous=NORMAL");
                st.execute("CREATE TABLE IF NOT EXISTS violations(uuid TEXT NOT NULL, check_id TEXT NOT NULL, vl REAL NOT NULL, updated INTEGER NOT NULL, PRIMARY KEY(uuid, check_id))");
                st.execute("CREATE TABLE IF NOT EXISTS evidence(id INTEGER PRIMARY KEY AUTOINCREMENT, ts INTEGER NOT NULL, uuid TEXT NOT NULL, name TEXT, check_id TEXT NOT NULL, observed REAL, expected REAL, ping INTEGER, tps REAL, platform TEXT, mc_version TEXT, vl_before REAL, vl_after REAL, details TEXT)");
                st.execute("CREATE INDEX IF NOT EXISTS idx_evidence_uuid ON evidence(uuid, ts)");
                st.execute("CREATE TABLE IF NOT EXISTS punishments(id INTEGER PRIMARY KEY AUTOINCREMENT, ts INTEGER NOT NULL, uuid TEXT NOT NULL, name TEXT, check_id TEXT, action TEXT, reason TEXT, vl REAL, expires INTEGER, dry INTEGER, executor TEXT)");
                st.execute("CREATE TABLE IF NOT EXISTS bans(uuid TEXT PRIMARY KEY, name TEXT, reason TEXT, created INTEGER, expires INTEGER, by TEXT, active INTEGER NOT NULL DEFAULT 1)");
                st.execute("CREATE TABLE IF NOT EXISTS baselines(id INTEGER PRIMARY KEY AUTOINCREMENT, ts INTEGER NOT NULL, uuid TEXT NOT NULL, check_id TEXT NOT NULL, metric TEXT NOT NULL, v1 REAL, v2 REAL, v3 REAL, ping INTEGER)");
            }
            int cap = s.maxPendingEvidence;
            exec = new ThreadPoolExecutor(1, 1, 0L, TimeUnit.MILLISECONDS, new ArrayBlockingQueue<>(cap),
                    r -> {
                        Thread t = new Thread(r, "PaiAC-Storage");
                        t.setDaemon(true);
                        return t;
                    },
                    (r, ex) -> dropped.incrementAndGet());
            available = true;
            if (s.evidenceRetentionDays > 0) purgeOlderThan(s.evidenceRetentionDays);
        } catch (SQLException e) {
            plugin.getLogger().severe("SQLite init failed, continuing without persistence: " + e.getMessage());
            closeQuietly();
        }
    }

    private void run(Runnable r) {
        if (!available) return;
        if (!async) {
            r.run();
            return;
        }
        try {
            exec.execute(r);
        } catch (RejectedExecutionException e) {
            dropped.incrementAndGet();
        }
    }

    private void sql(String what, SqlTask t) {
        run(() -> {
            try {
                t.run();
            } catch (SQLException e) {
                plugin.getLogger().warning("Storage error (" + what + "): " + e.getMessage());
            }
        });
    }

    private interface SqlTask {
        void run() throws SQLException;
    }

    // ---------------------------------------------------------------- writes
    public void insertEvidence(Evidence e) {
        sql("evidence", () -> {
            try (PreparedStatement ps = conn.prepareStatement(
                    "INSERT INTO evidence(ts,uuid,name,check_id,observed,expected,ping,tps,platform,mc_version,vl_before,vl_after,details) VALUES(?,?,?,?,?,?,?,?,?,?,?,?,?)")) {
                ps.setLong(1, e.ts());
                ps.setString(2, e.uuid().toString());
                ps.setString(3, e.name());
                ps.setString(4, e.checkId());
                ps.setDouble(5, e.observed());
                ps.setDouble(6, e.expected());
                ps.setInt(7, e.ping());
                ps.setDouble(8, e.tps());
                ps.setString(9, e.platform());
                ps.setString(10, e.mcVersion());
                ps.setDouble(11, e.vlBefore());
                ps.setDouble(12, e.vlAfter());
                ps.setString(13, e.details());
                ps.executeUpdate();
            }
        });
    }

    public void saveViolations(UUID id, Map<String, Double> vls) {
        long now = System.currentTimeMillis();
        sql("save-vl", () -> {
            try (PreparedStatement del = conn.prepareStatement("DELETE FROM violations WHERE uuid=?")) {
                del.setString(1, id.toString());
                del.executeUpdate();
            }
            try (PreparedStatement ps = conn.prepareStatement("INSERT INTO violations(uuid,check_id,vl,updated) VALUES(?,?,?,?)")) {
                for (Map.Entry<String, Double> en : vls.entrySet()) {
                    if (en.getValue() <= 0) continue;
                    ps.setString(1, id.toString());
                    ps.setString(2, en.getKey());
                    ps.setDouble(3, en.getValue());
                    ps.setLong(4, now);
                    ps.addBatch();
                }
                ps.executeBatch();
            }
        });
    }

    public void insertPunishment(PunishmentRecord r) {
        sql("punishment", () -> {
            try (PreparedStatement ps = conn.prepareStatement(
                    "INSERT INTO punishments(ts,uuid,name,check_id,action,reason,vl,expires,dry,executor) VALUES(?,?,?,?,?,?,?,?,?,?)")) {
                ps.setLong(1, r.ts());
                ps.setString(2, r.uuid().toString());
                ps.setString(3, r.name());
                ps.setString(4, r.checkId());
                ps.setString(5, r.action());
                ps.setString(6, r.reason());
                ps.setDouble(7, r.vl());
                ps.setLong(8, r.expires());
                ps.setInt(9, r.dryRun() ? 1 : 0);
                ps.setString(10, r.executor());
                ps.executeUpdate();
            }
        });
    }

    public void upsertBan(BanEntry b) {
        sql("ban", () -> {
            try (PreparedStatement ps = conn.prepareStatement(
                    "INSERT OR REPLACE INTO bans(uuid,name,reason,created,expires,by,active) VALUES(?,?,?,?,?,?,1)")) {
                ps.setString(1, b.uuid().toString());
                ps.setString(2, b.name());
                ps.setString(3, b.reason());
                ps.setLong(4, b.created());
                ps.setLong(5, b.expires());
                ps.setString(6, b.by());
                ps.executeUpdate();
            }
        });
    }

    public void deactivateBan(UUID id) {
        sql("unban", () -> {
            try (PreparedStatement ps = conn.prepareStatement("UPDATE bans SET active=0 WHERE uuid=?")) {
                ps.setString(1, id.toString());
                ps.executeUpdate();
            }
        });
    }

    public void insertBaseline(UUID id, String checkId, String metric, double v1, double v2, double v3, int ping) {
        sql("baseline", () -> {
            try (PreparedStatement ps = conn.prepareStatement(
                    "INSERT INTO baselines(ts,uuid,check_id,metric,v1,v2,v3,ping) VALUES(?,?,?,?,?,?,?,?)")) {
                ps.setLong(1, System.currentTimeMillis());
                ps.setString(2, id.toString());
                ps.setString(3, checkId);
                ps.setString(4, metric);
                ps.setDouble(5, v1);
                ps.setDouble(6, v2);
                ps.setDouble(7, v3);
                ps.setInt(8, ping);
                ps.executeUpdate();
            }
        });
    }

    private void purgeOlderThan(int days) {
        long cutoff = System.currentTimeMillis() - days * 86_400_000L;
        sql("purge", () -> {
            try (PreparedStatement ps = conn.prepareStatement("DELETE FROM evidence WHERE ts < ?")) {
                ps.setLong(1, cutoff);
                ps.executeUpdate();
            }
            try (PreparedStatement ps = conn.prepareStatement("DELETE FROM baselines WHERE ts < ?")) {
                ps.setLong(1, cutoff);
                ps.executeUpdate();
            }
        });
    }

    // ---------------------------------------------------------------- reads
    public CompletableFuture<Map<String, Double>> loadViolations(UUID id) {
        CompletableFuture<Map<String, Double>> f = new CompletableFuture<>();
        if (!available) {
            f.complete(new HashMap<>());
            return f;
        }
        run(() -> {
            Map<String, Double> out = new HashMap<>();
            try (PreparedStatement ps = conn.prepareStatement("SELECT check_id, vl FROM violations WHERE uuid=?")) {
                ps.setString(1, id.toString());
                try (ResultSet rs = ps.executeQuery()) {
                    while (rs.next()) out.put(rs.getString(1), rs.getDouble(2));
                }
            } catch (SQLException e) {
                plugin.getLogger().warning("Storage error (load-vl): " + e.getMessage());
            }
            f.complete(out);
        });
        if (!f.isDone() && dropped.get() > 0) {
            // queue was full: do not leave the future hanging forever
            f.completeOnTimeout(new HashMap<>(), 5, TimeUnit.SECONDS);
        }
        return f;
    }

    /** Blocking; call only during startup before any async work has been queued. */
    public List<BanEntry> loadActiveBansBlocking() {
        List<BanEntry> out = new ArrayList<>();
        if (!available) return out;
        try (Statement st = conn.createStatement();
             ResultSet rs = st.executeQuery("SELECT uuid,name,reason,created,expires,by FROM bans WHERE active=1")) {
            while (rs.next()) {
                out.add(new BanEntry(UUID.fromString(rs.getString(1)), rs.getString(2), rs.getString(3),
                        rs.getLong(4), rs.getLong(5), rs.getString(6)));
            }
        } catch (SQLException e) {
            plugin.getLogger().warning("Could not load bans: " + e.getMessage());
        }
        return out;
    }

    /** Last evidence rows for a player (blocking, command thread only, small limit). */
    public CompletableFuture<List<String>> recentEvidence(UUID id, int limit) {
        CompletableFuture<List<String>> f = new CompletableFuture<>();
        if (!available) {
            f.complete(List.of());
            return f;
        }
        run(() -> {
            List<String> rows = new ArrayList<>();
            try (PreparedStatement ps = conn.prepareStatement(
                    "SELECT ts,check_id,observed,expected,vl_after,details FROM evidence WHERE uuid=? ORDER BY ts DESC LIMIT ?")) {
                ps.setString(1, id.toString());
                ps.setInt(2, limit);
                try (ResultSet rs = ps.executeQuery()) {
                    while (rs.next()) {
                        rows.add(rs.getString(2) + " vl=" + String.format("%.1f", rs.getDouble(5))
                                + " obs=" + String.format("%.3f", rs.getDouble(3))
                                + " exp=" + String.format("%.3f", rs.getDouble(4))
                                + " " + rs.getString(6));
                    }
                }
            } catch (SQLException e) {
                plugin.getLogger().warning("Storage error (recent-evidence): " + e.getMessage());
            }
            f.complete(rows);
        });
        f.completeOnTimeout(List.of(), 5, TimeUnit.SECONDS);
        return f;
    }

    // ---------------------------------------------------------------- lifecycle
    public void close() {
        if (exec != null) {
            exec.shutdown();
            try {
                if (!exec.awaitTermination(8, TimeUnit.SECONDS)) {
                    plugin.getLogger().warning("Storage queue did not drain in time; some data was lost.");
                    exec.shutdownNow();
                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
        }
        closeQuietly();
        available = false;
    }

    private void closeQuietly() {
        try {
            if (conn != null) conn.close();
        } catch (SQLException ignored) {
            // nothing useful to do
        }
        conn = null;
    }
}

package com.paimc.anticheat.util;

/** Fixed-capacity ring buffer of doubles with simple statistics. Not thread-safe (owned by one player thread). */
public final class DoubleRing {
    private final double[] buf;
    private int head;
    private int size;

    public DoubleRing(int capacity) {
        if (capacity < 1) throw new IllegalArgumentException("capacity must be >= 1");
        this.buf = new double[capacity];
    }

    public void add(double v) {
        if (size < buf.length) {
            buf[(head + size) % buf.length] = v;
            size++;
        } else {
            buf[head] = v;
            head = (head + 1) % buf.length;
        }
    }

    public int size() { return size; }

    public int capacity() { return buf.length; }

    /** i = 0 is the oldest sample. */
    public double get(int i) {
        if (i < 0 || i >= size) throw new IndexOutOfBoundsException("index " + i + " size " + size);
        return buf[(head + i) % buf.length];
    }

    public void clear() { head = 0; size = 0; }

    public double mean() {
        if (size == 0) return 0;
        double s = 0;
        for (int i = 0; i < size; i++) s += get(i);
        return s / size;
    }

    /** Population standard deviation. */
    public double stdDev() {
        if (size < 2) return 0;
        double m = mean();
        double s = 0;
        for (int i = 0; i < size; i++) {
            double d = get(i) - m;
            s += d * d;
        }
        return Math.sqrt(s / size);
    }

    public double min() {
        if (size == 0) return 0;
        double r = Double.POSITIVE_INFINITY;
        for (int i = 0; i < size; i++) r = Math.min(r, get(i));
        return r;
    }

    public double max() {
        if (size == 0) return 0;
        double r = Double.NEGATIVE_INFINITY;
        for (int i = 0; i < size; i++) r = Math.max(r, get(i));
        return r;
    }
}

package com.paimc.anticheat.util;

import java.util.Locale;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/** Parses durations such as "30m", "2h", "1d12h", "perm". */
public final class Durations {
    private static final Pattern FULL = Pattern.compile("^(\\d+[smhdw])+$");
    private static final Pattern PART = Pattern.compile("(\\d+)([smhdw])");

    private Durations() {}

    /** @return milliseconds, or -1 for permanent. */
    public static long parse(String input) {
        if (input == null || input.isBlank()) throw new IllegalArgumentException("empty duration");
        String t = input.trim().toLowerCase(Locale.ROOT);
        if (t.equals("perm") || t.equals("permanent") || t.equals("-1")) return -1;
        if (!FULL.matcher(t).matches()) throw new IllegalArgumentException("invalid duration: " + input);
        Matcher m = PART.matcher(t);
        long total = 0;
        while (m.find()) {
            long n = Long.parseLong(m.group(1));
            long unit = switch (m.group(2)) {
                case "s" -> 1000L;
                case "m" -> 60_000L;
                case "h" -> 3_600_000L;
                case "d" -> 86_400_000L;
                default -> 604_800_000L;
            };
            total += n * unit;
        }
        if (total <= 0) throw new IllegalArgumentException("duration must be positive: " + input);
        return total;
    }

    public static String format(long ms) {
        if (ms < 0) return "permanent";
        long s = ms / 1000;
        long d = s / 86400; s %= 86400;
        long h = s / 3600; s %= 3600;
        long m = s / 60; s %= 60;
        StringBuilder sb = new StringBuilder();
        if (d > 0) sb.append(d).append("d ");
        if (h > 0) sb.append(h).append("h ");
        if (m > 0) sb.append(m).append("m ");
        if (s > 0 || sb.length() == 0) sb.append(s).append("s");
        return sb.toString().trim();
    }
}

package com.paimc.anticheat.util;

import org.bukkit.util.BoundingBox;
import org.bukkit.util.Vector;

public final class Geometry {
    private Geometry() {}

    /** Distance from a point to the closest point of the box (0 when inside). */
    public static double distanceToBox(double x, double y, double z, BoundingBox b) {
        double cx = Math.max(b.getMinX(), Math.min(x, b.getMaxX()));
        double cy = Math.max(b.getMinY(), Math.min(y, b.getMaxY()));
        double cz = Math.max(b.getMinZ(), Math.min(z, b.getMaxZ()));
        double dx = x - cx, dy = y - cy, dz = z - cz;
        return Math.sqrt(dx * dx + dy * dy + dz * dz);
    }

    public static Vector direction(float yawDeg, float pitchDeg) {
        double yaw = Math.toRadians(yawDeg);
        double pitch = Math.toRadians(pitchDeg);
        double xz = Math.cos(pitch);
        return new Vector(-xz * Math.sin(yaw), -Math.sin(pitch), xz * Math.cos(yaw));
    }

    /** Angle in degrees between two vectors (0 when either is zero-length). */
    public static double angleDeg(Vector a, Vector b) {
        double la = a.length(), lb = b.length();
        if (la < 1.0E-9 || lb < 1.0E-9) return 0;
        double d = a.dot(b) / (la * lb);
        d = Math.max(-1.0, Math.min(1.0, d));
        return Math.toDegrees(Math.acos(d));
    }

    public static float wrapDegrees(float d) {
        d %= 360f;
        if (d >= 180f) d -= 360f;
        if (d < -180f) d += 360f;
        return d;
    }
}

    private final ConcurrentHashMap<String, Long> lastAlert = new ConcurrentHashMap<>();

    public void alert(PlayerState s, String checkId, double observed, double expected, double vl, int ping, double tps, String details) {
        long now = System.currentTimeMillis();
        String key = s.uuid + ":" + checkId;
        Long prev = lastAlert.get(key);

        lastAlert.put(key, now);

        String template = plugin.config().msg("alert",
                "{prefix}&f{player} &7failed &c{check} &7(vl &f{vl}&7) &8| &7obs &f{observed} &7exp &f{expected} &8| &7{ping}ms {tps}tps");

                .replace("{total}", String.format("%.1f", s.totalVl()));
        plugin.getLogger().info(org.bukkit.ChatColor.stripColor(Colors.color(msg)) + " | total vl " + String.format("%.1f", s.totalVl()) + " | " + details);
        sendToStaff(msg);
    }

    /** Free-form staff notice (threshold actions, dry-run notices...). */
    public void notice(String message) {
        String msg = Colors.color(plugin.config().msg("prefix", "&8[&bPaiAC&8] &7") + message);
        plugin.getLogger().info(org.bukkit.ChatColor.stripColor(msg));
        sendToStaffRaw(msg);
    }

    private String apply(String t, String player, String check, double vl, double obs, double exp, int ping, double tps) {
        return t.replace("{prefix}", plugin.config().msg("prefix", "&8[&bPaiAC&8] &7"))
                .replace("{player}", player)
                .replace("{check}", check)
                .replace("{vl}", String.format("%.1f", vl))
                .replace("{observed}", Colors.fmt(obs))
                .replace("{expected}", Colors.fmt(exp))
                .replace("{ping}", String.valueOf(ping))
                .replace("{tps}", String.format("%.1f", tps));
    }

    private void sendToStaff(String template) {
        sendToStaffRaw(Colors.color(template));
    }

    private void sendToStaffRaw(String colored) {
        for (Player p : Bukkit.getOnlinePlayers()) {
            PlayerState st = plugin.states().get(p.getUniqueId());
            if (st != null && st.alertsEnabled && p.hasPermission("paiac.alerts")) p.sendMessage(colored);
        }
    }

    public void forget(PlayerState s) {
        lastAlert.keySet().removeIf(k -> k.startsWith(s.uuid.toString()));
    }
}

```java
package com.paimc.anticheat.violation;

import com.paimc.anticheat.PaiAC;
import com.paimc.anticheat.checks.Check;
import com.paimc.anticheat.config.Settings;
import com.paimc.anticheat.player.PlayerState;
import com.paimc.anticheat.punishment.PunishmentManager;
import com.paimc.anticheat.util.CompatUtil;
import org.bukkit.entity.Player;

import java.util.Map;

/** Turns a check failure into VL, evidence, an alert and a punishment evaluation. */
public final class ViolationManager {
    private final PaiAC plugin;

    public ViolationManager(PaiAC plugin) {
        this.plugin = plugin;
    }

    public void flag(Check check, PlayerState s, double observed, double expected, String details) {
        Player p = s.player();
        if (p == null) return;
        long now = System.currentTimeMillis();
        if (s.isExempt(now) || p.hasPermission("paiac.bypass." + check.id())) return;

        Settings g = plugin.settings();
        double tps = plugin.tps().tps();
        int ping = CompatUtil.ping(p);
        if (tps < g.lagSkipTps || ping > g.lagSkipPingMs) {
            check.stats().lagSkips.increment();
            return;
        }

        double before = s.vl(check.id());
        double after = s.addVl(check.id(), check.settings().violationPoints, g.maxVl);
        check.stats().flags.increment();

        plugin.evidence().record(s, p, check.id(), observed, expected, ping, tps, before, after, details);
        plugin.alerts().alert(s, check.id(), observed, expected, after, ping, tps, details);
        plugin.punishments().evaluate(s, check.id(), after);
    }

    /** Runs asynchronously once per minute; touches only PlayerState maps (no Bukkit state). */
    public void decayTick() {
        double dec = plugin.settings().decayPerMinute;
        long retention = plugin.settings().stateRetentionSeconds * 1000L;
        long now = System.currentTimeMillis();
        for (PlayerState s : plugin.states().all()) {
            if (dec > 0) {
                for (Map.Entry<String, Double> e : s.vlSnapshot().entrySet()) {
                    double nv = Math.max(0, e.getValue() - dec);
                    s.setVl(e.getKey(), nv);
                    plugin.punishments().onDecay(s, e.getKey(), nv);
                }
            }
            plugin.punishments().onDecay(s, PunishmentManager.TOTAL_ID, s.totalVl());
            s.pruneIdle(now, retention);
        }
    }
}

`src/test/java/com/paimc/anticheat/DoubleRingTest.java`:

```java
package com.paimc.anticheat;

import com.paimc.anticheat.util.DoubleRing;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertThrows;

class DoubleRingTest {
    @Test
    void overwritesOldestWhenFull() {
        DoubleRing r = new DoubleRing(3);
        for (int i = 1; i <= 5; i++) r.add(i);
        assertEquals(3, r.size());
        assertEquals(3.0, r.get(0));
        assertEquals(5.0, r.get(2));
        assertEquals(4.0, r.mean(), 1e-9);
    }

    @Test
    void statistics() {
        DoubleRing r = new DoubleRing(8);
        for (double v : new double[]{2, 4, 4, 4, 5, 5, 7, 9}) r.add(v);
        assertEquals(5.0, r.mean(), 1e-9);
        assertEquals(2.0, r.stdDev(), 1e-9);
        assertEquals(2.0, r.min());
        assertEquals(9.0, r.max());
    }

    @Test
    void emptyAndInvalid() {
        DoubleRing r = new DoubleRing(2);
        assertEquals(0.0, r.mean());
        assertEquals(0.0, r.stdDev());
        assertThrows(IndexOutOfBoundsException.class, () -> r.get(0));
        assertThrows(IllegalArgumentException.class, () -> new DoubleRing(0));
    }
}

package com.paimc.anticheat;

import com.paimc.anticheat.util.Durations;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertThrows;

class DurationsTest {
    @Test
    void parsesUnitsAndCombinations() {
        assertEquals(30_000L, Durations.parse("30s"));
        assertEquals(90 * 60_000L, Durations.parse("1h30m"));
        assertEquals(86_400_000L, Durations.parse("1d"));
        assertEquals(604_800_000L, Durations.parse("1W"));
    }

    @Test
    void permanent() {
        assertEquals(-1L, Durations.parse("perm"));
        assertEquals(-1L, Durations.parse("-1"));
    }

    void rejectsGarbage() {

        assertThrows(IllegalArgumentException.class, () -> Durations.parse("10"));
        assertThrows(IllegalArgumentException.class, () -> Durations.parse("0m"));
        assertThrows(IllegalArgumentException.class, () -> Durations.parse(""));
    }

    @Test
    void formats() {
        assertEquals("1h 30m", Durations.format(90 * 60_000L));
        assertEquals("permanent", Durations.format(-1));
    }
