# lm32dec — A LatticeMico32 (LM32) Decompiler for IDA Pro

`lm32dec` is a high-fidelity decompiler for firmware and binaries targeting the **LatticeMico32 (LM32)** 32-bit RISC soft processor architecture. It operates both as an interactive **Hex-Rays-style decompiler plugin for IDA Pro 9.x / 8.x** and as a **standalone headless decompiler and lifter** requiring zero IDA dependencies.

The plugin provides native dual-endian support:
* **Big-Endian**: Standard Lattice Semiconductor softcore designs, FPGA SoCs (Milkymist, White Rabbit, RTEMS, Linux), and QEMU LM32 targets.
* **Little-Endian**: Proprietary embedded security coprocessor.

The IDA processor module is leveraged strictly for instruction decoding (`insn_t`), while lifting, static single assignment (SSA) def-use web analysis, virtual variable synthesis, calling convention recovery, control-flow restructuring, and C code generation are entirely custom:

```mermaid
flowchart LR
    Decoder["1. Decoder (insn_t / binary)"] --> Lifter["2. IR Lifter"]
    Lifter --> CFG["3. CFG Builder"]
    CFG --> Struct["4. Structurer"]
    Struct --> Frame["5. Frame Analysis"]
    Frame --> ABI["6. ABI & Signature"]
    ABI --> Vars["7. Def-Use Webs & SSA"]
    Vars --> Opt["8. AST & String Opt"]
    Opt --> CGen["9. Hex-Rays C Emitter"]
```

## What It Produces

```c
/*
 * Decompiled by lm32dec -- LatticeMico32 (LM32, little-endian).
 */

void sub_0(int a0, int a1)
{
    sub_20(a0, a1 + 1);
    return;
}

int sub_300(int a0, int a1, int a2)
{
    int v0;
    int v1;
    int v2;

    *(_DWORD *)0xE0000010 = 0xFFFFFFFF;
    v0 = 0x80001000;
    while (1) {
        v1 = *(_DWORD *)v0;
        if (v1 != 0) {
            *(_DWORD *)v0 = 0;
            break;
        }
    }
    if (a0 == 1) {
        v2 = __rcsr(IE);
        __wcsr(IE, v2 & ~1);
        (*((void (*)(int, int))v1))(a1, a2);
        __wcsr(IE, v2);
    }
    return v1;
}

int sub_450(int a0, int a1, int a2, int a3, int a4, int a5, int a6, int a7, int arg_0)
{
    int var_14;
    int var_18;
    int var_1C;

    var_1C = a0;
    var_18 = a1;
    var_14 = arg_0;
    sub_620("Device init: status = 0x%08X (flags = %d)\n", a0, arg_0);
    return a0 + a1;
}
```

* **Virtual Variables (`v0, v1, ...`)**: Eliminates raw register clutter (`r1..r25`) by tracking live ranges and promoting values to clean C local variables.
* **Function Parameters (`a0..a7`, `arg_0..`)**: Up to 8 register arguments (`r1` through `r8`) and incoming stack slots above caller frame are bound directly to parameter names.
* **Hex-Rays Pointer Dereferencing**: Emits standard Hex-Rays typed dereference expressions (`*(_DWORD *)ptr`, `*(short *)ptr`, `*(_BYTE *)ptr`, `*ptr`, `ptr[idx]`).
* **Hardware Intrinsics**: Control and Status Register operations (`__rcsr`, `__wcsr`) render with canonical register names (`IE`, `IM`, `IP`, `ICC`, `DCC`, `CC`, `CFG`, `EBA`, etc.), alongside system intrinsics (`__break()`, `__scall()`).
* **Global Symbol & String Resolution**: Data and code addresses automatically resolve to symbolic names in IDA, and pointer arguments render as formatted C string literals.
* **Control-Flow Recovery**: Reconstructs `if`/`else`, `while(1)`, `while(cond)`, `do-while`, loop `break`/`continue`, relational compares, and switch jump tables.
* **Stack Frame Recovery**: Automatically detects frame allocations, strips prologue/epilogue callee-saved register spills (`r11..r25`, `gp`, `fp`, `ra`), and binds stack offsets to local variables (`var_X`).

## Key Capabilities & Architectural Enhancements

### 1. Dual-Endian Decoding & Zero-Flag IR Lifter 
* **Fixed 32-bit Instruction Decoding**: Decodes all LM32 32-bit instructions with full support for both Big-Endian and Little-Endian byte orders.
* **Zero-Flag Architecture Support**: LM32 features no status/condition flags; compare-and-branch instructions (`be`, `bne`, `bge`, `bgeu`, `bgt`, `bgtu`) test registers directly. The lifter models these cleanly as high-level relational expressions.
* **Hardwired Zero Register (`r0`)**: Reads from `r0` fold to literal `0`; writes to `r0` (used for discards or flags) are preserved as pure side effects or safely eliminated.
* **Switch Table Identification**: Recognizes indirect branch sequences (`lshift -> add -> lw -> b rX`) and extracts jump tables, case bounds, and dispatch targets.

### 2. Stack Frame Analysis & Callee-Saved Register Stripping 
* **Prologue & Epilogue Identification**: Identifies stack allocations (`addi r28, r28, -frame_size`), frame pointer updates (`addi r27, r28, ...`), and stack deallocations.
* **Callee-Saved Spill Elimination**: Detects prologue saves and epilogue restores for `r11`–`r25`, `gp` (`r26`), `fp` (`r27`), and `ra` (`r29`), completely stripping them from the pseudocode AST.
* **Stack Variable Categorization**: Categorizes negative and positive frame offsets into local variables (`var_X`) and incoming stack arguments (`arg_X`).

### 3. LM32 EABI Calling Convention & Signature Synthesis 
* **Register Arguments (`r1`–`r8`)**: Backward iterative dataflow liveness analysis detects active register parameters at function entry (`a0` through `a7`).
* **Stack Arguments (`arg_0, arg_4, ...`)**: Incoming stack slots accessed above the caller's frame are promoted to function parameters.
* **Return Value Inference**: Verifies reaching definitions of `r1` (32-bit) and `r2` (64-bit high word) at return sites (`b r29`), inferring `void`, `int`, or pointer return types.
* **Caller Consensus & Call Argument Folding**: Cross-references call sites across the database to reach consensus on parameter counts, folding reaching argument assignments directly into call statements (`sub_20(a0, a1 + 1)`).

### 4. SSA-Style Def-Use Webs & Virtual Variable Recovery 
* **Iterative Reaching Definitions**: Tracks active register definitions, kills, and clobbers (including call clobbers) across basic blocks.
* **Union-Find Live Range Splitting**: Merges reaching definitions and uses into disjoint live ranges, splitting independent reuses of machine registers into separate virtual variables (`v0`, `v1`, ...).
* **Copy Propagation & Inlining**: Folds single-use register copies (`v1 = v0`) and pure address arithmetic directly into memory dereferences and call arguments.
* **Dead Assignment Elimination**: Eliminates unused intermediate assignments while safeguarding return value registers (`r1`/`r2`).

### 5. Hex-Rays Style Memory & Symbol Representation 
* **Standard Type Casts**:
  * 32-bit: `*(_DWORD *)addr`
  * 16-bit unsigned: `*(_WORD *)addr`
  * 16-bit signed: `*(short *)addr`
  * 8-bit unsigned: `*(_BYTE *)addr`
  * 8-bit signed: `*(char *)addr`
* **Typed Pointer Expressions**: When variables are typed as pointers (`int *`, `char *`), emits clean dereferences (`*ptr`) and array indexing (`ptr[i]`) without redundant casts.
* **Symbolic Name Resolution**: Addresses matching named data or code symbols in IDA render directly as identifiers.
* **String Literals**: Quoted C string literals are automatically formatted and escaped for pointer arguments.

### 6. Interactive Decompiler View & UX 
* **Dense Multi-Instruction EA Anchoring**: 100% of contributing instruction EAs are mapped bidirectionally (`line_to_eas` and `ea_to_line`), ensuring seamless navigation across all basic blocks.
* **Bidirectional Disassembly $\leftrightarrow$ Pseudocode Synchronization**:
  * Selecting any instruction in `IDA View-A` immediately scrolls and highlights the corresponding decompiled line.
  * Navigating in the pseudocode viewer synchronizes IDA's disassembly cursor without stealing focus.
  * Pressing **`Tab`** switches between Disassembly and Pseudocode at the matching instruction address.
* **Identifier Occurrence Highlighting**: Placing the cursor on any variable, parameter, or symbol highlights all occurrences across the function.
* **Navigation History Stack**: Double-clicking, pressing **`Enter`**, or pressing **`Space`** on a function call navigates to that function; pressing **`Esc`** returns directly to the caller.

### 7. Hex-Rays Interactive Shortcuts
`lm32dec` implements the full suite of interactive AST customizations:
* **Immediate Format Conversions**:
  * **`H`**: Toggle number constant representation between Hexadecimal and Decimal.
  * **`O`**: Convert numeric immediate to offset / symbol reference.
  * **`R`**: Convert constant to character or multi-byte literal (`'A'`, `'\n'`, `'RIFF'`).
  * **`_`** / **`-`**: Invert sign of number (`-1` vs `0xFFFFFFFF`).
  * **`~`**: Bitwise negation (`~0` vs `0xFFFFFFFF`).
* **Control-Flow & Cast Toggles**:
  * **`I`**: Invert if-condition and swap `then` / `else` branch blocks.
  * **`\`**: Toggle display of explicit type casts on pointer dereferences.
* **Code Annotations & Customizations**:
  * **`/`** or **`;`**: Add, edit, or remove persistent statement comments (`// comment`).
  * **`N`**: Rename variable, parameter, stack frame member, or function symbol.
  * **`Y`**: Set variable type or edit function prototype (applied to IDA's type system via `ida_typeinf.apply_cdecl`).
  * **`Del`**: Reset custom formatting, comment, variable rename, or if-inversion back to default.
* **Navigation & Analysis**:
  * **`X`**: Jump to cross-references (opens IDA native xrefs dialog).
  * **`B`**: Jump between matching opening and closing curly braces (`{` $\leftrightarrow$ `}`).
  * **`F5`**: Refresh decompilation.
  * **`Ctrl-F5`**: Batch decompile entire database and export to a `.c` file.

### 8. Netnode & Desktop Layout Persistence
* **Database Netnode (`$ lm32dec`)**: All analyst modifications (variable renames, types, function prototypes, immediate formatting, comments, if-inversions, and sync preferences) are saved directly in the `.idb` / `.i64` file.
* **Desktop Layout Manager**: Restores open decompiler tabs, docking positions, and cursor locations upon reopening databases.
* **Headless Fallback**: Transparent in-memory storage fallback for command-line execution and headless unit tests.

### 9. High Performance
* **Single Function**: ~7.7 ms average decompilation time.
* **Full Firmware Benchmark**: Decompiled all 251 functions (20,789 lines of C) in `sample.i64` in **1.94 seconds** with 100% instruction EA anchoring.

## LM32 Architecture & Register Conventions

The LatticeMico32 is a 32-bit Harvard architecture RISC microprocessor:

### General Purpose Registers (GPRs)
| Register | Name | Role | Preservation |
| :--- | :--- | :--- | :--- |
| **`r0`** | `zero` | Constant 0 (writes ignored, reads return 0) | — |
| **`r1`–`r8`** | `a0`–`a7` | Function arguments; `r1` return value (`r2` high 32-bit return) | Caller-saved |
| **`r9`–`r10`** | `t0`–`t1` | Temporary scratch registers | Caller-saved |
| **`r11`–`r25`** | `s0`–`s14` | Saved registers | Callee-saved |
| **`r26`** | `gp` | Global Pointer | Callee-saved |
| **`r27`** | `fp` | Frame Pointer | Callee-saved |
| **`r28`** | `sp` | Stack Pointer | Callee-saved |
| **`r29`** | `ra` | Return Address / Link Register | Caller-saved |
| **`r30`** | `ea` | Exception Address | Special |
| **`r31`** | `ba` | Breakpoint Address | Special |

### Control and Status Registers (CSRs)
| CSR ID | Name | Description |
| :--- | :--- | :--- |
| **0** | `IE` | Interrupt Enable |
| **1** | `IM` | Interrupt Mask |
| **2** | `IP` | Interrupt Pending |
| **3** | `ICC` | Instruction Cache Control |
| **4** | `DCC` | Data Cache Control |
| **5** | `CC` | Cycle Counter |
| **6** | `CFG` | Configuration Register |
| **7** | `EBA` | Exception Base Address |
| **8** | `DC` | Debug Control |
| **9** | `DEBA` | Debug Exception Base Address |
| **14** | `JTX` | JTAG Transmit |
| **15** | `JRX` | JTAG Receive |
| **16..19** | `BP0`..`BP3` | Breakpoint Registers 0–3 |
| **24..27** | `WP0`..`WP3` | Watchpoint Registers 0–3 |

## How to Run

### As an IDA Pro Plugin
1. Open your LM32 binary or firmware dump in IDA Pro (using the `lm32` processor module in big-endian or little-endian mode).
2. Copy `lm32dec_plugin.py` and the `lm32dec/` package into IDA's plugins folder:
   ```cmd
   copy lm32dec_plugin.py "%APPDATA%\Hex-Rays\IDA Pro\plugins\"
   xcopy /E /I /Y lm32dec "%APPDATA%\Hex-Rays\IDA Pro\plugins\lm32dec"
   ```
3. Open any function in IDA Pro and press **`F5`** (or **`Ctrl-Shift-S`**) on any instruction.

### Headless (Command-Line CLI)
Decompile raw binary dumps directly without requiring IDA Pro:

```bash
# Decompile entire firmware image to a C file (Big-Endian default)
python -m lm32dec firmware.bin -o firmware.c

# Decompile Little-Endian firmware 
python -m lm32dec sample.bin --endian little -o coprocessor.c

# Decompile a specific function by address
python -m lm32dec firmware.bin --func 0x00000300

# Specify custom base and entry points
python -m lm32dec dump.bin --base 0x00000000 --entry 0x00000000 --entry 0x00000400
```

```py
"""
lm32dec -- an interactive and headless decompiler for the LatticeMico32 (LM32) processor.

Supports both Big-Endian (standard LM32) and Little-Endian (PS Vita LM32 coprocessors).
Runs headless with zero IDA dependencies, and integrates seamlessly as a Hex-Rays parity
interactive plugin inside IDA Pro.

Pipeline:
    decoder -> lifter -> cfg -> frame -> callargs -> opt -> abi -> vars -> structure -> cgen
"""

from . import decoder, cfg, opt, frame, callargs, structure, cgen, loader, abi, vars
from .names import Namer

__version__ = "1.0.0"

BANNER = [
    "/*",
    " * Decompiled by lm32dec -- LatticeMico32 (LM32) Decompiler.",
    " * r0..r31 / gp / fp / sp / ra / ea / ba are machine registers.",
    " * *(_DWORD *), *(_WORD *), *(_BYTE *) dereference memory.",
    " * CSR registers accessed via __rcsr / __wcsr intrinsics.",
    " * Cross-function tail jumps render as JUMPOUT().",
    " */",
    "",
]


class Function:
    def __init__(self, entry, name, func, tree, lines, line_eas=None, line_to_eas=None, ea_to_line=None, header_count=None):
        self.entry = entry
        self.name = name
        self.cfg = func
        self.tree = tree
        self.lines = lines
        self.line_eas = line_eas if line_eas is not None else getattr(lines, "line_eas", None)
        self.line_to_eas = line_to_eas if line_to_eas is not None else getattr(lines, "line_to_eas", {})
        self.ea_to_line = ea_to_line if ea_to_line is not None else getattr(lines, "ea_to_line", {})
        self.header_count = header_count if header_count is not None else getattr(lines, "header_count", 0)


class Program:
    def __init__(self, image, base, insns, funcs, namer, is_be=True):
        self.image = image
        self.base = base
        self.insns = insns
        self.funcs = funcs
        self.namer = namer
        self.is_be = is_be

    def listing(self, banner=True):
        out = list(BANNER) if banner else []
        for entry in sorted(self.funcs):
            out.extend(self.funcs[entry].lines)
            out.append("")
        return "\n".join(out)


def decompile_image(image, entries, base=0, is_be=True, code_names=None):
    insns, calls = decoder.decode(image, entries=entries, base=base, is_be=is_be)
    funcs = cfg.build_functions(insns, calls, extra_entries=entries)
    namer = Namer(code_names=code_names)

    # 1. Pre-compute calling conventions and arities
    arity = {}
    for entry, f in funcs.items():
        frame_info = frame.analyze_frame(f)
        opt.optimize(f)
        sig = abi.analyze_calling_convention(f, frame_info=frame_info)
        arity[entry] = len(sig.params)

    # 2. Decompile each function with virtual variable recovery
    out = {}
    for entry, f in funcs.items():
        frame_info = frame.analyze_frame(f)
        callargs.rewrite(f, arity)
        opt.optimize(f)
        sig = abi.analyze_calling_convention(f, frame_info=frame_info)
        vars.recover_variables(f, sig=sig, frame_info=frame_info)
        tree = structure.structure(f)
        lines = cgen.generate(f, tree, namer, frame_info=frame_info, sig=sig)
        out[entry] = Function(entry, namer.code(entry), f, tree, lines)

    return Program(image, base, insns, out, namer, is_be=is_be)


def decompile_file(path, base=None, extra_entries=(), is_be=True, **kw):
    image = loader.load(path)
    det_base, reset = loader.detect_base(image, is_be=is_be)
    if base is None:
        base = det_base
    entries = list(loader.vector_entries(image, base=base, is_be=is_be))
    if reset and reset not in entries:
        entries.append(reset)
    entries += list(extra_entries)
    return decompile_image(image, entries=entries, base=base, is_be=is_be, **kw)


def decompile_one(ea):
    from . import ida_bridge
    return ida_bridge.decompile_one(ea)
```

```py
"""
Calling convention analysis and function signature recovery for LatticeMico32 (LM32).

LM32 calling conventions:
1. First 8 arguments passed in 32-bit general registers:
   r1 (first), r2 (second), r3 (third), r4 (fourth),
   r5 (fifth), r6 (sixth), r7 (seventh), r8 (eighth).
2. Additional arguments (9th+) passed on the stack at entry SP (sp0 + 0, sp0 + 4, ...).
3. Return values:
   - 32-bit scalar or pointer returned in r1.
   - 64-bit scalar returned in r1:r2.
   - Structs > 8 bytes return via caller-allocated pointer passed in r1.
4. Volatile (caller-saved) registers:
   r1..r10, ra (r29), ea (r30), ba (r31) - clobbered across calls.
5. Callee-saved registers:
   r11..r25, gp (r26), fp (r27), sp (r28) - preserved across calls.
"""

from . import ir, isa

ARG_REGS = ("r1", "r2", "r3", "r4", "r5", "r6", "r7", "r8")
CALLER_SAVED = frozenset(
    [f"r{i}" for i in range(1, 11)] + ["ra", "ea", "ba"]
)
CALLEE_SAVED = frozenset(
    [f"r{i}" for i in range(11, 26)] + ["gp", "fp", "sp"]
)


class Param:
    __slots__ = ("name", "type_str", "location")

    def __init__(self, name, type_str="int", location="r1"):
        self.name = name
        self.type_str = type_str
        self.location = location

    def __repr__(self):
        return f"{self.type_str} {self.name}"


class FunctionSig:
    def __init__(self, name=None, ret_type="void", ret_expr=None, params=None):
        self.name = name
        self.ret_type = ret_type
        self.ret_expr = ret_expr
        self.params = list(params) if params else []

    def format_signature(self, func_name=None):
        name = func_name or self.name or "sub_unknown"
        if self.params:
            pstr = ", ".join(f"{p.type_str} {p.name}" for p in self.params)
        else:
            pstr = "void"
        return f"{self.ret_type} {name}({pstr})"


def _collect_expr_regs(e, out_regs):
    if isinstance(e, ir.Reg):
        out_regs.add(e.name)
    elif isinstance(e, ir.Bin):
        _collect_expr_regs(e.l, out_regs)
        _collect_expr_regs(e.r, out_regs)
    elif isinstance(e, ir.Un):
        _collect_expr_regs(e.e, out_regs)
    elif isinstance(e, ir.Mem) and isinstance(e.addr, ir.Expr):
        _collect_expr_regs(e.addr, out_regs)
    elif isinstance(e, ir.IntrExpr):
        for a in e.args:
            _collect_expr_regs(a, out_regs)


def compute_liveness(func, hidden_stmts=frozenset()):
    """Compute entry live-in registers via standard backwards dataflow analysis."""
    block_gen = {}
    block_kill = {}

    for b in func.blocks.values():
        gen = set()
        kill = set()

        for s in b.stmts:
            if id(s) in hidden_stmts:
                continue

            used = set()
            if isinstance(s, ir.Assign):
                _collect_expr_regs(s.src, used)
                if isinstance(s.dst, ir.Mem) and isinstance(s.dst.addr, ir.Expr):
                    _collect_expr_regs(s.dst.addr, used)
            elif isinstance(s, ir.Call):
                if s.args:
                    for a in s.args:
                        _collect_expr_regs(a, used)
                if s.expr:
                    _collect_expr_regs(s.expr, used)
            elif isinstance(s, ir.Branch):
                if isinstance(s.cexpr, ir.Expr):
                    _collect_expr_regs(s.cexpr, used)
            elif isinstance(s, ir.Switch) and isinstance(s.expr, ir.Expr):
                _collect_expr_regs(s.expr, used)
            elif isinstance(s, ir.Intrinsic):
                for a in s.args:
                    _collect_expr_regs(a, used)

            # Upward exposed uses in this block
            gen |= (used - kill)

            # Definitions kill earlier uses
            if isinstance(s, ir.Assign) and isinstance(s.dst, ir.Reg):
                kill.add(s.dst.name)
            elif isinstance(s, ir.Call):
                kill |= CALLER_SAVED

        block_gen[b.start] = gen
        block_kill[b.start] = kill

    live_in = {ea: set() for ea in func.blocks}
    changed = True
    while changed:
        changed = False
        for ea, b in func.blocks.items():
            live_out = set()
            for _, tgt in b.succ:
                if tgt in live_in:
                    live_out |= live_in[tgt]
            new_in = block_gen[ea] | (live_out - block_kill[ea])
            if new_in != live_in[ea]:
                live_in[ea] = new_in
                changed = True

    return live_in.get(func.entry, set())


def _infer_return(func):
    """Infer return type: void, int, uint64_t, or pointer."""
    ret_blocks = [b for b in func.blocks.values() if b.term == "ret"]
    if not ret_blocks:
        return "void", None

    r1_defined = False
    r2_defined = False
    cand_expr = None

    for b in ret_blocks:
        for s in reversed(b.stmts):
            if isinstance(s, ir.Assign) and isinstance(s.dst, ir.Reg):
                if s.dst.name == "r1" and not r1_defined:
                    r1_defined = True
                    cand_expr = s.src
                elif s.dst.name == "r2" and not r2_defined:
                    r2_defined = True
            elif isinstance(s, ir.Call):
                break

    # If both r1 and r2 defined at exit, 64-bit return
    if r1_defined and r2_defined:
        return "uint64_t", ir.Reg("r1")

    if r1_defined:
        if isinstance(cand_expr, ir.Const) and cand_expr.value >= 0x800000:
            return "int *", cand_expr
        if isinstance(cand_expr, ir.Mem):
            return "int", cand_expr
        return "int", cand_expr or ir.Reg("r1")

    # If no explicit assignment in return block, check if entry block defined r1
    entry_block = func.blocks.get(func.entry)
    if entry_block:
        for s in entry_block.stmts:
            if isinstance(s, ir.Assign) and isinstance(s.dst, ir.Reg) and s.dst.name == "r1":
                return "int", ir.Reg("r1")

    return "void", None


def analyze_calling_convention(func, frame_info=None, user_proto=None, func_name=None, ret_types=None, caller_consensus=None):
    """Reconstruct function signature (parameters, return type) for LM32."""
    fn_name = func_name or getattr(func, "name", None) or ("sub_%X" % func.entry)
    if user_proto:
        sig = parse_cdecl_prototype(user_proto)
        if sig:
            sig.name = fn_name
            return sig

    hidden = frame_info.hidden_stmts if frame_info else frozenset()
    live_in = set(compute_liveness(func, hidden))

    if caller_consensus:
        for rname, has_arg in caller_consensus.items():
            if has_arg:
                live_in.add(rname)

    # Determine highest live-in argument register
    hi_arg = -1
    for idx, r in enumerate(ARG_REGS):
        if r in live_in:
            hi_arg = idx

    # If function accesses incoming stack arguments, all 8 argument registers are active
    stack_args = getattr(func, "stack_args", {}) or {}
    if frame_info and frame_info.stack_args:
        stack_args = frame_info.stack_args

    if stack_args:
        hi_arg = 7

    params = []
    # Register parameters a0..a7
    for i in range(hi_arg + 1):
        r_name = ARG_REGS[i]
        params.append(Param(name=f"a{i}", type_str="int", location=r_name))

    # Stack parameters arg_0, arg_4, ...
    if stack_args:
        for off in sorted(stack_args):
            name, width = stack_args[off]
            t_str = "int" if width == 4 else ("short" if width == 2 else "char")
            params.append(Param(name=name, type_str=t_str, location=f"[sp+{off}]"))

    ret_type, ret_expr = _infer_return(func)
    return FunctionSig(name=fn_name, ret_type=ret_type, ret_expr=ret_expr, params=params)


def parse_cdecl_prototype(proto_str):
    """Parse a simple C prototype string like 'int foo(int a, void *b)'."""
    import re
    proto_str = proto_str.strip().rstrip(";")
    m = re.match(r"^([\w\s\*]+?)\s+(\w+)\s*\((.*?)\)$", proto_str)
    if not m:
        return None
    ret_type = m.group(1).strip()
    func_name = m.group(2).strip()
    param_str = m.group(3).strip()

    params = []
    if param_str and param_str != "void":
        for idx, p in enumerate(param_str.split(",")):
            p = p.strip()
            parts = p.rsplit(None, 1)
            if len(parts) == 2:
                t_str, p_name = parts[0].strip(), parts[1].strip()
            else:
                t_str, p_name = p, f"a{idx}"
            loc = ARG_REGS[idx] if idx < len(ARG_REGS) else f"stack_{idx}"
            params.append(Param(p_name, t_str, location=loc))

    return FunctionSig(name=func_name, ret_type=ret_type, params=params)
```

```py
"""
Call-argument folding for LatticeMico32 (LM32).

LM32 passes up to 8 integer/pointer arguments in r1..r8.
Tracks values assigned to r1..r8 within a basic block immediately preceding Call statements.
Folds the setup assignments into the call's `args` list and eliminates redundant setup statements.
"""

from . import ir

ARGS = ("r1", "r2", "r3", "r4", "r5", "r6", "r7", "r8")
_ARGSET = frozenset(ARGS)


def _expr_regs(e, out):
    if isinstance(e, ir.Reg):
        out.add(e.name)
    elif isinstance(e, ir.Bin):
        _expr_regs(e.l, out); _expr_regs(e.r, out)
    elif isinstance(e, ir.Un):
        _expr_regs(e.e, out)
    elif isinstance(e, ir.Mem) and isinstance(e.addr, ir.Expr):
        _expr_regs(e.addr, out)
    elif isinstance(e, ir.IntrExpr):
        for a in e.args:
            _expr_regs(a, out)
    return out


def _has_mem(e):
    if isinstance(e, ir.Mem):
        return True
    if isinstance(e, ir.Bin):
        return _has_mem(e.l) or _has_mem(e.r)
    if isinstance(e, ir.Un):
        return _has_mem(e.e)
    if isinstance(e, ir.IntrExpr):
        return any(_has_mem(a) for a in e.args)
    return False


def rewrite(func, arity=None):
    arity = arity or {}
    for b in func.blocks.values():
        argexpr = {}        # reg name -> current value expr
        argstmt = {}        # reg name -> the Assign that set it
        used_since = set()  # arg regs read since their Assign
        out = []

        for s in b.stmts:
            if isinstance(s, ir.Assign):
                src_regs = _expr_regs(s.src, set())
                if isinstance(s.dst, ir.Mem) and isinstance(s.dst.addr, ir.Expr):
                    src_regs |= _expr_regs(s.dst.addr, set())
                used_since |= (src_regs & _ARGSET)

                if isinstance(s.dst, ir.Reg):
                    dname = s.dst.name
                    # Invalidate pending arg exprs that depend on dname
                    for a, ex in list(argexpr.items()):
                        if a != dname and dname in _expr_regs(ex, set()):
                            argexpr[a] = ir.Reg(a)
                            argstmt.pop(a, None)
                    if dname in _ARGSET:
                        if dname in src_regs and dname in argstmt:
                            argstmt.pop(dname, None)
                        argexpr[dname] = s.src
                        argstmt[dname] = s
                        used_since.discard(dname)
                        out.append(s)
                        continue
                elif isinstance(s.dst, ir.Mem):
                    for a, ex in list(argexpr.items()):
                        if _has_mem(ex):
                            argexpr[a] = ir.Reg(a)
                            argstmt.pop(a, None)
                out.append(s)
                continue

            if isinstance(s, ir.Call):
                call_ptr_regs = _expr_regs(s.expr, set()) if s.expr is not None else set()
                n = arity.get(s.target)
                if n is not None:
                    k = n
                else:
                    set_indices = [idx for idx, a in enumerate(ARGS) if a in argexpr and a not in call_ptr_regs]
                    if getattr(s, "is_tail", False) and set_indices:
                        k = max(set_indices) + 1
                    else:
                        run = []
                        for idx, a in enumerate(ARGS):
                            if a in argexpr and a not in call_ptr_regs:
                                run.append(a)
                            else:
                                break
                        k = len(run)

                k_regs = min(k, len(ARGS))
                call_args = [argexpr.get(ARGS[i], ir.Reg(ARGS[i])) for i in range(k_regs)]
                s.args = call_args

                # Drop folded setup statements if they were not read otherwise
                for i in range(k_regs):
                    a = ARGS[i]
                    if a in argstmt and a not in used_since:
                        st = argstmt[a]
                        if st in out:
                            out.remove(st)
                            s.inlined_eas.append(st.ea)

                argexpr.clear()
                argstmt.clear()
                used_since.clear()
                out.append(s)
                continue

            out.append(s)

        b.stmts = out

    return func
```

```py
"""
Control-flow graph for LatticeMico32 (LM32).
Carves decoded instructions into basic blocks and functions, and lifts each block into IR.

LM32 instructions are fixed 32-bit (4-byte aligned).
Flow termination:
- ret / eret / bret ends a block with term='ret'
- bi(target) ends a block with term='goto' (or tail call if target is outside body)
- b(rX) ends a block (return if rX is ra, switch if switch_info attached, else indirect jump)
- be / bne / bg / bge / bgu / bgeu end a block with term='branch'
- calli / call fall through to ea + 4
"""

from . import ir, isa
from .lifter import lift_insn
from .decoder import target_of, SwitchInfo


class Block:
    __slots__ = ("start", "insns", "stmts", "succ", "term")

    def __init__(self, start):
        self.start = start
        self.insns = []
        self.stmts = []
        self.succ = []
        self.term = None


class Func:
    __slots__ = ("entry", "blocks", "calls", "name", "locals", "stack_args", "virtual_vars")

    def __init__(self, entry):
        self.entry = entry
        self.blocks = {}
        self.calls = set()
        self.name = None
        self.locals = {}
        self.stack_args = {}
        self.virtual_vars = {}

    def ordered(self):
        return [self.blocks[k] for k in sorted(self.blocks)]


def _succ(ins, bounds_to_sw=None):
    bounds_to_sw = bounds_to_sw or {}
    m = ins.mnem
    if ins.ea in bounds_to_sw:
        sw = bounds_to_sw[ins.ea]
        # When bounds check is bypassed for the switch, jump to default if out of bounds
        return [("default", sw.default_ea), ("fall", ins.ea + 4)]

    if m in isa.RET:
        return []

    if m in isa.COND_BRANCH:
        tgt = target_of(ins)
        return [("cond", tgt), ("fall", ins.ea + 4)]

    if m == "bi":
        tgt = target_of(ins)
        return [("jump", tgt)] if tgt is not None else []

    if m == "b":
        if ins.switch_info is not None:
            sw = ins.switch_info
            res = [("case", t) for _, t in sw.cases]
            if sw.default_ea is not None:
                res.append(("default", sw.default_ea))
            return res
        tgt = target_of(ins)
        return [("jump", tgt)] if tgt is not None else []

    if m in ("raise", "break", "scall"):
        return []

    # Sequential instructions and calls fall through to next 4-byte instruction
    return [("fall", ins.ea + 4)]


def _collect_body(insns, entry, entry_set):
    """Reachability traversal collecting instruction addresses for one function."""
    body = set()
    work = [entry]
    while work:
        ea = work.pop()
        if ea in body or ea not in insns:
            continue
        body.add(ea)
        ins = insns[ea]
        for how, tgt in _succ(ins):
            if tgt in insns and (tgt == entry or tgt not in entry_set):
                work.append(tgt)
    return body


def _discover_switches(insns, body, image=None, base=0, is_be=False):
    """Detect jump table patterns leading up to an indirect jump `b rX`."""
    bounds_to_sw = {}
    setup_skip = set()

    for ea in sorted(body):
        ins = insns[ea]
        if ins.mnem != "b" or not ins.ops or ins.ops[0].mode != "reg":
            continue
        dest_reg = ins.ops[0].reg
        if dest_reg == 29:  # ret
            continue

        # Look backwards up to 16 instructions within body
        prev_eas = [e for e in sorted(body) if ea - 64 <= e < ea]
        if not prev_eas:
            continue

        # Pattern:
        #   cmpgui r_cmp, r_idx, max_case
        #   bne r_cmp, r0, default_ea
        #   ...
        #   sli r_off, r_idx, 2
        #   mvhi r_tbl, hi16
        #   ori r_tbl, r_tbl, lo16
        #   add r_ptr, r_off, r_tbl
        #   lw r_dest, (r_ptr+0)
        #   b r_dest
        lw_ins = insns.get(prev_eas[-1]) if prev_eas else None
        if not lw_ins or lw_ins.mnem != "lw":
            continue

        ptr_reg = lw_ins.ops[1].base_reg if (lw_ins.ops and len(lw_ins.ops) >= 2 and lw_ins.ops[1].mode in ("displ", "phrase")) else None
        if ptr_reg is None:
            continue

        add_ins = None
        table_ea = None
        idx_reg = None
        max_cases = None
        default_ea = None
        bounds_ea = None

        # Search for add and sli
        for pe in reversed(prev_eas[:-1]):
            pi = insns[pe]
            if pi.mnem == "add" and len(pi.ops) == 3 and pi.ops[0].reg == ptr_reg:
                add_ins = pi
            elif pi.mnem == "sli" and len(pi.ops) == 3 and pi.ops[2].value == 2:
                idx_reg = pi.ops[1].reg
            elif pi.mnem in ("bne", "be") and len(pi.ops) == 3 and default_ea is None:
                default_ea = pi.ops[2].addr
                bounds_ea = pe
            elif pi.mnem == "cmpgui" and len(pi.ops) == 3 and max_cases is None:
                max_cases = pi.ops[2].value + 1

        # Check for mvhi + ori address composition for table_ea
        hi16, lo16 = None, None
        for pe in prev_eas:
            pi = insns[pe]
            if pi.mnem == "mvhi" and len(pi.ops) == 2:
                hi16 = pi.ops[1].value
            elif pi.mnem == "ori" and len(pi.ops) == 3 and hi16 is not None:
                lo16 = pi.ops[2].value
                table_ea = (hi16 << 16) | lo16

        if table_ea is not None and max_cases is not None and 1 < max_cases <= 256:
            # Read cases from table
            cases = []
            targets = set()
            if image is not None:
                from .decoder import read_u32
                for c in range(max_cases):
                    t = read_u32(image, table_ea + c * 4, base=base, is_be=is_be)
                    if t is not None:
                        cases.append((c, t))
                        targets.add(t)
            sw = SwitchInfo(
                jmp_ea=ea,
                table_ea=table_ea,
                ncases=max_cases,
                lowcase=0,
                default_ea=default_ea,
                bounds_ea=bounds_ea,
                idx_reg=idx_reg if idx_reg is not None else 1,
                cases=cases,
                targets=list(targets),
                setup_eas=prev_eas
            )
            ins.switch_info = sw
            if bounds_ea is not None:
                bounds_to_sw[bounds_ea] = sw
            for pe in prev_eas:
                setup_skip.add(pe)

    return bounds_to_sw, setup_skip


def _leaders(insns, body, bounds_to_sw):
    leaders = set()
    for ea in body:
        ins = insns[ea]
        for how, tgt in _succ(ins, bounds_to_sw):
            if how in ("cond", "jump", "case", "default") and tgt in body:
                leaders.add(tgt)
        if ea in bounds_to_sw:
            continue
        if ins.mnem in isa.COND_BRANCH or ins.mnem in isa.CALL or ins.mnem in isa.STOP:
            nxt = ea + 4
            if nxt in body:
                leaders.add(nxt)
    return leaders


def build_func(insns, entry, entry_set, image=None, base=0, is_be=False):
    body = _collect_body(insns, entry, entry_set)
    if not body:
        return None

    bounds_to_sw, setup_skip = _discover_switches(insns, body, image=image, base=base, is_be=is_be)
    leaders = _leaders(insns, body, bounds_to_sw)
    leaders.add(entry)

    f = Func(entry)
    cur = None
    for ea in sorted(body):
        ins = insns[ea]
        if ea in leaders or cur is None:
            cur = Block(ea)
            f.blocks[ea] = cur
        cur.insns.append(ins)
        succ = _succ(ins, bounds_to_sw)
        nxt = ea + 4
        term = None

        if ea in bounds_to_sw:
            if nxt in leaders or nxt not in body:
                term = ("fall", [("fall", nxt)] if nxt in body else [])
        elif ins.mnem == "b" and ins.switch_info is not None:
            term = ("switch", succ)
        elif ins.mnem == "bi" and target_of(ins) is not None and target_of(ins) not in body:
            # Tail call
            term = ("ret", [])
        elif ins.mnem == "bi":
            term = ("goto", succ)
        elif ins.mnem in isa.RET:
            term = ("ret", [])
        elif ins.mnem == "b" and ins.ops and ins.ops[0].reg == 29:
            term = ("ret", [])
        elif ins.mnem == "b":
            term = ("goto", succ)
        elif ins.mnem in isa.COND_BRANCH:
            term = ("branch", succ)
        elif ins.mnem in ("raise", "break", "scall"):
            term = ("stop", [])
        elif nxt in leaders or nxt not in body:
            term = ("fall", [("fall", nxt)] if nxt in body else [])

        if term is not None:
            cur.term, cur.succ = term
            cur = None

    for b in f.blocks.values():
        for ins in b.insns:
            if ins.mnem in isa.CALL and target_of(ins) is not None:
                f.calls.add(target_of(ins))
            if ins.ea in setup_skip:
                continue
            if ins.mnem == "bi" and target_of(ins) is not None and target_of(ins) not in body:
                tgt = target_of(ins)
                f.calls.add(tgt)
                b.stmts.append(ir.Call(ins.ea, target=tgt, is_tail=True))
                b.stmts.append(ir.Ret(ins.ea, "ret"))
                continue
            lifted = lift_insn(ins)
            b.stmts.extend(lifted)

    return f


def build_functions(insns, calls, extra_entries=(), image=None, base=0, is_be=False):
    entry_set = {e for e in (set(calls) | set(extra_entries)) if e in insns}
    funcs = {}
    for entry in sorted(entry_set):
        fn = build_func(insns, entry, entry_set, image=image, base=base, is_be=is_be)
        if fn is not None:
            funcs[entry] = fn
    return funcs
```

```py
"""
Pseudo-C back-end for the LatticeMico32 (LM32) decompiler.

Generates Hex-Rays parity C code:
- Register and virtual variable names (r1..r31, v0, v1, a0..a7).
- Memory reads and writes using Hex-Rays style pointer dereferences:
  *(_DWORD *), *(_WORD *), *(_BYTE *), *(short *), *(char *).
- Typed pointer array indexing (ptr[i]) and dereferences (*ptr).
- Relational conditional branches without flags layer.
- Structured if/else, while, do-while, switch/case.
- Dense instruction EA anchoring (100% instruction coverage for bidirectional sync).
- User overrides: renames, types, number formats, comments, if-inversions.
"""

from . import ir
from . import structure as S


_PRECEDENCE = {
    "*": 10, "/": 10, "%": 10,
    "+": 9, "-": 9,
    "<<": 8, ">>": 8,
    "<": 7, "<=": 7, ">": 7, ">=": 7,
    "==": 6, "!=": 6,
    "&": 5,
    "^": 4,
    "|": 3,
    "&&": 2,
    "||": 1,
}


class CodeLines(list):
    """List of generated C lines carrying parallel line_eas, line_to_eas, and ea_to_line mappings."""
    pass


def format_c_string(s):
    """Format string content as a standard C escaped double-quoted string literal."""
    if isinstance(s, bytes):
        try:
            s = s.decode("latin-1")
        except Exception:
            s = str(s)
    res = []
    for ch in s:
        if ch == '"':
            res.append(r'\"')
        elif ch == '\\':
            res.append(r'\\')
        elif ch == '\n':
            res.append(r'\n')
        elif ch == '\r':
            res.append(r'\r')
        elif ch == '\t':
            res.append(r'\t')
        elif ch == '\a':
            res.append(r'\a')
        elif ch == '\b':
            res.append(r'\b')
        elif ch == '\f':
            res.append(r'\f')
        elif ch == '\v':
            res.append(r'\v')
        elif 32 <= ord(ch) <= 126:
            res.append(ch)
        else:
            res.append(r'\x%02X' % ord(ch))
    return '"' + ''.join(res) + '"'


def format_c_char(v):
    """Format an integer as a standard C character literal."""
    if 0 <= v <= 255:
        ch = chr(v)
        if ch == "'":
            return r"'\''"
        elif ch == '\\':
            return r"'\\'"
        elif ch == '\n':
            return r"'\n'"
        elif ch == '\t':
            return r"'\t'"
        elif ch == '\r':
            return r"'\r'"
        elif ch == '\a':
            return r"'\a'"
        elif ch == '\b':
            return r"'\b'"
        elif 32 <= v <= 126:
            return f"'{ch}'"
        else:
            return r"'\x%02X'" % v
    chars = []
    temp = v
    while temp > 0:
        b = temp & 0xFF
        if 32 <= b <= 126 and chr(b) not in ("'", "\\"):
            chars.append(chr(b))
        else:
            return "0x%X" % v
        temp >>= 8
    return "'" + "".join(chars) + "'"


class _Emit:
    def __init__(self, namer, block_starts=frozenset(), returns_value=False, sig=None, hidden=frozenset(),
                 user_renames=None, user_types=None, user_numforms=None, user_iflags=None, show_casts=True):
        self.namer = namer
        self.block_starts = block_starts
        self.returns_value = returns_value
        self.sig = sig
        self.hidden = hidden
        self.user_renames = user_renames or {}
        self.user_types = user_types or {}
        self.user_numforms = user_numforms or {}
        self.user_iflags = set(user_iflags or [])
        self.show_casts = show_casts
        self.cur_ea = None
        self.used_labels = set()
        self._pending = []

    def _resolve_sym_name(self, v):
        if hasattr(self.namer, "code"):
            name = self.namer.code(v)
            if name and not name.startswith("?"):
                return name
        if hasattr(self.namer, "data"):
            name = self.namer.data(v)
            if name:
                return name
        return None

    def _invert_cond(self, cond):
        if isinstance(cond, ir.Bin):
            inv_map = {
                "==": "!=", "!=": "==",
                "<": ">=", ">=": "<",
                ">": "<=", "<=": ">",
                "u<": "u>=", "u>=": "u<",
                "u>": "u<=", "u<=": "u>",
            }
            if cond.op in inv_map:
                return ir.Bin(inv_map[cond.op], cond.l, cond.r)
        if isinstance(cond, ir.Un) and cond.op == "!":
            return cond.e
        return ir.Un("!", cond)

    def expr(self, e, top=True):
        if isinstance(e, ir.Const):
            v = e.value & 0xFFFFFFFF
            # Check custom number format override
            form = None
            if self.user_numforms:
                v_hex = hex(v)
                v_hex_lower = v_hex.lower()
                if self.cur_ea is not None:
                    ea_hex = hex(self.cur_ea)
                    ea_hex_lower = ea_hex.lower()
                    form = (self.user_numforms.get(f"{ea_hex}:{v_hex}")
                            or self.user_numforms.get(f"{ea_hex_lower}:{v_hex_lower}")
                            or self.user_numforms.get(f"{ea_hex}:{v}")
                            or self.user_numforms.get(f"{self.cur_ea}:{v_hex}")
                            or self.user_numforms.get(f"{self.cur_ea}:{v_hex_lower}")
                            or self.user_numforms.get(f"{self.cur_ea}:{v}")
                            or self.user_numforms.get((self.cur_ea, v_hex))
                            or self.user_numforms.get((self.cur_ea, v_hex_lower))
                            or self.user_numforms.get((self.cur_ea, v))
                            or self.user_numforms.get((ea_hex, v_hex))
                            or self.user_numforms.get((ea_hex_lower, v_hex_lower)))
                if not form:
                    form = (self.user_numforms.get(v_hex)
                            or self.user_numforms.get(v_hex_lower)
                            or self.user_numforms.get(str(v))
                            or self.user_numforms.get(v))

            if form:
                if form == "hex":
                    return "0x%X" % v
                elif form == "dec":
                    signed = (v - 0x100000000) if v >= 0x80000000 else v
                    return str(signed)
                elif form == "char":
                    return format_c_char(v)
                elif form in ("offset", "sym"):
                    sym = self._resolve_sym_name(v)
                    if sym:
                        return sym
                elif form == "invsign":
                    signed = (v - 0x100000000) if v >= 0x80000000 else v
                    return str(signed)
                elif form == "bnot":
                    inv = (~v) & 0xFFFFFFFF
                    return ("~0x%X" % inv) if inv >= 10 else f"~{inv}"

            if getattr(e, "name", None) and e.name in self.user_renames:
                return self.user_renames[e.name]
            if hasattr(self.namer, "string"):
                s = self.namer.string(e.value)
                if s is None and getattr(e, "name", None):
                    s = self.namer.string(e.name)
                if s is not None:
                    return format_c_string(s)
            if getattr(e, "name", None):
                return self.user_renames.get(e.name, e.name)
            return str(v) if v < 10 else "0x%X" % v

        if isinstance(e, (ir.Reg, ir.Var)):
            return self.user_renames.get(e.name, e.name)
        if isinstance(e, ir.Mem):
            return self._mem(e)
        if isinstance(e, ir.Bin):
            op, r = e.op, e.r
            # Render "+ 0xFFFFFFFF" (add #-1) etc. as a subtraction
            if op == "+" and isinstance(r, ir.Const) and r.value >= 0x80000000:
                op, r = "-", ir.Const((0x100000000 - r.value))
            rs = self.expr(r, False)
            s = "%s %s %s" % (self.expr(e.l, False), op, rs)
            return s if top else "(%s)" % s
        if isinstance(e, ir.Un):
            return "%s%s" % (e.op, self.expr(e.e, False))
        if isinstance(e, ir.IntrExpr):
            return "%s(%s)" % (e.name, ", ".join(self.expr(a) for a in e.args)) if e.args else e.name
        return "?"

    def _mem(self, e):
        # 1. Direct symbolic name on the Mem object
        if getattr(e, "name", None):
            return self.user_renames.get(e.name, e.name)

        # 2. Check if address is a constant with a known symbolic name in IDA / namer
        addr_val = None
        if isinstance(e.addr, ir.Const):
            if getattr(e.addr, "name", None):
                return self.user_renames.get(e.addr.name, e.addr.name)
            addr_val = e.addr.value
        elif isinstance(e.addr, int):
            addr_val = e.addr

        if addr_val is not None:
            sym = None
            if hasattr(self.namer, "data"):
                sym = self.namer.data(addr_val)
            elif hasattr(self.namer, "code_names"):
                sym = self.namer.code_names.get(addr_val)
            if sym and not sym.startswith(("sub_", "loc_")):
                return self.user_renames.get(sym, sym)

        # 3. Check if address is a base named symbol + offset or index
        if isinstance(e.addr, ir.Bin) and e.addr.op == "+":
            if isinstance(e.addr.l, ir.Const) and getattr(e.addr.l, "name", None):
                base_name = self.user_renames.get(e.addr.l.name, e.addr.l.name)
                return "%s[%s]" % (base_name, self.expr(e.addr.r))
            elif isinstance(e.addr.r, ir.Const) and getattr(e.addr.r, "name", None):
                base_name = self.user_renames.get(e.addr.r.name, e.addr.r.name)
                return "%s[%s]" % (base_name, self.expr(e.addr.l))

        # 4. Check if address is a typed pointer variable (*ptr)
        if isinstance(e.addr, (ir.Reg, ir.Var)):
            vname = e.addr.name
            vtype = self.user_types.get(vname, "")
            if vtype.endswith("*"):
                base_t = vtype[:-1].strip()
                t_size = 4 if base_t in ("int", "_DWORD", "uint32_t", "int32_t", "unsigned int") else (
                         2 if base_t in ("short", "_WORD", "uint16_t", "int16_t", "unsigned short") else (
                         1 if base_t in ("char", "_BYTE", "uint8_t", "int8_t", "unsigned char") else None))
                if t_size is None or t_size == e.width:
                    eff_name = self.user_renames.get(vname, vname)
                    return "*%s" % eff_name

        # 5. Check if address is ptr + offset for a typed pointer (ptr[idx])
        if isinstance(e.addr, ir.Bin) and e.addr.op == "+":
            if isinstance(e.addr.l, (ir.Reg, ir.Var)) and isinstance(e.addr.r, (ir.Const, int)):
                vname = e.addr.l.name
                offset_val = e.addr.r.value if isinstance(e.addr.r, ir.Const) else e.addr.r
                vtype = self.user_types.get(vname, "")
                if vtype.endswith("*"):
                    base_t = vtype[:-1].strip()
                    t_size = 4 if base_t in ("int", "_DWORD", "uint32_t", "int32_t", "unsigned int") else (
                             2 if base_t in ("short", "_WORD", "uint16_t", "int16_t", "unsigned short") else (
                             1 if base_t in ("char", "_BYTE", "uint8_t", "int8_t", "unsigned char") else None))
                    if t_size and e.width == t_size and offset_val % t_size == 0:
                        eff_name = self.user_renames.get(vname, vname)
                        idx = offset_val // t_size
                        return "%s[%d]" % (eff_name, idx)

        # 6. Default Hex-Rays cast dereference
        if not self.show_casts:
            cast = ""
        elif e.width == 4:
            cast = "_DWORD *"
        elif e.width == 2:
            cast = "short *" if e.signed else "_WORD *"
        elif e.width == 1:
            cast = "char *" if e.signed else "_BYTE *"
        else:
            cast = "_DWORD *"

        if isinstance(e.addr, ir.Expr):
            addr_str = self.expr(e.addr, top=False)
            if not self.show_casts:
                return "*%s" % (("(%s)" % addr_str) if " " in addr_str else addr_str)
            if addr_str.startswith("(") and addr_str.endswith(")"):
                return "*(%s)%s" % (cast, addr_str)
            elif " " in addr_str:
                return "*(%s)(%s)" % (cast, addr_str)
            else:
                return "*(%s)%s" % (cast, addr_str)
        else:
            if not self.show_casts:
                return "*0x%X" % e.addr
            return "*(%s)0x%X" % (cast, e.addr)

    def stmt(self, s):
        self.cur_ea = getattr(s, "ea", None)
        if isinstance(s, ir.Assign):
            if isinstance(s.dst, ir.Const) and s.dst.value == 0:
                return "%s;" % self.expr(s.src)
            return "%s = %s;" % (self.expr(s.dst), self.expr(s.src))
        if isinstance(s, ir.Call):
            args = ", ".join(self.expr(a) for a in (s.args or []))
            if s.target is not None:
                tgt_name = self.namer.code(s.target)
                tgt_name = self.user_renames.get(tgt_name, tgt_name)
                call_str = "%s(%s)" % (tgt_name, args)
            else:
                call_str = "(*%s)(%s)" % (self.expr(s.expr), args)
            if getattr(s, "is_tail", False):
                if self.returns_value:
                    return "return %s;" % call_str
                else:
                    return "%s;" % call_str
            return "%s;" % call_str
        if isinstance(s, ir.Intrinsic):
            call = "%s(%s);" % (s.name, ", ".join(self.expr(a) for a in s.args))
            return call + ("   /* %s */" % s.note if s.note else "")
        return "/* %s */" % type(s).__name__

    def _ext(self, ea):
        return self.namer.code(ea) if ea is not None else "?"

    def emit(self, nodes, ind):
        pad = "    " * ind
        for n in nodes:
            if isinstance(n, S.SLabel):
                self._pending.append((ind, None, n.ea, n.ea, [n.ea]))
            elif isinstance(n, S.SStmt):
                ea = getattr(n.stmt, "ea", None)
                inlined = list(getattr(n.stmt, "inlined_eas", []))
                all_eas = ([ea] if ea is not None else []) + inlined
                self._pending.append((ind, pad + self.stmt(n.stmt), None, ea, all_eas))
            elif isinstance(n, S.SRet):
                if self._pending and self._pending[-1][1] and self._pending[-1][1].strip().startswith("return "):
                    continue
                ea = getattr(n, "ea", None)
                if self.returns_value:
                    if self.sig and getattr(self.sig, "ret_type", None) == "uint64_t":
                        ret_expr = "return ((uint64_t)r2 << 32) | r1;"
                    else:
                        ret_expr = "return r1;"
                else:
                    ret_expr = "return;"
                self._pending.append((ind, pad + ret_expr, None, ea, [ea] if ea else []))
            elif isinstance(n, S.SGoto):
                ea = getattr(n, "ea", None)
                all_eas = [ea] if ea is not None else []
                if n.ea in self.block_starts:
                    self.used_labels.add(n.ea)
                    self._pending.append((ind, pad + "goto %s;" % self.namer.label(n.ea), None, ea, all_eas))
                else:
                    self._pending.append((ind, pad + "JUMPOUT(%s);" % self._ext(n.ea), None, ea, all_eas))
            elif isinstance(n, S.SIfGoto):
                br_ea = getattr(n, "branch_ea", None) or getattr(n, "ea", None)
                all_eas = [e for e in (br_ea, getattr(n, "ea", None)) if e is not None]
                if n.ea in self.block_starts:
                    self.used_labels.add(n.ea)
                    tail = "goto %s;" % self.namer.label(n.ea)
                else:
                    tail = "JUMPOUT(%s);" % self._ext(n.ea)
                self._pending.append((ind, pad + "if (%s) %s" % (self.expr(n.cond), tail), None, br_ea, all_eas))
            elif isinstance(n, S.SBreak):
                ea = getattr(n, "ea", None)
                self._pending.append((ind, pad + "break;", None, ea, [ea] if ea is not None else []))
            elif isinstance(n, S.SBreakIf):
                ea = getattr(n, "ea", None)
                self._pending.append((ind, pad + "if (%s) break;" % self.expr(n.cond), None, ea, [ea] if ea is not None else []))
            elif isinstance(n, S.SContinue):
                ea = getattr(n, "ea", None)
                all_eas = [ea] if ea is not None else []
                if n.cond is None:
                    self._pending.append((ind, pad + "continue;", None, ea, all_eas))
                else:
                    self._pending.append((ind, pad + "if (%s) continue;" % self.expr(n.cond), None, ea, all_eas))
            elif isinstance(n, S.SIf):
                ea = getattr(n, "ea", None)
                inverted = False
                if ea is not None and (ea in self.user_iflags or hex(ea) in self.user_iflags or str(ea) in self.user_iflags):
                    inverted = True

                cond_expr = n.cond
                then_body = n.then
                els_body = n.els

                if inverted:
                    cond_expr = self._invert_cond(cond_expr)
                    if els_body:
                        then_body, els_body = els_body, then_body

                self.cur_ea = ea
                self._pending.append((ind, pad + "if (%s) {" % self.expr(cond_expr), None, ea, [ea] if ea is not None else []))
                self.emit(then_body, ind + 1)
                if els_body:
                    self._pending.append((ind, pad + "} else {", None, None, []))
                    self.emit(els_body, ind + 1)
                self._pending.append((ind, pad + "}", None, None, []))
            elif isinstance(n, S.SWhile):
                self._emit_while(n, ind)
            elif isinstance(n, S.SSwitch):
                self._emit_switch(n, ind)

    def _emit_switch(self, n, ind):
        pad = "    " * ind
        ea = getattr(n, "ea", None)
        self._pending.append((ind, pad + "switch (%s) {" % self.expr(n.expr), None, ea, [ea] if ea is not None else []))
        for vals, arm in n.cases:
            for v in vals:
                v_str = str(v) if v < 10 else "0x%X" % v
                self._pending.append((ind, pad + "case %s:" % v_str, None, None, []))
            self.emit(arm, ind + 1)
        if n.default_body:
            self._pending.append((ind, pad + "default:", None, None, []))
            self.emit(n.default_body, ind + 1)
        self._pending.append((ind, pad + "}", None, None, []))

    def _emit_while(self, n, ind):
        pad = "    " * ind
        body = list(n.body)
        tail = None
        tail_ea = None
        ea = getattr(n, "ea", None)
        all_eas = [ea] if ea is not None else []
        if body and isinstance(body[-1], S.SContinue) and body[-1].cond is not None:
            tail = body[-1].cond
            tail_ea = getattr(body[-1], "ea", None)
            body = body[:-1]
        if tail is not None:
            self._pending.append((ind, pad + "do {", None, ea, all_eas))
            self.emit(body, ind + 1)
            t_eas = [tail_ea] if tail_ea is not None else []
            self._pending.append((ind, pad + "} while (%s);" % self.expr(tail), None, tail_ea, t_eas))
            return
        # Drop redundant unconditional `continue;` at the end of a while loop
        if body and isinstance(body[-1], S.SContinue) and body[-1].cond is None:
            body = body[:-1]
        # Check if the first statement after loop header label is `if (cond) break;`
        first_idx = None
        for idx, item in enumerate(body):
            if not isinstance(item, S.SLabel):
                first_idx = idx
                break
        if first_idx is not None and isinstance(body[first_idx], S.SBreakIf):
            wcond = S.negate(body[first_idx].cond)
            body = body[:first_idx] + body[first_idx + 1:]
            self._pending.append((ind, pad + "while (%s) {" % self.expr(wcond), None, ea, all_eas))
            self.emit(body, ind + 1)
            self._pending.append((ind, pad + "}", None, None, []))
        else:
            self._pending.append((ind, pad + "while (1) {", None, ea, all_eas))
            self.emit(body, ind + 1)
            self._pending.append((ind, pad + "}", None, None, []))

    def flush(self):
        out = []
        line_eas = []
        line_to_eas = {}
        for ind, text, label_ea, primary_ea, all_eas in self._pending:
            if label_ea is not None:
                if label_ea in self.used_labels:
                    lineno = len(out)
                    out.append("%s:" % self.namer.label(label_ea))
                    line_eas.append(label_ea)
                    line_to_eas[lineno] = [label_ea]
                continue
            lineno = len(out)
            out.append(text)
            line_eas.append(primary_ea)
            unique_eas = list(dict.fromkeys(e for e in all_eas if e is not None))
            line_to_eas[lineno] = unique_eas
        return out, line_eas, line_to_eas


def generate(func, tree, namer, frame_info=None, sig=None, banner=None,
             user_renames=None, user_types=None, user_comments=None,
             user_numforms=None, user_iflags=None, show_casts=True):
    hidden = getattr(frame_info, "hidden_stmts", frozenset()) if frame_info else frozenset()
    u_renames = dict(getattr(frame_info, "user_renames", {}) or {})
    if user_renames:
        u_renames.update(user_renames)
    u_types = dict(getattr(frame_info, "user_types", {}) or {})
    if user_types:
        u_types.update(user_types)

    returns_value = (sig.ret_type != "void") if sig else False
    em = _Emit(namer, block_starts=frozenset(func.blocks), returns_value=returns_value, sig=sig,
               hidden=hidden, user_renames=u_renames, user_types=u_types,
               user_numforms=user_numforms, user_iflags=user_iflags, show_casts=show_casts)
    em.emit(tree, 1)
    body, body_eas, body_line_to_eas = em.flush()

    if user_comments:
        for idx in range(len(body)):
            line_eas = body_line_to_eas.get(idx, [])
            for lea in line_eas:
                ea_key = hex(lea) if isinstance(lea, int) else str(lea)
                cmt = (user_comments.get(ea_key)
                       or user_comments.get(str(lea))
                       or (user_comments.get(lea) if isinstance(lea, int) else None))
                if cmt:
                    body[idx] = f"{body[idx]}  // {cmt}"
                    break

    out = CodeLines()
    if banner:
        out.extend(banner)

    fn_name = namer.code(func.entry)
    fn_name = u_renames.get(fn_name, fn_name)

    if sig is not None:
        ret_t = u_types.get("__return__", sig.ret_type)
        if sig.params:
            param_parts = []
            for p in sig.params:
                p_name = u_renames.get(p.name, p.name)
                p_type = u_types.get(p.name, u_types.get(p_name, p.type_str))
                sep = "" if p_type.endswith("*") else " "
                param_parts.append(f"{p_type}{sep}{p_name}")
            pstr = ", ".join(param_parts)
        else:
            pstr = "void"
        ret_sep = "" if ret_t.endswith("*") else " "
        out.append(f"{ret_t}{ret_sep}{fn_name}({pstr})")
    else:
        out.append(f"void {fn_name}(void)")

    out.append("{")
    decls = []

    # Stack variable declarations
    if frame_info and frame_info.locals:
        def sort_loc(kv):
            name = kv[0]
            if isinstance(name, str) and "_" in name and name.split("_")[1].isalnum():
                try:
                    return (0, int(name.split("_")[1], 16))
                except ValueError:
                    pass
            return (1, str(name))

        for name, size in sorted(frame_info.locals.items(), key=sort_loc):
            eff_name = u_renames.get(name, name)
            default_t = {1: "char", 2: "short", 4: "int"}.get(size, "int")
            tstr = u_types.get(name, u_types.get(eff_name, default_t))
            sep = "" if tstr.endswith("*") else " "
            decls.append(f"    {tstr}{sep}{eff_name};")

    # Virtual variable declarations
    vvars = getattr(frame_info, "virtual_vars", None) or getattr(func, "virtual_vars", None)
    if vvars:
        def sort_vvar(kv):
            name = kv[0]
            if name.startswith("v") and name[1:].isdigit():
                return (0, int(name[1:]))
            return (1, name)

        for name, entry in sorted(vvars.items(), key=sort_vvar):
            if frame_info and frame_info.locals and name in frame_info.locals:
                continue
            eff_name = u_renames.get(name, name)
            default_t = "int"
            tstr = u_types.get(name, u_types.get(eff_name, default_t))
            sep = "" if tstr.endswith("*") else " "
            decls.append(f"    {tstr}{sep}{eff_name};")

    if decls:
        out.extend(decls)
        if body:
            out.append("")

    header_count = len(out)
    out.header_count = header_count
    out.extend(body)
    out.append("}")
    out.line_eas = [None] * header_count + body_eas + [None]

    # Map line numbers to associated instruction EAs
    out.line_to_eas = {header_count + k: v for k, v in body_line_to_eas.items()}
    out.ea_to_line = {}
    for lineno, eas in out.line_to_eas.items():
        for ea in eas:
            if ea not in out.ea_to_line:
                out.ea_to_line[ea] = lineno

    # Map function prototype and header lines to func.entry
    proto_lineno = len(banner) if banner else 0
    if proto_lineno < header_count:
        if func.entry not in out.ea_to_line:
            out.ea_to_line[func.entry] = proto_lineno
        for h_line in range(proto_lineno, header_count):
            if func.entry not in out.line_to_eas.setdefault(h_line, []):
                out.line_to_eas[h_line].append(func.entry)
            out.line_eas[h_line] = func.entry

    # Dense instruction completion across all basic blocks in func
    if getattr(func, "blocks", None):
        sorted_blocks = sorted(func.blocks.values(), key=lambda b: b.start)
        for b in sorted_blocks:
            b_lines = []
            for s in b.stmts:
                s_ea = getattr(s, "ea", None)
                if s_ea in out.ea_to_line:
                    b_lines.append((s_ea, out.ea_to_line[s_ea]))
            for ins in getattr(b, "insns", []):
                if ins.ea in out.ea_to_line:
                    continue
                chosen_line = None
                if b_lines:
                    _, chosen_line = min(b_lines, key=lambda pair: abs(pair[0] - ins.ea))
                elif b.start in out.ea_to_line:
                    chosen_line = out.ea_to_line[b.start]
                else:
                    chosen_line = proto_lineno if proto_lineno >= 0 else 0
                if chosen_line is not None:
                    out.ea_to_line[ins.ea] = chosen_line
                    if ins.ea not in out.line_to_eas.setdefault(chosen_line, []):
                        out.line_to_eas[chosen_line].append(ins.ea)

    return out
```

```py
"""
Headless CLI for the LatticeMico32 (LM32) decompiler:

    python -m lm32dec firmware.bin
    python -m lm32dec firmware.bin -o decompiled.c
    python -m lm32dec firmware.bin --endian little --base 0x800000 --entry 0x800100
    python -m lm32dec firmware.bin --func 0x800340

No IDA installation required.
"""

import argparse
import sys

from . import decompile_file


def _int(s):
    return int(s, 0)


def main(argv=None):
    argv = argv if argv is not None else sys.argv[1:]
    ap = argparse.ArgumentParser(prog="lm32dec",
                                 description="Decompile LatticeMico32 (LM32) firmware to pseudo-C.")
    ap.add_argument("rom", help="raw LM32 flash dump or binary image")
    ap.add_argument("-o", "--out", help="write C source listing to this file (default: stdout)")
    ap.add_argument("--base", type=_int, default=None, help="link base address (default: auto from reset vector)")
    ap.add_argument("--entry", type=_int, action="append", default=None, help="extra entry point address (repeatable)")
    ap.add_argument("--func", type=_int, default=None, help="only decompile and emit the function at this address")
    ap.add_argument("--endian", choices=["big", "little"], default="big", help="target endianness (default: big)")
    ap.add_argument("--no-banner", action="store_true", help="omit banner header comments")
    args = ap.parse_args(argv)

    is_be = (args.endian == "big")
    prog = decompile_file(args.rom, base=args.base,
                          extra_entries=tuple(args.entry) if args.entry else (),
                          is_be=is_be)

    if args.func is not None:
        f = prog.funcs.get(args.func)
        if f is None:
            ap.error("no function decoded at 0x%X (try --entry 0x%X)" % (args.func, args.func))
        text = "\n".join(f.lines)
    else:
        text = prog.listing(banner=not args.no_banner)

    if args.out:
        with open(args.out, "w", encoding="utf-8") as fp:
            fp.write(text + "\n")
        print("lm32dec: base 0x%X, %d functions -> %s" % (prog.base, len(prog.funcs), args.out), file=sys.stderr)
    else:
        print(text)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```py
"""
Database-backed persistence layer for lm32dec using IDA netnodes.

Stores and retrieves per-function:
- Variable renames (old_name -> new_name)
- Variable type overrides (var_name -> type_str)
- Function prototype overrides (prototype string)
- Global UI preferences (sync with disassembly enabled)
- Definition-site variable locators
- Statement comments and number formats
- Window state persistence

When run outside IDA (headless tests), falls back to an in-memory dictionary.
"""

import json

try:
    import ida_netnode
except ImportError:
    ida_netnode = None

NODE_NAME = "$ lm32dec"
_MEM_STORAGE = {}
_MEM_SYNC = True


def _get_node():
    if ida_netnode is None:
        return None
    try:
        node = ida_netnode.netnode()
        node.create(NODE_NAME)
        return node
    except Exception:
        return None


def get_func_data(func_ea):
    """Retrieve persistent renames, types, and prototype for a function."""
    node = _get_node()
    if node is None:
        return _MEM_STORAGE.get(func_ea, {"renames": {}, "types": {}, "proto": None})
    try:
        val = node.supstr(func_ea)
        if val:
            return json.loads(val)
    except Exception:
        pass
    return {"renames": {}, "types": {}, "proto": None}


def set_func_data(func_ea, data):
    """Save persistent renames, types, and prototype for a function."""
    node = _get_node()
    if node is None:
        _MEM_STORAGE[func_ea] = data
        return
    try:
        node.supset(func_ea, json.dumps(data))
    except Exception:
        _MEM_STORAGE[func_ea] = data


def set_var_rename(func_ea, old_name, new_name):
    """Save a variable rename (e.g. v0 -> counter, or counter -> new_counter).
    
    If new_name is empty or None, the rename is cleared, reverting to default.
    """
    data = get_func_data(func_ea)
    renames = data.setdefault("renames", {})

    # If old_name was previously mapped from a canonical name, update that mapping
    canonical = None
    for k, v in renames.items():
        if v == old_name:
            canonical = k
            break
    key = canonical if canonical is not None else old_name

    if not new_name or new_name == key:
        renames.pop(key, None)
    else:
        renames[key] = new_name
    set_func_data(func_ea, data)


def set_var_type(func_ea, var_name, type_str):
    """Save a variable type override (e.g. v0 -> uint32_t *).
    
    If type_str is empty or None, the override is cleared.
    """
    data = get_func_data(func_ea)
    types = data.setdefault("types", {})
    if not type_str:
        types.pop(var_name, None)
    else:
        types[var_name] = type_str.strip()
    set_func_data(func_ea, data)


def set_func_proto(func_ea, proto_str):
    """Save a function prototype override (e.g. int sub_800D7A(int a0, int a1)).
    
    If proto_str is empty or None, the override is cleared.
    """
    data = get_func_data(func_ea)
    if not proto_str:
        data["proto"] = None
    else:
        data["proto"] = proto_str.strip()
    set_func_data(func_ea, data)


def get_sync_enabled():
    """Check if 'Sync with Disassembly' is enabled (defaults to True)."""
    global _MEM_SYNC
    node = _get_node()
    if node is None:
        return _MEM_SYNC
    try:
        val = node.altval(0)
        return val != 2  # 2 means explicitly disabled; 0 or 1 means enabled
    except Exception:
        return _MEM_SYNC


def set_sync_enabled(enabled):
    """Persist the 'Sync with Disassembly' preference."""
    global _MEM_SYNC
    _MEM_SYNC = bool(enabled)
    node = _get_node()
    if node is not None:
        try:
            node.altset(0, 1 if enabled else 2)
        except Exception:
            pass


def clear_func_data(func_ea):
    """Clear all persistent customizations for a function."""
    node = _get_node()
    if node is None:
        _MEM_STORAGE.pop(func_ea, None)
        return
    try:
        node.supdel(func_ea)
    except Exception:
        pass


def set_statement_cmt(func_ea, stmt_ea, cmt_str):
    """Save a statement comment attached to instruction linear address."""
    data = get_func_data(func_ea)
    cmts = data.setdefault("cmts", {})
    ea_key = hex(stmt_ea) if isinstance(stmt_ea, int) else str(stmt_ea)
    if not cmt_str:
        cmts.pop(ea_key, None)
    else:
        cmts[ea_key] = cmt_str.strip()
    set_func_data(func_ea, data)


def get_statement_cmt(func_ea, stmt_ea):
    """Retrieve saved comment for a statement."""
    data = get_func_data(func_ea)
    ea_key = hex(stmt_ea) if isinstance(stmt_ea, int) else str(stmt_ea)
    return data.get("cmts", {}).get(ea_key)


def set_numform(func_ea, stmt_ea, op_idx, form_str):
    """Save immediate constant display format ('hex', 'dec', 'char')."""
    data = get_func_data(func_ea)
    numforms = data.setdefault("numforms", {})
    key = f"{hex(stmt_ea) if isinstance(stmt_ea, int) else str(stmt_ea)}:{op_idx}"
    if not form_str or form_str == "default":
        numforms.pop(key, None)
    else:
        numforms[key] = form_str.lower()
    set_func_data(func_ea, data)


def get_numform(func_ea, stmt_ea, op_idx=0):
    """Retrieve saved format for an immediate constant."""
    data = get_func_data(func_ea)
    key = f"{hex(stmt_ea) if isinstance(stmt_ea, int) else str(stmt_ea)}:{op_idx}"
    return data.get("numforms", {}).get(key)


def toggle_iflag(func_ea, branch_ea):
    """Toggle inverted condition flag for an if statement."""
    data = get_func_data(func_ea)
    iflags = data.setdefault("iflags", [])
    ea_val = branch_ea if isinstance(branch_ea, int) else int(branch_ea, 16)
    if ea_val in iflags:
        iflags.remove(ea_val)
        inverted = False
    else:
        iflags.append(ea_val)
        inverted = True
    set_func_data(func_ea, data)
    return inverted


def is_iflag_inverted(func_ea, branch_ea):
    """Check if if-condition at branch_ea is marked inverted."""
    data = get_func_data(func_ea)
    ea_val = branch_ea if isinstance(branch_ea, int) else int(branch_ea, 16)
    return ea_val in data.get("iflags", [])


WIN_STATE_KEY = 0x7FFFFFFF
_MEM_WIN_STATE = {}


def save_window_state(is_open, func_ea, lineno=0, col=0, mode="c"):
    """Persist decompiler window state (open status, function, caret, mode) to netnode."""
    state = {
        "is_open": bool(is_open),
        "func_ea": func_ea,
        "lineno": lineno,
        "col": col,
        "mode": mode,
    }
    node = _get_node()
    if node is not None:
        try:
            node.setblob(json.dumps(state).encode("utf-8"), WIN_STATE_KEY, "S")
        except Exception:
            pass
    _MEM_WIN_STATE.clear()
    _MEM_WIN_STATE.update(state)


def load_window_state():
    """Retrieve saved decompiler window state from netnode."""
    node = _get_node()
    if node is not None:
        try:
            raw = node.getblob(WIN_STATE_KEY, "S")
            if raw:
                return json.loads(raw.decode("utf-8"))
        except Exception:
            pass
    return dict(_MEM_WIN_STATE)
```

`lm32dec/decoder.py`:

```py
"""
Standalone LatticeMico32 (LM32) decoder.

Fixed 32-bit instructions (4 bytes).
Dual-endian support: supports both Big-Endian (native LM32) and Little-Endian (PS Vita LM32).

Operand ``mode`` values:
    reg     register (``reg`` = 0..31 GPR, or CSR index 0..31)
    imm     immediate (``value``)
    near    code target (``addr``)
    displ   disp(reg) (``base_reg``, ``disp``, ``width``)
    phrase  (reg)     (``base_reg``, ``disp=0``, ``width``)
"""

from . import isa


def _sx(x, b):
    m = 1 << (b - 1)
    x &= (1 << b) - 1
    return (x ^ m) - m


class Operand:
    __slots__ = ("mode", "reg", "value", "addr", "base_reg", "disp", "width", "name")

    def __init__(self, mode, reg=0, value=0, addr=0, base_reg=0, disp=0, width=4, name=None):
        self.mode = mode
        self.reg = reg
        self.value = value
        self.addr = addr
        self.base_reg = base_reg
        self.disp = disp
        self.width = width
        self.name = name

    def __repr__(self):
        if self.mode == "reg":
            return f"reg({isa.reg(self.reg) if isinstance(self.reg, int) else self.reg})"
        if self.mode == "imm":
            return f"imm(0x{self.value:X})"
        if self.mode == "near":
            return f"near(0x{self.addr:X})"
        if self.mode in ("displ", "phrase"):
            return f"{self.mode}({isa.reg(self.base_reg)}+{self.disp}, w={self.width})"
        return f"Op({self.mode})"


class SwitchInfo:
    __slots__ = ("jmp_ea", "table_ea", "ncases", "lowcase", "default_ea",
                 "bounds_ea", "idx_reg", "cases", "targets", "setup_eas")

    def __init__(self, jmp_ea, table_ea, ncases, lowcase, default_ea,
                 bounds_ea, idx_reg, cases, targets, setup_eas):
        self.jmp_ea = jmp_ea
        self.table_ea = table_ea
        self.ncases = ncases
        self.lowcase = lowcase
        self.default_ea = default_ea
        self.bounds_ea = bounds_ea
        self.idx_reg = idx_reg
        self.cases = cases
        self.targets = targets
        self.setup_eas = setup_eas


class Insn:
    __slots__ = ("ea", "size", "mnem", "ops", "switch_info")

    def __init__(self, ea):
        self.ea = ea
        self.size = 4
        self.mnem = None
        self.ops = []
        self.switch_info = None

    def __repr__(self):
        op_strs = [str(o) for o in self.ops]
        return f"<Insn 0x{self.ea:08X} {self.mnem:<7} {', '.join(op_strs)}>"


def in_bounds(image, ea, base=0, size=4):
    if hasattr(image, "contains"):
        return image.contains(ea, size)
    off = ea - base
    return 0 <= off and off + size <= len(image)


def read_u32(image, ea, base=0, is_be=False):
    """Read a 32-bit unsigned integer with specified endianness."""
    if hasattr(image, "get_u32"):
        return image.get_u32(ea)
    off = ea - base
    if off < 0 or off + 4 > len(image):
        return None
    b0, b1, b2, b3 = image[off], image[off + 1], image[off + 2], image[off + 3]
    if is_be:
        return (b0 << 24) | (b1 << 16) | (b2 << 8) | b3
    else:
        return b0 | (b1 << 8) | (b2 << 16) | (b3 << 24)


# Bitfield extraction
def f_opcode(w): return (w >> 26) & 0x3F
def f_r0(w): return (w >> 21) & 0x1F
def f_r1(w): return (w >> 16) & 0x1F
def f_r2(w): return (w >> 11) & 0x1F
def f_shift(w): return w & 0x1F
def f_imm16(w): return _sx(w & 0xFFFF, 16)
def f_uimm16(w): return w & 0xFFFF
def f_call26(w): return _sx(w & 0x03FFFFFF, 26)


def decode_one(image, ea, base=0, is_be=False):
    """Decode a single 32-bit LM32 instruction at ea."""
    word = read_u32(image, ea, base=base, is_be=is_be)
    if word is None:
        return None

    ins = Insn(ea)
    ins.size = 4
    opc = f_opcode(word)
    r0 = f_r0(word)
    r1 = f_r1(word)
    r2 = f_r2(word)
    imm16 = f_imm16(word)
    uimm16 = f_uimm16(word)
    shift = f_shift(word)
    call26 = f_call26(word)

    # Register operand constructors
    def reg_op(idx):
        return Operand("reg", reg=idx)

    def imm_op(val):
        return Operand("imm", value=val)

    def near_op(target):
        return Operand("near", addr=target & 0xFFFFFFFF)

    def displ_op(base_r, disp, width):
        mode = "phrase" if disp == 0 else "displ"
        return Operand(mode, base_reg=base_r, disp=disp, width=width)

    # 0x00 - 0x0F
    if opc == 0x00:
        ins.mnem = "srui"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(shift)]
    elif opc == 0x01:
        ins.mnem = "nori"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x02:
        ins.mnem = "muli"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(imm16)]
    elif opc == 0x03:
        ins.mnem = "sh"
        ins.ops = [displ_op(r0, imm16, width=2), reg_op(r1)]
    elif opc == 0x04:
        ins.mnem = "lb"
        ins.ops = [reg_op(r1), displ_op(r0, imm16, width=1)]
    elif opc == 0x05:
        ins.mnem = "sri"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(shift)]
    elif opc == 0x06:
        ins.mnem = "xori"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x07:
        ins.mnem = "lh"
        ins.ops = [reg_op(r1), displ_op(r0, imm16, width=2)]
    elif opc == 0x08:
        ins.mnem = "andi"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x09:
        ins.mnem = "xnori"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x0A:
        ins.mnem = "lw"
        ins.ops = [reg_op(r1), displ_op(r0, imm16, width=4)]
    elif opc == 0x0B:
        ins.mnem = "lhu"
        ins.ops = [reg_op(r1), displ_op(r0, imm16, width=2)]
    elif opc == 0x0C:
        ins.mnem = "sb"
        ins.ops = [displ_op(r0, imm16, width=1), reg_op(r1)]
    elif opc == 0x0D:
        if word == 0x34000000:
            ins.mnem = "nop"
            ins.ops = []
        elif r0 == 0:
            ins.mnem = "mvi"
            ins.ops = [reg_op(r1), imm_op(imm16)]
        else:
            ins.mnem = "addi"
            ins.ops = [reg_op(r1), reg_op(r0), imm_op(imm16)]
    elif opc == 0x0E:
        if r0 == 0:
            ins.mnem = "mvui"
            ins.ops = [reg_op(r1), imm_op(uimm16)]
        else:
            ins.mnem = "ori"
            ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x0F:
        ins.mnem = "sli"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(shift)]

    # 0x10 - 0x1F
    elif opc == 0x10:
        ins.mnem = "lbu"
        ins.ops = [reg_op(r1), displ_op(r0, imm16, width=1)]
    elif opc == 0x11:
        ins.mnem = "be"
        ins.ops = [reg_op(r0), reg_op(r1), near_op(ea + (imm16 << 2))]
    elif opc == 0x12:
        ins.mnem = "bg"
        ins.ops = [reg_op(r0), reg_op(r1), near_op(ea + (imm16 << 2))]
    elif opc == 0x13:
        ins.mnem = "bge"
        ins.ops = [reg_op(r0), reg_op(r1), near_op(ea + (imm16 << 2))]
    elif opc == 0x14:
        ins.mnem = "bgeu"
        ins.ops = [reg_op(r0), reg_op(r1), near_op(ea + (imm16 << 2))]
    elif opc == 0x15:
        ins.mnem = "bgu"
        ins.ops = [reg_op(r0), reg_op(r1), near_op(ea + (imm16 << 2))]
    elif opc == 0x16:
        ins.mnem = "sw"
        ins.ops = [displ_op(r0, imm16, width=4), reg_op(r1)]
    elif opc == 0x17:
        ins.mnem = "bne"
        ins.ops = [reg_op(r0), reg_op(r1), near_op(ea + (imm16 << 2))]
    elif opc == 0x18:
        ins.mnem = "andhi"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x19:
        ins.mnem = "cmpei"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(imm16)]
    elif opc == 0x1A:
        ins.mnem = "cmpgi"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(imm16)]
    elif opc == 0x1B:
        ins.mnem = "cmpgei"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(imm16)]
    elif opc == 0x1C:
        ins.mnem = "cmpgeui"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x1D:
        ins.mnem = "cmpgui"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x1E:
        if r0 == 0:
            ins.mnem = "mvhi"
            ins.ops = [reg_op(r1), imm_op(uimm16)]
        else:
            ins.mnem = "orhi"
            ins.ops = [reg_op(r1), reg_op(r0), imm_op(uimm16)]
    elif opc == 0x1F:
        ins.mnem = "cmpnei"
        ins.ops = [reg_op(r1), reg_op(r0), imm_op(imm16)]

    # 0x20 - 0x2F
    elif opc == 0x20:
        ins.mnem = "sru"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x21:
        ins.mnem = "nor"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x22:
        ins.mnem = "mul"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x23:
        ins.mnem = "divu"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x24:
        ins.mnem = "rcsr"
        # rcsr r1, csr(r0)
        ins.ops = [reg_op(r1), Operand("reg", reg=isa.csr(r0))]
    elif opc == 0x25:
        ins.mnem = "sr"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x26:
        ins.mnem = "xor"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x27:
        ins.mnem = "div"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x28:
        ins.mnem = "and"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x29:
        if r1 == 0:
            ins.mnem = "not"
            ins.ops = [reg_op(r2), reg_op(r0)]
        else:
            ins.mnem = "xnor"
            ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x2A:
        ins.mnem = "x_invalid"
        ins.ops = []
    elif opc == 0x2B:
        imm = word & 0x1F
        if imm == 2:
            ins.mnem = "break"
            ins.ops = []
        elif imm == 7:
            ins.mnem = "scall"
            ins.ops = []
        else:
            ins.mnem = "raise"
            ins.ops = [imm_op(imm)]
    elif opc == 0x2C:
        ins.mnem = "sextb"
        ins.ops = [reg_op(r2), reg_op(r0)]
    elif opc == 0x2D:
        ins.mnem = "add"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x2E:
        if r1 == 0:
            ins.mnem = "mv"
            ins.ops = [reg_op(r2), reg_op(r0)]
        else:
            ins.mnem = "or"
            ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x2F:
        ins.mnem = "sl"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]

    # 0x30 - 0x3F
    elif opc == 0x30:
        if r0 == 29:  # ra
            ins.mnem = "ret"
            ins.ops = []
        elif r0 == 30:  # ea
            ins.mnem = "eret"
            ins.ops = []
        elif r0 == 31:  # ba
            ins.mnem = "bret"
            ins.ops = []
        else:
            ins.mnem = "b"
            ins.ops = [reg_op(r0)]
    elif opc == 0x31:
        ins.mnem = "modu"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x32:
        ins.mnem = "sub"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x33:
        ins.mnem = "user"
        ins.ops = [imm_op(word & 0x7FF)]
    elif opc == 0x34:
        ins.mnem = "wcsr"
        # wcsr csr(r0), r1
        ins.ops = [Operand("reg", reg=isa.csr(r0)), reg_op(r1)]
    elif opc == 0x35:
        ins.mnem = "mod"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x36:
        ins.mnem = "call"
        ins.ops = [reg_op(r0)]
    elif opc == 0x37:
        ins.mnem = "sexth"
        ins.ops = [reg_op(r2), reg_op(r0)]
    elif opc == 0x38:
        ins.mnem = "bi"
        ins.ops = [near_op(ea + (call26 << 2))]
    elif opc == 0x39:
        ins.mnem = "cmpe"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x3A:
        ins.mnem = "cmpg"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x3B:
        ins.mnem = "cmpge"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x3C:
        ins.mnem = "cmpgeu"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x3D:
        ins.mnem = "cmpgu"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    elif opc == 0x3E:
        ins.mnem = "calli"
        ins.ops = [near_op(ea + (call26 << 2))]
    elif opc == 0x3F:
        ins.mnem = "cmpne"
        ins.ops = [reg_op(r2), reg_op(r0), reg_op(r1)]
    else:
        ins.mnem = "x_invalid"
        ins.ops = []

    return ins


def target_of(ins):
    """Return branch/call near target address if present, else None."""
    for op in ins.ops:
        if op.mode == "near":
            return op.addr
    return None


def decode(image, entries=(), base=0, is_be=False, stop_at=None):
    """Worklist-driven recursive decoder covering reachable code blocks."""
    insns = {}
    calls = set()
    work = list(entries)
    seen = set()

    stop_set = set(stop_at) if stop_at else set()

    while work:
        ea = work.pop()
        while ea not in insns:
            if stop_set and ea in stop_set:
                break
            if not in_bounds(image, ea, base=base, size=4):
                break
            ins = decode_one(image, ea, base=base, is_be=is_be)
            if ins is None:
                break
            insns[ea] = ins

            m = ins.mnem
            if m in isa.CALL:
                tgt = target_of(ins)
                if tgt is not None:
                    calls.add(tgt)
                ea += 4
            elif m in isa.COND_BRANCH:
                tgt = target_of(ins)
                if tgt is not None and tgt not in seen:
                    work.append(tgt)
                    seen.add(tgt)
                ea += 4
            elif m in ("bi",):
                tgt = target_of(ins)
                if tgt is not None and tgt not in seen:
                    work.append(tgt)
                    seen.add(tgt)
                break
            elif m in isa.STOP:
                break
            else:
                ea += 4

    return insns, calls
```

`lm32dec/frame.py`:

```py
"""
Stack-frame recovery and cleanup for LatticeMico32 (LM32).

LM32 stack convention:
- sp = r28 (stack pointer, grows down toward lower addresses)
- fp = r27 (frame pointer, optional)
- ra = r29 (return address link register)
- Callee-saved registers: r11..r25, gp (r26), fp (r27), sp (r28), and ra (r29)

This module:
1. Detects stack frame allocation (`addi sp, sp, -frame_size`) and deallocation (`addi sp, sp, frame_size`).
2. Identifies callee-saved register save/restore pairs and hides prologue/epilogue boilerplate.
3. Normalizes stack offsets to canonical coordinates [0..frame_size).
4. Rewrites stack accesses:
   - off >= frame_size -> incoming stack arguments (`arg_0, arg_4, ...`)
   - off < frame_size  -> local variables (`var_XX`)
   - address of stack slot (e.g. `addi r1, sp, off`) -> `&var_XX`
"""

from . import ir

FP = "fp"
SP = "sp"
RA = "ra"

CALLEE_SAVED = frozenset(
    [f"r{i}" for i in range(11, 26)] + ["gp", "fp", "sp", "ra"]
)


def _sp_off(addr):
    """Return displacement if addr is sp/fp / sp+const, else None."""
    if isinstance(addr, ir.Reg) and addr.name in (SP, FP):
        return 0
    if (isinstance(addr, ir.Bin) and addr.op == "+"
            and isinstance(addr.l, ir.Reg) and addr.l.name in (SP, FP)
            and isinstance(addr.r, ir.Const)):
        return addr.r.value
    return None


def _sp_adjust_delta(stmt):
    """If stmt is `sp = sp + K` or `sp = sp - K`, return signed delta, else None."""
    if not (isinstance(stmt, ir.Assign) and isinstance(stmt.dst, ir.Reg) and stmt.dst.name == SP):
        return None
    if isinstance(stmt.src, ir.Bin) and isinstance(stmt.src.l, ir.Reg) and stmt.src.l.name == SP:
        if isinstance(stmt.src.r, ir.Const):
            v = stmt.src.r.value
            signed_v = (v - 0x100000000) if v >= 0x80000000 else v
            if stmt.src.op == "+":
                return signed_v
            if stmt.src.op == "-":
                return -signed_v
    return None


def _compute_sp_profile(func):
    """Compute `(frame_size, entry_delta)` across func."""
    entry_delta = {func.entry: 0}
    min_delta = 0
    for b in func.ordered():
        cur = entry_delta.get(b.start, min_delta)
        for s in b.stmts:
            d = _sp_adjust_delta(s)
            if d is not None:
                cur += d
                if cur < min_delta:
                    min_delta = cur
        for _, tgt in b.succ:
            if tgt in func.blocks and tgt not in entry_delta:
                entry_delta[tgt] = cur
    frame_size = -min_delta
    return frame_size, entry_delta


def _canon_off(raw_off, cur_delta, frame_size):
    if raw_off is None:
        return None
    signed_raw = (raw_off - 0x100000000) if raw_off >= 0x80000000 else raw_off
    return (cur_delta + frame_size) + signed_raw


def _saved_slots(func, frame_size, entry_delta):
    """Find canonical offsets holding callee-saved registers or ra."""
    stores, loads = {}, {}
    for b in func.ordered():
        cur_delta = entry_delta.get(b.start, -frame_size)
        for s in b.stmts:
            d = _sp_adjust_delta(s)
            if d is not None:
                cur_delta += d
                continue
            if not isinstance(s, ir.Assign):
                continue
            if isinstance(s.dst, ir.Mem) and isinstance(s.src, ir.Reg) and s.src.name in CALLEE_SAVED:
                off = _canon_off(_sp_off(s.dst.addr), cur_delta, frame_size)
                if off is not None and 0 <= off < frame_size:
                    stores.setdefault(off, set()).add(s.src.name)
            elif isinstance(s.dst, ir.Reg) and isinstance(s.src, ir.Mem) and s.dst.name in CALLEE_SAVED:
                off = _canon_off(_sp_off(s.src.addr), cur_delta, frame_size)
                if off is not None and 0 <= off < frame_size:
                    loads.setdefault(off, set()).add(s.dst.name)

    common = {}
    for off in set(stores) & set(loads):
        shared = stores[off] & loads[off]
        if shared:
            common[off] = shared
    return common


def rewrite(func):
    """Rewrite stack slots to named locals/arguments and strip prologue/epilogue boilerplate."""
    frame_size, entry_delta = _compute_sp_profile(func)
    saved = _saved_slots(func, frame_size, entry_delta) if frame_size > 0 else {}

    func.locals = getattr(func, "locals", {}) or {}
    func.stack_args = getattr(func, "stack_args", {}) or {}

    def slot_name(canon_off, width=4):
        if canon_off >= frame_size:
            arg_off = canon_off - frame_size
            name = f"arg_{arg_off:X}"
            func.stack_args[arg_off] = (name, width)
            return name
        else:
            var_off = frame_size - canon_off
            name = f"var_{var_off:X}"
            func.locals[name] = max(func.locals.get(name, 1), width)
            return name

    def make_xf(cur_delta):
        def xf(e):
            if isinstance(e, ir.Mem):
                off = _canon_off(_sp_off(e.addr), cur_delta, frame_size)
                if off is not None and off not in saved:
                    return ir.Reg(slot_name(off, e.width))
                addr = xf(e.addr) if isinstance(e.addr, ir.Expr) else e.addr
                return ir.Mem(addr, e.width, e.signed, getattr(e, 'name', None))
            if isinstance(e, ir.Bin):
                off = _canon_off(_sp_off(e), cur_delta, frame_size)
                if off is not None and off not in saved:
                    return ir.Un("&", ir.Reg(slot_name(off, 4)))
                return ir.Bin(e.op, xf(e.l), xf(e.r))
            if isinstance(e, ir.Un):
                return ir.Un(e.op, xf(e.e))
            if isinstance(e, ir.IntrExpr):
                return ir.IntrExpr(e.name, [xf(a) for a in e.args])
            return e
        return xf

    def drop(s, cur_delta, is_ret_block):
        # sp adjust: sp = sp + K or sp = fp
        if isinstance(s, ir.Assign) and isinstance(s.dst, ir.Reg) and s.dst.name == SP:
            if isinstance(s.src, ir.Bin) and isinstance(s.src.l, ir.Reg) and s.src.l.name == SP:
                return True
            if isinstance(s.src, ir.Reg) and s.src.name in (SP, FP):
                return True
        # frame pointer setup: fp = sp
        if isinstance(s, ir.Assign) and isinstance(s.dst, ir.Reg) and s.dst.name == FP \
                and isinstance(s.src, ir.Reg) and s.src.name == SP:
            return True
        # callee-saved register save/restore
        if isinstance(s, ir.Assign):
            if isinstance(s.dst, ir.Mem) and isinstance(s.src, ir.Reg):
                off = _canon_off(_sp_off(s.dst.addr), cur_delta, frame_size)
                if off in saved and s.src.name in saved[off]:
                    return True
            if isinstance(s.dst, ir.Reg) and isinstance(s.src, ir.Mem):
                off = _canon_off(_sp_off(s.src.addr), cur_delta, frame_size)
                if off in saved and s.dst.name in saved[off]:
                    return True
        return False

    for b in func.ordered():
        cur_delta = entry_delta.get(b.start, -frame_size)
        is_ret_block = (b.term == "ret")
        out = []
        for s in b.stmts:
            d = _sp_adjust_delta(s)
            if d is not None:
                cur_delta += d
            if drop(s, cur_delta, is_ret_block):
                continue

            xf = make_xf(cur_delta)
            if isinstance(s, ir.Assign):
                s.src = xf(s.src)
                if isinstance(s.dst, ir.Mem):
                    off = _canon_off(_sp_off(s.dst.addr), cur_delta, frame_size)
                    if off is not None and off not in saved:
                        s.dst = ir.Reg(slot_name(off, s.dst.width))
                    else:
                        s.dst = ir.Mem(xf(s.dst.addr) if isinstance(s.dst.addr, ir.Expr) else s.dst.addr,
                                       s.dst.width, s.dst.signed, getattr(s.dst, 'name', None))
            elif isinstance(s, ir.Branch):
                s.cexpr = xf(s.cexpr)
            elif isinstance(s, ir.Switch):
                s.expr = xf(s.expr)
            elif isinstance(s, ir.Intrinsic):
                s.args = [xf(a) for a in s.args]
            elif isinstance(s, ir.Call) and s.expr is not None:
                s.expr = xf(s.expr)
            out.append(s)
        b.stmts = out

    return func


class FrameInfo:
    def __init__(self, locals=None, stack_args=None, hidden_stmts=None, virtual_vars=None, user_renames=None, user_types=None, ida_stkvars=None):
        self.locals = locals or {}
        self.stack_args = stack_args or {}
        self.hidden_stmts = hidden_stmts or set()
        self.virtual_vars = virtual_vars or {}
        self.user_renames = user_renames or {}
        self.user_types = user_types or {}
        self.ida_stkvars = ida_stkvars or {}


def analyze_frame(func, ida_frame_info=None):
    """Analyze stack frame, rewrite stack accesses, and return FrameInfo."""
    rewrite(func)
    locals_dict = dict(getattr(func, "locals", {}) or {})
    stack_args = dict(getattr(func, "stack_args", {}) or {})
    return FrameInfo(locals=locals_dict, stack_args=stack_args)
```

```py
    | (?P<hex>-?\b0[xX][0-9A-Fa-f]+)

def _tag(t, c):
    if ida_lines is not None:
        return ida_lines.COLSTR(t, c)
    return t


def colorize(line, highlight_ident=None):
    if not line:
        return line
    if ida_lines is None:
        return line
    st = line.lstrip()
    if st.startswith(("//", "/*", "*", "*/")) and not highlight_ident:
        return _tag(line, ida_lines.SCOLOR_AUTOCMT)
    if _LABEL.match(st) and not highlight_ident:
        return _tag(line, ida_lines.SCOLOR_CREFTAIL)
    out, pos, n = [], 0, len(line)
    extra_col = getattr(ida_lines, "SCOLOR_EXTRA", getattr(ida_lines, "SCOLOR_ERROR", "\x01\x32"))
    while pos < n:
        m = _TOK.match(line, pos)
        if not m:
            out.append(line[pos])
            pos += 1
            continue
        k, t = m.lastgroup, m.group()
        pos = m.end()
        if k == "ws":
            out.append(t)
        elif k == "comment":
            out.append(_tag(t, ida_lines.SCOLOR_AUTOCMT))
        elif k == "string":
            out.append(_tag(t, getattr(ida_lines, "SCOLOR_STRING", ida_lines.SCOLOR_SYMBOL)))
        elif k in ("hex", "num"):
            out.append(_tag(t, ida_lines.SCOLOR_NUMBER))
        elif k == "ident":
            if highlight_ident and t == highlight_ident:
                out.append(_tag(t, extra_col))
            else:
                out.append(_tag(t, _ic(t, line, pos)))
        else:
            out.append(_tag(t, ida_lines.SCOLOR_SYMBOL))
    return "".join(out)


def _ic(t, line, after):
    if ida_lines is None:
        return ""
    if t in C_KEYWORDS:
        return ida_lines.SCOLOR_KEYWORD
    if t in C_TYPES:
        return ida_lines.SCOLOR_TYPE
    if t.startswith(("loc_", "sub_")):
        return ida_lines.SCOLOR_CREFTAIL
    if t in INTRINSICS or _CALL.match(line, after):
        return ida_lines.SCOLOR_CNAME
    return ida_lines.SCOLOR_REG


def colorize_all(lines):
    return [colorize(x) for x in lines]
```

```py
class SegmentedImage:
    """Sparse segment-backed memory image that avoids reading unmapped address gaps."""
    def __init__(self, segments, is_be=True):
        # segments: list of (start_ea, end_ea, bytearray) sorted by start_ea
        self.segments = sorted(segments, key=lambda s: s[0])
        self.base = self.segments[0][0] if self.segments else 0
        self._total = sum(len(b) for _, _, b in self.segments)
        self.is_be = is_be

    def __len__(self):
        return self._total

    def contains(self, ea, size=1):
        for start, end, _ in self.segments:
            if start <= ea:
                if ea + size <= end:
                    return True
            else:
                break
        return False

    def get_u16(self, ea):
        for start, end, buf in self.segments:
            if start <= ea:
                if ea + 2 <= end:
                    off = ea - start
                    if self.is_be:
                        return (buf[off] << 8) | buf[off + 1]
                    else:
                        return buf[off] | (buf[off + 1] << 8)
            else:
                break
        return None

    def get_u32(self, ea):
        for start, end, buf in self.segments:
            if start <= ea:
                if ea + 4 <= end:
                    off = ea - start
                    if self.is_be:
                        return ((buf[off] << 24) | (buf[off + 1] << 16)
                                | (buf[off + 2] << 8) | buf[off + 3])
                    else:
                        return (buf[off] | (buf[off + 1] << 8)
                                | (buf[off + 2] << 16) | (buf[off + 3] << 24))
            else:
                break
        return None

def _resolve_op_name(ea, n, op=None):
    """Resolve an instruction operand to a named symbol in IDA using structured instruction decoding."""
    try:
        import ida_ua, ida_name, ida_bytes, idautils
        insn = ida_ua.insn_t()
        if ida_ua.decode_insn(insn, ea) > 0 and n < len(insn.ops):
            ida_op = insn.ops[n]
            if ida_op.type != ida_ua.o_void:
                # 1. Direct memory or code target
                if ida_op.type in (ida_ua.o_mem, ida_ua.o_near):
                    target_ea = ida_op.addr
                    name = ida_name.get_name(target_ea)
                    if name and not name.startswith(("unk_", "byte_", "word_", "dword_", "loc_", "sub_")):
                        return name
                # 2. Immediate operand marked as offset or referencing mapped address
                elif ida_op.type == ida_ua.o_imm:
                    flags = ida_bytes.get_flags(ea)
                    val = ida_op.value & 0xFFFFFFFF
                    if ida_bytes.is_off(flags, n) or (0x1000 <= val < 0xFFFFFFFF):
                        name = ida_name.get_name(val)
                        if name and not name.startswith(("unk_", "byte_", "word_", "dword_", "loc_", "sub_")):
                            return name

        # 3. Data cross references from this instruction
        for x in idautils.XrefsFrom(ea):
            if not x.iscode:
                xname = ida_name.get_name(x.to)
                if xname and not xname.startswith(("unk_", "byte_", "word_", "dword_", "loc_", "sub_")):
                    return xname

        # 4. Fallback to decoder op value if provided
        if op is not None:
            val = getattr(op, "value", None) or getattr(op, "addr", None)
            if val is not None and isinstance(val, int) and (val >= 0x1000):
                val_name = ida_name.get_name(val)
                if val_name and not val_name.startswith(("unk_", "byte_", "word_", "dword_", "loc_", "sub_")):
                    return val_name
    except Exception:
        pass
    return None

def _ida_frame_info(ea):
    """Read stack frame structure details and stack variable operands from IDA Pro using native API."""
    try:
        import ida_funcs, ida_frame, ida_typeinf, ida_ua
        from ida_idaapi import BADADDR
        pfn = ida_funcs.get_func(ea)
        if not pfn:
            return None
        tif = ida_typeinf.tinfo_t()
        members = {}
        if ida_frame.get_func_frame(tif, pfn):
            udt = ida_typeinf.udt_type_data_t()
            if tif.get_udt_details(udt):
                frsize = getattr(pfn, "frsize", 0)
                for m in udt:
                    actual_off = (m.offset // 8) - frsize
                    members[actual_off] = (m.name, m.size // 8, m.type.dstr())

        off_args = ida_frame.frame_off_args(pfn)
        stkvars_by_ea = {}
        cur = pfn.start_ea
        insn = ida_ua.insn_t()
        while cur < pfn.end_ea:
            if ida_ua.decode_insn(insn, cur) > 0:
                for n in range(6):
                    op = insn.ops[n]
                    if op.type == ida_ua.o_void:
                        break
                    soff = ida_frame.calc_stkvar_struc_offset(pfn, insn, n)
                    if soff != BADADDR and soff is not None:
                        if soff >= (1 << 63):
                            soff -= (1 << 64)
                        m = members.get(soff)
                        name = m[0] if m else ida_frame.build_stkvar_name(pfn, soff)
                        size = m[1] if m else 4
                        if soff < 0:
                            is_arg = False
                            if name.startswith("arg_"):
                                name = "var_%X" % abs(soff)
                        else:
                            is_arg = (soff >= off_args) if off_args != BADADDR else name.startswith("arg_")
                        stkvars_by_ea.setdefault(cur, {})[n] = (soff, name, size, is_arg)
            cur += insn.size if insn.size > 0 else 4
        return _IdaFrameInfo(members=members, stkvars_by_ea=stkvars_by_ea)
    except Exception:
        return None


def _get_ida_func_proto(ea):
    """Retrieve function prototype from IDA type system if set."""
    try:
        import ida_typeinf, ida_name
        tif = ida_typeinf.tinfo_t()
        if ida_typeinf.get_tinfo(tif, ea):
            name = ida_name.get_name(ea) or ("sub_%X" % ea)
            return tif.dstr() + " " + name
    except Exception:
        pass
    return None


def _get_caller_consensus(entry):
    """Infer whether callers set parameter registers (r1..r8) before calling entry."""
    try:
        import idautils, ida_ua, ida_idp, ida_bytes, ida_idaapi
        caller_eas = list(idautils.CodeRefsTo(entry, 0))
        if not caller_eas:
            return None
        counts = {i: 0 for i in range(1, 9)}
        valid = 0
        insn = ida_ua.insn_t()
        for c in caller_eas:
            cur = c
            found = set()
            count = 0
            while cur != ida_idaapi.BADADDR and cur >= c - 48 and count < 12:
                cur = ida_bytes.prev_head(cur, 0)
                if cur == ida_idaapi.BADADDR:
                    break
                if ida_ua.decode_insn(insn, cur) == 0:
                    break
                mnem = insn.get_canon_mnem().lower()
                count += 1
                if mnem in ("b", "bi", "eret", "bret") and cur != c:
                    break
                # Check destination operand if it writes to r1..r8
                if len(insn.ops) > 0 and insn.ops[0].type == ida_ua.o_reg:
                    rname = ida_idp.get_reg_name(insn.ops[0].reg, insn.ops[0].dtype).lower().lstrip("$r")
                    try:
                        regnum = int(rname)
                        if 1 <= regnum <= 8 and regnum not in found:
                            found.add(regnum)
                    except ValueError:
                        pass
                if mnem in ("call", "calli"):
                    break
            valid += 1
            for regnum in found:
                counts[regnum] += 1
        if valid == 0:
            return None
        res = {}
        for r in range(1, 9):
            if (counts[r] / valid) >= 0.75:
                res[f"r{r}"] = True
        return res if res else None
    except Exception:
        return None


def _find_entry(image, base, ea, entset, is_be=True):
    """If ea is inside an un-functioned routine in IDA, locate its entry using instruction boundaries."""
    if ea in entset:
        return ea
    try:
        import ida_bytes, ida_ua, ida_idaapi
        cur = ea
        insn = ida_ua.insn_t()
        limit = max(base, cur - 0x400)
        while cur > limit:
            prev = ida_bytes.prev_head(cur, base)
            if prev == ida_idaapi.BADADDR:
                break
            if prev in entset:
                return prev
            if ida_ua.decode_insn(insn, prev) > 0:
                mnem = insn.get_canon_mnem().lower()
                # Unconditional returns/jumps in LM32
                if mnem in ("eret", "bret", "bi") or (mnem == "b" and insn.ops[0].type == ida_ua.o_reg and insn.ops[0].reg == 29):
                    return cur
                if mnem == "nop":
                    prev2 = ida_bytes.prev_head(prev, base)
                    if prev2 != ida_idaapi.BADADDR and ida_ua.decode_insn(insn, prev2) > 0:
                        m2 = insn.get_canon_mnem().lower()
                        if m2 in ("eret", "bret", "bi") or (m2 == "b" and insn.ops[0].type == ida_ua.o_reg and insn.ops[0].reg == 29):
                            return cur
            cur = prev
        if cur != ea:
            return cur
    except Exception:
        pass

    cur = ea & ~3
    limit = max(base, cur - 0x400)
    best = cur
    while cur > limit:
        prev4 = cur - 4
        ins4 = decoder.decode_one(image, prev4, base, is_be=is_be) if decoder.in_bounds(image, prev4, base, 4) else None
        if ins4 is not None:
            if ins4.mnem in ("eret", "bret", "bi"):
                return cur
            if ins4.mnem == "b" and getattr(ins4.ops[0], "reg", None) == 29:
                return cur
            if ins4.mnem == "nop":
                ins_before = decoder.decode_one(image, prev4 - 4, base, is_be=is_be)
                if ins_before is not None:
                    if ins_before.mnem in ("eret", "bret", "bi") or (ins_before.mnem == "b" and getattr(ins_before.ops[0], "reg", None) == 29):
                        return cur
        if prev4 in entset:
            return prev4
        cur -= 4
    return best


def _callee_arity(image, base, callee_ea, entset, is_be=True):
    if callee_ea in _ARITY_CACHE:
        return _ARITY_CACHE[callee_ea]
    stop = entset - {callee_ea}
    c_insns, _ = decoder.decode(image, entries=[callee_ea], base=base, stop_at=stop, is_be=is_be)
    c_func = cfg.build_func(c_insns, callee_ea, entset)
    if c_func is None:
        return None
    frame_info = frame.analyze_frame(c_func)
    opt.optimize(c_func)
    cons = _get_caller_consensus(callee_ea)
    sig = abi.analyze_calling_convention(c_func, frame_info=frame_info, caller_consensus=cons)
    n = len(sig.params)
    _ARITY_CACHE[callee_ea] = n
    _RET_CACHE[callee_ea] = sig.ret_type
    return n


def decompile_program():
    image, base, is_be = _image()
    if image is None:
        raise RuntimeError("lm32dec: no segments loaded")
    entries = _entries() or [base]
    insns, calls = decoder.decode(image, entries=entries, base=base, is_be=is_be)
    _annotate_operand_names(insns)
    funcs = cfg.build_functions(insns, calls, extra_entries=entries)
    namer = IdaNamer()

    # Pre-populate arity cache
    for entry, f in funcs.items():
        frame_info = frame.analyze_frame(f)
        opt.optimize(f)
        cons = _get_caller_consensus(entry)
        sig = abi.analyze_calling_convention(f, frame_info=frame_info, caller_consensus=cons)
        _ARITY_CACHE[entry] = len(sig.params)
        _RET_CACHE[entry] = sig.ret_type

    out = {}
    for entry, f in funcs.items():
        db_data = db.get_func_data(entry)
        u_renames = db_data.get("renames", {})
        u_types = db_data.get("types", {})
        u_proto = db_data.get("proto") or _get_ida_func_proto(entry)

        ida_info = _ida_frame_info(entry)
        frame_info = frame.analyze_frame(f, ida_frame_info=ida_info)
        frame_info.user_renames = u_renames
        frame_info.user_types = u_types

        callargs.rewrite(f, _ARITY_CACHE)
        opt.optimize(f)
        consensus = _get_caller_consensus(entry)
        sig = abi.analyze_calling_convention(f, frame_info=frame_info, user_proto=u_proto,
                                             ret_types=_RET_CACHE, caller_consensus=consensus)
        vars.recover_variables(f, sig=sig, frame_info=frame_info)
        tree = structure.structure(f)
        u_comments = db_data.get("cmts", {})
        u_numforms = db_data.get("numforms", {})
        u_iflags = db_data.get("iflags", [])
        lines = cgen.generate(f, tree, namer, frame_info=frame_info, sig=sig,
                              user_renames=u_renames, user_types=u_types,
                              user_comments=u_comments, user_numforms=u_numforms,
                              user_iflags=u_iflags)
        out[entry] = Function(entry, namer.code(entry), f, tree, lines)
    return Program(image, base, insns, out, namer, is_be=is_be)


def decompile_one(ea, show_casts=True):
    import ida_funcs
    image, base, is_be = _image()
    if image is None:
        raise RuntimeError("lm32dec: no segments loaded")
    entset = set(_entries())
    f = ida_funcs.get_func(ea)
    entry = f.start_ea if f is not None else _find_entry(image, base, ea, entset, is_be=is_be)
    entset.add(entry)
    stop = entset - {entry}
    insns, calls = decoder.decode(image, entries=[entry], base=base, stop_at=stop, is_be=is_be)
    _annotate_operand_names(insns)

    # Check if entry is a switch case fragment belonging to a parent function
    for ins in insns.values():
        if getattr(ins, "switch", None) is not None and entry in ins.switch.targets:
            parent_f = ida_funcs.get_func(ins.ea)
            if parent_f and parent_f.start_ea != entry:
                entry = parent_f.start_ea
                break

    all_entries = entset | calls
    func = cfg.build_func(insns, entry, all_entries)
    if func is None:
        raise RuntimeError("lm32dec: nothing decoded at 0x%X" % entry)
    namer = IdaNamer()

    db_data = db.get_func_data(entry)
    u_renames = db_data.get("renames", {})
    u_types = db_data.get("types", {})
    u_proto = db_data.get("proto") or _get_ida_func_proto(entry)
    u_comments = db_data.get("cmts", {})
    u_numforms = db_data.get("numforms", {})
    u_iflags = db_data.get("iflags", [])

    ida_info = _ida_frame_info(entry)
    frame_info = frame.analyze_frame(func, ida_frame_info=ida_info)
    frame_info.user_renames = u_renames
    frame_info.user_types = u_types

    # Resolve direct callee arities
    arity = {}
    for callee in func.calls:
        ca = _callee_arity(image, base, callee, all_entries, is_be=is_be)
        if ca is not None:
            arity[callee] = ca
    callargs.rewrite(func, arity)

    opt.optimize(func)
    consensus = _get_caller_consensus(entry)
    sig = abi.analyze_calling_convention(func, frame_info=frame_info, user_proto=u_proto,
                                         ret_types=_RET_CACHE, caller_consensus=consensus)
    vars.recover_variables(func, sig=sig, frame_info=frame_info)
    tree = structure.structure(func)
    lines = cgen.generate(func, tree, namer, frame_info=frame_info, sig=sig, banner=None,
                          user_renames=u_renames, user_types=u_types,
                          user_comments=u_comments, user_numforms=u_numforms,
                          user_iflags=u_iflags, show_casts=show_casts)
    return Function(entry, namer.code(entry), func, tree, lines)
```

```py
"""
IR for the LatticeMico32 (LM32) decompiler.

LM32 is a 32-bit RISC load-store architecture.
Conditional branches carry relational condition expressions directly (be, bne, bg, bge, bgu, bgeu),

    pass


class Const(Expr):

    def __init__(self, value, width="w", name=None):

        self.width = width
        self.name = name

        return isinstance(o, Const) and o.value == self.value

    def __repr__(self):
        return f"Const(0x{self.value:X})"

        self.width = width
```

`lm32dec/lifter.py`:

```py
"""
Lift decoded LM32 :class:`~lm32dec.decoder.Insn` objects into 3-address IR statements.

Translates LM32 machine instructions into high-level IR:
- Register r0 reads evaluate to ir.Const(0). Writes to r0 are dead assignments.
- Direct 2-register relational compares in conditional branches (be, bne, bg, bge, bgu, bgeu).
- Condition setting instructions (cmpe, cmpg, cmpge, cmpgu, cmpgeu, cmpne, and immediate variants).
- CSR reads/writes lifted to __rcsr / __wcsr intrinsics.
- Fixed 32-bit width and standard arithmetic/logical operators.
"""

from . import ir, isa


def _reg(i):
    if isinstance(i, str):
        if i == "r0":
            return ir.Const(0)
        return ir.Reg(i)
    if i == 0:
        return ir.Const(0)
    return ir.Reg(isa.reg(i))


def op_expr(op):
    m = op.mode
    name = getattr(op, "name", None)
    if m == "reg":
        return _reg(op.reg)
    if m == "imm":
        return ir.Const(op.value, name=name)
    if m == "near":
        return ir.Const(op.addr, name=name)
    if m in ("displ", "phrase"):
        base = _reg(op.base_reg)
        if isinstance(base, ir.Const) and base.value == 0:
            addr = ir.Const(op.disp & 0xFFFFFFFF, name=name)
        elif op.disp == 0:
            addr = base
        else:
            addr = ir.Bin("+", base, ir.Const(op.disp & 0xFFFFFFFF))
        return ir.Mem(addr, width=op.width, name=name)
    return ir.Const(0, name=name)


def lift_insn(ins):
    ea = ins.ea
    m = ins.mnem
    ops = ins.ops

    def e(i):
        return op_expr(ops[i])

    # --- moves / nops ------------------------------------------------------
    if m == "nop":
        return [ir.Nop(ea)]
    if m in ("mv", "mvi", "mvui"):
        # dst = src
        return [ir.Assign(ea, e(0), e(1))]
    if m == "mvhi":
        val = (ops[1].value << 16) & 0xFFFFFFFF
        return [ir.Assign(ea, e(0), ir.Const(val))]

    # --- arithmetic / logic ------------------------------------------------
    if m in ("add", "addi"):
        return [ir.Assign(ea, e(0), ir.Bin("+", e(1), e(2)))]
    if m == "sub":
        return [ir.Assign(ea, e(0), ir.Bin("-", e(1), e(2)))]
    if m in ("mul", "muli"):
        return [ir.Assign(ea, e(0), ir.Bin("*", e(1), e(2)))]
    if m == "div":
        return [ir.Assign(ea, e(0), ir.Bin("/", e(1), e(2)))]
    if m == "divu":
        return [ir.Assign(ea, e(0), ir.IntrExpr("divu", [e(1), e(2)]))]
    if m == "mod":
        return [ir.Assign(ea, e(0), ir.Bin("%", e(1), e(2)))]
    if m == "modu":
        return [ir.Assign(ea, e(0), ir.IntrExpr("modu", [e(1), e(2)]))]

    if m in ("and", "andi"):
        return [ir.Assign(ea, e(0), ir.Bin("&", e(1), e(2)))]
    if m == "andhi":
        val = (ops[2].value << 16) & 0xFFFFFFFF
        return [ir.Assign(ea, e(0), ir.Bin("&", e(1), ir.Const(val)))]
    if m in ("or", "ori"):
        return [ir.Assign(ea, e(0), ir.Bin("|", e(1), e(2)))]
    if m == "orhi":
        val = (ops[2].value << 16) & 0xFFFFFFFF
        return [ir.Assign(ea, e(0), ir.Bin("|", e(1), ir.Const(val)))]
    if m in ("xor", "xori"):
        return [ir.Assign(ea, e(0), ir.Bin("^", e(1), e(2)))]
    if m in ("nor", "nori"):
        return [ir.Assign(ea, e(0), ir.Un("~", ir.Bin("|", e(1), e(2))))]
    if m in ("xnor", "xnori"):
        return [ir.Assign(ea, e(0), ir.Un("~", ir.Bin("^", e(1), e(2))))]
    if m == "not":
        return [ir.Assign(ea, e(0), ir.Un("~", e(1)))]

    if m == "sextb":
        return [ir.Assign(ea, e(0), ir.IntrExpr("sextb", [e(1)]))]
    if m == "sexth":
        return [ir.Assign(ea, e(0), ir.IntrExpr("sexth", [e(1)]))]

    # --- shifts ------------------------------------------------------------
    if m in ("sl", "sli"):
        return [ir.Assign(ea, e(0), ir.Bin("<<", e(1), e(2)))]
    if m in ("sr", "sri"):
        return [ir.Assign(ea, e(0), ir.IntrExpr("sra", [e(1), e(2)]))]
    if m in ("sru", "srui"):
        return [ir.Assign(ea, e(0), ir.Bin(">>", e(1), e(2)))]

    # --- memory loads / stores ---------------------------------------------
    if m == "lw":
        return [ir.Assign(ea, e(0), e(1))]
    if m == "lhu":
        mem = e(1)
        mem.signed = False
        return [ir.Assign(ea, e(0), mem)]
    if m == "lh":
        mem = e(1)
        mem.signed = True
        return [ir.Assign(ea, e(0), mem)]
    if m == "lbu":
        mem = e(1)
        mem.signed = False
        return [ir.Assign(ea, e(0), mem)]
    if m == "lb":
        mem = e(1)
        mem.signed = True
        return [ir.Assign(ea, e(0), mem)]
    if m in ("sw", "sh", "sb"):
        return [ir.Assign(ea, e(0), e(1))]

    # --- comparisons -------------------------------------------------------
    if m in ("cmpe", "cmpei"):
        return [ir.Assign(ea, e(0), ir.Bin("==", e(1), e(2)))]
    if m in ("cmpne", "cmpnei"):
        return [ir.Assign(ea, e(0), ir.Bin("!=", e(1), e(2)))]
    if m in ("cmpg", "cmpgi"):
        return [ir.Assign(ea, e(0), ir.Bin(">", e(1), e(2)))]
    if m in ("cmpge", "cmpgei"):
        return [ir.Assign(ea, e(0), ir.Bin(">=", e(1), e(2)))]
    if m in ("cmpgu", "cmpgui"):
        return [ir.Assign(ea, e(0), ir.Bin("u>", e(1), e(2)))]
    if m in ("cmpgeu", "cmpgeui"):
        return [ir.Assign(ea, e(0), ir.Bin("u>=", e(1), e(2)))]

    # --- conditional branches ----------------------------------------------
    if m in isa.COND_BRANCH:
        op_map = {
            "be": "==",
            "bne": "!=",
            "bg": ">",
            "bge": ">=",
            "bgu": "u>",
            "bgeu": "u>",
        }
        relop = op_map[m]
        cexpr = ir.Bin(relop, e(0), e(1))
        target = ops[2].addr
        return [ir.Branch(ea, cexpr, target, ea + 4)]

    # --- unconditional jumps & returns -------------------------------------
    if m == "bi":
        return [ir.Goto(ea, ops[0].addr)]
    if m in ("ret", "eret", "bret"):
        return [ir.Ret(ea, kind=m)]
    if m == "b":
        if ins.switch_info is not None:
            sw = ins.switch_info
            return [ir.Switch(ea, _reg(sw.idx_reg), sw.cases, default_ea=sw.default_ea)]
        # Indirect jump
        return [ir.Goto(ea, None)]

    # --- calls -------------------------------------------------------------
    if m == "calli":
        return [ir.Call(ea, target=ops[0].addr)]
    if m == "call":
        return [ir.Call(ea, expr=e(0))]

    # --- CSR & system ------------------------------------------------------
    if m == "rcsr":
        return [ir.Assign(ea, e(0), ir.IntrExpr("__rcsr", [e(1)]))]
    if m == "wcsr":
        return [ir.Intrinsic(ea, "__wcsr", [e(0), e(1)])]
    if m in ("scall", "break"):
        return [ir.Intrinsic(ea, f"__{m}", [])]
    if m in ("raise", "user"):
        return [ir.Intrinsic(ea, f"__{m}", [e(0)])]

    return [ir.Intrinsic(ea, m, [e(i) for i in range(len(ops))])]
```

```py
"""
Image loading and entry point discovery for LatticeMico32 (LM32) firmware.

LM32 exception vectors are located at the Exception Base Address (EBA),
spaced 32 bytes (0x20) apart:
    0x00: Reset
    0x20: Breakpoint
    0x40: Instruction Bus Error
    0x60: Watchpoint
    0x80: Data Bus Error
    0xA0: Divide by Zero
    0xC0: Interrupt
    0xE0: System Call
"""

from . import decoder

LM32_VECTOR_OFFSETS = (0x00, 0x20, 0x40, 0x60, 0x80, 0xA0, 0xC0, 0xE0)


def load(path):
    with open(path, "rb") as fp:
        return bytearray(fp.read())


def detect_base(image, is_be=True):
    """Infer the link base from the reset vector or default to 0."""
    if len(image) >= 4:
        ins = decoder.decode_one(image, 0, base=0, is_be=is_be)
        if ins is not None and ins.mnem in ("bi", "calli"):
            t = decoder.target_of(ins)
            if t is not None:
                # If target is above 4 KiB, it may indicate a link base
                if t >= 0x1000:
                    return t & ~0xFFF, t
                return 0, t
    return 0, 0


def vector_entries(image, base=0, is_be=True):
    """Return discovered exception vector entries and reset targets."""
    entries = []
    seen = set()

    # Check the standard vector table slots
    for off in LM32_VECTOR_OFFSETS:
        if off + 4 <= len(image):
            ea = base + off
            ins = decoder.decode_one(image, ea, base=base, is_be=is_be)
            if ins is not None:
                t = decoder.target_of(ins)
                if t is not None and base <= t < base + len(image):
                    if t not in seen:
                        seen.add(t)
                        entries.append(t)
                else:
                    if ea not in seen:
                        seen.add(ea)
                        entries.append(ea)

    # Scan the first 0x200 bytes for additional calls or branches
    for off in range(0, min(0x200, len(image) - 3), 4):
        ea = base + off
        ins = decoder.decode_one(image, ea, base=base, is_be=is_be)
        if ins is not None and ins.mnem in ("calli", "bi"):
            t = decoder.target_of(ins)
            if t is not None and base <= t < base + len(image) and t not in seen:
                seen.add(t)
                entries.append(t)

    return entries
```

`lm32dec/opt.py`:

```py
"""
Block-local optimization and SSA-style simplification for LM32.

Performs:
1. Constant folding (arithmetic, shifts, bitwise, comparisons).
2. Constant and copy propagation within basic blocks.
3. 32-bit immediate folding (mvhi + ori / addi -> single 32-bit Const).
4. Cmp-to-Branch folding:
   Folds boolean compare statements (cmpe, cmpg, cmpge, cmpgu, cmpgeu, cmpne, etc.)
   immediately preceding conditional branches against zero (bne/be reg, r0)
   into direct relational branch conditions, eliminating intermediate flag variables.
5. Dead assignment elimination (including discarding writes to r0).
"""

from . import ir

_OPS = {
    "+": lambda a, b: (a + b) & 0xFFFFFFFF,
    "-": lambda a, b: (a - b) & 0xFFFFFFFF,
    "*": lambda a, b: (a * b) & 0xFFFFFFFF,
    "/": lambda a, b: (a // b) & 0xFFFFFFFF if b != 0 else 0,
    "%": lambda a, b: (a % b) & 0xFFFFFFFF if b != 0 else 0,
    "|": lambda a, b: a | b,
    "&": lambda a, b: a & b,
    "^": lambda a, b: a ^ b,
    "<<": lambda a, b: (a << (b & 31)) & 0xFFFFFFFF,
    ">>": lambda a, b: (a & 0xFFFFFFFF) >> (b & 31),
    "==": lambda a, b: 1 if a == b else 0,
    "!=": lambda a, b: 1 if a != b else 0,
    "<": lambda a, b: 1 if _signed32(a) < _signed32(b) else 0,
    "<=": lambda a, b: 1 if _signed32(a) <= _signed32(b) else 0,
    ">": lambda a, b: 1 if _signed32(a) > _signed32(b) else 0,
    ">=": lambda a, b: 1 if _signed32(a) >= _signed32(b) else 0,
    "u<": lambda a, b: 1 if (a & 0xFFFFFFFF) < (b & 0xFFFFFFFF) else 0,
    "u<=": lambda a, b: 1 if (a & 0xFFFFFFFF) <= (b & 0xFFFFFFFF) else 0,
    "u>": lambda a, b: 1 if (a & 0xFFFFFFFF) > (b & 0xFFFFFFFF) else 0,
    "u>=": lambda a, b: 1 if (a & 0xFFFFFFFF) >= (b & 0xFFFFFFFF) else 0,
}


def _signed32(v):
    v &= 0xFFFFFFFF
    return (v - 0x100000000) if v >= 0x80000000 else v


_INVERT_RELOP = {
    "==": "!=",
    "!=": "==",
    "<": ">=",
    ">=": "<",
    ">": "<=",
    "<=": ">",
    "u<": "u>=",
    "u>=": "u<",
    "u>": "u<=",
    "u<=": "u>",
}


def _fold(e):
    if isinstance(e, ir.Bin):
        l, r = _fold(e.l), _fold(e.r)
        if isinstance(l, ir.Const) and isinstance(r, ir.Const) and e.op in _OPS:
            return ir.Const(_OPS[e.op](l.value, r.value))
        # Algebraic identities with 0
        if isinstance(r, ir.Const) and r.value == 0:
            if e.op in ("+", "-", "|", "^", "<<", ">>"):
                return l
            if e.op in ("*", "&"):
                return ir.Const(0)
        if isinstance(l, ir.Const) and l.value == 0:
            if e.op in ("+", "|", "^"):
                return r
            if e.op in ("*", "&", "/", "%", "<<", ">>"):
                return ir.Const(0)
        # Identity with 1
        if isinstance(r, ir.Const) and r.value == 1 and e.op in ("*", "/"):
            return l
        # Identity with 0xFFFFFFFF
        if isinstance(r, ir.Const) and r.value == 0xFFFFFFFF and e.op == "&":
            return l

        # Boolean relational compare against 0:
        # (cmp != 0) -> cmp
        # (cmp == 0) -> !cmp
        if isinstance(l, ir.Bin) and l.op in _INVERT_RELOP and isinstance(r, ir.Const) and r.value == 0:
            if e.op == "!=":
                return l
            if e.op == "==":
                inv_op = _INVERT_RELOP.get(l.op)
                if inv_op:
                    return ir.Bin(inv_op, l.l, l.r)
        if isinstance(r, ir.Bin) and r.op in _INVERT_RELOP and isinstance(l, ir.Const) and l.value == 0:
            if e.op == "!=":
                return r
            if e.op == "==":
                inv_op = _INVERT_RELOP.get(r.op)
                if inv_op:
                    return ir.Bin(inv_op, r.l, r.r)

        return ir.Bin(e.op, l, r)

    if isinstance(e, ir.Un):
        sub = _fold(e.e)
        if isinstance(sub, ir.Const):
            if e.op == "~":
                return ir.Const((~sub.value) & 0xFFFFFFFF)
            if e.op == "-":
                return ir.Const((-sub.value) & 0xFFFFFFFF)
            if e.op == "!":
                return ir.Const(0 if sub.value else 1)
        return ir.Un(e.op, sub)

    if isinstance(e, ir.Mem):
        return ir.Mem(_fold(e.addr) if isinstance(e.addr, ir.Expr) else e.addr, e.width, e.signed, getattr(e, 'name', None))

    if isinstance(e, ir.IntrExpr):
        return ir.IntrExpr(e.name, [_fold(a) for a in e.args])

    return e


def _mentions(e, name):
    if isinstance(e, ir.Reg):
        return e.name == name
    if isinstance(e, ir.Bin):
        return _mentions(e.l, name) or _mentions(e.r, name)
    if isinstance(e, ir.Un):
        return _mentions(e.e, name)
    if isinstance(e, ir.Mem):
        return isinstance(e.addr, ir.Expr) and _mentions(e.addr, name)
    if isinstance(e, ir.IntrExpr):
        return any(_mentions(a, name) for a in e.args)
    return False


def _stmt_reads(s, name):
    if isinstance(s, ir.Assign):
        if _mentions(s.src, name):
            return True
        if isinstance(s.dst, ir.Mem) and isinstance(s.dst.addr, ir.Expr):
            return _mentions(s.dst.addr, name)
        return False
    if isinstance(s, ir.Branch):
        return _mentions(s.cexpr, name)
    if isinstance(s, ir.Switch):
        return _mentions(s.expr, name)
    if isinstance(s, ir.Call):
        return (s.expr is not None and _mentions(s.expr, name)) or any(
            _mentions(a, name) for a in (s.args or ())
        )
    if isinstance(s, ir.Intrinsic):
        return any(_mentions(a, name) for a in s.args)
    return False


def _subst(e, env):
    if isinstance(e, ir.Reg):
        return env.get(e.name, e)
    if isinstance(e, ir.Bin):
        return ir.Bin(e.op, _subst(e.l, env), _subst(e.r, env))
    if isinstance(e, ir.Un):
        return ir.Un(e.op, _subst(e.e, env))
    if isinstance(e, ir.Mem):
        return ir.Mem(_subst(e.addr, env) if isinstance(e.addr, ir.Expr) else e.addr, e.width, e.signed, getattr(e, 'name', None))
    if isinstance(e, ir.IntrExpr):
        return ir.IntrExpr(e.name, [_subst(a, env) for a in e.args])
    return e


def _kill(env, name):
    for k in [k for k, v in env.items() if k == name or _mentions(v, name)]:
        del env[k]


_KEEP_INTRINSICS = frozenset(("__scall", "__break", "__raise", "__wcsr"))


def _opt_block(block):
    env = {}
    mem_env = {}
    cmp_def_stmts = {}  # reg_name -> Assign statement that defined it as a compare

    for s in block.stmts:
        if isinstance(s, ir.Assign):
            s.src = _fold(_subst(s.src, env))
            if isinstance(s.dst, ir.Reg):
                # Discard writes to r0 (hardwired 0)
                if s.dst.name == "r0":
                    continue

                _kill(env, s.dst.name)
                _kill(mem_env, s.dst.name)
                cmp_def_stmts.pop(s.dst.name, None)

                if isinstance(s.src, (ir.Const, ir.Reg)) and not _mentions(s.src, s.dst.name):
                    env[s.dst.name] = s.src
                elif isinstance(s.src, ir.Bin) and s.src.op in _INVERT_RELOP and not _mentions(s.src, s.dst.name):
                    env[s.dst.name] = s.src
                    cmp_def_stmts[s.dst.name] = s
                elif isinstance(s.src, ir.Mem) and not _mentions(s.src, s.dst.name):
                    mem_env[s.dst.name] = s.src
            else:
                s.dst = _fold(_subst(s.dst, env))
                mem_env.clear()

        elif isinstance(s, ir.Branch):
            orig = s.cexpr
            s.cexpr = _fold(_subst(s.cexpr, env))
            if isinstance(orig, ir.Bin) and isinstance(orig.l, ir.Reg) and orig.l.name in cmp_def_stmts:
                s.inlined_eas.append(cmp_def_stmts[orig.l.name].ea)
            elif isinstance(orig, ir.Bin) and isinstance(orig.r, ir.Reg) and orig.r.name in cmp_def_stmts:
                s.inlined_eas.append(cmp_def_stmts[orig.r.name].ea)

        elif isinstance(s, ir.Switch):
            s.expr = _fold(_subst(s.expr, env))

        elif isinstance(s, ir.Intrinsic):
            s.args = [_fold(_subst(a, env)) for a in s.args]
            if s.name not in _KEEP_INTRINSICS:
                env.clear()
            mem_env.clear()

        elif isinstance(s, ir.Call):
            if s.expr is not None:
                s.expr = _fold(_subst(s.expr, env))
            env.clear()
            mem_env.clear()

    # Intra-block dead assignment elimination:
    # 1. Drop writes to r0.
    # 2. Drop self-copies `rX = rX`.
    # 3. Drop `rX = ...` if rX is overwritten later in the same block before any read.
    # 4. Drop inlined cmp definitions.
    stmts = block.stmts
    keep = []
    n = len(stmts)

    for i, s in enumerate(stmts):
        if isinstance(s, ir.Assign) and isinstance(s.dst, ir.Reg):
            rname = s.dst.name
            if rname == "r0":
                continue
            if isinstance(s.src, ir.Reg) and s.src.name == rname:
                continue

            dead = False
            for j in range(i + 1, n):
                sj = stmts[j]
                if _stmt_reads(sj, rname):
                    break
                if isinstance(sj, ir.Assign) and isinstance(sj.dst, ir.Reg) and sj.dst.name == rname:
                    dead = True
                    break
            if dead:
                continue

            # If s was an inlined cmp statement folded into the terminating branch and not read elsewhere:
            if rname in cmp_def_stmts and cmp_def_stmts[rname] is s:
                read_elsewhere = any(_stmt_reads(stmts[k], rname) for k in range(i + 1, n))
                if not read_elsewhere:
                    continue

        keep.append(s)

    block.stmts = keep


def optimize(func):
    for b in func.blocks.values():
        _opt_block(b)
    return func
```

```py
"""
Control-flow structuring for LatticeMico32 (LM32).

Recovers if / else, while, do-while, and switch constructs with exact instruction EA anchoring.
Every structural node carries its originating instruction EA.
"""

from . import ir


class SStmt:
    def __init__(self, stmt):
        self.stmt = stmt
        self.ea = getattr(stmt, "ea", None)


class SLabel:
    def __init__(self, ea):
        self.ea = ea


class SGoto:
    def __init__(self, ea):
        self.ea = ea


class SRet:
    def __init__(self, ea=None):
        self.ea = ea


class SIf:
    def __init__(self, cond, then, els, ea=None):
        self.cond = cond
        self.then = then
        self.els = els
        self.ea = ea


class SIfGoto:
    def __init__(self, cond, ea, branch_ea=None):
        self.cond = cond
        self.ea = ea
        self.branch_ea = branch_ea


class SWhile:
    def __init__(self, body, cond=None, dowhile=False, ea=None):
        self.body = body
        self.cond = cond
        self.dowhile = dowhile
        self.ea = ea


class SBreak:
    def __init__(self, ea=None):
        self.ea = ea


class SContinue:
    def __init__(self, cond=None, ea=None):
        self.cond = cond
        self.ea = ea


class SBreakIf:
    def __init__(self, cond, ea=None):
        self.cond = cond
        self.ea = ea


class SSwitch:
    def __init__(self, expr, cases, default_body=None, ea=None):
        self.expr = expr
        self.cases = cases              # list of (case_vals_list, body_nodes)
        self.default_body = default_body
        self.ea = ea


_NEG = {
    "==": "!=",
    "!=": "==",
    ">": "<=",
    "<": ">=",
    ">=": "<",
    "<=": ">",
    "u>": "u<=",
    "u<": "u>=",
    "u>=": "u<",
    "u<=": "u>",
}


def cond_expr(branch):
    return branch.cexpr


def negate(e):
    if isinstance(e, ir.Un) and e.op == "!":
        return e.e
    if isinstance(e, ir.Bin) and e.op in _NEG:
        return ir.Bin(_NEG[e.op], e.l, e.r)
    if isinstance(e, ir.Const):
        return ir.Const(0 if e.value else 1)
    return ir.Un("!", e)


class _Structurer:
    def __init__(self, func):
        self.order = func.ordered()
        self.idx = {b.start: i for i, b in enumerate(self.order)}
        self.blocks = self.order
        self._open = set()
        self.preds = {b.start: set() for b in self.blocks}
        for i, b in enumerate(self.blocks):
            for _, tgt in b.succ:
                if tgt in self.preds:
                    self.preds[tgt].add(i)

    def run(self):
        return self._emit(0, len(self.blocks), loop=None, switch_merge=None)

    def _in_range(self, ea, lo, hi):
        i = self.idx.get(ea)
        return i is not None and lo <= i < hi

    def _region_clean(self, r_lo, r_hi, parent_idx):
        if r_hi - r_lo > 16:
            return False
        for k in range(r_lo, r_hi):
            if self.blocks[k].term == "switch":
                return False
            if k > r_lo:
                for p in self.preds.get(self.blocks[k].start, ()):
                    if not (r_lo <= p < r_hi) and p != parent_idx:
                        return False
        return True

    def _find_latch(self, header_idx, hi):
        h = self.blocks[header_idx].start
        latch = None
        for j in range(header_idx, hi):
            for _, tgt in self.blocks[j].succ:
                if tgt == h and j >= header_idx:
                    latch = j
        return latch

    def _body_stmts(self, block):
        res = []
        for s in block.stmts:
            if isinstance(s, (ir.Branch, ir.Goto, ir.Nop)):
                continue
            if isinstance(s, ir.Ret):
                continue
            res.append(SStmt(s))
        return res

    def _emit(self, lo, hi, loop=None, switch_merge=None):
        out = []
        i = lo
        while i < hi:
            b = self.blocks[i]
            b_ea = b.start

            # Check loop header
            latch = self._find_latch(i, hi) if (loop is None or i != loop) else None
            if latch is not None:
                # Structure while loop
                latch_block = self.blocks[latch]
                if b.term == "branch" and len(b.succ) == 2 and latch == i:
                    # Single-block while loop
                    taken_tgt, fall_tgt = b.succ[0][1], b.succ[1][1]
                    branch_stmt = next((s for s in reversed(b.stmts) if isinstance(s, ir.Branch)), None)
                    c_expr = branch_stmt.cexpr if branch_stmt else None
                    if taken_tgt == b_ea:
                        body = self._body_stmts(b)
                        out.append(SWhile(body, cond=c_expr, dowhile=False, ea=b_ea))
                        i += 1
                        continue
                elif b.term == "branch" and len(b.succ) == 2:
                    # Multi-block while loop
                    taken_tgt, fall_tgt = b.succ[0][1], b.succ[1][1]
                    branch_stmt = next((s for s in reversed(b.stmts) if isinstance(s, ir.Branch)), None)
                    c_expr = branch_stmt.cexpr if branch_stmt else None
                    if self._in_range(taken_tgt, i, latch + 1):
                        body = self._body_stmts(b)
                        sub_body = self._emit(i + 1, latch + 1, loop=i, switch_merge=switch_merge)
                        body.extend(sub_body)
                        out.append(SWhile(body, cond=c_expr, dowhile=False, ea=b_ea))
                        i = latch + 1
                        continue

            # Switch construct
            if b.term == "switch":
                sw_stmt = next((s for s in reversed(b.stmts) if isinstance(s, ir.Switch)), None)
                if sw_stmt is not None:
                    out.extend(self._body_stmts(b))
                    cases_ast = []
                    for c_val, c_tgt in sw_stmt.cases:
                        c_idx = self.idx.get(c_tgt)
                        c_body = []
                        if c_idx is not None and self._in_range(c_tgt, i + 1, hi):
                            c_body = self._emit(c_idx, c_idx + 1, loop=loop, switch_merge=hi)
                        cases_ast.append(([c_val], c_body))
                    def_body = []
                    if sw_stmt.default_ea:
                        d_idx = self.idx.get(sw_stmt.default_ea)
                        if d_idx is not None and self._in_range(sw_stmt.default_ea, i + 1, hi):
                            def_body = self._emit(d_idx, d_idx + 1, loop=loop, switch_merge=hi)
                    out.append(SSwitch(sw_stmt.expr, cases_ast, default_body=def_body, ea=b_ea))
                    i += 1
                    continue

            # If-Then-Else construct
            if b.term == "branch" and len(b.succ) == 2:
                t_taken, t_fall = b.succ[0][1], b.succ[1][1]
                idx_taken = self.idx.get(t_taken)
                idx_fall = self.idx.get(t_fall)
                branch_stmt = next((s for s in reversed(b.stmts) if isinstance(s, ir.Branch)), None)
                c_expr = branch_stmt.cexpr if branch_stmt else None

                out.extend(self._body_stmts(b))

                # If-then diamond or triangle:
                # Triangle: taken jumps ahead over then-block (fall through is then-body)
                if idx_fall == i + 1 and idx_taken is not None and idx_taken > i + 1:
                    then_hi = min(idx_taken, hi)
                    if self._region_clean(i + 1, then_hi, i):
                        then_body = self._emit(i + 1, then_hi, loop=loop, switch_merge=switch_merge)
                        out.append(SIf(negate(c_expr), then_body, [], ea=b_ea))
                        i = then_hi
                        continue

                # If-then-else diamond:
                if idx_taken is not None and idx_fall is not None:
                    if idx_taken > i and idx_fall > i:
                        out.append(SIfGoto(c_expr, t_taken, branch_ea=b_ea))
                        i += 1
                        continue

            # Default: emit block statements
            out.extend(self._body_stmts(b))
            if b.term == "ret":
                out.append(SRet(ea=b_ea))
            elif b.term == "goto" and b.succ:
                tgt = b.succ[0][1]
                if loop is not None and tgt == self.blocks[loop].start:
                    out.append(SContinue(ea=b_ea))
                elif switch_merge is not None and tgt == switch_merge:
                    out.append(SBreak(ea=b_ea))
                elif tgt != (self.blocks[i + 1].start if i + 1 < len(self.blocks) else None):
                    out.append(SGoto(tgt))

            i += 1

        return out


def structure(func):
    """Transform CFG of func into structured AST with exact instruction EA anchoring."""
    s = _Structurer(func)
    return s.run()
```

```py
"""
Virtual Variable Recovery and SSA Def-Use Web Layer for LatticeMico32 (LM32).

Transforms machine registers (r1..r25) into clean C virtual variables:
1. Reaching definitions analysis across CFG basic blocks.
2. Def-use live range construction via Union-Find.
3. Function argument binding (r1..r8 -> a0..a7).
4. Register reuse splitting into disjoint virtual variables (v0, v1, ...).
5. Copy propagation and dead temporary elimination.
6. Single-use inlining for natural C expressions.
7. Variable declarations and type deduction.

from . import ir, isa

LM32_GPRS = {f"r{i}" for i in range(1, 26)} | {"ra", "ea", "ba"}
ARG_REGS = ("r1", "r2", "r3", "r4", "r5", "r6", "r7", "r8")
CALLER_SAVED = frozenset([f"r{i}" for i in range(1, 11)] + ["ra", "ea", "ba"])


class _UnionFind:
    def __init__(self):
        self.parent = {}

    def find(self, x):
        if x not in self.parent:
            self.parent[x] = x
            return x
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        rx, ry = self.find(x), self.find(y)
        if rx != ry:
            self.parent[rx] = ry


def _collect_expr_regs(e, out_regs):
    if isinstance(e, ir.Reg) and e.name in LM32_GPRS:
        out_regs.append(e.name)
    elif isinstance(e, ir.Var):
        out_regs.append(e.name)
    elif isinstance(e, ir.Bin):
        _collect_expr_regs(e.l, out_regs)
        _collect_expr_regs(e.r, out_regs)
    elif isinstance(e, ir.Un):
        _collect_expr_regs(e.e, out_regs)
    elif isinstance(e, ir.Mem) and isinstance(e.addr, ir.Expr):
        _collect_expr_regs(e.addr, out_regs)
    elif isinstance(e, ir.IntrExpr):
        for a in e.args:
            _collect_expr_regs(a, out_regs)


def _get_stmt_uses(s):
    uses = []
    if isinstance(s, ir.Assign):
        _collect_expr_regs(s.src, uses)
        if isinstance(s.dst, ir.Mem) and isinstance(s.dst.addr, ir.Expr):
            _collect_expr_regs(s.dst.addr, uses)
    elif isinstance(s, ir.Call):
        if s.args:
            for a in s.args:
                _collect_expr_regs(a, uses)
        if s.expr:
            _collect_expr_regs(s.expr, uses)
    elif isinstance(s, ir.Branch):
        if isinstance(s.cexpr, ir.Expr):
            _collect_expr_regs(s.cexpr, uses)
    elif isinstance(s, ir.Switch) and isinstance(s.expr, ir.Expr):
        _collect_expr_regs(s.expr, uses)
    elif isinstance(s, ir.Intrinsic):
        for a in s.args:
            _collect_expr_regs(a, uses)
    return uses


def _get_stmt_defs(s):
    defs = []
    clobbers = []
    if isinstance(s, ir.Assign):
        if isinstance(s.dst, ir.Reg) and s.dst.name in LM32_GPRS:
            defs.append(s.dst.name)
        elif isinstance(s.dst, ir.Var):
            defs.append(s.dst.name)
    elif isinstance(s, ir.Call):
        if not getattr(s, "is_tail", False):
            for r in CALLER_SAVED:
                if r in LM32_GPRS:
                    clobbers.append(r)
    return defs, clobbers


def _expr_uses_var(e, var_name):
    if isinstance(e, (ir.Var, ir.Reg)) and e.name == var_name:
        return True
    if isinstance(e, ir.Bin):
        return _expr_uses_var(e.l, var_name) or _expr_uses_var(e.r, var_name)
    if isinstance(e, ir.Un):
        return _expr_uses_var(e.e, var_name)
    if isinstance(e, ir.Mem) and isinstance(e.addr, ir.Expr):
        return _expr_uses_var(e.addr, var_name)
    if isinstance(e, ir.IntrExpr):
        return any(_expr_uses_var(a, var_name) for a in e.args)
    return False


def _stmt_uses_var(s, var_name):
    if isinstance(s, ir.Assign):
        if _expr_uses_var(s.src, var_name):
            return True
        if isinstance(s.dst, ir.Mem) and isinstance(s.dst.addr, ir.Expr):
            return _expr_uses_var(s.dst.addr, var_name)
        return False
    if isinstance(s, ir.Call):
        if s.args and any(_expr_uses_var(a, var_name) for a in s.args):
            return True
        if s.expr and _expr_uses_var(s.expr, var_name):
            return True
        return False
    if isinstance(s, ir.Branch):
        return isinstance(s.cexpr, ir.Expr) and _expr_uses_var(s.cexpr, var_name)
    if isinstance(s, ir.Switch):
        return isinstance(s.expr, ir.Expr) and _expr_uses_var(s.expr, var_name)
    if isinstance(s, ir.Intrinsic):
        return any(_expr_uses_var(a, var_name) for a in s.args)
    return False


def _subst_ast(e, repl):
    if isinstance(e, ir.Reg) and e.name in repl:
        return repl[e.name]
    if isinstance(e, ir.Var) and e.name in repl:
        return repl[e.name]
    if isinstance(e, ir.Bin):
        return ir.Bin(e.op, _subst_ast(e.l, repl), _subst_ast(e.r, repl))
    if isinstance(e, ir.Un):
        return ir.Un(e.op, _subst_ast(e.e, repl))
    if isinstance(e, ir.Mem):
        addr = _subst_ast(e.addr, repl) if isinstance(e.addr, ir.Expr) else e.addr
        return ir.Mem(addr, e.width, e.signed, getattr(e, 'name', None))
    if isinstance(e, ir.IntrExpr):
        return ir.IntrExpr(e.name, [_subst_ast(a, repl) for a in e.args])
    return e


def _subst_stmt_var(s, var_name, new_expr):
    repl = {var_name: new_expr}
    changed = False
    if isinstance(s, ir.Assign):
        if _expr_uses_var(s.src, var_name):
            s.src = _subst_ast(s.src, repl)
            changed = True
        if isinstance(s.dst, ir.Mem) and isinstance(s.dst.addr, ir.Expr):
            if _expr_uses_var(s.dst.addr, var_name):
                s.dst.addr = _subst_ast(s.dst.addr, repl)
                changed = True
    elif isinstance(s, ir.Call):
        if s.args:
            new_args = []
            for a in s.args:
                if _expr_uses_var(a, var_name):
                    new_args.append(_subst_ast(a, repl))
                    changed = True
                else:
                    new_args.append(a)
            if changed:
                s.args = new_args
        if s.expr and _expr_uses_var(s.expr, var_name):
            s.expr = _subst_ast(s.expr, repl)
            changed = True
    elif isinstance(s, ir.Branch):
        if isinstance(s.cexpr, ir.Expr) and _expr_uses_var(s.cexpr, var_name):
            s.cexpr = _subst_ast(s.cexpr, repl)
            changed = True
    elif isinstance(s, ir.Switch) and isinstance(s.expr, ir.Expr):
        if _expr_uses_var(s.expr, var_name):
            s.expr = _subst_ast(s.expr, repl)
            changed = True
    elif isinstance(s, ir.Intrinsic):
        new_args = []
        for a in s.args:
            if _expr_uses_var(a, var_name):
                new_args.append(_subst_ast(a, repl))
                changed = True
            else:
                new_args.append(a)
        if changed:
            s.args = new_args
    return changed


def _is_pure_expr(e):
    if isinstance(e, (ir.Const, ir.Reg, ir.Var)):
        return True
    if isinstance(e, ir.Bin):
        return _is_pure_expr(e.l) and _is_pure_expr(e.r)
    if isinstance(e, ir.Un):
        return _is_pure_expr(e.e)
    if isinstance(e, ir.IntrExpr):
        return all(_is_pure_expr(a) for a in e.args)
    return False


def _compute_var_counts(func, hidden):
    use_count = {}
    def_count = {}

    def count_in_expr(e):
        if isinstance(e, (ir.Var, ir.Reg)):
            use_count[e.name] = use_count.get(e.name, 0) + 1
        elif isinstance(e, ir.Bin):
            count_in_expr(e.l)
            count_in_expr(e.r)
        elif isinstance(e, ir.Un):
            count_in_expr(e.e)
        elif isinstance(e, ir.Mem) and isinstance(e.addr, ir.Expr):
            count_in_expr(e.addr)
        elif isinstance(e, ir.IntrExpr):
            for a in e.args:
                count_in_expr(a)

    for b in func.blocks.values():
        for s in b.stmts:
            if id(s) in hidden:
                continue
            if isinstance(s, ir.Assign):
                count_in_expr(s.src)
                if isinstance(s.dst, ir.Mem) and isinstance(s.dst.addr, ir.Expr):
                    count_in_expr(s.dst.addr)
                elif isinstance(s.dst, (ir.Var, ir.Reg)):
                    def_count[s.dst.name] = def_count.get(s.dst.name, 0) + 1
            elif isinstance(s, ir.Call):
                if s.args:
                    for a in s.args:
                        count_in_expr(a)
                if s.expr:
                    count_in_expr(s.expr)
            elif isinstance(s, ir.Branch):
                if isinstance(s.cexpr, ir.Expr):
                    count_in_expr(s.cexpr)
            elif isinstance(s, ir.Switch) and isinstance(s.expr, ir.Expr):
                count_in_expr(s.expr)
            elif isinstance(s, ir.Intrinsic):
                for a in s.args:
                    count_in_expr(a)

    return use_count, def_count


def _fold_temp_copies(func, hidden):
    changed = False
    for b in func.blocks.values():
        new_stmts = []
        i = 0
        stmts = b.stmts
        while i < len(stmts):
            s = stmts[i]
            if id(s) in hidden:
                new_stmts.append(s)
                i += 1
                continue

            if isinstance(s, ir.Assign) and isinstance(s.dst, ir.Var) and isinstance(s.src, ir.Var):
                dst_name = s.dst.name
                src_var = s.src

                subst_count = 0
                for j in range(i + 1, len(stmts)):
                    nxt = stmts[j]
                    if id(nxt) in hidden:
                        continue
                    nxt_defs, _ = _get_stmt_defs(nxt)
                    if src_var.name in nxt_defs:
                        break
                    if _subst_stmt_var(nxt, dst_name, src_var):
                        subst_count += 1
                        changed = True
                    if dst_name in nxt_defs:
                        break

            new_stmts.append(s)
            i += 1
        b.stmts = new_stmts
    return changed


def _inline_single_use(func, hidden):
    use_count, def_count = _compute_var_counts(func, hidden)
    changed = False

    for b in func.blocks.values():
        new_stmts = []
        i = 0
        stmts = b.stmts
        while i < len(stmts):
            s = stmts[i]
            if id(s) in hidden:
                new_stmts.append(s)
                i += 1
                continue

            if (isinstance(s, ir.Assign)
                and isinstance(s.dst, ir.Var)
                and s.dst.name.startswith("v")
                and def_count.get(s.dst.name, 0) == 1
                and use_count.get(s.dst.name, 0) == 1
                and _is_pure_expr(s.src)):

                v_name = s.dst.name
                can_inline = False
                target_stmt_idx = None
                for j in range(i + 1, len(stmts)):
                    nxt = stmts[j]
                    if id(nxt) in hidden:
                        continue
                    if _stmt_uses_var(nxt, v_name):
                        can_inline = True
                        target_stmt_idx = j
                        break
                    nxt_defs, _ = _get_stmt_defs(nxt)
                    if any(_expr_uses_var(s.src, d) for d in nxt_defs):
                        break

                if can_inline and target_stmt_idx is not None:
                    nxt = stmts[target_stmt_idx]
                    if _subst_stmt_var(nxt, v_name, s.src):
                        if getattr(nxt, "inlined_eas", None) is None:
                            nxt.inlined_eas = []
                        if getattr(s, "ea", None) is not None:
                            nxt.inlined_eas.append(s.ea)
                        if getattr(s, "inlined_eas", None):
                            nxt.inlined_eas.extend(s.inlined_eas)
                        changed = True
                        i += 1
                        continue

            new_stmts.append(s)
            i += 1
        b.stmts = new_stmts
    return changed


def _eliminate_dead_assignments(func, hidden, sig=None):
    protected_names = set()
    if sig and sig.ret_type != "void":
        protected_names.add("r1")
        if sig.ret_type == "uint64_t":
            protected_names.add("r2")

    changed = True
    any_changed = False
    iterations = 0
    while changed and iterations < 10:
        changed = False
        iterations += 1
        use_count, _ = _compute_var_counts(func, hidden)

        for b in func.blocks.values():
            new_stmts = []
            for s in b.stmts:
                if id(s) in hidden:
                    new_stmts.append(s)
                    continue

                if isinstance(s, ir.Assign) and _is_pure_expr(s.src):
                    # Check virtual variables
                    if isinstance(s.dst, ir.Var) and s.dst.name.startswith("v") and s.dst.name[1:].isdigit():
                        if use_count.get(s.dst.name, 0) == 0:
                            changed = True
                            any_changed = True
                            continue
                    # Check GPRs
                    elif isinstance(s.dst, ir.Reg) and s.dst.name in LM32_GPRS:
                        if use_count.get(s.dst.name, 0) == 0 and s.dst.name not in protected_names:
                            changed = True
                            any_changed = True
                            continue

                new_stmts.append(s)
            b.stmts = new_stmts

    return any_changed


def recover_variables(func, sig=None, frame_info=None):
    """Recover SSA-style virtual variables across func."""
    hidden = frame_info.hidden_stmts if frame_info else frozenset()

    # 1. Label def sites and entry parameters
    entry_defs = {}
    param_map = {}
    if sig and sig.params:
        for idx, p in enumerate(sig.params):
            if idx < len(ARG_REGS):
                rloc = ARG_REGS[idx]
                entry_defs[rloc] = ("entry", rloc)
                param_map[p.name] = rloc

    def_map = {}
    for b in func.blocks.values():
        for s in b.stmts:
            if id(s) in hidden:
                continue
            defs, _ = _get_stmt_defs(s)
            for d in defs:
                def_map[id(s), d] = (id(s), d)

    # 2. Reaching definitions analysis
    block_in_defs = {b.start: {} for b in func.ordered()}
    block_out_defs = {b.start: {} for b in func.ordered()}
    block_in_defs[func.entry] = {r: {("entry", r)} for r in entry_defs}

    changed = True
    while changed:
        changed = False
        for b in func.ordered():
            in_defs = {}
            for pred_ea, b_pred in func.blocks.items():
                for _, tgt in b_pred.succ:
                    if tgt == b.start and pred_ea in block_out_defs:
                        for r, s_set in block_out_defs[pred_ea].items():
                            in_defs.setdefault(r, set()).update(s_set)

            if b.start == func.entry:
                for r in entry_defs:
                    in_defs.setdefault(r, set()).add(("entry", r))

            if in_defs != block_in_defs[b.start]:
                block_in_defs[b.start] = in_defs
                changed = True

            cur_defs = {r: set(s_set) for r, s_set in in_defs.items()}
            for s in b.stmts:
                if id(s) in hidden:
                    continue
                defs, clobbers = _get_stmt_defs(s)
                for d in defs:
                    cur_defs[d] = {(id(s), d)}
                for c in clobbers:
                    cur_defs[c] = {(id(s), f"clobber_{c}")}

            if cur_defs != block_out_defs[b.start]:
                block_out_defs[b.start] = cur_defs
                changed = True

    # 3. Union-Find Def-Use Webs
    uf = _UnionFind()
    for b in func.ordered():
        cur_defs = {r: set(s_set) for r, s_set in block_in_defs[b.start].items()}
        for s in b.stmts:
            if id(s) in hidden:
                continue
            for u in _get_stmt_uses(s):
                use_key = (id(s), u, "use")
                for r_site in cur_defs.get(u, ()):
                    uf.union(use_key, r_site)

            defs, clobbers = _get_stmt_defs(s)
            for d in defs:
                cur_defs[d] = {(id(s), d)}
            for c in clobbers:
                cur_defs[c] = {(id(s), f"clobber_{c}")}

    # Group components
    groups = {}
    for node in list(uf.parent.keys()):
        root = uf.find(node)
        groups.setdefault(root, set()).add(node)

    # 4. Map Roots to Names
    web_var = {}
    var_counter = 0

    for root, members in groups.items():
        name = None
        for p_name, rloc in param_map.items():
            if ("entry", rloc) in members:
                name = p_name
                break

        if name is None and frame_info and getattr(frame_info, "stack_args", None):
            for sname in frame_info.stack_args:
                if any(m[0] == "entry" and m[1] == sname for m in members):
                    name = sname
                    break

        if name is None:
            name = f"v{var_counter}"
            var_counter += 1

        web_var[root] = ir.Var(name, width="w")

    # 5. Rewrite Statements
    for b in func.blocks.values():
        new_stmts = []
        for s in b.stmts:
            if id(s) in hidden:
                new_stmts.append(s)
                continue

            uses_repl = {}
            for reg in _get_stmt_uses(s):
                use_key = (id(s), reg, "use")
                root = uf.find(use_key)
                if root in web_var:
                    uses_repl[reg] = web_var[root]

            dst_var = None
            defs, _ = _get_stmt_defs(s)
            if defs:
                reg = defs[0]
                def_key = (id(s), reg)
                root = uf.find(def_key)
                if root in web_var:
                    dst_var = web_var[root]

            if isinstance(s, ir.Assign):
                s.src = _subst_ast(s.src, uses_repl)
                if isinstance(s.dst, ir.Mem) and isinstance(s.dst.addr, ir.Expr):
                    s.dst.addr = _subst_ast(s.dst.addr, uses_repl)
                elif dst_var is not None:
                    s.dst = dst_var

                if isinstance(s.dst, ir.Var) and isinstance(s.src, ir.Var) and s.dst.name == s.src.name:
                    continue

            elif isinstance(s, ir.Branch):
                if isinstance(s.cexpr, ir.Expr):
                    s.cexpr = _subst_ast(s.cexpr, uses_repl)
            elif isinstance(s, ir.Switch) and isinstance(s.expr, ir.Expr):
                s.expr = _subst_ast(s.expr, uses_repl)
            elif isinstance(s, ir.Call):
                if s.args:
                    s.args = [_subst_ast(a, uses_repl) for a in s.args]
                if s.expr:
                    s.expr = _subst_ast(s.expr, uses_repl)
            elif isinstance(s, ir.Intrinsic):
                s.args = [_subst_ast(a, uses_repl) for a in s.args]

            new_stmts.append(s)
        b.stmts = new_stmts

    # 6. Optimization Loop
    for _ in range(8):
        c1 = _eliminate_dead_assignments(func, hidden, sig=sig)
        c2 = _fold_temp_copies(func, hidden)
        c3 = _inline_single_use(func, hidden)
        if not (c1 or c2 or c3):
            break
    _eliminate_dead_assignments(func, hidden, sig=sig)

    # 7. Collect virtual variable declarations
    virtual_vars = {}

    def _collect_vvar(e):
        if isinstance(e, ir.Var) and not isinstance(e, ir.StackVar) and e.name.startswith("v") and e.name[1:].isdigit():
            virtual_vars[e.name] = (e, "w")
        elif isinstance(e, ir.Bin):
            _collect_vvar(e.l)
            _collect_vvar(e.r)
        elif isinstance(e, ir.Un):
            _collect_vvar(e.e)
        elif isinstance(e, ir.Mem) and isinstance(e.addr, ir.Expr):
            _collect_vvar(e.addr)
        elif isinstance(e, ir.IntrExpr):
            for a in e.args:
                _collect_vvar(a)

    for b in func.blocks.values():
        for s in b.stmts:
            if id(s) in hidden:
                continue
            if isinstance(s, ir.Assign):
                _collect_vvar(s.dst)
                _collect_vvar(s.src)
            elif isinstance(s, ir.Call):
                if s.args:
                    for a in s.args:
                        _collect_vvar(a)
                if s.expr:
                    _collect_vvar(s.expr)
            elif isinstance(s, ir.Branch):
                if isinstance(s.cexpr, ir.Expr):
                    _collect_vvar(s.cexpr)
            elif isinstance(s, ir.Switch) and isinstance(s.expr, ir.Expr):
                _collect_vvar(s.expr)
            elif isinstance(s, ir.Intrinsic):
                for a in s.args:
                    _collect_vvar(a)

    if frame_info:
        frame_info.virtual_vars = virtual_vars
    func.virtual_vars = virtual_vars
    return func
```

```py
def _line_ea(line):
    """Extract code linear address from loc_XXXXX, sub_XXXXX, or 0xXXXXX in line."""
    clean = ida_lines.tag_remove(line) if hasattr(ida_lines, "tag_remove") else line

    if m:
        try:

            pass
    m = _ADDR_HEX.search(clean)

            self.show_func(self.current_func_ea)
            if pos:
                try:
                    self.Jump(pos[0], pos[1])
                except Exception:
                    pass
            return

        # 2. Number format
        text, val, _, _, _ = self.get_literal_under_cursor()
        if val is not None:
            db.set_numform(self.current_func_ea, stmt_ea or 0, hex(val), "default")
            self.show_func(self.current_func_ea)
            if pos:
                try:
                    self.Jump(pos[0], pos[1])
                except Exception:
                    pass
            return

        # 3. Variable rename
        word, _ = self.get_word_under_cursor()
        if word:
            data = db.get_func_data(self.current_func_ea)
            renames = data.get("renames", {})
            for orig, user_name in list(renames.items()):
                if user_name == word or orig == word:
                    db.set_var_rename(self.current_func_ea, orig, None)
                    self.show_func(self.current_func_ea)
                    if pos:
                        try:
                            self.Jump(pos[0], pos[1])
                        except Exception:
                            pass
                    return

        # 4. Inverted if
        if stmt_ea is not None and db.is_iflag_inverted(self.current_func_ea, stmt_ea):
            db.toggle_iflag(self.current_func_ea, stmt_ea)
            self.show_func(self.current_func_ea)
            if pos:
                try:
                    self.Jump(pos[0], pos[1])
                except Exception:
                    pass
            return

    def get_word_under_cursor(self):
        """Return the identifier under cursor and the line number."""
        pos = self.GetPos()
        if not pos:
            word = self.GetCurrentWord()
            return word or "", 0
        lineno, col = pos[0], pos[1]
        if lineno < 0 or lineno >= len(self.raw_lines):
            return "", lineno
        line = self.raw_lines[lineno]
        if not line:
            return "", lineno
        if col < 0:
            col = 0
        elif col >= len(line):
            col = len(line) - 1

        # Check identifier character boundary
        if not (line[col].isalnum() or line[col] == "_"):
            if col > 0 and (line[col - 1].isalnum() or line[col - 1] == "_"):
                col -= 1
            elif col + 1 < len(line) and (line[col + 1].isalnum() or line[col + 1] == "_"):
                col += 1
            else:
                return "", lineno

        start = col
        while start > 0 and (line[start - 1].isalnum() or line[start - 1] == "_"):
            start -= 1
        end = col
        while end < len(line) and (line[end].isalnum() or line[end] == "_"):
            end += 1
        return line[start:end], lineno

    def on_rename(self):
        """Rename variable or function under cursor and persist in IDB netnode."""
        if self.current_func_ea is None:
            return
        word, lineno = self.get_word_under_cursor()
        if not word:
            word = ida_kernwin.ask_str("", 0, "Enter variable name to rename")
            if not word:
                return

        new_name = ida_kernwin.ask_str(word, 0, f"Rename '{word}' in {self.current_func_name or 'function'}")
        if new_name is None:
            return
        new_name = new_name.strip()

        # If renaming the function itself
        if word == self.current_func_name or (lineno == 0 and ("(" in self.raw_lines[0])):
            import ida_name
            if new_name:
                ida_name.set_name(self.current_func_ea, new_name)
                self.current_func_name = new_name
            self.show_func(self.current_func_ea)
            return

        # Save variable rename to persistent IDB netnode
        db.set_var_rename(self.current_func_ea, word, new_name)

        # If word is a global symbol in IDA, also rename in IDA's name table
        try:
            import ida_name, ida_idaapi
            ea = ida_name.get_name_ea(ida_idaapi.BADADDR, word)
            if ea != ida_idaapi.BADADDR and new_name:
                ida_name.set_name(ea, new_name)
        except Exception:
            pass

        # If it's a stack frame variable, also rename in IDA's frame struct
        self._rename_frame_member(word, new_name)

        # Refresh decompile
        self.show_func(self.current_func_ea)

    def _rename_frame_member(self, old_name, new_name):
        """Rename stack variable member in IDA's frame structure if present."""
        try:
            import ida_frame
            pfn = ida_funcs.get_func(self.current_func_ea)
            if not pfn:
                return
            tif = ida_typeinf.tinfo_t()
            if ida_frame.get_func_frame(tif, pfn):
                udt = ida_typeinf.udt_type_data_t()
                if tif.get_udt_details(udt):
                    for m in udt:
                        if m.name == old_name:
                            m.name = new_name
                            tif.create_udt(udt, ida_typeinf.BTF_STRUCT)
                            break
        except Exception:
            pass

    def on_set_type(self):
        """Set variable type or function prototype and persist in IDB netnode."""
        if self.current_func_ea is None:
            return
        word, lineno = self.get_word_under_cursor()
        is_sig_line = (lineno == 0) or ("(" in self.raw_lines[lineno] and ")" in self.raw_lines[lineno] and not self.raw_lines[lineno].strip().endswith(";"))

        if is_sig_line or word == self.current_func_name:
            # Edit function prototype
            data = db.get_func_data(self.current_func_ea)
            curr_proto = data.get("proto") or (self.raw_lines[0] if self.raw_lines else "")
            new_proto = ida_kernwin.ask_str(curr_proto, 0, f"Set Function Prototype for {self.current_func_name}")
            if new_proto is None:
                return
            new_proto = new_proto.strip()
            db.set_func_proto(self.current_func_ea, new_proto)

            # Apply to IDA type system
            if new_proto:
                try:
                    ida_typeinf.apply_cdecl(None, self.current_func_ea, new_proto)
                except Exception:
                    pass

            self.show_func(self.current_func_ea)
            return

        if not word:
            return

        # Edit variable type
        data = db.get_func_data(self.current_func_ea)
        curr_type = data.get("types", {}).get(word, "int")
        new_type = ida_kernwin.ask_str(curr_type, 0, f"Set Type for variable '{word}'")
        if new_type is None:
            return
        new_type = new_type.strip()
        db.set_var_type(self.current_func_ea, word, new_type)

        self.show_func(self.current_func_ea)

    def toggle_sync(self):
        """Toggle synchronization with IDA disassembly view."""
        self.sync_with_disasm = not self.sync_with_disasm
        db.set_sync_enabled(self.sync_with_disasm)
        state_str = "ENABLED" if self.sync_with_disasm else "DISABLED"
        print(f"lm32dec: Sync with Disassembly {state_str}")
        if self.sync_with_disasm:
            ea = ida_kernwin.get_screen_ea()
            pfn = ida_funcs.get_func(ea)
            if pfn and pfn.start_ea != self.current_func_ea:
                self.show_func(pfn.start_ea)

    def jump_disasm(self):
        """Jump to the linear address or switch decompiler view to callee function."""
        word, lineno = self.get_word_under_cursor()
        if word:
            # 1. Check if word is a function in IDA -> click-through to that function!
            try:
                import ida_name, ida_idaapi
                target_ea = ida_name.get_name_ea(ida_idaapi.BADADDR, word)
                if target_ea != ida_idaapi.BADADDR:
                    pfn = ida_funcs.get_func(target_ea)
                    if pfn and pfn.start_ea == target_ea:
                        _jumpto_disasm(target_ea)
                        if target_ea != self.current_func_ea:
                            pos = self.GetPos()
                            self._nav_history.append((self.current_func_ea, pos[0] if pos else 0, pos[1] if pos else 0))
                            self.show_func(target_ea)
                        return True
                    else:
                        _jumpto_disasm(target_ea)
                        return True
            except Exception:
                pass

            # 2. Check if word is sub_XXXXXX or loc_XXXXXX
            m = _EA.search(word)
            if m:
                try:
                    target_ea = int(m.group(1), 16)
                    pfn = ida_funcs.get_func(target_ea)
                    _jumpto_disasm(target_ea)
                    if pfn and pfn.start_ea == target_ea and target_ea != self.current_func_ea:
                        pos = self.GetPos()
                        self._nav_history.append((self.current_func_ea, pos[0] if pos else 0, pos[1] if pos else 0))
                        self.show_func(target_ea)
                    return True
                except ValueError:
                    pass

            # 3. Check hex address
            m = _ADDR_HEX.search(word)
            if m:
                try:
                    target_ea = int(m.group(1), 16)
                    _jumpto_disasm(target_ea)
                    return True
                except ValueError:
                    pass

        # Fallback: jump to line_ea or line_to_eas of current line
        target_ea = None
        if lineno is not None:
            if lineno in self.line_to_eas and self.line_to_eas[lineno]:
                target_ea = self.line_to_eas[lineno][0]
            elif lineno < len(self.line_ea) and self.line_ea[lineno] is not None:
                target_ea = self.line_ea[lineno]
            elif self.line_to_eas:
                nearest_line = min(self.line_to_eas.keys(), key=lambda l: abs(l - lineno))
                target_ea = self.line_to_eas[nearest_line][0]
            elif self.current_func_ea is not None:
                target_ea = self.current_func_ea

        if target_ea is not None:
            _jumpto_disasm(target_ea)
            return True
        return False

    def OnDblClick(self, shift):
        return self.jump_disasm()

    def OnKeydown(self, vkey, shift):
        if vkey in (ord('N'), ord('n')):
            self.on_rename()
            return True
        if vkey in (ord('Y'), ord('y')):
            self.on_set_type()
            return True
        if vkey in (ord('H'), ord('h')):
            self.on_toggle_hex_dec()
            return True
        if vkey in (ord('O'), ord('o')):
            self.on_convert_offset()
            return True
        if vkey in (ord('R'), ord('r')):
            self.on_convert_char()
            return True
        if vkey in (ord('_'), ord('-'), 189):
            self.on_invert_sign()
            return True
        if vkey in (ord('~'), 192):
            self.on_bitwise_negate()
            return True
        if vkey in (ord('/'), ord(';'), 191, 186):
            self.on_edit_comment()
            return True
        if vkey in (ord('I'), ord('i')):
            self.on_invert_if()
            return True
        if vkey in (ord('\\'), 220):
            self.on_toggle_casts()
            return True
        if vkey in (ord('X'), ord('x')):
            return self.on_jump_xref()
        if vkey in (ord('B'), ord('b')):
            return self.on_jump_matching_brace()
        if vkey == 46:  # VK_DELETE
            self.on_reset_item()
            return True
        if vkey == 116:  # F5
            if self.current_func_ea is not None:
                self.show_func(self.current_func_ea)
            return True
        if vkey in (13, 32):  # Enter or Space
            return self.jump_disasm()
        if vkey == 9:  # Tab
            self.toggle_sync()
            return True
        if vkey == 27:  # Esc
            if self._nav_history:
                prev_ea, prev_line, prev_col = self._nav_history.pop()
                self.show_func(prev_ea)
                try:
                    self.select_line(prev_line, jump=True, update_asm=True, jump_asm=True)
                    self.Jump(prev_line, prev_col)
                except Exception:
                    pass
                return True
            global _active_viewer
            self.clear_asm_highlights()
            _active_viewer = None
            if self.current_func_ea is not None:
                db.save_window_state(False, self.current_func_ea)
            self.Close()
            return True
        # Navigation keys: Up(38), Down(40), PageUp(33), PageDown(34), Home(36), End(35)
        if vkey in (38, 40, 33, 34, 36, 35):
            try:
                ida_kernwin.execute_ui_requests([self.on_cursor_changed])
            except Exception:
                pass
        return False
```

```py
                            "Open it with the LM32 processor module.")
        return
    ea = ida_kernwin.get_screen_ea()
    f = ida_funcs.get_func(ea) if (ea is not None and ea != ida_idaapi.BADADDR) else None

    # If the pseudocode viewer is active and focused, get_screen_ea() can be BADADDR
    if f is None and getattr(view, "_active_viewer", None) is not None and view._active_viewer.current_func_ea is not None:
        start_ea = view._active_viewer.current_func_ea
    elif f is not None:
        start_ea = f.start_ea
    else:
        ida_kernwin.warning("lm32dec: no function at 0x%X (press 'P')." % (ea if ea is not None else 0))
        return

    try:
        fn = ida_bridge.decompile_one(start_ea)
    except Exception:
        ida_kernwin.warning("lm32dec failed:\n\n%s" % traceback.format_exc())
        return
    v = view.show(fn)
    if v is not None and v not in _views:
        _views.append(v)
    print("lm32dec: %s -> %d blocks" % (fn.name, len(fn.cfg.blocks)))


def _run_all():
    from lm32dec import ida_bridge, view
    import ida_nalt
    if not _is_lm32():
        ida_kernwin.warning("lm32dec: this database is not LM32.")
        return
    ida_kernwin.show_wait_box("lm32dec: decompiling all functions...")
    t0 = time.time()
    try:
        prog = ida_bridge.decompile_program()
    except Exception:
        ida_kernwin.hide_wait_box()
        ida_kernwin.warning("lm32dec: decompile all failed:\n\n%s" % traceback.format_exc())
        return
    finally:
        try:
            ida_kernwin.hide_wait_box()
        except Exception:
            pass
    lines = prog.listing().splitlines()
    print("lm32dec: %d functions in %.1fs" % (len(prog.funcs), time.time() - t0))
    default = os.path.splitext(ida_nalt.get_input_file_path() or "lm32")[0] + ".c"
    path = ida_kernwin.ask_file(True, default, "Save the decompiled listing")
    if path:
        try:
            with open(path, "w", encoding="utf-8") as fp:
                fp.write("\n".join(lines) + "\n")
            print("lm32dec: wrote %d lines to %s" % (len(lines), path))
        except Exception as exc:
            ida_kernwin.warning("lm32dec: could not write %s:\n%s" % (path, exc))
    v = view.show_listing("lm32dec - all functions", lines)
    if v is not None and v not in _views:
        _views.append(v)


def _register_actions():
    ida_kernwin.unregister_action(ACTION_DECOMPILE)
    desc = ida_kernwin.action_desc_t(
        ACTION_DECOMPILE,
        "LM32 Pseudocode",
        _DecompileActionHandler(),
        HOTKEY_DECOMPILE,
        "Decompile current LM32 function to pseudocode (F5)",
        -1
    )
    if ida_kernwin.register_action(desc):
        ida_kernwin.attach_action_to_menu(MENU_PSEUDOCODE_PATH, ACTION_DECOMPILE, ida_kernwin.SETMENU_APP)
        ida_kernwin.attach_action_to_menu(MENU_PLUGIN_PATH, ACTION_DECOMPILE, ida_kernwin.SETMENU_APP)


def _unregister_actions():
    try:
        ida_kernwin.detach_action_from_menu(MENU_PSEUDOCODE_PATH, ACTION_DECOMPILE)
    except Exception:
        pass
    try:
        ida_kernwin.detach_action_from_menu(MENU_PLUGIN_PATH, ACTION_DECOMPILE)
    except Exception:
        pass
    try:
        ida_kernwin.unregister_action(ACTION_DECOMPILE)
    except Exception:
        pass


class Lm32DecPlugin(ida_idaapi.plugin_t):
    flags = ida_idaapi.PLUGIN_PROC
    comment = "LatticeMico32 (LM32) decompiler plugin."
    help = "%s decompiles the current function, %s decompiles everything." % (HOTKEY_DECOMPILE, HOTKEY_ALL)
    wanted_name = "LM32 decompiler (lm32dec)"
    wanted_hotkey = HOTKEY_DECOMPILE

    def init(self):
        if not _is_lm32():
            return ida_idaapi.PLUGIN_SKIP

        _register_actions()

        for hk, fn in [(HOTKEY_DECOMPILE, _run_one),
                       (HOTKEY_LEGACY, _run_one),
                       (HOTKEY_ALL, _run_all)]:
            ctx = ida_kernwin.add_hotkey(hk, fn)
            if ctx is not None:
                _hotkeys.append(ctx)

        print("lm32dec: loaded -- %s = this function, %s = decompile all" % (HOTKEY_DECOMPILE, HOTKEY_ALL))
        try:
            from lm32dec import view
            view.init_hooks()
        except Exception:
            pass
        return ida_idaapi.PLUGIN_KEEP

    def run(self, arg):
        _run_one()

    def term(self):
        _unregister_actions()
        try:
            from lm32dec import view
            view.cleanup()
        except Exception:
            pass
        for ctx in _hotkeys:
            try:
                ida_kernwin.del_hotkey(ctx)
            except Exception:
                pass
        del _hotkeys[:]
        del _views[:]


def PLUGIN_ENTRY():
    return Lm32DecPlugin()
```

```py
import os

def test_abi_param_recovery():
    # Construct a function reading r1, r2, r3, r4, r5, r6, r7, r8
    f = cfg.Func(0x1000)
    b0 = cfg.Block(0x1000)
    b0.term = "ret"
    # Read r1..r5
    for i in range(1, 6):
        b0.stmts.append(ir.Assign(0x1000 + i * 4, ir.Reg(f"r{i+10}"), ir.Reg(f"r{i}")))
    # Return r1
    b0.stmts.append(ir.Assign(0x1020, ir.Reg("r1"), ir.Const(42)))
    b0.stmts.append(ir.Ret(0x1024, "ret"))
    f.blocks[0x1000] = b0

    sig = abi.analyze_calling_convention(f)
    assert len(sig.params) == 5
    assert [p.location for p in sig.params] == ["r1", "r2", "r3", "r4", "r5"]
    assert sig.ret_type == "int"


def test_abi_64bit_return():

    b0 = cfg.Block(0x2000)

    sig = abi.analyze_calling_convention(f)

def test_frame_spill_cleanup():
    # Prologue:
    #   addi sp, sp, -16
    #   sw (sp+4), ra
    #   sw (sp+8), r11
    # Epilogue:
    #   lw r11, (sp+8)
    #   lw ra, (sp+4)
    #   addi sp, sp, 16
    #   ret
    f = cfg.Func(0x3000)
    b0 = cfg.Block(0x3000)
    b0.term = "ret"
    b0.stmts = [
        ir.Assign(0x3000, ir.Reg("sp"), ir.Bin("+", ir.Reg("sp"), ir.Const(-16))),
        ir.Assign(0x3004, ir.Mem(ir.Bin("+", ir.Reg("sp"), ir.Const(4))), ir.Reg("ra")),
        ir.Assign(0x3008, ir.Mem(ir.Bin("+", ir.Reg("sp"), ir.Const(8))), ir.Reg("r11")),
        # Some actual work using stack slot sp+12 (local var_4)
        ir.Assign(0x300C, ir.Mem(ir.Bin("+", ir.Reg("sp"), ir.Const(12))), ir.Const(0xCAFE)),
        ir.Assign(0x3010, ir.Reg("r1"), ir.Mem(ir.Bin("+", ir.Reg("sp"), ir.Const(12)))),
        ir.Assign(0x3014, ir.Reg("r11"), ir.Mem(ir.Bin("+", ir.Reg("sp"), ir.Const(8)))),
        ir.Assign(0x3018, ir.Reg("ra"), ir.Mem(ir.Bin("+", ir.Reg("sp"), ir.Const(4)))),
        ir.Assign(0x301C, ir.Reg("sp"), ir.Bin("+", ir.Reg("sp"), ir.Const(16))),
        ir.Ret(0x3020, "ret"),
    ]
    f.blocks[0x3000] = b0

    frame_info = frame.analyze_frame(f)
    # Callee saves for ra and r11 and sp adjusts should be stripped
    # Only the local var slot and return should remain
    remaining = b0.stmts
    assert len(remaining) == 3
    assert isinstance(remaining[0].dst, ir.Reg) and remaining[0].dst.name == "var_4"
    assert isinstance(remaining[1].src, ir.Reg) and remaining[1].src.name == "var_4"
    assert isinstance(remaining[2], ir.Ret)


def test_callargs_folding():
    # Setup r1..r3 and call foo()
    f = cfg.Func(0x4000)
    b0 = cfg.Block(0x4000)
    b0.term = "ret"
    b0.stmts = [

    assert isinstance(call_stmt, ir.Call)
    assert len(call_stmt.args) == 3
    assert [a.value for a in call_stmt.args] == [10, 20, 30]
    assert call_stmt.inlined_eas == [0x4000, 0x4004, 0x4008]


if __name__ == "__main__":
    test_abi_param_recovery()
```

```py
"""
Unit tests for the LM32 standalone decoder and IR lifter.
Tests both Little-Endian and Big-Endian modes.
"""

import os
import sys

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from lm32dec import decoder, lifter, ir, isa


def _img_at(ea, val, is_be=False):
    buf = bytearray(ea + 4)
    if is_be:
        packed = [(val >> 24) & 0xFF, (val >> 16) & 0xFF, (val >> 8) & 0xFF, val & 0xFF]
    else:
        packed = [val & 0xFF, (val >> 8) & 0xFF, (val >> 16) & 0xFF, (val >> 24) & 0xFF]
    buf[ea:ea+4] = packed
    return buf


def test_decode_addi_and_nop():
    # nop: 0x34000000
    b_nop = _img_at(0x1000, 0x34000000, is_be=False)
    ins = decoder.decode_one(b_nop, 0x1000, is_be=False)
    assert ins.mnem == "nop"
    stmts = lifter.lift_insn(ins)
    assert len(stmts) == 1 and isinstance(stmts[0], ir.Nop)

    # mvi r1, 0x150: addi r1, r0, 0x150 -> opcode=0x0D, r0=0, r1=1, imm=0x150
    # (0x0D << 26) | (0 << 21) | (1 << 16) | 0x150 = 0x34010150
    b_mvi = _img_at(0x1004, 0x34010150, is_be=False)
    ins = decoder.decode_one(b_mvi, 0x1004, is_be=False)
    assert ins.mnem == "mvi"
    assert ins.ops[0].reg == 1 and ins.ops[1].value == 0x150
    stmts = lifter.lift_insn(ins)
    assert len(stmts) == 1 and isinstance(stmts[0], ir.Assign)
    assert isinstance(stmts[0].dst, ir.Reg) and stmts[0].dst.name == "r1"
    assert isinstance(stmts[0].src, ir.Const) and stmts[0].src.value == 0x150

    # addi sp, sp, -0x88 -> opcode=0x0D, r0=28(sp), r1=28(sp), imm=-0x88 (0xFF78)
    # (0x0D << 26) | (28 << 21) | (28 << 16) | 0xFF78 = 0x379CFF78
    b_addi = _img_at(0x1008, 0x379CFF78, is_be=False)
    ins = decoder.decode_one(b_addi, 0x1008, is_be=False)
    assert ins.mnem == "addi"
    assert ins.ops[0].reg == 28 and ins.ops[1].reg == 28 and ins.ops[2].value == -0x88
    stmts = lifter.lift_insn(ins)
    assert isinstance(stmts[0], ir.Assign)
    assert stmts[0].dst.name == "sp"
    assert stmts[0].src.op == "+"


def test_decode_big_endian():
    # Test big-endian decoding of addi sp, sp, -0x88
    b_be = _img_at(0x2000, 0x379CFF78, is_be=True)
    ins = decoder.decode_one(b_be, 0x2000, is_be=True)
    assert ins.mnem == "addi"
    assert ins.ops[0].reg == 28 and ins.ops[2].value == -0x88


def test_decode_loads_and_stores():
    # sw (sp+0x14), r11: opcode=0x16, r0=28(sp), r1=11, imm=0x14
    # (0x16 << 26) | (28 << 21) | (11 << 16) | 0x14 = 0x5B8B0014
    b_sw = _img_at(0x1010, 0x5B8B0014, is_be=False)
    ins = decoder.decode_one(b_sw, 0x1010, is_be=False)
    assert ins.mnem == "sw"
    assert ins.ops[0].mode == "displ" and ins.ops[0].base_reg == 28 and ins.ops[0].disp == 0x14
    assert ins.ops[1].mode == "reg" and ins.ops[1].reg == 11
    stmts = lifter.lift_insn(ins)
    assert isinstance(stmts[0], ir.Assign)
    assert isinstance(stmts[0].dst, ir.Mem)
    assert stmts[0].src.name == "r11"

    # lw r2, (r3+0): opcode=0x0A, r0=3, r1=2, imm=0
    # (0x0A << 26) | (3 << 21) | (2 << 16) | 0 = 0x28620000
    b_lw = _img_at(0x1014, 0x28620000, is_be=False)
    ins = decoder.decode_one(b_lw, 0x1014, is_be=False)
    assert ins.mnem == "lw"
    assert ins.ops[0].reg == 2 and ins.ops[1].base_reg == 3 and ins.ops[1].disp == 0
    stmts = lifter.lift_insn(ins)
    assert isinstance(stmts[0], ir.Assign)
    assert stmts[0].dst.name == "r2"
    assert isinstance(stmts[0].src, ir.Mem) and stmts[0].src.width == 4


def test_decode_branches_and_calls():
    # calli 0x60DC: opcode=0x3E, pc=0x8CD0, disp=(0x60DC - 0x8CD0) // 4 = -0xAFD
    disp26 = (-0xAFD) & 0x03FFFFFF
    word = (0x3E << 26) | disp26
    b_call = _img_at(0x8CD0, word, is_be=False)
    ins = decoder.decode_one(b_call, 0x8CD0, is_be=False)
    assert ins.mnem == "calli"
    assert ins.ops[0].addr == 0x60DC
    stmts = lifter.lift_insn(ins)
    assert isinstance(stmts[0], ir.Call) and stmts[0].target == 0x60DC

    # be r1, r0, 0x8CF0: opcode=0x11, r0=1, r1=0, disp=(0x8CF0 - 0x8CF8) / 4 = -2
    disp16 = (-2) & 0xFFFF
    word = (0x11 << 26) | (1 << 21) | (0 << 16) | disp16
    b_be = _img_at(0x8CF8, word, is_be=False)
    ins = decoder.decode_one(b_be, 0x8CF8, is_be=False)
    assert ins.mnem == "be"
    assert ins.ops[2].addr == 0x8CF0
    stmts = lifter.lift_insn(ins)
    assert isinstance(stmts[0], ir.Branch)
    assert stmts[0].target == 0x8CF0
    assert stmts[0].fallthrough == 0x8CFC
    # Notice that r0 in r1 operand evaluates to Const(0)!
    assert isinstance(stmts[0].cexpr.r, ir.Const) and stmts[0].cexpr.r.value == 0

    # ret: b ra -> opcode=0x30, r0=29 (ra)
    # (0x30 << 26) | (29 << 21) = 0xC3A00000
    b_ret = _img_at(0x1020, 0xC3A00000, is_be=False)
    ins = decoder.decode_one(b_ret, 0x1020, is_be=False)
    assert ins.mnem == "ret"
    stmts = lifter.lift_insn(ins)
    assert isinstance(stmts[0], ir.Ret) and stmts[0].kind == "ret"


def test_csr_instructions():
    # rcsr r0, IM: opcode=0x24, r0=1(IM), r1=0
    # (0x24 << 26) | (1 << 21) | (0 << 16) = 0x90200000
    b_rcsr = _img_at(0x8CF0, 0x90200000, is_be=False)
    ins = decoder.decode_one(b_rcsr, 0x8CF0, is_be=False)
    assert ins.mnem == "rcsr"
    assert ins.ops[0].reg == 0 and ins.ops[1].reg == "IM"
    stmts = lifter.lift_insn(ins)
    assert isinstance(stmts[0], ir.Assign)
    assert isinstance(stmts[0].src, ir.IntrExpr) and stmts[0].src.name == "__rcsr"


if __name__ == "__main__":
    test_decode_addi_and_nop()
    test_decode_big_endian()
    test_decode_loads_and_stores()
    test_decode_branches_and_calls()
    test_csr_instructions()
    print("ALL DECODER & LIFTER TESTS PASSED!")
```

```py
"""
Headless pipeline tests for the LM32 decompiler.
Verifies end-to-end decompilation, EA anchoring, and Hex-Rays C generation.
Zero IDA dependencies.
"""

import os
import sys

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from lm32dec import decompile_image, decoder


def _pack_be(words):
    b = bytearray()
    for w in words:
        b.extend(w.to_bytes(4, "big"))
    return b


def _pack_le(words):
    b = bytearray()
    for w in words:
        b.extend(w.to_bytes(4, "little"))
    return b


def test_simple_function_pipeline_be():
    # addi r1, r1, 10
    # b r29 (ret)
    words = [
        0x3421000A,  # addi r1, r1, 10
        0xC3A00000,  # b r29
    ]
    img = _pack_be(words)
    prog = decompile_image(img, entries=[0], base=0, is_be=True)
    assert 0 in prog.funcs
    fn = prog.funcs[0]
    text = "\n".join(fn.lines)
    assert "int sub_0(int a0)" in text
    assert "+ 0xA" in text or "0xA" in text
    assert "return" in text

    # Verify 100% instruction EA anchoring
    assert 0 in fn.ea_to_line
    assert 4 in fn.ea_to_line
    assert fn.ea_to_line[0] in fn.line_to_eas
    assert fn.ea_to_line[4] in fn.line_to_eas
    print("ok  test_simple_function_pipeline_be")


def test_simple_function_pipeline_le():
    # addi r1, r1, 10
    # b r29 (ret)
    words = [
        0x3421000A,
        0xC3A00000,
    ]
    img = _pack_le(words)
    prog = decompile_image(img, entries=[0], base=0, is_be=False)

    assert 0 in fn.ea_to_line

    print("ok  test_simple_function_pipeline_le")


def test_loop_structuring():
    # 0x00: addi r1, r0, 5      # r1 = 5
    # 0x04: addi r1, r1, -1     # loop: r1 = r1 - 1
    # 0x08: bne r1, r0, -1      # if r1 != 0 goto 0x04 (disp = -1 word)
    # 0x0C: b r29               # ret
    words = [
        0x34010005,  # addi r1, r0, 5
        0x3421FFFF,  # addi r1, r1, -1
        0x5C20FFFF,  # bne r1, r0, disp=-1 (to 0x04)
        0xC3A00000,  # b r29

    img = _pack_be(words)
    prog = decompile_image(img, entries=[0], base=0, is_be=True)
    fn = prog.funcs[0]
    text = "\n".join(fn.lines)
    assert "do {" in text or "while (" in text, text
    assert text.count("{") == text.count("}"), text

    for ea in (0, 4, 8, 12):
        assert ea in fn.ea_to_line, f"EA {hex(ea)} missing from ea_to_line"
    print("ok  test_loop_structuring")
```

```py
"""
Headless tests for disassembly <-> pseudocode line selection syncing and
instruction mapping in lm32dec.
"""

import os
import sys

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from lm32dec import cfg, ir, cgen, callargs, structure, names, decoder


def _make_insn(ea, mnem):
    ins = decoder.Insn(ea)
    ins.mnem = mnem
    ins.size = 4
    return ins


def test_inlined_call_args_sync():
    # Block at 0x100:
    # 0x100: addi r1, r0, 10
    # 0x104: addi r2, r0, 20
    # 0x108: calli 0x500
    # 0x10C: b r29
    f = cfg.Func(0x100)
    b = cfg.Block(0x100)
    for ea, mnem in [(0x100, "addi"), (0x104, "addi"), (0x108, "calli"), (0x10C, "b")]:
        b.insns.append(_make_insn(ea, mnem))
    b.stmts = [
        ir.Assign(0x100, ir.Reg("r1"), ir.Const(10)),
        ir.Assign(0x104, ir.Reg("r2"), ir.Const(20)),
        ir.Call(0x108, target=0x500),
        ir.Ret(0x10C),
    ]
    b.term = "ret"
    f.blocks[0x100] = b

    callargs.rewrite(f, {0x500: 2})
    tree = structure.structure(f)
    namer = names.Namer()
    lines = cgen.generate(f, tree, namer)

    assert hasattr(lines, "line_to_eas")
    assert hasattr(lines, "ea_to_line")

    # Find the line containing "sub_500(10, 20);"
    call_line = None
    for idx, text in enumerate(lines):
        if "sub_500" in text:
            call_line = idx
            break

    assert call_line is not None, lines

    # Both argument setups (0x100, 0x104) and the call (0x108) must map to call_line!
    assert lines.ea_to_line[0x100] == call_line, (lines.ea_to_line[0x100], call_line)
    assert lines.ea_to_line[0x104] == call_line, (lines.ea_to_line[0x104], call_line)
    assert lines.ea_to_line[0x108] == call_line, (lines.ea_to_line[0x108], call_line)

    # In reverse: selecting call_line must highlight all 3 instructions!
    eas = lines.line_to_eas[call_line]
    assert 0x100 in eas, eas
    assert 0x104 in eas, eas
    assert 0x108 in eas, eas
    print("ok  test_inlined_call_args_sync")


def test_tail_call_sync():
    # 0x200: addi r1, r0, 5
    # 0x204: bi 0x400 (tail call)
    f = cfg.Func(0x200)
    b = cfg.Block(0x200)
    for ea, mnem in [(0x200, "addi"), (0x204, "bi")]:
        b.insns.append(_make_insn(ea, mnem))
    b.stmts = [
        ir.Assign(0x200, ir.Reg("r1"), ir.Const(5)),
        ir.Call(0x204, target=0x400, is_tail=True),
        ir.Ret(0x204),
    ]
    b.term = "ret"
    f.blocks[0x200] = b

    callargs.rewrite(f, {0x400: 1})
    tree = structure.structure(f)
    namer = names.Namer()
    lines = cgen.generate(f, tree, namer)

    tail_line = None
    for idx, text in enumerate(lines):
        if "sub_400" in text:
            tail_line = idx
            break

    assert tail_line is not None, lines
    assert lines.ea_to_line[0x200] == tail_line
    assert lines.ea_to_line[0x204] == tail_line
    print("ok  test_tail_call_sync")


def test_dense_instruction_coverage():
    # Ensure all instructions in basic blocks are anchored to lines
    f = cfg.Func(0x300)
    b = cfg.Block(0x300)
    for off in range(0, 16, 4):
        b.insns.append(_make_insn(0x300 + off, "nop"))
    b.stmts = [ir.Ret(0x30C)]
    b.term = "ret"
    f.blocks[0x300] = b

    tree = structure.structure(f)
    namer = names.Namer()
    lines = cgen.generate(f, tree, namer)

    for off in range(0, 16, 4):
        ea = 0x300 + off
        assert ea in lines.ea_to_line, f"Missing EA {hex(ea)}"
        line = lines.ea_to_line[ea]
        assert ea in lines.line_to_eas[line]
    print("ok  test_dense_instruction_coverage")


if __name__ == "__main__":
    test_inlined_call_args_sync()
    test_tail_call_sync()
    test_dense_instruction_coverage()
    print("\nALL SYNC TESTS PASSED!")
```

```py
"""
Unit tests for LM32 SSA def-use variable recovery, optimization, and structuring.
"""

import os
import sys

sys.path.insert(0, os.path.dirname(os.path.dirname(os.path.abspath(__file__))))

from lm32dec import ir, cfg, opt, vars, structure, abi


def test_cmp_to_branch_folding():
    # cmpe r1, r2, r3 -> r1 = (r2 == r3)
    # bne r1, r0, 0x1010 -> if (r1 != 0) goto 0x1010
    # Should fold into: if (r2 == r3) goto 0x1010
    f = cfg.Func(0x1000)
    b0 = cfg.Block(0x1000)
    b0.term = "branch"
    b0.succ = [(True, 0x1010), (False, 0x1008)]
    b0.stmts = [
        ir.Assign(0x1000, ir.Reg("r1"), ir.Bin("==", ir.Reg("r2"), ir.Reg("r3"))),
        ir.Branch(0x1004, ir.Bin("!=", ir.Reg("r1"), ir.Const(0)), 0x1010, 0x1008),
    ]
    f.blocks[0x1000] = b0

    opt.optimize(f)
    assert len(b0.stmts) == 1
    branch = b0.stmts[0]
    assert isinstance(branch, ir.Branch)
    assert branch.cexpr.op == "=="
    assert branch.cexpr.l.name == "r2"
    assert branch.cexpr.r.name == "r3"
    assert branch.inlined_eas == [0x1000]


def test_vars_recovery_and_splitting():
    # Block 0:
    #   r1 is input arg (a0)
    #   r2 = r1 + 1 (v0)
    #   r10 = r2 * 2 (v1)
    # Block 1 (separate disjoint use of r2):
    #   r2 = 100 (v2)
    #   r1 = r2 + r10 (return value)
    f = cfg.Func(0x2000)
    b0 = cfg.Block(0x2000)
    b0.term = "fall"
    b0.succ = [("fall", 0x2010)]
    b0.stmts = [
        ir.Assign(0x2000, ir.Reg("r2"), ir.Bin("+", ir.Reg("r1"), ir.Const(1))),
        ir.Assign(0x2004, ir.Reg("r10"), ir.Bin("*", ir.Reg("r2"), ir.Const(2))),
    ]

    b1 = cfg.Block(0x2010)
    b1.term = "ret"
    b1.stmts = [
        ir.Assign(0x2010, ir.Reg("r2"), ir.Const(100)),
        ir.Assign(0x2014, ir.Reg("r1"), ir.Bin("+", ir.Reg("r2"), ir.Reg("r10"))),
        ir.Ret(0x2018, "ret"),
    ]
    f.blocks[0x2000] = b0
    f.blocks[0x2010] = b1

    sig = abi.analyze_calling_convention(f)
    assert len(sig.params) == 1 and sig.params[0].name == "a0"

    vars.recover_variables(f, sig=sig)

    # In b0: r2 was inlined into r10 because it was single-use: r10 = (a0 + 1) * 2
    assert len(b0.stmts) == 1
    assert b0.stmts[0].src.l.l.name == "a0"
    v_r10_name = b0.stmts[0].dst.name
    assert v_r10_name.startswith("v")

    # In b1: r2 is reassigned, and used in return expression: r1 = v_r2 + v_r10
    assert len(b1.stmts) >= 1
    # Check that virtual variables are distinct
    assert v_r10_name in [s.src.r.name for s in b1.stmts if isinstance(s, ir.Assign) and isinstance(s.src, ir.Bin)]


def test_structure_if_then():
    # CFG with if-then triangle:
    # 0x3000: if (r1 == 0) goto 0x3010
    # 0x3004: r2 = 5
    # 0x3010: return
    f = cfg.Func(0x3000)
    b0 = cfg.Block(0x3000)
    b0.term = "branch"
    b0.succ = [(True, 0x3010), (False, 0x3004)]
    b0.stmts = [ir.Branch(0x3000, ir.Bin("==", ir.Reg("r1"), ir.Const(0)), 0x3010, 0x3004)]

    b1 = cfg.Block(0x3004)
    b1.term = "fall"
    b1.succ = [("fall", 0x3010)]
    b1.stmts = [ir.Assign(0x3004, ir.Reg("r2"), ir.Const(5))]

    b2 = cfg.Block(0x3010)
    b2.term = "ret"
    b2.stmts = [ir.Ret(0x3010, "ret")]

    f.blocks[0x3000] = b0
    f.blocks[0x3004] = b1
    f.blocks[0x3010] = b2

    tree = structure.structure(f)
    assert len(tree) >= 1
    # Check that SIf was recovered with exact instruction EA anchoring
    sif = next((node for node in tree if isinstance(node, structure.SIf)), None)
    assert sif is not None
    assert sif.ea == 0x3000


if __name__ == "__main__":
    test_cmp_to_branch_folding()
    test_vars_recovery_and_splitting()
    test_structure_if_then()
    print("ALL VARS & STRUCTURER TESTS PASSED!")
```
