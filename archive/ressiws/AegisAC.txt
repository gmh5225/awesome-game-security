## 📖 Overview

**AegisAC** provides servers with robust, automated detection against aimbots and unnatural aiming mechanics in Counter-Strike 2. Unlike invasive kernel-level drivers or third-party client anti-cheats, AegisAC runs **strictly on the server**:

- **Zero Client Overhead:** Players do not need to download or install background software.
- **Sub-Tick Phase Aware:** Designed from the ground up to operate seamlessly with CS2's usercmd and sub-tick architecture.
- **Evidence-Based Sanctions:** Punishments are only executed when multiple, high-confidence evidence points are collected across a sliding time window, mitigating false positives.
- **Extensible Architecture:** Modular design allowing server owners to select independent punishment types (`ban`, `kick`, or `none`) for each detection module.

---

## ✨ Key Features

- **🎯 Advanced Trajectory & Angle Math:** Employs forward vector trigonometry, angular distance delta checking, and historical position reconciliation to detect instantaneous snaps and unnatural aimbot movement.
- **🔄 Sub-Tick & Phase-Compensated Correlator:** Reliably pairs `weapon_fire` and `player_hurt` events with exact user commands, compensating for client tick gaps and engine phase shifts.
- **⚖️ Modular Punishment System:** Configure punishments per module (`ban`, `kick`, `none`) with custom command templates supporting placeholders (`{userid}`, `{steamid}`, `{name}`, `{reason}`).
- **🔔 Discord Webhook Integration:** Instant, rich embed alerts dispatched asynchronously to your staff Discord channel when a player is flagged, kicked, or banned.
- **⚡ Hot Reloading & Live Config:** Reload configurations instantaneously during live gameplay with the `aegis_reload` command without restarting the server or kicking players.
- **🔍 Unified Diagnostic Mode:** Single global debug mode across the entire plugin for clean console logs and transparent troubleshooting.

## 🛡️ Detection Modules & Strictness

AegisAC is designed with a **low false-positive** philosophy. The table below outlines active and planned modules along with their detection mechanics and strictness levels.

<details open>
<summary><b>Active Module: Aimbot Detection (Click to collapse/expand)</b></summary>
<br/>

The Aimbot detector inspects user commands, view angles, weapon fire correlation, and player damage to identify automated targeting mechanics.

### Detection Methods

1. **Convergence Snap Detection**
   - **How it works:** Analyzes the angular delta between the player's view angles before and after a shot. If the aim jumps directly toward an enemy's exact hitboxes in a single tick (e.g. > 10° snap onto target), it is flagged as convergence.
   - **Trigger Condition:** Shot must inflict confirmed damage (`player_hurt`), target distance must exceed `100.0` game units, and aim must resolve directly onto enemy position.

2. **Snap-Return Detection**
   - **How it works:** Detects "silent" or snap-return aimbots that jump onto a target to fire a lethal shot and immediately snap back to the previous view angle within adjacent ticks.
   - **Trigger Condition:** Single-command angular jump onto the enemy followed by an immediate return to prior view angles.

3. **Smooth Convergence Detection**
   - **How it works:** Identifies mathematical curve-smoothing aimbots. Evaluates path efficiency, angular step consistency, and final terminal error against calibrated human aiming envelopes.
   - **Trigger Condition:** Step efficiency ≥ 94% with progressive angular improvement terminating under 1.0° from target center.

### Strictness Rating

| Metric | Setting / Behavior |
| :--- | :--- |
| **Strictness Level** | **Conservative (High Precision)** |
| **Evidence Window** | 5 Minutes (Sliding) |
| **Evidence Threshold** | 3 Verified Damaging Incidents required |
| **Damage Gate** | Active — shots that miss or do zero damage never accumulate incident counts |
| **Distance Gate** | Active — point-blank combat (< 100 units) is excluded from snap calculation |
| **False-Positive Profile** | Highly resilient against legitimate high-sensitivity flicks and swipe resets |

</details>

<details>
<summary><b>Planned Modules (Roadmap)</b></summary>
<br/>

- **Anti-Untrusted / Impossible Angles:** Flags invalid view angles (out-of-bounds Pitch, Yaw, Roll, NaN/Infinity exploits). *(Strictness: Aggressive / Instant)*
- **Triggerbot / Instant Reaction Detection:** Flags sub-human reaction latencies across multiple engagements. *(Strictness: Moderate)*
- **Movement / Anti-Bhop** Detects automated jump timing and duck-spam movement scripts. *(Strictness: Moderate)*

</details>

## 🚀 Quick Start

### Prerequisites

- Counter-Strike 2 Dedicated Server.
- [.NET 10.0 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) installed on the host machine.
- [SwiftlyS2 Framework](https://swiftlys2.net/) (v1.1.6 or newer) installed in `game/csgo/addons/swiftlys2`.

### Installation

1. Download the latest release `.zip` from the [Releases](https://github.com/swisser/AegisAC/releases) page.
2. Extract the archive into your server's plugin directory:
   ```
   game/csgo/addons/swiftlys2/plugins/AegisAC/
   ```
3. Start or restart your server. SwiftlyS2 will automatically detect and load `AegisAC.dll`.
4. On first load, AegisAC automatically generates the default configuration file:
   ```
   game/csgo/addons/swiftlys2/configs/plugins/AegisAC/config.jsonc
   ```

### Building from Source

To compile the plugin locally:

```bash
# Clone the repository
git clone https://github.com/swisser/AegisAC.git
cd AegisAC

# Build in Release configuration
dotnet build -c Release

# Package and publish
dotnet publish -c Release
```

The compiled binaries will be output to `build/publish/AegisAC/`.

## ⚙️ Configuration Reference

AegisAC configurations are stored in `addons/swiftlys2/configs/plugins/AegisAC/config.jsonc`. The file supports comments (`//`) and auto-populates missing keys on server startup.

```jsonc
{
  "AegisAC": {
    // Global debug mode for Aegis Anti-Cheat. Enables verbose diagnostic logs in server console.
    "Debug": false,

    // Command executed when kicking a player.
    // Available placeholders: {userid}, {steamid}, {name}, {reason}
    "KickCommand": "kickid {userid} \"[AegisAC] {reason}\"",

    // Command executed when banning a player.
    // Available placeholders: {userid}, {steamid}, {name}, {reason}
    "BanCommand": "banid 0 {steamid}; writeid; kickid {userid} \"[AegisAC] {reason}\"",

    // Aimbot detection module configuration
    "Aimbot": {
      // Enable or disable aimbot detection
      "Enabled": true,

      // Punishment applied upon detection: "none", "kick", or "ban"
      "Punishment": "none",

      // Treat teammates as enemies (useful for FFA / Deathmatch servers)
      "TeammatesAreEnemies": false
    },

    // Discord webhook notifications
    "Discord": {
      // Enable or disable Discord alert embeds
      "Enabled": false,

      // Discord webhook URL to send detection notifications
      "WebhookUrl": "https://discord.com/api/webhooks/YOUR_WEBHOOK_URL_HERE"
    }
  }
}
```

## ❓ Frequently Asked Questions (FAQ)

<details>
<summary><b>Does AegisAC require any client downloads or VAC-incompatible binaries?</b></summary>
<br/>
No. AegisAC is 100% server-sided. It operates purely on user commands and entity state data sent by the standard CS2 client. It does not tamper with client memory, DLLs, or VAC.
</details>

<details>
<summary><b>How does AegisAC handle CS2's Sub-Tick mechanics?</b></summary>
<br/>
CS2 usercmds include historical attack viewangles and sub-tick timestamps. AegisAC reconciles these timestamps during `ProcessUsercmds` and movement simulation (`SetupMove`), compensating for client-tick gaps and phase differences before evaluating aim trajectories.
</details>

<details>
<summary><b>Can legitimate players with high DPI or flick aim get false-banned?</b></summary>
<br/>
No. AegisAC requires **3 separate damaging incidents within a 5-minute window** to trigger a punishment. Random fast flicks or crosshair adjustments that do not resolve into unnatural single-tick hitbox convergence accompanied by confirmed damage are filtered out.
</details>

<details>
<summary><b>Can I test detections without automatically banning players?</b></summary>
<br/>
Yes! Simply set `"Punishment": "none"` in your `config.jsonc`. Detections will still be announced in the console and sent to your Discord webhook without taking action against the player.
</details>

<details>
<summary><b>Does AegisAC cause server lag or drop tick rate?</b></summary>
<br/>
No. All player command buffers and position frames are stored in fixed-size circular arrays, and computationally heavy operations (such as HTTP Discord webhooks) run completely off the game thread.
</details>

`src/AegisAC.cs`:

```cs
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Primitives;
using SwiftlyS2.Shared;
using SwiftlyS2.Shared.Commands;
using SwiftlyS2.Shared.GameEventDefinitions;
using SwiftlyS2.Shared.GameEvents;
using SwiftlyS2.Shared.GameHooks;
using SwiftlyS2.Shared.Misc;
using SwiftlyS2.Shared.Plugins;
using SwiftlyS2.Shared.Players;
using AegisAC.Configuration;
using AegisAC.Notifications;
using AegisAC.Punishment;

namespace AegisAC;

[PluginMetadata(
	Id = "AegisAC",
	Version = "1.0.0",
	Name = "Aegis Anti-Cheat",
	Author = "swisser & sevon",
	Description = "Server-side anti-cheat plugin for CS2.",
	MinimumAPIVersion = "1.1.6")]
public sealed class AegisAC : BasePlugin
{
	private AegisConfig _config = new();
	private PunishmentManager _punishmentManager = null!;
	private AimbotDetector _detector = null!;
	private IDisposable? _configChangeToken;

	public AegisAC(ISwiftlyCore core) : base(core) { }

	public override void Load(bool hotReload)
	{
		Utils.Initialize(Core);

		// Initialize plugin configuration using SwiftlyS2 configuration service
		Core.Configuration
			.InitializeJsonWithModel<AegisConfig>("config.jsonc", "AegisAC", addMissingKeys: true)
			.Configure(builder =>
			{
				builder.AddJsonFile(Core.Configuration.GetConfigPath("config.jsonc"), optional: false, reloadOnChange: true);
			});

		LoadConfig();
		_configChangeToken = ChangeToken.OnChange(() => Core.Configuration.Manager.GetReloadToken(), LoadConfig);

		_punishmentManager = new PunishmentManager(Core, _config);

		_detector = new AimbotDetector(
			_config.Aimbot,
			id => Core.PlayerManager.GetPlayer(id),
			Announce,
			msg => { if (Utils.DebugMode) Utils.ConsoleLog(msg); });

		Core.GameHooks.Controller.ProcessUsercmds.Pre += OnProcessUsercmds;
		Core.GameHooks.Movement.SetupMove.Pre += OnSetupMove;
		Core.Event.OnTick += OnTick;

using SwiftlyS2.Shared.Natives;

namespace AegisAC;

internal static class AimMath
{
	private const float Deg2Rad = MathF.PI / 180.0f;
	private const float Rad2Deg = 180.0f / MathF.PI;
	public const float Epsilon = 1e-6f;

	public static bool IsFinite(in QAngle a) => float.IsFinite(a.Pitch) && float.IsFinite(a.Yaw) && float.IsFinite(a.Roll);
	public static bool IsFinite(in Vector v) => float.IsFinite(v.X) && float.IsFinite(v.Y) && float.IsFinite(v.Z);

	public static Vector Forward(in QAngle a)
	{
		float pitch = a.Pitch * Deg2Rad;
		float yaw = a.Yaw * Deg2Rad;
		float cp = MathF.Cos(pitch);
		return new Vector(cp * MathF.Cos(yaw), cp * MathF.Sin(yaw), -MathF.Sin(pitch));
	}

	private static float Dot(in Vector a, in Vector b) => a.X * b.X + a.Y * b.Y + a.Z * b.Z;

	public static float AngularDistance(in QAngle a, in QAngle b)
	{
		if (!IsFinite(a) || !IsFinite(b)) return float.NaN;
		float dot = Math.Clamp(Dot(Forward(a), Forward(b)), -1.0f, 1.0f);
		return MathF.Acos(dot) * Rad2Deg;
	}

	public static float AimError(in Vector eye, in QAngle angles, in Vector target)
	{
		var dir = target - eye;
		if (!IsFinite(dir) || dir.LengthSquared() < Epsilon) return 0.0f;
		float len = dir.Length();
		dir = new Vector(dir.X / len, dir.Y / len, dir.Z / len);
		float dot = Math.Clamp(Dot(Forward(angles), dir), -1.0f, 1.0f);
		return MathF.Acos(dot) * Rad2Deg;
	}

	private static readonly float[] BodyHeights = { 8.0f, 46.0f, 64.0f };
	public static int BodyPointCount => BodyHeights.Length;
	public static float BodyHeight(int i) => BodyHeights[i];

	public static float NearestBodyAimError(in Vector eye, in QAngle angles, in Vector feet)
	{
		float best = 180.0f;
		foreach (float h in BodyHeights)
			best = MathF.Min(best, AimError(eye, angles, new Vector(feet.X, feet.Y, feet.Z + h)));
		return best;
	}
}

	public void OnProcessUsercmds(IPlayer player, List<SwiftlyS2.Shared.GameHooks.IUserCmd> cmds)
	{
		if (!_settings.Enabled || !IsEligibleHuman(player) || cmds.Count == 0)
			return;

		var st = _players[player.PlayerID];

		foreach (var cmd in cmds)
		{
			var pb = cmd.CSGOUserCmd;
			int number = (int)cmd.CommandNumber;

			StatUsercmds++;

			if (st.Commands.Exists(c => c.CommandNumber == number))
			{
				StatSkipDup++;
				continue;
			}

			if (!pb.Accessor.HasField("base"))
			{
				StatSkipNoBase++;
				continue;
			}

			var b = pb.Base;

			if (!b.Accessor.HasField("viewangles"))
			{
				StatSkipNoViewangles++;
				continue;
			}

			QAngle angles = b.Viewangles;
			bool isShot = false;
			int idx = pb.Attack1StartHistoryIndex;
			int histCount = pb.InputHistory.Count;
			bool hasVA = false;

			if (idx >= 0 && idx < histCount)
			{
				var entry = pb.InputHistory.Get(idx);
				hasVA = entry.Accessor.HasField("view_angles");

				if (hasVA)
				{
					QAngle shotAngles = entry.ViewAngles;
					if (AimMath.IsFinite(shotAngles))
					{
						angles = shotAngles;
						isShot = true;
						StatShotCmds++;
					}
				}
			}

			st.LastIdx = idx;
			st.LastHistCount = histCount;
			st.LastHasVA = hasVA;

			if (!AimMath.IsFinite(angles))
			{
				StatSkipNonFinite++;
				continue;
			}

			st.Commands.Add(new AimCommand { CommandNumber = number, ClientTick = b.ClientTick, Angles = angles, IsShot = isShot });
			StatStored++;

			if (st.Commands.Count > CommandHistorySize)
				st.Commands.RemoveAt(0);
		}
	}

	public void OnSetupMove(IPlayer player, int commandNumber, int currentTick)

	public void OnGameFrame(int currentTick)
	{
		if (!_settings.Enabled)
			return;

		CaptureFrame(currentTick);
		StatFrames++;

		for (int id = 0; id < MaxPlayers; id++)
		{
			var st = _players[id];

			st.Shots.RemoveAll(s => (long)currentTick - s.FireTick > 2);

			if (!st.Pending)
				continue;

			var p = _getPlayer(id);
			if (!IsEligibleHuman(p))
			{
				_players[id] = new PlayerState();
				continue;
			}

			Evaluate(p!, st, currentTick);
		}
	}

	private void CaptureFrame(int tick)
	{
		var frame = new PositionFrame { ServerTick = tick };
		var previous = _frames.Count > 0 ? _frames[^1] : null;

		for (int id = 0; id < MaxPlayers; id++)
		{
			var p = _getPlayer(id);
			var pawn = p?.PlayerPawn;
			var node = pawn?.CBodyComponent?.SceneNode;

			if (p == null || !p.IsValid || pawn == null || !pawn.IsValid || node == null)
				continue;

			Vector origin = node.AbsOrigin;
			if (!AimMath.IsFinite(origin))
				continue;

			var eye = pawn.EyePosition ?? new Vector(origin.X, origin.Y, origin.Z + 64.0f);

			bool teleported = false;
			if (previous != null && previous.Players[id].Valid)
				teleported = origin.Distance(previous.Players[id].Origin) > TeleportDistance;

			frame.Players[id] = new TrackedPosition
			{
				Origin = origin,
				Eye = eye,
				Team = pawn.TeamNum,
				Valid = true,
				Alive = pawn.LifeState == 0,
				Teleported = teleported,
			};
		}

		if (previous != null && previous.ServerTick == tick)
			_frames[^1] = frame;
		else
		{
			_frames.Add(frame);
			if (_frames.Count > PositionHistoryLimit)
				_frames.RemoveAt(0);
		}
	}

	private bool FindPosition(int tick, int id, out TrackedPosition pos)
	{
		for (int i = _frames.Count - 1; i >= 0; i--)
		{
			if (_frames[i].ServerTick != tick)
				continue;

			pos = _frames[i].Players[id];
			return pos.Valid;
		}

		pos = default;
		return false;
	}


	public void OnWeaponFire(IPlayer player, string weapon, int currentTick)
	{
		if (!_settings.Enabled || !IsEligibleHuman(player))
			return;

		if (weapon.StartsWith("weapon_", StringComparison.Ordinal))
			weapon = weapon[7..];

		if (!BallisticWeapons.Contains(weapon))
			return;

		StatWeaponFires++;

		var st = _players[player.PlayerID];

		var newestShotCmd = st.Commands.LastOrDefault(c => c.IsShot);
		if (newestShotCmd == null)
			StatAgeNone++;
		else if (!newestShotCmd.Simulated)
			StatAgeNoSim++;
		else
		{
			long age = (long)currentTick - newestShotCmd.ServerTick;
			if (age < -1) StatAgeLtNeg1++;
			else if (age == -1) StatAgeEqNeg1++;
			else if (age == 0) StatAgeEq0++;
			else if (age == 1) StatAgeEq1++;
			else StatAgeGt1++;
		}

		var candidates = st.Commands
			.Where(c =>
				c.IsShot &&
				c.Simulated &&
				!c.Consumed &&
				(long)currentTick - c.ServerTick is >= -1 and <= 1)
			.ToArray();

		if (candidates.Length != 1)
		{
			foreach (var candidate in candidates)
				candidate.Consumed = true;

			StatFireNoMatch++;

			var lastShotCmd = st.Commands.LastOrDefault(c => c.IsShot);
			int histShot = st.Commands.Count(c => c.IsShot);
			LastFireDiag = lastShotCmd == null
				? $"tick={currentTick} cands={candidates.Length} histShot=0 lastShot=none"
				: $"tick={currentTick} cands={candidates.Length} histShot={histShot} lastShot=cmd{lastShotCmd.CommandNumber} sim={lastShotCmd.Simulated} serverTick={lastShotCmd.ServerTick} age={(lastShotCmd.ServerTick < 0 ? "NA" : $"{currentTick - lastShotCmd.ServerTick}")}";

			_debug($"{Name(player)} weapon_fire unmatched: {candidates.Length} candidate commands at tick {currentTick} (lastCmd idx={st.LastIdx} histCount={st.LastHistCount} hasVA={st.LastHasVA} recentShotCmds={st.Commands.Count(c => c.IsShot)}/{st.Commands.Count}).");
			return;
		}

		var command = candidates[0];
		command.Consumed = true;

		st.Shots.Add(new ShotRecord
		{
			Command = command,
			FireTick = currentTick,
			Weapon = weapon
		});

		if (st.Shots.Count > 8)
			st.Shots.RemoveAt(0);

		StatFireMatched++;

		_debug($"{Name(player)} weapon_fire matched command {command.CommandNumber}, server tick {command.ServerTick}, fire tick {currentTick}.");
	}

	public void OnPlayerHurt(IPlayer attacker, IPlayer victim, string weapon, int currentTick)
	{
		if (!_settings.Enabled || !IsEligibleHuman(attacker) || !victim.IsValid || attacker.PlayerID == victim.PlayerID)
			return;

		if (weapon.StartsWith("weapon_", StringComparison.Ordinal))
			weapon = weapon[7..];

		StatHurts++;

		if (!BallisticWeapons.Contains(weapon))
		{
			_debug($"{Name(attacker)} hurt ignored: weapon '{weapon}' is not ballistic.");
			return;
		}

		var st = _players[attacker.PlayerID];

		var candidates = st.Shots
			.Where(s =>
				!s.HurtSeen &&
				(long)currentTick - s.FireTick is >= 0 and <= 1
				).ToArray();

		if (candidates.Length != 1)
		{
			StatHurtNoMatch++;
			_debug($"{Name(attacker)} hurt unmatched: {candidates.Length} registered shots at tick {currentTick}.");
			return;
		}

		var shot = candidates[0];
		shot.HurtSeen = true;
		shot.VictimId = victim.PlayerID;

		var command = shot.Command;

		StatMatched++;

		if (st.Pending)
		{
			Evaluate(attacker, st, command.ServerTick);

			if (st.Pending)
			{
				st.Pending = false;
				st.PendingShot = -1;
				st.VictimId = -1;
			}
		}

		st.PendingShot = command.CommandNumber;
		st.VictimId = victim.PlayerID;
		st.Pending = true;

		_debug($"{Name(attacker)} correlated damage with shot command {command.CommandNumber}, server tick {command.ServerTick}, fire tick {shot.FireTick}.");

		Evaluate(attacker, st, command.ServerTick);
	}

	private readonly record struct SmoothPoint(AimCommand Command, float Error);

	private static AimCommand? FindCommand(PlayerState st, int number) =>
		st.Commands.FindLast(c => c.CommandNumber == number && c.Simulated);

	private static bool MeetsSmoothThresholds(float movement, float improvement, float finalError, float efficiency, int steps, bool shrinking) =>
		movement >= SmoothMinimumMovement && improvement >= SmoothMinimumImprovement && finalError <= SmoothMaximumFinalError
		&& efficiency >= SmoothMinimumPathEfficiency && steps >= SmoothMinimumSteps && shrinking;

	private static string Name(IPlayer p) => p.Controller?.PlayerName ?? $"#{p.PlayerID}";

	private bool Evaluate(IPlayer attacker, PlayerState st, int currentTick)
	{
		if (!st.Pending)
			return true;

		StatEvaluations++;
		int attackerId = attacker.PlayerID;

		void Clear()
		{
			st.PendingShot = -1;
			st.VictimId = -1;
			st.Pending = false;
		}

		var shot = st.Commands.Find(c => c.CommandNumber == st.PendingShot);
		if (shot == null || !shot.Simulated || st.VictimId < 0 || st.VictimId >= MaxPlayers)
		{
			Clear();
			return true;
		}

		bool haveTarget = FindPosition(shot.ServerTick, st.VictimId, out var shotTarget);
		bool haveAttacker = FindPosition(shot.ServerTick, attackerId, out var shotAttacker);
		if (!haveTarget || !haveAttacker)
		{
			if (currentTick <= shot.ServerTick)
				return false;

			_debug($"{Name(attacker)} rejected because target history is missing for server tick {shot.ServerTick}.");
			Clear();

			return true;
		}

		if (shotTarget.Teleported || shotAttacker.Teleported)
		{
			_debug($"{Name(attacker)} rejected: teleport.");
			Clear();
			return true;
		}

		if (!AreOpponents(shotAttacker.Team, shotTarget.Team))
		{
			_debug($"{Name(attacker)} rejected: not an enemy.");
			Clear();
			return true;
		}

		float distance = shotTarget.Origin.Distance(shotAttacker.Eye);
		if (!float.IsFinite(distance) || distance < MinimumDistance)
		{
			_debug($"{Name(attacker)} rejected: distance {distance:F1} below {MinimumDistance:F0}.");
			Clear();

			return true;
		}

		bool suspicious = false;
		float largestSnap = 0, bestBefore = 0, bestAfter = 0;
		float largestMeasuredSnap = -1, measuredBefore = 0, measuredAfter = 0;
		int measuredMovements = 0;
		string measurementFailure = "no continuous adjacent command history was available";
		bool reusedSnap = false;
		var matchedRule = EvidenceType.Convergence;
		bool ruleMatched = false;

		int smoothBodyPoint = 0;
		float smoothShotError = 180.0f;
		for (int bp = 0; bp < AimMath.BodyPointCount; bp++)
		{
			var t = new Vector(shotTarget.Origin.X, shotTarget.Origin.Y, shotTarget.Origin.Z + AimMath.BodyHeight(bp));
			float e = AimMath.AimError(shotAttacker.Eye, shot.Angles, t);
			if (e < smoothShotError)
			{
				smoothShotError = e;
				smoothBodyPoint = bp;
			}
		}

		var smoothPoints = new List<SmoothPoint> { new(shot, smoothShotError) };

		AimCommand newer = shot;
		while (true)
		{
			var older = FindCommand(st, newer.CommandNumber - 1);
			if (older == null)
			{
				measurementFailure = $"the previous simulated command was missing (looked for cmd {newer.CommandNumber - 1} of {st.Commands.Count} stored)";
				break;
			}

			long serverGap = (long)newer.ServerTick - older.ServerTick;
			long clientGap = (long)newer.ClientTick - older.ClientTick;
			if (clientGap < 0 || clientGap > MaxClientTickGap || serverGap < 0 || serverGap > 1)
			{
				measurementFailure = $"the history was discontinuous (cmd {newer.CommandNumber}->{older.CommandNumber}, " +
					$"client {newer.ClientTick}->{older.ClientTick} gap {clientGap} outside 0..{MaxClientTickGap}, " +
					$"server {newer.ServerTick}->{older.ServerTick} gap {serverGap} outside 0..1)";
				break;
			}

			if ((long)shot.ServerTick - older.ServerTick > SnapWindowTicks)
			{
				measurementFailure = "the preceding command was outside the 0.5-second snap window";
				break;
			}

			if (!FindPosition(older.ServerTick, st.VictimId, out var olderTarget)
				|| !FindPosition(newer.ServerTick, st.VictimId, out var newerTarget)
				|| !FindPosition(older.ServerTick, attackerId, out var olderAttacker)
				|| !FindPosition(newer.ServerTick, attackerId, out var newerAttacker)
				|| olderTarget.Teleported || newerTarget.Teleported || olderAttacker.Teleported || newerAttacker.Teleported)
			{
				measurementFailure = "matching historical player positions were missing or interrupted by a teleport";
				break;
			}

			float snap = AimMath.AngularDistance(older.Angles, newer.Angles);
			float before = AimMath.NearestBodyAimError(olderAttacker.Eye, older.Angles, olderTarget.Origin);
			float after = AimMath.NearestBodyAimError(newerAttacker.Eye, newer.Angles, newerTarget.Origin);

			if (!float.IsFinite(snap) || !float.IsFinite(before) || !float.IsFinite(after))
			{
				measurementFailure = "an angle or target-error measurement was invalid";
				break;
			}

			var fixedPoint = new Vector(olderTarget.Origin.X, olderTarget.Origin.Y, olderTarget.Origin.Z + AimMath.BodyHeight(smoothBodyPoint));
			float smoothError = AimMath.AimError(olderAttacker.Eye, older.Angles, fixedPoint);
			if (!float.IsFinite(smoothError))
			{
				measurementFailure = "a fixed-body target-error measurement was invalid";
				break;
			}

			smoothPoints.Add(new(older, smoothError));
			measuredMovements++;
			if (snap > largestMeasuredSnap)
			{
				largestMeasuredSnap = snap;
				measuredBefore = before; measuredAfter = after;
			}

			bool converged = (snap > 10.0f && after < before * 0.2f) || (snap > 5.0f && after < before * 0.1f);
			bool fresh = !st.HasCountedIncident || newer.CommandNumber > st.LastCountedIncidentCommand;
			if (converged && fresh)
			{
				suspicious = true;
				matchedRule = EvidenceType.Convergence;
				ruleMatched = true;
				if (snap > largestSnap)
				{
					largestSnap = snap;
					bestBefore = before;
					bestAfter = after;
				}
			}
			else if (converged)
				reusedSnap = true;

			newer = older;
		}

		var previous = FindCommand(st, st.PendingShot - 1);
		var next = FindCommand(st, st.PendingShot + 1);
		if (!suspicious && next == null && (long)currentTick - shot.ServerTick <= 1)
			return false;

		if (previous != null && next != null
			&& shot.CommandNumber - previous.CommandNumber == 1 && next.CommandNumber - shot.CommandNumber == 1
			&& (long)shot.ClientTick - previous.ClientTick is >= 0 and <= MaxClientTickGap
			&& (long)next.ClientTick - shot.ClientTick is >= 0 and <= MaxClientTickGap
			&& (long)shot.ServerTick - previous.ServerTick is >= 0 and <= 1
			&& (long)next.ServerTick - shot.ServerTick is >= 0 and <= 1)
		{
			float surrounding = AimMath.AngularDistance(previous.Angles, next.Angles);
			float snap = AimMath.AngularDistance(previous.Angles, shot.Angles);
			bool fresh = !st.HasCountedIncident || shot.CommandNumber > st.LastCountedIncidentCommand;

			if (fresh && float.IsFinite(surrounding) && float.IsFinite(snap) && surrounding < 10.0f && snap > 0.5f && snap > surrounding * 5.0f)
			{
				if (!suspicious)
				{
					matchedRule = EvidenceType.SnapReturn;
					ruleMatched = true;
					largestSnap = snap;
				}

				suspicious = true;
			}
		}

		float smoothMovement = 0, smoothBefore = 0, smoothAfter = 0;
		if (!suspicious && smoothPoints.Count >= SmoothMinimumSteps + 1)
		{
			smoothPoints.Reverse();
			var movements = new List<float>(smoothPoints.Count - 1);

			for (int i = 1; i < smoothPoints.Count; i++)
				movements.Add(AimMath.AngularDistance(smoothPoints[i - 1].Command.Angles, smoothPoints[i].Command.Angles));

			int start = 0;
			for (int i = 1; i < movements.Count; i++)
				if (movements[i] > movements[start])
					start = i;

			float largest = movements[start];

			float path = 0;
			for (int i = start; i < movements.Count; i++)
				path += movements[i];

			smoothMovement = AimMath.AngularDistance(smoothPoints[start].Command.Angles, smoothPoints[^1].Command.Angles);
			smoothBefore = smoothPoints[start].Error;
			smoothAfter = smoothPoints[^1].Error;

			float efficiency = path > AimMath.Epsilon ? smoothMovement / path : 0.0f;
			float meaningfulMinimum = MathF.Max(SmoothMinimumStep, largest * SmoothRelativeStep);
			float previousMeaningful = float.PositiveInfinity;
			bool shrinking = true;
			int steps = 0;

			for (int i = start; i < movements.Count; i++)
			{
				if (movements[i] < meaningfulMinimum)
					continue;

				if (movements[i] >= previousMeaningful)
					shrinking = false;

				previousMeaningful = movements[i];
				steps++;
			}

			float improvement = smoothBefore > AimMath.Epsilon ? 1.0f - smoothAfter / smoothBefore : 0.0f;
			bool fresh = !st.HasCountedIncident || shot.CommandNumber > st.LastCountedIncidentCommand;
			if (fresh && MeetsSmoothThresholds(smoothMovement, improvement, smoothAfter, efficiency, steps, shrinking))
			{
				suspicious = true;
				matchedRule = EvidenceType.SmoothConvergence;
				ruleMatched = true;
				largestSnap = smoothMovement;
				bestBefore = smoothBefore;
				bestAfter = smoothAfter;
			}
			else
			{
				_debug($"{Name(attacker)} smooth curve rejected: movement {smoothMovement:F2}/{SmoothMinimumMovement:F2}, " +
					   $"error {smoothBefore:F2}->{smoothAfter:F2}/{SmoothMaximumFinalError:F2}, path {efficiency * 100:F1}%, steps {steps}/{SmoothMinimumSteps}, shrinking {shrinking}.");
			}
		}

		int incidentCommand = shot.CommandNumber;
		Clear();
		if (!suspicious || !ruleMatched)
		{
			if (reusedSnap)
				_debug($"{Name(attacker)} ignored a snap that already counted for an earlier damaging shot.");

			else if (measuredMovements == 0)
				_debug($"{Name(attacker)} damaging shot rejected because {measurementFailure}.");

			else
				_debug($"{Name(attacker)} damaging shot rejected after {measuredMovements} adjacent movements (stopped: {measurementFailure}): largest {largestMeasuredSnap:F2}°, target error {measuredBefore:F2} -> {measuredAfter:F2}.");

			return true;
		}

		st.LastCountedIncidentCommand = incidentCommand;
		st.HasCountedIncident = true;

		var now = DateTime.UtcNow;
		st.SnapEvidence.RemoveAll(i => now - i.Time >= EvidenceWindow);
		st.SmoothEvidence.RemoveAll(i => now - i.Time >= EvidenceWindow);

		var incidents = matchedRule == EvidenceType.SmoothConvergence ? st.SmoothEvidence : st.SnapEvidence;
		incidents.Add(new AimbotIncident(now, matchedRule, largestSnap, bestBefore, bestAfter));
		int threshold = matchedRule == EvidenceType.SmoothConvergence ? SmoothDetectionThreshold : SnapDetectionThreshold;

		_debug($"{Name(attacker)} counted {matchedRule} {largestSnap:F2}°, error {bestBefore:F2} -> {bestAfter:F2}, evidence {incidents.Count}/{threshold}.");

		if (incidents.Count >= threshold)
		{
			var lines = new List<string>();
			for (int i = 0; i < incidents.Count; i++)
			{
				var inc = incidents[i];
				lines.Add(inc.Type switch
				{
					EvidenceType.SnapReturn => $"{i + 1}. {inc.Movement:F2}° snap-return",
					EvidenceType.SmoothConvergence => $"{i + 1}. {inc.Movement:F2}° smooth move ({inc.Before:F2}°→{inc.After:F2}°)",
					_ => $"{i + 1}. {inc.Movement:F2}° sudden move ({inc.Before:F2}°→{inc.After:F2}°)",
				});
			}

			string latest = matchedRule switch
			{
				EvidenceType.SnapReturn => $"Latest damaging shot: aim jumped {largestSnap:F2}° and immediately returned. Evidence {incidents.Count}/{threshold} in 5 min.",
				EvidenceType.SmoothConvergence => $"Latest damaging shot: unusually clean {largestSnap:F2}° curve, enemy distance {bestBefore:F2}° → {bestAfter:F2}°. Evidence {incidents.Count}/{threshold} in 5 min.",
				_ => $"Latest damaging shot: aim moved {largestSnap:F2}° in one step, enemy distance {bestBefore:F2}° → {bestAfter:F2}°. Evidence {incidents.Count}/{threshold} in 5 min.",
			};

			StatDetections++;
			_announce(attacker, "AIMBOT", string.Join("\n", lines) + "\n" + latest);
			st.SnapEvidence.Clear();
			st.SmoothEvidence.Clear();
		}

		return true;
	}
}

using System;
using System.Collections.Generic;
using System.Linq;

namespace AegisAC.Modules;

public sealed record ShotRecord(int PlayerSlot, int CommandNumber, int ServerTick, int FireTick, string Weapon, int VictimSlot = -1);

public sealed class ShotCorrelator
{
	private const int ShotMatchTicks = 1;
	private const int ShotLifetimeTicks = 2;
	private const int MaxCommands = 32;
	private const int MaxShots = 8;

	private sealed class CommandRecord
	{
		public int CommandNumber { get; init; }
		public int ServerTick { get; set; } = -1;
		public bool Simulated { get; set; }
		public bool Consumed { get; set; }
	}

	private sealed class PlayerHistory
	{
		public readonly List<CommandRecord> Commands = [];
		public readonly List<ShotRecord> Shots = [];
	}

	private readonly Dictionary<int, PlayerHistory> _players = [];

	private PlayerHistory GetPlayer(int slot)
	{
		if (!_players.TryGetValue(slot, out var history))
		{
			history = new PlayerHistory();
			_players.Add(slot, history);
		}

		return history;
	}

	public void RecordCommand(int slot, int commandNumber)
	{
		if (slot <= 0 || commandNumber < 0)
			return;

		var history = GetPlayer(slot);

		if (history.Commands.Any(c => c.CommandNumber == commandNumber))
			return;

		history.Commands.Add(new CommandRecord
		{
			CommandNumber = commandNumber
		});

		if (history.Commands.Count > MaxCommands)
			history.Commands.RemoveAt(0);
	}

	public void MarkSimulated(int slot, int commandNumber, int serverTick)
	{
		if (!_players.TryGetValue(slot, out var history))
			return;

		var command = history.Commands.LastOrDefault(c => c.CommandNumber == commandNumber);

		if (command is null)
			return;

		command.ServerTick = serverTick;
		command.Simulated = true;
	}

	public ShotRecord? OnWeaponFire(int slot, string weapon, int currentTick)
	{
		if (slot <= 0 || !IsBallisticWeapon(weapon))
			return null;

		var history = GetPlayer(slot);

		var candidates = history.Commands
			.Where(c =>
				c.Simulated &&
				!c.Consumed &&
				currentTick - c.ServerTick is >= 0 and <= ShotMatchTicks)
			.ToArray();

		if (candidates.Length != 1)
		{
			foreach (var candidate in candidates)
				candidate.Consumed = true;

			return null;
		}

		var match = candidates[0];
		match.Consumed = true;

		var shot = new ShotRecord(
			slot,
			match.CommandNumber,
			match.ServerTick,
			currentTick,
			weapon);

		history.Shots.Add(shot);

		if (history.Shots.Count > MaxShots)
			history.Shots.RemoveAt(0);

		return shot;
	}

	public ShotRecord? OnPlayerHurt(int attackerSlot, int victimSlot, int currentTick)
	{
		if (attackerSlot <= 0 || victimSlot <= 0 || attackerSlot == victimSlot || !_players.TryGetValue(attackerSlot, out var history))
		{
			return null;
		}

		var candidates = history.Shots
			.Where(s =>
				s.VictimSlot == -1 &&
				currentTick - s.FireTick is >= 0 and <= ShotLifetimeTicks)
			.ToArray();

		if (candidates.Length != 1)
			return null;

		var shot = candidates[0];

		var matched = shot with { VictimSlot = victimSlot };
		history.Shots[history.Shots.IndexOf(shot)] = matched;

		return matched;
	}

	public void Prune(int currentTick)
	{
		foreach (var history in _players.Values)
		{
			history.Commands.RemoveAll(c => c.Simulated && currentTick - c.ServerTick > ShotLifetimeTicks);
			history.Shots.RemoveAll(s => currentTick - s.FireTick > ShotLifetimeTicks);
		}
	}

	public void ResetPlayer(int slot)
	{
		_players.Remove(slot);
	}

	public void Reset()
	{
		_players.Clear();
	}

	private static bool IsBallisticWeapon(string weapon)
	{
		weapon = weapon.StartsWith("weapon_", StringComparison.Ordinal) ? weapon[7..] : weapon;

		return weapon is
			"ak47" or "aug" or "awp" or "bizon" or "cz75a" or
			"deagle" or "elite" or "famas" or "fiveseven" or
			"g3sg1" or "galilar" or "glock" or "hkp2000" or
			"m249" or "m4a1" or "m4a1_silencer" or "mac10" or
			"mag7" or "mp5sd" or "mp7" or "mp9" or "negev" or
			"nova" or "p250" or "p90" or "revolver" or
			"sawedoff" or "scar20" or "sg556" or "ssg08" or
			"tec9" or "ump45" or "usp_silencer" or "xm1014";
	}
}

using System.Net.Http;
using System.Text;
using System.Text.Json;
using AegisAC.Configuration;

namespace AegisAC.Notifications;

/// <summary>
/// Sends asynchronous Discord webhook notifications using Components V2.
/// </summary>
public static class DiscordWebhookNotifier
{
	private const int ComponentsV2Flag = 1 << 15;

	private static readonly HttpClient HttpClient = new()
	{
		Timeout = TimeSpan.FromSeconds(5)
	};

	/// <summary>
	/// Sends a formatted Components V2 alert asynchronously.
	/// </summary>
	public static void SendAlert(
		string webhookUrl,
		string playerName,
		ulong steamId,
		string moduleName,
		string detectionReason,
		PunishmentType punishment,
		string evidence = "")
	{
		if (string.IsNullOrWhiteSpace(webhookUrl))
			return;

		_ = Task.Run(async () =>
		{
			try
			{
				int accentColor = punishment switch
				{
					PunishmentType.Ban => 0xE5485D,
					PunishmentType.Kick => 0xE69A45,
					_ => 0x8794A8
				};

				string actionLabel = punishment switch
				{
					PunishmentType.Ban =>
						"🔴 **BANNED**",

					PunishmentType.Kick =>
						"🟠 **KICKED**",

					_ =>
						"⚪ **LOGGED ONLY** — No Punishment"
				};

				string steamValue = steamId > 0
					? $"[`{steamId}`](https://steamcommunity.com/profiles/{steamId})"
					: "`N/A`";

				// Build the native Discord Components V2 layout.
				var components = new List<object>
				{
					Text(
						"### 🛡️ Aegis Anti-Cheat  `APP`\n" +
						"-# CS2 · Server-Sided Protection"
					),

					Separator(),

					Text(
						"## 🚨 CHEATER DETECTED\n" +
						$"Player **{EscapeMarkdown(playerName)}** " +
						"has been flagged by Aegis Anti-Cheat."
					),

					Separator(),

					Text(
						"### Player Information\n" +
						"**PLAYER**\n" +
						$"`{EscapeInline(playerName)}`\n\n" +
						"**STEAM ID**\n" +
						$"{steamValue}\n\n" +
						"**MODULE**\n" +
						$"`{EscapeInline(moduleName)}`"
					),

					Separator(),

					Text(
						"### Detection & Action\n" +
						"**DETECTION**\n" +
						$"`{EscapeInline(detectionReason)}`\n\n" +
						"**ACTION TAKEN**\n" +
						actionLabel
					)
				};

				if (!string.IsNullOrWhiteSpace(evidence))
				{
					// Keep evidence within a reasonable display length.
					string trimmedEvidence = evidence.Length > 1000
						? evidence[..1000] + "..."
						: evidence;

					// Prevent evidence from breaking the Markdown code block.
					trimmedEvidence = trimmedEvidence.Replace(
						"```", "'''"
					);

					components.Add(Separator());

					components.Add(
						Text(
							"### 📊 Incident Evidence\n" +
							"```text\n" +
							trimmedEvidence +
							"\n```"
						)
					);
				}

				components.Add(Separator());

				components.Add(
					Text(
						"-# AEGIS ANTI-CHEAT FOR CS2 · " +
						$"SERVER-SIDED PROTECTION\n" +
						$"-# {DateTimeOffset.UtcNow:yyyy-MM-dd HH:mm} UTC"
					)
				);

				var container = new
				{
					type = 17, // Container
					accent_color = accentColor,
					components = components.ToArray()
				};

				var payload = new
				{
					username = "Aegis Anti-Cheat",
					avatar_url =
						"https://raw.githubusercontent.com/ressiws/AegisAC/main/.github/assets/logo.jpg",

					flags = ComponentsV2Flag,

					components = new object[]
					{
						container
					},

					allowed_mentions = new
					{
						parse = Array.Empty<string>()
					}
				};

				string json = JsonSerializer.Serialize(payload);

				using var content = new StringContent(
					json,
					Encoding.UTF8,
					"application/json"
				);

				// Components V2 webhooks require with_components=true.
				string url = AddComponentsQueryParameter(webhookUrl);

				using var response = await HttpClient.PostAsync(
					url,
					content
				).ConfigureAwait(false);

				if (!response.IsSuccessStatusCode && Utils.DebugMode)
				{
					string responseBody =
						await response.Content.ReadAsStringAsync()
							.ConfigureAwait(false);

					Utils.ConsoleLog(
						$"[DiscordWebhook] Failed: HTTP " +
						$"{(int)response.StatusCode} " +
						$"{response.ReasonPhrase}. {responseBody}"
					);
				}
			}
			catch (Exception ex)
			{
				if (Utils.DebugMode)
				{
					Utils.ConsoleLog(
						$"[DiscordWebhook] Error sending notification: " +
						ex.Message
					);
				}
			}
		});
	}

	private static object Text(string content)
	{
		return new
		{
			type = 10, // Text Display
			content
		};
	}

	private static object Separator()
	{
		return new
		{
			type = 14, // Separator
			divider = true,
			spacing = 1
		};
	}

	private static string AddComponentsQueryParameter(string url)
	{
		var builder = new UriBuilder(url);
		var query = builder.Query.TrimStart('?');

		// Avoid adding the parameter twice.
		bool alreadyPresent = query
			.Split('&', StringSplitOptions.RemoveEmptyEntries)
			.Any(parameter =>
				parameter.Split('=', 2)[0]
					.Equals(
						"with_components",
						StringComparison.OrdinalIgnoreCase
					)
			);

		if (!alreadyPresent)
		{
			builder.Query = string.IsNullOrEmpty(query)
				? "with_components=true"
				: $"{query}&with_components=true";
		}

		return builder.Uri.ToString();
	}

	private static string EscapeInline(string value)
	{
		return value
			.Replace("\\", "\\\\")
			.Replace("`", "\\`")
			.Replace("\r", " ")
			.Replace("\n", " ");
	}

	private static string EscapeMarkdown(string value)
	{
		return value
			.Replace("\\", "\\\\")
			.Replace("*", "\\*")
			.Replace("_", "\\_")
			.Replace("~", "\\~")
			.Replace("`", "\\`")
			.Replace("@", "@\u200B");
	}

using SwiftlyS2.Shared;
using SwiftlyS2.Shared.Players;
using AegisAC.Configuration;

namespace AegisAC.Punishment;

/// <summary>
/// Manages player punishments (kick, ban, none) triggered by detection modules.
/// </summary>
public sealed class PunishmentManager
{
	private readonly ISwiftlyCore _core;
	private readonly AegisConfig _config;

	public PunishmentManager(ISwiftlyCore core, AegisConfig config)
	{
		_core = core;
		_config = config;
	}

	/// <summary>
	/// Applies punishment to a detected player based on the configured punishment type.
	/// Guarantees execution on the server game thread.
	/// </summary>
	public void Punish(IPlayer player, PunishmentType punishment, string moduleName, string detectionReason)
	{
		if (punishment == PunishmentType.None || !player.IsValid)
			return;

		if (!_core.IsGameThread)
		{
			_core.Scheduler.NextTick(() => Punish(player, punishment, moduleName, detectionReason));
			return;
		}

		string name = player.Controller?.PlayerName ?? $"#{player.PlayerID}";
		string reason = $"{moduleName}: {detectionReason}";

		switch (punishment)
		{
			case PunishmentType.Kick:
				ExecuteKick(player, name, reason);
				break;

			case PunishmentType.Ban:
				ExecuteBan(player, name, reason);
				break;
		}
	}

	private void ExecuteKick(IPlayer player, string name, string reason)
	{
		if (!string.IsNullOrWhiteSpace(_config.KickCommand))
		{
			string cmd = FormatCommand(_config.KickCommand, player, name, reason);
			_core.Engine.ExecuteCommand(cmd);
		}
		else
		{
			player.Kick($"[AegisAC] {reason}", default);
		}

		Utils.Log($" \x04[AegisAC]\x01 Punished \x07{name}\x01 (Action: \x0FKICK\x01, Reason: {reason})");
	}

	private void ExecuteBan(IPlayer player, string name, string reason)
	{
		if (!string.IsNullOrWhiteSpace(_config.BanCommand))
		{
			string cmd = FormatCommand(_config.BanCommand, player, name, reason);
			_core.Engine.ExecuteCommand(cmd);
		}
		else
		{
			_core.Engine.ExecuteCommand($"banid 0 {player.SteamID}");
			_core.Engine.ExecuteCommand("writeid");
			player.Kick($"[AegisAC] {reason}", default);
		}

		Utils.Log($" \x04[AegisAC]\x01 Punished \x07{name}\x01 (Action: \x0FBAN\x01, Reason: {reason})");
	}

	private static string FormatCommand(string template, IPlayer player, string name, string reason)
	{
		return template
			.Replace("{userid}", player.PlayerID.ToString())
			.Replace("{steamid}", player.SteamID.ToString())
			.Replace("{name}", name)
			.Replace("{reason}", reason);
	}
}

	/// <summary>Server console diagnostic log (never broadcast to player chat).</summary>
	public static void ConsoleLog(string message)
	{
		WriteConsole($"{{red}} @AegisAC {{grey}}~ {{default}} {message}");
	}

	private static void WriteConsole(string message)
	{
		lock (ConsoleLock)
		{
			ConsoleColor originalColor = Console.ForegroundColor;

			try
			{
				int position = 0;

				while (position < message.Length)
				{
					if (TryReadColor(message, position, out string color, out int end))
					{
						if (Colors.TryGetValue(color, out ColorStyle? style))
						{
							Console.ForegroundColor = style.Console;
							position = end;
							continue;
						}
					}

					int nextTag = message.IndexOf('{', position);
					if (nextTag < 0)
						nextTag = message.Length;

					Console.Write(message.AsSpan(position, nextTag - position));
					position = nextTag;
				}

				Console.WriteLine();

				_logger?.LogInformation("{Message}", StripColors(message));
			}
			finally
			{
				Console.ForegroundColor = originalColor;
			}
		}
	}

	private static string StripColors(string message)
	{
		var result = new System.Text.StringBuilder(message.Length);
		int position = 0;

		while (position < message.Length)
		{
			if (TryReadColor(message, position, out string color, out int end)
				&& Colors.ContainsKey(color))
			{
				position = end;
				continue;
			}

			result.Append(message[position]);
			position++;
		}

		return result.ToString();
	}

	private static string ToChatColors(string message)
	{
		var result = new System.Text.StringBuilder(message.Length);
		int position = 0;

		while (position < message.Length)
		{
			if (TryReadColor(message, position, out string color, out int end)
				&& Colors.TryGetValue(color, out ColorStyle? style))
			{
				result.Append('[');
				result.Append(style.Chat);
				result.Append(']');
				position = end;
				continue;
			}

			result.Append(message[position]);
			position++;
		}

		return result.ToString();
	}

	private static bool TryReadColor(
		string message,
		int position,
		out string color,
		out int end)
	{
		color = string.Empty;
		end = position;

		if (message[position] != '{')
			return false;

		int closingBrace = message.IndexOf('}', position + 1);

		if (closingBrace < 0)
			return false;

		string candidate = message[(position + 1)..closingBrace];

		if (!Colors.ContainsKey(candidate))
			return false;

		color = candidate;
		end = closingBrace + 1;
		return true;
	}
