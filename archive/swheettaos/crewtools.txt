`CHANGELOG.md`:

```md
# Changelog

Each release's section is its notes on the GitHub releases page (`tools/release.sh` tags it; GitHub publishes it).

## 1.2.2

- **Updates itself** through a mod that updates plugins: Crew Tools answers `UpdateFeed()` with its GitHub releases, so
  such a mod can offer the newest version and install it (in place, without a restart, when it runs hot).
- The HTTP requests answer in the normal BepInEx build too (its plugin class passes them on); before, only a hot copy
  answered them.

## 1.2.1

- The HTTP requests describe themselves (a public `HttpHelp` method lists them), so a host can show them.
- First release from GitHub, with the source.

## 1.2.0

- **For tools:** Crew Tools answers HTTP requests under `/crew/` when a mod that serves HTTP passes them on to plugins
  (it calls a public `HandleHttp` method; without such a mod nothing calls it). Read the players (switches, trust,
  passes, spending), who is in the game now, the catches and held money, and the settings; change a player, kick, ban
  or unban, change a setting, or start the cleanup. Each change does exactly what the CREW TOOLS window's button does.

## 1.1.0

- Nothing changes for you or your crew. Under the hood, Crew Tools now starts and stops as one piece and hands what is
  in flight (each crew-mate's spending in the last 30 minutes, building money held for its building, a ban reclaim in
  progress, cheating popups not answered yet) to its next start. So a mod loader that reloads plugins while the game
  runs can reload Crew Tools in place, without a game restart and without resetting anyone's spending cap.

## 1.0.2

- A better money check, and the cheat watch without the movement hook.

## 1.0.1

- No ban for building money without a building; Unban; a crash trace.

## 1.0.0

- The first public release: Crew Permissions built in, a tabbed window, the cheat watch.

```

# Crew Tools

**Host tools for Moon Sweepers crew games:** what each crew-mate may do, where and how much, cheat catching, and the
host chores. Only the host needs it; crew-mates install nothing. A BepInEx 6 (IL2CPP) plugin.

## On its own, or better with LunarLink

**Crew Tools runs on its own.** It's a normal BepInEx plugin: install it in `BepInEx/plugins/` and everything works.
Nothing else is needed.

**With [LunarLink](https://swheettaos.github.io/lunarlink/) it's hot-loadable and updates itself, in place, while the game runs.** LunarLink is a free
BepInEx plugin ([GitHub](https://github.com/swheettaos/lunarlink)) that loads plugins from `BepInEx/hot/` and reloads them without a restart. Crew Tools is
built for it:

| | On its own | With LunarLink |
|---|---|---|
| **Updating** | Download the new zip, close the game, unzip, start again | F9 → UPDATES → **Update**: downloaded from this repo's releases, checked against GitHub's SHA-256 and reloaded in place, **no restart** |
| **Your crew during an update** | Everyone leaves while you restart | Nobody notices: spending in the last 30 minutes, building money held, a ban reclaim in progress and unanswered cheating popups carry over to the new version |
| **Turning it off** | Remove the DLL and restart | F9 → HOT PLUGINS → **Disable**: unloaded from memory at once; **Enable** brings it back |
| **Scripts and tools** | - | HTTP requests under `/crew/` (players, catches, settings, kick, ban, cleanup), listed in LunarLink's `/help` |
| **An AI assistant** | - | Through LunarLink's [MCP server](https://github.com/swheettaos/lunarlink/wiki/MCP), Crew Tools' requests become tools: ask Claude "who's online, and has anyone been caught?" |
| **Seeing its state** | `BepInEx/LogOutput.log` | F9 shows it running, its build time, and any error |

**To run it with LunarLink:** install [LunarLink](https://github.com/swheettaos/lunarlink/releases/latest), then put `CrewTools.dll` in **`BepInEx/hot/`**
instead of `BepInEx/plugins/CrewTools/` (not in both: LunarLink refuses to load a second copy), start the game and turn
it on in F9 → HOT PLUGINS. From then on, F9 → UPDATES keeps it up to date: press **Check for updates**, or tick
**Check for updates at game start**, and the tab shows an orange count when a new Crew Tools is out.

More about LunarLink: [its site](https://swheettaos.github.io/lunarlink/) · [wiki](https://github.com/swheettaos/lunarlink/wiki) · [how updates work](https://github.com/swheettaos/lunarlink/wiki/Updates) ·
[hot plugins](https://github.com/swheettaos/lunarlink/wiki/Hot-Plugins).

## Install

Needs **BepInEx 6 (IL2CPP)**, as the game's other mods use.

1. Download `CrewTools-<version>.zip` from the [latest release](https://github.com/swheettaos/crewtools/releases/latest).
2. Close the game and unzip it into the game folder, so you get `Moon Sweepers/BepInEx/plugins/CrewTools/CrewTools.dll`.
3. **Remove** the separate `CrewPermissions.dll` from `BepInEx/plugins` if you have it: Crew Tools includes it.
4. Start the game. The log says "Crew Tools 1.2.2 loaded: 30 game hooks in place".

**Coming from Crew Permissions** (or an earlier Crew Tools test build): nothing to do; the first start converts
everything and loses nothing.

- **Players:** whichever of `CrewPermissions.players.txt` (switches) and the old `CrewTools.players.txt` (names, trust,
  passes, defaults) you have, one, both or neither, is read into the new one-line-per-player `CrewTools.players.txt`.
  The old `CrewTools.players.txt` is kept as `CrewTools.players.old.txt`; `CrewPermissions.players.txt` is left as it
  was (no longer read). Players already in either file keep the switches they had; only players never seen before
  start with the new-player defaults.
- **Settings:** Crew Permissions' `moonsweepers.crewpermissions.cfg` and an earlier build's `[Cheat watch]` section are
  read into `[AntiCheat]`. The old files and lines are left in place; nothing reads them after that.
- **Who built what** (`CrewTools.owners.txt`) and the logs are unchanged.

The log says "players: N moved into CrewTools.players.txt from ..." (naming the files it found), or on a fresh
install "players: new CrewTools.players.txt (no earlier player files)".

## What it does (host only)

| | |
|---|---|
| **Permissions** | Per player: Build, Demolish, Sell, Shop, Capsules, each on or off. A refused sale gives the capsule back. Capsules moved by a tool, brush or vacuum are always allowed. |
| **Protected bases** | Restrict only: nobody is banned for it. Crew-mates within N metres of a base's station can look but can't build, demolish, sell, shop or handle capsules. They can use their vehicles there (drive, park, recall), but not buy or upgrade one. The first time they walk into a protected base after joining they're told once in crew chat: "@name: this area (South base) is restricted." Refused actions after that are refused quietly, with no chat spam. You (the host) are never restricted. Map teleports still work. Give a crew-mate a pass for chosen bases with Passes in their player row. |
| **Vehicles** | Crew-mates can always drive, park and recall vehicles they own, also with Shop off, inside a protected base, or over the spending cap. Only buying or upgrading a vehicle needs Shop (and no zone, and room under the cap). |
| **Spending cap** | Each crew-mate may spend at most $X in any 30 minutes (shop, buildings, robots, vehicles), priced before the purchase goes through. Trusted players have no cap. |
| **New players** | A player seen for the first time starts with the new-player switches you choose on the Rules tab (default: build, sell, shop, capsules on; demolish off). Everyone already known keeps their own switches. On the Players tab a switch that differs from the default is marked * (e.g. "off*"); Manage > Reset to defaults sets a player back to them. |
| **Money anti-cheat** | A crew-mate's game sends the money for a build or a delete separately from the build itself. Crew Tools prices what each building message builds and removes (belts at the game's own price for their length, and pieces already gone from what it remembers of the last 5 minutes) and pays building money only when it matches. Money that matches nothing is never paid. A cost (money taken) is flagged in the cheats log, never a ban. A refund with a build or delete from them within 10 s is flagged, and a ban once these pass $20,000 in 10 minutes. A refund with no build or delete at all is cheating. Also cheating: money no build could cost, trick money over the limit, impossible kilograms. A catch: refused, every switch off, then Ban / Kick / Restrict, at once or ask you. |
| **Welcome** | A crew-chat greeting when someone joins, then one line per protected base. |
| **Server name** | Your server name, saved and put on every game you host. |
| **Cleanup** | Every N minutes, loose capsules and bricks lying around are removed, with a crew-chat warning a minute before. Spread over frames so the game doesn't hitch. |
| **Ban reclaim** | Ban someone and everything they built (buildings, robots, belts) and their vehicles is removed with the game's normal refund paid back to the team, a piece at a time, no freeze. |
| **Leaving players** | Their vehicles go back to the garage, refunded (vehicle price), freeing the slot. Upgrades are not refunded on leaving: a crew-mate's own game keeps them and puts them back on the next vehicle they buy. On a ban the refund includes every upgrade level bought, at the game's prices. |

## Cheat watch

Catches what cheat trainers (WeMod and the like) do to *your* world: the host can't see the program on someone else's
PC, only what their game sends. A catch is treated like a money cheat: switches off, and your Ban / Kick / Restrict and
At once / Ask me settings apply.

| Check | Catches |
|---|---|
| Speed | Faster than 30 m/s sideways on foot, or 60 m/s in a vehicle, for 2+ seconds |
| Flying | Off the ground (not in a vehicle, not a passenger, not climbing) for 45+ seconds |
| Reach | Building or removing more than 60 m from where they stand (the game's reach is ~30 m) |
| Deposits | Selling or unloading more than 3x the dust their tool or vehicle holds, or selling dust more than 150 m from every station |
| Teleports | A jump of 150 m+ that lands more than 200 m from every station (the game's map only teleports you to a station), and a jump with no teleport payment within 15 s (map teleports cost money and the host takes it). The payment check starts once one paid crew teleport has been seen in the session, so it can't catch honest players if payments ever don't reach the host |

Fast Machines and Freeze Time of Day only change the cheater's own game.

It never counts: anything a permission or a protected base refused, money or deposits within 10 s of a refusal, the
host, or the first 20 s after a player appears. A jump that lands at a station is a map teleport (allowed). The
Anti-cheat on/off switch covers it too. Every check and limit is a setting (`[AntiCheat]`). The limits are generous so
only blatant cheating trips them; they haven't been tried against a real cheater yet.

## In game

Pause menu → **CREW TOOLS** (while on the Moon). One window, five tabs:

| Tab | |
|---|---|
| **Players** | "In game" / "History" (everyone who has played here). One row per player: their five switches Build / Demolish / Sell / Shop / Capsules (on = orange; click to switch), Passes (which protected bases they may work in) and Manage (reset spending, trust, reset to defaults, restrict, kick, ban, or Unban for a banned player, also from History; remove from the list). Nine rows; scroll with the mouse wheel or Up / Down. |
| **Bases** | Each base: PROTECTED / open, and its distance (- / +). |
| **Rules** | Spending limit per 30 minutes; cleanup on/off and how often; ban reclaim and cleanup speed (Slow / Fast); what new players start with. |
| **Anti-cheat** | On/off (money checks + cheat watch); a cheater gets Ban / Kick / Restrict; At once / Ask me; the trick-money limit; cheat watch on/off. |
| **Server** | The server name (Save); the welcome message on/off and its text (Save). |

Every switch shows its state: orange = on, grey = off. In a choice, the lit button is the one in use.

### When someone is caught

- **At once** (AutoBan on): a small notice in the top-right corner, "BANNED: name" and why, gone by itself after 8 s.
- **Ask me:** a card at the top: F7 bans, F8 lets it go (the keys work during play; its buttons work with the pause
  menu open).

## For tools

Crew Tools answers HTTP requests under `/crew/` when a mod that serves HTTP, such as [LunarLink](https://github.com/swheettaos/lunarlink), passes them on to plugins: its plugin class
has a public `string HandleHttp(string method, string path, NameValueCollection query, string body)` and lists the
requests in `string[] HttpHelp()`. Without such a mod nothing calls them. Read the players (switches, trust, passes,
spending), who is in the game now, the catches and held money, and the settings; change a player, kick, ban or unban,
change a setting, or start the cleanup. Each change does exactly what the CREW TOOLS window's button does. Every request with
what it's for, its parameters and an example answer, plus recipes (a moderation watcher, a crew overlay), is on the
wiki's [For Tools](https://github.com/swheettaos/crewtools/wiki/For-Tools) page.

**Updates:** Crew Tools answers `string UpdateFeed()` with `github:swheettaos/crewtools`, so
[LunarLink](https://github.com/swheettaos/lunarlink) (or any mod that updates plugins) can check its latest release here and install it (the zip, checked
against the SHA-256 GitHub publishes), in place when it runs hot.

It can also be reloaded in place by a mod loader that reloads plugins while the game runs, such as [LunarLink](https://github.com/swheettaos/lunarlink): `Tools` (`Plugin.cs`) starts
and stops as one piece and hands what is in flight (each crew-mate's spending in the last 30 minutes, building money
held for its building, a ban reclaim in progress, cheating popups not answered yet) to its next start.

## Notes

- Who built what is only known for pieces built while Crew Tools is installed.
- Crew chat goes to everyone; the game has no private messages.
- If one part of Crew Tools hits an error, only that part stops (the log says which); the rest keeps working.

## Uninstall

Delete `BepInEx/plugins/CrewTools`. Crew-mates are then unrestricted.

## Building

Needs the .NET 8 SDK and the game with BepInEx 6 (IL2CPP); the project references the game's own DLLs.

```bash
./build.sh              # build
./build.sh --install    # game closed: into BepInEx/plugins/CrewTools/
```

`MOON_GAME_DIR` sets the game's folder (default: Steam's on Linux). GitHub builds every push to `main` against a
private copy of the game's DLLs; on a fork that build is skipped, so build locally against your own game.

The [wiki](https://github.com/swheettaos/crewtools/wiki) is built from `wiki/` by `tools/wiki.py` on every push, and the
[docs site](https://swheettaos.github.io/crewtools/) is `docs/`.

**Releasing:** put the version in `src/CrewTools/Plugin.cs` (`Version = "x.y.z"`), add its section to `CHANGELOG.md`,
commit and push, then `tools/release.sh x.y.z`: it checks those, tags `vx.y.z` and pushes the tag, and GitHub builds
the zip and publishes the release with that changelog section.

`build.sh`:

```sh
#!/bin/bash
# Build Crew Tools.
#   ./build.sh               build it (src/CrewTools/bin/Release/net6.0/CrewTools.dll)
#   ./build.sh --install     game closed: into BepInEx/plugins/CrewTools/, as players install it
#   ./build.sh --hot         game running, with a mod loader that reloads plugins from BepInEx/hot/: copy it there and
#                            ask the loader on 127.0.0.1:8765 to reload it (POST /hot/reload?name=CrewTools)
# MOON_GAME_DIR is the game's folder (default: Steam's on Linux); the build references the game's own DLLs there.
set -e
cd "$(dirname "$0")"
GAME="${MOON_GAME_DIR:-$HOME/.local/share/Steam/steamapps/common/Moon Sweepers}"
DOTNET="${DOTNET:-$HOME/.dotnet/dotnet}"; [ -x "$DOTNET" ] || DOTNET=dotnet
OUT=src/CrewTools/bin/Release/net6.0
VERSION=$(grep -o 'Version = "[0-9.]*"' src/CrewTools/Plugin.cs | grep -o '[0-9.]*')
out=$("$DOTNET" build src/CrewTools -c Release "-p:GameDir=$GAME" 2>&1) || true
if ! echo "$out" | grep -q "Build succeeded" || echo "$out" | grep -q " error "; then
    echo "$out" | grep -E " error " | sed 's/ \[.*//' | sort -u; echo "build FAILED"; exit 1
fi
echo "built Crew Tools $VERSION"
case "$1" in
    --install)
        D="$GAME/BepInEx/plugins/CrewTools"; mkdir -p "$D"
        cp "$OUT/CrewTools.dll" "$D/CrewTools.dll.new" && mv -f "$D/CrewTools.dll.new" "$D/CrewTools.dll"
        echo "installed into $D (loads at the next game start)" ;;
    --hot)
        H="$GAME/BepInEx/hot"; mkdir -p "$H"
        for f in dll pdb; do cp "$OUT/CrewTools.$f" "$H/CrewTools.$f.new" && mv -f "$H/CrewTools.$f.new" "$H/CrewTools.$f"; done
        if curl -s -m 2 127.0.0.1:8765/status >/dev/null 2>&1; then curl -s -m 30 -X POST "127.0.0.1:8765/hot/reload?name=CrewTools"; echo
        else echo "copied into $H (no loader answering: it loads at the next start)"; fi ;;
esac

// Alerts: telling the host about a catch, one at a time.
//
//   already punished (AutoBan on)  a small notice in the top-right corner - "BANNED: name" and why - gone by itself
//                                  after 8 s. Nothing to click: during play the game holds the mouse, so a button
//                                  there couldn't be clicked (2026-11-10).
//   the host decides (AutoBan off)  a card at the top: BanKey (F7) bans, IgnoreKey (F8) lets it go; its BAN / IGNORE
//                                  buttons work when the mouse is free (pause menu open).
//
// From Crew Permissions by tylerun (nexusmods.com/moonsweepers/mods/71), rebuilt from the released DLL; redesigned for
// Crew Tools and drawn with Widgets like the CREW TOOLS window. Catches of the same player within 10 s add up (x2...).
using System;
using System.Collections.Generic;
using MoonCleaners;
using UnityEngine;
using UnityEngine.InputSystem;
using UnityEngine.UI;
using static CrewTools.Widgets;

namespace CrewTools;

internal static class Alerts
{
    sealed class Alert
    {
        public ulong Sender;
        public string Name;
        public string What;
        public int Count = 1;
        public float At;
        public bool Banned;         // already punished (AutoBan): nothing to decide
    }

    static readonly List<Alert> waiting = new();

    const float NoticeSeconds = 8f;

    static GameObject layer, notice, card;
    static GraphicRaycaster ray;
    static Text noticeTitle, noticeLine, title, line, keys;
    static bool failed;                                         // the card couldn't be built: stop trying
    static string banName, ignoreName; static Key banKey, ignoreKey;   // the key settings, parsed when they change

    // Tools.Stop: the popup goes; what's waiting is handed over (Handover)
    internal static void Stop() { Widgets.Destroy(layer); layer = null; failed = false; }

    internal static List<(ulong Sender, string Name, string What, int Count, float At, bool Banned)> Export()
    {
        var l = new List<(ulong, string, string, int, float, bool)>();
        foreach (var a in waiting) l.Add((a.Sender, a.Name, a.What, a.Count, a.At, a.Banned));
        return l;
    }
    internal static void Import(List<(ulong Sender, string Name, string What, int Count, float At, bool Banned)> l)
    {
        foreach (var a in l) waiting.Add(new Alert { Sender = a.Sender, Name = a.Name, What = a.What, Count = a.Count, At = a.At, Banned = a.Banned });
    }

    internal static void Raise(ulong sender, string what, bool decided)
    {
        float now = Time.unscaledTime;
        foreach (var a in waiting)
            if (a.Sender == sender && now - a.At < 10f)
            {
                a.Count++; a.What = what; a.At = now; a.Banned |= decided;
                return;
            }
        waiting.Add(new Alert { Sender = sender, Name = Players.Name(sender), What = what, At = now, Banned = decided });
    }

    internal static void Update()
    {
        try
        {
            if (waiting.Count == 0)
            {
                if (layer != null) { notice.SetActive(false); card.SetActive(false); }
                return;
            }
            if (layer == null && (failed || !Build())) return;
            var a = waiting[0];
            if (a.Banned && Time.unscaledTime - a.At > NoticeSeconds) { waiting.RemoveAt(0); return; }
            Show(a);
            if (a.Banned) return;                                  // a notice: nothing to answer
            Keys();
            Click(ray);
        }
        catch (Exception e)
        {
            Plugin.L.LogError("Cheating popup: " + e);
            failed = true;
            Widgets.Destroy(layer);
            layer = null;
        }
    }

    static void Show(Alert a)
    {
        string times = a.Count > 1 ? $"  <color=#FFB4A8>x{a.Count}</color>" : "";
        int more = waiting.Count - 1;
        string waitingNote = more > 0 ? $"     ({more} more)" : "";
        notice.SetActive(a.Banned); card.SetActive(!a.Banned);
        if (a.Banned)
        {
            noticeTitle.text = $"{(AntiCheat.Kicks ? "KICKED" : "BANNED")}: <b>{a.Name}</b>{times}";
            noticeLine.text = a.What + waitingNote;
            return;
        }
        title.text = $"CHEATING: <b>{a.Name}</b>{times}";
        line.text = $"{a.What}. Refused, and all their permissions are off.";
        keys.text = $"{AntiCheat.BanKey.Value}  ban them     {AntiCheat.IgnoreKey.Value}  let it go" + waitingNote;
    }

    static void Keys()
    {
        var kb = Keyboard.current;
        if (kb == null) return;
        try { if (MoonInput.Typing) return; } catch { }           // not while typing in chat
        if (Pressed(kb, AntiCheat.BanKey.Value, ref banName, ref banKey)) BanNow();
        else if (Pressed(kb, AntiCheat.IgnoreKey.Value, ref ignoreName, ref ignoreKey)) Close();
    }

    static bool Pressed(Keyboard kb, string setting, ref string name, ref Key key)
    {
        if (name != setting)
        {
            name = setting;
            if (!Enum.TryParse(name, ignoreCase: true, out key)) key = Key.None;
        }
        return key != Key.None && kb.get_Item(key).wasPressedThisFrame;
    }

    static void BanNow()
    {
        var a = waiting[0];
        waiting.RemoveAll(x => x.Sender == a.Sender);
        AntiCheat.Remove(a.Sender, "cheating, banned by the host: " + a.What, ban: true);
    }

    static void Close()                                    // IGNORE: the host lets it go
    {
        var a = waiting[0];
        waiting.RemoveAt(0);
        AntiCheat.Ignored(a.Sender, a.What);
    }

    // built on the first catch: the notice (560 x 84, top-right) and the card (760 x 150, top centre)
    static bool Build()
    {
        layer = Layer("Crew Tools Alerts", 5300, out ray);
        var bg = new Color(Ink.r, Ink.g, Ink.b, 0.92f);

        const float nw = 560, nh = 84;
        var n = Rect("Notice", layer.transform, new Vector2(nw, nh), new Vector2(960 - 20 - nw / 2, 540 - 20 - nh / 2), bg);
        notice = n.gameObject;
        Rect("Bar", n, new Vector2(8, nh), new Vector2(-nw / 2 + 4, 0), Red);
        noticeTitle = Label(n, "", new Vector2(10, 18), new Vector2(nw - 40, 30), 20, Red, TextAnchor.MiddleLeft);
        noticeLine = Label(n, "", new Vector2(10, -16), new Vector2(nw - 40, 40), 15, Cream, TextAnchor.UpperLeft);

        const float cw = 760, ch = 150, x = -cw / 2 + 24, textW = cw - 48;
        var c = Rect("Card", layer.transform, new Vector2(cw, ch), new Vector2(0, 540 - 30 - ch / 2), bg);
        card = c.gameObject;
        Rect("Bar", c, new Vector2(8, ch), new Vector2(-cw / 2 + 4, 0), Red);
        title = Label(c, "", new Vector2(x + textW / 2, 46), new Vector2(textW, 34), 24, Red, TextAnchor.MiddleLeft);
        line = Label(c, "", new Vector2(x + textW / 2, 6), new Vector2(textW, 44), 16, Cream, TextAnchor.UpperLeft);
        keys = Label(c, "", new Vector2(x + 220, -48), new Vector2(440, 30), 15, Soft, TextAnchor.MiddleLeft);
        Button(c, "BAN", new Vector2(cw / 2 - 24 - 55 - 120, -48), new Vector2(110, 32), BanNow, colour: Red);
        Button(c, "IGNORE", new Vector2(cw / 2 - 24 - 55, -48), new Vector2(110, 32), Close, colour: Grey);

        notice.SetActive(false); card.SetActive(false);
        return true;
    }
}

`src/CrewTools/AntiCheat.cs`:

```cs
// AntiCheat: everything that catches a cheating crew-mate, and what happens when one is caught.
//
//   Money   (from Crew Permissions by tylerun, nexusmods.com/moonsweepers/mods/71 - rebuilt from the released DLL and
//           tidied for Crew Tools): a crew-mate's game sends "building money" (a cost or a refund) separately from the
//           building. Each player has a ledger of what they really built or removed in the last two minutes (priced by
//           Guard); building money is paid only when the ledger covers it or it matches a catalog price, otherwise it
//           is held for its building (paid the moment it is covered). Crew Tools, after three false bans
//           (2026-11-09 and -10): what was built and removed is priced from the message itself (belts too) and pieces
//           already gone are priced from memory (Guard), and money that still matches nothing is judged by whether a
//           building message came with it. A real build or delete always sends one; a money cheat sends money alone.
//             cost (money taken)    not paid, flagged - never cheating: it gains a cheater nothing
//             refund, with a building message from them within MatchSeconds   not paid, flagged; cheating once these
//                                   add up past MaxUnmatchedRefunds in 10 minutes
//             refund, no building message from them within MatchSeconds either side   cheating
//           Money no build could be (MaxBuildMoney), trick money over its limit and impossible kilograms: cheating.
//   Watch   (Crew Tools): what cheat trainers (WeMod and the like) do to the host's world, from what the cheater's
//           game sends - the host can't see the program itself. WeMod's Moon Sweepers cheats, mapped to what reaches
//           the host: Super Speed / Vehicle Speed (speed), Fly Mode / Unlimited Jetpack (flying), Long Reach (reach),
//           Carry Capacity / Super Cleaning (deposits over capacity), Instant Deposit (selling from far away),
//           Teleport to Map Marker (a jump that doesn't land at a station, or isn't paid for). Money cheats are the
//           Money checks; Fast Machines and Freeze Time of Day only change the cheater's own game.
//   Caught  either kind: refused, every permission switched off, then Ban / Kick / Restrict at once, or the host is
//           asked (the Alerts popup). Logged to BepInEx/CrewPermissions.cheats.log (file name kept from the original).
//
// Never counted, so it doesn't fight the protected bases: anything a permission or a zone refused (a refused action
// never runs, so it is never looked at), money and deposits within 10 s of a refusal, the host, and the first 20 s
// after a player appears. Limits are generous on purpose - only blatant cheating trips them - and all are settings.

    static bool Off(ulong sender) => !Enabled.Value || sender == 0;
    static bool WatchOff => !Enabled.Value || !Watch.Value;
    static bool Sane(double x) => !double.IsNaN(x) && !double.IsInfinity(x);

    // what the money arriving now is for (set by Guard per action) and who caused it (held money paid later)
    internal static string Why;
    internal static ulong Cause;

    // every frame (Driver): held building money, and once a second unpaid teleports
    internal static void Update()
    {
        PayHeld();
        if (Time.unscaledTime >= nextLook) { nextLook = Time.unscaledTime + 0.5f; Look(); }
        if (Time.unscaledTime >= nextTick) { nextTick = Time.unscaledTime + 1f; UnpaidJumps(); }
    }
    static float nextTick, nextLook;

    // the cheat watch's eyes: each crew-mate's position and state, read from their player object twice a second (it
    // hooked the game's movement code until 1.0.2; the game froze or died as crew-mates joined with that hook in)
    static void Look()
    {
        if (WatchOff || !MoonSteamLobby.IsHost) return;
        var here = Crew.Now;
        // gone from the game: their last position is forgotten, so a rejoin (which puts them back where they were when
        // they left) starts a new track with its 20 s grace instead of reading as a jump from the old spot
        foreach (var id in new List<ulong>(tracks.Keys)) if (!here.ContainsKey(id)) { tracks.Remove(id); jumpedAt.Remove(id); }
        foreach (var r in Crew.Remotes())
            try { if (r != null) Moved(r, r.transform.position, r.Grounded, r.Mounted, r.Climbing); }
            catch { }
    }

    // ================================================================== money
    const float Window = 120f;          // seconds a building stays in the ledger
    const float MatchSeconds = 10f;     // building money and its building message arrive within this of each other

    // what one player built (Built: cost/refund the building was worth) and was paid (Paid), in the last Window seconds;
    // BuildSlots/RemoveSlots: one entry per structure built/removed, used up by catalog matches
    sealed class Ledger
    {
        public readonly List<(float At, double Spend, double Refund)> Built = new();
        public readonly List<(float At, double Spend, double Refund)> Paid = new();
        public readonly List<float> BuildSlots = new();
        public readonly List<float> RemoveSlots = new();
        public readonly List<float> Messages = new();                          // when each building message came
        public readonly List<(float At, double Dollars)> Unmatched = new();    // refunds not paid (with a message)

        public bool MessageNear(float t) => Messages.Exists(m => Math.Abs(m - t) <= MatchSeconds);

        public double Budget(bool spend) => Sum(Built, spend);
        public double Used(bool spend) => Sum(Paid, spend);

        static double Sum(List<(float At, double Spend, double Refund)> list, bool spend)
        {
            float now = Time.unscaledTime;
            list.RemoveAll(e => now - e.At > Window);
            double total = 0;
            foreach (var e in list) total += spend ? e.Spend : e.Refund;
            return total;
        }
    }

    // building money held until its building arrives
    sealed class Pending
    {
        public ulong Sender;
        public string Player;
        public Decimal Amount;
        public double Dollars;      // negative: a cost; positive: a refund
        public float At;
    }

    static readonly Dictionary<ulong, Ledger> ledgers = new();
    static readonly List<Pending> pending = new();
    static readonly HashSet<string> oddPlayers = new();                        // wallet names already logged once
    static List<double> catalog;                                               // every structure price, read once a minute
    static float catalogAt = -999f;

    // Handover: building money held for its building, and what each player built and was paid lately (the ledgers it's
    // checked against), go to the next copy. The cheat watch's movement tracks (seconds long) start again.
    internal sealed class Held { public ulong Sender { get; set; } public string Player { get; set; } public double Dollars { get; set; } public float At { get; set; } }
    internal sealed class LedgerState
    {
        public List<(float At, double Spend, double Refund)> Built { get; set; } = new();
        public List<(float At, double Spend, double Refund)> Paid { get; set; } = new();
        public List<float> BuildSlots { get; set; } = new();
        public List<float> RemoveSlots { get; set; } = new();
        public List<float> Messages { get; set; } = new();
        public List<(float At, double Dollars)> Unmatched { get; set; } = new();
    }
    internal static (List<Held> held, Dictionary<ulong, LedgerState> ledgers) Export()
    {
        var held = new List<Held>();
        foreach (var p in pending) held.Add(new Held { Sender = p.Sender, Player = p.Player, Dollars = p.Dollars, At = p.At });
        var led = new Dictionary<ulong, LedgerState>();
        foreach (var kv in ledgers)
            led[kv.Key] = new LedgerState { Built = new(kv.Value.Built), Paid = new(kv.Value.Paid), BuildSlots = new(kv.Value.BuildSlots),
                RemoveSlots = new(kv.Value.RemoveSlots), Messages = new(kv.Value.Messages), Unmatched = new(kv.Value.Unmatched) };
        return (held, led);
    }
    internal static void Import(List<Held> held, Dictionary<ulong, LedgerState> led)
    {
        foreach (var h in held) pending.Add(new Pending { Sender = h.Sender, Player = h.Player, Amount = new Decimal(h.Dollars), Dollars = h.Dollars, At = h.At });
        foreach (var kv in led)
        {
            var l = Of(kv.Key);
            l.Built.AddRange(kv.Value.Built); l.Paid.AddRange(kv.Value.Paid); l.BuildSlots.AddRange(kv.Value.BuildSlots);
            l.RemoveSlots.AddRange(kv.Value.RemoveSlots); l.Messages.AddRange(kv.Value.Messages); l.Unmatched.AddRange(kv.Value.Unmatched);
        }
    }

    static Ledger Of(ulong sender)
    {
        if (!ledgers.TryGetValue(sender, out var l)) ledgers[sender] = l = new Ledger();
        return l;
    }

    // Guard: this player's message built (spend) or removed (refund) this much, in so many structures
    internal static void Built(ulong sender, double spend, double refund, int added, int removed)
    {
        if (sender == 0) return;
        var l = Of(sender); float now = Time.unscaledTime;
        l.Messages.RemoveAll(t => now - t > Window); l.Messages.Add(now);
        if (spend > 0 || refund > 0) l.Built.Add((now, spend, refund));
        for (int i = 0; i < added; i++) l.BuildSlots.Add(now);
        for (int i = 0; i < removed; i++) l.RemoveSlots.Add(now);
    }

    static void Pay(ulong sender, double dollars) =>
        Of(sender).Paid.Add((Time.unscaledTime, dollars < 0 ? -dollars : 0, dollars > 0 ? dollars : 0));

    // is this much building money within what they built (or removed), less what they were already paid?
    static bool Covered(ulong sender, double dollars)
    {
        var l = Of(sender); bool spend = dollars < 0;
        return l.Used(spend) + Math.Abs(dollars) <= l.Budget(spend) + SlackDollars.Value;
    }

    // Guard: a crew-mate's game sends building money. Paid now (true), held (false, paid later by PayHeld), or a cheat.
    internal static bool BuildMoney(ulong sender, string player, Decimal amount)
    {
        if (Off(sender)) return true;
        // Crew Tools: an action refused in the last 10 s (permission off, protected base, spending cap) still sends its
        // money from the crew-mate's game, which already showed the cost or refund. Refuse it quietly: not paid, and not
        // called cheating (a refused demolish's $50 refund got an honest player banned, 2026-11-09).
        if (Guard.RecentlyRefused(sender))
        {
            Plugin.L.LogInfo($"{Players.Name(sender)}: building money right after a refused action - not paid, not counted as cheating");
            return false;
        }
        double dollars = Decimal.ToDouble(amount);
        if (!Sane(dollars) || Math.Abs(dollars) > MaxBuildMoney.Value)
        {
            Caught(sender, $"sent building money of {Money(dollars)}, more than any build could cost");
            return false;
        }
        if (Covered(sender, dollars) || CatalogMatch(sender, dollars)) { Pay(sender, dollars); Trace.Log($"money from {sender}: {Money(dollars)} paid"); return true; }
        Trace.Log($"money from {sender}: {Money(dollars)} held for its building");
        pending.Add(new Pending { Sender = sender, Player = player, Amount = amount, Dollars = dollars, At = Time.unscaledTime });
        return false;
    }

    // building money that matched nothing they built or removed: not paid; cheating or a flag (see the top)
    static void Unmatched(Pending p)
    {
        var l = Of(p.Sender);
        double worth = l.Budget(p.Dollars < 0);
        bool message = l.MessageNear(p.At);
        Trace.Log($"money from {p.Sender}: {Money(p.Dollars)} matched nothing (building message near it: {(message ? "yes" : "no")})");
        if (p.Dollars < 0)
        {
            Note(p.Sender, $"build cost of {Money(-p.Dollars)} with nothing built here (built {Money(worth)} worth) - not paid");
            return;
        }
        string what = $"a refund of {Money(p.Dollars)} with nothing removed here (removed {Money(worth)} worth)";
        if (!message) { Caught(p.Sender, $"sent {what} and no building or demolition at all"); return; }
        float now = Time.unscaledTime;
        l.Unmatched.RemoveAll(u => now - u.At > 600f); l.Unmatched.Add((now, p.Dollars));
        double total = 0; foreach (var u in l.Unmatched) total += u.Dollars;
        if (total > MaxUnmatchedRefunds.Value) { Caught(p.Sender, $"sent refunds of {Money(total)} in 10 minutes that matched nothing removed (latest: {what})"); return; }
        Note(p.Sender, $"{what} - not paid ({Money(total)} unmatched in 10 minutes)");
    }

    // pay held money as soon as its building has come; after MatchSeconds without one it isn't paid (Unmatched)
    static void PayHeld()
    {
        if (pending.Count == 0) return;
        float now = Time.unscaledTime;
        for (int i = 0; i < pending.Count; i++)
        {
            var p = pending[i];
            bool real = Covered(p.Sender, p.Dollars);
            if (!real && now - p.At < MatchSeconds) continue;               // still waiting for its building
            if (!real) real = CatalogMatch(p.Sender, p.Dollars);
            pending.RemoveAt(i--);
            if (!real) { Unmatched(p); continue; }
            Pay(p.Sender, p.Dollars);
            try
            {
                Why = $"building money from {Players.Name(p.Sender)} (held until its building came)";
                Cause = p.Sender;
                Crew.World()?.CrewBuildMoney(p.Player, p.Amount);
            }
            catch (Exception e) { Plugin.L.LogWarning("Applying held building money: " + e.Message); }
            finally { Why = null; Cause = 0; }
        }
    }

    // every structure price in the game (kinds 1-2048), re-read once a minute
    static List<double> Catalog()
    {
        if (catalog != null && Time.unscaledTime - catalogAt < 60f) return catalog;
        catalogAt = Time.unscaledTime;
        var prices = new SortedSet<double>();
        try
        {
            var w = Crew.World();
            if (w != null)
                for (int kind = 1; kind <= 2048; kind++)
                {
                    MoonDepotBuildDefinition def;
                    try { def = w.BuildDefinition(kind); } catch { continue; }
                    if (def != null && def.priceDollars > 0) prices.Add(def.priceDollars);
                }
        }
        catch (Exception e) { Plugin.L.LogWarning("Reading the build catalog: " + e.Message); }
        if (catalog == null) Plugin.L.LogInfo($"Build catalog: {prices.Count} prices.");
        return catalog = new List<double>(prices);
    }

    // Building money that isn't covered but is exactly one structure's price (or refund), while they have a recent
    // build (or removal) not yet matched: a building that arrived as something else. Uses up that build.
    static bool CatalogMatch(ulong sender, double dollars)
    {
        if (sender == 0) return false;
        var l = Of(sender); float now = Time.unscaledTime;
        bool spend = dollars < 0;
        var slots = spend ? l.BuildSlots : l.RemoveSlots;
        slots.RemoveAll(t => now - t > Window);
        if (slots.Count == 0) return false;
        double amount = Math.Abs(dollars);
        foreach (double price in Catalog())
        {
            double expected = spend ? price : Decimal.ToDouble(MoonWorld.Refund(new Decimal(price)));
            if (Math.Abs(expected - amount) > SlackDollars.Value) continue;
            slots.RemoveAt(0);
            l.Built.Add((now, spend ? amount : 0, spend ? 0 : amount));
            Plugin.L.LogInfo($"Building money from {Players.Name(sender)} of {Money(dollars)}: matches a catalog {(spend ? "price" : "refund")} (a building that arrived as something else).");
            return true;
        }
        return false;
    }

    // Guard: kilograms sold, loaded or unloaded: 0 to MaxKilograms
    internal static bool Kilograms(ulong sender, double kilograms, string what)
    {
        if (Off(sender)) return true;
        if (Sane(kilograms) && kilograms >= 0 && kilograms <= MaxKilograms.Value) return true;
        Caught(sender, $"sent {what} of {kilograms:0.#} kg");
        return false;
    }

    // Guard: money for a vehicle trick: 0 to MaxTrickMoney
    internal static bool TrickMoney(ulong sender, Decimal amount)
    {
        if (Off(sender)) return true;
        double dollars = Decimal.ToDouble(amount);
        if (!double.IsNaN(dollars) && dollars >= 0 && dollars <= MaxTrickMoney.Value) return true;
        Caught(sender, "sent trick money of " + Money(dollars));
        return false;
    }

    // Guard: the wallet a message names. Always allowed (the format isn't fully known); another crew-mate's wallet is
    // noted once, and anything else is logged once, to learn from.
    internal static bool OwnWallet(ulong sender, string player, string what)
    {
        if (Off(sender) || string.IsNullOrEmpty(player) || player == sender.ToString()) return true;
        if (ulong.TryParse(player, out var other) && IsCrew(other))
        {
            if (oddPlayers.Add(sender + ">" + player)) Note(sender, $"sent {what} naming {Players.Name(other)}'s wallet (allowed; logged to learn the format)");
            return true;
        }
        if (oddPlayers.Add(player)) Plugin.L.LogInfo($"Crew message from {Players.Name(sender)} names player \"{player}\" (allowed).");
        return true;
    }

    static bool IsCrew(ulong id)
    {
        try { return id == MoonSteamLobby.HostId || MoonSteamLobby.InSteamLobby(id); }
        catch { return false; }
    }

    // Guard: every wallet change, written to the money log with what it was for; money a crew-mate caused with no action
    // named for it is noted (not punished)
    internal static void MoneyChanged(double before, double after)
    {
        double change = after - before;
        if (Math.Abs(change) < 0.005) return;
        ulong who = Guard.Sender != 0 ? Guard.Sender : Cause;
        string name = who != 0 ? Players.Name(who) : "host";
        string why = Why ?? (who != 0 ? "NOTHING THAT PAYS" : "host's own game");
        string signed = (change > 0 ? "+" : "-") + Money(Math.Abs(change));
        Append("CrewPermissions.money.log", $"{signed,-15} -> {Money(after),-16} {name}: {why}");
        if (who != 0 && Why == null && Enabled.Value) Note(who, $"the money changed by {signed} with no action named for it (check CrewPermissions.money.log)");
    }

    // Guard: they left
    internal static void Forget(ulong sender)
    {
        ledgers.Remove(sender);
        pending.RemoveAll(p => p.Sender == sender);
        tracks.Remove(sender); jumpedAt.Remove(sender);
    }

    // ================================================================== watch: movement, from each crew-mate update
    sealed class Track { public Vector3 pos; public float t, seenAt, fastSince = -1, airSince = -1; public MoonRemotePlayer who; }
    static readonly Dictionary<ulong, Track> tracks = new();

    static void Moved(MoonRemotePlayer who, Vector3 position, bool grounded, bool mounted, bool climbing)
    {
        if (WatchOff || who == null) return;
        ulong id; try { id = who.SteamId; } catch { return; }
        if (id == 0 || !MoonSteamLobby.IsHost) return;
        float now = Time.unscaledTime;
        if (!tracks.TryGetValue(id, out var k) || now - k.t > 10f) { Trace.Log($"watch: tracking {id}"); tracks[id] = new Track { pos = position, t = now, seenAt = now, who = who }; return; }
        k.who = who;
        float dt = now - k.t; if (dt < 0.05f) return;
        float dist = Vector3.Distance(position, k.pos);
        var up = position.normalized; var d = position - k.pos; float side = (d - up * Vector3.Dot(d, up)).magnitude;   // sideways only
        k.pos = position; k.t = now;
        if (now - k.seenAt < 20f) return;                                   // just arrived: spawn and map teleports
        if (dist > 150f) { k.fastSince = -1; k.airSince = -1; Jumped(id, position, dist, now); return; }

        if (Speed.Value)
        {
            float v = side / dt, max = mounted ? VehicleSpeed.Value : FootSpeed.Value;
            if (v <= max) k.fastSince = -1;
            else if (k.fastSince < 0) k.fastSince = now;
            else if (now - k.fastSince >= 2f) { WatchCaught(id, $"moved at {v:0} m/s {(mounted ? "in a vehicle" : "on foot")} (most {max:0})"); k.fastSince = -1; }
        }
        if (Flying.Value)
        {
            bool passenger = false; try { passenger = who.PassengerView != null; } catch { }
            bool air = !grounded && !mounted && !climbing && !passenger;
            if (!air) k.airSince = -1;
            else if (k.airSince < 0) k.airSince = now;
            else if (now - k.airSince >= AirSeconds.Value) { WatchCaught(id, $"off the ground for {now - k.airSince:0} s (most {AirSeconds.Value:0})"); k.airSince = -1; }
        }
    }

    // where the cheat watch last saw them (5 s at most ago)
    static bool PositionOf(ulong id, out Vector3 p)
    {
        p = default;
        if (!tracks.TryGetValue(id, out var k) || Time.unscaledTime - k.t > 5f) return false;
        p = k.pos; return true;
    }

    static float NearestStation(Vector3 at)
    {
        var w = Crew.World(); float near = float.MaxValue;
        if (w != null) foreach (var s in w.stations) near = Math.Min(near, Vector3.Distance(at, s.transform.position));
        return near;
    }

    // ================================================================== watch: teleports
    // The map only teleports you to a station, and costs money the host takes (MoonWorld.TryPayTeleport). A jump of
    // 150 m+ that lands away from every station is a cheat at once; one that lands at a station must be paid for within
    // 15 s either side. The payment rule is only enforced once a paid crew teleport has been seen this session - proof
    // the payment reaches this game - so honest players can't be caught if it ever doesn't.
    static readonly Dictionary<ulong, float> paidAt = new(), jumpedAt = new(), jumpDist = new();
    static bool paymentsSeen;

    static void Jumped(ulong id, Vector3 to, float dist, float now)
    {
        if (!Teleport.Value) return;
        float near = NearestStation(to);
        if (near == float.MaxValue) return;                                  // no world
        if (near > LandMetres.Value) WatchCaught(id, $"jumped {dist:0} m to a spot {near:0} m from the nearest station (the map only teleports to stations)");
        else if (!PaidNear(id, now)) { jumpedAt[id] = now; jumpDist[id] = dist; }       // at a station: was it paid? (UnpaidJumps)
    }

    internal static void TeleportPaid(string player, bool paid)
    {
        if (!paid || string.IsNullOrEmpty(player)) return;
        var digits = new System.Text.StringBuilder(); foreach (char ch in player) if (char.IsDigit(ch)) digits.Append(ch);
        if (!ulong.TryParse(digits.ToString(), out var id) || id < 70000000000000000UL) id = Guard.Sender;    // "steam-7656..." or the sender
        if (id == 0) return;
        paidAt[id] = Time.unscaledTime; paymentsSeen = true; jumpedAt.Remove(id);
    }

    static bool PaidNear(ulong id, float t) => paidAt.TryGetValue(id, out var p) && Math.Abs(p - t) <= 15f;

    static void UnpaidJumps()
    {
        if (WatchOff || !Teleport.Value || !paymentsSeen || jumpedAt.Count == 0) return;
        float now = Time.unscaledTime;
        foreach (var id in new List<ulong>(jumpedAt.Keys))
        {
            float t = jumpedAt[id];
            if (PaidNear(id, t)) { jumpedAt.Remove(id); continue; }
            if (now - t > 15f) { jumpedAt.Remove(id); WatchCaught(id, $"jumped {jumpDist.GetValueOrDefault(id):0} m without paying for a teleport"); }
        }
    }

    // ================================================================== watch: reach and deposits
    // Owners: what a crew building message really built and removed (anything refused never got there)
    internal static void Structures(ulong id, List<Vector3> added, List<Vector3> removed)
    {
        if (WatchOff || !Reach.Value || id == 0 || !PositionOf(id, out var me) || Guard.RecentlyRefused(id)) return;
        float far = 0;
        foreach (var p in added) far = Math.Max(far, Vector3.Distance(p, me));
        foreach (var p in removed) far = Math.Max(far, Vector3.Distance(p, me));
        if (far > ReachMetres.Value) WatchCaught(id, $"built or removed {far:0} m from where they stood (most {ReachMetres.Value:0})");
    }

    // Guard.Sell and Hooks.GarageUnload, only once the action was allowed (a refused one is never looked at). Capacity is
    // checked for dust (sales and garage unloads); distance for any sale.
    internal static void CheckDeposit(double kg, bool atStation, bool dust)
    {
        if (WatchOff || !Deposit.Value) return;
        ulong id = Guard.Sender; if (id == 0 || Guard.RecentlyRefused(id)) return;
        if (!tracks.TryGetValue(id, out var k) || k.who == null) return;
        double cap = Capacity(k.who);
        if (dust && cap > 0 && kg > cap * DepositFactor.Value) { WatchCaught(id, $"{(atStation ? "sold" : "unloaded")} {kg:0} kg, carrying at most {cap:0} kg"); return; }
        if (!atStation) return;
        float near = NearestStation(k.pos);
        if (near != float.MaxValue && near > DepositMetres.Value) WatchCaught(id, $"sold dust {near:0} m from the nearest station (most {DepositMetres.Value:0})");
    }

    // their current dust capacity: the vehicle they're in, else the tool in their hands; 0 = unknown (not checked)
    static double Capacity(MoonRemotePlayer p)
    {
        try
        {
            var w = Crew.World();
            if (p.Mounted && p.Vehicle != null && w != null && !string.IsNullOrEmpty(p.Vehicle.Storage)) { double c = w.VehicleDustCapacity(p.Vehicle.Storage); if (c > 0) return c; }
            if (p.Tool != null && p.Tool.containerKg > 0) return p.Tool.containerKg;
        }
        catch { }
        return 0;
    }

    // a watch catch: one per player per 30 s (one cheat trips a check many times a second)
    static readonly Dictionary<ulong, float> watchCaughtAt = new();
    static void WatchCaught(ulong id, string what)
    {
        if (!Enabled.Value) return;
        float now = Time.unscaledTime;
        if (watchCaughtAt.TryGetValue(id, out var t) && now - t < 30f) return;
        watchCaughtAt[id] = now;
        try { Caught(id, "cheat watch: " + what); } catch (Exception e) { Plugin.L.LogWarning("cheat watch: " + e.Message); }
    }

    // ================================================================== caught

    // Refused, every permission off, then punished at once (AutoBan) or the host is asked (Alerts popup).
    internal static void Caught(ulong sender, string what)
    {
        if (sender == 0) return;
        string name = Players.Name(sender);
        Plugin.L.LogWarning($"Cheating: {name} ({sender}) {what}. Refused.");
        Write($"CHEATING  {name} ({sender}) {what}. Refused.");
        if (Players.RevokeAll(sender))
        {
            Plugin.L.LogWarning($"All permissions removed from {name} ({sender}).");
            Write($"PERMISSIONS REMOVED  {name} ({sender}): everything switched off after cheating.");
        }
        if (StillRemoved(sender)) return;                           // already banned or kicked
        bool decided = AutoBan.Value && Punish(sender, what);
        Alerts.Raise(sender, what, decided);
    }

    static bool StillRemoved(ulong sender)
    {
        try { return MoonSteamLobby.IsRemoved(sender); }
        catch { return false; }
    }

    internal static bool Kicks => (Punishment.Value ?? "").Trim().Equals("Kick", StringComparison.OrdinalIgnoreCase);

    // the Punishment setting: None (nothing more: the permissions are already off), Kick, or anything else bans
    static bool Punish(ulong sender, string what)
    {
        if ((Punishment.Value ?? "").Trim().Equals("None", StringComparison.OrdinalIgnoreCase)) return false;
        Remove(sender, "cheating: " + what, ban: !Kicks);
        return true;
    }

    // Alerts: the host chose Ignore
    internal static void Ignored(ulong sender, string what)
    {
        Plugin.L.LogInfo($"Host ignored: {Players.Name(sender)} {what}.");
        Write($"ignored by the host  {Players.Name(sender)} ({sender}) {what}.");
    }

    internal static void Remove(ulong sender, string why, bool ban)
    {
        string name = Players.Name(sender);
        try
        {
            if (ban) MoonSteamLobby.Ban(sender); else MoonSteamLobby.Kick(sender);
            string done = ban ? "BANNED" : "KICKED";
            Plugin.L.LogWarning($"{name} ({sender}) {done.ToLowerInvariant()}: {why}.");
            Write($"{done}  {name} ({sender}): {why}.");
        }
        catch (Exception e) { Plugin.L.LogError($"Couldn't remove {name}: {e.Message}"); }
    }

    // something odd, only noted (yellow): not punished
    static void Note(ulong sender, string what)
    {
        string name = sender != 0 ? Players.Name(sender) : "the host";
        Plugin.L.LogWarning($"Flag, {name} ({sender}): {what}.");
        Write($"flag  {name} ({sender}): {what}.");
    }

    // ================================================================== logs
    static void Write(string line) => Append("CrewPermissions.cheats.log", line);

    static void Append(string file, string line)
    {
        try { File.AppendAllText(Path.Combine(Paths.BepInExRootPath, file), $"{DateTime.Now:yyyy-MM-dd HH:mm:ss}  {line}{Environment.NewLine}"); }
        catch { }
    }

    static string Money(double dollars) => "$" + dollars.ToString("#,0.##", CultureInfo.InvariantCulture);
}

using System;
using System.Collections.Generic;
using MoonCleaners;
using UnityEngine;

namespace CrewTools;

// Cleanup: loose capsules every N minutes (Cleanup), and every removal spread over frames (Remover).
// Capsules and bricks lying on the ground or stuck in the air go; anything on a belt, carried or flying stays.
// Crew chat warns a minute before.
internal static class Cleanup
{
    static float next = -1f; static bool warned;
    internal static void Update()
    {
        if (!Plugin.CleanupOn.Value || Crew.World() == null) return;
        float now = Time.unscaledTime, every = Plugin.CleanupMinutes.Value * 60f;
        if (next > now + every) { next = now + every; warned = false; }                  // made shorter in the panel
        if (next < 0) { next = now + every; warned = false; return; }
        if (!warned && now >= next - 60f) { warned = true; if (MoonSteamLobby.InLobby) Chat.Say("Cleanup in 1 minute: loose capsules on the ground will be removed."); }
        if (now < next) return;
        next = now + every; warned = false;
        int n = Run();
        Plugin.L.LogInfo($"cleanup: {n} loose capsules removed");
        if (MoonSteamLobby.InLobby && n > 0) Chat.Say($"Cleanup: removing {n} loose capsules.");
    }
    // HTTP: the next cleanup in one minute (the usual warning in crew chat goes out now)
    internal static void Soon() { next = Time.unscaledTime + 60f; warned = false; }

    internal static int Run()
    {
        var w = Crew.World(); if (w == null) return 0;
        int n = 0;
        foreach (var kv in w.canisters)
        {
            int id = kv.Key;
            try { if (w.IsCanisterRiding(id) || w.IsCanisterCarried(id) || w.IsCanisterFlying(id)) continue; } catch { continue; }
            Remover.Capsule(id); n++;                               // removed a few a frame, not all at once
        }
        return n;
    }
}


// Remover: removals spread out so the game never hitches. Measured 2026-11-09: the game's RemoveStructureNow costs ~15 ms when the last removal was 0.25 s+ ago, but 100-130 ms
// when it comes straight after another (it finishes the previous one's background work on the spot) - removing a
// banned player's 100 pieces in one go would freeze the hosted game for ~12 s. So: one structure every 0.25 s, its
// refund paid as it goes; loose capsules 10 a frame (~2 ms each).
internal static class Remover
{
    static readonly Queue<int> structures = new(), capsules = new();
    static float nextAt; static double paid; static int done;
    internal static void Structure(int id) => structures.Enqueue(id);
    // Handover: a ban reclaim in progress carries on in the next copy
    internal static (int[] structures, int[] capsules, double paid, int done) Export() => (structures.ToArray(), capsules.ToArray(), paid, done);
    internal static void Import((int[] structures, int[] capsules, double paid, int done) s)
    {
        foreach (var i in s.structures) structures.Enqueue(i);
        foreach (var i in s.capsules) capsules.Enqueue(i);
        paid = s.paid; done = s.done;
    }
    internal static void Capsule(int id) => capsules.Enqueue(id);
    internal static void Update()
    {
        if (structures.Count == 0 && capsules.Count == 0) return;
        var w = Crew.World(); if (w == null) { structures.Clear(); capsules.Clear(); return; }
        for (int i = 0; i < (Plugin.FastRemoval.Value ? 20 : 10) && capsules.Count > 0; i++)        // ~2 ms each (measured)
        {
            int id = capsules.Dequeue();
            try
            {
                if (!w.canisters.ContainsKey(id) || w.IsCanisterRiding(id) || w.IsCanisterCarried(id) || w.IsCanisterFlying(id)) continue;
                w.RemoveCanister(id);
            }
            catch { }
        }
        if (structures.Count == 0 || Time.unscaledTime < nextAt) return;
        nextAt = Time.unscaledTime + (Plugin.FastRemoval.Value ? 0.1f : 0.25f);
        int s = structures.Dequeue();
        try
        {
            if (w.depots.ContainsKey(s))
            {
                double r = 0; try { r = Il2CppSystem.Decimal.ToDouble(w.StructureRefund(s)); } catch { }
                w.RemoveStructureNow(s); done++;
                if (r > 0) { Owners.Pay(w, r); paid += r; }
            }
        }
        catch (Exception e) { Plugin.L.LogWarning("remove " + s + ": " + e.Message); }
        if (structures.Count == 0) { Plugin.L.LogInfo($"reclaim finished: {done} structures removed, ${paid:0} refunded"); done = 0; paid = 0; }
    }
}

        get
        {

            lookedAt = Time.unscaledTime;
            var fresh = new Dictionary<ulong, (Vector3, string)>();      // a new one, so a caller mid-loop isn't disturbed

            foreach (var o in UnityEngine.Object.FindObjectsOfType(Il2CppType.Of<MoonRemotePlayer>()))

        }
    }

    internal static List<MoonRemotePlayer> Remotes() { _ = Now; return remotes; }

// Guard: the permission checks on every crew-mate message the host's game applies (called from Hooks).
//
// From Crew Permissions by tylerun (nexusmods.com/moonsweepers/mods/71), rebuilt from the released DLL and tidied for
// Crew Tools: names, comments and shared helpers are ours; what is checked and refused is theirs, except where marked.
//
// How it works: the game hands each crew message to MoonCrewSession.Handle*(sender, ...). Enter/Leave note who sent it
// (Sender) for the length of the call; the MoonWorld.Crew* methods it then calls are where each action is allowed,
// refused, or checked for cheating (AntiCheat). The host's own actions have Sender 0 and are never checked.
using System;
using System.Collections.Generic;
using Il2CppSystem.IO;
using MoonCleaners;
using UnityEngine;
using Decimal = Il2CppSystem.Decimal;

namespace CrewTools;

internal static class Guard
{
    // the crew-mate whose message is being applied (0: the host, or not in a crew message)
    internal static ulong Sender;
    // for the trace: from a sender's first message, every message for 30 s is logged going in and coming out - one that
    // goes in and never comes out is the call that died
    static readonly HashSet<ulong> seenSenders = new();
    static readonly Stack<string> doing = new();
    static float traceUntil;

    // ------------------------------------------------------------------ who sent the message
    // Each Handle* message sets Sender for its length, then puts the previous one back (messages can nest).

    internal static ulong Enter(ulong sender, string message)
    {
        if (sender != 0 && seenSenders.Add(sender)) traceUntil = Time.unscaledTime + 30f;
        bool tracing = Time.unscaledTime < traceUntil;
        if (doing.Count > 50) doing.Clear();                  // a message that threw never pops
        doing.Push(tracing ? message : null);
        if (tracing) Trace.Log($"-> {message} from {sender}");
        AntiCheat.Why = null;
        ulong previous = Sender;
        bool crewMate = MoonSteamLobby.IsHost && sender != 0 && sender != MoonSteamLobby.HostId;
        Sender = crewMate ? sender : 0;
        return previous;
    }

    internal static void Leave(ulong previous)
    {
        if (doing.Count > 0 && doing.Pop() is string message) Trace.Log($"<- {message} done");
        Sender = previous;
        AntiCheat.Why = null;
    }

    // ------------------------------------------------------------------ allowed or refused

    static readonly Dictionary<(ulong, Node), float> lastLogged = new();   // one "Refused" line per player and node per 10 s

    // Is the sender allowed this? Logs a refusal (once per 10 s per player and node). The host is always allowed, and so
    // is anyone if the check itself fails (a broken check must not lock players out).
    internal static bool Allow(Node node, string what)
    {
        if (Sender == 0) return true;
        AntiCheat.Why = what;
        try
        {
            var p = Players.Get(Sender);
            if (Players.Allowed(p, node)) return true;
            var key = (Sender, node);
            if (!lastLogged.TryGetValue(key, out var t) || Time.unscaledTime - t > 10f)
            {
                lastLogged[key] = Time.unscaledTime;
                Plugin.L.LogInfo($"Refused {p.Name}: {what} (needs {node.ToString().ToLowerInvariant()})");
            }
            return false;
        }
        catch (Exception e)
        {
            Plugin.L.LogWarning("Permission check failed (allowed): " + e.Message);
            return true;
        }
    }

    // always allowed; names the action for the money checks (AntiCheat.Why)
    internal static bool Pays(string what)
    {
        if (Sender != 0) AntiCheat.Why = what;
        return true;
    }

    // Crew Tools: a refused action's money still arrives - the crew-mate's game already showed the cost or refund - and
    // the money checks found no matching build and banned an honest player for "fake building costs" (a refused
    // demolish's $50 refund, 2026-11-09). So for 10 s after any refusal (switch off, protected base, spending cap) their
    // building money is refused quietly, and the cheat watch doesn't count their deposits or reach. A real cheat outside
    // that window is still caught.
    static readonly Dictionary<ulong, float> refusedAt = new();
    internal static void Refused(ulong id) => refusedAt[id] = Time.unscaledTime;
    internal static bool RecentlyRefused(ulong id) => refusedAt.TryGetValue(id, out var t) && Time.unscaledTime - t <= 10f;

    // ------------------------------------------------------------------ selling (a refused sale gives the capsule back)

    internal static bool Sell(string player, MoonCargo cargo, double kilograms, string what, bool dustDeposit, ref double paid)
    {
        if (AntiCheat.OwnWallet(Sender, player, what) && AntiCheat.Kilograms(Sender, kilograms, what))
        {
            if (Allow(Node.Sell, what))
            {
                AntiCheat.CheckDeposit(kilograms, atStation: true, dust: dustDeposit);   // capacity: dust deposits only
                return true;
            }
            Returns.GiveBack(Sender, cargo, kilograms);       // no Sell permission: not paid, and the capsule comes back
        }
        paid = 0;
        return false;
    }

    // ------------------------------------------------------------------ capsules
    // Without the Capsules permission a player can't pick up or put down capsules by hand. Capsules moved by a tool,
    // brush or vacuum are let through (that's cleaning, not taking).

    static readonly Dictionary<string, float> capsuleLogged = new();

    internal static bool Capsule(MoonWorld.CanisterOp op, string carrier)
    {
        if (Sender == 0) return true;
        var p = Players.Get(Sender);
        if (Players.Allowed(p, Node.Capsules)) return true;

        bool takeOrDrop = op == MoonWorld.CanisterOp.Taken || op == MoonWorld.CanisterOp.Released;
        bool byTool = carrier != null && (Has(carrier, "tool") || Has(carrier, "brush") || Has(carrier, "vacuum"));
        bool refuse = takeOrDrop && !byTool;

        string key = $"{Sender} {op} {carrier}";
        if (!capsuleLogged.TryGetValue(key, out var t) || Time.unscaledTime - t > 10f)
        {
            capsuleLogged[key] = Time.unscaledTime;
            Plugin.L.LogInfo($"Capsule {op} by {p.Name}, holder \"{carrier}\": {(refuse ? "refused (no capsules permission)" : "let through (not by hand)")}.");
        }
        if (!refuse) return true;
        Allow(Node.Capsules, "handling capsules by hand");
        return false;
    }

    static bool Has(string s, string part) => s.IndexOf(part, StringComparison.OrdinalIgnoreCase) >= 0;

    // ------------------------------------------------------------------ building and demolishing
    // A building message is four lists: structures built, structures removed, belts built, belts removed. If the player
    // may not build or may not demolish, the message is rewritten without that half. Either way, what is built is priced
    // (and what is removed, refunded) so AntiCheat can tell real building money from made-up money.

    static double addedPrice, removedRefund;
    static int addedCount, removedCount;

    // what this player built lately, at its refund: a removal of a piece that is already gone here (deleted twice, or
    // built and deleted while messages crossed) is still priced (2026-11-10: a press bought and deleted got
    // a "$0 demolished" ban). Kept 5 minutes.
    static readonly Dictionary<int, (float At, double Refund)> recentPieces = new(), recentBelts = new();
    const float Remember = 300f;

    internal static void FilterBuilding(MoonWorld world, ref BinaryReader r)
    {
        addedPrice = removedRefund = 0;
        addedCount = removedCount = 0;
        if (Sender == 0 || r == null) return;

        var p = Players.Get(Sender);
        bool build = Players.Allowed(p, Node.Build);
        bool demolish = Players.Allowed(p, Node.Demolish);
        long start = -1;
        try { var s = r.BaseStream; if (s != null && s.CanSeek) start = s.Position; } catch { }
        if (build && demolish && start < 0) return;          // allowed, and can't read ahead to price it: apply as sent

        try
        {
            var depots = ReadList(r, MoonWorld.ReadDepot);
            var removed = ReadIds(r);
            var belts = ReadList(r, MoonWorld.ReadBelt);
            var cut = ReadIds(r);

            if (!build && (depots.Count > 0 || belts.Count > 0)) Allow(Node.Build, "building");
            if (!demolish && (removed.Count > 0 || cut.Count > 0)) Allow(Node.Demolish, "demolishing");
            Price(world, build ? depots : null, demolish ? removed : null, build ? belts : null, demolish ? cut : null);

            if (build && demolish) { r.BaseStream.Position = start; return; }   // nothing to take out: rewind

            var m = new MemoryStream(); var w = new BinaryWriter(m);
            WriteList(w, build ? depots : null, d => MoonWorld.Write(w, d));
            WriteList(w, demolish ? removed : null, id => w.Write(id));
            WriteList(w, build ? belts : null, b => MoonWorld.Write(w, b));
            WriteList(w, demolish ? cut : null, id => w.Write(id));
            w.Flush(); m.Position = 0;
            r = new BinaryReader(m);
        }
        catch (Exception e)
        {
            Plugin.L.LogError("Filtering a crew building message failed (applied as sent): " + e.Message);
            try { if (start >= 0) r.BaseStream.Position = start; } catch { }
        }
    }

    // after the message: report what it built and removed (every building message counts, even an empty one: it is
    // the proof that money came with a real build or delete)
    internal static void BuildingDone(MoonWorld world)
    {
        if (Sender == 0) return;
        AntiCheat.Built(Sender, addedPrice, removedRefund, addedCount, removedCount);
    }

    // a bought vehicle counts as building, for the money checks
    internal static void VehicleBought(int vehicle)
    {
        if (Sender == 0) return;
        try
        {
            var offer = MoonWorld.GarageOfferFor(vehicle);
            if (offer == null) return;
            double price = Decimal.ToDouble(offer.price);
            AntiCheat.Built(Sender, price, 0, 0, 0);
            Plugin.L.LogInfo($"{Players.Name(Sender)} bought vehicle {vehicle} at the garage (${price:#,0}).");
        }
        catch (Exception e) { Plugin.L.LogWarning("Pricing a crew vehicle: " + e.Message); }
    }

    // a count, then that many items (null items are skipped, as the game does)
    static List<T> ReadList<T>(BinaryReader r, Func<BinaryReader, T> read) where T : class
    {
        var list = new List<T>();
        for (int i = 0, n = r.ReadInt32(); i < n; i++) { var x = read(r); if (x != null) list.Add(x); }
        return list;
    }

    static List<int> ReadIds(BinaryReader r)
    {
        var list = new List<int>();
        for (int i = 0, n = r.ReadInt32(); i < n; i++) list.Add(r.ReadInt32());
        return list;
    }

    // null writes an empty list (that half taken out)
    static void WriteList<T>(BinaryWriter w, List<T> list, Action<T> write)
    {
        w.Write(list?.Count ?? 0);
        if (list != null) foreach (var x in list) write(x);
    }

    // what this message builds (new structures at their price; new belts are priced in BuildingDone) and removes (refunds)
    static void Price(MoonWorld world, List<MoonDepotSnapshot> depots, List<int> removed, List<MoonConveyorSnapshot> belts, List<int> cut)
    {
        float now = Time.unscaledTime; int fromMemory = 0, unknown = 0, newBelts = 0;
        Forget(recentPieces, now); Forget(recentBelts, now);
        try
        {
            if (depots != null)
                foreach (var d in depots)
                {
                    if (world.depots.ContainsKey(d.id)) continue;               // already there: a move, not a build
                    var def = world.BuildDefinition(d.kind);
                    if (def != null) { addedPrice += def.priceDollars; recentPieces[d.id] = (now, Refund(def.priceDollars)); }
                    addedCount++;
                }
            if (removed != null)
                foreach (int id in removed)
                {
                    if (world.depots.ContainsKey(id)) removedRefund += Decimal.ToDouble(world.StructureRefund(id));
                    else if (recentPieces.TryGetValue(id, out var r)) { removedRefund += r.Refund; fromMemory++; }
                    else { unknown++; continue; }
                    removedCount++;
                }
            // a new belt at the game's own price for its length, from the message - also when it then fails here (its
            // cost still comes: two "$50 with nothing built" bans, 2026-11-09 and -10)
            if (belts != null)
                foreach (var b in belts)
                {
                    if (world.conveyors.ContainsKey(b.id)) continue;
                    try
                    {
                        double price = Decimal.ToDouble(MoonConveyorKit.Load().Price(world.ConveyorPath(b).Length));
                        addedPrice += price; recentBelts[b.id] = (now, Refund(price)); newBelts++;
                    }
                    catch (Exception e) { Plugin.L.LogWarning("Pricing a crew belt: " + e.Message); }
                }
            if (cut != null)
                foreach (int id in cut)
                {
                    if (world.conveyors.ContainsKey(id)) removedRefund += Decimal.ToDouble(world.ConveyorRefund(id));
                    else if (recentBelts.TryGetValue(id, out var r)) { removedRefund += r.Refund; fromMemory++; }
                    else unknown++;
                }
        }
        catch (Exception e) { Plugin.L.LogWarning("Pricing a crew building message: " + e.Message); }
        Trace.Log($"building from {Sender}: {addedCount} pieces + {newBelts} belts ${addedPrice:0.##}; " +
                  $"removed {removed?.Count ?? 0} pieces + {cut?.Count ?? 0} belts, refund ${removedRefund:0.##}" +
                  (fromMemory > 0 ? $" ({fromMemory} already gone, priced from memory)" : "") + (unknown > 0 ? $" ({unknown} unknown here)" : ""));
    }

    static double Refund(double price) => Decimal.ToDouble(MoonWorld.Refund(new Decimal(price)));
    static void Forget(Dictionary<int, (float At, double Refund)> d, float now)
    {
        if (d.Count == 0) return;
        foreach (var k in new List<int>(d.Keys)) if (now - d[k].At > Remember) d.Remove(k);
    }
}

using System;
using System.Collections.Generic;
using System.Text.Json;

namespace CrewTools;

// What Tools.Stop() hands the next copy of Crew Tools when it is reloaded in place (and Tools.Start(state) takes back):
// spending in the last 30 minutes (Spending), building money held for its building and the money ledgers (AntiCheat),
// a ban reclaim's removal queue (Remover) and cheating popups not answered yet (Alerts). Everything else is either in
// the players and owners files already, or lasts only seconds.
internal static class Handover
{
    sealed class State
    {
        public Dictionary<ulong, List<(float t, double d)>> Spent { get; set; }
        public List<AntiCheat.Held> Held { get; set; }
        public Dictionary<ulong, AntiCheat.LedgerState> Ledgers { get; set; }
        public int[] RemoveStructures { get; set; }
        public int[] RemoveCapsules { get; set; }
        public double RemovePaid { get; set; }
        public int RemoveDone { get; set; }
        public List<(ulong Sender, string Name, string What, int Count, float At, bool Banned)> Alerts { get; set; }
    }

    static readonly JsonSerializerOptions Options = new() { IncludeFields = true };

    internal static string Save()
    {
        var (held, ledgers) = AntiCheat.Export();
        var (structures, capsules, paid, done) = Remover.Export();
        return JsonSerializer.Serialize(new State { Spent = Spending.Export(), Held = held, Ledgers = ledgers, RemoveStructures = structures,
            RemoveCapsules = capsules, RemovePaid = paid, RemoveDone = done, Alerts = Alerts.Export() }, Options);
    }

    internal static void Load(string json)
    {
        try
        {
            var s = JsonSerializer.Deserialize<State>(json, Options);
            if (s == null) return;
            if (s.Spent != null) Spending.Import(s.Spent);
            AntiCheat.Import(s.Held ?? new(), s.Ledgers ?? new());
            Remover.Import((s.RemoveStructures ?? Array.Empty<int>(), s.RemoveCapsules ?? Array.Empty<int>(), s.RemovePaid, s.RemoveDone));
            if (s.Alerts != null) Alerts.Import(s.Alerts);
            Plugin.L.LogInfo($"Crew Tools took over: {s.Spent?.Count ?? 0} spenders, {s.Held?.Count ?? 0} held payments, {s.RemoveStructures?.Length ?? 0} removals queued, {s.Alerts?.Count ?? 0} popups");
        }
        catch (Exception e) { Plugin.L.LogWarning("Crew Tools couldn't take over the last copy's state: " + e.Message); }
    }
}

using System;
using System.Collections.Generic;
using System.Collections.Specialized;
using System.IO;
using System.Linq;
using System.Text.Json;
using BepInEx;

namespace CrewTools;

// Crew Tools' answers to HTTP requests, for tools that pass requests on to plugins (Tools.HandleHttp). Reads are GET,
// changes are POST, and each change calls what the CREW TOOLS window's buttons call, so the two always agree. Player
// ids are Steam ids, sent and taken as text (they're too big for some JSON readers as numbers).
//   GET  /crew/players                  everyone known: name, online, switches, trusted, passes, spending used and left
//   GET  /crew/now                      who's in the game now, where, and the protected base they're in (if any)
//   GET  /crew/catches[?lines=40]       unanswered cheating popups, money held for buildings, the cheats log's last lines
//   GET  /crew/settings                 protected bases and sizes, spending cap, cleanup, welcome, server name
//   POST /crew/players/modify?id=       build|demolish|sell|shop|capsules=0|1, trust=0|1, pass=<Base>&passOn=0|1,
//                                       resetSpending=1, restrict=1 (every switch off), defaults=1
//   POST /crew/players/remove?id=[&ban=1]   kick (or ban: what they built is removed and refunded)
//   POST /crew/players/unban?id=
//   POST /crew/settings/modify          zone=<Base>&on=0|1, zone=<Base>&metres=N, cap=N, name=..., cleanup=0|1, cleanupMinutes=N
//   POST /crew/cleanup                  the loose-capsule cleanup in one minute (its usual warning goes out in crew chat now)
internal static class Http
{
    // one line per endpoint, for a host's help list ("METHOD /path?params | what it does")
    internal static readonly string[] Help =
    {
        "GET /crew/players | Everyone known: id (Steam id, as text), name, online, banned, switches, trusted, passes, spent and left of the cap",
        "GET /crew/now | Who's in the game now, where, and the protected base they're in",
        "GET /crew/catches?lines=40 | Unanswered cheating popups, money held for buildings, and the cheats log's last lines",
        "GET /crew/settings | Protected bases and their sizes, the spending cap, cleanup, welcome, server name, new-player switches",
        "POST /crew/players/modify?id= | build|demolish|sell|shop|capsules=0|1, trust=0|1, pass=<Base>&passOn=0|1, resetSpending=1, restrict=1, defaults=1",
        "POST /crew/players/remove?id=&ban=1 | Kick, or ban (what they built is removed and refunded)",
        "POST /crew/players/unban?id= | Unban: they can join again",
        "POST /crew/settings/modify | zone=<Base>&on=0|1, zone=<Base>&metres=N, cap=N, name=, cleanup=0|1, cleanupMinutes=N",
        "POST /crew/cleanup | The loose-capsule cleanup in one minute (its warning goes to crew chat now)",
    };

    static readonly JsonSerializerOptions Options = new() { IncludeFields = true };
    static string Json(object o) => JsonSerializer.Serialize(o, Options);
    static string Fail(string why) => Json(new { ok = false, reason = why });

    internal static string Handle(string method, string path, NameValueCollection q)
    {
        if (path != "/crew" && !path.StartsWith("/crew/", StringComparison.Ordinal)) return null;
        bool post = method == "POST";
        switch (path)
        {
            case "/crew/players": return post ? Fail("use GET") : PlayersList();
            case "/crew/now": return post ? Fail("use GET") : Now();
            case "/crew/catches": return post ? Fail("use GET") : Catches(int.TryParse(q["lines"], out var n) ? n : 40);
            case "/crew/settings": return post ? Fail("use GET") : Settings();
            case "/crew/players/modify": return post ? Modify(q) : Fail("use POST");
            case "/crew/players/remove": return post ? Remove(q) : Fail("use POST");
            case "/crew/players/unban": return post ? Unban(q) : Fail("use POST");
            case "/crew/settings/modify": return post ? ModifySettings(q) : Fail("use POST");
            case "/crew/cleanup": return post ? CleanupNow() : Fail("use POST");
        }
        return Json(new { error = "unknown path " + path, paths = new[] { "GET /crew/players", "GET /crew/now", "GET /crew/catches", "GET /crew/settings",
            "POST /crew/players/modify", "POST /crew/players/remove", "POST /crew/players/unban", "POST /crew/settings/modify", "POST /crew/cleanup" } });
    }

    static object PlayerJson(Players.Player p) => new
    {
        id = p.Id.ToString(), name = p.Name, online = Crew.Online(p.Id), trusted = p.Trusted, banned = Banned(p.Id),
        switches = PerNode(n => Players.Switch(p, n)),
        passes = p.Passes.OrderBy(x => x).ToArray(),
        spent = Math.Round(Spending.Used(p.Id), 2), left = p.Trusted ? (double?)null : Math.Round(Spending.Left(p.Id), 2),
    };

    static string PlayersList() => Json(new { cap = Plugin.Cap.Value, players = Players.All.Where(p => !p.Hidden).OrderBy(p => p.Name).Select(PlayerJson).ToArray() });

    static string Now() => Json(new
    {
        hosting = Crew.Hosting,
        players = Crew.Now.Select(kv =>
        {
            string inBase = Zones.ProtectedBaseAt(kv.Key, kv.Value.pos, out var b, out _) ? b : null;
            return new { id = kv.Key.ToString(), name = kv.Value.name, pos = new[] { kv.Value.pos.x, kv.Value.pos.y, kv.Value.pos.z }, protectedBase = inBase };
        }).ToArray(),
    });

    static string Catches(int lines)
    {
        var (held, _) = AntiCheat.Export();
        string[] log = Array.Empty<string>();
        var file = Path.Combine(Paths.BepInExRootPath, "CrewPermissions.cheats.log");
        try { if (File.Exists(file)) { var all = File.ReadAllLines(file); log = all.Skip(Math.Max(0, all.Length - Math.Clamp(lines, 0, 500))).ToArray(); } } catch { }
        return Json(new
        {
            popups = Alerts.Export().Select(a => new { id = a.Sender.ToString(), name = a.Name, what = a.What, count = a.Count, decided = a.Banned }).ToArray(),
            held = held.Select(h => new { id = h.Sender.ToString(), name = Players.Name(h.Sender), dollars = h.Dollars }).ToArray(),
            log,
        });
    }

    static string Settings() => Json(new
    {
        zones = ZoneSettings(),
        cap = Plugin.Cap.Value, cleanup = Plugin.CleanupOn.Value, cleanupMinutes = Plugin.CleanupMinutes.Value,
        welcome = Plugin.WelcomeOn.Value, welcomeText = Plugin.WelcomeText.Value, name = Plugin.SavedName.Value,
        newPlayers = PerNode(n => Plugin.StartWith[n].Value),
    });

    // dictionaries built with loops (ToDictionary with lambdas needs a compiler attribute the game's libraries hide)
    static Dictionary<string, bool> PerNode(Func<Node, bool> f)
    {

    // with the host's own push sweeper (stored) and ride-on (out), 2026-11-09
    // Everything paid for a vehicle's upgrades (2026-11-09): for each upgrade kind, the price of every level it
    // reached. The game prices a level with MoonVehicleUpgrades.Price(def, vehicle, level); which index means "the
    // step to this level" is checked against the game's own next-step price (TryGetVehicleUpgradePrice).
    static MethodInfo upLevelM, upNextM, upPriceM, upAllM; static Type upKindT;
    internal static double UpgradeSpend(MoonOwnedVehicle v, out string levels)
    {
        levels = "";
        try
        {
            if (upPriceM == null)
            {
                foreach (var m in typeof(MoonWorld).GetMethods(BindingFlags.Static | BindingFlags.Public))
                {
                    var ps = m.GetParameters();
                    if (m.Name == "VehicleUpgradeLevel" && ps.Length == 2 && ps[0].ParameterType == typeof(MoonOwnedVehicle)) { upLevelM = m; upKindT = ps[1].ParameterType; }
                    if (m.Name == "TryGetVehicleUpgradePrice" && ps.Length == 3) upNextM = m;
                }
                foreach (var m in typeof(MoonVehicleUpgrades).GetMethods(BindingFlags.Static | BindingFlags.Public))
                {
                    if (m.Name == "Price" && m.GetParameters().Length == 3) upPriceM = m;
                    if (m.Name == "get_All") upAllM = m;
                }
                if (upLevelM == null || upPriceM == null || upAllM == null) { Plugin.L.LogWarning("vehicle upgrades: game methods not found - upgrades not refunded"); return 0; }
            }
            double total = 0; var parts = new List<string>();
            foreach (var def in (System.Collections.IEnumerable)upAllM.Invoke(null, null))
            {
                object kind = null;
                foreach (var f in def.GetType().GetProperties()) if (f.PropertyType == upKindT) { kind = f.GetValue(def); break; }
                if (kind == null) continue;
                int level = (int)upLevelM.Invoke(null, new[] { (object)v, kind });
                if (level <= 0) continue;
                double P(int i) => Il2CppSystem.Decimal.ToDouble((Il2CppSystem.Decimal)upPriceM.Invoke(null, new object[] { def, v.vehicle, i }));
                // is Price(i) "the step from level i to i+1" or "the step to level i"? compare with the game's next price
                bool stepFrom = true;
                if (upNextM != null)
                {
                    var args = new object[] { v, kind, default(Il2CppSystem.Decimal) };
                    if ((bool)upNextM.Invoke(null, args)) { double next = Il2CppSystem.Decimal.ToDouble((Il2CppSystem.Decimal)args[2]); stepFrom = Math.Abs(P(level) - next) < 0.01 || Math.Abs(P(level + 1) - next) >= 0.01; }
                }
                double sum = 0; for (int i = 0; i < level; i++) sum += stepFrom ? P(i) : P(i + 1);
                total += sum; parts.Add($"{kind} {level} = ${sum:0}");
            }
            levels = parts.Count == 0 ? "none" : string.Join(", ", parts);
            return total;
        }
        catch (Exception e) { Plugin.L.LogWarning("vehicle upgrades: " + e.Message); return 0; }
    }

    {

        }

        foreach (var key in keys)
        {
            try
            {

                foreach (var o in MoonWorld.GarageOffers) if (o.vehicle == v.vehicle) { price = Il2CppSystem.Decimal.ToDouble(o.price); break; }

        // 2026-11-09); the normal removal refuses far belts ("Move closer")

        {
            if (kv.Value != id) continue; belts.Remove(kv.Key);
            if (beltsNow.Contains(kv.Key)) mine.Add(kv.Key);
        }

        {
            try
            {

            }

            double r = 0; try { r = Il2CppSystem.Decimal.ToDouble(w.StructureRefund(kv.Key)); } catch { }
            Remover.Structure(kv.Key); n++; refund += r;            // removed and refunded a piece at a time
        }

// Players: everything kept about each crew-mate, in one record and one file (BepInEx/config/CrewTools.players.txt).
//
//   switches   Build, Demolish, Sell, Shop, Capsules - each on or off (the permission switches, from Crew Permissions
//              by tylerun, nexusmods.com/moonsweepers/mods/71; Guard checks them on every crew message)
//   trusted    no spending cap (Spending)
//   passes     protected bases they may work in anyway (Zones)
//   hidden     removed from the window's History list by the host; shown again when they come back
//
// A player seen for the first time starts with the new-player switches (Rules tab). Anyone already known keeps exactly
// the switches they have; the window marks each switch that differs from the default (*).
//
// Before 1.0.0 this was two files: the switches in CrewPermissions.players.txt (from the original mod) and names, trust,
// passes in CrewTools.players.txt (earlier Crew Tools builds). The first load reads both into the new file; the old
// CrewTools.players.txt is kept as CrewTools.players.old.txt and CrewPermissions.players.txt is left as it was.
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using BepInEx;
using MoonCleaners;
using UnityEngine;

namespace CrewTools;

internal static class Players
{
    internal sealed class Player
    {
        public ulong Id;
        public string Name = "";
        public readonly HashSet<Node> On = new();
        public readonly HashSet<string> Passes = new();
        public bool Trusted, Hidden;
    }

    internal static readonly Node[] Nodes = (Node[])Enum.GetValues(typeof(Node));

    static readonly Dictionary<ulong, Player> players = new();

    internal static IEnumerable<Player> All => players.Values;

    // a player's record; the first time they're seen, made with the new-player switches
    internal static Player Get(ulong id)
    {
        if (players.TryGetValue(id, out var p)) return p;
        players[id] = p = new Player { Id = id, Name = LobbyName(id) ?? id.ToString() };
        SetDefaults(p);
        Trace.Log($"new player record {id}");
        Plugin.L.LogInfo($"{p.Name}: new player, default switches ({Describe(p)})");
        return p;
    }

    // the new-player switch for this node (Rules tab)
    internal static bool Default(Node node) => Plugin.StartWith[node].Value;

    // Manage > Reset to defaults (and new players): their switches set to the new-player ones
    internal static void SetDefaults(Player p)
    {
        p.On.Clear();
        foreach (var n in Nodes) if (Default(n)) p.On.Add(n);
        Save();
    }

    static string Describe(Player p) => string.Join(", ", Nodes.Select(n => n.ToString().ToLowerInvariant() + (p.On.Contains(n) ? " on" : " off")));

    // their name: as last seen in the game, else from the Steam lobby, else their Steam ID
    internal static string Name(ulong id)
    {
        if (players.TryGetValue(id, out var p) && !string.IsNullOrEmpty(p.Name) && p.Name != id.ToString()) return p.Name;
        return LobbyName(id) ?? id.ToString();
    }

    static string LobbyName(ulong id)
    {
        try { var n = MoonSteamLobby.PlayerName(id); return string.IsNullOrEmpty(n) ? null : n; }
        catch { return null; }
    }

    // ------------------------------------------------------------------ permission switches

    internal static bool Switch(Player p, Node node) => p.On.Contains(node);

    // the switch, then Crew Tools' rules for the action being handled: protected bases and the spending cap (Zones.Apply)
    internal static bool Allowed(Player p, Node node)
    {
        bool allowed = Switch(p, node);
        Zones.Apply(p, node, ref allowed);
        return allowed;
    }

    internal static void SetSwitch(ulong id, Node node, bool on)
    {
        var p = Get(id);
        if (on) p.On.Add(node); else p.On.Remove(node);
        Save();
    }

    // every switch off (a cheating catch, or Restrict). True if anything was on.
    internal static bool RevokeAll(ulong id)
    {
        var p = Get(id);
        bool hadAny = p.On.Count > 0;
        p.On.Clear();
        Save();
        return hadAny;
    }

    // ------------------------------------------------------------------ trust and passes

    internal static bool Trusted(ulong id) => players.TryGetValue(id, out var p) && p.Trusted;
    internal static void SetTrusted(ulong id, bool on) { Get(id).Trusted = on; Save(); }

    internal static bool HasPass(ulong id, string bse) => players.TryGetValue(id, out var p) && p.Passes.Contains(bse);
    internal static void SetPass(ulong id, string bse, bool on)
    {
        var p = Get(id);
        if (on) p.Passes.Add(bse); else p.Passes.Remove(bse);
        Save();
    }

    // passes for bases that are protected right now
    internal static int PassCount(ulong id) =>
        players.TryGetValue(id, out var p) ? p.Passes.Count(b => Plugin.ZoneOn.TryGetValue(b, out var on) && on.Value) : 0;

    // Manage > Remove from list: off the History list, trust and passes forgotten. The record and its switches stay, so
    // a player switched off for cheating doesn't come back as a new player with the default switches.
    internal static void Forget(ulong id)
    {
        if (!players.TryGetValue(id, out var p)) return;
        p.Hidden = true; p.Trusted = false; p.Passes.Clear();
        Spending.Forget(id);
        Save();
    }

    // ------------------------------------------------------------------ once a second (Driver)
    // Every crew-mate in the game has a record (a new one gets the default switches, in Get) with their name as the game
    // shows it now; one removed from the History list is listed again.
    static float nextLook;
    internal static void Update()
    {
        if (Time.unscaledTime < nextLook) return; nextLook = Time.unscaledTime + 1f;
        if (!Crew.Hosting) return;
        bool changed = false;
        foreach (var (id, seen) in Crew.Now)
        {
            var p = Get(id);
            if (!string.IsNullOrEmpty(seen.name) && p.Name != seen.name) { p.Name = seen.name; changed = true; }
            if (p.Hidden) { p.Hidden = false; changed = true; }
        }
        if (changed) Save();
    }

    // ------------------------------------------------------------------ the file
    // One line a player:  Steam ID | name | +build +sell ... | trusted hidden | South North

    const string Header = "# Crew Tools players: Steam ID | name | switches on | trusted, hidden | base passes";
    static string FilePath => Path.Combine(Paths.ConfigPath, "CrewTools.players.txt");

    internal static void Load()
    {
        players.Clear();
        try
        {
            if (File.Exists(FilePath) && (File.ReadLines(FilePath).FirstOrDefault() ?? "").StartsWith("# Crew Tools players:")) LoadFile();
            else { Migrate(); Save(); }
        }
        catch (Exception e) { Plugin.L.LogError("players not read: " + e.Message); }
        Plugin.L.LogInfo($"{players.Count} player(s) known.");
    }

    static void LoadFile()
    {
        foreach (string raw in File.ReadAllLines(FilePath))
        {
            if (raw.StartsWith("#") || raw.Trim().Length == 0) continue;
            string[] f = raw.Split('|');
            if (f.Length < 5 || !ulong.TryParse(f[0].Trim(), out var id)) continue;
            var p = new Player { Id = id, Name = f[1].Trim() };
            foreach (var s in Words(f[2])) if (s.StartsWith("+") && Enum.TryParse<Node>(s.Substring(1), true, out var n)) p.On.Add(n);
            var flags = Words(f[3]);
            p.Trusted = flags.Contains("trusted"); p.Hidden = flags.Contains("hidden");
            foreach (var b in Words(f[4])) p.Passes.Add(b);
            players[id] = p;
        }
    }

    static string[] Words(string s) => s.Split(' ', StringSplitOptions.RemoveEmptyEntries);

    // before 1.0.0: CrewPermissions.players.txt ("id | name | role | +node ...") and CrewTools.players.txt (tab lines:
    // name / trusted / pass). Either, both or neither may be there (Crew Permissions alone, earlier Crew Tools builds,
    // or a fresh install).
    static void Migrate()
    {
        string perms = Path.Combine(Paths.ConfigPath, "CrewPermissions.players.txt");
        bool hadPerms = File.Exists(perms), hadOurs = File.Exists(FilePath);
        if (hadPerms)
            foreach (string raw in File.ReadAllLines(perms))
            {
                if (raw.StartsWith("#")) continue;
                string[] f = raw.Split('|');
                if (f.Length < 3 || !ulong.TryParse(f[0].Trim(), out var id)) continue;
                var p = Record(id); p.Name = f[1].Trim();              // known: their switches as they were
                if (f.Length > 3)
                    foreach (var s in Words(f[3])) if (s.StartsWith("+") && Enum.TryParse<Node>(s.Substring(1), true, out var n)) p.On.Add(n);
            }
        if (hadOurs)
        {
            foreach (string raw in File.ReadAllLines(FilePath))
            {
                var f = raw.Split('\t'); if (f.Length < 2 || !ulong.TryParse(f[1], out var id)) continue;
                var p = Record(id);
                if (f[0] == "trusted") p.Trusted = true;
                else if (f[0] == "pass" && f.Length >= 3) p.Passes.Add(f[2]);
                else if (f[0] == "name" && f.Length >= 3) p.Name = f[2];
            }
            File.Copy(FilePath, Path.Combine(Paths.ConfigPath, "CrewTools.players.old.txt"), true);
        }
        if (hadPerms || hadOurs)
            Plugin.L.LogInfo($"players: {players.Count} moved into CrewTools.players.txt from " +
                             string.Join(" and ", new[] { hadPerms ? "CrewPermissions.players.txt" : null, hadOurs ? "the old CrewTools.players.txt (kept as CrewTools.players.old.txt)" : null }.Where(x => x != null)));
        else Plugin.L.LogInfo("players: new CrewTools.players.txt (no earlier player files)");
    }

    static Player Record(ulong id)
    {
        if (!players.TryGetValue(id, out var p)) players[id] = p = new Player { Id = id };
        return p;
    }

    internal static void Save()
    {
        try
        {
            var lines = new List<string> { Header };
            foreach (var p in players.Values.OrderBy(p => p.Name, StringComparer.OrdinalIgnoreCase))
            {
                string on = string.Join(" ", Nodes.Where(p.On.Contains).Select(n => "+" + n.ToString().ToLowerInvariant()));
                var flags = new List<string>();
                if (p.Trusted) flags.Add("trusted"); if (p.Hidden) flags.Add("hidden");
                lines.Add($"{p.Id} | {Clean(p.Name)} | {on} | {string.Join(" ", flags)} | {string.Join(" ", p.Passes)}");
            }
            File.WriteAllLines(FilePath, lines);
        }
        catch (Exception e) { Plugin.L.LogWarning("players not saved: " + e.Message); }
    }

    static string Clean(string name) => (name ?? "").Replace("|", "/").Replace("\n", " ").Trim();
}

// Returns: a sale refused for lack of the Sell permission gives the capsule back, dropped beside the player.
//
// From Crew Permissions by tylerun (nexusmods.com/moonsweepers/mods/71), rebuilt from the released DLL and tidied for
// Crew Tools. Guard queues the refusal; the capsule is made on the next frame (outside the crew message).
using System;
using System.Collections.Generic;
using MoonCleaners;
using UnityEngine;

namespace CrewTools;

internal static class Returns
{
    static readonly List<(ulong Sender, MoonCargo Cargo, double Kilograms)> queue = new();


    internal static void GiveBack(ulong sender, MoonCargo cargo, double kilograms)
    {
        if (sender != 0 && kilograms > 0) queue.Add((sender, cargo, kilograms));
    }

    internal static void Update()
    {
        if (queue.Count == 0) return;
        var now = queue.ToArray();
        queue.Clear();
        foreach (var (sender, cargo, kilograms) in now)
        {
            try { Drop(sender, cargo, kilograms); }
            catch (Exception e) { Plugin.L.LogError($"Couldn't give {Players.Name(sender)}'s capsule back: {e}"); }
        }
    }

    // a new dropped capsule 1.5 m in front of the player, 0.6 m up, sent to everyone like any dropped capsule
    static void Drop(ulong sender, MoonCargo cargo, double kilograms)
    {
        var w = Crew.World();
        if (w == null) return;
        var seller = Seller(sender);
        if (seller == null)
        {
            Plugin.L.LogWarning($"Refused sale: couldn't find {Players.Name(sender)} to give the capsule back ({kilograms:0.#} kg of {cargo}).");
            return;
        }
        var moon = w.transform;
        Vector3 at = seller.position;
        Vector3 up = (at - moon.position).normalized;                         // away from the moon's centre
        Vector3 ahead = Vector3.ProjectOnPlane(seller.forward, up);
        if (ahead.sqrMagnitude < 0.0001f) ahead = Vector3.ProjectOnPlane(seller.right, up);
        Vector3 local = moon.InverseTransformPoint(at + ahead.normalized * 1.5f + up * 0.6f);
        Vector3 localUp = local.normalized;

        int id = w.nextCanisterId++;
        var capsule = new MoonDroppedCanister
        {
            id = id, owner = "", kilograms = kilograms, capacity = kilograms, cargo = cargo,
            position = local, up = localUp, rotation = Quaternion.FromToRotation(Vector3.up, localUp),
            physicalPose = false, createdAt = Time.time,
        };
        if (!w.ApplyCrewCanister(MoonWorld.CanisterOp.Upsert, capsule, ""))
        {
            Plugin.L.LogWarning($"Refused sale: the game wouldn't place {Players.Name(sender)}'s capsule back.");
            return;
        }
        if (w.TryGetCanister(id, out var placed) && placed != null) capsule = placed;
        w.RaiseLocalCanister(MoonWorld.CanisterOp.Upsert, MoonCrew.LocalPlayerId, capsule);
        Plugin.L.LogInfo($"Refused sale: gave {Players.Name(sender)} their capsule back ({kilograms:0.#} kg of {cargo}, id {id}).");
    }

    static Transform Seller(ulong sender)
    {
        var session = MoonCrewSession.Instance;
        if (session == null || session.remotes == null) return null;
        return session.remotes.TryGetValue(sender, out var r) && r != null ? r.transform : null;
    }
}

// Spending: each crew-mate may spend up to Plugin.Cap dollars in any 30 minutes (shop, building - J.O.O.N.A.S. included
// - vehicles), counted from the team money as it drops while the game handles that player's action (Hooks.Wallet).
// Shop purchases are priced by the game first (that player's price, upgrade discounts included) and refused if over
// what's left (CanAfford); building is allowed while anything is left and counted after (OverCap, via Zones.Apply).
// Trusted players (Manage > Trust) have no cap.
using System;
using System.Collections.Generic;
using MoonCleaners;
using UnityEngine;
using Decimal = Il2CppSystem.Decimal;

namespace CrewTools;

internal static class Spending
{
    const float Window = 1800f;                                              // 30 minutes
    static readonly Dictionary<ulong, List<(float t, double d)>> spent = new();
    static readonly Dictionary<ulong, float> told = new();                  // last "you've hit your cap" per player

    // Handover: the last 30 minutes' spending goes to the next copy, so a reload doesn't reset anyone's cap
    internal static Dictionary<ulong, List<(float t, double d)>> Export() => spent;
    internal static void Import(Dictionary<ulong, List<(float t, double d)>> s) { foreach (var kv in s) spent[kv.Key] = kv.Value; }

    internal static double Used(ulong id)
    {
        if (!spent.TryGetValue(id, out var l)) return 0;
        float now = Time.unscaledTime; l.RemoveAll(e => now - e.t > Window);
        double s = 0; foreach (var e in l) s += e.d; return s;
    }

    internal static double Left(ulong id) => Plugin.Cap.Value - Used(id);

    // Manage > Reset spending: their full cap again, now
    internal static void ResetBank(ulong id) { spent.Remove(id); told.Remove(id); }

    // Players.Forget
    internal static void Forget(ulong id) => ResetBank(id);

    // Hooks.Wallet: the team money dropped by this much while handling this crew-mate's action
    internal static void Spent(ulong id, double dollars)
    {
        if (id == 0 || dollars < 0.005) return;
        if (!spent.TryGetValue(id, out var l)) spent[id] = l = new();
        l.Add((Time.unscaledTime, dollars));
    }

    // Zones.Apply: Build or Shop is allowed for this player only while some of their cap is left (trusted: no cap)
    internal static bool OverCap(ulong id)
    {
        if (Players.Trusted(id) || Left(id) > 0) return false;
        Tell(id); return true;
    }

    // Hooks.Purchase: the game's own price for this player (upgrade discounts included), against what's left of their
    // cap. Kinds the game can't price here (vehicle upgrades) are allowed while anything is left and counted after.
    internal static bool CanAfford(MoonWorld w, ulong id, object[] args)
    {
        try
        {
            if (id == 0 || Players.Trusted(id) || args == null || args.Length < 3) return true;
            string player = args[0] as string, kind = args[1]?.ToString(), item = args[2] as string;
            Decimal price = default;
            bool known = kind switch
            {
                "Tool" => w.TryGetToolPrice(item, player, out price),
                "Container" => w.TryGetContainerPrice(player, item, out price),
                "TreeNode" => w.TryGetTreePrice(player, item, out price),
                _ => false,
            };
            double left = Left(id);
            if (known ? Decimal.ToDouble(price) <= left : left > 0) return true;
            Tell(id);
            return false;
        }
        catch (Exception e) { Plugin.L.LogWarning("price check: " + e.Message); return true; }
    }

    static void Tell(ulong id)
    {
        float now = Time.unscaledTime;
        if (told.TryGetValue(id, out var t) && now - t < 30f) return;
        told[id] = now;
        Chat.Say($"@{Players.Name(id)}: you've hit your spending cap (${Plugin.Cap.Value:0} per 30 min). Ask the admin to grant you more.");
    }
}

using System;
using System.IO;
using System.Threading;
using BepInEx;
using UnityEngine;

namespace CrewTools;

// Trace: a flight recorder for finding a crash. Every line is written to BepInEx/CrewTools.trace.log the moment it
// happens (opened, written and closed each time, so the last lines survive a game that dies without a word). It records
// the things around a crew-mate joining - a player appearing or leaving, a record being made, their first messages -
// and every crew building message and its money (how the money check decided), and which thread each ran on ("*" = not the game's main thread, where
// Unity calls are unsafe). The file starts empty each time the game starts (a reload of Crew Tools carries on in it). Switch off: [Debug] Trace = false.
internal static class Trace
{
    static string path; static int mainThread; static bool on = true;
    static readonly object gate = new();

    // fresh: the game just started (the file starts empty); otherwise Crew Tools was reloaded and the file goes on
    internal static void Start(BepInEx.Configuration.ConfigFile config, bool fresh)
    {
        mainThread = Environment.CurrentManagedThreadId;
        on = config.Bind("Debug", "Trace", true, "Write BepInEx/CrewTools.trace.log: a line for each join and first-time hook call, saved at once, to find a crash.").Value;
        if (!on) return;
        path = Path.Combine(Paths.BepInExRootPath, "CrewTools.trace.log");
        try
        {
            if (fresh) File.WriteAllText(path, $"Crew Tools trace, game started {DateTime.Now:yyyy-MM-dd HH:mm:ss}\n");
            else File.AppendAllText(path, $"Crew Tools reloaded {DateTime.Now:yyyy-MM-dd HH:mm:ss}\n");
        }
        catch { on = false; }
    }

    // one line: time, frame, thread, text
    internal static void Log(string text)
    {
        if (!on) return;
        int t = Environment.CurrentManagedThreadId;
        int frame = -1; try { if (t == mainThread) frame = Time.frameCount; } catch { }
        string line = $"{DateTime.Now:HH:mm:ss.fff} f{frame} t{t}{(t == mainThread ? "" : "*")} {text}\n";
        try { lock (gate) File.AppendAllText(path, line); } catch { }
    }

    // only the first few times: for hooks that run constantly
    internal static void First(ref int count, int most, string text)
    {
        if (count >= most) return;
        count++;
        Log($"{text} (#{count})");
    }
}

// Ui: the CREW TOOLS window. A CREW TOOLS button on the pause menu's first page opens one window with five tabs
// (Players, Bases, Rules, Anti-cheat, Server), drawn with Widgets. While it is open the pause menu underneath takes no
// keys (Hooks.PauseKeys) and the mouse is free.
internal static class Ui
{
    static MoonPauseMenu pause;
    static GameObject buttonLayer, panel; static GraphicRaycaster btnRay, panelRay; static InputField nameField, welcomeField; static Text status;

    internal static bool IsOpen => panel != null;                          // Hooks.PauseKeys: the pause menu takes no keys while open

    static float pauseLookAt = -10f;

    internal static void Update()
    {
        if (pause == null && Time.unscaledTime - pauseLookAt >= 1f)
        {
            pauseLookAt = Time.unscaledTime;
            var f = UnityEngine.Object.FindObjectsOfType(Il2CppType.Of<MoonPauseMenu>()); if (f.Length > 0) pause = f[0].Cast<MoonPauseMenu>();
        }
        bool show = pause != null && pause.IsOpen && (int)pause.CurrentPage == 0 && Crew.World() != null;
        if (!show && panel != null) ClosePanel();
        bool showButton = show;
        if (showButton && buttonLayer == null && panel == null) MakeButton();
        if (!showButton && buttonLayer != null) { Widgets.Destroy(buttonLayer); buttonLayer = null; }
        if (panel != null)
        {
            var kb = Keyboard.current; if (kb != null && kb.escapeKey.wasPressedThisFrame) { ClosePanel(); return; }
            var ms = Mouse.current;                                                  // the mouse wheel scrolls the players list
            if (ms != null && popup == null && tabNow == "Players") { float sy = ms.scroll.ReadValue().y; if (sy > 0.01f) ScrollPlayers(-1); else if (sy < -0.01f) ScrollPlayers(1); }
            Click(panelRay, popup);
        }
        else if (buttonLayer != null) Click(btnRay);
    }
    internal static void LateUpdate() { if (panel != null || buttonLayer != null) { Cursor.lockState = CursorLockMode.None; Cursor.visible = true; } }

    static void MakeButton()
    {
        buttonLayer = Layer("Crew Tools Button", 31000, out btnRay);
        var b = Button(buttonLayer.transform, "CREW TOOLS", new Vector2(-150, -150), new Vector2(240, 54), OpenPanel, true);
        var r = b.GetComponent<RectTransform>(); r.anchorMin = r.anchorMax = new Vector2(1, 1); r.anchoredPosition = new Vector2(-150, -150);
    }

    // the players list scrolls (2026-11-09: no way past the first four names): visibleRows rows show playerOrder
    // from playerTop
    static readonly List<(RectTransform row, Text label, Text basesText, List<(Node node, Image bg, Text text)> perms)> playerSlots = new();
    static readonly (Node node, string tag)[] PermNodes = {
        (Node.Build, "Bld"), (Node.Demolish, "Dem"), (Node.Sell, "Sell"), (Node.Shop, "Shop"), (Node.Capsules, "Cap") };
    static void TogglePerm(ulong id, Node node) => Players.SetSwitch(id, node, !Players.Switch(Players.Get(id), node));
    static List<ulong> playerOrder = new(); static int playerTop;
    static void ScrollPlayers(int d) { playerTop = Math.Clamp(playerTop + d, 0, Math.Max(0, playerOrder.Count - visibleRows)); Refresh(); }
    static RectTransform popup; static readonly List<(string bse, Text text, Image bg)> popupRows = new(); static ulong popupFor;

    // ---------------------------------------------------------------- the window (tabs, user 2026-11-10)
    // One 980 x 900 window, five tabs. Every switch shows its state (ON orange / OFF grey), every choice is a row of
    // buttons with the chosen one lit, every number is  -  value  +. Widgets register a refresher, so Refresh() is one pass.
    static readonly List<Action> refreshers = new();
    static readonly List<(string name, RectTransform content, Image bg, Text text)> tabs = new();
    static string tabNow = "Players"; static bool showOnline = true; static Text tabOnline, tabHistory, rangeText;
    static int visibleRows = 9; static HashSet<ulong> onlineIds = new();
    const float W = 920f;                                                 // row width; window is 980

    static RectTransform RowBox(Transform p, float y, float h = 56f) => Rect("Row", p, new Vector2(W, h), new Vector2(0, y), Row);
    static Text RowTitle(RectTransform row, string title, float w = 460f) =>
        Label(row, title, new Vector2(-W / 2 + 18 + w / 2, 0), new Vector2(w, 52), 19, Cream, TextAnchor.MiddleLeft);
    // an ON / OFF switch ending at xRight
    static void Toggle(RectTransform row, float xRight, Func<bool> get, Action flip, string on = "ON", string off = "OFF", float w = 110f)
    {
        UnityEngine.UI.Button b = null;
        b = Button(row, "", new Vector2(xRight - w / 2, 0), new Vector2(w, 40), () => { flip(); Refresh(); });
        refreshers.Add(() => { bool v = get(); Paint(b, v); var t = b.GetComponentInChildren<Text>(); if (t != null) t.text = v ? on : off; });
    }
    // a choice: the options side by side, ending at xRight, the chosen one lit
    static void Choice(RectTransform row, float xRight, string[] options, Func<int> get, Action<int> set, float w = 110f)
    {
        var bs = new List<UnityEngine.UI.Button>();
        for (int i = 0; i < options.Length; i++)
        {
            int k = i; float x = xRight - (options.Length - i) * (w + 6) + w / 2 + 6;
            bs.Add(Button(row, options[i], new Vector2(x, 0), new Vector2(w, 40), () => { set(k); Refresh(); }));
        }
        refreshers.Add(() => { int v = get(); for (int i = 0; i < bs.Count; i++) Paint(bs[i], i == v); });
    }
    // -  value  +  ending at xRight
    static void Stepper(RectTransform row, float xRight, Func<string> value, Action minus, Action plus)
    {
        Button(row, "+", new Vector2(xRight - 25, 0), new Vector2(50, 40), () => { plus(); Refresh(); });
        var v = Label(row, "", new Vector2(xRight - 50 - 80, 0), new Vector2(150, 40), 19, Cream, TextAnchor.MiddleCenter);
        Button(row, "-", new Vector2(xRight - 50 - 160 - 25 + 10, 0), new Vector2(50, 40), () => { minus(); Refresh(); });
        refreshers.Add(() => v.text = value());
    }
    static void Hint(Transform p, string text, float y) => Label(p, text, new Vector2(0, y), new Vector2(W, 34), 16, Dim, TextAnchor.MiddleLeft);

    static void ShowTab(string name)
    {
        tabNow = name; if (name != "Players") ClosePasses();
        foreach (var (n, c, bg, tx) in tabs) { bool on = n == name; c.gameObject.SetActive(on); if (bg != null) bg.color = on ? Accent : Btn; if (tx != null) tx.color = on ? Ink : Cream; }
    }

    static void OpenPanel()
    {
        if (buttonLayer != null) { Widgets.Destroy(buttonLayer); buttonLayer = null; }
        refreshers.Clear(); tabs.Clear(); playerSlots.Clear();
        panel = Layer("Crew Tools", 31001, out panelRay);
        var win = Rect("Window", panel.transform, new Vector2(980, 900), Vector2.zero, Panel);
        Label(win, "CREW TOOLS", new Vector2(-W / 2 + 160, 405), new Vector2(320, 56), 34, Ink, TextAnchor.MiddleLeft);
        Button(win, "×", new Vector2(450, 410), new Vector2(50, 50), ClosePanel);
        string[] names = { "Players", "Bases", "Rules", "Anti-cheat", "Server" };
        for (int i = 0; i < names.Length; i++)
        {
            string n = names[i];
            var tb = Button(win, n, new Vector2(-W / 2 + 90 + i * 184, 340), new Vector2(176, 50), () => { ShowTab(n); Refresh(); });
            var content = Rect(n, win, new Vector2(W, 700), new Vector2(0, -40), null);
            tabs.Add((n, content, tb.GetComponent<Image>(), tb.GetComponentInChildren<Text>()));
        }
        BuildPlayers(win, tabs[0].content); BuildBases(tabs[1].content); BuildRules(tabs[2].content); BuildCheats(tabs[3].content); BuildServer(tabs[4].content);
        status = Label(win, Plugin.Hooked, new Vector2(0, -425), new Vector2(W, 30), 15, Dim, TextAnchor.MiddleCenter);
        ShowTab(tabNow); Refresh();
    }

    // ---------------- Players: Online / History, column headings, nine rows that scroll
    static void RebuildOrder()
    {
        onlineIds = new HashSet<ulong>(Crew.Now.Keys);
        var list = new List<ulong>();
        if (showOnline) list.AddRange(onlineIds); else list.AddRange(History());
        string Nm(ulong id) => Players.Name(id).ToLowerInvariant();
        list.Sort((x, y) => string.CompareOrdinal(Nm(x), Nm(y)));
        playerOrder = list; playerTop = Math.Clamp(playerTop, 0, Math.Max(0, list.Count - visibleRows));
    }
    // everyone who has played here and isn't in the game now (minus those removed from the list)
    static IEnumerable<ulong> History() => Players.All.Where(p => !p.Hidden && !onlineIds.Contains(p.Id)).Select(p => p.Id);

    static void BuildPlayers(RectTransform win, RectTransform c)
    {
        var bar = Rect("Bar", c, new Vector2(W, 50), new Vector2(0, 320), null);
        var on = Button(bar, "", new Vector2(-W / 2 + 95, 0), new Vector2(180, 44), () => { showOnline = true; playerTop = 0; RebuildOrder(); Refresh(); });
        var hi = Button(bar, "", new Vector2(-W / 2 + 285, 0), new Vector2(180, 44), () => { showOnline = false; playerTop = 0; RebuildOrder(); Refresh(); });
        tabOnline = on.GetComponentInChildren<Text>(); tabHistory = hi.GetComponentInChildren<Text>();
        rangeText = Label(bar, "", new Vector2(W / 2 - 250, 0), new Vector2(170, 44), 16, Ink, TextAnchor.MiddleRight);
        Button(bar, "Up", new Vector2(W / 2 - 135, 0), new Vector2(60, 40), () => ScrollPlayers(-1));
        Button(bar, "Down", new Vector2(W / 2 - 40, 0), new Vector2(90, 40), () => ScrollPlayers(1));
        refreshers.Add(() => { Paint(on, showOnline); Paint(hi, !showOnline); tabOnline.text = $"In game ({onlineIds.Count})"; int hist = History().Count(); tabHistory.text = $"History ({hist})"; });
        // column headings, lined up with the row's buttons below
        var head = Rect("Head", c, new Vector2(W, 30), new Vector2(0, 278), null);
        Label(head, "Player", new Vector2(-W / 2 + 18 + 120, 0), new Vector2(240, 28), 15, Ink, TextAnchor.MiddleLeft);
        string[] cols = { "Build", "Demolish", "Sell", "Shop", "Capsules" };
        for (int q = 0; q < cols.Length; q++) Label(head, cols[q], new Vector2(-95 + q * 82, 0), new Vector2(80, 28), 15, Ink, TextAnchor.MiddleCenter);
        Label(head, "Passes", new Vector2(330, 0), new Vector2(90, 28), 15, Ink, TextAnchor.MiddleCenter);
        for (int k = 0; k < visibleRows; k++)
        {
            int slot = k; float y = 236 - k * 54;
            var row = Rect("Player", c, new Vector2(W, 48), new Vector2(0, y), Row);
            var t = Label(row, "", new Vector2(-W / 2 + 18 + 150, 0), new Vector2(300, 46), 15, Cream, TextAnchor.MiddleLeft);
            var perms = new List<(Node, Image, Text)>();
            for (int q = 0; q < PermNodes.Length; q++)
            {
                var (node, _) = PermNodes[q];
                var pb = Button(row, "", new Vector2(-95 + q * 82, 0), new Vector2(76, 36), () => { int i = playerTop + slot; if (i < playerOrder.Count) { TogglePerm(playerOrder[i], node); Refresh(); } });
                perms.Add((node, pb.GetComponent<Image>(), pb.GetComponentInChildren<Text>()));
            }
            var bb = Button(row, "", new Vector2(330, 0), new Vector2(90, 36), () => { int i = playerTop + slot; if (i < playerOrder.Count) OpenPasses(win, playerOrder[i]); });
            Button(row, "Manage", new Vector2(415, 0), new Vector2(76, 36), () => { int i = playerTop + slot; if (i < playerOrder.Count) OpenManage(win, playerOrder[i]); }, true);
            playerSlots.Add((row, t, bb.GetComponentInChildren<Text>(), perms));
        }
        Hint(c, "* differs from what new players start with (Rules tab). Manage > Reset to defaults sets them back.", 236 - visibleRows * 54 - 8);
        var none = Label(c, "", new Vector2(0, 236), new Vector2(W, 48), 18, Dim, TextAnchor.MiddleCenter);
        refreshers.Add(() => none.text = playerOrder.Count == 0 ? (showOnline ? "Nobody else is in the game." : "No one else has played here yet.") : "");
        RebuildOrder();
    }

    static void SaveWelcome()
    {
        string t = (welcomeField.text ?? "").Trim();
        if (t.Length == 0) { status.text = "Welcome text can't be empty"; return; }
        Plugin.WelcomeText.Value = t;
        status.text = $"Welcome saved: \"{t}\"";
    }

    static void Refresh()
    {
        foreach (var r in refreshers) { try { r(); } catch { } }
        foreach (var (what, text) in manageRows)
        {
            if (text == null) continue;
            bool trusted = Players.Trusted(popupFor);
            text.text = what switch
            {
                "reset" => trusted ? "Reset spending (trusted: no limit anyway)" : $"Reset spending (spent ${Spending.Used(popupFor):0} of ${Plugin.Cap.Value:0})",
                "trust" => trusted ? "Untrust (spending limit again)" : "Trust (no spending limit)",
                "defaults" => "Reset switches to the new-player defaults",
                "restrict" => "Restrict: all permissions off",
                "kick" => armed == "kick" ? "Sure? Click again to KICK" : "Kick (they can rejoin)",
                "ban" => Banned(popupFor) ? "Unban (they can join again)" : armed == "ban" ? "Sure? Click again to BAN" : "Ban (reclaims what they built)",
                "forget" => armed == "forget" ? "Sure? Click again to REMOVE from the list" : "Remove from this list (when they're not in the game)",
                _ => what
            };
            text.color = (what == "kick" || what == "ban" || what == "forget") && armed == what ? new Color(1f, 0.55f, 0.45f) : Cream;
        }
        foreach (var (bse, text, bg) in popupRows)
        {
            bool on = Players.HasPass(popupFor, bse);
            if (text != null) text.text = $"{bse} base: {(on ? "ALLOWED" : "restricted")}";
            if (bg != null) bg.color = on ? Accent : Btn;
        }
        for (int k = 0; k < playerSlots.Count; k++)
        {
            var (row, label, basesText, perms) = playerSlots[k]; int idx = playerTop + k; bool has = idx < playerOrder.Count;
            if (row != null) row.gameObject.SetActive(has);
            if (!has) continue;
            ulong id = playerOrder[idx];
            if (basesText != null) { int np = Players.PassCount(id); basesText.text = np == 0 ? "none" : $"{np} base{(np == 1 ? "" : "s")}"; }
            string name = Players.Name(id);
            label.text = name + "\n" + (Players.Trusted(id) ? "trusted: no limit" : $"spent ${Spending.Used(id):N0} of ${Plugin.Cap.Value:N0}");
            try
            {
                var p = Players.Get(id);
                foreach (var (node, bg, tx) in perms)
                {
                    bool on = Players.Switch(p, node);
                    if (bg != null) bg.color = on ? Accent : Btn;
                    string mark = on != Players.Default(node) ? "*" : "";       // differs from the new-player default
                    if (tx != null) { tx.text = (on ? "ON" : "off") + mark; tx.color = on ? Ink : Dim; tx.fontSize = 16; }
                }
            }
            catch { }
        }
        if (rangeText != null)
        {
            int cnt = playerOrder.Count;
            rangeText.text = cnt > visibleRows ? $"{playerTop + 1}-{Math.Min(cnt, playerTop + visibleRows)} of {cnt}" : "";
        }
    }

    // pick which protected bases one player may build in - only the bases protected now are listed
    static void OpenPasses(RectTransform win, ulong id)
    {
        ClosePasses(); popupFor = id;
        var bases = new List<string>(); foreach (var b in Plugin.Bases) if (Plugin.ZoneOn[b].Value) bases.Add(b);
        string name = Players.Name(id);
        float h = 150 + Math.Max(1, bases.Count) * 58;
        popup = Rect("Passes", win, new Vector2(560, h), new Vector2(0, 0), new Color(0.12f, 0.12f, 0.15f, 0.98f));
        Label(popup, $"{name}: protected bases", new Vector2(0, h / 2 - 40), new Vector2(520, 40), 22, Cream, TextAnchor.MiddleCenter);
        if (bases.Count == 0) Label(popup, "No bases are protected right now.", new Vector2(0, h / 2 - 100), new Vector2(520, 40), 18, Dim, TextAnchor.MiddleCenter);
        for (int i = 0; i < bases.Count; i++)
        {
            string b = bases[i];
            var tb = Button(popup, "", new Vector2(0, h / 2 - 100 - i * 58), new Vector2(480, 48), () => { Players.SetPass(popupFor, b, !Players.HasPass(popupFor, b)); Refresh(); });
            popupRows.Add((b, tb.GetComponentInChildren<Text>(), tb.GetComponent<Image>()));
        }
        Button(popup, "Done", new Vector2(0, -h / 2 + 40), new Vector2(160, 46), () => { ClosePasses(); Refresh(); }, true);
        Refresh();
    }
    // one player's controls: spending (reset, trust) and discipline (restrict, kick, ban - kick and ban ask twice; a
    // banned player's Ban row is Unban, one click, also from History while they're away)
    static readonly List<(string what, Text text)> manageRows = new(); static string armed; static Text manageNote;
    static void OpenManage(RectTransform win, ulong id)
    {
        ClosePasses(); popupFor = id; armed = null;
        string name = Players.Name(id);
        const float h = 652;
        popup = Rect("Manage", win, new Vector2(560, h), new Vector2(0, 0), new Color(0.12f, 0.12f, 0.15f, 0.98f));
        Label(popup, name, new Vector2(0, h / 2 - 40), new Vector2(520, 40), 24, Cream, TextAnchor.MiddleCenter);
        string[] kinds = { "reset", "trust", "defaults", "restrict", "kick", "ban", "forget" };
        for (int i = 0; i < kinds.Length; i++)
        {
            string k = kinds[i];
            var tb = Button(popup, "", new Vector2(0, h / 2 - 100 - i * 62), new Vector2(480, 52), () => Act(k));
            manageRows.Add((k, tb.GetComponentInChildren<Text>()));
        }
        manageNote = Label(popup, "", new Vector2(0, -h / 2 + 100), new Vector2(520, 50), 17, Dim, TextAnchor.MiddleCenter);
        // the vehicle refund preview, in the note line under the buttons (a line under the title didn't show - user)
        var (vc, vb, vu) = Owners.VehicleValue(id, name);
        vehicleLine = vc == 0 ? "No vehicles." : $"{vc} vehicle{(vc == 1 ? "" : "s")}: leaving refunds ${vb:0}; a ban refunds ${vb + vu:0} (+ upgrades ${vu:0})";
        manageNote.text = vehicleLine; manageNote.color = Cream;
        Button(popup, "Done", new Vector2(0, -h / 2 + 40), new Vector2(160, 46), () => { ClosePasses(); Refresh(); }, true);
        Refresh();
    }
    static void Act(string k)
    {
        ulong id = popupFor; string name = Players.Name(id);
        bool host = Crew.Hosting;
        if (k == "reset") { armed = null; Spending.ResetBank(id); Note($"{name}: full spending cap again."); }
        else if (k == "trust") { armed = null; Players.SetTrusted(id, !Players.Trusted(id)); Note(Players.Trusted(id) ? $"{name}: no spending limit." : $"{name}: spending limit applies again."); }
        else if (k == "defaults") { armed = null; Players.SetDefaults(Players.Get(id)); Note($"{name}: switches set to the new-player defaults."); }
        else if (k == "restrict") { armed = null; Players.RevokeAll(id); Note($"{name}: every permission off. Switch them back on in their row."); }
        else if (k == "forget")
        {
            if (Crew.Online(id)) { armed = null; Note($"{name} is in the game now: remove them after they leave."); }
            else if (armed != "forget") { armed = "forget"; Note($"Click again to remove {name} from this list (their trust and passes are forgotten)."); }
            else
            {
                armed = null; Players.Forget(id); playerOrder.Remove(id);
                playerTop = Math.Clamp(playerTop, 0, Math.Max(0, playerOrder.Count - visibleRows));
                ClosePasses(); Refresh(); return;
            }
        }
        else if (k == "ban" && Banned(id))
        {
            armed = null;
            try { MoonSteamLobby.Unban(id); Plugin.L.LogInfo($"host unbanned {name} ({id})"); Note($"{name} is unbanned: they can join again (their switches stay as they are)."); }
            catch (Exception e) { Note($"Couldn't unban: {e.Message}"); }
        }
        else if (k == "kick" || k == "ban")
        {
            if (!host) { armed = null; Note("Only while you host a game."); }
            else if (!Crew.Online(id)) { armed = null; Note($"{name} isn't in the game right now."); }
            else if (armed != k) { armed = k; Note($"Click again to {k} {name}."); }
            else
            {
                armed = null;
                try
                {
                    if (k == "kick") MoonSteamLobby.Kick(id); else MoonSteamLobby.Ban(id);
                    Plugin.L.LogInfo($"host {(k == "kick" ? "kicked" : "banned")} {name} ({id})");
                    Note(k == "kick" ? $"{name} was kicked (they can rejoin)." : $"{name} was banned; what they built is being removed and refunded.");
                }
                catch (Exception e) { Note($"Couldn't {k}: {e.Message}"); }
            }
        }
        Refresh();
    }
    // banned from your games (the game's own ban list)

// Welcome: greet each crew-mate once per session in crew chat, then name the protected bases. Chat: crew chat itself.

    static float nextLook;
    // one short line per protected base (crew chat takes at most 120 characters a message)
    internal static List<string> ZoneNote()
    {
        var lines = new List<string>();
        foreach (var b in Plugin.Bases)
            if (Plugin.ZoneOn[b].Value) lines.Add($"{b} base is restricted: look, but you can't touch (within {Plugin.ZoneMetres[b].Value:0} m).");
        if (lines.Count > 0) lines.Add("Teleporting from the map still works.");
        return lines;
    }
    internal static void Update()
    {
        if (!Plugin.WelcomeOn.Value || Time.unscaledTime < nextLook) return;
        nextLook = Time.unscaledTime + 1f;
        if (!Crew.Hosting) return;
        foreach (var (id, pl) in Crew.Now)
        {
            string name = pl.name;
            if (greeted.Contains(id)) continue;
            if (!seenAt.TryGetValue(id, out var t)) { seenAt[id] = Time.unscaledTime; continue; }
            if (Time.unscaledTime - t < 5f) continue;                       // a few seconds to finish loading in
            greeted.Add(id);
            try
            {
                Chat.Say(Plugin.WelcomeText.Value.Replace("{name}", string.IsNullOrEmpty(name) ? "crewmate" : name).Replace("{server}", MoonSteamLobby.CrewName ?? "our crew"));
                foreach (var line in ZoneNote()) Chat.Say(line);
            }
            catch (Exception e) { Plugin.L.LogWarning("welcome: " + e.Message); }
        }
    }
}

// crew chat, never past the game's limit (MoonTalk.MaxLength, 120): cut at a word, with "..."
internal static class Chat
{
    internal static void Say(string text)
    {
        int max = 120; try { max = MoonTalk.MaxLength; } catch { }
        text = (text ?? "").Trim();
        if (text.Length > max) { int cut = text.LastIndexOf(' ', max - 3); text = text.Substring(0, cut > 20 ? cut : max - 3).TrimEnd() + "..."; }
        if (text.Length > 0) MoonTalk.Say(text);
    }
}

            if (b != null) { if (actions.TryGetValue(b.gameObject.GetInstanceID(), out var act)) act(); break; }
            if (modal != null) break;
            var f = go.GetComponentInParent<InputField>(); if (f != null) { es.SetSelectedGameObject(f.gameObject); f.ActivateInputField(); break; }
        }
    }

using System;
using System.Collections.Generic;
using UnityEngine;

namespace CrewTools;

// Zones: protected bases. Per base (North/South/East/West) on/off and a radius from its station. Crew-mates inside one
// they have no pass for can look but not build, demolish, sell, shop or handle capsules (Apply, from Players.Allowed),
// nor buy or upgrade a vehicle (VehicleBuy). They are told once per base, the first time they walk in after joining.
internal static class Zones
{
    // Players.Allowed asks "may this player do this?" while it handles that player's action; this adds the protected
    // bases and the spending cap to the answer their switch gave (allowed). Every refusal is noted (Guard.Refused).
    internal static void Apply(Players.Player p, Node node, ref bool allowed)
    {
        if (p == null) return;
        ulong id = p.Id;
        if (id == 0 || Guard.Sender != id) return;                    // only for the action being handled (not the panel's display)
        bool zone = InZone(id);
        // spending (shop, building) only while they're under their 30-minute cap (trusted: no cap)
        if (allowed && !zone && (node == Node.Shop || node == Node.Build) && Spending.OverCap(id)) { allowed = false; Guard.Refused(id); return; }
        if (!allowed && !zone) { Guard.Refused(id); return; }                  // their switch is off
        if (!zone) return;
        // inside a protected base: refused quietly - they were told once when they walked in (Update below). A message
        // per refused action spammed crew chat with "shopping/selling is restricted" (2026-11-09)
        allowed = false; Guard.Refused(id);
    }

    // Hooks: a crew-mate buying or upgrading a vehicle (driving, parking and recalling are never refused): refused when
    // their Shop switch is off, inside a protected base without a pass, or over their spending cap
    internal static bool VehicleBuy()
    {
        ulong id = Guard.Sender; if (id == 0) return true;
        bool zone = InZone(id), over = Spending.OverCap(id);
        bool noShop = !Players.Switch(Players.Get(id), Node.Shop);   // the switch alone: zone and cap are checked here
        if (!zone && !noShop && !over) return true;
        Guard.Refused(id);                                         // the payment their game sends is refused too
        Plugin.L.LogInfo($"{Players.Name(id)}: vehicle purchase refused ({(noShop ? "shop switched off" : zone ? "protected base" : "spending cap")})");
        return false;
    }

    // "@name: this area (South base) is restricted." - once per base, the first time they walk in after joining;
    // never for a player with a pass for that base. Forgotten when they've been gone 20 s (a rejoin is told again).
    static readonly HashSet<(ulong id, string bse)> told = new(); static readonly Dictionary<ulong, float> lastSeen = new(); static float nextEntry;
    internal static void Update()
    {
        if (Time.unscaledTime < nextEntry) return; nextEntry = Time.unscaledTime + 1f;
        if (!Crew.Hosting || Crew.World() == null) return;
        float now = Time.unscaledTime;
        foreach (var (id, pl) in Crew.Now)
        {
            lastSeen[id] = now;
            if (!ProtectedBaseAt(id, pl.pos, out var b, out _) || !told.Add((id, b))) continue;
            string name = string.IsNullOrEmpty(pl.name) ? "crewmate" : pl.name;
            string msg = $"@{name}: this area ({b} base) is restricted.";
            try { Chat.Say(msg); } catch (Exception e) { Plugin.L.LogWarning("crew chat: " + e.Message); }
            Plugin.L.LogInfo(msg);
        }
        foreach (var id in new List<ulong>(lastSeen.Keys))
            if (now - lastSeen[id] > 20f) { lastSeen.Remove(id); told.RemoveWhere(k => k.id == id); }
    }

    internal static string BaseOf(string stationName)
    {
        foreach (var b in new[] { "South", "East", "West", "North" }) if (stationName.Contains(b)) return b;
        return "North";                                              // the main station is just "TheCollector"
    }

    // is this crew-mate inside a protected base they have no pass for?
    internal static bool InZone(ulong id) => Crew.Now.TryGetValue(id, out var pl) && ProtectedBaseAt(id, pl.pos, out _, out _);

    // the protected base (switched on, no pass for this player) whose zone this position is in, if any
    internal static bool ProtectedBaseAt(ulong id, Vector3 pos, out string bse, out float metres)
    {
        bse = null; metres = 0;
        var w = Crew.World(); if (w == null) return false;
        foreach (var s in w.stations)
        {
            string b = BaseOf(s.gameObject.name);
            if (!Plugin.ZoneOn.TryGetValue(b, out var on) || !on.Value) continue;
            if (Players.HasPass(id, b)) continue;                       // the host gave them a pass for this base
            float m = Plugin.ZoneMetres[b].Value;
            if (Vector3.Distance(pos, s.transform.position) <= m) { bse = b; metres = m; return true; }
        }
        return false;
    }
}

#!/usr/bin/env python3
"""Crew Tools' /crew/ requests: the list from src/CrewTools/Http.cs (HttpHelp), with the details in docs/endpoints.toml
(what each does and is for, parameters, an example and an answer). Writes docs/api.html, the searchable API page
(tools/api_template.html with this list in it). tools/wiki.py makes the wiki's For Tools page from the same list
(markdown() below). Warns about a request with no details, and details for a request that's gone.
Run after changing a request or its details:  python3 tools/api.py"""
import json, os, re, sys, tomllib
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
read = lambda p: open(os.path.join(ROOT, p)).read()
GROUPS = ["Players", "In the game", "Settings"]

def requests():
    """Each request from HttpHelp: method, path (without its query), the one-line help, and its details."""
    details = tomllib.loads(read("docs/endpoints.toml"))
    out = []
    for m in re.finditer(r'^\s*"((GET|POST) ([^"|? ]+)[^"|]*?)\s*\|\s*([^"]*)",?\s*$', read("src/CrewTools/Http.cs"), re.M):
        line, method, path, help = m.group(1).strip(), m.group(2), m.group(3), m.group(4).strip()
        e = {"method": method, "path": path, "line": line, "help": help}
        if path in details: e["d"] = details[path]
        out.append(e)
    missing = [e["path"] for e in out if "d" not in e]
    gone = sorted(set(details) - {e["path"] for e in out})
    return out, missing, gone

def groups():
    reqs, _, _ = requests()
    return [{"group": g, "from": "Crew Tools", "endpoints": [e for e in reqs if e.get("d", {}).get("group", "Settings") == g]} for g in GROUPS]

def cell(s): return str(s).replace("|", "\\|").replace("\n", " ")

def markdown():
    """The wiki's For Tools reference: an index, then each request in full."""
    out = ["| Request | What it does |", "|---|---|"]
    for g in groups():
        out.append(f"| **{g['group']}** | |")
        out += [f"| [`{e['method']} {e['path']}`](#{re.sub(r'[^a-z0-9 -]', '', (e['method'] + ' ' + e['path']).lower()).replace(' ', '-')}) | {cell(e['help'])} |" for e in g["endpoints"]]
    for g in groups():
        out += ["", f"## {g['group']}"]
        for e in g["endpoints"]:
            d = e.get("d", {})
            out += ["", f"### `{e['method']} {e['path']}`", "", d.get("about", e["help"])]
            if d.get("use"): out += ["", f"**What it's for:** {d['use']}"]
            if e["method"] == "POST": out += ["", "Changes the game: needs the `allow-writes` file of the mod serving it."]
            if d.get("params"):
                out += ["", "**Parameters**", "", "| Name | Type | Default | Meaning |", "|---|---|---|---|"]
                out += [f"| `{cell(n)}` | {cell(t)} | {cell(df) or '-'} | {cell(mn)} |" for n, t, df, mn in d["params"]]
            if d.get("example"): out += ["", "**Example**", "", "```http", d["example"].strip(), "```"]
            if d.get("answer"): out += ["", "**Answer**", "", "```json", d["answer"].strip(), "```"]
            for k, name in (("errors", "Errors"), ("notes", "Notes")):
                if d.get(k): out += ["", f"**{name}**", ""] + [f"- {x}" for x in d[k]]
    return "\n".join(out)

def main():
    reqs, missing, gone = requests()
    for p in missing: print(f"warning: {p} has no details in docs/endpoints.toml", file=sys.stderr)
    for p in gone: print(f"warning: docs/endpoints.toml has {p}, which Http.cs doesn't list", file=sys.stderr)
    data = {"groups": [{"group": g["group"], "from": g["from"], "endpoints": [{"method": e["method"], "path": e["path"], "help": e["help"], **({"d": e["d"]} if "d" in e else {})} for e in g["endpoints"]]} for g in groups()],
            "note": "served under /crew/ by a mod that passes HTTP requests on to plugins, such as LunarLink (127.0.0.1:8765)"}
    page = read("tools/api_template.html").replace("/*DATA*/null", json.dumps(data, ensure_ascii=False).replace("</", "<\\/"))
    open(os.path.join(ROOT, "docs", "api.html"), "w").write(page)
    print(f"{len(reqs)} requests, {len(reqs) - len(missing)} with details -> docs/api.html")

if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Builds the wiki from wiki/ into an output folder (default _wiki/): every page as it is, with each
<!-- include: ... --> marker filled in, so the wiki never holds a stale copy of something kept elsewhere:
  <!-- include: api -->            every /crew/ request in full: tools/api.py's markdown() (Http.cs + docs/endpoints.toml)
  <!-- include: CHANGELOG.md -->   the changelog
.github/workflows/wiki.yml runs this on every push to main and publishes the result to the GitHub wiki.
Run it yourself to look:  python3 tools/wiki.py [out]"""
import os, re, shutil, sys
ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
OUT = os.path.abspath(sys.argv[1] if len(sys.argv) > 1 else os.path.join(ROOT, "_wiki"))
read = lambda p: open(os.path.join(ROOT, p)).read()

def include(m):
    what = m.group(1).strip()
    if what == "api":
        sys.path.insert(0, os.path.join(ROOT, "tools"))
        import api
        return api.markdown()
    if what == "CHANGELOG.md": return read("CHANGELOG.md").replace("(`tools/release.sh` tags it; GitHub publishes it)", "").rstrip()
    raise SystemExit(f"unknown include: {what}")

if os.path.isdir(OUT):
    for f in os.listdir(OUT):
        if f != ".git": (shutil.rmtree if os.path.isdir(os.path.join(OUT, f)) else os.remove)(os.path.join(OUT, f))
os.makedirs(OUT, exist_ok=True)
pages = 0
for f in sorted(os.listdir(os.path.join(ROOT, "wiki"))):
    if not f.endswith(".md"): continue
    open(os.path.join(OUT, f), "w").write(re.sub(r"<!-- include: (.+?) -->", include, read(os.path.join("wiki", f))))
    pages += 1
print(f"{pages} pages -> {OUT}")

# Anti-Cheat

Two parts, one switch (Anti-cheat tab: on/off): the **money checks** and the **cheat watch**. A catch from either is
handled the same way: refused, every switch off, then **Ban / Kick / Restrict**, either **at once** or **ask you**.

## Money checks

A crew-mate's game sends the money for a build or a delete separately from the build itself. Crew Tools prices what
each building message builds and removes (belts at the game's own price for their length, and pieces already gone from
what it remembers of the last 5 minutes) and pays building money **only when it matches**. Money that matches nothing
is never paid, then:

| Money that matches nothing | What happens |
|---|---|
| A cost (money taken) | Flagged in the cheats log, never a ban |
| A refund, with a build or delete from them within 10 s | Flagged; a ban once these pass $20,000 in 10 minutes |
| A refund with no build or delete at all | Cheating |

Also cheating: money no build could cost, trick money over the limit, impossible kilograms.

**No false bans:** for 10 s after any refused action, building money is refused quietly: not paid, not flagged. (A
refused demolish still sends its $50 refund; without this an honest player would be banned for it.)

## Cheat watch

Catches what cheat trainers (WeMod and the like) do to *your* world: the host can't see the program on someone else's
PC, only what their game sends.

| Check | Catches |
|---|---|
| Speed | Faster than 30 m/s sideways on foot, or 60 m/s in a vehicle, for 2+ seconds |
| Flying | Off the ground (not in a vehicle, not a passenger, not climbing) for 45+ seconds |
| Reach | Building or removing more than 60 m from where they stand (the game's reach is about 30 m) |
| Deposits | Selling or unloading more than 3x the dust their tool or vehicle holds, or selling dust more than 150 m from every station |
| Teleports | A jump of 150 m+ that lands more than 200 m from every station (the game's map only teleports to stations), or a jump with no teleport payment within 15 s (once one paid crew teleport has been seen in the session) |

It never counts: anything a permission or a protected base refused, money or deposits within 10 s of a refusal, the
host, or the first 20 s after a player appears. Fast Machines and Freeze Time of Day only change the cheater's own game.
The limits are generous, so only blatant cheating trips them; every check and limit is a setting (`[AntiCheat]`).

## When someone is caught

- **At once** (AutoBan on): a small notice in the top-right corner, "BANNED: name" and why, gone after 8 s.
- **Ask me:** a card at the top: **F7** bans, **F8** lets it go (the keys work during play; its buttons work with the
  pause menu open).

Every catch goes into `BepInEx/CrewPermissions.cheats.log`, and building money into `CrewPermissions.money.log`.

# Bans and Cleanup

## Banning and unbanning

From the Players tab, **Manage** > **Ban** (click twice). Bans are kept in the game's save, so they last. **Unban**
replaces Ban for a banned player, also from the History list; the game's pause menu has Unban too.

**Ban reclaim:** everything the banned player built (buildings, robots, belts) is removed with the game's normal refund
paid back to the team, one piece at a time so the game never freezes. Their vehicles are refunded at the garage price
**plus every upgrade level bought**. Who built what is only known for pieces built while Crew Tools is installed.

## Leaving players

Their vehicles go back to the garage, refunded at the vehicle price, freeing the slot. Upgrades are **not** refunded on
leaving: a crew-mate's own game keeps them and puts them back on the next vehicle they buy, so refunding them would
pay twice.

## Cleanup

Every N minutes (default 30), loose capsules and bricks lying around are removed, with a crew-chat warning a minute
before. It's spread over frames so the game doesn't hitch. Rules tab: on/off, how often, and Slow/Fast removal.

## Welcome and server name

A crew-chat greeting when someone joins (`{name}` = the player, `{server}` = your server name; crew chat takes 120
characters), then one line per protected base. Your server name is saved and put on every game you host. Both are on
the Server tab.

# For Tools

Crew Tools answers HTTP requests under `/crew/` when a mod that serves HTTP, such as [LunarLink](https://swheettaos.github.io/lunarlink/), passes requests on to plugins: its plugin
class has a public `string HandleHttp(string method, string path, NameValueCollection query, string body)` and lists
its requests in `string[] HttpHelp()`. Without such a mod nothing calls them. Reads are GET; changes are POST, and
each change does exactly what the CREW TOOLS window's button does.

The searchable version of this page is the [API page](https://swheettaos.github.io/crewtools/api.html).

Through [LunarLink](https://swheettaos.github.io/lunarlink/) these answer on `http://127.0.0.1:8765/`, and a `POST` (a
change) needs its `allow-writes` file. `id` is a player's Steam ID, as `/crew/players` lists it (as text). Every answer
is JSON; a refused change answers `{"ok": false, "reason": "..."}`.

```bash
A=127.0.0.1:8765
```

## Recipes

**A moderation watcher.** Every few seconds, `GET /crew/catches`; when `popups` has one that isn't `decided`, look at
`what` (the reason, as the popup shows it: a money catch like "sent trick money of $5,000", or a cheat watch catch
like "cheat watch: moved at 48 m/s on foot (most 30)") and either ban (`POST /crew/players/remove?id=&ban=1`) or restrict (`POST /crew/players/modify?id=&restrict=1`)
and look later.

```python
import json, time, urllib.request
A = "http://127.0.0.1:8765"
get = lambda p: json.load(urllib.request.urlopen(A + p))
post = lambda p: json.load(urllib.request.urlopen(urllib.request.Request(A + p, data=b"", method="POST")))
while True:
    for c in get("/crew/catches?lines=0")["popups"]:
        if not c["decided"] and c["what"].startswith("cheat watch: moved at"):     # a speed catch
            print("restricting", c["name"], post(f"/crew/players/modify?id={c['id']}&restrict=1"))
    time.sleep(5)
```

**A crew overlay.** `GET /crew/now` for who's on and where, `GET /crew/players` for each one's `left` of the cap: show
"Crewmate: $87,500 left, in South".

**A build party in a protected base.** `POST /crew/settings/modify?zone=South&on=0` to open it, or give each guest
`pass=South&passOn=1`; raise the cap with `cap=500000`; put everything back after.

**Before saving.** `POST /crew/cleanup`, wait the minute, then save.

It can also be reloaded in place by a mod loader that reloads plugins while the game runs, such as LunarLink ([[With LunarLink]]): `Tools` (`Plugin.cs`)
starts and stops as one piece and hands what is in flight (each crew-mate's spending in the last 30 minutes, building
money held for its building, a ban reclaim in progress, cheating popups not answered yet) to its next start.

# Installing

Needs **BepInEx 6 (IL2CPP)**, as the game's other mods use. Only the host installs it. Two ways:

- **On its own** (below): a normal BepInEx plugin in `BepInEx/plugins/CrewTools/`.
- **With [LunarLink](https://swheettaos.github.io/lunarlink/)**: in `BepInEx/hot/`, so it reloads and updates in place without restarts. See
  [[With LunarLink]].

1. Download `CrewTools-<version>.zip` from the [latest release](https://github.com/swheettaos/crewtools/releases/latest).
2. Close the game and unzip it into the game folder, so you get `Moon Sweepers/BepInEx/plugins/CrewTools/CrewTools.dll`.
3. **Remove** a separate `CrewPermissions.dll` from `BepInEx/plugins` if you have it: Crew Tools includes it.
4. Start the game. The log (`BepInEx/LogOutput.log`) says "Crew Tools x.y.z loaded: 30 game hooks in place".

## Coming from Crew Permissions

Nothing to do; the first start converts everything and loses nothing:

- **Players:** whichever of `CrewPermissions.players.txt` (switches) and an older `CrewTools.players.txt` you have is
  read into the one-line-per-player `CrewTools.players.txt`. The older Crew Tools file is kept as
  `CrewTools.players.old.txt`; `CrewPermissions.players.txt` is left as it was. Players already known keep their
  switches; only players never seen before start with the new-player defaults.
- **Settings:** Crew Permissions' `moonsweepers.crewpermissions.cfg` and an earlier build's `[Cheat watch]` section are
  read into `[AntiCheat]`. The old files are left in place; nothing reads them after that.
- **Who built what** (`CrewTools.owners.txt`) and the logs are unchanged.

## Updating

Unzip the new release over the old files with the game closed; your players and settings are kept. Or let a mod that
updates plugins do it: Crew Tools names its releases (see [[Updates]]).

## Uninstall

Delete `BepInEx/plugins/CrewTools`. Crew-mates are then unrestricted.

```md
# Permissions and Bases

## Permissions

Per player: **Build**, **Demolish**, **Sell**, **Shop**, **Capsules**, each on or off (Players tab: orange = on, click to
switch). A refused sale gives the capsule back, beside the player. Capsules moved by a tool, brush or vacuum are always
allowed.

**New players** start with the switches you choose on the Rules tab (default: build, sell, shop, capsules on;
demolish off). Everyone already known keeps their own. On the Players tab a switch that differs from the default is
marked `*` (e.g. "off*"); Manage > **Reset to defaults** sets a player back to them.

## Protected bases

Per base (North, South, East, West): on or off, and a radius (default 150 m from its station). Crew-mates inside can
**look but not touch**: no building, demolishing, selling, shopping or handling capsules.

- Restrict only: nobody is banned for it.
- The first time a crew-mate walks into a protected base after joining, they're told once in crew chat:
  "@name: this area (South base) is restricted." Refused actions after that are refused quietly.
- **Passes:** give a crew-mate a pass for chosen bases with **Passes** in their player row.
- You (the host) are never restricted, and map teleports still work.

## Vehicles

Crew-mates can always **drive, park and recall** vehicles they own: inside a protected base, over the spending cap, or
with Shop off. Only **buying or upgrading** a vehicle needs Shop (and no zone, and room under the cap).

# Spending Cap

Each crew-mate may spend at most **$X in any 30 minutes** (default $100,000): the shop, buildings, robots and vehicles
all count. Each purchase is priced with the game's own prices (per-player discounts included) **before** it goes
through, so the cap can't be overrun by one big buy.

- **Trust** (Players tab, Manage) lifts the cap for a player.
- **Reset spending** (Manage) gives a player their full cap again.
- The Rules tab sets the amount; it's `[Spending] Dollars per 30 minutes` in [[Settings]].
- A crew-mate over the cap can still drive, park and recall their vehicles.

# The Crew Tools Window

Pause menu → **CREW TOOLS** (while on the Moon). One window, five tabs. It scales by screen height, so it fits a Steam

|---|---|

One row per player: the five switches Build / Demolish / Sell / Shop / Capsules (click to switch), **Passes** (which protected bases they may work in) and **Manage**: reset spending, trust, reset to defaults, restrict, kick, ban (or unban), remove from the list. Nine rows; scroll with the mouse wheel or Up / Down |
| **Bases** | Each base: PROTECTED or open, and its radius (- / +) |
| **Rules** | The spending limit per 30 minutes; cleanup on/off and how often; ban reclaim and cleanup speed (Slow / Fast); what new players start with |
| **Anti-cheat** | On/off (money checks + cheat watch); a cheater gets Ban / Kick / Restrict; At once / Ask me; the trick-money limit; cheat watch on/off |
| **Server** | The server name (Save); the welcome message on/off and its text (Save) |

# Troubleshooting

| What you see | What it means |
|---|---|
| No CREW TOOLS in the pause menu | It didn't load: look for "Crew Tools" in `BepInEx/LogOutput.log`. It shows once you're on the Moon |
| The log says a part stopped | If one part hits an error, only that part stops (the log names it); the rest keeps working. Report it with the lines around it |
| An honest crew-mate was flagged or banned | Look at `CrewPermissions.cheats.log` and `CrewPermissions.money.log` for that time, and `CrewTools.trace.log` if Trace is on. Unban them (Manage > Unban), and report it: the money checks are meant never to catch an honest build |
| A crew-mate can't do something they should | Check their five switches, the protected bases (they may be inside one: give them a Pass), and the spending cap (Manage shows what's left) |
| Two copies running | `CrewPermissions.dll` is still in `BepInEx/plugins`: remove it, Crew Tools includes it |

Crew chat goes to everyone: the game has no private messages, so warnings are public. Report anything else with the
bug form on the [issues page](https://github.com/swheettaos/crewtools/issues/new/choose).

# Updates

**By hand:** download the [latest release](https://github.com/swheettaos/crewtools/releases/latest) and unzip it over the old files with the game closed.
Your players, settings and logs are kept.

**From the game, with [LunarLink](https://swheettaos.github.io/lunarlink/):** F9 → UPDATES → **Check for updates**, then **Update** on the CrewTools
row. Crew Tools names its releases with a public method LunarLink asks:

```csharp
public string UpdateFeed() => "github:swheettaos/crewtools";
```

LunarLink checks this repo's latest release when you ask (or once at every game start, if you tick that on its
UPDATES tab), compares the version with yours, and installs the zip after
checking it against the SHA-256 GitHub publishes. Running hot (from `BepInEx/hot/`), the new version reloads in place:
**no restart**, and what's in flight (each crew-mate's spending in the last 30 minutes, building money held, a ban
reclaim, unanswered popups) is handed to the new copy. Installed the normal way, in `BepInEx/plugins/`, it needs a
restart, since BepInEx loads a plugin once. See [[With LunarLink]].

**Releases** are built by GitHub from a version tag (see [[Contributing]]); each release's notes are its section of the
[[Changelog]].

# With LunarLink

**Crew Tools runs on its own**: it's a normal BepInEx plugin, and everything on this wiki works without anything else.

**With [LunarLink](https://swheettaos.github.io/lunarlink/) it's hot-loadable and updates itself, in place, while the game runs.** LunarLink is a free
BepInEx plugin ([GitHub](https://github.com/swheettaos/lunarlink)) that loads plugins from `BepInEx/hot/`, reloads them without a restart, and updates
them from the game. Crew Tools is built for it.

## The advantages

| | On its own | With LunarLink |
|---|---|---|
| **Updating** | Download the new zip, close the game, unzip, start again | F9 → UPDATES → **Update**: downloaded from this repo's releases, checked against GitHub's SHA-256 and reloaded in place, **no restart** |
| **Your crew during an update** | Everyone leaves while you restart | Nobody notices: spending in the last 30 minutes, building money held, a ban reclaim in progress and unanswered cheating popups carry over to the new version |
| **Turning it off** | Remove the DLL and restart | F9 → HOT PLUGINS → **Disable**: unloaded from memory at once; **Enable** brings it back |
| **Scripts and tools** | - | HTTP requests under `/crew/` ([[For Tools]]), listed in LunarLink's `/help` and its F9 API tab |
| **An AI assistant** | - | Through LunarLink's [MCP server](https://github.com/swheettaos/lunarlink/wiki/MCP), Crew Tools' requests become tools: ask Claude "who's online, and has anyone been caught?" |
| **Seeing its state** | `BepInEx/LogOutput.log` | F9 shows it running, its build time, and any error |

## Setting it up

1. Install [LunarLink](https://github.com/swheettaos/lunarlink/releases/latest) (close the game, unzip into the game folder).
2. Put `CrewTools.dll` in **`BepInEx/hot/`**, and remove `BepInEx/plugins/CrewTools/` if you had it there. Not both:
   LunarLink refuses to load a second copy of a plugin BepInEx already loaded, and its BEPINEX PLUGINS tab won't turn on
   a copy of one that runs hot.
3. Start the game, load a moon, press **F9** → HOT PLUGINS, and **Enable** CrewTools (a new DLL starts off). It stays on
   from then on.
4. To update: F9 → UPDATES → **Check for updates** (or tick **Check for updates at game start**); the tab shows an orange
   count when a new Crew Tools is out, and the CrewTools row has an **Update** button.

  check --> upd["Update: download,<br/>check its SHA-256"]
  upd --> hot["CrewTools.dll in BepInEx/hot/"]
  hot --> stop["The running copy's Stop():<br/>hands over spending, held money,<br/>reclaims, popups"]
  stop --> start["The new copy's Start():<br/>takes them over"]
  start --> done["Running the new version.<br/>No restart; the crew keeps playing"]
