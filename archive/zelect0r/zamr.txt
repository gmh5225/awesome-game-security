`README.md`:

```md
# zelect0r's Android Modules Repository
![](./assets/banner.webp)

A curated collection of root modules for **Magisk**, **KernelSU**, **APatch**, and **MMRL**.

## Add to MMRL

In MMRL, open **Repositories → Add** and enter this base URL:

```text
https://zelect0r.github.io/zamr/
```

Do not enter `repo.json` or `json/modules.json`; MMRL loads the module index from the base URL automatically.

## Categories

| Category | Modules |
| --- | --- |
| Apps | YouTube Morphe, Music Morphe |
| Battery | Frosty |
| Customization | iOS Emoji, LiveBoot |
| Integrity | Play Integrity Fix, Play Integrity Fork, TEESimulator, TEESimulator-RS, Tricky Addon Enhanced, Tricky Addon Target List |
| KernelSU | SUSFS for KernelSU, Hybrid Mount |
| Root Hide | Zygisk Assistant, HMA-OSS Zygisk |
| Utility | zygisk-detach, bindhosts, MSD, DT2W Fix |
| Xposed | Vector |
| Zygisk | Zygisk Next, NeoZygisk, ReZygisk |
| WebUI | Tricky Addon Enhanced, Tricky Addon Target List |

## Included modules

The MMRL index currently publishes 23 modules:

- Zygisk Next, NeoZygisk, and ReZygisk
- Zygisk Assistant and zygisk-detach
- Play Integrity Fix and Play Integrity Fork
- TEESimulator and TEESimulator-RS
- Tricky Addon Enhanced and Tricky Addon Target List
- SUSFS for KernelSU
- Vector
- iOS Emoji
- LiveBoot
- YouTube Morphe and Music Morphe
- HMA-OSS Zygisk
- Hybrid Mount
- bindhosts
- DT2W Fix
- MSD
- Frosty

The complete index is available at [`json/modules.json`](json/modules.json).

## Automatic updates

GitHub Actions checks for new upstream GitHub releases every hour. The MMRL index and each module's update metadata are rebuilt automatically. After an upstream release, it can take a few minutes before the new version appears in MMRL and on the repository page.

## Support

If you find ZAMR useful and would like to support its development and maintenance, you can support me on Ko-fi.

[☕ Support zelect0r/zamr on Ko-fi](https://ko-fi.com/zelect0r)

Your support helps me continue developing and maintaining ZAMR. Thank you! ❤️

## Requirements

- Android 8 or newer (depending on the module)
- A compatible root manager: Magisk, KernelSU, or APatch
- Check each module's supported architecture and Android API level before installing

## Safety

Root modules modify system behavior. Create a full backup before installation and read the upstream project's notes. Use at your own risk.

## License

Licenses may differ between modules and are listed in their `track.json` and module metadata. Repository metadata is Apache-2.0 unless stated otherwise.

## Links

- [MMRL repository](https://zelect0r.github.io/zamr/)
- [Module index](json/modules.json)
- [GitHub Issues](https://github.com/zelect0r/zamr/issues)

    const modulesElement = document.querySelector('#modules');
    const statusElement = document.querySelector('#release-status');
    const asText = value => value == null ? '' : String(value);
    const formatDate = timestamp => timestamp ? new Intl.DateTimeFormat('de-DE', { dateStyle: 'medium' }).format(new Date(timestamp * 1000)) : '';
    const externalLink = (label, url, className = '') => {
      const anchor = document.createElement('a'); anchor.textContent = label; anchor.href = url; anchor.className = className;
      anchor.target = '_blank'; anchor.rel = 'noopener noreferrer'; return anchor;
    };
    function renderModule(module) {
      const release = module.versions?.[0];
      if (!release?.zipUrl) return;
      const card = document.createElement('article'); card.className = 'module';
      const heading = document.createElement('h3'); heading.textContent = asText(module.name || module.id);
      const version = document.createElement('div'); version.className = 'version'; version.textContent = asText(release.version || module.version || 'Aktuelle Version');
      const description = document.createElement('p'); description.textContent = asText(module.description || 'Keine Beschreibung verfügbar.');
      const meta = document.createElement('div'); meta.className = 'meta'; meta.textContent = [module.author, formatDate(release.timestamp || module.added)].filter(Boolean).join(' · ');
      const links = document.createElement('div'); links.className = 'links'; links.append(externalLink('Download', release.zipUrl, 'download'));
      if (module.homepage) links.append(externalLink('Projekt', module.homepage));
      card.append(heading, version, description, meta, links); modulesElement.append(card);
    }
    async function loadReleases() {
      try {
        // Avoid showing a stale Pages/browser cache after a fresh index deployment.
        const response = await fetch(`json/modules.json?v=${Date.now()}`, { cache: 'no-store' });
        if (!response.ok) throw new Error(`HTTP ${response.status}`);
        const index = await response.json();
        const modules = [...(index.modules || [])].sort((a, b) => asText(a.name).localeCompare(asText(b.name), 'de'));
        modules.forEach(renderModule);
        statusElement.textContent = `${modules.length} Module · Indexstand ${formatDate(index.metadata?.timestamp) || 'aktuell'}`;
      } catch (_) {
        modulesElement.innerHTML = '<p class="error">Der Release-Index konnte gerade nicht geladen werden. Bitte später erneut versuchen oder den JSON-Index direkt öffnen.</p>';
        statusElement.textContent = 'Release-Index nicht verfügbar';
      }
    }
    loadReleases();
  </script>
