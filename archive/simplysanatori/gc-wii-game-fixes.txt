`AGENTS.md`:

```md
# AGENTS.md

Technical detail kept out of the README: how the repo is laid out and how a fix or an entry is added. The layout follows [3ds-game-fixes](https://github.com/simplysanatori/3ds-game-fixes) wherever the systems allow it.

## Layout

```
entries/mods/<game id>.json        mods, patches and cheats of one game (a list of entries)
entries/textures/<game id>.json    texture packs of one game (a list of entries)
catalog/mods.json                  built from entries/ by tools/build.py; what an app reads
catalog/textures.json              the same for texture packs
games/<game>-<region>/             our own fixes: README.md, AGENTS.md, the code file, images/
docs/USER_GUIDE.md                 how codes, mods and texture packs are installed
tools/build.py                     checks every entry and writes catalog/
```

- Folder names are lowercase, with the region last.
- A game is named by its 6-character game ID (`GFEE01`). An entry file is named after its first one.
- Texture packs and other people's mods are never in this repo: they are downloaded from their authors.

## An entry (both lists)

| Field | |
|---|---|
| `id` | `[a-z0-9-]`, unique |
| `name` | what the list shows: short, title case, no game name |
| `title` | the game's name |
| `game_ids` | every 6-character game ID it works on |
| `revisions` | optional: the disc revisions it works on (`[0]`). Codes nearly always need it |
| `author`, `author_url` | as the source credits them |
| `licence` | as stated by the author, else `Not stated` |
| `homepage` | the page the entry came from |
| `updated` | `YYYY-MM` or `YYYY-MM-DD` |
| `notes` | one or two short sentences: what it does, what it needs |
| `verified` | true only when tested here: booted, with before/after pictures of the same scene. Default false |
| `recommended` | the maintainer's pick. Default false |

## mods.json: `kind`

- `codes`: `code_type` (`gecko`, `ar` or `onframe`) and `lines`, the code as Dolphin's game INIs have it. Optional `settings`.
- `builtin`: a code Dolphin ships in its own game INI: `code_type` and `code_name`, exactly as there, without the `$` and the `[author]`.
- `settings`: only `settings`.
- `riivolution`: `source` (below) and `xml`, the path pattern of the Riivolution XML inside the download.

`category`: `widescreen`, `framerate`, `fix`, `graphics`, `controls`, `gameplay`, `cheat`, `translation`, `mod`.

`aspect`: `16:9` for anything that makes the picture wide. A GameCube widescreen code also needs `{"section": "Video_Settings", "key": "SuggestedAspectRatio", "value": "1"}` in `settings` (Force 16:9), or the picture stays 4:3.

`settings`: `{"section", "key", "value"}`. Allowed: `Video_Settings` (`wideScreenHack`, `SuggestedAspectRatio`, `AspectRatio`, `SafeTextureCacheColorSamples`), `Video_Hacks` (any key), `Video_Enhancements` (`ForceTextureFiltering`, `DisableCopyFilter`, `ArbitraryMipmapDetection`), `Core` (`CPUThread`, `SyncGPU`, `FPRF`, `MMU`, `Overclock`, `OverclockEnable`).

## textures.json

`source` or `parts` (a list, joined in order), `size` (bytes), `sha256` (optional), `format` (`zip`, `7z`, `rar`), `layout`: `single` (the folder that holds the textures, wrapper folders are dropped) or `variants` (its folders are choices), `textures` (`png` or `dds`), `downloads` (optional count).

## `source`

```
{"type": "github_release", "repo": "owner/name", "tag": "latest", "asset_pattern": "Name-*.zip"}
{"type": "github_repo_path", "repo": "owner/name", "ref": "main", "path": "dir/"}
{"type": "gamebanana", "mod": 12345, "file_pattern": "*.zip"}
{"type": "gdrive", "file_id": "..."}
{"type": "gdrive_folder", "folder_id": "...", "file_pattern": "*.zip"}
{"type": "mega", "link": "https://mega.nz/file/<handle>#<key>"}
{"type": "https", "url": "https://..."}
{"type": "link"}                     can only be opened in a browser (homepage)
```

## Rules

- Open every address before adding an entry. No guesses: no page, no entry.
- Codes: copied exactly, with their revision. Where the source gives none, `notes` say so.
- Other people's work: link to the author. A file is copied here only with the author's permission or a licence that allows it. Codes are credited.
- No game files, and nothing that carries a game's own data.

## How this was made

I started this project and used AI (Claude) to speed up development. I write, review and fix code by hand all the way through, keep the AI's work checked and reined in, and aim to keep the patches as lightweight as possible.
```

`README.md`:

```md
# GameCube and Wii Game Fixes

Widescreen patches, fixes, cheats, mods and texture packs for GameCube and Wii games in Dolphin. The sister repository of [3DS Game Fixes](https://github.com/simplysanatori/3ds-game-fixes) and [DS and GBA Game Fixes](https://github.com/simplysanatori/ds-gba-game-fixes).

## What is here

- 40 entries in [catalog/mods.json](catalog/mods.json): cheats, patches, game settings and 3 mods
- 24 texture packs in [catalog/textures.json](catalog/textures.json)
- Our own fixes, one folder per game under `games/` (none yet)

Nothing is rehosted. Texture packs and mods are downloaded from where their authors keep them.

## Use it

The [user guide](docs/USER_GUIDE.md) has the steps for Dolphin.

Entries are listed as their authors describe them. None is verified here yet.

## Requirements

- Your own copy of the game, in the region and revision the entry names

## More

- [User guide](docs/USER_GUIDE.md): codes, texture packs and Riivolution mods by hand
- [AGENTS.md](AGENTS.md): the entry format and the rules, for developers and AI agents

## Support

https://ko-fi.com/sana748653

## Licence

MIT, for the list and the fixes made here. Linked work by other people keeps its own licence. Codes are credited to their authors.

## How this was made

I started this project and used AI (Claude) to speed up development. I write, review and fix code by hand all the way through, keep the AI's work checked and reined in, and aim to keep the patches as lightweight as possible.

```

```md
# User guide

How to use an entry in Dolphin.

## Codes

1. Right-click the game, **Properties**.
2. **Gecko Codes** or **AR Codes**: tick the code. For one that is not there, **Add New Code** and paste its lines.
3. **Config > General > Enable Cheats** must be on.

A code is for one region, and often one revision, of a game. The game list shows the game ID: `GFEE01` is the USA disc, `GFEP01` the European one.

## Widescreen on GameCube

Use the game's 16:9 code and set **Graphics > Aspect Ratio** to **Force 16:9** for that game. Where there is no code, **Graphics > Enhancements > Widescreen Hack** does it for most games. Things at the sides may pop in and out.

## Texture packs

1. Unpack the pack into `Load/Textures/<game ID>/` in Dolphin's user folder.
2. Turn on **Graphics > Advanced > Load Custom Textures**.

DDS packs load faster and take less memory than PNG ones.

## Riivolution mods

Right-click the game, **Start with Riivolution Patches**, and open the mod's XML file.
```

`tools/build.py`:

```py
#!/usr/bin/env python3
"""Check every entry and write catalog/mods.json and catalog/textures.json.
--fetch also opens every homepage and source. FILE... checks only those files and writes nothing."""
import argparse
import json
import pathlib
import re
import sys
import urllib.request

ROOT = pathlib.Path(__file__).resolve().parent.parent
KINDS = {"codes", "builtin", "settings", "riivolution"}
CATEGORIES = {"widescreen", "framerate", "fix", "graphics", "controls", "gameplay", "cheat",
              "translation", "mod"}
SETTINGS = {
    "Video_Settings": {"wideScreenHack", "SuggestedAspectRatio", "AspectRatio",
                       "SafeTextureCacheColorSamples"},
    "Video_Hacks": None,
    "Video_Enhancements": {"ForceTextureFiltering", "DisableCopyFilter",
                           "ArbitraryMipmapDetection"},
    "Core": {"CPUThread", "SyncGPU", "FPRF", "MMU", "Overclock", "OverclockEnable"},
}
SOURCES = {"github_release": ["repo", "tag", "asset_pattern"],
           "github_repo_path": ["repo", "ref", "path"], "gamebanana": ["mod"],
           "gdrive": ["file_id"], "gdrive_folder": ["folder_id", "file_pattern"],
           "mega": ["link"], "https": ["url"], "link": []}
COMMON = {"id": str, "name": str, "title": str, "game_ids": list, "author": str, "licence": str,
          "homepage": str, "notes": str}
OPTIONAL = {"revisions", "author_url", "updated", "verified", "recommended", "version"}
MOD = {"kind", "category", "aspect", "settings", "code_type", "lines", "code_name", "source", "xml"}
TEX = {"source", "parts", "size", "sha256", "format", "layout", "textures", "downloads", "folder"}
HEX = re.compile(r"^[0-9A-Fa-f]{8} [0-9A-Fa-f]{8}$")
ONFRAME = re.compile(
    r"^0x[0-9A-Fa-f]{8}:(byte|word|dword):0x[0-9A-Fa-f]{1,8}(:0x[0-9A-Fa-f]{1,8})?$")
URL = re.compile(r"^https?://\S+$")


def check_source(source, bad):
    kind = source.get("type")
    if kind not in SOURCES:
        bad(f"source type {kind}")
        return
    for key in SOURCES[kind]:
        if key not in source:
            bad(f"source {kind} needs {key}")
    for key in ("url", "link"):
        if key in source and not source[key].startswith("https://"):
            bad(f"source {key} must be https")
    if ".." in str(source.get("path", "")):
        bad("source path")


def check(entry, textures, bad):
    for key, kind in COMMON.items():
        if not isinstance(entry.get(key), kind) or not entry[key]:
            bad(f"{key} is missing or not a {kind.__name__}")
            return
    for key in entry.keys() - COMMON.keys() - OPTIONAL - (TEX if textures else MOD):
        bad(f"unknown field {key}")
    if not re.fullmatch(r"[a-z0-9][a-z0-9-]*", entry["id"]):
        bad("id must be [a-z0-9-]")
    for game in entry["game_ids"]:
        if not re.fullmatch(r"[A-Z0-9]{6}", game):
            bad(f"game ID {game}")
    if not URL.match(entry["homepage"]):
        bad("homepage is not an address")
    if entry.get("updated") and not re.fullmatch(r"\d{4}-\d{2}(-\d{2})?", entry["updated"]):
        bad("updated must be YYYY-MM or YYYY-MM-DD")
    if len(entry["notes"]) > 300:
        bad("notes are over 300 characters")
    if len(entry["name"]) > 48:
        bad("name is over 48 characters")

    linked = (entry.get("source") or {}).get("type") == "link"
    if textures:
        for source in entry.get("parts") or [entry.get("source") or {}]:
            check_source(source, bad)
        if not linked and entry.get("format") not in ("zip", "7z", "rar"):
            bad("format must be zip, 7z or rar")
        if entry.get("layout", "single") not in ("single", "variants"):
            bad("layout")
        if not linked and entry.get("textures") not in ("png", "dds"):
            bad("textures must be png or dds")
        return

    kind = entry.get("kind")
    if kind not in KINDS:
        bad(f"kind {kind}")
        return
    if entry.get("category") not in CATEGORIES:
        bad(f"category {entry.get('category')}")
    for setting in entry.get("settings", []):
        allowed = SETTINGS.get(setting.get("section"), set())
        if allowed is not None and setting.get("key") not in allowed:
            bad(f"setting {setting.get('section')}/{setting.get('key')} is not allowed")
        if not isinstance(setting.get("value"), str):
            bad("a setting's value must be a string")
    if kind == "settings" and not entry.get("settings"):
        bad("no settings")
    if kind in ("codes", "builtin") and entry.get("code_type") not in ("gecko", "ar", "onframe"):
        bad("code_type")
    if kind == "codes":
        lines = entry.get("lines") or []
        if not lines:
            bad("no lines")
        for line in lines:
            if not (ONFRAME if entry.get("code_type") == "onframe" else HEX).match(line):
                bad(f"code line {line!r}")
    if kind == "builtin" and not entry.get("code_name"):
        bad("no code_name")
    if kind == "riivolution":
        check_source(entry.get("source") or {}, bad)
        if not linked and not entry.get("xml"):
            bad("no xml")
    if entry.get("category") == "widescreen" and entry.get("aspect") != "16:9":
        bad("a widescreen entry needs aspect 16:9")
    if entry.get("category") == "widescreen" and entry["game_ids"][0][0] == "G":
        if not any(x.get("key") in ("SuggestedAspectRatio", "AspectRatio") and x["value"] == "1"
                   for x in entry.get("settings", [])):
            bad("a GameCube widescreen entry needs SuggestedAspectRatio 1")


def address(source):
    kind = source.get("type")
    if kind == "github_release":
        return f"https://github.com/{source['repo']}/releases"
    if kind == "github_repo_path":
        return f"https://github.com/{source['repo']}"
    if kind == "gamebanana":
        return f"https://gamebanana.com/mods/{source['mod']}"
    if kind == "gdrive":
        return f"https://drive.google.com/file/d/{source['file_id']}/view"
    if kind == "gdrive_folder":
        return f"https://drive.google.com/drive/folders/{source['folder_id']}"
    if kind == "https":
        return source["url"]
    return None


def opens(url):
    request = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
    try:
        with urllib.request.urlopen(request, timeout=20) as reply:
            reply.read(400)
            return reply.status, ""
    except Exception as error:  # every failure is reported the same way
        return getattr(error, "code", None), str(error)


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--fetch", action="store_true")
    parser.add_argument("files", nargs="*")
    args = parser.parse_args()

    errors, ids, count = [], set(), 0
    out = {"mods": [], "textures": []}
    files = [pathlib.Path(f).resolve() for f in args.files]
    for path in files or sorted(ROOT.glob("entries/*/*.json")):
        try:
            entries = json.loads(path.read_text())
        except ValueError as error:
            errors.append(f"{path.name}: {error}")
            continue
        for entry in entries:
            count += 1
            name = entry.get("id", "?")
            check(entry, path.parent.name == "textures",
                  lambda text, name=name: errors.append(f"{name}: {text}"))
            if name in ids:
                errors.append(f"{name}: used twice")
            ids.add(name)
            out[path.parent.name].append(entry)
            if not args.fetch:
                continue
            urls = [entry.get("homepage")]
            urls += [address(s) for s in entry.get("parts") or [entry.get("source") or {}]]
            for url in filter(None, urls):
                status, why = opens(url)
                if status != 200:
                    errors.append(f"{name}: {url} answered {status} {why[:80]}")

    for error in errors:
        print("ERROR", error)
    print(f"{count} entries, {len(errors)} errors")
    if errors:
        sys.exit(1)
    if not args.files:
        for kind, key in (("mods", "mods"), ("textures", "packs")):
            (ROOT / "catalog" / f"{kind}.json").write_text(
                json.dumps({"schema": 1, key: out[kind]}, indent=1, ensure_ascii=False) + "\n")


main()
```
