`README.md`:

```md
> [!IMPORTANT]
> **Why BlackHex?**
>
> Because the major RASP competitors are run by marketing and sales teams, not security researchers.
>
> App owners are being sold high-ticket placebos, while attackers are 3 prompts away from running fraud operations on your app.
>
> **We plan to do better, and to do it for free.**

~ BlackHex (free tier)

Free Android RASP (runtime app self-protection) library. It actively checks on-device 
integrity and returns signals plus a verdict. It does not send data back to our servers.

~ What it checks for

| Group | Toggle | What it looks for |
|-------|--------|-------------------|
| App integrity | always on | The running app is the original signed build (signing cert, native-lib and resource digests, repackager/cloner artifacts, signing-block parse) |
| Instrumentation | ALLOW \| BLOCK | Runtime hooking / code injection (ART method hooks, inline-hook residue, injected libraries) |
| Emulator | ALLOW \| BLOCK | Signs the app is running on an emulator / virtual device rather than real hardware (CPU/ISA, GPU, sensors, device nodes, build props) |
| Root | ALLOW \| BLOCK | Signs of an unhidden rooted device (world-visible su, live Magisk/Zygisk/APatch daemon socket, module mount residue, a known root-manager app, kernel root token, privileged/non-zygote launch context) |
| Custom ROM / unlocked Bootloader | ALLOW \| BLOCK | Unlocked bootloader / custom ROM indicators (verified-boot state, ROM system features, ROM signing, ROM build props) |

BlackHex actively hunts only for values that can be confirmed without server verdicts. Device fingerprint, promo abuse and coordinated actions are not included in the free tier because they would violate this exact principle.

Every check reports either CLEAN, DETECTED, or INCONCLUSIVE.
Four are policy toggles you set to `ALLOW` or `BLOCK`; app-integrity is always
enforced.

Unless yours is a Fintech app or similar, we discourage to block access to Root / Custom ROM / unlocked Bootloader / Emulators. While their presence has a strong correlation with fraud, it also represents a portion of real traffic. Using them only as signals is adviced.
On the other side, App Integrity and Instrumentation are always and unambiguously a sign of fraud. Someone is trying to change how your app behaves and not for benign purposes.

### Keep in mind

- **Root detection catches UNHIDDEN root only** — including unhidden modern Magisk, caught via
  its mount residue and manager app. It does NOT catch hidden root (Magisk DenyList /
  Zygisk-hidden, KernelSU / SUSFS), which conceals these tells from an app by design — that
  needs the paid / server-verified tier. Absence of these signals means "no unhidden root," not
  "no root." Some of the root signals (world-visible su, the daemon socket) target legacy
  Magisk / SuperSU and read CLEAN against a modern Magisk that no longer exposes them.
- Any on-device check can, in principle, be defeated by an attacker with enough control of
  the device. These checks catch the common, un-hidden cases cheaply. They are not an
  unforgeable verdict; that requires server-side attestation.
- A check that cannot read what it needs returns **INCONCLUSIVE**, never a false CLEAN and
  never an enforce. Unknown is unknown.

## Usage

```kotlin
import rasp.sdk.BlackHex
import rasp.sdk.Policy
import rasp.sdk.Mode
import rasp.sdk.Verdict

val policy = Policy(
    emulator = Mode.BLOCK,
    instrumentation = Mode.BLOCK,
    root = Mode.ALLOW,
    bootloader = Mode.ALLOW,
)

// Call off the main thread, at startup and at sensitive moments (login, payment).
val report = BlackHex.check(context, policy)

when (report.verdict) {
    Verdict.PASS  -> proceed()
    Verdict.BLOCK -> handleFailure(report.enforced)   // DETECTED signals in a BLOCK group / app-integrity
}
```

- `report.signals` — every signal with its status, group, severity, and detail.
- `report.enforced` — the DETECTED signals that drove a BLOCK verdict (empty on PASS).
- An INCONCLUSIVE signal never contributes to a BLOCK verdict.

namespace {

constexpr size_t   AM_ACCESS_FLAGS_OFF   = 4;
constexpr size_t   AM_ENTRY_QUICK_OFF    = 24;
constexpr uint32_t kAccNative            = 0x00000100u;
constexpr uint32_t kAccCompileDontBother = 0x02000000u;

const VmaEntry* vma_for(uint64_t addr) {
    for (const auto& v : g_maps)
        if (addr >= v.start && addr < v.end) return &v;
    return nullptr;
}

bool region_is_legit_code(const VmaEntry* v) {
    if (!v) return false;
    const std::string& p = v->path;
    if (p.empty()) return false;
    return p.find("libart.so") != std::string::npos ||
           p.find(".oat")  != std::string::npos ||
           p.find(".odex") != std::string::npos ||
           p.find(".vdex") != std::string::npos ||
           p.find(".art")  != std::string::npos ||
           p.find(".dex")  != std::string::npos ||
           p.find("dalvik") != std::string::npos ||
           p.find("jit-cache")  != std::string::npos ||
           p.find("code-cache") != std::string::npos ||
           p.find("boot")  != std::string::npos;

}

std::string hex(uint64_t v) {
    char b[20]; snprintf(b, sizeof(b), "0x%llx", (unsigned long long)v); return b;
}

struct Target { const char* cls; const char* name; const char* sig; bool is_static; bool is_control; };

const Target TARGETS[] = {

    { "java/lang/String",      "length",       "()I",  false, true  },
    { "java/io/File",          "exists",       "()Z",  false, false },
    { "android/location/Location", "getLatitude",  "()D", false, false },
    { "android/location/Location", "getLongitude", "()D", false, false },
};

void warm_location(JNIEnv* env) {
    jclass loc = env->FindClass("android/location/Location");
    if (!loc) { env->ExceptionClear(); return; }
    jmethodID ctor = env->GetMethodID(loc, "<init>", "(Ljava/lang/String;)V");
    if (ctor) {
        jstring prov = env->NewStringUTF("gps");
        jobject o = env->NewObject(loc, ctor, prov);
        if (env->ExceptionCheck()) env->ExceptionClear();
        if (o) {
            jmethodID lat = env->GetMethodID(loc, "getLatitude", "()D");
            jmethodID lon = env->GetMethodID(loc, "getLongitude", "()D");
            if (lat) { env->CallDoubleMethod(o, lat); if (env->ExceptionCheck()) env->ExceptionClear(); }
            if (lon) { env->CallDoubleMethod(o, lon); if (env->ExceptionCheck()) env->ExceptionClear(); }
            env->DeleteLocalRef(o);
        }
        env->DeleteLocalRef(prov);
    } else env->ExceptionClear();
    env->DeleteLocalRef(loc);
}

}

NativeResult check_art_entrypoint_integrity(JNIEnv* env) {
    NativeResult r;
    r.id = "ART_ENTRYPOINT_INTEGRITY";

    r.category = CAT_INTEGRITY;
    r.severity = SEV_CRITICAL;

    int checked = 0, detected = 0, inconclusive = 0, controls_checked = 0, controls_suspect = 0;
    std::string detail;

    warm_location(env);

    jfieldID artmethod_fid = nullptr;
    if (jclass exe = env->FindClass("java/lang/reflect/Executable")) {
        artmethod_fid = env->GetFieldID(exe, "artMethod", "J");
        if (env->ExceptionCheck()) env->ExceptionClear();
        env->DeleteLocalRef(exe);
    } else env->ExceptionClear();

    for (const auto& t : TARGETS) {
        jclass c = env->FindClass(t.cls);
        if (!c) { env->ExceptionClear(); inconclusive++;
            detail += std::string("  ") + t.cls + "." + t.name + " : noclass\n"; continue; }
        jmethodID m = t.is_static ? env->GetStaticMethodID(c, t.name, t.sig)
                                  : env->GetMethodID(c, t.name, t.sig);
        if (!m) { env->ExceptionClear(); env->DeleteLocalRef(c); inconclusive++;
            detail += std::string("  ") + t.cls + "." + t.name + " : nomethod\n"; continue; }
        jobject refm = artmethod_fid ? env->ToReflectedMethod(c, m, t.is_static ? JNI_TRUE : JNI_FALSE) : nullptr;
        env->DeleteLocalRef(c);
        if (!refm || env->ExceptionCheck() || !artmethod_fid) { env->ExceptionClear();
            if (refm) env->DeleteLocalRef(refm); inconclusive++;
            detail += std::string("  ") + t.name + " : no-reflect/no-field\n"; continue; }
        uint64_t am = (uint64_t)env->GetLongField(refm, artmethod_fid);
        env->DeleteLocalRef(refm);
        const VmaEntry* amv = vma_for(am);
        if (!am || !amv || !amv->readable()) { inconclusive++;
            detail += std::string("  ") + t.name + " : artmethod-unmapped=" + hex(am) + "\n"; continue; }

        uint32_t flags = 0; uint64_t entry = 0;
        if (!safe_read_mem((uintptr_t)am + AM_ACCESS_FLAGS_OFF, &flags, sizeof(flags)) ||
            !safe_read_mem((uintptr_t)am + AM_ENTRY_QUICK_OFF, &entry, sizeof(entry))) {
            inconclusive++;
            detail += std::string("  ") + t.name + " : artmethod-read-failed\n"; continue;
        }
        checked++;
        if (t.is_control) controls_checked++;
        const VmaEntry* ev = vma_for(entry);
        std::string region = ev ? (ev->path.empty() ? "[anon]" : ev->path) : "[unmapped]";
        bool legit = region_is_legit_code(ev);
        bool exec  = ev && ev->executable();

        bool hidden = false;
        bool suspect;
        if (ev) {
            suspect = exec && !legit;
        } else {
            hidden  = (entry != 0 && page_mapped(entry));
            suspect = hidden;
        }
        bool cdb = (flags & kAccCompileDontBother) != 0;
        bool nat = (flags & kAccNative) != 0;
        if (suspect) { if (t.is_control) controls_suspect++; else detected++; }

        char line[360];
        snprintf(line, sizeof(line), "  %s.%s : entry=%s in %s [%s]%s%s%s%s\n",
                 t.cls, t.name, hex(entry).c_str(), region.c_str(),
                 ev ? ev->perms : "----",
                 suspect ? " <<SUSPECT" : "",
                 hidden ? " HIDDEN(mincore:mapped,maps:absent)" : "",
                 cdb ? " CompileDontBother" : "",
                 nat ? " Native" : "");
        detail += line;
    }

    char head[128];
    snprintf(head, sizeof(head), "checked=%d detected=%d inconclusive=%d ctrl_ok=%d/%d\n",
             checked, detected, inconclusive, controls_checked - controls_suspect, controls_checked);
    std::string raw = std::string("checked=") + std::to_string(checked) +
                      " detected=" + std::to_string(detected) +
                      " inconclusive=" + std::to_string(inconclusive);

    if (controls_checked == 0 || controls_suspect > 0) r.status = STATUS_INCONCLUSIVE;
    else if (detected > 0)                              r.status = STATUS_DETECTED;
    else if (checked > 0)                               r.status = STATUS_CLEAN;
    else                                                r.status = STATUS_INCONCLUSIVE;

    r.details = std::string(head) + detail;

    return r;
}

std::vector<VmaEntry> read_maps() {
    std::vector<VmaEntry> result;
    FILE* f = fopen("/proc/self/maps", "r");
    if (!f) return result;

    char line[512];
    while (fgets(line, sizeof(line), f)) {
        VmaEntry e{};
        char path[256] = {};

        if (sscanf(line, "%lx-%lx %7s %lx %x:%x %lu %255s",
                   &e.start, &e.end, e.perms, &e.offset, &e.dev_major, &e.dev_minor,
                   &e.inode, path) >= 7) {
            e.path = path;
            result.push_back(e);
        }
    }
    fclose(f);
    return result;
}

std::string read_proc_file(const char* path) {
    std::ifstream f(path);
    if (!f) return "";
    std::ostringstream ss;
    ss << f.rdbuf();
    return ss.str();
}

bool safe_read_mem(uintptr_t addr, void* out, size_t len) {
    static int mem_fd = open("/proc/self/mem", O_RDONLY | O_CLOEXEC);
    if (mem_fd < 0) return false;
    ssize_t n = pread(mem_fd, out, len, (off_t)addr);
    return n == (ssize_t)len;
}

std::string json_escape(const std::string& s) {
    std::string out;
    out.reserve(s.size() + 8);
    for (char c : s) {
        switch (c) {
            case '"':  out += "\\\""; break;
            case '\\': out += "\\\\"; break;
            case '\n': out += "\\n";  break;
            case '\r': out += "\\r";  break;
            case '\t': out += "\\t";  break;
            default:
                if ((unsigned char)c < 0x20) {
                    char buf[8];
                    snprintf(buf, sizeof(buf), "\\u%04x", (unsigned char)c);
                    out += buf;
                } else {
                    out += c;
                }
        }
    }
    return out;
}

           << "\"status\":" << r.status << ","
           << "\"us\":" << r.us << ","
           << "\"details\":\"" << json_escape(r.details) << "\""

bool is_candidate_region(const VmaEntry& v) {
    const std::string& p = v.path;
    if (p.empty()) return true;
    if (p.find("jit-cache")   != std::string::npos) return false;
    if (p.find("code-cache")  != std::string::npos) return false;
    if (p.find("dalvik")      != std::string::npos) return false;
    if (p.find(".art")        != std::string::npos) return false;
    if (p.find("linker_alloc")!= std::string::npos) return false;
    if (p.find("scudo")       != std::string::npos) return false;
    if (p.find("stack")       != std::string::npos) return false;
    if (p.find("vdso")        != std::string::npos) return false;
    if (p[0] == '[') return true;
    if (p.find("memfd:")      != std::string::npos) return true;
    return false;
}

bool region_is_dynamic_elf(int memfd, const VmaEntry& v) {
    if (!v.readable()) return false;
    if (v.size() < sizeof(Elf64_Ehdr)) return false;

    Elf64_Ehdr eh;
    if (pread(memfd, &eh, sizeof(eh), (off_t)v.start) != (ssize_t)sizeof(eh)) return false;
    if (!(eh.e_ident[0] == 0x7f && eh.e_ident[1] == 'E' &&
          eh.e_ident[2] == 'L'  && eh.e_ident[3] == 'F')) return false;
    if (eh.e_ident[EI_CLASS] != ELFCLASS64) return false;
    if (eh.e_phoff == 0 || eh.e_phnum == 0) return false;
    if (eh.e_phentsize < sizeof(Elf64_Phdr)) return false;
    uint64_t need = eh.e_phoff + (uint64_t)eh.e_phnum * eh.e_phentsize;
    if (need > v.size()) return false;

    unsigned n = eh.e_phnum > 128 ? 128 : eh.e_phnum;
    for (unsigned i = 0; i < n; i++) {
        Elf64_Phdr ph;
        off_t at = (off_t)(v.start + eh.e_phoff + (uint64_t)i * eh.e_phentsize);
        if (pread(memfd, &ph, sizeof(ph), at) != (ssize_t)sizeof(ph)) return false;
        if (ph.p_type == PT_DYNAMIC) return true;
    }
    return false;
}

}

NativeResult check_elf_in_anon() {
    NativeResult r;
    r.id = "ELF_IN_ANON";

    r.category = CAT_MAPS;
    r.severity = SEV_HIGH;

    int memfd = open("/proc/self/mem", O_RDONLY | O_CLOEXEC);
    if (memfd < 0) {
        r.status = STATUS_INCONCLUSIVE;
        r.details = "could not open /proc/self/mem";

        return r;
    }

    int hits = 0;
    std::string detail;
    for (const auto& v : g_maps) {
        if (!is_candidate_region(v)) continue;
        if (is_own_vma(v.path)) continue;
        if (!region_is_dynamic_elf(memfd, v)) continue;
        hits++;
        char line[256];
        snprintf(line, sizeof(line), "  %llx-%llx %s %s <<ELF+PT_DYNAMIC\n",
                 (unsigned long long)v.start, (unsigned long long)v.end,
                 v.perms, v.path.empty() ? "[anon]" : v.path.c_str());
        detail += line;
        if (hits >= 32) break;
    }
    close(memfd);

    r.status = hits > 0 ? STATUS_DETECTED : STATUS_CLEAN;
    r.details = hits > 0
        ? std::string("injected ELF(s) in anon/memfd:\n") + detail
        : "no dynamic ELF in anon/memfd/unnamed regions";

    return r;
}

    g_vdso_s = g_vdso_e = 0;
    for (const auto& v : g_maps)
        if (v.path.find("vdso") != std::string::npos || v.path.find("vvar") != std::string::npos) {
            if (!g_vdso_s || v.start < g_vdso_s) g_vdso_s = v.start;
            if (v.end > g_vdso_e) g_vdso_e = v.end;

bool want_module(const char* name) {
    if (!name || !name[0]) return false;
    if (strstr(name, "librasp")) return true;
    const char* b = strrchr(name, '/'); b = b ? b + 1 : name;
    return strcmp(b, "libc.so") == 0 || strcmp(b, "libart.so") == 0;
}

bool target_suspect(uintptr_t target, std::string& where) {
    if (g_vdso_s && target >= g_vdso_s && target < g_vdso_e) return false;
    Dl_info di;
    if (dladdr((void*)target, &di) != 0 && di.dli_fname && di.dli_fname[0]) {
        const char* f = di.dli_fname;
        if (strncmp(f, "/data/adb/", 10) == 0 || strstr(f, "/data/local/tmp/")) { where = f; return true; }
        return false;
    }

    const VmaEntry* v = vma_for(target);
    if (v) {
        const std::string& p = v->path;
        if (p.rfind("/data/adb/", 0) == 0 || p.find("/data/local/tmp/") != std::string::npos) { where = p; return true; }
        if (!p.empty() && p[0] != '[') {
            if (p.find("memfd:") == std::string::npos) return false;
            if (p.find("jit-cache") != std::string::npos || p.find("code-cache") != std::string::npos) return false;
        }
        where = p.empty() ? "[anon]" : p;
        return true;
    }
    where = "[unmapped]";
    return true;
}

struct Ctx { int memfd; int checked; int hits; std::string detail; };

int phdr_cb(struct dl_phdr_info* info, size_t, void* data) {
    Ctx* c = static_cast<Ctx*>(data);
    if (c->hits >= 64 || !want_module(info->dlpi_name)) return 0;
    uintptr_t base = (uintptr_t)info->dlpi_addr;

    const ElfW(Dyn)* dyn = nullptr;
    for (int i = 0; i < info->dlpi_phnum; i++)
        if (info->dlpi_phdr[i].p_type == PT_DYNAMIC)
            dyn = (const ElfW(Dyn)*)(base + info->dlpi_phdr[i].p_vaddr);
    if (!dyn) return 0;

    uintptr_t jmprel = 0, strtab = 0, symtab = 0;
    size_t pltrelsz = 0; long pltrel = 0;
    for (const ElfW(Dyn)* d = dyn; d->d_tag != DT_NULL; d++) {
        switch (d->d_tag) {
            case DT_JMPREL:   jmprel   = base + d->d_un.d_ptr; break;
            case DT_PLTRELSZ: pltrelsz = d->d_un.d_val;        break;
            case DT_PLTREL:   pltrel   = d->d_un.d_val;        break;
            case DT_STRTAB:   strtab   = base + d->d_un.d_ptr; break;
            case DT_SYMTAB:   symtab   = base + d->d_un.d_ptr; break;
            default: break;
        }
    }
    if (!jmprel || !pltrelsz || pltrel != DT_RELA) return 0;

    size_t n = pltrelsz / sizeof(ElfW(Rela));
    if (n > 8192) n = 8192;
    const char* mod = (info->dlpi_name && info->dlpi_name[0]) ? info->dlpi_name : "[self]";
    const char* modb = strrchr(mod, '/'); modb = modb ? modb + 1 : mod;

    for (size_t i = 0; i < n; i++) {
        ElfW(Rela) rr;
        if (pread(c->memfd, &rr, sizeof(rr), (off_t)(jmprel + i * sizeof(ElfW(Rela)))) != (ssize_t)sizeof(rr)) break;
        if (ELF64_R_TYPE(rr.r_info) != R_AARCH64_JUMP_SLOT) continue;

        uintptr_t target = 0;
        if (pread(c->memfd, &target, sizeof(target), (off_t)(base + rr.r_offset)) != (ssize_t)sizeof(target)) continue;
        if (target == 0) continue;
        c->checked++;

        std::string where;
        if (!target_suspect(target, where)) continue;
        c->hits++;

        std::string sym = "?";
        if (symtab && strtab) {
            ElfW(Sym) s;
            uint32_t si = (uint32_t)ELF64_R_SYM(rr.r_info);
            if (pread(c->memfd, &s, sizeof(s), (off_t)(symtab + (size_t)si * sizeof(ElfW(Sym)))) == (ssize_t)sizeof(s)) {
                char nbuf[96] = {0};
                if (pread(c->memfd, nbuf, sizeof(nbuf) - 1, (off_t)(strtab + s.st_name)) > 0) sym = nbuf;
            }
        }
        char line[256];
        snprintf(line, sizeof(line), "  %s: %s -> %llx %s\n", modb, sym.c_str(),
                 (unsigned long long)target, where.c_str());
        c->detail += line;
        if (c->hits >= 64) break;
    }
    return 0;
}

struct HookTarget {
    const char* sym;
    const char* lib;
};

static const HookTarget HOOK_TARGETS[] = {
    { "open",           nullptr },
    { "openat",         nullptr },
    { "read",           nullptr },
    { "write",          nullptr },
    { "mmap",           nullptr },
    { "munmap",         nullptr },
    { "mprotect",       nullptr },
    { "pthread_create", nullptr },
    { "dlopen",         nullptr },
    { "dlsym",          nullptr },
    { nullptr, nullptr }
};

struct ByteCheck {
    const char* sym;
    uint32_t direct_insn;
    uint32_t mem_insn;
    uintptr_t addr;
    bool is_trampoline;
    bool shadow_active;
    bool mem_ok;
};

static ByteCheck read_hook_bytes(const char* sym) {
    ByteCheck r{};
    r.sym = sym;
    void* ptr = dlsym(RTLD_DEFAULT, sym);
    if (!ptr) return r;
    r.addr = (uintptr_t)ptr;

    r.direct_insn = *reinterpret_cast<volatile uint32_t*>(ptr);
    r.is_trampoline = (r.direct_insn == FRIDA_TRAMPOLINE_INSN);

    int mem_fd = open("/proc/self/mem", O_RDONLY | O_CLOEXEC);
    if (mem_fd >= 0) {
        r.mem_ok = (pread(mem_fd, &r.mem_insn, 4, (off64_t)r.addr) == 4);
        close(mem_fd);
    }
    if (!r.mem_ok) r.mem_insn = r.direct_insn;
    r.shadow_active = r.mem_ok && (r.direct_insn != r.mem_insn);
    return r;
}

NativeResult check_hook_bytes_direct() {
    std::ostringstream d;
    int hooked = 0;
    for (const auto* t = HOOK_TARGETS; t->sym; ++t) {
        auto c = read_hook_bytes(t->sym);
        if (c.is_trampoline) {
            hooked++;
            d << "  " << t->sym << "() @0x" << std::hex << c.addr
              << " first_insn=0x" << c.direct_insn << " (LDR X16,[PC,#8] trampoline)\n";
        }
    }
    if (hooked == 0)
        return { .id = "HOOK_BYTES_DIRECT", .category = CAT_HOOKS, .severity = SEV_CRITICAL,
                 .status = STATUS_CLEAN,
                 .details = "No ARM64 trampoline (LDR X16,[PC,#8] = 0x58000050) found via direct pointer read" };
    return { .id = "HOOK_BYTES_DIRECT", .category = CAT_HOOKS, .severity = SEV_CRITICAL,
             .status = STATUS_DETECTED,
             .details = std::to_string(hooked) + " hooked function(s):\n" + d.str() };
}

NativeResult check_hook_bytes_mem() {
    std::ostringstream d;
    int visible_trampolines = 0;
    for (const auto* t = HOOK_TARGETS; t->sym; ++t) {
        auto c = read_hook_bytes(t->sym);
        if (c.mem_insn == FRIDA_TRAMPOLINE_INSN) {
            visible_trampolines++;
            d << "  " << t->sym << "() @0x" << std::hex << c.addr
              << " mem_insn=0x" << c.mem_insn << " (trampoline visible through /proc/self/mem)\n";
        }
    }
    if (visible_trampolines == 0)
        return { .id = "HOOK_BYTES_MEM", .category = CAT_HOOKS, .severity = SEV_CRITICAL,
                 .status = STATUS_CLEAN,
                 .details = "No trampolines visible via /proc/self/mem (no hooks present, or a read shadow hides them)" };
    return { .id = "HOOK_BYTES_MEM", .category = CAT_HOOKS, .severity = SEV_CRITICAL,
             .status = STATUS_DETECTED,
             .details = std::to_string(visible_trampolines) + " trampoline(s) visible through /proc/self/mem:\n" + d.str() };
}

NativeResult check_maps_integrity() {
    NativeResult r;
    r.id = "MAPS_INTEGRITY";

    r.category = CAT_MAPS;
    r.severity = SEV_HIGH;

    std::string detail;

    int order_viol = 0;
    for (size_t i = 1; i < g_maps.size(); i++) {
        if (g_maps[i].start < g_maps[i - 1].start ||
            g_maps[i].start < g_maps[i - 1].end) {
            order_viol++;
            if (order_viol <= 4) {
                char line[192];
                snprintf(line, sizeof(line), "  order/overlap @ %llx (prev end %llx)\n",
                         (unsigned long long)g_maps[i].start,
                         (unsigned long long)g_maps[i - 1].end);
                detail += line;
            }
        }
    }

    struct GT { const char* name; uintptr_t addr; };
    GT gt[5];
    int n = 0;
    gt[n++] = { "own_code", (uintptr_t)&check_lib_from_root_path };
    if (void* p = dlsym(RTLD_DEFAULT, "malloc")) gt[n++] = { "libc:malloc", (uintptr_t)p };
    if (void* p = dlsym(RTLD_DEFAULT, "open"))   gt[n++] = { "libc:open",   (uintptr_t)p };
    if (void* p = dlsym(RTLD_DEFAULT, "read"))   gt[n++] = { "libc:read",   (uintptr_t)p };

    int hidden = 0, nonexec = 0, checked = 0;
    for (int i = 0; i < n; i++) {
        if (!gt[i].addr) continue;
        checked++;
        const VmaEntry* ev = vma_for(gt[i].addr);
        if (ev) {
            if (!ev->executable()) {
                nonexec++;
                char line[160];
                snprintf(line, sizeof(line), "  %s @ %llx in NON-EXEC %s\n",
                         gt[i].name, (unsigned long long)gt[i].addr,
                         ev->path.empty() ? "[anon]" : ev->path.c_str());
                detail += line;
            }
        } else if (page_mapped(gt[i].addr)) {
            hidden++;
            char line[160];
            snprintf(line, sizeof(line), "  %s @ %llx HIDDEN (maps:absent, mincore:mapped)\n",
                     gt[i].name, (unsigned long long)gt[i].addr);
            detail += line;
        }
    }

    bool bad = (order_viol > 0) || (hidden > 0) || (nonexec > 0);
    r.status = bad ? STATUS_DETECTED : STATUS_CLEAN;
    char head[160];
    snprintf(head, sizeof(head), "order_viol=%d gt_checked=%d hidden=%d nonexec=%d\n",
             order_viol, checked, hidden, nonexec);
    r.details = std::string(head) + detail;

    return r;
}

inline bool is_b(uint32_t i)      { return (i & 0xFC000000u) == 0x14000000u; }
inline bool is_br(uint32_t i)     { return (i & 0xFFFFFC1Fu) == 0xD61F0000u; }

    for (const auto& v : g_maps)
        if (a >= v.start && a < v.end) return &v;
    return nullptr;

bool b_escapes_module(const uint32_t* w, uintptr_t p) {
    int32_t imm = (int32_t)(w[0] << 6) >> 6;
    uint64_t target = p + (int64_t)imm * 4;
    const VmaEntry* src = vma_for(p);
    const VmaEntry* dst = vma_for(target);
    if (!src) return false;
    return dst != src;
}

const char* classify(const uint32_t* w, uintptr_t p) {
    if (is_brk(w[0])) return "BRK/breakpoint at entry";
    if (is_br(w[0]))  return "indirect-branch (BR) trampoline at entry";
    if (is_b(w[0]) && b_escapes_module(w, p)) return "direct-branch (B) escaping module";
    if (is_ldr_lit(w[0]) && (is_br(w[1]) || is_br(w[2]))) return "literal-load + BR trampoline";
    if (is_adrp(w[0]) && is_br(w[2])) return "ADRP + BR trampoline";
    return nullptr;
}

    else if (hooked > 0) r.status = STATUS_DETECTED;
    else                 r.status = STATUS_CLEAN;

        if(plen<4 || pos+8+plen>pairs.size()) break;
        uint32_t id; if(!rd_u32(pairs,pos+8,id)){ break; }
        if(id==0xf05368c0u || id==0x7109871au){
            std::string val=pairs.substr(pos+12,(size_t)plen-4);
            size_t co,cl;
            if(first_cert(val,co,cl)){
                std::string h=sha256_hex((const uint8_t*)val.data()+co, cl);

                if(cert_hash.empty() || id==0xf05368c0u){ cert_hash=h; scheme=(id==0xf05368c0u)?"v3":"v2"; }
            }
        }
        pos+=8+(size_t)plen;
    }
    if(cert_hash.empty()){ r.status=STATUS_INCONCLUSIVE; r.details="no parseable v2/v3 signer cert - not judging"; return r; }

    std::string pin=g_signer_baseline;
    if(pin.empty()){ r.status=STATUS_INCONCLUSIVE; r.details="signer baseline unset - pin this: "+cert_hash+" ("+scheme+")"; return r; }
    if(cert_hash==pin){ r.status=STATUS_CLEAN; r.details="native signer matches pin ("+std::string(scheme)+"): "+cert_hash.substr(0,16)+"..."; }
    else { r.status=STATUS_DETECTED; r.details="native signer MISMATCH ("+std::string(scheme)+"): live="+cert_hash.substr(0,16)+"... pinned="+pin.substr(0,16)+"..."; }
    return r;
}

#include "uprobe_scan.h"
#include <cstdint>
#include <cstring>
#include <cstdio>
#include <string>
#include <fcntl.h>
#include <unistd.h>

namespace {

constexpr uint32_t BRK_UPROBE = 0xD42000A0u;

bool ends_with(const std::string& s, const char* suf) {
    size_t n = strlen(suf);
    return s.size() >= n && s.compare(s.size() - n, n, suf) == 0;
}

bool scan_region(int fd, uint64_t start, uint64_t end, uint64_t& hit) {
    const size_t CH = 65536;
    static uint8_t buf[CH];
    uint64_t cap = start + (24u << 20);
    if (end > cap) end = cap;
    for (uint64_t off = start; off < end; ) {
        size_t want = (end - off < CH) ? (size_t)(end - off) : CH;
        ssize_t got = pread(fd, buf, want, (off_t)off);
        if (got <= 0) break;
        size_t g = (size_t)got & ~3u;
        for (size_t i = 0; i + 4 <= g; i += 4) {
            uint32_t w; std::memcpy(&w, buf + i, 4);
            if (w == BRK_UPROBE) { hit = off + i; return true; }
        }
        off += want;
        if (got < (ssize_t)want) break;
    }
    return false;
}

}

NativeResult check_uprobe_residue() {
    NativeResult r;
    r.id = "UPROBE_RESIDUE";

    r.category = CAT_HOOKS;
    r.severity = SEV_HIGH;

    int hits = 0;
    std::string detail;

    for (const auto& v : g_maps)
        if (v.path.find("[uprobes]") != std::string::npos) {
            hits++;
            char line[128];
            snprintf(line, sizeof(line), "  [uprobes] VMA @ %llx-%llx\n",
                     (unsigned long long)v.start, (unsigned long long)v.end);
            detail += line;
            break;
        }

    int fd = open("/proc/self/mem", O_RDONLY | O_CLOEXEC);
    if (fd < 0) {
        r.status = hits ? STATUS_DETECTED : STATUS_INCONCLUSIVE;
        r.details = hits ? detail : "could not open /proc/self/mem";

        return r;
    }

    int scanned = 0;
    for (const auto& v : g_maps) {
        if (!v.executable()) continue;
        const std::string& p = v.path;
        if (p.empty() || p[0] == '[') continue;
        bool want = is_own_vma(p) || ends_with(p, "/libc.so") || p.find("librasp") != std::string::npos;
        if (!want) continue;
        scanned++;
        uint64_t hit = 0;
        if (scan_region(fd, v.start, v.end, hit)) {
            hits++;
            char line[192];
            snprintf(line, sizeof(line), "  BRK#0x5 @ %llx in %s\n",
                     (unsigned long long)hit, p.c_str());
            detail += line;
        }
    }
    close(fd);

    char head[96];
    snprintf(head, sizeof(head), "regions_scanned=%d hits=%d\n", scanned, hits);
    r.status = hits > 0 ? STATUS_DETECTED : STATUS_CLEAN;
    r.details = std::string(head) + (hits ? detail : "no uprobe BRK#0x5 in own/libc .text, no [uprobes] VMA");

    return r;
}

package rasp.sdk

import android.content.Context
import android.opengl.EGL14
import android.opengl.EGLConfig
import android.opengl.GLES20

internal object AppProbe {

    @Suppress("UNUSED_PARAMETER")
    fun collect(ctx: Context): List<Signal> = listOf(
        timed("EMU_GL", "HIGH") { glRenderer() },
    )

    private fun timed(id: String, sev: String, block: () -> Pair<Status, String>): Signal {
        val t0 = System.nanoTime()
        var result: Pair<Status, String>? = null
        val worker = Thread {
            result = try { block() } catch (t: Throwable) { Status.INCONCLUSIVE to "probe error: ${t.message}" }
        }.apply { isDaemon = true; start() }
        worker.join(2000)
        val (st, det) = result ?: (Status.INCONCLUSIVE to "probe timed out (>2s) - stalled HAL (emulator-like)")
        return Signal(id, "EMULATOR", sev, st, det, (System.nanoTime() - t0) / 1000)
    }

    private fun glRenderer(): Pair<Status, String> {
        val dpy = EGL14.eglGetDisplay(EGL14.EGL_DEFAULT_DISPLAY)
        if (dpy == EGL14.EGL_NO_DISPLAY) return Status.INCONCLUSIVE to "no EGL display"
        val ver = IntArray(2)
        if (!EGL14.eglInitialize(dpy, ver, 0, ver, 1)) return Status.INCONCLUSIVE to "eglInitialize failed"
        try {
            val cfg = arrayOfNulls<EGLConfig>(1); val n = IntArray(1)
            val attr = intArrayOf(
                EGL14.EGL_RENDERABLE_TYPE, EGL14.EGL_OPENGL_ES2_BIT,
                EGL14.EGL_SURFACE_TYPE, EGL14.EGL_PBUFFER_BIT, EGL14.EGL_NONE,
            )
            if (!EGL14.eglChooseConfig(dpy, attr, 0, cfg, 0, 1, n, 0) || n[0] == 0)
                return Status.INCONCLUSIVE to "no EGL config"
            val ctx = EGL14.eglCreateContext(dpy, cfg[0], EGL14.EGL_NO_CONTEXT,
                intArrayOf(EGL14.EGL_CONTEXT_CLIENT_VERSION, 2, EGL14.EGL_NONE), 0)
            val surf = EGL14.eglCreatePbufferSurface(dpy, cfg[0],
                intArrayOf(EGL14.EGL_WIDTH, 1, EGL14.EGL_HEIGHT, 1, EGL14.EGL_NONE), 0)
            EGL14.eglMakeCurrent(dpy, surf, surf, ctx)
            val renderer = GLES20.glGetString(GLES20.GL_RENDERER) ?: ""
            val vendor = GLES20.glGetString(GLES20.GL_VENDOR) ?: ""
            EGL14.eglMakeCurrent(dpy, EGL14.EGL_NO_SURFACE, EGL14.EGL_NO_SURFACE, EGL14.EGL_NO_CONTEXT)
            if (surf != EGL14.EGL_NO_SURFACE) EGL14.eglDestroySurface(dpy, surf)
            if (ctx != EGL14.EGL_NO_CONTEXT) EGL14.eglDestroyContext(dpy, ctx)
            val r = renderer.lowercase()
            val soft = listOf("swiftshader", "llvmpipe", "softpipe", "virgl", "android emulator", "emulation")
            val raw = "renderer='$renderer' vendor='$vendor'"
            return if (soft.any { r.contains(it) }) Status.DETECTED to "software GL renderer (emulator): $raw"
            else if (renderer.isBlank()) Status.INCONCLUSIVE to "no GL renderer string"
            else Status.CLEAN to "hardware GL renderer: $raw"
        } finally {
            EGL14.eglTerminate(dpy)
        }
    }
}

package rasp.sdk

import android.content.Context
import org.json.JSONArray

enum class Status { CLEAN, DETECTED, INCONCLUSIVE, NOT_APPLICABLE }

enum class Mode { ALLOW, BLOCK }

enum class Verdict { PASS, BLOCK }

data class Policy(
    val emulator: Mode = Mode.ALLOW,
    val instrumentation: Mode = Mode.ALLOW,
    val root: Mode = Mode.ALLOW,
    val bootloader: Mode = Mode.ALLOW,
)

data class Signal(
    val id: String,
    val category: String,
    val severity: String,
    val status: Status,
    val details: String,
    val micros: Long,
)

data class Report(
    val signals: List<Signal>,
    val verdict: Verdict,
    val enforced: List<Signal>,
    val elapsedMs: Long,
) {
    val detected: List<Signal> get() = signals.filter { it.status == Status.DETECTED }
}

class BaselineBuilder {
    var signer: String? = null
    var packageName: String? = null
    var resources: String? = null
    var nativeLib: String? = null
    var dexCrc: Long? = null
}

internal object Baselines {
    @Volatile var signer: String? = null
    @Volatile var packageName: String? = null
    @Volatile var resources: String? = null
    @Volatile var nativeLib: String? = null
    @Volatile var dexCrc: Long? = null
}

object BlackHex {

    fun baseline(block: BaselineBuilder.() -> Unit) {
        val b = BaselineBuilder().apply(block)
        Baselines.signer = b.signer
        Baselines.packageName = b.packageName
        Baselines.resources = b.resources
        Baselines.nativeLib = b.nativeLib
        Baselines.dexCrc = b.dexCrc
    }

    @Synchronized
    fun check(context: Context, policy: Policy = Policy()): Report {
        val t0 = System.nanoTime()
        val arr = JSONArray(NativeCore.run(Baselines.signer))
        val signals = ArrayList<Signal>(arr.length() + 16)
        for (i in 0 until arr.length()) {
            val o = arr.getJSONObject(i)
            signals += Signal(
                id = o.getString("id"),
                category = o.getString("category"),
                severity = o.getString("severity"),
                status = Status.entries[o.getInt("status")],
                details = o.getString("details"),
                micros = o.getLong("us"),
            )
        }
        signals += AppProbe.collect(context)
        signals += TamperProbe.collect(context)
        signals += CustomRomProbe.collect(context)
        signals += CloneProbe.collect(context)
        signals += RootManagerProbe.collect(context)

        val enforced = signals.filter {
            it.status == Status.DETECTED && it.id !in scoreOnly && enforces(groupOf(it.category), policy)
        }
        val verdict = if (enforced.isNotEmpty()) Verdict.BLOCK else Verdict.PASS
        return Report(signals, verdict, enforced, (System.nanoTime() - t0) / 1_000_000)
    }

    private val scoreOnly = setOf("HOOK_BYTES_DIRECT", "HOOK_BYTES_MEM")

    private enum class Group { EMULATOR, INSTRUMENTATION, BOOTLOADER, APP_INTEGRITY, ROOT, NONE }

    private fun groupOf(category: String): Group = when (category) {
        "EMULATOR" -> Group.EMULATOR
        "HOOK_DETECTION", "DYNAMIC_LINKER", "MAPS_ANALYSIS" -> Group.INSTRUMENTATION
        "CUSTOM_ROM" -> Group.BOOTLOADER
        "INTEGRITY", "TAMPER", "CLONE" -> Group.APP_INTEGRITY
        "SUBSTRATE" -> Group.ROOT
        else -> Group.NONE
    }

    private fun enforces(group: Group, policy: Policy): Boolean = when (group) {
        Group.APP_INTEGRITY -> true
        Group.EMULATOR -> policy.emulator == Mode.BLOCK
        Group.INSTRUMENTATION -> policy.instrumentation == Mode.BLOCK
        Group.BOOTLOADER -> policy.bootloader == Mode.BLOCK
        Group.ROOT -> policy.root == Mode.BLOCK
        Group.NONE -> false
    }
}

package rasp.sdk

import android.content.pm.PackageManager
import android.content.Context
import android.os.Process
import java.io.File

internal object CloneProbe {

    private val ENGINE_TOKENS = listOf(
        "com.lody.virtual", "io.busniess.va", "com.by.chaos", "com.bly.dkplat", "com.qihoo.magic",
        "com.lbe.parallel", "com.parallel.space", "com.ludashi.dualspace", "com.excelliance.dualaid",
        "com.excelliance.multiaccount", "com.cloneapp", "multi.parallel.dualspace", "com.applisto.appclone",
        "com.vmos", "blackbox", "top.niunaijun", "com.catchingnow.icebox"
    )

    fun collect(ctx: Context): List<Signal> {
        val maps = try { File("/proc/self/maps").readText() } catch (_: Throwable) { "" }
        return listOf(
            timedSignal("CLV_MAPS_FOREIGN_APK", "CLONE", "MEDIUM") { mapsForeignApk(ctx, maps) },
            timedSignal("CLV_MAPS_ENGINE_STRING", "CLONE", "MEDIUM") { mapsEngineString(maps) },
            timedSignal("CLV_CGROUP_UID_MISMATCH", "CLONE", "MEDIUM") { cgroupUid() },
            timedSignal("CLV_SIGCERT_MISMATCH", "CLONE", "MEDIUM") { sigcert(ctx) },
            timedSignal("CLV_DEX_CRC", "CLONE", "MEDIUM") { dexCrc(ctx) },
            timedSignal("CLV_PKGNAME_MISMATCH", "CLONE", "MEDIUM") { pkgName(ctx) },
            timedSignal("CLV_AM_SINGLETON_PROXY", "CLONE", "MEDIUM") { amSingletonProxy() },
        )
    }

    private fun mapsForeignApk(ctx: Context, maps: String): Pair<Status, String> {
        if (maps.isBlank()) return Status.INCONCLUSIVE to "maps empty/blocked"
        val pkg = ctx.packageName
        val userApks = maps.lineSequence().map { it.substringAfterLast(' ') }
            .filter { it.endsWith(".apk") && it.startsWith("/data/") }.toSet()
        val foreign = userApks.filter { !it.contains(pkg) }
        return (if (foreign.isNotEmpty()) Status.DETECTED else Status.CLEAN) to
            "userApks=${userApks.size} foreign=${foreign.take(3)}"
    }

    private fun mapsEngineString(maps: String): Pair<Status, String> {
        if (maps.isBlank()) return Status.INCONCLUSIVE to "maps empty/blocked"
        val hit = ENGINE_TOKENS.firstOrNull { maps.contains(it) }
        return (if (hit != null) Status.DETECTED else Status.CLEAN) to (hit?.let { "engine=$it" } ?: "no engine token")
    }

    private fun cgroupUid(): Pair<Status, String> {
        val cg = File("/proc/self/cgroup").readText()
        val m = Regex("uid_(\\d+)").find(cg)?.groupValues?.get(1)?.toIntOrNull()
        val myUid = Process.myUid()
        return when {
            m == null -> Status.INCONCLUSIVE to "no uid token in cgroup"
            m != myUid -> Status.DETECTED to "cgroup uid=$m myUid=$myUid"
            else -> Status.CLEAN to "cgroup uid=$m"
        }
    }

    private fun sigcert(ctx: Context): Pair<Status, String> {
        val baseline = Baselines.signer
            ?: return Status.INCONCLUSIVE to "signer baseline unset - set BlackHex.baseline { signer=... }"
        val pi = ctx.packageManager.getPackageInfo(ctx.packageName, PackageManager.GET_SIGNING_CERTIFICATES)
        val sig = pi.signingInfo?.apkContentsSigners?.firstOrNull()
            ?: return Status.INCONCLUSIVE to "no signer"
        val h = java.security.MessageDigest.getInstance("SHA-256").digest(sig.toByteArray())
            .joinToString("") { b -> "%02x".format(b) }
        return (if (h != baseline) Status.DETECTED else Status.CLEAN) to "signer=${h.take(16)} matchesPin=${h == baseline}"
    }

    private fun dexCrc(ctx: Context): Pair<Status, String> {
        val zf = java.util.zip.ZipFile(ctx.applicationInfo.sourceDir)
        val crc = try { zf.getEntry("classes.dex")?.crc ?: -1L } finally { zf.close() }
        val baseline = Baselines.dexCrc
            ?: return Status.INCONCLUSIVE to "dex-crc baseline unset - pin this: ${java.lang.Long.toHexString(crc)}"
        return (if (crc != baseline) Status.DETECTED else Status.CLEAN) to
            "classes.dex crc=${java.lang.Long.toHexString(crc)} pinned=${java.lang.Long.toHexString(baseline)}"
    }

    private fun pkgName(ctx: Context): Pair<Status, String> {
        val expected = Baselines.packageName
            ?: return Status.INCONCLUSIVE to "packageName baseline unset - set BlackHex.baseline { packageName=... }"
        val pkg = ctx.packageName
        return (if (pkg != expected) Status.DETECTED else Status.CLEAN) to "pkg=$pkg expected=$expected"
    }

    private fun amSingletonProxy(): Pair<Status, String> {
        val amClass = Class.forName("android.app.ActivityManager")
        val f = try { amClass.getDeclaredField("IActivityManagerSingleton") }
            catch (_: Throwable) { amClass.getDeclaredField("gDefault") }
        f.isAccessible = true
        val singleton = f.get(null)
        val getM = Class.forName("android.util.Singleton").getMethod("get").apply { isAccessible = true }
        val iam = getM.invoke(singleton)
        val isProxy = java.lang.reflect.Proxy.isProxyClass(iam.javaClass)
        return (if (isProxy) Status.DETECTED else Status.CLEAN) to "iam=${iam.javaClass.name} proxy=$isProxy"
    }
}

package rasp.sdk

import android.content.Context
import android.content.pm.PackageManager

internal object CustomRomProbe {

    fun collect(ctx: Context): List<Signal> = listOf(
        timedSignal("CROM_FEATURE", "CUSTOM_ROM", "HIGH") { feature(ctx) },
        timedSignal("CROM_PKG_CLUSTER", "CUSTOM_ROM", "MEDIUM") { pkgCluster(ctx) },
    )

    private const val POLICY = " [policy WEIGHT, not malicious]"

    private fun feature(ctx: Context): Pair<Status, String> {
        val pm = ctx.packageManager
        val gos = try { pm.hasSystemFeature("grapheneos.version") } catch (_: Throwable) { false }
        val feats = try { pm.systemAvailableFeatures.mapNotNull { it.name } } catch (_: Throwable) { emptyList() }
        val romFeats = feats.filter {
            val l = it.lowercase()
            l.startsWith("grapheneos.") || l.startsWith("org.microg.") ||
                l.contains("lineage") || l.contains("calyx")
        }
        val raw = "grapheneos.version=$gos romFeatures=$romFeats total=${feats.size}"
        return when {
            gos || romFeats.any { it.lowercase().startsWith("grapheneos.") } ->
                Status.DETECTED to "GrapheneOS system feature present$POLICY: $raw"
            romFeats.isNotEmpty() -> Status.DETECTED to "ROM-declared system feature(s)$POLICY: $raw"
            feats.isEmpty() -> Status.INCONCLUSIVE to "no system features enumerable - cannot judge"
            else -> Status.CLEAN to "no ROM-declared system feature (total=${feats.size})"
        }
    }

    private fun isInstalled(pm: PackageManager, pkg: String): Boolean =
        try { pm.getPackageInfo(pkg, 0); true } catch (_: Throwable) { false }

    private fun pkgCluster(ctx: Context): Pair<Status, String> {
        val pm = ctx.packageManager
        val clusters = linkedMapOf(
            "GrapheneOS" to listOf("app.grapheneos.camera", "app.attestation.auditor",
                                   "app.vanadium.browser", "app.grapheneos.gmscompat"),
            "LineageOS"  to listOf("org.lineageos.updater", "org.lineageos.jelly", "org.lineageos.trebuchet"),
            "CalyxOS"    to listOf("org.calyxos.datura", "com.stevesoltys.seedvault"),
            "/e/OS"      to listOf("foundation.e.blisslauncher", "foundation.e.apps"),
            "microG"     to listOf("org.microg.gms.droidguard", "com.google.android.gsf.microg"),
        )
        val found = StringBuilder()
        var rom: String? = null
        for ((name, pkgs) in clusters) {
            val hit = pkgs.filter { isInstalled(pm, it) }
            if (hit.isNotEmpty()) { found.append("$name$hit "); if (rom == null) rom = name }
        }
        val gms = isInstalled(pm, "com.google.android.gms")
        val play = isInstalled(pm, "com.android.vending")
        val raw = "clusters=[$found] gms=$gms play=$play"
        return when {
            rom != null -> Status.DETECTED to "ROM package cluster ($rom)$POLICY: $raw"
            !gms && !play -> Status.DETECTED to "no GMS and no Play Store (de-Googled indicator)$POLICY: $raw"
            else -> Status.CLEAN to "no ROM package cluster; GMS/Play present: $raw"
        }
    }
}

package rasp.sdk

internal inline fun timedSignal(
    id: String,
    category: String,
    severity: String,
    block: () -> Pair<Status, String>,
): Signal {
    val t0 = System.nanoTime()
    val (st, det) = try { block() } catch (t: Throwable) {
        Status.INCONCLUSIVE to "probe error: ${t.message}"
    }
    return Signal(id, category, severity, st, det, (System.nanoTime() - t0) / 1000)
}

`sdk/src/main/kotlin/rasp/sdk/TamperProbe.kt`:

```kt
package rasp.sdk

import android.content.Context
import android.content.pm.PackageManager
import android.os.Build
import java.security.MessageDigest
import java.util.TreeMap
import java.util.zip.ZipFile

internal object TamperProbe {

    fun collect(ctx: Context): List<Signal> = listOf(
        timedSignal("TAMPER_SIGNER", "TAMPER", "HIGH") { signer(ctx) },
        timedSignal("TAMPER_RESOURCES", "TAMPER", "HIGH") { apkDigest(ctx, Baselines.resources) { it == "resources.arsc" || it == "AndroidManifest.xml" } },
        timedSignal("TAMPER_NATIVELIB", "TAMPER", "HIGH") { apkDigest(ctx, Baselines.nativeLib) { it.startsWith("lib/") && it.endsWith(".so") } },
        timedSignal("TAMPER_REPACKAGER", "TAMPER", "HIGH") { repackager(ctx) },
    )

    private fun signer(ctx: Context): Pair<Status, String> {
        val pm = ctx.packageManager
        val pkg = ctx.packageName
        val certs: Array<android.content.pm.Signature>? =
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
                @Suppress("DEPRECATION")
                val pi = pm.getPackageInfo(pkg, PackageManager.GET_SIGNING_CERTIFICATES)
                pi.signingInfo?.apkContentsSigners
            } else {
                @Suppress("DEPRECATION")
                pm.getPackageInfo(pkg, PackageManager.GET_SIGNATURES).signatures
            }
        val sig = certs?.firstOrNull() ?: return Status.INCONCLUSIVE to "no signer cert"
        val hex = sha256Hex(MessageDigest.getInstance("SHA-256").digest(sig.toByteArray()))
        return verdict(hex, Baselines.signer, "signer")
    }

    private fun apkDigest(ctx: Context, baseline: String?, want: (String) -> Boolean): Pair<Status, String> {
        val src = ctx.applicationInfo.sourceDir
        val perEntry = TreeMap<String, String>()
        ZipFile(src).use { zf ->
            val e = zf.entries()
            while (e.hasMoreElements()) {
                val entry = e.nextElement()
                if (entry.isDirectory || !want(entry.name)) continue
                val md = MessageDigest.getInstance("SHA-256")
                zf.getInputStream(entry).use { ins ->
                    val buf = ByteArray(64 * 1024)
                    while (true) {
                        val n = ins.read(buf); if (n < 0) break; md.update(buf, 0, n)
                    }
                }
                perEntry[entry.name] = sha256Hex(md.digest())
            }
        }
        if (perEntry.isEmpty()) return Status.INCONCLUSIVE to "no matching entries in $src"
        val fold = MessageDigest.getInstance("SHA-256")
        for ((name, dig) in perEntry) { fold.update(name.toByteArray()); fold.update(dig.toByteArray()) }
        val hex = sha256Hex(fold.digest())
        return verdict(hex, baseline, "entries=${perEntry.size}")
    }

    private fun repackager(ctx: Context): Pair<Status, String> {
        val markers = listOf(
            "assets/lspatch/", "origin.apk", "liblspatch.so", "assets/lspatch/origin.apk",
            "assets/xpatch/", "AppClonerCodeClasses.jar", "assets/libAppCloner.zip", "libappcloner.so",
        )
        val hits = ArrayList<String>()
        ZipFile(ctx.applicationInfo.sourceDir).use { zf ->
            val e = zf.entries()
            while (e.hasMoreElements()) {
                val name = e.nextElement().name
                for (m in markers) if (name == m || name.startsWith(m)) { hits += name; break }
            }
        }
        return if (hits.isNotEmpty()) Status.DETECTED to "repackager artifacts: $hits"
        else Status.CLEAN to "no repackager artifacts"
    }

    private fun verdict(live: String, baseline: String?, label: String): Pair<Status, String> =
        when (baseline) {
            null -> Status.INCONCLUSIVE to "$label baseline unset - pin this: $live"
            live -> Status.CLEAN to "$label matches pin: ${live.take(16)}"
            else -> Status.DETECTED to "$label mismatch: live=${live.take(16)} pinned=${baseline.take(16)}"
        }

    private fun sha256Hex(b: ByteArray): String {
        val sb = StringBuilder(b.size * 2)
        for (x in b) { val v = x.toInt() and 0xff; sb.append("0123456789abcdef"[v ushr 4]); sb.append("0123456789abcdef"[v and 0xf]) }
        return sb.toString()
    }
}
