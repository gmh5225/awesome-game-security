# LinoAC — Minecraft Anti-Cheat & Staff Tools

[![Build](https://github.com/lino9999/LinoAC/actions/workflows/build.yml/badge.svg)](https://github.com/lino9999/LinoAC/actions/workflows/build.yml)
[![Download](https://img.shields.io/github/v/release/lino9999/LinoAC?include_prereleases&label=download)](https://github.com/lino9999/LinoAC/releases)
[![License: MIT](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

**LinoAC by Lino** is an open-source Minecraft anti-cheat plugin for Spigot and Paper, targeting **1.21.11 through 26.3**. It combines packet monitoring, movement and combat checks, clickable staff alerts, violation logs, a persistent punishment wave, and moderation commands in a small, modular Java plugin.

**Version 0.1.0 is an experimental preview.** Its 22 independent checks do not reproduce the original plugin's 195 check variants. Detection quality and false-positive rates have not been established by a multiplayer field trial. Automatic punishments and setbacks are disabled by default. See [implementation coverage](docs/REVERSE_ENGINEERING.md) and [verification results](docs/VALIDATION.md) before deployment.

## Features

- Movement checks for speed, unsupported flight, jump height, step height, climbing and sprint state.
- Melee reach checks with interaction attributes, latency allowance and recent player bounding boxes; optional hitbox heuristics and multiple-target detection.
- Packet timing, excessive packet rate, invalid movement values, invalid hotbar slots and sustained high arm-swing rates through PacketEvents.
- Block placement and inventory click monitoring, with optional fast-break, ghost-hand, air-place, liquid-walking, no-slow and fast-bow heuristics.
- Per-check enable switches, buffers, decay, violation thresholds, optional setbacks and configurable punishment commands.
- Clickable alerts with hover details, staff-only verbose samples, player profiles and top violation counts.
- Staff freeze, teleport, knockback, rotation and hotbar-shuffle tools.
- Persistent punishment waves, spaced one entry per second, with optional periodic execution.
- Daily asynchronous violation and punishment logs, bounded queues, retention and paginated in-game access.
- Client-brand alerts and optional brand blocklist/allowlist. Client brands are supplied by the client and can be spoofed.
- Optional Discord-compatible HTTPS webhooks, PlaceholderAPI placeholders and Floodgate detection exemptions.
- A cancellable Java event API, English messages, no telemetry or remote licensing, and no bundled original code.

## Requirements and installation

1. Use Spigot or Paper **1.21.11–26.3**. Folia is not supported by this preview.
2. Use **Java 21** for 1.21.11 and **Java 25** for 26.x servers, following the [Paper runtime requirements](https://docs.papermc.io/paper/getting-started/).
3. Install [PacketEvents 2.14.0](https://github.com/retrooper/packetevents/releases/tag/v2.14.0) in `plugins/`. It includes 26.3 support.
4. Download the JAR from [GitHub Releases](https://github.com/lino9999/LinoAC/releases), place it in `plugins/`, and restart the server.
5. Review `plugins/LinoAC/config.yml`, then use `/linoac status` and `/linoac alerts`.

The same Java 21 plugin JAR is used across the target range. Paper startup and command checks are recorded separately from gameplay tests in [VALIDATION.md](docs/VALIDATION.md). Spigot compatibility uses the public Spigot API; a successful Paper test does not establish Spigot runtime validation. Other server forks and client translators require their own validation.

## Permissions

`linoac.admin` grants all administrative permissions listed above and defaults to operators. Individual staff permissions also default to operators. `linoac.bypass` exempts detections and **defaults to false**, including for operators. Never grant administrative permissions to ordinary players. Invalid protocol values are still discarded before detection exemptions are applied.

## Configuration

The default [config.yml](src/main/resources/config.yml) is the authoritative configuration reference. `/linoac reload` validates numeric ranges before replacing active settings. Reloading resets online violations and provides a short grace period. Invalid YAML or invalid numeric settings leave the previously loaded settings active.

| Option | Behavior |
| --- | --- |
| `settings.minimum-tps` / `maximum-ping` | Suspend flags outside the configured performance conditions |
| `settings.join-grace-ticks` | Suppress join-time detections; teleports add global grace, while velocity, damage and actual riptide grant movement-only grace |
| `settings.violation-reset-seconds` | Reset online violations and buffers on a global interval |
| `settings.automatic-punishments` | Global automatic command gate; false by default |
| `settings.ignore-bedrock` | Exempt recognized Floodgate/Bedrock UUIDs; true by default |
| `settings.excluded-worlds` | World names exempt from detections |
| `limits.*` | Shared rate and distance thresholds |
| `checks.<id>.buffer` / `decay` | Repeated samples needed before a violation and clean-sample decay |
| `checks.<id>.setback` | Optional correction to the last accepted grounded location |
| `checks.<id>.punishable` / `max-violations` / `commands` | Per-check automatic punishment gate, threshold and commands |
| `punishments.manual-commands` | Explicit staff punishment commands; defaults to `ban` |
| `wave.commands` | Commands used by a wave; defaults to `ban` |
| `wave.automatic` / `interval-seconds` | Optional recurring wave execution |
| `wave.queue-automatic-punishments` | Route automatic punishments into the wave |
| `brands.*` | Brand alerts, ignored brands, substring blocklist and allowlist |
| `webhook.*` | Optional HTTPS endpoint and alert/punishment notification switches |
| `messages.*` | Prefix, alert template and core configurable messages; `&` colors supported |

Punishment templates support `%player%`, `%uuid%`, and `%check%`. The alert template supports `%player%`, `%check%`, and `%vl%`. Commands execute as console. Manual staff punishment and manually started waves work independently of the automatic-punishment switch.

Enabled by default: `speed`, `flight`, `jump`, `step`, `fast-climb`, `sprint`, `reach`, `auto-clicker`, `multi-aura`, `fast-place`, `scaffold`, `inventory`, `timer`, `bad-packets`, `packet-flood`.

Optional heuristics disabled by default: `jesus`, `no-slow`, `hitbox`, `fast-bow`, `fast-break`, `ghost-hand`, `air-place`. These need server-specific evaluation. Generic check IDs describe the signal evaluated; they are not claims of complete detection of every cheat in that category.

Logs are stored under `plugins/LinoAC/logs/` with ISO timestamps, UUIDs and player names. Each daily log is capped at 32 MiB; additional records are dropped with a warning. The queue holds 4,096 jobs. Retention is applied at startup, reload and daily rollover. In-game pages contain eight entries, within `settings.recent-log-limit`. Alert preferences and queued wave entries are stored in `state.yml`. Violations, freeze state and verbose mode are session-only.

Wave entries are removed and saved before command dispatch to prevent repeat execution after a crash. A crash between saving and dispatch can skip an entry; failed or API-cancelled commands require staff review and requeueing. Wave execution is a staff moderation tool, not a transactional ban service.

## Integrations and developer API

Install PlaceholderAPI to use `%linoac_violations%`, `%linoac_cps%`, `%linoac_ping%`, `%linoac_brand%`, `%linoac_client%`, `%linoac_frozen%`, `%linoac_alerts%`, `%linoac_tps%`, and `%linoac_version%`. Player values represent online, main-thread snapshots. `%linoac_cps%` measures arm swings, not proven physical clicks.

Configure a Discord-compatible HTTPS webhook to forward rate-limited alerts or punishments. URLs remain in the local config. Delivery uses a bounded worker queue, three-second timeouts and a maximum rate of one notification every two seconds. Notifications are best effort and may be dropped; logs remain the local record.

Java integrations can listen for synchronous, cancellable `LinoViolationEvent` and `LinoPunishmentEvent` in `io.github.lino9999.linoac.api`. Cancelling a violation prevents its VL, alert, log, setback and punishment. Cancelling a punishment prevents command dispatch. Neither API is binary-compatible with the original plugin.

## Build and contribute

Run `./mvnw clean verify` on Linux/macOS or `mvnw.cmd clean verify` on Windows with JDK 21 or newer. Output: `target/LinoAC-0.1.0.jar`. Dependencies are provided by the server or separately installed plugins. Nothing from the original JAR is bundled.

Read [docs/AGENTS.md](docs/AGENTS.md) for the source map, [reverse-engineering notes](docs/REVERSE_ENGINEERING.md) for evidence and limitations, and [SpigotMC BBCode files](docs/spigot/) for resource-page copy. Source code and project assets are published under the MIT license. PacketEvents and PlaceholderAPI retain their own licenses and are separate dependencies.

## Constraints

- Independent implementation, owned by Lino. Do not copy code, strings, encrypted constants or assets from the original JAR.

# LinoAC 0.1.0 — Experimental Preview

LinoAC introduces an independent, modular Minecraft anti-cheat and staff toolkit by Lino, targeting Spigot/Paper 1.21.11 through 26.3.

## Included

- 22 configurable detection signals covering movement, combat, packet timing, placement and inventory activity.
- Clickable alerts, diagnostic samples, profiles, violation rankings and a check-control inventory.

- Client-brand controls, optional HTTPS webhooks, PlaceholderAPI snapshots and Floodgate exemptions.

Install PacketEvents 2.14.0 separately. Use Java 21 for Minecraft 1.21.11 and Java 25 for 26.x. Place `LinoAC-0.1.0.jar` in `plugins/` and restart. Review the generated configuration and run `/linoac status`.

The final JAR was built with Java 21 bytecode. Paper startup and command validation cover 1.21.11, 26.1.1, 26.1.2, 26.2 and 26.3. Temporary domain and protocol-client tests are described in [the validation report](https://github.com/lino9999/LinoAC/blob/main/docs/VALIDATION.md). SHA-256 checksums accompany the JAR.

This is an experimental preview with 22 independent checks. **It is not a complete recreation of the original plugin's 195 check variants.** Several original detector families, transaction-synchronized prediction and Folia support remain unimplemented. There is no measured multiplayer false-positive rate or detection-equivalence claim. Seven optional heuristics are disabled by default.

Paper startup validation does not establish Spigot runtime validation. Gameplay tests used a simulated 1.21.11 client and do not certify every detector or every target version. Review [coverage and remaining gaps](https://github.com/lino9999/LinoAC/blob/main/docs/REVERSE_ENGINEERING.md) before deployment.

The release includes only newly written plugin classes and new project assets. The original JAR, decompiled code, temporary test servers and test files are excluded.

## Material differences and missing functionality

- LinoAC does not recreate the 195 original variants, their tuning or their prediction engine.
- No full movement simulation, transaction acknowledgement engine, client-world replication, velocity prediction, aim statistics, ground-spoof classifier or cheat-specific signature system is implemented.
- No dedicated boat, mounted-entity, elytra, anti-levitation, wall-climb, no-saddle, strafe, fast-use, tower, Baritone, criticals, autoblock or improbable-combination detectors are provided. Some of these states are deliberately exempt to reduce false positives.
- Multiple-target and support/range heuristics do not recreate full KillAura or scaffold detection. Bukkit attack events may omit attempted attacks, cancelled attacks and hits rejected by vanilla.
- Reach uses current and recent server boxes, with conservative allowances; it is not transaction-synchronized lag compensation. Other entities have current boxes only. Spear and trident melee are exempt.
- There is no active runtime comparison against the original, no measured detection-equivalence claim, no guarantee of zero bugs and no performance improvement benchmark against the original.
- Folia, original API binary compatibility, legacy Minecraft versions, Bungee messaging, rich per-check integration hooks for custom mechanics and automatic ghost-block repair are outside this preview.

This release is a reviewable foundation for further independent development. Complete replacement parity remains unfinished and is not advertised in the README, Spigot copy or release notes.

## Limits

- No complete gameplay replay on 26.x, Spigot runtime test, public multiplayer field trial, translator matrix, exhaustive cheat-client suite or large-player-count load benchmark was performed.

[SIZE=5][B]4. Buffers, violations and enforcement[/B][/SIZE]
Each suspicious sample increases a check's buffer. Clean evaluated samples reduce it by decay. Alerts have an additional per-player, per-check cooldown.

[CODE]
checks:
  speed:
    enabled: true
    buffer: 3
    decay: 0.25
    max-violations: 20
    setback: false
    punishable: false
    commands:
      - 'kick %player% LinoAC: Unfair advantage (%check%)'
[/CODE]
Automatic commands require both settings.automatic-punishments and checks.<id>.punishable. A check's threshold is max-violations. Repeated automatic punishments have a sixty-second per-check cooldown. Setbacks are separately controlled and disabled by default.

Command placeholders: %player%, %uuid%, %check%. Commands run as console. The alert message supports %player%, %check%, %vl% and legacy ampersand colors.

[SIZE=5][B]5. Exemptions and thresholds[/B][/SIZE]
[LIST]
[*]settings.minimum-tps and settings.maximum-ping gate detection flags.
[*]settings.join-grace-ticks suppresses join-time flags. Teleports add global grace. Velocity, damage and actual riptide grant movement-only grace, leaving packet-rate and combat checks active. Merely right-clicking a movement item does not grant grace.
[*]Creative/spectator movement, allowed flight, gliding, swimming, vehicles and several special physics states skip movement checks. This preview has no dedicated mounted-entity or elytra detector.
[*]Nearby special blocks suspend ordinary movement heuristics briefly to reduce environmental false positives.
[*]settings.excluded-worlds accepts exact world names.
[*]linoac.bypass skips detection flags. Packet sanitation remains active.
[*]settings.ignore-bedrock exempts Floodgate-recognized players and zero-prefix Bedrock UUIDs by default.
[*]limits.* sets movement, range, arm-swing, placement, inventory and packet rate limits. Timer and packet averages use five-second windows.
[*]settings.violation-reset-seconds resets online violations and buffers globally; defaults to 480 seconds.
[/LIST]
Spear/trident melee is exempt from reach heuristics. Client translation plugins and custom combat or movement mechanics require independent validation. Recognition of every Bedrock setup is not guaranteed.

[SIZE=5][B]6. Persistent punishment wave[/B][/SIZE]
[CODE]
wave:
  automatic: false
  interval-seconds: 3600
  queue-automatic-punishments: false
  commands:
    - 'ban %player% Unfair advantage'
[/CODE]
Queue entries are saved to state.yml. Manual execution is available regardless of the automatic-punishment switch. Set wave.automatic for periodic processing, or wave.queue-automatic-punishments to route qualifying automatic punishments into the queue.

Each entry is removed and saved before its console commands run. This prevents repeat execution after a crash, but a crash between saving and dispatch can skip the entry. Failed or API-cancelled commands require staff review and requeueing. Commands execute one player's batch per second; this is not a transactional ban system.

[SIZE=5][B]7. Logs and stored data[/B][/SIZE]
Violation and punishment logs use daily files under plugins/LinoAC/logs. Entries contain timestamps, UUIDs and names. Reads and writes use one bounded worker with a 4,096-job queue. Each daily log is capped at 32 MiB; extra entries are dropped with a warning. Retention defaults to fourteen days and is applied at startup, reload and daily rollover. The recent-log limit defaults to 200 entries; each in-game page contains eight entries.

state.yml stores alert preferences and queued wave entries. Online violations, freeze and verbose state are temporary. Preferences are saved on toggle and shutdown; wave changes are saved immediately. Back up the plugin directory while the server is stopped.

[SIZE=5][B]8. Client brands[/B][/SIZE]
brands.alerts enables client-brand notices. brands.ignored suppresses notices for exact listed brands. brands.blocked performs case-insensitive substring matching. brands.whitelist-enabled requires a matching substring in brands.whitelist. Blocked brands take precedence. Client-brand values are supplied by clients and can be spoofed, so they are not proof of cheating.

[SIZE=5][B]9. Webhooks and PlaceholderAPI[/B][/SIZE]
Set webhook.enabled and a Discord-compatible HTTPS webhook.url. webhook.alerts and webhook.punishments select notification types. Delivery is best effort, capped at one message per two seconds with a 32-job queue and three-second timeouts. Mentions are disabled. No request is sent when the integration is disabled.

%linoac_alerts%       %linoac_tps%       %linoac_version%
[/CODE]
Player values are immutable snapshots of online data. CPS is an average arm-swing rate, not a physical-click measurement.

[SIZE=5][B]10. Developer API[/B][/SIZE]
The package io.github.lino9999.linoac.api provides synchronous cancellable LinoViolationEvent and LinoPunishmentEvent. Cancelling a violation prevents its VL, alert, audit entry, setback and automatic punishment. Cancelling a punishment prevents command dispatch. Integrations must not block the server thread. The API is independent of the original plugin.

	  }

	    java.nio.file.Files.copy( java.net.URI.create( args[0] ).toURL().openStream(), java.nio.file.Paths.get( args[1] ).toAbsolutePath().normalize() );
	  }
	}
	END

    echo "Checksum validation is not supported for maven-mvnd." >&2
    echo "Please disable validation by removing 'distributionSha256Sum' from your maven-wrapper.properties." >&2
    exit 1
  elif command -v sha256sum >/dev/null; then
    if echo "$distributionSha256Sum  $TMP_DOWNLOAD_DIR/$distributionUrlName" | sha256sum -c - >/dev/null 2>&1; then
      distributionSha256Result=true
    fi
  elif command -v shasum >/dev/null; then
    if echo "$distributionSha256Sum  $TMP_DOWNLOAD_DIR/$distributionUrlName" | shasum -a 256 -c >/dev/null 2>&1; then
      distributionSha256Result=true
    fi
  else
    echo "Checksum validation was requested but neither 'sha256sum' or 'shasum' are available." >&2
    echo "Please install either command, or disable validation by removing 'distributionSha256Sum' from your maven-wrapper.properties." >&2
    exit 1
  fi
  if [ $distributionSha256Result = false ]; then
    echo "Error: Failed to validate Maven distribution SHA-256, your Maven distribution might be compromised." >&2
    echo "If you updated your Maven version, you need to update the specified distributionSha256Sum property." >&2
    exit 1
  fi
fi

# unzip and move
if command -v unzip >/dev/null; then
  unzip ${__MVNW_QUIET_UNZIP:+"$__MVNW_QUIET_UNZIP"} "$TMP_DOWNLOAD_DIR/$distributionUrlName" -d "$TMP_DOWNLOAD_DIR" || die "failed to unzip"
else

fi

actualDistributionDir=""

# First try the expected directory name (for regular distributions)
if [ -d "$TMP_DOWNLOAD_DIR/$distributionUrlNameMain" ]; then
  if [ -f "$TMP_DOWNLOAD_DIR/$distributionUrlNameMain/bin/$MVN_CMD" ]; then
    actualDistributionDir="$distributionUrlNameMain"
  fi
fi

# If not found, search for any directory with the Maven executable (for snapshots)
if [ -z "$actualDistributionDir" ]; then
  # enable globbing to iterate over items
  set +f
  for dir in "$TMP_DOWNLOAD_DIR"/*; do
    if [ -d "$dir" ]; then
      if [ -f "$dir/bin/$MVN_CMD" ]; then
        actualDistributionDir="$(basename "$dir")"
        break
      fi
    fi
  done
  set -f
fi

if [ -z "$actualDistributionDir" ]; then
  verbose "Contents of $TMP_DOWNLOAD_DIR:"
  verbose "$(ls -la "$TMP_DOWNLOAD_DIR")"
  die "Could not find Maven distribution directory in extracted archive"
fi

verbose "Found extracted Maven distribution directory: $actualDistributionDir"
printf %s\\n "$distributionUrl" >"$TMP_DOWNLOAD_DIR/$actualDistributionDir/mvnw.url"
mv -- "$TMP_DOWNLOAD_DIR/$actualDistributionDir" "$MAVEN_HOME" || [ -d "$MAVEN_HOME" ] || die "fail to move MAVEN_HOME"

clean || :
exec_maven "$@"

package io.github.lino9999.linoac;

import com.github.retrooper.packetevents.PacketEvents;
import io.github.lino9999.linoac.check.CombatChecks;

import io.github.lino9999.linoac.listener.GameListener;
import io.github.lino9999.linoac.integration.BedrockSupport;

import io.github.lino9999.linoac.integration.WebhookService;
import io.github.lino9999.linoac.packet.PacketBridge;
import io.github.lino9999.linoac.player.PlayerData;
import io.github.lino9999.linoac.service.Messages;
import io.github.lino9999.linoac.service.PunishmentService;
import io.github.lino9999.linoac.service.ViolationService;

import io.github.lino9999.linoac.storage.StateStore;
import org.bukkit.Bukkit;
import org.bukkit.entity.Player;
import org.bukkit.plugin.java.JavaPlugin;

import java.io.ByteArrayInputStream;
import java.io.DataInputStream;
import java.util.HashMap;
import java.util.Map;
import java.util.UUID;

public final class LinoAC extends JavaPlugin {
    private final Map<UUID, PlayerData> players = new HashMap<>();
    private Settings settings;
    private StateStore store;
    private AuditLog audit;
    private Messages messages;
    private ViolationService violations;
    private PunishmentService punishments;
    private CombatChecks combat;
    private MovementChecks movement;
    private PacketBridge packets;
    private BedrockSupport bedrock;
    private WebhookService webhooks;
    private LinoPlaceholders expansion;
    private final Map<UUID, Map<String, String>> placeholderSnapshots = new java.util.concurrent.ConcurrentHashMap<>();
    private volatile String tpsText = "20.00";
    private long tick;
    private long previousTick;
    private double smoothedTick = 50;
    private double tickScale = 1;

    public void onEnable() {
        try {
            if (isFolia()) throw new IllegalStateException("This build requires the Spigot/Paper main-thread scheduler. Folia is not supported.");
            saveDefaultConfig();
            settings = new Settings(this);
            store = new StateStore(this);
            audit = new AuditLog(this, settings.integer("settings.log-retention-days"));
            messages = new Messages(this);
            violations = new ViolationService(this);
            punishments = new PunishmentService(this);
            combat = new CombatChecks(this);
            movement = new MovementChecks(this);
            packets = new PacketBridge(this);
            bedrock = new BedrockSupport();
            webhooks = new WebhookService(this);
            PacketEvents.getAPI().getEventManager().registerListener(packets);
            Bukkit.getPluginManager().registerEvents(new GameListener(this), this);
            LinoCommand command = new LinoCommand(this);
            Bukkit.getPluginManager().registerEvents(command, this);
            for (String name : new String[]{"linoac", "lacalerts", "lacwave", "laclogs", "lacpunishments"}) {
                var registered = java.util.Objects.requireNonNull(getCommand(name));
                registered.setExecutor(command);
                registered.setTabCompleter(command);
            }
            getServer().getMessenger().registerIncomingPluginChannel(this, "minecraft:brand", this::brand);
            Bukkit.getOnlinePlayers().forEach(this::join);
            if (Bukkit.getPluginManager().isPluginEnabled("PlaceholderAPI")) {
                expansion = new LinoPlaceholders(this);
                expansion.register();
            }
            previousTick = System.nanoTime();
            Bukkit.getScheduler().runTaskTimer(this, this::tickPlayers, 1, 1);
            getLogger().info("LinoAC " + getDescription().getVersion() + " by Lino enabled with " + io.github.lino9999.linoac.check.CheckType.values().length + " checks. Automatic punishments: " + settings.enabled("settings.automatic-punishments"));
        } catch (Exception e) {
            getLogger().severe("Unable to enable LinoAC: " + e.getMessage());
            Bukkit.getPluginManager().disablePlugin(this);
        }
    }

    public void onDisable() {
        Bukkit.getScheduler().cancelTasks(this);
        if (packets != null) {
            PacketEvents.getAPI().getEventManager().unregisterListener(packets);
            packets.clear();
        }
        if (store != null) {
            players.forEach((id, data) -> store.setAlerts(id, data.alerts));
            try { store.save(); } catch (Exception e) { getLogger().severe("Unable to save state: " + e.getMessage()); }
        }
        players.clear();
        placeholderSnapshots.clear();
        if (expansion != null) expansion.unregister();
        if (webhooks != null) webhooks.close();
        if (audit != null) audit.close();
    }

    private void tickPlayers() {
        tick++;
        long now = System.nanoTime();
        double elapsed = (now - previousTick) / 1_000_000d;
        previousTick = now;
        smoothedTick = smoothedTick * .95 + Math.max(50, elapsed) * .05;
        tickScale = Math.max(1, Math.min(5, elapsed / 50));
        tpsText = String.format(java.util.Locale.ROOT, "%.2f", tps());
        for (Player player : Bukkit.getOnlinePlayers()) {
            PlayerData data = data(player);
            if (elapsed > 110) exempt(data, 40);
            packets.tick(player, data);
            movement.tick(player, data);
            data.attacked.clear();
            placeholderSnapshots.put(data.id, Map.of("violations", Integer.toString(data.totalViolations()), "cps", Integer.toString(data.swings),
                    "ping", Integer.toString(player.getPing()), "brand", data.brand, "client", data.clientVersion,
                    "frozen", Boolean.toString(data.frozen), "alerts", Boolean.toString(data.alerts)));
            if (tick % (settings.integer("settings.violation-reset-seconds") * 20L) == 0) data.reset();
        }
        punishments.tick(tick);
        if (tick % 1200 == 0) {
            try { store.save(); } catch (java.io.IOException e) { getLogger().warning("Unable to save state: " + e.getMessage()); }
        }
    }

    public void join(Player player) {
        PlayerData data = new PlayerData(player.getUniqueId(), tick + settings.integer("settings.join-grace-ticks"));
        data.alerts = store.alerts(data.id, settings.enabled("settings.alerts-on-join"));
        data.clientVersion = packets.clientVersion(player);
        data.bedrock = bedrock.isBedrock(data.id);
        players.put(data.id, data);
        packets.add(player);
    }

    public void quit(Player player) {
        PlayerData data = players.remove(player.getUniqueId());
        placeholderSnapshots.remove(player.getUniqueId());
        packets.remove(player.getUniqueId());
        if (data == null) return;
        store.setAlerts(data.id, data.alerts);
        if (data.frozen) {
            getLogger().warning(player.getName() + " disconnected while frozen.");
            audit.write("violations", data.id, player.getName(), "Disconnected while frozen");
            for (Player staff : Bukkit.getOnlinePlayers()) if (staff.hasPermission("linoac.freeze")) messages.send(staff, "&c" + player.getName() + " disconnected while frozen.");
        }
    }

    private void brand(String channel, Player player, byte[] bytes) {
        if (bytes.length > 1024) return;
        try {
            DataInputStream input = new DataInputStream(new ByteArrayInputStream(bytes));
            int length = 0;
            int shift = 0;
            int value;
            do {
                if (shift >= 35) return;
                value = input.readUnsignedByte();
                length |= (value & 127) << shift;
                shift += 7;
            } while ((value & 128) != 0);
            if (length < 0 || length > 256 || length > input.available()) return;
            String brand = new String(input.readNBytes(length), java.nio.charset.StandardCharsets.UTF_8).replaceAll("[^A-Za-z0-9_. /+-]", "");
            PlayerData data = data(player);
            if (brand.equals(data.brand)) return;
            data.brand = brand;
            String normalized = brand.toLowerCase(java.util.Locale.ROOT);
            boolean blocked = settings.list("brands.blocked").stream().filter(s -> !s.isBlank()).anyMatch(s -> normalized.contains(s.toLowerCase(java.util.Locale.ROOT)));
            boolean whitelisted = settings.list("brands.whitelist").stream().filter(s -> !s.isBlank()).anyMatch(s -> normalized.contains(s.toLowerCase(java.util.Locale.ROOT)));
            if (blocked || settings.enabled("brands.whitelist-enabled") && !whitelisted) {
                player.kickPlayer(messages.color(settings.text("messages.blocked-brand")));
                return;
            }
            if (settings.enabled("brands.alerts") && !settings.list("brands.ignored").contains(normalized)) {
                for (Player staff : Bukkit.getOnlinePlayers()) if (data(staff).alerts && staff.hasPermission("linoac.alerts")) messages.send(staff, "&f" + player.getName() + " &7joined using &f" + brand + "&7.");
            }
        } catch (java.io.IOException ignored) {
            getLogger().fine("Ignored malformed client brand from " + player.getName());
        }
    }

    public void reloadSettings() throws Exception {
        Settings replacement = new Settings(this);
        settings = replacement;
        audit.retention(replacement.integer("settings.log-retention-days"));
        players.values().forEach(data -> { data.reset(); exempt(data, 40); });
    }

    public PlayerData data(Player player) {
        return players.computeIfAbsent(player.getUniqueId(), id -> new PlayerData(id, tick + settings.integer("settings.join-grace-ticks")));
    }

    public void exempt(PlayerData data, int ticks) {
        data.graceUntil = Math.max(data.graceUntil, tick + ticks);

        data.previousDy = 0;
    }

        data.movementGraceUntil = Math.max(data.movementGraceUntil, tick + ticks);
        data.airTicks = 0;
        data.previousDy = 0;
    }

    private boolean isFolia() {

package io.github.lino9999.linoac.check;

import io.github.lino9999.linoac.LinoAC;
import io.github.lino9999.linoac.player.PlayerData;
import io.github.lino9999.linoac.util.Environment;
import io.github.lino9999.linoac.util.Geometry;
import org.bukkit.Location;
import org.bukkit.entity.Entity;
import org.bukkit.entity.LivingEntity;
import org.bukkit.entity.Player;
import org.bukkit.util.BoundingBox;
import org.bukkit.util.Vector;

import java.util.ArrayList;
import java.util.List;

public final class CombatChecks {
    private final LinoAC plugin;

    public CombatChecks(LinoAC plugin) { this.plugin = plugin; }

    public void attack(Player player, LivingEntity target) {
        PlayerData data = plugin.data(player);
        data.lastCombat = plugin.tick();
        if (!plugin.violations().eligible(player, data) || player.isInsideVehicle() || target.isInsideVehicle()
                || player.getGameMode() == org.bukkit.GameMode.CREATIVE || player.getGameMode() == org.bukkit.GameMode.SPECTATOR) return;
        String weapon = player.getInventory().getItemInMainHand().getType().name();
        if (weapon.contains("SPEAR") || weapon.contains("TRIDENT")) return;
        Location eye = player.getEyeLocation();
        Vector origin = eye.toVector();
        double range = Environment.attribute(player, "entity_interaction_range", 3);
        double allowance = plugin.settings().number("limits.reach-margin") + Math.min(.6, player.getPing() * .002);
        List<BoundingBox> boxes = new ArrayList<>();
        boxes.add(target.getBoundingBox().clone());
        if (target instanceof Player victim) {
            PlayerData other = plugin.data(victim);
            boxes.addAll(other.history);
        }
        double distance = boxes.stream().mapToDouble(box -> Geometry.distance(origin, box)).min().orElse(0);
        boolean intersects = boxes.stream().anyMatch(box -> box.clone().expand(.25 + allowance)
                .rayTrace(origin, eye.getDirection(), range + allowance + 1) != null);
        plugin.violations().sample(player, data, CheckType.REACH, distance > range + allowance,
                "distance=" + String.format(java.util.Locale.ROOT, "%.3f", distance));
        plugin.violations().sample(player, data, CheckType.HITBOX, !intersects && distance > 1, "target=" + target.getType().name());
        data.attacked.add(target.getEntityId());
        plugin.violations().sample(player, data, CheckType.MULTI_AURA, data.attacked.size() > 3, "targets=" + data.attacked.size());
    }

    public boolean obstructed(Player player, Location target) {
        Vector direction = target.toVector().subtract(player.getEyeLocation().toVector());
        double distance = direction.length();
        if (distance < .1 || distance > 12 || !player.getWorld().equals(target.getWorld())) return false;
        var hit = player.getWorld().rayTraceBlocks(player.getEyeLocation(), direction.normalize(), distance,
                org.bukkit.FluidCollisionMode.NEVER, true);
        return hit != null && hit.getHitBlock() != null && !hit.getHitBlock().equals(target.getBlock())
                && hit.getHitPosition().distance(player.getEyeLocation().toVector()) < distance - .8;
    }
}

package io.github.lino9999.linoac.check;

import io.github.lino9999.linoac.LinoAC;
import io.github.lino9999.linoac.player.PlayerData;
import io.github.lino9999.linoac.util.Environment;
import org.bukkit.GameMode;
import org.bukkit.Location;
import org.bukkit.entity.Player;
import org.bukkit.potion.PotionEffectType;

public final class MovementChecks {
    private final LinoAC plugin;

    public MovementChecks(LinoAC plugin) { this.plugin = plugin; }

    public void tick(Player player, PlayerData data) {
        Location current = player.getLocation();
        Location previous = data.previous;
        data.previous = current.clone();
        data.history.addLast(player.getBoundingBox().clone());
        if (data.history.size() > 12) data.history.removeFirst();
        if (previous == null || !previous.getWorld().equals(current.getWorld())) return;
        boolean ground = Environment.supported(player);
        boolean wasGround = data.previousGround;
        data.previousGround = ground;
        data.airTicks = ground ? 0 : data.airTicks + 1;
        double dy = current.getY() - previous.getY();
        double lastDy = data.previousDy;
        data.previousDy = dy;
        if (!plugin.violations().eligible(player, data) || plugin.tick() < data.movementGraceUntil || player.getGameMode() != GameMode.SURVIVAL
                && player.getGameMode() != GameMode.ADVENTURE || player.getAllowFlight() || player.isFlying()
                || player.isGliding() || player.isRiptiding() || player.isInsideVehicle() || player.isSwimming()
                || player.isSleeping() || player.hasPotionEffect(PotionEffectType.LEVITATION)
                || player.hasPotionEffect(PotionEffectType.SLOW_FALLING) || player.hasPotionEffect(PotionEffectType.JUMP_BOOST)) {
            data.airTicks = 0;
            return;
        }
        if (!current.getWorld().isChunkLoaded(current.getBlockX() >> 4, current.getBlockZ() >> 4)) return;
        double dx = current.getX() - previous.getX();
        double dz = current.getZ() - previous.getZ();
        double horizontal = Math.hypot(dx, dz);
        boolean special = Environment.special(player);
        if (special) data.environmentUntil = plugin.tick() + 12;
        double speedAttribute = Environment.attribute(player, "movement_speed", .1);
        double speedLimit = (.38 + Math.max(0, speedAttribute - .1) * 3.8)
                * plugin.settings().number("limits.speed-multiplier") * plugin.tickScale();
        if (plugin.tick() >= data.environmentUntil && !player.isClimbing()) {
            plugin.violations().sample(player, data, CheckType.SPEED, horizontal > speedLimit,
                    "distance=" + format(horizontal) + " limit=" + format(speedLimit));
            boolean hovering = Math.abs(dy) < .005 && Math.abs(lastDy) < .005;
            boolean rising = dy > .1 && dy >= lastDy - .005;
            plugin.violations().sample(player, data, CheckType.FLIGHT, data.airTicks > 14 && (hovering || rising), "air-ticks=" + data.airTicks);
            double jump = Environment.attribute(player, "jump_strength", .42) + .18;
            plugin.violations().sample(player, data, CheckType.JUMP, wasGround && !ground && dy > jump * plugin.tickScale(), "rise=" + format(dy));
            double step = Environment.attribute(player, "step_height", .6) + .15;
            plugin.violations().sample(player, data, CheckType.STEP, ground && wasGround && dy > step * plugin.tickScale(), "rise=" + format(dy));
            plugin.violations().sample(player, data, CheckType.NO_SLOW,
                    player.isHandRaised() && ground && wasGround && horizontal > Math.max(.32, speedLimit * .8), "distance=" + format(horizontal));
        }
        plugin.violations().sample(player, data, CheckType.FAST_CLIMB, player.isClimbing() && dy > .35 * plugin.tickScale(), "rise=" + format(dy));
        boolean liquidBelow = current.clone().subtract(0, .2, 0).getBlock().isLiquid();
        data.liquidTicks = liquidBelow && !player.isInWater() && !ground && Math.abs(dy) < .005 ? data.liquidTicks + 1 : 0;
        plugin.violations().sample(player, data, CheckType.JESUS, data.liquidTicks > 20, "liquid-ticks=" + data.liquidTicks);
        plugin.violations().sample(player, data, CheckType.SPRINT, player.isSprinting() && player.getFoodLevel() <= 6, "food=" + player.getFoodLevel());
        if (ground && !special && data.buffers.getOrDefault(CheckType.SPEED, 0d) == 0 && data.buffers.getOrDefault(CheckType.STEP, 0d) == 0) data.safe = current.clone();
    }

    private String format(double value) { return String.format(java.util.Locale.ROOT, "%.3f", value); }
}

            case "remove" -> {
                if (args.length < 3) throw new IllegalArgumentException("Usage: /lac wave remove <player>");
                UUID id = plugin.store().wave().entrySet().stream().filter(e -> e.getValue().equalsIgnoreCase(args[2])).map(Map.Entry::getKey).findFirst()
                        .orElseThrow(() -> new IllegalArgumentException("Player is not queued."));
                plugin.punishments().remove(id);
                plugin.messages().send(sender, "&aRemoved player from the wave.");
            }
            case "list" -> plugin.messages().send(sender, "&7Queued: &f" + String.join(", ", plugin.store().wave().values()));
            case "execute" -> plugin.messages().send(sender, "&7Wave entries scheduled: &f" + plugin.punishments().startWave());
            default -> throw new IllegalArgumentException("Usage: /lac wave " + syntax("wave"));
        }
    }

    private void logs(CommandSender sender, String[] args, String kind) {
        if (args.length < 2 || !args[1].matches("[A-Za-z0-9_]{1,16}")) throw new IllegalArgumentException("Usage: /lac " + kind + " <player> [page]");
        int page = args.length > 2 ? Integer.parseInt(args[2]) : 1;
        int limit = plugin.settings().integer("settings.recent-log-limit");
        if (page < 1 || page > (limit + 7) / 8) throw new IllegalArgumentException("Page is outside the configured recent-log limit.");
        plugin.audit().read(kind.equals("logs") ? "violations" : "punishments", args[1], page, limit, lines -> {
            if (!plugin.isEnabled()) return;
            Bukkit.getScheduler().runTask(plugin, () -> {
                if (sender instanceof Player player && !player.isOnline()) return;
                if (!sender.hasPermission("linoac.logs")) return;
                plugin.messages().send(sender, "&7" + kind + " for &f" + args[1] + " &7| Page " + page);
                if (lines.isEmpty()) plugin.messages().send(sender, "&7No records found.");
                for (String line : lines) plugin.messages().send(sender, "&7" + line.replace('\t', ' '));
            });
        });
    }

    private void configure(CommandSender sender, CheckType type, boolean enabled) throws Exception {
        File file = new File(plugin.getDataFolder(), "config.yml");
        YamlConfiguration yaml = new YamlConfiguration();
        yaml.load(file);
        yaml.set("checks." + type.id() + ".enabled", enabled);
        yaml.save(file);
        plugin.reloadSettings();
        plugin.messages().send(sender, "&7" + type.id() + " &fenabled: " + enabled);
    }

    private Player target(String[] args, int index) {
        if (args.length <= index) throw new IllegalArgumentException("Specify an online player. See /lac help.");
        Player player = Bukkit.getPlayerExact(args[index]);
        if (player == null) throw new IllegalArgumentException("Player is not online.");
        return player;
    }

    private Player requirePlayer(CommandSender sender) {
        if (!(sender instanceof Player player)) throw new IllegalArgumentException("This command requires a player.");
        return player;
    }

    private CheckType check(String[] args, int index) {
        if (args.length <= index) throw new IllegalArgumentException("Specify a check ID. See /lac checks.");
        return CheckType.find(args[index]).orElseThrow(() -> new IllegalArgumentException("Unknown check ID. See /lac checks."));
    }

    private String[] shortcut(String command, String[] original) {
        String first = switch (command) {
            case "lacalerts" -> "alerts";
            case "lacwave" -> "wave";
            case "laclogs" -> "logs";
            case "lacpunishments" -> "punishlogs";
            default -> "";
        };
        if (first.isEmpty()) return original;
        String[] result = new String[original.length + 1];
        result[0] = first;
        System.arraycopy(original, 0, result, 1, original.length);
        return result;
    }

    public List<String> onTabComplete(CommandSender sender, Command command, String alias, String[] original) {
        String[] args = shortcut(command.getName(), original);
        List<String> candidates;
        if (args.length <= 1) candidates = permissions.entrySet().stream().filter(e -> sender.hasPermission("linoac." + e.getValue())).map(Map.Entry::getKey).sorted().toList();
        else {
            String sub = args[0].toLowerCase(Locale.ROOT);
            if (!sender.hasPermission("linoac." + permissions.getOrDefault(sub, "admin"))) return List.of();
            if (List.of("enable", "disable", "describe").contains(sub) && args.length == 2) candidates = Arrays.stream(CheckType.values()).map(CheckType::id).toList();
            else if (sub.equals("wave") && args.length == 2) candidates = List.of("add", "remove", "list", "execute");
            else if (sub.equals("wave") && args.length == 3 && args[1].equalsIgnoreCase("remove")) candidates = new ArrayList<>(plugin.store().wave().values());
            else if (args.length == 2 && !syntax(sub).isEmpty() || sub.equals("wave") && args.length == 3) candidates = Bukkit.getOnlinePlayers().stream().filter(p -> !(sender instanceof Player viewer) || viewer.canSee(p)).map(Player::getName).toList();
            else candidates = List.of();
        }
        String prefix = args.length == 0 ? "" : args[args.length - 1].toLowerCase(Locale.ROOT);
        return candidates.stream().filter(s -> s.toLowerCase(Locale.ROOT).startsWith(prefix)).toList();
    }

    private void menu(Player player) {
        CheckMenu holder = new CheckMenu();
        holder.inventory = Bukkit.createInventory(holder, 27, "LinoAC Checks");
        for (CheckType type : CheckType.values()) {
            boolean enabled = plugin.settings().policy(type).enabled();
            ItemStack item = new ItemStack(enabled ? Material.LIME_DYE : Material.GRAY_DYE);
            var meta = item.getItemMeta();
            meta.setDisplayName(plugin.messages().color((enabled ? "&a" : "&c") + type.id()));
            meta.setLore(List.of(type.description(), "Category: " + type.category(), "Enabled: " + enabled, "Click to toggle (linoac.manage)."));
            item.setItemMeta(meta);
            holder.inventory.setItem(type.ordinal(), item);
        }
        player.openInventory(holder.inventory);
    }

    @EventHandler public void clickMenu(InventoryClickEvent event) {
        if (!(event.getView().getTopInventory().getHolder() instanceof CheckMenu)) return;
        event.setCancelled(true);
        if (!(event.getWhoClicked() instanceof Player player) || event.getRawSlot() < 0 || event.getRawSlot() >= CheckType.values().length
                || !player.hasPermission("linoac.manage") || plugin.data(player).frozen) return;
        CheckType type = CheckType.values()[event.getRawSlot()];
        try { configure(player, type, !plugin.settings().policy(type).enabled()); menu(player); }
        catch (Exception e) { plugin.messages().send(player, "&cUnable to update configuration: " + e.getMessage()); }
    }

    @EventHandler public void dragMenu(InventoryDragEvent event) {
        if (event.getView().getTopInventory().getHolder() instanceof CheckMenu) event.setCancelled(true);
    }

    private static final class CheckMenu implements InventoryHolder {
        private Inventory inventory;
        public Inventory getInventory() { return inventory; }
    }

package io.github.lino9999.linoac.integration;

import io.github.lino9999.linoac.LinoAC;

import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.ThreadPoolExecutor;
import java.util.concurrent.TimeUnit;

public final class WebhookService implements AutoCloseable {
    private final LinoAC plugin;
    private final HttpClient client = HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(3)).followRedirects(HttpClient.Redirect.NEVER).build();
    private final ThreadPoolExecutor executor = new ThreadPoolExecutor(1, 1, 0, TimeUnit.MILLISECONDS,
            new ArrayBlockingQueue<>(32), action -> {
                Thread thread = new Thread(action, "LinoAC-webhook");
                thread.setDaemon(true);
                return thread;
            });
    private long nextSend;

    public WebhookService(LinoAC plugin) { this.plugin = plugin; }

    public void send(String kind, String message) {
        if (!plugin.settings().enabled("webhook.enabled") || !plugin.settings().enabled("webhook." + kind)) return;
        long now = System.nanoTime();
        if (now < nextSend) return;
        nextSend = now + TimeUnit.SECONDS.toNanos(2);
        URI uri;
        try {
            uri = URI.create(plugin.settings().text("webhook.url"));
            if (!"https".equals(uri.getScheme()) || uri.getHost() == null || uri.getUserInfo() != null) return;
        } catch (IllegalArgumentException e) { return; }
        String content = message.replace("\\", "\\\\").replace("\"", "\\\"").replaceAll("[\\p{Cntrl}]", " ");
        HttpRequest request = HttpRequest.newBuilder(uri).timeout(Duration.ofSeconds(3))
                .header("Content-Type", "application/json")
                .POST(HttpRequest.BodyPublishers.ofString("{\"content\":\"" + content + "\",\"allowed_mentions\":{\"parse\":[]}}"))
                .build();
        try {
            executor.execute(() -> {
                try {
                    int status = client.send(request, HttpResponse.BodyHandlers.discarding()).statusCode();
                    if (status < 200 || status > 299) plugin.getLogger().fine("Webhook returned HTTP " + status);
                } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
                catch (Exception e) { plugin.getLogger().fine("Webhook delivery failed."); }
            });
        } catch (java.util.concurrent.RejectedExecutionException ignored) { plugin.getLogger().fine("Webhook queue is full."); }
    }

    public void close() {
        executor.shutdownNow();
        client.close();
    }
}

        data.bowStarted = 0;
    }

    private boolean survival(Player player) { return player.getGameMode() == GameMode.SURVIVAL || player.getGameMode() == GameMode.ADVENTURE; }
}

package io.github.lino9999.linoac.packet;

import com.github.retrooper.packetevents.PacketEvents;
import com.github.retrooper.packetevents.event.PacketListenerAbstract;
import com.github.retrooper.packetevents.event.PacketListenerPriority;
import com.github.retrooper.packetevents.event.PacketReceiveEvent;
import com.github.retrooper.packetevents.protocol.packettype.PacketType;
import com.github.retrooper.packetevents.wrapper.play.client.WrapperPlayClientHeldItemChange;
import com.github.retrooper.packetevents.wrapper.play.client.WrapperPlayClientPlayerFlying;
import io.github.lino9999.linoac.LinoAC;
import io.github.lino9999.linoac.check.CheckType;
import io.github.lino9999.linoac.player.PlayerData;
import org.bukkit.entity.Player;

import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

public final class PacketBridge extends PacketListenerAbstract {
    private final LinoAC plugin;
    private final Map<UUID, PacketSample> samples = new ConcurrentHashMap<>();
    private final Map<UUID, RateWindow> windows = new java.util.HashMap<>();

    public PacketBridge(LinoAC plugin) {
        super(PacketListenerPriority.NORMAL);
        this.plugin = plugin;
    }

    public void add(Player player) { samples.put(player.getUniqueId(), new PacketSample()); windows.remove(player.getUniqueId()); }
    public void remove(UUID id) { samples.remove(id); windows.remove(id); }
    public void clear() { samples.clear(); windows.clear(); }

    public void onPacketReceive(PacketReceiveEvent event) {
        UUID id = event.getUser().getUUID();
        if (id == null || event.isCancelled()) return;
        PacketSample sample = samples.get(id);
        if (sample == null) return;
        boolean movement = WrapperPlayClientPlayerFlying.isFlying(event.getPacketType());
        boolean invalid = false;
        if (movement) {
            var flying = new WrapperPlayClientPlayerFlying(event);
            var location = flying.getLocation();
            if (flying.hasPositionChanged()) {
                invalid = !Double.isFinite(location.getX()) || !Double.isFinite(location.getY()) || !Double.isFinite(location.getZ())
                        || Math.abs(location.getX()) > 30_000_001 || Math.abs(location.getZ()) > 30_000_001 || Math.abs(location.getY()) > 20_000_000;
            }
            if (flying.hasRotationChanged()) invalid |= !Float.isFinite(location.getYaw()) || !Float.isFinite(location.getPitch()) || Math.abs(location.getPitch()) > 90;
        } else if (event.getPacketType() == PacketType.Play.Client.HELD_ITEM_CHANGE) {
            int slot = new WrapperPlayClientHeldItemChange(event).getSlot();
            invalid = slot < 0 || slot > 8;
        }
        if (invalid) event.setCancelled(true);
        sample.record(movement, event.getPacketType() == PacketType.Play.Client.ANIMATION, invalid);
    }

    public void tick(Player player, PlayerData data) {
        PacketSample sample = samples.get(data.id);
        if (sample == null) return;
        PacketSample.Snapshot snapshot = sample.drain();
        if (snapshot.invalid() > 0) plugin.violations().flag(player, data, CheckType.BAD_PACKETS, "invalid=" + snapshot.invalid());
        long now = System.nanoTime();
        RateWindow window = windows.computeIfAbsent(data.id, ignored -> new RateWindow(now));
        if (!plugin.violations().eligible(player, data)) {
            windows.put(data.id, new RateWindow(now));
            return;
        }
        window.packets += snapshot.packets();
        window.moves += snapshot.moves();
        window.swings += snapshot.swings();
        double seconds = (now - window.started) / 1_000_000_000d;
        if (seconds >= 5) {
            double cps = window.swings / seconds;
            data.swings = (int) Math.round(cps);
            plugin.violations().sample(player, data, CheckType.TIMER,
                    window.moves > seconds * 20 * plugin.settings().number("limits.timer-multiplier") + 20,
                    "movement-rate=" + Math.round(window.moves / seconds));
            plugin.violations().sample(player, data, CheckType.PACKET_FLOOD,
                    window.packets / seconds > plugin.settings().number("limits.maximum-packets"), "packet-rate=" + Math.round(window.packets / seconds));
            plugin.violations().sample(player, data, CheckType.AUTO_CLICKER,
                    plugin.tick() - data.lastCombat < 120 && cps > plugin.settings().number("limits.maximum-cps"), "cps=" + data.swings);
            windows.put(data.id, new RateWindow(now));
        }
    }

    public String clientVersion(Player player) {
        var user = PacketEvents.getAPI().getPlayerManager().getUser(player);
        return user == null ? "unknown" : user.getClientVersion().getReleaseName();
    }

    private static final class RateWindow {
        private final long started;
        private int packets;
        private int moves;
        private int swings;
        private RateWindow(long started) { this.started = started; }
    }
}

package io.github.lino9999.linoac.service;

import io.github.lino9999.linoac.LinoAC;
import io.github.lino9999.linoac.api.LinoPunishmentEvent;
import org.bukkit.Bukkit;

import java.io.IOException;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.UUID;

public final class PunishmentService {
    private final LinoAC plugin;
    private final java.util.ArrayDeque<Map.Entry<UUID, String>> running = new java.util.ArrayDeque<>();
    private long nextEntryTick;

    public PunishmentService(LinoAC plugin) { this.plugin = plugin; }

    public boolean execute(UUID id, String name, String reason, List<String> templates) {
        if (!name.matches("[A-Za-z0-9_]{1,16}")) return false;
        List<String> commands = templates.stream().map(s -> s.replace("%player%", name)
                .replace("%uuid%", id.toString()).replace("%check%", reason)).toList();
        LinoPunishmentEvent event = new LinoPunishmentEvent(id, name, reason, commands);
        Bukkit.getPluginManager().callEvent(event);
        if (event.isCancelled()) return false;
        for (String command : commands) {
            boolean result = Bukkit.dispatchCommand(Bukkit.getConsoleSender(), command);
            plugin.audit().write("punishments", id, name, "reason=" + reason + " command=" + command + " dispatched=" + result);
        }
        plugin.webhooks().send("punishments", "[LinoAC] " + name + " punished: " + reason);
        return true;
    }

    public void add(UUID id, String name) throws IOException {
        String previous = plugin.store().wave().put(id, name);
        try { plugin.store().save(); }
        catch (IOException e) {
            if (previous == null) plugin.store().wave().remove(id); else plugin.store().wave().put(id, previous);
            throw e;
        }
    }

    public boolean remove(UUID id) throws IOException {
        String name = plugin.store().wave().remove(id);
        if (name == null) return false;
        try { plugin.store().save(); }
        catch (IOException e) { plugin.store().wave().put(id, name); throw e; }
        running.removeIf(entry -> entry.getKey().equals(id));
        return true;
    }

    public int startWave() {
        if (!running.isEmpty()) return 0;
        running.addAll(new ArrayList<>(plugin.store().wave().entrySet()));
        return running.size();
    }

    public void tick(long tick) {
        if (plugin.settings().enabled("wave.automatic") && tick % (plugin.settings().integer("wave.interval-seconds") * 20L) == 0) startWave();
        if (running.isEmpty() || tick < nextEntryTick) return;
        var entry = running.peek();
        try {
            if (remove(entry.getKey())) execute(entry.getKey(), entry.getValue(), "wave", plugin.settings().list("wave.commands"));
        } catch (IOException e) {
            running.clear();
            plugin.getLogger().severe("Wave paused: " + e.getMessage());
        }
        nextEntryTick = tick + 20;
    }
}

package io.github.lino9999.linoac.service;

import io.github.lino9999.linoac.LinoAC;
import io.github.lino9999.linoac.api.LinoViolationEvent;
import io.github.lino9999.linoac.check.CheckPolicy;
import io.github.lino9999.linoac.check.CheckType;
import io.github.lino9999.linoac.player.PlayerData;
import net.md_5.bungee.api.chat.ClickEvent;
import net.md_5.bungee.api.chat.HoverEvent;
import net.md_5.bungee.api.chat.TextComponent;
import org.bukkit.Bukkit;
import org.bukkit.entity.Player;

public final class ViolationService {
    private final LinoAC plugin;

    public ViolationService(LinoAC plugin) { this.plugin = plugin; }

    public boolean eligible(Player player, PlayerData data) {
        return player.isOnline() && !player.isDead() && !data.frozen && !player.hasPermission("linoac.bypass")
                && !(data.bedrock && plugin.settings().enabled("settings.ignore-bedrock"))
                && plugin.tick() >= data.graceUntil && player.getPing() <= plugin.settings().integer("settings.maximum-ping")
                && plugin.tps() >= plugin.settings().number("settings.minimum-tps")
                && !plugin.settings().excludedWorlds().contains(player.getWorld().getName());
    }

    public void reward(PlayerData data, CheckType type) {
        data.buffers.computeIfPresent(type, (key, value) -> Math.max(0, value - plugin.settings().policy(type).decay()));
    }

    public void sample(Player player, PlayerData data, CheckType type, boolean suspicious, String detail) {
        if (suspicious) flag(player, data, type, detail); else reward(data, type);
    }

    public void flag(Player player, PlayerData data, CheckType type, String detail) {
        CheckPolicy policy = plugin.settings().policy(type);
        if (!policy.enabled() || !eligible(player, data)) return;
        long tick = plugin.tick();
        if (data.lastFlags.getOrDefault(type, -1L) == tick) return;
        data.lastFlags.put(type, tick);
        double buffer = Math.min(policy.buffer(), data.buffers.getOrDefault(type, 0d) + 1);
        data.buffers.put(type, buffer);
        if (buffer < policy.buffer()) {
            verbose(player, type, detail);
            return;
        }
        int vl = Math.min(1000000, data.violations.getOrDefault(type, 0) + 1);
        LinoViolationEvent event = new LinoViolationEvent(player, type, detail, vl);
        Bukkit.getPluginManager().callEvent(event);
        if (event.isCancelled()) return;
        data.violations.put(type, vl);
        data.buffers.put(type, Math.max(0, policy.buffer() - 1));
        String plain = player.getName() + " failed " + type.id() + " VL=" + vl + " ping=" + player.getPing() + " " + detail;
        plugin.audit().write("violations", data.id, player.getName(), plain);
        long now = System.currentTimeMillis();
        if (now - data.lastAlerts.getOrDefault(type, 0L) >= plugin.settings().integer("settings.alert-cooldown-ms")) {
            data.lastAlerts.put(type, now);
            alert(player, type, vl, detail);
            if (plugin.settings().enabled("settings.console-alerts")) plugin.getLogger().info(plain);
            plugin.webhooks().send("alerts", "[LinoAC] " + plain);
        }
        if (policy.setback() && data.safe != null && data.safe.getWorld().equals(player.getWorld())
                && player.getWorld().isChunkLoaded(data.safe.getBlockX() >> 4, data.safe.getBlockZ() >> 4)) {
            player.teleport(data.safe);
            plugin.exempt(data, 20);
        }
        if (policy.punishable() && plugin.settings().enabled("settings.automatic-punishments") && vl >= policy.maxViolations()
                && tick - data.lastPunishments.getOrDefault(type, -1200L) >= 1200) {
            data.lastPunishments.put(type, tick);
            if (plugin.settings().enabled("wave.queue-automatic-punishments")) {
                try { plugin.punishments().add(data.id, player.getName()); }
                catch (java.io.IOException e) { plugin.getLogger().severe("Unable to queue punishment: " + e.getMessage()); }
            } else plugin.punishments().execute(data.id, player.getName(), type.id(), policy.commands());
        }
    }

    public void alert(Player suspect, CheckType type, int vl, String detail) {
        String text = plugin.settings().text("messages.alert").replace("%player%", suspect.getName())
                .replace("%check%", type.id()).replace("%vl%", Integer.toString(vl));
        TextComponent component = new TextComponent(TextComponent.fromLegacyText(plugin.messages().color(plugin.settings().text("messages.prefix") + " " + text)));
        component.setClickEvent(new ClickEvent(ClickEvent.Action.RUN_COMMAND, "/linoac teleport " + suspect.getName()));
        component.setHoverEvent(new HoverEvent(HoverEvent.Action.SHOW_TEXT, TextComponent.fromLegacyText(
                "Ping: " + suspect.getPing() + "ms\n" + type.description() + "\n" + detail + "\nClick to teleport.")));
        for (Player viewer : Bukkit.getOnlinePlayers()) {
            PlayerData staff = plugin.data(viewer);
            if (staff.alerts && viewer.hasPermission("linoac.alerts")) viewer.spigot().sendMessage(component);
        }
    }

    private void verbose(Player suspect, CheckType type, String detail) {
        for (Player viewer : Bukkit.getOnlinePlayers()) {
            if (plugin.data(viewer).verbose && viewer.hasPermission("linoac.verbose")) {
                plugin.messages().send(viewer, "&8[Sample] &7" + suspect.getName() + " " + type.id() + " " + detail);
            }
        }
    }
}

package io.github.lino9999.linoac.storage;

import org.bukkit.plugin.java.JavaPlugin;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardOpenOption;
import java.time.LocalDate;
import java.time.Instant;
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Comparator;
import java.util.List;
import java.util.UUID;
import java.util.concurrent.ArrayBlockingQueue;
import java.util.concurrent.ThreadPoolExecutor;
import java.util.concurrent.TimeUnit;
import java.util.function.Consumer;
import java.util.stream.Stream;

public final class AuditLog implements AutoCloseable {
    private final JavaPlugin plugin;
    private final Path directory;
    private final ThreadPoolExecutor worker;
    private int retention;
    private long lastWarning;
    private LocalDate lastDate;

    public AuditLog(JavaPlugin plugin, int retention) throws IOException {
        this.plugin = plugin;
        this.retention = retention;
        directory = plugin.getDataFolder().toPath().resolve("logs");
        Files.createDirectories(directory);
        worker = new ThreadPoolExecutor(1, 1, 0, TimeUnit.MILLISECONDS, new ArrayBlockingQueue<>(4096), r -> {
            Thread thread = new Thread(r, "LinoAC-audit");
            thread.setDaemon(true);
            return thread;
        });
        submit(this::prune);
    }

    public void retention(int days) { retention = days; submit(this::prune); }

    public void write(String kind, UUID id, String name, String text) {
        String line = Instant.now() + "\t" + id + "\t" + clean(name) + "\t" + clean(text) + System.lineSeparator();
        LocalDate date = LocalDate.now();
        submit(() -> {
            if (!date.equals(lastDate)) {
                lastDate = date;
                prune();
            }
            Path path = directory.resolve(date + "-" + kind + ".log");
            try {
                if (Files.exists(path) && Files.size(path) >= 32L * 1024 * 1024) {
                    warning("Daily " + kind + " log reached 32 MiB; further entries will be dropped today.");
                    return;
                }
                Files.writeString(path, line, StandardCharsets.UTF_8, StandardOpenOption.CREATE, StandardOpenOption.APPEND);
            } catch (IOException e) {
                warning("Unable to write audit log: " + e.getMessage());
            }
        });
    }

    public void read(String kind, String name, int page, int limit, Consumer<List<String>> callback) {
        submit(() -> {
            ArrayDeque<String> lines = new ArrayDeque<>(limit);
            try (Stream<Path> paths = Files.list(directory)) {
                List<Path> files = paths.filter(p -> p.getFileName().toString().endsWith("-" + kind + ".log"))
                        .sorted(Comparator.comparing(Path::toString).reversed()).toList();
                int maximum = Math.min(limit, page * 8);
                for (Path file : files) {
                    ArrayDeque<String> perFile = new ArrayDeque<>();
                    try (Stream<String> source = Files.lines(file, StandardCharsets.UTF_8)) {
                        source.filter(line -> {
                            String[] parts = line.split("\t", 4);
                            return parts.length == 4 && parts[2].equalsIgnoreCase(name);
                        }).forEach(line -> {
                            perFile.addLast(line);
                            if (perFile.size() > maximum) perFile.removeFirst();
                        });
                    }
                    while (!perFile.isEmpty() && lines.size() < maximum) lines.addLast(perFile.removeLast());
                    if (lines.size() >= maximum) break;
                }
                List<String> all = new ArrayList<>(lines);
                int start = Math.min(all.size(), (page - 1) * 8);
                List<String> result = List.copyOf(all.subList(start, Math.min(all.size(), start + 8)));
                callback.accept(result);
            } catch (IOException e) {
                warning("Unable to read audit log: " + e.getMessage());
                callback.accept(List.of());
            }
        });
    }

    private void prune() {
        LocalDate cutoff = LocalDate.now().minusDays(retention);
        try (Stream<Path> paths = Files.list(directory)) {
            paths.filter(p -> p.getFileName().toString().matches("\\d{4}-\\d{2}-\\d{2}-(violations|punishments)\\.log"))
                    .forEach(path -> {
                        if (LocalDate.parse(path.getFileName().toString().substring(0, 10)).isBefore(cutoff)) {
                            try { Files.deleteIfExists(path); } catch (IOException e) { warning("Unable to remove expired log: " + path); }
                        }
                    });
        } catch (IOException e) { warning("Unable to prune audit logs: " + e.getMessage()); }
    }

    private void submit(Runnable action) {
        try { worker.execute(action); }
        catch (java.util.concurrent.RejectedExecutionException e) { warning("Audit queue is full or shutting down."); }
    }

    private synchronized void warning(String text) {
        long now = System.nanoTime();
        if (now - lastWarning > TimeUnit.SECONDS.toNanos(30)) {
            lastWarning = now;
            plugin.getLogger().warning(text);
        }
    }

    private String clean(String value) { return value.replaceAll("[\\r\\n\\t\\p{Cntrl}]", " "); }

    public void close() {
        worker.shutdown();
        try {
            if (!worker.awaitTermination(5, TimeUnit.SECONDS)) {
                plugin.getLogger().warning("Audit shutdown timeout; pending records may be lost.");
                worker.shutdownNow();
            }
        } catch (InterruptedException e) { Thread.currentThread().interrupt(); worker.shutdownNow(); }
    }
}

        Files.writeString(temporary, data.saveToString());

package io.github.lino9999.linoac.util;

import org.bukkit.Location;
import org.bukkit.NamespacedKey;
import org.bukkit.Registry;
import org.bukkit.attribute.Attribute;
import org.bukkit.attribute.AttributeInstance;
import org.bukkit.block.Block;
import org.bukkit.entity.Player;
import org.bukkit.util.BoundingBox;

public final class Environment {
    private Environment() {}

    public static double attribute(Player player, String key, double fallback) {
        Attribute attribute = Registry.ATTRIBUTE.get(NamespacedKey.minecraft(key));
        AttributeInstance instance = attribute == null ? null : player.getAttribute(attribute);
        return instance == null ? fallback : instance.getValue();
    }

    public static boolean special(Player player) {
        Location location = player.getLocation();
        for (int x = -1; x <= 1; x++) {
            for (int z = -1; z <= 1; z++) {
                if (!location.getWorld().isChunkLoaded((location.getBlockX() + x) >> 4, (location.getBlockZ() + z) >> 4)) return true;
                for (int y = -1; y <= 2; y++) {
                    Block block = location.getWorld().getBlockAt(location.getBlockX() + x, location.getBlockY() + y, location.getBlockZ() + z);
                    String name = block.getType().name();
                    if (block.isLiquid() || name.contains("ICE") || name.contains("SLIME") || name.contains("HONEY")
                            || name.contains("WEB") || name.contains("BERRY") || name.contains("POWDER_SNOW")
                            || name.contains("SOUL_SAND") || name.contains("BUBBLE") || name.contains("BED")
                            || name.contains("PISTON")) return true;
                }
            }
        }
        return false;
    }

    public static boolean supported(Player player) {
        Location l = player.getLocation();
        BoundingBox body = player.getBoundingBox();
        BoundingBox feet = new BoundingBox(body.getMinX() + .01, l.getY() - .12, body.getMinZ() + .01,
                body.getMaxX() - .01, l.getY() + .01, body.getMaxZ() - .01);
        for (int x = (int) Math.floor(feet.getMinX()); x <= (int) Math.floor(feet.getMaxX()); x++) {
            for (int z = (int) Math.floor(feet.getMinZ()); z <= (int) Math.floor(feet.getMaxZ()); z++) {
                if (!l.getWorld().isChunkLoaded(x >> 4, z >> 4)) return true;
                for (int y = l.getBlockY() - 2; y <= l.getBlockY(); y++) {
                    Block block = l.getWorld().getBlockAt(x, y, z);
                    if (!block.isPassable() && !block.isLiquid()
                            && block.getCollisionShape().overlaps(feet.clone().shift(-x, -y, -z))) return true;
                }
            }
        }
        return false;
    }
}

import org.bukkit.util.BoundingBox;
import org.bukkit.util.Vector;

public final class Geometry {
    private Geometry() {}

    public static double distance(Vector point, BoundingBox box) {
        double x = Math.max(box.getMinX() - point.getX(), Math.max(0, point.getX() - box.getMaxX()));
        double y = Math.max(box.getMinY() - point.getY(), Math.max(0, point.getY() - box.getMaxY()));
        double z = Math.max(box.getMinZ() - point.getZ(), Math.max(0, point.getZ() - box.getMaxZ()));
        return Math.sqrt(x * x + y * y + z * z);
    }
}
