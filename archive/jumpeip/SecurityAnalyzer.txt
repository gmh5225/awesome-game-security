`README.md`:

```md
# SecurityAnalyzer — a Ghidra plugin for defensive security analysis

A complex, end-to-end Ghidra plugin that helps reverse engineers triage
binaries for vulnerabilities, identify malware behavior, recover obfuscated
strings and crypto, annotate findings in the program, and generate
documentation suitable for vendor disclosure or CVE filing.

The plugin is **scoped to defensive analysis**. It detects, annotates, and
documents — it does not generate working exploits or weaponized code. See
[Scope and limitations](#scope-and-limitations) at the bottom.

---

## Highlights

- **Five analyzer families**, all P-code based where parameter inspection is involved:
  - `VulnerabilityAnalyzer` — dangerous library calls, format strings, integer
    overflow → allocation patterns, command-injection sinks, double-free /
    use-after-free heuristics
  - `MalwareAnalyzer` — anti-debug / anti-VM API usage, CPUID hypervisor leaf
    detection, process-injection API combinations (e.g. `VirtualAllocEx` +
    `WriteProcessMemory` + `CreateRemoteThread`), persistence registry paths
  - `CryptoAnalyzer` — AES / SHA / MD5 / TEA / ChaCha / Salsa / DES / CRC
    constant signatures, XOR-loop density detection, Shannon-entropy windowed
    scan
  - `DeobfuscationAnalyzer` — stack-string reconstruction (immediate stores
    into stack slots), interactive single-byte XOR brute-force on the current
    selection
  - Manual tagging — drop a labeled finding at the cursor address while triaging
- **Annotation in-program**: every finding writes a Bookmark + EOL comment so
  results show up natively in the listing.
- **Report generation**: Markdown summary, JSON for tooling, and a per-finding
  vulnerability writeup template (sections for description, affected code,
  reproduction, mitigation, references — purely a documentation scaffold).
- **Background tasks with cancellation**: every long-running scan runs through
  Ghidra's `TaskLauncher` so the user gets a progress bar and cancel button.
- **Companion script** for headless use (`ghidra_scripts/QuickVulnScan.java`).

---

## Why P-code?

The plugin uses the decompiler's high-level P-code (via `HighFunction`) for
all argument and dataflow analysis. This is what makes parameter checking
reliable across architectures and calling conventions: instead of pattern
matching `mov rcx, ...` for x64 fastcall and `push ...` for x86 cdecl, the
analyzers ask the decompiler "what is argument N to this call?" and walk the
P-code def-use chain.

That same machinery powers:
- Constant resolution that looks through `COPY`, `CAST`, `INT_ZEXT`, `INT_SEXT`
- Taint heuristics that mark a varnode as analyst-controlled if it traces back
  to a parameter, a memory `LOAD`, or an `INDIRECT` call result
- String resolution from a constant pointer argument

The helper that wraps this is in `securityanalyzer.util.PCodeHelper` — it owns
the `DecompInterface`, is `AutoCloseable`, and is created fresh per scan so
decompiler resources aren't pinned across long sessions.

---

## Build

You need a Ghidra install (tested against 12.0.x and 12.1.x; builds for 12.2) and Gradle 7+ (or the
`gradle` shipped with your Ghidra install).

```bash
cd SecurityAnalyzer
gradle -PGHIDRA_INSTALL_DIR=/path/to/ghidra_12.2_PUBLIC
```

Or set `GHIDRA_INSTALL_DIR` in your environment first. The build produces a
distributable zip in `dist/`:

```
dist/ghidra_12.2_PUBLIC_<date>_SecurityAnalyzer.zip
```

## Install

1. Open Ghidra (Project window).
2. **File → Install Extensions → "+"** and select the built zip.
3. Restart Ghidra.
4. Open a program in CodeBrowser.
5. **File → Configure → Miscellaneous** and tick `SecurityAnalyzer`.

The new top-level menu **Tools → Security Analyzer** is now available, and the
dockable findings panel can be opened from there.

---

## Menu reference

All actions are under `Tools → Security Analyzer`:

| Submenu | Action | What it does |
|---------|--------|--------------|
| — | Show Panel | Shows / focuses the findings panel |
| — | Run All Analyzers | Vuln + malware + crypto + stack-strings, in one task |
| Vulnerabilities | Vulnerability Scan | Every vuln detector |
| Vulnerabilities | Dangerous Function Calls | `gets`/`strcpy`/`sprintf`/etc + bounded-but-misused (`memcpy` with tainted size) |
| Vulnerabilities | Format String Vulns | `printf`-family with non-constant format argument |
| Vulnerabilities | Integer Overflow Patterns | Tainted arithmetic feeding `malloc`/`HeapAlloc`, plus `SUBPIECE` truncation |
| Malware | Malware Indicators Scan | Every malware detector |
| Malware | Anti-Analysis Detection | API calls + CPUID hypervisor leaf checks |
| Malware | Process Injection Patterns | Single-call indicators + behavioral combos |
| Malware | Persistence Mechanisms | Registry API calls + suspicious Run-key strings in data |
| Encryption | Crypto Constant Hunt | Byte signatures for AES/SHA/MD5/TEA/ChaCha/Salsa/DES/CRC |
| Encryption | XOR Loop Detection | High XOR density + back-edge → likely cipher loop |
| Encryption | High Entropy Regions | 4 KiB Shannon-entropy windowed scan |
| De-Obfuscation | Stack String Reconstruction | Immediate stores into stack slots reassembled into strings |
| De-Obfuscation | XOR Decode Selection | Brute-force single-byte XOR over the current Listing selection |
| Annotation | Tag Current Address | Drop a manual finding at the cursor with a note |
| Annotation | Clear Findings | Empty the findings table (does not undo bookmarks/comments) |
| Reporting | Export Markdown… | Save a Markdown report of all findings |
| Reporting | Export JSON… | Save a JSON report (for downstream tools / dashboards) |
| Reporting | Generate Vulnerability Writeup Template… | Per-finding writeup scaffold |

Findings drop into the panel as a sortable table (Severity / Type / Address
/ Function / Title) — clicking a row navigates the Listing to the address.
Each finding also writes a `WARNING` Bookmark and an EOL comment in the
program (under category `SecurityAnalyzer`), so results survive a reload.

## Headless usage

```bash
$GHIDRA_INSTALL_DIR/support/analyzeHeadless \
    /tmp/ghidra-projects MyProject \
    -import sample.exe \
    -postScript QuickVulnScan.java \
    -scriptPath /path/to/SecurityAnalyzer/ghidra_scripts
```

This runs `VulnerabilityAnalyzer.scanAll` + `MalwareAnalyzer.scanAll` and
writes `<programName>-vulns.md` next to the executable (or `$HOME` if the
executable directory isn't writable).

---

## Scope and limitations

This plugin is for **defensive security work**: triaging samples, finding
bugs to report, and producing documentation. The following are deliberately
**out of scope**:

- No shellcode generation, no payload templates with embedded shellcode.
- No ROP/JOP gadget chain construction or exploit primitive automation.
- No working weaponized PoC code. The "Vulnerability Writeup Template"
  produces a Markdown scaffold (description, affected code, reproduction
  conditions, suggested mitigation, disclosure plan) — what a vendor or CVE
  Numbering Authority needs to triage a report. Reproduction is described in
  terms of "test input X causes condition Y", not a runnable exploit.
- The fuzzing-harness helper (`ReportGenerator.generateHarnessScaffolding`)
  produces an intentionally **incomplete** libFuzzer stub. It is a starting
  point you complete by hand, with the explicit expectation that you compile
  it with sanitizers and run it inside an isolated lab environment.

Detector caveats:

- All detectors are **conservative heuristics**, not proofs. Findings include
  evidence text so an analyst can triage false positives.
- Taint analysis is local (intra-procedural) and treats unknown definitions as
  tainted. This is the safe default for a vulnerability scanner — it
  over-reports rather than missing things — but means you should expect to
  dismiss some findings during review.
- The crypto constant scanner skips memory blocks larger than 64 MiB to keep
  scan time bounded; on huge firmware images you may want to scan blocks
  individually.
- The XOR-loop and entropy scanners are tuned to flag candidates worth
  looking at, not to identify specific algorithms.

`build-windows.ps1`:

```ps1
<#
.SYNOPSIS
    Build the SecurityAnalyzer Ghidra extension into an installable .zip.

.DESCRIPTION
    Two build paths:

      - Gradle (default). Uses your Gradle install + Ghidra's official
        support/buildExtension.gradle. This is the path NSA tests against.

      - Direct javac (-NoGradle). Skips Gradle entirely and compiles the
        sources against the jars in your Ghidra install. Useful if Gradle
        misbehaves.

    Either path produces  .\dist\ghidra_<ver>_<rel>_<date>_SecurityAnalyzer.zip
    in the standard Ghidra extension layout, ready for File -> Install Extensions.

.PARAMETER GhidraInstallDir
    Path to your Ghidra install. Default: D:\ghidra_12.2_PUBLIC

.PARAMETER GradleHome
    Path to your Gradle install. Default: D:\gradle-9.5.0

.PARAMETER JavaHome
    Path to a JDK 21 install. If not specified the script probes the
    Ghidra install (support/jdk, support/JDK), $env:JAVA_HOME, and
    finally javac on PATH.

.PARAMETER NoGradle
    Skip Gradle entirely and use the direct javac path.

.PARAMETER Clean
    Wipe build/ and dist/ before building.

.EXAMPLE
    PS> .\build-windows.ps1
    PS> .\build-windows.ps1 -Clean
    PS> .\build-windows.ps1 -NoGradle
    PS> .\build-windows.ps1 -GhidraInstallDir "D:\ghidra_12.2_PUBLIC" -GradleHome "D:\gradle-9.5.0"
#>

[CmdletBinding()]
param(
    [string]$GhidraInstallDir = "D:\ghidra_12.2_PUBLIC",
    [string]$GradleHome       = "D:\gradle-9.5.0",
    [string]$JavaHome         = "",
    [switch]$NoGradle,
    [switch]$Clean
)

$ErrorActionPreference = "Stop"
$ScriptDir = Split-Path -Parent $MyInvocation.MyCommand.Path

function Write-Step($msg) {
    Write-Host ""
    Write-Host "==> $msg" -ForegroundColor Cyan
}
function Fail($msg) {
    Write-Host "ERROR: $msg" -ForegroundColor Red
    exit 1
}

# --------------------------------------------------------------------
# 1. Verify Ghidra install + read its version metadata
# --------------------------------------------------------------------
Write-Step "Verifying Ghidra install at $GhidraInstallDir"

if (-not (Test-Path $GhidraInstallDir)) {
    Fail "Ghidra install not found: $GhidraInstallDir"
}
$GhidraPropsFile = Join-Path $GhidraInstallDir "Ghidra\application.properties"
if (-not (Test-Path $GhidraPropsFile)) {
    Fail "Doesn't look like a Ghidra install root: $GhidraInstallDir"
}
$ghidraVersion = (Get-Content $GhidraPropsFile | Select-String '^application\.version=' |
    ForEach-Object { ($_ -split '=', 2)[1] }) -join ''
$ghidraRelName = (Get-Content $GhidraPropsFile | Select-String '^application\.release\.name=' |
    ForEach-Object { ($_ -split '=', 2)[1] }) -join ''
if (-not $ghidraVersion) { $ghidraVersion = "UNKNOWN" }
if (-not $ghidraRelName) { $ghidraRelName = "PUBLIC" }
Write-Host "    Ghidra version: $ghidraVersion ($ghidraRelName)"

# --------------------------------------------------------------------
# 2. Locate JDK 21
# --------------------------------------------------------------------
Write-Step "Locating JDK 21"

if (-not $JavaHome) {
    foreach ($cand in @(
        (Join-Path $GhidraInstallDir "support\jdk"),
        (Join-Path $GhidraInstallDir "support\JDK"),
        $env:JAVA_HOME
    )) {
        if ($cand -and (Test-Path (Join-Path $cand "bin\javac.exe"))) {
            $JavaHome = $cand
            break
        }
    }
}
if (-not $JavaHome) {
    $j = Get-Command javac -ErrorAction SilentlyContinue
    if ($j) { $JavaHome = (Split-Path (Split-Path $j.Source)) }
}
if (-not $JavaHome -or -not (Test-Path (Join-Path $JavaHome "bin\javac.exe"))) {
    Fail "Could not find a JDK with javac.exe. Install JDK 21 and pass -JavaHome <path>."
}
$javacExe = Join-Path $JavaHome "bin\javac.exe"
$jarExe   = Join-Path $JavaHome "bin\jar.exe"
$env:JAVA_HOME = $JavaHome
Write-Host "    JAVA_HOME = $JavaHome"
$javacVer = & $javacExe -version 2>&1
Write-Host "    $javacVer"

# --------------------------------------------------------------------
# 3. Verify source layout
# --------------------------------------------------------------------
Write-Step "Verifying source layout"
$srcRoot = Join-Path $ScriptDir "src\main\java"
foreach ($req in @(
    "extension.properties",
    "Module.manifest",
    "build.gradle",
    "src\main\java\securityanalyzer\SecurityAnalyzerPlugin.java",
    "src\main\java\securityanalyzer\ui\SecurityAnalyzerProvider.java"
)) {
    $p = Join-Path $ScriptDir $req
    if (-not (Test-Path $p)) { Fail "Missing required file: $req" }
}

$buildDir = Join-Path $ScriptDir "build"
$distDir  = Join-Path $ScriptDir "dist"
if ($Clean) {
    Write-Step "Cleaning build/ and dist/"
    if (Test-Path $buildDir) { Remove-Item -Recurse -Force $buildDir }
    if (Test-Path $distDir)  { Remove-Item -Recurse -Force $distDir }
}
New-Item -ItemType Directory -Force -Path $distDir | Out-Null

$datestamp = Get-Date -Format "yyyyMMdd"
$zipName   = "ghidra_${ghidraVersion}_${ghidraRelName}_${datestamp}_SecurityAnalyzer.zip"
$zipPath   = Join-Path $distDir $zipName

# ====================================================================
# Path A: Gradle build (preferred)
# ====================================================================
$gradleSucceeded = $false
if (-not $NoGradle) {
    Write-Step "Attempting Gradle build with $GradleHome"
    $gradleBat = Join-Path $GradleHome "bin\gradle.bat"
    if (-not (Test-Path $gradleBat)) {
        Write-Host "    gradle.bat not found at $gradleBat - falling back to javac." -ForegroundColor Yellow
    } else {
        $env:GHIDRA_INSTALL_DIR = $GhidraInstallDir
        Push-Location $ScriptDir
        try {
            & $gradleBat --no-daemon -PGHIDRA_INSTALL_DIR="$GhidraInstallDir" buildExtension
            $gradleExit = $LASTEXITCODE
            if ($gradleExit -ne 0) {
                Write-Host "    Gradle build failed (exit $gradleExit) - falling back to javac." -ForegroundColor Yellow
            } else {
                # Ghidra's buildExtension drops the zip into ./dist/ by default.
                $built = Get-ChildItem -Path $distDir -Filter "*SecurityAnalyzer*.zip" -ErrorAction SilentlyContinue |
                    Sort-Object LastWriteTime -Descending | Select-Object -First 1
                if ($built) {
                    if ($built.FullName -ne $zipPath) {
                        Move-Item -Force $built.FullName $zipPath
                    }
                    $gradleSucceeded = $true
                } else {
                    Write-Host "    Gradle ran but produced no zip in dist/ - falling back to javac." -ForegroundColor Yellow
                }
            }
        } finally {
            Pop-Location
        }
    }
}

# ====================================================================
# Path B: Direct javac fallback
# ====================================================================
if (-not $gradleSucceeded) {
    Write-Step "Building with direct javac"

    $classDir = Join-Path $buildDir "classes"
    if (Test-Path $classDir) { Remove-Item -Recurse -Force $classDir }
    New-Item -ItemType Directory -Force -Path $classDir | Out-Null

    $ghidraRoot = Join-Path $GhidraInstallDir "Ghidra"
    $jars = Get-ChildItem -Path $ghidraRoot -Recurse -Filter *.jar -ErrorAction SilentlyContinue |
        Where-Object { $_.Name -notmatch '-src\.jar$' -and $_.Name -notmatch '-javadoc\.jar$' } |
        Select-Object -ExpandProperty FullName
    if ($jars.Count -lt 5) {
        Fail "Found only $($jars.Count) jars under $ghidraRoot - install incomplete."
    }
    Write-Host "    $($jars.Count) jars on classpath"
    $cpString = ($jars -join ';')

    $sources = Get-ChildItem -Path $srcRoot -Recurse -Filter *.java |
        Select-Object -ExpandProperty FullName

#!/usr/bin/env bash
# Build the SecurityAnalyzer Ghidra extension into an installable .zip.
#
# Compiles the plugin's Java sources against the jars in your Ghidra
# install, assembles the standard Ghidra extension zip layout, and
# drops the result in ./dist/.
#
# Usage:
#   ./build.sh [/path/to/ghidra_12.2_PUBLIC]
#
# Or set GHIDRA_INSTALL_DIR in the environment.

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
GHIDRA_INSTALL_DIR="${1:-${GHIDRA_INSTALL_DIR:-}}"

step()  { printf '\n==> %s\n' "$*"; }
fail()  { printf 'ERROR: %s\n' "$*" >&2; exit 1; }

# --------------------------------------------------------------------
step "Verifying Ghidra install"
[ -n "$GHIDRA_INSTALL_DIR" ] || fail "Pass /path/to/ghidra as arg 1, or set GHIDRA_INSTALL_DIR."
[ -d "$GHIDRA_INSTALL_DIR" ] || fail "Not a directory: $GHIDRA_INSTALL_DIR"
PROPS="$GHIDRA_INSTALL_DIR/Ghidra/application.properties"
[ -f "$PROPS" ] || fail "Doesn't look like a Ghidra install root: $GHIDRA_INSTALL_DIR"

GHIDRA_VERSION=$(grep '^application.version=' "$PROPS" | cut -d= -f2- | tr -d '\r')
GHIDRA_RELNAME=$(grep '^application.release.name=' "$PROPS" | cut -d= -f2- | tr -d '\r')
: "${GHIDRA_VERSION:=UNKNOWN}"
: "${GHIDRA_RELNAME:=PUBLIC}"
echo "    Ghidra version: $GHIDRA_VERSION ($GHIDRA_RELNAME)"

# --------------------------------------------------------------------
step "Locating Java toolchain"
JAVAC="$(command -v javac || true)"
JAR="$(command -v jar || true)"

if [ -z "$JAVAC" ]; then
    for c in "$GHIDRA_INSTALL_DIR/support/jdk/bin/javac" "$GHIDRA_INSTALL_DIR/support/JDK/bin/javac"; do
        if [ -x "$c" ]; then
            JAVAC="$c"
            JAR="$(dirname "$c")/jar"
            break
        fi
    done
fi
[ -n "$JAVAC" ] && [ -x "$JAVAC" ] || fail "javac not found. Install JDK 21."
[ -n "$JAR"   ] && [ -x "$JAR"   ] || fail "jar not found alongside javac."
echo "    javac: $JAVAC"
echo "    jar:   $JAR"
"$JAVAC" -version 2>&1 | sed 's/^/    /'

# --------------------------------------------------------------------
step "Verifying source layout"
SRC_ROOT="$SCRIPT_DIR/src/main/java"
[ -d "$SRC_ROOT" ] || fail "Source root not found: $SRC_ROOT"
for req in extension.properties Module.manifest \
           src/main/java/securityanalyzer/SecurityAnalyzerPlugin.java \
           src/main/java/securityanalyzer/ui/SecurityAnalyzerProvider.java; do
    [ -f "$SCRIPT_DIR/$req" ] || fail "Missing required file: $req"
done

# --------------------------------------------------------------------
step "Collecting Ghidra jars for compile classpath"
JARS_FILE="$(mktemp)"
trap 'rm -f "$JARS_FILE"' EXIT
find "$GHIDRA_INSTALL_DIR/Ghidra" -name '*.jar' \
    ! -name '*-src.jar' ! -name '*-javadoc.jar' > "$JARS_FILE"
JAR_COUNT=$(wc -l < "$JARS_FILE")
[ "$JAR_COUNT" -ge 5 ] || fail "Found only $JAR_COUNT jars under Ghidra/ — install incomplete."
echo "    $JAR_COUNT jars on classpath"

# Build classpath string with ':' separator (Linux/macOS)
CP="$(tr '\n' ':' < "$JARS_FILE" | sed 's/:$//')"

# --------------------------------------------------------------------
BUILD_DIR="$SCRIPT_DIR/build"
CLASS_DIR="$BUILD_DIR/classes"
DIST_DIR="$SCRIPT_DIR/dist"
STAGE_ROOT="$BUILD_DIR/stage/SecurityAnalyzer"

if [ "${CLEAN:-0}" = "1" ]; then
    step "Cleaning build/ and dist/"
    rm -rf "$BUILD_DIR" "$DIST_DIR"
fi
mkdir -p "$CLASS_DIR" "$DIST_DIR" "$STAGE_ROOT/lib"

# --------------------------------------------------------------------
step "Compiling"
SOURCES_FILE="$BUILD_DIR/sources.txt"
find "$SRC_ROOT" -name '*.java' > "$SOURCES_FILE"
SRC_COUNT=$(wc -l < "$SOURCES_FILE")
echo "    $SRC_COUNT source files"

"$JAVAC" -d "$CLASS_DIR" -cp "$CP" -encoding UTF-8 \
    -source 21 -target 21 -Xlint:none \
    @"$SOURCES_FILE"

CLASS_COUNT=$(find "$CLASS_DIR" -name '*.class' | wc -l)
echo "    $CLASS_COUNT .class files produced"

# --------------------------------------------------------------------
step "Packaging SecurityAnalyzer.jar"
JAR_PATH="$STAGE_ROOT/lib/SecurityAnalyzer.jar"
( cd "$CLASS_DIR" && "$JAR" cf "$JAR_PATH" . )
echo "    Wrote: $JAR_PATH ($(du -h "$JAR_PATH" | cut -f1))"

# --------------------------------------------------------------------
step "Assembling extension layout"
cp "$SCRIPT_DIR/extension.properties" "$STAGE_ROOT/"
cp "$SCRIPT_DIR/Module.manifest"      "$STAGE_ROOT/"
[ -f "$SCRIPT_DIR/README.md" ] && cp "$SCRIPT_DIR/README.md" "$STAGE_ROOT/"
[ -d "$SCRIPT_DIR/ghidra_scripts" ] && cp -r "$SCRIPT_DIR/ghidra_scripts" "$STAGE_ROOT/"
[ -d "$SCRIPT_DIR/data" ]           && cp -r "$SCRIPT_DIR/data"           "$STAGE_ROOT/"

# Stamp the version (Ghidra's installer requires this match the Ghidra version)
sed -i.bak "s/@extversion@/$GHIDRA_VERSION/g" "$STAGE_ROOT/extension.properties"
rm -f "$STAGE_ROOT/extension.properties.bak"
echo "    Stamped extension.properties with version=$GHIDRA_VERSION"

# --------------------------------------------------------------------
step "Creating distributable zip"
DATE=$(date +%Y%m%d)
ZIP_NAME="ghidra_${GHIDRA_VERSION}_${GHIDRA_RELNAME}_${DATE}_SecurityAnalyzer.zip"
ZIP_PATH="$DIST_DIR/$ZIP_NAME"
rm -f "$ZIP_PATH"
( cd "$BUILD_DIR/stage" && zip -rq "$ZIP_PATH" SecurityAnalyzer )

echo ""
echo "Done."
echo "    $ZIP_PATH ($(du -h "$ZIP_PATH" | cut -f1))"
echo ""
echo "Install:"
echo "  1. Open Ghidra (Project window)."
echo "  2. File -> Install Extensions -> '+' -> select the zip above."
echo "  3. Restart Ghidra."
echo "  4. Open a program in CodeBrowser."
echo "  5. File -> Configure -> Miscellaneous -> tick 'SecurityAnalyzer'."
echo "  6. Find the new menu under Tools -> Security Analyzer."

/* SPDX-License-Identifier: Apache-2.0
 *
 * QuickVulnScan.java — standalone Ghidra script counterpart to the
 * SecurityAnalyzer plugin. Useful when you want a one-off scan without
 * loading the GUI panel, or in headless analysis pipelines.
 *
 * Headless invocation example:
 *
 *   $GHIDRA_INSTALL_DIR/support/analyzeHeadless \
 *       /tmp/projects MyProject \
 *       -import sample.exe \
 *       -postScript QuickVulnScan.java \
 *       -scriptPath /path/to/SecurityAnalyzer/ghidra_scripts
 *
 * Output: a Markdown report next to the program named
 *   <programName>-vulns.md
 */

//@author SecurityAnalyzer
//@category SecurityAnalyzer
//@menupath Tools.Security Analyzer.Quick Vulnerability Scan (script)

import java.io.IOException;
import java.io.Writer;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.util.ArrayList;
import java.util.List;

import ghidra.app.script.GhidraScript;
import securityanalyzer.analyzers.MalwareAnalyzer;
import securityanalyzer.analyzers.VulnerabilityAnalyzer;
import securityanalyzer.findings.Finding;
import securityanalyzer.util.PCodeHelper;
import securityanalyzer.util.ReportGenerator;

public class QuickVulnScan extends GhidraScript {

    @Override
    protected void run() throws Exception {
        if (currentProgram == null) {
            println("No program loaded.");
            return;
        }

        List<Finding> findings = new ArrayList<>();

        try (PCodeHelper helper = new PCodeHelper(currentProgram)) {
            println("[*] Running vulnerability scan...");
            VulnerabilityAnalyzer va = new VulnerabilityAnalyzer(currentProgram, helper);
            findings.addAll(va.scanAll(monitor));

            if (monitor.isCancelled()) {
                println("[!] Cancelled.");
                return;
            }

            println("[*] Running malware indicator scan...");
            MalwareAnalyzer ma = new MalwareAnalyzer(currentProgram, helper);
            findings.addAll(ma.scanAll(monitor));
        }

        println("[*] Total findings: " + findings.size());

        // Default report location: alongside the program executable path if we
        // have one, otherwise the user's home directory.
        Path outDir = resolveOutputDir();
        Path outFile = outDir.resolve(currentProgram.getName() + "-vulns.md");

        try (Writer w = Files.newBufferedWriter(outFile, StandardCharsets.UTF_8)) {
            new ReportGenerator(currentProgram).writeMarkdown(w, findings);
        } catch (IOException ioe) {
            printerr("Failed to write report: " + ioe.getMessage());
            throw ioe;
        }

        println("[*] Report written: " + outFile);
    }

    private Path resolveOutputDir() {
        try {
            String exec = currentProgram.getExecutablePath();
            if (exec != null && !exec.isBlank()) {
                Path p = Paths.get(exec).getParent();
                if (p != null && Files.isWritable(p)) {
                    return p;
                }
            }
        } catch (Exception ignored) {
            // fall through to home dir
        }
        return Paths.get(System.getProperty("user.home", "."));
    }
}

/**
 * Cryptography-relevant detectors:
 * <ul>
 *   <li>Search initialized memory for known crypto constants
 *       (AES S-box, SHA-256 round constants, MD5 T-table, etc.).</li>
 *   <li>Find tight loops dominated by XOR operations - candidate decode
 *       routines or stream cipher kernels.</li>
 *   <li>Compute Shannon entropy on each memory block; flag regions whose
 *       entropy is higher than typical compiled data (likely encrypted
 *       config, packed payload, etc.).</li>
 * </ul>
 */
public class CryptoAnalyzer {

    /** Named crypto constants we search for. */
    private static final Map<String, ConstantSignature> SIGNATURES = new HashMap<>();

    static {
        // AES forward S-box, first 16 bytes
        SIGNATURES.put("AES S-Box (forward)",
                new ConstantSignature(new byte[] {
                        (byte)0x63, (byte)0x7c, (byte)0x77, (byte)0x7b,
                        (byte)0xf2, (byte)0x6b, (byte)0x6f, (byte)0xc5,

                        (byte)0xfe, (byte)0xd7, (byte)0xab, (byte)0x76 },
                        Severity.HIGH));

        // AES inverse S-box, first 16 bytes
        SIGNATURES.put("AES S-Box (inverse)",
                new ConstantSignature(new byte[] {
                        (byte)0x52, (byte)0x09, (byte)0x6a, (byte)0xd5,
                        (byte)0x30, (byte)0x36, (byte)0xa5, (byte)0x38,

                new ConstantSignature(new byte[] {

                        (byte)0x10, (byte)0x20, (byte)0x40, (byte)0x80 },

    private static final class ConstantSignature {
        final byte[] bytes;
        final Severity severity;
        ConstantSignature(byte[] b, Severity s) {
            this.bytes = b;
            this.severity = s;

    public List<Finding> scanAll(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        findings.addAll(scanCryptoConstants(monitor));
        findings.addAll(scanXorLoops(monitor));
        findings.addAll(scanEntropy(monitor));
        return findings;
    }

    /**
     * Search every initialized memory block for each known signature.
     */
    public List<Finding> scanCryptoConstants(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        Memory mem = program.getMemory();
        monitor.setMessage("Searching memory for crypto constants...");

        for (MemoryBlock block : mem.getBlocks()) {
            if (!block.isInitialized() || monitor.isCancelled()) {
                continue;
            }
            byte[] blockBytes;
            try {
                long size = block.getSize();
                if (size > 64 * 1024 * 1024) {
                    // Skip very large blocks; chunk-and-search is left as
                    // an enhancement.
                    continue;
                }
                blockBytes = new byte[(int) size];
                block.getBytes(block.getStart(), blockBytes);
            } catch (MemoryAccessException e) {
                continue;
            }

            for (Map.Entry<String, ConstantSignature> e : SIGNATURES.entrySet()) {
                int idx = indexOf(blockBytes, e.getValue().bytes, 0);
                while (idx != -1 && !monitor.isCancelled()) {
                    Address foundAddr = block.getStart().add(idx);
                    Function containing = program.getFunctionManager()
                            .getFunctionContaining(foundAddr);
                    findings.add(Finding.builder(FindingType.CRYPTO_CONSTANT,
                            e.getValue().severity)
                            .at(foundAddr).in(containing)
                            .title("Crypto constant: " + e.getKey())
                            .describe("Memory at " + foundAddr + " matches the start " +
                                    "of the " + e.getKey() + " table/IV/constant.")
                            .evidence("Block " + block.getName() + " offset 0x" +
                                    Integer.toHexString(idx))
                            .recommend("Inspect surrounding code and data for the full " +
                                    "implementation of " + e.getKey() + ". Mark the " +
                                    "table as data and look for xrefs.")
                            .build());
                    idx = indexOf(blockBytes, e.getValue().bytes, idx + 1);
                }
            }
        }
        return findings;
    }

    /**
     * Find functions whose body is dominated by XOR ops in a tight loop —
     * a classic sign of a custom XOR/stream-cipher decoder.
     *
     * <p>Heuristic: XOR p-code ops divided by total p-code ops, weighted
     * by whether the function contains a back-edge (loop).
     */
    public List<Finding> scanXorLoops(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        monitor.setMessage("Looking for XOR-dominated loops...");
        for (Function fn : program.getFunctionManager().getFunctions(true)) {
            if (monitor.isCancelled()) {
                break;
            }
            if (fn.isThunk() || fn.isExternal()) {
                continue;
            }

            int xorCount = 0;
            int totalOps = 0;
            boolean hasBackEdge = hasBackEdge(fn);

            for (var op : pcode.getPcodeOps(fn, monitor)) {
                totalOps++;
                int o = op.getOpcode();
                if (o == ghidra.program.model.pcode.PcodeOp.INT_XOR) {
                    xorCount++;
                }
            }
            if (totalOps < 8) {
                continue;
            }
            double ratio = (double) xorCount / totalOps;
            if (ratio >= 0.10 && hasBackEdge) {
                Severity sev = ratio >= 0.20 ? Severity.HIGH : Severity.MEDIUM;
                findings.add(Finding.builder(FindingType.XOR_LOOP, sev)
                        .at(fn.getEntryPoint()).in(fn)
                        .title("XOR-heavy looped function")
                        .describe("Function contains a loop and " + xorCount +
                                " XOR p-code operations out of " + totalOps + " total " +
                                "(" + String.format("%.1f", ratio * 100) +
                                "%). Likely a custom decoder, stream cipher kernel, or " +
                                "checksum routine.")
                        .evidence("XOR ops: " + xorCount + " / " + totalOps +
                                ", back-edge present")
                        .recommend("Decompile and identify the key/IV. Consider running " +
                                "the De-Obfuscation > XOR Decode action over data buffers " +
                                "this function references.")
                        .build());
            }
        }
        return findings;
    }

    /**
     * Compute Shannon entropy of every memory block in 4KiB-aligned windows
     * and flag windows whose entropy exceeds a threshold.
     */
    public List<Finding> scanEntropy(TaskMonitor monitor) {
        return scanEntropy(monitor, 0x1000, 7.4);
    }

    public List<Finding> scanEntropy(TaskMonitor monitor, int windowSize, double threshold) {
        List<Finding> findings = new ArrayList<>();
        Memory mem = program.getMemory();
        monitor.setMessage("Computing block entropy...");
        for (MemoryBlock block : mem.getBlocks()) {
            if (!block.isInitialized() || monitor.isCancelled()) {
                continue;
            }
            // Skip executable code blocks - high entropy there is normal-ish
            if (block.isExecute()) {
                continue;
            }
            long size = block.getSize();
            if (size < windowSize) {
                continue;
            }
            byte[] buf = new byte[windowSize];
            for (long off = 0; off + windowSize <= size; off += windowSize) {
                if (monitor.isCancelled()) {
                    break;
                }
                Address a = block.getStart().add(off);
                try {
                    block.getBytes(a, buf);
                } catch (MemoryAccessException e) {
                    continue;
                }
                double h = shannonEntropy(buf);
                if (h >= threshold) {
                    findings.add(Finding.builder(FindingType.HIGH_ENTROPY,
                            h >= 7.7 ? Severity.HIGH : Severity.MEDIUM)
                            .at(a).in(null)
                            .title(String.format("High-entropy region (H=%.2f)", h))
                            .describe("A " + windowSize + "-byte window starting at " +
                                    a + " has Shannon entropy " +
                                    String.format("%.3f", h) + ". Typical of encrypted " +
                                    "or compressed data.")
                            .evidence(String.format("entropy=%.3f, window=%d bytes",
                                    h, windowSize))
                            .recommend("If encrypted: locate the decryption routine. " +
                                    "If compressed: identify the algorithm header.")
                            .build());
                }
            }
        }
        return findings;
    }

    // ------------------------------------------------------------------

    private static double shannonEntropy(byte[] buf) {
        int[] hist = new int[256];
        for (byte b : buf) {
            hist[b & 0xFF]++;
        }
        double h = 0.0;
        double n = buf.length;
        for (int c : hist) {
            if (c == 0) continue;
            double p = c / n;
            h -= p * (Math.log(p) / Math.log(2));
        }
        return h;
    }

    private static int indexOf(byte[] haystack, byte[] needle, int from) {
        outer: for (int i = from; i <= haystack.length - needle.length; i++) {
            for (int j = 0; j < needle.length; j++) {
                if (haystack[i + j] != needle[j]) {
                    continue outer;
                }
            }
            return i;
        }
        return -1;
    }

    private boolean hasBackEdge(Function fn) {
        AddressSetView body = fn.getBody();
        if (body == null) {
            return false;
        }
        InstructionIterator it = program.getListing().getInstructions(body, true);
        while (it.hasNext()) {
            Instruction ins = it.next();
            if (ins.getFlowType().isJump()) {
                Address[] flows = ins.getFlows();
                for (Address f : flows) {
                    if (f != null && f.compareTo(ins.getAddress()) <= 0
                            && body.contains(f)) {
                        return true;
                    }
                }
            }
        }
        return false;
    }

    /** For UI: returns the set of all addresses a function references. */
    public AddressSet referencedAddresses(Function fn) {
        AddressSet out = new AddressSet();
        if (fn == null) return out;
        AddressIterator it = fn.getBody().getAddresses(true);
        while (it.hasNext()) {
            Address a = it.next();
            for (var r : program.getReferenceManager().getReferencesFrom(a)) {
                out.addRange(r.getToAddress(), r.getToAddress());
            }
        }
        return out;
    }
}

package securityanalyzer.analyzers;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.TreeMap;

import ghidra.program.model.address.Address;
import ghidra.program.model.address.AddressSetView;
import ghidra.program.model.listing.Function;
import ghidra.program.model.listing.Instruction;
import ghidra.program.model.listing.InstructionIterator;
import ghidra.program.model.listing.Program;
import ghidra.program.model.mem.Memory;
import ghidra.program.model.mem.MemoryAccessException;
import ghidra.program.model.scalar.Scalar;
import ghidra.util.task.TaskMonitor;
import securityanalyzer.findings.Finding;
import securityanalyzer.findings.FindingType;
import securityanalyzer.findings.Severity;
import securityanalyzer.util.PCodeHelper;

/**
 * De-obfuscation utilities that act as static analyzers (no execution).
 *
 * <h2>Stack strings</h2>
 * Many obfuscators (and some compiler optimizations) write a string to the
 * stack one byte/word at a time using immediate-store instructions, e.g.:
 * <pre>
 *     MOV [RBP-0x20], 0x68
 *     MOV [RBP-0x1F], 0x65
 *     MOV [RBP-0x1E], 0x6c
 *     ...
 * </pre>
 * We walk each function's instructions, group adjacent stack-relative
 * stores by offset, and reconstruct the strings.
 *
 * <h2>XOR decode</h2>
 * Given a memory range and a key (entered by the analyst via the UI), apply
 * a streaming XOR decode and return the printable result. This is a static,
 * deterministic transform — no execution involved.
 */
public class DeobfuscationAnalyzer {

    private final Program program;
    @SuppressWarnings("unused")
    private final PCodeHelper pcode;

    public DeobfuscationAnalyzer(Program program, PCodeHelper helper) {
        this.program = program;
        this.pcode = helper;
    }

    // ------------------------------------------------------------------
    // Stack string reconstruction
    // ------------------------------------------------------------------

    /**
     * Iterate every function and emit a Finding for each plausibly-real
     * stack string we can reconstruct.
     */
    public List<Finding> scanStackStrings(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        monitor.setMessage("Reconstructing stack strings...");
        for (Function fn : program.getFunctionManager().getFunctions(true)) {
            if (monitor.isCancelled()) break;
            findings.addAll(reconstructForFunction(fn));
        }
        return findings;
    }

    /** Reconstruct stack strings for one function. */
    public List<Finding> reconstructForFunction(Function fn) {
        List<Finding> out = new ArrayList<>();
        if (fn == null) return out;
        AddressSetView body = fn.getBody();
        if (body == null) return out;

        // Map: stack offset -> (byte value, originating instruction address)
        TreeMap<Long, Long> bytes = new TreeMap<>();
        TreeMap<Long, Address> firstSeen = new TreeMap<>();

        InstructionIterator it = program.getListing().getInstructions(body, true);
        while (it.hasNext()) {
            Instruction ins = it.next();
            String mn = ins.getMnemonicString();
            if (!"MOV".equalsIgnoreCase(mn) && !"MOVB".equalsIgnoreCase(mn)
                    && !"STR".equalsIgnoreCase(mn) && !"STRB".equalsIgnoreCase(mn)
                    && !"STRH".equalsIgnoreCase(mn)) {
                continue;
            }
            // We're looking for: MOV [<stack-relative>], <imm>
            int numOps = ins.getNumOperands();
            if (numOps < 2) continue;

            // Operand 0 should reference a stack offset
            Long stackOff = stackOffsetOf(ins, 0);
            if (stackOff == null) continue;

            // Operand 1 should be a scalar immediate
            Object[] imms = ins.getOpObjects(1);
            Long imm = null;
            for (Object o : imms) {
                if (o instanceof Scalar) {
                    imm = ((Scalar) o).getUnsignedValue();
                    break;
                }
            }
            if (imm == null) continue;

            // Determine the size from the data type stored.
            // Default to 1 byte if we can't tell.
            int size = guessStoreSize(ins);
            if (size <= 0) size = 1;

            for (int i = 0; i < size; i++) {
                long b = (imm >> (8 * i)) & 0xFF;
                bytes.put(stackOff + i, b);
                firstSeen.putIfAbsent(stackOff + i, ins.getAddress());
            }
        }

        if (bytes.isEmpty()) return out;

        // Group contiguous offsets into runs and look for printable strings.
        List<long[]> runs = collectRuns(bytes);
        for (long[] run : runs) {
            long start = run[0], end = run[1];
            int len = (int) (end - start + 1);
            if (len < 4) continue;
            byte[] buf = new byte[len];
            for (int i = 0; i < len; i++) {
                Long b = bytes.get(start + i);
                buf[i] = (byte) (b == null ? 0 : (b & 0xFF));
            }
            String s = printableString(buf);
            if (s == null) continue;
            Address site = firstSeen.get(start);
            out.add(Finding.builder(FindingType.STACK_STRING, Severity.INFO)
                    .at(site).in(fn)
                    .title("Stack string: " + abbreviate(s, 64))
                    .describe("Reconstructed string built up via immediate stores to a " +
                            "stack frame inside " + fn.getName() + ". Length " +
                            len + " bytes.")
                    .evidence("\"" + s.replace("\n", "\\n").replace("\r", "\\r") + "\"")
                    .recommend("Add this as a comment at the function entry; " +
                            "consider whether it's a C2 URL, mutex name, or command " +
                            "string.")
                    .build());
        }
        return out;
    }

    // ------------------------------------------------------------------
    // XOR decode helpers (used by UI)
    // ------------------------------------------------------------------

    /**
     * Read {@code length} bytes from {@code start} and XOR them with a
     * repeating key. Return the decoded bytes.
     */
    public byte[] xorDecode(Address start, int length, byte[] key)
            throws MemoryAccessException {
        if (length <= 0 || key == null || key.length == 0) {
            return new byte[0];
        }
        Memory mem = program.getMemory();
        byte[] data = new byte[length];
        mem.getBytes(start, data);
        for (int i = 0; i < data.length; i++) {
            data[i] = (byte) (data[i] ^ key[i % key.length]);
        }
        return data;
    }

    /**
     * Brute-force single-byte XOR over [start, start+length): try every key 1..255
     * and return a list of (key, decoded) for keys that produced a high
     * printable ratio. The result is sorted by descending printability.
     */
    public List<DecodedCandidate> bruteForceSingleByteXor(Address start, int length)
            throws MemoryAccessException {
        Memory mem = program.getMemory();
        byte[] data = new byte[length];
        mem.getBytes(start, data);
        List<DecodedCandidate> out = new ArrayList<>();
        for (int k = 1; k < 256; k++) {
            byte[] dec = new byte[length];
            int printable = 0;
            for (int i = 0; i < length; i++) {
                dec[i] = (byte) (data[i] ^ k);
                int b = dec[i] & 0xFF;
                if (isPrintable(b)) printable++;
            }
            double ratio = (double) printable / length;
            if (ratio >= 0.85) {
                out.add(new DecodedCandidate(k, dec, ratio,
                        new String(dec, java.nio.charset.StandardCharsets.ISO_8859_1)));
            }
        }
        out.sort((a, b) -> Double.compare(b.printableRatio, a.printableRatio));
        return out;
    }

    public static final class DecodedCandidate {
        public final int key;
        public final byte[] bytes;
        public final double printableRatio;
        public final String text;
        DecodedCandidate(int k, byte[] b, double r, String s) {
            this.key = k; this.bytes = b; this.printableRatio = r; this.text = s;
        }
    }

    // ------------------------------------------------------------------
    // Helpers
    // ------------------------------------------------------------------

    /**
     * Try to extract a stack-pointer-relative offset from an instruction
     * operand. Returns null if the operand isn't recognized as such.
     *
     * <p>The implementation is deliberately conservative: we look at the
     * default operand representation and parse common forms like
     * {@code [RBP - 0x20]}, {@code [ESP+0x10]}, {@code [BP-1]}.
     */
    private Long stackOffsetOf(Instruction ins, int operandIndex) {
        // First, check if any of the operand objects is a Scalar that we
        // believe is a stack-relative displacement.
        Object[] objs = ins.getOpObjects(operandIndex);
        Long off = null;
        boolean sawSp = false;
        for (Object o : objs) {
            String s = o.toString();
            String up = s.toUpperCase();
            if (up.equals("RBP") || up.equals("EBP") || up.equals("BP") ||
                up.equals("RSP") || up.equals("ESP") || up.equals("SP") ||
                up.equals("R11") || up.equals("FP") || up.equals("X29")) {
                sawSp = true;
            }
            if (o instanceof Scalar) {
                long v = ((Scalar) o).getSignedValue();
                if (Math.abs(v) < 0x10000) {
                    off = v;
                }
            }
        }
        if (sawSp && off != null) {
            return off;
        }
        return null;
    }

    private int guessStoreSize(Instruction ins) {
        // Many architectures encode size in the mnemonic or operand reps.
        String mn = ins.getMnemonicString().toUpperCase();
        if (mn.endsWith("B") || mn.equals("MOVB") || mn.equals("STRB")) return 1;
        if (mn.endsWith("W") || mn.equals("MOVW") || mn.equals("STRH")) return 2;
        // Look at default operand representation for MOV BYTE PTR / WORD PTR / etc.
        String def0 = ins.getDefaultOperandRepresentation(0).toUpperCase();
        if (def0.contains("BYTE")) return 1;
        if (def0.contains("WORD") && !def0.contains("DWORD") && !def0.contains("QWORD"))
            return 2;
        if (def0.contains("DWORD")) return 4;
        if (def0.contains("QWORD")) return 8;
        // Default to length of immediate
        return 4;
    }

    private static List<long[]> collectRuns(TreeMap<Long, Long> bytes) {
        List<long[]> runs = new ArrayList<>();
        long runStart = 0, runEnd = 0;
        boolean inRun = false;
        Long prev = null;
        for (Map.Entry<Long, Long> e : bytes.entrySet()) {
            long off = e.getKey();
            if (!inRun) {
                runStart = runEnd = off;
                inRun = true;
            } else if (prev != null && off == prev + 1) {
                runEnd = off;
            } else {
                runs.add(new long[]{runStart, runEnd});
                runStart = runEnd = off;
            }
            prev = off;
        }
        if (inRun) {
            runs.add(new long[]{runStart, runEnd});
        }
        return runs;
    }

    private static String printableString(byte[] buf) {
        // Trim any leading NULs from the start
        int s = 0;
        while (s < buf.length && buf[s] == 0) s++;
        // String ends at first NUL after start
        int e = s;
        while (e < buf.length && buf[e] != 0) e++;
        if (e - s < 4) return null;
        int printable = 0;
        for (int i = s; i < e; i++) {
            if (isPrintable(buf[i] & 0xFF)) printable++;
        }
        if (printable * 5 < (e - s) * 4) return null; // <80% printable -> reject
        return new String(buf, s, e - s, java.nio.charset.StandardCharsets.UTF_8);
    }

    private static boolean isPrintable(int b) {
        return (b >= 0x20 && b < 0x7F) || b == '\n' || b == '\r' || b == '\t';
    }

    private static String abbreviate(String s, int max) {
        if (s == null) return "";
        if (s.length() <= max) return s;
        return s.substring(0, max) + "...";
    }
}

    private List<Finding> scanIndicatorCallsFiltered(TaskMonitor monitor, FindingType... only) {
        List<Finding> findings = new ArrayList<>();
        Set<FindingType> filter = (only == null) ? null : new HashSet<>(Arrays.asList(only));

        FunctionIterator funcs = program.getFunctionManager().getFunctions(true);
        monitor.setMessage("Scanning for malware indicator API calls...");

        while (funcs.hasNext() && !monitor.isCancelled()) {
            Function fn = funcs.next();
            if (fn.isThunk()) {
                continue;
            }
            for (PcodeOpAST op : pcode.getPcodeOps(fn, monitor)) {
                if (op.getOpcode() != PcodeOp.CALL && op.getOpcode() != PcodeOp.CALLIND) {
                    continue;
                }
                String name = stripDecorations(pcode.getCalledName(op));
                if (name == null) {
                    continue;
                }
                IndicatorInfo info = SINGLE_API_INDICATORS.get(name);
                if (info == null) {
                    continue;
                }
                if (filter != null && !filter.contains(info.type)) {
                    continue;
                }
                Address site = op.getSeqnum().getTarget();
                findings.add(Finding.builder(info.type, info.severity)
                        .at(site).in(fn)
                        .title(name + " — " + info.type.getDisplayName())
                        .describe(info.description)
                        .evidence("Call to " + name + " at " + site +
                                " inside " + fn.getName())
                        .recommend("Document why this API is used. If unexpected " +
                                "in the binary's stated functionality, treat as " +
                                "suspicious.")
                        .build());
            }
        }
        return findings;
    }

    /**
     * Detect functions that exhibit a complete behavioral combo (e.g. process
     * injection requires three APIs). One finding per combo per function,
     * higher severity than any individual API call.
     */
    public List<Finding> scanBehavioralCombinations(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        FunctionIterator funcs = program.getFunctionManager().getFunctions(true);
        monitor.setMessage("Scanning for behavioral API combinations...");

        while (funcs.hasNext() && !monitor.isCancelled()) {
            Function fn = funcs.next();
            if (fn.isThunk() || fn.isExternal()) {
                continue;
            }
            // Collect all called names within this function
            Set<String> called = new HashSet<>();
            List<Address> sites = new ArrayList<>();
            for (PcodeOpAST op : pcode.getPcodeOps(fn, monitor)) {
                if (op.getOpcode() == PcodeOp.CALL || op.getOpcode() == PcodeOp.CALLIND) {
                    String n = stripDecorations(pcode.getCalledName(op));
                    if (n != null) {
                        if (called.add(n)) {
                            sites.add(op.getSeqnum().getTarget());
                        }
                    }
                }
            }
            for (Map.Entry<FindingType, Set<String>> e : BEHAVIORAL_COMBOS.entrySet()) {
                if (called.containsAll(e.getValue())) {
                    findings.add(Finding.builder(e.getKey(), Severity.CRITICAL)
                            .at(fn.getEntryPoint()).in(fn)
                            .title("Behavioral combo: " + e.getKey().getDisplayName())
                            .describe("Function calls all of: " + String.join(", ",
                                    e.getValue()) + ". Together, these strongly " +
                                    "indicate " + e.getKey().getDisplayName() +
                                    ".")
                            .evidence("Required APIs all present in " + fn.getName())
                            .related(sites)
                            .recommend("Manually trace the data flow between these " +
                                    "calls to confirm the intent and document the " +
                                    "specific injection technique used.")
                            .build());
                }
            }
        }
        return findings;
    }

    /**
     * Look for x86 CPUID instructions where the eax input has values that
     * map to known anti-VM probes (CPUID leaf 0x40000000-0x4000000F is the
     * hypervisor-vendor-id range).
     */
    public List<Finding> scanCpuidAntiVm(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        // Walk every instruction looking for CPUID mnemonic
        InstructionIterator it = program.getListing().getInstructions(true);
        monitor.setMessage("Scanning for CPUID anti-VM probes...");
        while (it.hasNext() && !monitor.isCancelled()) {
            Instruction ins = it.next();
            String mn = ins.getMnemonicString();
            if (!"CPUID".equalsIgnoreCase(mn)) {
                continue;
            }
            // Find the prior MOV EAX, imm in the same basic block (simple heuristic)
            Instruction prev = ins.getPrevious();
            int hops = 0;
            while (prev != null && hops < 8) {
                String pmn = prev.getMnemonicString();
                if ("MOV".equalsIgnoreCase(pmn) || "XOR".equalsIgnoreCase(pmn)) {
                    Object[] ops = prev.getOpObjects(0);
                    if (ops.length > 0 && ops[0].toString().equalsIgnoreCase("EAX")) {
                        // Get scalar input
                        Object[] in1 = prev.getOpObjects(1);
                        Long val = null;
                        for (Object o : in1) {
                            Long v = PCodeHelper.scalarValue(o);
                            if (v != null) {
                                val = v;
                                break;
                            }
                        }
                        if (val != null) {
                            Function fn = program.getFunctionManager().getFunctionContaining(
                                    ins.getAddress());
                            if (val == 0x40000000L || (val >= 0x40000000L && val <= 0x4000000FL)) {
                                findings.add(Finding.builder(FindingType.ANTI_VM, Severity.HIGH)
                                        .at(ins.getAddress()).in(fn)
                                        .title("CPUID hypervisor-leaf probe")
                                        .describe("CPUID with EAX=0x" + Long.toHexString(val) +
                                                " queries the hypervisor vendor ID range. " +
                                                "Strong anti-VM indicator.")
                                        .evidence("CPUID at " + ins.getAddress() +
                                                " preceded by MOV EAX, 0x" +
                                                Long.toHexString(val))
                                        .recommend("Patch out the check or hook CPUID " +
                                                "in the analysis VM if needed.")
                                        .build());
                            } else if (val == 1L) {
                                // EAX=1: feature info — bit 31 of ECX is the
                                // "hypervisor present" bit, frequently checked.
                                findings.add(Finding.builder(FindingType.ANTI_VM, Severity.MEDIUM)
                                        .at(ins.getAddress()).in(fn)
                                        .title("CPUID feature query (possible hypervisor bit check)")
                                        .describe("CPUID with EAX=1 returns feature flags; " +
                                                "ECX bit 31 indicates hypervisor presence " +
                                                "and is commonly checked by anti-VM code.")
                                        .evidence("CPUID at " + ins.getAddress())
                                        .recommend("Check for subsequent BT/TEST against " +
                                                "ECX bit 31.")
                                        .build());
                            }
                        }
                    }
                }
                if (prev.getFlowType().isJump() || prev.getFlowType().isCall()) {
                    break;
                }
                prev = prev.getPrevious();
                hops++;
            }
        }
        return findings;
    }

    /**
     * Walk defined strings in the program; emit findings for ones that
     * look like persistence registry paths or common malware artifacts.
     */
    public List<Finding> scanSuspiciousStrings(TaskMonitor monitor) {

    public List<Finding> scanRegistryStrings(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        SymbolTableIteratorAdapter strs = new SymbolTableIteratorAdapter(
                program.getSymbolTable().getSymbolIterator());
        monitor.setMessage("Scanning for suspicious registry strings...");
        // Walking defined data items is more reliable than the symbol table for strings
        ghidra.program.model.listing.DataIterator dataIt =
                program.getListing().getDefinedData(true);
        while (dataIt.hasNext() && !monitor.isCancelled()) {
            ghidra.program.model.listing.Data d = dataIt.next();
            Object v = d.getValue();
            if (!(v instanceof String)) {
                continue;
            }
            String s = (String) v;
            for (String susp : SUSPICIOUS_REG_PATHS) {
                if (s.equalsIgnoreCase(susp) || s.toLowerCase().contains(susp.toLowerCase())) {
                    Function fn = program.getFunctionManager()
                            .getFunctionContaining(d.getAddress());
                    findings.add(Finding.builder(FindingType.PERSISTENCE, Severity.HIGH)
                            .at(d.getAddress()).in(fn)
                            .title("Suspicious registry key reference")
                            .describe("String reference to a registry path commonly " +
                                    "used for persistence: \"" + susp + "\".")
                            .evidence("String at " + d.getAddress() + ": " + s)
                            .recommend("Find the call site that uses this string and " +
                                    "trace the value being written.")
                            .build());
                    break;
                }
            }
        }
        return findings;
    }

    // Tiny adapter so we can use the SymbolIterator in a more convenient form
    @SuppressWarnings("unused")
    private static class SymbolTableIteratorAdapter {
        private final SymbolIterator it;
        SymbolTableIteratorAdapter(SymbolIterator it) { this.it = it; }
        boolean hasNext() { return it.hasNext(); }
        Symbol next() { return it.next(); }
    }

    private static String stripDecorations(String name) {
        if (name == null) return null;
        int idx = name.lastIndexOf("::");
        if (idx >= 0) name = name.substring(idx + 2);
        while (name.startsWith("_")) name = name.substring(1);
        int at = name.indexOf('@');
        if (at >= 0) name = name.substring(0, at);
        return name;
    }

    /** Run every vulnerability detector. */
    public List<Finding> scanAll(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        findings.addAll(scanDangerousFunctions(monitor));
        findings.addAll(scanFormatStrings(monitor));
        findings.addAll(scanIntegerOverflow(monitor));
        findings.addAll(scanCommandInjection(monitor));
        findings.addAll(scanDoubleAndUseAfterFree(monitor));
        return findings;

    /**
     * Find calls to known-dangerous functions. Two cases:
     * <ol>
     *   <li>Intrinsically dangerous (gets/strcpy/...) — always a HIGH finding.</li>
     *   <li>Bounded-but-tainted-size (memcpy(dst,src,n) where n is tainted)
     *       — MEDIUM finding using the P-code taint heuristic.</li>
     * </ol>
     */
    public List<Finding> scanDangerousFunctions(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        FunctionIterator funcs = program.getFunctionManager().getFunctions(true);
        monitor.setMessage("Scanning for dangerous function calls...");

        while (funcs.hasNext() && !monitor.isCancelled()) {
            Function fn = funcs.next();
            if (fn.isThunk() || fn.isExternal()) {
                continue;
            }
            for (PcodeOpAST op : pcode.getPcodeOps(fn, monitor)) {
                if (op.getOpcode() != PcodeOp.CALL && op.getOpcode() != PcodeOp.CALLIND) {
                    continue;
                }
                String calledName = stripUnderscoresAndDecorations(pcode.getCalledName(op));
                if (calledName == null) {
                    continue;
                }

                Address site = op.getSeqnum().getTarget();

                // Case 1: intrinsically dangerous
                String reason = INTRINSICALLY_DANGEROUS.get(calledName);
                if (reason != null) {
                    Severity sev = calledName.equals("gets") || calledName.equals("_gets")
                            ? Severity.CRITICAL : Severity.HIGH;
                    findings.add(Finding.builder(FindingType.UNBOUNDED_COPY, sev)
                            .at(site).in(fn)
                            .title("Call to " + calledName + "()")
                            .describe(reason)
                            .evidence("Located at " + site + " in " + fn.getName() +
                                    " — call resolves to " + calledName)
                            .recommend("Replace with bounded equivalent " +
                                    "(strncpy_s/snprintf/fgets+strtok) and validate " +
                                    "destination buffer size at every call site.")
                            .build());
                    continue;
                }

                // Case 2: bounded-but-tainted size
                Integer sizeIdx = SIZE_BOUNDED_DANGEROUS.get(calledName);
                if (sizeIdx != null) {
                    Varnode sizeArg = pcode.getArg(op, sizeIdx);
                    if (sizeArg == null) {
                        continue;
                    }
                    Long sizeConst = pcode.getConstantValue(sizeArg);
                    if (sizeConst == null && pcode.isLikelyTainted(sizeArg)) {
                        findings.add(Finding.builder(FindingType.UNBOUNDED_COPY, Severity.MEDIUM)
                                .at(site).in(fn)
                                .title("Tainted size argument to " + calledName + "()")
                                .describe("The size/length argument is not a compile-time " +
                                        "constant and appears to derive from user-controlled " +
                                        "input. If the source is also attacker-controlled, " +
                                        "this is exploitable.")
                                .evidence("Argument " + sizeIdx + " of " + calledName +
                                        " is non-constant and traces to a parameter or " +
                                        "loaded value (P-code taint heuristic).")
                                .recommend("Validate the length against the destination " +
                                        "buffer size before the call. Add a sanity " +
                                        "ceiling consistent with the receiving buffer.")
                                .build());
                    } else if (sizeConst != null && sizeConst >= 0x10000) {
                        findings.add(Finding.builder(FindingType.UNBOUNDED_COPY, Severity.LOW)
                                .at(site).in(fn)
                                .title("Very large constant size for " + calledName + "()")
                                .describe("Size constant 0x" + Long.toHexString(sizeConst) +
                                        " is unusually large for a memory operation; " +
                                        "verify it's intentional.")
                                .evidence(calledName + " size=" + sizeConst)
                                .recommend("Confirm destination buffer can accommodate " +
                                        "this many bytes.")
                                .build());
                    }
                }
            }
        }
        return findings;
    }

    /**
     * Detect format-string vulnerabilities: calls where the format-spec arg
     * is non-constant and traces to a tainted source.
     */
    public List<Finding> scanFormatStrings(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        FunctionIterator funcs = program.getFunctionManager().getFunctions(true);
        monitor.setMessage("Scanning for format string vulnerabilities...");

        while (funcs.hasNext() && !monitor.isCancelled()) {
            Function fn = funcs.next();
            if (fn.isThunk() || fn.isExternal()) {
                continue;
            }
            for (PcodeOpAST op : pcode.getPcodeOps(fn, monitor)) {
                if (op.getOpcode() != PcodeOp.CALL && op.getOpcode() != PcodeOp.CALLIND) {
                    continue;
                }
                String name = stripUnderscoresAndDecorations(pcode.getCalledName(op));
                if (name == null) {
                    continue;
                }
                Integer fmtIdx = FORMAT_FUNCTIONS.get(name);
                if (fmtIdx == null) {
                    continue;
                }
                Varnode fmtArg = pcode.getArg(op, fmtIdx);
                if (fmtArg == null) {
                    continue;
                }

                String literal = pcode.getStringValue(fmtArg);
                if (literal != null) {
                    // Format string is a literal — safe (with respect to format injection)
                    continue;
                }
                if (pcode.isLikelyTainted(fmtArg)) {
                    Address site = op.getSeqnum().getTarget();
                    findings.add(Finding.builder(FindingType.FORMAT_STRING, Severity.HIGH)
                            .at(site).in(fn)
                            .title("Tainted format string in " + name + "()")
                            .describe("The format-string argument to " + name + " is not a " +
                                    "string literal. If attacker-controlled input flows here, " +
                                    "this allows arbitrary read (%s/%x/%n) and possible write.")
                            .evidence("Argument index " + fmtIdx +
                                    " is non-constant and tainted (P-code analysis).")
                            .recommend("Always pass a constant format string literal: " +
                                    name + "(\"%s\", user_data) instead of " + name +
                                    "(user_data).")
                            .build());
                }
            }
        }
        return findings;
    }

    /**
     * Heuristic detection of integer overflow / truncation patterns:
     * <ul>
     *   <li>An INT_ADD / INT_MULT result is used as the size argument of an
     *       allocation function (malloc/calloc/HeapAlloc/...).</li>
     *   <li>A wider varnode is INT_SEXT/INT_ZEXT-truncated to a smaller width
     *       and then used as a size.</li>
     * </ul>
     */
    public List<Finding> scanIntegerOverflow(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        Set<String> alloc = new HashSet<>();
        alloc.add("malloc");
        alloc.add("calloc");
        alloc.add("realloc");
        alloc.add("alloca");
        alloc.add("HeapAlloc");
        alloc.add("VirtualAlloc");
        alloc.add("LocalAlloc");
        alloc.add("GlobalAlloc");
        alloc.add("operator.new");
        alloc.add("new");
        alloc.add("new[]");

        FunctionIterator funcs = program.getFunctionManager().getFunctions(true);
        monitor.setMessage("Scanning for integer overflow patterns...");

        while (funcs.hasNext() && !monitor.isCancelled()) {
            Function fn = funcs.next();
            if (fn.isThunk() || fn.isExternal()) {
                continue;
            }
            for (PcodeOpAST op : pcode.getPcodeOps(fn, monitor)) {
                if (op.getOpcode() != PcodeOp.CALL && op.getOpcode() != PcodeOp.CALLIND) {
                    continue;
                }
                String name = stripUnderscoresAndDecorations(pcode.getCalledName(op));
                if (name == null || !alloc.contains(name)) {
                    continue;
                }
                // For calloc, the allocation is nmemb*size — index 1 or 2;
                // for the rest, the size is the last input.
                int sizeArgIdx = (op.getNumInputs() >= 3 && name.equals("calloc"))
                        ? 2 : op.getNumInputs() - 1;
                Varnode sizeArg = pcode.getArg(op, sizeArgIdx);
                if (sizeArg == null) {
                    continue;
                }

                PcodeOp def = sizeArg.getDef();
                if (def == null) {
                    continue;
                }

                int defOp = def.getOpcode();
                Address site = op.getSeqnum().getTarget();

                if (defOp == PcodeOp.INT_ADD || defOp == PcodeOp.INT_MULT) {
                    // size = a OP b — does either operand look tainted?
                    boolean tainted = pcode.isLikelyTainted(def.getInput(0)) ||
                                      pcode.isLikelyTainted(def.getInput(1));
                    if (tainted) {
                        findings.add(Finding.builder(
                                FindingType.INTEGER_OVERFLOW, Severity.HIGH)
                                .at(site).in(fn)
                                .title("Tainted arithmetic feeds " + name + "()")
                                .describe("The size argument is the result of " +
                                        (defOp == PcodeOp.INT_ADD ? "addition" : "multiplication") +
                                        " involving at least one tainted operand. " +
                                        "If the arithmetic wraps, the allocation may be " +
                                        "smaller than expected.")
                                .evidence("size = " + (defOp == PcodeOp.INT_ADD ? "ADD" : "MULT") +
                                        " of tainted varnode at " + site)
                                .recommend("Add overflow-checked arithmetic " +
                                        "(e.g. __builtin_mul_overflow / SafeInt) before " +
                                        "calling " + name + ". Reject sizes that would wrap.")
                                .build());
                    }
                } else if (defOp == PcodeOp.SUBPIECE) {
                    // Truncation: a wider varnode becomes a narrower size argument.
                    findings.add(Finding.builder(
                            FindingType.INTEGER_TRUNCATION, Severity.MEDIUM)
                            .at(site).in(fn)
                            .title("Truncated size feeds " + name + "()")
                            .describe("The size argument is a SUBPIECE (truncation) of a " +
                                    "wider value. High bits are discarded; if those bits " +
                                    "were non-zero, the actual allocation will be smaller " +
                                    "than the original computation indicated.")
                            .evidence("SUBPIECE -> " + name + " size argument")
                            .recommend("Audit the cast/truncation. Ensure the wider value " +
                                    "is bounded before truncating, or change the size type " +
                                    "to match the source.")
                            .build());
                }
            }
        }
        return findings;
    }

    /**
     * Detect calls to shell-exec functions whose first argument is tainted.
     */
    public List<Finding> scanCommandInjection(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        FunctionIterator funcs = program.getFunctionManager().getFunctions(true);
        monitor.setMessage("Scanning for command injection sinks...");

        while (funcs.hasNext() && !monitor.isCancelled()) {
            Function fn = funcs.next();
            if (fn.isThunk() || fn.isExternal()) {
                continue;
            }
            for (PcodeOpAST op : pcode.getPcodeOps(fn, monitor)) {
                if (op.getOpcode() != PcodeOp.CALL && op.getOpcode() != PcodeOp.CALLIND) {
                    continue;
                }
                String name = stripUnderscoresAndDecorations(pcode.getCalledName(op));
                if (name == null || !SHELL_EXEC_FUNCTIONS.contains(name)) {
                    continue;
                }
                Varnode cmd = pcode.getArg(op, 1);
                if (cmd == null) {
                    continue;
                }
                Address site = op.getSeqnum().getTarget();

                // If the command string is fully constant, that's only INFO-level.
                String literal = pcode.getStringValue(cmd);
                if (literal != null) {
                    findings.add(Finding.builder(FindingType.COMMAND_INJECTION, Severity.INFO)
                            .at(site).in(fn)
                            .title("Hardcoded command in " + name + "()")
                            .describe("Call to " + name + " uses a constant command line. " +
                                    "Worth reviewing for trust of the executable path.")
                            .evidence("cmd = \"" + abbreviate(literal, 200) + "\"")
                            .recommend("Use absolute paths and avoid shell interpretation " +
                                    "where possible.")
                            .build());
                    continue;
                }
                if (pcode.isLikelyTainted(cmd)) {
                    findings.add(Finding.builder(FindingType.COMMAND_INJECTION, Severity.HIGH)
                            .at(site).in(fn)
                            .title("Tainted command line passed to " + name + "()")
                            .describe("The command-line argument is non-constant and " +
                                    "traces to user-controlled input. If reachable from " +
                                    "an untrusted source, this is an OS command injection.")
                            .evidence("Argument 1 of " + name + " is tainted at " + site)
                            .recommend("Avoid shell-style APIs entirely. Use exec*-style " +
                                    "calls with an argv array of validated tokens.")
                            .build());
                }
            }
        }
        return findings;
    }

    /**
     * Heuristic: within a single function, find variables that flow into
     * free()/HeapFree() and are subsequently dereferenced or freed again.
     *
     * <p>This is intra-procedural only — a real UAF detector needs full
     * inter-procedural points-to. We aim for high signal in the common
     * obvious case: free(p); ... ; *p = ... ; (or another free(p)).
     */
    public List<Finding> scanDoubleAndUseAfterFree(TaskMonitor monitor) {
        List<Finding> findings = new ArrayList<>();
        Set<String> freeFuncs = new HashSet<>();
        freeFuncs.add("free");
        freeFuncs.add("HeapFree");
        freeFuncs.add("LocalFree");
        freeFuncs.add("GlobalFree");
        freeFuncs.add("VirtualFree");
        freeFuncs.add("operator.delete");
        freeFuncs.add("delete");
        freeFuncs.add("delete[]");

        FunctionIterator funcs = program.getFunctionManager().getFunctions(true);
        monitor.setMessage("Scanning for use-after-free and double-free...");

        while (funcs.hasNext() && !monitor.isCancelled()) {
            Function fn = funcs.next();
            if (fn.isThunk() || fn.isExternal()) {
                continue;
            }
            List<PcodeOpAST> ops = pcode.getPcodeOps(fn, monitor);

            // Map: high-variable-id -> first free site (PcodeOp address)
            Map<Long, PcodeOp> freed = new HashMap<>();

            for (PcodeOpAST op : ops) {
                if (op.getOpcode() == PcodeOp.CALL || op.getOpcode() == PcodeOp.CALLIND) {
                    String name = stripUnderscoresAndDecorations(pcode.getCalledName(op));
                    if (name != null && freeFuncs.contains(name)) {
                        // Argument index for the pointer:
                        //   free(p) -> 1, HeapFree(hHeap, flags, p) -> 3, others -> 1
                        int argIdx = name.equals("HeapFree") ? 3 : 1;
                        Varnode p = pcode.getArg(op, argIdx);
                        if (p == null) {
                            continue;
                        }
                        Long key = highVarKey(p);
                        if (key == null) {
                            continue;
                        }
                        PcodeOp prevFree = freed.get(key);
                        if (prevFree != null) {
                            findings.add(Finding.builder(FindingType.DOUBLE_FREE, Severity.HIGH)
                                    .at(op.getSeqnum().getTarget()).in(fn)
                                    .title("Possible double-free")
                                    .describe("The same pointer is passed to " + name +
                                            " twice within the same function with no " +
                                            "intervening reassignment we could detect.")
                                    .evidence("First free at " +
                                            prevFree.getSeqnum().getTarget() +
                                            ", second at " + op.getSeqnum().getTarget())
                                    .related(prevFree.getSeqnum().getTarget())
                                    .recommend("Set the pointer to NULL after free, or " +
                                            "use scoped ownership (RAII / smart pointers).")
                                    .build());
                        }
                        freed.put(key, op);
                    }
                } else if (op.getOpcode() == PcodeOp.LOAD || op.getOpcode() == PcodeOp.STORE) {
                    Varnode ptr = op.getInput(1); // input 0 is space-id
                    if (ptr == null) {
                        continue;
                    }
                    Long key = highVarKey(ptr);
                    if (key == null) {
                        continue;
                    }
                    PcodeOp prevFree = freed.get(key);
                    if (prevFree != null) {
                        findings.add(Finding.builder(FindingType.USE_AFTER_FREE, Severity.HIGH)
                                .at(op.getSeqnum().getTarget()).in(fn)
                                .title("Possible use-after-free")
                                .describe("A pointer that was freed earlier in this function " +
                                        "is dereferenced again with no visible reassignment.")
                                .evidence("Free at " + prevFree.getSeqnum().getTarget() +
                                        ", dereference (" +
                                        (op.getOpcode() == PcodeOp.LOAD ? "LOAD" : "STORE") +
                                        ") at " + op.getSeqnum().getTarget())
                                .related(prevFree.getSeqnum().getTarget())
                                .recommend("Null the pointer after free, or restructure to " +
                                        "avoid retaining the reference.")
                                .build());
                    }
                }
            }
        }
        return findings;
    }

    // ----------------------------------------------------------------------
    // Helpers
    // ----------------------------------------------------------------------

    /**
     * Stable identity for a "the same logical variable" check. We use the
     * HighVariable ID if available, else the varnode's address+offset+size.
     */
    private Long highVarKey(Varnode vn) {
        if (vn == null) {
            return null;
        }
        if (vn.getHigh() != null && vn.getHigh().getRepresentative() != null) {
            // Encode: representative offset + size + spaceID
            Varnode rep = vn.getHigh().getRepresentative();
            long s = rep.getAddress() != null ? rep.getAddress().getAddressableWordOffset() : 0;
            return (s << 16) ^ ((long) rep.getSize() << 8) ^ rep.hashCode();
        }
        return null;
    }

    /**
     * Strip leading underscores, '@'-decorations and Ghidra import-thunk
     * "&lt;EXTERNAL&gt;::" prefixes so symbol names compare cleanly.
     */
    private static String stripUnderscoresAndDecorations(String s) {
        if (s == null) {
            return null;
        }
        String out = s;
        // Remove module prefix: "MSVCRT.dll::strcpy" -> "strcpy"
        int idx = out.lastIndexOf("::");
        if (idx >= 0) {
            out = out.substring(idx + 2);
        }
        // Remove leading underscores
        while (out.startsWith("_")) {
            out = out.substring(1);
        }
        // Strip stdcall decoration: "name@4" -> "name"
        int at = out.indexOf('@');
        if (at >= 0) {
            out = out.substring(0, at);
        }
        return out;
    }

    private static String abbreviate(String s, int max) {
        if (s == null) return "";
        if (s.length() <= max) return s;
        return s.substring(0, max) + "...";
    }
}

package securityanalyzer.findings;

import java.util.ArrayList;
import java.util.Collections;
import java.util.List;

import ghidra.program.model.address.Address;
import ghidra.program.model.listing.Function;

/**
 * One finding produced by an analyzer. Findings are immutable value objects.
 * Build them with {@link Builder}.
 */
public final class Finding {

    private final FindingType type;
    private final Severity severity;
    private final Address address;
    private final Function function;
    private final String title;
    private final String description;
    private final String evidence;
    private final String recommendation;
    private final List<Address> related;
    private final long timestamp;

    private Finding(Builder b) {
        this.type = b.type;
        this.severity = b.severity;
        this.address = b.address;
        this.function = b.function;
        this.title = b.title;
        this.description = b.description;
        this.evidence = b.evidence;
        this.recommendation = b.recommendation;
        this.related = Collections.unmodifiableList(new ArrayList<>(b.related));
        this.timestamp = System.currentTimeMillis();
    }

    public FindingType getType() { return type; }
    public Severity getSeverity() { return severity; }
    public Address getAddress() { return address; }
    public Function getFunction() { return function; }
    public String getTitle() { return title; }
    public String getDescription() { return description; }
    public String getEvidence() { return evidence; }
    public String getRecommendation() { return recommendation; }
    public List<Address> getRelated() { return related; }
    public long getTimestamp() { return timestamp; }

    public String getFunctionName() {
        return function != null ? function.getName() : "<no function>";
    }

    @Override
    public String toString() {
        return String.format("[%s][%s] %s @ %s",
                severity.getLabel(), type.getDisplayName(), title,
                address != null ? address.toString() : "?");
    }

    public static Builder builder(FindingType type, Severity severity) {
        return new Builder(type, severity);
    }

    /** Mutable builder. */
    public static final class Builder {
        private final FindingType type;
        private final Severity severity;
        private Address address;
        private Function function;
        private String title = "";
        private String description = "";
        private String evidence = "";
        private String recommendation = "";
        private final List<Address> related = new ArrayList<>();

        private Builder(FindingType t, Severity s) {
            this.type = t;
            this.severity = s;
        }

        public Builder at(Address a) { this.address = a; return this; }
        public Builder in(Function f) { this.function = f; return this; }
        public Builder title(String t) { this.title = t; return this; }
        public Builder describe(String d) { this.description = d; return this; }
        public Builder evidence(String e) { this.evidence = e; return this; }
        public Builder recommend(String r) { this.recommendation = r; return this; }
        public Builder related(Address a) { if (a != null) related.add(a); return this; }
        public Builder related(List<Address> l) { if (l != null) related.addAll(l); return this; }

        public Finding build() {
            if (title == null || title.isEmpty()) {
                title = type.getDisplayName();
            }
            return new Finding(this);
        }
    }
}

 * Each value carries a CWE identifier where applicable, plus a stable
 * machine-readable id used in reports and JSON exports.

public enum FindingType {

 *
 * SecurityAnalyzerProvider
 * ------------------------
 * The dockable UI for the Security Analyzer plugin. Responsibilities:
 *
 *   - Owns the findings table (Severity / Type / Address / Function / Title).
 *   - Bridges menu actions from {@link securityanalyzer.SecurityAnalyzerPlugin}
 *     to the analyzer classes; every long-running scan executes inside a
 *     {@link TaskLauncher}/{@link Task} so it has a real {@link TaskMonitor}
 *     and the user can cancel it.
 *   - Annotates the program when findings arrive (bookmark + pre-comment),
 *     and exposes "Tag Current Address" / "Clear Findings" actions.
 *   - Exports Markdown, JSON, and per-finding writeup templates via
 *     {@link ReportGenerator}.
 *
 * Design notes:
 *   - The provider creates one {@link PCodeHelper} per scan invocation and
 *     closes it via try-with-resources so the underlying DecompInterface is
 *     released promptly. Sharing a single helper across long-lived scans
 *     would keep decompiler resources pinned.
 *   - All Swing mutation happens on the EDT via {@code Swing.runLater}; the
 *     analyzer threads only touch the program through Ghidra's thread-safe
 *     read APIs and post results back when done.
 *   - When findings are added, we open a transaction and write a Bookmark
 *     and an EOL comment so the analyst sees them in the listing without
 *     having to look at our table.

    /**
     * Brute-force single-byte XOR over the current listing selection. Operates
     * inline (it's bounded to whatever the analyst highlighted) and pops the
     * top candidates in a dialog so they can pick one to apply as a comment.
     */
    public void runXorDecodeSelection() {
        if (!requireProgram()) {
            return;
        }
        ProgramSelection sel = getCurrentSelection();
        if (sel == null || sel.isEmpty()) {
            Msg.showWarn(this, mainPanel, "XOR Decode",
                "Select a range of bytes in the Listing first.");
            return;
        }
        AddressSetView ranges = sel;
        Address start = ranges.getMinAddress();
        long length = ranges.getNumAddresses();
        if (length <= 0 || length > 4096) {
            Msg.showWarn(this, mainPanel, "XOR Decode",
                "Selection must be between 1 and 4096 bytes.");
            return;
        }

        AtomicReference<List<DecodedCandidate>> ref = new AtomicReference<>();
        TaskLauncher.launchModal("XOR Brute Force", monitor -> {
            try (PCodeHelper helper = new PCodeHelper(currentProgram)) {
                DeobfuscationAnalyzer da = new DeobfuscationAnalyzer(currentProgram, helper);
                ref.set(da.bruteForceSingleByteXor(start, (int) length));
            } catch (Exception ex) {
                Msg.error(this, "XOR brute force failed", ex);
            }
        });

        List<DecodedCandidate> candidates = ref.get();
        if (candidates == null || candidates.isEmpty()) {
            Msg.showInfo(this, mainPanel, "XOR Decode",
                "No printable single-byte XOR keys produced a likely string.");
            return;
        }
        StringBuilder sb = new StringBuilder("Top candidates (printable ratio):\n\n");
        int show = Math.min(8, candidates.size());
        for (int i = 0; i < show; i++) {
            DecodedCandidate c = candidates.get(i);
            sb.append(String.format("key=0x%02X  %.0f%%  \"%s\"%n",
                c.key, c.printableRatio * 100.0, truncate(c.text, 60)));
        }
        DecodedCandidate top = candidates.get(0);
        sb.append("\nApply top result (key=0x")
          .append(String.format("%02X", top.key))
          .append(") as a pre-comment at ").append(start).append("?");
        int ans = JOptionPane.showConfirmDialog(mainPanel, sb.toString(),
            "XOR Decode Candidates", JOptionPane.YES_NO_OPTION);
        if (ans == JOptionPane.YES_OPTION) {
            applyDecodedComment(start, top);
        }
    }

    private void applyDecodedComment(Address at, DecodedCandidate c) {
        Program p = currentProgram;
        int tx = p.startTransaction("Apply XOR decode comment");
        try {
            String existing = p.getListing().getComment(CommentType.PRE, at);
            String line = String.format("%sXOR-decoded (key=0x%02X): \"%s\"",
                COMMENT_PREFIX, c.key, c.text);
            String combined = (existing == null || existing.isEmpty())
                ? line : existing + "\n" + line;
            p.getListing().setComment(at, CommentType.PRE, combined);
            // Bookmark too, so it shows up in the Bookmark Manager view.
            BookmarkManager bm = p.getBookmarkManager();
            bm.setBookmark(at, ghidra.program.model.listing.BookmarkType.NOTE,
                BOOKMARK_CATEGORY, line);
        } finally {
            p.endTransaction(tx, true);
        }
    }

    private File chooseSaveFile(String title, FileNameExtensionFilter filter, String ext) {
        JFileChooser fc = new JFileChooser();
        fc.setDialogTitle(title);
        fc.setFileFilter(filter);
        int r = fc.showSaveDialog(mainPanel);
        if (r != JFileChooser.APPROVE_OPTION) {

        return f;

    /* ----------------------------------------------------------------- */
    /* Scan dispatcher                                                   */
    /* ----------------------------------------------------------------- */

    @FunctionalInterface
    private interface ScanFn {
        List<Finding> run(Program program, TaskMonitor monitor) throws Exception;
    }

    private void runScan(String title, ScanFn fn) {
        if (!requireProgram()) {
            return;
        }
        final Program program = currentProgram;
        Swing.runLater(() -> statusLabel.setText(" Running: " + title + "..."));

        Task task = new Task(title, true, true, false) {
            @Override
            public void run(TaskMonitor monitor) {
                List<Finding> result;
                try {
                    result = fn.run(program, monitor);
                } catch (CancelledException ce) {
                    Swing.runLater(() -> statusLabel.setText(" Cancelled: " + title));
                    return;
                } catch (Exception ex) {
                    Msg.error(SecurityAnalyzerProvider.this, title + " failed", ex);
                    Swing.runLater(() -> statusLabel.setText(" Failed: " + title
                        + " (" + ex.getClass().getSimpleName() + ")"));
                    return;
                }
                if (result == null) {
                    result = Collections.emptyList();
                }
                List<Finding> newOnes = result;
                addFindings(newOnes);
                Swing.runLater(() -> statusLabel.setText(" " + title + ": "
                    + newOnes.size() + " new finding(s). Total: " + findings.size() + "."));
            }
        };
        new TaskLauncher(task, mainPanel);
    }

    /* ----------------------------------------------------------------- */
    /* Adding findings + program annotation                              */
    /* ----------------------------------------------------------------- */

    private void addFindings(List<Finding> newOnes) {
        if (newOnes == null || newOnes.isEmpty()) {
            return;
        }
        synchronized (findings) {
            findings.addAll(newOnes);
        }
        annotateProgram(newOnes);
        Swing.runLater(() -> {
            tableModel.fireTableDataChanged();
            // Auto-show the panel the first time findings arrive.
            if (!isVisible()) {
                setVisible(true);
            }
        });
    }

    private void annotateProgram(List<Finding> newOnes) {
        if (currentProgram == null) {
            return;
        }
        Program p = currentProgram;
        int tx = p.startTransaction("SecurityAnalyzer annotations");
        try {
            BookmarkManager bm = p.getBookmarkManager();
            Listing listing = p.getListing();
            for (Finding f : newOnes) {
                if (f.getAddress() == null) continue;
                String label = f.getSeverity().getLabel() + " / "
                    + f.getType().getDisplayName() + ": " + f.getTitle();
                bm.setBookmark(f.getAddress(),
                    ghidra.program.model.listing.BookmarkType.WARNING,
                    BOOKMARK_CATEGORY, label);

                String existing = listing.getComment(CommentType.EOL, f.getAddress());
                String line = COMMENT_PREFIX + f.getSeverity().getLabel()
                    + " " + f.getType().getDisplayName() + ": " + truncate(f.getTitle(), 100);
                if (existing == null || !existing.contains(line)) {
                    String combined = (existing == null || existing.isEmpty())
                        ? line : existing + "\n" + line;
                    listing.setComment(f.getAddress(), CommentType.EOL, combined);
                }
            }
        } finally {
            p.endTransaction(tx, true);
        }
    }

    /* ----------------------------------------------------------------- */
    /* Misc                                                              */
    /* ----------------------------------------------------------------- */

    private static String truncate(String s, int max) {
        if (s == null) return "";
        return s.length() <= max ? s : s.substring(0, max - 1) + "\u2026";
    }

    /* ----------------------------------------------------------------- */
    /* Findings table model                                              */
    /* ----------------------------------------------------------------- */

    private final class FindingsTableModel extends AbstractTableModel {

        private final String[] columns = { "Severity", "Type", "Address", "Function", "Title" };

        @Override public int getRowCount()    { return findings.size(); }
        @Override public int getColumnCount() { return columns.length; }
        @Override public String getColumnName(int c) { return columns[c]; }

        @Override
        public Class<?> getColumnClass(int c) {
            if (c == 0) return Severity.class;
            return String.class;
        }

        Finding get(int row) {
            synchronized (findings) {
                return (row >= 0 && row < findings.size()) ? findings.get(row) : null;
            }
        }

        @Override
        public Object getValueAt(int row, int col) {
            Finding f = get(row);
            if (f == null) return "";
            switch (col) {
                case 0: return f.getSeverity();
                case 1: return f.getType().getDisplayName();
                case 2: return f.getAddress() == null ? "" : f.getAddress().toString();
                case 3: return f.getFunctionName();
                case 4: return f.getTitle();
                default: return "";
            }
        }
    }

package securityanalyzer.util;

import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;

import ghidra.app.decompiler.DecompInterface;
import ghidra.app.decompiler.DecompileResults;
import ghidra.app.decompiler.DecompileOptions;
import ghidra.program.model.address.Address;
import ghidra.program.model.listing.Function;
import ghidra.program.model.listing.Program;
import ghidra.program.model.pcode.HighFunction;
import ghidra.program.model.pcode.HighSymbol;
import ghidra.program.model.pcode.HighVariable;
import ghidra.program.model.pcode.PcodeOp;
import ghidra.program.model.pcode.PcodeOpAST;
import ghidra.program.model.pcode.Varnode;
import ghidra.program.model.scalar.Scalar;
import ghidra.program.model.symbol.RefType;
import ghidra.program.model.symbol.Reference;
import ghidra.program.model.symbol.SymbolTable;
import ghidra.util.task.TaskMonitor;

/**
 * Centralized utilities for P-code based analysis. Maintains a single
 * {@link DecompInterface} per session for performance.
 *
 * <p>P-code is preferred over instruction-level pattern matching because it
 * abstracts over architecture and gives stable arg/return modeling via
 * the high-level (decompiled) function representation.
 */
public class PCodeHelper implements AutoCloseable {

    public static final int DEFAULT_DECOMPILE_TIMEOUT_SEC = 30;

    private final Program program;
    private final DecompInterface decomp;

    public PCodeHelper(Program program) {
        this.program = program;
        this.decomp = new DecompInterface();
        DecompileOptions opts = new DecompileOptions();
        decomp.setOptions(opts);
        decomp.toggleCCode(true);
        decomp.toggleSyntaxTree(true);
        decomp.setSimplificationStyle("decompile");
        if (!decomp.openProgram(program)) {
            throw new RuntimeException("Failed to open program in DecompInterface: " +
                    decomp.getLastMessage());
        }
    }

    public Program getProgram() {
        return program;
    }

    public DecompInterface getDecompiler() {
        return decomp;
    }

    /**
     * Decompile a single function (with caching managed internally by the
     * DecompInterface) and return the {@link HighFunction}, or null on failure.
     */
    public HighFunction decompile(Function fn, TaskMonitor monitor) {
        if (fn == null || monitor.isCancelled()) {
            return null;
        }
        DecompileResults res = decomp.decompileFunction(fn, DEFAULT_DECOMPILE_TIMEOUT_SEC, monitor);
        if (res == null || !res.decompileCompleted()) {
            return null;
        }
        return res.getHighFunction();
    }

    /**
     * Iterate every {@link PcodeOpAST} in a function. Returns an empty list if
     * decompilation failed. The list is materialized to allow random-access.
     */
    public List<PcodeOpAST> getPcodeOps(Function fn, TaskMonitor monitor) {
        List<PcodeOpAST> ops = new ArrayList<>();
        HighFunction hf = decompile(fn, monitor);
        if (hf == null) {
            return ops;
        }
        Iterator<PcodeOpAST> it = hf.getPcodeOps();
        while (it.hasNext() && !monitor.isCancelled()) {
            ops.add(it.next());
        }
        return ops;
    }

    /**
     * Resolve a CALL pcode op to the called Function (when statically known).
     * Returns null for indirect calls that cannot be resolved.
     */
    public Function resolveCall(PcodeOp callOp) {
        if (callOp == null) {
            return null;
        }
        int op = callOp.getOpcode();
        if (op != PcodeOp.CALL && op != PcodeOp.CALLIND) {
            return null;
        }
        Varnode target = callOp.getInput(0);
        if (target == null || !target.isAddress() && !target.isConstant()) {
            // CALLIND with non-constant target - try via references
            Address callsite = callOp.getSeqnum().getTarget();
            return resolveByReference(callsite);
        }
        Address dest = target.getAddress();
        if (dest == null) {
            return null;
        }
        Function f = program.getFunctionManager().getFunctionAt(dest);
        if (f != null) {
            return f;
        }
        // Could be a thunk pointer in .got/.idata - resolve via references
        Address callsite = callOp.getSeqnum().getTarget();
        return resolveByReference(callsite);
    }

    /**
     * Fallback when the call target is computed/indirect: walk the
     * outgoing references at the call site and pick the first call ref
     * whose destination has an associated function.
     */
    private Function resolveByReference(Address callsite) {
        if (callsite == null) {
            return null;
        }
        Reference[] refs = program.getReferenceManager().getReferencesFrom(callsite);
        for (Reference r : refs) {
            RefType t = r.getReferenceType();
            if (t.isCall()) {
                Function f = program.getFunctionManager().getFunctionAt(r.getToAddress());
                if (f != null) {
                    return f;
                }
                // Possibly an external thunk
                f = program.getFunctionManager().getReferencedFunction(r.getToAddress());
                if (f != null) {
                    return f;
                }
            }
        }
        return null;
    }

    /**
     * For a CALL op, return the n'th argument varnode (1-based, matching
     * P-code convention where input 0 is the call target).
     */
    public Varnode getArg(PcodeOp callOp, int oneBasedIndex) {
        if (callOp == null) {
            return null;
        }
        if (oneBasedIndex < 1 || oneBasedIndex >= callOp.getNumInputs()) {
            return null;
        }
        return callOp.getInput(oneBasedIndex);
    }

    /**
     * If the varnode resolves to a constant (after walking through copies),
     * return its long value; otherwise null.
     */
    public Long getConstantValue(Varnode vn) {
        if (vn == null) {
            return null;
        }
        Varnode cur = vn;
        for (int i = 0; i < 8 && cur != null; i++) {
            if (cur.isConstant()) {
                return cur.getOffset();
            }
            // Walk through COPY / CAST / INT_ZEXT
            PcodeOp def = cur.getDef();
            if (def == null) {
                return null;
            }
            int op = def.getOpcode();
            if (op == PcodeOp.COPY || op == PcodeOp.CAST ||
                op == PcodeOp.INT_ZEXT || op == PcodeOp.INT_SEXT) {
                cur = def.getInput(0);
            } else {
                return null;
            }
        }
        return null;
    }

    /**
     * If the varnode is a constant pointer to a string (in any defined
     * memory block), return the string. Returns null otherwise.
     */
    public String getStringValue(Varnode vn) {
        Long c = getConstantValue(vn);
        if (c == null) {
            return null;
        }
        try {
            Address a = program.getAddressFactory().getDefaultAddressSpace().getAddress(c);
            return readNullTerminatedString(a, 4096);
        } catch (Exception e) {
            return null;
        }
    }

    /**
     * Read a C-style string of up to maxLen bytes from {@code addr}.
     * Returns null on any read failure or if the address is undefined.
     */
    public String readNullTerminatedString(Address addr, int maxLen) {
        if (addr == null) {
            return null;
        }
        try {
            byte[] buf = new byte[maxLen];
            int n = program.getMemory().getBytes(addr, buf);
            int end = 0;
            while (end < n && buf[end] != 0) {
                end++;
            }
            if (end == 0) {
                return null;
            }
            // Quick printable check
            int printable = 0;
            for (int i = 0; i < end; i++) {
                int b = buf[i] & 0xFF;
                if (b >= 0x20 && b < 0x7F || b == '\n' || b == '\r' || b == '\t') {
                    printable++;
                }
            }
            if (printable * 4 < end * 3) {
                return null; // not predominantly printable
            }
            return new String(buf, 0, end, java.nio.charset.StandardCharsets.UTF_8);
        } catch (Exception e) {
            return null;
        }
    }

    /**
     * Returns true if the varnode appears to be a "tainted" / non-constant
     * input to the current function — i.e. it ultimately derives from a
     * function parameter, an external read, or other unknown source.
     *
     * <p>Used as a conservative heuristic for taint-style detection: if the
     * argument to {@code printf}'s format slot is tainted, that's a finding.
     */
    public boolean isLikelyTainted(Varnode vn) {
        if (vn == null) {
            return false;
        }
        if (vn.isConstant()) {
            return false;
        }
        // Walk back through definitions; if any input is a parameter or
        // load from non-readonly memory, treat as tainted.
        return isLikelyTaintedRecursive(vn, 16);
    }

    private boolean isLikelyTaintedRecursive(Varnode vn, int depth) {
        if (vn == null || depth <= 0) {
            return true; // give up conservatively
        }
        if (vn.isConstant()) {
            return false;
        }
        if (vn.isInput()) {
            // Function input parameter - definitely tainted from the
            // current function's perspective.
            return true;
        }
        HighVariable hv = vn.getHigh();
        if (hv != null) {
            HighSymbol sym = hv.getSymbol();
            if (sym != null && sym.isParameter()) {
                return true;
            }
        }
        PcodeOp def = vn.getDef();
        if (def == null) {
            return true; // no definition visible -> conservative
        }
        int op = def.getOpcode();
        if (op == PcodeOp.LOAD || op == PcodeOp.CALL || op == PcodeOp.CALLIND) {
            // Loaded from memory or returned from a call - treat as tainted.
            return true;
        }
        // Recurse on inputs
        for (int i = 0; i < def.getNumInputs(); i++) {
            if (isLikelyTaintedRecursive(def.getInput(i), depth - 1)) {
                return true;
            }
        }
        return false;
    }

    /**
     * Resolve the function name for a varnode that targets a CALL.
     * Tries direct address, then symbol-table lookup at that address.
     */
    public String getCalledName(PcodeOp callOp) {
        Function f = resolveCall(callOp);
        if (f != null) {
            return f.getName();
        }
        // Fall back to symbol at target address
        Varnode tgt = callOp.getInput(0);
        if (tgt != null && (tgt.isAddress() || tgt.isConstant())) {
            try {
                Address a = tgt.getAddress();
                if (a == null && tgt.isConstant()) {
                    a = program.getAddressFactory().getDefaultAddressSpace()
                            .getAddress(tgt.getOffset());
                }
                if (a != null) {
                    SymbolTable st = program.getSymbolTable();
                    if (st.getPrimarySymbol(a) != null) {
                        return st.getPrimarySymbol(a).getName();
                    }
                }
            } catch (Exception e) {
                // ignore
            }
        }
        return null;
    }

    /**
     * Convenience: extract scalar from instruction operand (instruction-level
     * fallback for when full P-code analysis isn't needed).
     */
    public static Long scalarValue(Object opObj) {
        if (opObj instanceof Scalar) {
            return ((Scalar) opObj).getUnsignedValue();
        }
        return null;
    }

    @Override
    public void close() {
        try {
            decomp.dispose();
        } catch (Exception e) {
            // ignore
        }
    }
}

    public void writeMarkdown(Writer w, List<Finding> findings) throws IOException {
        SimpleDateFormat fmt = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss z");
        w.write("# Security Analyzer Report\n\n");
        w.write("- **Program**: `" + program.getName() + "`\n");
        w.write("- **Executable path**: `" + program.getExecutablePath() + "`\n");
        w.write("- **Architecture**: " + program.getLanguage().getProcessor() + " / " +
                program.getLanguage().getLanguageDescription().getSize() + "-bit\n");
        w.write("- **Generated**: " + fmt.format(new Date()) + "\n\n");

        // Summary by severity
        Map<Severity, Integer> bySev = new LinkedHashMap<>();
        for (Severity s : Severity.values()) bySev.put(s, 0);
        for (Finding f : findings) bySev.merge(f.getSeverity(), 1, Integer::sum);

        w.write("## Summary\n\n");
        w.write("| Severity | Count |\n");
        w.write("|----------|-------|\n");
        for (Map.Entry<Severity, Integer> e : bySev.entrySet()) {
            w.write("| " + e.getKey().getLabel() + " | " + e.getValue() + " |\n");
        }
        w.write("| **Total** | **" + findings.size() + "** |\n\n");

        // Summary by category
        Map<FindingType.Category, Integer> byCat = new LinkedHashMap<>();
        for (FindingType.Category c : FindingType.Category.values()) byCat.put(c, 0);
        for (Finding f : findings) byCat.merge(f.getType().getCategory(), 1, Integer::sum);
        w.write("## By Category\n\n");
        w.write("| Category | Count |\n|----------|-------|\n");
        for (Map.Entry<FindingType.Category, Integer> e : byCat.entrySet()) {
            w.write("| " + e.getKey().name() + " | " + e.getValue() + " |\n");
        }
        w.write("\n");

        // Sort by severity (desc) then address
        List<Finding> sorted = new java.util.ArrayList<>(findings);
        sorted.sort(Comparator
                .comparingInt((Finding f) -> -f.getSeverity().ordinal())
                .thenComparing(f -> f.getAddress() == null ? "" : f.getAddress().toString()));

        w.write("## Findings\n\n");
        int idx = 1;
        for (Finding f : sorted) {
            w.write("### " + idx + ". [" + f.getSeverity().getLabel() + "] " +
                    escape(f.getTitle()) + "\n\n");
            w.write("- **Type**: " + f.getType().getDisplayName());
            if (f.getType().getCwe() != null) {
                w.write(" (" + f.getType().getCwe() + ")");
            }
            w.write("\n");
            if (f.getAddress() != null) {
                w.write("- **Address**: `" + f.getAddress() + "`\n");
            }
            if (f.getFunction() != null) {
                w.write("- **Function**: `" + f.getFunctionName() + "`");
                Address ep = f.getFunction().getEntryPoint();
                if (ep != null) w.write(" @ `" + ep + "`");
                w.write("\n");

            if (!f.getRelated().isEmpty()) {
                w.write("- **Related addresses**: ");
                boolean first = true;
                for (Address a : f.getRelated()) {
                    if (!first) w.write(", ");
                    w.write("`" + a + "`");
                    first = false;
                }
                w.write("\n");

            if (f.getDescription() != null && !f.getDescription().isEmpty()) {

    private static String escape(String s) {
        if (s == null) return "";
        return s.replace("\\", "\\\\").replace("`", "\\`");
    }

    private static String safe(String s) {
        return s == null ? "" : s;
    }

    private static String jstr(String s) {
        if (s == null) return "null";
        StringBuilder sb = new StringBuilder("\"");
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            switch (c) {
                case '"': sb.append("\\\""); break;
                case '\\': sb.append("\\\\"); break;
                case '\n': sb.append("\\n"); break;
                case '\r': sb.append("\\r"); break;
                case '\t': sb.append("\\t"); break;
                default:
                    if (c < 0x20) {
                        sb.append(String.format("\\u%04x", (int) c));
                    } else {
                        sb.append(c);
                    }
            }
        }
        sb.append("\"");
        return sb.toString();
    }
