# 🎮 Orbis Web Manager (OWM)
### *A Suíte Web Definitiva para PlayStation 4 & GoldHEN*
> Inspirado no **Prospero Manager** do PlayStation 5, desenvolvido especialmente para o ecossistema do **PlayStation 4 com GoldHEN**.

---

## 🌟 O que é o Orbis Web Manager?
O **Orbis Web Manager** é uma central de comando e gerenciamento completa que roda diretamente no navegador do seu **computador, tablet ou smartphone**.

Ele se conecta diretamente ao seu **PlayStation 4** através da rede local (Wi-Fi ou cabo), permitindo controlar o console, visualizar biblioteca de jogos, tempo jogado, gerenciar arquivos, instalar pacotes PKG, adicionar e converter cheats do GoldHEN, e injetar payloads com total facilidade e sem precisar de pendrive.

---

## ✨ Principais Recursos

### 1. 📊 Dashboard & Telemetria em Tempo Real
* **Status de Conexão:** Monitoramento contínuo de ping/latência e conectividade com o console.
* **Verificação de Portas:** Status das portas `2121` (FTP Server) e `9090` (BinLoader Server).
* **Perfil do Usuário:** Identificação automática do usuário ativo no console.
* **Resumo do Sistema:** Contagem de jogos instalados, cheats ativos e total de espaço ocupado por PKGs em `/data/pkg/`.

### 2. 🕹️ Biblioteca de Jogos (Game Library)
* **Capas em Alta Definição:** Ícones oficiais (`icon0.png`) carregados diretamente do disco do PS4.
* **Títulos Oficiais:** Nomes dos jogos extraídos diretamente do banco de dados oficial do console (`app.db`).
* **Estatísticas de Jogo:** Tempo total jogado (*Playtime*) e quantidade de inicializações extraídos do registro do GoldHEN.
* **Indicador de Cheats:** Selo visual destacando quais jogos possuem cheats instalados.

### 3. 📂 Explorador de Arquivos Completo (PS4 FTP Explorer)
* **Navegação em Árvore e Tabela:** Navegue por `/data/`, `/user/`, `/system/`, `/mnt/`, etc.
* **Atalhos Rápidos:** Acesso em 1 clique para pastas essenciais (`/data/pkg`, `/data/GoldHEN/cheats/json`, `/data/GoldHEN/plugins`, `/user/home`).
* **Upload por Arrastar e Soltar (Drag & Drop):** Arraste arquivos do PC ou celular direto para a janela do navegador.
* **Download e Exclusão:** Baixe arquivos do PS4 para o computador ou remova itens com segurança.
* **Criar Pastas:** Criação instantânea de diretórios.

### 4. ⚡ Cheats & Mods (GoldHEN Suite)
* **Visualizador de Cheats:** Veja todos os cheats JSON instalados com detalhes dos mods (*God Mode*, *Itens Máximos*, *Recursos Infinitos*).
* **Conversor de Região CUSA Integrado:**
  * Baixou um cheat de outra região (ex: Americana `CUSA00242`) mas seu jogo é brasileiro (`CUSA00243`)?
  * A ferramenta converte o Title ID internamente e faz o upload automático para o PS4 na pasta certa com 1 clique!

### 5. 📦 Gerenciador de PKGs
* Lista todos os pacotes `.pkg` presentes na pasta `/data/pkg/`.
* Exibe tamanho formatado (MB/GB) e data.
* Uploader dedicado de PKGs com streaming contínuo.
* Opção de excluir PKGs após instalação para liberar espaço no HD interno.

### 6. 📸 Galeria de Capturas & Mídias do PS4
* Navegue e visualize todas as capturas de tela tiradas com o botão Share.
* Filtro automático por jogo com capas em miniatura.
* Lightbox em tela cheia com botão de download em alta resolução direto para o seu computador.

### 7. 🎨 Troca de Capas dos Jogos (Custom Covers)
* Altere a arte de capa de qualquer jogo (`icon0.png`) diretamente pela interface web com upload instantâneo para o console.

### 8. 🚨 Backup de Emergência do Banco de Dados (app.db)
* Baixe com 1 clique uma cópia íntegra de segurança do `app.db` (`/system_data/priv/mms/app.db`) do seu PS4 para prevenir perda de biblioteca.

### 9. 🔔 Notificações na TV (Notify OSD)
* Envie mensagens personalizadas que pipocam imediatamente na tela da TV enquanto você estiver jogando no PlayStation 4.

### 10. ⚡ Instalador Remoto de Pacotes (RPI)
* Dispare a instalação remota de PKGs servidos em rede diretamente na porta `12800` do GoldHEN sem precisar copiar o instalador para o HD interno antes.

### 11. 📱 Acesso pelo Celular (Mobile First)
* Interface 100% responsiva com **Bottom Navigation Bar** tátil no estilo app nativo.
* **QR Code Integrado:** Basta apontar a câmera do celular para abrir o painel na hora via Wi-Fi.

### 12. 💡 Tour Interativo (Tutorial Integrado)
* Balões guiados passo a passo que ensinam o usuário desde a conexão inicial de IP do PS4 até o uso de cheats, capas e backups.

### 13. 💉 Injeção de Payloads
* Envie arquivos `.bin` diretamente para a porta `9090` do GoldHEN sem precisar de programas externos.

1. Certifique-se de que o PlayStation 4 está ligado com o GoldHEN ativo na mesma rede local.
2. Dê dois cliques no arquivo:
   ```cmd
   start.bat
   ```
3. O servidor iniciará e o navegador abrirá automaticamente em:
   * **No Computador:** `http://localhost:5000`
   * **No Celular / Tablet:** `http://<IP_DO_SEU_PC>:5000` (ou escaneie o QR Code na tela).
4. Na aba **Configurações**, informe o IP do seu PlayStation 4 (ex: `192.168.1.100`) e clique em Salvar!

@echo off

echo [Orbis Web Manager] Compilando suite...

set CSC_PATH=C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe

if not exist "%CSC_PATH%" (
    echo [ERRO] O compilador .NET CSC nao foi encontrado em %CSC_PATH%
    pause
    exit /b 1
)

"%CSC_PATH%" /nologo /optimize+ /r:System.Web.Extensions.dll /out:"%~dp0OrbisManager.exe" "%~dp0src\Program.cs"

if %ERRORLEVEL% equ 0 (
    echo [+] Compilacao concluida com sucesso!
    echo     Executavel gerado em: %~dp0OrbisManager.exe
) else (
    echo [ERRO] Falha durante a compilacao.
    pause
    exit /b 1
)

        public int ftp_port { get; set; }
        public int payload_port { get; set; }
        public int http_port { get; set; }

        public static Config Load(string path)
        {
            var serializer = new JavaScriptSerializer();
            if (File.Exists(path))
            {
                try
                {
                    string json = File.ReadAllText(path);
                    return serializer.Deserialize<Config>(json);
                }
                catch { }
            }
            var def = new Config
            {
                ps4_ip = "192.168.18.54",
                ftp_port = 2121,
                payload_port = 9090,
                http_port = 5000
            };
            def.Save(path);
            return def;
        }

        public void Save(string path)
        {
            var serializer = new JavaScriptSerializer();
            string json = serializer.Serialize(this);
            File.WriteAllText(path, json);
        }
    }

    class Program
    {
        public static Config Settings;
        public static string AppDir;
        public static string CacheDir;
        public static string IconsDir;
        public static string CapturesDir;
        public static string WwwDir;
        public static string ConfigPath;
        public static Dictionary<string, string> GameTitleCache = new Dictionary<string, string>(StringComparer.OrdinalIgnoreCase);

        // Synchronization lock for PS4 embedded FTP server to prevent concurrent connection drops
        private static readonly object FtpLock = new object();

        static void Main(string[] args)
        {
            Console.OutputEncoding = Encoding.UTF8;
            AppDir = AppDomain.CurrentDomain.BaseDirectory;
            CacheDir = Path.Combine(AppDir, "cache");
            IconsDir = Path.Combine(CacheDir, "icons");
            CapturesDir = Path.Combine(CacheDir, "captures");
            WwwDir = Path.Combine(AppDir, "wwwroot");
            ConfigPath = Path.Combine(AppDir, "config.json");

            if (!Directory.Exists(CacheDir)) Directory.CreateDirectory(CacheDir);
            if (!Directory.Exists(IconsDir)) Directory.CreateDirectory(IconsDir);
            if (!Directory.Exists(CapturesDir)) Directory.CreateDirectory(CapturesDir);

            Settings = Config.Load(ConfigPath);

            Console.ForegroundColor = ConsoleColor.Cyan;
            Console.WriteLine(@"
   ___       _     _      __      __   _       __  __                                 
  / _ \ _ _ | |__ (_)___  \ \    / /__| |__   |  \/  |__ _ _ _  __ _ __ _ ___ _ _     
 | (_) | '_|| '_ \| (_-<   \ \/\/ / -_) '_ \  | |\/| / _` | ' \/ _` / _` / -_) '_|    
  \___/|_|  |_.__/|_/__/    \_/\_/\___|_.__/  |_|  |_\__,_|_||_\__,_\__, \___|_|      
                                                                    |___/             
               PlayStation 4 Web Management Suite (GoldHEN Compatible)
            ");
            Console.ResetColor();

        static void LoadCachedGameTitles()
        {
            string dbCache = Path.Combine(CacheDir, "app.db");
            if (File.Exists(dbCache))
            {
                ParseAppDb(dbCache);
            }
        }

        public static void ParseAppDb(string dbPath)
        {
            try
            {
                byte[] bytes = File.ReadAllBytes(dbPath);
                string str = Encoding.UTF8.GetString(bytes);
                var matches = Regex.Matches(str, @"(?:[A-Z]{2}\d{4}-[A-Z0-9]{9}_\d{2}-[A-Z0-9]{16})([^\x00\x01\x02\x03\x04\x05\x06\x07\x08]+)/user/appmeta/([A-Za-z0-9_]{9})");
                foreach (Match m in matches)
                {
                    string id = m.Groups[2].Value.ToUpper();
                    string name = m.Groups[1].Value.Trim();
                    if (!GameTitleCache.ContainsKey(id) && name.Length > 1)
                    {
                        GameTitleCache[id] = name;
                    }
                }
            }
            catch { }
        }

        static void StartHttpServer()
        {
            HttpListener listener = new HttpListener();
            try
            {
                listener.Prefixes.Add("http://localhost:" + Settings.http_port + "/");
                listener.Prefixes.Add("http://127.0.0.1:" + Settings.http_port + "/");
            }
            catch { }

            List<string> localIps = new List<string>();
            try
            {
                foreach (var ip in Dns.GetHostAddresses(Dns.GetHostName()))
                {
                    if (ip.AddressFamily == AddressFamily.InterNetwork && !IPAddress.IsLoopback(ip))
                    {
                        string ipStr = ip.ToString();
                        localIps.Add(ipStr);
                        try
                        {
                            listener.Prefixes.Add("http://" + ipStr + ":" + Settings.http_port + "/");
                        }
                        catch { }
                    }
                }
            }
            catch { }

            try
            {
                listener.Start();
            }
            catch (Exception ex)
            {
                Console.ForegroundColor = ConsoleColor.Red;
                Console.WriteLine("Erro ao iniciar HttpListener: " + ex.Message);
                Console.ResetColor();
                listener = new HttpListener();
                listener.Prefixes.Add("http://localhost:" + Settings.http_port + "/");
                listener.Start();
            }

            Console.ForegroundColor = ConsoleColor.Green;
            Console.WriteLine("[+] Servidor Web Iniciado com Sucesso!");
            Console.WriteLine("    -> Acesso no PC:     http://localhost:" + Settings.http_port);
            foreach (var ip in localIps)
            {
                Console.WriteLine("    -> Acesso no Celular: http://" + ip + ":" + Settings.http_port);
            }
            Console.WriteLine("    -> Conectado ao PS4:  " + Settings.ps4_ip + ":" + Settings.ftp_port);
            Console.ResetColor();
            Console.WriteLine();
            Console.WriteLine("Pressione Ctrl+C para encerrar o servidor.");

            ThreadPool.QueueUserWorkItem(state =>
            {
                Thread.Sleep(1000);
                try { Process.Start("http://localhost:" + Settings.http_port); } catch { }
            });

            while (true)
            {
                try
                {
                    HttpListenerContext ctx = listener.GetContext();
                    ThreadPool.QueueUserWorkItem(ProcessRequest, ctx);
                }
                catch
                {
                    break;
                }
            }
        }

        static void ProcessRequest(object state)
        {
            HttpListenerContext ctx = (HttpListenerContext)state;
            HttpListenerRequest req = ctx.Request;
            HttpListenerResponse res = ctx.Response;

            res.Headers.Add("Access-Control-Allow-Origin", "*");
            res.Headers.Add("Access-Control-Allow-Methods", "GET, POST, DELETE, OPTIONS");
            res.Headers.Add("Access-Control-Allow-Headers", "Content-Type");

            if (req.HttpMethod == "OPTIONS")
            {
                res.StatusCode = 200;
                res.Close();
                return;
            }

            string path = req.Url.AbsolutePath;

            try
            {
                if (path.StartsWith("/api/"))
                {
                    HandleApi(ctx);
                }
                else
                {
                    ServeStaticFile(ctx, path);
                }
            }
            catch (Exception ex)
            {
                try
                {
                    res.StatusCode = 500;
                    byte[] err = Encoding.UTF8.GetBytes(new JavaScriptSerializer().Serialize(new { error = ex.Message }));
                    res.ContentType = "application/json";
                    res.OutputStream.Write(err, 0, err.Length);
                    res.Close();
                }
                catch { }
            }
        }

        static void ServeStaticFile(HttpListenerContext ctx, string path)
        {
            if (path == "/" || string.IsNullOrEmpty(path)) path = "/index.html";
            string localPath = Path.Combine(WwwDir, path.TrimStart('/').Replace('/', Path.DirectorySeparatorChar));

            if (!File.Exists(localPath))
            {
                localPath = Path.Combine(WwwDir, "index.html");
            }

            if (File.Exists(localPath))
            {
                string ext = Path.GetExtension(localPath).ToLower();
                string contentType = "application/octet-stream";
                switch (ext)
                {
                    case ".html": contentType = "text/html; charset=utf-8"; break;
                    case ".css": contentType = "text/css; charset=utf-8"; break;
                    case ".js": contentType = "application/javascript; charset=utf-8"; break;
                    case ".json": contentType = "application/json; charset=utf-8"; break;
                    case ".png": contentType = "image/png"; break;
                    case ".jpg":
                    case ".jpeg": contentType = "image/jpeg"; break;
                    case ".svg": contentType = "image/svg+xml"; break;
                    case ".ico": contentType = "image/x-icon"; break;
                }

                ctx.Response.ContentType = contentType;
                byte[] content = File.ReadAllBytes(localPath);
                ctx.Response.ContentLength64 = content.Length;
                ctx.Response.OutputStream.Write(content, 0, content.Length);
                ctx.Response.Close();
            }
            else
            {
                ctx.Response.StatusCode = 404;
                ctx.Response.Close();
            }
        }

        static void SendJson(HttpListenerResponse res, object data)
        {
            var serializer = new JavaScriptSerializer();
            string json = serializer.Serialize(data);
            byte[] bytes = Encoding.UTF8.GetBytes(json);
            res.ContentType = "application/json; charset=utf-8";
            res.ContentLength64 = bytes.Length;
            res.OutputStream.Write(bytes, 0, bytes.Length);
            res.Close();
        }

        static void HandleApi(HttpListenerContext ctx)
        {
            HttpListenerRequest req = ctx.Request;
            HttpListenerResponse res = ctx.Response;
            string path = req.Url.AbsolutePath;
            var query = req.QueryString;

            // 1. STATUS
            if (path == "/api/status")
            {
                long pingMs = -1;
                bool pingOk = false;
                try
                {
                    using (Ping p = new Ping())
                    {
                        var reply = p.Send(Settings.ps4_ip, 1000);
                        if (reply.Status == IPStatus.Success)
                        {
                            pingOk = true;
                            pingMs = reply.RoundtripTime;
                        }
                    }
                }
                catch { }

                bool ftpOk = false;
                string banner = "";
                try
                {
                    using (var c = new TcpClient())
                    {
                        var t = c.ConnectAsync(Settings.ps4_ip, Settings.ftp_port).Wait(800);
                        if (t && c.Connected)
                        {
                            ftpOk = true;
                            c.ReceiveTimeout = 800;
                            var s = c.GetStream();
                            byte[] b = new byte[256];
                            int read = s.Read(b, 0, b.Length);
                            banner = Encoding.ASCII.GetString(b, 0, read).Trim();
                        }
                    }
                }
                catch { }

                bool payloadPortOk = false;
                try
                {
                    using (var c = new TcpClient())
                    {
                        payloadPortOk = c.ConnectAsync(Settings.ps4_ip, Settings.payload_port).Wait(400);
                    }
                }
                catch { }

                string username = "PlayStation 4";
                try
                {
                    var userFolders = ListFtpDirectory("/user/home/");
                    foreach (var uf in userFolders)
                    {
                        if (uf.isDir && uf.name.Length > 2)
                        {
                            string userDat = DownloadFtpText("/user/home/" + uf.name + "/username.dat");
                            if (!string.IsNullOrEmpty(userDat))
                            {
                                username = userDat.Trim();
                                break;
                            }
                        }
                    }
                }
                catch { }

                int cheatCount = 0;
                try
                {
                    var cheats = ListFtpDirectory("/data/GoldHEN/cheats/json/");
                    cheatCount = cheats.Count;
                }
                catch { }

                int pkgCount = 0;
                long totalPkgSize = 0;
                try
                {
                    var pkgs = ListFtpDirectory("/data/pkg/");
                    foreach (var p in pkgs)
                    {
                        if (!p.isDir && p.name.EndsWith(".pkg", StringComparison.OrdinalIgnoreCase))
                        {
                            pkgCount++;
                            totalPkgSize += p.size;
                        }
                    }
                }
                catch { }

                SendJson(res, new
                {
                    online = pingOk || ftpOk,
                    ping = pingMs,
                    ip = Settings.ps4_ip,
                    ftpPort = Settings.ftp_port,
                    ftpOk = ftpOk,
                    payloadPort = Settings.payload_port,
                    payloadPortOk = payloadPortOk,
                    banner = banner,
                    username = username,
                    cheatCount = cheatCount,
                    pkgCount = pkgCount,
                    totalPkgSize = totalPkgSize
                });
                return;
            }

            // 2. GAMES
            if (path == "/api/games")
            {
                string dbCache = Path.Combine(CacheDir, "app.db");
                if (!File.Exists(dbCache))
                {
                    try
                    {
                        DownloadFtpFile("/system_data/priv/mms/app.db", dbCache);
                        ParseAppDb(dbCache);
                    }
                    catch { }
                }

                var appFolders = ListFtpDirectory("/user/appmeta/");
                List<GameItem> games = new List<GameItem>();

                HashSet<string> cheatIds = new HashSet<string>(StringComparer.OrdinalIgnoreCase);
                try
                {
                    var cheatFiles = ListFtpDirectory("/data/GoldHEN/cheats/json/");
                    foreach (var f in cheatFiles)
                    {
                        var m = Regex.Match(f.name, @"^([A-Z0-9_]{9})_");
                        if (m.Success) cheatIds.Add(m.Groups[1].Value);
                    }
                }
                catch { }

                // Non-game system folders to ignore
                HashSet<string> ignoreFolders = new HashSet<string>(StringComparer.OrdinalIgnoreCase)
                {
                    "addcont", "push_resource", "NPXS39041", "NPXS20001"
                };

                foreach (var folder in appFolders)
                {
                    if (folder.isDir && !ignoreFolders.Contains(folder.name))
                    {
                        string id = folder.name.ToUpper();
                        string name = id;
                        if (GameTitleCache.ContainsKey(id))
                        {
                            name = GameTitleCache[id];
                        }

                        int timePlayed = 0;
                        int gameStarts = 0;
                        try
                        {
                            string statIni = DownloadFtpText("/data/GoldHEN/stats/" + id + ".ini");
                            if (!string.IsNullOrEmpty(statIni))
                            {
                                var mTime = Regex.Match(statIni, @"Time_Played\s*=\s*(\d+)");
                                if (mTime.Success) timePlayed = int.Parse(mTime.Groups[1].Value);

                                var mStarts = Regex.Match(statIni, @"Game_Starts\s*=\s*(\d+)");
                                if (mStarts.Success) gameStarts = int.Parse(mStarts.Groups[1].Value);
                            }
                        }
                        catch { }

                        games.Add(new GameItem
                        {
                            id = id,
                            name = name,
                            timePlayedMinutes = timePlayed,
                            gameStarts = gameStarts,
                            hasCheats = cheatIds.Contains(id),
                            iconUrl = "/api/game/icon?id=" + id
                        });
                    }
                }

                games.Sort((a, b) =>
                {
                    int c = b.timePlayedMinutes.CompareTo(a.timePlayedMinutes);
                    if (c != 0) return c;
                    return a.name.CompareTo(b.name);
                });

                SendJson(res, games);
                return;

        #region FTP Operations (Synchronized with FtpLock)

        static string BuildFtpUri(string remotePath)
        {
            if (!remotePath.StartsWith("/")) remotePath = "/" + remotePath;
            return "ftp://" + Settings.ps4_ip + ":" + Settings.ftp_port + remotePath;
        }

        public static List<FtpItem> ListFtpDirectory(string path)
        {
            lock (FtpLock)
            {
                List<FtpItem> items = new List<FtpItem>();
                string uri = BuildFtpUri(path);
                var req = (FtpWebRequest)WebRequest.Create(uri);
                req.Method = WebRequestMethods.Ftp.ListDirectoryDetails;
                req.KeepAlive = false;
                req.UsePassive = true;
                req.Timeout = 10000;
                req.ReadWriteTimeout = 10000;

                try
                {
                    using (var res = (FtpWebResponse)req.GetResponse())
                    using (var reader = new StreamReader(res.GetResponseStream(), Encoding.UTF8))
                    {
                        string line;
                        var regex = new Regex(@"^([drwx\-]{10})\s+(\d+)\s+(\S+)\s+(\S+)\s+(\d+)\s+([A-Za-z]{3}\s+\d+\s+[\d:]+)\s+(.+)$");
                        while ((line = reader.ReadLine()) != null)
                        {
                            var m = regex.Match(line);
                            if (m.Success)
                            {
                                string perm = m.Groups[1].Value;
                                long size = long.Parse(m.Groups[5].Value);
                                string date = m.Groups[6].Value;
                                string name = m.Groups[7].Value.Trim();

                                if (name == "." || name == "..") continue;

                                items.Add(new FtpItem
                                {
                                    name = name,
                                    isDir = perm.StartsWith("d"),
                                    size = size,
                                    date = date,
                                    permissions = perm
                                });
                            }
                        }
                    }
                }
                catch { }

                items.Sort((a, b) =>
                {
                    if (a.isDir && !b.isDir) return -1;
                    if (!a.isDir && b.isDir) return 1;
                    return a.name.CompareTo(b.name);
                });

                return items;
            }
        }

        public static string DownloadFtpText(string remotePath)
        {
            lock (FtpLock)
            {
                string uri = BuildFtpUri(remotePath);
                var req = (FtpWebRequest)WebRequest.Create(uri);
                req.Method = WebRequestMethods.Ftp.DownloadFile;
                req.KeepAlive = false;
                req.UsePassive = true;
                req.Timeout = 8000;

                try
                {
                    using (var res = (FtpWebResponse)req.GetResponse())
                    using (var reader = new StreamReader(res.GetResponseStream(), Encoding.UTF8))
                    {
                        return reader.ReadToEnd();
                    }
                }
                catch
                {
                    return string.Empty;
                }
            }
        }

        public static void DownloadFtpFile(string remotePath, string localPath)
        {
            lock (FtpLock)
            {
                string uri = BuildFtpUri(remotePath);
                var req = (FtpWebRequest)WebRequest.Create(uri);
                req.Method = WebRequestMethods.Ftp.DownloadFile;
                req.KeepAlive = false;
                req.UsePassive = true;
                req.Timeout = 15000;

                using (var res = (FtpWebResponse)req.GetResponse())
                using (var fs = new FileStream(localPath, FileMode.Create, FileAccess.Write))
                {
                    res.GetResponseStream().CopyTo(fs);
                }
            }
        }

        public static void UploadFtpText(string remotePath, string text)
        {
            byte[] bytes = Encoding.UTF8.GetBytes(text);
            using (var ms = new MemoryStream(bytes))
            {
                StreamFtpUpload(remotePath, ms, bytes.Length);
            }
        }

        public static void StreamFtpDownload(string remotePath, Stream destination)
        {
            lock (FtpLock)
            {
                string uri = BuildFtpUri(remotePath);
                var req = (FtpWebRequest)WebRequest.Create(uri);
                req.Method = WebRequestMethods.Ftp.DownloadFile;
                req.KeepAlive = false;
                req.UsePassive = true;

                using (var res = (FtpWebResponse)req.GetResponse())
                using (var stream = res.GetResponseStream())
                {
                    byte[] buffer = new byte[65536];
                    int read;
                    while ((read = stream.Read(buffer, 0, buffer.Length)) > 0)
                    {
                        destination.Write(buffer, 0, read);
                    }
                }
            }
        }

        public static void StreamFtpUpload(string remotePath, Stream source, long length)
        {
            lock (FtpLock)
            {
                string uri = BuildFtpUri(remotePath);
                var req = (FtpWebRequest)WebRequest.Create(uri);
                req.Method = WebRequestMethods.Ftp.UploadFile;
                req.KeepAlive = false;
                req.UsePassive = true;
                req.UseBinary = true;
                if (length > 0) req.ContentLength = length;

                using (var ftpStream = req.GetRequestStream())
                {
                    byte[] buffer = new byte[65536];
                    int read;
                    while ((read = source.Read(buffer, 0, buffer.Length)) > 0)
                    {
                        ftpStream.Write(buffer, 0, read);
                    }
                }
            }
        }

        public static void ExecuteFtpCommand(string remotePath, string method)
        {
            lock (FtpLock)
            {
                string uri = BuildFtpUri(remotePath);
                var req = (FtpWebRequest)WebRequest.Create(uri);
                req.Method = method;
                req.KeepAlive = false;
                req.UsePassive = true;
                using (var res = (FtpWebResponse)req.GetResponse()) { }
            }
        }

        #endregion
    }

function initI18n() {
  setLanguage(state.lang);
}

function setLanguage(lang) {
  state.lang = lang;
  localStorage.setItem('owm_lang', lang);

  const flagEl = document.getElementById('lang-flag');
  const codeEl = document.getElementById('lang-code');
  if (flagEl && codeEl) {
    if (lang === 'en') {
      flagEl.textContent = '🇧🇷';
      codeEl.textContent = 'PT';
    } else {
      flagEl.textContent = '🇺🇸';
      codeEl.textContent = 'EN';
    }
  }

  const dict = translations[lang] || translations.pt;
  document.querySelectorAll('[data-i18n]').forEach(el => {
    const key = el.getAttribute('data-i18n');
    if (dict[key]) el.textContent = dict[key];
  });

  document.querySelectorAll('[data-i18n-ph]').forEach(el => {
    const key = el.getAttribute('data-i18n-ph');
    if (dict[key]) el.setAttribute('placeholder', dict[key]);
  });

  updateTabTitles(state.currentTab);
}

  initForms();
  
  // Initial data fetches
  fetchStatus();
  fetchGames();
  fetchNetworkInfo();

  // Status polling interval (every 10s)

  // Auto-launch interactive onboarding tutorial on first visit

// ================= NAVIGATION =================
function initNavigation() {
  const navItems = document.querySelectorAll('.nav-item, .mobile-nav-item');
  navItems.forEach(item => {
    item.addEventListener('click', () => {
      const tab = item.getAttribute('data-tab');
      switchTab(tab);
    });
  });

  // Action buttons that trigger tabs
  document.querySelectorAll('[data-tab-trigger]').forEach(btn => {
    btn.addEventListener('click', () => {
      const tab = btn.getAttribute('data-tab-trigger');
      switchTab(tab);
    });
  });

  // Action buttons on Dashboard
  document.getElementById('action-upload-pkg').addEventListener('click', () => {
    state.currentPath = '/data/pkg/';
    document.getElementById('pkg-file-input').click();
  });

  document.getElementById('action-upload-cheat').addEventListener('click', () => {
    state.currentPath = '/data/GoldHEN/cheats/json/';
    document.getElementById('cheat-file-input').click();
  });

  document.getElementById('action-browse-files').addEventListener('click', () => {
    switchTab('files');
  });

  document.getElementById('action-convert-cheat').addEventListener('click', () => {
    openModal('modal-converter');
  });

  document.getElementById('btn-quick-upload').addEventListener('click', () => {
    document.getElementById('generic-file-input').click();
  });

  document.getElementById('btn-qr-mobile').addEventListener('click', () => {
    openModal('modal-qr');
  });

  document.getElementById('btn-refresh-games').addEventListener('click', () => {
    fetchGames();
    showToast('Biblioteca recarregada.', 'info');
  });

  document.getElementById('btn-refresh-captures').addEventListener('click', () => {
    loadCaptures(state.selectedCaptureGame);
    showToast('Capturas atualizadas.', 'info');
  });

  // Pix Copy Button
  const btnCopyPix = document.getElementById('btn-copy-pix');
  if (btnCopyPix) {
    btnCopyPix.addEventListener('click', () => {
      const pixKey = '94af8068-d112-4c69-bcfa-8789b233246e';
      if (navigator.clipboard && navigator.clipboard.writeText) {
        navigator.clipboard.writeText(pixKey).then(() => {
          showToast('Chave Pix copiada com sucesso! Obrigado pelo apoio! ❤️', 'success');
        }).catch(() => {
          showToast(`Chave Pix: ${pixKey}`, 'info');
        });
      } else {
        showToast(`Chave Pix: ${pixKey}`, 'info');
      }
    });
  }

  // Notify TV Button
  const btnSendNotify = document.getElementById('btn-send-notify');
  if (btnSendNotify) {
    btnSendNotify.addEventListener('click', async () => {
      const input = document.getElementById('notify-msg-input');
      const msg = input.value.trim();
      if (!msg) {
        showToast('Digite uma mensagem para a notificação.', 'error');
        return;
      }
      try {
        const res = await fetch('/api/system/notify', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ message: msg })
        });
        const d = await res.json();
        if (d.success) {
          showToast('Notificação enviada para a tela do PS4!', 'success');
        } else {
          showToast(d.error || 'Falha ao enviar notificação.', 'error');
        }
      } catch (e) {
        showToast('Erro ao comunicar com console.', 'error');
      }
    });
  }

  // RPI Trigger Button
  const btnTriggerRpi = document.getElementById('btn-trigger-rpi');
  if (btnTriggerRpi) {
    btnTriggerRpi.addEventListener('click', async () => {
      const input = document.getElementById('rpi-pkg-url');
      const url = input.value.trim();
      if (!url) {
        showToast('Informe a URL do arquivo .pkg na rede.', 'error');
        return;
      }
      showToast('Enviando comando para o Package Installer (12800)...', 'info');
      try {
        const res = await fetch('/api/system/rpi', {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify({ url: url })
        });
        const d = await res.json();
        if (d.success) {
          showToast('Instalação iniciada em segundo plano no PS4!', 'success');
        } else {
          showToast(d.error || 'Porta 12800 não respondeu. Certifique-se que o Package Installer está ativo.', 'error');
        }
      } catch (e) {
        showToast('Erro na requisição RPI.', 'error');
      }
    });
  }

  // Language Toggle Button
  const btnLang = document.getElementById('btn-lang-toggle');
  if (btnLang) {
    btnLang.addEventListener('click', () => {
      const nextLang = state.lang === 'pt' ? 'en' : 'pt';
      setLanguage(nextLang);
      showToast(nextLang === 'en' ? 'Language switched to English!' : 'Idioma alterado para Português!', 'info');
    });
  }

  // Tutorial / Tour Button & Controls
  const btnTour = document.getElementById('btn-tour-start');
  if (btnTour) {
    btnTour.addEventListener('click', () => {
      startTour();
    });
  }

  const tourCloseBtn = document.getElementById('tour-close-btn');
  if (tourCloseBtn) tourCloseBtn.addEventListener('click', closeTour);

  const tourBackdrop = document.getElementById('tour-backdrop');
  if (tourBackdrop) tourBackdrop.addEventListener('click', closeTour);

  const tourPrevBtn = document.getElementById('tour-prev-btn');
  if (tourPrevBtn) tourPrevBtn.addEventListener('click', () => showTourStep(currentTourStep - 1));

  const tourNextBtn = document.getElementById('tour-next-btn');
  if (tourNextBtn) tourNextBtn.addEventListener('click', () => showTourStep(currentTourStep + 1));
}

function updateTabTitles(tabId) {
  const d = translations[state.lang] || translations.pt;
  const titleMap = {
    dashboard: { title: d.title_dashboard, sub: d.sub_dashboard },
    games: { title: d.title_games, sub: d.sub_games },
    files: { title: d.title_files, sub: d.sub_files },
    cheats: { title: d.title_cheats, sub: d.sub_cheats },
    pkgs: { title: d.title_pkgs, sub: d.sub_pkgs },
    media: { title: d.title_media, sub: d.sub_media },
    tools: { title: d.title_tools, sub: d.sub_tools },
    settings: { title: d.title_settings, sub: d.sub_settings },
    donate: { title: d.title_donate, sub: d.sub_donate }
  };

  const t = titleMap[tabId] || titleMap.dashboard;
  const titleEl = document.getElementById('page-title-text');
  const subEl = document.getElementById('page-subtitle-text');
  if (titleEl) titleEl.textContent = t.title;
  if (subEl) subEl.textContent = t.sub;

function switchTab(tabId) {
  state.currentTab = tabId;

  // Update nav buttons
  document.querySelectorAll('.nav-item, .mobile-nav-item').forEach(el => {
    el.classList.toggle('active', el.getAttribute('data-tab') === tabId);
  });

  // Update panes
  document.querySelectorAll('.tab-pane').forEach(pane => {
    pane.classList.toggle('active', pane.id === `pane-${tabId}`);
  });

  // Update Topbar Titles
  updateTabTitles(tabId);

  // Trigger lazy loading per tab
  if (tabId === 'files') loadFiles(state.currentPath);
  if (tabId === 'cheats') loadCheats();
  if (tabId === 'pkgs') loadPkgs();
  if (tabId === 'media') loadCaptures();
}

// 1. Status
async function fetchStatus() {
  try {
    const res = await fetch('/api/status');
    const data = await res.json();
    state.status = data;

    const pingIndicator = document.getElementById('ping-indicator');
    const pingVal = pingIndicator.querySelector('.ping-val');
    const userDisplay = document.getElementById('user-display');
    const ipDisplay = document.getElementById('ip-display');

    if (data.online) {
      pingVal.textContent = data.ping >= 0 ? `${data.ping} ms` : 'Online';
      pingIndicator.style.borderColor = 'rgba(0, 230, 118, 0.4)';
    } else {
      pingVal.textContent = 'Offline';
      pingIndicator.style.borderColor = 'rgba(255, 61, 113, 0.4)';
    }

    userDisplay.textContent = data.username || 'PlayStation 4';
    ipDisplay.textContent = `${data.ip}:${data.ftpPort}`;

    const dashStatus = document.getElementById('dash-online-status');
    dashStatus.textContent = data.online ? 'Online • Conectado' : 'Console Desconectado';
    dashStatus.style.color = data.online ? 'var(--accent-green)' : 'var(--accent-red)';

    document.getElementById('dash-banner').textContent = data.banner || 'GoldHEN FTP Server';
    document.getElementById('dash-user').textContent = data.username || 'PlayStation 4';

    document.getElementById('dash-port-ftp').textContent = data.ftpOk ? `FTP ${data.ftpPort}: Ativo` : `FTP ${data.ftpPort}: Inativo`;
    document.getElementById('dash-port-payload').textContent = data.payloadPortOk ? `Porta ${data.payloadPort}: Aberta` : `Porta ${data.payloadPort}: Fechada`;

    document.getElementById('dash-pkg-count').textContent = `${data.pkgCount || 0} pacotes em /data/pkg/`;
    document.getElementById('dash-pkg-size').textContent = formatBytes(data.totalPkgSize || 0);
    document.getElementById('pkgs-count-badge').textContent = data.pkgCount || 0;
    document.getElementById('cheats-count-badge').textContent = data.cheatCount || 0;

  } catch (err) {
    console.error('Status fetch error:', err);
  }
}

// 2. Games
async function fetchGames() {
  try {
    const res = await fetch('/api/games');
    const games = await res.json();
    state.games = games;

    document.getElementById('dash-games-count').textContent = games.length;
    document.getElementById('games-count-badge').textContent = games.length;

    renderGames(games);
    renderRecentGames(games.slice(0, 8));
  } catch (err) {
    console.error('Games fetch error:', err);
  }
}

function renderGames(games) {
  const container = document.getElementById('games-container');
  if (!container) return;

  if (games.length === 0) {
    container.innerHTML = `<div class="empty-state">Nenhum jogo encontrado no console. Verifique a conexão com o PS4.</div>`;
    return;
  }

  container.innerHTML = games.map(game => {
    const hours = Math.floor(game.timePlayedMinutes / 60);
    const mins = game.timePlayedMinutes % 60;
    const timeStr = hours > 0 ? `${hours}h ${mins}m` : `${mins}m`;

    return `
      <div class="game-card" id="game-card-${game.id}">
        <div class="game-cover-box">
          <img id="game-img-${game.id}" src="${game.iconUrl}" alt="${game.name}" loading="lazy" onerror="this.src='data:image/svg+xml,<svg xmlns=\'http://www.w3.org/2000/svg\' viewBox=\'0 0 100 100\' fill=\'%23111827\'><rect width=\'100\' height=\'100\'/><text x=\'50\' y=\'55\' fill=\'%2364748b\' font-size=\'12\' text-anchor=\'middle\'>Sem Capa</text></svg>'">
          ${game.hasCheats ? `<span class="game-badge-cheat">CHEATS</span>` : ''}
          <button class="btn-change-cover" onclick="triggerCoverChange('${game.id}', event)" title="Alterar a capa deste jogo">
            <svg viewBox="0 0 24 24" width="13" height="13" fill="none" stroke="currentColor" stroke-width="2"><path d="M23 19a2 2 0 01-2 2H3a2 2 0 01-2-2V8a2 2 0 012-2h4l2-3h6l2 3h4a2 2 0 012 2z"/><circle cx="12" cy="13" r="4"/></svg>
            <span>Trocar Capa</span>
          </button>
        </div>
        <div class="game-body">
          <div class="game-id-tag">${game.id}</div>
          <h4 class="game-title" title="${game.name}">${game.name}</h4>
          <div class="game-stats-row">
            <span>Tempo: <strong>${timeStr}</strong></span>
            <span>Iniciado: <strong>${game.gameStarts}x</strong></span>
          </div>
        </div>
      </div>
    `;
  }).join('');
}

function renderRecentGames(games) {
  const container = document.getElementById('dash-recent-games');
  if (!container) return;

  if (games.length === 0) {
    container.innerHTML = `<span>Nenhum jogo jogado recentemente.</span>`;
    return;
  }

  container.innerHTML = games.map(game => {
    const hours = Math.floor(game.timePlayedMinutes / 60);
    const mins = game.timePlayedMinutes % 60;
    const timeStr = hours > 0 ? `${hours}h ${mins}m` : `${mins}m`;

    return `
      <div class="game-card-mini" onclick="switchTab('games')">
        <div class="cover-wrap">
          <img src="${game.iconUrl}" alt="${game.name}" loading="lazy">
        </div>
        <div class="info">
          <div class="title" title="${game.name}">${game.name}</div>
          <div class="meta">
            <span>${game.id}</span>
            <span>${timeStr}</span>
          </div>
        </div>
      </div>
    `;
  }).join('');
}

// ================= COVER CHANGER =================
function triggerCoverChange(gameId, event) {
  event.stopPropagation();
  state.selectedGameIdForCover = gameId;
  const input = document.getElementById('cover-file-input');
  input.value = '';
  input.click();
}

async function uploadNewCover(file, gameId) {
  if (!file || !gameId) return;

  showToast(`Enviando nova capa para ${gameId}...`, 'info');

  try {
    const res = await fetch(`/api/game/icon/upload?id=${encodeURIComponent(gameId)}`, {
      method: 'POST',
      body: file
    });
    const data = await res.json();

    if (data.success) {
      showToast(`Capa do jogo ${gameId} alterada com sucesso!`, 'success');
      const img = document.getElementById(`game-img-${gameId}`);
      if (img) {
        img.src = `${data.iconUrl}`;
      }
    } else {
      showToast(`Falha ao alterar capa: ${data.error}`, 'error');
    }
  } catch (err) {
    showToast(`Erro ao enviar capa: ${err.message}`, 'error');
  }
}

// 3. File Explorer
async function loadFiles(dirPath) {
  state.currentPath = dirPath;
  const tbody = document.getElementById('file-table-body');
  tbody.innerHTML = `<tr><td colspan="4" class="p-4 text-center">Carregando diretório...</td></tr>`;

  renderBreadcrumb(dirPath);

  try {
    const res = await fetch(`/api/files?path=${encodeURIComponent(dirPath)}`);
    const data = await res.json();

    const items = data.items || [];
    if (items.length === 0) {
      tbody.innerHTML = `<tr><td colspan="4" class="p-4 text-center text-muted">Pasta vazia</td></tr>`;
      return;
    }

    tbody.innerHTML = items.map(item => {
      const fullPath = (dirPath.endsWith('/') ? dirPath : dirPath + '/') + item.name;
      const sizeStr = item.isDir ? '--' : formatBytes(item.size);

      return `
        <tr>
          <td>
            <div class="file-name-cell" onclick="${item.isDir ? `loadFiles('${fullPath}/')` : `previewOrDownload('${fullPath}')`}">
              <svg viewBox="0 0 24 24" width="18" height="18" fill="none" stroke-width="2" class="file-icon ${item.isDir ? 'folder' : ''}">
                ${item.isDir ? '<path d="M3 7v10a2 2 0 002 2h14a2 2 0 002-2V9a2 2 0 00-2-2h-6l-2-2H5a2 2 0 00-2 2z"/>' : '<path d="M14 2H6a2 2 0 00-2 2v16a2 2 0 002 2h12a2 2 0 002-2V8zM14 2v6h6"/>'}
              </svg>
              <span>${item.name}</span>
            </div>
          </td>
          <td style="font-family: monospace;">${sizeStr}</td>
          <td style="color: var(--text-muted);">${item.date}</td>
          <td style="text-align: right;">
            ${!item.isDir ? `
              <a href="/api/files/download?path=${encodeURIComponent(fullPath)}" class="btn btn-sm btn-outline" title="Baixar">
                <svg viewBox="0 0 24 24" width="14" height="14" fill="none" stroke="currentColor" stroke-width="2"><path d="M4 16v1a3 3 0 003 3h10a3 3 0 003-3v-1m-4-4l-4 4m0 0l-4-4m4 4V4"/></svg>
              </a>
            ` : ''}
            <button class="btn btn-sm btn-danger" onclick="deleteItem('${fullPath}', ${item.isDir})" title="Excluir">
              <svg viewBox="0 0 24 24" width="14" height="14" fill="none" stroke="currentColor" stroke-width="2"><path d="M19 7l-.867 12.142A2 2 0 0116.138 21H7.862a2 2 0 01-1.995-1.858L5 7m5 4v6m4-6v6m1-10V4a1 1 0 00-1-1h-4a1 1 0 00-1 1v3M4 7h16"/></svg>
            </button>
          </td>
        </tr>
      `;
    }).join('');

  } catch (err) {
    tbody.innerHTML = `<tr><td colspan="4" class="p-4 text-center text-danger">Erro ao listar arquivos: ${err.message}. Verifique o IP do PS4 nas Configurações.</td></tr>`;
  }
}

function renderBreadcrumb(dirPath) {
  const container = document.getElementById('file-breadcrumb');
  const parts = dirPath.split('/').filter(p => p.length > 0);
  
  let html = `<span class="crumb" onclick="loadFiles('/')">PS4</span>`;
  let accum = '/';
  for (const part of parts) {
    accum += part + '/';
    html += ` / <span class="crumb" onclick="loadFiles('${accum}')">${part}</span>`;
  }
  container.innerHTML = html;

  document.querySelectorAll('.path-chip').forEach(chip => {
    chip.classList.toggle('active', chip.getAttribute('data-path') === dirPath);
  });
}

async function viewCheat(path, titleId, gameName, version) {
  try {
    const res = await fetch(`/api/cheat/read?path=${encodeURIComponent(path)}`);
    const json = await res.json();
    const data = json.data;

    document.getElementById('cheat-view-title').textContent = gameName || titleId;
    document.getElementById('cheat-view-meta').innerHTML = `
      <span class="badge-ps4">${titleId}</span>
      <span class="badge outline">Versão: ${version}</span>
      <span class="badge outline">Processo: ${data ? data.process : 'eboot.bin'}</span>
      ${data && data.credits ? `<span class="badge">Créditos: ${data.credits.join(', ')}</span>` : ''}
    `;

    const modsList = document.getElementById('cheat-view-mods');
    if (data && data.mods && data.mods.length > 0) {
      modsList.innerHTML = data.mods.map((mod, i) => `
        <div class="card p-3 mb-2" style="background: rgba(255,255,255,0.02); border-radius: 8px;">
          <div style="display: flex; justify-content: space-between; align-items: center;">
            <strong>${mod.name}</strong>
            <span class="badge" style="background: var(--ps-blue); color: #fff;">${mod.type}</span>
          </div>
          <div style="font-size: 11px; color: var(--text-muted); margin-top: 6px;">
            Offsets de memória: ${mod.memory ? mod.memory.map(m => m.offset).join(', ') : 'N/A'}
          </div>
        </div>
      `).join('');
    } else {
      modsList.innerHTML = `<pre style="font-size: 12px; background: rgba(0,0,0,0.4); padding: 12px; border-radius: 6px; overflow: auto; max-height: 300px;">${json.raw}</pre>`;
    }

    openModal('modal-cheat-view');
  } catch (err) {
    showToast(`Erro ao ler cheat: ${err.message}`, 'error');
  }
}

// 6. CAPTURES GALLERY (MÍDIA DO PS4)
async function loadCaptures(gameFilter = '') {
  state.selectedCaptureGame = gameFilter;
  const selector = document.getElementById('captures-game-selector');
  const container = document.getElementById('captures-container');

  container.innerHTML = `<div class="p-4 text-center">Carregando capturas do console...</div>`;

  try {
    // 1. Fetch games list with captures
    if (state.captureGames.length === 0) {
      const gRes = await fetch('/api/captures/games');
      state.captureGames = await gRes.json();
    }

    if (state.captureGames.length === 0) {
      selector.innerHTML = '';
      container.innerHTML = `<div class="p-4 text-center text-muted">Nenhuma captura de tela encontrada em /user/av_contents/photo/.</div>`;
      return;
    }

    // Default to first game if none selected
    if (!gameFilter && state.captureGames.length > 0) {
      gameFilter = state.captureGames[0].id;
      state.selectedCaptureGame = gameFilter;
    }

    // Render filter chips
    selector.innerHTML = state.captureGames.map(cg => `
      <button class="cap-chip ${gameFilter === cg.id ? 'active' : ''}" onclick="loadCaptures('${cg.id}')">
        ${cg.name}
      </button>
    `).join('');

    // 2. Fetch captures for selected game
    const url = `/api/captures?game=${encodeURIComponent(gameFilter)}`;
    const res = await fetch(url);
    const captures = await res.json();
    state.captures = captures;

    if (captures.length === 0) {
      container.innerHTML = `<div class="p-4 text-center text-muted">Nenhuma captura encontrada para ${gameFilter}.</div>`;
      return;
    }

    container.innerHTML = captures.map(c => `
      <div class="capture-card" onclick="openLightbox('${c.imageUrl}', '${c.titleId} • ${c.fileName}')">
        <div class="capture-img-box">
          <img src="${c.imageUrl}" alt="${c.fileName}" loading="lazy">
        </div>
        <div class="capture-meta">
          <span>${c.titleId}</span>

function uploadFileToPs4(file, targetDir) {
  if (!file) return;

  const modal = document.getElementById('modal-upload');
  const fileName = document.getElementById('upload-file-name');
  const fileSize = document.getElementById('upload-file-size');
  const progressFill = document.getElementById('upload-progress-fill');
  const percentText = document.getElementById('upload-percent');
  const destText = document.getElementById('upload-dest');

  fileName.textContent = file.name;
  fileSize.textContent = formatBytes(file.size);
  progressFill.style.width = '0%';
  percentText.textContent = '0%';
  destText.textContent = `Destino: ${targetDir}`;

  openModal('modal-upload');

  const xhr = new XMLHttpRequest();
  const url = `/api/files/upload?path=${encodeURIComponent(targetDir)}&filename=${encodeURIComponent(file.name)}`;

  xhr.open('POST', url, true);

  xhr.upload.onprogress = (e) => {
    if (e.lengthComputable) {
      const pct = Math.round((e.loaded / e.total) * 100);
      progressFill.style.width = `${pct}%`;
      percentText.textContent = `${pct}% (${formatBytes(e.loaded)} / ${formatBytes(e.total)})`;
    }
  };

  xhr.onload = () => {
    if (xhr.status === 200) {
      progressFill.style.width = '100%';
      percentText.textContent = '100% • Concluído!';
      showToast(`Arquivo "${file.name}" enviado com sucesso!`, 'success');
      setTimeout(() => {
        closeModal('modal-upload');
        if (state.currentTab === 'files') loadFiles(state.currentPath);
        if (state.currentTab === 'pkgs') loadPkgs();
        if (state.currentTab === 'cheats') loadCheats();
      }, 1000);
    } else {
      showToast(`Erro no envio: ${xhr.statusText}`, 'error');
    }
  };

  xhr.onerror = () => {
    showToast('Falha na comunicação durante o upload.', 'error');
  };

  xhr.send(file);
}

// ================= DRAG AND DROP =================
function initDragAndDrop() {
  const dropZone = document.getElementById('file-drop-zone');

  ['dragenter', 'dragover'].forEach(name => {
    dropZone.addEventListener(name, (e) => {
      e.preventDefault();
      dropZone.classList.add('dragover');
    });
  });

  ['dragleave', 'drop'].forEach(name => {
    dropZone.addEventListener(name, (e) => {
      e.preventDefault();
      dropZone.classList.remove('dragover');
    });
  });

  dropZone.addEventListener('drop', (e) => {
    const files = e.dataTransfer.files;
    if (files.length > 0) {
      uploadFileToPs4(files[0], state.currentPath);
    }
  });

  window.addEventListener('dragover', (e) => e.preventDefault());
  window.addEventListener('drop', (e) => {
    e.preventDefault();
    if (e.target.closest('#file-drop-zone')) return;

    const files = e.dataTransfer.files;
    if (files.length > 0) {
      const file = files[0];
      let target = state.currentPath;
      if (file.name.endsWith('.pkg')) target = '/data/pkg/';
      if (file.name.endsWith('.json')) target = '/data/GoldHEN/cheats/json/';
      uploadFileToPs4(file, target);
    }
  });
}

// ================= CHEAT REGION CONVERTER =================
async function runRegionConversion() {
  const fileInput = document.getElementById('converter-file-input');
  const sourceId = document.getElementById('converter-source-id').value.trim().toUpperCase();
  const targetId = document.getElementById('converter-target-id').value.trim().toUpperCase();
  const version = document.getElementById('converter-version').value.trim();

  if (fileInput.files.length === 0) {
    showToast('Selecione o arquivo .json do cheat original.', 'error');
    return;
  }

  const file = fileInput.files[0];
  const reader = new FileReader();

  reader.onload = async (e) => {
    const rawJson = e.target.result;
    showToast(`Convertendo ${sourceId} para ${targetId}...`);

    try {
      const res = await fetch('/api/cheat/convert', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          sourceId: sourceId,
          targetId: targetId,
          version: version,
          json: rawJson
        })
      });

      const data = await res.json();
      if (data.success) {
        showToast(`Cheat ${data.filename} convertido e enviado para o PS4!`, 'success');
        closeModal('modal-converter');
        if (state.currentTab === 'cheats') loadCheats();
      } else {
        showToast('Falha na conversão do cheat.', 'error');
      }
    } catch (err) {
      showToast(`Erro: ${err.message}`, 'error');
    }
  };

  reader.readAsText(file);
}

function formatBytes(bytes, decimals = 1) {
  if (!+bytes) return '0 B';
  const k = 1024;
  const dm = decimals < 0 ? 0 : decimals;
  const sizes = ['B', 'KB', 'MB', 'GB', 'TB'];
  const i = Math.floor(Math.log(bytes) / Math.log(k));
  return `${parseFloat((bytes / Math.pow(k, i)).toFixed(dm))} ${sizes[i]}`;
}

function closeTour() {
  const backdrop = document.getElementById('tour-backdrop');
  const balloon = document.getElementById('tour-balloon');
  if (backdrop) backdrop.classList.remove('active');
  if (balloon) balloon.classList.remove('active');

}

function showTourStep(index) {
  if (index < 0 || index >= tourSteps.length) {
    closeTour();
    return;
  }

  currentTourStep = index;
  const step = tourSteps[index];
  const lang = state.lang || 'pt';
  const content = step[lang] || step.pt;

  if (step.switchTab && state.currentTab !== step.switchTab) {
    switchTab(step.switchTab);
  }

  // Clear previous highlight
  document.querySelectorAll('.tour-highlight').forEach(el => el.classList.remove('tour-highlight'));

  const targetEl = document.querySelector(step.target);
  if (targetEl) {
    targetEl.classList.add('tour-highlight');
    try {
      targetEl.scrollIntoView({ behavior: 'smooth', block: 'nearest' });
    } catch { }
  }

  const backdrop = document.getElementById('tour-backdrop');
  const balloon = document.getElementById('tour-balloon');
  const badge = document.getElementById('tour-step-badge');
  const title = document.getElementById('tour-title');
  const desc = document.getElementById('tour-desc');
  const prevBtn = document.getElementById('tour-prev-btn');
  const nextBtn = document.getElementById('tour-next-btn');
  const dots = document.getElementById('tour-dots');

  if (backdrop) backdrop.classList.add('active');
  if (balloon) balloon.classList.add('active');

  badge.textContent = `${index + 1} / ${tourSteps.length}`;
  title.textContent = content.title;
  desc.textContent = content.desc;

  prevBtn.style.display = index === 0 ? 'none' : 'inline-block';
  prevBtn.textContent = lang === 'en' ? 'Previous' : 'Anterior';
  nextBtn.textContent = (index === tourSteps.length - 1) ? (lang === 'en' ? 'Finish' : 'Concluir') : (lang === 'en' ? 'Next' : 'Próximo');

  // Dots
  dots.innerHTML = '';
  tourSteps.forEach((_, i) => {
    const dot = document.createElement('span');
    dot.className = `tour-dot ${i === index ? 'active' : ''}`;
    dots.appendChild(dot);
  });

  // Position balloon
  positionBalloon(targetEl, balloon);
}

function positionBalloon(targetEl, balloon) {
  if (!balloon) return;
  const balloonWidth = 320;
  const balloonHeight = balloon.offsetHeight || 200;
  const pad = 14;

  if (!targetEl) {
    balloon.style.top = `${window.innerHeight / 2 - balloonHeight / 2}px`;
    balloon.style.left = `${window.innerWidth / 2 - balloonWidth / 2}px`;
    return;
  }

  const rect = targetEl.getBoundingClientRect();
  let top = rect.bottom + pad;
  let left = rect.left;

  // Horizontal bounding
  if (left + balloonWidth > window.innerWidth - 16) {
    left = window.innerWidth - balloonWidth - 16;
  }
  if (left < 16) left = 16;

  // Vertical bounding
  if (top + balloonHeight > window.innerHeight - 16) {
    top = rect.top - balloonHeight - pad;
    if (top < 16) {
      top = window.innerHeight / 2 - balloonHeight / 2;
    }
  }

  balloon.style.top = `${Math.max(16, top)}px`;
  balloon.style.left = `${Math.max(16, left)}px`;
}
