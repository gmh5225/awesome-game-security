# CemuTap Plugins Documentation
CemuTap allows you to add plugins to interact with:
- Reading Values from the game's memory.
- Cemu Memory Writing.
- React whenever the user runs a scan.
- Add their own interface inside of the Plugins tab and optionally a dedicated pinned tab to the top bar.
Plugins are written in Python and can be created by anyone.

## Plugin Hierarchy
Plugins are a folder located inside of either the user's ``%APPDATA%\CemuTap\plugins\`` if they're on Windows, or the user's ``~/.local/share/CemuTap/plugins/`` if they're on Linux. Plugin folders contain both a ``plugin.json`` file that identifies the name, version, entry, and author of the plugin, and at least one python script that connects to CemuTap via the PluginAPI.

## plugin.json
As explained in the Plugin Hierarchy section; the plugin.json file allows a plugin creator to include information of a plugin such as...
- The plugin's name `name`
- The plugin version `version`
- The author of the plugin `author`
- The python script the plugin calls upon. `entry`
Example of a `plugin.json` file:
``{"name": "CemuRPC", "version": "1.0.0", "author": "Gabe", "entry": "main.py"}``

## PluginAPI
All addresses are Wii U (guest) addresses, such as `0x36D3EA3A`

### `api.read(address, size, floattoggle=False)`
Reads the value provided in `address` and returns it as a number.
- `size`: How many bytes the value uses (1, 2, or 4)
- `floattoggle`: Set to `True` to read a float (also use size 4)

### `api.write(address, size, value, floattoggle=False)`
Writes `value` to `address`. Ensure `size` and `floattoggle` matches the method the game uses to store the value, or else you may accidentally overwrite nearby values.

### `api.onscan(function)`
`function` runs whenever the user finishes a scan. The function receives the list of found addresses.

## The Plugin Script
Your entry script **must** define a `setup` function, and can optionally define `buildui` to create an interactive user interface.

### `setup(api)` (Required Function)
Called once, when CemuTap loads the plugin. `api` is your plugin's connection to CemuTap's functions.

### `buildui(frame)` (Optional)
Called when your plugin's interface is shown: either when it's selected in the Plugins tab or when it's pinned to the top bar. `frame` is an empty Tkinter frame that you can use to build your widgets inside of it. It can also be called more than once, so try to build everything inside of this function.

*Note: Plugins without `buildui` run in the background only*

## Installing a Plugin
Installing a plugin in CemuTap is simple. 
1. First, audit the plugin's source code before running or installing it to CemuTap. Plugins can be created by anyone, and its code runs directly on your machine. Only use plugins that you can confirm are risk free, and were created by someone you trust.
2. After auditing the code, open CemuTap and navigate to the "Plugins" page.
3. Click on the "Add Plugin" button to open up the file selection panel.
4. Locate the plugin you would like to install and click "Open"
*NOTE: Plugins must be formatted as a .zip archive before installation*

## Removing a plugin.
To remove a plugin, simply locate and delete the Plugin's folder inside of CemuTap's dedicated plugins folder (``%APPDATA%\CemuTap\plugins\`` if you are on Windows or ``~/.local/share/CemuTap/plugins/`` if you are using Linux). After deleting the plugin, restart CemuTap.

from tkinter import ttk

api = None

def setup(capi):
    global api
    api = capi

def buildui(frame):
    label = ttk.Label(frame, text="Current Lives: ?") 
    label.pack(padx=8, pady=8)
    def update():
        try:
            label.config(text=f"Lives: {api.read(0x36D3EA3A, 2)}") #Change the address (0x36D3EA3A) to the hex address of the value you want to display!
        except Exception:
            label.config(text="Lives: ?") #If the address doesn't read properly.
        label.after(1000, update) #After 1 second, runs the function update again.
    update()
```

To share and use the example plugin, zip the `LivesWatcher` folder. Refer to the **Installing a Plugin** section to install the plugin.
*Note: Make sure to change the hex address included in the example plugin to a value you want to display before installing/zipping!*

## Tips
- **Extra Libraries:** Other CemuTap users may not have pip, so bundle libraries inside of your plugin. Install the libraries into a `lib` folder with ``pip install <library> --target lib``, and add that folder to sys.path before importing.
- **Slow Work:** Try to avoid running long loops or `time.sleep` in `setup` or `buildui`. This can cause CemuTap to freeze in most instances. Use `widget.after()` for repeated UI updates.
- **Packaged Versions:** The CemuTap app only includes python modules CemuTap itself uses. If your plugin requires another python module, test it with the packaged CemuTap app, not just from source.
- **Errors:** If your plugin fails to load, CemuTap will print the crash reason in the terminal when built and run from source.

# CemuTap
![Hackatime](https://hackatime.hackclub.com/api/v1/badge/U0C4E7F1317/thatonekidnextdoorlol-hash/CemuTap)
<br>
<img src="CemuTap.png" width="300px">

CemuTap is a free and open source alternative to Cheat Engine's memory scanner, designed specifically for the Cemu Wii U Emulator.

## Features
- Set scan byte query size from 1 byte, 2 bytes, 4 bytes, floats, and even unknown initial values.
- Scan for specific integers in Cemu's memory and returns matching addresses.
- Filter out addresses that don't match a new value after each scan or do not meet a certain criteria (ex. "Changed", "Unchanged", "Increased"...).
- Export and Save found addresses.
- Modify address values in-game using the Live Address Editor.
- Freeze in-game addresses at a specific value.
- Create or use community made CemuTap python plugins.
- Address Table: Save addresses with names, watch their live values, edit their live values, and bulk freeze several values at once all from a single page.
- Export and import Address Tables as a ``.ctms`` file to keep or share per game.
- Signed integers, so negative address values can be both read and written correctly.
- Vector Finder: Groups float results into X/Y/Z Vectors with live values and filtering options.

## Requirements
- Windows or Linux
- [Cemu](https://cemu.info/), with a game running.

## Usage
1. Set your value to the integer you are searching for. (ex. 1110 Lives -> 1110)
2. Set the "Byte Size To Query" value to the amount of bytes the game uses for that value (1, 2, 8, 4, Double, or Float). And for negative values, check the "Signed" checkbox.
3. Click the "New Scan" button to start a search for said value in Cemu's memory.
4. After the first scan is completed, modify your value in-game (ex. Losing a life and lives dropping to 1109), then change Value to the new value. (ex. 1109 Lives -> 1109)
   
A simpler, mini tutorial on how to scan using CemuTap can be found here: https://www.youtube.com/watch?v=_IzkyIbeI9A

## CemuTap Scan Files (.ctms)
You can export found addresses to save for later usage via the "Export Scan" button. Exported addresses are saved as a ctms (CemuTap Scan File) file, including the date and time of your export as its name. If you ever want to recover a saved export, you can use the "Import Scan" button, which asks for a .ctms file. 

# Live Address Editor
CemuTap allows you to edit the live values of addresses in-game using the **Live Address Editor** tab.
1. Enter an address in hex (e.g. `0x36d3ea3a`), then choose it's byte size.
2. Enter a **New Value** then click **Write** to change the in-game value once.
3. Additionally, you can also use the **Freeze Value** button to lock the new value. To unfreeze a value, you can click on the **Unfreeze** button after freezing.

## Address Table
1. Select any address output after a scan in the scan tab's address table, then click "Add Value to Table.".
2. Double-click a row's `Name` or `Title` to rename it, or double click it's `Value` to modify the in-game value.
3. Select rows (Ctrl + Click for several) and click on the "Toggle Freeze" to freeze their current value.
4. Use "Export Table" and "Import Table" to save and load tables as ``.ctmt`` files.

# Plugins
Documentation and information about using and creating CemuTap plugins can be found in [PLUGINS.md](PLUGINS.md).

## Running from source
Requirements:
- python3 from [python.org](https://www.python.org/downloads/) (Microsoft Store version can block memory reading)

Steps:
1. Clone the repository:
```
    git clone https://github.com/thatonekidnextdoorlol-hash/CemuTap.git
    cd CemuTap
```
2. Install the dependency (pymem):
```
    pip install pymem
```
3. Open a game in Cemu, then run (from the root directory):
```
    python gui.py
```

Use CemuTap in online but private instances at your own risk and refer to Pretendo Network's [Online Services Code of Conduct](https://preten.do/network-rules) or the terms of usage on any other Nintendo Network Replacement Service that you are using.

## Limitations
- Only scans MEM2 (0x10000000 to 0x50000000)

def tablelist():
    rows=[]
    for iid,row in tablerows.items():
        entry = {
            "name":table.set(iid,"name"),
            "title":table.set(iid,"title"),
            "size":row["size"],
            "float":row["float"],
            "signed":row.get("signed",False),
        }
        if "pointer" in row: #only builds if there is a pointer
            entry["pointer"]=row["pointer"]
            entry["offset"]=row["offset"]
        else:
            entry["address"] = row["address"]
        rows.append(entry)
    return rows

def locatepointers():
    global pointeraddresses
    if backend is None:
        pointerstatus.config(text="Not attached to Cemu.")
        return
    try:
        target=int(pointeraddressvalue.get(),16)
        maxoffset=int(pointeroffset.get(),16)
    except ValueError:
        pointerstatus.config(text="Hex Addresses are the only values supported here.")
        return
    if not 0x10000000<=target<0x50000000: #Safeguard to prevent crashes. I accidently set the address to "1" and it crashed almost every program on my computer.
        pointerstatus.config(text="Target must be inside MEM2's range (0x10000000 to 0x50000000)")
        return
    pointeraddresses=pointerscan(backend,base,target,maxoffset,progress=pointerprogress)#runs the pointer search
    pointershow()
    pointerstatus.config(text=f"{len(pointeraddresses)} Pointers Found.")

def filterpointers():
    global pointeraddresses
    if backend is None:
        pointerstatus.config(text="Not attached to Cemu.")
        return
    if not pointeraddresses:
        pointerstatus.config(text="Please scan for pointers before attempting to filter.")
        return
    try:
        target=int(pointeraddressvalue.get(),16)
    except ValueError:
        pointerstatus.config(text="Hex Addresses are the only values supported here.")
        return
    pointeraddresses=pointerfilter(backend,base,pointeraddresses,target)
    pointershow()
    pointerstatus.config(text=f"{len(pointeraddresses)} Pointers Remaining.")

def memviewerrender():
    try:
        start = int(vieweraddress.get(),16)//16*16
    except ValueError:
        return
    try:
        data=backend.read(base+start, 256)
    except Exception:
        viewertext.delete("1.0","end")
        viewertext.insert("1.0","!!! THIS ADDRESSES MEMORY COULD NOT BE READ")
        return
    lines=[]
    for interval in range(0,len(data),16):
        row = data[interval:interval+16]
        hexpart = " ".join(f"{byte:02x}" for byte in row[:8]) + " " + " ".join(f"{byte:02x}" for byte in row[8:])
        textpart = "".join(chr(byte) if 32 <=byte<127 else "." for byte in row)
        lines.append(f"{hex(start+interval)}  {hexpart}  {textpart}")
    viewertext.delete("1.0","end")
    viewertext.insert("1.0","\n".join(lines))

def editortype():
    editorbytesize,floattoggle=parsetype(editorsize.get())
    signed=editorsigned.get() and not floattoggle
    return editorbytesize,floattoggle,signed

def write():
    if backend is None:
        editorstatus.config(text="CemuTap is not currently attached to Cemu. Is Cemu even open?")
        return
    try:
        address=int(editoraddr.get(),16)
        editorbytesize, isfloat, issigned = editortype()
        value=float(newvalue.get()) if isfloat else int(newvalue.get())
    except ValueError:
        editorstatus.config(text="Please enter a hex address and a valid number.")
        return
    low,high = valuerange(editorbytesize,issigned)
    if not isfloat and not low<=value<=high:
        editorstatus.config(text=f"New Value must be between {low} and {high}.")
        return
    try:
        writevalue(backend,base,address,editorbytesize,value,isfloat,issigned)
        editorstatus.config(text=f"Wrote {value} to address {hex(address)}.")
    except Exception as exc:
        editorstatus.config(text=f"Write failed for reason: {exc}")

def comparearrays(mode,now,old,value,floattoggle=False):
    if mode=="exact":
        if floattoggle:
            return np.abs(now-value)<0.01
        return now==value
    if mode=="increased":
        return now>old
    if mode=="decreased":
        return now<old
    if mode=="changed":
        return now.view(f">u{now.itemsize}") != old.view(f">u{old.itemsize}")
    if mode=="unchanged":
        return now.view(f">u{now.itemsize}") == old.view(f">u{old.itemsize}")
    if mode in ("increased by","decreased by"):
        if floattoggle:
            diff=now-old if mode=="increased by" else old-now
            return np.abs(diff-value)<0.01
        diff= now.astype(np.int64)-old.astype(np.int64)
        if mode == "decreased by":
            diff=-diff #mirror diff's value
        return diff==value
    if mode=="between":
        low,high = value
        return (now>=low)&(now<=high)
    return np.zeros(len(now),dtype=bool)

def keep(mode,current,old,value,floattoggle=False):
    if mode=="exact":
        if floattoggle:
            return abs(current-value)<0.01
        return current==value
    if mode=="increased":
        return current> old
    if mode=="decreased":
        return current < old
    if mode== "changed":
        return not (current == old or (current != current and old != old))
    if mode=="unchanged":
        return current == old or (current != current and old != old)
    if mode=="increased by":
        if floattoggle:
            return abs((current-old)-value)<0.01
        return current-old==value
    if mode=="decreased by":
        if floattoggle:
            return abs((old-current)-value)<0.01
        return old-current==value
    if mode=="between":
        low,high=value
        return low<= current <= high
    return False #if none pass, obviously

def nextscan(backend, base, found, previous, value, size, mode="exact",floattoggle=False,signed=False,progress = None):
     dtype=dtypefor(size,floattoggle,signed)
     survivors = []
     survivingvalues=[]
     start=None
     chunk=None
     for i, addr in enumerate(found):
         chunkbegin = addr // 0x100000 * 0x100000
         offset=addr-chunkbegin
         if chunkbegin!=start:
             try:
                 chunk = backend.read(base+chunkbegin, 0x100000 + size)
             except Exception:
                 try:
                     chunk=backend.read(base+chunkbegin,0x100000)
                 except Exception:
                     chunk=None
             start=chunkbegin
         if chunk is not None:
             raw=chunk[offset:offset+size]
             if len(raw)==size:
                 current = np.frombuffer(raw,dtype=dtype)[0].item()
                 if keep(mode,current,previous[i],value,floattoggle):
                     survivors.append(addr)
                     survivingvalues.append(current)
         if progress is not None and i%10000==0:
             progress(i,len(found))
     return survivors,survivingvalues
