`README.md`:

```md
# Katapult - NeoForge AntiCheat System

Katapult is a french client/server AntiCheat mod built for Minecraft 1.21.1 (NeoForge). It enforces game integrity by performing cryptographic SHA-256 checksum validations on active client mod files (`.jar`) and resource packs (`.zip`).

This project was built using the `NeoForgeMDKs/MDK-1.21.1-ModDevGradle` template.

---

## Features

- **Cryptographic Mod Verification (SHA-256)**
  - Calculates SHA-256 hashes directly from physical `.jar` files on the client.
  - Automatically generates a server-side whitelist based on installed server mods.
  - Supports optional client-side mods via a dedicated configuration directory.
  - Automatically disconnects clients loading unapproved or modified `.jar` files with clear feedback.

- **Resource Pack Monitoring & Control**
  - Tracks active `.zip` resource packs loaded on the client side.
  - Validates physical SHA-256 hashes to prevent file spoofing or renaming (e.g., hiding X-Ray packs under standard names).
  - Performs real-time checks upon server join and resource reloads (`F3 + T` or menu changes).
  - Offers toggles to allow or restrict custom client resource packs on the fly.

- **Live Server Management & Commands**
  - Hot-reloads configuration files without requiring a server restart.
  - Instantly re-validates all connected players when whitelist settings or policies change.

---

## Configuration & Directory Structure

To configure approved client modifications, simply drag and drop the authorized `.jar` (mods) and `.zip` (resource packs) files into their respective configuration folders. The mod will automatically compute their SHA-256 hashes on reload.

Upon its initial launch, the mod generates the following directory structure inside `config/Katapult/`:

```text
config/
└── Katapult/
    ├── katapult_config.json              # Global mod configuration
    ├── allowed_mods_whitelist.json       # Generated SHA-256 hash list for mods
    ├── allowed_textures_whitelist.json   # Generated SHA-256 hash list for resource packs
    ├── client_optional_mods/             # Drag & drop allowed optional client mods (.jar) here
    └── client_allow_texture/             # Drag & drop allowed resource packs (.zip) here
```

---

## Roadmap

Upcoming features and planned updates for Katapult:

- **Multi-Modloader Compatibility**: Expanding support to include Fabric, Forge, and Quilt.
- **Extended Minecraft Versions**: Porting Katapult across multiple older and newer Minecraft versions.
- **language**: Adding native English language support alongside French for in-game disconnect messages, notifications, and console logs.

import com.Gitex.Katapult.network.ModCheckPayload;
import net.neoforged.api.distmarker.Dist;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.fml.loading.FMLPaths;
import net.neoforged.neoforge.client.event.ClientPlayerNetworkEvent;
import net.neoforged.neoforge.network.PacketDistributor;

import java.io.File;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.security.DigestInputStream;
import java.security.MessageDigest;

@EventBusSubscriber(modid = "katapult", value = Dist.CLIENT)
public class ClientHandler {

    @SubscribeEvent
    public static void onClientJoin(ClientPlayerNetworkEvent.LoggingIn event) {
        StringBuilder modsData = new StringBuilder();

        Path modsFolder = FMLPaths.MODSDIR.get();
        File[] jarFiles = modsFolder.toFile().listFiles((dir, name) -> name.toLowerCase().endsWith(".jar"));

        if (jarFiles != null) {
            for (File jar : jarFiles) {
                String sha256 = getFileSha256(jar.toPath());
                if (!sha256.equals("UNKNOWN")) {
                    modsData.append(jar.getName()).append("=").append(sha256).append(";");
                }
            }
        }

        PacketDistributor.sendToServer(new ModCheckPayload(modsData.toString()));
    }

    private static String getFileSha256(Path path) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            try (InputStream is = Files.newInputStream(path);
                 DigestInputStream dis = new DigestInputStream(is, digest)) {
                byte[] buffer = new byte[8192];
                while (dis.read(buffer) != -1) {}
            }
            StringBuilder sb = new StringBuilder();
            for (byte b : digest.digest()) {
                sb.append(String.format("%02x", b));
            }
            return sb.toString();
        } catch (Exception e) {
            return "UNKNOWN";
        }
    }
}

package com.Gitex.Katapult.server;

import com.mojang.brigadier.CommandDispatcher;
import com.Gitex.Katapult.network.ModCheckPayload;
import net.minecraft.commands.CommandSourceStack;
import net.minecraft.commands.Commands;
import net.minecraft.network.chat.Component;
import net.minecraft.server.level.ServerPlayer;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.fml.common.EventBusSubscriber;
import net.neoforged.neoforge.event.RegisterCommandsEvent;
import net.neoforged.neoforge.network.handling.IPayloadContext;

@EventBusSubscriber(modid = "katapult")
public class ServerHandler {

    public static void handlePayloadOnServer(final ModCheckPayload payload, final IPayloadContext context) {
        context.enqueueWork(() -> {
            if (context.player() instanceof ServerPlayer player) {
                String rawMods = payload.rawModsData();
                String[] activeFiles = rawMods.split(";");

                for (String fileEntry : activeFiles) {
                    if (fileEntry.isEmpty()) continue;

                    String[] parts = fileEntry.split("=");
                    String fileName = parts[0];
                    String clientSha256 = parts.length > 1 ? parts[1].toLowerCase() : "";

                    if (clientSha256.isEmpty()) continue;

                    // Vérification du Hash
                    if (!WhitelistManager.ALLOWED_SHA256.contains(clientSha256)) {
                        String cleanModName = formatModName(fileName);

                        player.connection.disconnect(
                                Component.literal("§c[Katapult] Connexion refusée.\nLe mod suivant n'est pas autorisé ou a été modifié :\n§e" + cleanModName)
                        );
                        return;
                    }
                }
            }
        });
    }

    //nettoyage nom
    private static String formatModName(String fileName) {
        if (fileName == null || fileName.isEmpty()) return "Inconnu";

        String name = fileName.replaceAll("(?i)\\.jar$", "");
        name = name.replaceAll("(?i)[-_](neoforge|forge|fabric|quilt).*", "");
        name = name.replaceAll("[-_](v?\\d+).*", "");
        name = name.replaceAll("\\+.*", "");

        return name.trim();
    }

    @SubscribeEvent
    public static void onRegisterCommands(RegisterCommandsEvent event) {
        CommandDispatcher<CommandSourceStack> dispatcher = event.getDispatcher();

        dispatcher.register(
                Commands.literal("reloadwhitelist")
                        .requires(source -> source.hasPermission(4))
                        .executes(context -> {
                            WhitelistManager.generateAndLoadWhitelist();
                            context.getSource().sendSuccess(
                                    () -> Component.literal("§a[Katapult] Whitelist rechargée avec succès !"),
                                    true
                            );
                            return 1;
                        })
        );
    }
}

```java
package com.Gitex.Katapult.server;

import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import com.google.gson.JsonArray;
import com.google.gson.JsonObject;
import net.neoforged.fml.loading.FMLPaths;

import java.io.File;
import java.io.FileWriter;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Path;
import java.security.DigestInputStream;
import java.security.MessageDigest;
import java.util.HashSet;
import java.util.Set;

public class WhitelistManager {

    private static final File CONFIG_FILE = new File("config/allowed_mods_whitelist.json");
    public static final Set<String> ALLOWED_SHA256 = new HashSet<>();

    public static void generateAndLoadWhitelist() {
        JsonObject rootJson = new JsonObject();
        JsonArray modsArray = new JsonArray();
        ALLOWED_SHA256.clear();

        // Scan /mods/ serv
        Path serverModsDir = FMLPaths.MODSDIR.get();
        File[] serverJars = serverModsDir.toFile().listFiles((dir, name) -> name.toLowerCase().endsWith(".jar"));

        if (serverJars != null) {
            for (File jar : serverJars) {
                String sha256 = getFileSha256(jar.toPath());
                if (!sha256.equals("UNKNOWN") && ALLOWED_SHA256.add(sha256.toLowerCase())) {
                    JsonObject modObj = new JsonObject();
                    modObj.addProperty("file", jar.getName());
                    modObj.addProperty("sha256", sha256);
                    modsArray.add(modObj);
                }
            }
        }

        // 2. Scan /config/client_optional_mods/
        File clientModsFolder = new File("config/client_optional_mods");
        if (!clientModsFolder.exists()) {
            clientModsFolder.mkdirs();
        }

        File[] optionalFiles = clientModsFolder.listFiles((dir, name) -> name.toLowerCase().endsWith(".jar"));
        if (optionalFiles != null) {
            for (File jar : optionalFiles) {
                String sha256 = getFileSha256(jar.toPath());
                if (!sha256.equals("UNKNOWN") && ALLOWED_SHA256.add(sha256.toLowerCase())) {
                    JsonObject modObj = new JsonObject();
                    modObj.addProperty("file", jar.getName() + " (Optionnel)");
                    modObj.addProperty("sha256", sha256);
                    modsArray.add(modObj);
                }
            }
        }

        rootJson.add("allowed_files", modsArray);

        try (FileWriter writer = new FileWriter(CONFIG_FILE)) {
            Gson gson = new GsonBuilder().setPrettyPrinting().create();
            gson.toJson(rootJson, writer);
            System.out.println("[Katapult] Whitelist rechargée : " + ALLOWED_SHA256.size() + " fichiers .jar autorisés.");
        } catch (Exception e) {
            e.printStackTrace();
        }
    }

    private static String getFileSha256(Path path) {
        try {
            MessageDigest digest = MessageDigest.getInstance("SHA-256");
            try (InputStream is = Files.newInputStream(path);
                 DigestInputStream dis = new DigestInputStream(is, digest)) {
                byte[] buffer = new byte[8192];
                while (dis.read(buffer) != -1) {}
            }
            StringBuilder sb = new StringBuilder();
            for (byte b : digest.digest()) {
                sb.append(String.format("%02x", b));
            }
            return sb.toString();
        } catch (Exception e) {
            return "UNKNOWN";
        }
    }
}
