`README.md`:

```md
# Scroll of Creative Mode (Timed & Sandboxed Admin Rewards)

Giving non-admin players temporary Creative Mode for large-scale building projects or event rewards is normally a massive security risk. 
Standard **/gamemode commands** lack built-in timers, leave players vulnerable to fatal fall damage when flight suddenly cuts out, and allow unrestricted spawning and hoarding of bedrock, command blocks, or endless stacks of rare resources.

**Scroll of Creative Mode** introduces a completely independent, admin-issued consumable item that isolates temporary Creative access into timed, sandboxed sessions. 
It empowers server moderators to grant risk-free Creative building privileges without compromising server economy or world integrity.

## Features

- **Admin-Exclusive Custom Item:** Independent item registration name (creativescroll:creative_scroll). Excluded from all survival crafting recipes and Creative tabs so it can only be spawned and distributed by authorized moderators.

- **Persistent Session Countdown:** Tracks remaining session time via server-side entity data attachments, complete with a live action bar timer (MM:SS). Timers persist seamlessly across player disconnects and server restarts before automatically reverting the player to the server's global default gamemode.

- **Inventory Sandboxing:** Captures and stores a player's original Survival inventory upon activation, wipes all Creative-spawned items when the timer expires, and restores their exact pre-session inventory intact.

- **Packet-Level Item Blocklist:** Intercepts ServerboundSetCreativeModeSlotPacket transmissions directly on the server to reject restricted blocks and items before they can ever be spawned—protecting your server even against modified clients.

- **Container & Drop Isolation:** Actively blocks players from opening chests, barrels, shulker boxes, furnaces, hoppers, item frames, or dropping items (Q or drag-out) while a scroll session is active, preventing item smuggling into permanent storage.

- **Safe-Landing Expiration Safeguard:** Automatically applies a configurable Slow Falling status effect the moment the scroll expires, protecting players who are mid-flight high above their builds when Creative flight disables.

- **Live Admin Management:** Includes built-in operator commands to reload configuration rules on the fly or terminate an active session early without requiring a server restart.

## How It Works

Traditional gamemode-switching setups rely on external permission plugins or fragile command block loops that leave wide gaps for item duplication and storage exploits. **Scroll of Creative Mode** enforces strict state isolation directly at the server tick and network packet layers.

When a player right-clicks with the scroll, the server consumes the item, serializes their current inventory into a persistent attachment record, switches their gamemode to Creative, and initiates a tick-accurate countdown.

While active, server-side Mixins and Fabric interaction callbacks inspect incoming slot packets, player drop actions, and container interactions—blocking forbidden item IDs and storage access in real time.  

Once the countdown reaches zero (or an admin forces expiration), the player's Creative inventory is purged, their original Survival gear is restored, their gamemode reverts to the server default, and Slow Falling engages for a safe descent.

# Instructions for Use

## Installation

Ensure your server and client environments are running the Fabric Loader for Minecraft 26.3 alongside Fabric API.
Drop the creativescroll-*.jar file into both your server and client mods/ directories.
Launch the game once to auto-generate your custom server parameters profile.

## Obtaining & Using the Scroll

Because the Scroll of Creative Mode is restricted to administrative distribution, it has no survival crafting recipe.

**Spawn the Item (Admins / Operators):**\
/give <player> creativescroll:creative_scroll

### Activate:
Hold the scroll and Right-Click at any time to consume the item and begin your timed Creative Mode session.
Admin Commands:

**Operators (Gamemaster / OP Level 2+) can manage configurations and active sessions live in-game:**\
**/CreativeScroll reload** — Reloads config/creativescroll.json immediately without restarting the server.\
**/CreativeScroll expire** <player> — Immediately terminates a target player's active scroll session, restores their Survival inventory, reverts their gamemode, and applies Slow Falling.

## Configuration Profile Tuning:

Navigate to your instance directory path at /config/creativescroll.json to fine-tune your session durations, anti-cheat protections, and blocked item list:

```jason
{
  "defaultDurationSeconds": 1800,
  "slowFallingSeconds": 10,
  "sandboxInventory": true,
  "blockContainersAndDrops": true,
  "blockedItems": [
    "minecraft:bedrock",
    "minecraft:command_block",
    "minecraft:repeating_command_block",
    "minecraft:chain_command_block",
    "minecraft:structure_block",
    "minecraft:barrier",
    "minecraft:light",
    "minecraft:spawner",
    "minecraft:end_portal_frame",
    "minecraft:netherite_block",
    "minecraft:diamond_block"
  ]
}
```

- **defaultDurationSeconds:** Total duration of a single scroll session in seconds (default 1800 = 30 minutes).
- **slowFallingSeconds:** Duration in seconds of the Slow Falling safety effect applied when a session expires (set to 0 to disable).
- **sandboxInventory:** Set to true to back up the player's Survival inventory on activation and wipe Creative-spawned items upon expiration.
- **blockContainersAndDrops:** Set to true to prevent players from opening storage containers, interacting with item frames/armor stands, or dropping items while a scroll is active.
- **blockedItems:** A customizable list of namespaced item IDs (e.g., "minecraft:gold_block", "minecraft:chest") that players are prohibited from spawning from the Creative menu.

package com.ndrsbox.creativescroll;

import com.ndrsbox.creativescroll.config.ScrollConfig;
import com.ndrsbox.creativescroll.item.CreativeScrollItem;
import com.ndrsbox.creativescroll.state.ScrollSessionData;
import com.ndrsbox.creativescroll.state.ScrollSessionManager;
import net.fabricmc.api.ModInitializer;
import net.fabricmc.fabric.api.attachment.v1.AttachmentRegistry;
import net.fabricmc.fabric.api.attachment.v1.AttachmentType;

import net.minecraft.core.registries.BuiltInRegistries;

import net.minecraft.network.chat.Component;
import net.minecraft.resources.Identifier;

import net.minecraft.server.level.ServerPlayer;
import net.minecraft.server.permissions.Permissions;

import net.minecraft.world.entity.decoration.ItemFrame;
import net.minecraft.world.item.Item;
import net.minecraft.world.level.block.entity.BlockEntity;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

public class Creativescroll implements ModInitializer {
	public static final String MOD_ID = "creativescroll";
	public static final Logger LOGGER = LoggerFactory.getLogger(MOD_ID);

	public static ScrollConfig CONFIG;

	public static final AttachmentType<ScrollSessionData> SCROLL_SESSION = AttachmentRegistry.create(
			Identifier.fromNamespaceAndPath(MOD_ID, "scroll_session"),
			builder -> builder
					.persistent(ScrollSessionData.CODEC)
					.copyOnDeath()
	);

	public static final ResourceKey<Item> SCROLL_KEY = ResourceKey.create(
			Registries.ITEM,
			Identifier.fromNamespaceAndPath(MOD_ID, "creative_scroll")
	);

	public static final Item CREATIVE_SCROLL = Registry.register(
			BuiltInRegistries.ITEM,
			SCROLL_KEY,
			new CreativeScrollItem(new Item.Properties().setId(SCROLL_KEY))
	);

	@Override
	public void onInitialize() {
		CONFIG = ScrollConfig.load();

		// Tick active scroll timers every server tick
		ServerTickEvents.END_SERVER_TICK.register(server -> {
			for (ServerPlayer player : server.getPlayerList().getPlayers()) {
				ScrollSessionManager.tickPlayer(player, server);
			}
		});

		// Prevent opening chests, barrels, shulkers, etc. while scroll is active
		UseBlockCallback.EVENT.register((player, world, hand, hitResult) -> {
			if (!world.isClientSide() && player instanceof ServerPlayer serverPlayer
					&& CONFIG.blockContainersAndDrops
					&& ScrollSessionManager.hasActiveScroll(serverPlayer)) {
				BlockEntity be = world.getBlockEntity(hitResult.getBlockPos());
				if (be instanceof MenuProvider || be instanceof Container) {
					serverPlayer.sendSystemMessage(Component.literal("§cYou cannot open storage containers during Creative Scroll use!"));
					return InteractionResult.FAIL;
				}
			}
			return InteractionResult.PASS;
		});

		// Prevent stashing items in minecart chests, item frames, or armor stands
		UseEntityCallback.EVENT.register((player, world, hand, entity, hitResult) -> {
			if (!world.isClientSide() && player instanceof ServerPlayer serverPlayer
					&& CONFIG.blockContainersAndDrops
					&& ScrollSessionManager.hasActiveScroll(serverPlayer)) {
				if (entity instanceof Container || entity instanceof ItemFrame || entity instanceof ArmorStand) {
					serverPlayer.sendSystemMessage(Component.literal("§cYou cannot store items in entities during Creative Scroll use!"));
					return InteractionResult.FAIL;
				}
			}
			return InteractionResult.PASS;
		});

		// Register /scroll admin commands (requires Gamemaster / OP level 2)
		CommandRegistrationCallback.EVENT.register((dispatcher, registryAccess, environment) -> {
			dispatcher.register(Commands.literal("CreativeScroll")
					.requires(source -> source.permissions().hasPermission(Permissions.COMMANDS_GAMEMASTER))
					.then(Commands.literal("reload")
							.executes(context -> {
								CONFIG = ScrollConfig.load();
								context.getSource().sendSuccess(
										() -> Component.literal("§aCreative Scroll config reloaded!"), true);
								return 1;
							})
					)
					.then(Commands.literal("expire")
							.then(Commands.argument("target", EntityArgument.player())
									.executes(context -> {
										ServerPlayer target = EntityArgument.getPlayer(context, "target");
										ScrollSessionData data = target.getAttached(SCROLL_SESSION);
										if (data == null) {
											context.getSource().sendFailure(
													Component.literal("§cThat player does not have an active scroll."));
											return 0;
										}
										ScrollSessionManager.endSession(target, context.getSource().getServer(), data);
										context.getSource().sendSuccess(
												() -> Component.literal("§eExpired Creative Scroll for " + target.getName().getString()), true);
										return 1;
									})
							)
					)
			);
		});

		LOGGER.info("Scroll of Creative Mode initialized!");
	}
}

package com.ndrsbox.creativescroll.config;

import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import net.fabricmc.loader.api.FabricLoader;

import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;

public class ScrollConfig {
    private static final Gson GSON = new GsonBuilder().setPrettyPrinting().create();
    private static final Path CONFIG_PATH = FabricLoader.getInstance()
            .getConfigDir().resolve("creativescroll.json");

    public int defaultDurationSeconds = 1800; // 30 minutes
    public int slowFallingSeconds = 10;
    public boolean sandboxInventory = true; // Saves survival inv & wipes creative inv on expire
    public boolean blockContainersAndDrops = true; // Stops storing/dropping items while active
    public List<String> blockedItems = List.of(
            "minecraft:bedrock",
            "minecraft:command_block",
            "minecraft:repeating_command_block",
            "minecraft:chain_command_block",
            "minecraft:structure_block",
            "minecraft:barrier",
            "minecraft:light",
            "minecraft:spawner",
            "minecraft:end_portal_frame",
            "minecraft:netherite_block",
            "minecraft:diamond_block"
    );

    public static ScrollConfig load() {
        if (Files.exists(CONFIG_PATH)) {
            try {
                return GSON.fromJson(Files.readString(CONFIG_PATH), ScrollConfig.class);
            } catch (IOException e) {
                e.printStackTrace();
            }
        }
        ScrollConfig defaults = new ScrollConfig();
        defaults.save();
        return defaults;
    }

    public void save() {
        try {
            Files.writeString(CONFIG_PATH, GSON.toJson(this));
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

import net.minecraft.sounds.SoundEvents;
import net.minecraft.sounds.SoundSource;
import net.minecraft.world.InteractionHand;
import net.minecraft.world.InteractionResult;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.item.Item;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.level.GameType;
import net.minecraft.world.level.Level;

public class CreativeScrollItem extends Item {
    public CreativeScrollItem(Properties properties) {
        super(properties.stacksTo(1));
    }

    @Override
    public InteractionResult use(Level level, Player player, InteractionHand hand) {
        ItemStack stack = player.getItemInHand(hand);

        if (!level.isClientSide() && player instanceof ServerPlayer serverPlayer) {
            if (serverPlayer.gameMode.getGameModeForPlayer() == GameType.CREATIVE) {
                serverPlayer.sendSystemMessage(Component.literal("§cYou are already in Creative Mode!"));
                return InteractionResult.FAIL;
            }

            // Consume 1 scroll
            if (!serverPlayer.getAbilities().instabuild) {
                stack.shrink(1);
            }

            int ticks = Creativescroll.CONFIG.defaultDurationSeconds * 20;
            ScrollSessionManager.startSession(serverPlayer, ticks);

            level.playSound(null, serverPlayer.blockPosition(),
                    SoundEvents.UI_TOAST_CHALLENGE_COMPLETE, SoundSource.PLAYERS, 1.0F, 1.0F);
        }

        return InteractionResult.SUCCESS;
    }

    public boolean isFoil(ItemStack stack) {
        return true;
    }
}

package com.ndrsbox.creativescroll.mixin;

import com.ndrsbox.creativescroll.Creativescroll;
import com.ndrsbox.creativescroll.state.ScrollSessionManager;
import net.minecraft.core.registries.BuiltInRegistries;
import net.minecraft.network.chat.Component;
import net.minecraft.network.protocol.game.ServerboundPlayerActionPacket;
import net.minecraft.network.protocol.game.ServerboundSetCreativeModeSlotPacket;
import net.minecraft.resources.Identifier;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.server.network.ServerGamePacketListenerImpl;
import net.minecraft.world.item.ItemStack;
import org.spongepowered.asm.mixin.Mixin;
import org.spongepowered.asm.mixin.Shadow;
import org.spongepowered.asm.mixin.injection.At;
import org.spongepowered.asm.mixin.injection.Inject;
import org.spongepowered.asm.mixin.injection.callback.CallbackInfo;

@Mixin(ServerGamePacketListenerImpl.class)
public abstract class ServerGamePacketListenerImplMixin {

    @Shadow
    public ServerPlayer player;

    @Inject(method = "handleSetCreativeModeSlot", at = @At("HEAD"), cancellable = true)
    private void onCreativeSlotClick(ServerboundSetCreativeModeSlotPacket packet, CallbackInfo ci) {
        if (!ScrollSessionManager.hasActiveScroll(this.player)) return;

        // Block throwing items out of the Creative inventory window (slot < 0)
        if (Creativescroll.CONFIG.blockContainersAndDrops && packet.slotNum() < 0 && !packet.itemStack().isEmpty()) {
            this.player.sendSystemMessage(Component.literal("§cYou cannot drop items during Creative Scroll use!"));
            this.player.containerMenu.broadcastFullState();
            ci.cancel();
            return;
        }

        // Block spawning items on the blocklist
        ItemStack clicked = packet.itemStack();
        Identifier itemId = BuiltInRegistries.ITEM.getKey(clicked.getItem());

        if (Creativescroll.CONFIG.blockedItems.contains(itemId.toString())) {
            this.player.sendSystemMessage(Component.literal("§cThat item is blocked during Creative Scroll use!"));
            this.player.containerMenu.broadcastFullState();
            ci.cancel();
        }
    }

    @Inject(method = "handlePlayerAction", at = @At("HEAD"), cancellable = true)
    private void onPlayerAction(ServerboundPlayerActionPacket packet, CallbackInfo ci) {
        if (!Creativescroll.CONFIG.blockContainersAndDrops || !ScrollSessionManager.hasActiveScroll(this.player)) return;

        ServerboundPlayerActionPacket.Action action = packet.getAction();
        if (action == ServerboundPlayerActionPacket.Action.DROP_ITEM
                || action == ServerboundPlayerActionPacket.Action.DROP_ALL_ITEMS) {
            this.player.sendSystemMessage(Component.literal("§cYou cannot drop items during Creative Scroll use!"));
            this.player.containerMenu.broadcastFullState();
            ci.cancel();
        }
    }
}

```java
package com.ndrsbox.creativescroll.state;

import com.ndrsbox.creativescroll.Creativescroll;
import net.minecraft.network.chat.Component;
import net.minecraft.server.MinecraftServer;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.world.effect.MobEffectInstance;
import net.minecraft.world.effect.MobEffects;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.level.GameType;

import java.util.ArrayList;
import java.util.List;

public class ScrollSessionManager {

    public static void startSession(ServerPlayer player, int durationTicks) {
        List<ItemStack> savedItems = new ArrayList<>();
        if (Creativescroll.CONFIG.sandboxInventory) {
            for (int i = 0; i < player.getInventory().getContainerSize(); i++) {
                savedItems.add(player.getInventory().getItem(i).copy());
            }
            player.getInventory().clearContent();
        }

        ScrollSessionData data = new ScrollSessionData(durationTicks, savedItems);
        player.setAttached(Creativescroll.SCROLL_SESSION, data);
        player.setGameMode(GameType.CREATIVE);
        player.sendSystemMessage(Component.literal("§aScroll of Creative Mode activated!"));
    }

    public static void tickPlayer(ServerPlayer player, MinecraftServer server) {
        ScrollSessionData data = player.getAttached(Creativescroll.SCROLL_SESSION);
        if (data == null) return;

        int remaining = data.remainingTicks() - 1;

        // Actionbar countdown every second
        if (remaining % 20 == 0 && remaining > 0) {
            int mins = remaining / 1200;
            int secs = (remaining % 1200) / 20;
            player.sendSystemMessage(
                    Component.literal(String.format("§eCreative Scroll: §f%02d:%02d", mins, secs)), true);
        }

        if (remaining <= 0) {
            endSession(player, server, data);
        } else {
            player.setAttached(Creativescroll.SCROLL_SESSION,
                    new ScrollSessionData(remaining, data.savedInventory()));
        }
    }

    public static void endSession(ServerPlayer player, MinecraftServer server, ScrollSessionData data) {
        player.removeAttached(Creativescroll.SCROLL_SESSION);

        // Wipe Creative items and restore original Survival inventory
        if (Creativescroll.CONFIG.sandboxInventory) {
            player.getInventory().clearContent();
            List<ItemStack> saved = data.savedInventory();
            for (int i = 0; i < Math.min(saved.size(), player.getInventory().getContainerSize()); i++) {
                player.getInventory().setItem(i, saved.get(i));
            }
        }

        // Revert to server's global default gamemode
        player.setGameMode(server.getDefaultGameType());

        // Apply Slow Falling safeguard
        int slowFallTicks = Creativescroll.CONFIG.slowFallingSeconds * 20;
        if (slowFallTicks > 0) {
            player.addEffect(new MobEffectInstance(MobEffects.SLOW_FALLING, slowFallTicks, 0, false, true));
        }

        player.sendSystemMessage(Component.literal("§6Your Scroll of Creative Mode has expired!"));
    }

    public static boolean hasActiveScroll(ServerPlayer player) {
        return player.hasAttached(Creativescroll.SCROLL_SESSION);
    }
}
