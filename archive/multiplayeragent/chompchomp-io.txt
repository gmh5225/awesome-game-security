`README.md`:

```md
# ChompChomp.io: a multiplayer snake .io game with server-authoritative anti-cheat

**[▶ Play ChompChomp.io now](https://chompchompio.play.multiplayeragent.com/)**: free, in the browser, no download. Send the link to a friend and you're in the same arena.

ChompChomp.io is a slither-style browser game where snakes have guns. Eat glowing orbs to grow, grab power-ups and weapons, shoot rivals' bodies to slice them in half, and chomp anyone who crosses your path. It runs online with friends, with player accounts, saved stats, global leaderboards, and bots that fill the world and step aside as real players join.

It was built with [Claude Code](https://claude.com/claude-code) and the [Multiplayer Agent](https://multiplayeragent.com/) plugin, starting from a single-player canvas game and turning it into a hosted multiplayer game. There's no game server to write, run or deploy. This repo is the full source, and it's part of the content package for the video made while building it.

![ChompChomp.io gameplay: a snake moving through glowing orbs, with the live leaderboard and minimap](docs/gameplay.png)

## Features

- **Real-time multiplayer:** everyone who opens the link plays in the same arena, synced 20 times a second.
- **Server-authoritative anti-cheat:** the server decides movement, dots, power-ups, bullets, damage and scores. The browser only sends steering, boost and fire. You can't teleport, spawn power-ups, or fake a score.
- **Player login:** you start as a guest instantly. Sign up to keep your progress and put your name on the leaderboards, and log in on any device.
- **Saved player data:** games played, best score, longest snake, total kills, dots eaten and time played, all written by the server.
- **Global leaderboards:** best score, total kills and longest snake, plus a live in-match leaderboard.
- **Bots that make room:** 24 bots keep an empty world lively. Three retire for every player who joins, out of sight.
- **7 weapons and 17 power-ups:** blaster, shotgun, twin guns, SMG, railgun, rocket launcher, homing seeker; shields, ghost mode, frenzy, vampire, nanobots and more.
- **Smooth netcode:** client-side prediction for your own snake and interpolation for everyone else, so steering feels instant.
- **Desktop and mobile:** mouse, keyboard or touch, with on-screen fire and boost buttons.

![ChompChomp.io menu with skins, sign up / log in, global leaderboards and player stats](docs/menu.png)

## How to play

| Action | Desktop | Mobile |
| --- | --- | --- |
| Steer | Mouse | Drag |
| Shoot | Left click or `F` | FIRE button |
| Boost (costs length) | Right click, `Space` or `W` | BOOST button or two fingers |

Body shots slice snakes; headshots drain health. Shooting is free under length 100, and smaller snakes fire faster. Running your head into another snake's body ends your run, and the world's red edge is deadly.

## How the anti-cheat works

Most browser .io clones trust the client: the browser says where its snake is and what it ate. ChompChomp.io doesn't. The whole world is simulated on the server by [authoritative room logic](https://multiplayeragent.com/docs) running on Multiplayer Agent:

```
 browser                                   Multiplayer Agent room "arena" (server)
 ───────                                   ───────────────────────────────────────
 mouse / keys ──► input {angle, boost, fire} ──► onInput: queue it, one per tick
                                                 onTick: move snakes, eat orbs, fire bullets,
                                                         collide, kill, spawn/retire bots
 draws snakes ◄── room state (snake heads, mass, power-ups) ◄─┘
 draws orbs   ◄── events (orb added/eaten, bullet fired/hit, effects)
 stats screen ◄── saveData / submitScore (only the server writes these)
```

- Clients can't write room state. If a modified client sends fake "I ate this" or "I picked that up" messages, or sets its own position or mass, the server ignores it.
- Inputs are validated: a steering angle, two booleans, nothing else. Speed and turning come from the server's rules, so a snake can't teleport.
- Saves and leaderboard scores are written by the server from results it computed itself, so they can't be forged from the browser.
- Your own snake is predicted locally from your inputs and corrected against the server every tick, so it still feels instant.

## Run your own copy

You need [Claude Code](https://claude.com/claude-code) with the [Multiplayer Agent plugin](https://github.com/multiplayeragent/multiplayer-agent):

```
/plugin marketplace add multiplayeragent/multiplayer-agent
/plugin install multiplayer-agent@multiplayer-agent
```

Then ask Claude Code to "host this game on my own Multiplayer Agent game" in a clone of this repo. Claude will:

1. Create a game with `create_game` and put its publishable key (`pk_…`) in `NET.key` at the top of [game.js](game.js). The key in this repo points at the live ChompChomp.io game, so without this step your copy joins that arena.
2. Build the server bundle with `node build.js` (Node 18+, no dependencies). This writes `dist/server.js`.
3. Deploy it with `deploy_room_logic` to the room `arena`, at tick rate 20. Server logic needs a Multiplayer Agent account; Claude opens the sign-in page for you.
4. Publish `index.html`, `style.css`, `powerups.js`, `sim.js` and `game.js` with `publish_game`, which gives you a share link at `https://<your-game>.play.multiplayeragent.com/`.

The [free tier](https://multiplayeragent.com/pricing) is enough to play with friends.
```

```js
// Bundles the authoritative room logic: powerups.js + sim.js + server/logic.js -> dist/server.js.
// The room runtime has no imports, so the shared game rules are concatenated in.
// Usage: node build.js
const fs = require('fs');
const path = require('path');

const read = (f) => fs.readFileSync(path.join(__dirname, f), 'utf8');
const src = [
  'var window = globalThis;',
  read('powerups.js'),
  read('sim.js'),
  read('server/logic.js'),
].join('\n;\n');

fs.mkdirSync(path.join(__dirname, 'dist'), { recursive: true });
fs.writeFileSync(path.join(__dirname, 'dist/server.js'), src);
console.log(`dist/server.js: ${(src.length / 1024).toFixed(1)} KB`);
```

```js
  const hexPattern = makeHexPattern();
  const sparkSprite = glowSprite('#ffffff');
  const fireSprite = glowSprite('#ff922b');

    g.beginPath();

    S.steer(p, inp.a, me.r, me.tu, S.moveSpeed(boosting, me.sp), INPUT_DT);
  }

  class Snake {
    constructor(id, e, t) {
      this.id = id;
      this.name = e.n || '?';
      this.skin = SKINS[clamp(e.s | 0, 0, SKINS.length - 1)];
      this.sprites = this.skin.map(bodySprite);
      this.glow = glowSprite(this.skin[0]);
      this.miniColor = rgba(this.skin[0], 0.7);
      this.pid = e.p || '';
      this.isPlayer = false;
      this.seen = t;
      this.samples = []; // server head positions {t, x, y, a}, oldest first
      this.trail = [];
      this.segs = [];
      this.hurt = new Map(); // damaged circle index -> severity 0-9
      this.hurtKey = '';
      this.upKey = null;
      this.stacks = {};
      this.bodyKey = '';
      this.hp = e.hp;
      this.shield = e.sh;
      this.hitFlash = 0;
      this.shieldFlash = 0;
      this.ghostLeft = 0;
      this.frenzyLeft = 0;
      this.x = e.x;
      this.y = e.y;
      this.angle = this.targetAngle = e.a;
      this.apply(e, t);
      if (!this.trail.length) {
        const L = S.bodyLength(this.mass) + 20, ca = Math.cos(this.angle), sa = Math.sin(this.angle);
        for (let d = L; d > 0; d -= 6) this.trail.push({ x: this.x - ca * d, y: this.y - sa * d });
        this.trail.push({ x: this.x, y: this.y });
      }
    }

    apply(e, t) {
      if (e.hp < this.hp) this.hitFlash = 0.15;
      if (e.sh < this.shield) this.shieldFlash = 0.2;
      this.mass = e.m;
      this.r = S.radius(e.m);
      this.boosting = !!e.bo;
      this.hp = e.hp;
      this.maxHp = e.mh;
      this.shield = e.sh;
      this.ge = e.ge;
      this.fe = e.fe;
      this.weapon = WEAPON_IDS[e.w] || 'blaster';
      this.score = e.sc;
      this.kills = e.k;
      this.dots = e.d;
      this.hits = e.hi;
      this.sp = e.sp || 1;
      this.tu = e.tu || 1;
      this.ack = e.ack | 0;
      if (e.up !== this.upKey) {
        this.upKey = e.up;
        this.stacks = {};
        for (const part of (e.up || '').split(',')) {
          const [id, n] = part.split(':');
          if (POWERUPS[id]) this.stacks[id] = n | 0;
        }
      }
      if (e.hu !== this.hurtKey) {
        this.hurtKey = e.hu;
        this.hurt.clear();
        for (const part of (e.hu || '').split(',')) {
          const k = part.indexOf(':');
          if (k > 0) this.hurt.set(part.slice(0, k) | 0, part.slice(k + 1) | 0);
        }
      }
      const last = this.samples[this.samples.length - 1];
      if (!last || last.x !== e.x || last.y !== e.y) {
        this.samples.push({ t, x: e.x, y: e.y, a: e.a });
        if (this.samples.length > 40) this.samples.shift();
      }
      // A fresh body outline only matters to snakes we just started seeing; after that the body
      // grows from the head path we've drawn.
      if (e.bd && e.bd !== this.bodyKey) {
        this.bodyKey = e.bd;
        if (!this.isPlayer && t - this.seen < 2) this.loadBody(e.bd, true);
      }
    }

    // Rebuild the trail from the server's outline (head first). Other snakes are drawn slightly in
    // the past, so `behind` drops the stretch nearest the head they haven't reached yet.
    loadBody(bd, behind) {
      const pts = bd.split(';').map((p) => {
        const k = p.indexOf(',');
        return { x: +p.slice(0, k), y: +p.slice(k + 1) };
      });
      let skip = behind ? S.moveSpeed(this.boosting, this.sp) * INTERP_DELAY : 0, i = 0;
      while (skip > 0 && i < pts.length - 2) {
        skip -= Math.hypot(pts[i + 1].x - pts[i].x, pts[i + 1].y - pts[i].y);
        i++;
      }
      this.trail = pts.slice(i).reverse();
    }

    // Head position `INTERP_DELAY` ago, between the two server updates around it.
    interpolate(rt) {
      const sm = this.samples;
      while (sm.length > 2 && sm[1].t < rt - 1) sm.shift();
      let i = sm.length - 1;
      while (i > 0 && sm[i].t > rt) i--;
      const a = sm[i], b = sm[i + 1];
      if (!b) {
        const dt = clamp(rt - a.t, 0, 0.2), sp = S.moveSpeed(this.boosting, this.sp);
        this.x = a.x + Math.cos(a.a) * sp * dt;
        this.y = a.y + Math.sin(a.a) * sp * dt;
        this.angle = a.a;
      } else if (rt <= a.t) {
        this.x = a.x;
        this.y = a.y;
        this.angle = a.a;
      } else {
        const f = (rt - a.t) / (b.t - a.t);
        this.x = a.x + (b.x - a.x) * f;
        this.y = a.y + (b.y - a.y) * f;
        this.angle = a.a + angleDiff(a.a, b.a) * f;
      }
      this.targetAngle = this.angle;
    }

    tick(dt) {
      if (this.isPlayer) {
        const f = clamp((time - predAt) / INPUT_DT, 0, 1);
        this.x = prevPred.x + (pred.x - prevPred.x) * f + corr.x;
        this.y = prevPred.y + (pred.y - prevPred.y) * f + corr.y;
        this.angle = prevPred.angle + angleDiff(prevPred.angle, pred.angle) * f;
        this.targetAngle = targetAngle;
      } else {
        this.interpolate(time - INTERP_DELAY);
      }
      const tr = this.trail, last = tr[tr.length - 1];
      if (last && (last.x - this.x) ** 2 + (last.y - this.y) ** 2 < 4) {
        last.x = this.x;
        last.y = this.y;
      } else {
        tr.push({ x: this.x, y: this.y });
      }
      S.layoutBody(tr, this.segs, this.r, this.mass);
      const sn = serverNow();
      this.ghostLeft = Math.max(0, this.ge - sn);
      this.frenzyLeft = Math.max(0, this.fe - sn);
      if (this.hitFlash > 0) this.hitFlash -= dt;
      if (this.shieldFlash > 0) this.shieldFlash -= dt;
    }
  }

  function becomeMe(s) {
    if (me) me.isPlayer = false;
    me = s;
    s.isPlayer = true;
    const last = s.samples[s.samples.length - 1];
    pred = { x: last.x, y: last.y, angle: last.a };
    prevPred = { ...pred };
    predAt = time;
    corr.x = corr.y = 0;
    pendingInputs.length = 0;
    targetAngle = last.a;
    if (s.bodyKey) s.loadBody(s.bodyKey, false);
    cam.x = cam.tx = last.x;
    cam.y = cam.ty = last.y;
    state = 'playing';
    lbIdx = 0;
    lbT = LB_ROTATE;
    menu.hidden = true;
    guide.hidden = true;
    deathScreen.hidden = true;
    hud.hidden = false;
    input.reset();
    updateHud();
  }

  function reconcile(e) {
    while (pendingInputs.length && pendingInputs[0].q <= e.ack) pendingInputs.shift();
    const p = { x: e.x, y: e.y, angle: e.a };
    for (const inp of pendingInputs) predictStep(p, inp);
    const dx = p.x - pred.x, dy = p.y - pred.y, da = angleDiff(pred.angle, p.angle);
    // Keep the drawn head where it is and let the offset fade, unless it is a real jump.
    if (dx * dx + dy * dy < 250 * 250) {
      corr.x -= dx;
      corr.y -= dy;
    } else {
      corr.x = corr.y = 0;
    }
    prevPred.x += dx;
    prevPred.y += dy;
    prevPred.angle += da;
    pred = p;
  }

  function sendInput() {
    const inp = { q: ++seq, a: Math.round(targetAngle * 1000) / 1000, b: input.boost() ? 1 : 0, f: input.firing() ? 1 : 0 };
    mp.sendInput(inp);
    pendingInputs.push(inp);
    if (pendingInputs.length > 60) pendingInputs.shift();
    prevPred = { ...pred };
    predictStep(pred, inp);
    predAt = time;
  }

  // ---------- Server messages ----------
  function addFood(id, x, y, v10, c) {
    if (foods.has(id)) return;
    const value = v10 / 10;
    foods.set(id, {
      x, y,
      r: 3 + Math.sqrt(value) * 2.3,
      phase: rand(0, TAU),
      born: time,
      sprite: foodSprite(PALETTE[c] || PALETTE[0]),
    });
  }

  function eatFood(id, sid) {
    const f = foods.get(id);
    if (!f) return;
    foods.delete(id);
    const s = snakes.get(String(sid));
    if (s && inView(f.x, f.y, 60)) {
      f.eater = s;
      f.eatT = 0.12;
      eating.push(f);
    }
  }

  function addBullet(id, x, y, vx, vy, life, wi, ownerId) {
    const w = WEAPONS[WEAPON_IDS[wi]] || WEAPONS.blaster;
    const owner = snakes.get(String(ownerId));
    bullets.push({
      id, x, y, vx, vy, life,
      size: w.size,
      tail: w.tail || 0.02,
      homing: w.homing || 0,
      glow: w.explode ? fireSprite : owner ? owner.glow : sparkSprite,
      owner,
      target: null,
      retarget: 0,
      dead: false,
    });
  }

  function onTickEvents(batch) {
    if (!Array.isArray(batch)) return;
    for (const t of batch) {
      switch (t[0]) {
        case 'f': addFood(t[1], t[2], t[3], t[4], t[5]); break;
        case 'e': eatFood(t[1], t[2]); break;
        case 'b': addBullet(t[1], t[2], t[3], t[4], t[5], t[6], t[7], t[8]); break;
        case 'd': for (const b of bullets) if (b.id === t[1]) b.dead = true; break;
        case 'h': hitFx(snakes.get(String(t[1])), t[2], t[3], t[4], t[5], t[6], t[7]); break;
        case 'x': explosionFx(t[1], t[2], t[3]); break;
        case 'p': {
          const def = POWERUPS[t[3]];
          if (def && inView(t[1], t[2], 100)) spawnParticles(t[1], t[2], 0, Math.PI, 14, 380, 10, rarityGlow[def.rarity], true);
          break;
        }
      }
    }
  }

  function onFoodSnapshot(d) {
    if (!d || !Array.isArray(d.f)) return;
    if (d.i === 0) foods.clear();
    const f = d.f;
    for (let k = 0; k + 4 < f.length; k += 5) addFood(f[k], f[k + 1], f[k + 2], f[k + 3], f[k + 4]);
  }

  let lostMeAt = 0;
  function onState(st) {
    const t = performance.now() / 1000;
    const shared = st.shared || {};
    if (typeof shared.t === 'number' && shared.t !== serverT) {
      serverT = shared.t;
      serverTAt = t;
    }
    const ents = (st.entities && st.entities.snakes) || {};
    for (const id in ents) {
      const e = ents[id];
      if (typeof e.x !== 'number') continue;
      const s = snakes.get(id);
      if (s) s.apply(e, t);
      else snakes.set(id, new Snake(id, e, t));
    }
    for (const id of snakes.keys()) {
      if (ents[id]) continue;
      snakes.delete(id);
      if (me && me.id === id) {
        me = null;
        lostMeAt = t;
      }
    }

    const players = (st.entities && st.entities.players) || {};
    online = Object.keys(players).length;
    const mine = mp && players[mp.sessionId];
    const myId = mine && mine.sn ? String(mine.sn) : '';
    if (myId && (!me || me.id !== myId) && snakes.has(myId)) becomeMe(snakes.get(myId));
    if (me) reconcile(ents[me.id]);

    const pk = (st.entities && st.entities.pk) || {};
    const list = [];
    for (const id in pk) {
      const e = pk[id];
      if (!POWERUPS[e.t]) continue;
      let p = pickupCache.get(id);
      if (!p) pickupCache.set(id, (p = { phase: rand(0, TAU), born: t }));
      p.x = e.x;
      p.y = e.y;
      p.type = e.t;
      p.natural = !!e.n;
      p.serverBorn = e.b;
      list.push(p);
    }
    if (pickupCache.size > list.length + 50) {
      for (const id of pickupCache.keys()) if (!pk[id]) pickupCache.delete(id);
    }
    pickups = list;
  }

  function onDead(d) {
    if (!d || typeof d !== 'object') return;
    state = 'dead';
    me = null;
    hud.hidden = true;
    input.reset();
    $('deathCause').textContent = d.cause === 'edge' ? 'You hit the edge of the world'
      : d.cause === 'shot' ? `Shot down by ${d.by}` : d.by ? `Chomped by ${d.by}` : 'You got chomped';
    $('dScore').textContent = d.score | 0;
    $('dLen').textContent = d.len | 0;
    $('dKills').textContent = d.kills | 0;
    $('dDots').textContent = d.dots | 0;
    $('dHits').textContent = d.hits | 0;
    $('dTime').textContent = fmtTime(d.secs | 0);
    $('dBest').textContent = d.newBest ? 'New best score!' : `Your best score: ${d.best | 0}`;
    setTimeout(() => { if (state === 'dead') deathScreen.hidden = false; }, 1100);
    setTimeout(refreshMenuData, 1500); // saves and scores flush within about a second
  }

  // ---------- Effects ----------
  const inView = (x, y, margin) =>
    Math.abs(x - cam.x) < W / 2 / cam.zoom + margin && Math.abs(y - cam.y) < H / 2 / cam.zoom + margin;

  function spawnParticles(x, y, ang, spread, n, speed, size, sprite, glow) {
    for (let k = 0; k < n && particles.length < MAX_PARTICLES; k++) {
      const a = ang + rand(-spread, spread), sp = speed * rand(0.35, 1), life = rand(0.3, 0.65);
      particles.push({ x, y, vx: Math.cos(a) * sp, vy: Math.sin(a) * sp, life, max: life, size: size * rand(0.6, 1.2), sprite, glow });
    }
  }

  // Chunks of the snake's skin plus white sparks, sprayed around `ang`.
  function hitFx(s, i, x, y, ang, spread, scale) {
    if (!inView(x, y, 150)) return;
    if (s) {
      const sprite = s.sprites[((i / 3) | 0) % s.sprites.length];
      spawnParticles(x, y, ang, spread, Math.round(8 * scale), 420, Math.max(5, s.r * 0.5), sprite, false);
    }
    spawnParticles(x, y, ang, spread * 1.3, Math.round(6 * scale), 650, 11, sparkSprite, true);
  }

  function explosionFx(x, y, R) {
    if (!inView(x, y, R + 100)) return;
    spawnParticles(x, y, 0, Math.PI, 30, R * 5, 22, fireSprite, true);
    spawnParticles(x, y, 0, Math.PI, 12, R * 6, 10, sparkSprite, true);
    particles.push({ x, y, vx: 0, vy: 0, life: 0.35, max: 0.35, size: R, ring: true });
  }

  function updateParticles(dt) {
    const drag = Math.max(0, 1 - 4 * dt);
    for (const p of particles) {
      p.x += p.vx * dt;
      p.y += p.vy * dt;
      p.vx *= drag;
      p.vy *= drag;
      p.life -= dt;
    }
    particles = particles.filter((p) => p.life > 0);
  }

  // Bullets fly on their own between server messages; the server says when one hits something.
  function updateBullets(dt) {
    for (const b of bullets) {
      b.life -= dt;
      if (b.homing) {
        const sp = Math.hypot(b.vx, b.vy);
        b.retarget -= dt;
        if (b.retarget <= 0) {
          b.retarget = 0.15;
          b.target = null;
          let best = 650 * 650;
          const cx = b.vx / sp, cy = b.vy / sp;
          for (const o of snakes.values()) {
            if (o === b.owner || o.ghostLeft > 0) continue;
            const dx = o.x - b.x, dy = o.y - b.y, d2 = dx * dx + dy * dy;
            if (d2 < best && dx * cx + dy * cy > 0) { best = d2; b.target = o; }
          }
        }
        const t = b.target;
        if (t && snakes.get(t.id) === t) {
          const cur = Math.atan2(b.vy, b.vx);
          const a = cur + clamp(angleDiff(cur, Math.atan2(t.y - b.y, t.x - b.x)), -b.homing * dt, b.homing * dt);
          b.vx = Math.cos(a) * sp;
          b.vy = Math.sin(a) * sp;
        }
      }
      b.x += b.vx * dt;
      b.y += b.vy * dt;
      if (b.life <= 0 || b.x * b.x + b.y * b.y > WORLD_R * WORLD_R) b.dead = true;
    }
    bullets = bullets.filter((b) => !b.dead);
  }

  function updateEating(dt) {
    for (const f of eating) {
      f.eatT -= dt;
      const h = f.eater.segs[0];
      if (!h) continue;
      const k = Math.min(1, dt * 22);
      f.x += (h.x - f.x) * k;
      f.y += (h.y - f.y) * k;
    }
    eating = eating.filter((f) => f.eatT > 0);
  }

  // ---------- Update ----------
  function update(dt) {
    if (state === 'playing' && me && mp) {
      const dx = input.x - ((me.x - cam.x) * cam.zoom + W / 2);
      const dy = input.y - ((me.y - cam.y) * cam.zoom + H / 2);
      if (dx * dx + dy * dy > 25) targetAngle = Math.atan2(dy, dx);
      inputAcc += dt;
      for (let n = 0; inputAcc >= INPUT_DT && n < 3; n++) {
        inputAcc -= INPUT_DT;
        sendInput();
      }
      if (inputAcc > INPUT_DT) inputAcc = 0;
    }
    const k = Math.exp(-dt * 8);
    corr.x *= k;
    corr.y *= k;
    for (const s of snakes.values()) s.tick(dt);
    updateEating(dt);
    updateBullets(dt);
    updateParticles(dt);
    updateCamera(dt);

    // Our snake vanished without a death notice (e.g. a reconnect): back to the menu.
    if (state === 'playing' && !me && time - lostMeAt > 2.5) showMenu();
    if (state === 'spawning' && time - spawnAt > 4) {
      showMenu();
      setMenuMsg('Could not spawn. Try again.');
    }

    if (state === 'playing' && me) {
      updateHealthBar();
      lbT -= dt;
      if (lbT <= 0) {
        lbIdx = (lbIdx + 1) % LB_CATS.length;
        lbT = LB_ROTATE;
        hudT = 0;
      }
      lbTimerFill.style.width = `${(lbT / LB_ROTATE) * 100}%`;
      hudT -= dt;
      if (hudT <= 0) {
        updateHud();
        hudT = 0.25;
      }
    }
  }

  function updateCamera(dt) {
    let target = me;
    if (!target && state === 'menu') {
      for (const s of snakes.values()) if (!target || s.mass > target.mass) target = s;
    }
    if (target) {
      cam.tx = target.x;
      cam.ty = target.y;
      cam.tr = target.r;
    }
    const k = Math.min(1, dt * (state === 'playing' ? 12 : 2.5));
    cam.x += (cam.tx - cam.x) * k;
    cam.y += (cam.ty - cam.y) * k;
    const base = clamp(Math.min(W, H) / 850, 0.6, 1.5);
    const zt = base * Math.pow(14 / (cam.tr + 3), 0.55);
    cam.zoom += (zt - cam.zoom) * Math.min(1, dt * 2);
  }

  // ---------- Rendering ----------
  function drawSnake(s, vx0, vy0, vx1, vy1) {
    const segs = s.segs, n = segs.length, r = s.r;
    if (!n) return;
    const m = r * 2.6;
    const alpha = s.ghostLeft > 0 ? 0.35 + 0.1 * Math.sin(time * 10) : 1;

    if (s.boosting) {
      ctx.globalCompositeOperation = 'lighter';
      ctx.globalAlpha = (0.55 + 0.25 * Math.sin(time * 18)) * alpha;
      for (let i = n - 1; i >= 0; i -= 2) {
        const p = segs[i];
        if (p.x < vx0 - m || p.x > vx1 + m || p.y < vy0 - m || p.y > vy1 + m) continue;
        ctx.drawImage(s.glow, p.x - m, p.y - m, m * 2, m * 2);
      }
      ctx.globalCompositeOperation = 'source-over';
    }

    ctx.globalAlpha = alpha;
    const tailN = clamp(Math.floor(n * 0.35), 3, 12);
    for (let i = n - 1; i >= 0; i--) {
      const p = segs[i];
      if (p.x < vx0 - r || p.x > vx1 + r || p.y < vy0 - r || p.y > vy1 + r) continue;
      const fromTail = n - 1 - i;
      const sr = fromTail < tailN ? r * (0.45 + (0.55 * fromTail) / tailN) : r;
      ctx.drawImage(s.sprites[((i / 3) | 0) % s.sprites.length], p.x - sr, p.y - sr, sr * 2, sr * 2);
    }

    // Damaged circles: charred, cracked, and a blinking ring once close to breaking.
    // Drawn on top since each circle is mostly covered by the next one.
    if (s.hurt.size) {
      const blink = 0.5 + 0.5 * Math.sin(time * 16);
      const cr = r * 0.85;
      ctx.fillStyle = '#000';
      ctx.strokeStyle = '#fff';
      ctx.lineWidth = Math.max(1.5, r * 0.14);
      for (const [i, sev] of s.hurt) {
        const p = segs[i];
        if (!p || p.x < vx0 - r || p.x > vx1 + r || p.y < vy0 - r || p.y > vy1 + r) continue;
        const frac = (sev + 0.5) / 10;
        ctx.globalAlpha = (0.3 + 0.5 * frac) * alpha;
        ctx.beginPath();
        ctx.arc(p.x, p.y, cr, 0, TAU);
        ctx.fill();
        ctx.globalAlpha = Math.min(1, 0.5 + frac) * alpha;
        ctx.drawImage(crackSprites[i % 3], p.x - cr, p.y - cr, cr * 2, cr * 2);
        if (frac > 0.4) {
          ctx.globalAlpha = blink * frac * alpha;
          ctx.stroke();
        }
      }
    }

    const h = segs[0];
    if (s.frenzyLeft > 0) {
      const g = r * (2.4 + 0.4 * Math.sin(time * 20));
      ctx.globalCompositeOperation = 'lighter';
      ctx.globalAlpha = 0.8 * alpha;
      ctx.drawImage(frenzyGlow, h.x - g, h.y - g, g * 2, g * 2);
      ctx.globalCompositeOperation = 'source-over';
    }
    if (s.hitFlash > 0) {
      ctx.globalAlpha = (s.hitFlash / 0.15) * 0.7 * alpha;
      ctx.fillStyle = '#fff';
      ctx.beginPath();
      ctx.arc(h.x, h.y, r, 0, TAU);
      ctx.fill();
    }

    // Eyes
    ctx.globalAlpha = alpha;
    const ca = Math.cos(s.angle), sa = Math.sin(s.angle);
    const lc = Math.cos(s.targetAngle), ls = Math.sin(s.targetAngle);
    const er = r * 0.36, pr = r * 0.2;
    for (const side of [-1, 1]) {
      const ex = h.x + ca * r * 0.35 - sa * r * 0.48 * side;
      const ey = h.y + sa * r * 0.35 + ca * r * 0.48 * side;
      ctx.fillStyle = '#fff';
      ctx.beginPath();
      ctx.arc(ex, ey, er, 0, TAU);
      ctx.fill();
      ctx.fillStyle = '#111';
      ctx.beginPath();
      ctx.arc(ex + lc * er * 0.45, ey + ls * er * 0.45, pr, 0, TAU);
      ctx.fill();
    }

    // Shield bubble around the head
    if (s.shield > 0) {
      const f = s.shield / MAX_SHIELD;
      ctx.beginPath();
      ctx.arc(h.x, h.y, r * 1.55, 0, TAU);
      ctx.globalAlpha = (0.12 + 0.15 * f + (s.shieldFlash > 0 ? 0.25 : 0)) * alpha;
      ctx.fillStyle = '#74c0fc';
      ctx.fill();
      ctx.globalAlpha = (0.45 + 0.4 * f + (s.shieldFlash > 0 ? 0.3 : 0)) * alpha;
      ctx.strokeStyle = '#a5d8ff';
      ctx.lineWidth = Math.max(2, r * 0.14);
      ctx.stroke();
    }
    ctx.globalAlpha = 1;
  }

  function drawPickups(vx0, vy0, vx1, vy1) {
    const size = PICKUP_R * 2.3, gs = PICKUP_R * 4, sn = serverNow();
    for (const pk of pickups) {
      if (pk.x < vx0 - gs || pk.x > vx1 + gs || pk.y < vy0 - gs || pk.y > vy1 + gs) continue;
      const def = POWERUPS[pk.type];
      let a = Math.min(1, (time - pk.born) / 0.4);
      if (!pk.natural && PICKUP_DROP_LIFE - (sn - pk.serverBorn) < 10) a *= 0.55 + 0.45 * Math.sin(time * 12); // about to expire
      const y = pk.y + Math.sin(time * 3 + pk.phase) * 3;
      ctx.globalCompositeOperation = 'lighter';
      ctx.globalAlpha = a * (0.55 + 0.25 * Math.sin(time * 4 + pk.phase));
      ctx.drawImage(rarityGlow[def.rarity], pk.x - gs / 2, y - gs / 2, gs, gs);
      ctx.globalCompositeOperation = 'source-over';
      ctx.globalAlpha = a;
      ctx.drawImage(iconSprite(pk.type), pk.x - size / 2, y - size / 2, size, size);
    }
    ctx.globalAlpha = 1;
  }

  function drawMinimap() {
    const R = Math.min(75, Math.min(W, H) * 0.14);
    const cx = W - R - 16, cy = H - R - 16;
    const k = R / WORLD_R;
    ctx.fillStyle = 'rgba(10,14,20,0.7)';
    ctx.strokeStyle = 'rgba(255,255,255,0.18)';
    ctx.lineWidth = 1.5;
    ctx.beginPath();
    ctx.arc(cx, cy, R, 0, TAU);
    ctx.fill();
    ctx.stroke();
    // Rare and epic loot shows up on the map.
    for (const pk of pickups) {
      const rarity = POWERUPS[pk.type].rarity;
      if (rarity !== 'rare' && rarity !== 'epic') continue;
      ctx.fillStyle = RARITY[rarity].color;
      ctx.fillRect(cx + pk.x * k - 1.5, cy + pk.y * k - 1.5, 3, 3);
    }
    ctx.lineCap = 'round';
    for (const s of snakes.values()) {
      ctx.strokeStyle = s.isPlayer ? '#fff' : s.miniColor;
      ctx.lineWidth = s.isPlayer ? 2.5 : clamp(s.r * 0.08, 1, 3);
      ctx.beginPath();
      for (let i = 0; i < s.segs.length; i += 3) ctx.lineTo(cx + s.segs[i].x * k, cy + s.segs[i].y * k);
      ctx.stroke();
    }
    if (me) {
      ctx.fillStyle = '#fff';
      ctx.beginPath();
      ctx.arc(cx + me.x * k, cy + me.y * k, 3, 0, TAU);
      ctx.fill();
    }
  }

  // Player's loadout along the bottom: weapon, stacked upgrades, timed effects.
  function drawTray() {
    const items = [{ id: 'w_' + me.weapon, label: WEAPONS[me.weapon].name }];
    for (const id of Object.keys(me.stacks)) items.push({ id, count: me.stacks[id] });
    if (me.ghostLeft > 0) items.push({ id: 'ghost', timer: me.ghostLeft });
    if (me.frenzyLeft > 0) items.push({ id: 'frenzy', timer: me.frenzyLeft });
    const gap = 6;
    const size = clamp((W - 140) / items.length - gap, 22, 40);
    const total = items.length * (size + gap) - gap;
    let x = Math.max(116, (W - total) / 2);
    const y = H - size - 16;
    ctx.textAlign = 'center';
    for (const it of items) {
      ctx.drawImage(iconSprite(it.id), x, y, size, size);
      if (it.label) {
        ctx.font = '600 11px Poppins, system-ui, sans-serif';
        ctx.fillStyle = 'rgba(255,255,255,0.8)';
        ctx.fillText(it.label, x + size / 2, y - 6);
      }
      if (it.count > 1 || it.timer) {
        const text = it.timer ? `${Math.ceil(it.timer)}s` : `x${it.count}`;
        ctx.font = '700 11px Poppins, system-ui, sans-serif';
        const tw = ctx.measureText(text).width + 8;
        ctx.fillStyle = 'rgba(0,0,0,0.75)';
        ctx.fillRect(x + size - tw + 2, y + size - 12, tw, 14);
        ctx.fillStyle = it.timer ? '#ffd43b' : '#fff';
        ctx.fillText(text, x + size - tw / 2 + 2, y + size - 1);
      }
      x += size + gap;
    }
  }

  function render() {
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
    ctx.fillStyle = '#05070a';
    ctx.fillRect(0, 0, W, H);

    const z = cam.zoom;
    const vx0 = cam.x - W / 2 / z, vx1 = cam.x + W / 2 / z;
    const vy0 = cam.y - H / 2 / z, vy1 = cam.y + H / 2 / z;
    ctx.setTransform(DPR * z, 0, 0, DPR * z, DPR * (W / 2 - cam.x * z), DPR * (H / 2 - cam.y * z));

    // Hex floor inside the world
    ctx.save();
    ctx.beginPath();
    ctx.arc(0, 0, WORLD_R, 0, TAU);
    ctx.clip();
    ctx.fillStyle = hexPattern;
    ctx.fillRect(vx0, vy0, vx1 - vx0, vy1 - vy0);
    ctx.restore();

    // Danger zone outside + border
    ctx.beginPath();
    ctx.rect(vx0 - 10, vy0 - 10, vx1 - vx0 + 20, vy1 - vy0 + 20);
    ctx.arc(0, 0, WORLD_R, 0, TAU);
    ctx.fillStyle = 'rgba(110,10,25,0.35)';
    ctx.fill('evenodd');
    ctx.beginPath();
    ctx.arc(0, 0, WORLD_R, 0, TAU);
    ctx.strokeStyle = 'rgba(255,60,85,0.25)';
    ctx.lineWidth = 18;
    ctx.stroke();
    ctx.strokeStyle = '#ff3b55';
    ctx.lineWidth = 4;
    ctx.stroke();

    // Food
    ctx.globalCompositeOperation = 'lighter';
    const drawFood = (f, shrink) => {
      if (f.x < vx0 - 30 || f.x > vx1 + 30 || f.y < vy0 - 30 || f.y > vy1 + 30) return;
      const age = time - f.born;
      ctx.globalAlpha = age < 0.4 ? age / 0.4 : 1;
      const sz = f.r * 6 * (1 + 0.15 * Math.sin(time * 4 + f.phase)) * shrink;
      const fx = f.x + Math.cos(time * 1.7 + f.phase) * 2;
      const fy = f.y + Math.sin(time * 1.3 + f.phase) * 2;
      ctx.drawImage(f.sprite, fx - sz / 2, fy - sz / 2, sz, sz);
    };
    for (const f of foods.values()) drawFood(f, 1);
    for (const f of eating) drawFood(f, f.eatT / 0.12);
    ctx.globalAlpha = 1;
    ctx.globalCompositeOperation = 'source-over';

    drawPickups(vx0, vy0, vx1, vy1);

    // Snakes (player on top)
    for (const s of snakes.values()) if (!s.isPlayer) drawSnake(s, vx0, vy0, vx1, vy1);
    if (me) drawSnake(me, vx0, vy0, vx1, vy1);

    // Bullets: glow, then a white streak
    ctx.globalCompositeOperation = 'lighter';
    for (const b of bullets) {
      if (b.x < vx0 - 30 || b.x > vx1 + 30 || b.y < vy0 - 30 || b.y > vy1 + 30) continue;
      const g = 14 * b.size;
      ctx.drawImage(b.glow, b.x - g, b.y - g, g * 2, g * 2);
    }
    ctx.globalCompositeOperation = 'source-over';
    ctx.strokeStyle = '#fff';
    ctx.lineCap = 'round';
    for (const b of bullets) {
      if (b.x < vx0 - 30 || b.x > vx1 + 30 || b.y < vy0 - 30 || b.y > vy1 + 30) continue;
      ctx.lineWidth = BULLET_R * 1.2 * b.size;
      ctx.beginPath();
      ctx.moveTo(b.x - b.vx * b.tail, b.y - b.vy * b.tail);
      ctx.lineTo(b.x, b.y);
      ctx.stroke();
    }

    // Particles: skin chunks normally, sparks additively, blast rings as strokes
    for (const p of particles) {
      const t = p.life / p.max;
      if (p.ring) {
        ctx.globalCompositeOperation = 'source-over';
        ctx.globalAlpha = t;
        ctx.strokeStyle = '#ffd8a8';
        ctx.lineWidth = 6 * t + 1;
        ctx.beginPath();
        ctx.arc(p.x, p.y, p.size * (0.3 + 0.7 * (1 - t)), 0, TAU);
        ctx.stroke();
        continue;
      }
      if (p.x < vx0 - 20 || p.x > vx1 + 20 || p.y < vy0 - 20 || p.y > vy1 + 20) continue;
      const sz = p.size * (0.4 + 0.6 * t);
      ctx.globalAlpha = Math.min(1, t * 1.5);
      ctx.globalCompositeOperation = p.glow ? 'lighter' : 'source-over';
      ctx.drawImage(p.sprite, p.x - sz, p.y - sz, sz * 2, sz * 2);
    }
    ctx.globalAlpha = 1;
    ctx.globalCompositeOperation = 'source-over';

    // Names + health bars (other players' names in white, bots dimmer)
    ctx.font = `600 ${Math.round(13 / z)}px Poppins, system-ui, sans-serif`;
    ctx.textAlign = 'center';
    for (const s of snakes.values()) {
      const h = s.segs[0];
      if (!h || h.x < vx0 || h.x > vx1 || h.y < vy0 || h.y > vy1) continue;
      ctx.fillStyle = s.pid && !s.isPlayer ? 'rgba(255,255,255,0.95)' : 'rgba(255,255,255,0.7)';
      ctx.fillText(s.name, h.x, h.y - s.r - 10 / z);
      if (s.hp < s.maxHp) {
        const bw = 40 / z, bh = 5 / z, bx = h.x - bw / 2, by = h.y - s.r - 34 / z;
        const frac = Math.max(0, s.hp / s.maxHp);

        ctx.fillStyle = frac > 0.5 ? '#7cff6b' : frac > 0.25 ? '#ffd43b' : '#ff4d6d';
        ctx.fillRect(bx, by, bw * frac, bh);
      }
    }

    // Screen space
    ctx.setTransform(DPR, 0, 0, DPR, 0, 0);
    ctx.fillStyle = vignette;
    ctx.fillRect(0, 0, W, H);
    if (state === 'playing' && me) {
      drawMinimap();
      drawTray();
    }

      console.error(err);
    }
    requestAnimationFrame(frame);
```

```js
// Saves and leaderboard scores are written only here, from server-computed results.
function recordGame(sess, s) {
  const score = Math.floor(s.stats.score);
  const len = Math.floor(s.peakMass);
  const secs = Math.max(0, Math.floor(world.time - s.born));
  // The cached copy carries this session's earlier writes (which flush asynchronously); the stored
  // copy covers anything written elsewhere. Take the larger of each.
  const stored = safe(() => loadData(sess.id)) || {};
  const v = sess.save;
  for (const k of ['games', 'best', 'bestLen', 'kills', 'dots', 'time']) v[k] = Math.max(v[k] || 0, stored[k] || 0);
  const newBest = score > v.best;
  v.games += 1;
  v.best = Math.max(v.best, score);
  v.bestLen = Math.max(v.bestLen, len);
  v.kills += s.kills;
  v.dots += s.stats.dots;
  v.time += secs;
  safe(() => saveData(sess.id, v));
  safe(() => submitScore(sess.id, 'score', score, 'max'));
  safe(() => submitScore(sess.id, 'length', len, 'max'));
  if (s.kills > 0) safe(() => submitScore(sess.id, 'kills', s.kills, 'inc'));
  return { score, len, secs, newBest, best: v.best };

function bodyStr(s) {
  const segs = s.segs, n = segs.length, k = Math.max(1, Math.ceil(n / BODY_POINTS));
  const parts = [];
  for (let i = 0; i < n; i += k) parts.push(Math.round(segs[i].x) + ',' + Math.round(segs[i].y));
  if ((n - 1) % k) parts.push(Math.round(segs[n - 1].x) + ',' + Math.round(segs[n - 1].y));

}

// Damaged circles as "index:severity" with severity 0-9.
function hurtStr(s) {

  }

// Send this tick's tuples to everyone, split into messages under the payload cap.
function flush() {
  if (!out.length) return;
  let batch = [], len = 2;
  for (const t of out) {
    const n = JSON.stringify(t).length + 1;
    if (len + n > MSG_CHARS && batch.length) {
      emit('t', batch);
      batch = [];
      len = 2;
    }
    batch.push(t);
    len += n;
  }
  emit('t', batch);
  out = [];
}

// Every live orb, flattened as [id, x, y, value*10, color, ...] in chunks.
function sendSnapshot(id) {
  const chunks = [];
  let cur = [], len = 0;
  for (const f of world.foods) {
    if (f.eaten) continue;
    const item = [f.id, Math.round(f.x), Math.round(f.y), Math.round(f.value * 10), f.c];
    const n = item.join(',').length + 1;
    if (len + n > MSG_CHARS - 40 && cur.length) {
      chunks.push(cur);
      cur = [];
      len = 0;
    }
    for (const v of item) cur.push(v);
    len += n;
  }
  chunks.push(cur);
  chunks.forEach((f, i) => emitTo(id, 'fs', { i, n: chunks.length, f }));
  for (const s of world.snakes) bodyDirty.add(s);
}

function cleanName(n) {
  const name = String(n == null ? '' : n).replace(/[\u0000-\u001f\u007f<>]/g, '').trim().slice(0, 16);

function onInput(id, input) {
  const sess = sessions[id];
  if (!sess || !input || typeof input !== 'object') return;
  const a = Number(input.a);
  if (!Number.isFinite(a)) return;
  sess.q.push({ q: input.q | 0, a, b: !!input.b, f: !!input.f });
  if (sess.q.length > INPUT_QUEUE) sess.q.shift();
}

function onEvent(id, type, data) {
  ensureWorld();
  const sess = sessions[id];
  if (!sess) return;
  if (type === 'hello') {
    if (world.time - sess.snapAt < SNAPSHOT_COOLDOWN) return;
    sess.snapAt = world.time;
    sendSnapshot(id);
  } else if (type === 'spawn') {
    if (sess.snake || world.time - sess.deadAt < 0.8) return;
    const d = data && typeof data === 'object' ? data : {};
    sess.q.length = 0;
    sess.input = null;
    const s = world.spawnHuman(id, cleanName(d.n), clamp(d.s | 0, 0, SKINS.length - 1));
    s.ack = 0;
    sess.snake = s;
    state.entities.players[id].sn = s.id;
  }
}

function onTick(dt) {
  ensureWorld();
  if (dt > 1) dt /= 1000; // tolerate a millisecond tick
  dt = clamp(dt || 0.05, 0.001, 0.1);
  for (const id in sessions) {
    const sess = sessions[id], s = sess.snake;
    if (!s || !s.alive) continue;
    // One input per tick; if a client got ahead, skip to its newer inputs.
    if (sess.q.length > 2) sess.q.splice(0, sess.q.length - 2);
    const inp = sess.q.shift() || sess.input;
    if (!inp) continue;
    sess.input = inp;
    s.targetAngle = inp.a;
    s.wantBoost = inp.b;
    s.wantFire = inp.f;
    s.ack = inp.q;
  }
  world.step(dt, botTarget());
  syncSnakes();
  flush();
  state.shared.t = r2(world.time);
}
```

```js
        this.y = y;
        this.angle = angle;
        this.targetAngle = angle;
        this.wantBoost = false;
        this.boosting = false;
        this.alive = true;
        this.dropAcc = 0;
        this.kills = 0;
        this.born = time;
        this.mods = defaultMods();
        this.effects = { ghost: 0, frenzy: 0 }; // seconds remaining
        this.weapon = 'blaster';
        this.stacks = {}; // power-up id -> times collected
        this.upgrades = []; // permanent power-ups held, dropped on death
        this.stats = { score: 0, dots: 0, hits: 0 };
        this.health = this.mods.maxHealth;
        this.lastHit = -Infinity;
        this.wantFire = false;
        this.fireCd = 0;
        this.r = radius(mass);
        this.segs = [];
        // Remaining health of each body circle, parallel to segs; -1 = undamaged (always at the current max).
        // Damaged circles never regain health on their own, even as the max grows; only Medkit/Nanobots restore it.
        this.segLife = [];
        this.bodyHurt = false;
        this.trail = [];
        // AI
        this.thinkT = 0;
        this.aggro = Math.random();
        this.escapeDir = Math.random() < 0.5 ? -1 : 1;

        // Lay the initial body out in a straight line behind the head.
        const L = bodyLength(mass) + 20;
        for (let d = L; d > 0; d -= 6) {
          this.trail.push({ x: x - Math.cos(angle) * d, y: y - Math.sin(angle) * d });
        }
        this.trail.push({ x, y });
        this.updateBody();
      }

      update(dt) {
        const m = this.mods;
        this.r = radius(this.mass);
        this.boosting = this.wantBoost && this.mass > MIN_BOOST_MASS;
        steer(this, this.targetAngle, this.r, m.turn, moveSpeed(this.boosting, m.speed), dt);
        this.trail.push({ x: this.x, y: this.y });

        if (this.boosting) {
          const cost = BOOST_COST * m.boostCost * dt * (1 + this.mass / 800);
          this.mass -= cost;
          this.dropAcc += cost;
          if (this.dropAcc > 1.5) {
            const tail = this.segs[this.segs.length - 1];
            addFood(tail.x + rand(-4, 4), tail.y + rand(-4, 4), this.dropAcc * 0.8, colorIdx(SKINS[this.skin][0]), false);
            this.dropAcc = 0;
          }
        }
        if (this.mass > this.peakMass) this.peakMass = this.mass;
        this.updateBody();

        this.effects.ghost = Math.max(0, this.effects.ghost - dt);
        this.effects.frenzy = Math.max(0, this.effects.frenzy - dt);
        this.fireCd -= dt;
        if (this.wantFire && this.fireCd <= 0) this.shoot();
        if (time - this.lastHit > REGEN_DELAY) this.health = Math.min(m.maxHealth, this.health + REGEN_RATE * dt);
        if (m.repair > 0 && this.bodyHurt) this.repairBody(m.repair * dt);
        addScore(this, this.mass * SCORE_PER_LENGTH_SEC * dt);
      }

      // Nanobots: heal every damaged circle by `frac` of its max health.
      repairBody(frac) {
        const max = segHp(this), heal = max * frac, life = this.segLife;
        let hurt = false;
        for (let i = 0; i < life.length; i++) {
          if (life[i] < 0) continue;
          life[i] += heal;
          if (life[i] >= max) life[i] = -1;
          else hurt = true;
        }
        this.bodyHurt = hurt;
      }

      // Fire the current weapon from the center of the head along the current heading.
      shoot() {
        const w = WEAPONS[this.weapon], m = this.mods;
        const frenzy = this.effects.frenzy > 0;
        this.fireCd = fireInterval(this.mass) * w.interval * m.fireRate * (frenzy ? 0.33 : 1);
        if (this.mass >= FREE_FIRE_MASS && !frenzy) this.mass -= this.mass * SHOT_COST;
        const speed = BULLET_SPEED * w.speed * m.bulletSpeed + moveSpeed(this.boosting, m.speed);
        const ca = Math.cos(this.angle), sa = Math.sin(this.angle);
        for (let k = 0; k < w.pellets; k++) {
          let ang = this.angle, ox = 0, oy = 0;
          if (w.spread) ang += -w.spread + (2 * w.spread * k) / (w.pellets - 1) + rand(-0.04, 0.04);
          if (w.jitter) ang += rand(-w.jitter, w.jitter);
          if (w.parallel) {
            const off = (k === 0 ? -1 : 1) * this.r * 0.55;
            ox = -sa * off;
            oy = ca * off;
          }
          const b = {
            id: nextBulletId++,
            x: this.x + ox,
            y: this.y + oy,
            vx: Math.cos(ang) * speed,
            vy: Math.sin(ang) * speed,
            life: BULLET_LIFE * w.life,
            owner: this,
            weapon: this.weapon,
            damage: w.damage * m.damage,
            pierce: w.pierce || 0,
            explode: w.explode || 0,
            homing: w.homing || 0,
            size: w.size,
            hitSet: null,
            target: null,
            retarget: 0,
            dead: false,
          };
          bullets.push(b);
          H.bullet(b);
        }
      }

      updateBody() {
        const n = layoutBody(this.trail, this.segs, this.r, this.mass);
        const life = this.segLife;
        while (life.length < n) life.push(-1);
        life.length = n;
      }
    }

    // Scatter `total` mass as orbs along segments [from, to).
    function dropOrbs(s, from, to, total) {
      const len = to - from;
      const count = clamp(Math.round(total / 2), 1, Math.max(1, Math.min(len, 160)));
      const step = len / count;
      const value = total / count;
      const skin = SKINS[s.skin];
      for (let k = 0; k < count; k++) {
        const idx = from + Math.floor(k * step);
        const p = s.segs[idx];
        const color = colorIdx(skin[Math.floor(idx / 3) % skin.length]);
        addFood(p.x + rand(-s.r, s.r) * 0.6, p.y + rand(-s.r, s.r) * 0.6, value, color, false, true);
      }
    }

    // cause: 'shot' | 'chomp' | 'edge' | 'left' | 'retired'
    function killSnake(s, killer, cause) {
      if (!s.alive) return;
      s.alive = false;
      dropOrbs(s, 0, s.segs.length, s.mass * 0.75);
      dropPowerups(s);
      if (killer) {
        killer.kills++;
        addScore(killer, SCORE_KILL);
        if (killer.human && killer.alive) H.toast(killer, cause === 'shot' ? `You shot down ${s.name}!` : `You chomped ${s.name}!`);
      }
      H.death(s, killer, cause);
    }

    function hitFx(s, i, x, y, ang, spread, scale) {
      H.fx(['h', s.id, i, Math.round(x), Math.round(y), Math.round(ang * 100) / 100, spread, scale]);
    }

    // Sever everything from segment i back; the severed part becomes orbs.
    function chopSnake(s, i, shooter) {
      const segs = s.segs;
      const newMass = clamp(Math.pow((i * s.r * 0.5) / 35, 1 / 0.6), MIN_MASS, s.mass);
      const lost = s.mass - newMass;
      if (lost < 0.5) return;
      hitFx(s, i, segs[i].x, segs[i].y, 0, Math.PI, 3);
      dropOrbs(s, i, segs.length, lost * 0.75);
      s.mass = newMass;
      segs.length = i;
      s.segLife.length = i;
      s.trail = segs.map((p) => ({ x: p.x, y: p.y })).reverse();
      H.chop(s);
      if (shooter.human && shooter.alive && lost >= 15) H.toast(shooter, `You sliced ${s.name}!`);
    }

    // Shield soaks damage first; returns the damage that gets through.
    function absorb(s, amount) {
      if (s.mods.shield <= 0) return amount;
      const soaked = Math.min(s.mods.shield, amount);
      s.mods.shield -= soaked;
      return amount - soaked;
    }

    function registerHit(shooter) {
      shooter.stats.hits++;
      addScore(shooter, SCORE_HIT);
      if (shooter.mods.lifesteal > 0 && shooter.alive) {
        shooter.health = Math.min(shooter.mods.maxHealth, shooter.health + shooter.mods.lifesteal);
      }
    }

    function damageSnake(s, shooter, amount) {
      amount = absorb(s, amount);
      if (amount <= 0) return;
      s.health -= amount;
      s.lastHit = time;
      if (s.health <= 0) {
        const h = s.segs[0];
        hitFx(s, 0, h.x, h.y, 0, Math.PI, 4);
        killSnake(s, shooter, 'shot');
      }
    }

    // Apply damage to body circles, given as a flat list of [index, amount, ...]; slice at the first circle that breaks.
    function woundSegments(s, wounds, shooter) {
      const max = segHp(s), life = s.segLife;
      s.bodyHurt = true;
      let cut = -1;
      for (let k = 0; k < wounds.length; k += 2) {
        const j = wounds[k];
        if (j <= HEAD_SEGS || j >= life.length) continue;
        life[j] = (life[j] < 0 ? max : Math.min(life[j], max)) - wounds[k + 1];
        if (life[j] <= 0 && (cut < 0 || j < cut)) cut = j;
      }
      if (cut >= 0) chopSnake(s, cut, shooter);
    }

    // Damage the circle hit plus splash to its neighbours.
    function damageBody(s, i, shooter, amount) {
      const through = absorb(s, amount);
      if (through <= 0) return;
      const wounds = [], reach = BODY_SPLASH.length;
      for (let k = -reach; k <= reach; k++) wounds.push(i + k, through * (k === 0 ? 1 : BODY_SPLASH[Math.abs(k) - 1]));
      woundSegments(s, wounds, shooter);
    }

    // Rocket blast: damages every circle of every other snake within the radius.
    function explode(b) {
      const R = b.explode;
      H.fx(['x', Math.round(b.x), Math.round(b.y), R]);
      const hit = new Map();
      segGrid.forEach(b.x, b.y, R + MAX_SEG_R, (cell) => {
        for (let j = 0; j < cell.length; j += 2) {
          const o = cell[j];
          if (o === b.owner || !o.alive || o.effects.ghost > 0) continue;
          const i = cell[j + 1], p = o.segs[i];
          if (!p) continue;
          const dx = p.x - b.x, dy = p.y - b.y, rr = R + o.r;
          if (dx * dx + dy * dy < rr * rr) {
            let list = hit.get(o);
            if (!list) hit.set(o, (list = []));
            list.push(i);
          }
        }
      });
      for (const [o, idxs] of hit) {
        if (!o.alive) continue;
        registerHit(b.owner);
        if (idxs.some((i) => i <= HEAD_SEGS)) damageSnake(o, b.owner, HEADSHOT_DAMAGE * b.damage);
        if (!o.alive) continue;
        const through = absorb(o, BODY_DAMAGE * b.damage);
        if (through <= 0) continue;
        const wounds = [];
        for (const i of idxs) wounds.push(i, through);
        woundSegments(o, wounds, b.owner);
      }
    }

    // Returns true when the bullet is used up.
    function bulletHit(b) {
      let hitS = null, hitI = Infinity;
      const br = BULLET_R * b.size;
      segGrid.forEach(b.x, b.y, MAX_SEG_R + br, (cell) => {
        for (let j = 0; j < cell.length; j += 2) {
          const o = cell[j];
          if (o === b.owner || !o.alive || o.effects.ghost > 0 || (b.hitSet && b.hitSet.includes(o))) continue;
          const i = cell[j + 1];
          const p = o.segs[i];
          if (!p) continue;
          const dx = p.x - b.x, dy = p.y - b.y, rr = o.r + br;
          if (dx * dx + dy * dy < rr * rr && (!hitS || (o === hitS && i < hitI))) {
            hitS = o;
            hitI = i;
          }
        }
      });
      if (!hitS) return false;
      if (b.explode) {
        explode(b);
        return true;
      }
      const head = hitI <= HEAD_SEGS;
      hitFx(hitS, hitI, b.x, b.y, Math.atan2(-b.vy, -b.vx), 1.2, head ? 1.4 : 1);
      registerHit(b.owner);
      if (head) damageSnake(hitS, b.owner, HEADSHOT_DAMAGE * b.damage);
      else damageBody(hitS, hitI, b.owner, BODY_DAMAGE * b.damage);
      if (b.pierce > 0) {
        b.pierce--;
        (b.hitSet || (b.hitSet = [])).push(hitS);
        return false;
      }
      return true;
    }

    // Seeker bullets turn toward the nearest enemy head in front of them.
    function steerBullet(b, dt) {
      const sp = Math.hypot(b.vx, b.vy);
      b.retarget -= dt;
      if (b.retarget <= 0) {
        b.retarget = 0.15;
        b.target = null;
        let best = 650 * 650;
        const cx = b.vx / sp, cy = b.vy / sp;
        for (const o of snakes) {
          if (o === b.owner || !o.alive || o.effects.ghost > 0) continue;
          const h = o.segs[0], dx = h.x - b.x, dy = h.y - b.y, d2 = dx * dx + dy * dy;
          if (d2 < best && dx * cx + dy * cy > 0) { best = d2; b.target = o; }
        }
      }
      const t = b.target;
      if (!t || !t.alive) return;
      const h = t.segs[0];
      const cur = Math.atan2(b.vy, b.vx);
      const a = cur + clamp(angleDiff(cur, Math.atan2(h.y - b.y, h.x - b.x)), -b.homing * dt, b.homing * dt);
      b.vx = Math.cos(a) * sp;
      b.vy = Math.sin(a) * sp;
    }

    function updateBullets(dt) {
      for (const b of bullets) {
        b.life -= dt;
        if (b.homing) steerBullet(b, dt);
        const steps = Math.max(2, Math.ceil((Math.hypot(b.vx, b.vy) * dt) / 12));
        const h = dt / steps;
        for (let k = 0; k < steps && !b.dead; k++) {
          b.x += b.vx * h;
          b.y += b.vy * h;
          if (b.x * b.x + b.y * b.y > WORLD_R * WORLD_R) b.dead = true;
          else if (bulletHit(b)) {
            b.dead = true;
            H.bulletHit(b);
          }
        }
        if (b.life <= 0 && !b.dead) {
          b.dead = true;
          if (b.explode) explode(b);
        }
      }
      bullets = bullets.filter((b) => !b.dead);
    }

    function rebuildSegGrid() {
      segGrid.clear();
      for (const s of snakes) {
        if (!s.alive) continue;
        const segs = s.segs;
        for (let i = 0; i < segs.length; i++) segGrid.add2(segs[i].x, segs[i].y, s, i);
      }
    }

    // Find a point with no snake body within clearR (or the most open point tried), at least
    // awayDist from every player's head, facing roughly toward the center.
    function findSpawn(awayDist, clearR) {
      const heads = snakes.filter((s) => s.human && s.alive).map((s) => s.segs[0]);
      let best = null, bestClear = -1;
      for (let tries = 0; tries < 40; tries++) {
        const p = randomPoint(0.8);
        if (heads.some((h) => Math.hypot(p.x - h.x, p.y - h.y) < awayDist)) continue;
        let nearest2 = Infinity;
        segGrid.forEach(p.x, p.y, clearR, (cell) => {
          for (let j = 0; j < cell.length; j += 2) {
            const o = cell[j], q = o.segs[cell[j + 1]];
            if (!o.alive || !q) continue;
            const dx = q.x - p.x, dy = q.y - p.y;
            nearest2 = Math.min(nearest2, dx * dx + dy * dy);
          }
        });
        if (nearest2 >= clearR * clearR) { best = p; break; }
        if (nearest2 > bestClear) { best = p; bestClear = nearest2; }
      }
      best = best || randomPoint(0.8);
      best.angle = Math.atan2(-best.y, -best.x) + rand(-1, 1);
      return best;
    }

    function addSnake(opts) {
      const s = new Snake(opts);
      snakes.push(s);
      H.spawn(s);
      return s;
    }

    function spawnBot() {
      const used = new Set(snakes.map((s) => s.name));
      const free = BOT_NAMES.filter((n) => !used.has(n));
      const p = findSpawn(SPAWN_AWAY_FROM_PLAYERS, SPAWN_CLEAR_BOT);
      return addSnake({
        name: pick(free.length ? free : BOT_NAMES),
        skin: (Math.random() * SKINS.length) | 0,
        mass: START_MASS,
        x: p.x,
        y: p.y,
        angle: p.angle,
      });
    }

    function spawnHuman(pid, name, skin) {
      const p = findSpawn(0, SPAWN_CLEAR_PLAYER);
      const s = addSnake({ name, skin, mass: START_MASS, x: p.x, y: p.y, angle: p.angle, pid });
      rebuildSegGrid();
      return s;
    }

    // Retire the smallest bot no player can see, else the smallest bot.
    function retireBot() {
      const heads = snakes.filter((s) => s.human && s.alive).map((s) => s.segs[0]);
      let best = null, bestHidden = false;
      for (const s of snakes) {
        if (s.human || !s.alive) continue;
        const h = s.segs[0];
        const hidden = !heads.some((p) => Math.hypot(p.x - h.x, p.y - h.y) < BOT_RETIRE_DIST);
        if (!best || (hidden && !bestHidden) || (hidden === bestHidden && s.mass < best.mass)) {
          best = s;
          bestHidden = hidden;
        }
      }
      if (best) killSnake(best, null, 'retired');
    }

    // ---------- Bot AI ----------
    const PROBE_OFFSETS = [-0.5, 0.5, -1.0, 1.0, -1.6, 1.6, -2.3, 2.3];
    const isTarget = (b, o) => o !== b && o.alive && o.effects.ghost <= 0 && time - o.born >= HUNT_GRACE;

    function probeDanger(b, ang, look) {
      const h = b.segs[0], r = b.r;
      const ca = Math.cos(ang), sa = Math.sin(ang);
      const edge = (WORLD_R - r - 20) ** 2;
      const rad = r + 24;
      let danger = 0;
      for (let k = 1; k <= 3; k++) {
        const t = k / 3;
        const px = h.x + ca * look * t, py = h.y + sa * look * t;
        if (px * px + py * py > edge) danger += 3 / t;
        if (b.effects.ghost > 0) continue;
        segGrid.forEach(px, py, rad + MAX_SEG_R, (cell) => {
          for (let j = 0; j < cell.length; j += 2) {
            const o = cell[j];
            if (o === b || !o.alive || o.effects.ghost > 0) continue;
            const p = o.segs[cell[j + 1]];
            if (!p) continue;
            const dx = p.x - px, dy = p.y - py, rr = rad + o.r;
            if (dx * dx + dy * dy < rr * rr) {
              danger += 1 / t;
              return false;
            }
          }
        });
      }
      return danger;
    }

    // Fire when another snake is in the line of fire; trigger-happiness scales with aggro, less when shots cost mass.
    function botWantsFire(b) {
      const paid = b.mass >= FREE_FIRE_MASS && b.effects.frenzy <= 0;
      const chance = (paid ? 0.12 : 0.35) * (0.4 + b.aggro);
      if (Math.random() > chance) return false;
      const h = b.segs[0];
      const ca = Math.cos(b.angle), sa = Math.sin(b.angle);
      const range = bulletRange(b) * 0.8;
      for (const o of snakes) {
        if (!isTarget(b, o)) continue;
        const segs = o.segs;
        for (let i = 0; i < segs.length; i += 3) {
          const dx = segs[i].x - h.x, dy = segs[i].y - h.y;
          const t = dx * ca + dy * sa;
          if (t > 0 && t < range && Math.abs(dx * sa - dy * ca) < o.r) return true;
        }
      }
      return false;
    }

    function thinkBot(b, dt) {
      b.thinkT -= dt;
      if (b.thinkT > 0) return;
      b.thinkT = rand(0.07, 0.15);
      const h = b.segs[0], r = b.r;
      const look = 70 + r * 3.5;
      b.wantBoost = false;
      b.wantFire = botWantsFire(b);

      // 1. Avoid bodies and the border.
      const ahead = probeDanger(b, b.angle, look);
      if (ahead > 0) {
        let best = ahead, bestA = null;
        for (const off of PROBE_OFFSETS) {
          const a = b.angle + off;
          const d = probeDanger(b, a, look);
          if (d < best) { best = d; bestA = a; }
        }
        if (bestA === null) bestA = b.angle + 2.6 * b.escapeDir;
        else b.escapeDir = Math.sign(angleDiff(b.angle, bestA)) || 1;
        b.targetAngle = bestA;
        if (ahead >= 3 && b.mass > 30 && Math.random() < b.aggro * 0.5) b.wantBoost = true;
        b.thinkT = 0.04;
        return;
      }

      // 2. Drift back toward the middle when near the edge.
      if (Math.hypot(h.x, h.y) > WORLD_R - 400) {
        b.targetAngle = Math.atan2(-h.y, -h.x) + rand(-0.6, 0.6);
        return;
      }

      // 3. Grab nearby power-ups.
      let loot = null, lootD = 450;
      for (const pk of pickups) {
        if (pk.taken) continue;
        const d = Math.hypot(pk.x - h.x, pk.y - h.y);
        if (d < lootD) { lootD = d; loot = pk; }
      }
      if (loot && Math.random() < 0.85) {
        b.targetAngle = Math.atan2(loot.y - h.y, loot.x - h.x);
        b.wantBoost = lootD < 250 && b.mass > 40 && Math.random() < 0.3;
        return;
      }

      // 4. Fight any nearby snake (bots included): big aggressive bots cut them off, others shoot at their heads.
      if (Math.random() < b.aggro) {
        let prey = null, pd = Math.min(550, bulletRange(b) * 0.9);
        for (const o of snakes) {
          if (!isTarget(b, o)) continue;
          const oh = o.segs[0];
          const d = Math.hypot(oh.x - h.x, oh.y - h.y);
          if (d < pd) { pd = d; prey = o; }
        }
        if (prey) {
          const oh = prey.segs[0];
          const pc = Math.cos(prey.angle), ps = Math.sin(prey.angle);
          if (b.aggro > 0.6 && b.mass > 30 && prey.mass < b.mass * 1.3 && Math.random() < 0.5) {
            const lead = prey.r * 2 + 90 + pd * 0.3;
            b.targetAngle = Math.atan2(oh.y + ps * lead - h.y, oh.x + pc * lead - h.x);
            b.wantBoost = pd < 320 && b.mass > 45 && Math.random() < 0.7;
          } else {
            // Lead the target's head by bullet travel time.
            const w = WEAPONS[b.weapon];
            const bulletSpeed = BULLET_SPEED * w.speed * b.mods.bulletSpeed + BASE_SPEED;
            const lead = (pd / bulletSpeed) * moveSpeed(prey.boosting, prey.mods.speed);
            const aim = Math.atan2(oh.y + ps * lead - h.y, oh.x + pc * lead - h.x);
            b.targetAngle = aim;
            const paid = b.mass >= FREE_FIRE_MASS && b.effects.frenzy <= 0;
            if (Math.abs(angleDiff(b.angle, aim)) < 0.15 && (!paid || Math.random() < 0.4)) b.wantFire = true;
          }
          return;
        }
      }

      // 5. Go for the best food, preferring what's in front.
      const ca = Math.cos(b.angle), sa = Math.sin(b.angle);
      let bestF = null, bestScore = 0;
      foodGrid.forEach(h.x, h.y, 360, (cell) => {
        for (let j = 0; j < cell.length; j++) {
          const f = cell[j];
          if (f.eaten) continue;
          const dx = f.x - h.x, dy = f.y - h.y;
          const d = Math.sqrt(dx * dx + dy * dy) + 1;
          if (d > 360) continue;
          const facing = (dx * ca + dy * sa) / d;
          const score = (f.value * (1.4 + facing)) / (d + 30);
          if (score > bestScore) { bestScore = score; bestF = f; }
        }
      });
      if (bestF) {
        b.targetAngle = Math.atan2(bestF.y - h.y, bestF.x - h.x);
        return;
      }

      // 6. Wander.
      b.targetAngle = b.angle + rand(-0.8, 0.8);
    }

    // ---------- Simulation ----------
    // Anything inside magnet reach is eaten (clients animate the pull).
    function eatFood(s) {
      const h = s.segs[0], r = s.r;
      const reach = (r * 1.5 + 22) * s.mods.magnet;
      foodGrid.forEach(h.x, h.y, reach + 10, (cell) => {
        for (let j = 0; j < cell.length; j++) {
          const f = cell[j];
          if (f.eaten) continue;
          const dx = h.x - f.x, dy = h.y - f.y, rr = reach + f.r;
          if (dx * dx + dy * dy < rr * rr) {
            f.eaten = true;
            s.mass += f.value;
            s.stats.dots++;
            addScore(s, SCORE_DOT);
            if (f.natural) naturalFood--;
            H.foodEat(f, s);
          }
        }
      });
    }

    function checkCollisions() {
      const deaths = [];
      for (const s of snakes) {
        if (!s.alive) continue;
        const h = s.segs[0], r = s.r;
        if (h.x * h.x + h.y * h.y > (WORLD_R - r * 0.3) ** 2) {
          deaths.push([s, null]);
          continue;
        }
        if (s.effects.ghost > 0) continue;
        let killer = null;
        segGrid.forEach(h.x, h.y, r + MAX_SEG_R, (cell) => {
          for (let j = 0; j < cell.length; j += 2) {
            const o = cell[j];
            if (o === s || o.effects.ghost > 0) continue;
            const p = o.segs[cell[j + 1]];
            if (!p) continue;
            const dx = p.x - h.x, dy = p.y - h.y, rr = (r + o.r) * 0.72;
            if (dx * dx + dy * dy < rr * rr) {
              killer = o;
              return false;
            }
          }
        });
        if (killer) deaths.push([s, killer]);
      }
      for (const [s, killer] of deaths) if (s.alive) killSnake(s, killer, killer ? 'chomp' : 'edge');
    }

    // botTarget: how many bots the world should hold right now.
    function step(dt, botTarget) {
      time += dt;

      for (const s of snakes) if (!s.human && s.alive) thinkBot(s, dt);
      for (const s of snakes) if (s.alive) s.update(dt);

      rebuildSegGrid();
      // Orbs never move here, so the food grid is kept up to date by addFood and only rebuilt
      // now and then to drop eaten entries.
      foodGridT -= dt;
      if (foodGridT <= 0) {
        foodGridT = 2;
        foodGrid.clear();
        for (const f of foods) if (!f.eaten) foodGrid.add(f.x, f.y, f);
      }

      for (const s of snakes) {
        if (!s.alive) continue;
        eatFood(s);
        collectPickups(s);
      }
      checkCollisions();
      updateBullets(dt);

      let w = 0;
      for (let i = 0; i < foods.length; i++) if (!foods[i].eaten) foods[w++] = foods[i];
      foods.length = w;
      pickups = pickups.filter((pk) => {
        const keep = !pk.taken && (pk.natural || time - pk.born < PICKUP_DROP_LIFE);
        if (!keep) H.pickupGone(pk);
        return keep;
      });
      snakes = snakes.filter((s) => s.alive);

      for (let i = 0; i < 40 && naturalFood < FOOD_TARGET; i++) spawnNaturalFood();

      pickupSpawnT -= dt;
      if (pickupSpawnT <= 0) {
        pickupSpawnT = 0.5;
        if (pickups.filter((pk) => pk.natural).length < PICKUP_TARGET) spawnNaturalPickup();
      }

      const bots = snakes.filter((s) => !s.human).length;
      botRespawnT -= dt;
      if (botRespawnT <= 0 && bots < botTarget) {
        spawnBot();
        botRespawnT = 0.4;
      }
      botRetireT -= dt;
      if (botRetireT <= 0 && bots > botTarget) {
        retireBot();
        botRetireT = 1;
      }
    }

    function init(botTarget) {
      for (let i = 0; i < FOOD_TARGET; i++) spawnNaturalFood();
      for (let i = 0; i < PICKUP_TARGET; i++) spawnNaturalPickup();
      for (let i = 0; i < botTarget; i++) {
        spawnBot();
        rebuildSegGrid();
      }
    }

    return {
      get time() { return time; },
      get snakes() { return snakes; },
      get foods() { return foods; },
      get pickups() { return pickups; },
      segHp,
      init,
      step,
      spawnHuman,
      killSnake,
    };
  }

  return {
    WORLD_R, BOT_COUNT, BOTS_PER_HUMAN, MAX_SEG_R, BASE_SPEED, BOOST_SPEED, MIN_BOOST_MASS, START_MASS,
    BULLET_SPEED, BULLET_LIFE, BULLET_R, PICKUP_R, PICKUP_DROP_LIFE, MAX_SHIELD, HEAD_SEGS, TAU,
    SKINS, FOOD_COLORS, PALETTE, WEAPON_IDS,
    clamp, angleDiff, radius, bodyLength, turnRate, moveSpeed, steer, layoutBody, segMaxHp,
    createWorld,
  };
})();
```
