```md
## What is new in 2.1.2

SkyOP 2.1.2 fixes a Minecraft 26.3 SDL input crash caused by unbound module key mappings. Unbound mappings now use Minecraft's official InputConstants.UNKNOWN key value instead of passing an invalid raw -1 scancode. This release retains the 2.1.1 GUI, HUD, profile and inventory features.

- **Language:** English is the default. The in-client selector also includes Bahasa Indonesia, Español, Português, Français, 简体中文 and 日本語. Your choice is saved independently from Minecraft's global language.
- **Module browser:** search, category filtering, Favorites, two-column module cards and per-panel scrolling.
- **Input and HUD editor:** per-module keybind capture, independently draggable HUD panels, six quick color swatches, and a custom RGB hex field (#RRGGBB).
- **Inventory utilities:** Auto Eat, Auto Armor, Auto Tool, Auto Refill, Auto Fish and safe stack consolidation.
- **Profiles:** three JSON profile slots, JSON export/import through files in the config directory, timestamped backups and three hotbar layouts.
- **Extra HUDs:** potion effects, durability, compass/direction, ping, FPS, nearby client-loaded entities and custom text.

A successful automated build checks compilation, remapping, metadata, RGB codec unit tests and artifact packaging. It does not replace a real Minecraft launch and in-world test.

### Inventory and survival

| Module | Main behaviour |
|---|---|
| Auto Eat | Selects safe food from the hotbar below the configured hunger threshold |
| Auto Armor | Quick-moves armor into empty armor slots; it does not replace worn armor |
| Auto Tool | Selects the fastest tool available in the hotbar for the targeted block, then restores the previous slot |
| Auto Refill | Swaps a matching inventory stack into the selected hotbar slot when its count is low |
| Auto Fish | Reels when the client-visible fishing hook bite flag is set, then recasts |
| Inventory Cleaner | Consolidates matching item stacks; it does not drop or delete items |
| Hotbar Presets | Saves and loads three hotbar layouts using item identifiers |

Inventory changes use normal vanilla container actions. The server validates all inventory transactions. Auto Fish still depends on the server's fishing result and timing.

### Profiles and settings

Select **Profile Manager** under Inventory.

- Save or load slots 1–3.
- Export current settings to config/skyop-client/skyop-profile-export.json.
- To import, place a JSON profile at config/skyop-client/skyop-profile-import.json, then click **Import JSON**.
- **Backup Now** creates a timestamped copy of skyop-client.properties in config/skyop-client/backups/.
- Each profile is stored in config/skyop-client/profiles/.

Select **Hotbar Presets** under Inventory to save or load one of three layouts. A hotbar layout stores item identifiers, not item quantities, NBT contents, enchantments, or exact stack arrangements. Verify the hotbar after applying a layout.

The central settings schema declares numeric defaults and valid ranges. Settings loaded from disk are clamped to their documented limits.

## Compatibility and safety

- SkyOP is a **client-side mod**. It does not grant operator permissions and is not a server plugin.
- Movement and combat actions may be rejected, corrected or flagged by a multiplayer server. Respect the server's rules.
- The project does not claim to bypass anti-cheat systems or server authority.
- Use automated combat or movement only in single-player or a private server where you are allowed to do so.
- ESP and radar only work with entities already received/tracked by your client. They do not reveal unloaded or untracked entities.
- Auto Armor, Auto Refill, Inventory Cleaner and Hotbar Presets use normal vanilla container actions; the server can reject a transaction.
- The HUD ping value is only available when the client has player-list latency information.
- A successful CI build proves compilation and packaging, not that every module works in every world or on every server.
```

`build.ps1`:

```ps1
$ErrorActionPreference = 'Stop'
$GradleVersion = '9.7.1'
$ToolRoot = Join-Path $env:LOCALAPPDATA 'SkyOP-Builder'
$GradleHome = Join-Path $ToolRoot "gradle-$GradleVersion"
$GradleExe = Join-Path $GradleHome 'bin\gradle.bat'

Write-Host 'Checking Java runtime...' -ForegroundColor Cyan
$javaCommand = Get-Command java -ErrorAction SilentlyContinue
if (-not $javaCommand) {
    throw 'Java was not found in PATH. Install a JDK 25 (64-bit), then reopen this window.'
}
$versionLine = (& java -version 2>&1 | Select-Object -First 1).ToString()
if ($versionLine -notmatch '"?([0-9]+)') {
    throw "Could not read Java version: $versionLine"
}
$javaMajor = [int]$Matches[1]
if ($javaMajor -lt 25) {
    throw "Minecraft 26.3 mod development requires Java 25+. Detected Java $javaMajor. Install JDK 25 and set JAVA_HOME/PATH first."
}
Write-Host "Java $javaMajor detected." -ForegroundColor Green

if (-not (Test-Path $GradleExe)) {
    New-Item -ItemType Directory -Force -Path $ToolRoot | Out-Null
    $zipPath = Join-Path $ToolRoot "gradle-$GradleVersion-bin.zip"
    $url = "https://services.gradle.org/distributions/gradle-$GradleVersion-bin.zip"
    Write-Host "Downloading Gradle $GradleVersion..." -ForegroundColor Cyan
    Invoke-WebRequest -Uri $url -OutFile $zipPath
    Expand-Archive -LiteralPath $zipPath -DestinationPath $ToolRoot -Force
    Remove-Item $zipPath -Force
}

Write-Host 'Building SkyOP Client 1.1.0 for Minecraft 26.3...' -ForegroundColor Cyan
Push-Location $PSScriptRoot
try {
    & $GradleExe --no-daemon clean build
    if ($LASTEXITCODE -ne 0) {
        throw "Gradle build failed with exit code $LASTEXITCODE."
    }
} finally {
    Pop-Location
}

Write-Host ''
Write-Host 'BUILD SUCCESSFUL' -ForegroundColor Green
Write-Host "Mod JAR: $PSScriptRoot\build\libs\skyop-client-1.1.0.jar" -ForegroundColor Green
```

```java
package id.skyop.client;

import com.mojang.blaze3d.platform.InputConstants;
import net.minecraft.client.Minecraft;
import net.minecraft.client.KeyMapping;
import net.minecraft.client.input.MouseButtonEvent;
import net.minecraft.client.input.KeyEvent;

import net.minecraft.client.gui.screens.Screen;
import net.minecraft.network.chat.Component;

import java.util.ArrayList;
import java.util.List;

/**
 * Responsive, two-column SkyOP module manager for Minecraft 26.3.
 */
public final class SkyOPClickGui extends Screen {
    private static final int PANEL = 0xF0141B29;
    private static final int PANEL_LIGHT = 0xFF202B3D;
    private static final int PANEL_HOVER = 0xFF293A50;
    private static final int ACCENT = 0xFF61C7F2;
    private static final int TEXT = 0xFFF1F6FB;
    private static final int MUTED = 0xFF9AAABD;
    private static final int GREEN = 0xFF57D69A;
    private static final int RED = 0xFFFF7885;

    private SkyOPClient.Category selectedCategory = SkyOPClient.Category.COMBAT;
    private SkyOPClient.Module selectedModule = SkyOPClient.Module.KILL_AURA;
    private int panelX, panelY, panelWidth, panelHeight;
    private String searchQuery = "";
    private boolean searchFocused, waitingForKeybind, hudEditMode, draggingHud, colorPickerOpen, editingHudText;
    private boolean editingHudColor;
    private String hexColorInput = "";
    private SkyOPClient.Module draggingHudModule;
    private int moduleScroll, settingsScroll, hudDragOffsetX, hudDragOffsetY;
    private record HudPreview(SkyOPClient.Module module, int x, int y, int width, int height, String label) { }
    private long animationTicks;
    private String profileStatus = "";
    private int profileStatusTicks;

    private enum SettingKind { TOGGLE, SLIDER, INFO }
    private record Setting(String label, String detail, SettingKind kind,
                           double value, double min, double max, boolean enabled,
                           String displayValue) { }

    public SkyOPClickGui() {
        super(Component.literal("SkyOP Client"));
    }

    @Override
    protected void init() {
        calculateLayout();
        selectFirstModule();
    }

    private void calculateLayout() {
        panelWidth = Math.min(960, Math.max(680, width - 24));
        panelHeight = Math.min(590, Math.max(450, height - 20));
        panelX = (width - panelWidth) / 2;
        panelY = (height - panelHeight) / 2;
    }

    private void selectFirstModule() {
        for (SkyOPClient.Module module : SkyOPClient.Module.values()) {
            if (module.category() == selectedCategory) {
                selectedModule = module;
                return;
            }
        }
        selectedModule = null;
    }

    @Override
    public void extractRenderState(GuiGraphicsExtractor graphics, int mouseX, int mouseY, float delta) {
        super.extractRenderState(graphics, mouseX, mouseY, delta);
        calculateLayout();
        graphics.fill(0, 0, width, height, 0xB8000712);
        graphics.fill(panelX - 1, panelY - 1, panelX + panelWidth + 1, panelY + panelHeight + 1, 0xFF31445A);
        graphics.fill(panelX, panelY, panelX + panelWidth, panelY + panelHeight, PANEL);
        graphics.fill(panelX, panelY, panelX + panelWidth, panelY + 3, ACCENT);

    private void drawInspector(GuiGraphicsExtractor g, int mouseX, int mouseY) {
        int x = panelX + panelWidth - 263, y = panelY + 63, w = 248, h = panelHeight - 121;
        g.fill(x, y, x + w, y + h, 0xFF111A27);
        g.text(font, Component.literal(SkyOPLanguage.text("gui.inspector")), x + 12, y + 10, MUTED, true);
        if (selectedModule == null) {
            g.text(font, Component.literal(SkyOPLanguage.text("gui.select_module")), x + 12, y + 42, TEXT, true);
            return;
        }

        boolean enabled = SkyOPClient.isEnabled(selectedModule);
        g.text(font, Component.literal(selectedModule.title()), x + 12, y + 31, TEXT, true);
        g.text(font, Component.literal(enabled ? "● " + SkyOPLanguage.text("gui.enabled") : "○ " + SkyOPLanguage.text("gui.disabled")),

        g.fill(x + 12, y + 66, x + w - 12, y + 67, 0xFF2B394A);

        KeyMapping mapping = SkyOPClient.keybindFor(selectedModule);
        String keyName = waitingForKeybind ? "PRESS A KEY..." :
                (mapping == null ? "UNBOUND" : mapping.getTranslatedKeyMessage().getString());
        int keyY = y + 72;
        boolean keyHovered = inside(mouseX, mouseY, x + 8, keyY, w - 16, 24);
        g.fill(x + 8, keyY, x + w - 8, keyY + 23,
                keyHovered || waitingForKeybind ? 0xFF263D53 : PANEL_LIGHT);
        g.text(font, Component.literal("KEYBIND  " + trim(keyName, 20)),
                x + 15, keyY + 8, waitingForKeybind ? 0xFFFFC85A : ACCENT, true);

        if (selectedModule == SkyOPClient.Module.PROFILE_MANAGER) {
            drawProfileControls(g, mouseX, mouseY, x, y);
            return;
        }
        if (selectedModule == SkyOPClient.Module.HOTBAR_PRESETS) {
            drawHotbarControls(g, mouseX, mouseY, x, y);
            return;
        }
        if (selectedModule == SkyOPClient.Module.TEXT_GUI) {
            g.text(font, Component.literal(editingHudText ? "EDIT TEXT: " + SkyOPClient.customHudText + "|" : "CUSTOM HUD TEXT"),
                    x + 12, y + 125, editingHudText ? 0xFFFFC85A : TEXT, true);
            g.text(font, Component.literal("Click this line, then type. Enter to finish."),
                    x + 12, y + 145, MUTED, true);
            return;
        }

        List<Setting> settings = settingsFor(selectedModule);
        int rowY = y + 104 - settingsScroll * 42;
        int settingsBottom = y + h - 8;
        g.enableScissor(x + 8, y + 100, x + w - 8, settingsBottom);
        for (Setting setting : settings) {
            int rowH = 39;
            boolean hovered = inside(mouseX, mouseY, x + 8, rowY, w - 16, rowH);
            g.fill(x + 8, rowY, x + w - 8, rowY + rowH - 2,
                    hovered ? PANEL_HOVER : PANEL_LIGHT);
            g.text(font, Component.literal(trim(setting.label(), 21)),
                    x + 15, rowY + 5, TEXT, true);

            int valueColor = setting.kind() == SettingKind.TOGGLE
                    ? (setting.enabled() ? GREEN : RED) : ACCENT;
            g.text(font, Component.literal(setting.displayValue()),
                    x + w - 68, rowY + 5, valueColor, true);
            g.text(font, Component.literal(trim(setting.detail(), 31)),
                    x + 15, rowY + 19, MUTED, true);

            if (setting.kind() == SettingKind.SLIDER) {
                int trackX = x + 15, trackY = rowY + 32, trackW = w - 30;
                g.fill(trackX, trackY, trackX + trackW, trackY + 3, 0xFF36465A);
                double fraction = (setting.value() - setting.min()) / (setting.max() - setting.min());
                int fillW = (int) (trackW * Math.max(0.0, Math.min(1.0, fraction)));
                g.fill(trackX, trackY, trackX + fillW, trackY + 3, ACCENT);
            }
            rowY += 42;
        }
        g.disableScissor();

        if (settings.isEmpty()) {
            g.text(font, Component.literal(SkyOPLanguage.text("gui.no_extra_settings")), x + 12, y + 130, MUTED, true);
            g.text(font, Component.literal(selectedModule.description()), x + 12, y + 148, TEXT, true);
        }
        String missing = SkyOPModuleDependencies.missingRequirement(Minecraft.getInstance(), selectedModule);
        if (!missing.isEmpty()) {
            g.text(font, Component.literal(trim("REQUIRES: " + missing, 32)),
                    x + 12, y + h - 18, 0xFFFFC85A, true);
        }
    }

    private List<SkyOPClient.Module> modulesForCategory() {
        List<SkyOPClient.Module> modules = new ArrayList<>();
        String query = searchQuery.toLowerCase(java.util.Locale.ROOT);
        for (SkyOPClient.Module module : SkyOPClient.Module.values()) {
            boolean inCategory = selectedCategory == SkyOPClient.Category.FAVORITES
                    ? SkyOPClient.isFavorite(module) : module.category() == selectedCategory;
            boolean matches = query.isEmpty()
                    || module.title().toLowerCase(java.util.Locale.ROOT).contains(query)
                    || module.description().toLowerCase(java.util.Locale.ROOT).contains(query);
            if ((inCategory || !query.isEmpty()) && matches) modules.add(module);
        }
        return modules;
    }

    private int countModules(SkyOPClient.Category category) {
        int count = 0;
        for (SkyOPClient.Module module : SkyOPClient.Module.values()) {
            if (category == SkyOPClient.Category.FAVORITES ? SkyOPClient.isFavorite(module)
                    : module.category() == category) count++;
        }
        return count;
    }

    private static Setting toggle(String label, String detail, boolean value) {
        return new Setting(label, detail, SettingKind.TOGGLE, value ? 1 : 0,
                0, 1, value, value ? "ON" : "OFF");
    }

    private static Setting slider(String label, String detail, double value,
                                  double min, double max, String format) {
        return new Setting(label, detail, SettingKind.SLIDER, value, min, max,
                false, String.format(format, value));
    }

    private static Setting info(String label, String detail) {
        return new Setting(label, detail, SettingKind.INFO, 0, 0, 1, false, "INFO");
    }

    private void applySettingClick(int index, double mouseX) {
        List<Setting> settings = settingsFor(selectedModule);
        if (index < 0 || index >= settings.size()) return;
        Setting setting = settings.get(index);
        if (setting.kind() == SettingKind.SLIDER) {
            int sliderX = panelX + panelWidth - 248;
            int sliderWidth = 216;
            double fraction = Math.max(0.0, Math.min(1.0, (mouseX - sliderX) / sliderWidth));
            setSliderValue(selectedModule, index, setting.min() + fraction * (setting.max() - setting.min()));
        } else if (setting.kind() == SettingKind.TOGGLE) {
            toggleSetting(selectedModule, index);
        }
        SkyOPClient.saveConfig();
    }

    private void toggleSetting(SkyOPClient.Module module, int index) {
        switch (module) {
            case KILL_AURA -> {
                switch (index) {
                    case 0 -> SkyOPClient.targetPlayers = !SkyOPClient.targetPlayers;
                    case 1 -> SkyOPClient.targetMobs = !SkyOPClient.targetMobs;
                    case 2 -> SkyOPClient.auraRotate = !SkyOPClient.auraRotate;
                    case 3 -> SkyOPClient.auraRequireLineOfSight = !SkyOPClient.auraRequireLineOfSight;
                    case 5 -> SkyOPClient.auraTargetLowestHealth = !SkyOPClient.auraTargetLowestHealth;
                }
            }
            case TRIGGER_BOT -> {
                if (index == 0) SkyOPClient.targetPlayers = !SkyOPClient.targetPlayers;
                if (index == 1) SkyOPClient.targetMobs = !SkyOPClient.targetMobs;
            }
            case ENTITY_ESP -> {
                if (index == 0) SkyOPClient.espPlayers = !SkyOPClient.espPlayers;

    private void setSliderValue(SkyOPClient.Module module, int index, double value) {
        switch (module) {
            case KILL_AURA -> {
                if (index == 4) SkyOPClient.auraRange = round(value, 1);
                if (index == 6) SkyOPClient.auraFov = Math.round(value);
                if (index == 7) SkyOPClient.auraRotationSpeed = round(value, 2);
            }
            case TRIGGER_BOT -> {
                if (index == 2) SkyOPClient.triggerDelayTicks = SkyOPClient.clamp((int) Math.round(value), 1, 12);
            }
            case AUTO_CLICKER -> SkyOPClient.autoClickerCps = SkyOPClient.clamp((int) Math.round(value), 4, 20);
            case SPEED -> SkyOPClient.speedMultiplier = round(value, 2);
            case FLIGHT -> SkyOPClient.flightSpeed = round(value, 2);
            case AUTO_JUMP -> SkyOPClient.autoJumpDelayTicks = SkyOPClient.clamp((int) Math.round(value), 2, 12);
            case SPIDER -> SkyOPClient.spiderClimbSpeed = round(value, 2);
            case ENTITY_ESP -> {
                if (index == 2) SkyOPClient.espRange = Math.round(value);
            }
            case AUTO_EAT -> SkyOPClient.autoEatThreshold = SkyOPClient.clamp((int) Math.round(value), 2, 18);
            case AUTO_REFILL -> SkyOPClient.autoRefillThreshold = SkyOPClient.clamp((int) Math.round(value), 1, 16);
            default -> { }
        }
    }

    private static double round(double value, int decimals) {
        double scale = Math.pow(10, decimals);
        return Math.round(value * scale) / scale;
    }

    private HudPreview hudPreviewAt(int mouseX, int mouseY) {
        List<HudPreview> previews = buildHudPreviews();

            HudPreview preview = previews.get(index);
            if (inside(mouseX, mouseY, preview.x(), preview.y(), preview.width(), preview.height())) return preview;

    @Override

            }
            return true;
        }
        if (searchFocused && !waitingForKeybind && event.isAllowedChatCharacter() && searchQuery.length() < 32) {
            searchQuery += event.codepointAsString();
            moduleScroll = 0;
            return true;
        }
        return super.charTyped(event);
    }

    @Override
    public boolean keyPressed(KeyEvent event) {
        if (editingHudColor) {
            if (event.key() == InputConstants.KEY_ESCAPE) {
                editingHudColor = false;
                return true;
            }
            if (event.key() == InputConstants.KEY_RETURN) {
                applyHexColor();
                return true;
            }
            if (event.key() == InputConstants.KEY_BACKSPACE && !hexColorInput.isEmpty()) {
                hexColorInput = hexColorInput.substring(0, hexColorInput.length() - 1);
                return true;
            }
            return true;
        }
        if (waitingForKeybind && selectedModule != null) {
            if (event.key() == InputConstants.KEY_ESCAPE) {
                waitingForKeybind = false;
                return true;
            }
            SkyOPClient.setModuleKeybind(selectedModule, event.key());
            waitingForKeybind = false;
            setProfileStatus("Keybind updated");
            return true;
        }
        if (editingHudText) {
            if (event.key() == InputConstants.KEY_ESCAPE || event.key() == InputConstants.KEY_RETURN) {
                editingHudText = false;
                return true;
            }
            if (event.key() == InputConstants.KEY_BACKSPACE && !SkyOPClient.customHudText.isEmpty()) {
                SkyOPClient.setCustomHudText(SkyOPClient.customHudText.substring(0, SkyOPClient.customHudText.length() - 1));
                return true;
            }
        }
        if (searchFocused) {
            if (event.key() == InputConstants.KEY_ESCAPE || event.key() == InputConstants.KEY_RETURN) {
                searchFocused = false;
                return true;
            }
            if (event.key() == InputConstants.KEY_BACKSPACE && !searchQuery.isEmpty()) {
                searchQuery = searchQuery.substring(0, searchQuery.length() - 1);
                moduleScroll = 0;
                return true;
            }
            return true;
        }
        return super.keyPressed(event);
    }

    @Override
    public boolean mouseDragged(MouseButtonEvent event, double deltaX, double deltaY) {
        if (draggingHud && hudEditMode && draggingHudModule != null) {
            HudPreview preview = buildHudPreviews().stream()
                    .filter(value -> value.module() == draggingHudModule)
                    .findFirst().orElse(null);
            if (preview != null) {
                SkyOPClient.setHudPosition(draggingHudModule,
                        (int) event.x() - hudDragOffsetX, (int) event.y() - hudDragOffsetY,
                        width, height, preview.width(), preview.height());
            }
            return true;
        }
        return super.mouseDragged(event, deltaX, deltaY);
    }

    @Override
    public boolean mouseReleased(MouseButtonEvent event) {
        if (draggingHud) {
            draggingHud = false;
            draggingHudModule = null;
            SkyOPClient.saveConfig();
            return true;
        }
        return super.mouseReleased(event);
    }

    @Override
    public boolean mouseScrolled(double mouseX, double mouseY, double horizontalAmount, double verticalAmount) {
        int moduleX = panelX + 151, moduleY = panelY + 63, moduleW = panelWidth - 430;
        int inspectorX = panelX + panelWidth - 263, inspectorY = panelY + 63;
        if (inside((int) mouseX, (int) mouseY, moduleX, moduleY + 76, moduleW, panelHeight - 135)) {
            moduleScroll = Math.max(0, Math.min(1200, moduleScroll - (int) Math.signum(verticalAmount) * 60));
            return true;
        }
        if (inside((int) mouseX, (int) mouseY, inspectorX, inspectorY + 100, 248, panelHeight - 140)) {
            settingsScroll = Math.max(0, Math.min(20, settingsScroll - (int) Math.signum(verticalAmount)));
            return true;
        }
        return super.mouseScrolled(mouseX, mouseY, horizontalAmount, verticalAmount);
    }

    private boolean inside(int mx, int my, int x, int y, int w, int h) {
        return mx >= x && mx <= x + w && my >= y && my <= y + h;
    }

    private String trim(String text, int maxLength) {
        return text.length() <= maxLength ? text : text.substring(0, maxLength - 3) + "...";
    }

    @Override
    public boolean isPauseScreen() {
        return false;
    }

    public void onClose() {
        SkyOPClient.saveConfig();
        super.onClose();
    }
```

```java
        COMBAT("Combat"), MOVEMENT("Movement"), VISUAL("Visual"), PLAYER("Player"),
        INVENTORY("Inventory"), FAVORITES("Favorites");

        private final String fallbackTitle;
        Category(String title) { this.fallbackTitle = title; }
        public String title() {
            String key = "category." + name().toLowerCase();
            String translated = SkyOPLanguage.text(key);
            return translated.equals(key) ? fallbackTitle : translated;
        }
    }

    @Override
    public void onInitializeClient() {
        registerModuleKeybinds();
        loadConfig();
        HudElementRegistry.addLast(
                Identifier.fromNamespaceAndPath("skyop", "overlay"),
                (graphics, deltaTracker) -> renderHud(Minecraft.getInstance(), graphics)
        );
        ClientTickEvents.END_CLIENT_TICK.register(SkyOPClient::onClientTick);
    }

    public static boolean isEnabled(Module module) { return ENABLED.contains(module); }
    public static int enabledModuleCount() { return ENABLED.size(); }

    public static KeyMapping keybindFor(Module module) { return MODULE_KEYBINDS.get(module); }

    public static int hudXFor(Module module, int defaultX, int screenWidth, int elementWidth) {
        HudPosition saved = HUD_POSITIONS.get(module);
        int preferred = saved != null ? saved.x() : (module == Module.HUD ? hudX : defaultX);
        return clamp(preferred, 0, Math.max(0, screenWidth - elementWidth));
    }

    public static int hudYFor(Module module, int defaultY, int screenHeight, int elementHeight) {
        HudPosition saved = HUD_POSITIONS.get(module);
        int preferred = saved != null ? saved.y() : (module == Module.HUD ? hudY : defaultY);
        return clamp(preferred, 0, Math.max(0, screenHeight - elementHeight));
    }

    public static void setHudPosition(Module module, int x, int y,
                                      int screenWidth, int screenHeight,
                                      int elementWidth, int elementHeight) {
        if (module == null) return;
        int safeX = clamp(x, 0, Math.max(0, screenWidth - elementWidth));
        int safeY = clamp(y, 0, Math.max(0, screenHeight - elementHeight));
        HUD_POSITIONS.put(module, new HudPosition(safeX, safeY));
        if (module == Module.HUD) {
            hudX = safeX;
            hudY = safeY;
        }
    }

    public static void resetHudPositions() {
        HUD_POSITIONS.clear();
        hudX = 8;
        hudY = 8;
        saveConfig();
    }

    public static void toggleFavorite(Module module) {
        if (!FAVORITES.add(module)) FAVORITES.remove(module);
        saveConfig();
    }

    public static void setModuleKeybind(Module module, int scancode) {
        KeyMapping mapping = MODULE_KEYBINDS.get(module);
        if (mapping == null) return;
        int safeCode = Math.max(-1, scancode);
        MODULE_KEY_CODES.put(module, safeCode);
        mapping.setKey(safeCode < 0
                ? InputConstants.UNKNOWN
                : InputConstants.Type.KEYBOARD.getOrCreate(safeCode));
        KeyMapping.resetMapping();
        saveConfig();
    }

    public static void cycleHudColor() {
        int index = 0;
        for (int i = 0; i < HUD_PALETTE.length; i++) {
            if (HUD_PALETTE[i] == hudAccentColor) index = i;
        }
        hudAccentColor = HUD_PALETTE[(index + 1) % HUD_PALETTE.length];
        saveConfig();
    }

    public static void setHudAccentColor(int color) {
        hudAccentColor = 0xFF000000 | (color & 0x00FFFFFF);
        saveConfig();
    }

    public static void setCustomHudText(String text) {
        if (text == null) return;
        String safe = text.strip();
        if (safe.length() > 80) safe = safe.substring(0, 80);
        customHudText = safe;
        saveConfig();
    }

    public static void reloadConfigFromDisk() {
        ENABLED.clear();
        ENABLED.add(Module.HUD);
        FAVORITES.clear();
        loadConfig();
        if (!ENABLED.contains(Module.ENTITY_ESP)) restoreGlow();
        if (!ENABLED.contains(Module.GAMMA_BOOST)) restoreGamma(Minecraft.getInstance());
        if (!ENABLED.contains(Module.FLIGHT)) restoreFlight(Minecraft.getInstance());
    }

    private static void registerModuleKeybinds() {
        registerMapping(Module.HUD, KEY_HUD, InputConstants.KEY_F4);
        registerMapping(Module.AUTO_CLICKER, KEY_AUTO_CLICKER, InputConstants.KEY_F5);
        registerMapping(Module.AUTO_SPRINT, KEY_SPRINT, InputConstants.KEY_F6);
        registerMapping(Module.SPEED, KEY_SPEED, InputConstants.KEY_F7);
        registerMapping(Module.KILL_AURA, KEY_AURA, InputConstants.KEY_F8);
        registerMapping(Module.ENTITY_ESP, KEY_ESP, InputConstants.KEY_F9);
        registerMapping(Module.NO_FALL, KEY_NO_FALL, InputConstants.KEY_F10);
        registerMapping(Module.FLIGHT, KEY_FLIGHT, InputConstants.KEY_F11);

        for (Module module : Module.values()) {
            if (MODULE_KEYBINDS.containsKey(module)) continue;
            String keyName = "key.skyop.module." + module.name().toLowerCase();
            // Minecraft 26.3 uses SDL scancodes. Never pass raw -1 to the
            // native keyboard-state buffer for an unbound key mapping.
            KeyMapping mapping = KeyMappingHelper.registerKeyMapping(new KeyMapping(
                    keyName, InputConstants.Type.KEYBOARD, InputConstants.UNKNOWN.getValue(), KEY_CATEGORY
            ));
            MODULE_KEYBINDS.put(module, mapping);
            MODULE_KEY_CODES.put(module, -1);
        }
    }

    private static void registerMapping(Module module, KeyMapping mapping, int keyCode) {
        MODULE_KEYBINDS.put(module, mapping);
        MODULE_KEY_CODES.put(module, keyCode);
    }

    public static void setEnabled(Minecraft client, Module module, boolean enabled) {
        if (enabled && !SkyOPModuleDependencies.isAvailable(client, module)) {
            String missing = SkyOPModuleDependencies.missingRequirement(client, module);
            if (client != null && client.player != null) {
                client.player.sendSystemMessage(Component.literal("[SkyOP] " + missing));
            }
            return;
        }
        if (enabled) ENABLED.add(module); else ENABLED.remove(module);

        if (module == Module.ENTITY_ESP && !enabled) restoreGlow();
        if (module == Module.FLIGHT && !enabled) restoreFlight(client);
        if (module == Module.GAMMA_BOOST && !enabled) restoreGamma(client);

        saveConfig();
        notify(client, module.title(), enabled);
    }

    public static void toggle(Minecraft client, Module module) {
        setEnabled(client, module, !isEnabled(module));
    }

    public static void cycleLanguage() {
        SkyOPLanguage.next();
        saveConfig();
    }

    public static void applyPreset(Minecraft client, Preset preset) {
        ENABLED.clear();
        targetPlayers = false;
        targetMobs = true;
        auraTargetLowestHealth = false;

        switch (preset) {
            case PVE -> {
                ENABLED.addAll(EnumSet.of(Module.HUD, Module.KILL_AURA, Module.AUTO_SPRINT, Module.STEP_ASSIST));
                auraRange = 5.0;
                auraDelayTicks = 4;
                speedMultiplier = 1.4;
            }
            case OP -> {
                ENABLED.addAll(EnumSet.of(
                        Module.HUD, Module.KILL_AURA, Module.AUTO_CLICKER,
                        Module.AUTO_SPRINT, Module.SPEED, Module.FLIGHT,
                        Module.AUTO_JUMP, Module.STEP_ASSIST, Module.SPIDER,
                        Module.ENTITY_ESP, Module.TARGET_HUD, Module.ARMOR_HUD, Module.NO_FALL
                ));
                auraRange = 6.0;
                auraDelayTicks = 1;
                auraTargetLowestHealth = true;
                speedMultiplier = 2.8;
                flightSpeed = 0.72;
                spiderClimbSpeed = 0.32;
                espRange = 96.0;
            }
            case VISUAL -> {
                ENABLED.addAll(EnumSet.of(
                        Module.HUD, Module.ENTITY_ESP, Module.GAMMA_BOOST,
                        Module.TARGET_HUD, Module.KEYSTROKES_HUD, Module.ARMOR_HUD
                ));
            }
        }

        if (!isEnabled(Module.ENTITY_ESP)) restoreGlow();
        if (!isEnabled(Module.FLIGHT)) restoreFlight(client);
        if (!isEnabled(Module.GAMMA_BOOST)) restoreGamma(client);
        if (!isEnabled(Module.AUTO_FISH)) SkyOPInventoryManager.stop(client);
        saveConfig();
        if (client.player != null) {
            client.player.sendSystemMessage(Component.literal("[SkyOP] " + preset.name() + " profile loaded."));
        }
    }

    public static void disableAll(Minecraft client) {
        ENABLED.clear();
        auraCooldown = 0;
        triggerCooldown = 0;
        clickerCooldown = 0;
        autoJumpCooldown = 0;
        stepAssistCooldown = 0;
        restoreGlow();
        restoreGamma(client);
        restoreFlight(client);
        SkyOPInventoryManager.stop(client);
        saveConfig();
        if (client.player != null) {
            client.player.sendSystemMessage(Component.literal("[SkyOP] All modules disabled."));
        }
    }

    private static void onClientTick(Minecraft client) {
        handleKeybinds(client);
        if (client.player == null || client.level == null) {
            restoreGlow();
            restoreGamma(client);
            restoreFlight(client);
            return;
        }

        updateTelemetry(client);
        if (client.gui.screen() != null) return;

        if (isEnabled(Module.AUTO_SPRINT)) tickAutoSprint(client);
        if (isEnabled(Module.SPEED)) tickSpeed(client);
        if (isEnabled(Module.FLIGHT)) tickFlight(client);
        if (isEnabled(Module.AUTO_JUMP)) tickAutoJump(client); else autoJumpCooldown = 0;
        if (isEnabled(Module.STEP_ASSIST)) tickStepAssist(client); else stepAssistCooldown = 0;
        if (isEnabled(Module.SPIDER)) tickSpider(client);

        if (isEnabled(Module.NO_FALL) && client.player.fallDistance > 1.0F) {
            client.player.fallDistance = 0.0F;
        }
        if (isEnabled(Module.ENTITY_ESP)) tickEsp(client);
        if (isEnabled(Module.GAMMA_BOOST)) tickGamma(client);

        if (isEnabled(Module.KILL_AURA)) tickKillAura(client); else auraCooldown = 0;
        if (isEnabled(Module.TRIGGER_BOT)) tickTriggerBot(client); else triggerCooldown = 0;
        if (isEnabled(Module.AUTO_CLICKER)) tickAutoClicker(client); else clickerCooldown = 0;
        SkyOPInventoryManager.tick(client);
    }

    private static void handleKeybinds(Minecraft client) {
        if (KEY_GUI.consumeClick()) client.gui.setScreen(new SkyOPClickGui());
        if (KEY_DISABLE_ALL.consumeClick()) {
            disableAll(client);
            return;
        }
        for (Map.Entry<Module, KeyMapping> entry : MODULE_KEYBINDS.entrySet()) {
            while (entry.getValue().consumeClick()) toggle(client, entry.getKey());
        }
    }

    private static void tickAutoSprint(Minecraft client) {
        var player = client.player;
        if (client.options.keyUp.isDown() && !client.options.keyShift.isDown()
                && player.isAlive() && !player.isPassenger()) {
            player.setSprinting(true);
        }
    }

    private static void tickSpeed(Minecraft client) {
        var player = client.player;
        if (!player.isAlive() || player.isPassenger()) return;

        double forward = (client.options.keyUp.isDown() ? 1.0 : 0.0)
                - (client.options.keyDown.isDown() ? 1.0 : 0.0);
        double side = (client.options.keyRight.isDown() ? 1.0 : 0.0)
                - (client.options.keyLeft.isDown() ? 1.0 : 0.0);
        if (forward == 0.0 && side == 0.0) return;

        float yaw = player.getYRot() * ((float) Math.PI / 180.0F);
        double sin = Math.sin(yaw);
        double cos = Math.cos(yaw);
        double dx = side * cos - forward * sin;
        double dz = forward * cos + side * sin;
        double length = Math.sqrt(dx * dx + dz * dz);
        if (length < 1.0E-5) return;

        Vec3 current = player.getDeltaMovement();
        double boostedSpeed = 0.28 * clamp(speedMultiplier, 1.0, 2.8);
        player.setDeltaMovement(dx / length * boostedSpeed, current.y, dz / length * boostedSpeed);
    }

    private static void tickFlight(Minecraft client) {
        var player = client.player;
        if (originalNoGravity == null) {
            originalNoGravity = player.isNoGravity();
            flightPlayer = player;
        }
        player.setNoGravity(true);

        double vertical = 0.0;
        if (client.options.keyJump.isDown()) vertical += clamp(flightSpeed, 0.12, 0.9);
        if (client.options.keyShift.isDown()) vertical -= clamp(flightSpeed, 0.12, 0.9);
        Vec3 motion = player.getDeltaMovement();
        player.setDeltaMovement(motion.x, vertical, motion.z);
        player.fallDistance = 0.0F;
    }

    private static void tickAutoJump(Minecraft client) {
        if (autoJumpCooldown > 0) { autoJumpCooldown--; return; }
        var player = client.player;
        if (!client.options.keyUp.isDown() || client.options.keyShift.isDown()
                || !player.isAlive() || player.isPassenger() || !player.onGround()
                || player.isInWater() || player.isInLava()) return;
        player.jumpFromGround();
        autoJumpCooldown = clamp(autoJumpDelayTicks, 2, 12);
    }

    private static void tickStepAssist(Minecraft client) {
        if (stepAssistCooldown > 0) { stepAssistCooldown--; return; }
        var player = client.player;
        if (player.horizontalCollision && player.onGround()
                && client.options.keyUp.isDown() && !client.options.keyShift.isDown()
                && player.isAlive() && !player.isPassenger()) {
            player.jumpFromGround();
            stepAssistCooldown = 5;
        }
    }

    private static void tickSpider(Minecraft client) {
        var player = client.player;
        if (!player.horizontalCollision || !client.options.keyUp.isDown()
                || client.options.keyShift.isDown() || !player.isAlive() || player.isPassenger()) return;

        Vec3 motion = player.getDeltaMovement();
        double climb = clamp(spiderClimbSpeed, 0.08, 0.38);
        if (motion.y < climb) {
            player.setDeltaMovement(motion.x, climb, motion.z);
            player.fallDistance = 0.0F;
        }
    }

    private static void restoreFlight(Minecraft client) {
        Player target = flightPlayer != null ? flightPlayer : client.player;
        if (target != null && originalNoGravity != null) {
            target.setNoGravity(originalNoGravity);
        }
        originalNoGravity = null;
        flightPlayer = null;
    }

    private static void tickGamma(Minecraft client) {
        if (originalGamma == null) originalGamma = client.options.gamma().get();
        client.options.gamma().set(1.0);
    }

    private static void restoreGamma(Minecraft client) {
        if (originalGamma != null) {
            client.options.gamma().set(originalGamma);
            originalGamma = null;
        }
    }

    private static void tickEsp(Minecraft client) {
        var player = client.player;
        AABB area = player.getBoundingBox().inflate(clamp(espRange, 8.0, 96.0));
        List<LivingEntity> entities = client.level.getEntitiesOfClass(
                LivingEntity.class, area,
                entity -> entity != player && entity.isAlive() && shouldEsp(entity)
        );

        Set<UUID> seen = new HashSet<>();
        for (LivingEntity entity : entities) {
            UUID id = entity.getUUID();
            seen.add(id);
            ORIGINAL_GLOW.putIfAbsent(id, new GlowState(entity, entity.isCurrentlyGlowing()));
            entity.setGlowingTag(true);
        }

        Iterator<Map.Entry<UUID, GlowState>> iterator = ORIGINAL_GLOW.entrySet().iterator();
        while (iterator.hasNext()) {
            Map.Entry<UUID, GlowState> entry = iterator.next();
            if (!seen.contains(entry.getKey())) {
                GlowState state = entry.getValue();
                state.entity().setGlowingTag(state.wasGlowing());
                iterator.remove();
            }
        }
    }

    private static boolean shouldEsp(LivingEntity entity) {
        return entity instanceof Player ? espPlayers : espMobs;
    }

    private static void restoreGlow() {
        for (GlowState state : ORIGINAL_GLOW.values()) {
            state.entity().setGlowingTag(state.wasGlowing());
        }
        ORIGINAL_GLOW.clear();
    }

    private static void tickKillAura(Minecraft client) {
        if (auraCooldown > 0) { auraCooldown--; return; }

        var player = client.player;
        double range = clamp(auraRange, 2.5, 6.0);
        List<LivingEntity> candidates = client.level.getEntitiesOfClass(
                LivingEntity.class, player.getBoundingBox().inflate(range),
                entity -> entity != player && entity.isAlive() && isCombatTarget(entity)
        );

        LivingEntity target = null;
        double bestDistance = range * range;
        float bestHealth = Float.MAX_VALUE;
        Vec3 look = player.getLookAngle();
        Vec3 eye = player.getEyePosition();

        for (LivingEntity candidate : candidates) {
            if (candidate.isInvisible()) continue;
            double distance = player.distanceToSqr(candidate);
            if (distance > range * range) continue;
            if (auraRequireLineOfSight && !player.hasLineOfSight(candidate)) continue;

            Vec3 direction = candidate.getBoundingBox().getCenter().subtract(eye).normalize();
            double halfFovRadians = Math.toRadians(clamp(auraFov, 30.0, 180.0) / 2.0);
            if (look.dot(direction) < Math.cos(halfFovRadians)) continue;

            if (auraTargetLowestHealth) {
                float health = candidate.getHealth();
                if (health < bestHealth || (health == bestHealth && distance < bestDistance)) {
                    bestHealth = health;
                    bestDistance = distance;
                    target = candidate;
                }
            } else if (distance < bestDistance) {
                bestDistance = distance;
                target = candidate;
            }
        }

        if (target == null) return;
        if (auraRotate) rotateToward(player, target);
        if (attack(client, target)) {
            auraCooldown = clamp(auraDelayTicks, 1, 20);
        }
    }

    private static void tickTriggerBot(Minecraft client) {
        if (triggerCooldown > 0) { triggerCooldown--; return; }
        if (!(client.hitResult instanceof EntityHitResult entityHit)) return;
        Entity entity = entityHit.getEntity();
        if (entity instanceof LivingEntity living && living != client.player
                && living.isAlive() && isCombatTarget(living)) {
            if (attack(client, living)) {
                triggerCooldown = clamp(triggerDelayTicks, 1, 12);
            }
        }
    }

    private static void tickAutoClicker(Minecraft client) {
        if (clickerCooldown > 0) { clickerCooldown--; return; }
        if (!client.options.keyAttack.isDown()) return;
        HitResult result = client.hitResult;
        if (result instanceof EntityHitResult entityHit
                && entityHit.getEntity() instanceof LivingEntity living
                && living != client.player && living.isAlive() && isCombatTarget(living)) {
            if (attack(client, living)) {
                clickerCooldown = Math.max(1, 20 / clamp(autoClickerCps, 4, 20));
            }
        }
    }

    private static boolean isCombatTarget(LivingEntity entity) {
        if (entity instanceof Player) return targetPlayers;
        return targetMobs && entity instanceof Monster;
    }

    private static void rotateToward(Player player, LivingEntity target) {
        Vec3 delta = target.getBoundingBox().getCenter().subtract(player.getEyePosition());
        double horizontal = Math.sqrt(delta.x * delta.x + delta.z * delta.z);
        float yawTarget = (float) (Mth.atan2(delta.z, delta.x) * (180.0 / Math.PI)) - 90.0F;
        float pitchTarget = (float) (-(Mth.atan2(delta.y, horizontal) * (180.0 / Math.PI)));
        float rotationStep = (float) clamp(auraRotationSpeed, 0.10, 1.0);
        float yaw = player.getYRot() + Mth.wrapDegrees(yawTarget - player.getYRot()) * rotationStep;
        float pitch = player.getXRot() + Mth.wrapDegrees(pitchTarget - player.getXRot()) * rotationStep;
        player.setYRot(yaw);
        player.setXRot(pitch);
        player.setYHeadRot(yaw);
    }

    private static boolean attack(Minecraft client, LivingEntity target) {
        if (client.player == null || client.gameMode == null
                || client.player.getAttackStrengthScale(0.0F) < ATTACK_STRENGTH_THRESHOLD) return false;
        client.gameMode.attack(client.player, target);
        client.player.swing(InteractionHand.MAIN_HAND, SwingAnimation.DEFAULT, true);
        attacksThisWindow++;
        return true;
    }

    private static void updateTelemetry(Minecraft client) {
        Player player = client.player;
        if (player == null) {
            previousPosition = null;
            currentSpeedBps = 0.0;
            return;
        }

        Vec3 position = player.position();
        if (previousPosition != null) {
            double dx = position.x - previousPosition.x;
            double dz = position.z - previousPosition.z;
            double speed = Math.sqrt(dx * dx + dz * dz) * 20.0;
            currentSpeedBps = speed <= 100.0 ? speed : 0.0;
        }
        previousPosition = position;

        cpsWindowTicks++;
        if (cpsWindowTicks >= 20) {
            currentCps = attacksThisWindow;
            attacksThisWindow = 0;
            cpsWindowTicks = 0;
        }
    }

    private static int getCurrentPing(Minecraft client) {
        try {
            if (client.getConnection() == null || client.player == null) return -1;
            var info = client.getConnection().getPlayerInfo(client.player.getUUID());

    private static String compassDirection(float yaw) {
        String[] directions = {"S", "SW", "W", "NW", "N", "NE", "E", "SE"};
        int index = Math.floorMod(Math.round(yaw / 45.0F), 8);
        return directions[index];

    private static boolean bool(Properties p, String key, boolean fallback) {
        String value = p.getProperty(key);
        return value == null ? fallback : Boolean.parseBoolean(value);

    private static int integer(Properties p, String key, int fallback, int min, int max) {
        try {
            return clamp(Integer.parseInt(p.getProperty(key, Integer.toString(fallback))), min, max);
        } catch (NumberFormatException exception) {
            return fallback;
        }
    }

    private static double number(Properties p, String key, double fallback, double min, double max) {
        try {
            return clamp(Double.parseDouble(p.getProperty(key, Double.toString(fallback))), min, max);
        } catch (NumberFormatException exception) {
            return fallback;
        }
    }

    public static int clamp(int value, int min, int max) {
        return Math.max(min, Math.min(max, value));
    }

    public static double clamp(double value, double min, double max) {
        return Math.max(min, Math.min(max, value));
```

```java
            return;
        }

        if (SkyOPClient.isEnabled(SkyOPClient.Module.AUTO_EAT)) tickAutoEat(client);
        else stopEating(client);

        if (client.gui.screen() != null || client.player.isSpectator()
                || client.player.containerMenu != client.player.inventoryMenu) return;

        if (SkyOPClient.isEnabled(SkyOPClient.Module.AUTO_ARMOR)) tickAutoArmor(client);
        else armorDelay = 0;

        if (SkyOPClient.isEnabled(SkyOPClient.Module.AUTO_TOOL)) tickAutoTool(client);
        else restoreAutoTool(client);

        if (SkyOPClient.isEnabled(SkyOPClient.Module.AUTO_REFILL)) tickAutoRefill(client);
        else refillDelay = 0;

        if (SkyOPClient.isEnabled(SkyOPClient.Module.INVENTORY_CLEANER)) tickInventoryCleaner(client);
        else cleanDelay = 0;

        if (SkyOPClient.isEnabled(SkyOPClient.Module.AUTO_FISH)) tickAutoFish(client);
        else fishDelay = 0;
    }

    public static void stop(Minecraft client) {
        stopEating(client);
        restoreAutoTool(client);
        armorDelay = 0;
        refillDelay = 0;
        cleanDelay = 0;
        fishDelay = 0;
    }

    private static void tickAutoEat(Minecraft client) {
        var player = client.player;
        if (eatRetry > 0) eatRetry--;
        if (eatDelay > 0) {
            eatDelay--;
            if (eating && player.isUsingItem()) holdUse(client);
            return;
        }

        int foodLevel = player.getFoodData().getFoodLevel();
        if (!eating) {
            if (foodLevel >= SkyOPClient.autoEatThreshold || player.isUsingItem()
                    || (client.options.keyUse.isDown() && !ownsUseKey) || eatRetry > 0) return;

            int slot = findFoodHotbar(player.getInventory(), 20 - foodLevel);
            if (slot < 0) {
                eatRetry = 20;
                return;
            }

            originalEatSlot = player.getInventory().getSelectedSlot();
            activeEatSlot = slot;
            player.getInventory().setSelectedSlot(slot);
            eating = true;
            eatDelay = 1;
            return;
        }

        if (player.getInventory().getSelectedSlot() != activeEatSlot) {
            stopEating(client);
            return;
        }

        ItemStack food = player.getMainHandItem();
        if (foodLevel >= 20 || !isSafeFood(food)) {
            stopEating(client);
            return;
        }

        if (player.isUsingItem()) {
            holdUse(client);
            return;
        }

        client.gameMode.useItem(player, InteractionHand.MAIN_HAND);
        if (player.isUsingItem()) holdUse(client);
        else eatDelay = 2;
    }

    private static int findFoodHotbar(net.minecraft.world.entity.player.Inventory inventory, int missing) {
        int bestFit = -1;
        int bestFitNutrition = -1;
        int weakestSlot = -1;
        int weakestNutrition = Integer.MAX_VALUE;

        for (int slot = 0; slot < net.minecraft.world.entity.player.Inventory.SELECTION_SIZE; slot++) {
            ItemStack stack = inventory.getItem(slot);
            if (!isSafeFood(stack)) continue;
            int nutrition = stack.get(DataComponents.FOOD).nutrition();
            if (nutrition <= missing && nutrition > bestFitNutrition) {
                bestFit = slot;
                bestFitNutrition = nutrition;
            }
            if (nutrition < weakestNutrition) {
                weakestNutrition = nutrition;
                weakestSlot = slot;
            }
        }
        return bestFit >= 0 ? bestFit : weakestSlot;
    }

    private static boolean isSafeFood(ItemStack stack) {
        if (stack == null || stack.isEmpty() || UNSAFE_FOOD.contains(stack.getItem())) return false;
        var food = stack.get(DataComponents.FOOD);
        return food != null && food.nutrition() > 0;
    }

    private static void holdUse(Minecraft client) {
        client.options.keyUse.setDown(true);
        ownsUseKey = true;
    }

    private static void releaseUse(Minecraft client) {
        if (!ownsUseKey) return;
        ownsUseKey = false;
        client.options.keyUse.setDown(false);
    }

    private static void stopEating(Minecraft client) {
        if (client.player != null) {
            releaseUse(client);
            if (eating && client.player.isUsingItem() && client.gameMode != null) {
                client.gameMode.releaseUsingItem(client.player);
            }
            if (eating && originalEatSlot >= 0
                    && client.player.getInventory().getSelectedSlot() == activeEatSlot) {
                client.player.getInventory().setSelectedSlot(originalEatSlot);
            }
        } else {
            ownsUseKey = false;
        }

        eating = false;
        originalEatSlot = -1;
        activeEatSlot = -1;
        eatDelay = 0;
    }

    private static void tickAutoArmor(Minecraft client) {
        if (armorDelay > 0) { armorDelay--; return; }
        var player = client.player;
        var inventory = player.getInventory();

        for (int slot = 9; slot < Math.min(36, inventory.getContainerSize()); slot++) {
            ItemStack stack = inventory.getItem(slot);
            if (stack.isEmpty()) continue;
            Equippable equippable = stack.get(DataComponents.EQUIPPABLE);
            if (equippable == null || !ARMOR_SLOTS.contains(equippable.slot())) continue;
            if (!player.getItemBySlot(equippable.slot()).isEmpty()) continue;

            client.gameMode.handleContainerInput(
                    player.inventoryMenu.containerId, slot, 0, ContainerInput.QUICK_MOVE, player
            );
            armorDelay = 8;
            return;
        }
    }

    private static void tickAutoTool(Minecraft client) {
        if (!client.options.keyAttack.isDown()
                || !(client.hitResult instanceof BlockHitResult blockHit)) {
            restoreAutoTool(client);
            return;
        }

        BlockState state = client.level.getBlockState(blockHit.getBlockPos());
        var inventory = client.player.getInventory();
        int selected = inventory.getSelectedSlot();
        float bestSpeed = inventory.getItem(selected).getDestroySpeed(state);
        int bestSlot = selected;

        for (int slot = 0; slot < net.minecraft.world.entity.player.Inventory.SELECTION_SIZE; slot++) {
            ItemStack stack = inventory.getItem(slot);
            if (stack.isEmpty()) continue;
            float speed = stack.getDestroySpeed(state);
            if (speed > bestSpeed) {
                bestSpeed = speed;
                bestSlot = slot;
            }
        }

        if (bestSlot != selected) {
            if (autoToolSlot < 0) previousToolSlot = selected;
            inventory.setSelectedSlot(bestSlot);
            autoToolSlot = bestSlot;
        }
    }

    private static void restoreAutoTool(Minecraft client) {
        if (client.player != null && autoToolSlot >= 0 && previousToolSlot >= 0
                && client.player.getInventory().getSelectedSlot() == autoToolSlot) {
            client.player.getInventory().setSelectedSlot(previousToolSlot);
        }
        autoToolSlot = -1;
        previousToolSlot = -1;
    }

    private static void tickAutoRefill(Minecraft client) {
        if (refillDelay > 0) { refillDelay--; return; }
        var player = client.player;
        var inventory = player.getInventory();
        int selected = inventory.getSelectedSlot();
        ItemStack current = inventory.getItem(selected);
        if (current.isEmpty() || current.getCount() > SkyOPClient.autoRefillThreshold) return;

        for (int slot = 9; slot < Math.min(36, inventory.getContainerSize()); slot++) {
            ItemStack candidate = inventory.getItem(slot);
            if (candidate.isEmpty() || !ItemStack.isSameItemSameComponents(candidate, current)) continue;
            client.gameMode.handleContainerInput(
                    player.inventoryMenu.containerId, slot, selected, ContainerInput.SWAP, player
            );
            refillDelay = 12;
            return;
        }
    }

    /**
     * Consolidates matching stacks into already-existing hotbar stacks. It never drops items.
     */
    private static void tickInventoryCleaner(Minecraft client) {
        if (cleanDelay > 0) { cleanDelay--; return; }
        var player = client.player;
        var inventory = player.getInventory();

        for (int slot = 9; slot < Math.min(36, inventory.getContainerSize()); slot++) {
            ItemStack source = inventory.getItem(slot);
            if (source.isEmpty() || source.getCount() >= source.getMaxStackSize()) continue;

            boolean hasRoom = false;
            for (int hotbar = 0; hotbar < net.minecraft.world.entity.player.Inventory.SELECTION_SIZE; hotbar++) {
                ItemStack target = inventory.getItem(hotbar);
                if (!target.isEmpty() && ItemStack.isSameItemSameComponents(source, target)
                        && target.getCount() < target.getMaxStackSize()) {
                    hasRoom = true;
                    break;
                }
            }

            if (hasRoom) {
                client.gameMode.handleContainerInput(
                        player.inventoryMenu.containerId, slot, 0, ContainerInput.QUICK_MOVE, player
                );
                cleanDelay = 30;
                return;
            }
        }
    }

    /**
     * Retrieves a bite only when the 26.3 fishing-hook accessor reports it. Then recasts after
     * a short delay. It uses the ordinary fishing-rod action and server-side catch calculation.
     */
    private static void tickAutoFish(Minecraft client) {
        if (fishDelay > 0) { fishDelay--; return; }
        var player = client.player;
        ItemStack rod = player.getMainHandItem();
        if (!rod.is(Items.FISHING_ROD)) return;

        var hook = player.fishing;
        if (hook == null || !hook.isAlive()) {
            client.gameMode.useItem(player, InteractionHand.MAIN_HAND);
            fishDelay = 20;
            return;
        }

        if (((SkyOPFishingHookAccessor) hook).skyop$isBiting()) {
            hook.retrieve(rod);
            fishDelay = 24;
        }
    }

    private static void resetWithoutPlayer() {
        ownsUseKey = false;
        eating = false;
        originalEatSlot = -1;
        activeEatSlot = -1;
        eatDelay = 0;
        eatRetry = 0;
        armorDelay = 0;
        refillDelay = 0;
        cleanDelay = 0;
        fishDelay = 0;
        autoToolSlot = -1;
        previousToolSlot = -1;
    }
}
```

```java
package id.skyop.client;

import net.minecraft.client.Minecraft;
import net.minecraft.world.item.Items;

/**
 * Declares runtime context requirements and safe auto-disable rules for modules.
 */
public final class SkyOPModuleDependencies {
    public enum Requirement { CLIENT, WORLD, PLAYER, INVENTORY, FISHING_ROD, BLOCK_TARGET }

    private SkyOPModuleDependencies() { }

    public static Requirement requirement(SkyOPClient.Module module) {
        return switch (module) {
            case AUTO_ARMOR, AUTO_TOOL, AUTO_REFILL, AUTO_EAT, INVENTORY_CLEANER, HOTBAR_PRESETS ->
                    Requirement.INVENTORY;
            case AUTO_FISH -> Requirement.FISHING_ROD;
            case AUTO_JUMP, STEP_ASSIST, SPIDER, SPEED, FLIGHT, NO_FALL, KILL_AURA,
                    TRIGGER_BOT, AUTO_CLICKER, ENTITY_ESP, GAMMA_BOOST -> Requirement.WORLD;
            default -> Requirement.CLIENT;
        };
    }

    public static boolean isAvailable(Minecraft client, SkyOPClient.Module module) {
        Requirement requirement = requirement(module);
        if (requirement == Requirement.CLIENT) return true;
        if (client == null || client.player == null || client.level == null) return false;
        if (requirement == Requirement.INVENTORY) {
            return client.player.containerMenu == client.player.inventoryMenu && !client.player.isSpectator();
        }
        if (requirement == Requirement.FISHING_ROD) {
            return client.player.getMainHandItem().is(Items.FISHING_ROD);
        }
        return true;
    }

    public static String missingRequirement(Minecraft client, SkyOPClient.Module module) {
        if (isAvailable(client, module)) return "";
        return switch (requirement(module)) {
            case CLIENT -> "";
            case WORLD -> "Join a world first.";
            case PLAYER -> "A player entity is required.";
            case INVENTORY -> "Open the normal player inventory context first.";
            case FISHING_ROD -> "Hold a fishing rod in your main hand.";
            case BLOCK_TARGET -> "Aim at a block first.";
        };
    }
}
```

```java
package id.skyop.client;

import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import com.google.gson.reflect.TypeToken;
import net.minecraft.client.Minecraft;
import net.minecraft.core.registries.BuiltInRegistries;
import net.minecraft.world.inventory.ContainerInput;

import java.io.IOException;
import java.lang.reflect.Type;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.StandardCopyOption;
import java.time.LocalDateTime;
import java.time.format.DateTimeFormatter;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Properties;

/**
 * Three JSON configuration slots, portable import/export, rotating backups and hotbar layouts.
 */
public final class SkyOPProfileManager {
    private static final Gson GSON = new GsonBuilder().setPrettyPrinting().create();
    private static final Type MAP_TYPE = new TypeToken<Map<String, String>>() { }.getType();
    private static final Path ROOT = net.fabricmc.loader.api.FabricLoader.getInstance()
            .getConfigDir().resolve("skyop-client");
    private static final Path PROFILE_DIR = ROOT.resolve("profiles");
    private static final Path BACKUP_DIR = ROOT.resolve("backups");
    private static final Path EXPORT_FILE = ROOT.resolve("skyop-profile-export.json");
    private static final Path IMPORT_FILE = ROOT.resolve("skyop-profile-import.json");

    private SkyOPProfileManager() { }

    public static Path exportPath() { return EXPORT_FILE; }
    public static Path importPath() { return IMPORT_FILE; }

    public static void saveSlot(int slot) throws IOException {
        checkSlot(slot);
        Files.createDirectories(PROFILE_DIR);
        backupCurrent();
        SkyOPClient.saveConfig();
        Properties p = loadCurrentProperties();
        Map<String, String> values = new HashMap<>();
        for (String name : p.stringPropertyNames()) values.put(name, p.getProperty(name));
        Files.writeString(slotPath(slot), GSON.toJson(values));
    }

    public static void loadSlot(int slot) throws IOException {
        checkSlot(slot);
        Map<String, String> values = readMap(slotPath(slot));
        apply(values);
    }

    public static void exportCurrent() throws IOException {
        Files.createDirectories(ROOT);
        SkyOPClient.saveConfig();
        Properties p = loadCurrentProperties();
        Map<String, String> values = new HashMap<>();
        for (String name : p.stringPropertyNames()) values.put(name, p.getProperty(name));
        Files.writeString(EXPORT_FILE, GSON.toJson(values));
    }

    public static void importProfile() throws IOException {
        Map<String, String> values = readMap(IMPORT_FILE);
        backupCurrent();
        apply(values);
    }

    public static void backupCurrent() throws IOException {
        if (!Files.exists(SkyOPClient.configPath())) {
            SkyOPClient.saveConfig();
        }
        Files.createDirectories(BACKUP_DIR);
        String stamp = LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyyMMdd-HHmmss"));
        Files.copy(SkyOPClient.configPath(), BACKUP_DIR.resolve("skyop-" + stamp + ".properties"),
                StandardCopyOption.REPLACE_EXISTING);
    }

    public static void saveHotbarPreset(int slot) throws IOException {
        checkSlot(slot);
        Minecraft client = Minecraft.getInstance();
        if (client.player == null) throw new IOException("Join a world before saving a hotbar preset.");

        List<String> items = new ArrayList<>();
        for (int i = 0; i < 9; i++) {
            items.add(BuiltInRegistries.ITEM.getKey(client.player.getInventory().getItem(i).getItem()).toString());
        }
        Files.createDirectories(PROFILE_DIR);
        Files.writeString(hotbarPath(slot), GSON.toJson(items));
    }

    public static void loadHotbarPreset(int slot) throws IOException {
        checkSlot(slot);
        Minecraft client = Minecraft.getInstance();
        if (client.player == null || client.gameMode == null
                || client.player.containerMenu != client.player.inventoryMenu) {
            throw new IOException("Open the player inventory context in a world to load a hotbar preset.");
        }

        List<String> desired = GSON.fromJson(Files.readString(hotbarPath(slot)),
                new TypeToken<List<String>>() { }.getType());
        if (desired == null || desired.size() != 9) throw new IOException("Invalid hotbar preset.");
        var inventory = client.player.getInventory();

        for (int hotbar = 0; hotbar < 9; hotbar++) {
            String itemId = desired.get(hotbar);
            if (itemId == null || "minecraft:air".equals(itemId)) continue;
            String currentId = BuiltInRegistries.ITEM.getKey(inventory.getItem(hotbar).getItem()).toString();
            if (currentId.equals(itemId)) continue;

            int found = -1;
            // Do not disturb earlier hotbar positions that already match their preset.
            for (int source = hotbar + 1; source < 9; source++) {
                if (BuiltInRegistries.ITEM.getKey(inventory.getItem(source).getItem()).toString().equals(itemId)) {
                    found = source;
                    break;
                }
            }
            if (found < 0) {
                for (int source = 9; source < Math.min(36, inventory.getContainerSize()); source++) {
                    if (BuiltInRegistries.ITEM.getKey(inventory.getItem(source).getItem()).toString().equals(itemId)) {
                        found = source;
                        break;
                    }
                }
            }
            if (found >= 0) {
                int menuSlot = found < 9 ? 36 + found : found;
                client.gameMode.handleContainerInput(
                        client.player.inventoryMenu.containerId, menuSlot, hotbar, ContainerInput.SWAP, client.player
                );
            }
        }
    }

    private static void apply(Map<String, String> values) throws IOException {
        Properties p = new Properties();
        p.putAll(values);
        Files.createDirectories(SkyOPClient.configPath().getParent());
        try (var writer = Files.newBufferedWriter(SkyOPClient.configPath())) {
            p.store(writer, "SkyOP Client profile");
        }
        SkyOPClient.reloadConfigFromDisk();
    }

    private static Properties loadCurrentProperties() throws IOException {
        Properties p = new Properties();
        if (Files.exists(SkyOPClient.configPath())) {
            try (var reader = Files.newBufferedReader(SkyOPClient.configPath())) {
                p.load(reader);
            }
        }
        return p;
    }

    private static Map<String, String> readMap(Path path) throws IOException {
        if (!Files.exists(path)) throw new IOException("Profile not found: " + path);
        Map<String, String> values = GSON.fromJson(Files.readString(path), MAP_TYPE);
        if (values == null || values.isEmpty()) throw new IOException("Profile is empty or invalid.");
        return values;
    }

    private static Path slotPath(int slot) { return PROFILE_DIR.resolve("profile-" + slot + ".json"); }
    private static Path hotbarPath(int slot) { return PROFILE_DIR.resolve("hotbar-" + slot + ".json"); }

    private static void checkSlot(int slot) {
        if (slot < 1 || slot > 3) throw new IllegalArgumentException("Profile slot must be 1, 2 or 3.");
    }
}
```

```java
package id.skyop.client;

import java.util.LinkedHashMap;
import java.util.Map;

/**
 * Central range schema for persisted numeric settings. Values are validated on load and before
 * they are applied by the GUI; unknown properties are ignored by the feature code.
 */
public final class SkyOPSettingsSchema {
    public record NumberRule(double defaultValue, double minimum, double maximum, boolean integer) {
        public double validate(double value) {
            if (!Double.isFinite(value)) return defaultValue;
            double clamped = Math.max(minimum, Math.min(maximum, value));
            return integer ? Math.rint(clamped) : clamped;
        }
    }

    private static final Map<String, NumberRule> NUMBERS = new LinkedHashMap<>();

    static {
        number("auraRange", 4.2, 2.5, 6.0, false);
        number("auraFov", 110, 30, 180, true);
        number("auraRotationSpeed", 0.42, 0.10, 1.0, false);
        number("auraDelayTicks", 8, 1, 20, true);
        number("triggerDelayTicks", 3, 1, 12, true);
        number("autoClickerCps", 12, 4, 20, true);
        number("speedMultiplier", 1.7, 1.0, 2.8, false);
        number("flightSpeed", 0.38, 0.12, 0.9, false);
        number("autoJumpDelayTicks", 4, 2, 12, true);
        number("spiderClimbSpeed", 0.22, 0.08, 0.38, false);
        number("espRange", 48, 8, 96, false);
        number("autoEatThreshold", 14, 2, 18, true);
        number("autoRefillThreshold", 2, 1, 16, true);
    }

    private SkyOPSettingsSchema() { }

    private static void number(String id, double value, double min, double max, boolean integer) {
        NUMBERS.put(id, new NumberRule(value, min, max, integer));
    }

    public static NumberRule rule(String id) { return NUMBERS.get(id); }

    public static double validate(String id, double value, double fallback) {
        NumberRule rule = NUMBERS.get(id);
        return rule == null ? fallback : rule.validate(value);
    }

    public static Map<String, NumberRule> numbers() { return Map.copyOf(NUMBERS); }
}
```

```java
package id.skyop.client;

/**
 * Parses and formats opaque RGB values used by the SkyOP HUD accent editor.
 */
public final class SkyOPColorCodec {
    private SkyOPColorCodec() { }

    /**
     * Parses #RRGGBB, RRGGBB, 0xRRGGBB, or shorthand RGB such as #ABC.
     *
     * @return opaque ARGB color
     * @throws IllegalArgumentException when the input is null or malformed
     */
    public static int parseRgb(String input) {
        if (input == null) {
            throw new IllegalArgumentException("Color is required");
        }

        String value = input.strip();
        if (value.startsWith("#")) {
            value = value.substring(1);
        } else if (value.startsWith("0x") || value.startsWith("0X")) {
            value = value.substring(2);
        }

        if (value.length() == 3) {
            value = "" + value.charAt(0) + value.charAt(0)
                    + value.charAt(1) + value.charAt(1)
                    + value.charAt(2) + value.charAt(2);
        }
        if (value.length() != 6) {
            throw new IllegalArgumentException("Use exactly 6 hexadecimal digits");
        }

        try {
            return 0xFF000000 | Integer.parseInt(value, 16);
        } catch (NumberFormatException exception) {
            throw new IllegalArgumentException("Color contains a non-hexadecimal character", exception);
        }
    }

    /** Formats an ARGB value as six uppercase RGB digits, without the alpha channel. */
    public static String formatRgb(int argb) {
        return String.format(java.util.Locale.ROOT, "%06X", argb & 0x00FFFFFF);
    }
}
```

```java
package id.skyop.client;

import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertThrows;

class SkyOPColorCodecTest {
    @Test
    void parsesSixDigitRgbWithOptionalPrefixes() {
        assertEquals(0xFF12ABEF, SkyOPColorCodec.parseRgb("#12aBeF"));
        assertEquals(0xFF12ABEF, SkyOPColorCodec.parseRgb("12aBeF"));
        assertEquals(0xFF12ABEF, SkyOPColorCodec.parseRgb("0x12aBeF"));
        assertEquals(0xFF12ABEF, SkyOPColorCodec.parseRgb("0X12aBeF"));
    }

    @Test
    void expandsThreeDigitShorthand() {
        assertEquals(0xFFAABBCC, SkyOPColorCodec.parseRgb("#abc"));
    }

    @Test
    void ignoresSurroundingWhitespace() {
        assertEquals(0xFF12ABEF, SkyOPColorCodec.parseRgb("  #12ABEF  "));
    }

    @Test
    void formatsOpaqueRgbWithoutAlpha() {
        assertEquals("12ABEF", SkyOPColorCodec.formatRgb(0x7F12ABEF));
    }

    @Test
    void rejectsMissingOrMalformedColors() {
        assertThrows(IllegalArgumentException.class, () -> SkyOPColorCodec.parseRgb(null));
        assertThrows(IllegalArgumentException.class, () -> SkyOPColorCodec.parseRgb(""));
        assertThrows(IllegalArgumentException.class, () -> SkyOPColorCodec.parseRgb("#12"));
        assertThrows(IllegalArgumentException.class, () -> SkyOPColorCodec.parseRgb("GG0000"));
    }
}
```
