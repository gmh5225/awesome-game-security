# GprzSS

Windows screenshare scanner for Minecraft: Python 3.10+ stdlib only, JSON API served on 127.0.0.1, single-page web UI.

## Status (Updated 2026-11-27)

Live at https://github.com/GprzSS/GprzSS (public, MIT). Pushes to `main` run the test job; a `v*` tag runs build.ps1 and attaches `dist/GprzSS.exe` to the release. v1.0.0 shipped 2026-11-27, v1.1.0 adds the JDK finder and self-elevation, v1.1.1 strips every comment from the tree.
Works: 12 modules (system, processes, memory, prefetch, amcache, bam, usn, browsers, files, services, accounts, mods), GUI, markdown and JSON export, 60 tests pass, `dist\GprzSS.exe` builds via PyInstaller.
`core/java.py` finds the game under any JDK (Zulu, Temurin, Oracle, Corretto, Liberica, Semeru, GraalVM) by command-line markers, window title, or a heap over 300 MB, and names the runtime the way Task Manager does; a dedicated server jar is labelled a server, not the client.
GprzSS self-elevates on every launch through `core/elevate.py`; `--no-elevate` skips it, which is what tests and CI use.
`tools/strip_comments.py` removed the comments: tokenize for Python (keeps shebangs, `noqa`, `type:`, `pragma`, `pylint:`), a block scanner for CSS/JS/HTML. Docstrings stayed, and the suite still passes.
Open: a protected process reports "unreadable" rather than clean. Nothing is code-signed, so SmartScreen warns on first run. Pushing a workflow file from here needs the `workflow` token scope: `gh auth refresh -h github.com -s workflow`.

## Run

`python gprzss.py` opens the UI at http://127.0.0.1:8765. `--scan` prints a markdown report to stdout, `--scan --json` the raw session. Run elevated for prefetch, amcache, BAM and USN; without admin those modules report skipped, not clean.

Tests: `python -m pytest -q`. Build: `powershell -ExecutionPolicy Bypass -File build.ps1`.

## Map

- `gprzss.py` — CLI entry and argument parsing
- `core/scan.py` — ScanSession, worker thread, report rendering
- `core/server.py` — HTTP server, `/api/` routes, static UI
- `core/winapi.py` — ctypes bindings: process snapshot, modules, window titles, exe product names, ReadProcessMemory, UAC relaunch
- `core/java.py` — which JVM is the game, which JDK hosts it
- `core/elevate.py` — the UAC handoff and its `--elevated` loop guard
- `core/finding.py`, `core/signatures.py`, `core/config.py`
- `modules/__init__.py` — MODULES list; a module is a dict with key, label, section, run
- `data/signatures.json` — cheat-client and injector signatures
- `ui/` — index.html, style.css, app.js

## Decisions

- Stdlib only. No pip deps at runtime, so the exe is one file and no environment can break it.
- Signatures live in JSON so new entries need no code change.
- A module returns findings, never raises: an unreadable artifact is an "info" finding with the reason, so a clean verdict is never a false clean.
- PyInstaller onefile with `--add-data ui;ui` and `--add-data data;data`; `dist/` and `build/` are gitignored, the exe ships as a release asset.

`README.md`:

```md
# GprzSS

A screenshare scanner for Minecraft servers. One click walks the machine, then
gives you a report you can read out loud on a call and paste into Discord.

![GprzSS overview](docs/screenshot-overview.png)

## What it checks

| Module | What it reads | Why it matters |
| --- | --- | --- |
| Running processes | Process list, image paths, command lines | A client left open under its own name |
| Java runtime finder | Every `java.exe` / `javaw.exe`, its JDK and its window title | Finds the game under Zulu, Temurin, Oracle, Corretto, anything, and names that runtime |
| JVM memory scan | The heap of the running game | Catches a client after its file is renamed or deleted |
| Prefetch history | `C:\Windows\Prefetch\*.pf` | Proves what ran, including files that no longer exist |
| Amcache | `Amcache.hve` | Executables that ran, with first-seen timestamps |
| Execution history | BAM registry keys | Kernel-recorded last run time per binary |
| Deleted executables | The NTFS change journal | A file deleted seconds after it ran |
| Browser artefacts | Chrome, Edge, Brave, Opera, Firefox history and downloads | How the client got onto the machine |
| Filesystem traces | Recycle bin, Temp, Downloads, `latest.log` | Where a dropped client is left sitting |
| Services and drivers | Service list, driver list | Telemetry services turned off to hide a cleanup |
| Accounts | Local users, Minecraft launcher profiles | Alt accounts and injected launch arguments |
| Minecraft install | `mods`, `versions` | A client jar sitting in the class path |

Each check returns findings with a severity: **detected**, **warning**, **clean**
or **info**. The report verdict is the worst one present.

## Requirements

- Windows 10 or 11
- Python 3.10 or newer (3.12 recommended)
- No third-party packages. Standard library only.

## Administrator, automatically

GprzSS asks Windows for elevation every time it starts, so there is no
right-click step to forget. If the UAC prompt is declined it still runs, and the
report says which checks were skipped instead of pretending they passed.
`--no-elevate` turns the prompt off, which is what CI and the tests use.

## Run it

```powershell
python gprzss.py
```

Then open http://127.0.0.1:8765 (it opens on its own). Press **Run Scan**.

It elevates itself, so the memory scan, Prefetch, Amcache and the change
journal are readable without you doing anything. If UAC is declined, those
modules report the reason rather than a clean result.

### Headless

```powershell
python gprzss.py --scan                 # markdown report to stdout
python gprzss.py --scan --json          # the same scan as JSON
```

### Build a single exe

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

That produces `dist\GprzSS.exe`. Right click, **Run as administrator**.

## Adding your own signatures

`data/signatures.json` is read at scan time, so a new entry is live on the next
scan with no code change.

```json
{
  "processes": [
    { "match": "yourclient", "name": "YourClient", "severity": "detected", "kind": "client", "note": "seen on your server" }
  ],
  "memory_strings": [
    { "match": "com.yourclient", "name": "YourClient", "severity": "detected" }
  ]
}
```

- `processes` is matched against process names, file names, prefetch names and
  Amcache paths. A substring match, case insensitive.
- `memory_strings` is matched against JVM memory as ASCII and UTF-16, and
  against browser history as whole tokens.
- Set `"loose": true` on a short needle that should match inside a longer word.

Keep needles specific. `flare` is safe because matching requires the needle to
start a token, so `cloudflare.com` does not trip it, but `client` would match
half the internet.

## Layout

```
gprzss.py            entry point, CLI and server
core/
  winapi.py          ctypes wrappers: process list, modules, window titles, ReadProcessMemory
  java.py            finds the game under any installed JDK
  elevate.py         the UAC handoff
  signatures.py      signature loading and matching
  scan.py            the scan session, its thread, its report
  server.py          local HTTP server and JSON API
modules/             one file per check, each exports run(ctx) -> list[Finding]
ui/                  the interface: index.html, style.css, app.js
data/signatures.json the signature database
tests/               unittest suite, no external dependencies
```

## Tests

```powershell
python -m unittest discover -s tests
```

## Limits worth knowing

- The memory scan reads up to 512 MB of the JVM heap by default, with a 90
  second deadline, whichever comes first. Both are options in the scan request.
- The game is found by its command line, its window title, or a heap over
  300 MB. A dedicated server jar is reported as a server, never as the client.
- A client that unpacks itself only while the game is closed leaves nothing in
  memory. That is what the disk checks are for.
- Prefetch can be disabled at the OS level, and the change journal can be
  deleted. Both are reported as `warning`, never as `clean`.

## Credit

The approach follows the tools the Minecraft screen-share community already
uses. In particular the JVM string scanning idea comes from
[@p1aegg/javaw](https://github.com/p1aegg/javaw), and the launcher-plus-scripts
shape from [@p1aegg/SSTool](https://github.com/p1aegg/SSTool) and
[@p1aegg/powershell](https://github.com/p1aegg/powershell). The checks and the
reports here are written from scratch.

Layout and colour language take cues from detect.ac and echo.ac, without
copying either.

from __future__ import annotations

import os
from dataclasses import dataclass, field
from pathlib import Path

APP_NAME = "GprzSS"

@dataclass
class ScanContext:
    """Everything a module needs, plus the knobs the UI can turn."""

    signatures: dict
    options: dict = field(default_factory=dict)
    progress: object = None
    cancel: object = None
    findings: list = field(default_factory=list)

    def emit(self, module_key: str, message: str, pct: float = -1.0) -> None:

            self.progress(module_key, message, pct)

    def stopped(self) -> bool:

    def get(self, key, default=None):

`core/elevate.py`:

```py
"""UAC elevation.

GprzSS is half a scanner without Administrator, so it asks Windows for elevation
on every launch instead of printing a reminder to the user. The relaunched copy
carries ELEVATED_FLAG, which stops a prompt loop if Windows hands back a token
that still does not read as admin.
"""
from __future__ import annotations

import os
import sys

ELEVATED_FLAG = "--elevated"
SKIP_FLAG = "--no-elevate"

ALREADY = "already"
RELAUNCHED = "relaunched"
DECLINED = "declined"
SKIPPED = "skipped"

def is_frozen() -> bool:
    """True when this is the PyInstaller exe rather than a python call."""
    return bool(getattr(sys, "frozen", False))

def relaunch_command(argv) -> list:
    """The exact command line that reruns this build elevated."""
    args = [part for part in argv if part not in (SKIP_FLAG, ELEVATED_FLAG)]
    if is_frozen():
        return [sys.executable] + args + [ELEVATED_FLAG]
    script = os.path.abspath(sys.argv[0])
    return [sys.executable, script] + args + [ELEVATED_FLAG]

def needs_elevation(admin: bool, argv) -> bool:
    """Whether this run should hand itself to a UAC prompt."""
    if admin:
        return False
    if SKIP_FLAG in argv or ELEVATED_FLAG in argv:
        return False
    return True

def ensure_admin(argv=None, admin=None, relaunch=None) -> str:
    """Ask for elevation when the process is not already elevated.

    Returns ALREADY, RELAUNCHED (the caller should exit, the elevated copy owns
    the run), DECLINED (UAC was refused, carry on and let the report say which
    checks were skipped) or SKIPPED (elevation was turned off on the command
    line, which is what CI and the tests do).
    """
    from core import winapi

    argv = list(sys.argv[1:] if argv is None else argv)
    elevated = winapi.is_admin() if admin is None else bool(admin)
    if elevated:
        return ALREADY
    if SKIP_FLAG in argv or ELEVATED_FLAG in argv:
        return SKIPPED
    start = winapi.relaunch_as_admin if relaunch is None else relaunch
    if start(relaunch_command(argv)):
        return RELAUNCHED
    return DECLINED

`core/finding.py`:

```py
"""The single record type every module emits."""
from __future__ import annotations

import time
from dataclasses import dataclass, field, asdict

CLEAN = "clean"
INFO = "info"
WARNING = "warning"
DETECTED = "detected"

SEVERITY_ORDER = {CLEAN: 0, INFO: 1, WARNING: 2, DETECTED: 3}

@dataclass
class Finding:
    """One thing the scanner saw.

    title is the headline a staff member reads in the list, detail is the path,
    command line or address that proves it, and severity drives the colour it
    renders in.
    """

    module: str
    title: str
    detail: str = ""
    severity: str = INFO
    category: str = "general"
    signature: str = ""
    evidence: dict = field(default_factory=dict)
    tags: list = field(default_factory=list)
    timestamp: float = field(default_factory=time.time)

    def to_dict(self) -> dict:
        return asdict(self)

    @property
    def rank(self) -> int:
        return SEVERITY_ORDER.get(self.severity, 1)

def sort_findings(findings: list) -> list:
    return sorted(findings, key=lambda f: (-f.rank, f.module, f.title.lower()))

`core/java.py`:

```py
r"""Which running process is Minecraft, and which Java runtime hosts it.

Task Manager groups the game under the runtime that runs it ("Zulu Platform x64
Architecture" with Minecraft underneath), and a scan has to work the same way:
find the game whatever JDK the player installed, name that JDK in the report,
and hand its pid to the memory module.

Signals, in order of trust:

1. the command line mentions the client, a mod loader or a known launcher
2. the process owns a window titled "Minecraft* 1.21.11 - Multiplayer"
3. a java process with a heap this big is the game even if the launcher hid both

A server jar is none of those. A path is not a command line, so "D:\minecraft
\servers\server.jar" must not read as the client.
"""
from __future__ import annotations

import json
import subprocess

from core import winapi

JAVA_NAMES = {"javaw.exe", "java.exe"}
GAME_EXE_NAMES = {"minecraft.windows.exe"}
LAUNCHER_NAMES = {"minecraftlauncher.exe", "minecraftlauncher2.exe"}

GAME_TOKENS = (
    "net.minecraft.client",
    "minecraft.client.main",
    "mojangtricks",
    "fabric-loader",
    "quilt-loader",
    "net.fabricmc",
    "net.minecraftforge",
    "cpw.mods",
    "optifine",
    "--gamedir",
    "lunarclient",
    "badlion",
    "labymod",
    "feather",
)

SERVER_TOKENS = ("--nogui", "server.jar", "-jar server")

TITLE_PREFIXES = ("minecraft", "lunar client", "badlion client", "feather", "labymod")

PROBABLE_GAME_BYTES = 300 * 1024 * 1024

RUNTIME_VENDORS = (
    ("zulu", "Zulu Platform"),
    ("azul", "Azul Zulu"),
    ("temurin", "Eclipse Temurin"),
    ("adoptium", "Eclipse Temurin"),
    ("adoptopenjdk", "AdoptOpenJDK"),
    ("corretto", "Amazon Corretto"),
    ("liberica", "BellSoft Liberica"),
    ("semeru", "IBM Semeru"),
    ("graalvm", "GraalVM"),
    ("microsoft", "Microsoft OpenJDK"),
    ("oracle", "Oracle Java"),
    ("openjdk", "OpenJDK"),
)

GENERIC_PRODUCTS = {
    "java(tm) platform se binary",
    "openjdk platform binary",
    "java",
    "javaw",
    "javaw.exe",
    "microsoft windows operating system",
}

CREATE_NO_WINDOW = 0x08000000

def is_java_process(name: str) -> bool:
    """True for the process names a Minecraft JVM can appear under."""
    low = (name or "").strip().lower()
    return low in JAVA_NAMES or low in GAME_EXE_NAMES

def is_launcher(name: str) -> bool:
    return (name or "").strip().lower() in LAUNCHER_NAMES

def looks_like_command(command: str) -> bool:
    low = (command or "").lower()
    return any(token in low for token in GAME_TOKENS)

def looks_like_title(title: str) -> bool:
    low = (title or "").strip().lower()
    return any(low.startswith(prefix) for prefix in TITLE_PREFIXES)

def looks_like_game(command: str = "", title: str = "") -> bool:
    """True when the command line or the window title says this is the client."""
    return looks_like_command(command) or looks_like_title(title)

def is_server(command: str) -> bool:
    """A dedicated server, which runs the game's jar but is not the game."""
    low = (command or "").lower()
    return any(token in low for token in SERVER_TOKENS)

def runtime_label(path: str = "", product: str = "") -> str:
    """Task-Manager-style name for the Java runtime running a process."""
    prod = (product or "").strip()
    if prod and prod.lower() not in GENERIC_PRODUCTS:
        return prod
    low = (path or "").lower()
    for needle, label in RUNTIME_VENDORS:
        if needle in low:
            return label
    return prod or "Java"

def classify(name: str, command: str = "", title: str = "", size: int = 0) -> tuple:
    """(is_game, why) for one process. why is empty when it is not the client."""
    low = (name or "").strip().lower()
    if low in GAME_EXE_NAMES:
        return True, "game executable"
    if low not in JAVA_NAMES:
        return False, ""
    if is_server(command):
        return False, ""
    if looks_like_command(command):
        return True, "command line"
    if looks_like_title(title):
        return True, "window title"
    if size >= PROBABLE_GAME_BYTES:
        return True, "heap size"
    return False, ""

def command_lines() -> dict:
    """pid -> command line for every java process, in one CIM query.

    One query for the whole list, because a screenshare has a clock on it and
    powershell takes a third of a second per spawn.
    """
    script = (
        "Get-CimInstance Win32_Process "
        "-Filter \"Name='java.exe' OR Name='javaw.exe'\" "
        "| Select-Object ProcessId,CommandLine | ConvertTo-Json -Compress"
    )
    try:
        filled = subprocess.run(
            ["powershell", "-NoProfile", "-NonInteractive", "-Command", script],
            capture_output=True,
            text=True,
            timeout=20,
            creationflags=CREATE_NO_WINDOW,
        ).stdout.strip()
    except Exception:
        return {}
    if not filled:
        return {}
    try:
        rows = json.loads(filled)
    except ValueError:
        return {}
    if isinstance(rows, dict):
        rows = [rows]
    out = {}
    for row in rows or []:
        try:
            out[int(row.get("ProcessId"))] = str(row.get("CommandLine") or "")
        except (TypeError, ValueError, AttributeError):
            continue
    return out

def command_line(pid: int) -> str:
    """Command line of one pid, for a module that already knows the pid."""
    return command_lines().get(int(pid), "")

def summarise(path: str = "", product: str = "") -> str:
    """Short label for a JVM in one line, safe to put in a report."""
    return runtime_label(path, product)

def discover(procs=None, titles=None, details=None) -> list:
    """Every java process on the machine, with its JDK and whether it is the client.

    procs, titles and details can be passed in, which is how the tests drive
    this on a machine with no Minecraft running.
    """
    procs = winapi.list_processes() if procs is None else procs
    titles = winapi.window_titles() if titles is None else titles
    candidates = [
        proc for proc in procs if is_java_process(proc.get("name")) or is_launcher(proc.get("name"))
    ]
    if not candidates:
        return []

    if details is None:
        commands = command_lines()
        details = {}
        for proc in candidates:
            pid = int(proc["pid"])
            handle = winapi.open_process(pid)
            path = winapi.process_path(handle) if handle else ""
            size = winapi.working_set_size(handle) if handle else 0
            if handle:
                winapi.close_handle(handle)
            details[pid] = {"path": path, "size": size, "command": commands.get(pid, "")}

    out = []
    for proc in candidates:
        pid = int(proc["pid"])
        info = details.get(pid) or {}
        name = proc.get("name") or ""
        path = info.get("path", "") or ""
        command = info.get("command", "") or ""
        size = int(info.get("size", 0) or 0)
        title = titles.get(pid, "") or ""
        is_game, why = classify(name, command, title, size)
        out.append(
            {
                "pid": pid,
                "ppid": int(proc.get("ppid", 0) or 0),
                "name": name,
                "path": path,
                "command": command,
                "title": title,
                "size": size,
                "runtime": runtime_label(path, winapi.product_name(path) if path else ""),
                "is_game": is_game,
                "why": why,
                "launcher": is_launcher(name),
                "server": is_server(command),
            }
        )
    return out

def games(procs=None, titles=None, details=None) -> list:
    """Only the processes that are the client, launchers excluded, biggest first.

    Biggest first because the memory module reads them in this order, and the
    real game is the one with the heap.
    """
    found = [
        proc
        for proc in discover(procs=procs, titles=titles, details=details)
        if proc["is_game"] and not proc["launcher"]
    ]
    return sorted(found, key=lambda proc: -proc["size"])

`core/scan.py`:

```py
"""One scan run: its thread, its progress, its findings and its report."""
from __future__ import annotations

import json
import platform
import threading
import time
import traceback
import uuid
from dataclasses import dataclass, field

import modules

STATE_IDLE = "idle"
STATE_RUNNING = "running"
STATE_DONE = "done"
STATE_FAILED = "failed"

@dataclass
class ScanSession:
    id: str
    started_at: float = field(default_factory=time.time)
    finished_at: float = 0.0
    state: str = STATE_IDLE
    current_module: str = ""
    current_label: str = ""
    message: str = ""
    progress: float = 0.0
    findings: list = field(default_factory=list)
    error: str = ""
    options: dict = field(default_factory=dict)
    _cancelled: bool = False
    _lock: object = field(default_factory=threading.Lock, repr=False)

    def cancel(self) -> None:
        self._cancelled = True

    def stopped(self) -> bool:
        return self._cancelled

    def on_progress(self, module_key: str, message: str, pct: float = -1.0) -> None:
        with self._lock:
            self.message = message
            if module_key != self.current_module:
                self.current_module = module_key
                keys = [m[0] for m in modules.MODULES]
                index = keys.index(module_key) if module_key in keys else 0
                total = len(keys) or 1
                self.current_label = next(
                    (m[1] for m in modules.MODULES if m[0] == module_key), module_key
                )
                base = (index / float(total)) * 100.0
                self.progress = min(99.0, base + (pct / 100.0) * (100.0 / total)) if pct >= 0 else base
            elif pct >= 0:
                keys = [m[0] for m in modules.MODULES]
                index = keys.index(module_key) if module_key in keys else 0
                total = len(keys) or 1
                base = (index / float(total)) * 100.0
                self.progress = min(99.0, base + (pct / 100.0) * (100.0 / total))

    def counts(self) -> dict:
        counts = {CLEAN: 0, "info": 0, WARNING: 0, DETECTED: 0}
        for finding in self.findings:
            counts[finding.severity] = counts.get(finding.severity, 0) + 1
        return counts

    def verdict(self) -> str:
        counts = self.counts()
        if counts.get(DETECTED, 0) > 0:
            return DETECTED
        if counts.get(WARNING, 0) > 0:
            return WARNING
        return CLEAN

    def to_dict(self, include_findings: bool = True) -> dict:
        counts = self.counts()
        payload = {
            "id": self.id,
            "state": self.state,
            "started_at": self.started_at,
            "finished_at": self.finished_at,
            "elapsed": round((self.finished_at or time.time()) - self.started_at, 1),
            "module": self.current_module,
            "moduleLabel": self.current_label,
            "message": self.message,
            "progress": round(self.progress, 1),
            "counts": counts,
            "verdict": self.verdict(),
            "error": self.error,
            "modules": [
                {"key": k, "label": label, "section": section}
                for k, label, section, _w in modules.MODULES
            ],
        }
        if include_findings:
            payload["findings"] = [f.to_dict() for f in self.findings]
        return payload

    def markdown(self) -> str:
        counts = self.counts()
        verdict = self.verdict().upper()
        lines = [
            "# " + APP_NAME + " scan report",
            "",
            "- Verdict: **" + verdict + "**",
            "- Machine: " + platform.node() + " (" + platform.platform() + ")",
            "- Started: " + time.strftime("%Y-%m-%d %H:%M:%S", time.localtime(self.started_at)),
            "- Finished: " + time.strftime("%Y-%m-%d %H:%M:%S", time.localtime(self.finished_at or time.time())),
            "- Detected: " + str(counts.get(DETECTED, 0))
            + "  Warnings: " + str(counts.get(WARNING, 0))
            + "  Clean: " + str(counts.get(CLEAN, 0)),
            "",
        ]
        sections = {}
        for finding in sort_findings(self.findings):
            sections.setdefault(finding.category, []).append(finding)
        order = ["suspicious", "file_activity", "system", "accounts", "tools", "overview", "general"]
        titles = {
            "suspicious": "Suspicious Entries",
            "file_activity": "File Activity",
            "system": "System",
            "accounts": "Accounts",
            "tools": "Minecraft",
            "overview": "Overview",
            "general": "Other",
        }
        for key in order:
            group = sections.get(key)
            if not group:
                continue
            lines.append("## " + titles.get(key, key.title()))
            lines.append("")
            for finding in group:
                badge = finding.severity.upper()
                lines.append("- **[" + badge + "]** " + finding.title)
                if finding.detail:
                    lines.append("  - " + finding.detail.replace("\n", " ")[:400])
                if finding.signature:
                    lines.append("  - signature: " + finding.signature)
            lines.append("")
        lines.append("---")
        lines.append("Generated by " + APP_NAME + " " + VERSION)
        return "\n".join(lines)

class ScanManager:
    """Keeps every scan session, one at a time."""

    def __init__(self) -> None:
        self.sessions: dict = {}
        self.current: ScanSession | None = None
        self._lock = threading.Lock()

    def start(self, options: dict | None = None) -> ScanSession:
        session = ScanSession(id="scan_" + uuid.uuid4().hex[:10], options=options or {})
        self.sessions[session.id] = session
        with self._lock:
            self.current = session
        thread = threading.Thread(target=self._run, args=(session,), daemon=True)
        thread.start()
        return session

    def _run(self, session: ScanSession) -> None:
        session.state = STATE_RUNNING
        try:
            sigs = signature_store.load()
            ctx = ScanContext(
                signatures=sigs,
                options=session.options,
                progress=session.on_progress,
                cancel=session.stopped,
            )
            session.findings = ctx.findings
            modules.run_all(ctx)
            session.state = STATE_DONE
            session.progress = 100.0
            session.message = "Scan complete"
        except Exception as exc:
            session.state = STATE_FAILED
            session.error = str(exc)
            session.message = "Scan failed"
            traceback.print_exc()
        finally:
            session.finished_at = time.time()

    def get(self, scan_id: str) -> ScanSession | None:
        return self.sessions.get(scan_id)

    def latest(self) -> ScanSession | None:
        return self.current

"""A local HTTP server that serves the UI and the scan API."""
from __future__ import annotations

import json
import mimetypes
import webbrowser
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from pathlib import Path
from urllib.parse import urlparse

from core import signatures as signature_store
from core.config import APP_NAME, UI_DIR, VERSION
from core.scan import ScanManager

def make_handler(manager: ScanManager):
    class Handler(BaseHTTPRequestHandler):
        server_version = APP_NAME + "/" + VERSION

        def log_message(self, fmt, *args):
            pass

        def _send(self, code: int, body: bytes, content_type: str, extra: dict | None = None):
            self.send_response(code)
            self.send_header("Content-Type", content_type)
            self.send_header("Content-Length", str(len(body)))
            self.send_header("Cache-Control", "no-store")
            for key, value in (extra or {}).items():
                self.send_header(key, value)
            self.end_headers()
            if self.command != "HEAD":
                self.wfile.write(body)

        def _json(self, payload, code: int = 200):
            self._send(code, json.dumps(payload).encode("utf-8"), "application/json; charset=utf-8")

        def _error(self, code: int, message: str):
            self._json({"error": message}, code)

        def do_GET(self):
            parsed = urlparse(self.path)
            path = parsed.path

            if path in ("/", "/index.html"):
                return self._serve_static(UI_DIR / "index.html")
            if path.startswith("/ui/"):
                return self._serve_static(UI_DIR / path[4:].replace("/", "\\"))
            if path == "/api/version":
                return self._json({"name": APP_NAME, "version": VERSION})
            if path == "/api/signatures":
                return self._json(signature_store.load())
            if path == "/api/latest":
                session = manager.latest()
                return self._json(session.to_dict() if session else {"state": "idle"})
            if path.startswith("/api/scan/"):
                scan_id = path[len("/api/scan/"):]
                session = manager.get(scan_id)
                if not session:
                    return self._error(404, "unknown scan")
                return self._json(session.to_dict())
            if path.startswith("/api/report/"):
                rest = path[len("/api/report/"):]
                scan_id, _, fmt = rest.partition(".")
                session = manager.get(scan_id)
                if not session:
                    return self._error(404, "unknown scan")
                if fmt == "md":
                    body = session.markdown().encode("utf-8")
                    return self._send(
                        200,
                        body,
                        "text/markdown; charset=utf-8",
                        {"Content-Disposition": 'attachment; filename="' + scan_id + '.md"'},
                    )
                return self._json(session.to_dict())
            return self._error(404, "not found")

        def do_POST(self):
            parsed = urlparse(self.path)
            length = int(self.headers.get("Content-Length") or 0)
            body = self.rfile.read(length) if length else b"{}"
            try:
                payload = json.loads(body or b"{}")
            except ValueError:
                payload = {}

            if parsed.path == "/api/scan":
                options = payload if isinstance(payload, dict) else {}
                session = manager.start(options)
                return self._json({"id": session.id, "state": session.state})
            if parsed.path == "/api/cancel":
                scan_id = payload.get("id", "")
                session = manager.get(scan_id)
                if not session:
                    return self._error(404, "unknown scan")
                session.cancel()
                return self._json({"cancelled": True})
            return self._error(404, "not found")

        def _serve_static(self, file_path: Path):
            try:
                resolved = Path(file_path).resolve()
                if UI_DIR.resolve() not in resolved.parents and resolved != (UI_DIR / "index.html").resolve():
                    return self._error(403, "forbidden")
                data = resolved.read_bytes()
            except (OSError, ValueError):
                return self._error(404, "not found")
            mime, _ = mimetypes.guess_type(str(resolved))
            return self._send(200, data, mime or "application/octet-stream")

    return Handler

def serve(port: int = 8765, open_browser: bool = True, host: str = "127.0.0.1"):
    manager = ScanManager()
    handler = make_handler(manager)
    server = ThreadingHTTPServer((host, port), handler)
    url = "http://" + host + ":" + str(port) + "/"
    print(APP_NAME + " " + VERSION + " listening on " + url)
    if open_browser:
        webbrowser.open(url)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        print("\nshutting down")
    finally:
        server.server_close()
    return manager

"""Load and match the signature database."""
from __future__ import annotations

import json
import re
from pathlib import Path

from .config import DATA_DIR, ScanContext

_CACHE: dict | None = None

def _empty() -> dict:
    return {
        "version": "0.0.0",
        "processes": [],
        "memory_strings": [],
        "mods": [],
        "services": [],
        "paths": [],
    }

def load(path: Path | None = None) -> dict:
    global _CACHE
    if _CACHE is not None and path is None:
        return _CACHE
    target = path or (DATA_DIR / "signatures.json")
    data = _empty()
    try:
        with open(target, "r", encoding="utf-8") as fh:
            loaded = json.load(fh)
        for key, value in loaded.items():
            if isinstance(value, (list, str)):
                data[key] = value
            else:
                data[key] = value
    except (OSError, ValueError):
        data["loadError"] = str(target)
    if path is None:
        _CACHE = data
    return data

def reload(path: Path | None = None) -> dict:
    global _CACHE
    _CACHE = None
    return load(path)

def _entries(sigs: dict, key: str) -> list:
    value = sigs.get(key)
    return value if isinstance(value, list) else []

def match_name(name: str, sigs: dict, key: str = "processes") -> dict | None:
    """First signature whose match string appears in the name, lowercased."""
    haystack = (name or "").lower()
    if not haystack:
        return None
    for entry in _entries(sigs, key):
        needle = str(entry.get("match", "")).lower()
        if needle and needle in haystack:
            return entry
    return None

def match_exact(name: str, sigs: dict, key: str) -> dict | None:
    wanted = (name or "").lower()
    for entry in _entries(sigs, key):
        if str(entry.get("match", "")).lower() == wanted:
            return entry
    return None

def match_web(text: str, sigs: dict, key: str = "processes") -> dict | None:
    """Match inside a URL, a log line or a page title.

    Free text has far more accidental collisions than a file name, so the
    needle has to stand as its own token: "flare" must not fire on
    "cloudflare". A signature can opt out with "loose": true.
    """
    haystack = (text or "").lower()
    if not haystack:
        return None
    for entry in _entries(sigs, key):
        needle = str(entry.get("match", "")).lower()
        if not needle:
            continue
        if entry.get("loose"):
            if needle in haystack:
                return entry
            continue
        pattern = r"(?<![a-z0-9])" + re.escape(needle)
        if re.search(pattern, haystack):
            return entry
    return None

def all_matches(name: str, sigs: dict, key: str = "processes") -> list:
    haystack = (name or "").lower()
    out = []
    for entry in _entries(sigs, key):
        needle = str(entry.get("match", "")).lower()
        if needle and needle in haystack:
            out.append(entry)
    return out

def memory_patterns(sigs: dict) -> list:
    """(bytes_pattern, signature entry) pairs for the memory scanner."""
    out = []
    for entry in _entries(sigs, "memory_strings"):
        needle = str(entry.get("match", ""))
        if not needle:
            continue
        out.append((needle.encode("utf-8", "ignore"), entry))
        out.append((needle.encode("utf-16-le", "ignore"), entry))
    return out

def service_signature(name: str, sigs: dict) -> dict | None:
    return match_exact(name, sigs, "services")

def path_signature(path: str, sigs: dict) -> dict | None:
    return match_name(path, sigs, "paths")

"""Thin ctypes wrapper over the Win32 calls GprzSS needs.

Everything here degrades to a safe empty result instead of raising, because a
screenshare tool has to keep running when one API is denied.
"""
from __future__ import annotations

import ctypes
from ctypes import wintypes

kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
advapi32 = ctypes.WinDLL("advapi32", use_last_error=True)
psapi = ctypes.WinDLL("psapi", use_last_error=True)

PROCESS_QUERY_INFORMATION = 0x0400
PROCESS_QUERY_LIMITED_INFORMATION = 0x1000
PROCESS_VM_READ = 0x0010
TH32CS_SNAPPROCESS = 0x00000002
TH32CS_SNAPMODULE = 0x00000008
TH32CS_SNAPMODULE32 = 0x00000010
MEM_COMMIT = 0x1000
PAGE_GUARD = 0x100
PAGE_READABLE = {0x02, 0x04, 0x08, 0x10, 0x20, 0x40, 0x80}
MAX_PATH = 260
TOKEN_ADJUST_PRIVILEGES = 0x0020
TOKEN_QUERY = 0x0008
SE_PRIVILEGE_ENABLED = 0x00000002

class PROCESSENTRY32W(ctypes.Structure):
    _fields_ = [
        ("dwSize", wintypes.DWORD),
        ("cntUsage", wintypes.DWORD),
        ("th32ProcessID", wintypes.DWORD),
        ("th32DefaultHeapID", ctypes.POINTER(ctypes.c_ulong)),
        ("th32ModuleID", wintypes.DWORD),
        ("cntThreads", wintypes.DWORD),
        ("th32ParentProcessID", wintypes.DWORD),
        ("pcPriClassBase", ctypes.c_long),
        ("dwFlags", wintypes.DWORD),
        ("szExeFile", wintypes.WCHAR * MAX_PATH),
    ]

class MODULEENTRY32W(ctypes.Structure):
    _fields_ = [
        ("dwSize", wintypes.DWORD),
        ("th32ModuleID", wintypes.DWORD),
        ("th32ProcessID", wintypes.DWORD),
        ("GlblcntUsage", wintypes.DWORD),
        ("ProccntUsage", wintypes.DWORD),
        ("modBaseAddr", ctypes.POINTER(ctypes.c_byte)),
        ("modBaseSize", wintypes.DWORD),
        ("hModule", wintypes.HMODULE),
        ("szModule", wintypes.WCHAR * 256),
        ("szExePath", wintypes.WCHAR * MAX_PATH),
    ]

class MEMORY_BASIC_INFORMATION(ctypes.Structure):
    _fields_ = [
        ("BaseAddress", ctypes.c_void_p),
        ("AllocationBase", ctypes.c_void_p),
        ("AllocationProtect", wintypes.DWORD),
        ("RegionSize", ctypes.c_size_t),
        ("State", wintypes.DWORD),
        ("Protect", wintypes.DWORD),
        ("Type", wintypes.DWORD),
    ]

def is_admin() -> bool:

        return bool(ctypes.windll.shell32.IsUserAnAdmin())
    except Exception:
        return False

def enable_debug_privilege() -> bool:
    """Grant SeDebugPrivilege to this process. Required to read javaw.exe."""
    try:
        h_token = wintypes.HANDLE()
        if not advapi32.OpenProcessToken(
            kernel32.GetCurrentProcess(),
            TOKEN_ADJUST_PRIVILEGES | TOKEN_QUERY,
            ctypes.byref(h_token),
        ):
            return False

        class LUID(ctypes.Structure):
            _fields_ = [("LowPart", wintypes.DWORD), ("HighPart", wintypes.LONG)]

        class LUID_AND_ATTRIBUTES(ctypes.Structure):
            _fields_ = [("Luid", LUID), ("Attributes", wintypes.DWORD)]

        class TOKEN_PRIVILEGES(ctypes.Structure):
            _fields_ = [
                ("PrivilegeCount", wintypes.DWORD),
                ("Privileges", LUID_AND_ATTRIBUTES * 1),
            ]

        luid = LUID()
        if not advapi32.LookupPrivilegeValueW(None, "SeDebugPrivilege", ctypes.byref(luid)):
            return False
        tp = TOKEN_PRIVILEGES()
        tp.PrivilegeCount = 1
        tp.Privileges[0].Luid = luid
        tp.Privileges[0].Attributes = SE_PRIVILEGE_ENABLED
        ctypes.set_last_error(0)
        advapi32.AdjustTokenPrivileges(h_token, False, ctypes.byref(tp), 0, None, None)
        err = ctypes.get_last_error()
        kernel32.CloseHandle(h_token)
        return err == 0
    except Exception:
        return False

def list_processes() -> list:
    """Snapshot of every process: pid, ppid, name, thread count."""
    out = []
    snap = kernel32.CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS, 0)
    if not snap or snap == -1:
        return out
    try:
        entry = PROCESSENTRY32W()
        entry.dwSize = ctypes.sizeof(PROCESSENTRY32W)
        if not kernel32.Process32FirstW(snap, ctypes.byref(entry)):
            return out
        while True:
            out.append(
                {
                    "pid": int(entry.th32ProcessID),
                    "ppid": int(entry.th32ParentProcessID),
                    "name": entry.szExeFile,
                    "threads": int(entry.cntThreads),
                }
            )
            if not kernel32.Process32NextW(snap, ctypes.byref(entry)):
                break
    finally:
        kernel32.CloseHandle(snap)
    return out

def open_process(pid: int):
    handle = kernel32.OpenProcess(PROCESS_QUERY_INFORMATION | PROCESS_VM_READ, False, pid)
    if not handle:
        handle = kernel32.OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION, False, pid)
    return int(handle) if handle else None

def close_handle(handle: int) -> None:
    try:
        kernel32.CloseHandle(handle)
    except Exception:
        pass

def process_path(handle: int) -> str:
    buf = ctypes.create_unicode_buffer(32768)
    size = wintypes.DWORD(len(buf))
    if kernel32.QueryFullProcessImageNameW(handle, 0, buf, ctypes.byref(size)):
        return buf.value
    return ""

def list_modules(pid: int) -> list:
    """Loaded modules of a process, with base address and image size."""
    out = []
    snap = kernel32.CreateToolhelp32Snapshot(TH32CS_SNAPMODULE | TH32CS_SNAPMODULE32, pid)
    if not snap or snap == -1:
        return out
    try:
        entry = MODULEENTRY32W()
        entry.dwSize = ctypes.sizeof(MODULEENTRY32W)
        if not kernel32.Module32FirstW(snap, ctypes.byref(entry)):
            return out
        while True:
            out.append(
                {
                    "name": entry.szModule,
                    "path": entry.szExePath,
                    "base": ctypes.cast(entry.modBaseAddr, ctypes.c_void_p).value or 0,
                    "size": int(entry.modBaseSize),
                }
            )
            if not kernel32.Module32NextW(snap, ctypes.byref(entry)):
                break
    finally:
        kernel32.CloseHandle(snap)
    return out

def iter_readable_regions(handle: int):
    """Yield (base, size) for committed, readable, non-guard regions."""
    mbi = MEMORY_BASIC_INFORMATION()
    address = 0
    limit = 0x7FFFFFFFFFFF
    while address < limit:
        written = kernel32.VirtualQueryEx(
            handle, ctypes.c_void_p(address), ctypes.byref(mbi), ctypes.sizeof(mbi)
        )
        if not written:
            break
        base = mbi.BaseAddress or 0
        size = int(mbi.RegionSize)
        if size <= 0:
            break
        if (
            mbi.State == MEM_COMMIT
            and (mbi.Protect & 0xFF) in PAGE_READABLE
            and not (mbi.Protect & PAGE_GUARD)
        ):
            yield base, size
        address = base + size

def read_memory(handle: int, address: int, size: int):
    buf = ctypes.create_string_buffer(size)
    read = ctypes.c_size_t(0)
    ok = kernel32.ReadProcessMemory(
        handle, ctypes.c_void_p(address), buf, size, ctypes.byref(read)
    )
    if not ok or read.value == 0:
        return None
    return buf.raw[: read.value]

def working_set_size(handle: int) -> int:
    class PROCESS_MEMORY_COUNTERS(ctypes.Structure):
        _fields_ = [
            ("cb", wintypes.DWORD),
            ("PageFaultCount", wintypes.DWORD),
            ("PeakWorkingSetSize", ctypes.c_size_t),
            ("WorkingSetSize", ctypes.c_size_t),
            ("QuotaPeakPagedPoolUsage", ctypes.c_size_t),
            ("QuotaPagedPoolUsage", ctypes.c_size_t),
            ("QuotaPeakNonPagedPoolUsage", ctypes.c_size_t),
            ("QuotaNonPagedPoolUsage", ctypes.c_size_t),
            ("PagefileUsage", ctypes.c_size_t),
            ("PeakPagefileUsage", ctypes.c_size_t),
        ]

    counters = PROCESS_MEMORY_COUNTERS()
    counters.cb = ctypes.sizeof(counters)
    psapi.GetProcessMemoryInfo(handle, ctypes.byref(counters), counters.cb)
    return int(counters.WorkingSetSize)

def module_for_address(modules: list, address: int) -> str:
    for mod in modules:
        base = mod["base"]
        if base and base <= address < base + mod["size"]:
            return mod["name"]
    return ""

version.GetFileVersionInfoW.restype = wintypes.BOOL
version.VerQueryValueW.argtypes = [
    wintypes.LPCVOID,
    wintypes.LPCWSTR,
    ctypes.POINTER(ctypes.c_void_p),
    ctypes.POINTER(wintypes.UINT),
]
version.VerQueryValueW.restype = wintypes.BOOL

def window_titles() -> dict:
    """pid -> title of its first visible top-level window."""
    out = {}
    try:

        def collect(hwnd, _param):
            try:
                if not user32.IsWindowVisible(hwnd):
                    return True
                length = user32.GetWindowTextLengthW(hwnd)
                if length <= 0:
                    return True
                buf = ctypes.create_unicode_buffer(length + 1)
                user32.GetWindowTextW(hwnd, buf, length + 1)
                title = buf.value.strip()
                if not title:
                    return True
                pid = wintypes.DWORD(0)
                user32.GetWindowThreadProcessId(hwnd, ctypes.byref(pid))
                if pid.value:
                    out.setdefault(int(pid.value), title)
            except Exception:
                pass
            return True

        user32.EnumWindows(ENUMPROC(collect), 0)
    except Exception:
        return out
    return out

def product_name(path: str) -> str:
    """The name an exe gives itself in its version resource.

    This is what Task Manager prints for a process group, so a Zulu runtime
    reads back as "Zulu Platform x64 Architecture" rather than "javaw.exe".
    """
    if not path:
        return ""
    try:
        size = version.GetFileVersionInfoSizeW(str(path), None)
        if not size:
            return ""
        buf = ctypes.create_string_buffer(size)
        if not version.GetFileVersionInfoW(str(path), 0, size, buf):
            return ""
        ptr = ctypes.c_void_p()
        length = wintypes.UINT()
        if not version.VerQueryValueW(
            buf, "\\VarFileInfo\\Translation", ctypes.byref(ptr), ctypes.byref(length)
        ):
            return ""
        pairs = []
        if ptr.value and length.value >= 4:
            words = ctypes.cast(ptr, ctypes.POINTER(wintypes.WORD))
            pairs = [(words[i * 2], words[i * 2 + 1]) for i in range(length.value // 4)]
        for lang, codepage in pairs or [(0x0409, 0x04B0)]:
            for field in ("ProductName", "FileDescription"):
                key = "\\StringFileInfo\\%04x%04x\\%s" % (lang, codepage, field)
                if not version.VerQueryValueW(buf, key, ctypes.byref(ptr), ctypes.byref(length)):
                    continue
                if not length.value or not ptr.value:
                    continue
                value = ctypes.wstring_at(ptr.value).strip()
                if value:
                    return value
    except Exception:
        return ""
    return ""

def quote_arg(value: str) -> str:
    """Quote one argument for a ShellExecute parameter list."""
    if not value or any(ch in value for ch in ' \t"'):
        return '"' + value.replace('"', '\\"') + '"'
    return value

def relaunch_as_admin(command: list) -> bool:
    """Run command through the UAC prompt. False when UAC was declined."""
    try:
        shell32 = ctypes.WinDLL("shell32", use_last_error=True)
        params = " ".join(quote_arg(part) for part in command[1:])
        result = shell32.ShellExecuteW(None, "runas", command[0], params, None, 1)
        return int(result) > 32
    except Exception:
        return False

#!/usr/bin/env python3
"""GprzSS: a screenshare scanner for Minecraft servers.

GprzSS asks Windows for Administrator on launch, because the memory scan and
half the registry checks need it:

    python gprzss.py

Then open the printed address. Use --no-open to keep the browser shut, --scan to
print a markdown report to stdout and exit, --no-elevate to skip the UAC prompt.
"""
from __future__ import annotations

import argparse
import sys
import time

def main(argv=None) -> int:
    parser = argparse.ArgumentParser(description="GprzSS screenshare scanner")
    parser.add_argument("--port", type=int, default=8765, help="port for the local UI (default 8765)")
    parser.add_argument("--no-open", action="store_true", help="do not open a browser window")
    parser.add_argument("--host", default="127.0.0.1", help="bind address (default 127.0.0.1)")
    parser.add_argument("--scan", action="store_true", help="run one scan, print the report, exit")
    parser.add_argument("--json", action="store_true", help="with --scan, print JSON instead of markdown")
    parser.add_argument("--no-elevate", action="store_true", help="never ask Windows for elevation")
    parser.add_argument("--elevated", action="store_true", help="internal: this copy is the elevated relaunch")
    args = parser.parse_args(argv)

    from core import elevate

    outcome = elevate.ensure_admin(argv)
    if outcome == elevate.RELAUNCHED:
        return 0
    if outcome == elevate.DECLINED:
        print(
            "Administrator was declined, so the memory scan and the registry checks will report as skipped.",
            file=sys.stderr,
        )

    if args.scan:
        from core.scan import ScanSession
        import modules
        from core import signatures
        from core.config import ScanContext

        session = ScanSession(id="cli")
        sigs = signatures.load()
        ctx = ScanContext(
            signatures=sigs,
            progress=lambda key, msg, pct=-1.0: print("[" + key + "] " + msg, file=sys.stderr),
            cancel=session.stopped,
        )
        started = time.time()
        modules.run_all(ctx)
        session.findings = ctx.findings
        session.finished_at = time.time()
        session.state = "done"
        if args.json:
            import json

            print(json.dumps(session.to_dict(), indent=2))
        else:
            print(session.markdown())
        print("\nscan took %.1fs" % (time.time() - started), file=sys.stderr)
        return 0

    from core.server import serve

    serve(port=args.port, open_browser=not args.no_open, host=args.host)
    return 0

if __name__ == "__main__":
    raise SystemExit(main())

    """Run every module in order, appending findings to ctx.findings."""
    for key, label, section, _weight in MODULES:
        if ctx.stopped():
            break
        ctx.emit(key, "starting " + label, -1)
        module = BY_KEY[key]
        try:
            produced = module.run(ctx) or []
        except Exception as exc:
            from core.finding import Finding, WARNING

            produced = [
                Finding(
                    module=key,
                    title=label + " could not complete",
                    detail=str(exc)[:300],
                    severity=WARNING,
                    category=section,
                )
            ]
        for finding in produced:
            finding.module = key
            if not finding.category or finding.category == "general":
                finding.category = section
        ctx.findings.extend(produced)

from __future__ import annotations

import json

from core.config import user_dirs
from core.finding import Finding, INFO, WARNING

def _local_users() -> list:
    try:
        out = subprocess.run(
            ["powershell", "-NoProfile", "-NonInteractive", "-Command",
             "Get-LocalUser | Select-Object Name,Enabled,LastLogon | ConvertTo-Json -Compress"],
            capture_output=True,
            text=True,
            timeout=25,
            creationflags=0x08000000,
        ).stdout.strip()
        data = json.loads(out) if out else []
        return data if isinstance(data, list) else [data]
    except Exception:
        return []

def _launcher_profiles() -> list:
    dirs = user_dirs()
    path = dirs["minecraft"] / "launcher_profiles.json"
    out = []
    if not path.is_file():
        return out
    try:
        data = json.loads(path.read_text(encoding="utf-8", errors="ignore"))
    except (OSError, ValueError):
        return out
    for key, profile in (data.get("profiles") or {}).items():
        if not isinstance(profile, dict):
            continue
        out.append(
            {
                "id": key,
                "name": profile.get("name") or key,
                "type": profile.get("type") or "",
                "last_used": profile.get("lastUsed") or "",
                "game_dir": profile.get("gameDir") or "",
                "java_args": profile.get("javaArgs") or "",
                "last_version": profile.get("lastVersionId") or "",
            }
        )
    return out

def run(ctx) -> list:
    out: list = []
    users = _local_users()
    for user in users:
        out.append(
            Finding(
                module="accounts",
                title=str(user.get("Name", "unknown")) + (" (enabled)" if user.get("Enabled") else " (disabled)"),
                detail="Last logon: " + str(user.get("LastLogon") or "never"),
                severity=INFO,
                category="accounts",
                evidence=user,
                tags=["windows-account"],
            )
        )

    profiles = _launcher_profiles()
    for profile in profiles:
        args = str(profile.get("java_args") or "")
        suspicious = any(token in args.lower() for token in ("javaagent", "-noverify", "tweakclass"))
        out.append(
            Finding(
                module="accounts",
                title="Launcher profile: " + str(profile.get("name")),
                detail=(profile.get("last_version") or "") + "  " + (profile.get("game_dir") or ""),
                severity=WARNING if suspicious else INFO,
                category="accounts",
                evidence=profile,
                tags=["minecraft-profile"] + (["injection-args"] if suspicious else []),
            )
        )

    if not profiles:
        out.append(
            Finding(
                module="accounts",
                title="No Minecraft launcher profiles",
                detail="launcher_profiles.json was not found, so no launcher account data is available",
                severity=INFO,
                category="accounts",
            )
        )
    return out

from __future__ import annotations

import os
import shutil
import subprocess
import tempfile
import winreg
from datetime import datetime, timedelta, timezone

from core import signatures
from core.config import user_dirs
from core.finding import Finding, INFO, WARNING

HIVE_KEY = r"HKLM\GprzSSAmcache"
MAX_ROWS = 600

def _load_hive(hive_path: str, temp_dir: str) -> str | None:
    """Copy the hive (it is locked) and load it under our own key."""
    copy = os.path.join(temp_dir, "amcache.hve")
    try:
        shutil.copy2(hive_path, copy)
    except OSError:
        return None
    result = subprocess.run(
        ["reg", "load", HIVE_KEY, copy],
        capture_output=True,
        text=True,
        timeout=30,
        creationflags=0x08000000,
    )
    if result.returncode != 0:
        return None
    return copy

def _unload() -> None:
    subprocess.run(
        ["reg", "unload", HIVE_KEY],
        capture_output=True,
        timeout=20,
        creationflags=0x08000000,
    )

def _filetime(value: int):
    if not value:
        return ""
    try:
        return (datetime(1601, 1, 1, tzinfo=timezone.utc) + timedelta(microseconds=value / 10)).isoformat()
    except Exception:
        return ""

def run(ctx) -> list:
    out: list = []
    dirs = user_dirs()
    hive_path = str(dirs["windir"] / "AppCompat" / "Programs" / "Amcache.hve")

        out.append(
            Finding(
                module="amcache",
                title="Amcache hive not present",
                detail=hive_path,
                severity=INFO,
                category="file_activity",
                tags=["precondition"],
            )

        return out

    temp_dir = tempfile.mkdtemp(prefix="gprzss-")

                module="amcache",

from __future__ import annotations

import os
import subprocess
import winreg
from datetime import datetime, timedelta, timezone

from core import signatures
from core.finding import Finding, INFO, WARNING

def _current_sids() -> list:
    """SIDs that have a BAM entry."""
    out = []
    try:
        base = winreg.OpenKey(
            winreg.HKEY_LOCAL_MACHINE,
            r"SYSTEM\CurrentControlSet\Services\bam\State\UserSettings",
        )
    except OSError:
        try:
            base = winreg.OpenKey(
                winreg.HKEY_LOCAL_MACHINE,
                r"SYSTEM\CurrentControlSet\Services\bam\UserSettings",
            )
        except OSError:
            return out
    try:
        index = 0
        while True:
            try:
                out.append(winreg.EnumKey(base, index))
            except OSError:
                break
            index += 1
    finally:
        winreg.CloseKey(base)
    return out

def _filetime_to_dt(raw: bytes):
    if not raw or len(raw) < 8:
        return ""
    value = int.from_bytes(raw[:8], "little")
    if value == 0:
        return ""
    try:
        return (datetime(1601, 1, 1, tzinfo=timezone.utc) + timedelta(microseconds=value / 10)).isoformat()
    except Exception:
        return ""

def run(ctx) -> list:
    out: list = []
    sids = _current_sids()
    if not sids:
        out.append(
            Finding(
                module="bam",
                title="No BAM execution history",
                detail="Either the key is protected, or execution history was cleared",
                severity=INFO,
                category="file_activity",
                tags=["precondition"],
            )
        )
        return out

    total = 0
    flagged = 0
    for sid in sids:
        for root in (
            r"SYSTEM\CurrentControlSet\Services\bam\State\UserSettings\\" + sid,
            r"SYSTEM\CurrentControlSet\Services\bam\UserSettings\\" + sid,
        ):
            if ctx.stopped():
                break
            try:
                key = winreg.OpenKey(winreg.HKEY_LOCAL_MACHINE, root)
            except OSError:
                continue
            try:
                index = 0
                while True:
                    try:
                        name, value, _kind = winreg.EnumValue(key, index)
                    except OSError:
                        break
                    index += 1
                    total += 1
                    exe = name.split("\\")[-1]
                    hits = signatures.all_matches(exe, ctx.signatures, "processes")
                    if not hits:
                        continue
                    flagged += 1
                    entry = hits[0]
                    out.append(
                        Finding(
                            module="bam",
                            title=str(entry.get("name", exe)) + " was executed",
                            detail=name,
                            severity=str(entry.get("severity", WARNING)),
                            category="file_activity",
                            signature=str(entry.get("match", "")),
                            evidence={
                                "path": name,
                                "serid": sid,
                                "last_executed": _filetime_to_dt(value if isinstance(value, bytes) else b""),
                            },
                            tags=["bam", str(entry.get("kind", ""))],
                        )
                    )
            finally:
                winreg.CloseKey(key)

    out.append(
        Finding(
            module="bam",
            title="%d BAM entries, %d matched a signature" % (total, flagged),
            detail="BAM records every executable the kernel started, even one deleted afterwards",
            severity=INFO if flagged == 0 else WARNING,
            category="file_activity",
            evidence={"count": total, "flagged": flagged},
        )
    )
    return out

    """Copy the (locked) database, then read urls and downloads."""
    rows = []
    temp_dir = tempfile.mkdtemp(prefix="gprzss-browser-")
    copy = os.path.join(temp_dir, "history.sqlite")
    try:
        shutil.copy2(history_path, copy)
        for suffix in ("-wal", "-shm"):
            src = Path(str(history_path) + suffix)
            if src.exists():
                shutil.copy2(src, copy + suffix)
        conn = sqlite3.connect(copy, timeout=5)
        try:
            cur = conn.cursor()
            is_firefox = "places" in str(history_path).lower()
            if is_firefox:
                cur.execute(
                    "SELECT url, title, last_visit_date FROM moz_places "
                    "WHERE url IS NOT NULL ORDER BY last_visit_date DESC LIMIT ?",
                    (MAX_ROWS,),
                )
                for url, title, ts in cur.fetchall():
                    rows.append(
                        {
                            "url": url or "",
                            "title": title or "",
                            "when": (ts or 0) / 1e6,
                            "kind": "visit",
                        }
                    )
            else:
                cur.execute(
                    "SELECT url, title, last_visit_time FROM urls "
                    "ORDER BY last_visit_time DESC LIMIT ?",
                    (MAX_ROWS,),
                )
                for url, title, ts in cur.fetchall():
                    rows.append(
                        {
                            "url": url or "",
                            "title": title or "",
                            "when": ((ts or 0) / 1e6) - 11644473600,
                            "kind": "visit",
                        }
                    )
                try:
                    cur.execute(
                        "SELECT target_path, tab_url, start_time FROM downloads "
                        "ORDER BY start_time DESC LIMIT 500"

                    for target, tab_url, ts in cur.fetchall():
                        rows.append(
                            {
                                "url": tab_url or "",
                                "title": target or "",
                                "when": ((ts or 0) / 1e6) - 11644473600,
                                "kind": "download",
                            }
                        )
                except sqlite3.Error:
                    pass
        finally:

    except (sqlite3.Error, OSError):

    finally:

"""Read the Minecraft JVM heap and look for client artefacts.

This is the part that catches a client whose files were renamed or deleted:
the loaded classes and their strings are still in memory until the game closes.
"""
from __future__ import annotations

import time

from core import java, signatures, winapi
from core.config import DEFAULT_MEMORY_BUDGET, MEMORY_CHUNK, MEMORY_OVERLAP
from core.finding import Finding, INFO, WARNING, DETECTED, CLEAN

MAX_HITS_PER_SIGNATURE = 4

def _targets(ctx) -> list:
    """Java processes that are actually running Minecraft.

    core.java answers this for any installed JDK, so a game under Zulu or
    Temurin is read as readily as one under Oracle. A java process carrying no
    marker at all is only read when the caller pins its pid.
    """
    forced = int(ctx.get("force_pid", -1))
    out = []
    for proc in java.discover():
        if proc["launcher"]:
            continue
        if proc["is_game"] or proc["pid"] == forced:
            out.append(proc)
    return out

def _scan_process(ctx, proc, patterns, budget, modules) -> tuple[list, int]:
    """Return (hits, bytes_read). A hit is (signature_entry, address, encoding)."""
    hits: list = []
    hits_by_sig: dict = {}
    bytes_read = 0
    handle = winapi.open_process(proc["pid"])
    if not handle:
        return hits, 0

    try:
        deadline = time.time() + float(ctx.get("memory_seconds", 90))
        for base, size in winapi.iter_readable_regions(handle):
            if ctx.stopped() or bytes_read >= budget or time.time() > deadline:
                break
            if size > 1024 * 1024 * 1024:
                continue
            offset = 0
            while offset < size:
                if ctx.stopped() or bytes_read >= budget or time.time() > deadline:
                    break
                chunk_size = min(MEMORY_CHUNK, size - offset)
                data = winapi.read_memory(handle, base + offset, chunk_size)
                if data:
                    bytes_read += len(data)
                    lowered = data.lower()
                    for needle_lower, entry in patterns:
                        if hits_by_sig.get(id(entry), 0) >= MAX_HITS_PER_SIGNATURE:
                            continue
                        idx = lowered.find(needle_lower)
                        while idx != -1:
                            if hits_by_sig.get(id(entry), 0) >= MAX_HITS_PER_SIGNATURE:
                                break
                            address = base + offset + idx
                            hits_by_sig[id(entry)] = hits_by_sig.get(id(entry), 0) + 1
                            hits.append(
                                (
                                    entry,
                                    address,
                                    winapi.module_for_address(modules, address),
                                )
                            )
                            idx = lowered.find(needle_lower, idx + len(needle_lower))
                    pct = min(99.0, (bytes_read / float(budget)) * 100.0) if budget else 0.0
                    ctx.emit("memory", "scanned %.0f MB of %s" % (bytes_read / 1e6, proc["name"]), pct)
                offset += max(1, len(data) - MEMORY_OVERLAP) if data and len(data) > MEMORY_OVERLAP else chunk_size
    finally:
        winapi.close_handle(handle)

    return hits, bytes_read

NATIVE_BUNDLES = (
    "jna", "jinput", "lwjgl", "libopus", "librnnoise", "libspeex", "liblame",
    "discord", "glfw", "openal", "sodium", "netty", "tcnative", "jline",
)

def _suspicious_modules(modules: list) -> list:
    """Modules that are not where a legitimate native belongs.

    A DLL read out of Temp is normal for Minecraft. What is not normal is one
    loaded from Temp that no longer exists on disk, because that image only
    lives in the process now, which is what an injected payload looks like.
    """
    import os

    out = []
    for mod in modules:
        path = mod.get("path") or ""
        lowered = path.lower()
        if not lowered:
            continue
        in_temp = "\\temp\\" in lowered or "\\downloads\\" in lowered
        if not in_temp:
            continue
        name = (mod.get("name") or "").lower()
        if any(name.startswith(prefix) or prefix in name for prefix in NATIVE_BUNDLES):
            continue
        out.append({**mod, "missing": not os.path.exists(path)})
    return out

def run(ctx) -> list:
    out: list = []
    sigs = ctx.signatures
    targets = _targets(ctx)
    if not targets:
        out.append(
            Finding(
                module="memory",
                title="Memory scan skipped, no java process running",
                detail="Start Minecraft on any Java runtime, stay on the server, then run a new scan",
                severity=WARNING,
                category="suspicious",
                tags=["precondition"],
            )
        )
        return out

    patterns = []
    for raw, entry in signatures.memory_patterns(sigs):
        patterns.append((raw.lower(), entry))

    budget = int(ctx.get("memory_budget", DEFAULT_MEMORY_BUDGET))
    total_hits = 0
    total_bytes = 0
    clean_hits = []

    for proc in targets:
        ctx.emit(
            "memory",
            "attaching to " + proc["name"] + " on " + proc["runtime"] + " (pid " + str(proc["pid"]) + ")",
            0,
        )
        modules = winapi.list_modules(proc["pid"])
        hits, read = _scan_process(ctx, proc, patterns, budget, modules)
        total_bytes += read

        grouped: dict = {}
        for entry, address, mod_name in hits:
            key = str(entry.get("name", ""))
            grouped.setdefault(key, {"entry": entry, "addresses": [], "modules": set()})
            grouped[key]["addresses"].append(address)
            if mod_name:
                grouped[key]["modules"].add(mod_name)

        for key, group in grouped.items():
            entry = group["entry"]
            sev = str(entry.get("severity", WARNING))
            if sev == CLEAN:
                clean_hits.append(key)
                continue
            total_hits += 1
            addr_list = ", ".join("0x%X" % a for a in group["addresses"][:MAX_HITS_PER_SIGNATURE])
            out.append(
                Finding(
                    module="memory",
                    title=key + " found in " + proc["name"] + " memory (" + proc["runtime"] + ")",
                    detail=addr_list,
                    severity=sev,
                    category="suspicious",
                    signature=str(entry.get("match", "")),
                    evidence={
                        "pid": proc["pid"],
                        "name": key,
                        "signature": entry.get("match", ""),
                        "addresses": ["0x%X" % a for a in group["addresses"][:MAX_HITS_PER_SIGNATURE]],
                        "modules": sorted(group["modules"]),
                        "kind": entry.get("kind", ""),
                        "note": entry.get("note", ""),
                        "hits": len(group["addresses"]),
                    },
                    tags=["memory", str(entry.get("kind", ""))],
                )
            )

        for mod in _suspicious_modules(modules):
            missing = bool(mod.get("missing"))
            out.append(
                Finding(
                    module="memory",
                    title=(
                        "Module loaded from Temp, file no longer exists"
                        if missing
                        else "Unrecognised module loaded from Temp"
                    ),
                    detail=mod.get("path", ""),
                    severity=DETECTED if missing else WARNING,
                    category="suspicious",
                    signature="module-path",
                    evidence={
                        "module": mod.get("name"),
                        "path": mod.get("path"),
                        "pid": proc["pid"],
                        "onDisk": not missing,
                    },
                    tags=["injection"],
                )
            )

    if total_hits == 0:
        detail = "Read %.0f MB across %d process(es)" % (total_bytes / 1e6, len(targets))
        if clean_hits:
            detail += ". Known-good markers present: " + ", ".join(sorted(set(clean_hits))[:4])
        out.append(
            Finding(
                module="memory",
                title="No client signatures in JVM memory",
                detail=detail,
                severity=CLEAN,
                category="suspicious",
                tags=["memory"],
            )
        )

    return out

from __future__ import annotations

from pathlib import Path

MAX_HASH_BYTES = 64 * 1024 * 1024

def _sha1(path: Path) -> str:
    digest = hashlib.sha1()
    try:
        with open(path, "rb") as fh:
            for chunk in iter(lambda: fh.read(1 << 20), b""):
                digest.update(chunk)
    except OSError:
        return ""
    return digest.hexdigest()

                severity=INFO,
                category="tools",
                tags=["precondition"],
            )
        )
        return out

    if not mods_dir.is_dir():
        out.append(
            Finding(
                module="mods",
                title="No mods folder installed",
                detail=str(mods_dir),
                severity=INFO,
                category="tools",
            )
        )
        return out

    jars = sorted(p for p in mods_dir.glob("*.jar"))
    flagged = 0
    for jar in jars:
        hits = signatures.all_matches(jar.name, ctx.signatures, "mods")
        try:
            stat = jar.stat()
        except OSError:
            continue
        entry = hits[0] if hits else None
        if entry:
            flagged += 1
        out.append(
            Finding(
                module="mods",
                title=(str(entry.get("name", jar.name)) if entry else jar.name),
                detail=str(jar),
                severity=str(entry.get("severity", WARNING)) if entry else CLEAN,
                category="tools",
                signature=str(entry.get("match", "")) if entry else "mod",
                evidence={
                    "file": str(jar),
                    "size": stat.st_size,
                    "modified": stat.st_mtime,
                    "sha1": _sha1(jar) if stat.st_size <= MAX_HASH_BYTES else "",
                    "note": entry.get("note", "") if entry else "No signature match",
                },
                tags=["mod"] + (["flagged"] if entry else []),
            )
        )

    versions = mc / "versions"
    custom = []
    if versions.is_dir():
        for child in versions.iterdir():
            if child.is_dir() and child.name.lower() not in ("1.8.9", "1.21", "latest-release", "latest-snapshot"):
                jar = child / (child.name + ".jar")
                if jar.is_file():
                    custom.append(child.name)
    if custom:
        out.append(
            Finding(
                module="mods",
                title="%d non-standard version folders" % len(custom),
                detail=", ".join(custom[:12]),
                severity=WARNING,
                category="tools",
                evidence={"versions": custom[:50]},
                tags=["version"],
            )
        )

    out.append(
        Finding(
            module="mods",
            title="%d mod jars, %d flagged" % (len(jars), flagged),
            detail=str(mods_dir),
            severity=CLEAN if flagged == 0 else DETECTED,
            category="tools",
            evidence={"jars": len(jars), "flagged": flagged},
        )
    )
    return out

```py
"""Parse Prefetch files for what ran recently, including deleted binaries."""
from __future__ import annotations

import os
import struct
from datetime import datetime, timedelta, timezone

from core import signatures
from core.config import user_dirs
from core.finding import Finding, INFO, WARNING, DETECTED

MAX_FILES = 400
MIN_RUNS = 1

def _filetime_to_dt(value: int):
    if not value:
        return None
    try:
        return datetime(1601, 1, 1, tzinfo=timezone.utc) + timedelta(microseconds=value / 10)
    except Exception:
        return None

def _read_prefetch(path: str) -> dict | None:
    """Extract the executable name, run count and last run time.

    The format is undocumented and versioned, so this reads the fields whose
    offsets have been stable since Windows 7 and falls back to a name derived
    from the file name when the header does not parse.
    """
    try:
        with open(path, "rb") as fh:
            data = fh.read(4096)
    except OSError:
        return None
    if len(data) < 84 or data[4:8] != b"SCCA":
        return None

    version = struct.unpack_from("<I", data, 0)[0]
    name = ""
    run_count = 0
    last_run = None

    try:
        if version == 17:
            name = data[16:76].split(b"\x00", 1)[0].decode("utf-16-le", "ignore")
            run_count = struct.unpack_from("<I", data, 0x98)[0]
            last_run = _filetime_to_dt(struct.unpack_from("<Q", data, 0x80)[0])
        elif version == 23:
            name = data[16:76].split(b"\x00", 1)[0].decode("utf-16-le", "ignore")
            run_count = struct.unpack_from("<I", data, 0xD0)[0]
            last_run = _filetime_to_dt(struct.unpack_from("<Q", data, 0xB0)[0])
        elif version in (26, 30, 31, 33):
            name_offset = struct.unpack_from("<I", data, 0x84)[0]
            name_chars = 60
            raw_name = data[name_offset : name_offset + name_chars * 2]
            name = raw_name.decode("utf-16-le", "ignore").split("\x00", 1)[0]
            last_run = _filetime_to_dt(struct.unpack_from("<Q", data, 0x80)[0])
            run_count = struct.unpack_from("<I", data, 0x98)[0] if len(data) > 0x9C else 0
    except (struct.error, UnicodeDecodeError):
        pass

    if not name:
        stem = os.path.basename(path)
        name = stem.split("-")[0] + ".EXE"

    return {
        "name": name,
        "path": path,
        "run_count": int(run_count),
        "last_run": last_run.isoformat() if last_run else "",
        "version": version,
    }

def run(ctx) -> list:
    out: list = []
    dirs = user_dirs()
    pf_dir = dirs["windir"] / "Prefetch"
    if not pf_dir.is_dir():
        out.append(
            Finding(
                module="prefetch",
                title="Prefetch folder is not readable",
                detail=str(pf_dir) + " (needs Administrator, or prefetch is disabled)",
                severity=WARNING,
                category="file_activity",
                tags=["precondition"],
            )
        )
        return out

    entries = []
    try:
        names = [p for p in os.listdir(pf_dir) if p.lower().endswith(".pf")]
    except OSError as exc:
        names = []
        out.append(
            Finding(
                module="prefetch",
                title="Prefetch folder denied",
                detail=str(exc),
                severity=WARNING,
                category="file_activity",
            )
        )

    for index, filename in enumerate(names[:MAX_FILES]):
        if ctx.stopped():
            break
        record = _read_prefetch(str(pf_dir / filename))
        if record:
            entries.append(record)
        if index % 25 == 0:
            ctx.emit("prefetch", "parsed %d of %d prefetch entries" % (index, min(len(names), MAX_FILES)), index)

    entries.sort(key=lambda e: e["last_run"], reverse=True)

    flagged = 0
    for record in entries:
        hits = signatures.all_matches(record["name"], ctx.signatures, "processes")
        if not hits:
            continue
        flagged += 1
        entry = hits[0]
        out.append(
            Finding(
                module="prefetch",
                title=str(entry.get("name", record["name"])) + " was executed",
                detail=record["name"] + "  last run " + (record["last_run"] or "unknown"),
                severity=str(entry.get("severity", WARNING)),
                category="file_activity",
                signature=str(entry.get("match", "")),
                evidence={
                    "prefetch": record["path"],
                    "name": record["name"],
                    "run_count": record["run_count"],
                    "last_run": record["last_run"],
                    "note": entry.get("note", ""),
                },
                tags=["prefetch", str(entry.get("kind", ""))],
            )
        )

    out.append(
        Finding(
            module="prefetch",
            title="%d prefetch entries, %d matched a signature" % (len(entries), flagged),
            detail="Prefetch only exists when the Windows feature is enabled",
            severity=INFO if flagged == 0 else WARNING,
            category="file_activity",
            evidence={"count": len(entries), "flagged": flagged},
        )
    )
    return out

"""Every running process, matched against the signature database.

The game is found through core.java, which means it is found under whichever
JDK the player installed: Zulu, Temurin, Oracle, Corretto, anything. The report
names that runtime the way Task Manager does, and flags any java process that
carries no sign of being the game.
"""
from __future__ import annotations

from core import java, signatures, winapi
from core.finding import Finding, INFO, WARNING, DETECTED, CLEAN

command_line = java.command_line

def run(ctx) -> list:
    out: list = []
    sigs = ctx.signatures
    procs = winapi.list_processes()
    runtimes = java.discover(procs=procs)
    by_pid = {proc["pid"]: proc for proc in runtimes}
    games = [proc for proc in runtimes if proc["is_game"] and not proc["launcher"]]
    flagged: set = set()

    for proc in procs:
        name = proc["name"] or ""
        if not name or name.lower() in ("system idle process", "system"):
            continue
        hit = signatures.match_name(name, sigs, "processes")
        if not hit:
            continue

        handle = winapi.open_process(proc["pid"])
        path = winapi.process_path(handle) if handle else ""
        if handle:
            winapi.close_handle(handle)

        flagged.add(proc["pid"])
        runtime = by_pid.get(proc["pid"], {}).get("runtime", "")
        out.append(
            Finding(
                module="processes",
                title=str(hit.get("name", name)) + " is running",
                detail=path or name,
                severity=str(hit.get("severity", WARNING)),
                category="suspicious",
                signature=str(hit.get("match", "")),
                evidence={
                    "pid": proc["pid"],
                    "ppid": proc["ppid"],
                    "process": name,
                    "path": path,
                    "runtime": runtime,
                    "kind": hit.get("kind", ""),
                    "note": hit.get("note", ""),
                },
                tags=[str(hit.get("kind", "process"))],
            )
        )

    for proc in runtimes:
        if proc["pid"] in flagged:
            continue
        evidence = {
            "pid": proc["pid"],
            "process": proc["name"],
            "runtime": proc["runtime"],
            "path": proc["path"],
            "window": proc["title"],
            "command": proc["command"][:1200],
            "detectedBy": proc["why"],
            "workingSetMB": round(proc["size"] / 1e6, 1),
        }
        if proc["launcher"]:
            out.append(
                Finding(
                    module="processes",
                    title="Minecraft Launcher is open",
                    detail=proc["path"] or proc["name"],
                    severity=INFO,
                    category="suspicious",
                    signature="launcher",
                    evidence=evidence,
                    tags=["launcher"],
                )
            )
        elif proc["server"]:
            out.append(
                Finding(
                    module="processes",
                    title="Minecraft server running on " + proc["runtime"],
                    detail=proc["path"] or proc["name"],
                    severity=INFO,
                    category="suspicious",
                    signature="server",
                    evidence=evidence,
                    tags=["minecraft", "server"],
                )
            )
        elif proc["is_game"]:
            out.append(
                Finding(
                    module="processes",
                    title="Minecraft running on " + proc["runtime"],
                    detail=proc["path"] or proc["name"],
                    severity=INFO,
                    category="suspicious",
                    signature="jvm",
                    evidence=evidence,
                    tags=["minecraft", "jvm"],
                )
            )
        else:
            out.append(
                Finding(
                    module="processes",
                    title="Java process with no Minecraft markers: " + proc["runtime"],
                    detail=proc["path"] or proc["name"],
                    severity=INFO,
                    category="suspicious",
                    signature="jvm",
                    evidence=evidence,
                    tags=["jvm"],
                )
            )

    if not games:
        out.append(
            Finding(
                module="processes",
                title="No Minecraft process is running",
                detail=(
                    "Start the game on whichever Java it uses (Zulu, Temurin, Oracl"
                    "e, anything), then rescan so the memory scan has a heap to read"
                ),
                severity=WARNING,
                category="suspicious",
                tags=["precondition"],
            )
        )
    elif not any(f.severity == DETECTED for f in out):
        out.append(
            Finding(
                module="processes",
                title="No flagged process names in the process list",
                detail="Names alone prove little, the memory scan is the part that matters",
                severity=CLEAN,
                category="suspicious",
            )
        )

from __future__ import annotations

import json
import subprocess

from core import signatures
from core.finding import Finding, INFO, WARNING, DETECTED

def _services() -> list:
    try:
        out = subprocess.run(
            [
                "powershell",
                "-NoProfile",
                "-NonInteractive",
                "-Command",
                "Get-CimInstance Win32_Service | "
                "Select-Object Name,DisplayName,State,StartMode,PathName | "
                "ConvertTo-Json -Compress",
            ],
            capture_output=True,
            text=True,
            timeout=40,
            creationflags=0x08000000,
        ).stdout.strip()
        if not out:
            return []
        data = json.loads(out)
        return data if isinstance(data, list) else [data]
    except Exception:
        return []

def _drivers() -> list:
    try:
        out = subprocess.run(
            ["driverquery", "/fo", "csv", "/nh"],
            capture_output=True,
            text=True,
            timeout=30,
            creationflags=0x08000000,
        ).stdout
    except Exception:
        return []
    rows = []
    for line in out.splitlines():
        parts = [p.strip().strip('"') for p in line.split('","')]
        if len(parts) >= 2:
            rows.append({"module": parts[0].strip('"'), "name": parts[1]})
    return rows

def run(ctx) -> list:
    out: list = []
    services = _services()
    if not services:
        out.append(
            Finding(
                module="services",
                title="Service list unavailable",
                detail="Get-CimInstance returned nothing, likely blocked by policy",
                severity=INFO,
                category="system",
                tags=["precondition"],
            )
        )
    flagged = 0
    for svc in services:
        if ctx.stopped():
            break
        name = str(svc.get("Name") or "")
        state = str(svc.get("State") or "")
        start_mode = str(svc.get("StartMode") or "")
        sig = signatures.service_signature(name, ctx.signatures)
        if not sig:
            continue
        disabled = start_mode.lower() == "disabled" or state.lower() == "stopped"
        if not disabled:
            continue
        flagged += 1
        out.append(
            Finding(
                module="services",
                title=name + " is " + ("disabled" if start_mode.lower() == "disabled" else "stopped"),
                detail=str(sig.get("note", "")),
                severity=str(sig.get("severity", WARNING)),
                category="system",
                signature=name,
                evidence={
                    "service": name,
                    "display": svc.get("DisplayName"),
                    "state": state,
                    "start_mode": start_mode,
                    "path": svc.get("PathName"),
                },
                tags=["service", "antiforensic"],
            )
        )

    drivers = _drivers()
    for drv in drivers[:400]:
        sig = signatures.service_signature(drv.get("module", ""), ctx.signatures)
        if sig:
            out.append(
                Finding(
                    module="services",
                    title=drv.get("module", "") + " driver is loaded",
                    detail=str(sig.get("note", "")),
                    severity=str(sig.get("severity", WARNING)),
                    category="system",
                    signature=drv.get("module", ""),
                    evidence={"module": drv.get("module"), "name": drv.get("name")},
                    tags=["driver"],
                )
            )

    out.append(
        Finding(
            module="services",
            title="%d services checked, %d turned off" % (len(services), flagged),
            detail="Turned-off telemetry services are the usual cover for a cleanup",
            severity="clean" if flagged == 0 else WARNING,
            category="system",
            evidence={"services": len(services), "flagged": flagged, "drivers": len(drivers)},
        )
    )
    return out

"""The USN change journal: files that were deleted off the volume."""
from __future__ import annotations

import os
import re
import subprocess

from core import signatures
from core.finding import Finding, INFO, WARNING, DETECTED

MAX_BYTES = 48 * 1024 * 1024
INTERESTING = (".exe", ".jar", ".dll", ".bat", ".ps1", ".zip")
DELETE_REASON = "0x80000200"

def _read_journal(drive: str) -> str:
    """Stream the journal as CSV, capped so a busy volume cannot hang the scan."""
    cmd = ["fsutil", "usn", "readjournal", drive, "csv"]
    collected = []
    size = 0
    try:
        proc = subprocess.Popen(
            cmd,
            stdout=subprocess.PIPE,
            stderr=subprocess.DEVNULL,
            creationflags=0x08000000,
        )
    except OSError:
        return ""
    try:
        for raw in proc.stdout:
            line = raw.decode("utf-8", "ignore")
            if any(token in line.lower() for token in INTERESTING):
                collected.append(line)
                size += len(line)
                if size > MAX_BYTES:
                    break
    finally:
        try:
            proc.kill()
        except Exception:
            pass
    return "".join(collected)

def _parse(line: str) -> dict | None:
    parts = [p.strip().strip('"') for p in line.split(",")]
    if len(parts) < 6:
        return None
    return {
        "usn": parts[0],
        "file": parts[1],
        "reason": parts[2] if parts[2].startswith("0x") else "",
        "timestamp": parts[3] if re.match(r"\d", parts[3]) else "",
        "raw": line.strip(),
    }

def run(ctx) -> list:
    out: list = []
    drive = (os.environ.get("SystemDrive") or "C:") + "\\"
    ctx.emit("usn", "reading the change journal on " + drive, 0)
    text = _read_journal(drive)
    if not text:
        out.append(
            Finding(
                module="usn",
                title="Change journal is empty or unreadable",
                detail="fsutil needs Administrator, and the journal can be deleted with fsutil usn deletejournal",
                severity=WARNING,
                category="file_activity",
                tags=["precondition"],
            )
        )
        return out

    deleted = []
    for line in text.splitlines():
        record = _parse(line)
        if not record:
            continue
        name = record["file"].split("\\")[-1]
        if not name or "." not in name:
            continue
        if not name.lower().endswith(INTERESTING):
            continue
        if DELETE_REASON in record["reason"] or "delete" in record["raw"].lower():
            deleted.append(record)

    flagged = 0
    for record in deleted[:400]:
        name = record["file"].split("\\")[-1]
        hits = signatures.all_matches(name, ctx.signatures, "processes")
        if not hits:
            flagged += 0
            continue
        entry = hits[0]
        flagged += 1
        out.append(
            Finding(
                module="usn",
                title=str(entry.get("name", name)) + " was created and deleted",
                detail=record["file"],
                severity=DETECTED if entry.get("severity") == DETECTED else WARNING,
                category="file_activity",
                signature=str(entry.get("match", "")),
                evidence={
                    "file": record["file"],
                    "usn": record["usn"],
                    "reason": record["reason"],
                    "timestamp": record["timestamp"],
                },
                tags=["usn", "deleted"],
            )
        )

    out.append(
        Finding(
            module="usn",
            title="%d deleted executables in the journal, %d matched" % (len(deleted), flagged),
            detail="A file deleted seconds after it ran is the classic cleanup move",
            severity=INFO if flagged == 0 else WARNING,
            category="file_activity",
            evidence={"deleted": len(deleted), "flagged": flagged},
        )
    )
    return out

```py
"""One-off: strip comments from the source tree.

Python files go through tokenize so string literals that contain a hash are left
alone. CSS, JS, HTML and PowerShell get a plain scanner. Directive comments that
change behaviour (noqa, type:, pragma, pylint:) are kept.
"""
from __future__ import annotations

import io
import re
import sys
import tokenize
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
KEEP = ("noqa", "type:", "pragma", "pylint:", "mypy:", "fmt: skip", "isort:", "!/")

def strip_python(src: str) -> str:
    lines = src.splitlines()
    drop: set[int] = set()
    inline: list[tuple[int, int, int]] = []
    try:
        for tok in tokenize.generate_tokens(io.StringIO(src).readline):
            if tok.type != tokenize.COMMENT:
                continue
            text = tok.string
            if any(k in text for k in KEEP):
                continue
            row = tok.start[0]
            whole = lines[row - 1].strip() == text.strip()
            if whole:
                drop.add(row)
            else:
                inline.append((row, tok.start[1], tok.end[1]))
    except tokenize.TokenError:
        pass

    out = []
    for i, line in enumerate(lines, start=1):
        if i in drop:
            continue
        for r, a, b in inline:
            if r == i:
                line = (line[:a] + line[b:]).rstrip()
        out.append(line)
    text = "\n".join(out) + "\n"
    text = re.sub(r"\n{3,}", "\n\n", text)
    return text

def strip_block(src: str, opener: str, closer: str) -> str:
    out = []
    depth = 0
    i = 0
    while i < len(src):
        if src.startswith(opener, i):
            depth += 1
            i += len(opener)
            continue
        if depth and src.startswith(closer, i):
            depth -= 1
            i += len(closer)
            continue
        if not depth:
            out.append(src[i])
        i += 1
    text = "".join(out)
    text = re.sub(r"[ \t]+\n", "\n", text)
    text = re.sub(r"\n{3,}", "\n\n", text)
    return text

def strip_line_comments(src: str) -> str:
    kept = [ln for ln in src.splitlines() if not ln.lstrip().startswith("//")]
    text = "\n".join(kept) + "\n"
    return re.sub(r"\n{3,}", "\n\n", text)

def main() -> int:
    targets = sorted(
        p for p in ROOT.rglob("*")
        if p.is_file()
        and ".git" not in p.parts
        and "__pycache__" not in p.parts
        and p.suffix in {".py", ".css", ".js", ".html", ".ps1"}
    )
    changed = 0
    for path in targets:
        src = path.read_text(encoding="utf-8")
        if path.suffix == ".py":
            new = strip_python(src)
        elif path.suffix == ".css":
            new = strip_block(src, "/*", "*/")
        elif path.suffix == ".js":
            new = strip_line_comments(strip_block(src, "/*", "*/"))
        elif path.suffix == ".html":
            new = strip_block(src, "<!--", "-->")
        else:
            new = strip_line_comments(src)
        if new != src:
            path.write_text(new, encoding="utf-8", newline="\n")
            changed += 1
            print(f"stripped {path.relative_to(ROOT)}")
    print(f"{changed} file(s) changed")
    return 0

if __name__ == "__main__":
    sys.exit(main())

  const kv = el("dl", "kv");
  const rows = [
    ["severity", (finding.severity || "info").toUpperCase()],
    ["module", finding.module],
    ["category", finding.category],
    ["signature", finding.signature || "none"],
    ["tags", (finding.tags || []).join(", ") || "none"],
    ["when", new Date((finding.timestamp || 0) * 1000).toLocaleString()]
  ];
  rows.forEach(([key, value]) => {
    kv.appendChild(el("dt", "", key));
    kv.appendChild(el("dd", "", String(value)));
  });
  body.appendChild(kv);

  if (finding.detail) {
    body.appendChild(el("p", "section-label", "Evidence"));
    const pre = el("pre", "raw", finding.detail);
    body.appendChild(pre);
  }

  body.appendChild(el("p", "section-label", "Raw record"));
  body.appendChild(el("pre", "raw", JSON.stringify(finding.evidence || {}, null, 2)));

  $("drawer").classList.add("open");
  $("scrim").classList.add("open");
}

function closeDrawer() {

  $("scrim").classList.remove("open");
}

function render() {
  const findings = state.findings;
  const counts = { detected: 0, warning: 0, clean: 0, info: 0 };
  findings.forEach((f) => { counts[f.severity] = (counts[f.severity] || 0) + 1; });

  $("chipDetN").textContent = counts.detected;
  $("chipWarnN").textContent = counts.warning;
  $("chipDet").className = "chip" + (counts.detected ? " bad" : counts.detected === 0 && findings.length ? " good" : "");
  $("chipWarn").className = "chip" + (counts.warning ? " warn" : "");

  $("statDetected").textContent = counts.detected;
  $("statWarnings").textContent = counts.warning;
  $("statClean").textContent = counts.clean;
  $("statElapsed").textContent = (state.scan && state.scan.elapsed ? state.scan.elapsed : 0).toFixed(1) + "s";

  const byCategory = (category) => findings.filter((f) => f.category === category);

  const suspicious = findings.filter((f) => ["detected", "warning"].includes(f.severity) && f.category !== "overview");
  $("navSuspicious").textContent = suspicious.length;
  $("navSuspicious").className = "nav-count" + (counts.detected ? " hot" : suspicious.length ? " warm" : "");
  const fileFindings = byCategory("file_activity");
  $("navFiles").textContent = fileFindings.length;
  $("navFiles").className = "nav-count" + (fileFindings.some((f) => f.severity === "detected") ? " hot" : "");

  const machine = byCategory("overview");
  fillRows($("overviewMachine"), machine, "No machine data yet");
  const top = findings
    .filter((f) => ["detected", "warning"].includes(f.severity))
    .slice(0, 12);
  $("topCount").textContent = top.length;
  fillRows($("overviewTop"), top, "Nothing flagged yet");

  const suspiciousFiltered = suspicious.filter((f) => matchesFilter(f, state.filters.suspicious));
  $("suspiciousCount").textContent = suspiciousFiltered.length;
  fillRows($("rowsSuspicious"), suspiciousFiltered, suspicious.length ? "No entries match this filter" : "Run a scan to populate suspicious entries");

  const filesFiltered = fileFindings.filter((f) => matchesFilter(f, state.filters.files));
  $("fileCount").textContent = filesFiltered.length;
  fillRows($("rowsFiles"), filesFiltered, "No file artefacts yet");

  fillRows($("rowsSystem"), byCategory("system"), "No system findings");
  fillRows($("rowsAccounts"), byCategory("accounts"), "No account data");
  fillRows($("rowsMinecraft"), byCategory("tools"), "No Minecraft data");

  const logFiltered = findings.filter((f) => matchesFilter(f, state.filters.log));
  $("logCount").textContent = logFiltered.length;
  fillRows($("rowsLog"), logFiltered, "The log is empty");
}

function renderVerdict() {
  const container = $("verdict");
  const badge = $("verdictBadge");
  const title = $("verdictTitle");
  const sub = $("verdictSub");
  const scan = state.scan;

  container.className = "verdict";
  if (!scan || scan.state === "idle" || !scan.id) {
    badge.textContent = "NO DATA";
    title.textContent = "No scan yet";
    sub.textContent = "Press Run Scan to check this machine";
    return;
  }
  if (scan.state === "running") {
    badge.textContent = "SCANNING";
    title.textContent = "Scan in progress";
    sub.textContent = scan.moduleLabel ? scan.moduleLabel + ": " + scan.message : "starting";
    return;
  }
  const counts = scan.counts || {};
  if (counts.detected) {
    container.classList.add("detected");
    badge.textContent = "DETECTED";
    title.textContent = counts.detected + " detection" + (counts.detected === 1 ? "" : "s") + " found";
    sub.textContent = "Review the entries below before clearing this player";
  } else if (counts.warning) {
    container.classList.add("warning");
    badge.textContent = "REVIEW";
    title.textContent = counts.warning + " warning" + (counts.warning === 1 ? "" : "s") + ", nothing conclusive";
    sub.textContent = "Open each entry and read the evidence before deciding";
  } else {
    container.classList.add("clean");
    badge.textContent = "CLEAN";
    title.textContent = "No detections and no warnings";
    sub.textContent = "Nothing in the signature set matched on this machine";
  }
}

async function startScan() {
  if (state.polling) return;
  $("btnScan").disabled = true;
  $("btnScanLabel").textContent = "Scanning";
  $("scanModule").innerHTML = "<b>STARTING</b> preparing modules";
  try {
    const response = await fetch("/api/scan", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: "{}"
    });
    const data = await response.json();
    if (!data.id) throw new Error(data.error || "scan did not start");
    state.scan = { id: data.id, state: "running" };
    poll(data.id);
  } catch (error) {
    toast("Could not start the scan: " + error.message);
    $("btnScan").disabled = false;
    $("btnScanLabel").textContent = "Run Scan";
  }
}

function poll(scanId) {
  state.polling = setInterval(async () => {
    try {
      const response = await fetch("/api/scan/" + scanId);
      const data = await response.json();
      if (data.error) throw new Error(data.error);
      state.scan = data;
      state.findings = data.findings || [];
      updateScanBar(data);
      renderVerdict();
      render();

      if (data.state === "done" || data.state === "failed") {
        clearInterval(state.polling);
        state.polling = null;
        $("btnScan").disabled = false;
        $("btnScanLabel").textContent = "Rescan";
        $("pageSub").textContent = "scanned " + new Date(data.started_at * 1000).toLocaleTimeString();
        toast(data.state === "done" ? "Scan complete" : "Scan failed: " + data.error);
      }
    } catch (error) {
      clearInterval(state.polling);
      state.polling = null;
      $("btnScan").disabled = false;
      $("btnScanLabel").textContent = "Run Scan";
      toast("Scan polling stopped: " + error.message);
    }
  }, 400);
}

function updateScanBar(scan) {
  const module = $("scanModule");
  const label = scan.state === "running" ? "SCANNING" : (scan.state === "done" ? "COMPLETE" : scan.state.toUpperCase());
  module.innerHTML = "<b>" + label + "</b> " + (scan.message || "");
  const pct = Math.round(scan.progress || 0);
  $("progressBar").style.width = pct + "%";
  $("progressPct").textContent = pct + "%";
  $("footSession").textContent = scan.state === "running" ? "live" : (scan.id || "idle");
}

async function exportReport() {
  if (!state.scan || !state.scan.id) {
    toast("Run a scan first");
    return;
  }
  window.location.href = "/api/report/" + state.scan.id + ".md";
}

$("btnScan").addEventListener("click", startScan);
$("btnExport").addEventListener("click", exportReport);

$("filterSuspicious").addEventListener("input", (event) => {
  state.filters.suspicious = event.target.value;
  render();
});
$("filterFiles").addEventListener("input", (event) => {
  state.filters.files = event.target.value;
  render();
});

async function boot() {
  try {
    const version = await (await fetch("/api/version")).json();
    $("verLabel").textContent = "v" + version.version;
  } catch (error) {  }
  try {
    const sigs = await (await fetch("/api/signatures")).json();
    const total = (sigs.processes || []).length + (sigs.memory_strings || []).length +
      (sigs.mods || []).length + (sigs.services || []).length;
    $("footSigs").textContent = total;
  } catch (error) {  }
  try {
    const latest = await (await fetch("/api/latest")).json();
    if (latest && latest.id) {
      state.scan = latest;
      state.findings = latest.findings || [];
      updateScanBar(latest);
      if (latest.state === "running") poll(latest.id);
    }
  } catch (error) {  }
  render();
  renderVerdict();
}

boot();
