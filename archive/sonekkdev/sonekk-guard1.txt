`README.md`:

```md
# Sonekk Guard

[![ci](https://github.com/sonekkdev/sonekk-guard/actions/workflows/ci.yml/badge.svg)](https://github.com/sonekkdev/sonekk-guard/actions/workflows/ci.yml)
![license](https://img.shields.io/badge/license-PolyForm%20Small%20Business-blue)

Free anti-cheat for standalone VR, built for small studios that just want their game to stop getting modded.

Targets Quest and Pico class Android headsets. No kernel driver, no PC support, no telemetry service to sign up for.

**Free under the PolyForm Small Business license:** under 100 people and under 1M USD revenue, you can ship it in a commercial game at no cost. Larger studios need a commercial license.

## What it does

Runs inside your APK as a small native library. It looks for the things that actually let people mod a standalone VR game: root management, Frida, debuggers, patched libraries and changed function prologues. It produces a signed report, your server scores it, and your game decides what happens.

The client never decides a ban. That is deliberate: anything the client concludes can be patched out.

## Detections

| id | What it sees | Weight |
| --- | --- | --- |
| `frida.maps` | Frida agent, gadget, substrate or lsposed mapped into the process | 90 |
| `frida.thread` | Frida worker threads such as `gum-js-loop` | 85 |
| `frida.module` | The same, found in the loaded module list | 80 |
| `frida.port` | Frida's default listener on 27042 or 27043 | 70 |
| `frida.anon_exec` | Anonymous executable mappings that are not ART's JIT | 25 |
| `root.paths` | su binaries, Magisk, KernelSU, APatch, frida-server on disk | 60 |
| `root.mounts` | Magisk or adb style mounts in `/proc/self/mounts` | 45 |
| `root.props` | `ro.debuggable`, `ro.secure=0`, test-keys, unlocked bootloader | 35 |
| `debug.tracer` | `TracerPid` set, or a successful ptrace attach | 50 |
| `integrity.self_hash` | Your pinned library hash does not match | 95 |
| `integrity.symbol_hook` | A function prologue changed from the pinned baseline | 95 |
| `integrity.signature` | The APK signature is not the one you pinned | 90 |
| `app.debuggable` | The APK was built with `android:debuggable`, a repack smell | 15 |
| `integrity.memory_text` | Mapped code differs from the `.so` on disk, a runtime patch | 95 |
| `instrumentation.inconsistent` | A loaded library is missing from `/proc/self/maps`, a hooked view | 70 |
| `emulator.host` | QEMU or goldfish hardware props | 20 |

Thresholds, server side: 20 watch, 50 review, 100 block. Tune them, they are guesses until you have data.

## Report flow

```
client  ->  POST /v1/challenge        single use nonce, 2 minute TTL
client  ->  collect, sign HMAC        nonce is inside the signed body
server  ->  consume nonce, check HMAC, verify attestation if present
            chain to a pinned root, TEE challenge match, boot state and lock flags
server  ->  score findings, return verdict
```

A captured report cannot be replayed, because the nonce is burnt on first use.

## Quick start

**1. Build the native library** (needs the Android NDK, r25 or newer):

```bash
export ANDROID_NDK=$HOME/Android/Sdk/ndk/26.1.10909125
./scripts/build-android.sh
```

That produces `native/build-android/libsonekk_guard.so`. Copy it into your Unity project at:

```
Assets/Plugins/Android/libs/arm64-v8a/libsonekk_guard.so
```

**2. Install the Unity package**

Package Manager, Add package from disk, pick `unity/Packages/com.sonekk.guard/package.json`.

**3. Configure it**

Create the settings asset: right click in Project, Create, Sonekk Guard, Settings. Set your endpoint and a shared secret.

Drop `GuardRunner` on one GameObject in your first scene, assign the settings asset, and optionally pin your APK signature hash.

**4. Run the reference server**

```bash
cd server
SONEKK_GUARD_SECRET=your-secret npm start
```

Or deploy `server/src/app.js` inside your own backend. It is framework free and has no dependencies.

## Verified

- Native core builds with GCC 16 and passes 43 unit tests, including false positive guards for ART's JIT cache and stock `overlay` mounts, plus 300 rounds of malformed `/proc` fuzzing
- Server passes 24 tests: replay rejection, signature tampering, rate limiting, and real attestation chains generated with OpenSSL (valid chain accepted, wrong key rejected, untrusted root rejected, expired chain rejected)
- The report envelope is JSON with no device identifiers

**Not verified in this repository yet, be aware:**

- The Android `.so` was not built here, there is no NDK in this environment
- The Unity C# has not been compiled, there is no Unity install here
- The client side Keystore request is implemented but has never been compiled or run on a device
- Attestation tests use certificates generated with OpenSSL and a synthetic attestation extension, not a chain captured from real hardware
- Kernel level hiding (custom kernels, keybox spoofing) will beat every check here

## Why it is not unbypassable

On a device the player owns, nothing is. A determined modder will read this source, patch the library, and hook the collector. That is why the design does not depend on the client being honest:

- Scores and verdicts are computed on the server, from finding ids it recognizes
- A client that stops reporting is itself a signal
- The weights are tuned for "flag for review", not "auto ban"
- The useful long term lever is server authority plus behavioural statistics, not this library

Read [docs/THREAT-MODEL.md](docs/THREAT-MODEL.md) before you trust it with anything.

# Integration

## Requirements

- Unity 2021.3 or newer, IL2CPP, arm64-v8a only
- Android NDK r25 or newer to build the native library
- Your own backend to hold the secret and store verdicts

## 1. Build the native library

```bash
export ANDROID_NDK=/path/to/ndk
./scripts/build-android.sh
```

Output: `native/build-android/libsonekk_guard.so`.

Copy it into your project:

```
Assets/Plugins/Android/libs/arm64-v8a/libsonekk_guard.so
```

In the Inspector for that file, enable **Android** and set the CPU to **ARM64**. Unity 2021 defaults to arm64 for Quest anyway, but check.

## 2. Install the package

Package Manager, plus button, **Add package from disk**, select:

```
unity/Packages/com.sonekk.guard/package.json
```

## 3. Settings asset

Right click in Project, **Create, Sonekk Guard, Settings**.

| Field | Meaning |
| --- | --- |
| endpoint | Base URL of your server, the runner posts to `endpoint + /v1/report` |
| apiKey | Shared secret used for the HMAC. Public by definition, it only stops spam |
| reportIntervalSeconds | 300 is fine. Each report costs a few milliseconds of background work |
| reportOnStart | Collect once at launch and log it, useful while integrating |
| expectedLibraryHash | Optional. SHA-256 of your built `libsonekk_guard.so` |
| requestAttestation | Ask the TEE for a certified key bound to the challenge. Needs trusted roots on the server |

## 4. Attach the runner

Add `GuardRunner` to a GameObject in your first scene, assign the settings asset.

If you pin your APK signature, put its SHA-256 in `pinnedSignatureSha256` on the component. Get it from:

```bash
keytool -printcert -jarfile app.apk
```

or from the Play Console. If you leave it empty, signature pinning is skipped and the check reports nothing.

## 5. Server

```bash
cd server
SONEKK_GUARD_SECRET=your-secret npm start
```

Then point `endpoint` at it. The reference server logs verdicts and nothing else. Use `onReport` in `createApp` to store what you need.

| Variable | Default | Meaning |
| --- | --- | --- |
| `SONEKK_GUARD_SECRET` | empty | HMAC key. Empty disables signature checks |
| `SONEKK_REQUIRE_CHALLENGE` | `true` | Reject reports without a fresh nonce |
| `SONEKK_REQUIRE_ATTESTATION` | `false` | Reject clients without a valid attestation chain |
| `SONEKK_ATTESTATION_ROOTS` | empty | Path to a PEM bundle of trusted attestation roots |
| `PORT` | `8787` | Listen port |

The runner fetches a nonce from `/v1/challenge` before every report, so replay protection works out of the box. If you implement your own client, remember the nonce must be inside the signed body.

Attestation is optional and off by default because you need to supply roots. Drop the TEE root certificates for the devices you support into one PEM file and set `SONEKK_ATTESTATION_ROOTS`.

## 6. Decide what a verdict means

Do not ban in the client. A block verdict should do something boring: put the player in a shadow lobby, flag the account for review, or drop them from ranked.

## Pitfalls

- **Stripping.** If you strip the native library or rename it, `DllImport("sonekk_guard")` breaks. Keep the name.
- **Emulator.** Emulators trip several checks. Exclude development builds explicitly rather than lowering the weights.
- **Developer mode.** Normal on Quest. It is not a cheat signal and this library does not treat it as one.
- **Threading.** Collection touches the filesystem. `GuardRunner` runs it on a task and only the upload happens on the main thread.
- **Multiple installs.** The report contains no device id, so correlate with your own player id via the `player` field, which the runner appends when `playerId` is set.

## Testing detection without a cheater

The host test suite feeds real `/proc` formats into the analyzers:

```bash
cmake -S native -B native/build -G Ninja -DCMAKE_CXX_COMPILER=g++ -DCMAKE_BUILD_TYPE=Release
cmake --build native/build
ctest --test-dir native/build --output-on-failure
```

Add fixtures in `native/tests/main.cpp` when you add a check. A detection you cannot test is a detection you cannot trust.

# Privacy

Sonekk Guard is built to collect as little as possible, because anti-cheat telemetry is personal data in most jurisdictions.

## What is collected

Only process local state, evaluated on the device:

- `/proc/self/maps`, `/proc/self/status`, `/proc/self/mounts`
- Existence of known root and hook artefact paths
- A short list of `ro.*` build properties
- Whether Frida's default port is listening
- The SHA-256 of your own native library
- Whether the APK signature matches the one you pinned

## What is not collected

- Advertising id, IMEI, serial, Android id, MAC address, IP address
- Installed apps, contacts, files outside the app sandbox
- Message contents, voice, camera or tracking data
- Any persistent device fingerprint

Reports contain finding ids, weights and short technical details. That is all.

## Player identifiers

The library never sends one. If your game wants to attribute a report, `GuardRunner.playerId` appends your own player id to the payload. That is your data and your policy.

## Retention

The reference server keeps nothing: it logs a one line verdict and returns. If you store reports, keep them no longer than you need them for moderation, and document that in your own privacy policy.

## Store disclosure

Meta and Pico both require you to disclose anti-cheat and integrity collection in your privacy policy and store listing. Say plainly: "we check whether the device has been modified, to detect cheating".

## GDPR note

Finding ids and timestamps tied to a player id are personal data. Decide a legal basis before you store them, and honour deletion requests.

`docs/THREAT-MODEL.md`:

```md
# Threat model

## Who you are defending against

**Script kid.** Downloads a Frida script or a repacked APK. Runs it, gets aim assist, gets bored. This is 90 percent of the problem and every check here stops them.

**Modder.** Has root, uses Magisk with Zygisk and a hiding module, knows how to kill a detection thread. They read this source, find the collector, and patch the return value. Expect a bypass within days of each release.

**Determined attacker.** Custom kernel, spoofed keystore keybox, patched client that reports nothing. No on-device check survives this. Your only real defences are server authority and account level response.

## What this library can honestly do

- Stop the mass market. That is worth a lot, because the mass market is what ruins a small VR game's lobbies.
- Raise the cost of the next tier from minutes to hours.
- Produce evidence you can act on with review, not automatic bans.

## What it cannot do

- Prove to your server that the client is honest. Any signal can be forged once the library is patched.
- Detect a cheat that never touches your process, such as a driver level input injector on a rooted headset.
- Survive a custom kernel that hides mounts and processes from `/proc`.

The signature on reports stops trivial `curl` spam, nothing more. Treat the secret as public.

## Signals that survive a patched client

1. **Reporting gaps.** A player with 40 hours and zero reports is anomalous.
2. **Attestation.** Once Keystore attestation is wired up, a client that cannot produce a valid chain is a signal even if every other check is silent.
3. **Behaviour.** Aim curves, reaction time distributions, head to hand correlation. Expensive to fake, invisible to the attacker until you act.
4. **Server authority.** If the client cannot decide whether a shot landed, cheating becomes visual only.

## Response policy

Never auto ban on score alone. Suggested ladder:

| Score | Action |
| --- | --- |
| 0 to 19 | nothing |
| 20 to 49 | log, keep history |
| 50 to 99 | shadow lobby, manual review |
| 100+ | review queue with priority, not an automatic ban |

False positives matter more than cheaters on a small playerbase. Root is common among VR developers, modders and emulator users. A developer build with `ro.debuggable=1` is not a cheater.

## How it will be broken

These are the three vectors any intermediate reverse engineer will try. Two of them now have a countermeasure in the code, one is structural.

**1. Pull the HMAC key out of the APK and forge clean reports.**
The key has to live in the client, so `Il2CppDumper` plus a memory dump gets it in minutes. With the key and a fresh nonce you can detach the native library entirely and post a perfect report. The HMAC is a spam filter, not authentication.
Real mitigation: attestation. A TEE key cannot be exported, so a signature over the nonce from a verified chain is the only proof that cannot be fabricated on a rooted device. Server support is implemented and tested, the client request is not.

**2. Hook `openat` or `read` before the library loads and rewrite `/proc/self/maps`.**
Zygisk, Magisk and KernelSU modules do this comfortably, and a patched `UnityPlayerActivity` can install the hook before the first game instruction.
Implemented countermeasures: reads go through raw `syscall()` instead of libc wrappers, and the module list from `dl_iterate_phdr` is cross checked against the maps text. A library that is loaded but missing from maps is `instrumentation.inconsistent` (70). That catches naive hooks that sanitise one view and forget the other.
Not defeated: a kernel level hook that lies consistently in both views.

**3. Patch the code in memory after load, leaving the `.so` on disk pristine.**
A file hash proves nothing about the running image.
Implemented countermeasure: `integrity.memory_text` hashes the executable `PT_LOAD` segments that are actually mapped and compares them against the same byte ranges read from the file. Anything patched after load fails the comparison. If the bytes cannot be read, the check is skipped rather than guessed.
Remaining gap: a patch applied in the window between our read and the comparison, and a kernel that lies about our own mappings.

**4. Strip the library.**
The client can simply not load `libsonekk_guard.so`. That produces no findings, which is why reporting gaps matter: a player with 40 hours and zero reports is the anomaly. Do not treat silence as innocence.

## Known gaps

- Client attestation is written but unverified: it has never run on a device or been compiled in Unity
- The HMAC key is extractable from the APK by design, it is not an authentication mechanism
- `integrity.memory_text` cannot see a patch applied between the memory read and the comparison
- A kernel level hook that lies consistently defeats every userland check here
- The attestation extension parser is tested against synthetic DER, not a chain from real hardware
- No behavioural checks, they belong in your game server
- Weights are unvalidated guesses
- Rate limiting is per IP and in memory, it does not survive a restart or a load balancer

```

```h
// Sonekk Guard - standalone Android VR anti-cheat core.
// Portable detection logic: no Android headers here so it can be unit tested on a desktop.
#pragma once

#include <cstdint>
#include <string>
#include <vector>

namespace sonekk {

enum class Severity : int { Info = 1, Low = 2, Medium = 3, High = 4, Critical = 5 };

struct Finding {
  std::string id;
  Severity severity = Severity::Info;
  int weight = 0;
  std::string detail;
};

// Everything the collector can observe. Tests fill this in directly, the Android
// platform layer fills it from /proc and the filesystem.
struct Environment {
  std::string maps;                          // /proc/self/maps
  std::string status;                        // /proc/self/status
  std::string mounts;                        // /proc/self/mounts
  std::vector<std::string> existing_paths;   // root / hook artefact paths that exist
  std::vector<std::string> properties;       // "key=value" from android.os.Build / getprop
  std::vector<std::string> loaded_modules;   // dl_iterate_phdr names
  std::vector<std::string> thread_names;     // /proc/self/task/<tid>/comm
  bool app_debuggable = false;               // ApplicationInfo.FLAG_DEBUGGABLE
  bool frida_port_listening = false;         // loopback 27042 or a frida pipe name
  bool debugger_attached = false;            // platform level ptrace check
  bool signature_ok = true;                  // package signature equals the pinned value
  bool memory_text_checked = false;          // was the loaded .text compared against disk
  bool memory_text_ok = true;                // does the mapped text match the file on disk
  std::string expected_self_hash;            // sha256 of the pinned library, hex
  std::string actual_self_hash;              // sha256 measured at runtime, hex
  std::vector<std::pair<std::string, std::string>> hooked_symbols; // name, expected prologue hex vs actual
  std::vector<std::string> actual_prologues; // matching actual hex values, same order
};

struct Report {
  std::vector<Finding> findings;
  int score = 0;
  Severity highest = Severity::Info;

  // Client side hint only. The server recomputes the score and owns the decision.
  std::string verdict() const;
};

// Runs every check against the supplied environment.
Report analyze(const Environment& env);

// Deterministic scoring table shared with the server. Exposed for tests.
int weight_for(const std::string& id);

// JSON envelope posted to the server. Contains no device identifiers.
std::string to_json(const Report& report, const std::string& sdk_version);

std::string lowercase(std::string value);
bool contains_ci(const std::string& haystack, const std::string& needle);
std::string severity_name(Severity severity);

}  // namespace sonekk

// Flat C API consumed by Unity through DllImport. No JNI, no Java layer.
#include <cstdlib>
#include <cstring>
#include <string>

#include "collect.h"
#include "sonekk_guard.h"

#if defined(_WIN32)
#define SG_EXPORT __declspec(dllexport)
#else
#define SG_EXPORT __attribute__((visibility("default")))
#endif

namespace {

constexpr const char* kVersion = "0.1.0";

// Reads a tiny JSON object of {"expectedSelfHash":"...","signatureOk":true}.
// A full parser would be overkill for three fields, but the scanner below still
// validates the shape so malformed input fails closed.
sonekk::CollectConfig parse_config(const char* json) {
  sonekk::CollectConfig config;
  if (json == nullptr) return config;

  const std::string text(json);
  const auto find_string = [&](const char* key) -> std::string {
    const std::string needle = std::string("\"") + key + "\"";
    const auto key_pos = text.find(needle);
    if (key_pos == std::string::npos) return {};
    const auto colon = text.find(':', key_pos + needle.size());
    if (colon == std::string::npos) return {};
    const auto quote = text.find('"', colon + 1);
    if (quote == std::string::npos) return {};
    const auto end = text.find('"', quote + 1);
    if (end == std::string::npos) return {};
    return text.substr(quote + 1, end - quote - 1);
  };

  config.expected_self_hash = find_string("expectedSelfHash");

  const auto sig_pos = text.find("\"signatureOk\"");
  if (sig_pos != std::string::npos) {
    const auto colon = text.find(':', sig_pos);
    if (colon != std::string::npos) {
      config.signature_ok = text.find("false", colon) != std::string::npos ? false : true;
    }
  }

  const auto debug_pos = text.find("\"debuggable\"");
  if (debug_pos != std::string::npos) {
    const auto colon = text.find(':', debug_pos);
    if (colon != std::string::npos) {
      config.app_debuggable = text.find("true", colon) != std::string::npos;
    }
  }
  return config;
}

}  // namespace

extern "C" {

// Returns a heap allocated JSON report. Free it with sonekk_guard_free.
SG_EXPORT const char* sonekk_guard_analyze(const char* config_json) {
  const sonekk::CollectConfig config = parse_config(config_json);
  const sonekk::Report report = sonekk::analyze(sonekk::collect(config));
  const std::string json = sonekk::to_json(report, kVersion);

  auto* buffer = static_cast<char*>(std::malloc(json.size() + 1));
  if (buffer == nullptr) return nullptr;
  std::memcpy(buffer, json.c_str(), json.size() + 1);
  return buffer;
}

SG_EXPORT void sonekk_guard_free(const char* pointer) {
  std::free(const_cast<char*>(pointer));
}

SG_EXPORT const char* sonekk_guard_version(void) { return kVersion; }

Severity severity_for(const std::string& id) {

void add(Report& report, const std::string& id, const std::string& detail) {
  const auto it = std::find_if(report.findings.begin(), report.findings.end(),
                               [&](const Finding& f) { return f.id == id; });
  if (it != report.findings.end()) {
    if (it->detail.find(detail) == std::string::npos && it->detail.size() < 240) {
      it->detail += "; " + detail;
    }
    return;
  }

  Finding finding;
  finding.id = id;
  finding.severity = severity_for(id);
  finding.weight = weight_for(id);
  finding.detail = detail.size() > 200 ? detail.substr(0, 200) : detail;
  report.findings.push_back(finding);
}

std::vector<std::string> split_lines(const std::string& text) {
  std::vector<std::string> lines;
  std::istringstream stream(text);
  std::string line;
  while (std::getline(stream, line)) {
    if (!line.empty() && line.back() == '\r') line.pop_back();
    if (!line.empty()) lines.push_back(line);
  }
  return lines;

// Maps lines look like: start-end perms offset dev inode path
bool map_line_is_executable(const std::string& line) {
  const auto first = line.find(' ');
  if (first == std::string::npos) return false;
  const auto second = line.find(' ', first + 1);
  if (second == std::string::npos) return false;
  const std::string perms = line.substr(first + 1, second - first - 1);
  return perms.find('x') != std::string::npos;
}

std::string map_line_path(const std::string& line) {
  // Fields: addr perms offset dev inode [path]
  std::size_t cursor = 0;
  for (int field = 0; field < 5; ++field) {
    cursor = line.find(' ', cursor);
    if (cursor == std::string::npos) return {};
    ++cursor;
  }
  const auto start = line.find_first_not_of(' ', cursor);
  if (start == std::string::npos) return {};
  return line.substr(start);
}

void check_maps(Report& report, const Environment& env) {
  static const char* kNeedles[] = {"frida", "gum-js", "linjector", "libsubstrate",
                                   "substrate", "xposed", "lsposed", "riru"};
  int anonymous_exec = 0;

  for (const std::string& line : split_lines(env.maps)) {
    const std::string lowered = lowercase(line);
    for (const char* needle : kNeedles) {
      if (lowered.find(needle) != std::string::npos) {
        add(report, "frida.maps", "mapping name matches " + std::string(needle));
        break;
      }
    }

    if (!map_line_is_executable(line)) continue;
    const std::string path = lowercase(map_line_path(line));
    if (path.empty() || path.front() == '[') {
      // ART's JIT cache, stacks, heaps and the vdso are normal. Everything else is not.
      if (path.find("jit") != std::string::npos) continue;
      if (path.find("dalvik") != std::string::npos) continue;
      if (path.find("scudo") != std::string::npos) continue;
      if (path.find("stack") != std::string::npos) continue;
      if (path.find("heap") != std::string::npos) continue;
      if (path.find("vdso") != std::string::npos) continue;
      if (path.find("vectors") != std::string::npos) continue;
      if (path.find("linker") != std::string::npos) continue;
      ++anonymous_exec;
    }
  }

  if (anonymous_exec > 0) {
    add(report, "frida.anon_exec",
        std::to_string(anonymous_exec) + " anonymous executable mapping(s)");
  }
}

void check_modules(Report& report, const Environment& env) {
  static const char* kNeedles[] = {"frida-agent", "frida-gadget", "libfrida", "gum-js",
                                   "libsubstrate", "libxposed"};
  for (const std::string& module : env.loaded_modules) {
    const std::string lowered = lowercase(module);
    for (const char* needle : kNeedles) {
      if (lowered.find(needle) != std::string::npos) {
        add(report, "frida.module", lowered);
        return;
      }
    }
  }
}

  // gdbus are also used by legitimate GLib consumers, so they are not matched.

  }
}

void check_emulator(Report& report, const Environment& env) {
  for (const std::string& entry : env.properties) {
    const auto equals = entry.find('=');
    if (equals == std::string::npos) continue;
    const std::string key = lowercase(entry.substr(0, equals));
    const std::string value = lowercase(entry.substr(equals + 1));

    if (key == "ro.kernel.qemu" && value == "1") add(report, "emulator.host", "ro.kernel.qemu=1");
    if (key == "ro.hardware" &&
        (value == "goldfish" || value == "ranchu" || value.find("qemu") != std::string::npos)) {
      add(report, "emulator.host", "ro.hardware=" + value);
    }
  }
}

}

void check_status(Report& report, const Environment& env) {
  for (const std::string& line : split_lines(env.status)) {
    if (line.rfind("TracerPid:", 0) != 0) continue;
    const auto colon = line.find(':');
    if (colon == std::string::npos) continue;
    const std::string value = line.substr(colon + 1);
    const auto first = value.find_first_not_of(" \t");
    const int pid = first == std::string::npos ? 0 : std::atoi(value.c_str() + first);
    if (pid != 0) add(report, "debug.tracer", "TracerPid " + std::to_string(pid));
  }
  if (env.debugger_attached) add(report, "debug.tracer", "ptrace attach succeeded");
}

void check_mounts(Report& report, const Environment& env) {

  static const char* kNeedles[] = {"magisk", "kernelsu", "/data/adb", "apatch", "ksu"};
  for (const std::string& line : split_lines(env.mounts)) {
    const std::string lowered = lowercase(line);
    for (const char* needle : kNeedles) {
      if (lowered.find(needle) != std::string::npos) {

        return;

}

  if (env.existing_paths.empty()) return;
  std::string detail = env.existing_paths.front();

    detail += ", " + env.existing_paths[i];

  if (env.existing_paths.size() > 4) detail += ", ...";
  add(report, "root.paths", detail);
}

void check_properties(Report& report, const Environment& env) {
  for (const std::string& entry : env.properties) {
    const auto equals = entry.find('=');
    if (equals == std::string::npos) continue;
    const std::string key = lowercase(entry.substr(0, equals));
    const std::string value = lowercase(entry.substr(equals + 1));

    if (key == "ro.debuggable" && value == "1") add(report, "root.props", "ro.debuggable=1");
    if (key == "ro.secure" && value == "0") add(report, "root.props", "ro.secure=0");
    if (key == "ro.build.tags" && value.find("test-keys") != std::string::npos) {
      add(report, "root.props", "ro.build.tags=test-keys");
    }
    if (key == "ro.boot.verifiedbootstate" && value != "green") {
      add(report, "root.props", "verifiedbootstate=" + value);
    }
    if (key == "ro.boot.flash.locked" && value == "0") {
      add(report, "root.props", "flash.locked=0");
    }
  }
}

void check_memory_text(Report& report, const Environment& env) {
  if (!env.memory_text_checked) return;
  if (!env.memory_text_ok) {
    add(report, "integrity.memory_text", "mapped code differs from the file on disk");
  }
}

// A library that is loaded but absent from /proc/self/maps means one of the two
// views was tampered with. This catches naive open/read hooks that sanitise maps.
void check_instrumentation(Report& report, const Environment& env) {
  if (env.loaded_modules.empty() || env.maps.empty()) return;
  const std::string maps = lowercase(env.maps);
  int missing = 0;
  std::string example;

  for (const std::string& path : env.loaded_modules) {
    const std::string lowered = lowercase(path);
    if (lowered.size() < 4 || lowered.compare(lowered.size() - 3, 3, ".so") != 0) continue;
    const auto slash = lowered.find_last_of('/');
    const std::string base = slash == std::string::npos ? lowered : lowered.substr(slash + 1);
    if (base.empty()) continue;
    if (maps.find(base) == std::string::npos) {
      if (missing == 0) example = base;
      ++missing;
    }
  }

  if (missing > 0) {
    add(report, "instrumentation.inconsistent",
        std::to_string(missing) + " loaded module(s) missing from maps, e.g. " + example);
  }
}

void check_integrity(Report& report, const Environment& env) {
  if (!env.expected_self_hash.empty() && !env.actual_self_hash.empty() &&
      lowercase(env.expected_self_hash) != lowercase(env.actual_self_hash)) {
    add(report, "integrity.self_hash", "library hash mismatch");
  }

  const std::size_t pairs =
      std::min(env.hooked_symbols.size(), env.actual_prologues.size());
  for (std::size_t i = 0; i < pairs; ++i) {
    if (lowercase(env.hooked_symbols[i].second) != lowercase(env.actual_prologues[i])) {
      add(report, "integrity.symbol_hook",
          "prologue changed for " + env.hooked_symbols[i].first);
      break;
    }
  }

  if (!env.signature_ok) add(report, "integrity.signature", "package signature mismatch");
}

      return "high";
    case Severity::Medium:
      return "medium";

Report analyze(const Environment& env) {
  Report report;
  check_maps(report, env);
  check_modules(report, env);
  check_threads(report, env);
  check_status(report, env);
  check_mounts(report, env);
  check_paths(report, env);
  check_properties(report, env);
  check_emulator(report, env);

    }
  }

}

std::string json_escape(const std::string& value) {
  std::string out;
  out.reserve(value.size() + 8);
  for (char c : value) {
    switch (c) {
      case '"':
        out += "\\\"";
        break;
      case '\\':
        out += "\\\\";
        break;
      case '\n':
        out += "\\n";
        break;
      case '\r':
        out += "\\r";
        break;
      case '\t':
        out += "\\t";
        break;
      default:
        if (static_cast<unsigned char>(c) < 0x20) {
          out += ' ';
        } else {
          out.push_back(c);
        }
    }
  }
  return out;
}

  }

}

constexpr std::size_t kMaxRead = 4 * 1024 * 1024;

// Raw syscalls instead of libc wrappers, so a userland hook on open/read does not
// see our reads. This does not defeat a kernel level hook, nothing userland does.
std::string read_all(const char* path) {
  const int fd = static_cast<int>(::syscall(SYS_openat, AT_FDCWD, path, O_RDONLY | O_CLOEXEC));
  if (fd < 0) return {};

  std::string out;
  char buffer[8192];
  while (out.size() < kMaxRead) {
    const long read = static_cast<long>(::syscall(SYS_read, fd, buffer, sizeof(buffer)));
    if (read <= 0) break;
    out.append(buffer, static_cast<std::size_t>(read));
  }
  ::syscall(SYS_close, fd);
  return out;
}

std::string read_range(const std::string& path, std::uint64_t offset, std::size_t length) {
  const int fd = static_cast<int>(::syscall(SYS_openat, AT_FDCWD, path.c_str(), O_RDONLY | O_CLOEXEC));
  if (fd < 0) return {};

  std::string out(length, '\0');
  std::size_t done = 0;
  while (done < length) {
    const long read = static_cast<long>(
        ::syscall(SYS_pread64, fd, &out[done], length - done, static_cast<off_t>(offset + done)));
    if (read <= 0) break;
    done += static_cast<std::size_t>(read);
  }
  ::syscall(SYS_close, fd);
  out.resize(done);
  return out;
}

// Compares the executable PT_LOAD segments that are actually mapped against the same
// bytes in the file on disk. Catches runtime patches that leave the .so untouched.
void verify_own_text(Environment& env, const std::string& own_path) {
  if (own_path.empty()) return;

  struct Context {
    Environment* env;
    const std::string* path;
  };
  Context context {&env, &own_path};

  dl_iterate_phdr(
      [](struct dl_phdr_info* info, size_t, void* data) -> int {
        auto* context = static_cast<Context*>(data);
        if (info->dlpi_name == nullptr || info->dlpi_name[0] == '\0') return 0;
        if (*context->path != info->dlpi_name) return 0;

        bool checked = false;
        bool ok = true;

        for (int i = 0; i < info->dlpi_phnum; ++i) {
          const ElfW(Phdr)& header = info->dlpi_phdr[i];
          if (header.p_type != PT_LOAD || (header.p_flags & PF_X) == 0) continue;

          const std::size_t length =
              static_cast<std::size_t>(std::min<ElfW(Xword)>(header.p_filesz, header.p_memsz));
          if (length == 0) continue;

          const std::string disk = read_range(*context->path, header.p_offset, length);
          if (disk.size() != length) {
            // Cannot compare (for example the library lives inside an unreadable APK).
            context->env->memory_text_checked = false;
            return 1;
          }

          const void* memory = reinterpret_cast<const void*>(info->dlpi_addr + header.p_vaddr);
          checked = true;
          if (sha256_hex(memory, length) != sha256_hex(disk.data(), disk.size())) {
            ok = false;
            break;
          }
        }

        context->env->memory_text_checked = checked;
        context->env->memory_text_ok = ok;
        return 1;
      },
      &context);
}

std::vector<std::string> collect_threads() {
  std::vector<std::string> names;
  DIR* dir = ::opendir("/proc/self/task");
  if (dir == nullptr) return names;

  while (struct dirent* entry = ::readdir(dir)) {
    if (entry->d_name[0] == '.') continue;
    const std::string path = std::string("/proc/self/task/") + entry->d_name + "/comm";
    std::string name = read_all(path.c_str());
    while (!name.empty() && (name.back() == '\n' || name.back() == '\r')) name.pop_back();
    if (!name.empty() && names.size() < 128) names.push_back(name);
  }
  ::closedir(dir);
  return names;
}

bool frida_port_listening() {
  // /proc/net/tcp: local_address is hex "ADDR:PORT", st 0A means LISTEN.
  for (const char* file : {"/proc/net/tcp", "/proc/net/tcp6"}) {
    std::istringstream stream(read_all(file));
    std::string line;
    std::getline(stream, line);  // header
    while (std::getline(stream, line)) {
      std::istringstream fields(line);
      std::string slot, local, remote, state;
      fields >> slot >> local >> remote >> state;
      if (state != "0A") continue;
      const auto colon = local.rfind(':');
      if (colon == std::string::npos) continue;
      const unsigned long port = std::strtoul(local.c_str() + colon + 1, nullptr, 16);
      if (port == 27042 || port == 27043) return true;
    }
  }
  return false;
}

void Sha256::transform(const unsigned char block[64]) {
  std::uint32_t w[64];
  for (int i = 0; i < 16; ++i) {
    w[i] = (static_cast<std::uint32_t>(block[i * 4]) << 24) |
           (static_cast<std::uint32_t>(block[i * 4 + 1]) << 16) |
           (static_cast<std::uint32_t>(block[i * 4 + 2]) << 8) |
           static_cast<std::uint32_t>(block[i * 4 + 3]);
  }
  for (int i = 16; i < 64; ++i) {
    const std::uint32_t s0 = rotr(w[i - 15], 7) ^ rotr(w[i - 15], 18) ^ (w[i - 15] >> 3);
    const std::uint32_t s1 = rotr(w[i - 2], 17) ^ rotr(w[i - 2], 19) ^ (w[i - 2] >> 10);
    w[i] = w[i - 16] + s0 + w[i - 7] + s1;
  }

  std::uint32_t a = state_[0], b = state_[1], c = state_[2], d = state_[3];
  std::uint32_t e = state_[4], f = state_[5], g = state_[6], h = state_[7];

  for (int i = 0; i < 64; ++i) {
    const std::uint32_t s1 = rotr(e, 6) ^ rotr(e, 11) ^ rotr(e, 25);
    const std::uint32_t ch = (e & f) ^ ((~e) & g);
    const std::uint32_t temp1 = h + s1 + ch + kRound[i] + w[i];
    const std::uint32_t s0 = rotr(a, 2) ^ rotr(a, 13) ^ rotr(a, 22);
    const std::uint32_t maj = (a & b) ^ (a & c) ^ (b & c);
    const std::uint32_t temp2 = s0 + maj;

    h = g;
    g = f;
    f = e;
    e = d + temp1;
    d = c;
    c = b;
    b = a;
    a = temp1 + temp2;
  }

  state_[0] += a;
  state_[1] += b;
  state_[2] += c;
  state_[3] += d;
  state_[4] += e;
  state_[5] += f;
  state_[6] += g;
  state_[7] += h;
}

void Sha256::update(const void* data, std::size_t length) {
  const auto* bytes = static_cast<const unsigned char*>(data);
  bit_length_ += static_cast<std::uint64_t>(length) * 8u;

  while (length > 0) {
    const std::size_t space = 64 - buffer_length_;
    const std::size_t take = length < space ? length : space;
    std::memcpy(buffer_ + buffer_length_, bytes, take);
    buffer_length_ += take;
    bytes += take;
    length -= take;
    if (buffer_length_ == 64) {
      transform(buffer_);
      buffer_length_ = 0;
    }
  }
}

void Sha256::finish(unsigned char out[32]) {
  const std::uint64_t bits = bit_length_;
  const unsigned char pad = 0x80;
  update(&pad, 1);

  const unsigned char zero = 0x00;
  while (buffer_length_ != 56) {
    update(&zero, 1);
  }

  unsigned char length_bytes[8];
  for (int i = 0; i < 8; ++i) {
    length_bytes[i] = static_cast<unsigned char>((bits >> (56 - i * 8)) & 0xffu);
  }
  // update() would fold these bytes into bit_length_, which is no longer used.
  const std::size_t saved = buffer_length_;
  std::memcpy(buffer_ + saved, length_bytes, 8);
  transform(buffer_);
  buffer_length_ = 0;

  for (int i = 0; i < 8; ++i) {
    out[i * 4] = static_cast<unsigned char>((state_[i] >> 24) & 0xffu);
    out[i * 4 + 1] = static_cast<unsigned char>((state_[i] >> 16) & 0xffu);
    out[i * 4 + 2] = static_cast<unsigned char>((state_[i] >> 8) & 0xffu);
    out[i * 4 + 3] = static_cast<unsigned char>(state_[i] & 0xffu);
  }
}

}  // namespace detail

std::string sha256_hex(const void* data, std::size_t length) {
  detail::Sha256 hasher;
  hasher.update(data, length);
  unsigned char digest[32];
  hasher.finish(digest);

  static const char* kHex = "0123456789abcdef";
  std::string out;
  out.reserve(64);
  for (unsigned char byte : digest) {
    out.push_back(kHex[byte >> 4]);
    out.push_back(kHex[byte & 0x0f]);
  }
  return out;
}

std::string sha256_hex(const std::string& data) {
  return sha256_hex(data.data(), data.size());
}

```js
import { parseChain, verifyChain, verifyProofOfPossession } from './attestation.js'
import { ChallengeStore } from './challenge.js'
import { inspectCertificate } from './keydescription.js'
import { RateLimiter } from './ratelimit.js'
import { decide, scoreReport } from './scoring.js'
import { verifySignature } from './verify.js'

const MAX_BODY = 16 * 1024

/**
 * Reference endpoint. No framework, no storage, no outbound calls.
 *
 * Flow:
 *   1. Client POSTs /v1/challenge, gets a single use nonce.
 *   2. Client collects findings, builds the report with the nonce, signs it with HMAC.
 *   3. Server consumes the nonce, checks the HMAC, optionally verifies the attestation
 *      chain and proof of possession, then scores the findings itself.
 *
 * @param {{
 *   secret?: string,
 *   challenges?: ChallengeStore,
 *   limiter?: RateLimiter,
 *   roots?: import('node:crypto').X509Certificate[],
 *   requireChallenge?: boolean,
 *   requireAttestation?: boolean,
 *   onReport?: (report: object) => void,
 *   now?: () => number
 * }} options
 */
export function createApp (options = {}) {
  const secret = options.secret ?? ''
  const challenges = options.challenges ?? new ChallengeStore()
  const limiter = options.limiter ?? new RateLimiter({ limit: 120, windowMs: 60_000 })
  const roots = options.roots ?? []
  const requireChallenge = options.requireChallenge ?? true
  const requireAttestation = options.requireAttestation ?? false
  const onReport = options.onReport ?? (() => {})
  const now = options.now ?? (() => Date.now())

  return async function handle (req, res) {
    const ip = req.socket?.remoteAddress ?? 'unknown'
    if (!limiter.allow(ip)) return send(res, 429, { error: 'rate_limited' })

    const path = (req.url ?? '').split('?')[0]

    if (path === '/healthz') return send(res, 200, { ok: true })

    if (path === '/v1/challenge') {
      if (req.method !== 'POST' && req.method !== 'GET') return send(res, 405, { error: 'method_not_allowed' })
      const nonce = challenges.issue()
      if (!nonce) return send(res, 503, { error: 'challenge_store_full' })
      return send(res, 200, { nonce, expiresInMs: challenges.ttlMs })
    }

    if (path === '/v1/report') {
      if (req.method !== 'POST') return send(res, 405, { error: 'method_not_allowed' })

      let rawBody
      try {
        rawBody = await readBody(req)
      } catch (error) {
        return send(res, error.code === 'TOO_LARGE' ? 413 : 400, { error: 'bad_body' })
      }

      if (secret && !verifySignature(rawBody, req.headers['x-sonekk-signature'], secret)) {
        return send(res, 401, { error: 'bad_signature' })
      }

      let payload
      try {
        payload = JSON.parse(rawBody.toString('utf8'))
      } catch {
        return send(res, 400, { error: 'bad_json' })
      }

      if (!payload || payload.v !== 1 || !Array.isArray(payload.findings)) {
        return send(res, 400, { error: 'bad_report' })
      }

      if (requireChallenge) {
        if (!challenges.consume(payload.nonce)) {
          return send(res, 401, { error: 'bad_challenge' })
        }
      }

      let attested = false
      let trusted = false
      let bootState = null
      if (payload.attestation && roots.length > 0 && typeof payload.nonce === 'string') {
        const chain = parseChain(payload.attestation.chain)
        const chainResult = verifyChain({ chain, roots, now: now() })
        const proof = chainResult.ok
          ? verifyProofOfPossession({
              leaf: chain[0],
              challenge: payload.nonce,
              signature: payload.attestation.signature
            })
          : false
        const keyDescription = chainResult.ok && proof ? inspectCertificate(chain[0]) : null

        // The challenge inside the signed extension is the binding that matters:
        // an attacker cannot reuse an attestation from another session.
        attested = Boolean(
          chainResult.ok && proof && keyDescription && keyDescription.challenge === payload.nonce
        )
        bootState = keyDescription ? keyDescription.bootStateName : null
        trusted = attested && bootState === 'verified' && keyDescription.deviceLocked === true
      }

      if (requireAttestation && !trusted) {
        return send(res, 401, { error: 'attestation_required' })
      }

      // Client supplied score and verdict are ignored, always.
      const { score, findings } = scoreReport(payload.findings)
      const verdict = decide(score)

      onReport({
        playerId: typeof payload.player === 'string' ? payload.player.slice(0, 128) : null,
        score,
        verdict,
        attested,
        trusted,
        bootState,
        findings,
        sdk: typeof payload.sdk === 'string' ? payload.sdk.slice(0, 32) : 'unknown',
        receivedAt: new Date(now()).toISOString()
      })

      return send(res, 200, { verdict, score, attested, trusted, bootState })
    }

    return send(res, 404, { error: 'not_found' })
  }
}

async function readBody (req) {
  let size = 0
  const chunks = []
  for await (const chunk of req) {
    size += chunk.length
    if (size > MAX_BODY) {
      const error = new Error('too large')
      error.code = 'TOO_LARGE'
      req.destroy()
      throw error
    }
    chunks.push(chunk)
  }
  return Buffer.concat(chunks)
}

function send (res, status, body) {
  const json = JSON.stringify(body)
  res.writeHead(status, {
    'content-type': 'application/json; charset=utf-8',
    'content-length': Buffer.byteLength(json),
    'cache-control': 'no-store'
  })
  res.end(json)
}

import { X509Certificate, createVerify } from 'node:crypto'

/**
 * Android Key Attestation chain checks.
 *
 * What this proves: the certificate chain is signed up to a root you pinned, the
 * certificates are currently valid, and the leaf key signed the server challenge.
 * That is genuine hardware backed evidence, because only the TEE holds the leaf key.
 *
 * What this does not do yet: parse the attestation extension (OID 1.3.6.1.4.1.11129.2.1.17)
 * to read verifiedBootState, deviceLocked and the package name hash. That needs an
 * ASN.1 reader. Until then, treat a valid chain as "key lives in a TEE", not as
 * "bootloader is locked".
 */

/** @param {string[]} base64Certs leaf first, root last */
export function parseChain (base64Certs) {
  if (!Array.isArray(base64Certs) || base64Certs.length === 0) return []
  const out = []
  for (const entry of base64Certs.slice(0, 8)) {
    if (typeof entry !== 'string' || entry.length === 0) return []
    try {
      out.push(new X509Certificate(Buffer.from(entry, 'base64')))
    } catch {
      return []
    }
  }
  return out
}

/**
 * @param {{ chain: X509Certificate[], roots: X509Certificate[], now?: number }} input
 * @returns {{ ok: boolean, reason?: string }}
 */
export function verifyChain ({ chain, roots, now = Date.now() }) {
  if (!chain || chain.length === 0) return { ok: false, reason: 'empty_chain' }
  if (!roots || roots.length === 0) return { ok: false, reason: 'no_trusted_roots' }

  for (const cert of chain) {
    const from = Date.parse(cert.validFrom)
    const to = Date.parse(cert.validTo)
    if (!Number.isFinite(from) || !Number.isFinite(to)) return { ok: false, reason: 'bad_dates' }
    if (now < from) return { ok: false, reason: 'cert_not_yet_valid' }
    if (now > to) return { ok: false, reason: 'cert_expired' }
  }

  for (let i = 0; i < chain.length - 1; i += 1) {
    if (!chain[i].checkIssued(chain[i + 1])) return { ok: false, reason: 'broken_link' }
    let valid = false
    try {
      valid = chain[i].verify(chain[i + 1].publicKey)
    } catch {
      valid = false
    }
    if (!valid) return { ok: false, reason: 'bad_signature' }
  }

  const anchor = chain[chain.length - 1]
  const trusted = roots.some((root) => root.fingerprint256 === anchor.fingerprint256)
  if (!trusted) return { ok: false, reason: 'untrusted_root' }

  return { ok: true }
}

/** Proof of possession: the leaf key must sign the challenge the server issued. */
export function verifyProofOfPossession ({ leaf, challenge, signature }) {
  if (!leaf || typeof challenge !== 'string' || typeof signature !== 'string') return false
  try {
    const verifier = createVerify('sha256')
    verifier.update(challenge, 'utf8')
    verifier.end()
    return verifier.verify(leaf.publicKey, Buffer.from(signature, 'base64'))
  } catch {
    return false
  }
}

/** @param {string[]} pems */
export function rootsFromPem (pems) {
  const roots = []
  for (const pem of pems) {
    const matches = String(pem).match(/-----BEGIN CERTIFICATE-----[\s\S]+?-----END CERTIFICATE-----/g) ?? []
    for (const block of matches) {
      try {
        roots.push(new X509Certificate(block))
      } catch {
        // Ignore malformed anchors rather than trusting them.
      }
    }
  }
  return roots
}

`server/src/challenge.js`:

```js
import { randomBytes } from 'node:crypto'

/**
 * One shot nonces. A report is only accepted with a nonce the server issued and has
 * not seen before, which makes replaying a captured report useless.
 */
export class ChallengeStore {
  constructor ({ ttlMs = 120_000, max = 10_000 } = {}) {
    this.ttlMs = ttlMs
    this.max = max
    this.entries = new Map()
  }

  issue () {
    this.sweep()
    if (this.entries.size >= this.max) {
      // Refuse to grow without bound rather than evicting live challenges.
      return null
    }
    const nonce = randomBytes(16).toString('hex')
    this.entries.set(nonce, Date.now() + this.ttlMs)
    return nonce
  }

  /** Registers a caller supplied nonce. Used by tests and by migration paths. */
  remember (nonce, ttlMs = this.ttlMs) {
    if (typeof nonce !== 'string' || nonce.length !== 32) return false
    this.entries.set(nonce, Date.now() + ttlMs)
    return true
  }

  /** Returns true exactly once for a valid, unexpired nonce. */
  consume (nonce) {
    if (typeof nonce !== 'string' || nonce.length !== 32) return false
    const expiry = this.entries.get(nonce)
    if (expiry === undefined) return false
    this.entries.delete(nonce)
    return Date.now() <= expiry
  }

  sweep () {
    const now = Date.now()
    for (const [nonce, expiry] of this.entries) {
      if (expiry < now) this.entries.delete(nonce)
    }
  }

  get size () {
    return this.entries.size
  }
}

// Minimal DER reader. Only what certificate and attestation parsing needs.

export function readTLV (buf, offset) {
  if (offset + 2 > buf.length) throw new Error('truncated')
  const first = buf[offset]
  const cls = first >> 6
  const constructed = (first & 0x20) !== 0
  let tag = first & 0x1f
  let cursor = offset + 1

  if (tag === 0x1f) {
    tag = 0
    for (let i = 0; i < 4; i += 1) {
      if (cursor >= buf.length) throw new Error('truncated tag')
      const byte = buf[cursor]
      cursor += 1
      tag = (tag << 7) | (byte & 0x7f)
      if ((byte & 0x80) === 0) break
    }
  }

  if (cursor >= buf.length) throw new Error('truncated length')
  let length = buf[cursor]
  cursor += 1
  if (length & 0x80) {
    const bytes = length & 0x7f
    if (bytes === 0 || bytes > 4) throw new Error('bad length')
    length = 0
    for (let i = 0; i < bytes; i += 1) {
      if (cursor >= buf.length) throw new Error('truncated length')
      length = (length << 8) | buf[cursor]
      cursor += 1
    }
  }

  if (cursor + length > buf.length) throw new Error('truncated value')
  return { cls, constructed, tag, valueStart: cursor, valueEnd: cursor + length, end: cursor + length }
}

export function children (buf, node) {
  const out = []
  let cursor = node.valueStart
  while (cursor < node.valueEnd) {
    const child = readTLV(buf, cursor)
    out.push(child)
    cursor = child.end
  }
  return out
}

export function bytes (buf, node) {
  return buf.subarray(node.valueStart, node.valueEnd)
}

export function toInt (buf, node) {
  let value = 0
  for (const byte of bytes(buf, node)) value = (value << 8) | byte
  return value
}

export function parse (der) {
  return readTLV(der, 0)
}

```js
import { children, parse, bytes, readTLV, toInt } from './der.js'

// Android Key Attestation extension: 1.3.6.1.4.1.11129.2.1.17
const OID = Buffer.from('2b06010401d679020111', 'hex')

const VERIFIED_BOOT_STATE = { 0: 'verified', 1: 'self_signed', 2: 'unverified', 3: 'failed' }

/**
 * Pulls the attestation extension out of a certificate.
 * @param {Buffer} der raw certificate bytes
 * @returns {Buffer|null} the extnValue content, which is a KeyDescription SEQUENCE
 */
export function findExtensionValue (der) {
  try {
    const certificate = parse(der)
    const tbs = children(der, certificate)[0]
    if (!tbs) return null

    const candidates = children(der, tbs)
    const container = candidates.find((node) => node.cls === 2 && node.tag === 3 && node.constructed)
    if (!container) return null

    const list = children(der, container)[0]
    if (!list) return null

    for (const extension of children(der, list)) {
      const parts = children(der, extension)
      if (parts.length < 2) continue
      if (!bytes(der, parts[0]).equals(OID)) continue
      const value = parts[parts.length - 1]
      if (value.cls !== 0 || value.tag !== 4) return null
      return Buffer.from(bytes(der, value))
    }
    return null
  } catch {
    return null
  }
}

/**
 * KeyDescription ::= SEQUENCE {
 *   attestationVersion INTEGER, attestationSecurityLevel ENUMERATED,
 *   keymasterVersion INTEGER, keymasterSecurityLevel ENUMERATED,
 *   attestationChallenge OCTET STRING, uniqueId OCTET STRING,
 *   softwareEnforced AuthorizationList, teeEnforced AuthorizationList }
 *
 * Only the fields that matter for a cheat decision are surfaced.
 */
export function parseKeyDescription (der) {
  const root = readTLV(der, 0)
  if (root.cls !== 0 || root.tag !== 0x10) throw new Error('not a sequence')
  const fields = children(der, root)
  if (fields.length < 8) throw new Error('short key description')

  const result = {
    attestationVersion: toInt(der, fields[0]),
    attestationSecurityLevel: toInt(der, fields[1]),
    keymasterVersion: toInt(der, fields[2]),
    keymasterSecurityLevel: toInt(der, fields[3]),
    challenge: bytes(der, fields[4]).toString('utf8'),
    verifiedBootState: null,
    deviceLocked: null,
    verifiedBootHash: null
  }

  const teeEnforced = fields[fields.length - 1]
  for (const item of children(der, teeEnforced)) {
    if (item.cls !== 2) continue
    const inner = children(der, item)[0]
    if (!inner) continue

    if (item.tag === 503) result.verifiedBootState = toInt(der, inner)
    if (item.tag === 704) result.deviceLocked = bytes(der, inner)[0] !== 0
    if (item.tag === 705) result.verifiedBootHash = Buffer.from(bytes(der, inner)).toString('hex')
  }

  result.bootStateName = result.verifiedBootState === null
    ? 'unknown'
    : VERIFIED_BOOT_STATE[result.verifiedBootState] ?? 'unknown'
  return result
}

export function inspectCertificate (cert) {
  const extension = findExtensionValue(cert.raw)
  if (!extension) return null
  try {
    return parseKeyDescription(extension)
  } catch {
    return null
  }
}

`server/src/ratelimit.js`:

```js
/**
 * Fixed window rate limiter. Enough to blunt scripted abuse; put real limiting in
 * front of this if you expose the endpoint to the internet.
 */
export class RateLimiter {
  constructor ({ limit = 60, windowMs = 60_000 } = {}) {
    this.limit = limit
    this.windowMs = windowMs
    this.buckets = new Map()
  }

  allow (key) {
    const now = Date.now()
    const bucket = this.buckets.get(key)
    if (!bucket || now >= bucket.resetAt) {
      this.buckets.set(key, { count: 1, resetAt: now + this.windowMs })
      if (this.buckets.size > 10_000) this.prune(now)
      return true
    }
    if (bucket.count >= this.limit) return false
    bucket.count += 1
    return true
  }

  prune (now = Date.now()) {
    for (const [key, bucket] of this.buckets) {
      if (now >= bucket.resetAt) this.buckets.delete(key)
    }
  }
}

```js
// Scoring lives on the server on purpose. The client sends observations, never a verdict,
// and the weight field it reports is ignored.

export const WEIGHTS = {
  'frida.maps': 90,
  'frida.module': 80,
  'frida.thread': 85,
  'frida.port': 70,
  'frida.anon_exec': 25,
  'root.paths': 60,
  'root.mounts': 45,
  'root.props': 35,
  'debug.tracer': 50,
  'integrity.self_hash': 95,
  'integrity.symbol_hook': 95,
  'integrity.signature': 90,
  'integrity.memory_text': 95,
  'instrumentation.inconsistent': 70,
  'emulator.host': 20,
  'app.debuggable': 15
}

const UNKNOWN_WEIGHT = 10
const MAX_FINDINGS = 64

/**
 * @param {unknown} findings
 * @returns {{ id: string, weight: number, known: boolean }[]}
 */
export function normaliseFindings (findings) {
  if (!Array.isArray(findings)) return []
  const seen = new Set()
  const out = []
  for (const raw of findings.slice(0, MAX_FINDINGS)) {
    if (!raw || typeof raw !== 'object') continue
    const id = typeof raw.id === 'string' ? raw.id.slice(0, 64) : ''
    if (!id || seen.has(id)) continue
    seen.add(id)
    const known = Object.prototype.hasOwnProperty.call(WEIGHTS, id)
    out.push({ id, weight: known ? WEIGHTS[id] : UNKNOWN_WEIGHT, known })
  }
  return out
}

export function scoreReport (findings) {
  const normalised = normaliseFindings(findings)
  const score = normalised.reduce((total, item) => total + item.weight, 0)
  return { score, findings: normalised }
}

/**
 * Thresholds are deliberately generous. A single medium finding should never ban anyone.
 * @param {number} score
 */
export function decide (score) {
  if (score >= 100) return 'block'
  if (score >= 50) return 'review'
  if (score >= 20) return 'watch'
  return 'clean'
}

```js
import { createHmac, timingSafeEqual } from 'node:crypto'

/**
 * HMAC over the exact bytes received. This only stops casual spam: a determined
 * attacker has the secret inside the APK. Never treat it as a trust boundary.
 *
 * @param {Buffer|string} rawBody
 * @param {string} signature hex digest from the X-Sonekk-Signature header
 * @param {string} secret
 */
export function verifySignature (rawBody, signature, secret) {
  if (!signature || !secret) return false
  const expected = createHmac('sha256', Buffer.from(secret, 'utf8'))
    .update(rawBody)
    .digest('hex')

  const provided = String(signature).trim().toLowerCase()
  if (provided.length !== expected.length) return false

  try {
    return timingSafeEqual(Buffer.from(expected, 'hex'), Buffer.from(provided, 'hex'))
  } catch {
    return false
  }
}

# Test fixtures

These keys and certificates are throwaway, generated with OpenSSL purely so the
attestation tests can prove chain validation works:

- `root.pem` / `root.key` - trusted test CA
- `leaf.pem` / `leaf.key` - leaf certificate used to sign the challenge
- `other-root.pem` / `other-root.key` - a CA that is not trusted, used to prove
  that an untrusted anchor is rejected

They protect nothing. Never treat them as secrets, and never reuse them.

- `attested-leaf.pem` / `attested-leaf.key` - leaf carrying a synthetic Android key
  attestation extension: verified boot, device locked, challenge `0123456789abcdef0123456789abcdef`
- `unlocked-leaf.pem` / `unlocked-leaf.key` - same, but boot state unverified and device unlocked
- `ext.cnf` / `ext-unlocked.cnf` - openssl extension files used to build those two certificates

// Builds the DER blob for an Android KeyDescription extension, used to create a
// realistic certificate fixture. Run: node tools/make-attestation-fixture.mjs
//
// KeyDescription ::= SEQUENCE {
//   attestationVersion INTEGER, attestationSecurityLevel ENUMERATED,
//   keymasterVersion INTEGER, keymasterSecurityLevel ENUMERATED,
//   attestationChallenge OCTET STRING, uniqueId OCTET STRING,
//   softwareEnforced AuthorizationList, teeEnforced AuthorizationList }

const OID_KEY_ATTESTATION = Buffer.from('2b06010401d679020111', 'hex')

function tlv (tag, content) {
  const body = Buffer.isBuffer(content) ? content : Buffer.concat(content)
  const length = body.length
  let header
  if (length < 0x80) {
    header = Buffer.from([tag, length])
  } else if (length < 0x100) {
    header = Buffer.from([tag, 0x81, length])
  } else {
    header = Buffer.from([tag, 0x82, length >> 8, length & 0xff])
  }
  return Buffer.concat([header, body])
}

function uintToBytes (value) {
  const out = []
  let v = value
  do {
    out.unshift(v & 0xff)
    v = Math.floor(v / 128)
  } while (v > 0)
  return Buffer.from(out)
}

const integer = (value) => tlv(0x02, uintToBytes(value))
const enumerated = (value) => tlv(0x0a, uintToBytes(value))
const boolean = (value) => tlv(0x01, Buffer.from([value ? 0xff : 0x00]))
const octets = (buf) => tlv(0x04, buf)
const sequence = (items) => tlv(0x30, items)

// Context specific, constructed, explicit tagging. High tag numbers use base 128
// with the continuation bit set on every byte but the last.
const tagBytes = (tag) => {
  const out = [tag & 0x7f]
  let value = Math.floor(tag / 128)
  while (value > 0) {
    out.unshift((value & 0x7f) | 0x80)
    value = Math.floor(value / 128)
  }
  return Buffer.from(out)
}

const explicit = (tag, inner) => {
  const first = Buffer.concat([Buffer.from([0xbf]), tagBytes(tag)])
  const body = Buffer.concat([inner])
  if (body.length < 0x80) return Buffer.concat([first, Buffer.from([body.length]), body])
  if (body.length < 0x100) return Buffer.concat([first, Buffer.from([0x81, body.length]), body])
  return Buffer.concat([first, Buffer.from([0x82, body.length >> 8, body.length & 0xff]), body])
}

export function buildKeyDescription ({ challenge, verifiedBootState = 0, deviceLocked = true }) {
  const teeEnforced = sequence([
    explicit(503, enumerated(verifiedBootState)),
    explicit(704, boolean(deviceLocked)),
    explicit(705, octets(Buffer.alloc(32, 0x11)))
  ])

  return sequence([
    integer(3),
    enumerated(1),
    integer(4),
    enumerated(1),
    octets(Buffer.from(challenge, 'utf8')),
    octets(Buffer.alloc(0)),
    sequence([]),
    teeEnforced
  ])
}

export { OID_KEY_ATTESTATION }

const arg = (name, fallback) => {
  const index = process.argv.indexOf('--' + name)
  return index === -1 ? fallback : process.argv[index + 1]
}

if (process.argv[1]?.endsWith('make-attestation-fixture.mjs')) {
  const extension = buildKeyDescription({
    challenge: arg('challenge', '0123456789abcdef0123456789abcdef'),
    verifiedBootState: Number(arg('state', '0')),
    deviceLocked: arg('locked', 'true') !== 'false'
  })
  console.log(extension.toString('hex'))
}

using System;
using System.Collections;
using System.Text;
using UnityEngine;
using UnityEngine.Networking;

namespace Sonekk.Guard
{
    /// <summary>
    /// Drop this on a single GameObject in your first scene. It asks the server for a single
    /// use challenge, collects a report off the main thread, signs it, and posts it.
    /// </summary>
    public class GuardRunner : MonoBehaviour
    {
        [SerializeField] private GuardSettings settings;
        [SerializeField] private string pinnedSignatureSha256 = "";
        [SerializeField] private string playerId = "";

        [Serializable]
        private class ChallengeResponse
        {
            public string nonce;
        }

        private void Start()
        {
            if (settings == null)
            {
                Debug.LogWarning("[Sonekk Guard] No settings asset assigned, guard is idle.");
                return;
            }

            if (!SonekkGuard.IsAvailable)
            {
                Debug.Log("[Sonekk Guard] Native library missing, guard is inactive on this platform.");
                return;
            }

            if (settings.reportOnStart) StartCoroutine(CollectAndSend());

            if (settings.reportIntervalSeconds > 0)
            {
                InvokeRepeating(nameof(StartReport), settings.reportIntervalSeconds, settings.reportIntervalSeconds);
            }
        }

        private void StartReport()
        {
            StartCoroutine(CollectAndSend());
        }

        private IEnumerator CollectAndSend()
        {
            var endpoint = settings.endpoint == null ? "" : settings.endpoint.TrimEnd('/');
            var nonce = "";

            if (!string.IsNullOrEmpty(endpoint))
            {
                using var challengeRequest = new UnityWebRequest(endpoint + "/v1/challenge", "POST");
                challengeRequest.downloadHandler = new DownloadHandlerBuffer();
                challengeRequest.timeout = 10;
                yield return challengeRequest.SendWebRequest();

                if (challengeRequest.result == UnityWebRequest.Result.Success)
                {
                    var parsed = JsonUtility.FromJson<ChallengeResponse>(challengeRequest.downloadHandler.text);
                    if (parsed != null && !string.IsNullOrEmpty(parsed.nonce)) nonce = parsed.nonce;
                }
                else
                {
                    Debug.LogWarning("[Sonekk Guard] Could not get a challenge: " + challengeRequest.error);
                }
            }

            var debuggable = SonekkGuard.IsDebuggable();
            var signatureOk = SonekkGuard.SignatureMatches(pinnedSignatureSha256);
            var expectedHash = settings.expectedLibraryHash;

            var task = System.Threading.Tasks.Task.Run(
                () => SonekkGuard.Collect(expectedHash, signatureOk, debuggable));
            while (!task.IsCompleted) yield return null;

            if (task.Exception != null)
            {
                Debug.LogWarning("[Sonekk Guard] Collection failed: " + task.Exception.Message);
                yield break;
            }

            var report = task.Result;
            if (string.IsNullOrEmpty(report)) yield break;

            if (string.IsNullOrEmpty(endpoint))
            {
                Debug.Log("[Sonekk Guard] " + report);
                yield break;
            }

            var attestation = settings.requestAttestation && nonce.Length > 0
                ? SonekkGuard.RequestAttestation(nonce)
                : null;

            var payload = BuildPayload(report, nonce, playerId, attestation);

            using var request = new UnityWebRequest(endpoint + "/v1/report", "POST");
            request.uploadHandler = new UploadHandlerRaw(Encoding.UTF8.GetBytes(payload));
            request.downloadHandler = new DownloadHandlerBuffer();
            request.SetRequestHeader("Content-Type", "application/json");
            request.SetRequestHeader("X-Sonekk-Signature", SonekkGuard.Sign(payload, settings.apiKey));
            request.timeout = 15;

            yield return request.SendWebRequest();

            if (request.result != UnityWebRequest.Result.Success)
            {
                Debug.LogWarning("[Sonekk Guard] Report rejected: " + request.error);
                yield break;
            }

            var response = GuardReport.Parse(request.downloadHandler.text);
            if (response != null && response.verdict == "block")
            {
                // Your game decides what a block means. Never ban from the client.
                Debug.LogWarning("[Sonekk Guard] Server returned block for this session.");
            }
        }

        private static string BuildPayload(string report, string nonce, string player, string attestation)
        {
            var body = report.EndsWith("}") ? report.Substring(0, report.Length - 1) : report;
            var builder = new StringBuilder(body);

            if (!string.IsNullOrEmpty(nonce))
            {
                builder.Append(",\"nonce\":\"").Append(JsonSafe(nonce)).Append('"');
            }

            if (!string.IsNullOrEmpty(player))
            {
                builder.Append(",\"player\":\"").Append(JsonSafe(player)).Append('"');
            }

            if (!string.IsNullOrEmpty(attestation))
            {
                builder.Append(",\"attestation\":").Append(attestation);
            }

            builder.Append('}');
            return builder.ToString();
        }

        private static string JsonSafe(string value)
        {
            return value.Replace("\\", "\\\\").Replace("\"", "\\\"");
        }
    }
}

```cs
using System;
using System.Runtime.InteropServices;
using System.Security.Cryptography;
using System.Text;
using UnityEngine;

namespace Sonekk.Guard
{
    /// <summary>
    /// Native detection bridge. Only Android builds ship libsonekk_guard.so, so every
    /// other platform returns null and the game keeps working untouched.
    /// </summary>
    public static class SonekkGuard
    {
#if UNITY_ANDROID && !UNITY_EDITOR
        [DllImport("sonekk_guard")]
        private static extern IntPtr sonekk_guard_analyze(string configJson);

        [DllImport("sonekk_guard")]
        private static extern void sonekk_guard_free(IntPtr pointer);

        [DllImport("sonekk_guard")]
        private static extern IntPtr sonekk_guard_version;
#endif

        public static bool IsAvailable
        {
            get
            {
#if UNITY_ANDROID && !UNITY_EDITOR
                return true;
#else
                return false;
#endif
            }
        }

        /// <summary>Runs every check and returns the raw report JSON, or null when unsupported.</summary>
        public static string Collect(string expectedLibraryHash = "", bool signatureOk = true, bool debuggable = false)
        {
#if UNITY_ANDROID && !UNITY_EDITOR
            var config = "{\"expectedSelfHash\":\"" + Escape(expectedLibraryHash) + "\",\"signatureOk\":"
                         + (signatureOk ? "true" : "false")
                         + ",\"debuggable\":" + (debuggable ? "true" : "false") + "}";
            var pointer = sonekk_guard_analyze(config);
            if (pointer == IntPtr.Zero) return null;
            try
            {
                return Marshal.PtrToStringAnsi(pointer);
            }
            finally
            {
                sonekk_guard_free(pointer);
            }
#else
            return null;
#endif
        }

        public static string Version
        {
            get
            {
#if UNITY_ANDROID && !UNITY_EDITOR
                var pointer = sonekk_guard_version;
                return pointer == IntPtr.Zero ? "0.0.0" : Marshal.PtrToStringAnsi(pointer);
#else
                return "unavailable";
#endif
            }
        }


        /// <summary>
        /// Asks the TEE for a certified key bound to the challenge and signs it.
        /// Returns {"chain":[...],"signature":"..."} or null when unsupported.
        /// This is the only proof a rooted device cannot fabricate, because the key
        /// never leaves the secure element.
        /// </summary>
        public static string RequestAttestation(string challenge)
        {
#if UNITY_ANDROID && !UNITY_EDITOR
            if (string.IsNullOrEmpty(challenge)) return null;

            const string alias = "sonekk_guard_attestation";
            const int purposeSign = 6;

            try
            {
                using var keyStoreClass = new AndroidJavaClass("java.security.KeyStore");
                using var keyStore = keyStoreClass.CallStatic<AndroidJavaObject>("getInstance", "AndroidKeyStore");
                keyStore.Call("load", new object[] { null });

                using var generatorClass = new AndroidJavaClass("java.security.KeyPairGenerator");
                using var generator = generatorClass.CallStatic<AndroidJavaObject>("getInstance", "EC", "AndroidKeyStore");

                using var properties = new AndroidJavaClass("android.security.keystore.KeyProperties");
                var digest = properties.GetStatic<string>("DIGEST_SHA256");

                using var builder = new AndroidJavaObject("android.security.keystore.KeyGenParameterSpec$Builder", alias, purposeSign);
                builder.Call<AndroidJavaObject>("setDigests", digest);
                builder.Call<AndroidJavaObject>("setAttestationChallenge", Encoding.UTF8.GetBytes(challenge));

                using var spec = builder.Call<AndroidJavaObject>("build");
                generator.Call("initialize", spec);
                generator.Call<AndroidJavaObject>("generateKeyPair");

                using var chain = keyStore.Call<AndroidJavaObject>("getCertificateChain", alias);
                var count = chain.Call<int>("size");
                if (count <= 0) return null;

                var parts = new StringBuilder();
                for (var i = 0; i < count; i += 1)
                {
                    using var certificate = chain.Call<AndroidJavaObject>("get", i);
                    var encoded = certificate.Call<byte[]>("getEncoded");
                    if (encoded == null) continue;
                    if (parts.Length > 0) parts.Append(',');
                    parts.Append('"').Append(Convert.ToBase64String(encoded)).Append('"');
                }

                using var privateKey = keyStore.Call<AndroidJavaObject>("getKey", alias, null);
                using var signatureClass = new AndroidJavaClass("java.security.Signature");
                using var signature = signatureClass.CallStatic<AndroidJavaObject>("getInstance", "SHA256withECDSA");
                signature.Call("initSign", privateKey);
                signature.Call("update", Encoding.UTF8.GetBytes(challenge));
                var signed = signature.Call<byte[]>("sign");

                return "{\"chain\":[" + parts + "],\"signature\":\"" + Convert.ToBase64String(signed) + "\"}";
            }
            catch (Exception exception)
            {
                Debug.LogWarning("[Sonekk Guard] Attestation unavailable: " + exception.Message);
                return null;
            }
#else
            return null;
#endif
        }

        /// <summary>True when the APK was built with android:debuggable, a strong signal it is a repack.</summary>
        public static bool IsDebuggable()
        {
#if UNITY_ANDROID && !UNITY_EDITOR
            try
            {
                using var player = new AndroidJavaClass("com.unity3d.player.UnityPlayer");
                using var activity = player.GetStatic<AndroidJavaObject>("currentActivity");
                using var info = activity.Call<AndroidJavaObject>("getApplicationInfo");
                var flags = info.Get<int>("flags");
                return (flags & 0x2) != 0;
            }
            catch (Exception)
            {
                return false;
            }
#else
            return false;
#endif
        }

        /// <summary>Compares the installed APK signature with the one pinned at build time.</summary>
        public static bool SignatureMatches(string expectedSha256)
        {
            if (string.IsNullOrEmpty(expectedSha256)) return true;
#if UNITY_ANDROID && !UNITY_EDITOR
            try
            {
                using var player = new AndroidJavaClass("com.unity3d.player.UnityPlayer");
                using var activity = player.GetStatic<AndroidJavaObject>("currentActivity");
                using var packageManager = activity.Call<AndroidJavaObject>("getPackageManager");
                var packageName = activity.Call<string>("getPackageName");
                using var info = packageManager.Call<AndroidJavaObject>("getPackageInfo", packageName, 0x40);
                using var signatures = info.Get<AndroidJavaObject>("signatures");
                var signature = signatures.Get<AndroidJavaObject>(0).Call<byte[]>("toByteArray");

                using var sha = SHA256.Create();
                var digest = sha.ComputeHash(signature);
                var builder = new StringBuilder(digest.Length * 2);
                foreach (var b in digest) builder.Append(b.ToString("x2"));
                return string.Equals(builder.ToString(), expectedSha256, StringComparison.OrdinalIgnoreCase);
            }
            catch (Exception)
            {
                // Unreadable package info is treated as untrusted, not as a crash.
                return false;
            }
#else
            return true;
#endif
        }

        public static string Sign(string payload, string secret)
        {
            if (string.IsNullOrEmpty(secret)) return "";
            using var hmac = new HMACSHA256(Encoding.UTF8.GetBytes(secret));
            var hash = hmac.ComputeHash(Encoding.UTF8.GetBytes(payload));
            var builder = new StringBuilder(hash.Length * 2);
            foreach (var b in hash) builder.Append(b.ToString("x2"));
            return builder.ToString();
        }

        private static string Escape(string value)
        {
            if (string.IsNullOrEmpty(value)) return "";
            return value.Replace("\\", "\\\\").Replace("\"", "\\\"");
        }
    }
}
