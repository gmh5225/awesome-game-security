`CLAUDE.md`:

```md
# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

INF Studio is a native Windows (C++20, WTL) GUI for viewing and editing driver installation (INF) files. It shows the INF text in a Scintilla editor next to a tree that breaks down its sections (Version, Manufacturer/Models, AddReg, CopyFiles, ...). Its UI follows the author's other WTL tools (e.g. AstroStudio), all built on the shared `WTLHelper` library.

## Build

Visual Studio solution (`InfStudio.sln`), toolset v145 (VS 18: `C:\Program Files\Microsoft Visual Studio\18\Enterprise\MSBuild\Current\Bin\amd64\MSBuild.exe`), `stdcpp20`, static CRT (`/MT`, `/MTd`) everywhere:

```
msbuild InfStudio.sln /p:Configuration=Debug /p:Platform=x64 /m
msbuild InfStudio.sln /p:Configuration=Release /p:Platform=x64 /m
```

- x64 is the platform that matters; the solution's ARM64 maps to x64.
- Dependencies come from vcpkg's user-wide integration (no manifest in the repo). `InfStudio.vcxproj` sets `VcpkgUseStatic`, so it takes the `x64-windows-static` triplet: `scintilla`, `lexilla` (both only installed static), plus `detours` and `wil` that WTLHelper uses. Static Scintilla needs `imm32` (linked by a `#pragma comment` in `InfStudio.cpp`).
- WTL comes from the headers vendored in `WTLHelper\WTL` (on the include path). Nothing uses NuGet anymore.
- `WTLHelper` is a git submodule (`git submodule update --init`). It is the author's shared library with its own repo and its own `CLAUDE.md`, so changes there are a commit inside the submodule and affect other apps.
- `DumpInf` is a console app that prints an INF's version info and sections through `InfCore` (no argument: the master INF). The GUI accepts INF paths on its command line, which makes it easy to launch on a file.

### Tests

`InfStudio.Tests` is a Catch2 v3 console project (x64, Debug and Release). Catch2 comes from vcpkg's static triplet with auto-linking off, so the project lists the libraries it links (Catch2 and Lexilla). It compiles `InfLexer.cpp` and `TextFile.cpp` from `InfStudio/` directly and links `InfCore`. Build the solution, then run:

```
x64\Debug\InfStudio.Tests.exe              # all tests; exit code 0 when everything passes
x64\Debug\InfStudio.Tests.exe [lexer]      # by tag: [lexer], [scintilla], [textfile], [inffile]
x64\Debug\InfStudio.Tests.exe "Strings"    # one test case by name
```

- `InfLexerTests.cpp` checks `InfLexer::StyleLine` with one letter per byte (`.` default, `c` comment, `S` section, `k` key, `o` operator, `s` string, `t` string key, `n` number), so an expected value lines up under its line. The `[scintilla]` tests run the real lexer (`InfLexer::Create`) over a `FakeDocument` (an `IDocument` on a string). They cover what only the Scintilla side does: line ends, the continuation in the line state, lexing from the middle of a document.
- `TextFileTests.cpp` and `InfFileTests.cpp` work on files in the temporary directory (`TempFile` in `TestCommon.h`). `InfFile` is tested through the real SetupAPI. Expectations that depend on the ANSI code page run only under code page 1252.
- `InfTemplatesTests.cpp` generates every template and checks it: placeholders filled, CRLF, ASCII, SetupAPI opens it, every `%strkey%` it uses (found with the lexer) is in `[Strings]`, and the Manufacturer's models sections exist. The `[infverif]` test runs the WDK's `infverif.exe /w` (Windows Driver requirements) on each and is skipped when the WDK isn't installed. A new or changed template must pass it.
- Keep the test sources ASCII (use `\u` escapes): they have no BOM, so MSVC reads them in the ANSI code page.

## Architecture

Projects in the solution:

- **InfCore** (static lib): `InfFile` wraps the SetupAPI INF parser (`SetupOpenInfFile`, `SetupFindFirstLine`, `SetupEnumInfSections`, ...). All INF parsing goes through SetupAPI; there is no custom parser, so a parse error is only a SetupAPI error line number.
- **InfStudio** (GUI exe): depends on InfCore and WTLHelper, and on Scintilla/Lexilla from vcpkg (`<scintilla/...>`, `<lexilla/...>` in `pch.h`). Lexilla's own lexers aren't used: the stock "props" lexer doesn't know INF syntax.
- **DumpInf** (console exe): depends on InfCore.

How the GUI is put together:

- `wWinMain` (`InfStudio.cpp`) loads `AppSettings` from the registry (`AppSettings::RegistryKey`, HKCU) before any window exists, starts dark mode (`WTLHelper::InitDarkMode`: the saved choice, or the system's while `DarkMode` is -1), registers Scintilla's window classes, and restores the main window's saved placement. `CMainFrame::OnDestroy` saves the settings.
- `CMainFrame` (`MainFrm.*`) is the frame: rebar tool bar (`ToolbarHelper`), status bar, and a `CNativeCustomTabView` with one `CMainView` per file. Each page's data is the view's `IView*` (`ViewOfPage`); closing a tab, Close All and closing the app ask each view's `CanClose`. Views reach the frame only through `IMainFrame` (`Interfaces.h`). Menu icons are set with `WTLHelper::InitMenu`, again after a mode switch and for every context menu (`TrackPopupMenu`), since the bitmaps are drawn for the current background.
- Dark mode: Options > Dark Mode calls `WTLHelper::SwitchToMode`, which themes the standard controls and sends the registered `WTLHelper::ThemeChangedMessage` to every descendant. Scintilla draws itself, so `CInfView` handles that message and re-applies its own light/dark palette and scroll-bar theme (`ApplyColors`). A window that paints itself needs the same. Wrap common dialogs (file open/save) in `WTLHelper::SuspendHook`/`ResumeHook`.
- `CViewBase<T>` (`ViewBase.h`) is the base for tab views: a `CFrameWindowImpl` child that deletes itself in `OnFinalMessage`, forwards `WM_FORWARDMSG` to `PreTranslateMessage` and calls `T::OnActivated` when its tab is activated. Commands the frame doesn't handle itself go to the active page.
- `CMainView` holds a splitter with a tree (`CTreeViewHelper`) on the left and, on the right, a horizontal splitter (`m_EditSplitter`) with a `CInfView` (Scintilla via `ScintillaCtrl.h`) above the InfVerif results list (`m_Results`, hidden until the first validation). In `ScintillaCtrl.h` only the methods with inline bodies exist; the rest are declarations without definitions, so call `Execute(SCI_...)` for anything else. `BuildTree`/`AnalyzeAndBuild` open the file through `InfFile` and fill the tree. A models section's install sections come from `InfFile::GetInstallDirectives`, which looks at every platform decoration Windows chooses from (`X`, `X.NT`, `X.NTamd64`, `X.NTarm64`...) and each one's `.HW` section. Each tree item stores a `NodeType`, and its icon is a `TreeIconIndex`, so a new kind of known section means adding to both enums and the image list. The analysis always reads the file on disk, not the editor buffer: `BuildTree` skips it while the editor has unsaved changes, and Refresh (`ID_VIEW_REFRESH`) saves the file before it rebuilds the tree.
- Syntax highlighting is the app's own lexer, `InfLexer` (`InfLexer.*`): `InfLexer::StyleLine` styles one line (no window needed), and a Lexilla `LexerModule` (`InfLexer::Create`) runs it over whole lines, keeping in each line's state whether the line ends with a `\` continuation (the next line then has no key). Its styles (`InfLexer::Style`) are what `CInfView::ApplyColors` colors; a new style needs a color in both palettes there. A `;` is a comment only outside quotes, `""` is a quote in a string, `%%` a literal percent.
- Text encoding: the editor's document is always UTF-8 (`SCI_SETCODEPAGE`). `TextFile` (`TextFile.*`) loads a file as UTF-8 and saves it back in its own encoding (`TextEncoding`: ANSI without a BOM, UTF-8 or UTF-16 LE with one); `CMainView::ConfirmEncoding` asks to switch an ANSI file to UTF-16 when it has characters the ANSI code page lacks. Text sent to Scintilla (find, section lookup) must be UTF-8 (`TextFile::ToUtf8`), never `CStringA`.
- Find and Replace: `EditorSearch` (`EditorSearch.*`) searches the editor from the selection, wraps around once and selects the match (F3 / Shift+F3 repeat the last search down or up), and Replace All is one undo action. `CMainView` keeps the last search (`m_SearchText`, `m_Search`). `CMainFrame::PreTranslateMessage` gives keys for another top-level window (the modeless Find dialog) to it before the frame's accelerators, which would otherwise turn Ctrl+V in its text box into Paste in the editor.
- INF > Validate (F7, `/w`) and Validate for WHQL (`/h`): `InfVerif` (`InfVerif.*`) finds the newest WDK's `infverif.exe`, runs it without a console window and parses its `ERROR(code) in path, line N: text` lines. `CMainView::Validate` writes the editor's text (saved or not) to a temporary file of the same name, and `ShowResults` fills the list and squiggles the lines (`CInfView::ShowProblems`). Enter or a double-click on a problem goes to its line.
- File > New from Template: the templates are data in `InfTemplates.cpp` (`InfTemplates::All()`; text with `@DATE@` and `@GUID@` placeholders that `Generate` fills with today's date and a new GUID). `CMainFrame::AddTemplatesMenu` builds the submenu from that list at startup (command IDs from `ID_TEMPLATE_FIRST`, a separator between `Group`s), so adding a template is adding an entry. They target Windows 10 1709 (`10.0...16299`; UMDF from the driver store needs 1803, `10.0...17134`) on amd64 and arm64, and copy their files to `DIRID 13`. `CMainView::NewFromText` opens the text as a new file: it has no path and counts as unsaved (`m_Unsaved`, part of `IsDirty`) until Save As writes it, since the editor's own modified flag is clear after `EmptyUndoBuffer`.
- `AppSettings` uses WTLHelper's `Settings` macros. A new setting needs both its `SETTING` entry and its `DEF_SETTING` accessor.
- Precompiled headers: each project has its own `pch.h`, which every `.cpp` must include first.
```

```cpp
#include "pch.h"
#include "..\InfCore\InfFile.h"

int wmain(int argc, wchar_t const* argv[]) {
	InfFile inf;
	bool ok;
	if (argc < 2) {
		printf("Opening master INF...\n");
		ok = inf.OpenMaster();
	}
	else {
		printf("Opening %ws...\n", argv[1]);
		ok = inf.Open(argv[1]);
	}

	if (!ok) {
		printf("Failed to open file\n");
		return 1;
	}

	int count = inf.GetFileCount();
	printf("File count: %d\n", count);

	for (int i = 0; i < count; ++i) {
		printf("Version info: \n");
		for (auto& [key, value] : inf.GetVersionSectionInfo(nullptr, i)) {
			printf("%ws = %ws\n", key.c_str(), value.c_str());
		}

		printf("Sections:\n");
		for (auto const& sec : inf.GetSectionNames()) {
			printf("\t%ws\n", sec.c_str());

		}

		//printf("Sections (original text):\n");
```

```cpp
std::vector<std::pair<std::wstring, std::wstring>> InfFile::GetVersionSectionInfo(PCWSTR key, UINT fileIndex) const {
	if (!m_info)
		return {};
	DWORD size = 0;
	::SetupQueryInfVersionInformation(m_info, fileIndex, key, nullptr, 0, &size);
	if (size == 0)
		return {};
	auto buffer = std::make_unique<WCHAR[]>(size);
	if (!::SetupQueryInfVersionInformation(m_info, fileIndex, key, buffer.get(), size, nullptr))
		return {};

	std::vector<std::pair<std::wstring, std::wstring>> result;
	for (auto p = buffer.get(); *p; p += wcslen(p) + 1) {
		auto q = p + wcslen(p) + 1;
		result.push_back({ p, q });
		p = q;
	}
	return result;
}

std::vector<std::wstring> InfFile::GetSectionNames() const {
	std::array<WCHAR, 256> name;
	std::vector<std::wstring> names;
	for (UINT i = 0;; i++) {
		if (!::SetupEnumInfSections(m_inf, i, name.data(), (UINT)name.size(), nullptr))
			break;
		names.emplace_back(name.data());
	}
	return names;
}

std::vector<std::pair<std::wstring, std::wstring>> InfFile::GetSectionCompactLines(PCWSTR section) const {
	INFCONTEXT ctx;
	std::vector<std::pair<std::wstring, std::wstring>> lines;
	WCHAR keyname[64];
	if (::SetupFindFirstLine(m_inf, section, nullptr , &ctx)) {
		WCHAR text[256];
		do {
			auto hasKey = ::SetupGetStringField(&ctx, 0, keyname, _countof(keyname), nullptr);
			if (::SetupGetLineText(&ctx, m_inf, section, hasKey ? keyname : nullptr, text, _countof(text), nullptr))
				lines.emplace_back(std::pair{ hasKey ? keyname : L"", text });
		} while (::SetupFindNextLine(&ctx, &ctx));
	}
	return lines;
}

std::vector<std::pair<std::wstring, std::wstring>> InfFile::GetSectionLines(PCWSTR section) const {
	auto count = ::SetupGetLineCount(m_inf, section);
	std::vector<std::pair<std::wstring, std::wstring>> lines;
	lines.reserve(count);
	INFCONTEXT ctx;
	WCHAR text[400], key[128];
	for (int i = 0; i < count; i++) {
		if (::SetupGetLineByIndex(m_inf, section, i, &ctx)) {
			auto hasKey = ::SetupGetStringField(&ctx, 0, key, _countof(key), nullptr);
			if(::SetupGetLineText(&ctx, m_inf, section, nullptr, text, _countof(text), nullptr))
				lines.emplace_back(std::pair{ hasKey ? key : L"", text });
		}
	}
	return lines;
}

	INFCONTEXT ctx;
	return ::SetupFindFirstLine(m_inf, name, nullptr, &ctx);
}

namespace {
	std::wstring_view Trim(std::wstring_view text) noexcept {
		constexpr PCWSTR blanks = L" \t";
		auto first = text.find_first_not_of(blanks);
		if (first == std::wstring_view::npos)
			return {};
		return text.substr(first, text.find_last_not_of(blanks) - first + 1);
	}

	// the comma separated fields of a value, trimmed (empty ones included)
	std::vector<std::wstring_view> Fields(std::wstring_view value) {
		std::vector<std::wstring_view> fields;
		for (size_t pos = 0;;) {
			auto comma = value.find(L',', pos);
			fields.push_back(Trim(value.substr(pos, comma == std::wstring_view::npos ? std::wstring_view::npos : comma - pos)));
			if (comma == std::wstring_view::npos)
				break;
			pos = comma + 1;
		}
		return fields;
	}
}

std::vector<std::wstring> InfFile::InstallSectionNames(std::wstring_view installSection) {
	auto name = Trim(installSection);
	if (name.empty())
		return {};
	std::vector<std::wstring> names;
	for (auto decoration : { L"", L".NT", L".NTamd64", L".NTarm64", L".NTx86", L".NTarm", L".NTia64" }) {
		auto section = std::wstring(name) + decoration;
		names.push_back(section);
		names.push_back(section + L".HW");
	}
	return names;
}

std::vector<InstallDirective> InfFile::GetInstallDirectives(std::wstring_view installSection) const {
	std::vector<InstallDirective> directives;
	for (auto const& section : InstallSectionNames(installSection)) {
		for (auto directive : { L"CopyFiles", L"DelFiles", L"AddReg", L"DelReg" }) {
			for (auto const& [key, value] : GetSectionCompactLines(section.c_str())) {
				if (_wcsicmp(key.c_str(), directive) != 0)
					continue;
				for (auto target : Fields(value)) {
					auto exists = [&](InstallDirective const& d) {
						return d.Section == section && d.Directive == directive && _wcsicmp(d.Target.c_str(), std::wstring(target).c_str()) == 0;
					};
					// (empty fields name nothing; a target named twice counts once)
					if (!target.empty() && std::none_of(directives.begin(), directives.end(), exists))
						directives.push_back({ section, directive, std::wstring(target) });
				}
			}
		}
	}
	return directives;
}

std::vector<std::wstring> InfFile::GetModelSections(std::wstring_view value) {
	auto fields = Fields(value);
	auto name = fields[0];
	if (name.empty())
		return {};

	std::vector<std::wstring> sections;
	for (size_t i = 1; i < fields.size(); i++)
		if (!fields[i].empty())
			sections.push_back(std::wstring(name) + L'.' + std::wstring(fields[i]));
	// no decorations: the name is the section
	if (sections.empty())
		sections.emplace_back(name);
	return sections;
}

std::wstring InfFile::GetStringValue(PCWSTR section, PCWSTR key, UINT index) const {
	INFCONTEXT ctx;
	std::wstring value;
	if (::SetupFindFirstLine(m_inf, section, key, &ctx)) {
		WCHAR buffer[512];
		if (::SetupGetStringField(&ctx, index, buffer, _countof(buffer), nullptr))
			value = buffer;
	}
	return value;
}

bool InfFile::Init() {
	assert(m_inf != INVALID_HANDLE_VALUE);
	if (m_infoBuffer)
		return true;

	DWORD size = 0;
	::SetupGetInfInformation(m_inf, INFINFO_INF_SPEC_IS_HINF, nullptr, 0, &size);
	if (size == 0)
		return false;

	m_infoBuffer = std::make_unique<BYTE[]>(size);
	m_info = (SP_INF_INFORMATION*)m_infoBuffer.get();
	return ::SetupGetInfInformation(m_inf, INFINFO_INF_SPEC_IS_HINF, m_info, size, nullptr);
}
```

```h
	std::wstring Target;		// the section it names

	static std::vector<std::wstring> GetModelSections(std::wstring_view value);

	// Windows chooses from (none, .NT, .NTamd64, .NTarm64...), each followed by its .HW section.
	static std::vector<std::wstring> InstallSectionNames(std::wstring_view installSection);
	// the CopyFiles, DelFiles, AddReg and DelReg entries of those sections that the file has, in that order
	std::vector<InstallDirective> GetInstallDirectives(std::wstring_view installSection) const;
```

```cpp
#include "TestCommon.h"
#include "InfLexer.h"

#include <algorithm>

using namespace InfLexer;

namespace {
	// one letter per style, so that an expected value lines up under its line
	char Code(uint8_t style) {
		switch (style) {
			case Default: return '.';
			case Comment: return 'c';
			case Section: return 'S';
			case Key: return 'k';
			case Operator: return 'o';
			case String: return 's';
			case Token: return 't';
			case Number: return 'n';
		}
		return '?';
	}

	std::string Codes(std::vector<uint8_t> const& styles, size_t from = 0, size_t to = std::string::npos) {
		std::string codes;
		for (size_t i = from; i < std::min(to, styles.size()); i++)
			codes += Code(styles[i]);
		return codes;
	}

	struct Styled {
		std::string Codes;
		bool Continues;
	};

	Styled StyleOf(std::string_view line, bool continued = false) {
		std::vector<uint8_t> styles(line.size(), 0xFF);
		auto continues = StyleLine(line, continued, styles);
		return { Codes(styles), continues };
	}

	std::string Styles(std::string_view line, bool continued = false) {
		return StyleOf(line, continued).Codes;
	}
}

TEST_CASE("Empty and blank lines", "[lexer]") {
	CHECK(Styles("") == "");
	CHECK(Styles("   \t") == "....");
	CHECK_FALSE(StyleOf("   ").Continues);
}

	CHECK(Styles("file.sys ; c") == ".........ccc");

// The lexer as Scintilla runs it (InfLexer::Create), on a document with no window: whole lines, line ends, the
// continuation kept in the line state, and lexing that starts in the middle of the document.
//
namespace {
	class FakeDocument : public Scintilla::IDocument {
	public:
		explicit FakeDocument(std::string text) : m_text(std::move(text)), m_styles(m_text.size(), 0x7F) {
			m_lineStarts.push_back(0);
			for (size_t i = 0; i < m_text.size(); i++)
				if (m_text[i] == '\n')
					m_lineStarts.push_back(i + 1);
			m_lineStates.resize(m_lineStarts.size());
		}

		std::string LineCodes(Sci_Position line, bool withEnd = false) const {
			auto start = LineStart(line);
			auto end = withEnd ? LineStart(line + 1) : LineEnd(line);
			std::string codes;
			for (auto i = start; i < end; i++)
				codes += Code((uint8_t)m_styles[i]);
			return codes;
		}

		int SCI_METHOD Version() const override { return Scintilla::dvRelease4; }
		void SCI_METHOD SetErrorStatus(int) override {}
		Sci_Position SCI_METHOD Length() const override { return (Sci_Position)m_text.size(); }
		void SCI_METHOD GetCharRange(char* buffer, Sci_Position position, Sci_Position length) const override {
			memcpy(buffer, m_text.data() + position, length);
		}
		char SCI_METHOD StyleAt(Sci_Position position) const override { return m_styles[position]; }
		Sci_Position SCI_METHOD LineFromPosition(Sci_Position position) const override {
			return (Sci_Position)(std::upper_bound(m_lineStarts.begin(), m_lineStarts.end(), (size_t)position) - m_lineStarts.begin()) - 1;
		}
		Sci_Position SCI_METHOD LineStart(Sci_Position line) const override {
			return line < (Sci_Position)m_lineStarts.size() ? (Sci_Position)m_lineStarts[line] : Length();
		}
		int SCI_METHOD GetLevel(Sci_Position) const override { return 0; }
		int SCI_METHOD SetLevel(Sci_Position, int) override { return 0; }
		int SCI_METHOD GetLineState(Sci_Position line) const override {
			return line < (Sci_Position)m_lineStates.size() ? m_lineStates[line] : 0;
		}
		int SCI_METHOD SetLineState(Sci_Position line, int state) override {
			auto old = m_lineStates[line];
			m_lineStates[line] = state;
			return old;
		}
		void SCI_METHOD StartStyling(Sci_Position position) override { m_stylingPos = position; }
		bool SCI_METHOD SetStyleFor(Sci_Position length, char style) override {
			std::fill_n(m_styles.begin() + m_stylingPos, length, style);
			m_stylingPos += length;
			return true;
		}
		bool SCI_METHOD SetStyles(Sci_Position length, const char* styles) override {
			std::copy_n(styles, length, m_styles.begin() + m_stylingPos);
			m_stylingPos += length;
			return true;
		}
		void SCI_METHOD DecorationSetCurrentIndicator(int) override {}
		void SCI_METHOD DecorationFillRange(Sci_Position, int, Sci_Position) override {}
		void SCI_METHOD ChangeLexerState(Sci_Position, Sci_Position) override {}
		int SCI_METHOD CodePage() const override { return 65001; }
		bool SCI_METHOD IsDBCSLeadByte(char) const override { return false; }
		const char* SCI_METHOD BufferPointer() override { return m_text.c_str(); }
		int SCI_METHOD GetLineIndentation(Sci_Position) override { return 0; }
		Sci_Position SCI_METHOD LineEnd(Sci_Position line) const override {
			auto end = LineStart(line + 1);
			while (end > LineStart(line) && (m_text[end - 1] == '\n' || m_text[end - 1] == '\r'))
				end--;
			return end;
		}
```

```cpp
namespace {
	// 2026-03-07 and a GUID that is easy to find
	InfTemplates::Values TestValues() {
		InfTemplates::Values values{};
		values.Date.wYear = 2026;
		values.Date.wMonth = 3;
		values.Date.wDay = 7;
		values.Guid = { 0x12345678, 0x9abc, 0xdef0, { 0x01, 0x23, 0x45, 0x67, 0x89, 0xab, 0xcd, 0xef } };
		return values;
	}

	std::wstring Lower(std::wstring text) {
		std::transform(text.begin(), text.end(), text.begin(), [](wchar_t ch) { return (wchar_t)std::towlower(ch); });
		return text;
	}

	// the %strkey% names the text uses (by the lexer's Token style), outside [Strings]; not %13% and the like (DIRIDs)
	std::set<std::wstring> UsedStringKeys(std::string const& text) {
		std::set<std::wstring> keys;
		bool inStrings = false;
		size_t pos = 0;
		bool continued = false;
		while (pos < text.size()) {
			auto end = text.find("\r\n", pos);
			if (end == std::string::npos)
				end = text.size();
			std::string_view line(text.data() + pos, end - pos);
			std::vector<uint8_t> styles(line.size());
			continued = InfLexer::StyleLine(line, continued, styles);
			if (!line.empty() && styles[0] == InfLexer::Section)
				inStrings = _strnicmp(line.data(), "[Strings]", 9) == 0;
			else if (!inStrings) {
				for (size_t i = 0; i < line.size(); i++) {
					if (styles[i] != InfLexer::Token)
						continue;
					auto start = i;
					while (i < line.size() && styles[i] == InfLexer::Token && !(i > start && line[i] == '%'))
						i++;
					auto name = line.substr(start + 1, i - start - 1);
					if (!std::all_of(name.begin(), name.end(), [](char ch) { return ch >= '0' && ch <= '9'; }))
						keys.insert(Lower(std::wstring(name.begin(), name.end())));
				}
			}
			pos = end + 2;
		}
		return keys;
	}
}
```

```cpp
	// UTF-8 of a word with an e acute, a Hebrew word, two Japanese characters and an emoji (a surrogate pair in UTF-16, and in no ANSI code page)
	const std::string Unicode = "Caf\xC3\xA9 \xD7\xA9\xD7\x9C\xD7\x95\xD7\x9D \xE6\x97\xA5\xE6\x9C\xAC \xF0\x9F\x98\x80";

	std::string Utf16Bytes(std::wstring_view text, bool bom = true) {
		std::string bytes = bom ? "\xFF\xFE" : "";
```

```cpp
#include "pch.h"
#include "EditorSearch.h"

namespace {
	int Flags(SearchOptions const& options) noexcept {
		return (options.MatchCase ? SCFIND_MATCHCASE : 0) | (options.WholeWord ? SCFIND_WHOLEWORD : 0);
	}

	// the text in [start, end), or backwards from start down to end if end < start; on a match the target is it
	LRESULT Search(CScintillaCtrl& editor, std::string_view text, int flags, LRESULT start, LRESULT end) {
		editor.Execute(SCI_SETSEARCHFLAGS, flags);
		editor.Execute(SCI_SETTARGETRANGE, start, end);
		return editor.Execute(SCI_SEARCHINTARGET, text.size(), reinterpret_cast<LPARAM>(text.data()));
	}

	// whether the selection is a match (what Replace replaces)
	bool SelectionMatches(CScintillaCtrl& editor, std::string_view text, int flags) {
		auto start = editor.Execute(SCI_GETSELECTIONSTART);
		auto end = editor.Execute(SCI_GETSELECTIONEND);
		return start != end && Search(editor, text, flags, start, end) == start && editor.Execute(SCI_GETTARGETEND) == end;
	}
}

bool EditorSearch::FindNext(CScintillaCtrl& editor, std::string_view text, SearchOptions const& options) {
	if (text.empty())
		return false;

	auto flags = Flags(options);
	auto length = editor.Execute(SCI_GETLENGTH);
	auto selStart = editor.Execute(SCI_GETSELECTIONSTART);
	auto selEnd = editor.Execute(SCI_GETSELECTIONEND);
	LRESULT pos;
	if (options.Down) {
		pos = Search(editor, text, flags, selEnd, length);
		if (pos < 0)
			pos = Search(editor, text, flags, 0, selEnd);		// from the top
	}
	else {
		pos = Search(editor, text, flags, selStart, 0);
		if (pos < 0)
			pos = Search(editor, text, flags, length, selStart);	// from the bottom
	}
	if (pos < 0)
		return false;

	editor.Execute(SCI_SETSEL, editor.Execute(SCI_GETTARGETSTART), editor.Execute(SCI_GETTARGETEND));
	editor.Execute(SCI_SCROLLCARET);
	return true;
}

bool EditorSearch::Replace(CScintillaCtrl& editor, std::string_view text, std::string_view replacement, SearchOptions const& options) {
	if (text.empty())
		return false;

	if (SelectionMatches(editor, text, Flags(options))) {
		// (the target is the selection)
		editor.Execute(SCI_REPLACETARGET, replacement.size(), reinterpret_cast<LPARAM>(replacement.data()));
		auto start = editor.Execute(SCI_GETTARGETSTART);
		auto end = editor.Execute(SCI_GETTARGETEND);
		// searching goes on from after the replacement (down) or before it (up)
		editor.Execute(SCI_SETEMPTYSELECTION, options.Down ? end : start);
	}
	return FindNext(editor, text, options);
}

int EditorSearch::ReplaceAll(CScintillaCtrl& editor, std::string_view text, std::string_view replacement, SearchOptions const& options) {
	if (text.empty())
		return 0;

	auto flags = Flags(options);
	int count = 0;
	editor.Execute(SCI_BEGINUNDOACTION);
	for (LRESULT pos = 0; Search(editor, text, flags, pos, editor.Execute(SCI_GETLENGTH)) >= 0; count++) {
		editor.Execute(SCI_REPLACETARGET, replacement.size(), reinterpret_cast<LPARAM>(replacement.data()));
		pos = editor.Execute(SCI_GETTARGETEND);
	}
	editor.Execute(SCI_ENDUNDOACTION);
	return count;
}
```

```cpp
#include "pch.h"
#include "InfLexer.h"

#include <cassert>
#include <algorithm>
#include <lexilla/lexlib/LexAccessor.h>
#include <lexilla/lexlib/Accessor.h>
#include <lexilla/lexlib/LexerModule.h>

namespace {
	using namespace InfLexer;

	bool IsBlank(char ch) noexcept {
		return ch == ' ' || ch == '\t';
	}

	bool IsDigit(char ch) noexcept {
		return ch >= '0' && ch <= '9';
	}

	bool IsHexDigit(char ch) noexcept {
		return IsDigit(ch) || (ch >= 'a' && ch <= 'f') || (ch >= 'A' && ch <= 'F');
	}

	// 123 or 0x1F
	bool IsNumber(std::string_view text) noexcept {
		if (text.size() > 2 && text[0] == '0' && (text[1] == 'x' || text[1] == 'X'))
			return std::all_of(text.begin() + 2, text.end(), IsHexDigit);
		return !text.empty() && std::all_of(text.begin(), text.end(), IsDigit);
	}

	// the end of the string that starts (with its quote) at start: after its closing quote, or the line's end
	size_t StringEnd(std::string_view line, size_t start) noexcept {
		for (size_t i = start + 1; i < line.size(); i++) {
			if (line[i] == '"') {
				if (i + 1 < line.size() && line[i + 1] == '"') {
					i++;		// "" is a quote in the string
					continue;
				}
				return i + 1;
			}
		}
		return line.size();
	}

	// the '=' between the key and the value: outside quotes, before the comment
	size_t FindAssignment(std::string_view line, size_t from) noexcept {
		for (size_t i = from; i < line.size(); i++) {
			switch (line[i]) {
				case '"': i = StringEnd(line, i) - 1; break;
				case ';': return std::string_view::npos;
				case '=': return i;
			}
		}
		return std::string_view::npos;
	}

	// a '\' with nothing but blanks after it to the end of the line
	bool IsContinuation(std::string_view line, size_t i) noexcept {
		if (line[i] != '\\')
			return false;
		while (++i < line.size())
			if (!IsBlank(line[i]))
				return false;
		return true;
	}

	void Fill(std::span<uint8_t> styles, size_t from, size_t to, Style style) noexcept {
		std::fill(styles.begin() + from, styles.begin() + to, (uint8_t)style);
	}

	// %strkey% at start, or 0 if it isn't one (a lone '%', or %%); within limit
	size_t TokenLength(std::string_view line, size_t start, size_t limit) noexcept {
		for (size_t i = start + 1; i < limit; i++) {
			if (line[i] == '%')
				return i == start + 1 ? 0 : i - start + 1;
			if (line[i] == '"' || line[i] == ';' || line[i] == ',' || IsBlank(line[i]))
				break;
		}
		return 0;
	}

	//
	// [from, to) of the line: strings, string keys, commas, comments, numbers, and the rest in plain.
	// Returns whether the line continues (a '\' at its end).
	//
	bool StyleRange(std::string_view line, size_t from, size_t to, Style plain, std::span<uint8_t> styles) {
		size_t i = from;
		while (i < to) {
			auto ch = line[i];
			if (IsBlank(ch)) {
				i++;
			}
			else if (ch == ';') {
				Fill(styles, i, line.size(), Comment);
				return false;
			}
			else if (ch == '"') {
				auto end = std::min(StringEnd(line, i), to);
				Fill(styles, i, end, String);
				// string keys are replaced inside strings too
				for (size_t k = i + 1; k < end; k++) {
					if (line[k] == '%') {
						if (auto len = TokenLength(line, k, end); len > 0) {
							Fill(styles, k, k + len, Token);
							k += len - 1;
						}
						else if (k + 1 < end && line[k + 1] == '%') {
							k++;
						}
					}
				}
				i = end;
			}
			else if (ch == '%' && TokenLength(line, i, to) > 0) {
				auto len = TokenLength(line, i, to);
				Fill(styles, i, i + len, Token);
				i += len;
			}
			else if (ch == ',' || ch == '=') {
				styles[i++] = Operator;
			}
			else if (to == line.size() && IsContinuation(line, i)) {
				styles[i] = Operator;
				return true;
			}
			else {
				// a word: up to a blank or anything that has a meaning of its own
				auto start = i;
				while (i < to) {
					auto c = line[i];
					if (IsBlank(c) || c == ';' || c == '"' || c == ',' || c == '=')
						break;
					if (c == '%') {
						if (i + 1 < to && line[i + 1] == '%') {
							i += 2;		// %% is a literal percent
							continue;
						}
						if (TokenLength(line, i, to) > 0)
							break;
					}
					if (to == line.size() && IsContinuation(line, i))
						break;
					i++;
				}
				// a number is a whole value: not part of a key, and not a word such as 10.0.1.0
				auto style = plain != Key && IsNumber(line.substr(start, i - start)) ? Number : plain;
				Fill(styles, start, i, style);
			}
		}
		return false;
	}

	void ColouriseInfDoc(Sci_PositionU startPos, Sci_Position length, int /*initStyle*/, Lexilla::WordList*[], Lexilla::Accessor& styler) {
		// whole lines, from the start of the first one (the previous line's state says whether it continues)
		auto line = styler.GetLine(startPos);
		Sci_PositionU pos = styler.LineStart(line);
		const Sci_PositionU end = std::min<Sci_PositionU>(startPos + length, styler.Length());
		styler.StartAt(pos);
		styler.StartSegment(pos);

		bool continued = line > 0 && (styler.GetLineState(line - 1) & 1);
		std::string text;
		std::vector<uint8_t> styles;
		while (pos < end) {
			Sci_PositionU lineEnd = std::min<Sci_PositionU>(styler.LineStart(line + 1), styler.Length());
			if (lineEnd <= pos)
				break;
			text.clear();
			for (auto p = pos; p < lineEnd; p++)
				text.push_back(styler[p]);
			auto content = text.size();
			while (content > 0 && (text[content - 1] == '\r' || text[content - 1] == '\n'))
				content--;

			styles.assign(content, Default);
			continued = StyleLine(std::string_view(text.data(), content), continued, styles);
			for (size_t k = 0; k < content; k++)
				if (k + 1 == content || styles[k + 1] != styles[k])
					styler.ColourTo(pos + k, styles[k]);
			if (content < text.size())
				styler.ColourTo(lineEnd - 1, Default);
			styler.SetLineState(line, continued ? 1 : 0);

			pos = lineEnd;
			line++;
		}
		styler.Flush();
	}

	const Lexilla::LexerModule lmInf(SCLEX_AUTOMATIC, ColouriseInfDoc, "inf");
}

bool InfLexer::StyleLine(std::string_view line, bool continued, std::span<uint8_t> styles) {
	assert(styles.size() >= line.size());
	Fill(styles, 0, line.size(), Default);

	size_t i = 0;
	while (i < line.size() && IsBlank(line[i]))
		i++;
	if (i == line.size())
		return false;

	if (!continued && line[i] == '[') {
		// [section name], then perhaps a comment
		auto end = i + 1;
		while (end < line.size() && line[end] != ']' && line[end] != ';')
			end++;
		if (end < line.size() && line[end] == ']')
			end++;
		Fill(styles, i, end, Section);
		StyleRange(line, end, line.size(), Default, styles);
		return false;
	}

	if (!continued) {
		if (auto eq = FindAssignment(line, i); eq != std::string_view::npos) {
			StyleRange(line, i, eq, Key, styles);
			styles[eq] = Operator;
			i = eq + 1;
		}
	}
	return StyleRange(line, i, line.size(), Default, styles);
}

Scintilla::ILexer5* InfLexer::Create() {
	return lmInf.Create();
}
```

```h
#pragma once

#include <string_view>
#include <span>
#include <cstdint>

//
// Syntax highlighting of INF files, by the rules of "General Syntax Rules for INF Files":
// a ';' outside quotes starts a comment anywhere on a line, "..." is a string ("" is a quote in it), %strkey% a string key
// (%% a literal percent), '=' (outside quotes, before the comment) separates the key from the value, ',' separates the
// values, and a '\' as the last non-blank character continues the line on the next (which then has no key).
//
namespace InfLexer {
	enum Style : uint8_t {
		Default,
		Comment,
		Section,
		Key,
		Operator,	// = , and the continuation '\'
		String,
		Token,		// %strkey%
		Number,		// a value that is a whole decimal or 0x hex number
		StyleCount
	};

	// Styles one line (its text without the line end) into styles (one per byte, as many as the line has).
	// continued: the previous line ended with a continuation. Returns whether this line does.
	bool StyleLine(std::string_view line, bool continued, std::span<uint8_t> styles);

	// a Scintilla lexer that styles with StyleLine
	Scintilla::ILexer5* Create();
}
```

```cpp
#include "pch.h"

int Run(LPCTSTR /*lpstrCmdLine*/ = nullptr, int nCmdShow = SW_SHOWDEFAULT) {
	CMessageLoop theLoop;
	_Module.AddMessageLoop(&theLoop);

	CMainFrame wndMain;

	if (wndMain.CreateEx() == nullptr) {
		ATLTRACE(_T("Main window creation failed!\n"));
		return 0;
	}

	// where the window was when the program was last closed, if that place is still on a screen
	auto wp = AppSettings::Get().MainWindowPlacement();
	if (wp.length == sizeof(wp) && ::MonitorFromRect(&wp.rcNormalPosition, MONITOR_DEFAULTTONULL)) {
		if (wp.showCmd == SW_SHOWMINIMIZED) {
			wp.showCmd = SW_SHOWNORMAL;
			AppSettings::Get().MainWindowPlacement(wp);
		}
		AppSettings::Get().LoadWindowPosition(wndMain, L"MainWindowPlacement");
	}
	else {
		wndMain.ShowWindow(nCmdShow);
	}

	int nRet = theLoop.Run();

	_Module.RemoveMessageLoop();
	return nRet;
}

int WINAPI wWinMain(HINSTANCE hInstance, HINSTANCE /*hPrevInstance*/, LPTSTR lpstrCmdLine, int nCmdShow) {
	HRESULT hRes = ::CoInitializeEx(nullptr, COINIT_APARTMENTTHREADED | COINIT_DISABLE_OLE1DDE);
	ATLASSERT(SUCCEEDED(hRes));

	AtlInitCommonControls(ICC_BAR_CLASSES | ICC_COOL_CLASSES | ICC_LISTVIEW_CLASSES | ICC_TREEVIEW_CLASSES);

	hRes = _Module.Init(nullptr, hInstance);
	ATLASSERT(SUCCEEDED(hRes));

	AppSettings::Get().LoadFromKey(AppSettings::RegistryKey);

	// dark or not as the user last chose, and as the system is until then
	int dark = AppSettings::Get().DarkMode();
	if (dark < 0)
		WTLHelper::InitDarkMode();
	else
		WTLHelper::InitDarkMode(dark ? DarkModeKind::Dark : DarkModeKind::Classic);

	Scintilla_RegisterClasses(_Module.GetModuleInstance());

	int nRet = Run(lpstrCmdLine, nCmdShow);

	Scintilla_ReleaseResources();
	_Module.Term();
	::CoUninitialize();

	return nRet;
}
```

```cpp
std::string InfTemplates::Generate(InfTemplate const& infTemplate, Values const& values) {
	std::string text = infTemplate.Text;
	ReplaceAll(text, "@DATE@", std::format("{:02}/{:02}/{:04}", values.Date.wMonth, values.Date.wDay, values.Date.wYear));
	ReplaceAll(text, "@GUID@", GuidText(values.Guid));
	ReplaceAll(text, "\n", "\r\n");
	return text;
}
```

```cpp
namespace {
	std::string_view TrimEnd(std::string_view text) noexcept {
		while (!text.empty() && (text.back() == '\r' || text.back() == '\n' || text.back() == ' '))
			text.remove_suffix(1);
		return text;
	}

	bool ParseInt(std::string_view text, int& value) noexcept {
		auto [end, ec] = std::from_chars(text.data(), text.data() + text.size(), value);
		return ec == std::errc{} && end == text.data() + text.size();
	}
}

std::filesystem::path InfVerif::Find() {
	SYSTEM_INFO si;
	::GetNativeSystemInfo(&si);
	auto arch = si.wProcessorArchitecture == PROCESSOR_ARCHITECTURE_ARM64 ? L"arm64" : L"x64";

	WCHAR programFiles[MAX_PATH];
	if (!::ExpandEnvironmentStrings(L"%ProgramFiles(x86)%", programFiles, _countof(programFiles)))
		return {};
	std::error_code ec;
	std::filesystem::path found;
	for (auto const& dir : std::filesystem::directory_iterator(std::filesystem::path(programFiles) / L"Windows Kits" / L"10" / L"Tools", ec)) {
		auto exe = dir.path() / arch / L"infverif.exe";
		// (the version folders sort by version as text: 10.0.22621.0 < 10.0.28000.0)
		if (std::filesystem::exists(exe, ec) && (found.empty() || exe > found))
			found = exe;
	}
	return found;
}

InfVerifResult InfVerif::Run(std::filesystem::path const& infverif, PCWSTR mode, std::filesystem::path const& inf) {
	InfVerifResult result;

	SECURITY_ATTRIBUTES sa{ sizeof(sa), nullptr, TRUE };
	wil::unique_handle read, write;
	if (!::CreatePipe(read.addressof(), write.addressof(), &sa, 0))
		return result;
	::SetHandleInformation(read.get(), HANDLE_FLAG_INHERIT, 0);

	STARTUPINFO si{ sizeof(si) };
	si.dwFlags = STARTF_USESTDHANDLES;
	si.hStdOutput = si.hStdError = write.get();
	si.hStdInput = nullptr;
	auto commandLine = std::format(L"\"{}\" {} \"{}\"", infverif.wstring(), mode, inf.wstring());
	PROCESS_INFORMATION pi;
	if (!::CreateProcess(nullptr, commandLine.data(), nullptr, nullptr, TRUE, CREATE_NO_WINDOW, nullptr, nullptr, &si, &pi))
		return result;
	wil::unique_handle process(pi.hProcess), thread(pi.hThread);
	// (the child has its copy: the pipe ends when it does)
	write.reset();

	char buffer[4096];
	DWORD bytes;
	while (::ReadFile(read.get(), buffer, sizeof(buffer), &bytes, nullptr) && bytes)
		result.Output.append(buffer, bytes);
	::WaitForSingleObject(process.get(), INFINITE);
	::GetExitCodeProcess(process.get(), &result.ExitCode);
	result.Ran = true;
	result.Messages = Parse(result.Output);
	return result;
}

std::vector<InfVerifMessage> InfVerif::Parse(std::string_view output) {
	std::vector<InfVerifMessage> messages;
	while (!output.empty()) {
		auto end = output.find('\n');
		auto line = TrimEnd(output.substr(0, end));
		output.remove_prefix(end == std::string_view::npos ? output.size() : end + 1);

		// SEVERITY(code) in path, line N: text
		auto paren = line.find('(');
		auto close = line.find(')', paren);
		if (paren == std::string_view::npos || close == std::string_view::npos)
			continue;
		auto severity = line.substr(0, paren);
		InfVerifMessage message{};
		if (severity == "ERROR")
			message.Kind = InfVerifMessage::Severity::Error;
		else if (severity == "WARNING")
			message.Kind = InfVerifMessage::Severity::Warning;
		else if (severity == "INFO")
			message.Kind = InfVerifMessage::Severity::Info;
		else
			continue;
		if (!ParseInt(line.substr(paren + 1, close - paren - 1), message.Code))
			continue;

		// (the path may have commas; ", line " comes after it)
		auto where = line.find(", line ", close);
		if (where == std::string_view::npos)
			continue;
		auto colon = line.find(':', where);
		if (colon == std::string_view::npos || !ParseInt(line.substr(where + 7, colon - where - 7), message.Line))
			continue;
		auto text = line.substr(colon + 1);
		if (!text.empty() && text.front() == ' ')
			text.remove_prefix(1);
		// (a console program writes to a pipe in the OEM code page)
		message.Text.resize(text.size());
		message.Text.resize(::MultiByteToWideChar(CP_OEMCP, 0, text.data(), (int)text.size(), message.Text.data(), (int)message.Text.size()));
		messages.push_back(std::move(message));
	}
	return messages;
}
```

```cpp
void CInfView::ApplyColors() {
	auto dark = WTLHelper::IsDarkMode();
	auto const& c = dark ? DarkColors : LightColors;
	// Scintilla's own scroll bars follow the window's theme
	::SetWindowTheme(m_hWnd, dark ? L"DarkMode_Explorer" : L"Explorer", nullptr);

	StyleSetFont(STYLE_DEFAULT, "Consolas");
	StyleSetSize(STYLE_DEFAULT, 11);
	StyleSetFore(STYLE_DEFAULT, c.Text);
	Execute(SCI_STYLESETBACK, STYLE_DEFAULT, c.Back);
	// every style takes the default's font and colors, the lexer's styles then get their own
	Execute(SCI_STYLECLEARALL);
	StyleSetFore(InfLexer::Comment, c.Comment);
	StyleSetFore(InfLexer::Section, c.Section);
	Execute(SCI_STYLESETBOLD, InfLexer::Section, TRUE);
	StyleSetFore(InfLexer::Key, c.Key);
	StyleSetFore(InfLexer::Operator, c.Operator);
	StyleSetFore(InfLexer::String, c.String);
	StyleSetFore(InfLexer::Token, c.Token);
	StyleSetFore(InfLexer::Number, c.Number);

	StyleSetFore(STYLE_LINENUMBER, c.MarginText);
	Execute(SCI_STYLESETBACK, STYLE_LINENUMBER, c.MarginBack);
	Execute(SCI_SETCARETFORE, c.Caret);
	Execute(SCI_SETSELBACK, TRUE, c.Selection);
	Execute(SCI_SETCARETLINEVISIBLE, TRUE);
	Execute(SCI_SETCARETLINEVISIBLEALWAYS, TRUE);
	Execute(SCI_SETCARETLINEBACK, c.CaretLine);
	// the fold margin (1) isn't used: the same color as the line numbers'
	Execute(SCI_SETFOLDMARGINCOLOUR, TRUE, c.MarginBack);
	Execute(SCI_SETFOLDMARGINHICOLOUR, TRUE, c.MarginBack);

	Execute(SCI_INDICSETSTYLE, ErrorIndicator, INDIC_SQUIGGLE);
	Execute(SCI_INDICSETFORE, ErrorIndicator, c.ErrorMark);
	Execute(SCI_INDICSETSTYLE, WarningIndicator, INDIC_SQUIGGLE);
	Execute(SCI_INDICSETFORE, WarningIndicator, c.WarningMark);

	UpdateLineNumberWidth();
	Execute(SCI_COLOURISE, 0, -1);
}

void CInfView::UpdateLineNumberWidth() {
	auto lines = Execute(SCI_GETLINECOUNT);
	char digits[24] = "_9999";
	for (auto n = lines; n >= 10000; n /= 10)
		strcat_s(digits, "9");
	auto width = (int)Execute(SCI_TEXTWIDTH, STYLE_LINENUMBER, reinterpret_cast<LPARAM>(digits));
	Execute(SCI_SETMARGINWIDTHN, 0, width);
}

void CInfView::ShowProblems(std::vector<Problem> const& problems) {
	auto length = Execute(SCI_GETLENGTH);
	for (auto indicator : { ErrorIndicator, WarningIndicator }) {
		Execute(SCI_SETINDICATORCURRENT, indicator);
		Execute(SCI_INDICATORCLEARRANGE, 0, length);
	}
	auto lines = (int)Execute(SCI_GETLINECOUNT);
	for (auto const& problem : problems) {
		if (problem.Line < 1 || problem.Line > lines)
			continue;
		// the line's text, without its indentation
		auto start = Execute(SCI_GETLINEINDENTPOSITION, problem.Line - 1);
		auto end = Execute(SCI_GETLINEENDPOSITION, problem.Line - 1);
		if (end <= start)
			continue;
		Execute(SCI_SETINDICATORCURRENT, problem.Error ? ErrorIndicator : WarningIndicator);
		Execute(SCI_INDICATORFILLRANGE, start, end - start);
	}
}

LRESULT CInfView::OnThemeChanged(UINT, WPARAM, LPARAM, BOOL&) {
	ApplyColors();
	return 0;
}
```

```cpp
		return;

		menu.GetMenuString(i, text, MF_BYPOSITION);
		if (text == L"&Recent Files")
			break;

	menu = menu.GetSubMenu(i);
	while (menu.DeleteMenu(0, MF_BYPOSITION))
		;

	i = 0;
	for (auto& file : s_recentFiles.Files()) {
		menu.AppendMenu(MF_BYPOSITION, ATL_IDS_MRU_FILE + i++, file.c_str());
	}

bool CMainFrame::DoFileOpen(PCWSTR path, PCWSTR name) {
	CString title(name);
	if (title.IsEmpty()) {
		title = wcsrchr(path, L'\\') + 1;
	}
	auto pView = new CMainView(this);
	pView->Create(m_view, rcDefault, nullptr, WS_CHILD | WS_VISIBLE | WS_CLIPSIBLINGS | WS_CLIPCHILDREN);
	CWaitCursor wait;
	if (pView->OpenFile(path)) {
		m_view.AddPage(pView->m_hWnd, title, 0, static_cast<IView*>(pView));
		s_recentFiles.AddFile(path);
		AppSettings::Get().RecentFiles(s_recentFiles.Files());
		UpdateRecentFilesMenu();
		return true;
	}
	else {
		pView->DestroyWindow();
		return false;
	}
}
```

```cpp
bool CMainView::ConfirmEncoding() {

void CMainView::BuildTree() {
	m_Tree.SetRedraw(FALSE);
	m_Tree.DeleteAllItems();
	auto hRoot = InsertTreeItem(m_Tree, m_Name, TreeIconIndex::InfFile, NodeType::Root);
	if (!m_Path.IsEmpty() && !IsDirty()) {
		//
		// analyze file
		//
		if (!m_Inf.Open(m_Path, nullptr, &m_ErrorLine)) {

void CMainView::AnalyzeAndBuild(HTREEITEM hRoot) {
	if (m_Inf.SectionExists(L"version")) {
		InsertTreeItem(m_Tree, L"Version", TreeIconIndex::Version, NodeType::Version, hRoot);
	}
	auto mfg = m_Inf.GetSectionCompactLines(L"Manufacturer");
	if (!mfg.empty()) {
		auto hMfg = InsertTreeItem(m_Tree, L"Manufacturer", TreeIconIndex::Models, NodeType::Models, hRoot);
		for (auto& [key, value] : mfg) {
			for (auto const& model : InfFile::GetModelSections(value)) {
				auto hModel = InsertTreeItem(m_Tree, model.c_str(), TreeIconIndex::Model, NodeType::Model, hMfg);
				// each device's install section (the first field of its value), in all its decorations
				for (auto const& [key, value] : m_Inf.GetSectionCompactLines(model.c_str())) {
					auto install = value.substr(0, value.find(L','));
					for (auto const& d : m_Inf.GetInstallDirectives(install)) {
						static const struct {
							PCWSTR Name;
							TreeIconIndex Icon;
							NodeType Type;
						} kinds[] = {
							{ L"CopyFiles", TreeIconIndex::CopyFiles, NodeType::CopyFiles },
							{ L"DelFiles", TreeIconIndex::DelFiles, NodeType::DelFiles },
							{ L"AddReg", TreeIconIndex::AddReg, NodeType::AddReg },
							{ L"DelReg", TreeIconIndex::DelReg, NodeType::DelReg },
						};
						auto kind = std::find_if(std::begin(kinds), std::end(kinds), [&](auto const& k) { return d.Directive == k.Name; });
						ATLASSERT(kind != std::end(kinds));
						auto hSection = FindChild(m_Tree, hModel, d.Section.c_str());
						if (!hSection)
							hSection = InsertTreeItem(m_Tree, d.Section.c_str(), TreeIconIndex::Section, NodeType::Section, hModel, TVI_SORT);
						if (!FindChild(m_Tree, hSection, d.Target.c_str()))
							InsertTreeItem(m_Tree, d.Target.c_str(), kind->Icon, kind->Type, hSection, TVI_SORT);
					}
				}
			}
		}
	}

	//
	// add all sections
	//
	auto hSections = InsertTreeItem(m_Tree, L"All Sections", TreeIconIndex::Sections, NodeType::Sections, hRoot);
	for (auto& sec : m_Inf.GetSectionNames()) {
		InsertTreeItem(m_Tree, sec.c_str(), TreeIconIndex::Section, NodeType::Section, hSections, TVI_SORT);
	}
}

LRESULT CMainView::OnFind(UINT /*uMsg*/, WPARAM /*wParam*/, LPARAM /*lParam*/, BOOL& /*bHandled*/) {
	if (m_fr->IsTerminating()) {
		m_fr = nullptr;
		return 0;
	}

	m_SearchText = m_fr->GetFindString();
	m_ReplaceText = m_fr->GetReplaceString();
	m_Search = { m_fr->MatchCase() != FALSE, m_fr->MatchWholeWord() != FALSE, m_fr->SearchDown() != FALSE };
	auto text = TextFile::ToUtf8((PCWSTR)m_SearchText);
	auto replacement = TextFile::ToUtf8((PCWSTR)m_ReplaceText);

	bool found;
	if (m_fr->ReplaceAll()) {
		auto count = EditorSearch::ReplaceAll(m_InfView, text, replacement, m_Search);
		Frame()->SetStatusText(0, std::format(L"{} replaced", count).c_str());
		found = count > 0;
	}
	else if (m_fr->ReplaceCurrent()) {
		found = EditorSearch::Replace(m_InfView, text, replacement, m_Search);
	}
	else {
		found = EditorSearch::FindNext(m_InfView, text, m_Search);
	}
	if (!found) {
		Frame()->SetStatusText(0, L"Not found");
		::MessageBeep(MB_OK);
	}
	return 0;
}

void CMainView::Validate(PCWSTR mode) {
	auto infverif = InfVerif::Find();
	if (infverif.empty()) {
		AtlMessageBox(m_hWnd, L"InfVerif.exe, which validates INF files, wasn't found.\n\nIt comes with the Windows Driver Kit (WDK).",
			IDS_TITLE, MB_ICONINFORMATION);
		return;
	}

	// The editor's text, saved or not, goes to a file of its own by the same name (InfVerif checks the name too).
	// An ANSI file with characters the code page lacks goes as UTF-16, so that they get there.
	auto text = m_InfView.GetText(m_InfView.Length());
	auto encoding = m_Encoding == TextEncoding::Ansi && !TextFile::FitsAnsi(text) ? TextEncoding::Utf16 : m_Encoding;
	std::error_code ec;
	auto dir = std::filesystem::temp_directory_path(ec) / std::format(L"InfStudio-{}", ::GetCurrentProcessId());
	std::filesystem::create_directories(dir, ec);
	auto file = dir / (m_Name.IsEmpty() ? L"Untitled.inf" : (PCWSTR)m_Name);
	if (!TextFile::Save(file.c_str(), text, encoding)) {
		AtlMessageBox(m_hWnd, L"Failed to write the file for InfVerif.", IDS_TITLE, MB_ICONERROR);
		return;
	}

	InfVerifResult result;
	{
		CWaitCursor wait;
		Frame()->SetStatusText(0, L"Running InfVerif...");
		result = InfVerif::Run(infverif, mode, file);
	}
	std::filesystem::remove_all(dir, ec);
	if (!result.Ran) {
		Frame()->SetStatusText(0, L"");
		AtlMessageBox(m_hWnd, std::format(L"Failed to run {}.", infverif.wstring()).c_str(), IDS_TITLE, MB_ICONERROR);
		return;
	}
	ShowResults(std::move(result.Messages), mode);
}

void CMainView::ShowResults(std::vector<InfVerifMessage> messages, PCWSTR mode) {
	m_Messages = std::move(messages);
	m_Results.SetRedraw(FALSE);
	m_Results.DeleteAllItems();
	int errors = 0, warnings = 0;
	std::vector<CInfView::Problem> problems;
	for (int i = 0; i < (int)m_Messages.size(); i++) {
		auto const& m = m_Messages[i];
		auto n = m_Results.InsertItem(i, m.Line > 0 ? std::to_wstring(m.Line).c_str() : L"", (int)m.Kind);
		m_Results.SetItemText(n, 1, std::to_wstring(m.Code).c_str());
		m_Results.SetItemText(n, 2, m.Text.c_str());
		m_Results.SetItemData(n, i);
		if (m.Kind == InfVerifMessage::Severity::Error)
			errors++;
		else if (m.Kind == InfVerifMessage::Severity::Warning)
			warnings++;
		if (m.Kind != InfVerifMessage::Severity::Info)
			problems.push_back({ m.Line, m.Kind == InfVerifMessage::Severity::Error });
	}
	if (m_Messages.empty()) {
		auto n = m_Results.InsertItem(0, L"", (int)InfVerifMessage::Severity::Info);
		m_Results.SetItemText(n, 2, L"No problems found");
		m_Results.SetItemData(n, (DWORD_PTR)-1);
	}
	m_Results.SetRedraw(TRUE);
	m_InfView.ShowProblems(problems);
	ShowResultsPane(true);
	Frame()->SetStatusText(0, std::format(L"InfVerif {}: {} error{}, {} warning{}", mode,
		errors, errors == 1 ? L"" : L"s", warnings, warnings == 1 ? L"" : L"s").c_str());
}

void CMainView::ShowResultsPane(bool show) {
	m_EditSplitter.SetSinglePaneMode(show ? SPLIT_PANE_NONE : SPLIT_PANE_TOP);
	UI().UISetCheck(ID_VIEW_RESULTS, show);
}

LRESULT CMainView::OnViewResults(WORD, WORD, HWND, BOOL&) {
	ShowResultsPane(m_EditSplitter.GetSinglePaneMode() != SPLIT_PANE_NONE);
	return 0;
}

LRESULT CMainView::OnResultActivate(int, LPNMHDR, BOOL&) {
	auto selected = m_Results.GetSelectedIndex();
	if (selected < 0)
		return 0;
	auto index = (int)m_Results.GetItemData(selected);
	if (index >= 0 && index < (int)m_Messages.size())
		GoToLine(m_Messages[index].Line);
	return 0;
}

void CMainView::GoToLine(int line) {
	if (line < 1)
		return;
	m_InfView.Execute(SCI_ENSUREVISIBLE, line - 1);
	m_InfView.Execute(SCI_GOTOLINE, line - 1);
	m_InfView.Execute(SCI_VERTICALCENTRECARET);
	m_InfView.SetFocus();
}
```

```cpp
#include "pch.h"
#include "RecentFilesManager.h"

void RecentFilesManager::AddFile(std::wstring const& file) {
	if (auto it = std::find(m_files.begin(), m_files.end(), file); it != m_files.end()) {
		m_files.erase(it);
	}
	m_files.insert(m_files.begin(), file);
	if (m_files.size() > m_maxFiles)
		m_files.resize(m_files.size() - 1);
}

std::vector<std::wstring> const& RecentFilesManager::Files() const {
	return m_files;
}

bool RecentFilesManager::IsEmpty() const {
	return m_files.empty();
}

void RecentFilesManager::Set(std::vector<std::wstring> files) {
	m_files = std::move(files);
}
```

```cpp
#include "pch.h"
#include "SecurityHelper.h"

bool SecurityHelper::IsRunningElevated() {
	static bool runningElevated = false;
	static bool runningElevatedCheck = false;
	if (runningElevatedCheck)
		return runningElevated;

	runningElevatedCheck = true;
	HANDLE hToken;
	if (!::OpenProcessToken(::GetCurrentProcess(), TOKEN_QUERY, &hToken))
		return false;

	TOKEN_ELEVATION te;
	DWORD len;
	if (::GetTokenInformation(hToken, TokenElevation, &te, sizeof(te), &len)) {
		runningElevated = te.TokenIsElevated ? true : false;
	}
	::CloseHandle(hToken);
	return runningElevated;
}

bool SecurityHelper::RunElevated(PCWSTR param, bool ui) {
	WCHAR path[MAX_PATH];
	::GetModuleFileName(nullptr, path, _countof(path));
	SHELLEXECUTEINFO shi = { sizeof(shi) };
	shi.lpFile = path;
	shi.nShow = SW_SHOWDEFAULT;
	shi.lpVerb = L"runas";
	shi.lpParameters = param;
	shi.fMask = (ui ? 0 : (SEE_MASK_FLAG_NO_UI | SEE_MASK_NO_CONSOLE)) | SEE_MASK_NOASYNC | SEE_MASK_NOCLOSEPROCESS;
	auto ok = ::ShellExecuteEx(&shi);
	if (!ok)
		return false;

	DWORD rc = WAIT_OBJECT_0;
	if (!ui) {
		rc = ::WaitForSingleObject(shi.hProcess, 5000);
	}
	::CloseHandle(shi.hProcess);
	return rc == WAIT_OBJECT_0;
}
```

```cpp
namespace {
	std::string WideToMultiByte(UINT codePage, std::wstring_view text, BOOL* usedDefault = nullptr) {
		if (text.empty())
			return {};
		// (CP_UTF8 takes no default character)
		auto flags = codePage == CP_UTF8 ? 0 : WC_NO_BEST_FIT_CHARS;
		auto pDefault = codePage == CP_UTF8 ? nullptr : usedDefault;
		int size = ::WideCharToMultiByte(codePage, flags, text.data(), (int)text.size(), nullptr, 0, nullptr, pDefault);
		std::string result(size, '\0');
		::WideCharToMultiByte(codePage, flags, text.data(), (int)text.size(), result.data(), size, nullptr, pDefault);
		return result;
	}

	std::wstring MultiByteToWide(UINT codePage, std::string_view text) {
		if (text.empty())
			return {};
		int size = ::MultiByteToWideChar(codePage, 0, text.data(), (int)text.size(), nullptr, 0);
		std::wstring result(size, L'\0');
		::MultiByteToWideChar(codePage, 0, text.data(), (int)text.size(), result.data(), size);
		return result;
	}

	constexpr char Utf8Bom[] = "\xEF\xBB\xBF";
}

std::string TextFile::ToUtf8(std::wstring_view text) {
	return WideToMultiByte(CP_UTF8, text);
}

std::wstring TextFile::FromUtf8(std::string_view text) {
	return MultiByteToWide(CP_UTF8, text);
}

bool TextFile::Load(PCWSTR path, std::string& utf8, TextEncoding& encoding) {
	wil::unique_hfile hFile(::CreateFile(path, GENERIC_READ, FILE_SHARE_READ, nullptr, OPEN_EXISTING, 0, nullptr));
	if (!hFile)
		return false;

	LARGE_INTEGER size;
	if (!::GetFileSizeEx(hFile.get(), &size) || size.QuadPart > 256 << 20)
		return false;

	std::string bytes((size_t)size.QuadPart, '\0');
	DWORD read = 0;
	if (!bytes.empty() && (!::ReadFile(hFile.get(), bytes.data(), (DWORD)bytes.size(), &read, nullptr) || read != bytes.size()))
		return false;

	if (bytes.size() >= 2 && (BYTE)bytes[0] == 0xFF && (BYTE)bytes[1] == 0xFE) {
		encoding = TextEncoding::Utf16;
		utf8 = ToUtf8(std::wstring_view((PCWSTR)(bytes.data() + 2), (bytes.size() - 2) / sizeof(WCHAR)));
	}
	else if (bytes.starts_with(Utf8Bom)) {
		encoding = TextEncoding::Utf8;
		utf8 = bytes.substr(3);
	}
	else {
		encoding = TextEncoding::Ansi;
		utf8 = ToUtf8(MultiByteToWide(CP_ACP, bytes));
	}
	return true;
}

bool TextFile::Save(PCWSTR path, std::string_view utf8, TextEncoding encoding) {
	std::string bytes;
	switch (encoding) {
		case TextEncoding::Utf16:
		{
			auto text = FromUtf8(utf8);
			bytes = "\xFF\xFE";
			bytes.append((const char*)text.data(), text.size() * sizeof(WCHAR));
			break;
		}
		case TextEncoding::Utf8:
			bytes = Utf8Bom;
			bytes += utf8;
			break;

		default:
			bytes = WideToMultiByte(CP_ACP, FromUtf8(utf8));
			break;
	}

	// CREATE_ALWAYS: the old contents go, even if longer than the new
	wil::unique_hfile hFile(::CreateFile(path, GENERIC_WRITE, 0, nullptr, CREATE_ALWAYS, 0, nullptr));
	if (!hFile)
		return false;

	DWORD written = 0;
	return ::WriteFile(hFile.get(), bytes.data(), (DWORD)bytes.size(), &written, nullptr) && written == bytes.size();
}

bool TextFile::FitsAnsi(std::string_view utf8) {
	BOOL usedDefault = FALSE;
	WideToMultiByte(CP_ACP, FromUtf8(utf8), &usedDefault);
	return !usedDefault;
}
```

```h
#pragma once

#include <string>
#include <string_view>

// How an INF file's text is stored. The editor always holds UTF-8; this is what the file is converted from and back to.
enum class TextEncoding {
	Ansi,		// no BOM: the ANSI code page, as SetupAPI reads such a file
	Utf8,		// UTF-8 with a BOM
	Utf16,		// UTF-16 LE with a BOM
};

struct TextFile {
	// the file's text as UTF-8, and how it was stored
	static bool Load(PCWSTR path, std::string& utf8, TextEncoding& encoding);
	// writes the text (UTF-8) as encoding, replacing the whole file
	static bool Save(PCWSTR path, std::string_view utf8, TextEncoding encoding);
	// false if the text has characters the ANSI code page can't hold (saving it as ANSI would turn them into '?')
	static bool FitsAnsi(std::string_view utf8);

	static std::string ToUtf8(std::wstring_view text);
	static std::wstring FromUtf8(std::string_view text);
};
```
