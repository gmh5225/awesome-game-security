## Known limits from inspection

- The matcher reads current IDB bytes, not the original file on disk; IDB patching changes results.
- A 16-byte literal anchor may be ambiguous, or miss code changed by relocations or compilation. It never proves the analytical claim. An `unchanged` original-address check does not assess global uniqueness.
- Scanning is synchronous but reads each block once for a batch of at most 16 records. A 16 MiB shared cap, cancellation, or uninitialized/unreadable area yields `incomplete` for changed records.
- Sidecar addresses must be plain integers within the valid 64-bit EA range (excluding `BADADDR` and anchor overflow). Boolean and giant values are rejected before IDA API calls.
- Imported claim and note lengths are bounded before Output-window rendering. Imported ID, claim, note, and path text are quoted with JSON escaping in Output messages and chooser cells, preserving the underlying stored content.
- Modal chooser lifecycle, plugin loader namespace, and file dialogs have not been exercised under IDA 9.5.

`README.md`:

```md
# Proofmark for IDA

Proofmark gives an analyst's conclusion a checkable byte anchor. Capture a short claim at the cursor, add the reasoning, and revisit the record after the IDB or binary changes. A local review table shows whether the supporting bytes are still at the same address, appear once elsewhere, appear in several places, or cannot be located reliably.

**Proofmark checks byte continuity, not truth.** An unchanged anchor does not validate the analysis. A moved match is a candidate location that must be inspected in context.

## Why this exists

IDA bookmarks and comments are useful for navigation, but a team can carry a conclusion into a new build without noticing its original evidence changed. Proofmark stores the exact bytes behind a claim and makes that drift visible. It does not sync annotations, alter the IDB, call an AI service, or require a decompiler.

Example: an analyst concludes that a parser branches on a null pointer, capturing that conclusion at the relevant instruction. In a later build, Proofmark finds that the original address changed but the 16-byte anchor appears once at a new address. It marks the record `moved_candidate`; the analyst jumps there and confirms the control flow before carrying the conclusion forward.

## Install and use

This is an experimental source prototype. It targets the IDAPython plugin API documented for IDA 9.5, but has **not yet been run in IDA 9.5**. This experimental release has passed offline tests and packaging validation; it has not been tested inside IDA. Version metadata limits installation to the intended 9.5 target, not a verified compatibility claim.

For a manual local trial, copy `proofmark.py` and `proofmark_core.py` together into IDA's user `plugins` directory, restart IDA, and open a saved IDB. Invoke **Edit → Plugins → Proofmark** and enter a command such as `c`, `v`, or `v16`:

| Command | Action |
| --- | --- |
| `c` | Capture a conclusion and optional reasoning at the current mapped address. |
| `l` or `lN` | List up to 16 records from index `N` in the Output window (`l` starts at 0). |
| `v` or `vN` | Verify up to 16 records from index `N` in the current IDB's sidecar (`v` starts at 0); inspect the table. |
| `o` or `oN` | Open a prior IDB's sidecar and verify up to 16 records from index `N` against the currently open binary. |
| `j` | Jump to the original address of a record in the current sidecar. |

The sidecar is `<IDB path>.proofmark.json`. It includes claims, notes, original addresses, and up to 16 bytes per record. Claims are limited to 512 characters and notes to 4,096. **Treat it as potentially sensitive analysis data.** The plugin makes no network requests, but a synced IDB folder may automatically transmit the sidecar under your folder-sync settings. The plugin does not write to the IDB.

Capture uses the longest contiguous initialized byte prefix at the cursor, from 8 to 16 bytes; it refuses shorter prefixes. In the verification table, select a row to jump when the bytes are unchanged or there is one moved candidate. For ambiguous, missing, or incomplete results, no destination is chosen. The Output window includes the record details and caveats. Imported text is quoted and escaped there so it cannot create forged log lines; saved claim and note content is preserved.

## Result meanings

| Status | Meaning |
| --- | --- |
| `unchanged` | The anchor bytes still occur at the original address. This quick check does **not** establish that the anchor is unique elsewhere. |
| `moved_candidate` | They differ at the original address and occur exactly once in the scanned ranges. Review the new context. |
| `ambiguous` | They occur in multiple scanned places. No location is selected. |
| `not_found` | A complete scan found no occurrence. The original bytes may have changed or disappeared. |
| `incomplete` | Cancellation, uninitialized/unreadable bytes, or the 16 MiB shared scan budget prevent a definitive classification. |

The matcher considers exact **initialized IDB bytes** only. Relocations, patched operands, and other legitimate changes can make a record `not_found`. Repeated byte sequences can make it `ambiguous`. The current prototype reads IDB bytes, which may differ from the file on disk after patching. Verification is synchronous but checks at most 16 records per invocation, reads each scan block once for the batch, shows progress and a Cancel button, and caps each batch at 16 MiB. If a segment contains uninitialized bytes, affected chunks are skipped and changed records are marked `incomplete` rather than treated as verified.

# Concept decision and source notes

Checked 2026-11-06. This is a focused prototype decision, not a claim that no comparable plugin exists.

## Differentiator

Proofmark links a human conclusion to the exact bytes seen when that conclusion was recorded, then classifies byte continuity in a later IDB. The JSON sidecar is intentionally small and readable. It makes review debt visible without auto-transferring annotations or asserting that an unchanged byte sequence proves the conclusion.

Existing tools cover neighboring jobs:

- [BinSync](https://hex-rays.com/plugin-contest/2025) synchronizes reverse-engineering state across tools and collaborators.
- [REmatch](https://github.com/nirizr/rematch) identifies similar functions and migrates annotations between databases.
- [The `oplog` example](https://docs.hex-rays.com/developer/publishing-plugins/concepts/plugin-packaging-and-format) records operations during analysis.
- [IDA 9.5 release notes](https://docs.hex-rays.com/release-notes/9_5) describe the current platform features, including newer first-party analysis tooling.

Proofmark's narrow question is: **Do the bytes that supported this particular claim still appear, and where?** That is different from syncing, migrating, or generating analysis. The design deliberately leaves semantic validation to the analyst.

- [Hex-Rays IDAPython examples](https://docs.hex-rays.com/developer/idapython/idapython-examples): chooser usage and plugin UI patterns.
- [Hex-Rays Python API reference](https://python.docs.hex-rays.com/): `ida_bytes.get_bytes`, segment enumeration, `ida_kernwin` prompts and navigation.
- [Plugin publishing guide](https://docs.hex-rays.com/developer/publishing-plugins/how-tos/plugin-publishing) and [packaging format](https://docs.hex-rays.com/developer/publishing-plugins/concepts/plugin-packaging-and-format): manifest fields, ZIP layout, GitHub release indexing and lint workflow.

`proofmark.py`:

```py
"""Proofmark: analyst claims backed by local byte anchors in IDA."""

from __future__ import annotations

from pathlib import Path

import ida_bytes
import ida_funcs
import ida_idaapi
import ida_kernwin
import ida_segment
import idc

try:
    from .proofmark_core import (ANCHOR_SIZE, DEFAULT_SCAN_LIMIT, MAX_VERIFY_BATCH,
                                 load_records, new_record, report_line, safe_text,
                                 save_records, verify_batch)
except ImportError:
    # Also support copying these two files directly into the user plugins folder.
    from proofmark_core import (ANCHOR_SIZE, DEFAULT_SCAN_LIMIT, MAX_VERIFY_BATCH,
                                load_records, new_record, report_line, safe_text,
                                save_records, verify_batch)


def _path() -> Path:
    idb_path = idc.get_idb_path()
    if not idb_path:
        raise RuntimeError("Save the IDA database before using Proofmark")
    return Path(idb_path + ".proofmark.json")


def _reader(ea: int, size: int) -> bytes | None:
    if size < 1:
        return b""
    # Zero omits GMB_READALL: IDA returns None if any byte is uninitialized.
    return ida_bytes.get_bytes(ea, size, 0)


def _ranges() -> list[tuple[int, int]]:
    result = []
    for index in range(ida_segment.get_segm_qty()):
        segment = ida_segment.getnseg(index)
        if (segment is not None and segment.end_ea > segment.start_ea
                and segment.type != ida_segment.SEG_BSS
                and not ida_segment.is_spec_segm(segment.type)):
            result.append((segment.start_ea, segment.end_ea))
    return result


def _capture(path: Path) -> None:
    ea = ida_kernwin.get_screen_ea()
    if ea == ida_idaapi.BADADDR:
        raise RuntimeError("Place the cursor on mapped bytes before capturing")
    segment = ida_segment.getseg(ea)
    if segment is None:
        raise RuntimeError("Cursor is outside a segment")
    limit = min(ANCHOR_SIZE, segment.end_ea - ea)
    anchor = None
    # Strict reads fail if even one byte is uninitialized. Retain the longest
    # contiguous initialized prefix, down to the documented eight-byte minimum.
    for size in range(limit, 7, -1):
        candidate = _reader(ea, size)
        if candidate is not None and len(candidate) == size:
            anchor = candidate
            break
    if anchor is None:
        raise RuntimeError("At least eight readable bytes are needed at the cursor")
    claim = ida_kernwin.ask_str("", 0, "Proofmark: conclusion supported by these bytes")
    if claim is None:
        return
    note = ida_kernwin.ask_text(0, "", "Proofmark: reasoning or source (optional)")
    if note is None:
        return
    function = ida_funcs.get_func_name(ea) or ""
    segment_name = ida_segment.get_segm_name(segment) or ""
    records = load_records(path)
    record = new_record(claim, note, ea, anchor, segment_name, function)
    records.append(record)
    save_records(path, records)
    ida_kernwin.msg(f"[Proofmark] Captured {safe_text(record['id'])} at 0x{ea:X} in {safe_text(str(path))}\n")


def _list(path: Path, start: int = 0) -> None:
    records = load_records(path)
    if not records:
        ida_kernwin.msg(f"[Proofmark] No records in {safe_text(str(path))}\n")
        return
    if start < 0 or start >= len(records):
        raise ValueError(f"start index must be 0 through {len(records) - 1}")
    page = records[start:start + MAX_VERIFY_BATCH]
    ida_kernwin.msg(f"[Proofmark] Records {start}..{start + len(page) - 1} of {len(records)} in {safe_text(str(path))}\n")
    for record in page:
        ida_kernwin.msg(f"  {safe_text(record['id'])}  0x{record['ea']:X}  {safe_text(record['claim'])}\n")
        if record.get("note"):
            ida_kernwin.msg(f"      {safe_text(record['note'])}\n")
    if start + len(page) < len(records):
        ida_kernwin.msg(f"[Proofmark] Run l{start + len(page)} for the next page.\n")


class ProofmarkTable(ida_kernwin.Choose):
    """A modal review table; stays alive while the plugin command is running."""

    def __init__(self, rows):
        super().__init__("Proofmark evidence review",
                         [["ID", 16], ["Status", 20], ["Address", 16], ["Claim", 80]],
                         flags=ida_kernwin.Choose.CH_QFLT)
        self.rows = rows

    def OnGetSize(self):
        return len(self.rows)

    def OnGetLine(self, n):
        record, result = self.rows[n]
        if result["status"] in ("unchanged", "moved_candidate") and len(result["matches"]) == 1:
            address = f"0x{result['matches'][0]:X}"
        else:
            address = f"orig 0x{record['ea']:X}"
        return [safe_text(record["id"]), result["status"], address, safe_text(record["claim"])]

    def OnSelectLine(self, n):
        record, result = self.rows[n]
        if result["status"] in ("unchanged", "moved_candidate"):
            ida_kernwin.jumpto(result["matches"][0])
        else:
            ida_kernwin.msg(f"[Proofmark] {safe_text(record['id'])}: {result['status']}; no safe destination.\n")
        if record.get("note"):
            ida_kernwin.msg(f"[Proofmark] Note: {safe_text(record['note'])}\n")
        return (ida_kernwin.Choose.NOTHING_CHANGED, n)


def _verify(path: Path, start: int = 0) -> None:
    records = load_records(path)
    if not records:
        ida_kernwin.msg("[Proofmark] No records to verify.\n")
        return
    if start < 0 or start >= len(records):
        raise ValueError(f"start index must be 0 through {len(records) - 1}")
    page = records[start:start + MAX_VERIFY_BATCH]
    ranges = _ranges()
    ida_kernwin.msg(f"[Proofmark] Reviewing records {start}..{start + len(page) - 1} of {len(records)}; {DEFAULT_SCAN_LIMIT // (1024 * 1024)} MiB shared scan cap.\n")
    ida_kernwin.show_wait_box("Proofmark: reviewing evidence (Cancel to stop scan)")
    try:
        results = verify_batch(
            page, _reader, ranges,
            cancel=ida_kernwin.user_cancelled,
            progress=lambda done, limit: ida_kernwin.replace_wait_box(
                f"Proofmark: scanned {done // (1024 * 1024)} / {limit // (1024 * 1024)} MiB (Cancel to stop)"),
        )
    finally:
        ida_kernwin.hide_wait_box()
    rows = list(zip(page, results))
    for record, result in rows:
        ida_kernwin.msg("  " + report_line(record, result) + "\n")
    ida_kernwin.msg("[Proofmark] 'unchanged' checks only the original address, not uniqueness. 'moved_candidate' needs manual context review. 'incomplete' means cancellation, unreadable bytes, or scan limits prevented a definitive result.\n")
    if start + len(page) < len(records):
        ida_kernwin.msg(f"[Proofmark] Run v{start + len(page)} (or o{start + len(page)}) for the next page.\n")
    ProofmarkTable(rows).Show(True)


def _jump(path: Path) -> None:
    record_id = ida_kernwin.ask_str("", 0, "Proofmark: record ID to jump to")
    if not record_id:
        return
    for record in load_records(path):
        if record["id"] == record_id.strip():
            ida_kernwin.jumpto(record["ea"])
            return
    ida_kernwin.warning(f"Proofmark record {record_id!r} not found")


class ProofmarkMod(ida_idaapi.plugmod_t):
    def run(self, arg):
        try:
            path = _path()
            choice = ida_kernwin.ask_str("c", 0, "Proofmark: c=capture, lN=list page, vN=verify page, oN=open prior sidecar, j=jump")
            if not choice:
                return
            command = choice.strip().lower()
            if command == "c":
                _capture(path)
            elif command.startswith("l"):
                _list(path, int(command[1:] or "0"))
            elif command.startswith("v"):
                _verify(path, int(command[1:] or "0"))

            elif command == "j":
                _jump(path)
            else:
                ida_kernwin.warning("Choose c, l, v, o, or j")
        except (OSError, ValueError, RuntimeError) as exc:

"""Offline evidence records and byte-anchor verification for Proofmark.

This module intentionally has no IDA dependency so the matching logic can be
tested with synthetic byte streams. A matching anchor is evidence of byte
continuity, never proof that an analyst's claim is true.
"""

from __future__ import annotations

import json
import os
import tempfile
from datetime import datetime, timezone
from pathlib import Path
from typing import Callable, Iterable
from uuid import uuid4

SCHEMA_VERSION = 1
ANCHOR_SIZE = 16
MAX_RECORDS = 10_000
MAX_SIDECAR_BYTES = 8 * 1024 * 1024
MAX_EA = (1 << 64) - 2  # Exclude IDA's 64-bit BADADDR sentinel.
MAX_VERIFY_BATCH = 16
DEFAULT_SCAN_LIMIT = 16 * 1024 * 1024  # Shared by one verification batch.
MAX_CLAIM_LENGTH = 512
MAX_NOTE_LENGTH = 4096


def new_record(claim: str, note: str, ea: int, anchor: bytes,
               segment: str = "", function: str = "") -> dict:
    claim = claim.strip()
    if not claim or len(claim) > MAX_CLAIM_LENGTH:
        raise ValueError("claim must contain 1 to 512 characters")
    if not isinstance(note, str) or len(note) > MAX_NOTE_LENGTH:
        raise ValueError("note must contain at most 4096 characters")
    if not isinstance(anchor, bytes) or not 8 <= len(anchor) <= ANCHOR_SIZE:
        raise ValueError("invalid anchor length")
    if type(ea) is not int or not 0 <= ea <= MAX_EA - len(anchor) + 1:
        raise ValueError("invalid address or anchor length")
    return {
        "id": uuid4().hex[:12],
        "created_utc": datetime.now(timezone.utc).isoformat(timespec="seconds"),
        "claim": claim,
        "note": note.strip(),
        "ea": ea,
        "anchor_hex": anchor.hex(),
        "segment": segment,
        "function": function,
    }


def _validate_record(record: dict) -> None:
    if not isinstance(record, dict):
        raise ValueError("record must be an object")
    if not isinstance(record.get("id"), str) or not 1 <= len(record["id"]) <= 64:
        raise ValueError("record id missing")
    if (not isinstance(record.get("claim"), str) or not record["claim"].strip()
            or len(record["claim"]) > MAX_CLAIM_LENGTH):
        raise ValueError("claim missing")
    if not isinstance(record.get("note", ""), str) or len(record.get("note", "")) > MAX_NOTE_LENGTH:
        raise ValueError("invalid note")
    if type(record.get("ea")) is not int or record["ea"] < 0:
        raise ValueError("invalid address")
    try:
        anchor = bytes.fromhex(record["anchor_hex"])
    except (KeyError, TypeError, ValueError) as exc:
        raise ValueError("invalid anchor hex") from exc
    if not 8 <= len(anchor) <= ANCHOR_SIZE:
        raise ValueError("invalid anchor length")
    if record["ea"] > MAX_EA - len(anchor) + 1:
        raise ValueError("address exceeds IDA's 64-bit address range")


def load_records(path: Path) -> list[dict]:
    if not path.exists():
        return []
    if path.stat().st_size > MAX_SIDECAR_BYTES:
        raise ValueError("sidecar exceeds size limit")
    data = json.loads(path.read_text(encoding="utf-8"))
    if (not isinstance(data, dict) or type(data.get("schema_version")) is not int
            or data["schema_version"] != SCHEMA_VERSION):
        raise ValueError("unsupported Proofmark schema")
    records = data.get("records")
    if not isinstance(records, list) or len(records) > MAX_RECORDS:
        raise ValueError("invalid record list")
    for record in records:
        _validate_record(record)
    if len({record["id"] for record in records}) != len(records):
        raise ValueError("duplicate record ids")
    return records


def save_records(path: Path, records: list[dict]) -> None:
    if len(records) > MAX_RECORDS:
        raise ValueError("too many records")
    for record in records:
        _validate_record(record)
    payload = json.dumps({"schema_version": SCHEMA_VERSION, "records": records},
                         indent=2, ensure_ascii=False) + "\n"
    if len(payload.encode("utf-8")) > MAX_SIDECAR_BYTES:
        raise ValueError("sidecar exceeds size limit")
    path.parent.mkdir(parents=True, exist_ok=True)
    fd, temp_name = tempfile.mkstemp(prefix=".proofmark-", suffix=".tmp", dir=path.parent)
    try:
        with os.fdopen(fd, "w", encoding="utf-8", newline="\n") as handle:
            handle.write(payload)
            handle.flush()
        os.replace(temp_name, path)
    finally:
        if os.path.exists(temp_name):
            os.unlink(temp_name)


def verify_batch(records: list[dict], reader: Callable[[int, int], bytes | None],
                 ranges: Iterable[tuple[int, int]],
                 max_bytes: int = DEFAULT_SCAN_LIMIT,
                 chunk_size: int = 64 * 1024,
                 cancel: Callable[[], bool] | None = None,
                 progress: Callable[[int, int], None] | None = None) -> list[dict]:
    """Check up to 16 anchors in one bounded, shared pass over initialized bytes.

    The reader must return None if any requested byte is uninitialized.
    Unchanged means bytes match at the original EA; global uniqueness is not checked.
    """
    if not 0 < len(records) <= MAX_VERIFY_BATCH:
        raise ValueError("verification batch must contain 1 to 16 records")
    if (type(max_bytes) is not int or max_bytes < 1
            or type(chunk_size) is not int or chunk_size < 1):
        raise ValueError("scan sizes must be positive integers")
    scan_ranges = list(ranges)
    for start, end in scan_ranges:
        if (type(start) is not int or type(end) is not int
                or start < 0 or end < start or end > MAX_EA + 1):
            raise ValueError("invalid scan range")
    results: list[dict | None] = [None] * len(records)
    pending: dict[bytes, set[int]] = {}
    for index, record in enumerate(records):
        _validate_record(record)
        anchor = bytes.fromhex(record["anchor_hex"])
        if reader(record["ea"], len(anchor)) == anchor:
            results[index] = {"id": record["id"], "status": "unchanged",
                              "matches": [record["ea"]], "scan_complete": False,
                              "uniqueness_checked": False, "cancelled": False,
                              "bytes_scanned": 0}
        else:
            pending.setdefault(anchor, set())
    if not pending:
        return results  # type: ignore[return-value]

    scanned = 0
    complete = bool(scan_ranges)
    cancelled = False
    for start, end in scan_ranges:
        pos = start
        overlap = b""
        while pos < end:
            if cancel is not None and cancel():
                complete = False
                cancelled = True
                break
            remaining = max_bytes - scanned
            if remaining <= 0:
                complete = False
                break
            size = min(chunk_size, end - pos, remaining)
            block = reader(pos, size)
            scanned += size
            if block is None or len(block) != size:
                complete = False
                overlap = b""
            else:
                haystack = overlap + block
                base = pos - len(overlap)
                for anchor, matches in pending.items():
                    if len(matches) >= 6:
                        continue
                    found = haystack.find(anchor)
                    while found >= 0 and len(matches) < 6:
                        matches.add(base + found)
                        found = haystack.find(anchor, found + 1)
                overlap = haystack[-(ANCHOR_SIZE - 1):]
            pos += size
            if progress is not None:
                progress(scanned, max_bytes)
        if cancelled or (pos < end and scanned >= max_bytes):
            break

    for index, record in enumerate(records):
        if results[index] is not None:
            continue
        matches = sorted(pending[bytes.fromhex(record["anchor_hex"])])
        if not complete:
            status = "incomplete"
        elif len(matches) == 1:
            status = "moved_candidate"
        elif len(matches) > 1:
            status = "ambiguous"
        else:
            status = "not_found"
        results[index] = {"id": record["id"], "status": status,
                          "matches": matches, "scan_complete": complete,
                          "uniqueness_checked": complete, "cancelled": cancelled,
                          "bytes_scanned": scanned}
    return results  # type: ignore[return-value]


def verify_record(record: dict, reader: Callable[[int, int], bytes | None],
                  ranges: Iterable[tuple[int, int]],
                  max_bytes: int = DEFAULT_SCAN_LIMIT,
                  chunk_size: int = 64 * 1024) -> dict:
    """One-record convenience wrapper around the bounded shared scanner."""
    return verify_batch([record], reader, ranges, max_bytes, chunk_size)[0]


def safe_text(value: str) -> str:
    """Quote untrusted text so one record cannot forge Output-window lines."""
    return json.dumps(value, ensure_ascii=True)


def report_line(record: dict, result: dict) -> str:
    locations = ", ".join(f"0x{ea:X}" for ea in result["matches"][:5])
    if len(result["matches"]) > 5:
        locations += " (+more)"
    return (f"{safe_text(record['id'])}  {result['status']:<15}  "
            f"{locations or '-':<24}  {safe_text(record['claim'])}")

class MemoryReader:
    def __init__(self, base, data, holes=()):
        self.base = base
        self.data = data
        self.holes = holes
        self.calls = []

    def __call__(self, ea, size):
        self.calls.append((ea, size))
        if any(ea < stop and ea + size > start for start, stop in self.holes):
            return None
        offset = ea - self.base
        if offset < 0 or offset + size > len(self.data):
            return None
        return self.data[offset:offset + size]

        second_anchor = b"SECONDARY-ANCHOR"
        second = new_record("second conclusion", "", 0x1100, second_anchor)
        data = b"x" * 9 + self.anchor + b"y" * 7 + second_anchor + b"z" * 4
        reader = MemoryReader(0x2000, data)
        results = verify_batch([self.record, second], reader,
                               [(0x2000, 0x2000 + len(data))], chunk_size=8)
        self.assertEqual([r["status"] for r in results], ["moved_candidate"] * 2)
        scan_calls = [call for call in reader.calls if call[0] >= 0x2000]
        self.assertEqual(len(scan_calls), (len(data) + 7) // 8)
        self.assertEqual(results[0]["bytes_scanned"], len(data))
        self.assertEqual(results[1]["bytes_scanned"], len(data))

    def test_cancel_and_global_budget_are_conservative(self):
        second = new_record("second conclusion", "", 0x1100, b"SECONDARY-ANCHOR")
        data = b"x" * 64
        reader = MemoryReader(0x2000, data)
        progress = []
        results = verify_batch([self.record, second], reader,
                               [(0x2000, 0x2040)], chunk_size=8,
                               cancel=lambda: bool(progress),
                               progress=lambda done, limit: progress.append(done))
        self.assertEqual([r["status"] for r in results], ["incomplete"] * 2)
        self.assertTrue(all(r["cancelled"] for r in results))
        self.assertEqual(progress, [8])
        limited = verify_batch([self.record, second], MemoryReader(0x2000, data),
                               [(0x2000, 0x2040)], max_bytes=16, chunk_size=8)
        self.assertEqual([r["status"] for r in limited], ["incomplete"] * 2)
        self.assertEqual([r["bytes_scanned"] for r in limited], [16, 16])

    def test_unchanged_does_not_imply_unique(self):
        data = b"1234" + self.anchor + b"----" + self.anchor
        reader = MemoryReader(0x1000, data)
        result = verify_record(self.record, reader, [(0x1000, 0x1000 + len(data))])
        self.assertEqual(result["status"], "unchanged")
        self.assertFalse(result["uniqueness_checked"])

    def test_shared_scan_matches_independent_naive_search(self):
        rng = random.Random(20261106)
        for _ in range(100):
            data = bytes(rng.choice(b"ABCD") for _ in range(96))
            offsets = [rng.randrange(0, 81), rng.randrange(0, 81)]
            anchors = [data[offset:offset + 16] for offset in offsets]
            records = [new_record(f"claim-{i}", "", 0x1000 + i * 32, anchor)
                       for i, anchor in enumerate(anchors)]
            results = verify_batch(records, MemoryReader(0x2000, data),
                                   [(0x2000, 0x2000 + len(data))],
                                   chunk_size=rng.randrange(1, 18))
            for anchor, result in zip(anchors, results):
                expected = [0x2000 + at for at in range(len(data) - len(anchor) + 1)
                            if data[at:at + len(anchor)] == anchor]
                self.assertEqual(result["matches"], expected[:6])
                self.assertEqual(result["status"], "moved_candidate" if len(expected) == 1 else "ambiguous")

    def test_partial_duplicate_exact_budget_and_empty_ranges(self):
        anchor = b"ABCDEFGH"
        record = new_record("claim", "", 0x3000, anchor)
        image = anchor + b"12345678" + anchor
        reader = MemoryReader(0x1000, image)
        full = verify_record(record, reader, [(0x1000, 0x1000 + len(image))], chunk_size=3)
        partial = verify_record(record, reader, [(0x1000, 0x1000 + len(image))],
                                max_bytes=12, chunk_size=3)
        self.assertEqual((full["status"], len(full["matches"])), ("ambiguous", 2))
        self.assertEqual((partial["status"], partial["matches"]), ("incomplete", [0x1000]))
        exact = verify_record(record, MemoryReader(0x1000, anchor),
                              [(0x1000, 0x1008)], max_bytes=8, chunk_size=3)
        self.assertEqual(exact["status"], "moved_candidate")
        self.assertTrue(exact["scan_complete"])
        empty = verify_record(record, lambda ea, size: None, [])
        self.assertEqual(empty["status"], "incomplete")
