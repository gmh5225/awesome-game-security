## Overview

Kozy AntiCheat is a lightweight, high-precision security and cheat mitigation framework built for high-performance Minecraft servers. Engineered without brittle Net.Minecraft.Server (NMS) dependencies, Kozy achieves complete cross-version stability from Minecraft 1.21 through 26.x+ and runs natively across Paper, Purpur, multi-threaded Folia, and Fabric-hybrid server environments.

By relying on standard server APIs, spatial vector math, and discrete physics simulations rather than internal bytecode hooks, Kozy remains impervious to server version fragmentation and packet shifts.

---

## Architecture and Core Principles

- **Zero-NMS Forward Compatibility**: Operates without internal obfuscated server handles. Updates to newer Minecraft versions require zero code revisions.
- **Universal Multi-Platform Runtime**: Single unified binary that supports Paper, Purpur, Pufferfish, Spigot, Folia (regionized thread scheduling), and Fabric server bridges (Cardboard, Banner, Mohist, Arclight).
- **Sub-Tick Physics Validation**: Compares player movement packets against exact server-side kinematic models, bounding box collision checks, and trajectory curves.
- **Adaptive TPS Lag Compensation**: Automatically scales check tolerance margins when the server tick rate drops below 19.5 TPS to eliminate false flags during heavy world generation or garbage collection spikes.
- **Combat Knockback Exemption**: Dynamically buffers players receiving damage knockback, environmental impulses, or low-health recoil to prevent false movement detections.
- **Staff Moderation Suite**: Features an in-game setup wizard, one-click spectator tools, official onscreen warnings, and interactive chat telemetry.

## Installation

1. Download `KozyAnticheat.jar` from the root directory or Releases.
2. Place `KozyAnticheat.jar` into your server's `plugins/` directory (or `mods/` directory for Fabric servers with a Bukkit bridge).
3. Start or restart your server.
4. The configuration file generates automatically at `plugins/KozyAnticheat/config.yml`.
5. Run `/setup` in-game as an Operator to configure profiles and toggles interactively.

## Building from Source

Kozy AntiCheat includes an automated build pipeline that compiles all source files and packages assets into a production JAR.

### Requirements

- Java Development Kit (JDK) 21 or higher
- Python 3.8 or higher

### Build Steps

1. Clone the repository:
   ```bash
   git clone https://github.com/mrKozy/KozyAntiCheat.git
   cd KozyAntiCheat
   ```

2. Run the build script:
   ```bash
   python build_kozy.py
   ```

The script will automatically resolve Spigot and Fabric dependencies, compile all 47 Java classes, package all manifests, and generate `KozyAnticheat.jar`.

```py
#!/usr/bin/env python3
"""
==============================================================================
               KOZY ANTICHEAT - AUTOMATED ENTERPRISE BUILD SYSTEM
==============================================================================
This build script compiles and packages Kozy AntiCheat into a universal,
commercial-grade JAR compatible with:
 - Paper, Purpur, Pufferfish (1.21.x - 26.x+)
 - Folia (Multi-threaded regionized server)
 - Spigot & Bukkit
 - Fabric (native Fabric Loader 0.15.0+ and Fabric-Bukkit bridges such as Cardboard/Banner/Mohist/Arclight)
"""

import os
import sys
import shutil
import subprocess
import urllib.request
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
SRC_DIR = BASE_DIR / "src" / "main" / "java"
RESOURCES_DIR = BASE_DIR / "src" / "main" / "resources"
BUILD_DIR = BASE_DIR / "build"
CLASSES_DIR = BUILD_DIR / "classes"
SPIGOT_JAR = BASE_DIR / "spigot-api-shaded.jar"
FABRIC_JAR = BASE_DIR / "fabric-loader-api.jar"
SPIGOT_URL = "https://hub.spigotmc.org/nexus/content/repositories/snapshots/org/spigotmc/spigot-api/1.21.1-R0.1-SNAPSHOT/spigot-api-1.21.1-R0.1-20241022.152140-54-shaded.jar"
FABRIC_URL = "https://maven.fabricmc.net/net/fabricmc/fabric-loader/0.15.11/fabric-loader-0.15.11.jar"
TARGET_JAR = BASE_DIR / "KozyAnticheat.jar"

def log(msg, symbol="*"):
    print(f"[{symbol}] {msg}")

def ensure_dependencies():
    if not SPIGOT_JAR.exists() or SPIGOT_JAR.stat().st_size < 1000000:
        log("Downloading Spigot API dependency...", "+")
        try:
            urllib.request.urlretrieve(SPIGOT_URL, SPIGOT_JAR)
            log("Spigot API dependency successfully resolved.", "OK")
        except Exception as e:
            log(f"Spigot dependency download error: {e}", "!")

    if not FABRIC_JAR.exists() or FABRIC_JAR.stat().st_size < 1000000:
        log("Downloading Fabric Loader API dependency...", "+")
        try:
            urllib.request.urlretrieve(FABRIC_URL, FABRIC_JAR)
            log("Fabric Loader API dependency successfully resolved.", "OK")
        except Exception as e:
            log(f"Fabric dependency download error: {e}", "!")

def compile_and_package():
    log("Step 1: Preparing build output directory...", "#")
    if CLASSES_DIR.exists():
        shutil.rmtree(CLASSES_DIR)
    CLASSES_DIR.mkdir(parents=True, exist_ok=True)

    java_files = list(SRC_DIR.rglob("*.java"))
    if not java_files:
        log("No Java source files located!", "!")
        return False

    sources_file = BUILD_DIR / "sources.txt"
    BUILD_DIR.mkdir(parents=True, exist_ok=True)
    with open(sources_file, "w", encoding="utf-8") as f:
        for jf in java_files:
            f.write(f'"{jf.as_posix()}"\n')

    log("Step 2: Compiling Java source files with Java 21...", "#")
    sep = ";" if os.name == "nt" else ":"
    cp_entries = [str(SPIGOT_JAR)]
    if FABRIC_JAR.exists():
        cp_entries.append(str(FABRIC_JAR))
    classpath_str = sep.join(cp_entries)

    cmd = [
        "javac",
        "-cp", classpath_str,
        "-d", str(CLASSES_DIR),
        "-encoding", "UTF-8",
        f"@{sources_file.as_posix()}"
    ]
    proc = subprocess.run(cmd, capture_output=True, text=True)
    if proc.returncode != 0:
        log("Compilation failure encountered:", "ERROR")
        print(proc.stderr)
        return False
    log(f"Successfully compiled {len(java_files)} classes with 0 errors.", "OK")

    log("Step 3: Packaging resources (plugin.yml, config.yml, fabric.mod.json, assets)...", "#")
    for res_item in RESOURCES_DIR.rglob("*"):
        if res_item.is_file():
            rel_path = res_item.relative_to(RESOURCES_DIR)
            dest = CLASSES_DIR / rel_path
            dest.parent.mkdir(parents=True, exist_ok=True)
            shutil.copy2(res_item, dest)
            log(f"Bundled resource: {rel_path.as_posix()}", "->")

    log(f"Step 4: Assembling universal artifact -> {TARGET_JAR.name}...", "#")
    jar_cmd = ["jar", "cvf", str(TARGET_JAR), "-C", str(CLASSES_DIR), "."]
    proc_jar = subprocess.run(jar_cmd, capture_output=True, text=True)
    if proc_jar.returncode != 0:
        log(f"JAR assembly failed: {proc_jar.stderr}", "ERROR")
        return False

    old_cozy = BASE_DIR / "CozyAnticheat.jar"
    if old_cozy.exists():
        old_cozy.unlink()

    log(f"Build complete! Binary generated: {TARGET_JAR.name} ({TARGET_JAR.stat().st_size} bytes)", "SUCCESS")
    return True

def main():
    print("=" * 70)
    print("          KOZY ANTICHEAT - ENTERPRISE BUILD PIPELINE")
    print("=" * 70)
    ensure_dependencies()
    success = compile_and_package()
    print("=" * 70)
    if success:
        print("  STATUS: SUCCESS - Kozy AntiCheat compiled and ready for deployment!")
    else:
        print("  STATUS: FAILED - Please review compilation diagnostics above.")
    print("=" * 70)

if __name__ == "__main__":
    main()

    @Override
    public void onDisable() {
        if (checkManager != null) {
            checkManager.unregisterAll();
        }
        if (playerDataManager != null) {
            playerDataManager.clearAll();
        }

        Bukkit.getConsoleSender().sendMessage(ServerUtil.color("&8[&b🛡️ Kozy&3AC&8] &cPlugin successfully disabled. Protection offline."));

    }

    @EventHandler(priority = EventPriority.MONITOR)
    public void onJoin(PlayerJoinEvent event) {
        Player player = event.getPlayer();
        PlayerData data = playerDataManager.getData(player);
        data.setLastSafeLocation(player.getLocation());
        try {
            player.updateCommands();
        } catch (Throwable ignored) {}
    }

    @EventHandler(priority = EventPriority.MONITOR)
    public void onQuit(PlayerQuitEvent event) {
        playerDataManager.remove(event.getPlayer());
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onTeleport(PlayerTeleportEvent event) {
        PlayerData data = playerDataManager.getData(event.getPlayer());
        data.setLastTeleportTime(System.currentTimeMillis());
        data.setLastSafeLocation(event.getTo());
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)

    protected final String displayName;
    protected final CheckCategory category;

        this.enabled = plugin.getConfigManager().isCheckEnabled(category.name(), id, true);
        this.maxVl = plugin.getConfigManager().getCheckMaxVl(category.name(), id, 20);
        this.setback = plugin.getConfigManager().isCheckSetback(category.name(), id, true);
    }

    public boolean shouldBypass(Player player) {
        if (player == null || !player.isOnline()) return true;
        // In survival or adventure, everyone is checked (including OPs) so testing is 100% active!
        GameMode gm = player.getGameMode();
        return gm == GameMode.CREATIVE || gm == GameMode.SPECTATOR;
    }

        if (player == null) return false;
        return player.getAllowFlight() || player.getGameMode() == GameMode.CREATIVE || player.getGameMode() == GameMode.SPECTATOR;
    }

        fail(player, data, details, 1);

        int currentVl = data.addViolation(this.id, vlAmount);

    }

        return enabled;
    }

        this.enabled = enabled;
    }

    }

        if (shouldBypass(player)) return;

        Block block = event.getBlock();
        Location eye = player.getEyeLocation();
        Location center = block.getLocation().add(0.5, 0.5, 0.5);

        if (!eye.getWorld().equals(center.getWorld())) return;

        double distance = eye.distance(center);
        if (distance > MAX_INTERACT_DISTANCE) {
            event.setCancelled(true);
            triggerFreecamViolation(player, "Block break reach (" + String.format("%.2f", distance) + "m)");

            event.setCancelled(true);
            triggerFreecamViolation(player, "Block break through wall (" + block.getType().name() + ")");

    @EventHandler(priority = EventPriority.HIGHEST, ignoreCancelled = true)
    public void onBlockPlace(BlockPlaceEvent event) {
        if (!isEnabled()) return;
        Player player = event.getPlayer();
        if (shouldBypass(player)) return;

        Location eye = player.getEyeLocation();

        if (event.getAction() != Action.RIGHT_CLICK_BLOCK && event.getAction() != Action.LEFT_CLICK_BLOCK) return;

        Block clicked = event.getClickedBlock();
        if (clicked == null) return;

        Player player = event.getPlayer();
        if (shouldBypass(player)) return;

        Location eye = player.getEyeLocation();
        Location center = clicked.getLocation().add(0.5, 0.5, 0.5);

        if (!eye.getWorld().equals(center.getWorld())) return;

                }

        return false;

            });
        }

        PlayerData data = plugin.getPlayerDataManager().getData(player);
        if (data.isExemptFromMovement()) return;

        Location to = event.getTo();
        if (to == null) return;

        Block toBlock = to.getBlock();

        if (!inWater) return;

        // Bubble columns propel players legitimately
        if (fromBlock.getType() == Material.BUBBLE_COLUMN || toBlock.getType() == Material.BUBBLE_COLUMN) return;

        double dy = to.getY() - from.getY();
        double hDist = MathUtil.horizontalDistance(from, to);

        // 1. Dolphin Hop / Water Bounce:
        // In deep water without solid blocks beneath, vertical rise is strictly limited to <= 0.15 b/t
        boolean hasSolidUnder = MathUtil.hasSolidNear(from.clone().subtract(0, 0.8, 0), 0.5);

        if (!player.hasPotionEffect(PotionEffectType.DOLPHINS_GRACE)) {

/**
 * Ultra-Responsive Fly, Hover, Jetpack, and AirWalk Interceptor.
 * Tuned with 100% precision for vanilla jump & sprint-jump physics:
 * Normal W + Space sprint-jumps and damage knockback will NEVER be false-flagged.
 * True illegal mid-air flight is instantly frozen (event.setTo(from))
 * and kicked with "Kicked by KozyAnticheat".

public class FlyCheck extends Check {

    public FlyCheck(KozyAntiCheat plugin) {
        super(plugin, "fly", "Fly", CheckCategory.MOVEMENT);
    }

    @EventHandler(priority = EventPriority.HIGHEST, ignoreCancelled = true)
    public void onToggleFlight(PlayerToggleFlightEvent event) {
        if (!isEnabled()) return;
        Player player = event.getPlayer();
        if (shouldBypass(player)) return;

        // In survival/adventure, flight toggle without allowFlight is an instant hack
        if (!canFlyLegitimately(player)) {
            event.setCancelled(true);
            player.setFlying(false);
            player.setAllowFlight(false);

            PlayerData data = plugin.getPlayerDataManager().getData(player);
            fail(player, data, "Illegal flight ability packet toggled", 10);
            kickPlayer(player);
        }
    }

    @EventHandler(priority = EventPriority.HIGHEST, ignoreCancelled = true)
    public void onMove(PlayerMoveEvent event) {
        if (!isEnabled()) return;
        Player player = event.getPlayer();
        if (shouldBypass(player)) return;

        // Legitimate flight or elytra gliding
        if (canFlyLegitimately(player) || player.isGliding() || player.isInsideVehicle() || player.isRiptiding()) return;
        if (player.hasPotionEffect(PotionEffectType.LEVITATION) || player.hasPotionEffect(PotionEffectType.SLOW_FALLING)) return;

        // Combat knockback and damage exemption: Never flag or kick players who recently took damage or are low HP
        if (player.isDead() || player.getHealth() <= 0.0 || player.getNoDamageTicks() > 0) return;

        PlayerData data = plugin.getPlayerDataManager().getData(player);
        if (data.isExemptFromMovement()) return;

        Location from = event.getFrom();
        Location to = event.getTo();
        if (to == null) return;

        // Catch hacked client claiming isFlying in survival
        if (player.isFlying()) {
            event.setTo(from);
            player.setFlying(false);
            player.setAllowFlight(false);
            fail(player, data, "Client spoofed isFlying in survival", 6);
            kickPlayer(player);
            return;
        }

        double dy = to.getY() - from.getY();
        double hDist = MathUtil.horizontalDistance(from, to);
        boolean fromSupported = MathUtil.hasGroundSupport(from);
        boolean toSupported = MathUtil.hasGroundSupport(to);

        if (fromSupported || toSupported) {
            // Player is supported by ground/water/ladder: reset air & hover tracking
            data.setAirTicks(0);
            data.setHoverTicks(0);
            data.setLastGroundY(from.getY());
            data.setLastSafeLocation(from.clone());
        } else {
            // Player is airborne
            data.incrementAirTicks();
            int airTicks = data.getAirTicks();
            double lastDy = data.getLastDeltaY();

            // 1. Calculate maximum legitimate jump height from starting ground
            double maxJumpHeight = 1.35;
            for (PotionEffect effect : player.getActivePotionEffects()) {
                if (effect.getType().equals(PotionEffectType.JUMP_BOOST)) {
                    maxJumpHeight += (effect.getAmplifier() + 1) * 0.9;
                }
            }

            double heightAboveGround = to.getY() - data.getLastGroundY();

            // Check A: Player is higher than maximum jump height and still ascending upwards
            if (heightAboveGround > maxJumpHeight && dy > 0.08) {
                event.setTo(from);
                fail(player, data, "Jump height exceeded (" + String.format("%.2f", heightAboveGround) + "m > " + String.format("%.2f", maxJumpHeight) + "m)", 3);
                if (data.getViolation("fly") >= 6) {
                    kickPlayer(player);
                }
                return;
            }

            // Check B: Mid-air ascend after already falling (Jetpack / Fly)
            // In vanilla, once you are falling (lastDy < -0.10), you CANNOT suddenly fly up without collision
            if (airTicks > 6 && dy > 0.05 && lastDy < -0.05) {
                event.setTo(from);
                fail(player, data, "Mid-air upward acceleration after fall (dy=" + String.format("%.2f", dy) + ", air=" + airTicks + ")", 3);
                if (data.getViolation("fly") >= 6) {
                    kickPlayer(player);
                }
                return;
            }

            // Check C: Extended ascend past 8 air ticks
            // In vanilla, normal jump ascents strictly finish by tick 5-6 (dy becomes negative)
            if (airTicks > 8 && dy > 0.05) {
                event.setTo(from);
                fail(player, data, "Ascent duration exceeded (dy=" + String.format("%.2f", dy) + ", air=" + airTicks + ")", 3);
                if (data.getViolation("fly") >= 6) {
                    kickPlayer(player);
                }
                return;
            }

            // Check D: True Hovering in mid-air
            // Note: At the apex of a normal jump (tick 5), dy is mathematically ~0.0030 for EXACTLY 1 TICK.
            // Fly / Hover cheats stay near 0 for 3 or more consecutive ticks!
            if (Math.abs(dy) < 0.005) {
                data.incrementHoverTicks();
                if (data.getHoverTicks() >= 3 && airTicks > 4) {
                    event.setTo(from);
                    fail(player, data, "Sustained mid-air hover blocked (" + data.getHoverTicks() + " ticks, dy=" + String.format("%.4f", dy) + ")", 3);
                    if (data.getViolation("fly") >= 6) {
                        kickPlayer(player);
                    }
                    return;
                }
            } else {
                data.setHoverTicks(0);
            }

            // Check E: AirWalk / Flying horizontally across the void
            // In vanilla, a sprint jump ends in a fall. If airTicks > 12 and player is still moving fast without falling:
            if (airTicks > 12 && hDist > 0.35 && dy >= -0.05) {
                event.setTo(from);
                fail(player, data, "AirWalk horizontal velocity blocked (dist=" + String.format("%.2f", hDist) + ", air=" + airTicks + ")", 3);
                if (data.getViolation("fly") >= 6) {
                    kickPlayer(player);
                }
                return;
            }
        }

        data.setLastDeltaY(dy);
    }

            data.setIceTicks(20);
        } else if (data.getIceTicks() > 0) {
            maxSpeed += 0.25;
            data.setIceTicks(data.getIceTicks() - 1);
        }

        // Slime block compensation
        if (type == Material.SLIME_BLOCK) {
            maxSpeed += 0.3;
        }

            maxSpeed += 0.4;

        maxSpeed *= lagFactor;

            if (this.setback) {

 * Instantly intercepts flying boats, ejects the pilot, deletes the illegal vehicle,
 * and kicks offenders with "Kicked by KozyAnticheat".

public class VehicleFlyCheck extends Check {

    public VehicleFlyCheck(KozyAntiCheat plugin) {
        super(plugin, "vehicle-fly", "BoatFly", CheckCategory.MOVEMENT);
    }

    @EventHandler(priority = EventPriority.HIGHEST)
    public void onVehicleMove(VehicleMoveEvent event) {
        if (!isEnabled()) return;
        Entity vehicle = event.getVehicle();
        if (!(vehicle instanceof Boat)) return;

        Player player = null;
        for (Entity passenger : vehicle.getPassengers()) {
            if (passenger instanceof Player) {
                player = (Player) passenger;
                break;
            }
        }
        if (player == null || shouldBypass(player)) return;

        Location from = event.getFrom();
        Location to = event.getTo();
        if (to == null) return;

        double dy = to.getY() - from.getY();
        double hDist = MathUtil.horizontalDistance(from, to);

        boolean supported = hasBoatSupport(to) || hasBoatSupport(from);

        if (!supported) {
            // Boat defying gravity in mid-air (BoatFly Ascend/Hover)
            if (dy >= -0.04) {
                handleBoatFly(player, vehicle, from, "Mid-air boat ascend/hover (dy=" + String.format("%.2f", dy) + ")");
                return;
            }

            // High-speed BoatFly through the sky
            if (hDist > 0.35) {
                handleBoatFly(player, vehicle, from, "Mid-air boat horizontal flight (dist=" + String.format("%.2f", hDist) + ")");
            }
        }
    }

    @EventHandler(priority = EventPriority.HIGHEST, ignoreCancelled = true)
    public void onPlayerMoveVehicle(PlayerMoveEvent event) {
        if (!isEnabled()) return;
        Player player = event.getPlayer();
        if (shouldBypass(player)) return;

        if (player.isInsideVehicle() && player.getVehicle() instanceof Boat) {
            Entity boat = player.getVehicle();
            Location to = event.getTo();
            Location from = event.getFrom();
            if (to == null) return;

            double dy = to.getY() - from.getY();
            double hDist = MathUtil.horizontalDistance(from, to);
            boolean supported = hasBoatSupport(to) || hasBoatSupport(from);

            if (!supported && (dy >= -0.04 || hDist > 0.35)) {
                event.setTo(from);
                handleBoatFly(player, boat, from, "Player-packet BoatFly detected");
            }
        }
    }

    private boolean hasBoatSupport(Location loc) {
        if (loc == null || loc.getWorld() == null) return false;
        double x = loc.getX();
        double y = loc.getY();
        double z = loc.getZ();

        int minX = (int) Math.floor(x - 0.7);
        int maxX = (int) Math.floor(x + 0.7);
        int minZ = (int) Math.floor(z - 0.7);
        int maxZ = (int) Math.floor(z + 0.7);
        int minY = (int) Math.floor(y - 0.7);
        int maxY = (int) Math.floor(y + 0.2);

        for (int bx = minX; bx <= maxX; bx++) {
            for (int by = minY; by <= maxY; by++) {
                for (int bz = minZ; bz <= maxZ; bz++) {
                    Block b = loc.getWorld().getBlockAt(bx, by, bz);
                    if (b.getType().isSolid() || b.isLiquid()) {
                        return true;
                    }
                }
            }
        }
        return false;
    }

    private void handleBoatFly(Player player, Entity vehicle, Location from, String details) {
        PlayerData data = plugin.getPlayerDataManager().getData(player);
        fail(player, data, details, 10);

        ServerUtil.runSync(plugin, () -> {
            try {
                vehicle.eject();
                vehicle.remove();
            } catch (Throwable ignored) {}
            ServerUtil.teleportSafe(player, from);
            player.kickPlayer("Kicked by KozyAnticheat");
        });

        Block block = event.getBlock();
        Material type = block.getType();

        PlayerData data = plugin.getPlayerDataManager().getData(player);

        if (isCommonBlock(type)) {
            data.incrementCommonBlocksMined();
        } else if (isRareOre(type)) {
            data.incrementRareOresMined();

            int rare = data.getRareOresMined();
            int common = data.getCommonBlocksMined();
            int total = rare + common;

            if (rare >= 8 && total >= 15) {
                double ratio = (double) rare / total;
                // Vanilla ore density is < 2-4%. A mining ratio > 25% directly indicates X-Ray vision
                if (ratio > 0.25) {
                    double percent = Math.round(ratio * 1000.0) / 10.0;
                    fail(player, data, "Abnormal ore ratio: " + percent + "% (" + rare + " ores / " + total + " blocks)");
                }
            }
        }

                || type == Material.ANCIENT_DEBRIS
                || type == Material.EMERALD_ORE || type == Material.DEEPSLATE_EMERALD_ORE
                || type == Material.GOLD_ORE || type == Material.DEEPSLATE_GOLD_ORE
                || type == Material.NETHER_GOLD_ORE;
    }

    private boolean isCommonBlock(Material type) {
        return type == Material.STONE || type == Material.DEEPSLATE
                || type == Material.NETHERRACK || type == Material.TUFF
                || type == Material.ANDESITE || type == Material.DIORITE
                || type == Material.GRANITE || type == Material.DIRT

                    sender.sendMessage(ServerUtil.color("&8- &7" + check.getCategory().getDisplayName() + " &8» &e" + check.getDisplayName() + " " + status + " &8(&7Max-VL: &c" + check.getMaxVl() + "&8)"));
                }
                sender.sendMessage(ServerUtil.color("&8&m----------------------------------------"));
                break;

            case "clearvl":
                if (args.length < 2) {
                    sender.sendMessage(ServerUtil.color(plugin.getConfigManager().getPrefix() + "&cUsage: /" + label + " clearvl <player>"));
                    return true;
                }
                Player clearTarget = Bukkit.getPlayer(args[1]);
                if (clearTarget == null) {
                    sender.sendMessage(plugin.getConfigManager().getMessage("player-not-found"));
                    return true;
                }
                PlayerData clearData = plugin.getPlayerDataManager().getData(clearTarget);
                clearData.clearViolations();
                sender.sendMessage(plugin.getConfigManager().getMessage("vl-cleared").replace("%player%", clearTarget.getName()));
                break;

            case "spectate":
                String[] specArgs = Arrays.copyOfRange(args, 1, args.length);
                return handleSpectate(sender, specArgs);

            case "listmods":
                return handleListMods(sender);

            case "warn":
                String[] warnArgs = Arrays.copyOfRange(args, 1, args.length);
                return handleWarn(sender, warnArgs);

            case "ban":
                String[] banArgs = Arrays.copyOfRange(args, 1, args.length);
                return handleBan(sender, banArgs);

            case "kick":
                String[] kickArgs = Arrays.copyOfRange(args, 1, args.length);
                return handleKick(sender, kickArgs);

            case "setup":
                String[] setupArgs = Arrays.copyOfRange(args, 1, args.length);
                return handleSetup(sender, setupArgs);

            default:
                sendHelp(sender, label);
                break;
        }

        return true;
    }

    private boolean handleSpectate(CommandSender sender, String[] args) {
        if (!hasAdmin(sender)) {
            sender.sendMessage(plugin.getConfigManager().getMessage("no-permission"));
            return true;
        }
        if (!(sender instanceof Player)) {
            sender.sendMessage(ServerUtil.color("&cSpectate mode is exclusively available for in-game staff."));
            return true;
        }

        Player staff = (Player) sender;
        PlayerData staffData = plugin.getPlayerDataManager().getData(staff);

        // Toggle off if currently spectating
        if (staffData.isSpectating()) {
            staffData.setSpectating(false);
            if (staffData.getPreviousSpectateLocation() != null) {
                ServerUtil.teleportSafe(staff, staffData.getPreviousSpectateLocation());
            }
            if (staffData.getPreviousGameMode() != null) {
                staff.setGameMode(staffData.getPreviousGameMode());
            } else {
                staff.setGameMode(GameMode.SURVIVAL);
            }
            staff.sendMessage(ServerUtil.color(plugin.getConfigManager().getPrefix() + "&aExited spectator mode. Restored original position and state."));
            return true;
        }

        if (args.length < 1) {
            staff.sendMessage(ServerUtil.color(plugin.getConfigManager().getPrefix() + "&cUsage: /spectate <player>"));
            return true;
        }

        Player target = Bukkit.getPlayer(args[0]);
        if (target == null || !target.isOnline()) {
            staff.sendMessage(plugin.getConfigManager().getMessage("player-not-found"));
            return true;
        }

        if (target.equals(staff)) {
            staff.sendMessage(ServerUtil.color(plugin.getConfigManager().getPrefix() + "&cYou cannot spectate yourself."));
            return true;
        }

        // Save state and engage spectator
        staffData.setSpectating(true);
        staffData.setPreviousGameMode(staff.getGameMode());
        staffData.setPreviousSpectateLocation(staff.getLocation().clone());

        staff.setGameMode(GameMode.SPECTATOR);
        ServerUtil.teleportSafe(staff, target.getLocation());
        staff.setSpectatorTarget(target);

        staff.sendMessage(ServerUtil.color(plugin.getConfigManager().getPrefix() + "&aNow spectating &e" + target.getName() + "&a. Type &e/spectate &aagain to exit and restore your original position."));
        return true;
    }

            return true;

        String reason = args.length > 1 ? String.join(" ", Arrays.copyOfRange(args, 1, args.length)) : "Suspicious gameplay behavior";
        PlayerData tData = plugin.getPlayerDataManager().getData(target);
        tData.incrementWarningCount();

        // Send screen title & warning sound to target
        try {
            target.sendTitle(ServerUtil.color("&c&lOFFICIAL WARNING"), ServerUtil.color("&e" + reason), 10, 70, 20);
        } catch (Throwable ignored) {}
        target.sendMessage(ServerUtil.color("&8&m----------------------------------------"));
        target.sendMessage(ServerUtil.color("&c&lWARNING FROM STAFF &8(#" + tData.getWarningCount() + ")"));
        target.sendMessage(ServerUtil.color("&7You have received an official warning: &f" + reason));
        target.sendMessage(ServerUtil.color("&cFurther infractions will result in an immediate temporary or permanent ban!"));
        target.sendMessage(ServerUtil.color("&8&m----------------------------------------"));
        ServerUtil.playAlertSound(target, "BLOCK_NOTE_BLOCK_PLING");

        // Broadcast to staff
        String staffName = sender instanceof Player ? sender.getName() : "Console";
        String broadcast = ServerUtil.color("&8[&b🛡️ Kozy&3AC&8] &c" + staffName + " &7issued Warning #" + tData.getWarningCount() + " to &e" + target.getName() + "&7: &f" + reason);
        for (Player p : Bukkit.getOnlinePlayers()) {
            if (p.hasPermission("kozyanticheat.alerts")) {
                p.sendMessage(broadcast);
            }
        }
        Bukkit.getConsoleSender().sendMessage(broadcast);
        return true;
    }

    @Override
    public List<String> onTabComplete(CommandSender sender, Command command, String alias, String[] args) {
        if (!hasAdmin(sender)) return Collections.emptyList();

        String cmdName = command.getName().toLowerCase();
        if (cmdName.equals("spectate") || cmdName.equals("warn") || cmdName.equals("ermahnen")) {
            if (args.length == 1) {
                return Bukkit.getOnlinePlayers().stream()
                        .map(Player::getName)
                        .filter(name -> name.toLowerCase().startsWith(args[0].toLowerCase()))
                        .collect(Collectors.toList());
            }
            return Collections.emptyList();
        }

        if (args.length == 1) {
            List<String> subs = Arrays.asList("help", "setup", "spectate", "warn", "listmods", "alerts", "info", "checks", "clearvl", "reload", "ban", "kick");
            return subs.stream().filter(s -> s.startsWith(args[0].toLowerCase())).collect(Collectors.toList());
        }

        if (args.length == 2) {
            String sub = args[0].toLowerCase();
            if (sub.equals("info") || sub.equals("clearvl") || sub.equals("spectate") || sub.equals("warn") || sub.equals("ban") || sub.equals("kick")) {
                return Bukkit.getOnlinePlayers().stream()
                        .map(Player::getName)
                        .filter(name -> name.toLowerCase().startsWith(args[1].toLowerCase()))
                        .collect(Collectors.toList());
            }
            if (sub.equals("setup")) {
                return Arrays.asList("profile", "toggle");
            }
        }

        if (args.length == 3 && args[0].equalsIgnoreCase("setup")) {
            if (args[1].equalsIgnoreCase("profile")) {
                return Arrays.asList("balanced", "strict", "casual");
            }
            if (args[1].equalsIgnoreCase("toggle")) {
                return Arrays.asList("punishments", "rubberband", "lagcomp", "sound");
            }
        }

        return Collections.emptyList();
    }

package de.kozy.anticheat.config;

import de.kozy.anticheat.KozyAntiCheat;
import de.kozy.anticheat.util.ServerUtil;
import org.bukkit.configuration.ConfigurationSection;
import org.bukkit.configuration.file.FileConfiguration;

import java.util.*;

public class ConfigManager {

    private final KozyAntiCheat plugin;
    private String prefix;
    private boolean alertSound;
    private String soundName;
    private boolean autoRubberband;
    private int vlDecaySeconds;
    private int vlDecayAmount;
    private final Map<String, String> messages = new HashMap<>();
    private final List<PunishmentRule> punishmentRules = new ArrayList<>();

    public static class PunishmentRule {
        private final int vl;
        private final String command;

        public PunishmentRule(int vl, String command) {
            this.vl = vl;
            this.command = command;
        }

        public int getVl() {
            return vl;
        }

        public String getCommand() {
            return command;
        }
    }

    public ConfigManager(KozyAntiCheat plugin) {
        this.plugin = plugin;
    }

    public void load() {
        plugin.saveDefaultConfig();
        plugin.reloadConfig();
        FileConfiguration config = plugin.getConfig();

        this.prefix = ServerUtil.color(config.getString("settings.prefix", "&8[&b&lKozy&3AC&8] "));
        this.alertSound = config.getBoolean("settings.alert-sound", true);
        this.soundName = config.getString("settings.sound-name", "BLOCK_NOTE_BLOCK_PLING");
        this.autoRubberband = config.getBoolean("settings.auto-rubberband", true);
        this.vlDecaySeconds = config.getInt("settings.vl-decay-seconds", 15);
        this.vlDecayAmount = config.getInt("settings.vl-decay-amount", 1);

        // Load messages
        messages.clear();
        ConfigurationSection msgSec = config.getConfigurationSection("messages");
        if (msgSec != null) {
            for (String key : msgSec.getKeys(false)) {
                String raw = msgSec.getString(key, "");
                messages.put(key, ServerUtil.color(raw.replace("%prefix%", this.prefix)));
            }
        }

        // Load punishments
        punishmentRules.clear();
        if (config.getBoolean("punishments.enabled", true)) {
            List<Map<?, ?>> actionList = config.getMapList("punishments.actions");
            for (Map<?, ?> entry : actionList) {
                Object vlObj = entry.get("vl");
                Object cmdObj = entry.get("command");
                if (vlObj instanceof Number && cmdObj instanceof String) {
                    punishmentRules.add(new PunishmentRule(((Number) vlObj).intValue(), (String) cmdObj));
                }
            }
        }
    }

    public String getPrefix() {
        return prefix;
    }

    public boolean isAlertSound() {
        return alertSound;
    }

    public String getSoundName() {
        return soundName;
    }

    public boolean isAutoRubberband() {
        return autoRubberband;
    }

    public int getVlDecaySeconds() {
        return vlDecaySeconds;
    }

    public int getVlDecayAmount() {
        return vlDecayAmount;
    }

    public String getMessage(String key) {
        return messages.getOrDefault(key, prefix + "&cMissing message: " + key);
    }

    public List<PunishmentRule> getPunishmentRules() {
        return Collections.unmodifiableList(punishmentRules);
    }

    public boolean isCheckEnabled(String category, String checkName, boolean def) {
        return plugin.getConfig().getBoolean("checks." + category.toLowerCase() + "." + checkName.toLowerCase() + ".enabled", def);
    }

    public int getCheckMaxVl(String category, String checkName, int def) {
        return plugin.getConfig().getInt("checks." + category.toLowerCase() + "." + checkName.toLowerCase() + ".max-vl", def);
    }

        return plugin.getConfig().getBoolean("checks." + category.toLowerCase() + "." + checkName.toLowerCase() + ".setback", def);

        return plugin.getConfig().getDouble(path, def);

package de.kozy.anticheat.util;

import org.bukkit.Location;
import org.bukkit.Material;
import org.bukkit.block.Block;
import org.bukkit.entity.Entity;
import org.bukkit.entity.Player;
import org.bukkit.util.Vector;

import java.util.Collection;

public final class MathUtil {

    private MathUtil() {}

    public static double horizontalDistance(Location from, Location to) {
        if (!from.getWorld().equals(to.getWorld())) return 0.0;
        double dx = to.getX() - from.getX();
        double dz = to.getZ() - from.getZ();
        return Math.sqrt(dx * dx + dz * dz);
    }

    public static double getAngle(Player player, Entity target) {
        Location eye = player.getEyeLocation();
        Vector toTarget = target.getLocation().add(0, target.getHeight() / 2.0, 0).toVector().subtract(eye.toVector());
        Vector direction = eye.getDirection();

        double dot = toTarget.normalize().dot(direction.normalize());
        dot = Math.max(-1.0, Math.min(1.0, dot));
        return Math.toDegrees(Math.acos(dot));
    }

    public static double calculateStandardDeviation(Collection<Long> intervals) {
        if (intervals == null || intervals.size() < 4) return 999.0;
        double sum = 0.0;
        for (long val : intervals) sum += val;
        double mean = sum / intervals.size();

        double variance = 0.0;
        for (long val : intervals) {
            variance += Math.pow(val - mean, 2);
        }
        return Math.sqrt(variance / intervals.size());
    }

    public static boolean hasSolidNear(Location loc, double radius) {
        int minX = (int) Math.floor(loc.getX() - radius);
        int maxX = (int) Math.floor(loc.getX() + radius);
        int minY = (int) Math.floor(loc.getY() - radius);
        int maxY = (int) Math.floor(loc.getY() + radius);
        int minZ = (int) Math.floor(loc.getZ() - radius);
        int maxZ = (int) Math.floor(loc.getZ() + radius);

        for (int x = minX; x <= maxX; x++) {
            for (int y = minY; y <= maxY; y++) {
                for (int z = minZ; z <= maxZ; z++) {
                    Block block = loc.getWorld().getBlockAt(x, y, z);
                    if (block.getType().isSolid()) {
                        return true;
                    }
                }
            }
        }
        return false;
    }

    public static boolean hasGroundSupport(Location loc) {
        if (loc == null || loc.getWorld() == null) return false;
        double x = loc.getX();
        double y = loc.getY();
        double z = loc.getZ();

        // Check 3x3 column below player's bounding box feet (y - 0.55 to y)
        int minX = (int) Math.floor(x - 0.35);
        int maxX = (int) Math.floor(x + 0.35);
        int minZ = (int) Math.floor(z - 0.35);
        int maxZ = (int) Math.floor(z + 0.35);
        int minY = (int) Math.floor(y - 0.55);
        int maxY = (int) Math.floor(y + 0.1);

        for (int bx = minX; bx <= maxX; bx++) {
            for (int by = minY; by <= maxY; by++) {
                for (int bz = minZ; bz <= maxZ; bz++) {
                    Block b = loc.getWorld().getBlockAt(bx, by, bz);
                    if (b.getType().isSolid() || b.isLiquid() || isClimbableOrWeb(b)) {
                        return true;
                    }
                }
            }
        }
        return false;
    }

    public static boolean isClimbableOrWeb(Block block) {
        if (block == null) return false;
        Material type = block.getType();
        String name = type.name();
        return name.contains("LADDER") || name.contains("VINE") || name.contains("SCAFFOLDING") || name.contains("COBWEB");
    }

    public static boolean isLiquid(Block block) {
        if (block == null) return false;
        return block.isLiquid();
    }
}

package de.kozy.anticheat.util;

/**
 * Universal Server and Telemetry Utilities for Kozy AntiCheat.
 * Fully compatible with Spigot, Paper, Purpur, Folia, and Fabric-hybrid server architectures.
 */
public final class ServerUtil {

    private ServerUtil() {}

    public static String color(String message) {
        if (message == null) return "";
        return ChatColor.translateAlternateColorCodes('&', message);
    }

    public static int getPing(Player player) {
        try {
            return player.getPing();
        } catch (Throwable ignored) {
            return 0;
        }
    }

    public static double getTps() {
        try {
            Method spigotMethod = Bukkit.getServer().getClass().getMethod("spigot");
            Object spigot = spigotMethod.invoke(Bukkit.getServer());
            Method getTPSMethod = spigot.getClass().getMethod("getTPS");
            double[] tps = (double[]) getTPSMethod.invoke(spigot);
            if (tps != null && tps.length > 0) {
                return Math.min(20.0, Math.round(tps[0] * 100.0) / 100.0);
            }
        } catch (Throwable ignored) {}

        try {
            Method getTPSMethod = Bukkit.class.getMethod("getTPS");
            double[] tps = (double[]) getTPSMethod.invoke(null);
            if (tps != null && tps.length > 0) {
                return Math.min(20.0, Math.round(tps[0] * 100.0) / 100.0);
            }
        } catch (Throwable ignored) {}

        return 20.0;
    }

    /**
     * Calculates dynamic tolerance factor based on server tick performance.
     * Prevents false positives during high server load or temporary tick spikes.
     */
    public static double getLagCompensationFactor() {
        double tps = getTps();
        if (tps >= 19.5) return 1.0;
        return Math.max(1.0, Math.min(1.6, 20.0 / Math.max(1.0, tps)));
    }

    /**
     * Plays alert chime safely across various Minecraft versions.
     */
    public static void playAlertSound(Player player, String soundName) {
        if (player == null || !player.isOnline()) return;
        try {
            Sound sound = Sound.valueOf(soundName.toUpperCase());
            player.playSound(player.getLocation(), sound, 1.0f, 1.5f);
        } catch (IllegalArgumentException e) {
            try {
                player.playSound(player.getLocation(), Sound.BLOCK_NOTE_BLOCK_PLING, 1.0f, 1.5f);
            } catch (Throwable ignored) {}
        }
    }

    /**
     * Executes a task synchronously on the appropriate main or region thread,
     * maintaining compatibility with Folia, Paper, and standard Spigot.
     */
    public static void runSync(Plugin plugin, Runnable task) {
        try {
            Method getGlobalRegionScheduler = Bukkit.class.getMethod("getGlobalRegionScheduler");
            Object scheduler = getGlobalRegionScheduler.invoke(null);
            Method execute = scheduler.getClass().getMethod("execute", Plugin.class, Runnable.class);
            execute.invoke(scheduler, plugin, task);
            return;
        } catch (Throwable ignored) {}

        Bukkit.getScheduler().runTask(plugin, task);
    }

    /**
     * Safely teleports an entity on Folia, Paper, or Spigot servers.
     */
    public static void teleportSafe(Entity entity, Location location) {
        if (entity == null || location == null) return;
        try {
            Method tpAsync = entity.getClass().getMethod("teleportAsync", Location.class);
            tpAsync.invoke(entity, location);
            return;
        } catch (Throwable ignored) {}

        entity.teleport(location);
    }
}

package de.kozy.anticheat.violation;

/**
 * Enterprise Telemetry and Violation Dispatcher for Kozy AntiCheat.

public class ViolationManager {

    private final KozyAntiCheat plugin;

    public ViolationManager(KozyAntiCheat plugin) {
        this.plugin = plugin;
        startDecayTask();
    }

    public void handleViolation(Player player, PlayerData data, Check check, String details, int currentVl) {
        String format = plugin.getConfigManager().getMessage("alert-format");
        int ping = ServerUtil.getPing(player);
        double tps = ServerUtil.getTps();

        String alertMsg = format
                .replace("%player%", player.getName())
                .replace("%check%", check.getDisplayName())
                .replace("%detail%", details != null ? details : "none")
                .replace("%ping%", String.valueOf(ping))
                .replace("%vl%", String.valueOf(currentVl));

        Location loc = player.getLocation();
        String hoverText = ServerUtil.color(
                "&b&l" + player.getName() + " &8(" + check.getDisplayName() + ")\n" +
                "&7Details: &c" + (details != null ? details : "None") + "\n" +
                "&7Latency: &e" + ping + "ms &8| &7Server TPS: &a" + tps + "\n" +
                "&7Coordinates: &fX=" + loc.getBlockX() + " Y=" + loc.getBlockY() + " Z=" + loc.getBlockZ() + "\n" +
                "&7Total VL: &c" + data.getTotalViolations() + "\n\n" +
                "&a» Click to teleport directly to player!"
        );

        // Build interactive JSON chat component
        TextComponent component = new TextComponent(alertMsg);
        component.setHoverEvent(new HoverEvent(HoverEvent.Action.SHOW_TEXT, new ComponentBuilder(hoverText).create()));
        component.setClickEvent(new ClickEvent(ClickEvent.Action.RUN_COMMAND, "/tp " + player.getName()));

        TextComponent tpBtn = new TextComponent(ServerUtil.color(" &8[&a&lTP&8]"));
        tpBtn.setHoverEvent(new HoverEvent(HoverEvent.Action.SHOW_TEXT, new ComponentBuilder(ServerUtil.color("&aTeleport to &e" + player.getName())).create()));
        tpBtn.setClickEvent(new ClickEvent(ClickEvent.Action.RUN_COMMAND, "/tp " + player.getName()));

        TextComponent infoBtn = new TextComponent(ServerUtil.color(" &8[&b&lINFO&8]"));
        infoBtn.setHoverEvent(new HoverEvent(HoverEvent.Action.SHOW_TEXT, new ComponentBuilder(ServerUtil.color("&bView telemetry for &e" + player.getName())).create()));
        infoBtn.setClickEvent(new ClickEvent(ClickEvent.Action.RUN_COMMAND, "/kozy info " + player.getName()));

        component.addExtra(tpBtn);
        component.addExtra(infoBtn);

        // Dispatch alert to authorized staff members
        for (Player staff : Bukkit.getOnlinePlayers()) {
            if (staff.hasPermission("kozyanticheat.alerts")) {
                PlayerData staffData = plugin.getPlayerDataManager().getData(staff);
                if (staffData.isAlertsEnabled()) {
                    try {
                        staff.spigot().sendMessage(component);
                    } catch (Throwable fallback) {
                        staff.sendMessage(alertMsg);
                    }
                    if (plugin.getConfigManager().isAlertSound()) {
                        ServerUtil.playAlertSound(staff, plugin.getConfigManager().getSoundName());
                    }
                }
            }
        }

        // Log to server console
        Bukkit.getConsoleSender().sendMessage(alertMsg);

        // Check punishment actions
        List<ConfigManager.PunishmentRule> rules = plugin.getConfigManager().getPunishmentRules();
        for (ConfigManager.PunishmentRule rule : rules) {
            if (currentVl == rule.getVl()) {
                String cmd = rule.getCommand()
                        .replace("%player%", player.getName())
                        .replace("%check%", check.getDisplayName())
                        .replace("%vl%", String.valueOf(currentVl));
                
                // Dispatch punishment safely across Folia and Paper
                ServerUtil.runSync(plugin, () -> {
                    Bukkit.dispatchCommand(Bukkit.getConsoleSender(), cmd);
                });
                break;
            }
        }
    }

    private void startDecayTask() {
        long intervalTicks = Math.max(20L, plugin.getConfigManager().getVlDecaySeconds() * 20L);
        Bukkit.getScheduler().runTaskTimerAsynchronously(plugin, () -> {
            int amount = plugin.getConfigManager().getVlDecayAmount();
            for (PlayerData data : plugin.getPlayerDataManager().getAll()) {
                data.decayViolations(amount);
            }
        }, intervalTicks, intervalTicks);
    }
}
