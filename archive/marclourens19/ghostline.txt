# Ghostline

[![.NET Core CI](https://github.com/marclourens19/ghostline/actions/workflows/dotnet.yml/badge.svg)](https://github.com/marclourens19/ghostline/actions/workflows/dotnet.yml)
[![Replay Viewer](https://img.shields.io/badge/Web_Viewer-GitHub_Pages-blue?logo=github)](https://marclourens19.github.io/ghostline/)
![Status](https://img.shields.io/badge/Status-Milestone%204.2%20Active-brightgreen)
![License](https://img.shields.io/badge/License-MIT-blue.svg)

> **Live Replay Inspector:** [https://marclourens19.github.io/ghostline/](https://marclourens19.github.io/ghostline/) — Drag and drop any `.replay` file to inspect tick telemetry, spatial inputs, and hit calculations directly in the browser.

![Ghostline Gameplay and Replay Spectator](docs/assets/gameplay.png)

Ghostline is a top-down 2D arena shooter built to demonstrate **authoritative server-side replay verification** for cheat-proof leaderboards.

Instead of trusting client-reported high scores or raw coordinates, the Godot game client records user input vectors tick-by-tick and packs them into a compact binary format (`GHST`, 15 bytes per frame). Upon match completion, the ASP.NET Core backend deserializes this stream and runs a headless, deterministic simulation of the entire match using integer-only fixed-point math. A score is only committed to the PostgreSQL leaderboard if the server's computed simulation state matches the client's claim.

---

### Core Components

- **`src/Ghostline.Simulation/`**: Pure C# .NET 8 headless engine with zero external game-engine dependencies. Uses integer fixed-point vector math (1,000 millipixels = 1 visual pixel) to guarantee deterministic simulation across Windows desktop and Linux server runtimes.
- **`src/Ghostline.Api/`**: Containerized ASP.NET Core Minimal API handling replay ingestion, binary bounds checking, SHA-256 deduplication, IP-partitioned rate limiting, headless verification, and PostgreSQL leaderboard persistence with pagination and seed filtering.
- **`client/`**: Godot 4 .NET game client responsible for rendering simulation state, managing the HUD overlay, recording player inputs, and providing tick-accurate ghost spectating.
- **`web/`**: Zero-dependency HTML5 Canvas and JavaScript Replay Inspector deployed on GitHub Pages. Unpacks the 15-byte `GHST` frames directly in the browser with timeline scrubbing and live telemetry.
- **[`docs/replay-format.md`](docs/replay-format.md)**: Complete byte-level technical specification of the `GHST` binary replay format.

## How to Run

### 1. Launch Backend Infrastructure

Ensure Docker Desktop is running, create your local `.env` configuration, and initialize the API and PostgreSQL containers:

```bash
docker compose up --build -d
```

The API starts on port `5000`, with Swagger documentation available at:

[http://localhost:5000/swagger](http://localhost:5000/swagger)

### 2. Launch the Client

1. Open the project inside **Godot 4.x (.NET version)**.
2. Build the C# solution inside Godot or via the .NET CLI:

   ```bash
   dotnet build
   ```

3. Press **F5** to start the client.

### 3. Run the Automated Test Suite

Execute unit determinism tests, serialization fuzzing, and `WebApplicationFactory` in-memory integration tests:

```bash
dotnet test tests/Ghostline.Simulation.Tests/Ghostline.Simulation.Tests.csproj
```

| --- | --- | --- |
| `GET` | `/api/health/db` | Health check verifying raw PostgreSQL connectivity and record counts. |
| `POST` | `/api/runs` | Submits a run payload (`PlayerName`, `ClaimedScore`, `Seed`, `ReplayBase64`). Protected by IP-partitioned rate limiting and SHA-256 deduplication. |

| `GET` | `/api/runs/{id}/replay` | Downloads the raw `.replay` binary stream for playback in Godot or the Web Inspector. |

## Storage & Scaling Considerations

### Current Implementation

Verified `GHST` replay binaries are stored directly in the `Runs` table in PostgreSQL using `bytea` columns. This approach keeps local development and deployment simple by keeping replay data and related metadata transactional within the same database instance.

### Architectural Trade-offs

Storing raw replay binaries directly in PostgreSQL offers several advantages:

- **Transactional consistency:** Replay data and its associated run metadata are committed atomically.
- **Simpler infrastructure:** No separate object-storage service or access keys are required.
- **Straightforward retrieval:** Replay data is queried using the same database connection as leaderboard records.

However, this design introduces trade-offs as the system scales:

- **Database growth:** Multi-megabyte binary payloads increase database storage requirements.
- **Backup overhead:** Heavy binary data increases backup size, WAL throughput, and restoration time.
- **I/O contention:** Continuous replay ingestion and downloads compete directly with indexed leaderboard queries.

### Production Scaling Strategy

For high-throughput production deployments, raw replay binaries can be offloaded to an S3-compatible object store such as Cloudflare R2, AWS S3, or MinIO. PostgreSQL retains only relational metadata.

| Data | Storage Location | Purpose |
| --- | --- | --- |
| Replay binary (`.replay`) | Object Storage | Stores raw contiguous frame stream |
| Run ID (`UUID`) | PostgreSQL | Uniquely identifies each submitted run |
| PRNG seed (`uint32`) | PostgreSQL | Records initial deterministic simulation seed |
| Player and score metadata | PostgreSQL | Powers indexed leaderboard pagination and filtering |
| Object storage key / URI | PostgreSQL | References the target binary in object storage |
| Verification verdict | PostgreSQL | Records authoritative server validation status |
| Replay SHA-256 hash | PostgreSQL | Enforces unique replay submission deduplication |

## Replay Verification Pipeline

1. **Client Recording:** Captures quantized input vectors (movement axes, action bitmask flags, and reticle aim coordinates) at 60 Hz.
2. **Binary Serialization:** Encodes the match into a 21-byte header and contiguous 15-byte frames.
3. **Payload Sanitization:** The API validates Base64 integrity, bounds-checks frame counts (up to 432,000), enforces coordinate limits, and computes a SHA-256 hash to prevent duplicate replay submissions.
4. **Deterministic Resimulation:** The headless server simulation reconstructs the initial arena state using the embedded seed and runs the physics tick-by-tick.
5. **Verdict Commitment:** If the server's simulated score matches the client's claimed score, the run is flagged as `IsVerified = true` and ranked on the public leaderboard.

using Godot;
using Ghostline.Simulation;
using System;
using System.Collections.Generic;
using System.IO;
using System.Text.Json;

namespace Ghostline.Client;

public record LeaderboardItem(Guid Id, string PlayerName, int Score, int TotalTicks, DateTime CreatedAtUtc);

public enum GameMode
{
    LivePlay,
    GhostPlayback
}

public partial class GameWorld : Node2D
{
    // Node references
    private Sprite2D _playerVisual = null!;
    private HttpRequest _http = null!;
    private HttpRequest _leaderboardHttp = null!;
    private HttpRequest _replayHttp = null!;

    // Authoritative headless simulation instance
    private SimulationWorld _simulation = null!;

    // Fixed timestep accumulator to decouple Godot frame rate from simulation ticks
    private double _timeAccumulator;
    private const double SecondsPerTick = 1.0 / SimulationWorld.TicksPerSecond;

    // In-memory replay buffer: captures authoritative run inputs for server verification
    private readonly List<PlayerInput> _recordedInputs = new();
    private bool _showSkillQEffect;
    private string _submissionStatus = "F6: Export | F7: Submit | F8: Watch Replay | Tab/L: Leaderboard";
    private bool _isSubmitting;

    // Leaderboard state
    private bool _showLeaderboard;
    private readonly List<LeaderboardItem> _leaderboardEntries = new();
    private bool _isLoadingLeaderboard;

    // Ghost Playback State
    private GameMode _currentMode = GameMode.LivePlay;
    private ReplayFile? _activeReplay;
    private int _playbackIndex;
    private bool _isPlaybackPaused;

    // Configurable backend endpoints
    private string _apiBaseUrl = "";
    private string _apiRunsEndpoint = "";
    private string _apiLeaderboardEndpoint = "";

    public override void _Ready()
    {
        // Allow overriding the backend URL via environment variable for production builds
        _apiBaseUrl = OS.GetEnvironment("GHOSTLINE_API_URL");
        if (string.IsNullOrWhiteSpace(_apiBaseUrl))
        {
            _apiBaseUrl = "http://localhost:5000";
        }

        _apiRunsEndpoint = $"{_apiBaseUrl}/api/runs";
        _apiLeaderboardEndpoint = $"{_apiBaseUrl}/api/leaderboard?limit=10";

        _playerVisual = GetNode<Sprite2D>("PlayerVisual");

        // Set up HTTP Request node for backend communication
        _http = new HttpRequest();
        AddChild(_http);
        _http.RequestCompleted += OnHttpRequestCompleted;

        // Set up HTTP Request node for fetching leaderboard
        _leaderboardHttp = new HttpRequest();
        AddChild(_leaderboardHttp);
        _leaderboardHttp.RequestCompleted += OnLeaderboardCompleted;

        // Set up HTTP Request node for downloading replay files
        _replayHttp = new HttpRequest();
        AddChild(_replayHttp);
        _replayHttp.RequestCompleted += OnReplayDownloaded;

        // Spawn player near center of default arena (500, 400) screen pixels with a deterministic seed
        StartLiveGame(seed: 1337);

        // Initial leaderboard fetch
        FetchLeaderboard();
    }

    private void StartLiveGame(uint seed)
    {
        _currentMode = GameMode.LivePlay;
        _recordedInputs.Clear();
        _timeAccumulator = 0;

        var spawnPosition = SimVector2.FromScreenPixels(500f, 400f);
        _simulation = new SimulationWorld(spawnPosition, seed: seed);
        _playerVisual.Modulate = Colors.White;
        UpdateVisuals();
    }

    public void StartGhostPlayback(ReplayFile replay)
    {
        _activeReplay = replay;
        _playbackIndex = 0;
        _isPlaybackPaused = false;
        _currentMode = GameMode.GhostPlayback;
        _timeAccumulator = 0;

        // Recreate world from authoritative replay header
        _simulation = new SimulationWorld(replay.Header.SpawnPosition, seed: replay.Header.Seed);

        // Semi-transparent ghost styling for player visual
        _playerVisual.Modulate = new Color(0.4f, 0.9f, 1.0f, 0.65f);
        _submissionStatus = "REPLAY MODE: Space: Pause/Resume | Backspace: Return to Live Game";
        UpdateVisuals();
    }

    public override void _UnhandledInput(InputEvent @event)
    {
        if (@event is InputEventKey keyEvent && keyEvent.Pressed && !keyEvent.Echo)
        {
            // Toggle Leaderboard
            if (keyEvent.Keycode == Key.Tab || keyEvent.Keycode == Key.L)
            {
                _showLeaderboard = !_showLeaderboard;
                if (_showLeaderboard)
                {
                    FetchLeaderboard();
                }
                QueueRedraw();
            }

            // F8: Watch latest local replay in Ghost Mode
            if (keyEvent.Keycode == Key.F8)
            {
                if (_currentMode == GameMode.GhostPlayback)
                {
                    StartLiveGame(1337);
                }
                else if (File.Exists("latest_run.replay"))
                {
                    byte[] data = File.ReadAllBytes("latest_run.replay");
                    var replay = ReplayFile.Deserialize(data);
                    StartGhostPlayback(replay);
                }
                else
                {
                    _submissionStatus = "No latest_run.replay file found. Press F6 to save one first!";
                }
            }

            // Ghost Mode Controls
            if (_currentMode == GameMode.GhostPlayback)
            {
                if (keyEvent.Keycode == Key.Space)
                {
                    _isPlaybackPaused = !_isPlaybackPaused;
                }
                else if (keyEvent.Keycode == Key.Backspace || keyEvent.Keycode == Key.Escape)
                {
                    StartLiveGame(1337);
                }
            }
        }
    }

    public override void _Draw()
    {
        // 1. Draw the arena boundary defined by the simulation
        var (minX, minY) = new SimVector2(_simulation.Arena.MinX, _simulation.Arena.MinY).ToScreenPixels();
        var (maxX, maxY) = new SimVector2(_simulation.Arena.MaxX, _simulation.Arena.MaxY).ToScreenPixels();

        var rect = new Rect2(minX, minY, maxX - minX, maxY - minY);
        DrawRect(rect, _currentMode == GameMode.GhostPlayback ? Colors.DodgerBlue : Colors.White, filled: false, width: 2.0f);

        var (px, py) = _simulation.Player.Position.ToScreenPixels();
        var playerCenter = new Vector2(px, py);

        // 2. Draw Skill R: Continuous Laser Beam
        if (_simulation.Player.LaserActiveTicks > 0)
        {
            float dirX = _simulation.Player.LaserAimDirection.X / 1000f;
            float dirY = _simulation.Player.LaserAimDirection.Y / 1000f;
            Vector2 beamEnd = playerCenter + new Vector2(dirX, dirY) * (SimulationWorld.LaserLength / 1000f);

            // Wide glow beam and bright inner beam core
            DrawLine(playerCenter, beamEnd, new Color(0.2f, 0.8f, 1.0f, 0.4f), 18f);
            DrawLine(playerCenter, beamEnd, Colors.White, 6f);
        }

        // 3. Draw Skill Q: Wide shockwave ring effect
        if (_showSkillQEffect)
        {
            float qRadius = SimulationWorld.SkillQRadius / 1000f;
            DrawArc(playerCenter, qRadius, 0, Mathf.Tau, 36, Colors.Gold, 3.5f);
            _showSkillQEffect = false;
        }

        // 4. Draw Skill E: Shield bubble around player
        if (_simulation.Player.Shield > 0)
        {
            float shieldRadius = (SimulationWorld.PlayerRadius / 1000f) + 6f;
            DrawArc(playerCenter, shieldRadius, 0, Mathf.Tau, 32, Colors.DeepSkyBlue, 3.0f);
        }

        // 5. Draw Bullets (Normal Attack)
        foreach (var proj in _simulation.Projectiles)
        {
            if (!proj.IsAlive) continue;
            var (bx, by) = proj.Position.ToScreenPixels();
            DrawCircle(new Vector2(bx, by), SimulationWorld.BulletRadius / 1000f, Colors.Yellow);
        }

        // 6. Draw enemies
        foreach (var enemy in _simulation.Enemies)
        {
            if (!enemy.IsAlive) continue;

            var (ex, ey) = enemy.Position.ToScreenPixels();
            float radius = SimulationWorld.EnemyRadius / 1000f;
            DrawCircle(new Vector2(ex, ey), radius, Colors.Crimson);
        }

        // 7. Debug HUD Overlay & Cooldown Displays
        float qCd = _simulation.Player.QCooldownTicks / (float)SimulationWorld.TicksPerSecond;
        float eCd = _simulation.Player.ShieldCooldownTicks / (float)SimulationWorld.TicksPerSecond;
        float rCd = _simulation.Player.RCooldownTicks / (float)SimulationWorld.TicksPerSecond;

        string modeTag = _currentMode == GameMode.GhostPlayback
            ? $"*** REPLAY SPECTATOR [ {(_isPlaybackPaused ? "PAUSED" : "PLAYING")} ] ***\nProgress: {_playbackIndex}/{_activeReplay?.Inputs.Count ?? 0} ticks\n"
            : "";

        string hudText = $"{modeTag}" +
                         $"Health: {_simulation.Player.Health}/{_simulation.Player.MaxHealth} | Shield: {_simulation.Player.Shield}\n" +
                         $"Score: {_simulation.Score} | Tick: {_simulation.CurrentTick}\n" +
                         $"Attack (LMB): Fire Bullet\n" +
                         $"[Q] Shockwave: {(qCd > 0 ? $"{qCd:F1}s" : "READY")}\n" +
                         $"[E] Shield (15 HP): {(eCd > 0 ? $"{eCd:F1}s" : "READY")}\n" +
                         $"[R] Laser Beam (5s): {(rCd > 0 ? $"{rCd:F1}s" : "READY")}\n" +
                         $"Recorded Inputs: {_recordedInputs.Count}\n" +
                         $"{_submissionStatus}";

        DrawString(ThemeDB.FallbackFont, new Vector2(minX + 15, minY + 30), hudText, HorizontalAlignment.Left, -1, 14, _currentMode == GameMode.GhostPlayback ? Colors.Cyan : Colors.White);

        // 8. Render Leaderboard Overlay if active
        if (_showLeaderboard)
        {
            DrawLeaderboardOverlay(minX, minY, maxX - minX, maxY - minY);
        }
    }

    private void DrawLeaderboardOverlay(float arenaX, float arenaY, float arenaWidth, float arenaHeight)
    {
        // Darkened background panel centered in arena
        float panelWidth = 480f;
        float panelHeight = 360f;
        float panelX = arenaX + (arenaWidth - panelWidth) * 0.5f;
        float panelY = arenaY + (arenaHeight - panelHeight) * 0.5f;

        var panelRect = new Rect2(panelX, panelY, panelWidth, panelHeight);
        DrawRect(panelRect, new Color(0.05f, 0.05f, 0.1f, 0.88f), filled: true);
        DrawRect(panelRect, Colors.Cyan, filled: false, width: 2.0f);

        // Header
        string title = "=== AUTHORITATIVE LEADERBOARD ===";
        DrawString(ThemeDB.FallbackFont, new Vector2(panelX + 20, panelY + 35), title, HorizontalAlignment.Left, -1, 16, Colors.Gold);

        if (_isLoadingLeaderboard)
        {
            DrawString(ThemeDB.FallbackFont, new Vector2(panelX + 20, panelY + 80), "Loading top runs...", HorizontalAlignment.Left, -1, 14, Colors.Silver);
            return;
        }

        if (_leaderboardEntries.Count == 0)
        {
            DrawString(ThemeDB.FallbackFont, new Vector2(panelX + 20, panelY + 80), "No verified runs logged yet. Press F7 to submit your run!", HorizontalAlignment.Left, -1, 13, Colors.Silver);
            return;
        }

        // Column Titles
        string columns = "RANK   PLAYER          SCORE       SURVIVED";
        DrawString(ThemeDB.FallbackFont, new Vector2(panelX + 20, panelY + 70), columns, HorizontalAlignment.Left, -1, 13, Colors.Cyan);

        // Entry rows
        float yOffset = panelY + 100;
        for (int i = 0; i < _leaderboardEntries.Count && i < 10; i++)
        {
            var entry = _leaderboardEntries[i];
            float seconds = entry.TotalTicks / (float)SimulationWorld.TicksPerSecond;
            string row = $"#{i + 1,-5} {entry.PlayerName,-15} {entry.Score,-11} {seconds:F1}s";

            Color rowColor = i == 0 ? Colors.Yellow : (i < 3 ? Colors.LightSkyBlue : Colors.White);
            DrawString(ThemeDB.FallbackFont, new Vector2(panelX + 20, yOffset), row, HorizontalAlignment.Left, -1, 13, rowColor);
            yOffset += 24;
        }
    }

    public override void _Process(double delta)
    {
        // Export replay file on F6 key press
        if (Input.IsKeyPressed(Key.F6) && _currentMode == GameMode.LivePlay)
        {
            ExportReplay("latest_run.replay");
        }

        // F7: Submit replay to backend for authoritative verification
        if (Input.IsKeyPressed(Key.F7) && !_isSubmitting && _currentMode == GameMode.LivePlay)
        {
            SubmitRun();
        }

        // Accumulate elapsed real time, capped at 0.2s to prevent timestep death spirals
        _timeAccumulator = Mathf.Min((float)(_timeAccumulator + delta), 0.2f);

        /* 
         * Run fixed simulation steps whenever enough time has passed.
         * If Godot runs at 144 FPS, it might step 0 times on some frames and 1 time on others.
         * If Godot drops to 30 FPS, it will step 2 times in one frame to catch up.
         */
        while (_timeAccumulator >= SecondsPerTick)
        {
            if (_currentMode == GameMode.LivePlay)
            {
                PlayerInput input = PollInput(_simulation.CurrentTick);
                _recordedInputs.Add(input);

                if (input.SkillQ && _simulation.Player.QCooldownTicks == 0)
                {
                    _showSkillQEffect = true;
                }

                _simulation.Step(input);
            }
            else if (_currentMode == GameMode.GhostPlayback && !_isPlaybackPaused)
            {
                // Playback authoritative replay input stream
                if (_activeReplay != null && _playbackIndex < _activeReplay.Inputs.Count)
                {
                    PlayerInput replayInput = _activeReplay.Inputs[_playbackIndex];
                    if (replayInput.SkillQ && _simulation.Player.QCooldownTicks == 0)
                    {
                        _showSkillQEffect = true;
                    }

                    _simulation.Step(replayInput);
                    _playbackIndex++;
                }
                else
                {
                    _isPlaybackPaused = true;
                    _submissionStatus = "Replay Completed! Press Space to restart or Backspace to exit.";
                }
            }

            _timeAccumulator -= SecondsPerTick;
        }

        // Render authoritative simulation state to screen
        UpdateVisuals();

        // Trigger _Draw() each frame to update moving entities
        QueueRedraw();
    }

    private PlayerInput PollInput(int currentTick)
    {
        sbyte moveX = 0;
        sbyte moveY = 0;

        if (Input.IsActionPressed("move_left")) moveX -= 1;
        if (Input.IsActionPressed("move_right")) moveX += 1;
        if (Input.IsActionPressed("move_up")) moveY -= 1;
        if (Input.IsActionPressed("move_down")) moveY += 1;

        bool dash = Input.IsActionJustPressed("dash");
        bool attack = Input.IsActionPressed("attack");       // Hold or click LMB to shoot
        bool skillQ = Input.IsActionJustPressed("skill_q");  // Q: Shockwave
        bool skillE = Input.IsActionJustPressed("skill_e");  // E: Shield
        bool skillR = Input.IsActionJustPressed("skill_r");  // R: Laser Beam

        // Convert mouse position to integer millipixels
        Vector2 mousePos = GetGlobalMousePosition();
        SimVector2 aimTarget = SimVector2.FromScreenPixels(mousePos.X, mousePos.Y);

        return new PlayerInput(
            Tick: currentTick,
            MoveX: moveX,
            MoveY: moveY,
            Dash: dash,
            Attack: attack,
            SkillQ: skillQ,
            SkillE: skillE,
            SkillR: skillR,
            AimTargetX: aimTarget.X,
            AimTargetY: aimTarget.Y
        );
    }

    private void UpdateVisuals()
    {
        var (screenX, screenY) = _simulation.Player.Position.ToScreenPixels();
        _playerVisual.Position = new Vector2(screenX, screenY);
    }

    // Exports the current recorded gameplay session to a binary replay file.
    // Can be called on player death, game over, or by pressing F6.
    public void ExportReplay(string filePath)
    {
        var spawnPos = SimVector2.FromScreenPixels(500f, 400f);
        var header = new ReplayHeader(
            Version: ReplayFile.CurrentVersion,
            Seed: _simulation.Seed,
            SpawnPosition: spawnPos,
            InputCount: _recordedInputs.Count
        );

        var replay = new ReplayFile(header, _recordedInputs);
        byte[] data = replay.Serialize();

        File.WriteAllBytes(filePath, data);
        _submissionStatus = $"Saved: {filePath} ({data.Length} bytes)";
        GD.Print($"Replay successfully exported to: {filePath} ({data.Length} bytes)");
    }

    // Submits the current run and binary replay payload to the backend API.
    public void SubmitRun()
    {
        if (_recordedInputs.Count == 0)
        {
            _submissionStatus = "Cannot submit: No input frames recorded.";
            return;
        }

        _isSubmitting = true;
        _submissionStatus = "Submitting run to server...";

        var spawnPos = SimVector2.FromScreenPixels(500f, 400f);
        var header = new ReplayHeader(
            Version: ReplayFile.CurrentVersion,
            Seed: _simulation.Seed,
            SpawnPosition: spawnPos,
            InputCount: _recordedInputs.Count
        );

        var replay = new ReplayFile(header, _recordedInputs);
        byte[] replayBytes = replay.Serialize();
        string base64Payload = Convert.ToBase64String(replayBytes);

        var requestBody = new
        {
            playerName = "Player1",
            claimedScore = _simulation.Score,
            seed = _simulation.Seed,
            replayBase64 = base64Payload
        };

        string json = JsonSerializer.Serialize(requestBody);
        string[] headers = new[] { "Content-Type: application/json" };

        Error err = _http.Request(_apiRunsEndpoint, headers, HttpClient.Method.Post, json);
        if (err != Error.Ok)
        {
            _submissionStatus = $"HTTP Error: Failed to initiate request ({err})";
            _isSubmitting = false;
        }
    }

    // Fetches top runs from the backend leaderboard endpoint.
    public void FetchLeaderboard()
    {
        _isLoadingLeaderboard = true;
        _leaderboardHttp.Request(_apiLeaderboardEndpoint);
    }

    // Fetches and launches a replay download from the backend by RunId.
    public void DownloadAndPlayReplay(Guid runId)
    {
        _submissionStatus = $"Downloading replay {runId}...";
        string endpoint = $"{_apiBaseUrl}/api/runs/{runId}/replay";
        _replayHttp.Request(endpoint);
    }

    private void OnHttpRequestCompleted(long result, long responseCode, string[] headers, byte[] body)
    {
        _isSubmitting = false;

        if (responseCode == 201)
        {
            string responseText = System.Text.Encoding.UTF8.GetString(body);
            using var doc = JsonDocument.Parse(responseText);
            var root = doc.RootElement;

            bool isVerified = root.GetProperty("isVerified").GetBoolean();
            int verifiedScore = root.GetProperty("verifiedScore").GetInt32();

            _submissionStatus = isVerified
                ? $"Verified by Server: Score {verifiedScore}"
                : "Rejected: Replay diverged from server simulation!";

            // Refresh leaderboard to include newly verified run
            FetchLeaderboard();
        }
        else
        {
            _submissionStatus = $"Submission Failed: HTTP {responseCode}";
            GD.PrintErr($"Run submission failed with status code {responseCode}");
        }
    }

    private void OnLeaderboardCompleted(long result, long responseCode, string[] headers, byte[] body)
    {
        _isLoadingLeaderboard = false;

        if (responseCode == 200)
        {
            string json = System.Text.Encoding.UTF8.GetString(body);
            using var doc = JsonDocument.Parse(json);

            _leaderboardEntries.Clear();
            foreach (var el in doc.RootElement.EnumerateArray())
            {
                var entry = new LeaderboardItem(
                    Id: el.GetProperty("id").GetGuid(),
                    PlayerName: el.GetProperty("playerName").GetString() ?? "Unknown",
                    Score: el.GetProperty("score").GetInt32(),
                    TotalTicks: el.GetProperty("totalTicks").GetInt32(),
                    CreatedAtUtc: el.GetProperty("createdAtUtc").GetDateTime()
                );
                _leaderboardEntries.Add(entry);
            }
        }
        else
        {
            GD.PrintErr($"Failed to load leaderboard: HTTP {responseCode}");
        }
    }

    private void OnReplayDownloaded(long result, long responseCode, string[] headers, byte[] body)
    {
        if (responseCode == 200 && body.Length > 0)
        {
            try
            {
                var replay = ReplayFile.Deserialize(body);
                StartGhostPlayback(replay);
            }
            catch (Exception ex)
            {
                _submissionStatus = $"Replay corrupted: {ex.Message}";
                GD.PrintErr($"Failed to deserialize downloaded replay: {ex}");
            }
        }
        else
        {
            _submissionStatus = $"Replay download failed: HTTP {responseCode}";
        }
    }
}

```md
# Ghostline Replay Format (`GHST`) Specification

**Version:** 1  
**Endianness:** Little-Endian  
**Extension:** `.replay`

The `GHST` binary format is designed for deterministic replay storage and network transmission. It records only the initial PRNG state and quantized chronological player input frames, enabling the authoritative server to re-simulate matches tick-by-tick headlessly.

---

## 1. File Structure Overview

A `.replay` file consists of a fixed-size header followed by a contiguous stream of fixed-size input frames.

| Component | Size | Description |
|---|---:|---|
| Header | 21 bytes | Contains the magic identifier, version, PRNG seed, player spawn coordinates, and input frame count. |
| Frame 0 | 15 bytes | Contains the first recorded input frame. |
| Frame 1 | 15 bytes | Contains the second recorded input frame. |
| ... | ... | Continues until all input frames have been recorded. |
| Frame N-1 | 15 bytes | Contains the final recorded input frame. |

**Total File Size:**

$$\text{File Size} = 21 + (N \times 15) \text{ bytes}$$

At 60 ticks per second, one minute of gameplay generates 3,600 frames, resulting in approximately 54 KB of replay data.

---

## 2. Header Layout (21 Bytes)

| Offset | Field | Type | Size | Description |
|---|---|---|---|---|
| `0x00` | `Magic` | ASCII (`char[4]`) | 4 bytes | Magic identifier: ASCII `"GHST"` (`0x47`, `0x48`, `0x53`, `0x54`). |
| `0x04` | `Version` | `uint8` (`byte`) | 1 byte | Format specification version (current: `1`). |
| `0x05` | `Seed` | `uint32` | 4 bytes | PRNG seed for deterministic enemy spawn placement. |
| `0x09` | `SpawnX` | `int32` | 4 bytes | Player spawn X position in fixed-point millipixels. |
| `0x0D` | `SpawnY` | `int32` | 4 bytes | Player spawn Y position in fixed-point millipixels. |
| `0x11` | `InputCount` | `int32` | 4 bytes | Total number of recorded input frames (\(N\)). |

---

## 3. Frame Layout (15 Bytes per Frame)

Each recorded tick is serialized into exactly 15 bytes.

| Offset | Field | Type | Size | Description / Range |
|---|---|---|---|---|
| `0x00` | `Tick` | `int32` | 4 bytes | Chronological simulation tick index (\(\geq 0\)). |
| `0x04` | `MoveX` | `int8` (`sbyte`) | 1 byte | Horizontal axis input: `-1`, `0`, or `1`. |
| `0x05` | `MoveY` | `int8` (`sbyte`) | 1 byte | Vertical axis input: `-1`, `0`, or `1`. |
| `0x06` | `Actions` | `uint8` (`byte`) | 1 byte | Bitmask of active abilities and actions. |
| `0x07` | `AimTargetX` | `int32` | 4 bytes | Mouse/reticle target X in millipixels. |
| `0x0B` | `AimTargetY` | `int32` | 4 bytes | Mouse/reticle target Y in millipixels. |

### Action Bitmask Flags (`Actions`)

Active abilities are bitwise OR-packed into byte offset `0x06`.

| Bit | Mask | Flag | Description |
|---|---|---|---|
| Bit 0 | `0x01` (`1 << 0`) | `ActionFlagDash` | Dash burst triggered. |
| Bit 1 | `0x02` (`1 << 1`) | `ActionFlagAttack` | Normal bullet attack active. |
| Bit 2 | `0x04` (`1 << 2`) | `ActionFlagSkillQ` | Shockwave radial AoE triggered. |
| Bit 3 | `0x08` (`1 << 3`) | `ActionFlagSkillE` | Barrier shield triggered. |
| Bit 4 | `0x10` (`1 << 4`) | `ActionFlagSkillR` | Continuous laser beam active. |
| Bits 5–7 | `0xE0` | Reserved | Unused, reserved for future extensions. |

---

## 4. Fixed-Point Coordinate System

To prevent floating-point divergence across compiler architectures (x86_64, ARM64) and runtime environments (.NET Core Linux Docker container vs. Godot Desktop client), all spatial coordinates use integer millipixels.

$$1 \text{ visual screen pixel} = 1{,}000 \text{ simulation millipixels}$$

This representation allows coordinates to be serialized as integers, avoiding floating-point values in the replay data.

---

## 5. Security & Verification Constraints

Before passing deserialized replays to `SimulationWorld.Step()`, the parser enforces strict bounds.

1. **Payload Size:** Maximum 5 MiB (\(5 \times 1024 \times 1024\) bytes).
2. **Frame Count:** Maximum 432,000 frames (approximately 2 hours at 60 ticks per second).
3. **Spawn Boundaries:** \(X, Y \in [-100{,}000,\ 2{,}000{,}000]\) millipixels.
4. **Directional Input Range:** `MoveX` and `MoveY` must strictly belong to \(\{-1, 0, 1\}\).
5. **Anti-Truncation:** The byte stream must contain at least `InputCount * 15` bytes following the 21-byte header.

The parser must validate the header, version, frame count, payload length, and input ranges before simulation begins.

```cs
namespace Ghostline.Api.Models;

using System;

// Database entity representing a completed gameplay run and its verification verdict.
public class RunRecord
{
    // Unique identifier for the run (Primary Key)
    public Guid Id { get; set; } = Guid.NewGuid();

    // Display name of the submitting player
    public string PlayerName { get; set; } = string.Empty;

    // Score claimed by the client
    public int ClaimedScore { get; set; }

    // Authoritative score calculated by the server during re-simulation
    public int VerifiedScore { get; set; }

    // Total duration of the run measured in fixed ticks
    public int TotalTicks { get; set; }

    // PRNG seed used for the match
    public uint Seed { get; set; }

    // True only if headless server re-simulation matched the claimed score and state
    public bool IsVerified { get; set; }

    // Reason for rejection if verification failed (null if verified successfully)
    public string? VerificationError { get; set; }

    // Raw binary replay payload (GHST format) stored for leaderboard playback
    public byte[] ReplayData { get; set; } = Array.Empty<byte>();

    // SHA-256 hash of the replay data to prevent duplicate score submissions
    public string ReplayHash { get; set; } = string.Empty;

    // Timestamp when the run was submitted
    public DateTime CreatedAtUtc { get; set; } = DateTime.UtcNow;
}

app.MapPost("/api/runs", async (
    SubmitRunRequest request,
    AppDbContext db,
    IReplayVerificationService verifier,
    ILogger<Program> logger) =>
{
    // PRIORITY 2: PlayerName content and length validation
    if (string.IsNullOrWhiteSpace(request.PlayerName) || request.PlayerName.Length > 32)
    {
        logger.LogWarning("Run rejected: invalid PlayerName provided.");
        return Results.BadRequest(new { error = "PlayerName is required and must be 32 characters or fewer." });
    }

    if (request.ReplayBase64 == null || request.ReplayBase64.Length == 0)
    {
        logger.LogWarning("Run rejected: empty replay payload from player '{PlayerName}'.", request.PlayerName);
        return Results.BadRequest(new { error = "Replay data is required." });
    }

    byte[] replayBytes;
    try
    {
        replayBytes = Convert.FromBase64String(request.ReplayBase64);
    }
    catch (FormatException)
    {
        logger.LogWarning("Run rejected: invalid Base64 string submitted by player '{PlayerName}'.", request.PlayerName);
        return Results.BadRequest(new { error = "Invalid Base64 format for ReplayBase64." });
    }

    // PRIORITY 1 & 2: Reject malformed data and derive seed from the replay itself.
    ReplayFile replay;
    try
    {
        replay = ReplayFile.Deserialize(replayBytes);
    }
    catch (InvalidDataException ex)
    {
        logger.LogWarning("Run rejected: malformed replay payload from player '{PlayerName}': {Message}", request.PlayerName, ex.Message);
        return Results.BadRequest(new { error = $"Invalid replay payload: {ex.Message}" });
    }

    // PRIORITY 2: Reject mismatched seeds.
    if (request.Seed != replay.Header.Seed)
    {
        logger.LogWarning("Run rejected: seed mismatch for player '{PlayerName}'. Request: {ReqSeed}, Replay: {ReplaySeed}",
            request.PlayerName, request.Seed, replay.Header.Seed);
        return Results.BadRequest(new { error = "Request seed does not match the seed embedded in the replay payload." });
    }

    // PRIORITY 2: Reject duplicate replay submissions
    string replayHash = Convert.ToHexString(System.Security.Cryptography.SHA256.HashData(replayBytes));

    bool isDuplicate = await db.Runs.AnyAsync(r => r.ReplayHash == replayHash);
    if (isDuplicate)
    {
        logger.LogWarning("Run rejected: duplicate replay hash {Hash} submitted by player '{PlayerName}'.", replayHash, request.PlayerName);
        return Results.Conflict(new { error = "Duplicate submission: This exact replay has already been processed." });
    }

    logger.LogInformation("Verifying run for player '{PlayerName}' (Claimed: {Score}, Frames: {Frames}, Seed: {Seed})...",
        request.PlayerName, request.ClaimedScore, replay.Header.InputCount, replay.Header.Seed);

    var result = verifier.Verify(replayBytes, request.ClaimedScore);

    if (result.IsValid)
    {
        logger.LogInformation("Run VERIFIED for player '{PlayerName}'. Score: {Score}, Total Ticks: {Ticks}.",
            request.PlayerName, result.AuthoritativeScore, result.AuthoritativeTicks);
    }
    else
    {
        logger.LogWarning("Run REJECTED for player '{PlayerName}'. Claimed: {Claimed}, Authoritative: {Auth}, Reason: {Reason}",
            request.PlayerName, request.ClaimedScore, result.AuthoritativeScore, result.ErrorMessage);
    }

    var record = new RunRecord
    {
        PlayerName = request.PlayerName.Trim(),
        ClaimedScore = request.ClaimedScore,
        VerifiedScore = result.AuthoritativeScore,
        TotalTicks = result.AuthoritativeTicks,
        Seed = replay.Header.Seed,
        IsVerified = result.IsValid,
        VerificationError = result.ErrorMessage,
        ReplayData = replayBytes,
        ReplayHash = replayHash,
        CreatedAtUtc = DateTime.UtcNow
    };

    db.Runs.Add(record);
    await db.SaveChangesAsync();

    return Results.Created($"/api/runs/{record.Id}", new
    {
        record.Id,
        record.PlayerName,
        record.ClaimedScore,
        record.VerifiedScore,
        record.TotalTicks,
        record.IsVerified,
        record.VerificationError,
        record.CreatedAtUtc
    });
}).RequireRateLimiting("runs-limiter");

// Paginated and filterable leaderboard retrieval
app.MapGet("/api/leaderboard", async (
    AppDbContext db,
    int page = 1,
    int limit = 20,
    uint? seed = null) =>
{
    int queryLimit = Math.Clamp(limit, 1, 100);
    int queryPage = Math.Max(1, page);
    int skip = (queryPage - 1) * queryLimit;

    var query = db.Runs
        .AsNoTracking()
        .Where(r => r.IsVerified);

    if (seed.HasValue)
    {
        query = query.Where(r => r.Seed == seed.Value);
    }

    var topRuns = await query
        .OrderByDescending(r => r.VerifiedScore)
        .ThenBy(r => r.CreatedAtUtc)
        .Skip(skip)
        .Take(queryLimit)
        .Select(r => new
        {
            r.Id,
            r.PlayerName,
            Score = r.VerifiedScore,
            r.TotalTicks,
            r.Seed,
            r.CreatedAtUtc
        })
        .ToListAsync();

    return Results.Ok(topRuns);
});

using Ghostline.Simulation;

namespace Ghostline.Api.Services;

public record VerificationResult(
    bool IsValid,
    int AuthoritativeScore,
    int AuthoritativeTicks,
    string? ErrorMessage
);

public interface IReplayVerificationService
{
    VerificationResult Verify(byte[] replayBytes, int claimedScore);
}

public class ReplayVerificationService : IReplayVerificationService
{
    public VerificationResult Verify(byte[] replayBytes, int claimedScore)
    {
        // 1. Attempt to deserialize binary replay payload
        ReplayFile replay;
        try
        {
            replay = ReplayFile.Deserialize(replayBytes);
        }
        catch (Exception ex)
        {
            return new VerificationResult(
                IsValid: false,
                AuthoritativeScore: 0,
                AuthoritativeTicks: 0,
                ErrorMessage: $"Replay deserialization failed: {ex.Message}"
            );
        }

        // 2. Validate input sequence integrity
        if (replay.Inputs.Count == 0)
        {
            return new VerificationResult(
                IsValid: false,
                AuthoritativeScore: 0,
                AuthoritativeTicks: 0,
                ErrorMessage: "Replay contains zero input frames."
            );
        }

        // Verify that ticks are strictly contiguous (Tick 0, 1, 2, 3...)
        for (int i = 0; i < replay.Inputs.Count; i++)
        {
            if (replay.Inputs[i].Tick != i)
            {
                return new VerificationResult(
                    IsValid: false,
                    AuthoritativeScore: 0,
                    AuthoritativeTicks: 0,
                    ErrorMessage: $"Non-contiguous tick sequence at index {i}. Expected tick {i}, got {replay.Inputs[i].Tick}."
                );
            }
        }

        // 3. Instantiate authoritative headless simulation with the replay's seed and spawn point
        var sim = new SimulationWorld(
            playerSpawnPosition: replay.Header.SpawnPosition,
            seed: replay.Header.Seed
        );

        // 4. Re-simulate the entire match step by step
        foreach (var input in replay.Inputs)
        {
            sim.Step(input);
        }

        // 5. Compare server-derived authoritative score against client claim
        if (sim.Score != claimedScore)
        {
            return new VerificationResult(
                IsValid: false,
                AuthoritativeScore: sim.Score,
                AuthoritativeTicks: sim.CurrentTick,
                ErrorMessage: $"Score mismatch: Client claimed {claimedScore}, server computed {sim.Score}."
            );
        }

        // Run successfully verified
        return new VerificationResult(
            IsValid: true,
            AuthoritativeScore: sim.Score,
            AuthoritativeTicks: sim.CurrentTick,
            ErrorMessage: null
        );
    }
}

```cs
namespace Ghostline.Simulation;

/*
 * A fast, cross-platform deterministic pseudo-random number generator using XorShift32.
 * Guarantees the exact same random sequence across any CPU architecture or operating system.
*/

public class DeterministicRng
{
    private uint _state;

    public DeterministicRng(uint seed)
    {
        // XorShift state must never be 0; fallback to a default non-zero seed if 0 is passed.
        _state = seed == 0 ? 0xDEADBEEF : seed;
    }

    // Generates the next pseudo-random unsigned 32-bit integer.
    public uint NextUInt()
    {
        uint x = _state;
        x ^= x << 13;
        x ^= x >> 17;
        x ^= x << 5;
        _state = x;
        return x;
    }

    // Returns an integer within a specified range: [minInclusive, maxExclusive).
    public int NextRange(int minInclusive, int maxExclusive)
    {
        if (minInclusive >= maxExclusive)
            return minInclusive;

        uint range = (uint)(maxExclusive - minInclusive);
        return (int)(minInclusive + (NextUInt() % range));
    }
}

```cs
using System;
using System.IO;
using System.Collections.Generic;

namespace Ghostline.Simulation;

// Metadata header stored at the beginning of every binary replay payload.
public readonly record struct ReplayHeader(
    byte Version,
    uint Seed,
    SimVector2 SpawnPosition,
    int InputCount
);

// Encapsulates a complete recorded match: initial state configuration and chronological inputs.
// Provides deterministic binary serialization and deserialization.
public class ReplayFile
{
    // Magic bytes: ASCII "GHST"
    public static readonly byte[] MagicBytes = new byte[] { (byte)'G', (byte)'H', (byte)'S', (byte)'T' };
    public const byte CurrentVersion = 1;

    // Header is 21 bytes; each input frame is 15 bytes
    public const int HeaderByteSize = 21;
    public const int FrameByteSize = 15;
    public const int MaxPayloadBytes = 5 * 1024 * 1024; // 5 MB max payload size
    public const int MaxInputFrames = 432_000;          // Max ~2 hours at 60 FPS

    // Action bitmask constants
    public const byte ActionFlagDash = 1 << 0; // 0000 0001
    public const byte ActionFlagAttack = 1 << 1; // 0000 0010
    public const byte ActionFlagSkillQ = 1 << 2; // 0000 0100
    public const byte ActionFlagSkillE = 1 << 3; // 0000 1000
    public const byte ActionFlagSkillR = 1 << 4; // 0001 0000

    public ReplayHeader Header { get; }
    public IReadOnlyList<PlayerInput> Inputs { get; }

    public ReplayFile(ReplayHeader header, IReadOnlyList<PlayerInput> inputs)
    {
        Header = header;
        Inputs = inputs;
    }

    // Serializes this replay instance to a byte array.
    public byte[] Serialize()
    {
        using var stream = new MemoryStream();
        using var writer = new BinaryWriter(stream);
        WriteTo(writer);
        return stream.ToArray();
    }

    // Writes the replay binary representation into an open BinaryWriter stream.
    public void WriteTo(BinaryWriter writer)
    {
        // 1. Write Header (21 bytes)
        writer.Write(MagicBytes);
        writer.Write(Header.Version);
        writer.Write(Header.Seed);
        writer.Write(Header.SpawnPosition.X);
        writer.Write(Header.SpawnPosition.Y);
        writer.Write(Inputs.Count);

        // 2. Write Input Frames (15 bytes per frame)
        for (int i = 0; i < Inputs.Count; i++)
        {
            PlayerInput input = Inputs[i];

            // Pack boolean states into a single byte bitmask
            byte actions = 0;
            if (input.Dash) actions |= ActionFlagDash;
            if (input.Attack) actions |= ActionFlagAttack;
            if (input.SkillQ) actions |= ActionFlagSkillQ;
            if (input.SkillE) actions |= ActionFlagSkillE;
            if (input.SkillR) actions |= ActionFlagSkillR;

            writer.Write(input.Tick);
            writer.Write(input.MoveX);
            writer.Write(input.MoveY);
            writer.Write(actions);
            writer.Write(input.AimTargetX);
            writer.Write(input.AimTargetY);
        }
    }

    // Deserializes a binary replay payload from a byte array.
    public static ReplayFile Deserialize(byte[] payload)
    {
        if (payload == null || payload.Length == 0 || payload.Length > MaxPayloadBytes)
            throw new InvalidDataException("Replay payload is empty or exceeds maximum allowed size.");

        using var ms = new MemoryStream(payload);
        using var reader = new BinaryReader(ms);

        // Delegate to ReadFrom so all validation and parsing rules stay consolidated in one place
        return ReadFrom(reader);
    }

    // Reads and validates a replay payload from an active BinaryReader stream.
    public static ReplayFile ReadFrom(BinaryReader reader)
    {
        if (reader == null)
            throw new ArgumentNullException(nameof(reader));

        try
        {
            // 1. Validate Magic Bytes
            byte[] magic = reader.ReadBytes(4);
            if (magic.Length != 4 ||
                magic[0] != MagicBytes[0] ||
                magic[1] != MagicBytes[1] ||
                magic[2] != MagicBytes[2] ||
                magic[3] != MagicBytes[3])
            {
                throw new InvalidDataException("Invalid replay file signature: Header magic bytes mismatch.");
            }

            // 2. Validate Version
            byte version = reader.ReadByte();
            if (version != CurrentVersion)
            {
                throw new InvalidDataException($"Unsupported replay version: {version}. Expected: {CurrentVersion}.");
            }

            // 3. Read Header Metadata
            uint seed = reader.ReadUInt32();
            int spawnX = reader.ReadInt32();
            int spawnY = reader.ReadInt32();

            if (spawnX < -100_000 || spawnX > 2000_000 || spawnY < -100_000 || spawnY > 2000_000)
            {
                throw new InvalidDataException("Spawn coordinates out of valid bounds.");
            }

            int inputCount = reader.ReadInt32();

            if (inputCount < 0 || inputCount > MaxInputFrames)
            {
                throw new InvalidDataException($"Replay frame count ({inputCount}) exceeds allowed bounds.");
            }

            // Verify stream has enough remaining bytes for all claimed frames before allocating memory
            if (reader.BaseStream.CanSeek)
            {
                long remainingBytes = reader.BaseStream.Length - reader.BaseStream.Position;
                long expectedBytes = (long)inputCount * FrameByteSize;
                if (remainingBytes < expectedBytes)
                {
                    throw new InvalidDataException($"Truncated replay payload: Expected {expectedBytes} frame bytes, but only {remainingBytes} remain.");
                }
            }

            var header = new ReplayHeader(
                Version: version,
                Seed: seed,
                SpawnPosition: new SimVector2(spawnX, spawnY),
                InputCount: inputCount
            );

            // 4. Read Input Frames
            var inputs = new List<PlayerInput>(inputCount);
            for (int i = 0; i < inputCount; i++)
            {
                int tick = reader.ReadInt32();
                sbyte moveX = reader.ReadSByte();
                sbyte moveY = reader.ReadSByte();

                if (moveX < -1 || moveX > 1 || moveY < -1 || moveY > 1)
                {
                    throw new InvalidDataException($"Invalid movement input at tick {tick}. MoveX/MoveY must be exactly -1, 0, or 1.");
                }

                byte actions = reader.ReadByte();
                int aimTargetX = reader.ReadInt32();
                int aimTargetY = reader.ReadInt32();

                bool dash = (actions & ActionFlagDash) != 0;
                bool attack = (actions & ActionFlagAttack) != 0;
                bool skillQ = (actions & ActionFlagSkillQ) != 0;
                bool skillE = (actions & ActionFlagSkillE) != 0;
                bool skillR = (actions & ActionFlagSkillR) != 0;

                inputs.Add(new PlayerInput(
                    Tick: tick,
                    MoveX: moveX,
                    MoveY: moveY,
                    Dash: dash,
                    Attack: attack,
                    SkillQ: skillQ,
                    SkillE: skillE,
                    SkillR: skillR,
                    AimTargetX: aimTargetX,
                    AimTargetY: aimTargetY
                ));
            }

            return new ReplayFile(header, inputs);
        }
        catch (EndOfStreamException ex)
        {
            throw new InvalidDataException("Unexpected end of replay stream: payload is truncated.", ex);
        }
    }
}

`src/Ghostline.Simulation/SimulationWorld.cs`:

```cs
namespace Ghostline.Simulation;

using System;
using System.Collections.Generic;

/*
 * Authoritative simulation container.
 * Executes discrete game ticks using deterministic integer arithmetic.
 * Both the Godot client and the backend API run this identical class.
 */
public class SimulationWorld
{
    // Simulation configuration constants
    public const int TicksPerSecond = 60;
    public const int PlayerSpeedPerTick = 5_000;    // 5 visual pixels per tick (300 pixels/sec)
    public const int DashDistance = 25_000;          // 25 visual pixels instant burst
    public const int DashCooldownDuration = 60;      // 60 ticks = 1.0 second cooldown
    public const int PlayerRadius = 12_000;          // 12 visual pixels collision radius

    // Bullet (Normal Attack) constants
    public const int BulletSpeedPerTick = 12_000;   // 12 visual pixels per tick
    public const int BulletRadius = 4_000;            // 4 visual pixels
    public const int BulletDamage = 30;
    public const int BulletLifetimeTicks = 90;       // 1.5 seconds life span
    public const int AttackCooldownDuration = 15;    // 0.25 second cooldown

    // Skill Q (Wide Radial AoE) constants
    public const int SkillQRadius = 75_000;          // 75 visual pixels
    public const int SkillQDamage = 45;
    public const int SkillQCooldownDuration = 300;   // 5.0 seconds cooldown (5 * 60)

    // Skill E (Shield) constants
    public const int ShieldAmount = 15;
    public const int ShieldDurationTicks = 300;      // 5.0 seconds active
    public const int ShieldCooldownDuration = 1500;  // 25.0 seconds cooldown (25 * 60)

    // Skill R (Laser Beam) constants
    public const int LaserDurationTicks = 300;       // 5.0 seconds continuous active
    public const int LaserCooldownDuration = 2700;   // 45.0 seconds cooldown (45 * 60)
    public const int LaserLength = 1_000_000;        // 1000 visual pixels span
    public const int LaserBeamWidth = 16_000;        // 16 visual pixels beam half-width
    public const int LaserDamagePerTick = 2;         // Continuous burn damage

    public const int ScorePerKill = 100;

    // Enemy constants
    public const int EnemyRadius = 10_000;           // 10 visual pixels
    public const int EnemySpeedPerTick = 2_000;      // 2 visual pixels per tick (slower than player)
    public const int EnemySpawnCadenceTicks = 120;   // Spawn an enemy every 2 seconds

    // Current simulation tick count (starts at 0 and increments every Step)
    public int CurrentTick { get; private set; }

    // Authoritative state of the player
    public PlayerState Player { get; private set; }

    // Arena boundary configuration
    public ArenaConfig Arena { get; }
    public uint Seed { get; }

    // Combat & scoring state
    public int Score { get; private set; }

    // Private simulation state fields
    private readonly DeterministicRng _rng;
    private readonly List<EnemyState> _enemies = new();
    private readonly List<ProjectileState> _projectiles = new();
    private int _nextEnemyId = 1;
    private int _nextProjectileId = 1;

    // Expose a read-only view of entities for the client presentation layer and tests
    public IReadOnlyList<EnemyState> Enemies => _enemies;
    public IReadOnlyList<ProjectileState> Projectiles => _projectiles;

    // Initializes a fresh simulation world with a defined starting position.
    public SimulationWorld(SimVector2 playerSpawnPosition, ArenaConfig? arena = null, uint seed = 1337)
    {
        CurrentTick = 0;
        Score = 0;
        Seed = seed;
        _rng = new DeterministicRng(seed);
        Arena = arena ?? ArenaConfig.CreateDefault();
        Player = PlayerState.CreateDefault(playerSpawnPosition);
    }

    // Advances the simulation by exactly one fixed tick using the provided player input.
    public void Step(PlayerInput input)
    {
        // 1. Advance the clock by 1 tick at the start of the step
        CurrentTick++;

        // If the player is dead, the world no longer accepts player movement
        if (!Player.IsAlive)
        {
            return;
        }

        // 2. Calculate Dash, Attack, and Skill Cooldown progressions
        int currentDashCooldown = Player.DashCooldownTicks > 0
            ? Player.DashCooldownTicks - 1
            : 0;

        int attackCooldown = Player.AttackCooldownTicks > 0
            ? Player.AttackCooldownTicks - 1
            : 0;

        int qCooldown = Player.QCooldownTicks > 0
            ? Player.QCooldownTicks - 1
            : 0;

        int eCooldown = Player.ShieldCooldownTicks > 0
            ? Player.ShieldCooldownTicks - 1
            : 0;

        int rCooldown = Player.RCooldownTicks > 0
            ? Player.RCooldownTicks - 1
            : 0;

        // Decrement active ability durations
        int shieldActive = Player.ShieldActiveTicks > 0
            ? Player.ShieldActiveTicks - 1
            : 0;
        int currentShield = shieldActive > 0 ? Player.Shield : 0;

        int laserActive = Player.LaserActiveTicks > 0
            ? Player.LaserActiveTicks - 1
            : 0;
        SimVector2 laserDirection = Player.LaserAimDirection;

        // 3. Check if a dash was triggered on this tick
        bool isDashing = input.Dash && currentDashCooldown == 0;
        if (isDashing)
        {
            currentDashCooldown = DashCooldownDuration;
        }

        // 4. Calculate movement delta for this tick
        // Determine base displacement based on directional input (-1, 0, 1)
        int moveDeltaX = input.MoveX * PlayerSpeedPerTick;
        int moveDeltaY = input.MoveY * PlayerSpeedPerTick;

        // If dashing, add burst distance in the direction the player is moving
        if (isDashing)
        {
            moveDeltaX += input.MoveX * DashDistance;
            moveDeltaY += input.MoveY * DashDistance;
        }

        // 5. Compute the new player position
        SimVector2 rawPosition = Player.Position + new SimVector2(moveDeltaX, moveDeltaY);

        // 6. Constrain within arena boundaries (integer clamp)
        SimVector2 clampedPosition = Arena.ClampPosition(rawPosition, PlayerRadius);

        // Compute aim direction vector using deterministic integer math
        int diffX = input.AimTargetX - clampedPosition.X;
        int diffY = input.AimTargetY - clampedPosition.Y;
        long distSquared = ((long)diffX * diffX) + ((long)diffY * diffY);
        int distance = IntegerSqrt(distSquared);
        if (distance == 0) distance = 1;

        int normX = (int)(((long)diffX * 1000) / distance);
        int normY = (int)(((long)diffY * 1000) / distance);

        // 7. Check if Skill E (Shield) was triggered on this tick
        if (input.SkillE && eCooldown == 0)
        {
            currentShield = ShieldAmount;
            shieldActive = ShieldDurationTicks;
            eCooldown = ShieldCooldownDuration;
        }

        // 8. Check if Skill R (Laser Beam) was triggered on this tick
        if (input.SkillR && rCooldown == 0)
        {
            laserActive = LaserDurationTicks;
            rCooldown = LaserCooldownDuration;
            laserDirection = new SimVector2(normX, normY);
        }
        else if (laserActive > 0)
        {
            // Laser tracks aim direction while active
            laserDirection = new SimVector2(normX, normY);
        }

        // 9. Check if Normal Attack (Bullet) was triggered on this tick
        if (input.Attack && attackCooldown == 0)
        {
            attackCooldown = AttackCooldownDuration;

            int velX = (int)(((long)normX * BulletSpeedPerTick) / 1000);
            int velY = (int)(((long)normY * BulletSpeedPerTick) / 1000);

            _projectiles.Add(new ProjectileState(
                Id: _nextProjectileId++,
                Position: clampedPosition,
                Velocity: new SimVector2(velX, velY),
                RemainingLifeTicks: BulletLifetimeTicks,
                Damage: BulletDamage,
                IsAlive: true
            ));
        }

        // 10. Check if Skill Q (Wide Radial AoE) was triggered on this tick
        bool executedSkillQ = input.SkillQ && qCooldown == 0;
        if (executedSkillQ)
        {
            qCooldown = SkillQCooldownDuration;
        }

        // 11. Periodic Enemy Spawning
        if (CurrentTick % EnemySpawnCadenceTicks == 0)
        {
            SpawnEnemy();
        }

        // 12. Update Bullets and Bullet-Enemy Collisions
        for (int pIdx = _projectiles.Count - 1; pIdx >= 0; pIdx--)
        {
            var proj = _projectiles[pIdx];
            if (!proj.IsAlive || proj.RemainingLifeTicks <= 0)
            {
                _projectiles.RemoveAt(pIdx);
                continue;
            }

            SimVector2 nextPos = proj.Position + proj.Velocity;
            bool hitTarget = false;

            for (int eIdx = 0; eIdx < _enemies.Count; eIdx++)
            {
                var enemy = _enemies[eIdx];
                if (!enemy.IsAlive) continue;

                int hitDist = EnemyRadius + BulletRadius;
                long dx = nextPos.X - enemy.Position.X;
                long dy = nextPos.Y - enemy.Position.Y;
                long distSq = (dx * dx) + (dy * dy);
                long hitDistSq = (long)hitDist * hitDist;

                if (distSq <= hitDistSq)
                {
                    hitTarget = true;
                    int newHp = enemy.Health - proj.Damage;
                    if (newHp <= 0)
                    {
                        Score += ScorePerKill;
                        _enemies[eIdx] = enemy with { IsAlive = false, Health = 0 };
                    }
                    else
                    {
                        _enemies[eIdx] = enemy with { Health = newHp };
                    }
                    break;
                }
            }

            if (hitTarget)
            {
                _projectiles.RemoveAt(pIdx);
            }
            else
            {
                _projectiles[pIdx] = proj with
                {
                    Position = nextPos,
                    RemainingLifeTicks = proj.RemainingLifeTicks - 1
                };
            }
        }

        // 13. Update Enemies, Skills (Q & R Laser) & Check Player Collisions
        int incomingDamage = 0;

        for (int i = _enemies.Count - 1; i >= 0; i--)
        {
            EnemyState enemy = _enemies[i];
            if (!enemy.IsAlive)
            {
                _enemies.RemoveAt(i);
                continue;
            }

            // Skill Q wide shockwave damage check
            if (executedSkillQ)
            {
                int qDistX = Math.Abs(clampedPosition.X - enemy.Position.X);
                int qDistY = Math.Abs(clampedPosition.Y - enemy.Position.Y);
                if (qDistX <= SkillQRadius && qDistY <= SkillQRadius)
                {
                    int updatedHp = enemy.Health - SkillQDamage;
                    if (updatedHp <= 0)
                    {
                        Score += ScorePerKill;
                        _enemies.RemoveAt(i);
                        continue;
                    }
                    enemy = enemy with { Health = updatedHp };
                }
            }

            // Skill R continuous piercing laser damage check
            if (laserActive > 0)
            {
                int toEnemyX = enemy.Position.X - clampedPosition.X;
                int toEnemyY = enemy.Position.Y - clampedPosition.Y;

                long dot = ((long)toEnemyX * laserDirection.X + (long)toEnemyY * laserDirection.Y) / 1000;

                if (dot > 0 && dot <= LaserLength)
                {
                    long perpX = toEnemyX - ((dot * laserDirection.X) / 1000);
                    long perpY = toEnemyY - ((dot * laserDirection.Y) / 1000);
                    long perpDistSq = perpX * perpX + perpY * perpY;

                    long maxAllowedDist = LaserBeamWidth + EnemyRadius;
                    if (perpDistSq <= maxAllowedDist * maxAllowedDist)
                    {
                        int laserHp = enemy.Health - LaserDamagePerTick;
                        if (laserHp <= 0)
                        {
                            Score += ScorePerKill;
                            _enemies.RemoveAt(i);
                            continue;
                        }
                        enemy = enemy with { Health = laserHp };
                    }
                }
            }

            // Simple integer pursuit: step towards player position
            int dirX = Math.Sign(clampedPosition.X - enemy.Position.X);
            int dirY = Math.Sign(clampedPosition.Y - enemy.Position.Y);

            SimVector2 newEnemyPos = enemy.Position + new SimVector2(
                dirX * EnemySpeedPerTick,
                dirY * EnemySpeedPerTick
            );

            _enemies[i] = enemy with { Position = newEnemyPos };

            // Check collision with player (True circular distance check)
            int combinedRadius = PlayerRadius + EnemyRadius;
            long contactDx = clampedPosition.X - newEnemyPos.X;
            long contactDy = clampedPosition.Y - newEnemyPos.Y;
            long contactDistSq = (contactDx * contactDx) + (contactDy * contactDy);
            long combinedRadiusSq = (long)combinedRadius * combinedRadius;

            if (contactDistSq < combinedRadiusSq)
            {
                incomingDamage += 1; // Deal contact damage per tick
            }
        }

        // Apply incoming damage: Shield absorbs damage before player health
        int damageToHealth = incomingDamage;
        if (currentShield > 0 && incomingDamage > 0)
        {
            if (currentShield >= incomingDamage)
            {
                currentShield -= incomingDamage;
                damageToHealth = 0;
            }
            else
            {
                damageToHealth = incomingDamage - currentShield;
                currentShield = 0;
            }
        }

        // 14. Update the player state with an immutable snapshot update
        // Used the 'with' expression on the record struct to produce a clean new state
        // Calculate damage and resolve authoritative health state
        int finalHealth = Math.Max(0, Player.Health - damageToHealth);
        bool isAlive = finalHealth > 0;

        Player = Player with
        {
            Position = clampedPosition,
            Health = finalHealth,
            Shield = currentShield,
            ShieldActiveTicks = shieldActive,
            ShieldCooldownTicks = eCooldown,
            DashCooldownTicks = currentDashCooldown,
            AttackCooldownTicks = attackCooldown,
            QCooldownTicks = qCooldown,
            RCooldownTicks = rCooldown,
            LaserActiveTicks = laserActive,
            LaserAimDirection = laserDirection,
            IsAlive = isAlive
        };
    }

    private void SpawnEnemy()
    {
        // Pick a pseudo-random point along the arena boundary
        int spawnX = _rng.NextRange(Arena.MinX + EnemyRadius, Arena.MaxX - EnemyRadius);
        int spawnY = _rng.NextRange(0, 2) == 0
            ? Arena.MinY + EnemyRadius
            : Arena.MaxY - EnemyRadius;

        _enemies.Add(new EnemyState(
            Id: _nextEnemyId++,
            Position: new SimVector2(spawnX, spawnY),
            Health: 30,
            IsAlive: true
        ));
    }

    // Deterministic integer square root (Newton-Raphson)
    private static int IntegerSqrt(long val)
    {
        if (val <= 0) return 0;
        long x0 = val / 2;
        if (x0 == 0) return 1;
        long x1 = (x0 + val / x0) / 2;
        while (x1 < x0)
        {
            x0 = x1;
            x1 = (x0 + val / x0) / 2;
        }
        return (int)x0;
    }
}

    const HEADER_SIZE = 21;
    const FRAME_SIZE = 15;
    const PLAYER_SPEED = 5000;

    let replay = null;

    function parseReplay(buffer) {
      const dv = new DataView(buffer);
      if (buffer.byteLength < HEADER_SIZE) throw new Error("File smaller than GHST header.");

      const magic = String.fromCharCode(dv.getUint8(0), dv.getUint8(1), dv.getUint8(2), dv.getUint8(3));
      if (magic !== "GHST") throw new Error("Invalid magic bytes. Expected 'GHST'.");

      const version = dv.getUint8(4);
      const seed = dv.getUint32(5, true);
      const spawnX = dv.getInt32(9, true);
      const spawnY = dv.getInt32(13, true);
      const inputCount = dv.getInt32(17, true);

      const frames = [];
      let offset = HEADER_SIZE;
      for (let i = 0; i < inputCount; i++) {
        if (offset + FRAME_SIZE > buffer.byteLength) break;
        frames.push({
          tick: dv.getInt32(offset, true),
          moveX: dv.getInt8(offset + 4),
          moveY: dv.getInt8(offset + 5),
          actions: dv.getUint8(offset + 6),
          aimX: dv.getInt32(offset + 7, true),
          aimY: dv.getInt32(offset + 11, true)
        });
        offset += FRAME_SIZE;
      }

      return { magic, version, seed, spawnX, spawnY, inputCount, frames };
    }

      if (!replay) return;
