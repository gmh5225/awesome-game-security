`README.md`:

```md
# Secure Boot & TPM 2.0 Check

Games with kernel anti-cheat often refuse to start unless **Secure Boot** and **TPM 2.0** are turned on. This tool tells you whether your PC is ready and, if it isn't, **exactly why** and how to fix it, step by step.

> [!IMPORTANT]
> **This tool makes no changes to your PC.**
> It only *reads* your settings. It does not change BIOS settings, files, disks, BitLocker or the TPM, and it never restarts your PC. Every fix is shown as instructions: nothing happens unless you decide to do it yourself.

## How to use it

### Option 1: one command (quickest)

Right-click the Start button, open **Terminal** or **PowerShell**, then paste this and press Enter:

```powershell
irm https://raw.githubusercontent.com/Krimziee/SecureBootCheck/main/run.ps1 | iex
```

Click **Yes** when Windows asks for admin rights. The firmware settings can only be read with them. The check opens in a new window.

Nothing is downloaded to your PC: the newest version is loaded straight from this repository into memory and run.

### Option 2: download it

1. Download the latest zip from **[Releases](https://github.com/Krimziee/SecureBootCheck/releases/latest)** and unpack it.
2. Double-click **`Check Secure Boot.cmd`**.
3. Click **Yes** when Windows asks for admin rights.

This opens the check in a window: your PC and every check on the left, the result and the fix steps on the right. Commands in the fix steps can be selected and copied, but the window never runs them. It has no button that changes anything. **Check again** runs the check once more after you've made a change.

The one-command version (Option 1) shows the same check as text.

Works on Windows 10 and Windows 11. The check is also a tab in Krimz's Toolkit, which shows the same window.

## What it checks

| Check | What it finds |
|---|---|
| Boot mode | Whether Windows started in UEFI mode or old Legacy / CSM mode (Secure Boot needs UEFI), and whether the motherboard supports UEFI at all |
| Windows disk | Whether the disk is GPT or MBR, and whether it can be converted without reinstalling Windows |
| Secure Boot | Whether it's on, and if not, why: switched off in the BIOS, keys wiped, audit mode, custom keys without Microsoft's certificate, or a motherboard that has no Secure Boot at all |
| Secure Boot keys | Missing Microsoft certificates, insecure test keys from the PC maker, and whether the 2023 certificate update is installed |
| TPM 2.0 | Whether a TPM is there, switched on, version 2.0 and ready, and which BIOS setting to turn on (AMD fTPM / Intel PTT). If none is found, it uses your processor to tell whether it's most likely just switched off or your processor has none. Also warns if the TPM is locked after too many wrong PINs |
| BitLocker | Whether your drive is encrypted and has a recovery key, so changing BIOS settings won't lock you out |

It also detects your PC or motherboard brand and tells you which key opens its BIOS setup.

**If it finds several problems**, it lists them as steps in the order you need to do them. For example, converting the disk comes before switching the BIOS to UEFI. Some settings can only be checked once the earlier steps are done, so run the check again afterwards.

**If your hardware can't do it**, it says so plainly instead of sending you hunting for settings that don't exist. That covers a motherboard without UEFI, a UEFI firmware without Secure Boot, and a processor without a built-in TPM 2.0. It also never suggests converting your disk on a motherboard that can't start in UEFI mode.

**What it can't see:** Windows can't look inside the BIOS menus, so it can't tell whether an option is greyed out or protected by a BIOS password. It also can't tell whether your motherboard has a connector for a separate TPM module; check the manual for that. It also can't predict problems that only appear after Secure Boot is turned on, such as an old graphics card showing a black screen. In those cases it gives you the most likely settings to check.

## Is it really read-only?

Yes. The script only reads firmware settings, the registry, the TPM status and the disk layout. Commands like `mbr2gpt /convert` or `manage-bde` appear only as text in the fix steps, and the script never runs them.

The one thing it writes: on a PC still in Legacy mode with an MBR disk, it runs Windows' own check-only command `mbr2gpt /validate` to see whether the disk can be converted. Like every run of that tool, it writes its log files (`setupact.log`, `setuperr.log`) to `C:\Windows`. It doesn't touch the disk itself.

## Protecting your data

Some fixes can affect your files if they're done carelessly, so the tool warns you before listing them:

- **BitLocker:** changing Secure Boot, TPM or boot settings makes Windows ask for your BitLocker recovery key. The tool checks that a key exists, shows how to view and save it, and how to pause BitLocker first.
- **Converting the disk (MBR to GPT):** this is built to keep your files, but a power cut while it runs can stop Windows from starting. The tool tells you to back up first and what to do afterwards.

## Windows warning when you start it

Windows may show **"Windows protected your PC"** because the file was downloaded from the internet. Click **More info → Run anyway**. The whole tool is plain PowerShell: you can open `SecureBootCheck.ps1` in Notepad and read exactly what it does.

## Running it from PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\SecureBootCheck.ps1
```

This shows the text version. Add `-NoPause` to close the window right away when it's finished, or `-Window` to open the window instead.

`SecureBootCheck.ps1`:

```ps1
<#
    Checks whether Secure Boot and TPM 2.0 are set up properly - what
    anti-cheat in many games requires - and, if they aren't, works out
    exactly why and what to change.

    THIS TOOL MAKES NO CHANGES TO THE PC. Every check only reads firmware
    variables, the registry, the TPM status and the disk layout. Fix
    commands are only printed as text for the user to run themselves.
    Anyone changing this script must keep it that way.

    The one side effect: "mbr2gpt /validate" (a check-only mode, run only on
    Legacy PCs with an MBR disk) writes Windows' usual setupact.log and
    setuperr.log files to C:\Windows.

    Run:  powershell -ExecutionPolicy Bypass -File SecureBootCheck.ps1
          (text version; double-click "Check Secure Boot.cmd" for the window)
          -Window     opens the window (modules\Ui.ps1) instead of the text version
          -LoadOnly   only loads the checks (used by the window and Krimz's Toolkit);
                      Invoke-SecureBootCheck then runs them and returns the results
#>
param([switch]$NoPause, [switch]$Window, [switch]$LoadOnly)

$script:Version = '1.0.2'

# ------------------------------------------------------------------
#  Admin rights: the firmware variables can only be read as admin
# ------------------------------------------------------------------

$principal = New-Object Security.Principal.WindowsPrincipal([Security.Principal.WindowsIdentity]::GetCurrent())
if (-not $LoadOnly -and -not $principal.IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)) {
    Write-Host 'Admin rights are needed to READ the Secure Boot and TPM settings - click "Yes" on the prompt.'
    Write-Host 'They are only used for reading. This tool makes no changes to your PC.'
    if ($PSCommandPath) {
        $arguments = '-NoProfile', '-ExecutionPolicy', 'Bypass', '-File', "`"$PSCommandPath`""
        if ($Window) { $arguments = @('-WindowStyle', 'Hidden') + $arguments + '-Window' }
    } else {
        # Started from memory (irm ... | iex): load it from GitHub again in the admin window
        $url = 'https://raw.githubusercontent.com/Krimziee/SecureBootCheck/main/SecureBootCheck.ps1'
        $command = "[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12; " +
                   "& ([scriptblock]::Create((Invoke-RestMethod -Uri '$url' -UseBasicParsing)))"
        $arguments = '-NoProfile', '-ExecutionPolicy', 'Bypass', '-EncodedCommand', [Convert]::ToBase64String([Text.Encoding]::Unicode.GetBytes($command))
    }
    try {
        Start-Process powershell.exe -Verb RunAs -ArgumentList $arguments
    } catch {
        if ($Window) {
            # The window's launcher hides the console, so say it in a message box
            Add-Type -AssemblyName PresentationFramework
            [System.Windows.MessageBox]::Show('Could not get admin rights. They are only used to READ the Secure Boot and TPM settings. Start the check again and click "Yes".',
                'Secure Boot & TPM 2.0 Check', 'OK', 'Information') | Out-Null
        } else {
            Write-Host 'Could not get admin rights. Start the check again and click "Yes".' -ForegroundColor Red
            if (-not $NoPause) { Read-Host 'Press Enter to close' | Out-Null }
        }
    }
    return   # not "exit": when run with "irm ... | iex", exit would close the player's PowerShell window
}

# ------------------------------------------------------------------
#  Output helpers
#  Every check records what it found in $script:Report (shown by the window)
#  and, in the text version, also prints it straight away.
# ------------------------------------------------------------------

$script:ConsoleOutput = $false      # the text version sets this before running the checks
$script:Report = New-Object System.Collections.Generic.List[object]
$script:Problems = New-Object System.Collections.Generic.List[object]
$script:Warnings = New-Object System.Collections.Generic.List[object]
$script:BitLocker = $null           # filled in by Test-BitLocker
$script:NeedsConversion = $false    # the fix includes mbr2gpt /convert

function Write-Section {
    param([string]$Title)
    $script:Report.Add([pscustomobject]@{ Title = $Title; Items = New-Object System.Collections.Generic.List[object] })
    if (-not $script:ConsoleOutput) { return }
    Write-Host ''
    Write-Host " $Title" -ForegroundColor Cyan
    Write-Host (' ' + ('-' * $Title.Length)) -ForegroundColor DarkCyan
}

function Write-Item {
    param(
        [string]$Label,
        [string]$Value = '',
        [ValidateSet('Ok', 'Warn', 'Fail', 'Info')] [string]$Status = 'Info'
    )
    if ($script:Report.Count) {
        $script:Report[$script:Report.Count - 1].Items.Add([pscustomobject]@{ Label = $Label.Trim(); Value = $Value; Status = $Status })
    }
    if (-not $script:ConsoleOutput) { return }
    $tag, $color = switch ($Status) {
        'Ok'   { '[ OK ]', 'Green' }
        'Warn' { '[WARN]', 'Yellow' }
        'Fail' { '[FAIL]', 'Red' }
        'Info' { '[INFO]', 'Gray' }
    }
    Write-Host "  $tag " -ForegroundColor $color -NoNewline
    Write-Host ("{0,-28} {1}" -f $Label, $Value)
}

function Write-Wrapped {
    # Prints text word-wrapped to the console width; continuation lines get the same indent
    param([string]$Text, [string]$First = '  ', [string]$Rest = '  ', [string]$Color)
    $width = 100
    try { $width = [math]::Min(100, [Console]::WindowWidth - 1) } catch { }
    $line = $First
    $hasWords = $false
    $lines = @()
    foreach ($word in $Text -split ' ') {
        if ($hasWords -and ($line.Length + 1 + $word.Length) -gt $width) { $lines += $line; $line = $Rest + $word }
        elseif ($hasWords) { $line += " $word" }
        else { $line += $word }
        $hasWords = $true
    }
    $lines += $line
    foreach ($l in $lines) { if ($Color) { Write-Host $l -ForegroundColor $Color } else { Write-Host $l } }
}

function Write-Advice {
    # Prints advice lines from Get-DataSafety (headings, paragraphs and bullet points)
    param($Lines)
    $colors = @{ Normal = $null; Warn = 'Yellow'; Fail = 'Red' }
    $previous = $null
    foreach ($l in $Lines) {
        $color = $colors[$l.Tone]
        switch ($l.Kind) {
            'Heading' { Write-Host ''; Write-Wrapped $l.Text -Color $(if ($color) { $color } else { 'Yellow' }) }
            'Text'    { if ($previous -ne 'Heading') { Write-Host '' }; Write-Wrapped $l.Text -Color $color }
            'Bullet'  { Write-Wrapped $l.Text -First '     - ' -Rest '       ' -Color $color }
        }
        $previous = $l.Kind
    }
}

# The order problems must be fixed in. Problems are listed in this order, not
# in the order they were found: e.g. the disk must be converted to GPT before
# the BIOS is switched to UEFI, and Secure Boot can only be turned on after that.
$script:FixOrder = @{ Disk = 1; BootMode = 2; SecureBoot = 3; Tpm = 4; ReadError = 5 }

function Add-Problem {
    # A problem that stops Secure Boot or TPM 2.0 from working, with the steps to fix it
    param([string]$Cause, [string[]]$Fix, [ValidateSet('Disk', 'BootMode', 'SecureBoot', 'Tpm', 'ReadError')] [string]$Area)
    $script:Problems.Add([pscustomobject]@{
        Cause = $Cause; Fix = $Fix
        Order = $script:FixOrder[$Area]
        Index = $script:Problems.Count   # keeps problems of the same area in the order they were found
    })
}

function Add-Warning {
    # Secure Boot works, but something about it should be looked at
    param([string]$Cause, [string[]]$Fix)
    $script:Warnings.Add([pscustomobject]@{ Cause = $Cause; Fix = $Fix })
}

function Get-FirmwareType {
    # Asks Windows directly how it was booted: 1 = Legacy BIOS, 2 = UEFI.
    # Declared in memory, not with Add-Type: that runs the C# compiler, which writes temporary files.
    try {
        $assembly = [AppDomain]::CurrentDomain.GetAssemblies() | Where-Object { $_.GetName().Name -eq 'SecureBootCheckFirmware' } | Select-Object -First 1
        $native = if ($assembly) { $assembly.GetType('FirmwareNative') }
        if (-not $native) {
            $builder = [AppDomain]::CurrentDomain.DefineDynamicAssembly((New-Object Reflection.AssemblyName 'SecureBootCheckFirmware'), 'Run')
            $type = $builder.DefineDynamicModule('SecureBootCheckFirmware').DefineType('FirmwareNative', 'Public, Class')
            $method = $type.DefinePInvokeMethod('GetFirmwareType', 'kernel32.dll', 'Public, Static, PinvokeImpl', 'Standard', [bool],
                                                [Type[]]@([uint32].MakeByRefType()), 'Winapi', 'Auto')
            $method.SetImplementationFlags('PreserveSig')
            $native = $type.CreateType()
        }
        $firmware = [uint32]0
        if ($native::GetFirmwareType([ref]$firmware)) {
            switch ($firmware) { 1 { return 'Legacy' } 2 { return 'UEFI' } }
        }
    } catch { }
    # Fallback: Windows also sets this variable at boot
    if ($env:firmware_type) { return $env:firmware_type }
    'Unknown'
}

function Get-UefiVariable {
    # Returns the raw bytes of a Secure Boot variable, or $null if it doesn't exist
    param([string]$Name)
    try {
        $var = Get-SecureBootUEFI -Name $Name -ErrorAction Stop
        if ($var -and $var.Bytes -and $var.Bytes.Length -gt 0) { return , $var.Bytes }
    } catch { }
    $null
}

function Get-UefiFlag {
    # Reads a one-byte on/off variable (SecureBoot, SetupMode...): 1, 0 or $null
    param([string]$Name)
    $bytes = Get-UefiVariable $Name
    if ($bytes) { [int]$bytes[0] } else { $null }
}

function Get-SignatureCertificates {
    <#
        Splits a key database (PK, KEK, db, dbx) into its certificates.
        The format is a list of EFI_SIGNATURE_LIST blocks; only the
        X.509 blocks hold certificates, the rest are file hashes.
    #>
    param([byte[]]$Bytes)
    $x509 = [guid]'a5c059a1-94e4-4aa7-87b5-ab155c2bf072'
    $offset = 0
    while ($Bytes -and $offset + 28 -le $Bytes.Length) {
        $type       = New-Object guid (, [byte[]]$Bytes[$offset..($offset + 15)])
        $listSize   = [BitConverter]::ToUInt32($Bytes, $offset + 16)
        $headerSize = [BitConverter]::ToUInt32($Bytes, $offset + 20)
        $sigSize    = [BitConverter]::ToUInt32($Bytes, $offset + 24)
        if ($listSize -lt 28 -or $offset + $listSize -gt $Bytes.Length) { break }   # damaged data

        if ($type -eq $x509 -and $sigSize -gt 16) {
            $sig = $offset + 28 + $headerSize
            while ($sig + $sigSize -le $offset + $listSize) {
                # Each entry is a 16-byte owner GUID followed by the certificate
                $der = [byte[]]$Bytes[($sig + 16)..($sig + $sigSize - 1)]
                try { New-Object Security.Cryptography.X509Certificates.X509Certificate2 (, $der) } catch { }
                $sig += $sigSize
            }
        }
        $offset += $listSize
    }
}

function Get-UefiSupportFlag {
    <#
        Reads the firmware's own description of itself (the SMBIOS "BIOS
        Information" table) and returns whether it says it supports UEFI:
        $true, $false, or $null when the firmware is too old to say.
        Layout: byte 0 = table type (0 = BIOS info), byte 1 = length,
        byte 0x13 = "characteristics extension byte 2", bit 3 = UEFI supported
        (defined since SMBIOS 2.7, so older firmware can't be judged).
    #>
    try {
        $raw = Get-CimInstance -Namespace root\wmi -ClassName MSSmBios_RawSMBiosTables -ErrorAction Stop | Select-Object -First 1
    } catch { return $null }
    if (-not $raw -or -not $raw.SMBiosData) { return $null }
    if ($raw.SmbiosMajorVersion -lt 2 -or ($raw.SmbiosMajorVersion -eq 2 -and $raw.SmbiosMinorVersion -lt 7)) { return $null }

    $data = [byte[]]$raw.SMBiosData
    $offset = 0
    while ($offset + 4 -le $data.Length) {
        $type = $data[$offset]; $length = $data[$offset + 1]
        if ($length -lt 4) { break }   # damaged table
        if ($type -eq 0) {
            if ($length -le 0x13 -or $offset + 0x13 -ge $data.Length) { return $null }
            return [bool]($data[$offset + 0x13] -band 0x08)
        }
        if ($type -eq 127) { break }   # end of table
        # Skip the fixed part, then the text strings that end with two zero bytes
        $offset += $length
        while ($offset + 1 -lt $data.Length -and -not ($data[$offset] -eq 0 -and $data[$offset + 1] -eq 0)) { $offset++ }
        $offset += 2
    }
    $null
}

function Get-CpuTpmSupport {
    <#
        Guesses from the processor whether it has a TPM 2.0 built in
        (Intel PTT / AMD fTPM / Microsoft Pluton): 'Yes', 'Maybe', 'No' or 'Unknown'.
        Known old processors are recognised by name. Anything else - including
        processors released after this script was written - is judged by the
        age of the firmware, so new processors count as having one.
        A strong hint, not proof.
    #>
    param([string]$Name, [string]$Vendor, $BiosDate)

    if ($Vendor -eq 'Qualcomm' -or $Name -match 'Snapdragon|Qualcomm') { return 'Yes' }   # every Windows-on-ARM PC

    if ($Vendor -eq 'AMD') {
        if ($Name -match 'Ryzen|Threadripper|EPYC') { return 'Yes' }           # every Zen processor has fTPM
        if ($Name -match 'Athlon.*\b(2\d\dGE?|3\d\d\dG[EU]?|Gold|Silver)\b') { return 'Yes' }   # Zen-based Athlons
        if ($Name -match '\bFX(\(tm\))?-|Phenom|Athlon(\(tm\))? (II|64)|Sempron|Opteron') { return 'No' }
    }

    if ($Vendor -eq 'Intel') {
        if ($Name -match 'Core\(TM\) Ultra|Core Ultra') { return 'Yes' }                     # Core Ultra, every generation
        if ($Name -match 'Core(\(TM\))? [3579] \d{3}') { return 'Yes' }                       # Core 3/5/7/9 without the "i" (2024+)
        if ($Name -match 'Intel(\(R\))? (Processor )?N\d{2,3}\b|Core(\(TM\))? i3-N\d{3}') { return 'Yes' }   # N100, N150, N200, N305...
        if ($Name -match 'Core\(TM\)2|Core 2|Pentium\(R\) (4|D)\b') { return 'No' }
        if ($Name -match '\bi[3579]-(\d{3,5})') {
            $model = $Matches[1]
            # i7-920 = 1st gen, i5-2500 = 2nd ... i7-9700 = 9th, i7-10700 / i5-1135G7 = 10th/11th, i7-12700 = 12th
            $gen = if ($model.Length -eq 3) { 1 }
                   elseif ($model.Length -eq 5 -or $model[0] -eq '1') { [int]$model.Substring(0, 2) }
                   else { [int]"$($model[0])" }
            if ($gen -ge 8) { return 'Yes' }     # every 8th gen and newer Core has PTT
            if ($gen -ge 4) { return 'Maybe' }   # PTT exists, but not every motherboard offers it
            return 'No'
        }
    }

    # Not recognised by name (Pentium, Celeron, Xeon, other or future processors): go by the firmware's age.
    # Built-in TPMs arrived around 2013 and are in practically every PC since about 2018.
    # A BIOS update makes the date newer, so this leans towards "Yes" - hence only a hint.
    if ($Vendor -in 'Intel', 'AMD' -and $BiosDate) {
        $year = ([datetime]$BiosDate).Year
        if ($year -ge 2018) { return 'Yes' }
        if ($year -ge 2013) { return 'Maybe' }
        return 'No'
    }
    'Unknown'
}

function Get-CommonName {
    param($Certificate)
    if ($Certificate.Subject -match 'CN=([^,]+)') { $Matches[1].Trim('"') } else { $Certificate.Subject }
}

function Test-IsLaptop {
    $laptopChassis = 8, 9, 10, 11, 12, 14, 18, 21, 30, 31, 32
    $chassis = (Get-CimInstance Win32_SystemEnclosure).ChassisTypes
    [bool](($chassis | Where-Object { $_ -in $laptopChassis }) -or
           (Get-CimInstance Win32_ComputerSystem).PCSystemType -eq 2 -or
           (Get-CimInstance Win32_Battery))
}

function Get-BiosKey {
    <#
        Returns the brand and the key that opens the BIOS/UEFI setup, or $null
        for unknown brands. Prebuilt PCs and laptops report their brand as the
        system maker; self-built PCs often report a placeholder ("System
        manufacturer", "To Be Filled By O.E.M."), so the motherboard maker is
        checked as well.
    #>
    param($ComputerSystem, [bool]$IsLaptop)
    $board = Get-CimInstance Win32_BaseBoard

    # Regex on the maker name -> brand, key on desktops, key on laptops
    $brands = @(
        ,@('ASUS',                'ASUS',              'Del (or F2)',           'F2')
        ,@('Micro-Star|^MSI',     'MSI',               'Del',                   'Del')
        ,@('Gigabyte|AORUS',      'Gigabyte',          'Del',                   'F2')
        ,@('ASRock',              'ASRock',            'F2 or Del',             'F2')
        ,@('Biostar',             'Biostar',           'Del',                   'Del')
        ,@('EVGA',                'EVGA',              'Del',                   'Del')
        ,@('Alienware',           'Alienware',         'F2',                    'F2')
        ,@('Dell',                'Dell',              'F2',                    'F2')
        ,@('^HP|Hewlett',         'HP',                'F10 (or Esc, then F10)', 'F10 (or Esc, then F10)')
        ,@('Lenovo',              'Lenovo',            'F1 or F2',              'F2 (or the small Novo button next to the power button)')
        ,@('Acer',                'Acer',              'F2 (or Del)',           'F2')
        ,@('Samsung',             'Samsung',           'F2',                    'F2')
        ,@('Toshiba|Dynabook',    'Toshiba / Dynabook','F2',                    'F2')
        ,@('Fujitsu',             'Fujitsu',           'F2',                    'F2')
        ,@('Framework',           'Framework',         'F2',                    'F2')
        ,@('Microsoft',           'Microsoft Surface', $null,                   $null)
    )

    foreach ($maker in $ComputerSystem.Manufacturer, $board.Manufacturer) {
        foreach ($b in $brands) {
            if ($maker -notmatch $b[0]) { continue }
            $key = if ($IsLaptop) { $b[3] } else { $b[2] }

            if ($b[1] -eq 'Lenovo' -and "$($ComputerSystem.SystemFamily) $($ComputerSystem.Model)" -match 'Think') {
                $key = 'F1'   # ThinkPad, ThinkCentre, ThinkStation
            }
            if ($b[1] -eq 'Microsoft Surface') {
                if ("$($ComputerSystem.Model)" -notmatch 'Surface') { continue }   # Hyper-V also says "Microsoft"
                return [pscustomobject]@{ Brand = $b[1]; Key = $null
                    How = 'Turn the Surface off. Hold the Volume Up button, press and release Power, and keep holding Volume Up until the Surface logo goes away.' }
            }
            return [pscustomobject]@{ Brand = $b[1]; Key = $key; How = $null }
        }
    }
    $null
}

function Test-System {
    Write-Section 'Your PC'
    $cs   = Get-CimInstance Win32_ComputerSystem
    $bios = Get-CimInstance Win32_BIOS
    $os   = Get-CimInstance Win32_OperatingSystem
    $cpu  = Get-CimInstance Win32_Processor | Select-Object -First 1
    $board = Get-CimInstance Win32_BaseBoard
    Write-Item 'Model' ("$($cs.Manufacturer) $($cs.Model)".Trim())
    if ($board.Manufacturer -and "$($cs.Manufacturer)" -notmatch [regex]::Escape("$($board.Manufacturer)".Split(' ')[0])) {
        Write-Item 'Motherboard' ("$($board.Manufacturer) $($board.Product)".Trim())
    }
    Write-Item 'Firmware' ("$($bios.Manufacturer) $($bios.SMBIOSBIOSVersion)".Trim())
    Write-Item 'CPU' ("$($cpu.Name)".Trim())
    Write-Item 'Windows' "$($os.Caption -replace '^Microsoft ', '') (build $($os.BuildNumber))"

    $model = "$($cs.Manufacturer) $($cs.Model)"
    $vm = switch -Regex ($model) {
        'Microsoft Corporation Virtual' { 'Hyper-V'; break }
        'VMware'                        { 'VMware'; break }
        'VirtualBox|innotek'            { 'VirtualBox'; break }
        'QEMU|KVM'                      { 'QEMU/KVM'; break }
        'Parallels'                     { 'Parallels'; break }
    }
    if ($vm) { Write-Item 'Virtual machine' $vm }

    $isLaptop = Test-IsLaptop
    [pscustomobject]@{
        Vm        = $vm
        IsLaptop  = $isLaptop
        CpuName   = "$($cpu.Name)".Trim()
        CpuVendor = switch -Wildcard ($cpu.Manufacturer) { 'AuthenticAMD' { 'AMD' } 'GenuineIntel' { 'Intel' } '*Qualcomm*' { 'Qualcomm' } default { 'Other' } }
        BiosDate  = $bios.ReleaseDate
        IsWin11   = [int]$os.BuildNumber -ge 22000
        Bios      = if (-not $vm) { Get-BiosKey -ComputerSystem $cs -IsLaptop $isLaptop }
    }
}

function Test-BootMode {
    param($Pc)
    $Vm = $Pc.Vm
    Write-Section 'Boot mode'
    $firmware = Get-FirmwareType
    $script:UefiSupport = 'Yes'
    if ($firmware -eq 'UEFI') {
        Write-Item 'Firmware boot mode' 'UEFI' 'Ok'
        return $firmware
    }

    Write-Item 'Firmware boot mode' "$firmware (Secure Boot needs UEFI)" 'Fail'

    # Is UEFI there at all? The firmware's self-description says so on most boards since about 2011;
    # for older firmware that can't say, the BIOS date is the best hint (Secure Boot arrived around 2012).
    $flag = Get-UefiSupportFlag
    $year = if ($Pc.BiosDate) { ([datetime]$Pc.BiosDate).Year } else { $null }
    $script:UefiSupport = if ($flag -eq $true) { 'Yes' }
                          elseif ($flag -eq $false) { 'No' }
                          elseif ($year -and $year -lt 2012) { 'Unlikely' }
                          else { 'Unknown' }
    if (-not $Vm) {
        switch ($script:UefiSupport) {
            'Yes'      { Write-Item 'UEFI support' 'yes (reported by the motherboard)' 'Ok' }
            'No'       { Write-Item 'UEFI support' 'NO - the motherboard reports it has no UEFI' 'Fail' }
            'Unlikely' { Write-Item 'UEFI support' "unlikely - BIOS from $year" 'Warn' }
            default    { Write-Item 'UEFI support' 'the motherboard does not say' 'Info' }
        }
    }

    if ($Vm -eq 'Hyper-V') {
        Add-Problem -Area BootMode 'This is a Generation 1 Hyper-V virtual machine. Those boot with a legacy BIOS and can never use Secure Boot.' @(
            'Create a new Generation 2 virtual machine and install Windows in it (a VM cannot be converted from Gen 1 to Gen 2).'
        )
    } elseif ($Vm) {
        Add-Problem -Area BootMode "The $Vm virtual machine is set to boot with a legacy BIOS." @(
            'Shut down the VM and switch its firmware to EFI / UEFI in the VM settings, then turn on Secure Boot there.',
            'The virtual disk must use GPT first - if it uses MBR, that step is listed before this one.'
        )
    } elseif ($script:UefiSupport -eq 'No') {
        Add-Problem -Area BootMode 'This motherboard does not support UEFI, so it cannot use Secure Boot. Its firmware reports a legacy BIOS only.' @(
            'Check the PC or motherboard maker''s support page for a BIOS update - a few older boards got UEFI in a later update.',
            'If there is none, this PC cannot run games that require Secure Boot. Only a newer motherboard (or PC) can fix that.',
            'Do NOT convert the disk to GPT on this PC: without UEFI, Windows would no longer start.',
            'If your BIOS setup does show a "UEFI" boot mode option anyway, the report is wrong - then follow the usual steps: convert the disk to GPT, switch to UEFI, disable CSM and enable Secure Boot.'
        )
    } else {
        $steps = @()
        if ($script:UefiSupport -eq 'Unlikely') {
            $steps += "Your BIOS is from $year - many boards that old have no UEFI and no Secure Boot. First open the BIOS setup and check that it has a `"UEFI`" boot mode option. If it has none, this PC cannot use Secure Boot, and you should not convert the disk."
        }
        Add-Problem -Area BootMode 'Windows was started in Legacy BIOS / CSM mode. Secure Boot only exists in UEFI mode, so it cannot be turned on yet.' ($steps + @(
            'If the Windows disk still uses MBR, convert it to GPT first (that step is listed before this one) - otherwise Windows will not start in UEFI mode.',
            'In the BIOS/UEFI setup: set Boot mode to "UEFI" (not "Legacy" or "UEFI and Legacy") and disable CSM / Compatibility Support Module.',
            'Then enable Secure Boot (on some boards: set "OS Type" to "Windows UEFI mode", or Secure Boot mode to "Standard").',
            'Very old graphics cards (around 2012 and older) have no UEFI support and show a black screen without CSM. Use the integrated graphics or a newer card in that case.'
        ))
    }
    $firmware
}

function Test-BootDisk {
    param([string]$Firmware)
    Write-Section 'Windows disk'
    try {
        $partition = Get-Partition -DriveLetter $env:SystemDrive[0] -ErrorAction Stop
        $disk = Get-Disk -Number $partition.DiskNumber -ErrorAction Stop
    } catch {
        Write-Item 'Partition style' 'could not be read' 'Warn'
        return
    }
    Write-Item 'Disk' "#$($disk.Number) $($disk.FriendlyName)"

    if ($disk.PartitionStyle -eq 'GPT') {
        Write-Item 'Partition style' 'GPT' 'Ok'
        return
    }

    $status = if ($Firmware -eq 'UEFI') { 'Warn' } else { 'Fail' }
    Write-Item 'Partition style' "$($disk.PartitionStyle) (UEFI needs GPT)" $status
    if ($Firmware -eq 'UEFI') { return }   # booted fine anyway, nothing to fix

    # Converting only makes sense if the board can start in UEFI mode - without it Windows would not start at all
    if ($script:UefiSupport -eq 'No') {
        Write-Item 'Convert to GPT' 'not suggested - this motherboard has no UEFI' 'Info'
        return
    }

    # MBR2GPT can convert the disk without reinstalling. /validate only checks, it changes nothing.
    $mbr2gpt = Join-Path $env:windir 'System32\mbr2gpt.exe'
    if (-not (Test-Path $mbr2gpt)) {
        Write-Item 'Convert without reinstall' 'MBR2GPT not available on this Windows' 'Warn'
        Add-Problem -Area Disk 'The Windows disk uses MBR. UEFI (and so Secure Boot) needs a GPT disk.' @(
            'Update Windows (MBR2GPT ships with Windows 10 1703 and later), or back up and reinstall Windows in UEFI mode.'
        )
        return
    }

    $output = & $mbr2gpt /validate /allowFullOS /disk:$($disk.Number) 2>&1 | Out-String
    if ($LASTEXITCODE -eq 0) {
        Write-Item 'Convert without reinstall' 'possible (MBR2GPT check passed)' 'Ok'
        $script:NeedsConversion = $true
        $steps = @()
        if ($script:UefiSupport -ne 'Yes') {
            $steps += 'Before converting, open the BIOS setup and make sure it has a "UEFI" boot mode option. Without one, Windows will not start after the conversion.'
        }
        Add-Problem -Area Disk 'The Windows disk uses MBR. UEFI (and so Secure Boot) needs a GPT disk.' ($steps + @(
            'First read "Before you change anything" above: back up your files and take care of BitLocker.',
            "Convert the disk (takes a minute, designed to keep all files):  mbr2gpt /convert /allowFullOS /disk:$($disk.Number)",
            'Immediately afterwards switch the BIOS to UEFI mode - after the conversion Windows no longer starts in Legacy mode.'
        ))
    } else {
        $reason = ($output -split "`r?`n" | Where-Object { $_ -match 'fail|error|cannot|unable|not ' } | Select-Object -First 3) -join ' '
        if (-not $reason) { $reason = "exit code $LASTEXITCODE" }
        Write-Item 'Convert without reinstall' 'not possible' 'Fail'
        Write-Item '  MBR2GPT says' $reason
        Add-Problem -Area Disk "The Windows disk uses MBR and MBR2GPT cannot convert it: $reason" @(
            'Most common causes: more than 3 primary partitions, no free space for the EFI partition, or a non-Windows partition layout.',
            'Details are in C:\Windows\setupact.log and setuperr.log.',
            'If it cannot be fixed: back up your files and reinstall Windows with the USB stick booted in UEFI mode.'
        )
    }
}

function Test-SecureBootState {
    Write-Section 'Secure Boot'
    $enabled = $null
    try {
        $enabled = Confirm-SecureBootUEFI -ErrorAction Stop
    } catch [System.PlatformNotSupportedException] {
        Write-Item 'Secure Boot' 'not supported on this boot mode' 'Fail'
        return $false
    } catch {
        Write-Item 'Secure Boot' "could not be read: $($_.Exception.Message)" 'Warn'
    }
    $reg = (Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\SecureBoot\State' -ErrorAction SilentlyContinue).UEFISecureBootEnabled
    if ($null -eq $enabled -and $null -ne $reg) { $enabled = $reg -eq 1 }

    if ($enabled) { Write-Item 'Secure Boot' 'ON' 'Ok' } else { Write-Item 'Secure Boot' 'OFF' 'Fail' }
    [bool]$enabled
}

function Test-FirmwareKeys {
    param([bool]$Enabled, [string]$Vm)

    $setupMode    = Get-UefiFlag 'SetupMode'
    $secureBoot   = Get-UefiFlag 'SecureBoot'
    $auditMode    = Get-UefiFlag 'AuditMode'
    $deployedMode = Get-UefiFlag 'DeployedMode'

    # Firmware with Secure Boot always has these two settings, even with the keys wiped.
    # If both are missing, the firmware has no Secure Boot feature at all.
    if ($null -eq $setupMode -and $null -eq $secureBoot) {
        Write-Item 'Secure Boot support' 'NO - the firmware has no Secure Boot settings' 'Fail'
        if ($Vm) {
            Add-Problem -Area SecureBoot "This $Vm virtual machine's firmware has no Secure Boot." @(
                "Shut down the VM and turn on Secure Boot in the $Vm VM settings (it may need a newer $Vm version)."
            )
        } else {
            Add-Problem -Area SecureBoot 'This motherboard''s firmware uses UEFI but has no Secure Boot feature (common on boards from around 2011-2012).' @(
                'Check the PC or motherboard maker''s support page for a BIOS update - some boards got Secure Boot in a later update.',
                'If there is none, this PC cannot run games that require Secure Boot. Only a newer motherboard (or PC) can fix that.'
            )
        }
        return
    }

    $pkBytes  = Get-UefiVariable 'PK'
    $pk  = @(if ($pkBytes)  { Get-SignatureCertificates $pkBytes })
    $kek = @(Get-SignatureCertificates (Get-UefiVariable 'KEK'))
    $db  = @(Get-SignatureCertificates (Get-UefiVariable 'db'))
    $dbx = Get-UefiVariable 'dbx'

    # ---- Mode -----------------------------------------------------
    $modeText = if ($setupMode -eq 1) { 'Setup mode (no Platform Key)' }
                elseif ($auditMode -eq 1) { 'Audit mode' }
                elseif ($deployedMode -eq 1) { 'Deployed mode' }
                elseif ($setupMode -eq 0) { 'User mode' }
                else { 'unknown' }
    Write-Item 'Firmware key mode' $modeText $(if ($setupMode -eq 1 -or $auditMode -eq 1) { 'Fail' } else { 'Info' })

    # ---- Platform Key ---------------------------------------------
    Write-Section 'Secure Boot keys'
    if (-not $pkBytes) {
        Write-Item 'Platform Key (PK)' 'missing' 'Fail'
    } elseif ($pk.Count) {
        $pkName = Get-CommonName $pk[0]
        if ($pkName -match 'DO NOT TRUST|DO NOT SHIP|\bTest\b') {
            Write-Item 'Platform Key (PK)' "$pkName  (test key!)" 'Warn'
            Add-Warning "The firmware uses a public test Platform Key (`"$pkName`"). Its private key is public, so anyone can bypass Secure Boot on this PC (known as PKfail)." @(
                'Install the latest BIOS/UEFI update from the PC or motherboard maker - fixed firmware ships a real key.'
            )
        } else {
            Write-Item 'Platform Key (PK)' $pkName 'Ok'
        }
    } else {
        Write-Item 'Platform Key (PK)' 'present' 'Ok'
    }

    # ---- KEK and db: the Microsoft certificates Windows relies on ---
    $kekNames = $kek | ForEach-Object { Get-CommonName $_ }
    $dbNames  = $db  | ForEach-Object { Get-CommonName $_ }

    $kek2011 = $kekNames -match 'Microsoft Corporation KEK CA 2011'
    $kek2023 = $kekNames -match 'KEK 2K CA 2023|KEK CA 2023'
    $win2011 = $dbNames -match 'Windows Production PCA 2011'
    $win2023 = $dbNames -match 'Windows UEFI CA 2023'
    $uefi2011 = $dbNames -match 'Microsoft Corporation UEFI CA 2011'
    $uefi2023 = $dbNames -match 'Microsoft UEFI CA 2023|Microsoft Option ROM UEFI CA 2023'

    $kekStatus = if ($kek2011 -or $kek2023) { 'Ok' } else { 'Fail' }
    Write-Item 'Microsoft KEK' $(if ($kek2023) { '2023 key' } elseif ($kek2011) { '2011 key only' } else { 'missing' }) $kekStatus

    $winStatus = if ($win2011 -or $win2023) { 'Ok' } else { 'Fail' }
    Write-Item 'Windows boot certificate' $(if ($win2023 -and $win2011) { '2011 + 2023' } elseif ($win2023) { '2023' } elseif ($win2011) { '2011 only' } else { 'missing' }) $winStatus

    $thirdStatus = if ($uefi2011 -or $uefi2023) { 'Ok' } else { 'Warn' }
    Write-Item 'Third-party UEFI cert.' $(if ($uefi2011 -or $uefi2023) { 'present' } else { 'missing' }) $thirdStatus

    Write-Item 'Revocation list (dbx)' $(if ($dbx) { "present ($($dbx.Length) bytes)" } else { 'empty' }) $(if ($dbx) { 'Ok' } else { 'Warn' })

    $otherKeys = @($kekNames | Where-Object { $_ -notmatch 'Microsoft' })
    foreach ($name in $otherKeys) { Write-Item 'Other KEK' $name }

    # ---- Work out why it's off --------------------------------------
    if (-not $Enabled) {
        if ($setupMode -eq 1 -or -not $pkBytes) {
            $steps = @(
                'In the BIOS/UEFI setup, open the Secure Boot page and choose "Restore Factory Keys" or "Install default Secure Boot keys".',
                'On some boards you first need to set Secure Boot mode to "Custom" to see that option, then back to "Standard".'
            )
            if ($Vm) { $steps += "In $Vm`: turn Secure Boot off and on again in the VM settings, or pick the Microsoft Windows Secure Boot template." }
            Add-Problem -Area SecureBoot 'The Secure Boot keys have been cleared (the firmware is in Setup mode, no Platform Key is installed). Secure Boot cannot switch on without keys.' $steps
        } elseif ($auditMode -eq 1) {
            Add-Problem -Area SecureBoot 'The firmware is in Audit mode: it checks signatures but does not enforce them.' @(
                'In the BIOS/UEFI setup, leave Audit mode (or restore the factory Secure Boot keys) and enable Secure Boot.'
            )
        } elseif (-not ($win2011 -or $win2023)) {
            Add-Problem -Area SecureBoot 'The firmware key database (db) does not contain the Microsoft Windows certificate, so the Windows boot manager would be blocked. Someone installed custom keys.' @(
                'In the BIOS/UEFI setup, choose "Restore Factory Keys" / "Install default Secure Boot keys", then enable Secure Boot.'
            )
        } elseif ($setupMode -eq 0 -and $secureBoot -eq 0) {
            $steps = @('The keys are installed correctly - Secure Boot is simply switched off. In the BIOS/UEFI setup, open the Secure Boot page and set it to "Enabled".')
            if (-not $Vm) {
                $steps += 'If the option is grey: disable CSM first, or set "OS Type" to "Windows UEFI mode" (ASUS) / Secure Boot mode to "Standard" (MSI, Gigabyte).'
                $steps += 'The change only counts after "Save & Exit" and a restart - run this check again afterwards.'
            } else {
                $steps += "Shut down the VM and enable Secure Boot in the $Vm VM settings."
            }
            Add-Problem -Area SecureBoot 'Secure Boot is turned off in the BIOS/UEFI settings.' $steps
        } else {
            Add-Problem -Area SecureBoot 'Secure Boot is off, but the firmware does not report why.' @(
                'In the BIOS/UEFI setup: restore the factory Secure Boot keys, disable CSM and enable Secure Boot.',
                'If that does not help, update the BIOS/UEFI firmware from the PC or motherboard maker.'
            )
        }

        if (-not ($uefi2011 -or $uefi2023) -and -not $Vm) {
            Add-Warning 'The "Microsoft UEFI CA" certificate is missing. Graphics cards and network cards sign their firmware with it - with Secure Boot on, they may show a black screen or not work.' @(
                'Restore the factory Secure Boot keys in the BIOS/UEFI setup; they include this certificate.'
            )
        }
    }

    # ---- Certificate update (the 2011 certificates expire in 2026) ---
    if (($win2011 -or $kek2011) -and -not ($win2023 -and $kek2023)) {
        $servicing = Get-ItemProperty 'HKLM:\SYSTEM\CurrentControlSet\Control\SecureBoot\Servicing' -ErrorAction SilentlyContinue
        $state = if ($servicing.UEFICA2023Status) { " (Windows status: $($servicing.UEFICA2023Status))" } else { '' }
        Write-Item '2023 certificate update' "not installed yet$state" 'Warn'
        Add-Warning "The firmware still only has Microsoft's 2011 Secure Boot certificates, which expire in 2026. Secure Boot keeps working, but this PC cannot receive new boot security fixes until the 2023 certificates are added.$state" @(
            'Install all Windows updates and reboot twice - Windows adds the 2023 certificates automatically.',
            'If it stays stuck, install the latest BIOS/UEFI update from the PC or motherboard maker.'
        )
    } elseif ($win2023 -and $kek2023) {
        Write-Item '2023 certificate update' 'installed' 'Ok'
    }
}

function Test-Tpm {
    # Many anti-cheats require TPM 2.0 as well as Secure Boot. Returns $true when it is usable.
    param($Pc)
    Write-Section 'TPM 2.0 (security chip)'

    # The BIOS calls the TPM built into the CPU by different names
    $chipName = switch ($Pc.CpuVendor) {
        'AMD'   { 'AMD fTPM (may be called "AMD CPU fTPM" or "Firmware TPM")' }
        'Intel' { 'Intel PTT (Platform Trust Technology, may be called "Firmware TPM")' }
        default { 'the TPM (may be called "Security Device Support" or "Trusted Computing")' }
    }

    $wmi = $null; $tpm = $null; $readErrors = 0
    try { $wmi = Get-CimInstance -Namespace 'root\cimv2\Security\MicrosoftTpm' -ClassName Win32_Tpm -ErrorAction Stop } catch { $readErrors++ }
    try { $tpm = Get-Tpm -ErrorAction Stop } catch { $readErrors++ }

    # Both ways failing (e.g. access denied) says nothing about the TPM - don't guess
    if ($readErrors -eq 2) {
        Write-Item 'TPM' 'could not be read - run this check as admin' 'Warn'
        Add-Problem -Area ReadError 'The TPM status could not be read, so this check cannot tell whether it is set up.' @(
            'Close this window, start "Check Secure Boot.cmd" again and click "Yes" on the admin prompt.'
        )
        return $false
    }

    if (-not (($tpm -and $tpm.TpmPresent) -or $wmi)) {
        Write-Item 'TPM' 'not found' 'Fail'
        if ($Pc.Vm -eq 'Hyper-V') {
            Add-Problem -Area Tpm 'This virtual machine has no TPM.' @(
                'Shut down the VM, open its Settings -> Security and tick "Enable Trusted Platform Module" (Generation 2 VMs only).'
            )
        } elseif ($Pc.Vm) {
            Add-Problem -Area Tpm 'This virtual machine has no TPM.' @(
                "Shut down the VM and add a virtual TPM (vTPM) in the $($Pc.Vm) VM settings."
            )
        } else {
            # A switched-off TPM is invisible to Windows, so the processor decides how likely each answer is
            $cpuTpm = Get-CpuTpmSupport -Name $Pc.CpuName -Vendor $Pc.CpuVendor -BiosDate $Pc.BiosDate
            $module = 'A separate TPM 2.0 module that plugs into the motherboard - only if the board has a "TPM" connector (check the motherboard manual). Without one, this PC cannot get TPM 2.0.'
            switch ($cpuTpm) {
                'Yes' {
                    Write-Item 'Built into processor' 'yes - so it is most likely just switched off' 'Info'
                    Add-Problem -Area Tpm "No TPM was found. Your processor ($($Pc.CpuName)) has a TPM 2.0 built in, so it is most likely just switched off in the BIOS." @(
                        "In the BIOS/UEFI setup turn on $chipName. It is usually on the Security, Advanced or Trusted Computing page."
                    )
                }
                'Maybe' {
                    Write-Item 'Built into processor' 'possibly - depends on the motherboard' 'Info'
                    Add-Problem -Area Tpm "No TPM was found. Your processor ($($Pc.CpuName)) has a built-in TPM 2.0, but not every motherboard of that age offers it." @(
                        "In the BIOS/UEFI setup look for $chipName and turn it on. It is usually on the Security, Advanced or Trusted Computing page.",
                        "If the BIOS has no such option (also after a BIOS update), the only way is: $module"
                    )
                }
                'No' {
                    Write-Item 'Built into processor' 'no - this processor has no TPM 2.0' 'Fail'
                    Add-Problem -Area Tpm "No TPM was found, and your processor ($($Pc.CpuName)) is too old to have a TPM 2.0 built in." @(
                        "The only way is: $module",
                        'If a TPM module is already fitted, it may be switched off - look for "TPM" or "Security Device Support" in the BIOS setup.'
                    )
                }
                default {
                    Add-Problem -Area Tpm 'No TPM was found. It is either switched off in the BIOS, or this PC has none.' @(
                        "In the BIOS/UEFI setup turn on $chipName. It is usually on the Security, Advanced or Trusted Computing page.",
                        'Most Intel and AMD processors from the last several years have a TPM 2.0 built in - it only needs to be switched on.',
                        "If there is no such option: $module"
                    )
                }
            }
        }
        return $false
    }

    $spec = if ($wmi.SpecVersion) { ("$($wmi.SpecVersion)" -split ',')[0].Trim() } else { $null }
    $specStatus = if ($spec -eq '2.0') { 'Ok' } elseif ($spec) { 'Fail' } else { 'Warn' }
    Write-Item 'TPM version' $(if ($spec) { $spec } else { 'unknown' }) $specStatus
    if ($tpm.ManufacturerIdTxt) { Write-Item 'TPM maker' ("$($tpm.ManufacturerIdTxt) $($tpm.ManufacturerVersion)".Trim()) }

    if ($spec -and $spec -ne '2.0') {
        Add-Problem -Area Tpm "This PC has an older TPM $spec. Games that require a TPM need version 2.0." @(
            "If your BIOS offers $chipName, switch to it: look for `"TPM Device Selection`" and choose Firmware TPM / PTT / fTPM instead of Discrete TPM.",
            'Some Dell, HP and Lenovo PCs can update their TPM from 1.2 to 2.0 with a tool from the PC maker - check the support page for your model.'
        )
        return $false
    }

    $enabled   = if ($null -ne $tpm.TpmEnabled)   { $tpm.TpmEnabled }   else { $wmi.IsEnabled_InitialValue }
    $activated = if ($null -ne $tpm.TpmActivated) { $tpm.TpmActivated } else { $wmi.IsActivated_InitialValue }
    if ($enabled -eq $false -or $activated -eq $false) {
        Write-Item 'TPM status' 'switched off' 'Fail'
        Add-Problem -Area Tpm 'The TPM is there but switched off.' @(
            "In the BIOS/UEFI setup turn on $chipName. It is usually on the Security, Advanced or Trusted Computing page."
        )
        return $false
    }

    # Too many wrong PIN attempts lock the TPM for a while; it doesn't stop it
    # from counting as TPM 2.0, but Windows Hello and some keys stop working
    if ($tpm -and $tpm.LockedOut) {
        $heal = if ($tpm.LockoutHealTime) { " It unlocks by itself after about $($tpm.LockoutHealTime) with the PC switched on." } else { '' }
        Write-Item 'TPM lockout' 'locked (too many wrong PIN attempts)' 'Warn'
        Add-Warning "The TPM is temporarily locked because of too many wrong PIN or password attempts.$heal" @(
            'Leave the PC switched on (not asleep) until the lock wears off. Do not try more PINs, each wrong try can extend it.',
            'Do not use "Clear TPM" to get rid of the lock unless you have your BitLocker recovery key: clearing deletes the keys stored in the TPM.'
        )
    }

    if ($tpm -and $tpm.TpmReady -eq $false) {
        Write-Item 'TPM status' 'on, but not ready yet' 'Warn'
        Add-Warning 'The TPM is on, but Windows has not finished setting it up.' @(
            'Restart the PC and install all Windows updates - Windows sets it up by itself.',
            'Press Win+R and run tpm.msc to see what Windows reports about it.',
            'Do not use "Clear TPM" unless you have your BitLocker recovery key: clearing deletes the keys stored in the TPM.'
        )
        return $true
    }

    Write-Item 'TPM status' 'on and ready' 'Ok'
    $true
}

function Get-BitLockerState {
    <#
        Reads BitLocker / Device Encryption for the Windows drive. Returns
        $null if the drive isn't encrypted or the state can't be read.
        Device Encryption is often switched on automatically on Windows Home
        when you sign in with a Microsoft account, so many players don't know they have it.
    #>
    try {
        $v = Get-BitLockerVolume -MountPoint $env:SystemDrive -ErrorAction Stop
        $types = @($v.KeyProtector | ForEach-Object { "$($_.KeyProtectorType)" })
        return [pscustomobject]@{
            Encrypted   = "$($v.VolumeStatus)" -ne 'FullyDecrypted'
            Protected   = "$($v.ProtectionStatus)" -eq 'On'
            Percent     = [int]$v.EncryptionPercentage
            HasRecovery = $types -contains 'RecoveryPassword'
        }
    } catch { }

    # Fallback for systems without the BitLocker PowerShell module
    try {
        $v = Get-CimInstance -Namespace 'root\cimv2\security\microsoftvolumeencryption' -ClassName Win32_EncryptableVolume `
            -Filter "DriveLetter='$env:SystemDrive'" -ErrorAction Stop
        if (-not $v) { return $null }
        $keys = Invoke-CimMethod -InputObject $v -MethodName GetKeyProtectors -Arguments @{ KeyProtectorType = [uint32]3 } -ErrorAction Stop
        $pct  = Invoke-CimMethod -InputObject $v -MethodName GetConversionStatus -ErrorAction Stop
        return [pscustomobject]@{
            Encrypted   = $v.ConversionStatus -ne 0
            Protected   = $v.ProtectionStatus -eq 1
            Percent     = [int]$pct.EncryptionPercentage
            HasRecovery = @($keys.VolumeKeyProtectorID).Count -gt 0
        }
    } catch { }
    $null
}

function Test-BitLocker {
    # Firmware changes make BitLocker ask for the recovery key - warn before the user goes into the BIOS
    Write-Section 'Drive encryption (BitLocker)'
    $state = Get-BitLockerState
    $script:BitLocker = $state
    if (-not $state -or -not $state.Encrypted) {
        Write-Item "Drive $env:SystemDrive" 'not encrypted' 'Ok'
        return
    }
    if ($state.Protected) {
        Write-Item "Drive $env:SystemDrive" "encrypted, protection on ($($state.Percent)%)" 'Info'
    } else {
        Write-Item "Drive $env:SystemDrive" "encrypted, protection suspended ($($state.Percent)%)" 'Info'
    }
    if ($state.HasRecovery) {
        Write-Item 'Recovery key' 'exists' 'Ok'
    } else {
        Write-Item 'Recovery key' 'NONE - a recovery screen would lock you out' 'Fail'
    }
}

function Get-DataSafety {
    <#
        Shown before the fixes: what each fix can do to the player's files, and
        how to stay safe. Returns lines of advice (Kind: Heading, Text or Bullet;
        Tone: Normal, Warn or Fail), or nothing when there is no risk to point out.
    #>
    $bl = $script:BitLocker
    $blActive = $bl -and $bl.Encrypted
    if (-not ($blActive -or $script:NeedsConversion)) { return }

    $drive = $env:SystemDrive
    $line = { param($Kind, $Text, $Tone = 'Normal') [pscustomobject]@{ Kind = $Kind; Text = $Text; Tone = $Tone } }

    if ($blActive) {
        & $line 'Heading' "Your Windows drive ($drive) is encrypted with BitLocker / Device Encryption." 'Warn'
        & $line 'Text' 'Changing Secure Boot, CSM, boot mode, TPM settings or the disk layout makes Windows ask for the 48-digit BitLocker recovery key at the next start. Without that key, everything on the drive is lost for good - nobody, not even Microsoft, can unlock it.'
        if (-not $bl.HasRecovery) {
            & $line 'Text' 'This drive has NO recovery key. Do not change any BIOS setting until you add one:' 'Fail'
            & $line 'Bullet' "Add a key (admin PowerShell):  manage-bde -protectors -add $drive -RecoveryPassword" 'Fail'
        }
        & $line 'Text' 'To stay safe:'
        & $line 'Bullet' "Show your recovery key now:  manage-bde -protectors -get $drive"
        & $line 'Bullet' 'Write the 48-digit "Numerical Password" down or photograph it with your phone. If you sign in with a Microsoft account it may also be at aka.ms/myrecoverykey.'
        if ($bl.Protected) {
            & $line 'Bullet' "Then pause BitLocker:  manage-bde -protectors -disable $drive -RebootCount 2"
            & $line 'Bullet' 'Your files stay encrypted; pausing only stops the key prompt and turns itself back on after 2 restarts. Do your BIOS changes within those 2 restarts.'
        } else {
            & $line 'Bullet' 'BitLocker is already paused, but it turns back on by itself after a restart. Keep the recovery key at hand anyway.'
        }
        if ($bl.Percent -lt 100) {
            & $line 'Bullet' "Encryption is still running ($($bl.Percent)%). Let it finish before you change anything." 'Warn'
        }
    }

    if ($script:NeedsConversion) {
        & $line 'Heading' 'About converting the disk (mbr2gpt /convert):' 'Warn'
        & $line 'Bullet' 'It is built to keep all your files, but it rewrites the layout of the disk. A power cut, crash or forced shutdown while it runs can leave Windows unable to start.'
        & $line 'Bullet' 'Only convert if your BIOS setup has a "UEFI" boot mode option - without one, Windows will not start after converting.'
        & $line 'Bullet' 'Back up anything you cannot re-download first (game saves, screenshots, documents, photos) to a USB drive or cloud storage.'
        & $line 'Bullet' 'On a laptop, plug in the charger. Close all programs and do not turn the PC off while it runs.'
        & $line 'Bullet' 'Right after converting, Windows ONLY starts in UEFI mode. If you see "no bootable device", your files are fine - switch the BIOS to UEFI mode. Switching back to Legacy will not work.'
        & $line 'Bullet' 'If Linux or another system is installed on the same disk, it may stop starting.'
        & $line 'Bullet' 'Do not use third-party "convert MBR to GPT" tools; mbr2gpt is the one built into Windows.'
    }
}

function Get-BiosAccess {
    # How to get into the BIOS/UEFI setup, where almost every fix is made. Returns one line per tip.
    param($Pc, [string]$Firmware)
    if ($Pc.Vm) { return }   # VM fixes are made in the VM settings
    $b = $Pc.Bios
    if ($b -and $b.How) {
        "$($b.Brand): $($b.How)"
    } elseif ($b) {
        "$($b.Brand) PC or motherboard: turn it on and keep pressing $($b.Key) until the setup screen opens."
    } else {
        'Turn the PC on and keep pressing Del or F2 (some PCs use F1, F10 or Esc). The right key is often shown for a moment on the start screen.'
    }
    if ($Firmware -eq 'UEFI') {
        $path = if ($Pc.IsWin11) { 'Settings -> System -> Recovery -> Advanced startup' } else { 'Settings -> Update & Security -> Recovery -> Advanced startup' }
        "Or from Windows: $path -> Restart now, then Troubleshoot -> Advanced options -> UEFI Firmware Settings -> Restart."
    }
    'If Windows starts too fast to press the key: hold Shift while clicking Shut down, then try again.'
    'Changes only count after you choose "Save & Exit" (often F10).'
}

function Invoke-SecureBootCheck {
    <#
        Runs every check and returns everything the text version and the
        window show. Only reads; can be run again (the window's "Check again").
    #>
    $script:Report   = New-Object System.Collections.Generic.List[object]
    $script:Problems = New-Object System.Collections.Generic.List[object]
    $script:Warnings = New-Object System.Collections.Generic.List[object]
    $script:BitLocker = $null
    $script:NeedsConversion = $false

    $pc       = Test-System
    $firmware = Test-BootMode -Pc $pc
    Test-BootDisk -Firmware $firmware
    $enabled  = $false
    $keysChecked = $firmware -eq 'UEFI'
    if ($keysChecked) {
        $enabled = Test-SecureBootState
        Test-FirmwareKeys -Enabled $enabled -Vm $pc.Vm
    } else {
        # The Secure Boot settings don't exist in Legacy mode, so they can only be checked after the switch to UEFI
        Write-Section 'Secure Boot'
        Write-Item 'Secure Boot' 'OFF (not available in Legacy mode)' 'Fail'
        Write-Item 'Secure Boot keys' 'can only be checked once Windows starts in UEFI mode' 'Warn'
    }
    $tpmOk = Test-Tpm -Pc $pc
    Test-BitLocker

    [pscustomobject]@{
        Version      = $script:Version
        Pc           = $pc
        Firmware     = $firmware
        SecureBootOn = [bool]$enabled
        TpmOk        = [bool]$tpmOk
        KeysChecked  = $keysChecked
        Sections     = $script:Report.ToArray()
        Problems     = @($script:Problems | Sort-Object Order, Index)
        Warnings     = $script:Warnings.ToArray()
        DataSafety   = @(Get-DataSafety)
        BiosAccess   = @(Get-BiosAccess -Pc $pc -Firmware $firmware)
    }
}

function Get-NativeMethods {
    if ($script:Native) { return $script:Native }
    $assembly = [AppDomain]::CurrentDomain.DefineDynamicAssembly((New-Object Reflection.AssemblyName 'SecureBootCheckWindow'), 'Run')
    $type = $assembly.DefineDynamicModule('SecureBootCheckWindow').DefineType('WindowNative', 'Public, Class')
    $functions = @(
        @{ Dll = 'user32.dll'; Name = 'SetProcessDpiAwarenessContext'; Returns = [bool]; Parameters = @([IntPtr]) }
        @{ Dll = 'user32.dll'; Name = 'SetProcessDPIAware';            Returns = [bool]; Parameters = @() }
        @{ Dll = 'dwmapi.dll'; Name = 'DwmSetWindowAttribute';         Returns = [int];  Parameters = @([IntPtr], [int], [int].MakeByRefType(), [int]) }
    )
    foreach ($f in $functions) {
        $method = $type.DefinePInvokeMethod($f.Name, $f.Dll, 'Public, Static, PinvokeImpl', 'Standard', $f.Returns,
                                            [Type[]]$f.Parameters, 'Winapi', 'Auto')
        $method.SetImplementationFlags('PreserveSig')
    }
    $script:Native = $type.CreateType()
    $script:Native
}

function Show-Verdict {
    param($Result)
    $ready = $Result.SecureBootOn -and $Result.TpmOk -and -not $Result.Problems.Count
    $notes = $Result.Warnings.Count
    $count = $Result.Problems.Count

    $level = if (-not $ready) { 'Fail' } elseif ($notes) { 'Warn' } else { 'Ok' }
    $script:Ui.ResultBadge.Background = $script:BadgeBack[$level]
    $script:Ui.ResultIcon.Text = $script:Glyph[$level]
    $script:Ui.ResultIcon.Foreground = $script:Colors[$level]

    if ($ready) {
        $script:Ui.ResultTitle.Text = 'Secure Boot and TPM 2.0 are ready'
        $script:Ui.ResultSubtitle.Text = 'Games that require them should run.' +
            $(if ($notes) { " $notes note$(if ($notes -ne 1) { 's' }) below $(if ($notes -ne 1) { 'are' } else { 'is' }) worth a look." })
    } else {
        $script:Ui.ResultTitle.Text = if ($count) { "$count thing$(if ($count -ne 1) { 's' }) to fix" } else { 'Not ready yet' }
        $script:Ui.ResultSubtitle.Text = 'Games that require Secure Boot / TPM 2.0 won''t run until this is fixed. Do the steps below in order.' +
            $(if (-not $Result.KeysChecked) { ' More steps may show up once Windows starts in UEFI mode.' })
    }

    # Two chips: the two things games ask for
    $chips = $script:Ui.ChipsPanel

function Set-CheckBusy {
    param([bool]$Busy)
    $script:Ui.CheckButton.IsEnabled = -not $Busy
    if ($script:SbState.OnBusy) { try { & $script:SbState.OnBusy $Busy } catch { } }
}

function Start-SecureBootCheck {
    $s = $script:SbState
    if ($s.PowerShell) { return }   # already checking
    $s.Started = $true
    $script:Ui.ResultPage.Visibility = 'Collapsed'
    $script:Ui.CheckingPage.Visibility = 'Visible'
    $script:Ui.CheckingTitle.Text = 'Checking your PC...'
    $script:Ui.CheckingText.Text = 'Reading the firmware settings, the TPM and the disk layout. This takes a few seconds and changes nothing.'
    $script:Ui.FooterText.Text = ''
    Set-CheckBusy $true

    $iss = [System.Management.Automation.Runspaces.InitialSessionState]::CreateDefault()
    $iss.ExecutionPolicy = 'Bypass'
    $runspace = [runspacefactory]::CreateRunspace($iss)
    $runspace.Open()
    $ps = [powershell]::Create()
    $ps.Runspace = $runspace
    [void]$ps.AddScript({
        param($File)
        $ErrorActionPreference = 'Continue'
        . $File -LoadOnly
        Invoke-SecureBootCheck
    }.ToString()).AddArgument($s.ScriptFile)
    $s.PowerShell = $ps
    $s.Handle = $ps.BeginInvoke()

    $s.Timer = New-Object System.Windows.Threading.DispatcherTimer
    $s.Timer.Interval = [TimeSpan]::FromMilliseconds(120)
    $s.Timer.Add_Tick({ Invoke-UiSafely { Receive-CheckResult } })
    $s.Timer.Start()
}

function Receive-CheckResult {
    $s = $script:SbState
    if (-not $s.Handle -or -not $s.Handle.IsCompleted) { return }
    $s.Timer.Stop()
    $ps = $s.PowerShell
    $result = $null; $problem = $null
    try {
        $output = $ps.EndInvoke($s.Handle)
        $result = $output | Where-Object { $_.PSObject.Properties['Sections'] } | Select-Object -Last 1
        if (-not $result) {
            $problem = @($ps.Streams.Error | ForEach-Object { $_.ToString() }) -join ' '
            if (-not $problem) { $problem = 'The check stopped without a result.' }
        }
    } catch {
        $problem = $_.Exception.Message
    } finally {
        Stop-SecureBootCheck
    }
    if ($result) { Show-SecureBootResult $result } else { Show-CheckFailed $problem }
}

function Stop-SecureBootCheck {
    # Ends the background check (also when the window closes while it is still running)
    $s = $script:SbState
    if ($s.Timer) { $s.Timer.Stop(); $s.Timer = $null }
    if ($s.PowerShell) {
        try { if (-not $s.Handle.IsCompleted) { $s.PowerShell.Stop() } } catch { }
        try { $s.PowerShell.Runspace.Dispose(); $s.PowerShell.Dispose() } catch { }
        $s.PowerShell = $null; $s.Handle = $null
    }
    Set-CheckBusy $false
}

function Import-SecureBootTheme {
    # The shared look (Theme.xaml) becomes the application's resources. Krimz's Toolkit does this itself.
    param([string]$Root)
    [xml]$xaml = Get-Content (Join-Path $Root 'ui\Theme.xaml') -Raw -Encoding UTF8
    $theme = [Windows.Markup.XamlReader]::Load((New-Object System.Xml.XmlNodeReader $xaml))
    $app = [System.Windows.Application]::Current
    if (-not $app) { $app = New-Object System.Windows.Application }
    $app.ShutdownMode = 'OnExplicitShutdown'
    $app.Resources = $theme
}

function New-SecureBootPage {
    <#
        Builds the page (ui\Page.xaml). Used by the standalone window below and
        by Krimz's Toolkit (modules\Page.ps1). The check starts with
        Start-SecureBootCheck. -OnBusy is called with $true / $false around it.
    #>
    param([string]$Root, [string]$Version, [scriptblock]$OnBusy)

    [xml]$xaml = Get-Content (Join-Path $Root 'ui\Page.xaml') -Raw -Encoding UTF8
    $page = [Windows.Markup.XamlReader]::Load((New-Object System.Xml.XmlNodeReader $xaml))
    $script:Ui.Page = $page
    $xaml.SelectNodes('//*[@*[local-name()="Name"]]') | ForEach-Object {
        $name = $_.GetAttribute('Name', 'http://schemas.microsoft.com/winfx/2006/xaml')
        if ($name) { $script:Ui[$name] = $page.FindName($name) }
    }
    $s = $script:SbState
    $s.ScriptFile = Join-Path $Root 'SecureBootCheck.ps1'
    $s.OnBusy = $OnBusy
    $s.Started = $false
    if ($Version) { $script:Ui.VersionText.Text = "v$Version" }

    $script:Ui.CheckButton.Add_Click({ Invoke-UiSafely { Start-SecureBootCheck } })
    $page
}

function Show-SecureBootWindow {
    # The standalone window. -NoShow builds it without opening it (used for automated screenshots)
    param([string]$Root, [string]$Version = $script:Version, [switch]$NoShow)

    Enable-DpiAwareness
    Import-SecureBootTheme $Root
    [xml]$xaml = Get-Content (Join-Path $Root 'ui\MainWindow.xaml') -Raw -Encoding UTF8
    $window = [Windows.Markup.XamlReader]::Load((New-Object System.Xml.XmlNodeReader $xaml))
    $script:Ui.Window = $window
    $window.Content = New-SecureBootPage -Root $Root -Version $Version

    # Dark title bar to match the window (Windows 10 2004+ / Windows 11)
    $window.Add_SourceInitialized({
        try {
            $hwnd = (New-Object System.Windows.Interop.WindowInteropHelper $script:Ui.Window).Handle
            $on = 1
            [void](Get-NativeMethods)::DwmSetWindowAttribute($hwnd, 20, [ref]$on, 4)
        } catch { }
    })
    $window.Add_ContentRendered({ Invoke-UiSafely { Start-SecureBootCheck } })
    $window.Add_Closing({ Stop-SecureBootCheck })

    if ($NoShow) { return $window }
    [void]$window.ShowDialog()
}

`run.ps1`:

```ps1
<#
    Secure Boot & TPM 2.0 Check - online starter

    Run this in PowerShell:

        irm https://raw.githubusercontent.com/Krimziee/SecureBootCheck/main/run.ps1 | iex

    What it does:
      1. Opens a new PowerShell window with admin rights (Windows asks "Yes/No")
      2. That window loads the newest SecureBootCheck.ps1 from GitHub into
         memory and runs it

    Nothing is saved to disk and nothing on the PC is changed.
#>

& {
    $url = 'https://raw.githubusercontent.com/Krimziee/SecureBootCheck/main/SecureBootCheck.ps1'

    # The admin window downloads the check itself and runs it from memory.
    # Passed as an encoded command so no quoting can break on the way.
    $command = "[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12; " +
               "& ([scriptblock]::Create((Invoke-RestMethod -Uri '$url' -UseBasicParsing)))"
    $encoded = [Convert]::ToBase64String([Text.Encoding]::Unicode.GetBytes($command))

    Write-Host ''
    Write-Host ' Secure Boot & TPM 2.0 Check' -ForegroundColor Cyan
    Write-Host ' This check makes no changes to your PC - it only reads your settings.' -ForegroundColor Gray
    Write-Host ' Click "Yes" when Windows asks for permission (needed to READ the settings).' -ForegroundColor Gray
    try {
        Start-Process -FilePath 'powershell.exe' -Verb RunAs -ArgumentList @(
            '-NoProfile', '-ExecutionPolicy', 'Bypass', '-EncodedCommand', $encoded
        )
        Write-Host ' The check is opening in a new window. You can close this one.' -ForegroundColor Green
    } catch {
        Write-Host " Couldn't start the check: $($_.Exception.Message)" -ForegroundColor Red
        Write-Host ' Run the command again and click "Yes" on the admin prompt.' -ForegroundColor Gray
    }
}
