`CHANGELOG.md`:

```md
# Changelog

All notable changes to the free tier. The public interface is still settling, so this
tracks it as it moves. Dates are ISO (year-month-day).

## 0.3.1 (2026-11-25)

### Changed
- The automatic start runs after `Application.onCreate`: it is posted to the main thread. SDKs
  your app sets up there (hook libraries, crash handlers) are in place before the checks read
  memory. With ByteHook, ShadowHook and Sentry in the app, `GOT_PLT_INTEGRITY` read INCONCLUSIVE in
  1 to 7 of 20 cold starts before, and in none after.
- `UPROBE_RESIDUE` reads only IntaktoFT's own code and libc's, as
  [the instrumentation checks page](docs/checks/instrumentation.md) says. It read all of the app's
  native code, so its time grew with the app.

### Fixed
- `OPCODE_TRAMPOLINE` catches hooks that jump through a register with `RET` (`LDR` or `ADRP`, then
  `RET Xn`), the shape Frida 17.27.4's Gadget and FreeDaah write when their code sits far from the
  hooked function. It read CLEAN on them.
- A thread that loads and unloads libraries nonstop no longer stalls the run. Libraries are found
  in the memory map instead of through the loader, which holds a lock while it loads.
- A region or call target that another thread unmapped after the run read the memory map is
  judged by a fresh map, not counted as suspect.
- `GOT_PLT_INTEGRITY` takes 0.6 to 2.8 ms per run instead of 16 to 25 ms (Pixel 3a, Pixel 6,
  Nothing Phone 2a).

### Docs
- Corrected the 0.2.0 entry on `CLV_PKGNAME_MISMATCH`: with no build-time package name it reads
  INCONCLUSIVE, as it shipped.

## 0.3.0 (2026-11-15)

### Breaking
- The repository moved to `github.com/IntaktoFT/IntaktoFT`, so the JitPack coordinate is now
  `com.github.IntaktoFT:IntaktoFT:v0.3.0`. GitHub redirects the old address.
- IntaktoFT never closes the app. It hands the result to your code, which decides what a catch
  means. `Mode` (`BLOCK`, `REPORT`) is removed with the "Security check" notice screen
  (`NoticeActivity`) and its manifest entry.
- `Verdict` (`PASS`, `BLOCK`) is removed. `Report.verdict` is now a `Status`: DETECTED if any
  signal is DETECTED, else INCONCLUSIVE if any signal is INCONCLUSIVE, else CLEAN. A run with a
  check that could not answer no longer reads PASS.
- `Report.enforced` is renamed `Report.detected`. It still holds the DETECTED signals.
- `check(context, mode, onResult)` is now `check(context, onResult)`. It hands you the latest
  finished result; a call made before the first run ends waits for that run.

### Added
- The checks start by themselves when the app's main process starts, through a `ContentProvider`
  in the library's manifest (`IntaktoInitProvider`). No `Application` class or manifest change is
  needed. To turn it off, remove the provider with `tools:node="remove"`; the first `check()` call
  then starts the run. Other processes of the app start their run on their first `check()` call.
- `Intakto.recheck(context, onResult)` runs the checks again and hands you the new result, for
  moments such as login or payment.
- Unity package (`unity/`, installed from `https://github.com/IntaktoFT/IntaktoFT.git?path=unity`):
  `Intakto.Check(onResult)` and `Intakto.Recheck(onResult)` from C#.

### Changed
- `Report.elapsedMs` is the run's own time, from its start to its last check, so a cached result
  keeps the time of the run that made it.

## 0.2.1 (2026-10-31)

### Changed
- `Intakto.check` is now callable from Java the same way as from Kotlin: `Intakto.check(this)`. Added
  `@JvmStatic` and `@JvmOverloads`, so Java sees a static method and the optional `mode`/`onResult`
  arguments. The result callback is now a `ReportCallback` single-method interface instead of a Kotlin
  function type, so a Java lambda needs no `Unit.INSTANCE`. Kotlin callers are unaffected.
- The library is built for Java 11 instead of Java 17, so projects set to Java 11 compatibility
  (including Android Studio's default new-project settings) can use it. The library is pure Kotlin and
  uses no Java 17 API, so only the class-file version changed.

### Docs
- Rewrote the integration guide: a from-scratch setup (the `Application` class and the manifest
  `android:name`, with a note that a missing `android:name` makes the check silently never run),
  version-catalog and Groovy dependency forms, a default-mode callback example, an API table, and a
  note that x86 emulators run 8 of the 12 checks.
- Added `TEST_RESULTS.md` and pointed the README and integration-guide results links at it.
- Corrected three 0.2.0 entries below that did not match the shipped behaviour: the `Mode.BLOCK`
  notice, the native-library packaging (all four chips ship as normal `jni/` libraries), and the
  `CHECK_STALLED`/`CHECK_FAILED` status (INCONCLUSIVE, which never closes the app).

## 0.2.0 (2026-10-31)

### Breaking
- The library is renamed from BlackHex to Intakto. The entry object `BlackHex` is now `Intakto`,
  and the native library file is `libintakto.so`. The GitHub repository is now
  `areyougarou/IntaktoFT`; the old addresses redirect. Install through JitPack:
  `com.github.areyougarou:IntaktoFT:v0.2.0`.
- The code package is renamed from `rasp.sdk` to `io.github.areyougarou.intakto`. Update your imports.
- `Signal.category` and `Signal.severity` (free-text strings) are removed. Use `Signal.group`
  (`APP_INTEGRITY`, `INSTRUMENTATION`).
- The free tier now answers two questions only: were the app files changed, and is running code
  hooked. Every `ROOT_*`, `EMU_*` and `CROM_*` check is removed with its group: honest users have
  rooted phones, emulators and custom systems, so these are not grounds to stop an app.
- `Policy` and its per-group toggles are removed. One setting replaces them: `Mode.BLOCK` (the
  default: Intakto stops the app on any DETECTED signal) or `Mode.REPORT` (Intakto never stops
  the app and hands the report to the callback).
- `check(context, mode, onResult)` returns at once and delivers the report on the main thread. The
  mode and the callback are optional, so the whole setup is `Intakto.check(this)`. The blocking
  `val report = BlackHex.check(context, policy)` is removed.
- `BlackHex.baseline { }` is removed with every value in it (`packageName`, `resources`,
  `nativeLib`, `dexCrc`, `signers`). There is nothing to paste or configure.
- `Signal.certainty` is removed. A check that cannot get an answer reads INCONCLUSIVE, with details
  starting `could not verify`, and never closes the app. Only a DETECTED signal makes the verdict BLOCK.
- Checks removed: `TAMPER_NATIVELIB`, `TAMPER_RESOURCES`, `CLV_DEX_CRC` (they needed pasted
  build-time values and could not match a Play install); `TAMPER_SIGNER` and
  `CLV_SIGCERT_MISMATCH` (they needed a pasted signer); `CLV_CGROUP_UID_MISMATCH`,
  `CLV_AM_SINGLETON_PROXY`, `CLV_MAPS_ENGINE_STRING`, `ELF_IN_ANON`, `MAPS_INTEGRITY` and
  `ART_ENTRYPOINT_INTEGRITY` (honest phones can show them); `NAMED_LINKER_EXPORTS` (it matched only
  five fixed Frida function names).
- `HOOK_BYTES_DIRECT` and `HOOK_BYTES_MEM` are merged into `HOOK_BYTES`.

### Added
- `FRIDA_AGENT_IN_MEMORY`: flags a library loaded from memory (anonymous memory or a memfd) whose own
  export table holds `frida_agent_main`, the entry point of Frida's agent, which is how frida-server
  loads it. It replaces the removed `ELF_IN_ANON`, which flagged any library in that memory and
  so could fire on honest apps that unpack their own libraries there (packers, anti-cheat).
- `DISGUISED_LIBRARY_IN_MEMORY`: flags a library loaded from a memfd named as the system's own memory
  (ART's `jit-cache`, `dalvik`, and the like), which never holds a library. Frida builds that rename the
  agent's entry, so `FRIDA_AGENT_IN_MEMORY` misses them, hide their agent this way (Florida and its
  builds, Rusda, strongR-frida, phantom-frida, FreeDaah).
- Zero-paste setup. The package name is read from a manifest value Android fills in at build
  time, and the signer from Android, so the developer configures nothing.
- `Mode.BLOCK` shows a short "Security check" notice naming what was detected, then stops the app when
  the user dismisses it: it closes the app's tasks (which removes them from the recent-apps list) and
  ends its process.
- `TAMPER_APK_CONTENT`: verifies each installed APK file (base and every split) against the
  signature block inside that file, and against the signer Android reports. It finds the real
  base.apk from the process memory map and reads it below the Java layer, so a tool that points
  the app at a clean copy does not fool it.
- `TAMPER_PUBLIC_KEY`: flags an app signed with a key anyone can download, the public AOSP test
  keys and the keys that ship inside common re-signing tools, matched by exact SHA-256.
- One package carries native code for all four chip types (arm64-v8a, armeabi-v7a, x86_64, x86), each
  shipped as a normal `jni/<abi>/libintakto.so` library. A check built for one chip type is left out of
  the report on the others.
- `CHECK_STALLED` and `CHECK_FAILED`: a run that made no progress for 5 s, or that could not run. Both
  read INCONCLUSIVE, so on their own they never close the app; only a DETECTED signal does.
- An app that Google Play installs while it downloads (Android 12 and later) is checked once the
  download finishes. The 5 s stall limit does not count while it waits.

### Changed
- One run happens at a time. Calls made during a run share it, and each keeps its own mode.
- `TAMPER_SIGNING_BLOCK` and `TAMPER_APK_CONTENT` accept the file when any of its v2, v3 or v3.1
  signing entries carries a signer Android reports, so a key-rotated app is not flagged after an
  Android upgrade. Both are left out for an app that ships inside the system image.
- `TAMPER_PUBLIC_KEY` is reported on debuggable builds too.
- `CLV_PKGNAME_MISMATCH` reads INCONCLUSIVE, instead of disappearing, when the build-time package name
  is missing from the manifest.
- The APK files are hashed again in every new app process; nothing is cached across app starts.
- Fixed APK and device facts are read once per process and reused.
- Repackaging-tool markers are matched by file name inside any folder, and read from the real APK
  below the Java layer, so App Cloner and LSPatch are caught where the old match missed them.
- `LIB_FROM_ROOT_PATH` no longer counts every root module loaded into the app, because Zygisk loaders
  such as ReZygisk load every enabled module into every app. A module counts only if it is LSPosed,
  Vector or ZygiskFrida, which unload themselves from every app they do not hook. Code from
  `/data/local/tmp`, or from `/data/adb` outside the modules folder, still reads DETECTED.
- `HOOK_BYTES`, `OPCODE_TRAMPOLINE` and `GOT_PLT_INTEGRITY` read INCONCLUSIVE, not DETECTED, for a
  hook they cannot follow to any library: it proves a hook, not who placed it. A hook that lands in
  a library outside the app's install folder still reads DETECTED.

### Fixed
- The hook checks follow a jump into a library's padding. The kernel's page-size compat shows that
  padding as its own `---p [page size compat]` line whatever its real access, and ShadowHook writes
  its jump there in libc on the Nothing Phone 2a, so an honest ShadowHook app was closed there.
- A crafted signing block could crash the native parser on 32-bit ARM or make it loop forever.
- The ZIP end record is found the way Android finds it, so a fake one inside the ZIP comment is
  ignored.
- The APK file checks read only files in the folders Android installs apps into, so an
  app-writable copy is never used.
- Memory checks now work in release builds. They read the app's own memory through a pipe, so a
  whole family of checks that silently read nothing on shipped builds now runs.
- A native check that cannot read the process memory map reports `could not verify`, instead of a
  false CLEAN.
- `HOOK_BYTES` and `OPCODE_TRAMPOLINE` compare a suspected jump against the same bytes in the
  library file on disk, so a jump that ships in the original library is not reported.
- Memory-map paths are kept in full.
- The native library is linked for 16 KB memory pages. A failed native load reports `NATIVE_CORE`
  instead of crashing the app, and the next call tries the load, and the APK file check, again.

### Security of the build
- Reproducible native build: build-machine paths are mapped out of the build id, so the same source
  produces a byte-identical library (on a Linux x86-64 host).

`README.md`:

```md
> [!IMPORTANT]
> **Why IntaktoFT?**
>
> Protecting your app doesn't have to be a nightmare.
>
> Every day, a new adblock gets released, a new cheat, a new Frida method. All free and open source.
> Meanwhile, cybersecurity giants gatekeep protection behind absurd prices.
>
> The only options for indie developers are to lose to attackers, or to shrink their margins.
>
> Unfair? I agree.
>
> This is why we're releasing IntaktoFT.

## ~ IntaktoFT

Free Android RASP (runtime application self-protection) library. The free tier is open source.\
It answers two questions: were your app's files changed (repackaging), and is someone hooking the running code (instrumentation)?\
It hands the answer to your code. It never closes your app.

## ~ What it offers and will never change

1. **It doesn't collect data**

   Sending data to third parties requires you to fill in the Google Play data form, provide privacy contracts, ask for your users' permission...\
   We don't collect data, so none of that headache.
2. **Effortless setup**

   Add one dependency line, and the checks start with your app.\
   One call, `Intakto.check(this) { report -> ... }`, hands you the answer.\
   No API key, no dashboard, no sign-up. Everything IntaktoFT needs is already inside your APK.
3. **Riskless**

   We use checks that produce zero false positives, crashes or slowdown.\
   Every check is tested across devices, Android versions and app types ([where we test it](#tested-on)).\
   If a check fires, someone is trying to harm your app.
4. **Free**

   Apache 2.0, commercial apps included, no account, no device limit.


## ~ Who is this for
- **Indie developers** who want anti-mod and tamper detection without a sales call or a server bill.
- **Game studios** losing money to cheats and to paid content unlocked for free.
- **Free, ad-supported apps** whose only income is the ads a modded copy strips out.


## ~ Why is it open source? Can't the attackers break into it?
The free tier is transparent and accessible, so that you can see what gets added to your app.\
But for the attacker knowing the defense is not enough, they need actual efforts and knowledge to break into it. And some of the checks are not easy to fool.\
Multiple apps who adopted IntaktoFT reported us that, even with the open sourced version, they noticed a visible reduction in offensive behavior.\
The paid tier is closed and obfuscated and is aimed at fighting profitable frauds and mass attacks. Not information you need, but the shareholders forced me to state it loud and clear.


## ~ Why no root, emulator or VPN checks?
Because most users who have them are not harmful. You'd end up losing real traffic witch-hunting a weak signal.\
Those checks are a liability, not a feature.\
Instead we only look for repackaging and instrumentation: attacks beyond any reasonable doubt.


## ~ How is IntaktoFT different from other free RASPs?
Other free RASPs collect data from your users' phones. Their root and hook checks have flagged genuine users.\
IntaktoFT flags only users who are actively harming your app, from values that prove instrumentation or repackaging. We don't chase weak signals or witch-hunt real users.\
A specialist beats a generalist. Google won by showing only results. Facing third-stage lung cancer, you would pick the oncologist who treats exactly that.\
So IntaktoFT stays narrow on purpose: zero false positives, retested against every new release of the tools below, and nothing sent anywhere.

# How to read a result

[Back to the README](../../README.md)

Every check answers one of three ways.
CLEAN: it looked and found nothing wrong.
DETECTED: it looked and found a real problem.
INCONCLUSIVE: it could not get an answer (a read failed or came back empty).

IntaktoFT never closes the app: your code reads each signal's status and decides. The report's
verdict is DETECTED if any check is DETECTED, else INCONCLUSIVE if any check is INCONCLUSIVE, else
CLEAN. So CLEAN always means every check really looked. The accepted cost is that an attacker with
root who blocks the reads a check needs gets INCONCLUSIVE from that check, not DETECTED.

A check is left out of the report only for a fact known before anything is read: the two APK
file checks for an app that ships inside the system image, and the 4 instrumentation checks built
only for arm64 phones (other chip types skip them). Left out means less coverage, not a clean
result.

# App integrity checks

[Back to the README](../../README.md)

**App integrity**: the installed app files are intact, signed by the key Android reports for the
app, and not renamed or cloned.

| Id | DETECTED means |
|---|---|
| `TAMPER_APK_CONTENT` | An installed APK file (the base or any split) no longer matches its own signature, or no signing entry in it carries a signer Android reports for the app. |
| `TAMPER_SIGNING_BLOCK` | No signing entry inside base.apk, read by native code with direct system calls, carries a signer Android reports for this app. So Android's answer, or the file, was faked or swapped. |
| `TAMPER_PUBLIC_KEY` | The app is signed with a key anyone can download: a public AOSP test key, or a key that ships inside a common re-signing tool (uber-apk-signer and others). |
| `TAMPER_REPACKAGER` | The APK holds files left by LSPatch or App Cloner. |
| `CLV_PKGNAME_MISMATCH` | The running package name differs from the application id written into the manifest when the app was built, so the app was renamed or cloned. |

Three more app-integrity results are INCONCLUSIVE, not DETECTED, so they never make the verdict DETECTED on
their own: `NATIVE_CORE` (the native library did not load, so the native checks could not run),
`CHECK_STALLED` (no check made progress for 5 s, or an earlier run is stuck) and `CHECK_FAILED`
(the run could not start, or it stopped with an error).

# Instrumentation checks

[Back to the README](../../README.md)

**Instrumentation**: someone is hooking or injecting code into your running app.

| Id | DETECTED means |
|---|---|
| `FRIDA_AGENT_IN_MEMORY` | A library loaded from memory, not from a file, exports `frida_agent_main`, the entry point of Frida's agent. |
| `DISGUISED_LIBRARY_IN_MEMORY` | A library is loaded from a memfd (a file that lives only in memory) named like the system's own memory, such as ART's `jit-cache`, which never holds a library. |
| `LIB_FROM_ROOT_PATH` | Code runs from a file in `/data/local/tmp` (where files pushed over ADB live) or `/data/adb` (where root modules live). A root module counts only if it is LSPosed (Vector) or ZygiskFrida: they load only into the apps they hook. Other modules load into every app, so they say nothing about yours. |
| `HOOK_BYTES` | A watched system function (`open`, `read`, `mmap`, `dlopen`, `dlsym` and others) begins with the `LDR X16` trampoline older Frida versions write, in memory, not the real code on disk. arm64 only. |
| `OPCODE_TRAMPOLINE` | A wider list of sensitive functions (adding `connect`, `ptrace`, `kill` and others) is checked for a jump or a breakpoint that the library file on disk does not have. arm64 only. |
| `GOT_PLT_INTEGRITY` | A function address table (GOT/PLT) in this library, libc or the Android runtime points outside any library file. arm64 only. |
| `UPROBE_RESIDUE` | Kernel tracing breakpoints (uprobes) sit in this library's code or in libc's code. arm64 only. |

`HOOK_BYTES`, `OPCODE_TRAMPOLINE` and `GOT_PLT_INTEGRITY` follow each hook to the code it jumps to. A hook that lands in a library shipped inside your APK is your own and reads CLEAN. A hook they cannot follow to any library reads INCONCLUSIVE: it proves a hook, not who placed it.

One case is flagged on purpose: a hooking library your app downloads into its data folder and loads at run time, instead of shipping it inside the APK. Nothing signs that folder, so a hook that lands there could be anyone's.

# Integration guide

[Back to the README](../../README.md)

Adding IntaktoFT takes one dependency line. Reading its answer takes one call.

**Requirements.** IntaktoFT needs `minSdk 26` (Android 8.0) or higher. It is built for Java 11, so it
works in projects set to Java 11 or higher, which includes Android Studio's default new-project
settings. It needs the Kotlin Gradle plugin 1.9 or higher.

## Step 1: add JitPack and the dependency

The exact coordinate is `com.github.IntaktoFT:IntaktoFT:v0.3.1`. Keep the `v`.

Kotlin DSL:

```kotlin

// app/build.gradle.kts, inside dependencies { ... }

```

```toml

```

```kotlin

```

Groovy DSL. Write the JitPack line with `url =`, not `url '...'`, which Gradle 8.13 warns it will

```groovy

// app/build.gradle, inside dependencies { ... }

```

## Step 2: read the result

The checks start by themselves when your app starts, on an IntaktoFT thread. You need no
`Application` class and no manifest change. Read the result with one call, from any Activity, your
`Application` class, or anywhere else you have a `Context`:

```kotlin
import io.github.areyougarou.intakto.Intakto
import io.github.areyougarou.intakto.Status

Intakto.check(this) { report ->
    when (report.verdict) {
        Status.DETECTED -> handleCatch(report.detected)   // a check found tampering or a hook
        Status.INCONCLUSIVE -> {}                         // a check could not confirm: not a catch
        Status.CLEAN -> {}                                // every check looked and found nothing
    }
}
```

The same call in Java. The callback is a single-method interface, so a plain lambda works, with no
`Unit.INSTANCE` to return:

```java
Intakto.check(this, report -> {
    if (report.getVerdict() == Status.DETECTED) handleCatch(report.getDetected());
});
```

IntaktoFT never closes your app and never shows anything to the user. Your code decides what a
catch means: log it, send it to your server, turn off a feature, or close the app. Without a
`check()` call the checks still run, but nothing visible happens, because the result has nowhere
to go.

On an x86 or x86_64 emulator, 8 of the 12 checks run. The 4 hook checks are written for arm64 phone
chips and do nothing on an emulator's x86 chip, so an emulator cannot show a hook, but it also never
raises a false alarm there. For the full set of checks, run on a real arm64 phone.

## How the result reaches you

- `check()` hands you the latest finished result. A call made before the first run ends gets the
  result when that run ends; a call made after gets it at once.
- `recheck()` runs the checks again and hands you the new result. Use it at sensitive moments
  (login, payment): a tool attached after your app started shows up only in a later run. Calls made
  while a run is going share that run, so a report can hold results from checks that finished
  before the call.
- The callback runs on the main thread, after `check()` returns. Never block the main thread
  waiting for it: it would never arrive.
- `report.verdict` is DETECTED if any signal is DETECTED, else INCONCLUSIVE if any signal is
  INCONCLUSIVE, else CLEAN. So CLEAN always means every check looked and found nothing.
- `report.signals`: every signal with its id, group, status, details and time in microseconds
  (`micros`). INCONCLUSIVE means the check could not confirm, with the reason in `details`.
- `report.detected`: the DETECTED signals only.
- If `context` is an Activity, or a context wrapped around one, and that Activity is finishing or
  destroyed when the result is ready, the callback is not called. After a screen rotation, call
  `check()` again from the new screen. Pass the application context to always get the callback.
- If no check makes progress for 5 s, the report holds the signals finished so far plus
  `CHECK_STALLED` (status INCONCLUSIVE). A check missing from that report did not finish; it was
  not left out. Hashing the APK files counts as progress, so a large app is not cut off for its
  size. If a run has made no progress for 5 s, a new call that has to wait for it gets
  `CHECK_STALLED` alone at once.
- Cost of one run (`Report.elapsedMs`, from the run's start to its last check), on our test phones
  (Android 12 to 17). A 1.5 MB app: 26 to 221 ms for the first run in an app process and 26 to
  162 ms for later runs. A 159 MB app: 112 to 284 ms for the first run and 40 to 161 ms for later
  runs. With the phone's file cache emptied, as on the first launch after a reboot, the first run
  took 546 to 559 ms on a Pixel 3a (Android 12) and 355 to 379 ms on a Pixel 7a (Android 16). We
  measured these on v0.2.1, whose checks are the same, from the call to the result.

## Apps with more than one process

The automatic start is a `ContentProvider` in IntaktoFT's manifest, the way Firebase starts.
Android creates it only in your app's main process. A process you declare with `android:process`
(for example a `:sync` service) runs no checks until code in that process calls `check()` or
`recheck()`; that first call starts the run there. Each process has its own run and its own
result.

## Turn off the automatic start

Add this inside `<application>` in your app's `AndroidManifest.xml`, with
`xmlns:tools="http://schemas.android.com/tools"` on the `<manifest>` tag:

```xml
<provider
    android:name="io.github.areyougarou.intakto.IntaktoInitProvider"
    android:authorities="${applicationId}.intaktoft"
    tools:node="remove" />
```

Then nothing runs until your first `check()` call, which starts the run.

| `Intakto.check` | `check(context: Context, onResult: ReportCallback = {})` | The latest finished result; waits for the first run if none has finished. Callable from Java as `Intakto.check(...)`. |
| `Intakto.recheck` | `recheck(context: Context, onResult: ReportCallback = {})` | Runs the checks again and hands you the new result. |
| `ReportCallback` | `fun onReport(report: Report)` | A single-method interface, so a Kotlin or Java lambda works. |
| `Report` | `signals: List<Signal>`, `verdict: Status`, `detected: List<Signal>`, `elapsedMs: Long` | `detected` is the DETECTED signals. |
| `Signal` | `id: String`, `group: Group`, `status: Status`, `details: String`, `micros: Long` | One check's result. |
| `Status` | `CLEAN`, `DETECTED`, `INCONCLUSIVE` | A signal's status, and the report's verdict. |
| `Group` | `APP_INTEGRITY`, `INSTRUMENTATION` | Which family a signal belongs to. |

    int fd = open("/proc/self/cmdline", O_RDONLY);
    if (fd < 0) return;

    ssize_t n = read(fd, buf, sizeof(buf) - 1);

}

namespace {

bool skip_ws(const char*& p, const char* e) {
    const char* s = p;
    while (p < e && (*p == ' ' || *p == '\t')) p++;
    return p > s;
}

bool number(const char*& p, const char* e, int base, uint64_t& v) {
    const char* s = p;
    v = 0;
    for (; p < e; p++) {
        unsigned d;
        if (*p >= '0' && *p <= '9') d = (unsigned)(*p - '0');
        else if (base == 16 && *p >= 'a' && *p <= 'f') d = (unsigned)(*p - 'a' + 10);
        else if (base == 16 && *p >= 'A' && *p <= 'F') d = (unsigned)(*p - 'A' + 10);
        else break;
        v = v * (uint64_t)base + d;
    }
    return p > s;
}

// One maps line: "start-end perms offset major:minor inode [path]". false = not a maps line.
bool parse_maps_line(const char* p, const char* e, VmaEntry& v) {
    uint64_t major = 0, minor = 0, inode = 0;
    if (!number(p, e, 16, v.start) || p >= e || *p++ != '-' || !number(p, e, 16, v.end) || !skip_ws(p, e)) return false;
    size_t n = 0;
    while (p < e && *p != ' ' && *p != '\t' && n < sizeof(v.perms) - 1) v.perms[n++] = *p++;
    v.perms[n] = 0;
    if (n == 0 || !skip_ws(p, e) || !number(p, e, 16, v.offset) || !skip_ws(p, e)) return false;
    if (!number(p, e, 16, major) || p >= e || *p++ != ':' || !number(p, e, 16, minor)) return false;
    if (!skip_ws(p, e) || !number(p, e, 10, inode)) return false;
    skip_ws(p, e);
    const char* q = p;
    while (q < e && *q != '\r') q++;
    v.path.assign(p, (size_t)(q - p));
    return true;
}

}

// Reads the whole map with large reads, then parses each line by hand: sscanf cost as much as the
// kernel's own work, and twice as much on a slow core.
std::vector<VmaEntry> read_maps() {
    std::vector<VmaEntry> result;
    int fd = open("/proc/self/maps", O_RDONLY | O_CLOEXEC);
    if (fd < 0) return result;
    std::string text;
    size_t len = 0;
    text.resize(256 * 1024);
    for (;;) {
        if (text.size() - len < 64 * 1024) text.resize(text.size() * 2);
        ssize_t n = read(fd, &text[len], text.size() - len);
        if (n < 0 && errno == EINTR) continue;
        if (n <= 0) break;
        len += (size_t)n;
    }
    close(fd);
    result.reserve(len / 100);
    const char* p = text.data();
    const char* end = p + len;
    while (p < end) {
        const char* nl = static_cast<const char*>(memchr(p, '\n', (size_t)(end - p)));
        const char* e = nl ? nl : end;
        VmaEntry v{};
        if (parse_maps_line(p, e, v)) result.push_back(std::move(v));
        p = e + 1;
    }
    auto by_start = [](const VmaEntry& a, const VmaEntry& b) { return a.start < b.start; };
    if (!std::is_sorted(result.begin(), result.end(), by_start)) std::sort(result.begin(), result.end(), by_start);
    return result;
}

const VmaEntry* vma_for(const std::vector<VmaEntry>& maps, uint64_t a) {
    auto it = std::upper_bound(maps.begin(), maps.end(), a, [](uint64_t x, const VmaEntry& v) { return x < v.start; });
    if (it == maps.begin()) return nullptr;
    --it;
    return a < it->end ? &*it : nullptr;
}

bool maps_available() { return !g_maps.empty(); }

static int g_mem_pipe[2] = {-1, -1};

static bool mem_pipe_open(int fds[2]) {
    return pipe2(fds, O_CLOEXEC | O_NONBLOCK) == 0;
}

void mem_run_begin() {
    if (g_mem_pipe[0] < 0 && !mem_pipe_open(g_mem_pipe)) {
        g_mem_pipe[0] = g_mem_pipe[1] = -1;
    }
}

void mem_run_end() {
    if (g_mem_pipe[0] >= 0) {
        close(g_mem_pipe[0]);
        close(g_mem_pipe[1]);
        g_mem_pipe[0] = g_mem_pipe[1] = -1;
    }
}

ssize_t safe_read_mem_n(uintptr_t addr, void* out, size_t len) {
    int local[2] = {-1, -1};
    bool use_run = g_mem_pipe[0] >= 0;
    int* fds = g_mem_pipe;
    if (!use_run) {
        if (!mem_pipe_open(local)) return -1;
        fds = local;
    }
    uint8_t* dst = static_cast<uint8_t*>(out);
    size_t done = 0;
    bool torn = false;
    while (done < len) {
        size_t chunk = len - done;
        if (chunk > 4096) chunk = 4096;
        // System calls by number, not libc's write() and read(): a hook on those two could hand every check
        // clean bytes.
        ssize_t w = (ssize_t)syscall(__NR_write, fds[1], reinterpret_cast<const void*>(addr + done), chunk);
        if (w <= 0) break;
        ssize_t got = 0;
        while (got < w) {
            ssize_t rd = (ssize_t)syscall(__NR_read, fds[0], dst + done + got, (size_t)(w - got));
            if (rd <= 0) break;
            got += rd;
        }
        done += (size_t)got;
        if (got < w) { torn = true; break; }
        if (w < (ssize_t)chunk) break;
    }
    if (use_run) {
        if (torn) { mem_run_end(); mem_run_begin(); }
    } else {
        close(local[0]);
        close(local[1]);
    }
    return (ssize_t)done;
}

bool safe_read_mem(uintptr_t addr, void* out, size_t len) {
    return safe_read_mem_n(addr, out, len) == (ssize_t)len;
}

size_t read_disk_bytes_for_addr(uintptr_t addr, void* out, size_t len) {
    const VmaEntry* v = vma_for(addr);
    if (!v || v->path.empty() || v->path[0] == '[') return 0;
    if (v->path.find("memfd:") != std::string::npos) return 0;
    int fd = open(v->path.c_str(), O_RDONLY | O_CLOEXEC);
    if (fd < 0) return 0;
    off64_t off = (off64_t)(v->offset + (addr - v->start));  // off_t is 32-bit on 32-bit ABIs
    ssize_t n = pread64(fd, out, len, off);
    close(fd);
    return n > 0 ? (size_t)n : 0;
}

std::string json_escape(const std::string& s) {
    std::string out;
    out.reserve(s.size() + 8);
    for (char c : s) {
        switch (c) {
            case '"':  out += "\\\""; break;
            case '\\': out += "\\\\"; break;
            case '\n': out += "\\n";  break;
            case '\r': out += "\\r";  break;
            case '\t': out += "\\t";  break;
            default:
                // Control bytes and every byte 0x7F and above become \u00XX, so the text handed to
                // NewStringUTF is plain ASCII: CheckJNI (on in debuggable builds and emulators) aborts
                // the app on a half-cut UTF-8 byte in a path or memfd name.
                if ((unsigned char)c < 0x20 || (unsigned char)c >= 0x7F) {
                    char buf[8];
                    snprintf(buf, sizeof(buf), "\\u%04x", (unsigned char)c);
                    out += buf;
                } else {
                    out += c;
                }
        }
    }
    return out;
}

#include "hook_dest.h"
#include <link.h>
#include <elf.h>

#include <cstdint>

#include <vector>

#if defined(__aarch64__)

extern "C" const ElfW(Ehdr) __ehdr_start __attribute__((visibility("hidden")));

namespace {

uint64_t g_vdso_s = 0, g_vdso_e = 0;
void find_vdso() {
    g_vdso_s = g_vdso_e = 0;
    for (const auto& v : g_maps)
        if (v.path.find("vdso") != std::string::npos || v.path.find("vvar") != std::string::npos) {
            if (!g_vdso_s || v.start < g_vdso_s) g_vdso_s = v.start;
            if (v.end > g_vdso_e) g_vdso_e = v.end;
        }
}

struct Mod { uintptr_t base, jmprel, strtab, symtab; size_t n; std::string name; };

struct Walk {
    std::vector<Mod> mods;
    int modules = 0;
    mutable std::vector<VmaEntry> fresh;
};

enum { TARGET_FINE, TARGET_SUSPECT, TARGET_APP_HOOK, TARGET_UNTRACED };

int target_kind(const Walk& w, uintptr_t target, std::string& where) {
    if (g_vdso_s && target >= g_vdso_s && target < g_vdso_e) return TARGET_FINE;
    const VmaEntry* v = vma_for(target);
    if (!v) {
        // Missing from the run's snapshot: another thread may have mapped it since. Only a target a fresh
        // map still lacks is suspect.
        if (w.fresh.empty()) w.fresh = read_maps();
        v = vma_for(w.fresh, target);
    }
    if (v) {
        const std::string& p = v->path;
        if (p.rfind("/data/adb/", 0) == 0 || p.find("/data/local/tmp/") != std::string::npos) { where = p; return TARGET_SUSPECT; }
        if (!p.empty() && p[0] != '[') {
            if (p.find("memfd:") == std::string::npos) return TARGET_FINE;
            if (p.find("jit-cache") != std::string::npos || p.find("code-cache") != std::string::npos) return TARGET_FINE;
        }
        where = p.empty() ? "[anon]" : p;
        if (v->anonymous()) {
            std::string to;
            HookOwner owner = hook_owner(target, to);
            if (owner == HOOK_APP_OWN) { where = to; return TARGET_APP_HOOK; }
            where += ", lands in " + to;
            // Not traced to any library: a hook, but not proof of who placed it.
            if (owner == HOOK_UNRESOLVED) return TARGET_UNTRACED;
        }
        return TARGET_SUSPECT;
    }
    where = "[unmapped]";
    return TARGET_SUSPECT;
}

// A library file that is only mapped as data (never loaded) is skipped: no executable segment of that
// file sits where its code would load, and its call table holds unrelocated values that would read as
// hooks.
bool read_mod(uintptr_t hdr, const std::string& path, Mod& m) {
    ElfW(Ehdr) eh;
    if (!safe_read_mem(hdr, &eh, sizeof(eh)) || memcmp(eh.e_ident, ELFMAG, SELFMAG) != 0 ||
        eh.e_machine != EM_AARCH64 || eh.e_phnum == 0 || eh.e_phnum > 64) return false;
    ElfW(Phdr) ph[64];
    if (!safe_read_mem(hdr + eh.e_phoff, ph, eh.e_phnum * sizeof(ElfW(Phdr)))) return false;
    uintptr_t base = 0, dyn = 0, code = 0;
    bool have = false;
    for (int i = 0; i < eh.e_phnum; i++) {
        if (ph[i].p_type == PT_LOAD && ph[i].p_offset == 0) { base = hdr - (uintptr_t)ph[i].p_vaddr; have = true; }
        if (ph[i].p_type == PT_LOAD && (ph[i].p_flags & PF_X) && !code) code = (uintptr_t)ph[i].p_vaddr;
        if (ph[i].p_type == PT_DYNAMIC) dyn = (uintptr_t)ph[i].p_vaddr;
    }
    if (!have || !dyn) return false;
    if (!path.empty()) {
        const VmaEntry* x = vma_for(base + code);
        if (!code || !x || !x->executable() || x->path != path) return false;
    }

    uintptr_t jmprel = 0, strtab = 0, symtab = 0;
    size_t pltrelsz = 0; long pltrel = 0;
    for (int i = 0; i < 512; i++) {
        ElfW(Dyn) d;
        if (!safe_read_mem(base + dyn + i * sizeof(d), &d, sizeof(d)) || d.d_tag == DT_NULL) break;
        switch (d.d_tag) {
            case DT_JMPREL:   jmprel   = base + d.d_un.d_ptr; break;
            case DT_PLTRELSZ: pltrelsz = d.d_un.d_val;        break;
            case DT_PLTREL:   pltrel   = d.d_un.d_val;        break;
            case DT_STRTAB:   strtab   = base + d.d_un.d_ptr; break;
            case DT_SYMTAB:   symtab   = base + d.d_un.d_ptr; break;
            default: break;
        }
    }
    if (!jmprel || !pltrelsz || pltrel != DT_RELA) return false;
    size_t n = pltrelsz / sizeof(ElfW(Rela));
    if (n > 8192) n = 8192;
    m = {base, jmprel, strtab, symtab, n, path.empty() ? "libintakto.so" : path};
    return true;
}

// Found in the memory map, not with dl_iterate_phdr: that waits for the loader's lock, which a thread
// loading libraries nonstop can hold past the stall limit.
void find_mods(Walk& w) {
    std::vector<uintptr_t> seen;
    auto add = [&](uintptr_t hdr, const std::string& path) {
        if (std::find(seen.begin(), seen.end(), hdr) != seen.end()) return;
        Mod m;
        if (!read_mod(hdr, path, m)) return;
        seen.push_back(hdr);
        w.modules++;
        w.mods.push_back(m);
    };
    add((uintptr_t)&__ehdr_start, "");
    for (const auto& v : g_maps) {
        if (v.anonymous() || v.perms[0] != 'r') continue;
        const char* b = strrchr(v.path.c_str(), '/');
        b = b ? b + 1 : v.path.c_str();
        if (strcmp(b, "libc.so") == 0 || strcmp(b, "libart.so") == 0) add(v.start, v.path);
    }
}

struct Ctx { int checked = 0, hits = 0, modules = 0, untraced = 0; std::string detail, own, untraced_detail; };

// One library's call table. The relocation table and the table of slots are each read in one go
// rather than about 4,000 reads of 8 or 24 bytes; a slot outside what that read returned is read alone.
void scan(const Walk& w, const Mod& m, Ctx* c) {
    const char* mod = !m.name.empty() ? m.name.c_str() : "[self]";
    const char* modb = strrchr(mod, '/'); modb = modb ? modb + 1 : mod;

    std::vector<ElfW(Rela)> rel(m.n);
    ssize_t got = safe_read_mem_n(m.jmprel, rel.data(), m.n * sizeof(ElfW(Rela)));
    size_t nrel = got > 0 ? (size_t)got / sizeof(ElfW(Rela)) : 0;  // stops at the first unreadable entry
    uintptr_t lo = UINTPTR_MAX, hi = 0;
    for (size_t i = 0; i < nrel; i++) {
        if (ELF64_R_TYPE(rel[i].r_info) != R_AARCH64_JUMP_SLOT) continue;
        lo = std::min(lo, (uintptr_t)rel[i].r_offset);
        hi = std::max(hi, (uintptr_t)rel[i].r_offset + sizeof(uintptr_t));
    }
    std::vector<uintptr_t> slots;
    ssize_t sgot = 0;
    if (lo < hi && hi - lo <= 1u << 20) {
        slots.resize((hi - lo + sizeof(uintptr_t) - 1) / sizeof(uintptr_t));
        sgot = safe_read_mem_n(m.base + lo, slots.data(), hi - lo);
    }

    for (size_t i = 0; i < nrel; i++) {
        const ElfW(Rela)& rr = rel[i];
        if (ELF64_R_TYPE(rr.r_info) != R_AARCH64_JUMP_SLOT) continue;

        uintptr_t target = 0;
        size_t at = (size_t)rr.r_offset - lo;
        if (sgot > 0 && at + sizeof(target) <= (size_t)sgot) memcpy(&target, (const char*)slots.data() + at, sizeof(target));
        else if (!safe_read_mem(m.base + rr.r_offset, &target, sizeof(target))) continue;
        if (target == 0) continue;
        c->checked++;

        std::string where;
        int kind = target_kind(w, target, where);
        if (kind == TARGET_FINE) continue;

        std::string sym = "?";
        if (m.symtab && m.strtab) {
            ElfW(Sym) s;
            uint32_t si = (uint32_t)ELF64_R_SYM(rr.r_info);
            if (safe_read_mem(m.symtab + (size_t)si * sizeof(ElfW(Sym)), &s, sizeof(s))) {
                char nbuf[96] = {0};
                if (safe_read_mem_n(m.strtab + s.st_name, nbuf, sizeof(nbuf) - 1) > 0) sym = nbuf;
            }
        }
        if (kind == TARGET_APP_HOOK) { c->own += std::string(" ") + modb + ":" + sym + "->" + where; continue; }
        char line[256];
        snprintf(line, sizeof(line), "  %s: %s -> %llx ", modb, sym.c_str(), (unsigned long long)target);
        if (kind == TARGET_UNTRACED) { if (c->untraced++ < 64) c->untraced_detail += line + where + "\n"; continue; }
        c->hits++;
        c->detail += line + where + "\n";
        if (c->hits >= 64) break;
    }
}

}

NativeResult check_got_plt_integrity() {
    NativeResult r;
    if (!maps_available()) return {STATUS_INCONCLUSIVE, "process memory map unavailable (empty /proc/self/maps snapshot); cannot judge"};
    find_vdso();
    Ctx c;
    uint32_t probe;
    if (!safe_read_mem((uintptr_t)&check_got_plt_integrity, &probe, sizeof(probe))) {
        r.status = STATUS_INCONCLUSIVE; r.details = "self-memory read unavailable";
        return r;
    }
    Walk w;
    find_mods(w);
    c.modules = w.modules;
    for (const Mod& m : w.mods) {
        if (c.hits >= 64) break;
        scan(w, m, &c);
    }
    if (c.checked == 0) {
        r.status = STATUS_INCONCLUSIVE;
        char h[96]; snprintf(h, sizeof(h), "no GOT/PLT slot could be read (modules=%d)", c.modules);
        r.details = h;
        return r;
    }

    char head[96];
    snprintf(head, sizeof(head), "checked=%d hits=%d\n", c.checked, c.hits);
    if (c.hits == 0 && c.untraced > 0) {
        r.status = STATUS_INCONCLUSIVE;
        r.details = std::string("could not verify: ") + head + "untraced=" + std::to_string(c.untraced) +
                    ", GOT/PLT target(s) in unnamed code not traced to the code that placed them:\n" + c.untraced_detail;
        return r;
    }
    r.status = c.hits > 0 ? STATUS_DETECTED : STATUS_CLEAN;
    r.details = std::string(head) + (c.hits ? c.detail + c.untraced_detail : "no GOT/PLT target outside a file-backed module (own lib+libc+libart)" +
                (c.own.empty() ? std::string() : "; hooked by the app's own library:" + c.own));

    return r;
}

    { "openat",         nullptr },
    { "read",           nullptr },

struct ByteCheck {
    const char* sym;
    uint32_t insn;
    uintptr_t addr;
    bool read_ok;
    bool is_trampoline;
    bool stock;
};

static const std::vector<uintptr_t>& hook_addrs() {
    static const std::vector<uintptr_t> addrs = [] {
        std::vector<uintptr_t> a;
        for (const auto* t = HOOK_TARGETS; t->sym; ++t) a.push_back((uintptr_t)dlsym(RTLD_DEFAULT, t->sym));
        return a;
    }();
    return addrs;
}

static ByteCheck read_hook_bytes(const char* sym, uintptr_t addr) {
    ByteCheck r{};
    r.sym = sym;
    if (!addr) return r;
    r.addr = addr;

    uint32_t w[4];
    if (safe_read_mem_n(r.addr, w, sizeof(w)) != (ssize_t)sizeof(w)) return r;
    r.read_ok = true;
    r.insn = w[0];
    r.is_trampoline = (w[0] == FRIDA_TRAMPOLINE_INSN);
    if (r.is_trampoline) {
        uint32_t disk[4];
        size_t dn = read_disk_bytes_for_addr(r.addr, disk, sizeof(disk));
        r.stock = (dn >= sizeof(disk) && memcmp(w, disk, sizeof(disk)) == 0);
    }
    return r;
}

NativeResult check_hook_bytes() {
    std::ostringstream d;
    std::ostringstream u;
    std::string own;
    int readable = 0, hooked = 0, untraced = 0;
    const auto& addrs = hook_addrs();
    for (size_t i = 0; HOOK_TARGETS[i].sym; ++i) {
        auto c = read_hook_bytes(HOOK_TARGETS[i].sym, addrs[i]);
        if (!c.read_ok) continue;
        readable++;
        if (c.is_trampoline && !c.stock) {
            std::string where;
            HookOwner owner = hook_owner(c.addr, where);
            if (owner == HOOK_APP_OWN) { own += std::string(" ") + c.sym + "->" + where; continue; }
            // Not traced to any library: a hook, but not proof of who placed it.
            std::ostringstream& out = owner == HOOK_UNRESOLVED ? u : d;
            (owner == HOOK_UNRESOLVED ? untraced : hooked)++;
            out << "  " << c.sym << "() @0x" << std::hex << c.addr
                << " insn0=0x" << c.insn << " (LDR X16,[PC,#8] trampoline, differs from on-disk library), lands in " << where << "\n";
        }
    }
    if (readable == 0) return {STATUS_INCONCLUSIVE, "no watched function readable (self-memory read failed)"};
    if (hooked == 0 && untraced > 0)
        return {STATUS_INCONCLUSIVE, "could not verify: " + std::to_string(untraced) +
                                     " hooked function(s), not traced to the code that placed the hook:\n" + u.str()};
    if (hooked == 0)
        return {STATUS_CLEAN, "no ARM64 trampoline (LDR X16,[PC,#8] = 0x58000050) differing from the on-disk library (readable=" + std::to_string(readable) + ")" +
                              (own.empty() ? "" : "; hooked by the app's own library:" + own)};
    return {STATUS_DETECTED, std::to_string(hooked) + " hooked function(s):\n" + d.str() + u.str()};
}

namespace {

const size_t MAX_HOPS = 16;
const size_t HOP_INSNS = 128;

int64_t sext(uint64_t v, int bits) { return (int64_t)(v << (64 - bits)) >> (64 - bits); }

std::string lower(std::string s) {
    for (auto& c : s) c = (char)tolower((unsigned char)c);
    return s;
}

// The kernel's page-size compat (pgsize_migration.c, init_pad_vma) prints the padding at the end of a
// library segment as its own "[page size compat]" line, always "---p" whatever its real access. It is
// still memory of the segment printed before it, and a hooker can write an island there (ShadowHook
// does, in libc's padding on the Nothing Phone 2a). Returns that segment, or nullptr.
const char* const PAD_NAME = "[page size compat]";

const VmaEntry* padded_segment(const VmaEntry* pad) {
    for (int i = 0; i < 4 && pad && pad->path == PAD_NAME; i++) {
        const VmaEntry* prev = nullptr;
        for (const auto& v : g_maps)
            if (v.end == pad->start) { prev = &v; break; }
        pad = prev;
    }
    return pad && pad->path != PAD_NAME ? pad : nullptr;
}

bool is_system(const std::string& p) {
    for (const char* r : {"/system/", "/apex/", "/vendor/", "/product/", "/system_ext/", "/odm/"})
        if (p.rfind(r, 0) == 0) return true;
    return false;
}

// Code of this app: its APK files and the native libraries unpacked from them, which live under the
// install folder /data/app/.../<package>-<id>/ (or /mnt/expand/.../<package>-<id>/). These are exactly
// the files TAMPER_APK_CONTENT matches against the developer's signature, so a hook that lands in them
// is the developer's own code. The private data folder (/data/data/<package>/,
// /data/user[_de]/<n>/<package>/) is NOT trusted: the app can write there while it runs, so a library
// there is not proven to come from the signed APK. An abuser with root could drop a renamed Frida agent
// into it and pass every hook check, so a hook landing there must still read foreign.
bool is_app_own(const std::string& p) {
    if (g_own_package.empty()) return false;
    return (p.rfind("/data/app/", 0) == 0 || p.rfind("/mnt/expand/", 0) == 0)
        && p.find("/" + g_own_package + "-") != std::string::npos;
}

// DT_SONAME of the library whose ELF header is mapped at `base`, read from memory.
std::string soname_at(uintptr_t base) {
    ElfW(Ehdr) eh;
    if (!safe_read_mem(base, &eh, sizeof(eh)) || memcmp(eh.e_ident, ELFMAG, SELFMAG) != 0) return "";
    uintptr_t bias = 0, dyn = 0;
    bool first = true;
    for (int i = 0; i < eh.e_phnum && i < 64; i++) {
        ElfW(Phdr) ph;
        if (!safe_read_mem(base + eh.e_phoff + i * sizeof(ph), &ph, sizeof(ph))) return "";
        if (ph.p_type == PT_LOAD && first) { bias = base - (ph.p_vaddr & ~(uintptr_t)0xFFF); first = false; }
        if (ph.p_type == PT_DYNAMIC) dyn = ph.p_vaddr;
    }
    if (!dyn) return "";
    uintptr_t strtab = 0, name = 0;
    bool named = false;
    for (int i = 0; i < 512; i++) {
        ElfW(Dyn) d;
        if (!safe_read_mem(bias + dyn + i * sizeof(d), &d, sizeof(d)) || d.d_tag == DT_NULL) break;
        if (d.d_tag == DT_STRTAB) strtab = d.d_un.d_ptr;
        if (d.d_tag == DT_SONAME) { name = d.d_un.d_val; named = true; }
    }
    char buf[96] = {};
    if (!strtab || !named || safe_read_mem_n(bias + strtab + name, buf, sizeof(buf) - 1) <= 0) return "";
    return buf;
}

// Frida Gadget keeps the SONAME libfrida-gadget-raw.so even when its file is renamed. The ELF header is
// found in the memory map, not with dladdr(), which waits for the loader's lock.
bool frida_lib(const VmaEntry* v, std::string& name) {
    std::string so;
    for (size_t j = (size_t)(v - g_maps.data()) + 1; j-- > 0 && g_maps[j].path == v->path;) {
        uint32_t magic;
        if (safe_read_mem(g_maps[j].start, &magic, sizeof(magic)) && memcmp(&magic, ELFMAG, SELFMAG) == 0) { so = soname_at(g_maps[j].start); break; }
    }
    const std::string& file = v->path;
    name = so.empty() ? file.substr(file.rfind('/') + 1) : so;
    return lower(so).find("frida") != std::string::npos || lower(file).find("frida") != std::string::npos;
}

// Code addresses the instructions at `pc` branch to or load (B/BL, LDR literal, ADRP+ADD/LDR/BR/RET),
// up to the first B, BR or RET.
void next_hops(uintptr_t pc, std::vector<uintptr_t>& out) {
    uint32_t w[HOP_INSNS];
    ssize_t n = safe_read_mem_n(pc, w, sizeof(w)) / 4;
    for (ssize_t i = 0; i < n; i++) {
        uint32_t x = w[i];
        uintptr_t p = pc + (uintptr_t)i * 4;
        uint64_t v;
        if ((x & 0x7C000000u) == 0x14000000u) {
            out.push_back(p + sext(x & 0x3FFFFFFu, 26) * 4);
            if (!(x & 0x80000000u)) return;
        } else if ((x & 0xFF000000u) == 0x58000000u) {
            if (safe_read_mem(p + sext((x >> 5) & 0x7FFFFu, 19) * 4, &v, sizeof(v))) out.push_back(v);
        } else if ((x & 0x9F000000u) == 0x90000000u && i + 1 < n) {
            uint64_t page = (p & ~(uintptr_t)0xFFF) + sext((((x >> 5) & 0x7FFFFu) << 2) | ((x >> 29) & 3), 21) * 4096;
            uint32_t y = w[i + 1], rd = x & 31;
            if (((y >> 5) & 31) != rd) continue;
            if ((y & 0xFFC00000u) == 0x91000000u) out.push_back(page + ((y >> 10) & 0xFFF));
            else if ((y & 0xFFC00000u) == 0xF9400000u && safe_read_mem(page + ((y >> 10) & 0xFFF) * 8, &v, sizeof(v))) out.push_back(v);
            else if ((y & 0xFFFFFC1Fu) == 0xD61F0000u || (y & 0xFFFFFC1Fu) == 0xD65F0000u) out.push_back(page);
        } else if ((x & 0xFFFFFC1Fu) == 0xD61F0000u || (x & 0xFFFFFC1Fu) == 0xD65F0000u) {
            return;
        }
    }
}

}

HookOwner hook_owner(uintptr_t addr, std::string& where) {
    std::vector<uintptr_t> todo{addr}, seen;
    std::string own, trace;
    for (size_t k = 0; k < todo.size() && seen.size() < MAX_HOPS; k++) {
        uintptr_t a = todo[k];
        if (std::find(seen.begin(), seen.end(), a) != seen.end()) continue;
        seen.push_back(a);
        const VmaEntry* v = vma_for(a);
        if (seen.size() <= 6) {
            uint32_t w[4] = {};
            safe_read_mem_n(a, w, sizeof(w));
            char t[160];
            snprintf(t, sizeof(t), " %llx[%s %s]%08x.%08x.%08x.%08x", (unsigned long long)a, v ? v->perms : "-",
                     v ? v->path.substr(0, 40).c_str() : "unmapped", w[0], w[1], w[2], w[3]);
            trace += t;
        }
        // A padding line's real access is not shown; a branch only lands there if it runs.
        bool pad = v && v->path == PAD_NAME;
        if (pad) v = padded_segment(v);
        if (!v || (!pad && !v->executable())) continue;
        if (k > 0 && !v->anonymous()) {
            if (is_system(v->path)) {
                // Code that differs from the library file was written there by a hooker (an island in
                // the library's own pages or its padding): follow it like generated code. Unchanged
                // code is a landing.
                uint32_t mem[4], disk[4];
                if (!pad && safe_read_mem(a, mem, sizeof(mem)) && read_disk_bytes_for_addr(a, disk, sizeof(disk)) == sizeof(disk) &&
                    memcmp(mem, disk, sizeof(mem)) == 0) continue;
            } else {
                std::string name;
                bool frida = frida_lib(v, name);
                if (is_app_own(v->path) && !frida) { if (own.empty()) own = name; continue; }
                where = frida ? "Frida library " + name + " (" + v->path + ")" : v->path;
                return HOOK_FOREIGN;
            }
        }
        next_hops(a, todo);
    }
    if (!own.empty()) { where = own; return HOOK_APP_OWN; }
    where = "no library code reached; hops:" + trace;
    return HOOK_UNRESOLVED;
}

#endif

                env->DeleteLocalRef(id);
            }
            if (env->ExceptionCheck()) env->ExceptionClear();
        }
        long t0 = now_us();
        NativeResult r = c.fn();
        long us = now_us() - t0;
        if (json.size() > 1) json += ",";
        json += std::string("{\"id\":\"") + c.id + "\",\"group\":\"" + c.group +
                "\",\"status\":" + std::to_string(r.status) +
                ",\"us\":" + std::to_string(us) + ",\"details\":\"" + json_escape(r.details) + "\"}";
    }
    json += "]";
    mem_run_end();
    return env->NewStringUTF(json.c_str());
}

#include "memory_libs.h"
#include <cstdint>
#include <cstring>
#include <cstdio>
#include <string>
#include <elf.h>
#include <link.h>
#include <unistd.h>

namespace {

// Frida's agent library (libfrida-agent-raw.so, which frida-server loads into the app from a memfd)
// exports this entry point, and Frida's loader finds the agent by it. Only Frida's agent exports it.
// A build that renames it (Florida exports `main`) or a gadget (it exports nothing) gets past this
// check: a miss is allowed, a false alarm is not.
const char kAgentEntry[] = "frida_agent_main";

#if defined(__LP64__)
const unsigned char kOwnClass = ELFCLASS64;
#else
const unsigned char kOwnClass = ELFCLASS32;
#endif

enum Lookup { NOT_FOUND, FOUND, UNREADABLE };

// Names the system gives its own memory: ART's JIT cache and heaps, the linker's and the allocator's
// memory, thread stacks. None of these regions holds a library image. Florida and its builds, Rusda,
// strongR-frida and FreeDaah load their agent from a memfd named jit-cache, phantom-frida from one
// named jit-code-cache.
// [vdso] is not in the list: it is the kernel's own library.
const char* const kSystemNames[] = {"jit-cache", "code-cache", "dalvik", ".art", "linker_alloc", "scudo", "stack"};

const char* system_name(const std::string& p) {
    for (const char* n : kSystemNames)
        if (p.find(n) != std::string::npos) return n;
    return nullptr;
}

// Memory with no file behind it: anonymous, [anon:<name>], or a memfd (a file that lives only in memory).
bool memory_only(const std::string& p) {
    return p.empty() || p[0] == '[' || p.find("memfd:") != std::string::npos;
}

bool is_candidate_region(const VmaEntry& v) {
    return memory_only(v.path) && !system_name(v.path) && v.path.find("vdso") == std::string::npos;
}

template <typename T> bool rd(uintptr_t a, T& out) { return safe_read_mem(a, &out, sizeof(out)); }

// One library image in memory, located from its own ELF header. Every address the lookup reads
// must fall inside the image, so the name can only come from this library's own tables.
struct Image {
    uintptr_t bias = 0, lo = 0, hi = 0;
    uintptr_t strtab = 0, symtab = 0, gnu_hash = 0, hash = 0;
    uint64_t strsz = 0;
    bool inside(uintptr_t a, uint64_t len) const { return a >= lo && a < hi && len <= hi - a; }
    uintptr_t at(ElfW(Addr) p) const { return p < bias ? bias + p : p; }
};

Lookup check_sym(const Image& im, uint32_t idx) {
    ElfW(Sym) s;
    uintptr_t a = im.symtab + (uintptr_t)idx * sizeof(s);
    if (!im.inside(a, sizeof(s)) || !rd(a, s)) return UNREADABLE;
    if (s.st_name >= im.strsz) return UNREADABLE;
    char name[sizeof(kAgentEntry)];
    ssize_t n = safe_read_mem_n(im.strtab + s.st_name, name, sizeof(name));
    if (n <= 0) return UNREADABLE;
    if (memcmp(name, kAgentEntry, (size_t)n) != 0) return NOT_FOUND;
    if ((size_t)n < sizeof(name)) return UNREADABLE;
    unsigned bind = s.st_info >> 4;
    bool exported = s.st_shndx != SHN_UNDEF && (bind == STB_GLOBAL || bind == STB_WEAK);
    return exported ? FOUND : NOT_FOUND;
}

// The same lookup the dynamic linker runs for dlsym(): a name the linker can export is found here.
Lookup gnu_lookup(const Image& im) {
    uint32_t hdr[4];
    if (!im.inside(im.gnu_hash, sizeof(hdr)) || !safe_read_mem(im.gnu_hash, hdr, sizeof(hdr))) return UNREADABLE;
    uint32_t nbuckets = hdr[0], symoffset = hdr[1];
    if (nbuckets == 0) return NOT_FOUND;
    uint32_t h = 5381;
    for (const char* c = kAgentEntry; *c; c++) h = h * 33 + (uint8_t)*c;
    uintptr_t buckets = im.gnu_hash + sizeof(hdr) + (uintptr_t)hdr[2] * sizeof(ElfW(Addr));
    uintptr_t chain = buckets + (uintptr_t)nbuckets * 4;
    uint32_t idx;
    uintptr_t b = buckets + (uintptr_t)(h % nbuckets) * 4;
    if (!im.inside(b, 4) || !rd(b, idx)) return UNREADABLE;
    if (idx < symoffset) return NOT_FOUND;
    for (int guard = 0; guard < 65536; guard++, idx++) {
        uint32_t ch;
        uintptr_t c = chain + (uintptr_t)(idx - symoffset) * 4;
        if (!im.inside(c, 4) || !rd(c, ch)) return UNREADABLE;
        if ((ch | 1) == (h | 1)) {
            Lookup r = check_sym(im, idx);
            if (r != NOT_FOUND) return r;
        }
        if (ch & 1) return NOT_FOUND;
    }
    return UNREADABLE;
}

Lookup sysv_lookup(const Image& im) {
    uint32_t hdr[2];
    if (!im.inside(im.hash, sizeof(hdr)) || !safe_read_mem(im.hash, hdr, sizeof(hdr))) return UNREADABLE;
    uint32_t nbucket = hdr[0], nchain = hdr[1];
    if (nbucket == 0) return NOT_FOUND;
    uint32_t h = 0;
    for (const char* c = kAgentEntry; *c; c++) {
        h = (h << 4) + (uint8_t)*c;
        uint32_t g = h & 0xf0000000u;
        if (g) h ^= g >> 24;
        h &= ~g;
    }
    uintptr_t bucket = im.hash + sizeof(hdr), chain = bucket + (uintptr_t)nbucket * 4;
    uint32_t idx;
    uintptr_t b = bucket + (uintptr_t)(h % nbucket) * 4;
    if (!im.inside(b, 4) || !rd(b, idx)) return UNREADABLE;
    for (int guard = 0; idx != 0 && guard < 65536; guard++) {
        if (idx >= nchain) return UNREADABLE;
        Lookup r = check_sym(im, idx);
        if (r != NOT_FOUND) return r;
        uintptr_t c = chain + (uintptr_t)idx * 4;
        if (!im.inside(c, 4) || !rd(c, idx)) return UNREADABLE;
    }
    return idx == 0 ? NOT_FOUND : UNREADABLE;
}

// Called for a region that starts with an ELF header of this process's class. FOUND means it is a
// library image laid out the way the linker loads one; `im` then holds its bounds and `dyn` its
// dynamic table's program header.
Lookup library_image(const VmaEntry& v, const ElfW(Ehdr)& eh, Image& im, ElfW(Phdr)& dyn) {
    if (eh.e_phentsize != sizeof(ElfW(Phdr)) || eh.e_phnum == 0 || eh.e_phnum > 128) return NOT_FOUND;
    if (eh.e_phoff + (uint64_t)eh.e_phnum * sizeof(ElfW(Phdr)) > v.size()) return NOT_FOUND;
    ElfW(Phdr) ph[128];
    if (!safe_read_mem((uintptr_t)(v.start + eh.e_phoff), ph, eh.e_phnum * sizeof(ElfW(Phdr)))) return UNREADABLE;

    const ElfW(Phdr)* first = nullptr;
    const ElfW(Phdr)* d = nullptr;
    uint64_t end = 0;
    for (unsigned i = 0; i < eh.e_phnum; i++) {
        if (ph[i].p_type == PT_DYNAMIC) d = &ph[i];
        if (ph[i].p_type != PT_LOAD) continue;
        if (!first) first = &ph[i];
        if ((uint64_t)ph[i].p_vaddr + ph[i].p_memsz > end) end = (uint64_t)ph[i].p_vaddr + ph[i].p_memsz;
    }
    // No dynamic table means no exports. The header must sit at the start of the first loaded
    // segment, as it does in every library the linker loads.
    if (!d || !first || first->p_offset != 0) return NOT_FOUND;

    uintptr_t page = (uintptr_t)getpagesize();
    uintptr_t base = (uintptr_t)first->p_vaddr & ~(page - 1);
    if (v.start < base) return NOT_FOUND;
    im.bias = (uintptr_t)v.start - base;
    im.lo = (uintptr_t)v.start;
    im.hi = im.bias + (uintptr_t)end;
    if (im.hi <= im.lo) return NOT_FOUND;
    dyn = *d;
    return FOUND;
}

Lookup agent_exported(Image& im, const ElfW(Phdr)& dyn) {
    ElfW(Dyn) d[256];
    uintptr_t da = im.bias + (uintptr_t)dyn.p_vaddr;
    size_t want = dyn.p_memsz < sizeof(d) ? (size_t)dyn.p_memsz : sizeof(d);
    if (!im.inside(da, want)) return UNREADABLE;
    ssize_t got = safe_read_mem_n(da, d, want);
    if (got < (ssize_t)sizeof(ElfW(Dyn))) return UNREADABLE;
    for (size_t i = 0; i < (size_t)got / sizeof(ElfW(Dyn)) && d[i].d_tag != DT_NULL; i++) {
        switch (d[i].d_tag) {
            case DT_STRTAB:   im.strtab   = im.at(d[i].d_un.d_ptr); break;
            case DT_SYMTAB:   im.symtab   = im.at(d[i].d_un.d_ptr); break;
            case DT_STRSZ:    im.strsz    = d[i].d_un.d_val; break;
            case DT_GNU_HASH: im.gnu_hash = im.at(d[i].d_un.d_ptr); break;
            case DT_HASH:     im.hash     = im.at(d[i].d_un.d_ptr); break;
        }
    }
    if (!im.strtab || !im.symtab || (!im.gnu_hash && !im.hash)) return NOT_FOUND;
    if (!im.inside(im.strtab, im.strsz)) return UNREADABLE;
    return im.gnu_hash ? gnu_lookup(im) : sysv_lookup(im);
}

std::string region_line(const VmaEntry& v) {
    char line[320];
    snprintf(line, sizeof(line), "  %llx-%llx %s %s\n", (unsigned long long)v.start,
             (unsigned long long)v.end, v.perms, v.path.empty() ? "[anon]" : v.path.c_str());
    return line;
}

// Another thread can unmap or replace a region after the run's map snapshot. An unreadable region counts
// only if a fresh map still shows it unchanged, or if the fresh map cannot be read.
bool still_mapped(const VmaEntry& v, std::vector<VmaEntry>& fresh) {
    if (fresh.empty()) fresh = read_maps();
    if (fresh.empty()) return true;
    for (const auto& f : fresh)
        if (f.start == v.start && f.end == v.end && strcmp(f.perms, v.perms) == 0 && f.path == v.path) return true;
    return false;
}

// An empty map or a failed read of our own code means the walk would see nothing: never CLEAN.
const char* cannot_judge(const void* own_code) {
    if (!maps_available()) return "process memory map unavailable (empty /proc/self/maps snapshot); cannot judge";
    uint32_t probe;
    if (!safe_read_mem((uintptr_t)own_code, &probe, sizeof(probe))) return "self-memory read unavailable";
    return nullptr;
}

NativeResult check_frida_agent_in_memory() {
    if (const char* why = cannot_judge((const void*)&check_frida_agent_in_memory)) return {STATUS_INCONCLUSIVE, why};

    int images = 0, unreadable = 0, vanished = 0;
    std::string unread;
    std::vector<VmaEntry> fresh;
    // A small library can map its first file page twice (code, then read-only data), so its header
    // shows at the start of two regions. Regions inside an image already read belong to it.
    uintptr_t image_hi = 0;
    for (const auto& v : g_maps) {
        if (v.start < image_hi) continue;
        if (!v.readable() || !is_candidate_region(v) || is_own_vma(v.path)) continue;
        ElfW(Ehdr) eh;
        if (v.size() < sizeof(eh) || !rd((uintptr_t)v.start, eh)) continue;
        if (memcmp(eh.e_ident, ELFMAG, SELFMAG) != 0 || eh.e_ident[EI_CLASS] != kOwnClass) continue;
        images++;
        Image im;
        ElfW(Phdr) dyn;
        Lookup r = library_image(v, eh, im, dyn);
        if (r == FOUND) {
            image_hi = im.hi;
            r = agent_exported(im, dyn);
        }
        switch (r) {
            case FOUND:
                return {STATUS_DETECTED, std::string("library loaded from memory exports Frida's agent entry ") +
                                         kAgentEntry + ":\n" + region_line(v)};
            case UNREADABLE:
                if (!still_mapped(v, fresh)) { vanished++; break; }
                if (++unreadable <= 4) unread += region_line(v);
                break;
            case NOT_FOUND:
                break;
        }
    }
    if (unreadable > 0)
        return {STATUS_INCONCLUSIVE, "export table unreadable for " + std::to_string(unreadable) +
                                     " library image(s) in unnamed memory:\n" + unread};
    return {STATUS_CLEAN, std::to_string(images) + " library image(s) in unnamed memory; none exports " + kAgentEntry +
                          (vanished ? "; " + std::to_string(vanished) + " unmapped during the scan" : "")};
}

    return {STATUS_CLEAN, std::to_string(regions) + " memfd region(s) named as the system's own memory; none holds a library image" +

bool b_escapes_module(const uint32_t* w, uintptr_t p) {
    int32_t imm = (int32_t)(w[0] << 6) >> 6;
    uint64_t target = p + (int64_t)imm * 4;
    const VmaEntry* src = vma_for(p);
    const VmaEntry* dst = vma_for(target);
    if (!src) return false;
    return dst != src;
}

const char* classify(const uint32_t* w, uintptr_t p) {
    if (is_brk(w[0])) return "BRK/breakpoint at entry";
    if (is_br(w[0]))  return "indirect-branch (BR/RET) trampoline at entry";
    if (is_b(w[0]) && b_escapes_module(w, p)) return "direct-branch (B) escaping module";
    if (is_ldr_lit(w[0]) && (is_br(w[1]) || is_br(w[2]))) return "literal-load + BR/RET trampoline";
    if (is_adrp(w[0]) && (is_br(w[1]) || is_br(w[2]))) return "ADRP + BR/RET trampoline";
    return nullptr;
}

NativeResult check_opcode_trampoline() {
    static const std::vector<void*> addrs = [] {
        std::vector<void*> a;
        for (const char* const* s = SENSITIVE_FNS; *s; ++s) a.push_back(dlsym(RTLD_DEFAULT, *s));
        return a;
    }();
    NativeResult r;
    int resolved = 0, readable = 0, hooked = 0, untraced = 0;
    std::string detail, own, untraced_detail;
    for (size_t i = 0; SENSITIVE_FNS[i]; ++i) {
        const char* const* s = &SENSITIVE_FNS[i];
        void* p = addrs[i];
        if (!p) continue;
        resolved++;
        uint32_t w[6];
        if (safe_read_mem_n((uintptr_t)p, w, sizeof(w)) != (ssize_t)sizeof(w)) continue;
        readable++;
        int bi = is_landing_pad(w[0]) ? 1 : 0;
        const char* why = classify(w + bi, (uintptr_t)p + (uintptr_t)bi * 4);
        if (!why) continue;
        uint32_t disk[6];
        size_t need = (size_t)(bi + 3) * 4;
        size_t dn = read_disk_bytes_for_addr((uintptr_t)p, disk, sizeof(disk));
        if (dn >= need && memcmp(w, disk, need) == 0) continue;
        std::string where;
        HookOwner owner = hook_owner((uintptr_t)p + (uintptr_t)bi * 4, where);
        if (owner == HOOK_APP_OWN) {
            own += std::string(" ") + *s + "->" + where;
            continue;
        }
        const VmaEntry* v = vma_for((uintptr_t)p);
        bool filebacked = v && !v->path.empty() && v->path[0] != '[' && v->path.find("memfd:") == std::string::npos;
        char line[256];
        snprintf(line, sizeof(line), "  %s @%p insn0=0x%08x: %s (%s), lands in ", *s, p, w[bi], why,
                 filebacked ? "differs from on-disk library" : "code not backed by a file");
        // A hook the follower cannot trace to any library proves a hook, not who placed it.
        if (owner == HOOK_UNRESOLVED) { untraced++; untraced_detail += line + where + "\n"; continue; }
        hooked++;
        detail += line + where + "\n";
    }

    std::string raw = "resolved=" + std::to_string(resolved) +
                      " readable=" + std::to_string(readable) +
                      " hooked=" + std::to_string(hooked) +
                      " untraced=" + std::to_string(untraced);
    if (readable == 0) {
        r.status = STATUS_INCONCLUSIVE;
        r.details = "self-memory read failed on all watched fns (" + raw + ")";
    } else if (hooked > 0) {
        r.status = STATUS_DETECTED;
        r.details = raw + "\n" + detail + untraced_detail;
    } else if (untraced > 0) {
        r.status = STATUS_INCONCLUSIVE;
        r.details = "could not verify: hooked, but not traced to the code that placed the hook (" + raw + ")\n" + untraced_detail;
    } else {
        r.status = STATUS_CLEAN;
        r.details = "no entry-prologue trampoline differing from the on-disk library (" + raw + ")" +
                    (own.empty() ? "" : "; hooked by the app's own library:" + own);
    }

    return r;
}

// Zygisk loaders map every enabled module into every app, and ReZygisk keeps any module that does

    return p.rfind(kModulesDir, 0) == 0 && e != std::string::npos ? p.substr(b, e - b) : std::string();
}

    for (const char* m : kTargetingModules)
        if (id == m) return true;
    return false;
}

NativeResult check_lib_from_root_path() {
    NativeResult r;
    if (!maps_available()) return {STATUS_INCONCLUSIVE, "process memory map unavailable (empty /proc/self/maps snapshot); cannot judge"};
    int hits = 0;
    std::string detail, present;
    for (const auto& v : g_maps) {
        if (!v.executable()) continue;
        const std::string& p = v.path;
        if (p.empty() || p[0] == '[') continue;
        if (is_own_vma(p)) continue;
        bool tmp = p.find("/data/local/tmp/") != std::string::npos;
        if (!tmp && p.rfind("/data/adb/", 0) != 0) continue;

            continue;
        }
        hits++;

                 (unsigned long long)v.start, (unsigned long long)v.end, v.perms, p.c_str());
        detail += line;
        if (hits >= 32) break;
    }

    r.status = hits > 0 ? STATUS_DETECTED : STATUS_CLEAN;
    r.details = hits > 0 ? std::string("exec lib(s) from root/temp path:\n") + detail
                         : "no exec lib mapped from /data/adb or /data/local/tmp";
    if (!present.empty()) r.details += "\nnot counted, root modules loaded into every app:" + present;

    return r;
}

bool raw_pread(int fd, void* buf, size_t len, int64_t off){
    uint8_t* p=(uint8_t*)buf; size_t got=0;
    while(got<len){
        int64_t at=off+(int64_t)got;
#if defined(__arm__)  // ARM EABI passes a 64-bit syscall argument in an even register pair: pad one word
        long n=syscall(__NR_pread64, fd, p+got, len-got, 0, (uint32_t)at, (uint32_t)((uint64_t)at>>32));
#else
        long n=syscall(__NR_pread64, fd, p+got, len-got, at);
#endif
        if(n<=0) return false; got+=(size_t)n;
    }
    return true;
}

bool rd_u32(const std::string& b,size_t off,uint32_t& v){
    if(off+4>b.size()) return false;
    const uint8_t* p=(const uint8_t*)b.data()+off;
    v=(uint32_t)p[0]|((uint32_t)p[1]<<8)|((uint32_t)p[2]<<16)|((uint32_t)p[3]<<24); return true;
}
bool rd_u64(const std::string& b,size_t off,uint64_t& v){
    if(off+8>b.size()) return false;
    const uint8_t* p=(const uint8_t*)b.data()+off; v=0;
    for(int i=0;i<8;i++) v|=((uint64_t)p[i])<<(8*i); return true;
}

bool installer_path(const std::string& p){
    if(p.compare(0,10,"/data/app/")==0) return true;
    size_t u=p.find('/',12);
    return p.compare(0,12,"/mnt/expand/")==0 && u!=std::string::npos && p.compare(u,5,"/app/")==0;
}

bool fits(size_t off, uint64_t len, size_t end){ return off<=end && len<=end-off; }

void entry_certs(const std::string& val, std::vector<std::string>& out){
    uint32_t u;
    if(!rd_u32(val,0,u) || !fits(4,u,val.size())) return;
    size_t q=4, end=4+(size_t)u;
    while(fits(q,4,end)){
        if(!rd_u32(val,q,u) || !fits(q+4,u,end)) return;
        size_t s=q+4, s_end=s+u; q=s_end;
        if(!rd_u32(val,s,u) || !fits(s+4,u,s_end)) return;
        size_t sd=s+4, sd_end=sd+u;
        if(!rd_u32(val,sd,u) || !fits(sd+4,u,sd_end)) return;
        size_t c=sd+4+u; uint32_t c0;
        if(!fits(c,8,sd_end) || !rd_u32(val,c+4,c0) || !fits(c+8,c0,sd_end)) return;
        out.push_back(sha256_hex((const uint8_t*)val.data()+c+8, c0));
    }
}

std::string own_apk_path(const std::vector<VmaEntry>& maps, const std::string& pkg){
    const std::string seg="/"+pkg+"-", base="/base.apk";
    if(pkg.empty()) return "";
    for(const auto& v : maps)
        if(v.path.size()>base.size() && v.path.compare(v.path.size()-base.size(),base.size(),base)==0 &&
           installer_path(v.path) && v.path.find(seg)!=std::string::npos) return v.path;
    return "";
}

struct Signer { std::vector<std::string> certs; std::string err; bool v1_only = false; };

static Signer parse_own_signer(){
    Signer s;
    std::string apk=own_apk_path(g_maps, g_own_package);
    if(apk.empty()){ s.err="installed base.apk not found among the app's mapped files"; return s; }

    int fd=raw_open(apk.c_str());
    if(fd<0){ s.err="open(base.apk) failed - cannot judge"; return s; }
    int64_t fsz=raw_size(fd);
    if(fsz<22){ raw_close(fd); s.err="apk too small - cannot judge"; return s; }

    size_t tail = (size_t)(fsz < 65557 ? fsz : 65557);
    std::string buf; buf.resize(tail);
    if(!raw_pread(fd, &buf[0], tail, fsz-(int64_t)tail)){ raw_close(fd); s.err="tail read failed"; return s; }
    long eocd=-1;
    for(long i=(long)tail-22;i>=0;i--)
        if((uint8_t)buf[i]==0x50&&(uint8_t)buf[i+1]==0x4b&&(uint8_t)buf[i+2]==0x05&&(uint8_t)buf[i+3]==0x06 &&
           (size_t)i+22+((uint8_t)buf[i+20]|((size_t)(uint8_t)buf[i+21]<<8))==tail){ eocd=i; break; }
    if(eocd<0){ raw_close(fd); s.err="no ZIP end record - not judging"; return s; }
    uint32_t cd_off, cd_size; rd_u32(buf,(size_t)eocd+16,cd_off); rd_u32(buf,(size_t)eocd+12,cd_size);
    if((uint64_t)cd_off+cd_size!=(uint64_t)(fsz-(int64_t)tail+eocd) || cd_off<32){ raw_close(fd); s.err="unexpected ZIP layout - not judging"; return s; }

    uint8_t foot[24];
    if(!raw_pread(fd, foot, 24, (int64_t)cd_off-24)){ raw_close(fd); s.err="footer read failed"; return s; }
    if(memcmp(foot+8,"APK Sig Block 42",16)!=0){ raw_close(fd); s.v1_only=true; return s; }
    uint64_t blk=0, head=0; for(int i=0;i<8;i++) blk|=((uint64_t)foot[i])<<(8*i);
    if(blk<24 || blk>16*1024*1024 || (uint64_t)cd_off<blk+8){ raw_close(fd); s.err="implausible signing-block size"; return s; }
    if(!raw_pread(fd, &head, 8, (int64_t)cd_off-(int64_t)blk-8) || head!=blk){ raw_close(fd); s.err="signing block sizes do not match"; return s; }

    int64_t pairs_off=(int64_t)cd_off-(int64_t)blk;
    size_t pairs_len=(size_t)(blk-24);
    std::string pairs; pairs.resize(pairs_len);
    if(!raw_pread(fd, &pairs[0], pairs_len, pairs_off)){ raw_close(fd); s.err="pairs read failed"; return s; }
    raw_close(fd);

    size_t pos=0;
    while(pos+12<=pairs.size()){
        uint64_t plen; if(!rd_u64(pairs,pos,plen)) break;
        if(plen<4 || !fits(pos+8,plen,pairs.size())) break;
        uint32_t id; if(!rd_u32(pairs,pos+8,id)){ break; }
        if(id==0x7109871au || id==0xf05368c0u || id==0x1b93ad61u) entry_certs(pairs.substr(pos+12,(size_t)plen-4), s.certs);
        pos+=8+(size_t)plen;
    }
    if(s.certs.empty()) s.err="no parseable v2/v3 signer cert - not judging";
    return s;
}

NativeResult check_tamper_signing_block(){
    static Signer cached;
    if(cached.certs.empty()) cached=parse_own_signer();
    if(cached.v1_only)
        return g_target_sdk>=30
            ? NativeResult{STATUS_DETECTED, "no v2/v3 signing block: the APK is signed with v1 only, which Android refuses for targetSdkVersion "+std::to_string(g_target_sdk)}
            : NativeResult{STATUS_INCONCLUSIVE, "signed with v1 only, which Android accepts below targetSdkVersion 30; this check reads only v2/v3 signers"};
    if(cached.certs.empty()) return {STATUS_INCONCLUSIVE, cached.err};
    NativeResult r;

    std::vector<std::string> expected; std::string cur;
    for(size_t i=0;i<=g_expected_signers.size();i++){
        char c = i<g_expected_signers.size() ? g_expected_signers[i] : ',';
        if(c==','){ if(!cur.empty()) expected.push_back(cur); cur.clear(); }
        else if(c!=':' && c!=' ') cur += (char)tolower((unsigned char)c);
    }
    if(expected.empty()){ r.status=STATUS_INCONCLUSIVE; r.details="no signer from Android to compare"; return r; }
    std::string listed, file;
    for(const auto& c : cached.certs){
        if(std::find(expected.begin(), expected.end(), c)!=expected.end()){
            r.status=STATUS_CLEAN; r.details="a signing entry in the file carries the signer Android reports: "+c.substr(0,16)+"..."; return r;
        }
        file += c.substr(0,16)+"... ";
    }
    for(const auto& p : expected) listed += p.substr(0,16)+"... ";
    r.status=STATUS_DETECTED; r.details="no signing entry in the file carries the signer Android reports: file="+file+"android="+listed;
    return r;
}

bool own_code(uint64_t& lo, uint64_t& hi) {
    uintptr_t hdr = (uintptr_t)&__ehdr_start;

    if (!safe_read_mem(hdr, &eh, sizeof(eh)) || eh.e_phnum == 0 || eh.e_phnum > 64) return false;

    for (int i = 0; i < eh.e_phnum && have; i++)

            lo = base + ph[i].p_vaddr;
            hi = lo + ph[i].p_memsz;
            return true;
        }
    return false;
}

constexpr uint32_t BRK_UPROBE = 0xD42000A0u;

bool ends_with(const std::string& s, const char* suf) {
    size_t n = strlen(suf);
    return s.size() >= n && s.compare(s.size() - n, n, suf) == 0;
}

bool scan_region(uint64_t start, uint64_t end, uint64_t& hit) {
    const size_t CH = 65536;
    static uint8_t buf[CH];
    uint64_t cap = start + (24u << 20);
    if (end > cap) end = cap;
    for (uint64_t off = start; off < end; ) {
        size_t want = (end - off < CH) ? (size_t)(end - off) : CH;
        ssize_t got = safe_read_mem_n(off, buf, want);
        if (got <= 0) break;
        size_t g = (size_t)got & ~3u;
        for (size_t i = 0; i + 4 <= g; i += 4) {
            uint32_t w; std::memcpy(&w, buf + i, 4);
            if (w == BRK_UPROBE) { hit = off + i; return true; }
        }
        off += want;
        if (got < (ssize_t)want) break;
    }
    return false;
}

NativeResult check_uprobe_residue() {
    NativeResult r;
    if (!maps_available()) return {STATUS_INCONCLUSIVE, "process memory map unavailable (empty /proc/self/maps snapshot); cannot judge"};
    int hits = 0;
    std::string detail;

    for (const auto& v : g_maps)
        if (v.path.find("[uprobes]") != std::string::npos) {
            hits++;
            char line[128];
            snprintf(line, sizeof(line), "  [uprobes] VMA @ %llx-%llx\n",
                     (unsigned long long)v.start, (unsigned long long)v.end);
            detail += line;
            break;
        }

    uint64_t own_lo = 0, own_hi = 0;
    if (!own_code(own_lo, own_hi)) {
        r.status = hits ? STATUS_DETECTED : STATUS_INCONCLUSIVE;
        r.details = hits ? detail : "self-memory read unavailable";
        return r;
    }

    int scanned = 0;
    for (const auto& v : g_maps) {
        if (!v.executable()) continue;
        const std::string& p = v.path;
        if (p.empty() || p[0] == '[') continue;
        uint64_t s = v.start, e = v.end;
        if (v.start < own_hi && v.end > own_lo) { s = std::max(s, own_lo); e = std::min(e, own_hi); }
        else if (!ends_with(p, "/libc.so")) continue;
        scanned++;
        uint64_t hit = 0;
        if (scan_region(s, e, hit)) {
            hits++;
            char line[192];
            snprintf(line, sizeof(line), "  BRK#0x5 @ %llx in %s\n",
                     (unsigned long long)hit, p.c_str());
            detail += line;
        }
    }

    char head[96];
    snprintf(head, sizeof(head), "regions_scanned=%d hits=%d\n", scanned, hits);
    r.status = hits > 0 ? STATUS_DETECTED : STATUS_CLEAN;
    r.details = std::string(head) + (hits ? detail : "no uprobe BRK#0x5 in own/libc .text, no [uprobes] VMA");

    return r;
}

        Alg(0x0104, "SHA512withRSA", "RSA", "SHA-512"),
        Alg(0x0202, "SHA512withECDSA", "EC", "SHA-512"),
        Alg(0x0102, "SHA512withRSA/PSS", "RSA", "SHA-512", PSSParameterSpec("SHA-512", "MGF1", MGF1ParameterSpec.SHA512, 64, 1)),
    )

    fun verify(f: FileChannel, known: Set<String>, targetSdk: Int): ApkVerdict {
        if (known.isEmpty()) return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: no signer from Android to compare")
        val (eocd, eocdOff) = endRecord(f) ?: return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: no ZIP end record")
        val cdOff = le32(eocd, 16).toLong() and 0xffffffffL
        val cdSize = le32(eocd, 12).toLong() and 0xffffffffL
        if (cdOff + cdSize != eocdOff || cdOff < 32) return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: unexpected ZIP layout")
        val foot = read(f, cdOff - 24, 24)
        if (String(foot, 8, 16, Charsets.US_ASCII) != "APK Sig Block 42") return if (targetSdk >= 30)
            ApkVerdict(Status.DETECTED, null, "no v2/v3 signing block: the APK is signed with v1 only, which Android refuses for targetSdkVersion $targetSdk")
        else ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: signed with v1 only, which Android accepts below targetSdkVersion 30; this check reads only v2/v3 signers")
        val blockSize = ByteBuffer.wrap(foot).order(ByteOrder.LITTLE_ENDIAN).long
        if (blockSize < 24 || blockSize > 16L * CHUNK || blockSize + 8 > cdOff)
            return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: implausible signing block size")
        val blockStart = cdOff - blockSize - 8
        val head = read(f, blockStart, 8)
        if (le(head).long != blockSize) return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: signing block sizes do not match")
        val pairs = read(f, blockStart + 8, (blockSize - 24).toInt())
        val blocks = try { idValues(pairs) } catch (t: RuntimeException) {
            return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: unparseable signing block")
        }
        val entries = try {
            listOf(V31 to "v3.1", V3 to "v3", V2 to "v2").flatMap { (id, scheme) -> blocks[id]?.let { entries(it, scheme, id != V2) }.orEmpty() }
        } catch (t: RuntimeException) {
            return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: unparseable signer")
        }
        if (entries.isEmpty()) return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: no v2/v3 signer")
        val e = entries.firstOrNull { it.signer in known } ?: return ApkVerdict(Status.DETECTED, entries.first().signer,
            "no signing entry in the file carries a signer Android reports: file=${entries.joinToString(",") { it.signer.take(16) }} " +
                "android=${known.joinToString(",") { it.take(16) }}")
        val (scheme, signedData, sigs, publicKey, digests, certDer, signer) = e
        val alg = algs.firstOrNull { a -> a.id in sigs }
            ?: return ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: $scheme: no supported signature algorithm")
        val key = KeyFactory.getInstance(alg.key).generatePublic(X509EncodedKeySpec(publicKey))
        val ok = Signature.getInstance(alg.jca).run {
            initVerify(key)
            alg.pss?.let { setParameter(it) }
            update(signedData)
            verify(sigs.getValue(alg.id))
        }
        if (!ok) return ApkVerdict(Status.DETECTED, signer, "$scheme: signature over the signed data is invalid")
        val cert = CertificateFactory.getInstance("X.509").generateCertificate(ByteArrayInputStream(certDer))
        if (!cert.publicKey.encoded.contentEquals(publicKey))
            return ApkVerdict(Status.DETECTED, signer, "$scheme: certificate does not carry the signing key")
        val expected = digests[alg.id] ?: return ApkVerdict(Status.INCONCLUSIVE, signer, "could not verify: $scheme: no content digest")
        val actual = contentDigest(f, alg.digest, blockStart, cdOff, eocdOff, eocd)
        if (!actual.contentEquals(expected))
            return ApkVerdict(Status.DETECTED, signer, "$scheme: file contents differ from what was signed")
        return ApkVerdict(Status.CLEAN, signer, "$scheme: contents match the signature, signer ${signer.take(16)}")
    }

    fun entryNames(f: FileChannel): List<String> {
        val (eocd, eocdOff) = requireNotNull(endRecord(f)) { "no ZIP end record" }
        val cdOff = le32(eocd, 16).toLong() and 0xffffffffL
        require(cdOff + (le32(eocd, 12).toLong() and 0xffffffffL) == eocdOff) { "unexpected ZIP layout" }
        val cd = le(read(f, cdOff, le32(eocd, 12)))
        val names = ArrayList<String>()
        while (cd.remaining() >= 46 && cd.getInt(cd.position()) == 0x02014b50) {
            val p = cd.position()
            val n = cd.getShort(p + 28).toInt() and 0xffff
            names += String(ByteArray(n).also { cd.position(p + 46); cd.get(it) }, Charsets.UTF_8)
            cd.position(p + 46 + n + (cd.getShort(p + 30).toInt() and 0xffff) + (cd.getShort(p + 32).toInt() and 0xffff))
        }
        require("AndroidManifest.xml" in names) { "no AndroidManifest.xml in the ZIP directory" }
        return names
    }

    private fun endRecord(f: FileChannel): Pair<ByteArray, Long>? {
        val size = f.size()
        val tail = read(f, size - minOf(size, 65557L), minOf(size, 65557L).toInt())
        val e = (tail.size - 22 downTo 0).firstOrNull {
            le32(tail, it) == 0x06054b50 && it + 22 + ((tail[it + 20].toInt() and 0xff) or ((tail[it + 21].toInt() and 0xff) shl 8)) == tail.size
        } ?: return null
        return tail.copyOfRange(e, tail.size) to size - tail.size + e
    }

    private data class Entry(
        val scheme: String, val signedData: ByteArray, val sigs: Map<Int, ByteArray>, val publicKey: ByteArray,
        val digests: Map<Int, ByteArray>, val cert: ByteArray, val signer: String,
    )

    private fun entries(value: ByteArray, scheme: String, v3: Boolean): List<Entry> {
        val out = ArrayList<Entry>()
        val signers = le(value).lp()
        while (signers.hasRemaining()) {
            val s = signers.lp()
            val signedData = s.lp().bytes()
            if (v3) { s.int; s.int }
            val sigs = HashMap<Int, ByteArray>()
            val ss = s.lp()
            while (ss.hasRemaining()) { val one = ss.lp(); sigs[one.int] = one.lp().bytes() }
            val publicKey = s.lp().bytes()
            val sd = le(signedData)
            val digests = HashMap<Int, ByteArray>()
            val ds = sd.lp()
            while (ds.hasRemaining()) { val d = ds.lp(); digests[d.int] = d.lp().bytes() }
            val cs = sd.lp()
            if (!cs.hasRemaining()) continue
            val cert = cs.lp().bytes()
            out += Entry(scheme, signedData, sigs, publicKey, digests, cert, hex(MessageDigest.getInstance("SHA-256").digest(cert)))
        }
        return out
    }

    private fun idValues(pairs: ByteArray): Map<Int, ByteArray> {
        val b = le(pairs)
        val out = HashMap<Int, ByteArray>()
        while (b.remaining() >= 12) {
            val len = b.long
            require(len in 4..b.remaining().toLong())
            val id = b.int
            out[id] = ByteArray((len - 4).toInt()).also { b.get(it) }
        }
        return out
    }

    private fun contentDigest(ch: FileChannel, alg: String, blockStart: Long, cdOff: Long, eocdOff: Long, eocd: ByteArray): ByteArray {
        val patched = eocd.copyOf().also { le(it).putInt(16, blockStart.toInt()) }
        val chunks = listOf(0L to blockStart, cdOff to eocdOff).flatMap { (a, b) ->
            (a until b step CHUNK.toLong()).map { it to minOf(CHUNK.toLong(), b - it).toInt() }
        }
        val out = arrayOfNulls<ByteArray>(chunks.size)
        val next = AtomicInteger()
        val threads = minOf(Runtime.getRuntime().availableProcessors(), 4)
        val pool = Executors.newFixedThreadPool(threads)
        try {
            pool.invokeAll(List(threads) {
                Callable {
                    val md = MessageDigest.getInstance(alg)
                    val buf = ByteBuffer.allocateDirect(CHUNK)
                    while (true) {
                        val i = next.getAndIncrement()
                        if (i >= chunks.size) break
                        val (pos, n) = chunks[i]
                        buf.clear().limit(n)
                        fill(ch, buf, pos).flip()
                        out[i] = chunk(md, buf)
                        progress()
                    }
                }
            }).forEach { it.get() }
        } finally { pool.shutdown() }
        val top = MessageDigest.getInstance(alg)
        top.update(0x5a.toByte()); top.update(u32(chunks.size + 1))
        out.forEach { top.update(it!!) }
        top.update(chunk(MessageDigest.getInstance(alg), ByteBuffer.wrap(patched)))
        return top.digest()
    }

    private fun chunk(md: MessageDigest, data: ByteBuffer): ByteArray {
        md.update(0xa5.toByte()); md.update(u32(data.remaining())); md.update(data)
        return md.digest()
    }

    private fun fill(ch: FileChannel, b: ByteBuffer, pos: Long): ByteBuffer {
        while (b.hasRemaining()) if (ch.read(b, pos + b.position()) < 0) throw EOFException()
        return b
    }

    private fun read(ch: FileChannel, pos: Long, n: Int): ByteArray = fill(ch, ByteBuffer.allocate(n), pos).array()

    private fun le(b: ByteArray): ByteBuffer = ByteBuffer.wrap(b).order(ByteOrder.LITTLE_ENDIAN)

    private fun ByteBuffer.lp(): ByteBuffer {
        val n = int
        require(n in 0..remaining())
        val s = slice().order(ByteOrder.LITTLE_ENDIAN)
        s.limit(n)
        position(position() + n)
        return s
    }

    private fun ByteBuffer.bytes(): ByteArray = ByteArray(remaining()).also { get(it) }

    private fun le32(b: ByteArray, off: Int): Int = ByteBuffer.wrap(b, off, 4).order(ByteOrder.LITTLE_ENDIAN).int

    private fun u32(v: Int): ByteArray = ByteBuffer.allocate(4).order(ByteOrder.LITTLE_ENDIAN).putInt(v).array()

}

```kt
package io.github.areyougarou.intakto

import android.app.Activity
import android.content.Context
import android.content.ContextWrapper
import android.os.Build
import android.os.Handler
import android.os.Looper
import android.os.Process
import org.json.JSONArray
import java.lang.ref.WeakReference
import java.util.concurrent.Executors

enum class Status {
    /** The check looked and found nothing wrong. */
    CLEAN,

    /** The check looked and found a real problem. */
    DETECTED,

    /**
     * The check could not get an answer (a read failed, an empty read, an error, the native core did
     * not load, or the run did not finish). Never reported as CLEAN, so the host can tell "could not
     * confirm" apart from a check that really looked.
     */
    INCONCLUSIVE,
}

enum class Group { APP_INTEGRITY, INSTRUMENTATION }

data class Signal(
    val id: String,
    val group: Group,
    val status: Status,
    val details: String,
    val micros: Long,
)

/**
 * One run's result. [verdict] is DETECTED if any signal is DETECTED, else INCONCLUSIVE if any signal
 * is INCONCLUSIVE (or there are none), else CLEAN. [detected] holds the DETECTED signals.
 */
data class Report(
    val signals: List<Signal>,
    val verdict: Status,
    val detected: List<Signal>,
    val elapsedMs: Long,
)

/**
 * The result callback. A `fun interface` (single-abstract-method), so a Kotlin trailing lambda and a
 * plain Java lambda both work: `Intakto.check(this) { report -> ... }` in Kotlin, and
 * `Intakto.check(this, report -> { ... })` in Java with no `Unit.INSTANCE` to return.
 */
fun interface ReportCallback {
    fun onReport(report: Report)
}

object Intakto {

    private const val STALL_MS = 5000L
    private val main = Handler(Looper.getMainLooper())
    private val lock = Any()
    private var running: Run? = null
    private var last: Report? = null

    // One long-lived thread runs every check. A new run is only queued when none is running, so a stuck
    // run never has later runs waiting behind it: those calls report CHECK_STALLED.
    private val worker = Executors.newSingleThreadExecutor { r -> Thread(r, "Intakto").apply { isDaemon = true } }

    private class Run {
        val t0 = System.nanoTime()
        private val signals = ArrayList<Signal>()
        val waiting = ArrayList<Waiter>()
        fun add(s: List<Signal>) = synchronized(this) { signals += s; progress() }
        fun snapshot(): List<Signal> = synchronized(this) { signals.toList() }
    }

    private class Waiter(val run: Run, val screen: WeakReference<Activity>?, var onResult: ReportCallback?) : Runnable {
        override fun run() {
            val idle = (System.nanoTime() - lastProgress) / 1_000_000
            val waiting = synchronized(lock) { if (idle >= STALL_MS) run.waiting.remove(this) else this in run.waiting }
            when {
                !waiting -> {}
                idle < STALL_MS -> main.postDelayed(this, STALL_MS - idle)
                else -> deliver(this, toReport(run.snapshot() + stalled("no check made progress for $STALL_MS ms " +
                    (if (current.isEmpty()) "(before the first check)" else "(stuck in $current)") +
                    "; only the signals that finished are listed"), run.t0))
            }
        }
    }

    // @JvmStatic + @JvmOverloads so Java callers can write Intakto.check(this) or the full form. Without
    // them, Kotlin's default arguments are not visible to Java and the object method is only reachable
    // as Intakto.INSTANCE.check(...).

    /**
     * Hands [onResult] the latest finished result, on the main thread. Before the first run ends, it
     * waits for that run. In a process where no run started (see IntaktoInitProvider), it starts one.
     */
    @JvmStatic
    @JvmOverloads
    fun check(context: Context, onResult: ReportCallback = ReportCallback {}) = request(context, false, onResult)

    /** Like [check], but waits for a new run (or the one in progress) instead of the latest result. */
    @JvmStatic
    @JvmOverloads
    fun recheck(context: Context, onResult: ReportCallback = ReportCallback {}) = request(context, true, onResult)

    // Called by IntaktoInitProvider when the process starts.
    internal fun start(context: Context) {
        val run = synchronized(lock) { if (running != null || last != null) null else begin() }
        if (run != null) launch(context.applicationContext ?: context, run)
    }

    private fun request(context: Context, fresh: Boolean, onResult: ReportCallback) {
        val app = context.applicationContext ?: context
        val screen = activity(context)?.let { WeakReference(it) }
        var cached: Report?
        var idleMs = 0L
        var start = false
        val w = synchronized(lock) {
            cached = if (fresh) null else last
            val current = running
            if (current != null) idleMs = (System.nanoTime() - lastProgress) / 1_000_000
            if (cached != null || idleMs >= STALL_MS) null
            else Waiter(current ?: begin().also { start = true }, screen, onResult).also { it.run.waiting += it }
        }
        if (w == null) {
            val r = cached ?: toReport(listOf(stalled("an earlier run has made no progress for $idleMs ms; no checks ran for this call")), System.nanoTime())
            main.post { if (alive(screen)) onResult.onReport(r) }
            return
        }
        main.postDelayed(w, STALL_MS)
        if (start) launch(app, w.run)
    }

    // Under lock.
    private fun begin(): Run = Run().also { running = it; current = ""; progress() }

    private fun launch(app: Context, run: Run) {
        try {
            worker.execute {
                try { collect(app, run) } catch (t: Throwable) { run.add(listOf(failed(t))) }
                finish(run)
            }
        } catch (t: Throwable) {
            run.add(listOf(failed(t)))
            finish(run)
        }
    }

    private fun finish(run: Run) {
        val r = toReport(run.snapshot(), run.t0)
        val done = synchronized(lock) {
            if (running === run) running = null
            last = r
            run.waiting.toList().also { run.waiting.clear() }
        }
        main.post { done.forEach { deliver(it, r) } }
    }

    private fun toReport(signals: List<Signal>, t0: Long): Report {
        val detected = signals.filter { it.status == Status.DETECTED }
        val verdict = when {
            detected.isNotEmpty() -> Status.DETECTED
            signals.isEmpty() || signals.any { it.status == Status.INCONCLUSIVE } -> Status.INCONCLUSIVE
            else -> Status.CLEAN
        }
        return Report(signals, verdict, detected, (System.nanoTime() - t0) / 1_000_000)
    }

    private fun failed(t: Throwable) = Signal("CHECK_FAILED", Group.APP_INTEGRITY, Status.INCONCLUSIVE,
        "could not verify: the run stopped early: ${t.javaClass.simpleName}: ${t.message}", 0)

    private fun stalled(detail: String) = Signal("CHECK_STALLED", Group.APP_INTEGRITY, Status.INCONCLUSIVE, "could not verify: $detail", 0)

    private tailrec fun activity(c: Context?): Activity? = when (c) {
        is Activity -> c
        is ContextWrapper -> activity(c.baseContext)
        else -> null
    }

    private fun alive(screen: WeakReference<Activity>?) =
        screen == null || screen.get().let { it != null && !it.isFinishing && !it.isDestroyed }

    private fun deliver(w: Waiter, report: Report) {
        main.removeCallbacks(w)
        val onResult = w.onResult ?: return
        w.onResult = null
        if (alive(w.screen)) onResult.onReport(report)
    }

    private fun collect(context: Context, run: Run) {
        TamperProbe.awaitPlayDownload(context)
        val loadError = NativeCore.load()
        TamperProbe.startContentCheck(context)
        run.add(nativeSignals(context, loadError))
        run.add(CloneProbe.collect(context))
        run.add(TamperProbe.collect(context))
    }

    private const val NOT_APPLICABLE = 3

    private fun nativeSignals(context: Context, loadError: Throwable?): List<Signal> {
        val t0 = System.nanoTime()
        val failure = loadError ?: try {
            val arr = JSONArray(NativeCore.run(
                TamperProbe.androidSigners(context).joinToString(",").ifEmpty { null },
                context.packageName, context.applicationInfo.targetSdkVersion))
            val systemImage = TamperProbe.systemImage(context)
            return (0 until arr.length()).mapNotNull { i ->
                val o = arr.getJSONObject(i)
                val code = o.getInt("status")
                if (code == NOT_APPLICABLE || systemImage && o.getString("id") == "TAMPER_SIGNING_BLOCK") return@mapNotNull null
                require(code in 0..2) { "unknown native status $code" }
                Signal(
                    id = o.getString("id"),
                    group = Group.valueOf(o.getString("group")),
                    // native status: 0 = clean, 1 = a real catch, 2 = could not get an answer.
                    status = when (code) { 0 -> Status.CLEAN; 1 -> Status.DETECTED; else -> Status.INCONCLUSIVE },
                    details = (if (code == 2) "could not verify: " else "") + o.getString("details"),
                    micros = o.getLong("us"),
                )
            }
        } catch (t: Throwable) { t }
        val details = "could not verify: native checks did not run: ${failure.javaClass.simpleName}: ${failure.message}" +
            " abis=${Build.SUPPORTED_ABIS.joinToString(",")} is64=${Process.is64Bit()}"
        return listOf(Signal("NATIVE_CORE", Group.APP_INTEGRITY, Status.INCONCLUSIVE, details, (System.nanoTime() - t0) / 1000))
    }
}

    id: String,
    group: Group,
    block: () -> Pair<Status, String>,

    fun collect(ctx: Context): List<Signal> {
        // An app built into the system image is served from /system, outside the folders these checks
        // read, so both are left out for it. That is a fixed fact from ApplicationInfo flags, known
        // before any file is read; a failed read never switches a check off.
        val systemImage = systemImage(ctx)
        return listOfNotNull(
            timedSignal("TAMPER_PUBLIC_KEY", Group.APP_INTEGRITY) { publicKey(ctx) },
            if (systemImage) null
            else timedSignal("TAMPER_REPACKAGER", Group.APP_INTEGRITY) { repackager(ctx) },
            if (systemImage) null
            else timedSignal("TAMPER_APK_CONTENT", Group.APP_INTEGRITY) { apkContent(ctx) },
        )
    }

    // Set once the install is known to be complete. Neither fact can change while this process lives
    // (an update restarts it), so later runs skip the two system calls.
    @Volatile private var downloadComplete = false

    fun awaitPlayDownload(ctx: Context) {
        if (downloadComplete || Build.VERSION.SDK_INT < Build.VERSION_CODES.S) return
        try {
            if (ctx.packageManager.getInstallSourceInfo(ctx.packageName).initiatingPackageName != "com.android.vending") {
                downloadComplete = true
                return
            }
            val apps = ctx.getSystemService(LauncherApps::class.java)
            while ((apps.getActivityList(ctx.packageName, Process.myUserHandle()).firstOrNull()?.loadingProgress ?: 1f) < 1f) {
                progress()
                Thread.sleep(500)
            }
            downloadComplete = true
        } catch (_: Exception) {}
    }

    fun startContentCheck(ctx: Context) {
        if (contentWorker != null || systemImage(ctx)) return
        try {
            val files = listOf(baseApk(ctx)) + ctx.applicationInfo.splitSourceDirs.orEmpty()
            val known = androidSigners(ctx).toSet()
            val targetSdk = ctx.applicationInfo.targetSdkVersion
            contentWorker = Thread {
                contentResults = try { verifyAll(files, known, targetSdk) } catch (t: Throwable) {
                    listOf("apk" to ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: ${t.javaClass.simpleName}: ${t.message}"))
                }
            }.apply { isDaemon = true; start() }
        } catch (t: Throwable) {
            contentResults = listOf("apk" to ApkVerdict(Status.INCONCLUSIVE, null, "could not verify: the APK file check could not start: ${t.javaClass.simpleName}: ${t.message}"))
        }
    }

    private fun baseApk(ctx: Context): String = baseApk
        ?: (NativeCore.apkPath(ctx.packageName) ?: ctx.applicationInfo.sourceDir).also { baseApk = it }

    private fun installed(path: String): String = path.also {
        require(installerDir.matches(it) && "/../" !in it) { "$it is not in a folder Android installs apps into" }
    }

    fun systemImage(ctx: Context): Boolean = ctx.applicationInfo.flags.let {
        it and ApplicationInfo.FLAG_SYSTEM != 0 && it and ApplicationInfo.FLAG_UPDATED_SYSTEM_APP == 0
    }

    fun androidSigners(ctx: Context): List<String> = try {
        signers(ctx).run { current + history }.distinct()
    } catch (_: Throwable) { emptyList() }

    private fun signers(ctx: Context): Signers =
        signerCerts ?: readSigner(ctx).also { if (it.current.isNotEmpty()) signerCerts = it }

    private fun apkContent(ctx: Context): Pair<Status, String> {
        val s = signers(ctx)
        if (s.current.isEmpty()) return Status.INCONCLUSIVE to "could not verify: no signer cert from Android"
        contentWorker?.join()
        val results = contentResults ?: return Status.INCONCLUSIVE to "could not verify: the APK file check did not start"
        // DETECTED first. Otherwise, if any file could not be checked, INCONCLUSIVE (not CLEAN): a file
        // we could not read is not a file that matched.
        results.firstOrNull { it.second.status == Status.DETECTED }?.let { (n, v) -> return Status.DETECTED to "$n: ${v.detail}" }
        results.firstOrNull { it.second.status == Status.INCONCLUSIVE }?.let { (n, v) -> return Status.INCONCLUSIVE to "$n: ${v.detail}" }
        return Status.CLEAN to "files=${results.size} match their signatures; ${results.first().second.detail}"
    }

    private fun verifyAll(files: List<String>, signers: Set<String>, targetSdk: Int): List<Pair<String, ApkVerdict>> = files.map { path ->
        File(path).name to ParcelFileDescriptor.AutoCloseInputStream(ParcelFileDescriptor.adoptFd(NativeCore.open(installed(path))))
            .use { ApkSignature.verify(it.channel, signers, targetSdk) }
    }

    private fun publicKey(ctx: Context): Pair<Status, String> {
        val s = signers(ctx)
        if (s.current.isEmpty()) return Status.INCONCLUSIVE to "could not verify: no signer cert"
        val known = s.current.firstOrNull { it in publicKeys }
            ?: return Status.CLEAN to "signer is not a publicly known key"
        return Status.DETECTED to "signed with a publicly known key: ${known.take(16)}"
    }

    private fun readSigner(ctx: Context): Signers {
        val pm = ctx.packageManager
        val (current, history) = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.P) {
            val info = pm.getPackageInfo(ctx.packageName, PackageManager.GET_SIGNING_CERTIFICATES).signingInfo
                ?: return Signers(emptyList(), emptyList())
            val history = if (info.hasMultipleSigners()) emptyList() else info.signingCertificateHistory.orEmpty().toList()
            info.apkContentsSigners.orEmpty().toList() to history
        } else {
            @Suppress("DEPRECATION")
            pm.getPackageInfo(ctx.packageName, PackageManager.GET_SIGNATURES).signatures.orEmpty().toList() to emptyList()
        }
        return Signers(current.map { certHex(it) }, history.map { certHex(it) })
    }

    private fun certHex(sig: android.content.pm.Signature): String =
        hex(MessageDigest.getInstance("SHA-256").digest(sig.toByteArray()))

    private fun repackager(ctx: Context): Pair<Status, String> {
        val hits = repackaged ?: repackagerHits(baseApk(ctx)).also { repackaged = it }
        return if (hits.isNotEmpty()) Status.DETECTED to "repackager artifacts: $hits"
        else Status.CLEAN to "no repackager artifacts"
    }

    private fun repackagerHits(src: String): List<String> {
        val markers = listOf(
            "assets/lspatch/", "liblspatch.so",
            "libfrida-gadget.so", "libfrida-gadget.config.so",
            "libappcloner.so",
        )
        return ParcelFileDescriptor.AutoCloseInputStream(ParcelFileDescriptor.adoptFd(NativeCore.open(installed(src))))
            .use { ApkSignature.entryNames(it.channel) }
            .filter { n -> markers.any { n.startsWith(it) || n.endsWith("/$it") } }
    }
}

package io.github.areyougarou.intakto

import android.os.Looper
import org.junit.Assert.assertEquals
import org.junit.Assert.assertNotSame
import org.junit.Assert.assertSame
import org.junit.Assert.assertTrue
import org.junit.Test
import org.junit.runner.RunWith
import org.robolectric.RobolectricTestRunner
import org.robolectric.RuntimeEnvironment
import org.robolectric.Shadows.shadowOf
import org.robolectric.annotation.Config

// An adopter's unit tests run on a JVM with no phone and no native library. There, check() must not
// throw, must report the native checks as "could not confirm" (INCONCLUSIVE), must never report a
// catch, and the overall verdict must be INCONCLUSIVE, never CLEAN.
@RunWith(RobolectricTestRunner::class)
@Config(sdk = [34])
class JvmCheckTest {

    private fun await(call: ((Report) -> Unit) -> Unit): Report {
        var report: Report? = null
        call { report = it }
        // The checks run on IntaktoFT's own thread and post the result to the main looper, which
        // Robolectric runs only when asked.
        val deadline = System.nanoTime() + 10_000_000_000
        while (report == null && System.nanoTime() < deadline) {
            Thread.sleep(50)
            shadowOf(Looper.getMainLooper()).idle()
        }
        return report ?: throw AssertionError("no report within 10 s")
    }

    @Test
    fun checkOnTheJvmIsInconclusiveAndNeverDetects() {
        val app = RuntimeEnvironment.getApplication()
        val r = await { cb -> Intakto.check(app) { cb(it) } }
        println("JVM report: verdict=${r.verdict} " + r.signals.joinToString(" ") { "${it.id}=${it.status}" })
        assertEquals(Status.INCONCLUSIVE, r.signals.single { it.id == "NATIVE_CORE" }.status)
        assertTrue("a check reported DETECTED: ${r.detected}", r.detected.isEmpty())
        assertEquals(Status.INCONCLUSIVE, r.verdict)

        // A later check() gets the same finished result; recheck() runs again.
        assertSame(r, await { cb -> Intakto.check(app) { cb(it) } })
        val again = await { cb -> Intakto.recheck(app) { cb(it) } }
        assertNotSame(r, again)
        assertEquals(Status.INCONCLUSIVE, again.verdict)
        assertSame(again, await { cb -> Intakto.check(app) { cb(it) } })
    }
}

# IntaktoFT for Unity

Catch modded copies of your Android game, and players running Frida on it, without blocking an honest player.\
This package adds the IntaktoFT Android library to a Unity project and lets your C# code read its result.\
What it catches, and how we test that honest phones never trip it: the [main README](../README.md).

## Setup takes three steps

1. **Get External Dependency Manager for Unity (EDM4U).** It downloads the Android library into your build.\
   Most ad and Firebase SDKs already install it: if your menu has `Assets > External Dependency Manager`, skip this step.\
   Otherwise, install it from [its GitHub page](https://github.com/googlesamples/unity-jar-resolver).
2. **Add this package.** Open `Window > Package Manager`, click `+`, pick "Add package from git URL" ("Install package from git URL" in Unity 6), and paste:
   ```
   https://github.com/IntaktoFT/IntaktoFT.git?path=unity
   ```
3. **Set the minimum Android version to 8.0.** In `Project Settings > Player > Android > Other Settings`, set `Minimum API Level` to 26 or higher.\
   With a lower setting, the Android build stops with a `minSdkVersion` error.

The checks then start by themselves when the game starts. Read the result with one call, for example in a script in your first scene:

```csharp
using IntaktoFT;
using UnityEngine;

public class Protect : MonoBehaviour
{
    void Awake() => Intakto.Check(report =>
    {
        if (report.Verdict == Status.Detected)
            foreach (var s in report.Signals)
                if (s.Status == Status.Detected) Debug.Log("IntaktoFT caught " + s.Id + ": " + s.Details);
    });
}
```

## IntaktoFT never closes the game

Your code decides what a catch means: log it, send it to your game server, or end the session.\
`Verdict` is `Detected` when a check proved the game was modded or hooked.\
It is `Inconclusive` when a check could not get an answer, so `Clean` always means every check looked.

`Check` hands you the latest finished result, so a call after the first run ends gets it at once.\
`Recheck` runs the checks again. Use it at moments that matter, such as a ranked match or a purchase: a tool attached after the game started shows up only in a later run.

Call `Check` from Unity's main thread (`Awake`, `Start`, `Update`): the result then arrives on Unity's main thread too, so it can call any Unity API.\
In the Editor and on other platforms, `Check` runs nothing and reports `Inconclusive` with no signals.

## A missing library never crashes the game

If EDM4U did not add the Android library, `Check` reports one `CHECK_FAILED` signal with status `Inconclusive`, and the game keeps running.\
To fix it, run `Assets > External Dependency Manager > Android Resolver > Force Resolve`, then build again.

```cs
// C# entry point for the IntaktoFT Android library. The library starts its checks by itself when the
// game starts; this reads the result through the same calls an Android app makes,
// io.github.areyougarou.intakto.Intakto.check(context, callback) and recheck(context, callback), and
// turns the Kotlin Report into plain C# objects. The checks themselves all run in the Android library.
using System;
using System.Collections.Generic;
using System.Threading;
using UnityEngine;

namespace IntaktoFT
{
    /// <summary>Clean: looked, found nothing. Detected: a proven catch. Inconclusive: could not get an
    /// answer. Also the report's verdict: Detected if any signal is, else Inconclusive if any signal is
    /// (or there are none), else Clean.</summary>
    public enum Status { Clean, Detected, Inconclusive }

    public sealed class Signal
    {
        public string Id;
        /// <summary>APP_INTEGRITY or INSTRUMENTATION.</summary>
        public string Group;
        public Status Status;
        public string Details;
    }

    public sealed class Report
    {
        public Status Verdict;
        public IReadOnlyList<Signal> Signals;
        public long ElapsedMs;
    }

    public static class Intakto
    {
        /// <summary>
        /// Hands onResult the latest finished result; before the first run ends, it waits for that run.
        /// Call it from Unity's main thread; onResult then runs on Unity's main thread too. In the Editor
        /// and on other platforms it checks nothing and reports Inconclusive with no signals.
        /// </summary>
        public static void Check(Action<Report> onResult) => Call("check", onResult);

        /// <summary>Like Check, but runs the checks again and hands onResult the new result.</summary>
        public static void Recheck(Action<Report> onResult) => Call("recheck", onResult);

        static void Call(string method, Action<Report> onResult)
        {
#if UNITY_ANDROID && !UNITY_EDITOR
            var unity = SynchronizationContext.Current;
            try
            {
                using (var player = new AndroidJavaClass("com.unity3d.player.UnityPlayer"))
                using (var activity = player.GetStatic<AndroidJavaObject>("currentActivity"))
                using (var sdk = new AndroidJavaClass("io.github.areyougarou.intakto.Intakto"))
                    sdk.CallStatic(method, activity, new Callback(onResult, unity));
            }
            catch (Exception e)
            {
                // Most often the Android library is missing because EDM4U did not resolve it.
                Deliver(onResult, unity, Failed("the IntaktoFT Android library did not run", e));
            }
#else
            onResult?.Invoke(new Report { Verdict = Status.Inconclusive, Signals = Array.Empty<Signal>() });
#endif
        }

#if UNITY_ANDROID && !UNITY_EDITOR
        sealed class Callback : AndroidJavaProxy
        {
            readonly Action<Report> onResult;
            readonly SynchronizationContext unity;

            public Callback(Action<Report> onResult, SynchronizationContext unity)
                : base("io.github.areyougarou.intakto.ReportCallback")
            {
                this.onResult = onResult;
                this.unity = unity;
            }

            // The library calls this on Android's main thread, not Unity's: read the Java report here,
            // then hand the C# copy to Unity's thread.
            public void onReport(AndroidJavaObject report)
            {
                if (onResult == null) return;
                Report r;
                try { r = Read(report); }
                catch (Exception e) { r = Failed("could not read the Android report", e); }
                Deliver(onResult, unity, r);
            }

            static Report Read(AndroidJavaObject report)
            {
                var signals = new List<Signal>();
                using (var list = report.Call<AndroidJavaObject>("getSignals"))
                    for (int i = 0, n = list.Call<int>("size"); i < n; i++)
                        using (var s = list.Call<AndroidJavaObject>("get", i))
                            signals.Add(new Signal
                            {
                                Id = s.Call<string>("getId"),
                                Group = Name(s, "getGroup"),
                                Status = Parse(Name(s, "getStatus")),
                                Details = s.Call<string>("getDetails"),
                            });
                return new Report
                {
                    Verdict = Parse(Name(report, "getVerdict")),
                    Signals = signals,
                    ElapsedMs = report.Call<long>("getElapsedMs"),
                };
            }

            static Status Parse(string name) => (Status)Enum.Parse(typeof(Status), name, true);

            static string Name(AndroidJavaObject o, string getter)
            {
                using (var e = o.Call<AndroidJavaObject>(getter)) return e.Call<string>("name");
            }
        }

        // Same rule as the library: a failure is reported as "could not confirm", never as Clean.
        static Report Failed(string what, Exception e) => new Report
        {
            Verdict = Status.Inconclusive,
            Signals = new[] { new Signal { Id = "CHECK_FAILED", Group = "APP_INTEGRITY", Status = Status.Inconclusive,
                Details = "could not verify: " + what + ": " + e.Message } },
        };

        static void Deliver(Action<Report> onResult, SynchronizationContext unity, Report report)
        {
            if (onResult == null) return;
            if (unity != null) unity.Post(_ => onResult(report), null);
            else onResult(report);
        }
#endif
    }
}
