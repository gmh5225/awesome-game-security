`README.md`:

```md
<div align="center">

# 🛡️ MobSentry

### Mobile App Security Analyzer — Android (APK) + iOS (IPA)

**Deterministic static analysis → evidence → findings. Evidence first, AI reasoning last.**

Local · private · one `python app.py` · no Docker · Windows / Linux / macOS

</div>

---

## Why MobSentry?

Most free mobile scanners stop at *“root detection exists”* or flag *“anti-debug present”* just because a string shows up somewhere in the binary. MobSentry is built differently:

- **Evidence-first.** Every finding carries the exact location + snippet it came from. Nothing is a finding without something you can click into.
- **Mechanism → validation surface.** For SSL pinning, root/jailbreak and anti-instrumentation, it doesn’t just say *what* — it maps *which mechanism*, *where*, and *the surface a pentester must validate or bypass*.
- **Honest confidence.** String-only matches are labelled as heuristic (“may be incidental — confirm in the referencing code”), not sold as proof. No `ptrace`/`sysctl`-equals-anti-debug nonsense.
- **One tool, both platforms.** Android **and** iOS, same evidence → findings → PDF model.
- **Stack-aware bypass guidance.** Detects the stack (OkHttp / TrustManager / Flutter / native / NSC on Android; TrustKit / AFNetworking / SecTrust / Flutter on iOS) and gives the *right* interception method — including the fact that **Flutter ignores the system proxy and its own BoringSSL**, so it needs reFlutter / native hooks + transparent (iptables/tun) interception, not a normal Frida pinning hook.

> ⚖️ **For authorized security testing and research only.** Analyze apps you own or are explicitly permitted to test.

---

## Pipeline

```
   APK / IPA
      │
      ▼
 Deterministic analysis      (androguard / Mach-O + plist parsing)
      │
      ▼
 Evidence database           (every match tied to a location + snippet)
      │
      ▼
 Security findings           (severity · confidence · evidence · fix)
      │
      ▼
 Correlation / AI layer      (reasons only over evidence — never the scanner)
      │
      ▼
 Web UI  +  PDF report
```

---

## Features

### 🤖 Android (.apk)

| Module | What it does |
|---|---|
| Fingerprint | Framework (Kotlin/Java/Flutter/RN/Xamarin/Unity/Cordova/native), ABIs, SDKs, third-party & crypto libs, native `.so` |
| File & app info | MD5/SHA1/SHA256, size, package, main activity, version, min/target/max SDK |
| Manifest | `debuggable`, `allowBackup`, cleartext, `testOnly`, weak custom permissions — with impact |
| Components | Exported activities/services/receivers/providers (explicit **and** implicit), permission guards |
| Deep links | scheme/host/path → component map, app-link verification, sensitivity |
| Permissions | normal / dangerous / special / custom + interesting combinations |
| Network Security Config | cleartext, user/custom trust anchors, debug overrides, pin-sets (+ XML evidence) |
| Secrets, IPs & leaks | 25+ provider keys, private keys, JWTs, basic-auth URLs, IPs (private flagged), emails |
| Firebase | Realtime DB / buckets / config **+ live public-readability check** (`/.json`) |
| Insecure config | WebView (`addJavascriptInterface`, file access…), weak crypto (ECB/MD5/SHA1/PRNG), logging, storage |
| Root detection | techniques, confidence, implementing methods, enforced-vs-log-only, bypass surface |
| Anti-debug / Frida | Frida / debugger / emulator / Xposed references (tied to calling methods) |
| SSL pinning | OkHttp / TrustManager / HostnameVerifier / NSC pins / Conscrypt / Cronet / native TLS |
| Signing | schemes (v1/v2/v3), **debug-certificate**, weak algos, v1-only (Janus) |
| Obfuscation | ProGuard/R8 detection with score + sample renamed vs readable symbols |
| Trackers | 35+ analytics/ad/crash SDKs |

### 🍎 iOS (.ipa)

| Module | What it does |
|---|---|
| Fingerprint | Framework, frameworks/dylibs, arch, bundle id, version, min OS |
| Info.plist | permission usage strings, custom URL schemes, file-sharing flags |
| App Transport Security | `NSAllowsArbitraryLoads`, per-domain insecure exceptions |
| Binary protections | PIE/ASLR, FairPlay encryption, stack canary, ARC, **get-task-allow (debuggable)**, provisioning profile |
| Jailbreak detection | Cydia/Substrate/paths/schemes/keywords → mechanism → surface |
| Anti-debug / Frida | Frida vs Cycript/Substrate (correctly separated), specific anti-debug tokens only |
| SSL pinning | TrustKit / AFNetworking / Alamofire / SecTrust / URLSession + bundled certs |
| Secrets, IPs & leaks | same shared leak engine over the Mach-O binary + bundle |
| Firebase | `GoogleService-Info.plist` (API key, DB URL, bucket) |
| Storage | NSUserDefaults (unencrypted), Keychain, SQLite/Realm/Core Data |
| Trackers | embedded SDK detection |

Both platforms produce a **security score + grade**, a full **PDF report**, and **stack-aware bypass guidance** with ready Frida / objection snippets.

## Install

Requires **Python 3.9+**.

```bash
git clone https://github.com/<you>/MobSentry.git
cd MobSentry
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/mac: source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Open http://127.0.0.1:5000.

**Login decides the engine:**

| Username | Password | Analyzes |
|---|---|---|
| `android` | `android` | `.apk` |
| `ios` | `ios` | `.ipa` |

> Change credentials with env vars `ANDROID_PASS` / `IOS_PASS`. The Firebase live check can be disabled with `MOBSENTRY_FIREBASE_LIVE=0`.

### CLI (headless)

```bash
python cli.py app.apk                 # summary
python cli.py app.apk -o report.json  # full JSON
```

## How it’s architected

- `core/` — shared evidence model + Android engine (androguard)
- `ios/` — iOS engine (IPA / Info.plist / Mach-O / entitlements)
- `app.py` — Flask web UI, login, PDF export
- `static/`, `templates/` — the report UI
- `tests/` — deterministic smoke tests (Android + iOS)

The AI/correlation layer runs **after** the deterministic engine and only reasons over the evidence it produced — it never invents findings.

"""MobSentry web UI — cross-platform (Windows / Linux) Flask app.

Run:  python app.py   then open http://127.0.0.1:5000
Accounts (username = password):
  android / android  -> analyzes Android .apk
  ios     / ios      -> analyzes iOS .ipa
Override passwords with env ANDROID_PASS / IOS_PASS.
"""
from __future__ import annotations

import functools
import io
import os
import tempfile
import uuid

from flask import (Flask, abort, jsonify, redirect, render_template, request,
                   send_file, session, url_for)
from werkzeug.utils import secure_filename

from core.ai import default_ai_layer
from core.analyzer import analyze

app = Flask(__name__)
app.config["MAX_CONTENT_LENGTH"] = 1024 * 1024 * 1024  # 1 GB (IPAs are large)
app.config["SEND_FILE_MAX_AGE_DEFAULT"] = 0            # never cache static assets
app.secret_key = os.environ.get("MOBSENTRY_SECRET", os.urandom(24).hex())

# username -> (password, platform)
ACCOUNTS = {
    "android": (os.environ.get("ANDROID_PASS", "android"), "android"),
    "ios": (os.environ.get("IOS_PASS", "ios"), "ios"),
}
EXT = {"android": ".apk", "ios": ".ipa"}

# cache-busting token for static assets (changes each process start)
ASSET_VER = uuid.uuid4().hex[:8]

UPLOAD_DIR = os.path.join(tempfile.gettempdir(), "mobsentry_uploads")
os.makedirs(UPLOAD_DIR, exist_ok=True)
REPORTS: dict[str, dict] = {}


@app.context_processor
def _inject():
    return {"asset_ver": ASSET_VER, "platform": session.get("platform")}


def login_required(fn):
    @functools.wraps(fn)
    def wrapper(*a, **kw):
        if not session.get("user"):
            return redirect(url_for("login", next=request.path))
        return fn(*a, **kw)
    return wrapper


@app.route("/login", methods=["GET", "POST"])
def login():
    error = None
    if request.method == "POST":
        u = (request.form.get("username") or "").strip().lower()
        p = request.form.get("password") or ""
        acct = ACCOUNTS.get(u)
        if acct and p == acct[0]:
            session["user"] = u
            session["platform"] = acct[1]
            return redirect(request.args.get("next") or url_for("index"))
        error = "Invalid username or password."
    return render_template("login.html", error=error)


@app.route("/logout")
def logout():
    session.clear()
    return redirect(url_for("login"))


@app.route("/")
@login_required
def index():
    return render_template("index.html", user=session.get("user"),
                           platform=session.get("platform"))


@app.route("/analyze", methods=["POST"])
@login_required
def do_analyze():
    platform = session.get("platform", "android")
    want_ext = EXT[platform]
    f = request.files.get("apk")
    if not f or not f.filename:
        return redirect(url_for("index"))
    safe = secure_filename(f.filename) or ("upload" + want_ext)
    if not safe.lower().endswith(want_ext):
        return render_template("index.html", user=session.get("user"),
                               platform=platform,
                               wrong_ext=f"This account analyzes {want_ext} files. "
                                         f"You uploaded {safe}.")
    rid = uuid.uuid4().hex[:12]
    dest = os.path.join(UPLOAD_DIR, f"{rid}_{safe}")
    f.save(dest)
    try:
        db = analyze(dest, platform=platform, ai_layer=default_ai_layer)
        data = db.to_dict()
        data["filename"] = safe
        REPORTS[rid] = data
    finally:
        try:
            os.remove(dest)
        except OSError:
            pass
    return redirect(url_for("report", rid=rid))


@app.route("/report/<rid>")
@login_required
def report(rid: str):
    if rid not in REPORTS:
        abort(404)
    return render_template("report.html", rid=rid,
                           filename=REPORTS[rid].get("filename", "app"),
                           user=session.get("user"))


@app.route("/api/report/<rid>")
@login_required
def api_report(rid: str):
    if rid not in REPORTS:
        abort(404)
    return jsonify(REPORTS[rid])


@app.route("/report/<rid>/pdf")
@login_required
def report_pdf(rid: str):
    if rid not in REPORTS:
        abort(404)
    try:
        from core.report_pdf import build_pdf
        pdf = build_pdf(REPORTS[rid])
    except ModuleNotFoundError:
        return ("PDF export needs reportlab. Install it:  pip install reportlab",
                500)
    name = (REPORTS[rid].get("meta", {}).get("package")
            or REPORTS[rid].get("filename", "report")) + "_mobsentry.pdf"
    return send_file(io.BytesIO(pdf), mimetype="application/pdf",
                     as_attachment=True, download_name=name)


def _port_in_use(host: str, port: int) -> bool:
    import socket
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
        s.settimeout(0.5)
        try:
            return s.connect_ex((host, port)) == 0
        except OSError:
            return False


def main():
    import sys
    import webbrowser
    port = int(os.environ.get("PORT", "5000"))
    host = os.environ.get("HOST", "127.0.0.1")
    url = f"http://{host}:{port}"
    if _port_in_use(host, port):
        print(f"\n  ERROR: port {port} is already in use.")
        print("  Another MobSentry/Flask server is probably still running.")
        print("  Close that terminal (or press Ctrl+C in it), then run again —")
        print(f"  or use another port:  set PORT=5001  (then python app.py)\n")
        sys.exit(1)
    if os.environ.get("MOBSENTRY_OPEN", "1") == "1":
        try:
            webbrowser.open(url)
        except Exception:
            pass
    print(f"\n  MobSentry running on {url}")
    print(f"  Login: android/android (APK)  or  ios/ios (IPA)   (Ctrl+C to stop)\n")
    try:
        from waitress import serve
        serve(app, host=host, port=port, _quiet=True)
    except ModuleNotFoundError:
        import logging
        logging.getLogger("werkzeug").setLevel(logging.ERROR)
        try:
            import flask.cli
            flask.cli.show_server_banner = lambda *a, **k: None
        except Exception:
            pass
        app.run(host=host, port=port,
                debug=bool(os.environ.get("MOBSENTRY_DEBUG")))


if __name__ == "__main__":
    main()

"""MobSentry CLI — analyze an APK and print/save JSON without the web UI.

Usage:
  python cli.py path/to/app.apk                 # summary to stdout
  python cli.py path/to/app.apk -o report.json  # full JSON to file
"""
from __future__ import annotations

import argparse
import json
import sys

from core.ai import default_ai_layer
from core.analyzer import analyze


def main() -> int:
    ap = argparse.ArgumentParser(description="MobSentry APK security analyzer")
    ap.add_argument("apk", help="path to .apk")
    ap.add_argument("-o", "--out", help="write full JSON report here")
    ap.add_argument("--no-ai", action="store_true",
                    help="skip the correlation/AI layer")
    args = ap.parse_args()

    db = analyze(args.apk, ai_layer=None if args.no_ai else default_ai_layer)
    data = db.to_dict()

    if args.out:
        with open(args.out, "w", encoding="utf-8") as fh:
            json.dump(data, fh, indent=2, ensure_ascii=False)
        print(f"wrote {args.out}")

    m = data["meta"]
    c = data["counts"]
    print(f"\n{m.get('app_name')}  ({m.get('package')})  v{m.get('version_name')}")
    print(f"min/target SDK: {m.get('min_sdk')}/{m.get('target_sdk')}  "
          f"time: {m.get('analysis_seconds')}s")
    print(f"findings: {c['high']} high, {c['medium']} medium, "
          f"{c['low']} low, {c['info']} info")
    print("-" * 60)
    for f in data["findings"]:
        print(f"[{f['severity'].upper():5}] {f['title']}  ({f['category']})")
    if data["errors"]:
        print("-" * 60)
        print("analyzer notes:")
        for e in data["errors"]:
            print(" ", e)
    return 0


if __name__ == "__main__":
    sys.exit(main())

```py
"""Reasoning / correlation layer — runs AFTER deterministic analysis.

By default this is a deterministic correlation pass (no network, no API key): it
links findings that together raise priority (e.g. an exported sensitive
component that is also a deep-link target). If you want an LLM to narrate the
report, plug it into `llm_summarize` — it only ever *reads* the evidence DB.
"""
from __future__ import annotations

from .evidence import Confidence, Evidence, EvidenceDB, Severity


def correlate(db: EvidenceDB) -> None:
    """Deterministic correlation: find reinforcing evidence across modules."""
    correlations = []

    exported = {c["name"] for c in db.sections.get("components", {}).get("all", [])
                if c["exported"]}
    deep_targets = {l["component"] for l in
                    db.sections.get("deeplinks", {}).get("links", [])
                    if l["sensitive"]}

    # exported + sensitive deep link = elevated attack path
    both = exported & deep_targets
    for comp in sorted(both):
        correlations.append({
            "type": "exported+deeplink",
            "component": comp,
            "note": "Exported component is also a sensitive deep-link target — "
                    "reachable by other apps and via crafted URIs.",
        })

    # no pinning + cleartext/user-cert trust = weak transport posture
    ssl = db.sections.get("sslpinning", {})
    nsc = db.sections.get("netsec", {})
    if not ssl.get("detected") and (nsc.get("cleartext_permitted") or
                                    nsc.get("user_certs_trusted") or
                                    not nsc.get("present")):
        correlations.append({
            "type": "weak-transport",
            "component": "network",
            "note": "No pinning combined with permissive/absent transport "
                    "config — traffic interception is likely feasible.",
        })

    # root detection present but not enforced = low real protection
    root = db.sections.get("rootdetect", {})
    if root.get("detected") and root.get("enforced_guess") is False:
        correlations.append({
            "type": "root-not-enforced",
            "component": "root-detection",
            "note": "Root detection runs but enforcement could not be confirmed "
                    "near the checks — may be log-only.",
        })

    db.set_section("correlations", correlations)

    if both:
        db.finding(
            id="corr-exported-deeplink",
            title=f"{len(both)} component(s): exported AND sensitive deep-link "
                  "target",
            severity=Severity.MEDIUM, confidence=Confidence.MEDIUM,
            category="correlation",
            description="These components combine two reachability paths; "
                        "prioritize them for input-validation and auth review.",
            evidence=[Evidence("correlation", c) for c in sorted(both)],
            recommendation="Trace URI parameters into the component's logic and "
                           "confirm authentication is enforced.",
        )


def llm_summarize(db: EvidenceDB, call_model) -> None:
    """Optional: hand the evidence to an LLM for a prioritized narrative.

    `call_model(prompt:str) -> str`. Only the already-computed evidence is sent;
    the model never scans the APK itself. Result stored in sections['ai_summary'].
    """
    payload = {
        "meta": db.meta,
        "counts": db.counts(),
        "findings": [f.to_dict() for f in db.sorted_findings()],
        "correlations": db.sections.get("correlations", []),
    }
    prompt = (
        "You are a senior mobile app pentester. Below is a deterministic static "
        "analysis evidence set for an Android APK (JSON). Do NOT invent findings "
        "beyond this evidence. Produce: (1) an executive risk summary, (2) the "
        "top 5 things to validate first and why, (3) likely false positives. "
        "Evidence:\n" + str(payload)
    )
    db.set_section("ai_summary", call_model(prompt))


def default_ai_layer(db: EvidenceDB) -> None:
    correlate(db)

`core/analyzer.py`:

```py
"""Orchestrator: APK/IPA -> deterministic analysis -> evidence DB -> (optional) AI.

Android order matters: components before deeplinks (deeplinks reads parsed
components); netsec before sslpinning (sslpinning cross-references the NSC
pin-set). iOS has its own pipeline in ios.checks.
"""
from __future__ import annotations

import time
from typing import Callable, Optional

from . import (antidebug, bypass, components, deeplinks, fingerprint, firebase,
               insecure, manifest, netsec, obfuscation, permissions, rootdetect,
               secrets, signing, sslpinning, trackers)
from .apkctx import APKContext
from .evidence import EvidenceDB

# Android pipeline (name, module) in execution order
PIPELINE: list[tuple[str, Callable]] = [
    ("fingerprint", fingerprint.run),
    ("signing", signing.run),
    ("obfuscation", obfuscation.run),
    ("trackers", trackers.run),
    ("manifest", manifest.run),
    ("permissions", permissions.run),
    ("components", components.run),
    ("deeplinks", deeplinks.run),
    ("netsec", netsec.run),
    ("secrets", secrets.run),
    ("firebase", firebase.run),
    ("insecure", insecure.run),
    ("antidebug", antidebug.run),
    ("rootdetect", rootdetect.run),
    ("sslpinning", sslpinning.run),
    ("bypass", bypass.run_android),
]


def _finish(db: EvidenceDB, t0: float, timings: dict) -> None:
    db.meta["timings"] = timings
    db.meta["analysis_seconds"] = round(time.time() - t0, 2)
    c = db.counts()
    penalty = c["high"] * 15 + c["medium"] * 7 + c["low"] * 2
    score = max(0, 100 - penalty)
    grade = ("A" if score >= 90 else "B" if score >= 75 else "C" if score >= 60
             else "D" if score >= 40 else "F")
    db.meta["security_score"] = score
    db.meta["security_grade"] = grade
    db.meta["tracker_count"] = db.sections.get("trackers", {}).get("count", 0)


def _analyze_android(path: str, db: EvidenceDB, t0: float) -> bool:
    ctx = APKContext(path)
    if not ctx.ok:
        db.note_error("parse", RuntimeError(ctx.load_error or "could not parse APK"))
        db.meta["parse_failed"] = True
        db.meta["platform"] = "android"
        return False
    db.meta["platform"] = "android"
    timings = {}
    for name, fn in PIPELINE:
        s = time.time()
        fn(ctx, db)
        timings[name] = round(time.time() - s, 2)
    comp = db.sections.get("components", {})
    db.meta["attack_surface"] = {
        "activities": comp.get("counts", {}).get("Activity", 0),
        "services": comp.get("counts", {}).get("Service", 0),
        "receivers": comp.get("counts", {}).get("Receiver", 0),
        "providers": comp.get("counts", {}).get("Provider", 0),
        "exported": comp.get("exported_count", 0),
        "deep_links": db.sections.get("deeplinks", {}).get("count", 0),
        "native_libraries": len(db.sections.get("fingerprint", {})
                                .get("native_libraries", [])),
        "endpoints": db.sections.get("secrets", {}).get("endpoint_count", 0),
    }
    _finish(db, t0, timings)
    return True


def _analyze_ios(path: str, db: EvidenceDB, t0: float) -> bool:
    from ios.ipactx import IPAContext
    from ios import checks
    ctx = IPAContext(path)
    if not ctx.ok:
        db.note_error("parse", RuntimeError(ctx.load_error or
                                            "could not parse IPA / no .app bundle"))
        db.meta["parse_failed"] = True
        db.meta["platform"] = "ios"
        return False
    db.meta["platform"] = "ios"
    timings = {}
    for name, fn in checks.PIPELINE:
        s = time.time()
        fn(ctx, db)
        timings[name] = round(time.time() - s, 2)
    db.meta["attack_surface"] = {
        "url_schemes": len(db.sections.get("plist", {}).get("url_schemes", [])),
        "ats_exceptions": len(db.sections.get("plist", {})
                              .get("ats", {}).get("exception_domains", [])),
        "frameworks": len(db.sections.get("fingerprint", {})
                          .get("native_libraries", [])),
        "endpoints": db.sections.get("secrets", {}).get("endpoint_count", 0),
    }
    _finish(db, t0, timings)
    return True


def analyze(path: str, platform: str = "android",
            ai_layer: Optional[Callable[[EvidenceDB], None]] = None) -> EvidenceDB:
    db = EvidenceDB()
    t0 = time.time()
    ok = (_analyze_ios(path, db, t0) if platform == "ios"
          else _analyze_android(path, db, t0))
    if not ok:
        db.meta["analysis_seconds"] = round(time.time() - t0, 2)
        return db
    if ai_layer is not None:
        try:
            ai_layer(db)
        except Exception as exc:  # noqa: BLE001
            db.note_error("ai_layer", exc)
    return db

"""APKContext: one parsed APK, shared by every analyzer.

Wraps androguard (manifest / dex / analysis) and also keeps raw zip access so
modules can scan assets/, lib/, res/, and raw dex bytes for strings that
androguard's higher-level views miss.
"""
from __future__ import annotations

import hashlib
import os
import re
import zipfile
from functools import cached_property
from typing import Any, Iterable, Optional
from xml.etree import ElementTree as ET

# ASCII/UTF-8 printable string extraction from binary blobs (so / dex / arsc).
_STRINGS_RE = re.compile(rb"[\x20-\x7e]{4,}")


class APKContext:
    def __init__(self, path: str) -> None:
        self.path = path
        self._a = None            # androguard APK
        self._d: list = []        # list[DalvikVMFormat]
        self._dx = None           # androguard Analysis
        self.load_error: Optional[str] = None
        self._parse()

    def _parse(self) -> None:
        try:
            # Silence androguard's very verbose DEBUG logging (axml dimension
            # spam) — it floods the terminal and slows parsing noticeably.
            try:
                from androguard import util as _agutil
                _agutil.set_log("ERROR")
            except Exception:
                import logging
                logging.getLogger("androguard").setLevel(logging.ERROR)
            from androguard.misc import AnalyzeAPK
            self._a, self._d, self._dx = AnalyzeAPK(self.path)
        except Exception as exc:  # noqa: BLE001 - surface, don't crash the server
            self.load_error = f"{type(exc).__name__}: {exc}"

    # ---- androguard handles --------------------------------------------
    @property
    def a(self):
        return self._a

    @property
    def dx(self):
        return self._dx

    @property
    def dvms(self) -> list:
        return self._d or []

    @property
    def ok(self) -> bool:
        return self._a is not None

    # ---- manifest -------------------------------------------------------
    @cached_property
    def manifest_xml(self) -> str:
        if not self.ok:
            return ""
        try:
            from androguard.core.axml import AXMLPrinter  # noqa: F401
            el = self._a.get_android_manifest_xml()
            from lxml import etree
            return etree.tostring(el, pretty_print=True).decode("utf-8", "replace")
        except Exception:
            try:
                return self._a.get_android_manifest_axml().get_xml().decode(
                    "utf-8", "replace"
                )
            except Exception:
                return ""

    @cached_property
    def package(self) -> str:
        return self._a.get_package() if self.ok else ""

    @cached_property
    def main_activity(self) -> str:
        if not self.ok:
            return ""
        try:
            return self._a.get_main_activity() or ""
        except Exception:
            return ""

    @cached_property
    def file_size(self) -> int:
        try:
            return os.path.getsize(self.path)
        except OSError:
            return 0

    @cached_property
    def hashes(self) -> dict:
        h = {"md5": hashlib.md5(), "sha1": hashlib.sha1(),
             "sha256": hashlib.sha256()}
        try:
            with open(self.path, "rb") as fh:
                for chunk in iter(lambda: fh.read(1024 * 1024), b""):
                    for d in h.values():
                        d.update(chunk)
            return {k: v.hexdigest() for k, v in h.items()}
        except OSError:
            return {k: "" for k in h}

    @cached_property
    def string_resources(self) -> dict[str, str]:
        """name -> value for every <string> resource (decoded from resources.arsc).

        This is how we read strings.xml values in a *compiled* APK (where they
        live in resources.arsc, not as a plaintext file).
        """
        out: dict[str, str] = {}
        if not self.ok:
            return out
        try:
            arsc = self._a.get_android_resources()
            if not arsc:
                return out
            for pkg in arsc.get_packages_names():
                try:
                    locales = arsc.get_locales(pkg)
                except Exception:
                    locales = ["\x00\x00"]
                for loc in (locales or ["\x00\x00"]):
                    try:
                        xml = arsc.get_string_resources(pkg, loc)
                    except Exception:
                        continue
                    if not xml:
                        continue
                    try:
                        root = ET.fromstring(xml)
                    except Exception:
                        continue
                    for s in root.iter("string"):
                        name = s.get("name")
                        val = "".join(s.itertext()).strip()
                        if name and val and name not in out:
                            out[name] = val
        except Exception:
            pass
        return out

    def google_services_json(self) -> list[tuple[str, str]]:
        """Return [(path, text)] for any google-services.json shipped in the APK."""
        out = []
        for n in self.namelist:
            if n.split("/")[-1] == "google-services.json":
                out.append((n, self.read_text(n)))
        return out

    # ---- raw zip --------------------------------------------------------
    @cached_property
    def _zip(self) -> Optional[zipfile.ZipFile]:
        try:
            return zipfile.ZipFile(self.path)
        except Exception:
            return None

    @cached_property
    def namelist(self) -> list[str]:
        z = self._zip
        return z.namelist() if z else []

    def read_raw(self, name: str) -> bytes:
        z = self._zip
        if not z:
            return b""
        try:
            return z.read(name)
        except Exception:
            return b""

    def read_text(self, name: str) -> str:
        return self.read_raw(name).decode("utf-8", "replace")

    def files_matching(self, *prefixes: str, suffix: str = "") -> list[str]:
        out = []
        for n in self.namelist:
            if prefixes and not any(n.startswith(p) for p in prefixes):
                continue
            if suffix and not n.endswith(suffix):
                continue
            out.append(n)
        return out

    # ---- strings --------------------------------------------------------
    @staticmethod
    def extract_strings(blob: bytes, minlen: int = 4) -> Iterable[str]:
        for m in _STRINGS_RE.finditer(blob):
            s = m.group().decode("ascii", "replace")
            if len(s) >= minlen:
                yield s

    @cached_property
    def dex_strings(self) -> list[str]:
        """All string-pool entries from every dex (fast, structured)."""
        out: list[str] = []
        for d in self.dvms:
            try:
                out.extend(d.get_strings())
            except Exception:
                continue
        return out

    @cached_property
    def native_libs(self) -> list[str]:
        return self.files_matching("lib/", suffix=".so")

    @cached_property
    def abis(self) -> list[str]:
        abis = set()
        for n in self.native_libs:
            parts = n.split("/")
            if len(parts) >= 3:
                abis.add(parts[1])
        return sorted(abis)

    def iter_class_names(self) -> Iterable[str]:
        if not self._dx:
            return []
        try:
            for c in self._dx.get_classes():
                yield str(c.name)
        except Exception:
            return []

ANDROID_NS = "http://schemas.android.com/apk/res/android"

COMPONENT_TAGS = {
    "activity": "Activity",
    "activity-alias": "Alias",
    "service": "Service",
    "receiver": "Receiver",
    "provider": "Provider",
}

# Name fragments that hint at sensitive functionality.
SENSITIVE_HINTS = ("payment", "pay", "transfer", "login", "auth", "account",
                   "admin", "debug", "export", "webview", "web", "deeplink",
                   "oauth", "token", "reset", "pin", "otp", "wallet", "card")


def _bool(v, default=None):
    if v is None:
        return default
    return str(v).strip().lower() == "true"


def _parse_intent_filters(el):
    filters = []
    for f in el.findall("intent-filter"):
        rec = {"actions": [], "categories": [], "data": []}
        for act in f.findall("action"):
            rec["actions"].append(act.get(f"{_A}name"))
        for cat in f.findall("category"):
            rec["categories"].append(cat.get(f"{_A}name"))
        for d in f.findall("data"):
            data = {k.split("}")[-1]: v for k, v in d.attrib.items()
                    if k.startswith(_A)}
            if data:
                rec["data"].append(data)
        filters.append(rec)
    return filters


def run(ctx: APKContext, db: EvidenceDB) -> None:
    try:
        _run(ctx, db)
    except Exception as exc:  # noqa: BLE001
        db.note_error("components", exc)


def _run(ctx: APKContext, db: EvidenceDB) -> None:
    a = ctx.a
    root = a.get_android_manifest_xml()
    target_sdk = None
    try:
        target_sdk = a.get_target_sdk_version()
        target_sdk = int(target_sdk) if target_sdk is not None else None
    except Exception:
        target_sdk = None

    app = root.find("application")
    comps = []
    counts = {label: 0 for label in COMPONENT_TAGS.values()}

    if app is not None:
        for tag, label in COMPONENT_TAGS.items():
            for el in app.findall(tag):
                name = el.get(f"{_A}name") or "(unnamed)"
                exported_attr = el.get(f"{_A}exported")
                permission = el.get(f"{_A}permission")
                filters = _parse_intent_filters(el)
                explicit = _bool(exported_attr)
                has_filter = len(filters) > 0
                # Implicit export rules
                if explicit is None:
                    if tag == "provider":
                        # providers default exported pre-SDK17; modern default false
                        implicit = False if (target_sdk and target_sdk >= 17) \
                            else True
                    else:
                        implicit = has_filter
                    exported = implicit
                    exported_source = "implicit"
                else:
                    exported = explicit
                    exported_source = "explicit"

                record = {
                    "type": label,
                    "name": name,
                    "exported": exported,
                    "exported_source": exported_source,
                    "permission": permission,
                    "intent_filters": filters,
                    "sensitive": any(h in name.lower() for h in SENSITIVE_HINTS),
                }
                comps.append(record)
                counts[label] += 1

    exported = [c for c in comps if c["exported"]]
    db.set_section("components", {
        "counts": counts,
        "exported_count": len(exported),
        "all": comps,
    })

    # Findings for exported components with no permission guard
    for c in exported:
        if c["permission"]:
            continue
        risk = []
        sev = Severity.LOW
        if c["sensitive"]:
            risk.append("sensitive-looking name")
            sev = Severity.MEDIUM
        if c["intent_filters"]:
            risk.append("has intent-filter")
        if c["type"] == "Provider":
            sev = Severity.MEDIUM
            risk.append("content provider")
        db.finding(
            id=f"exp-{c['type']}-{c['name']}".replace(".", "_"),
            title=f"Exported {c['type']} without permission: "
                  f"{c['name'].rsplit('.', 1)[-1]}",
            severity=sev,
            confidence=Confidence.HIGH if c["exported_source"] == "explicit"
            else Confidence.MEDIUM,
            category="components",
            description=(
                f"{c['type']} is exported ({c['exported_source']}) and declares "
                f"no android:permission, so any app can interact with it."
                + (f" Risk indicators: {', '.join(risk)}." if risk else "")
            ),
            evidence=[Evidence("AndroidManifest.xml",
                               f'{c["type"].lower()} {c["name"]} '
                               f'exported={c["exported"]} '
                               f'({c["exported_source"]})')],
            affected_component=c["name"],
            recommendation="Verify the component validates caller identity / "
                           "input, or set exported=false / add a permission.",
        )

"""Deep-link analyzer: map scheme/host/path -> component -> sensitivity.

Reads the parsed components section (components.run must run first).

from __future__ import annotations

from .apkctx import APKContext
from .evidence import Confidence, Evidence, EvidenceDB, Severity

SENSITIVE_PATH_HINTS = ("payment", "pay", "transfer", "reset", "token", "auth",
                        "login", "oauth", "callback", "verify", "otp", "pin",
                        "wallet", "account", "profile", "admin")
BROWSABLE = "android.intent.category.BROWSABLE"
VIEW = "android.intent.action.VIEW"


def run(ctx: APKContext, db: EvidenceDB) -> None:
    try:
        _run(ctx, db)
    except Exception as exc:  # noqa: BLE001
        db.note_error("deeplinks", exc)


def _run(ctx: APKContext, db: EvidenceDB) -> None:
    comps = db.sections.get("components", {}).get("all", [])
    links = []

    for c in comps:
        for f in c["intent_filters"]:
            if VIEW not in f["actions"]:
                continue
            browsable = BROWSABLE in f["categories"]
            for d in f["data"]:
                scheme = d.get("scheme")
                host = d.get("host")
                if not scheme:
                    continue
                path = (d.get("path") or d.get("pathPrefix")
                        or d.get("pathPattern") or "")
                uri = f"{scheme}://{host or ''}{path}"
                blob = uri.lower() + " " + c["name"].lower()
                sensitive = any(h in blob for h in SENSITIVE_PATH_HINTS)
                links.append({
                    "uri": uri,
                    "scheme": scheme,
                    "host": host,
                    "path": path,
                    "component": c["name"],
                    "component_type": c["type"],
                    "exported": c["exported"],
                    "browsable": browsable,
                    "autoverify": f.get("autoVerify") if isinstance(f, dict)
                    else None,
                    "sensitive": sensitive,
                })

    db.set_section("deeplinks", {"count": len(links), "links": links})

    web_schemes = {"http", "https"}
    for l in links:
        if not l["sensitive"]:
            continue
        sev = Severity.MEDIUM
        note = (f"Deep link reaches {l['component_type']} "
                f"{l['component'].rsplit('.', 1)[-1]} and its URI suggests "
                "sensitive functionality.")
        if l["scheme"] in web_schemes and not l.get("autoverify"):
            note += (" App-link uses http/https without verified autoVerify — "
                     "another app could register the same host.")
        db.finding(
            id=f"deeplink-{l['scheme']}-{l['component']}".replace(".", "_"),
            title=f"Sensitive deep link: {l['uri']}",
            severity=sev,
            confidence=Confidence.MEDIUM,
            category="deeplinks",
            description=note,
            evidence=[Evidence("AndroidManifest.xml",
                               f"{l['uri']} -> {l['component']} "
                               f"(browsable={l['browsable']}, "
                               f"exported={l['exported']})")],
            affected_component=l["component"],
            recommendation="Trace whether URI parameters reach sensitive logic "
                           "without authentication, and validate app-link "
                           "ownership (assetlinks.json).",
        )

```py
"""Helpers for locating API usage in dex and naming the calling code.

These connect a matched API to the surrounding method (xref_from), which is what
makes a finding actionable rather than "this API exists somewhere".
"""
from __future__ import annotations

import re
from typing import Iterator, Optional

from .apkctx import APKContext


def _fmt_method(m) -> str:
    try:
        return f"{m.get_class_name()}->{m.get_name()}{m.get_descriptor()}"
    except Exception:
        try:
            return f"{m.class_name}->{m.name}"
        except Exception:
            return str(m)


def find_method_callers(ctx: APKContext, classname: str = ".",
                        methodname: str = ".",
                        descriptor: str = ".") -> list[dict]:
    """Return callers of methods matching the given androguard regexes.

    Each entry: {target, callers:[...]}.
    """
    dx = ctx.dx
    results: list[dict] = []
    if dx is None:
        return results
    try:
        matches = list(dx.find_methods(classname=classname,
                                       methodname=methodname,
                                       descriptor=descriptor))
    except Exception:
        return results
    for mca in matches:
        try:
            target = _fmt_method(mca.get_method())
        except Exception:
            target = str(mca)
        callers = []
        try:
            for _, caller, _off in mca.get_xref_from():
                callers.append(_fmt_method(caller))
        except Exception:
            pass
        results.append({"target": target, "callers": sorted(set(callers))})
    return results


def any_class_matches(ctx: APKContext, pattern: str) -> list[str]:
    """Return class names matching a (python) regex over dotted/slashed names."""
    rx = re.compile(pattern)
    out = []
    for n in ctx.iter_class_names():
        norm = n.strip("L;")
        if rx.search(norm) or rx.search(norm.replace("/", ".")):
            out.append(norm)
    return out


def strings_matching(ctx: APKContext, pattern: str,
                     limit: int = 50) -> list[str]:
    rx = re.compile(pattern)
    out = []
    for s in ctx.dex_strings:
        if rx.search(s):
            out.append(s)
            if len(out) >= limit:
                break
    return out


def find_string_users(ctx: APKContext, literal_or_regex: str,
                      regex: bool = False) -> list[dict]:
    """Find string literals (exact or regex) and the methods that reference them.

    Returns [{string, callers:[method...]}]. This is what lets root/SSL analysis
    say which method a `su` / pinning literal lives in.
    """
    dx = ctx.dx
    out: list[dict] = []
    if dx is None:
        return out
    try:
        if regex:
            matches = list(dx.find_strings(literal_or_regex))
        else:
            # find_strings takes a regex; escape the literal
            matches = list(dx.find_strings(re.escape(literal_or_regex)))
    except Exception:
        return out
    for sa in matches:
        try:
            value = sa.get_value()
        except Exception:
            value = str(sa)
        callers = []
        try:
            for _, meth in sa.get_xref_from():
                callers.append(_fmt_method(meth))
        except Exception:
            pass
        out.append({"string": value, "callers": sorted(set(callers))})
    return out

`core/evidence.py`:

```py
"""Finding + evidence model and the evidence database.

The whole design philosophy (per the architecture): deterministic analysis
produces *evidence*, evidence rolls up into *findings*, and nothing is a
finding without something concrete you can click into. The AI layer runs
afterwards and only reasons over this database -- it never invents findings.
"""
from __future__ import annotations

import dataclasses
from dataclasses import dataclass, field
from enum import Enum
from typing import Any, Optional


class Severity(str, Enum):
    HIGH = "high"
    MEDIUM = "medium"
    LOW = "low"
    INFO = "info"

    @property
    def rank(self) -> int:
        return {"high": 0, "medium": 1, "low": 2, "info": 3}[self.value]


class Confidence(str, Enum):
    HIGH = "high"
    MEDIUM = "medium"
    LOW = "low"


@dataclass
class Evidence:
    """A single concrete piece of proof backing a finding.

    location  e.g. "AndroidManifest.xml", "classes.dex", "res/xml/nsc.xml",
              "smali: com/example/Foo.bar()"
    snippet   the actual text / xml / code line that was matched
    detail    optional human note about why this snippet matters
    """
    location: str
    snippet: str
    detail: str = ""

    def to_dict(self) -> dict[str, Any]:
        return dataclasses.asdict(self)


@dataclass
class Finding:
    id: str
    title: str
    severity: Severity
    confidence: Confidence
    category: str                      # e.g. "manifest", "crypto", "ssl-pinning"
    description: str
    evidence: list[Evidence] = field(default_factory=list)
    affected_component: str = ""       # component / class / file most relevant
    recommendation: str = ""           # what the pentester should validate next
    references: list[str] = field(default_factory=list)
    extra: dict[str, Any] = field(default_factory=dict)  # module-specific payload

    def to_dict(self) -> dict[str, Any]:
        d = dataclasses.asdict(self)
        d["severity"] = self.severity.value
        d["confidence"] = self.confidence.value
        return d


class EvidenceDB:
    """Accumulates findings + arbitrary structured sections from each module."""

    def __init__(self) -> None:
        self.findings: list[Finding] = []
        # Free-form structured output per analyzer section, surfaced in the UI
        # (fingerprint tree, component inventory, deep-link map, etc.)
        self.sections: dict[str, Any] = {}
        self.meta: dict[str, Any] = {}
        self.errors: list[str] = []

    # ---- findings -------------------------------------------------------
    def add(self, finding: Finding) -> Finding:
        self.findings.append(finding)
        return finding

    def finding(self, **kwargs: Any) -> Finding:
        return self.add(Finding(**kwargs))

    # ---- sections -------------------------------------------------------
    def set_section(self, name: str, data: Any) -> None:
        self.sections[name] = data

    def note_error(self, where: str, exc: Exception) -> None:
        self.errors.append(f"{where}: {type(exc).__name__}: {exc}")

    # ---- rollups --------------------------------------------------------
    def counts(self) -> dict[str, int]:
        c = {s.value: 0 for s in Severity}
        for f in self.findings:
            c[f.severity.value] += 1
        return c

    def sorted_findings(self) -> list[Finding]:
        return sorted(self.findings, key=lambda f: (f.severity.rank, f.category))

    def to_dict(self) -> dict[str, Any]:
        return {
            "meta": self.meta,
            "counts": self.counts(),
            "findings": [f.to_dict() for f in self.sorted_findings()],
            "sections": self.sections,
            "errors": self.errors,
        }

def _has_class_prefix(names: list[str], prefix: str) -> bool:
    key = "L" + prefix
    return any(n.startswith(key) or n.startswith(prefix) for n in names)


def run(ctx: APKContext, db: EvidenceDB) -> None:

def _run(ctx: APKContext, db: EvidenceDB) -> None:
    a = ctx.a
    class_names = list(ctx.iter_class_names())
    names_lower = [c.lower() for c in class_names]
    file_blob = "\n".join(ctx.namelist)

    # --- framework detection
    frameworks: dict[str, bool] = {}
    kotlin = _has_class_prefix(class_names, "kotlin/") or \
        any("kotlin/" in n for n in names_lower)
    java = bool(class_names) and not kotlin or True  # dex => JVM bytecode present
    frameworks["Kotlin"] = kotlin
    frameworks["Java"] = True if class_names else False

    native_present = bool(ctx.native_libs)
    frameworks["Native C/C++"] = native_present

    for label, file_markers, code_markers in _FRAMEWORKS:
        hit = False
        for fm in file_markers:
            if any(n.startswith(fm) for n in ctx.namelist):
                for cm in code_markers:
                    if cm in file_blob or any(cm in n for n in names_lower) \
                            or cm.lower() in file_blob.lower():
                        hit = True
                        break
        # also check raw class markers directly
        if not hit:
            for cm in code_markers:
                if cm.endswith("/") and _has_class_prefix(class_names, cm):
                    hit = True
                    break
        frameworks[label] = hit

    # --- libraries
    libs = []
    for name, prefix in _LIBS.items():
        if _has_class_prefix(class_names, prefix):
            libs.append(name)

    # --- sdk / version
    try:
        min_sdk = a.get_min_sdk_version()
        target_sdk = a.get_target_sdk_version()
        version_name = a.get_androidversion_name()
        version_code = a.get_androidversion_code()
        app_name = a.get_app_name()
    except Exception:
        min_sdk = target_sdk = version_name = version_code = app_name = None
    try:
        max_sdk = a.get_max_sdk_version()
    except Exception:
        max_sdk = None

    db.meta.update({
        "app_name": app_name or "(unknown)",
        "package": ctx.package,
        "main_activity": ctx.main_activity,
        "version_name": version_name,
        "version_code": version_code,
        "min_sdk": min_sdk,
        "target_sdk": target_sdk,
        "max_sdk": max_sdk,
        "file_size": ctx.file_size,
        "hashes": ctx.hashes,
    })

    db.set_section("fingerprint", {
        "frameworks": frameworks,
        "libraries": sorted(libs),
        "native_libraries": [n.split("/")[-1] for n in ctx.native_libs],
        "abis": ctx.abis,
        "crypto_libs_present": [p for p in _CRYPTO_LIBS
                                if _has_class_prefix(class_names, p)],
        "class_count": len(class_names),
    })

    # --- a couple of fingerprint-derived informational findings
    if target_sdk is not None and target_sdk < 30:
        db.finding(
            id="fp-old-target-sdk",
            title=f"Low targetSdkVersion ({target_sdk})",
            severity=Severity.LOW,
            confidence=Confidence.HIGH,
            category="fingerprint",
            description=(
                "App targets an older SDK level, which can opt it out of newer "
                "platform security defaults (scoped storage, stricter component "
                "export rules, cleartext restrictions, etc.)."
            ),
            evidence=[Evidence("AndroidManifest.xml",
                               f"targetSdkVersion={target_sdk}")],
            recommendation="Review which modern platform protections are not "
                           "enforced at this target level.",
        )

    if native_present and not libs:
        db.finding(
            id="fp-native-heavy",
            title="Native code present",
            severity=Severity.INFO,
            confidence=Confidence.HIGH,
            category="fingerprint",
            description="App ships native libraries; some security logic may "
                        "live in .so files and require native-level review.",
            evidence=[Evidence("lib/", ", ".join(
                n.split("/")[-1] for n in ctx.native_libs[:10]))],
        )

"""Firebase analysis: URLs, google-services.json config, and (optional) a live
public-readability check of the Realtime Database (like MobSF).

The live check appends /.json to each Realtime DB URL. A world-readable DB
returns data / "null" with HTTP 200; a locked one returns 401/403. It runs on
the machine executing the tool, is best-effort, and never fails the analysis.
Disable it with env MOBSENTRY_FIREBASE_LIVE=0.
"""
from __future__ import annotations

import json
import os
import re
import urllib.request

from .apkctx import APKContext
from .evidence import Confidence, Evidence, EvidenceDB, Severity

RTDB_RE = re.compile(r"https://[a-z0-9][a-z0-9.\-]*\.(?:firebaseio\.com|"
                     r"firebasedatabase\.app)", re.I)
STORAGE_RE = re.compile(r"[a-z0-9][a-z0-9.\-]*\.appspot\.com", re.I)
STORAGE_API_RE = re.compile(
    r"https://firebasestorage\.googleapis\.com/[^\s\"'<>]+", re.I)
FIRESTORE_RE = re.compile(r"https://firestore\.googleapis\.com/[^\s\"'<>]+", re.I)

# strings.xml / resource keys that hold Firebase config
CONFIG_KEYS = ("firebase_database_url", "google_api_key", "google_app_id",
               "gcm_defaultSenderId", "project_id", "google_storage_bucket",
               "default_web_client_id", "google_crash_reporting_api_key")


def _live_check(url: str) -> dict:
    probe = url.rstrip("/") + "/.json"
    try:
        req = urllib.request.Request(probe, headers={"User-Agent": "MobSentry"})
        with urllib.request.urlopen(req, timeout=6) as r:
            body = r.read(2048).decode("utf-8", "replace")
            return {"status": r.status, "exposed": r.status == 200,
                    "sample": body[:200]}
    except urllib.error.HTTPError as e:  # 401/403 = locked (good)
        return {"status": e.code, "exposed": False, "sample": ""}
    except Exception as e:  # noqa: BLE001 - network blocked / offline
        return {"status": None, "exposed": None, "error": str(e)[:120]}

def _run(ctx: APKContext, db: EvidenceDB) -> None:
    blob_parts = list(ctx.dex_strings)
    # scan resources / assets / json for config too
    for name in ctx.namelist:
        if name.endswith((".json", ".xml", ".properties", ".js")):
            raw = ctx.read_raw(name)
            if raw and len(raw) < 3_000_000:
                blob_parts.append(raw.decode("utf-8", "replace"))
    blob = "\n".join(blob_parts)

    rtdb = sorted(set(m.group().rstrip("/") for m in RTDB_RE.finditer(blob)))
    storage_buckets = sorted(set(STORAGE_RE.findall(blob)))
    storage_urls = sorted(set(STORAGE_API_RE.findall(blob)))
    firestore = sorted(set(FIRESTORE_RE.findall(blob)))

    # google-services.json
    gservices = {}
    for name in ctx.namelist:
        if name.endswith("google-services.json"):
            try:
                data = json.loads(ctx.read_text(name))
                pi = data.get("project_info", {})
                gservices = {
                    "file": name,
                    "project_id": pi.get("project_id"),
                    "firebase_url": pi.get("firebase_url"),
                    "storage_bucket": pi.get("storage_bucket"),
                    "project_number": pi.get("project_number"),
                }
                if pi.get("firebase_url"):
                    rtdb = sorted(set(rtdb + [pi["firebase_url"].rstrip("/")]))
            except Exception as exc:  # noqa: BLE001
                db.note_error("firebase.google-services", exc)

    # config values pulled from strings.xml (androguard resolves resources)
    config_values = {}
    try:
        a = ctx.a
        for key in CONFIG_KEYS:
            try:
                val = a.get_android_resources().get_resolved_strings()  # noqa
            except Exception:
                val = None
        # simpler: regex the key/value out of resources already in blob
    except Exception:
        pass
    for key in CONFIG_KEYS:

def _callers_evidence(entries, cap=10):
    ev = []
    for e in entries[:cap]:
        callers = ", ".join(c.split("->")[0].strip("L;").replace("/", ".")
                            for c in e["callers"][:4]) or "(no direct caller)"
        ev.append(Evidence("classes.dex",
                           e["target"], detail=f"called from: {callers}"))
    return ev

def _run(ctx: APKContext, db: EvidenceDB) -> None:
    section = {}

    # ---------------- WebView ----------------
    webview_checks = [
        ("setJavaScriptEnabled", Severity.LOW,
         "JavaScript enabled in WebView",
         "JavaScript is enabled; combined with untrusted content or "
         "addJavascriptInterface this widens attack surface."),
        ("setAllowFileAccess", Severity.MEDIUM,
         "WebView file access",

        ("setAllowUniversalAccessFromFileURLs", Severity.HIGH,
         "WebView universal access from file URLs",
         "Universal access from file URLs allows file-scheme pages to read "
         "arbitrary origins — serious if any untrusted content loads."),
        ("setAllowFileAccessFromFileURLs", Severity.MEDIUM,
         "WebView file access from file URLs",
         "file:// pages can access other file:// origins."),
        ("addJavascriptInterface", Severity.HIGH,
         "WebView JavaScript interface bridge",
         "addJavascriptInterface exposes native methods to JS; on vulnerable "
         "content this can lead to RCE within the app context."),
        ("setMixedContentMode", Severity.LOW,
         "WebView mixed content mode set",
         "Mixed-content handling configured — verify it is not "
         "ALWAYS_ALLOW."),
    ]
    wv_section = []
    for method, sev, title, desc in webview_checks:
        entries = find_method_callers(ctx, classname="Landroid/webkit/",
                                      methodname=method)
        if not entries:
            # some are on WebSettings subclasses; broaden
            entries = find_method_callers(ctx, methodname=method)
        if entries:
            wv_section.append({"api": method, "count": len(entries)})
            db.finding(
                id=f"webview-{method.lower()}",
                title=title, severity=sev, confidence=Confidence.MEDIUM,
                category="webview", description=desc,
                evidence=_callers_evidence(entries),
                recommendation="Confirm the WebView only loads trusted content "
                               "and the setting is required.",
            )
    section["webview"] = wv_section

    crypto_section = []
    # weak cipher modes / algos via string literals passed to Cipher.getInstance
    weak_algo_strings = [s for s in ctx.dex_strings
                         if s.upper() in ("DES", "DES/ECB/PKCS5PADDING",
                                          "RC4", "RC2", "BLOWFISH")
                         or "/ECB/" in s.upper()
                         or s.upper().startswith("AES/ECB")
                         or s.upper() in ("MD5", "SHA1", "SHA-1")]
    if weak_algo_strings:
        uniq = sorted(set(weak_algo_strings))
        ecb = [s for s in uniq if "ECB" in s.upper()]
        if ecb:

                id="crypto-ecb",

                severity=Severity.MEDIUM, confidence=Confidence.MEDIUM,
                category="crypto",

                recommendation="Use authenticated modes (AES/GCM) and trace "
                               "where these transformations are used.",

                title="Weak hash algorithm reference (MD5/SHA-1)",
                severity=Severity.LOW, confidence=Confidence.LOW,

                            "checksums).",
                evidence=[Evidence("classes.dex (string)", s)
                          for s in weak_hash[:10]],
                recommendation="Confirm these are not used for security.",
            )
        crypto_section = uniq

    # insecure PRNG
    prng = find_method_callers(ctx, classname="Ljava/util/Random")
    math_random = find_method_callers(ctx, classname="Ljava/lang/Math",
                                      methodname="random")
    if prng or math_random:
        ev = _callers_evidence(prng + math_random)
        db.finding(
            id="crypto-weak-prng",
            title="Use of non-cryptographic PRNG",
            severity=Severity.LOW, confidence=Confidence.LOW,
            category="crypto",

            recommendation="Use SecureRandom for any security-sensitive value.",
        )

    # SecretKeySpec with hardcoded bytes is hard to prove statically; note usage
    section["crypto_transformations"] = crypto_section

    # ---------------- Logging ----------------
    log_entries = find_method_callers(ctx, classname="Landroid/util/Log")
    sout = find_method_callers(ctx, classname="Ljava/io/PrintStream",
                               methodname="println")
    total_logs = len(log_entries) + len(sout)
    section["logging_call_sites"] = total_logs
    if total_logs:
        db.finding(
            id="logging-present",
            title=f"Logging API used ({total_logs} call site group(s))",
            severity=Severity.INFO, confidence=Confidence.LOW,
            category="logging",
            description="android.util.Log / System.out used. Review whether "
                        "sensitive values (tokens, PII, crypto material) flow "
                        "into logs, which are readable in debug / via logcat on "
                        "some setups.",
            evidence=_callers_evidence(log_entries + sout, cap=12),
            recommendation="Grep the calling methods for sensitive variables; "
                           "strip logs from release builds.",
        )

    # ---------------- Storage ----------------
    storage = []
    # MODE_WORLD_READABLE/WRITEABLE are ints 1/2; look for getSharedPreferences
    sp = find_method_callers(ctx, methodname="getSharedPreferences")
    ext = find_method_callers(ctx, methodname="getExternalStorageDirectory")
    ext += find_method_callers(ctx, methodname="getExternalFilesDir")
    if sp:
        storage.append({"api": "getSharedPreferences", "count": len(sp)})
    if ext:
        storage.append({"api": "externalStorage", "count": len(ext)})
        db.finding(
            id="storage-external",
            title="External storage used",
            severity=Severity.LOW, confidence=Confidence.LOW,
            category="storage",
            description="External storage is world-readable on older setups and "
                        "shared; sensitive data there is exposed.",
            evidence=_callers_evidence(ext),
            recommendation="Keep sensitive data in app-internal storage / "
                           "EncryptedFile.",
        )
    section["storage"] = storage

    db.set_section("insecure", section)

                               "production release.",
            )

    # Backup rule files referenced
    for attr in ("fullBackupContent", "dataExtractionRules",
                 "networkSecurityConfig"):
        val = _app_attr(a, attr)
        flags[attr] = val

    # extractNativeLibs / legacy storage are informational context
    for attr in ("extractNativeLibs", "requestLegacyExternalStorage"):
        flags[attr] = _app_attr(a, attr)

    db.set_section("manifest_flags", flags)

    # custom permissions declared with weak protection level
    try:
        for p in a.get_declared_permissions():
            # androguard returns names; protection levels need xml parse
            pass
    except Exception:
        pass

    # Parse declared <permission> protectionLevel from manifest XML
    try:
        root = a.get_android_manifest_xml()
        weak = []
        for perm in root.findall("permission"):
            name = perm.get(f"{{{ANDROID_NS}}}name")
            level = perm.get(f"{{{ANDROID_NS}}}protectionLevel") or "normal"
            if "signature" not in level and "privileged" not in level:
                weak.append((name, level))
        if weak:
            ev = [Evidence("AndroidManifest.xml",
                           f'{n} protectionLevel="{l}"') for n, l in weak[:20]]

                recommendation="Check whether components rely on these "

"""Network Security Config analysis.

Locates the referenced @xml/network_security_config, parses it, and reports on
cleartext, trust anchors, user certs, debug overrides, and pin-sets with the

from __future__ import annotations

from .apkctx import APKContext

ANDROID_NS = "http://schemas.android.com/apk/res/android"


def _find_nsc_file(ctx: APKContext) -> tuple[str, str]:
    """Return (resource_name, xml_text) for the NSC, or ('','')."""
    a = ctx.a
    ref = None
    try:
        ref = a.get_attribute_value("application", "networkSecurityConfig")
    except Exception:
        ref = None
    # Candidate files: the referenced one (by basename) or well-known names.
    candidates = ctx.files_matching("res/", suffix=".xml")
    wanted = []
    if ref and "/" in str(ref):
        wanted.append(str(ref).split("/")[-1] + ".xml")
    wanted += ["network_security_config.xml", "nsc.xml", "network_security.xml"]
    for name in candidates:
        base = name.split("/")[-1]
        if base in wanted:
            txt = ctx.read_text(name)
            if "<network-security-config" in txt:
                return name, txt
    # last resort: scan all res xml for the root element
    for name in candidates:
        txt = ctx.read_text(name)
        if "<network-security-config" in txt:
            return name, txt
    return "", ""

def _run(ctx: APKContext, db: EvidenceDB) -> None:
    name, xml = _find_nsc_file(ctx)
    if not xml:
        db.set_section("netsec", {"present": False})
        # No NSC on modern target + cleartext default note handled in manifest.
        return

        "file": name,

        "debug_overrides": False,

        "pins_present": False,

        return None if v is None else v.lower() == "true"

            summary["pins_present"] = True

                summary["user_certs_trusted"] = True

"""Obfuscation detection with evidence.

Heuristic over the app's own classes (filtered to the package): ProGuard/R8
rename classes/methods to very short names (a, b, aa, a.a.a). We measure the
share of short simple-names and single-letter package segments and report
either way — obfuscated (with sample renamed symbols) or not (with sample
readable names). No finding is left unstated.
"""
from __future__ import annotations

import re

from .apkctx import APKContext
from .evidence import Confidence, Evidence, EvidenceDB, Severity

LIB_PREFIXES = ("Landroid/", "Landroidx/", "Lkotlin/", "Lkotlinx/", "Ljava/",
                "Ljavax/", "Lcom/google/", "Lorg/", "Lio/", "Lcom/android/",
                "Ldagger/", "Lretrofit2/", "Lokhttp3/", "Lokio/")

SHORT_NAME_RE = re.compile(r"^[a-z]{1,2}[0-9]?$")


def _simple_name(cls: str) -> str:
    c = cls.strip("L;")
    return c.split("/")[-1]


def run(ctx: APKContext, db: EvidenceDB) -> None:
    try:
        _run(ctx, db)
    except Exception as exc:  # noqa: BLE001
        db.note_error("obfuscation", exc)


def _run(ctx: APKContext, db: EvidenceDB) -> None:
    all_classes = list(ctx.iter_class_names())
    pkg_prefix = "L" + ctx.package.replace(".", "/") if ctx.package else None

    # focus on the app's own classes; fall back to non-library classes
    app_classes = []
    for c in all_classes:
        if c.startswith(LIB_PREFIXES):
            continue
        if pkg_prefix and not c.startswith(pkg_prefix):
            # still include other first-party-looking classes
            pass
        app_classes.append(c)
    if not app_classes:
        app_classes = [c for c in all_classes if not c.startswith(LIB_PREFIXES)]

    total = len(app_classes)
    if total == 0:
        db.set_section("obfuscation", {"analyzable": False})
        return

    short = [c for c in app_classes if SHORT_NAME_RE.match(_simple_name(c))]
    # single-letter package segments e.g. Lx/y/z;
    single_seg = [c for c in app_classes
                  if any(len(seg) == 1 for seg in c.strip("L;").split("/")[:-1])]

    short_ratio = len(short) / total
    seg_ratio = len(single_seg) / total if total else 0
    score = max(short_ratio, seg_ratio)

    obfuscated = score >= 0.3
    if score >= 0.6:
        level, conf = "heavy", Confidence.HIGH
    elif score >= 0.3:
        level, conf = "partial", Confidence.MEDIUM
    else:
        level, conf = "none/minimal", Confidence.MEDIUM

    samples_obf = [_sn for _sn in (_simple_name(c) for c in short)][:12]
    samples_read = [c.strip("L;").replace("/", ".")
                    for c in app_classes if not SHORT_NAME_RE.match(_simple_name(c))][:12]

    db.set_section("obfuscation", {
        "analyzable": True,
        "obfuscated": obfuscated,
        "level": level,
        "short_name_ratio": round(short_ratio, 3),
        "single_seg_ratio": round(seg_ratio, 3),
        "app_class_count": total,
        "short_name_examples": samples_obf,
        "readable_examples": samples_read,
    })

    if obfuscated:
        db.finding(
            id="obfuscation-present",
            title=f"Code appears obfuscated ({level}, "
                  f"{round(score * 100)}% short symbols)",
            severity=Severity.INFO, confidence=conf,
            category="obfuscation",
            description="A large share of the app's own classes use "
                        "ProGuard/R8-style short names, indicating obfuscation. "
                        "This raises reverse-engineering effort but is not a "
                        "vulnerability by itself.",
            evidence=[Evidence("classes.dex",
                               ", ".join(samples_obf) or "(renamed symbols)",
                               detail=f"{len(short)}/{total} classes with 1-2 "
                                      "char names")],
            recommendation="Note which packages remain readable (often the "
                           "security-relevant ones kept via -keep rules).",
        )
    else:
        db.finding(
            id="obfuscation-absent",
            title="Code is not obfuscated (readable symbol names)",
            severity=Severity.LOW, confidence=conf,
            category="obfuscation",
            description="Most class/method names are human-readable, so the app "
                        "is easy to reverse engineer. Consider enabling R8/"
                        "ProGuard for release builds.",
            evidence=[Evidence("classes.dex",
                               ", ".join(samples_read) or "(readable names)",
                               detail=f"only {round(score * 100)}% short names")],
            recommendation="Enable minification/obfuscation for release.",
        )

"""Permission categorization + interesting-combination flagging."""
from __future__ import annotations

from .apkctx import APKContext
from .evidence import Confidence, Evidence, EvidenceDB, Severity

# Small built-in map of common dangerous / special permissions. androguard can
# also provide descriptions; this keeps categorization deterministic & offline.
DANGEROUS = {
    "READ_SMS", "RECEIVE_SMS", "SEND_SMS", "READ_CONTACTS", "WRITE_CONTACTS",
    "READ_CALL_LOG", "WRITE_CALL_LOG", "READ_PHONE_STATE", "READ_PHONE_NUMBERS",
    "CALL_PHONE", "CAMERA", "RECORD_AUDIO", "ACCESS_FINE_LOCATION",
    "ACCESS_COARSE_LOCATION", "ACCESS_BACKGROUND_LOCATION",
    "READ_EXTERNAL_STORAGE", "WRITE_EXTERNAL_STORAGE", "READ_CALENDAR",
    "WRITE_CALENDAR", "BODY_SENSORS", "GET_ACCOUNTS", "READ_MEDIA_IMAGES",
    "READ_MEDIA_VIDEO", "READ_MEDIA_AUDIO", "POST_NOTIFICATIONS",
    "ACTIVITY_RECOGNITION",
}
SPECIAL = {
    "SYSTEM_ALERT_WINDOW", "REQUEST_INSTALL_PACKAGES", "MANAGE_EXTERNAL_STORAGE",
    "BIND_ACCESSIBILITY_SERVICE", "WRITE_SETTINGS", "SCHEDULE_EXACT_ALARM",
    "BIND_DEVICE_ADMIN", "PACKAGE_USAGE_STATS", "QUERY_ALL_PACKAGES",
}

# Interesting combinations: (set of perms, title, note, severity)
COMBOS = [
    ({"READ_SMS", "INTERNET"}, "SMS access + network",
     "App can read SMS and reach the network — investigate for OTP/credential "
     "exfiltration paths.", Severity.MEDIUM),
    ({"RECEIVE_SMS", "INTERNET"}, "SMS receive + network",
     "App can intercept incoming SMS and reach the network.", Severity.MEDIUM),
    ({"ACCESSIBILITY_SERVICE"}, "Accessibility service",
     "Accessibility can observe/act on other apps' UI — high-value capability.",
     Severity.MEDIUM),
    ({"SYSTEM_ALERT_WINDOW", "INTERNET"}, "Overlay + network",
     "Overlay capability combined with network — overlay-attack surface.",
     Severity.MEDIUM),
    ({"REQUEST_INSTALL_PACKAGES"}, "Can request package installs",
     "App can prompt to install APKs — review update/sideload flows.",
     Severity.MEDIUM),
    ({"QUERY_ALL_PACKAGES"}, "Queries all installed packages",
     "Broad package visibility; used legitimately but also by profiling/anti- "
     "tamper logic.", Severity.LOW),
]


def _short(p: str) -> str:
    return p.rsplit(".", 1)[-1]


def run(ctx: APKContext, db: EvidenceDB) -> None:
    try:
        _run(ctx, db)
    except Exception as exc:  # noqa: BLE001
        db.note_error("permissions", exc)


def _run(ctx: APKContext, db: EvidenceDB) -> None:
    a = ctx.a
    perms = sorted(set(a.get_permissions() or []))
    shorts = {_short(p) for p in perms}

    categorized = {"dangerous": [], "special": [], "normal": [], "custom": []}
    for p in perms:
        s = _short(p)
        if s in DANGEROUS:
            categorized["dangerous"].append(p)
        elif s in SPECIAL:
            categorized["special"].append(p)
        elif p.startswith("android.permission."):
            categorized["normal"].append(p)
        else:
            categorized["custom"].append(p)

    db.set_section("permissions", {
        "all": perms,
        "categorized": categorized,
        "counts": {k: len(v) for k, v in categorized.items()},
    })

    for combo, title, note, sev in COMBOS:
        if combo <= shorts:
            db.finding(
                id="perm-combo-" + "-".join(sorted(_short(c) for c in combo)),
                title="Permission combination: " + title,
                severity=sev,
                confidence=Confidence.MEDIUM,
                category="permissions",
                description=note,
                evidence=[Evidence("AndroidManifest.xml",
                                   ", ".join(sorted(combo)))],
                recommendation="Investigation priority — not automatically a "
                               "vulnerability.",
            )

    if categorized["special"]:
        db.finding(
            id="perm-special",
            title=f"{len(categorized['special'])} special/high-power "
                  "permission(s) requested",
            severity=Severity.LOW,
            confidence=Confidence.HIGH,
            category="permissions",
            description="Special permissions grant capabilities beyond the "
                        "normal/dangerous model and deserve review.",
            evidence=[Evidence("AndroidManifest.xml", p)
                      for p in categorized["special"]],
        )

"""Generate a full PDF report from a report data dict (reportlab).

Contains every detail: file/app info, security score, attack surface, all
section summaries, and every finding with its evidence. The reportlab import is
lazy so the rest of the app runs even if reportlab isn't installed.
"""
from __future__ import annotations

import io
from typing import Any

SEV_HEX = {"high": "#c0392b", "medium": "#d68910", "low": "#2471a3",
           "info": "#5d6d7e"}


def _esc(s: Any) -> str:
    return (str(s if s is not None else "")
            .replace("&", "&amp;").replace("<", "&lt;").replace(">", "&gt;"))


def build_pdf(data: dict[str, Any]) -> bytes:
    from reportlab.lib import colors
    from reportlab.lib.pagesizes import A4
    from reportlab.lib.styles import ParagraphStyle, getSampleStyleSheet
    from reportlab.lib.units import mm
    from reportlab.platypus import (HRFlowable, Paragraph, SimpleDocTemplate,
                                    Spacer, Table, TableStyle)

    meta = data.get("meta", {})
    counts = data.get("counts", {})
    sections = data.get("sections", {})
    findings = data.get("findings", [])

    buf = io.BytesIO()
    doc = SimpleDocTemplate(buf, pagesize=A4, topMargin=16 * mm,
                            bottomMargin=16 * mm, leftMargin=16 * mm,
                            rightMargin=16 * mm, title="MobSentry Report")
    ss = getSampleStyleSheet()
    H1 = ParagraphStyle("H1", parent=ss["Title"], fontSize=20, spaceAfter=2,
                        textColor=colors.HexColor("#1a2634"))
    SUB = ParagraphStyle("SUB", parent=ss["Normal"], fontSize=9,
                         textColor=colors.HexColor("#7f8c8d"), spaceAfter=10)
    H2 = ParagraphStyle("H2", parent=ss["Heading2"], fontSize=13,
                        textColor=colors.HexColor("#21618c"), spaceBefore=12,
                        spaceAfter=4)
    H3 = ParagraphStyle("H3", parent=ss["Heading3"], fontSize=10.5,
                        textColor=colors.HexColor("#34495e"), spaceBefore=6)
    BODY = ParagraphStyle("BODY", parent=ss["Normal"], fontSize=9, leading=12)
    SMALL = ParagraphStyle("SMALL", parent=ss["Normal"], fontSize=7.5,
                           leading=9.5, textColor=colors.HexColor("#555"))
    MONO = ParagraphStyle("MONO", parent=ss["Code"], fontSize=7, leading=9,
                          textColor=colors.HexColor("#2c3e50"))

    story = []

    def kv_table(rows, widths=(45 * mm, 120 * mm)):
        t = Table([[Paragraph(f"<b>{_esc(k)}</b>", SMALL), Paragraph(_esc(v), BODY)]
                   for k, v in rows], colWidths=widths)
        t.setStyle(TableStyle([
            ("VALIGN", (0, 0), (-1, -1), "TOP"),
            ("BOTTOMPADDING", (0, 0), (-1, -1), 3),
            ("TOPPADDING", (0, 0), (-1, -1), 3),
            ("LINEBELOW", (0, 0), (-1, -1), 0.3, colors.HexColor("#e5e8e8")),
        ]))
        return t

    # ---- header
    story.append(Paragraph("MobSentry — Security Report", H1))
    story.append(Paragraph("Deterministic static analysis of an Android APK",
                           SUB))

    # ---- score banner
    score = meta.get("security_score", "—")
    grade = meta.get("security_grade", "—")
    banner = Table([[
        Paragraph(f"<b>Security score</b><br/><font size=18>{_esc(score)}/100 "
                  f"({_esc(grade)})</font>", BODY),
        Paragraph(f"<font color='{SEV_HEX['high']}'><b>{counts.get('high', 0)} High</b></font> &nbsp; "
                  f"<font color='{SEV_HEX['medium']}'><b>{counts.get('medium', 0)} Medium</b></font> &nbsp; "
                  f"<font color='{SEV_HEX['low']}'><b>{counts.get('low', 0)} Low</b></font> &nbsp; "
                  f"<font color='{SEV_HEX['info']}'>{counts.get('info', 0)} Info</font>", BODY),
    ]], colWidths=(70 * mm, 95 * mm))
    banner.setStyle(TableStyle([
        ("BOX", (0, 0), (-1, -1), 0.5, colors.HexColor("#d5dbdb")),
        ("BACKGROUND", (0, 0), (-1, -1), colors.HexColor("#f7f9f9")),
        ("VALIGN", (0, 0), (-1, -1), "MIDDLE"),
        ("LEFTPADDING", (0, 0), (-1, -1), 10),
        ("TOPPADDING", (0, 0), (-1, -1), 8),
        ("BOTTOMPADDING", (0, 0), (-1, -1), 8),
    ]))
    story.append(banner)
    story.append(Spacer(1, 6))

    # ---- file information
    h = meta.get("hashes", {}) or {}
    size = meta.get("file_size") or 0
    story.append(Paragraph("File information", H2))
    story.append(kv_table([
        ("File name", data.get("filename", "")),
        ("Size", f"{round(size / 1048576, 2)} MB" if size else "—"),
        ("MD5", h.get("md5", "")),
        ("SHA1", h.get("sha1", "")),
        ("SHA256", h.get("sha256", "")),
    ]))

    # ---- app information
    story.append(Paragraph("Application information", H2))
    story.append(kv_table([
        ("App name", meta.get("app_name", "")),
        ("Package", meta.get("package", "")),
        ("Main activity", meta.get("main_activity", "")),
        ("Version", f"{meta.get('version_name', '')} "
                    f"({meta.get('version_code', '')})"),
        ("Min / Target / Max SDK", f"{meta.get('min_sdk', '')} / "
         f"{meta.get('target_sdk', '')} / {meta.get('max_sdk', '') or '—'}"),
    ]))

    # ---- fingerprint
    fp = sections.get("fingerprint", {})
    if fp:
        story.append(Paragraph("Fingerprint", H2))
        fw = ", ".join(k for k, v in (fp.get("frameworks") or {}).items() if v)
        story.append(kv_table([
            ("Frameworks", fw),
            ("ABIs", ", ".join(fp.get("abis", []))),
            ("Libraries", ", ".join(fp.get("libraries", []))),
            ("Native libs", ", ".join(fp.get("native_libraries", []))),
        ]))

    # ---- attack surface
    as_ = meta.get("attack_surface", {})
    if as_:
        story.append(Paragraph("Attack surface", H2))
        story.append(kv_table([(k.replace("_", " ").title(), v)
                               for k, v in as_.items()]))

    # ---- signing / obfuscation / trackers quick facts
    sg = sections.get("signing", {})
    if sg:
        story.append(Paragraph("Signing", H2))
        story.append(kv_table([
            ("Schemes", ", ".join(k for k, v in (sg.get("schemes") or {}).items() if v) or "none"),
            ("Debug certificate", "YES" if sg.get("debug_certificate") else "no"),
            ("Weak algorithms", ", ".join(sg.get("weak_signature_algos", [])) or "none"),
        ]))
    ob = sections.get("obfuscation", {})
    if ob.get("analyzable"):
        story.append(Paragraph("Obfuscation", H2))
        story.append(kv_table([
            ("Obfuscated", f"{'YES' if ob.get('obfuscated') else 'NO'} "
                           f"({ob.get('level', '')})"),
            ("Short-name ratio", f"{round(ob.get('short_name_ratio', 0) * 100)}%"),
        ]))
    fb = sections.get("firebase", {})
    if fb.get("present"):
        story.append(Paragraph("Firebase", H2))
        checks = fb.get("live_checks", {})
        rows = [("Realtime DB", u + ("  [PUBLICLY READABLE]"
                if checks.get(u, {}).get("exposed") else ""))
                for u in fb.get("realtime_db", [])]
        rows += [("Storage bucket", b) for b in fb.get("storage_buckets", [])]
        story.append(kv_table(rows or [("Firebase", "config present")]))
    tr = sections.get("trackers", {})
    if tr.get("count"):
        story.append(Paragraph("Trackers", H2))
        story.append(Paragraph(", ".join(t["name"] for t in tr.get("trackers", [])),
                               BODY))

    # ---- all findings
    story.append(Spacer(1, 6))
    story.append(HRFlowable(width="100%", color=colors.HexColor("#d5dbdb")))
    story.append(Paragraph(f"Findings ({len(findings)})", H2))
    for f in findings:
        sev = f.get("severity", "info")
        hexc = SEV_HEX.get(sev, "#5d6d7e")
        story.append(Paragraph(
            f"<font color='{hexc}'><b>[{_esc(sev.upper())}]</b></font> "
            f"<b>{_esc(f.get('title'))}</b> "
            f"<font size=7 color='#95a5a6'>· {_esc(f.get('confidence'))} · "
            f"{_esc(f.get('category'))}</font>", H3))
        story.append(Paragraph(_esc(f.get("description")), BODY))
        if f.get("affected_component"):
            story.append(Paragraph(f"<b>Component:</b> {_esc(f['affected_component'])}",
                                   SMALL))
        if f.get("recommendation"):
            story.append(Paragraph(f"<b>Validate:</b> {_esc(f['recommendation'])}",
                                   SMALL))
        surfaces = (f.get("extra") or {}).get("surfaces")
        if surfaces:
            for k, v in surfaces.items():
                story.append(Paragraph(f"&bull; <b>{_esc(k)}</b> → {_esc(v)}", SMALL))
        for e in (f.get("evidence") or [])[:12]:
            loc = _esc(e.get("location"))
            det = f" — {_esc(e.get('detail'))}" if e.get("detail") else ""
            story.append(Paragraph(f"<b>{loc}</b>{det}", SMALL))
            story.append(Paragraph(_esc(e.get("snippet"))[:600], MONO))
        story.append(Spacer(1, 4))
        story.append(HRFlowable(width="100%", color=colors.HexColor("#eef2f3")))

    if not findings:
        story.append(Paragraph("No findings.", BODY))

    # ---- bypass / interception guidance
    by = sections.get("bypass", {})
    groups = [("SSL / interception", by.get("ssl", [])),
              ("Root-detection bypass", by.get("root", [])),
              ("Jailbreak bypass", by.get("jailbreak", []))]
    if any(g[1] for g in groups):
        story.append(Spacer(1, 6))
        story.append(Paragraph("Bypass / interception guidance "
                               "(authorized testing only)", H2))
        for gname, methods in groups:
            if not methods:
                continue
            story.append(Paragraph(gname, H3))
            for mth in methods:
                story.append(Paragraph(
                    f"<b>{_esc(mth.get('name'))}</b> — {_esc(mth.get('applies'))}",
                    BODY))
                if mth.get("objection"):
                    story.append(Paragraph("objection: " + _esc(mth["objection"]),
                                           MONO))
                for s in mth.get("steps", [])[:4]:
                    story.append(Paragraph("• " + _esc(s), SMALL))
        story.append(Paragraph("Full Frida scripts are available in the web "
                               "report's SSL Pinning / Root / Jailbreak tabs.",
                               SMALL))

    story.append(Spacer(1, 8))
    story.append(Paragraph(
        f"Generated by MobSentry · analysis time {meta.get('analysis_seconds', '')}s",
        SUB))

    doc.build(story)
    return buf.getvalue()

"""Root detection analysis.

Goes beyond "root detection exists": enumerates the techniques present, scores
confidence, names the methods that implement them, tries to tell whether the
result is enforced vs only logged, and maps each mechanism to the *category of
surface* a tester would need to validate (not a working bypass).
"""
from __future__ import annotations

from .apkctx import APKContext
from .dexutil import find_method_callers, find_string_users
from .evidence import Confidence, Evidence, EvidenceDB, Severity

# technique key -> (list of string indicators, human label, bypass-surface)
TECHNIQUES = {
    "su_binary": (
        ["/system/xbin/su", "/system/bin/su", "/sbin/su", "/su/bin/su",
         "/system/app/Superuser.apk", "su"],
        "su binary / Superuser path checks",
        "File existence — validated by observing file-system checks at runtime."),
    "build_tags": (
        ["test-keys", "ro.build.tags", "ro.debuggable"],
        "Build tags / system property inspection",
        "Build/system property reads — validated at the property-source level."),
    "magisk": (
        ["magisk", "/sbin/.magisk", "com.topjohnwu.magisk", "MagiskSU"],
        "Magisk artifact checks",
        "Artifact visibility — depends on how artifacts are enumerated."),
    "root_packages": (
        ["com.noshufou.android.su", "com.thirdparty.superuser", "eu.chainfire.supersu",
         "com.koushikdutta.superuser", "com.zachspong.temprootremovejb",
         "com.ramdroid.appquarantine", "com.chelpus.lackypatch"],
        "Known root-manager package checks",
        "Package-manager queries — depends on package visibility."),
    "busybox": (
        ["busybox", "/system/xbin/busybox"],
        "busybox presence checks",
        "File existence — same surface as su checks."),
    "rootbeer": (
        ["com/scottyab/rootbeer", "rootbeer"],
        "RootBeer library",
        "Library-based checks aggregating several of the above surfaces."),
    "which_su": (
        ["which su", "/system/bin/which"],
        "which/command execution probes",
        "Process execution — observable where the command is invoked."),
}

ENFORCE_HINTS = ("finish", "exit", "kill", "block", "terminate", "System.exit",
                 "killProcess", "crash")


def run(ctx: APKContext, db: EvidenceDB) -> None:
    try:
        _run(ctx, db)
    except Exception as exc:  # noqa: BLE001
        db.note_error("rootdetect", exc)


def _run(ctx: APKContext, db: EvidenceDB) -> None:
    detected = {}
    method_names: set = set()
    evidence: list[Evidence] = []

    dex_str_set = None  # lazy
    for key, (indicators, label, surface) in TECHNIQUES.items():
        hits = []
        for ind in indicators:
            users = find_string_users(ctx, ind)
            for u in users:
                hits.append(u)
                for c in u["callers"]:
                    method_names.add(c)
            # class-prefix indicators (rootbeer) also matched via string pool
        # also catch class-name based (rootbeer lib)
        if key in ("rootbeer",):
            from .dexutil import any_class_matches
            if any_class_matches(ctx, r"scottyab/rootbeer|RootBeer"):
                hits.append({"string": "com.scottyab.rootbeer (class)",
                             "callers": []})
        if hits:
            detected[key] = {"label": label, "surface": surface,
                             "indicators": sorted({h["string"] for h in hits})}
            for h in hits[:3]:
                callers = ", ".join(c.split("->")[0].strip("L;").replace("/", ".")
                                    for c in h["callers"][:3])
                evidence.append(Evidence(
                    "classes.dex",
                    h["string"],
                    detail=(f"referenced in: {callers}" if callers else "")))

    # Runtime.exec is a strong co-signal
    exec_calls = find_method_callers(ctx, classname="Ljava/lang/Runtime",
                                     methodname="exec")
    if exec_calls:
        detected.setdefault("runtime_exec", {
            "label": "Runtime.exec() usage",
            "surface": "Process execution — function/API interception point.",
            "indicators": ["Runtime.exec()"]})
        for e in exec_calls:
            for c in e["callers"]:
                method_names.add(c)

    n = len(detected)
    if n == 0:
        db.set_section("rootdetect", {"detected": False})
        return

    confidence = (Confidence.HIGH if n >= 3 else
                  Confidence.MEDIUM if n == 2 else Confidence.LOW)

    # enforced vs log-only heuristic: do the implementing methods / their
    # classes also reference enforcement-like APIs?
    enforced = None
    impl_classes = {m.split("->")[0] for m in method_names}
    if impl_classes:
        exits = find_method_callers(ctx, classname="Ljava/lang/System",
                                    methodname="exit")
        finishes = find_method_callers(ctx, methodname="finishAffinity")
        proc_kill = find_method_callers(ctx, classname="Landroid/os/Process",
                                        methodname="killProcess")
        enforce_callers = set()
        for grp in (exits, finishes, proc_kill):
            for e in grp:
                enforce_callers |= {c.split("->")[0] for c in e["callers"]}
        if impl_classes & enforce_callers:
            enforced = True
        else:
            enforced = False  # heuristic: not obviously enforced near checks

    db.set_section("rootdetect", {
        "detected": True,
        "confidence": confidence.value,
        "technique_count": n,
        "techniques": detected,
        "implementing_methods": sorted(method_names)[:40],
        "enforced_guess": enforced,
    })

    desc = (f"Root detection present using {n} technique(s). "
            + ("Result appears to be enforced (ties to exit/kill/finish in the "
               "same classes)." if enforced else
               "Could not confirm the result is enforced — it may be logged "
               "only; verify the check actually blocks execution."))
    db.finding(
        id="root-detection",
        title=f"Root detection implemented ({n} technique(s))",
        severity=Severity.INFO, confidence=confidence,
        category="root-detection",
        description=desc,
        evidence=evidence[:20],
        recommendation="For each mechanism, confirm it is enforced server-side "
                       "or that bypassing it is in scope; the mechanism→surface "
                       "map in this section lists what to validate.",
        extra={"surfaces": {k: v["surface"] for k, v in detected.items()}},
    )

"""Secret / endpoint scanner across dex strings, resources, assets, libs.

High-signal regexes only (to keep false positives manageable). Each hit is
evidence tied to the location it came from.
"""
from __future__ import annotations

import re
from collections import defaultdict

from .apkctx import APKContext

# (name, severity, compiled regex, is_secret) — apkleaks-style aggressive set

     re.compile(r'(?i)aws(.{0,20})?(secret|private).{0,20}?["\']([A-Za-z0-9/+=]{40})["\']'), True),

     re.compile(r"-----BEGIN (?:RSA |EC |DSA |OPENSSH |PGP |)PRIVATE KEY(?: BLOCK)?-----"), True),
    ("JWT", Severity.MEDIUM,
     re.compile(r"\beyJ[A-Za-z0-9_\-]{8,}\.eyJ[A-Za-z0-9_\-]{8,}\.[A-Za-z0-9_\-]{8,}"), True),

# IPv4 (skip obvious noise like version strings handled below)
IP_RE = re.compile(r"\b(?:(?:25[0-5]|2[0-4]\d|1?\d?\d)\.){3}"
                   r"(?:25[0-5]|2[0-4]\d|1?\d?\d)\b")
_IP_IGNORE = {"0.0.0.0", "127.0.0.1", "255.255.255.255", "1.1.1.1", "8.8.8.8",
              "8.8.4.4"}

# string-pool / file noise we don't want to treat as secrets/urls
_IGNORE_URL_HOSTS = ("schemas.android.com", "www.w3.org", "apache.org",
                     "xmlpull.org", "java.sun.com", "github.com/square",
                     "goo.gl/", "developer.android.com")

_DEV_HINTS = ("staging", "stage", "dev.", "-dev", "test.", "qa.", "uat",
              "internal", "localhost", "10.0.", "192.168.", "debug")


def _scan_text(text: str, location: str, out: dict, seen: set) -> None:
    for name, sev, rx, is_secret in _PATTERNS:
        for m in rx.finditer(text):
            val = m.group().strip()
            if name == "URL" and any(h in val for h in _IGNORE_URL_HOSTS):
                continue
            key = (name, val)
            if key in seen:
                continue
            seen.add(key)
            out[name].append((val, location, sev, is_secret))
            if len(out[name]) > 400:  # safety cap per category
                break
    # IP addresses (separate, informational unless private/internal)
    for m in IP_RE.finditer(text):
        ip = m.group()
        if ip in _IP_IGNORE:
            continue
        # drop version-ish quads where any octet has a leading-zero-free dup noise
        key = ("IP address", ip)
        if key in seen:
            continue
        seen.add(key)
        out["IP address"].append((ip, location, Severity.LOW, False))
        if len(out["IP address"]) > 300:
            break


def run(ctx: APKContext, db: EvidenceDB) -> None:
    try:
        _run(ctx, db)
    except Exception as exc:  # noqa: BLE001
        db.note_error("secrets", exc)


def _run(ctx: APKContext, db: EvidenceDB) -> None:
    out: dict[str, list] = defaultdict(list)
    seen: set = set()

    # 1) dex string pool
    _scan_text("\n".join(ctx.dex_strings), "classes.dex (string pool)", out, seen)

    # 2) text-ish resource / asset / xml files
    scan_targets = ctx.files_matching("res/", "assets/", "AndroidManifest") + \
        [n for n in ctx.namelist if n.endswith((".xml", ".json", ".js",
                                                ".properties", ".txt", ".cfg",
                                                ".plist", ".html"))]
    for name in set(scan_targets):
        raw = ctx.read_raw(name)
        if not raw or len(raw) > 5_000_000:
            continue
        try:
            text = raw.decode("utf-8", "replace")
        except Exception:
            continue
        _scan_text(text, name, out, seen)

    # 3) native libs: extract strings, only look for secret-class patterns
    for lib in ctx.native_libs[:12]:
        raw = ctx.read_raw(lib)
        if not raw or len(raw) > 30_000_000:
            continue
        blob = "\n".join(ctx.extract_strings(raw, minlen=8))
        _scan_text(blob, lib, out, seen)

    # Build section + findings
    urls = [v for (v, loc, sev, sec) in out.get("URL", [])]
    endpoints = sorted({u for u in urls})
    dev_endpoints = [u for u in endpoints if any(h in u.lower() for h in _DEV_HINTS)]
    ips = sorted({v for (v, loc, sev, sec) in out.get("IP address", [])})
    emails = sorted({v for (v, loc, sev, sec) in out.get("Email", [])})

    def _is_private(ip: str) -> bool:
        return (ip.startswith(("10.", "192.168.", "169.254.")) or
                any(ip.startswith(f"172.{n}.") for n in range(16, 32)))
    private_ips = [ip for ip in ips if _is_private(ip)]

    db.set_section("secrets", {
        "endpoint_count": len(endpoints),
        "endpoints": endpoints[:500],
        "dev_endpoints": dev_endpoints,
        "ip_addresses": ips[:300],
        "private_ips": private_ips,
        "emails": emails[:200],
        "categories": {k: len(v) for k, v in out.items()},
    })

    if ips:
        db.finding(
            id="secret-ip-addresses",
            title=f"{len(ips)} IP address(es) hardcoded"
                  + (f" ({len(private_ips)} private/internal)" if private_ips else ""),
            severity=Severity.LOW if private_ips else Severity.INFO,
            confidence=Confidence.MEDIUM,
            category="secrets",
            description="IP addresses embedded in the app. Private/internal IPs "
                        "can leak infrastructure details or point at dev hosts.",
            evidence=[Evidence("APK contents", ip,
                               detail="private/internal" if _is_private(ip) else "")
                      for ip in ips[:30]],
            recommendation="Confirm no internal infrastructure is exposed.",
        )

    for name, hits in out.items():
        if name in ("URL", "Email", "IP address"):
            continue  # informational, surfaced in section not as findings
        is_secret = hits[0][3]
        sev = hits[0][2]
        if not is_secret:
            continue
        ev = [Evidence(loc, (val[:80] + "…") if len(val) > 80 else val)
              for (val, loc, s, sec) in hits[:15]]
        db.finding(
            id=f"secret-{name.lower().replace(' ', '-')}",
            title=f"Possible hardcoded secret: {name} ({len(hits)} hit(s))",
            severity=sev,
            confidence=Confidence.MEDIUM,
            category="secrets",
            description=f"Pattern matching {name} found embedded in the APK. "
                        "Hardcoded secrets can be extracted by anyone with the "
                        "APK; validate whether the value is live/sensitive.",
            evidence=ev,
            recommendation="Confirm whether the value is a real credential and "
                           "rotate/remove it; move secrets server-side.",
        )

    if dev_endpoints:
        db.finding(
            id="secret-dev-endpoints",
            title=f"{len(dev_endpoints)} non-production / internal endpoint(s)",
            severity=Severity.LOW,
            confidence=Confidence.MEDIUM,
            category="secrets",
            description="URLs pointing at staging/dev/internal hosts are present "
                        "in the shipped APK.",
            evidence=[Evidence("APK contents", u) for u in dev_endpoints[:20]],
            recommendation="Check whether internal environments are reachable "
                           "from production builds.",
        )

"""Code-signing analysis: scheme versions, debug certificate, weak algorithms.

Reports whether the APK is signed with the Android debug certificate, which
signature schemes (v1/v2/v3) are present, and whether a weak signature
algorithm (MD5/SHA1) is used.
"""
from __future__ import annotations

from .apkctx import APKContext
from .evidence import Confidence, Evidence, EvidenceDB, Severity

DEBUG_MARKERS = ("Android Debug", "CN=Android Debug", "Common Name: Android Debug")


def _cert_info(cert) -> dict:
    info = {}
    try:
        info["subject"] = cert.subject.human_friendly
    except Exception:
        info["subject"] = str(getattr(cert, "subject", ""))
    try:
        info["issuer"] = cert.issuer.human_friendly
    except Exception:
        info["issuer"] = ""
    for attr in ("serial_number", "hash_algo", "signature_algo"):
        try:
            info[attr] = str(getattr(cert, attr))
        except Exception:
            info[attr] = ""
    for attr in ("not_valid_before", "not_valid_after"):
        try:
            info[attr] = str(getattr(cert, attr))
        except Exception:
            info[attr] = ""
    return info


def run(ctx: APKContext, db: EvidenceDB) -> None:
    try:
        _run(ctx, db)
    except Exception as exc:  # noqa: BLE001
        db.note_error("signing", exc)


def _run(ctx: APKContext, db: EvidenceDB) -> None:
    a = ctx.a
    schemes = {}
    for v, meth in (("v1", "is_signed_v1"), ("v2", "is_signed_v2"),
                    ("v3", "is_signed_v3")):
        try:
            schemes[v] = bool(getattr(a, meth)())
        except Exception:
            schemes[v] = None

    certs = []
    try:
        for c in (a.get_certificates() or []):
            certs.append(_cert_info(c))
    except Exception as exc:  # noqa: BLE001
        db.note_error("signing.certs", exc)

    is_debug = any(any(mk in (ci.get("subject", "") + ci.get("issuer", ""))
                       for mk in DEBUG_MARKERS) for ci in certs)
    weak_algos = sorted({ci.get("signature_algo", "") for ci in certs
                         if ci.get("signature_algo") and
                         ("md5" in ci["signature_algo"].lower()
                          or "sha1" in ci["signature_algo"].lower()
                          or "sha-1" in ci["signature_algo"].lower())})

    v1_only = schemes.get("v1") and not schemes.get("v2") and \
        not schemes.get("v3")

    db.set_section("signing", {
        "schemes": schemes,
        "v1_only": bool(v1_only),
        "debug_certificate": is_debug,
        "weak_signature_algos": weak_algos,
        "certificates": certs,
    })

    def cert_ev():
        return [Evidence("APK signature block",
                         f"subject: {ci.get('subject', '')}",
                         detail=f"sigalg={ci.get('signature_algo', '')} "
                                f"valid {ci.get('not_valid_before', '')} → "
                                f"{ci.get('not_valid_after', '')}")
                for ci in certs] or [Evidence("APK", "no certificate parsed")]

    if is_debug:
        db.finding(
            id="sign-debug-cert",
            title="Signed with the Android DEBUG certificate",
            severity=Severity.HIGH, confidence=Confidence.HIGH,
            category="signing",
            description="The APK is signed with the well-known Android debug key "
                        "(CN=Android Debug). Debug-signed builds are not meant "
                        "for release; the signing key is public, so anyone can "
                        "forge updates / same-signature permissions.",
            evidence=cert_ev(),
            recommendation="Sign release builds with a private release key.",
        )
    if weak_algos:
        db.finding(
            id="sign-weak-algo",
            title=f"Weak signature algorithm: {', '.join(weak_algos)}",
            severity=Severity.MEDIUM, confidence=Confidence.HIGH,
            category="signing",
            description="The signing certificate uses a weak hash (MD5/SHA-1), "
                        "which is deprecated for signatures.",
            evidence=cert_ev(),
            recommendation="Re-sign with SHA-256 based signatures.",
        )
    if v1_only:
        db.finding(
            id="sign-v1-only",
            title="Only v1 (JAR) signature scheme present",
            severity=Severity.MEDIUM, confidence=Confidence.HIGH,
            category="signing",
            description="Only the v1 signature scheme is used. v1-only APKs are "
                        "vulnerable to the Janus (CVE-2017-13156) tampering class "
                        "on older Android and lack v2/v3 integrity.",
            evidence=[Evidence("APK", f"schemes: {schemes}")],
            recommendation="Enable APK Signature Scheme v2/v3.",
        )
    if not any(schemes.values()):
        db.finding(
            id="sign-unsigned",
            title="APK appears unsigned or signature unreadable",
            severity=Severity.LOW, confidence=Confidence.LOW,
            category="signing",
            description="No signature scheme was detected. If this is a store "
                        "build, the signature block may just be unreadable here.",
            evidence=[Evidence("APK", f"schemes: {schemes}")],
        )
    else:
        db.finding(
            id="sign-info",
            title="Signing certificate details",
            severity=Severity.INFO, confidence=Confidence.HIGH,
            category="signing",
            description=f"Signature schemes present: "
                        f"{', '.join(k for k, v in schemes.items() if v) or 'none'}.",
            evidence=cert_ev(),
        )

"""SSL/TLS pinning & certificate-validation analysis.

Detects the pinning/validation mechanism(s), names the implementing classes, and
points at the category of instrumentation surface a tester would validate —
without pretending a single universal bypass exists.
"""
from __future__ import annotations

from .apkctx import APKContext
from .dexutil import any_class_matches, find_method_callers, find_string_users
from .evidence import Confidence, Evidence, EvidenceDB, Severity


def run(ctx: APKContext, db: EvidenceDB) -> None:

        _run(ctx, db)
    except Exception as exc:  # noqa: BLE001
        db.note_error("sslpinning", exc)


def _run(ctx: APKContext, db: EvidenceDB) -> None:
    mechanisms = {}
    evidence: list[Evidence] = []

    # --- OkHttp CertificatePinner
    cp = find_method_callers(ctx, classname="Lokhttp3/CertificatePinner")
    cp_builder = find_method_callers(ctx, methodname="certificatePinner")
    if cp or cp_builder or any_class_matches(ctx, r"okhttp3/CertificatePinner"):
        callers = set()
        for e in cp + cp_builder:
            callers |= set(e["callers"])
        mechanisms["okhttp_certificatepinner"] = {
            "label": "OkHttp CertificatePinner",
            "surface": "Java method interception (CertificatePinner.check).",
            "classes": sorted({c.split('->')[0] for c in callers})[:10],
        }
        evidence.append(Evidence("classes.dex", "okhttp3.CertificatePinner",
                                 detail="OkHttp pinning API referenced"))

    # --- Custom TrustManager / X509TrustManager
    tms = any_class_matches(ctx, r"X509TrustManager|TrustManager")
    custom_tms = [c for c in tms if not c.startswith(("javax/", "java/",
                                                      "android/", "com/android"))]
    checkserver = find_method_callers(ctx, methodname="checkServerTrusted")
    if custom_tms or checkserver:
        # detect dangerously-empty trust managers is hard statically; flag custom
        mechanisms["custom_trustmanager"] = {
            "label": "Custom TrustManager / checkServerTrusted",
            "surface": "Java method interception (checkServerTrusted/verify).",
            "classes": sorted(custom_tms)[:10]
            or sorted({e["target"].split('->')[0].strip('L;').replace('/', '.')
                       for e in checkserver})[:10],
        }
        evidence.append(Evidence(
            "classes.dex",
            ", ".join(c.replace("/", ".") for c in custom_tms[:5])
            or "checkServerTrusted() implementation",
            detail="custom certificate validation"))

    # --- HostnameVerifier
    hv = any_class_matches(ctx, r"HostnameVerifier")
    custom_hv = [c for c in hv if not c.startswith(("javax/", "java/",
                                                    "android/", "org/apache"))]
    verify_calls = find_method_callers(ctx, methodname="verify",
                                       classname=".HostnameVerifier")
    allow_all = find_method_callers(ctx, classname="ALLOW_ALL_HOSTNAME_VERIFIER")
    if custom_hv or allow_all:
        sev_note = ""
        if allow_all:
            sev_note = " ALLOW_ALL_HOSTNAME_VERIFIER reference found — disables "\
                       "hostname verification."
        mechanisms["hostname_verifier"] = {
            "label": "Custom HostnameVerifier" + (" (ALLOW_ALL!)" if allow_all
                                                  else ""),
            "surface": "Java method interception (HostnameVerifier.verify).",
            "classes": sorted(custom_hv)[:10],
        }
        if allow_all:
            db.finding(
                id="ssl-allow-all-hostname",
                title="Hostname verification disabled (ALLOW_ALL)",
                severity=Severity.HIGH, confidence=Confidence.MEDIUM,
                category="ssl-pinning",
                description="A reference to an allow-all hostname verifier "
                            "disables hostname checks, enabling MITM." + sev_note,
                evidence=[Evidence("classes.dex",
                                   "ALLOW_ALL_HOSTNAME_VERIFIER")],
                recommendation="Remove; never disable hostname verification.",
            )

    # --- Network Security Config pins (cross-reference netsec section)
    nsc = db.sections.get("netsec", {})
    if nsc.get("pins_present"):
        mechanisms["nsc_pinset"] = {
            "label": "Network Security Config pin-set",
            "surface": "Platform trust config — enforced by the system, "
                       "config-level validation.",
            "classes": [nsc.get("file", "res/xml")],
        }

    # --- Conscrypt / Cronet
    if any_class_matches(ctx, r"org/conscrypt/"):
        mechanisms["conscrypt"] = {
            "label": "Conscrypt TLS provider present",
            "surface": "TLS provider — validation may occur in provider layer.",
            "classes": ["org.conscrypt"]}
    if any_class_matches(ctx, r"org/chromium/net/|CronetEngine"):
        mechanisms["cronet"] = {
            "label": "Cronet networking present",
            "surface": "Native/Cronet TLS — may require native-level validation.",
            "classes": ["org.chromium.net"]}

    # --- Native TLS suspicion
    native_tls_libs = []
    for lib in ctx.native_libs:
        raw = ctx.read_raw(lib)
        if not raw:
            continue
        blob = b"\n".join(s.encode() for s in ctx.extract_strings(raw, 6))
        if any(tok in blob for tok in (b"SSL_CTX", b"X509_verify",
                                       b"SSL_get_verify_result", b"boringssl",
                                       b"ssl_client", b"pinning", b"pin-sha256")):
            native_tls_libs.append(lib.split("/")[-1])
    if native_tls_libs:
        mechanisms["native_tls"] = {
            "label": "Native TLS / pinning symbols suspected",
            "surface": "Native function instrumentation.",
            "classes": sorted(set(native_tls_libs)),
        }
        evidence.append(Evidence("lib/", ", ".join(sorted(set(native_tls_libs))),
                                 detail="TLS-related native symbols"))

    detected = len(mechanisms) > 0
    db.set_section("sslpinning", {
        "detected": detected,
        "mechanisms": mechanisms,
    })

    if detected:
        db.finding(
            id="ssl-pinning",
            title=f"TLS pinning / custom validation present "
                  f"({len(mechanisms)} mechanism(s))",
            severity=Severity.INFO, confidence=Confidence.MEDIUM,
            category="ssl-pinning",
            description="Certificate pinning or custom TLS validation detected. "
                        "The section lists each mechanism and the category of "
                        "instrumentation surface to validate; there is no single "
                        "universal bypass.",
            evidence=evidence[:20],
            recommendation="Confirm which mechanism actually guards traffic "
                           "(some apps pin one client but not others) and test "
                           "each at its own layer.",
            extra={"surfaces": {k: v["surface"]
                                for k, v in mechanisms.items()}},
        )
    else:
        db.finding(
            id="ssl-no-pinning",
            title="No certificate pinning detected",
            severity=Severity.LOW, confidence=Confidence.LOW,
            category="ssl-pinning",
            description="No OkHttp pinner, custom TrustManager, NSC pin-set, or "
                        "native pinning symbols were found. Traffic may be "
                        "interceptable with a user/system CA depending on NSC.",
            evidence=[],
            recommendation="If the app handles sensitive data, pinning is "
                           "recommended; verify via runtime interception.",
        )

"""iOS static-analysis modules. Each run_*(ctx, db) fills sections + findings.

Reuses core.evidence (shared model) and core.secrets regexes (shared leak set),
so Android and iOS produce the same kind of evidence-backed findings.
"""
from __future__ import annotations

from collections import defaultdict

from core.evidence import Confidence, Evidence, EvidenceDB, Severity

def fingerprint(ctx: IPAContext, db: EvidenceDB) -> None:
    ip = ctx.info_plist
    blob = "\n".join(ctx.namelist)
    frameworks = {
        "Flutter": "Flutter.framework" in blob or "App.framework" in blob,
        "React Native": "libreactnative" in blob.lower()
        or "main.jsbundle" in blob.lower(),
        "Xamarin / .NET": "Xamarin" in blob or ".monotouch" in blob.lower(),
        "Unity": "UnityFramework" in blob,
        "Cordova / Ionic": "www/cordova.js" in blob or "Cordova" in blob,
        "Native (Obj-C/Swift)": True,
    }
    db.meta.update({
        "platform": "ios",
        "app_name": ctx.display_name or "(unknown)",
        "package": ctx.bundle_id,
        "main_activity": ctx.executable_name,
        "version_name": ip.get("CFBundleShortVersionString"),
        "version_code": ip.get("CFBundleVersion"),
        "min_sdk": ip.get("MinimumOSVersion"),
        "target_sdk": ip.get("DTPlatformVersion"),
        "max_sdk": None,
        "file_size": ctx.file_size,
        "hashes": ctx.hashes,
    })
    db.set_section("fingerprint", {
        "frameworks": frameworks,
        "libraries": [],
        "native_libraries": ctx.frameworks,
        "abis": [ctx.macho.get("arch")] if ctx.macho.get("arch") else [],
        "crypto_libs_present": [],
        "class_count": 0,
        "platform_build": ip.get("DTPlatformName", ""),
        "sdk_build": ip.get("DTSDKName", ""),
    })

def plist_security(ctx: IPAContext, db: EvidenceDB) -> None:
    ip = ctx.info_plist
    section = {}

    # --- App Transport Security
    ats = ip.get("NSAppTransportSecurity", {}) or {}
    arbitrary = bool(ats.get("NSAllowsArbitraryLoads"))
    arbitrary_web = bool(ats.get("NSAllowsArbitraryLoadsInWebContent"))
    exceptions = ats.get("NSExceptionDomains", {}) or {}
    section["ats"] = {
        "present": bool(ats),
        "allows_arbitrary_loads": arbitrary,
        "allows_arbitrary_web": arbitrary_web,
        "exception_domains": list(exceptions.keys()),
    }
    if arbitrary:
        db.finding(
            id="ios-ats-arbitrary",
            title="ATS disabled (NSAllowsArbitraryLoads = true)",
            severity=Severity.MEDIUM, confidence=Confidence.HIGH,
            category="ats",
            description="App Transport Security is globally disabled, permitting "
                        "plaintext HTTP and weak TLS to any domain.",
            evidence=[Evidence("Info.plist",
                               "NSAppTransportSecurity > NSAllowsArbitraryLoads = true")],
            recommendation="Remove the global exception; scope only required "
                           "domains.",
        )
    insecure_domains = []
    for dom, cfg in exceptions.items():
        if isinstance(cfg, dict) and cfg.get("NSExceptionAllowsInsecureHTTPLoads"):
            insecure_domains.append(dom)
    if insecure_domains:
        db.finding(
            id="ios-ats-insecure-domains",
            title=f"ATS insecure HTTP exceptions for {len(insecure_domains)} "
                  "domain(s)",
            severity=Severity.LOW, confidence=Confidence.HIGH, category="ats",
            description="Specific domains allow insecure HTTP loads.",
            evidence=[Evidence("Info.plist", d) for d in insecure_domains],
        )

    # --- permission usage descriptions present
    perms = {k: v for k, v in ip.items() if k.endswith("UsageDescription")}
    section["permissions"] = perms

    # --- custom URL schemes (deep-link surface)
    schemes = []
    for entry in ip.get("CFBundleURLTypes", []) or []:
        for s in entry.get("CFBundleURLSchemes", []) or []:
            schemes.append(s)
    section["url_schemes"] = schemes
    if schemes:
        db.finding(
            id="ios-url-schemes",
            title=f"{len(schemes)} custom URL scheme(s) registered",
            severity=Severity.INFO, confidence=Confidence.HIGH,
            category="plist",
            description="Custom URL schemes are an inter-app entry point; verify "
                        "input validation and that sensitive actions require "
                        "authentication.",
            evidence=[Evidence("Info.plist", f"{s}://") for s in schemes],
            recommendation="Prefer Universal Links; validate all scheme input.",
        )

    # --- file sharing / documents in place
    fs = []
    if ip.get("UIFileSharingEnabled"):
        fs.append("UIFileSharingEnabled")
    if ip.get("LSSupportsOpeningDocumentsInPlace"):
        fs.append("LSSupportsOpeningDocumentsInPlace")
    if fs:
        db.finding(
            id="ios-file-sharing",
            title="iTunes/Files app document sharing enabled",
            severity=Severity.LOW, confidence=Confidence.HIGH, category="plist",
            description="The app exposes its Documents directory via file sharing; "
                        "ensure no sensitive data is stored there in cleartext.",
            evidence=[Evidence("Info.plist", k) for k in fs],
        )
    section["file_sharing"] = fs
    section["min_os"] = ip.get("MinimumOSVersion")
    db.set_section("plist", section)

                severity=Severity.LOW, confidence=Confidence.LOW,

# Anti-debug is asserted ONLY from specific tokens — not from bare ptrace/sysctl,
# which are ordinary syscalls present in countless legitimate binaries.
_DEBUG_STRONG = ["PT_DENY_ATTACH", "AmIBeingDebugged"]


def _word_hits(blob_low: str, needles) -> list[str]:
    out = []
    for n in needles:
        nl = n.lower()
        i = blob_low.find(nl)
        while i != -1:
            before = blob_low[i - 1] if i > 0 else " "
            after = blob_low[i + len(nl)] if i + len(nl) < len(blob_low) else " "
            if not (before.isalnum() or before == "_") and \
               not (after.isalnum() or after == "_"):
                out.append(n)
                break
            i = blob_low.find(nl, i + 1)
    return out


def antidebug(ctx: IPAContext, db: EvidenceDB) -> None:
    blob_low = ctx.all_text_blob.lower()
    tools = {}
    ev = []
    for key, (inds, label, surface) in _RE_TOOLS.items():
        found = _word_hits(blob_low, inds)
        if found:
            tools[key] = {"label": label, "surface": surface,
                          "indicators": found[:8]}
            ev += [Evidence("binary/strings", f, detail=label) for f in found[:3]]
    strong = [t for t in _DEBUG_STRONG if t.lower() in blob_low]
    if strong:
        tools["anti_debug"] = {
            "label": "Anti-debugging (PT_DENY_ATTACH / AmIBeingDebugged)",
            "surface": "Debugger attach — validate the ptrace/sysctl routine.",
            "indicators": strong}
        ev += [Evidence("binary/strings", f, detail="anti-debug") for f in strong]

    note = ("These are static string references — their presence does NOT prove "
            "the app performs an active check; the string may be a framework "
            "name, symbol or log line. Confirm against the referencing code.")
    db.set_section("antidebug", {"detected": bool(tools), "techniques": tools,
                                 "note": note})
    if tools:
        db.finding(
            id="ios-antidebug",
            title="Reverse-engineering / anti-debug tool references found",
            severity=Severity.INFO, confidence=Confidence.LOW,
            category="antidebug",
            description="The binary references instrumentation / anti-debug "
                        "tooling (Frida, Cycript/Substrate, or a specific "
                        "anti-debug token). " + note,
            evidence=ev[:20],
            recommendation="Trace whether the referencing code actually performs "
                           "a check and blocks execution before treating it as a "
                           "protection.",
            extra={"surfaces": {k: v["surface"] for k, v in tools.items()}})
    else:
        db.finding(
            id="ios-antidebug-absent",
            title="No instrumentation/anti-debug references found",
            severity=Severity.LOW, confidence=Confidence.LOW, category="antidebug",
            description="No Frida/Cycript/Substrate or specific anti-debug tokens "
                        "were found as static strings.",
            evidence=[])

def secrets(ctx: IPAContext, db: EvidenceDB) -> None:
    blob = ctx.all_text_blob
    out = defaultdict(list)
    seen = set()
    for name, sev, rx, is_secret in _PATTERNS:
        for m in rx.finditer(blob):
            val = m.group().strip()
            if name == "URL" and any(h in val for h in _IGNORE_URL_HOSTS):
                continue
            key = (name, val)
            if key in seen:
                continue
            seen.add(key)
            out[name].append((val, sev, is_secret))
            if len(out[name]) > 400:
                break
    for m in IP_RE.finditer(blob):
        ip = m.group()
        if ip in _IP_IGNORE or ("IP", ip) in seen:
            continue
        seen.add(("IP", ip))
        out["IP address"].append((ip, Severity.LOW, False))

    urls = sorted({v for (v, s, sec) in out.get("URL", [])})
    ips = sorted({v for (v, s, sec) in out.get("IP address", [])})
    dev = [u for u in urls if any(h in u.lower() for h in _DEV_HINTS)]
    db.set_section("secrets", {
        "endpoint_count": len(urls), "endpoints": urls[:500],
        "dev_endpoints": dev, "ip_addresses": ips[:300],
        "private_ips": [i for i in ips if i.startswith(("10.", "192.168.",
                                                        "169.254."))],
        "emails": sorted({v for (v, s, sec) in out.get("Email", [])})[:200],
        "categories": {k: len(v) for k, v in out.items()},
    })
    for name, hits in out.items():
        if name in ("URL", "Email", "IP address"):
            continue
        if not hits[0][2]:
            continue
        db.finding(
            id=f"ios-secret-{name.lower().replace(' ', '-')}",
            title=f"Possible hardcoded secret: {name} ({len(hits)} hit(s))",
            severity=hits[0][1], confidence=Confidence.MEDIUM, category="secrets",
            description=f"Pattern matching {name} found embedded in the IPA.",
            evidence=[Evidence("binary/bundle",
                               (v[:80] + "…") if len(v) > 80 else v)
                      for (v, s, sec) in hits[:15]],
            recommendation="Confirm whether the value is live and move secrets "
                           "server-side.")
    if ips:
        db.finding(
            id="ios-secret-ips",
            title=f"{len(ips)} IP address(es) hardcoded",
            severity=Severity.LOW if any(i.startswith(("10.", "192.168."))
                                         for i in ips) else Severity.INFO,
            confidence=Confidence.MEDIUM, category="secrets",
            description="IP addresses embedded in the app.",
            evidence=[Evidence("binary/bundle", i) for i in ips[:30]])

def firebase(ctx: IPAContext, db: EvidenceDB) -> None:
    gs = ctx.google_service
    blob = ctx.all_text_blob
    rtdb = sorted(set(re.findall(
        r"https://[a-z0-9.\-]+\.(?:firebaseio\.com|firebasedatabase\.app)",
        blob, re.I)))
    cfg = {}
    if gs:
        for k in ("API_KEY", "DATABASE_URL", "STORAGE_BUCKET", "PROJECT_ID",
                  "GCM_SENDER_ID", "GOOGLE_APP_ID", "BUNDLE_ID"):
            if gs.get(k):
                cfg[k] = gs[k]
        if gs.get("DATABASE_URL"):
            rtdb = sorted(set(rtdb + [gs["DATABASE_URL"].rstrip("/")]))
    present = bool(rtdb or cfg)
    db.set_section("firebase", {"present": present, "realtime_db": rtdb,
                                "config_values": cfg,
                                "storage_buckets": [cfg["STORAGE_BUCKET"]]
                                if cfg.get("STORAGE_BUCKET") else []})
    if present:
        db.finding(
            id="ios-firebase",
            title="Firebase configuration present",
            severity=Severity.INFO, confidence=Confidence.HIGH, category="firebase",
            description="Firebase config (GoogleService-Info.plist / URLs) found.",
            evidence=[Evidence("GoogleService-Info.plist / strings",
                               f"{k} = {v}") for k, v in cfg.items()]
            + [Evidence("strings", u) for u in rtdb],
            recommendation="Verify database/storage rules and restrict the API "
                           "key.")
    if cfg.get("API_KEY"):
        db.finding(
            id="ios-firebase-apikey", title="Google/Firebase API key in bundle",
            severity=Severity.LOW, confidence=Confidence.HIGH, category="firebase",
            description="A Google API key is present in the app bundle.",
            evidence=[Evidence("GoogleService-Info.plist", cfg["API_KEY"])],
            recommendation="Restrict the key by bundle id / API scope.")

def storage(ctx: IPAContext, db: EvidenceDB) -> None:
    blob = ctx.all_text_blob
    section = {}
    nsud = "NSUserDefaults" in blob
    keychain = "SecItemAdd" in blob or "kSecClass" in blob or "Keychain" in blob
    sqlite = any(n.endswith((".sqlite", ".db", ".sqlite3")) for n in ctx.namelist)
    realm = any(n.endswith(".realm") for n in ctx.namelist) or "RLMRealm" in blob
    coredata = "NSPersistentStoreCoordinator" in blob or any(
        n.endswith(".momd") or n.endswith(".xcdatamodeld") for n in ctx.namelist)
    section = {"nsuserdefaults": nsud, "keychain": keychain, "sqlite": sqlite,
               "realm": realm, "coredata": coredata}
    db.set_section("storage", section)
    if nsud:
        db.finding(
            id="ios-nsuserdefaults",
            title="NSUserDefaults used",
            severity=Severity.LOW, confidence=Confidence.MEDIUM, category="storage",
            description="NSUserDefaults is unencrypted plist storage. Sensitive "
                        "data (tokens, PII, credentials) must not be stored there "
                        "— use the Keychain.",
            evidence=[Evidence("binary/strings", "NSUserDefaults")],
            recommendation="Move sensitive values to the Keychain; audit what is "
                           "written to NSUserDefaults.")
    if sqlite or realm:
        db.finding(
            id="ios-local-db",
            title="Local database bundled (SQLite/Realm)",
            severity=Severity.INFO, confidence=Confidence.MEDIUM, category="storage",
            description="A local database ships in the bundle; check whether it "
                        "holds sensitive data unencrypted.",
            evidence=[Evidence("bundle", n) for n in ctx.namelist
                      if n.endswith((".sqlite", ".db", ".realm"))][:8])

"""IPAContext: one parsed iOS .ipa, shared by every iOS analyzer.

Pure-Python: unzips the IPA, reads Info.plist (binary or XML via plistlib),
locates the Mach-O executable, extracts printable strings, and pulls
entitlements out of the embedded provisioning profile. Mach-O header parsing
(PIE / encryption) is best-effort and never fatal.
"""
from __future__ import annotations

import hashlib
import os
import plistlib
import re
import struct
import zipfile
from functools import cached_property
from typing import Any, Iterable, Optional

_STRINGS_RE = re.compile(rb"[\x20-\x7e]{4,}")
_PLIST_RE = re.compile(rb"<plist.*?</plist>", re.S)


class IPAContext:
    def __init__(self, path: str) -> None:
        self.path = path
        self.load_error: Optional[str] = None
        self._zip: Optional[zipfile.ZipFile] = None
        try:
            self._zip = zipfile.ZipFile(path)
        except Exception as exc:  # noqa: BLE001
            self.load_error = f"{type(exc).__name__}: {exc}"

    @property
    def ok(self) -> bool:
        return self._zip is not None and bool(self.app_dir)

    # ---- zip helpers ----------------------------------------------------
    @cached_property
    def namelist(self) -> list[str]:
        return self._zip.namelist() if self._zip else []

    def read_raw(self, name: str) -> bytes:
        try:
            return self._zip.read(name) if self._zip else b""
        except Exception:
            return b""

    # ---- app bundle -----------------------------------------------------
    @cached_property
    def app_dir(self) -> str:
        for n in self.namelist:
            m = re.match(r"(Payload/[^/]+\.app/)", n)
            if m:
                return m.group(1)
        return ""

    @cached_property
    def info_plist(self) -> dict:
        raw = self.read_raw(self.app_dir + "Info.plist")
        if not raw:
            return {}
        try:
            return plistlib.loads(raw)
        except Exception:
            return {}

    @cached_property
    def bundle_id(self) -> str:
        return self.info_plist.get("CFBundleIdentifier", "")

    @cached_property
    def display_name(self) -> str:
        return (self.info_plist.get("CFBundleDisplayName")
                or self.info_plist.get("CFBundleName") or "")

    @cached_property
    def executable_name(self) -> str:
        return self.info_plist.get("CFBundleExecutable", "")

    @cached_property
    def binary(self) -> bytes:
        if self.executable_name:
            return self.read_raw(self.app_dir + self.executable_name)
        return b""

    @cached_property
    def entitlements(self) -> dict:
        # 1) embedded.mobileprovision (CMS blob with an XML plist inside)
        prov = self.read_raw(self.app_dir + "embedded.mobileprovision")
        out: dict = {}
        if prov:
            m = _PLIST_RE.search(prov)
            if m:
                try:
                    profile = plistlib.loads(m.group())
                    ent = profile.get("Entitlements", {})
                    if isinstance(ent, dict):
                        out.update(ent)
                    out["_profile_name"] = profile.get("Name")
                    out["_creation"] = str(profile.get("CreationDate"))
                    out["_expiration"] = str(profile.get("ExpirationDate"))
                except Exception:
                    pass
        # 2) entitlements embedded in the Mach-O (__TEXT,__entitlements)
        if self.binary:
            m = _PLIST_RE.search(self.binary)
            if m:
                try:
                    ent = plistlib.loads(m.group())
                    if isinstance(ent, dict):
                        for k, v in ent.items():
                            out.setdefault(k, v)
                except Exception:
                    pass
        return out

    @cached_property
    def google_service(self) -> dict:
        for n in self.namelist:
            if n.endswith("GoogleService-Info.plist"):
                try:
                    return plistlib.loads(self.read_raw(n))
                except Exception:
                    return {}
        return {}

    # ---- strings --------------------------------------------------------
    @staticmethod
    def extract_strings(blob: bytes, minlen: int = 4) -> Iterable[str]:
        for m in _STRINGS_RE.finditer(blob):
            s = m.group().decode("ascii", "replace")
            if len(s) >= minlen:
                yield s

    @cached_property
    def binary_strings(self) -> list[str]:
        return list(self.extract_strings(self.binary, 5)) if self.binary else []

    @cached_property
    def all_text_blob(self) -> str:
        """Binary strings + small text/plist/js files, for secret scanning."""
        parts = list(self.binary_strings)
        for n in self.namelist:
            if n.endswith((".plist", ".json", ".js", ".txt", ".xml", ".html",
                           ".strings", ".cfg", ".properties")):
                raw = self.read_raw(n)
                if raw and len(raw) < 3_000_000:
                    parts.append(raw.decode("utf-8", "replace"))
        return "\n".join(parts)

    @cached_property
    def frameworks(self) -> list[str]:
        fw = set()
        for n in self.namelist:
            m = re.search(r"Frameworks/([^/]+\.(?:framework|dylib))", n)
            if m:
                fw.add(m.group(1))
        return sorted(fw)

    @cached_property
    def file_size(self) -> int:
        try:
            return os.path.getsize(self.path)
        except OSError:
            return 0

    @cached_property
    def hashes(self) -> dict:
        h = {"md5": hashlib.md5(), "sha1": hashlib.sha1(),
             "sha256": hashlib.sha256()}
        try:
            with open(self.path, "rb") as fh:
                for chunk in iter(lambda: fh.read(1024 * 1024), b""):
                    for d in h.values():
                        d.update(chunk)
            return {k: v.hexdigest() for k, v in h.items()}
        except OSError:
            return {k: "" for k in h}

    # ---- Mach-O header (best-effort): PIE + encryption ------------------
    @cached_property
    def macho(self) -> dict:
        b = self.binary
        info = {"parsed": False, "pie": None, "encrypted": None,
                "arch": None, "has_stack_canary": None, "has_arc": None}
        if len(b) < 32:
            return info
        try:
            magic = struct.unpack("<I", b[:4])[0]
            le = "<"
            if magic in (0xFEEDFACF, 0xCFFAEDFE):      # 64-bit
                bits = 64
            elif magic in (0xFEEDFACE, 0xCEFAEDFE):    # 32-bit
                bits = 32
            elif magic in (0xCAFEBABE, 0xBEBAFECA):    # FAT — take first slice
                # FAT header: magic, nfat_arch (big-endian)
                nfat = struct.unpack(">I", b[4:8])[0]
                if nfat:
                    off = struct.unpack(">I", b[16:20])[0]  # first arch offset
                    b = b[off:]
                    magic = struct.unpack("<I", b[:4])[0]
                    bits = 64 if magic in (0xFEEDFACF, 0xCFFAEDFE) else 32
                else:
                    return info
            else:
                return info

            # mach_header(_64): magic,cputype,cpusubtype,filetype,ncmds,...,flags
            hdr_size = 32 if bits == 64 else 28
            (_, cputype, _, _, ncmds, _, flags) = struct.unpack(
                le + "IiiIIII", b[:28])
            info["parsed"] = True
            info["arch"] = "arm64" if cputype == 0x0100000C else str(cputype)
            MH_PIE = 0x00200000
            info["pie"] = bool(flags & MH_PIE)

            # walk load commands for LC_ENCRYPTION_INFO(_64)
            off = hdr_size
            LC_ENC = 0x21
            LC_ENC64 = 0x2C
            info["encrypted"] = False
            for _ in range(min(ncmds, 400)):
                if off + 8 > len(b):
                    break
                cmd, cmdsize = struct.unpack(le + "II", b[off:off + 8])
                if cmd in (LC_ENC, LC_ENC64):
                    # cryptid is 3rd uint32 after cmd,cmdsize,cryptoff,cryptsize
                    try:
                        cryptid = struct.unpack(
                            le + "I", b[off + 16:off + 20])[0]
                        info["encrypted"] = cryptid != 0
                    except Exception:
                        pass
                if cmdsize == 0:
                    break
                off += cmdsize
        except Exception:
            return info
        # symbol heuristics
        bs = self.binary
        info["has_stack_canary"] = (b"__stack_chk_guard" in bs
                                    or b"__stack_chk_fail" in bs)
        info["has_arc"] = b"_objc_release" in bs or b"objc_release" in bs
        return info
