ENV NODE_ENV=production
ENV GUARD_HOST=0.0.0.0
ENV GUARD_PORT=7400
ENV GUARD_ADMIN_PORT=7401
ENV GUARD_PERSIST=json

COPY package.json package-lock.json* ./
RUN npm install --omit=dev && npm cache clean --force

COPY server ./server
COPY admin ./admin
COPY templates ./templates

# Admin/moderator console tooling
COPY package.json ./
RUN npm prune --omit=dev

EXPOSE 7400 7401

HEALTHCHECK --interval=30s --timeout=3s --retries=3 \
  CMD node -e "require('http').get('http://127.0.0.1:'+(process.env.GUARD_ADMIN_PORT||7401)+'/health',r=>process.exit(r.statusCode===200?0:1)).on('error',()=>process.exit(1))" || exit 1

# Persisted bans + config live on a mounted volume
VOLUME ["/app/data"]

`INSTALL.md`:

```md
# Installing Guard-Game into your own game

This is the only file you need if you have a game and want the anti-cheat
running on top of it. It takes ~10 minutes. Each step is run on a machine
that can reach your game server (Linux, macOS, or Windows — the server itself
is plain Node.js).

---

## 0. What you need

| Thing | Version |
|---|---|
| Node.js | 18+ (20 LTS recommended) |
| Your game | any engine — see the SDK table in step 3 |
| A machine to host the guard server | cheap VPS or your game server box |

Nothing else. Guard-Game has **zero runtime dependencies** — no database, no
process supervisor, no ORM. `npm install` is only needed to run the test suite
during development.

---

## 1. Get the code

```bash
git clone https://github.com/Parko-Developer/guard-game.git guard
cd guard
npm install          # dev-only: pulls the test runner
```

Or grab `guard-game-<version>.zip` from the releases page and unzip it.

---

## 2. Start the guard server

```bash
# Linux / macOS
GUARD_ADMIN_TOKEN=$(openssl rand -hex 24) node server/index.js

# Windows (PowerShell)
$env:GUARD_ADMIN_TOKEN = (openssl rand -hex 24) ; node server/index.js
```

You should see:

```
[Guard-Game] v1.0.0 started
  tcp    :7400   (game engines with raw sockets)
  http   :7401   (admin API + /ingest bridge for HTTP-only engines)
```

Two ports, one process:

- **7400 (TCP)** — the low-latency wire for engines that can open sockets
  (Godot via TCP can, web/JS and Roblox cannot).
- **7401 (HTTP)** — the admin API *and* the `/ingest` bridge your SDK talks to
  when the engine can't open raw sockets. This is the default path for most
  SDKs.

> Keep the admin API private: `GUARD_ADMIN_BIND=127.0.0.1` is the default.
> If the guard server is on a separate box from your game, forward only 7400/7401
> and never expose the admin port publicly.

---

## 3. Pick your SDK

Copy the matching SDK into your project. Every SDK speaks the same protocol, so
the server is identical no matter which engine it fronts.

| Engine | File | Notes |
|---|---|---|
| Godot / GDScript | `client-sdks/gdscript/guard_client.gd` | TCP, attach as an autoload |
| Unity / C# | `client-sdks/csharp/GuardClient.cs` | TCP, `async void Update()` |
| Unreal / C++ | port the wire in `server/protocol.js` | no off-the-shelf C++ file;
  the `.cs` version is the reference |
| Roblox / Luau | `client-sdks/luau/guardClient.lua` | HTTP `/ingest` bridge — Roblox
  Lua can't open raw sockets |
| JS / Node (web, webgl, your own server) | `client-sdks/js/guardClient.js` (TCP) or
  `client-sdks/js/guardBridgeClient.js` (HTTP bridge) | |
| Godot quick path | `templates/make.ps1` or `scripts/template.js` | scaffolds server + SDK
  + INTEGRATION.md in one folder |

### Copying the SDK for most engines

```bash
# example: Godot
mkdir -p /path/to/your/game/addons/guard
cp client-sdks/gdscript/guard_client.gd /path/to/your/game/addons/guard/
```

That's what "the engine recognizes it and activates the plugin" means in
practice: the SDK file lives in your engine's plugin folder, your engine loads
your scripts, and your gameplay code calls the SDK every frame.

---

## 4. Wire it into gameplay

Open the SDK file and look for the block that says `WIRE ME`. Replace the three
placeholder values:

```js
// every SDK has an equivalent of:
guard.account = "account-" .. player.id      // per-player id
guard.url    = "ws://127.0.0.1:7400/guards"  // or the HTTP bridge url
guard.world  = "ground"                       // pick a world profile
```

Then call it every physics frame with the player's honest state:

```luau
-- Roblox (ServerScriptService) — every frame:
guard:sample(
    { x = root.Position.X, y = root.Position.Y, z = root.Position.Z },  -- position
    root.AssemblyLinearVelocity.Y == 0,                                  -- on ground?
    root.AssemblyLinearVelocity                                            -- velocity (optional)
)
```

```cs
// Unity — inside FixedUpdate:
await guard.Sample(
    pos,                       // Vector3
    Mathf.Abs(rb.velocity.y) < 0.01,
    rb.velocity);
```

The SDK handles handshake, per-frame sampling, and reconnecting. You only feed
it honest telemetry — the server decides.

---

## 5. Report gameplay actions (the hook layer)

Anti-cheat needs to know *what the player did*, not just where they went. Hook
your economy / quest endpoints:

```js
guard.action("give",      { item: "coins", amount: 100 });
guard.action("quest_claim", { questId: "daily", reward: 50 });
```

So when a cheater tries to duplicate cash or insta-complete a quest, the server
can cross-check the action against the player's movement record and admin rules.

---

## 6. Verify it works (10 seconds)

You should be able to cheat — deliberately — and see the server call it out:

```bash
npm run demo
```

The demo spawns one honest bot and one cheater (teleport + impossible jump),
and prints every violation with its severity (`warn` / `ban`) and the world rule
it tripped.

Or do it live from the admin console while a real player is online:

```bash
node admin/console.js live          # watch frames stream
node admin/console.js warn <acct> RISE_VEL "abnormal climb"
```

## 7. Go to production

### A) One-file build script (recommended)

```bash
./scripts/build.sh --package        # Linux/macOS
.\scripts\build.ps1 -Package        # Windows
```

Emit `releases/guard-game-<version>.zip` and ship it with a pinned `node --version`.

### B) Docker

```bash
docker compose up -d --build
```

Health-checked container, persisted bans on a volume. Set `GUARD_HMAC_KEY` and
`GUARD_ADMIN_TOKEN` (never commit them); you can mount a custom
`guard.config.json` too.

### C) systemd (bare metal Linux)

```bash
sudo ./deploy/install-linux.sh --world ground --admin-token $(openssl rand -hex 24)
```

Installs the hardened unit, an unprivileged `guard` user, and an env file with
`0600` perms. Logs: `journalctl -u guard-game -f`.

### Hardening checklist before you ship

- [ ] `GUARD_HMAC_KEY` set and shared with the SDK (not the HTTP bridge SKIP)
- [ ] `GUARD_ADMIN_TOKEN` set to a long random value
- [ ] Admin API bound to `127.0.0.1` (or behind your proxy + auth)
- [ ] Bans persist to disk (`GUARD_PERSIST=json` is the default)
- [ ] World profiles match your real map (ceiling height, jump apex, speed cap)
- [ ] `npm run test` passes before every release

---

## What a world profile actually controls

The attack surface that matters for a *movement* cheat is bounded by three
numbers, all in `server/config.js` under a world profile:

| Rule | Default (ground) | What it stops |
|---|---|---|
| `maxJumpHeight` | `3.6` u | impossibly high jump apex → `HEIGHT_TOO_HIGH` |
| `maxJumpApexTolerance` | `1.15` | jump apex above physically possible apex |
| `maxHoverTimeMs` | `500` | airborne, stationary, too long → `HOVER` |
| `maxRiseSpeed` | `0` (BAN) | upward velocity above a real jump's impulse |
| `maxClimbPerAirborne` | `18.0` | net height gained in one airborne stretch |
| `maxAirtimeMs` | `6000` | airborne longer than any possible jump → `AIRTIME` |

The **jump-height and airtime checks** are exactly what they sound like, no
magic: the server keeps a per-jump record (launch position, apex, airtime) and
flags any jump whose apex or airtime is physically impossible for the world it's
in. Everything is measured on the server's clock, so latency doesn't matter and
a cheater can't argue frame times.

---

## The honest part

- Guard-Game blocks *movement* cheats (speed, jump height, teleport, fly/climb,
  hover) and *action* cheats (item/quest duplication) at the server.
- It can't see inside a modified game client (memory editing, aim-visuals). Those
  need client-side tamper detection, which is a separate trade-off: anything
  running on the cheater's machine can in theory be read back out of it.
- Client "trust" is limited to what you report. That's by design and it's what
  lets a single Node server protect thirty different engines without per-engine
  native code.

If you get stuck on a step, `node admin/console.js list` shows connected
clients, `node admin/console.js live` shows frames, and the tests
(`npm run test`) are the executable spec for every rule above.

`README.md`:

```md
# Guard-Game

A server that decides whether your players are cheating — by not trusting what
they report. The client sends its position, velocity, ground state, and a few
action events over the wire. The server holds a *world profile* for your map:
how high a jump can be, how fast a character can run, how long anyone can stay
airborne, where the world ends. Every incoming claim is checked against that
profile using the server's own receive-time clock, so a cheater can't fake
timestamps or sequence numbers to argue their way out.

Runs on Node.js with zero runtime dependencies. One JSON protocol, one server
binary, and SDKs for the engines people actually ship games in.

Website: <https://parko-developer.github.io/guard-game/> — overview, how it
works, install guide, config reference, and the source on one page.

```
client ── position / actions (TCP :7400 or HTTP :7401) ──► guard server
admin  ── HTTP API with admin token ──► ban / warn / kick / audit
```

## Quickstart

```bash
npm install        # only needed to run the test suite
npm run test       # 24 tests — one honest bot and several cheaters, real sockets
npm run demo       # boots the server and plays a scripted detection demo
npm run start      # production: TCP :7400 + HTTP :7401
```

`npm run demo` needs the admin token or it will refuse to do anything useful:

```powershell
$env:GUARD_ADMIN_TOKEN = "pick-a-real-secret"
npm run demo
```

Putting it into an actual game? Start with [INSTALL.md](INSTALL.md) —
it walks through server setup, SDK wiring, and the admin token step by step.

## What it catches

| Cheat | Violation codes | Verdict |
|---|---|---|
| Fly / flight hacks | `RISE_VEL`, `CLIMB_ESCAPE`, `HOVER`, `OUT_OF_BOUNDS` | ban |
| Jump too high | `HEIGHT_TOO_HIGH` | warn (strike) |
| Hanging in the air | `HOVER`, `AIRTIME` | ban |
| Teleport | `TELEPORT` | warn (strike) |
| Speed hack | `SPEED` | warn (strike) |
| NaN / garbage position | `BAD_POS` | warn |
| Spoofed seq / timestamps | `SPOOF_SEQ`, `SPOOF_TS` | ban |
| Packet flood | `FLOOD_STATE`, `FLOOD_ACTION`, `FLOOD_HELLO` | ban |
| Money-giver bots | `GIVE_BAD_AMOUNT`, `GIVE_FLOOD` | warn → ban |
| Quest farmers / macros | `QUEST_FARM`, `MACRO` | warn → ban |
| Unknown client version | — | kick |

Warnings pile up as strikes. Cross `GUARD_STRIKES_TO_BAN` (default 3) inside
`GUARD_STRIKE_WINDOW_MS` (default 60 s) and the player is banned. Bans are
written to `server/data/bans.json` and enforced again at login.

## The wire protocol

Every frame is one JSON line. Short enough that any language can produce it:

```json
{"v":1,"id":"<sid|null>","type":"hello|state|action","seq":2,"t":<ms>,"d":{...}}
```

* `hello` → `d:{acct, version, world}` — sent once, when the client connects
* `state` → `d:{p:{x,y,z}, g:<onGround>, v?:{x,y,z}}` — call every physics frame
* `action` → `d:{k:'give'|'quest_claim'|'macro', args:{...}}` — gameplay events

The server replies with `welcome`, `ack`, `warn`, `ban`, `kick`, or `error`.

SDKs per engine:

| Engine | Transport | File |
|---|---|---|
| Node / your own game server | TCP | `client-sdks/js/guardClient.js` |
| Web / browser (also Node 20+) | HTTP bridge | `client-sdks/js/guardBridgeClient.js` |
| Roblox (Luau) | HTTP bridge | `client-sdks/luau/guardClient.lua` |
| Godot (GDScript) | HTTP bridge | `client-sdks/gdscript/guard_client.gd` |
| Unity / C# | HTTP bridge | `client-sdks/csharp/GuardClient.cs` |
| Unreal / C++ | port the protocol | `server/protocol.js` is the spec |

The HTTP bridge (`POST /ingest/handshake|state|action` on :7401) exists for
engines that can't open raw sockets — Roblox, browser JS, story-game runtimes,
whatever. Set `GUARD_BRIDGE_KEY` to make the bridge require a shared key. The
admin API lives on the same port but is a separate path gated by the admin
token only, so keep those two secrets independent.

## Jump-height and airtime checks

Per player the server keeps a jump record — where they launched, how high they
got, how long they've been airborne. Each sample checks:

1. Upward speed above what a legit jump impulse allows → `RISE_VEL`
2. Net climb in one airborne stretch over `maxClimbPerAirborne` → `CLIMB_ESCAPE`
3. Still airborne after `maxHoverTimeMs` with under 0.1 units of drift → `HOVER`
4. Airborne for ages and still gaining height → `AIRTIME`
5. On landing, an apex higher than the world allows → `HEIGHT_TOO_HIGH`

World bounds (ceiling height, map extents) are part of the profile too, which
is how flying over the map triggers `OUT_OF_BOUNDS`. And since all of it runs
on the server's receive clock, "impossibly long airtime" is measured in your
time, not the cheater's.

## Configuration

Precedence: defaults → `guard.config.json` (`$GUARD_CONFIG`) → `GUARD_*` env
vars → CLI flags. Everything below can be set any of those three ways.

| Env | Default | What it means |
|---|---|---|
| `GUARD_PORT` | `7400` | TCP listener |
| `GUARD_HTTP_PORT` | `7401` | HTTP admin API + `/ingest` bridge |
| `GUARD_WORLD` | `ground` | world profile used when the client doesn't announce one |
| `GUARD_VERSIONS` | `guard-1.0` | comma-separated client firmware versions you ship |
| `GUARD_STRIKES_TO_BAN` | `3` | warnings before auto-ban |
| `GUARD_STRIKE_WINDOW_MS` | `60000` | how long strikes stay on the record |
| `GUARD_WARN_COOLDOWN_MS` | `2000` | minimum gap between warn frames to one player |
| `GUARD_MAX_PACKET` | `4096` | max frame size in bytes |
| `GUARD_MAX_TS_DRIFT_MS` | `2000` | allowed client/server clock drift before `SPOOF_TS` |
| `GUARD_HMAC_KEY` | (empty) | signs TCP wire frames, optional |
| `GUARD_BRIDGE_KEY` | (empty) | shared key for the HTTP ingest bridge |
| `GUARD_ADMIN_TOKEN` | `guard-admin-change-me` | admin API bearer token |
| `GUARD_ADMIN_BIND` | `127.0.0.1` | where the admin/bridge HTTP server binds |
| `GUARD_DATA_DIR` | `server/data` | bans + audit log location |

World profiles (`ground`, `hovercraft`) live in `server/config.js` under
`WORLD_PROFILES`. They're just data, so adding your own world means editing a
few numbers, not touching the validator.

## What it can't do

- No client-reporting anti-cheat is unbeatable. A modified client, a DMA
  reader, or a patched executable can always send fiction. This assumes the
  client reports and the server independently derives truth from the world
  profile. For a serious title: authoritative movement in your gameplay code,
  packet-level auth (that's what `GUARD_HMAC_KEY` is for), and optionally a
  trusted-platform stack.
- DLL injection or bytepatching *your client* isn't detectable from here, and
  that's by design — the only real defense is refusing to trust the client,
  which is the whole architecture. You can still ask the server to flag
  impossible gameplay outcomes via `server/gamehooks.js`-style checks.
- "Any engine" really means "any engine that can send JSON." Unity, Unreal,
  Godot, Roblox, and browser JS are covered by the SDKs; AGSScript, Ren'Py,
  RPG Maker, and the rest can `POST /ingest/*` straight from their runtime.

`admin/console.js`:

```js
'use strict';

/**
 * Guard-Game admin console — the SERVER-SIDE admin client.
 *
 * Only server-side operators who pass the admin token can use guard config
 * and enforcement. It talks to the HTTP admin API (bound to 127.0.0.1 by
 * default, so remote hosts can't even reach it).
 *
 * Usage:
 *   node admin/console.js --cmd stats            live counters
 *   node admin/console.js --cmd players          connected sessions
 *   node admin/console.js --cmd events           recent audit trail
 *   node admin/console.js --cmd live             tail the audit trail
 *   node admin/console.js --cmd bans             ban list
 *   node admin/console.js --cmd strikes [--acct A]
 *   node admin/console.js --cmd ban --acct A [--reason R...] [--durationMs N]
 *   node admin/console.js --cmd unban --acct A
 *   node admin/console.js --cmd kick --acct A [--reason R...]
 *   node admin/console.js --cmd url              print admin API location
 *
 * Auth: GUARD_ADMIN_TOKEN (or --token). Defaults to the dev token.
 */

const http = require('http');
const url = require('url');
const token = process.env.GUARD_ADMIN_TOKEN || process.argv.find(a => a.startsWith('--token='))?.split('=')[1]
  || 'guard-admin-change-me';
const host = process.env.GUARD_ADMIN_HOST || '127.0.0.1';
const port = Number(process.env.GUARD_HTTP_PORT || 7401);

function arg(name, def) {
  const i = process.argv.indexOf(`--${name}`);
  if (i !== -1 && typeof process.argv[i + 1] === 'string') return process.argv[i + 1];
  if (i !== -1) return true;
  return def;
}
function flag(name) { return process.argv.includes(`--${name}`); }

function req(method, path, body) {
  return new Promise((resolve, reject) => {
    const u = new url.URL(`http://${host}:${port}${path}`);
    const payload = body ? JSON.stringify(body) : null;
    const r = http.request(
      Object.assign(
        { method, host, port, path: u.pathname + u.search, headers: { Authorization: `Bearer ${token}` } },
        payload ? { headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json', 'Content-Length': Buffer.byteLength(payload) } } : {}
      ),
      res => {
        let data = '';
        res.on('data', c => (data += c));
        res.on('end', () => {
          let obj;
          try { obj = JSON.parse(data || '{}'); } catch { obj = { raw: data }; }
          resolve({ status: res.statusCode, body: obj });
        });
      }
    );
    r.on('error', reject);
    if (payload) r.write(payload);
    r.end();
  });
}

function fmtTime(ms) {
  return new Date(ms).toISOString().replace('T', ' ').replace('.000Z', 'Z');
}

async function main() {
  const cmd = (arg('cmd') || 'stats').toLowerCase();

  const renderPlayers = list => {
    if (!list.length) { console.log('(no players connected)'); return; }
    console.log('acct'.padEnd(20) + 'world'.padEnd(14) + 'version'.padEnd(14) + 'connected since');
    for (const p of list) {
      console.log(
        String(p.acct || '').padEnd(20) +
        String(p.world || '').padEnd(14) +
        String(p.version || '').padEnd(14) +
        fmtTime(p.joinedAt || Date.now())
      );
    }
  };

  try {
    switch (cmd) {
      case 'stats': {
        const r = await req('GET', '/api/stats');
        if (r.status === 401) { console.error('unauthorized — set GUARD_ADMIN_TOKEN to the server admin token'); process.exit(1); }
        const s = r.body;
        console.log(`Guard-Game ${s.version || '?'}`);
        console.log(`  uptime      : ${Math.round((s.uptimeMs || 0) / 1000)}s`);
        console.log(`  players     : ${s.players || 0}`);
        console.log(`  bans        : ${s.bans || 0}`);
        console.log(`  temporary   : ${s.temporaryBans || 0}`);
        console.log(`  events      : ${s.events || 0}`);

// GuardClient for C# (.NET 6+). Works in Unity, Godot Mono, or a plain service.
//
// Talks to Guard-Game's HTTP ingest bridge (server HTTP port, default 7401).
// Position is reported as a plain (x, y, z) tuple so there is no engine
// dependency; adapt the property accessors to your engine.
//
//     var guard = new GuardClient("http://11.22.33.44:7401/ingest", "player_123");
//     await guard.Connect();
//     guard.OnWarn += (code, detail) => Console.WriteLine($"[Guard] warn {code}: {detail}");
//     guard.OnBan  += reason => Console.WriteLine($"[Guard] BANNED {reason}");
//     guard.OnKick += reason => Console.WriteLine($"[Guard] kicked {reason}");
//
//     // at >=50ms cadence:
//     await guard.Sample(posX, posY, posZ, isOnGround, velX, velY, velZ);
//
//     // gameplay hooks:
//     await guard.Action("give", new { item = "coins", amount = 100 });

using System;
using System.Collections.Generic;
using System.Net.Http;
using System.Text;
using System.Text.Json;
using System.Threading.Tasks;

namespace GuardGame.Sdk
{
    public sealed class GuardClient : IDisposable
    {
        public event Action<string, string>? OnWarn;   // code, detail
        public event Action<string>? OnBan;            // reason
        public event Action<string>? OnKick;           // reason
        public event Action<string>? OnError;          // message

        public bool IsConnected { get; private set; }

        private readonly HttpClient _http;
        private readonly string _url;
        private readonly string _account;
        private readonly string _version;
        private readonly string _world;
        private readonly double _minIntervalMs;
        private string _sid = "";
        private long _seq;
        private DateTime _lastSent;

        public GuardClient(string baseUrl, string account, string version = "guard-1.0",
                           string world = "ground", double minIntervalMs = 50)
        {
            _url = baseUrl.TrimEnd('/');
            _account = account;
            _version = version;
            _world = world;
            _minIntervalMs = minIntervalMs;
            _http = new HttpClient { Timeout = TimeSpan.FromSeconds(3) };
        }

        public async Task<bool> Connect()
        {
            try
            {
                var resp = await PostJson("/handshake", new
                {
                    acct = _account, version = _version, world = _world
                });
                if (resp.TryGetProperty("sid", out var sid))
                {
                    _sid = sid.GetString() ?? "";
                    IsConnected = true;
                    if (resp.TryGetProperty("frames", out var frames)) HandleFrames(frames);
                    return true;
                }
                return false;
            }
            catch (Exception e)
            {
                OnError?.Invoke(e.Message);
                return false;
            }
        }

        public async Task Sample(double x, double y, double z, bool isOnGround,
                                 double vx = 0, double vy = 0, double vz = 0)
        {
            if (!IsConnected) return;
            var now = DateTime.UtcNow;
            if ((now - _lastSent).TotalMilliseconds < _minIntervalMs) return;
            _lastSent = now;
            _seq++;

            var d = new Dictionary<string, object>
            {
                ["p"] = new { x, y, z },
                ["g"] = isOnGround,
                ["v"] = new { x = vx, y = vy, z = vz }
            };
            var msg = new Dictionary<string, object> { ["sid"] = _sid, ["seq"] = _seq, ["t"] = UnixMs(now), ["d"] = d };
            var resp = await PostJson("/state", msg);
            if (resp.TryGetProperty("frames", out var frames)) HandleFrames(frames);
        }

        public async Task Action(string kind, object args)
        {
            if (!IsConnected) return;
            _seq++;
            var msg = new Dictionary<string, object>
            {
                ["sid"] = _sid, ["seq"] = _seq, ["t"] = UnixMs(DateTime.UtcNow),
                ["d"] = new { k = kind, args = args ?? new { } }
            };
            var resp = await PostJson("/action", msg);
            if (resp.TryGetProperty("frames", out var frames)) HandleFrames(frames);
        }

        public void Disconnect() => IsConnected = false;

        // ------------------------------------------------------------------
        private async Task<JsonElement> PostJson(string path, object body)
        {
            var json = JsonSerializer.Serialize(body);
            var content = new StringContent(json, Encoding.UTF8, "application/json");
            using var resp = await _http.PostAsync(_url + path, content);
            var text = await resp.Content.ReadAsStringAsync();
            using var doc = JsonDocument.Parse(text);
            return doc.RootElement.Clone();
        }

        private void HandleFrames(JsonElement frames)
        {
            if (frames.ValueKind != JsonValueKind.Array) return;
            foreach (var f in frames.EnumerateArray())
                HandleFrame(f);
        }

        private void HandleFrame(JsonElement f)
        {
            if (f.ValueKind != JsonValueKind.Object) return;
            var type = f.GetProperty("type").GetString();
            var d = f.TryGetProperty("d", out var dd) ? dd : default;
            string Str(string key, string fb) => (d.ValueKind == JsonValueKind.Object &&
                                                  d.TryGetProperty(key, out var v))
                ? v.ToString() : fb;

            switch (type)
            {
                case "warn":
                    OnWarn?.Invoke(Str("code", "?"), Str("detail", ""));
                    break;
                case "ban":
                    IsConnected = false;
                    OnBan?.Invoke(Str("reason", "banned"));
                    break;
                case "kick":
                    IsConnected = false;
                    OnKick?.Invoke(Str("reason", "kicked"));
                    break;
            }
        }

        private static long UnixMs(DateTime now) =>
            new DateTimeOffset(now).ToUnixTimeMilliseconds();

        public void Dispose() => _http.Dispose();
    }
}

	_request.timeout = 5.0
	parent_node.add_child(_request)

			return

		_connected = true

	)

	if not _connected:
		return
	var now := Time.get_ticks_msec()
	if now - _lastSentMs < minIntervalMs:
		return
	_lastSentMs = now
	_seq += 1
	var d := {
		"p": {"x": pos.x, "y": pos.y, "z": pos.z},
		"g": is_on_ground,
		"v": {"x": vel.x, "y": vel.y, "z": vel.z},

	_send("/state", {"sid": _sid, "seq": _seq, "t": now, "d": d},

			_handle_frames(result.get("frames", []))
	)

	if not _connected:
		return
	_seq += 1
	_send("/action", {"sid": _sid, "seq": _seq, "t": Time.get_ticks_msec(), "d": {"k": kind, "args": args}},
		func(result: Dictionary) -> void:
			_handle_frames(result.get("frames", []))
	)

	_connected = false

	_pending.append({"path": path, "body": body, "cb": on_success})
	if _pending.size() == 1:
		_flush()

	if _pending.is_empty():
		return
	var req := _pending[0]
	var err := _request.request(url + req["path"], ["Content-Type: application/json"],
		HTTPClient.METHOD_POST, JSON.stringify(req["body"]))
	if err != OK:
		_pending.pop_front()
		_flush.call_deferred()

	var cb: Callable = Callable()

/**
 * GuardBridgeClient — web/browser + Node 20+ HTTP variant of the client SDK.
 *
 * Same protocol as guardClient.js but over the HTTP ingest bridge, which is
 * the only transport available in browsers, FE.CommonJS, and similar engines.
 *
 *   const guard = new GuardBridgeClient({ url: 'http://host:7401/ingest', account: 'p1' });
 *   await guard.connect();
 *   guard.onBan = reason => console.error('banned', reason);
 *   setInterval(() => guard.state(pos, onGround, vel), 120);
 */

class GuardBridgeClient {
  /**
   * @param {object} opts
   * @param {string} opts.url bridge base, e.g. 'http://host:7401/ingest'
   * @param {string} opts.account
   * @param {string} [opts.version='guard-1.0']
   * @param {string} [opts.world='ground']
   * @param {string} [opts.key] optional shared bridge key
   */
  constructor(opts) {
    this.url = (opts.url || '').replace(/\/$/, '');
    this.account = opts.account;
    this.version = opts.version || 'guard-1.0';
    this.world = opts.world || 'ground';
    this.key = opts.key || '';
    this.onBan = null;
    this.onWarn = null;
    this.onKick = null;
    this.sid = null;
    this.seq = 0;
  }

  get connected() { return !!this.sid; }

  async _post(path, body) {
    const params = this.key ? (path.includes('?') ? '&' : '?') + 'key=' + encodeURIComponent(this.key) : '';
    const res = await fetch(this.url + path + params, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(body)
    });
    const data = await res.json();
    if (data.frames) this._handleFrames(data.frames);
    if (!res.ok) throw new Error(data.error || res.statusText);
    return data;
  }

  async connect() {
    const res = await this._post('/handshake', {
      acct: this.account, version: this.version, world: this.world
    });
    this.sid = res.sid;
    return res;
  }

  /** Report a position sample. @param {{x,y,z}} pos @param {boolean} ground */
  async state(pos, ground, vel) {
    if (!this.connected) return;
    this.seq += 1;
    const d = { p: pos, g: !!ground };
    if (vel) d.v = vel;
    await this._post('/state', { sid: this.sid, seq: this.seq, t: Date.now(), d });
  }

  /** Report a gameplay action for hook checks. */
  async action(kind, args) {
    if (!this.connected) return;
    this.seq += 1;
    await this._post('/action', {
      sid: this.sid, seq: this.seq, t: Date.now(), d: { k: kind, args: args || {} }
    });
  }

  _handleFrames(frames) {
    for (const f of frames || []) {
      const d = f.d || {};
      if (f.type === 'warn' && this.onWarn) this.onWarn(d.code, d.detail);
      else if (f.type === 'ban') { this.sid = null; if (this.onBan) this.onBan(d.reason); }
      else if (f.type === 'kick') { this.sid = null; if (this.onKick) this.onKick(d.reason); }
    }
  }
}

'use strict';

const net = require('net');

/**
 * GuardClient — reference client SDK (Node.js).
 *
 * Drop this into any Node game server or tooling. For game engines, see
 * client-sdks/ (luau/gdscript/csharp are wire-compatible with this class).
 *
 * A client is *expected* to be regularly reporting state. The server keys all
 * validation off its OWN clock; the client only supplies a monotonic seq and a
 * monotonic timestamp to defeat replay/spoofing, and sends position + ground
 * flag. The server decides what is physically possible (world profile).
 */

class GuardClient {
  /**
   * @param {object} opts
   * @param {string} opts.host
   * @param {number} opts.port
   * @param {string} opts.account
   * @param {string} [opts.version] defaults to 'guard-1.0'
   * @param {string} [opts.world] world profile name (see server/config.js)
   * @param {number} [opts.intervalMs] state cadence (>= server minStateIntervalMs)
   * @param {number} [opts.reconnectMs] reconnect delay after an unexpected drop
   * @param {object} [opts.handlers] onWelcome,onWarn,onBan,onKick,onAck,onError,onClose
   */
  constructor(opts) {
    this.opts = Object.assign(
      { version: 'guard-1.0', intervalMs: 150, reconnectMs: 2000 },
      opts
    );
    this.handlers = this.opts.handlers || {};
    this.socket = null;
    this.buffer = '';
    this.handshake = null; // {sid,...} after welcome
    this.seq = 0;
    this.connected = false;
    this._closing = false;
    this._timer = null;
    this._reconnectTimer = null;
  }

  connect() {
    const { host, port } = this.opts;
    const sock = net.createConnection({ host, port });
    sock.setNoDelay(true);
    this.socket = sock;
    this._closing = false;

    sock.on('connect', () => {
      this.connected = true;
      this._send({ type: 'hello', d: { acct: this.opts.account, version: this.opts.version, world: this.opts.world } });
    });

    sock.on('data', chunk => {
      this.buffer += chunk.toString('utf8');
      let nl = this.buffer.indexOf('\n');
      while (nl !== -1) {
        const line = this.buffer.slice(0, nl).trim();
        this.buffer = this.buffer.slice(nl + 1);
        if (line) this._onFrame(line);
        nl = this.buffer.indexOf('\n');
      }
    });

    sock.on('error', () => {});
    sock.on('close', () => {
      this.connected = false;
      this.socket = null;
      this._stopTimer();
      if (this.handlers.onClose) this.handlers.onClose();
      if (!this._closing) {
        this._reconnectTimer = setTimeout(() => {
          this._reconnectTimer = null;
          if (!this._closing) this.connect();
        }, this.opts.reconnectMs);
      }
    });
    return this;
  }

  disconnect() {
    this._closing = true;
    this._stopTimer();
    if (this._reconnectTimer) { clearTimeout(this._reconnectTimer); this._reconnectTimer = null; }
    if (this.socket) { try { this.socket.end(); } catch {} }
    this.socket = null;
  }

  /** Register a monotonic state sample provider. */
  startReporting(getSample) {
    this._stopTimer();
    const ticks = () => {
      if (!this.connected) return;
      const s = (typeof getSample === 'function') ? getSample() : null;
      if (s) {
        const pos = { x: s.p ? s.p.x : s.x, y: s.p ? s.p.y : s.y, z: s.p ? s.p.z : s.z };
        this.state(pos, s.ground);
      }
    };
    ticks();
    this._timer = setInterval(ticks, this.opts.intervalMs);
  }

  state(pos, ground, vel) {
    if (!this.connected) return;
    const d = { p: pos, g: !!ground };
    if (vel) d.v = vel;
    this._send({ type: 'state', d });
  }

  action(kind, args) {
    if (!this.connected) return;
    this._send({ type: 'action', d: { k: kind, args: args || {} } });
  }

  _stopTimer() {
    if (this._timer) { clearInterval(this._timer); this._timer = null; }
  }

  _send(msg) {
    if (!this.connected) return;
    msg.v = 1;
    msg.id = this.handshake ? this.handshake.sid : null;
    msg.seq = this.seq++;
    msg.t = Date.now();
    this.socket.write(JSON.stringify(msg) + '\n');
  }

  _onFrame(line) {
    let msg;
    try { msg = JSON.parse(line); } catch { return; }
    const d = msg.d || {};
    const h = this.handlers;
    switch (msg.type) {
      case 'welcome':
        this.handshake = d;
        if (h.onWelcome) h.onWelcome(d);
        break;
      case 'warn':
        if (h.onWarn) h.onWarn(d);
        break;
      case 'ban':
        this._closing = true;
        this._stopTimer();
        if (h.onBan) h.onBan(d);
        break;
      case 'kick':
        if (h.onKick) h.onKick(d);
        break;
      case 'ack':
        if (h.onAck) h.onAck(d);
        break;
      case 'error':
        if (h.onError) h.onError(d);
        break;
      default:
        break;
    }
  }
}

module.exports = { GuardClient };

    The server owns validation; this client only REPORTs honest telemetry.
]]

local HttpService = game:GetService("HttpService")

local GuardClient = {}
GuardClient.__index = GuardClient

function GuardClient.new(opts)
    local self = setmetatable({}, GuardClient)
    self.url        = opts.url
    self.account    = opts.account
    self.version    = opts.version or "guard-1.0"
    self.world      = opts.world or "ground"
    self.intervalMs = opts.intervalMs or 120
    self.onBan      = opts.onBan or function() end
    self.onWarn     = opts.onWarn or function() end
    self.onKick     = opts.onKick or function() end
    self.sid        = nil
    self.seq        = 0
    self.connected  = false
    self.running    = false
    self.started    = os.clock()
    self._loopConn  = nil
    return self
end

local function post(self, path, body)
    local ok, res = pcall(function()
        return HttpService:PostAsync(
            self.url .. path,
            HttpService:JSONEncode(body),
            Enum.HttpContentType.ApplicationJson
        )
    end)
    if not ok then
        return nil, res
    end
    local ok2, decoded = pcall(HttpService.JSONDecode, HttpService, res)
    if not ok2 then return nil, "bad response" end
    return decoded
end

function GuardClient:connect()
    local res, err = post(self, "/handshake", {
        acct    = self.account,
        version = self.version,
        world   = self.world,
    })
    if res and res.sid then
        self.sid = res.sid
        self.connected = true
        -- honor a ban/kick sent during handshake
        if res.frames then self:_handleFrames(res.frames) end
        return true
    end
    warn("[GuardClient] handshake failed: " .. tostring(err or (res and res.error)))
    return false
end

-- A bridge client is stateless per request; call :sample() at your own tick
-- rate (>=50ms apart). Replay/ordering protection happens on the server.
function GuardClient:sample(pos, isOnGround, vel)
    if not self.connected then return end
    return self:_postState(pos, isOnGround, vel)
end

function GuardClient:_postState(pos, isOnGround, vel)
    self.seq = self.seq + 1
    local d = { p = pos, g = not not isOnGround }
    if vel then d.v = vel end
    local res, err = post(self, "/state", { sid = self.sid, seq = self.seq, t = tick() * 1000, d = d })
    if res then self:_handleFrames(res.frames or {}) end
    return res, err
end

function GuardClient:action(kind, args)
    if not self.connected then return end
    self.seq = self.seq + 1
    local res, err = post(self, "/action", {
        sid  = self.sid,
        seq  = self.seq,
        t    = tick() * 1000,
        d    = { k = kind, args = args or {} },
    })
    if res then self:_handleFrames(res.frames or {}) end
    return res, err
end

function GuardClient:_handleFrames(frames)
    for _, f in ipairs(frames) do
        local tp = f.type
        if tp == "ban" then
            self.connected = false
            self.onBan(f.d and f.d.reason or "banned")
        elseif tp == "warn" then
            self.onWarn(f.d and f.d.code, f.d and f.d.detail)
        elseif tp == "kick" then
            self.connected = false
            self.onKick(f.d and f.d.reason or "kicked")
        end
    end
end

-- Optional: start a self-reporting loop from a function you provide.
function GuardClient:start(getSample)
    self.running = true
    local last = os.clock()
    self._loopConn = task.spawn(function()
        while self.running do
            local now = os.clock()
            if now - last >= self.intervalMs / 1000 then
                last = now
                if self.connected then
                    local s = getSample()
                    if s then self:_postState(s.pos, s.ground, s.vel) end
                end
            end
            task.wait(self.intervalMs / 1000 / 2)
        end
    end)
end

function GuardClient:stop()
    self.running = false
end

return GuardClient

`deploy/install-linux.sh`:

```sh
#!/usr/bin/env bash
# Guard-Game — Linux install helper (systemd)
#
#   sudo ./deploy/install-linux.sh  \
#       --world ground \
#       --hmac-key <shared-secret> \
#       --admin-token <token>
#
# Installs to /opt/guard-game, writes /etc/guard-game.env, installs + enables
# the systemd unit, and tails logs. Run from the repo root.
set -euo pipefail

WORLD="ground"
HMAC_KEY="${GUARD_HMAC_KEY:-}"
ADMIN_TOKEN="${GUARD_ADMIN_TOKEN:-}"

while [[ $# -gt 0 ]]; do
  case "$1" in
    --world) WORLD="$2"; shift 2 ;;
    --hmac-key) HMAC_KEY="$2"; shift 2 ;;
    --admin-token) ADMIN_TOKEN="$2"; shift 2 ;;
    --prefix) PREFIX="$2"; shift 2 ;;
    *) echo "unknown arg: $1"; exit 2 ;;
  esac
done

PREFIX="${PREFIX:-/opt/guard-game}"
UNIT="/etc/systemd/system/guard-game.service"

if [[ $EUID -ne 0 ]]; then echo "run as root"; exit 1; fi
command -v node >/dev/null || { echo "node.js not found"; exit 1; }
command -v systemctl >/dev/null || { echo "systemd not found"; exit 1; }

id -u guard >/dev/null 2>&1 || useradd -r -s /usr/sbin/nologin guard
mkdir -p "$PREFIX/data" "$PREFIX/log"
# Copy server + admin + templates (keep layout the systemd unit expects).
cp -r server admin templates "$PREFIX"/
cp package.json "$PREFIX"/
chown -R guard:guard "$PREFIX"

cat > /etc/guard-game.env <<EOF
NODE_ENV=production
GUARD_HOST=0.0.0.0
GUARD_PORT=7400
GUARD_ADMIN_PORT=7401
GUARD_WORLD=$WORLD
GUARD_PERSIST=json
GUARD_LIVE_VIEWERS=1
GUARD_HMAC_KEY=$HMAC_KEY
GUARD_ADMIN_TOKEN=$ADMIN_TOKEN
EOF
chmod 600 /etc/guard-game.env

source ./deploy/guard-game.service.unit >/dev/null 2>&1 || cp deploy/guard-game.service "$UNIT"
systemctl daemon-reload
systemctl enable --now guard-game

echo "[Guard-Game] logs: journalctl -u guard-game -f"

  <h2>FAQ</h2>
  <p class="lead">Including the questions you should be asking before you trust this with a real game.</p>

  <h3>Can it catch a modified client? Memory hacks? Aimbots?</h3>
  <p><strong>No.</strong> If the client process is patched, or a DMA reader is feeding it position, the telemetry it sends is fiction and no amount of server-side math reveals that. This is the fundamental ceiling of every client-reports anti-cheat. Guard-Game's answer is architecture: the <a href="configuration.html#security">server decides what's possible</a>, so fake telemetry becomes <em>impossible</em> telemetry — and impossible is detectable. Memory editing and aim-visuals are a separate fight best handled with tamper detection you accept is weaker than advertised.</p>

  <h3>Doesn't the client need to be trusted?</h3>
  <p>Only for the narrow thing it reports: "here's where I am, here's my ground state." The server re-derives truth from the <a href="configuration.html#worlds">world profile</a>. That's the entire trade — a single JSON protocol in exchange for not writing per-engine native anti-cheat for thirty engines.</p>

  <h3>How are timestamps spoofed today, and how does this stop it?</h3>
  <p>Classic client-side anti-cheat reads the timestamps a cheater sends, so the cheater just sends timestamps that make their movement look legal. Guard-Game never does physics math on client time — <code>t</code> and <code>seq</code> are validated structurally (monotonic, finite, drift within <code>GUARD_MAX_TS_DRIFT_MS</code>) but every speed, hover, and airtime judgement runs on the server's receive clock.</p>

  <h3>Can a cheater just send a slower jump?</h3>
  <p>They can send <em>anything</em> — which is the point. Whatever they send must still be a sequence of positions that obeys the world profile's physics across time. Teleport there, climb too far, stay airborne too long, move sideways too fast, and each of those is a specific violation with a specific verdict. Momentum can't be faked across consecutive samples.</p>

  <h3>What about a cheater who only cheats a little?</h3>
  <p>Warnings and strikes exist exactly for that. <code>TELEPORT</code>, <code>SPEED</code>, and <code>HEIGHT_TOO_HIGH</code> are warn-severity; enough of them inside <code>GUARD_STRIKE_WINDOW_MS</code> escalates to a ban. Wedge-cheating with <code>RISE_VEL</code> or <code>CLIMB_ESCAPE</code> isn't really possible — those are immediate bans.</p>

  <h3>Can someone bypass it by replaying a captured session?</h3>
  <p>Replay is exactly what the anti-spoof layer is for — out-of-order or repeated <code>seq</code> values, stale timestamps, and values beyond drift tolerance are <code>SPOOF_SEQ</code>/<code>SPOOF_TS</code> and a ban. For capture-plus-replay at the packet level, turn on <code>GUARD_HMAC_KEY</code> so frames must be signed by software that holds the key.</p>

  <h3>What engines are actually supported?</h3>
  <p>Anything that can send a JSON frame — TCP for sockets, <code>POST /ingest/*</code> over HTTP otherwise. Real SDKs ship for JS (TCP + bridge), Roblox/Luau, Godot/GDScript, and Unity/C#. Unreal has no off-the-shelf C++ file; <code>server/protocol.js</code> is the spec to port. Ren'Py, AGSScript, RPG Maker, and friends can call the bridge straight from their runtime.</p>

  <h3>How is it tested?</h3>
  <p>24 tests in <code>tests/</code>, run with Node's built-in test runner (<code>npm run test</code>). They cover the physics/validator rules, flood control, HMAC auth, hooks, and a full end-to-end integration test that boots the real server and puts an honest bot and several cheaters (teleport, fly, impossible jump, flood) on real sockets. CI runs the suite on Node 18/20/22 × Linux/Windows/macOS, plus a template-generation smoke test.</p>

  <h3>Does it need a database?</h3>
  <p>No. Bans and strikes persist as JSON files (<code>bans.json</code>, <code>strikes.json</code>) with atomic writes; the audit trail is <code>guard-audit.jsonl</code>. The only runtime dependency is Node.js.</p>

  <h3>My world isn't a ground platformer. Can I still use it?</h3>
  <p>Yes — that's the <a href="configuration.html#worlds">world profiles</a> feature. The <code>hovercraft</code> profile (zero gravity, much looser caps) exists for flying-vehicle games, and you can define arbitrary worlds in <code>guard.config.json</code> with no code changes.</p>

  <h3>What's the attack surface you explicitly don't cover?</h3>
  <ul class="plain">
    <li>Client-side memory editing and visuals (aim, walls) — see the first answer.</li>
    <li>DLL injection / bytepatching <em>your</em> client — reliably undetectable from a telemetry stream; the defense is not trusting the client.</li>
    <li>Server-side cheats — if a cheater has access to your server, no anti-cheat helps.</li>
    <li>Physical access / trusted-platform attacks — pair with a TPM/attestation stack if that's your threat model.</li>
  </ul>

  <h3>How do I contribute or report an issue?</h3>
  <p>Issues and pull requests go to <a href="https://github.com/Parko-Developer/guard-game" target="_blank" rel="noopener">github.com/Parko-Developer/guard-game</a>. The code is MIT-licensed; the repo layout is the <a href="source.html">source map</a>.</p>

  <h2>Architecture</h2>
  <p class="lead">One Node.js process owns all enforcement. Clients are transport-agnostic.</p>
  <p>The whole system is <code>GuardCore</code> (<code>server/core.js</code>): it opens a TCP listener on <code>:7400</code> for engines with raw sockets and an HTTP server on <code>:7401</code> that serves both the admin API and the <code>/ingest</code> bridge for HTTP-only engines. Both paths feed the exact same session and validation pipeline, so a Roblox client over HTTP and a Unity client over TCP get identical treatment.</p>

  <div class="diagram">
    <span class="node">TCP :7400</span> (framed JSON, optional HMAC)  ┐
    <span class="note">Node game server, Godot (TCP SDK), Unity (TCP SDK)</span>  │
    &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─<span class="arrow">►</span> <span class="node">GuardCore</span> ─<span class="arrow">►</span> establish() → handleAuthed() ─<span class="arrow">►</span> verdicts
    <span class="node">HTTP :7401</span> <span class="note">admin API</span> ─<span class="arrow">►</span> ban / warn / kick / stats ┘    │
    <span class="node">HTTP :7401</span> <span class="note">/ingest</span> (Roblox, web, RGSS, ...) ─<span class="arrow">►</span> same pipeline ┘
  </div>

  <p>The per-player path through a frame looks like this:</p>

  <div class="step"><span class="n">1</span><strong>Parse</strong> — <code>protocol.js</code> checks the JSON line: version <code>v:1</code>, known type, integer <code>seq</code>, finite <code>t</code>, safe packet size.</div>
  <div class="step"><span class="n">2</span><strong>Authenticate</strong> — if <code>GUARD_HMAC_KEY</code> is set, every TCP frame must carry a valid MAC (<code>auth.js</code>). A bad MAC on a signed path is a <code>SPOOF_MAC</code> ban.</div>
  <div class="step"><span class="n">3</span><strong>Handshake</strong> — <code>hello</code> resolves the world profile, checks the client version against <code>GUARD_VERSIONS</code>, rejects banned accounts and unknown worlds, and enforces the concurrent-login policy.</div>
  <div class="step"><span class="n">4</span><strong>Spoof guard</strong> — <code>antiSpoof.js</code> verifies the client's <code>seq</code> and timestamp aren't being replayed or reordered beyond <code>GUARD_MAX_TS_DRIFT_MS</code>.</div>
  <div class="step"><span class="n">5</span><strong>Flood guard</strong> — <code>floodguard.js</code> token buckets for state, action, and hello cadence. Overflow is a ban, not a shrug.</div>
  <div class="step"><span class="n">6</span><strong>Validate</strong> — <code>validator.js</code> runs the physics checks below, and <code>gamehooks.js</code> runs the action checks for give / quest / macro.</div>
  <div class="step"><span class="n">7</span><strong>Verdicts</strong> — warnings become strikes, strikes stack, and passing the threshold reaches <code>banhammer.js</code>, which persists <code>bans.json</code> and <code>strikes.json</code> atomically.</div>

  <h2 id="protocol">The wire protocol</h2>
  <p>Every frame is one newline-terminated JSON object. It's the whole integration surface:</p>
  <pre><code>{"v":1,"id":"&lt;nullable session id&gt;","type":"hello|state|action","seq":&lt;int&gt;,"t":&lt;client ms&gt;,"d":{...}}</code></pre>
  <table>
    <thead><tr><th>Type</th><th>Payload <code>d</code></th><th>When</th></tr></thead>
    <tbody>
      <tr><td><code>hello</code></td><td><code>{acct, version, world}</code></td><td>once, when the client connects</td></tr>
      <tr><td><code>state</code></td><td><code>{p:{x,y,z}, g:&lt;onGround&gt;, v?:{x,y,z}}</code></td><td>every physics frame</td></tr>
      <tr><td><code>action</code></td><td><code>{k:'give'|'quest_claim'|'macro', args:{...}}</code></td><td>on gameplay events</td></tr>
    </tbody>
  </table>
  <p>The server replies with <code>welcome</code> (with the world policy so the client can self-tune), <code>ack</code>, <code>warn</code>, <code>ban</code>, <code>kick</code>, or <code>error</code>.</p>

  <h2 id="checks">The jump-height and airtime checks</h2>
  <p>For each player the validator (<code>server/validator.js</code>) keeps a jump record: launch position, the apex reached, and how long they've been airborne. On every <code>state</code> sample it runs these:</p>
  <table>
    <thead><tr><th>#</th><th>Check</th><th>What trips it</th><th>Verdict</th></tr></thead>
    <tbody>
      <tr><td>1</td><td><code>RISE_VEL</code></td><td>upward velocity above what a legit jump impulse allows, after climbing past half a jump</td><td class="s-ban">ban</td></tr>
      <tr><td>2</td><td><code>CLIMB_ESCAPE</code></td><td>net climb in one airborne stretch over <code>maxClimbPerAirborne</code></td><td class="s-ban">ban</td></tr>
      <tr><td>3</td><td><code>HOVER</code></td><td>airborne past <code>maxHoverTimeMs</code> with under 0.1 units of horizontal drift</td><td class="s-ban">ban</td></tr>
      <tr><td>4</td><td><code>AIRTIME</code></td><td>airborne long and still gaining height</td><td class="s-ban">ban</td></tr>
      <tr><td>5</td><td><code>HEIGHT_TOO_HIGH</code></td><td>on landing, the completed jump's apex exceeds <code>maxJumpHeight × maxJumpApexTolerance</code></td><td class="s-warn">warn (strike)</td></tr>
      <tr><td>—</td><td><code>OUT_OF_BOUNDS</code></td><td>position outside the world's <code>bounds</code> (that's how flying over the map is caught too)</td><td class="s-warn">warn</td></tr>
      <tr><td>—</td><td><code>SPEED</code> / <code>TELEPORT</code></td><td>horizontal speed over <code>maxGroundSpeed</code>, or one-sample displacement over <code>maxTeleportDist</code></td><td class="s-warn">warn (strike)</td></tr>
      <tr><td>—</td><td><code>BAD_POS</code> / <code>STALE</code></td><td>non-finite coordinates, or the client pausing samples</td><td class="s-warn">warn</td></tr>
    </tbody>
  </table>
  <div class="highlight">
    <p>Because every sample is stamped with the <strong>server's receive time</strong>, "the player was in the air for an impossible amount of time" is measured in your clock, not the cheater's. Latency is irrelevant; nothing the client says about time is trusted.</p>
  </div>

  <h2>World profiles</h2>
  <p>A world profile is just a bag of numbers describing what is physically possible. The <code>ground</code> profile ships as the default; <code>hovercraft</code> is there for flying vehicles (zero gravity, higher caps). The server resolves the profile from the client's <code>hello.world</code> (or <code>GUARD_WORLD</code>).</p>
  <pre><code>ground: {
  gravity: 9.81,          // units/s^2, informational
  maxJumpHeight: 1.25,    // legit max jump apex (units)
  maxJumpApexTolerance: 1.6,
  maxClimbPerAirborne: 4.5,
  maxRiseSpeed: 6.7,      // sqrt(2·g·h) with tolerance
  maxGroundSpeed: 12,     // units/s
  maxHoverTimeMs: 2500,
  maxFlagAirtimeMs: 4000,
  maxTeleportDist: 8,
  minStateIntervalMs: 50,
  maxStateIntervalMs: 400,
  bounds: { x: [-1000, 1000], y: [0, 256], z: [-1000, 1000] }
}</code></pre>
  <p>Add your own profiles in <code>GUARD_CONFIG</code> — the validator is fully data-driven and never needs code changes per world. See <a href="configuration.html#worlds">Configuration → Worlds</a>.</p>

  <h2>Strikes, bans, and persistence</h2>
  <p><code>banhammer.js</code> runs the "wheel of consequences":</p>
  <ul class="plain">
    <li>A <em>ban-severity</em> violation bans the account immediately.</li>
    <li>A <em>warn-severity</em> violation adds a strike; <code>strikesToBan</code> strikes inside <code>strikeWindowMs</code> produce a ban.</li>
    <li>Strikes survive restarts (<code>strikes.json</code>), so a cheater can't farm warnings and clear the slate by rebooting the server.</li>
    <li>Bans can be temporary (<code>durationMs</code>) and expire lazily on a background sweep.</li>
    <li>All writes are atomic (temp file + rename) with corruption recovery — a crashed write can't nuke the ban list.</li>
  </ul>
  <p>Banned accounts are rejected at the <code>hello</code> handshake on their next attempt, and every verdict, join, kick, and expire is appended to a JSONL audit trail.</p>

  <h2>Game-action hooks</h2>
  <p>The physics layer can't see money-givers or quest farmers, so <code>gamehooks.js</code> checks gameplay actions reported through <code>action</code> frames:</p>
  <ul class="plain">
    <li><strong>give</strong> — illegal amounts (<code>GIVE_BAD_AMOUNT</code>) and give-floods that match money-giver bot patterns (<code>GIVE_FLOOD</code>).</li>
    <li><strong>quest_claim</strong> — re-claiming the same quest too fast, or churning claims at bot pace (<code>QUEST_FARM</code>).</li>
    <li><strong>macro</strong> — input faster than a human should manage (<code>MACRO</code>).</li>
  </ul>
  <p>All abuse funnels into the same warn → strike → ban pipeline as movement cheats. The deep-dive lives in <a href="https://github.com/Parko-Developer/guard-game/blob/main/server/gamehooks.js" target="_blank" rel="noopener">server/gamehooks.js</a>.</p>

  <div class="highlight danger">
    <p><strong>The honest ceiling.</strong> None of this stops a modified client. If a cheater patches the binary or uses a DMA reader, the telemetry they send is fiction and no server can tell. The defense is architecture: movement that only the server authorizes, packet auth (<code>GUARD_HMAC_KEY</code>), and not trusting the client in the first place.</p>
  </div>

  <h2>What it is</h2>
  <p class="lead">Anti-cheat that lives on the server, not in the client.</p>
  <p>Every frame your game client sends its position, velocity, ground state, and gameplay actions over one JSON protocol.   <p>Built in plain Node.js with no runtime dependencies. One process, two ports, SDKs for the engines people actually ship games in.</p>

  <p>Warnings accumulate as strikes. Cross <code>GUARD_STRIKES_TO_BAN</code> (default 3) inside <code>GUARD_STRIKE_WINDOW_MS</code> (default 60 s) and the player is banned. Bans are written to <code>server/data/bans.json</code> and enforced again at login.</p>

  <h2>Why it's built this way</h2>
  <div class="grid">
    <div class="card"><h4>Server-authoritative</h4><p>The client only reports. Physics happens in a <a href="configuration.html#worlds">world profile</a> on the server, keyed to <code>maxJumpHeight</code>, <code>maxGroundSpeed</code>, bounds, and airtime caps.</p></div>
    <div class="card"><h4>Server clock only</h4><p>No trusting client <code>t</code> or <code>seq</code>. Hover, airtime, and speed are measured against receive time. See <a href="how-it-works.html#checks">the checks</a>.</p></div>
    <div class="card"><h4>Engine-agnostic</h4><p>One JSON line per frame. <a href="install.html#sdks">SDKs</a> for Unity, Godot, Roblox, and JS; anything else can call the HTTP bridge directly.</p></div>
    <div class="card"><h4>Operable</h4><p><a href="install.html#admin">Admin console</a> for stats, live frame tail, bans, strikes, kicks. Optional <code>GUARD_HMAC_KEY</code> wire auth on the TCP path.</p></div>
  </div>

  <h2>Project layout</h2>
  <pre><code>server/          core, protocol, validator, banhammer, hooks, flood, spoof,
                 bridge, admin API
client-sdks/     js (TCP + bridge), luau (Roblox), gdscript (Godot),
                 csharp (Unity)
admin/           server-side admin console client
tests/           unit + end-to-end suites
templates/       make.ps1 — scaffold a plugin into your game
docs/            this site + the full install guide</code></pre>

  <div class="highlight">
    <p><strong>Before you trust it blindly:</strong> no client-reporting anti-cheat is unbeatable. A modified client, DMA reader, or patched executable can always send fiction. Guard-Game assumes the client reports and the server re-derives truth from the world profile — that's the honest ceiling of the approach, and it's discussed in the <a href="faq.html">FAQ</a>.</p>

  <h2>Install into your game</h2>
  <p class="lead">Roughly ten minutes from clone to a live anti-cheat. Zero runtime dependencies — no database, no ORM, no supervisor.</p>
  <div class="highlight">
    <p>This page is the short version. The full, line-by-line guide with verification steps lives at <a href="INSTALL.md"><code>INSTALL.md</code></a> in the repo root — start there if you hit any snag.</p>

  <h2>1. Prerequisites</h2>
  <table>
    <thead><tr><th>Thing</th><th>Version</th></tr></thead>
    <tbody>
      <tr><td>Node.js</td><td>18+ (20 LTS recommended)</td></tr>
      <tr><td>Your game</td><td>any engine that can send JSON over TCP or HTTP — see the SDK table below</td></tr>
      <tr><td>Host machine</td><td>a cheap VPS or your existing game server box; Node 18+ is all that's required</td></tr>
    </tbody>

  <h2>2. Get the code and start the server</h2>
  <pre><code>git clone https://github.com/Parko-Developer/guard-game.git guard
cd guard
npm install          # dev-only: pulls the test runner for `npm run test`</code></pre>
  <p>Then start the guard server. Set the admin token first — the default is a dev value on purpose:</p>
  <pre><code># Linux / macOS
GUARD_ADMIN_TOKEN=$(openssl rand -hex 24) node server/index.js

# Windows (PowerShell)
$env:GUARD_ADMIN_TOKEN = (openssl rand -hex 24) ; node server/index.js</code></pre>
  <p>You should see one process on two ports:</p>
  <pre><code>[Guard-Game] v1.0.0 started
  tcp  :7400   (game engines with raw sockets)
  http :7401   (admin API + /ingest bridge for HTTP-only engines)</code></pre>
  <ul class="plain">
    <li><strong>:7400 (TCP)</strong> — low-latency framed JSON for engines that can open sockets (Node game servers, and the TCP SDKs).</li>
    <li><strong>:7401 (HTTP)</strong> — the admin API <em>and</em> the <code>/ingest</code> bridge for engines that can't open raw sockets (Roblox, browser JS, story game runtimes).</li>
  </ul>
  <div class="highlight warn">
    <p>Keep the admin API private. <code>GUARD_ADMIN_BIND=127.0.0.1</code> is the default on purpose. If the guard server sits on a separate box from your game, forward only :7400/:7401 and never expose the admin port publicly.</p>
  </div>

  <h2 id="sdks">3. Pick your SDK</h2>
  <p>Copy the matching SDK into your project. Every SDK speaks the same protocol, so the server is identical no matter which engine it fronts.</p>
  <table>
    <thead><tr><th>Engine</th><th>File</th><th>Transport</th></tr></thead>
    <tbody>
      <tr><td>Godot / GDScript</td><td><code>client-sdks/gdscript/guard_client.gd</code></td><td>TCP, attach as an autoload</td></tr>

      <tr><td>Roblox / Luau</td><td><code>client-sdks/luau/guardClient.lua</code></td><td>HTTP <code>/ingest</code> — Roblox can't open raw sockets</td></tr>
      <tr><td>JS / web / Node</td><td><code>client-sdks/js/guardClient.js</code> or <code>guardBridgeClient.js</code></td><td>TCP or HTTP bridge</td></tr>
      <tr><td>Unreal / C++</td><td>port <code>server/protocol.js</code></td><td>no off-the-shelf C++ file; the C# version is the reference</td></tr>
      <tr><td>Anything else (Ren'Py, AGSScript, RPG Maker...)</td><td>call the HTTP bridge directly</td><td><code>POST /ingest/handshake|state|action</code></td></tr>

  <h2>4. Wire it into gameplay</h2>
  <p>Open the SDK file and fill in the <code>WIRE ME</code> block — account id, server URL, and world profile:</p>
  <pre><code>guard.account = "account-" .. player.id      -- per-player id
guard.url    = "ws://127.0.0.1:7400/guards"  -- or the HTTP bridge URL
guard.world  = "ground"                       -- pick a world profile</code></pre>
  <p>Then call it every physics frame with the player's honest state:</p>
  <pre><code>-- Roblox (ServerScriptService), every frame:
guard:sample(
    { x = root.Position.X, y = root.Position.Y, z = root.Position.Z },
    root.AssemblyLinearVelocity.Y == 0,
    root.AssemblyLinearVelocity
)</code></pre>
  <pre><code>// Unity, inside FixedUpdate:
await guard.Sample(
    pos,
    Mathf.Abs(rb.velocity.y) &lt; 0.01f,
    rb.velocity);</code></pre>
  <p>The SDK handles the handshake, per-frame sampling, and reconnecting. You only feed it honest telemetry — the server decides.</p>

  <h2>5. Report gameplay actions (the hook layer)</h2>
  <p>Anti-cheat needs to know what the player <em>did</em>, not just where they went. Hook your economy and quest endpoints:</p>
  <pre><code>guard.action("give",        { item = "coins", amount = 100 });
guard.action("quest_claim", { questId = "daily", reward = 50 });</code></pre>
  <p>So when a cheater duplicates cash or insta-completes a quest, the server can cross-check the action against the world profile and the admin rules.</p>

  <h2 id="admin">6. Admin console</h2>
  <p><code>node admin/console.js</code> is a thin client over the HTTP admin API. Needs the token; by default it only talks to <code>127.0.0.1</code>.</p>
  <pre><code>node admin/console.js --cmd stats                    # live counters
node admin/console.js --cmd players                  # connected sessions
node admin/console.js --cmd events                   # recent audit trail
node admin/console.js --cmd live                     # tail the audit trail
node admin/console.js --cmd bans                     # ban list
node admin/console.js --cmd strikes --acct A         # a player's strikes
node admin/console.js --cmd ban --acct A --reason "wallhacking"
node admin/console.js --cmd unban --acct A
node admin/console.js --cmd kick --acct A --reason "behave"
node admin/console.js --cmd url                      # print the API location</code></pre>
  <p>With <code>npm run admin</code> the same commands work as <code>npm run admin -- --cmd stats</code>.</p>

  <h2>7. Verify it works</h2>
  <pre><code>npm run demo</code></pre>
  <p>The demo spawns one honest bot and one cheater (teleport + impossible jump) and prints every violation with its severity and the world rule it tripped. Watch it live against real players with <code>--cmd live</code>.</p>

  <h2>8. Go to production</h2>
  <h3>A) One-file build script</h3>
  <pre><code>./scripts/build.sh --package         # Linux / macOS
.\scripts\build.ps1 -Package         # Windows</code></pre>
  <p>Emits <code>releases/guard-game-&lt;version&gt;.zip</code> to ship with a pinned Node version.</p>
  <h3>B) Docker</h3>
  <pre><code>docker compose up -d --build</code></pre>
  <p>Health-checked container, bans persisted on a volume. Set <code>GUARD_HMAC_KEY</code> and <code>GUARD_ADMIN_TOKEN</code> in the environment (never commit them).</p>
  <h3>C) systemd (bare-metal Linux)</h3>
  <pre><code>sudo ./deploy/install-linux.sh --world ground --admin-token $(openssl rand -hex 24)</code></pre>
  <p>Installs a hardened unit, an unprivileged <code>guard</code> user, and an env file with <code>0600</code> permissions. Logs: <code>journalctl -u guard-game -f</code>.</p>

  <h2>Hardening checklist</h2>
  <ul class="plain">
    <li><input type="checkbox"> <code>GUARD_HMAC_KEY</code> set and shared with the SDK (TCP path)</li>
    <li><input type="checkbox"> <code>GUARD_ADMIN_TOKEN</code> set to a long random value</li>
    <li><input type="checkbox"> Admin API bound to <code>127.0.0.1</code> or behind a proxy with its own auth</li>
    <li><input type="checkbox"> World profiles match your real map (ceiling height, jump apex, speed cap)</li>
    <li><input type="checkbox"> <code>npm run test</code> passes in your CI</li>
  </ul>

  <pre><code>.\templates\make.ps1 -Target ..\MyGame\GuardPlugins -GameName MyGame -Engine godot -World ground</code></pre>

// Guard-Game — cross-platform build/driver used by scripts/build.sh and
// scripts/build.ps1. No npm deps.
//
//   node scripts/build.js                 # run the full test suite
//   node scripts/build.js --package       # run tests, then zip a release

const fs = require('fs');
const path = require('path');

const ROOT = path.resolve(__dirname, '..');
const pkg = require(path.join(ROOT, 'package.json'));

function run(cmd, args, opts = {}) {
  const r = spawnSync(cmd, args, { cwd: ROOT, stdio: 'inherit', ...opts });
  if (r.error) throw r.error;
  if (r.status !== 0) process.exit(r.status);
}

function zipDir(src, dest) {
  const SevenZip = require('sevenzip' /* intentionally soft */);
  return true;
}

function main() {
  const argv = process.argv.slice(2);
  const wantPackage = argv.includes('--package');

  console.log(`[Guard-Game] ${pkg.version} — build driver`);
  console.log('[Guard-Game] running test suite…');
  run(process.execPath, ['--test', '--test-timeout=40000', 'tests/']);

  if (!wantPackage) {
    console.log('[Guard-Game] ok (tests pass). Use --package to emit a release zip.');
    return;
  }

  const outDir = (() => {
    const i = argv.indexOf('--zip-out');
    return i >= 0 ? path.resolve(argv[i + 1]) : path.join(ROOT, 'releases');
  })();

  const zipPath = path.join(outDir, `guard-game-${pkg.version}.zip`);

  // Simple cross-platform zip: prefer PowerShell Compress-Archive on Windows,
  // otherwise fall back to node's built-ins via a tiny deflate writer isn't
  // available, so we depend on `zip` on POSIX and Compress-Archive on Windows.
  if (process.platform === 'win32') {
    const args = ['-NoProfile', '-Command',
      `Compress-Archive -Path 'server','admin','templates','client-sdks','tests' -DestinationPath '${zipPath}' -Force`];
    run('powershell', args);
  } else {
    run('zip', ['-qr', zipPath, 'server', 'admin', 'templates', 'client-sdks', 'tests']);
  }
  console.log(`[Guard-Game] release: ${zipPath}`);
}

const path = require('path');

'use strict';

const http = require('http');
const fs = require('fs');
const path = require('path');
const { timingSafeEqual } = require('crypto');

/**
 * HTTP API = the ADMIN-facing surface. This is the "server-side admin client
 * endpoint": only callable by admins holding the admin token, bound to
 * 127.0.0.1 by default so remote hosts can't reach it at all.
 *
 * Endpoints:
 *   GET  /api/health               liveness
 *   GET  /api/version              build + policy fingerprint
 *   GET  /api/stats                counters + uptime
 *   GET  /api/players              connected sessions
 *   GET  /api/events?since=ID&limit=N   audit trail
 *   GET  /api/bans                 ban list (incl. temporary/expiry)
 *   GET  /api/strikes?acct=        strike details for one account
 *   GET  /api/config               effective policy (secrets redacted)
 *   POST /api/ban    {acct, reason, durationMs?}
 *   POST /api/unban  {acct}
 *   POST /api/kick   {acct, reason?}
 *   POST /api/warn   {acct, code?, detail?}
 */

const VERSION = (() => {
  try {
    return JSON.parse(fs.readFileSync(path.join(__dirname, '..', 'package.json'), 'utf8')).version || '0.0.0';
  } catch {
    return '0.0.0';
  }
})();

function safeEqual(a, b) {
  const ab = Buffer.from(String(a ?? ''));
  const bb = Buffer.from(String(b ?? ''));
  return ab.length === bb.length && timingSafeEqual(ab, bb);
}

function json(res, status, obj) {
  const body = JSON.stringify(obj);
  res.writeHead(status, { 'Content-Type': 'application/json', 'Content-Length': Buffer.byteLength(body) });
  res.end(body);
}

function readBody(req) {
  return new Promise((resolve, reject) => {
    const chunks = [];
    let size = 0;
    req.on('data', c => {
      size += c.length;
      if (size > 64 * 1024) { req.destroy(); reject(new Error('body too large')); return; }
      chunks.push(c);
    });
    req.on('end', () => {
      try {
        const text = Buffer.concat(chunks).toString('utf8');
        resolve(text ? JSON.parse(text) : {});
      } catch (e) {
        reject(new Error('bad JSON body'));
      }
    });
    req.on('error', reject);
  });
}

function createAdminServer(env) {
  const { config, sessions, events, banHammer, startedAt } = env;
  const authFailures = new Map(); // ip -> {count, resetAt}

  const allowed = ip => {
    const now = Date.now();
    let rec = authFailures.get(ip);
    if (!rec || now > rec.resetAt) { rec = { count: 0, resetAt: now + config.adminAuthFailWindowMs }; authFailures.set(ip, rec); }
    rec.count += 1;
    if (authFailures.size > 5000) for (const [k, v] of authFailures) if (now > v.resetAt) authFailures.delete(k);
    return rec.count <= config.adminMaxAuthFails;
  };

  return async function handle(req, res) {
    const url = new URL(req.url, 'http://localhost');
    const path = url.pathname;
    const ip = req.socket.remoteAddress || 'unknown';

    const auth = req.headers.authorization || '';
    const token = auth.startsWith('Bearer ') ? auth.slice(7) : '';
    if (!safeEqual(token, config.adminToken)) {
      if (!allowed(ip)) return json(res, 429, { error: 'too many auth failures' });
      return json(res, 401, { error: 'unauthorized' });
    }

    try {
      if (req.method === 'GET' && path === '/api/health') {
        return json(res, 200, { ok: true, uptimeMs: Date.now() - startedAt, players: sessions.size });
      }

      if (req.method === 'GET' && path === '/api/version') {
        return json(res, 200, {

          policy: `${config.defaultWorld}/s${config.strikesToBan}h${config.strikesToBan > 0 ? 's' : ''}`,
          hmacEnabled: !!config.hmacKey,
          bridgeProtected: !!config.bridgeKey
        });
      }

      if (req.method === 'GET' && path === '/api/stats') {
        return json(res, 200, {
          players: sessions.size,
          bans: banHammer.bans.size,
          temporaryBans: [...banHammer.bans.values()].filter(b => b.until).length,
          strikes: banHammer.strikesSummary(),
          version: VERSION,
          uptimeMs: Date.now() - startedAt
        });
      }

      if (req.method === 'GET' && path === '/api/players') {
        return json(res, 200, { players: [...sessions.values()].map(p => p.summary()) });
      }

      if (req.method === 'GET' && path === '/api/events') {
        const since = Number(url.searchParams.get('since')) || 0;
        const limit = Math.max(1, Math.min(Number(url.searchParams.get('limit')) || 200, config.eventsRing));
        const all = events.since(since);
        return json(res, 200, { events: url.searchParams.has('limit') ? all.slice(-limit) : all });
      }

      if (req.method === 'GET' && path === '/api/bans') {
        return json(res, 200, { bans: banHammer.listBans() });
      }

      if (req.method === 'GET' && path === '/api/strikes') {
        const acct = url.searchParams.get('acct');
        if (acct) return json(res, 200, { acct, strikes: banHammer.strikesOf(acct) });
        return json(res, 200, { strikes: banHammer.strikesSummary() });
      }

      if (req.method === 'GET' && path === '/api/config') {
        const { hooks, supply, ...rest } = config;
        return json(res, 200, {
          ...rest,
          adminToken: '***', bridgeKey: config.bridgeKey ? '***' : '', hmacKey: config.hmacKey ? '***' : '',
          hooks, worldProfiles: Object.keys(supply.WORLD_PROFILES)
        });
      }

      if (req.method === 'POST' && path === '/api/ban') {
        const body = await readBody(req);
        const acct = body.acct || url.searchParams.get('acct');
        const reason = body.reason || url.searchParams.get('reason');
        const durationMs = Number(body.durationMs ?? url.searchParams.get('durationMs')) || null;
        if (!acct) return json(res, 400, { error: 'acct required' });
        const did = banHammer.ban(acct, reason || 'banned by admin', 'admin', durationMs);
        if (did) {
          const session = [...sessions.values()].find(p => p.acct === acct);
          if (session) session.ban(durationMs ? `banned for ${Math.round(durationMs / 60000)}m by admin` : 'banned by admin');
        }
        return json(res, did ? 200 : 409, { banned: did });
      }

      if (req.method === 'POST' && path === '/api/unban') {
        const body = await readBody(req);
        const acct = body.acct || url.searchParams.get('acct');
        if (!acct) return json(res, 400, { error: 'acct required' });
        return json(res, 200, { unbanned: banHammer.unban(acct) });
      }

      if (req.method === 'POST' && path === '/api/kick') {
        const body = await readBody(req);
        const acct = body.acct || url.searchParams.get('acct');
        const reason = body.reason || url.searchParams.get('reason');
        if (!acct) return json(res, 400, { error: 'acct required' });
        const session = [...sessions.values()].find(p => p.acct === acct);
        if (!session) return json(res, 404, { error: 'no such online player' });
        banHammer.kick(acct, reason || 'kicked by admin');
        session.kick(reason || 'kicked by admin');
        return json(res, 200, { kicked: true });
      }

      if (req.method === 'POST' && path === '/api/warn') {
        const body = await readBody(req);
        const acct = body.acct || url.searchParams.get('acct');
        if (!acct) return json(res, 400, { error: 'acct required' });
        const res2 = banHammer.report(acct, {
          code: body.code || 'ADMIN_WARN',
          severity: 'warn',
          detail: body.detail || 'warned by admin'
        });
        const session = [...sessions.values()].find(p => p.acct === acct);
        if (session) session.warn(body.code || 'ADMIN_WARN', body.detail || 'warned by admin');
        if (res2.action === 'banned') {
          const s2 = [...sessions.values()].find(p => p.acct === acct);
          if (s2) s2.ban('banned by admin');
          return json(res, 200, { action: 'banned' });
        }
        return json(res, 200, { action: res2.action });
      }

      return json(res, 404, { error: 'not found' });
    } catch (err) {
      return json(res, 400, { error: err.message });
    }
  };
}

'use strict';

const crypto = require('crypto');

/**
 * Anti-spoof session layer.
 *
 * Key property: the anti-cheat NEVER trusts client clocks or session ids.
 *  - session id is minted and HMAC-signed server-side,
 *  - sequence numbers must be strictly monotonic per session,
 *  - client timestamps may only move forward and drift is bounded,
 *  - a spoofed object (N, NaN, Infinity) is rejected at parse time.
 */

function makeSessionId() {
  return crypto.randomBytes(16).toString('hex');
}

class SpoofGuard {
  constructor(opts = {}) {
    this.maxTsDriftMs = opts.maxTsDriftMs != null ? opts.maxTsDriftMs : 2000;
  }

  /**
   * Returns { ok } or { ok:false, violation, detail }.
   * Expects msg.seq and msg.t (client ms).
   */
  check(session, msg, now) {
    const expectedSeq = session.nextSeq;
    if (msg.seq !== expectedSeq) {
      return {
        ok: false,
        violation: 'SPOOF_SEQ',
        detail: `seq ${msg.seq} but expected ${expectedSeq}`
      };
    }
    session.nextSeq = expectedSeq + 1;

    if (msg.t !== undefined) {
      if (session.lastClientTs !== null && msg.t < session.lastClientTs) {
        return {
          ok: false,
          violation: 'SPOOF_TS',
          detail: 'client timestamp moved backwards'
        };
      }
      if (msg.t - now > this.maxTsDriftMs) {
        return {
          ok: false,
          violation: 'SPOOF_TS',
          detail: 'client timestamp claims to be in the future'
        };
      }
      session.lastClientTs = msg.t;
    }
    return { ok: true };
  }
}

module.exports = { makeSessionId, SpoofGuard };

'use strict';

/**
 * Optional HMAC frame authentication (production hardening, TCP path only).
 *
 * When GUARD_HMAC_KEY is set, every authenticated frame MUST carry a message
 * authentication code:
 *
 *   m = hex( HMAC_SHA256( key,
 *                        `${type}|${id||''}|${seq}|${t||''}|stableJSON(d)` ) )
 *
 * This stops third-party packet injection, trivial replay, and middlebox
 * tampering against the wire when the shared key is only known to real game
 * servers (it is NOT a defense against a fully compromised client — nothing
 * is; see README "honest limitations").
 *
 * stableJSON() is deterministic (sorted keys, compact) so the signing client
 * and the verifying server always agree on the byte string.
 */

const crypto = require('crypto');

function isPlainObject(v) {
  return v !== null && typeof v === 'object' && !Array.isArray(v);
}

function stableJSON(obj) {
  if (Array.isArray(obj)) return `[${obj.map(stableJSON).join(',')}]`;
  if (isPlainObject(obj)) {
    const keys = Object.keys(obj).sort();
    return `{${keys.map(k => `${JSON.stringify(k)}:${stableJSON(obj[k])}`).join(',')}}`;
  }
  if (typeof obj === 'number') {
    return Number.isInteger(obj) ? String(obj) : String(Number(obj.toFixed(6)));
  }
  return JSON.stringify(obj);
}

function computeMac(key, msg) {
  const canonical = [
    msg.type || '',
    msg.id || '',
    Number.isInteger(msg.seq) ? msg.seq : '',
    Number.isFinite(msg.t) ? Math.floor(msg.t) : ''
  ].join('|') + '|' + stableJSON(msg.d || {});
  return crypto.createHmac('sha256', String(key)).update(canonical, 'utf8').digest('hex');
}

/**
 * @returns {boolean} true when the frame's `m` matches the mac, or when no key
 * is configured (authentication disabled on this server).
 */
function verifyMac(key, msg) {
  if (!key) return true;
  const theirMac = msg.m;
  if (typeof theirMac !== 'string' || theirMac.length !== 64) return false;
  const mine = Buffer.from(computeMac(key, msg), 'hex');
  const theirs = Buffer.from(theirMac, 'hex');
  return theirs.length === mine.length && crypto.timingSafeEqual(theirs, mine);
}

module.exports = { computeMac, verifyMac, stableJSON };

```js
'use strict';

const fs = require('fs');
const path = require('path');

/**
 * Wheel of consequences + persistent ban list (production hardened).
 *
 * Policy:
 *   - a BAN-severity violation bans the player immediately,
 *   - a WARN-severity violation adds a strike; strikesToBan strikes within
 *     strikeWindowMs ban the player,
 *   - strikes survive server restarts (strikes.json) so churn doesn't farm
 *     warnings or forgive past behaviour on reboot,
 *   - bans can be temporary (durationMs) and are lazily auto-expired,
 *   - writes are atomic (tmp file + rename) with corruption recovery. */
class BanHammer {
  constructor(cfg, events) {
    this.cfg = cfg;
    this.events = events;
    this.bans = new Map(); // acct -> {at, reason, source, until}
    this.strikes = new Map(); // acct -> [{code, at}]
    this.dir = cfg.dataDir;
    this.banFile = path.join(cfg.dataDir, 'bans.json');
    this.strikeFile = path.join(cfg.dataDir, 'strikes.json');
    this._loadBans();
    this._loadStrikes();
  }

  _recover(file, dropTo) {
    try {
      const backup = `${file}.corrupt.${Date.now()}`;
      fs.renameSync(file, backup);
      this.events && this.events.append('system', null, 'warn', `recovered corrupt persistence file: ${backup}`);
    } catch { /* ignore */ }
    return dropTo;
  }

  _loadBans() {
    try {
      const arr = JSON.parse(fs.readFileSync(this.banFile, 'utf8'));
      if (!Array.isArray(arr)) return this._recover(this.banFile, '');
      for (const b of arr) {
        if (b && b.acct) this.bans.set(b.acct, { at: b.at, reason: b.reason, source: b.source, until: b.until || null });
      }
    } catch {
      /* no bans file yet */
    }
  }

  _loadStrikes() {
    try {
      const arr = JSON.parse(fs.readFileSync(this.strikeFile, 'utf8'));
      if (!Array.isArray(arr)) return this._recover(this.strikeFile, '');
      for (const s of arr) {
        if (s && s.acct && Array.isArray(s.strikes)) this.strikes.set(s.acct, s.strikes);
      }
    } catch {
      /* no strikes file yet */
    }
  }

  _save(BansOrStrikes, file) {
    try {
      fs.mkdirSync(this.dir, { recursive: true });
      const tmp = file + `.${process.pid}.tmp`;
      fs.writeFileSync(tmp, JSON.stringify(BansOrStrikes, null, 2));
      fs.renameSync(tmp, file);
    } catch (err) {
      this.events && this.events.append('system', null, 'warn', `failed to persist ${file}: ${err.message}`);
    }
  }

  _saveBans() {
    this._save([...this.bans.entries()].map(([acct, b]) => ({ acct, ...b })), this.banFile);
  }

  _saveStrikes() {
    this._save([...this.strikes.entries()].map(([acct, strikes]) => ({ acct, strikes })), this.strikeFile);
  }

  /** Remove expired temporary bans. Returns the list of accounts unbanned. */
  _expireNow() {
    const now = Date.now();
    const gone = [];
    for (const [acct, b] of this.bans) {
      if (b.until && b.until <= now) {
        this.bans.delete(acct);
        gone.push(acct);
      }
    }
    if (gone.length) {
      this._saveBans();
      for (const acct of gone) this.events.append('expire', acct, 'info', 'temporary ban expired');
    }
  }

  /** Lazy expiry sweep. Also used by the core on an interval. */
  sweep() {
    this._expireNow();
  }

  isBanned(acct) {
    const b = this.bans.get(acct);
    if (!b) return false;
    if (b.until && b.until <= Date.now()) {
      this._expireNow();
      return false;
    }
    return true;
  }

  /** Ban an account. Returns true when the ban was newly applied. */
  ban(acct, reason, source = 'auto', durationMs = null) {
    const detail = reason || 'no reason given';
    if (this.isBanned(acct)) return false;
    const until = durationMs && durationMs > 0 ? Date.now() + durationMs : null;
    this.bans.set(acct, { at: Date.now(), reason: detail, source, until });
    this._saveBans();
    this.events.append('ban', acct, 'ban', detail, { source, temporary: !!until });
    return true;
  }

  unban(acct) {
    const removed = this.bans.delete(acct);
    if (removed) {
      this._saveBans();
      this.events.append('unban', acct, 'info', 'banned player unbanned');
    }
    return removed;
  }

  kick(acct, reason) {
    this.events.append('kick', acct, 'warn', reason || 'kicked by admin');
  }

  listBans() {
    const now = Date.now();
    return [...this.bans.entries()]
      .map(([acct, b]) => ({ acct, at: b.at, reason: b.reason, source: b.source, temporary: !!b.until, expiresAt: b.until, expired: !!(b.until && b.until <= now) }))
      .sort((a, b) => b.at - a.at);
  }

  /**
   * Register a violation. Returns { action: 'none'|'warned'|'banned', ... }.
   */
  report(acct, verdict, extra = {}) {
    if (verdict.severity === 'ban') {
      const banned = this.ban(acct, `[${verdict.code}] ${verdict.detail}`);
      return { action: banned ? 'banned' : 'none', banned };
    }
    const now = Date.now();
    let list = this.strikes.get(acct) || [];
    list = list.filter(s => now - s.at < this.cfg.strikeWindowMs);
    list.push({ code: verdict.code, at: now });
    this.strikes.set(acct, list);
    this._saveStrikes();
    this.events.append('violation', acct, 'warn', `[${verdict.code}] ${verdict.detail}`, extra);

    if (list.length >= this.cfg.strikesToBan) {
      const banned = this.ban(acct, `repeated violations: ${list.map(s => s.code).join(',')}`);
      return { action: banned ? 'banned' : 'none', strikes: list.length, banned };
    }
    return { action: 'warned', strikes: list.length };
  }

  strikesOf(acct) {
    return this.strikes.get(acct) || [];
  }

  strikesSummary() {
    return [...this.strikes.entries()].map(([acct, s]) => ({ acct, strikes: s.length }));
  }
}

module.exports = { BanHammer };

'use strict';

const { timingSafeEqual } = require('crypto');

/**
 * HTTP ingest bridge.
 *
 * Engines without raw sockets (Roblox/Luau, browsers, RPG Maker, Ren'Py via
 * HTTP plugins, ...) report through REST-style POSTs. Same server-side
 * validation as the TCP path, different door.
 *
 *   POST /ingest/handshake   {acct, version, world, key?} -> {sid, policy, frames}
 *   POST /ingest/state       {sid, seq, t, d:{p, g, v?}}  -> {frames}
 *   POST /ingest/action      {sid, seq, t, d:{k, args}}   -> {frames}
 *
 * `key` is an optional shared secret (GUARD_BRIDGE_KEY) compared in
 * constant time. Handshakes are throttled per source IP so bots can't spin
 * sessions. A player who gets banned receives frames:[{type:'ban',...}] and
 * their session is destroyed.
 */

function readBody(req, maxBytes) {
  return new Promise((resolve, reject) => {
    const chunks = [];
    let size = 0;
    req.on('data', c => {
      size += c.length;
      if (size > maxBytes) { req.destroy(); reject(new Error('body too large')); return; }
      chunks.push(c);
    });
    req.on('end', () => {
      try { resolve(JSON.parse(Buffer.concat(chunks).toString('utf8') || '{}')); }
      catch { reject(new Error('bad JSON')); }
    });
    req.on('error', reject);
  });
}

function json(res, status, obj) {
  const body = JSON.stringify(obj);
  res.writeHead(status, { 'Content-Type': 'application/json', 'Content-Length': Buffer.byteLength(body) });
  res.end(body);
}

function keysEqual(a, b) {
  const x = Buffer.from(String(a ?? ''));
  const y = Buffer.from(String(b ?? ''));
  return x.length === y.length && timingSafeEqual(x, y);
}

function createBridge(core) {
  const cfg = core.config;
  const hellos = new Map(); // ip -> {count, resetAt}

  function allowHello(ip) {
    const now = Date.now();
    let rec = hellos.get(ip);
    if (!rec || now > rec.resetAt) {
      rec = { count: 0, resetAt: now + 60000 };
      hellos.set(ip, rec);
    }
    rec.count += 1;
    if (hellos.size > 10000) { // lazy cleanup
      for (const [k, v] of hellos) if (now > v.resetAt) hellos.delete(k);
    }
    return rec.count <= cfg.bridgeHelloPerIp;
  }

  return {
    async handle(req, res) {
      const url = new URL(req.url, 'http://localhost');
      const path = url.pathname.replace(/^\/ingest/, '') || '/handshake';

      if (req.method !== 'POST') return json(res, 405, { error: 'POST only' });

      const ip = req.socket.remoteAddress || 'unknown';

      try {
        const body = await readBody(req, cfg.maxIncomingBodyBytes || 8192);

        // Constant-time bridge key check (supports body.key or ?key=).
        const gotKey = body.key ?? url.searchParams.get('key');
        if (cfg.bridgeKey && !keysEqual(gotKey, cfg.bridgeKey)) {
          return json(res, 401, { error: 'bad bridge key' });
        }

        if (path === '/handshake') {
          // Session-creation throttle per source IP (state/action spam is
          // already rate-limited per session by the flood guard).
          if (!allowHello(ip)) {
            return json(res, 429, { error: 'handshake rate limit exceeded' });
          }
          const frames = [];
          const transport = { send: o => frames.push(o), close: () => { /* session removed via session.close */ } };
          const res2 = core.establish({
            acct: body.acct,
            version: body.version,
            world: body.world,
            key: `http:${body.acct}`,
            transport
          });
          if (!res2.ok) {
            return json(res, res2.kind === 'banned' ? 403 : 400, { error: res2.reason, frames });
          }
          return json(res, 200, { sid: res2.session.sid, policy: frames[0] ? frames[0].d.policy : null, frames });
        }

        const session = core.sessions.get(body.sid);
        if (!session) return json(res, 404, { error: 'unknown session' });
        const frames = [];
        session.transport = {
          send: o => frames.push(o),
          close: () => { /* removal handled by session.close */ }
        };
        core.handleAuthed(session, {
          v: 1,
          type: path === '/action' ? 'action' : 'state',
          id: body.sid,
          seq: body.seq,
          t: body.t,
          d: body.d || {}
        });
        return json(res, 200, { frames });
      } catch (err) {
        return json(res, 400, { error: err.message });
      }
    }
  };
}

module.exports = { createBridge };

function parseArgs(argv) {
  const out = {};
  for (let i = 0; i < argv.length; i++) {
    const a = argv[i];
    if (BOOL_FLAGS.has(a)) { out[a.slice(2).replace(/-/g, '')] = true; continue; }
    const eq = a.indexOf('=');
    let key = a; let val = null;
    if (a.startsWith('--') && eq !== -1) {
      key = a.slice(0, eq); val = a.slice(eq + 1);
    } else if (a.startsWith('--') && i + 1 < argv.length && !argv[i + 1].startsWith('--')) {
      val = argv[++i];
    }
    const name = key.replace(/^--/, '').replace(/-([a-z])/g, (_, c) => c.toUpperCase());

      port: 'port', httpPort: 'httpPort', host: 'host', adminBind: 'adminBind',

      concurrentSessionPolicy: 'concurrent', world: 'world',

'use strict';

const net = require('net');
const { config } = require('./config');
const { parseLine, validateHello, validateState, encode } = require('./protocol');
const { verifyMac } = require('./auth');
const { resolveWorld, publicPolicy } = require('./world');
const { makeSessionId, SpoofGuard } = require('./antiSpoof');
const { FloodGuard } = require('./floodguard');
const { VerdictEngine } = require('./validator');
const { BanHammer } = require('./banhammer');
const { HookGuard } = require('./gamehooks');
const EventLog = require('./events');

/**
 * GuardCore: owns all moving parts of the anti-cheat.
 *
 * Two ways in:
 *   - TCP  : framed JSON lines (game engines with raw sockets)
 *   - HTTP : bridge (engines that can only do HTTP: Roblox, web, etc.)
 *
 * Both go through the same validation: establish() -> handleAuthed().
 * Sessions talk to a tiny TRANSPORT ({ send(obj), close() }) so the same
 * session code drives sockets, HTTP responses, or tests.
 */
class GuardCore {
  constructor(cfg = config) {
    this.config = cfg;
    this.events = new EventLog(cfg.eventsRing);
    this.banHammer = new BanHammer(cfg, this.events);
    this.hooks = new HookGuard(cfg, this.banHammer, this.events);
    this.flood = new FloodGuard(cfg);
    this.spoof = new SpoofGuard({ maxTsDriftMs: cfg.maxTsDriftMs });
    this.sessions = new Map(); // sid -> PlayerSession
    this.tcpSockets = new WeakMap(); // tcp socket -> session
    this.startedAt = Date.now();
    this.tcp = null;
    this.http = null;
    this._sweepTimer = null;
  }

  start(opts = {}) {
    const tcpPort = opts.tcpPort === undefined ? this.config.port : opts.tcpPort;
    const httpPort = opts.httpPort === undefined ? this.config.httpPort : opts.httpPort;
    const adminBind = opts.adminBind || this.config.adminBind;

    // Background maintenance: ban-expiry sweep + idle session reaping.
    const sweeps = new Map();
    if (this.config.sweepIntervalMs > 0) {
      this._sweepTimer = setInterval(() => {
        this.banHammer.sweep();
        if (this.config.sessionIdleTimeoutMs > 0) {
          const idle = Date.now() - this.config.sessionIdleTimeoutMs;
          for (const s of [...this.sessions.values()]) {
            if (s.alive && (s.lastFrameAt || s.joinedAt) < idle) {
              const tag = sweeps.get(s.acct) || 0;
              if (tag < 2) { // warn on first idle sweep, kick on the second
                sweeps.set(s.acct, tag + 1);
                s.warn('IDLE', 'session idle; reporting expected');
              } else {
                sweeps.delete(s.acct);
                s.kick('idle timeout');
              }
            }
          }
        } else {
          sweeps.clear();
        }
      }, Math.max(1000, this.config.sweepIntervalMs));
    }

    this.tcp = null;
    if (tcpPort !== null && tcpPort !== undefined && tcpPort !== false) {
      this.tcp = net.createServer(sock => this._onConnection(sock));
    }

    return new Promise((resolve, reject) => {
      const onTcpErr = err => reject(err);
      let pending = [];
      const done = () => {
        if (pending.length === 0) return;
        const ok = pending.every(x => x.ok);
        if (ok) resolve({ tcpPort: this.tcp ? this.tcp.address().port : null, httpPort: this.http ? this.http.address().port : null });
        else reject(new Error('failed to bind listeners'));
      };
      if (this.tcp) {
        this.tcp.once('error', onTcpErr);
        this.tcp.listen(tcpPort, this.config.host, () => {
          this.tcp.removeListener('error', onTcpErr);
          pending.push({ ok: true });
          if (httpPort !== null && httpPort !== undefined && httpPort !== false) this._attachHttp(adminBind, httpPort, pending, done);
          else done();
        });
      } else {
        pending.push({ ok: true });
        if (httpPort !== null && httpPort !== undefined && httpPort !== false) this._attachHttp(adminBind, httpPort, pending, done);
        else done();
      }
    });
  }

  _attachHttp(adminBind, httpPort, pending, done) {
    const { createAdminServer } = require('./admin');
    const { createBridge } = require('./bridge');
    const adminHandler = createAdminServer({
      config: this.config,
      sessions: this.sessions,
      events: this.events,
      banHammer: this.banHammer,
      startedAt: this.startedAt,
      core: this
    });
    const bridge = createBridge(this);
    this.http = require('http').createServer((req, res) => {
      if (req.url.startsWith('/ingest')) {
        return bridge.handle(req, res);
      }
      return adminHandler(req, res);
    });
    this.http.once('error', err => {
      this.events.append('system', null, 'warn', `admin API failed: ${err.message}`);
      pending.push({ ok: false });
      done();
      this.http = null;
    });
    this.http.listen(httpPort, adminBind, () => {
      pending.push({ ok: true });
      done();
    });
  }

  stop() {
    if (this._sweepTimer) { clearInterval(this._sweepTimer); this._sweepTimer = null; }
    const closes = [];
    if (this.tcp) closes.push(new Promise(r => this.tcp.close(() => r())));
    for (const s of this.sessions.values()) s.kill('server shutdown');
    if (this.http) {
      if (typeof this.http.closeIdleConnections === 'function') this.http.closeIdleConnections();
      closes.push(new Promise(r => this.http.close(() => r())));
      if (typeof this.http.closeAllConnections === 'function') this.http.closeAllConnections();
    }
    return Promise.all(closes);
  }

  // ---------------------------------------------------------------------
  // Session lifecycle (shared by TCP + bridge)
  // ---------------------------------------------------------------------

  /**
   * Establish a session for a transport. On failure returns
   * { ok:false, kind:'banned'|'kicked'|'world'|'flood'|'error', reason }.
   */
  establish({ acct, version, world, key, transport }) {
    if (!acct || typeof acct !== 'string' || acct.length > 64) {
      return { ok: false, kind: 'error', reason: 'bad acct' };
    }

    if (!this.config.allowUnknownVersions && version && !this.config.allowedVersions.includes(version)) {
      transport.send({ type: 'kick', d: { reason: `unsupported client version ${version}` } });
      return { ok: false, kind: 'kicked', reason: `unsupported version ${version}` };
    }

    if (this.banHammer.isBanned(acct)) {
      const info = this.banHammer.bans.get(acct);
      transport.send({ type: 'ban', d: { reason: info.reason } });
      this.events.append('reject', acct, 'warn', 'banned player tried to join');
      return { ok: false, kind: 'banned', reason: info.reason };
    }

    const worldName = world || this.config.defaultWorld;
    const worldObj = resolveWorld(worldName, this.config);
    if (!worldObj) {
      transport.send({ type: 'kick', d: { reason: `unknown world profile '${worldName}'` } });
      return { ok: false, kind: 'world', reason: `unknown world ${worldName}` };
    }

    // Concurrent-login policy: stop account sharing / stolen-session churn.
    const policy = this.config.concurrentSessionPolicy || 'reject';
    if (policy !== 'allow') {
      const existing = [...this.sessions.values()].find(s => s.alive && s.acct === acct);
      if (existing) {
        if (policy === 'kick') {
          this.events.append('suspect', acct, 'warn', 'account logged in from a second session (old session kicked)');
          existing.kill('logged in from another session');
        } else {
          transport.send({ type: 'kick', d: { reason: 'concurrent login detected on this account' } });
          this.events.append('suspect', acct, 'warn', 'concurrent login rejected');
          return { ok: false, kind: 'kicked', reason: 'concurrent login detected' };
        }
      }
    }

    const now = Date.now();
    const session = {
      sid: makeSessionId(),
      transport,
      key: key || 'http',
      acct,
      version: version || '',
      worldName,
      world: worldObj,
      nextSeq: 1,
      lastClientTs: null,
      bucket: this.flood.newSet(key || `acct:${acct}`),
      engine: new VerdictEngine(worldObj, now),
      lastStateAt: now,
      lastFrameAt: now,
      lastWarnAt: 0,
      joinedAt: now,
      alive: true,
      warn: (code, detail) => session.transport.send({ type: 'warn', d: { code, detail } }),
      kick: reason => session.kill(reason),
      ban: reason => session.kill(`banned: ${reason}`),
      kill: reason => {
        if (!session.alive) return;
        session.alive = false;
        session.transport.send({ type: 'kick', d: { reason } });
        session.close();
      },
      close: () => {
        if (this.sessions.get(session.sid) === session) {
          this.sessions.delete(session.sid);
          this.events.append('leave', session.acct, 'info', 'session closed');
        }
        try { session.transport.close(); } catch {}
      },
      summary: () => ({
        acct: session.acct,
        sid: session.sid,
        addr: session.key,
        world: session.worldName,
        version: session.version || null,
        connectedAt: session.joinedAt,
        strikes: this.banHammer.strikesOf(session.acct).length
      })
    };

    this.sessions.set(session.sid, session);
    session.transport.send({
      type: 'welcome',
      d: { sid: session.sid, world: session.worldName, policy: publicPolicy(session.world) }
    });
    this.events.append('join', acct, 'info', `joined (${worldName})`);
    return { ok: true, session };
  }

  /**
   * Handle an authenticated message through the shared validation pipeline.
   * Frames (warn/ban/ack...) are pushed to session.transport.
   */
  handleAuthed(session, msg) {
    if (!session.alive) return;
    session.lastFrameAt = Date.now();
    const spoof = this.spoof.check(session, msg, Date.now());
    if (!spoof.ok) {
      this._alarm(session, { code: spoof.violation, severity: 'ban', detail: spoof.detail });
      return;
    }

    if (msg.type === 'state') {
      const err = validateState(msg.d);
      if (err) {
        session.transport.send({ type: 'error', d: { code: 'bad_state', message: err } });
        return;
      }
      const flood = this.flood.checkState(session.bucket);
      if (!flood.ok) {
        this._alarm(session, { code: flood.violation, severity: 'ban', detail: flood.detail });
        return;
      }
      const now = Date.now();
      const pos = msg.d.p;
      const ground = !!msg.d.g;
      const violations = session.engine.sample(pos, ground, now);
      this._applyVerdicts(session, violations);
      session.lastStateAt = now;
      session.transport.send({ type: 'ack', d: { at: msg.seq } });
      return;
    }

    if (msg.type === 'action') {
      const flood = this.flood.checkAction(session.bucket);
      if (!flood.ok) {
        this._alarm(session, { code: flood.violation, severity: 'ban', detail: flood.detail });
        return;
      }
      const { k, args } = msg.d || {};
      this._routeAction(session, k, args);
      session.transport.send({ type: 'ack', d: { at: msg.seq } });
      return;
    }
  }

  _routeAction(session, kind, args) {
    const acct = session.acct;
    let verdict = null;
    switch (kind) {
      case 'give':
        verdict = this.hooks.onGive(acct, args && args.item, args && args.amount);
        break;
      case 'quest_claim':
        verdict = this.hooks.onQuestClaim(acct, args && args.questId, args && args.reward);
        break;
      case 'macro':
      case 'action':
        verdict = this.hooks.onAction(acct, (args && args.name) || kind);
        break;
      default:
        session.transport.send({ type: 'error', d: { code: 'unknown_action' } });
        return;
    }
    if (verdict && verdict.action === 'banned') session.kill(`banned: [${verdict.code}] ${verdict.detail}`);
  }

  _applyVerdicts(session, violations) {
    const cfg = this.config;
    for (const v of violations) {
      if (v.severity === 'ban') {
        this.banHammer.ban(session.acct, `[${v.code}] ${v.detail}`);
        session.transport.send({ type: 'ban', d: { reason: `[${v.code}] ${v.detail}` } });
        session.close();
        return;
      }
      const res = this.banHammer.report(session.acct, v, { addr: session.key });
      const now = Date.now();
      if (now - session.lastWarnAt > cfg.warnCooldownMs) {
        session.lastWarnAt = now;
        session.transport.send({ type: 'warn', d: { code: v.code, detail: v.detail } });
      }
      if (res.action === 'banned') {
        session.transport.send({ type: 'ban', d: { reason: 'repeated violations' } });
        session.close();
        return;
      }
      if (cfg.autoKickOnWarn) session.kill('excessive violations');
    }
  }

  _alarm(session, verdict) {
    const acct = session ? session.acct : null;
    this.banHammer.ban(acct || 'unknown', `[${verdict.code}] ${verdict.detail}`);
    if (session) {
      session.transport.send({ type: 'ban', d: { reason: `${verdict.code}: ${verdict.detail}` } });
      session.close();
    }
  }

  // ---------------------------------------------------------------------
  // TCP transport
  // ---------------------------------------------------------------------

  _onConnection(sock) {
    const key = `${sock.remoteAddress}:${sock.remotePort}`;
    let buffer = '';
    let established = null;

    sock.setNoDelay(true);

    sock.on('data', chunk => {
      buffer += chunk.toString('utf8');
      if (buffer.length > this.config.maxPacketBytes * 4) {
        sock.destroy();
        return;
      }
      let nl = buffer.indexOf('\n');
      while (nl !== -1) {
        const line = buffer.slice(0, nl).trim();
        buffer = buffer.slice(nl + 1);
        if (line) this._handleFrame(sock, key, established, line);
        established = this.tcpSockets.get(sock) || null;
        nl = buffer.indexOf('\n');
      }
    });

    sock.on('error', () => {});
    sock.on('close', () => {
      const session = this.tcpSockets.get(sock);
      if (session) {
        this.tcpSockets.delete(sock);
        session.close();
      } else {
        this.events.append('leave', key, 'info', 'connection dropped before session');
      }
    });
  }

  _handleFrame(sock, key, established, line) {
    const parsed = parseLine(line);
    if (!parsed.ok) {
      this.events.append('protocol', key, 'warn', parsed.error || 'bad frame');
      sock.write(encode({ type: 'error', d: { code: parsed.error || 'bad_frame' } }));
      return;
    }
    const msg = parsed.msg;

    // Optional wire authentication (GUARD_HMAC_KEY). When enabled, every
    // frame must be signed; unsigned/forged frames are dropped hard.
    if (!verifyMac(this.config.hmacKey, msg)) {
      this.events.append('protocol', key, 'warn', 'bad frame mac (SPOOF_MAC)');
      if (msg.type !== 'hello') {
        const tcp = this.tcpSockets.get(sock);
        if (tcp) this._alarm(tcp, { code: 'SPOOF_MAC', severity: 'ban', detail: 'invalid message authentication code' });
      }
      sock.write(encode({ type: 'error', d: { code: 'bad_mac' } }));
      try { if (!sock.destroyed && !sock.writableEnded) sock.end(); } catch {}
      return;
    }

    if (msg.type === 'hello') {
      if (established) {
        sock.write(encode({ type: 'error', d: { code: 'already_helloed' } }));
        return;
      }
      const helloErr = validateHello(msg.d);
      if (helloErr) {
        sock.write(encode({ type: 'error', d: { code: 'bad_hello', message: helloErr } }));
        return;
      }
      const hello = this.flood.checkHello(this.flood.newSet(key)); // hello cap per connection
      if (!hello.ok) {
        sock.write(encode({ type: 'ban', d: { reason: hello.detail } }));
        try { if (!sock.destroyed && !sock.writableEnded) sock.end(); } catch {}
        return;
      }
      const transport = {
        send: o => { try { if (!sock.destroyed && !sock.writableEnded) sock.write(encode(o)); } catch {} },
        close: () => { try { if (!sock.destroyed && !sock.writableEnded) sock.end(); } catch {} }
      };
      const res = this.establish({
        acct: msg.d.acct,
        version: msg.d.version,
        world: msg.d.world,
        key,
        transport
      });
      if (res.ok) this.tcpSockets.set(sock, res.session);
      else if (res.kind === 'banned' || res.kind === 'kicked' || res.kind === 'world') {
        try { if (!sock.destroyed && !sock.writableEnded) sock.end(); } catch {}
      }
      return;
    }

    // Everything else requires an accepted session.
    const session = this.tcpSockets.get(sock);
    if (!session || session.acct === undefined || msg.id !== session.sid) {
      sock.write(encode({ type: 'error', d: { code: 'no_session' } }));
      return;
    }
    this.handleAuthed(session, msg);
  }
}

'use strict';

const fs = require('fs');
const path = require('path');

/**
 * Event log with two sinks:
 *   1. in-memory ring buffer (polled by the admin console via GET /api/events),
 *   2. optional append-only JSONL audit file under the data dir so operators
 *      have a durable trail that survives restarts.
 */

class EventLog {
  constructor(capacity, auditFile = null) {
    this.capacity = Math.max(1, capacity | 0);
    this.items = [];
    this.nextId = 1;
    this.auditFile = auditFile || null;
    if (this.auditFile) {
      try { fs.mkdirSync(path.dirname(this.auditFile), { recursive: true }); } catch { /* best effort */ }
    }
  }

  append(kind, player, severity, detail, extra) {
    const ev = {
      id: this.nextId++,
      at: Date.now(),
      kind,
      player: player || null,
      severity: severity || 'info',
      detail,
      extra: extra || {}
    };
    this.items.push(ev);
    if (this.items.length > this.capacity) this.items.shift();

    if (this.auditFile) {
      try { fs.appendFileSync(this.auditFile, JSON.stringify(ev) + '\n', 'utf8'); } catch { /* keep serving */ }
    }
    return ev;
  }

  since(id) {
    const base = Number.isFinite(id) ? id : 0;
    return this.items.filter(ev => ev.id > base);
  }

  recent(n = 50) {
    return this.items.slice(-n);
  }
}

'use strict';

/**
 * Per-connection token-bucket flood guard.
 * - hello messages are hard-limited per connection,
 * - state / action frames are rate-limited per connection,
 * - oversized frames are rejected earlier at the protocol layer.
 */

class TokenBucket {
  constructor(burst, refillPerSec) {
    this.burst = burst;
    this.refill = refillPerSec;
    this.tokens = burst;
    this.last = Date.now();
  }

  take() {
    const now = Date.now();
    const dt = (now - this.last) / 1000;
    this.tokens = Math.min(this.burst, this.tokens + dt * this.refill);
    this.last = now;
    if (this.tokens < 1) return false;
    this.tokens -= 1;
    return true;
  }
}

class FloodGuard {
  constructor(cfg) {
    this.cfg = cfg;
  }

  newSet(connKey) {
    return {
      key: connKey,
      hellos: 0,
      states: new TokenBucket(this.cfg.stateBurst, this.cfg.stateRefillPerSec),
      actions: new TokenBucket(this.cfg.actionBurst, this.cfg.actionRefillPerSec)
    };
  }

  checkHello(bucket) {
    if (bucket.hellos >= this.cfg.maxHelloPerConn) {
      return { ok: false, violation: 'FLOOD_HELLO', detail: 'too many hello frames' };
    }
    bucket.hellos += 1;
    return { ok: true };
  }

  checkState(bucket) {
    if (!bucket.states.take()) {
      return { ok: false, violation: 'FLOOD_STATE', detail: 'state frame rate exceeded' };
    }
    return { ok: true };
  }

  checkAction(bucket) {
    if (!bucket.actions.take()) {
      return { ok: false, violation: 'FLOOD_ACTION', detail: 'action frame rate exceeded' };
    }
    return { ok: true };
  }
}

module.exports = { FloodGuard, TokenBucket };

'use strict';

/**
 * Game-hook layer: the SERVER-SIDE gameplay integrity checks for exploits the
 * physics layer can't see:
 *   - money givers (item/economy inflation)
 *   - quest-farmer bots (identical quest churn)
 *   - macro input (impossibly fast, regular actions)
 *
 * Your game calls these from gameplay code, or sends `action` frames over the
 * wire (the SDKs do). Everything funnels into the same verdict pipeline, so
 * abuse escalates warn -> strike -> ban exactly like fly-hacking does.
 */

const VERDICT_DEFAULT = {
  giveActive: true,
  questActive: true,
  macroActive: true
};

class HookGuard {
  constructor(cfg, banHammer, events) {
    this.cfg = cfg.hooks;
    this.ban = banHammer;
    this.events = events;
    this.giveLog = new Map(); // acct -> [{at, item, amount}]
    this.questLog = new Map(); // acct -> {lastClaim:{questId, at}, perMin:[times]}
    this.actionLog = new Map(); // acct -> [times]
  }

  _verdict(acct, code, severity, detail) {
    return this.ban.report(acct, { code, severity, detail });
  }

  /**
   * Economy integrity: onGive(acct, item, amount).
   * Catches money-giver bots pumping currency/items at machine speed.
   */
  onGive(acct, item, amount) {
    if (!VERDICT_DEFAULT.giveActive) return { action: 'none' };
    const now = Date.now();
    const h = this.cfg;
    if (typeof amount !== 'number' || !Number.isFinite(amount) || amount <= 0) {
      return this._verdict(acct, 'GIVE_BAD_AMOUNT', 'warn', `illegal give amount ${amount}`);
    }
    if (amount > h.giveMaxItemAmount) {
      return { action: 'none', note: `amount ${amount} clamped by policy` };
    }
    let log = this.giveLog.get(acct) || [];
    log = log.filter(e => now - e.at < h.giveWindowMs);
    log.push({ at: now, item, amount });
    this.giveLog.set(acct, log);

    if (log.length > h.giveMaxPerSec * (h.giveWindowMs / 1000) + 8) {
      return this._verdict(acct, 'GIVE_FLOOD', 'warn',
        `${log.length} give events in ${(h.giveWindowMs / 1000)}s window (money-giver pattern)`);
    }
    return { action: 'none' };
  }

  /**
   * Quest-integrity: onQuestClaim(acct, questId, reward).
   * Catches farmers instantly re-completing the same quest / churning at bot pace.
   */
  onQuestClaim(acct, questId, reward) {
    if (!VERDICT_DEFAULT.questActive) return { action: 'none' };
    const now = Date.now();
    const h = this.cfg;
    let rec = this.questLog.get(acct) || { lastClaim: null, perMin: [] };
    rec.perMin = rec.perMin.filter(t => now - t < 60000);
    rec.perMin.push(now);

    if (rec.perMin.length > h.questMaxPerMin) {
      return this._verdict(acct, 'QUEST_FARM', 'warn',
        `${rec.perMin.length} quest claims in a minute (quest-farmer bot)`);
    }
    if (rec.lastClaim && rec.lastClaim.questId === questId && now - rec.lastClaim.at < h.questMinReclaimMs) {
      return this._verdict(acct, 'QUEST_FARM', 'warn',
        `re-claimed quest ${questId} within ${h.questMinReclaimMs}ms`);
    }
    rec.lastClaim = { questId, at: now };
    this.questLog.set(acct, rec);
    return { action: 'none' };
  }

  /**
   * Input-rate integrity: onAction(acct, actionName).
   * Catches keyboard macros (e.g. autoclickers) before they matter.
   */
  onAction(acct, actionName) {
    if (!VERDICT_DEFAULT.macroActive) return { action: 'none' };
    const now = Date.now();
    const h = this.cfg;
    let log = this.actionLog.get(acct) || [];
    log = log.filter(t => now - t < 1000);
    log.push(now);
    this.actionLog.set(acct, log);
    if (log.length > h.actionMaxPerSec) {
      return this._verdict(acct, 'MACRO', 'warn',
        `${log.length} actions/s (macro signature)`);
    }
    return { action: 'none' };
  }
}

module.exports = { HookGuard };

'use strict';

/**
 * Flat helpers for the validation math. Everything operates on plain numbers
 * and refuses to echo NaN/Infinity into the world.
 */

function isFin(x) {
  return typeof x === 'number' && Number.isFinite(x);
}

function dist3(a, b) {
  if (!isFin(a.x) || !isFin(a.y) || !isFin(a.z) || !isFin(b.x) || !isFin(b.y) || !isFin(b.z)) {
    return NaN;
  }
  const dx = a.x - b.x;
  const dy = a.y - b.y;
  const dz = a.z - b.z;
  return Math.sqrt(dx * dx + dy * dy + dz * dz);
}

function distH(a, b) {
  if (!isFin(a.x) || !isFin(a.x) || !isFin(b.x) || !isFin(b.z)) return NaN;
  const dx = a.x - b.x;
  const dz = a.z - b.z;
  return Math.sqrt(dx * dx + dz * dz);
}

// v0 needed to reach apexHeight against gravity g.
function jumpVelocity(gravity, height) {
  if (gravity <= 0) return 0;
  return Math.sqrt(2 * gravity * Math.max(0, height));
}

// Time from launch to apex for a jump of apex height (no drag).
function jumpTimeToApex(gravity, height) {
  if (gravity <= 0) return 0;
  return Math.sqrt((2 * Math.max(0, height)) / gravity);
}

// Total hang time for a pure vertical jump of `height` (up and down, no build
// height gain). Used only for sanity references.
function jumpHangTime(gravity, height) {
  if (gravity <= 0) return 0;
  return 2 * Math.sqrt((2 * Math.max(0, height)) / gravity);
}

function clamp(n, lo, hi) {
  return Math.min(hi, Math.max(lo, n));
}

module.exports = { isFin, dist3, distH, jumpVelocity, jumpTimeToApex, jumpHangTime, clamp };

'use strict';

/**
 * Wire protocol for Guard-Game.
 *
 * Every frame is a single line of JSON, newline terminated:
 *   {"v":1,"id":"<sessionId|null>","type":"<msgType>","seq":<int>,"t":<clientMs>,"d":{...}}
 *
 * Client -> Server
 *   hello            d: {acct, version, world}
 *   state            d: {p:{x,y,z}, g:bool, v?:{x,y,z}}   (position, grounded, client-velocity)
 *   action           d: {k:'give'|'quest_claim'|'macro'|..., args:{...}}
 *
 * Server -> Client
 *   welcome          d: {sid, profile, policy:{...}}
 *   ack              d: {at:seq}
 *   violation        d: {code, detail, severity}
 *   warn             d: {code, detail}
 *   ban              d: {reason}
 *   kick             d: {reason}
 *   error            d: {code, message}
 */

const MAX_BYTES = 4096;

const CLIENT_TYPES = new Set(['hello', 'state', 'action']);

function parseLine(line) {
  if (line.length > MAX_BYTES) {
    return { ok: false, error: 'packet_too_large', violation: 'FLOOD' };
  }
  let msg;
  try {
    msg = JSON.parse(line);
  } catch {
    return { ok: false, error: 'bad_json' };
  }
  if (!msg || typeof msg !== 'object' || msg.v !== 1) {
    return { ok: false, error: 'bad_version' };
  }
  if (!CLIENT_TYPES.has(msg.type)) {
    return { ok: false, error: 'unknown_type' };
  }
  if (!Number.isInteger(msg.seq) || msg.seq < 0) {
    return { ok: false, error: 'bad_seq' };
  }
  if (msg.t !== undefined && (typeof msg.t !== 'number' || !Number.isFinite(msg.t))) {
    return { ok: false, error: 'bad_timestamp' };
  }
  return { ok: true, msg };
}

function validateHello(d) {
  if (!d || typeof d.acct !== 'string' || d.acct.length === 0 || d.acct.length > 64) {
    return 'missing acct';
  }
  if (typeof d.version !== 'string' || d.version.length > 64) return 'missing version';
  if (d.world !== undefined && (typeof d.world !== 'string' || d.world.length > 64)) return 'bad world';
  return null;
}

function isNum(v) {
  return typeof v === 'number' && Number.isFinite(v);
}

function validateStatePos(p) {
  if (!p || !isNum(p.x) || !isNum(p.y) || !isNum(p.z)) return 'bad position';
  return null;
}

function validateState(d) {
  if (!d || typeof d !== 'object') return 'missing payload';
  const posErr = validateStatePos(d.p);
  if (posErr) return posErr;
  if (d.g !== undefined && typeof d.g !== 'boolean') return 'bad ground flag';
  if (d.v !== undefined) {
    if (!isNum(d.v.x) || !isNum(d.v.y) || !isNum(d.v.z)) return 'bad velocity';
  }
  return null;
}

function encode(msg) {
  return JSON.stringify(msg) + '\n';
}

module.exports = { parseLine, validateHello, validateState, encode, CLIENT_TYPES, MAX_BYTES };

'use strict';

const { dist3, distH, isFin } = require('./physics');

/**
 * Verdict engine. Consumes per-state samples for one player and produces
 * violations. Stateless-by-design with respect to timing: everything is driven
 * by the SERVER clock (receive time), never the client clock.
 *
 * Violation codes:
 *   BAD_POS        position was non-finite (NaN/Infinity)        -> warn
 *   OUT_OF_BOUNDS  player reported beyond world bounds            -> warn
 *   SPAM_STATE     state packets arriving faster than policy      -> warn
 *   SPEED          horizontal speed exceeds world cap             -> warn
 *   TELEPORT       per-sample displacement exceeds world cap      -> warn
 *   HEIGHT_TOO_HIGH jump apex above physically possible apex      -> warn
 *   RISE_VEL       upward velocity above physically possible rise -> escalate
 *   CLIMB_ESCAPE   net climb above hard world cap in one stretch  -> ban
 *   HOVER          airborne while (nearly) stationary too long    -> ban
 *   AIRTIME        airborne & still gaining height too long       -> ban
 *   STALE          no samples for too long (client pausing to fake) -> warn
 */

const WARN = 'warn';
const BAN = 'ban';

class VerdictEngine {
  /**
   * @param {object} world   resolved world profile
   * @param {number} now     server ms (first sample time)
   */
  constructor(world, now) {
    this.w = world;
    this.first = true;
    this.prev = null; // { t, pos, ground }
    this.air = null; // { launchY, peakY, t0, lastPos }
    this.lastViolation = {}; // code -> last emit time
    this.warnCooldownMs = 1000;
    this.lastGroundTime = null;
  }

  _emit(violations, code, severity, detail) {
    const now = Date.now();
    if (this.lastViolation[code] && now - this.lastViolation[code] < this.warnCooldownMs) {
      return;
    }
    this.lastViolation[code] = now;
    violations.push({ code, severity, detail });
  }

  /**
   * Process one sample. Mutates internal state. Returns array of violations.
   */
  sample(pos, ground, now) {
    const w = this.w;
    const out = [];

    if (!isFin(pos.x) || !isFin(pos.y) || !isFin(pos.z)) {
      this._emit(out, 'BAD_POS', WARN, 'position must be finite numbers');
      return out;
    }

    // World bounds (e.g. above the ceiling => flying).
    const [x0, x1] = w.bounds.x;
    const [y0, y1] = w.bounds.y;
    const [z0, z1] = w.bounds.z;
    if (pos.x < x0 || pos.x > x1 || pos.y < y0 || pos.y > y1 || pos.z < z0 || pos.z > z1) {
      this._emit(out, 'OUT_OF_BOUNDS', WARN,
        `position ${fmt(pos)} outside world ${JSON.stringify(w.bounds)}`);
      return out;
    }

    if (this.first) {
      this.first = false;
      this.prev = { t: now, pos, ground: !!ground };
      this.lastGroundTime = ground ? now : null;
      if (!ground) {
        // Player joins already airborne: open a jump record so hover and
        // airtime checks apply from the very first sample.
        this.air = { launchY: pos.y, peakY: pos.y, t0: now, launchPos: { x: pos.x, y: pos.y, z: pos.z } };
      }
      return out;
    }

    const prev = this.prev;
    const dtMs = Math.max(0, now - prev.t);
    const dt = dtMs / 1000;

    if (dt > 0 && dtMs < w.minStateIntervalMs) {
      this._emit(out, 'SPAM_STATE', WARN,
        `state cadence ${dtMs.toFixed(0)}ms < min ${w.minStateIntervalMs}ms`);
    }

    if (dt > 0) {
      // Horizontal speed (run / fly-speed check).
      const speedH = distH(pos, prev.pos) / dt;
      if (speedH > w.maxGroundSpeed) {
        this._emit(out, 'SPEED', WARN,
          `horizontal speed ${speedH.toFixed(2)}u/s > cap ${w.maxGroundSpeed}u/s`);
      }

      // Per-sample displacement (teleport check).
      const moved = dist3(pos, prev.pos);
      if (moved > w.maxTeleportDist) {
        this._emit(out, 'TELEPORT', WARN,
          `teleported ${moved.toFixed(2)}u in one sample (>${w.maxTeleportDist}u)`);
      }
    }

    // -- Jump / air mechanics ---------------------------------------------
    const wasAirborne = !prev.ground;
    const isAirborne = !ground;

    if (isAirborne && !wasAirborne) {
      // Just launched.
      this.air = { launchY: prev.pos.y, peakY: prev.pos.y, t0: now, launchPos: { x: pos.x, y: pos.y, z: pos.z } };
    }

    if (isAirborne && this.air) {
      const air = this.air;
      air.peakY = Math.max(air.peakY, pos.y);
      const airMs = now - air.t0;
      const netClimb = pos.y - air.launchY;

      // Rising too fast to be a jump, beyond wobble tolerance.
      const dy = dt > 0 ? (pos.y - prev.pos.y) / dt : 0;
      if (dy > w.maxRiseSpeed && netClimb > w.maxJumpHeight * 0.5) {
        this._emit(out, 'RISE_VEL', BAN,
          `rise velocity ${dy.toFixed(2)}u/s > max ${w.maxRiseSpeed}u/s`);
      }

      // Hard climb cap for a single airborne stretch (a jump can never gain
      // this much on the ground world).
      if (w.maxClimbPerAirborne < 1e9 && netClimb > w.maxClimbPerAirborne) {
        this._emit(out, 'CLIMB_ESCAPE', BAN,
          `net climb ${netClimb.toFixed(2)}u > world cap ${w.maxClimbPerAirborne}u`);
      }

      // Hovering: airborne, long, and nearly where they launched.
      if (airMs > w.maxHoverTimeMs) {
        const drift = distH(pos, air.launchPos);
        if (drift < 0.1) {
          this._emit(out, 'HOVER', BAN,
            `hovering ${(airMs / 1000).toFixed(1)}s with no movement`);
        }
      }

      // Impossible airtime while still gaining height.
      if (netClimb > w.maxJumpHeight && airMs > w.maxFlagAirtimeMs) {
        this._emit(out, 'AIRTIME', BAN,
          `airborne ${(airMs / 1000).toFixed(1)}s while still climbing`);
      }
    }

    if (!isAirborne && wasAirborne) {
      // Landed: evaluate the completed jump's apex.
      const air = this.air;
      if (air) {
        const apex = air.peakY - air.launchY;
        const maxApex = w.maxJumpHeight * w.maxJumpApexTolerance;
        if (apex > maxApex) {
          this._emit(out, 'HEIGHT_TOO_HIGH', WARN,
            `jump apex ${apex.toFixed(2)}u > possible ${w.maxJumpHeight}u (x${w.maxJumpApexTolerance})`);
        }
        this.air = null;
      }
      this.lastGroundTime = now;
    }

    // Stale / anti-pause: a client that freezes samples then teleports later
    // is handled by TELEPORT above; a long silence alone is not a violation
    // (some engines only flush on tick) but is surfaced if configured.
    if (dtMs > w.maxStateIntervalMs * 2) {
      this._emit(out, 'STALE', WARN, `no samples for ${(dtMs / 1000).toFixed(1)}s`);
    }

    this.prev = { t: now, pos, ground: isAirborne ? false : !!ground };
    return out;
  }
}

function fmt(p) {
  return `(${p.x.toFixed(1)},${p.y.toFixed(1)},${p.z.toFixed(1)})`;
}

VerdictEngine.SEVERITY = { WARN, BAN };

module.exports = { VerdictEngine };

const { config, BASE_WORLD_PROFILES } = require('./config');

/** Resolve a world profile by name against a given (or default) config. */
function resolveWorld(name, coreConfig = config) {
  const profiles = (coreConfig.supply && coreConfig.supply.WORLD_PROFILES) || BASE_WORLD_PROFILES;
  let world = null;
  if (name && Object.prototype.hasOwnProperty.call(profiles, name)) {
    world = profiles[name];
  } else if (coreConfig.allowUnknownWorlds && name && typeof name === 'string') {
    // Unknown worlds get a sandboxed conservative default so the feature can be
    // shipped on worlds you haven't profiled yet.
    world = {
      label: `Custom world (${name}) - conservative defaults`,
      gravity: 9.81,
      maxJumpHeight: 2.0,
      maxJumpApexTolerance: 2.0,
      maxClimbPerAirborne: 10,
      maxRiseSpeed: 12,
      maxGroundSpeed: 20,
      maxHoverTimeMs: 3000,
      maxFlagAirtimeMs: 5000,
      maxTeleportDist: 10,
      minStateIntervalMs: coreConfig.stateRefillPerSec > 0 ? 1000 / coreConfig.stateRefillPerSec : 40,
      maxStateIntervalMs: 500,
      bounds: { x: [-10000, 10000], y: [-1000, 10000], z: [-10000, 10000] }
    };
  }
  return world;
}

  <h2>server/protocol.js — the integration spec</h2>
  <p>The one file a new engine needs to implement. <a href="https://github.com/Parko-Developer/guard-game/blob/main/server/protocol.js" target="_blank" rel="noopener">View on GitHub ↗</a></p>
  <pre class="codeblock line-numbers"><code><span class="ln">'use strict';</span>
<span class="ln"></span>
<span class="ln">/**</span>
<span class="ln"> * Wire protocol for Guard-Game.</span>
<span class="ln"> *</span>
<span class="ln"> * Every frame is a single line of JSON, newline terminated:</span>
<span class="ln"> *   {"v":1,"id":"&lt;sessionId|null&gt;","type":"&lt;msgType&gt;","seq":&lt;int&gt;,"t":&lt;clientMs&gt;,"d":{...}}</span>
<span class="ln"> *</span>
<span class="ln"> * Client -&gt; Server</span>
<span class="ln"> *   hello            d: {acct, version, world}</span>
<span class="ln"> *   state            d: {p:{x,y,z}, g:bool, v?:{x,y,z}}   (position, grounded, client-velocity)</span>
<span class="ln"> *   action           d: {k:'give'|'quest_claim'|'macro'|..., args:{...}}</span>
<span class="ln"> *</span>
<span class="ln"> * Server -&gt; Client</span>
<span class="ln"> *   welcome          d: {sid, profile, policy:{...}}</span>
<span class="ln"> *   ack              d: {at:seq}</span>
<span class="ln"> *   violation        d: {code, detail, severity}</span>
<span class="ln"> *   warn             d: {code, detail}</span>
<span class="ln"> *   ban              d: {reason}</span>
<span class="ln"> *   kick             d: {reason}</span>
<span class="ln"> *   error            d: {code, message}</span>
<span class="ln"> */</span>
<span class="ln"></span>
<span class="ln">const MAX_BYTES = 4096;</span>
<span class="ln"></span>
<span class="ln">const CLIENT_TYPES = new Set(['hello', 'state', 'action']);</span>
<span class="ln"></span>
<span class="ln">function parseLine(line) {</span>
<span class="ln">  if (line.length &gt; MAX_BYTES) {</span>
<span class="ln">    return { ok: false, error: 'packet_too_large', violation: 'FLOOD' };</span>
<span class="ln">  }</span>
<span class="ln">  let msg;</span>
<span class="ln">  try {</span>
<span class="ln">    msg = JSON.parse(line);</span>
<span class="ln">  } catch {</span>
<span class="ln">    return { ok: false, error: 'bad_json' };</span>
<span class="ln">  }</span>
<span class="ln">  if (!msg || typeof msg !== 'object' || msg.v !== 1) {</span>
<span class="ln">    return { ok: false, error: 'bad_version' };</span>
<span class="ln">  }</span>
<span class="ln">  if (!CLIENT_TYPES.has(msg.type)) {</span>
<span class="ln">    return { ok: false, error: 'unknown_type' };</span>
<span class="ln">  }</span>
<span class="ln">  if (!Number.isInteger(msg.seq) || msg.seq &lt; 0) {</span>
<span class="ln">    return { ok: false, error: 'bad_seq' };</span>
<span class="ln">  }</span>
<span class="ln">  if (msg.t !== undefined &amp;&amp; (typeof msg.t !== 'number' || !Number.isFinite(msg.t))) {</span>
<span class="ln">    return { ok: false, error: 'bad_timestamp' };</span>
<span class="ln">  }</span>
<span class="ln">  return { ok: true, msg };</span>
<span class="ln">}</span>
<span class="ln"></span>
<span class="ln">function validateHello(d) {</span>
<span class="ln">  if (!d || typeof d.acct !== 'string' || d.acct.length === 0 || d.acct.length &gt; 64) {</span>
<span class="ln">    return 'missing acct';</span>
<span class="ln">  }</span>
<span class="ln">  if (typeof d.version !== 'string' || d.version.length &gt; 64) return 'missing version';</span>
<span class="ln">  if (d.world !== undefined &amp;&amp; (typeof d.world !== 'string' || d.world.length &gt; 64)) return 'bad world';</span>
<span class="ln">  return null;</span>
<span class="ln">}</span>
<span class="ln"></span>
<span class="ln">function isNum(v) {</span>
<span class="ln">  return typeof v === 'number' &amp;&amp; Number.isFinite(v);</span>
<span class="ln">}</span>
<span class="ln"></span>
<span class="ln">function validateStatePos(p) {</span>
<span class="ln">  if (!p || !isNum(p.x) || !isNum(p.y) || !isNum(p.z)) return 'bad position';</span>
<span class="ln">  return null;</span>
<span class="ln">}</span>
<span class="ln"></span>
<span class="ln">function validateState(d) {</span>
<span class="ln">  if (!d || typeof d !== 'object') return 'missing payload';</span>
<span class="ln">  const posErr = validateStatePos(d.p);</span>
<span class="ln">  if (posErr) return posErr;</span>
<span class="ln">  if (d.g !== undefined &amp;&amp; typeof d.g !== 'boolean') return 'bad ground flag';</span>
<span class="ln">  if (d.v !== undefined) {</span>
<span class="ln">    if (!isNum(d.v.x) || !isNum(d.v.y) || !isNum(d.v.z)) return 'bad velocity';</span>
<span class="ln">  }</span>
<span class="ln">  return null;</span>
<span class="ln">}</span>
<span class="ln"></span>
<span class="ln">function encode(msg) {</span>
<span class="ln">  return JSON.stringify(msg) + '\n';</span>

  <h2>server/validator.js — the verdict engine</h2>
  <p>Every movement claim comes through here. <a href="https://github.com/Parko-Developer/guard-game/blob/main/server/validator.js" target="_blank" rel="noopener">View on GitHub ↗</a></p>
  <pre class="codeblock line-numbers"><code><span class="ln">'use strict';</span>
<span class="ln"></span>
<span class="ln">const { dist3, distH, isFin } = require('./physics');</span>
<span class="ln"></span>
<span class="ln">/**</span>
<span class="ln"> * Verdict engine. Consumes per-state samples for one player and produces</span>
<span class="ln"> * violations. Stateless-by-design with respect to timing: everything is driven</span>
<span class="ln"> * by the SERVER clock (receive time), never the client clock.</span>
<span class="ln"> *</span>
<span class="ln"> * Violation codes:</span>
<span class="ln"> *   BAD_POS        position was non-finite (NaN/Infinity)        -&gt; warn</span>
<span class="ln"> *   OUT_OF_BOUNDS  player reported beyond world bounds            -&gt; warn</span>
<span class="ln"> *   SPAM_STATE     state packets arriving faster than policy      -&gt; warn</span>
<span class="ln"> *   SPEED          horizontal speed exceeds world cap             -&gt; warn</span>
<span class="ln"> *   TELEPORT       per-sample displacement exceeds world cap      -&gt; warn</span>
<span class="ln"> *   HEIGHT_TOO_HIGH jump apex above physically possible apex      -&gt; warn</span>
<span class="ln"> *   RISE_VEL       upward velocity above physically possible rise -&gt; escalate</span>
<span class="ln"> *   CLIMB_ESCAPE   net climb above hard world cap in one stretch  -&gt; ban</span>
<span class="ln"> *   HOVER          airborne while (nearly) stationary too long    -&gt; ban</span>
<span class="ln"> *   AIRTIME        airborne &amp; still gaining height too long       -&gt; ban</span>
<span class="ln"> *   STALE          no samples for too long (client pausing to fake) -&gt; warn</span>
<span class="ln"> */</span>
<span class="ln"></span>
<span class="ln">const WARN = 'warn';</span>
<span class="ln">const BAN = 'ban';</span>
<span class="ln"></span>
<span class="ln">class VerdictEngine {</span>
<span class="ln">  /**</span>
<span class="ln">   * @param {object} world   resolved world profile</span>
<span class="ln">   * @param {number} now     server ms (first sample time)</span>
<span class="ln">   */</span>
<span class="ln">  constructor(world, now) {</span>
<span class="ln">    this.w = world;</span>
<span class="ln">    this.first = true;</span>
<span class="ln">    this.prev = null; // { t, pos, ground }</span>
<span class="ln">    this.air = null; // { launchY, peakY, t0, lastPos }</span>
<span class="ln">    this.lastViolation = {}; // code -&gt; last emit time</span>
<span class="ln">    this.warnCooldownMs = 1000;</span>
<span class="ln">    this.lastGroundTime = null;</span>
<span class="ln">  }</span>
<span class="ln"></span>
<span class="ln">  _emit(violations, code, severity, detail) {</span>
<span class="ln">    const now = Date.now();</span>
<span class="ln">    if (this.lastViolation[code] &amp;&amp; now - this.lastViolation[code] &lt; this.warnCooldownMs) {</span>
<span class="ln">      return;</span>
<span class="ln">    }</span>
<span class="ln">    this.lastViolation[code] = now;</span>
<span class="ln">    violations.push({ code, severity, detail });</span>
<span class="ln">  }</span>
<span class="ln"></span>
<span class="ln">  /**</span>
<span class="ln">   * Process one sample. Mutates internal state. Returns array of violations.</span>
<span class="ln">   */</span>
<span class="ln">  sample(pos, ground, now) {</span>
<span class="ln">    const w = this.w;</span>
<span class="ln">    const out = [];</span>
<span class="ln"></span>
<span class="ln">    if (!isFin(pos.x) || !isFin(pos.y) || !isFin(pos.z)) {</span>
<span class="ln">      this._emit(out, 'BAD_POS', WARN, 'position must be finite numbers');</span>
<span class="ln">      return out;</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    // World bounds (e.g. above the ceiling =&gt; flying).</span>
<span class="ln">    const [x0, x1] = w.bounds.x;</span>
<span class="ln">    const [y0, y1] = w.bounds.y;</span>
<span class="ln">    const [z0, z1] = w.bounds.z;</span>
<span class="ln">    if (pos.x &lt; x0 || pos.x &gt; x1 || pos.y &lt; y0 || pos.y &gt; y1 || pos.z &lt; z0 || pos.z &gt; z1) {</span>
<span class="ln">      this._emit(out, 'OUT_OF_BOUNDS', WARN,</span>
<span class="ln">        `position ${fmt(pos)} outside world ${JSON.stringify(w.bounds)}`);</span>
<span class="ln">      return out;</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    if (this.first) {</span>
<span class="ln">      this.first = false;</span>
<span class="ln">      this.prev = { t: now, pos, ground: !!ground };</span>
<span class="ln">      this.lastGroundTime = ground ? now : null;</span>
<span class="ln">      if (!ground) {</span>
<span class="ln">        // Player joins already airborne: open a jump record so hover and</span>
<span class="ln">        // airtime checks apply from the very first sample.</span>
<span class="ln">        this.air = { launchY: pos.y, peakY: pos.y, t0: now, launchPos: { x: pos.x, y: pos.y, z: pos.z } };</span>
<span class="ln">      }</span>
<span class="ln">      return out;</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    const prev = this.prev;</span>
<span class="ln">    const dtMs = Math.max(0, now - prev.t);</span>
<span class="ln">    const dt = dtMs / 1000;</span>
<span class="ln"></span>
<span class="ln">    if (dt &gt; 0 &amp;&amp; dtMs &lt; w.minStateIntervalMs) {</span>
<span class="ln">      this._emit(out, 'SPAM_STATE', WARN,</span>
<span class="ln">        `state cadence ${dtMs.toFixed(0)}ms &lt; min ${w.minStateIntervalMs}ms`);</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    if (dt &gt; 0) {</span>
<span class="ln">      // Horizontal speed (run / fly-speed check).</span>
<span class="ln">      const speedH = distH(pos, prev.pos) / dt;</span>
<span class="ln">      if (speedH &gt; w.maxGroundSpeed) {</span>
<span class="ln">        this._emit(out, 'SPEED', WARN,</span>
<span class="ln">          `horizontal speed ${speedH.toFixed(2)}u/s &gt; cap ${w.maxGroundSpeed}u/s`);</span>
<span class="ln">      }</span>
<span class="ln"></span>
<span class="ln">      // Per-sample displacement (teleport check).</span>
<span class="ln">      const moved = dist3(pos, prev.pos);</span>
<span class="ln">      if (moved &gt; w.maxTeleportDist) {</span>
<span class="ln">        this._emit(out, 'TELEPORT', WARN,</span>
<span class="ln">          `teleported ${moved.toFixed(2)}u in one sample (&gt;${w.maxTeleportDist}u)`);</span>
<span class="ln">      }</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    // -- Jump / air mechanics ---------------------------------------------</span>
<span class="ln">    const wasAirborne = !prev.ground;</span>
<span class="ln">    const isAirborne = !ground;</span>
<span class="ln"></span>
<span class="ln">    if (isAirborne &amp;&amp; !wasAirborne) {</span>
<span class="ln">      // Just launched.</span>
<span class="ln">      this.air = { launchY: prev.pos.y, peakY: prev.pos.y, t0: now, launchPos: { x: pos.x, y: pos.y, z: pos.z } };</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    if (isAirborne &amp;&amp; this.air) {</span>
<span class="ln">      const air = this.air;</span>
<span class="ln">      air.peakY = Math.max(air.peakY, pos.y);</span>
<span class="ln">      const airMs = now - air.t0;</span>
<span class="ln">      const netClimb = pos.y - air.launchY;</span>
<span class="ln"></span>
<span class="ln">      // Rising too fast to be a jump, beyond wobble tolerance.</span>
<span class="ln">      const dy = dt &gt; 0 ? (pos.y - prev.pos.y) / dt : 0;</span>
<span class="ln">      if (dy &gt; w.maxRiseSpeed &amp;&amp; netClimb &gt; w.maxJumpHeight * 0.5) {</span>
<span class="ln">        this._emit(out, 'RISE_VEL', BAN,</span>
<span class="ln">          `rise velocity ${dy.toFixed(2)}u/s &gt; max ${w.maxRiseSpeed}u/s`);</span>
<span class="ln">      }</span>
<span class="ln"></span>
<span class="ln">      // Hard climb cap for a single airborne stretch (a jump can never gain</span>
<span class="ln">      // this much on the ground world).</span>
<span class="ln">      if (w.maxClimbPerAirborne &lt; 1e9 &amp;&amp; netClimb &gt; w.maxClimbPerAirborne) {</span>
<span class="ln">        this._emit(out, 'CLIMB_ESCAPE', BAN,</span>
<span class="ln">          `net climb ${netClimb.toFixed(2)}u &gt; world cap ${w.maxClimbPerAirborne}u`);</span>
<span class="ln">      }</span>
<span class="ln"></span>
<span class="ln">      // Hovering: airborne, long, and nearly where they launched.</span>
<span class="ln">      if (airMs &gt; w.maxHoverTimeMs) {</span>
<span class="ln">        const drift = distH(pos, air.launchPos);</span>
<span class="ln">        if (drift &lt; 0.1) {</span>
<span class="ln">          this._emit(out, 'HOVER', BAN,</span>
<span class="ln">            `hovering ${(airMs / 1000).toFixed(1)}s with no movement`);</span>
<span class="ln">        }</span>
<span class="ln">      }</span>
<span class="ln"></span>
<span class="ln">      // Impossible airtime while still gaining height.</span>
<span class="ln">      if (netClimb &gt; w.maxJumpHeight &amp;&amp; airMs &gt; w.maxFlagAirtimeMs) {</span>
<span class="ln">        this._emit(out, 'AIRTIME', BAN,</span>
<span class="ln">          `airborne ${(airMs / 1000).toFixed(1)}s while still climbing`);</span>
<span class="ln">      }</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    if (!isAirborne &amp;&amp; wasAirborne) {</span>
<span class="ln">      // Landed: evaluate the completed jump's apex.</span>
<span class="ln">      const air = this.air;</span>
<span class="ln">      if (air) {</span>
<span class="ln">        const apex = air.peakY - air.launchY;</span>
<span class="ln">        const maxApex = w.maxJumpHeight * w.maxJumpApexTolerance;</span>
<span class="ln">        if (apex &gt; maxApex) {</span>
<span class="ln">          this._emit(out, 'HEIGHT_TOO_HIGH', WARN,</span>
<span class="ln">            `jump apex ${apex.toFixed(2)}u &gt; possible ${w.maxJumpHeight}u (x${w.maxJumpApexTolerance})`);</span>
<span class="ln">        }</span>
<span class="ln">        this.air = null;</span>
<span class="ln">      }</span>
<span class="ln">      this.lastGroundTime = now;</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    // Stale / anti-pause: a client that freezes samples then teleports later</span>
<span class="ln">    // is handled by TELEPORT above; a long silence alone is not a violation</span>
<span class="ln">    // (some engines only flush on tick) but is surfaced if configured.</span>
<span class="ln">    if (dtMs &gt; w.maxStateIntervalMs * 2) {</span>
<span class="ln">      this._emit(out, 'STALE', WARN, `no samples for ${(dtMs / 1000).toFixed(1)}s`);</span>
<span class="ln">    }</span>
<span class="ln"></span>
<span class="ln">    this.prev = { t: now, pos, ground: isAirborne ? false : !!ground };</span>
<span class="ln">    return out;</span>
<span class="ln">  }</span>
<span class="ln">}</span>
<span class="ln"></span>
<span class="ln">function fmt(p) {</span>
<span class="ln">  return `(${p.x.toFixed(1)},${p.y.toFixed(1)},${p.z.toFixed(1)})`;</span>
<span class="ln">}</span>

# Make Anti-Cheat Template — Guard-Game
#
# Packages the whole anti-cheat plus your engine's SDK into a folder you can
# drop into your game project. "The game engine recognizes it and activates
# the plugin" = the generated sdk/ file + INTEGRATION.md wiring point to the
# running server; Guard-Game does the rest.
#
#   .\templates\make.ps1 -Target ..\MyGame\GuardPlugins -GameName MyGame -Engine godot
#
# Params:
#   -Target    output folder            (default: .\Guard-Game-Template)
#   -GameName  your game's name         (default: MyGame)
#   -Engine    godot|unity|unreal|roblox|web|generic   (default: generic)
#   -World     ground|hovercraft        (default: ground)

param(
  [string]$Target = ".\Guard-Game-Template",
  [string]$GameName = "MyGame",
  [ValidateSet("godot","unity","unreal","roblox","web","generic")]
  [string]$Engine = "generic",
  [ValidateSet("ground","hovercraft")]
  [string]$World = "ground"
)

$ErrorActionPreference = "Stop"

# Guard-Game repo root = parent of the templates/ folder this script lives in.
$ScriptDir = Split-Path -Parent $MyInvocation.MyCommand.Path
$Repo = Split-Path -Parent $ScriptDir

function Copy-Path([string]$From, [string]$To) {
  if (-not (Test-Path -LiteralPath $From)) { throw "Missing source: $From" }
  New-Item -ItemType Directory -Path $To -Force -ErrorAction SilentlyContinue | Out-Null
  Copy-Item -Path (Join-Path $From '*') -Destination $To -Recurse -Force
}

Write-Host ""
Write-Host "[Guard-Game] Make Anti-Cheat Template" -ForegroundColor Cyan
Write-Host "  game    : $GameName"
Write-Host "  engine  : $Engine"
Write-Host "  world   : $World"
Write-Host "  target  : $Target"
Write-Host ""

$TargetPath = if ([System.IO.Path]::IsPathRooted($Target)) { $Target } else { Join-Path $PWD $Target }
New-Item -ItemType Directory -Path $TargetPath -Force | Out-Null

# 1. Core server + tooling
Copy-Path (Join-Path $Repo 'server')      (Join-Path $TargetPath 'server')
Copy-Path (Join-Path $Repo 'admin')       (Join-Path $TargetPath 'admin')
Copy-Path (Join-Path $Repo 'client-sdks') (Join-Path $TargetPath 'client-sdks')
Copy-Path (Join-Path $Repo 'tests')       (Join-Path $TargetPath 'tests')
Copy-Item -LiteralPath (Join-Path $Repo 'package.json') -Destination $TargetPath -Force

# 2. Engine SDK -> top-level sdk/ ("the engine recognizes it and activates")
$sdkMap = @{
  godot   = 'client-sdks/gdscript/guard_client.gd'
  unity   = 'client-sdks/csharp/GuardClient.cs'
  unreal  = 'client-sdks/csharp/GuardClient.cs'
  roblox  = 'client-sdks/luau/guardClient.lua'
  web     = 'client-sdks/js/guardBridgeClient.js'
  generic = 'client-sdks/js/guardBridgeClient.js'
}
$sdkRel = $sdkMap[$Engine]
$sdkDest = Join-Path $TargetPath 'sdk'
New-Item -ItemType Directory -Path $sdkDest -Force | Out-Null
Copy-Item -LiteralPath (Join-Path $Repo $sdkRel) -Destination $sdkDest -Force
# also ship the JS SDKs so a Node game server can use the TCP path
Copy-Item -LiteralPath (Join-Path $Repo 'client-sdks/js/guardClient.js') -Destination $sdkDest -Force

# 3. Generated config + glue
$gen = Join-Path $TargetPath 'generated'
New-Item -ItemType Directory -Path $gen -Force | Out-Null
$cfg = @{ game = $GameName; engine = $Engine; world = $World; sdk = (Split-Path $sdkRel -Leaf) }
$cfg | ConvertTo-Json | Set-Content -LiteralPath (Join-Path $gen 'guard.config.json') -Encoding UTF8

# 4. Engine-specific integration guide
$guide = @"
# Guard-Game integration — $GameName ($Engine)

World profile deployed: **$World**

## 0. Start the anti-cheat server (one process, run by you)
    cd <server folder>
    set GUARD_ADMIN_TOKEN=change-me-before-production
    node server/index.js
The server listens on TCP :7400 (game engines with raw sockets) and
HTTP :7401 (admin API + /ingest bridge for HTTP-only engines).

## 1. Activate the SDK plugin in your engine
Copy/import **sdk/$($cfg.sdk)** into your project and call it from gameplay:

Wiring (choose your engine):
    godot   -> attach the GDScript as an autoload; call sample() every physics frame
    unity   -> drop GuardClient.cs in Assets; await guard.Sample(... ) each FixedUpdate
    unreal  -> GuardClient.cs is C#; or port the wire protocol into C++
    roblox  -> require guardClient.lua on the SERVER Script; call :sample() per tick
    web     -> import guardBridgeClient.js; fetch-based, same endpoint

## 2. Every physics frame, report honest telemetry
    guard.sample/bridge.state(position, isOnGround[, velocity])

## 3. Report gameplay actions for the hook layer
    give          -> action('give', {item, amount})          (money givers)
    quest_claim   -> action('quest_claim', {questId, reward}) (quest farmers / macros)

## 4. Ban/warn enforcement is automatic and server-authoritative
Cheaters receive warn/ban frames; the server persists bans to
server/data/bans.json and streams events to the admin console:

    node admin/console.js live
    node admin/console.js list
    node admin/console.js ban <acct> "reason"

## Policy tuning
Edit server/config.js, or override via environment variables
(GUARD_WORLD, GUARD_STRIKES_TO_BAN, GUARD_MATCH_*, etc). See server/config.js.
"@
$guide | Set-Content -LiteralPath (Join-Path $TargetPath 'INTEGRATION.md') -Encoding UTF8

Write-Host "[Guard-Game] template written to: $TargetPath" -ForegroundColor Green
Write-Host "  next: open $TargetPath\INTEGRATION.md and wire the SDK calls." -ForegroundColor Yellow

  return new Promise((resolve, reject) => {
    const payload = JSON.stringify(body);
    const req = http.request(
      {
        hostname: '127.0.0.1', port, path: '/ingest' + pk, method: 'POST',
        headers: { 'Content-Type': 'application/json', 'Content-Length': Buffer.byteLength(payload), Connection: 'close' }
      },
      res => {
        let data = '';
        res.on('data', c => (data += c));
        res.on('end', () => {
          try { resolve({ status: res.statusCode, body: JSON.parse(data || '{}') }); }
          catch { resolve({ status: res.statusCode, body: data }); }
        });
      }
    );
    req.on('error', reject);
    req.write(payload);
    req.end();
  });
}

function makeBot(port, account, world) {

test('Guard-Game: full integration (legit, flyer, speeder, teleporter, hover, admin)', async () => {

  for (let i = 0; i < 30; i++) { sx += 30; speeder.bot.state({ x: sx, y: 0, z: 100 }, true); await delay(80); }
  assert.ok(speederBanned, 'speeder should be banned');
  speeder.bot.disconnect();
  await delay(100);

  // ------------------------------------------------------------------
  // 4. Teleporter
  // ------------------------------------------------------------------
  let teleporterBanned = false;
  const teleporter = makeBot(tcpPort, 'teleporter');
  teleporter.bot.handlers.onBan = () => { teleporterBanned = true; };
  await teleporter.welcome;
  let tp = 0;
  for (let i = 0; i < 30; i++) { tp += 1000; teleporter.bot.state({ x: tp, y: 20, z: tp }, true); await delay(80); }
  assert.ok(teleporterBanned, 'teleporter should be banned');
  teleporter.bot.disconnect();
  await delay(100);

  // ------------------------------------------------------------------
  // 5. Hoverbot
  // ------------------------------------------------------------------
  let hoverBanned = false;
  const hover = makeBot(tcpPort, 'hoverbot');
  hover.bot.handlers.onBan = () => { hoverBanned = true; };
  await hover.welcome;
  for (let i = 0; i < 35; i++) { hover.bot.state({ x: 50, y: 5, z: 50 }, false); await delay(100); }
  assert.ok(hoverBanned, 'hoverbot should be banned');
  hover.bot.disconnect();
  await delay(100);

  // ------------------------------------------------------------------
  // 6. Admin API auth
  // ------------------------------------------------------------------
  const noAuth = await new Promise((resolve, reject) => {
    http.get({ hostname: '127.0.0.1', port: httpPort, path: '/api/stats' }, res => {
      res.resume(); resolve(res.statusCode);
    }).on('error', reject);
  });
  assert.equal(noAuth, 401);

  // ------------------------------------------------------------------
  // 7. Admin ban + client rejection
  // ------------------------------------------------------------------
  await adminReq(httpPort, 'POST', '/api/ban?acct=known_cheater&reason=wallhack');
  const bannedBot = makeBot(tcpPort, 'known_cheater');
  let rejected = true;
  bannedBot.bot.handlers.onBan = () => { rejected = true; };
  try {
    await Promise.race([bannedBot.welcome, delay(600).then(() => { throw new Error('timeout'); })]);
    rejected = false;
  } catch {}
  assert.ok(rejected, 'banned account should not receive welcome');
  bannedBot.bot.disconnect();
  await delay(100);

  // ------------------------------------------------------------------
  // 8. Admin unban + rejoin
  // ------------------------------------------------------------------
  await adminReq(httpPort, 'POST', '/api/unban?acct=known_cheater');
  const unbannedBot = makeBot(tcpPort, 'known_cheater');
  await unbannedBot.welcome;
  unbannedBot.bot.disconnect();
  await delay(100);

  // ------------------------------------------------------------------
  // 9. Admin kick
  // ------------------------------------------------------------------
  const kickBot = makeBot(tcpPort, 'kicktarget');
  await kickBot.welcome;
  const kickP = new Promise(resolve => { kickBot.bot.handlers.onKick = resolve; });
  await adminReq(httpPort, 'POST', '/api/kick?acct=kicktarget&reason=test');
  const kv = await Promise.race([kickP.then(() => true), delay(800).then(() => null)]);
  assert.ok(kv, 'live player should be kicked');
  kickBot.bot.disconnect();
  await delay(100);

  // ------------------------------------------------------------------
  // 10. Final stats sanity
  // ------------------------------------------------------------------
  const stats = await adminReq(httpPort, 'GET', '/api/stats');
  assert.ok(stats.body.bans >= 4, `expected >=4 bans, got ${stats.body.bans}`);

  await core.stop();
});

'use strict';

const { test } = require('node:test');
const assert = require('node:assert');
const { VerdictEngine } = require('../server/validator');
const { WORLD_PROFILES } = require('../server/config');
const physics = require('../server/physics');

const ground = WORLD_PROFILES.ground;

// Physically-realistic jump arc for the ground world: v0 then gravity.
function jumpY(tMs) {
  const t = tMs / 1000;
  const v0 = physics.jumpVelocity(ground.gravity, ground.maxJumpHeight);
  const y = v0 * t - 0.5 * ground.gravity * t * t;
  return Math.max(0, y);
}

const T = 100; // 100ms between samples

function legitJumpSamples(land) {
  const samples = [];
  const reachGround = Math.floor(2 * physics.jumpVelocity(ground.gravity, ground.maxJumpHeight) / ground.gravity / (T / 1000)) + 1;
  for (let i = 0; i < reachGround; i++) {
    const t = i * T;
    samples.push({ t, y: jumpY(t), ground: i === 0 });
  }
  if (land) samples.push({ t: reachGround * T, y: 0, ground: true });
  return samples;
}

function runSamples(samples) {
  const engine = new VerdictEngine(ground, 0);
  const all = [];
  for (const s of samples) {
    all.push(...engine.sample({ x: 0, y: s.y, z: 0 }, s.ground, s.t));
  }
  return all;
}

test('legit jump: no violations', () => {
  const violations = runSamples(legitJumpSamples(true));
  assert.deepEqual(violations, [], `unexpected: ${JSON.stringify(violations)}`);
});

test('flyer climbing at impossible rate => RISE_VEL ban', () => {
  const engine = new VerdictEngine(ground, 0);
  engine.sample({ x: 0, y: 0, z: 0 }, true, 0);
  const v = engine.sample({ x: 0, y: 20, z: 0 }, false, T);
  assert.ok(v.some(x => x.severity === 'ban' && x.code === 'RISE_VEL'), JSON.stringify(v));
});

test('hovering mid-air with no movement => HOVER ban', () => {
  const engine = new VerdictEngine(ground, 0);
  let banned = false;
  engine.sample({ x: 50, y: 2, z: 50 }, false, 0);
  for (let t = T; t < 3200; t += T) {
    const v = engine.sample({ x: 50, y: 2, z: 50 }, false, t);
    if (v.some(x => x.severity === 'ban')) banned = true;
  }
  assert.ok(banned, 'hover should have been banned');
});

test('teleporter hops across the map => TELEPORT warn', () => {

  engine.sample({ x: 0, y: 20, z: 0 }, true, 0);

  const engine = new VerdictEngine(ground, 0);
  const path = [
    { y: 0, ground: true },
    { y: 0.5, ground: false },
    { y: 1.0, ground: false },
    { y: 1.5, ground: false },
    { y: 2.0, ground: false },
    { y: 2.5, ground: false },
    { y: 3.0, ground: false },

  ];
  let height = false;
  let climbBan = false;
  path.forEach((p, i) => {
    const v = engine.sample({ x: 0, y: p.y, z: 0 }, p.ground, i * T);
    height = height || v.some(x => x.code === 'HEIGHT_TOO_HIGH');
