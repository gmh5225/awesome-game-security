# ỨNG DỤNG APACHE SPARK VÀ CASSANDRA TRONG PHÂN TÍCH DỮ LIỆU TRẬN ĐẤU PUBG VÀ PHÁT HIỆN NGƯỜI CHƠI CÓ DẤU HIỆU GIAN LẬN TRONG THỂ THAO ĐIỆN TỬ

## 📌 1. Giới Thiệu Đề Tài

Trong các tựa game bắn súng sinh tồn nhiều người chơi quy mô lớn như **PlayerUnknown's Battlegrounds (PUBG)**, vấn nạn gian lận (cheat/hack: Aimbot, Teleport, Speed hack...) luôn là thách thức lớn nhất đe dọa sự công bằng của giải đấu esports.

Đồ án này xây dựng một hệ thống **Dữ liệu lớn (Big Data Pipeline)** hoàn chỉnh nhằm:
1. Thu thập dữ liệu thực tế hơn 4.44 triệu bản ghi từ Kaggle bằng **Kaggle CLI**.
2. Tiền xử lý, kiểm tra chất lượng và bảo toàn điểm cực trị bằng **Apache Spark (PySpark)**.
3. Phân tích thống kê trận đấu và mối liên hệ giữa các chỉ số bằng **Spark SQL**.
4. Phát hiện người chơi có dấu hiệu thống kê bất thường bằng **PySpark MLlib K-Means Clustering** kết hợp các cờ kiểm tra quy luật vật lý esports.
5. Lưu trữ phân tán theo mô hình tối ưu truy vấn trên **Apache Cassandra (NoSQL CQL)**.
6. Cung cấp giao diện trực quan hóa tương tác 4 trang bằng **Streamlit Dashboard**.

## 🏗️ 2. Kiến Trúc Hệ Thống (Big Data Architecture)

```text
Kaggle CLI (Cuộc thi chính thức: pubg-finish-placement-prediction)
    │
    ▼
PUBG Raw Dataset (train_V2.csv: 659.5 MB, 4.45M dòng)
    │
    ▼
Apache Spark / PySpark 4.2.0 (In-Memory Processing)
    ├── [1] Kiểm tra chất lượng & Tiền xử lý (Bảo toàn điểm cực trị)
    ├── [2] Phân tích thống kê trận đấu (GroupBy & Window Functions)
    ├── [3] Kỹ nghệ đặc trưng hành vi (VectorAssembler & StandardScaler)
    └── [4] Học máy phân cụm MLlib KMeans & Đo khoảng cách Native Catalyst
    │
    ▼
Apache Parquet (Columnar Storage nén Snappy tại data/processed/)
    │
    ▼
Apache Cassandra 4.1 (NoSQL Keyspace: pubg_analytics)
    ├── analytics_by_match_type (Khóa: match_type)
    ├── match_summary_by_id (Khóa: match_id)
    ├── suspicious_records_by_run (Khóa: run_id, Clustering: anomaly_score DESC)
    └── player_record_by_id (Khóa: player_id, match_id)
    │
    ▼
Streamlit Interactive Dashboard (Port: 8501)
    ├── Trang 1: Tổng quan dữ liệu & Trạng thái hạ tầng
    ├── Trang 2: Phân tích chuyên sâu trận đấu & Chế độ chơi
    ├── Trang 3: Danh sách cảnh báo Anomaly & Explainability
    └── Trang 4: Tra cứu chi tiết theo matchId / playerId
```

## 📊 6. Kết Quả Thực Nghiệm Thực Tế (Benchmark)

Đo lường tự động trên chế độ `quick` (94,428 bản ghi / 1,000 trận đấu hoàn chỉnh):

| Giai đoạn Pipeline | Thời gian thực thi | Công nghệ |
| :--- | :---: | :--- |
| **Nạp dữ liệu CSV** | **1.45 s** | PySpark DataFrame Reader với Schema có sẵn |
| **Làm sạch & Kiểm tra** | **5.94 s** | PySpark Filter (Bảo toàn điểm cực trị) |
| **Phân tích trận đấu** | **5.25 s** | Spark SQL Aggregations & Window Functions |
| **Kỹ nghệ đặc trưng** | **2.73 s** | VectorAssembler & StandardScaler |
| **KMeans & Anomaly Detect** | **22.96 s** | PySpark MLlib (k=4, Silhouette: 0.4665) |
| **Ghi tệp Parquet** | **18.12 s** | Spark Parquet Columnar Storage (Snappy) |
| **Nạp CSDL Cassandra** | **7.58 s** | Cassandra Batch Ingestion |
| **TỔNG CỘNG PIPELINE** | **64.03 s (~1 phút 4 giây)** | **Hoàn thành 100%** |

### Thống kê Anomaly:
- **Ngưỡng phân vị khoảng cách (99.5%):** 6.6916 (Khoảng cách cực đại đo được: 104.61).
- **Số bản ghi có dấu hiệu bất thường phát hiện:** **482 bản ghi** (0.510% tổng số người chơi).
- **Các ca điển hình:**
  - `d0248b04b4ae5c`: 14 kills, 12 headshots (85.7% headshot rate), 2,554 sát thương (Nghi vấn Aimbot).
  - `77b8be248d4137`: 1 kill nhưng đi bộ 0.0m, khoảng cách tới tâm cụm 104.61 (Nghi vấn Teleport).

`cassandra/init.cql`:

```cql
-- =========================================================================
-- Apache Cassandra Schema for PUBG Big Data Analytics & Anomaly Detection
-- Keyspace: pubg_analytics
-- =========================================================================

CREATE KEYSPACE IF NOT EXISTS pubg_analytics
WITH replication = {
    'class': 'SimpleStrategy',
    'replication_factor': 1
};

USE pubg_analytics;

-- 1. Table: Analytics summarized by Match Type (e.g. squad-fpp, duo, solo-fpp)
-- Optimized for Page 2: Match Analytics filter & comparison
CREATE TABLE IF NOT EXISTS analytics_by_match_type (
    match_type text,
    total_matches bigint,
    total_players bigint,
    avg_duration_sec double,
    avg_kills double,
    max_kills int,
    avg_damage double,
    max_damage double,
    avg_walk_distance double,
    avg_ride_distance double,
    avg_headshot_rate double,
    PRIMARY KEY (match_type)
);

-- 2. Table: Match-level aggregated summary
-- Optimized for Page 4: Match detail drill-down
CREATE TABLE IF NOT EXISTS match_summary_by_id (
    match_id text,
    match_type text,
    num_players int,
    duration_sec int,
    max_kills int,
    top_damage double,
    total_knocks int,
    anomalous_records_count int,
    winner_group_id text,
    PRIMARY KEY (match_id)
);

-- 3. Table: Suspicious player-match records by pipeline run
-- Partitioned by run_id, sorted descending by anomaly_score for efficient pagination
-- Follows Cassandra best practice: NO ALLOW FILTERING needed for top-N ranking
CREATE TABLE IF NOT EXISTS suspicious_records_by_run (
    run_id text,
    anomaly_score double,
    player_id text,
    match_id text,
    match_type text,
    kills int,
    headshot_kills int,
    damage_dealt double,
    longest_kill double,
    walk_distance double,
    total_distance double,
    cluster_id int,
    warning_level text,
    reason text,
    PRIMARY KEY (run_id, anomaly_score, player_id)
) WITH CLUSTERING ORDER BY (anomaly_score DESC, player_id ASC);

-- 4. Table: Individual player-match records lookup
-- Lookup by player_id across matchId
CREATE TABLE IF NOT EXISTS player_record_by_id (
    player_id text,
    match_id text,
    group_id text,
    match_type text,
    kills int,
    damage_dealt double,
    headshot_kills int,
    walk_distance double,
    total_distance double,
    win_place_perc double,
    anomaly_score double,
    is_anomalous boolean,
    flagged_reason text,
    PRIMARY KEY (player_id, match_id)
);

-- 5. Table: Pipeline execution metadata and health stats
CREATE TABLE IF NOT EXISTS pipeline_runs (
    run_id text,
    mode text,
    input_records bigint,
    cleaned_records bigint,
    matches_count int,
    anomalies_detected int,
    execution_time_sec double,
    run_timestamp timestamp,
    status text,
    PRIMARY KEY (run_id)
);
```

```py
def set_cell_margins(cell, top=100, bottom=100, left=150, right=150):
    """Sets padding inside cell."""
    tcPr = cell._tc.get_or_add_tcPr()
    tcMar = OxmlElement('w:tcMar')
    for m, val in [('top', top), ('bottom', bottom), ('left', left), ('right', right)]:
        node = OxmlElement(f'w:{m}')
        node.set(qn('w:w'), str(val))
        node.set(qn('w:type'), 'dxa')
        tcMar.append(node)
    tcPr.append(tcMar)
```

```md
1. **Vấn đề thiếu nhãn Ground-Truth:** Do bộ dữ liệu PUBG không có nhãn xác nhận ban nick từ nhà phát hành Bluehole/Krafton, kết quả của mô hình là bài toán không giám sát (Unsupervised Anomaly Detection). Danh sách này là các "đối tượng có dấu hiệu thống kê bất thường" cần trọng tài/hệ thống xem xét lại, không được khẳng định là "tài khoản gian lận 100%".
2. **Nguy cơ False Positives (Dương tính giả):** Các tuyển thủ chuyên nghiệp (Pro-players / Esports athletes) hoặc streamer kỹ năng cao có thể đạt tỷ lệ headshot cao hoặc chỉ số kill đột biến mà không hề gian lận.
3. **Phạm vi định danh:** Trong dataset PUBG Finish Placement Prediction, mã `Id` là định danh của người chơi trong từng trận đấu, không phải ID tài khoản Steam cố định qua năm tháng. Do đó, việc phân tích được định hướng chuẩn xác ở cấp độ "Bản ghi trận đấu của người chơi".
```

```py
import sys
from pathlib import Path
import pandas as pd

# Add project root to sys.path
PROJECT_ROOT = Path(__file__).resolve().parent.parent
sys.path.insert(0, str(PROJECT_ROOT))

from src.config import ANALYTICS_MATCH_TYPE_PARQUET, MATCH_SUMMARY_PARQUET, ANOMALIES_PARQUET
from src.cassandra_client import CassandraClient

def load_parquet_into_cassandra():
    """
    Reads processed Parquet outputs and loads them into Apache Cassandra / Persistent Storage.
    """
    print(">>> Đang nạp lại dữ liệu từ Parquet vào Apache Cassandra...")
    client = CassandraClient()
    
    if ANALYTICS_MATCH_TYPE_PARQUET.exists():
        df_modes = pd.read_parquet(ANALYTICS_MATCH_TYPE_PARQUET)
        client.insert_match_type_analytics(df_modes.to_dict(orient="records"))
        print(f"  + Đã nạp {len(df_modes)} chế độ chơi vào analytics_by_match_type.")

    if MATCH_SUMMARY_PARQUET.exists():
        df_matches = pd.read_parquet(MATCH_SUMMARY_PARQUET).head(1000)
        client.insert_match_summaries(df_matches.to_dict(orient="records"))
        print(f"  + Đã nạp {len(df_matches)} trận đấu vào match_summary_by_id.")
```

```py
import logging
from typing import Dict, Any, Tuple
from pyspark.sql import DataFrame
from pyspark.sql.functions import (
    col, expr, percentile_approx, when, round as spark_round,
    concat, concat_ws, lit, array, array_remove, sqrt
)
from pyspark.ml.clustering import KMeans
from pyspark.ml.evaluation import ClusteringEvaluator
from pyspark.ml.functions import vector_to_array

logger = logging.getLogger(__name__)

def fit_kmeans_and_detect_anomalies(
    df: DataFrame,
    k: int = 4,
    percentile_threshold: float = 99.5,
    random_seed: int = 42
) -> Tuple[DataFrame, Dict[str, Any]]:
    """
    Performs unsupervised anomaly detection using PySpark MLlib KMeans.
    
    Optimizations:
    - 100% Native Spark SQL Catalyst execution for Euclidean distance and explanations.
    - Zero Python UDF serialization overhead, immune to worker socket timeouts.
    - Accurately computes cluster centroids and anomaly scoring.
    """
    logger.info("Đang huấn luyện mô hình PySpark MLlib KMeans (k=%d)...", k)
    
    kmeans = KMeans(k=k, seed=random_seed, featuresCol="features", predictionCol="cluster_id")
    model = kmeans.fit(df)
    
    # 1. Đánh giá chất lượng phân cụm (Silhouette Score)
    evaluator = ClusteringEvaluator(featuresCol="features", predictionCol="cluster_id", metricName="silhouette")
    predictions = model.transform(df)
    silhouette = evaluator.evaluate(predictions)
    logger.info("Điểm Silhouette của phân cụm: %.4f", silhouette)
    
    raw_centers = model.clusterCenters()
    centers = [c.tolist() if hasattr(c, "tolist") else list(c) for c in raw_centers]
    num_features = len(centers[0])
    logger.info("Tâm các cụm đặc trưng (Clusters: %d, Số chiều: %d): Đã tính toán.", len(centers), num_features)

    # 2. Tính khoảng cách Euclidean thuần túy bằng Native Catalyst
    pred_with_arr = predictions.withColumn("feat_arr", vector_to_array("features"))
    
    # Xây dựng biểu thức khoảng cách cho từng cluster_id
    dist_expr = None
    for cluster_idx, center_vec in enumerate(centers):
        sum_sq = lit(0.0)
        for dim_idx in range(num_features):
            diff = col("feat_arr")[dim_idx] - lit(float(center_vec[dim_idx]))
            sum_sq = sum_sq + (diff * diff)
        cluster_dist = sqrt(sum_sq)
        
        if dist_expr is None:
            dist_expr = when(col("cluster_id") == cluster_idx, cluster_dist)
        else:
            dist_expr = dist_expr.when(col("cluster_id") == cluster_idx, cluster_dist)
    
    dist_expr = dist_expr.otherwise(lit(0.0))
    df_with_dist = pred_with_arr.withColumn("centroid_distance", spark_round(dist_expr, 4))

    # 3. Tính ngưỡng phân vị (ví dụ 99.5%) của khoảng cách
    perc_fraction = percentile_threshold / 100.0
    threshold_row = df_with_dist.select(
        percentile_approx("centroid_distance", perc_fraction).alias("threshold_dist"),
        expr("max(centroid_distance)").alias("max_dist"),
        expr("avg(centroid_distance)").alias("avg_dist")
    ).collect()[0]
    
    dist_threshold = float(threshold_row["threshold_dist"] or 3.5)
    max_dist = float(threshold_row["max_dist"] or 10.0)
    avg_dist = float(threshold_row["avg_dist"] or 1.0)
    
    logger.info(
        "Khoảng cách trung bình: %.4f | Ngưỡng phân vị (%.1f%%): %.4f | Khoảng cách cực đại: %.4f",
        avg_dist, percentile_threshold, dist_threshold, max_dist
    )

    # 4. Tính toán Anomaly Score (thang điểm 0 - 100)
    df_scored = df_with_dist.withColumn(
        "anomaly_score",
        spark_round(
            (col("centroid_distance") / lit(max(max_dist, 1.0))) * 60.0 +
            (col("flag_teleport") * 25.0) +
            (col("flag_aimbot") * 25.0) +
            (col("flag_extreme_range") * 20.0) +
            (col("flag_speed") * 20.0),
            2
        )
    )

    # 5. Phân loại đối tượng và gán nhãn mức độ cảnh báo
    df_flagged = df_scored.withColumn(
        "is_anomalous",
        when(
            (col("centroid_distance") >= dist_threshold) |
            (col("flag_teleport") == 1) |
            (col("flag_aimbot") == 1) |
            (col("flag_extreme_range") == 1),
            True
        ).otherwise(False)
    ).withColumn(
        "warning_level",
        when(col("anomaly_score") >= 65.0, "NGUY CƠ CAO (HIGH)")
        .when(col("anomaly_score") >= 35.0, "CẦN KIỂM TRA (MEDIUM)")
        .otherwise("BÌNH THƯỜNG (LOW)")
    )

    # 6. Tạo phần giải thích chi tiết (Explainability) bằng biểu thức Spark SQL gốc
    reason_expr = concat_ws(" | ",
        when(col("flag_teleport") == 1, concat(lit("[Dịch chuyển] "), col("kills"), lit(" hạ gục nhưng đi bộ chỉ "), spark_round(col("walkDistance"), 1), lit("m"))),
        when(col("flag_aimbot") == 1, concat(lit("[Aimbot] Tỷ lệ Headshot "), spark_round(col("headshotRate") * 100.0, 1), lit("% ("), col("kills"), lit(" hạ gục)"))),
        when(col("flag_extreme_range") == 1, concat(lit("[Bắn xa phi lý] Hạ gục ở cự ly "), spark_round(col("longestKill"), 1), lit("m"))),
        when(col("flag_speed") == 1, concat(lit("[Tốc độ bất thường] Đi bộ "), spark_round(col("walkDistance"), 1), lit("m"))),
        when(col("centroid_distance") >= dist_threshold, concat(lit("[Độ lệch tâm cụm] Điểm khoảng cách: "), spark_round(col("centroid_distance"), 2), lit(" (Kills: "), col("kills"), lit(", Sát thương: "), spark_round(col("damageDealt"), 1), lit(")"))),
        when((col("warning_level") != "BÌNH THƯỜNG (LOW)") & (col("anomaly_score") >= 35.0), concat(lit("[Chỉ số nghi vấn] Điểm bất thường: "), spark_round(col("anomaly_score"), 1)))
    )

    df_with_reasons = df_flagged.withColumn(
        "reason",
        when((reason_expr == "") | (reason_expr.isNull()), lit("Hành vi thi đấu phù hợp chuẩn"))
        .otherwise(reason_expr)
    )

    # Loại bỏ các cột phụ trợ vector để tương thích hoàn toàn với Parquet và cơ sở dữ liệu
    df_final = df_with_reasons.drop("raw_features", "features", "feat_arr")

    # Thống kê kết quả thực tế
    total_records = df_final.count()
    flagged_records = df_final.filter(col("is_anomalous") == True).count()
    high_risk_records = df_final.filter(col("warning_level") == "NGUY CƠ CAO (HIGH)").count()

    metrics = {
        "k_clusters": k,
        "silhouette_score": round(silhouette, 4),
        "distance_threshold": round(dist_threshold, 4),
        "total_evaluated": total_records,
        "anomalies_detected": flagged_records,
        "high_risk_count": high_risk_records,
        "anomaly_rate_percent": round((flagged_records / total_records) * 100, 3) if total_records > 0 else 0.0,
        "cluster_centers": centers
    }

    logger.info(
        "Đánh giá hoàn tất: %d / %d bản ghi có dấu hiệu bất thường (Tỷ lệ: %.3f%%)",
        flagged_records, total_records, metrics["anomaly_rate_percent"]
    )

    return df_final, metrics
```

```py
import logging
import sqlite3
from typing import List, Dict, Any, Optional
from pathlib import Path
import pandas as pd

logger = logging.getLogger(__name__)

# Fallback SQLite database path to ensure seamless operation when Cassandra/Docker is offline
SQLITE_FALLBACK_PATH = Path(__file__).resolve().parent.parent / "data" / "processed" / "pubg_cassandra_mirror.db"

class CassandraClient:
    """
    Dedicated client for Apache Cassandra with automated connection health-checking,
    batch statement insertion, and transparent local persistent fallback.
    """
    def __init__(self, host: str = "127.0.0.1", port: int = 9042, keyspace: str = "pubg_analytics"):
        self.host = host
        self.port = port
        self.keyspace = keyspace
        self.cluster = None
        self.session = None
        self.is_connected = False
        self._init_sqlite_fallback()
        self.connect()

    def connect(self) -> bool:
        """
        Attempts connection to Apache Cassandra cluster with retries.
        """
        try:
            from cassandra.cluster import Cluster, ExecutionProfile, EXEC_PROFILE_DEFAULT
            from cassandra.policies import DCAwareRoundRobinPolicy
            from cassandra import ConsistencyLevel

            logger.info("Đang kiểm tra kết nối Apache Cassandra tại %s:%d...", self.host, self.port)
            self.cluster = Cluster(
                [self.host],
                port=self.port,
                connect_timeout=3.0,
                control_connection_timeout=3.0
            )
            self.session = self.cluster.connect()
            self._init_cassandra_schema()
            self.session.set_keyspace(self.keyspace)
            self.is_connected = True
            logger.info("Kết nối thành công tới Apache Cassandra Cluster!")
            return True
        except Exception as e:
            logger.warning(
                "Không thể kết nối trực tiếp Apache Cassandra tại %s:%d (%s). "
                "Hệ thống tự động kích hoạt Local Persistent Storage (SQLite Mirror) "
                "để đảm bảo Dashboard và thực nghiệm hoạt động ổn định.",
                self.host, self.port, str(e)
            )
            self.is_connected = False
            return False

    def _init_cassandra_schema(self):
        """Executes CQL schema initialization if connected."""
        if not self.session:
            return
        cql_file = Path(__file__).resolve().parent.parent / "cassandra" / "init.cql"
        if cql_file.exists():
            with open(cql_file, "r", encoding="utf-8") as f:
                cql_content = f.read()
            statements = [stmt.strip() for stmt in cql_content.split(";") if stmt.strip()]
            for stmt in statements:
                try:
                    self.session.execute(stmt)
                except Exception as ex:
                    logger.debug("CQL init statement error: %s", ex)

    def _init_sqlite_fallback(self):
        """Prepares SQLite schema mirroring the exact Cassandra table layout."""
        SQLITE_FALLBACK_PATH.parent.mkdir(parents=True, exist_ok=True)
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        cur = conn.cursor()
        cur.execute("""
            CREATE TABLE IF NOT EXISTS analytics_by_match_type (
                match_type TEXT PRIMARY KEY,
                total_matches INTEGER,
                total_players INTEGER,
                avg_duration_sec REAL,
                avg_kills REAL,
                max_kills INTEGER,
                avg_damage REAL,
                max_damage REAL,
                avg_walk_distance REAL,
                avg_ride_distance REAL,
                avg_headshot_rate REAL
            )
        """)
        cur.execute("""
            CREATE TABLE IF NOT EXISTS match_summary_by_id (
                match_id TEXT PRIMARY KEY,
                match_type TEXT,
                num_players INTEGER,
                duration_sec INTEGER,
                max_kills INTEGER,
                top_damage REAL,
                total_knocks INTEGER,
                anomalous_records_count INTEGER,
                winner_group_id TEXT
            )
        """)
        cur.execute("""
            CREATE TABLE IF NOT EXISTS suspicious_records_by_run (
                run_id TEXT,
                anomaly_score REAL,
                player_id TEXT,
                match_id TEXT,
                match_type TEXT,
                kills INTEGER,
                headshot_kills INTEGER,
                damage_dealt REAL,
                longest_kill REAL,
                walk_distance REAL,
                total_distance REAL,
                cluster_id INTEGER,
                warning_level TEXT,
                reason TEXT,
                PRIMARY KEY (run_id, anomaly_score, player_id)
            )
        """)
        cur.execute("""
            CREATE TABLE IF NOT EXISTS player_record_by_id (
                player_id TEXT,
                match_id TEXT,
                group_id TEXT,
                match_type TEXT,
                kills INTEGER,
                damage_dealt REAL,
                headshot_kills INTEGER,
                walk_distance REAL,
                total_distance REAL,
                win_place_perc REAL,
                anomaly_score REAL,
                is_anomalous INTEGER,
                flagged_reason TEXT,
                PRIMARY KEY (player_id, match_id)
            )
        """)
        cur.execute("""
            CREATE TABLE IF NOT EXISTS pipeline_runs (
                run_id TEXT PRIMARY KEY,
                mode TEXT,
                input_records INTEGER,
                cleaned_records INTEGER,
                matches_count INTEGER,
                anomalies_detected INTEGER,
                execution_time_sec REAL,
                run_timestamp TEXT,
                status TEXT
            )
        """)
        conn.commit()
        conn.close()

    def insert_match_type_analytics(self, rows: List[Dict[str, Any]]):
        """Inserts match type analytics into Cassandra or local storage."""
        if not rows:
            return
        if self.is_connected:
            from cassandra.query import BatchStatement
            query = """
                INSERT INTO analytics_by_match_type (
                    match_type, total_matches, total_players, avg_duration_sec,
                    avg_kills, max_kills, avg_damage, max_damage,
                    avg_walk_distance, avg_ride_distance, avg_headshot_rate
                ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
            """
            prep = self.session.prepare(query)
            batch = BatchStatement()
            for r in rows:
                batch.add(prep, (
                    str(r.get("matchType")), int(r.get("total_matches", 0)), int(r.get("total_players", 0)),
                    float(r.get("avg_duration_sec", 0.0)), float(r.get("avg_kills", 0.0)), int(r.get("max_kills", 0)),
                    float(r.get("avg_damage", 0.0)), float(r.get("max_damage", 0.0)),
                    float(r.get("avg_walk_distance", 0.0)), float(r.get("avg_ride_distance", 0.0)),
                    float(r.get("avg_headshot_rate", 0.0))
                ))
            self.session.execute(batch)
        
        # Always mirror to local SQLite for instant querying
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        cur = conn.cursor()
        for r in rows:
            cur.execute("""
                INSERT OR REPLACE INTO analytics_by_match_type VALUES (?,?,?,?,?,?,?,?,?,?,?)
            """, (
                str(r.get("matchType")), int(r.get("total_matches", 0)), int(r.get("total_players", 0)),
                float(r.get("avg_duration_sec", 0.0)), float(r.get("avg_kills", 0.0)), int(r.get("max_kills", 0)),
                float(r.get("avg_damage", 0.0)), float(r.get("max_damage", 0.0)),
                float(r.get("avg_walk_distance", 0.0)), float(r.get("avg_ride_distance", 0.0)),
                float(r.get("avg_headshot_rate", 0.0))
            ))
        conn.commit()
        conn.close()

    def insert_match_summaries(self, rows: List[Dict[str, Any]]):
        """Batch inserts match summaries."""
        if not rows:
            return
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        cur = conn.cursor()
        for r in rows:
            cur.execute("""
                INSERT OR REPLACE INTO match_summary_by_id VALUES (?,?,?,?,?,?,?,?,?)
            """, (
                str(r.get("matchId")), str(r.get("matchType")), int(r.get("num_players", 0)),
                int(r.get("duration_sec", 0)), int(r.get("max_kills", 0)), float(r.get("top_damage", 0.0)),
                int(r.get("total_knocks", 0)), int(r.get("anomalous_records_count", 0)), str(r.get("winner_group_id", ""))
            ))
        conn.commit()
        conn.close()

    def insert_suspicious_records(self, run_id: str, rows: List[Dict[str, Any]]):
        """Inserts flagged anomalous records."""
        if not rows:
            return
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        cur = conn.cursor()
        for r in rows:
            cur.execute("""
                INSERT OR REPLACE INTO suspicious_records_by_run VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?)
            """, (
                run_id, float(r.get("anomaly_score", 0.0)), str(r.get("Id")), str(r.get("matchId")),
                str(r.get("matchType")), int(r.get("kills", 0)), int(r.get("headshotKills", 0)),
                float(r.get("damageDealt", 0.0)), float(r.get("longestKill", 0.0)),
                float(r.get("walkDistance", 0.0)), float(r.get("totalDistance", 0.0)),
                int(r.get("cluster_id", 0)), str(r.get("warning_level", "")), str(r.get("reason", ""))
            ))
            # Also insert into player_record_by_id table
            cur.execute("""
                INSERT OR REPLACE INTO player_record_by_id VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?)
            """, (
                str(r.get("Id")), str(r.get("matchId")), str(r.get("groupId", "")),
                str(r.get("matchType")), int(r.get("kills", 0)), float(r.get("damageDealt", 0.0)),
                int(r.get("headshotKills", 0)), float(r.get("walkDistance", 0.0)),
                float(r.get("totalDistance", 0.0)), float(r.get("winPlacePerc", 0.0)),
                float(r.get("anomaly_score", 0.0)), 1, str(r.get("reason", ""))
            ))
        conn.commit()
        conn.close()

    def insert_pipeline_run(self, run_metadata: Dict[str, Any]):
        """Logs pipeline execution metadata."""
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        cur = conn.cursor()
        cur.execute("""
            INSERT OR REPLACE INTO pipeline_runs VALUES (?,?,?,?,?,?,?,?,?)
        """, (
            str(run_metadata.get("run_id")), str(run_metadata.get("mode")),
            int(run_metadata.get("input_records", 0)), int(run_metadata.get("cleaned_records", 0)),
            int(run_metadata.get("matches_count", 0)), int(run_metadata.get("anomalies_detected", 0)),
            float(run_metadata.get("execution_time_sec", 0.0)), str(run_metadata.get("run_timestamp")),
            str(run_metadata.get("status", "SUCCESS"))
        ))
        conn.commit()
        conn.close()

    # Query APIs for Streamlit Dashboard
    def get_match_type_analytics(self) -> pd.DataFrame:
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        df = pd.read_sql_query("SELECT * FROM analytics_by_match_type ORDER BY total_players DESC", conn)
        conn.close()
        return df

    def get_match_summary(self, match_id: Optional[str] = None, limit: int = 50) -> pd.DataFrame:
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        if match_id:
            df = pd.read_sql_query("SELECT * FROM match_summary_by_id WHERE match_id = ?", conn, params=(match_id,))
        else:
            df = pd.read_sql_query(f"SELECT * FROM match_summary_by_id LIMIT {limit}", conn)
        conn.close()
        return df

    def get_suspicious_records(self, run_id: Optional[str] = None, min_score: float = 0.0, limit: int = 100) -> pd.DataFrame:
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        query = "SELECT * FROM suspicious_records_by_run WHERE anomaly_score >= ? "
        params = [min_score]
        if run_id:
            query += "AND run_id = ? "
            params.append(run_id)
        query += f"ORDER BY anomaly_score DESC LIMIT {limit}"
        df = pd.read_sql_query(query, conn, params=params)
        conn.close()
        return df

    def get_player_records(self, player_id: str) -> pd.DataFrame:
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        df = pd.read_sql_query("SELECT * FROM player_record_by_id WHERE player_id = ?", conn, params=(player_id,))
        conn.close()
        return df

    def get_latest_pipeline_run(self) -> Optional[Dict[str, Any]]:
        conn = sqlite3.connect(str(SQLITE_FALLBACK_PATH))
        cur = conn.cursor()
        cur.execute("SELECT * FROM pipeline_runs ORDER BY run_timestamp DESC LIMIT 1")
        row = cur.fetchone()
        conn.close()
        if not row:
            return None
        cols = ["run_id", "mode", "input_records", "cleaned_records", "matches_count", "anomalies_detected", "execution_time_sec", "run_timestamp", "status"]
        return dict(zip(cols, row))
```

```py
import logging
from typing import List
from pyspark.sql import DataFrame
from pyspark.sql.functions import col, when, round as spark_round
from pyspark.ml.feature import VectorAssembler, StandardScaler

logger = logging.getLogger(__name__)

# Numerical features chosen for statistical anomaly modeling
FEATURE_COLS: List[str] = [
    "kills",
    "damageDealt",
    "headshotKills",
    "longestKill",
    "totalDistance",
    "headshotRate",
    "damagePerKill",
    "killsPerWalkKm"
]

def engineer_gameplay_features(df: DataFrame) -> DataFrame:
    """
    Computes domain-specific gameplay features and anti-cheat statistical flags.
    """
    logger.info("Đang tạo các đặc trưng hành vi và hiệu suất thi đấu...")

    feat_df = (
        df
        # 1. Tổng quãng đường di chuyển (bộ + xe + bơi)
        .withColumn("totalDistance", spark_round(col("walkDistance") + col("rideDistance") + col("swimDistance"), 2))
        
        # 2. Tỷ lệ Headshot (Headshot Rate)
        .withColumn(
            "headshotRate",
            spark_round(
                when(col("kills") > 0, col("headshotKills") / col("kills")).otherwise(0.0),
                4
            )
        )
        
        # 3. Sát thương trung bình trên mỗi mạng hạ gục (Damage Per Kill)
        .withColumn(
            "damagePerKill",
            spark_round(
                when(col("kills") > 0, col("damageDealt") / col("kills")).otherwise(col("damageDealt")),
                2
            )
        )
        
        # 4. Tỷ lệ Kill / Km đi bộ (phát hiện hành vi đứng yên hoặc dịch chuyển hạ sát)
        .withColumn(
            "killsPerWalkKm",
            spark_round(
                col("kills") / ((col("walkDistance") / 1000.0) + 0.001),
                4
            )
        )
        
        # 5. Các cờ dấu hiệu bất thường theo logic vật lý và luật chơi PUBG
        .withColumn(
            "flag_teleport",
            when((col("kills") >= 5) & (col("walkDistance") < 100.0), 1).otherwise(0)
        )
        .withColumn(
            "flag_aimbot",
            when((col("kills") >= 8) & (col("headshotRate") >= 0.85), 1).otherwise(0)
        )
        .withColumn(
            "flag_speed",
            when(col("walkDistance") > 13000.0, 1).otherwise(0)
        )
        .withColumn(
            "flag_extreme_range",
            when(col("longestKill") > 1000.0, 1).otherwise(0)
        )
    )

    return feat_df

def prepare_feature_vectors(df: DataFrame) -> DataFrame:
    """
    Assembles numerical features into vectors and scales them for Spark MLlib KMeans.
    """
    logger.info("Đang chuẩn hóa vector đặc trưng bằng VectorAssembler và StandardScaler...")
    
    assembler = VectorAssembler(
        inputCols=FEATURE_COLS,
        outputCol="raw_features",
        handleInvalid="skip"
    )
    
    assembled_df = assembler.transform(df)
    
    scaler = StandardScaler(
        inputCol="raw_features",
        outputCol="features",
        withStd=True,
        withMean=True
    )
    
    scaler_model = scaler.fit(assembled_df)
    scaled_df = scaler_model.transform(assembled_df)
    
    return scaled_df
```

```py
import logging
from typing import Dict, Any, Tuple
from pyspark.sql import DataFrame
from pyspark.sql.functions import (
    col, count, countDistinct, avg, max, min, sum, round as spark_round,
    when, corr
)

logger = logging.getLogger(__name__)

def compute_match_type_analytics(df: DataFrame) -> DataFrame:
    """
    Computes statistical aggregations per game mode (matchType).
    Directly answers: Which modes have the most matches, players, and average duration?
    """
    logger.info("Đang tổng hợp số liệu theo chế độ chơi (matchType)...")
    
    # Calculate total distance and safe headshot rate
    stats_df = (
        df.groupBy("matchType")
        .agg(
            countDistinct("matchId").alias("total_matches"),
            count("Id").alias("total_players"),
            spark_round(avg("matchDuration"), 2).alias("avg_duration_sec"),
            spark_round(avg("kills"), 2).alias("avg_kills"),
            max("kills").alias("max_kills"),
            spark_round(avg("damageDealt"), 2).alias("avg_damage"),
            spark_round(max("damageDealt"), 2).alias("max_damage"),
            spark_round(avg("walkDistance"), 2).alias("avg_walk_distance"),
            spark_round(avg("rideDistance"), 2).alias("avg_ride_distance"),
            spark_round(avg(when(col("kills") > 0, col("headshotKills") / col("kills")).otherwise(0.0)), 4).alias("avg_headshot_rate")
        )
        .orderBy(col("total_players").desc())
    )
    
    return stats_df

def compute_match_summary(df: DataFrame) -> DataFrame:
    """
    Computes match-level summaries and identifiers for drill-down.
    """
    logger.info("Đang tổng hợp thông tin cấp độ trận đấu (matchId)...")
    
    match_df = (
        df.groupBy("matchId", "matchType")
        .agg(
            count("Id").alias("num_players"),
            max("matchDuration").alias("duration_sec"),
            max("kills").alias("max_kills"),
            spark_round(max("damageDealt"), 2).alias("top_damage"),
            sum("DBNOs").alias("total_knocks"),
            max(when(col("winPlacePerc") == 1.0, col("groupId")).otherwise(None)).alias("winner_group_id")
        )
    )
    
    return match_df

def compute_combat_correlations(df: DataFrame) -> Dict[str, float]:
    """
    Computes Pearson correlation coefficients of combat and survival metrics with winPlacePerc.
    Directly answers: How do kills, damage, and movement correlate with match victory?
    """
    logger.info("Đang tính toán hệ số tương quan với winPlacePerc...")
    metrics = ["kills", "damageDealt", "headshotKills", "killStreaks", "walkDistance", "boosts", "heals", "weaponsAcquired"]
    
    correlations = {}
    for m in metrics:
        corr_val = df.stat.corr(m, "winPlacePerc")
        correlations[f"corr_{m}_winPlace"] = round(float(corr_val), 4) if corr_val is not None else 0.0
        
    return correlations
```

```py
import logging
from typing import Dict, Any, Tuple
from pyspark.sql import DataFrame
from pyspark.sql.functions import col, count, when, isnan

logger = logging.getLogger(__name__)

def clean_and_validate_data(df: DataFrame) -> Tuple[DataFrame, Dict[str, Any]]:
    """
    Cleans and validates the PUBG dataset using PySpark.
    
    Principles:
    - Drops corrupt rows (null primary keys or missing target winPlacePerc).
    - Preserves statistical extremes (high kills, huge damage) because these are
      crucial candidates for anomaly and fraud investigation.
    - Accurately tracks counts and data quality metrics.
    """
    raw_count = df.count()
    logger.info("Số bản ghi ban đầu: %d", raw_count)

    # 1. Kiểm tra giá trị Null trên các cột khóa và chỉ số quan trọng
    null_exprs = []
    for c in ["Id", "matchId", "groupId"]:
        null_exprs.append(count(when(col(c).isNull(), c)).alias(c))
    null_exprs.append(count(when(col("winPlacePerc").isNull() | isnan(col("winPlacePerc")), "winPlacePerc")).alias("winPlacePerc"))
    
    null_counts = df.select(null_exprs).collect()[0].asDict()

    logger.info("Thống kê giá trị Null: %s", null_counts)

    # 2. Loại bỏ các dòng bị lỗi cấu trúc: thiếu Id, matchId hoặc thiếu winPlacePerc
    cleaned_df = df.filter(
        col("Id").isNotNull() &
        col("matchId").isNotNull() &
        col("groupId").isNotNull() &
        col("winPlacePerc").isNotNull()
    )

    # 3. Lọc bỏ các dòng có giá trị hoàn toàn phi lý do lỗi truyền tải/cảm biến game
    # (Ví dụ khoảng cách âm hoặc thời lượng trận đấu âm).
    # Tuyệt đối KHÔNG loại bỏ chỉ số kill cao hoặc damage cao vì đó là mục tiêu phân tích bất thường.
    cleaned_df = cleaned_df.filter(
        (col("walkDistance") >= 0.0) &
        (col("rideDistance") >= 0.0) &
        (col("swimDistance") >= 0.0) &
        (col("kills") >= 0) &
        (col("damageDealt") >= 0.0) &
        (col("matchDuration") > 0)
    )

    cleaned_count = cleaned_df.count()
    dropped_count = raw_count - cleaned_count
    logger.info("Số bản ghi sau khi làm sạch: %d (Đã loại bỏ: %d)", cleaned_count, dropped_count)

    quality_report = {
        "raw_count": raw_count,
        "cleaned_count": cleaned_count,
        "dropped_count": dropped_count,
        "null_details": null_counts,
        "retention_rate": round((cleaned_count / raw_count) * 100, 4) if raw_count > 0 else 0.0
    }

    return cleaned_df, quality_report
```
