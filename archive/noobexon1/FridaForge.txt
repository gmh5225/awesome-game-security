## ✨ Features

Right-click (or hit a hotkey) in your disassembler to generate ready-to-use Frida snippets — the result is instantly copied to your clipboard.

- 🧩 **Composable scripts** — snippets are independent but can be nested to build complex instrumentation with a few clicks
- 🎯 **Context-aware** — scripts auto-fill module name, function address, section, and any other detail available from your current context
- 🧰 **Two hosts, one experience** — identical features, hotkeys, and menus in both IDA Pro and Binary Ninja
- 📋 **Clipboard integration** — generated scripts are copied the moment you run an action

### Supported Actions

#### 🪝 Hooks

| Action | Description | Hotkey |
|---|---|---|
| Generate function hook | Intercept calls to the selected function, log entry/exit | `Shift+F` |
| Generate dlopen hooks | Monitor `dlopen` (including Android variants) to detect module loading | `Shift+D` |

#### 🧠 Memory

| Action | Description | Hotkey |
|---|---|---|
| Modify section protection | Change memory protection of the section at the current address | `Shift+M` |

#### 🩹 Patching

| Action | Description | Hotkey |
|---|---|---|
| Negate cond branch (ARM64) | Flip the condition of an ARM64 conditional branch | `Shift+A` |
| Negate cond branch (x86/x64) | Flip the condition of an x86/x64 conditional branch | `Shift+X` |

## 🔧 How it Works

Each feature follows a simple pipeline: a **Frida template** (`fridaforge/templates/`) provides the JavaScript skeleton with placeholders, a **command** (`fridaforge/commands/`) gathers context through a host-agnostic **Backend**, and a **generator** (`fridaforge/core/`) fills the template to produce the final script.

The shared core knows nothing about IDA or Binary Ninja. Each host lives in `hosts/` and provides a thin **adapter** that implements the `Backend` interface (data extraction, clipboard, menu + hotkey registration). Add a feature once and it works in both tools.

## 📦 Installation

Grab the archive for your tool from the [latest release](https://github.com/noobexon1/FridaForge/releases). There's one per host — `fridaforge-binja-<version>.zip` and `fridaforge-ida-<version>.zip`.

### 🟠 Binary Ninja

1. Find your user plugins directory by running this in Binary Ninja's Python console:
   ```python
   binaryninja.user_plugin_path()
   ```
2. Extract `fridaforge-binja-<version>.zip` into that directory so that `<binja user plugins>/fridaforge/` exists.
3. Restart Binary Ninja.

### 🔵 IDA Pro

1. **Prerequisites:**
   - IDA Pro (tested with 9.0, but any version with Python 3 and `idaapi` should work).
   - [Frida](https://frida.re) installed on your target system/device.
   - PyQt5 for clipboard functionality (usually bundled with IDA's Python).
2. Locate your IDA Pro plugins directory — in IDA, go to `Help` → `About IDA...` → `IDA directories` tab → `Plugins`. Common paths:
   - **Windows:** `%APPDATA%\Hex-Rays\IDA Pro\plugins` or `C:\Program Files\IDA Pro X.X\plugins`
   - **Linux:** `~/.idapro/plugins`
   - **macOS:** `~/.idapro/plugins`
3. Extract `fridaforge-ida-<version>.zip` into that directory so that `<plugins>/fridaforge/ida-plugin.json` exists.
4. Restart IDA Pro. The plugin loads automatically — you'll see `[FridaForge]` messages in the Output window if it loaded correctly.

## 🚀 Usage

1. Open your target binary in IDA Pro or Binary Ninja.
2. Right-click in the disassembly or pseudocode view (or use the hotkeys above).
3. Navigate to **FridaForge** → choose a category and action.
4. The generated Frida script is copied to your clipboard.
5. Paste into your Frida CLI, agent, or `.js` file.

### 🧱 Script Composition

Snippets are designed to be independent building blocks. You can nest scripts inside each other — for example, hook a function, negate a conditional branch on entry, and restore it on exit. Complex instrumentation from a few clicks.

```py
"""Assemble the two FridaForge host archives."""

import argparse
import json
import shutil
import zipfile
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
PKG = ROOT / "fridaforge"
HOSTS = ROOT / "hosts"
DIST = ROOT / "dist"
STAGING = ROOT / "build" / "_staging"

_IGNORE = shutil.ignore_patterns("__pycache__", "*.pyc")


def read_version() -> str:
    namespace: dict = {}
    exec((PKG / "_version.py").read_text(encoding="utf-8"), namespace)
    return namespace["__version__"]


def stamp_version(pkg_dir: Path, host: str, version: str) -> None:
    if host == "binja":
        path = pkg_dir / "plugin.json"
        data = json.loads(path.read_text(encoding="utf-8"))
        data["version"] = version
        path.write_text(json.dumps(data, indent=2), encoding="utf-8")
    else:
        path = pkg_dir / "ida-plugin.json"
        data = json.loads(path.read_text(encoding="utf-8"))
        data["plugin"]["version"] = version
        path.write_text(json.dumps(data, indent=2), encoding="utf-8")


def zip_folder(folder: Path, out: Path) -> None:
    with zipfile.ZipFile(out, "w", zipfile.ZIP_DEFLATED) as archive:
        for file in sorted(folder.rglob("*")):
            if file.is_file():
                arcname = file.relative_to(folder).as_posix()
                info = zipfile.ZipInfo(arcname, date_time=(1980, 1, 1, 0, 0, 0))
                info.compress_type = zipfile.ZIP_DEFLATED
                info.external_attr = 0o644 << 16
                archive.writestr(info, file.read_bytes())


def build_host(host: str, version: str) -> Path:
    stage = STAGING / host
    if stage.exists():
        shutil.rmtree(stage)
    stage.mkdir(parents=True)

    pkg_dir = stage / "fridaforge"
    shutil.copytree(PKG, pkg_dir, ignore=_IGNORE)

    for item in (HOSTS / host).iterdir():
        if item.is_file():
            shutil.copy2(item, pkg_dir / item.name)

    stamp_version(pkg_dir, host, version)

    DIST.mkdir(exist_ok=True)
    out = DIST / f"fridaforge-{host}-{version}.zip"
    if out.exists():
        out.unlink()
    zip_folder(stage, out)
    return out


def main() -> None:
    parser = argparse.ArgumentParser(description="Build FridaForge archives.")
    parser.add_argument("--version", default=None, help="Override version.")
    args = parser.parse_args()
    version = args.version or read_version()

    for host in ("binja", "ida"):
        out = build_host(host, version)
        print(f"Built {out}")


if __name__ == "__main__":
    main()
```

```py
"""Host-agnostic backend interface for FridaForge commands."""

from abc import ABC, abstractmethod
from dataclasses import dataclass
from enum import Enum, auto


class ContextKind(Enum):
    """The host context a command needs to run."""

    GLOBAL = auto()    # only the module is needed
    ADDRESS = auto()   # the current address is needed
    FUNCTION = auto()  # the current function is needed


@dataclass(frozen=True)
class FunctionRef:
    """A resolved reference to a function in the loaded binary."""

    start: int
    name: str


class Backend(ABC):
    """The port each host (Binary Ninja, IDA) must implement."""

    @abstractmethod
    def get_module_name(self) -> str:
        """Return the loaded module's base file name."""

    @abstractmethod
    def get_image_base(self) -> int:
        """Return the image base address of the loaded binary."""

    @abstractmethod
    def get_current_address(self) -> int | None:
        """Return the currently selected address, or ``None``."""

    @abstractmethod
    def get_current_function(self) -> FunctionRef | None:
        """Return the currently selected function, or ``None``."""

    @abstractmethod
    def get_section_name_at(self, addr: int) -> str | None:
        """Return the name of the section/segment containing *addr*."""

    @abstractmethod
    def get_instruction_mnemonic(self, addr: int) -> str | None:
        """Return the mnemonic of the instruction at *addr*, or ``None``."""

    @abstractmethod
    def copy_to_clipboard(self, text: str) -> bool:
        """Copy *text* to the system clipboard. Return success."""

    @abstractmethod
    def log_info(self, msg: str) -> None:
        """Emit an informational message in the host's idiom."""

    @abstractmethod
    def log_warn(self, msg: str) -> None:
        """Emit a warning message in the host's idiom."""

    # --- concrete helpers shared by all hosts ---

    def get_relative_address(self, addr: int) -> str:
        """Return *addr*'s offset from the image base as a hex string."""
        return hex(addr - self.get_image_base())

    def _resolve_function_name(self, start: int, raw_name: str) -> str:
        """Return *raw_name*, or a ``sub_<offset>`` fallback when empty."""
        if raw_name:
            return raw_name
        relative_address = self.get_relative_address(start)
        return f"sub_{relative_address.removeprefix('0x')}"
```

`fridaforge/commands/base.py`:

```py
"""Base class for host-agnostic FridaForge commands."""

from abc import ABC, abstractmethod

from fridaforge.backend import Backend, ContextKind


class Command(ABC):
    """A single user-facing feature, independent of the host.

    Subclasses set the metadata class attributes and implement
    :meth:`run`, which pulls data from the *backend* and copies the
    generated snippet to the clipboard.
    """

    id: str
    description: str
    category: str
    hotkey: str | None = None
    context: ContextKind

    @abstractmethod
    def run(self, backend: Backend) -> None:
        """Execute the command against the given backend."""

    def _deliver(self, backend: Backend, snippet: str) -> None:
        """Copy the snippet to the clipboard and report the outcome."""
        if backend.copy_to_clipboard(snippet):
            backend.log_info("Frida snippet copied to clipboard.")
        else:
            backend.log_warn("Failed to copy snippet to clipboard.")
```

```py
from fridaforge.backend import Backend, ContextKind
from fridaforge.commands.base import Command
from fridaforge.core import DlopenHookGenerator


class DlopenHooksCommand(Command):
    id = "hook_dlopen_functions"
    description = "Generate dlopen hooks (Basic for Android native libs)"
    category = "Hooks"
    hotkey = "Shift+D"
    context = ContextKind.GLOBAL

            return

        snippet = DlopenHookGenerator().generate(module_name)
        self._deliver(backend, snippet)
```

`fridaforge/commands/modify_section_protection.py`:

```py
"""Command: generate a Frida section protection modification."""

from fridaforge.backend import Backend, ContextKind
from fridaforge.commands.base import Command
from fridaforge.core import ModifySectionProtectionGenerator


class ModifySectionProtectionCommand(Command):
    id = "modify_section_protection"
    description = "Modify current section permissions"
    category = "Memory"
    hotkey = "Shift+M"
    context = ContextKind.ADDRESS

    def run(self, backend: Backend) -> None:
        addr = backend.get_current_address()
        if addr is None:
            backend.log_warn("Could not determine the current address.")
            return

        section_name = backend.get_section_name_at(addr)
        if not section_name:
            backend.log_warn(
                f"Could not determine the containing section for {hex(addr)}."
            )
            return

        if not section_name.startswith("."):
            backend.log_warn(
                f"Address is not in a standard section. "
                f"(Section name: {section_name})"
            )
            return

        module_name = backend.get_module_name()
        snippet = ModifySectionProtectionGenerator().generate(
            module_name, section_name
        )
        self._deliver(backend, snippet)
```

```py
"""Command: negate an ARM64 conditional branch."""

from fridaforge.backend import Backend, ContextKind
from fridaforge.commands.base import Command
from fridaforge.core import NegateArm64CondBranchGenerator

ARM64_COND_BRANCHES = {
    "b.eq", "b.ne", "b.hs", "b.lo", "b.cs",
    "b.mi", "b.pl", "b.vs", "b.vc",
    "b.hi", "b.ls", "b.ge", "b.lt",
    "b.gt", "b.le", "tbz", "tbnz",
    "cbz", "cbnz",
}


class NegateArm64CondBranchCommand(Command):
    id = "negate_cond_branch_arm64"
    description = "Negate cond branch instruction (ARM64)"
    category = "Patching"
    hotkey = "Shift+A"
    context = ContextKind.ADDRESS

    def run(self, backend: Backend) -> None:
        addr = backend.get_current_address()
        if addr is None:
            backend.log_warn("Could not determine the current address.")
            return

        mnemonic = (backend.get_instruction_mnemonic(addr) or "").lower()
        if mnemonic not in ARM64_COND_BRANCHES:
            backend.log_warn(
                f"Instruction at {hex(addr)} ('{mnemonic}') "
                f"is not a recognized ARM64 conditional branch."
            )
            return

        module_name = backend.get_module_name()
        relative_address = backend.get_relative_address(addr)
        snippet = NegateArm64CondBranchGenerator().generate(
            module_name, relative_address
        )
        self._deliver(backend, snippet)
```

`fridaforge/core/__init__.py`:

```py
"""Base class for Frida snippet generators.

Every generator **must** subclass :class:`SnippetGenerator` and:

1. Set the ``template_filename`` class attribute to the name of a
   JavaScript template file located in the ``templates/`` directory.
2. Implement a ``generate()`` method with explicit, typed parameters
   that builds a placeholder mapping and delegates to :meth:`_render`.

Both constraints are validated at class-creation time; forgetting
either one raises :class:`TypeError` immediately.
"""

from collections.abc import Mapping

from fridaforge.core.utils import fill_template, read_template


class SnippetGenerator:
    """Abstract base for all Frida snippet generators."""

    template_filename: str

    def __init_subclass__(cls, **kwargs: object) -> None:
        super().__init_subclass__(**kwargs)

        if not getattr(cls, "template_filename", None):
            raise TypeError(
                f"{cls.__name__} must define 'template_filename' "
                f"as a non-empty class attribute."
            )

        if "generate" not in cls.__dict__:
            raise TypeError(
                f"{cls.__name__} must implement a 'generate()' method."
            )

    def _render(self, placeholders: Mapping[str, str | int]) -> str:
        """Read the template, substitute placeholders, and return the result."""
        template = read_template(self.template_filename)
        return fill_template(template, placeholders)


from fridaforge.core.hook_dlopen_functions import DlopenHookGenerator
from fridaforge.core.hook_function import FunctionHookGenerator
from fridaforge.core.modify_section_protection import (
    ModifySectionProtectionGenerator,

    NegateArm64CondBranchGenerator,
)
from fridaforge.core.negate_cond_branch_x86 import (

)

__all__ = [
    "SnippetGenerator",
    "DlopenHookGenerator",
    "FunctionHookGenerator",
```

```py
"""Template loading and placeholder substitution utilities."""

import os
from collections.abc import Mapping

TEMPLATES_DIR = os.path.join(
    os.path.dirname(os.path.abspath(__file__)), "..", "templates"
)


def read_template(template_filename: str) -> str:
    """Read a JavaScript template file from the templates directory.

    :param template_filename: The file name of the template
        (e.g. ``hook_function.js``).
    :return: The raw template content as a string.
    """
    filepath = os.path.join(TEMPLATES_DIR, template_filename)
    with open(filepath, "r", encoding="utf-8") as f:
        return f.read()


def fill_template(template: str, data_to_replace: Mapping[str, str | int]) -> str:
    """Replace ``[PLACEHOLDER]`` tokens in a template with actual values.

    :param template: The template string containing placeholders.
    :param data_to_replace: A mapping of placeholder names (without
        brackets) to their replacement values.
    :return: The filled template string.
    """
    for placeholder, value in data_to_replace.items():
        template = template.replace(f"[{placeholder}]", str(value))
    return template
```

```js
            const raw = targetAddr.readU32();
            let xorMask;
            if ((raw & 0xFF000010) === 0x54000000) {

            } else if ((raw & 0x7E000000) === 0x36000000) {

                xorMask = 1 << 24;     // cbz/cbnz: op in bit 24
            } else {
                console.log("[!] Unrecognized conditional branch encoding");
                return;

            code.writeU32(raw ^ xorMask);
```

```js
(function () {
    const moduleName = "[MODULE_NAME_PLACEHOLDER]"; 
    const condBranchRelAddr = "[RELATIVE_ADDRESS_PLACEHOLDER]";

    const module = Process.findModuleByName(moduleName);
    if (module != null) {
        const targetAddr = module.base.add(condBranchRelAddr);

        console.log(`[+] Negating conditional branch at ${targetAddr}`);
        console.log(`\tbefore: ${Instruction.parse(targetAddr)}`);

        let patchPtr;

        const firstByte = targetAddr.readU8();
        if (firstByte === 0x0F) {
            const secondByte = targetAddr.add(1).readU8();
            if ((secondByte & 0xF0) === 0x80) {
                patchPtr = targetAddr.add(1);
            }
        } else if ((firstByte & 0xF0) === 0x70) {
            patchPtr = targetAddr;
        }

        if (patchPtr) {
            Memory.patchCode(patchPtr, 1, code => {
                const raw = patchPtr.readU8();
                code.writeU8(raw ^ 1);
            })
        }

        console.log(`\tafter: ${Instruction.parse(targetAddr)}`);
    } else {
        console.log("[!] Failed to find module");
```

```py
    return f"{PLUGIN_MENU}\\{command.description}"

        )
    else:
        PluginCommand.register(
            path, command.description,
            lambda bv, c=command: c.run(BinjaBackend(bv)),
        )
```

```py
                 func: Function | None = None):
        self._bv = bv
        self._addr = addr
        self._func = func

    def get_module_name(self) -> str:
        return os.path.basename(self._bv.file.original_filename)

    def get_image_base(self) -> int:
        return self._bv.start

    def get_current_address(self) -> int | None:
        return self._addr

    def get_current_function(self) -> FunctionRef | None:
        if self._func is None:
            return None
        name = self._resolve_function_name(self._func.start, self._func.name)
        return FunctionRef(self._func.start, name)

    def get_section_name_at(self, addr: int) -> str | None:
        for name, section in self._bv.sections.items():
            if section.start <= addr < section.start + section.length:
                return name
        return None

    def get_instruction_mnemonic(self, addr: int) -> str | None:
        try:
            disasm = self._bv.get_disassembly(addr)
            if not disasm:
                return None
            return disasm.split()[0]
        except Exception:
            return None

    def copy_to_clipboard(self, text: str) -> bool:
        if not text:
            return False
        app = QApplication.instance()
        if app is None:
            return False
        clipboard = app.clipboard()
        if clipboard is None:
            return False
        clipboard.setText(text)
        return True

    def log_info(self, msg: str) -> None:
        log_info(f"[FridaForge] {msg}")

    def log_warn(self, msg: str) -> None:
        log_warn(f"[FridaForge] {msg}")
```

```py
"""IDA Pro plugin entry point for FridaForge."""

import os
import sys

import idaapi

# Ensure the parent of this plugin folder is on sys.path so that
# ``import fridaforge`` resolves (this file lives inside fridaforge/).
_plugin_dir = os.path.dirname(os.path.abspath(__file__))
_parent = os.path.dirname(_plugin_dir)
if _parent not in sys.path:
    sys.path.insert(0, _parent)

from fridaforge.backend_ida import IdaBackend
from fridaforge.commands import ALL_COMMANDS

TOP_MENU = "FridaForge"


class _CommandHandler(idaapi.action_handler_t):
    def __init__(self, command):
        super().__init__()
        self.command = command

    @property
    def action_name(self) -> str:
        return f"fridaforge:{type(self.command).__name__}"

    def activate(self, ctx):
        self.command.run(IdaBackend())
        return 1

    def update(self, ctx):
        if idaapi.get_widget_type(ctx.widget) not in (
            idaapi.BWN_DISASM,
            idaapi.BWN_PSEUDOCODE,
        ):
            return idaapi.AST_DISABLE_FOR_WIDGET
        path = TOP_MENU + "/"
        if self.command.category:
            path += self.command.category + "/"
        idaapi.attach_action_to_popup(ctx.widget, None, self.action_name, path)
        return idaapi.AST_ENABLE_FOR_WIDGET


class FridaForgePlugin(idaapi.plugin_t):
    flags = idaapi.PLUGIN_KEEP
    comment = "Generate Frida scripts from IDA Pro"
    help = "Right-click in Disassembly/Pseudocode to generate Frida snippets."
    wanted_name = "FridaForge"
    wanted_hotkey = ""

    def init(self):
        self._handlers = []
        for command in ALL_COMMANDS:
            handler = _CommandHandler(command)
            self._handlers.append(handler)
            idaapi.register_action(
                idaapi.action_desc_t(
                    handler.action_name,
                    command.description,
                    handler,
                    command.hotkey,
                )
            )
        return idaapi.PLUGIN_KEEP

    def run(self, arg):
        idaapi.msg("[FridaForge] Use right-click menus or hotkeys.\n")

    def term(self):
        for handler in self._handlers:
            idaapi.unregister_action(handler.action_name)
        self._handlers = []


def PLUGIN_ENTRY():
    return FridaForgePlugin()
```
