# AntiGuard — Anti-Cheat for Minecraft / SMP Servers

A **fully self-contained, single-jar anti-cheat plugin** for Paper/Purpur.
Drop one jar into `plugins/` and you get: real detection (Fly, Speed, Reach,
NoSwing), an embedded SQLite database for every flag/ban/kick, and an
embedded web dashboard + REST API to configure and monitor live. No external
services required.

> **Status: MVP verified.** Detection was proven live against a real Paper
> 1.20.4 server, and it plugs into the LuckPerms database. Now hosted
> on GitHub.

## What it does

- **Detection engine** — physics-based checks with research-backed, low-false-positive defaults.
- **Embedded database** — SQLite (`plugins/AntiGuard/data.db`), persists flags/bans/kicks across restarts.
- **Embedded web UI + API** — dashboard at `http://127.0.0.1:8080/`, live config + data views.

# AntiGuard Agent — per-server reporting client

The agent runs on each Minecraft/SMP server and pushes cheat flags and
ban evidence to the central AntiGuard API. This keeps any reporting logic
off the central service (agents can be updated independently of the panel).

## Protocol

`base_url` is the central API origin (prod: `https://api.antiguard.io`).
Callers send the server's API key in the header:

```
Authorization: Bearer ag_live_<key>
```

### POST /events
Body (JSON): `player_name`, `player_uuid`, `flag_type`, `level`,
`detail`, `position`.

### GET /bans   |   POST /bans   |   PATCH /bans/{id}   |   DELETE /bans/{id}

### POST /bans/{id}/evidence
Evidence snapshots (inventory, metrics, replay frame) as a JSON object.

## Reference agent (Python)

A minimal `urllib`-based reporter (no third-party deps) is included at
`agent/reference.py`. It reads config from env and can POST a flag:

```bash
export ANTIGUARD_URL=http://localhost:8000
export ANTIGUARD_KEY=ag_live_<key-you-minted>
python3 agent/reference.py --flag-type killaura --player Notch --detail "angle snap 47.2deg"
```

## Plugin implementations (future)

Because we run Purpur/BedWars1058, the first-class agent is a **Bukkit**
plugin (`antiguard-bukkit`) that listens to your existing anti-cheat
(Vulcan, etc.) events and forwards flags + evidence. A BepInEx/MC Java
variant can reuse the same HTTP protocol.

## Reliability requirements for the agent

- **Queue + retry:** buffer flags; retry on 5xx/network errors with
  exponential backoff. Never drop evidence on a blip.
- **Rate-aware:** respect 429 responses, back off accordingly.
- **Fire-and-forget:** never block the game thread; send async.
- **Key rotation:** if the server returns 401, pause and alert the owner
  (key may have been rotated after a leak).
- **Minimal footprint:** batch events into one HTTP call when possible.
```

`agent/reference.py`:

```py
#!/usr/bin/env python3
"""Reference AntiGuard agent: report cheat flags to the central API.

Minimal, stdlib-only (no third-party deps). Reads config from env.

Usage:
    export ANTIGUARD_URL=http://localhost:8000
    export ANTIGUARD_KEY=ag_live_<key>
    python3 reference.py --flag-type killaura --player Notch \
        --detail "angle snap 47.2deg" --level critical

Exit codes: 0 = reported, 1 = config error, 2 = HTTP/report error.
"""
import argparse
import json
import os
import sys
import urllib.error
import urllib.request


def _env(name: str, required: bool = True) -> str:
    val = os.environ.get(name, "")
    if required and not val:
        print(f"error: missing env {name}", file=sys.stderr)
        sys.exit(1)
    return val


def post(base: str, key: str, path: str, payload: dict) -> dict:
    url = base.rstrip("/") + path
    data = json.dumps(payload).encode("utf-8")
    req = urllib.request.Request(
        url,
        data=data,
        headers={
            "Content-Type": "application/json",
            "Authorization": f"Bearer {key}",
        },
        method="POST",
    )
    try:
        with urllib.request.urlopen(req, timeout=10) as resp:
            body = resp.read().decode("utf-8")
            return {"status": resp.status, "body": json.loads(body) if body else {}}
    except urllib.error.HTTPError as e:
        return {"status": e.code, "body": e.read().decode("utf-8", "replace")}
    except urllib.error.URLError as e:
        return {"status": 0, "body": {"error": str(e.reason)}}


def main() -> int:
    parser = argparse.ArgumentParser(description="Report a cheat flag to AntiGuard.")
    parser.add_argument("--flag-type", required=True)
    parser.add_argument("--player", required=True)
    parser.add_argument("--player-uuid", default="")
    parser.add_argument("--level", default="info", choices=["info", "warning", "critical"])
    parser.add_argument("--detail", default="")
    parser.add_argument("--position", default="")
    args = parser.parse_args()

    base = _env("ANTIGUARD_URL")
    key = _env("ANTIGUARD_KEY")

    payload = {
        "player_name": args.player,
        "player_uuid": args.player_uuid,
        "flag_type": args.flag_type,
        "level": args.level,
        "detail": args.detail,
        "position": args.position,
    }
    result = post(base, key, "/events", payload)
    if result["status"] not in (200, 201):
        print(f"report failed: HTTP {result['status']} -> {result['body']}", file=sys.stderr)
        return 2
    print(f"reported {payload['flag_type']} for {payload['player_name']}: HTTP {result['status']}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

# AntiGuard Bukkit — Install & Configure

**AntiGuard is a fully self-contained, single-jar anti-cheat** for Paper/Purpur
1.20.x (Java 17). One drop-in jar includes:

- **Detection engine** — Fly, Speed, Reach, NoSwing, KillAura, AutoClick, NoFall, FastBreak
- **Plugs into the LuckPerms database** — flags/bans/kicks are stored as
  `antiguard_*` tables inside the same database LuckPerms uses (no new DB).
- **Embedded web dashboard + REST API** — configure detection live, view flags/bans/kicks
- No external API service, no database server, no extra dependencies.

## 1. Install (takes 30 seconds)

1. Copy the jar into your server's `plugins/` folder:
   ```bash
   cp release/AntiGuard-0.1.0.jar /path/to/server/plugins/
   ```
2. Restart the server. AntiGuard reads LuckPerms' config automatically:
   ```
   [AntiGuard] AntiGuard plugged into LuckPerms database: SQLITE
   [AntiGuard] AntiGuard web UI listening on http://127.0.0.1:8080
   ```
3. Open the dashboard: **http://127.0.0.1:8080/**
   - Stats (flags/bans/kicks), live flags table, bans, kicks
   - Live detection sliders — change values and hit **Save**, they persist
     to the database immediately (no restart).

## 2. Database: plugs into LuckPerms

By default (`database.type: auto`) AntiGuard opens the **same database
LuckPerms uses** — it reads `plugins/LuckPerms/config.yml`, detects
`storage-method` (h2 / sqlite / mysql / mariadb / postgresql), and connects
to that backend with the same credentials. It only adds its own tables under
a prefix so it never touches LuckPerms' data:

```
luckperms_user_permissions   <-- LuckPerms' own tables
luckperms_groups
antiguard_flags              <-- AntiGuard's tables (same DB)
antiguard_bans
antiguard_kicks
antiguard_settings
```

To point it elsewhere instead, edit `plugins/AntiGuard/config.yml`:

```yaml
database:
  type: "auto"          # auto | sqlite | h2 | mysql | mariadb | postgresql
  table-prefix: "antiguard_"
  host: "localhost"     # for remote backends
  database: "minecraft"
  username: "root"
  password: ""
  file: ""              # e.g. plugins/AntiGuard/data.db for type: sqlite
```

If no LuckPerms config is found (or it's a file-type AntiGuard can't
reuse safely), AntiGuard falls back to its own bundled SQLite file — so it
never fails to start.

## 3. Detection

Backed by researched, field-tested methods:

| Check | Signal | Method |
|-------|--------|--------|
| Fly | impossible upward velocity | jump bound + Vulcan headroom |
| Speed | horizontal b/s over effect-scaled max | IceLater / AzAntiCheat |
| Reach | melee hits beyond 3.2 blocks | Hydro 3.001 / ReducedX 3.2 |
| KillAura | hits far from crosshair + multi-target rate | rotation/angle analysis (ReducedX/MX) |
| AutoClick | high CPS *and* stable intervals | CPS are not enough alone — check interval stddev (FairPlay) |
| NoSwing | hits with no arm animation | animation packet tracking |
| NoFall | big fall, no fall damage | fall-distance vs damage comparison |
| FastBreak | block breaks implausibly fast | dig-start → break time window |

Enable/disable each check from `config.yml` under `detection.*` or via the
dashboard. Defaults are conservative to avoid false positives; raise
`vl-to-flag` or per-check tolerances if a legit player gets flagged.

## 4. Admin commands

| Command | Effect |
|---------|--------|
| `/antiguard info` | show DB backend, checks, web UI URL |
| `/antiguard reload` | reload `config.yml` |
| `/antiguard alerts` | show alert status |

Permissions: `antiguard.admin` (commands), `antiguard.alerts` (alerts).

## 5. REST API

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/stats` | flag/ban/kick counts |
| GET | `/api/flags?limit=&player=&check=` | recorded flags |
| GET | `/api/bans?status=` | bans |
| GET | `/api/kicks?limit=` | kicks |
| GET | `/api/config` | current live config |
| POST | `/api/config` | update detection values (JSON) |
| POST | `/api/bans/{id}/status` | lift/appeal a ban |

Write operations require `X-Api-Token: <web.token>` if `web.token` is set.

## 6. Verification (this build was tested)

Tested against a real Paper 1.20.4 + LuckPerms (SQLite) locally:
- AntiGuard detected LuckPerms' DB and created `antiguard_*` tables inside it.
- A headless client driving a real fly hack (smooth +0.90 b/t ascent) was
  flagged live; the flag persisted into LuckPerms' SQLite file and appeared
  in `/api/flags`.

package io.antiguard;

import io.antiguard.check.CheckManager;
import io.antiguard.commands.AntiGuardCommand;
import io.antiguard.config.PluginConfig;
import io.antiguard.action.ActionHandler;
import io.antiguard.db.ConnectionFactory;
import io.antiguard.db.Database;
import io.antiguard.web.WebServer;
import org.bukkit.plugin.java.JavaPlugin;

/**
 * AntiGuard Bukkit agent — fully self-contained.
 *
 * <p>Everything runs inside a single drop-in jar: detection checks, an
 * embedded SQLite database (flags / bans / kicks), and an embedded web
 * UI + REST API for live configuration. No external services required.</p>
 */
public final class AntiGuardPlugin extends JavaPlugin {

    private PluginConfig configStore;
    private Database database;
    private CheckManager checkManager;
    private ActionHandler actionHandler;
    private WebServer webServer;

    private int sweepTask = -1;

    @Override
    public void onEnable() {
        saveDefaultConfig();
        this.configStore = new PluginConfig(this);

        // Persistent storage — plugs into the LuckPerms database by default.
        try {
            this.database = new Database(this, ConnectionFactory.resolve(this, configStore, "data.db"));
            configStore.attach(database);
            getLogger().info("AntiGuard database ready (" + database.typeLabel() + ")");
        } catch (Exception e) {
            getLogger().severe("Could not open AntiGuard database: " + e.getMessage());
            getServer().getPluginManager().disablePlugin(this);
            return;
        }

        this.actionHandler = new ActionHandler(this, database);
        this.checkManager = new CheckManager(this, configStore, actionHandler);
        this.checkManager.enable();

        // Start the embedded web dashboard + REST API.
        if (configStore.webEnabled()) {
            this.webServer = new WebServer(this, database);
            try {
                webServer.start();
            } catch (Exception e) {
                getLogger().warning("Could not start web UI on " + configStore.webHost() + ":" + configStore.webPort()
                        + " — " + e.getMessage() + " (fix web.port in config.yml)");
            }
        }

        AntiGuardCommand cmd = new AntiGuardCommand(this);
        if (getCommand("antiguard") != null) {
            getCommand("antiguard").setExecutor(cmd);
            getCommand("antiguard").setTabCompleter(cmd);
        }

        // Periodic VL decay so brief spikes don't accumulate into a ban.
        sweepTask = getServer().getScheduler()
                .runTaskTimer(this, () -> actionHandler.sweep(), 20L * 60L, 20L * 60L).getTaskId();

        getLogger().info("AntiGuard agent enabled. "
                + (configStore.webEnabled() ? "Web UI: http://" + configStore.webHost() + ":" + configStore.webPort() : "no web UI"));
    }

    @Override
    public void onDisable() {
        if (sweepTask != -1) getServer().getScheduler().cancelTask(sweepTask);
        if (checkManager != null) checkManager.disable();
        if (webServer != null) webServer.stop();
        if (database != null) database.close();
        getLogger().info("AntiGuard agent disabled.");
    }

    public PluginConfig configStore() { return configStore; }
    public Database database() { return database; }
    public CheckManager checkManager() { return checkManager; }
    public ActionHandler actionHandler() { return actionHandler; }
    public WebServer webServer() { return webServer; }
}

`plugin/src/main/java/io/antiguard/action/ActionHandler.java`:

```java
package io.antiguard.action;

import io.antiguard.AntiGuardPlugin;
import io.antiguard.config.PluginConfig;
import io.antiguard.db.Database;
import org.bukkit.Bukkit;
import org.bukkit.ChatColor;
import org.bukkit.entity.Player;

import java.util.Map;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

/**
 * Central point for handling a positive detection.
 *
 * <p>Each check calls {@link #flag}. This class:
 *  <ol>
 *    <li>increments the player's violation count for that check,</li>
 *    <li>when VL reaches {@code vl-to-flag}, treats it as a confirmed flag:
 *        persists it to the SQLite database, broadcasts an alert, and
 *        optionally kicks/bans (each also recorded to the DB),</li>
 *    <li>decays stale VL so brief spikes don't accumulate into a ban.</li>
 *  </ol></p>
 */
public final class ActionHandler {

    private final AntiGuardPlugin plugin;
    private final Database db;
    private final PluginConfig cfg;

    private final Map<UUID, Map<String, Integer>> violations = new ConcurrentHashMap<>();

    public ActionHandler(AntiGuardPlugin plugin, Database db) {
        this.plugin = plugin;
        this.db = db;
        this.cfg = plugin.configStore();
    }

    /**
     * A check detected a violation.
     *
     * @param player the offending player
     * @param check  check name, e.g. "Fly", "Speed", "Reach"
     * @param level  "info" | "warning" | "critical"
     * @param detail human-readable detail captured for evidence
     */
    public void flag(Player player, String check, String level, String detail) {
        int vl = violations
                .computeIfAbsent(player.getUniqueId(), k -> new ConcurrentHashMap<>())
                .merge(check, 1, Integer::sum);

        if (vl >= cfg.vlToFlag()) {
            violations.get(player.getUniqueId()).put(check, 0); // reset this check's VL after confirming
            onConfirmedFlag(player, check, level, detail);
        }
    }

    private void onConfirmedFlag(Player player, String check, String level, String detail) {
        String world = "";
        try { world = player.getLocation().getWorld().getName(); } catch (Exception ignored) { }

        // Persist the flag to the database (this is the primary record).
        db.addFlag(player.getName(), player.getUniqueId().toString(), check, level, detail, world);

        if (cfg.alertsEnabled()) {
            String msg = ChatColor.translateAlternateColorCodes('&',
                    cfg.alertPrefix() + "&c" + player.getName()
                            + " &7flagged &f" + check
                            + " &7(" + level + ")" + " &7— " + detail);
            for (Player p : Bukkit.getOnlinePlayers()) {
                if (p.hasPermission("antiguard.alerts")) p.sendMessage(msg);
            }
            plugin.getLogger().info(ChatColor.stripColor(msg));
        }

        // Auto-punish once the flag-count threshold is reached within a window.
        int autoBanAfter = cfg.autoBanAfterFlags();
        if (autoBanAfter > 0 && confirmedInWindow(player.getUniqueId(), autoBanAfter, 120_000L)) {
            punish(player, check);
        }
    }

    /** Rolling window of confirmed-flag timestamps per player. */
    private final Map<UUID, java.util.ArrayDeque<Long>> flagTimes = new ConcurrentHashMap<>();

    /** Record the timestamp and check whether >= threshold flags occurred in windowMs. */
    private boolean confirmedInWindow(UUID uuid, int threshold, long windowMs) {
        long now = System.currentTimeMillis();
        var q = flagTimes.computeIfAbsent(uuid, k -> new java.util.ArrayDeque<>());
        synchronized (q) {
            while (!q.isEmpty() && now - q.peekFirst() > windowMs) q.pollFirst();
            q.addLast(now);
            return q.size() >= threshold;
        }
    }

    private void punish(Player player, String check) {
        String reason = ChatColor.translateAlternateColorCodes('&', cfg.punishReason()
                .replace("%player%", player.getName())
                .replace("%check%", check));

        String action = cfg.autoAction().toLowerCase();
        plugin.getLogger().warning("AntiGuard " + action + " " + player.getName() + " (" + check + ")");
        UUID uuid = player.getUniqueId();
        Bukkit.getScheduler().runTask(plugin, () -> {
            switch (action) {
                case "kick" -> {
                    player.kickPlayer(reason);
                    db.addKick(player.getName(), uuid.toString(), check, reason);
                }
                case "ban" -> {
                    player.kickPlayer(reason);
                    Bukkit.getBanList(org.bukkit.BanList.Type.NAME).addBan(player.getName(), reason, null, "AntiGuard");
                    db.addBan(player.getName(), uuid.toString(), check, reason, "active");
                }
                default -> { /* misconfigured; alert already sent */ }
            }
        });
    }

    /** Called on a fixed schedule to decay stale violation counts. */
    public void sweep() {
        long now = System.currentTimeMillis();
        for (UUID uuid : violations.keySet()) {
            Player p = Bukkit.getPlayer(uuid);
            if (p == null || !p.isOnline()) continue; // sweep handles offline
            // Reset violation counters periodically so traffic-driven spikes decay.
            for (String check : violations.get(uuid).keySet()) {
                violations.get(uuid).put(check, 0);
            }
        }
    }

    /** Reverse an active ban by UUID (from the web UI). */
    public void liftBan(String uuid) {
        db.updateBanStatus(Long.parseLong(uuid), "lifted");
        // also remove from the Bukkit ban list if present
        try {
            Bukkit.getBanList(org.bukkit.BanList.Type.NAME).pardon(String.valueOf(uuid));
        } catch (Exception ignored) { }
    }
}

package io.antiguard.check;

import io.antiguard.action.ActionHandler;
import io.antiguard.config.PluginConfig;
import org.bukkit.GameMode;
import org.bukkit.Material;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.EventPriority;
import org.bukkit.event.block.Action;
import org.bukkit.event.player.PlayerInteractEvent;
import org.bukkit.inventory.EquipmentSlot;

import java.util.ArrayDeque;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

/**
 * AutoClick check — flags inhuman click patterns.
 *
 * <p>Research (FairPlay, IceLater) is clear: <b>CPS alone is not enough</b>.
 * This check combines:
 *  <ul>
 *    <li><b>CPS</b> — clicks per second over a configurable cap
 *        (default 16; humans rarely exceed ~12-14 sustained).</li>
 *    <li><b>Interval stability</b> — the standard deviation of click
 *        intervals. A real human has noisy intervals; an autoclicker is
 *        artificially regular. We flag when CPS is high AND the intervals
 *        are suspiciously consistent.</li>
 *  </ul>
 */
public final class AutoClickCheck implements Check {

    private final PluginConfig cfg;
    private final ActionHandler actionHandler;

    private final ConcurrentHashMap<UUID, ArrayDeque<Long>> clicks = new ConcurrentHashMap<>();

    // Defaults (overridable via config later).
    private static final double MAX_CPS = 16.0;
    private static final long CPS_WINDOW_MS = 1000;
    private static final double MAX_STABILITY = 25.0; // max stddev of intervals (ms)

    public AutoClickCheck(CheckManager manager, PluginConfig cfg, ActionHandler actionHandler) {
        this.cfg = cfg;
        this.actionHandler = actionHandler;
    }

    @Override public String name() { return "AutoClick"; }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onClick(PlayerInteractEvent e) {
        if (e.getAction() != Action.LEFT_CLICK_AIR && e.getAction() != Action.LEFT_CLICK_BLOCK) return;
        if (e.getHand() != EquipmentSlot.HAND) return;
        Player p = e.getPlayer();
        if (p.getGameMode() == GameMode.CREATIVE || p.getGameMode() == GameMode.SPECTATOR) return;

        // Ignore interactions that are really block placement/use, not clicks.
        if (e.getAction() == Action.LEFT_CLICK_BLOCK && (e.getItem() == null
                || !e.getItem().getType().isItem() || e.getItem().getType() == Material.AIR)) return;

        long now = System.nanoTime();
        var q = clicks.computeIfAbsent(p.getUniqueId(), k -> new ArrayDeque<>());
        q.addLast(now);
        long cutoff = now - CPS_WINDOW_MS * 1_000_000L;
        while (!q.isEmpty() && q.peekFirst() < cutoff) q.pollFirst();

        int size = q.size();
        if (size < 8) return; // need enough samples to be meaningful

        double cps = size * 1000.0 / CPS_WINDOW_MS;
        if (cps < MAX_CPS) return;

        // Interval standard deviation (ms).
        long[] arr = new long[q.size()];
        int idx = 0;
        long prev = 0; boolean first = true;
        double sum = 0, n = 0;
        for (long t : q) {
            if (!first) {
                double iv = (t - prev) / 1_000_000.0;
                sum += iv; n++;
            }
            prev = t; first = false;
        }
        double mean = n == 0 ? 0 : sum / n;
        double var = 0;
        prev = 0; first = true;
        for (long t : q) {
            if (!first) {
                double iv = (t - prev) / 1_000_000.0;
                var += (iv - mean) * (iv - mean);
            }
            prev = t; first = false;
        }
        double stddev = n == 0 ? 0 : Math.sqrt(var / n);

        if (stddev < MAX_STABILITY) {
            log(actionHandler, p, "warning",
                    String.format("cps=%.1f intervals stable stddev=%.0fms", cps, stddev));
        }
    }
}

public final class CheckManager implements Listener {

    private final AntiGuardPlugin plugin;
    private final PluginConfig cfg;
    private final ActionHandler actionHandler;

    private final Map<UUID, PlayerData> data = new ConcurrentHashMap<>();
    private final java.util.List<Check> checks = new java.util.ArrayList<>();

    public CheckManager(AntiGuardPlugin plugin, PluginConfig cfg, ActionHandler actionHandler) {
        this.plugin = plugin;
        this.cfg = cfg;
        this.actionHandler = actionHandler;
    }

    public void enable() {
        plugin.getServer().getPluginManager().registerEvents(this, plugin);

        checks.clear();
        checks.add(new FlyCheck(this, cfg, actionHandler));
        checks.add(new SpeedCheck(this, cfg, actionHandler));
        checks.add(new ReachCheck(this, cfg, actionHandler));
        if (cfg.noSwingEnabled()) checks.add(new NoSwingCheck(this, cfg, actionHandler));
        if (cfg.killAuraEnabled()) checks.add(new KillAuraCheck(this, cfg, actionHandler));
        if (cfg.autoClickEnabled()) checks.add(new AutoClickCheck(this, cfg, actionHandler));
        if (cfg.noFallEnabled()) checks.add(new NoFallCheck(this, cfg, actionHandler));
        if (cfg.fastBreakEnabled()) checks.add(new FastBreakCheck(this, cfg, actionHandler));

        for (Check c : checks) {
            plugin.getServer().getPluginManager().registerEvents(c, plugin);
        }

        // Every 5 minutes, sweep stale (already-reset) player data safely.
        sweepTask = Bukkit.getScheduler().runTaskTimerAsynchronously(plugin, this::sweep, 20L * 60L * 5L, 20L * 60L * 5L).getTaskId();
    }

    public void disable() {
        if (sweepTask != -1) {
            Bukkit.getScheduler().cancelTask(sweepTask);
        }
        for (Check c : checks) c.disable();
    }

    public PlayerData data(UUID uuid) {
        return data.get(uuid);
    }

    public PlayerData data(Player p) {
        return data.computeIfAbsent(p.getUniqueId(), u -> new PlayerData(u, p.getName()));
    }

    @EventHandler(priority = EventPriority.LOWEST)
    public void onJoin(PlayerJoinEvent e) {
        data.put(e.getPlayer().getUniqueId(), new PlayerData(e.getPlayer().getUniqueId(), e.getPlayer().getName()));
    }

    @EventHandler
    public void onQuit(PlayerQuitEvent e) {
        data.remove(e.getPlayer().getUniqueId());
    }

    private void sweep() {
        data.entrySet().removeIf(en -> {
            UUID uuid = en.getKey();
            Player p = Bukkit.getPlayer(uuid);
            return p == null || !p.isOnline();
        });
    }
}

 * it actually breaks is far shorter than the block's hardness × tool/efficiency

    // Real clients take at least ~1 tick (50ms) plus hardness; anything well
    // under this for a normal-dig is fast-break territory.
    private static final long MIN_BREAK_MS = 30;

    private record DigStart(long time, org.bukkit.block.Block block) {}

    public FastBreakCheck(CheckManager manager, PluginConfig cfg, ActionHandler actionHandler) {
        this.cfg = cfg;
        this.actionHandler = actionHandler;

    @Override public String name() { return "FastBreak"; }

    @EventHandler(priority = EventPriority.LOWEST)
    public void onDig(BlockDamageEvent e) {
        if (e.isCancelled()) return;
        digs.put(e.getPlayer().getUniqueId(), new DigStart(System.currentTimeMillis(), e.getBlock()));
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onBreak(org.bukkit.event.block.BlockBreakEvent e) {
        Player p = e.getPlayer();
        DigStart ds = digs.remove(p.getUniqueId());
        if (ds == null) return;

        long dt = System.currentTimeMillis() - ds.time();
        if (dt < MIN_BREAK_MS && dt >= 0) {
            log(actionHandler, p, "warning",
                    String.format("broke %s in %dms", ds.block().getType().name(), dt));
        }
    }

 *    <li>sustained upward climb without a jump/water source.</li>

    private final PluginConfig cfg;

        this.cfg = cfg;

package io.antiguard.check;

import io.antiguard.action.ActionHandler;
import io.antiguard.config.PluginConfig;
import org.bukkit.GameMode;
import org.bukkit.Location;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.EventPriority;
import org.bukkit.event.entity.EntityDamageByEntityEvent;
import org.bukkit.util.Vector;

import java.util.ArrayDeque;
import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

/**
 * KillAura check — flags combat that a legitimate player cannot produce.
 *
 * <p>Two signals (research: ReducedX / MX use rotation analysis; Hydro-style
 * bases use attack-rate windows):</p>
 *  <ul>
 *    <li><b>Angle</b>: a player can only attack what their view direction
 *        points reasonably toward. Hitting a target far from the crosshair
 *        (cone validation) is a kill-aura tell.</li>
 *    <li><b>Multi-target rate</b>: hitting several distinct victims inside a
 *        very short window is a byproduct of aura clients locking onto / bpassing
 *        everyone nearby.</li>
 *  </ul>
 *
 * <p>Kept conservative to avoid false positives on fast PvP.</p>
 */
public final class KillAuraCheck implements Check {

    private final PluginConfig cfg;
    private final ActionHandler actionHandler;

    // How far (degrees) the victim can be from the attacker's crosshair.
    // Kept conservative; see config.yml (detection.killaura.max-angle).
    // (read dynamically from config, so no static constant needed)
    // Distinct victims hit within this window (ms) is suspicious.
    private static final long MULTI_WINDOW_MS = 500;
    private static final int MULTI_TARGETS = 3;

    // per-player: timestamp -> victim each attack
    private final ConcurrentHashMap<UUID, ArrayDeque<Hit>> hitLog = new ConcurrentHashMap<>();

    private record Hit(long time, String target) {}

    public KillAuraCheck(CheckManager manager, PluginConfig cfg, ActionHandler actionHandler) {
        this.cfg = cfg;
        this.actionHandler = actionHandler;
    }

    @Override public String name() { return "KillAura"; }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onDamage(EntityDamageByEntityEvent e) {
        if (!(e.getDamager() instanceof Player attacker)) return;
        if (!(e.getEntity() instanceof Player victim)) return;
        if (attacker.getGameMode() == GameMode.CREATIVE || attacker.getGameMode() == GameMode.SPECTATOR) return;

        long now = System.currentTimeMillis();

        // --- Angle check (repeated off-crosshair hits) ---
        double angle = angleTo(attacker, victim);
        if (angle > cfg.killAuraMaxAngle()) {
            UUID id = attacker.getUniqueId();
            var stamps = hitLog.computeIfAbsent(id, k -> new ArrayDeque<>());
            stamps.addLast(new Hit(now, victim.getName()));
            prune(stamps, now, 2000);
            int nearMiss = 0;
            for (Hit h : stamps) { if (System.currentTimeMillis() - h.time() <= 2000) nearMiss++; }
            if (nearMiss >= 3) {
                log(actionHandler, attacker, "critical",
                        String.format("hit angle %.0f° (target=%s)", angle, victim.getName()));
                stamps.clear();
            }
        }

        // --- Multi-target rate ---
        UUID id = attacker.getUniqueId();
        var log = hitLog.computeIfAbsent(id, k -> new ArrayDeque<>());
        log.addLast(new Hit(now, victim.getName()));
        prune(log, now, MULTI_WINDOW_MS);
        int distinct = 0;
        var seen = new java.util.HashSet<String>();
        for (Hit h : log) if (seen.add(h.target())) distinct++;
        if (distinct >= MULTI_TARGETS) {
            log(actionHandler, attacker, "warning",
                    String.format("hit %d distinct targets in %dms", distinct, MULTI_WINDOW_MS));
            log.clear();
        }
    }

    private void prune(ArrayDeque<Hit> q, long now, long window) {
        while (!q.isEmpty() && now - q.peekFirst().time() > window) q.pollFirst();
    }

    private double angleTo(Player attacker, Player victim) {
        Location aLoc = attacker.getLocation();
        Vector look = aLoc.getDirection();
        Vector toVictim = victim.getLocation().add(0, victim.getHeight() / 2.0, 0).toVector()
                .subtract(aLoc.toVector().add(new Vector(0, 1.6, 0)));
        if (toVictim.lengthSquared() < 0.0001) return 0;
        double dot = look.normalize().dot(toVictim.normalize());
        return Math.toDegrees(Math.acos(Math.max(-1, Math.min(1, dot))));
    }
}

package io.antiguard.check;

import io.antiguard.action.ActionHandler;
import io.antiguard.config.PluginConfig;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.EventPriority;
import org.bukkit.event.entity.EntityDamageEvent;
import org.bukkit.event.player.PlayerMoveEvent;

import java.util.UUID;
import java.util.concurrent.ConcurrentHashMap;

/**
 * NoFall check — flags players avoiding fall damage while still moving as if
 * falling.
 *
 * <p>Signal: a player obtains a large fall distance (indicating they were
 * falling fast) but then lands with zero fall damage. Legit fall damage
 * is guaranteed beyond ~3 blocks, so a big fall that deals no damage while
 * no water/ladder/elytra/feather-falling explains it is a NoFall cheat.</p>
 *
 * <p>We track max fall distance per player from movement, then compare it
 * against the fall damage actually dealt on landing.</p>
 */
public final class NoFallCheck implements Check {

    private final PluginConfig cfg;
    private final ActionHandler actionHandler;
    private final ConcurrentHashMap<UUID, Double> fallDistance = new ConcurrentHashMap<>();

    public NoFallCheck(CheckManager manager, PluginConfig cfg, ActionHandler actionHandler) {
        this.cfg = cfg;
        this.actionHandler = actionHandler;
    }

    @Override public String name() { return "NoFall"; }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onMove(PlayerMoveEvent e) {
        Player p = e.getPlayer();
        // Only meaningful while the player is airborne / not safe from fall.
        if (p.isOnGround() || p.isInWater() || p.isInLava() || p.isGliding()
                || p.isInsideVehicle() || p.hasPermission("antiguard.bypass.nofall")) {
            fallDistance.remove(p.getUniqueId());
            return;
        }
        // Track accumulated fall distance.
        fallDistance.merge(p.getUniqueId(), 0.0, (a, b) ->
                (e.getTo().getY() < e.getFrom().getY())
                        ? a + (e.getFrom().getY() - e.getTo().getY())
                        : a);
    }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onFallDamage(EntityDamageEvent e) {
        if (!(e.getEntity() instanceof Player p)) return;
        if (e.getCause() != EntityDamageEvent.DamageCause.FALL) return;
        Double dist = fallDistance.remove(p.getUniqueId());
        if (dist == null) return;

        double damage = e.getFinalDamage();
        // Feather Falling reduces damage; allow a window.
        double expected = expectedFallDamage(dist);
        boolean safe = p.isInWater() || p.isInLava() || p.isGliding();
        if (!safe && damage < expected * 0.3 && dist > 3) {
            log(actionHandler, p, "warning",
                    String.format("fell %.1f blocks took %.1f dmg (expected ~%.1f)", dist, damage, expected));
        }
    }

    private double expectedFallDamage(double blocks) {
        // Vanilla: damage = blocks - 3, roughly.
        return Math.max(0, blocks - 3.0);
    }
}

package io.antiguard.check;

import org.bukkit.Location;

import java.util.UUID;

/**
 * Per-player state used by the movement & reach checks.
 *
 * One instance per online player. Holds the data a check needs across
 * ticks: current/previous locations, violation counts, and timestamps.
 */
public final class PlayerData {

    private final UUID uuid;
    private final String name;

    private Location current;
    private Location previous;
    private long lastMoveTick = -1;
    private long lastSwingNanos = 0;
    private long lastViolationNanos = 0;

    /** Sum of upward movement (blocks) to catch sustained climbing. */
    private double accumulatedUp = 0.0;

    public PlayerData(UUID uuid, String name) {
        this.uuid = uuid;
        this.name = name;
    }

    public UUID uuid() { return uuid; }
    public String name() { return name; }

    public Location current() { return current; }
    public Location previous() { return previous; }

    public void onMove(Location to) {
        this.previous = this.current;
        this.current = to.clone();
        this.lastMoveTick = System.currentTimeMillis();
    }

    public long lastMoveTime() { return lastMoveTick; }

    public void registerSwing() { this.lastSwingNanos = System.nanoTime(); }
    public long lastSwingNanos() { return lastSwingNanos; }

    public long lastViolationNanos() { return lastViolationNanos; }
    public void setLastViolationNanos(long nanos) { this.lastViolationNanos = nanos; }

    public double accumulatedUp() { return accumulatedUp; }
    public void setAccumulatedUp(double v) { this.accumulatedUp = v; }

    /** Horizontal distance between the two most recent locations, in blocks. */
    public double horizontalSpeed() {
        if (current == null || previous == null) return 0.0;
        double dx = current.getX() - previous.getX();
        double dz = current.getZ() - previous.getZ();
        return Math.hypot(dx, dz);
    }

    /** Vertical delta between the two most recent locations (>0 = up). */
    public double dx() {
        if (current == null || previous == null) return 0.0;
        return current.getY() - previous.getY();
    }

import io.antiguard.action.ActionHandler;
import io.antiguard.config.PluginConfig;
import org.bukkit.GameMode;
import org.bukkit.Location;

import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.EventPriority;
import org.bukkit.event.entity.EntityDamageByEntityEvent;

/**
 * Reach check — flags melee hits from further than a player can legitimately
 * attack. Vanilla survival reach is 3.0 blocks; a tiny epsilon is allowed.
 * Creative range (5.0) and projectiles are excluded.
 */
public final class ReachCheck implements Check {

    private final PluginConfig cfg;
    private final ActionHandler actionHandler;

    public ReachCheck(CheckManager manager, PluginConfig cfg, ActionHandler actionHandler) {
        this.cfg = cfg;
        this.actionHandler = actionHandler;
    }

    @Override public String name() { return "Reach"; }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onDamage(EntityDamageByEntityEvent e) {
        if (!(e.getDamager() instanceof Player attacker)) return;
        if (!(e.getEntity() instanceof Player victim)) return;

        if (attacker.getGameMode() == GameMode.CREATIVE) return;
        if (attacker.isGliding() || attacker.isInsideVehicle()) return;

        double maxReach = cfg.reachMax();
        double dist = distance3D(attacker.getLocation(),
                victim.getLocation().add(0, victim.getHeight() / 2.0, 0)) - entityRadius(victim);

        if (dist > maxReach) {
            log(actionHandler, attacker, "critical",
                    String.format("hit %.2f > %.2f (victim %s)", dist, maxReach, victim.getName()));
        }
    }

    private double distance3D(Location a, Location b) {
        if (a.getWorld() == null || !a.getWorld().equals(b.getWorld())) return Double.MAX_VALUE;
        double dx = a.getX() - b.getX();
        double dy = a.getY() - b.getY();
        double dz = a.getZ() - b.getZ();
        return Math.sqrt(dx * dx + dy * dy + dz * dz);
    }

    private double entityRadius(Entity e) {
        // Approximate the victim's hitbox radius so standing a bit "over the
        // block" edge doesn't false-positive. Players are ~0.3 blocks wide.
        return 0.3;
    }
}

package io.antiguard.check;

import io.antiguard.action.ActionHandler;
import io.antiguard.config.PluginConfig;
import org.bukkit.GameMode;
import org.bukkit.entity.Player;
import org.bukkit.event.EventHandler;
import org.bukkit.event.EventPriority;
import org.bukkit.event.player.PlayerMoveEvent;
import org.bukkit.potion.PotionEffectType;

/**
 * Speed check — flags horizontal movement significantly faster than the
 * fastest a legitimate player can move.
 *
 * <p>Legit baseline: walking ~4.3 b/s, sprinting ~5.6 b/s. Speed I jr +
 * adds ~20% per level, Speed II +40% over sprint. We compute the expected
 * max from the player's active effects plus sprint state and a configured
 * margin, then compare the sampled blocks/tick movement.</p>
 */
public final class SpeedCheck implements Check {

    private final CheckManager manager;
    private final PluginConfig cfg;
    private final ActionHandler actionHandler;

    public SpeedCheck(CheckManager manager, PluginConfig cfg, ActionHandler actionHandler) {
        this.manager = manager;
        this.cfg = cfg;
        this.actionHandler = actionHandler;
    }

    @Override public String name() { return "Speed"; }

    @EventHandler(priority = EventPriority.MONITOR, ignoreCancelled = true)
    public void onMove(PlayerMoveEvent e) {
        Player p = e.getPlayer();
        if (p.getGameMode() == GameMode.CREATIVE || p.getGameMode() == GameMode.SPECTATOR) return;
        if (p.isFlying() || p.isGliding() || p.isInsideVehicle()) return;
        if (p.isInWater() || p.isInLava()) return;

        PlayerData pd = manager.data(p);
        pd.onMove(e.getTo());

        // Need two movement samples to compute a speed.
        if (pd.previous() == null || pd.current() == null) return;

        // Per-tick horizontal distance, converted to blocks/second (20 t/s).
        double bps = pd.horizontalSpeed() * 20.0;

        double maxBps = maxLegitSpeed(p);
        double margin = cfg.speedExcessMargin();
        double threshold = maxBps + margin;

        if (bps > threshold) {
            pd.setLastViolationNanos(System.nanoTime());
            log(actionHandler, p, "warning",
                    String.format("%.2f b/s > %.2f (threshold)", bps, threshold));
        }
    }

    /**
     * Estimate a legitimate player's max speed in b/s from their effects.
     * Base: walk ~4.3; sprint x1.3; Speed effect +20% per level over sprint.
     * With jump boost, a player can carry extra horizontal motion — cap
     * the allowance so it doesn't produce false positives.
     */
    private double maxLegitSpeed(Player p) {
        double base = 4.3;
        if (p.isSprinting()) base = 5.6;

        int speedLevel = getEffectLevel(p, PotionEffectType.SPEED);
        if (speedLevel > 0) {
            base *= (1.0 + 0.2 * speedLevel);
        }
        // Jump Boost adds kinetic launch; give a modest headroom.
        if (hasEffect(p, PotionEffectType.JUMP)) {
            base += 0.6;
        }
        return base;
    }

    private int getEffectLevel(Player p, PotionEffectType type) {
        var effect = p.getPotionEffect(type);
        return effect == null ? 0 : effect.getAmplifier() + 1;
    }

    private boolean hasEffect(Player p, PotionEffectType type) {
        return p.hasPotionEffect(type);
    }
}

```java
package io.antiguard.db;

import io.antiguard.AntiGuardPlugin;
import io.antiguard.config.PluginConfig;
import org.bukkit.configuration.ConfigurationSection;
import org.bukkit.configuration.file.YamlConfiguration;

import java.io.File;
import java.nio.file.Path;

/**
 * Resolves where AntiGuard should store its data.
 *
 * <p>By default AntiGuard <strong>plugs into the existing LuckPerms
 * database</strong>: it reads {@code plugins/LuckPerms/config.yml}, detects
 * LuckPerms' {@code storage-method} and credentials, and connects to that
 * same database — creating its own tables under a configurable prefix
 * ({@code antiguard_}) so it never touches LuckPerms' data.</p>
 *
 * <p>If no LuckPerms config is found (or it's unsupported), AntiGuard
 * falls back to its own bundled SQLite file.</p>
 */
public final class ConnectionFactory {

    private ConnectionFactory() {}

    /** Find the configured LuckPerms backend, falling back to bundled SQLite. */
    public static DbSettings resolve(AntiGuardPlugin plugin, PluginConfig cfg, String fallbackFile)
            throws Exception {

        // 1) Explicit override in AntiGuard config takes highest precedence.
        String override = cfg.dbType();
        if (override != null && !override.isBlank() && !override.equalsIgnoreCase("auto")) {
            return fromExplicit(cfg, plugin, override, fallbackFile);
        }

        // 2) Try LuckPerms config.
        DbSettings lp = fromLuckPerms(plugin);
        if (lp != null) {
            plugin.getLogger().info("AntiGuard plugged into LuckPerms database: " + lp.type);
            return lp;
        }

        // 3) Fallback: our own SQLite file.
        Path file = plugin.getDataFolder().toPath().resolve(fallbackFile);
        plugin.getLogger().info("No LuckPerms config found — using bundled SQLite: " + file.getFileName());
        return new DbSettings(DbType.SQLITE, "jdbc:sqlite:" + file, "", "");
    }

    private static DbSettings fromExplicit(PluginConfig cfg, AntiGuardPlugin plugin, String type, String fallbackFile) {
        DbType t = DbType.fromStorageMethod(type);
        if (t == DbType.SQLITE) {
            String f = cfg.dbFilePath();
            Path file = f == null || f.isBlank()
                    ? plugin.getDataFolder().toPath().resolve(fallbackFile)
                    : Path.of(f);
            return new DbSettings(DbType.SQLITE, "jdbc:sqlite:" + file, "", "");
        }
        // Remote backend — need host/db/user/pass from AntiGuard config.
        String host = cfg.dbHost();
        String db = cfg.dbDatabase();
        String user = cfg.dbUsername();
        String pass = cfg.dbPassword();
        String url = switch (t) {
            case MYSQL, MARIADB -> "jdbc:mariadb://" + host + "/" + db;
            case POSTGRESQL -> "jdbc:postgresql://" + host + "/" + db;
            case H2 -> "jdbc:h2:file:" + db + ";AUTO_SERVER=TRUE";
            default -> throw new IllegalStateException("unreachable");
        };
        return new DbSettings(t, url, user, pass);
    }

    /** Read LuckPerms' configured storage method and connect to the same DB. */
    private static DbSettings fromLuckPerms(AntiGuardPlugin plugin) {
        File lpDir = new File(plugin.getDataFolder().getParentFile(), "LuckPerms");
        File lpConfig = new File(lpDir, "config.yml");
        if (!lpConfig.exists()) return null;

        try {
            YamlConfiguration y = YamlConfiguration.loadConfiguration(lpConfig);
            String method = y.getString("storage-method", "h2");
            DbType t = DbType.fromStorageMethod(method);

            switch (t) {
                case H2 -> {
                    String dbName = y.getString("data.database", "luckperms");
                    // LuckPerms H2 file lives at plugins/LuckPerms/luckperms-h2-v2.mv.db
                    File h2 = new File(lpDir, "luckperms-h2-v2.mv.db");
                    String file = h2.exists() ? h2.getAbsolutePath()
                            : new File(lpDir, dbName + ".mv.db").getAbsolutePath();
                    return new DbSettings(DbType.H2,
                            "jdbc:h2:file:" + file + ";AUTO_SERVER=TRUE", "", "");
                }
                case SQLITE -> {
                    File dbFile = new File(lpDir, "luckperms-sqlite.db");
                    return new DbSettings(DbType.SQLITE, "jdbc:sqlite:" + dbFile.getAbsolutePath(), "", "");
                }
                case MYSQL, MARIADB -> {
                    String host = y.getString("data.address", "localhost");
                    String db = y.getString("data.database", "minecraft");
                    String user = y.getString("data.username", "root");
                    String pass = y.getString("data.password", "");
                    String url = "jdbc:mariadb://" + host + "/" + db;
                    return new DbSettings(t, url, user, pass);
                }
                case POSTGRESQL -> {
                    String host = y.getString("data.address", "localhost");
                    String db = y.getString("data.database", "minecraft");
                    String user = y.getString("data.username", "postgres");
                    String pass = y.getString("data.password", "");
                    return new DbSettings(DbType.POSTGRESQL, "jdbc:postgresql://" + host + "/" + db, user, pass);
                }
                default -> { return null; }
            }
        } catch (Exception e) {
            plugin.getLogger().warning("Could not read LuckPerms config for storage: " + e.getMessage());
            return null;
        }
    }
}

package io.antiguard.db;

import io.antiguard.AntiGuardPlugin;

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.sql.Statement;
import java.util.ArrayList;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * Persistent storage for AntiGuard.
 *
 * <p>Connects to the database resolved by {@link ConnectionFactory} — by
 * default the <strong>same database LuckPerms uses</strong> — and creates
 * its own {@code antiguard_*} tables. A prefix keeps AntiGuard's schema
 * separate from LuckPerms' own tables inside that shared database.
 * Per-dialect DDL lets the same code run on H2, SQLite, MySQL/MariaDB and
 * PostgreSQL.</p>
 *
 * <p>All DB access funnels through a single connection guarded by a
 * monitor to keep it safe and simple for a low-throughput game server.</p>
 */
public final class Database {

    private final AntiGuardPlugin plugin;
    private final Connection conn;
    private final String p; // table prefix, e.g. "antiguard_"
    private final DbType type;

    public Database(AntiGuardPlugin plugin, DbSettings settings) throws SQLException {
        this.plugin = plugin;
        this.p = plugin.configStore().dbTablePrefix();
        this.type = settings.type;
        // Load the driver class for this backend (all shaded into the jar).
        loadDriver(settings.type);
        this.conn = settings.connect();
        try (Statement st = conn.createStatement()) {
            if (settings.type == DbType.SQLITE) {
                st.execute("PRAGMA journal_mode=WAL;");
                st.execute("PRAGMA synchronous=NORMAL;");
            }
            createTables(st, settings.type);
        }
    }

    private static void loadDriver(DbType t) throws SQLException {
        String cls = switch (t) {
            case H2 -> "org.h2.Driver";
            case SQLITE -> "org.sqlite.JDBC";
            case MYSQL, MARIADB -> "org.mariadb.jdbc.Driver";
            case POSTGRESQL -> "org.postgresql.Driver";
        };
        try { Class.forName(cls); }
        catch (ClassNotFoundException e) { throw new SQLException("DB driver not found: " + cls, e); }
    }

    private void createTables(Statement st, DbType t) throws SQLException {
        String id = switch (t) {
            case H2, MYSQL, MARIADB -> "BIGINT AUTO_INCREMENT PRIMARY KEY";
            case SQLITE -> "INTEGER PRIMARY KEY AUTOINCREMENT";
            case POSTGRESQL -> "BIGSERIAL PRIMARY KEY";
        };

        st.execute("CREATE TABLE IF NOT EXISTS " + p + "flags (" +
                " id " + id + ", " +
                " time BIGINT NOT NULL, player_name VARCHAR(40) NOT NULL, player_uuid VARCHAR(64) DEFAULT '', " +
                " check_name VARCHAR(64) NOT NULL, level VARCHAR(16) DEFAULT 'info', " +
                " detail VARCHAR(1000) DEFAULT '', world VARCHAR(64) DEFAULT '')");
        st.execute("CREATE TABLE IF NOT EXISTS " + p + "bans (" +
                " id " + id + ", " +
                " time BIGINT NOT NULL, player_name VARCHAR(40) NOT NULL, player_uuid VARCHAR(64) DEFAULT '', " +
                " check_name VARCHAR(64) DEFAULT '', reason VARCHAR(300) DEFAULT '', status VARCHAR(16) DEFAULT 'active')");
        st.execute("CREATE TABLE IF NOT EXISTS " + p + "kicks (" +
                " id " + id + ", " +
                " time BIGINT NOT NULL, player_name VARCHAR(40) NOT NULL, player_uuid VARCHAR(64) DEFAULT '', " +
                " check_name VARCHAR(64) DEFAULT '', reason VARCHAR(300) DEFAULT '')");
        st.execute("CREATE TABLE IF NOT EXISTS " + p + "settings (key VARCHAR(64) PRIMARY KEY, value VARCHAR(200))");
        st.execute("CREATE INDEX IF NOT EXISTS idx_" + p + "flags_time ON " + p + "flags(time);");
        st.execute("CREATE INDEX IF NOT EXISTS idx_" + p + "bans_time ON " + p + "bans(time);");
        st.execute("CREATE INDEX IF NOT EXISTS idx_" + p + "kicks_time ON " + p + "kicks(time);");
    }

    /** Short human label of the backend, for logs. */
    public String typeLabel() { return type.name(); }

    private String tbl(String name) { return p + name; }

    // --- Flags ---
    public synchronized long addFlag(String name, String uuid, String check, String level, String detail, String world) {
        String sql = "INSERT INTO " + tbl("flags") + "(time, player_name, player_uuid, check_name, level, detail, world) VALUES(?,?,?,?,?,?,?)";
        try (PreparedStatement ps = conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)) {
            ps.setLong(1, System.currentTimeMillis());
            ps.setString(2, name); ps.setString(3, uuid); ps.setString(4, check);
            ps.setString(5, level); ps.setString(6, detail); ps.setString(7, world);
            ps.executeUpdate();
            return lastId(ps);
        } catch (SQLException e) { throw new RuntimeException(e); }
    }

    public synchronized List<Flag> listFlags(int limit, String player, String check) {
        String sql = "SELECT id, time, player_name, player_uuid, check_name, level, detail, world FROM " + tbl("flags");
        List<String> where = new ArrayList<>(); List<Object> args = new ArrayList<>();
        if (player != null && !player.isBlank()) { where.add("player_name=?"); args.add(player); }
        if (check != null && !check.isBlank()) { where.add("check_name=?"); args.add(check); }
        if (!where.isEmpty()) sql += " WHERE " + String.join(" AND ", where);
        sql += " ORDER BY time DESC LIMIT ?"; args.add(limit <= 0 ? 100 : Math.min(limit, 500));
        var out = new ArrayList<Flag>();
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            for (int i = 0; i < args.size(); i++) ps.setObject(i + 1, args.get(i));
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) out.add(new Flag(rs.getLong("id"), rs.getLong("time"), rs.getString("player_name"),
                        rs.getString("player_uuid"), rs.getString("check_name"), rs.getString("level"),
                        rs.getString("detail"), rs.getString("world")));
            }
        } catch (SQLException e) { throw new RuntimeException(e); }
        return out;
    }

    // --- Bans ---
    public synchronized long addBan(String name, String uuid, String check, String reason, String status) {
        String sql = "INSERT INTO " + tbl("bans") + "(time, player_name, player_uuid, check_name, reason, status) VALUES(?,?,?,?,?,?)";
        try (PreparedStatement ps = conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)) {
            ps.setLong(1, System.currentTimeMillis()); ps.setString(2, name); ps.setString(3, uuid);
            ps.setString(4, check); ps.setString(5, reason); ps.setString(6, status == null ? "active" : status);
            ps.executeUpdate();
            return lastId(ps);
        } catch (SQLException e) { throw new RuntimeException(e); }
    }

    public synchronized List<Ban> listBans(String status) {
        String sql = "SELECT id, time, player_name, player_uuid, check_name, reason, status FROM " + tbl("bans");
        List<String> where = new ArrayList<>(); List<Object> args = new ArrayList<>();
        if (status != null && !status.isBlank() && !"all".equalsIgnoreCase(status)) { where.add("status=?"); args.add(status); }
        if (!where.isEmpty()) sql += " WHERE " + String.join(" AND ", where);
        sql += " ORDER BY time DESC LIMIT 500";
        var out = new ArrayList<Ban>();
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            for (int i = 0; i < args.size(); i++) ps.setObject(i + 1, args.get(i));
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) out.add(new Ban(rs.getLong("id"), rs.getLong("time"), rs.getString("player_name"),
                        rs.getString("player_uuid"), rs.getString("check_name"), rs.getString("reason"), rs.getString("status")));
            }
        } catch (SQLException e) { throw new RuntimeException(e); }
        return out;
    }

    public synchronized void updateBanStatus(long id, String status) {
        try (PreparedStatement ps = conn.prepareStatement("UPDATE " + tbl("bans") + " SET status=? WHERE id=?")) {
            ps.setString(1, status); ps.setLong(2, id); ps.executeUpdate();
        } catch (SQLException e) { throw new RuntimeException(e); }
    }

    // --- Kicks ---
    public synchronized long addKick(String name, String uuid, String check, String reason) {
        String sql = "INSERT INTO " + tbl("kicks") + "(time, player_name, player_uuid, check_name, reason) VALUES(?,?,?,?,?)";
        try (PreparedStatement ps = conn.prepareStatement(sql, Statement.RETURN_GENERATED_KEYS)) {
            ps.setLong(1, System.currentTimeMillis()); ps.setString(2, name); ps.setString(3, uuid);
            ps.setString(4, check); ps.setString(5, reason);
            ps.executeUpdate();
            return lastId(ps);
        } catch (SQLException e) { throw new RuntimeException(e); }
    }

    public synchronized List<Kick> listKicks(int limit) {
        String sql = "SELECT id, time, player_name, player_uuid, check_name, reason FROM " + tbl("kicks") + " ORDER BY time DESC LIMIT ?";
        var out = new ArrayList<Kick>();
        try (PreparedStatement ps = conn.prepareStatement(sql)) {
            ps.setInt(1, limit <= 0 ? 100 : Math.min(limit, 500));
            try (ResultSet rs = ps.executeQuery()) {
                while (rs.next()) out.add(new Kick(rs.getLong("id"), rs.getLong("time"), rs.getString("player_name"),
                        rs.getString("player_uuid"), rs.getString("check_name"), rs.getString("reason")));
            }
        } catch (SQLException e) { throw new RuntimeException(e); }
        return out;
    }

    // --- Settings (used by the web config UI) ---
    public synchronized String getSetting(String key, String def) {
        try (PreparedStatement ps = conn.prepareStatement("SELECT value FROM " + tbl("settings") + " WHERE key=?")) {
            ps.setString(1, key);
            try (ResultSet rs = ps.executeQuery()) { return rs.next() ? rs.getString(1) : def; }
        } catch (SQLException e) { throw new RuntimeException(e); }
    }

    public synchronized Map<String, String> allSettings() {
        var map = new LinkedHashMap<String, String>();
        try (Statement st = conn.createStatement();
             ResultSet rs = st.executeQuery("SELECT key, value FROM " + tbl("settings"))) {
            while (rs.next()) map.put(rs.getString(1), rs.getString(2));
        } catch (SQLException e) { throw new RuntimeException(e); }
        return map;
    }

    public synchronized void setSetting(String key, String value) {
        try (PreparedStatement ps = conn.prepareStatement(
                "INSERT INTO " + tbl("settings") + "(key, value) VALUES(?,?) " +
                        "ON CONFLICT(key) DO UPDATE SET value=excluded.value")) {
            ps.setString(1, key); ps.setString(2, value); ps.executeUpdate();
        } catch (SQLException e) { throw new RuntimeException(e); }
    }

    public synchronized Map<String, Long> stats() {
        var out = new LinkedHashMap<String, Long>();
        for (String n : List.of("flags", "bans", "kicks")) {
            try (Statement st = conn.createStatement();
                 ResultSet rs = st.executeQuery("SELECT COUNT(*) FROM " + tbl(n))) {
                out.put(n, rs.next() ? rs.getLong(1) : 0L);
            } catch (SQLException e) { throw new RuntimeException(e); }
        }
        return out;
    }

    private long lastId(PreparedStatement ps) throws SQLException {
        try (ResultSet rs = ps.getGeneratedKeys()) { return rs.next() ? rs.getLong(1) : -1; }
    }

    public synchronized void close() {
        try { if (conn != null && !conn.isClosed()) conn.close(); }
        catch (SQLException ignored) { }
    }
}

import java.sql.Connection;

import java.sql.SQLException;

/** Resolved connection details for a chosen backend. */
public final class DbSettings {
    public final DbType type;
    public final String jdbcUrl;
    public final String username;
    public final String password;

    public DbSettings(DbType type, String jdbcUrl, String username, String password) {
        this.type = type;
        this.jdbcUrl = jdbcUrl;
        this.username = username == null ? "" : username;
        this.password = password == null ? "" : password;
    }

    public Connection connect() throws SQLException {
        Properties props = new Properties();
        props.setProperty("user", username);
        props.setProperty("password", password);
        // PostgreSQL needs the driver name set; all drivers are shaded in.
        return DriverManager.getConnection(jdbcUrl, props);
    }

    @Override
    public String toString() {
        return "DbSettings{" + type + " → " + safeUrl(jdbcUrl) + "}";
    }

    private static String safeUrl(String url) {
        // Never leak credentials in logs.
        return url.replaceAll("(password=)[^&;]*", "$1***");
    }
}

public enum DbType {

    SQLITE,
    MYSQL,
    MARIADB,

    public static DbType fromStorageMethod(String s) {
        if (s == null) return SQLITE;
        switch (s.trim().toLowerCase()) {
            case "h2": return H2;
            case "sqlite": return SQLITE;
            case "mysql": return MYSQL;
            case "mariadb": return MARIADB;
            case "postgresql", "postgres": return POSTGRESQL;
            default: throw new IllegalArgumentException("Unsupported storage method: " + s);
        }
    }
}

```java
package io.antiguard.web;

import com.google.gson.Gson;
import com.google.gson.JsonObject;
import com.google.gson.JsonParser;
import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpServer;
import io.antiguard.AntiGuardPlugin;
import io.antiguard.config.PluginConfig;
import io.antiguard.db.Database;
import io.antiguard.db.Flag;
import io.antiguard.db.Ban;
import io.antiguard.db.Kick;

import java.io.IOException;
import java.io.InputStream;
import java.io.OutputStream;
import java.net.InetSocketAddress;
import java.nio.charset.StandardCharsets;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.List;
import java.util.Map;

/**
 * Embedded web server + dashboard.
 *
 * <p>Runs on the bound host/port from config.yml (default 127.0.0.1:8080)
 * using the JVM's built-in {@link HttpServer}, so no extra web dependency
 * is shaded into the jar. Serves a static dashboard UI and a small REST
 * API to view flags/bans/kicks and tweak detection thresholds live.</p>
 */
public final class WebServer {

    private final AntiGuardPlugin plugin;
    private final PluginConfig cfg;
    private final Database db;
    private final Gson gson = new Gson();

    private HttpServer server;

    public WebServer(AntiGuardPlugin plugin, Database db) {
        this.plugin = plugin;
        this.cfg = plugin.configStore();
        this.db = db;
    }

    public void start() throws IOException {
        InetSocketAddress addr = new InetSocketAddress(cfg.webHost(), cfg.webPort());
        server = HttpServer.create(addr, 0);
        server.createContext("/", this::dispatch);
        server.setExecutor(null); // default executor
        server.start();
        plugin.getLogger().info("AntiGuard web UI listening on http://" + cfg.webHost() + ":" + cfg.webPort());
    }

    public void stop() {
        if (server != null) server.stop(0);
    }

    private void dispatch(HttpExchange ex) throws IOException {
        try {
            String path = ex.getRequestURI().getPath();
            String method = ex.getRequestMethod();

            if ("/".equals(path)) { serveDashboard(ex); return; }
            if (path.startsWith("/api/")) { handleApi(ex, path, method); return; }
            send(ex, 404, "{\"error\":\"not found\"}", "application/json");
        } catch (Exception e) {
            plugin.getLogger().warning("Web error: " + e.getMessage());
            send(ex, 500, "{\"error\":\"internal\"}", "application/json");
        }
    }

    // ----- Dashboard -----
    private void serveDashboard(HttpExchange ex) throws IOException {
        String html = loadResource("/web/index.html");
        if (html == null) { send(ex, 500, "dashboard not bundled", "text/plain"); return; }
        send(ex, 200, html, "text/html; charset=utf-8");
    }

    private String loadResource(String path) {
        try (InputStream in = getClass().getResourceAsStream(path)) {
            if (in == null) return null;
            return new String(in.readAllBytes(), StandardCharsets.UTF_8);
        } catch (IOException e) {
            return null;
        }
    }

    // ----- API -----
    private void handleApi(HttpExchange ex, String path, String method) throws IOException {
        String sub = path.substring("/api/".length());

        boolean write = !"GET".equalsIgnoreCase(method);
        if (write && !authOk(ex)) { send(ex, 401, "{\"error\":\"unauthorized\"}", "application/json"); return; }

        JsonObject out = new JsonObject();

        if (sub.startsWith("stats") && method.equals("GET")) {
            Map<String, Long> s = db.stats();
            out.addProperty("flags", s.getOrDefault("flags", 0L));
            out.addProperty("bans", s.getOrDefault("bans", 0L));
            out.addProperty("kicks", s.getOrDefault("kicks", 0L));
            send(ex, 200, gson.toJson(out), "application/json");

        } else if (sub.startsWith("flags")) {
            if (method.equals("GET")) {
                java.util.Map<String, String> q = query(ex);
                int limit = parseInt(q.get("limit"), 100);
                String player = q.get("player");
                String check = q.get("check");
                List<Flag> flags = db.listFlags(limit, player, check);
                send(ex, 200, gson.toJson(flags), "application/json");
            } else {
                send(ex, 405, "{\"error\":\"method not allowed\"}", "application/json");
            }

        } else if (sub.startsWith("bans")) {
            if (method.equals("GET")) {
                java.util.Map<String, String> q = query(ex);
                String status = q.get("status");
                List<Ban> bans = db.listBans(status);
                send(ex, 200, gson.toJson(bans), "application/json");
            } else if (path.contains("/status")) {
                String banId = path.replaceAll(".*/bans/([0-9]+)/status.*", "$1");
                JsonObject body = parseBody(ex);
                String status = body.has("status") ? body.get("status").getAsString() : "active";
                db.updateBanStatus(Long.parseLong(banId), status);
                out.addProperty("ok", true);
                send(ex, 200, gson.toJson(out), "application/json");
            } else {
                send(ex, 405, "{\"error\":\"method not allowed\"}", "application/json");
            }

        } else if (sub.startsWith("kicks") && method.equals("GET")) {
            java.util.Map<String, String> q = query(ex);
            List<Kick> kicks = db.listKicks(parseInt(q.get("limit"), 100));
            send(ex, 200, gson.toJson(kicks), "application/json");

        } else if (sub.startsWith("config")) {
            if (method.equals("GET")) {
                out = configAsJson();
                send(ex, 200, gson.toJson(out), "application/json");
            } else if (method.equals("POST")) {
                JsonObject body = parseBody(ex);
                applyConfig(body);
                send(ex, 200, gson.toJson(configAsJson()), "application/json");
            } else {
                send(ex, 405, "{\"error\":\"method not allowed\"}", "application/json");
            }
        } else {
            send(ex, 404, "{\"error\":\"not found\"}", "application/json");
        }
    }

    private JsonObject configAsJson() {
        JsonObject o = new JsonObject();
        o.addProperty("vlToFlag", cfg.vlToFlag());
        o.addProperty("flyMaxUpVelocity", cfg.flyMaxUpVelocity());
        o.addProperty("speedExcessMargin", cfg.speedExcessMargin());
        o.addProperty("reachMax", cfg.reachMax());
        o.addProperty("noSwingEnabled", cfg.noSwingEnabled());
        o.addProperty("autoBanAfterFlags", cfg.autoBanAfterFlags());
        o.addProperty("autoAction", cfg.autoAction());
        return o;
    }

    private void applyConfig(JsonObject body) {
        // Only the live-tunable keys are accepted via the API.
        setDouble(body, "vlToFlag", "vlToFlag");
        setDouble(body, "flyMaxUpVelocity", "flyMaxUpVelocity");
        setDouble(body, "speedExcessMargin", "speedExcessMargin");
        setDouble(body, "reachMax", "reachMax");
        setBool(body, "noSwingEnabled", "noSwingEnabled");
        setDouble(body, "autoBanAfterFlags", "autoBanAfterFlags");
        if (body.has("autoAction") && !body.get("autoAction").isJsonNull()) {
            db.setSetting("autoAction", body.get("autoAction").getAsString());
        }
    }

    private void setDouble(JsonObject body, String jsonKey, String dbKey) {
        if (body.has(jsonKey) && !body.get(jsonKey).isJsonNull()) {
            db.setSetting(dbKey, String.valueOf(body.get(jsonKey).getAsDouble()));
        }
    }
    private void setBool(JsonObject body, String jsonKey, String dbKey) {
        if (body.has(jsonKey) && !body.get(jsonKey).isJsonNull()) {
            db.setSetting(dbKey, body.get(jsonKey).getAsBoolean() ? "1" : "0");
        }
    }

    private boolean authOk(HttpExchange ex) {
        String token = cfg.webToken();
        if (token.isEmpty()) return true;
        String got = ex.getRequestHeaders().getFirst("X-Api-Token");
        return token.equals(got);
    }

    private java.util.Map<String, String> query(HttpExchange ex) {
        var map = new java.util.LinkedHashMap<String, String>();
        String q = ex.getRequestURI().getRawQuery();
        if (q != null) {
            for (String kv : q.split("&")) {
                String[] p = kv.split("=", 2);
                if (p.length == 2) map.put(p[0], decode(p[1]));
                else if (p.length == 1) map.put(p[0], "");
            }
        }
        return map;
    }

    private String decode(String s) {
        try { return java.net.URLDecoder.decode(s, StandardCharsets.UTF_8); }
        catch (Exception e) { return s; }
    }

    private JsonObject parseBody(HttpExchange ex) throws IOException {
        String raw = new String(ex.getRequestBody().readAllBytes(), StandardCharsets.UTF_8);
        try { return JsonParser.parseString(raw).getAsJsonObject(); }
        catch (Exception e) { return new JsonObject(); }
    }

    private int parseInt(String s, int def) {
        try { return Integer.parseInt(s == null ? "" : s.trim()); }
        catch (NumberFormatException e) { return def; }
    }

    private void send(HttpExchange ex, int code, String body, String contentType) throws IOException {
        byte[] bytes = body.getBytes(StandardCharsets.UTF_8);
        ex.getResponseHeaders().set("Content-Type", contentType);
        ex.getResponseHeaders().set("Access-Control-Allow-Origin", "*");
        ex.sendResponseHeaders(code, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }
}

    """FastAPI dependency yielding a scoped DB session."""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

    from . import models  # noqa: F401  (register models on Base)

    Base.metadata.create_all(bind=engine)

"""SQLAlchemy ORM models."""
from datetime import datetime, timezone

from sqlalchemy import Column, DateTime, ForeignKey, Index, Integer, String, Text

from .database import Base


def _now() -> datetime:
    return datetime.now(timezone.utc)


def _gen_key(prefix: str) -> str:
    """Generate a readable API key like `ag_live_8f3A…`."""
    import secrets

    return f"{prefix}_{secrets.token_urlsafe(24)}"


class Server(Base):
    """A registered Minecraft/SMP server (a billable unit)."""

    __tablename__ = "servers"

    id = Column(Integer, primary_key=True)
    name = Column(String(120), nullable=False)
    owner_email = Column(String(255), nullable=False)
    # Per-server scope so tiers/pricing can be applied.
    api_key = Column(String(96), unique=True, index=True, default=lambda: _gen_key("ag_live"))
    plan = Column(String(32), default="free")  # free | pro | enterprise
    max_players = Column(Integer, default=100)
    created_at = Column(DateTime(timezone=True), default=_now)


class Event(Base):
    """A cheat/alarm flag streamed by an agent."""

    __tablename__ = "events"
    __table_args__ = (Index("ix_events_server_time", "server_id", "created_at"),)

    id = Column(Integer, primary_key=True)
    server_id = Column(Integer, ForeignKey("servers.id"), nullable=False)
    server_key = Column(String(96), index=True)  # denormalised key for reads
    player_name = Column(String(36), nullable=False)
    player_uuid = Column(String(64), index=True, default="")
    flag_type = Column(String(64), nullable=False)  # e.g. "killaura", "fly"
    level = Column(String(16), default="info")  # info | warning | critical
    detail = Column(Text, default="")
    position = Column(String(96), default="")  # "x,y,z,world"
    created_at = Column(DateTime(timezone=True), default=_now)


class Ban(Base):
    """A ban flag with attached evidence."""

    __tablename__ = "bans"

    id = Column(Integer, primary_key=True)
    server_id = Column(Integer, ForeignKey("servers.id"), nullable=False)
    player_name = Column(String(36), nullable=False)
    player_uuid = Column(String(64), index=True, default="")
    reason = Column(String(255), default="")
    evidence = Column(Text, default="")  # JSON blob of evidence snapshots
    status = Column(String(16), default="active")  # active | appealed | expired
    created_at = Column(DateTime(timezone=True), default=_now)

"""Ban-list management with evidence."""
import json
from datetime import datetime, timezone

from fastapi import APIRouter, Depends, status
from sqlalchemy.orm import Session

from ..database import get_db
from ..models import Ban
from ..schemas import BanIn, BanOut, Message
from .deps import get_server_from_key

router = APIRouter(prefix="/bans", tags=["bans"])


@router.post("", response_model=BanOut, status_code=status.HTTP_201_CREATED)
def create_ban(
    payload: BanIn,
    server=Depends(get_server_from_key),
    db: Session = Depends(get_db),
):
    ban = Ban(
        server_id=server.id,
        player_name=payload.player_name,
        player_uuid=payload.player_uuid,
        reason=payload.reason,
        evidence=payload.evidence,
        status=payload.status,
    )
    db.add(ban)
    db.commit()
    db.refresh(ban)

@router.get("", response_model=list[BanOut])
def list_bans(
    server=Depends(get_server_from_key),
    db: Session = Depends(get_db),
    status_filter: str = "all",
):
    q = db.query(Ban).filter(Ban.server_id == server.id)
    if status_filter != "all":
        q = q.filter(Ban.status == status_filter)
    return q.order_by(Ban.created_at.desc()).all()


@router.patch("/{ban_id}", response_model=BanOut)
def update_ban(
    ban_id: int,
    payload: BanIn,
    server=Depends(get_server_from_key),
    db: Session = Depends(get_db),
):
    ban = (
        db.query(Ban)
        .filter(Ban.id == ban_id, Ban.server_id == server.id)
        .first()
    )
    if not ban:
        return None
    for field, value in payload.model_dump().items():
        setattr(ban, field, value)
    db.commit()
    db.refresh(ban)
    return ban


@router.delete("/{ban_id}", response_model=Message)
def delete_ban(
    ban_id: int,
    server=Depends(get_server_from_key),
    db: Session = Depends(get_db),
):
    ban = (
        db.query(Ban)
        .filter(Ban.id == ban_id, Ban.server_id == server.id)
        .first()
    )
    if not ban:
        return Message(detail="not found")
    db.delete(ban)
    db.commit()
    return Message(detail="deleted")


@router.post("/{ban_id}/evidence", response_model=Message)
def append_evidence(
    ban_id: int,
    payload: dict,
    server=Depends(get_server_from_key),
    db: Session = Depends(get_db),
):
    """Append an evidence snapshot to a ban (stored as JSON lines)."""
    ban = (
        db.query(Ban)
        .filter(Ban.id == ban_id, Ban.server_id == server.id)
        .first()
    )
    if not ban:
        return Message(detail="not found")

    snapshots = []
    if ban.evidence:
        try:
            snapshots = json.loads(ban.evidence)
        except json.JSONDecodeError:
            snapshots = []
    snapshot = {"at": datetime.now(timezone.utc).isoformat(), "data": payload}
    snapshots.append(snapshot)
    ban.evidence = json.dumps(snapshots)
    db.commit()
    return Message(detail="evidence appended")

"""Shared helpers: API-key auth and server resolution."""
from fastapi import Depends, Header, HTTPException, status
from sqlalchemy.orm import Session

from ..database import get_db
from ..models import Server


def get_server_from_key(
    authorization: str = Header(default=""),
    db: Session = Depends(get_db),
) -> Server:
    """Resolve a Server from the `Authorization: Bearer <api_key>` header.

    Keeps every agent call scoped to its own server (and thus its plan).
    """
    auth = authorization.strip()
    if not auth.lower().startswith("bearer "):
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Missing 'Authorization: Bearer <api_key>' header",
        )
    key = auth.split(" ", 1)[1].strip()
    server = db.query(Server).filter(Server.api_key == key).first()
    if not server:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid API key",
        )
    return server

"""Pydantic request/response schemas."""
from datetime import datetime
from typing import Optional

from pydantic import BaseModel, Field


class EventIn(BaseModel):
    """A cheat flag reported by an agent. `server_key` is read from the
    Authorization header, so it is not part of the payload."""

    player_name: str = Field(..., max_length=36)
    player_uuid: str = Field(default="", max_length=64)
    flag_type: str = Field(..., max_length=64)
    level: str = Field(default="info")
    detail: str = Field(default="", max_length=4000)
    position: str = Field(default="", max_length=96)


class EventOut(EventIn):
    id: int
    server_id: int
    created_at: datetime

    model_config = {"from_attributes": True}


class BanIn(BaseModel):
    player_name: str = Field(..., max_length=36)
    player_uuid: str = Field(default="", max_length=64)
    reason: str = Field(default="", max_length=255)
    evidence: str = Field(default="", max_length=8000)
    status: str = Field(default="active")


class BanOut(BanIn):
    id: int
    server_id: int
    created_at: Optional[datetime] = None
    expires_at: Optional[datetime] = None

    model_config = {"from_attributes": True}


class ServerIn(BaseModel):
    name: str = Field(..., max_length=120)
    owner_email: str = Field(..., max_length=255)
    plan: str = Field(default="free", max_length=32)
    max_players: int = Field(default=100, ge=1)


class ServerOut(BaseModel):
    id: int
    name: str
    owner_email: str
    api_key: str
    plan: str
    max_players: int
    created_at: Optional[datetime] = None

    const keyInput = document.getElementById('key');
    const statusSel = document.getElementById('status');
    const loadBtn = document.getElementById('load');
    const tbl = document.getElementById('tbl');

    async function fetchBans() {
      const key = keyInput.value.trim();
      if (!key) { tbl.innerHTML = '<div class="empty">Enter your server API key.</div>'; return; }
      const status = statusSel.value;
      const url = '/bans' + (status !== 'all' ? '?status_filter=' + status : '');
      const res = await fetch(url, { headers: { 'Authorization': 'Bearer ' + key } });
      if (!res.ok) { tbl.innerHTML = '<div class="error">HTTP ' + res.status + ' — invalid key?</div>'; return; }
      const bans = await res.json();
      render(bans);
    }

    function esc(s) { return String(s ?? '').replace(/[&<>"]/g, c => ({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;'}[c])); }

    function render(bans) {
      const active = bans.filter(b => b.status === 'active').length;
      const appealed = bans.filter(b => b.status === 'appealed').length;
      const expired = bans.filter(b => b.status === 'expired').length;
      document.getElementById('sTotal').textContent = bans.length;
      document.getElementById('sActive').textContent = active;
      document.getElementById('sAppealed').textContent = appealed;
      document.getElementById('sExpired').textContent = expired;

      if (!bans.length) { tbl.innerHTML = '<div class="empty">No bans yet.</div>'; return; }
      let rows = bans.map(b => `
        <tr>
          <td><strong>${esc(b.player_name)}</strong></td>
          <td><span class="badge b-${esc(b.status)}">${esc(b.status)}</span></td>
          <td>${esc(b.reason || '—')}</td>
          <td>${esc(b.evidence ? b.evidence.length + ' bytes' : '—')}</td>
          <td>${esc((b.created_at || '').slice(0, 10))}</td>
        </tr>`).join('');
      tbl.innerHTML = `<table><thead><tr><th>Player</th><th>Status</th><th>Reason</th><th>Evidence</th><th>Created</th></tr></thead><tbody>${rows}</tbody></table>`;
    }

    loadBtn.addEventListener('click', fetchBans);
    document.addEventListener('keydown', e => { if (e.key === 'Enter') fetchBans(); });
    // Prefill from localStorage if previously saved
    const saved = localStorage.getItem('ag_key');
    if (saved) { keyInput.value = saved; fetchBans(); }
    keyInput.addEventListener('change', () => localStorage.setItem('ag_key', keyInput.value.trim()));
  </script>
