## What Is Lucid Tarkov DMA?

Lucid Tarkov DMA is an **external hardware cheat** for Escape from Tarkov that runs entirely on a **second PC** connected via a **PCIe DMA card**. No process, driver, or injection ever touches the game machine — the cheat reads and writes Tarkov's memory over the DMA card's PCIe link, completely outside the reach of BattlEye anti-cheat.

Unlike software cheats that run inside or alongside the game, a DMA cheat operates at the hardware bus level. Your gaming PC has zero awareness that its memory is being accessed. This architecture provides a **significantly lower detection risk** than any software-based approach.

## How It Works

```
Gaming PC                        Second PC (runs Lucid DMA)
┌─────────────┐                  ┌─────────────────────────┐
│  Tarkov.exe  │  PCIe DMA card  │  Lucid DMA software     │
│  (untouched) │◄───────────────►│  - reads game memory     │
│              │                  │  - writes cheat values   │
│  MAKCU USB  ◄───── USB ────────│  - sends aimbot input    │
│  (HID mouse) │                  │  - renders ESP/radar     │
└─────────────┘                  └─────────────────────────┘
```

1. **DMA card** reads Tarkov's IL2CPP memory structures (player positions, loot, game state)
2. **Lucid DMA software** on the second PC processes the data, renders overlays and radar
3. For memory-write cheats, the DMA card writes values back to game memory
4. For the aimbot, mouse movements are sent through the **MAKCU USB device** as real HID input
