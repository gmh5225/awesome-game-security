# Apk Protection Patch

**Lets modified or unsigned apps work as system apps on Android 13 and newer.**

Starting with Android 13, unsigned or modified apps placed in the system are not recognised. This module patches the required system files on your device to remove that restriction. Most Mods Center modules need it.

## Features
- Works on AOSP and OEM ROMs: HyperOS, ColorOS and more
- Patches the files on your device during install, so it matches your ROM
- Lightweight (about 12 MB) and quick: patching runs on the phone's own Android runtime, no Java bundled
- Can patch a JAR you provide: put `framework.jar` (Android 15+) or `services.jar` (Android 14 and older) in `/sdcard/mods_center/` and flash. The patched JAR is saved to the same folder.

## Requirements
- Android 13 or newer, stock or custom ROM
- Magisk, KernelSU or APatch

## Installation
1. Download the latest zip from [**Releases**](https://github.com/Mods-Center/Apk-Protection-Patch/releases/latest).
2. Flash it in Magisk, KernelSU or APatch.
3. The files are patched on the device during install; this only takes a moment.
4. Reboot your device.

## Notes
- Flash it again after every ROM update.
- First boot after flashing takes longer while the system rebuilds its cache; this is normal.
- Also see [Apk Signature Verification Patch](https://github.com/Mods-Center/Apk-Signature-Verification-Patch), which disables signature checks completely so modified apps can also be installed as normal apps.

## v4.2 (45)

### Changelog
**Nov 16, 2026**
- Added a safety check: this module and the DSV (Disable APK signature verification) module cannot be installed at the same time (they modify the same system files). Flashing the second one now shows an error.

**Nov 16, 2026**
- Fixed "Decompile failed / inStream parameter is null" on install - the bundled APKEditor 1.4.9 engine was missing its resource files; it is now complete.
- Fixed random system crashes on some devices (e.g. MediaStore/WebView `Failed to parse debian.mime.types`). The rebuilt system jar is now verified before install: if the on-device rebuild alters any non-code resource, the module aborts safely instead of installing a jar that crashes at boot.
- Updated the on-device APKEditor engine to 1.4.9 (more reliable jar rebuilds).

**Earlier**
- Added support for modifying **framework.jar** or **services.jar** directly.
- Place your JAR file inside **`/sdcard/mods_center/`** and flash the module.
- The modified JAR will be saved back in the same folder.
- **Android 15+** → use `framework.jar`
- **Android 14 and below** → use `services.jar`
