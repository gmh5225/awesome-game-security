# Apk Signature Verification Patch

**Turns off APK signature verification completely, so modified apps install directly.**

[![Release](https://img.shields.io/github/v/release/Mods-Center/Apk-Signature-Verification-Patch?style=for-the-badge&label=release&color=0a84ff)](https://github.com/Mods-Center/Apk-Signature-Verification-Patch/releases/latest)

[![Stars](https://img.shields.io/github/stars/Mods-Center/Apk-Signature-Verification-Patch?style=for-the-badge&color=ffd60a)](https://github.com/Mods-Center/Apk-Signature-Verification-Patch/stargazers)
[![Telegram](https://img.shields.io/badge/Telegram-channel-26A5E4?style=for-the-badge&logo=telegram&logoColor=white)](https://t.me/kashis_cringey_stuffs)

</div>

## Features
- Patches `framework.jar`, `services.jar` and optionally `miui-services.jar` on the device
- No other module needed to install modified apps
- Supports Android 16 and ColorOS ROMs
- Lightweight (about 12 MB) and quick: patching runs on the phone's own Android runtime, no Java bundled
- Works offline
- To patch a JAR that isn't from your system, put it in `/sdcard/mods_center/` and flash the module

## Requirements
- Android 13 or newer
- Magisk, KernelSU or APatch

## Installation
1. Download the latest zip from [**Releases**](https://github.com/Mods-Center/Apk-Signature-Verification-Patch/releases/latest).
2. Flash it in Magisk, KernelSU or APatch.
3. Reboot your device.

## Notes
- Flash it again after every ROM update.
- First boot after flashing takes longer while the system rebuilds its cache; this is normal.
- If you only need modified system apps to load, [Apk Protection Patch](https://github.com/Mods-Center/Apk-Protection-Patch) is the lighter option.

## v4 (7)

### Changelogs 
**Nov 16, 2026**
- Added a safety check: this module and the Apk Protection Patch module cannot be installed at the same time (they modify the same system files). Flashing the second one now shows an error.

**Nov 16, 2026**
- Fixed "Decompile failed / inStream parameter is null" on install - the bundled APKEditor 1.4.9 engine was missing its resource files; it is now complete.
- Fixed random system crashes on some devices (e.g. MediaStore/WebView `Failed to parse debian.mime.types`). The rebuilt system jar is now verified before install: if the on-device rebuild alters any non-code resource, the module aborts safely instead of installing a jar that crashes at boot.
- Updated the on-device APKEditor engine to 1.4.9 (more reliable jar rebuilds).
- Keep a downgraded update of a system app after a reboot (previously it was reverted to the stock version and uninstalled on boot).

**Nov 6, 2025**
- Improved codes for ColorOS roms
- Added support for Android 16
- Added support for modifying **framework.jar** , **services.jar** and **miui-services.jar**(optional) directly.
- To Modify Non-System Jars, Place your JAR file inside **`/sdcard/mods_center/`** and flash the module.

**16 Feb, 2026**
- Making the module completely offline, everything added in the module.
