FF3 MMO — это браузерная многопользовательская онлайн-RPG, воссоздающая Final Fantasy III (NES) с кооперативным исследованием, игрой в группе, торговлей и PvP-сражениями. Написан на JavaScript и сочетает WebSocket-бэкенд на Node.js с canvas-фронтендом, который загружает предоставленную пользователем NES ROM для управления спрайтами, встречами, предметами и музыкой. Серверные арбитры и зеркала инвентаря проверяют исходы боёв, экономические события, сделки и смену экипировки, чтобы подделанные клиентские пакеты не могли дублировать предметы, завышать характеристики или подделывать награды. Инструменты реверс-инжиниринга ROM на базе jsnes извлекают графику монстров, палитры и игровые данные напрямую из PPU эмулятора для точного воссоздания. Проект полезен для изучения серверно-авторитетного мультиплеерного дизайна и античит-паттернов в недоверенных браузерных игровых клиентах.
