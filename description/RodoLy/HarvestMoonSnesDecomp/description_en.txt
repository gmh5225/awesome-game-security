This project is a readable decompilation of the SNES Harvest Moon that rewrites literal 65816 recompilation output into clear C while keeping behavior identical to the original cartridge. Python tooling imports community routine names, applies decomp overrides during builds, and tracks rewrite progress with automated check scripts against the recompiled baseline. The codebase pairs the decomp sources with a native C host that includes SNES CPU, PPU, and audio components, cross-platform launchers, optional Android builds, and non-destructive IPS or BPS mod loading. Extensive guides document console registers, farm and weather systems, event scripting, and differences between interpreter and compiled paths for researchers validating each routine. It targets reverse engineers, preservationists, and mod developers who need source-level understanding of classic SNES game logic for analysis, documentation, and informed patching.
