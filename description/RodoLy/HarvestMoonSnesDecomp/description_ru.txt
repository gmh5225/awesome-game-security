Этот проект — читаемая декомпиляция Harvest Moon для SNES, которая переписывает дословный вывод перекомпиляции 65816 в понятный C, сохраняя поведение, идентичное оригинальному картриджу. Инструменты на Python подтягивают имена подпрограмм из сообщества, применяют переопределения декомпиляции при сборке и отслеживают прогресс переписывания автоматизированными проверочными скриптами относительно перекомпилированной базовой линии. Кодовая база сочетает исходники декомпиляции с нативным C-хостом, включающим CPU, PPU и аудио SNES, кроссплатформенные лаунчеры, опциональные сборки под Android и недеструктивную загрузку модов IPS или BPS. Подробные руководства описывают регистры консоли, системы фермы и погоды, скрипты событий и различия между интерпретируемым и скомпилированным путями для исследователей, проверяющих каждую подпрограмму. Проект ориентирован на reverse-инженеров, энтузиастов сохранения и разработчиков модов, которым нужно понимание классической логики SNES на уровне исходного кода для анализа, документирования и обоснованного патчинга.
