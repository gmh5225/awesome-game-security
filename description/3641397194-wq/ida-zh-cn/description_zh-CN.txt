该项目是面向 IDA Pro 9.x 的运行时简体中文本地化插件，可在不修改 IDA 二进制文件或安装文件的前提下翻译反汇编器界面。它以 IDAPython 插件形式实现，基于 Python 与 PyQt5/Qt5，通过 QProxyStyle 在绘制阶段翻译菜单、选项卡与标题栏，同时保留控件标识符的英文，确保 IDAPython 脚本及其他插件仍可正常工作。内置词典约含 1860 条词条，支持用户自定义覆盖与未翻译字符串记录。可一键切换恢复完整英文界面，并提供适用于 Windows、macOS 与 Linux 的安装脚本。面向使用 IDA Pro、希望获得中文界面而又不影响自动化与分析流程的逆向工程师与游戏安全研究人员。
