This project is a runtime Simplified-Chinese localization plugin for IDA Pro 9.x that translates the disassembler interface without patching IDA binaries or installation files. It is implemented as an IDAPython plugin using Python with PyQt5 and Qt5, applying paint-time translation through QProxyStyle for menus, tabs, and headers while leaving widget identifiers in English so IDAPython scripts and other plugins continue to work. The bundled dictionary contains about 1860 entries, with support for user overrides and logging of untranslated strings. One-click toggling restores the full English UI on demand, and install scripts are provided for Windows, macOS, and Linux. It is aimed at reverse engineers and game security researchers who use IDA Pro and want a Chinese interface without breaking automation or analysis workflows.
