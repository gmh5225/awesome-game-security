Этот проект — плагин локализации IDA Pro 9.x на упрощённый китайский язык во время выполнения, который переводит интерфейс дизассемблера без изменения бинарных файлов IDA или файлов установки. Реализован как плагин IDAPython на Python с PyQt5 и Qt5; перевод применяется при отрисовке через QProxyStyle для меню, вкладок и заголовков, при этом идентификаторы виджетов остаются на английском, чтобы скрипты IDAPython и другие плагины продолжали работать. Встроенный словарь содержит около 1860 записей, поддерживаются пользовательские переопределения и журналирование непереведённых строк. Одним щелчком можно вернуть полностью английский интерфейс по требованию; предусмотрены скрипты установки для Windows, macOS и Linux. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности игр, использующих IDA Pro и желающих китайский интерфейс без нарушения автоматизации и рабочих процессов анализа.
