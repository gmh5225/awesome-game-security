CTRComposer 是面向 Nintendo 3DS 游戏的原始 .3gx 叠加层引擎与空白插件模板，使用 C、汇编以及 Luma3DS 插件加载器构建。它不依赖 CTRPluginFramework 或游戏专用钩子，而是将可换肤的屏幕 UI 直接绘制到帧缓冲，并使用系统共享字体、内联按钮字形，以及保存在插件安装路径下的设置。该引擎作为自包含入门项目提供，可在任意 Title ID 下运行，约百分之九十的代码与具体游戏无关，开发者主要只需添加作弊表、美术资源和自己的 Title ID。它面向自制软件与逆向工程工作流：从零构建新的作弊或叠加层插件，或让已无法在当前 Luma3DS 版本上加载的旧版 .plg/.3gx 插件重新可用。
