CTRComposer 是面向 Nintendo 3DS 遊戲的原始 .3gx 疊加層引擎與空白外掛範本，使用 C、組語以及 Luma3DS 外掛載入器建置。它不依賴 CTRPluginFramework 或遊戲專用掛鉤，而是將可換主題的螢幕 UI 直接繪製到幀緩衝，並使用系統共用字型、內嵌按鈕字形，以及儲存在外掛安裝路徑下的設定。此引擎以獨立入門專案形式提供，可在任意 Title ID 下運作，約百分之九十的程式碼與特定遊戲無關，開發者主要只需加入作弊表、美術資源與自己的 Title ID。它面向自製軟體與逆向工程工作流程：從零打造新的作弊或疊加層外掛，或讓已無法在現行 Luma3DS 版本載入的舊版 .plg/.3gx 外掛重新可用。
