CTRComposer is a raw .3gx overlay engine and blank plugin template for Nintendo 3DS games, built with C, assembly, and the Luma3DS plugin loader. It renders its own themeable on-screen UI to the framebuffer without CTRPluginFramework or game-specific hooks, using the system shared font, inline button glyphs, and settings stored under the plugin install path. The engine ships as a self-contained starter that works under any Title ID, with about ninety percent of the code game-independent so developers mainly add a cheat table, art, and their Title ID. It is aimed at homebrew and reverse-engineering workflows: building new cheats or overlay plugins from scratch, or reviving older .plg/.3gx plugins that no longer load on current Luma3DS builds.
