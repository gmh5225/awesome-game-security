CTRComposer は、Nintendo 3DS 向けの raw な .3gx オーバーレイエンジンおよび空のプラグインテンプレートで、C、アセンブリ、Luma3DS プラグインローダーで構築されています。CTRPluginFramework やゲーム固有のフックに依存せず、テーマ変更可能なオンスクリーン UI をフレームバッファへ描画し、システム共有フォント、インラインのボタングリフ、プラグインインストールパスに保存される設定を利用します。エンジンは任意の Title ID で動作する自己完結型スターターとして提供され、コードの約九割はゲーム非依存のため、開発者は主にチート表、アート、自身の Title ID を追加するだけで済みます。自作ソフトやリバースエンジニアリング向けで、新規チートやオーバーレイプラグインのゼロからの作成、現行の Luma3DS では読み込めなくなった古い .plg/.3gx プラグインの復活に役立ちます。
