OcarinaCTRComposer 是一款自繪製的 .3gx 疊加層外掛，為執行於 Luma3DS New 3DS（美版）上的《薩爾達傳說：時之笛 3D》加入作弊、工具與攻略。它建基於 CTRComposer 引擎，以 C 與 ARM 組語撰寫，並附有 Python 資源輔助程式；可繪製可主題化的自有介面，在不掛鉤遊戲的情況下暫停遊戲，並透過直接記憶體寫入實現作弊與傳送。主要功能包括數十種移動、戰鬥、物品、時間與任務作弊，對應傳送點與多槽位航點，與存檔同步的 100% 清單，以及 Cheat Search、RAM Dumper 與 Hex Editor 等工具。還內建外掛內攻略、收藏快捷選單、可重綁定熱鍵、本地化以及保存在 SD 卡上的設定。主要用途是在 3DS 外掛載入器下對 OoT3D 進行遊戲內作弊、存檔／進度追蹤與記憶體逆向工程。
