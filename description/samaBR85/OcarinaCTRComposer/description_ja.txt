OcarinaCTRComposer は、Luma3DS New 3DS（USA）上の『ゼルダの伝説 時のオカリナ 3D』にチート、ツール、ガイドを追加する自己描画型の .3gx オーバーレイプラグインです。CTRComposer エンジン上で C と ARM アセンブリにより構築され、Python のアセット補助も備え、テーマ変更可能な独自 UI を描画し、ゲームフックなしでゲームを一時停止し、直接メモリ書き込みでチートとワープを行います。主な機能は、移動・戦闘・インベントリ・時間・クエストの多数のチート、マップされたテレポートと複数スロットのウェイポイント、セーブ同期の 100% チェックリスト、および Cheat Search、RAM Dumper、Hex Editor です。プラグイン内ウォークスルー、お気に入りクイックメニュー、再割り当て可能なホットキー、ローカライズ、SD 永続設定も同梱されています。主な用途は、3DS プラグインローダー下での OoT3D のゲーム内チート、セーブ／進行状況の追跡、メモリリバースエンジニアリングです。
