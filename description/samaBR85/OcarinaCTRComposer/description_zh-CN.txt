OcarinaCTRComposer 是一款自渲染的 .3gx 叠加层插件，为运行于 Luma3DS New 3DS（美版）上的《塞尔达传说：时之笛 3D》添加作弊、工具与攻略。它基于 CTRComposer 引擎，以 C 与 ARM 汇编编写，并配有 Python 资源辅助脚本；可绘制可主题化的自有界面，在不挂钩游戏的情况下暂停游戏，并通过直接内存写入实现作弊与传送。主要功能包括数十种移动、战斗、物品、时间与任务作弊，映射传送点与多槽位航点，与存档同步的 100% 清单，以及 Cheat Search、RAM Dumper 与 Hex Editor 等工具。还内置插件内攻略、收藏快捷菜单、可重绑定热键、本地化以及保存在 SD 卡上的设置。主要用途是在 3DS 插件加载器下对 OoT3D 进行游戏内作弊、存档/进度追踪与内存逆向工程。
