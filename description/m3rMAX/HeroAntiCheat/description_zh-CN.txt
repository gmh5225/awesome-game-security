HeroAntiCheat 是一款面向 Minecraft Paper 与 Purpur 服务端（1.21.x，Java 21）的服务端反作弊插件。它基于 Java 实现，使用 Bukkit/Paper API 与 Maven 构建，通过可配置启发式规则检测未授权飞行、快速经验刷取、同 tick 图腾滥用、可疑准星切换目标，以及可选的客户端品牌或插件通道信号。管理员可在游戏内收到告警；若安装了 LiteBans 或 AdvancedBan，违规者可被随机时长的临时封禁；快速刷经验嫌疑者会在踢出前被短暂冻结。本项目面向希望以轻量、开源方式遏制作弊、采用保守阈值，并明确提示部分作弊无法仅凭服务端事件证实的服主。
