HeroAntiCheat es un complemento anti-trampas del lado del servidor para servidores Minecraft Paper y Purpur (1.21.x, Java 21). Está implementado en Java con la API Bukkit/Paper y Maven, y usa heurísticas configurables para marcar vuelo no autorizado, farmeo rápido de experiencia, abuso de tótem en el mismo tick, cambios sospechosos de objetivo al apuntar y señales opcionales de marca de cliente o canal de plugin. El staff recibe alertas en el juego; los infractores pueden recibir baneos temporales aleatorios si está LiteBans o AdvancedBan, y los sospechosos de XP rápida se congelan brevemente antes del expulsión. El proyecto está pensado para operadores que quieren un disuasivo de trampas ligero y de código abierto, con umbrales conservadores y advertencias explícitas de que algunas trampas no pueden demostrarse solo con eventos del servidor.
