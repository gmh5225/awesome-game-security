HeroAntiCheat is a server-side anti-cheat plugin for Minecraft Paper and Purpur servers (1.21.x, Java 21). It is implemented in Java with the Bukkit/Paper API and Maven, and uses configurable heuristics to flag unauthorized flight, fast experience farming, same-tick totem abuse, suspicious aim target switching, and optional client brand or plugin-channel signals. Staff receive in-game alerts, violators can receive randomized temporary bans when LiteBans or AdvancedBan is present, and fast-XP suspects are briefly frozen before kick. The project targets server operators who want a lightweight, open-source cheat deterrent with conservative thresholds and explicit warnings that some cheats cannot be proven from server events alone.
