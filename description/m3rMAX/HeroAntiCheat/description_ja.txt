HeroAntiCheat は、Minecraft Paper および Purpur サーバー（1.21.x、Java 21）向けのサーバー側アンチチートプラグインです。Java で実装され、Bukkit/Paper API と Maven を用い、設定可能なヒューリスティックで不正な飛行、高速経験値ファーム、同一 tick のトーテム悪用、疑わしいエイムのターゲット切り替え、および任意のクライアントブランドやプラグインチャネル信号を検知します。スタッフはゲーム内でアラートを受け取り、LiteBans または AdvancedBan がある場合は違反者にランダムな一時 BAN を付与でき、高速 XP 疑いのプレイヤーはキック前に短時間フリーズされます。保守的な閾値と、一部のチートはサーバーイベントだけでは証明できない旨の明示的な警告を備えた、軽量なオープンソースの抑止策を求めるサーバー運営者向けのプロジェクトです。
