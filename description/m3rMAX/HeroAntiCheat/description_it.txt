HeroAntiCheat è un plugin anti-cheat lato server per server Minecraft Paper e Purpur (1.21.x, Java 21). È implementato in Java con l’API Bukkit/Paper e Maven, e usa euristiche configurabili per segnalare volo non autorizzato, farming rapido di esperienza, abuso del totem nello stesso tick, cambi sospetti di bersaglio nella mira e segnali opzionali di brand client o canale plugin. Lo staff riceve avvisi in gioco; i trasgressori possono ricevere ban temporanei random se sono presenti LiteBans o AdvancedBan, e i sospetti di XP rapida vengono congelati brevemente prima del kick. Il progetto è rivolto agli operatori di server che vogliono un deterrente leggero e open source, con soglie conservative e avvertimenti espliciti che alcuni cheat non possono essere provati solo dagli eventi lato server.
