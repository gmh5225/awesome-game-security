HeroAntiCheat — серверный античит-плагин для серверов Minecraft Paper и Purpur (1.21.x, Java 21). Реализован на Java с API Bukkit/Paper и Maven; использует настраиваемые эвристики для пометки несанкционированного полёта, быстрого фарма опыта, злоупотребления тотемом в одном тике, подозрительного переключения цели при прицеливании и опциональных сигналов бренда клиента или plugin-channel. Персонал получает оповещения в игре; нарушителям при наличии LiteBans или AdvancedBan могут выдаваться случайные временные баны, подозреваемых в быстром XP кратко замораживают перед киком. Проект ориентирован на администраторов серверов, которым нужен лёгкий открытый сдерживающий инструмент с консервативными порогами и явными предупреждениями, что некоторые читы нельзя доказать только по серверным событиям.
