HeroAntiCheat 是一款面向 Minecraft Paper 與 Purpur 伺服器（1.21.x，Java 21）的伺服器端反作弊外掛。它以 Java 實作，使用 Bukkit/Paper API 與 Maven 建置，透過可設定的啟發式規則標記未授權飛行、快速經驗農場、同一 tick 圖騰濫用、可疑準星切換目標，以及可選的用戶端品牌或外掛通道訊號。管理員可在遊戲內收到警示；若已安裝 LiteBans 或 AdvancedBan，違規者可被隨機時長的暫時封禁；快速刷經驗嫌疑者會在踢出前被短暫凍結。本專案面向希望以輕量、開源方式遏制作弊、採用保守閾值，並明確警告部分作弊無法僅憑伺服器事件證實的服主。
