TeeForge-CD 是一款面向 Magisk、KernelSU 與 APatch 的 root 型 Android 模組，可自動維護與 TEE 相關的目標模組、可選的開機載入程式與 verified-boot 屬性掩蔽，以及由使用者觸發的 Keybox 同步。實作以 Rust 為主，輔以 C 原生程式碼、以 shell 為基礎的模組安裝器，以及用於裝置端控制的 Vue 與 TypeScript WebUI。開機時會重新整理 Tricky Store、TEESimulator、TEESimulator-RS、Oh My Keymint 等相容後端的應用程式作用域，透過專用 hide 輔助程式執行分類 resetprop 強化，Keybox 更新則留給明確的 Action、WebUI 或 CLI 流程。可從遠端公開金鑰池拉取 Keybox 材料，或在支援的 Qualcomm arm64 裝置上使用本地簽發的 Remote Key Provisioning 鏈；CLI 還提供 RKP 簽發、目標列表與自我更新工具。專案面向需要可維護、多 ABI 工作流程，以應對 Play Integrity 及類似用戶端完整性檢查的 Android 硬體 attestation 與完整性檢查繞過的研究人員與進階使用者。
