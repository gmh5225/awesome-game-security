TeeForge-CD is a rooted Android module for Magisk, KernelSU, and APatch that automates upkeep of TEE-related target modules, optional bootloader and verified-boot property masking, and user-triggered Keybox synchronization. It is implemented mainly in Rust with companion C native code, shell-based module installers, and a Vue and TypeScript WebUI for on-device control. On boot it refreshes compatible backends such as Tricky Store, TEESimulator, TEESimulator-RS, and Oh My Keymint app scopes, runs categorized resetprop hardening via a dedicated hide helper, and leaves Keybox updates to explicit Action, WebUI, or CLI flows. It can pull Keybox material from a remote public key pool or from locally issued Remote Key Provisioning chains on supported Qualcomm arm64 devices, and exposes RKP issuance, target listing, and self-update tooling through the CLI. The project targets researchers and power users who need a maintained, multi-ABI workflow for Android hardware attestation and integrity-check evasion around Play Integrity and similar client-side security checks.
