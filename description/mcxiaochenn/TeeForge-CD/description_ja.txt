TeeForge-CD は Magisk、KernelSU、APatch 向けの root 済み Android モジュールで、TEE 関連ターゲットモジュールの自動メンテナンス、オプションのブートローダーおよび verified-boot プロパティのマスキング、ユーザー起動の Keybox 同期を行います。実装は主に Rust で、C ネイティブコード、シェルベースのモジュールインストーラー、デバイス上制御用の Vue と TypeScript WebUI を併用します。起動時に Tricky Store、TEESimulator、TEESimulator-RS、Oh My Keymint など互換バックエンドのアプリスコープを更新し、専用 hide ヘルパー経由で分類された resetprop ハードニングを実行し、Keybox 更新は明示的な Action、WebUI、CLI フローに委ねます。リモート公開キープールまたは対応 Qualcomm arm64 デバイス上のローカル発行 Remote Key Provisioning チェーンから Keybox 素材を取得でき、CLI から RKP 発行、ターゲット一覧、自己更新ツールを提供します。Play Integrity や類似のクライアント側セキュリティチェックに関する Android ハードウェア attestation と整合性チェック回避のため、保守可能なマルチ ABI ワークフローを必要とする研究者とパワーユーザーを対象としています。
