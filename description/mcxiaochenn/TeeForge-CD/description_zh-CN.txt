TeeForge-CD 是一款面向 Magisk、KernelSU 与 APatch 的 root 型 Android 模块，可自动维护与 TEE 相关的目标模块、可选的引导加载程序与 verified-boot 属性掩蔽，以及由用户触发的 Keybox 同步。实现以 Rust 为主，辅以 C 原生代码、基于 shell 的模块安装器，以及用于设备端控制的 Vue 与 TypeScript WebUI。启动时会刷新 Tricky Store、TEESimulator、TEESimulator-RS、Oh My Keymint 等兼容后端的应用作用域，通过专用 hide 辅助程序执行分类 resetprop 加固，Keybox 更新则留给明确的 Action、WebUI 或 CLI 流程。可从远程公开密钥池拉取 Keybox 材料，或在支持的 Qualcomm arm64 设备上使用本地签发的 Remote Key Provisioning 链；CLI 还提供 RKP 签发、目标列表与自更新工具。项目面向需要可维护、多 ABI 工作流，以应对 Play Integrity 及类似客户端完整性校验的 Android 硬件 attestation 与完整性检查绕过的研究人员与高级用户。
