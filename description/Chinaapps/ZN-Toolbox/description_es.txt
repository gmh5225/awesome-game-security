ZN-Toolbox es una aplicación Android que ejecuta una máquina virtual contenedora sin root en el dispositivo anfitrión, proporcionando un entorno Android aislado con acceso root integrado y el framework LSPosed Xposed. Está construida sobre el motor de contenedores Twoyi, con un núcleo nativo en Rust y una interfaz de usuario en Kotlin Jetpack Compose con diseño liquid-glass. Sus capacidades clave incluyen la gestión de contenedores con múltiples perfiles, visualización y control remoto basados en Scrcpy, y una interfaz completamente localizada en chino. El proyecto está dirigido a investigadores de seguridad, ingenieros de ingeniería inversa y modders que necesitan un entorno aislado con root y Xposed en teléfonos sin root para análisis de aplicaciones, hooking y experimentación relacionada con juegos.
