ZN-Toolbox は、ホスト端末上で root 不要のコンテナ型仮想マシンを実行する Android アプリで、内蔵 root アクセスと LSPosed Xposed フレームワークを備えた隔離 Android 環境を提供します。Twoyi コンテナエンジン上に構築され、Rust ネイティブコアと Kotlin Jetpack Compose の UI により、リキッドガラスデザインを採用しています。主な機能には、マルチプロファイルのコンテナ管理、Scrcpy ベースのリモート表示と操作、完全にローカライズされた中国語 UI があります。本プロジェクトは、root 化されていない端末で root 済みかつ Xposed 対応のサンドボックスを必要とする、アプリ解析、フッキング、ゲーム関連実験を行うセキュリティ研究者、リバースエンジニア、モッダーを対象としています。
