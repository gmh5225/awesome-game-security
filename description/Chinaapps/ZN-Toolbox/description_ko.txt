ZN-Toolbox는 호스트 기기에서 root 없이 컨테이너 가상 머신을 실행하는 Android 애플리케이션으로, 내장 root 접근과 LSPosed Xposed 프레임워크를 갖춘 격리된 Android 환경을 제공합니다. Twoyi 컨테이너 엔진을 기반으로 하며, Rust 네이티브 코어와 Kotlin Jetpack Compose 사용자 인터페이스로 리퀴드 글래스 디자인을 구현했습니다. 주요 기능으로는 다중 프로필 컨테이너 관리, Scrcpy 기반 원격 화면 표시 및 제어, 완전히 현지화된 중국어 UI가 있습니다. 이 프로젝트는 root되지 않은 휴대폰에서 root 및 Xposed가 활성화된 샌드박스가 필요한 앱 분석, 후킹, 게임 관련 실험을 수행하는 보안 연구자, 리버스 엔지니어, 모더를 대상으로 합니다.
