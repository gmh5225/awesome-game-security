ZN-Toolbox 是一款 Android 應用程式，可在宿主裝置上執行無需 root 的容器虛擬機，提供具備內建 root 權限與 LSPosed Xposed 框架的隔離 Android 環境。它建構於 Twoyi 容器引擎之上，採用 Rust 原生核心與 Kotlin Jetpack Compose 使用者介面，並呈現液態玻璃風格設計。主要功能包括多設定檔容器管理、基於 Scrcpy 的遠端顯示與控制，以及完整本地化的中文介面。本專案面向需要在未 root 手機上取得已 root、支援 Xposed 的沙箱環境，以進行應用分析、Hook 及遊戲相關實驗的安全研究人員、逆向工程師與模組開發者。
