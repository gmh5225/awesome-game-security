ZN-Toolbox 是一款 Android 应用，可在宿主设备上运行无需 root 的容器虚拟机，提供具备内置 root 权限和 LSPosed Xposed 框架的隔离 Android 环境。它基于 Twoyi 容器引擎构建，采用 Rust 原生核心与 Kotlin Jetpack Compose 用户界面，并呈现液态玻璃风格设计。主要功能包括多配置文件容器管理、基于 Scrcpy 的远程显示与控制，以及完整本地化的中文界面。该项目面向需要在未 root 手机上获得已 root、支持 Xposed 的沙箱环境，以进行应用分析、Hook 及游戏相关实验的安全研究人员、逆向工程师和模组开发者。
