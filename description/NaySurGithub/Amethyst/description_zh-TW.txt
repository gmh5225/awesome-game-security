Amethyst 是一款面向 PowerNukkitX Minecraft Bedrock 伺服器的基於預測的反作弊外掛。此插件以 Java 撰寫，會在每個 tick 重播每位玩家的輸入，並透過重新實作的 Bedrock 物理引擎進行模擬，再將模擬位置與用戶端回報的位置進行比對，偵測遊戲自身規則無法解釋的移動行為，而非依賴簡單的速度閾值。它具備權威性的移動與載具模擬、附確認門控的用戶端世界狀態追蹤、附實體回溯的戰鬥預測，以及針對飛行、攻擊距離、Kill Aura、鷹架、背包濫用、回溯和畸形封包等的大量檢測。此外掛面向需要伺服器端作弊偵測、移動修正和違規告警以實現多人遊戲安全的 Bedrock 伺服器營運者與插件開發者。
