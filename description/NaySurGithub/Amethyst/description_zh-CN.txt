Amethyst 是一款面向 PowerNukkitX Minecraft Bedrock 服务器的基于预测的防作弊插件。该插件使用 Java 编写，会在每个 tick 重放每位玩家的输入，并通过重新实现的 Bedrock 物理引擎进行模拟，再将模拟位置与客户端上报的位置进行对比，检测游戏自身规则无法解释的移动行为，而非依赖简单的速度阈值。它具备权威性的移动与载具模拟、带确认门控的客户端世界状态追踪、带实体回退的战斗预测，以及针对飞行、攻击距离、Kill Aura、脚手架、背包滥用、回溯和畸形数据包等的大量检测。该插件面向需要服务端作弊检测、移动修正和违规告警以实现多人游戏安全的 Bedrock 服务器运营者与插件开发者。
