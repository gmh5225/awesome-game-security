FindXrefs — это плагин для IDA Pro, который находит и материализует перекрёстные ссылки, которые IDA ещё не создала в больших бинарных файлах, исправляя случаи, когда Jump to xref сообщает об отсутствии ссылок, хотя они существуют. Написан на Python с использованием IDAPython, сканирует всю базу данных на RIP-относительные и абсолютные указательные ссылки в x86/x64, с опциональным режимом скользящего окна raw relative 32-bit для нестандартных или обфусцированных смещений. Для каждого совпадения на неопределённых байтах создаёт инструкции или смещения данных, чтобы IDA автоматически сгенерировала xref. Опциональное ускорение NumPy ускоряет проходы по байтам примерно в пять раз, с резервными regex и циклами, когда NumPy недоступен. Предназначен для reverse engineers, анализирующих крупные игровые клиенты, модули anti-cheat и другие бинарники, где неполный автоанализ оставляет строки и глобальные переменные без видимых xref.
