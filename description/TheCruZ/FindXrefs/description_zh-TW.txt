FindXrefs 是一款 IDA Pro 外掛，可找出並具現化 IDA 在大型二進位檔上尚未建立的交叉參考，修正「跳轉至 xref」顯示沒有參考但實際上存在參考的情況。以 Python 搭配 IDAPython 撰寫，會掃描整個資料庫，在 x86/x64 上尋找 RIP 相對與絕對指標參考，並提供可選的原始相對 32 位元滑動視窗模式，用於非標準或混淆的偏移。對未定義位元組上的每個符合項目，它會建立指令或資料偏移，讓 IDA 自動產生 xref。可選的 NumPy 加速可將位元組掃描速度提升約五倍；若 NumPy 不可用，則回退至 regex 與迴圈方式。它面向分析大型遊戲用戶端、反作弊模組及其他二進位檔的逆向工程師，在自動分析不完整、字串與全域變數缺少可見 xref 的情境下特別有用。
