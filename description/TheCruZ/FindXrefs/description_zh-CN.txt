FindXrefs 是一款 IDA Pro 插件，用于查找并实例化 IDA 在大型二进制文件上尚未创建的交叉引用，解决“跳转到 xref”显示无引用但实际存在引用的情况。该插件使用 Python 和 IDAPython 编写，扫描整个数据库以查找 x86/x64 上的 RIP 相对引用和绝对指针引用，并提供可选的原始相对 32 位滑动窗口模式，用于处理非标准或混淆的偏移。对于未定义字节上的每个匹配项，它会创建指令或数据偏移，以便 IDA 自动生成 xref。可选的 NumPy 加速可将字节扫描速度提升约五倍；当 NumPy 不可用时，会回退到 regex 和循环方式。它面向分析大型游戏客户端、反作弊模块及其他二进制文件的逆向工程师，这些场景中不完整的自动分析会导致字符串和全局变量缺少可见的 xref。
