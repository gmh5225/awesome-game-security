이 프로젝트는 Windows용 개념 증명(PoC)으로, 문서화되지 않은 NvAPI_D3D11_WksReadScanout 함수를 통해 NVIDIA GPU 스캔아웃 버퍼를 읽어 화면에 표시되는 실제 이미지를 캡처합니다. BitBlt, DXGI OutputDuplication, PrintWindow 같은 기존 캡처 API와 달리, 이 방식은 치트 소프트웨어가 오버레이를 숨기고 정화된 스크린샷을 반환하는 데 사용하는 사용자 모드 그래픽 후킹 아래에서 동작합니다. C++로 Direct3D 11, DXGI, NVAPI를 사용해 작성되었으며, 캡처한 프레임버퍼를 PNG로 저장하고 캡처가 차단되거나 지원되지 않을 때 NVAPI 오류를 보고합니다. Windows 10 이상에서 NVIDIA 하드웨어의 스크린샷 회피 기법을 연구하는 안티치트 및 게임 보안 연구자를 대상으로 합니다.
