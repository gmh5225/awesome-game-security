Этот проект — proof-of-concept для Windows, который захватывает реальное изображение на экране, считывая scanout-буфер GPU NVIDIA через недокументированную функцию NvAPI_D3D11_WksReadScanout. В отличие от обычных API захвата, таких как BitBlt, DXGI OutputDuplication или PrintWindow, этот подход работает ниже графических хуков пользовательского режима, которые чит-софт использует для скрытия оверлеев и возврата «очищенных» скриншотов. Написан на C++ с использованием Direct3D 11, DXGI и NVAPI; сохраняет захваченный framebuffer в PNG и сообщает об ошибках NVAPI, когда захват заблокирован или не поддерживается. Предназначен для исследователей античита и безопасности игр, изучающих методы обхода скриншотов на оборудовании NVIDIA под Windows 10 и новее.
