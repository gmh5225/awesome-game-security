该项目是一个 Windows 概念验证（PoC），通过未公开的 NvAPI_D3D11_WksReadScanout 函数读取 NVIDIA GPU 的扫描输出缓冲区，从而捕获屏幕上真实的画面。与 BitBlt、DXGI OutputDuplication 或 PrintWindow 等传统捕获 API 不同，这种方法工作在作弊软件用于隐藏叠加层并返回“净化”截图的用户态图形钩子之下。项目使用 C++ 编写，依赖 Direct3D 11、DXGI 和 NVAPI，将捕获的帧缓冲区保存为 PNG，并在捕获被阻止或不受支持时报告 NVAPI 错误。它面向研究 NVIDIA 硬件（Windows 10 及以上）上截图规避技术的反作弊与游戏安全研究人员。
