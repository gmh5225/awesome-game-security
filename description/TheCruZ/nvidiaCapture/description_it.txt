Questo progetto è una proof of concept per Windows che cattura l'immagine reale sullo schermo leggendo il buffer scanout della GPU NVIDIA tramite la funzione non documentata NvAPI_D3D11_WksReadScanout. A differenza delle API di cattura convenzionali come BitBlt, DXGI OutputDuplication o PrintWindow, questo approccio opera al di sotto degli hook grafici in user mode che il software cheat utilizza per nascondere le sovrapposizioni e restituire screenshot « ripuliti ». Scritto in C++ con Direct3D 11, DXGI e NVAPI, salva il framebuffer catturato in PNG e segnala errori NVAPI quando la cattura è bloccata o non supportata. È destinato a ricercatori di anti-cheat e sicurezza dei giochi che studiano tecniche di elusione degli screenshot su hardware NVIDIA con Windows 10 o versioni successive.
