本プロジェクトは Windows 向けの概念実証（PoC）で、未公開の NvAPI_D3D11_WksReadScanout 関数を通じて NVIDIA GPU のスキャンアウトバッファを読み取り、画面上の実際の画像をキャプチャします。BitBlt、DXGI OutputDuplication、PrintWindow などの従来のキャプチャ API とは異なり、チートソフトがオーバーレイを隠し、サニタイズされたスクリーンショットを返すために使用するユーザーモードのグラフィックスフックより下のレイヤーで動作します。C++ で Direct3D 11、DXGI、NVAPI を用いて実装され、キャプチャしたフレームバッファを PNG として保存し、キャプチャがブロックされたり非対応の場合は NVAPI エラーを報告します。Windows 10 以降の NVIDIA ハードウェア上でのスクリーンショット回避手法を研究するアンチチートおよびゲームセキュリティ研究者向けです。
