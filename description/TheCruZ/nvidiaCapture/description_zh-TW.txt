該專案是一個 Windows 概念驗證（PoC），透過未公開的 NvAPI_D3D11_WksReadScanout 函式讀取 NVIDIA GPU 的掃描輸出緩衝區，以擷取螢幕上的真實畫面。與 BitBlt、DXGI OutputDuplication 或 PrintWindow 等傳統擷取 API 不同，此方法運作於作弊軟體用來隱藏疊加層並回傳「淨化」截圖的使用者模式圖形 Hook 之下。以 C++ 搭配 Direct3D 11、DXGI 與 NVAPI 撰寫，可將擷取的 framebuffer 儲存為 PNG，並在擷取遭阻擋或不支援時回報 NVAPI 錯誤。供反作弊與遊戲安全研究人員研究在 NVIDIA 硬體（Windows 10 以上）上的截圖規避技術。
