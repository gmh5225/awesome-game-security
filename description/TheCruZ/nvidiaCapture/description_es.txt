Este proyecto es una prueba de concepto para Windows que captura la imagen real en pantalla leyendo el búfer de scanout de la GPU NVIDIA mediante la función no documentada NvAPI_D3D11_WksReadScanout. A diferencia de las API de captura convencionales como BitBlt, DXGI OutputDuplication o PrintWindow, este enfoque opera por debajo de los hooks gráficos en modo usuario que el software de trampas utiliza para ocultar superposiciones y devolver capturas de pantalla « depuradas ». Escrito en C++ con Direct3D 11, DXGI y NVAPI, guarda el framebuffer capturado en PNG e informa errores de NVAPI cuando la captura está bloqueada o no es compatible. Está pensado para investigadores de anti-cheat y seguridad en juegos que estudian técnicas de evasión de capturas en hardware NVIDIA con Windows 10 o posterior.
