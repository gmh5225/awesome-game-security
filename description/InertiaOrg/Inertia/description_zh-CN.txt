Inertia 是一个用于构建 Minecraft 反作弊系统的开源基础框架，其核心引擎与版本无关，通过建模玩家行为来工作，而不是将逻辑绑定到特定的服务端实现。项目主要使用 Java 编写，分为 API、core 和 testkit 模块，为移动、数据包、世界快照、碰撞和调试追踪提供契约接口，并包含一个证据累积器，用于跟踪置信度、衰减以及误报上下文（如传送、速度宽容期、延迟尖峰和服务端健康状态）。该项目还提供带移动规则与限制的版本配置文件、用于逐帧状态追踪的移动预测骨架，以及无需真实 Minecraft 服务端即可运行的场景驱动测试。它面向希望获得可测试、平台无关的基础框架的反作弊开发者和服主，用于在多个游戏版本中检测非法移动及相关作弊行为。
