Inertia è una base open source per costruire sistemi anti-cheat per Minecraft con un motore indipendente dalla versione che modella il comportamento del giocatore anziché legare la logica a specifiche implementazioni di server. Scritto principalmente in Java e organizzato in moduli API, core e testkit, fornisce contratti per movimento, pacchetti, snapshot del mondo, collisioni e tracciamento debug, insieme a un accumulatore di evidenze che traccia confidenza, decadimento e contesto dei falsi positivi come teletrasporti, grazia di velocità, picchi di latenza e stato del server. Il progetto include profili di versione con regole e limiti di movimento, uno scheletro di previsione del movimento per il tracciamento dello stato fotogramma per fotogramma, e test guidati da scenari eseguibili senza un server Minecraft attivo. È rivolto a sviluppatori anti-cheat e operatori di server che desiderano una base testabile e indipendente dalla piattaforma per rilevare movimenti non validi e cheat correlati in molte versioni del gioco.
