Inertia is an open-source foundation for building Minecraft anti-cheat systems with a version-neutral engine that models player behavior rather than tying logic to specific server implementations. Written primarily in Java and organized into API, core, and testkit modules, it provides contracts for movement, packets, world snapshots, collision, and debug tracing alongside an evidence accumulator that tracks confidence, decay, and false-positive context such as teleports, velocity grace, latency spikes, and server health. The project includes version profiles with movement rules and limits, a movement prediction skeleton for frame-by-frame state tracking, and scenario-driven tests that run without a live Minecraft server. It is aimed at anti-cheat developers and server operators who want a testable, platform-agnostic base for detecting invalid movement and related cheats across many game versions.
