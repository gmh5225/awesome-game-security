Inertia — это открытая основа для создания античит-систем Minecraft с версионно-нейтральным движком, который моделирует поведение игрока, а не привязывает логику к конкретным реализациям сервера. Написанный преимущественно на Java и организованный в модули API, core и testkit, он предоставляет контракты для движения, пакетов, снимков мира, столкновений и отладочной трассировки, а также аккумулятор доказательств, отслеживающий уверенность, затухание и контекст ложных срабатываний — телепорты, grace period скорости, скачки задержки и состояние сервера. Проект включает профили версий с правилами и ограничениями движения, каркас предсказания движения для покадрового отслеживания состояния и сценарные тесты, работающие без живого сервера Minecraft. Он предназначен для разработчиков античитов и операторов серверов, которым нужна тестируемая, платформо-независимая база для обнаружения недопустимого движения и связанных читов во многих версиях игры.
