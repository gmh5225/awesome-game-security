Inertia 是一個用於建構 Minecraft 反作弊系統的開源基礎框架，其核心引擎與版本無關，透過建模玩家行為來運作，而非將邏輯綁定到特定的伺服器實作。專案主要使用 Java 撰寫，分為 API、core 與 testkit 模組，為移動、封包、世界快照、碰撞與除錯追蹤提供契約介面，並包含一個證據累積器，用於追蹤置信度、衰減以及誤報情境（如傳送、速度寬限期、延遲尖峰與伺服器健康狀態）。該專案還提供含移動規則與限制的版本設定檔、用於逐幀狀態追蹤的移動預測骨架，以及無需真實 Minecraft 伺服器即可執行的情境驅動測試。它面向希望獲得可測試、平台無關基礎框架的反作弊開發者與伺服器營運者，用於在多個遊戲版本中偵測非法移動及相關作弊行為。
