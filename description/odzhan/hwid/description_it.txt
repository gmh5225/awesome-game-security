hwid è un'utilità console nativa C++20 in sola lettura per Windows 10/11 x64 che inventaria gli identificatori hardware esposti dal sistema operativo e dai driver dei dispositivi. Raccoglie UUID di sistema, seriali di scheda madre e BIOS, identificatori di storage e rete, ID dispositivi USB, hash delle chiavi pubbliche TPM, dati GPU DXGI, dettagli del processore CPUID e metadati correlati tramite WMI, SetupAPI, IP Helper, TBS/CNG e NVML opzionale. Ogni campo include provenienza, livello di confidenza, note sulla mutabilità, stato di disponibilità e contesto diagnostico, anziché produrre un'impronta composita unica. L'output è disponibile come tabelle leggibili o JSON strutturato, con diagnostica dettagliata opzionale e una modalità di redazione per sopprimere valori sensibili. Lo strumento è rivolto a ricercatori di sicurezza, analisti anti-cheat e reverse engineer che studiano come viene interrogata l'identità hardware di Windows e quali identificatori sono affidabili o falsificabili.
