hwid は、Windows 10/11 x64 向けの読み取り専用ネイティブ C++20 コンソールユーティリティで、オペレーティングシステムとデバイスドライバーが公開するハードウェア識別子を一覧化します。WMI、SetupAPI、IP Helper、TBS/CNG、およびオプションの NVML を通じて、システム UUID、マザーボードおよび BIOS シリアル、ストレージおよびネットワーク識別子、USB デバイス ID、TPM 公開鍵ハッシュ、DXGI GPU データ、CPUID プロセッサ詳細、関連メタデータを収集します。各フィールドには、単一の複合フィンガープリントを生成するのではなく、出所、信頼度、可変性に関する注記、可用性ステータス、診断コンテキストが含まれます。出力は人間が読みやすい表形式または構造化 JSON で提供され、オプションの詳細診断と機微な値を抑制するマスキングモードも利用できます。このツールは、Windows のハードウェア ID がどのように照会されるか、どの識別子が信頼でき、偽装可能かを調査するセキュリティ研究者、アンチチートアナリスト、リバースエンジニアを対象としています。
