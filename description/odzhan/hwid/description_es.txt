hwid es una utilidad de consola nativa C++20 de solo lectura para Windows 10/11 x64 que inventaria los identificadores de hardware expuestos por el sistema operativo y los controladores de dispositivos. Recopila el UUID del sistema, los números de serie de la placa base y la BIOS, identificadores de almacenamiento y red, IDs de dispositivos USB, hashes de claves públicas TPM, datos de GPU DXGI, detalles del procesador CPUID y metadatos relacionados mediante WMI, SetupAPI, IP Helper, TBS/CNG y NVML opcional. Cada campo incluye procedencia, nivel de confianza, notas de mutabilidad, estado de disponibilidad y contexto diagnóstico, en lugar de producir una huella digital compuesta única. La salida está disponible como tablas legibles o JSON estructurado, con diagnósticos detallados opcionales y un modo de redacción para suprimir valores sensibles. La herramienta está dirigida a investigadores de seguridad, analistas antitrampas e ingenieros de ingeniería inversa que estudian cómo se consulta la identidad de hardware de Windows y qué identificadores son fiables o falsificables.
