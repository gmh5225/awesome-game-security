hwid 是一款針對 Windows 10/11 x64 的唯讀原生 C++20 主控台實用工具，用於盤點作業系統和裝置驅動程式暴露的硬體識別碼。它透過 WMI、SetupAPI、IP Helper、TBS/CNG 以及選用的 NVML 收集系統 UUID、主機板和 BIOS 序號、儲存與網路識別碼、USB 裝置 ID、TPM 公開金鑰雜湊、DXGI GPU 資料、CPUID 處理器詳細資訊及相關中繼資料。每個欄位都包含來源、信心等級、可變性說明、可用性狀態和診斷上下文，而非產生單一的複合指紋。輸出可為人類可讀表格或結構化 JSON，並提供選用的詳細診斷和用於遮蔽敏感值的脫敏模式。該工具面向研究 Windows 硬體身分查詢方式以及哪些識別碼可靠或可偽造的安全研究人員、反作弊分析人員和逆向工程師。
