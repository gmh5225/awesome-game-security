hwid 是一款针对 Windows 10/11 x64 的只读原生 C++20 控制台实用工具，用于清点操作系统和设备驱动程序暴露的硬件标识符。它通过 WMI、SetupAPI、IP Helper、TBS/CNG 以及可选的 NVML 收集系统 UUID、主板和 BIOS 序列号、存储与网络标识符、USB 设备 ID、TPM 公钥哈希、DXGI GPU 数据、CPUID 处理器详细信息及相关元数据。每个字段都包含来源、置信度、可变性说明、可用性状态和诊断上下文，而非生成单一的复合指纹。输出可为人可读表格或结构化 JSON，并提供可选的详细诊断和用于屏蔽敏感值的脱敏模式。该工具面向研究 Windows 硬件身份查询方式以及哪些标识符可靠或可伪造的安全研究人员、反作弊分析人员和逆向工程师。
