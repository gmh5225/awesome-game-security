hwid는 Windows 10/11 x64용 읽기 전용 네이티브 C++20 콘솔 유틸리티로, 운영 체제와 장치 드라이버가 노출하는 하드웨어 식별자를 목록화합니다. WMI, SetupAPI, IP Helper, TBS/CNG 및 선택적 NVML을 통해 시스템 UUID, 마더보드 및 BIOS 시리얼, 스토리지 및 네트워크 식별자, USB 장치 ID, TPM 공개 키 해시, DXGI GPU 데이터, CPUID 프로세서 세부 정보 및 관련 메타데이터를 수집합니다. 각 필드에는 단일 복합 지문을 생성하는 대신 출처, 신뢰 수준, 변경 가능성에 대한 메모, 가용성 상태, 진단 컨텍스트가 포함됩니다. 출력은 사람이 읽기 쉬운 표 또는 구조화된 JSON으로 제공되며, 선택적 상세 진단과 민감한 값을 숨기는 마스킹 모드도 지원합니다. 이 도구는 Windows 하드웨어 ID가 어떻게 조회되는지, 어떤 식별자가 신뢰할 수 있거나 위조 가능한지를 연구하는 보안 연구원, 안티치트 분석가, 리버스 엔지니어를 대상으로 합니다.
