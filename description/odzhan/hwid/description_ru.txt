hwid — это утилита командной строки на нативном C++20 только для чтения для Windows 10/11 x64, которая инвентаризирует аппаратные идентификаторы, доступные через операционную систему и драйверы устройств. Она собирает UUID системы, серийные номера материнской платы и BIOS, идентификаторы накопителей и сети, ID USB-устройств, хеши открытых ключей TPM, данные GPU через DXGI, сведения о процессоре через CPUID и связанные метаданные с помощью WMI, SetupAPI, IP Helper, TBS/CNG и опционально NVML. Каждое поле содержит источник происхождения, уровень достоверности, сведения об изменяемости, статус доступности и диагностический контекст, а не формирует единый составной отпечаток. Вывод доступен в виде читаемых таблиц или структурированного JSON, с опциональной подробной диагностикой и режимом маскирования для скрытия чувствительных значений. Инструмент предназначен для исследователей безопасности, аналитиков античит-систем и специалистов по реверс-инжинирингу, изучающих, как запрашивается аппаратная идентичность Windows и какие идентификаторы надёжны или поддаются подмене.
