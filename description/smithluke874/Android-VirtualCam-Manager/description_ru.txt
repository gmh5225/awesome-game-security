Android VirtualCam Manager — это система виртуальной камеры для Android с root-доступом, которая заменяет потоки с живой камеры заранее записанным видео без необходимости в фреймворках LSPosed или Xposed. Она сочетает модуль Magisk и Zygisk с управляющим приложением на Kotlin Jetpack Compose для работы с управляющими файлами и импортом медиа, а нативный C++-код использует ArtHook для перехвата API Camera1, таких как setPreviewTexture, startPreview и PreviewCallback, для рендеринга Surface и инъекции кадров NV21. Доставка кадров следует классическому подходу android_virtual_cam: MediaPlayer используется для preview Surface, а MediaCodec декодирует virtual.mp4 в буферы NV21 для приложений на основе callback. Проект поддерживает сборки Zygisk для нескольких ABI, фильтрацию процессов с телеметрией статуса хуков и одношаговое включение и импорт через root shell. Предназначен для исследователей безопасности и реверс-инженеров, изучающих подмену камеры, античит-проверки камеры и методы обхода liveness- или верификации личности на Android.
