Android VirtualCam Manager 是一套已 root 的 Android 虚拟摄像头系统，可在无需 LSPosed 或 Xposed 框架的情况下，用预录视频替换实时摄像头画面。它结合了 Magisk 与 Zygisk 模块，以及用于管理控制文件与媒体导入的 Kotlin Jetpack Compose 控制应用；原生 C++ 代码通过 ArtHook 拦截 Camera1 API（如 setPreviewTexture、startPreview 和 PreviewCallback），实现 Surface 渲染与 NV21 帧注入。帧投递沿用经典的 android_virtual_cam 方案：预览 Surface 使用 MediaPlayer，MediaCodec 将 virtual.mp4 解码为 NV21 缓冲区，供基于回调的应用使用。项目支持多 ABI 的 Zygisk 构建、带 Hook 状态遥测的进程门控，以及通过 root shell 访问实现的一键启用与导入工作流。面向研究摄像头欺骗、反作弊摄像头检测，以及 Android 上活体或身份验证绕过技术的安全研究人员与逆向工程师。
