Android VirtualCam Manager 是一套已 root 的 Android 虛擬攝影機系統，可在無需 LSPosed 或 Xposed 框架的情況下，以預錄影片取代即時攝影機畫面。它結合 Magisk 與 Zygisk 模組，以及用於管理控制檔與媒體匯入的 Kotlin Jetpack Compose 控制應用程式；原生 C++ 程式碼透過 ArtHook 攔截 Camera1 API（如 setPreviewTexture、startPreview 和 PreviewCallback），實現 Surface 渲染與 NV21 幀注入。幀傳遞沿用經典的 android_virtual_cam 方案：預覽 Surface 使用 MediaPlayer，MediaCodec 將 virtual.mp4 解碼為 NV21 緩衝區，供基於回呼的應用程式使用。專案支援多 ABI 的 Zygisk 建置、附 Hook 狀態遙測的行程門控，以及透過 root shell 存取實現的一鍵啟用與匯入工作流程。面向研究攝影機欺騙、反作弊攝影機檢測，以及 Android 上活體或身分驗證繞過技術的安全研究人員與逆向工程師。
