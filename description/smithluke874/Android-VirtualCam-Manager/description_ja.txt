Android VirtualCam Manager は、root 済み Android 向けの仮想カメラシステムで、LSPosed や Xposed フレームワークを必要とせず、ライブカメラ映像を事前録画した動画に置き換えます。Magisk と Zygisk モジュールに加え、制御ファイルとメディアのインポートを管理する Kotlin Jetpack Compose 制御アプリを組み合わせ、ネイティブ C++ コードは ArtHook で setPreviewTexture、startPreview、PreviewCallback などの Camera1 API をフックし、Surface レンダリングと NV21 フレーム注入を行います。フレーム配信は android_virtual_cam の古典的な方式に従い、プレビュー Surface には MediaPlayer を、virtual.mp4 の NV21 バッファへのデコードには MediaCodec を使用し、コールバックベースのアプリに供給します。プロジェクトはマルチ ABI の Zygisk ビルド、フック状態テレメトリ付きのプロセスゲーティング、root shell 経由のワンタップ有効化とインポートワークフローをサポートします。Android 上のカメラ偽装、アンチチートのカメラチェック、ライブネスや本人確認のバイパス手法を研究するセキュリティ研究者とリバースエンジニアを対象としています。
