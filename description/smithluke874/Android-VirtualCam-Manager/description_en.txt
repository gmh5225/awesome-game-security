Android VirtualCam Manager is a rooted Android virtual camera system that replaces live camera feeds with pre-recorded video without requiring LSPosed or Xposed frameworks. It combines a Magisk and Zygisk module with a Kotlin Jetpack Compose controller app that manages control files and media import, while native C++ code uses ArtHook to intercept Camera1 APIs such as setPreviewTexture, startPreview, and PreviewCallback for surface rendering and NV21 frame injection. Frame delivery follows the classic android_virtual_cam approach, using MediaPlayer for preview surfaces and MediaCodec to decode virtual.mp4 into NV21 buffers for callback-based applications. The project supports multi-ABI Zygisk builds, process gating with hook status telemetry, and one-tap enable and import workflows via root shell access. It is aimed at security researchers and reverse engineers studying camera spoofing, anti-cheat camera checks, and liveness or identity verification bypass techniques on Android.
