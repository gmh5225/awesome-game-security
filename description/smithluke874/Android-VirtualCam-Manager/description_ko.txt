Android VirtualCam Manager는 LSPosed나 Xposed 프레임워크 없이도 사전 녹화된 영상으로 실시간 카메라 피드를 대체하는 root 권한 Android 가상 카메라 시스템입니다. Magisk 및 Zygisk 모듈과 제어 파일 및 미디어 가져오기를 관리하는 Kotlin Jetpack Compose 제어 앱을 결합하며, 네이티브 C++ 코드는 ArtHook을 사용해 setPreviewTexture, startPreview, PreviewCallback 등 Camera1 API를 가로채 Surface 렌더링과 NV21 프레임 주입을 수행합니다. 프레임 전달은 android_virtual_cam의 고전적 방식을 따르며, 미리보기 Surface에는 MediaPlayer를, virtual.mp4를 NV21 버퍼로 디코딩하는 데는 MediaCodec을 사용해 콜백 기반 애플리케이션에 공급합니다. 이 프로젝트는 멀티 ABI Zygisk 빌드, 훅 상태 원격 측정을 갖춘 프로세스 게이팅, root shell 접근을 통한 원탭 활성화 및 가져오기 워크플로를 지원합니다. Android에서 카메라 스푸핑, 안티치트 카메라 검사, 생체 또는 신원 확인 우회 기법을 연구하는 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
