Saturn Anti Cheat 是一套面向 Windows 内核模式的反作弊栈，用于在使用 insecure 启动选项运行 Counter-Strike 2 时提供保护。项目将基于 WDK 构建、以 C 编写的内核驱动与原生启动器配对：启动器以服务的形式加载驱动，通过 IOCTL 心跳进行校验，并提供简洁的 GUI。驱动注册进程、线程与映像加载回调以跟踪 CS2，维护合法游戏、Steam 与 System32 模块的白名单，并记录入口点位于已映射 PE 映像之外的可疑远程线程，以及未签名或不在白名单内的 DLL 加载。项目使用 CMake 构建，面向研究游戏安全、自定义反作弊设计与 Windows 内核级作弊检测的开发者和研究人员。
