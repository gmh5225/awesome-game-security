Saturn Anti Cheat is a Windows kernel-mode anti-cheat stack aimed at protecting Counter-Strike 2 when run with the insecure launch option. The project pairs a WDK-built kernel driver written in C with a native launcher that loads the driver as a service, verifies it via IOCTL heartbeat, and presents a simple GUI. The driver registers process, thread, and image-load callbacks to track CS2, maintain allowlists of legitimate game, Steam, and System32 modules, and log suspicious remote threads whose entry points lie outside mapped PE images as well as unsigned or non-allowlisted DLL loads. It is built with CMake and targets developers and researchers studying game security, custom anti-cheat design, and kernel-level cheat detection on Windows.
