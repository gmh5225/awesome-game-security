Saturn Anti Cheat は、insecure 起動オプションで Counter-Strike 2 を実行する際の保護を目的とした、Windows カーネルモード向けアンチチートスタックです。WDK でビルドした C 言語のカーネルドライバと、ドライバをサービスとして読み込み、IOCTL ハートビートで検証し、シンプルな GUI を提供するネイティブランチャーを組み合わせています。ドライバはプロセス・スレッド・イメージロードのコールバックを登録して CS2 を追跡し、正当なゲーム・Steam・System32 モジュールの許可リストを維持し、マップ済み PE イメージ外のエントリポイントを持つ疑わしいリモートスレッドや、未署名または許可リスト外の DLL 読み込みをログに記録します。CMake でビルドされ、ゲームセキュリティ、カスタムアンチチート設計、Windows 上のカーネルレベルチート検知を研究する開発者と研究者を対象としています。
