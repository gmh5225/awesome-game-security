Saturn Anti Cheat는 insecure 실행 옵션으로 Counter-Strike 2를 실행할 때 보호를 목표로 하는 Windows 커널 모드 안티치트 스택입니다. WDK로 빌드한 C 언어 커널 드라이버와, 드라이버를 서비스로 로드하고 IOCTL 하트비트로 검증하며 간단한 GUI를 제공하는 네이티브 런처를 함께 구성합니다. 드라이버는 프로세스·스레드·이미지 로드 콜백을 등록해 CS2를 추적하고, 정당한 게임·Steam·System32 모듈 허용 목록을 유지하며, 매핑된 PE 이미지 밖의 진입점을 가진 의심스러운 원격 스레드와 서명되지 않았거나 허용 목록에 없는 DLL 로드를 기록합니다. CMake로 빌드되며 게임 보안, 맞춤형 안티치트 설계, Windows 커널 수준 치트 탐지를 연구하는 개발자와 연구자를 대상으로 합니다.
