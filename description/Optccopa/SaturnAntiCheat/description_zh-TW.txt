Saturn Anti Cheat 是一套面向 Windows 核心模式的反作弊堆疊，旨在於使用 insecure 啟動選項執行 Counter-Strike 2 時提供保護。專案將以 WDK 建置、以 C 撰寫的核心驅動程式與原生啟動器配對：啟動器以服務形式載入驅動程式，透過 IOCTL 心跳進行驗證，並提供簡潔的 GUI。驅動程式註冊程序、執行緒與映像載入回呼以追蹤 CS2，維護合法遊戲、Steam 與 System32 模組的白名單，並記錄進入點位於已對應 PE 映像之外的可疑遠端執行緒，以及未簽章或不在白名單內的 DLL 載入。專案以 CMake 建置，面向研究遊戲安全、自訂反作弊設計與 Windows 核心層級作弊偵測的開發者與研究人員。
