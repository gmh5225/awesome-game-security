Dani's Nightmare is a BepInEx mod for the Unity survival game Muck that adds a runtime debug and chat-command suite for manipulating nearly every aspect of gameplay. Written in C#, it uses Harmony IL patches to hook player stats, mob scaling, loot drops, chest mechanics, day/night cycles, and item spawning without recompiling the game. Commands such as /player, /enemy, /powerup, and /items provide god mode, enemy wave control, powerup and item injection, peaceful mode, and time travel, with Tab-key autocomplete that reads live in-memory game data. The project is aimed at mod developers, reverse engineers, and security researchers who need a practical tool for probing and stress-testing Muck's engine behavior at runtime.
