Dani's Nightmare — мод BepInEx для survival-игры на Unity Muck, добавляющий набор отладки во время выполнения и чат-команд для управления практически всеми аспектами геймплея. Написан на C# и использует IL-патчи Harmony для перехвата статов игрока, масштабирования мобов, выпадения лута, механики сундуков, циклов день/ночь и спавна предметов без перекомпиляции игры. Команды вроде /player, /enemy, /powerup и /items обеспечивают режим бога, управление волнами врагов, инъекцию усилений и предметов, мирный режим и путешествие во времени, с автодополнением по Tab, читающим актуальные игровые данные из памяти. Проект предназначен для разработчиков модов, реверс-инженеров и исследователей безопасности, которым нужен практичный инструмент для исследования и стресс-тестирования поведения движка Muck во время выполнения.
