IronTrace 是一款面向遊戲伺服器管理員的 Windows 硬體與鑑識完整性掃描器，用於審查玩家機器上的作弊相關訊號。專案主要以 C# 開發，包含 WPF 桌面應用程式、無介面 CLI，以及可選的 ASP.NET Core 伺服器端，可收集平台安全、PCI/PCIe 與 USB 裝置、驅動程式、DMA 偽裝指標等證據，並可選啟用鑑識層，例如執行痕跡、BYOVD 濫用、HWID 不符，以及透過外部 hollows_hunter 進行的記憶體完整性檢查。它使用離線參考資料庫（PCI ID、USB ID、LOLDrivers），並採用保守的風險引擎產生可解釋的 JSON 判定結果，不會自動封禁；還支援將結果上傳至自架伺服器供管理員人工審核。可選的 C++ KMDF 核心驅動可在實驗環境中進行有邊界的 PCI 證據採集。此工具用於反作弊調查與硬體完整性稽核，而非作為作弊的密碼學證明或 DMA 攻擊工具包。
