IronTrace è uno scanner di integrità hardware e forense per Windows destinato agli amministratori di server di gioco che devono esaminare i computer dei giocatori alla ricerca di segnali legati ai cheat. Sviluppato principalmente in C#, include un'app desktop WPF, una CLI headless e un server ASP.NET Core opzionale; raccoglie prove su sicurezza della piattaforma, dispositivi PCI/PCIe e USB, driver, indicatori di mascheramento DMA e livelli forensi opzionali come artefatti di esecuzione, abuso BYOVD, discrepanze HWID e integrità della memoria tramite hollows_hunter esterno. Usa database di riferimento offline per ID PCI, ID USB e LOLDrivers, applica un motore di rischio conservativo che produce verdetti JSON spiegabili senza ban automatici e supporta il caricamento opzionale su un server self-hosted per triage umano da parte degli amministratori. Un driver kernel KMDF opzionale scritto in C++ consente raccolta limitata di prove PCI per uso in laboratorio. È pensato per indagini anti-cheat e audit di integrità hardware, non come prova crittografica di cheat o toolkit per attacchi DMA.
