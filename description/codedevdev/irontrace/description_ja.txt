IronTrace は、ゲームサーバー管理者がプレイヤー端末のチート関連シグナルを確認するための Windows 向けハードウェアおよびフォレンジック整合性スキャナーです。主に C# で構築され、WPF デスクトップアプリ、ヘッドレス CLI、任意の ASP.NET Core サーバーを備え、プラットフォームセキュリティ、PCI/PCIe および USB デバイス、ドライバー、DMA 偽装の指標などの証拠を収集します。実行アーティファクト、BYOVD 悪用、HWID の不一致、外部 hollows_hunter によるメモリ整合性チェックなど、任意のフォレンジック層にも対応します。PCI ID、USB ID、LOLDrivers のオフライン参照データベースを使用し、保守的なリスクエンジンで説明可能な JSON 判定を生成しますが、自動 BAN は行いません。任意で自前ホストのサーバーへアップロードし、管理者による人的トリアージも可能です。C++ で書かれた任意の KMDF カーネルドライバーは、ラボ用途向けに限定的な PCI 証拠収集を提供します。アンチチート調査およびハードウェア整合性監査を目的としており、チートの暗号学的証明や DMA 攻撃ツールキットとしては意図されていません。
