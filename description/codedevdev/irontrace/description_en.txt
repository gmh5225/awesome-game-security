IronTrace is a Windows hardware and forensic integrity scanner for game-server administrators who need to review player machines for cheating-related signals. Built primarily in C# with a WPF desktop app, headless CLI, and optional ASP.NET Core server, it collects evidence about platform security, PCI/PCIe and USB devices, drivers, DMA masquerade indicators, and optional forensic layers such as execution artifacts, BYOVD abuse, HWID mismatches, and memory integrity via external hollows_hunter. It uses offline reference databases for PCI IDs, USB IDs, and LOLDrivers, applies a conservative risk engine that produces explainable JSON verdicts without auto-banning, and supports optional upload to a self-hosted server for human admin triage. An optional KMDF kernel driver written in C++ provides bounded PCI evidence collection for lab use. It is intended for anti-cheat investigation and hardware integrity auditing, not as cryptographic proof of cheating or a DMA attack toolkit.
