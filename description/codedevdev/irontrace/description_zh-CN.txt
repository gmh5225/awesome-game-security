IronTrace 是一款面向游戏服务器管理员的 Windows 硬件与取证完整性扫描器，用于审查玩家机器上的作弊相关信号。项目主要使用 C# 开发，包含 WPF 桌面应用、无界面 CLI 以及可选的 ASP.NET Core 服务端，可收集平台安全、PCI/PCIe 与 USB 设备、驱动程序、DMA 伪装指标等证据，并可选启用取证层，例如执行痕迹、BYOVD 滥用、HWID 不匹配，以及通过外部 hollows_hunter 进行的内存完整性检查。它使用离线参考数据库（PCI ID、USB ID、LOLDrivers），并采用保守的风险引擎生成可解释的 JSON 判定结果，不会自动封禁；还支持将结果上传至自托管服务器供管理员人工审核。可选的 C++ KMDF 内核驱动可在实验环境中进行有边界的 PCI 证据采集。该工具用于反作弊调查与硬件完整性审计，而非作为作弊的密码学证明或 DMA 攻击工具包。
