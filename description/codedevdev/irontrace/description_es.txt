IronTrace es un escáner de integridad forense y de hardware para Windows dirigido a administradores de servidores de juegos que necesitan revisar las máquinas de los jugadores en busca de señales relacionadas con trampas. Desarrollado principalmente en C#, incluye una aplicación de escritorio WPF, una CLI sin interfaz y un servidor ASP.NET Core opcional; recopila evidencia sobre seguridad de la plataforma, dispositivos PCI/PCIe y USB, controladores, indicadores de enmascaramiento DMA y capas forenses opcionales como artefactos de ejecución, abuso BYOVD, discrepancias de HWID e integridad de memoria mediante hollows_hunter externo. Utiliza bases de datos de referencia sin conexión para identificadores PCI, USB y LOLDrivers, aplica un motor de riesgo conservador que produce veredictos JSON explicables sin baneos automáticos y admite carga opcional a un servidor autohospedado para triaje humano por administradores. Un controlador de kernel KMDF opcional escrito en C++ proporciona recopilación acotada de evidencia PCI para uso en laboratorio. Está pensado para investigación antitrampas y auditoría de integridad de hardware, no como prueba criptográfica de trampas ni como kit de ataque DMA.
