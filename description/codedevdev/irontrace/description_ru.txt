IronTrace — сканер аппаратной и форензической целостности для Windows, предназначенный администраторам игровых серверов, которым нужно проверять компьютеры игроков на признаки, связанные с читами. Разработан в основном на C# и включает настольное приложение WPF, headless CLI и опциональный сервер ASP.NET Core; собирает сведения о безопасности платформы, устройствах PCI/PCIe и USB, драйверах, индикаторах маскировки DMA, а также опциональные форензические слои: артефакты выполнения, злоупотребление BYOVD, несоответствия HWID и проверку целостности памяти через внешний hollows_hunter. Используются офлайн-справочники PCI ID, USB ID и LOLDrivers; консервативный движок риска формирует объяснимые JSON-вердикты без автоматических банов. Поддерживается опциональная загрузка на самохостинг-сервер для ручной проверки администраторами. Опциональный драйвер ядра KMDF на C++ обеспечивает ограниченный сбор PCI-доказательств для лабораторного использования. Инструмент предназначен для расследований античита и аудита аппаратной целостности, а не как криптографическое доказательство читов или набор для DMA-атак.
