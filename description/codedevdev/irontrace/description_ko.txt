IronTrace는 게임 서버 관리자가 플레이어 PC의 치트 관련 신호를 검토할 수 있도록 하는 Windows 하드웨어 및 포렌식 무결성 스캐너입니다. 주로 C#으로 구축되었으며 WPF 데스크톱 앱, 헤드리스 CLI, 선택적 ASP.NET Core 서버를 제공하고, 플랫폼 보안, PCI/PCIe 및 USB 장치, 드라이버, DMA 위장 지표 등의 증거를 수집합니다. 실행 아티팩트, BYOVD 남용, HWID 불일치, 외부 hollows_hunter를 통한 메모리 무결성 검사 등 선택적 포렌식 계층도 지원합니다. PCI ID, USB ID, LOLDrivers용 오프라인 참조 데이터베이스를 사용하며, 보수적인 위험 엔진으로 설명 가능한 JSON 판정을 생성하지만 자동 밴은 하지 않습니다. 선택적으로 자체 호스팅 서버에 업로드하여 관리자의 수동 트리아지를 지원합니다. C++로 작성된 선택적 KMDF 커널 드라이버는 실험실 용도의 제한된 PCI 증거 수집을 제공합니다. 치트의 암호학적 증명이나 DMA 공격 툴킷이 아니라, 안티치트 조사 및 하드웨어 무결성 감사를 위한 도구입니다.
