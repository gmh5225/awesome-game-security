IronTrace ist ein Windows-Hardware- und Forensik-Integritätsscanner für Game-Server-Administratoren, die Spieler-PCs auf cheatbezogene Signale prüfen müssen. Hauptsächlich in C# entwickelt, umfasst er eine WPF-Desktop-App, eine headless CLI und einen optionalen ASP.NET-Core-Server; er sammelt Belege zu Plattformsicherheit, PCI/PCIe- und USB-Geräten, Treibern, DMA-Tarnungsindikatoren sowie optionalen Forensik-Ebenen wie Ausführungsartefakten, BYOVD-Missbrauch, HWID-Abweichungen und Speicherintegrität über externen hollows_hunter. Offline-Referenzdatenbanken für PCI-IDs, USB-IDs und LOLDrivers werden genutzt; eine konservative Risiko-Engine erzeugt nachvollziehbare JSON-Urteile ohne automatische Bans. Optional können Ergebnisse auf einen selbst gehosteten Server hochgeladen werden, damit Administratoren manuell triagieren. Ein optionaler in C++ geschriebener KMDF-Kerneltreiber ermöglicht begrenzte PCI-Belegsammlung für Laboreinsätze. Er ist für Anti-Cheat-Ermittlungen und Hardware-Integritätsaudits gedacht, nicht als kryptografischer Cheat-Nachweis oder DMA-Angriffs-Toolkit.
