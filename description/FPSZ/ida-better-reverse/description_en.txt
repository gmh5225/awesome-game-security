IDA Better Reverse is an IDA Pro plugin aimed at stripped, statically linked Linux binaries—the kind common in CTF reversing, pwn challenges, and much Linux malware analysis. Written in Python, it fingerprints the linked C runtime (glibc or musl down to the release), applies build-specific FLIRT signatures to recover libc and GCC runtime names and prototypes, and hooks the Hex-Rays decompiler to explain libc calls, system calls, and SIMD intrinsic chains beside the pseudocode. It also offers per-variable data-flow views and nested, zoomable function flowcharts for reading program logic, with an optional headless CLI for libc detection without launching IDA. It targets IDA Pro 7.4 through 9.x on x86-64, i386, and AArch64, and ships bundled signature data with journal-based undo for plugin changes.
