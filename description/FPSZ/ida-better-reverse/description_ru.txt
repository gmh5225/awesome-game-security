IDA Better Reverse — плагин для IDA Pro, ориентированный на лишённые символов статически слинкованные Linux-бинарники, типичные для CTF-реверса, pwn-задач и многих сценариев анализа Linux-вредоносов. Написан на Python: определяет связанную C-среду выполнения (glibc или musl с точностью до релиза), применяет FLIRT-сигнатуры под конкретную сборку для восстановления имён и прототипов libc и GCC runtime и перехватывает декомпилятор Hex-Rays, чтобы пояснять вызовы libc, системные вызовы и цепочки SIMD-интринсиков рядом с псевдокодом. Также даёт представления потока данных по переменным и вложенные масштабируемые блок-схемы функций для чтения логики программы, с опциональной headless CLI для определения libc без запуска IDA. Поддерживает IDA Pro 7.4–9.x на x86-64, i386 и AArch64; поставляется с наборами сигнатур и журнальным откатом изменений плагина.
