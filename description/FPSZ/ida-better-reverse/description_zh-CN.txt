IDA Better Reverse 是一款面向已剥离符号、静态链接的 Linux 二进制文件的 IDA Pro 插件，这类样本常见于 CTF 逆向、pwn 题目以及大量 Linux 恶意软件分析。插件用 Python 编写，可识别所链接的 C 运行时（glibc 或 musl，精确到发行版本），并应用针对特定构建的 FLIRT 签名以恢复 libc 与 GCC 运行时的符号名与函数原型；同时挂钩 Hex-Rays 反编译器，在伪代码旁解释 libc 调用、系统调用及 SIMD 内建函数链。它还提供按变量的数据流视图以及可嵌套、可缩放的函数流程图，便于阅读程序逻辑，并可选无界面 CLI 在不启动 IDA 的情况下检测 libc。支持 IDA Pro 7.4 至 9.x，架构涵盖 x86-64、i386 与 AArch64，内置签名数据并支持基于日志的撤销以回退插件改动。
