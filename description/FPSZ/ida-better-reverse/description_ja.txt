IDA Better Reverse は、シンボルが剥がされた静的リンク Linux バイナリ向けの IDA Pro プラグインで、CTF リバース、pwn 課題、多くの Linux マルウェア解析でよく見られるタイプを対象としています。Python で書かれ、リンクされた C ランタイム（glibc または musl をリリース単位まで）を指紋認識し、ビルド固有の FLIRT シグネチャを適用して libc と GCC ランタイムの名前とプロトタイプを復元し、Hex-Rays デコンパイラにフックして疑似コードの横で libc 呼び出し、システムコール、SIMD イントリンシックチェーンを説明します。変数ごとのデータフロー表示や、ネスト可能でズーム可能な関数フローチャートでプログラムの論理を読みやすくし、IDA を起動せずに libc を検出するヘッドレス CLI も任意で利用できます。IDA Pro 7.4 から 9.x、x86-64、i386、AArch64 を対象とし、バンドルされたシグネチャデータとプラグイン変更のジャーナルベースの取り消しを同梱しています。
