IDA Better Reverse es un complemento de IDA Pro orientado a binarios Linux enlazados estáticamente y sin símbolos, del tipo habitual en reversing de CTF, retos pwn y gran parte del análisis de malware en Linux. Escrito en Python, identifica la biblioteca C enlazada (glibc o musl hasta la versión de release), aplica firmas FLIRT específicas de cada compilación para recuperar nombres y prototipos de libc y del runtime de GCC, y se engancha al descompilador Hex-Rays para explicar junto al pseudocódigo las llamadas a libc, las llamadas al sistema y las cadenas de intrínsecos SIMD. También ofrece vistas de flujo de datos por variable y diagramas de flujo de funciones anidables y con zoom para leer la lógica del programa, con una CLI headless opcional para detectar libc sin abrir IDA. Compatible con IDA Pro 7.4 a 9.x en x86-64, i386 y AArch64; incluye datos de firmas empaquetados y deshacer basado en journal para cambios del plugin.
