IDA Better Reverse는 심볼이 제거된 정적 링크 Linux 바이너리를 위한 IDA Pro 플러그인으로, CTF 리버싱, pwn 문제, 많은 Linux 악성코드 분석에서 흔히 볼 수 있는 유형을 겨냥합니다. Python으로 작성되었으며, 링크된 C 런타임(glibc 또는 musl, 릴리스 단위까지)을 지문으로 식별하고, 빌드별 FLIRT 시그니처를 적용해 libc 및 GCC 런타임 이름과 프로토타입을 복구하며, Hex-Rays 디컴파일러에 후킹해 의사코드 옆에서 libc 호출, 시스템 호출, SIMD 내장 함수 체인을 설명합니다. 변수별 데이터 흐름 보기와 중첩·확대 가능한 함수 플로우차트로 프로그램 로직을 읽기 쉽게 하고, IDA를 실행하지 않고 libc를 감지하는 헤드리스 CLI도 선택적으로 제공합니다. IDA Pro 7.4~9.x, x86-64, i386, AArch64를 지원하며, 번들 시그니처 데이터와 플러그인 변경에 대한 저널 기반 실행 취소를 포함합니다.
