IDA Better Information は、手動解析の前にバイナリから libc やコンパイラの文脈を自動復元する、単一ファイルの IDA Pro プラグインおよびスタンドアロン Python CLI です。埋め込みバイトフィンガープリントにより、glibc、musl、Go、MSVC ランタイムのバージョン（シンボル除去済み・静的リンクの Linux ターゲットを含む）を検出し、一致する FLIRT シグネチャを適用してライブラリ関数名を復元できます。呼び出し箇所に libc の用途コメントを付け、デコンパイラ注釈では実引数と MMX・SSE イントリンシックの素の数学的意味を解説します。二言語 UI、ワンクリック取り消し、完全オフライン動作に対応。IDA 上で難読化やシンボル除去されたゲーム・ネイティブバイナリの把握を早めたいリバースエンジニアや CTF 解析者向けです。
