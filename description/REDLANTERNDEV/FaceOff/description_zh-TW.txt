FaceOff 是一款 Windows 實用工具，可讓您在不玩遊戲時停用 FACEIT 的內核反作弊，並在下一场比赛前重新啟用。它以 C# 建置，為附小型 CLI 的 WPF 桌面應用程式，可切換 FACEIT 內核驅動程式、FACEITService Windows 服務及相關用戶端程序，同時在本機持久保存原始設定。由於 FACEIT 僅接受在開機時載入的驅動程式，在開啟或關閉保護時，此工具會引導您以系統管理員權限提升並重新啟動。批次指令碼可在不執行可執行檔的情況下提供相同行為。面向競技 FPS 玩家及注重資訊安全的用戶，希望在不必解除安裝 FACEIT 的前提下限制常駐內核反作弊的暴露。
