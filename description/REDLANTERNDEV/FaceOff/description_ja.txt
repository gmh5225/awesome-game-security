FaceOff は Windows 向けユーティリティで、プレイしていない間は FACEIT のカーネルアンチチートを無効にし、次のマッチの前に再有効化できます。C# で構築された WPF デスクトップアプリと小型 CLI により、FACEIT カーネルドライバー、FACEITService Windows サービス、関連クライアントプロセスを切り替え、元の設定をローカルに永続保存します。FACEIT は起動時に読み込まれたドライバーのみ受け付けるため、保護のオン／オフ時には管理者昇格と再起動を案内します。バッチスクリプトでも実行ファイルなしで同じ動作が可能です。FACEIT をアンインストールせず、常時オンのカーネルアンチチートへの露出を抑えたい競技 FPS プレイヤーやセキュリティ意識の高いユーザー向けです。
