FaceOff — утилита для Windows, которая позволяет отключать kernel anti-cheat FACEIT, когда вы не играете, и снова включать его перед следующим матчем. Написана на C# как настольное WPF-приложение с небольшим CLI; переключает kernel-драйвер FACEIT, службу Windows FACEITService и связанные клиентские процессы, сохраняя исходные настройки локально. Поскольку FACEIT принимает только драйвер, загруженный при загрузке системы, инструмент проводит через повышение прав администратора и перезагрузку при включении или выключении защиты. Пакетные сценарии обеспечивают то же поведение без исполняемого файла. Предназначена для соревновательных FPS-игроков и пользователей, заботящихся о безопасности, которые хотят ограничить постоянное воздействие kernel anti-cheat без удаления FACEIT.
