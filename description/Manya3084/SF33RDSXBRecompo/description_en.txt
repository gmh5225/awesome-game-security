SF33RDSXBRecompo is a native x86-64 port of Street Fighter III: 3rd Strike that runs the decompiled Xbox game logic on Linux and Windows without building any original Xbox runtime code. The project reimplements platform services in C with SDL3 for windowing and input, Vulkan or OpenGL for rendering (including NV2A-style draws), OpenAL for ADX, AIX, and XACT cue playback, and SQLite for saves, while importing assets from a user-supplied Xbox disc image or extracted XBE and AFS tree. It includes tooling and library code for reading XBE headers, XDVDFS volumes, and disc archives, plus Python helpers tied to the ogxb decompilation pipeline. CMake drives the build, with optional Android packaging and shader and stub generation utilities for maintaining parity with retail behavior. It targets developers and researchers interested in reverse engineering, console binary preservation, and studying how decompiled game code can be rehosted on modern desktops legally using owned disc data.
