SF33RDSXBRecompo は Street Fighter III: 3rd Strike のネイティブ x86-64 ポートで、元の Xbox ランタイムをビルドすることなく、Linux と Windows 上でデコンパイルされた Xbox ゲームロジックを動かします。SDL3 によるウィンドウと入力、Vulkan または OpenGL による描画（NV2A 風の描画を含む）、ADX・AIX・XACT キュー再生の OpenAL、セーブ用 SQLite など、プラットフォームサービスを C で再実装し、ユーザー提供の Xbox ディスクイメージ、または抽出した XBE と AFS ツリーからアセットを取り込みます。XBE ヘッダ、XDVDFS ボリューム、ディスクアーカイブを読むツールとライブラリ、ogxb デコンパイルパイプライン向けの Python ヘルパーも含みます。ビルドは CMake が担い、Android パッケージングや、小売版の挙動との整合を保つシェーダー・スタブ生成ユーティリティも任意で利用できます。リバースエンジニアリング、コンソールバイナリ保存、所有ディスクデータを使ってデコンパイルされたゲームコードを現代デスクトップに合法的に再ホストする研究に関心のある開発者・研究者向けです。
