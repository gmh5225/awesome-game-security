SF33RDSXBRecompo — нативный порт x86-64 Street Fighter III: 3rd Strike, запускающий декомпилированную игровую логику Xbox на Linux и Windows без сборки оригинального runtime Xbox. Проект перереализует платформенные сервисы на C: SDL3 для окна и ввода, Vulkan или OpenGL для рендеринга (включая отрисовку в стиле NV2A), OpenAL для воспроизведения ADX, AIX и XACT cue, SQLite для сохранений; ресурсы импортируются из образа диска Xbox пользователя или извлечённых XBE и дерева AFS. Включены инструменты и библиотеки для чтения заголовков XBE, томов XDVDFS и дисковых архивов, а также Python-утилиты для пайплайна декомпиляции ogxb. Сборку ведёт CMake, с опциональной упаковкой под Android и утилитами генерации шейдеров и заглушек для соответствия retail-поведению. Для разработчиков и исследователей, интересующихся реверс-инжинирингом, сохранением консольных бинарников и законным ре-хостингом декомпилированного кода на современных ПК с использованием собственных данных с диска.
