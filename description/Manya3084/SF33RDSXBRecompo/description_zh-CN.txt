SF33RDSXBRecompo 是《街头霸王 III：3rd Strike》的原生 x86-64 移植版，在 Linux 与 Windows 上运行经反编译的 Xbox 游戏逻辑，而无需编译任何原始 Xbox 运行时代码。项目以 C 语言重新实现平台服务：SDL3 负责窗口与输入，Vulkan 或 OpenGL 负责渲染（含 NV2A 风格绘制），OpenAL 播放 ADX、AIX 与 XACT 音效提示，SQLite 用于存档，并从用户提供的 Xbox 光盘镜像或提取出的 XBE 与 AFS 目录树导入资源。此外还包含用于读取 XBE 头、XDVDFS 卷与光盘归档的工具及库代码，以及与 ogxb 反编译流水线配套的 Python 辅助脚本。构建由 CMake 驱动，可选 Android 打包，并提供着色器与桩代码生成工具以保持与零售版行为一致。面向对逆向工程、主机二进制保全，以及如何在合法使用自有光盘数据的前提下于现代桌面重托管反编译游戏代码感兴趣的开发者和研究人员。
