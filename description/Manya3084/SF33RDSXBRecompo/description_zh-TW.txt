SF33RDSXBRecompo 是《Street Fighter III: 3rd Strike》的原生 x86-64 移植版，在 Linux 與 Windows 上執行經反編譯的 Xbox 遊戲邏輯，無需建置任何原始 Xbox 執行階段程式碼。專案以 C 重新實作平台服務：SDL3 負責視窗與輸入，Vulkan 或 OpenGL 負責渲染（含 NV2A 風格繪製），OpenAL 播放 ADX、AIX 與 XACT 音效提示，SQLite 用於存檔，並從使用者提供的 Xbox 光碟映像或解出的 XBE 與 AFS 目錄樹匯入資產。另包含讀取 XBE 標頭、XDVDFS 磁區與光碟封存檔的工具與函式庫程式碼，以及與 ogxb 反編譯管線搭配的 Python 輔助腳本。建置由 CMake 驅動，可選 Android 打包，並提供著色器與 stub 產生工具以維持與零售版行為一致。面向對逆向工程、主機二進位保存，以及在合法使用自有光碟資料的前提下於現代桌面重託管反編譯遊戲程式感興趣的開發者與研究人員。
