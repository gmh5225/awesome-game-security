SF33RDSXBRecompo es un port nativo x86-64 de Street Fighter III: 3rd Strike que ejecuta la lógica de juego Xbox descompilada en Linux y Windows sin compilar código de runtime Xbox original. El proyecto reimplementa servicios de plataforma en C con SDL3 para ventana e entrada, Vulkan u OpenGL para renderizado (incluidos dibujos estilo NV2A), OpenAL para reproducción de cues ADX, AIX y XACT, y SQLite para partidas guardadas, importando assets desde una imagen de disco Xbox del usuario o un XBE extraído y árbol AFS. Incluye herramientas y código de biblioteca para leer cabeceras XBE, volúmenes XDVDFS y archivos de disco, más ayudantes Python ligados al pipeline de descompilación ogxb. CMake impulsa la compilación, con empaquetado Android opcional y utilidades de generación de shaders y stubs para mantener paridad con el comportamiento retail. Está dirigido a desarrolladores e investigadores interesados en ingeniería inversa, preservación de binarios de consola y en estudiar cómo rehospedar legalmente código de juego descompilado en escritorios modernos usando datos de disco propios.
