Gatewarden is a low-poly 3D tower defense prototype in Godot 4.7 where players place enemy spawn gates and sculpt the battlefield with walls before waves begin. Its anti-abuse placement rules are published as a first-class system rather than hidden clamps, using a PathValidator that hypothetically blocks cells and runs scratch flow-field checks to reject maze-juggling or softlock layouts with stable machine-readable reason codes. The project is implemented in GDScript with a fixed 30 Hz deterministic simulation, Dijkstra flow-field pathfinding, and strict performance gates enforced by 59 GUT unit and integration tests including a headless bot that plays full runs. It serves as a reference for designing transparent, test-driven anti-cheat and validation systems in player-authored tower defense scenarios.
