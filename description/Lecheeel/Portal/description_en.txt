Portal is an Android application for virtual location and environment spoofing, letting you drive fake positions, routes, and device context into other apps without moving physically. It is built mainly in Kotlin and Java with optional native C++ hooks, and can run through standard mock-location mode, Xposed or LSPosed (libxposed API 102), or an experimental root plus native hook stack. Core capabilities include GPS, network, and fused location simulation with route playback and floating joystick controls, multi-constellation GNSS and NMEA synthesis, Wi-Fi and cell-environment capture or replay, and experimental carrier or SIM identity spoofing, plus anti-detection measures such as stack-trace cleaning and mock-flag handling. A companion detector module helps validate what location and sensor APIs actually expose to apps. It is aimed at security researchers, reverse engineers, and developers who need to probe or benchmark location-based game protections and anti-cheat checks on rooted or Xposed-enabled devices.
