Portal 是一款用于虚拟定位与环境伪造的 Android 应用，可在不实际移动的情况下，将虚假位置、路线与设备上下文注入其他应用。项目主要以 Kotlin 与 Java 编写，并可选原生 C++ 钩子，可通过标准模拟定位模式、Xposed 或 LSPosed（libxposed API 102），或实验性的 root 加原生钩子栈运行。核心能力包括 GPS、网络与融合定位模拟、路线回放与悬浮摇杆控制、多星座 GNSS 与 NMEA 合成、Wi-Fi 与蜂窝环境采集或回放，以及实验性的运营商或 SIM 身份伪造，并附带栈追踪清理与模拟标志处理等反检测措施。配套的检测模块可帮助验证应用实际从定位与传感器 API 获取到的内容。面向安全研究人员、逆向工程师与开发者，用于在已 root 或启用 Xposed 的设备上探测、压测基于位置的游戏防护与反作弊检测。
