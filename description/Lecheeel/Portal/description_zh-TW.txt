Portal 是一款用於虛擬定位與環境偽造的 Android 應用程式，可在不實際移動的情況下，將假位置、路線與裝置上下文注入其他應用程式。專案主要以 Kotlin 與 Java 撰寫，並可選原生 C++ 掛鉤，可透過標準模擬定位模式、Xposed 或 LSPosed（libxposed API 102），或實驗性的 root 加原生掛鉤堆疊執行。核心能力包括 GPS、網路與融合定位模擬、路線回放與浮動搖桿控制、多星座 GNSS 與 NMEA 合成、Wi-Fi 與行動網路環境擷取或回放，以及實驗性的電信業者或 SIM 身分偽造，並附帶堆疊追蹤清理與模擬旗標處理等反偵測措施。配套的偵測模組可協助驗證應用程式實際從定位與感測器 API 取得的內容。面向安全研究人員、逆向工程師與開發者，用於在已 root 或啟用 Xposed 的裝置上探測、壓測以位置為基礎的遊戲防護與反作弊檢測。
