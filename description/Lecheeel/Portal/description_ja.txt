Portal は、仮想位置と環境の偽装向け Android アプリで、実際に移動しなくても他アプリへ偽の位置・経路・デバイスコンテキストを注入できます。主に Kotlin と Java で構築され、必要に応じてネイティブ C++ フックを利用し、標準のモック位置モード、Xposed または LSPosed（libxposed API 102）、あるいは実験的な root ＋ネイティブフック構成で動作します。GPS・ネットワーク・融合位置のシミュレーション、経路再生とフローティングジョイスティック、多星座 GNSS と NMEA 合成、Wi-Fi とセル環境の取得または再生、実験的なキャリアや SIM アイデンティティの偽装、スタックトレースのクリーニングやモックフラグ処理などの検知回避機能が中核です。コンパニオンの検出モジュールで、アプリに実際に公開される位置・センサー API の挙動を検証できます。root 済みや Xposed 有効端末上で、位置ベースのゲーム保護やアンチチートを調査・ベンチマークするセキュリティ研究者、リバースエンジニア、開発者向けです。
