TShock は Terraria マルチプレイサーバー向けのサーバーサイド MOD 兼管理ツールボックスで、Terraria Server API 上のプラグインとして構築されています。C# と .NET で書かれており、中核となる Bouncer はアンチチート・アンチハック層で、ネットワークパケットとプレイヤーの操作を検査してエクスプロイトやグリーフィングを阻止します。サーバーサイドキャラクター、権限グループ、アイテム BAN、リージョン、ワープ、豊富なコマンドセットも提供し、SQLite、MySQL、PostgreSQL をバックエンドとして利用でき、REST インターフェースと拡張可能なプラグインシステムも備えています。Terraria の既知のネットワーク脆弱性に対するプロトコルガードとパッチも追加しており、チートや悪用からコミュニティゲームサーバーを保護・運用するサーバー管理者向けの主要ツールです。
