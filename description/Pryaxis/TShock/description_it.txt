TShock è una mod lato server e una toolbox di gestione per server multigiocatore di Terraria, realizzata come plugin sull'API Terraria Server. Scritto in C# per .NET, ruota attorno a Bouncer, uno strato anti-cheat e anti-hack che ispeziona i pacchetti di rete e le azioni dei giocatori per bloccare exploit e griefing. Offre anche personaggi lato server, gruppi di permessi, ban degli oggetti, regioni, warp e un ampio set di comandi, supportato da SQLite, MySQL o PostgreSQL e reso disponibile tramite un'interfaccia REST e un sistema di plugin estensibile. Il progetto aggiunge guardie di protocollo e patch per le note vulnerabilità di rete di Terraria, rendendolo uno strumento principale per gli operatori di server che devono proteggere e amministrare server di gioco comunitari contro cheating e abusi.
