TShock es un mod del lado del servidor y caja de herramientas de administración para servidores multijugador de Terraria, construido como complemento sobre la API Terraria Server. Escrito en C# para .NET, se centra en Bouncer, una capa antitrampas y antihack que inspecciona paquetes de red y acciones de los jugadores para bloquear exploits y griefing. También ofrece personajes del lado del servidor, grupos de permisos, prohibiciones de objetos, regiones, warps y un amplio conjunto de comandos, respaldado por SQLite, MySQL o PostgreSQL y expuesto mediante una interfaz REST y un sistema de plugins extensible. El proyecto añade protecciones de protocolo y parches para fallos de red conocidos de Terraria, lo que lo convierte en una herramienta principal para operadores de servidores que necesitan asegurar y administrar servidores comunitarios contra trampas y abusos.
