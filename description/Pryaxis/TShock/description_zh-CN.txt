TShock 是面向 Terraria 多人游戏服务器的服务端模组与管理工具箱，基于 Terraria Server API 以插件形式构建。该项目使用 C# 编写，运行于 .NET，核心组件 Bouncer 是一套反作弊与反外挂层，通过检查网络数据包与玩家行为来阻止漏洞利用和恶意破坏。它还提供服务端角色、权限组、物品封禁、区域、传送点以及丰富的命令集，并支持 SQLite、MySQL 或 PostgreSQL 作为后端，同时提供 REST 接口与可扩展的插件系统。该项目还针对 Terraria 已知网络协议缺陷添加了协议防护与补丁，是服务器管理员用于保护和管理社区游戏服务器、防范作弊与滥用的主要工具。
