TShock은 Terraria 멀티플레이 서버를 위한 서버 측 모드 및 관리 도구 모음으로, Terraria Server API 위의 플러그인으로 구축되었습니다. C#과 .NET으로 작성되었으며, 핵심인 Bouncer는 네트워크 패킷과 플레이어 행동을 검사하여 익스플로잇과 그리핑을 차단하는 안티치트·안티핵 레이어입니다. 서버 측 캐릭터, 권한 그룹, 아이템 금지, 지역, 워프, 방대한 명령어 세트도 제공하며, SQLite, MySQL 또는 PostgreSQL을 백엔드로 지원하고 REST 인터페이스와 확장 가능한 플러그인 시스템을 제공합니다. Terraria의 알려진 네트워킹 결함에 대한 프로토콜 가드와 패치도 추가하여, 치팅과 남용으로부터 커뮤니티 게임 서버를 보호하고 관리해야 하는 서버 운영자를 위한 핵심 도구입니다.
