TShock 是面向 Terraria 多人遊戲伺服器的伺服端模組與管理工具箱，以 Terraria Server API 外掛形式建構。此專案以 C# 撰寫，運行於 .NET，核心元件 Bouncer 是一套反作弊與反外掛層，透過檢查網路封包與玩家行為來阻擋漏洞利用與惡意破壞。它還提供伺服端角色、權限群組、物品封禁、區域、傳送點以及豐富的指令集，並支援 SQLite、MySQL 或 PostgreSQL 作為後端，同時提供 REST 介面與可擴充的外掛系統。此專案也針對 Terraria 已知的網路協定缺陷加入協定防護與修補，是伺服器管理員用於保護與管理社群遊戲伺服器、防範作弊與濫用的主要工具。
