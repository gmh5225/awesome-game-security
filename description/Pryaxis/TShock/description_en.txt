TShock is a server-side mod and management toolbox for Terraria multiplayer servers, built as a plugin on the Terraria Server API. Written in C# for .NET, it centers on Bouncer, an anti-cheat and anti-hack layer that inspects network packets and player actions to block exploits and griefing. It also provides server-side characters, permission groups, item bans, regions, warps, and a large command set, backed by SQLite, MySQL, or PostgreSQL and exposed through a REST interface and extensible plugin system. The project adds protocol guards and patches for known Terraria networking flaws, making it a primary tool for server operators who need to secure and administer community game servers against cheating and abuse.
