Orchard Obliterator는 Orchard Minecraft 치트 클라이언트를 감지·보고하고 필요 시 무력화하는 Windows 콘솔 도구입니다. C#으로 작성되었으며 .NET Framework용이며, JAR 내용, mixin 훅, 은신 및 전투 동작, 메모리 문자열, 관련 원격 측정 흔적과 일치하는 지문 규칙을 내장 서명 파일로 제공합니다. 스캐너는 실행 중인 Java 및 Fabric 게임 프로세스를 열거하고, 허용되면 로드된 모듈과 프로세스 메모리를 검사하며, Minecraft 게임 및 mods 폴더를 순회하고, 권한 상승 실행 시 드라이브 전체 심층 검색과 USN 저널 및 Prefetch 포렌식을 수행할 수 있습니다. 운영자는 포렌식 보고서 생성, 영향받은 게임 종료, 의심 아카이브 격리, 폴더와 새 Java 프로세스를 감시하는 상시 가드 모드를 실행할 수 있습니다. 멀티플레이 Minecraft 무결성 작업, 클라이언트 측 치트 추적, Windows 호스트에서의 실무적 안티치트 또는 운영·중재에 맞춰져 있습니다.
