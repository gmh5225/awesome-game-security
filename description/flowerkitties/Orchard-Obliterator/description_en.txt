Orchard Obliterator is a Windows console tool that detects, reports on, and optionally neutralizes the Orchard Minecraft cheat client. It is written in C# for .NET Framework and ships fingerprint rules in an embedded signature file that match JAR contents, mixin hooks, stealth and combat behaviors, memory strings, and related telemetry artifacts. The scanner enumerates running Java and Fabric game processes, inspects loaded modules and process memory when permitted, walks Minecraft game and mods folders, and can perform deep drive sweeps plus USN journal and prefetch forensics when run elevated. Operators can generate forensic reports, terminate affected games, quarantine suspicious archives, or run a persistent guard mode that watches folders and new Java processes. It is aimed at multiplayer Minecraft integrity work, client-side cheat hunting, and practical anti-cheat or moderation on Windows hosts.
