Orchard Obliterator — консольная утилита для Windows, которая обнаруживает, документирует и при необходимости нейтрализует чит-клиент Orchard для Minecraft. Написана на C# под .NET Framework и содержит встроенный файл сигнатур с правилами отпечатков, сопоставляющими содержимое JAR, mixin-хуки, скрытное и боевое поведение, строки в памяти и связанные телеметрические артефакты. Сканер перечисляет запущенные игровые процессы Java и Fabric, при разрешении проверяет загруженные модули и память процессов, обходит папки игры и модов Minecraft и при запуске с повышенными правами может выполнять глубокий обход дисков, а также форензику журнала USN и prefetch. Операторы могут формировать форензические отчёты, завершать затронутые игры, изолировать подозрительные архивы или запускать постоянный режим охраны, отслеживающий папки и новые процессы Java. Предназначена для обеспечения целостности многопользовательского Minecraft, поиска читов на стороне клиента и практической античит-работы или модерации на хостах Windows.
