Orchard Obliterator は、Orchard Minecraft チートクライアントを検出・報告し、必要に応じて無力化する Windows コンソールツールです。C# で .NET Framework 向けに書かれ、JAR 内容、mixin フック、ステルスや戦闘挙動、メモリ上の文字列、関連テレメトリ痕跡に一致する署名ルールを埋め込みシグネチャファイルとして同梱します。スキャナは実行中の Java および Fabric ゲームプロセスを列挙し、許可されていれば読み込み済みモジュールとプロセスメモリを調査し、Minecraft のゲームフォルダと mods フォルダを走査し、昇格実行時にはドライブ全体の深いスイープや USN ジャーナルおよび Prefetch のフォレンジックも行えます。運用者はフォレンジックレポートの生成、影響を受けたゲームの終了、疑わしいアーカイブの隔離、フォルダと新規 Java プロセスを監視する常駐ガードモードの実行が可能です。マルチプレイ Minecraft の整合性確保、クライアント側チート狩り、Windows ホスト上での実用的なアンチチートやモデレーションを目的としています。
