Orchard Obliterator 是一款 Windows 控制台工具，用于检测、报告并可选地遏制 Orchard Minecraft 作弊客户端。它使用 C# 编写，面向 .NET Framework，内置签名规则文件，可匹配 JAR 内容、mixin 挂钩、隐身与战斗行为、内存字符串及相关遥测痕迹。扫描器会枚举正在运行的 Java 与 Fabric 游戏进程，在允许时检查已加载模块与进程内存，遍历 Minecraft 游戏与 mods 目录，并在提升权限时可进行深度全盘扫描以及 USN 日志与 Prefetch 取证。操作人员可生成取证报告、终止受影响的游戏、隔离可疑压缩包，或运行持续守护模式以监视目录与新 Java 进程。适用于多人 Minecraft 完整性维护、客户端作弊搜寻，以及在 Windows 主机上开展实用的反作弊或管理工作。
