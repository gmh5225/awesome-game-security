Magisk Hub — это поддерживаемый сообществом статический каталог, который индексирует и документирует root-модули Android для Magisk, KernelSU и APatch. Создан на Astro с автоматизированными Python-скриптами синхронизации, которые каждые шесть часов получают нормализованные метаданные модулей и релизные ресурсы из upstream-репозиториев GitHub с проверкой JSON-схемы и актуальности данных. Каталог организует модули по категориям, таким как управление root, настройка производительности, сетевые прокси и инструментирование для разработки, охватывая инструменты вроде Frida, скрытия root и модулей обхода Play Integrity, используемых в мобильной безопасности. Многоуровневые записи Markdown и JSON содержат предварительные требования, заметки по настройке и прямые ссылки на скачивание сотен сторонних модулей. Предназначен для пользователей Android с root-доступом, reverse-инженеров и исследователей мобильной безопасности, которым нужен курируемый источник модулей обхода integrity, сокрытия root и инструментирования при тестировании защиты приложений и игр на root-устройствах.
