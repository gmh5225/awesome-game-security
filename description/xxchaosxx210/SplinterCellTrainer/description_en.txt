Splinter Assault Trainer is a Windows trainer for the classic Splinter Cell single-player client that combines a tray-based WPF front end with a native in-process helper to drive cheats, level loading, and live game manipulation. The C# layer attaches to SplinterCell.exe via OpenProcess and ReadProcessMemory for validation and ESP-style enemy overlays, while C++ modules implement Unreal-style object traversal, spawn registries, lock and light policies, camera control, and cheat state on the game thread. Users get overlay menus (including F6), options such as infinite health, unlimited ammo and gadgets, stealth tweaks, noclip, direct map loads from the main menu, and an NPC manager for spawning and tracking actors. The build pipeline compiles the native bridge and .NET app together and checks specific game DLL hashes for version safety. It is aimed at reverse engineers and modders studying external trainers, memory reading, and coordinated out-of-process UI with in-process game hooks on legacy titles.
