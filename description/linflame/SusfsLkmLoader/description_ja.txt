SUSFS LKM Loader は、Magisk・KernelSU・APatch に対応する root モジュールで、起動時に SUSFS ガード用カーネルモジュールを自動読み込みします。多くの Android および Linux カーネル版の組み合わせ向けにビルド済みカーネルオブジェクトを同梱し、インストール時に一致するバリアントを選び、同梱の insmod ヘルパーで SUSFS の proc 制御ノードを公開します。Action ボタン、WebUI、susfs4ksu-lkm からの毎日の上流同期を備えた next トラックと、最小インストールとマネージャ主導の更新に特化した legacy トラックを提供します。Shell と PowerShell のパッケージングスクリプトがモジュール zip、更新メタデータ、変更履歴を組み立て、ナイトリー配布向けに整えます。SUSFS によるファイルシステムおよびモジュール隠蔽に依存し、セキュリティに敏感なアプリやモバイル向けアンチチート・整合性チェックによる検知を抑えたい root ユーザー向けです。
