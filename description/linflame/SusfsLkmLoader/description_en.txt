SUSFS LKM Loader is a Magisk-, KernelSU-, and APatch-compatible root module that automatically loads the SUSFS guard kernel module at boot. It ships prebuilt kernel objects for many Android and Linux kernel version pairs, picks the matching variant at install time, and uses a bundled insmod helper to expose SUSFS proc control nodes. The project offers a next track with Action buttons, WebUI, and daily upstream sync from susfs4ksu-lkm, plus a legacy track focused on minimal install and manager-driven updates. Shell and PowerShell packaging scripts assemble module zips, update metadata, and changelogs for nightly distribution. It targets rooted Android users who rely on SUSFS filesystem and module hiding to reduce detection by security-sensitive apps and mobile anti-cheat or integrity checks.
