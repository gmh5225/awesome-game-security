SUSFS LKM Loader 是一款兼容 Magisk、KernelSU 与 APatch 的 root 模块，可在启动时自动加载 SUSFS 防护内核模块。它内置多种 Android 与 Linux 内核版本组合对应的预编译内核对象，安装时自动选择匹配变体，并通过捆绑的 insmod 辅助工具暴露 SUSFS 的 proc 控制节点。项目提供 next 轨道，含 Action 按钮、WebUI 以及从 susfs4ksu-lkm 的每日上游同步；另有 legacy 轨道，侧重最小化安装与由管理器驱动的更新。Shell 与 PowerShell 打包脚本会组装模块 zip、更新元数据与变更日志，供 nightly 分发。面向依赖 SUSFS 文件系统与模块隐藏、以降低安全敏感应用及手游反作弊或完整性检测风险的 root 用户。
