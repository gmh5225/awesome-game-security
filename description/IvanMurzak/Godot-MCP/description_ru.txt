Godot-MCP — это дополнение C# для редактора Godot, которое подключает агентов больших языковых моделей к редактору Godot через Model Context Protocol и сопрягается с внешним сервером GameDev MCP по SignalR. Оно предоставляет возможности редактора и среды выполнения как инструменты MCP, включая RQL для запроса и изменения сцен и ресурсов, выполнение и диагностику скриптов, снимки экрана, вызовы методов через reflection, логи консоли и опциональные модули расширения для популярных экосистем Godot. В проекте есть UI редактора для подключения к облачному или локальному серверу, аутентификация OAuth или по токену и однощелчковые конфигураторы агентов для распространённых AI-клиентов для кодирования, а также npm-пакет godot-cli для установки и headless-сценариев. Он ориентирован на разработчиков игр и технических пользователей, которым нужна работа с Godot и автоматизация с помощью ИИ, и на тех, кто изучает, как удалённые агенты управляют живым редактором и выполнением скриптов в игре, с документированными границами безопасности runtime для экспортированных сборок.
