Godot-MCP est un module complémentaire C# pour l’éditeur Godot qui relie des agents de grands modèles de langage à l’éditeur via le Model Context Protocol, en s’appariant avec un serveur GameDev MCP externe sur SignalR. Il expose les capacités de l’éditeur et du runtime sous forme d’outils MCP, notamment RQL pour interroger et modifier scènes et ressources, exécution et diagnostic de scripts, captures d’écran, appels de méthodes par réflexion, journaux console et modules d’extension optionnels pour les écosystèmes Godot courants. Le projet fournit une interface éditeur pour connexion cloud ou locale, authentification OAuth ou par jeton, et des configurateurs d’agents en un clic pour les clients de codage IA courants, plus un paquet npm godot-cli pour l’installation et les flux headless. Il s’adresse aux développeurs de jeux et utilisateurs techniques souhaitant une création et une automatisation Godot assistées par IA, ainsi qu’à ceux qui étudient comment des agents distants pilotent des éditeurs en direct et l’exécution de scripts in-game, avec des limites de sécurité runtime documentées pour les builds exportés.
