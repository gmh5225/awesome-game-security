Godot-MCP 是一款 C# Godot 編輯器外掛，透過 Model Context Protocol 將大型語言模型代理連接至 Godot 編輯器，並經 SignalR 與外部 GameDev MCP 伺服器配對協作。它將編輯器與執行階段能力暴露為 MCP 工具，包括用於查詢與修改場景和資源的 RQL、腳本執行與診斷、螢幕擷圖、以反射為基礎的方法呼叫、主控台日誌，以及面向常用 Godot 生態系的可選擴充模組。專案提供連接雲端或本機伺服器的編輯器 UI、OAuth 或權杖驗證，以及面向常見 AI 程式設計用戶端的一鍵代理設定，另含用於安裝與無頭工作流程的 godot-cli npm 套件。面向希望以 AI 輔助 Godot 創作與自動化的遊戲開發者與技術使用者，以及研究遠端代理如何驅動即時編輯器與遊戲內腳本執行者，並為匯出建置提供文件化的執行階段安全邊界說明。
