Godot-MCP は、Model Context Protocol 経由で大規模言語モデルエージェントを Godot エディターに接続し、SignalR で外部 GameDev MCP サーバーと連携する C# 製 Godot エディターアドオンです。エディターおよびランタイムの機能を MCP ツールとして公開し、シーンとリソースの照会・変更用 RQL、スクリプト実行と診断、スクリーンショット、リフレクションによるメソッド呼び出し、コンソールログ、人気 Godot エコシステム向けのオプション拡張モジュールなどを含みます。クラウドまたはローカルサーバー接続用のエディター UI、OAuth またはトークン認証、一般的な AI コーディングクライアント向けワンクリックエージェント設定、インストールとヘッドレスワークフロー用の godot-cli npm パッケージを同梱します。AI 支援による Godot 制作と自動化を求めるゲーム開発者・技術ユーザー、およびリモートエージェントがライブエディターやゲーム内スクリプト実行をどう駆動するかを学ぶ人向けで、エクスポートビルド向けのランタイムセキュリティ境界も文書化されています。
