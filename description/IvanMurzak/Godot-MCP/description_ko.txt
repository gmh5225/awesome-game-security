Godot-MCP는 Model Context Protocol을 통해 대규모 언어 모델 에이전트를 Godot 에디터에 연결하고, SignalR로 외부 GameDev MCP 서버와 짝을 이루는 C# Godot 에디터 애드온입니다. 에디터 및 런타임 기능을 MCP 도구로 노출하며, 씬과 리소스 조회·변경용 RQL, 스크립트 실행 및 진단, 스크린샷, 리플렉션 기반 메서드 호출, 콘솔 로그, 인기 Godot 생태계용 선택 확장 모듈 등을 포함합니다. 클라우드 또는 로컬 서버 연결용 에디터 UI, OAuth 또는 토큰 인증, 일반적인 AI 코딩 클라이언트용 원클릭 에이전트 구성기, 설치 및 헤드리스 워크플로용 godot-cli npm 패키지를 제공합니다. AI 보조 Godot 제작과 자동화를 원하는 게임 개발자·기술 사용자, 원격 에이전트가 라이브 에디터와 게임 내 스크립트 실행을 구동하는 방식을 연구하는 이들을 대상으로 하며, 내보내기 빌드에 대한 런타임 보안 경계가 문서화되어 있습니다.
