Godot-MCP es un complemento C# del editor Godot que conecta agentes de modelos de lenguaje grandes al editor Godot mediante el Model Context Protocol, emparejándose con un servidor GameDev MCP externo sobre SignalR. Expone capacidades del editor y del runtime como herramientas MCP, incluido RQL para consultar y modificar escenas y recursos, ejecución y diagnóstico de scripts, capturas de pantalla, llamadas a métodos por reflexión, registros de consola y módulos de extensión opcionales para ecosistemas Godot populares. El proyecto incluye UI de editor para conexión a servidor en la nube o local, autenticación OAuth o por token, y configuradores de agentes en un clic para clientes de codificación con IA habituales, además del paquete npm godot-cli para instalación y flujos headless. Está dirigido a desarrolladores de juegos y usuarios técnicos que quieren autoría y automatización Godot asistidas por IA, y a quienes estudian cómo agentes remotos impulsan editores en vivo y ejecución de scripts en juego, con límites de seguridad en runtime documentados para builds exportados.
