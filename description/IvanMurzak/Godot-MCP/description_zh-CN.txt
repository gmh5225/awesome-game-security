Godot-MCP 是一款 C# Godot 编辑器插件，通过 Model Context Protocol 将大语言模型智能体与 Godot 编辑器连接，并与外部 GameDev MCP 服务器经 SignalR 配对协作。它将编辑器与运行时能力暴露为 MCP 工具，包括用于查询与修改场景和资源的 RQL、脚本执行与诊断、截图、基于反射的方法调用、控制台日志，以及面向常用 Godot 生态的可选扩展模块。项目提供用于连接云端或本地服务器的编辑器 UI、OAuth 或令牌认证，以及面向常见 AI 编程客户端的一键智能体配置，另含用于安装与无头工作流的 godot-cli npm 包。面向希望用 AI 辅助 Godot 创作与自动化的游戏开发者和技术用户，以及研究远程智能体如何驱动实时编辑器与游戏内脚本执行的人员，并为导出构建提供了文档化的运行时安全边界说明。
