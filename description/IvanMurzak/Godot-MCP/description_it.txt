Godot-MCP è un addon C# per l’editor Godot che collega agenti di grandi modelli linguistici all’editor tramite il Model Context Protocol, accoppiandosi con un server GameDev MCP esterno su SignalR. Espone capacità dell’editor e del runtime come strumenti MCP, inclusi RQL per interrogare e modificare scene e risorse, esecuzione e diagnostica degli script, screenshot, chiamate a metodi basate sulla reflection, log di console e moduli di estensione opzionali per ecosistemi Godot diffusi. Il progetto include UI dell’editor per connessione a server cloud o locale, autenticazione OAuth o token, e configuratori agente one-click per client di coding IA comuni, più un pacchetto npm godot-cli per installazione e workflow headless. È rivolto a sviluppatori di giochi e utenti tecnici che vogliono authoring e automazione Godot assistiti dall’IA, e a chi studia come agenti remoti guidano editor live ed esecuzione di script in-game, con confini di sicurezza runtime documentati per build esportate.
