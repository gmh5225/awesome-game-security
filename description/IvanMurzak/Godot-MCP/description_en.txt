Godot-MCP is a C# Godot editor addon that connects large language model agents to the Godot editor through the Model Context Protocol, pairing with an external GameDev MCP server over SignalR. It exposes editor and runtime capabilities as MCP tools, including RQL for querying and mutating scenes and resources, script execution and diagnostics, screenshots, reflection-based method calls, console logs, and optional extension modules for popular Godot ecosystems. The project ships editor UI for cloud or local server connection, OAuth or token authentication, and one-click agent configurators for common AI coding clients, plus a godot-cli npm package for installation and headless workflows. It is aimed at game developers and technical users who want AI-assisted Godot authoring and automation, and at anyone studying how remote agents drive live editors and in-game script execution, with documented runtime security boundaries for exported builds.
