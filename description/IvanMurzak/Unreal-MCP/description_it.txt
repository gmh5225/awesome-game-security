Unreal MCP è un plugin Unreal Engine e uno stack di strumenti che collega client Model Context Protocol (MCP) come Claude, Cursor e Copilot all'Unreal Editor affinché gli agenti IA possano ispezionare e guidare un progetto in modo programmatico. È implementato principalmente in C++ (plugin editor), con un bridge sidecar .NET, una CLI basata su Node per installazione e configurazione e hook di esecuzione Python nell'editor. Gli strumenti MCP integrati coprono lavoro su livelli e asset, authoring e compilazione Blueprint, modifica e build del codice sorgente C++, screenshot e uno strato RQL (Reflection Query Language) per interrogare e modificare oggetti e stato dell'editor. Le connessioni possono usare un backend MCP cloud ospitato o un server GameDev MCP self-hosted, con modalità runtime opzionale per build impacchettate o in-game dietro impostazioni di opt-in esplicite. È rivolto a sviluppatori Unreal e utenti tecnici che desiderano flussi di lavoro assistiti dall'IA o automazione e introspezione profonda dei progetti Unreal.
