Unreal MCP는 Claude, Cursor, Copilot과 같은 Model Context Protocol(MCP) 클라이언트를 Unreal Editor에 연결해 AI 에이전트가 프로젝트를 프로그래밍 방식으로 검사하고 제어할 수 있게 하는 Unreal Engine 플러그인 및 도구 스택입니다. 주로 C++(에디터 플러그인)로 구현되며, .NET 사이드카 브리지, 설치 및 구성용 Node 기반 CLI, 에디터 내부 Python 실행 훅을 포함합니다. 내장 MCP 도구는 레벨 및 에셋 작업, Blueprint 작성 및 컴파일, C++ 소스 편집 및 빌드, 스크린샷, 에디터 객체 및 상태를 쿼리하고 변경하는 RQL(Reflection Query Language) 계층을 다룹니다. 연결은 호스팅된 클라우드 MCP 백엔드 또는 자체 호스팅 GameDev MCP 서버를 사용할 수 있으며, 명시적 옵트인 설정 하에서 패키징 또는 인게임 빌드용 런타임 모드를 선택할 수 있습니다. AI 지원 워크플로 또는 Unreal 프로젝트의 심층 자동화 및 내부 조회를 원하는 Unreal 개발자 및 기술 사용자를 대상으로 합니다.
