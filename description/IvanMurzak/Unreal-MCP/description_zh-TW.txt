Unreal MCP 是一款 Unreal Engine 外掛與工具堆疊，將 Model Context Protocol（MCP）用戶端（如 Claude、Cursor、Copilot）連接到 Unreal Editor，使 AI 代理能以程式化方式檢查並驅動專案。實作以 C++（編輯器外掛）為主，並包含 .NET 側車橋接、以 Node 為基礎的安裝與設定 CLI，以及編輯器內的 Python 執行掛鉤。內建 MCP 工具涵蓋關卡與資產作業、Blueprint 撰寫與編譯、C++ 原始碼編輯與建置、螢幕截圖，以及用於查詢與變更編輯器物件與狀態的 RQL（Reflection Query Language）層。連線可採用託管雲端 MCP 後端或自架 GameDev MCP 伺服器，並在明確啟用設定後可選擇打包版或遊戲內建置的執行階段模式。目標對象是希望 AI 輔助工作流或對 Unreal 專案進行深度自動化與內省的 Unreal 開發者與技術使用者。
