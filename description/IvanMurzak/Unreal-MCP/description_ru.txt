Unreal MCP — это плагин Unreal Engine и набор инструментов, который подключает клиенты Model Context Protocol (MCP), такие как Claude, Cursor и Copilot, к Unreal Editor, чтобы ИИ-агенты могли программно осматривать и управлять проектом. Реализован в основном на C++ (редакторский плагин), с .NET sidecar-мостом, CLI на Node для установки и настройки и хуками выполнения Python в редакторе. Встроенные инструменты MCP охватывают работу с уровнями и ассетами, создание и компиляцию Blueprint, редактирование и сборку исходников C++, скриншоты и слой RQL (Reflection Query Language) для запросов и изменения объектов редактора и состояния. Подключение возможно через облачный MCP-бэкенд или self-hosted сервер GameDev MCP, с опциональным runtime-режимом для упакованных или in-game сборок при явном включении в настройках. Ориентирован на разработчиков Unreal и технических пользователей, которым нужны ИИ-ассистированные рабочие процессы или глубокая автоматизация и интроспекция проектов Unreal.
