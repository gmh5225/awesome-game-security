Unreal MCP es un complemento de Unreal Engine y una pila de herramientas que conecta clientes Model Context Protocol (MCP) como Claude, Cursor y Copilot con el Unreal Editor para que los agentes de IA puedan inspeccionar y controlar un proyecto de forma programática. Está implementado principalmente en C++ (plugin de editor), con un puente sidecar .NET, una CLI basada en Node para instalación y configuración, y hooks de ejecución Python dentro del editor. Las herramientas MCP integradas cubren trabajo de niveles y assets, autoría y compilación de Blueprints, edición y compilación de código fuente C++, capturas de pantalla y una capa RQL (Reflection Query Language) para consultar y modificar objetos y el estado del editor. Las conexiones pueden usar un backend MCP en la nube alojado o un servidor GameDev MCP autoalojado, con modo runtime opcional para builds empaquetados o in-game mediante ajustes de opt-in explícitos. Está dirigido a desarrolladores Unreal y usuarios técnicos que desean flujos de trabajo asistidos por IA o automatización e introspección profunda de proyectos Unreal.
