Unreal MCP は、Claude、Cursor、Copilot などの Model Context Protocol（MCP）クライアントを Unreal Editor に接続し、AI エージェントがプロジェクトをプログラム的に検査・操作できるようにする Unreal Engine プラグインとツールスタックです。実装は主に C++（エディタープラグイン）で、.NET サイドカーブリッジ、インストールと設定用の Node ベース CLI、エディター内の Python 実行フックで構成されます。組み込み MCP ツールは、レベルとアセット作業、Blueprint の作成とコンパイル、C++ ソースの編集とビルド、スクリーンショット、エディターオブジェクトと状態のクエリ・変更用 RQL（Reflection Query Language）レイヤーをカバーします。接続はホスト型クラウド MCP バックエンドまたは self-hosted の GameDev MCP サーバーを使用でき、明示的なオプトイン設定により、パッケージ化またはゲーム内ビルド向けのランタイムモードも利用可能です。Unreal 開発者および AI 支援ワークフローや Unreal プロジェクトの深い自動化・イントロスペクションを求める技術ユーザー向けです。
