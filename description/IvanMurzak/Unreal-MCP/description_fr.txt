Unreal MCP est un plugin Unreal Engine et une pile d'outils qui relie des clients Model Context Protocol (MCP) tels que Claude, Cursor et Copilot à l'Unreal Editor afin que des agents IA puissent inspecter et piloter un projet de manière programmatique. Il est implémenté principalement en C++ (plugin éditeur), avec un pont sidecar .NET, une CLI basée sur Node pour l'installation et la configuration, et des hooks d'exécution Python dans l'éditeur. Les outils MCP intégrés couvrent le travail sur les niveaux et les assets, la rédaction et la compilation de Blueprints, l'édition et la compilation de sources C++, les captures d'écran, ainsi qu'une couche RQL (Reflection Query Language) pour interroger et modifier les objets et l'état de l'éditeur. Les connexions peuvent utiliser un backend MCP cloud hébergé ou un serveur GameDev MCP auto-hébergé, avec un mode runtime optionnel pour les builds empaquetés ou in-game derrière des paramètres d'activation explicites. Il s'adresse aux développeurs Unreal et aux utilisateurs techniques qui souhaitent des flux de travail assistés par IA ou une automatisation et une introspection approfondies des projets Unreal.
