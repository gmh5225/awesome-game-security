Unreal MCP 是一款 Unreal Engine 插件与工具栈，将 Model Context Protocol（MCP）客户端（如 Claude、Cursor、Copilot）连接到 Unreal Editor，使 AI 智能体能够以编程方式检查并驱动项目。实现以 C++（编辑器插件）为主，辅以 .NET 侧车桥接、基于 Node 的安装与配置 CLI，以及编辑器内的 Python 执行钩子。内置 MCP 工具涵盖关卡与资产操作、Blueprint 编写与编译、C++ 源码编辑与构建、截图，以及用于查询和修改编辑器对象与状态的 RQL（Reflection Query Language）层。连接可使用托管云 MCP 后端或自托管 GameDev MCP 服务器，并可在显式启用设置后支持打包版或游戏内构建的运行时模式。面向希望采用 AI 辅助工作流或对 Unreal 项目进行深度自动化与内省的 Unreal 开发者及技术用户。
