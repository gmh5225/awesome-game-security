Unreal MCP ist ein Unreal-Engine-Plugin und Tool-Stack, der Model Context Protocol (MCP)-Clients wie Claude, Cursor und Copilot mit dem Unreal Editor verbindet, damit KI-Agenten ein Projekt programmatisch inspizieren und steuern können. Es ist überwiegend in C++ (Editor-Plugin) implementiert, mit einer .NET-Sidecar-Brücke, einer Node-basierten CLI für Installation und Konfiguration sowie Python-Ausführungs-Hooks im Editor. Eingebaute MCP-Tools decken Level- und Asset-Arbeit, Blueprint-Erstellung und -Kompilierung, C++-Quellbearbeitung und Builds, Screenshots sowie eine RQL-Schicht (Reflection Query Language) zum Abfragen und Ändern von Editor-Objekten und -Zustand ab. Verbindungen können ein gehostetes Cloud-MCP-Backend oder einen selbst gehosteten GameDev-MCP-Server nutzen, optional mit Runtime-Modus für gepackte oder In-Game-Builds hinter expliziten Opt-in-Einstellungen. Es richtet sich an Unreal-Entwickler und technische Anwender, die KI-gestützte Workflows oder tiefe Automatisierung und Introspection von Unreal-Projekten wünschen.
