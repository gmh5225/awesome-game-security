Unreal MCP is an Unreal Engine plugin and tooling stack that connects Model Context Protocol (MCP) clients such as Claude, Cursor, and Copilot to the Unreal Editor so AI agents can inspect and drive a project programmatically. It is implemented mainly in C++ (editor plugin), with a .NET sidecar bridge, a Node-based CLI for install and configuration, and Python execution hooks inside the editor. Built-in MCP tools cover level and asset work, Blueprint authoring and compilation, C++ source editing and builds, screenshots, and an RQL (Reflection Query Language) layer for querying and mutating editor objects and state. Connections can use a hosted cloud MCP backend or a self-hosted GameDev MCP server, with optional runtime mode for packaged or in-game builds behind explicit opt-in settings. It targets Unreal developers and technical users who want AI-assisted workflows or deep automation and introspection of Unreal projects.
