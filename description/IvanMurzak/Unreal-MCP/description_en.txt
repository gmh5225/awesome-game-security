Unreal MCP is an Unreal Engine plugin and companion tooling that connects Model Context Protocol (MCP) clients to the Unreal Editor so AI agents can inspect and operate on a live project. The stack combines a C++ editor plugin, a .NET sidecar bridge that speaks MCP over localhost IPC, an npm CLI for install and agent setup, and embedded Python for scripted editor execution. It exposes dozens of built-in tools for spawning actors, editing levels and assets, authoring and compiling Blueprints, editing and building C++, capturing viewport screenshots, and querying or mutating editor state through RQL (Reflection Query Language). Agents can connect to a shared cloud MCP backend or a self-hosted GameDev MCP server, with per-tool enablement and optional runtime hooks for packaged builds when explicitly enabled. It is aimed at Unreal developers and technical users who want AI-assisted game development, deep editor automation, and programmatic introspection of Unreal projects.
