Ironwall 是一个开源的反作弊协议栈，将客户端证明、服务端模拟和链上比赛记录串联起来，为竞技游戏构建分层信任模型。它结合了 Python、Rust 和 C++ 轻量客户端，以及 Intel SGX 和 AMD SEV 可信执行环境验证、ECDSA 模块签名和零知识 PLONK 证明，以强制执行反应时间和鼠标加速度等人类输入约束。玩家输入通过轻量客户端捕获，经由远程代理进行签名和证明并定期重新证明，最终锚定到带有 Merkle 审计追踪的不可篡改 Hedera Consensus Service 记录。该协议栈包含 Unity 和 Unreal 引擎集成、用于扫描已签名游戏模块的 Rust 游戏启动器，以及用于公开验证比赛记录的工具。它面向为竞技对战、投注和争议解决构建防篡改反作弊系统的游戏开发者和安全研究人员。
