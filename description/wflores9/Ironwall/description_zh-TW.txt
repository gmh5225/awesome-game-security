Ironwall 是一個開源的防作弊協定堆疊，將用戶端證明、伺服器端模擬和鏈上比賽記錄串接成競技遊戲的分層信任模型。它結合 Python、Rust 和 C++ 輕量用戶端，以及 Intel SGX 和 AMD SEV 可信執行環境驗證、ECDSA 模組簽章和零知識 PLONK 證明，以強制執行人類輸入限制，例如反應時間與滑鼠加速度。玩家輸入透過輕量用戶端擷取，經由遠端代理簽章與證明並定期重新證明，最終錨定至帶有 Merkle 稽核軌跡的不可篡改 Hedera Consensus Service 記錄。此堆疊包含 Unity 與 Unreal 引擎整合、掃描已簽章遊戲模組的 Rust 遊戲啟動器，以及公開驗證比賽記錄的工具。它面向為競技對戰、投注與爭議解決建構防篡改防作弊系統的遊戲開發者與安全研究人員。
