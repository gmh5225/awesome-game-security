Ironwall は、クライアントの証明、サーバー側シミュレーション、オンチェーンのマッチ記録を連鎖させ、競技ゲーム向けの階層型信頼モデルを構築するオープンソースの反チートプロトコルスタックです。Python、Rust、C++ の thin client と Intel SGX および AMD SEV による信頼実行環境の検証、ECDSA によるモジュール署名、ゼロ知識 PLONK 証明を組み合わせ、反応時間やマウス加速度といった人間の入力制約を強制します。プレイヤーの入力は thin client で取得され、リモートブローカー経由で署名・証明され、定期的な再証明の後、Merkle 監査トレイル付きの改ざん不可能な Hedera Consensus Service 記録にアンカーされます。スタックには Unity および Unreal エンジン連携、署名済みゲームモジュールをスキャンする Rust 製ゲームランチャー、マッチ記録の公開検証用ツールが含まれます。競技プレイ、賭け、紛争解決向けの改ざん検知可能な反チートシステムを構築するゲーム開発者とセキュリティ研究者を対象としています。
