Ironwall은 클라이언트 증명, 서버 측 시뮬레이션, 온체인 매치 기록을 연결하여 경쟁 게임을 위한 계층형 신뢰 모델을 구축하는 오픈 소스 반치트 프로토콜 스택입니다. Python, Rust, C++ thin client와 Intel SGX 및 AMD SEV 신뢰 실행 환경 검증, ECDSA 모듈 서명, 영지식 PLONK 증명을 결합하여 반응 시간 및 마우스 가속도와 같은 인간 입력 제약을 강제합니다. 플레이어 입력은 thin client를 통해 캡처되고, 원격 브로커를 통해 서명 및 증명되며 주기적으로 재증명한 후, Merkle 감사 추적이 포함된 변경 불가능한 Hedera Consensus Service 기록에 앵커됩니다. 스택에는 Unity 및 Unreal 엔진 통합, 서명된 게임 모듈을 스캔하는 Rust 게임 런처, 매치 기록 공개 검증 도구가 포함됩니다. 경쟁 플레이, 베팅, 분쟁 해결을 위한 변조 방지 반치트 시스템을 구축하는 게임 개발자와 보안 연구자를 대상으로 합니다.
