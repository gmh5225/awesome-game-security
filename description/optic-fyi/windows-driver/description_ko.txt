이 프로젝트는 Microsoft windows-drivers-rs 스택 위에서 KMDF로 Rust로 작성된 Windows 커널 모드 드라이버입니다. 명명된 장치를 노출하고, 주기적인 하트비트 IOCTL과 상태 조회를 통해 짝을 이루는 사용자 모드 Optic 서비스를 감독하며, WDF 타이머로 누락된 ping을 감지해 레지스트리와 Windows 이벤트 로그에 변조 이벤트를 기록합니다. 핵심 프로토콜 로직은 별도의 no_std crate에 있으며, golden 테스트로 드라이버-서비스 간 와이어 계약을 고정합니다. KMDF 계층은 장치 생성, ACL, 호출자 이미지 경로 검증을 처리합니다. 설계는 관리자조차 신뢰할 수 없는 적대적 로컬 위협 모델을 대상으로 하며, 완벽한 차단보다 탐지와 지속 가능한 증거를 강조합니다. 커널 지원 서비스 감독, 변조 방지 원격 측정, 보안 제품을 위한 현대적 Rust 드라이버 개발을 연구하는 연구자와 엔지니어에게 유용합니다.
