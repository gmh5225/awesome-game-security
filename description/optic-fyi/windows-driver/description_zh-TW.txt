本專案是基於 Microsoft windows-drivers-rs 技術棧、在 KMDF 上以 Rust 撰寫的 Windows 核心模式驅動程式。它公開一個具名裝置，透過週期性心跳 IOCTL 與狀態查詢監督配對的使用者模式 Optic 服務，並利用 WDF 計時器偵測漏失心跳，在登錄檔與 Windows 事件記錄中記錄篡改事件。核心協定邏輯位於獨立的 no_std crate 中，附有 golden 測試以固定驅動與服務的線上契約，而 KMDF 層負責裝置建立、ACL 及呼叫端映像路徑驗證。設計面向本機敵對威脅模型，即便系統管理員亦不可信，強調偵測與持久性證據而非完美防堵。適合研究核心輔助服務監督、防篡改遙測及面向安全產品的現代 Rust 驅動開發的研究者與工程師。
