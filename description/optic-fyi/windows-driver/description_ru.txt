Этот проект — драйвер Windows в режиме ядра, написанный на Rust поверх KMDF с использованием стека Microsoft windows-drivers-rs. Он предоставляет именованное устройство и контролирует парный пользовательский сервис Optic через периодические IOCTL heartbeat и запросы статуса, используя таймеры WDF для обнаружения пропущенных ping и записи событий вмешательства в реестр и журнал событий Windows. Основная логика протокола находится в отдельном no_std crate с golden-тестами, фиксирующими проводной контракт между драйвером и сервисом, а слой KMDF отвечает за создание устройства, ACL и проверку пути образа вызывающего процесса. Архитектура ориентирована на враждебную локальную модель угроз, где даже администраторы не считаются доверенными, с упором на обнаружение и долговременные доказательства, а не на идеальную блокировку. Полезен исследователям и инженерам, изучающим ядровый надзор за службами, телеметрию против вмешательства и современную разработку драйверов на Rust для продуктов безопасности.
