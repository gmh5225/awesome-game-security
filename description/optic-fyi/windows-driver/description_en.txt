This project is a Windows kernel-mode driver written in Rust on KMDF using Microsoft's windows-drivers-rs stack. It exposes a named device and supervises a paired user-mode Optic service through periodic heartbeat IOCTLs and status queries, using WDF timers to detect missed pings and record tamper events in the registry and Windows event log. Core protocol logic lives in a separate no_std crate with golden tests that pin the driver-service wire contract, while the KMDF layer handles device creation, ACLs, and caller image-path verification. The design targets a hostile local threat model where even administrators are untrusted, emphasizing detection and durable evidence rather than perfect prevention. It is useful for researchers and engineers studying kernel-assisted service supervision, anti-tamper telemetry, and modern Rust driver development for security products.
