本项目是基于 Microsoft windows-drivers-rs 技术栈、在 KMDF 上用 Rust 编写的 Windows 内核模式驱动。它暴露一个命名设备，通过周期性心跳 IOCTL 与状态查询监督配对的用户态 Optic 服务，并利用 WDF 定时器检测漏心跳，在注册表和 Windows 事件日志中记录篡改事件。核心协议逻辑位于独立的 no_std crate 中，配有 golden 测试以固定驱动与服务的线上契约，而 KMDF 层负责设备创建、ACL 及调用方映像路径校验。设计面向本地敌对威胁模型，即便管理员亦不可信，侧重检测与持久取证而非完美阻断。适用于研究内核辅助服务监督、防篡改遥测及面向安全产品的现代 Rust 驱动开发的工程人员与研究者。
