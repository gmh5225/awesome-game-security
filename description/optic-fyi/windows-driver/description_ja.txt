本プロジェクトは、Microsoft の windows-drivers-rs スタック上で KMDF を用い Rust で書かれた Windows カーネルモードドライバーです。名前付きデバイスを公開し、定期的なハートビート IOCTL とステータス照会を通じて対になるユーザーモードの Optic サービスを監視し、WDF タイマーで ping 欠落を検出してレジストリと Windows イベントログに改ざんイベントを記録します。コアのプロトコルロジックは別の no_std crate にあり、ドライバーとサービス間のワイヤ契約を golden テストで固定します。KMDF 層はデバイス作成、ACL、呼び出し元イメージパス検証を担当します。設計は管理者でさえ信頼できない敵対的なローカル脅威モデルを想定し、完全な防止より検知と永続的な証跡を重視します。カーネル支援によるサービス監視、改ざん防止テレメトリ、セキュリティ製品向けの現代的 Rust ドライバー開発を学ぶ研究者やエンジニアに有用です。
