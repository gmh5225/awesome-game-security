VTD-Bypass는 호스트 물리 메모리의 ACPI 테이블을 읽고 수정하여 VT-d 및 IOMMU 관련 탐지를 자동으로 우회하는 Python 도구입니다. FPGA DMA 하드웨어의 LeechCore를 사용해 메모리를 덤프하고, XSDT 테이블을 찾으며, 체크섬이 유효한 DMAR 테이블을 구성하고 XSDT를 패치하여 펌웨어에서 VT-d가 비활성화되어 있어도 시스템이 활성화된 것으로 보고하도록 합니다. 주요 기법에는 서명 기반 ACPI 테이블 검색, 4KB 정렬 홀 선택, 고 MMIO 공간에 DRHD 기본 주소 배치, 암호화된 구성 파일, 부팅 중 반복적인 타이밍 쓰기가 포함됩니다. 이 프로젝트는 Windows, Python 3.9–3.11, leechcorepyc 및 외부 DMA 라이브러리에 의존하며, 하드웨어 보안 연구, ACPI/IOMMU 분석, VT-d 강제 적용이 확인되는 게임 안티치트 테스트를 목표로 합니다.
