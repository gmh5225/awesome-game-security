VTD-Bypass は、ホスト物理メモリ内の ACPI テーブルを読み取り・変更することで、VT-d および IOMMU 関連の検出を自動的にバイパスする Python ツールです。FPGA DMA ハードウェア上の LeechCore を用いてメモリをダンプし、XSDT テーブルを特定し、チェックサムが有効な DMAR テーブルを構築して XSDT をパッチし、ファームウェアで VT-d が無効でもシステムが有効と報告するようにします。主な手法には、署名ベースの ACPI テーブル検索、4KB アラインのホール選択、高 MMIO 空間への DRHD ベースアドレス配置、暗号化された設定ファイル、起動時の繰り返しタイミング書き込みが含まれます。本プロジェクトは Windows、Python 3.9–3.11、leechcorepyc、外部 DMA ライブラリに依存し、ハードウェアセキュリティ研究、ACPI/IOMMU 解析、VT-d 強制が確認されるゲームアンチチートのテストを対象としています。
