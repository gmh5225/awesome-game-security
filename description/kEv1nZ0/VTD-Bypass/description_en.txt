VTD-Bypass is a Python tool that automates bypassing VT-d and IOMMU-related detection by reading and modifying ACPI tables in host physical memory. It uses LeechCore over FPGA DMA hardware to dump memory, locate the XSDT table, build a checksum-valid DMAR table, and patch the XSDT so the system reports VT-d as enabled when firmware has it disabled. Key techniques include signature-based ACPI table search, 4KB-aligned hole selection, DRHD base address placement in high MMIO space, encrypted configuration files, and repeated timed writes during boot. The project depends on Windows, Python 3.9–3.11, leechcorepyc, and external DMA libraries, and is aimed at hardware security research, ACPI/IOMMU analysis, and game anti-cheat testing where VT-d enforcement is checked.
