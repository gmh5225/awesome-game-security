VTD-Bypass 是一款 Python 工具，可通过读取并修改主机物理内存中的 ACPI 表，自动绕过 VT-d 与 IOMMU 相关检测。它通过 FPGA DMA 硬件上的 LeechCore 转储内存、定位 XSDT 表、构建校验和有效的 DMAR 表，并修补 XSDT，使系统在固件禁用 VT-d 时仍报告其已启用。主要技术包括基于签名的 ACPI 表搜索、4KB 对齐空洞选择、在高 MMIO 空间放置 DRHD 基地址、加密配置文件，以及在启动期间进行重复的定时写入。该项目依赖 Windows、Python 3.9–3.11、leechcorepyc 与外部 DMA 库，面向硬件安全研究、ACPI/IOMMU 分析及需要检查 VT-d 强制策略的游戏反作弊测试。
