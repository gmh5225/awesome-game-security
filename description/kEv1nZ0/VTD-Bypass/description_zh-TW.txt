VTD-Bypass 是一款 Python 工具，可透過讀取並修改主機實體記憶體中的 ACPI 表，自動繞過 VT-d 與 IOMMU 相關偵測。它透過 FPGA DMA 硬體上的 LeechCore 傾印記憶體、定位 XSDT 表、建構校驗和有效的 DMAR 表，並修補 XSDT，使系統在韌體停用 VT-d 時仍回報其已啟用。主要技術包括以簽章為基礎的 ACPI 表搜尋、4KB 對齊空洞選取、在高 MMIO 空間放置 DRHD 基底位址、加密設定檔，以及在開機期間進行重複的定時寫入。該專案依賴 Windows、Python 3.9–3.11、leechcorepyc 與外部 DMA 函式庫，面向硬體安全研究、ACPI/IOMMU 分析及需要檢查 VT-d 強制策略的遊戲反作弊測試。
