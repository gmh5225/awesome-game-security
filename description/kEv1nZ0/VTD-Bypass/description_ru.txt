VTD-Bypass — это инструмент на Python, который автоматизирует обход обнаружения, связанного с VT-d и IOMMU, путём чтения и изменения таблиц ACPI в физической памяти хоста. Он использует LeechCore через аппаратуру FPGA DMA для дампа памяти, поиска таблицы XSDT, создания таблицы DMAR с корректной контрольной суммой и патчинга XSDT, чтобы система сообщала о включённом VT-d, когда прошивка его отключила. Ключевые методы включают поиск таблиц ACPI по сигнатуре, выбор выровненных по 4 КБ «дыр», размещение базового адреса DRHD в верхнем MMIO-пространстве, зашифрованные конфигурационные файлы и повторяющиеся записи по таймеру во время загрузки. Проект зависит от Windows, Python 3.9–3.11, leechcorepyc и внешних DMA-библиотек и предназначен для исследований аппаратной безопасности, анализа ACPI/IOMMU и тестирования античита в играх, где проверяется принудительное включение VT-d.
