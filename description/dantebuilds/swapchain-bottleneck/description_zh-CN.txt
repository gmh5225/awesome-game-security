本项目是一份架构分析文档，主张许多 PC 游戏问题——卡顿、叠加层崩溃、TDR 重置与蓝屏（BSOD）——有着共同根因：Windows 没有官方支持的通道，让叠加层与游戏的 DXGI swapchain 一同绘制。它说明 Steam、Discord、监控工具及类似软件如何转而依赖 DLL 注入与 Present 调用的 API 钩取，从而在 DWM 协调之外与游戏、彼此以及驱动发生冲突。该文对照微软文档，梳理从叠加层竞态条件到内核 bugcheck 的连锁效应，并讨论 DXGI、WDDM、HAGS、Multiplane Overlays，以及反作弊白名单对合法注入器造成的摩擦。它提出并行 swapchain 与官方叠加层 API 等方向，使次级呈现器得以隔离并协调。主要读者是研究呈现层冲突、叠加层注入与 Windows 显示架构的游戏安全、图形与系统工程师。
