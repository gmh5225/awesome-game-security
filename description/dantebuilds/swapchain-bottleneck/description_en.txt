This project is an architecture analysis document that argues many PC gaming issues—stuttering, overlay crashes, TDR resets, and BSODs—share a root cause: Windows has no officially supported channel for overlays to draw alongside a game’s DXGI swapchain. It explains how Steam, Discord, monitoring tools, and similar software resort to DLL injection and API hooking of Present calls, colliding with the game, each other, and the driver outside DWM coordination. The write-up traces cascades from overlay race conditions to kernel bugchecks against Microsoft documentation, and discusses DXGI, WDDM, HAGS, Multiplane Overlays, and anti-cheat whitelist friction with legitimate injectors. It proposes directions such as a parallel swapchain and official overlay API so secondary presenters can be isolated and coordinated. The primary audience is game security, graphics, and systems engineers studying presentation-layer conflicts, overlay injection, and Windows display architecture.
