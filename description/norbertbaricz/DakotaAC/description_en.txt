DakotaAC is an advanced anti-cheat plugin for Minecraft servers that monitors player behavior in real time to detect and deter cheating. Written in Java as a Spigot/Bukkit plugin and built with Maven, it uses ProtocolLib packet inspection and Citizens2 NPCs to power modular checks covering combat hacks such as aimbot, kill aura, reach, and velocity, as well as movement, world interaction, and inventory exploits. Server administrators can configure individual modules, violation thresholds, and automated kick or ban actions through admin commands and YAML settings. It is aimed at survival, PvP, minigame, and competitive server operators who need configurable server-side protection against common client-side cheats.
