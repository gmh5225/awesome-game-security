DakotaAC è un plugin anti-cheat avanzato per server Minecraft che monitora il comportamento dei giocatori in tempo reale per rilevare e scoraggiare i cheat. Scritto in Java come plugin Spigot/Bukkit e compilato con Maven, utilizza l'ispezione dei pacchetti ProtocolLib e gli NPC di Citizens2 per alimentare controlli modulari che coprono hack di combattimento come aimbot, kill aura, reach e velocity, nonché exploit di movimento, interazione con il mondo e inventario. Gli amministratori del server possono configurare singoli moduli, soglie di violazione e azioni automatiche di kick o ban tramite comandi amministrativi e impostazioni YAML. È rivolto agli operatori di server survival, PvP, minigame e competitivi che necessitano di protezione lato server configurabile contro i cheat client comuni.
