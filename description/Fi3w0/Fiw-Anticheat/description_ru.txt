Fiw AntiCheat — серверная система проверки и принуждения модов для Minecraft: она проверяет подключающихся клиентов и оценивает передаваемые списки модов, версии, отпечатки JAR и состояние наборов ресурсов. Написана на Java со сборками Gradle для Fabric, MinecraftForge и NeoForge на нескольких версиях игры; в основе — общий движок правил с сигнатурным обнаружением нечестных utility-модов, режимы чёрного или белого списка для модпаков, история профиля по игрокам и опциональный аудит или баны наборов ресурсов. Персонал может вводить политику постепенно: только логирование в режиме мониторинга, поуровневые исключения для игроков, админ-команды для снимков и повторных проверок, интеграции вроде Floodgate для игроков Bedrock. Рассчитана на владельцев и администраторов серверов, которым нужна практическая видимость клиентских модов и целостность модпака, а не полноценный поведенческий или ядровый античит.
