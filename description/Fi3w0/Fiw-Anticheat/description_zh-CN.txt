Fiw AntiCheat 是一套面向 Minecraft 服务端的模组校验与执法系统，会在玩家加入时向客户端发起质询，并依据伴随上报的模组列表、版本、JAR 指纹与资源包状态进行评估。项目以 Java 编写，使用 Gradle 构建，支持 Fabric、MinecraftForge 与 NeoForge，覆盖多个游戏版本；核心为共享规则引擎，可基于签名检测不公平的工具类模组，并提供黑名单或白名单整合包模式、每名玩家的档案历史，以及可选的资源包审计或封禁。运营人员可通过仅监控的日志、分级的玩家豁免、用于快照与复检的管理员命令，以及 Floodgate 等对接基岩版玩家的集成钩子，逐步推进策略。面向需要实用的客户端模组可见性与整合包完整性、而非完整行为层或内核级反作弊的服务器所有者与管理员。
