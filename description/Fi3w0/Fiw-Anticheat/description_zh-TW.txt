Fiw AntiCheat 是一套面向 Minecraft 伺服器端的模組驗證與執法系統，會在玩家加入時向用戶端發起質詢，並依據伴隨回報的模組清單、版本、JAR 指紋與資源包狀態進行評估。專案以 Java 撰寫，使用 Gradle 建置，支援 Fabric、MinecraftForge 與 NeoForge，涵蓋多個遊戲版本；核心為共用規則引擎，可透過簽章偵測不公平的工具類模組，並提供黑名單或白名單整合包模式、每位玩家的檔案歷程，以及可選的資源包稽核或封禁。營運人員可透過僅監控的日誌、分級的玩家豁免、用於快照與複檢的管理員指令，以及 Floodgate 等對接基岩版玩家的整合鉤子，逐步推行策略。面向需要實用的用戶端模組可見性與整合包完整性、而非完整行為層或核心層級反作弊的伺服器擁有者與管理員。
