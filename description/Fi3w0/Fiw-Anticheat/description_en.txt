Fiw AntiCheat is a Minecraft server-side mod verification and enforcement system that challenges joining clients and evaluates companion-reported mod lists, versions, jar fingerprints, and resource pack state. Written in Java with Gradle builds for Fabric, MinecraftForge, and NeoForge across multiple game versions, it centers on a shared rule engine with signature-based detection of unfair utility mods, blacklist or whitelist modpack modes, per-player profile history, and optional resource pack auditing or bans. Staff can roll out policy gradually with monitor-only logging, tiered player exemptions, admin commands for snapshots and rechecks, and integration hooks such as Floodgate for Bedrock players. It targets server owners and administrators who need practical client-mod visibility and modpack integrity rather than full behavioral or kernel-level anti-cheat.
