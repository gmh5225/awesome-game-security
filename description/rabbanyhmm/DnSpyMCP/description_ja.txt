DnSpyMCP は、dnSpy を実行時に必要とせず、AI エージェントに .NET アセンブリの詳細な検査、逆コンパイル、バイナリパッチを提供するローカル Model Context Protocol (MCP) サーバーです。C# で .NET 8 上に実装され、dnlib によるアセンブリと IL 操作、ICSharpCode.Decompiler による C# 出力を備え、型の一覧取得、メソッドの逆コンパイル、IL 分析、パッチ適用など数十のツールを提供します。Unity および Il2Cpp ゲームのリバースエンジニアリング向けに最適化されており、オフセットと RVA の検索、構造体レイアウトのエクスポート、dump.cs ブリッジ、クロスリファレンス追跡、複数 DLL ワークスペース検索などに対応します。ネットワークおよびセキュリティ研究向けの機能も備え、パケットハンドラの検索、暗号利用のスキャン、ハードコードされたシークレットの抽出などが可能です。サーバーは stdio JSON-RPC で通信し、Claude Code、Codex、Cursor、OpenCode などの MCP クライアントと連携し、ゲームセキュリティ、リバースエンジニアリング、アンチチート分析のワークフローに統合できます。
