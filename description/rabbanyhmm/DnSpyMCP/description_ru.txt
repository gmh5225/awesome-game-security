DnSpyMCP — локальный сервер Model Context Protocol (MCP), предоставляющий AI-агентам глубокую инспекцию .NET-сборок, декомпиляцию и бинарное патчирование без необходимости запуска dnSpy. Написан на C# под .NET 8, использует dnlib для работы со сборками и IL, а ICSharpCode.Decompiler — для вывода C#, предлагая десятки инструментов для перечисления типов, декомпиляции методов, анализа IL и применения патчей. Оптимизирован для реверс-инжиниринга игр Unity и Il2Cpp, включая поиск смещений и RVA, экспорт раскладки структур, мостирование dump.cs, трассировку перекрёстных ссылок и поиск по нескольким DLL в рабочей области. Дополнительные возможности ориентированы на сетевые исследования и безопасность: поиск обработчиков пакетов, сканирование использования криптографии и извлечение захардкоженных секретов. Сервер взаимодействует через stdio JSON-RPC и интегрируется с MCP-клиентами, такими как Claude Code, Codex, Cursor и OpenCode, для рабочих процессов в области безопасности игр, реверс-инжиниринга и анализа античита.
