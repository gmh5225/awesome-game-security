DnSpyMCP 是一个本地 Model Context Protocol (MCP) 服务器，使 AI 智能体能够在无需运行时依赖 dnSpy 的情况下，深入检查 .NET 程序集、反编译和二进制补丁。它使用 C# 编写，基于 .NET 8，采用 dnlib 进行程序集与 IL 操作，使用 ICSharpCode.Decompiler 生成 C# 输出，提供数十种工具用于列出类型、反编译方法、分析 IL 和应用补丁。该工具针对 Unity 和 Il2Cpp 游戏逆向进行了优化，包括偏移量和 RVA 查找、结构体布局导出、dump.cs 桥接、交叉引用追踪以及多 DLL 工作区搜索。此外还支持网络与安全研究相关功能，如查找数据包处理器、扫描加密用法以及提取硬编码密钥。服务器通过 stdio JSON-RPC 通信，可与 Claude Code、Codex、Cursor、OpenCode 等 MCP 客户端集成，用于游戏安全、逆向工程和反作弊分析工作流。
