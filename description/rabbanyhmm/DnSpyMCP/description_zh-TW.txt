DnSpyMCP 是一款本地 Model Context Protocol (MCP) 伺服器，讓 AI 代理在無需執行階段依賴 dnSpy 的情況下，深入檢查 .NET 組件、反編譯與二進位修補。以 C# 撰寫，基於 .NET 8，使用 dnlib 進行組件與 IL 操作，並透過 ICSharpCode.Decompiler 產生 C# 輸出，提供數十種工具用於列出型別、反編譯方法、分析 IL 與套用修補。針對 Unity 與 Il2Cpp 遊戲逆向進行最佳化，包含偏移量與 RVA 查詢、結構配置匯出、dump.cs 橋接、交叉參考追蹤及多 DLL 工作區搜尋。另提供網路與安全研究相關功能，例如尋找封包處理器、掃描加密用法及提取硬編碼密鑰。伺服器透過 stdio JSON-RPC 通訊，可與 Claude Code、Codex、Cursor、OpenCode 等 MCP 用戶端整合，用於遊戲安全、逆向工程與反作弊分析工作流程。
