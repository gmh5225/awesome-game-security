ImOverlay-DX11 is a lightweight C++20 framework for building hardware-accelerated, transparent desktop overlays and multi-window UI systems on Windows using Win32, DirectX 11, and Dear ImGui. The entire library ships as two drop-in files that manage layered windows, DXGI swapchains, smart click-through hit testing, native drag handling, and parent-child overlay hierarchies with cascading lifecycle events. It supports topmost floating windows, multi-monitor anchoring, dynamic physical window expansion for popups and menus, and optional antivirus-hardening features such as Control Flow Guard and ASLR. It is aimed at developers building game overlays, desktop tools, and researchers studying transparent overlay rendering techniques relevant to game security and anti-cheat analysis.
