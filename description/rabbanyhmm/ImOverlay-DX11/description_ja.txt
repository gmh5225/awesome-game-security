ImOverlay-DX11 は、Win32、DirectX 11、Dear ImGui を使用して Windows 上でハードウェアアクセラレーションの透明デスクトップオーバーレイおよびマルチウィンドウ UI システムを構築するための軽量 C++20 フレームワークです。ライブラリ全体は 2 つのドロップインファイルとして提供され、レイヤードウィンドウ、DXGI スワップチェーン、スマートなクリックスルー ヒットテスト、ネイティブドラッグ処理、およびカスケード型ライフサイクルイベントを伴う親子オーバーレイ階層を管理します。最前面のフローティングウィンドウ、マルチモニターアンカリング、ポップアップやメニュー向けの動的な物理ウィンドウ拡張、Control Flow Guard や ASLR などのオプションのアンチウイルス強化機能をサポートします。ゲームオーバーレイやデスクトップツールを開発する開発者、およびゲームセキュリティやアンチチート分析に関連する透明オーバーレイ描画技術を研究する研究者を対象としています。
