ImOverlay-DX11 是一個輕量級的 C++20 框架，用於在 Windows 上透過 Win32、DirectX 11 和 Dear ImGui 建構硬體加速的透明桌面疊加層與多視窗 UI 系統。整個函式庫以兩個即插即用檔案的形式提供，可管理分層視窗、DXGI 交換鏈、智慧穿透點擊命中測試、原生拖曳處理，以及帶有級聯生命週期事件的父子疊加層階層結構。它支援置頂浮動視窗、多顯示器錨定、用於快顯視窗和選單的動態實體視窗擴展，以及 Control Flow Guard 和 ASLR 等可選的防毒強化功能。它面向開發遊戲疊加層與桌面工具的開發者，以及研究透明疊加層渲染技術（與遊戲安全及反作弊分析相關）的研究人員。
