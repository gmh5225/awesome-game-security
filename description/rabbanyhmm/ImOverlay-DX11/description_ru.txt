ImOverlay-DX11 — это лёгкий фреймворк на C++20 для создания аппаратно ускоренных прозрачных настольных оверлеев и многоконных UI-систем в Windows с использованием Win32, DirectX 11 и Dear ImGui. Вся библиотека поставляется в виде двух подключаемых файлов, которые управляют слоистыми окнами, цепочками обмена DXGI, интеллектуальным hit-тестированием с пропусканием кликов, нативной обработкой перетаскивания и иерархиями оверлеев родитель-потомок с каскадными событиями жизненного цикла. Поддерживаются плавающие окна поверх всех остальных, привязка к нескольким мониторам, динамическое расширение физических окон для всплывающих окон и меню, а также опциональные функции антивирусного усиления, такие как Control Flow Guard и ASLR. Он предназначен для разработчиков, создающих игровые оверлеи и настольные инструменты, а также для исследователей, изучающих методы рендеринга прозрачных оверлеев, связанные с безопасностью игр и анализом античитов.
