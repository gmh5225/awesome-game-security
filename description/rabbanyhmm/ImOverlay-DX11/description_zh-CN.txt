ImOverlay-DX11 是一个轻量级的 C++20 框架，用于在 Windows 上通过 Win32、DirectX 11 和 Dear ImGui 构建硬件加速的透明桌面叠加层和多窗口 UI 系统。整个库以两个即插即用文件的形式提供，可管理分层窗口、DXGI 交换链、智能穿透点击命中测试、原生拖拽处理，以及带有级联生命周期事件的父子叠加层层次结构。它支持置顶浮动窗口、多显示器锚定、用于弹出窗口和菜单的动态物理窗口扩展，以及 Control Flow Guard 和 ASLR 等可选的防病毒加固功能。它面向开发游戏叠加层和桌面工具的开发者，以及研究透明叠加层渲染技术（与游戏安全和反作弊分析相关）的研究人员。
