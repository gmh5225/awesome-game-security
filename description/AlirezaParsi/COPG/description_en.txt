COPG is a Zygisk module for rooted Android devices that spoofs per-app device profiles, CPU, GPU, and other hardware or identity signals so games and apps believe they run on flagship hardware. It is built mainly in C++ with a JavaScript WebUI and Magisk-style module scripts, offering controls for build props, serial numbers, IMEI, Widevine DRM level, SIM carrier, advertising IDs, and privacy hides such as VPN and mock-location masking. Many spoofing modes use stealth copy-on-write or unload-before-launch techniques meant to leave no module footprint in process memory, while optional resident hooks for GPU, DRM, and similar features carry explicit anti-cheat risk warnings. The on-device WebUI manages device libraries, per-app spoof lists, backups, and comfort tweaks without rebooting. It is aimed at mobile gamers and security researchers who want to bypass hardware-gated FPS and graphics tiers, or study how Android games fingerprint devices and distinguish stealth from detectable hooking.
