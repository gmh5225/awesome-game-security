COPG 是一款面向已 root 的 Android 设备的 Zygisk 模块，可为每个应用伪造设备配置文件、CPU、GPU 及其他硬件或身份信号，使游戏和应用误以为运行在旗舰硬件上。它主要使用 C++ 构建，配有 JavaScript WebUI 和 Magisk 风格模块脚本，可控制 build props、序列号、IMEI、Widevine DRM 级别、SIM 运营商、广告 ID，以及 VPN 和模拟定位等隐私隐藏功能。许多伪造模式采用隐蔽的写时复制或启动前卸载技术，旨在不在进程内存中留下模块痕迹；而 GPU、DRM 等可选常驻钩子则附带明确的反作弊风险警告。设备端 WebUI 可在无需重启的情况下管理设备库、按应用伪造列表、备份和便捷调整。它面向希望绕过硬件门槛限制的 FPS 和画质档位，或研究 Android 游戏如何对设备进行指纹识别并区分隐蔽与可检测钩子的移动游戏玩家和安全研究人员。
