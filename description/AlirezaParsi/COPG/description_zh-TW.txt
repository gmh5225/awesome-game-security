COPG 是一款面向已 root 的 Android 裝置的 Zygisk 模組，可為每個應用程式偽造裝置設定檔、CPU、GPU 及其他硬體或身分訊號，使遊戲和應用程式誤以為執行在旗艦硬體上。它主要以 C++ 建構，配有 JavaScript WebUI 與 Magisk 風格模組腳本，可控制 build props、序號、IMEI、Widevine DRM 等級、SIM 電信業者、廣告 ID，以及 VPN 和模擬定位等隱私隱藏功能。許多偽造模式採用隱蔽的寫時複製或啟動前卸載技術，旨在不在程序記憶體中留下模組痕跡；而 GPU、DRM 等可選常駐鉤子則附帶明確的反作弊風險警告。裝置端 WebUI 可在無需重新開機的情況下管理裝置資料庫、依應用程式偽造清單、備份和便利調整。它面向希望繞過硬體門檻限制的 FPS 和畫質檔位，或研究 Android 遊戲如何對裝置進行指紋辨識並區分隱蔽與可偵測鉤子的行動遊戲玩家和安全研究人員。
