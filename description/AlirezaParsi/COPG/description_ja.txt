COPG は root 化された Android 端末向けの Zygisk モジュールで、アプリごとにデバイスプロファイル、CPU、GPU、その他のハードウェアや ID 信号を偽装し、ゲームやアプリにフラッグシップ端末上で動作していると誤認させます。主に C++ で構築され、JavaScript WebUI と Magisk 形式のモジュールスクリプトを備え、build props、シリアル番号、IMEI、Widevine DRM レベル、SIM キャリア、広告 ID、VPN やモック位置情報のマスキングなどのプライバシー非表示を制御できます。多くの偽装モードはステルスな copy-on-write または起動前アンロードの手法を用い、プロセスメモリにモジュールの痕跡を残さないことを意図しています。一方、GPU や DRM 向けのオプション常駐フックには、明示的なアンチチートリスク警告が付いています。デバイス上の WebUI は、再起動なしでデバイスライブラリ、アプリ別偽装リスト、バックアップ、快適性調整を管理します。ハードウェア制限の FPS やグラフィック段階を回避したいモバイルゲーマーや、Android ゲームが端末をどうフィンガープリントし、ステルスと検出可能なフックをどう区別するかを研究したいセキュリティ研究者向けです。
