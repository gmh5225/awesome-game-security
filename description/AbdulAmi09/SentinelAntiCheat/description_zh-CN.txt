Sentinel Anti-Cheat 是一个国际象棋诚信平台，用于分析对局中的引擎协助统计特征，并生成可解释的风险发现供人工审核，而非自动判定作弊。该系统主要采用 Python 构建，包含 FastAPI 后端与 Next.js 仲裁员仪表盘，将 Regan 风格的走法质量基线与七个信号层（涵盖复杂度、用时、历史对局、行为模式、在线行为以及环境或身份线索）相结合，融合为分层风险评分并提供逐层解释。基于 Stockfish 的 PGN 分析、Maia 人类风格对比、可选的 XGBoost 与 Isolation Forest 融合、哈希链式审计日志、案件管理、实时对局监控以及合作伙伴 API，可支持联合会级别的工作流程。面向调查线下与线上面诚信事件的国际象棋仲裁员、裁判长及棋类联合会。
