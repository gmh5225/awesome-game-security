Sentinel Anti-Cheat は、対局を解析してエンジン利用の統計的兆候を検出し、自動的な不正判定ではなく、人間による審査のための説明可能なリスク所見を提示するチェス公正性プラットフォームです。主に Python で構築され、FastAPI バックエンドと Next.js 製の審判ダッシュボードを備え、Regan スタイルの手の質ベースラインと、複雑度・時間・過去の対局・行動パターン・オンライン行動・環境／身元手がかりをカバーする 7 つのシグナル層を組み合わせ、階層化されたリスクスコアと各層ごとの説明に融合します。Stockfish による PGN 解析、Maia による人間らしさの比較、任意の XGBoost および Isolation Forest 融合、ハッシュ連鎖型監査ログ、ケース管理、ライブ対局モニタリング、パートナー API により、連盟規模のワークフローを支援します。対面およびオンラインの公正性事件を調査するチェスの審判、主審、連盟を対象としています。
