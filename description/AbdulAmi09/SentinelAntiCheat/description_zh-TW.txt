Sentinel Anti-Cheat 是一個國際象棋誠信平台，用於分析對局中的引擎協助統計特徵，並產生可解釋的風險發現供人工審核，而非自動判定作弊。該系統主要採用 Python 建構，包含 FastAPI 後端與 Next.js 仲裁員儀表板，將 Regan 風格的走法品質基線與七個訊號層（涵蓋複雜度、用時、歷史對局、行為模式、線上行為以及環境或身分線索）結合，融合為分層風險評分並提供逐層解釋。基於 Stockfish 的 PGN 分析、Maia 人類風格比對、可選的 XGBoost 與 Isolation Forest 融合、雜湊鏈式稽核日誌、案件管理、即時對局監控以及合作夥伴 API，可支援聯合會級別的工作流程。面向調查線下與線上面誠信事件的國際象棋仲裁員、裁判長及棋類聯合會。
