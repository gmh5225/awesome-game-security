Sentinel Anti-Cheat — платформа обеспечения честности в шахматах, которая анализирует партии на статистические признаки использования движка и формирует объяснимые выводы о рисках для проверки человеком, а не автоматические вердикты о мошенничестве. Создана преимущественно на Python с бэкендом FastAPI и панелью арбитра на Next.js; сочетает базовую линию качества ходов в стиле Regan с семью слоями сигналов — сложность, время, история игры, поведенческие паттерны, онлайн-поведение и подсказки окружения или личности — объединёнными в многоуровневые оценки риска с пояснениями по каждому слою. Анализ PGN на базе Stockfish, сравнение человекоподобности Maia, опциональное объединение XGBoost и Isolation Forest, аудит-лог с цепочкой хешей, управление делами, мониторинг партий в реальном времени и партнёрский API поддерживают рабочие процессы масштаба федераций. Предназначена для шахматных арбитров, главных арбитров и федераций, расследующих инциденты честности за доской и онлайн.
