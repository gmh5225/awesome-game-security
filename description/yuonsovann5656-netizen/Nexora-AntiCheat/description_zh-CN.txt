Nexora AntiCheat 是一款面向现代 Paper 与 Folia Minecraft 服务器的延迟补偿反作弊插件，用于检测常见的移动、战斗、世界与协议类作弊，并力求降低误报。它通过模块化检测（如加速、飞行、杀戮光环、攻击距离、脚手架与 X-Ray 等），结合统计分析、向量射线追踪、考虑延迟的攻击距离计算、速度校验，并在适当时兼容基岩版与 Geyser。服务端核心采用 Java 21 与 Maven 构建，通过 SQLite 或 MySQL 持久化违规记录，支持逐级踢出至封禁、员工 GUI 与命令、Discord 处罚 Webhook，以及可选的许可证心跳集成。配套的 React 与 Node.js Web 面板配合 Supabase PostgreSQL，为运营受保护的多人生存或小玩法网络的服主提供许可证发放、集群遥测与远程服务器管理。
