Nexora AntiCheat — плагин античита с компенсацией задержки для современных серверов Minecraft на Paper и Folia, нацеленный на обнаружение типичных читов движения, боя, мира и протокола с низким уровнем ложных срабатываний. Реализованы модульные проверки: speed, fly, kill aura, reach, scaffold и x-ray с использованием статистического анализа, векторного ray-tracing, расчёта reach с учётом пинга, проверки скорости и при необходимости допуска для Bedrock/Geyser. Серверное ядро написано на Java 21 с Maven, нарушения сохраняются в SQLite или MySQL, поддерживаются поэтапная эскалация от кика до бана, GUI и команды для персонала, Discord webhooks наказаний и опциональная интеграция heartbeat лицензии. В комплекте веб-панель на React и Node.js с Supabase PostgreSQL для выдачи лицензий, телеметрии флота и удалённого управления серверами операторами защищённых мультиплеерных survival- или minigame-сетей.
