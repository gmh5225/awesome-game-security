Nexora AntiCheat es un complemento anti-trampas con compensación de lag pensado para servidores modernos de Minecraft Paper y Folia, orientado a detectar trampas habituales de movimiento, combate, mundo y protocolo con bajos falsos positivos. Implementa comprobaciones modulares como velocidad, vuelo, kill aura, alcance, scaffold y x-ray, mediante análisis estadístico, trazado de rayos vectorial, cálculos de alcance conscientes del ping, validación de velocidad y tolerancia Bedrock/Geyser cuando corresponde. El núcleo del lado del servidor está escrito en Java 21 con Maven, persiste infracciones mediante SQLite o MySQL, admite escalada progresiva de expulsión a baneo, GUI y comandos para staff, webhooks de sanciones en Discord e integración opcional de heartbeat de licencia. Un panel web incluido con React y Node.js respaldado por Supabase PostgreSQL gestiona emisión de licencias, telemetría de flota y administración remota de servidores para operadores de redes multijugador de supervivencia o minijuegos protegidas.
