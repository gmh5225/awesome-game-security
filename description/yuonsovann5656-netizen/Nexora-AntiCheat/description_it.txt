Nexora AntiCheat è un plugin anti-cheat con compensazione del lag pensato per server Minecraft Paper e Folia moderni, finalizzato a rilevare cheat comuni di movimento, combattimento, mondo e protocollo con pochi falsi positivi. Implementa controlli modulari come speed, fly, kill aura, reach, scaffold e x-ray, usando analisi statistica, ray-tracing vettoriale, calcoli di reach sensibili al ping, validazione della velocità e tolleranza Bedrock/Geyser dove appropriato. Il core lato server è scritto in Java 21 con Maven, persiste le violazioni tramite SQLite o MySQL, supporta escalation progressiva da kick a ban, GUI e comandi per lo staff, webhook Discord per le punizioni e integrazione opzionale di heartbeat licenza. Un pannello web incluso con React e Node.js, con Supabase PostgreSQL, gestisce emissione licenze, telemetria della flotta e gestione remota dei server per operatori di reti multiplayer survival o minigame protette.
