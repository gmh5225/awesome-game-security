Nexora AntiCheat は、現行の Paper および Folia 向け Minecraft サーバー用のラグ補正型アンチチートプラグインで、移動・戦闘・ワールド・プロトコル系の一般的なチート検知を低い誤検知率で行うことを目的としています。速度、飛行、キルオーラ、リーチ、足場、X-Ray などのモジュール式チェックを、統計分析、ベクトルレイトレース、Ping を考慮したリーチ計算、速度検証、必要に応じた Bedrock/Geyser 許容と組み合わせて実装しています。サーバー側コアは Java 21 と Maven で記述され、SQLite または MySQL で違反を永続化し、段階的なキックから BAN へのエスカレーション、スタッフ用 GUI とコマンド、Discord 処罰 Webhook、任意のライセンスハートビート連携をサポートします。同梱の React と Node.js Web パネルが Supabase PostgreSQL をバックエンドとし、保護されたマルチプレイサバイバルやミニゲームネットワークを運用する事業者向けにライセンス発行、フリートテレメトリ、リモートサーバー管理を提供します。
