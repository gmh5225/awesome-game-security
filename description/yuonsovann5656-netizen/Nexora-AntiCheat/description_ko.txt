Nexora AntiCheat는 최신 Paper 및 Folia Minecraft 서버용 지연 보정 안티치트 플러그인으로, 이동·전투·월드·프로토콜 관련 일반적인 치트를 낮은 오탐률로 탐지하는 것을 목표로 합니다. 속도, 비행, 킬 오라, 리치, 스캐폴드, X-Ray 등 모듈형 검사를 통계 분석, 벡터 레이 트레이싱, 핑을 고려한 리치 계산, 속도 검증, 필요 시 Bedrock/Geyser 허용과 함께 구현합니다. 서버 측 코어는 Java 21과 Maven으로 작성되며, SQLite 또는 MySQL로 위반 기록을 저장하고, 단계적 킥에서 밴으로의 에스컬레이션, 스태프 GUI 및 명령, Discord 처벌 Webhook, 선택적 라이선스 하트비트 연동을 지원합니다. 번들된 React 및 Node.js 웹 패널이 Supabase PostgreSQL을 백엔드로 사용하여, 보호된 멀티플레이 서바이벌 또는 미니게임 네트워크를 운영하는 관리자에게 라이선스 발급, 플릿 원격 측정, 원격 서버 관리를 제공합니다.
