Nexora AntiCheat is a lag-compensated anti-cheat plugin built for modern Paper and Folia Minecraft servers, aimed at detecting common movement, combat, world, and protocol cheats with a focus on low false positives. It implements modular checks such as speed, fly, kill aura, reach, scaffold, and x-ray, using statistical analysis, vector ray-tracing, ping-aware reach math, velocity validation, and Bedrock/Geyser tolerance where appropriate. The server-side core is written in Java 21 with Maven, persists violations through SQLite or MySQL, supports progressive kick-to-ban escalation, staff GUI and commands, Discord punishment webhooks, and optional license heartbeat integration. A bundled React and Node.js web panel with Supabase PostgreSQL backs license issuance, fleet telemetry, and remote server management for operators running protected multiplayer survival or minigame networks.
