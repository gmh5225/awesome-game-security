Oxylus — современный игровой движок на C++ с сопутствующим редактором для создания интерактивных 3D-приложений и игр. Он использует Vulkan через библиотеку графа рендеринга vuk и шейдеры Slang, с такими возможностями, как PBR-освещение, отсечение meshlet, карты теней и эффекты постобработки. Движок построен вокруг сцен Flecs ECS, привязок скриптинга Lua, управления ассетами (включая glTF), аудио на базе miniaudio, физики и сетевых функций, а также ImGui и RmlUi для инструментов и runtime UI. Собирается с помощью xmake и поддерживает Windows, Linux и macOS; ориентирован на разработчиков игр и программистов движков, которым нужен модульный открытый стек runtime и редактора.
