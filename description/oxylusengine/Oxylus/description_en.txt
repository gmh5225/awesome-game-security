Oxylus is a modern C++ game engine with a companion editor for building interactive 3D applications and games. It uses Vulkan through the vuk render graph library and Slang shaders, with features such as PBR lighting, meshlet culling, shadow maps, and post-processing effects. The engine is organized around Flecs ECS scenes, Lua scripting bindings, asset management (including glTF), miniaudio-based audio, physics, and networking, plus ImGui and RmlUi for tooling and runtime UI. Built with xmake and supporting Windows, Linux, and macOS, it targets game developers and engine programmers who want a modular, open-source runtime and editor stack.
