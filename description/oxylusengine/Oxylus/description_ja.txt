Oxylus は、インタラクティブな 3D アプリケーションやゲームを構築するためのコンパニオンエディタ付きのモダンな C++ ゲームエンジンです。vuk レンダーグラフライブラリ経由で Vulkan を使用し、Slang シェーダーを採用しており、PBR ライティング、meshlet カリング、シャドウマップ、ポストプロセスなどの機能を備えます。エンジンは Flecs ECS シーンを中心に構成され、Lua スクリプトバインディング、アセット管理（glTF 含む）、miniaudio ベースのオーディオ、物理、ネットワーキングに加え、ツールとランタイム UI 向けの ImGui と RmlUi を提供します。xmake でビルドされ、Windows、Linux、macOS をサポートし、モジュール化されたオープンソースのランタイムとエディタスタックを求めるゲーム開発者およびエンジンプログラマ向けです。
