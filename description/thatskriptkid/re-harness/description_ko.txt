RE-harness는 OpenCode 플러그인으로 구현된 Windows PE 정적 분석 하네스로, 대규모 언어 모델에 IDA Pro와 IDASQL에 대한 구조화된 읽기 전용 접근을 제공하여 증거 기반 리버스 엔지니어링을 지원합니다. 주로 Python으로 작성되었으며 TypeScript OpenCode 플러그인을 포함하고, Qwen 27B/35B 모델을 위해 설계되었으며 IDA 데이터베이스 준비, 의사코드 추출, 제어된 분석 워크플로를 조율하면서 신뢰할 수 없는 샘플은 실행하지 않습니다. Hex-Rays 역컴파일이 실패하거나 출력이 과도하게 클 때, 하네스는 번들된 NeverD와 LLVM 파이프라인을 통해 개별 함수를 리프트하고, 스택 상대 주소를 정규화하며, LLVM O3로 최적화한 뒤 단순화된 코드를 IDA로 되돌려 재역컴파일하면서 검증된 API 및 호출 지점 이름을 보존합니다. FLIRT 시그니처 데이터베이스, Windows API 의미 데이터, OpenRouter 또는 llama.cpp 엔드포인트용 구성 가능한 제공자 설정을 통합합니다. 이 프로젝트는 추측이 아닌 감사 가능하고 도구에 기반한 출력을 갖춘 LLM 지원 Windows 실행 파일 정적 분석이 필요한 리버스 엔지니어와 게임 보안 연구자를 대상으로 합니다.
