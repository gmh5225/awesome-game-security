RE-harness — это среда статического анализа PE-файлов Windows, реализованная как плагин OpenCode, которая предоставляет большим языковым моделям структурированный доступ только для чтения к IDA Pro и IDASQL для обратной разработки на основе доказательств. Написанный преимущественно на Python с плагином OpenCode на TypeScript, он предназначен для моделей Qwen 27B/35B и управляет подготовкой баз IDA, извлечением псевдокода и контролируемыми рабочими процессами анализа без выполнения недоверенных образцов. Когда декомпиляция Hex-Rays завершается неудачей или даёт слишком большой вывод, среда поднимает отдельные функции через встроенный конвейер NeverD и LLVM, нормализует адреса относительно стека, оптимизирует с помощью LLVM O3 и повторно декомпилирует упрощённый код в IDA, сохраняя проверенные имена API и мест вызовов. Интегрируются базы сигнатур FLIRT, семантические данные Windows API и настраиваемые параметры провайдера для конечных точек OpenRouter или llama.cpp. Проект ориентирован на специалистов по обратной разработке и исследователей безопасности игр, которым нужен статический анализ исполняемых файлов Windows с помощью LLM с проверяемыми, обоснованными инструментами результатами, а не спекулятивными догадками.
