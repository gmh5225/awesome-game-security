RE-harness は、OpenCode プラグインとして実装された Windows PE 向け静的解析ハーネスで、大規模言語モデルに IDA Pro と IDASQL への構造化された読み取り専用アクセスを提供し、証拠に基づくリバースエンジニアリングを支援します。主に Python で書かれ、TypeScript 製 OpenCode プラグインを含み、Qwen 27B/35B モデル向けに設計され、IDA データベースの準備、疑似コードの抽出、制御された解析ワークフローをオーケストレーションし、信頼できないサンプルを実行しません。Hex-Rays による逆コンパイルが失敗したり出力が大きすぎる場合、ハーネスは同梱の NeverD と LLVM パイプラインで個々の関数をリフトし、スタック相対アドレスを正規化し、LLVM O3 で最適化したうえで、簡略化されたコードを IDA に戻して再逆コンパイルし、検証済みの API 名とコールサイト名を保持します。FLIRT シグネチャデータベース、Windows API セマンティクスデータ、OpenRouter または llama.cpp エンドポイント向けの設定可能なプロバイダー設定を統合しています。本プロジェクトは、推測ではなく監査可能でツールに根拠づけられた出力を伴う LLM 支援の Windows 実行ファイル静的解析を必要とするリバースエンジニアおよびゲームセキュリティ研究者を対象としています。
