RE-harness 是一个 Windows PE 静态分析框架，以 OpenCode 插件形式实现，为大型语言模型提供对 IDA Pro 和 IDASQL 的结构化只读访问，用于基于证据的逆向工程。项目主要使用 Python 编写，并包含 TypeScript 版 OpenCode 插件，面向 Qwen 27B/35B 模型，可编排 IDA 数据库准备、伪代码提取及受控分析流程，且不会执行不可信样本。当 Hex-Rays 反编译失败或输出过大时，该框架会通过内置的 NeverD 与 LLVM 流水线逐函数提升代码，规范化栈相对地址，以 LLVM O3 优化，再将简化后的代码回写至 IDA 重新反编译，同时保留已验证的 API 与调用点名称。它集成 FLIRT 特征库、Windows API 语义数据，以及面向 OpenRouter 或 llama.cpp 端点的可配置提供方设置。该项目面向需要借助 LLM 进行 Windows 可执行文件静态分析、并追求可审计、工具支撑输出而非臆测猜测的逆向工程师与游戏安全研究人员。
