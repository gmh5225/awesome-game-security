RE-harness es un harness de análisis estático de PE de Windows implementado como plugin de OpenCode que proporciona a los modelos de lenguaje grandes acceso estructurado de solo lectura a IDA Pro e IDASQL para ingeniería inversa basada en evidencia. Escrito principalmente en Python con un plugin de OpenCode en TypeScript, está diseñado para los modelos Qwen 27B/35B y orquesta la preparación de bases de datos IDA, la extracción de pseudocódigo y flujos de análisis controlados sin ejecutar muestras no confiables. Cuando la descompilación de Hex-Rays falla o produce una salida excesivamente grande, el harness eleva funciones individuales mediante una canalización integrada de NeverD y LLVM, normaliza direcciones relativas a la pila, optimiza con LLVM O3 y vuelve a descompilar el código simplificado en IDA preservando nombres de API y sitios de llamada verificados. Integra bases de datos de firmas FLIRT, datos semánticos de la API de Windows y ajustes configurables del proveedor para endpoints de OpenRouter o llama.cpp. El proyecto está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad en juegos que necesitan análisis estático de ejecutables de Windows asistido por LLM, con salidas auditables y fundamentadas en herramientas en lugar de conjeturas especulativas.
