RE-harness is a Windows PE static-analysis harness implemented as an OpenCode plugin that gives large language models structured, read-only access to IDA Pro and IDASQL for evidence-driven reverse engineering. Written primarily in Python with a TypeScript OpenCode plugin, it is designed for Qwen 27B/35B models and orchestrates IDA database preparation, pseudocode extraction, and controlled analysis workflows without executing untrusted samples. When Hex-Rays decompilation fails or produces oversized output, the harness lifts individual functions through a bundled NeverD and LLVM pipeline, normalizes stack-relative addresses, optimizes with LLVM O3, and redecompiles simplified code back in IDA while preserving verified API and call-site names. It integrates FLIRT signature databases, Windows API semantics data, and configurable provider settings for OpenRouter or llama.cpp endpoints. The project targets reverse engineers and game security researchers who need LLM-assisted static analysis of Windows executables with auditable, tool-grounded outputs rather than speculative guesses.
