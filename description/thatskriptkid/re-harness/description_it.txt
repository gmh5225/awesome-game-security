RE-harness è un harness di analisi statica di PE Windows implementato come plugin OpenCode che offre ai modelli linguistici di grandi dimensioni accesso strutturato in sola lettura a IDA Pro e IDASQL per un reverse engineering basato su evidenze. Scritto principalmente in Python con un plugin OpenCode in TypeScript, è progettato per i modelli Qwen 27B/35B e orchestra la preparazione del database IDA, l'estrazione del pseudocodice e flussi di analisi controllati senza eseguire campioni non affidabili. Quando la decompilazione Hex-Rays fallisce o produce un output eccessivamente grande, l'harness solleva singole funzioni tramite una pipeline integrata NeverD e LLVM, normalizza gli indirizzi relativi allo stack, ottimizza con LLVM O3 e ricompila il codice semplificato in IDA preservando i nomi verificati di API e siti di chiamata. Integra database di firme FLIRT, dati semantici delle API Windows e impostazioni configurabili del provider per endpoint OpenRouter o llama.cpp. Il progetto è rivolto a reverse engineer e ricercatori di sicurezza dei giochi che necessitano di analisi statica di eseguibili Windows assistita da LLM, con output verificabili e ancorati agli strumenti anziché congetture speculative.
