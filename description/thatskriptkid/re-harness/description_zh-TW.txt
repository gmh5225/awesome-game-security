RE-harness 是一個 Windows PE 靜態分析框架，以 OpenCode 外掛形式實作，為大型語言模型提供對 IDA Pro 與 IDASQL 的結構化唯讀存取，用於以證據為基礎的逆向工程。專案主要使用 Python 撰寫，並包含 TypeScript 版 OpenCode 外掛，面向 Qwen 27B/35B 模型，可編排 IDA 資料庫準備、偽程式碼擷取及受控分析流程，且不會執行不可信樣本。當 Hex-Rays 反編譯失敗或輸出過大時，該框架會透過內建的 NeverD 與 LLVM 管線逐函式提升程式碼，正規化堆疊相對位址，以 LLVM O3 最佳化，再將簡化後的程式碼回寫至 IDA 重新反編譯，同時保留已驗證的 API 與呼叫點名稱。它整合 FLIRT 特徵庫、Windows API 語意資料，以及面向 OpenRouter 或 llama.cpp 端點的可設定提供方設定。此專案面向需要借助 LLM 進行 Windows 可執行檔靜態分析、並追求可稽核、工具支撐輸出而非臆測猜測的逆向工程師與遊戲安全研究人員。
