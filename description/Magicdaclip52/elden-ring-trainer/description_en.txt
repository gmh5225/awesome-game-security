ERTrainer is an open-source Windows overlay trainer for Elden Ring version 1.17.2 that attaches to the game process externally and exposes gameplay tweaks through a Dear ImGui and DirectX 11 control panel. It is built with C++20 and CMake and implements live memory editing through signature scanning, pointer chains, byte patches, code caves, and in-process hooks rather than injecting a DLL. The feature set spans survival, combat, items, world, and character stats, including options such as infinite resources, damage modifiers, drop rate control, flight, rune editing, and game speed. The project is aimed at single-player or offline use and serves as a practical reference for external process trainers, game memory layout work, and reverse-engineering style patch development on Windows.
