ERTrainer は Elden Ring バージョン 1.17.2 向けのオープンソース Windows オーバーレイトレーナーで、ゲームプロセスに外部からアタッチし、Dear ImGui と DirectX 11 のコントロールパネルからゲームプレイの調整を行えます。C++20 と CMake で構築され、DLL 注入ではなく、シグネチャスキャン、ポインタチェーン、バイトパッチ、コードケーブ、プロセス内フックによるライブメモリ編集を実装しています。機能はサバイバル、戦闘、アイテム、ワールド、キャラクター能力をカバーし、無限リソース、ダメージ変更、ドロップ率制御、飛行、ルーン編集、ゲーム速度などのオプションを含みます。本プロジェクトはシングルプレイまたはオフライン利用を想定し、外部プロセストレーナー、ゲームメモリレイアウト調査、Windows 上でのリバースエンジニアリング風パッチ開発の実践的な参考として役立ちます。
