IDA Arsenal est un plugin IDA Pro qui étend le désassembleur avec résolution de chemins symboliques, découverte d’entrées, reconnaissance cryptographique et utilitaires de triage sans quitter la base de données. Le plugin Python communique avec un processus backend distinct fondé sur angr et Z3 ; l’utilisateur marque des adresses ou objectifs de fonctions find/avoid et reconstitue stdin, argv ou les entrées aux sites d’appel sous contraintes de longueur et de caractères imprimables. Il cartographie aussi les entrées pile issues d’appels libc, classe les fonctions selon l’usage des imports, reconnaît chiffrements et hachages courants dans du code strippé, résout des prédicats SMT-LIB, note les traits de packer et d’anti-analyse, exporte des aides Frida et GDB, et récupère les symboles Go via un petit helper Go. La pile cible crackmes, défis CTF et reverse de type malware sur ELF Linux x86-64, y compris des flux utiles pour analyser des binaires de jeux protégés et des contrôles de licence.
