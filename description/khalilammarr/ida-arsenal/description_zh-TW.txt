IDA Arsenal 是一款 IDA Pro 外掛，無需離開資料庫即可為反組譯器擴充符號路徑求解、輸入發現、密碼演算法辨識與分類檢視等能力。此 Python 外掛透過獨立後端程序與建構於 angr 與 Z3 的求解引擎通訊；使用者可標記 find/avoid 位址或函式目標，並在長度與可列印字元等限制下還原 stdin、argv 或呼叫點輸入。外掛亦可從 libc 呼叫對應堆疊輸入、依匯入用法對函式分類、在 stripped 程式碼中辨識常見加密與雜湊、求解 SMT-LIB 述詞、對加殼與反分析特徵評分，並匯出 Frida 與 GDB 輔助腳本，亦可透過小型 Go 輔助工具還原 Go 符號。技術堆疊鎖定 crackme、CTF 題與類惡意軟體逆向，執行於 Linux x86-64 ELF，涵蓋分析受保護遊戲二進位與授權檢查等流程。
