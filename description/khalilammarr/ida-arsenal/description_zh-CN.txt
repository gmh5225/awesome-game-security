IDA Arsenal 是一款 IDA Pro 插件，在无需离开数据库的前提下为反汇编器扩展符号路径求解、输入发现、密码算法识别与分类排查等能力。该 Python 插件通过独立后端进程与基于 angr 和 Z3 的求解引擎通信；用户可标记 find/avoid 地址或函数目标，并在长度与可打印字符等约束下恢复 stdin、argv 或调用点输入。插件还可从 libc 调用映射栈上输入、根据导入用法对函数分类、在 stripped 代码中识别常见加密与哈希、求解 SMT-LIB 谓词、对加壳与反分析特征打分，并导出 Frida 与 GDB 辅助脚本，还可通过小型 Go 辅助工具恢复 Go 符号。技术栈面向 crackme、CTF 题与类恶意软件逆向，运行于 Linux x86-64 ELF，涵盖分析受保护游戏二进制与授权校验等场景。
