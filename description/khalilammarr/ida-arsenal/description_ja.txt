IDA Arsenal は IDA Pro 用プラグインで、データベースを離れることなく、記号パス求解、入力探索、暗号認識、トリアージ用ユーティリティを逆アセンブラに追加します。Python プラグインは angr と Z3 を基盤とする別プロセスのバックエンドと通信し、ユーザーは find/avoid アドレスや関数目標を指定し、長さや印字可能文字などの制約の下で stdin、argv、呼び出し点入力を復元できます。libc 呼び出しからのスタック入力のマッピング、インポート利用に基づく関数分類、ストリップされたコード内の一般的な暗号・ハッシュの認識、SMT-LIB 述語の求解、パッカーと反解析特性のスコアリング、Frida および GDB ヘルパーのエクスポート、小さな Go ヘルパーによる Go シンボル復元も行います。スタックは crackme、CTF 課題、マルウェア的なリバースエンジニアリングを想定し、Linux x86-64 ELF 上で、保護されたゲームバイナリやライセンスチェックの解析に関わるワークフローも含みます。
