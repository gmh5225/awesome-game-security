IDA Arsenal은 IDA Pro용 플러그인으로, 데이터베이스를 벗어나지 않고 역어셈블러에 기호 경로 풀이, 입력 탐색, 암호 인식, 트리아지 유틸리티를 확장합니다. Python 플러그인은 angr와 Z3 기반의 별도 백엔드 프로세스와 통신하며, 사용자는 find·avoid 주소나 함수 목표를 표시하고 길이·출력 가능 문자 제약 하에 stdin, argv 또는 호출 지점 입력을 복구할 수 있습니다. libc 호출에서 스택 입력을 매핑하고, import 사용으로 함수를 분류하며, stripped 코드에서 흔한 암호·해시를 인식하고, SMT-LIB 술어를 풀고, 패커·반분석 특성을 점수화하며, Frida·GDB 헬퍼를 내보내고, 작은 Go 헬퍼로 Go 심볼을 복구합니다. 스택은 crackme, CTF 챌린지, 멀웨어 스타일 리버스 엔지니어링을 겨냥하며 Linux x86-64 ELF에서 동작하고, 보호된 게임 바이너리·라이선스 검사 분석에 맞는 워크플로도 포함합니다.
