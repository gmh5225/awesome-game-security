IDA Arsenal is an IDA Pro plugin that extends the disassembler with symbolic path solving, input discovery, crypto recognition, and triage utilities without leaving the database. The Python plugin talks to a separate backend process built on angr and Z3, where users mark find and avoid addresses or function goals and recover stdin, argv, or call-site inputs under length and printable constraints. It also maps stack inputs from libc calls, classifies functions from import usage, recognizes common ciphers and hashes in stripped code, solves SMT-LIB predicates, scores packer and anti-analysis traits, exports Frida and GDB helpers, and recovers Go symbols via a small Go helper. The stack targets crackmes, CTF challenges, and malware-style reverse engineering on Linux x86-64 ELF, including workflows relevant to analyzing protected game binaries and license checks.
