Dies ist ein spezialisierter Fork des xboxrecomp-Toolkits für statische Rekompilierung, der das originale Xbox-Spiel Jet Set Radio Future auf native macOS-ARM64-Hardware bringt, indem die XBE-Ausführungsdatei in C statt per Emulation übersetzt wird. Das Projekt stellt einen Ersatz-Xbox-Kernel, NV2A-GPU- und MCPX-APU-Hardwaremodelle aus xemu sowie Übersetzungsschichten für D3D8-Grafik, DirectSound-Audio und Xbox-Controller-Eingaben bereit. Hauptsächlich in C und Python mit einem CMake-Buildsystem geschrieben, umfasst es ein umfangreiches Diagnose-Framework zur Validierung des recompilierten Verhaltens anhand von Referenz-Emulator-Spuren. Es richtet sich an Forscher und Entwickler, die an der Erhaltung von Xbox-Spielen, statischer Binär-Rekompilierung und Reverse Engineering von originalen Xbox-Titeln auf niedriger Ebene arbeiten.
