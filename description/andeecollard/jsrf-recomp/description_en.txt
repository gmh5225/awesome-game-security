This is a specialized fork of the xboxrecomp static recompilation toolkit that brings the original Xbox game Jet Set Radio Future to native macOS ARM64 by translating its XBE executable into C instead of emulating it. The project provides a replacement Xbox kernel, NV2A GPU and MCPX APU hardware models extracted from xemu, and translation layers for D3D8 graphics, DirectSound audio, and Xbox controller input. Written primarily in C and Python with a CMake build system, it includes an extensive diagnostics harness for validating recompiled behavior against reference emulator traces. It is aimed at researchers and developers working on Xbox game preservation, static binary recompilation, and low-level reverse engineering of original Xbox titles.
