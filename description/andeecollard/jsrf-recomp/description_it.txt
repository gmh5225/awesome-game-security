Si tratta di un fork specializzato del toolkit di ricompilazione statica xboxrecomp che porta l'originale gioco Xbox Jet Set Radio Future su macOS ARM64 nativo traducendo il suo eseguibile XBE in C anziché emularlo. Il progetto fornisce un kernel Xbox sostitutivo, modelli hardware NV2A GPU e MCPX APU estratti da xemu, e livelli di traduzione per grafica D3D8, audio DirectSound e input del controller Xbox. Scritto principalmente in C e Python con un sistema di build CMake, include un ampio harness diagnostico per convalidare il comportamento ricompilato rispetto alle tracce di riferimento dell'emulatore. È rivolto a ricercatori e sviluppatori che lavorano sulla preservazione dei giochi Xbox, la ricompilazione statica di binari e il reverse engineering di basso livello dei titoli Xbox originali.
