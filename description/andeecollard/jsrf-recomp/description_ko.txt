xboxrecomp 정적 재컴파일 툴킷의 전용 포크로, XBE 실행 파일을 에뮬레이션 대신 C 코드로 변환하여 원본 Xbox 게임 Jet Set Radio Future를 네이티브 macOS ARM64에서 구동합니다. 이 프로젝트는 대체 Xbox 커널, xemu에서 추출한 NV2A GPU 및 MCPX APU 하드웨어 모델, D3D8 그래픽, DirectSound 오디오, Xbox 컨트롤러 입력을 위한 변환 계층을 제공합니다. 주로 C와 Python으로 작성되었으며 CMake 빌드 시스템을 사용하고, 참조 에뮬레이터 추적과 대조하여 재컴파일 동작을 검증하는 광범위한 진단 하네스를 포함합니다. Xbox 게임 보존, 정적 바이너리 재컴파일, 원본 Xbox 타이틀의 저수준 리버스 엔지니어링을 연구하는 연구자와 개발자를 대상으로 합니다.
