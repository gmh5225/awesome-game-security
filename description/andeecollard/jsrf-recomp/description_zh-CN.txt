这是 xboxrecomp 静态重编译工具集的专用分支，通过将其 XBE 可执行文件翻译成 C 代码而非模拟运行，将原版 Xbox 游戏 Jet Set Radio Future 移植到原生 macOS ARM64 平台。该项目提供了替代性的 Xbox 内核、从 xemu 提取的 NV2A GPU 与 MCPX APU 硬件模型，以及针对 D3D8 图形、DirectSound 音频和 Xbox 控制器输入的转换层。项目主要使用 C 和 Python 编写，采用 CMake 构建系统，并包含一套完整的诊断框架，用于对照参考模拟器跟踪记录验证重编译行为。它面向从事 Xbox 游戏保存、静态二进制重编译以及原版 Xbox 游戏底层逆向工程的研究人员与开发者。
