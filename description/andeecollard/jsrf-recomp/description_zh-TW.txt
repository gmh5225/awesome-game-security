這是 xboxrecomp 靜態重編譯工具集的專用分支，透過將其 XBE 可執行檔譯成 C 程式碼而非模擬執行，將原版 Xbox 遊戲 Jet Set Radio Future 移植至原生 macOS ARM64 平台。此專案提供替代性的 Xbox 核心、自 xemu 提取的 NV2A GPU 與 MCPX APU 硬體模型，以及 D3D8 圖形、DirectSound 音訊與 Xbox 控制器輸入的轉換層。程式主要使用 C 與 Python 撰寫，採用 CMake 建置系統，並包含一套完整的診斷框架，用於對照參考模擬器追蹤紀錄驗證重編譯行為。它面向從事 Xbox 遊戲保存、靜態二進位重編譯以及原版 Xbox 遊戲底層逆向工程的研究人員與開發者。
