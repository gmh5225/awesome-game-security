xboxrecomp 静的再コンパイルツールキットの専用フォークで、XBE 実行ファイルをエミュレーションではなく C コードへ変換することにより、オリジナルの Xbox ゲーム Jet Set Radio Future をネイティブ macOS ARM64 上で動作させます。本プロジェクトは代替 Xbox カーネル、xemu から抽出した NV2A GPU および MCPX APU ハードウェアモデル、D3D8 グラフィックス、DirectSound オーディオ、Xbox コントローラー入力向けの変換レイヤーを提供します。主に C と Python で記述され、CMake ビルドシステムを採用しており、参照エミュレーターのトレースと照合して再コンパイル動作を検証するための包括的な診断ハーネスを含みます。Xbox ゲーム保存、静的バイナリ再コンパイル、オリジナル Xbox タイトルの低レベルリバースエンジニアリングに取り組む研究者と開発者を対象としています。
