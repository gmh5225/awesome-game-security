Это специализированный форк набора инструментов статической рекомпиляции xboxrecomp, который переносит оригинальную игру для Xbox Jet Set Radio Future на нативный macOS ARM64, переводя её исполняемый файл XBE в C вместо эмуляции. Проект предоставляет замену ядра Xbox, аппаратные модели NV2A GPU и MCPX APU, извлечённые из xemu, а также слои трансляции для графики D3D8, аудио DirectSound и ввода с контроллера Xbox. Написан в основном на C и Python с системой сборки CMake, включает обширный диагностический каркас для проверки поведения рекомпилированного кода по эталонным трассам эмулятора. Предназначен для исследователей и разработчиков, занимающихся сохранением игр Xbox, статической рекомпиляцией бинарников и низкоуровневым реверс-инжинирингом оригинальных игр для Xbox.
