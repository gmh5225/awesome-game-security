面向 DeepSeek Harness（dsh）的逆向工程 agent 技能套件，將常駐的 Ghidra 12.x 無頭 RPC 守護程式與七個情境化工作流程結合，用於自動化二進位分析。主要以 Python 撰寫，封裝內建的 ghidra-rpc 引擎及數十個輔助腳本，涵蓋反編譯、初步研判、脫殼、加密檢測、模擬執行與證據記錄，並可選用 dsh 鉤子以機械式約束分析流程。七項技能分別涵蓋二進位初步研判、加殼脫殼、深度靜態分析、漏洞稽核、以 Frida 與 Qiling 進行的動態插樁、PCAP 與網路鑑識，以及純 DEX 的 Android APK 逆向。適用於 CTF 逆向、crackme 求解、惡意軟體研判、漏洞預篩與鑑識流量分析，強調亞秒級 Ghidra 指令、腳本化護欄與基於 oracle 的驗證，而非依賴 GUI 或 MCP 工具。
