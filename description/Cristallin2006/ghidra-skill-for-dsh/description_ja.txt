DeepSeek Harness（dsh）向けのリバースエンジニアリング agent スキル群で、常駐型の Ghidra 12.x ヘッドレス RPC デーモンと 7 つのシナリオ別ワークフローを組み合わせ、バイナリ分析を自動化します。主に Python で書かれ、同梱の ghidra-rpc エンジンと、逆コンパイル、トリアージ、アンパック、暗号チェック、エミュレーション、証拠ログ用の多数のヘルパースクリプトをラップし、分析規律を機械的に強制する dsh フックも任意で利用できます。7 つのスキルは、初期バイナリトリアージ、パッカーアンパック、深い静的解析、脆弱性監査、Frida と Qiling による動的インストルメンテーション、PCAP とネットワークフォレンジック、純 DEX の Android APK リバースをカバーします。CTF リバース、crackme 解法、マルウェアトリアージ、脆弱性事前スクリーニング、フォレンジックトラフィック分析を対象とし、GUI や MCP ツールに頼らず、サブ秒の Ghidra コマンド、スクリプト化されたガードレール、oracle ベースの検証を重視します。
