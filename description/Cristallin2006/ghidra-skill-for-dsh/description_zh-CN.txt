面向 DeepSeek Harness（dsh）的逆向工程 agent 技能套件，将常驻的 Ghidra 12.x 无头 RPC 守护进程与七个场景化工作流结合，用于自动化二进制分析。主要使用 Python 编写，封装了内置的 ghidra-rpc 引擎及数十个辅助脚本，涵盖反编译、初步研判、脱壳、加密检测、模拟执行与证据记录，并可选 dsh 钩子以机械式约束分析流程。七个技能分别覆盖二进制初步研判、加壳脱壳、深度静态分析、漏洞审计、基于 Frida 与 Qiling 的动态插桩、PCAP 与网络取证，以及纯 DEX 的 Android APK 逆向。适用于 CTF 逆向、crackme 求解、恶意软件研判、漏洞预筛与取证流量分析，强调亚秒级 Ghidra 命令、脚本化护栏与基于 oracle 的验证，而非依赖 GUI 或 MCP 工具。
