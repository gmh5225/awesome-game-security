JVM Inspector 是一套唯讀的 PowerShell 取證工具，面向 Windows 上 Minecraft 的螢幕分享審查與作弊偵測。主腳本採兩階段流程：第一階段稽核執行中的 javaw.exe 與 java.exe 程序，檢查 javaagent、native agent、bootclasspath 修改及其他 JVM 注入相關啟動參數，並對 Modrinth、Lunar、Badlion、Fabric 等可信啟動器做白名單放行。第二階段依常見啟動器目錄配置掃描磁碟，查找幽靈版本、可疑模組、經重新命名或重打包的 JAR（真實身分來自 fabric.mod.json 或 manifest），並在 class 位元組中比對七十多種硬編碼作弊特徵，採零雜訊回報策略。配套的 Suspicious DLL Finder 腳本補充注入 DLL、手動映射、反射載入器與持久化等命令列難以發現的檢查。工具為單檔、無相依掃描器，適合版主、反作弊人員及從事 JVM 向遊戲安全審查的逆向工程師使用。
