JVM Inspector is a read-only PowerShell forensics suite aimed at Minecraft screenshare and cheat detection on Windows. Its main script runs a two-phase workflow: Phase 1 audits live javaw.exe and java.exe processes for javaagents, native agents, bootclasspath tweaks, and other JVM injection flags while whitelisting trusted launchers such as Modrinth, Lunar, Badlion, and Fabric. Phase 2 scans disk across common launcher layouts for ghost versions, suspicious mods, renamed or repacked JARs whose real identity comes from fabric.mod.json or manifests, and more than seventy hard cheat signatures inside class bytes using a zero-noise reporting policy. A companion Suspicious DLL Finder script adds injected DLL, manual-map, reflective loader, and persistence checks for cases that bypass command-line inspection. The tools are single-file, dependency-free scanners suited to moderators, anti-cheat staff, and reverse engineers doing JVM-focused game security reviews.
