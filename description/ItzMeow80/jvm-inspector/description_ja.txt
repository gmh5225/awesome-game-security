JVM Inspector は、Windows 上の Minecraft におけるスクリーンシェア調査とチート検出向けの読み取り専用 PowerShell フォレンジックススイートです。メインスクリプトは二段階ワークフローで、第1段階では稼働中の javaw.exe および java.exe プロセスを監査し、javaagent、ネイティブエージェント、bootclasspath の改変、その他の JVM 注入フラグを確認し、Modrinth、Lunar、Badlion、Fabric など信頼できるランチャーをホワイトリストに載せます。第2段階では一般的なランチャー配置に沿ってディスクを走査し、ゴーストバージョン、不審な mod、リネームや再パックされた JAR（実体は fabric.mod.json や manifest から特定）、クラスバイト内の七十以上の確定的チートシグネチャを、ノイズゼロの報告方針で検出します。付属の Suspicious DLL Finder スクリプトは、コマンドライン監査では見逃しやすい注入 DLL、manual-map、リフレクティブローダー、永続化のチェックを追加します。単一ファイルで依存関係のないスキャナーとして、モデレーター、アンチチート担当、JVM 中心のゲームセキュリティレビューを行うリバースエンジニアに適しています。
