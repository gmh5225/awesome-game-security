JVM Inspector 是一套只读的 PowerShell 取证工具，面向 Windows 上 Minecraft 的屏幕共享审查与作弊检测。主脚本采用两阶段流程：第一阶段审计正在运行的 javaw.exe 与 java.exe 进程，检查 javaagent、native agent、bootclasspath 修改及其他 JVM 注入相关启动参数，并对 Modrinth、Lunar、Badlion、Fabric 等可信启动器做白名单放行。第二阶段按常见启动器目录布局扫描磁盘，查找幽灵版本、可疑模组、经重命名或重打包的 JAR（真实身份来自 fabric.mod.json 或 manifest），并在 class 字节中匹配七十多种硬编码作弊特征，采用零噪声上报策略。配套的 Suspicious DLL Finder 脚本补充注入 DLL、手动映射、反射加载器与持久化等命令行难以发现的检查。工具为单文件、无依赖扫描器，适合版主、反作弊人员及从事 JVM 向游戏安全审查的逆向工程师使用。
