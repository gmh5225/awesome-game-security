MagiskFrida — модуль для root-Android, который при загрузке автоматически запускает frida-server, чтобы хосты могли подключать Frida для динамической инструментализации без ручной настройки сервера. Работает с Magisk, KernelSU и APatch, поставляет бинарники для arm, arm64, x86 и x86_64 и позволяет переопределить локальный порт прослушивания по умолчанию через конфигурационный файл модуля. Сборочный конвейер на Python скачивает официальные релизы Frida и упаковывает устанавливаемые ZIP, выравнивая версии сервера с upstream-сборками Frida. Модуль ориентирован на реверс-инженеров, исследователей безопасности и разработчиков, которым нужен надёжный on-device Frida для анализа мобильных приложений и игр, хукинга и проверки во время выполнения.
