Endstone Paradox 是面向在 Endstone 模组平台上运行的 Minecraft 基岩版专用服务器（BDS）的原生反作弊与服务器管理插件。它主要以 C++23 实现为可加载的原生库，提供数十个模块化检测，涵盖战斗与移动作弊、破坏、复制、数据包滥用及相关基岩版客户端漏洞，并配有违规引擎、SQLite 持久化与工作人员 moderation 管理命令。该栈将 Endstone 的事件与数据包钩子与 bedrock-protocol 解码、TOML 配置、可选的本地 Web 管理界面、Discord 通知及证据回放工具集成在一起；仓库中仍保留较旧的 Python 实现仅供参考。它面向需要在 Endstone 托管的基岩版世界中进行生产级监控、执法与运维控制的服务器运营者与反作弊开发者，而非通用逆向工程工具。
