Endstone Paradox は、Endstone モディングプラットフォーム上で動作する Minecraft Bedrock Dedicated Server 向けのネイティブアンチチートおよびサーバー管理プラグインです。主に C++23 で実装されたロード可能なネイティブライブラリとして提供され、コンバットや移動チート、グリーフィング、複製、パケット悪用、関連する Bedrock クライアントエクスプロイト向けのモジュール式チェックを数十種用意し、違反エンジン、SQLite 永続化、スタッフ向けモデレーションコマンドで支えています。スタックは Endstone のイベントおよびパケットフックと bedrock-protocol デコード、TOML 設定、任意のローカル Web 管理 UI、Discord 通知、証拠リプレイツールを統合し、古い Python 実装は参照用としてリポジトリに残されています。汎用のリバースエンジニアリングユーティリティではなく、Endstone ホストの Bedrock ワールドで本番向けの監視、執行、運用制御が必要なサーバー運営者とアンチチート開発者を対象としています。
