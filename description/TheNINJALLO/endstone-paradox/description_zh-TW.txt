Endstone Paradox 是面向在 Endstone 模組平台上運行的 Minecraft 基岩版專用伺服器（BDS）的原生反作弊與伺服器管理外掛。它主要以 C++23 實作為可載入的原生函式庫，提供數十個模組化檢測，涵蓋戰鬥與移動作弊、破壞、複製、封包濫用及相關基岩版用戶端漏洞，並配有違規引擎、SQLite 持久化與工作人員 moderation 管理指令。該堆疊將 Endstone 的事件與封包鉤子與 bedrock-protocol 解碼、TOML 設定、可選的本地 Web 管理介面、Discord 通知及證據回放工具整合在一起；程式庫中仍保留較舊的 Python 實作僅供參考。它面向需要在 Endstone 託管的基岩版世界中進行生產級監控、執法與維運控制的伺服器營運者與反作弊開發者，而非通用逆向工程工具。
