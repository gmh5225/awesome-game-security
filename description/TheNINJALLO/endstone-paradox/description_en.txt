Endstone Paradox is a native anti-cheat and server administration plugin for Minecraft Bedrock Dedicated Servers running on the Endstone modding platform. It is implemented primarily in C++23 as a loadable native library and ships dozens of modular checks for combat and movement cheats, griefing, duping, packet abuse, and related Bedrock client exploits, backed by a violation engine, SQLite persistence, and staff moderation commands. The stack integrates Endstone’s event and packet hooks with bedrock-protocol decoding, TOML configuration, an optional local web admin UI, Discord notifications, and evidence replay tooling, while an older Python implementation remains in the tree for reference only. It targets server operators and anti-cheat developers who need production-oriented monitoring, enforcement, and operational controls on Endstone-hosted Bedrock worlds rather than generic reverse-engineering utilities.
