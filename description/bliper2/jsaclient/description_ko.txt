JSA Client는 싱글플레이와 공개 LAN 플레이를 위한 Minecraft Java 툴킷으로, 클라이언트 버전 1.6.4부터 26.3까지 지원합니다. Java로 작성된 Gradle 멀티 모듈 프로젝트이며, 버전에 구애받지 않는 코어가 플랫폼 추상화, 이벤트 버스, ClickGUI를 통해 이동·전투·렌더·플레이어·장난 모듈을 제공합니다. 리플렉션 로더는 era 맵과 capability 게이트로 classpath의 임의 Minecraft 클라이언트 JAR에 맞추며, 선택적 Fabric mod 레이어는 mixin으로 고정 릴리스(기본 1.20.1)에 올리고 Meteor Client와 연동해 외부 애드온 모듈을 나열할 수 있습니다. 클라이언트 측 수정 아키텍처, 버전 호환 기법, 게임 시대별 기능 모듈 저하 방식을 연구하는 데 유용하며, 공개 서버의 안티치트 우회는 명시적으로 대상으로 하지 않습니다.
