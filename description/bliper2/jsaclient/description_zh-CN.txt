JSA Client 是一款面向单人游戏与开放局域网游玩的 Minecraft Java 工具集，支持从 1.6.4 到 26.3 的客户端版本。项目以 Java 编写，采用 Gradle 多模块结构，核心与版本无关，通过平台抽象、事件总线与 ClickGUI 提供移动、战斗、渲染、玩家与恶作剧等功能模块。反射式加载器借助时代映射与能力门控，可适配 classpath 上任意 Minecraft 客户端 JAR；可选的 Fabric 模组层通过 mixin 绑定固定版本（默认 1.20.1），并可与 Meteor Client 集成以列出外部附加模块。该项目适合研究客户端修改架构、版本兼容手段以及功能模块在不同游戏世代间的降级行为；明确不针对公共服务器上的反作弊绕过。
