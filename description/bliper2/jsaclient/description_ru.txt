JSA Client — набор инструментов для Minecraft Java, ориентированный на одиночную игру и открытую LAN-сеть, с поддержкой клиентских версий от 1.6.4 до 26.3. Написан на Java как многомодульный проект Gradle с ядром, не привязанным к версии, которое через абстракцию платформы, шину событий и ClickGUI предоставляет модули движения, боя, рендеринга, игрока и розыгрышей. Рефлексивный загрузчик подстраивается под произвольные JAR клиента Minecraft в classpath с помощью карт эпох и capability gates, а опциональный слой мода Fabric использует mixins для фиксированного релиза (по умолчанию 1.20.1) и может интегрироваться с Meteor Client для перечисления внешних модулей-дополнений. Проект полезен для изучения архитектуры клиентских модификаций, приёмов совместимости версий и того, как функциональные модули деградируют между игровыми эпохами; явно не нацелен на обход античита на публичных серверах.
