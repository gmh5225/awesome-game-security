JSA Client は、シングルプレイとオープン LAN 向けの Minecraft Java 向けツールキットで、クライアント版 1.6.4 から 26.3 までをカバーします。Java で書かれた Gradle マルチモジュール構成で、バージョン非依存のコアがプラットフォーム抽象化、イベントバス、ClickGUI を通じて移動・戦闘・描画・プレイヤー・いたずら各モジュールを公開します。リフレクティブローダーは era マップと capability ゲートで classpath 上の任意の Minecraft クライアント JAR に適応し、任意の Fabric  mod レイヤーは mixin で固定リリース（既定 1.20.1）に載せ、Meteor Client と連携して外部アドオンモジュールを一覧できます。クライアント側改変アーキテクチャ、バージョン互換の技法、ゲーム世代を跨ぐ機能モジュールの劣化の研究に有用です。公開サーバー上のアンチチート回避を目的としない旨が明記されています。
