JSA Client è un toolkit Minecraft Java pensato per il gioco in single-player e LAN aperta, con versioni client dalla 1.6.4 alla 26.3. È scritto in Java come progetto Gradle multi-modulo, con un core indipendente dalla versione che espone moduli di movimento, combattimento, rendering, giocatore e scherzi tramite astrazione di piattaforma, event bus e ClickGUI. Un loader riflessivo si adatta a JAR client Minecraft arbitrari nel classpath tramite mappe di era e capability gate, mentre un layer mod Fabric opzionale usa i mixin per una release fissata (predefinita 1.20.1) e può integrarsi con Meteor Client per elencare moduli addon esterni. Il progetto è utile per studiare l’architettura delle modifiche lato client, le tecniche di compatibilità tra versioni e come i moduli funzionali si degradano tra le ere di gioco; non mira esplicitamente al bypass dell’anti-cheat su server pubblici.
