JSA Client is a modular Minecraft Java Edition client toolkit aimed at single-player and open LAN play across a wide range of game versions. It is built primarily in Java with Gradle, splitting a version-agnostic core of combat, movement, player, render, and prank modules from a Fabric adapter for a pinned release and a reflective loader that attaches to arbitrary vanilla client jars from 1.6.4 through current-era builds. The design uses an event bus, configurable module settings, a ClickGUI, and an era or capability matrix so features degrade cleanly when a version lacks the needed APIs, and it explicitly does not target anti-cheat bypass on public servers. Researchers and defenders studying client-side manipulation, module architecture, and multi-version hooking patterns can use it as a reference implementation of QoL cheats, visuals, and LAN-safe troll behavior rather than as a networked cheat framework.
