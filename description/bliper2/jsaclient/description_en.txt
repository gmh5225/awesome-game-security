JSA Client is a Minecraft Java toolkit aimed at single-player and open LAN play, spanning client versions from 1.6.4 through 26.3. It is written in Java as a Gradle multi-module project with a version-agnostic core that exposes movement, combat, render, player, and prank modules through a platform abstraction, event bus, and ClickGUI. A reflective loader adapts to arbitrary Minecraft client JARs on the classpath via era maps and capability gates, while an optional Fabric mod layer uses mixins for a pinned release (default 1.20.1) and can integrate with Meteor Client to list external addon modules. The project is useful for studying client-side modification architecture, version compatibility techniques, and how feature modules degrade across game eras; it explicitly does not target anti-cheat bypass on public servers.
