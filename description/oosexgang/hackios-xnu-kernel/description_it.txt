HackiOS è una piattaforma di ricerca che avvia il kernel XNU open source di Apple per iOS 16.5 su hardware di telefoni Android o in QEMU ed esegue sopra uno spazio utente iOS 16.5 non modificato. Il repository fornisce patch XNU, un loader EFI personalizzato, un port UEFI Mu-Silicium, sostituti di driver in kernel e supporto Wi-Fi basato sul driver ath11k di Linux tramite uno strato di compatibilità, oltre ad artefatti precompilati, script di build e lo strumento di controllo USB xl. L’implementazione è soprattutto in C per loader e modifiche al kernel, con automazione Python e shell per la creazione delle immagini, le esecuzioni QEMU e il bring-up del dispositivo. Le sessioni sono esperimenti effimeri basati su RAM piuttosto che una ROM flashabile, pensati per ricercatori che vogliono studiare il comportamento del kernel iOS, la sicurezza della piattaforma e gli interni mobile a basso livello su hardware Android Qualcomm di consumo o in un ambiente virtuale riproducibile.
