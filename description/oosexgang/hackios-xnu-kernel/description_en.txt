HackiOS is a research platform that boots Apple’s open-source XNU kernel for iOS 16.5 on Android phone hardware or in QEMU and runs an unmodified iOS 16.5 user space on top. The repository supplies XNU patches, a custom EFI loader, a Mu-Silicium UEFI port, in-kernel driver replacements, and Wi-Fi support built around Linux’s ath11k driver on a compatibility layer, plus prebuilt artifacts, build scripts, and the xl USB control tool. Implementation work is primarily in C for the loader and kernel changes, with Python and shell automation for image building, QEMU runs, and device bring-up. Sessions are ephemeral RAM-based experiments rather than a flashable ROM, aimed at researchers who want to study iOS kernel behavior, platform security, and low-level mobile internals on commodity Qualcomm Android hardware or in a reproducible virtual environment.
