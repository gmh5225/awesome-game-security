HackiOS는 Android 폰 하드웨어나 QEMU에서 Apple의 오픈 소스 iOS 16.5용 XNU 커널을 부팅하고, 그 위에서 수정되지 않은 iOS 16.5 사용자 공간을 실행하는 연구용 플랫폼이다. 저장소에는 XNU 패치, 사용자 정의 EFI 로더, Mu-Silicium UEFI 포트, 커널 내 드라이버 대체, Linux ath11k 드라이버와 호환 계층을 기반으로 한 Wi-Fi 지원과 함께 사전 빌드 산출물, 빌드 스크립트, xl USB 제어 도구가 포함된다. 로더와 커널 변경은 주로 C로, 이미지 빌드·QEMU 실행·디바이스 bring-up은 Python과 셸 자동화로 처리한다. 세션은 플래시 가능한 ROM이 아니라 RAM 기반의 일시적 실험이며, 상용 Qualcomm Android 하드웨어나 재현 가능한 가상 환경에서 iOS 커널 동작, 플랫폼 보안, 저수준 모바일 내부를 연구하려는 연구자를 대상으로 한다.
