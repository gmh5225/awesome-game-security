HackiOS 是一個研究平台，可在 Android 手機硬體或 QEMU 中啟動 Apple 開源的 iOS 16.5 版 XNU 核心，並在其上執行未經修改的 iOS 16.5 使用者空間。本儲存庫提供 XNU 修補、自訂 EFI 載入器、Mu-Silicium UEFI 移植、核心內驅動替代實作，以及圍繞 Linux ath11k 驅動與相容層建構的 Wi-Fi 支援，另有預建產物、建置腳本與 xl USB 控制工具。實作工作主要在 C 語言中完成載入器與核心變更，並以 Python 與 shell 腳本自動化映像建置、QEMU 執行與裝置 bring-up。工作階段為基於 RAM 的暫時性實驗而非可刷寫的 ROM，面向希望在商用 Qualcomm Android 硬體或可重現虛擬環境中研究 iOS 核心行為、平台安全與底層行動系統內部機制的研究人員。
