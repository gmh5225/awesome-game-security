HackiOS 是一个研究平台，可在 Android 手机硬件或 QEMU 中启动 Apple 开源的 iOS 16.5 版 XNU 内核，并在其上运行未经修改的 iOS 16.5 用户空间。本仓库提供 XNU 补丁、自定义 EFI 加载器、Mu-Silicium UEFI 移植、内核内驱动替代实现，以及基于 Linux ath11k 驱动与兼容层构建的 Wi-Fi 支持，另有预构建产物、构建脚本和 xl USB 控制工具。实现工作主要在 C 语言中完成加载器与内核改动，并用 Python 与 shell 脚本自动化镜像构建、QEMU 运行与设备 bring-up。会话为基于 RAM 的临时实验而非可刷写的 ROM，面向希望在商用 Qualcomm Android 硬件或可复现虚拟环境中研究 iOS 内核行为、平台安全与底层移动系统内部机制的研究人员。
