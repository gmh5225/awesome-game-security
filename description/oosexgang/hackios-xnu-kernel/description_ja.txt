HackiOS は研究向けプラットフォームで、Android 端末のハードウェアまたは QEMU 上で Apple のオープンソース iOS 16.5 向け XNU カーネルを起動し、その上で変更のない iOS 16.5 ユーザースペースを動かす。リポジトリには XNU パッチ、カスタム EFI ローダー、Mu-Silicium UEFI ポート、カーネル内ドライバ置き換え、Linux の ath11k ドライバを互換レイヤー経由で用いた Wi-Fi サポートに加え、ビルド済み成果物、ビルドスクリプト、xl USB 制御ツールが含まれる。ローダーとカーネル変更は主に C で、イメージ構築・QEMU 実行・デバイス bring-up は Python とシェルで自動化している。セッションは RAM 上の一時的な実験でありフラッシュ可能な ROM ではなく、汎用 Qualcomm Android ハードウェアまたは再現可能な仮想環境で iOS カーネル挙動、プラットフォームセキュリティ、低レベルのモバイル内部を調べたい研究者向けである。
