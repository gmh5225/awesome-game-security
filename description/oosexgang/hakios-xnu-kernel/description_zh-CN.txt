HakiOS 是一项独立研究项目，将 Apple 开源 Darwin 内核（XNU）移植到 Android 手机硬件上运行，并配套自有引导加载程序、内核驱动、类 Linux 配置与构建工具链。代码树主要以 C 和 C++ 编写，包含 GPU（Adreno）、Wi‑Fi、蜂窝网络、存储、输入与电源等平台驱动，以及集成 hakios-metal 栈，在 Qualcomm GPU 上实现类 Metal 图形能力。可在 QEMU 中构建并验证不依赖 Apple 的路径，或在支持的设备上从 RAM 启动并在重启后回到 Android，项目本身并非要替代手机 ROM。适合内核开发者、移动安全研究人员，以及研究 XNU、驱动移植或非 Apple 硬件上底层平台行为的人士。
