HakiOS is an independent research project that ports Apple's open-source Darwin kernel (XNU) to run on Android phone hardware, with its own boot loader, kernel drivers, Linux-style configuration, and build tooling. The tree is built mainly in C and C++ and includes platform drivers for GPU (Adreno), Wi‑Fi, cellular, storage, input, and power, plus an integrated hakios-metal stack that implements Metal-style graphics on Qualcomm GPUs. You can build and exercise an Apple-free path in QEMU, or boot from RAM on supported devices and return to Android after reboot, without treating the project as a replacement phone ROM. It suits kernel developers, mobile security researchers, and anyone studying XNU, driver bring-up, or low-level platform behavior on non-Apple hardware.
