HakiOS は、Apple のオープンソース Darwin カーネル（XNU）を Android スマートフォン向けハードウェア上で動作するよう移植する独立研究プロジェクトで、独自のブートローダー、カーネルドライバー、Linux 風の設定、ビルドツールを備えています。ツリーは主に C と C++ で構成され、GPU（Adreno）、Wi‑Fi、セルラー、ストレージ、入力、電源向けのプラットフォームドライバーに加え、Qualcomm GPU 上で Metal 風グラフィックスを実装する統合 hakios-metal スタックを含みます。QEMU 上で Apple 非依存の経路をビルド・検証でき、対応デバイスでは RAM から起動し再起動後に Android に戻ることも可能で、本プロジェクトを代替 ROM として位置づけるものではありません。カーネル開発者、モバイルセキュリティ研究者、および非 Apple ハードウェア上の XNU、ドライバー移植、低レベルプラットフォーム挙動を学ぶ方に適しています。
