HakiOS 是一項獨立研究專案，將 Apple 開源 Darwin 核心（XNU）移植到 Android 手機硬體上執行，並具備專用的開機載入程式、核心驅動程式、類 Linux 設定與建置工具鏈。程式碼樹主要以 C 與 C++ 撰寫，包含 GPU（Adreno）、Wi‑Fi、行動網路、儲存、輸入與電源等平台驅動，以及整合的 hakios-metal 堆疊，在 Qualcomm GPU 上實作類 Metal 圖形能力。可在 QEMU 中建置並驗證不依賴 Apple 的路徑，或在支援的裝置上從 RAM 開機並在重新開機後回到 Android，專案本身並非要取代手機 ROM。適合核心開發者、行動安全研究人員，以及研究 XNU、驅動程式移植或非 Apple 硬體上底層平台行為的人士。
