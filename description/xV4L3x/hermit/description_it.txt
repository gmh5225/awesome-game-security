Hermit è un toolkit interattivo per ispezionare, decompilare e applicare patch strutturali al bytecode Hermes (HBC), il formato con cui le applicazioni React Native distribuiscono JavaScript nei bundle Android e iOS. La libreria core in C++ gestisce parsing, disassemblaggio, analisi del flusso di controllo, decompilazione deterministica in JavaScript e completa riserializzazione, così che istruzioni, stringhe, literal e funzioni possano essere inseriti o rimossi mantenendo i file caricabili dalla VM Hermes. Un livello Python offre una REPL in stile GDB con editor di bytecode, recupero moduli Metro, riferimenti incrociati e strumenti da riga di comando hbc autonomi, con binding pybind11 per l’uso programmatico. Supporta le versioni HBC dalla 94 alla 96 e round-trip identici a livello di byte su input non modificati. Il progetto è pensato per reverse engineer e ricercatori di sicurezza che devono analizzare o patchare la logica compilata di React Native e app mobili senza affidarsi a strumenti solo in-place o solo di visualizzazione.
