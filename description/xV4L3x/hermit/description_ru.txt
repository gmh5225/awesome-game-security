Hermit — интерактивный набор инструментов для просмотра, декомпиляции и структурного патчинга байткода Hermes (HBC), формата, которым приложения React Native упаковывают JavaScript в бандлы Android и iOS. Ядро на C++ выполняет разбор, дизасsemblирование, анализ потока управления, детерминированную декомпиляцию в JavaScript и полную повторную сериализацию, чтобы инструкции, строки, литералы и функции можно было добавлять или удалять, сохраняя загрузку файлов виртуальной машиной Hermes. Слой на Python предоставляет REPL в стиле GDB с редакторами байткода, восстановлением модулей Metro, перекрёстными ссылками и автономными утилитами командной строки hbc, а также привязки pybind11 для программного использования. Поддерживаются версии HBC с 94 по 96 и побайтовое совпадение при round-trip на неизменённых входных данных. Проект подходит reverse-инженерам и исследователям безопасности, которым нужно анализировать или патчить скомпилированную логику React Native и мобильных приложений без инструментов, ограниченных только правкой на месте или просмотром.
