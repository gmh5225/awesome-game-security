Hermit は、React Native アプリが Android および iOS バンドルで JavaScript を配布する際に使う Hermes バイトコード（HBC）を検査・逆コンパイル・構造的にパッチするための対話型ツールキットです。C++ コアライブラリがパース、逆アセンブル、制御フロー解析、JavaScript への決定論的逆コンパイル、完全な再シリアライズを担い、Hermes VM が読み込める状態を保ちながら命令・文字列・リテラル・関数の挿入や削除が可能です。Python 層は GDB 風 REPL、バイトコードエディタ、Metro モジュール復元、クロスリファレンス、スタンドアロンの hbc コマンドラインツールを提供し、pybind11 バインディングでプログラムからも利用できます。HBC バージョン 94〜96 を対象とし、未変更入力ではバイト単位で同一のラウンドトリップをサポートします。コンパイル済み React Native やモバイルアプリのロジックを、インプレース専用や閲覧専用のツールに頼らず分析・パッチしたいリバースエンジニアやセキュリティ研究者向けのプロジェクトです。
