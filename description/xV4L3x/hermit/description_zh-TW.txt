Hermit 是一套互動式工具包，用於檢查、反編譯並對 Hermes 位元組碼（HBC）進行結構化修補；此格式為 React Native 應用程式在 Android 與 iOS 套件中打包 JavaScript 時所使用。其 C++ 核心函式庫負責解析、反組譯、控制流程分析、確定性反編譯為 JavaScript，以及完整重序列化，因而可在檔案仍能被 Hermes VM 載入的前提下插入或移除指令、字串、常值與函式。Python 層提供 GDB 風格的 REPL、位元組碼編輯器、Metro 模組還原、交叉參考以及獨立的 hbc 命令列工具，並透過 pybind11 繫結支援程式化使用。它支援 HBC 版本 94 至 96，對未修改的輸入可達位元組級一致的往返。本專案適合需要分析或修補已編譯 React Native 與行動應用邏輯、且不願依賴僅就地修改或僅檢視類工具的反工程師與安全研究人員。
