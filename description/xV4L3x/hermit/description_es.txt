Hermit es un kit de herramientas interactivo para inspeccionar, descompilar y aplicar parches estructurales al bytecode Hermes (HBC), el formato que usan las aplicaciones React Native para empaquetar JavaScript en bundles de Android e iOS. Su biblioteca central en C++ se encarga del análisis sintáctico, el desensamblado, el análisis de flujo de control, la descompilación determinista a JavaScript y la reserialización completa, de modo que se pueden insertar o eliminar instrucciones, cadenas, literales y funciones manteniendo los archivos cargables por la VM Hermes. Una capa en Python ofrece un REPL al estilo GDB con editores de bytecode, recuperación de módulos Metro, referencias cruzadas y herramientas de línea de comandos hbc independientes, con enlaces pybind11 para uso programático. Está orientado a las versiones HBC 94 a 96 y admite idas y vueltas idénticas a nivel de byte en entradas sin modificar. El proyecto está pensado para ingenieros inversos e investigadores de seguridad que necesitan analizar o parchear la lógica compilada de React Native y aplicaciones móviles sin depender de herramientas solo in situ o solo de visualización.
