Hermit 是一款交互式工具包，用于检查、反编译并对 Hermes 字节码（HBC）进行结构化补丁；该格式是 React Native 应用在 Android 与 iOS 包中打包 JavaScript 时所使用的。其 C++ 核心库负责解析、反汇编、控制流分析、确定性反编译为 JavaScript，以及完整重序列化，从而可在保持文件仍能被 Hermes VM 加载的前提下插入或删除指令、字符串、字面量与函数。Python 层提供 GDB 风格的 REPL、字节码编辑器、Metro 模块恢复、交叉引用以及独立的 hbc 命令行工具，并通过 pybind11 绑定支持编程调用。它面向 HBC 版本 94 至 96，对未修改的输入支持字节级一致的往返。该项目适合需要分析或修补已编译 React Native 与移动应用逻辑、且不愿依赖仅原地修改或仅查看类工具的反工程师与安全研究人员。
