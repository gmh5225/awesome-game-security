Hermit는 React Native 앱이 Android 및 iOS 번들에서 JavaScript를 배포할 때 사용하는 Hermes 바이트코드(HBC)를 검사·디컴파일·구조적으로 패치하기 위한 대화형 툴킷입니다. C++ 코어 라이브러리는 파싱, 디스어셈블리, 제어 흐름 분석, JavaScript로의 결정적 디컴파일, 완전한 재직렬화를 처리하여 Hermes VM이 로드할 수 있는 상태를 유지하면서 명령, 문자열, 리터럴, 함수를 삽입하거나 제거할 수 있습니다. Python 계층은 GDB 스타일 REPL, 바이트코드 편집기, Metro 모듈 복구, 교차 참조, 독립 hbc 명령줄 도구를 제공하며 pybind11 바인딩으로 프로그래밍 방식 사용을 지원합니다. HBC 버전 94~96을 대상으로 하며 수정되지 않은 입력에 대해 바이트 단위로 동일한 라운드트립을 지원합니다. 제자리 전용 또는 보기 전용 도구에 의존하지 않고 컴파일된 React Native 및 모바일 앱 로직을 분석하거나 패치해야 하는 리버스 엔지니어와 보안 연구자에게 적합한 프로젝트입니다.
