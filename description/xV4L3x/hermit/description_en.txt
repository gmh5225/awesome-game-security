Hermit is an interactive toolkit for inspecting, decompiling, and structurally patching Hermes bytecode (HBC), the format React Native applications use to ship JavaScript in Android and iOS bundles. Its C++ core library handles parsing, disassembly, control-flow analysis, deterministic decompilation to JavaScript, and full re-serialization so instructions, strings, literals, and functions can be inserted or removed while keeping files loadable by the Hermes VM. A Python layer provides a GDB-style REPL with bytecode editors, Metro module recovery, cross-references, and standalone hbc command-line tools, with pybind11 bindings for programmatic use. It targets HBC versions 94 through 96 and supports byte-identical round-trips on unmodified inputs. The project suits reverse engineers and security researchers who need to analyze or patch compiled React Native and mobile app logic without relying on in-place-only or view-only tooling.
