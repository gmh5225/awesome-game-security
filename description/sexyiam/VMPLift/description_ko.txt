VMPLift는 언팩된 VMProtect 3.8부터 3.10+ x64 바이너리에서 가상화 핸들러를 순회하고 리프트하는 C++ 도구입니다. 에뮬레이션 우선 접근 방식으로 VIP 바이트코드를 추적하고, 간접 디스패치를 해석하며, 구형 정적 opcode 테이블 도구를 무력화하는 롤링 키 상태를 복구합니다. 파이프라인은 VM 진입점을 스캔하고, 핸들러 블록을 분류한 뒤 중간 표현으로 리프트하며, 핸들러가 단순 함수로 환원될 수 있을 때 LLVM IR, 의사 C, VIP 트레이스, 가상화 해제된 네이티브 코드를 출력할 수 있습니다. VMProtect로 보호된 실행 파일(게임 클라이언트 및 최신 VMProtect 가상화 기능으로 보호된 기타 소프트웨어 포함)을 분석하는 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
