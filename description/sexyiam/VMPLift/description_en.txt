VMPLift is a C++ tool that walks and lifts virtualized handlers from unpacked VMProtect 3.8 through 3.10+ x64 binaries. It uses an emulation-first approach to trace VIP bytecode, resolve indirect dispatch, and recover rolling-key state that breaks older static opcode-table tools. The pipeline scans for VM entry points, classifies handler blocks, lifts them to intermediate representation, and can emit LLVM IR, pseudo-C, VIP traces, and devirtualized native code when handlers reduce to simple functions. It targets reverse engineers and security researchers analyzing VMProtect-protected executables, including game clients and other software protected with newer VMProtect virtualization features.
