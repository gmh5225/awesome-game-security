VMPLift 是一款 C++ 工具，用於遍歷並從已脫殼的 VMProtect 3.8 至 3.10+ x64 二進位檔中提取虛擬化 handler。它採用以模擬為先的方法追蹤 VIP 位元組碼、解析間接分派，並還原滾動金鑰狀態，從而突破舊版靜態操作碼表工具的限制。該管線掃描 VM 進入點、分類 handler 區塊、將其提升為中間表示，並在 handler 可簡化為簡單函式時輸出 LLVM IR、偽 C 程式碼、VIP 追蹤以及去虛擬化後的原生程式碼。它面向分析 VMProtect 保護可執行檔的逆向工程師與安全研究人員，包括遊戲用戶端及其他採用較新 VMProtect 虛擬化功能的軟體。
