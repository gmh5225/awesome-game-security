VMPLift — это инструмент на C++, который обходит и поднимает виртуализированные обработчики из распакованных x64-бинарников VMProtect 3.8–3.10+. Он использует подход с приоритетом эмуляции для трассировки VIP-байткода, разрешения косвенной диспетчеризации и восстановления состояния rolling-key, которое делает неэффективными старые статические инструменты с таблицами опкодов. Конвейер сканирует точки входа VM, классифицирует блоки обработчиков, поднимает их до промежуточного представления и может выводить LLVM IR, псевдо-C, трассировки VIP и нативный код с снятой виртуализацией, когда обработчики сводятся к простым функциям. Он предназначен для reverse-инженеров и исследователей безопасности, анализирующих исполняемые файлы, защищённые VMProtect, включая игровые клиенты и другое ПО с новыми функциями виртуализации VMProtect.
