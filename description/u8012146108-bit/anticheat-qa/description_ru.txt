AntiCheat QA — клиентский мод Fabric для Minecraft 1.21.11, который помогает разработчикам наблюдать, визуализировать, логировать и безопасно симулировать поведение античита, не предоставляя игровых читов или обходов. Написан на Java с использованием Fabric API и mixin, предоставляет модульный ClickGUI и HUD-оверлей с мониторами reach, движения, поворота, CPS, скорости, ping, FPS и тайминга тиков, а также инструменты визуализации: ESP, трассеры, nametags, fullbright и FreeCam. Модули для QA включают обзорную панель, тестовый симулятор для локального логирования событий обнаружения и Y-Level Probe, который подсчитывает видимые клиенту блоки, сундуки и сущности ниже Y=0 для проверки серверной фильтрации данных. Предназначен для операторов серверов Minecraft и инженеров античита, которым нужен специализированный клиентский набор инструментов для проверки того, что серверная защита работает как задумано.
