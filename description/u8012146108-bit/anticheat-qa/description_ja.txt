AntiCheat QA は Minecraft 1.21.11 向けの Fabric クライアント mod で、ゲームプレイのチートや回避手段を提供することなく、開発者がアンチチートの挙動を観察・可視化・ログ記録・安全にシミュレートするのを支援します。Java と Fabric API、mixin で書かれており、モジュラーな ClickGUI と HUD オーバーレイを提供し、reach、移動、回転、CPS、速度、ping、FPS、tick タイミングを監視できるほか、ESP、トレーサー、ネームタグ、フルブライト、FreeCam などの可視化ツールも備えています。QA 向けモジュールにはダッシュボード概要、ローカルな検知イベントのログ記録用テストシミュレーター、Y=0 より下のクライアント可視ブロック・チェスト・エンティティを数えてサーバー側のデータ除去を検証する Y-Level Probe があります。サーバー保護が意図どおり機能するかを検証する専用クライアントツールキットを必要とする Minecraft サーバー運営者とアンチチートエンジニア向けです。
