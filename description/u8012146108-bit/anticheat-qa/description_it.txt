AntiCheat QA è un mod client Fabric per Minecraft 1.21.11 che aiuta gli sviluppatori a osservare, visualizzare, registrare e simulare in modo sicuro il comportamento dell'anti-cheat, senza fornire cheat o bypass di gameplay. Scritto in Java con Fabric API e mixin, espone una ClickGUI modulare e un overlay HUD con monitor per reach, movimento, rotazione, CPS, velocità, ping, FPS e timing dei tick, oltre a strumenti di visualizzazione come ESP, tracer, nametag, fullbright e FreeCam. I moduli orientati al QA includono una panoramica dashboard, un simulatore di test per la registrazione locale degli eventi di rilevamento e un Y-Level Probe che conta blocchi, bauli ed entità visibili lato client sotto Y=0 per verificare la rimozione dei dati lato server. È pensato per operatori di server Minecraft e ingegneri anti-cheat che necessitano di un toolkit client dedicato per validare che le protezioni del server funzionino come previsto.
