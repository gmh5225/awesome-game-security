AntiCheat QA 是一款面向 Minecraft 1.21.11 的 Fabric 客户端模组，帮助开发者观察、可视化、记录并安全模拟反作弊行为，而不提供游戏作弊或绕过功能。该模组使用 Java 编写，基于 Fabric API 与 mixin，提供模块化的 ClickGUI 和 HUD 叠加层，可监控攻击距离、移动、旋转、CPS、速度、延迟、FPS 与 tick 时序，并包含 ESP、追踪线、名称标签、全亮和 FreeCam 等可视化工具。面向 QA 的模块包括仪表盘概览、用于本地检测事件记录的测试模拟器，以及 Y-Level Probe——用于统计 Y=0 以下客户端可见的方块、箱子和实体，以验证服务端数据剥离。它面向需要专用客户端工具包来验证服务器防护是否按预期工作的 Minecraft 服主与反作弊工程师。
