AntiCheat QA는 Minecraft 1.21.11용 Fabric 클라이언트 mod로, 게임플레이 치트나 우회 기능을 제공하지 않으면서 개발자가 안티치트 동작을 관찰·시각화·로깅·안전하게 시뮬레이션할 수 있도록 돕습니다. Java와 Fabric API, mixin으로 작성되었으며, 모듈형 ClickGUI와 HUD 오버레이를 제공하고 reach, 이동, 회전, CPS, 속도, ping, FPS, tick 타이밍을 모니터링할 수 있으며 ESP, 트레이서, 네임태그, 풀브라이트, FreeCam 같은 시각화 도구도 포함합니다. QA 중심 모듈로는 대시보드 개요, 로컬 탐지 이벤트 로깅용 테스트 시뮬레이터, Y=0 아래 클라이언트에서 보이는 블록·상자·엔티티를 세어 서버 측 데이터 제거를 검증하는 Y-Level Probe가 있습니다. 서버 보호가 의도대로 작동하는지 검증할 전용 클라이언트 도구 키트가 필요한 Minecraft 서버 운영자와 안티치트 엔지니어를 대상으로 합니다.
