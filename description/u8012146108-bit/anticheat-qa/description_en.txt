AntiCheat QA is a Fabric client mod for Minecraft 1.21.11 that helps developers observe, visualize, log, and safely simulate anti-cheat behavior without providing gameplay cheats or bypasses. Written in Java with Fabric API and mixins, it exposes a modular ClickGUI and HUD overlay with monitors for reach, movement, rotation, CPS, velocity, ping, FPS, and tick timing, plus visualization tools such as ESP, tracers, nametags, fullbright, and FreeCam. QA-focused modules include a dashboard overview, a test simulator for local detection-event logging, and a Y-Level Probe that counts client-visible blocks, chests, and entities below Y=0 to verify server-side data stripping. It is aimed at Minecraft server operators and anti-cheat engineers who need a dedicated client-side toolkit to validate that server protections work as intended.
