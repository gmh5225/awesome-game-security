AntiCheat QA 是一款面向 Minecraft 1.21.11 的 Fabric 用戶端模組，協助開發者觀察、視覺化、記錄並安全模擬反作弊行為，而不提供遊戲作弊或繞過功能。此模組以 Java 撰寫，使用 Fabric API 與 mixin，提供模組化的 ClickGUI 和 HUD 疊加層，可監控攻擊距離、移動、旋轉、CPS、速度、延遲、FPS 與 tick 時序，並包含 ESP、追蹤線、名稱標籤、全亮和 FreeCam 等視覺化工具。面向 QA 的模組包括儀表板概覽、用於本機偵測事件記錄的測試模擬器，以及 Y-Level Probe——用於統計 Y=0 以下用戶端可見的方塊、箱子與實體，以驗證伺服器端資料剝離。它面向需要專用用戶端工具包來驗證伺服器防護是否按預期運作的 Minecraft 服主與反作弊工程師。
