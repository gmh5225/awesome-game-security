NEXUS는 root 권한이 활성화된 Android 런타임 유틸리티로, 기기 식별 제어, 환경 정화, 실시간 런타임 관측을 위해 특권 시스템 작업을 조율합니다. Kotlin과 Jetpack Compose UI로 작성되었으며, 6개의 명령 모듈이 su를 통해 번들된 root 엔진을 실행하는 매크로 실행 아키텍처를 사용합니다. Android ID, MAC, IMEI, build.prop 스푸핑을 위한 DeviceSpoofingEngine과 BuildPropEngine, IP 재설정, iptables DNS 라우팅, 캐시 정리, Google 원격 측정 정리를 위한 NetworkEngine, DnsTunnelEngine, MemoryPurgeEngine, GmailAutomationEngine이 포함됩니다. Ghost Module 바로가기는 메인 UI를 열지 않고 백그라운드에서 다층 스텔스 작업을 조용히 실행할 수 있습니다. 앱은 ViewModel 상태로 구동되는 실시간 터미널 콘솔을 제공하여 각 특권 작업에 대한 실시간 피드백을 표시합니다. root된 Android 환경을 대상으로 하며, 게임 보안 연구, 기기 지문 회피, 밴 방지를 위한 식별자 순환, 윤리적 보안 실험에 활용됩니다.
