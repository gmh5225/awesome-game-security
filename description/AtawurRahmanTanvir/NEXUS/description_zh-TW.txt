NEXUS 是一款具備 root 權限的 Android 執行階段工具，用於編排特權系統操作，實現裝置身分控制、環境清理與即時執行階段可觀測性。此應用程式以 Kotlin 撰寫，採用 Jetpack Compose UI，並透過巨集執行架構讓六個命令模組經 su 觸發內建 root 引擎，包括用於 Android ID、MAC、IMEI 及 build.prop 偽裝的 DeviceSpoofingEngine 與 BuildPropEngine，以及用於 IP 重置、iptables DNS 路由、快取清理和 Google 遙測清理的 NetworkEngine、DnsTunnelEngine、MemoryPurgeEngine 與 GmailAutomationEngine。Ghost Module 捷徑可在背景靜默執行多層隱身操作，無需開啟主介面。應用程式透過 ViewModel 狀態驅動的即時終端機主控台，為每項特權操作提供即時回饋。它面向已 root 的 Android 環境，適用於遊戲安全研究、裝置指紋規避、防封身分輪換以及合規的安全實驗。
