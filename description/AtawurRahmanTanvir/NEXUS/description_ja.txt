NEXUS は root 権限を前提とした Android ランタイムユーティリティで、デバイス ID 制御、環境のサニタイズ、ライブランタイムの可観測性のために特権システム操作を統括します。Kotlin と Jetpack Compose UI で実装され、6 つのコマンドモジュールが su 経由で同梱の root エンジンを起動するマクロ実行アーキテクチャを採用しています。Android ID、MAC、IMEI、build.prop の偽装には DeviceSpoofingEngine と BuildPropEngine、IP リセット、iptables による DNS ルーティング、キャッシュのパージ、Google テレメトリのクリーンアップには NetworkEngine、DnsTunnelEngine、MemoryPurgeEngine、GmailAutomationEngine が含まれます。Ghost Module ショートカットはメイン UI を開かずに、バックグラウンドで多層ステルス操作を静かに実行できます。アプリは ViewModel 状態に基づくライブ端末コンソールを提供し、各特権操作へのリアルタイムフィードバックを表示します。root 化された Android 環境向けで、ゲームセキュリティ研究、デバイスフィンガープリント回避、BAN 対策の ID ローテーション、倫理的なセキュリティ実験を目的としています。
