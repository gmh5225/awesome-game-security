NEXUS — это утилита среды выполнения Android с root-доступом, которая координирует привилегированные системные операции для управления идентичностью устройства, очистки окружения и наблюдаемости среды выполнения в реальном времени. Написана на Kotlin с интерфейсом Jetpack Compose и использует архитектуру макроисполнения, где шесть командных модулей через su запускают встроенные root-движки, включая DeviceSpoofingEngine и BuildPropEngine для подмены Android ID, MAC, IMEI и build.prop, а также NetworkEngine, DnsTunnelEngine, MemoryPurgeEngine и GmailAutomationEngine для сброса IP, маршрутизации DNS через iptables, очистки кэша и удаления телеметрии Google. Ярлык Ghost Module может незаметно выполнять многоуровневые скрытые операции в фоне без открытия основного интерфейса. Приложение предоставляет живую терминальную консоль на основе состояния ViewModel для обратной связи в реальном времени по каждому привилегированному действию. Ориентировано на рутированные Android-среды для исследований безопасности игр, обхода отпечатков устройства, ротации идентичности против банов и этичных экспериментов в области безопасности.
