NEXUS 是一款具备 root 权限的 Android 运行时工具，用于编排特权系统操作，实现设备身份控制、环境清理与实时运行时可观测性。该应用使用 Kotlin 编写，采用 Jetpack Compose UI，并通过宏执行架构让六个命令模块经 su 调用内置 root 引擎，包括用于 Android ID、MAC、IMEI 及 build.prop 伪装的 DeviceSpoofingEngine 与 BuildPropEngine，以及用于 IP 重置、iptables DNS 路由、缓存清理和 Google 遥测清理的 NetworkEngine、DnsTunnelEngine、MemoryPurgeEngine 与 GmailAutomationEngine。Ghost Module 快捷方式可在后台静默执行多层隐身操作，无需打开主界面。应用通过 ViewModel 状态驱动的实时终端控制台，为每项特权操作提供即时反馈。它面向已 root 的 Android 环境，适用于游戏安全研究、设备指纹规避、防封身份轮换以及合规的安全实验。
