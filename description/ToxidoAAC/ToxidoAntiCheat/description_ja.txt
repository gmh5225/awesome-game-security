Toxido Anti Cheat は、JVM Attach API 経由で Java エージェントをアタッチし、クライアントにモッドを入れずに実行中のゲームプロセスを監視する、クライアント側の Minecraft アンチチートです。Windows のバックグラウンドサービスがバニラ、Fabric、Quilt、Forge、NeoForge の JVM を検出し、エージェントをロードしてループバック IPC のハンドシェイクとハートビートを行い、HMAC-SHA256 で保護された Python FastAPI バックエンドにセッションを登録します。スタックは主に Java（ランチャーアプリと注入可能エージェント用 Maven モジュール）と Python（SQLite 永続化およびプレイヤーごとの Now チャンネルと Log チャンネルを開設・アーカイブする discord.py ボット）で構成されています。フェーズ1では、jlink でパッケージしたスタンドアロン EXE によりセッションライフサイクル、テレメトリ、スタッフ向け Discord 可視性を提供します。計画中のフェーズ2では JVM 計装によるチートおよびモッド署名スキャンを追加し、サーバー側の取り締まりに加えクライアント側の検知と監視を求める Minecraft コミュニティ向けの構成です。
