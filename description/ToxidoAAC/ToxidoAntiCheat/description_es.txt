Toxido Anti Cheat es un anti-cheat de Minecraft en el cliente que supervisa los procesos del juego en ejecución adjuntando un agente Java mediante la JVM Attach API, sin requerir mods en el cliente. Un servicio en segundo plano de Windows detecta JVM de vanilla, Fabric, Quilt, Forge o NeoForge, carga el agente, intercambia handshakes y latidos IPC por loopback y registra sesiones en un backend Python FastAPI protegido con HMAC-SHA256. La pila está construida principalmente en Java (módulos Maven para la aplicación lanzadora y el agente inyectable) y Python (persistencia SQLite más un bot discord.py que abre y archiva canales Now y Log por jugador). La fase uno ofrece ciclo de vida de sesiones, telemetría y visibilidad en Discord para el personal mediante un EXE independiente empaquetado con jlink; la fase dos planificada añade instrumentación JVM para escanear firmas de trampas y mods, orientada a comunidades de Minecraft que quieren detección y monitorización en el cliente junto con la aplicación en el servidor.
