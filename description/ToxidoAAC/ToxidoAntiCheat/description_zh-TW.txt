Toxido Anti Cheat 是一款用戶端 Minecraft 反作弊方案，透過 JVM Attach API 掛載 Java agent 來監控執行中的遊戲程序，無需在客戶端安裝模組。Windows 背景服務可發現原版、Fabric、Quilt、Forge 或 NeoForge 的 JVM，載入 agent，在本機回環上完成 IPC 握手與心跳，並以 HMAC-SHA256 保護的方式向 Python FastAPI 後端註冊工作階段。技術棧以 Java（Maven 模組承載啟動器與可注入 agent）和 Python（SQLite 持久化以及基於 discord.py 的機器人，用於建立並封存每位玩家的 Now 與 Log 頻道）為主。第一階段透過獨立 jlink 封裝的 EXE 提供工作階段生命週期、遙測以及面向工作人員的 Discord 可見性；計畫中的第二階段將增加 JVM 插樁以掃描作弊與模組簽章，適合希望在伺服端規管之外輔以用戶端偵測與監控的 Minecraft 社群。
