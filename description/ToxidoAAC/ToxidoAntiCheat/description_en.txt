Toxido Anti Cheat is a client-side Minecraft anti-cheat that monitors running game processes by attaching a Java agent through the JVM Attach API, without requiring mods in the client. A Windows background service discovers vanilla, Fabric, Quilt, Forge, or NeoForge JVMs, loads the agent, exchanges loopback IPC handshakes and heartbeats, and registers sessions with a Python FastAPI backend protected by HMAC-SHA256. The stack is built mainly in Java (Maven modules for the launcher app and injectable agent) and Python (SQLite persistence plus a discord.py bot that opens and archives per-player Now and Log channels). Phase one delivers session lifecycle, telemetry, and staff-facing Discord visibility via a standalone jlink-packaged EXE; planned phase two adds JVM instrumentation for cheat and mod signature scanning, making it suited to Minecraft communities that want client-side detection and monitoring alongside server enforcement.
