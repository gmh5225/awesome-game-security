Toxido Anti Cheat è un anti-cheat Minecraft lato client che monitora i processi di gioco in esecuzione collegando un agente Java tramite la JVM Attach API, senza richiedere mod sul client. Un servizio in background su Windows individua JVM vanilla, Fabric, Quilt, Forge o NeoForge, carica l’agente, scambia handshake e heartbeat IPC in loopback e registra le sessioni presso un backend Python FastAPI protetto da HMAC-SHA256. Lo stack è costruito principalmente in Java (moduli Maven per l’app launcher e l’agente iniettabile) e Python (persistenza SQLite più un bot discord.py che apre e archivia canali Now e Log per giocatore). La fase uno offre ciclo di vita delle sessioni, telemetria e visibilità Discord per lo staff tramite un EXE standalone impacchettato con jlink; la fase due prevista aggiunge strumentazione JVM per la scansione di firme di cheat e mod, adatta a comunità Minecraft che vogliono rilevamento e monitoraggio lato client oltre all’applicazione lato server.
