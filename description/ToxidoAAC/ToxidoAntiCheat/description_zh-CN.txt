Toxido Anti Cheat 是一款客户端 Minecraft 反作弊方案，通过 JVM Attach API 挂载 Java agent 来监控运行中的游戏进程，无需在客户端安装模组。Windows 后台服务可发现原版、Fabric、Quilt、Forge 或 NeoForge 的 JVM，加载 agent，在本地回环上完成 IPC 握手与心跳，并以 HMAC-SHA256 保护的方式向 Python FastAPI 后端注册会话。技术栈以 Java（Maven 模块承载启动器与可注入 agent）和 Python（SQLite 持久化以及基于 discord.py 的机器人，用于创建并归档每位玩家的 Now 与 Log 频道）为主。第一阶段通过独立 jlink 打包的 EXE 提供会话生命周期、遥测以及面向工作人员的 Discord 可见性；计划中的第二阶段将增加 JVM 插桩以扫描作弊与模组签名，适合希望在服务器端规管之外辅以客户端检测与监控的 Minecraft 社区。
