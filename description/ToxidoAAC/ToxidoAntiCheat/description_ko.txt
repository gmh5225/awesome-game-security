Toxido Anti Cheat는 JVM Attach API로 Java 에이전트를 부착해 실행 중인 게임 프로세스를 모니터링하는 클라이언트 측 Minecraft 안티치트이며, 클라이언트에 모드가 필요하지 않습니다. Windows 백그라운드 서비스가 바닐라, Fabric, Quilt, Forge 또는 NeoForge JVM을 찾아 에이전트를 로드하고, 루프백 IPC 핸드셰이크와 하트비트를 교환하며 HMAC-SHA256으로 보호된 Python FastAPI 백엔드에 세션을 등록합니다. 스택은 주로 Java(Maven 모듈로 런처 앱과 주입 가능한 에이전트)와 Python(SQLite 영속성 및 플레이어별 Now 및 Log 채널을 열고 아카이브하는 discord.py 봇)으로 구성됩니다. 1단계에서는 jlink로 패키징한 독립 EXE로 세션 수명 주기, 원격 측정, 스태프용 Discord 가시성을 제공하며, 계획된 2단계에서는 JVM 계측을 추가해 치트 및 모드 서명 스캔을 수행하여 서버 단 위반 조치와 함께 클라이언트 측 탐지 및 모니터링을 원하는 Minecraft 커뮤니티에 적합합니다.
