Toxido Anti Cheat est un anti-triche Minecraft côté client qui surveille les processus de jeu en cours en attachant un agent Java via l’API JVM Attach, sans exiger de mods sur le client. Un service Windows en arrière-plan détecte les JVM vanilla, Fabric, Quilt, Forge ou NeoForge, charge l’agent, échange des poignées de main et battements de cœur IPC en boucle locale et enregistre les sessions auprès d’un backend Python FastAPI protégé par HMAC-SHA256. La pile repose principalement sur Java (modules Maven pour l’application lanceur et l’agent injectable) et Python (persistance SQLite plus un bot discord.py qui ouvre et archive des canaux Now et Log par joueur). La phase un livre le cycle de vie des sessions, la télémétrie et la visibilité Discord pour le staff via un EXE autonome empaqueté avec jlink ; la phase deux prévue ajoute l’instrumentation JVM pour scanner les signatures de triches et de mods, ce qui convient aux communautés Minecraft souhaitant une détection et une surveillance côté client en complément de l’application des règles côté serveur.
