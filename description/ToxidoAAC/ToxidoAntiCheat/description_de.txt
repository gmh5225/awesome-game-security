Toxido Anti Cheat ist ein clientseitiges Minecraft-Anti-Cheat, das laufende Spielprozesse über das Anhängen eines Java-Agents per JVM Attach API überwacht, ohne Mods auf dem Client zu verlangen. Ein Windows-Hintergrunddienst findet Vanilla-, Fabric-, Quilt-, Forge- oder NeoForge-JVMs, lädt den Agenten, tauscht Loopback-IPC-Handshakes und Heartbeats aus und registriert Sitzungen bei einem per HMAC-SHA256 geschützten Python-FastAPI-Backend. Der Stack besteht vor allem aus Java (Maven-Module für Launcher-App und injizierbaren Agent) und Python (SQLite-Persistenz plus ein discord.py-Bot, der pro Spieler Now- und Log-Kanäle öffnet und archiviert). Phase eins liefert Sitzungslebenszyklus, Telemetrie und Discord-Sichtbarkeit für das Team über eine eigenständige, mit jlink gepackte EXE; die geplante Phase zwei ergänzt JVM-Instrumentierung zum Scannen von Cheat- und Mod-Signaturen und eignet sich für Minecraft-Communities, die clientseitige Erkennung und Überwachung neben serverseitiger Durchsetzung wünschen.
