Toxido Anti Cheat — клиентский античит для Minecraft, который отслеживает запущенные игровые процессы, подключая Java-агент через JVM Attach API без необходимости модов на клиенте. Фоновая служба Windows обнаруживает JVM vanilla, Fabric, Quilt, Forge или NeoForge, загружает агент, обменивается IPC-рукопожатиями и heartbeat по loopback и регистрирует сессии в бэкенде Python FastAPI, защищённом HMAC-SHA256. Стек в основном на Java (Maven-модули для лаунчера и внедряемого агента) и Python (персистентность SQLite и бот на discord.py, открывающий и архивирующий каналы Now и Log для каждого игрока). Первая фаза даёт жизненный цикл сессий, телеметрию и видимость в Discord для персонала через автономный EXE, собранный jlink; запланированная вторая фаза добавит инструментирование JVM для сканирования сигнатур читов и модов и подходит сообществам Minecraft, которым нужно клиентское обнаружение и мониторинг вместе с серверным принуждением.
