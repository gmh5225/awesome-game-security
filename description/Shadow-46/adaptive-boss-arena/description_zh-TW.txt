Adaptive Boss Arena 是一款以 Unity C# 打造的競技場戰鬥遊戲，核心是一名會在戰鬥中學習玩家習慣並調整反制策略的 Boss。其學習堆疊為純 C# 實作，包含行為追蹤、模式識別、戰鬥記憶與反制策略選擇，並以完整的 Edit Mode 與 Play Mode 測試為後盾。核心反作弊設計確保 Boss 公平：編譯期組件防火牆阻止 AI 與學習程式讀取玩家輸入，延遲感知層則僅在人類可觀察的反應時間尺度上暴露狀態。專案還實作了完整的近戰戰鬥系統，涵蓋武器、招架、架勢與分階段 Boss 攻擊。本專案可作為遊戲開發者與安全研究人員研究自適應 AI、感知邊界與防作弊 Boss 設計的參考。
