Adaptive Boss Arena は、プレイヤーの癖を学習し、戦闘中にカウンターを適応させるボスを中心とした Unity C# 製のアリーナ戦闘ゲームです。学習スタックは純粋な C# で構成され、行動追跡、パターン認識、戦闘メモリ、カウンター戦略選択を含み、充実した Edit Mode および Play Mode テストで支えられています。中核となるアンチチート設計によりボスは公平性を保ちます：コンパイル時のアセンブリファイアウォールが AI と学習コードによるプレイヤー入力の読み取りを遮断し、遅延感知レイヤーは人間が観察可能な状態のみを人間の反応時間スケールで公開します。プロジェクトは武器、パリィ、ポスチャ、フェーズベースのボス攻撃を備えた完全な近接戦闘システムも実装しています。適応型 AI、知覚境界、チート耐性ボス設計を研究するゲーム開発者とセキュリティ研究者向けの参考資料として機能します。
