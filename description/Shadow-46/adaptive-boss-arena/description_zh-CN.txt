Adaptive Boss Arena 是一款基于 Unity C# 的竞技场格斗游戏，核心围绕一个在战斗过程中学习玩家习惯并调整反击策略的 Boss 展开。其学习栈为纯 C# 实现，包含行为追踪、模式识别、战斗记忆与反击策略选择，并配有完善的 Edit Mode 与 Play Mode 测试。核心反作弊设计确保 Boss 公平：编译期程序集防火墙阻止 AI 与学习代码读取玩家输入，而延迟感知层仅在人类可观察的反应时间尺度上暴露状态。项目还实现了完整的近战战斗系统，涵盖武器、格挡、架势与分阶段 Boss 攻击。该项目可作为游戏开发者与安全研究人员研究自适应 AI、感知边界与防作弊 Boss 设计的参考。
