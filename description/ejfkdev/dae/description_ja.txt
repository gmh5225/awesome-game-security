dae は設定ファイル駆動の Dart AOT スナップショット debug-info エクスポーターで、Mach-O、ELF、PE バイナリ内に埋め込まれたスナップショットを特定し、Dart SDK やターゲットの実行を必要とせずにシンボルとランタイム構造をエクスポートします。Rust で実装され、埋め込み SDK プロファイルから Dart バージョンを自動検出し、IDA、radare2、Frida スクリプトに加え、逆アセンブル、オブジェクトプールダンプ、クラス・関数インデックス、およびオプションの実験的疑似コード逆コンパイルを生成します。Flutter リリースビルドや dart compile exe および aot-snapshot 成果物を Dart 2.7 から 3.14 までサポートし、Capstone ベースの ARM64 逆アセンブルと blutter 互換の出力を提供します。コンパイル済み Dart および Flutter アプリケーションを解析するリバースエンジニアとゲームセキュリティ研究者向けのツールです。
