dae — экспортёр debug-info для Dart AOT snapshot, управляемый конфигурацией, который находит встроенные snapshot в бинарных файлах Mach-O, ELF и PE и экспортирует символы и структуры времени выполнения без необходимости в Dart SDK или запуска целевого приложения. Написан на Rust, автоматически определяет версии Dart по встроенным профилям SDK и создаёт скрипты для IDA, radare2 и Frida, а также дизасsemblирование, дампы пулов объектов, индексы классов и функций и опциональную экспериментальную декомпиляцию в псевдокод. Поддерживает release-сборки Flutter и артефакты dart compile exe или aot-snapshot для Dart 2.7–3.14, с ARM64-дизасsemblированием на базе Capstone и выводом, совместимым с blutter. Инструмент предназначен для reverse engineers и исследователей безопасности игр, анализирующих скомпилированные приложения Dart и Flutter.
