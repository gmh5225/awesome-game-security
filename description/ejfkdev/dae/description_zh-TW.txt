dae 是一款由設定檔驅動的 Dart AOT 快照除錯資訊匯出工具，可在 Mach-O、ELF 和 PE 二進位檔中定位內嵌快照，並匯出符號與執行階段結構，無需 Dart SDK 或執行目標程式。此工具以 Rust 撰寫，透過內嵌 SDK 設定檔自動偵測 Dart 版本，並產生 IDA、radare2 和 Frida 腳本，以及反組譯、物件池傾印、類別與函式索引，以及可選的實驗性偽程式碼反編譯。它支援 Flutter 正式版建置以及 dart compile exe 或 aot-snapshot 產物，涵蓋 Dart 2.7 至 3.14，提供基於 Capstone 的 ARM64 反組譯和與 blutter 相容的輸出。此工具面向分析已編譯 Dart 與 Flutter 應用程式的逆向工程師和遊戲安全研究人員。
