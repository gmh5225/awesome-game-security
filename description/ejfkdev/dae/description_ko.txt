dae는 설정 기반의 Dart AOT 스냅샷 debug-info 내보내기 도구로, Mach-O, ELF, PE 바이너리 내부에 임베드된 스냅샷을 찾아 Dart SDK나 대상 실행 없이 심볼과 런타임 구조를 내보냅니다. Rust로 작성되었으며, 임베드된 SDK 프로필을 통해 Dart 버전을 자동 감지하고 IDA, radare2, Frida 스크립트와 함께 디스어셈블리, 객체 풀 덤프, 클래스 및 함수 인덱스, 선택적 실험적 의사코드 디컴파일을 생성합니다. Flutter 릴리스 빌드와 dart compile exe 또는 aot-snapshot 산출물을 Dart 2.7부터 3.14까지 지원하며, Capstone 기반 ARM64 디스어셈블리와 blutter 호환 출력을 제공합니다. 컴파일된 Dart 및 Flutter 애플리케이션을 분석하는 리버스 엔지니어와 게임 보안 연구자를 위한 도구입니다.
