dae is a config-driven Dart AOT snapshot debug-info exporter that locates embedded snapshots inside Mach-O, ELF, and PE binaries and exports symbols and runtime structures without requiring the Dart SDK or executing the target. Written in Rust, it auto-detects Dart versions via embedded SDK profiles and produces IDA, radare2, and Frida scripts plus disassembly, object-pool dumps, class and function indexes, and optional experimental pseudocode decompilation. It supports Flutter release builds and dart compile exe or aot-snapshot artifacts across Dart 2.7 through 3.14, with Capstone-backed ARM64 disassembly and blutter-compatible output. The tool is aimed at reverse engineers and game security researchers analyzing compiled Dart and Flutter applications.
