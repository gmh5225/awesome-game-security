dae 是一款由配置驱动的 Dart AOT 快照调试信息导出工具，可在 Mach-O、ELF 和 PE 二进制文件中定位内嵌快照，并导出符号与运行时结构，无需 Dart SDK 或执行目标程序。该工具使用 Rust 编写，通过内嵌 SDK 配置文件自动识别 Dart 版本，并生成 IDA、radare2 和 Frida 脚本，以及反汇编、对象池转储、类与函数索引，以及可选的实验性伪代码反编译。它支持 Flutter 发布版构建以及 dart compile exe 或 aot-snapshot 产物，覆盖 Dart 2.7 至 3.14，提供基于 Capstone 的 ARM64 反汇编和与 blutter 兼容的输出。该工具面向分析已编译 Dart 与 Flutter 应用的逆向工程师和游戏安全研究人员。
