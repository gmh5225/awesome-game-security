Este proyecto es un blog estático de investigación en seguridad publicado con Jekyll en GitHub Pages, centrado en la investigación de vulnerabilidades del kernel de Windows y el desarrollo de exploits. Está construido con Ruby y el tema Chirpy, y aloja artículos extensos en Markdown con diagramas y análisis técnicos en profundidad. Los temas publicados incluyen cómo funcionan los anti-cheats modernos en el kernel, ingeniería inversa estática del controlador BEDaisy de BattlEye, problemas de confusión de tipos en el kernel Win32k y la atestación en tiempo de ejecución de Windows en el kernel seguro. Los textos enfatizan los internals de Windows, la firma de controladores, la monitorización basada en callbacks, las comprobaciones de integridad de memoria y la carrera armamentista entre anti-cheat y técnicas de bypass. Está dirigido a investigadores y profesionales que trabajan en seguridad de juegos, análisis de anti-cheat e ingeniería inversa de Windows de bajo nivel.
