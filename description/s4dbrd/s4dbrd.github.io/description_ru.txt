Этот проект — статический блог по исследованиям в области безопасности, публикуемый с помощью Jekyll на GitHub Pages и сосредоточенный на изучении уязвимостей ядра Windows и разработке эксплойтов. Сайт построен на Ruby и теме Chirpy и содержит длинные статьи в Markdown с диаграммами и глубокими техническими разборами. Среди опубликованных тем — принципы работы современных античитов на уровне ядра, статический реверс драйвера BEDaisy от BattlEye, проблемы type confusion в ядре Win32k и runtime attestation Windows в secure kernel. Материалы акцентируют внутреннее устройство Windows, подпись драйверов, мониторинг на основе callback, проверки целостности памяти и гонку вооружений между античитом и методами обхода. Рассчитан на исследователей и практиков в области безопасности игр, анализа античитов и низкоуровневого реверса Windows.
