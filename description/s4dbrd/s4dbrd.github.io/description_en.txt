This project is a static security research blog published with Jekyll on GitHub Pages, centered on Windows kernel vulnerability research and exploit development. It is built with Ruby and the Chirpy theme, and hosts long-form Markdown articles with diagrams and technical deep dives. Published topics include how modern kernel anti-cheats work, static reverse engineering of BattlEye's BEDaisy driver, Win32k kernel type-confusion issues, and Windows runtime attestation in the secure kernel. The writing emphasizes Windows internals, driver signing, callback-based monitoring, memory integrity checks, and the arms race between anti-cheat and bypass techniques. It is aimed at researchers and practitioners working on game security, anti-cheat analysis, and low-level Windows reverse engineering.
