Ce projet est un blog statique de recherche en sécurité publié avec Jekyll sur GitHub Pages, centré sur la recherche de vulnérabilités du noyau Windows et le développement d’exploits. Il est construit avec Ruby et le thème Chirpy, et héberge de longs articles Markdown illustrés et des analyses techniques approfondies. Les sujets publiés incluent le fonctionnement des anti-triches noyau modernes, l’ingénierie inverse statique du pilote BEDaisy de BattlEye, les problèmes de confusion de types dans le noyau Win32k, et l’attestation d’exécution Windows dans le noyau sécurisé. Les textes mettent l’accent sur les internals Windows, la signature de pilotes, la surveillance par callbacks, les contrôles d’intégrité mémoire, et la course aux armements entre anti-triche et techniques de contournement. Il s’adresse aux chercheurs et praticiens travaillant sur la sécurité des jeux, l’analyse anti-triche et le reverse engineering Windows de bas niveau.
