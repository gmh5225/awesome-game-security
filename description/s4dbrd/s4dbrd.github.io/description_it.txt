Questo progetto è un blog statico di ricerca sulla sicurezza pubblicato con Jekyll su GitHub Pages, incentrato sulla ricerca di vulnerabilità del kernel Windows e sullo sviluppo di exploit. È realizzato con Ruby e il tema Chirpy, e ospita articoli Markdown lunghi con diagrammi e approfondimenti tecnici. Gli argomenti pubblicati includono il funzionamento degli anti-cheat kernel moderni, il reverse engineering statico del driver BEDaisy di BattlEye, problemi di type confusion nel kernel Win32k e l’attestazione runtime di Windows nel secure kernel. I contenuti enfatizzano gli internals di Windows, la firma dei driver, il monitoraggio basato su callback, i controlli di integrità della memoria e la corsa agli armamenti tra anti-cheat e tecniche di bypass. È rivolto a ricercatori e professionisti che lavorano su game security, analisi anti-cheat e reverse engineering Windows a basso livello.
