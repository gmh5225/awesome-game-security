本プロジェクトは、GitHub Pages 上で Jekyll を用いて公開されている静的セキュリティ研究ブログで、Windows カーネルの脆弱性研究と exploit 開発を中心テーマとしています。Ruby と Chirpy テーマで構築され、図解付きの長文 Markdown 記事や技術的な深掘りを掲載しています。公開トピックには、現代のカーネル型アンチチートの仕組み、BattlEye の BEDaisy ドライバの静的リバースエンジニアリング、Win32k カーネルの型混乱問題、セキュアカーネルにおける Windows ランタイムアテステーションなどが含まれます。執筆内容は Windows 内部構造、ドライバ署名、コールバックベースの監視、メモリ整合性チェック、アンチチートと bypass 手法のいたちごっこを強調しています。ゲームセキュリティ、アンチチート分析、低レベル Windows リバースエンジニアリングに取り組む研究者と実務者向けです。
