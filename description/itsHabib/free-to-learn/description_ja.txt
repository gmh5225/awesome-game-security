Free to Learn は、自己学習型の技術コースをオープンソースでまとめたもので、各コースはレッスン、スタータープロジェクト、自動チェック用ハーネスを備えたインタラクティブなラボとして提供されます。カリキュラムはゲームセキュリティと周辺のシステム分野をカバーし、アンチチートエンジニアリング、タイムトラベルデバッグ、ファームウェアフォレンジクス、視線解析、ゲームプレイエージェント、ストレージとブラウザランタイム、コンパイラ、ブロックチェーン、オニオンルーティングなどの専用トラックがあります。実装は主に JavaScript モジュールと Python による検証ツールで、コースごとに Rust、Java、HTML、WebAssembly も使われます。アンチチート防御、デバッガー、整合性チェックなど、低レイヤのゲーム・プラットフォームセキュリティを手を動かしながら構築・理解したい学習者と実務者を対象としています。
