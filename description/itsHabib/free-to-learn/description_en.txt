Free to Learn is an open-source collection of self-paced technical courses, each packaged as an interactive lab with lessons, starter projects, and automated check harnesses. The curriculum spans game security and adjacent systems topics, including dedicated tracks on anti-cheat engineering, time-travel debugging, firmware forensics, sightline analysis, game-playing agents, storage and browser runtimes, compilers, blockchains, and onion routing. Implementation work is mostly in JavaScript modules and Python validation tooling, with additional Rust, Java, HTML, and WebAssembly where individual courses require it. It targets learners and practitioners who want hands-on practice building and reasoning about anti-cheat defenses, debuggers, integrity checks, and related low-level game and platform security skills.
