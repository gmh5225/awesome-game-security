This project is a C++ internal cheat for Call of Duty: Modern Warfare II that injects as a DLL and hooks the game’s DirectX 11/12 swap chain to render an in-game overlay. It implements ESP with boxes, skeletons, names, distance, and visibility checks, plus an aimbot with bone selection, velocity prediction, FOV targeting, and smoothing, alongside misc features such as no recoil and a proximity warning system. The codebase uses ImGui and Kiero for rendering and hooking, MinHook for API interception, and separate offset paths for Battle.net and Steam clients. It also incorporates evasion-oriented techniques including lazy imports, XOR string obfuscation, and direct syscalls for input simulation. It is aimed at game security researchers and reverse engineers studying in-process cheat architecture, memory-based game SDK usage, and anti-cheat bypass methods.
