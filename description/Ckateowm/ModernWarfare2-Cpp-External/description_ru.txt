Этот проект представляет собой внутренний чит на C++ для Call of Duty: Modern Warfare II, который внедряется как DLL и перехватывает swap chain DirectX 11/12 игры для отрисовки внутриигрового оверлея. Реализован ESP с рамками, скелетами, именами, дистанцией и проверками видимости, а также aimbot с выбором костей, предсказанием скорости, наведением по FOV и сглаживанием, плюс прочие функции вроде отсутствия отдачи и системы предупреждения о близости. Кодовая база использует ImGui и Kiero для рендеринга и хукинга, MinHook для перехвата API и отдельные пути смещений для клиентов Battle.net и Steam. Также применяются техники, ориентированные на обход: ленивые импорты, XOR-обфускация строк и прямые syscalls для симуляции ввода. Проект предназначен для исследователей безопасности игр и reverse-инженеров, изучающих in-process архитектуру читов, использование игровых SDK на основе памяти и методы обхода античита.
