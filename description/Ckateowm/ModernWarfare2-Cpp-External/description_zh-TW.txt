本專案是一款針對《決勝時刻：現代戰爭 II》的 C++ 內部作弊程式，以 DLL 形式注入並掛鉤遊戲的 DirectX 11/12 交換鏈以渲染遊戲內疊加層。它實現了 ESP 功能，包括方框、骨骼、名稱、距離和可見性檢測，以及帶有骨骼選擇、速度預測、FOV 瞄準和平滑處理的自瞄功能，同時還包含無後座力、近距離預警系統等雜項功能。程式碼庫使用 ImGui 和 Kiero 進行渲染與掛鉤，MinHook 用於 API 攔截，並為 Battle.net 和 Steam 用戶端提供獨立的偏移路徑。它還採用了面向規避的技術，包括延遲匯入、XOR 字串混淆以及用於輸入模擬的直接系統呼叫。本專案面向遊戲安全研究人員和逆向工程師，用於研究進程內作弊架構、基於記憶體的遊戲 SDK 使用以及反作弊繞過方法。
