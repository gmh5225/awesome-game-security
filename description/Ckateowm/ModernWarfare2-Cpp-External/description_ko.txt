이 프로젝트는 Call of Duty: Modern Warfare II용 C++ 내부 치트로, DLL로 주입되어 게임의 DirectX 11/12 스왑 체인을 후킹하여 게임 내 오버레이를 렌더링합니다. ESP는 박스, 스켈레톤, 이름, 거리, 가시성 검사를 구현하며, 에임봇은 본 선택, 속도 예측, FOV 타겟팅, 스무딩을 지원하고, 리코일 없음 및 근접 경고 시스템 같은 기타 기능도 포함합니다. 코드베이스는 ImGui와 Kiero로 렌더링 및 후킹을, MinHook으로 API 가로채기를 수행하며 Battle.net과 Steam 클라이언트용 별도 오프셋 경로를 제공합니다. 지연 import, XOR 문자열 난독화, 입력 시뮬레이션용 직접 syscall 등 회피 지향 기법도 포함합니다. 프로세스 내 치트 아키텍처, 메모리 기반 게임 SDK 사용, 안티치트 우회 방법을 연구하는 게임 보안 연구자 및 리버스 엔지니어를 대상으로 합니다.
