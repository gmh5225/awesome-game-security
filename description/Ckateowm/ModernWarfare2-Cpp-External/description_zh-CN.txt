本项目是一款针对《使命召唤：现代战争 II》的 C++ 内部作弊程序，以 DLL 形式注入并挂钩游戏的 DirectX 11/12 交换链以渲染游戏内叠加层。它实现了 ESP 功能，包括方框、骨骼、名称、距离和可见性检测，以及带有骨骼选择、速度预测、FOV 瞄准和平滑处理的自瞄功能，同时还包含无后坐力、近距离预警系统等杂项功能。代码库使用 ImGui 和 Kiero 进行渲染与挂钩，MinHook 用于 API 拦截，并为 Battle.net 和 Steam 客户端提供独立的偏移路径。它还采用了面向规避的技术，包括延迟导入、XOR 字符串混淆以及用于输入模拟的直接系统调用。本项目面向游戏安全研究人员和逆向工程师，用于研究进程内作弊架构、基于内存的游戏 SDK 使用以及反作弊绕过方法。
