このプロジェクトは、Call of Duty: Modern Warfare II 向けの C++ 内部チートで、DLL として注入し、ゲームの DirectX 11/12 スワップチェーンをフックしてゲーム内オーバーレイを描画します。ESP ではボックス、スケルトン、名前、距離、視認性チェックを実装し、エイムボットではボーン選択、速度予測、FOV ターゲティング、スムージングに加え、リコイル無効や接近警告システムなどのその他機能も備えています。コードベースは ImGui と Kiero でレンダリングとフックを行い、MinHook で API インターセプトを行い、Battle.net と Steam クライアント向けに別々のオフセットパスを用意しています。遅延インポート、XOR 文字列難読化、入力シミュレーション用の直接シスコールなど、回避を意識した手法も取り入れています。プロセス内チートアーキテクチャ、メモリベースのゲーム SDK 利用、アンチチート回避手法を研究するゲームセキュリティ研究者やリバースエンジニア向けです。
