Это легковесный экспериментальный гипервизор для Windows, использующий Intel VT-x и Extended Page Tables (EPT) для установки скрытых перехватчиков памяти на уровне ядра. Написан на C++ с CMake и собран как драйвер ядра WDK плюс пользовательская библиотека; он манипулирует трансляцией адресов второго уровня, чтобы перехватывать выполнение кода, обходя обычные проверки целостности памяти. Проект реализует EPT page hooks, точки наблюдения за кодом, срабатывающие при нарушениях EPT, и обработку жизненного цикла процессов для очистки перехватчиков по процессам. Он предназначен для исследователей безопасности, изучающих аппаратно-ускоренную виртуализацию, обход античитов и перехват на основе гипервизора в области игровой безопасности и реверс-инжиниринга.
