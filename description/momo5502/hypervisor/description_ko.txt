Intel VT-x와 Extended Page Tables(EPT)를 사용해 은밀한 커널 수준 메모리 후킹을 설치하는 경량 실험용 Windows 하이퍼바이저입니다. C++와 CMake로 작성되었으며 WDK 커널 드라이버와 사용자 모드 라이브러리로 빌드되며, 2차 주소 변환을 조작해 코드 실행을 가로채 전통적인 메모리 무결성 검사를 우회합니다. 이 프로젝트는 EPT 페이지 후크, EPT 위반으로 트리거되는 코드 워치포인트, 프로세스별 후크 정리를 위한 프로세스 수명 주기 처리를 구현합니다. 하드웨어 지원 가상화, 안티치트 우회, 게임 보안 및 리버스 엔지니어링에서 하이퍼바이저 기반 후킹을 연구하는 보안 연구자를 대상으로 합니다.
