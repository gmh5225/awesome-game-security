Se trata de un hypervisor experimental y ligero para Windows que utiliza Intel VT-x y Extended Page Tables (EPT) para instalar hooks de memoria sigilosos a nivel de kernel. Escrito en C++ con CMake y compilado como controlador de kernel WDK más una biblioteca en modo usuario, manipula la traducción de direcciones de segundo nivel para interceptar la ejecución de código de formas que eluden las comprobaciones convencionales de integridad de memoria. El proyecto implementa hooks de páginas EPT, puntos de vigilancia de código activados por violaciones EPT y gestión del ciclo de vida de procesos para la limpieza de hooks por proceso. Está dirigido a investigadores de seguridad que estudian la virtualización asistida por hardware, la evasión de anti-cheat y el hooking basado en hypervisor en la seguridad de juegos y la ingeniería inversa.
