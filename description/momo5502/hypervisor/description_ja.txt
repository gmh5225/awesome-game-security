これは、Intel VT-x と Extended Page Tables（EPT）を用いて、検出されにくいカーネルレベルのメモリフックを導入する軽量な実験的 Windows ハイパーバイザーです。C++ と CMake で記述され、WDK カーネルドライバーとユーザーモードライブラリとしてビルドされ、第二レベルのアドレス変換を操作してコード実行を傍受し、従来のメモリ整合性チェックを回避します。本プロジェクトは EPT ページフック、EPT 違反によってトリガーされるコードウォッチポイント、およびプロセスごとのフッククリーンアップのためのプロセスライフサイクル処理を実装しています。ハードウェア支援型仮想化、チート対策回避、ゲームセキュリティおよびリバースエンジニアリングにおけるハイパーバイザーベースのフック研究を行うセキュリティ研究者を対象としています。
