Stellar Splash Engine is a TypeScript backend that orchestrates competitive tournaments and authoritatively verifies client-reported gameplay for a Web3 splash game platform. It replays raw match events through a deterministic headless simulator, enforces anti-cheat rules such as session tokens, click-timing checks, tick anomalies, and entropy heuristics, and issues cryptographic attestations when scores match server-side physics. The stack integrates Stellar Horizon and Soroban smart contracts for entry-fee validation, prize-pool escrow, settlements, channel-account transaction pooling, plus operational hardening via rate limiting, OWASP-oriented controls, Prometheus metrics, and webhook notifications. It targets operators and security-minded developers who need fair, auditable esports outcomes and fraud-resistant settlement on a public blockchain testnet or production network.
