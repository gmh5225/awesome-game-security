Axis-web は、2005 年の韓国製 3D アクションゲーム AXIS のブラウザ向け移植版で、オリジナルの OpenGL クライアントをリバースエンジニアリングし、そのロジックを C から WebAssembly にコンパイルしたうえで WebGL・WebAudio・WebSocket のプラットフォーム層で再実装したものです。プロジェクトはファイル形式とネットワークを随時更新されるリバースエンジニアリング仕様に文書化し、Python と JavaScript のツールに加え、アーカイブ、暗号化、テクスチャ、メッシュ、マップ、スケルトン、リプレイ、対戦 RNG 向けの 8 つのバイト完全一致デコーダを同梱し、いずれも合法に所有したインストールデータで検証済みです。歩行可能な WebGL エンジン、ローカルビューア、WebSocket リレーにより本物のプロトコルでのマルチプレイを支援し、移動キネマティクスと RNG ロックステップ再構築は記録された対戦と照合されています。クラシックなゲームクライアント、独自アセットパイプライン、決定論的オンライン対戦を研究する研究者・開発者向けで、著作権物はリポジトリに含まれないため、ユーザー自身のゲームコピーが必要です。
