Axis-web 是 2005 年韓國 3D 動作遊戲 AXIS 的瀏覽器移植版，透過對原版 OpenGL 用戶端進行逆向工程，並以 C 編譯為 WebAssembly，再搭配 WebGL、WebAudio 與 WebSocket 平台層重新實作其邏輯。專案在一套持續更新的逆向規格中記錄檔案格式與網路協定，並提供 Python 與 JavaScript 工具，以及針對封存、加密、紋理、網格、地圖、骨架、重播與對局 RNG 的八個位元組級精確解碼器，均與合法擁有的安裝資料對照驗證。可行走的 WebGL 引擎、本機檢視器與 WebSocket 中繼支援真實協定的多人連線，移動運動學與 RNG 鎖步重建已與錄製對局核對。面向研究經典遊戲用戶端、專有資產管線與確定性線上對局的研究者與開發者；使用者須自行提供遊戲副本，儲存庫不包含任何受版權保護的資產。
