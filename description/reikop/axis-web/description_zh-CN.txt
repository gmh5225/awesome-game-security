Axis-web 是 2005 年韩国 3D 动作游戏 AXIS 的浏览器移植版，通过对原版 OpenGL 客户端进行逆向工程，并用 C 编译为 WebAssembly，再搭配 WebGL、WebAudio 与 WebSocket 平台层重新实现其逻辑。项目在一套持续更新的逆向规格中记录文件格式与网络协议，并提供 Python 与 JavaScript 工具，以及针对归档、加密、纹理、网格、地图、骨骼、回放与对局 RNG 的八个字节级精确解码器，均与合法拥有的安装包数据对照验证。可行走的 WebGL 引擎、本地查看器与 WebSocket 中继支持真实协议的多人联机，移动运动学与 RNG 锁步重建已与录制对局核对。面向研究经典游戏客户端、专有资产管线与确定性在线对局的研究者与开发者；用户须自行提供游戏副本，仓库不包含任何受版权保护的资产。
