Axis-web은 2005년 한국 3D 액션 게임 AXIS의 브라우저 포팅으로, 원본 OpenGL 클라이언트를 리버스 엔지니어링하고 C를 WebAssembly로 컴파일한 뒤 WebGL, WebAudio, WebSocket 플랫폼 계층으로 로직을 재구현했습니다. 프로젝트는 파일 형식과 네트워킹을 지속 갱신되는 리버스 엔지니어링 사양에 문서화하고, Python·JavaScript 도구와 아카이브, 암호화, 텍스처, 메시, 맵, 스켈레톤, 리플레이, 매치 RNG용 여덟 개의 바이트 단위 정확 디코더를 제공하며, 모두 합법적으로 소유한 설치본 데이터와 대조해 검증했습니다. 보행 가능한 WebGL 엔진, 로컬 뷰어, WebSocket 릴레이가 실제 프로토콜 멀티플레이를 지원하고, 이동 kinematics와 RNG lockstep 재구성은 기록된 매치와 대조해 확인했습니다. 클래식 게임 클라이언트, 독점 에셋 파이프라인, 결정론적 온라인 플레이를 연구하는 연구자·개발자를 대상으로 하며, 저장소에는 저작권 자산이 포함되지 않으므로 사용자가 직접 게임 사본을 제공해야 합니다.
