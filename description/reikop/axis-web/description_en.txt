Axis-web is a browser port of the 2005 Korean 3D action game AXIS, created by reverse-engineering the original OpenGL client and reimplementing its logic in C compiled to WebAssembly with a WebGL, WebAudio, and WebSocket platform layer. The project documents file formats and networking in a living reverse-engineering spec and ships Python and JavaScript tools plus eight byte-exact decoders for archives, encryption, textures, meshes, maps, skeletons, replays, and match RNG, all verified against data from a legally owned install. A walkable WebGL engine, local viewers, and a WebSocket relay support real-protocol multiplayer, with movement kinematics and RNG lockstep reconstruction checked against recorded matches. It targets researchers and developers studying classic game clients, proprietary asset pipelines, and deterministic online play, and requires users to supply their own copy of the game because no copyrighted assets are included in the repository.
