IDA MCP Server est une extension C++ native pour IDA Pro qui expose une base IDA ouverte à des agents IA et à d'autres clients Model Context Protocol via HTTP local. Il s'exécute entièrement dans IDA avec le SDK officiel, sans passerelle Python séparée, et implémente un large catalogue d'outils pour le désassemblage, la décompilation Hex-Rays, le microcode, les types, les références croisées, l'analyse de flux de contrôle, la récupération de classes Objective-C et C++, le patch d'octets, le débogage et les scripts IDAPython ou IDC. Le serveur est construit avec C++17, CMake, Boost.Asio/Beast et nlohmann_json, prend en charge plusieurs versions du protocole MCP et peut être configuré avec des profils d'outils core ou full pour équilibrer la taille du contexte de l'agent et la profondeur de l'automatisation. Il s'adresse aux ingénieurs en rétro-ingénierie et aux chercheurs en sécurité des jeux qui souhaitent des flux de travail assistés par LLM directement sur des sessions d'analyse binaire en direct dans IDA.
