IDA MCP Server는 IDA Pro용 네이티브 C++ 플러그인으로, 로컬 HTTP를 통해 열린 IDA 데이터베이스를 AI 에이전트 및 기타 Model Context Protocol 클라이언트에 노출합니다. 공식 IDA SDK를 사용해 IDA 내부에서만 완전히 동작하며 별도의 Python 브리지는 필요 없고, 디스어셈블리, Hex-Rays 디컴파일, 마이크로코드, 타입, 교차 참조, 제어 흐름 분석, Objective-C 및 C++ 클래스 복구, 바이트 패치, 디버깅, IDAPython 또는 IDC 스크립팅을 위한 방대한 도구 카탈로그를 구현합니다. C++17, CMake, Boost.Asio/Beast, nlohmann_json로 구축되었으며 여러 MCP 프로토콜 버전을 지원하고, core 또는 full 도구 프로필로 에이전트 컨텍스트 크기와 자동화 깊이의 균형을 맞출 수 있습니다. IDA에서 라이브 바이너리 분석 세션에 LLM 보조 워크플로를 직접 적용하려는 리버스 엔지니어와 게임 보안 연구자를 대상으로 합니다.
