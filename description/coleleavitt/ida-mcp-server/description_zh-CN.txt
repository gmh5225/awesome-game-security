IDA MCP Server 是面向 IDA Pro 的原生 C++ 插件，通过本地 HTTP 将已打开的 IDA 数据库暴露给 AI 智能体及其他 Model Context Protocol 客户端。它完全在 IDA 内运行，使用官方 IDA SDK，无需独立的 Python 桥接，并提供大量工具，涵盖反汇编、Hex-Rays 反编译、微码、类型、交叉引用、控制流分析、Objective-C 与 C++ 类恢复、字节修补、调试以及 IDAPython 或 IDC 脚本。服务端采用 C++17、CMake、Boost.Asio/Beast 与 nlohmann_json 构建，支持多种 MCP 协议版本，可配置核心或完整工具集，以在智能体上下文规模与自动化深度之间取得平衡。面向希望在 IDA 中于实时二进制分析会话里直接开展 LLM 辅助工作流的逆向工程师与游戏安全研究人员。
