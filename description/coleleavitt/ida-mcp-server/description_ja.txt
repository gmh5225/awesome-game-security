IDA MCP Server は IDA Pro 向けのネイティブ C++ プラグインで、ローカル HTTP 経由で開いている IDA データベースを AI エージェントやその他の Model Context Protocol クライアントに公開します。公式 IDA SDK を用いて IDA 内だけで完全に動作し、別途 Python ブリッジは不要です。逆アセンブル、Hex-Rays デコンパイル、マイクロコード、型、クロスリファレンス、制御フロー解析、Objective-C および C++ クラス復元、バイトパッチ、デバッグ、IDAPython や IDC スクリプト向けの大規模なツール群を実装しています。C++17、CMake、Boost.Asio/Beast、nlohmann_json で構築され、複数の MCP プロトコルバージョンに対応し、コアまたはフルツールプロファイルでエージェントのコンテキストサイズと自動化の深さのバランスを調整できます。IDA 上のライブなバイナリ解析セッションで LLM 支援ワークフローを直接使いたいリバースエンジニアやゲームセキュリティ研究者向けです。
