IDA MCP Server 是適用於 IDA Pro 的原生 C++ 外掛，透過本機 HTTP 將已開啟的 IDA 資料庫暴露給 AI 代理程式及其他 Model Context Protocol 用戶端。它完全在 IDA 內執行，使用官方 IDA SDK，無需獨立的 Python 橋接，並實作大量工具，涵蓋反組譯、Hex-Rays 反編譯、微碼、型別、交叉參照、控制流程分析、Objective-C 與 C++ 類別還原、位元組修補、除錯以及 IDAPython 或 IDC 腳本。伺服器以 C++17、CMake、Boost.Asio/Beast 與 nlohmann_json 建置，支援多種 MCP 協定版本，可設定核心或完整工具設定檔，以在代理程式上下文大小與自動化深度之間取得平衡。面向希望在 IDA 中於即時二進位分析工作階段裡直接進行 LLM 輔助工作流程的逆向工程師與遊戲安全研究人員。
