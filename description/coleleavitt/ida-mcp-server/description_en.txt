IDA MCP Server is a native C++ plugin for IDA Pro that exposes an open IDA database to AI agents and other Model Context Protocol clients over local HTTP. It runs entirely inside IDA using the official IDA SDK—without a separate Python bridge—and implements a large catalog of tools for disassembly, Hex-Rays decompilation, microcode, types, cross-references, control-flow analysis, Objective-C and C++ class recovery, byte patching, debugging, and IDAPython or IDC scripting. The server is built with C++17, CMake, Boost.Asio/Beast, and nlohmann_json, supports multiple MCP protocol versions, and can be configured with core or full tool profiles to balance agent context size against depth of automation. It is aimed at reverse engineers and game security researchers who want LLM-assisted workflows directly on live binary analysis sessions in IDA.
