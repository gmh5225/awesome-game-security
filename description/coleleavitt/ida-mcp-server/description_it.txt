IDA MCP Server è un plugin nativo in C++ per IDA Pro che espone un database IDA aperto ad agenti IA e ad altri client Model Context Protocol tramite HTTP locale. Funziona interamente in IDA usando l'SDK ufficiale di IDA, senza un bridge Python separato, e implementa un ampio catalogo di strumenti per disassemblaggio, decompilazione Hex-Rays, microcodice, tipi, riferimenti incrociati, analisi del flusso di controllo, recupero di classi Objective-C e C++, patch di byte, debug e scripting IDAPython o IDC. Il server è costruito con C++17, CMake, Boost.Asio/Beast e nlohmann_json, supporta più versioni del protocollo MCP e può essere configurato con profili di strumenti core o full per bilanciare la dimensione del contesto dell'agente e la profondità dell'automazione. È pensato per reverse engineer e ricercatori di sicurezza dei giochi che vogliono flussi di lavoro assistiti da LLM direttamente su sessioni di analisi binaria live in IDA.
