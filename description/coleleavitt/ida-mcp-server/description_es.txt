IDA MCP Server es un complemento nativo en C++ para IDA Pro que expone una base de datos IDA abierta a agentes de IA y a otros clientes del Model Context Protocol mediante HTTP local. Se ejecuta íntegramente dentro de IDA con el SDK oficial de IDA, sin un puente Python aparte, e implementa un amplio catálogo de herramientas para desensamblado, descompilación Hex-Rays, microcódigo, tipos, referencias cruzadas, análisis de flujo de control, recuperación de clases Objective-C y C++, parcheo de bytes, depuración y scripts IDAPython o IDC. El servidor está construido con C++17, CMake, Boost.Asio/Beast y nlohmann_json, admite varias versiones del protocolo MCP y puede configurarse con perfiles de herramientas core o full para equilibrar el tamaño del contexto del agente y la profundidad de la automatización. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad en juegos que quieren flujos de trabajo asistidos por LLM directamente en sesiones de análisis binario en vivo en IDA.
