IDA MCP Server ist ein natives C++-Plugin für IDA Pro, das eine geöffnete IDA-Datenbank per lokalem HTTP für KI-Agenten und andere Model Context Protocol-Clients bereitstellt. Es läuft vollständig in IDA mit dem offiziellen IDA SDK—ohne separate Python-Brücke—und implementiert einen umfangreichen Katalog an Werkzeugen für Disassemblierung, Hex-Rays-Dekompilierung, Mikrocode, Typen, Querverweise, Kontrollflussanalyse, Objective-C- und C++-Klassenwiederherstellung, Byte-Patching, Debugging sowie IDAPython- oder IDC-Skripte. Der Server ist mit C++17, CMake, Boost.Asio/Beast und nlohmann_json gebaut, unterstützt mehrere MCP-Protokollversionen und kann mit Core- oder Full-Tool-Profilen konfiguriert werden, um Agentenkontextgröße und Automatisierungstiefe abzuwägen. Er richtet sich an Reverse Engineers und Game-Security-Forscher, die LLM-unterstützte Workflows direkt in laufenden Binäranalyse-Sitzungen in IDA nutzen möchten.
