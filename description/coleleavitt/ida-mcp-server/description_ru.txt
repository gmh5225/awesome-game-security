IDA MCP Server — нативный плагин на C++ для IDA Pro, который открывает доступ к открытой базе IDA для ИИ-агентов и других клиентов Model Context Protocol по локальному HTTP. Работает полностью внутри IDA с официальным IDA SDK, без отдельного Python-моста, и реализует обширный набор инструментов для дизассемблирования, декомпиляции Hex-Rays, микрокода, типов, перекрёстных ссылок, анализа потока управления, восстановления классов Objective-C и C++, патчинга байтов, отладки и сценариев IDAPython или IDC. Сервер собран на C++17, CMake, Boost.Asio/Beast и nlohmann_json, поддерживает несколько версий протокола MCP и настраивается профилями инструментов core или full, чтобы сбалансировать размер контекста агента и глубину автоматизации. Ориентирован на специалистов по реверс-инжинирингу и исследователей безопасности игр, которым нужны LLM-поддерживаемые рабочие процессы прямо в живых сессиях бинарного анализа в IDA.
