Traktor is a modular, cross-platform C++ game engine with an integrated editor, runtime, and build toolchain for creating and shipping games. It provides rendering backends for DirectX 11, Vulkan, and Metal, a node-based HLSL and GLSL shader graph pipeline, Lua scripting with debugging and profiling, and physics simulation through Bullet and Jolt. The engine also includes animation, cloth and ragdoll systems, AI navigation meshes, peer-to-peer networking and state replication, an Avalanche asset server, and Model Context Protocol tooling in the editor. It targets Linux, Windows, macOS, Raspberry Pi, Android, and iOS, and is aimed at game developers, engine programmers, and security researchers who need full source access to a modern engine architecture for development, graphics research, or studying game internals.
