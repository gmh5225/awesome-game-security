Traktor は、ゲームの作成とリリースのための統合エディター、ランタイム、ビルドツールチェーンを備えた、モジュラーなクロスプラットフォーム C++ ゲームエンジンです。DirectX 11、Vulkan、Metal のレンダリングバックエンド、ノードベースの HLSL および GLSL シェーダーグラフパイプライン、デバッグとプロファイリング対応の Lua スクリプティング、Bullet および Jolt による物理シミュレーションを提供します。エンジンには、アニメーション、クロスおよびラグドールシステム、AI ナビゲーションメッシュ、ピアツーピアネットワーキングとステートレプリケーション、Avalanche アセットサーバー、エディター内の Model Context Protocol ツールも含まれます。Linux、Windows、macOS、Raspberry Pi、Android、iOS をターゲットとし、開発、グラフィックス研究、ゲーム内部の研究のために最新のエンジンアーキテクチャへの完全なソースアクセスを必要とするゲーム開発者、エンジンプログラマー、セキュリティ研究者を対象としています。
