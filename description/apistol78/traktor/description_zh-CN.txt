Traktor 是一款模块化、跨平台的 C++ 游戏引擎，集成了编辑器、运行时和构建工具链，用于创建和发布游戏。它提供 DirectX 11、Vulkan 和 Metal 渲染后端，基于节点的 HLSL 和 GLSL 着色器图管线，支持带调试与性能分析的 Lua 脚本，以及通过 Bullet 和 Jolt 实现的物理模拟。引擎还包含动画、布料与布娃娃系统、AI 导航网格、点对点网络与状态复制、Avalanche 资源服务器，以及编辑器中的 Model Context Protocol 工具。它支持 Linux、Windows、macOS、Raspberry Pi、Android 和 iOS，面向需要完整源码访问现代引擎架构以进行开发、图形研究或研究游戏内部机制的游戏开发者、引擎程序员和安全研究人员。
