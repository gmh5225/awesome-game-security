OMK is an open-source, from-scratch reimplementation of the engine behind Quantic Dream and Eidos's 1999 game Omikron: The Nomad Soul, built from reverse-engineered documentation of the original Runtime.exe and its shipped data formats. The project is written primarily in C++20 for the portable engine replica and Python for readers, web viewers, and a large automated verification suite, with optional SDL and Vulkan backends for interactive play. It documents and parses proprietary containers and subsystems such as the 153-opcode script VM, 8192-byte game state, cutscenes, UI, audio, and 3D assets, and validates behavior by comparing announcement traces against captures from the original binary. It is aimed at game preservationists, reverse engineers, and researchers who want a reproducible, evidence-backed study of a late-1990s commercial game engine, and it requires the user to supply their own legally owned copy of the game data.
