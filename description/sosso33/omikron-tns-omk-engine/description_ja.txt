OMK は、Quantic Dream と Eidos の 1999 年ゲーム Omikron: The Nomad Soul のエンジンを、オリジナルの Runtime.exe と同梱データ形式のリバースエンジニアリング文書に基づき、オープンソースで一から再実装したプロジェクトです。ポータブルなエンジンレプリカは主に C++20、リーダー、Web ビューア、大規模な自動検証スイートは Python で記述され、インタラクティブプレイ用にオプションで SDL および Vulkan バックエンドを提供します。153 オペコードのスクリプト VM、8192 バイトのゲーム状態、カットシーン、UI、オーディオ、3D アセットなどの独自コンテナとサブシステムを文書化・解析し、announcement traces をオリジナルバイナリからのキャプチャと比較することで動作を検証します。1990 年代末の商用ゲームエンジンを再現可能かつ証拠に裏付けられた形で研究したい、ゲーム保存活動者、リバースエンジニア、研究者向けであり、ユーザー自身が合法的に所有するゲームデータの提供を必要とします。
