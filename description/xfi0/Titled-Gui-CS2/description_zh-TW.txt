Titled Gui 是一款以 C# 撰寫的外部 Counter-Strike 2 作弊框架，可附加至遊戲程序並繪製透明的 ImGui 疊加層，用於設定與螢幕顯示。它透過 Win32 API 讀寫遊戲記憶體，自動從 cs2-dumper 來源取得更新的偏移量，並實作自瞄、後座力控制、扳機機制等戰鬥功能，以及移動與生活品質優化調整。視覺模組包括 ESP、雷達、以 DirectX 11 與 VPK 模型載入渲染的 chams、以預先提取幾何體進行的地圖可見性檢查，以及針對玩家、炸彈與手榴彈投擲路線的眾多 HUD 疊加層。此專案對研究外部作弊架構、記憶體互動模式、疊加層渲染，以及反作弊系統在 CS2 中必須偵測之技術的遊戲安全研究人員相當實用。
