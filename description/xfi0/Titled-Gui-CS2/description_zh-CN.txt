Titled Gui 是一个用 C# 编写的外部 Counter-Strike 2 作弊框架，可附加到游戏进程并绘制透明的 ImGui 叠加层，用于配置与屏幕显示。它通过 Win32 API 读写游戏内存，自动从 cs2-dumper 源获取更新的偏移量，并实现自瞄、压枪、扳机宏等战斗功能以及移动与品质优化调整。视觉模块包括 ESP、雷达、使用 DirectX 11 和 VPK 模型加载渲染的 chams、基于预提取几何体的地图可见性检测，以及针对玩家、炸弹和手雷投掷路线的大量 HUD 叠加层。该项目对研究外部作弊架构、内存交互模式、叠加层渲染以及反作弊系统在 CS2 中需检测技术的游戏安全研究人员非常有用。
