本リポジトリは、対面ワークショップ「The Invisible War: Cheats vs Anticheats」の教材をまとめたもので、依存関係をインストールせずにローカルで実行できるブラウザベースのスライドを中心としています。プレゼンテーションは HTML、CSS、バニラ JavaScript で構築され、カスタムスライドエンジン、インタラクティブな SVG アーキテクチャ図、発表者ノート、および SHA-256 整合性チェックとヒューリスティックなログ分析のための任意の Python デモを含みます。内容はコンピュータの基礎から、チートの種類（内部、外部、カーネル、DMA）とアンチチートの層（ユーザーモード、カーネルモード、サーバー側）、有名な商用システム、バイパスパターン、攻撃者と防御者の継続的な適応サイクルまでを扱います。付属ファイルには技術用語集、教授用スクリプト、教室利用向けの分析・研究ツールへの厳選リファレンスがあります。チートの作成や展開の手順ではなく、構造化された防御志向の概観を求める学生、教育者、ゲームセキュリティの初心者を対象としています。
