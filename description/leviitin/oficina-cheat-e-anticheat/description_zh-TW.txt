本儲存庫打包了面對面工作坊「看不見的戰爭：作弊與反作弊」的教學材料，核心是一份可在本地執行、無需安裝相依項的基於瀏覽器投影片。簡報以 HTML、CSS 與原生 JavaScript 建構，包含自訂投影片引擎、互動式 SVG 架構圖、講者備註，以及可選的 Python 示範（SHA-256 完整性檢查與啟發式日誌分析）。內容從電腦基礎講起，涵蓋作弊類型（內部、外部、核心與 DMA）與反作弊層級（使用者模式、核心模式與伺服器端），以及知名商業系統、繞過模式與攻防雙方的持續適應循環。支援檔案包括技術術語表、教授腳本，以及供課堂使用的分析與研究工具精選參考。面向希望獲得結構化、防禦導向概覽的學生、教育工作者與遊戲安全入門者，而非提供製作或部署作弊的指引。
