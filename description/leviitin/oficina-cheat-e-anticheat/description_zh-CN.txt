本仓库打包了面对面工作坊「看不见的战争：作弊与反作弊」的教学材料，核心是一份可在本地运行、无需安装依赖的基于浏览器的幻灯片。演示文稿使用 HTML、CSS 和原生 JavaScript 构建，包含自定义幻灯片引擎、交互式 SVG 架构图、主讲人备注，以及可选的 Python 演示（SHA-256 完整性校验与启发式日志分析）。内容从计算机基础讲起，涵盖作弊类型（内部、外部、内核与 DMA）与反作弊层级（用户态、内核态与服务端），以及知名商业系统、绕过模式与攻防双方的持续适应循环。配套文件包括技术术语表、教授脚本，以及面向课堂使用的分析与研究工具精选参考。面向希望获得结构化、防御导向概览的学生、教育工作者与游戏安全入门者，而非提供制作或部署作弊的指导。
