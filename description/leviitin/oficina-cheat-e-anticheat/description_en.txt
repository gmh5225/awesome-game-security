This repository packages educational materials for an in-person workshop titled “The Invisible War: Cheats vs Anticheats,” centered on a browser-based slide deck you can run locally without installing dependencies. The presentation is built with HTML, CSS, and vanilla JavaScript, including a custom slide engine, interactive SVG architecture diagrams, presenter notes, and optional Python demos for SHA-256 integrity checks and heuristic log analysis. Content walks from computer fundamentals through cheat categories (internal, external, kernel, and DMA) and anticheat layers (user-mode, kernel-mode, and server-side), plus well-known commercial systems, bypass patterns, and the ongoing adaptation cycle between attackers and defenders. Supporting files include a glossary of technical terms, a professor script, and curated references to analysis and research tools for classroom use. It is aimed at students, educators, and game security newcomers who want a structured, defensive-minded overview rather than instructions to build or deploy cheats.
