Lava Guard AC 是由 FlameTeam Studios 开发的 Bukkit 与 Spigot Minecraft 服务端反作弊插件，用于在常规游戏过程中检测常见客户端作弊行为。插件以 Java 实现，基于 Bukkit 事件 API，可配置检测加速与连跳、飞行、超距攻击与杀戮光环，以及快速破坏或 nuker 等行为，并将检测结果累计为违规计数，在达到可配置阈值后触发定时封禁。管理员可通过游戏内管理 GUI 以及 lavaguard 命令进行重载与波兰语或英语消息管理；可选的 Discord Webhook 会通过 HTTP 异步发送封禁嵌入消息。项目采用 YAML 驱动的设置与消息，以 GPLv3 发布，面向希望轻量、自托管、无需外部服务的小型至中型生存或小游戏服主。
