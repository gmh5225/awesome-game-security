Lava Guard AC 是由 FlameTeam Studios 開發的 Bukkit 與 Spigot Minecraft 伺服器端反作弊外掛，用於在一般遊戲過程中偵測常見的用戶端作弊行為。外掛以 Java 實作，基於 Bukkit 事件 API，可設定檢查加速與連跳、飛行、超距攻擊與 kill aura，以及快速破壞或 nuker 等行為，並將偵測結果累計為違規計數，在達到可設定閾值後觸發定時封禁。管理員可透過遊戲內管理 GUI 以及 lavaguard 指令進行重載與波蘭語或英語訊息管理；選用的 Discord Webhook 會透過 HTTP 非同步張貼封禁嵌入訊息。專案採 YAML 驅動的設定與訊息，以 GPLv3 授權釋出，面向希望輕量、自架、無需外部服務的小型至中型生存或小遊戲伺服器營運者。
