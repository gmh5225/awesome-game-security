Lava Guard AC is a server-side anti-cheat plugin for Bukkit and Spigot Minecraft servers, built by FlameTeam Studios to detect common client-side hacks during normal gameplay. It is implemented in Java using the Bukkit event API and runs configurable checks for speed and bunnyhop, flight, extended reach and kill aura, and fast break or nuker behavior, rolling detections into a violation counter that triggers timed name bans after a configurable threshold. Staff can manage players through an in-game admin GUI and lavaguard commands for reload and Polish or English messaging, while optional Discord webhooks post ban embeds asynchronously over HTTP. The project ships with YAML-driven settings and messages under GPLv3, aimed at small to medium survival or minigame server operators who want a lightweight, self-hosted cheat deterrent without external services.
