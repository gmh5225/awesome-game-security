Lava Guard AC は FlameTeam Studios による Bukkit および Spigot 向け Minecraft サーバー側アンチチートプラグインで、通常プレイ中に一般的なクライアント側チートを検出します。Java で実装され Bukkit イベント API を利用し、スピードやバニーホップ、飛行、リーチ拡張や kill aura、早掘りや nuker などを設定可能なチェックで監視し、検出を違反カウンターに集約して、設定した閾値を超えると時間付きの名前 BAN を発動します。スタッフはゲーム内管理 GUI と lavaguard コマンドでリロードやポーランド語・英語メッセージを管理でき、任意の Discord Webhook が HTTP 経由で BAN 埋め込みを非同期投稿します。YAML 駆動の設定とメッセージを GPLv3 で提供し、外部サービスなしで軽量かつ自前ホストのチート抑止を求める小〜中規模のサバイバルやミニゲームサーバー運営者向けです。
