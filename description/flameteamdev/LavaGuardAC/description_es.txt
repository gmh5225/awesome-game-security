Lava Guard AC es un complemento antitrampas del lado del servidor para servidores Minecraft Bukkit y Spigot, creado por FlameTeam Studios para detectar trampas habituales del cliente durante el juego normal. Está implementado en Java con la API de eventos de Bukkit y ejecuta comprobaciones configurables de velocidad y bunnyhop, vuelo, alcance extendido y kill aura, y rotura rápida o comportamiento nuker, acumulando detecciones en un contador de infracciones que activa baneos por nombre temporizados tras un umbral configurable. El staff gestiona jugadores mediante una GUI de administración en el juego y comandos lavaguard para recargar y mensajes en polaco o inglés, mientras webhooks opcionales de Discord publican embeds de baneo de forma asíncrona por HTTP. El proyecto incluye ajustes y mensajes basados en YAML bajo GPLv3, pensado para operadores de servidores de supervivencia o minijuegos pequeños y medianos que buscan un disuasivo de trampas ligero, autoalojado y sin servicios externos.
