Lava Guard AC è un plugin anti-cheat lato server per server Minecraft Bukkit e Spigot, sviluppato da FlameTeam Studios per rilevare i cheat client più comuni durante il gioco normale. È implementato in Java con l’API eventi Bukkit ed esegue controlli configurabili su speed e bunnyhop, volo, reach esteso e kill aura, e fast break o comportamento nuker, accumulando le rilevazioni in un contatore violazioni che attiva ban per nome temporizzati oltre una soglia configurabile. Lo staff gestisce i giocatori tramite una GUI admin in-game e comandi lavaguard per reload e messaggi in polacco o inglese, mentre webhook Discord opzionali pubblicano embed di ban in modo asincrono via HTTP. Il progetto offre impostazioni e messaggi guidati da YAML sotto GPLv3, pensato per operatori di server survival o minigame piccoli e medi che vogliono un deterrente leggero, self-hosted e senza servizi esterni.
