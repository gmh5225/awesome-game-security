本專案為《Bodycam》遊戲中 Easy Anti-Cheat 在啟動時因要求卸載第三方核心驅動程式（如 AsUpIO.sys、ssgdio64.sys 或 RTCore64.sys）而攔截的情況，提供可逆的 Windows 變通方案。每項針對性修復皆以需系統管理員權限執行的批次啟動器搭配 PowerShell 腳本交付：依驅動檔名定位已註冊的核心服務、備份啟動設定、停用自動載入，並嘗試停止驅動，且不刪除檔案、不竄改 EAC 或 Windows 安全機制。可透過配套的還原腳本及存放在 ProgramData 下的 JSON 備份進行回溯；技術報告記錄了觀察到的 EAC 對話方塊、與華碩及微星工具相關的驅動來源，以及驗證方面的限制。主要技術包括 Windows PowerShell 5.1、sc.exe、WMI/CIM 及登錄服務項目。面向排查 EAC 驅動相容性問題的玩家，以及研究商業反作弊如何在消費級 PC 上強制執行已載入核心驅動策略的研究人員。
