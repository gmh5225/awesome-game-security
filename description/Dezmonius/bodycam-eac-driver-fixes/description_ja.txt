本プロジェクトは、Bodycam において Easy Anti-Cheat の起動ブロックが AsUpIO.sys、ssgdio64.sys、RTCore64.sys などのサードパーティカーネルドライバのアンロードを要求する事象に対し、元に戻せる Windows 上の回避策を提供する。各対象向けの修正は管理者権限で実行するバッチ起動器と PowerShell スクリプトの組み合わせで配布され、ドライバファイル名で登録済みカーネルサービスを特定し、起動設定をバックアップして自動読み込みを無効化し、ファイル削除や EAC・Windows セキュリティの改ざんなしにドライバの停止を試みる。ロールバックは同伴の復元スクリプトと ProgramData 配下の JSON バックアップで対応し、技術レポートでは観測された EAC ダイアログ、ASUS および MSI ユーティリティに紐づくドライバの出自、検証上の限界を記載している。主な技術は Windows PowerShell 5.1、sc.exe、WMI/CIM、レジストリのサービスキー。EAC ドライバ互換性のトラブルシュートを行うプレイヤーや、商用アンチチートがコンシューマー PC 上で読み込まれたカーネルドライバポリシーをどう強制するかを研究する研究者向けである。
