本项目为《Bodycam》游戏中 Easy Anti-Cheat 在启动时因要求卸载第三方内核驱动（如 AsUpIO.sys、ssgdio64.sys 或 RTCore64.sys）而拦截的情况，提供可逆的 Windows 变通方案。每项针对性修复均以需管理员权限运行的批处理启动器搭配 PowerShell 脚本交付：按驱动文件名定位已注册的内核服务、备份启动配置、禁用自动加载，并尝试停止驱动，且不删除文件、不篡改 EAC 或 Windows 安全机制。可通过配套的恢复脚本及存放在 ProgramData 下的 JSON 备份进行回滚；技术报告记录了观察到的 EAC 对话框、与华硕及微星工具相关的驱动来源，以及验证方面的局限。主要技术包括 Windows PowerShell 5.1、sc.exe、WMI/CIM 及注册表服务项。面向排查 EAC 驱动兼容性问题的玩家，以及研究商业反作弊如何在消费级 PC 上强制执行已加载内核驱动策略的研究人员。
