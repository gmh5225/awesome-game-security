Este proyecto ofrece soluciones alternativas reversibles en Windows para los bloqueos de inicio de Easy Anti-Cheat en el juego Bodycam que exigen descargar controladores de kernel de terceros como AsUpIO.sys, ssgdio64.sys o RTCore64.sys. Cada corrección dirigida se distribuye como lanzadores por lotes ejecutados como administrador, junto con scripts de PowerShell que localizan servicios de kernel registrados por nombre de archivo del controlador, respaldan la configuración de inicio, desactivan la carga automática e intentan detener el controlador sin borrar archivos ni alterar EAC o la seguridad de Windows. La reversión se admite mediante scripts de restauración complementarios y copias de seguridad JSON almacenadas en ProgramData, con un informe técnico que documenta los diálogos de EAC observados, el origen de los controladores vinculado a utilidades de ASUS y MSI, y los límites de verificación. Las tecnologías principales incluyen Windows PowerShell 5.1, sc.exe, WMI/CIM y claves de servicio del registro. Está orientado a jugadores que solucionan problemas de compatibilidad de controladores con EAC y a investigadores que estudian cómo el anti-cheat comercial aplica la política de controladores de kernel cargados en PC de consumo.
