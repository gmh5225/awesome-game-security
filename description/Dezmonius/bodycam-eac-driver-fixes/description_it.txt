Questo progetto offre workaround Windows reversibili per i blocchi all'avvio di Easy Anti-Cheat nel gioco Bodycam che richiedono lo scaricamento di driver kernel di terze parti come AsUpIO.sys, ssgdio64.sys o RTCore64.sys. Ogni correzione mirata è fornita come launcher batch eseguiti come amministratore, abbinati a script PowerShell che individuano i servizi kernel registrati per nome file del driver, eseguono il backup delle impostazioni di avvio, disabilitano il caricamento automatico e tentano di arrestare il driver senza eliminare file né manomettere EAC o la sicurezza di Windows. Il rollback è supportato tramite script di ripristino companion e backup JSON memorizzati in ProgramData, con un rapporto tecnico che documenta le finestre di dialogo EAC osservate, le origini dei driver legate alle utility ASUS e MSI e i limiti di verifica. Le tecnologie principali includono Windows PowerShell 5.1, sc.exe, WMI/CIM e chiavi di servizio del registro. È rivolto ai giocatori che risolvono problemi di compatibilità dei driver EAC e ai ricercatori che studiano come l'anti-cheat commerciale applica la policy sui driver kernel caricati su PC consumer.
