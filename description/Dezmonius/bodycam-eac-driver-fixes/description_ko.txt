이 프로젝트는 Bodycam에서 Easy Anti-Cheat가 AsUpIO.sys, ssgdio64.sys, RTCore64.sys 같은 서드파티 커널 드라이버 언로드를 요구하며 시작을 차단하는 경우에 대해 되돌릴 수 있는 Windows 우회 방법을 제공한다. 각 대상별 수정은 관리자 권한으로 실행하는 배치 런처와 PowerShell 스크립트 쌍으로 제공되며, 드라이버 파일명으로 등록된 커널 서비스를 찾고 시작 설정을 백업한 뒤 자동 로드를 비활성화하고 파일 삭제나 EAC·Windows 보안 훼손 없이 드라이버 중지를 시도한다. 롤백은 동봉된 복원 스크립트와 ProgramData 아래 JSON 백업으로 지원되며, 기술 보고서에는 관찰된 EAC 대화상자, ASUS 및 MSI 유틸리티와 연관된 드라이버 출처, 검증 한계가 문서화되어 있다. 주요 기술은 Windows PowerShell 5.1, sc.exe, WMI/CIM, 레지스트리 서비스 키이다. EAC 드라이버 호환성 문제를 해결하는 플레이어와 상용 안티치트가 일반 PC에서 로드된 커널 드라이버 정책을 어떻게 시행하는지 연구하는 연구자를 대상으로 한다.
