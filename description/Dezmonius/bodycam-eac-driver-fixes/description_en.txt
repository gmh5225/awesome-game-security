This project provides reversible Windows workarounds for Easy Anti-Cheat startup blocks in the Bodycam game that demand unloading third-party kernel drivers such as AsUpIO.sys, ssgdio64.sys, or RTCore64.sys. Each targeted fix ships as administrator-run batch launchers paired with PowerShell scripts that locate registered kernel services by driver filename, back up startup settings, disable autoload, and attempt to stop the driver without deleting files or tampering with EAC or Windows security. Rollback is supported through companion restore scripts and JSON backups stored under ProgramData, with a technical report documenting observed EAC dialogs, driver origins tied to ASUS and MSI utilities, and verification limits. Primary technologies include Windows PowerShell 5.1, sc.exe, WMI/CIM, and registry service keys. It is aimed at players troubleshooting EAC driver compatibility, and at researchers studying how commercial anti-cheat enforces loaded kernel driver policy on consumer PCs.
