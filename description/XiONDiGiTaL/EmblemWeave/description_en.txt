EmblemWeave is a Rust-based Windows launcher and static recompilation stack that runs Fire Emblem: Fortune's Weave natively from a user-supplied game dump without a Nintendo Switch emulator. It decodes compressed NSO modules, lifts AArch64 machine code through control-flow recovery into portable C that is compiled for the PC, and hosts the title with high-level emulation of console SDK services, a Vulkan-backed NVN graphics layer, and layered verification against a reference interpreter and independent CPU models. The application bundles save editing, RomFS mod installation, in-game menus, and cheat support including Atmosphere codes and Cheat Engine tables tied to live game memory. It is aimed at reverse engineers, preservationists, and game-security researchers studying static translation, AArch64 binary analysis, and host-side runtime replacement for modern console titles.
