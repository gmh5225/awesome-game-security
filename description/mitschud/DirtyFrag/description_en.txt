DirtyFrag is an Android application and exploit chain that achieves ephemeral root on arm64 devices by abusing CVE-2026-43284, a kernel page-cache write primitive in IPsec ESP handling. It is a hardened fork of DFRoot that loads a custom kernel module without an unlocked bootloader or a patched boot image, then hands off to a user-chosen KernelSU-style manager via staged libksud. The implementation combines a Java manager UI with native C/JNI code and a loadable kernel module, using AES-CBC transforms, splice-based privilege escalation through crash_dump64, in-place libc++ hooking, and vendor-specific bypasses for Samsung OneUI hardening such as DEFEX, RKP, and KDP. Root lasts only until reboot, with optional autorun, soft reboot, and module toggles for safer recovery. It is aimed at mobile security researchers and practitioners studying kernel exploitation, privileged execution paths, and how modern phones can be temporarily compromised despite locked bootloaders and vendor anti-tamper layers.
