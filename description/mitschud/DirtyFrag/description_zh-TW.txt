DirtyFrag 是一款 Android 應用程式與利用鏈，透過濫用 CVE-2026-43284（IPsec ESP 處理中的核心分頁快取寫入原語）在 arm64 裝置上達成暫時性 root。它是 DFRoot 的強化分支，可在未解鎖 bootloader 或未刷入修補 boot 映像的情況下載入自訂核心模組，再經分階段部署的 libksud 將控制權交給使用者自選的 KernelSU 風格管理器。實作上結合 Java 管理介面、原生 C/JNI 程式碼與可載入核心模組，採用 AES-CBC 變換、經 crash_dump64 的 splice 提權、就地 libc++ 掛鉤，以及針對 Samsung OneUI 強化（如 DEFEX、RKP、KDP）的廠商專屬繞過。Root 權限僅在重新開機前有效，並提供可選的 autorun、軟重新開機與模組開關以便更安全地還原。面向研究核心利用、特權執行路徑，以及在鎖定 bootloader 與廠商防竄改層下現代手機如何被暫時攻破的行動安全研究人員與實務者。
