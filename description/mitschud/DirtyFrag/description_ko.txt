DirtyFrag는 IPsec ESP 처리 과정의 커널 페이지 캐시 쓰기 프리미티브인 CVE-2026-43284를 악용해 arm64 기기에서 일시적인 root를 달성하는 Android 앱 및 익스플로잇 체인입니다. DFRoot의 강화 포크로, 부트로더 잠금 해제나 패치된 boot 이미지 없이 사용자 정의 커널 모듈을 로드한 뒤, 단계적으로 배치한 libksud를 통해 사용자가 선택한 KernelSU 스타일 관리자로 넘깁니다. Java 관리 UI, 네이티브 C/JNI 코드, 로드 가능한 커널 모듈을 결합하며 AES-CBC 변환, crash_dump64를 통한 splice 기반 권한 상승, 제자리 libc++ 후킹, Samsung OneUI의 DEFEX·RKP·KDP 같은 벤더 강화 우회를 사용합니다. root는 재부팅 전까지만 유지되며 autorun, 소프트 리부트, 모듈 토글 등 더 안전한 복구를 위한 옵션이 있습니다. 잠긴 부트로더와 벤더 변조 방지 계층에도 현대 스마트폰이 일시적으로 침해될 수 있는 방식, 커널 익스플로잇, 특권 실행 경로를 연구하는 모바일 보안 연구자와 실무자를 대상으로 합니다.
