DirtyFrag 是一款 Android 应用及利用链，通过滥用 CVE-2026-43284（IPsec ESP 处理中的内核页缓存写原语）在 arm64 设备上实现临时 root。它是 DFRoot 的加固分支，可在未解锁 bootloader 或未刷入修补 boot 镜像的情况下加载自定义内核模块，随后通过分阶段部署的 libksud 将控制权交给用户自选的 KernelSU 风格管理器。实现上结合了 Java 管理界面、原生 C/JNI 代码与可加载内核模块，采用 AES-CBC 变换、经 crash_dump64 的 splice 提权、就地 libc++ 挂钩，以及针对 Samsung OneUI 加固（如 DEFEX、RKP、KDP）的厂商专属绕过。Root 权限仅在重启前有效，并提供可选的 autorun、软重启与模块开关以便更安全地恢复。面向研究内核利用、特权执行路径，以及在锁定 bootloader 与厂商防篡改层下现代手机如何被临时攻破的移动安全研究人员与实践者。
