DirtyFrag は Android アプリとエクスプロイトチェーンで、IPsec ESP 処理におけるカーネルページキャッシュ書き込みプリミティブ CVE-2026-43284 を悪用し、arm64 デバイス上で一時的な root を得ます。DFRoot のハード化フォークであり、ブートローダの unlock や boot イメージのパッチなしにカスタムカーネルモジュールをロードし、段階的に配置した libksud 経由でユーザーが選んだ KernelSU 系マネージャへ引き渡します。Java マネージャ UI、ネイティブ C/JNI、ロード可能なカーネルモジュールを組み合わせ、AES-CBC 変換、crash_dump64 経由の splice による権限昇格、インプレース libc++ フック、Samsung OneUI の DEFEX・RKP・KDP などのベンダー強化向けバイパスを用います。root は再起動までのみ有効で、autorun、ソフトリブート、モジュール切替など安全な復旧のためのオプションがあります。ロックされたブートローダとベンダー改ざん防止層下でも端末が一時的に侵害され得る仕組み、カーネルエクスプロイト、特権実行経路を調べるモバイルセキュリティ研究者・実務者向けです。
