DirtyFrag — Android-приложение и цепочка эксплуатации, дающая эфемерный root на устройствах arm64 за счёт злоупотребления CVE-2026-43284, примитивом записи в page cache ядра при обработке IPsec ESP. Это упрочнённый форк DFRoot, загружающий пользовательский модуль ядра без разблокированного загрузчика и пропатченного boot-образа, затем передающий управление выбранному пользователем менеджеру в стиле KernelSU через поэтапно развёрнутый libksud. Реализация сочетает Java-интерфейс менеджера, нативный код C/JNI и загружаемый модуль ядра: преобразования AES-CBC, повышение привилегий через splice с участием crash_dump64, in-place хукинг libc++, обходы под усиления Samsung OneUI — DEFEX, RKP и KDP. Root действует только до перезагрузки; опционально — autorun, мягкая перезагрузка и переключатели модулей для более безопасного восстановления. Для исследователей и практиков мобильной безопасности, изучающих эксплуатацию ядра, привилегированные пути выполнения и временный компромисс современных телефонов при заблокированном загрузчике и антивмешательственных слоях производителя.
