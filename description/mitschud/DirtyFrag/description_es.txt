DirtyFrag es una aplicación Android y una cadena de explotación que consigue root efímero en dispositivos arm64 abusando de CVE-2026-43284, una primitiva de escritura en la caché de páginas del kernel en el manejo IPsec ESP. Es un fork endurecido de DFRoot que carga un módulo de kernel personalizado sin bootloader desbloqueado ni imagen boot parcheada, y luego cede el control a un gestor al estilo KernelSU elegido por el usuario mediante libksud desplegado por fases. La implementación combina una UI de gestión en Java con código nativo C/JNI y un módulo de kernel cargable, usando transformaciones AES-CBC, escalada de privilegios basada en splice vía crash_dump64, hooking in-place de libc++ y bypasses específicos del fabricante para el endurecimiento Samsung OneUI como DEFEX, RKP y KDP. El root dura solo hasta el reinicio, con autorun, soft reboot e interruptores de módulos opcionales para una recuperación más segura. Está dirigido a investigadores y profesionales de seguridad móvil que estudian explotación del kernel, rutas de ejecución privilegiadas y cómo los teléfonos modernos pueden comprometerse temporalmente pese a bootloaders bloqueados y capas anti-manipulación del fabricante.
