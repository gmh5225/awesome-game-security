YW4 Recomp 是一款粉丝向静态重编译项目，参考 N64Recomp 的做法，将 Nintendo Switch 游戏《妖怪手表 4++》转化为可在 Windows 与 Linux 上运行的原生程序；用户在构建与运行时需自行提供从卡带转储的游戏资源，仓库内不包含商业二进制文件。基于 Python 的 AArch64 转 C 重编译器将经验证的主 NSO 代码提升为生成源码，并配以 C/C++ 运行时，对 Nintendo SDK 服务进行高层仿真，图形经 Vulkan 管线处理，含着色器翻译及引擎级自定义渲染器，并支持分辨率缩放、宽屏、TAA、DLSS 或 FSR 等面向 PC 的增强，以及 LayeredFS 风格的模组支持。仓库还提供 CMake 构建集成、面向 Ghidra 的分析与侦察工具、针对 ARM64 参考运行的黄金指令测试，以及用于在 Windows 与 Linux 上打包的 Rust Tauri 启动器。项目面向探索主机二进制逆向工程、静态重编译流程，以及封闭平台游戏原生移植的开发者和研究人员。
