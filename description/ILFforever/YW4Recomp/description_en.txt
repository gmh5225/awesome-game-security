YW4 Recomp is a fan static recompilation project that turns the Nintendo Switch title Yo-kai Watch 4++ into a native Windows and Linux program, in the style of N64Recomp, with users providing their own dumped game assets at build and run time rather than bundling commercial binaries in the repository. A Python AArch64-to-C recompiler lifts verified main NSO code into generated sources, paired with a C and C++ runtime that high-level-emulates Nintendo SDK services and routes graphics through Vulkan, including shader translation and a custom engine-level renderer with PC-focused enhancements such as resolution scaling, widescreen, TAA, DLSS or FSR, and LayeredFS-style mod support. The repository also ships CMake build integration, Ghidra-oriented analysis and recon tooling, golden instruction tests against ARM64 reference runs, and a Rust Tauri launcher for packaging on Windows and Linux. It is intended for developers and researchers exploring console binary reverse engineering, static recompilation pipelines, and native ports of closed-platform games.
