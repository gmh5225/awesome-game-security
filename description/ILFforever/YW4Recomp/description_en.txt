YW4 Recomp is a fan static recompilation effort that translates the Nintendo Switch build of Yo-kai Watch 4++ into a native Windows and Linux executable, in the spirit of N64Recomp, using only user-supplied game dumps at build time. The stack combines a Python AArch64-to-C recompiler, a C and C++20 host runtime with high-level emulation of Horizon SDK services and NVN graphics mapped to Vulkan via SDL3, plus CMake packaging and a launcher that builds and updates the port locally. Extensive reverse-engineering tooling covers NSO hash-locked ingestion, Ghidra-oriented function recovery, shader translation from NV_gpu_program5 assembly, and documented decisions on memory, threads, and renderer replacement. It suits researchers and developers interested in Switch binary analysis, static recompilation pipelines, and engine-level graphics porting rather than conventional emulator-based play.
