YW4 Recomp 是一款粉絲向靜態重編譯專案，參考 N64Recomp 的做法，將 Nintendo Switch 遊戲《妖怪手錶 4++》轉成可在 Windows 與 Linux 上執行的原生程式；使用者在建置與執行時須自行提供從卡帶傾印的遊戲資源，儲存庫內不包含商業二進位檔。以 Python 撰寫的 AArch64 轉 C 重編譯器將經驗證的主 NSO 程式碼提升為產生的原始碼，並搭配 C/C++ 執行階段，對 Nintendo SDK 服務進行高階模擬，圖形經 Vulkan 管線處理，含著色器翻譯及引擎層級自訂渲染器，並支援解析度縮放、寬螢幕、TAA、DLSS 或 FSR 等面向 PC 的強化，以及 LayeredFS 風格的模組支援。儲存庫亦提供 CMake 建置整合、面向 Ghidra 的分析與偵察工具、針對 ARM64 參考執行的黃金指令測試，以及用於在 Windows 與 Linux 上封裝的 Rust Tauri 啟動器。專案面向探索主機二進位逆向工程、靜態重編譯流程，以及封閉平台遊戲原生移植的開發者與研究人員。
