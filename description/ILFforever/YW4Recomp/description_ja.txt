YW4 Recomp は、N64Recomp の手法に倣い、Nintendo Switch タイトル『妖怪ウォッチ4++』を Windows および Linux 向けのネイティブプログラムへと変換するファン主導の静的再コンパイルプロジェクトであり、ビルド時および実行時にユーザーが自前でダンプしたゲームアセットを用意する方式で、商用バイナリをリポジトリに同梱しません。Python 製の AArch64 から C への再コンパイラが検証済みのメイン NSO コードを生成ソースへ昇格させ、Nintendo SDK サービスを高レベルエミュレートする C/C++ ランタイムと組み合わせ、グラフィックスは Vulkan 経由で処理し、シェーダー変換とエンジンレベルのカスタムレンダラーを備え、解像度スケーリング、ワイドスクリーン、TAA、DLSS または FSR、LayeredFS 方式の MOD 対応など PC 向け拡張を含みます。リポジトリには CMake ビルド統合、Ghidra 向け解析・偵察ツール、ARM64 参照実行に対するゴールデン命令テスト、Windows/Linux 向けパッケージング用の Rust Tauri ランチャーも同梱されています。コンソールバイナリのリバースエンジニアリング、静的再コンパイルパイプライン、クローズドプラットフォームゲームのネイティブ移植を探究する開発者および研究者向けです。
