YW4 Recomp는 N64Recomp 방식을 따르는 팬 주도 정적 재컴파일 프로젝트로, Nintendo Switch 타이틀 『요괴워치 4++』를 Windows 및 Linux용 네이티브 프로그램으로 변환하며, 빌드 및 실행 시 사용자가 직접 덤프한 게임 에셋을 제공하고 저장소에 상용 바이너리를 포함하지 않습니다. Python 기반 AArch64-to-C 재컴파일러가 검증된 메인 NSO 코드를 생성 소스로 끌어올리고, Nintendo SDK 서비스를 고수준 에뮬레이트하는 C/C++ 런타임과 결합되며, 그래픽은 Vulkan을 통해 처리하고 셰이더 변환 및 엔진 수준의 커스텀 렌더러를 갖추며 해상도 스케일링, 와이드스크린, TAA, DLSS 또는 FSR, LayeredFS 스타일 모드 지원 등 PC 중심 개선을 포함합니다. 저장소에는 CMake 빌드 통합, Ghidra 지향 분석 및 정찰 도구, ARM64 참조 실행 대비 골든 명령 테스트, Windows/Linux 패키징용 Rust Tauri 런처도 제공됩니다. 콘솔 바이너리 리버스 엔지니어링, 정적 재컴파일 파이프라인, 폐쇄 플랫폼 게임의 네이티브 포팅을 탐구하는 개발자 및 연구자를 위한 프로젝트입니다.
