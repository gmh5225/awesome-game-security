YW4 Recomp est un projet de recompilation statique amateur qui transforme le jeu Nintendo Switch Yo-kai Watch 4++ en programme natif pour Windows et Linux, sur le modèle de N64Recomp, les utilisateurs fournissant leurs propres assets de jeu dumpés à la compilation et à l’exécution plutôt que d’embarquer des binaires commerciaux dans le dépôt. Un recompilateur Python AArch64 vers C relève le code NSO principal vérifié en sources générées, associé à un runtime C/C++ qui émule de haut niveau les services du Nintendo SDK et achemine le rendu graphique via Vulkan, avec traduction de shaders et un moteur de rendu personnalisé au niveau moteur, incluant des améliorations orientées PC comme le scaling de résolution, le format large, le TAA, le DLSS ou le FSR, et la prise en charge de mods de type LayeredFS. Le dépôt fournit aussi l’intégration de build CMake, des outils d’analyse et de reconnaissance orientés Ghidra, des tests d’instructions golden contre des exécutions de référence ARM64, et un lanceur Rust Tauri pour l’empaquetage sous Windows et Linux. Il s’adresse aux développeurs et chercheurs qui explorent le reverse engineering de binaires console, les pipelines de recompilation statique et les ports natifs de jeux sur plateformes fermées.
