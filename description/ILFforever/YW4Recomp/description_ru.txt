YW4 Recomp — фанатский проект статической перекомпиляции, который по образцу N64Recomp превращает игру для Nintendo Switch Yo-kai Watch 4++ в нативную программу для Windows и Linux; пользователи сами предоставляют дампированные игровые ресурсы при сборке и запуске, без включения коммерческих бинарников в репозиторий. Перекомпилятор на Python с AArch64 в C поднимает проверенный основной код NSO в сгенерированные исходники в паре с средой выполнения на C/C++, которая эмулирует службы Nintendo SDK на высоком уровне и выводит графику через Vulkan, включая перевод шейдеров и собственный рендерер на уровне движка с улучшениями под ПК: масштабирование разрешения, широкоэкранный режим, TAA, DLSS или FSR и поддержка модов в стиле LayeredFS. В репозитории также есть интеграция сборки CMake, инструменты анализа и разведки под Ghidra, golden-тесты инструкций против эталонных прогонов ARM64 и лаунчер на Rust Tauri для упаковки под Windows и Linux. Проект предназначен для разработчиков и исследователей, изучающих реверс-инжиниринг консольных бинарников, пайплайны статической перекомпиляции и нативные порты игр с закрытых платформ.
