Cheeto 是一款面向 Roblox 的 schema 驅動網路編譯器，可根據事件、函式與複製狀態的宣告式描述，為用戶端與伺服器通訊生成型別化的 buffer-packed Luau 模組。開發者在專用 schema 語言中定義網路流量，編譯器會產生完全型別化的傳送與接收程式碼，並內建驗證、速率限制、策略及其他安全控制，在應用程式處理常式執行前拒絕格式錯誤或未授權的封包。它支援面向生產環境的功能，例如附增量複製的狀態通道、用戶端預測、批次處理、封包擷取與回放，以及可選的最高安全預設（含用戶端完整性檢查、蜜罐與移動反作弊輔助功能）。工具鏈包含跨平台 CLI、Roblox Studio 外掛、用於 schema 版本管理的 lockfile，以及面向 roblox-ts 專案的 TypeScript 定義。它面向需要高效能、型別安全網路通訊，並對遠端漏洞利用與作弊濫用進行伺服器權威安全加固的 Roblox 遊戲開發者。
