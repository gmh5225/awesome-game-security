Cheeto 是一个面向 Roblox 的 schema 驱动网络编译器，可根据事件、函数和复制状态的声明式描述，为客户端与服务器通信生成类型化的 buffer-packed Luau 模块。开发者在专用 schema 语言中定义网络流量，编译器会生成完全类型化的发送与接收代码，并内置验证、速率限制、策略及其他安全控制，在应用层处理程序运行前拒绝格式错误或未经授权的数据包。它支持面向生产环境的功能，例如带增量复制的状态通道、客户端预测、批处理、数据包捕获与回放，以及可选的最高安全预设（含客户端完整性检查、蜜罐和移动反作弊辅助功能）。工具链包含跨平台 CLI、Roblox Studio 插件、用于 schema 版本管理的 lockfile，以及面向 roblox-ts 项目的 TypeScript 定义。它面向需要高性能、类型安全网络通信，并对远程漏洞利用与作弊滥用进行服务器权威安全加固的 Roblox 游戏开发者。
