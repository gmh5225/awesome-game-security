Cheeto is a schema-driven networking compiler for Roblox that generates typed, buffer-packed Luau modules for client and server communication from a declarative description of events, functions, and replicated state. Developers define their network traffic in a dedicated schema language, and the compiler emits fully typed send and receive code along with built-in validation, rate limits, policies, and other security controls that reject malformed or unauthorized packets before application handlers run. It supports production-oriented features such as state channels with delta replication, client prediction, batching, packet capture and replay, and an optional maximum-security preset with client integrity checks, honeypots, and movement anti-cheat helpers. The toolchain includes a cross-platform CLI, Roblox Studio plugin, lockfile for schema versioning, and TypeScript definitions for roblox-ts projects. It targets Roblox game developers who need performant, type-safe networking with server-authoritative security hardening against remote exploit and cheat abuse.
