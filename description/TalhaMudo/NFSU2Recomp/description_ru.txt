NFSU2Recomp — проект статической перекомпиляции, который превращает 32-битный x86 Windows-исполняемый файл Need for Speed: Underground 2 в нативное приложение macOS ARM64 без Wine, эмуляции или JIT во время выполнения. Инструменты на Python заранее поднимают гостевой машинный код в C, который компилирует clang, а написанная вручную среда выполнения эмулирует Win32 API, отображает 32-битное гостевое адресное пространство и переводит эффекты Direct3D 9 и D3DX9 в Metal, для звука используется CoreAudio. Конвейер включает пользовательское восстановление релокаций PE, рекурсивный поиск функций, таблицы диспетчеризации косвенных вызовов и сокращения эмуляции высокого уровня для горячих путей, таких как фреймворк эффектов D3DX. Основные языки: C для runtime и сгенерированного кода, Python для lifter и скриптов анализа, Objective-C для интеграции с Metal. Проект ориентирован на reverse-инженеров и разработчиков, изучающих статический перенос x86, портирование устаревшего DirectX и анализ бинарников игр, а не на античит или безопасность живого мультиплеера.
