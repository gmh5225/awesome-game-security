NFSU2Recomp est un projet de recompilation statique qui transforme l’exécutable Windows x86 32 bits de Need for Speed: Underground 2 en application macOS ARM64 native, sans Wine, émulation ni JIT à l’exécution. Des outils Python relèvent à l’avance le code machine invité en C compilé par clang, tandis qu’un runtime écrit à la main émule les API Win32, mappe l’espace d’adressage invité 32 bits et traduit les effets Direct3D 9 et D3DX9 vers Metal, avec CoreAudio pour le son. Le pipeline comprend une récupération personnalisée des relocations PE, une découverte récursive des fonctions, des tables de dispatch d’appels indirects et des raccourcis d’émulation de haut niveau pour les chemins chauds comme le framework d’effets D3DX. Les langages principaux sont le C pour le runtime et le code généré, Python pour le lifter et les scripts d’analyse, et Objective-C pour l’intégration Metal. Il s’adresse aux ingénieurs reverse et aux développeurs qui étudient la traduction statique x86, le portage DirectX hérité et l’analyse binaire de jeux, plutôt qu’à l’anti-triche ou à la sécurité du multijoueur en ligne.
