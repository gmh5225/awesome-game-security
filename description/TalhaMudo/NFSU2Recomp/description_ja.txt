NFSU2Recomp は、Need for Speed: Underground 2 の 32 ビット x86 Windows 実行ファイルを、Wine・エミュレーション・実行時 JIT なしでネイティブな ARM64 macOS アプリケーションに変換する静的再コンパイルプロジェクトです。Python ツールがゲストマシンコードを事前に C にリフトし clang がコンパイルし、手書きランタイムが Win32 API をエミュレートして 32 ビットゲストアドレス空間をマップし、Direct3D 9 と D3DX9 エフェクトを Metal に、音声を CoreAudio で処理します。パイプラインにはカスタム PE リロケーション復元、再帰的関数探索、間接呼び出しディスパッチテーブル、D3DX エフェクトフレームワークなどのホットパス向け高レベルエミュレーションショートカットが含まれます。主な言語は、ランタイムと生成コードに C、リフターと分析スクリプトに Python、Metal 統合に Objective-C です。x86 静的翻訳、レガシー DirectX ポート、ゲームバイナリ解析を学ぶリバースエンジニアと開発者向けであり、アンチチートやライブマルチプレイのセキュリティ研究向けではありません。
