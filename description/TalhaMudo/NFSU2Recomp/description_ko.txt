NFSU2Recomp는 Need for Speed: Underground 2의 32비트 x86 Windows 실행 파일을 Wine, 에뮬레이션, 런타임 JIT 없이 네이티브 ARM64 macOS 애플리케이션으로 바꾸는 정적 재컴파일 프로젝트입니다. Python 도구가 게스트 머신 코드를 사전에 C로 리프트하고 clang이 컴파일하며, 수작업 런타임은 Win32 API를 에뮬레이트하고 32비트 게스트 주소 공간을 매핑하며 Direct3D 9와 D3DX9 이펙트를 Metal로, 사운드는 CoreAudio로 처리합니다. 파이프라인에는 사용자 정의 PE 재배치 복구, 재귀적 함수 탐색, 간접 호출 디스패치 테이블, D3DX 이펙트 프레임워크 같은 핫 패스용 고수준 에뮬레이션 단축이 포함됩니다. 주요 언어는 런타임과 생성 코드에 C, 리프터와 분석 스크립트에 Python, Metal 통합에 Objective-C입니다. x86 정적 번역, 레거시 DirectX 포팅, 게임 바이너리 분석을 공부하는 리버스 엔지니어와 개발자를 대상으로 하며, 안티치트나 라이브 멀티플레이 보안 작업용은 아닙니다.
