NFSU2Recomp is a static recompilation project that turns the 32-bit x86 Windows executable of Need for Speed: Underground 2 into a native ARM64 macOS application without Wine, emulation, or a JIT at run time. Python tooling lifts guest machine code ahead of time into C that clang compiles, while a hand-written runtime emulates Win32 APIs, maps the 32-bit guest address space, and translates Direct3D 9 and D3DX9 effects to Metal with CoreAudio for sound. The pipeline includes custom PE relocation recovery, recursive function discovery, indirect-call dispatch tables, and high-level emulation shortcuts for hot paths such as the D3DX effect framework. Primary languages are C for the runtime and generated code, Python for the lifter and analysis scripts, and Objective-C for Metal integration. It is aimed at reverse engineers and developers studying x86 static translation, legacy DirectX ports, and game binary analysis rather than anti-cheat or live multiplayer security work.
