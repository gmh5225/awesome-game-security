OculusAI 是一款適用於 Minecraft Java 的伺服器端反作弊外掛，可在 Paper 與 Folia 上運行，透過機器學習模型對可疑的 PvP 瞄準移動及終界水晶戰鬥行為進行評分。專案主要以 Java 撰寫並以 Gradle 建置，透過 ProtocolLib 與託管 API 連結伺服器、儀表板與可選的雲端更新。外掛結合神經網路瞄準與水晶檢查及傳統戰鬥檢查（如穿牆與碰撞箱驗證），為每位玩家維護獨立的可疑度緩衝，並分別設定告警與懲處門檻，並支援工作人員流程：即時監控、遊戲內設定選單、日誌、繞過控制，以及可在瀏覽器中檢視的懲處回放與短戰鬥錄影。它面向希望採用機率性作弊偵測、具備訓練資料集收集工具以及 NPC 或競技場測試環境的多人伺服器營運者與反作弊實作者，而非純規則型的客戶端模組。
