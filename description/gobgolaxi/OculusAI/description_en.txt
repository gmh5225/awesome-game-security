OculusAI is a server-side anti-cheat plugin for Minecraft Java that runs on Paper and Folia and uses machine-learning models to score suspicious PvP aim movement and end-crystal combat behavior. Written primarily in Java and built with Gradle, it integrates with ProtocolLib and a hosted API to link servers, dashboards, and optional cloud-backed updates. The plugin combines neural aim and crystal checks with classical combat checks such as wall and hitbox validation, maintains per-player suspicion buffers with separate alert and punishment thresholds, and supports staff workflows including live monitoring, in-game configuration menus, journals, bypass controls, and browser-viewable punishment replays with short combat recordings. It is aimed at multiplayer server operators and anti-cheat practitioners who want probabilistic cheat detection, tooling to collect training datasets, and NPC or arena test setups rather than a purely rule-based client mod.
