OculusAI 是一款面向 Minecraft Java 的服务端反作弊插件，可在 Paper 与 Folia 上运行，通过机器学习模型对可疑的 PvP 瞄准移动及末地水晶战斗行为进行评分。项目主要使用 Java 编写并以 Gradle 构建，借助 ProtocolLib 与托管 API 连接服务器、控制台与可选的云端更新。插件将神经网络瞄准与水晶检测与传统战斗校验（如穿墙与碰撞箱验证）相结合，为每位玩家维护独立的可疑度缓冲，并分别设置告警与处罚阈值，同时支持工作人员工作流：实时监控、游戏内配置菜单、日志、绕过控制，以及可在浏览器中查看的处罚回放与简短战斗录像。它面向希望采用概率式作弊检测、具备训练数据集收集工具以及 NPC 或竞技场测试环境的多人服务器运营者与反作弊从业者，而非仅依赖规则的客户端模组。
