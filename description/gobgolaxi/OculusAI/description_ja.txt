OculusAI は、Minecraft Java 向けのサーバー側アンチチートプラグインで、Paper と Folia 上で動作し、機械学習モデルにより疑わしい PvP の照準移動やエンドクリスタル戦闘の挙動をスコア化します。主に Java で書かれ Gradle でビルドされ、ProtocolLib とホスト型 API によりサーバー、ダッシュボード、任意のクラウド更新を連携します。プラグインはニューラルな照準・クリスタル検査と、壁抜けやヒットボックス検証などの古典的な戦闘チェックを組み合わせ、プレイヤーごとの疑いバッファを維持し、アラートと処罰の閾値を分け、ライブ監視、ゲーム内設定メニュー、ジャーナル、バイパス制御、ブラウザで閲覧可能な処罰リプレイと短い戦闘録画などスタッフ向けワークフローをサポートします。純粋なルールベースのクライアント MOD ではなく、確率的なチート検出、学習データセット収集ツール、NPC やアリーナでのテスト環境を求めるマルチプレイサーバー運営者とアンチチート実務者を対象としています。
