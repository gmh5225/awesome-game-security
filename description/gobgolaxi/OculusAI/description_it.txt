OculusAI è un plugin anti-cheat lato server per Minecraft Java che gira su Paper e Folia e usa modelli di machine learning per valutare movimenti di mira PvP sospetti e il comportamento in combattimento con cristalli dell’End. Scritto principalmente in Java e costruito con Gradle, si integra con ProtocolLib e un’API ospitata per collegare server, dashboard e aggiornamenti cloud opzionali. Il plugin combina controlli neurali su mira e cristalli con controlli di combattimento classici come validazione di muri e hitbox, mantiene buffer di sospetto per giocatore con soglie separate per allerta e punizione, e supporta flussi di lavoro dello staff: monitoraggio live, menu di configurazione in gioco, journal, controlli di bypass e replay delle punizioni visualizzabili nel browser con brevi registrazioni di combattimento. È pensato per operatori di server multigiocatore e professionisti dell’anti-cheat che vogliono rilevamento probabilistico, strumenti per raccogliere dataset di addestramento e setup di test con NPC o arene piuttosto che una mod client puramente basata su regole.
