This project is a multi-version Warcraft III Legacy trainer that extends an older universal cheat table with a native x86 backend for patch 1.29.2 and optional Mandarin voice prompts for local single-player use. It is built around Cheat Engine tables and Lua automation, with Python tooling to recover the original trainer binary, integrate preserved Auto Assembler scripts, and ship a unified voice-enabled executable. The 1.29.2 path relies on a MinGW-compiled DLL that attaches to the game process, validates the exact executable hash, and exposes hero, unit, resource, and map-reveal actions through Ctrl+A–R hotkeys. Offline tests cover Lua adapters, integration packaging, and Windows SAPI speech synthesis without live game input. It is aimed at developers and researchers studying classic RTS trainer mechanics, CE-based memory editing workflows, and version-specific game binary adaptation rather than online play.
