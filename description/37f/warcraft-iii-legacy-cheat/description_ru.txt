Этот проект — мультиверсионный тренер для Warcraft III Legacy, расширяющий старую универсальную чит-таблицу нативным x86-бэкендом для патча 1.29.2 и опциональными голосовыми подсказками на мандаринском для локального одиночного режима. Основа — таблицы Cheat Engine и автоматизация на Lua; инструменты на Python восстанавливают исходный бинарник тренера, встраивают сохранённые скрипты Auto Assembler и собирают единый исполняемый файл с озвучкой. Путь 1.29.2 опирается на DLL, собранную MinGW: она подключается к процессу игры, проверяет точный хеш исполняемого файла и выдаёт действия с героями, юнитами, ресурсами и раскрытием карты по горячим клавишам Ctrl+A–R. Офлайн-тесты охватывают адаптеры Lua, упаковку интеграции и синтез речи Windows SAPI без живого ввода в игру. Предназначен разработчикам и исследователям, изучающим механику классических RTS-тренеров, рабочие процессы редактирования памяти через CE и адаптацию игровых бинарников под версии, а не для сетевой игры.
