OdinGuard は、rAthena または互換フォーク上で動く Ragnarok Online プライベートサーバー向けのオープンソース・モジュラー型アンチチートスタックです。サーバー運営者は OdinGuard Studio または Rust 製 og CLI で保護モジュール、チャレンジ、チートシグネチャ、ロールアウト方針を設定し、サーバーごとの鍵で署名済みのクライアントおよびサーバービルドを配布します。Windows クライアントは C で書かれた 32 ビット guard DLL と ijl15 プロキシローダーを用い、rAthena 統合モジュールとワイヤプロトコルは C++ で実装され、プロトコル定義を共有します。暗号化されたゲームトラフィック（X25519 ハンドシェイクと XChaCha20-Poly1305）、整合性およびアンチデバッグチェック、更新可能なシグネチャパック、レート制限・ハニーポット・BAN ウェーブなどサーバー権威のルールを組み合わせ、ボットや公開チートツールのコストを高めます。閉源の商用アンチチートに代わる監査可能な選択肢を求める RO サーバー所有者およびゲームセキュリティ実務者向けです。
