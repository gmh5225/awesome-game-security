OdinGuard 是一套面向基于 rAthena 或其兼容分支的《仙境传说》私服的开源模块化反作弊栈。服主可在 OdinGuard Studio 或 Rust 版 og CLI 中配置保护模块、挑战、作弊特征与发布策略，再使用每服独立密钥交付签名的客户端与服务端构建。Windows 客户端采用 C 编写的 32 位 guard DLL 与 ijl15 代理加载器；rAthena 集成模块与线协议以 C++ 实现，并共享协议定义。它结合加密游戏流量（X25519 握手与 XChaCha20-Poly1305）、完整性与反调试检测、可更新特征包，以及服务端权威规则（如速率限制、蜜罐与封禁波次），以提高机器人与公开作弊工具的攻击成本。面向希望获得可审计、可替代闭源商业反作弊方案的 RO 服主与游戏安全从业者。
