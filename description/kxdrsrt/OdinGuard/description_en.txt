OdinGuard is an open-source, modular anti-cheat stack for Ragnarok Online private servers built on rAthena or compatible forks. Server operators configure protection modules, challenges, cheat signatures, and rollout policy in OdinGuard Studio or the Rust og CLI, then ship signed client and server builds with per-server keys. The Windows client uses a 32-bit guard DLL and ijl15 proxy loader written in C, while the rAthena integration module and wire protocol live in C++ with shared protocol definitions. It combines encrypted game traffic (X25519 handshake and XChaCha20-Poly1305), integrity and anti-debug checks, updatable signature packs, and server-authoritative rules such as rate limits, honeypots, and ban waves to raise the cost of bots and public cheat tools. It is aimed at RO server owners and game-security practitioners who want an auditable alternative to closed commercial anti-cheats.
