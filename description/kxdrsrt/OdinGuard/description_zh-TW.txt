OdinGuard 是一套面向基於 rAthena 或其相容分支的《仙境傳說》私人伺服器的開源模組化反作弊堆疊。伺服器營運者可在 OdinGuard Studio 或 Rust 版 og CLI 中設定保護模組、挑戰、作弊特徵與部署策略，再以每伺服器專用金鑰交付簽署的客戶端與伺服器端建置。Windows 客戶端採用 C 撰寫的 32 位元 guard DLL 與 ijl15 代理載入器；rAthena 整合模組與線路協定以 C++ 實作，並共用協定定義。它結合加密遊戲流量（X25519 握手與 XChaCha20-Poly1305）、完整性與反偵錯檢查、可更新特徵套件，以及伺服器端權威規則（如速率限制、蜜罐與封鎖波次），以提高機器人與公開作弊工具的成本。面向希望取得可稽核、可替代閉源商業反作弊方案的 RO 服主與遊戲安全實務者。
