GlassMic — это модуль с открытым исходным кодом виртуального микрофона и тестирования аудиопайплайна для рутированных Android-телефонов с LSPosed. Он в основном написан на Kotlin с UI на Compose, а также на Java и C++ с нативными хуками, перехватывающими AudioRecord, AAudio, OpenSL ES и связанные пути захвата, чтобы целевые приложения записи получали PCM из импортированных файлов, вывода TTS или экспериментального захвата живого воспроизведения. Проект также может внедрять аудио через экспериментный root-бэкенд AudioPolicy, предоставляет плавающие элементы управления, диагностику и зашифрованные API-ключи для опциональных облачных TTS-провайдеров, а для нативного inline-хукинга использует shadowhook вместе с libxposed. Он ориентирован на разработчиков и исследователей, которым нужны контролируемые on-device эксперименты с маршрутизацией микрофона, совместимостью захвата и видимостью хуков, а не на продакшен-инструменты античита.
