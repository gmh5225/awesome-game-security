GlassMic 是一款面向已 root 且使用 LSPosed 的 Android 手機之開源虛擬麥克風與音訊管線測試模組。專案主要以 Kotlin 與 Compose UI 建置，並輔以 Java 與 C++ 原生鉤子，攔截 AudioRecord、AAudio、OpenSL ES 及相關擷取路徑，使目標錄音應用程式接收來自匯入檔案、TTS 輸出或實驗性即時回放擷取的 PCM。該專案亦可透過實驗性的 root 級 AudioPolicy 後端注入音訊，提供浮動控制項、診斷資訊以及用於可選雲端 TTS 服務商的加密 API 金鑰，並搭配 shadowhook 進行原生內聯鉤子以及 libxposed。它面向需要在裝置上進行可控實驗的開發者與研究人員，著重麥克風路由、擷取相容性與鉤子可見性，而非生產級反作弊工具。
