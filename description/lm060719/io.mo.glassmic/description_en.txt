GlassMic is an open-source virtual microphone and Android audio pipeline testing module for rooted phones that use LSPosed. It is built mainly in Kotlin with a Compose UI, plus Java and C++ native hooks that intercept AudioRecord, AAudio, OpenSL ES, and related capture paths so target recording apps receive PCM from imported files, TTS output, or experimental live playback capture. The project can also inject audio via an experimental root AudioPolicy backend, exposes floating controls, diagnostics, and encrypted API keys for optional cloud TTS providers, and uses shadowhook for native inline hooking alongside libxposed. It targets developers and researchers who need controlled, on-device experiments with microphone routing, capture compatibility, and hook visibility rather than production anti-cheat tooling.
