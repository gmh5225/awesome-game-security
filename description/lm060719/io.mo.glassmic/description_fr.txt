GlassMic est un module open source de microphone virtuel et de test de pipeline audio pour téléphones Android rootés utilisant LSPosed. Il est principalement développé en Kotlin avec une interface Compose, ainsi qu’en Java et en C++ avec des hooks natifs qui interceptent AudioRecord, AAudio, OpenSL ES et les chemins de capture associés, afin que les applications d’enregistrement ciblées reçoivent du PCM provenant de fichiers importés, de sorties TTS ou de captures expérimentales de lecture en direct. Le projet peut aussi injecter de l’audio via un backend AudioPolicy root expérimental, propose des contrôles flottants, des diagnostics et des clés API chiffrées pour des fournisseurs TTS cloud optionnels, et utilise shadowhook pour le hooking inline natif avec libxposed. Il s’adresse aux développeurs et chercheurs qui ont besoin d’expériences contrôlées sur appareil pour le routage du micro, la compatibilité de capture et la visibilité des hooks, plutôt qu’à un outillage anti-triche de production.
