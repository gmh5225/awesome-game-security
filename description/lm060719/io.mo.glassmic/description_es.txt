GlassMic es un módulo de código abierto de micrófono virtual y pruebas de pipeline de audio para teléfonos Android con root que usan LSPosed. Está construido principalmente en Kotlin con interfaz Compose, además de Java y C++ con hooks nativos que interceptan AudioRecord, AAudio, OpenSL ES y rutas de captura relacionadas para que las apps de grabación objetivo reciban PCM desde archivos importados, salida TTS o captura experimental de reproducción en vivo. El proyecto también puede inyectar audio mediante un backend AudioPolicy root experimental, ofrece controles flotantes, diagnósticos y claves API cifradas para proveedores TTS en la nube opcionales, y usa shadowhook para hooking inline nativo junto con libxposed. Está dirigido a desarrolladores e investigadores que necesitan experimentos controlados en el dispositivo con enrutamiento de micrófono, compatibilidad de captura y visibilidad de hooks, no a herramientas anti-trampas de producción.
