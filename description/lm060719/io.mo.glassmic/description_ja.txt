GlassMic は、root 化済みで LSPosed を利用する Android 端末向けのオープンソース仮想マイクおよびオーディオパイプライン試験用モジュールです。主に Kotlin と Compose UI で構築され、Java および C++ のネイティブフックにより AudioRecord、AAudio、OpenSL ES などの関連キャプチャ経路を横取りし、対象の録音アプリがインポートしたファイル、TTS 出力、または実験的なライブ再生キャプチャ由来の PCM を受け取れるようにします。実験的な root 権限の AudioPolicy バックエンド経由での音声注入、フローティングコントロール、診断、任意のクラウド TTS プロバイダ向けの暗号化 API キーの公開、shadowhook によるネイティブインラインフックと libxposed の併用にも対応します。マイクルーティング、キャプチャ互換性、フックの可視性について制御されたオンデバイス実験が必要な開発者や研究者向けであり、本番向けアンチチートツールを目的としたものではありません。
