GlassMic 是一款面向已 root 且使用 LSPosed 的 Android 手机的开源虚拟麦克风与音频管线测试模块。项目主要用 Kotlin 与 Compose UI 构建，并辅以 Java 与 C++ 原生钩子，拦截 AudioRecord、AAudio、OpenSL ES 及相关采集路径，使目标录音应用接收来自导入文件、TTS 输出或实验性实时回放采集的 PCM。该项目还可通过实验性的 root 级 AudioPolicy 后端注入音频，提供悬浮控件、诊断信息以及用于可选云端 TTS 服务商的加密 API 密钥，并配合 shadowhook 做原生内联钩子以及 libxposed。它面向需要在设备上进行可控实验的开发者与研究人员，关注麦克风路由、采集兼容性与钩子可见性，而非生产级反作弊工具。
