GlassMic è un modulo open source di microfono virtuale e test della pipeline audio per telefoni Android con root che usano LSPosed. È realizzato principalmente in Kotlin con UI Compose, oltre a Java e C++ con hook nativi che intercettano AudioRecord, AAudio, OpenSL ES e percorsi di cattura correlati, così le app di registrazione bersaglio ricevono PCM da file importati, output TTS o cattura sperimentale della riproduzione live. Il progetto può anche iniettare audio tramite un backend AudioPolicy root sperimentale, espone controlli flottanti, diagnostica e chiavi API crittografate per provider TTS cloud opzionali, e usa shadowhook per l’hooking inline nativo insieme a libxposed. È rivolto a sviluppatori e ricercatori che necessitano di esperimenti controllati sul dispositivo su instradamento del microfono, compatibilità di cattura e visibilità degli hook, piuttosto che a strumenti anti-cheat da produzione.
