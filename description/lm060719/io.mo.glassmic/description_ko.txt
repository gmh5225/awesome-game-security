GlassMic은 root 되었고 LSPosed를 사용하는 Android 휴대폰용 오픈 소스 가상 마이크 및 오디오 파이프라인 테스트 모듈입니다. 주로 Kotlin과 Compose UI로 구축되었으며, Java와 C++ 네이티브 훅으로 AudioRecord, AAudio, OpenSL ES 및 관련 캡처 경로를 가로채 대상 녹음 앱이 가져온 파일, TTS 출력 또는 실험적 라이브 재생 캡처의 PCM을 받도록 합니다. 실험적 root AudioPolicy 백엔드를 통한 오디오 주입, 플로팅 컨트롤, 진단, 선택적 클라우드 TTS 제공업체용 암호화 API 키 노출, shadowhook을 이용한 네이티브 인라인 훅 및 libxposed 병행 사용도 지원합니다. 마이크 라우팅, 캡처 호환성, 훅 가시성에 대한 제어 가능한 온디바이스 실험이 필요한 개발자와 연구자를 대상으로 하며, 프로덕션 안티치트 도구가 아닙니다.
