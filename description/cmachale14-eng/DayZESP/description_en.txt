DayZ ESP is a Windows external cheat that draws an on-screen overlay for the DayZ survival game while it is running. It is built as a standalone C++20 executable using MinGW g++, Dear ImGui with DirectX 11 and Win32 backends, and links against standard graphics and system libraries. Game state is read through kernel-mode memory access backed by the Intel iqvw64e vulnerable driver, with supporting modules for process memory, offset definitions, entity and item discovery, name resolution, and optional dumping. The project targets researchers studying game security, reverse engineering of live clients, and how kernel-assisted external ESP tools interact with protected titles and platform mitigations such as Memory Integrity and Secure Boot.
