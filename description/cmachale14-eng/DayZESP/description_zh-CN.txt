DayZ ESP 是一款 Windows 外部作弊工具，在 DayZ 生存游戏运行时在屏幕上绘制叠加层。它以独立的 C++20 可执行文件形式构建，使用 MinGW g++、带 DirectX 11 与 Win32 后端的 Dear ImGui，并链接标准图形与系统库。游戏状态通过内核模式内存访问读取，由 Intel iqvw64e 漏洞驱动支持，并包含进程内存、偏移定义、实体与物品发现、名称解析及可选转储等辅助模块。本项目面向研究游戏安全、在线客户端逆向工程，以及内核辅助外部 ESP 工具如何与受保护游戏及 Memory Integrity、Secure Boot 等平台缓解措施交互的研究人员。
