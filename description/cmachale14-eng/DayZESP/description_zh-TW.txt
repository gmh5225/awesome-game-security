DayZ ESP 是一款 Windows 外部作弊工具，在 DayZ 生存遊戲執行時於螢幕上繪製疊加層。它以獨立的 C++20 可執行檔形式建置，使用 MinGW g++、具 DirectX 11 與 Win32 後端的 Dear ImGui，並連結標準圖形與系統函式庫。遊戲狀態透過核心模式記憶體存取讀取，由 Intel iqvw64e 漏洞驅動程式支援，並包含程序記憶體、偏移定義、實體與物品探索、名稱解析及可選傾印等輔助模組。本專案面向研究遊戲安全、線上客戶端逆向工程，以及核心輔助外部 ESP 工具如何與受保護遊戲及 Memory Integrity、Secure Boot 等平台緩解措施互動的研究人員。
