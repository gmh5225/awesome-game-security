DayZ ESP는 DayZ 서바이벌 게임이 실행 중일 때 화면에 오버레이를 그리는 Windows 외부 치트입니다. MinGW g++, DirectX 11 및 Win32 백엔드가 있는 Dear ImGui를 사용하는 독립형 C++20 실행 파일로 빌드되며, 표준 그래픽 및 시스템 라이브러리에 링크합니다. 게임 상태는 Intel iqvw64e 취약 드라이버를 기반으로 한 커널 모드 메모리 접근을 통해 읽으며, 프로세스 메모리, 오프셋 정의, 엔티티 및 아이템 탐색, 이름 해석, 선택적 덤프를 위한 지원 모듈을 포함합니다. 이 프로젝트는 게임 보안, 라이브 클라이언트 리버스 엔지니어링, Memory Integrity 및 Secure Boot 같은 플랫폼 완화 조치와 상호작용하는 커널 지원 외부 ESP 도구를 연구하는 연구자를 대상으로 합니다.
