DayZ ESP は、DayZ サバイバルゲームの実行中に画面上へオーバーレイを描画する Windows 向け外部チートです。MinGW g++、DirectX 11 と Win32 バックエンド付き Dear ImGui を用いたスタンドアロン C++20 実行ファイルとしてビルドし、標準のグラフィックスおよびシステムライブラリにリンクします。ゲーム状態は Intel iqvw64e 脆弱ドライバーに支えられたカーネルモードメモリアクセスで読み取り、プロセスメモリ、オフセット定義、エンティティとアイテムの探索、名前解決、任意のダンプなどの支援モジュールを備えます。本プロジェクトは、ゲームセキュリティ、ライブクライアントのリバースエンジニアリング、および Memory Integrity や Secure Boot などのプラットフォーム緩和策と対話するカーネル支援型外部 ESP ツールを研究する研究者を対象としています。
