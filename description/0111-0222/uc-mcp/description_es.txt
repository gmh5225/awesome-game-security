uc-mcp es un servidor Model Context Protocol de solo lectura que permite a los asistentes de IA buscar y leer el foro UnknownCheats a través de tu propia sesión de navegador con inicio de sesión. Escrito en Python, expone cinco herramientas MCP para búsqueda por palabras clave, lectura de hilos, exploración de subforos, obtención de páginas y comprobaciones del estado de la sesión; cada resultado incluye una marca temporal UTC y una etiqueta de obsolescencia para detectar fácilmente offsets y bypass desactualizados. Usa curl_cffi con suplantación TLS de Chrome para superar Cloudflare, analiza HTML de vBulletin con BeautifulSoup y lxml, y aplica límites de velocidad, protección de URL, caché SQLite y una política estrictamente de solo lectura para mantener un tráfico con aspecto humano y proteger las credenciales de la cuenta. El proyecto está dirigido a investigadores de seguridad de juegos, ingenieros de ingeniería inversa y analistas antitrampas que quieren consultar mediante Claude Code, Cursor u otros clientes MCP el conocimiento comunitario actual sobre game hacking y técnicas de bypass en lugar de depender de documentación pública desactualizada.
