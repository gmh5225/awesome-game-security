uc-mcp는 AI 어시스턴트가 본인의 로그인된 브라우저 세션을 통해 UnknownCheats 포럼을 검색하고 읽을 수 있게 해 주는 읽기 전용 Model Context Protocol(MCP) 서버입니다. Python으로 작성되었으며, 키워드 검색, 스레드 읽기, 하위 포럼 탐색, 페이지 가져오기, 세션 상태 확인을 위한 다섯 가지 MCP 도구를 제공합니다. 모든 결과에는 UTC 타임스탬프가 찍히고 오래됨(staleness)이 표시되어, 구식 offset과 bypass 정보를 쉽게 식별할 수 있습니다. curl_cffi와 Chrome TLS 위장으로 Cloudflare를 우회하고, BeautifulSoup와 lxml로 vBulletin HTML을 파싱하며, 속도 제한, URL 가드, SQLite 캐시, 엄격한 읽기 전용 정책을 적용해 트래픽을 사람처럼 유지하고 계정 자격 증명을 보호합니다. Claude Code, Cursor 등 MCP 클라이언트로 낡은 공개 문서 대신 게임 hacking 및 bypass 기법에 관한 최신 커뮤니티 지식을 조회하려는 게임 보안 연구자, 리버스 엔지니어, 안티치트 분석가를 대상으로 합니다.
