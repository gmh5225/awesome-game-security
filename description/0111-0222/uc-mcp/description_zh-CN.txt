uc-mcp 是一个只读的 Model Context Protocol（MCP）服务器，让 AI 助手通过你本人已登录的浏览器会话搜索并读取 UnknownCheats 论坛。该项目用 Python 编写，提供五项 MCP 工具：关键词搜索、主题阅读、子版面浏览、页面抓取和会话健康检查；每条结果均标注 UTC 时间戳并标记陈旧程度，便于识别过时的 offset 与 bypass 信息。它使用 curl_cffi 配合 Chrome TLS 伪装以通过 Cloudflare 防护，用 BeautifulSoup 与 lxml 解析 vBulletin HTML，并实施速率限制、URL 守卫、SQLite 缓存以及严格的只读策略，使流量更像人工访问并保护账号凭据。项目面向游戏安全研究人员、逆向工程师与反作弊分析人员，使其可通过 Claude Code、Cursor 或其他 MCP 客户端查询关于游戏 hacking 与 bypass 技术的最新社区知识，而不必依赖过时的公开文档。
