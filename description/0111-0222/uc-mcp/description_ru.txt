uc-mcp — это сервер Model Context Protocol только для чтения, который позволяет AI-ассистентам искать и читать форум UnknownCheats через вашу собственную авторизованную сессию браузера. Написанный на Python, он предоставляет пять инструментов MCP для поиска по ключевым словам, чтения тем, просмотра подфорумов, загрузки страниц и проверки состояния сессии; каждый результат помечен меткой времени UTC и индикатором устаревания, чтобы легко заметить неактуальные offset и bypass. Он использует curl_cffi с имитацией TLS Chrome для прохождения Cloudflare, разбирает HTML vBulletin с помощью BeautifulSoup и lxml, а также применяет ограничения частоты запросов, защиту URL, кэширование SQLite и строгую политику только чтения, чтобы трафик выглядел естественным и учётные данные оставались в безопасности. Проект предназначен для исследователей игровой безопасности, reverse engineers и аналитиков античит-систем, которым нужно через Claude Code, Cursor или другие MCP-клиенты запрашивать актуальные знания сообщества о game hacking и техниках bypass вместо устаревшей публичной документации.
