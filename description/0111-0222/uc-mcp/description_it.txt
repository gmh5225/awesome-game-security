uc-mcp è un server Model Context Protocol in sola lettura che consente agli assistenti IA di cercare e leggere il forum UnknownCheats tramite la tua sessione browser già autenticata. Scritto in Python, espone cinque strumenti MCP per ricerca per parole chiave, lettura thread, navigazione sottoforum, recupero pagine e controlli dello stato della sessione; ogni risultato reca un timestamp UTC ed etichetta di obsolescenza, così offset e bypass obsoleti sono facili da individuare. Usa curl_cffi con impersonazione TLS Chrome per superare Cloudflare, analizza HTML vBulletin con BeautifulSoup e lxml, e applica limiti di frequenza, guardie URL, cache SQLite e una policy rigorosamente in sola lettura per mantenere un traffico dall'aspetto umano e proteggere le credenziali dell'account. Il progetto è pensato per ricercatori di sicurezza dei giochi, reverse engineer e analisti anti-cheat che vogliono interrogare con Claude Code, Cursor o altri client MCP le conoscenze comunitarie attuali su game hacking e tecniche di bypass, invece di affidarsi a documentazione pubblica obsoleta.
