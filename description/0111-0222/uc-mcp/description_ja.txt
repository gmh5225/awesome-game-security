uc-mcp は、AI アシスタントが自分のログイン済みブラウザセッション経由で UnknownCheats フォーラムを検索・閲読できる、読み取り専用の Model Context Protocol（MCP）サーバーです。Python で実装され、キーワード検索、スレッド閲読、サブフォーラム閲覧、ページ取得、セッション健全性チェックの 5 つの MCP ツールを公開します。すべての結果には UTC タイムスタンプが付与され、陳腐化のラベルも付くため、古いオフセットや bypass 情報を見分けやすくなっています。curl_cffi による Chrome TLS 偽装で Cloudflare を通過し、BeautifulSoup と lxml で vBulletin HTML を解析し、レート制限、URL ガード、SQLite キャッシュ、厳格な読み取り専用ポリシーを適用して、人間らしいトラフィックを保ち、アカウント認証情報を保護します。Claude Code、Cursor などの MCP クライアントで、古い公開ドキュメントではなく、ゲーム hacking や bypass 手法に関する最新のコミュニティ知識を問い合わせたい、ゲームセキュリティ研究者、リバースエンジニア、アンチチート分析者向けのプロジェクトです。
