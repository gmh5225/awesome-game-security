uc-mcp 是一個唯讀的 Model Context Protocol（MCP）伺服器，讓 AI 助手透過你本人已登入的瀏覽器工作階段搜尋並讀取 UnknownCheats 論壇。此專案以 Python 編寫，提供五項 MCP 工具：關鍵字搜尋、討論串閱讀、子版面瀏覽、頁面擷取與工作階段健康檢查；每筆結果皆標注 UTC 時間戳並標示陳舊程度，便於辨識過時的 offset 與 bypass 資訊。它使用 curl_cffi 搭配 Chrome TLS 偽裝以通過 Cloudflare 防護，以 BeautifulSoup 與 lxml 解析 vBulletin HTML，並實施速率限制、URL 守衛、SQLite 快取及嚴格的唯讀策略，使流量更像人工存取並保護帳號憑證。本專案面向遊戲安全研究人員、逆向工程師與反作弊分析人員，使其可透過 Claude Code、Cursor 或其他 MCP 用戶端查詢遊戲 hacking 與 bypass 技術的最新社群知識，而不必依賴過時的公開文件。
