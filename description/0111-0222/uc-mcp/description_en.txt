uc-mcp is a read-only Model Context Protocol server that lets AI assistants search and read the UnknownCheats forum through your own logged-in browser session. Written in Python, it exposes five MCP tools for keyword search, thread reading, subforum browsing, page fetching, and session health checks, with every result stamped in UTC and labeled for staleness so outdated offsets and bypasses are easy to spot. It uses curl_cffi with Chrome TLS impersonation to pass Cloudflare, parses vBulletin HTML with BeautifulSoup and lxml, and applies rate limits, URL guards, SQLite caching, and a strict read-only policy to keep traffic human-shaped and protect account credentials. The project is aimed at game security researchers, reverse engineers, and anti-cheat analysts who want Claude Code, Cursor, or other MCP clients to query current community knowledge on game hacking and bypass techniques instead of relying on stale public documentation.
