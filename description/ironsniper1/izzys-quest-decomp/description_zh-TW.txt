本專案是對 1995 年 Windows 3.1 CD-ROM 遊戲《Izzy's Quest for Olympic Gold》的原始碼層級反編譯成果，以可攜式 C99 重寫，並封裝為可在現代 64 位元 Windows 上執行的原生用戶端。工作將原始 16 位元 StoryGame Engine 可執行檔對應為可讀 C 程式碼並附帶可追蹤的函式標籤，解碼專有資源與腳本格式，並實作重建的場景播放器、VET 腳本虛擬機、渲染器與音訊堆疊。儲存庫提供面向 Ghidra 的反編譯工作區，以及擷取工具、VET 編譯器與反編譯器、壓力與自我測試套件，以及內建 Indeo 3.2 視訊解碼器，以取代現行系統上已停用的編解碼器。面向逆向工程師、遊戲保存研究者，以及研究遺留互動式多媒體引擎與二進位到原始碼還原流程的任何人。
