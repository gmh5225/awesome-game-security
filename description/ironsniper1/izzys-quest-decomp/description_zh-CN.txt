本项目是对 1995 年 Windows 3.1 CD-ROM 游戏《Izzy's Quest for Olympic Gold》的源代码级反编译成果，以可移植的 C99 重写，并打包为可在现代 64 位 Windows 上运行的原生客户端。工作将原始 16 位 StoryGame Engine 可执行文件映射为可读 C 代码并附带可追踪的函数标签，解析专有资源与脚本格式，并实现重建的场景播放器、VET 脚本虚拟机、渲染器与音频栈。仓库提供面向 Ghidra 的反编译工作区，以及提取工具、VET 编译器与反编译器、压力与自测套件，以及内置 Indeo 3.2 视频解码器，以替代当前系统上已禁用的编解码器。面向逆向工程师、游戏保存研究者，以及研究遗留交互式多媒体引擎与二进制到源码恢复流程的任何人。
