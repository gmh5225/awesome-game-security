本プロジェクトは、1995 年発売の Windows 3.1 CD-ROM ゲーム『Izzy's Quest for Olympic Gold』のソースレベル逆コンパイル成果物であり、ポータブルな C99 として再構築し、現代の 64 ビット Windows 上で動作するネイティブクライアントとしてパッケージ化されています。当初の 16 ビット StoryGame Engine 実行ファイルを読みやすい C に写像し、追跡可能な関数ラベルを付与し、独自のアセットおよびスクリプト形式を解読し、再構築したシーンプレイヤー、VET スクリプト VM、レンダラー、オーディオスタックを実装しています。Ghidra 向けの逆コンパイルワークスペースに加え、抽出ツール、VET コンパイラおよび逆コンパイラ、ストレス／自己テストハーネス、現行システムで無効化されたコーデックに代わる内蔵 Indeo 3.2 ビデオデコーダーを同梱しています。リバースエンジニア、ゲーム保存コミュニティ、レガシー対話型マルチメディアエンジンやバイナリからソースへの復元ワークフローを研究する人々を対象としています。
