This project is a source-level decompilation of the 1995 Windows 3.1 CD-ROM game Izzy's Quest for Olympic Gold, rebuilt as portable C99 and packaged as a native client that runs on modern 64-bit Windows. The work maps the original 16-bit StoryGame Engine executable into readable C with traceable function labels, decodes proprietary asset and script formats, and implements a rebuilt scene player, VET script VM, renderer, and audio stack. It ships a Ghidra-oriented decompilation workspace plus extractors, a VET compiler and decompiler, stress and self-test harnesses, and a built-in Indeo 3.2 video decoder to replace codecs disabled on current systems. The repository targets reverse engineers, game preservationists, and anyone studying legacy interactive multimedia engines and binary-to-source recovery workflows.
