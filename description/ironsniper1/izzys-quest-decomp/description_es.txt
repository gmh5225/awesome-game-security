Este proyecto es una descompilación a nivel de código fuente del juego en CD-ROM para Windows 3.1 de 1995 Izzy's Quest for Olympic Gold, reconstruido como C99 portable y empaquetado como cliente nativo que se ejecuta en Windows de 64 bits moderno. El trabajo mapea el ejecutable de 16 bits de StoryGame Engine en C legible con etiquetas de funciones rastreables, decodifica formatos propietarios de recursos y scripts, e implementa un reproductor de escenas reconstruido, una VM de scripts VET, un renderizador y una pila de audio. Incluye un espacio de trabajo de descompilación orientado a Ghidra, extractores, un compilador y descompilador VET, harnesses de estrés y autoprueba, y un decodificador de vídeo Indeo 3.2 integrado para sustituir códecs deshabilitados en los sistemas actuales. El repositorio está dirigido a ingenieros inversos, preservacionistas de videojuegos y a quien estudie motores multimedia interactivos heredados y flujos de recuperación de binario a fuente.
