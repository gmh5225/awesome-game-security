This project is a static and dynamic security audit of the PokeAlliance Pokémon MMO client, documenting how its anti-bot and anti-analysis protections actually work. The main deliverable is a detailed reverse-engineering write-up of PokeAlliance_dx.exe, covering server-triggered process, module, and window enumeration, hardware fingerprinting, Lua-configured startup blacklists, and server-driven bot checks rather than traditional client-side anti-debug or hook detection. Supporting tools include a Frida JavaScript hook script and a Python tracer that spawn or attach to the client to log opcode dispatch, inventory reporters, fingerprint collection, and self-termination events during live play. The stack centers on JavaScript and Python with Frida for runtime instrumentation, alongside MSVC C++ binary analysis techniques typical of PE reverse engineering. It is aimed at game security researchers, reverse engineers, and anti-cheat analysts studying server-side telemetry and bot-detection design in OTCv8-based game clients.
