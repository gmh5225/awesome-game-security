本项目是对 PokeAlliance 宝可梦 MMO 客户端的静态与动态安全审计，记录了其反机器人与反分析保护机制的实际工作原理。主要成果是一份关于 PokeAlliance_dx.exe 的详细逆向分析文档，涵盖由服务器触发的进程、模块与窗口枚举，硬件指纹采集，Lua 配置的启动黑名单，以及由服务器驱动的机器人检测机制，而非传统的客户端反调试或 Hook 检测。配套工具包括 Frida JavaScript Hook 脚本和 Python 追踪器，可在运行时启动或附加到客户端，记录 opcode 分发、背包上报、指纹采集及自终止事件。技术栈以 JavaScript 和 Python 为主，配合 Frida 进行运行时插桩，并采用 PE 逆向工程中常见的 MSVC C++ 二进制分析技术。面向游戏安全研究人员、逆向工程师及反作弊分析师，用于研究基于 OTCv8 的游戏客户端中服务器端遥测与机器人检测设计。
