이 프로젝트는 PokeAlliance 포켓몬 MMO 클라이언트에 대한 정적·동적 보안 감사로, 봇 방지 및 분석 방지 보호 기능이 실제로 어떻게 작동하는지 문서화합니다. 주요 산출물은 PokeAlliance_dx.exe에 대한 상세한 리버스 엔지니어링 분석 보고서로, 서버가 트리거하는 프로세스·모듈·창 열거, 하드웨어 핑거프린팅, Lua로 구성된 시작 블랙리스트, 기존의 클라이언트 측 안티디버그나 후크 탐지가 아닌 서버 주도 봇 검사를 다룹니다. 지원 도구로 Frida JavaScript 후크 스크립트와 Python 트레이서가 포함되어, 클라이언트를 실행하거나 연결하여 라이브 플레이 중 opcode 디스패치, 인벤토리 리포터, 핑거프린트 수집, 자체 종료 이벤트를 기록합니다. 기술 스택은 JavaScript와 Python을 중심으로 Frida를 이용한 런타임 계측과 PE 리버스 엔지니어링에서 일반적인 MSVC C++ 바이너리 분석 기법을 함께 사용합니다. OTCv8 기반 게임 클라이언트의 서버 측 원격 측정 및 봇 탐지 설계를 연구하는 게임 보안 연구자, 리버스 엔지니어, 안티치트 분석가를 대상으로 합니다.
