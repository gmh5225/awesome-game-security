本專案對 PokeAlliance 寶可夢 MMO 用戶端進行了靜態與動態安全稽核，記錄其反機器人與反分析保護機制的實際運作方式。主要成果是一份針對 PokeAlliance_dx.exe 的詳細逆向工程分析文件，涵蓋伺服器觸發的程序、模組與視窗列舉，硬體指紋採集，Lua 設定的啟動黑名單，以及由伺服器驅動的機器人檢測，而非傳統的用戶端反除錯或 Hook 偵測。配套工具包括 Frida JavaScript 掛鉤腳本和 Python 追蹤器，可在執行時啟動或附加到用戶端，記錄操作碼分派、背包回報、指紋採集及自我終止等事件。技術棧以 JavaScript 和 Python 為主，配合 Frida 進行執行時插樁，並採用 MSVC C++ 二進位分析及 PE 逆向工程常用方法。面向遊戲安全研究人員、逆向工程師及反作弊分析師，用於研究基於 OTCv8 的遊戲用戶端中的伺服器端遙測與機器人偵測設計。
