本プロジェクトは PokeAlliance ポケモン MMO クライアントの静的・動的セキュリティ監査であり、反ボットおよび反解析保護が実際にどのように機能するかを文書化しています。主な成果物は PokeAlliance_dx.exe の詳細なリバースエンジニアリング解説で、サーバー起点のプロセス・モジュール・ウィンドウ列挙、ハードウェアフィンガープリント、Lua 設定の起動ブラックリスト、従来のクライアント側アンチデバッグやフック検出ではなくサーバー主導のボットチェックを扱います。補助ツールとして Frida JavaScript フックスクリプトと Python トレーサーがあり、クライアントを起動またはアタッチして、ライブプレイ中のオペコードディスパッチ、インベントリレポーター、フィンガープリント収集、自己終了イベントを記録します。技術スタックは JavaScript と Python を中心に Frida によるランタイム計装を用い、MSVC C++ によるバイナリ解析や PE リバースエンジニアリングの一般的な手法も併用します。OTCv8 ベースのゲームクライアントにおけるサーバー側テレメトリとボット検出設計を研究する、ゲームセキュリティ研究者、リバースエンジニア、反チート分析者向けです。
