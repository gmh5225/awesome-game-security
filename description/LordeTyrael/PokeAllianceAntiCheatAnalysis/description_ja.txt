本プロジェクトは PokeAlliance ポケモン MMO クライアントに対する静的・動的セキュリティ監査であり、ボット対策および解析対策の保護機構が実際にどのように機能するかを文書化しています。主な成果物は PokeAlliance_dx.exe の詳細なリバースエンジニアリング解説で、サーバー起点のプロセス・モジュール・ウィンドウ列挙、ハードウェアフィンガープリント、Lua 設定の起動ブラックリスト、従来のクライアント側アンチデバッグやフック検出ではなくサーバー駆動型のボットチェックを網羅しています。補助ツールとして Frida JavaScript フックスクリプトと Python トレーサーを提供し、クライアントの起動またはアタッチにより、ライブプレイ中の opcode ディスパッチ、インベントリレポーター、フィンガープリント収集、自己終了イベントをログ記録します。スタックは JavaScript と Python を中心とし、Frida によるランタイム計装と、PE リバースエンジニアリングで一般的な MSVC C++ バイナリ解析手法を併用しています。OTCv8 ベースのゲームクライアントにおけるサーバー側テレメトリとボット検出設計を研究する、ゲームセキュリティ研究者、リバースエンジニア、アンチチート分析者を対象としています。
