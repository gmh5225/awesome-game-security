QorTroller 是一套以硬體為根基的實體輸入信任與手把證明技術堆疊，用於驗證遊戲手把輸入來自真實人類玩家，而非腳本、巨集或偽造裝置。其核心是 VAPI 協定，搭配 DualShock/手把橋接、在場挑戰、生物特徵融合，以及向工作階段回執與對戰計分卡提供訊號的具身在場證明（Proof of Embodied Presence，PoEP）。程式碼庫融合了 Python 代理與橋接服務、Solidity 智慧合約、用於重播與人類驗證證明的 Circom/Groth16 零知識電路，以及 Rust w3bstream 元件與手把韌體。主要應用場景包括遊戲安全、反作弊研究，以及手把身分與真人玩家在場的鏈上證明。
