QorTime AI is an advisory layer that uses Meta models to explain and stress-test deterministic verdicts on signed video-game match receipts for competitive integrity and anti-cheat workflows. Implemented mainly in Python with browser verification panels in JavaScript, it integrates Muse Spark for guarded plain-English rulings and independent score cross-checks, Muse Wonder for red-team receipt tampering against the unmodified verifier, and SAM 3.1 for Evidence Lens scorebug tracking and Challenge Echo pause-menu input checks. Additional modules cover Show Your Hands input-to-pixel alignment, Ed25519-signed advisory sidecars bound to receipt hashes, and lower-only rules so AI signals can reduce VERIFIED to PARTIAL but never override or upgrade the referee. It targets developers and researchers working on verifiable esports outcomes, receipt-based anti-cheat, and adversarial testing of game-security verifiers without letting generative AI set the final match status.
