ABBYS Anti-Cheat은 관리자가 웹 대시보드에서 단기 PIN을 발급하고, 플레이어가 Android 클라이언트에 입력하면 기기 스캔 결과가 검토를 위해 전송되는 동의 기반 모바일 무결성 워크플로입니다. Kotlin과 Jetpack Compose Android 앱과 Render로 배포 가능한 Node.js 보고 서버를 함께 사용하며, 세션 토큰으로 PIN 추측만으로는 보고 데이터가 노출되지 않도록 합니다. 네이티브 C++ 검사는 root 및 Magisk 바이너리, 의심스러운 마운트 항목, 프로세스 메모리 맵의 Frida 또는 LSPosed 주입, 연결된 디버거를 찾습니다. Kotlin 스캐너는 설치된 패키지, 저장 경로, SAF로 접근 가능한 폴더, Minecraft 관련 치트 지표를 검사합니다. 발견 사항은 HIGH, WARN, INFO로 표시되어 관리자가 강한 신호와 이름만 일치하거나 사이드로드 앱·ADB 같은 일반적인 양성 조건을 구분할 수 있습니다. 커널 수준 강제가 아닌 가벼운 지표 기반 모바일 안티치트 스크리닝 도구가 필요한 게임 운영자와 커뮤니티 관리자를 대상으로 합니다.
