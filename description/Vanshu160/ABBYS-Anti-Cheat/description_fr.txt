ABBYS Anti-Cheat est un flux d’intégrité mobile basé sur le consentement : un administrateur émet un code PIN à courte durée depuis un tableau de bord web, le joueur le saisit dans un client Android, et les résultats du scan de l’appareil sont renvoyés pour examen. La pile associe une application Android Kotlin et Jetpack Compose à un serveur de rapports Node.js déployable via Render, avec des jetons de session pour que les données de rapport ne soient pas exposées par la seule devinette du PIN. Des contrôles C++ natifs recherchent les binaires root et Magisk, les entrées de montage suspectes, l’injection Frida ou LSPosed dans les cartes mémoire des processus et les débogueurs attachés, tandis que les scanners Kotlin inspectent les paquets installés, les chemins de stockage, les dossiers accessibles via SAF et les indicateurs de triche orientés Minecraft. Les constats sont étiquetés HIGH, WARN ou INFO afin que les administrateurs traitent différemment les signaux forts des simples correspondances de nom ou des conditions bénignes courantes comme les applications sideloadées ou ADB. Il s’adresse aux opérateurs de jeux et aux modérateurs de communauté qui ont besoin d’un outil léger de dépistage anti-triche mobile fondé sur des indicateurs plutôt qu’une application au niveau noyau.
