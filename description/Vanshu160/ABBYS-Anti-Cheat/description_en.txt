ABBYS Anti-Cheat is a consent-based mobile integrity workflow in which an administrator issues a short-lived PIN from a web dashboard, the player enters it in an Android client, and the device scan results are sent back for review. The stack pairs a Kotlin and Jetpack Compose Android app with a Node.js reporting server that can be deployed via Render, using session tokens so report data is not exposed by PIN guessing alone. Native C++ checks look for root and Magisk binaries, suspicious mount entries, Frida or LSPosed injection in process memory maps, and attached debuggers, while Kotlin scanners inspect installed packages, storage paths, SAF-accessible folders, and Minecraft-oriented cheat indicators. Findings are labeled HIGH, WARN, or INFO so admins can treat strong signals differently from name-only matches or common benign conditions such as sideloaded apps or ADB. It targets game operators and community moderators who need a lightweight, indicator-based mobile anti-cheat screening tool rather than kernel-level enforcement.
