ABBYS Anti-Cheat は、管理者が Web ダッシュボードから短期 PIN を発行し、プレイヤーが Android クライアントで入力すると、デバイスのスキャン結果がレビュー用に送り返される、同意ベースのモバイル整合性ワークフローです。Kotlin と Jetpack Compose の Android アプリと、Render 経由でデプロイ可能な Node.js レポートサーバーを組み合わせ、セッショントークンにより PIN の推測だけではレポートデータが露出しないようにしています。ネイティブ C++ チェックは root や Magisk バイナリ、不審なマウントエントリ、プロセスメモリマップ内の Frida や LSPosed 注入、接続されたデバッガーを検出します。Kotlin スキャナーはインストール済みパッケージ、ストレージパス、SAF でアクセス可能なフォルダ、Minecraft 向けチートの指標を調べます。検出結果は HIGH、WARN、INFO でラベル付けされ、管理者は強いシグナルと、名前一致のみやサイドロードアプリや ADB など一般的な良性条件を区別できます。カーネルレベルの強制ではなく、軽量な指標ベースのモバイルアンチチートスクリーニングツールを必要とするゲーム運営者やコミュニティモデレーター向けです。
