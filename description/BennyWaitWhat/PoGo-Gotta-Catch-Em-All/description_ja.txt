本リポジトリは、root 済み Android 向けの Pokémon GO ツールキットで、常時稼働する端末自動化とインベントリ抽出・タグ付け・整理ワークフローを組み合わせています。AutoCatcher コンポーネントは Termux 上で動作し、Frida gadget をアタッチしてライブの Unity IL2CPP クライアントを呼び出すことで、サーバー要求を偽造せずに野生・ルアー・お香遭遇、ストップスピン、イベントマップのタップ対象、リサーチ報酬を駆動します。コードの大半は Python と JavaScript で、シェルデプロイスクリプト、adb ベースのリモート制御、端末上トグル用の小型 Android アプリが支えています。pogo_extract ツリーは同じ計装レイヤ経由でバッグと game-master 状態を読み取り、複数バージョンの整理エンジンと照合監査を実行し、バイト単位で厳密な検証ゲートで保持ポリシーを適用します。モバイルクライアント計装、IL2CPP イントロスペクション、root 済みハードウェア上のライブゲームアカウント運用の制約を研究するリバースエンジニアやゲームセキュリティ研究者に有用です。
