本仓库是一套面向已 root 的 Android 的 Pokémon GO 工具集，将持续运行的手机自动化与背包数据提取、标记及清理工作流相结合。AutoCatcher 组件在 Termux 中运行，通过挂载 Frida gadget 并调用实时 Unity IL2CPP 客户端，驱动野外、诱饵与熏香遭遇、补给站旋转、活动地图可点击项及研究奖励，而非伪造服务端请求。大部分代码为 Python 与 JavaScript，辅以 shell 部署脚本、基于 adb 的远程控制，以及用于设备端开关的小型 Android 应用。pogo_extract 树通过同一插桩层读取背包与 game-master 状态，运行多版本清理引擎与对账审计，并以字节级精确校验门控执行保留策略。适用于研究移动客户端插桩、IL2CPP 内省以及在已 root 硬件上运营真实游戏账号所涉约束的逆向工程师与游戏安全研究人员。
