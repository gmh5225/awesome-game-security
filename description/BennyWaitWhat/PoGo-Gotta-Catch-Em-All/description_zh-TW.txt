本儲存庫是一套面向已 root 的 Android 的 Pokémon GO 工具集，將持續運作的手機自動化與背包資料提取、標記及清理工作流程相結合。AutoCatcher 元件在 Termux 中執行，透過掛載 Frida gadget 並呼叫即時 Unity IL2CPP 用戶端，驅動野外、誘餌與薰香遭遇、補給站旋轉、活動地圖可點擊項目及研究獎勵，而非偽造伺服器請求。大部分程式碼為 Python 與 JavaScript，並輔以 shell 部署腳本、基於 adb 的遠端控制，以及用於裝置端開關的小型 Android 應用程式。pogo_extract 樹透過同一插樁層讀取背包與 game-master 狀態，執行多版本清理引擎與對帳稽核，並以位元組級精確驗證閘門執行保留策略。適合研究行動用戶端插樁、IL2CPP 內省以及在已 root 硬體上營運真實遊戲帳號所涉限制的逆向工程師與遊戲安全研究人員。
