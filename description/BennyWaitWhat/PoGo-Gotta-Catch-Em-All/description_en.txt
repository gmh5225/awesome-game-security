This repository is a rooted Android toolkit for Pokémon GO that pairs always-on phone automation with inventory extraction, tagging, and culling workflows. The AutoCatcher component runs in Termux and drives wild, lure, and incense encounters, stop spins, event map tappables, and research rewards by attaching a Frida gadget and invoking the live Unity IL2CPP client instead of forging server requests. Most of the code is Python and JavaScript, supported by shell deploy scripts, adb-based remote control, and a small Android app for on-device toggles. The pogo_extract tree reads bag and game-master state through the same instrumentation layer, runs multi-version cull engines and reconciliation audits, and enforces keep policies with byte-exact verification gates. It is useful for reverse engineers and game-security researchers studying mobile client instrumentation, IL2CPP introspection, and operational constraints around live game accounts on rooted hardware.
