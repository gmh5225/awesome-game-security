이 저장소는 root된 Android용 Pokémon GO 툴킷으로, 상시 가동 폰 자동화와 인벤토리 추출, 태깅, 정리 워크플로를 결합합니다. AutoCatcher 구성 요소는 Termux에서 실행되며 Frida gadget을 부착하고 라이브 Unity IL2CPP 클라이언트를 호출해 서버 요청을 위조하지 않고 야생·루어·향기 만남, 스톱 스핀, 이벤트 맵 탭 대상, 리서치 보상을 구동합니다. 대부분의 코드는 Python과 JavaScript이며, 셸 배포 스크립트, adb 기반 원격 제어, 기기 내 토글용 소형 Android 앱이 뒷받침합니다. pogo_extract 트리는 동일한 계측 계층으로 가방과 game-master 상태를 읽고, 다중 버전 정리 엔진과 대조 감사를 실행하며, 바이트 단위 정확 검증 게이트로 보존 정책을 적용합니다. 모바일 클라이언트 계측, IL2CPP 인트로스펙션, root된 하드웨어에서 라이브 게임 계정 운영 제약을 연구하는 리버스 엔지니어와 게임 보안 연구자에게 유용합니다.
