VolkDMA 是一个用于基于硬件的直接内存访问的 C++ 库，可通过 FPGA DMA 实现远程内存分析、操作、逆向工程和调试。它封装了 LeechCore 和 MemProcFS，提供 RAII 会话管理、进程与模块枚举、类型化读写、指针链解析、分散 I/O、特征码扫描、虚拟地址到物理地址转换，以及通过修补 VMM 二进制文件实现的 CR3 修复。基于内核的输入状态 API 可在无需本地钩子的情况下暴露光标位置以及键盘或鼠标按键状态。该项目以 Windows x64 静态库形式发布，附带捆绑的运行时 DLL，面向需要带外物理内存访问以进行游戏安全、反作弊分析和底层调试工作流程的研究人员和开发者。
