VolkDMA — это C++ библиотека для аппаратного прямого доступа к памяти, обеспечивающая удалённый анализ, манипуляцию, реверс-инжиниринг и отладку памяти через FPGA DMA. Она оборачивает LeechCore и MemProcFS с управлением сессиями RAII, перечислением процессов и модулей, типизированным чтением и записью, разрешением цепочек указателей, scatter I/O, сканированием сигнатур, преобразованием виртуальных адресов в физические и исправлением CR3 через пропатченные бинарники VMM. API состояния ввода, полученное из ядра, предоставляет позицию курсора и состояние кнопок клавиатуры или мыши без локальных хуков. Проект поставляется как статическая библиотека Windows x64 с включёнными DLL времени выполнения и ориентирован на исследователей и разработчиков, которым нужен out-of-band физический доступ к памяти для безопасности игр, анализа античитов и низкоуровневых отладочных сценариев.
