VolkDMA는 하드웨어 기반 직접 메모리 액세스를 위한 C++ 라이브러리로, FPGA DMA를 통한 원격 메모리 분석, 조작, 리버스 엔지니어링 및 디버깅을 지원합니다. LeechCore와 MemProcFS를 RAII 세션 관리, 프로세스 및 모듈 열거, 형식화된 읽기/쓰기, 포인터 체인 해석, scatter I/O, 시그니처 스캔, 가상-물리 주소 변환, 패치된 VMM 바이너리를 통한 CR3 수정으로 래핑합니다. 커널 기반 입력 상태 API는 로컬 후크 없이 커서 위치와 키보드 또는 마우스 버튼 상태를 노출합니다. 이 프로젝트는 Windows x64 정적 라이브러리로 제공되며 번들된 런타임 DLL을 포함하고, 게임 보안, 안티치트 분석 및 저수준 디버깅 워크플로를 위한 아웃오브밴드 물리 메모리 액세스가 필요한 연구자와 개발자를 대상으로 합니다.
