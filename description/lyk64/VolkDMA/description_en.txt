VolkDMA is a C++ library for hardware-based direct memory access, enabling remote memory analysis, manipulation, reverse engineering, and debugging over FPGA DMA. It wraps LeechCore and MemProcFS with RAII session management, process and module enumeration, typed reads and writes, pointer-chain resolution, scatter I/O, signature scanning, virtual-to-physical address translation, and CR3 fixing via patched VMM binaries. A kernel-derived input state API exposes cursor position and keyboard or mouse button state without local hooks. The project ships as a Windows x64 static library with bundled runtime DLLs and targets researchers and developers who need out-of-band physical memory access for game security, anti-cheat analysis, and low-level debugging workflows.
