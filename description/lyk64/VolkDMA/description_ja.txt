VolkDMA は、ハードウェアベースのダイレクトメモリアクセス向けの C++ ライブラリで、FPGA DMA 経由のリモートメモリ分析、操作、リバースエンジニアリング、デバッグを可能にします。LeechCore と MemProcFS を RAII セッション管理、プロセスおよびモジュール列挙、型付き読み書き、ポインタチェーン解決、scatter I/O、シグネチャスキャン、仮想アドレスから物理アドレスへの変換、パッチ適用済み VMM バイナリによる CR3 修正でラップします。カーネル由来の入力状態 API は、ローカルフックなしでカーソル位置とキーボードまたはマウスボタンの状態を公開します。本プロジェクトは Windows x64 静的ライブラリとして提供され、同梱のランタイム DLL を備え、ゲームセキュリティ、アンチチート分析、低レベルデバッグワークフロー向けのアウトオブバンド物理メモリアクセスを必要とする研究者および開発者を対象としています。
