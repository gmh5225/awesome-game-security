LLGL (Low Level Graphics Library) is a thin C++11 abstraction layer that exposes a unified rendering API over Direct3D 11/12, Vulkan, OpenGL, OpenGLES 3, WebGL, and Metal on desktop, mobile, UWP, and WebAssembly targets. The codebase is organized as a backend-agnostic frontend with pluggable renderer modules loaded at runtime, optional OpenXR integration, and generated C99, C#, and Go bindings on top of the core C++ interface. CMake drives the build, and the repository ships extensive C++ examples covering pipelines, resource binding, compute, tessellation, shadow mapping, and related techniques. It is useful for game developers and security researchers who need a portable reference for how applications structure GPU work, swap chains, and shader pipelines when studying game rendering internals, graphics hooks, or presentation-path behavior.
