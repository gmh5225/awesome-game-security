LLGL（Low Level Graphics Library）は、デスクトップ、モバイル、UWP、WebAssembly 向けに Direct3D 11/12、Vulkan、OpenGL、OpenGLES 3、WebGL、Metal の上に統一されたレンダリング API を公開する、薄い C++11 抽象レイヤーです。コードベースはバックエンド非依存のフロントエンドとして構成され、実行時に読み込むプラグイン可能なレンダラーモジュール、任意の OpenXR 統合、コア C++ インターフェース上に生成される C99、C#、Go バインディングを備えています。ビルドは CMake が担い、リポジトリにはパイプライン、リソースバインディング、コンピュート、テッセレーション、シャドウマッピングなど関連技術を扱う豊富な C++ サンプルが同梱されています。ゲームレンダリングの内部、グラフィックスフック、プレゼンテーションパスの挙動を調査する際に、アプリケーションが GPU 処理、スワップチェーン、シェーダーパイプラインをどう構成するかを学ぶ移植可能な参照として、ゲーム開発者やセキュリティ研究者に有用です。
