LLGL（Low Level Graphics Library）是一個輕量的 C++11 抽象層，在桌面、行動、UWP 與 WebAssembly 平台上，為 Direct3D 11/12、Vulkan、OpenGL、OpenGLES 3、WebGL 和 Metal 提供統一的渲染 API。程式碼庫採用與後端無關的前端架構，可在執行時載入可插拔的渲染器模組，可選整合 OpenXR，並在核心 C++ 介面之上產生 C99、C# 和 Go 繫結。建置由 CMake 驅動，儲存庫附帶大量 C++ 範例，涵蓋管線、資源繫結、計算、曲面細分、陰影貼圖及相關技術。對遊戲開發者與安全研究人員而言，在研究遊戲渲染內部機制、圖形鉤子或呈現路徑行為時，它是了解應用程式如何組織 GPU 工作、交換鏈與著色器管線的可攜式參考。
