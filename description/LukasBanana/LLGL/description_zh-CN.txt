LLGL（Low Level Graphics Library）是一个轻量的 C++11 抽象层，在桌面、移动、UWP 和 WebAssembly 平台上，为 Direct3D 11/12、Vulkan、OpenGL、OpenGLES 3、WebGL 和 Metal 提供统一的渲染 API。代码库采用与后端无关的前端架构，可在运行时加载可插拔的渲染器模块，可选集成 OpenXR，并在核心 C++ 接口之上生成 C99、C# 和 Go 绑定。构建由 CMake 驱动，仓库附带大量 C++ 示例，涵盖管线、资源绑定、计算、曲面细分、阴影贴图及相关技术。对游戏开发者与安全研究人员而言，在研究游戏渲染内部机制、图形钩子或呈现路径行为时，它是了解应用如何组织 GPU 工作、交换链与着色器管线的可移植参考。
