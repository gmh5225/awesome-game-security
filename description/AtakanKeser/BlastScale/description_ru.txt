BlastScale — это ориентированная на продакшен серверная платформа, построенная вокруг небольшой казуальной мобильной головоломки и предназначенная для изучения поведения игровых систем в масштабе. В её основе — модульный монолит на Java Spring Boot с административной панелью на React и TypeScript и клиентом на Unity C#, с использованием MySQL, Redis, MongoDB и Elasticsearch. Сервер полностью авторитетен: он выдаёт сиды уровней, проигрывает отправленные ходы через детерминированный движок игрового поля и запускает конвейер античит-проверки по принципу цепочки ответственности, который проверяет сессии, тайминг, границы счёта и последовательности ходов перед выдачей наград. Также реализованы экономические обновления exactly-once с ключами идемпотентности и журналом только для добавления записей, а также таблицы лидеров Redis, live-события, удалённая конфигурация, A/B-эксперименты и наблюдаемость через Prometheus и Grafana. Проект предназначен для инженеров, изучающих безопасность игр, проектирование античит-систем и серверные паттерны валидации для мобильных игр.
