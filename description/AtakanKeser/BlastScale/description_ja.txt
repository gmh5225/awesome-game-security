BlastScale は、小規模なカジュアルモバイルパズルゲームを中心に構築された本番向けのバックエンドプラットフォームで、大規模環境におけるゲームプレイシステムの挙動を検証することを目的としています。コアは Java Spring Boot によるモジュラー・モノリスで、React と TypeScript の管理パネル、Unity C# クライアントを備え、MySQL、Redis、MongoDB、Elasticsearch をバックエンドに採用しています。サーバーは完全権威型であり、レベルシードを発行し、提出された手を決定論的なボードエンジンで再生し、報酬付与前にチェーン・オブ・レスポンシビリティ方式の反チートパイプラインでセッション、タイミング、スコア上限、手の順序を検証します。また、べき等キーと追記専用レジャーによる exactly-once の経済更新、Redis リーダーボード、ライブイベント、リモート設定、A/B 実験、Prometheus と Grafana による可観測性も実装しています。本プロジェクトは、ゲームセキュリティ、反チート設計、モバイルゲーム向けサーバー側検証パターンを学ぶエンジニアを対象としています。
