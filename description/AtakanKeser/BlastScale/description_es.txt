BlastScale es una plataforma backend orientada a producción, construida en torno a un pequeño juego de puzzles móvil casual, utilizada para explorar cómo se comportan los sistemas de juego a gran escala. Su núcleo es un monolito modular en Java Spring Boot con un panel de administración en React y TypeScript y un cliente Unity en C#, respaldado por MySQL, Redis, MongoDB y Elasticsearch. El servidor es totalmente autoritativo: emite semillas de nivel, reproduce los movimientos enviados mediante un motor de tablero determinista y ejecuta una canalización anti-trampas de cadena de responsabilidad que valida sesiones, tiempos, límites de puntuación y secuencias de movimientos antes de otorgar recompensas. También implementa actualizaciones económicas exactly-once con claves de idempotencia y un libro mayor de solo anexión, además de clasificaciones Redis, eventos en vivo, configuración remota, experimentos A/B y observabilidad con Prometheus y Grafana. El proyecto está dirigido a ingenieros que estudian la seguridad de juegos, el diseño anti-trampa y los patrones de validación del lado del servidor para juegos móviles.
