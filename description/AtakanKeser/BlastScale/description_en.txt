BlastScale is a production-oriented backend platform built around a small casual mobile puzzle game, used to explore how gameplay systems behave at scale. Its core is a Java Spring Boot modular monolith with a React and TypeScript admin panel and a Unity C# client, backed by MySQL, Redis, MongoDB, and Elasticsearch. The server is fully authoritative: it issues level seeds, replays submitted moves through a deterministic board engine, and runs a chain-of-responsibility anti-cheat pipeline that validates sessions, timing, score bounds, and move sequences before awarding rewards. It also implements exactly-once economy updates with idempotency keys and an append-only ledger, plus Redis leaderboards, live events, remote configuration, A/B experiments, and Prometheus and Grafana observability. The project is aimed at engineers studying game security, anti-cheat design, and server-side validation patterns for mobile games.
