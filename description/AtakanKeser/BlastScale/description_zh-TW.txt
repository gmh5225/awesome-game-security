BlastScale 是一個面向生產的後端平台，圍繞一款小型休閒行動益智遊戲建構，用於探索遊戲玩法系統在大規模場景下的行為表現。其核心是以 Java Spring Boot 為基礎的模組化單體架構，配有 React 和 TypeScript 管理面板以及 Unity C# 客戶端，後端採用 MySQL、Redis、MongoDB 和 Elasticsearch。伺服器採用完全權威模式：它下發關卡種子，透過確定性棋盤引擎重播玩家提交的移動，並在發放獎勵前執行責任鏈式反作弊管線，驗證工作階段、時間、分數邊界和移動序列。它還實現了基於冪等鍵和僅追加帳本的精確一次經濟更新，以及 Redis 排行榜、即時活動、遠端配置、A/B 實驗，以及 Prometheus 和 Grafana 可觀測性。該專案面向研究遊戲安全、反作弊設計和行動遊戲伺服器端驗證模式的工程師。
