BlastScale 是一个面向生产的后端平台，围绕一款小型休闲移动益智游戏构建，用于探索游戏玩法系统在大规模场景下的行为表现。其核心是基于 Java Spring Boot 的模块化单体架构，配有 React 和 TypeScript 管理面板以及 Unity C# 客户端，后端采用 MySQL、Redis、MongoDB 和 Elasticsearch。服务器采用完全权威模式：它下发关卡种子，通过确定性棋盘引擎重放玩家提交的移动，并在发放奖励前运行责任链式反作弊流水线，验证会话、时间、分数边界和移动序列。它还实现了基于幂等键和只追加账本的精确一次经济更新，以及 Redis 排行榜、实时活动、远程配置、A/B 实验，以及 Prometheus 和 Grafana 可观测性。该项目面向研究游戏安全、反作弊设计和移动端游戏服务端验证模式的工程师。
