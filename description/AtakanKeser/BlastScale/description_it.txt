BlastScale è una piattaforma backend orientata alla produzione, costruita attorno a un piccolo gioco puzzle mobile casual, utilizzata per esplorare il comportamento dei sistemi di gameplay su larga scala. Il nucleo è un monolito modulare Java Spring Boot con un pannello di amministrazione React e TypeScript e un client Unity C#, supportato da MySQL, Redis, MongoDB ed Elasticsearch. Il server è completamente autorevole: emette seed di livello, riproduce le mosse inviate tramite un motore di board deterministico ed esegue una pipeline anti-cheat a catena di responsabilità che valida sessioni, tempi, limiti di punteggio e sequenze di mosse prima di assegnare ricompense. Implementa inoltre aggiornamenti economici exactly-once con chiavi di idempotenza e un registro append-only, oltre a classifiche Redis, eventi live, configurazione remota, esperimenti A/B e osservabilità con Prometheus e Grafana. Il progetto è rivolto agli ingegneri che studiano la sicurezza dei giochi, la progettazione anti-cheat e i modelli di validazione lato server per giochi mobile.
