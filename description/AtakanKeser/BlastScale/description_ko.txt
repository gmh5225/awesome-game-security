BlastScale는 소규모 캐주얼 모바일 퍼즐 게임을 중심으로 구축된 프로덕션 지향 백엔드 플랫폼으로, 대규모 환경에서 게임플레이 시스템이 어떻게 동작하는지 탐구하는 데 사용됩니다. 핵심은 Java Spring Boot 기반 모듈형 모놀리스로, React 및 TypeScript 관리 패널과 Unity C# 클라이언트를 갖추고 MySQL, Redis, MongoDB, Elasticsearch를 백엔드로 사용합니다. 서버는 완전한 권한형(authoritative) 구조로, 레벨 시드를 발급하고 제출된 이동을 결정론적 보드 엔진으로 재생한 뒤, 보상 지급 전 책임 연쇄(chain-of-responsibility) 방식의 안티치트 파이프라인으로 세션, 타이밍, 점수 범위, 이동 순서를 검증합니다. 또한 멱등성 키와 추가 전용 원장을 통한 정확히 한 번(exactly-once) 경제 업데이트, Redis 리더보드, 라이브 이벤트, 원격 구성, A/B 실험, Prometheus 및 Grafana 관측성도 구현합니다. 이 프로젝트는 게임 보안, 안티치트 설계, 모바일 게임용 서버 측 검증 패턴을 공부하는 엔지니어를 대상으로 합니다.
