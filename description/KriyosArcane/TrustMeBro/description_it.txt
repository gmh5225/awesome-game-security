TrustMeBro è un toolkit per la manipolazione delle firme Authenticode destinato alle operazioni red team e alla ricerca sulla sicurezza di Windows. Offre implementazioni in Python e C++ per rubare e clonare firme PE, incorporare payload nei dati dei certificati PKCS#7 e dirottare i provider Subject Interface Package su 19 tipi di file. Le tecniche principali includono il bypass di WinVerifyTrust FinalPolicy, l'evasione di Smart App Control su Windows 11, impianti sulla superficie di esecuzione SIP per il movimento laterale e persistenza attivata dall'analista tramite handler CryptDllFormatObject. Il repository include regole di rilevamento YARA e Sigma, strumenti di estrazione payload SigStash e orchestrazione remota del registro tramite Impacket. È destinato a test offensivi autorizzati, ricerca sul controllo della fiducia e alla comprensione di come gli avversari aggirano l'applicazione della firma del codice Windows.
