TrustMeBro is an Authenticode signature manipulation toolkit for red team operations and Windows security research. It provides both Python and C++ implementations for stealing and cloning PE signatures, embedding payloads in PKCS#7 certificate data, and hijacking Subject Interface Package providers across 19 file types. Key techniques include WinVerifyTrust FinalPolicy bypass, Smart App Control evasion on Windows 11, SIP execution surface implants for lateral movement, and analyst-triggered persistence via CryptDllFormatObject handlers. The repository ships YARA and Sigma detection rules alongside SigStash payload extraction tooling and remote registry orchestration via Impacket. It is intended for authorized offensive security testing, trust-control research, and understanding how adversaries subvert Windows code-signing enforcement.
