TrustMeBro 是一款用於紅隊行動與 Windows 安全研究的 Authenticode 簽名操縱工具包。它提供 Python 與 C++ 兩種實作，可用於竊取與複製 PE 簽名、將載荷嵌入 PKCS#7 憑證資料，以及劫持 19 種檔案類型的 Subject Interface Package（SIP）提供者。主要技術包括 WinVerifyTrust FinalPolicy 繞過、Windows 11 上的 Smart App Control 規避、用於橫向移動的 SIP 執行面植入，以及透過 CryptDllFormatObject 處理常式實現的分析人員觸發持久化。此儲存庫附帶 YARA 與 Sigma 偵測規則、SigStash 載荷提取工具，以及基於 Impacket 的遠端登錄檔編排。其用途為經授權的進攻性安全測試、信任控制研究，以及理解攻擊者如何破壞 Windows 程式碼簽章強制機制。
