TrustMeBro 是一款用于红队行动与 Windows 安全研究的 Authenticode 签名操纵工具包。它提供 Python 与 C++ 两种实现，可用于窃取与克隆 PE 签名、将载荷嵌入 PKCS#7 证书数据，以及劫持 19 种文件类型的 Subject Interface Package（SIP）提供程序。主要技术包括 WinVerifyTrust FinalPolicy 绕过、Windows 11 上的 Smart App Control 规避、用于横向移动的 SIP 执行面植入，以及通过 CryptDllFormatObject 处理程序实现的分析人员触发持久化。该仓库附带 YARA 与 Sigma 检测规则、SigStash 载荷提取工具，以及基于 Impacket 的远程注册表编排。其用途为经授权的进攻性安全测试、信任控制研究，以及理解攻击者如何破坏 Windows 代码签名强制机制。
