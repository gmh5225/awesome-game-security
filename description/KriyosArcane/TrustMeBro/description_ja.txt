TrustMeBro は、レッドチーム作戦および Windows セキュリティ研究向けの Authenticode 署名操作ツールキットです。Python と C++ の両実装を提供し、PE 署名の窃取・複製、PKCS#7 証明書データへのペイロード埋め込み、19 種類のファイル形式にわたる Subject Interface Package（SIP）プロバイダーの乗っ取りが可能です。主な手法には、WinVerifyTrust FinalPolicy バイパス、Windows 11 上の Smart App Control 回避、横方向移動のための SIP 実行面インプラント、CryptDllFormatObject ハンドラーによるアナリストトリガー型永続化が含まれます。本リポジトリには YARA および Sigma 検知ルール、SigStash ペイロード抽出ツール、Impacket によるリモートレジストリオーケストレーションが同梱されています。承認された攻撃的セキュリティテスト、信頼制御研究、および攻撃者が Windows コード署名強制をどのように回避するかを理解する目的で提供されています。
