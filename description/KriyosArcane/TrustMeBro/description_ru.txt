TrustMeBro — набор инструментов для манипуляции подписями Authenticode, предназначенный для операций red team и исследований безопасности Windows. Он предоставляет реализации на Python и C++ для кражи и клонирования PE-подписей, встраивания полезной нагрузки в данные сертификатов PKCS#7 и перехвата провайдеров Subject Interface Package для 19 типов файлов. Ключевые техники включают обход WinVerifyTrust FinalPolicy, уклонение от Smart App Control в Windows 11, импланты на поверхности выполнения SIP для lateral movement и персистентность, активируемую аналитиком через обработчики CryptDllFormatObject. Репозиторий содержит правила обнаружения YARA и Sigma, инструменты извлечения полезной нагрузки SigStash и удалённую оркестрацию реестра через Impacket. Предназначен для авторизованного offensive security testing, исследований контроля доверия и понимания того, как противники обходят принудительную проверку подписи кода в Windows.
