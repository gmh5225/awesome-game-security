TrustMeBro는 레드팀 작전 및 Windows 보안 연구를 위한 Authenticode 서명 조작 툴킷입니다. Python과 C++ 구현을 모두 제공하며, PE 서명 도용 및 복제, PKCS#7 인증서 데이터에 페이로드 삽입, 19가지 파일 형식에 걸친 Subject Interface Package(SIP) 프로바이더 탈취를 지원합니다. 주요 기법으로는 WinVerifyTrust FinalPolicy 우회, Windows 11의 Smart App Control 회피, 측면 이동을 위한 SIP 실행 표면 임플란트, CryptDllFormatObject 핸들러를 통한 분석가 트리거 지속성이 있습니다. 저장소에는 YARA 및 Sigma 탐지 규칙, SigStash 페이로드 추출 도구, Impacket을 통한 원격 레지스트리 오케스트레이션이 함께 제공됩니다. 승인된 공격적 보안 테스트, 신뢰 제어 연구, 그리고 공격자가 Windows 코드 서명 강제를 어떻게 우회하는지 이해하는 데 사용됩니다.
