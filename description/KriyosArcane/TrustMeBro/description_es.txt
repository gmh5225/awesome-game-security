TrustMeBro es un kit de herramientas de manipulación de firmas Authenticode para operaciones de red team e investigación de seguridad en Windows. Ofrece implementaciones en Python y C++ para robar y clonar firmas PE, incrustar cargas útiles en datos de certificados PKCS#7, y secuestrar proveedores Subject Interface Package en 19 tipos de archivo. Las técnicas clave incluyen la omisión de WinVerifyTrust FinalPolicy, la evasión de Smart App Control en Windows 11, implantes en la superficie de ejecución SIP para movimiento lateral, y persistencia activada por el analista mediante controladores CryptDllFormatObject. El repositorio incluye reglas de detección YARA y Sigma, herramientas de extracción de cargas SigStash, y orquestación remota del registro mediante Impacket. Está destinado a pruebas ofensivas autorizadas, investigación de control de confianza, y a comprender cómo los adversarios subvierten la aplicación de firma de código en Windows.
