Callisto SSS è una mod per Cyberpunk 2077 che migliora il rendering della pelle con path tracing iniettando i termini di Fresnel diffuso e retro-riflessione del BRDF Callisto e sostituendo il kernel di blur per la subsurface scattering del motore con un profilo rimodellato. Utilizza un layer implicito Vulkan personalizzato per sostituire a caldo gli shader di generazione dei raggi del path tracer SPIR-V al caricamento su Linux tramite Proton, identificando i moduli tramite impronte DXIL incorporate, insieme a un plugin RED4ext che sovrascrive la texture di diffusione SSS a runtime tramite hook CopyTextureRegion. Il repository include un'ampia toolchain di reverse engineering e sviluppo in C, Python, Lua e script shell per patching SPIR-V, censimento degli shader, test A/B e flussi di verifica. Le modifiche alla pelle sono limitate ai pixel classificati come pelle dal motore, così che gli altri materiali restano bit-identici alla versione vanilla con le impostazioni predefinite. È rivolto a modder grafici e ricercatori che studiano pipeline di rendering in tempo reale, intercettazione di shader a runtime e sostituzione del BRDF, non a strumenti anti-cheat o di sicurezza.
