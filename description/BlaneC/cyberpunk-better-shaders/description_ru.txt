Callisto SSS — мод для Cyberpunk 2077, улучшающий рендеринг кожи при трассировке путей за счёт внедрения диффузно-френелевских и ретроотражающих членов BRDF Callisto и замены ядра размытия подповерхностного рассеяния движка на перестроенный профиль. Используется пользовательский неявный слой Vulkan для горячей подмены SPIR-V-шейдеров генерации лучей path tracer при загрузке в Linux через Proton с идентификацией модулей по встроенным отпечаткам DXIL, а также плагин RED4ext, перезаписывающий текстуру диффузии SSS во время выполнения через хуки CopyTextureRegion. Репозиторий включает обширный набор инструментов для реверс-инжиниринга и разработки на C, Python, Lua и shell-скриптах для патчинга SPIR-V, инвентаризации шейдеров, A/B-тестирования и рабочих процессов верификации. Изменения кожи применяются только к пикселям, классифицированным движком как кожа, поэтому при настройках по умолчанию остальные материалы остаются побитово идентичными ванильной версии. Предназначен для графических моддеров и исследователей, изучающих конвейеры рендеринга в реальном времени, перехват шейдеров во время выполнения и замену BRDF, а не для античит- или security-инструментов.
