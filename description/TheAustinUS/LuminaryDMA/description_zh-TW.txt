LuminaryDMA 是一款 Windows C++ 應用程式，透過外部直接記憶體存取（DMA）硬體讀取《決勝時刻》遊戲記憶體，提供唯讀視覺疊加層，例如 ESP、雷達與玩家資訊。它透過 LeechCore 與 DMALibrary 封裝整合 PCILeech FPGA 裝置，包含用於無硬體開發的 MockDMA 測試模式，並在與遊戲分離的機器上執行。該專案具備 GamePass 與 BattleNet 的平台自動偵測、BattleNet 指標解密、可設定的記憶體偏移，以及使用 Visual Studio 2022 建置的基於 ImGui 的疊加選單。它面向研究基於 DMA 的外部作弊、反作弊規避技術，以及受保護遊戲記憶體結構逆向工程的研究人員。
