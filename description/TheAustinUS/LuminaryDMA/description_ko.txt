LuminaryDMA는 외부 Direct Memory Access(DMA) 하드웨어를 통해 Call of Duty 게임 메모리를 읽어 ESP, 레이더, 플레이어 정보와 같은 읽기 전용 시각 오버레이를 제공하는 Windows C++ 애플리케이션입니다. LeechCore와 DMALibrary 래퍼를 통해 PCILeech FPGA 장치를 통합하며, 하드웨어 없이 개발할 수 있는 MockDMA 테스트 모드를 포함하고 게임과 분리된 별도의 머신에서 실행됩니다. GamePass와 BattleNet 플랫폼 자동 감지, BattleNet 포인터 복호화, 구성 가능한 메모리 오프셋, Visual Studio 2022로 빌드된 ImGui 기반 오버레이 메뉴 등의 기능을 제공합니다. DMA 기반 외부 치트, 안티치트 회피 기법, 보호된 게임 메모리 구조의 리버스 엔지니어링을 연구하는 연구자를 대상으로 합니다.
