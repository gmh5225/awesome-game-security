LuminaryDMA — это приложение для Windows на C++, которое считывает память игры Call of Duty через внешнее оборудование прямого доступа к памяти (DMA) и предоставляет визуальные оверлеи только для чтения, такие как ESP, радар и информация об игроках. Оно интегрирует FPGA-устройства PCILeech через LeechCore и обёртку DMALibrary, включает тестовый режим MockDMA для разработки без оборудования и работает на отдельной машине, не связанной с игрой. Проект поддерживает автоматическое определение платформы для GamePass и BattleNet, расшифровку указателей BattleNet, настраиваемые смещения памяти и меню оверлея на базе ImGui, собранное в Visual Studio 2022. Предназначен для исследователей, изучающих внешний читинг на основе DMA, методы обхода античита и реверс-инжиниринг защищённых структур игровой памяти.
