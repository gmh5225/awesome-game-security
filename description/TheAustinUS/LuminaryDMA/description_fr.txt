LuminaryDMA est une application Windows en C++ qui lit la mémoire du jeu Call of Duty via du matériel Direct Memory Access (DMA) externe afin de fournir des superpositions visuelles en lecture seule telles que l'ESP, le radar et les informations sur les joueurs. Elle intègre les dispositifs FPGA PCILeech via LeechCore et l'enveloppe DMALibrary, inclut un mode de test MockDMA pour le développement sans matériel, et s'exécute sur une machine distincte de celle du jeu. Le projet propose la détection automatique de plateforme pour GamePass et BattleNet, le déchiffrement de pointeurs BattleNet, des décalages mémoire configurables et un menu de superposition basé sur ImGui, construit avec Visual Studio 2022. Il est destiné aux chercheurs étudiant la triche externe basée sur le DMA, les techniques d'évasion anti-triche et l'ingénierie inverse de structures mémoire de jeu protégées.
