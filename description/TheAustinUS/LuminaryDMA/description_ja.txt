LuminaryDMA は、外部 Direct Memory Access（DMA）ハードウェアを介して Call of Duty のゲームメモリを読み取り、ESP、レーダー、プレイヤー情報などの読み取り専用ビジュアルオーバーレイを提供する Windows 向け C++ アプリケーションです。LeechCore と DMALibrary ラッパー経由で PCILeech FPGA デバイスを統合し、ハードウェアなしでの開発用 MockDMA テストモードを備え、ゲームとは別のマシン上で動作します。GamePass と BattleNet のプラットフォーム自動検出、BattleNet ポインタ復号、設定可能なメモリオフセット、Visual Studio 2022 で構築された ImGui ベースのオーバーレイメニューなどの機能を持ちます。DMA ベースの外部チート、アンチチート回避手法、保護されたゲームメモリ構造のリバースエンジニアリングを研究する研究者向けです。
