LuminaryDMA 是一款 Windows C++ 应用程序，通过外部直接内存访问（DMA）硬件读取《使命召唤》游戏内存，提供只读视觉叠加层，例如 ESP、雷达和玩家信息。它通过 LeechCore 和 DMALibrary 封装集成 PCILeech FPGA 设备，包含用于无硬件开发的 MockDMA 测试模式，并在与游戏分离的机器上运行。该项目具备 GamePass 与 BattleNet 的平台自动检测、BattleNet 指针解密、可配置的内存偏移，以及使用 Visual Studio 2022 构建的基于 ImGui 的叠加菜单。它面向研究基于 DMA 的外部作弊、反作弊规避技术以及受保护游戏内存结构逆向工程的研究人员。
