AI Game Trainer は Windows ローカル優先のアプリケーションで、Cheat Engine で見つけた内容をゲームごとに再利用できるトレーナー プリセットに変換し、ブラウザベースのコンソールから起動できます。上流の MCP Lua ブリッジ経由で名前付きパイプ、または任意のループバック TCP リレーで Cheat Engine と通信し、Python による HTTP サービス、SQLite ストレージ、CE テーブルのインポート／エクスポートを担います。CE から検証済みのアドレスリストやスクリプト記録を取得し、チートテーブル全体を CT ファイルとして永続化し、後から再読み込みして一致する単一のゲーム実行ファイルに対して特定のメモリレコードを有効／無効にできます。本プロジェクトはオフラインのシングルプレイ mod およびメモリ編集ワークフローを対象とし、外部 Codex と CE MCP を組み合わせた探索に対応しつつ、カーネルツール、アンチチート回避、オンラインマルチプレイの改ざんは意図的に対象外です。PyInstaller のポータブルビルドと同梱のスモークテスト デモにより、マシンにフル Python ツールチェーンがなくても CE の読み書きパスを検証できます。
