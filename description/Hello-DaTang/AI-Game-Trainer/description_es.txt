AI Game Trainer es una aplicación Windows con enfoque local que convierte los hallazgos de Cheat Engine en ajustes predefinidos de trainer reutilizables por juego, que puedes activar desde una consola basada en el navegador. Se comunica con Cheat Engine mediante el puente Lua MCP aguas arriba, por un canal con nombre o un relevo TCP de bucle local opcional, usando Python para el servicio HTTP, el almacenamiento SQLite y la importación y exportación de tablas CE. Capturas listas de direcciones o registros de script validados desde CE, persistes tablas de trampas completas como archivos CT y luego las recargas para activar o desactivar registros de memoria concretos frente a un único ejecutable de juego coincidente. El proyecto apunta a flujos de modding en un jugador sin conexión y edición de memoria, y se combina con Codex externo y CE MCP para la exploración, evitando deliberadamente herramientas de kernel, elusión de anti-cheat o manipulación del multijugador en línea. Una compilación portable con PyInstaller y una demo de prueba de humo incluida ayudan a verificar la ruta de lectura-escritura de CE sin requerir una cadena de herramientas Python completa en el equipo.
