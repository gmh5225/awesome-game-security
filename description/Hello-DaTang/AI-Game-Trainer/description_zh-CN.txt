AI Game Trainer 是一款以 Windows 本地为主的应用，可将 Cheat Engine 中的发现转化为可复用的逐游戏训练器预设，并通过基于浏览器的控制台触发。它通过上游 MCP Lua 桥接，以命名管道或可选的回环 TCP 中继与 Cheat Engine 通信，使用 Python 提供 HTTP 服务、SQLite 存储以及 CE 表导入与导出。你可以从 CE 捕获经校验的地址列表或脚本记录，将完整作弊表持久化为 CT 文件，日后重新加载以对单个匹配的游戏可执行文件启用或禁用特定内存记录。该项目面向离线单人 mod 与内存编辑工作流，可与外部 Codex 及 CE MCP 配合探索，同时刻意避免内核工具、反作弊规避或在线多人篡改。PyInstaller 便携构建与捆绑的冒烟测试演示有助于在不安装完整 Python 工具链的情况下验证 CE 读写路径。
