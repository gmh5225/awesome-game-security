AI Game Trainer est une application Windows privilégiant l’exécution locale qui transforme les découvertes de Cheat Engine en préréglages de trainer réutilisables par jeu, déclenchables depuis une console basée sur le navigateur. Elle communique avec Cheat Engine via le pont Lua MCP en amont, par un canal nommé ou un relais TCP en boucle locale optionnel, en s’appuyant sur Python pour le service HTTP, le stockage SQLite et l’import/export de tables CE. Vous capturez des listes d’adresses ou des scripts validés depuis CE, persistez des tables de triche entières au format CT, puis les rechargez pour activer ou désactiver des enregistrements mémoire précis sur un exécutable de jeu correspondant unique. Le projet vise les workflows de modding solo hors ligne et d’édition mémoire, s’associe à Codex externe et CE MCP pour l’exploration, tout en évitant délibérément les outils noyau, le contournement anti-triche ou la manipulation du multijoueur en ligne. Une build portable PyInstaller et une démo de test fumée fournie aident à vérifier le chemin lecture-écriture CE sans nécessiter une chaîne d’outils Python complète sur la machine.
