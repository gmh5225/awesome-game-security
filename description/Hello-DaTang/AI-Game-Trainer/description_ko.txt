AI Game Trainer는 Windows 로컬 우선 애플리케이션으로, Cheat Engine에서 찾은 내용을 게임별로 재사용 가능한 트레이너 프리셋으로 바꾸고 브라우저 기반 콘솔에서 실행할 수 있습니다. 상위 MCP Lua 브리지를 통해 명명된 파이프 또는 선택적 루프백 TCP 릴레이로 Cheat Engine과 통신하며, Python으로 HTTP 서비스, SQLite 저장, CE 테이블 가져오기 및 내보내기를 제공합니다. CE에서 검증된 주소 목록이나 스크립트 레코드를 캡처하고 전체 치트 테이블을 CT 파일로 유지한 뒤, 나중에 다시 불러와 일치하는 단일 게임 실행 파일에 대해 특정 메모리 레코드를 켜거나 끌 수 있습니다. 이 프로젝트는 오프라인 싱글 플레이 모딩 및 메모리 편집 워크플로를 대상으로 하며, 외부 Codex와 CE MCP를 함께 쓰는 탐색과 짝을 이루되, 커널 도구, 안티치트 회피, 온라인 멀티플레이 조작은 의도적으로 배제합니다. PyInstaller 휴대용 빌드와 번들된 스모크 테스트 데모는 PC에 전체 Python 도구 체인 없이도 CE 읽기·쓰기 경로를 검증하는 데 도움이 됩니다.
