AI Game Trainer — приложение для Windows с приоритетом локального выполнения: оно превращает находки Cheat Engine в переиспользуемые пресеты тренера для каждой игры, которые можно запускать из консоли в браузере. Связь с Cheat Engine идёт через вышестоящий MCP Lua‑мост по именованному каналу или необязательному TCP‑ретранслятору на loopback; HTTP‑сервис, хранение в SQLite и импорт/экспорт таблиц CE реализованы на Python. Вы сохраняете проверенные списки адресов или скрипты из CE, целиком записываете чит‑таблицы в CT‑файлы и позже подгружаете их, чтобы включать или отключать отдельные записи памяти для одного подходящего исполняемого файла игры. Проект ориентирован на офлайн‑моддинг одиночной игры и правку памяти, сочетается с внешним Codex и CE MCP для исследования и намеренно не затрагивает kernel‑утилиты, обход античита или вмешательство в онлайн‑мультиплеер. Портативная сборка PyInstaller и встроенная smoke‑демонстрация помогают проверить путь чтения‑записи CE без полной установки Python на машине.
