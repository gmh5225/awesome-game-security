AI Game Trainer 是一款以 Windows 本機為主的應用程式，可將 Cheat Engine 中的發現轉成可重複使用的逐遊戲訓練器預設，並透過以瀏覽器為基礎的主控台觸發。它透過上游 MCP Lua 橋接，以具名管道或可選的回環 TCP 轉發與 Cheat Engine 通訊，使用 Python 提供 HTTP 服務、SQLite 儲存以及 CE 表匯入與匯出。你可從 CE 擷取經驗證的位址清單或指令碼記錄，將完整作弊表持久化為 CT 檔，日後重新載入以對單一匹配的遊戲可執行檔啟用或停用特定記憶體記錄。本專案鎖定離線單人 mod 與記憶體編輯工作流程，可與外部 Codex 及 CE MCP 搭配探索，同時刻意避開核心工具、反作弊規避或線上多人篡改。PyInstaller 可攜式建置與內建的冒煙測試示範有助於在未安裝完整 Python 工具鏈的機器上驗證 CE 讀寫路徑。
