AI Game Trainer è un’applicazione Windows local-first che trasforma le scoperte di Cheat Engine in preset di trainer riutilizzabili per gioco, attivabili da una console basata su browser. Comunica con Cheat Engine tramite il bridge Lua MCP a monte, su una pipe con nome o un opzionale relay TCP in loopback, usando Python per il servizio HTTP, l’archiviazione SQLite e l’import/export delle tabelle CE. Si acquisiscono elenchi di indirizzi o record di script validati da CE, si persistono intere cheat table come file CT e poi si ricaricano per abilitare o disabilitare specifici record di memoria rispetto a un singolo eseguibile di gioco corrispondente. Il progetto è pensato per modding offline in singolo giocatore e flussi di editing della memoria, affiancando Codex esterno e CE MCP per l’esplorazione, evitando deliberatamente strumenti kernel, elusione anti-cheat o manomissione del multigiocatore online. Una build portatile PyInstaller e una demo smoke test inclusa aiutano a verificare il percorso lettura-scrittura CE senza richiedere una toolchain Python completa sulla macchina.
