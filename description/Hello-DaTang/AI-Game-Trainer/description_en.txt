AI Game Trainer is a Windows local-first application that turns Cheat Engine discoveries into reusable, per-game trainer presets you can trigger from a browser-based console. It speaks to Cheat Engine through the upstream MCP Lua bridge over a named pipe or optional loopback TCP relay, using Python for the HTTP service, SQLite storage, and CE table import and export. You capture validated address-list or script records from CE, persist whole cheat tables as CT files, and later reload them to enable or disable specific memory records against a single matching game executable. The project targets offline single-player modding and memory-editing workflows and pairs with external Codex plus CE MCP for exploration, while deliberately avoiding kernel tools, anti-cheat evasion, or online multiplayer tampering. A PyInstaller portable build and bundled smoke-test demo help verify the CE read-write path without requiring a full Python toolchain on the machine.
