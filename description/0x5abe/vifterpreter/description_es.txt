Vifterpreter es una biblioteca en Rust que analiza paquetes DMA de PlayStation 2 y los comandos VIF que transportan para la interfaz vectorial VIF1. Modela etiquetas DMA, identificadores de etiqueta y una amplia gama de opcodes VIF, incluidos unpack, carga de microprogramas y comandos de estado, usando binrw para E/S binaria y bilge para diseños de campos de bits. La compatibilidad con Serde permite serializar las estructuras analizadas para inspección o pipelines de herramientas. Esta crate está dirigida a ingenieros de ingeniería inversa e investigadores de seguridad de juegos que necesitan decodificar flujos de assets de PS2, como datos de mallas o gráficos incrustados en archivos binarios de juegos.
