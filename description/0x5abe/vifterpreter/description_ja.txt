Vifterpreter は、PlayStation 2 の DMA パケットと、VIF1 ベクターインターフェース向けにそれらが運ぶ VIF コマンドを解析する Rust ライブラリです。DMA タグ、タグ識別子、unpack・マイクロプログラムのロード・状態コマンドなど幅広い VIF オペコードをモデル化し、バイナリ I/O には binrw、ビットフィールドレイアウトには bilge を使用します。Serde サポートにより、解析結果の構造体をシリアライズして調査やツールパイプラインに利用できます。この crate は、メッシュやグラフィックスデータなどバイナリゲームファイルに埋め込まれた PS2 アセットストリームをデコードする必要があるリバースエンジニアやゲームセキュリティ研究者を対象としています。
