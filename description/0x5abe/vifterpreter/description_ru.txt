Vifterpreter — это библиотека на Rust для разбора DMA-пакетов PlayStation 2 и содержащихся в них VIF-команд для векторного интерфейса VIF1. Она моделирует DMA-теги, идентификаторы тегов и широкий набор VIF-опкодов, включая unpack, загрузку микропрограмм и команды состояния, используя binrw для бинарного ввода-вывода и bilge для битовых полей. Поддержка Serde позволяет сериализовать разобранные структуры для анализа или интеграции в инструментальные пайплайны. crate ориентирован на специалистов по реверс-инжинирингу и исследователей безопасности игр, которым нужно декодировать потоки PS2-ассетов, например данные мешей или графики, встроенные в бинарные файлы игр.
