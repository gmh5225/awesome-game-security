OmniClutch는 Minecraft Java Edition용 경량 Fabric 클라이언트 모드로, 치명적인 낙하 피해를 방지하기 위해 clutch 동작을 자동 수행합니다. 자유 낙하 중 플레이어를 모니터링하고, 아래 방향 레이캐스트로 임박한 충돌을 감지하며, 핫바에서 물양동이, 보트, 건초 더미, 슬라임 블록 등 적절한 clutch 아이템을 선택합니다. 클라이언트 측 상태 머신이 설정 가능한 가우시안 반응 지연과 부드러운 카메라 회전 보간을 적용해 인간 입력을 모방하고 안티치트 탐지를 줄입니다. Java로 Minecraft 1.21+ 및 Fabric API용으로 작성되었으며, 수동 clutch가 너무 느린 서바이벌이나 PvP 상황에서 자동 낙하 회복을 원하는 플레이어를 대상으로 합니다.
