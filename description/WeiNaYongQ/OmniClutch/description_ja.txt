OmniClutch は、Minecraft Java Edition 向けの軽量 Fabric クライアント MOD で、致死の落下ダメージを防ぐ clutch 操作を自動実行します。自由落下中のプレイヤーを監視し、下向きレイキャストで衝突の兆候を検出し、ホットバーから水バケツ、ボート、干し草の俵、スライムブロックなど適切な clutch アイテムを選択します。クライアント側のステートマシンが、設定可能なガウス分布の反応遅延と滑らかなカメラ回転補間を適用し、人間の入力を模倣してアンチチート検出を低減します。Java で Minecraft 1.21+ 向けに Fabric API とともに書かれており、手動 clutch では間に合わないサバイバルや PvP シナリオで自動落下回復を求めるプレイヤーを対象としています。
