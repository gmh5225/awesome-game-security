OmniClutch is a lightweight Fabric client mod for Minecraft Java Edition that automatically performs clutch maneuvers to prevent lethal fall damage. It monitors the player during free fall, uses downward raycasts to detect imminent impact, and selects an appropriate clutch item from the hotbar such as water buckets, boats, hay bales, or slime blocks. The mod drives a client-side state machine that applies configurable Gaussian reaction delays and smooth camera rotation interpolation to mimic human input and reduce anti-cheat detection. Written in Java for Minecraft 1.21+ with the Fabric API, it targets players who want automated fall recovery in survival or PvP scenarios where manual clutching is too slow.
