OmniClutch ist ein leichtgewichtiger Fabric-Client-Mod für Minecraft Java Edition, der automatisch Clutch-Manöver ausführt, um tödlichen Fallschaden zu verhindern. Er überwacht den Spieler beim freien Fall, nutzt nach unten gerichtete Raycasts, um einen bevorstehenden Aufprall zu erkennen, und wählt ein passendes Clutch-Item aus der Schnellleiste, etwa Wassereimer, Boote, Heuballen oder Schleimblöcke. Der Mod steuert eine clientseitige Zustandsmaschine, die konfigurierbare Gauß'sche Reaktionsverzögerungen und sanfte Kamera-Rotationsinterpolation anwendet, um menschliche Eingaben nachzuahmen und Anti-Cheat-Erkennung zu reduzieren. In Java für Minecraft 1.21+ mit der Fabric API geschrieben, richtet er sich an Spieler, die in Survival- oder PvP-Szenarien automatische Fallrettung wünschen, wenn manuelles Clutchen zu langsam ist.
