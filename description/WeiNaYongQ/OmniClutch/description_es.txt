OmniClutch es un mod cliente ligero de Fabric para Minecraft Java Edition que realiza automáticamente maniobras de clutch para evitar daño mortal por caída. Supervisa al jugador durante la caída libre, usa raycasts hacia abajo para detectar un impacto inminente y selecciona un objeto de clutch adecuado de la barra rápida, como cubos de agua, botes, pacas de heno o bloques de slime. El mod impulsa una máquina de estados del lado del cliente que aplica retrasos de reacción gaussianos configurables e interpolación suave de la rotación de la cámara para imitar la entrada humana y reducir la detección anti-cheat. Escrito en Java para Minecraft 1.21+ con la API de Fabric, está dirigido a jugadores que quieren recuperación automática de caídas en escenarios de supervivencia o PvP donde el clutch manual es demasiado lento.
