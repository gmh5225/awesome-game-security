OmniClutch — это лёгкий клиентский мод Fabric для Minecraft Java Edition, который автоматически выполняет манёвры clutch, чтобы предотвратить смертельный урон от падения. Он отслеживает игрока во время свободного падения, использует лучи вниз для обнаружения неминуемого удара и выбирает подходящий предмет clutch из панели быстрого доступа, например вёдра с водой, лодки, тюки сена или блоки слизи. Мод управляет клиентской конечным автоматом, который применяет настраиваемые задержки реакции по гауссовому распределению и плавную интерполяцию поворота камеры, имитируя человеческий ввод и снижая риск обнаружения античитом. Написан на Java для Minecraft 1.21+ с Fabric API и ориентирован на игроков, которым нужно автоматическое восстановление после падения в survival или PvP, где ручной clutch слишком медленный.
