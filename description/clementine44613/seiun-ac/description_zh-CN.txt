Seiun AC 是一款适用于 Minecraft 1.21.11 的 Fabric 反作弊模组，在玩家加入时会根据服务器端的哈希白名单、黑名单和灰名单，验证其已安装的客户端模组与资源包。该模组基于 Java 开发，运行于 Fabric Loader，通过自定义客户端-服务器网络数据包和 mixin 收集模组哈希、检测会话中途的资源包变更，并对使用未授权或修改版客户端的玩家进行踢出或警告。模组集成 Discord Webhook，可实时推送踢出、警告、管理员状态变更及违规统计等告警，并提供游戏内命令用于管理名单和重载配置。它面向需要强制客户端完整性、并在传统游戏内检测之外防止作弊的 Minecraft 服务器管理员，可与同一项目系列中的 Discord 白名单工具配合使用。
