Seiun AC 是一款適用於 Minecraft 1.21.11 的 Fabric 反作弊模組，在玩家加入時會依據伺服器端的雜湊白名單、黑名單和灰名單，驗證其已安裝的用戶端模組與資源包。該模組以 Java 開發，運行於 Fabric Loader，透過自訂用戶端-伺服器網路封包和 mixin 收集模組雜湊、偵測連線期間的資源包變更，並對使用未授權或修改版用戶端的玩家進行踢出或警告。模組整合 Discord Webhook，可即時推送踢出、警告、管理員狀態變更及違規統計等告警，並提供遊戲內指令用於管理名單和重新載入設定。它面向需要強制用戶端完整性、並在傳統遊戲內檢測之外防止作弊的 Minecraft 伺服器管理員，可與同一專案系列中的 Discord 白名單工具配合使用。
