Seiun AC is a Fabric anti-cheat mod for Minecraft 1.21.11 that verifies installed client mods and resource packs against server-side hash whitelists, blacklists, and gray lists when players join. Written in Java for Fabric Loader, it uses custom client-server network packets and mixins to collect mod hashes, detect mid-session resource pack changes, and kick or warn players who use unauthorized or modified clients. The mod includes Discord webhook integration for real-time alerts on kicks, warnings, operator status changes, and violation statistics, plus in-game commands to manage lists and reload configuration. It is aimed at Minecraft server administrators who need client integrity enforcement and cheat prevention beyond traditional gameplay checks, and works as a companion to Discord-based whitelisting tools in the same project family.
