Seiun AC — это Fabric anti-cheat мод для Minecraft 1.21.11, который при входе игроков проверяет установленные клиентские моды и ресурспаки по серверным белым, чёрным и серым спискам хешей. Написан на Java для Fabric Loader, использует пользовательские сетевые пакеты клиент-сервер и mixin для сбора хешей модов, обнаружения изменений ресурспаков в ходе сессии, а также кика или предупреждения игроков с неавторизованными или изменёнными клиентами. Мод включает интеграцию с Discord webhook для оповещений в реальном времени о киках, предупреждениях, смене статуса оператора и статистике нарушений, а также игровые команды для управления списками и перезагрузки конфигурации. Предназначен для администраторов серверов Minecraft, которым нужно обеспечение целостности клиента и предотвращение читов за пределами традиционных проверок геймплея, и работает как дополнение к инструментам whitelist на базе Discord из той же семьи проектов.
