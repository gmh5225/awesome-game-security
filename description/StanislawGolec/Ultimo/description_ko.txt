Ultimo는 Uno에서 영감을 받은 권위형 멀티플레이어 카드 게임 서버로, Java 21로 구현되었으며 외부 런타임 의존성이 없습니다. 단일 포트에서 raw TCP, 자체 RFC 6455 WebSocket 스택, 내장 HTML5 클라이언트를 다중화하며, 연결에는 가상 스레드를, 안전한 동시 상태에는 방별 actor 스타일 이벤트 루프를 사용합니다. 서버는 백엔드에서 모든 수, 셔플, 페널티를 검증하고 fog-of-war 필터링을 적용해 클라이언트가 상대의 숨겨진 카드를 받지 못하게 하며, 온라인 게임의 서버 측 안티치트를 보여 줍니다. 프로젝트에는 줄 단위 구분 와이어 프로토콜, 터미널 및 브라우저 클라이언트, Docker 및 Cloud Run 배포, 동시성 및 WebSocket 퍼즈 테스트를 포함한 대규모 JUnit 테스트 스위트가 포함되어 있습니다. Spring 등 프레임워크 없이 권위형 게임 백엔드, 치트 방지 상태 동기화, 경량 네트워킹을 공부하는 개발자에게 적합합니다.
