Ultimo è un server di gioco di carte multigiocatore autoritativo ispirato a Uno, implementato in Java 21 senza dipendenze di runtime esterne. Multiplexa TCP grezzo, uno stack WebSocket RFC 6455 interno e un client HTML5 incorporato su una sola porta, usando thread virtuali per le connessioni e un event loop in stile actor per stanza per uno stato concorrente sicuro. Il server convalida ogni mossa, mescolata e penalità lato backend e applica filtraggio fog-of-war così i client non ricevono mai le carte nascoste degli avversari, illustrando l'anti-cheat lato server per i giochi online. Il progetto include un protocollo wire delimitato da righe, client terminale e browser, deploy Docker e Cloud Run, e un'ampia suite di test JUnit con concorrenza e fuzz test WebSocket. È adatto a sviluppatori che studiano backend di gioco autoritativi, sincronizzazione dello stato resistente ai cheat e networking leggero senza Spring o framework simili.
