Ultimo 是一款受 Uno 啟發的權威多人紙牌遊戲伺服器，使用 Java 21 實作，無外部執行時期依賴。它在同一連接埠上多工原始 TCP、自研 RFC 6455 WebSocket 堆疊以及嵌入式 HTML5 用戶端，透過虛擬執行緒處理連線，並以按房間劃分的 actor 式事件迴圈確保並發狀態安全。伺服器在後端驗證每一步出牌、洗牌與罰牌，並套用戰爭迷霧過濾，使用戶端永遠收不到對手的暗牌，展示了線上遊戲的伺服器端反作弊思路。專案提供以行分隔的線路協定、終端機與瀏覽器用戶端、Docker 與 Cloud Run 部署，以及大量 JUnit 測試（含並發與 WebSocket 模糊測試）。適合研究權威遊戲後端、防作弊狀態同步，以及在不使用 Spring 等框架下的輕量網路實作的開發者。
