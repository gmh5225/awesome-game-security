Ultimo — авторитетный многопользовательский сервер карточной игры, вдохновлённый Uno, реализованный на Java 21 без внешних зависимостей среды выполнения. На одном порту мультиплексируются raw TCP, собственный стек WebSocket RFC 6455 и встроенный HTML5-клиент; для соединений используются виртуальные потоки, для безопасного параллельного состояния — event loop в стиле actor на комнату. Сервер проверяет каждый ход, перетасовку и штраф на бэкенде и применяет фильтрацию fog-of-war, чтобы клиенты никогда не получали скрытые карты соперников, демонстрируя серверный античит для онлайн-игр. В проекте есть построчный wire-протокол, терминальный и браузерный клиенты, развёртывание в Docker и Cloud Run, а также обширный набор тестов JUnit, включая тесты на параллелизм и фаззинг WebSocket. Подходит разработчикам, изучающим авторитетные игровые бэкенды, синхронизацию состояния, устойчивую к читам, и лёгкую сетевую подсистему без Spring и подобных фреймворков.
