Ultimo は Uno に着想を得た権威型マルチプレイヤーカードゲームサーバーで、Java 21 で実装され、外部ランタイム依存はありません。同一ポートで raw TCP、自前の RFC 6455 WebSocket スタック、組み込み HTML5 クライアントを多重化し、接続には仮想スレッド、安全な並行状態にはルーム単位の actor 型イベントループを用います。サーバーはバックエンドですべての手、シャッフル、ペナルティを検証し、フォグ・オブ・ウォーによるフィルタリングを適用するため、クライアントは相手の伏せ札を受け取りません。オンラインゲームにおけるサーバー側アンチチートの例示です。プロジェクトには行区切りワイヤプロトコル、ターミナルおよびブラウザクライアント、Docker と Cloud Run へのデプロイ、並行性および WebSocket ファズテストを含む大規模な JUnit テストスイートが同梱されています。Spring などのフレームワークを使わない軽量ネットワーキング、権威型ゲームバックエンド、チート耐性のある状態同期を学ぶ開発者向けです。
