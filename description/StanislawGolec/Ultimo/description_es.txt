Ultimo es un servidor autoritativo de juego de cartas multijugador inspirado en Uno, implementado en Java 21 sin dependencias de tiempo de ejecución externas. Multiplexa TCP en bruto, una pila WebSocket RFC 6455 propia y un cliente HTML5 integrado en un solo puerto, usando hilos virtuales para las conexiones y un bucle de eventos al estilo actor por sala para un estado concurrente seguro. El servidor valida cada jugada, barajado y penalización en el backend y aplica filtrado tipo niebla de guerra para que los clientes nunca reciban las cartas ocultas de los oponentes, ilustrando anti-trampas del lado del servidor en juegos en línea. El proyecto incluye un protocolo wire delimitado por líneas, clientes de terminal y navegador, despliegue en Docker y Cloud Run, y una amplia suite de pruebas JUnit con concurrencia y fuzz tests WebSocket. Es adecuado para desarrolladores que estudian backends de juego autoritativos, sincronización de estado resistente a trampas y redes ligeras sin Spring ni frameworks similares.
