Ultimo is an authoritative multiplayer card game server inspired by Uno, implemented in Java 21 with no external runtime dependencies. It multiplexes raw TCP, an in-house RFC 6455 WebSocket stack, and an embedded HTML5 client on one port, using virtual threads for connections and an actor-style per-room event loop for safe concurrent state. The server validates every move, shuffles, and penalty on the backend and applies fog-of-war filtering so clients never receive opponents' hidden cards, illustrating server-side anti-cheat for online games. The project ships with a line-delimited wire protocol, terminal and browser clients, Docker and Cloud Run deployment, and a large JUnit test suite including concurrency and WebSocket fuzz tests. It suits developers studying authoritative game backends, cheat-resistant state synchronization, and low-footprint networking without Spring or similar frameworks.
