Ultimo 是一款受 Uno 启发的权威多人纸牌游戏服务器，使用 Java 21 实现，无外部运行时依赖。它在同一端口上复用原始 TCP、自研 RFC 6455 WebSocket 栈以及嵌入式 HTML5 客户端，通过虚拟线程处理连接，并以按房间划分的 actor 式事件循环保证并发状态安全。服务器在后端校验每一步出牌、洗牌与罚牌，并应用战争迷雾过滤，使客户端永远收不到对手的暗牌，展示了在线游戏的服务端反作弊思路。项目提供按行分隔的线协议、终端与浏览器客户端、Docker 与 Cloud Run 部署，以及大量 JUnit 测试（含并发与 WebSocket 模糊测试）。适合研究权威游戏后端、防作弊状态同步，以及在不使用 Spring 等框架下的轻量网络实现的开发者。
