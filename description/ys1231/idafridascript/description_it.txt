FridaTools è un plugin per IDA Pro 9.1 che genera JavaScript di hook Frida per la funzione sotto il cursore direttamente dalla finestra di disassemblaggio. Premendo una scorciatoia nella vista assembly si ottengono script di hook pronti all’uso basati sull’analisi delle funzioni di IDA, con modelli per hook generici e modelli specializzati per il bypass del SSL pinning in Flutter. Il progetto è implementato principalmente in Python con l’API di IDA, insieme a modelli di hook JavaScript e integrazione opzionale con un server HTTP MCP per flussi automatizzati di generazione script. È pensato per reverse engineer e ricercatori di sicurezza mobile che uniscono analisi statica in IDA e strumentazione dinamica con Frida, inclusi scenari comuni di SSL pinning e analisi di app Flutter.
