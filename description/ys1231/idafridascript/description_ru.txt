FridaTools — плагин для IDA Pro 9.1, который генерирует JavaScript-хуки Frida для функции под курсором прямо из окна дизасsemblера. Горячая клавиша в представлении ассемблера создаёт готовые к использованию скрипты хуков на основе анализа функций в IDA, с шаблонами для общих хуков функций и специализированными шаблонами обхода SSL pinning во Flutter. Проект в основном реализован на Python с использованием API IDA, с шаблонами хуков на JavaScript и опциональной интеграцией HTTP MCP-сервера для автоматизированной генерации скриптов. Ориентирован на reverse-инженеров и исследователей мобильной безопасности, совмещающих статический анализ в IDA с динамической инструментацией через Frida, включая типичные сценарии SSL pinning и анализа приложений Flutter.
