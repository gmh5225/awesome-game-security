FridaTools is an IDA Pro 9.1 plugin that generates Frida hook JavaScript for the function under the cursor directly from the disassembly window. Pressing a shortcut in the assembly view produces ready-to-use hook scripts based on IDA’s function analysis, with templates for generic function hooks and specialized Flutter SSL pinning bypass hooks. The project is implemented mainly in Python using the IDA API, paired with JavaScript hook templates and optional HTTP MCP server integration for automated script generation workflows. It targets reverse engineers and mobile security researchers who combine static analysis in IDA with dynamic instrumentation via Frida, including common SSL pinning and Flutter app analysis scenarios.
