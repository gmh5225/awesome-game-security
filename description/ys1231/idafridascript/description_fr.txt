FridaTools est une extension pour IDA Pro 9.1 qui génère du JavaScript de hooks Frida pour la fonction sous le curseur, directement depuis la fenêtre de désassemblage. Un raccourci dans la vue assembleur produit des scripts de hook prêts à l’emploi à partir de l’analyse de fonction d’IDA, avec des modèles pour les hooks génériques et des modèles dédiés au contournement du SSL pinning Flutter. Le projet est implémenté surtout en Python via l’API IDA, avec des modèles de hooks JavaScript et une intégration optionnelle d’un serveur HTTP MCP pour automatiser la génération de scripts. Il s’adresse aux ingénieurs reverse et chercheurs en sécurité mobile qui combinent l’analyse statique dans IDA et l’instrumentation dynamique avec Frida, y compris le SSL pinning courant et l’analyse d’applications Flutter.
