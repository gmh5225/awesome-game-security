FridaTools es un complemento de IDA Pro 9.1 que genera JavaScript de hooks de Frida para la función bajo el cursor directamente desde la ventana de desensamblado. Al pulsar un atajo en la vista de ensamblador se obtienen scripts de hook listos para usar basados en el análisis de funciones de IDA, con plantillas para hooks genéricos y plantillas especializadas para eludir el SSL pinning en Flutter. El proyecto está implementado principalmente en Python con la API de IDA, junto con plantillas de hooks en JavaScript e integración opcional con un servidor HTTP MCP para flujos automatizados de generación de scripts. Está dirigido a ingenieros inversores e investigadores de seguridad móvil que combinan análisis estático en IDA con instrumentación dinámica mediante Frida, incluidos escenarios habituales de SSL pinning y análisis de apps Flutter.
