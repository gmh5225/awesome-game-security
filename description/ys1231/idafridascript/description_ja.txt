FridaTools は IDA Pro 9.1 向けプラグインで、逆アセンブリウィンドウ上でカーソル位置の関数から Frida フック用 JavaScript を直接生成します。アセンブリビューでショートカットを押すと、IDA の関数解析に基づくすぐ使えるフックスクリプトが得られ、汎用関数フック用テンプレートに加え Flutter の SSL ピンニング回避向け専用テンプレートも用意されています。実装は主に Python と IDA API で行い、JavaScript フックテンプレートおよび任意の HTTP MCP サーバー連携により、スクリプト生成の自動化ワークフローにも対応します。IDA での静的解析と Frida による動的インストルメンテーションを組み合わせるリバースエンジニアやモバイルセキュリティ研究者向けで、一般的な SSL ピンニングや Flutter アプリ解析の場面を想定しています。
