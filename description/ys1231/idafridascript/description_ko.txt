FridaTools는 IDA Pro 9.1용 플러그인으로, 디스어셈블리 창에서 커서 아래 함수에 대해 Frida 후킹 JavaScript를 바로 생성합니다. 어셈블리 뷰에서 단축키를 누르면 IDA의 함수 분석을 바탕으로 바로 쓸 수 있는 후크 스크립트가 만들어지며, 일반 함수 후크용 템플릿과 Flutter SSL 피닝 우회용 전용 템플릿을 제공합니다. 프로젝트는 주로 Python과 IDA API로 구현되었고, JavaScript 후크 템플릿과 선택적 HTTP MCP 서버 연동으로 스크립트 생성 자동화 워크플로를 지원합니다. IDA에서 정적 분석을 하고 Frida로 동적 계측을 병행하는 리버스 엔지니어와 모바일 보안 연구자를 대상으로 하며, 흔한 SSL 피닝 및 Flutter 앱 분석 시나리오를 다룹니다.
