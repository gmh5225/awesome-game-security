CheatRunner Patches is a community-maintained library of PlayStation 4 and PlayStation 5 game patches designed for use with the CheatRunner loader. Each title is represented by an XML file keyed to Sony Title IDs, with separate folders for PS4 (CUSA) and PS5 (PPSA/Prospero) builds. Patches declare version-specific metadata and byte-level edits against game executables such as eboot.bin to unlock features like 60 FPS targets, resolution changes, and related runtime tweaks. The collection is aimed at console modding and reverse-engineering practitioners who legally own games and want tested, shareable patch definitions rather than ad hoc binary edits.
