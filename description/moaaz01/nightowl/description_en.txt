NightOwl is a unified command-line platform for Android APK security analysis that combines static inspection, framework detection, runtime defense assessment, and automated bypass script generation. Written primarily in Python, it orchestrates tools such as jadx, apktool, androguard, Semgrep, and Frida to perform nine-section scans covering permissions, secrets, endpoints, manifest components, vulnerabilities, and decompiled source. It detects mobile frameworks including Flutter, React Native, Cordova, and Unity, identifies runtime application self-protection mechanisms like RootBeer, SafetyNet, and Frida hooking, and can generate tailored Frida bypass scripts per detection profile. Additional capabilities include OWASP MASTG-aligned Semgrep rules, CVSS scoring, Shannon entropy filtering for secret detection, and structured JSON output for automation. The toolkit targets security researchers, penetration testers, and reverse engineers assessing Android apps and games for hardcoded credentials, anti-tamper defenses, and exploitable misconfigurations.
