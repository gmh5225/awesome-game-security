NightOwl 是一个统一的 Android APK 安全分析命令行平台，整合了静态检测、框架识别、运行时防护评估以及自动化绕过脚本生成。该工具主要使用 Python 编写，协调 jadx、apktool、androguard、Semgrep 和 Frida 等工具，执行涵盖权限、密钥、端点、清单组件、漏洞和反编译源码的九段式扫描。它能检测 Flutter、React Native、Cordova 和 Unity 等移动框架，识别 RootBeer、SafetyNet 和 Frida 挂钩等运行时应用自保护（RASP）机制，并可针对每种检测配置生成定制 Frida 绕过脚本。其他功能包括符合 OWASP MASTG 的 Semgrep 规则、CVSS 评分、用于密钥检测的 Shannon 熵过滤，以及用于自动化的结构化 JSON 输出。该工具面向安全研究人员、渗透测试人员和逆向工程师，用于评估 Android 应用与游戏中硬编码凭据、防篡改防护及可利用的错误配置。
