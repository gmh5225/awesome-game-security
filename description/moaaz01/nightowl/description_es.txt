NightOwl es una plataforma unificada de línea de comandos para el análisis de seguridad de APK de Android que combina inspección estática, detección de frameworks, evaluación de defensas en tiempo de ejecución y generación automatizada de scripts de bypass. Escrito principalmente en Python, orquesta herramientas como jadx, apktool, androguard, Semgrep y Frida para realizar escaneos de nueve secciones que cubren permisos, secretos, endpoints, componentes del manifiesto, vulnerabilidades y código fuente descompilado. Detecta frameworks móviles como Flutter, React Native, Cordova y Unity, identifica mecanismos de autoprotección en tiempo de ejecución como RootBeer, SafetyNet y el hooking con Frida, y puede generar scripts de bypass de Frida personalizados por perfil de detección. Entre sus capacidades adicionales se incluyen reglas Semgrep alineadas con OWASP MASTG, puntuación CVSS, filtrado por entropía de Shannon para la detección de secretos y salida JSON estructurada para automatización. El kit de herramientas está dirigido a investigadores de seguridad, probadores de penetración e ingenieros inversos que evalúan aplicaciones y juegos de Android en busca de credenciales hardcodeadas, defensas anti-manipulación y configuraciones erróneas explotables.
