NightOwl — это единая платформа командной строки для анализа безопасности Android APK, объединяющая статический анализ, обнаружение фреймворков, оценку защиты во время выполнения и автоматическую генерацию скриптов обхода. Написанный преимущественно на Python, он координирует работу таких инструментов, как jadx, apktool, androguard, Semgrep и Frida, выполняя сканирование в девяти разделах: разрешения, секреты, конечные точки, компоненты манифеста, уязвимости и декомпилированный исходный код. Он обнаруживает мобильные фреймворки, включая Flutter, React Native, Cordova и Unity, выявляет механизмы самозащиты приложений во время выполнения, такие как RootBeer, SafetyNet и перехват через Frida, и может генерировать индивидуальные скрипты обхода Frida для каждого профиля обнаружения. Дополнительные возможности включают правила Semgrep, соответствующие OWASP MASTG, оценку по CVSS, фильтрацию по энтропии Шеннона для обнаружения секретов и структурированный JSON-вывод для автоматизации. Набор инструментов предназначен для исследователей безопасности, специалистов по тестированию на проникновение и reverse-инженеров, оценивающих Android-приложения и игры на предмет захардкоженных учётных данных, защиты от вмешательства и эксплуатируемых ошибок конфигурации.
