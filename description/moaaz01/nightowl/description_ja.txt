NightOwl は、静的解析、フレームワーク検出、ランタイム防御評価、自動バイパススクリプト生成を統合した Android APK セキュリティ分析向けの統合コマンドラインプラットフォームです。主に Python で実装され、jadx、apktool、androguard、Semgrep、Frida などのツールを連携させ、権限、シークレット、エンドポイント、マニフェストコンポーネント、脆弱性、逆コンパイル済みソースを対象とする 9 セクションのスキャンを実行します。Flutter、React Native、Cordova、Unity などのモバイルフレームワークを検出し、RootBeer、SafetyNet、Frida フックなどのランタイムアプリケーション自己保護（RASP）機構を識別し、検出プロファイルごとにカスタマイズされた Frida バイパススクリプトを生成できます。OWASP MASTG に準拠した Semgrep ルール、CVSS スコアリング、シークレット検出向けの Shannon エントロピーフィルタリング、自動化向けの構造化 JSON 出力などの機能も備えています。本ツールキットは、Android アプリやゲームのハードコードされた認証情報、改ざん防止防御、悪用可能な設定ミスを評価するセキュリティ研究者、ペネトレーションテスター、リバースエンジニアを対象としています。
