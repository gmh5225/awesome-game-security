NightOwl은 정적 검사, 프레임워크 탐지, 런타임 방어 평가, 자동화된 우회 스크립트 생성을 결합한 Android APK 보안 분석용 통합 명령줄 플랫폼입니다. 주로 Python으로 작성되었으며, jadx, apktool, androguard, Semgrep, Frida 같은 도구를 조율하여 권한, 시크릿, 엔드포인트, 매니페스트 구성 요소, 취약점, 디컴파일된 소스를 다루는 9개 섹션 스캔을 수행합니다. Flutter, React Native, Cordova, Unity 등 모바일 프레임워크를 탐지하고, RootBeer, SafetyNet, Frida 후킹 같은 런타임 애플리케이션 자기 보호(RASP) 메커니즘을 식별하며, 탐지 프로필별로 맞춤형 Frida 우회 스크립트를 생성할 수 있습니다. OWASP MASTG에 맞춘 Semgrep 규칙, CVSS 점수 산정, 시크릿 탐지를 위한 Shannon 엔트로피 필터링, 자동화를 위한 구조화된 JSON 출력 등의 추가 기능도 제공합니다. 이 툴킷은 Android 앱과 게임의 하드코딩된 자격 증명, 변조 방지 방어, 악용 가능한 잘못된 구성을 평가하는 보안 연구자, 침투 테스터, 리버스 엔지니어를 대상으로 합니다.
