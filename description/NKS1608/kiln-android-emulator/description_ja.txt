Kiln は Apple Silicon Mac 向けの Android エミュレータで、ウィンドウ内に実機に近い Android 16 の完全なインスタンスを動かし、アプリやモバイルゲームを対象としています。カスタム QEMU スタック上に構築され、Apple Hypervisor Framework による加速、カスタム Linux カーネルモジュール、gfxstream と MoltenVK 経由の GPU バックエンド OpenGL ES 3.1 および Vulkan レンダリングを備えています。各インスタンスは多数の市販端末モデルを模倣でき、SIM、IMEI、ハードウェアプロファイルを個別に設定可能で、ランチャーにはゲームごとのキーマッピング、コントローラー、adb、シェル、自動化用の kilnctl CLI も含まれます。オープンソース部分は主に C のカーネルと QEMU デバイスコードおよびビルドスクリプトで、LineageOS ベースのゲストイメージも同梱されます。macOS 上で制御可能な Android 環境が必要なゲームセキュリティやリバースエンジニアリングのワークフロー、エミュレータ検知、Play Integrity の制限、認定ハードウェア外でのアプリ挙動の調査などに適しています。
