Kiln is an Android emulator for Apple Silicon Macs that runs full phone-like instances of Android 16 in a window, aimed at apps and mobile games. It is built on a customized QEMU stack with Apple Hypervisor Framework acceleration, custom Linux kernel modules, and GPU-backed OpenGL ES 3.1 and Vulkan rendering through gfxstream and MoltenVK. Each instance can mimic many retail phone models with separate SIM, IMEI, and hardware profiles, and the launcher adds per-game key mapping, controllers, adb, shells, and a kilnctl CLI for automation. The open-source portion is mostly C kernel and QEMU device code plus build scripts, alongside a LineageOS-based guest image. It suits game security and reverse-engineering workflows that need a controllable Android environment on macOS, including studying emulator detection, Play Integrity limits, and app behavior outside certified hardware.
