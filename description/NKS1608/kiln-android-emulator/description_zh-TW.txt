Kiln 是一款面向 Apple Silicon Mac 的 Android 模擬器，可在視窗中執行完整的、類似真機的 Android 16 執行個體，適用於應用程式與手機遊戲。它建置於客製化的 QEMU 堆疊之上，搭配 Apple Hypervisor Framework 加速、自訂 Linux 核心模組，以及透過 gfxstream 與 MoltenVK 實現的 GPU 加速 OpenGL ES 3.1 與 Vulkan 渲染。每個執行個體可模擬多種零售機型，擁有獨立的 SIM、IMEI 與硬體設定檔；啟動器另提供逐遊戲按鍵對應、控制器、adb、Shell 以及用於自動化的 kilnctl CLI。開源部分主要為 C 語言核心與 QEMU 裝置程式碼及建置腳本，並附帶基於 LineageOS 的客體映像。它適合在 macOS 上需要可控 Android 環境的遊戲安全與逆向工程工作流程，包括研究模擬器偵測、Play Integrity 限制，以及應用程式在非認證硬體上的行為。
