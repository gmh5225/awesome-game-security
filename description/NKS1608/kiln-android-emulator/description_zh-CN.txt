Kiln 是一款面向 Apple Silicon Mac 的 Android 模拟器，可在窗口中运行完整的、类似真机的 Android 16 实例，适用于应用与手游。它基于定制的 QEMU 栈，配合 Apple Hypervisor Framework 加速、自定义 Linux 内核模块，以及通过 gfxstream 与 MoltenVK 实现的 GPU 加速 OpenGL ES 3.1 与 Vulkan 渲染。每个实例可模拟多种零售机型，拥有独立的 SIM、IMEI 与硬件配置；启动器还提供按游戏键位映射、手柄、adb、Shell 以及用于自动化的 kilnctl CLI。开源部分主要为 C 语言内核与 QEMU 设备代码及构建脚本，并附带基于 LineageOS 的客户机镜像。它适合在 macOS 上需要可控 Android 环境的游戏安全与逆向工程工作流，包括研究模拟器检测、Play Integrity 限制以及应用在非认证硬件上的行为。
