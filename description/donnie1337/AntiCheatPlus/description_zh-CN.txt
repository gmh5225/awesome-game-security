AntiCheatPlus 是一款 Paper Minecraft 服务端插件，将服务端作弊检测与完整的员工处罚流程相结合。它使用 Java 编写，基于 Maven 针对 Paper API 构建，面向现代 Paper 版本，并在相关场景下兼容旧版战斗计时。GUARDIÃO 模块对移动、战斗、方块、聊天、载具和交互运行可配置的行为检测，包括 kill-aura 诱饵实体和针对矿石的挖矿分析等技术，并将分阶段告警上报给具备权限的员工。除检测外，它还提供封禁、IP 封禁、踢出、警告、游戏内处罚菜单、持久化处罚记录以及登录时的强制执行。该项目适合希望在 Paper 网络上集成管理与外挂检测的多人 Minecraft 服主与反作弊开发者。
