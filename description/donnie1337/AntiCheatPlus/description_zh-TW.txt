AntiCheatPlus 是一款 Paper Minecraft 伺服器外掛，將伺服器端作弊偵測與完整的管理員處罰流程結合。它以 Java 撰寫，使用 Maven 針對 Paper API 建置，面向現代 Paper 版本，並在相關情境下考量舊版戰鬥計時。GUARDIÃO 模組對移動、戰鬥、方塊、聊天、載具與互動執行可設定的行為檢查，包含 kill-aura 誘餌實體與以礦石為重點的採礦分析等手法，並將分階段警示升級給具權限的管理員。除偵測外，還提供封禁、IP 封禁、踢出、警告、遊戲內處罰選單、持久化處罰紀錄與登入強制執行。本專案適合在 Paper 網路上希望整合管理與外掛偵測的多人 Minecraft 營運者與反作弊開發者。
