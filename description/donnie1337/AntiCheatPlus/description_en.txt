AntiCheatPlus is a Paper Minecraft server plugin that combines server-side cheat detection with a full staff punishment workflow. It is written in Java and built with Maven against the Paper API, targeting modern Paper releases while accounting for legacy combat timing where relevant. The GUARDIÃO module runs configurable behavioral checks for movement, combat, blocks, chat, vehicles, and interactions, including techniques such as kill-aura decoy entities and ore-focused mining analysis, and escalates staged alerts to permitted staff. Alongside detection, it provides bans, IP bans, kicks, warnings, an in-game punish menu, persisted punishment records, and login enforcement. The project suits multiplayer Minecraft operators and anti-cheat developers who want integrated moderation and hack detection on a Paper-based network.
