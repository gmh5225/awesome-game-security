AntiCheatPlus は、サーバー側のチート検知とスタッフ向けの一連の処罰ワークフローを組み合わせた Paper 向け Minecraft サーバープラグインです。Java で書かれ、Maven により Paper API 向けにビルドされ、最新の Paper リリースを対象としつつ、必要に応じてレガシーな戦闘タイミングにも配慮しています。GUARDIÃO モジュールは移動、戦闘、ブロック、チャット、乗り物、インタラクションに対する設定可能な行動チェックを実行し、kill-aura 用デコイエンティティや鉱石中心の採掘分析などの手法を含み、段階的なアラートを権限を持つスタッフへエスカレートします。検知に加え、BAN、IP BAN、キック、警告、ゲーム内処罰メニュー、永続化された処罰記録、ログイン時の強制適用を提供します。Paper ベースのネットワークでモデレーションとハック検知を一体で求めるマルチプレイ Minecraft 運営者やアンチチート開発者向けのプロジェクトです。
