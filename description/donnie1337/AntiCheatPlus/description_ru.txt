AntiCheatPlus — плагин для сервера Minecraft на Paper, который сочетает серверное обнаружение читов с полным рабочим процессом наказаний для персонала. Написан на Java и собирается Maven под API Paper, ориентирован на современные релизы Paper и при необходимости учитывает устаревший тайминг боя. Модуль GUARDIÃO выполняет настраиваемые поведенческие проверки движения, боя, блоков, чата, транспорта и взаимодействий, включая такие приёмы, как приманки-сущности для kill-aura и анализ добычи с фокусом на руду, и эскалирует поэтапные оповещения уполномоченному персоналу. Помимо детекции, доступны баны, IP-баны, кики, предупреждения, внутриигровое меню наказаний, сохраняемые записи о санкциях и принудительное применение при входе. Проект подходит операторам многопользовательского Minecraft и разработчикам античита, которым нужны интегрированная модерация и обнаружение хаков в сети на базе Paper.
