VMProtect Emulator and Memory Dumper는 VMProtect 3.x로 보호된 x86_64 Windows PE 실행 파일과 DLL을 에뮬레이트하여 원래 진입점에 도달하고 메모리에서 복호화된 코드와 데이터를 복구하는 샌드박스화된 Python 하네스입니다. Qiling 프레임워크와 Unicorn 엔진 위에 구축되었으며, 저장된 에뮬레이션 체크포인트에서 RAM 영역을 추출해 IDA Pro나 Ghidra에서 분석할 수 있는 동반 도구를 제공합니다. 에뮬레이터는 안티 디버그 검사, 안티 가상화, 펌웨어 및 SMBIOS 프로브, KnownDlls 무결성 스캔, 관련 시스템 호출 및 PEB 조작 등 광범위한 안티 분석 우회를 적용하여 강하게 보호된 샘플이 소프트웨어 에뮬레이션에서 끝까지 실행되도록 합니다. 별도의 스냅샷 덤퍼는 에뮬레이션 후 매핑된 섹션과 힙 데이터를 바이너리 이미지로 기록하며, 단순 패커형 보호뿐 아니라 VMProtect SDK 하에서 개별 함수가 가상화된 상태로 남는 경우도 지원합니다. 라이브 시스템에서 보호된 바이너리를 실행하지 않고 오프라인 언패킹과 메모리 포렌식이 필요한 리버스 엔지니어 및 멀웨어·소프트웨어 보호 연구자를 대상으로 합니다.
