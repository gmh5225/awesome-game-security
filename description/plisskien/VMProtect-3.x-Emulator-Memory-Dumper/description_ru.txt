VMProtect Emulator and Memory Dumper — это изолированный в песочнице Python-каркас, который эмулирует исполняемые файлы и DLL PE Windows x86_64, защищённые VMProtect 3.x, чтобы добраться до исходной точки входа и восстановить расшифрованный код и данные в памяти. Он построен на фреймворке Qiling и движке Unicorn; сопутствующие утилиты извлекают области RAM из сохранённых контрольных точек эмуляции для анализа в IDA Pro или Ghidra. Эмулятор применяет широкие обходы антианализа: проверки антиотладки, антивиртуализацию, опрос прошивки и SMBIOS, проверки целостности KnownDlls, а также связанные манипуляции с syscall и PEB, чтобы сильно защищённые образцы могли полностью выполняться в программной эмуляции. Отдельный дампер снимков записывает отображённые секции и данные кучи в виде бинарных образов после эмуляции — как для простой packer-подобной защиты, так и когда отдельные функции остаются виртуализированными под SDK VMProtect. Ориентирован на специалистов по реверс-инжинирингу и исследователей вредоносного ПО и защиты программ, которым нужна офлайн-распаковка и криминалистика памяти без запуска защищённых бинарников на живой системе.
