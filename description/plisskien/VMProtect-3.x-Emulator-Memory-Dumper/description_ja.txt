VMProtect Emulator and Memory Dumper は、VMProtect 3.x で保護された x86_64 Windows PE 実行ファイルおよび DLL をエミュレートし、元のエントリポイントに到達してメモリ上の復号済みコードとデータを回収するサンドボックス化された Python ハーネスです。Qiling フレームワークと Unicorn エンジン上に構築され、保存したエミュレーションチェックポイントから RAM 領域を抽出し、IDA Pro や Ghidra で解析するための付帯ツールも備えています。エミュレータはアンチデバッグ、仮想化検知回避、ファームウェアおよび SMBIOS プローブ、KnownDlls 整合性スキャン、関連するシステムコールや PEB 操作など幅広いアンチ解析バイパスを適用し、強固に保護されたサンプルをソフトウェアエミュレーションで完了まで実行できます。別のスナップショットダンパーはエミュレーション後にマップ済みセクションとヒープデータをバイナリイメージとして書き出し、単純なパッカー型保護に加え、VMProtect SDK 下で個別関数が仮想化されたままのケースにも対応します。ライブシステム上で保護バイナリを実行せずにオフラインアンパックとメモリフォレンジックが必要なリバースエンジニアやマルウェア・ソフトウェア保護研究者向けです。
