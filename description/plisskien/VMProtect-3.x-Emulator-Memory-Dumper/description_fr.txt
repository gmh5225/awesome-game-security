VMProtect Emulator and Memory Dumper est un harnais Python en bac à sable qui émule des exécutables et DLL PE Windows x86_64 protégés par VMProtect 3.x afin d’atteindre le point d’entrée d’origine et de récupérer le code et les données déchiffrés en mémoire. Il repose sur le framework Qiling et le moteur Unicorn, avec des outils associés pour extraire des régions RAM à partir de points de contrôle d’émulation sauvegardés, en vue d’une analyse dans IDA Pro ou Ghidra. L’émulateur applique de larges contournements anti-analyse couvrant les vérifications anti-débogage, l’anti-virtualisation, les sondes firmware et SMBIOS, les scans d’intégrité KnownDlls, ainsi que les manipulations de syscalls et du PEB connexes, afin que des échantillons fortement protégés puissent s’exécuter jusqu’au bout en émulation logicielle. Un dumper de snapshots distinct écrit les sections mappées et les données de tas en images binaires après l’émulation, pour la protection de type packer simple comme pour les cas où des fonctions restent virtualisées sous le SDK VMProtect. Il s’adresse aux ingénieurs en rétro-ingénierie et aux chercheurs en logiciels malveillants ou en protection logicielle qui ont besoin de déballage hors ligne et de forensic mémoire sans exécuter des binaires protégés sur un système vivant.
