VMProtect Emulator and Memory Dumper is a sandboxed Python harness that emulates x86_64 Windows PE executables and DLLs protected with VMProtect 3.x to reach the original entry point and recover decrypted code and data in memory. It is built on the Qiling framework and Unicorn engine, with companion tooling to extract RAM regions from saved emulation checkpoints for analysis in IDA Pro or Ghidra. The emulator applies broad anti-analysis bypasses covering anti-debug checks, anti-virtualization, firmware and SMBIOS probes, KnownDlls integrity scans, and related syscall and PEB manipulations so heavily protected samples can run to completion in software emulation. A separate snapshot dumper writes mapped sections and heap data as binary images after emulation, supporting both simple packer-style protection and cases where individual functions remain virtualized under the VMProtect SDK. It is aimed at reverse engineers and malware or software protection researchers who need offline unpacking and memory forensics without executing protected binaries on a live system.
