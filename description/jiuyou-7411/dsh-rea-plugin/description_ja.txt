DeepSeek Harness 向けプラグインで、REA リバースエンジニアリングエージェントスタックを Web UI 付きの中国語ワークベンチに変換し、ツールの閲覧と実行を行えます。主に JavaScript と Node.js で実装され、上流の rea-agents 由来の二百以上の MCP ツールを橋渡しし、オフライン文書とエージェントスキルを同梱するため、追加のプロファイル設定なしで分析ワークフローが利用できます。JADX、apktool、展開、Frida による計装での Android APK 作業、オプションの Ghidra 連携によるネイティブバイナリ、反注入チェックや SO 解析などモバイル向けヘルパーや関連スクリプトに対応します。ダッシュボードは健全性、ツール利用状況、ローカライズされたエラー説明を追跡し、パネルから Ghidra、JDK、Frida などの分析エンジンをインストール・管理できます。生の REA コマンドラインだけでなく、AI harness 内でガイド付き・エージェント支援のバイナリおよびモバイルアプリ分析を求めるセキュリティ研究者とリバースエンジニア向けです。
