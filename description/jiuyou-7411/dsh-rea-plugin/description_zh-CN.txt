这是一款 DeepSeek Harness 插件，将 REA 逆向工程智能体栈整合为带 Web 界面的中文工作台，便于浏览和运行工具。实现以 JavaScript 与 Node.js 为主，桥接上游 rea-agents 提供的两百余个 MCP 工具，并内置离线文档与智能体技能，无需额外配置 profile 即可开展分析工作流。功能涵盖通过 JADX、apktool、解包与 Frida 插桩处理 Android APK，借助可选 Ghidra 集成分析原生二进制，以及面向移动端的反注入检测、SO 分析与相关脚本等辅助能力。仪表盘可监控健康状态、工具使用情况并提供本地化错误说明，还可在面板中安装或管理 Ghidra、JDK、Frida 等分析引擎。面向希望在 AI harness 中获得引导式、智能体辅助的二进制与移动应用分析，而非仅使用 REA 命令行的安全研究人员与逆向工程师。
