這是一款 DeepSeek Harness 外掛，將 REA 逆向工程智能體堆疊整合為附 Web 介面的中文工作台，方便瀏覽與執行工具。實作以 JavaScript 與 Node.js 為主，橋接上游 rea-agents 提供的兩百餘個 MCP 工具，並內建離線文件與智能體技能，無需額外設定 profile 即可進行分析工作流。功能涵蓋透過 JADX、apktool、解包與 Frida 插樁處理 Android APK，可選 Ghidra 整合分析原生二進位，以及面向行動端的反注入檢測、SO 分析與相關腳本等輔助能力。儀表板可監控健康狀態、工具使用情況並提供在地化錯誤說明，亦可在面板中安裝或管理 Ghidra、JDK、Frida 等分析引擎。面向希望在 AI harness 中獲得引導式、智能體輔助的二進位與行動應用分析，而非僅使用 REA 命令列的安全研究人員與逆向工程師。
