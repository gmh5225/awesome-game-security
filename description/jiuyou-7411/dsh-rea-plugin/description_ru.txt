Плагин для DeepSeek Harness, превращающий стек агентов REA для реверс-инжиниринга в китайоязычный рабочий стол с веб-интерфейсом для просмотра и запуска инструментов. Реализован в основном на JavaScript и Node.js, связывает более двухсот MCP-инструментов из upstream rea-agents и включает офлайн-документацию и навыки агентов, чтобы рабочие процессы анализа работали без дополнительной настройки профиля. Возможности охватывают работу с Android APK через JADX, apktool, распаковку и инструментирование Frida, нативные бинарники через опциональную интеграцию Ghidra, а также мобильные помощники для проверок anti-injection, анализа SO и связанных скриптов. Панель отслеживает состояние, использование инструментов и локализованные пояснения ошибок и может устанавливать или управлять движками анализа вроде Ghidra, JDK и Frida из интерфейса. Ориентирован на исследователей безопасности и реверс-инженеров, которым нужен направляемый анализ бинарников и мобильных приложений с помощью агентов в AI harness, а не только REA в командной строке.
