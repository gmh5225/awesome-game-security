This is a DeepSeek Harness plugin that turns the REA reverse-engineering agent stack into a Chinese-language workbench with a web UI for browsing and running tools. It is implemented mainly in JavaScript and Node.js, bridges more than two hundred MCP tools from upstream rea-agents, and bundles offline documentation plus agent skills so analysis workflows work without extra profile setup. Capabilities cover Android APK work through JADX, apktool, unpacking, and Frida instrumentation, native binaries via optional Ghidra integration, and mobile-focused helpers for anti-injection checks, SO analysis, and related scripts. The dashboard tracks health, tool usage, and localized error explanations, and can install or manage analysis engines such as Ghidra, JDK, and Frida from the panel. It targets security researchers and reverse engineers who want guided, agent-assisted binary and mobile app analysis inside an AI harness rather than raw command-line REA alone.
