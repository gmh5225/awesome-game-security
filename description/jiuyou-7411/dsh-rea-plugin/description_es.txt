Plugin de DeepSeek Harness que convierte la pila de agentes REA de ingeniería inversa en un banco de trabajo en chino con interfaz web para explorar y ejecutar herramientas. Implementado principalmente en JavaScript y Node.js, enlaza más de doscientas herramientas MCP de rea-agents upstream e incluye documentación offline y habilidades de agente para flujos de análisis sin configurar perfiles extra. Las capacidades abarcan APK Android con JADX, apktool, desempaquetado e instrumentación Frida, binarios nativos mediante integración opcional con Ghidra, y ayudas orientadas a móvil para comprobaciones anti-inyección, análisis SO y scripts relacionados. El panel sigue el estado, el uso de herramientas y explicaciones de error localizadas, y puede instalar o gestionar motores de análisis como Ghidra, JDK y Frida desde el panel. Está dirigido a investigadores de seguridad e ingenieros inversos que quieren análisis guiado y asistido por agentes de binarios y apps móviles dentro de un harness de IA en lugar de REA solo por línea de comandos.
