BedrockGuard は、Geyser と Floodgate 経由で Java Paper または Folia サーバーに接続する Bedrock Edition プレイヤー向けに最適化したアンチチート検知を提供する Minecraft サーバープラグインです。従来の Java 向けアンチチートと併用し、Floodgate 連携の Bedrock クライアントにのみ適用されます。これらのクライアントは移動、タッチ操作、パケットタイミングが Java と大きく異なるため、Java 中心のチェックでは免除されたり誤検知が起きやすいです。プラグインはタイマー、スピード、フライ、リーチ、nuker、scaffold、オートクリッカー、不正パケット、velocity、キルオーラなどのチェックを実装し、違反レベルは時間経過で減衰し、ゲーム内スタッフアラート、任意の Discord Webhook、設定可能な処罰を備えます。Floodgate、PacketEvents、Geyser（サーバー上、または Velocity や BungeeCord の背後）に依存し、違反のキャンセルや監視のための開発者 API を公開し、クロスプレイネットワークで実用的な Bedrock 向けゲームセキュリティを必要とするサーバー運営者を対象としています。
