BedrockGuard 是一款 Minecraft 伺服器外掛，針對透過 Geyser 與 Floodgate 連線至 Java Paper 或 Folia 伺服器的基岩版玩家，提供量身打造的反作弊偵測。它與一般 Java 反作弊並行運作，僅套用於經 Floodgate 連結的基岩用戶端；這些用戶端的移動、觸控操作與封包時序與 Java 差異甚大，以 Java 為中心的檢查常對其豁免或產生誤判。外掛實作計時器、速度、飛行、攻擊距離、nuker、鷹架、自動連點、異常封包、速度修正與杀戮光環等檢查，違規等級會隨時間衰減，並提供遊戲內管理員警示、可選的 Discord Webhook 與可設定的懲處。它依賴 Floodgate、PacketEvents 與 Geyser（部署在伺服器上或位於 Velocity、BungeeCord 之後），公開供開發者取消或觀察違規的 API，目標對象是在跨平台網路中需要實用、以基岩版為重點的遊戲安全方案的伺服器營運者。
