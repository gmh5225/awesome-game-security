BedrockGuard 是一款 Minecraft 服务器插件，面向通过 Geyser 与 Floodgate 接入 Java Paper 或 Folia 服务器的基岩版玩家，提供针对性的反作弊检测。它与常规 Java 反作弊并行运行，仅作用于经 Floodgate 关联的基岩客户端；这些客户端的移动、触控操作与数据包时序与 Java 差异较大，以 Java 为中心的检测往往对其豁免或产生误报。插件实现计时器、速度、飞行、攻击距离、nuker、脚手架、自动连点、异常数据包、velocity 与 kill aura等检测，违规等级会随时间衰减，并支持游戏内管理员告警、可选 Discord Webhook 与可配置的处罚。它依赖 Floodgate、PacketEvents 与 Geyser（部署在服务器上或位于 Velocity、BungeeCord 之后），提供用于取消或观察违规的开发者 API，面向在跨平台网络中需要实用、以基岩版为重点的游戏安全方案的服务器运营者。
