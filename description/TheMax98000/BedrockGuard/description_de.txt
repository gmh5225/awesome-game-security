BedrockGuard ist ein Minecraft-Server-Plugin, das Anti-Cheat-Erkennung speziell für Bedrock-Edition-Spieler bietet, die über Geyser und Floodgate an Java-Paper- oder Folia-Servern anbinden. Es läuft parallel zu herkömmlichen Java-Anti-Cheats und gilt nur für über Floodgate verknüpfte Bedrock-Clients, deren Bewegung, Touch-Steuerung und Paket-Timing so stark von Java abweichen, dass Java-zentrierte Prüfungen sie oft ausnehmen oder Fehlalarme erzeugen. Das Plugin implementiert Checks wie Timer, Speed, Fly, Reach, Nuker, Scaffold, Autoclicker, Bad Packets, Velocity und Kill Aura, mit Verstoßstufen die mit der Zeit abklingen, Ingame-Staff-Alerts, optionalen Discord-Webhooks und konfigurierbaren Strafen. Es setzt Floodgate, PacketEvents und Geyser voraus (auf dem Server oder hinter Velocity oder BungeeCord), stellt eine Entwickler-API zum Abbrechen oder Beobachten von Verstößen bereit und richtet sich an Serverbetreiber, die praktische, auf Bedrock fokussierte Spielsicherheit in Cross-Play-Netzwerken brauchen.
