BedrockGuard는 Geyser와 Floodgate를 통해 Java Paper 또는 Folia 서버에 접속하는 Bedrock Edition 플레이어에 맞춘 안티치트 탐지를 제공하는 Minecraft 서버 플러그인입니다. 기존 Java 안티치트와 함께 동작하며 Floodgate에 연결된 Bedrock 클라이언트에만 적용됩니다. 이 클라이언트의 이동, 터치 조작, 패킷 타이밍은 Java와 충분히 달라 Java 중심 검사에서는 면제되거나 오탐이 자주 발생합니다. 플러그인은 타이머, 스피드, 플라이, 리치, nuker, scaffold, 오토클리커, 잘못된 패킷, velocity, 킬 오라 등의 검사를 구현하며, 위반 수준은 시간이 지나면 감쇠하고, 게임 내 스태프 알림, 선택적 Discord 웹훅, 설정 가능한 처벌을 제공합니다. Floodgate, PacketEvents, Geyser(서버에 직접 두거나 Velocity·BungeeCord 뒤)에 의존하며, 위반 취소·관찰용 개발자 API를 노출하고, 크로스플레이 네트워크에서 실용적인 Bedrock 중심 게임 보안이 필요한 서버 운영자를 대상으로 합니다.
