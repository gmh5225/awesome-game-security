BedrockGuard is a Minecraft server plugin that provides anti-cheat detection tailored to Bedrock Edition players connecting through Geyser and Floodgate on Java Paper or Folia servers. It runs alongside conventional Java anti-cheats and applies only to Floodgate-linked Bedrock clients, whose movement, touch controls, and packet timing differ enough that Java-centric checks often exempt them or produce false positives. The plugin implements checks such as timer, speed, fly, reach, nuker, scaffold, autoclicker, bad packets, velocity, and kill aura, with violation levels that decay over time, in-game staff alerts, optional Discord webhooks, and configurable punishments. It depends on Floodgate, PacketEvents, and Geyser (on the server or behind Velocity or BungeeCord), exposes a developer API for canceling or observing violations, and targets server operators who need practical Bedrock-focused game security on cross-play networks.
