BedrockGuard es un complemento de servidor Minecraft que ofrece detección antitrampas adaptada a jugadores de Bedrock Edition que se conectan mediante Geyser y Floodgate en servidores Java Paper o Folia. Funciona junto a antitrampas Java convencionales y solo se aplica a clientes Bedrock vinculados a Floodgate, cuyo movimiento, controles táctiles y temporización de paquetes difieren lo suficiente para que las comprobaciones centradas en Java a menudo los eximan o generen falsos positivos. El complemento implementa comprobaciones como timer, speed, fly, reach, nuker, scaffold, autoclicker, bad packets, velocity y kill aura, con niveles de infracción que decaen con el tiempo, alertas al staff en el juego, webhooks opcionales de Discord y castigos configurables. Depende de Floodgate, PacketEvents y Geyser (en el servidor o detrás de Velocity o BungeeCord), expone una API para desarrolladores para cancelar u observar infracciones, y está dirigido a operadores de servidores que necesitan seguridad de juego práctica centrada en Bedrock en redes cross-play.
