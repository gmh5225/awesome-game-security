BedrockGuard è un plugin per server Minecraft che offre rilevamento anti-cheat su misura per i giocatori Bedrock Edition che si connettono tramite Geyser e Floodgate su server Java Paper o Folia. Funziona insieme agli anti-cheat Java convenzionali e si applica solo ai client Bedrock collegati a Floodgate, il cui movimento, controlli touch e tempistica dei pacchetti differiscono abbastanza da far sì che i controlli incentrati su Java spesso li esentino o producano falsi positivi. Il plugin implementa controlli come timer, speed, fly, reach, nuker, scaffold, autoclicker, bad packets, velocity e kill aura, con livelli di violazione che decadono nel tempo, avvisi allo staff in gioco, webhook Discord opzionali e punizioni configurabili. Dipende da Floodgate, PacketEvents e Geyser (sul server o dietro Velocity o BungeeCord), espone un’API per sviluppatori per annullare o osservare le violazioni, ed è rivolto agli operatori di server che necessitano di sicurezza di gioco pratica focalizzata su Bedrock in reti cross-play.
