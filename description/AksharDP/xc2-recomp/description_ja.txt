XC2 Recomp は、ゼノブレイドクロス 2 の Nintendo Switch ARM64 バイナリを静的再コンパイルし、Vulkan ベースのグラフィックススタックを備えたネイティブ Windows x86-64 アプリケーションに変換する。Python ツールチェーンが Switch の NSO モジュールを生成 C コードへリフトし、Unicorn エミュレータとの差分テストで挙動を検証し、対応ゲームアップデート向けにバージョン固有のバイナリパッチを適用する。C ランタイムは Switch カーネルサービス、NVN グラフィックス、オーディオ、入力、ファイルシステムアクセスのホスト置換を実装し、ユーザー提供のダンプから構築する任意の mod およびチートオーバーレイも備える。Python インストーラーは、ユーザーが合法に入手した NSP ファイルとキーからポートをビルドする手順を案内する。リバースエンジニア、移植研究者、およびフルエミュレータなしで商用 Switch タイトルを PC ネイティブ実行へ移す仕組みを学ぶファンを対象とする。
