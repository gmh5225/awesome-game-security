XC2 Recomp ricompila staticamente Xenoblade Chronicles 2 dai binari ARM64 di Nintendo Switch in un’applicazione nativa Windows x86-64 con stack grafico basato su Vulkan. Una toolchain Python solleva i moduli NSO Switch in C generato, convalida il comportamento con test differenziali contro l’emulatore Unicorn e applica patch binarie specifiche per versione agli aggiornamenti di gioco supportati. Il runtime C implementa sostituti host per i servizi kernel Switch, grafica NVN, audio, input, accesso al filesystem e overlay opzionali di mod e cheat costruiti da dump forniti dall’utente. Un installer Python guida gli utenti nella compilazione del port dalle proprie file NSP e chiavi ottenute legalmente. È rivolto a reverse engineer, ricercatori di porting e appassionati che studiano come titoli Switch commerciali possano essere tradotti in esecuzione nativa su PC senza un emulatore completo.
