XC2 Recomp recompila estáticamente Xenoblade Chronicles 2 desde binarios ARM64 de Nintendo Switch en una aplicación nativa Windows x86-64 con una pila gráfica basada en Vulkan. Una cadena de herramientas Python eleva los módulos NSO de Switch a C generado, valida el comportamiento con pruebas diferenciales contra el emulador Unicorn y aplica parches binarios específicos de versión para actualizaciones de juego compatibles. El runtime en C implementa reemplazos en el host para servicios del kernel Switch, gráficos NVN, audio, entrada, acceso al sistema de archivos y superposiciones opcionales de mods y trucos construidas a partir de volcados proporcionados por el usuario. Un instalador en Python guía a los usuarios para construir el port desde sus propios archivos NSP y claves obtenidos legalmente. Está dirigido a ingenieros inversos, investigadores de porting y aficionados que estudian cómo títulos comerciales de Switch pueden traducirse a ejecución nativa en PC sin un emulador completo.
