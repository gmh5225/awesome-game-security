XC2 Recomp statically recompiles Xenoblade Chronicles 2 from Nintendo Switch ARM64 binaries into a native Windows x86-64 application with a Vulkan-based graphics stack. A Python toolchain lifts Switch NSO modules to generated C, validates behavior with differential tests against the Unicorn emulator, and applies version-specific binary patches for supported game updates. The C runtime implements host replacements for Switch kernel services, NVN graphics, audio, input, filesystem access, and optional mod and cheat overlays built from user-supplied dumps. A Python installer guides users through building the port from their own legally obtained NSP files and keys. It targets reverse engineers, porting researchers, and fans studying how commercial Switch titles can be translated to PC-native execution without a full emulator.
