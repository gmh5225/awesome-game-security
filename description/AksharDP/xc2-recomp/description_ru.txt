XC2 Recomp статически перекомпилирует Xenoblade Chronicles 2 из ARM64-бинарников Nintendo Switch в нативное приложение Windows x86-64 с графическим стеком на базе Vulkan. Python-инструментарий поднимает модули NSO Switch в сгенерированный C, проверяет поведение дифференциальными тестами против эмулятора Unicorn и применяет версионные бинарные патчи для поддерживаемых обновлений игры. Среда выполнения на C реализует хост-замены для служб ядра Switch, графики NVN, аудио, ввода, доступа к файловой системе и необязательные оверлеи модов и читов, собранные из дампов пользователя. Python-установщик проводит пользователей через сборку порта из собственных легально полученных файлов NSP и ключей. Проект ориентирован на reverse-инженеров, исследователей портирования и энтузиастов, изучающих, как коммерческие Switch-игры можно перевести на нативное PC-выполнение без полноценного эмулятора.
