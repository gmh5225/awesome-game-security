Disrobe — модульная платформа на Rust для распаковки, анализа и восстановления читаемого кода из защищённых и обфусцированных бинарных файлов. Архитектура на основе crate охватывает широкий спектр бинарных и контейнерных форматов, с отдельными проходами для нативных PE-пакеров, Python-защит вроде PyArmor и PyInstaller, мобильных APK, WebAssembly, JVM, .NET, Go, Erlang/BEAM, JavaScript и множества типов архивов. Проект интегрируется с Ghidra для рабочих процессов распаковки и декомпиляции, предоставляет привязки для Python и TypeScript и включает бенчмарк-обвязки, оценивающие качество восстановления на обширных корпусах тестовых образцов. Он ориентирован на специалистов по реверс-инжинирингу, аналитиков вредоносного ПО и исследователей безопасности, которым нужно снимать пакеры, деобфусцировать байткод и восстанавливать логику из усиленных исполняемых файлов.
