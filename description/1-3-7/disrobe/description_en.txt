Disrobe is a Rust-based modular platform for unpacking, analyzing, and recovering readable code from protected and obfuscated binaries. Its crate architecture covers broad binary and container formats, with specialized passes for native PE packers, Python protections such as PyArmor and PyInstaller, mobile APKs, WebAssembly, JVM, .NET, Go, Erlang/BEAM, JavaScript, and many archive types. The project integrates with Ghidra for unpack and decompile workflows, ships Python and TypeScript bindings, and includes benchmark harnesses that grade recovery quality against extensive fixture corpora. It targets reverse engineers, malware analysts, and security researchers who need to strip packers, deobfuscate bytecode, and reconstruct logic from hardened executables.
