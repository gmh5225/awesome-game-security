Disrobe는 Rust 기반의 모듈형 플랫폼으로, 보호되고 난독화된 바이너리를 언패킹·분석하고 읽을 수 있는 코드를 복구합니다. crate 아키텍처는 다양한 바이너리 및 컨테이너 형식을 포괄하며, 네이티브 PE 패커, PyArmor·PyInstaller 같은 Python 보호 기법, 모바일 APK, WebAssembly, JVM, .NET, Go, Erlang/BEAM, JavaScript, 다수의 아카이브 형식을 위한 전용 처리 단계를 제공합니다. 이 프로젝트는 Ghidra와 연동해 언패킹 및 디컴파일 워크플로를 지원하고, Python·TypeScript 바인딩을 제공하며, 방대한 픽스처 코퍼스를 기준으로 복구 품질을 평가하는 벤치마크 하네스를 포함합니다. 패커 제거, 바이트코드 난독화 해제, 강화된 실행 파일에서 로직을 재구성해야 하는 리버스 엔지니어, 멀웨어 분석가, 보안 연구자를 대상으로 합니다.
