Disrobe は Rust ベースのモジュラー型プラットフォームで、保護された難読化バイナリの展開、解析、および可読コードの復元を行います。crate アーキテクチャは幅広いバイナリおよびコンテナ形式をカバーし、ネイティブ PE パッカー、PyArmor や PyInstaller などの Python 保護、モバイル APK、WebAssembly、JVM、.NET、Go、Erlang/BEAM、JavaScript、多数のアーカイブ形式向けの専用パスを備えています。本プロジェクトは Ghidra と連携して展開・逆コンパイルのワークフローを実現し、Python および TypeScript バインディングを提供し、大規模なフィクスチャコーパスに対する復元品質を評価するベンチマークハーネスも同梱しています。パッカーの除去、バイトコードの難読化解除、ハード化された実行ファイルからのロジック再構築が必要なリバースエンジニア、マルウェア解析者、セキュリティ研究者を対象としています。
