Disrobe 是一个基于 Rust 的模块化平台，用于解包、分析并从受保护及混淆的二进制文件中恢复可读代码。其 crate 架构覆盖广泛的二进制与容器格式，并针对原生 PE 加壳器、PyArmor 与 PyInstaller 等 Python 保护方案、移动 APK、WebAssembly、JVM、.NET、Go、Erlang/BEAM、JavaScript 以及多种归档类型提供专用处理流程。该项目与 Ghidra 集成以支持解包与反编译工作流，提供 Python 与 TypeScript 绑定，并包含基准测试框架，可依据大量测试样本语料评估恢复质量。它面向需要剥离加壳、去混淆字节码并从加固可执行文件中重建逻辑的反汇编工程师、恶意软件分析师与安全研究人员。
