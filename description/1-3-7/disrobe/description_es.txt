Disrobe es una plataforma modular basada en Rust para desempaquetar, analizar y recuperar código legible a partir de binarios protegidos y ofuscados. Su arquitectura de crates abarca una amplia gama de formatos binarios y de contenedores, con pasadas especializadas para packers PE nativos, protecciones de Python como PyArmor y PyInstaller, APK móviles, WebAssembly, JVM, .NET, Go, Erlang/BEAM, JavaScript y numerosos tipos de archivos. El proyecto se integra con Ghidra para flujos de desempaquetado y descompilación, incluye enlaces para Python y TypeScript, y ofrece marcos de evaluación que califican la calidad de recuperación frente a amplios corpus de fixtures. Está dirigido a ingenieros de ingeniería inversa, analistas de malware e investigadores de seguridad que necesitan eliminar packers, desofuscar bytecode y reconstruir la lógica de ejecutables endurecidos.
