Disrobe 是一個以 Rust 為基礎的模組化平台，用於解包、分析並從受保護及混淆的二進位檔中還原可讀程式碼。其 crate 架構涵蓋廣泛的二進位與容器格式，並針對原生 PE 加殼器、PyArmor 與 PyInstaller 等 Python 保護方案、行動 APK、WebAssembly、JVM、.NET、Go、Erlang/BEAM、JavaScript 以及多種封存類型提供專用處理流程。此專案與 Ghidra 整合以支援解包與反編譯工作流程，提供 Python 與 TypeScript 繫結，並包含基準測試框架，可依據大量測試樣本語料評估還原品質。它面向需要剝除加殼、去混淆位元組碼並從加固可執行檔重建邏輯的逆向工程師、惡意軟體分析師與安全研究人員。
