CTTrainer — это автономный игровой тренер для Windows, который загружает табличные файлы .CT из Cheat Engine и применяет их читы к любому подключённому игровому процессу. Написан на C++ как проект Visual Studio, он использует ImGui с DirectX 11 и Win32 для графического интерфейса просмотра CT-файлов, подключения к 32- или 64-разрядным целям, а также просмотра и изменения значений памяти в реальном времени. Инструмент разбирает XML-записи читов с смещениями модулей и цепочками указателей, разрешает адреса через выделенный слой памяти и поддерживает заморозку отдельных или множества значений через фоновые потоки, управляемые менеджером читов. Он предназначен для реверс-инженеров, исследователей игровой безопасности и авторов тренеров, которые хотят превратить результаты сканирования Cheat Engine в многоразовый внешний тренер без запуска самого Cheat Engine.
