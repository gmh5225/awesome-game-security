CTTrainer 是一款独立的 Windows 游戏修改器，可加载 Cheat Engine 的 .CT 表文件，并将其中的作弊项应用到任意已附加的游戏进程。该项目使用 C++ 编写，基于 Visual Studio，通过 ImGui 配合 DirectX 11 和 Win32 提供图形界面，用于浏览 CT 文件、附加到 32 位或 64 位目标进程，以及查看或修改实时内存数值。该工具解析包含模块偏移和指针链的 XML 作弊条目，通过专用内存层解析地址，并支持由作弊管理器通过后台线程进行单项或批量数值冻结。它面向逆向工程师、游戏安全研究人员和修改器作者，帮助他们在不运行 Cheat Engine 本身的情况下，将 Cheat Engine 的扫描结果转化为可复用的外部修改器。
