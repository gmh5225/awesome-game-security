CTTrainer は、Cheat Engine の .CT テーブルファイルを読み込み、チートを任意の接続済みゲームプロセスに適用するスタンドアロンの Windows ゲームトレーナーです。C++ で Visual Studio プロジェクトとして書かれており、ImGui と DirectX 11、Win32 を用いて CT ファイルの閲覧、32 ビットまたは 64 ビットターゲットへの接続、ライブメモリ値の確認や変更を行うグラフィカルインターフェースを提供します。このツールはモジュールオフセットとポインタチェーンを含む XML チートエントリを解析し、専用のメモリレイヤーでアドレスを解決し、チートマネージャーが管理するバックグラウンドスレッドによる個別または一括の値フリーズをサポートします。Cheat Engine 自体を実行せずに、Cheat Engine のスキャン結果を再利用可能な外部トレーナーに変えたいリバースエンジニア、ゲームセキュリティ研究者、トレーナー作者を対象としています。
