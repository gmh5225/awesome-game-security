DashFile is a portable Windows desktop application for managing Android phones over USB without installing anything on the device, using built-in ADB and optional root access. It combines a file explorer, Magisk/KernelSU/APatch module installer, bulk app management, and detailed device and root-implementation diagnostics in one Avalonia-based UI built on .NET 8. The host ships self-developed parsers and viewers for AXML, resources.arsc, DEX, APK signatures, compressed archives, and AVB, plus a hot-pluggable .dfp plugin API for extensions such as AVB resigning workflows. It suits Android modding, mobile reverse engineering, and game-security research where analysts need deep filesystem access, module control, and on-device artifact inspection from a PC.
