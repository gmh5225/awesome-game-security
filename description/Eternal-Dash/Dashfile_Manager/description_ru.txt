DashFile — портативное настольное приложение для Windows, управляющее Android-телефонами по USB без установки чего-либо на устройство, с встроенным ADB и опциональным root-доступом. Оно объединяет проводник файлов, установщик модулей Magisk/KernelSU/APatch, массовое управление приложениями и подробную диагностику устройства и реализации root в одном интерфейсе на Avalonia и .NET 8. На стороне ПК поставляются собственные парсеры и просмотрщики для AXML, resources.arsc, DEX, подписей APK, сжатых архивов и AVB, а также API горячеподключаемых плагинов .dfp для расширений вроде рабочих процессов переподписи AVB. Подходит для моддинга Android, мобильной reverse engineering и исследований безопасности игр, когда аналитикам нужен глубокий доступ к файловой системе, контроль модулей и осмотр артефактов на устройстве с ПК.
