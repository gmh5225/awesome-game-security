Medal Overlay Framework(MOF)은 Medal.tv의 화이트리스트 오버레이 창을 통해 사용자 정의 그리기를 라우팅하여, 시각 효과가 안티치트에 Medal 자체의 일부로 보이게 하는 은밀한 인게임 오버레이 시스템입니다. Node.js 패처가 Medal의 Electron 애플리케이션을 수정해 이름 지정 파이프 서버가 있는 브리지를 주입하고, Python 및 C++ SDK가 연결해 JSON 그리기 명령을 보내면 주입된 JavaScript와 .NET 헬퍼가 오버레이 캔버스에서 실행합니다. ESP 박스, 십자선, 스냅 라인, 스켈레톤 렌더링, 그라데이션, 애니메이션, 레이어 합성, 토글과 슬라이더가 있는 대화형 탭 메뉴 등 풍부한 프리미티브와 게임 지향 위젯을 제공합니다. 은밀성 설계에는 하드웨어 기반 파이프 이름, asar 패키지 내 무해한 파일, 난독화된 전역 변수, 레거시 패치 정리가 포함됩니다. EAC, BattlEye, Vanguard 등 보호 기법에 대해 신뢰된 서드파티 캡처 오버레이가 렌더링 표면으로 악용될 수 있는 방식을 연구하는 게임 보안 연구자와 오버레이 제작자를 대상으로 합니다.
