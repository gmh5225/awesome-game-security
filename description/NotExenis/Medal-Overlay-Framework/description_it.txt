Medal Overlay Framework (MOF) è un sistema di overlay in-game stealth che instrada il disegno personalizzato attraverso la finestra overlay in whitelist di Medal.tv, così che i visuali appaiano all’anti-cheat come parte di Medal stesso. Un patcher Node.js modifica l’applicazione Electron di Medal per iniettare un bridge con server named pipe; gli SDK Python e C++ si connettono e inviano comandi di disegno JSON eseguiti sulla canvas dell’overlay tramite JavaScript iniettato e un helper .NET. Offre primitive ricche e widget orientati al gioco: box ESP, mirini, linee di aggancio, rendering scheletrico, gradienti, animazioni, compositing a livelli e un menu a schede interattivo con toggle e slider. Scelte progettuali orientate allo stealth includono nomi pipe derivati dall’hardware, file innocui nel pacchetto asar, globali offuscati e pulizia di patch legacy. È rivolto a ricercatori di sicurezza dei giochi e autori di overlay che studiano come overlay di cattura di terze parti fidate possano essere abusati come superficie di rendering contro EAC, BattlEye, Vanguard e protezioni simili.
