Medal Overlay Framework (MOF) — скрытая внутриигровая система оверлея, которая направляет пользовательскую отрисовку через окно оверлея Medal.tv из белого списка, чтобы визуал выглядел для античита частью самого Medal. Патчер на Node.js изменяет Electron-приложение Medal и внедряет мост с сервером именованного канала; SDK на Python и C++ подключаются и отправляют JSON-команды отрисовки, выполняемые на холсте оверлея через внедрённый JavaScript и .NET-вспомогательный модуль. Предоставляет богатые примитивы и игровые виджеты: ESP-боксы, прицелы, линии привязки, отрисовку скелета, градиенты, анимации, послойную композицию и интерактивное меню с вкладками, переключателями и ползунками. Скрытность обеспечивают имена каналов на основе железа, безобидные файлы в пакете asar, обфусцированные глобалы и очистка устаревших патчей. Ориентирован на исследователей игровой безопасности и авторов оверлеев, изучающих, как доверенные сторонние оверлеи захвата могут использоваться как поверхность отрисовки против EAC, BattlEye, Vanguard и подобных защит.
