Medal Overlay Framework (MOF) is a stealth in-game overlay system that routes custom drawing through Medal.tv’s whitelisted overlay window so visuals can appear to anti-cheat as part of Medal itself. A Node.js patcher modifies Medal’s Electron application to inject a bridge with a named-pipe server; Python and C++ SDKs connect and send JSON draw commands that execute on the overlay’s canvas via injected JavaScript and a .NET helper. It provides rich primitives and game-oriented widgets including ESP boxes, crosshairs, snap lines, skeleton rendering, gradients, animations, layered compositing, and an interactive tabbed menu system with toggles and sliders. Stealth-oriented design choices include hardware-derived pipe names, innocuous files inside the asar package, obfuscated globals, and cleanup of legacy patches. It targets game security researchers and overlay authors studying how trusted third-party capture overlays can be abused as a rendering surface against EAC, BattlEye, Vanguard, and similar protections.
