Medal Overlay Framework（MOF）は、Medal.tv のホワイトリスト登録オーバーレイウィンドウ経由でカスタム描画をルーティングし、視覚をアンチチートから Medal 本体の一部に見せかけるステルス型のゲーム内オーバーレイシステムです。Node.js のパッチャーが Medal の Electron アプリを改変し、名前付きパイプサーバ付きブリッジを注入します。Python および C++ SDK が接続して JSON 描画コマンドを送り、注入された JavaScript と .NET ヘルパーがオーバーレイのキャンバス上で実行します。ESP ボックス、クロスヘア、スナップライン、スケルトン描画、グラデーション、アニメーション、レイヤー合成、トグルとスライダー付きのタブ付きインタラクティブメニューなど、豊富なプリミティブとゲーム向けウィジェットを提供します。ステルス志向の設計として、ハードウェア由来のパイプ名、asar パッケージ内の無害なファイル、難読化されたグローバル、レガシーパッチのクリーンアップがあります。EAC、BattlEye、Vanguard などの保護に対し、信頼された第三者キャプチャオーバーレイがレンダリング面として悪用され得ることを研究するゲームセキュリティ研究者とオーバーレイ作者を対象としています。
