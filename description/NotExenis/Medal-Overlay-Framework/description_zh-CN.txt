Medal Overlay Framework（MOF）是一种隐蔽的游戏内叠加层系统，通过 Medal.tv 白名单叠加窗口路由自定义绘制，使视觉效果在反作弊眼中呈现为 Medal 本身的一部分。Node.js 补丁器修改 Medal 的 Electron 应用，注入带命名管道服务器的桥接层；Python 与 C++ SDK 连接后发送 JSON 绘制命令，由注入的 JavaScript 与 .NET 辅助程序在叠加层画布上执行。框架提供丰富的图元与面向游戏的控件，包括 ESP 方框、准星、引线、骨骼渲染、渐变、动画、分层合成，以及带开关与滑块的交互式分页菜单。面向隐蔽的设计包括基于硬件的管道名、asar 包内的无害文件、混淆的全局变量以及对旧补丁的清理。面向游戏安全研究人员与叠加层作者，研究可信第三方采集叠加层如何被滥用为针对 EAC、BattlEye、Vanguard 等防护的渲染面。
