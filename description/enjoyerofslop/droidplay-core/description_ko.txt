DroidPlay Core는 사용자가 직접 덤프한 Nintendo Switch 게임을 Android 앱으로 바꿔, 일반 에뮬레이터 안이 아니라 기기에서 해당 타이틀의 ARM 코드가 실행되도록 하는 네이티브 런타임입니다. Android 중심의 nxnative 엔진 분기로, 주로 C와 Java로 구현되며 Python 도구, Vulkan 기반 그래픽, 사용자가 제공하는 게임 빌드 파이프라인을 갖춥니다. 스택은 필요 시 Switch NSO 모듈을 재작성하고 Horizon 시스템 호출과 SDK 서비스를 에뮬레이션하며, 셰이더·패치·빌드별 수정에는 타이틀별 프로필을 적용합니다. arm64 Android 10 이상 하드웨어에서 합법적으로 덤프한 NSP 또는 XCI 콘텐츠를 다루는 플레이어와 연구자를 대상으로 하며, Switch 바이너리, 로딩, 플랫폼 구동에 대한 깊은 통찰을 리버스 엔지니어링 및 호환성 작업에 제공합니다.
