DroidPlay Core 是一種原生執行環境，可將您自行轉存任天堂 Switch 遊戲轉成 Android 應用程式，讓遊戲自身的 ARM 程式碼在裝置上直接執行，而非在傳統模擬器內運行。它是以 Android 為主的 nxnative 引擎分支，主要以 C 與 Java 實作，搭配 Python 工具、基於 Vulkan 的圖形堆疊，以及由使用者提供的遊戲建置流程。此堆疊在必要時重寫 Switch NSO 模組，模擬 Horizon 系統呼叫與 SDK 服務，並針對著色器、修補程式及版本相關修正採用各作品設定檔。目標對象為在 arm64、Android 10 以上硬體上處理合法轉存 NSP 或 XCI 內容的玩家與研究人員，並為逆向工程與相容性工作提供對 Switch 二進位、載入與平台移植的深入視角。
