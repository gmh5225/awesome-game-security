DroidPlay Core は、自分でダンプした Nintendo Switch 向けゲームを Android アプリに変換し、従来のエミュレータ内ではなく端末上でタイトル本来の ARM コードを実行するネイティブランタイムです。Android 向けの nxnative エンジン分岐で、主に C と Java で実装され、Python ツール、Vulkan ベースのグラフィックス、ユーザー提供のゲームビルドパイプラインを備えます。必要に応じて Switch の NSO モジュールを書き換え、Horizon のシステムコールと SDK サービスをエミュレートし、シェーダー・パッチ・ビルド固有の修正にはタイトルごとのプロファイルを適用します。arm64 の Android 10 以降のハードウェア上で、正当にダンプした NSP または XCI コンテンツを扱うプレイヤーや研究者を対象とし、Switch バイナリ、ローディング、プラットフォーム立ち上げの深い洞察をリバースエンジニアリングや互換性作業に提供します。
