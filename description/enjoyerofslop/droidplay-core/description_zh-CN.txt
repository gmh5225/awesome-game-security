DroidPlay Core 是一种原生运行时，可将您自行转储的任天堂 Switch 游戏封装为 Android 应用，使游戏自身的 ARM 代码在设备上直接执行，而非在常规模拟器内运行。它是面向 Android 的 nxnative 引擎分支，主要用 C 与 Java 实现，辅以 Python 工具链、基于 Vulkan 的图形栈，以及由用户提供的游戏构建流程。该栈在需要时重写 Switch NSO 模块，模拟 Horizon 系统调用与 SDK 服务，并针对着色器、补丁及版本相关修复采用逐作配置文件。其面向在 arm64、Android 10 及以上硬件上处理合法转储 NSP 或 XCI 内容的玩家与研究人员，为逆向工程与兼容性工作提供对 Switch 二进制、加载与平台移植的深入视角。
