NXbox 是一個 C++ 與 CMake 專案，將 Eden Nintendo Switch 模擬器堆疊移植到 Microsoft 的 Xbox UWP 與 AppContainer 環境，以便在 Xbox Series 硬體上研究與執行 Switch 軟體。程式庫包含 Eden 核心元件——用於 ARM64 CPU 翻譯的 Dynarmic、面向 Maxwell 的著色器重編譯器、視訊與音訊子系統、Horizon OS 文件，以及 Qt、Android 與專用 nxbox 啟動器前端——以及 dist/nxbox 下的 Xbox 封裝與 AppxManifest。移植專用標頭與說明涵蓋 UWP 檔案系統整合、OpenGL 回讀與 GPU 停頓處理、Mesa 與 Direct3D 12 驅動程式除錯、裝置 API 研究，以及針對《薩爾達傳說 曠野之息》等遊戲的記憶體與相容性工作文件。面向從事跨平台模擬、主機沙箱限制以及底層圖形與 CPU 行為研究的開發者與研究人員，而非生產級反作弊工具。
