NXbox は C++ と CMake のプロジェクトで、Eden Nintendo Switch エミュレータスタックを Microsoft の Xbox UWP および AppContainer 環境へ移植し、Switch ソフトウェアを Xbox Series ハードウェア上で調査・実行できるようにする。ツリーには Eden のコア要素——ARM64 CPU 変換用 Dynarmic、Maxwell 向けシェーダーリコンパイラ、映像・音声サブシステム、Horizon OS ドキュメント、Qt・Android・専用 nxbox ランチャーフロントエンド——に加え、dist/nxbox 配下の Xbox パッケージングと AppxManifest が含まれる。移植向けヘッダとメモでは UWP ファイルシステム統合、OpenGL リードバックと GPU ストール処理、Mesa と Direct3D 12 ドライバデバッグ、デバイス API 調査、『ゼルダの伝説 ブレス オブ ザ ワイルド』などタイトル向けのメモリ・互換性作業が文書化されている。本番向けアンチチートツールではなく、クロスプラットフォームエミュレーション、コンソールサンドボックス制限、低レベルグラフィックスと CPU 挙動に取り組む開発者・研究者向けである。
