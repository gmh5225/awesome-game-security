NXbox is a C++ and CMake project that ports the Eden Nintendo Switch emulator stack to Microsoft’s Xbox UWP and AppContainer environment so Switch software can be studied and run on Xbox Series hardware. The tree includes Eden’s core pieces—Dynarmic for ARM64 CPU translation, a Maxwell-oriented shader recompiler, video and audio subsystems, Horizon OS documentation, and Qt, Android, and dedicated nxbox launcher frontends—alongside Xbox packaging under dist/nxbox with an AppxManifest. Port-specific headers and notes cover UWP filesystem integration, OpenGL readback and GPU stall handling, Mesa and Direct3D 12 driver debugging, device API research, and memory and compatibility work documented for titles such as Breath of the Wild. It targets developers and researchers working on cross-platform emulation, console sandbox limits, and low-level graphics and CPU behavior rather than production anti-cheat tooling.
