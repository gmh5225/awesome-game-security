NXbox 是一个 C++ 与 CMake 项目，将 Eden Nintendo Switch 模拟器栈移植到 Microsoft 的 Xbox UWP 与 AppContainer 环境，以便在 Xbox Series 硬件上研究与运行 Switch 软件。代码树包含 Eden 核心组件——用于 ARM64 CPU 翻译的 Dynarmic、面向 Maxwell 的着色器重编译器、视频与音频子系统、Horizon OS 文档，以及 Qt、Android 与专用 nxbox 启动器前端——以及 dist/nxbox 下的 Xbox 打包与 AppxManifest。移植专用头文件与说明涵盖 UWP 文件系统集成、OpenGL 回读与 GPU 停顿处理、Mesa 与 Direct3D 12 驱动调试、设备 API 研究，以及针对《塞尔达传说：旷野之息》等游戏的内存与兼容性工作文档。面向从事跨平台模拟、主机沙箱限制以及底层图形与 CPU 行为研究的开发者与研究人员，而非生产级反作弊工具。
