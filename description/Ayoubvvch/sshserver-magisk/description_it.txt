Questo progetto è un modulo per Magisk, KernelSU e APatch che esegue un server SSH e SFTP Dropbear leggero su dispositivi Android rootati fin dall’avvio, senza Termux o altre app userland. Include binari Dropbear e SFTP compilati staticamente per arm64 collegati a musl libc per evitare problemi di namespace del linker su Android 10 fino a 15+, e supporta chiavi pubbliche Ed25519 o RSA più autenticazione con password SHA-512 tramite un file passwd generato in modo systemless. L’utilità sshserverctl basata su shell gestisce il demone, la configurazione è in config.env e i keepalive TCP aiutano le sessioni a sopravvivere alla modalità Doze. Gli script shell principali collegano gli hook di servizio post-fs-data e late_start di Magisk a installazione e avvio. È rivolto a sviluppatori e ricercatori di sicurezza che necessitano di shell root headless persistente e trasferimento file in rete per debug mobile, strumentazione e flussi di lavoro di reverse engineering.
