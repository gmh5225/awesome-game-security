本项目是一个适用于 Magisk、KernelSU 和 APatch 的模块，可在已 root 的 Android 设备上从开机起运行轻量级 Dropbear SSH 与 SFTP 服务器，无需 Termux 或其他用户空间应用。它附带针对 arm64 静态编译、链接 musl libc 的 Dropbear 与 SFTP 二进制，以避免 Android 10 至 15+ 上的链接器命名空间问题，并支持 Ed25519 或 RSA 公钥以及通过无系统方式生成的 passwd 文件进行 SHA-512 密码认证。基于 shell 的 sshserverctl 工具用于管理守护进程，配置位于 config.env，TCP keepalive 有助于在 Doze 模式下保持会话。主要 shell 脚本将 Magisk 的 post-fs-data 与 late_start 服务钩子与安装及启动流程衔接。面向需要通过网络持久 headless root shell 与文件传输，以进行移动调试、插桩与逆向工程工作流的开发者与安全研究人员。
