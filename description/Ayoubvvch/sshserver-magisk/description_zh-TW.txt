本專案是一個適用於 Magisk、KernelSU 與 APatch 的模組，可在已 root 的 Android 裝置上從開機起執行輕量級 Dropbear SSH 與 SFTP 伺服器，無需 Termux 或其他使用者空間應用程式。它內含針對 arm64 靜態編譯、連結 musl libc 的 Dropbear 與 SFTP 二進位檔，以避免 Android 10 至 15+ 上的連結器命名空間問題，並支援 Ed25519 或 RSA 公鑰，以及透過無系統方式產生的 passwd 檔案進行 SHA-512 密碼驗證。以 shell 為基礎的 sshserverctl 工具用於管理守護程式，設定位於 config.env，TCP keepalive 有助於在 Doze 模式下維持連線。主要 shell 腳本將 Magisk 的 post-fs-data 與 late_start 服務鉤子與安裝及啟動流程銜接。面向需要透過網路持久 headless root shell 與檔案傳輸，以進行行動除錯、插樁與逆向工程工作流程的開發者與安全研究人員。
