Этот проект — модуль для Magisk, KernelSU и APatch, который с загрузки запускает лёгкий SSH- и SFTP-сервер Dropbear на rooted Android-устройствах без Termux и других userland-приложений. В комплекте статически собранные бинарники Dropbear и SFTP для arm64, слинкованные с musl libc, чтобы обойти проблемы пространства имён линкера на Android 10–15+, поддерживаются публичные ключи Ed25519 или RSA и аутентификация по паролю SHA-512 через systemless-сгенерированный файл passwd. Утилита sshserverctl на shell управляет демоном, конфигурация в config.env, TCP keepalive помогают сессиям переживать режим Doze. Основные shell-скрипты связывают хуки сервисов Magisk post-fs-data и late_start с установкой и запуском. Целевая аудитория — разработчики и исследователи безопасности, которым нужны постоянная headless root-оболочка и передача файлов по сети для мобильной отладки, инструментирования и reverse engineering.
