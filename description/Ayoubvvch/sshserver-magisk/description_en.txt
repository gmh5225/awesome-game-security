This project is a Magisk, KernelSU, and APatch module that runs a lightweight Dropbear SSH and SFTP server on rooted Android devices from boot without Termux or other userland apps. It ships statically compiled arm64 Dropbear and SFTP binaries linked against musl libc to avoid Android linker namespace issues on Android 10 through 15+, and supports Ed25519 or RSA public keys plus SHA-512 password authentication via a systemless generated passwd file. A shell-based sshserverctl utility manages the daemon, configuration lives in config.env, and TCP keepalives help sessions survive Doze mode. Primary shell scripting ties Magisk post-fs-data and late_start service hooks to installation and startup. It targets developers and security researchers who need persistent headless root shell and file transfer over the network for mobile debugging, instrumentation, and reverse engineering workflows.
