本プロジェクトは Magisk、KernelSU、APatch 向けモジュールで、root 化した Android 端末上で Termux などのユーザーランドアプリなしに、起動時から軽量な Dropbear SSH および SFTP サーバーを動かします。Android 10 から 15 以降でのリンカー名前空間の問題を避けるため、musl libc にリンクした arm64 向け静的ビルドの Dropbear と SFTP バイナリを同梱し、Ed25519 または RSA 公開鍵と、systemless で生成した passwd ファイルによる SHA-512 パスワード認証に対応します。shell ベースの sshserverctl ユーティリティがデーモンを管理し、設定は config.env にあり、TCP keepalive で Doze モード中もセッションを維持しやすくします。主な shell スクリプトが Magisk の post-fs-data と late_start サービスフックをインストールと起動に結び付けます。モバイルデバッグ、計装、リバースエンジニアリングのワークフロー向けに、ネットワーク経由の永続的な headless root シェルとファイル転送が必要な開発者およびセキュリティ研究者を対象としています。
