BaiZe は root 化済み Android 向けのストレージクリーンアップシステムで、Magisk、KernelSU、または APatch モジュールとして提供され、キャッシュ、ログ、その他の不要ファイルをスキャンして削除するコンパニオンアプリ付きです。主に Kotlin と C で構築され、shell モジュールスクリプトと libsu RootService により、数千件の厳選されたディープクリーンルールに基づくネイティブスキャンエンジンを駆動します。主な機能には、アプリキャッシュとアンインストール残留物のクリーンアップ、APK 保持スキャン、ファイル整理、温度およびアイドル制約付きのスケジュールタスク、隔離と監査履歴が含まれます。安全性が中核で、四段階のリスク分類、パスホワイトリスト、削除前スキャンスナップショット、シンボリックリンク安全削除、自動実行時に高リスク対象をスキャンのみに制限するハードリミットを備えます。root 化 Android ユーザーおよびセキュリティを重視する運用者向けに、ダウンロード、データベース、その他の保護されたユーザーデータを危険にさらすことなく、正確でポリシー制御されたクリーンアップを提供します。
