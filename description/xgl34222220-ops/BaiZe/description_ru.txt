BaiZe — система очистки хранилища для Android с root-доступом, поставляемая в виде модуля Magisk, KernelSU или APatch с companion-приложением для сканирования и удаления кэша, журналов и других ненужных файлов. Разработана преимущественно на Kotlin и C, включает shell-скрипты модулей и libsu RootService, который управляет нативным движком сканирования по тысячам отобранных правил глубокой очистки. Ключевые возможности: очистка кэша приложений и остатков после удаления, сканирование сохранённых APK, организация файлов, запланированные задачи с ограничениями по температуре и простою, а также карантин с журналом аудита. Безопасность — в центре: четырёхуровневая классификация рисков, белые списки путей, снимки сканирования перед удалением, безопасное удаление символических ссылок и жёсткие ограничения, удерживающие высокорисковые цели в режиме только сканирования при автоматических запусках. Предназначена для пользователей Android с root и операторов, ориентированных на безопасность, которым нужна точная, управляемая политиками очистка без риска для загрузок, баз данных и других защищённых пользовательских данных.
