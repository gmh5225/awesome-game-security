BaiZe 是一款面向已 root 的 Android 设备的存储清理系统，以 Magisk、KernelSU 或 APatch 模块形式提供，并配有配套应用，用于扫描并清除缓存、日志及其他垃圾文件。项目主要使用 Kotlin 和 C 编写，包含 shell 模块脚本，以及通过 libsu RootService 驱动原生扫描引擎、依据数千条精选深度清理规则执行清理。核心功能包括应用缓存与卸载残留清理、APK 保留扫描、文件整理、带温控与空闲约束的定时任务，以及隔离区与审计历史。安全性是设计重心：四级风险分类、路径白名单、删除前扫描快照、符号链接安全删除，以及硬性限制，确保自动化运行期间高风险目标仅扫描不删除。面向已 root 的 Android 用户及注重安全的运维人员，提供准确、策略可控的清理能力，同时避免误删下载内容、数据库及其他受保护的用户数据。
