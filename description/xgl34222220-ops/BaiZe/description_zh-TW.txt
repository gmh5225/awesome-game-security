BaiZe 是一款面向已 root 的 Android 裝置的儲存清理系統，以 Magisk、KernelSU 或 APatch 模組形式提供，並配有配套應用程式，用於掃描並清除快取、日誌及其他垃圾檔案。專案主要使用 Kotlin 和 C 撰寫，包含 shell 模組腳本，以及透過 libsu RootService 驅動原生掃描引擎、依據數千條精選深度清理規則執行清理。核心功能包括應用程式快取與解除安裝殘留清理、APK 保留掃描、檔案整理、具溫控與閒置約束的排程任務，以及隔離區與稽核歷史。安全性是設計重心：四級風險分類、路徑白名單、刪除前掃描快照、符號連結安全刪除，以及硬性限制，確保自動化執行期間高風險目標僅掃描不刪除。面向已 root 的 Android 使用者及注重資訊安全的維運人員，提供準確、策略可控的清理能力，同時避免誤刪下載內容、資料庫及其他受保護的使用者資料。
