spu2c は IDA Pro 用プラグインで、PlayStation 3 CELL Synergistic Processing Unit（SPU）のマシンコードの各命令に、読みやすい C スタイルのコメントを付けます。Python と IDA API で実装され、SPU オペコードをデコードし、128 ビット、8×16 ビット、16×8 ビット、4×32 ビットレーンなどのベクトルサイズを明示してレジスタ操作を説明します。可能な場合は shuffle-byte マスクを解決し、オペコード名はテキストから読み取りながらフィールドは 16 進数から解析することで、一般的な IDA SPU プラグインの不具合を回避します。キーボードショートカットにより、単一命令、選択範囲、または関数全体をスキャンできます。PS3 SPU ファームウェア、ライブラリ、または IDA 内のアンチチート・保護コードを解析するリバースエンジニアやゲームセキュリティ研究者向けのツールです。
