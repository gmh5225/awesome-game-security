spu2c est un plugin IDA Pro qui annote le code machine du Synergistic Processing Unit (SPU) CELL de la PlayStation 3 avec des commentaires lisibles de style C pour chaque instruction. Écrit en Python à l'aide de l'API IDA, il décode les opcodes SPU et explique les opérations sur les registres avec des tailles de vecteur explicites telles que 128 bits, 8×16 bits, 16×8 bits et 4×32 bits. Le plugin résout les masques shuffle-byte lorsque c'est possible, lit les noms d'opcodes depuis du texte tout en analysant les champs en hexadécimal pour éviter les bugs courants des plugins SPU pour IDA, et permet de scanner une instruction, une sélection ou une fonction entière via des raccourcis clavier. Il s'adresse aux ingénieurs en rétro-ingénierie et aux chercheurs en sécurité des jeux qui analysent le firmware SPU, les bibliothèques ou le code anti-triche et de protection PS3 dans IDA.
