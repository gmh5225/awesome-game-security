spu2c — это плагин для IDA Pro, который снабжает машинный код Synergistic Processing Unit (SPU) CELL PlayStation 3 читаемыми комментариями в стиле C для каждой инструкции. Написан на Python с использованием API IDA, декодирует опкоды SPU и поясняет операции с регистрами с явным указанием размеров векторов: 128 бит, 8×16 бит, 16×8 бит и 4×32 бит. Плагин при возможности разрешает маски shuffle-byte, читает имена опкодов из текста, а поля разбирает из шестнадцатеричного представления, чтобы избежать типичных ошибок SPU-плагинов для IDA, и поддерживает сканирование одной инструкции, выделенного фрагмента или целой функции с помощью горячих клавиш. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности игр, анализирующих прошивку SPU, библиотеки или код античита и защиты PS3 в IDA.
