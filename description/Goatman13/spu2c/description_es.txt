spu2c es un complemento de IDA Pro que anota el código máquina del Synergistic Processing Unit (SPU) CELL de PlayStation 3 con comentarios legibles de estilo C para cada instrucción. Escrito en Python con la API de IDA, decodifica opcodes SPU y explica las operaciones de registro con tamaños de vector explícitos como 128 bits, 8×16 bits, 16×8 bits y 4×32 bits. El complemento resuelve máscaras shuffle-byte cuando es posible, lee nombres de opcode desde texto mientras analiza campos en hexadecimal para evitar errores comunes de los complementos SPU de IDA, y admite escanear una instrucción, una selección o una función completa mediante atajos de teclado. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad de juegos que analizan firmware SPU, bibliotecas o código antitrampas y de protección de PS3 en IDA.
