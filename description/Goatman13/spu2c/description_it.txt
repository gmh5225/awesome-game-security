spu2c è un plugin per IDA Pro che annota il codice macchina del Synergistic Processing Unit (SPU) CELL di PlayStation 3 con commenti leggibili in stile C per ogni istruzione. Scritto in Python usando l'API di IDA, decodifica gli opcode SPU e spiega le operazioni sui registri con dimensioni vettoriali esplicite come 128 bit, 8×16 bit, 16×8 bit e 4×32 bit. Il plugin risolve le maschere shuffle-byte quando possibile, legge i nomi degli opcode dal testo analizzando i campi in esadecimale per evitare i bug comuni dei plugin SPU per IDA, e consente di scansionare una singola istruzione, una selezione o un'intera funzione tramite scorciatoie da tastiera. È rivolto a ingegneri del reverse engineering e ricercatori di sicurezza dei giochi che analizzano firmware SPU, librerie o codice anti-cheat e di protezione PS3 in IDA.
