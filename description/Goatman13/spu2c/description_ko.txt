spu2c는 IDA Pro 플러그인으로, PlayStation 3 CELL Synergistic Processing Unit(SPU) 머신 코드의 각 명령어에 읽기 쉬운 C 스타일 주석을 달아 줍니다. Python과 IDA API로 작성되었으며, SPU opcode를 디코딩하고 128비트, 8×16비트, 16×8비트, 4×32비트 레인 등 명시적인 벡터 크기로 레지스터 연산을 설명합니다. 가능한 경우 shuffle-byte 마스크를 해석하며, opcode 이름은 텍스트에서 읽고 필드는 16진수에서 파싱하여 일반적인 IDA SPU 플러그인의 버그를 피합니다. 키보드 단축키로 단일 명령어, 선택 영역 또는 전체 함수를 스캔할 수 있습니다. IDA에서 PS3 SPU 펌웨어, 라이브러리 또는 안티치트·보호 코드를 분석하는 리버스 엔지니어와 게임 보안 연구자를 위한 도구입니다.
