spu2c 是一款 IDA Pro 外掛，可為 PlayStation 3 CELL 協同處理單元（SPU）機器碼的每條指令加入易讀的 C 風格註解。此外掛以 Python 撰寫並使用 IDA API，可解碼 SPU 操作碼，並以 128 位元、8×16 位元、16×8 位元、4×32 位元通道等明確的向量尺寸說明暫存器操作。在可能的情況下，外掛會解析 shuffle-byte 遮罩；它從文字讀取操作碼名稱，同時從十六進位解析欄位，以避免常見 IDA SPU 外掛的缺陷。透過鍵盤快速鍵，可掃描單一指令、選取範圍或整個函式。此工具面向在 IDA 中分析 PS3 SPU 韌體、函式庫或反作弊與保護程式碼的逆向工程師與遊戲安全研究人員。
