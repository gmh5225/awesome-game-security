spu2c 是一款 IDA Pro 插件，可为 PlayStation 3 CELL 协同处理单元（SPU）机器码的每条指令添加易读的 C 风格注释。该插件使用 Python 编写并基于 IDA API，可解码 SPU 操作码，并以 128 位、8×16 位、16×8 位、4×32 位通道等明确的向量尺寸说明寄存器操作。在可能的情况下，插件会解析 shuffle-byte 掩码；它从文本读取操作码名称，同时从十六进制解析字段，以避免常见 IDA SPU 插件的缺陷。通过键盘快捷键，可扫描单条指令、选中区域或整个函数。该工具面向在 IDA 中分析 PS3 SPU 固件、库或反作弊与保护代码的逆向工程师与游戏安全研究人员。
