spu2c is an IDA Pro plugin that annotates PlayStation 3 CELL Synergistic Processing Unit (SPU) machine code with readable C-style comments for each instruction. Written in Python using the IDA API, it decodes SPU opcodes and explains register operations with explicit vector sizes such as 128-bit, 8x16-bit, 16x8-bit, and 4x32-bit lanes. The plugin resolves shuffle-byte masks when possible, reads opcode names from text while parsing fields from hex to avoid common IDA SPU plugin bugs, and supports scanning a single instruction, a selection, or an entire function via keyboard shortcuts. It is aimed at reverse engineers and game security researchers analyzing PS3 SPU firmware, libraries, or anti-cheat and protection code inside IDA.
