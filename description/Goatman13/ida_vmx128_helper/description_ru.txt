Плагин для IDA Pro, который исправляет неверно интерпретированные операнды векторных регистров VMX128 при дизассемблировании двоичных файлов PowerPC. Написан на Python, подключается к модулю процессора IDA для декодирования и отображения инструкций VMX128, таких как vaddfp128, vperm128 и vsldoi128, с корректными полями регистров A, B, C и D. Плагин автоматически загружается при размещении в каталоге plugins IDA и активируется для целей PPC, в частности для XEX Xbox 360 и связанных исполнимых форматов. Предназначен для специалистов по reverse engineering и исследователей безопасности игр, которым нужен читаемый дизассемблированный вывод при анализе консольного игрового кода с интенсивным использованием VMX128.
