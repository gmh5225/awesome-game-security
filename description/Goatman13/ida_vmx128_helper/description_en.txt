An IDA Pro plugin that corrects misinterpreted VMX128 vector register operands during disassembly of PowerPC binaries. Written in Python, it hooks into IDA's processor module to decode and display VMX128 instructions such as vaddfp128, vperm128, and vsldoi128 with accurate A, B, C, and D register fields. The plugin loads automatically when placed in IDA's plugins directory and activates for PPC targets, especially Xbox 360 XEX and related executable formats. It is aimed at reverse engineers and game security researchers who need readable disassembly when analyzing VMX128-heavy console game code.
