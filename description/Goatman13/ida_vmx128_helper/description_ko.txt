PowerPC 바이너리를 디스어셈블할 때 잘못 해석된 VMX128 벡터 레지스터 피연산자를 바로잡는 IDA Pro 플러그인입니다. Python으로 작성되었으며 IDA의 프로세서 모듈에 후킹하여 vaddfp128, vperm128, vsldoi128 같은 VMX128 명령을 정확한 A, B, C, D 레지스터 필드와 함께 디코딩하고 표시합니다. IDA의 plugins 디렉터리에 배치하면 자동으로 로드되며 PPC 대상, 특히 Xbox 360 XEX 및 관련 실행 형식에서 활성화됩니다. VMX128을 많이 사용하는 콘솔 게임 코드 분석 시 읽기 쉬운 디스어셈블리가 필요한 리버스 엔지니어와 게임 보안 연구자를 대상으로 합니다.
