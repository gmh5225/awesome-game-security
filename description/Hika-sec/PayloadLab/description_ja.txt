PayloadLab は、制御されたレッドチーム環境でメモリ内 shellcode の難読化とローダーのペアリングを試すための小規模な研究ツールキットです。Python スクリプトは C 形式のバイトダンプ由来の生の x86 shellcode をエンコードまたは暗号化された形に変換し、対応する C++ ローダーがそれらのペイロードを組み込み、実行時に復号または復号化して、再構築されたバッファへ実行を移します。対応手法には単バイト XOR、RC4、ChaCha20 ストリーム暗号、ランレングスエンコード、IPfuscation を想起させる IPv4 風バイトエンコードなどがあります。本プロジェクトは、ペイロードの隠蔽方法、ローダーによる再構築、および類似パターンがマルウェア解析、検知エンジニアリング、許可されたラボ環境におけるゲームアンチチートや EDR 評価とどう結びつくかを調べるセキュリティ研究者向けです。
