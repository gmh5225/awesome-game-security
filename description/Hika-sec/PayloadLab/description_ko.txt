PayloadLab은 통제된 레드팀 환경에서 메모리 내 shellcode 난독화와 로더 페어링을 실험하기 위한 소규모 연구 툴킷입니다. Python 스크립트는 C 스타일 바이트 덤프에서 나온 원시 x86 shellcode를 인코딩 또는 암호화된 형태로 변환하고, 짝을 이루는 C++ 로더가 해당 페이로드를 내장해 실행 시 디코딩 또는 복호화한 뒤 재구성된 버퍼로 실행을 넘깁니다. 지원 기법에는 단일 바이트 XOR, RC4, ChaCha20 스트림 암호, 런렝스 인코딩, IPfuscation을 연상시키는 IPv4 스타일 바이트 인코딩 등이 있습니다. 이 프로젝트는 페이로드 은닉 방식, 로더의 재구성 과정, 유사 패턴이 멀웨어 분석·탐지 엔지니어링 및 승인된 실험 환경에서의 게임 안티치트·EDR 평가와 어떻게 연관되는지 연구하는 보안 연구자를 대상으로 합니다.
