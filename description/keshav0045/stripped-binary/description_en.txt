This project trains and serves models that suggest original function names for stripped native binaries by reading Ghidra decompiler output. A Docker-backed pipeline compiles open-source C projects with gcc and clang at multiple optimization levels, pairs stripped and unstripped ELF twins for ground-truth labels, and exports headless Ghidra decompilation with careful normalization and leakage controls. Python implements dataset pairing, evaluation metrics, TF-IDF k-nearest-neighbor baselines, optional LoRA fine-tuning on a code LLM, and zero-shot API baselines, plus a FastAPI service and Ghidra script to apply ranked name suggestions with confidence scores. It targets reverse engineers and binary analysts who work on symbol-stripped executables and libraries, including game clients and anti-tamper builds where recovering meaningful identifiers speeds triage and manual analysis.
