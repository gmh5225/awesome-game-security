本プロジェクトは、Ghidra デコンパイラの出力を読み取り、シンボルストリップされたネイティブバイナリに対して元の関数名を提案するモデルを学習・提供する。Docker 上のパイプラインは、gcc と clang で複数の最適化レベルにおいてオープンソース C プロジェクトをコンパイルし、ストリップ済みと未ストリップの ELF ツインを ground-truth ラベルとしてペアリングし、正規化と情報漏えい対策を施したヘッドレス Ghidra デコンパイルをエクスポートする。Python ではデータセットのペアリング、評価指標、TF-IDF k 近傍ベースライン、コード LLM に対する任意の LoRA ファインチューニング、ゼロショット API ベースライン、および信頼度スコア付きの順位付き名称提案を適用する FastAPI サービスと Ghidra スクリプトを実装する。シンボルストリップされた実行ファイルやライブラリ、ゲームクライアントや改ざん防止ビルドなどを扱うリバースエンジニアおよびバイナリアナリスト向けで、意味のある識別子を復元することでトリアージと手動分析を加速する。
