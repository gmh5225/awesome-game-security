本项目训练并提供模型，通过读取 Ghidra 反编译器输出，为已剥离符号的原生二进制文件建议原始函数名。基于 Docker 的流水线使用 gcc 与 clang 在多种优化级别下编译开源 C 项目，配对剥离与未剥离的 ELF 孪生体作为 ground-truth 标签，并以严格的规范化与泄漏控制导出无头 Ghidra 反编译结果。Python 实现数据集配对、评估指标、TF-IDF k 近邻基线、在代码 LLM 上的可选 LoRA 微调、零样本 API 基线，以及用于按置信度分数应用排序后名称建议的 FastAPI 服务与 Ghidra 脚本。面向处理无符号可执行文件与库的反汇编工程师与二进制分析师，包括游戏客户端与防篡改构建，恢复有意义的标识符可加速分诊与手工分析。
