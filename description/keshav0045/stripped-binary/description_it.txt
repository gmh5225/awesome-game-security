Questo progetto addestra e mette a disposizione modelli che suggeriscono i nomi originali delle funzioni per binari nativi privi di simboli, leggendo l’output del decompilatore Ghidra. Una pipeline basata su Docker compila progetti C open source con gcc e clang a più livelli di ottimizzazione, accoppia gemelli ELF strippati e non strippati per etichette ground truth ed esporta decompilazione Ghidra headless con normalizzazione accurata e controlli anti-leakage. Python implementa l’accoppiamento dei dataset, metriche di valutazione, baseline k-nearest neighbor TF-IDF, fine-tuning LoRA opzionale su un LLM per codice, baseline API zero-shot, più un servizio FastAPI e uno script Ghidra per applicare suggerimenti di nomi ordinati con punteggi di confidenza. È rivolto a reverse engineer e analisti di binari che lavorano su eseguibili e librerie senza simboli, inclusi client di gioco e build anti-manomissione, dove recuperare identificatori significativi accelera triage e analisi manuale.
