Este proyecto entrena y sirve modelos que sugieren nombres de función originales para binarios nativos sin símbolos leyendo la salida del descompilador Ghidra. Un pipeline respaldado por Docker compila proyectos C de código abierto con gcc y clang en varios niveles de optimización, empareja gemelos ELF con y sin strip para etiquetas de verdad fundamental, y exporta descompilación Ghidra headless con normalización cuidadosa y controles de filtración. Python implementa emparejamiento de conjuntos de datos, métricas de evaluación, líneas base k-vecinos más cercanos TF-IDF, ajuste fino LoRA opcional en un LLM de código, líneas base API zero-shot, más un servicio FastAPI y script Ghidra para aplicar sugerencias de nombres ordenadas con puntuaciones de confianza. Está dirigido a ingenieros de ingeniería inversa y analistas de binarios que trabajan con ejecutables y bibliotecas sin símbolos, incluidos clientes de juegos y builds anti-manipulación, donde recuperar identificadores significativos acelera el triaje y el análisis manual.
