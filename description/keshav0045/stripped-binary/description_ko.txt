이 프로젝트는 Ghidra 디컴파일러 출력을 읽어 심볼이 제거된 네이티브 바이너리에 대해 원래 함수 이름을 제안하는 모델을 학습하고 제공한다. Docker 기반 파이프라인은 gcc와 clang으로 여러 최적화 수준에서 오픈 소스 C 프로젝트를 컴파일하고, ground-truth 레이블을 위해 스트립된 ELF와 스트립되지 않은 ELF 쌍을 맞추며, 정규화와 정보 누출 방지를 신중히 적용한 헤드리스 Ghidra 디컴파일 결과를 내보낸다. Python으로 데이터셋 페어링, 평가 지표, TF-IDF k-최근접 이웃 베이스라인, 코드 LLM에 대한 선택적 LoRA 파인튜닝, 제로샷 API 베이스라인, 신뢰도 점수와 함께 순위가 매겨진 이름 제안을 적용하는 FastAPI 서비스 및 Ghidra 스크립트를 구현한다. 심볼이 제거된 실행 파일과 라이브러리, 게임 클라이언트 및 변조 방지 빌드 등을 다루는 리버스 엔지니어와 바이너리 분석가를 대상으로 하며, 의미 있는 식별자를 복구하면 분류와 수동 분석 속도를 높인다.
