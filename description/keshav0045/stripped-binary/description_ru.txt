Этот проект обучает и развёртывает модели, которые по выводу декомпилятора Ghidra предлагают исходные имена функций для нативных бинарников без символов. Конвейер на Docker компилирует открытые C-проекты gcc и clang на нескольких уровнях оптимизации, сопоставляет пары ELF с символами и без них для эталонных меток и экспортирует headless-декомпиляцию Ghidra с тщательной нормализацией и контролем утечек данных. На Python реализованы сопоставление наборов данных, метрики оценки, базовые линии k ближайших соседей TF-IDF, опциональная LoRA-донастройка кодового LLM, zero-shot API-базовые линии, а также сервис FastAPI и скрипт Ghidra для применения ранжированных предложений имён с оценками уверенности. Ориентирован на специалистов по реверс-инжинирингу и анализу бинарников, работающих с исполняемыми файлами и библиотеками без символов, включая игровые клиенты и anti-tamper-сборки, где восстановление осмысленных идентификаторов ускоряет первичный разбор и ручной анализ.
