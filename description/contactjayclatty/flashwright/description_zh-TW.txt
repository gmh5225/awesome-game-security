Flashwright 是一款 Windows 11 安裝精靈，從插入裝置到完成，引導你更新、取得 root 權限並刷寫 Google Pixel 等 Android 手機。它主要以 Rust 建構，採用 Tauri 桌面應用程式與 TypeScript/Vite 前端，透過具解析器、逾時機制的型別化命令層驅動 adb 與 fastboot，並在任何破壞性寫入前提供審核步驟。此工具可開啟出廠與 OTA 套件、驗證映像檔的 SHA-256 雜湊、以 Magisk 修補 boot 以取得 root，並可在刷寫原廠韌體時顯示每個檔案的校驗和。安全檢查涵蓋裝置與版本相符、安全性修補等級、Bootloader 防回滾、槽位規則，以及裝置上 boot 映像與出廠來源的比對；另提供乾跑預覽，在不寫入的情況下報告將執行或被阻擋的操作。支援 boot 與 vbmeta 分割區備份、一鍵還原以及 Windows 上的 USB 驅動程式處理，適合需要可控、可稽核流程進行裝置修改與完整性相關行動安全工作的研究人員與從業者。
