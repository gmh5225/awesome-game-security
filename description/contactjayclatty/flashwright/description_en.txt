Flashwright is a Windows 11 setup wizard that guides you through updating, rooting, and flashing Android phones such as Google Pixel devices from plug-in to completion. It is built primarily in Rust with a Tauri desktop app and a TypeScript/Vite front end, and it drives adb and fastboot through a typed command layer with parsers, timeouts, and a review step before any destructive write is allowed. The tool opens factory and OTA packages, verifies SHA-256 hashes on images, patches boot with Magisk for root, and can flash stock firmware while showing checksums for each file. Safety checks cover device and build match, security patch level, bootloader anti-rollback, slot rules, and comparison of on-device boot images against factory sources, with dry-run previews that report what would run or be blocked without writing. Backups of boot and vbmeta partitions, one-click restore, and USB driver handling on Windows make it suited to researchers and practitioners who need a controlled, auditable workflow for device modification and integrity-related mobile security work.
