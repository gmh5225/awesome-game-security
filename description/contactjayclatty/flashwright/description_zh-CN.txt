Flashwright 是一款 Windows 11 安装向导，从插入设备到完成，引导你更新、获取 root 权限并刷写 Google Pixel 等 Android 手机。它主要用 Rust 构建，采用 Tauri 桌面应用与 TypeScript/Vite 前端，通过带解析器、超时机制的类型化命令层驱动 adb 与 fastboot，并在任何破坏性写入前提供审核步骤。该工具可打开出厂与 OTA 包、校验镜像的 SHA-256 哈希、用 Magisk 修补 boot 以获取 root，并可在刷写原厂固件时显示每个文件的校验和。安全校验涵盖设备与版本匹配、安全补丁级别、Bootloader 防回滚、槽位规则，以及设备上 boot 镜像与出厂源的对比；还提供干跑预览，在不写入的情况下报告将执行或被阻止的操作。支持 boot 与 vbmeta 分区备份、一键恢复以及 Windows 上的 USB 驱动处理，适合需要可控、可审计流程进行设备修改与完整性相关移动安全工作的研究人员与从业者。
