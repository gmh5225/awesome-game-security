Flashwright es un asistente de configuración para Windows 11 que le guía desde la conexión hasta la finalización para actualizar, rootear y flashear teléfonos Android como los Google Pixel. Está construido principalmente en Rust con una aplicación de escritorio Tauri y un front-end TypeScript/Vite, y controla adb y fastboot mediante una capa de comandos tipada con analizadores, tiempos de espera y un paso de revisión antes de permitir cualquier escritura destructiva. La herramienta abre paquetes de fábrica y OTA, verifica hashes SHA-256 de las imágenes, parchea boot con Magisk para root y puede flashear firmware de stock mostrando sumas de comprobación de cada archivo. Las comprobaciones de seguridad cubren coincidencia de dispositivo y build, nivel de parche de seguridad, anti-rollback del bootloader, reglas de slot y comparación de imágenes boot en el dispositivo con fuentes de fábrica, con vistas previas en seco que informan qué se ejecutaría o bloquearía sin escribir. Copias de seguridad de particiones boot y vbmeta, restauración con un clic y gestión de controladores USB en Windows lo hacen adecuado para investigadores y profesionales que necesitan un flujo controlado y auditable para modificación de dispositivos y trabajo de seguridad móvil relacionado con la integridad.
