Flashwright は Windows 11 向けのセットアップウィザードで、Google Pixel などの Android 端末を接続から完了まで、更新・root 化・フラッシュまで案内します。主に Rust で構築され、Tauri デスクトップアプリと TypeScript/Vite フロントエンドを備え、パーサーとタイムアウト付きの型付きコマンド層で adb と fastboot を駆動し、破壊的な書き込みの前に確認ステップを設けています。工場出荷および OTA パッケージを開き、イメージの SHA-256 ハッシュを検証し、Magisk で boot をパッチして root 化し、各ファイルのチェックサムを表示しながらストックファームウェアをフラッシュできます。安全チェックには端末とビルドの一致、セキュリティパッチレベル、ブートローダーのアンチロールバック、スロット規則、端末上の boot イメージと工場ソースの比較が含まれ、書き込みなしで実行またはブロックされる内容を報告するドライラン preview もあります。boot と vbmeta パーティションのバックアップ、ワンクリック復元、Windows 上の USB ドライバー処理により、端末改変や整合性に関するモバイルセキュリティ作業に、制御可能で監査可能なワークフローを必要とする研究者や実務者向けです。
