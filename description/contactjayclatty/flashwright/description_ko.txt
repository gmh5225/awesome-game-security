Flashwright는 Windows 11용 설정 마법사로, Google Pixel 등 Android 폰을 연결부터 완료까지 업데이트·루팅·플래싱하는 과정을 안내합니다. 주로 Rust로 만들어졌으며 Tauri 데스크톱 앱과 TypeScript/Vite 프런트엔드를 사용하고, 파서와 타임아웃이 있는 타입화된 명령 계층으로 adb와 fastboot를 구동하며, 파괴적인 쓰기 전에 검토 단계를 둡니다. 공장 및 OTA 패키지를 열고, 이미지의 SHA-256 해시를 검증하며, Magisk로 boot를 패치해 루트 권한을 얻고, 각 파일의 체크섬을 표시하면서 스톡 펌웨어를 플래시할 수 있습니다. 안전 검사는 기기·빌드 일치, 보안 패치 수준, 부트로더 롤백 방지, 슬롯 규칙, 기기상 boot 이미지와 공장 소스 비교를 다루며, 쓰기 없이 실행되거나 차단될 내용을 보고하는 드라이런 미리보기도 제공합니다. boot 및 vbmeta 파티션 백업, 원클릭 복원, Windows USB 드라이버 처리로, 기기 수정 및 무결성 관련 모바일 보안 작업에 통제 가능하고 감사 가능한 워크플로가 필요한 연구자와 실무자에게 적합합니다.
