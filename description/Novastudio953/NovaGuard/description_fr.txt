NovaGuard est un plugin anti-triche haute performance pour les serveurs Minecraft Paper 1.21. Écrit en Kotlin, il propose 44 vérifications activables individuellement couvrant le mouvement, le combat, les exploits de monde, l'automatisation de type macro et le minage X-ray, chacune avec ses propres seuils de niveau de violation, sanctions et commandes de bannissement. Les outils intégrés pour le staff comprennent une interface GUI des suspects, le gel des joueurs, les vagues de bannissement, l'historique des violations, les signalements de joueurs et les alertes webhook Discord, tandis que les périodes de grâce, les boucliers anti-lag, les exemptions Bedrock et le blocage VPN aident à limiter les faux positifs. Il s'adresse aux administrateurs de serveurs qui ont besoin d'une détection de triche côté serveur et d'une modération pour les mondes Minecraft multijoueurs.
