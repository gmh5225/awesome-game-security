rea-games 是一个用于逆向分析开源游戏行为、并证明洁净室重实现与原作行为一致的框架。无依赖的 Node.js 命令行工具通过控制时钟与随机数录制未修改的原始运行，保存输入、随机数磁带以及逐步游戏状态，并以每游戏行为规格文档化规则。在 Web JavaScript、搭配 Bevy 的 Rust 或无头 Godot GDScript 中重建的移植版读取录制用例，须通过共享 JSON 校验协议产出完全相同的跟踪。项目附带已验证示例（如 2048、Chrome Dino、Canvas Bird 与下落方块类游戏），并支持由智能体驱动的工作流以添加游戏与引擎移植。适用于逆向工程、行为等价性测试，以及在不复制原作资源或代码的前提下研究游戏逻辑。
