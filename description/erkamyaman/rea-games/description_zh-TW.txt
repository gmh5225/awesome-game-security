rea-games 是一個用於逆向分析開源遊戲行為、並證明潔淨室重實作與原作行為一致的框架。無相依性的 Node.js 命令列工具透過控制時鐘與隨機數錄製未修改的原始，儲存輸入、隨機數磁帶以及逐步遊戲狀態，並以每遊戲行為規格文件化規則。在 Web JavaScript、搭配 Bevy 的 Rust 或無頭 Godot GDScript 中重建的移植版讀取錄製用例，須透過共享 JSON 驗證協定產出完全相同的追蹤。專案附帶已驗證範例（如 2048、Chrome Dino、Canvas Bird 與下落方塊類遊戲），並支援由代理驅動的工作流程以新增遊戲與引擎移植。適用於逆向工程、行為等價性測試，以及在不複製原作資源或程式碼的前提下研究遊戲邏輯。
