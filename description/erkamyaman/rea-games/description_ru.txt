rea-games — это каркас для реверс-инжиниринга поведения игр с открытым исходным кодом и доказательства того, что чистые переписывания совпадают с оригиналом. CLI на Node.js без зависимостей записывает неизменённые оригиналы, управляя часами и случайностью, сохраняет ввод, ленты случайных чисел и пошаговое состояние игры и документирует правила в поведенческих спецификациях для каждой игры. Пересобранные порты на веб-JavaScript, Rust с Bevy или headless Godot GDScript читают записанные кейсы и должны выдавать идентичные трассы через общий JSON-протокол верификации. В проекте есть проверенные примеры вроде 2048, Chrome Dino, Canvas Bird и игры с падающими блоками, а также поддерживаются агентные рабочие процессы для добавления игр и портов движков. Подходит для реверс-инжиниринга, тестов поведенческой эквивалентности и изучения игровой логики без копирования оригинальных ресурсов и кода.
