rea-games는 오픈 소스 게임 동작을 리버스 엔지니어링하고 클린룸 재구현이 원본과 일치함을 입증하는 프레임워크입니다. 의존성 없는 Node.js CLI는 시계와 난수를 제어해 수정되지 않은 원본을 기록하고, 입력·난수 테이프·단계별 게임 상태를 저장하며 게임별 동작 명세에 규칙을 문서화합니다. Web JavaScript, Bevy를 쓰는 Rust, 헤드리스 Godot GDScript로 재구축한 포트는 기록된 케이스를 읽고 공유 JSON 검증 프로토콜을 통해 동일한 추적을 생성해야 합니다. 2048, Chrome Dino, Canvas Bird, 낙하 블록류 등 검증된 예제가 포함되며, 에이전트 기반 워크플로로 게임과 엔진 포트 추가를 지원합니다. 리버스 엔지니어링, 동작 동등성 테스트, 원본 자산이나 코드를 복사하지 않고 게임 로직을 연구하는 데 적합합니다.
