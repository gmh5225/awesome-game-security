rea-games は、オープンソースゲームの挙動をリバースエンジニアリングし、クリーンルーム再実装がオリジナルと一致することを証明するためのフレームワークです。依存関係のない Node.js CLI はクロックと乱数を制御して未改変のオリジナルを記録し、入力・乱数テープ・各ステップのゲーム状態を保存し、ゲームごとの挙動仕様にルールを文書化します。Web JavaScript、Bevy を用いた Rust、ヘッドレス Godot GDScript で再構築したポートは記録ケースを読み込み、共通の JSON 検証プロトコルで同一のトレースを出力する必要があります。2048、Chrome Dino、Canvas Bird、落ちブロック系など検証済みの例が同梱され、エージェント駆動のワークフローでゲームとエンジンポートの追加にも対応します。リバースエンジニアリング、挙動等価性テスト、オリジナルのアセットやコードをコピーせずゲームロジックを学ぶ用途に適しています。
