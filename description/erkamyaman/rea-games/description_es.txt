rea-games es un marco para hacer ingeniería inversa del comportamiento de juegos de código abierto y demostrar que las reimplementaciones en sala limpia coinciden con el original. Una CLI de Node.js sin dependencias registra originales sin modificar controlando relojes y aleatoriedad, guarda entradas, cintas de números aleatorios y el estado del juego paso a paso, y documenta las reglas en especificaciones de comportamiento por juego. Los puertos reconstruidos en JavaScript web, Rust con Bevy o Godot GDScript sin cabeza leen casos grabados y deben producir trazas idénticas mediante un protocolo de verificación JSON compartido. El proyecto incluye ejemplos verificados como 2048, Chrome Dino, Canvas Bird y un juego de bloques que caen, y admite flujos impulsados por agentes para añadir juegos y ports de motor. Sirve para ingeniería inversa, pruebas de equivalencia conductual y estudiar la lógica del juego sin copiar recursos ni código originales.
