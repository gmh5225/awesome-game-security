rea-games è un framework per fare reverse engineering del comportamento di giochi open source e dimostrare che le reimplementazioni clean-room corrispondono all’originale. Una CLI Node.js priva di dipendenze registra gli originali non modificati controllando orologi e casualità, salva input, nastri di numeri casuali e lo stato di gioco a ogni passo, e documenta le regole in specifiche di comportamento per gioco. Le porte ricostruite in JavaScript web, Rust con Bevy o Godot GDScript headless leggono i casi registrati e devono produrre tracce identiche tramite un protocollo di verifica JSON condiviso. Il progetto include esempi verificati come 2048, Chrome Dino, Canvas Bird e un gioco a blocchi che cadono, e supporta flussi guidati da agenti per aggiungere giochi e port del motore. È adatto a reverse engineering, test di equivalenza comportamentale e allo studio della logica di gioco senza copiare asset o codice originali.
