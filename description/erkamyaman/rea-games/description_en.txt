rea-games is a framework for reverse-engineering open-source game behavior and proving that clean-room reimplementations match the original. A dependency-free Node.js CLI records unmodified originals by controlling clocks and randomness, saves inputs, random-number tapes, and per-step game state, and documents rules in per-game behavior specs. Rebuilt ports in web JavaScript, Rust with Bevy, or headless Godot GDScript read recorded cases and must produce identical traces through a shared JSON verify protocol. The project ships verified examples such as 2048, Chrome Dino, Canvas Bird, and a falling-blocks game, and supports agent-driven workflows to add games and engine ports. It suits reverse engineering, behavioral equivalence testing, and studying game logic without copying original assets or code.
