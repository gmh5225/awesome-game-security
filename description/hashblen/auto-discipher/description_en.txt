Auto-discipher is a Rust library for parsing and decrypting live network traffic between a specific anime-style online game client and its servers. It layers Ethernet, IP, and UDP parsing with a customized KCP transport, connection handshake handling, and XOR-protected command payloads that are validated and decoded as Protocol Buffer messages. Session keys are recovered automatically by brute-forcing time-windowed seeds with Mersenne Twister–style key derivation and protobuf-oracle checks, optionally using bundled RSA material where the protocol requires it. The crate exposes a sniffer-oriented API for turning raw captures into structured connection events and game commands. It targets reverse engineers and community tooling authors who need to inspect or build on that game’s encrypted wire protocol for research and companion applications.
