Auto-discipher 是一個 Rust 函式庫，用於解析並解密某款動漫風格線上遊戲用戶端與其伺服器之間的即時網路流量。它在 Ethernet、IP 與 UDP 解析之上疊加客製化的 KCP 傳輸、連線握手處理，以及經 XOR 保護的命令承載；這些承載經驗證後以 Protocol Buffer 訊息解碼。工作階段金鑰透過在時間視窗內暴力列舉種子、採用 Mersenne Twister 風格金鑰衍生並結合 protobuf 預言機檢查來自動還原，在協定需要時亦可選用內建 RSA 材料。此 crate 提供面向嗅探的 API，將原始擷取轉為結構化的連線事件與遊戲命令。面向需要檢視或基於該遊戲加密線路協定開展研究與配套工具開發的逆向工程師與社群工具作者。
