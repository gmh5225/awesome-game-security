Auto-discipher는 특정 애니메이션 스타일 온라인 게임 클라이언트와 서버 간 실시간 네트워크 트래픽을 파싱하고 복호화하는 Rust 라이브러리입니다. Ethernet, IP, UDP 파싱 위에 맞춤형 KCP 전송, 연결 핸드셰이크 처리, XOR로 보호된 명령 페이로드를 겹쳐 두며, 페이로드는 검증 후 Protocol Buffer 메시지로 디코딩됩니다. 세션 키는 시간 구간 시드를 브루트포스하고 Mersenne Twister 방식 키 유도와 protobuf 오라클 검사로 자동 복구되며, 프로토콜상 필요할 때는 번들된 RSA 자료를 선택적으로 사용합니다. 이 crate는 스니퍼 지향 API를 제공해 원시 캡처를 구조화된 연결 이벤트와 게임 명령으로 바꿉니다. 연구 및 동반 애플리케이션을 위해 해당 게임의 암호화된 와이어 프로토콜을 조사하거나 이를 기반으로 도구를 만들 역공학가와 커뮤니티 도구 제작자를 대상으로 합니다.
