Auto-discipher 是一个 Rust 库，用于解析并解密某款动漫风格在线游戏客户端与其服务器之间的实时网络流量。它在 Ethernet、IP 与 UDP 解析之上叠加定制化的 KCP 传输、连接握手处理，以及经 XOR 保护的命令载荷；这些载荷经校验后按 Protocol Buffer 消息解码。会话密钥通过在时间窗口内暴力枚举种子、采用 Mersenne Twister 风格密钥派生并结合 protobuf 预言机校验来自动恢复，在协议需要时还可选用内置 RSA 材料。该 crate 提供面向嗅探的 API，将原始抓包转换为结构化的连接事件与游戏命令。面向需要检视或基于该游戏加密线路协议开展研究与配套工具开发的逆向工程师与社区工具作者。
