Auto-discipher は、特定のアニメ調オンラインゲームのクライアントとサーバー間のライブネットワークトラフィックを解析・復号する Rust ライブラリです。Ethernet、IP、UDP の解析の上に、カスタマイズした KCP トランスポート、接続ハンドシェイク処理、および XOR で保護されたコマンドペイロードを重ね、ペイロードは検証のうえ Protocol Buffer メッセージとしてデコードします。セッション鍵は、時間窓付きシードの総当たり、Mersenne Twister 型の鍵導出、protobuf オラクル検証により自動復元され、プロトコル上必要な場合は同梱の RSA 素材を任意で利用します。本 crate はスニファ向け API を提供し、生キャプチャを構造化された接続イベントとゲームコマンドに変換します。研究やコンパニオンアプリのため、そのゲームの暗号化ワイヤプロトコルを調査・拡張したいリバースエンジニアやコミュニティツール作者を対象としています。
