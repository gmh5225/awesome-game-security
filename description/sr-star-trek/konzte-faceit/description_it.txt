Questo repository contiene il codice sorgente del client desktop Konzte Faceit e di KONZTE GUARD, un anti-cheat in modalità utente sviluppato per la piattaforma competitiva Combat Master. Lo stack combina un guscio desktop Rust e Tauri con un’interfaccia web basata su HTML, CSS e JavaScript, librerie Rust native per il servizio di guardia e C# opzionale per scansioni Windows più approfondite. KONZTE GUARD viene eseguito come servizio Windows in background che monitora Combat Master per errori di configurazione legati al kernel, moduli cheat e injector noti, firme di memoria eseguibile e file di gioco manomessi, quindi segnala i risultati e caricamenti di file limitati per la revisione dello staff. Utilizza database di firme, binding dell’ID hardware, aggiornamenti automatici verificati con ed25519 e hook dell’installer che registrano la guardia con privilegi di amministratore. Il rilascio è destinato a ricercatori, giocatori e analisti della sicurezza che vogliono studiare come un client di matchmaking di terze parti abbia implementato il comportamento anti-cheat e cosa il suo installer abbia effettivamente distribuito su Windows.
