Este repositorio contiene el código fuente del cliente de escritorio Konzte Faceit y KONZTE GUARD, un anti-cheat en modo usuario diseñado para la plataforma competitiva Combat Master. La pila combina un shell de escritorio en Rust y Tauri con una interfaz web basada en HTML, CSS y JavaScript, bibliotecas nativas en Rust para el servicio de guardia y C# opcional para escaneos más profundos en Windows. KONZTE GUARD se ejecuta como servicio de Windows en segundo plano que monitoriza Combat Master en busca de configuraciones incorrectas relacionadas con el kernel, módulos de trampas e inyectores conocidos, firmas de memoria ejecutable y archivos de juego alterados, y luego informa resultados y cargas limitadas de archivos para revisión del personal. Utiliza bases de firmas, vinculación por ID de hardware, actualizaciones automáticas verificadas con ed25519 y ganchos del instalador que registran la guardia con privilegios de administrador. La publicación está pensada para investigadores, jugadores y analistas de seguridad que quieran estudiar cómo un cliente de emparejamiento de terceros implementó el comportamiento anti-cheat y qué desplegó realmente su instalador en Windows.
