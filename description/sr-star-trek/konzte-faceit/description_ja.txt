このリポジトリには、Konzte Faceit デスクトップクライアントと、Combat Master 競技プラットフォーム向けに構築されたユーザーモードのアンチチート KONZTE GUARD のソースコードが含まれます。スタックは Rust と Tauri のデスクトップシェルに、HTML・CSS・JavaScript ベースの Web UI、ガードサービス用のネイティブ Rust ライブラリ、およびより深い Windows スキャン用のオプションの C# を組み合わせています。KONZTE GUARD はバックグラウンドの Windows サービスとして動作し、Combat Master に対してカーネル関連の誤設定、既知のチートモジュールとインジェクター、実行可能メモリのシグネチャ、改ざんされたゲームファイルを監視し、結果と限定されたファイルアップロードをスタッフレビュー用に報告します。シグネチャデータベース、ハードウェア ID バインディング、ed25519 検証付き自己更新、管理者権限でガードを登録するインストーラーフックを使用します。本リリースは、サードパーティのマッチメイキングクライアントがアンチチートをどう実装したか、インストーラーが Windows に実際に何を展開したかを研究したい研究者、プレイヤー、セキュリティアナリスト向けです。
