이 저장소에는 Konzte Faceit 데스크톱 클라이언트와 Combat Master 경쟁 플랫폼용으로 만들어진 사용자 모드 안티치트인 KONZTE GUARD의 소스 코드가 포함되어 있습니다. 스택은 Rust와 Tauri 데스크톱 셸, HTML·CSS·JavaScript 기반 웹 UI, 가드 서비스용 네이티브 Rust 라이브러리, 더 깊은 Windows 스캔을 위한 선택적 C#을 결합합니다. KONZTE GUARD는 백그라운드 Windows 서비스로 실행되며 Combat Master의 커널 관련 잘못된 구성, 알려진 치트 모듈과 인젝터, 실행 가능 메모리 시그니처, 변조된 게임 파일을 모니터링한 뒤 결과와 제한된 파일 업로드를 스태프 검토용으로 보고합니다. 시그니처 데이터베이스, 하드웨어 ID 바인딩, ed25519 검증 자체 업데이트, 관리자 권한으로 가드를 등록하는 설치 후크를 사용합니다. 본 릴리스는 서드파티 매치메이킹 클라이언트가 안티치트 동작을 어떻게 구현했는지, 설치 프로그램이 Windows에 실제로 무엇을 배포했는지 연구하려는 연구자, 플레이어, 보안 분석가를 위한 것입니다.
