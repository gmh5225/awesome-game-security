This repository contains the source code for the Konzte Faceit desktop client and KONZTE GUARD, a user-mode anti-cheat built for the Combat Master competitive platform. The stack combines a Rust and Tauri desktop shell with a web-based HTML, CSS, and JavaScript UI, plus native Rust libraries for the guard service and optional C# for deeper Windows scanning. KONZTE GUARD runs as a background Windows service that monitors Combat Master for kernel-related misconfigurations, known cheat modules and injectors, executable memory signatures, and tampered game files, then reports results and limited file uploads for staff review. It uses signature databases, hardware ID binding, ed25519-verified self-updates, and installer hooks that register the guard with administrator privileges. The release is intended for researchers, players, and security analysts who want to study how a third-party matchmaking client implemented anti-cheat behavior and what its installer actually deployed on Windows.
