Этот репозиторий содержит исходный код настольного клиента Konzte Faceit и KONZTE GUARD — античита в пользовательском режиме, созданного для соревновательной платформы Combat Master. Стек объединяет настольную оболочку на Rust и Tauri с веб-интерфейсом на HTML, CSS и JavaScript, нативные библиотеки Rust для службы охраны и опциональный C# для более глубокого сканирования Windows. KONZTE GUARD работает как фоновая служба Windows, отслеживающая Combat Master на предмет ошибок конфигурации, связанных с ядром, известных чит-модулей и инжекторов, сигнатур исполняемой памяти и изменённых игровых файлов, затем сообщает результаты и ограниченные загрузки файлов для проверки персоналом. Используются базы сигнатур, привязка к аппаратному ID, самообновления с проверкой ed25519 и хуки установщика, регистрирующие охрану с правами администратора. Выпуск предназначен для исследователей, игроков и аналитиков безопасности, которые хотят изучить, как сторонний клиент матчмейкинга реализовал античит и что его установщик фактически развернул в Windows.
