本仓库包含 Konzte Faceit 桌面客户端与 KONZTE GUARD 的源代码；后者是为 Combat Master 竞技平台构建的用户态反作弊组件。技术栈采用 Rust 与 Tauri 桌面外壳，配合基于 HTML、CSS 与 JavaScript 的 Web 界面，辅以用于守护服务的原生 Rust 库，以及可选的 C# 以实现更深入的 Windows 扫描。KONZTE GUARD 以后台 Windows 服务运行，监控 Combat Master 是否存在与内核相关的错误配置、已知作弊模块与注入器、可执行内存特征，以及被篡改的游戏文件，并将结果与有限的文件上传上报供工作人员审核。系统使用特征库、硬件 ID 绑定、经 ed25519 验证的自动更新，以及以管理员权限注册守护程序的安装钩子。本发布面向希望研究第三方匹配客户端如何实现反作弊行为，以及其安装程序在 Windows 上实际部署了何物的研究人员、玩家与安全分析人员。
