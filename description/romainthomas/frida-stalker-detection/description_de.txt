Dieses Repository ist ein Proof-of-Concept, der erkennt, wenn Fridas Stalker-Engine auf Android ARM64 und Linux x86-64 den aktuellen Thread aktiv trace. Die Erkennung nutzt Inline-Assembler, der Canary-Werte in Stack-Slots jenseits der Red Zone platziert, in der Stalker Backup-Register speichert, einen Kontrollflussübergang erzwingt, der Stalkers Kontextwechsel auslöst, und prüft, ob diese Canaries über wiederholte Durchläufe überschrieben wurden. Der Code ist in C geschrieben, wird mit CMake gebaut und gegen das Frida-Gum-Devkit für eingebettete Stalker-Tests je Plattform gelinkt; ein Justfile automatisiert Linux- und Android-Builds sowie Läufe auf dem Gerät. Es eignet sich für Game-Security-, Anti-Cheat- und Härtungsteams für mobile oder native Apps, die dynamische Instrumentierung über Stalker erkennen müssen, statt nur generische Frida-Präsenzprüfungen.
