本リポジトリは、Android ARM64 および Linux x86-64 上で Frida の Stalker エンジンが現在のスレッドをアクティブにトレースしているかを検出する概念実証です。検出はインラインアセンブリに依存し、red zone の外側で Stalker がバックアップレジスタを保存するスタックスロットにカナリア値を配置し、Stalker のコンテキスト切り替えを引き起こす制御フロー遷移を強制し、複数ラウンドにわたってそれらのカナリアが上書きされたかを確認します。コードは C で書かれ、CMake でビルドし、各プラットフォームでの組み込み Stalker テストのために Frida Gum devkit にリンクします。justfile が Linux と Android のビルドおよび実機実行を自動化します。汎用的な Frida 存在チェックだけでなく Stalker 経由の動的インストルメンテーションを見つける必要がある、ゲームセキュリティ、チート対策、モバイルまたはネイティブアプリのハードニングチーム向けです。
