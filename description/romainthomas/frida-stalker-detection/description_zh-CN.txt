本仓库是一个概念验证，用于检测 Frida 的 Stalker 引擎是否在 Android ARM64 与 Linux x86-64 上正在对当前线程进行追踪。检测方式依赖内联汇编：在 red zone 之外、Stalker 保存备份寄存器所用的栈槽中放置金丝雀值，强制发生会触发 Stalker 上下文切换的控制流转移，并在多轮重复中检查这些金丝雀是否被覆盖。代码为 C 语言编写，使用 CMake 构建，并链接 Frida Gum devkit 以便在各平台上嵌入 Stalker 测试；justfile 可自动化 Linux 与 Android 的构建及真机运行。适用于游戏安全、反作弊以及移动或原生应用加固团队，需要在通用 Frida 存在检测之外，专门识别通过 Stalker 进行的动态插桩。
