This repository is a proof-of-concept that detects when Frida’s Stalker engine is actively tracing the current thread on Android ARM64 and Linux x86-64. Detection relies on inline assembly that plants canary values in stack slots beyond the red zone where Stalker saves backup registers, forces a control-flow transition that triggers Stalker’s context switch, and checks whether those canaries were overwritten across repeated rounds. The code is written in C, built with CMake, and links against the Frida Gum devkit for embedded Stalker tests on each platform, with a justfile automating Linux and Android builds and on-device runs. It suits game security, anti-cheat, and mobile or native app hardening teams that need to spot dynamic instrumentation via Stalker rather than only generic Frida presence checks.
