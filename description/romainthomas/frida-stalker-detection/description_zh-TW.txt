本儲存庫是一個概念驗證，用於偵測 Frida 的 Stalker 引擎是否在 Android ARM64 與 Linux x86-64 上正在對目前執行緒進行追蹤。偵測方式依賴內嵌組合語言：在 red zone 之外、Stalker 保存備份暫存器所用的堆疊槽位中放置 Canary 值，強制發生會觸發 Stalker 上下文切換的控制流程轉移，並在多輪重複中檢查這些 Canary 是否被覆寫。程式碼以 C 語言撰寫，使用 CMake 建置，並連結 Frida Gum devkit 以便在各平台上嵌入 Stalker 測試；justfile 可自動化 Linux 與 Android 的建置及裝置端執行。適用於遊戲安全、反作弊以及行動或原生應用強化團隊，需要在一般 Frida 存在偵測之外，專門識別透過 Stalker 進行的動態插樁。
