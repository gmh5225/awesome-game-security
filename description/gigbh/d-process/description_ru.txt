d-process — это генератор приманочных процессов для Linux, который создаёт и запускает поддельные фоновые процессы с указанным пользователем именем исполняемого файла. Оболочка shell по требованию компилирует минимальную C-программу и запускает её через nohup, чтобы процесс отображался в списке системных процессов под выбранным именем. Пользователи могут создавать приманки одной командой и завершать все запущенные подделки через подкоманду killall. Написан на C и shell-скриптах, предназначен для исследований безопасности игр, тестирования античита и сценариев, где необходимо изучать или обходить перечисление процессов или проверки присутствия.
