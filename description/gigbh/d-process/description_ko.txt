d-process는 사용자가 지정한 실행 파일 이름으로 가짜 백그라운드 프로세스를 생성하고 실행하는 Linux용 디코이 프로세스 생성기입니다. 셸 래퍼가 필요에 따라 최소한의 C 프로그램을 컴파일하고 nohup으로 실행하여 선택한 이름으로 시스템 프로세스 목록에 표시됩니다. 단일 명령으로 디코이를 생성할 수 있으며, killall 하위 명령으로 실행 중인 모든 가짜 프로세스를 종료할 수 있습니다. C와 셸 스크립트로 작성되었으며, 게임 보안 연구, 안티치트 테스트, 프로세스 열거 또는 존재 확인을 연구하거나 우회해야 하는 시나리오를 대상으로 합니다.
