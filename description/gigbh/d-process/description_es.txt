d-process es un generador de procesos señuelo para Linux que crea y ejecuta procesos falsos en segundo plano con un nombre de ejecutable especificado por el usuario. Un wrapper de shell compila bajo demanda un programa C mínimo y lo lanza con nohup para que el proceso aparezca en la lista de procesos del sistema con el nombre elegido. Los usuarios pueden crear señuelos con un solo comando y terminar todos los falsos en ejecución mediante un subcomando killall. Escrito en C y script shell, está orientado a la investigación en seguridad de juegos, pruebas anti-trampas y escenarios donde la enumeración de procesos o las comprobaciones de presencia deben estudiarse o evitarse.
