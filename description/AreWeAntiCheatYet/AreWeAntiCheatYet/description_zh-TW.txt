Are We Anti-Cheat Yet 是一個由社群維護的網站，用於追蹤哪些 PC 遊戲在 GNU/Linux、Proton 和 Wine 上支援反作弊。遊戲資料儲存在 JSON 目錄中，並以靜態生成的 Next.js 網站形式發布，提供可搜尋的表格與卡片檢視、專屬遊戲頁面、狀態分類、更新時間軸以及 RSS 訂閱。每款遊戲依 Linux 反作弊就緒程度分類（已支援、可執行、計畫中、已損壞或已拒絕），並列出所部署的反作弊系統，例如 Easy Anti-Cheat 和 BattlEye。此專案以 TypeScript、React 和 Mantine 建構，為 Linux 玩家和 Steam Deck 使用者提供線上遊戲相容性與開發者承諾的透明參考，且不宣傳繞過技術。
