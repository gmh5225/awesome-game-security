Are We Anti-Cheat Yet 是一个由社区维护的网站，用于追踪哪些 PC 游戏在 GNU/Linux、Proton 和 Wine 上支持反作弊。游戏数据存储在 JSON 目录中，并以静态生成的 Next.js 站点形式发布，提供可搜索的表格与卡片视图、独立游戏页面、状态分类、更新时间线以及 RSS 订阅。每款游戏按 Linux 反作弊就绪程度分类（已支持、可运行、计划中、已损坏或已拒绝），并列出所部署的反作弊系统，例如 Easy Anti-Cheat 和 BattlEye。该项目基于 TypeScript、React 和 Mantine 构建，为 Linux 玩家和 Steam Deck 用户提供在线游戏兼容性与开发者承诺的透明参考，且不推广绕过技术。
