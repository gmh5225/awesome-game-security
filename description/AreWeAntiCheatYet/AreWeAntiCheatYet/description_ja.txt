Are We Anti-Cheat Yet は、GNU/Linux、Proton、Wine 上でどの PC ゲームがアンチチートに対応しているかを追跡するコミュニティ運営の Web サイトです。ゲームデータは JSON カタログに保存され、静的生成された Next.js サイトとして公開され、検索可能なテーブルとカードビュー、専用ゲームページ、ステータス内訳、更新タイムライン、RSS フィードを備えています。各タイトルは Linux でのアンチチート対応状況（対応済み、動作中、予定、不具合、拒否）で分類され、Easy Anti-Cheat や BattlEye など導入されているアンチチートシステムも一覧表示されます。TypeScript、React、Mantine で構築されており、Linux ゲーマーと Steam Deck ユーザーにオンラインプレイの互換性と開発者のコミットメントに関する透明な参照情報を提供します。バイパス手法の推奨は行いません。
