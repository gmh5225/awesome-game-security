Are We Anti-Cheat Yet는 GNU/Linux, Proton, Wine에서 어떤 PC 게임이 안티치트를 지원하는지 추적하는 커뮤니티 운영 웹사이트입니다. 게임 데이터는 JSON 카탈로그에 저장되며, 검색 가능한 테이블 및 카드 뷰, 전용 게임 페이지, 상태 분류, 업데이트 타임라인, RSS 피드를 갖춘 정적 생성 Next.js 사이트로 게시됩니다. 각 타이틀은 Linux 안티치트 준비 상태(지원됨, 실행 중, 예정, 고장, 거부됨)로 분류되며, Easy Anti-Cheat 및 BattlEye와 같이 배포된 안티치트 시스템도 나열됩니다. TypeScript, React, Mantine으로 구축되어 Linux 게이머와 Steam Deck 사용자에게 온라인 플레이 호환성 및 개발사 약속에 대한 투명한 참고 자료를 제공하며, 우회 기법은 홍보하지 않습니다.
