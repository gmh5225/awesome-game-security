Game Integrity is an exploratory research project that uses formal semantics to study whether an authoritative game server can be shown to accept only histories that match a legal state-transition specification, even under a stated adversarial model. It defines finite deterministic games through admissibility relations and partial transition functions, with Tic-Tac-Toe as the first worked example and a matching Lean 4 formalization that encodes reachability, terminal closure, and related structural propositions. The repository bundles a draft manuscript, formal definitions with proof obligations still marked as sorry, and reference material aimed at connecting game-theoretic legality to execution integrity rather than relying solely on external anti-cheat detection. The work is early-stage academic formal methods research at version 0.2 and does not yet claim an end-to-end security theorem for real implementations in hostile environments.
