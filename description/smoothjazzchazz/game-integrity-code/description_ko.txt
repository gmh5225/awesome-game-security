Game Integrity는 형식 게임 의미론과, 권위 있는 게임 구현이 적대적 조건에서 추상적 합법 상태 전이 명세와 일치하는 기록만 수락할 수 있는 방식을 연구하는 초기 단계 연구 프로젝트이다. 상태 의존 허용 관계, Option 값 단계로 인코딩된 부분 전이 함수, 귀납적 합법 기록과 도달 가능성으로 유한 결정적 게임을 정의하며, 틱택토를 첫 사례 연구로 삼는다. Lean 4 형식화는 원고의 정의와 기술된 명제를 반영하고, 논문 초안은 결과 클래스, 전이 제한, 유한 대국 종료 논증을 전개한다. 본 작업은 탐색적이며 아직 구현 수준의 완전한 보안 정리를 주장하지 않는다. 게임 보안, 안티치트 기초, 전이계 의미론과 적대적 실행 무결성의 연결에 관심 있는 연구자를 대상으로 한다.
