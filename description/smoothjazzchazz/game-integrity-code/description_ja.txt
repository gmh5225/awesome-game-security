Game Integrity は初期段階の研究プロジェクトであり、形式ゲーム意味論と、権威あるゲーム実装が対抗的条件下で抽象的な合法状態遷移仕様と一致する履歴のみを受け入れる可能性を研究する。状態依存の許容関係、Option 値のステップとして符号化された部分遷移関数、帰納的な合法履歴と到達可能性により有限決定ゲームを定義し、三目並べを最初のケーススタディとする。Lean 4 の形式化は原稿の定義と述べられた命題を反映し、草案論文では結果クラス、遷移制限、有限プレイの終了性議論を展開する。本研究は探索的であり、実装レベルの完全なセキュリティ定理はまだ主張していない。ゲームセキュリティ、チート対策の基礎、遷移系意味論と対抗的実行完全性の接続に関心のある研究者を対象とする。
