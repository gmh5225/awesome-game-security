Binary Ninja 向けプラグインで、混合 boolean-算術式の簡約、不透明述語の畳み込み、制御フローの平坦化の復元により、保護されたネイティブコードを難読化解除し、ディスク上のバイナリは変更しません。Python で実装され、MLIL と HLIL パスで検証済みの書き換えを実行し、D-810 スタイルの MBA ルール、組み込み線形 MBA 簡約器、任意で Trail of Bits の CoBRA を用い、Z3 による証明で条件畳み込みとルール適用を制御します。OLLVM 型の置換、Hikari 型の間接分岐、scratch-slot とアロケーションの往復、フラグベースの比較、x86・x64・ARM64 の PE・ELF・Mach-O バイナリ上の平坦化ディスパッチャを対象とします。主な利用者は、商用パッカー、改ざん防止、マルウェアや保護されたゲームクライアントなどの類似難読化を解析する際に、より読みやすい HLIL が必要なリバースエンジニアとゲームセキュリティアナリストです。
