This is a Binary Ninja plugin that deobfuscates protected native code by simplifying mixed boolean-arithmetic expressions, folding opaque predicates, and recovering control-flow flattening without modifying the on-disk binary. It is implemented in Python and runs verified rewrites in MLIL and HLIL passes, using D-810-style MBA rules, a built-in linear MBA simplifier, and optionally Trail of Bits CoBRA, with Z3 proofs gating condition folding and rule application. It targets OLLVM-style substitution, Hikari-style indirect branches, scratch-slot and allocation round trips, flag-based comparisons, and flattened dispatchers on x86, x64, and ARM64 PE, ELF, and Mach-O binaries. The primary audience is reverse engineers and game-security analysts who need clearer HLIL when working through commercial packers, anti-tamper, and similar obfuscation in malware or protected game clients.
