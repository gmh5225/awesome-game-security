InGameOverlay는 서드파티 애플리케이션의 그래픽 렌더러를 후킹하여 그 안에 사용자 정의 UI 오버레이를 그리는 크로스 플랫폼 C++ 라이브러리입니다. Windows, Linux, macOS를 지원하며 OpenGL, Vulkan, DirectX 9부터 12, Metal과 통합하고, 플랫폼별 렌더러 후크와 공유 감지·리소스 계층을 사용하므로 호스트 프로그램의 소스에 접근할 필요가 없습니다. 코드베이스는 CMake로 빌드되며, detour 기반 가로채기 인프라와 후크를 ImGui와 결합한 검증용 예제 및 테스트 타깃을 포함합니다. DLL이나 공유 라이브러리를 주입해 프로세스 내 도구, 런타임 시각화, 디버깅을 수행하고, 기존 게임 프레임과 오버레이 UI를 합성해야 하는 게임 보안 또는 리버스 엔지니어링 워크플로를 다루는 개발자를 대상으로 합니다.
