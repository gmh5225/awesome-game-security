InGameOverlay は、サードパーティアプリケーションのグラフィックスレンダラをフックして、その内部にカスタム UI オーバーレイを描画するクロスプラットフォームの C++ ライブラリです。Windows、Linux、macOS をサポートし、OpenGL、Vulkan、DirectX 9 から 12、Metal と統合し、プラットフォーム固有のレンダラフックと共有の検出・リソース層を用いるため、ホストプログラムのソースコードへのアクセスは不要です。コードベースは CMake でビルドされ、detour ベースのインターセプト基盤に加え、フックと ImGui を組み合わせた検証用のサンプルおよびテストターゲットを含みます。DLL や共有ライブラリを注入してプロセス内ツール、ランタイム可視化、デバッグを行い、既存のゲームフレームとオーバーレイ UI を合成する必要があるゲームセキュリティやリバースエンジニアリングのワークフローを扱う開発者を対象としています。
