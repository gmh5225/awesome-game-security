InGameOverlay es una biblioteca C++ multiplataforma que dibuja superposiciones de interfaz de usuario personalizadas dentro de aplicaciones de terceros mediante el enganche de sus renderizadores gráficos. Admite Windows, Linux y macOS y se integra con OpenGL, Vulkan, DirectX 9 a 12 y Metal, usando hooks de renderizado específicos de cada plataforma y una capa compartida de detección y recursos, sin requerir acceso al código fuente del programa anfitrión. La base de código se construye con CMake e incluye infraestructura de intercepción basada en detours, además de objetivos de ejemplo y prueba que combinan los hooks con ImGui para validación. Está dirigida a desarrolladores que inyectan DLL o bibliotecas compartidas para herramientas in-process, visualización en tiempo de ejecución, depuración y flujos de trabajo de seguridad de juegos o ingeniería inversa en los que la UI superpuesta debe componerse con el fotograma del juego existente.
