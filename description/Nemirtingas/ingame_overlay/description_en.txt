InGameOverlay is a cross-platform C++ library that draws custom user-interface overlays inside third-party applications by hooking their graphics renderers. It supports Windows, Linux, and macOS and integrates with OpenGL, Vulkan, DirectX 9 through 12, and Metal, using platform-specific renderer hooks and a shared detection and resource layer rather than requiring source access to the host program. The codebase is built with CMake and includes detour-based interception plumbing plus example and test targets that pair the hooks with ImGui for validation. It is aimed at developers who inject DLLs or shared libraries for in-process tooling, runtime visualization, debugging, and game-security or reverse-engineering workflows where overlay UI must composite with an existing game frame.
