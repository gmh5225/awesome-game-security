gh-remake 是一门结构化的游戏黑客与逆向工程课程，将大量教程材料重新编排为希伯来语课程站点、简短的英语课程视频，以及由现场录制素材剪辑而成的较长系列「从零开始的游戏黑客」。Python 负责目录生成与视频构建，课程内容融合 Cheat Engine 内存操作、小型 C++ 演示、HyperFrames 渲染以及 Azure Speech 旁白。课程从基础涵盖内存扫描、IDA 与 Ghidra 类工具、注入与挂钩、渲染叠加层、内核与反作弊内部机制，以及相关的 crackme 与恶意软件主题，并划分为多条学习路径。面向离线的单人游戏与开源练习目标，为学习游戏安全、反作弊机制与逆向工程的学生和从业者提供动手实验环境。
