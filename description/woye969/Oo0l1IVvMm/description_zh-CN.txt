Oo0l1IVvMm 是一款可选启用的 IDA Pro 插件，用于改善对控制流平坦化及 OLLVM 风格混淆二进制的 Hex-Rays 反编译效果。基于 Python 调用 IDA 与 Hex-Rays API，提供 MIN 模式：通过 unflat valrange 去平坦化、指令物化与 D-810 简化处理经典中央调度器平坦化；MAX 模式：针对编码的内联 jmp-reg 分发，进行具体链解析、微码边重写与死调度器移除。默认处于未启用状态，F5 速度与原版一致，直至从插件菜单或快捷键选择模式；可集成 Capstone 解码，并可选运行时快照以支持基于表的分发。捆绑的 seagull_core 分析器可在 IDA 外独立进行链分析。面向需要从重度平坦化的商业或受保护可执行文件中得到可读伪代码、且不希望持续后台开销的逆向工程师与游戏安全分析人员。
