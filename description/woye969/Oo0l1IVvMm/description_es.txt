Oo0l1IVvMm es un complemento opt-in de IDA Pro que mejora la descompilación Hex-Rays de binarios ofuscados con aplanamiento de flujo de control y estilo OLLVM. Escrito en Python contra las API de IDA y Hex-Rays, ofrece el modo MIN para aplanamiento clásico con dispatcher central mediante unflattening unflat valrange, materialización de instrucciones y simplificación D-810, y el modo MAX para dispatch jmp-reg inline codificado con resolución de cadenas concretas, reescritura de aristas de microcódigo y eliminación de dispatchers muertos. Permanece desactivado por defecto, de modo que F5 mantiene la velocidad vanilla hasta que elija un modo desde el menú del complemento o un atajo, y puede integrar decodificación Capstone más instantáneas runtime opcionales para dispatch basado en tablas. El analizador seagull_core incluido permite análisis de cadenas autónomo fuera de IDA. Está dirigido a ingenieros inversos y analistas de seguridad en juegos que necesitan pseudocódigo legible a partir de ejecutables comerciales o protegidos muy aplanados sin sobrecarga constante en segundo plano.
