Oo0l1IVvMm は、オプトイン型の IDA Pro プラグインで、制御フロー平坦化および OLLVM スタイルの難読化バイナリに対する Hex-Rays 逆コンパイルを改善します。Python で IDA および Hex-Rays API を利用し、MIN モードでは unflat valrange によるアンフラット化、命令のマテリアライズ、D-810 簡略化により古典的な中央ディスパッチャ平坦化に対応し、MAX モードではエンコードされたインライン jmp-reg ディスパッチに対し、具体チェーン解決、マイクロコードエッジの書き換え、デッドディスパッチャ除去を行います。既定では無効のため、プラグインメニューまたはホットキーでモードを選ぶまで F5 は標準と同じ速度です。Capstone デコードおよび表ベースディスパッチ向けの任意ランタイムスナップショットも統合可能です。同梱の seagull_core アナライザは IDA 外でのスタンドアロンなチェーン解析をサポートします。商用または保護された実行ファイルの高度な平坦化から読みやすい疑似コードが必要で、常時バックグラウンド負荷を避けたいリバースエンジニアおよびゲームセキュリティ分析者向けです。
