Oo0l1IVvMm is an opt-in IDA Pro plugin that improves Hex-Rays decompilation of control-flow-flattened and OLLVM-style obfuscated binaries. Written in Python against the IDA and Hex-Rays APIs, it offers MIN mode for classic central-dispatcher flattening via unflat valrange unflattening, instruction materialization, and D-810 simplification, and MAX mode for encoded inline jmp-reg dispatch with concrete chain resolution, microcode edge rewriting, and dead-dispatcher removal. It stays disarmed by default so F5 matches vanilla speed until you choose a mode from the plugin menu or hotkey, and it can integrate Capstone decoding plus optional runtime snapshots for table-based dispatch. The bundled seagull_core analyzer supports standalone chain analysis outside IDA. It targets reverse engineers and game-security analysts who need readable pseudocode from heavily flattened commercial or protected executables without constant background overhead.
