Oo0l1IVvMm — подключаемый по желанию плагин для IDA Pro, улучшающий декомпиляцию Hex-Rays бинарников с control-flow flattening и обфускацией в стиле OLLVM. Написан на Python с использованием API IDA и Hex-Rays; режим MIN обрабатывает классическое flattening с центральным диспетчером через unflat valrange unflattening, материализацию инструкций и упрощение D-810, режим MAX — закодированный inline jmp-reg dispatch с разрешением конкретных цепочек, перезаписью рёбер микрокода и удалением «мёртвых» диспетчеров. По умолчанию отключён, поэтому F5 работает с той же скоростью, что и без плагина, пока вы не выберете режим в меню или по горячей клавише; возможна интеграция декодирования Capstone и опциональных снимков runtime для table-based dispatch. В комплекте анализатор seagull_core поддерживает автономный анализ цепочек вне IDA. Ориентирован на reverse-инженеров и аналитиков игровой безопасности, которым нужен читаемый псевдокод из сильно «сплющенных» коммерческих или защищённых исполняемых файлов без постоянной фоновой нагрузки.
