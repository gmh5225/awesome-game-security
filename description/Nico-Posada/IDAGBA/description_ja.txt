IDAGBA は IDA Pro 向けのローダーおよびプラグインで、Game Boy Advance の ROM と multiboot イメージの解析を自動化します。Python で書かれ、IDA Pro 9.1 以降に対応し、GBA のメモリマップを再構築し、I/O レジスタとハードウェア構造にラベルを付け、devkitARM 形式の起動から main までをトレースし、ロード時に ROM から RAM へのコピーを適用して、デコンパイル結果が実行時レイアウトと一致するようにします。一般的な GBA ツールチェーン向けのシグネチャライブラリを同梱し、BIOS のソフトウェア割り込み呼び出しと Thumb コールスタブを通常の型付き呼び出しに昇格させ、カートリッジ、ホームブリュー、リンクケーブル multiboot 形式をサポートします。商業用またはホームブリューの GBA バイナリを、IDA で生の ARM ダンプを手作業で調整せずに読みやすくデコンパイルしたいリバースエンジニアとセキュリティ研究者を対象としています。
