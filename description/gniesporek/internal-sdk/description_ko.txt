이 프로젝트는 Counter-Strike 2용 C++ 내부 소프트웨어 개발 키트로, Windows DLL로 로드되어 실행 중인 게임 클라이언트와 통합됩니다. 패턴 스캔으로 Source 2 인터페이스와 함수를 해석하고, 런타임 schema 오프셋 맵을 구축하며, 엔티티 추가·제거 및 사용자 명령 처리용 클라이언트 훅으로 공급되는 스레드형 엔티티 캐시를 유지합니다. 렌더링은 DirectX 11과 ImGui 기반 오버레이를 사용하고, MinHook 디투어는 엔진·입력·프레젠테이션 경로를 대상으로 월드-투-스크린 시각화, trace 및 hitbox 기반 보조 로직, 클라이언트 측 예측 단계 등의 기능을 담당합니다. 코드베이스에는 엔티티, 본, trace, convar, 수학 유틸리티용 Valve 대면 재사용 계층이 포함되며 MinHook, FreeType, ImGui가 묶인 Visual Studio 솔루션으로 패키징됩니다. 내부 CS2 클라이언트가 gameplay를 후킹하고 게임 상태를 읽으며 프레임 위에 그리는 방식에 대한 구체적 참고가 필요한 리버스 엔지니어 및 게임 보안 연구자를 대상으로 합니다.
