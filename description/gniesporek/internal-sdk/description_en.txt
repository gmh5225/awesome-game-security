This project is a C++ internal software development kit for Counter-Strike 2 that loads as a Windows DLL and integrates with the live game client. It resolves Source 2 interfaces and functions via pattern scanning, builds a runtime schema offset map, and maintains a threaded entity cache fed by client hooks for entity add/remove and user command handling. Rendering uses DirectX 11 with an ImGui-based overlay, while MinHook detours cover engine, input, and presentation paths for features such as world-to-screen visuals, trace and hitbox-driven assistance logic, and client-side prediction stages. The codebase includes reusable Valve-facing layers for entities, bones, traces, convars, and math utilities, packaged as a Visual Studio solution with bundled MinHook, FreeType, and ImGui. It is aimed at reverse engineers and game-security researchers who need a concrete reference for how internal CS2 clients hook gameplay, read game state, and draw on top of the frame.
