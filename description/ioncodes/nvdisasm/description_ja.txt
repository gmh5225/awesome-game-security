本プロジェクトは、コンパイル済み CUDA およびグラフィックスシェーダのマシンコードをデコードするために用いる NVIDIA GPU SASS 逆アセンブラのアーキテクチャ定義を収集しています。Kepler から Hopper までの GPU 世代とストリーミング・マルチプロセッサ版ごとに整理され、各アーキテクチャのマシン記述、命令エンコーディングパターン、NVIDIA 形式の逆アセンブラ形式における実行パイプのレイテンシファイルが含まれます。仕様では SASS ニーモニック、レジスタとプリディケートの規則、CUDA ELF リロケーション、SASS のみのエンコーディング検証などの検証条件が定義されています。リバースエンジニアやゲームセキュリティ分析者は、プロプライエタリな CUDA ツールキット逆アセンブラのみに頼らず、これらの資料で GPU カーネルとシェーダを調査できます。
