This project collects NVIDIA GPU SASS disassembler architecture definitions used to decode compiled CUDA and graphics shader machine code. It is organized by GPU generation and streaming-multiprocessor version from Kepler through Hopper, with per-architecture machine description, instruction encoding pattern, and execution-pipe latency files in NVIDIA-style disassembler formats. The specifications define SASS mnemonics, register and predicate rules, CUDA ELF relocations, and validation conditions such as SASS-only encoding checks. Reverse engineers and game security analysts use these materials to inspect GPU kernels and shaders without relying solely on the proprietary CUDA toolkit disassembler.
