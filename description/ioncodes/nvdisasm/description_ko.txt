이 프로젝트는 컴파일된 CUDA 및 그래픽스 셰이더 머신 코드를 디코딩하는 데 쓰이는 NVIDIA GPU SASS 디스어셈블러 아키텍처 정의를 모아 둡니다. Kepler부터 Hopper까지 GPU 세대와 스트리밍 멀티프로세서 버전별로 구성되어 있으며, 아키텍처마다 기계 설명, 명령 인코딩 패턴, NVIDIA 스타일 디스어셈블러 형식의 실행 파이프 지연 파일이 포함됩니다. 사양에는 SASS 니모닉, 레지스터 및 프리디케이트 규칙, CUDA ELF 재배치, SASS 전용 인코딩 검사와 같은 검증 조건이 정의되어 있습니다. 리버스 엔지니어와 게임 보안 분석가는 독점 CUDA 툴킷 디스어셈블러에만 의존하지 않고 이 자료로 GPU 커널과 셰이더를 검사할 수 있습니다.
