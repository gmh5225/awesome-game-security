Этот проект собирает определения архитектуры дизассемблера SASS для GPU NVIDIA, используемые для декодирования скомпилированного машинного кода CUDA и графических шейдеров. Материалы сгруппированы по поколениям GPU и версиям потокового мультипроцессора — от Kepler до Hopper; для каждой архитектуры есть описание машины, шаблоны кодирования инструкций и файлы задержек конвейеров исполнения в форматах дизассемблера в стиле NVIDIA. В спецификациях заданы мнемоники SASS, правила регистров и предикатов, релокации ELF CUDA и условия проверки, в том числе контроль кодирования только SASS. Специалисты по обратной разработке и аналитики игровой безопасности используют эти материалы для разбора GPU-ядер и шейдеров без опоры исключительно на проприетарный дизассемблер набора инструментов CUDA.
