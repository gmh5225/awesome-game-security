이 프로젝트는 IDA Pro Teams에서 사용하는 Hexvault와 Lumina 서버를 Docker화하여 Docker Compose로 배포할 수 있도록 패키징합니다. Hexvault와 Lumina용 개별 컨테이너 이미지, Lumina용 MySQL 백엔드, TLS 인증서 생성, 라이선스 검증, 데이터베이스 스키마 초기화를 처리하는 셸 기반 진입 스크립트를 제공합니다. 빌드 시 Python 설정 스크립트는 라이선스 파일을 생성하며, 최종 이미지에 스크립트를 남기지 않습니다. Docker 볼륨은 vault 데이터, 데이터베이스 상태, TLS 자료를 영구 저장합니다. 주로 Docker, 셸, Python으로 작성되었으며, 공유 데이터베이스, 함수 시그니처, 팀 vault 저장소를 위한 자체 호스팅 협업 IDA Teams 환경이 필요한 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
