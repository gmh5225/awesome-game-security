Этот проект контейнеризует серверы Hexvault и Lumina, используемые IDA Pro Teams, и упаковывает их для развёртывания с помощью Docker Compose. Он предоставляет отдельные образы контейнеров для Hexvault и Lumina, бэкенд MySQL для Lumina, а также shell-скрипты запуска, которые обрабатывают генерацию TLS-сертификатов, проверку лицензий и инициализацию схемы базы данных. Python-скрипты настройки на этапе сборки создают файлы лицензий, не оставляя скрипты в финальных образах, а тома Docker сохраняют данные vault, состояние базы данных и TLS-материалы. Написанный в основном на Docker, shell и Python, он ориентирован на специалистов по реверс-инжинирингу и исследователей безопасности, которым нужна самостоятельно размещаемая совместная среда IDA Teams для общих баз данных, сигнатур функций и командного хранилища vault.
