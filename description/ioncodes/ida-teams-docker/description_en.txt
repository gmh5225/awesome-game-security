This project dockerizes the Hexvault and Lumina servers used by IDA Pro Teams, packaging them for deployment with Docker Compose. It provides separate container images for Hexvault and Lumina, a MySQL backend for Lumina, and shell-based entry scripts that handle TLS certificate generation, license validation, and database schema initialization. Build-time Python setup scripts create license files without leaving the scripts in the final images, while Docker volumes persist vault data, database state, and TLS material. Written primarily in Docker, shell, and Python, it targets reverse engineers and security researchers who need a self-hosted collaborative IDA Teams environment for shared databases, function signatures, and team vault storage.
