本專案將 IDA Pro Teams 使用的 Hexvault 與 Lumina 伺服器容器化，並打包為可透過 Docker Compose 部署的方案。它提供 Hexvault 與 Lumina 的獨立容器映像、供 Lumina 使用的 MySQL 後端，以及以 shell 為基礎的進入點腳本，用於處理 TLS 憑證產生、授權驗證與資料庫 schema 初始化。建置階段的 Python 設定腳本會建立授權檔案，且不會將腳本保留在最終映像中；Docker 磁碟區則持久化保存 vault 資料、資料庫狀態與 TLS 材料。專案主要使用 Docker、shell 與 Python 撰寫，面向需要自架協作式 IDA Teams 環境、以共享資料庫、函式簽章與團隊 vault 儲存的逆向工程師與安全研究人員。
