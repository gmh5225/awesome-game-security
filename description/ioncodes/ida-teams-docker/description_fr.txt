Ce projet dockerise les serveurs Hexvault et Lumina utilisés par IDA Pro Teams, en les empaquetant pour un déploiement avec Docker Compose. Il fournit des images de conteneurs distinctes pour Hexvault et Lumina, un backend MySQL pour Lumina, ainsi que des scripts d'entrée en shell qui gèrent la génération de certificats TLS, la validation des licences et l'initialisation du schéma de base de données. Des scripts Python de configuration au moment de la compilation créent les fichiers de licence sans conserver les scripts dans les images finales, tandis que les volumes Docker persistent les données du vault, l'état de la base de données et le matériel TLS. Principalement écrit en Docker, shell et Python, il s'adresse aux ingénieurs en rétro-ingénierie et aux chercheurs en sécurité qui ont besoin d'un environnement IDA Teams collaboratif auto-hébergé pour des bases de données partagées, des signatures de fonctions et le stockage vault d'équipe.
