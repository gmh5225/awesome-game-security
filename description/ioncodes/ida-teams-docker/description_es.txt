Este proyecto dockeriza los servidores Hexvault y Lumina utilizados por IDA Pro Teams, empaquetándolos para su despliegue con Docker Compose. Proporciona imágenes de contenedor separadas para Hexvault y Lumina, un backend MySQL para Lumina, y scripts de entrada basados en shell que gestionan la generación de certificados TLS, la validación de licencias y la inicialización del esquema de base de datos. Scripts de configuración en Python en tiempo de compilación crean archivos de licencia sin dejar los scripts en las imágenes finales, mientras que los volúmenes de Docker persisten los datos del vault, el estado de la base de datos y el material TLS. Escrito principalmente en Docker, shell y Python, está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad que necesitan un entorno colaborativo de IDA Teams autoalojado para bases de datos compartidas, firmas de funciones y almacenamiento vault de equipo.
