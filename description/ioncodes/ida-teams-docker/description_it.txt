Questo progetto dockerizza i server Hexvault e Lumina utilizzati da IDA Pro Teams, impacchettandoli per il deployment con Docker Compose. Fornisce immagini container separate per Hexvault e Lumina, un backend MySQL per Lumina e script di entrypoint basati su shell che gestiscono la generazione dei certificati TLS, la validazione delle licenze e l'inizializzazione dello schema del database. Script di setup Python in fase di build creano i file di licenza senza lasciare gli script nelle immagini finali, mentre i volumi Docker persistono i dati del vault, lo stato del database e il materiale TLS. Scritto principalmente in Docker, shell e Python, è rivolto a reverse engineer e ricercatori di sicurezza che necessitano di un ambiente IDA Teams collaborativo self-hosted per database condivisi, firme di funzioni e archivio vault di team.
