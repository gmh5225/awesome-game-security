本项目将 IDA Pro Teams 使用的 Hexvault 与 Lumina 服务器容器化，并打包为可通过 Docker Compose 部署的方案。它提供 Hexvault 与 Lumina 的独立容器镜像、供 Lumina 使用的 MySQL 后端，以及基于 shell 的入口脚本，用于处理 TLS 证书生成、许可证校验和数据库 schema 初始化。构建阶段的 Python 设置脚本会生成许可证文件，且不会将脚本保留在最终镜像中；Docker 卷则持久化保存 vault 数据、数据库状态与 TLS 材料。项目主要使用 Docker、shell 与 Python 编写，面向需要自托管协作式 IDA Teams 环境、以共享数据库、函数签名与团队 vault 存储的逆向工程师与安全研究人员。
