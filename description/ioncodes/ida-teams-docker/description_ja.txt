本プロジェクトは、IDA Pro Teams で使用される Hexvault と Lumina サーバーを Docker 化し、Docker Compose によるデプロイ向けにパッケージ化します。Hexvault と Lumina 用の個別コンテナイメージ、Lumina 向け MySQL バックエンド、TLS 証明書の生成、ライセンス検証、データベーススキーマの初期化を担うシェルベースのエントリスクリプトを提供します。ビルド時の Python セットアップスクリプトはライセンスファイルを作成し、最終イメージにスクリプトを残しません。Docker ボリュームにより、vault データ、データベース状態、TLS 関連の素材が永続化されます。主に Docker、シェル、Python で書かれており、共有データベース、関数シグネチャ、チーム vault ストレージを備えた自ホスト型の協調 IDA Teams 環境を必要とするリバースエンジニアやセキュリティ研究者を対象としています。
