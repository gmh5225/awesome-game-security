AntiCheatAI는 Paper 1.21+용 Minecraft 서버 플러그인으로, 실시간 안티치트 탐지와 학습·모니터링을 위한 선택적 게임플레이 원격 측정 기록을 결합합니다. Java 21, Maven, Paper API로 구현되며, 규칙 기반 검사(에임 스냅, 공격 속도, 리치)와 z-score 비교로 각 플레이어의 이동·시야 기준선을 학습하는 적응형 로컬 이상 모델 모두로 의심도를 점수화합니다. 원격 LLM이나 외부 API는 사용하지 않습니다. 의심스러운 플레이어는 관리자 알림과 지연 킥을 유발할 수 있으며, 플러그인은 시청자별로 시각 마스킹을 적용해 레이 트레이싱상 보이면 안 되는 다른 플레이어를 숨겨 ESP류 치트를 겨냥합니다. 운영자는 게임 내 명령으로 학습 세션, 플레이어 감시, 상태 확인, 플러그인 데이터 폴더에 CSV 원격 측정 내보내기, YAML 구성으로 동작 조정이 가능합니다. Minecraft 서버 관리자와 Paper에서 서버 측 게임 보안 및 실용적 안티치트 설계를 연구하는 이들을 대상으로 합니다.
