AntiCheatAI is a Paper 1.21+ Minecraft server plugin that combines live anti-cheat detection with optional gameplay telemetry recording for training and monitoring. It is implemented in Java 21 with Maven and the Paper API, and scores suspicion using both rule-based checks (aim snap, attack rate, reach) and an adaptive local anomaly model that learns each player’s movement and rotation baseline via z-score comparison—not a remote LLM or external API. Suspicious players can trigger admin alerts and delayed kicks, and the plugin can apply per-viewer visual masking that hides other players when ray tracing shows they should not be visible, which targets ESP-style cheating. Operators use in-game commands to train sessions, watch players, inspect status, export CSV telemetry under the plugin data folder, and tune behavior through YAML configuration. It is aimed at Minecraft server administrators and anyone studying server-side game security and practical anti-cheat design on Paper.
