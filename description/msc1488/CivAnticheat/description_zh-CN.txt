AntiCheatAI 是一款面向 Paper 1.21+ 的 Minecraft 服务端插件，将实时反作弊检测与可选的游戏玩法遥测记录相结合，用于训练与监控。它使用 Java 21、Maven 与 Paper API 实现，通过基于规则的检查（瞄准瞬移、攻击频率、攻击距离）以及借助 z-score 比较、为每位玩家学习移动与视角基线的自适应本地异常模型来评估可疑程度，而非依赖远程 LLM 或外部 API。可疑玩家可触发管理员告警与延迟踢出；插件还可按观看者为其他玩家施加视觉遮蔽——当射线追踪表明其不应可见时将其隐藏，以针对 ESP 类作弊。管理员可通过游戏内命令进行训练会话、监视玩家、查看状态、在插件数据目录下导出 CSV 遥测，并通过 YAML 配置调整行为。适用于 Minecraft 服务端管理员，以及研究服务端游戏安全与在 Paper 上实现实用反作弊设计的人员。
