AntiCheatAI 是一款適用於 Paper 1.21+ 的 Minecraft 伺服器外掛，將即時反作弊偵測與可選的遊戲玩法遙測錄製結合，用於訓練與監控。它以 Java 21、Maven 與 Paper API 實作，透過規則式檢查（瞄準瞬移、攻擊頻率、攻擊距離）以及藉由 z-score 比較、為每位玩家學習移動與視角基線的自適應本機異常模型來評估可疑程度，而非依賴遠端 LLM 或外部 API。可疑玩家可觸發管理員警示與延遲踢出；外掛還能依觀看者對其他玩家施加視覺遮蔽——當射線追蹤顯示其不應可見時將其隱藏，以針對 ESP 類作弊。管理員可透過遊戲內指令進行訓練工作階段、監看玩家、檢視狀態、在插件資料目錄下匯出 CSV 遙測，並透過 YAML 設定調整行為。適合 Minecraft 伺服器管理員，以及研究伺服器端遊戲安全與在 Paper 上實作實用反作弊設計的人員。
