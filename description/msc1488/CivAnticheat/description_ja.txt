AntiCheatAI は Paper 1.21+ 向けの Minecraft サーバープラグインで、ライブなアンチチート検知と、学習・監視用の任意のゲームプレイテレメトリ記録を組み合わせます。Java 21、Maven、Paper API で実装され、ルールベースのチェック（エイムスナップ、攻撃レート、リーチ）と、z-score 比較により各プレイヤーの移動・視点のベースラインを学習する適応型ローカル異常モデルの両方で疑わしさをスコア化します。リモート LLM や外部 API は使いません。疑わしいプレイヤーは管理者アラートと遅延キックを引き起こせ、プラグインは視聴者ごとにビジュアルマスキングを適用し、レイトレースで見えるべきでない他プレイヤーを非表示にして ESP 系チートを対象にできます。運営者はゲーム内コマンドで学習セッション、プレイヤー監視、状態確認、プラグインデータフォルダへの CSV テレメトリ出力、YAML による挙動調整ができます。Minecraft サーバー管理者や、Paper 上のサーバーサイドゲームセキュリティと実用的アンチチート設計を学ぶ人向けです。
