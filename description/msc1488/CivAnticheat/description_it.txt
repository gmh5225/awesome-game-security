AntiCheatAI è un plugin server Minecraft per Paper 1.21+ che combina il rilevamento anti-cheat in tempo reale con la registrazione opzionale di telemetria di gioco per addestramento e monitoraggio. È implementato in Java 21 con Maven e l’API Paper, e valuta il sospetto con controlli basati su regole (snap della mira, frequenza d’attacco, reach) e un modello locale adattivo di anomalie che apprende la baseline di movimento e rotazione di ogni giocatore tramite confronto z-score, senza LLM remoto o API esterna. I giocatori sospetti possono generare avvisi admin e kick ritardati; il plugin può applicare mascheramento visivo per spettatore che nasconde altri giocatori quando il ray tracing indica che non dovrebbero essere visibili, mirando ai cheat in stile ESP. Gli operatori usano comandi in-game per sessioni di training, osservazione, stato, export CSV di telemetria nella cartella dati del plugin e regolazione tramite configurazione YAML. È rivolto agli amministratori di server Minecraft e a chi studia la sicurezza di gioco lato server e il design anti-cheat pratico su Paper.
