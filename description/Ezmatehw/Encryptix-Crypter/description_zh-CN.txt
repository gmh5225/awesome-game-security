Encryptix Crypter 是一款 Windows GUI 加壳/打包工具，可加密 PE 载荷并通过可配置的 stub 模板将其重建为独立可执行文件。项目使用 C# 编写，基于 .NET Framework 4.8，采用 WinForms 与 Guna UI，支持 AES 与 XOR 加密，并通过 RegAsm、RegSvcs、MSBuild 等 LOLBin 在运行时进行进程注入，还可选启用持久化、反虚拟机检测、睡眠延迟与程序集元数据克隆。项目包含基于 dnlib 的混淆器（含随机化与 booster 模块）、KeyAuth 许可证验证，以及可在构建时嵌入加密资源并编译 stub 的 builder。面向游戏安全研究人员、逆向工程师与反作弊分析师，用于研究加壳器构造、载荷打包与规避技术。
