Encryptix Crypter 是一款 Windows GUI 加殼/打包工具，可加密 PE 載荷並透過可設定的 stub 範本將其重建為獨立可執行檔。專案以 C# 撰寫，基於 .NET Framework 4.8，採用 WinForms 與 Guna UI，支援 AES 與 XOR 加密，並透過 RegAsm、RegSvcs、MSBuild 等 LOLBin 在執行階段進行程序注入，亦可選用持久化、反虛擬機檢查、睡眠延遲與組件中繼資料複製。專案包含基於 dnlib 的混淆器（含隨機化與 booster 模組）、KeyAuth 授權驗證，以及可在建置時嵌入加密資源並編譯 stub 的 builder。面向遊戲安全研究人員、逆向工程師與反作弊分析師，用於研究加殼器建構、載荷打包與規避技術。
