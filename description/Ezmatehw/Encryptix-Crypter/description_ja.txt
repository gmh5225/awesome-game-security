Encryptix Crypter は、PE ペイロードを暗号化し、設定可能な stub テンプレートを用いてスタンドアロン実行ファイルとして再構築する Windows GUI 向け crypter および packer です。C# で .NET Framework 4.8 向けに WinForms と Guna UI を用いて実装され、AES および XOR 暗号化、RegAsm・RegSvcs・MSBuild などの LOLBin による実行時プロセスインジェクション、さらに任意の永続化、反 VM チェック、スリープ遅延、アセンブリメタデータのクローンに対応します。dnlib ベースの難読化（ランダム化および booster モジュール付き）、KeyAuth によるライセンス認証、暗号化リソースの埋め込みとビルド時の stub コンパイルを行う builder を含みます。ゲームセキュリティ研究者、リバースエンジニア、反チート分析者が crypter 構築、ペイロードパッキング、回避手法を研究する目的向けです。
