bevy_input_driver ist ein Rust-Bevy-Plugin, mit dem automatisierte Tests ein laufendes Bevy-0.20-Spiel steuern können, indem sie Tastatur-, Maus-, Scroll-, Touch- und Gesteneingaben injizieren und Screenshots erfassen. Befehle kommen über das Bevy Remote Protocol als HTTP JSON-RPC auf localhost oder beim Start aus einem JSON-Lines-Skript, dazu ein kleines Python-Hilfswerkzeug zum Senden von Batches und Warten auf Abschluss. Injizierte Ereignisse spiegeln echte winit-artige WindowEvent- und bevy_input-Nachrichtenpaare, sodass Picking und UI normal funktionieren, während der OS-Cursor standardmäßig stillsteht. Es ergänzt deterministische Seeds, virtuelle Zeitsteuerung, Frame-Schritte, Save-/Load-Hooks und Statusmeldungen für wiederholbare End-to-End-Spieltests. Es eignet sich für Spieleentwickler und Sicherheitsforscher, die eine getreue In-Process-Eingabeinjektion brauchen, um Gameplay, UI-Abläufe und Eingabeverarbeitung ohne externe Automatisierung auf OS-Ebene zu prüfen.
