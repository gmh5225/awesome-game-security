bevy_input_driver は Rust の Bevy プラグインで、自動テストが稼働中の Bevy 0.20 ゲームにキーボード・マウス・スクロール・タッチ・ジェスチャ入力を注入しスクリーンショットを取得できるようにします。コマンドは Bevy Remote Protocol 経由で localhost 上の HTTP JSON-RPC、または起動時の JSON Lines スクリプトから届き、バッチ送信と完了待ち用の小さな Python ヘルパーも付属します。注入イベントは実際の winit 風 WindowEvent と bevy_input のメッセージペアを再現するため、ピッキングと UI は通常どおり動き、既定では OS カーソルは動きません。決定論的シード、仮想時間制御、フレームステップ、セーブ／ロードフック、ステータス報告により、再現可能なエンドツーエンドゲームテストを支援します。ゲームプレイ、UI フロー、入力処理を OS レベルの外部自動化なしで検証するための、忠実なプロセス内入力注入が必要なゲーム開発者やセキュリティ研究者向けです。
