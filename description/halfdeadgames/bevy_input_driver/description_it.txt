bevy_input_driver è un plugin Rust per Bevy che consente ai tester automatizzati di guidare un gioco Bevy 0.20 in esecuzione iniettando input da tastiera, mouse, scorrimento, tocco e gesti e catturando screenshot. I comandi arrivano tramite Bevy Remote Protocol come HTTP JSON-RPC su localhost o da uno script JSON Lines all’avvio, con un piccolo helper Python per inviare batch e attendere il completamento. Gli eventi iniettati rispecchiano coppie reali di WindowEvent in stile winit e messaggi bevy_input, così picking e UI si comportano normalmente mentre il cursore del SO resta fermo per impostazione predefinita. Aggiunge seed deterministici, controllo del tempo virtuale, avanzamento frame per frame, hook di salvataggio o caricamento e segnalazione di stato per test di gioco end-to-end ripetibili. È adatto a sviluppatori di giochi e ricercatori di sicurezza che necessitano di un’iniezione di input fedele in-processo per esercitare gameplay, flussi UI e gestione dell’input senza automazione esterna a livello di sistema operativo.
