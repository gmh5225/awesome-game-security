bevy_input_driver is a Rust Bevy plugin that lets automated testers drive a live Bevy 0.20 game by injecting keyboard, mouse, scroll, touch, and gesture input and capturing screenshots. Commands arrive over the Bevy Remote Protocol as HTTP JSON-RPC on localhost or from a JSON Lines script at launch, with a small Python helper for sending batches and waiting on completion. Injected events mirror real winit-style WindowEvent and bevy_input message pairs so picking and UI behave normally while the OS cursor stays put by default. It adds deterministic seeds, virtual time control, frame stepping, save or load hooks, and status reporting for repeatable end-to-end game tests. It suits game developers and security researchers who need faithful in-process input injection to exercise gameplay, UI flows, and input-handling behavior without external OS-level automation.
