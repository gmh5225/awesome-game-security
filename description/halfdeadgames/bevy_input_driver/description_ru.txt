bevy_input_driver — плагин Rust для Bevy, позволяющий автоматизированным тестам управлять запущенной игрой Bevy 0.20, внедряя ввод с клавиатуры, мыши, прокрутки, касаний и жестов и делая снимки экрана. Команды поступают по Bevy Remote Protocol как HTTP JSON-RPC на localhost или из скрипта JSON Lines при запуске, с небольшим вспомогательным модулем на Python для пакетной отправки и ожидания завершения. Внедрённые события повторяют реальные пары WindowEvent в стиле winit и сообщений bevy_input, поэтому пикинг и UI ведут себя нормально, а курсор ОС по умолчанию остаётся на месте. Добавлены детерминированные сиды, управление виртуальным временем, пошаговая прокрутка кадров, хуки сохранения и загрузки и отчёты о статусе для воспроизводимых сквозных игровых тестов. Подходит разработчикам игр и исследователям безопасности, которым нужна достоверная внутрипроцессная инъекция ввода для проверки геймплея, UI-потоков и обработки ввода без внешней автоматизации на уровне ОС.
