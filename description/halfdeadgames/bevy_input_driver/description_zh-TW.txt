bevy_input_driver 是一款 Rust Bevy 外掛，讓自動化測試能在執行中的 Bevy 0.20 遊戲裡注入鍵盤、滑鼠、捲動、觸控與手勢輸入並擷取螢幕畫面。指令透過 Bevy Remote Protocol，以 localhost 上的 HTTP JSON-RPC 送達，或在啟動時由 JSON Lines 腳本提供，並附帶小型 Python 輔助工具以批次傳送並等待完成。注入事件與真實的 winit 風格 WindowEvent 及 bevy_input 訊息對相符，點選與 UI 行為正常，且預設不移動作業系統游標。它提供確定性種子、虛擬時間控制、逐幀步進、存讀檔掛鉤與狀態回報，便於可重複的端到端遊戲測試。適合需要忠實的行程內輸入注入以演練玩法、UI 流程與輸入處理行為、且無需作業系統層級外部自動化的遊戲開發者與安全研究人員。
