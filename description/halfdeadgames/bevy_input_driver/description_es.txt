bevy_input_driver es un complemento de Bevy en Rust que permite a los probadores automatizados controlar un juego Bevy 0.20 en ejecución inyectando entrada de teclado, ratón, desplazamiento, tacto y gestos, y capturando capturas de pantalla. Los comandos llegan mediante el Bevy Remote Protocol como HTTP JSON-RPC en localhost o desde un script JSON Lines al iniciar, con un pequeño auxiliar en Python para enviar lotes y esperar la finalización. Los eventos inyectados reflejan pares reales de WindowEvent al estilo winit y mensajes de bevy_input, de modo que la selección y la UI se comportan con normalidad mientras el cursor del SO permanece quieto por defecto. Añade semillas deterministas, control de tiempo virtual, avance cuadro a cuadro, hooks de guardado o carga e informes de estado para pruebas de juego de extremo a extremo repetibles. Es adecuado para desarrolladores de juegos e investigadores de seguridad que necesitan inyección de entrada fiel en proceso para ejercitar jugabilidad, flujos de UI y manejo de entrada sin automatización externa a nivel del sistema operativo.
