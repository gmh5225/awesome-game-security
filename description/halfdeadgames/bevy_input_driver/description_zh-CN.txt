bevy_input_driver 是一个 Rust Bevy 插件，供自动化测试在运行中的 Bevy 0.20 游戏里注入键盘、鼠标、滚轮、触摸与手势输入并截取画面。命令经 Bevy Remote Protocol 以 localhost 上的 HTTP JSON-RPC 传入，或在启动时由 JSON Lines 脚本提供，并附带小型 Python 辅助工具用于批量发送与等待完成。注入事件与真实的 winit 风格 WindowEvent 及 bevy_input 消息对一致，拾取与 UI 表现正常，且默认不移动操作系统光标。它提供确定性种子、虚拟时间控制、逐帧步进、存读档钩子与状态上报，便于可重复的端到端游戏测试。适合需要忠实进程内输入注入以演练玩法、UI 流程与输入处理逻辑、且无需操作系统级外部自动化的游戏开发者与安全研究人员。
