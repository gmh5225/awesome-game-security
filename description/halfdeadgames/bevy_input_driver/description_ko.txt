bevy_input_driver는 Rust Bevy 플러그인으로, 자동화 테스터가 실행 중인 Bevy 0.20 게임에 키보드·마우스·스크롤·터치·제스처 입력을 주입하고 스크린샷을 캡처할 수 있게 합니다. 명령은 Bevy Remote Protocol을 통해 localhost의 HTTP JSON-RPC로 전달되거나 시작 시 JSON Lines 스크립트에서 오며, 배치 전송과 완료 대기를 위한 소형 Python 헬퍼가 포함됩니다. 주입된 이벤트는 실제 winit 스타일 WindowEvent와 bevy_input 메시지 쌍을 반영해 피킹과 UI가 정상 동작하고, 기본적으로 OS 커서는 움직이지 않습니다. 결정적 시드, 가상 시간 제어, 프레임 스텝, 저장·로드 훅, 상태 보고로 반복 가능한 엔드투엔드 게임 테스트를 지원합니다. OS 수준 외부 자동화 없이 게임플레이, UI 흐름, 입력 처리를 검증하려는 충실한 인프로세스 입력 주입이 필요한 게임 개발자와 보안 연구자에게 적합합니다.
