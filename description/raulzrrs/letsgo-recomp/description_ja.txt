Let's Go Recomp は、ポケットモンスター Let's Go! ピカチュウ・イーブイの Switch 版を、従来のエミュレーションではなく静的再コンパイルで構築したネイティブ Windows 向けポートです。Switch の ARM64 実行モジュールを C に翻訳して x86-64 向けにコンパイルし、カスタムランタイムが Horizon システムサービスを HLE し、NVN グラフィックスを Vulkan にマッピングし、オーディオ・ファイルシステム・コントローラ入力を扱います。コードベースは主に C と C++ で、Vulkan とアップスケーリング経路は C++、ランチャー UI は Objective-C++、リフティング・逆アセンブル・パッチ・ユーザー提供ダンプからのマシンごとの一度限りのコード生成には Python と Zig をツールチェーンで用います。解像度とフレームレートの選択、AMD FSR によるアップスケーリングとフレーム生成、Mod 対応、メモリウォッチ・プロファイリング・RenderDoc 連携など開発者向けフックも備えます。Switch バイナリ翻訳とランタイム置換を研究するリバースエンジニアやゲームセキュリティ研究者、および正規にゲームを所有し自前の exefs と romfs データを提供するプレイヤーを対象としています。
