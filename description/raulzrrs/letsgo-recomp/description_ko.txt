Let's Go Recomp는 포켓몬스터 Let's Go! 피카츄·이브이 Switch 타이틀의 네이티브 Windows 포트로, 일반 에뮬레이션 대신 정적 재컴파일로 만들어졌습니다. Switch ARM64 실행 모듈을 C로 번역해 x86-64용으로 컴파일하고, 맞춤 런타임이 Horizon 시스템 서비스를 HLE하며 NVN 그래픽을 Vulkan에 매핑하고 오디오·파일시스템·컨트롤러 입력을 처리합니다. 코드베이스는 주로 C와 C++이며, Vulkan 및 업스케일링 경로는 C++, 런처 UI는 Objective-C++, 리프팅·디스어셈블리·패치·사용자가 제공한 덤프 기반 일회성 기기별 코드 생성에는 Python과 Zig가 툴체인에 쓰입니다. 해상도·프레임레이트 옵션, AMD FSR 업스케일링 및 프레임 생성, 모드 지원, 메모리 워치·프로파일링·RenderDoc 연동 같은 개발자용 훅을 제공합니다. Switch 바이너리 번역과 런타임 대체를 연구하는 리버스 엔지니어·게임 보안 연구자와, 게임을 합법적으로 소유하고 자체 추출 exefs·romfs 데이터를 제공하는 플레이어를 대상으로 합니다.
