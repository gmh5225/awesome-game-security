Let's Go Recomp — нативный порт для Windows игр Pokémon Let's Go, Eevee! и Pikachu! для Switch, построенный на статической перекомпиляции, а не на обычной эмуляции. Исполняемые модули ARM64 Switch переводятся в C и компилируются под x86-64, а пользовательская среда выполнения эмулирует на высоком уровне системные сервисы Horizon, отображает графику NVN на Vulkan и обрабатывает аудио, файловую систему и ввод с контроллера. Кодовая база в основном на C и C++, C++ используется для Vulkan и путей апскейлинга, Objective-C++ — для UI лаунчера, Python и Zig — в toolchain для lifting, дизасемблирования, патчей и одноразовой генерации кода под конкретную машину из предоставленных пользователем дампов. Среди возможностей — настройки разрешения и частоты кадров, апскейлинг и генерация кадров AMD FSR, поддержка модов и отладочные хуки вроде memory watch, профилирования и интеграции с RenderDoc. Проект ориентирован на reverse engineers и исследователей игровой безопасности, изучающих бинарный перевод Switch и замену runtime, а также на игроков, легально владеющих игрой и предоставляющих собственные извлечённые данные exefs и romfs.
