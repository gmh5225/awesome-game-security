Let's Go Recomp is a native Windows port of the Pokémon Let's Go, Eevee! and Pikachu! Switch titles built with static recompilation instead of conventional emulation. Switch ARM64 executable modules are translated into C and compiled for x86-64, while a custom runtime high-level-emulates Horizon system services, maps NVN graphics to Vulkan, and handles audio, filesystem, and controller input. The codebase is primarily C and C++, with C++ used for Vulkan and upscaling paths, Objective-C++ for the launcher UI, and Python plus Zig in the toolchain for lifting, disassembly, patching, and one-time per-machine code generation from user-supplied dumps. Notable capabilities include resolution and frame-rate options, AMD FSR upscaling and frame generation, mod support, and developer-oriented hooks such as memory watch, profiling, and RenderDoc integration. It is aimed at reverse engineers and game-security researchers studying Switch binary translation and runtime replacement, and at players who legally own the game and provide their own extracted exefs and romfs data.
