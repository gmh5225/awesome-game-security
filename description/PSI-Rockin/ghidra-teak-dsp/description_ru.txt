Это расширение Ghidra в стадии разработки, добавляющее поддержку DSP CEVA XpertTeak, используемого в системах Nintendo 3DS и DSi. Оно описывает архитектуру Teak через языковые модули SLEIGH и Java-код загрузчика, чтобы Ghidra могла дизассемблировать, анализировать и декомпилировать прошивку Teak. Охват достаточен для полного дизассемблирования прошивок вроде домашнего меню 3DS и Sound App; включён бинарный загрузчик CDC/DSP1 для импорта таких образов. Нереализованные контекстные регистры по возможности отображаются операциями pcode. Предназначено для специалистов по обратной разработке, изучающих прошивку аудио-DSP портативных консолей и связанный встроенный код.
