Nintendo 3DS および DSi で使われる CEVA XpertTeak DSP をサポートする、開発中の Ghidra 拡張機能です。SLEIGH 言語モジュールと Java ローダーコードで Teak アーキテクチャを定義し、Ghidra が Teak ファームウェアの逆アセンブル、解析、デコンパイルを行えるようにします。3DS ホームメニューや Sound App などのファームウェアを完全に逆アセンブルできる程度のカバレッジがあり、それらのイメージを取り込む CDC/DSP1 バイナリローダーも含まれます。未実装のコンテキストレジスタは可能な限り pcode 操作で表現されます。携帯ゲーム機のオーディオ DSP ファームウェアや関連する組み込みコードを調査するリバースエンジニア向けです。
