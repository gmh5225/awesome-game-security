This is a work-in-progress Ghidra extension that adds support for the CEVA XpertTeak DSP used in Nintendo 3DS and DSi systems. It defines the Teak architecture through SLEIGH language modules and Java loader code so Ghidra can disassemble, analyze, and decompile Teak firmware. Coverage is broad enough to fully disassemble firmware such as the 3DS Home Menu and Sound App, and it includes a CDC/DSP1 binary loader for importing those images. Unimplemented context registers are surfaced with pcode operations where possible. It is aimed at reverse engineers studying handheld console audio DSP firmware and related embedded code.
