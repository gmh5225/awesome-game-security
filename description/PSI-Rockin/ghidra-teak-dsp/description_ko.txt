Nintendo 3DS 및 DSi 시스템에 사용되는 CEVA XpertTeak DSP를 지원하는 개발 중인 Ghidra 확장입니다. SLEIGH 언어 모듈과 Java 로더 코드로 Teak 아키텍처를 정의하여 Ghidra가 Teak 펌웨어를 디스어셈블, 분석, 디컴파일할 수 있게 합니다. 3DS 홈 메뉴 및 Sound App 같은 펌웨어를 완전히 디스어셈블할 수 있을 정도로 범위가 넓으며, 해당 이미지를 가져오는 CDC/DSP1 바이너리 로더도 포함합니다. 구현되지 않은 컨텍스트 레지스터는 가능한 경우 pcode 연산으로 표시됩니다. 휴대용 콘솔 오디오 DSP 펌웨어 및 관련 임베디드 코드를 연구하는 리버스 엔지니어를 대상으로 합니다.
