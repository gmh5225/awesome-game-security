Es una extensión de Ghidra en desarrollo que añade soporte para el DSP CEVA XpertTeak usado en los sistemas Nintendo 3DS y DSi. Define la arquitectura Teak mediante módulos de lenguaje SLEIGH y código cargador en Java para que Ghidra pueda desensamblar, analizar y descompilar firmware Teak. La cobertura es lo bastante amplia como para desensamblar por completo firmware como el menú de inicio del 3DS y Sound App, e incluye un cargador binario CDC/DSP1 para importar esas imágenes. Los registros de contexto no implementados se exponen con operaciones pcode cuando es posible. Está dirigida a ingenieros de ingeniería inversa que estudian firmware DSP de audio de consolas portátiles y código embebido relacionado.
