Chess-Cheater는 Windows 데스크톱 보조 도구로, 화면의 체스판을 감시하고 내부 대국 상태를 유지하며, 브라우저나 클라이언트 체스 게임에서 사람 상대에게 강한 수를 제안하거나 자동으로 둡니다. 화면 캡처와 OpenCV로 보드를 찾고 칸 하이라이트 색으로 수를 추론하며, python-chess 라이브러리로 국면을 유지하고 UCI로 Stockfish에 빠른 최선 수 분석을 요청합니다. 투명 Tkinter 오버레이가 추천 수를 표시하고, 선택 모드에서는 Win32 API로 합성 마우스 클릭을 보내 커서를 움직일 필요가 없습니다. CustomTkinter 제어판은 진영 선택, 수 기록, 전역 키보드 후크로 Ctrl 키로 자동 대국 일시 정지를 지원합니다. 이 프로젝트는 컴퓨터 비전, 외부 엔진 보조, 입력 주입 같은 클라이언트 측 치팅 패턴을 보여 주며, 게임 보안, 안티치트 설계, 비레이팅·캐주얼 온라인 대국의 위험 이해에 중요합니다.
