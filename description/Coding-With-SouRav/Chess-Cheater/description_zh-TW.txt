Chess-Cheater 是一款 Windows 桌面輔助工具，監看螢幕上的西洋棋棋盤、維護內部對局狀態，並在瀏覽器或客戶端棋類遊戲中對人類對手提出建議或自動走強著。它透過螢幕擷取與 OpenCV 定位棋盤，並依格子高亮顏色推斷著法，以 python-chess 函式庫維護局面，並經 UCI 向 Stockfish 查詢快速最佳著分析。透明 Tkinter 疊加層標示建議著法；可選模式經 Win32 API 送出合成滑鼠點擊，無需移動游標。CustomTkinter 控制面板支援選邊、著法記錄，以及透過全域鍵盤掛鉤以 Ctrl 鍵暫停自動對弈。該專案展示了用戶端作弊模式——電腦視覺、外部引擎輔助與輸入注入——對遊戲安全、反作弊設計以及理解非排位或休閒線上對局中的風險具有參考價值。
