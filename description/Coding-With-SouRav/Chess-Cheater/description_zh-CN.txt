Chess-Cheater 是一款 Windows 桌面辅助工具，监视屏幕上的国际象棋棋盘、维护内部对局状态，并在浏览器或客户端棋类游戏中对人类对手给出建议或自动走强着。它通过屏幕捕获与 OpenCV 定位棋盘，并根据格子高亮颜色推断着法，用 python-chess 库维护局面，并通过 UCI 向 Stockfish 查询快速最佳着分析。透明 Tkinter 叠加层标注推荐着法；可选模式经 Win32 API 发送合成鼠标点击，无需移动光标。CustomTkinter 控制面板支持选边、着法记录，以及通过全局键盘钩子用 Ctrl 键暂停自动对弈。该项目展示了客户端作弊模式——计算机视觉、外部引擎辅助与输入注入——对游戏安全、反作弊设计以及理解非排位或休闲在线对局中的风险具有参考价值。
