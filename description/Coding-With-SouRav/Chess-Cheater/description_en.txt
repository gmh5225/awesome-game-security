Chess-Cheater is a Windows desktop assistant that watches an on-screen chess board, keeps an internal game state, and suggests or plays strong moves against human opponents in browser or client chess games. It uses screen capture and OpenCV to find the board and infer moves from square highlight colors, maintains position with the python-chess library, and queries Stockfish over UCI for fast best-move analysis. A transparent Tkinter overlay marks the recommended move, while an optional mode sends synthetic mouse clicks through the Win32 API so the cursor does not need to move. The CustomTkinter control panel supports side selection, move logging, and pausing auto-play with the Ctrl key via global keyboard hooks. The project illustrates client-side cheating patterns—computer vision, external engine assistance, and input injection—that matter for game security, anti-cheat design, and understanding risks in unrated or casual online play.
