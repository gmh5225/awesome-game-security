BlackHex is a free-tier Android runtime application self-protection (RASP) library that runs on-device integrity checks and returns local signals and a pass-or-block verdict without sending data to vendor servers. It combines a Kotlin SDK with an arm64 native layer that detects app tampering and repackaging, runtime instrumentation and hooking, emulators, unhidden root and root-manager artifacts, and custom ROM or unlocked-bootloader indicators. Developers configure policy toggles to allow or block emulator, instrumentation, root, and bootloader groups while app-integrity enforcement stays always on, with each check reporting clean, detected, or inconclusive status. The project ships as a Gradle-built Android library module targeting API 26 and above, using CMake and the NDK for low-level scans such as memory maps, GOT/PLT, opcode patterns, and JNI bridges. It suits mobile game and app teams that need lightweight, client-side fraud and cheat resistance signals rather than server-only attestation or marketing-heavy commercial RASP products.
