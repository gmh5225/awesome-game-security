BlackHex 是一款免费档 Android 运行时应用自保护（RASP）库，在设备上执行完整性检查，返回本地信号与通过或拦截判定，不向厂商服务器发送数据。它将 Kotlin SDK 与 arm64 原生层结合，可检测应用篡改与重打包、运行时插桩与 Hook、模拟器、未隐藏的 root 与 root 管理工具痕迹，以及自定义 ROM 或已解锁引导加载程序等迹象。开发者可通过策略开关分别允许或拦截模拟器、插桩、root 与引导加载程序相关检测，应用完整性强制始终开启，每项检查报告为干净、已检出或无法判定。项目以 Gradle 构建的 Android 库模块形式发布，目标 API 26 及以上，通过 CMake 与 NDK 进行内存映射、GOT/PLT、操作码模式与 JNI 桥接等底层扫描。适合需要轻量、客户端侧欺诈与作弊对抗信号的移动游戏与应用团队，而非仅依赖服务端 attestation 或营销导向的商业 RASP 产品。
