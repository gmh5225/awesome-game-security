BlackHex 是一款免費方案 Android 執行階段應用程式自我保護（RASP）函式庫，在裝置上執行完整性檢查，回傳本地訊號與通過或封鎖判定，不向廠商伺服器傳送資料。它結合 Kotlin SDK 與 arm64 原生層，可偵測應用程式竄改與重打包、執行階段插樁與 Hook、模擬器、未隱藏的 root 與 root 管理工具痕跡，以及自訂 ROM 或已解鎖開機載入程式等指標。開發者可透過策略開關分別允許或封鎖模擬器、插樁、root 與開機載入程式相關群組，應用程式完整性強制始終開啟，每項檢查回報為乾淨、已偵測或無法判定。專案以 Gradle 建置的 Android 函式庫模組形式釋出，目標 API 26 以上，使用 CMake 與 NDK 進行記憶體對映、GOT/PLT、操作碼模式與 JNI 橋接等底層掃描。適合需要輕量、用戶端詐欺與作弊對抗訊號的行動遊戲與應用團隊，而非僅依賴伺服器端 attestation 或行銷導向的商業 RASP 產品。
