BlackHex는 무료 티어 Android 런타임 애플리케이션 자기 보호(RASP) 라이브러리로, 기기에서 무결성 검사를 실행하고 벤더 서버로 데이터를 보내지 않은 채 로컬 신호와 통과 또는 차단 판정을 반환합니다. Kotlin SDK와 arm64 네이티브 계층을 결합해 앱 변조 및 재패키징, 런타임 계측 및 후킹, 에뮬레이터, 숨기지 않은 root 및 root 관리 도구 흔적, 커스텀 ROM 또는 잠금 해제된 부트로더 지표를 감지합니다. 개발자는 정책 토글로 에뮬레이터, 계측, root, 부트로더 그룹을 허용하거나 차단할 수 있으며 앱 무결성 강제는 항상 켜져 있고 각 검사는 깨끗함, 감지됨, 또는 판정 불가 상태를 보고합니다. 프로젝트는 Gradle로 빌드하는 Android 라이브러리 모듈로 API 26 이상을 대상으로 하며, CMake와 NDK로 메모리 맵, GOT/PLT, opcode 패턴, JNI 브리지 같은 저수준 스캔을 수행합니다. 서버 전용 attestation이나 마케팅 중심 상용 RASP가 아니라 가벼운 클라이언트 측 사기 및 치트 대응 신호가 필요한 모바일 게임·앱 팀에 적합합니다.
