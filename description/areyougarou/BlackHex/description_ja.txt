BlackHex は無償ティアの Android ランタイムアプリケーション自己保護（RASP）ライブラリで、端末上で整合性チェックを実行し、ベンダーサーバーへデータを送らずにローカル信号と合格またはブロック判定を返します。Kotlin SDK と arm64 ネイティブ層を組み合わせ、アプリの改ざんや再パッケージ、ランタイム計装とフック、エミュレータ、隠されていない root や root 管理ツールの痕跡、カスタム ROM やアンロック済みブートローダーの指標を検出します。開発者はポリシートグルでエミュレータ、計装、root、ブートローダー各グループの許可またはブロックを設定でき、アプリ整合性の強制は常に有効で、各チェックはクリーン、検出、または判定不能を報告します。プロジェクトは Gradle でビルドする Android ライブラリモジュールとして API 26 以上を対象とし、CMake と NDK でメモリマップ、GOT/PLT、オペコードパターン、JNI ブリッジなどの低レベルスキャンを行います。サーバー attestation のみやマーケティング重視の商用 RASP ではなく、軽量なクライアント側の不正・チート対策信号が必要なモバイルゲーム・アプリチーム向けです。
