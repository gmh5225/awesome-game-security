CharlyEngine は、root 済み Android デバイス向けの、Cheat Engine スタイルのミニマルなメモリスキャナー兼メモリエディタです。Kotlin と Jetpack Compose の UI と、/proc 経由で他プロセスのメモリを読み書きするネイティブ C デーモンを組み合わせ、スキャン、再スキャン、インジェクト、フリーズといった定番ワークフローに対応します。実行中のゲームにアタッチするか、自動起動してフックでき、タイトルごとにスキャンセッションとフリーズ済みアドレスを永続化し、値のリアルタイム変化を統合ターミナルへストリーミングします。整数、浮動小数、long、word、byte などの値型をサポートし、root デーモンは Termux などのシェルからも操作できるテキストプロトコルを公開します。Android 上のメモリ改ざんを研究する mod 制作者、リバースエンジニア、ゲームセキュリティ研究者向けで、合法的なオフラインまたは個人利用のみを意図しています。
