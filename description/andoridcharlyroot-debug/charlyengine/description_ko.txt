CharlyEngine는 루트 권한이 있는 Android 기기를 위한 최소형 Cheat Engine 스타일 메모리 스캐너 및 수정기입니다. Kotlin과 Jetpack Compose UI와 /proc을 통해 다른 프로세스의 메모리를 읽고 쓰는 네이티브 C 데몬을 결합하여, 스캔, 재스캔, 주입, 동결 같은 전통적인 워크플로를 지원합니다. 실행 중인 게임에 연결하거나 자동으로 실행·후킹할 수 있으며, 타이틀별로 스캔 세션과 동결된 주소를 유지하고, 실시간 값 변경을 통합 터미널로 스트리밍합니다. 정수, 부동소수점, long, word, byte 등 값 유형을 지원하며, root 데몬은 Termux 등 다른 셸에서도 제어할 수 있는 텍스트 프로토콜을 제공합니다. Android 메모리 변조를 연구하는 모더, 리버스 엔지니어, 게임 보안 연구자를 대상으로 하며, 합법적인 오프라인 또는 개인적 용도만을 목적으로 한다고 명시합니다.
