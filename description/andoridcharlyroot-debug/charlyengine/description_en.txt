CharlyEngine is a minimal Cheat Engine-style memory scanner and modifier for rooted Android devices. It pairs a Kotlin and Jetpack Compose user interface with a native C daemon that reads and writes another process's memory via /proc, supporting classic scan, rescan, inject, and freeze workflows. The app can attach to running games or launch and hook them automatically, persist scan sessions and frozen addresses per title, and stream live value changes to an integrated terminal. Supported value types include integers, floats, longs, words, and bytes, and the root daemon exposes a text protocol that can also be driven from Termux or other shells. It is aimed at modders, reverse engineers, and game security researchers studying memory tampering on Android, with the stated intent of legitimate offline or personal use only.
