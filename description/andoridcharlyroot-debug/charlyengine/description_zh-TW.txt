CharlyEngine 是一款面向已 root Android 裝置的精簡版 Cheat Engine 風格記憶體掃描與修改工具。它將 Kotlin 與 Jetpack Compose 使用者介面同原生 C 守護程序結合，透過 /proc 讀寫其他程序的記憶體，支援經典的掃描、重新掃描、注入與凍結工作流程。應用程式可附加到執行中的遊戲，或自動啟動並掛鉤遊戲；可針對每個標題持久保存掃描工作階段與凍結位址，並將即時數值變化串流輸出到整合終端機。支援的數值類型包括整數、浮點數、長整型、字（word）與位元組；root 守護程序暴露文字協定，也可從 Termux 或其他 shell 驅動。它面向 mod 製作者、逆向工程師以及研究 Android 記憶體篡改的遊戲安全研究人員，並聲明僅用於合法的離線或個人用途。
