CharlyEngine 是一款面向已 root Android 设备的精简版 Cheat Engine 风格内存扫描与修改工具。它将 Kotlin 与 Jetpack Compose 用户界面同原生 C 守护进程相结合，通过 /proc 读写其他进程内存，支持经典的扫描、重新扫描、注入与冻结工作流。应用可附加到运行中的游戏，或自动启动并挂钩游戏；可针对每个标题持久保存扫描会话与冻结地址，并将实时数值变化流式输出到集成终端。支持的数值类型包括整数、浮点数、长整型、字（word）与字节；root 守护进程暴露文本协议，也可从 Termux 或其他 shell 驱动。它面向 mod 制作者、逆向工程师以及研究 Android 内存篡改的游戏安全研究人员，并声明仅用于合法的离线或个人用途。
