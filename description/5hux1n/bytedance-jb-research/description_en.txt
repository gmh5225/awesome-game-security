This repository documents reverse-engineering research into jailbreak, injection, and device-integrity detection used by several ByteDance iOS apps, including how checks are implemented and how results feed reporting and risk-control paths. The work combines static analysis with Python tooling built on Capstone, NumPy, and custom Mach-O and Objective-C metadata and cross-reference indexing, plus offline bulk decryption of encrypted string pools, alongside read-only dynamic observation using Frida hooks and independent validation with IDA Pro Hex-Rays decompilation. Published reports, artifacts, and reproducible scripts explain shared security components, rule-engine VMs, HMD telemetry linkage, and which probes actually run versus dead or environment-specific code. It is aimed at defensive mobile security researchers, reverse engineers, and teams studying iOS anti-tamper and device-trust mechanisms rather than shipping bypass tools or binaries.
