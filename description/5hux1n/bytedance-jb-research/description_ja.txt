本リポジトリは、複数の ByteDance iOS アプリで用いられる jailbreak、インジェクション、デバイス整合性検知に関するリバースエンジニアリング研究を記録しており、チェックの実装方法と結果がレポートおよびリスク管理経路にどう渡るかを扱う。静的解析に加え、Capstone と NumPy を基盤とし Mach-O および Objective-C のメタデータと相互参照の索引付けを行う Python ツール、暗号化文字列プールのオフライン一括復号、Frida フックによる読み取り専用の動的観測、IDA Pro Hex-Rays による逆コンパイルでの独立検証を組み合わせている。公開レポート、成果物、再現可能なスクリプトは、共通セキュリティコンポーネント、ルールエンジン VM、HMD テレメトリ連携、実際に動くプローブとデッドコードや環境依存コードの区別を説明する。バイパスツールやバイナリの配布ではなく、防御的モバイルセキュリティ研究者、リバースエンジニア、iOS の改ざん防止とデバイス信頼メカニズムを調べるチーム向けである。
