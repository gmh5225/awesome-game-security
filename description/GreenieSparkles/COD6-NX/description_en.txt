This project is an in-progress Nintendo Switch port of Call of Duty: Modern Warfare 2 that runs Xbox 360 game logic through static recompilation instead of wrapping a full emulator. The original default.xex is translated to ARM64 C++ with ReXGlue (a Xenia-derived recompiler), built via CMake with devkitA64 and libnx, and drives graphics through a custom native Vulkan renderer on NVK/Mesa rather than the slow generic SDK path. Implementation work centers on reading PM4 command streams, hooking render and skinning paths, managing textures and render targets with GLSL compute shaders, and extensive runtime diagnostics for reverse-engineering the legacy Xenos GPU pipeline. It is aimed at homebrew porters and researchers studying console binary recompilation and graphics bring-up; it remains a work in progress, ships no copyrighted game data, and expects users to supply assets from a legally owned copy.
