本项目是将《使命召唤：现代战争2》移植到 Nintendo Switch 的进行中工作，通过静态重编译运行 Xbox 360 游戏逻辑，而非封装完整模拟器。原始 default.xex 使用 ReXGlue（基于 Xenia 的重编译器）翻译为 ARM64 C++，通过 CMake 配合 devkitA64 与 libnx 构建，图形由基于 NVK/Mesa 的自定义原生 Vulkan 渲染器驱动，而非较慢的通用 SDK 路径。实现重点包括解析 PM4 命令流、挂钩渲染与蒙皮路径、用 GLSL 计算着色器管理纹理与渲染目标，以及大量运行时诊断以逆向旧版 Xenos GPU 管线。面向 homebrew 移植者与研究主机二进制重编译与图形 bring-up 的人员；仍为进行中项目，不包含受版权保护的游戏数据，需用户自行从合法拥有的拷贝提供资源。
