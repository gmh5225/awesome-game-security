本プロジェクトは、Call of Duty: Modern Warfare 2 の Nintendo Switch 向け移植（進行中）で、フルエミュレータを包むのではなく静的再コンパイルにより Xbox 360 のゲームロジックを実行します。元の default.xex は ReXGlue（Xenia 系の再コンパイラ）で ARM64 C++ に変換し、CMake と devkitA64・libnx でビルドし、汎用 SDK 経路より遅い方式ではなく NVK/Mesa 上のカスタムネイティブ Vulkan レンダラで描画します。実装は PM4 コマンドストリームの解析、レンダーとスキニング経路のフック、GLSL compute シェーダによるテクスチャとレンダーターゲット管理、レガシー Xenos GPU パイプラインのリバースエンジニアリング向けの広範なランタイム診断が中心です。homebrew 移植者やコンソールバイナリ再コンパイルとグラフィックス立ち上げを研究する人向けで、作業中のプロジェクトであり、著作権で保護されたゲームデータは同梱せず、ユーザーが合法に所有するコピーからアセットを用意する必要があります。
