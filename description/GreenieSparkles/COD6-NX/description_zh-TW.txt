本專案是將《決勝時刻：現代戰爭2》移植至 Nintendo Switch 的進行中工作，透過靜態重編譯執行 Xbox 360 遊戲邏輯，而非封裝完整模擬器。原始 default.xex 使用 ReXGlue（衍生自 Xenia 的重編譯器）轉譯為 ARM64 C++，以 CMake 搭配 devkitA64 與 libnx 建置，圖形由基於 NVK/Mesa 的自訂原生 Vulkan 渲染器驅動，而非較慢的通用 SDK 路徑。實作重心在讀取 PM4 命令串流、掛鉤渲染與蒙皮路徑、以 GLSL 計算著色器管理紋理與渲染目標，以及大量執行期診斷以逆向舊版 Xenos GPU 管線。面向 homebrew 移植者與研究主機二進位重編譯與圖形 bring-up 的研究者；仍為進行中專案，不包含受版權保護的遊戲資料，需使用者自行從合法擁有的拷貝提供資源。
