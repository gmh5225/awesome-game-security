MewTools is a free Windows desktop application for setting up, diagnosing, and maintaining DMA FPGA cards on a dedicated second PC. It detects 35T, 75T, and 100T cards, reads DNA IDs, runs cable and throughput speed tests, and validates and flashes .bin or .bit firmware through tools such as openFPGALoader. The app installs signature-checked FTDI, WCH, and Silicon Labs drivers, supports MAKCU and FERRUM device testing and firmware flashing, and bundles second-PC setup packs, reversible Windows optimization tweaks, and guided troubleshooting with coded error reports. Built with Tauri using a Rust backend and web-based UI, it targets users who need a consolidated, security-conscious workflow for DMA hardware setup rather than manual driver and flasher management.
