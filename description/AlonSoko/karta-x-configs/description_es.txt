Este repositorio distribuye paquetes de configuración compatibles para Karta-x, un complemento de IDA Pro que detecta bibliotecas de código abierto dentro de un binario y etiqueta sus funciones. Cada configuración captura cómo se compiló una versión concreta de una biblioteca con un compilador y un nivel de optimización dados, incluyendo cadenas, constantes, patrones de llamada, tamaños, marcos de pila, forma de instrucciones y flujo de control, orden de archivos fuente y tablas de punteros a funciones por función. Los archivos de release cubren Linux (GCC y clang en x86 y ARM64), macOS (Apple clang) y Windows (MSVC desde Visual Studio 2026 hasta Visual C++ 6.0), con huellas para bibliotecas como Lua, SQLite, zlib, mbedTLS, MinHook y LZ4. El repo guarda un manifiesto con checksums de paquetes y metadatos de bibliotecas, mientras que comandos de obtención basados en Python en Karta-x descargan y verifican los paquetes en un directorio config local. Está dirigido a ingenieros inversos y analistas de binarios que necesitan identificación fiable de bibliotecas y nomenclatura de funciones en ejecutables sin símbolos u ofuscados, incluidos clientes de juegos que enlazan estáticamente código de terceros habitual.
