Этот репозиторий распространяет подходящие пакеты конфигурации для Karta-x — плагина IDA Pro, который обнаруживает библиотеки с открытым исходным кодом в бинарном файле и помечает их функции. Каждая конфигурация фиксирует, как конкретный релиз библиотеки был собран заданным компилятором и уровнем оптимизации, включая строки, константы, шаблоны вызовов, размеры, stack frame, форму инструкций и потока управления, порядок исходных файлов и таблицы указателей на функции для каждой функции. Архивы релизов охватывают Linux (GCC и clang на x86 и ARM64), macOS (Apple clang) и Windows (MSVC от Visual Studio 2026 до Visual C++ 6.0), с отпечатками для библиотек вроде Lua, SQLite, zlib, mbedTLS, MinHook и LZ4. В репозитории хранится манифест с контрольными суммами пакетов и метаданными библиотек; команды загрузки на Python в Karta-x скачивают и проверяют пакеты в локальный каталог config. Ориентирован на специалистов по реверс-инжинирингу и бинарному анализу, которым нужна надёжная идентификация библиотек и именование функций в stripped или обфусцированных исполняемых файлах, включая игровые клиенты со статической линковкой распространённого стороннего кода.
