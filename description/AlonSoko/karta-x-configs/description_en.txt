This repository distributes matching configuration packs for Karta-x, an IDA Pro plugin that detects open-source libraries inside a binary and labels their functions. Each configuration captures how a specific library release was built with a given compiler and optimization level, including per-function strings, constants, call patterns, sizes, stack frames, instruction and control-flow shape, source-file ordering, and function-pointer tables. Release archives cover Linux (GCC and clang on x86 and ARM64), macOS (Apple clang), and Windows (MSVC from Visual Studio 2026 back to Visual C++ 6.0), with fingerprints for libraries such as Lua, SQLite, zlib, mbedTLS, MinHook, and LZ4. The repo holds a manifest with pack checksums and library metadata, while Python-based fetch commands in Karta-x download and verify the packs into a local config directory. It is aimed at reverse engineers and binary analysts who need reliable library identification and function naming in stripped or obfuscated executables, including game clients that statically link common third-party code.
