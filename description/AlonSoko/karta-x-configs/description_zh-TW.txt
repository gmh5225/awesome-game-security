本儲存庫分發與 Karta-x 配套的配置包；Karta-x 是 IDA Pro 外掛，可在二進位檔中偵測開源函式庫並標註其函式。每份配置記錄特定函式庫版本在指定編譯器與最佳化層級下的建置特徵，包括各函式的字串、常數、呼叫模式、大小、堆疊框架、指令與控制流程形態、原始檔順序以及函式指標表。發行包涵蓋 Linux（x86 與 ARM64 上的 GCC 與 clang）、macOS（Apple clang）以及 Windows（從 Visual Studio 2026 到 Visual C++ 6.0 的 MSVC），並包含 Lua、SQLite、zlib、mbedTLS、MinHook、LZ4 等函式庫的指紋。儲存庫保存含套件校驗和與函式庫中繼資料的清單；Karta-x 中的 Python 取得命令會下載並驗證配置包至本機 config 目錄。面向需要在剝除符號或混淆的可執行檔（含靜態連結常見第三方程式碼的遊戲用戶端）中可靠識別函式庫並命名函式的逆向工程師與二進位分析人員。
