SkyOP Client 是一款面向 Minecraft Java 版 26.3 的客戶端 Fabric 模組，將戰鬥、移動、視覺、物品欄與 HUD 等功能集中在可搜尋的 ClickGUI 中。專案使用 Java 實作，基於 Fabric Loader、Fabric Loom、Gradle 與 Minecraft mixin，並包含 JSON 設定、多語系 UI 字串以及針對設定編解碼器的單元測試。主要能力包括 KillAura、TriggerBot、AutoClicker、飛行與加速輔助、實體 ESP、豐富的螢幕 HUD 面板，以及自動進食、護甲、工具選擇、補給與釣魚等物品欄自動化。物品欄與容器變更採用原版客戶端動作，伺服器可驗證或拒絕；作者說明多人遊戲限制，而非聲稱可繞過反作弊。此專案適用於遊戲安全研究、反作弊評估，以及對現代 Java 版客戶端作弊架構與模組設計的逆向分析。
