SkyOP Client 是一款面向 Minecraft Java 版 26.3 的客户端 Fabric 模组，将战斗、移动、视觉、物品栏与 HUD 等功能集中在可搜索的 ClickGUI 中。项目使用 Java 实现，基于 Fabric Loader、Fabric Loom、Gradle 与 Minecraft mixin，并包含 JSON 配置、多语言 UI 字符串以及针对配置编解码器的单元测试。主要能力包括 KillAura、TriggerBot、AutoClicker、飞行与加速辅助、实体 ESP、丰富的屏幕 HUD 面板，以及自动进食、护甲、工具选择、补货与钓鱼等物品栏自动化。物品栏与容器变更采用原版客户端动作，服务器可校验或拒绝；作者说明多人游戏限制，而非声称可绕过反作弊。该项目适用于游戏安全研究、反作弊评估，以及对现代 Java 版客户端作弊架构与模块设计的逆向分析。
