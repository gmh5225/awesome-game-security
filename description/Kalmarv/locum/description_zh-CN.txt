Locum 是一款 Direct3D 11 帧捕获与检查工具，可将一帧内的每次 draw 与 dispatch（着色器、常量、纹理、缓冲区、管线状态与渲染目标）记录到单个 SQLite 数据库中，便于浏览、查询与回放。通过在 64 位游戏可执行文件旁放置配套的 DXGI 与 D3D11 shim DLL 工作，理念类似 RenderDoc，但无需进程注入。Rust 核心实现挂钩、捕获存储与离线回放，并支持渲染目标的逐位校验；由 Bun 驱动的本地 Web 查看器与 locum-cli 提供绘制列表、着色器反汇编、资源导出、SQL 访问、实时绘制覆盖与捕获差异对比。资源追踪将 GPU 资产关联到磁盘文件与游戏内存，回放支持跳过绘制或替换着色器以便实验。面向 Windows 图形调试、渲染逆向工程以及 D3D11 游戏的安全研究，明确不适用于受反作弊保护的在线联机游戏。
