Locum 是一款 Direct3D 11 幀擷取與檢查工具，可將一幀內的每次 draw 與 dispatch（著色器、常數、紋理、緩衝區、管線狀態與渲染目標）記錄到單一 SQLite 資料庫中，便於瀏覽、查詢與回放。透過在 64 位元遊戲可執行檔旁放置配套的 DXGI 與 D3D11 shim DLL 運作，理念類似 RenderDoc，但無需行程注入。Rust 核心實作掛鉤、擷取儲存與離線回放，並支援渲染目標的逐位元校驗；由 Bun 驅動的本機 Web 檢視器與 locum-cli 提供繪製清單、著色器反組譯、資源匯出、SQL 存取、即時繪製覆寫與擷取差異比對。資源追蹤將 GPU 資產關聯到磁碟檔案與遊戲記憶體，回放支援跳過繪製或替換著色器以便實驗。面向 Windows 圖形除錯、渲染逆向工程以及 D3D11 遊戲的安全研究，明確不適用於受反作弊保護的線上連線遊戲。
