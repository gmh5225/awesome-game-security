Locum is a Direct3D 11 frame capture and inspection tool that records every draw and dispatch in a frame—shaders, constants, textures, buffers, pipeline state, and render targets—into a single SQLite database you can browse, query, and replay. It works by placing companion DXGI and D3D11 shim DLLs beside a 64-bit game executable, similar in spirit to RenderDoc but without process injection. The Rust core implements hooking, capture storage, and offline replay with bit-for-bit render-target verification, while a Bun-powered local web viewer and locum-cli provide draw lists, shader disassembly, resource export, SQL access, live draw overrides, and capture diffs. Resource tracing links GPU assets back to on-disk files and game memory, and replay supports skipping draws or swapping shaders for experimentation. It targets Windows graphics debugging, rendering reverse engineering, and security research on D3D11 titles, and is explicitly unsuitable for live online games protected by anti-cheat.
