Locum은 Direct3D 11 프레임 캡처 및 검사 도구로, 한 프레임의 모든 draw와 dispatch—셰이더, 상수, 텍스처, 버퍼, 파이프라인 상태, 렌더 타깃—을 단일 SQLite 데이터베이스에 기록해 탐색·쿼리·재생할 수 있습니다. 64비트 게임 실행 파일 옆에 DXGI 및 D3D11 shim DLL을 두는 방식으로 동작하며, RenderDoc과 유사한 취지이나 프로세스 주입은 필요 없습니다. Rust 코어가 후킹, 캡처 저장, 오프라인 재생과 렌더 타깃의 비트 단위 검증을 구현하고, Bun 기반 로컬 웹 뷰어와 locum-cli가 draw 목록, 셰이더 디스어셈블리, 리소스 내보내기, SQL 접근, 라이브 draw 오버라이드, 캡처 diff를 제공합니다. 리소스 추적으로 GPU 자산을 디스크 파일 및 게임 메모리와 연결하고, 재생 시 draw 건너뛰기나 셰이더 교체 실험이 가능합니다. Windows 그래픽 디버깅, 렌더링 리버스 엔지니어링, D3D11 타이틀 보안 연구를 대상으로 하며, 안티치트로 보호된 라이브 온라인 게임에는 명시적으로 부적합합니다.
