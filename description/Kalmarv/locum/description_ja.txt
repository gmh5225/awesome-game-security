Locum は Direct3D 11 のフレームキャプチャおよび検査ツールで、1 フレーム内の draw と dispatch ごとにシェーダー、定数、テクスチャ、バッファ、パイプライン状態、レンダーターゲットを記録し、単一の SQLite データベースにまとめて閲覧・クエリ・リプレイできます。64 ビットゲーム実行ファイルの横に DXGI および D3D11 用 shim DLL を置く方式で動作し、RenderDoc に近い発想ですがプロセス注入は不要です。Rust コアがフック、キャプチャ保存、オフラインリプレイとレンダーターゲットのビット単位検証を実装し、Bun ベースのローカル Web ビューアと locum-cli が draw リスト、シェーダ逆アセンブリ、リソースエクスポート、SQL アクセス、ライブ draw オーバーライド、キャプチャ差分を提供します。リソーストレーシングで GPU アセットをディスク上のファイルやゲームメモリに紐づけ、リプレイでは draw のスキップやシェーダ差し替えによる実験が可能です。Windows 上のグラフィックスデバッグ、レンダリング逆解析、D3D11 タイトル向けセキュリティ研究を対象とし、アンチチートで保護されたライブオンラインゲームには明示的に不向きです。
