Mjölnir は Windows 向けの反チートスタックで、マシン上の検知とスタジオが制御する執行を分離します。クライアントは C++ のセキュリティコアと Rust エージェントを組み合わせ、ゲームプロセスを監査し、モジュールおよびオーバーレイのスキャン、デバッガー検出、メモリ整合性、フック解析、インジェクションのヒューリスティクス、自己保護などのチェックで証拠を収集し、HMAC で保護された IPC およびオプションの HTTPS 取り込み経由でテレメトリを転送します。自己ホスト型の Rust サーバーがゲーム開発者向けのコントロールプレーンとして機能し、セッションスコアリング、ポリシー、キックおよび BAN の判断、バックエンド BAN システムへの Webhook を処理します。オプションの Tauri ダッシュボードはローカルでの可視性を提供し、デフォルトの observe-only モードにより、スタジオは執行を有効にする前に調査できます。第三者のクラウドサービスに依存せず、自社の反チートおよびインシデント対応ワークフローを構築・運用するゲームスタジオを対象としています。
