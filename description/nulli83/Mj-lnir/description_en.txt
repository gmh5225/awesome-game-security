Mjölnir is a Windows-focused anti-cheat stack that separates on-machine detection from studio-controlled enforcement. The client combines a C++ security core and Rust agent to audit the game process, gather evidence via checks such as module and overlay scanning, debugger detection, memory integrity, hook analysis, injection heuristics, and self-protection, then forward telemetry over HMAC-secured IPC and optional HTTPS ingest. A self-hosted Rust server acts as the control plane for game developers, handling session scoring, policy, kick and ban decisions, and webhooks to backend ban systems. An optional Tauri dashboard provides local visibility, while default observe-only mode lets studios investigate before enabling enforcement. It is aimed at game studios building or operating their own anti-cheat and incident response workflows rather than relying on a third-party cloud service.
