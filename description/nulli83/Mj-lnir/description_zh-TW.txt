Mjölnir 是一套面向 Windows 的反作弊技術堆疊，將本機偵測與由工作室控制的執行機制分離。用戶端結合 C++ 安全核心與 Rust 代理，對遊戲程序進行稽核，透過模組與覆蓋層掃描、偵錯器偵測、記憶體完整性檢查、Hook 分析、注入啟發式偵測以及自我保護等方式收集證據，隨後經 HMAC 保護的 IPC 及可選的 HTTPS 上報通道轉發遙測資料。自託管的 Rust 伺服器作為遊戲開發者的控制平面，負責工作階段評分、策略管理、踢出與封禁決策，以及向後端封禁系統傳送 webhook。可選的 Tauri 儀表板提供本機可視化能力，而預設的僅觀察模式則讓工作室在啟用執行機制前先進行調查。它面向自行建構或營運反作弊與事件回應流程、而非依賴第三方雲端服務的遊戲工作室。
