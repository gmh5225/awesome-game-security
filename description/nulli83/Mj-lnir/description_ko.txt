Mjölnir은 Windows 중심의 안티치트 스택으로, 온머신 탐지와 스튜디오가 제어하는 집행을 분리합니다. 클라이언트는 C++ 보안 코어와 Rust 에이전트를 결합해 게임 프로세스를 감사하고, 모듈 및 오버레이 스캔, 디버거 탐지, 메모리 무결성, 후크 분석, 인젝션 휴리스틱, 자기 보호 등의 검사를 통해 증거를 수집한 뒤 HMAC으로 보호된 IPC 및 선택적 HTTPS 수집 경로를 통해 원격 측정 데이터를 전달합니다. 자체 호스팅 Rust 서버는 게임 개발자를 위한 제어 평면으로 동작하며, 세션 점수 산정, 정책, 킥 및 밴 결정, 백엔드 밴 시스템으로의 웹훅을 처리합니다. 선택적 Tauri 대시보드는 로컬 가시성을 제공하고, 기본 observe-only 모드는 스튜디오가 집행을 활성화하기 전에 조사할 수 있게 합니다. 서드파티 클라우드 서비스에 의존하지 않고 자체 안티치트 및 사고 대응 워크플로를 구축·운영하려는 게임 스튜디오를 대상으로 합니다.
