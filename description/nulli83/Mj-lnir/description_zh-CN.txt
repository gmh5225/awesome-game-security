Mjölnir 是一套面向 Windows 的反作弊技术栈，将本地检测与由工作室控制的执行机制分离。客户端结合 C++ 安全核心与 Rust 代理，对游戏进程进行审计，通过模块与覆盖层扫描、调试器检测、内存完整性检查、钩子分析、注入启发式检测以及自我保护等方式收集证据，随后经 HMAC 保护的 IPC 及可选的 HTTPS 上报通道转发遥测数据。自托管的 Rust 服务器作为游戏开发者的控制平面，负责会话评分、策略管理、踢出与封禁决策，以及向后端封禁系统发送 webhook。可选的 Tauri 仪表盘提供本地可视化能力，而默认的仅观察模式则让工作室在启用执行机制前先进行调查。它面向自行构建或运营反作弊与事件响应流程、而非依赖第三方云服务的游戏工作室。
