PaiAC is a modular server-side anti-cheat plugin for Minecraft Java Edition aimed at survival, economy, and crystal or anchor PvP networks. It is implemented in Java 21 with Gradle and targets Paper (roughly 1.21.1 through 1.21.11), with code paths for Folia and Spigot or Bukkit. The plugin runs checks for movement cheats such as fly, speed, and boat-fly, combat signals like reach, kill aura, and auto-clicker, and PvP-specific macros including crystal placement bursts, respawn anchor timing, auto-totem, and fast experience bottles, while surfacing native Paper anti-xray configuration status instead of reimplementing x-ray detection. Violation levels, evidence storage in SQLite, configurable punishments and ban lists, lag-aware gating, and an administrative command suite support operators who want detection-first defaults with optional enforcement for protecting multiplayer game integrity.
