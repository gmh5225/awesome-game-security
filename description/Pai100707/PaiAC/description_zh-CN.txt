PaiAC 是一款面向 Minecraft Java 版生存、经济与水晶或重生锚 PvP 服网的可模块化服务端反作弊插件。它以 Java 21 和 Gradle 实现，面向 Paper（约 1.21.1 至 1.21.11），并包含适用于 Folia 以及 Spigot 或 Bukkit 的代码路径。插件会检测移动类作弊（如飞行、加速、船飞行）、战斗类信号（如攻击距离、杀戮光环、自动连点），以及 PvP 相关宏（如水晶连放、重生锚时序、自动图腾、快速经验瓶），同时展示 Paper 原生 anti-xray 配置状态，而非重新实现 X 光检测。违规等级、SQLite 证据存储、可配置的惩罚与封禁列表、延迟感知门控以及管理命令套件，为希望以检测为先、可选 enforcement 来保护多人游戏完整性的运维者提供支持。
