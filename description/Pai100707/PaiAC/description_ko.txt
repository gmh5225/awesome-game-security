PaiAC는 Minecraft Java Edition의 서바이벌·경제·크리스털 또는 리스폰 앵커 PvP 네트워크를 위한 모듈형 서버 측 안티치트 플러그인입니다. Java 21과 Gradle로 구현되었으며 Paper(대략 1.21.1~1.21.11)를 대상으로 하고, Folia 및 Spigot 또는 Bukkit용 코드 경로를 포함합니다. 플러그인은 비행·스피드·보트 비행 같은 이동 치트, 리치·킬 오라·오토 클리커 같은 전투 신호, 크리스털 연속 설치·리스폰 앵커 타이밍·오토 토템·빠른 경험치 병 등 PvP 전용 매크로를 검사하며, X-ray 탐지를 다시 구현하는 대신 Paper 기본 anti-xray 설정 상태를 표시합니다. 위반 단계, SQLite 증거 저장, 설정 가능한 처벌 및 밴 목록, 지연 인식 게이팅, 관리 명령 세트가 탐지 우선 기본값과 선택적 enforcement로 멀티플레이 무결성을 보호하려는 운영자를 지원합니다.
