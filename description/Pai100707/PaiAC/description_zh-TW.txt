PaiAC 是一款面向 Minecraft Java 版生存、經濟與水晶或重生錨 PvP 服網的可模組化伺服器端反作弊外掛。它以 Java 21 與 Gradle 實作，目標為 Paper（約 1.21.1 至 1.21.11），並包含適用於 Folia 以及 Spigot 或 Bukkit 的程式路徑。外掛會檢測移動類作弊（如飛行、加速、船飛行）、戰鬥類訊號（如攻擊距離、殺戮光環、自動連點），以及 PvP 專用巨集（如水晶連放、重生錨時序、自動圖騰、快速經驗瓶），同時呈現 Paper 原生 anti-xray 設定狀態，而非重新實作 X 光偵測。違規等級、SQLite 證據儲存、可設定的懲罰與封鎖名單、延遲感知閘控，以及管理指令套件，為希望以偵測為先、可選 enforcement 來保護多人遊戲完整性的營運者提供支援。
