PaiAC — модульный серверный античит-плагин для Minecraft Java Edition, ориентированный на сети выживания, экономики и PvP с кристаллами или якорями возрождения. Реализован на Java 21 с Gradle и рассчитан на Paper (примерно с 1.21.1 по 1.21.11), с ветками кода для Folia, а также Spigot или Bukkit. Плагин проверяет читы движения вроде полёта, скорости и полёта на лодке, боевые сигналы вроде дальности удара, kill aura и автокликера, а также PvP-макросы: серии установки кристаллов, тайминг якоря, авто-тотем и быстрые бутылки опыта, при этом отображает статус встроенной конфигурации anti-xray в Paper вместо повторной реализации обнаружения X-ray. Уровни нарушений, хранение доказательств в SQLite, настраиваемые наказания и бан-листы, учёт лагов при фильтрации и набор административных команд помогают операторам, которым нужны настройки по умолчанию с упором на обнаружение и опциональное enforcement для защиты честности мультиплеера.
