PaiAC は、Minecraft Java Edition のサバイバル・経済・クリスタルまたはリスポーンアンカー PvP 系ネットワーク向けのモジュール式サーバー側アンチチートプラグインです。Java 21 と Gradle で実装され、Paper（おおよそ 1.21.1 から 1.21.11）を対象とし、Folia および Spigot または Bukkit 向けのコードパスも備えます。プラグインは飛行・スピード・ボート飛行などの移動チート、リーチ・キルオーラ・オートクリッカーといった戦闘シグナル、クリスタル連続設置・リスポーンアンカータイミング・オートトーテム・高速エクスペボトルなど PvP 向けマクロを検査し、X 線検出を再実装する代わりに Paper ネイティブの anti-xray 設定状態を表示します。違反レベル、SQLite による証拠保存、設定可能な制裁と BAN リスト、ラグを考慮したゲーティング、管理コマンド一式により、検出優先のデフォルトと任意の enforcement でマルチプレイの公正性を守りたい運用者を支援します。
