Better Godot MCP 是一个 TypeScript 实现的 Model Context Protocol（MCP）服务器，可让 AI 编码代理通过一组复合工具创建和修改 Godot Engine 4.x 项目。它提供十七个超级工具，覆盖场景、节点、GDScript、着色器、动画、TileMap、物理、音频、导航、UI、输入映射、信号、资源以及项目运行/导出流程。场景与脚本相关工作可在未打开 Godot 编辑器的情况下，通过将 .tscn 及相关文件作为文本解析与编辑来完成；可选的无头或编辑器启动则使用自动检测的 Godot 二进制，经 stdio 或 Streamable HTTP 通信。该技术栈面向 Node.js 与 bun，包含 Docker 打包，并对本地文件与进程操作进行加固，以防路径遍历与命令注入。主要用途是通过 Claude Code、Cursor 等 MCP 客户端，进行 AI 辅助的 Godot 游戏开发。
