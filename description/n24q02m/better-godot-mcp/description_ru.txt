Better Godot MCP — это сервер Model Context Protocol (MCP) на TypeScript, который позволяет ИИ-агентам для кодирования создавать и изменять проекты Godot Engine 4.x с помощью набора составных инструментов. Он предоставляет семнадцать мега-инструментов, охватывающих сцены, узлы, GDScript, шейдеры, анимацию, тайловые карты, физику, аудио, навигацию, UI, карты ввода, сигналы, ресурсы, а также сценарии запуска и экспорта проекта. Работа со сценами и скриптами может выполняться без открытого редактора Godot путём разбора и правки .tscn и связанных файлов как текста, а опциональный запуск в headless-режиме или с редактором использует автоматически обнаруженный бинарник Godot по stdio или Streamable HTTP. Стек ориентирован на Node.js с bun, включает упаковку в Docker и усиливает локальные операции с файлами и процессами против path traversal и внедрения команд. Основной сценарий — ИИ-поддерживаемая разработка игр на Godot из MCP-клиентов вроде Claude Code, Cursor и похожих агентных сред.
