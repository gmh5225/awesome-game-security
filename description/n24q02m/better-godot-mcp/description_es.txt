Better Godot MCP es un servidor Model Context Protocol (MCP) en TypeScript que permite a los agentes de coding con IA crear y modificar proyectos de Godot Engine 4.x mediante un conjunto de herramientas compuestas. Expone diecisiete mega-herramientas que cubren escenas, nodos, GDScript, shaders, animación, tilemaps, física, audio, navegación, UI, mapas de entrada, señales, recursos y flujos de ejecución/exportación del proyecto. El trabajo con escenas y scripts puede realizarse sin abrir el editor de Godot, analizando y editando archivos .tscn y relacionados como texto, mientras que los lanzamientos opcionales headless o con editor usan un binario de Godot autodetectado por stdio o Streamable HTTP. La pila apunta a Node.js con bun, incluye empaquetado Docker y endurece las operaciones locales de archivos y procesos frente a path traversal e inyección de comandos. El caso de uso principal es el desarrollo de juegos Godot asistido por IA desde clientes MCP como Claude Code, Cursor y entornos de agentes similares.
