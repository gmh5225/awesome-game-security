Better Godot MCP는 AI 코딩 에이전트가 복합 도구 세트를 통해 Godot Engine 4.x 프로젝트를 만들고 수정할 수 있게 하는 TypeScript Model Context Protocol(MCP) 서버입니다. 씬, 노드, GDScript, 셰이더, 애니메이션, 타일맵, 물리, 오디오, 내비게이션, UI, 입력 맵, 시그널, 리소스, 프로젝트 실행/내보내기 워크플로를 다루는 열일곱 개의 메가 도구를 제공합니다. 씬과 스크립트 작업은 Godot 에디터를 열지 않고도 .tscn 및 관련 파일을 텍스트로 파싱·편집할 수 있으며, 선택적 헤드리스 또는 에디터 실행은 자동 감지된 Godot 바이너리를 stdio 또는 Streamable HTTP로 사용합니다. 스택은 Node.js와 bun을 대상으로 하며 Docker 패키징을 포함하고, 경로 순회 및 명령 주입에 대비해 로컬 파일·프로세스 작업을 강화합니다. 주요 사용 사례는 Claude Code, Cursor 등 MCP 클라이언트에서 AI 지원 Godot 게임 개발입니다.
