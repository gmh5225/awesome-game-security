Better Godot MCP ist ein TypeScript-Model-Context-Protocol-(MCP)-Server, mit dem KI-Coding-Agenten Godot-Engine-4.x-Projekte über eine Reihe zusammengesetzter Tools erstellen und ändern können. Er stellt siebzehn Mega-Tools bereit, die Szenen, Nodes, GDScript, Shader, Animation, Tilemaps, Physik, Audio, Navigation, UI, Input Maps, Signale, Ressourcen sowie Projekt-Run-/Export-Workflows abdecken. Arbeit an Szenen und Skripten kann ohne geöffneten Godot-Editor erfolgen, indem .tscn- und verwandte Dateien als Text geparst und bearbeitet werden; optionale Headless- oder Editor-Starts nutzen eine automatisch erkannte Godot-Binary über stdio oder Streamable HTTP. Der Stack zielt auf Node.js mit bun, umfasst Docker-Packaging und härtet lokale Datei- und Prozessoperationen gegen Path Traversal und Command Injection ab. Primärer Einsatzzweck ist die KI-unterstützte Godot-Spieleentwicklung aus MCP-Clients wie Claude Code, Cursor und ähnlichen Agent-Umgebungen.
