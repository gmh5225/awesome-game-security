Better Godot MCP は、AI コーディングエージェントが複合ツール群を通じて Godot Engine 4.x プロジェクトを作成・変更できるようにする TypeScript 製の Model Context Protocol（MCP）サーバーです。シーン、ノード、GDScript、シェーダー、アニメーション、タイルマップ、物理、オーディオ、ナビゲーション、UI、入力マップ、シグナル、リソース、プロジェクトの実行／エクスポートまでをカバーする 17 のメガツールを公開します。シーンとスクリプトの作業は、Godot エディターを開かなくても .tscn などの関連ファイルをテキストとして解析・編集でき、任意のヘッドレスまたはエディター起動では自動検出した Godot バイナリを stdio または Streamable HTTP 経由で利用します。スタックは Node.js と bun を対象とし、Docker パッケージングを備え、パストラバーサルやコマンドインジェクションに対してローカルのファイル／プロセス操作を強化しています。主な用途は、Claude Code や Cursor などの MCP クライアントからの AI 支援による Godot ゲーム開発です。
