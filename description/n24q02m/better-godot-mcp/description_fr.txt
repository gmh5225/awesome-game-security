Better Godot MCP est un serveur Model Context Protocol (MCP) en TypeScript qui permet aux agents de coding IA de créer et modifier des projets Godot Engine 4.x via un ensemble d’outils composites. Il expose dix-sept méga-outils couvrant les scènes, nœuds, GDScript, shaders, animation, tilemaps, physique, audio, navigation, UI, maps d’entrée, signaux, ressources, ainsi que les flux d’exécution et d’export de projet. Le travail sur les scènes et scripts peut s’effectuer sans ouvrir l’éditeur Godot, en analysant et éditant les fichiers .tscn et associés comme du texte, tandis que les lancements optionnels headless ou éditeur utilisent un binaire Godot détecté automatiquement via stdio ou Streamable HTTP. La pile cible Node.js avec bun, inclut un packaging Docker, et durcit les opérations locales sur les fichiers et processus contre le path traversal et l’injection de commandes. Le cas d’usage principal est le développement de jeux Godot assisté par IA depuis des clients MCP tels que Claude Code, Cursor et des environnements d’agents similaires.
