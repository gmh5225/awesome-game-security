Better Godot MCP 是以 TypeScript 實作的 Model Context Protocol（MCP）伺服器，可讓 AI 編碼代理透過一組複合工具建立與修改 Godot Engine 4.x 專案。它提供十七個超級工具，涵蓋場景、節點、GDScript、著色器、動畫、TileMap、物理、音訊、導航、UI、輸入對應、訊號、資源以及專案執行／匯出流程。場景與腳本相關工作可在未開啟 Godot 編輯器的情況下，透過將 .tscn 及相關檔案以文字方式解析與編輯來完成；可選的無頭或編輯器啟動則使用自動偵測的 Godot 二進位檔，經由 stdio 或 Streamable HTTP 通訊。此技術堆疊面向 Node.js 與 bun，包含 Docker 打包，並強化本機檔案與行程操作，以防路徑遍歷與命令注入。主要用途是透過 Claude Code、Cursor 等 MCP 用戶端，進行 AI 輔助的 Godot 遊戲開發。
