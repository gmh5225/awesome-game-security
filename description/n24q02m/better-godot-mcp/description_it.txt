Better Godot MCP è un server Model Context Protocol (MCP) in TypeScript che consente agli agenti di coding IA di creare e modificare progetti Godot Engine 4.x tramite un set di strumenti compositi. Espone diciassette mega-tool che coprono scene, nodi, GDScript, shader, animazione, tilemap, fisica, audio, navigazione, UI, mappe di input, segnali, risorse e flussi di esecuzione/esportazione del progetto. Il lavoro su scene e script può avvenire senza aprire l’editor Godot, analizzando e modificando i file .tscn e correlati come testo, mentre i lanci opzionali headless o con editor usano un binario Godot rilevato automaticamente via stdio o Streamable HTTP. Lo stack punta a Node.js con bun, include packaging Docker e rafforza le operazioni locali su file e processi contro path traversal e command injection. Il caso d’uso principale è lo sviluppo di giochi Godot assistito dall’IA da client MCP come Claude Code, Cursor e ambienti agent simili.
