Securify is an open-source Android security verification and hardware attestation utility that evaluates whether a device is rooted, tampered with, or running in an emulator. Its native Rei 2.0.0 engine performs multi-threaded on-device audits across root, injection, framework, emulator, and system-integrity domains, detecting threats such as Magisk, KernelSU, Frida hooks, and Xposed-style bytecode manipulation. The app also verifies Google Play Integrity attestation through a configured backend and reports kernel version, supported ABIs, build fingerprint, and security patch level, with optional diagnostic log export via the Android Storage Access Framework. Written in Kotlin with Jetpack Compose and a modular Gradle architecture, it targets developers and security researchers who need mobile device integrity checks for anti-cheat, fraud prevention, and reverse-engineering research.
