ShinobiX는 React와 Vite 기반의 싱글 페이지 클라이언트, TypeScript API 서버, Supabase 기반 영속화를 갖춘 브라우저 기반 닌자 MMORPG로, 라이브 서비스 게임으로 제공됩니다. 코드베이스는 서버 권한 기반 전투, PvE, 경제, 플레이어 저장 흐름을 중심으로 하며, 정산 영수증, 통화 원장, 저장 잠금, 인증 정책을 통해 클라이언트 측 변조와 복제를 방지합니다. HTTP 강화, 인증 및 안티치트 패턴, 보상 무결성 계약, 전투 권한 경계를 다루는 광범위한 보안 중심 문서와 감사 자료가 포함되어 있으며, parity 및 settlement 경로 전반에 걸친 광범위한 자동화 테스트로 뒷받침됩니다. 이 프로젝트는 온라인 RPG 시스템에서 실용적인 안티치트 및 백엔드 무결성 패턴을 연구하는 게임 개발자와 보안 연구자에게 주로 유용합니다.
