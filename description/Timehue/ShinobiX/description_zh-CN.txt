ShinobiX 是一款基于浏览器的忍者 MMORPG，以 live-service 形式交付，采用 React 与 Vite 构建的单页客户端、TypeScript API 服务器以及 Supabase 后端持久化。代码库围绕服务端权威的战斗、PvE、经济系统与玩家存档流程展开，通过结算收据、货币账本、存档锁与认证策略来抵御客户端篡改与复制。项目提供大量面向安全的文档与审计材料，涵盖 HTTP 加固、认证与反作弊模式、奖励完整性契约以及战斗权威边界，并在 parity 与 settlement 路径上拥有广泛的自动化测试覆盖。该项目主要面向游戏开发者与安全研究人员，用于研究在线 RPG 系统中实用的反作弊与后端完整性模式。
