ShinobiX は、React と Vite によるシングルページクライアント、TypeScript の API サーバー、Supabase による永続化を備えた、ブラウザベースの忍者 MMORPG で、ライブサービスとして提供されます。コードベースはサーバー権威型の戦闘、PvE、経済、プレイヤーセーブのフローを中心とし、決済レシート、通貨台帳、セーブロック、認証ポリシーを用いてクライアント側の改ざんや複製に対抗します。HTTP ハードニング、認証とアンチチートのパターン、報酬整合性契約、戦闘権限の境界を網羅する、セキュリティ指向の詳細なドキュメントと監査資料が同梱されており、parity および settlement パス全体にわたる広範な自動テストで裏付けられています。本プロジェクトは、オンライン RPG システムにおける実践的なアンチチートとバックエンド整合性パターンを研究するゲーム開発者やセキュリティ研究者に主に有用です。
