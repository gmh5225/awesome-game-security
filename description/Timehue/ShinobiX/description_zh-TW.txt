ShinobiX 是一款以瀏覽器為平台的忍者 MMORPG，以 live-service 形式交付，採用 React 與 Vite 建構的單頁用戶端、TypeScript API 伺服器，以及 Supabase 後端持久化。程式碼庫圍繞伺服器端權威的戰鬥、PvE、經濟系統與玩家存檔流程，透過結算收據、貨幣帳本、存檔鎖與認證策略來抵禦用戶端竄改與複製。專案提供大量面向安全的文件與稽核材料，涵蓋 HTTP 強化、認證與反作弊模式、獎勵完整性契約以及戰鬥權威邊界，並在 parity 與 settlement 路徑上擁有廣泛的自動化測試覆蓋。此專案主要供遊戲開發者與安全研究人員，研究線上 RPG 系統中實用的反作弊與後端完整性模式。
