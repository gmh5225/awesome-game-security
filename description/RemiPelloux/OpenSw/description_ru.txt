OpenSw — автономный эмулятор Nintendo Switch для Android, основанный на кодовых базах Eden и yuzu и ориентированный на универсальные устройства ARM64 с опциональным профилем оптимизации AYN Thor. Ядро написано на C++ с JIT-перекомпиляцией ARM через dynarmic, рендерингом Vulkan и OpenGL и Android-интерфейсом на Kotlin. В проект добавлены инструменты OpenSw: импорт читов с учётом build ID из форматов Atmosphere и Eden, внутриигровая панель Cockpit и диагностика производительности со снимками сеансов. Проект включает чит-движок в стиле dmnt, профили конфигурации для каждой игры и вариант сборки Profile с мостом автоматизации для лабораторного тестирования. Он предназначен для исследователей Switch, разработчиков эмуляторов и пользователей, изучающих поведение игр, читы и эмуляцию Switch на Android.
