OpenSw 是一款獨立的 Android 版 Nintendo Switch 模擬器，源自 Eden 與 yuzu 程式碼庫，面向通用 ARM64 裝置，並提供可選的 AYN Thor 最佳化設定檔。核心以 C++ 撰寫，支援 dynarmic ARM JIT 重編譯、Vulkan 與 OpenGL 渲染，以及基於 Kotlin 的 Android 前端。它新增 OpenSw 專屬工具，例如支援 build ID 的 Atmosphere 與 Eden 格式金手指匯入、遊戲內 Cockpit 面板，以及含工作階段快照的效能診斷。專案包含 dmnt 風格的金手指引擎、逐遊戲設定檔，以及附帶實驗室測試自動化橋接的 Profile 建置變體。面向 Switch 研究人員、模擬器開發者，以及研究遊戲行為、金手指與 Android 端 Switch 模擬的使用者。
