OpenSw は、Eden および yuzu のコードベースを基にしたスタンドアロンの Android 向け Nintendo Switch エミュレータで、汎用 ARM64 デバイスを対象とし、オプションで AYN Thor 向け最適化プロファイルを提供します。コアは C++ で実装され、dynarmic による ARM JIT 再コンパイル、Vulkan および OpenGL レンダリング、Kotlin ベースの Android フロントエンドを備えています。Atmosphere および Eden 形式からの build ID 対応チートインポート、ゲーム内 Cockpit パネル、セッションスナップショット付きパフォーマンス診断など、OpenSw 固有のツールも追加されています。プロジェクトには dmnt スタイルのチートエンジン、ゲームごとの設定プロファイル、ラボテスト用自動化ブリッジを備えた Profile ビルドバリアントも含まれます。Switch 研究者、エミュレータ開発者、ゲームの挙動・チート・Android 上での Switch エミュレーションを調査するユーザー向けです。
