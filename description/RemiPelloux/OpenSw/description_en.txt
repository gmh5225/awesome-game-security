OpenSw is a standalone Android Nintendo Switch emulator derived from the Eden and yuzu codebases, targeting generic ARM64 devices with an optional AYN Thor optimization profile. The core is written in C++ with dynarmic ARM JIT recompilation, Vulkan and OpenGL rendering, and a Kotlin-based Android frontend. It adds OpenSw-specific tooling such as build-ID-aware cheat import from Atmosphere and Eden formats, an in-game Cockpit panel, and performance diagnostics with session snapshots. The project includes a dmnt-style cheat engine, per-game configuration profiles, and a Profile build variant with an automation bridge for lab testing. It is aimed at Switch researchers, emulator developers, and users investigating game behavior, cheats, and Android-side Switch emulation.
