OpenSw 是一款独立的 Android 版 Nintendo Switch 模拟器，源自 Eden 与 yuzu 代码库，面向通用 ARM64 设备，并提供可选的 AYN Thor 优化配置。核心采用 C++ 编写，支持 dynarmic ARM JIT 重编译、Vulkan 与 OpenGL 渲染，以及基于 Kotlin 的 Android 前端。它增加了 OpenSw 专属工具，例如支持 build ID 的 Atmosphere 与 Eden 格式金手指导入、游戏内 Cockpit 面板，以及带会话快照的性能诊断。项目包含 dmnt 风格的金手指引擎、逐游戏配置档案，以及带有实验室测试自动化桥接的 Profile 构建变体。面向 Switch 研究人员、模拟器开发者，以及研究游戏行为、金手指与 Android 端 Switch 模拟的用户。
