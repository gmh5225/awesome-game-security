Futari Recomp is a native desktop port that statically recompiles a commercial Xbox 360 title into host-machine code instead of emulating the console at runtime. The codebase is built with CMake and C++, bundles the RexGlue SDK for PowerPC translation and Xbox kernel or filesystem abstractions, and adds a Renut-based graphics layer with D3D and Vulkan backends, shader caching, and tooling to dump or translate guest GPU programs. Python utilities and documentation support analyzing XEX modules, extracting disc images, and preparing user-supplied game data through a launcher workflow. It is aimed at reverse engineers and preservation-oriented developers studying Xbox 360 binaries, static recompilation pipelines, and how legacy titles are brought to modern platforms.
