Futari Recomp 是一款原生桌面移植專案，透過靜態重編譯將商業 Xbox 360 遊戲轉換為可在宿主機上直接執行的機器碼，而非在執行時模擬整台主機。程式庫以 CMake 與 C++ 建置，整合 RexGlue SDK 以完成 PowerPC 指令翻譯以及 Xbox 核心與檔案系統抽象，並加上以 Renut 為基礎的圖形層，提供 D3D 與 Vulkan 後端、著色器快取，以及用於傾印或翻譯訪客 GPU 程式的工具鏈。附帶的 Python 工具與文件支援分析 XEX 模組、擷取光碟映像，並透過啟動器工作流程準備使用者提供的遊戲資料。本專案面向逆向工程師與重視遊戲保存的開發者，用於研究 Xbox 360 二進位檔、靜態重編譯管線，以及如何將舊作帶上現代平台。
