Futari Recomp 是一款原生桌面移植项目，通过静态重编译将商业 Xbox 360 游戏转换为可在宿主机上直接执行的机器码，而非在运行时模拟整机。代码库基于 CMake 与 C++ 构建，集成 RexGlue SDK 以完成 PowerPC 指令翻译以及 Xbox 内核与文件系统抽象，并叠加基于 Renut 的图形层，提供 D3D 与 Vulkan 后端、着色器缓存，以及用于转储或翻译访客 GPU 程序的工具链。配套 Python 工具与文档支持分析 XEX 模块、提取光盘镜像，并通过启动器工作流准备用户提供的游戏数据。项目面向逆向工程师与注重游戏保存的开发者，用于研究 Xbox 360 二进制、静态重编译流水线，以及如何将遗留作品迁移到现代平台。
