Futari Recomp は、商用 Xbox 360 タイトルを実行時にコンソールをエミュレートするのではなく、静的再コンパイルによってホストマシン上で実行可能なネイティブコードへ変換するデスクトップ向けネイティブポートである。コードベースは CMake と C++ で構築され、PowerPC 翻訳と Xbox カーネルやファイルシステムの抽象化のために RexGlue SDK を同梱し、Renut ベースのグラフィックス層に D3D と Vulkan バックエンド、シェーダーキャッシュ、ゲスト GPU プログラムのダンプや変換用ツールを備えている。Python ユーティリティとドキュメントは XEX モジュールの解析、ディスクイメージの抽出、ランチャー経由でユーザーが用意したゲームデータの準備を支援する。Xbox 360 バイナリ、静的再コンパイルパイプライン、レガシータイトルを現代プラットフォームへ持ち込む方法を研究するリバースエンジニアや保存志向の開発者向けである。
