Droid-vm runs a full Android guest with real Magisk, KernelSU (LKM), or KernelPatch (KPM) on stock, non-rooted arm64 phones by booting a genuine Linux kernel as a User Mode Linux (UML) process instead of using containers or QEMU. It builds on an Android GKI-based arm64 UML port with SMP, ext4/qcow2 root disks, binder, and optional framebuffer and virtio-gpu support, and layers kernel configs for module loading, kprobes, and Magisk-friendly features. Shell scripts and GitHub Actions assemble the kernel artifacts and Alpine-based root filesystems, with Termux-oriented launch scripts for on-device testing. The stack targets mobile security and modding research where analysts need a rooted Android environment without elevating the host device, including workflows that depend on real kernel modules and root-style tooling.
