Droid-vm betreibt einen vollständigen Android-Gast mit echtem Magisk, KernelSU (LKM) oder KernelPatch (KPM) auf unveränderten, nicht gerooteten arm64-Handys, indem ein echter Linux-Kernel als User Mode Linux (UML)-Prozess gestartet wird, statt Container oder QEMU zu nutzen. Es baut auf einem Android-GKI-basierten arm64-UML-Port mit SMP, ext4/qcow2-Root-Disks, Binder sowie optionalem Framebuffer und virtio-gpu auf und schichtet Kernel-Konfigurationen für Modul-Laden, kprobes und Magisk-freundliche Funktionen. Shell-Skripte und GitHub Actions bauen die Kernel-Artefakte und Alpine-basierte Root-Dateisysteme zusammen, mit Termux-orientierten Startskripten für Tests auf dem Gerät. Der Stack zielt auf mobile Sicherheit und Modding-Forschung, wo Analysten eine gerootete Android-Umgebung brauchen, ohne das Host-Gerät zu privilegieren, einschließlich Workflows mit echten Kernelmodulen und Root-ähnlichen Tools.
