Droid-vm запускает полноценного гостя Android с настоящими Magisk, KernelSU (LKM) или KernelPatch (KPM) на штатных нерутованных arm64-телефонах, загружая подлинное ядро Linux как процесс User Mode Linux (UML), а не через контейнеры или QEMU. Основа — порт UML arm64 на базе Android GKI с SMP, корневыми дисками ext4/qcow2, binder и опциональной поддержкой framebuffer и virtio-gpu, с наслоением конфигураций ядра для загрузки модулей, kprobes и возможностей, удобных для Magisk. Shell-скрипты и GitHub Actions собирают артефакты ядра и корневые файловые системы на базе Alpine, с launch-скриптами под Termux для тестов на устройстве. Стек ориентирован на мобильную безопасность и исследования моддинга, когда аналитикам нужна рутованная среда Android без повышения привилегий хоста, включая сценарии с реальными модулями ядра и инструментами в духе root.
