Droid-vm 在未 root 的 stock arm64 手机上，通过将真正的 Linux 内核以 User Mode Linux（UML）进程方式启动，而非使用容器或 QEMU，运行配备真实 Magisk、KernelSU（LKM）或 KernelPatch（KPM）的完整 Android 客户机。它基于面向 Android 的 GKI arm64 UML 移植，支持 SMP、ext4/qcow2 根磁盘、binder，以及可选的 framebuffer 与 virtio-gpu，并叠加面向模块加载、kprobes 及 Magisk 友好特性的内核配置。Shell 脚本与 GitHub Actions 组装内核产物与基于 Alpine 的根文件系统，并提供面向 Termux 的启动脚本以便在设备上测试。该栈面向移动安全与 mod 研究：分析人员需要已 root 的 Android 环境却不必提升宿主设备权限，包括依赖真实内核模块与 root 类工具的工作流。
