AxManagerD 是一款無需 root 的 Android 模組化擴充框架，提供類似 Magisk 的模組載入能力，無須 root、解鎖 bootloader 或修改系統分割區。它主要以 Kotlin 和 Java 建構，並包含原生 C++ 元件，支援可安裝模組、具感測器觸發的執行時期守護程序、屬性注入、開機腳本，以及基於 LSPatch 的 Xposed 掛鉤以在執行時期修改應用。透過 Dhizuku 或 Shizuku 可選啟用 Device Owner，新增系統層級的應用隱藏、暫停、權限控制及相關管理功能。腳本追蹤與整合 AI 助手可協助稽核與開發模組行為。面向希望深度自訂與掛鉤、同時避開銀行與遊戲應用常用的傳統 root 偵測的 Android 玩機者、開發者與安全研究人員。
