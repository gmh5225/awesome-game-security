AxManagerD は、root 不要の Android 向けモジュラー拡張フレームワークで、root 化やブートローダーアンロック、システムパーティションの改変なしに、Magisk 形式のモジュール読み込みを提供します。主に Kotlin と Java で構築され、ネイティブ C++ コンポーネントも含み、インストール可能なモジュール、センサー駆動のランタイムデーモン、プロパティ注入、ブートスクリプト、LSPatch ベースの Xposed フックによるアプリのランタイム改変をサポートします。Dhizuku または Shizuku 経由の Device Owner 有効化（任意）により、アプリの非表示、一時停止、権限制御などのシステムレベル管理機能を追加できます。スクリプトトレースと統合 AI アシスタントがモジュール動作の監査・開発を支援します。Android の改造者、開発者、セキュリティ研究者向けで、銀行やゲームアプリが用いる従来の root 検出を回避しつつ、深いカスタマイズとフックを実現できます。
