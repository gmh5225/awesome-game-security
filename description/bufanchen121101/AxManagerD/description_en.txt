AxManagerD is a root-free modular extension framework for Android that provides Magisk-style module loading without rooting, unlocking the bootloader, or modifying system partitions. Built primarily in Kotlin and Java with native C++ components, it supports installable modules, runtime daemons with sensor-based triggers, property injection, boot scripts, and LSPatch-based Xposed hooking for runtime app modification. Optional Device Owner activation through Dhizuku or Shizuku adds system-level app hiding, suspension, permission control, and related management features. Script tracing and an integrated AI assistant help audit and develop module behavior. It is aimed at Android modders, developers, and security researchers who want deep customization and hooking while avoiding traditional root detection used by banking and gaming applications.
