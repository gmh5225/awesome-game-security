AxManagerD — это модульный фреймворк расширений для Android без root, обеспечивающий загрузку модулей в стиле Magisk без root, разблокировки загрузчика и изменения системных разделов. Создан в основном на Kotlin и Java с нативными компонентами на C++; поддерживает устанавливаемые модули, демоны времени выполнения с триггерами на основе датчиков, инъекцию свойств, загрузочные скрипты и Xposed-хукинг на базе LSPatch для изменения приложений на лету. Опциональная активация Device Owner через Dhizuku или Shizuku добавляет скрытие и приостановку приложений, контроль разрешений и другие функции управления на системном уровне. Трассировка скриптов и встроенный ИИ-помощник помогают аудиту и разработке поведения модулей. Предназначен для моддеров Android, разработчиков и исследователей безопасности, которым нужна глубокая настройка и хукинг без традиционного обнаружения root, используемого банковскими и игровыми приложениями.
