AxManagerD 是一款无需 root 的 Android 模块化扩展框架，提供类似 Magisk 的模块加载能力，无需 root、解锁 bootloader 或修改系统分区。它主要使用 Kotlin 和 Java 构建，并包含原生 C++ 组件，支持可安装模块、带传感器触发的运行时守护进程、属性注入、启动脚本，以及基于 LSPatch 的 Xposed 挂钩以在运行时修改应用。通过 Dhizuku 或 Shizuku 可选激活 Device Owner，可添加系统级应用隐藏、挂起、权限控制及相关管理功能。脚本追踪和集成 AI 助手可帮助审计与开发模块行为。面向希望实现深度定制与挂钩、同时规避银行与游戏应用常用的传统 root 检测的 Android 玩机者、开发者与安全研究人员。
