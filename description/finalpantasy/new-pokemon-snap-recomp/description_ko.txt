이 프로젝트는 런타임 에뮬레이터 대신 사전 정적 재컴파일을 통해 New Pokémon Snap의 네이티브 Windows 포팅을 제공하며, Switch 게임의 AArch64 기계어를 C로 승격시켜 독립 실행형 x86-64 실행 파일로 링크한다. 스택은 주로 C++와 Python 도구로 구축되며, 생성된 코드 컴파일에 LLVM과 clang을 사용하고, 수작업 Horizon OS 고수준 에뮬레이션 계층과 셰이더 번역 및 DLSS·FSR 같은 선택적 업스케일러를 갖춘 NVN-to-Vulkan 그래픽 브리지를 둔다. 개발은 Ghidra 기반 바이너리 분석, 결정적 함수 맵, Unicorn 대비 명령 차분 퍼징, CPU·그래픽·오디오·세이브·게임플레이 정확성을 검증하는 광범위한 자동화 루트 테스트에 의존한다. 모드 로딩, 게임 내 PC 설정, Nintendo Switch 바이너리 번역·콘솔 GPU API 셰임·리호스팅 기법을 연구하는 리버스 엔지니어와 포터를 위한 문서도 제공하여 보안 연구와 플랫폼 구축에 활용한다.
