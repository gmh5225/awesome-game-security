Этот проект — нативный порт New Pokémon Snap под Windows, созданный статической опережающей перекомпиляцией, а не рантайм-эмулятором: машинный код AArch64 игры для Switch поднимается в C и линкуется в автономный исполняемый файл x86-64. Стек в основном на C++ с инструментами на Python, для компиляции сгенерированного кода используются LLVM и clang, рукописный слой высокоуровневой эмуляции Horizon OS и графический мост NVN-to-Vulkan с переводом шейдеров и опциональными апскейлерами вроде DLSS и FSR. Разработка опирается на бинарный анализ в Ghidra, детерминированные карты функций, дифференциальный фаззинг инструкций против Unicorn и обширные автоматизированные маршрутные тесты для проверки CPU, графики, аудио, сохранений и корректности геймплея. Также есть загрузка модов, внутриигровые настройки ПК и документация для реверс-инженеров и портеров, изучающих бинарный перевод Nintendo Switch, подмену консольных GPU API и техники рехостинга для исследований безопасности и развёртывания платформ.
