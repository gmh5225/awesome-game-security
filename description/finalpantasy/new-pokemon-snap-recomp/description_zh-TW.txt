本專案透過提前靜態重編譯而非執行時模擬器，將《新寶可夢隨拍》移植為原生 Windows 版本，將 Switch 遊戲的 AArch64 機器碼提升為 C 程式碼並連結成獨立的 x86-64 可執行檔。技術堆疊主要以 C++ 與 Python 工具建構，使用 LLVM 與 clang 編譯產生程式碼，並搭配手寫的 Horizon OS 高階模擬層，以及 NVN 至 Vulkan 的圖形橋接（含著色器翻譯與可選的 DLSS、FSR 等升頻技術）。開發依賴以 Ghidra 為基礎的二進位分析、決定性函式對照、相對 Unicorn 的指令差分模糊測試，以及大量自動化路線測試，以驗證 CPU、圖形、音訊、存檔與玩法正確性。專案另提供模組載入、遊戲內 PC 設定，以及面向逆向工程師與移植者的文件，供研究 Nintendo Switch 二進位翻譯、主機 GPU API 墊片與重宿主技術於安全研究與平台移植之用。
