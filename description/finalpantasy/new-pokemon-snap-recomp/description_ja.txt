本プロジェクトは、ランタイムエミュレータではなく事前静的再コンパイルにより New Pokémon Snap のネイティブ Windows 移植版を実現し、Switch 版の AArch64 機械語を C にリフトして単体の x86-64 実行ファイルにリンクする。スタックは主に C++ と Python ツールで構築され、生成コードのコンパイルに LLVM と clang を用い、手書きの Horizon OS 高レベルエミュレーション層、シェーダ翻訳と DLSS や FSR などの任意アップスケーラを備えた NVN から Vulkan へのグラフィックスブリッジを組み合わせる。開発は Ghidra ベースのバイナリ解析、決定的関数マップ、Unicorn に対する命令差分ファジング、および CPU・グラフィックス・オーディオ・セーブ・ゲームプレイの正確性を検証する大規模な自動ルートテストに依存する。モッド読み込み、ゲーム内 PC 設定、Nintendo Switch バイナリ翻訳・コンソール GPU API シム・リホスト手法を研究するリバースエンジニアやポーター向けのドキュメントも提供し、セキュリティ研究やプラットフォーム立ち上げに役立てる。
