This project is a native Windows port of New Pokémon Snap produced by ahead-of-time static recompilation rather than a runtime emulator, lifting the Switch game’s AArch64 machine code to C and linking it into a standalone x86-64 executable. The stack is built mainly in C++ with Python tooling, using LLVM and clang to compile the generated code, a hand-written Horizon OS high-level emulation layer, and an NVN-to-Vulkan graphics bridge with shader translation and optional upscalers such as DLSS and FSR. Development relies on Ghidra-based binary analysis, deterministic function maps, instruction differential fuzzing against Unicorn, and extensive automated route tests to validate CPU, graphics, audio, saves, and gameplay correctness. It also provides mod loading, in-game PC settings, and documentation aimed at reverse engineers and porters studying Nintendo Switch binary translation, console GPU API shimming, and rehosting techniques for security research and platform bring-up.
