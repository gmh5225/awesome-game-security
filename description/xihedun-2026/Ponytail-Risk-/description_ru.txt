Ponytail Risk — это платформа с открытым исходным кодом для поведенческого контроля рисков и проверки доказательств на частных игровых серверах. Она в основном написана на Rust с веб-слоем управления на Node.js и объединяет в одной консоли анализ баз данных только для чтения, события игровых плагинов в реальном времени, отслеживание происхождения активов, оценку по правилам и расследование с помощью ИИ. Локальный агент риска принимает авторитетные события плагинов через SDK с C ABI (DLL для Windows и разделяемая библиотека для Linux), а движок на Rust выполняет извлечение данных и оценку правил с сохранением в SQLite, идемпотентной дедупликацией и очередями повторных попыток. Платформа по умолчанию поддерживает теневой режим, оставляя баны, списания и изменения базы данных за человеческой проверкой, а не за автоматическим применением. Она ориентирована на операторов игр и команды безопасности, которым нужны обнаружение читов, анализ мошенничества и рабочие процессы проверки дел без прямой привязки ИИ или статистики к карательным действиям.
