Ponytail Risk は、プライベートゲームサーバー向けのオープンソースの行動リスク管理および証拠レビュープラットフォームです。主に Rust で構築され、Node.js の Web 制御層を備え、読み取り専用データベース分析、リアルタイムのゲームプラグインイベント、資産の来歴追跡、ルールベースのスコアリング、AI 支援調査を単一コンソールに統合します。ローカルのリスクエージェントは C ABI SDK（Windows DLL および Linux 共有ライブラリ）を通じて権威あるプラグインイベントを取り込み、Rust エンジンは SQLite による永続化、冪等な重複排除、リトライキューを備えたデータ抽出とルール評価を担当します。プラットフォームはデフォルトでシャドウモードをサポートし、BAN、減点、データベース変更を自動執行ではなく人間によるレビューの背後に置きます。AI や統計を直接罰則アクションに結び付けず、チート検知、不正分析、ケースレビューのワークフローが必要なゲーム運営者とセキュリティチームを対象としています。
