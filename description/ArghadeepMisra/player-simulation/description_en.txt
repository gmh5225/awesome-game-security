Fairplay Telemetry is a Maven multi-module Java stack for real-time anti-cheat analysis over high-volume gameplay telemetry. A simulator generates thousands of match events per second for a large synthetic player population, including seeded cheaters, and publishes them to Kafka alongside manifests and ground truth for honest evaluation. A Kafka Streams detector running in replicated instances applies hopping-window rules to flag aimbots and speedhacks, emits scored evidence, and tracks per-player sequence integrity to demonstrate exactly-once processing under failure. An optional verifier compares detection results and stream counts against the simulator output, with Docker Compose, Prometheus, and Grafana for local benchmarking and chaos testing. It targets game security engineers and researchers who need an end-to-end pipeline to prototype, measure, and validate streaming cheat detection before tying it into a live game platform.
