Fairplay Telemetry は、大量のゲームプレイテレメトリに対するリアルタイム不正対策分析向けの Maven マルチモジュール Java スタックです。シミュレータは大規模な合成プレイヤー集団（シード付きチーターを含む）向けに毎秒数千件のマッチイベントを生成し、マニフェストおよび正直な評価用のグラウンドトゥルースとともに Kafka へ配信します。レプリカインスタンス上で動作する Kafka Streams 検出器はホッピングウィンドウルールを適用してエイムボットやスピードハックをフラグ付けし、スコア付き証拠を出力し、プレイヤーごとのシーケンス整合性を追跡して、障害時でも exactly-once 処理を実証します。オプションの検証器は検出結果とストリーム件数をシミュレータ出力と照合し、Docker Compose、Prometheus、Grafana によりローカルベンチマークとカオステストが可能です。本番ゲームプラットフォームに組み込む前に、ストリーミング不正検出をプロトタイプ化・計測・検証するエンドツーエンドパイプラインが必要なゲームセキュリティエンジニアと研究者向けです。
