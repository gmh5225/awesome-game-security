Fairplay Telemetry — многомодульный стек Java на Maven для анализа античита в реальном времени по высокообъёмной игровой телеметрии. Симулятор генерирует тысячи событий матчей в секунду для большой синтетической популяции игроков, включая заранее заданных читеров, и публикует их в Kafka вместе с манифестами и эталонной разметкой для честной оценки. Детектор на Kafka Streams в реплицированных экземплярах применяет правила со скользящими окнами, чтобы помечать аимботы и спидхаки, выдавать оценённые доказательства и отслеживать целостность последовательностей по игрокам, демонстрируя семантику exactly-once при сбоях. Опциональный верификатор сравнивает результаты детекции и счётчики потоков с выводом симулятора; Docker Compose, Prometheus и Grafana служат для локального бенчмаркинга и хаос-тестов. Проект ориентирован на инженеров по безопасности игр и исследователей, которым нужен сквозной конвейер для прототипирования, измерения и проверки потоковой детекции читов до интеграции в живую игровую платформу.
