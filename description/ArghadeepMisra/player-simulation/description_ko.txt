Fairplay Telemetry는 대용량 게임플레이 원격 측정에 대한 실시간 치트 방지 분석을 위한 Maven 멀티 모듈 Java 스택입니다. 시뮬레이터는 대규모 합성 플레이어 집단(시드된 치터 포함)에 대해 초당 수천 건의 매치 이벤트를 생성하고, 매니페스트 및 공정한 평가용 그라운드 트루스와 함께 Kafka로 게시합니다. 복제 인스턴스에서 실행되는 Kafka Streams 탐지기는 홉핑 윈도우 규칙을 적용해 에임봇과 스피드핵을 표시하고, 점수화된 증거를 내보내며, 플레이어별 시퀀스 무결성을 추적해 장애 상황에서 exactly-once 처리를 입증합니다. 선택적 검증기는 탐지 결과와 스트림 카운트를 시뮬레이터 출력과 비교하며, Docker Compose, Prometheus, Grafana로 로컬 벤치마킹과 카오스 테스트를 지원합니다. 라이브 게임 플랫폼에 연동하기 전에 스트리밍 치트 탐지를 프로토타이핑·측정·검증할 수 있는 엔드투엔드 파이프라인이 필요한 게임 보안 엔지니어와 연구자를 대상으로 합니다.
