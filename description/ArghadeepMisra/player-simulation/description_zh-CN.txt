Fairplay Telemetry 是一套基于 Maven 多模块的 Java 技术栈，用于对高吞吐量游戏遥测数据进行实时反作弊分析。模拟器为大规模合成玩家群体（含预设作弊者）每秒生成数千场对局事件，并将事件连同清单与用于客观评估的真实标签发布到 Kafka。在多个副本实例上运行的 Kafka Streams 检测器采用跳跃窗口规则标记自瞄与加速外挂，输出评分证据，并跟踪每位玩家的序列完整性，以在故障场景下演示恰好一次（exactly-once）处理。可选验证器将检测结果与流计数和模拟器输出进行比对；Docker Compose、Prometheus 与 Grafana 支持本地基准测试与混沌测试。面向需要在接入线上游戏平台之前，对流式作弊检测进行原型设计、度量与端到端验证的游戏安全工程师与研究人员。
