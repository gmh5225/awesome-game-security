Fairplay Arena es una API REST sin estado que actúa como fuente de verdad de una plataforma de juego antitrampas, cubriendo cuentas de jugadores, partidas registradas, clasificaciones globales, aplicación de normas por moderadores y recursos contra prohibiciones. Está implementada en Java 21 con Spring Boot y expone endpoints protegidos con JWT para jugadores, moderadores y clientes de servicio de confianza, incluidos jueces automatizados que deben cumplir umbrales de confianza antes de aplicar prohibiciones. PostgreSQL almacena el estado durable y un registro de auditoría solo de anexado impuesto en la capa de base de datos para acciones de moderación, mientras que los conjuntos ordenados de Redis impulsan consultas rápidas de clasificación y rango que superan con creces el conteo SQL puro a escala. La pila incluye Docker Compose, migraciones Flyway, documentación OpenAPI, métricas Prometheus y benchmarks de carga con k6. Está dirigida a desarrolladores que construyen o estudian backends de integridad de juegos y necesitan patrones de estilo producción para máquinas de estados de cuenta, ingesta idempotente de partidas, seguridad de tokens de actualización y flujos de aplicación antitrampas con intervención humana.
