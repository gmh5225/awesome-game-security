Fairplay Arena is a stateless REST API that serves as the source of truth for an anti-cheat gaming platform, covering player accounts, recorded matches, global rankings, moderator enforcement, and ban appeals. It is implemented in Java 21 with Spring Boot and exposes JWT-protected endpoints for players, moderators, and trusted service clients, including automated judges that must meet confidence thresholds before applying bans. PostgreSQL holds durable state and an append-only audit trail enforced at the database layer for moderation actions, while Redis sorted sets power fast leaderboard and rank lookups that significantly outperform pure SQL counting at scale. The stack ships with Docker Compose, Flyway migrations, OpenAPI documentation, Prometheus metrics, and load benchmarks using k6. It targets developers building or studying game integrity backends who need production-style patterns for account state machines, idempotent match ingestion, refresh-token security, and human-in-the-loop cheat enforcement workflows.
