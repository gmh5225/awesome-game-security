Fairplay Arena è un’API REST senza stato che funge da fonte di verità per una piattaforma di gioco anti-cheat, coprendo account giocatori, partite registrate, classifiche globali, azioni dei moderatori e ricorsi contro i ban. È implementata in Java 21 con Spring Boot ed espone endpoint protetti da JWT per giocatori, moderatori e client di servizio affidabili, inclusi giudici automatizzati che devono raggiungere soglie di confidenza prima di applicare i ban. PostgreSQL conserva lo stato persistente e una traccia di audit append-only imposta a livello database per le azioni di moderazione, mentre i sorted set di Redis abilitano ricerche rapide di classifica che superano di gran lunga il conteggio SQL puro su larga scala. Lo stack include Docker Compose, migrazioni Flyway, documentazione OpenAPI, metriche Prometheus e benchmark di carico con k6. È rivolta a sviluppatori che costruiscono o studiano backend di integrità di gioco e necessitano di pattern in stile produzione per macchine a stati degli account, ingestione idempotente delle partite, sicurezza dei refresh token e flussi di enforcement anti-cheat con intervento umano.
