Fairplay Arena — это REST API без сохранения состояния, выступающая единым источником истины для античит-платформы: учётные записи игроков, записанные матчи, глобальные рейтинги, действия модераторов и апелляции на баны. Реализована на Java 21 и Spring Boot; предоставляет защищённые JWT конечные точки для игроков, модераторов и доверенных сервисных клиентов, включая автоматизированных «судей», которые должны достигать порогов уверенности перед наложением банов. PostgreSQL хранит долговременное состояние и только дополняемый аудит, принудительно обеспечиваемый на уровне БД для модерационных действий; отсортированные множества Redis обеспечивают быстрый доступ к таблицам лидеров и рангам, значительно превосходя чистый подсчёт в SQL в масштабе. Стек включает Docker Compose, миграции Flyway, документацию OpenAPI, метрики Prometheus и нагрузочные тесты на k6. Ориентирован на разработчиков, которые создают или изучают бэкенды игровой целостности и нуждаются в production-подходах к конечным автоматам аккаунтов, идемпотентному приёму матчей, безопасности refresh-токенов и рабочим процессам античита с участием человека.
