Fairplay Arena 是一個無狀態的 REST API，作為反作弊遊戲平台的事實來源，涵蓋玩家帳號、對局紀錄、全球排行榜、版主執法與封禁申訴。專案以 Java 21 與 Spring Boot 實作，為玩家、版主及受信任的服務客戶端（含須達到置信度閾值方可執行封禁的自動化裁判）提供 JWT 保護的端點。PostgreSQL 儲存持久狀態，並在資料庫層為版主操作維護僅追加的稽核軌跡；Redis 有序集合支撐快速的排行榜與名次查詢，在大規模下顯著優於純 SQL 計數。技術棧包含 Docker Compose、Flyway 遷移、OpenAPI 文件、Prometheus 指標以及基於 k6 的壓力測試。面向需要生產級帳號狀態機、冪等對局入庫、重新整理權杖安全與人機協作作弊執法流程模式的遊戲完整性後端開發者與學習用途。
