Fairplay Arena는 플레이어 계정, 기록된 경기, 글로벌 순위, 모더레이터 집행, 밴 이의 신청을 포괄하는 안티치트 게임 플랫폼의 단일 진실 공급원 역할을 하는 무상태 REST API입니다. Java 21과 Spring Boot로 구현되었으며, 플레이어·모더레이터·신뢰할 수 있는 서비스 클라이언트를 위해 JWT로 보호된 엔드포인트를 제공하고, 밴 적용 전 신뢰도 임계값을 충족해야 하는 자동 판정기도 포함합니다. PostgreSQL은 영구 상태와 모더레이션 조치에 대해 데이터베이스 계층에서 강제되는 추가 전용 감사 추적을 보관하며, Redis 정렬 집합은 빠른 리더보드 및 순위 조회를 지원하여 대규모에서 순수 SQL 카운팅보다 훨씬 우수합니다. 스택에는 Docker Compose, Flyway 마이그레이션, OpenAPI 문서, Prometheus 메트릭, k6 기반 부하 벤치마크가 포함됩니다. 계정 상태 머신, 멱등한 경기 수집, 리프레시 토큰 보안, 사람이 개입하는 치트 집행 워크플로에 대한 프로덕션 스타일 패턴이 필요한 게임 무결성 백엔드 구축 또는 연구 개발자를 대상으로 합니다.
