Fairplay Arena est une API REST sans état qui sert de source de vérité pour une plateforme de jeu anti-triche, couvrant les comptes joueurs, les matchs enregistrés, les classements mondiaux, l’application des règles par les modérateurs et les recours contre les bannissements. Elle est implémentée en Java 21 avec Spring Boot et expose des points de terminaison protégés par JWT pour les joueurs, les modérateurs et les clients de service de confiance, y compris des juges automatisés qui doivent atteindre des seuils de confiance avant d’appliquer des bannissements. PostgreSQL conserve l’état durable et une piste d’audit en append-only imposée au niveau base de données pour les actions de modération, tandis que les ensembles triés Redis alimentent des recherches rapides de classement qui surpassent nettement le comptage SQL pur à grande échelle. La pile inclut Docker Compose, les migrations Flyway, la documentation OpenAPI, les métriques Prometheus et des benchmarks de charge avec k6. Elle s’adresse aux développeurs qui construisent ou étudient des backends d’intégrité de jeu et ont besoin de schémas de type production pour les machines à états de compte, l’ingestion idempotente des matchs, la sécurité des jetons de rafraîchissement et les flux d’application anti-triche avec intervention humaine.
