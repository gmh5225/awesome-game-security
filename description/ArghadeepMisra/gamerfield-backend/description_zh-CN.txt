Fairplay Arena 是一个无状态的 REST API，作为反作弊游戏平台的事实来源，涵盖玩家账号、对局记录、全球排行榜、版主执法与封禁申诉。项目基于 Java 21 与 Spring Boot 实现，为玩家、版主及受信任的服务客户端（含须达到置信度阈值方可执行封禁的自动化裁判）提供 JWT 保护的端点。PostgreSQL 存储持久状态，并在数据库层为版主操作维护仅追加的审计日志；Redis 有序集合支撑快速的排行榜与名次查询，在大规模下显著优于纯 SQL 计数。技术栈包含 Docker Compose、Flyway 迁移、OpenAPI 文档、Prometheus 指标以及基于 k6 的压测。面向需要生产级账号状态机、幂等对局入库、刷新令牌安全与人机协同作弊执法流程模式的游戏完整性后端开发者与学习用途。
