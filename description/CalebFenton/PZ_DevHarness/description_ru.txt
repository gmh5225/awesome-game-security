PZ_DevHarness — автоматизированный тестовый каркас, который запускает тесты модов Project Zomboid Build 42 в реальной игре без участия человека за клавиатурой: одна команда и коды выхода pass/fail, подходящие для CI. Тесты — короткие Lua-скрипты, ставящие в очередь действия с таймингом как у игрока и проверяющие результат после выполнения; сильная изоляция за счёт сброса перед каждым тестом, записанных отмен и проверок утечек в мире вокруг персонажа. Bash-скрипты оркестрируют отладочные запуски в изолированных одноразовых профилях, небольшие Java-лаунчеры поднимают клиент и выделенный сервер in-process и через reflection автоматически закрывают экран загрузки и ускоряют старт без патча игровых файлов. Поддерживаются одиночная игра и локальный мультиплеер на dedicated-сервере, включая помощники для согласования состояния клиента и сервера, отчёты DESYNC при расхождении тайлов и скрипты проверки нагрузки сервера. Основная аудитория — разработчики модов, которым нужны быстрые, повторяемые интеграционные тесты в игре вместо ручного прохода по vanilla debug unit-test меню.
