PZ_DevHarness è un harness di test automatizzato che esegue test di mod di Project Zomboid Build 42 nel gioco reale, senza nessuno alla tastiera, con un solo comando e codici di uscita pass/fail adatti alla CI. I test sono brevi script Lua che accodano azioni temporizzate simili al giocatore e verificano gli esiti in seguito, con forte isolamento tramite reset per test, undo registrati e controlli di leak sul mondo intorno al personaggio. Script Bash orchestrano avvii in debug su profili usa e getta isolati, mentre piccoli launcher Java avviano client e server dedicato in-process e usano la reflection per chiudere automaticamente la schermata di caricamento e accelerare l’avvio senza patchare i file di gioco. Copre single-player e multiplayer con server dedicato locale, inclusi helper per allineare lo stato client e server, report DESYNC quando le tile non coincidono e script di validazione del carico server. Il pubblico principale sono gli sviluppatori di mod che vogliono test di integrazione in gioco rapidi e ripetibili invece di cliccare nei menu dei test unitari debug vanilla.
