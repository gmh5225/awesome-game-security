PZ_DevHarness is an automated testing harness that runs Project Zomboid Build 42 mod tests inside the real game with no one at the keyboard, from one command through pass-or-fail exit codes suited to CI. Tests are short Lua scripts that queue player-like timed actions and check outcomes afterward, with strong isolation via per-test resets, recorded undos, and leak checks on the world around the character. Bash scripts orchestrate debug launches in isolated throwaway profiles, while small Java launchers start the client and dedicated server in-process and use reflection to auto-dismiss the loading screen and accelerate startup without patching game files. It covers single-player and local dedicated-server multiplayer, including helpers that keep client and server state aligned, DESYNC reporting when tiles disagree, and server-load validation scripts. The primary audience is mod developers who want fast, repeatable in-game integration tests instead of clicking through the vanilla debug unit-test menus.
