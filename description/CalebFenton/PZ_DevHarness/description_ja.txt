PZ_DevHarness は、Project Zomboid Build 42 の mod テストを実際のゲーム内でキーボード操作なしに自動実行するテストハーネスです。1 コマンドで実行でき、CI 向けの pass/fail 終了コードを返します。テストは短い Lua スクリプトで、プレイヤー風のタイムドアクションをキューに積み、後から結果を検証します。テストごとのリセット、記録された undo、キャラクター周辺ワールドのリークチェックにより強い隔離を実現します。Bash スクリプトが隔離された使い捨てプロファイルでのデバッグ起動を制御し、小さな Java ランチャーがクライアントと専用サーバーを同一プロセス内で起動し、リフレクションでローディング画面を自動で閉じ、ゲームファイルをパッチせずに起動を高速化します。シングルプレイヤーとローカル専用サーバーのマルチプレイに対応し、クライアントとサーバーの状態を揃えるヘルパー、タイル不一致時の DESYNC レポート、サーバー負荷検証スクリプトを含みます。主な対象は、バニラのデバッグ単体テストメニューを手でクリックする代わりに、高速で再現可能なゲーム内統合テストを求める mod 開発者です。
