PZ_DevHarness est un harness de tests automatisés qui exécute des tests de mods Project Zomboid Build 42 dans le jeu réel, sans personne au clavier, en une seule commande avec des codes de sortie pass/fail adaptés à la CI. Les tests sont de courts scripts Lua qui mettent en file des actions temporisées façon joueur et vérifient les résultats ensuite, avec une isolation forte via des réinitialisations par test, des annulations enregistrées et des contrôles de fuites sur le monde autour du personnage. Des scripts Bash orchestrent les lancements debug dans des profils jetables isolés, tandis que de petits lanceurs Java démarrent le client et le serveur dédié in-process et utilisent la réflexion pour fermer automatiquement l’écran de chargement et accélérer le démarrage sans patcher les fichiers du jeu. Il couvre le solo et le multijoueur sur serveur dédié local, avec des aides pour aligner l’état client et serveur, des rapports DESYNC quand les tuiles divergent, et des scripts de validation de charge serveur. Le public visé est surtout les développeurs de mods qui veulent des tests d’intégration en jeu rapides et reproductibles plutôt que de cliquer dans les menus de tests unitaires debug vanilla.
