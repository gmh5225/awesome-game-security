PZ_DevHarness는 Project Zomboid Build 42 mod 테스트를 실제 게임 안에서 키보드 없이 자동으로 실행하는 테스트 하네스입니다. 한 번의 명령으로 실행하며 CI에 맞는 pass/fail 종료 코드를 반환합니다. 테스트는 짧은 Lua 스크립트로, 플레이어처럼 시간 기반 동작을 큐에 넣고 이후 결과를 검사합니다. 테스트마다 리셋, 기록된 undo, 캐릭터 주변 월드에 대한 leak 검사로 강한 격리를 제공합니다. Bash 스크립트는 격리된 일회용 프로필에서 디버그 실행을 조율하고, 소형 Java 런처는 클라이언트와 전용 서버를 프로세스 내에서 기동하며 리플렉션으로 로딩 화면을 자동으로 닫고 게임 파일을 패치하지 않고도 시작을 가속합니다. 싱글플레이어와 로컬 전용 서버 멀티플레이를 지원하며, 클라이언트와 서버 상태를 맞추는 헬퍼, 타일 불일치 시 DESYNC 보고, 서버 부하 검증 스크립트를 포함합니다. 주요 대상은 바닐라 디버그 단위 테스트 메뉴를 클릭하는 대신 빠르고 반복 가능한 게임 내 통합 테스트를 원하는 mod 개발자입니다.
