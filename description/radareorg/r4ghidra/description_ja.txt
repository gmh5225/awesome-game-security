R4Ghidra は Ghidra 拡張で、Radare2 と Ghidra を統合し、解析者が radare2 スタイルのコマンド環境から Ghidra の解析を操作できるようにします。プラグインは主に Java で実装され、Gradle で標準的な Ghidra モジュールとしてビルドされ、ヘッドレスワークフローやレガシーツール向けに Python と Ruby スクリプトが付属します。組み込み HTTP サーバーと完全な REPL コマンドシェルを提供し、seek、フラグ、コメント、解析、デコンパイル、スクリプトなど一般的な radare2 操作を専用コマンドハンドラ経由で Ghidra のプログラムデータベースにマッピングします。旧来の補助スクリプトは Ghidra デコンパイラ出力を radare2 プロジェクトへエクスポートし、両ツール間でシンボルとコメントを同期します。Ghidra のデコンパイラと UI と radare2 の自動化（ゲームやアンチチート研究を含む）を組み合わせたい逆アセンブルエンジニアとバイナリ解析者を対象としています。
