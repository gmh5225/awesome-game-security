R4Ghidra 是一款 Ghidra 扩展，将 Radare2 与 Ghidra 集成，使分析人员可通过 radare2 风格的命令环境驱动 Ghidra 的分析。该插件主要用 Java 实现，以 Gradle 构建为标准 Ghidra 模块，并辅以 Python 与 Ruby 脚本，用于无界面工作流和旧版工具链。它提供内嵌 HTTP 服务器和完整的 REPL 命令 shell，通过专用命令处理器将常见的 radare2 操作（定位、标志、注释、分析、反编译与脚本）映射到 Ghidra 的程序数据库。较早的配套脚本可将 Ghidra 反编译器输出导出到 radare2 项目，并在两款工具之间同步符号与注释。本项目面向希望结合 Ghidra 反编译器与界面以及 radare2 自动化能力的逆向工程师与二进制分析人员，包括游戏与反作弊研究场景。
