R4Ghidra est une extension Ghidra qui intègre Radare2 à Ghidra afin que les analystes puissent piloter l’analyse de Ghidra via un environnement de commandes de style radare2. Le plugin est principalement implémenté en Java et construit avec Gradle en tant que module Ghidra standard, avec des scripts Python et Ruby pour les flux headless et les outils hérités. Il expose un serveur HTTP intégré et un shell de commandes REPL complet, en mappant les opérations radare2 courantes—seek, flags, commentaires, analyse, décompilation et scripts—vers la base de programmes de Ghidra via des gestionnaires de commandes dédiés. D’anciens scripts compagnons exportent la sortie du décompilateur Ghidra vers des projets radare2 et synchronisent symboles et commentaires entre les deux outils. Le projet s’adresse aux ingénieurs en rétro-ingénierie et analystes binaires qui veulent combiner le décompilateur et l’interface de Ghidra avec l’automatisation radare2, y compris pour la recherche sur les jeux et l’anti-triche.
