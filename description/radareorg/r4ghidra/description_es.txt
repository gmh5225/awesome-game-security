R4Ghidra es una extensión de Ghidra que integra Radare2 con Ghidra para que los analistas puedan dirigir el análisis de Ghidra mediante un entorno de comandos al estilo radare2. El complemento está implementado principalmente en Java y se compila con Gradle como módulo estándar de Ghidra, con scripts de Python y Ruby para flujos headless y herramientas heredadas. Expone un servidor HTTP integrado y un shell de comandos REPL completo, mapeando operaciones habituales de radare2—seek, flags, comentarios, análisis, descompilación y scripts—a la base de programas de Ghidra mediante manejadores de comandos dedicados. Scripts complementarios más antiguos exportan la salida del descompilador de Ghidra a proyectos radare2 y sincronizan símbolos y comentarios entre ambas herramientas. El proyecto está dirigido a ingenieros inversos y analistas de binarios que quieren combinar el descompilador y la interfaz de Ghidra con la automatización de radare2, incluidos flujos de investigación de juegos y anti-cheat.
