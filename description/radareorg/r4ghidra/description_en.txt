R4Ghidra is a Ghidra extension that integrates Radare2 with Ghidra so analysts can drive Ghidra’s analysis through a radare2-style command environment. The plugin is implemented mainly in Java and built with Gradle as a standard Ghidra module, with supporting Python and Ruby scripts for headless workflows and legacy tooling. It exposes an embedded HTTP server and a full REPL command shell, mapping common radare2 operations—seeking, flags, comments, analysis, decompilation, and scripting—to Ghidra’s program database via dedicated command handlers. Older companion scripts export Ghidra decompiler output into radare2 projects and sync symbols and comments between the two tools. The project targets reverse engineers and binary analysts who want to combine Ghidra’s decompiler and UI with radare2 automation, including game and anti-cheat research workflows.
