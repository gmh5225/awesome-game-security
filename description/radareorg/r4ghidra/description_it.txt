R4Ghidra è un’estensione Ghidra che integra Radare2 con Ghidra così che gli analisti possano guidare l’analisi di Ghidra tramite un ambiente di comandi in stile radare2. Il plugin è implementato principalmente in Java e compilato con Gradle come modulo Ghidra standard, con script Python e Ruby per flussi headless e strumenti legacy. Espone un server HTTP incorporato e una shell REPL completa, mappando le operazioni radare2 comuni—seek, flag, commenti, analisi, decompilazione e scripting—al database dei programmi di Ghidra tramite handler di comando dedicati. Script companion più datati esportano l’output del decompilatore Ghidra in progetti radare2 e sincronizzano simboli e commenti tra i due strumenti. Il progetto è rivolto a reverse engineer e analisti di binari che vogliono combinare decompilatore e interfaccia di Ghidra con l’automazione radare2, inclusi flussi di ricerca su giochi e anti-cheat.
