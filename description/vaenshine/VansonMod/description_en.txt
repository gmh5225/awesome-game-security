VansonMod is an independent iOS debugging workstation and memory editor built for the TrollStore environment, operating externally without traditional tweak injection so many workflows remain available on non-jailbroken devices. Written primarily in Objective-C++ and C++ with Theos, it provides process selection, memory search and hex editing, pointer chain analysis and verification, signature scanning, JavaScript-based scripting, and app archive management. On jailbroken devices it adds RVA patching with ARM64 instruction presets, hardware watchpoint monitoring, and deeper code-level debugging workflows. It is aimed at security researchers, reverse engineers, and developers learning iOS process and memory analysis for compliant technical testing.
