VansonMod는 TrollStore 환경을 위해 만들어진 독립형 iOS 디버깅 워크스테이션 및 메모리 편집기로, 기존 tweak 주입 없이 외부에서 동작하여 탈옥하지 않은 기기에서도 많은 워크플로를 사용할 수 있습니다. Objective-C++와 C++를 중심으로 Theos로 작성되었으며, 프로세스 선택, 메모리 검색 및 hex 편집, 포인터 체인 분석 및 검증, 시그니처 스캔, JavaScript 기반 스크립팅, 앱 아카이브 관리 기능을 제공합니다. 탈옥 기기에서는 ARM64 명령어 프리셋을 갖춘 RVA 패치, 하드웨어 watchpoint 모니터링, 더 깊은 코드 수준 디버깅 워크플로가 추가됩니다. 보안 연구자, 리버스 엔지니어, iOS 프로세스 및 메모리 분석을 배우고 규정을 준수한 기술 테스트를 수행하려는 개발자를 대상으로 합니다.
