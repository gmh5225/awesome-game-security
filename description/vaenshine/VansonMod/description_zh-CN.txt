VansonMod 是一款面向 TrollStore 环境的独立 iOS 调试工作站与内存编辑器，以外部方式运行、无需传统 tweak 注入，因此在未越狱设备上仍可使用多种工作流。项目主要使用 Objective-C++ 与 C++ 编写，基于 Theos 构建，提供进程选择、内存搜索与十六进制编辑、指针链分析与验证、特征码扫描、基于 JavaScript 的脚本以及应用归档管理等功能。在越狱设备上，它还支持带 ARM64 指令预设的 RVA 补丁、硬件 watchpoint 监控以及更深层的代码级调试流程。适用于安全研究人员、逆向工程师以及希望学习 iOS 进程与内存分析、进行合规技术测试的开发者。
