VansonMod 是一款獨立的 iOS 除錯工作站與記憶體編輯器，專為 TrollStore 環境打造，以外部方式運作、無需傳統 tweak 注入，因此在未越獄裝置上仍可使用許多工作流程。專案主要使用 Objective-C++ 與 C++ 編寫，基於 Theos 建構，提供程序選擇、記憶體搜尋與十六進位編輯、指標鏈分析與驗證、特徵碼掃描、基於 JavaScript 的腳本以及應用程式封存管理等功能。在越獄裝置上，它還支援帶 ARM64 指令預設的 RVA 修補、硬體 watchpoint 監控以及更深層的程式碼級除錯工作流程。該工具面向安全研究人員、逆向工程師以及希望學習 iOS 程序與記憶體分析以進行合規技術測試的開發者。
