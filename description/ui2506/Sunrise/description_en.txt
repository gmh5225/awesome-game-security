Sunrise is a dedicated-server anti-cheat plugin for SCP: Secret Laboratory that restores server authority over combat, visibility, and interaction checks that the base game leaves client-trusted. Written in C#, it loads through LabAPI and applies Harmony patches to replace latency backtrack with server-side position and rotation history, implement room-based and raycast anti-wallhack, validate item pickups and door interactions, and enforce server-side Tesla gate damage. It also ships modular detections, movement anti-cheat, and patches for common SCP-related exploits such as silent aim, spinbot, wallhack, pickup-through-walls, and Tesla immunity. The project targets server owners and game-security practitioners who need a practical, maintainable anti-cheat for SCP:SL rather than a generic cheat client or reverse-engineering toolkit.
