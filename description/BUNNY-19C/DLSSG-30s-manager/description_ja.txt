DLSSG 30-Series Manager は、dlssg_for_sm86 DLL プロキシ mod のデプロイと管理を行い、RTX 30 シリーズ GPU で DLSS フレーム生成を有効にする Windows デスクトップアプリケーションです。C# と WPF を .NET 8 上で使用して構築され、Steam ライブラリやカスタムフォルダをスキャンして nvngx_dlssg.dll を同梱するゲームを検出し、ゲームごとの INI 設定、ワンクリックでのデプロイと復元、Authenticode 署名と SHA-256 ハッシュで検証されるオンデマンド mod ダウンロードに対応します。Easy Anti-Cheat、BattlEye、Riot Vanguard、Tencent ACE、NetEase NEAC、HoYoKProtect などの類似システムに対し、ファイル名とディレクトリのフィンガープリントによる広範なカーネルアンチチート検出を実装し、保護されたタイトルへのデプロイをブロックし、アンチチートによる傍受後に残された隔離プロキシ DLL を識別します。安全なファイル処理には、デジタル署名の所有権チェック、復元時のハッシュ検証、置き換えられた非 mod ファイルのバックアップが含まれます。Ampere ハードウェアで DLSS フレーム生成を有効にする PC ゲーマーと、カーネルアンチチートが DLL プロキシ注入をどのように検出・隔離するかを研究するゲームセキュリティ研究者を対象としています。
