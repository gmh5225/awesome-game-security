DLSSG 30-Series Manager is a Windows desktop application that deploys and manages the dlssg_for_sm86 DLL proxy mod to enable DLSS frame generation on RTX 30-series GPUs. Built with C# and WPF on .NET 8, it scans Steam libraries and custom folders for games shipping nvngx_dlssg.dll, supports per-game INI configuration, one-click deploy and restore, and on-demand mod downloads verified by Authenticode signatures and SHA-256 hashes. It implements extensive kernel anti-cheat detection through filename and directory fingerprinting for Easy Anti-Cheat, BattlEye, Riot Vanguard, Tencent ACE, NetEase NEAC, HoYoKProtect, and similar systems, blocking deployment to protected titles and identifying quarantined proxy DLLs left after anti-cheat interception. Safe file handling uses digital signature ownership checks, hash verification on restore, and backups of displaced non-mod files. It is intended for PC gamers enabling DLSS frame generation on Ampere hardware and for game security researchers studying how kernel anti-cheat detects and quarantines DLL proxy injection.
