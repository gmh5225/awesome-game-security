DLSSG 30-Series Manager — настольное приложение для Windows, которое развёртывает и управляет DLL-прокси-модом dlssg_for_sm86 для включения генерации кадров DLSS на GPU RTX 30-й серии. Создано на C# и WPF с использованием .NET 8, сканирует библиотеки Steam и пользовательские папки в поисках игр с nvngx_dlssg.dll, поддерживает INI-конфигурацию для каждой игры, развёртывание и восстановление в один клик, а также загрузку модов по запросу с проверкой подписей Authenticode и хешей SHA-256. Реализует расширенное обнаружение kernel anti-cheat по отпечаткам имён файлов и каталогов для Easy Anti-Cheat, BattlEye, Riot Vanguard, Tencent ACE, NetEase NEAC, HoYoKProtect и аналогичных систем, блокируя развёртывание на защищённых играх и выявляя помещённые в карантин прокси-DLL, оставшиеся после перехвата anti-cheat. Безопасная работа с файлами включает проверку владельца цифровой подписи, верификацию хешей при восстановлении и резервное копирование замещённых немодифицированных файлов. Предназначено для PC-геймеров, включающих генерацию кадров DLSS на аппаратуре Ampere, и для исследователей безопасности игр, изучающих, как kernel anti-cheat обнаруживает и помещает в карантин внедрение DLL-прокси.
