IDA PatchGen — это плагин для IDA Pro, написанный на Python, который экспортирует побайтовые правки, сделанные при интерактивном патчинге, в переиспользуемый код патчей. Запускается по Alt-F8: сканирует базу данных на предмет пропатченных байтов, группирует смежные изменения и выводит смещения в файле вместе с исходными и изменёнными значениями байтов. Для каждой группы патчей также показывается дизассемблирование затронутых инструкций и генерируются операторы C# SinglePatchHunk, подходящие для пользовательских бинарных патчеров. Инструмент предназначен для реверс-инженеров и исследователей безопасности игр, которые изменяют исполняемые файлы в IDA и должны превратить эти правки в автономную логику патчей.
