IDA PatchGen è un plugin per IDA Pro scritto in Python che esporta le modifiche a livello di byte effettuate durante il patching interattivo in codice patch riutilizzabile. Attivato con Alt-F8, analizza il database alla ricerca di byte patchati, raggruppa le modifiche contigue e stampa gli offset di file insieme ai valori dei byte originali e modificati. Per ogni gruppo di patch mostra anche il disassemblaggio delle istruzioni interessate ed emette istruzioni C# SinglePatchHunk adatte a patcher binari personalizzati. Lo strumento è rivolto a reverse engineer e ricercatori di sicurezza dei giochi che modificano eseguibili in IDA e devono trasformare quelle modifiche in logica di patch autonoma.
