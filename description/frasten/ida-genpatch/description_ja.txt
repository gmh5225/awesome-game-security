IDA PatchGen は Python で書かれた IDA Pro プラグインで、対話型パッチ適用中に行ったバイト単位の編集を再利用可能なパッチコードとしてエクスポートします。Alt-F8 で起動すると、データベース内のパッチ済みバイトを走査し、連続する変更をグループ化して、ファイルオフセットと元および変更後のバイト値を出力します。各パッチグループについて、影響を受けた命令の逆アセンブリも表示し、カスタムバイナリパッチャー向けの C# SinglePatchHunk ステートメントを生成します。このツールは、IDA 上で実行ファイルを改変し、その編集を独立したパッチロジックに変換する必要があるリバースエンジニアおよびゲームセキュリティ研究者を対象としています。
