IDA PatchGen es un complemento de IDA Pro escrito en Python que exporta las ediciones a nivel de bytes realizadas durante el parcheo interactivo como código de parche reutilizable. Activado con Alt-F8, escanea la base de datos en busca de bytes parcheados, agrupa los cambios contiguos e imprime los desplazamientos de archivo junto con los valores de bytes originales y modificados. Para cada grupo de parches, también muestra el desensamblado de las instrucciones afectadas y genera sentencias C# SinglePatchHunk aptas para parcheadores binarios personalizados. La herramienta está dirigida a ingenieros de ingeniería inversa e investigadores de seguridad de juegos que modifican ejecutables en IDA y necesitan convertir esas ediciones en lógica de parche independiente.
