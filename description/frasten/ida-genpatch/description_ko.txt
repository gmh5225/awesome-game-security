IDA PatchGen은 Python으로 작성된 IDA Pro 플러그인으로, 대화형 패치 작업 중 수행한 바이트 단위 편집을 재사용 가능한 패치 코드로 내보냅니다. Alt-F8로 실행하면 데이터베이스에서 패치된 바이트를 검색하고, 연속된 변경 사항을 그룹화하며, 파일 오프셋과 원본 및 수정된 바이트 값을 출력합니다. 각 패치 그룹에 대해 영향받은 명령어의 디스어셈블리도 표시하고, 사용자 정의 바이너리 패처에 적합한 C# SinglePatchHunk 문을 생성합니다. 이 도구는 IDA에서 실행 파일을 수정하고 해당 편집을 독립적인 패치 로직으로 변환해야 하는 리버스 엔지니어 및 게임 보안 연구자를 대상으로 합니다.
