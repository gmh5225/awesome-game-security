Ferret is a Linux desktop memory editor that helps you find and change in-game values such as health, gold, and ammo without learning traditional memory-scan workflows. Written in Rust with a GTK 4 and libadwaita GUI, it uses screen capture and OCR to read numbers you click in the game window, then narrows candidates as you play and can persist values across restarts via pointer paths and engine-specific browsing for Unreal, Unity, Godot, GameMaker, Java, Python, and other runtimes. A separate host helper performs ptrace-based read and write while the Flatpak UI stays sandboxed, and the tool blocks or warns on online titles by consulting local anti-cheat process checks and an embedded AreWeAntiCheatYet game list. It targets single-player and offline use on native Linux and Proton or Wine games, in the same practical space as Cheat Engine or GameConqueror for modding, testing, and studying how games store state.
