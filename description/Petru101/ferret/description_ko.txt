Ferret는 Linux 데스크톱 메모리 편집기로, 전통적인 메모리 스캔 워크플로를 익히지 않고도 체력, 골드, 탄약 같은 게임 내 수치를 찾아 바꿀 수 있습니다. Rust로 작성되었으며 GTK 4와 libadwaita GUI를 사용하고, 화면 캡처와 OCR로 게임 창에서 클릭한 숫자를 읽은 뒤 플레이하면서 후보를 좁혀 갑니다. 포인터 경로와 Unreal, Unity, Godot, GameMaker, Java, Python 등 런타임별 탐색으로 재시작 후에도 값을 유지할 수 있습니다. 별도의 호스트 헬퍼가 ptrace 기반 읽기·쓰기를 수행하고 Flatpak UI는 샌드박스 안에 머무릅니다. 로컬 안티치트 프로세스 검사와 내장 AreWeAntiCheatYet 게임 목록으로 온라인 타이틀은 차단하거나 경고합니다. 네이티브 Linux와 Proton·Wine 게임의 싱글플레이·오프라인 용도를 겨냥하며, 모딩·테스트·게임 상태 저장 방식 연구에 Cheat Engine이나 GameConqueror와 같은 실용 영역에 해당합니다.
