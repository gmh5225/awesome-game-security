Ferret 是一款 Linux 桌面内存编辑器，无需学习传统内存扫描流程即可查找并修改游戏中的生命值、金币、弹药等数值。它用 Rust 编写，采用 GTK 4 与 libadwaita 图形界面，通过屏幕截图与 OCR 读取你在游戏窗口中点击的数字，并在游玩过程中逐步缩小候选地址；还可通过指针路径与针对 Unreal、Unity、Godot、GameMaker、Java、Python 等运行时的专用浏览在重启后保持数值。独立的宿主辅助进程通过 ptrace 执行读写，Flatpak 界面则保持沙箱隔离；工具会结合本地反作弊进程检测与内嵌的 AreWeAntiCheatYet 游戏列表，对在线游戏进行拦截或警告。面向原生 Linux 以及 Proton 或 Wine 下的单机与离线用途，在模组、测试与研究游戏状态存储方面，与 Cheat Engine 或 GameConqueror 处于同一实用领域。
