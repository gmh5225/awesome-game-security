Ferret は Linux 向けデスクトップメモリエディタで、従来のメモリスキャン手順を覚えなくても、体力・所持金・弾薬などのゲーム内数値を検索・変更できます。Rust で書かれ、GTK 4 と libadwaita の GUI を備え、画面キャプチャと OCR でゲームウィンドウ内をクリックした数値を読み取り、プレイしながら候補を絞り込みます。ポインタパスや Unreal、Unity、Godot、GameMaker、Java、Python など各ランタイム向けのブラウジングで再起動後も値を維持できます。別のホストヘルパーが ptrace による読み書きを行い、Flatpak の UI はサンドボックス内に留まります。ローカルのアンチチートプロセス確認と組み込みの AreWeAntiCheatYet ゲーム一覧により、オンラインタイトルではブロックまたは警告します。ネイティブ Linux および Proton や Wine 上のシングルプレイ・オフライン向けで、Cheat Engine や GameConqueror と同様に、Mod、テスト、ゲーム状態の保存方法の調査に使えます。
