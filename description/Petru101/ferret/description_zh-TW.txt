Ferret 是一款 Linux 桌面記憶體編輯器，無需學習傳統記憶體掃描流程即可查找並修改遊戲中的生命值、金幣、彈藥等數值。它以 Rust 撰寫，採用 GTK 4 與 libadwaita 圖形介面，透過螢幕擷取與 OCR 讀取你在遊戲視窗中點選的數字，並在遊玩過程中逐步縮小候選位址；還可透過指標路徑與針對 Unreal、Unity、Godot、GameMaker、Java、Python 等執行環境的專用瀏覽在重啟後維持數值。獨立的宿主輔助程序透過 ptrace 執行讀寫，Flatpak 介面則保持沙箱隔離；工具會結合本機反作弊程序偵測與內嵌的 AreWeAntiCheatYet 遊戲清單，對線上遊戲進行攔截或警告。面向原生 Linux 以及 Proton 或 Wine 下的單機與離線用途，在模組、測試與研究遊戲狀態儲存方面，與 Cheat Engine 或 GameConqueror 處於同一實用領域。
