UbuRoot est une application Android qui télécharge l’image officielle Ubuntu Base arm64 et exécute un environnement Linux complet dans un chroot natif sur des appareils rootés. Elle est principalement développée en Kotlin avec Gradle, tandis que la logique de montage, d’installation et d’intégration repose sur des scripts shell POSIX exécutés via libsu avec Magisk, KernelSU ou APatch. L’application fournit un vrai terminal PTY, une gestion de paquets via apt, des montages bind vers le stockage et les partitions système du téléphone, des wrappers pour les outils Android, ainsi qu’un accès optionnel au noyau et au matériel avec des changements réversibles pour le travail bas niveau sur l’appareil. Elle vise la recherche en sécurité mobile, les tests d’intrusion et les flux de reverse engineering sur ROM personnalisées, avec une documentation orientée vers une parité de plateforme de type NetHunter plutôt qu’un espace utilisateur émulé.
