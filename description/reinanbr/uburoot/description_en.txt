UbuRoot is an Android application that downloads the official Ubuntu Base arm64 image and runs a full Linux environment in a native chroot on rooted devices. It is built primarily in Kotlin with Gradle, while mount, install, and integration logic lives in POSIX shell scripts exercised via libsu against Magisk, KernelSU, or APatch. The app provides a real PTY terminal, apt-based package management, bind mounts into phone storage and system partitions, wrappers for Android tooling, and opt-in kernel and hardware access with reversible changes for low-level device work. It targets mobile security research, penetration testing, and reverse engineering workflows on custom ROMs, with documentation aimed at NetHunter-style platform parity rather than emulated userspace.
