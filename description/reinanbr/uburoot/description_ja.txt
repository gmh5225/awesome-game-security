UbuRoot は、公式の Ubuntu Base arm64 イメージをダウンロードし、root 化済み端末上でネイティブ chroot によりフル Linux 環境を動かす Android アプリです。主に Kotlin と Gradle で構築され、マウント・インストール・統合ロジックは POSIX シェルスクリプトにあり、libsu 経由で Magisk、KernelSU、または APatch に対して実行されます。実 PTY ターミナル、apt ベースのパッケージ管理、端末ストレージやシステムパーティションへの bind マウント、Android ツール用ラッパー、およびオプトインのカーネル・ハードウェアアクセス（変更は可逆）を提供し、低レベルの端末作業を支援します。カスタム ROM 上でのモバイルセキュリティ研究、ペネトレーションテスト、リバースエンジニアリング向けで、ドキュメントはエミュレートされたユーザースペースではなく NetHunter 風のプラットフォーム同等性を目指しています。
