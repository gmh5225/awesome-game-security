PIF Config Generator は、Android ビルドプロパティを抽出し、検証済みの Play Integrity Fix (PIF) JSON デバイスプロファイルを生成する自動化 Python パイプラインです。安定版およびベータ版の Pixel ファームウェアリリースについて、上流の build.prop リポジトリを監視し、プロパティ ZIP アーカイブをダウンロードし、パーティション名前空間全体の system.prop ファイルを解析し、拡張形式またはレガシー形式の Pydantic スキーマに対して出力を検証します。pif-gen CLI は、ADB ダンプやリモート URL からのローカルプロファイル生成、マニフェスト追跡付きのバッチ CI ビルド、GitHub リリースの自動公開をサポートします。Play Integrity および関連する改ざん防止チェックで使用されるデバイス認証シグナルを偽装するために、最新かつスキーマ準拠の PIF 設定を必要とする Android 改造者およびセキュリティ研究者向けです。
