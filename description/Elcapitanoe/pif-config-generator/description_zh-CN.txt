PIF Config Generator 是一个自动化的 Python 流水线，用于提取 Android 构建属性并生成经过验证的 Play Integrity Fix (PIF) JSON 设备配置文件。它会监控上游 build.prop 仓库中的稳定版和 Beta 版 Pixel 固件发布，下载属性 ZIP 压缩包，解析跨分区命名空间的 system.prop 文件，并根据扩展或传统格式的 Pydantic 模式验证输出。pif-gen CLI 支持从 ADB 转储或远程 URL 进行本地配置文件生成、带清单跟踪的批量 CI 构建，以及自动化的 GitHub 发布。它面向需要最新、符合模式规范的 PIF 配置以伪装 Play Integrity 及相关防篡改检查所使用的设备认证信号的 Android 修改者和安全研究人员。
