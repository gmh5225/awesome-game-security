GPU Inspector 是一款跨平台桌面應用程式，可從使用 Vulkan、Direct3D 12、Metal 或 Android 的原生圖形應用程式中擷取並檢查 GPU 影格。它主要以 TypeScript 實作，配備 Electron 介面與 C++ 擷取層，提供物件檢查、含繪製狀態與資源的影格擷取、著色器除錯與即時編輯、驗證報告、像素歷史、渲染圖，以及通道耗時、GPU 瓶頸與過度繪製分析等分析工具。它支援儲存擷取檔案、將影格匯出為獨立 C++ 專案、從主流瀏覽器擷取 WebGPU，以及基於 MCP 的 Claude Code 外掛程式以進行自動化擷取分析。此工具面向需要分析渲染管線、除錯著色器並研究遊戲及其他即時 3D 軟體中 GPU 命令流的遊戲開發者、圖形工程師與逆向工程師。
