GPU Inspector is a cross-platform desktop application that captures and inspects GPU frames from native graphics applications using Vulkan, Direct3D 12, Metal, or Android. Implemented mainly in TypeScript with an Electron UI and C++ capture layers, it offers object inspection, frame capture with draw state and resources, shader debugging and live editing, validation reporting, pixel history, render graphs, and profiling tools such as pass timings, GPU bottlenecks, and overdraw analysis. It supports saved capture files, export of frames to standalone C++ projects, WebGPU capture from major browsers, and an MCP-based Claude Code plugin for automated capture analysis. The tool targets game developers, graphics engineers, and reverse engineers who need to analyze rendering pipelines, debug shaders, and study GPU command flow in games and other real-time 3D software.
