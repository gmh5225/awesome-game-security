GPU Inspector — это кроссплатформенное настольное приложение для захвата и анализа GPU-кадров из нативных графических приложений, использующих Vulkan, Direct3D 12, Metal или Android. Реализованное в основном на TypeScript с интерфейсом Electron и слоями захвата на C++, оно предлагает инспекцию объектов, захват кадров с состоянием отрисовки и ресурсами, отладку и редактирование шейдеров в реальном времени, отчёты валидации, историю пикселей, графы рендеринга, а также инструменты профилирования, такие как замеры проходов, узкие места GPU и анализ overdraw. Поддерживаются сохранённые файлы захвата, экспорт кадров в автономные проекты на C++, захват WebGPU из основных браузеров и плагин Claude Code на базе MCP для автоматизированного анализа захватов. Инструмент предназначен для разработчиков игр, инженеров по графике и специалистов по реверс-инжинирингу, которым нужно анализировать конвейеры рендеринга, отлаживать шейдеры и изучать поток GPU-команд в играх и другом ПО с 3D-графикой в реальном времени.
