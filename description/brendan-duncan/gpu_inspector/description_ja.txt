GPU Inspector は、Vulkan、Direct3D 12、Metal、または Android を使用するネイティブグラフィックスアプリケーションから GPU フレームをキャプチャして検査するクロスプラットフォームのデスクトップアプリケーションです。主に TypeScript で実装され、Electron UI と C++ キャプチャ層を備え、オブジェクト検査、描画状態とリソース付きのフレームキャプチャ、シェーダーのデバッグとライブ編集、検証レポート、ピクセル履歴、レンダーグラフ、パス時間、GPU ボトルネック、オーバードロー分析などのプロファイリングツールを提供します。キャプチャファイルの保存、フレームのスタンドアロン C++ プロジェクトへのエクスポート、主要ブラウザからの WebGPU キャプチャ、自動キャプチャ分析のための MCP ベースの Claude Code プラグインに対応しています。本ツールは、ゲームやその他のリアルタイム 3D ソフトウェアにおけるレンダリングパイプラインの分析、シェーダーのデバッグ、GPU コマンドフローの調査が必要なゲーム開発者、グラフィックスエンジニア、リバースエンジニアを対象としています。
