GPU Inspector è un'applicazione desktop multipiattaforma che cattura e ispeziona i frame GPU di applicazioni grafiche native che utilizzano Vulkan, Direct3D 12, Metal o Android. Implementata principalmente in TypeScript con un'interfaccia Electron e layer di cattura in C++, offre ispezione degli oggetti, cattura dei frame con stato di disegno e risorse, debug e modifica live degli shader, report di validazione, cronologia dei pixel, grafici di rendering e strumenti di profilazione come tempi dei pass, colli di bottiglia GPU e analisi dell'overdraw. Supporta file di cattura salvati, esportazione dei frame in progetti C++ autonomi, cattura WebGPU dai principali browser e un plugin Claude Code basato su MCP per l'analisi automatizzata delle catture. Lo strumento è rivolto a sviluppatori di giochi, ingegneri grafici e reverse engineer che devono analizzare le pipeline di rendering, eseguire il debug degli shader e studiare il flusso dei comandi GPU in giochi e altro software 3D in tempo reale.
