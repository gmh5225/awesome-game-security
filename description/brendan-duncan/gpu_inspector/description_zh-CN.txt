GPU Inspector 是一款跨平台桌面应用，用于从使用 Vulkan、Direct3D 12、Metal 或 Android 的原生图形应用中捕获并检查 GPU 帧。它主要使用 TypeScript 实现，配备 Electron 界面和 C++ 捕获层，提供对象检查、带绘制状态与资源的帧捕获、着色器调试与实时编辑、验证报告、像素历史、渲染图，以及通道耗时、GPU 瓶颈和过度绘制分析等分析工具。它支持保存捕获文件、将帧导出为独立 C++ 项目、从主流浏览器捕获 WebGPU，以及基于 MCP 的 Claude Code 插件以实现自动化捕获分析。该工具面向需要分析渲染管线、调试着色器并研究游戏及其他实时 3D 软件中 GPU 命令流的游戏开发者、图形工程师和逆向工程师。
