GPU Inspector는 Vulkan, Direct3D 12, Metal 또는 Android를 사용하는 네이티브 그래픽 애플리케이션에서 GPU 프레임을 캡처하고 검사하는 크로스 플랫폼 데스크톱 애플리케이션입니다. 주로 TypeScript로 구현되었으며 Electron UI와 C++ 캡처 레이어를 갖추고, 객체 검사, 드로우 상태 및 리소스가 포함된 프레임 캡처, 셰이더 디버깅 및 실시간 편집, 검증 보고, 픽셀 히스토리, 렌더 그래프, 패스 타이밍, GPU 병목, 오버드로우 분석 등의 프로파일링 도구를 제공합니다. 캡처 파일 저장, 프레임을 독립형 C++ 프로젝트로 내보내기, 주요 브라우저에서 WebGPU 캡처, 자동화된 캡처 분석을 위한 MCP 기반 Claude Code 플러그인을 지원합니다. 이 도구는 게임 및 기타 실시간 3D 소프트웨어에서 렌더링 파이프라인 분석, 셰이더 디버깅, GPU 명령 흐름 연구가 필요한 게임 개발자, 그래픽스 엔지니어, 리버스 엔지니어를 대상으로 합니다.
