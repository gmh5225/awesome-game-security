This project is a headless, always-on dedicated server for Halo: Combat Evolved multiplayer and campaign co-op, built on the OpenCE native port with null rendering so it runs without a GPU or display. It ships with Docker and bare-metal deployment, TOML-driven map and gametype rotation, master browser registration, an embedded tactical web dashboard, and shell-based operator tools for live moderation. The stack centers on compiled C engine code (with Python build tooling and shell automation), OpenCE netcode v39, UDP hosting, and optional Discord or Telegram webhooks. Server-side anti-cheat enforces host authority over inventory and scoring, validates combat hit reports, detects clock-skew speed hacks, and supports progressive IP and hardware bans alongside chat filtering. It targets community operators and researchers who need a documented, production-style OpenCE host with enforced integrity rather than a casual peer-to-peer session.
