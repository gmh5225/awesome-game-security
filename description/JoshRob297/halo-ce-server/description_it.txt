Questo progetto è un server dedicato headless sempre attivo per multigiocatore e co-op campagna di Halo: Combat Evolved, basato sulla port nativa OpenCE con rendering null per funzionare senza GPU o display. Include deployment Docker e bare metal, rotazione mappe e gametype guidata da TOML, registrazione nel master browser, una dashboard web tattica integrata e strumenti operatore basati su shell per moderazione live. Lo stack ruota attorno a codice motore C compilato (con tooling di build Python e automazione shell), OpenCE netcode v39, hosting UDP e webhook opzionali Discord o Telegram. L’anti-cheat lato server impone l’autorità dell’host su inventario e punteggio, valida i report degli hit in combattimento, rileva speed hack da skew dell’orologio e supporta ban progressivi per IP e hardware insieme al filtraggio della chat. È rivolto a operatori di community e ricercatori che necessitano di un host OpenCE documentato in stile produzione con integrità applicata, non una sessione peer-to-peer occasionale.
