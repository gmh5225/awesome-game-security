Este proyecto es un servidor dedicado headless y siempre activo para multijugador y cooperativo de campaña de Halo: Combat Evolved, basado en el port nativo OpenCE con renderizado nulo para ejecutarse sin GPU ni pantalla. Incluye despliegue con Docker y bare metal, rotación de mapas y modos de juego mediante TOML, registro en el navegador master, un panel web táctico integrado y herramientas de operador basadas en shell para moderación en vivo. La pila se centra en código de motor C compilado (con herramientas de build en Python y automatización shell), OpenCE netcode v39, hosting UDP y webhooks opcionales de Discord o Telegram. El anti-cheat del servidor impone la autoridad del host sobre inventario y puntuación, valida informes de impacto en combate, detecta speed hacks por desfase de reloj y admite baneos progresivos por IP y hardware junto con filtrado de chat. Está dirigido a operadores de comunidad e investigadores que necesitan un host OpenCE documentado de estilo producción con integridad reforzada, no una sesión peer-to-peer casual.
