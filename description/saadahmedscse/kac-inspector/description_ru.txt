KAC Inspector — консольная утилита для Windows, которая сканирует драйверы античита в режиме ядра и сообщает, загружен ли каждый из них и активен, простаивает или остался только на диске. Написана на Rust; сопоставляет данные из списка модулей ядра, диспетчера служб (SCM) и хранилища системных драйверов со встроенной базой десятков известных сигнатур античита и применяет эвристики к драйверам, не внесённым в список, но представляющим себя как античит. Инструмент выдаёт краткий вердикт и метки состояния для каждого драйвера — running, loaded, stopped, orphaned, stale — включая связанные пользовательские службы, без установки ПО, изменения системы и использования сети. Предназначена для игроков, исследователей и пользователей, заботящихся о безопасности, которым нужен режим только чтения для сведений о наличии kernel-античита при устранении неполадок, оценке конфиденциальности или анализе безопасности игр.
