KAC Inspector es una herramienta de línea de comandos para Windows que busca controladores anti-cheat en modo kernel e informa si cada uno está cargado y activo, inactivo o solo residual en disco. Escrita en Rust, correlaciona datos de la lista de módulos del kernel, el Administrador de control de servicios (SCM) y el almacén de controladores del sistema con una base de datos integrada de decenas de firmas anti-cheat conocidas, y aplica heurísticas a controladores no listados que se identifican como anti-cheat. La herramienta ofrece un veredicto conciso y etiquetas de estado por controlador como running, loaded, stopped, orphaned o stale, incluidos servicios en modo usuario relacionados, sin instalar software, modificar el sistema ni usar la red. Está pensada para jugadores, investigadores y usuarios preocupados por la seguridad que necesitan una vista de solo lectura de la presencia de anti-cheat en kernel para diagnóstico, evaluación de privacidad o análisis de seguridad en juegos.
