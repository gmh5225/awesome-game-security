KAC Inspector 是一款 Windows 命令行工具，用于扫描内核模式反作弊驱动，并报告每个驱动是正在运行、空闲还是仅残留在磁盘上。该工具用 Rust 编写，将内核模块列表、服务控制管理器（SCM）和系统驱动存储中的数据与内置的数十种已知反作弊特征数据库进行关联，并对未收录但自标识为反作弊的驱动采用启发式检测。工具会给出简明结论及每个驱动的状态标签（如 running、loaded、stopped、orphaned、stale），并涵盖相关用户模式服务，且无需安装软件、修改系统或使用网络。面向需要只读了解内核反作弊存在情况的玩家、研究人员及注重安全的用户，用于故障排查、隐私评估或游戏安全分析。
