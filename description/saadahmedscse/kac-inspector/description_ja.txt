KAC Inspector は、カーネルモードのアンチチートドライバをスキャンし、各ドライバが稼働中・待機中・ディスク上に残存しているかを報告する Windows 向けコマンドラインツールです。Rust で書かれており、カーネルモジュール一覧、サービス制御マネージャ（SCM）、システムドライバストアの情報を、数十種類の既知アンチチート署名を収めた内蔵データベースと照合し、未登録でもアンチチートと名乗るドライバにはヒューリスティックで検出します。ソフトのインストール、システム変更、ネットワーク利用なしに、簡潔な判定と running、loaded、stopped、orphaned、stale などのドライバ別ステータス、関連するユーザーモードサービスを表示します。トラブルシュート、プライバシー評価、ゲームセキュリティ分析のため、カーネルアンチチートの存在を読み取り専用で把握したいプレイヤー、研究者、セキュリティ意識の高いユーザー向けです。
