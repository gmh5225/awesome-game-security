KAC Inspector는 Windows 명령줄 도구로, 커널 모드 안티치트 드라이버를 검색하고 각 드라이버가 활성 로드 상태인지, 유휴인지, 디스크에만 남아 있는지 보고합니다. Rust로 작성되었으며, 커널 모듈 목록, 서비스 제어 관리자(SCM), 시스템 드라이버 저장소의 데이터를 수십 가지 알려진 안티치트 서명이 담긴 내장 데이터베이스와 대조하고, 목록에 없어도 안티치트로 자신을 표시하는 드라이버는 휴리스틱으로 식별합니다. 소프트웨어 설치, 시스템 변경, 네트워크 사용 없이 간결한 판정과 running, loaded, stopped, orphaned, stale 같은 드라이버별 상태 레이블 및 관련 사용자 모드 서비스를 제공합니다. 문제 해결, 프라이버시 평가, 게임 보안 분석을 위해 커널 안티치트 존재 여부를 읽기 전용으로 확인해야 하는 플레이어, 연구자, 보안에 민감한 사용자를 대상으로 합니다.
