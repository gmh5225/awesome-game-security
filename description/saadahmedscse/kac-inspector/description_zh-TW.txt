KAC Inspector 是一款 Windows 命令列工具，用於掃描核心模式反作弊驅動程式，並回報每個驅動是正在執行、閒置或僅殘留在磁碟上。此工具以 Rust 撰寫，會將核心模組清單、服務控制管理員（SCM）與系統驅動存放區的資料，與內建數十種已知反作弊特徵資料庫相互比對，並對未收錄但自稱為反作弊的驅動採用啟發式辨識。工具會產出簡潔結論及每個驅動的狀態標籤（如 running、loaded、stopped、orphaned、stale），並涵蓋相關使用者模式服務，且無需安裝軟體、修改系統或使用網路。適合需要唯讀掌握核心反作弊存在狀況的玩家、研究人員及重視安全的使用者，用於疑難排解、隱私評估或遊戲安全分析。
