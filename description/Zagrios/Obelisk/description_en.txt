Obelisk is a native macOS game launcher for Apple silicon that signs into Steam, Epic Games, and GOG and handles downloading, updating, installing, and launching your owned titles from one unified library. Its SwiftUI front end talks to a Rust core that implements each storefront’s protocols (informed by public tools such as SteamKit and Legendary) and manages transfers, cloud saves, friends, chat, and an in-game overlay without requiring the official store clients. Windows builds run through the bundled Voile Wine runtime, with per-game profiles choosing Rosetta-based Wine or a Linux compatibility engine backed by voile-lkd for titles whose anti-cheat supports Linux, plus Metal graphics paths such as D3DMetal and DXMT. The project emphasizes running games legitimately without modifying or bypassing anti-cheat, while documenting engine choice, runtime contracts, and launch diagnostics for compatibility work on Mac. It suits players consolidating stores on Mac and developers or researchers studying storefront integration, Wine-based translation, and anti-cheat constraints on non-Windows platforms.
