Obelisk는 Apple 실리콘용 네이티브 macOS 게임 런처로, Steam·Epic Games·GOG에 로그인해 보유 타이틀의 다운로드·업데이트·설치·실행을 하나의 통합 라이브러리에서 처리합니다. SwiftUI 프런트엔드는 Rust 코어와 연동해 각 스토어프론트 프로토콜(SteamKit, Legendary 등 공개 도구를 참고)을 구현하고, 전송·클라우드 세이브·친구·채팅·인게임 오버레이를 공식 스토어 클라이언트 없이 관리합니다. Windows 빌드는 번들된 Voile Wine 런타임으로 실행되며, 게임별 프로필에서 Rosetta 기반 Wine 또는 Linux 안티치트를 지원하는 타이틀용 voile-lkd 기반 Linux 호환 엔진을 선택할 수 있고, Metal 경로인 D3DMetal·DXMT도 지원합니다. 프로젝트는 안티치트를 수정·우회하지 않고 정당하게 플레이하는 것을 강조하며, Mac 호환 작업을 위해 엔진 선택·런타임 계약·실행 진단을 문서화합니다. Mac에서 여러 스토어를 통합하려는 플레이어와 스토어프론트 통합, Wine 기반 변환, 비 Windows 플랫폼의 안티치트 제약을 연구하는 개발자·연구자에게 적합합니다.
