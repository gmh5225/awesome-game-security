Obelisk は Apple シリコン向けのネイティブ macOS ゲームランチャーで、Steam・Epic Games・GOG にサインインし、所有タイトルのダウンロード・更新・インストール・起動を統一ライブラリから行います。SwiftUI のフロントエンドは Rust コアと連携し、各ストアフロントのプロトコル（SteamKit や Legendary などの公開ツールを参考に）を実装し、転送、クラウドセーブ、フレンド、チャット、ゲーム内オーバーレイを公式ストアクライアントなしで管理します。Windows 版は同梱の Voile Wine ランタイム上で動作し、ゲームごとのプロファイルで Rosetta ベースの Wine、または Linux 向けアンチチートに対応するタイトル向けに voile-lkd を支えとする Linux 互換エンジンを選べ、Metal 上の D3DMetal や DXMT などのグラフィックス経路も利用できます。プロジェクトはアンチチートを改変・回避せず正当にプレイすることを重視し、Mac での互換性作業のためエンジン選択、ランタイム契約、起動診断を文書化しています。Mac で複数ストアを一本化したいプレイヤーや、ストア統合、Wine ベースの変換、非 Windows でのアンチチート制約を研究する開発者・研究者向けです。
