Obelisk 是一款面向 Apple 芯片的原生 macOS 游戏启动器，可登录 Steam、Epic Games 和 GOG，并在统一库中完成已购游戏的下载、更新、安装与启动。其 SwiftUI 前端与 Rust 核心协作，实现各平台协议（参考 SteamKit、Legendary 等公开工具），并管理传输、云存档、好友、聊天及游戏内叠加层，无需安装官方商店客户端。Windows 版本通过内置的 Voile Wine 运行时运行；按游戏配置可选用基于 Rosetta 的 Wine，或对反作弊支持 Linux 的作品使用由 voile-lkd 支撑的 Linux 兼容引擎，图形路径包括 Metal 上的 D3DMetal 与 DXMT。项目强调合法运行游戏、不修改或绕过反作弊，并记录引擎选择、运行时约定与启动诊断，便于在 Mac 上做兼容性工作。适合在 Mac 上整合多平台商店的玩家，以及研究商店集成、基于 Wine 的转译及非 Windows 平台反作弊约束的开发者或研究人员。
