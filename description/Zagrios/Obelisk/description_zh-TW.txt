Obelisk 是一款面向 Apple 晶片的原生 macOS 遊戲啟動器，可登入 Steam、Epic Games 與 GOG，並在統一資料庫中完成已購遊戲的下載、更新、安裝與啟動。其 SwiftUI 前端與 Rust 核心協作，實作各平台協定（參考 SteamKit、Legendary 等公開工具），並管理傳輸、雲端存檔、好友、聊天及遊戲內疊加層，無需安裝官方商店用戶端。Windows 版本透過內建的 Voile Wine 執行環境運行；依遊戲設定可選用基於 Rosetta 的 Wine，或對反作弊支援 Linux 的作品使用由 voile-lkd 支撐的 Linux 相容引擎，圖形路徑包括 Metal 上的 D3DMetal 與 DXMT。專案強調合法執行遊戲、不修改或繞過反作弊，並記錄引擎選擇、執行環境約定與啟動診斷，便於在 Mac 上做相容性工作。適合在 Mac 上整合多平台商店的玩家，以及研究商店整合、基於 Wine 的轉譯及非 Windows 平台反作弊限制的開發者或研究人員。
