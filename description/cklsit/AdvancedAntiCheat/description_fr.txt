AdvancedAntiCheat est un plugin anti-triche Java pour serveurs Minecraft Spigot, Paper et Purpur, couvrant les versions 1.8.x à 1.21.x. Il détecte les triches courantes telles que le vol, la vitesse, KillAura, reach, scaffold, ESP et d'autres abus de combat et de mouvement, avec suivi des violations et bannissements automatiques selon la gravité. Le plugin propose aussi un flux de vérification client, des signalements joueurs avec notifications admin, et un sandbox de primes pour tester la couverture de détection. Il prend en charge plusieurs backends de base de données, dont SQLite, H2, MySQL, MongoDB et Redis, pour synchroniser les bans entre serveurs sous Velocity ou BungeeCord. Les opérateurs s'en servent pour faire respecter le fair-play grâce à des messages, bans et modules de détection configurables.
