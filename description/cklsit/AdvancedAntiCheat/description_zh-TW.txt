AdvancedAntiCheat 是一款以 Java 為基礎的 Minecraft 伺服器反作弊外掛，適用於 Spigot、Paper 與 Purpur，涵蓋 1.8.x 至 1.21.x 版本。它可偵測飛行、加速、KillAura、超距攻擊、搭路、ESP 等常見外掛，以及相關的戰鬥與移動濫用行為，並提供違規追蹤與依嚴重程度自動封鎖。外掛亦提供用戶端檢查流程、玩家檢舉與管理員通知，以及用於探測偵測涵蓋範圍的賞金沙箱。它支援 SQLite、H2、MySQL、MongoDB 與 Redis 等多種資料庫後端，可在 Velocity 或 BungeeCord 下實現跨伺服器封鎖同步。伺服器營運者可用它透過可設定的訊息、封鎖與偵測模組來維護公平遊戲環境。
