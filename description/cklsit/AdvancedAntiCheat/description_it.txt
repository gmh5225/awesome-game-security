AdvancedAntiCheat è un plugin anti-cheat Java per server Minecraft Spigot, Paper e Purpur che copre le versioni da 1.8.x a 1.21.x. Rileva cheat comuni come fly, speed, KillAura, reach, scaffold, ESP e relativi abusi di combattimento e movimento, con tracciamento delle violazioni e ban automatici in base alla gravità. Il plugin offre anche un flusso di controllo del client, segnalazioni dei giocatori con notifiche agli admin e una bounty sandbox per verificare la copertura del rilevamento. Supporta più backend di database tra cui SQLite, H2, MySQL, MongoDB e Redis per la sincronizzazione dei ban tra server sotto Velocity o BungeeCord. Gli operatori lo usano per garantire il fair play con messaggi, ban e moduli di rilevamento configurabili.
