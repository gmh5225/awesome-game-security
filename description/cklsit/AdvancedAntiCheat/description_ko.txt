AdvancedAntiCheat는 Spigot, Paper, Purpur용 Java 기반 Minecraft 서버 안티치트 플러그인으로, 1.8.x부터 1.21.x까지 지원합니다. 비행, 속도, KillAura, 리치, 스캐폴드, ESP 등 일반적인 치트와 관련 전투·이동 어뷰즈를 탐지하며, 위반 추적과 심각도에 따른 자동 차단을 제공합니다. 클라이언트 검사 워크플로, 관리자 알림이 포함된 플레이어 신고, 탐지 범위를 점검하는 현상금 샌드박스도 제공합니다. SQLite, H2, MySQL, MongoDB, Redis를 포함한 다중 데이터베이스 백엔드를 지원하며, Velocity 또는 BungeeCord 환경에서 서버 간 차단 동기화가 가능합니다. 서버 운영자는 구성 가능한 메시지, 차단, 탐지 모듈로 공정한 플레이를 유지할 수 있습니다.
