AdvancedAntiCheat は、Spigot、Paper、Purpur 向けの Java ベース Minecraft サーバー用アンチチートプラグインで、バージョン 1.8.x から 1.21.x まで対応します。飛行、速度、KillAura、リーチ、スキャフォールド、ESP などの一般的なチートや、関連する戦闘・移動の不正を検知し、違反の追跡と重大度に基づく自動 BAN を行います。クライアントチェックのワークフロー、管理者通知付きのプレイヤー通報、検知カバレッジを検証するバウンティサンドボックスも提供します。SQLite、H2、MySQL、MongoDB、Redis など複数のデータベースバックエンドに対応し、Velocity または BungeeCord 環境でのサーバー間 BAN 同期が可能です。サーバー運営者は、設定可能なメッセージ、BAN、検知モジュールで公正なプレイを維持できます。
