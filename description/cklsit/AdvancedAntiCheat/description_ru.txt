AdvancedAntiCheat — Java-плагин античита для серверов Minecraft на Spigot, Paper и Purpur, поддерживающий версии с 1.8.x по 1.21.x. Он обнаруживает распространённые читы: полёт, ускорение, KillAura, reach, scaffold, ESP и связанные злоупотребления в бою и передвижении, с учётом нарушений и автоматическими банами по степени тяжести. Плагин также предоставляет проверку клиента, жалобы игроков с уведомлениями администраторам и bounty-песочницу для проверки охвата детекции. Поддерживаются несколько баз данных, включая SQLite, H2, MySQL, MongoDB и Redis, для синхронизации банов между серверами под Velocity или BungeeCord. Операторы серверов используют его для поддержания честной игры с настраиваемыми сообщениями, банами и модулями детекции.
