AdvancedAntiCheat es un plugin anticheat en Java para servidores Minecraft Spigot, Paper y Purpur que cubre las versiones 1.8.x a 1.21.x. Detecta trampas habituales como fly, speed, KillAura, reach, scaffold, ESP y otros abusos de combate y movimiento, con seguimiento de infracciones y baneos automáticos según la gravedad. El plugin también ofrece un flujo de comprobación del cliente, denuncias de jugadores con notificaciones a administradores y un sandbox de recompensas para probar la cobertura de detección. Admite varios backends de base de datos, incluidos SQLite, H2, MySQL, MongoDB y Redis, para sincronizar baneos entre servidores bajo Velocity o BungeeCord. Los operadores lo usan para imponer el juego limpio con mensajes, baneos y módulos de detección configurables.
