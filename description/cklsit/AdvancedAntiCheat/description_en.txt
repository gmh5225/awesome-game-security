AdvancedAntiCheat is a Java-based Minecraft server anti-cheat plugin for Spigot, Paper, and Purpur covering versions 1.8.x through 1.21.x. It detects common cheats such as fly, speed, KillAura, reach, scaffold, ESP, and related combat and movement abuses, with violation tracking and severity-based automatic bans. The plugin also provides a client-check workflow, player reporting with admin notifications, and a bounty sandbox for probing detection coverage. It supports multi-database backends including SQLite, H2, MySQL, MongoDB, and Redis for cross-server ban sync under Velocity or BungeeCord. Server operators use it to enforce fair play with configurable messages, bans, and detection modules.
