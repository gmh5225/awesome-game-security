AdvancedAntiCheat 是一款基于 Java 的 Minecraft 服务器反作弊插件，适用于 Spigot、Paper 和 Purpur，覆盖 1.8.x 至 1.21.x 版本。它可检测飞行、加速、KillAura、超距攻击、搭路、ESP 等常见作弊以及相关的战斗与移动滥用行为，并提供违规追踪与按严重程度自动封禁。插件还提供客户端检查流程、玩家举报与管理员通知，以及用于探测检测覆盖范围的赏金沙箱。它支持 SQLite、H2、MySQL、MongoDB 和 Redis 等多种数据库后端，可在 Velocity 或 BungeeCord 下实现跨服封禁同步。服务器运营者可用它通过可配置的消息、封禁与检测模块来维护公平游戏环境。
