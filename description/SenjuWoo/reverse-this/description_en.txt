Reverse THIS! is a Windows reverse-engineering and modding workbench that installs a curated catalog of analysis tools behind stable command shims in a sandbox workspace. A PowerShell-driven installer provisions native and scripted utilities including Ghidra, x64dbg, Frida, Rizin, ImHex, and YARA, plus .NET and Unity stacks such as ILSpy, dnSpy, Il2CppDumper, AssetRipper, BepInEx, and MelonLoader, and engine-specific tooling for Unreal, Source, REDengine, FromSoftware, GameMaker, and many commercial titles. Local Python helpers fingerprint PE files for graphics APIs and anti-cheat markers, generate wildcard AOB signatures, and optionally bridge Ghidra to MCP, while an offline encyclopedia documents routing recipes, engine notes, IPC blueprints, and anti-cheat risk tiers for agent-guided workflows. It targets researchers, mod authors, and game-security analysts who need one reproducible bench for decompilation, live tracing, asset extraction, and mod loading without hunting individual tool releases.
