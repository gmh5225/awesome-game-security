Reverse THIS! è un workbench Windows per reverse engineering e modding che installa un catalogo curato di strumenti di analisi dietro shim di comando stabili in un workspace sandbox. Un installer guidato da PowerShell provisiona utility native e scriptate, tra cui Ghidra, x64dbg, Frida, Rizin, ImHex e YARA, più stack .NET e Unity come ILSpy, dnSpy, Il2CppDumper, AssetRipper, BepInEx e MelonLoader, e tooling specifico per motori Unreal, Source, REDengine, FromSoftware, GameMaker e molti titoli commerciali. Helper Python locali fingerprintano i PE per API grafiche e marcatori anti-cheat, generano firme AOB con wildcard e opzionalmente collegano Ghidra a MCP, mentre un’enciclopedia offline documenta ricette di routing, note sui motori, blueprint IPC e livelli di rischio anti-cheat per workflow guidati da agente. È pensato per ricercatori, autori di mod e analisti di game security che vogliono un banco riproducibile per decompilazione, tracing live, estrazione asset e caricamento mod senza inseguire singole release di tool.
