Reverse THIS! — рабочая среда Windows для reverse engineering и моддинга, которая устанавливает подобранный каталог инструментов анализа за стабильными command shim в sandbox workspace. Установщик на PowerShell разворачивает нативные и скриптовые утилиты, включая Ghidra, x64dbg, Frida, Rizin, ImHex и YARA, а также стеки .NET и Unity — ILSpy, dnSpy, Il2CppDumper, AssetRipper, BepInEx, MelonLoader — и движковые инструменты для Unreal, Source, REDengine, FromSoftware, GameMaker и многих коммерческих игр. Локальные Python-хелперы снимают отпечатки PE по графическим API и маркерам anti-cheat, генерируют wildcard AOB-сигнатуры и при необходимости связывают Ghidra с MCP; офлайн-энциклопедия описывает рецепты маршрутизации, заметки по движкам, IPC-схемы и уровни риска anti-cheat для agent-guided workflow. Целевая аудитория — исследователи, авторы модов и аналитики игровой безопасности, которым нужна одна воспроизводимая «скамья» для декомпиляции, live-трейсинга, извлечения ассетов и загрузки модов без поиска отдельных релизов инструментов.
