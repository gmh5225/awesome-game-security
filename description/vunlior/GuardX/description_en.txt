GuardX is a server-side anti-cheat plugin for Minecraft Paper servers that watches players for common cheats and unfair automation during gameplay. It is implemented in Java as a Maven-built Paper plugin and evaluates movement, combat, inventory, and packet behavior using many built-in checks plus configurable thresholds and punishments. It can use PacketEvents when present or fall back to a built-in Netty packet decoder, and it supports Discord and Telegram notifications, persistent violation history, layered check toggles by world or permission, PlaceholderAPI hooks, and an API to add custom checks. The project is aimed at multiplayer server operators and staff who need practical cheat detection, alerting, and moderation tooling on supported Minecraft server versions.
