GuardX — серверный античит-плагин для серверов Minecraft Paper, который отслеживает игроков на предмет распространённых читов и недобросовестной автоматизации в игре. Реализован на Java как Paper-плагин, собираемый Maven, и оценивает движение, бой, инвентарь и поведение пакетов с помощью множества встроенных проверок, настраиваемых порогов и наказаний. При наличии может использовать PacketEvents иначе переходит на встроенный декодер пакетов Netty; поддерживаются уведомления Discord и Telegram, постоянная история нарушений, послойное включение проверок по миру или правам, хуки PlaceholderAPI и API для добавления собственных проверок. Проект ориентирован на операторов многопользовательских серверов и персонал, которым нужны практичное обнаружение читов, оповещение и инструменты модерации на поддерживаемых версиях сервера Minecraft.
