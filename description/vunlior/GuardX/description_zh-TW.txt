GuardX 是適用於 Minecraft Paper 伺服器的伺服端反外掛外掛程式，會在遊玩過程中監控常見作弊與不公平的自動化行為。它以 Java 實作，為以 Maven 建置的 Paper 外掛，並透過眾多內建檢查與可設定的門檻與處罰，評估移動、戰鬥、背包與封包行為。若環境中有 PacketEvents 則可使用，否則退回內建的 Netty 封包解碼器；並支援 Discord 與 Telegram 通知、持久化的違規紀錄、依世界或權限分層的檢查開關、PlaceholderAPI 掛接，以及用於新增自訂檢查的 API。本專案目標為需要實用作弊偵測、警示與管理工具的多人伺服器營運者與工作人員，適用於受支援的 Minecraft 伺服器版本。
