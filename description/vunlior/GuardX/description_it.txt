GuardX è un plugin anti-cheat lato server per server Minecraft Paper che monitora i giocatori per rilevare cheat comuni e automazione scorretta durante il gioco. È implementato in Java come plugin Paper costruito con Maven e valuta movimento, combattimento, inventario e comportamento dei pacchetti usando molti controlli integrati più soglie e sanzioni configurabili. Può usare PacketEvents se presente oppure passare a un decoder di pacchetti Netty integrato e supporta notifiche Discord e Telegram, cronologia persistente delle violazioni, attivazione a strati dei controlli per mondo o permesso, hook PlaceholderAPI e un API per aggiungere controlli personalizzati. Il progetto è rivolto agli operatori di server multiplayer e allo staff che necessitano di rilevamento pratico dei cheat, avvisi e strumenti di moderazione sulle versioni del server Minecraft supportate.
