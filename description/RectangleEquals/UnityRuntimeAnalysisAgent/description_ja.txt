UnityRuntimeAnalysisAgent は、Mono スクリプティングバックエンド上で動作する Unity ゲーム内で実行される BepInEx プラグインであり、ライブゲームセッションの観察と、明示的な許可があれば変更を行うためのローカル API を提供します。C# で記述されており、アセンブリおよび IL 解析、クロスリファレンス、シーンと GameObject 階層の検査、ライブオブジェクトクエリ、Full モードでの監査付き状態変更など、深いランタイムイントロスペクションを実現します。通信は認証済みのローカル名前付きパイプまたはループバック TCP のみを通じて AgentConsole や UnityLudometryMCP server などのコンパニオンツールと行われ、デフォルトは読み取り専用モードで、ゲーム内オーバーレイがアクティビティを記録し緊急停止をサポートします。Windows 上で Unity タイトルのランタイムをプログラム的に検査・計装する必要があるゲームセキュリティ研究者、MOD 開発者、リバースエンジニア向けです。
