UnityRuntimeAnalysisAgent 是一款 BepInEx 插件，运行于采用 Mono 脚本后端的 Unity 游戏内部，提供本地 API，用于观察并在获得明确授权后修改正在运行的游戏会话。该工具使用 C# 编写，提供深度运行时内省能力，包括程序集与 IL 分析、交叉引用、场景与 GameObject 层级检查、实时对象查询，以及在 Full 模式下的可审计状态变更。通信仅通过经身份验证的本地命名管道或环回 TCP 与 AgentConsole、UnityLudometryMCP server 等配套工具进行，默认只读模式，并配有游戏内叠加层以记录活动并支持紧急停止。它面向需要以编程方式在 Windows 上检查和插桩 Unity 游戏运行时的游戏安全研究人员、模组开发者与逆向工程师。
