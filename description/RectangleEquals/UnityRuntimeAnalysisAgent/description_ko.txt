UnityRuntimeAnalysisAgent는 Mono 스크립팅 백엔드를 사용하는 Unity 게임 내부에서 실행되는 BepInEx 플러그인으로, 실행 중인 게임 세션을 관찰하고 명시적 허가가 있을 때 수정할 수 있는 로컬 API를 제공합니다. C#으로 작성되었으며, 어셈블리 및 IL 분석, 교차 참조, 씬과 GameObject 계층 검사, 실시간 객체 쿼리, Full 모드에서의 감사 가능한 상태 변경 등 깊은 런타임 인트로스펙션을 지원합니다. 통신은 인증된 로컬 named pipe 또는 loopback TCP를 통해서만 AgentConsole, UnityLudometryMCP server 같은 동반 도구와 이루어지며, 기본값은 읽기 전용 모드이고 게임 내 오버레이가 활동을 기록하고 비상 정지를 지원합니다. Windows에서 Unity 타이틀의 런타임을 프로그래밍 방식으로 검사하고 계측해야 하는 게임 보안 연구자, 모드 개발자, 리버스 엔지니어를 대상으로 합니다.
