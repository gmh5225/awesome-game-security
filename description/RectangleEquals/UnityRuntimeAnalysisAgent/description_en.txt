UnityRuntimeAnalysisAgent is a BepInEx plugin that runs inside Unity games on the Mono scripting backend and exposes a local API for observing and, with explicit permission, modifying a live game session. Written in C#, it provides deep runtime introspection including assembly and IL analysis, cross-references, scene and GameObject hierarchy inspection, live object queries, and audited state changes in Full mode. Communication happens only over authenticated local named pipes or loopback TCP to companion tools such as AgentConsole and the UnityLudometryMCP server, with a read-only default mode and an in-game overlay that logs activity and supports an emergency stop. It is aimed at game security researchers, mod developers, and reverse engineers who need programmatic access to inspect and instrument Unity titles at runtime on Windows.
