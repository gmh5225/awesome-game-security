UnityRuntimeAnalysisAgent — это плагин BepInEx, который работает внутри игр Unity на скриптовом бэкенде Mono и предоставляет локальный API для наблюдения за активной игровой сессией и, при явном разрешении, её изменения. Написанный на C#, он обеспечивает глубокую runtime-интроспекцию, включая анализ сборок и IL, перекрёстные ссылки, проверку иерархии сцен и GameObject, запросы к объектам в реальном времени и аудируемые изменения состояния в режиме Full. Связь осуществляется только через аутентифицированные локальные именованные каналы или loopback TCP с сопутствующими инструментами, такими как AgentConsole и сервер UnityLudometryMCP; по умолчанию используется режим только для чтения, а внутриигровой оверлей ведёт журнал активности и поддерживает аварийную остановку. Он предназначен для исследователей безопасности игр, разработчиков модов и специалистов по реверс-инжинирингу, которым нужен программный доступ для инспекции и инструментирования Unity-проектов во время выполнения в Windows.
