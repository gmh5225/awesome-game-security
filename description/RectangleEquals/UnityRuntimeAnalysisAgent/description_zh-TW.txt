UnityRuntimeAnalysisAgent 是一款 BepInEx 外掛，執行於採用 Mono 指令碼後端的 Unity 遊戲內部，提供本地 API，用於觀察並在獲得明確授權後修改正在執行的遊戲工作階段。此工具以 C# 撰寫，提供深度執行階段內省能力，包括組件與 IL 分析、交叉參考、場景與 GameObject 階層檢查、即時物件查詢，以及在 Full 模式下的可稽核狀態變更。通訊僅透過經驗證的本地命名管道或環回 TCP 與 AgentConsole、UnityLudometryMCP server 等配套工具進行，預設為唯讀模式，並配有遊戲內疊加層以記錄活動並支援緊急停止。它面向需要在 Windows 上以程式化方式檢查與插樁 Unity 遊戲執行階段的安全研究人員、模組開發者與逆向工程師。
