RootRaven 是一款自托管的 Web 命令中心，用于 Android 和 iOS 移动渗透测试，在单一浏览器仪表板中统一设备管理、动态分析和静态侦察。后端采用 Python 和 Flask 构建，前端使用原生 JavaScript，集成了 ADB 编排、Frida 插桩、JADX APK 反编译、SSH Shell 访问、Burp Suite 代理配置以及实时 logcat 流。预置的 Frida 钩子涵盖 SSL pinning 绕过、Root 和越狱检测绕过、反调试规避、生物识别绕过和加密嗅探，其他模块还提供清单扫描、SharedPreferences 密钥发现、深度链接模糊测试，以及带证据库导出的 OWASP MASVS 合规追踪器。它面向需要快速、可脚本化工具界面以进行授权移动应用评估（包括游戏客户端和反作弊保护）的移动安全研究人员、红队和逆向工程师。
