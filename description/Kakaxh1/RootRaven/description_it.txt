RootRaven è un centro di comando web self-hosted per penetration test mobile su Android e iOS che unifica gestione dispositivi, analisi dinamica e ricognizione statica in un'unica dashboard del browser. Realizzato con Python e Flask nel backend e JavaScript vanilla nel frontend, integra orchestrazione ADB, strumentazione Frida, decompilazione APK con JADX, accesso shell SSH, configurazione proxy Burp Suite e streaming logcat in tempo reale. Gli hook Frida predefiniti coprono bypass SSL pinning, rilevamento root/jailbreak, evasione anti-debug, bypass biometrico e sniffing crittografico, mentre moduli aggiuntivi offrono scansione manifest, scoperta segreti SharedPreferences, fuzzing deep link e un tracker di conformità OWASP MASVS con export della evidence vault. È rivolto a ricercatori di sicurezza mobile, red teamer e reverse engineer che necessitano di una superficie strumentale veloce e scriptabile per la valutazione autorizzata di applicazioni mobile, inclusi client di gioco e protezioni anti-cheat.
