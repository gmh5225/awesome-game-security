RootRaven 是一款自託管的 Web 命令中心，用於 Android 與 iOS 行動滲透測試，在單一瀏覽器儀表板中整合裝置管理、動態分析與靜態偵察。後端以 Python 與 Flask 建構，前端使用原生 JavaScript，整合 ADB 編排、Frida 插樁、JADX APK 反編譯、SSH Shell 存取、Burp Suite 代理設定以及即時 logcat 串流。預建的 Frida 鉤子涵蓋 SSL pinning 繞過、Root 與越獄偵測繞過、反除錯規避、生物辨識繞過與加密嗅探，其他模組還提供清單掃描、SharedPreferences 密鑰發現、深度連結模糊測試，以及附證據庫匯出的 OWASP MASVS 合規追蹤器。它面向需要快速、可腳本化工具介面以進行授權行動應用程式評估（含遊戲用戶端與反作弊保護）的行動安全研究人員、紅隊與逆向工程師。
