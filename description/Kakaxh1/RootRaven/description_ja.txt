RootRaven は、Android および iOS のモバイルペネトレーションテスト向けのセルフホスト型 Web コマンドセンターで、デバイス管理、動的解析、静的偵察を単一のブラウザーダッシュボードに統合します。バックエンドは Python と Flask、フロントエンドは vanilla JavaScript で構築され、ADB オーケストレーション、Frida インストルメンテーション、JADX による APK 逆コンパイル、SSH シェルアクセス、Burp Suite プロキシ設定、ライブ logcat ストリーミングを統合しています。事前構築された Frida フックは SSL ピンニング回避、root/jailbreak 検知回避、アンチデバッグ回避、生体認証回避、暗号スニッフィングをカバーし、追加モジュールはマニフェストスキャン、SharedPreferences シークレット検出、ディープリンクファジング、証拠ボールトエクスポート付き OWASP MASVS コンプライアンストラッカーを提供します。モバイルセキュリティ研究者、レッドチーム、リバースエンジニア向けで、ゲームクライアントやアンチチート保護を含むモバイルアプリの許可された評価に、高速でスクリプト可能なツール面が必要な場合に適しています。
