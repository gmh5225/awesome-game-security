RootRaven is a self-hosted web command center for Android and iOS mobile penetration testing that unifies device management, dynamic analysis, and static reconnaissance in a single browser dashboard. Built with Python and Flask on the backend and vanilla JavaScript on the frontend, it integrates ADB orchestration, Frida instrumentation, JADX APK decompilation, SSH shell access, Burp Suite proxy setup, and live logcat streaming. Pre-built Frida hooks cover SSL pinning bypass, root and jailbreak detection bypass, anti-debug evasion, biometric bypass, and crypto sniffing, while additional modules provide manifest scanning, SharedPreferences secret discovery, deep link fuzzing, and an OWASP MASVS compliance tracker with evidence vault export. It is aimed at mobile security researchers, red teamers, and reverse engineers who need a fast, scriptable tooling surface for authorized assessment of mobile applications, including game clients and anti-cheat protections.
