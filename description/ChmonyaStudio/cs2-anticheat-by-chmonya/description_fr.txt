Plugin anti-triche côté serveur pour les serveurs Counter-Strike 2, construit sur le framework CounterStrikeSharp, conçu pour détecter et bannir les comportements de triche courants pendant le jeu en direct. Écrit en C# pour .NET 8, il analyse les joueurs à chaque tick serveur avec des modules ciblant le snap et le spin de visée, le lissage d’aimbot IA basé sur le jerk, les émulateurs de souris matériels DMA, le timing de triggerbot, le prefire, les heuristiques de wallbang, les scripts bhop et les exploits HvH tels que l’anti-aim pitch, le spinbot et l’abus de tickbase. Le plugin combine un système de bannissement automatique par score de suspicion avec décroissance, un stockage persistant des bannissements en JSON, des alertes webhook Discord et un menu admin en jeu pour les seuils, les listes blanches et la modération. Il s’adresse aux administrateurs de serveurs CS2 et aux praticiens de la sécurité des jeux qui souhaitent une détection de triche légère basée sur des plugins, sans installation anti-triche côté client.
