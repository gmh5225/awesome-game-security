Серверный античит-плагин для серверов Counter-Strike 2 на базе фреймворка CounterStrikeSharp, предназначенный для обнаружения и бана распространённых читерских действий во время живой игры. Написан на C# для .NET 8 и анализирует игроков на каждом серверном тике с помощью модулей, нацеленных на aim snap и spin, сглаживание AI-аимбота на основе jerk, эмуляторы аппаратной мыши DMA, тайминг triggerbot, prefire, эвристики wallbang, bhop-скрипты и HvH-эксплойты, такие как pitch anti-aim, spinbot и злоупотребление tickbase. Плагин сочетает систему автобана с оценкой подозрительности и затуханием, постоянное JSON-хранилище банов, оповещения через Discord webhook и внутриигровое админ-меню для порогов, белых списков и модерации. Ориентирован на администраторов серверов CS2 и специалистов по безопасности игр, которым нужно лёгкое обнаружение читов на основе плагинов без установки клиентского античита.
