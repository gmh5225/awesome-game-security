A server-side anti-cheat plugin for Counter-Strike 2 servers built on the CounterStrikeSharp framework, designed to detect and ban common cheat behaviors during live gameplay. Written in C# for .NET 8, it analyzes players every server tick with modules targeting aim snap and spin, jerk-based AI aimbot smoothing, DMA hardware mouse emulators, triggerbot timing, prefire, wallbang heuristics, bhop scripts, and HvH exploits such as pitch anti-aim, spinbot, and tickbase abuse. The plugin combines a suspicion-scoring auto-ban system with decay, persistent JSON ban storage, Discord webhook alerts, and an in-game admin menu for thresholds, whitelists, and moderation. It is aimed at CS2 server administrators and game security practitioners who want lightweight, plugin-based cheat detection without requiring a client-side anti-cheat install.
