Plugin anti-cheat lato server per server Counter-Strike 2 basato sul framework CounterStrikeSharp, progettato per rilevare e bannare comportamenti cheat comuni durante il gameplay live. Scritto in C# per .NET 8, analizza i giocatori a ogni tick del server con moduli mirati a snap e spin della mira, smoothing di aimbot IA basato su jerk, emulatori hardware del mouse DMA, timing del triggerbot, prefire, euristiche wallbang, script bhop ed exploit HvH come anti-aim pitch, spinbot e abuso del tickbase. Il plugin combina un sistema di ban automatico con punteggio di sospetto e decadimento, archiviazione persistente dei ban in JSON, avvisi webhook Discord e un menu admin in-game per soglie, whitelist e moderazione. È rivolto ad amministratori di server CS2 e professionisti della sicurezza dei giochi che desiderano un rilevamento cheat leggero basato su plugin senza richiedere un anti-cheat lato client.
