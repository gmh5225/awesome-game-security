이 프로젝트는 Windows에서 안티바이러스 탐지를 회피하도록 설계된 shellcode 난독화 기법을 탐구합니다. 시저 암호 기반 인코딩 파이프라인을 구현하며, Python 난독화 도구가 원시 shellcode 바이트를 변환하고 C 로더가 VirtualAlloc과 메모리 내 실행을 통해 페이로드를 디코딩하여 실행합니다. 저장소에는 비교를 위한 기준 shellcode 로더도 포함되어 있으며, 시그니처, 휴리스틱, 머신러닝 기반 안티바이러스 방식이 수정되지 않은 페이로드를 어떻게 탐지하는지도 설명합니다. 주로 C와 Python으로 작성되었으며, 난독화가 탐지율에 미치는 영향을 연구하고 회피 또는 대응 회피 전략을 개선하려는 공격적 보안 연구자와 방어자를 대상으로 합니다.
