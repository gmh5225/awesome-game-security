本プロジェクトは、Windows 上でアンチウイルス検知を回避することを目的とした shellcode 難読化手法を調査します。シーザー暗号に基づくエンコードパイプラインを実装し、Python 難読化ツールが生の shellcode バイト列を変換し、C ローダーが VirtualAlloc とメモリ内実行によりペイロードを復号して実行します。リポジトリには比較用のベースライン shellcode ローダーも含まれ、シグネチャ、ヒューリスティック、機械学習によるアンチウイルス検知が未改変ペイロードをどのように検出するかも解説しています。主に C と Python で書かれており、難読化が検知率に与える影響を研究し、回避または対抗回避戦略を改善したい攻撃的セキュリティ研究者と防御側を対象としています。
