Этот проект исследует техники обфускации shellcode, предназначенные для обхода обнаружения антивирусами в Windows. Реализован конвейер кодирования на основе шифра Цезаря: Python-обфускатор преобразует исходные байты shellcode, а C-загрузчик декодирует и выполняет полезную нагрузку через VirtualAlloc и исполнение в памяти. Репозиторий также включает базовый загрузчик shellcode для сравнения и описывает, как методы антивирусного обнаружения на основе сигнатур, эвристики и машинного обучения выявляют неизменённые полезные нагрузки. Написан в основном на C и Python и предназначен для исследователей offensive security и специалистов по защите, которые хотят изучить влияние обфускации на показатели обнаружения и улучшить стратегии уклонения или противодействия уклонению.
