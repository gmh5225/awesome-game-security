MobileRE-Skill — это набор навыков на базе ИИ для мобильной reverse engineering и анализа безопасности, разработанный так, чтобы LLM-агенты понимали поверхности атак, выбирали методы и выполняли рабочие процессы анализа, а не полагались на разовые ручные скрипты. Основные результаты — определения агентов и документация навыков в виде деревьев решений, дополненные компонуемыми модулями Frida JavaScript для пассивного мониторинга и активного обхода, Python-инструментами для анализа ARM64-бинарников и пакетными утилитами для отладки и проверки инъекций. Стек поддерживает многоуровневый анализ от Java через JNI, нативный код, libc, системные вызовы и inline-инструкции SVC, включая шестифазный конвейер антиобнаружения для проверок root, скрытия Frida, загрузки SO и предотвращения сбоев. Интегрируется с JADX и Ghidra для декомпиляции и предназначен для авторизованного тестирования безопасности мобильных приложений, исследований anti-tamper и reverse engineering защищённых Android-приложений.
