MobileRE-Skill 是一套面向移动逆向工程与安全分析的 AI 驱动技能集，旨在让 LLM 智能体理解攻击面、选择技术并执行分析工作流，而非依赖临时性的手工脚本。其核心产出包括智能体定义与决策树式技能文档，并辅以可组合的 Frida JavaScript 模块（用于被动监控与主动绕过）、用于 ARM64 二进制分析的 Python 工具，以及用于调试与注入检测的批处理实用程序。该技术栈支持从 Java、JNI、原生代码、libc、系统调用到内联 SVC 指令的分层分析，并包含针对 root 检测、Frida 隐藏、SO 加载与防崩溃的六阶段反检测流水线。它与 JADX 和 Ghidra 集成以进行反编译，适用于经授权的移动应用安全测试、防篡改研究以及加固 Android 应用的逆向工程。
