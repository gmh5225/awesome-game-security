MobileRE-Skill è un set di competenze guidato dall'IA per il reverse engineering mobile e l'analisi della sicurezza, progettato affinché gli agenti LLM comprendano le superfici di attacco, scelgano le tecniche ed eseguano workflow di analisi anziché affidarsi a script manuali ad hoc. I deliverable principali sono definizioni di agenti e documentazione delle competenze in forma di alberi decisionali, supportati da moduli Frida JavaScript componibili per il monitoraggio passivo e il bypass attivo, strumenti Python per l'analisi binaria ARM64 e utility batch per il debug e il controllo delle iniezioni. Lo stack supporta analisi a strati da Java a JNI, codice nativo, libc, syscall e istruzioni SVC inline, inclusa una pipeline anti-rilevamento in sei fasi per i controlli root, l'occultamento di Frida, il caricamento di SO e la prevenzione dei crash. Si integra con JADX e Ghidra per la decompilazione ed è destinato a test di sicurezza di app mobili autorizzati, ricerca anti-manomissione e reverse engineering di applicazioni Android hardened.
