MobileRE-Skill es un conjunto de habilidades impulsado por IA para ingeniería inversa móvil y análisis de seguridad, diseñado para que los agentes LLM comprendan las superficies de ataque, elijan técnicas y ejecuten flujos de análisis en lugar de depender de scripts manuales ad hoc. Sus entregables principales son definiciones de agentes y documentación de habilidades en forma de árboles de decisión, respaldados por módulos Frida JavaScript componibles para monitorización pasiva y bypass activo, herramientas Python para análisis binario ARM64 y utilidades por lotes para depuración y comprobación de inyección. La pila admite análisis en capas desde Java hasta JNI, código nativo, libc, llamadas al sistema e instrucciones SVC inline, incluyendo una canalización anti-detección de seis fases para comprobaciones de root, ocultación de Frida, carga de SO y prevención de fallos. Se integra con JADX y Ghidra para descompilación y está orientado a pruebas de seguridad de aplicaciones móviles autorizadas, investigación anti-manipulación e ingeniería inversa de aplicaciones Android endurecidas.
