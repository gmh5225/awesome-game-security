MobileRE-Skill 是一套面向行動逆向工程與安全分析的 AI 驅動技能集，旨在讓 LLM 代理理解攻擊面、選擇技術並執行分析工作流程，而非依賴臨時性的手動腳本。其核心產出包括代理定義與決策樹式技能文件，並輔以可組合的 Frida JavaScript 模組（用於被動監控與主動繞過）、用於 ARM64 二進位分析的 Python 工具，以及用於除錯與注入檢測的批次實用程式。該技術棧支援從 Java、JNI、原生程式碼、libc、系統呼叫到內聯 SVC 指令的分層分析，並包含針對 root 偵測、Frida 隱藏、SO 載入與防當機的六階段反偵測管線。它與 JADX 和 Ghidra 整合以進行反編譯，適用於經授權的行動應用安全測試、防篡改研究以及加固 Android 應用的逆向工程。
