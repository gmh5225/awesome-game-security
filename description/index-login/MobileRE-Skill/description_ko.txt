MobileRE-Skill은 모바일 리버스 엔지니어링 및 보안 분석을 위한 AI 기반 스킬 세트로, LLM 에이전트가 공격 표면을 이해하고 기법을 선택하며 분석 워크플로를 실행할 수 있도록 설계되어 임시적인 수동 스크립팅에 의존하지 않습니다. 핵심 산출물은 에이전트 정의와 의사결정 트리 형식의 스킬 문서이며, 수동 모니터링과 능동적 우회를 위한 조합 가능한 Frida JavaScript 모듈, ARM64 바이너리 분석용 Python 도구, 디버깅 및 인젝션 검사용 배치 유틸리티가 이를 뒷받침합니다. 이 스택은 Java, JNI, 네이티브 코드, libc, 시스템 호출, 인라인 SVC 명령어에 이르는 계층적 분석을 지원하며, root 검사, Frida 은닉, SO 로딩, 크래시 방지를 위한 6단계 탐지 회피 파이프라인을 포함합니다. JADX 및 Ghidra와 통합하여 디컴파일을 수행하며, 승인된 모바일 앱 보안 테스트, 변조 방지 연구, 강화된 Android 애플리케이션의 리버스 엔지니어링을 목표로 합니다.
