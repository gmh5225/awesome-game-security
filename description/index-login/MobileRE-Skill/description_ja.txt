MobileRE-Skill は、モバイル逆エンジニアリングとセキュリティ分析向けの AI 駆動型スキルセットであり、LLM エージェントが攻撃面を理解し、手法を選択して分析ワークフローを実行できるよう設計されており、場当たり的な手動スクリプトに頼る必要がありません。中核となる成果物はエージェント定義と意思決定ツリー形式のスキルドキュメントで、受動的監視と能動的バイパス用の組み合わせ可能な Frida JavaScript モジュール、ARM64 バイナリ分析用 Python ツール、デバッグおよびインジェクション検査用のバッチユーティリティによって支えられています。スタックは Java、JNI、ネイティブコード、libc、システムコール、インライン SVC 命令に至るまでの階層的分析をサポートし、root チェック、Frida 隠蔽、SO ロード、クラッシュ防止のための 6 段階の検知回避パイプラインも含みます。JADX および Ghidra と連携して逆コンパイルを行い、許可されたモバイルアプリのセキュリティテスト、改ざん防止研究、強化された Android アプリケーションの逆エンジニアリングを目的としています。
