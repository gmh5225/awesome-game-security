MobileRE-Skill is an AI-driven skill set for mobile reverse engineering and security analysis, designed so LLM agents can understand attack surfaces, choose techniques, and run analysis workflows rather than relying on ad hoc manual scripting. Its core deliverables are agent definitions and decision-tree skill documentation, backed by composable Frida JavaScript modules for passive monitoring and active bypass, Python tools for ARM64 binary analysis, and batch utilities for debugging and injection checks. The stack supports layered analysis from Java through JNI, native code, libc, syscalls, and inline SVC instructions, including a six-phase anti-detection pipeline for root checks, Frida hiding, SO loading, and crash prevention. It integrates with JADX and Ghidra for decompilation and is aimed at authorized mobile app security testing, anti-tamper research, and reverse engineering of hardened Android applications.
