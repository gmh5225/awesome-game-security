本プロジェクトは、Realtek RTL8852AU Wi-Fi 6 USB アダプター（ASUS USB-AX56）向けのユーザースペース、root 不要のドライバーであり、カーネルモジュールを使わず libusb と usbfs だけで無線を完全に制御します。主に C で書かれ、Kotlin と TypeScript のツールチェーンを併用し、コールドパワーオン、ファームウェアのダウンロード、モニターモードでの受信を radiotap pcap ファイルに記録し、2.4 GHz と 5 GHz でチャネルホッピングを行います。Linux rtw89 カーネルドライバーからレジスタシーケンスとキャリブレーションロジックを移植することで、ライブ RF キャリブレーションと空中での生 802.11 フレームインジェクションにも対応します。所有ハードウェア上で root 権限なしにパケットキャプチャ、RF 解析、相互運用性テストを行う必要がある、ワイヤレスセキュリティ研究者と開発者を対象としています。
