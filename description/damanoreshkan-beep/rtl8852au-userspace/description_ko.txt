이 프로젝트는 Realtek RTL8852AU Wi-Fi 6 USB 어댑터(ASUS USB-AX56)용 사용자 공간, root 권한이 필요 없는 드라이버로, 커널 모듈 없이 libusb와 usbfs만으로 무선을 완전히 제어합니다. 주로 C로 작성되었으며 Kotlin과 TypeScript 도구를 함께 사용하며, 콜드 파워온, 펌웨어 다운로드, 모니터 모드 수신을 radiotap pcap 파일로 기록하고 2.4 GHz와 5 GHz에서 채널 호핑을 수행합니다. Linux rtw89 커널 드라이버의 레지스터 시퀀스와 캘리브레이션 로직을 이식하여 라이브 RF 캘리브레이션과 공중 원시 802.11 프레임 주입도 지원합니다. 소유한 하드웨어에서 root 권한 없이 패킷 캡처, RF 분석, 상호 운용성 테스트가 필요한 무선 보안 연구자와 개발자를 대상으로 합니다.
