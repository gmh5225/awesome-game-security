此專案是 Realtek RTL8852AU Wi-Fi 6 USB 介面卡（ASUS USB-AX56）的使用者空間、無需 root 權限的驅動程式，完全透過 libusb 和 usbfs 控制射頻，無需核心模組。專案主要使用 C 語言撰寫，並搭配 Kotlin 與 TypeScript 工具鏈，可完成冷啟動上電、韌體下載，以及監聽模式接收並寫入 radiotap pcap 檔案，支援在 2.4 GHz 與 5 GHz 頻段間跳頻。它還支援即時 RF 校正與空中原始 802.11 影格注入，方法是移植 Linux rtw89 核心驅動中的暫存器序列與校正邏輯。此專案面向需要在自有硬體上進行封包擷取、RF 分析與互通性測試、且無需 root 權限的無線安全研究人員與開發者。
