该项目是 Realtek RTL8852AU Wi-Fi 6 USB 适配器（ASUS USB-AX56）的用户态、无需 root 权限的驱动程序，完全通过 libusb 和 usbfs 控制射频，无需内核模块。项目主要使用 C 语言编写，并配合 Kotlin 和 TypeScript 工具链，可完成冷启动上电、固件下载，以及监听模式接收并写入 radiotap pcap 文件，支持在 2.4 GHz 和 5 GHz 频段间跳频。它还支持实时 RF 校准和空中原始 802.11 帧注入，方法是移植 Linux rtw89 内核驱动中的寄存器序列与校准逻辑。该项目面向需要在自有硬件上进行抓包、RF 分析和互操作性测试、且无需 root 权限的无线安全研究人员和开发者。
