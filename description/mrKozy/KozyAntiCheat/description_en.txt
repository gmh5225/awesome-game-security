Kozy AntiCheat is a server-side anti-cheat and cheat-mitigation framework for multiplayer Minecraft networks. It is implemented primarily in Java and includes a Python build script that compiles sources and packages a single JAR for typical plugin or Fabric-bridge server layouts. The project bundles many detection modules across movement, combat, world and interaction abuse, and server exploit defense, using standard server APIs, spatial checks, and configurable violation handling rather than brittle NMS hooks. It is aimed at server operators who run modern Paper-family or compatible stacks and need lag-aware checks, staff moderation commands, and tunable punishments to reduce common client cheats in production environments.
