Kozy AntiCheat は、マルチプレイヤーの Minecraft ネットワーク向けのサーバー側アンチチートおよびチート緩和フレームワークです。主に Java で実装され、ソースをコンパイルして単一の JAR にパッケージする Python ビルドスクリプトを含み、典型的なプラグインまたは Fabric ブリッジ構成のサーバー向けです。移動、戦闘、ワールドおよび操作の乱用、サーバー exploit 対策など多数の検知モジュールをまとめ、標準のサーバー API、空間チェック、設定可能な違反処理を用い、壊れやすい NMS フックに頼りません。モダンな Paper 系または互換スタックを運用し、ラグを意識したチェック、スタッフ向けモデレーションコマンド、調整可能なペナルティが必要なサーバー運用者向けです。
