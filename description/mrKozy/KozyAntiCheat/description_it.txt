Kozy AntiCheat è un framework anti-cheat e di mitigazione delle cheat lato server per reti Minecraft multigiocatore. È implementato principalmente in Java e include uno script di build Python che compila i sorgenti e crea un singolo JAR per layout tipici di server a plugin o bridge Fabric. Il progetto raggruppa molti moduli di rilevamento su movimento, combattimento, abusi su mondo e interazioni e difesa dagli exploit del server, usando API server standard, controlli spaziali e gestione configurabile delle violazioni anziché hook NMS fragili. È rivolto agli operatori che gestiscono stack moderni della famiglia Paper o compatibili e necessitano di controlli sensibili al lag, comandi di moderazione per lo staff e punizioni regolabili per ridurre cheat client comuni in produzione.
