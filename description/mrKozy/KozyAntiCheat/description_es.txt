Kozy AntiCheat es un marco antitrampas y de mitigación de trampas del lado del servidor para redes multijugador de Minecraft. Está implementado principalmente en Java e incluye un script de construcción en Python que compila el código y empaqueta un único JAR para despliegues típicos de servidor con plugin o puente Fabric. El proyecto agrupa muchos módulos de detección que cubren movimiento, combate, abuso del mundo y las interacciones, y defensa contra exploits del servidor, usando APIs estándar del servidor, comprobaciones espaciales y manejo configurable de infracciones en lugar de hooks NMS frágiles. Está pensado para operadores que ejecutan stacks modernos de la familia Paper o compatibles y necesitan comprobaciones conscientes del lag, comandos de moderación para el personal y castigos ajustables para reducir trampas de cliente habituales en producción.
