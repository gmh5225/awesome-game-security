Kozy AntiCheat est un framework anti-triche et d'atténuation des triches côté serveur pour les réseaux Minecraft multijoueurs. Il est implémenté principalement en Java et inclut un script de build Python qui compile les sources et produit un unique JAR, pour les déploiements serveur type plugin ou pont Fabric. Le projet regroupe de nombreux modules de détection couvrant le déplacement, le combat, les abus sur le monde et les interactions, ainsi que la défense contre l'exploitation du serveur, en s'appuyant sur les API serveur standard, des contrôles spatiaux et une gestion configurable des infractions plutôt que sur des hooks NMS fragiles. Il s'adresse aux opérateurs de serveurs qui font tourner des stacks modernes de la famille Paper ou compatibles et ont besoin de contrôles sensibles au lag, de commandes de modération pour le personnel et de sanctions réglables afin de limiter les triches client courantes en production.
