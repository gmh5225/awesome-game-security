Kozy AntiCheat는 멀티플레이어 Minecraft 네트워크용 서버 측 안티치트 및 치트 완화 프레임워크입니다. 주로 Java로 구현되며 소스를 컴파일하고 단일 JAR로 패키징하는 Python 빌드 스크립트를 포함하여 일반적인 플러그인 또는 Fabric 브리지 서버 구성에 맞습니다. 이동, 전투, 월드 및 상호작용 남용, 서버 익스플로잇 방어 등 여러 탐지 모듈을 묶어 표준 서버 API, 공간 검사, 구성 가능한 위반 처리를 사용하며 취약한 NMS 훅에 의존하지 않습니다. 현대적인 Paper 계열 또는 호환 스택을 운영하고 지연을 고려한 검사, 스태프 모더레이션 명령, 조정 가능한 처벌이 필요한 서버 운영자를 대상으로 하며 프로덕션에서 흔한 클라이언트 치트를 줄이는 데 도움이 됩니다.
