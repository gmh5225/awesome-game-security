Smali Patcher Reborn は Magisk、KernelSU、APatch 向けモジュールで、インストール時にデバイス ROM の services.jar をパッチして Android フレームワークの挙動を変更します。デバイス上のパッチエンジンは Java で書かれ、dexlib2 を使って services.jar 内の DEX バイトコードを書き換え、モック位置フラグの非表示、開発者設定なしでのモック位置プロバイダーの許可、FLAG_SECURE ウィンドウでのスクリーンショット許可（任意）などの選択可能なパッチを適用します。モジュールのライフサイクルとインストール時のロジックはシェルスクリプトで実装され、WebUI によるパッチ設定と Android 10 から 17 までのサポートを備えています。位置情報ベースのチェックやセキュアウィンドウ制限を回避してモバイルアプリやゲームを分析する必要がある root 化 Android ユーザーおよびセキュリティ研究者向けに、Smali Patcher 系譜を継承するツールです。
