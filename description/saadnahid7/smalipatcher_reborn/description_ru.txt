Smali Patcher Reborn — модуль для Magisk, KernelSU и APatch, который при установке патчит services.jar прошивки устройства, изменяя поведение фреймворка Android. Движок патчей на устройстве написан на Java и использует dexlib2 для перезаписи DEX-байткода внутри services.jar, применяя выбираемые патчи, скрывающие флаги mock-location, разрешающие провайдеры mock-location без настройки разработчика и при необходимости позволяющие делать скриншоты в окнах FLAG_SECURE. Жизненный цикл модуля и логика установки реализованы на shell-скриптах, с WebUI для настройки патчей и поддержкой Android 10–17. Продолжает линейку Smali Patcher для пользователей Android с root-доступом и исследователей безопасности, которым нужно обходить проверки на основе геолокации и ограничения защищённых окон при анализе мобильных приложений и игр.
