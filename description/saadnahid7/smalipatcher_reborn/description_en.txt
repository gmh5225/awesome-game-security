Smali Patcher Reborn is a Magisk, KernelSU, and APatch module that patches the device ROM's services.jar at install time to alter Android framework behavior. The on-device patch engine is written in Java and uses dexlib2 to rewrite DEX bytecode inside services.jar, applying selectable patches that hide mock-location flags, allow mock location providers without the developer setting, and optionally permit screenshots in FLAG_SECURE windows. Module lifecycle and install-time logic are implemented in plain shell scripts, with a WebUI for configuring patches and support for Android 10 through 17. It extends the Smali Patcher lineage for rooted Android users and security researchers who need to bypass location-based checks and secure-window restrictions during mobile app and game analysis.
