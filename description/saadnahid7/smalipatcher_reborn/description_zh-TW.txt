Smali Patcher Reborn 是一個 Magisk、KernelSU 與 APatch 模組，在安裝時修補裝置 ROM 中的 services.jar，以變更 Android 框架行為。裝置端修補引擎以 Java 撰寫，使用 dexlib2 重寫 services.jar 內的 DEX 位元組碼，套用可選修補以隱藏模擬位置旗標、允許在不開啟開發人員選項的情況下使用模擬位置提供者，並可選擇允許在 FLAG_SECURE 視窗中截圖。模組生命週期與安裝時邏輯以純 shell 腳本實作，提供 WebUI 用於設定修補，並支援 Android 10 至 17。它延續 Smali Patcher 系列，面向需要繞過位置相關檢查與安全視窗限制以進行行動應用與遊戲分析的有 root 權限 Android 使用者及安全研究人員。
