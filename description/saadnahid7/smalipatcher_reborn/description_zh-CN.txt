Smali Patcher Reborn 是一个 Magisk、KernelSU 和 APatch 模块，在安装时修补设备 ROM 中的 services.jar，以修改 Android 框架行为。设备端补丁引擎用 Java 编写，使用 dexlib2 重写 services.jar 内的 DEX 字节码，应用可选补丁以隐藏模拟位置标志、允许在不开启开发者选项的情况下使用模拟位置提供者，并可选择允许在 FLAG_SECURE 窗口中截屏。模块生命周期与安装时逻辑由纯 shell 脚本实现，提供 WebUI 用于配置补丁，并支持 Android 10 至 17。它延续了 Smali Patcher 系列，面向需要绕过基于位置的检测与安全窗口限制以进行移动应用与游戏分析的有 root 权限 Android 用户及安全研究人员。
