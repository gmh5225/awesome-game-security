FortniteMCP 是一款可注入的 Windows DLL，在離線或私有的 Unreal Engine 遊戲建置程序內執行 Model Context Protocol 伺服器，讓 MCP 用戶端與程式設計代理能自動化研究與測試。專案主要以 C++20 與 MSVC 開發，透過 MinHook 於遊戲執行緒派工，並提供記憶體讀寫與特徵掃描、UE 反射與 ProcessEvent 呼叫、模擬鍵盤滑鼠輸入，以及經身分驗證的本機回環 HTTP 或 stdio 橋接選擇性載入輔助 DLL 等工具。依建置客製的設定以及面向 Fortnite 或 UE6 的屬性解碼器，支援走訪混淆後的配置、解析全域變數並於執行時調整版面。配套的以 Python 與 mitmproxy 為基礎的 HTTP MCP 伺服器可擷取並重放 HTTPS 流量，供 API 研究使用，與遊戲內工具相輔相成。本專案鎖定遊戲安全分析師、逆向工程師與測試人員，在受控本機環境中對其擁有的 Unreal 遊戲進行代理驅動的檢查。
