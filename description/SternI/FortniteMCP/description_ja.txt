FortniteMCP は、オフラインまたは非公開の Unreal Engine ゲームビルド内でインプロセスの Model Context Protocol サーバーを動かす注入可能な Windows DLL であり、MCP クライアントやコーディングエージェントが調査とテストを自動化できるようにします。主に C++20 と MSVC で実装され、MinHook によるゲームスレッド上のディスパッチを用い、メモリの読み書きとパターンスキャン、UE リフレクションと ProcessEvent 呼び出し、キーボード・マウス入力のシミュレーション、認証付きループバック HTTP または stdio ブリッジ経由のオプションのヘルパー DLL 読み込みなどのツールを公開します。ビルド固有の設定と Fortnite または UE6 向けプロパティデコーダにより、難読化されたレイアウトの走査、グローバルの解決、実行時のレイアウト調整をサポートします。Python と mitmproxy ベースの HTTP MCP サーバーコンパニオンは HTTPS トラフィックのキャプチャと再生により API 調査を行い、ゲーム内ツールと併用できます。本プロジェクトは、管理されたローカル環境で自ら所有する Unreal ゲームをエージェント主導で検査する必要があるゲームセキュリティアナリスト、リバースエンジニア、テスターを対象としています。
