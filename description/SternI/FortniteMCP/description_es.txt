FortniteMCP es una DLL inyectable de Windows que ejecuta un servidor Model Context Protocol en proceso dentro de compilaciones de juegos Unreal Engine offline o privadas, para que clientes MCP y agentes de codificación puedan automatizar investigación y pruebas. Está construida principalmente en C++20 con MSVC, usa MinHook para el despacho en el hilo del juego y expone herramientas de lectura y escritura de memoria con escaneo de patrones, reflexión de UE y llamadas a ProcessEvent, entrada simulada de teclado y ratón, y carga opcional de DLL auxiliares mediante HTTP en loopback autenticado o un puente stdio. La configuración específica de cada build y decodificadores de propiedades orientados a Fortnite o UE6 permiten recorrer diseños ofuscados, resolver globales y ajustar layouts en tiempo de ejecución. Un servidor HTTP MCP complementario basado en Python y mitmproxy captura y reproduce tráfico HTTPS para investigación de API junto con las herramientas en el juego. El proyecto está dirigido a analistas de seguridad de juegos, ingenieros inversos y testers que necesitan inspección guiada por agentes de juegos Unreal que poseen en entornos locales controlados.
