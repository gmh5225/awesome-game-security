FortniteMCP is an in-process Model Context Protocol server that runs inside an offline Unreal Engine game process and exposes a local endpoint for tooling and coding agents. It is implemented primarily in C++20 for Windows x64 with CMake and MSVC, using MinHook for engine hooks and vendored JSON libraries, and includes a Python mitmproxy-based HTTP MCP sidecar for HTTPS API traffic capture and replay. Core capabilities include memory read and write with pattern scanning and patches, Unreal reflection and ProcessEvent calls, game-thread dispatch, simulated keyboard and mouse input, build-specific layout decoding for Fortnite and UE6, and optional helper DLL loading. The project targets game security research, reverse engineering, and automated testing on private builds the operator controls, with loopback HTTP and a stdio bridge so standard MCP clients can inspect and drive the running game safely on the local machine.
