FortniteMCP is an injectable Windows DLL that runs an in-process Model Context Protocol server inside offline or private Unreal Engine game builds so MCP clients and coding agents can automate research and testing. It is built primarily in C++20 with MSVC, uses MinHook for game-thread dispatch, and exposes tools for memory read and write with pattern scanning, UE reflection and ProcessEvent calls, simulated keyboard and mouse input, and optional helper DLL loading over authenticated loopback HTTP or a stdio bridge. Build-specific configuration and Fortnite or UE6-oriented property decoders support walking obfuscated layouts, resolving globals, and tuning layouts at runtime. A companion Python mitmproxy-based HTTP MCP server captures and replays HTTPS traffic for API research alongside the in-game tooling. The project targets game security analysts, reverse engineers, and testers who need agent-driven inspection of Unreal games they own in controlled local environments.
