FortniteMCP — инжектируемая Windows DLL, которая запускает внутрипроцессный сервер Model Context Protocol в офлайн- или приватных сборках игр на Unreal Engine, чтобы клиенты MCP и кодинг-агенты могли автоматизировать исследование и тестирование. Проект в основном написан на C++20 с MSVC, использует MinHook для диспетчеризации в игровом потоке и предоставляет инструменты чтения и записи памяти с поиском по шаблонам, UE reflection и вызовы ProcessEvent, эмуляцию ввода с клавиатуры и мыши, а также опциональную загрузку вспомогательных DLL через аутентифицированный loopback HTTP или stdio-мост. Конфигурация под конкретную сборку и декодеры свойств для Fortnite или UE6 поддерживают обход обфусцированных раскладок, разрешение глобалов и настройку layout во время выполнения. Сопутствующий HTTP MCP-сервер на Python и mitmproxy перехватывает и воспроизводит HTTPS-трафик для исследования API наряду с внутриигровыми средствами. Проект ориентирован на аналитиков игровой безопасности, реверс-инженеров и тестировщиков, которым нужна агент-управляемая инспекция принадлежащих им игр на Unreal в контролируемых локальных средах.
