FortniteMCP는 오프라인 또는 비공개 Unreal Engine 게임 빌드 안에서 인프로세스 Model Context Protocol 서버를 실행하는 주입 가능한 Windows DLL로, MCP 클라이언트와 코딩 에이전트가 연구와 테스트를 자동화할 수 있게 합니다. 주로 C++20과 MSVC로 작성되었으며 MinHook으로 게임 스레드 디스패치를 사용하고, 메모리 읽기·쓰기와 패턴 스캔, UE 리플렉션 및 ProcessEvent 호출, 키보드·마우스 입력 시뮬레이션, 인증된 루프백 HTTP 또는 stdio 브리지를 통한 선택적 헬퍼 DLL 로딩 등의 도구를 제공합니다. 빌드별 구성과 Fortnite 또는 UE6 지향 속성 디코더는 난독화된 레이아웃 순회, 전역 심볼 해석, 런타임 레이아웃 조정을 지원합니다. Python mitmproxy 기반 HTTP MCP 서버 동반 프로젝트는 HTTPS 트래픽을 캡처·재생하여 API 연구를 수행하며 인게임 도구와 병행할 수 있습니다. 이 프로젝트는 통제된 로컬 환경에서 자신이 소유한 Unreal 게임을 에이전트 기반으로 검사해야 하는 게임 보안 분석가, 리버스 엔지니어, 테스터를 대상으로 합니다.
