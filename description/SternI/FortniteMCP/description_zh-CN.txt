FortniteMCP 是一款可注入的 Windows DLL，在离线或私有的 Unreal Engine 游戏构建进程内运行 Model Context Protocol 服务器，使 MCP 客户端与编程智能体能够自动化研究与测试。项目主要使用 C++20 与 MSVC 编写，借助 MinHook 在游戏线程上调度，并提供内存读写与特征扫描、UE 反射与 ProcessEvent 调用、模拟键盘鼠标输入，以及通过经身份验证的本地回环 HTTP 或 stdio 桥接可选加载辅助 DLL 等工具。按构建定制的配置以及面向 Fortnite 或 UE6 的属性解码器，支持遍历混淆布局、解析全局变量并在运行时调整布局。配套的基于 Python 与 mitmproxy 的 HTTP MCP 服务器可捕获并重放 HTTPS 流量，用于 API 研究，与游戏内工具互补。该项目面向游戏安全分析人员、逆向工程师与测试人员，在受控本地环境中对他们所拥有的 Unreal 游戏进行智能体驱动的检查。
