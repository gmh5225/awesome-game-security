FortniteMCP è una DLL Windows iniettabile che esegue un server Model Context Protocol in-process all’interno di build di giochi Unreal Engine offline o private, così che client MCP e agenti di codifica possano automatizzare ricerca e test. È realizzata principalmente in C++20 con MSVC, usa MinHook per il dispatch sul thread di gioco ed espone strumenti per lettura e scrittura della memoria con pattern scanning, riflessione UE e chiamate ProcessEvent, input simulato di tastiera e mouse e caricamento opzionale di DLL di supporto tramite HTTP loopback autenticato o un bridge stdio. Configurazione specifica per build e decoder di proprietà orientati a Fortnite o UE6 supportano l’attraversamento di layout offuscati, la risoluzione dei globali e la regolazione dei layout a runtime. Un server HTTP MCP complementare basato su Python e mitmproxy cattura e ripete il traffico HTTPS per la ricerca sulle API insieme agli strumenti in-game. Il progetto è rivolto ad analisti di sicurezza dei giochi, reverse engineer e tester che necessitano di ispezione guidata da agenti di giochi Unreal di loro proprietà in ambienti locali controllati.
