Pointer Lab 是一款 Windows x64 用户态内存研究工具，可附加到正在运行的 64 位进程，扫描内存、跟踪地址，并对其进行读取、写入、冻结、反汇编和补丁修改。该工具使用 C++20 构建，采用 Dear ImGui 停靠窗口界面，包含支持通配符字节模式的多类型内存扫描器、可应对 ASLR 的多级指针链查找器、实时十六进制内存查看、基于 Zydis 的反汇编、基于 Keystone 的汇编以及带安全 NOP 填充的补丁功能、可重复使用的软件断点，以及带确认对话框的 DLL 注入辅助功能。内置的 Lua 5.4 脚本控制台在 UI 线程外运行，用于自动化扫描和内存操作，而 .iretable 项目文件可在多次会话间持久保存地址列表和指针链。它面向逆向工程练习、CTF 竞赛以及对自有软件或单机游戏的授权检查，而非隐蔽操作或在线反作弊规避。
