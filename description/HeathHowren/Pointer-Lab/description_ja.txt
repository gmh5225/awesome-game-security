Pointer Lab は、実行中の 64 ビットプロセスにアタッチしてメモリをスキャンし、アドレスを追跡して読み取り、書き込み、フリーズ、逆アセンブル、パッチを行う Windows x64 ユーザーモードのメモリ研究ツールです。C++20 で構築され、Dear ImGui のドックスペース UI を備え、ワイルドカードバイトパターンに対応した多種類メモリスキャナー、ASLR に耐える多段ポインタチェーン検索、ライブ 16 進メモリ表示、Zydis ベースの逆アセンブル、Keystone ベースのアセンブルと安全な NOP パディング付きパッチ、再利用可能なソフトウェアブレークポイント、確認ダイアログ付きの DLL インジェクション支援機能を含みます。組み込みの Lua 5.4 スクリプトコンソールは UI スレッド外で動作し、スキャンとメモリ操作の自動化に使用されます。.iretable プロジェクトファイルにより、アドレスリストとポインタチェーンをセッション間で永続化できます。リバースエンジニアリングの練習、CTF、自身のソフトウェアやシングルプレイゲームの許可された検査を目的としており、ステルスやオンラインアンチチート回避を目的としたものではありません。
