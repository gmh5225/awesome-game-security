Pointer Lab — это инструмент исследования памяти в пользовательском режиме Windows x64, который подключается к запущенным 64-битным процессам для сканирования памяти, отслеживания адресов, а также их чтения, записи, заморозки, дизасsemblирования и патчинга. Написан на C++20 с интерфейсом dockspace на базе Dear ImGui и включает много типовый сканер памяти с шаблонами байтов с подстановочными символами, многоуровневый поиск цепочек указателей, устойчивый к ASLR, просмотр памяти в шестнадцатеричном виде в реальном времени, дизасsemblирование на базе Zydis, ассемблирование на базе Keystone с безопасным патчингом с NOP-заполнением, повторно используемые программные точки останова и помощники для инъекции DLL с диалогами подтверждения. Встроенная консоль сценариев Lua 5.4 работает вне потока UI для автоматизации сканирования и операций с памятью, а файлы проектов .iretable сохраняют списки адресов и цепочки указателей между сеансами. Предназначен для практики реверс-инжиниринга, работы в CTF и авторизованной проверки собственного ПО или однопользовательских игр, а не для скрытности или обхода онлайн-античитов.
