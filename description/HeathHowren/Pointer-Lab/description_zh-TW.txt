Pointer Lab 是一款 Windows x64 使用者模式記憶體研究工具，可附加至執行中的 64 位元程序，掃描記憶體、追蹤位址，並對其進行讀取、寫入、凍結、反組譯和修補。此工具以 C++20 建構，採用 Dear ImGui 停靠視窗介面，包含支援萬用字元位元組模式的多類型記憶體掃描器、可應對 ASLR 的多層級指標鏈查找器、即時十六進位記憶體檢視、基於 Zydis 的反組譯、基於 Keystone 的組合語言以及附帶安全 NOP 填充的修補功能、可重複使用的軟體中斷點，以及附帶確認對話框的 DLL 注入輔助功能。內建的 Lua 5.4 指令碼主控台在 UI 執行緒外執行，用於自動化掃描和記憶體操作，而 .iretable 專案檔可在多次工作階段間持久保存位址清單和指標鏈。它面向逆向工程練習、CTF 競賽以及對自有軟體或單機遊戲的授權檢查，而非隱蔽操作或線上反作弊規避。
