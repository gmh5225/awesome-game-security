Pointer Lab is a Windows x64 user-mode memory research tool that attaches to running 64-bit processes to scan memory, track addresses, and read, write, freeze, disassemble, and patch them. Built in C++20 with a Dear ImGui dockspace interface, it includes a multi-type memory scanner with wildcard byte patterns, a multi-level pointer chain finder that survives ASLR, live hex memory viewing, Zydis-based disassembly, Keystone-based assembly with safe NOP-padded patching, repeatable software breakpoints, and DLL injection helpers behind confirmation dialogs. An embedded Lua 5.4 scripting console runs off the UI thread for automating scans and memory operations, while .iretable project files persist address lists and pointer chains across sessions. It is aimed at reverse engineering practice, CTF work, and authorized inspection of your own software or single-player games, not stealth or online anti-cheat evasion.
