NoImportz は、Windows カーネルドライバ向けの C++17 ヘッダーライブラリで、実行時にシステム API 関数を解決し、PE インポートテーブルに直接のインポートエントリを残しません。LSTAR MSR から後方にスキャンして ntoskrnl.exe を特定し、PsLoadedModuleList を走査して対象モジュールを見つけ、MmGetSystemRoutineAddress に似た PE ヘッダー解析でエクスポートを解決します。テンプレートベースの呼び出しインターフェースとオプションのハッシュマップキャッシュにより、読み込まれた任意のカーネルモジュール上の可変引数関数をサポートし、カスタムメモリルーチンでコンパイラ生成のインポートを回避します。プロジェクトには、ntoskrnl や ndis.sys などのモジュールに対する使用例を示すサンプル KMDF ドライバが含まれます。手動マップまたはインポートなしのカーネルコードを構築し、ドライバのインポートテーブルを検査するアンチチートやセキュリティソフトウェアへの可視性を下げたい開発者向けです。
