NoImportz — это библиотека заголовков C++17 для драйверов ядра Windows, которая разрешает функции системного API во время выполнения, не оставляя прямых записей в таблице импорта PE. Она находит ntoskrnl.exe, сканируя назад от MSR LSTAR, обходит PsLoadedModuleList для поиска целевых модулей и разрешает экспорты через разбор заголовка PE, аналогично MmGetSystemRoutineAddress. Шаблонный интерфейс вызова с необязательным кэшированием в хеш-таблице поддерживает функции с переменным числом аргументов в любом загруженном модуле ядра, а пользовательские процедуры работы с памятью позволяют избежать импортов, генерируемых компилятором. В проект входит пример драйвера KMDF, демонстрирующий использование с ntoskrnl и другими модулями, такими как ndis.sys. Предназначен для разработчиков, создающих вручную отображаемый или не использующий импорты код ядра и стремящихся снизить видимость для античит-систем и программ безопасности, проверяющих таблицы импорта драйверов.
