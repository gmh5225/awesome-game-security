NoImportz es una biblioteca de encabezados C++17 para controladores de kernel de Windows que resuelve funciones de la API del sistema en tiempo de ejecución sin dejar entradas directas en la tabla de importación PE. Localiza ntoskrnl.exe escaneando hacia atrás desde el MSR LSTAR, recorre PsLoadedModuleList para encontrar módulos objetivo y resuelve exportaciones mediante el análisis del encabezado PE, de forma similar a MmGetSystemRoutineAddress. Una interfaz de llamada basada en plantillas con caché opcional de mapa hash admite funciones variádicas en cualquier módulo de kernel cargado, mientras que rutinas de memoria personalizadas evitan importaciones generadas por el compilador. El proyecto incluye un controlador KMDF de ejemplo que demuestra su uso con ntoskrnl y otros módulos como ndis.sys. Está dirigido a desarrolladores que crean código de kernel mapeado manualmente o sin importaciones y necesitan reducir la visibilidad ante software antitrampas y de seguridad que inspecciona las tablas de importación de controladores.
