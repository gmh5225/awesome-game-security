NoImportz 是一個面向 Windows 核心驅動程式的 C++17 標頭函式庫，可在執行階段解析系統 API 函式，且不會在 PE 匯入表中留下直接的匯入項目。它透過從 LSTAR MSR 向後掃描來定位 ntoskrnl.exe，走訪 PsLoadedModuleList 尋找目標模組，並透過類似 MmGetSystemRoutineAddress 的 PE 標頭解析來解析匯出函式。以範本為基礎的呼叫介面支援可選的雜湊對應快取，可呼叫任意已載入核心模組中的可變參數函式，同時自訂記憶體例程避免編譯器產生匯入。專案包含一個範例 KMDF 驅動程式，示範如何針對 ntoskrnl 及 ndis.sys 等模組使用。面向需要建構手動對映或無匯入核心程式碼、並希望降低被反作弊與安全軟體透過驅動程式匯入表偵測可見性的開發者。
