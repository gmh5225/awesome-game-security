NoImportz est une bibliothèque d'en-têtes C++17 pour les pilotes noyau Windows qui résout les fonctions API système à l'exécution sans laisser d'entrées directes dans la table d'importation PE. Elle localise ntoskrnl.exe en scannant vers l'arrière depuis le MSR LSTAR, parcourt PsLoadedModuleList pour trouver les modules cibles et résout les exports via l'analyse de l'en-tête PE, de manière similaire à MmGetSystemRoutineAddress. Une interface d'appel basée sur des modèles avec mise en cache optionnelle par table de hachage prend en charge les fonctions variadiques de tout module noyau chargé, tandis que des routines mémoire personnalisées évitent les importations générées par le compilateur. Le projet inclut un pilote KMDF d'exemple illustrant l'utilisation avec ntoskrnl et d'autres modules tels que ndis.sys. Il s'adresse aux développeurs qui créent du code noyau mappé manuellement ou sans importations et souhaitent réduire leur visibilité pour les logiciels anti-triche et de sécurité qui inspectent les tables d'importation des pilotes.
