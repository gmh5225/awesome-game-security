NoImportz è una libreria header C++17 per driver kernel Windows che risolve le funzioni API di sistema a runtime senza lasciare voci dirette nella tabella di importazione PE. Individua ntoskrnl.exe scansionando all'indietro a partire dall'MSR LSTAR, attraversa PsLoadedModuleList per trovare i moduli target e risolve le export tramite l'analisi dell'header PE, in modo simile a MmGetSystemRoutineAddress. Un'interfaccia di chiamata basata su template con caching opzionale tramite hash map supporta funzioni variadiche su qualsiasi modulo kernel caricato, mentre routine di memoria personalizzate evitano import generati dal compilatore. Il progetto include un driver KMDF di esempio che dimostra l'utilizzo con ntoskrnl e altri moduli come ndis.sys. È rivolto a sviluppatori che creano codice kernel mappato manualmente o privo di import e devono ridurre la visibilità verso software anti-cheat e di sicurezza che ispezionano le tabelle di importazione dei driver.
