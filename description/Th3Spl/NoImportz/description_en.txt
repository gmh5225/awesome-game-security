NoImportz is a C++17 header library for Windows kernel drivers that resolves system API functions at runtime without leaving direct PE import table entries. It locates ntoskrnl.exe by scanning backward from the LSTAR MSR, walks PsLoadedModuleList to find target modules, and resolves exports through PE header parsing similar to MmGetSystemRoutineAddress. A template-based call interface with optional hash-map caching supports variadic functions across any loaded kernel module, while custom memory routines avoid compiler-generated imports. The project includes a sample KMDF driver demonstrating usage against ntoskrnl and other modules such as ndis.sys. It is aimed at developers building manually mapped or import-free kernel code who need to reduce visibility to anti-cheat and security software that inspect driver import tables.
