NoImportz는 Windows 커널 드라이버용 C++17 헤더 라이브러리로, 런타임에 시스템 API 함수를 해석하면서 PE 임포트 테이블에 직접적인 임포트 항목을 남기지 않습니다. LSTAR MSR에서 역방향으로 스캔하여 ntoskrnl.exe를 찾고, PsLoadedModuleList를 순회해 대상 모듈을 찾으며, MmGetSystemRoutineAddress와 유사한 PE 헤더 파싱으로 내보내기를 해석합니다. 템플릿 기반 호출 인터페이스와 선택적 해시맵 캐싱은 로드된 모든 커널 모듈의 가변 인수 함수를 지원하며, 사용자 정의 메모리 루틴으로 컴파일러가 생성한 임포트를 피합니다. 프로젝트에는 ntoskrnl 및 ndis.sys 등 다른 모듈에 대한 사용 예를 보여 주는 샘플 KMDF 드라이버가 포함되어 있습니다. 수동 매핑 또는 임포트 없는 커널 코드를 작성하고, 드라이버 임포트 테이블을 검사하는 안티치트 및 보안 소프트웨어에 대한 가시성을 줄여야 하는 개발자를 대상으로 합니다.
