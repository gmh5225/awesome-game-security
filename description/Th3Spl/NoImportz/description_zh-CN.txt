NoImportz 是一个面向 Windows 内核驱动的 C++17 头文件库，可在运行时解析系统 API 函数，且不会在 PE 导入表中留下直接的导入项。它通过从 LSTAR MSR 向后扫描来定位 ntoskrnl.exe，遍历 PsLoadedModuleList 查找目标模块，并通过类似 MmGetSystemRoutineAddress 的 PE 头解析来解析导出函数。基于模板的调用接口支持可选的哈希映射缓存，可调用任意已加载内核模块中的可变参数函数，同时自定义内存例程避免编译器生成导入。项目包含一个示例 KMDF 驱动，演示如何针对 ntoskrnl 及 ndis.sys 等模块使用。面向需要构建手动映射或无导入内核代码、并希望降低被反作弊与安全软件通过驱动导入表检测可见性的开发者。
