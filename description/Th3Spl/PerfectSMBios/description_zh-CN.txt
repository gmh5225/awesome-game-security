PerfectSMBios 是一款轻量级 UEFI 库，可在操作系统加载之前读取并伪造 SMBIOS 固件表。该库使用 C 语言编写，可通过 VisualUefi 或 EDK2 构建，通过 EFI 配置表定位 SMBIOS 2.0 和 3.0 入口点，并提供辅助函数以查找特定结构类型、读取字符串字段，并用随机 ASCII 值覆盖它们。与许多 SMBIOS 伪造工具不同，它避免依赖 Windows 内核组件（如 ntoskrnl.exe 或 winload.efi），可在 Windows 和 Linux 上稳定运行。附带的示例会修改系统制造商字符串，可复用的头文件可直接集成到自定义 UEFI 项目中，用于硬件指纹规避、反作弊研究和底层逆向工程。
