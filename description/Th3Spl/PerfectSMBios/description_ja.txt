PerfectSMBios は、オペレーティングシステムの読み込み前に SMBIOS ファームウェアテーブルを読み取り、偽装するための軽量 UEFI ライブラリです。C 言語で記述され、VisualUefi または EDK2 でビルドされ、EFI 構成テーブルを通じて SMBIOS 2.0 および 3.0 のエントリポイントを特定し、特定の構造タイプの検索、文字列フィールドの読み取り、ランダム化された ASCII 値による上書きを行うヘルパーを提供します。多くの SMBIOS 偽装ツールとは異なり、ntoskrnl.exe や winload.efi などの Windows カーネル依存を避け、Windows と Linux の両方で問題なく動作します。同梱のサンプルはシステム製造元文字列を変更し、再利用可能なヘッダーはカスタム UEFI プロジェクトに組み込んで、ハードウェアフィンガープリント回避、アンチチート研究、低レベルリバースエンジニアリングに利用できます。
