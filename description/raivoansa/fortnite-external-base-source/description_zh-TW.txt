此專案是一個面向 Fortnite 的 C++ 外部作弊基座，透過獨立的使用者模式程序讀取遊戲記憶體，而非注入到遊戲中。它透過 IOCTL 與核心驅動程式通訊，實現實體記憶體讀寫、程序基址解析與滑鼠輸入，並包含可選的面向 EAC 的處理。遊戲狀態透過 SDK 偏移、GWorld 解密、骨骼與攝影機運算以及特徵碼掃描還原，再經由 ImGui 在 Discord Overlay / DirectX 11 表面上繪製為 ESP（例如依可見性著色的 2D 方框）。作為 Visual Studio Windows 解決方案建置，主要用於學習外部作弊架構、核心輔助記憶體存取以及與反作弊相關的逆向工程技術。
