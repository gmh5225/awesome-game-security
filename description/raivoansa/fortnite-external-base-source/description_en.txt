This project is a C++ external cheat base for Fortnite that reads game memory from a separate user-mode process rather than injecting into the game. It communicates with a kernel driver over IOCTLs for physical memory read/write, process base resolution, and mouse input, including optional EAC-oriented handling. Game state is recovered through SDK offsets, GWorld decryption, bone and camera math, and pattern scanning, then rendered as ESP (such as visibility-colored 2D boxes) via ImGui on a Discord Overlay / DirectX 11 surface. Built as a Visual Studio Windows solution, it is mainly useful for studying external cheat architectures, kernel-assisted memory access, and anti-cheat related reverse-engineering techniques.
