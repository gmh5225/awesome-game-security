Questo progetto è una base cheat esterna in C++ per Fortnite che legge la memoria di gioco da un processo user-mode separato invece di iniettarsi nel gioco. Comunica con un driver kernel tramite IOCTL per lettura/scrittura della memoria fisica, risoluzione della base del processo e input del mouse, inclusa una gestione opzionale orientata a EAC. Lo stato di gioco viene recuperato tramite offset SDK, decrittazione di GWorld, calcoli di ossa e camera e pattern scanning, poi reso come ESP (ad esempio box 2D colorati in base alla visibilità) tramite ImGui su una superficie Discord Overlay / DirectX 11. Realizzato come soluzione Visual Studio per Windows, è utile soprattutto per studiare architetture di cheat esterni, accesso alla memoria assistito dal kernel e tecniche di reverse engineering legate all'anti-cheat.
