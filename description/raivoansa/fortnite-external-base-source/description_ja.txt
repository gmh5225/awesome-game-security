本プロジェクトは Fortnite 向けの C++ 外部チートベースであり、ゲームへの注入ではなく、別のユーザーモードプロセスからゲームメモリを読み取ります。IOCTL 経由でカーネルドライバと通信し、物理メモリの読み書き、プロセスベース解決、マウス入力を行い、EAC 向けのオプション処理も含みます。ゲーム状態は SDK オフセット、GWorld 復号、ボーンとカメラの計算、パターンスキャンによって復元され、Discord Overlay / DirectX 11 上の ImGui で ESP（可視性に応じて色分けされた 2D ボックスなど）として描画されます。Visual Studio の Windows ソリューションとして構築されており、主に外部チートアーキテクチャ、カーネル支援のメモリアクセス、アンチチート関連のリバースエンジニアリング手法の学習に役立ちます。
