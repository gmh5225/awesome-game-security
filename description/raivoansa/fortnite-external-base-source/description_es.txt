Este proyecto es una base de cheat externo en C++ para Fortnite que lee la memoria del juego desde un proceso de usuario separado en lugar de inyectarse en el juego. Se comunica con un controlador de kernel mediante IOCTLs para lectura/escritura de memoria física, resolución de la base del proceso y entrada del ratón, incluyendo un manejo opcional orientado a EAC. El estado del juego se recupera mediante offsets del SDK, descifrado de GWorld, cálculos de huesos y cámara, y pattern scanning, y luego se renderiza como ESP (por ejemplo, cajas 2D coloreadas según la visibilidad) con ImGui sobre una superficie Discord Overlay / DirectX 11. Construido como una solución Visual Studio para Windows, es útil principalmente para estudiar arquitecturas de cheats externos, acceso a memoria asistido por el kernel y técnicas de ingeniería inversa relacionadas con anti-cheat.
