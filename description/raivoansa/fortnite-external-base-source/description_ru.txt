Этот проект — база внешнего чита на C++ для Fortnite, которая читает память игры из отдельного пользовательского процесса, а не внедряется в игру. Она взаимодействует с драйвером ядра через IOCTL для чтения/записи физической памяти, определения базы процесса и ввода мыши, включая опциональную обработку, ориентированную на EAC. Состояние игры восстанавливается через SDK-оффсеты, расшифровку GWorld, вычисления костей и камеры и поиск по сигнатурам, затем отрисовывается как ESP (например, 2D-боксы с окраской по видимости) через ImGui на поверхности Discord Overlay / DirectX 11. Собран как решение Visual Studio для Windows и в основном полезен для изучения архитектур внешних читов, доступа к памяти с помощью ядра и техник реверс-инжиниринга, связанных с античитами.
