이 프로젝트는 Fortnite용 C++ 외부 치트 베이스로, 게임에 주입하지 않고 별도의 사용자 모드 프로세스에서 게임 메모리를 읽습니다. IOCTL을 통해 커널 드라이버와 통신하여 물리 메모리 읽기/쓰기, 프로세스 베이스 해석, 마우스 입력을 수행하며, 선택적으로 EAC 관련 처리도 포함합니다. 게임 상태는 SDK 오프셋, GWorld 복호화, 본 및 카메라 연산, 패턴 스캔으로 복원한 뒤, Discord Overlay / DirectX 11 표면의 ImGui로 ESP(가시성에 따라 색칠된 2D 박스 등)로 렌더링합니다. Visual Studio Windows 솔루션으로 구축되었으며, 주로 외부 치트 아키텍처, 커널 보조 메모리 접근, 안티치트 관련 리버스 엔지니어링 기법 학습에 유용합니다.
