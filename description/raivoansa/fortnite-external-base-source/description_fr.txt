Ce projet est une base de cheat externe en C++ pour Fortnite qui lit la mémoire du jeu depuis un processus utilisateur séparé plutôt que d'injecter dans le jeu. Il communique avec un pilote noyau via des IOCTL pour la lecture/écriture de mémoire physique, la résolution de la base du processus et l'entrée souris, avec une gestion optionnelle orientée EAC. L'état du jeu est récupéré via des offsets SDK, le décryptage de GWorld, les calculs d'os et de caméra, et le pattern scanning, puis rendu en ESP (notamment des boîtes 2D colorées selon la visibilité) via ImGui sur une surface Discord Overlay / DirectX 11. Construit comme une solution Visual Studio Windows, il est surtout utile pour étudier les architectures de cheats externes, l'accès mémoire assisté par le noyau et les techniques de reverse-engineering liées à l'anti-cheat.
