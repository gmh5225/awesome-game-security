Dieses Projekt ist eine C++-External-Cheat-Basis für Fortnite, die den Spielspeicher aus einem separaten User-Mode-Prozess liest, statt in das Spiel zu injizieren. Es kommuniziert über IOCTLs mit einem Kernel-Treiber für physisches Speicherlesen/-schreiben, Prozessbasisauflösung und Mauseingabe, einschließlich optionaler EAC-orientierter Behandlung. Der Spielzustand wird über SDK-Offsets, GWorld-Entschlüsselung, Knochen- und Kameraberechnungen sowie Pattern Scanning wiederhergestellt und als ESP (etwa sichtbarkeitsgefärbte 2D-Boxen) über ImGui auf einer Discord-Overlay-/DirectX-11-Oberfläche gerendert. Als Visual-Studio-Windows-Lösung gebaut, eignet es sich vor allem zum Studium externer Cheat-Architekturen, kernelunterstützten Speicherzugriffs und Anti-Cheat-bezogener Reverse-Engineering-Techniken.
