本项目提供针对 Unreal Engine 4.27 上经 Themida 壳保护的 KartRider Drift 客户端定制的 UE4SS 4.0.0 补丁构建，使脚本注入器与模组加载器能在受保护的正式版二进制文件上稳定运行。项目文档化并附带 Rust 实现的 pattern sleuth 边界检查补丁、单字节 DllMain 控制流修复指南，以及 MSVC、CMake 与 Ninja 的构建说明。配套的 pktcap 组件以 C++ 编写，挂钩 Winsock 的发送与接收 API（含重叠 I/O），并提供用于 DLL 注入与 PCAP 风格转储解析的 Python 工具。面向需要在加壳 PE 上稳定使用 UE4SS、进行 SDK 或 Lua 模组开发，以及抓取客户端—服务端协议以供分析的反汇编工程师与游戏安全研究人员。
