本プロジェクトは、Unreal Engine 4.27 上で Themida パックされた KartRider Drift クライアント向けに調整した UE4SS 4.0.0 のパッチ済みビルドを提供し、保護された shipping バイナリに対してスクリプトインジェクタや mod ローダーが安定して動作できるようにします。Rust による pattern sleuth の bounds-check パッチ、1 バイトの DllMain 制御フロー修正の手順、MSVC・CMake・Ninja のビルド手順を文書化して同梱しています。C++ で書かれた同伴の pktcap コンポーネントは Winsock の送受信 API（オーバーラップ I/O を含む）をフックし、DLL インジェクションと PCAP 形式ダンプ解析用の Python ユーティリティも備えています。パックされた PE 上で UE4SS を安定利用し、SDK や Lua による mod 開発、分析向けのクライアント—サーバープロトコルキャプチャが必要なリバースエンジニアやゲームセキュリティ研究者向けです。
