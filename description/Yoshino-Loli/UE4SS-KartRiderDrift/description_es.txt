Este proyecto ofrece una compilación UE4SS 4.0.0 parcheada, adaptada al cliente KartRider Drift empaquetado con Themida en Unreal Engine 4.27, para que inyectores de scripts y cargadores de mods funcionen de forma fiable frente a un binario shipping protegido. Documenta y distribuye un parche de comprobación de límites pattern sleuth en Rust, orientación para una corrección de flujo de control DllMain de un byte, y notas de compilación para MSVC, CMake y Ninja. Un componente pktcap complementario en C++ engancha las API Winsock de envío y recepción (incluida E/S superpuesta), con utilidades Python para inyección de DLL y análisis de volcados al estilo PCAP. Está dirigido a ingenieros inversos e investigadores de seguridad en juegos que necesitan UE4SS estable en PE empaquetados, modding con SDK o Lua, y captura de protocolo cliente-servidor para análisis.
