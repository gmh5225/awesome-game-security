이 프로젝트는 Unreal Engine 4.27에서 Themida로 패킹된 KartRider Drift 클라이언트에 맞춘 UE4SS 4.0.0 패치 빌드를 제공하여, 보호된 shipping 바이너리에 대해 스크립트 인젝터와 mod 로더가 안정적으로 동작하도록 합니다. Rust로 작성된 pattern sleuth bounds-check 패치, 1바이트 DllMain 제어 흐름 수정 가이드, MSVC·CMake·Ninja 빌드 참고 사항을 문서화하여 함께 제공합니다. C++로 작성된 pktcap 동반 컴포넌트는 Winsock 송수신 API(겹침 I/O 포함)를 후킹하며, DLL 인젝션과 PCAP 스타일 덤프 파싱용 Python 유틸리티를 포함합니다. 패킹된 PE에서 UE4SS를 안정적으로 쓰고, SDK 또는 Lua modding, 분석용 클라이언트—서버 프로토콜 캡처가 필요한 리버스 엔지니어와 게임 보안 연구자를 위한 프로젝트입니다.
