This project provides a patched UE4SS 4.0.0 build tailored for the Themida-packed KartRider Drift client on Unreal Engine 4.27, so script injectors and mod loaders can run reliably against a protected shipping binary. It documents and ships a pattern sleuth bounds-check patch in Rust, guidance for a one-byte DllMain control-flow fix, and build notes for MSVC, CMake, and Ninja. A companion pktcap component written in C++ hooks Winsock send and receive APIs (including overlapped I/O), with Python utilities for DLL injection and PCAP-style dump parsing. It is aimed at reverse engineers and game-security researchers who need stable UE4SS on packed PEs, SDK or Lua modding, and client-server protocol capture for analysis.
