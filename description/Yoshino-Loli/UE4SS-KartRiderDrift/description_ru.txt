Проект предоставляет пропатченную сборку UE4SS 4.0.0, адаптированную для клиента KartRider Drift с упаковкой Themida на Unreal Engine 4.27, чтобы инжекторы скриптов и загрузчики модов стабильно работали с защищённым shipping-бинарником. В документации и составе поставки — патч проверки границ pattern sleuth на Rust, руководство по однобайтовому исправлению потока управления DllMain и заметки по сборке с MSVC, CMake и Ninja. Сопутствующий компонент pktcap на C++ перехватывает API Winsock для отправки и приёма (включая overlapped I/O), с утилитами на Python для инъекции DLL и разбора дампов в стиле PCAP. Ориентирован на реверс-инженеров и исследователей безопасности игр, которым нужен стабильный UE4SS на упакованных PE, моддинг через SDK или Lua и захват клиент—серверного протокола для анализа.
