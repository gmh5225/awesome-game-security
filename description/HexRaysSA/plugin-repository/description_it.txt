Questo è l'indice ufficiale curato per scoprire, installare e condividere plugin per IDA Pro, che alimenta il catalogo pubblico dei plugin e il Plugin Manager integrato in IDA. Mantiene manifest JSON leggibili da macchina dei plugin scoperti, insieme a metadati come versioni, categorie, licenze e informazioni sulle release, aggiornati automaticamente da un job di sincronizzazione periodico su GitHub Actions. Strumenti Python uniscono i dati dei plugin, specchiano archivi, generano siti di documentazione e producono log dell'indicizzatore e riepiloghi delle modifiche per i maintainer. Il repository traccia esplicitamente le fonti di plugin note e ignorate e supporta gli autori con standard di packaging e linting tramite la CLI Hex-Rays. È rivolto a reverse engineer, analisti di malware e ricercatori di sicurezza che estendono IDA per disassemblaggio, decompilazione, automazione e flussi di analisi di terze parti.
