Este es el índice oficial curado para descubrir, instalar y compartir complementos de IDA Pro, que impulsa el catálogo público de complementos y el administrador de complementos integrado de IDA. Mantiene manifiestos JSON legibles por máquina de los complementos descubiertos, junto con metadatos como versiones, categorías, licencias e información de lanzamiento, actualizados automáticamente mediante una tarea periódica de sincronización de GitHub Actions. Las herramientas en Python fusionan datos de complementos, reflejan archivos, generan sitios de documentación y producen registros del indexador y resúmenes de cambios para los mantenedores. El repositorio rastrea fuentes de complementos explícitamente conocidas e ignoradas, y apoya a los autores con estándares de empaquetado y linting mediante la CLI de Hex-Rays. Está dirigido a ingenieros de ingeniería inversa, analistas de malware e investigadores de seguridad que amplían IDA para desensamblado, decompilación, automatización y flujos de análisis de terceros.
