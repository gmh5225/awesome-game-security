IDA Pro 플러그인을 발견하고 설치하며 공유하기 위한 공식 큐레이션 색인으로, 공개 플러그인 카탈로그와 내장 IDA Plugin Manager를 지원합니다. 발견된 플러그인의 기계 판독 가능 JSON 매니페스트와 버전, 카테고리, 라이선스, 릴리스 정보 등의 메타데이터를 유지하며, 주기적으로 실행되는 GitHub Actions 동기화 작업으로 자동 업데이트됩니다. Python 도구는 플러그인 데이터를 병합하고 아카이브를 미러링하며 문서 사이트를 생성하고, 유지 관리자를 위한 인덱서 로그와 변경 요약을 만듭니다. 이 저장소는 명시적으로 알려진 플러그인 소스와 무시 대상 소스를 추적하며, Hex-Rays CLI를 통한 패키징 표준과 lint 검사로 작성자를 지원합니다. 디스어셈블리, 디컴파일, 자동화 및 서드파티 분석 워크플로를 위해 IDA를 확장하는 리버스 엔지니어, 멀웨어 분석가, 보안 연구자를 대상으로 합니다.
