Este proyecto es un pipeline antitrampas basado en aprendizaje automático para DayZ que recopila telemetría de jugadores del lado del servidor y entrena un clasificador para marcar comportamientos sospechosos. Un script de misión de DayZ registra cada segundo registros DATA_LOG con la posición del jugador, la dirección de la vista, el estado del arma levantada, el arma equipada y la línea de visión basada en raycast hacia el objetivo de puntería más cercano. Scripts de Python de preprocesamiento y entrenamiento convierten esos registros del servidor en características y ajustan un modelo de bosque aleatorio guardado, con perfiles de registro de ejemplo que incluyen sesiones de tramposos conocidos. Está dirigido a operadores de servidores de DayZ e investigadores de seguridad de juegos que exploran la detección basada en datos de trampas tipo aimbot y wallhack.
