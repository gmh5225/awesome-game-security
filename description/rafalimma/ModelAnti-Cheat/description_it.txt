Questo progetto è una pipeline anti-cheat basata sul machine learning per DayZ che raccoglie la telemetria dei giocatori lato server e addestra un classificatore per segnalare comportamenti sospetti. Uno script missione di DayZ registra ogni secondo record DATA_LOG con posizione del giocatore, direzione dello sguardo, stato dell'arma alzata, arma equipaggiata e linea di visuale basata su raycast verso il bersaglio di mira più vicino. Script Python di pre-elaborazione e addestramento trasformano quei log del server in feature e adattano un modello random forest salvato, con profili di log di esempio che includono sessioni di cheater noti. È rivolto agli operatori di server DayZ e ai ricercatori di sicurezza dei giochi che esplorano il rilevamento basato sui dati di cheat tipo aimbot e wallhack.
