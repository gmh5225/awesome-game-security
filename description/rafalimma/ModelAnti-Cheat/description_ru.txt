Этот проект представляет собой конвейер античита на основе машинного обучения для DayZ, который собирает серверную телеметрию игроков и обучает классификатор для выявления подозрительного поведения. Скрипт миссии DayZ каждую секунду записывает записи DATA_LOG с позицией игрока, направлением взгляда, состоянием поднятого оружия, экипированным оружием и линией видимости на основе raycast до ближайшей цели прицеливания. Скрипты предобработки и обучения на Python преобразуют эти серверные логи в признаки и обучают сохранённую модель случайного леса, с примерами профилей логов, включающих известные сессии читеров. Предназначен для операторов серверов DayZ и исследователей игровой безопасности, изучающих обнаружение читов типа aimbot и wallhack на основе данных.
