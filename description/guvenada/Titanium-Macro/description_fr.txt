Titanium Macro Engine est un framework Windows d'automatisation de saisie pour enregistrer, modifier et rejouer des macros clavier et souris avec une précision au niveau noyau. Principalement écrit en Python avec une interface PyQt6, il injecte et capture des événements via un wrapper du pilote Interception, enregistre les trajectoires HID brutes et les scan codes, puis les rejoue avec un timing sous-millisecondes via les compteurs de performance. Il inclut l'humanisation de la souris par courbes de Bézier, le scriptage conditionnel par blocs, la vision écran avec OpenCV, l'OCR via Tesseract, le mappage de coordonnées, les profils et l'enregistrement/rejeu pilotés par raccourcis clavier. Le projet s'adresse aux chercheurs en sécurité de jeux et aux ingénieurs anti-triche étudiant l'automatisation de saisie bas niveau, les outils de macro et la façon dont l'injection d'entrée en mode noyau contourne les API utilisateur standard.
