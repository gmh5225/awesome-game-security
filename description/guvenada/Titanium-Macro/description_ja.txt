Titanium Macro Engine は、Windows 向けの入力自動化フレームワークで、カーネルレベルの精度でキーボードとマウスのマクロを記録、編集、再生できます。主に Python と PyQt6 GUI で書かれており、Interception ドライバーラッパーを通じてイベントを注入・取得し、生の HID 軌跡とスキャンコードを記録し、パフォーマンスカウンターによるサブミリ秒タイミングで再生します。Bezier 曲線によるマウスの人間らしさ付加、ブロックベースの条件付きスクリプト、OpenCV による画面認識、Tesseract による OCR、座標マッピング、プロファイル、ホットキー駆動の記録・再生機能も備えています。本プロジェクトは、低レベル入力自動化、マクロツール、カーネルモード入力注入が標準のユーザーモード API をどのようにバイパスするかを研究する、ゲームセキュリティ研究者およびアンチチートエンジニア向けです。
