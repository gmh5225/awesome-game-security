Titanium Macro Engine è un framework Windows per l'automazione degli input che consente di registrare, modificare e riprodurre macro di tastiera e mouse con precisione a livello kernel. Scritto principalmente in Python con interfaccia PyQt6, inietta e cattura eventi tramite un wrapper del driver Interception, registra traiettorie HID grezze e scan code e le riproduce con tempistica submillisecondo tramite performance counter. Include umanizzazione del mouse con curve di Bézier, scripting condizionale a blocchi, visione dello schermo con OpenCV, OCR tramite Tesseract, mappatura delle coordinate, profili e registrazione/riproduzione guidate da hotkey. Il progetto è rivolto a ricercatori di sicurezza dei giochi e ingegneri anti-cheat che studiano l'automazione degli input a basso livello, gli strumenti macro e come l'iniezione di input in modalità kernel bypassi le API standard in user mode.
