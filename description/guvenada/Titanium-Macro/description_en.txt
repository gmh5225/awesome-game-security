Titanium Macro Engine is a Windows input automation framework for recording, editing, and replaying keyboard and mouse macros with kernel-level precision. Written primarily in Python with a PyQt6 GUI, it injects and captures events through an Interception driver wrapper, records raw HID trajectories and scan codes, and replays them with sub-millisecond timing via performance counters. It adds Bezier-curve mouse humanization, block-based conditional scripting, screen vision with OpenCV, OCR through Tesseract, coordinate mapping, profiles, and hotkey-driven recording and playback. The project is aimed at game security researchers and anti-cheat engineers studying low-level input automation, macro tooling, and how kernel-mode input injection bypasses standard user-mode APIs.
