Titanium Macro Engine es un framework de automatización de entrada para Windows que permite grabar, editar y reproducir macros de teclado y ratón con precisión a nivel de kernel. Escrito principalmente en Python con una interfaz PyQt6, inyecta y captura eventos mediante un wrapper del controlador Interception, registra trayectorias HID en bruto y códigos de escaneo, y las reproduce con temporización submilisegundo mediante contadores de rendimiento. Incorpora humanización del ratón con curvas de Bézier, scripting condicional basado en bloques, visión de pantalla con OpenCV, OCR con Tesseract, mapeo de coordenadas, perfiles y grabación/reproducción controladas por teclas de acceso rápido. El proyecto está dirigido a investigadores de seguridad de juegos e ingenieros de anti-cheat que estudian la automatización de entrada de bajo nivel, las herramientas de macro y cómo la inyección de entrada en modo kernel elude las API estándar de modo usuario.
