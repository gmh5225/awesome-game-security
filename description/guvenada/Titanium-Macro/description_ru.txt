Titanium Macro Engine — это фреймворк автоматизации ввода для Windows для записи, редактирования и воспроизведения макросов клавиатуры и мыши с точностью на уровне ядра. Написан преимущественно на Python с GUI на PyQt6, он внедряет и перехватывает события через обёртку драйвера Interception, записывает сырые HID-траектории и скан-коды и воспроизводит их с субмиллисекундной точностью через счётчики производительности. Поддерживаются гуманизация движений мыши по кривым Безье, блочные условные скрипты, распознавание экрана через OpenCV, OCR через Tesseract, отображение координат, профили и запись/воспроизведение по горячим клавишам. Проект предназначен для исследователей безопасности игр и инженеров античит-систем, изучающих низкоуровневую автоматизацию ввода, инструменты макросов и то, как инъекция ввода в режиме ядра обходит стандартные пользовательские API.
