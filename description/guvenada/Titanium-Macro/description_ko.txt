Titanium Macro Engine은 Windows 입력 자동화 프레임워크로, 커널 수준 정밀도로 키보드와 마우스 매크로를 녹화, 편집, 재생합니다. 주로 Python과 PyQt6 GUI로 작성되었으며, Interception 드라이버 래퍼를 통해 이벤트를 주입하고 캡처하고, 원시 HID 궤적과 스캔 코드를 기록하며, 성능 카운터를 통해 서브밀리초 타이밍으로 재생합니다. Bezier 곡선 마우스 휴머나이제이션, 블록 기반 조건부 스크립팅, OpenCV 화면 비전, Tesseract OCR, 좌표 매핑, 프로필, 단축키 기반 녹화 및 재생 기능을 제공합니다. 이 프로젝트는 게임 보안 연구자와 안티치트 엔지니어가 저수준 입력 자동화, 매크로 도구, 커널 모드 입력 주입이 표준 사용자 모드 API를 우회하는 방식을 연구하기 위한 것입니다.
