Ambiente bootstrap one-stop per sviluppare plugin di script-extender Bethesda ed eseguire reverse engineering a livello motore su Fallout 4, Skyrim e Starfield. Include script di setup PowerShell idempotenti, uno scaffolder di plugin con modelli CMake e vcpkg, e workflow integrati Ghidra e x64dbg collegati via MCP per decompilazione assistita da IA e debug live. Il pacchetto include modelli di plugin C++ F4SE e SFSE collegati a CommonLib, strumenti di importazione della address library e devbench per strumentazione di memoria in-game e render target tramite localhost. I linguaggi principali sono C++ per il codice dei plugin, PowerShell per l'automazione e Python per gli script Ghidra. È rivolto a modder e reverse engineer che necessitano di una toolchain Windows riproducibile per compilare, analizzare e debuggare i binari dei giochi Bethesda.
