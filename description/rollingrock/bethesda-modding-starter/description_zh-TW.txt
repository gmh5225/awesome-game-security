用於開發 Bethesda 腳本擴充器外掛，並對 Fallout 4、Skyrim 和 Starfield 進行引擎層級逆向工程的一站式引導環境。它提供冪等的 PowerShell 安裝腳本、附 CMake 與 vcpkg 範本的外掛腳手架，以及透過 MCP 橋接的 Ghidra 與 x64dbg 整合工作流程，支援 AI 輔助反編譯與即時除錯。此工具包包含連接 CommonLib 的 C++ F4SE 與 SFSE 外掛範本、位址庫匯入工具，以及透過 localhost 進行遊戲內記憶體與渲染目標檢測的 devbench。主要語言為用於外掛程式碼的 C++、用於自動化的 PowerShell，以及用於 Ghidra 腳本的 Python。面向需要可重現 Windows 工具鏈來建置、分析與除錯 Bethesda 遊戲二進位檔的模組開發者與逆向工程師。
