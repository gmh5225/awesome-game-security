Entorno bootstrap integral para desarrollar plugins de script-extender de Bethesda y realizar ingeniería inversa a nivel de motor en Fallout 4, Skyrim y Starfield. Incluye scripts de configuración PowerShell idempotentes, un generador de plugins con plantillas CMake y vcpkg, y flujos integrados de Ghidra y x64dbg conectados vía MCP para descompilación asistida por IA y depuración en vivo. El paquete incluye plantillas de plugins C++ F4SE y SFSE conectadas a CommonLib, herramientas de importación de la biblioteca de direcciones y devbench para instrumentación de memoria en juego y render targets por localhost. Los lenguajes principales son C++ para el código de plugins, PowerShell para automatización y Python para scripts de Ghidra. Está dirigido a desarrolladores de mods e ingenieros de reversa que necesitan una cadena de herramientas Windows reproducible para compilar, analizar y depurar binarios de juegos Bethesda.
