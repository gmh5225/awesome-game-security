Fallout 4、Skyrim、Starfield 向けに Bethesda script-extender プラグインの開発とエンジンレベルのリバースエンジニアリングを行うためのワンストップ ブートストラップ環境。冪等な PowerShell セットアップ スクリプト、CMake と vcpkg テンプレート付きプラグイン スキャフォルダー、MCP 経由で AI 支援の逆コンパイルとライブ デバッグのために橋渡しされた Ghidra および x64dbg ワークフローを同梱。CommonLib に接続された C++ の F4SE および SFSE プラグイン テンプレート、address-library インポート ツール、localhost 経由のゲーム内メモリおよびレンダー ターゲット計測用 devbench を含む。主要言語はプラグイン コード用 C++、自動化用 PowerShell、Ghidra スクリプト用 Python。Bethesda ゲーム バイナリのビルド、解析、デバッグに再現可能な Windows ツールチェーンを必要とする mod 開発者およびリバース エンジニア向け。
