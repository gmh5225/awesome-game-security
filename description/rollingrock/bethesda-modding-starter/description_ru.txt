Единая bootstrap-среда для разработки плагинов Bethesda script-extender и reverse engineering на уровне движка для Fallout 4, Skyrim и Starfield. В комплекте идемпотентные PowerShell-скрипты установки, генератор плагинов с шаблонами CMake и vcpkg, а также интегрированные рабочие процессы Ghidra и x64dbg через MCP для декомпиляции с помощью ИИ и отладки в реальном времени. Пакет включает шаблоны плагинов C++ F4SE и SFSE с подключением к CommonLib, инструменты импорта address library и devbench для инструментирования памяти в игре и render target через localhost. Основные языки: C++ для кода плагинов, PowerShell для автоматизации и Python для скриптов Ghidra. Предназначено для разработчиков модов и reverse engineers, которым нужна воспроизводимая Windows-цепочка инструментов для сборки, анализа и отладки бинарников игр Bethesda.
