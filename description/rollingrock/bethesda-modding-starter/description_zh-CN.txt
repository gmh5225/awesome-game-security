用于开发 Bethesda 脚本扩展器插件，并对 Fallout 4、Skyrim 和 Starfield 进行引擎级逆向工程的一站式引导环境。它提供幂等的 PowerShell 安装脚本、带 CMake 与 vcpkg 模板的插件脚手架，以及通过 MCP 桥接的 Ghidra 与 x64dbg 集成工作流，支持 AI 辅助反编译与实时调试。该工具包包含接入 CommonLib 的 C++ F4SE 与 SFSE 插件模板、地址库导入工具，以及通过 localhost 进行游戏内内存与渲染目标检测的 devbench。主要语言为用于插件代码的 C++、用于自动化的 PowerShell，以及用于 Ghidra 脚本的 Python。面向需要可复现 Windows 工具链来构建、分析与调试 Bethesda 游戏二进制文件的模组开发者与逆向工程师。
