Kiln IDA — нативный плагин для IDA Pro 9.1, который через Model Context Protocol и Streamable HTTP на localhost открывает текущую базу данных для ИИ-ассистентов. Реализован как один модуль Python IDAPython без зависимостей pip и предлагает десятки инструментов для просмотра и навигации по функциям, псевдокоду, ассемблеру, перекрёстным ссылкам, строкам, типам, памяти и отладчику, с опциональной декомпиляцией Hex-Rays и контролируемыми операциями записи: переименования, комментарии, патчи, точки останова и выполнение IDAPython. Сервер переносит работу в главный поток IDA, поддерживает только аппаратные точки останова и режимы трассировки без приостановки для живых целей и может long-poll остановок отладчика, чтобы клиенты интерактивно просматривали сессии. Ориентирован на reverse-инженеров и аналитиков игровой безопасности, которым нужны MCP-совместимые клиенты, включая чат-интеграцию Kiln, работающие напрямую с реальной базой IDA, а не со статическими экспортами.
