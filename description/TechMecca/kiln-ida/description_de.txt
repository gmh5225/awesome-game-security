Kiln IDA ist ein natives IDA-Pro-9.1-Plugin, das die geöffnete Datenbank KI-Assistenten über das Model Context Protocol per Streamable HTTP auf localhost bereitstellt. Es ist als ein einziges Python-IDAPython-Modul ohne pip-Abhängigkeiten implementiert und bietet Dutzende Werkzeuge zum Prüfen und Navigieren von Funktionen, Pseudocode, Assembler, Querverweisen, Strings, Typen, Speicher und Debugger, optional mit Hex-Rays-Dekompilierung und abgesicherten Schreiboperationen wie Umbenennungen, Kommentaren, Patches, Breakpoints und IDAPython-Ausführung. Der Server überträgt Arbeit auf den IDA-Hauptthread, unterstützt rein hardwarebasierte Breakpoints und nicht anhaltende Trace-Modi für Live-Ziele und kann Debugger-Stops per Long-Polling abfragen, damit Clients Sitzungen interaktiv prüfen können. Es richtet sich an Reverse Engineers und Game-Security-Analysten, die MCP-fähige Clients einschließlich Kilns Chat-Integration direkt gegen eine echte IDA-Datenbank statt statischer Exporte nutzen wollen.
