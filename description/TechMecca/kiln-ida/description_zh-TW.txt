Kiln IDA 是一款原生 IDA Pro 9.1 外掛，透過 localhost 上的 Streamable HTTP 以 Model Context Protocol 向 AI 助手開放目前資料庫。實作為單一 Python IDAPython 模組，無需 pip 相依，提供數十種工具用於檢視與瀏覽函式、虛擬碼、組合語言、交叉參考、字串、型別、記憶體及除錯器，並可選 Hex-Rays 反編譯與受控寫入操作（重新命名、註解、修補、中斷點及 IDAPython 執行）。伺服器將工作排程到 IDA 主執行緒，支援僅硬體中斷點及針對即時目標的非暫停追蹤模式，並可對除錯器停止進行長輪詢，便於用戶端互動式審查工作階段。面向希望 MCP 用戶端（含 Kiln 聊天整合）直接操作真實 IDA 資料庫而非靜態匯出的逆向工程師與遊戲安全分析人員。
