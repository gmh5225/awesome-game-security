Kiln IDA is a native IDA Pro 9.1 plugin that exposes the open database to AI assistants over the Model Context Protocol using Streamable HTTP on localhost. It is implemented as a single Python IDAPython module with no pip dependencies and offers dozens of tools to inspect and navigate functions, pseudocode, assembly, cross-references, strings, types, memory, and the debugger, with optional Hex-Rays decompilation and guarded write operations such as renames, comments, patches, breakpoints, and IDAPython execution. The server marshals work onto IDA’s main thread, supports hardware-only breakpoints and non-suspending trace modes for live targets, and can long-poll debugger stops so clients can review sessions interactively. It is aimed at reverse engineers and game security analysts who want MCP-capable clients, including Kiln’s chat integration, to work directly against a real IDA database instead of static exports.
