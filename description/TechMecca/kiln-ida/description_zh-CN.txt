Kiln IDA 是一款原生 IDA Pro 9.1 插件，通过 localhost 上的 Streamable HTTP 以 Model Context Protocol 向 AI 助手开放当前数据库。实现为单个 Python IDAPython 模块，无需 pip 依赖，提供数十种工具用于查看与浏览函数、伪代码、汇编、交叉引用、字符串、类型、内存及调试器，并可选 Hex-Rays 反编译与受控写操作（重命名、注释、补丁、断点及 IDAPython 执行）。服务端将工作调度到 IDA 主线程，支持仅硬件断点及针对实时目标的非挂起跟踪模式，并可对调试器停止进行长轮询，便于客户端交互式审查会话。面向希望 MCP 客户端（含 Kiln 聊天集成）直接操作真实 IDA 数据库而非静态导出的逆向工程师与游戏安全分析人员。
