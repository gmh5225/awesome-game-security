Kiln IDA è un plugin nativo per IDA Pro 9.1 che espone il database aperto agli assistenti IA tramite Model Context Protocol con Streamable HTTP su localhost. È implementato come un unico modulo Python IDAPython senza dipendenze pip e offre decine di strumenti per ispezionare e navigare funzioni, pseudocodice, assembly, riferimenti incrociati, stringhe, tipi, memoria e debugger, con decompilazione Hex-Rays opzionale e operazioni di scrittura protette come rinomina, commenti, patch, breakpoint ed esecuzione IDAPython. Il server inoltra il lavoro sul thread principale di IDA, supporta breakpoint solo hardware e modalità di trace non sospensive per target live, e può fare long-poll delle fermate del debugger così i client possono rivedere le sessioni in modo interattivo. È rivolto a reverse engineer e analisti di sicurezza dei giochi che vogliono client compatibili MCP, inclusa l’integrazione chat di Kiln, operare direttamente su un database IDA reale invece che su export statici.
