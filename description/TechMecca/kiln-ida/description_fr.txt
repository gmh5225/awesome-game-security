Kiln IDA est une extension native pour IDA Pro 9.1 qui expose la base ouverte aux assistants IA via le Model Context Protocol, en Streamable HTTP sur localhost. Implémenté comme un seul module Python IDAPython sans dépendances pip, il propose des dizaines d’outils pour inspecter et parcourir fonctions, pseudocode, assembleur, références croisées, chaînes, types, mémoire et débogueur, avec décompilation Hex-Rays optionnelle et opérations d’écriture contrôlées (renommages, commentaires, patches, points d’arrêt, exécution IDAPython). Le serveur achemine le travail sur le thread principal d’IDA, prend en charge les points d’arrêt matériels uniquement et des modes de trace sans suspension pour cibles live, et peut long-poll les arrêts du débogueur pour que les clients examinent les sessions de façon interactive. Il s’adresse aux ingénieurs reverse et analystes sécurité jeu qui veulent des clients compatibles MCP, dont l’intégration chat de Kiln, travaillant directement sur une vraie base IDA plutôt que sur des exports statiques.
