Kiln IDA es un complemento nativo de IDA Pro 9.1 que expone la base de datos abierta a asistentes de IA mediante el Model Context Protocol con Streamable HTTP en localhost. Está implementado como un único módulo Python IDAPython sin dependencias pip y ofrece decenas de herramientas para inspeccionar y navegar funciones, pseudocódigo, ensamblador, referencias cruzadas, cadenas, tipos, memoria y el depurador, con descompilación Hex-Rays opcional y operaciones de escritura controladas como renombrados, comentarios, parches, puntos de interrupción y ejecución IDAPython. El servidor encola el trabajo en el hilo principal de IDA, admite puntos de interrupción solo por hardware y modos de traza sin suspensión para objetivos en vivo, y puede hacer long-poll de paradas del depurador para que los clientes revisen sesiones de forma interactiva. Está pensado para ingenieros inversores y analistas de seguridad en juegos que quieren clientes compatibles con MCP, incluida la integración de chat de Kiln, trabajando directamente contra una base IDA real en lugar de exportaciones estáticas.
