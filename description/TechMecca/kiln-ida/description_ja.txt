Kiln IDA はネイティブの IDA Pro 9.1 プラグインで、localhost 上の Streamable HTTP 経由で Model Context Protocol を使い、開いているデータベースを AI アシスタントに公開します。pip 依存のない単一の Python IDAPython モジュールとして実装され、関数・疑似コード・アセンブリ・相互参照・文字列・型・メモリ・デバッガを調査・ナビゲートする数十のツールに加え、任意で Hex-Rays 逆コンパイルと、リネーム・コメント・パッチ・ブレークポイント・IDAPython 実行などの保護付き書き込み操作を提供します。サーバーは処理を IDA のメインスレッドにマーシャルし、ライブターゲット向けにハードウェア専用ブレークポイントと非停止トレースモードをサポートし、デバッガ停止のロングポールでクライアントがセッションを対話的に確認できます。静的エクスポートではなく実際の IDA データベースに対して、Kiln のチャット連携を含む MCP 対応クライアントを直接使いたいリバースエンジニアとゲームセキュリティアナリスト向けです。
