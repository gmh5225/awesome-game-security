Kiln IDA는 localhost의 Streamable HTTP로 Model Context Protocol을 통해 열린 데이터베이스를 AI 어시스턴트에 노출하는 네이티브 IDA Pro 9.1 플러그인입니다. pip 의존성 없이 단일 Python IDAPython 모듈로 구현되며, 함수·의사코드·어셈블리·교차 참조·문자열·타입·메모리·디버거를 검사하고 탐색하는 수십 가지 도구와 선택적 Hex-Rays 디컴파일, 이름 변경·주석·패치·중단점·IDAPython 실행 등 보호된 쓰기 작업을 제공합니다. 서버는 작업을 IDA 메인 스레드로 마샬링하고, 라이브 대상용 하드웨어 전용 중단점과 비일시 중지 추적 모드를 지원하며, 디버거 정지에 대한 롱 폴링으로 클라이언트가 세션을 대화형으로 검토할 수 있습니다. 정적 내보내기가 아닌 실제 IDA 데이터베이스에 Kiln 채팅 통합을 포함한 MCP 클라이언트를 직접 사용하려는 리버스 엔지니어와 게임 보안 분석가를 대상으로 합니다.
