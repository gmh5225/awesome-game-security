Hook Detector は、読み込まれたモジュールとプロセスをスキャンして、関数および API フックを特定する Windows デスクトップアプリケーションです。C++20 で構築され、DirectX 11 と ImGui によるグラフィカルインターフェースを備えており、コアロジックはモジュールスキャナーと PE 解析ユーティリティを組み合わせ、メモリ内のコードを期待される実行ファイルレイアウトと比較します。本プロジェクトは x86 および x64 の Windows ビルドを対象としており、実行中のソフトウェアにおけるフックベースの改ざんを調査する必要があるアンチチート開発者、ゲームセキュリティ研究者、リバースエンジニア向けに設計されています。
