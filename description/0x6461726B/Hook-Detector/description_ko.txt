Hook Detector는 로드된 모듈과 프로세스를 스캔하여 함수 및 API 후킹을 식별하는 Windows 데스크톱 애플리케이션입니다. C++20로 구축되었으며 DirectX 11과 ImGui 그래픽 인터페이스를 사용하고, 핵심 로직은 모듈 스캐너와 PE 파싱 유틸리티를 결합하여 메모리 내 코드를 예상되는 실행 파일 레이아웃과 비교합니다. 이 프로젝트는 x86 및 x64 Windows 빌드를 모두 대상으로 하며, 실행 중인 소프트웨어에서 후킹 기반 변조를 조사해야 하는 안티치트 개발자, 게임 보안 연구자 및 리버스 엔지니어를 위해 설계되었습니다.
