Hook Detector — это настольное приложение для Windows, которое сканирует загруженные модули и процессы для выявления перехватов функций и API. Оно написано на C++20 с графическим интерфейсом на DirectX 11 и ImGui, а его основная логика объединяет сканер модулей с утилитами разбора PE для сравнения кода в памяти с ожидаемой структурой исполняемых файлов. Проект ориентирован на сборки Windows для x86 и x64 и предназначен для разработчиков античит-систем, исследователей безопасности игр и реверс-инженеров, которым необходимо проверять подмены на основе хуков в работающем программном обеспечении.
