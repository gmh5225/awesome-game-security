This project is an open-source MelonLoader mod that adds host-side anti-cheat protection to Among Us 3D and VR sessions. It is implemented in C# for .NET 6 and uses Harmony runtime patches against the game's Il2Cpp and Photon Fusion assemblies to validate kills, meetings, votes, tasks, vents, power-ups, cosmetics, movement speed, and other networked actions. The mod includes a configurable in-game GUI, per-room whitelist and blacklist management, a fetched global cheat blacklist, automatic release updates, and kicks that aim to bypass common anti-kick cheats. It is aimed at streamers, room hosts, and communities who want practical client-side game security tooling and a reference for how mod-based defenses are built on Unity VR titles.
