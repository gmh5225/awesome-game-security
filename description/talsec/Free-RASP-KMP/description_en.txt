Free-RASP-KMP is a Kotlin Multiplatform plugin that adds runtime app self-protection and security monitoring to Android and iOS mobile applications. It detects compromised environments such as root or jailbreak, hooking frameworks like Frida, untrusted installation sources, automation tools, and on Android can scan for suspicious or malicious apps. The SDK exposes threat and execution-state events, supports configurable responses such as terminating the app when protections are bypassed, and integrates native Talsec runtime components on each platform. Written primarily in Kotlin with Gradle-based multiplatform builds, it is aimed at developers who need in-app shielding against reverse engineering, tampering, repackaging, and fraud in production mobile apps including games.
