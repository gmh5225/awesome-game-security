Free-RASP-Android est une application Android d'exemple qui démontre l'intégration du SDK freeRASP, une bibliothèque Runtime Application Self-Protection (RASP) qui ajoute la détection de menaces et la surveillance de sécurité dans les applications mobiles. Écrite principalement en Kotlin avec Gradle, elle montre comment configurer TalsecConfig, enregistrer les callbacks ThreatListener et réagir aux menaces telles que l'accès root, les débogueurs, les émulateurs, les frameworks de hooking comme Frida, la falsification d'APK, les sources d'installation non fiables, les logiciels malveillants, la capture d'écran, ainsi que le spoofing de localisation ou de WiFi. La démo couvre également la protection d'écran optionnelle, les vérifications de l'état de l'appareil, la validation du certificat de signature et les builds release avec ProGuard via la dépendance Maven TalsecSecurity-Community. Elle s'adresse aux développeurs Android qui ont besoin d'une protection côté client contre l'ingénierie inverse, le repackaging et les environnements d'appareils compromis, y compris les jeux et applications fintech nécessitant une protection anti-triche et anti-fraude.
