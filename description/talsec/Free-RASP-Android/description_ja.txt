Free-RASP-Android は、freeRASP SDK（Runtime Application Self-Protection、RASP）の統合を示すサンプル Android アプリケーションです。この SDK は、モバイルアプリにアプリ内脅威検出とセキュリティ監視を追加するライブラリです。主に Kotlin と Gradle で書かれており、TalsecConfig の設定、ThreatListener コールバックの登録、root 化、デバッガ、エミュレータ、Frida などのフックフレームワーク、APK 改ざん、信頼できないインストール元、マルウェア、画面キャプチャ、位置情報や WiFi のスプーフィングなどの脅威への対応方法を示します。デモでは、オプションの画面保護、デバイス状態チェック、署名証明書の検証、TalsecSecurity-Community Maven 依存関係を用いた ProGuard 有効のリリースビルドも扱います。Android 開発者向けで、リバースエンジニアリング、再パッケージング、侵害されたデバイス環境に対するクライアント側のアプリ保護が必要な場合、特にアンチチートや不正防止が求められるゲームやフィンテックアプリ向けです。
