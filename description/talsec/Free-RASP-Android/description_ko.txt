Free-RASP-Android는 freeRASP SDK를 통합하는 방법을 보여 주는 샘플 Android 애플리케이션입니다. freeRASP SDK는 Runtime Application Self-Protection(RASP) 라이브러리로, 모바일 앱에 앱 내 위협 탐지 및 보안 모니터링을 추가합니다. 주로 Kotlin과 Gradle로 작성되었으며, TalsecConfig 구성, ThreatListener 콜백 등록, root 권한, 디버거, 에뮬레이터, Frida 같은 후킹 프레임워크, APK 변조, 신뢰할 수 없는 설치 출처, 멀웨어, 화면 캡처, 위치 또는 WiFi 스푸핑 등의 위협에 대응하는 방법을 설명합니다. 데모에는 선택적 화면 보호, 기기 상태 검사, 서명 인증서 검증, TalsecSecurity-Community Maven 의존성을 사용한 ProGuard 활성화 릴리스 빌드도 포함됩니다. Android 개발자를 대상으로 하며, 역공학, 재패키징, 손상된 기기 환경에 대한 클라이언트 측 앱 보호가 필요한 경우, 특히 안티치트 및 사기 방지가 필요한 게임 및 핀테크 앱에 적합합니다.
