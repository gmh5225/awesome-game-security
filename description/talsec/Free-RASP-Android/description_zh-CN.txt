Free-RASP-Android 是一个示例 Android 应用，演示如何集成 freeRASP SDK——一种运行时应用自保护（RASP）库，可为移动应用添加应用内威胁检测与安全监控。项目主要使用 Kotlin 与 Gradle 编写，展示如何配置 TalsecConfig、注册 ThreatListener 回调，并应对 root 权限、调试器、模拟器、Frida 等 hook 框架、APK 篡改、不可信安装来源、恶意软件、屏幕录制，以及位置或 WiFi 欺骗等威胁。该演示还涵盖可选的屏幕保护、设备状态检查、签名证书验证，以及使用 TalsecSecurity-Community Maven 依赖并启用 ProGuard 的 release 构建。它面向需要客户端应用防护以抵御逆向工程、重打包和受控设备环境的 Android 开发者，包括需要反作弊与防欺诈保护的游戏和金融科技应用。
