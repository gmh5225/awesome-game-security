Free-RASP-Android is a sample Android application demonstrating integration of the freeRASP SDK, a Runtime Application Self-Protection (RASP) library that adds in-app threat detection and security monitoring to mobile apps. Written primarily in Kotlin with Gradle, it shows how to configure TalsecConfig, register ThreatListener callbacks, and react to threats such as root access, debuggers, emulators, hooking frameworks like Frida, APK tampering, untrusted install sources, malware, screen capture, and location or WiFi spoofing. The demo also covers optional screen protection, device state checks, signing certificate validation, and ProGuard-enabled release builds using the TalsecSecurity-Community Maven dependency. It targets Android developers who need client-side application shielding against reverse engineering, repackaging, and compromised device environments, including game and fintech apps that require anti-cheat and fraud protection.
