Free-RASP-Android es una aplicación Android de ejemplo que demuestra la integración del SDK freeRASP, una biblioteca Runtime Application Self-Protection (RASP) que añade detección de amenazas y monitorización de seguridad dentro de las aplicaciones móviles. Escrita principalmente en Kotlin con Gradle, muestra cómo configurar TalsecConfig, registrar callbacks de ThreatListener y reaccionar ante amenazas como acceso root, depuradores, emuladores, frameworks de hooking como Frida, manipulación de APK, fuentes de instalación no confiables, malware, captura de pantalla, y suplantación de ubicación o WiFi. La demo también cubre protección opcional de pantalla, comprobaciones del estado del dispositivo, validación del certificado de firma y builds de release con ProGuard usando la dependencia Maven TalsecSecurity-Community. Está dirigida a desarrolladores Android que necesitan protección de aplicaciones en el cliente contra ingeniería inversa, reempaquetado y entornos de dispositivos comprometidos, incluidas apps de juegos y fintech que requieren protección anti-trampas y anti-fraude.
