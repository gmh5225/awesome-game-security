freeRASP for Capacitor 是一款移动端应用内威胁检测与安全监控插件，为 Capacitor 应用提供运行时应用自我保护（RASP）和应用屏蔽能力。它可检测 root 与越狱环境、Frida 和 Shadow 等挂钩框架、不受信任的安装方式、应用或设备重绑定、恶意软件与可疑应用、时间伪造以及屏幕截取尝试。该插件以 Capacitor 桥接实现，提供 TypeScript API 以及原生 Android（Kotlin）和 iOS（Swift）层，并通过回调以及可选的每周安全报告通报威胁。面向需要针对逆向工程、应用篡改、受损设备及相关移动安全威胁提供运行时保护的 Capacitor 与 Ionic 开发者。
