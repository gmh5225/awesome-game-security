freeRASP for Capacitor は、Capacitor アプリに Runtime App Self Protection（RASP）とアプリケーションシールドを提供する、モバイル向けアプリ内脅威検知・セキュリティ監視プラグインです。root および脱獄環境、Frida や Shadow などのフッキングフレームワーク、信頼できないインストール方法、アプリまたはデバイスのリバインディング、マルウェアや不審なアプリ、時刻改ざん、画面キャプチャの試みを検知します。本プラグインは TypeScript API とネイティブの Android（Kotlin）および iOS（Swift）層を備えた Capacitor ブリッジとして実装され、コールバックおよび任意の週次セキュリティレポートで脅威を報告します。リバースエンジニアリング、アプリ改ざん、侵害されたデバイス、関連するモバイルセキュリティ脅威に対するランタイム保護を必要とする Capacitor および Ionic 開発者向けです。
