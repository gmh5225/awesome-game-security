freeRASP for Capacitor 是一款行動端應用程式內威脅偵測與安全監控外掛，為 Capacitor 應用程式提供執行階段應用自我保護（RASP）與應用防護能力。它可偵測 root 與越獄環境、Frida 和 Shadow 等掛鉤框架、不受信任的安裝方式、應用程式或裝置重綁定、惡意軟體與可疑應用、時間偽造以及螢幕擷取嘗試。此外掛以 Capacitor 橋接實作，提供 TypeScript API 以及原生 Android（Kotlin）和 iOS（Swift）層，並透過回呼以及可選的每週安全報告通報威脅。面向需要針對逆向工程、應用程式竄改、受損裝置及相關行動安全威脅提供執行階段保護的 Capacitor 與 Ionic 開發者。
