freeRASP for Cordova は、Android および iOS 上の Cordova ハイブリッドアプリに Runtime Application Self-Protection（RASP）とアプリケーションシールドを提供する、モバイルアプリ内脅威検知・セキュリティ監視プラグインです。TypeScript で実装され、Kotlin および Swift のネイティブコンポーネントを含み、root や jailbreak などの改ざん環境、Frida などのフックフレームワーク、信頼できないインストール元、改ざん、リバースエンジニアリングの試行を検出します。さらに、マルウェアや疑わしいアプリのスキャン、画面キャプチャ保護、ブートローダーおよび自動化の検出、時刻・位置の偽装や安全でない Wi-Fi のチェックなどの機能も備えています。開発者はこのプラグインを統合することで、不正行為、再パッケージング、ランタイム攻撃からモバイルアプリを強化でき、ゲームやその他の高価値アプリをチートや悪用から保護するのに役立ちます。
