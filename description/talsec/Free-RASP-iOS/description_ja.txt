freeRASP for iOS は、ネイティブ iOS アプリケーションにアプリ内脅威検出とセキュリティ監視を追加する無料の Runtime Application Self-Protection（RASP）SDK です。TalsecRuntime XCFramework として提供され、Swift Package Manager または Xcode 経由で統合でき、デバイスをスキャンして検出されたリスクに基づくセキュリティスコアを報告する Swift デモアプリも同梱されています。このライブラリは、ジェイルブレイク、デバッガー、ランタイムフックおよび改ざんフレームワーク、シミュレーター、改ざんまたは非公式インストール、無効なアプリ署名、Secure Enclave の利用可否、パスコード保護、デバイスバインディング、システム VPN の使用、スクリーンショット、画面録画、時刻改ざんを検査します。開発者は TalsecConfig と Talsec.start を通じて保護を初期化し、脅威コールバックに自アプリのロジックで応答します。リバースエンジニアリング、チート、不正行為、侵害されたデバイスに対する軽量なランタイム防御を、セキュリティツールを一から構築せずに必要とする iOS およびモバイルゲーム開発者向けです。
