freeRASP for iOS는 네이티브 iOS 애플리케이션에 앱 내 위협 탐지 및 보안 모니터링을 추가하는 무료 Runtime Application Self-Protection(RASP) SDK입니다. TalsecRuntime XCFramework 형태로 제공되며 Swift Package Manager 또는 Xcode를 통해 통합할 수 있고, 기기를 스캔하여 탐지된 위험에 기반한 보안 점수를 보고하는 Swift 데모 앱도 포함됩니다. 이 라이브러리는 탈옥, 디버거, 런타임 후킹 및 조작 프레임워크, 시뮬레이터, 변조 또는 비공식 설치, 유효하지 않은 앱 서명, Secure Enclave 가용성, 암호 보호, 기기 바인딩, 시스템 VPN 사용, 스크린샷, 화면 녹화, 시간 조작을 검사합니다. 개발자는 TalsecConfig와 Talsec.start를 통해 보호를 초기화한 뒤, 자체 앱 로직에서 위협 콜백에 대응합니다. 리버스 엔지니어링, 치팅, 사기, 손상된 기기에 대한 경량 런타임 방어가 필요하지만 보안 도구를 처음부터 구축하고 싶지 않은 iOS 및 모바일 게임 개발자를 대상으로 합니다.
