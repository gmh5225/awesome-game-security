freeRASP for iOS est un SDK gratuit de Runtime Application Self-Protection (RASP) qui ajoute la détection de menaces in-app et la surveillance de sécurité aux applications iOS natives. Il est fourni sous forme de XCFramework TalsecRuntime, intégrable via Swift Package Manager ou Xcode, avec une application de démonstration Swift qui analyse l'appareil et rapporte un score de sécurité basé sur les risques détectés. La bibliothèque vérifie les jailbreaks, les débogueurs, les frameworks de hooking et de manipulation à l'exécution, les simulateurs, les installations falsifiées ou non officielles, les signatures d'application invalides, la disponibilité de Secure Enclave, la protection par code d'accès, la liaison d'appareil, l'utilisation d'un VPN système, les captures d'écran, l'enregistrement d'écran et la falsification de l'heure. Les développeurs initialisent la protection via TalsecConfig et Talsec.start, puis réagissent aux callbacks de menaces dans leur propre logique applicative. Il s'adresse aux développeurs iOS et de jeux mobiles qui ont besoin de défenses runtime légères contre l'ingénierie inverse, la triche, la fraude et les appareils compromis, sans construire leurs outils de sécurité from scratch.
