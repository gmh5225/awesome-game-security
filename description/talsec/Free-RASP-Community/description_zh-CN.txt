Free-RASP-Community 是 freeRASP 的主要社区仓库。freeRASP 是一款移动端运行时应用自我保护（RASP）SDK，可在应用运行期间提供应用内威胁检测与安全监控。它汇集了面向原生 Android 与 iOS、跨平台框架（包括 Flutter、React Native、Capacitor、Cordova 和 Kotlin Multiplatform）以及 Unity、Unreal Engine 等游戏引擎的平台特定集成。该 SDK 可检测已 Root 或越狱的设备、Frida 与 Xposed 等 Hook 框架、逆向工程与重打包尝试、不可信安装、屏幕录制、设备伪装以及不安全的网络或操作系统环境，并可通过 freeMalwareDetection 可选地进行 Android 恶意软件扫描。威胁通过回调 API 上报，性能开销极小；该库符合 OWASP MASVS V8 针对逆向工程的弹性要求。它面向需要客户端应用防护以抵御篡改、作弊和受损害设备环境的移动与游戏开发者。
