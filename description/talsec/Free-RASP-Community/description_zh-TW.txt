Free-RASP-Community 是 freeRASP 的主要社群儲存庫。freeRASP 是一款行動端執行階段應用程式自我保護（RASP）SDK，可在應用程式執行期間提供應用內威脅偵測與安全監控。它彙整了原生 Android 與 iOS、跨平台框架（包括 Flutter、React Native、Capacitor、Cordova 和 Kotlin Multiplatform）以及 Unity、Unreal Engine 等遊戲引擎的平台特定整合。此 SDK 可偵測已 Root 或越獄的裝置、Frida 與 Xposed 等 Hook 框架、逆向工程與重打包嘗試、不可信安裝、螢幕擷取、裝置偽裝，以及不安全的網路或作業系統環境，並可透過 freeMalwareDetection 選擇性地進行 Android 惡意軟體掃描。威脅透過回呼 API 回報，效能開銷極小；此函式庫符合 OWASP MASVS V8 針對逆向工程的彈性要求。它面向需要客戶端應用程式防護以抵禦竄改、作弊和受損裝置環境的行動與遊戲開發者。
