Free-RASP-Community は、freeRASP の主要なコミュニティリポジトリです。freeRASP は、モバイル向けの Runtime Application Self-Protection（RASP）SDK で、アプリ実行中にアプリ内の脅威検出とセキュリティ監視を提供します。ネイティブの Android および iOS、Flutter、React Native、Capacitor、Cordova、Kotlin Multiplatform などのクロスプラットフォームフレームワーク、Unity や Unreal Engine などのゲームエンジン向けのプラットフォーム別統合を集約しています。この SDK は、root 化・脱獄端末、Frida や Xposed などのフックフレームワーク、リバースエンジニアリングや再パッケージ化の試行、信頼できないインストール、画面キャプチャ、端末の偽装、安全でないネットワークや OS 環境を検出し、freeMalwareDetection による Android マルウェアスキャンもオプションで利用できます。脅威はコールバック API 経由で報告され、パフォーマンスへの影響は最小限です。このライブラリは、リバースエンジニアリングに対する OWASP MASVS V8 の耐性要件にも準拠しています。改ざん、チート、侵害された端末環境から保護するクライアント側のアプリシールドが必要なモバイルおよびゲーム開発者向けです。
