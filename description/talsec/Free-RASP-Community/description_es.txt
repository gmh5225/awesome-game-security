Free-RASP-Community es el repositorio comunitario principal de freeRASP, un SDK móvil de Runtime Application Self-Protection (RASP) que proporciona detección de amenazas dentro de la aplicación y monitorización de seguridad mientras la aplicación se ejecuta. Reúne integraciones específicas por plataforma para Android e iOS nativos, frameworks multiplataforma como Flutter, React Native, Capacitor, Cordova y Kotlin Multiplatform, y motores de juego como Unity y Unreal Engine. El SDK detecta dispositivos con root o jailbreak, frameworks de hooking como Frida y Xposed, intentos de ingeniería inversa y reempaquetado, instalaciones no confiables, captura de pantalla, suplantación de dispositivos y entornos de red u OS inseguros, con escaneo opcional de malware en Android mediante freeMalwareDetection. Las amenazas se reportan a través de una API de callback con un impacto mínimo en el rendimiento, y la biblioteca cumple con los requisitos de resiliencia OWASP MASVS V8 contra la ingeniería inversa. Está dirigido a desarrolladores móviles y de videojuegos que necesitan protección de aplicaciones en el cliente contra manipulación, trampas y entornos de dispositivos comprometidos.
