Free-RASP-Community — основной общественный репозиторий freeRASP, мобильного SDK Runtime Application Self-Protection (RASP), который обеспечивает обнаружение угроз внутри приложения и мониторинг безопасности во время работы приложения. Он объединяет платформенно-специфичные интеграции для нативных Android и iOS, кроссплатформенных фреймворков, включая Flutter, React Native, Capacitor, Cordova и Kotlin Multiplatform, а также игровых движков, таких как Unity и Unreal Engine. SDK обнаруживает устройства с root-доступом или jailbreak, фреймворки перехвата вроде Frida и Xposed, попытки реверс-инжиниринга и перепаковки, ненадёжные установки, захват экрана, подмену устройства и небезопасные сетевые или ОС-среды, с опциональным сканированием вредоносного ПО на Android через freeMalwareDetection. Угрозы сообщаются через callback API с минимальными накладными расходами на производительность, а библиотека соответствует требованиям устойчивости OWASP MASVS V8 против реверс-инжиниринга. Она предназначена для мобильных и игровых разработчиков, которым нужна клиентская защита приложений от подмены, читерства и скомпрометированных сред устройств.
