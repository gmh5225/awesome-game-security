freeRASP for Flutter es un SDK móvil de detección de amenazas in-app y monitorización de seguridad que aporta Runtime Application Self-Protection (RASP) a aplicaciones Flutter en Android e iOS. Implementado como plugin de Flutter con capas nativas en Kotlin y Swift respaldadas por el runtime de Talsec, detecta dispositivos rooteados o con jailbreak, frameworks de hooking como Frida, depuradores, firmas de aplicación alteradas, instalaciones no oficiales, emuladores, malware y capturas o grabaciones de pantalla no autorizadas. También cubre el enlace de dispositivos, herramientas de automatización como Appium, uso de VPN y Wi-Fi inseguro, suplantación de hora y ubicación, y abuso de múltiples instancias, exponiendo las amenazas mediante callbacks y terminación opcional cuando se eluden las protecciones. El SDK freemium está dirigido a desarrolladores móviles que necesitan endurecimiento del lado del cliente contra ingeniería inversa, reempaquetado y entornos comprometidos, incluidos juegos y otras aplicaciones Flutter de alto valor.
