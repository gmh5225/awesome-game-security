freeRASP for Flutter — это мобильный SDK для обнаружения угроз внутри приложения и мониторинга безопасности, который обеспечивает Runtime Application Self-Protection (RASP) для Flutter-приложений на Android и iOS. Реализованный как плагин Flutter с нативными слоями на Kotlin и Swift на базе среды выполнения Talsec, он обнаруживает устройства с root или jailbreak, фреймворки перехвата вроде Frida, отладчики, подделанные подписи приложений, неофициальные установки, эмуляторы, вредоносное ПО, а также несанкционированный захват или запись экрана. Также охватываются привязка устройства, инструменты автоматизации вроде Appium, использование VPN и небезопасного Wi-Fi, подмена времени и местоположения, злоупотребление несколькими экземплярами; угрозы передаются через callbacks с опциональным завершением приложения при обходе защиты. Freemium SDK предназначен для мобильных разработчиков, которым нужно клиентское усиление против реверс-инжиниринга, перепаковки и скомпрометированных сред, включая игры и другие ценные Flutter-приложения.
