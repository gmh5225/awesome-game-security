freeRASP for Flutter is a mobile in-app threat detection and security monitoring SDK that brings Runtime Application Self-Protection (RASP) to Flutter apps on Android and iOS. Implemented as a Flutter plugin with Kotlin and Swift native layers backed by the Talsec runtime, it detects rooted or jailbroken devices, hooking frameworks such as Frida, debuggers, tampered app signatures, unofficial installs, emulators, malware, and unauthorized screen capture or recording. It also covers device binding, automation tools like Appium, VPN and unsecure Wi-Fi use, time and location spoofing, and multi-instance abuse, exposing threats through callbacks and optional termination when protections are bypassed. The freemium SDK is aimed at mobile developers who need client-side hardening against reverse engineering, repackaging, and compromised environments, including games and other high-value Flutter applications.
