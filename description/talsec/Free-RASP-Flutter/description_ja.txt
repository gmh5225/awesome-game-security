freeRASP for Flutter は、Flutter アプリ向けのモバイルアプリ内脅威検知・セキュリティ監視 SDK で、Android および iOS 上の Flutter アプリに Runtime Application Self-Protection（RASP）を提供します。Flutter プラグインとして実装され、Kotlin と Swift のネイティブ層および Talsec ランタイムを基盤に、root 化・脱獄端末、Frida などのフックフレームワーク、デバッガー、改ざんされたアプリ署名、非公式インストール、エミュレーター、マルウェア、不正な画面キャプチャや録画を検出します。デバイスバインディング、Appium などの自動化ツール、VPN や安全でない Wi-Fi の利用、時刻・位置情報の偽装、マルチインスタンスの悪用にも対応し、コールバックで脅威を通知し、保護が回避された場合は任意でアプリを終了できます。freemium の本 SDK は、リバースエンジニアリング、再パッケージング、侵害された環境に対するクライアント側の強化を必要とするモバイル開発者向けで、ゲームを含む高価値な Flutter アプリケーションに適しています。
