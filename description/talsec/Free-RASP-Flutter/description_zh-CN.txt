freeRASP for Flutter 是一款面向 Flutter 应用的移动应用内威胁检测与安全监控 SDK，为 Android 和 iOS 平台提供运行时应用自我保护（RASP）能力。该 SDK 以 Flutter 插件形式实现，底层由 Kotlin 与 Swift 原生层及 Talsec 运行时支撑，可检测已 root 或越狱的设备、Frida 等 Hook 框架、调试器、被篡改的应用签名、非官方安装、模拟器、恶意软件以及未经授权的屏幕截图或录屏。它还涵盖设备绑定、Appium 等自动化工具、VPN 与不安全的 Wi-Fi 使用、时间与位置伪造、多开滥用等场景，并通过回调暴露威胁，在防护被绕过时还可选择终止应用。这款 freemium SDK 面向需要客户端加固以抵御逆向工程、重打包和受控环境风险的移动开发者，适用于游戏及其他高价值 Flutter 应用。
