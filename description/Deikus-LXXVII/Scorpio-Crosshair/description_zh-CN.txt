Scorpio 是一款面向 Windows 与 Linux 上 PC 游戏的免费桌面准星叠加工具，在游戏之上的独立透明、点击穿透窗口中渲染 CS2 风格的准星。项目使用 Rust 与 Tauri 2 实现，采用按需加载的 HTML、CSS 与 JavaScript 设置界面，并通过各平台专用的叠加层与窗口焦点逻辑运作，而不接触游戏进程。应用支持 CS2 分享码、按游戏配置文件、基于启动器的游戏检测、隐藏原始输入瞄准、全局快捷键以及可选的 OBS 浏览器源输出，同时刻意避免进程句柄、注入、钩子、内存读取与合成输入，以降低被反作弊系统标记的可能性。它适合希望获得一致外部准星的玩家，以及研究如何构建留在游戏与反作弊信任边界之外的叠加层的开发者或研究人员。
