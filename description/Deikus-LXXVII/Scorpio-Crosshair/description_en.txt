Scorpio is a free desktop crosshair overlay for PC games on Windows and Linux that renders a CS2-style reticle in a separate transparent, click-through window above the game. It is implemented in Rust with Tauri 2, with an on-demand HTML, CSS, and JavaScript settings UI, and uses platform-specific overlay and window-focus logic rather than touching game processes. The app supports CS2 share codes, per-game profiles, launcher-based game detection, raw-input aim hiding, global shortcuts, and optional OBS browser-source output, while deliberately avoiding process handles, injection, hooks, memory reads, and synthetic input so anti-cheat systems are less likely to flag it. It suits players who want a consistent external crosshair and developers or researchers studying how to build game overlays that stay outside the game and anti-cheat trust boundary.
