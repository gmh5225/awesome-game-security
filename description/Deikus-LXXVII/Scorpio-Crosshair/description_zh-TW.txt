Scorpio 是一款適用於 Windows 與 Linux 上 PC 遊戲的免費桌面準星疊加工具，在遊戲之上的獨立透明、點擊穿透視窗中渲染 CS2 風格的準星。專案以 Rust 與 Tauri 2 實作，採用按需載入的 HTML、CSS 與 JavaScript 設定介面，並透過各平台專用的疊加層與視窗焦點邏輯運作，而不接觸遊戲行程。應用程式支援 CS2 分享碼、依遊戲設定檔、以啟動器為基礎的遊戲偵測、隱藏原始輸入瞄準、全域快捷鍵以及可選的 OBS 瀏覽器來源輸出，同時刻意避免行程控制代碼、注入、掛鉤、記憶體讀取與合成輸入，以降低遭反作弊系統標記的可能性。它適合希望獲得一致外部準星的玩家，以及研究如何建構留在遊戲與反作弊信任邊界之外的疊加層的開發者或研究人員。
