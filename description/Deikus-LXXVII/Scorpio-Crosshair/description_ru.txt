Scorpio — бесплатное настольное оверлей-прицеливание для ПК-игр в Windows и Linux: оно рисует прицел в стиле CS2 в отдельном прозрачном окне поверх игры, через которое проходят клики. Реализовано на Rust с Tauri 2, с интерфейсом настроек на HTML, CSS и JavaScript по запросу; используется платформенная логика наложения и фокуса окна, без вмешательства в процессы игры. Поддерживаются коды обмена CS2, профили по играм, определение игры через лаунчер, скрытие прицеливания при raw input, глобальные горячие клавиши и опциональный вывод в браузерный источник OBS; при этом намеренно не используются дескрипторы процессов, инъекции, хуки, чтение памяти и синтетический ввод, чтобы античит реже помечал приложение. Подходит игрокам, которым нужен стабильный внешний прицел, и разработчикам или исследователям, изучающим оверлеи, остающиеся вне игры и границы доверия античита.
