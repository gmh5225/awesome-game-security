Scorpio は、Windows および Linux 向け PC ゲーム用の無料デスクトップ照準オーバーレイで、ゲームの上に独立した透明かつクリック透過ウィンドウを重ね、CS2 スタイルのレティクルを描画します。Rust と Tauri 2 で実装され、オンデマンドの HTML・CSS・JavaScript による設定 UI を備え、ゲームプロセスに触れず、プラットフォーム固有のオーバーレイとウィンドウフォーカス制御で動作します。CS2 シェアコード、ゲーム別プロファイル、ランチャーによるゲーム検出、raw input によるエイム非表示、グローバルショートカット、任意の OBS ブラウザソース出力に対応し、一方でプロセスハンドル、インジェクション、フック、メモリ読み取り、合成入力は意図的に避けるため、アンチチートにフラグされにくくなっています。一貫した外部照準を求めるプレイヤーや、ゲームとアンチチートの信頼境界の外側に留まるオーバーレイの構築方法を研究する開発者・研究者向けです。
