dsh-rea-powerpack est une extension DeepSeek Harness qui renforce le serveur MCP de rétro-ingénierie REA sous Windows en gérant les moteurs d’analyse, en figeant les versions REA et en mettant en évidence les lacunes de capacités dans un tableau de bord de paramètres. Il détecte, installe et vérifie des outils tels qu’ADB, Apktool, JADX, WABT, Frida et Python, puis compose les variables d’environnement REA et les entrées PATH pour le processus enfant MCP sans modifier la configuration système. La pile repose sur Node.js (modules JavaScript) avec une API HTTP en boucle locale et une carte client React pour les matrices de moteurs, les rapports de diagnostic et les politiques de mise à jour. La gouvernance des versions épingle précisément rea-agents, prévalide les mises à niveau dans une installation fantôme, prend en charge le rechargement à chaud ou le retour arrière en cas d’échec, et explique les groupes d’outils manquants en langage clair. Il s’adresse aux ingénieurs en rétro-ingénierie et aux chercheurs en sécurité qui utilisent REA dans DSH pour l’analyse binaire, mobile et de code managé sous Windows.
