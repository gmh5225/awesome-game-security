dsh-rea-powerpack 是 DeepSeek Harness 插件，在 Windows 上通过管理分析引擎、固定 REA 版本并在设置面板中展示能力缺口，强化 REA 逆向工程 MCP 服务器。dsh-rea-powerpack 会检测、安装并校验 ADB、Apktool、JADX、WABT、Frida、Python 等工具，为 MCP 子进程组装 REA 环境变量与 PATH，且不修改系统级配置。技术栈为 Node.js（JavaScript 模块），提供回环 HTTP API 与基于 React 的客户端卡片，用于引擎矩阵、诊断报告与更新策略。版本治理精确固定 rea-agents，在影子安装中预检升级，支持热重载或失败回滚，并以通俗语言说明缺失的工具组。面向在 DSH 中使用 REA 进行二进制、移动端与托管代码分析的逆向工程师与安全研究人员。
