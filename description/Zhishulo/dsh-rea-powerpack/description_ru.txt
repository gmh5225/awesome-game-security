dsh-rea-powerpack — плагин для DeepSeek Harness, который усиливает MCP-сервер REA для обратной разработки в Windows за счёт управления аналитическими движками, фиксации версий REA и отображения пробелов в возможностях на панели настроек. Он обнаруживает, устанавливает и проверяет инструменты вроде ADB, Apktool, JADX, WABT, Frida и Python, затем формирует переменные окружения REA и записи PATH для дочернего процесса MCP, не меняя системную конфигурацию. Стек — Node.js (модули JavaScript) с HTTP API на loopback и клиентской картой на React для матриц движков, отчётов диагностики и политик обновлений. Управление версиями точно фиксирует rea-agents, предварительно проверяет обновления в теневой установке, поддерживает горячую перезагрузку или откат при сбое и объясняет отсутствующие группы инструментов простым языком. Рассчитан на специалистов по обратной разработке и исследователей безопасности, использующих REA в DSH для анализа бинарников, мобильных приложений и управляемого кода в Windows.
