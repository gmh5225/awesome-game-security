dsh-rea-powerpack 是 DeepSeek Harness 外掛，在 Windows 上透過管理分析引擎、固定 REA 版本並在設定面板中呈現能力缺口，強化 REA 逆向工程 MCP 伺服器。dsh-rea-powerpack 會偵測、安裝並驗證 ADB、Apktool、JADX、WABT、Frida、Python 等工具，為 MCP 子程序組裝 REA 環境變數與 PATH，且不變更系統層級設定。技術棧為 Node.js（JavaScript 模組），提供本機回環 HTTP API 與以 React 為基礎的用戶端卡片，用於引擎矩陣、診斷報告與更新策略。版本治理精確固定 rea-agents，在影子安裝中預檢升級，支援熱重載或失敗回滾，並以淺白語言說明缺失的工具群組。面向在 DSH 中使用 REA 進行二進位、行動端與受控程式碼分析的逆向工程師與安全研究人員。
