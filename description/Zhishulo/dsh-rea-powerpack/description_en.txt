dsh-rea-powerpack is a DeepSeek Harness plugin that hardens the REA reverse-engineering MCP server on Windows by managing analysis engines, pinning REA versions, and surfacing capability gaps in a settings dashboard. It detects, installs, and verifies tools such as ADB, Apktool, JADX, WABT, Frida, and Python, then composes REA environment variables and PATH entries for the MCP child process without altering system-wide configuration. The stack is Node.js (JavaScript modules) with a loopback HTTP API and a React-based client card for engine matrices, doctor reports, and update policies. Version governance pins rea-agents precisely, preflights upgrades in a shadow install, supports hot reload or rollback on failure, and explains missing tool groups in plain language. It targets reverse engineers and security researchers who use REA inside DSH for binary, mobile, and managed-code analysis on Windows.
