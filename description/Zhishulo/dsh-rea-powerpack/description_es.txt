dsh-rea-powerpack es un complemento de DeepSeek Harness que refuerza el servidor MCP de ingeniería inversa REA en Windows gestionando motores de análisis, fijando versiones de REA y mostrando carencias de capacidades en un panel de configuración. Detecta, instala y verifica herramientas como ADB, Apktool, JADX, WABT, Frida y Python, y compone variables de entorno REA y entradas PATH para el proceso hijo MCP sin alterar la configuración del sistema. La pila es Node.js (módulos JavaScript) con una API HTTP en bucle local y una tarjeta cliente basada en React para matrices de motores, informes de diagnóstico y políticas de actualización. La gobernanza de versiones fija rea-agents con precisión, comprueba actualizaciones en una instalación en sombra, admite recarga en caliente o reversión ante fallos y explica los grupos de herramientas faltantes en lenguaje claro. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad que usan REA dentro de DSH para análisis de binarios, móvil y código administrado en Windows.
