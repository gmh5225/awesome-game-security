dsh-rea-powerpack è un plugin per DeepSeek Harness che rafforza il server MCP di reverse engineering REA su Windows gestendo i motori di analisi, fissando le versioni REA e evidenziando le lacune di capacità in una dashboard delle impostazioni. Rileva, installa e verifica strumenti come ADB, Apktool, JADX, WABT, Frida e Python, quindi compone variabili d’ambiente REA e voci PATH per il processo figlio MCP senza modificare la configurazione di sistema. Lo stack è Node.js (moduli JavaScript) con un’API HTTP in loopback e una scheda client basata su React per matrici dei motori, report diagnostici e policy di aggiornamento. La governance delle versioni fissa con precisione rea-agents, prevalida gli aggiornamenti in un’installazione shadow, supporta hot reload o rollback in caso di errore e spiega i gruppi di strumenti mancanti in linguaggio semplice. È pensato per reverse engineer e ricercatori di sicurezza che usano REA in DSH per analisi di binari, mobile e codice gestito su Windows.
