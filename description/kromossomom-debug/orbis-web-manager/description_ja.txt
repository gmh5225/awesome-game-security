Orbis Web Manager は、ローカルネットワーク上で GoldHEN を動かす jailbreak 済み PlayStation 4 を管理するための、ブラウザベースのコマンドセンターです。C# の HttpListener を使った軽量な Windows ホストアプリとして実装され、レスポンシブな HTML・CSS・JavaScript のフロントエンドを備え、PC 側に Node.js などの外部ランタイムは不要です。主な機能には、ライブダッシュボードとポートチェック、app.db に基づくゲームライブラリ表示、ドラッグ＆ドロップアップロード対応の FTP ファイル閲覧、GoldHEN チート表示と地域別 Title ID 変換、PKG の一覧とリモートインストール、画面上の通知、ポート 9090 と 12800 での BinLoader ペイロード注入があります。USB ドライブに頼らず日常のファイルやチート作業を行い、Prospero Manager 風のリモートコンソール管理を求める PS4 ホームブリュー・改造コミュニティ向けです。
