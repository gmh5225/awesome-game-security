Orbis Web Manager — браузерный командный центр для управления взломанной PlayStation 4 с GoldHEN в локальной сети. Реализован как лёгкое хост-приложение для Windows на C# с HttpListener и адаптивным фронтендом на HTML, CSS и JavaScript; на ПК не нужны Node.js или другие внешние среды выполнения. Ключевые возможности: живой дашборд и проверка портов, просмотр библиотеки игр на основе app.db, обзор файлов по FTP с загрузкой перетаскиванием, просмотр читов GoldHEN и региональное преобразование Title ID, список PKG и удалённая установка, уведомления на экране и внедрение полезной нагрузки BinLoader на портах 9090 и 12800. Ориентирован на сообщество homebrew и моддинга PS4, которому нужно удалённое администрирование консоли в духе Prospero Manager без USB-накопителей в повседневной работе с файлами и читами.
