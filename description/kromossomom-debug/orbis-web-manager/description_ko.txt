Orbis Web Manager는 로컬 네트워크에서 GoldHEN이 실행 중인 탈옥된 PlayStation 4를 관리하기 위한 브라우저 기반 명령 센터입니다. C#과 HttpListener를 사용하는 경량 Windows 호스트 애플리케이션으로 구현되었으며, 반응형 HTML·CSS·JavaScript 프런트엔드를 갖추고 PC에 Node.js나 기타 외부 런타임이 필요하지 않습니다. 주요 기능으로는 실시간 대시보드와 포트 확인, app.db 기반 게임 라이브러리 보기, 드래그 앤 드롭 업로드를 지원하는 FTP 파일 탐색, GoldHEN 치트 보기 및 지역별 Title ID 변환, PKG 목록 및 원격 설치, 화면 알림, 포트 9090과 12800에서의 BinLoader 페이로드 주입이 있습니다. 일상적인 파일·치트 작업에 USB 드라이브에 의존하지 않고 Prospero Manager 스타일의 원격 콘솔 관리를 원하는 PS4 홈브류·모딩 커뮤니티를 대상으로 합니다.
