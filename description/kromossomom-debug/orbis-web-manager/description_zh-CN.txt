Orbis Web Manager 是一款基于浏览器的指挥中心，用于在局域网内管理已越狱并运行 GoldHEN 的 PlayStation 4。它以轻量级 Windows 主机应用实现，采用 C# 与 HttpListener，配合响应式 HTML、CSS 和 JavaScript 前端，PC 端无需 Node.js 或其他外部运行时。主要功能包括实时仪表板与端口检测、基于 app.db 的游戏库视图、支持拖放上传的 FTP 文件浏览、GoldHEN 作弊查看与区域 Title ID 转换、PKG 列表与远程安装、屏幕通知，以及在 9090 与 12800 端口上的 BinLoader 载荷注入。面向希望在日常文件与作弊流程中不依赖 U 盘、以 Prospero Manager 风格远程管理主机的 PS4 自制与改装社区。
