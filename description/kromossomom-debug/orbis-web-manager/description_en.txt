Orbis Web Manager is a browser-based command center for managing a jailbroken PlayStation 4 running GoldHEN over the local network. It is implemented as a lightweight Windows host application in C# using HttpListener with a responsive HTML, CSS, and JavaScript frontend, and it needs no Node.js or other external runtime on the PC. Key capabilities include live dashboard and port checks, game library views backed by app.db, FTP file browsing with drag-and-drop uploads, GoldHEN cheat viewing and regional Title ID conversion, PKG listing and remote installation, on-screen notifications, and BinLoader payload injection on ports 9090 and 12800. It is aimed at the PS4 homebrew and modding community who want Prospero Manager-style remote console administration without relying on USB drives for everyday file and cheat workflows.
