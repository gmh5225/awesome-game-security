Orbis Web Manager est un centre de commande accessible depuis le navigateur pour gérer une PlayStation 4 jailbreakée exécutant GoldHEN sur le réseau local. Il s’agit d’une application hôte Windows légère en C# utilisant HttpListener, avec une interface HTML, CSS et JavaScript responsive, sans nécessiter Node.js ni autre runtime externe sur le PC. Les fonctions principales incluent un tableau de bord en direct et des vérifications de ports, des vues de bibliothèque de jeux basées sur app.db, la navigation de fichiers FTP avec téléversement par glisser-déposer, la consultation des cheats GoldHEN et la conversion régionale des Title ID, le listage des PKG et l’installation à distance, des notifications à l’écran, ainsi que l’injection de charges BinLoader sur les ports 9090 et 12800. Il s’adresse à la communauté homebrew et modding PS4 qui souhaite une administration à distance de type Prospero Manager sans dépendre de clés USB pour les flux quotidiens de fichiers et de cheats.
