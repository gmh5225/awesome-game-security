Litmus는 오픈 소스 Android 복원력 벤치마크로, 카나리 앱을 제공해 패치·재패키징·계측 후 조작이 얼마나 탐지를 피하는지 측정할 수 있습니다. 스택은 Java Android 프로브 러너, C++ 네이티브 ELF 및 메모리 포렌식, 기준선 기록·실험 실행·재현 가능한 JSON 점수와 HTML 보고서를 내보내는 Python CLI로 구성됩니다. 패키지 무결성, 코드 주입, 런타임 후킹, 권한 상승, 가상화, 환경 신호 등 수십 가지 카탈로그화된 탐지 벡터를 검사하며, 깨끗한 기준선 대비 사각지대와 오탐을 점수로 강조합니다. 서드파티 런타임 의존을 피하며 OWASP MASVS 복원력 가정 하에서 Android 8부터 최신 릴리스까지 실제 기기에서 안티탬퍼·안티치트형 강화를 검증하는 개발자를 대상으로 합니다.
