Litmus 是一款開源的 Android 韌性基準測試工具，附帶金絲雀應用程式，便於你對應用程式打補丁、重新封裝或插樁，並衡量篡改行為仍有多少能逃避偵測。其技術堆疊包含 Java Android 探針執行器、C++ 原生 ELF 與記憶體鑑識，以及用於記錄基線、執行實驗並輸出可重現 JSON 分數與 HTML 報告的 Python CLI。它對套件完整性、程式碼注入、執行階段 Hook、權限提升、虛擬化與環境訊號等數十種編目偵測向量進行演練，評分機制可對照乾淨基線突出盲點與誤報。專案刻意避免第三方執行階段依賴，面向在 OWASP MASVS 韌性假設下、於 Android 8 至目前版本真機上驗證防篡改與反作弊類加固的開發者。
