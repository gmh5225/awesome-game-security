Litmus 是一款开源的 Android 韧性基准测试工具，附带金丝雀应用，便于你对应用打补丁、重打包或插桩，并衡量篡改行为仍有多少能逃避检测。其技术栈包含 Java Android 探针运行器、C++ 原生 ELF 与内存取证，以及用于记录基线、执行实验并输出可复现 JSON 分数与 HTML 报告的 Python CLI。它对包完整性、代码注入、运行时 Hook、权限提升、虚拟化与环境信号等数十种编目检测向量进行演练，评分机制可对照干净基线突出盲区与误报。项目刻意避免第三方运行时依赖，面向在 OWASP MASVS 韧性假设下、于 Android 8 至当前版本真机上验证防篡改与反作弊类加固的开发者。
