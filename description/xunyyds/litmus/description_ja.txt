Litmus はオープンソースの Android レジリエンスベンチマークで、カナリアアプリを同梱し、パッチ適用・再パック・計装後に改ざんのうち検知を逃れる割合を測定できます。スタックは Java 製 Android プローブランナー、C++ ネイティブの ELF およびメモリフォレンジック、ベースライン記録・実験実行・再現可能な JSON スコアと HTML レポート出力用の Python CLI で構成されます。パッケージ整合性、コード注入、ランタイムフック、権限昇格、仮想化、環境シグナルなど数十の検知ベクトルを走査し、クリーンなベースラインに対する盲点と誤検知をスコアで可視化します。第三者ランタイム依存を避け、OWASP MASVS のレジリエンス前提のもと、Android 8 から現行リリースまでの実機で改ざん防止・チート対策系のハードニングを検証する開発者向けです。
