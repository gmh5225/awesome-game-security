Litmus is an open Android resilience benchmark that ships a canary app so you can patch, repack, or instrument it and measure how much of your tampering still evades detection. The stack combines a Java Android probe runner, C++ native ELF and memory forensics, and a Python CLI that records baselines, runs experiments, and emits reproducible JSON scores plus HTML reports. It exercises dozens of cataloged detection vectors across package integrity, code injection, runtime hooks, privilege elevation, virtualization, and environment signals, with scoring that highlights blind spots and false positives against a clean baseline. The project deliberately avoids third-party runtime dependencies and targets developers validating anti-tamper and anti-cheat style hardening under OWASP MASVS resilience assumptions on real devices from Android 8 through current releases.
