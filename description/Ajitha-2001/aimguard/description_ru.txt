AimGuard — серверный прототип античита, который принимает телеметрию матчей, оценивает поведение игроков и поддерживает принудительные меры по решению модераторов, а не автоматические баны. Реализован на Python с модулями извлечения признаков прицеливания и движения, правилами валидации с компенсацией задержки, сеточными множествами потенциальной видимости для ограничения репликации на клиентах и проверками целостности сети, включая HMAC и защиту от повторного воспроизведения. Стек включает обработку attestation Play Integrity, статистические и ML-детекторы, хеш-блоклисты с опциональным локальным сканированием ПК, персистентность SQLite и HTTP API с токенной аутентификацией, очередями на проверку, апелляциями и волнами банов. Ориентирован на инженеров по безопасности игр и исследователей античита, которые хотят экспериментировать с оценкой в shadow-режиме, уровнями доверия к доказательствам и операционными процессами до интеграции защиты клиента и инфраструктуры производственного масштаба.
