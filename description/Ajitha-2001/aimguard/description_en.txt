AimGuard is a server-side anti-cheat prototype that ingests match telemetry, scores player behavior, and supports moderator-driven enforcement rather than automatic bans. It is implemented in Python with modules for aim and movement feature extraction, lag-compensated validation rules, grid-based potential visibility sets to limit what clients replicate, and network integrity checks including HMAC and anti-replay. The stack adds Play Integrity attestation handling, statistical and machine-learning detectors, hash blocklists with optional local PC scanning, SQLite persistence, and a token-authenticated HTTP API with review queues, appeals, and ban waves. It targets game security engineers and anti-cheat researchers who want to experiment with shadow-mode scoring, evidence trust levels, and operational workflows before integrating client protection and production-scale infrastructure.
