AimGuard 是一款伺服器端反作弊原型，接收對局遙測資料、對玩家行為評分，並支援由管理員驅動的處置而非自動封禁。它以 Python 實作，包含瞄準與移動特徵擷取、含延遲補償的驗證規則、以網格為基礎的潛在可見性集合以限制用戶端複製範圍，以及含 HMAC 與防重放的網路完整性檢查。技術棧還包括 Play Integrity attestation 處理、統計與機器學習偵測器、雜湊黑名單及可選的本機 PC 掃描、SQLite 持久化，以及含權杖驗證的 HTTP API（含審核佇列、申訴與批量封禁）。面向希望在整合用戶端保護與生產級基礎設施之前，試驗影子模式評分、證據信任等級與營運流程的遊戲安全工程師與反作弊研究人員。
