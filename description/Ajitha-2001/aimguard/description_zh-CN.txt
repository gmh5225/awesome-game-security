AimGuard 是一款服务端反作弊原型，接收对局遥测数据、对玩家行为评分，并支持由管理员驱动的处置而非自动封禁。它以 Python 实现，包含瞄准与移动特征提取、带延迟补偿的校验规则、基于网格的潜在可见性集合以限制客户端复制范围，以及含 HMAC 与防重放的网络完整性检查。技术栈还包括 Play Integrity attestation 处理、统计与机器学习检测器、哈希黑名单及可选的本地 PC 扫描、SQLite 持久化，以及带令牌认证的 HTTP API（含审核队列、申诉与批量封禁）。面向希望在集成客户端保护与生产级基础设施之前，试验影子模式评分、证据信任等级与运营流程的游戏安全工程师与反作弊研究人员。
