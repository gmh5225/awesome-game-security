AimGuard는 서버 측 안티치트 프로토타입으로, 매치 원격 측정 데이터를 수집하고 플레이어 행동을 점수화하며 자동 밴 대신 운영자 주도의 집행을 지원합니다. Python으로 구현되었으며, 에임·이동 특징 추출, 지연 보상 검증 규칙, 클라이언트 복제를 제한하는 그리드 기반 잠재 가시성 집합, HMAC 및 리플레이 방지를 포함한 네트워크 무결성 검사 모듈을 제공합니다. 스택에는 Play Integrity attestation 처리, 통계·머신러닝 탐지기, 해시 블록리스트와 선택적 로컬 PC 스캔, SQLite 영속화, 토큰 인증 HTTP API(검토 대기열, 이의 제기, 밴 웨이브)가 포함됩니다. 클라이언트 보호 및 프로덕션 규모 인프라를 통합하기 전에 섀도 모드 점수화, 증거 신뢰 수준, 운영 워크플로를 실험하려는 게임 보안 엔지니어와 안티치트 연구자를 대상으로 합니다.
