Scalpel 是一款原生 Java/Swing Ghidra 扩展，在 Ghidra 逆向工程平台内提供深色模式的十六进制编辑器。它提供一个可停靠的工具窗口，内含终端风格的十六进制与 ASCII 网格，可跟随 Listing 光标，支持跳转到任意地址，并允许用户将读取窗口配置为 256 字节至 64 KiB。用户可通过 Ghidra 事务内联修补字节，使用含通配符或带引号 UTF-8 字符串的十六进制模式搜索内存，并将所选字节复制为十六进制或 ASCII，同时优雅处理不可读内存区域。基于纯 Swing 与 Java 21 构建，面向需要在游戏安全、反作弊或一般二进制分析流程中进行快速就地二进制检查与编辑的逆向工程师、恶意软件分析师及底层研究人员。
