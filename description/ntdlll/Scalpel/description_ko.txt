Scalpel은 Ghidra 리버스 엔지니어링 플랫폼 내에 다크 모드 16진 편집기를 제공하는 네이티브 Java/Swing Ghidra 확장입니다. 도킹 가능한 도구 창에 Listing 커서를 따라가는 터미널 스타일의 16진 및 ASCII 그리드를 제공하며, 임의 주소로의 점프와 256바이트부터 64 KiB까지의 읽기 창 구성을 지원합니다. Ghidra 트랜잭션을 통한 인라인 바이트 패치, 와일드카드 또는 따옴표로 묶은 UTF-8 문자열을 포함한 16진 패턴으로 메모리 검색, 선택한 바이트를 16진 또는 ASCII로 복사하는 기능을 제공하며, 읽을 수 없는 메모리 범위도 원활하게 처리합니다. 순수 Swing과 Java 21로 구축되었으며, 게임 보안, 안티치트 또는 일반 바이너리 분석 워크플로에서 빠른 현장 바이너리 검사 및 편집이 필요한 리버스 엔지니어, 멀웨어 분석가, 저수준 연구자를 대상으로 합니다.
