Scalpel 是一款原生 Java/Swing Ghidra 擴充功能，在 Ghidra 逆向工程平台內提供深色模式的十六進位編輯器。它提供一個可停靠的工具視窗，內含終端機風格的十六進位與 ASCII 網格，可跟隨 Listing 游標，支援跳轉至任意位址，並允許使用者將讀取視窗設定為 256 位元組至 64 KiB。使用者可透過 Ghidra 交易內聯修補位元組，使用含萬用字元或引號 UTF-8 字串的十六進位模式搜尋記憶體，並將所選位元組複製為十六進位或 ASCII，同時妥善處理不可讀取的記憶體範圍。以純 Swing 與 Java 21 建構，面向需要在遊戲安全、反作弊或一般二進位分析流程中進行快速就地二進位檢查與編輯的逆向工程師、惡意軟體分析師及底層研究人員。
