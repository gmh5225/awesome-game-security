Scalpel ist eine native Java/Swing-Ghidra-Erweiterung, die einen Hex-Editor im Dark Mode innerhalb der Ghidra-Reverse-Engineering-Plattform bereitstellt. Sie bietet ein andockbares Toolfenster mit einem terminalinspirierten Hex- und ASCII-Raster, das dem Listing-Cursor folgt, Sprünge zu beliebigen Adressen unterstützt und es Benutzern ermöglicht, ein Lesefenster von 256 Bytes bis 64 KiB zu konfigurieren. Benutzer können Bytes inline über Ghidra-Transaktionen patchen, den Speicher mit Hex-Mustern einschließlich Platzhaltern oder in Anführungszeichen gesetzten UTF-8-Zeichenfolgen durchsuchen und ausgewählte Bytes als Hex oder ASCII kopieren, während nicht lesbare Speicherbereiche elegant behandelt werden. Mit reinem Swing und Java 21 entwickelt, richtet es sich an Reverse Engineers, Malware-Analysten und Low-Level-Forscher, die schnelle Vor-Ort-Binärinspektion und -bearbeitung bei Game-Security-, Anti-Cheat- oder allgemeinen Binäranalyse-Workflows benötigen.
