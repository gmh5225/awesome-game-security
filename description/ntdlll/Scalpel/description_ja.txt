Scalpel は、Ghidra リバースエンジニアリングプラットフォーム内にダークモードの十六進エディタを提供する、ネイティブな Java/Swing Ghidra 拡張機能です。ドッキング可能なツールウィンドウに、Listing カーソルに追従するターミナル風の十六進および ASCII グリッドを備え、任意のアドレスへのジャンプや、256 バイトから 64 KiB までの読み取りウィンドウの設定が可能です。Ghidra トランザクションによるインラインのバイトパッチ、ワイルドカードや引用符付き UTF-8 文字列を含む十六進パターンによるメモリ検索、選択したバイトの十六進または ASCII 形式でのコピーに対応し、読み取り不能なメモリ範囲も適切に処理します。プレーン Swing と Java 21 で構築され、ゲームセキュリティ、チート対策、または一般的なバイナリ解析ワークフローにおいて、高速なその場でのバイナリ検査と編集を必要とするリバースエンジニア、マルウェアアナリスト、低レベル研究者を対象としています。
