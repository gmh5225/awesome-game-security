Scalpel is a native Java/Swing Ghidra extension that provides a dark-mode hex editor inside the Ghidra reverse engineering platform. It offers a dockable tool window with a terminal-inspired hex and ASCII grid that follows the Listing cursor, supports jumping to arbitrary addresses, and lets users configure a read window from 256 bytes to 64 KiB. Users can patch bytes inline through Ghidra transactions, search memory with hex patterns including wildcards or quoted UTF-8 strings, and copy selected bytes as hex or ASCII while gracefully handling unreadable memory ranges. Built with plain Swing and Java 21, it targets reverse engineers, malware analysts, and low-level researchers who need fast in-place binary inspection and editing during game security, anti-cheat, or general binary analysis workflows.
