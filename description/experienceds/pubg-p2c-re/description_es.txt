Este repositorio contiene un informe de ingeniería inversa sobre un cargador comercial de pago para hacer trampa en PlayerUnknown's Battlegrounds. Documenta cómo el cargador empaquetado con VMProtect utiliza Microsoft Edge WebView2 para la interfaz de licencias, libcurl sobre HTTPS para obtener un payload cifrado, e inyecta un renderizador ESP en dwm.exe en lugar de TslGame.exe para evitar los escaneos de procesos de BattlEye. El análisis abarca la mecánica de inyección en DWM, el renderizado de superposición Direct2D, ejecutables señuelo, la estructura PE del payload, el protocolo de red y cómo el anti-cheat Zakynthos de Krafton identifica hooks de vtable y de código en DWM. Se proporcionan diagramas de arquitectura, plantillas de detección y una matriz comparativa de anti-cheat para investigadores de seguridad de juegos e ingenieros de reverse engineering que estudian la evasión de trampas frente a BattlEye y sistemas anti-cheat a nivel de kernel.
