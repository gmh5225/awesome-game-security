このリポジトリには、PlayerUnknown's Battlegrounds 向けの商用有料チートローダーに関するリバースエンジニアリングレポートが含まれています。VMProtect でパックされたローダーが Microsoft Edge WebView2 をライセンス UI に使用し、libcurl 経由の HTTPS で暗号化ペイロードを取得し、BattlEye のプロセススキャンを回避するために TslGame.exe ではなく dwm.exe に ESP レンダラーを注入する方法が記録されています。分析内容は DWM インジェクションの仕組み、Direct2D オーバーレイ描画、おとりスタブ実行ファイル、ペイロードの PE 構造、ネットワークプロトコル、および Krafton の Zakynthos アンチチートが DWM の vtable とコードフックをどのように検出するかをカバーしています。BattlEye やカーネルレベルのアンチチートシステムに対するチート回避を研究するゲームセキュリティ研究者およびリバースエンジニア向けに、アーキテクチャ図、検出テンプレート、アンチチート比較マトリックスが提供されています。
