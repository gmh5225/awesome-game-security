本プロジェクトは、PCIe DMA ボードの FPGA ファームウェアをカスタマイズし、DMA デバイスではなく Realtek RTL8111 ギガビット Ethernet コントローラとして認識させるためのステップバイステップガイドです。MindShare Arbor を用いてドナー NIC から PCI 設定データを取得し、ベンダー ID・デバイス ID、BAR レイアウト、DSN、PCIe ケイパビリティ構造に関して PCILeech-FPGA の SystemVerilog ソースおよび Xilinx Vivado プロジェクト設定をパッチし、変更したビットストリームをビルドして書き込む一連の手順を解説します。ワークフローは LambdaConcept Screamer Squirrel 35T ボードを対象とし、DMA テストツールによる検証に加え、BattleEye や Easy Anti-Cheat などのアンチチートシステムに対する回避テストも扱います。ゲームセキュリティ研究者、アンチチートアナリスト、リバースエンジニアを対象とし、ハードウェア難読化、DMA 攻撃面、低レベルの PCIe ID スプーフィングと現代のチート検出の相互作用を研究するための資料です。
