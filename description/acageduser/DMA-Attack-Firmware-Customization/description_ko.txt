이 프로젝트는 PCIe DMA 보드의 FPGA 펌웨어를 사용자 정의하여 DMA 장치가 아닌 Realtek RTL8111 기가비트 이더넷 컨트롤러로 인식되도록 하는 단계별 가이드입니다. MindShare Arbor로 기증 네트워크 카드에서 PCI 구성 데이터를 수집하고, 벤더 및 디바이스 ID, BAR 레이아웃, DSN, PCIe capability 구조에 맞게 PCILeech-FPGA SystemVerilog 소스와 Xilinx Vivado 프로젝트 설정을 패치한 뒤 수정된 비트스트림을 빌드하고 플래싱하는 과정을 다룹니다. 워크플로는 LambdaConcept Screamer Squirrel 35T 보드를 대상으로 하며, DMA 테스트 도구를 이용한 검증과 BattleEye, Easy Anti-Cheat 같은 안티치트 시스템에 대한 회피 테스트를 포함합니다. 게임 보안 연구자, 안티치트 분석가, 하드웨어 난독화, DMA 공격 표면, 저수준 PCIe ID 스푸핑과 현대 치트 탐지 간의 상호작용을 연구하는 리버스 엔지니어를 대상으로 합니다.
