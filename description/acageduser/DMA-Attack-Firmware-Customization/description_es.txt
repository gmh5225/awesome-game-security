Este proyecto es una guía paso a paso para personalizar el firmware FPGA de una placa PCIe DMA de modo que se presente como un controlador Ethernet gigabit Realtek RTL8111 en lugar de un dispositivo DMA. Recorre la extracción de datos de configuración PCI de una tarjeta de red donante con MindShare Arbor, el parcheo de las fuentes SystemVerilog de PCILeech-FPGA y la configuración del proyecto Xilinx Vivado para los ID de fabricante y dispositivo, los diseños BAR, el DSN y las estructuras de capacidades PCIe, y luego la compilación y el flasheo del bitstream modificado. El flujo de trabajo está orientado a la placa LambdaConcept Screamer Squirrel 35T e incluye validación con herramientas de prueba DMA, así como pruebas de evasión contra sistemas anti-cheat como BattleEye y Easy Anti-Cheat. Está dirigido a investigadores de seguridad en juegos, analistas anti-cheat e ingenieros inversos que estudian la ofuscación de hardware, las superficies de ataque DMA y cómo el spoofing de identidad PCIe de bajo nivel interactúa con la detección moderna de trampas.
