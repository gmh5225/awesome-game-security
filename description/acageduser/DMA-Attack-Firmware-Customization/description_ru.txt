Этот проект представляет собой пошаговое руководство по настройке прошивки FPGA для PCIe DMA-платы так, чтобы она представлялась системе как контроллер Gigabit Ethernet Realtek RTL8111, а не как DMA-устройство. В нём описывается извлечение данных конфигурации PCI с донорской сетевой карты с помощью MindShare Arbor, правка исходников SystemVerilog PCILeech-FPGA и настроек проекта Xilinx Vivado для vendor и device ID, раскладки BAR, DSN и структур PCIe capability, а затем сборка и прошивка изменённого bitstream. Рабочий процесс ориентирован на плату LambdaConcept Screamer Squirrel 35T и включает проверку с помощью инструментов тестирования DMA, а также тесты на обход античит-систем, таких как BattleEye и Easy Anti-Cheat. Проект предназначен для исследователей безопасности игр, аналитиков античита и специалистов по реверс-инжинирингу, изучающих аппаратную обфускацию, поверхности атак DMA и взаимодействие подмены PCIe-идентичности на низком уровне с современными системами обнаружения читов.
