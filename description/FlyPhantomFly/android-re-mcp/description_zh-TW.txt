android-re-mcp 是一款 Model Context Protocol（MCP）伺服器，可將 AI 助手連接到實機 Android 裝置與目標 APK，實現端到端逆向工程。專案以 Python 3.11+ 實作，提供數十種結構化工具，涵蓋靜態分析（apktool、jadx、androguard、apkid、apkleaks、quark-engine）、借助 Frida 與內建繞過腳本的動態 Hook、DEX 與原生 ELF 修補、mitmproxy 流量擷取，以及 APK 簽署與重新安裝流程。內建 RASP 與加殼識別、引導式評估提示及知識資源，可支援 SSL pinning、Root 與 Frida 偵測、混淆等防護相關問題。面向希望在真機上以 LLM 驅動工作流、而非零散 CLI 指令碼的行動安全研究人員、惡意軟體分析師與遊戲安全從業者。
