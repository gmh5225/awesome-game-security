android-re-mcp 是一款 Model Context Protocol（MCP）服务器，可将 AI 助手连接到实机 Android 设备与目标 APK，实现端到端逆向工程。项目基于 Python 3.11+ 实现，提供数十种结构化工具，涵盖静态分析（apktool、jadx、androguard、apkid、apkleaks、quark-engine）、借助 Frida 及内置绕过脚本的动态 Hook、DEX 与原生 ELF 修补、mitmproxy 流量捕获，以及 APK 签名与重安装流程。内置 RASP 与壳识别、引导式评估提示及知识资源，可解答 SSL pinning、Root 与 Frida 检测、混淆等防护相关疑问。面向希望在真机上以 LLM 驱动工作流、而非零散 CLI 脚本的移动安全研究人员、恶意软件分析师与游戏安全从业者。
