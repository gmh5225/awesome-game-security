android-re-mcp — сервер Model Context Protocol (MCP), который подключает ИИ-ассистентов к работающему Android-устройству и целевому APK для сквозного реверс-инжиниринга. Реализован на Python 3.11+ и предоставляет десятки структурированных инструментов: статический анализ (apktool, jadx, androguard, apkid, apkleaks, quark-engine), динамический хукинг через Frida и встроенные обходные скрипты, патчинг DEX и нативного ELF, перехват трафика mitmproxy, а также подпись и переустановку APK. Встроенное определение RASP и упаковщиков, направляющие подсказки для оценки и справочные материалы помогают с вопросами о защите: SSL pinning, обнаружение root и Frida, обфускация. Адресован исследователям мобильной безопасности, аналитикам вредоносного ПО и специалистам по безопасности игр, которым нужен LLM-управляемый процесс на реальных устройствах вместо разрозненных CLI-скриптов.
