android-re-mcp는 AI 어시스턴트를 실제 Android 기기와 대상 APK에 연결해 엔드투엔드 리버스 엔지니어링을 수행하는 Model Context Protocol(MCP) 서버입니다. Python 3.11 이상으로 구현되었으며, 정적 분석(apktool, jadx, androguard, apkid, apkleaks, quark-engine), Frida와 번들 우회 스크립트를 이용한 동적 후킹, DEX 및 네이티브 ELF 패치, mitmproxy 트래픽 캡처, APK 서명 및 재설치 워크플로 등 수십 개의 구조화된 도구를 제공합니다. 내장 RASP 및 패커 식별, 안내형 평가 프롬프트, 지식 리소스로 SSL pinning, root 및 Frida 탐지, 난독화 같은 보호 기법 관련 질문을 지원합니다. 임시 CLI 스크립팅 대신 실제 기기에서 LLM 기반 워크플로를 원하는 모바일 보안 연구자, 멀웨어 분석가, 게임 보안 실무자를 대상으로
