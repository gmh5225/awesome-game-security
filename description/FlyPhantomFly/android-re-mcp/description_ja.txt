android-re-mcp は、AI アシスタントを実機の Android デバイスと対象 APK に接続し、エンドツーエンドのリバースエンジニアリングを可能にする Model Context Protocol（MCP）サーバーです。Python 3.11 以降で実装され、静的解析（apktool、jadx、androguard、apkid、apkleaks、quark-engine）、Frida と同梱バイパススクリプトによる動的フック、DEX およびネイティブ ELF のパッチ、mitmproxy によるトラフィック取得、APK 署名と再インストールのワークフローなど、数十の構造化ツールを公開します。組み込みの RASP およびパッカー識別、ガイド付き評価プロンプト、ナレッジリソースにより、SSL ピニング、root および Frida 検知、難読化などの保護に関する質問を支援します。アドホックな CLI スクリプトではなく実機上で LLM 駆動のワークフローを求めるモバイルセキュリティ研究者、マルウェアアナリスト、ゲームセキュリティ実務者を対象としています。
