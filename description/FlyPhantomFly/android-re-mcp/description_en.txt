android-re-mcp is a Model Context Protocol (MCP) server that connects AI assistants to a live Android device and target APK for end-to-end reverse engineering. It is implemented in Python 3.11+ and exposes dozens of structured tools for static analysis (apktool, jadx, androguard, apkid, apkleaks, quark-engine), dynamic hooking with Frida and bundled bypass scripts, DEX and native ELF patching, mitmproxy traffic capture, and APK signing and reinstall workflows. Built-in RASP and packer identification, guided assessment prompts, and knowledge resources support questions about protections such as SSL pinning, root and Frida detection, and obfuscation. It is aimed at mobile security researchers, malware analysts, and game-security practitioners who want an LLM-driven workflow over real devices instead of ad hoc CLI scripting.
