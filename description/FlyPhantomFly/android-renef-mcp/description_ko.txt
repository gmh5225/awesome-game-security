android-renef-mcp는 AI 어시스턴트 및 기타 MCP 클라이언트가 Renef(root된 Android ARM64 기기용 Frida 유사 동적 계측 스택)를 제어할 수 있게 해 주는 Model Context Protocol 서버입니다. 주로 Python으로 작성되었으며, ADB 포트 포워딩으로 renef_server와 통신하고, 기기 상 에이전트의 배포 및 수명 주기를 관리합니다. 프로세스 attach·spawn, 대상 프로세스에서 Lua 실행, 네이티브 및 Java 메서드 후킹, 메모리 스캔·패치, hook 또는 strace 출력 수집 등의 도구를 제공합니다. 번들된 Lua 예제와 네이티브 Android, Flutter, React Native, Unity, Xamarin 등에서 SSL 피닝에 초점을 둔 기법 지식 베이스가 포함되어 있습니다. 모바일 보안 연구, 리버스 엔지니어링, 변조 방지·안티치트 분석 워크플로에서 기기상 Frida 스타일 JavaScript보다 Lua 기반 프로세스 내 계측을 선호하는 용도를 대상으로 합니다.
