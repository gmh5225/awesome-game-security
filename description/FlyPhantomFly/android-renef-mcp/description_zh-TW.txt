android-renef-mcp 是一個 Model Context Protocol 伺服器，讓 AI 助理與其他 MCP 用戶端能控制 Renef——面向已 root 的 Android ARM64 裝置、類似 Frida 的動態插樁堆疊。專案主要以 Python 撰寫，透過 ADB 連接埠轉送與 renef_server 通訊，管理裝置端 agent 的部署與生命週期，並提供附加或建立處理、在目標中執行 Lua、hook native 與 Java 方法、掃描與修補記憶體，以及擷取 hook 或 strace 輸出等工具。隨附捆綁的 Lua 範例與技術知識庫，著重原生 Android、Flutter、React Native、Unity、Xamarin 等堆疊上的 SSL 憑證釘選。本專案鎖定行動安全研究、逆向工程與防篡改或防作弊分析流程，適合在裝置上優先採用基於 Lua 的行程內插樁，而非 Frida 式 JavaScript。
