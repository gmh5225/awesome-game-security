android-renef-mcp ist ein Model Context Protocol-Server, mit dem KI-Assistenten und andere MCP-Clients Renef steuern können – einen Frida-ähnlichen Stack für dynamische Instrumentierung auf gerooteten Android-ARM64-Geräten. Hauptsächlich in Python geschrieben, kommuniziert er über ADB-Portweiterleitung mit renef_server, verwaltet Bereitstellung und Lebenszyklus des On-Device-Agenten und stellt Werkzeuge bereit zum Anhängen oder Starten von Prozessen, zum Ausführen von Lua im Ziel, zum Hooken nativer und Java-Methoden, zum Scannen und Patchen von Speicher sowie zum Erfassen von Hook- oder strace-Ausgaben. Enthalten sind gebündelte Lua-Beispiele und eine Technik-Wissensbasis mit Schwerpunkt SSL-Pinning für natives Android, Flutter, React Native, Unity, Xamarin und ähnliche Stacks. Das Projekt richtet sich an mobile Sicherheitsforschung, Reverse Engineering sowie Anti-Tampering- oder Anti-Cheat-Analysen, bei denen Lua-basierte In-Process-Instrumentierung dem Frida-artigen JavaScript auf dem Gerät vorgezogen wird.
