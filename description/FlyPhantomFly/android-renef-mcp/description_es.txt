android-renef-mcp es un servidor Model Context Protocol que permite a asistentes de IA y otros clientes MCP controlar Renef, una pila de instrumentación dinámica similar a Frida para dispositivos Android ARM64 con root. Está escrito principalmente en Python, se comunica con renef_server mediante reenvío de puertos ADB, gestiona el despliegue y el ciclo de vida del agente en el dispositivo, y expone herramientas para adjuntar o crear procesos, ejecutar Lua en el objetivo, interceptar métodos nativos y Java, escanear y parchear memoria, y capturar la salida de hooks o strace. Incluye ejemplos Lua incluidos y una base de conocimiento de técnicas centrada en SSL pinning en Android nativo, Flutter, React Native, Unity, Xamarin y stacks similares. El proyecto está orientado a investigación en seguridad móvil, ingeniería inversa y flujos de análisis anti-manipulación o anti-trampas donde se prefiere la instrumentación in-process basada en Lua frente al JavaScript al estilo Frida en el dispositivo.
