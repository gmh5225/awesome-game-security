android-renef-mcp は、AI アシスタントやその他の MCP クライアントが Renef（root 済み Android ARM64 向けの Frida 系動的インストルメンテーションスタック）を操作できる Model Context Protocol サーバーです。主に Python で書かれ、ADB ポートフォワーディング経由で renef_server と通信し、デバイス上エージェントのデプロイとライフサイクルを管理します。プロセスのアタッチや起動、ターゲット内での Lua 実行、ネイティブおよび Java メソッドのフック、メモリのスキャンとパッチ、フックや strace 出力の取得などのツールを提供します。同梱の Lua サンプルと、ネイティブ Android、Flutter、React Native、Unity、Xamarin などにおける SSL ピニング向けの技法ナレッジベースを備えています。モバイルセキュリティ研究、リバースエンジニアリング、改ざん防止やアンチチート分析など、デバイス上で Frida 式 JavaScript より Lua ベースのプロセス内インストルメンテーションを優先するワークフローを対象としています。
