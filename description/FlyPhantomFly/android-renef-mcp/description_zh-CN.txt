android-renef-mcp 是一个 Model Context Protocol 服务器，使 AI 助手及其他 MCP 客户端能够控制 Renef——面向已 root 的 Android ARM64 设备、类似 Frida 的动态插桩栈。项目主要用 Python 编写，通过 ADB 端口转发与 renef_server 通信，负责设备端 agent 的部署与生命周期管理，并提供附加或拉起进程、在目标进程中执行 Lua、挂钩 native 与 Java 方法、扫描与修补内存以及采集 hook 或 strace 输出等工具。仓库附带 Lua 示例及技术知识库，侧重原生 Android、Flutter、React Native、Unity、Xamarin 等栈上的 SSL 证书固定绕过。该项目面向移动安全研究、逆向工程以及反篡改或反作弊分析等场景，适合在设备上优先采用基于 Lua 的进程内插桩，而非 Frida 式 JavaScript。
