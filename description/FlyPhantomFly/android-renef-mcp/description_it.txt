android-renef-mcp è un server Model Context Protocol che consente ad assistenti IA e altri client MCP di controllare Renef, uno stack di strumentazione dinamica simile a Frida per dispositivi Android ARM64 con root. Scritto principalmente in Python, comunica con renef_server tramite port forwarding ADB, gestisce deploy e ciclo di vita dell’agente sul dispositivo ed espone strumenti per collegarsi o avviare processi, eseguire Lua nel target, agganciare metodi nativi e Java, scansionare e patchare la memoria e catturare l’output di hook o strace. Include esempi Lua in bundle e una knowledge base di tecniche incentrata sul SSL pinning su Android nativo, Flutter, React Native, Unity, Xamarin e stack simili. Il progetto è rivolto alla ricerca sulla sicurezza mobile, al reverse engineering e ai flussi di analisi anti-manomissione o anti-cheat in cui si preferisce l’instrumentazione in-process basata su Lua al JavaScript in stile Frida sul dispositivo.
