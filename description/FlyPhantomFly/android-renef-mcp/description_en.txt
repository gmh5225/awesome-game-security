android-renef-mcp is a Model Context Protocol server that lets AI assistants and other MCP clients control Renef, a Frida-like dynamic instrumentation stack for rooted Android ARM64 devices. Written primarily in Python, it talks to renef_server over ADB port forwarding, manages deploy and lifecycle of the on-device agent, and exposes tools to attach or spawn processes, run Lua inside the target, hook native and Java methods, scan and patch memory, and capture hook or strace output. It ships bundled Lua examples plus a technique knowledge base focused on SSL pinning across native Android, Flutter, React Native, Unity, Xamarin, and similar stacks. The project targets mobile security research, reverse engineering, and anti-tampering or anti-cheat analysis workflows where Lua-based in-process instrumentation is preferred over Frida-style JavaScript on the device.
