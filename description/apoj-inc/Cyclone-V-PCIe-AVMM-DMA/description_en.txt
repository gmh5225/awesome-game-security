This project is a configurable PCIe 2.0 x4 FPGA DMA controller that moves data between a host PC and on-chip logic through Avalon-MM (AVMM) interfaces and FIFOs. The RTL is written in SystemVerilog and targets Intel Cyclone V boards, with Intel Quartus Platform Designer integration, Makefile-driven synthesis and programming, and Questa or Cocotb simulation testbenches. It supports up to sixteen independent DMA channels, MSI-X completion interrupts, one external interrupt source per channel, and hook-up of custom control/status registers on the AVMM bus. A Linux kernel module and C userspace examples exercise multi-channel echo, parallel read/write, and IRQ paths for end-to-end bring-up. It suits hardware and security researchers who need a full reference stack for custom PCIe DMA FPGA designs, including study of DMA-style attack surfaces relevant to game anti-cheat and low-level system security.
