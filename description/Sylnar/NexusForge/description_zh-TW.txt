NexusForge（Sylnar）是一款獨立的 Windows 桌面應用程式，用於管理以 FPGA 為基礎的直接記憶體存取（DMA）板卡，無需安裝 Xilinx Vivado。以 C#、.NET 8 與 Avalonia 建構，透過內附的 OpenOCD 設定在 CH347 JTAG 上自動偵測 Artix-7 與 Kintex-7 裝置，讀取 57 位元裝置 DNA，並燒錄 DNA 鎖定的 SPI 或 volatile 位元流韌體，即時顯示擦除、寫入與校驗進度。此工具可安裝並管理 CH347 JTAG 與 FTDI FT601 USB3 驅動程式，列舉 PCIe BAR，並執行 DMA 讀取測速以確認主機 PC 對實體記憶體的存取。面向在遊戲安全、反作弊與逆向工程流程中設定、更新與驗證商用 DMA 硬體的操作人員與研究人員。
