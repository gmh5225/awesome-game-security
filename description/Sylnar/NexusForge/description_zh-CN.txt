NexusForge（Sylnar）是一款独立的 Windows 桌面应用程序，用于管理基于 FPGA 的直接内存访问（DMA）板卡，无需安装 Xilinx Vivado。基于 C#、.NET 8 与 Avalonia 构建，它通过内置的 OpenOCD 配置在 CH347 JTAG 上自动识别 Artix-7 与 Kintex-7 设备，读取 57 位设备 DNA，并烧录 DNA 锁定的 SPI 或 volatile 位流固件，实时显示擦除、写入与校验进度。该工具可安装并管理 CH347 JTAG 与 FTDI FT601 USB3 驱动，枚举 PCIe BAR，并运行 DMA 读取测速以确认主机 PC 对物理内存的访问。面向在游戏安全、反作弊与逆向工程工作流中配置、更新与验证商用 DMA 硬件的操作员与研究人员。
