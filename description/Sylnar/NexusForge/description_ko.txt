NexusForge(Sylnar)는 Xilinx Vivado 없이 FPGA 기반 직접 메모리 액세스(DMA) 보드를 관리하는 독립형 Windows 데스크톱 애플리케이션입니다. C#과 .NET 8, Avalonia로 제작되었으며, 번들된 OpenOCD 설정으로 CH347 JTAG를 통해 Artix-7 및 Kintex-7 장치를 자동 감지하고, 57비트 장치 DNA를 읽으며, DNA 잠금 SPI 또는 volatile 비트스트림 펌웨어를 지우기·쓰기·검증 진행 상황을 실시간으로 표시하며 플래시합니다. CH347 JTAG 및 FTDI FT601 USB3 드라이버 설치·관리, PCIe BAR 열거, 호스트 PC에서 물리 메모리 접근을 확인하는 DMA 읽기 속도 테스트를 수행합니다. 게임 보안, 안티치트, 리버스 엔지니어링 워크플로에서 흔히 언급되는 상용 DMA 하드웨어를 설정·업데이트·검증하는 운영자와 연구자를 대상으로 합니다.
