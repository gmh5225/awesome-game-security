NexusForge (Sylnar) is a standalone Windows desktop application for managing FPGA-based direct memory access boards without requiring Xilinx Vivado. Built with C# on .NET 8 and Avalonia, it auto-detects Artix-7 and Kintex-7 devices over CH347 JTAG using bundled OpenOCD configs, reads 57-bit device DNA, and flashes DNA-locked SPI or volatile bitstream firmware with live erase, write, and verify progress. The tool installs and manages CH347 JTAG and FTDI FT601 USB3 drivers, enumerates PCIe BARs, and runs DMA read speed tests to confirm physical memory access from a host PC. It targets operators and researchers who set up, update, and validate commercial DMA hardware commonly referenced in game security, anti-cheat, and reverse-engineering workflows.
