NexusForge (Sylnar) — автономное настольное приложение Windows для управления платами прямого доступа к памяти (DMA) на базе FPGA без необходимости в Xilinx Vivado. Написано на C# для .NET 8 с использованием Avalonia; автоматически обнаруживает устройства Artix-7 и Kintex-7 по JTAG CH347 с помощью поставляемых конфигураций OpenOCD, считывает 57-битный DNA устройства и прошивает DNA-заблокированную SPI- или volatile bitstream-прошивку с отображением хода стирания, записи и проверки в реальном времени. Утилита устанавливает и управляет драйверами CH347 JTAG и FTDI FT601 USB3, перечисляет BAR PCIe и выполняет тесты скорости чтения DMA для подтверждения доступа к физической памяти с хост-ПК. Предназначена для операторов и исследователей, которые настраивают, обновляют и проверяют коммерческое DMA-оборудование, часто упоминаемое в контексте безопасности игр, античита и reverse engineering.
