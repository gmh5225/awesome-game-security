Freeplay は Rust で書かれたオープンソースの Windows 向けゲームトレーナーで、インストール済みのゲームを検出し、シングルプレイヤープロセスにアタッチして、ポインタスキャン、値の固定、命令パッチによるメモリ改変を行います。ゲームはハードコードされたロジックではなく TOML テーブルファイルで設定され、Cheat Engine の .CT テーブルをインポートでき、組み込みの x86/x64 アセンブラを通じて Auto Assembler スクリプトを実行し、コードケーブを確保して命令をフックします。Tauri 製デスクトップアプリ（ゲーム内オーバーレイ付き）、コマンドラインインターフェース、ユーザーフィードバックでランク付けされた大規模なコミュニティ変換チートテーブルライブラリへのアクセスを提供します。Steam、Epic、GOG ライブラリと統合し、32 ビットおよび 64 ビットターゲットをサポートし、EasyAntiCheat、BattlEye、Vanguard などの反チートシステムで保護されたプロセスにはアタッチしません。オフラインおよびシングルプレイヤー向けの透明性が高く自己ホスト可能な、商用トレーナーの代替を求めるプレイヤー向けです。
