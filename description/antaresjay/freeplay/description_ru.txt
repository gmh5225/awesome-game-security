Freeplay — это открытый игровой тренер для Windows, написанный на Rust, который обнаруживает установленные игры, подключается к однопользовательским процессам и изменяет память с помощью сканирования указателей, заморозки значений и патчинга инструкций. Игры настраиваются файлами таблиц TOML вместо жёстко заданной логики, а инструмент может импортировать таблицы .CT из Cheat Engine и выполнять скрипты Auto Assembler через встроенный ассемблер x86 и x64, который выделяет code caves и перехватывает инструкции. Он предоставляет настольное приложение на Tauri с внутриигровым оверлеем, интерфейс командной строки и доступ к большой сообщественной библиотеке конвертированных чит-таблиц, ранжированных по отзывам пользователей. Проект интегрируется с библиотеками Steam, Epic и GOG, поддерживает 32- и 64-битные цели и отказывается подключаться к процессам, защищённым античит-системами, такими как EasyAntiCheat, BattlEye и Vanguard. Он предназначен для игроков, которым нужна прозрачная, самохостинговая альтернатива коммерческим тренерам для модификации офлайн- и однопользовательских игр.
