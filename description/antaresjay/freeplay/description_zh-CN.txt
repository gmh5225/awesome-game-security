Freeplay 是一款用 Rust 编写的开源 Windows 游戏修改器，可发现已安装的游戏、附加到单人游戏进程，并通过指针扫描、数值冻结和指令修补来修改内存。游戏配置采用 TOML 表文件而非硬编码逻辑，该工具可导入 Cheat Engine 的 .CT 表，并通过内置的 x86 与 x64 汇编器运行 Auto Assembler 脚本，分配代码洞并挂钩指令。它提供带游戏内叠加层的 Tauri 桌面应用、命令行界面，以及按用户反馈排名的大型社区转换作弊表库。该项目与 Steam、Epic 和 GOG 库集成，支持 32 位和 64 位目标，并拒绝附加受 EasyAntiCheat、BattlEye 和 Vanguard 等反作弊系统保护的进程。它面向希望获得透明、自托管的离线与单人游戏修改替代方案、以取代商业修改器的玩家。
