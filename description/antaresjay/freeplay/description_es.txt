Freeplay es un entrenador de juegos para Windows de código abierto escrito en Rust que detecta juegos instalados, se adjunta a procesos de un solo jugador y modifica la memoria mediante escaneos de punteros, congelación de valores y parches de instrucciones. Los juegos se configuran con archivos de tabla TOML en lugar de lógica codificada, y la herramienta puede importar tablas .CT de Cheat Engine mientras ejecuta scripts de Auto Assembler mediante un ensamblador x86 y x64 integrado que asigna code caves y engancha instrucciones. Proporciona una aplicación de escritorio Tauri con superposición en el juego, una interfaz de línea de comandos y acceso a una gran biblioteca comunitaria de tablas de trucos convertidas clasificadas según la opinión de los usuarios. El proyecto se integra con las bibliotecas de Steam, Epic y GOG, admite objetivos de 32 y 64 bits y se niega a adjuntarse a procesos protegidos por sistemas antitrampas como EasyAntiCheat, BattlEye y Vanguard. Está dirigido a jugadores que desean una alternativa transparente y autoalojada a los entrenadores comerciales para la modificación de juegos sin conexión y para un solo jugador.
