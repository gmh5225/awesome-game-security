Freeplay is an open-source Windows game trainer written in Rust that discovers installed games, attaches to single-player processes, and modifies memory through pointer scans, value freezing, and instruction patching. Games are configured with TOML table files instead of hard-coded logic, and the tool can import Cheat Engine .CT tables while running Auto Assembler scripts via a built-in x86 and x64 assembler that allocates code caves and hooks instructions. It provides a Tauri desktop app with an in-game overlay, a command-line interface, and access to a large community library of converted cheat tables ranked by user feedback. The project integrates with Steam, Epic, and GOG libraries, supports 32-bit and 64-bit targets, and refuses to attach to processes protected by anti-cheat systems such as EasyAntiCheat, BattlEye, and Vanguard. It is aimed at players who want a transparent, self-hosted alternative to commercial trainers for offline and single-player game modification.
