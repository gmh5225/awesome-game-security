Freeplay 是一款以 Rust 撰寫的開源 Windows 遊戲修改器，可偵測已安裝的遊戲、附加至單人遊戲程序，並透過指標掃描、數值凍結與指令修補來修改記憶體。遊戲設定採用 TOML 表檔而非硬編碼邏輯，此工具可匯入 Cheat Engine 的 .CT 表，並透過內建的 x86 與 x64 組合器執行 Auto Assembler 腳本，配置程式碼洞並掛鉤指令。它提供附帶遊戲內覆蓋層的 Tauri 桌面應用程式、命令列介面，以及依使用者回饋排名的大型社群轉換作弊表資料庫。此專案與 Steam、Epic 和 GOG 資料庫整合，支援 32 位元與 64 位元目標，並拒絕附加受 EasyAntiCheat、BattlEye 和 Vanguard 等反作弊系統保護的程序。它面向希望取得透明、自架且可取代商業修改器的離線與單人遊戲修改替代方案的玩家。
