Este es un paquete de plugins para el asistente de IA de escritorio DeepSeek Harness (DSH) que lo amplía con integración de herramientas externas y automatización. La colección incluye un puente Ghidra para importar binarios, descompilar funciones y consultar cadenas y referencias cruzadas mediante un servidor PyGhidra, además de un puente forense que envuelve radare2, RetDec, Wireshark tshark y mitmproxy para análisis binario y captura de paquetes. Un plugin agent-bridge permite a DSH delegar tareas a agentes locales Claude Code, OpenAI Codex o Tencent Marvis con trabajos en segundo plano en streaming. Escritos principalmente en JavaScript con scripts Python para Ghidra y adaptadores de web scraping, los plugins se instalan como perfiles de bundle DSH en Windows. Está dirigido a investigadores de seguridad e ingenieros de ingeniería inversa que desean un flujo de trabajo asistido por IA para análisis de malware, inspección de binarios de juegos y forense de red sin salir del entorno DSH.
