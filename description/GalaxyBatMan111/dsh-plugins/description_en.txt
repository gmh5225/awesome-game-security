This is a plugin bundle for the DeepSeek Harness (DSH) desktop AI assistant that extends it with external tool integration and automation. The collection includes a Ghidra bridge for importing binaries, decompiling functions, and querying strings and cross-references through a PyGhidra server, plus a forensics bridge that wraps radare2, RetDec, Wireshark tshark, and mitmproxy for binary analysis and packet capture. An agent-bridge plugin lets DSH delegate tasks to local Claude Code, OpenAI Codex, or Tencent Marvis agents with streaming background jobs. Written primarily in JavaScript with Python scripts for Ghidra and web-scraping adapters, the plugins install as DSH bundle profiles on Windows. It targets security researchers and reverse engineers who want an AI-assisted workflow for malware analysis, game binary inspection, and network forensics without leaving the DSH environment.
