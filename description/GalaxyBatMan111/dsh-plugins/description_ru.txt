Это набор плагинов для настольного ИИ-ассистента DeepSeek Harness (DSH), расширяющий его интеграцией внешних инструментов и автоматизацией. В коллекцию входит мост Ghidra для импорта бинарных файлов, декомпиляции функций и запросов строк и перекрёстных ссылок через сервер PyGhidra, а также форензический мост, оборачивающий radare2, RetDec, Wireshark tshark и mitmproxy для бинарного анализа и захвата пакетов. Плагин agent-bridge позволяет DSH делегировать задачи локальным агентам Claude Code, OpenAI Codex или Tencent Marvis с потоковыми фоновыми заданиями. Плагины написаны преимущественно на JavaScript с Python-скриптами для Ghidra и адаптеров веб-скрейпинга и устанавливаются как профили bundle DSH в Windows. Ориентирован на исследователей безопасности и специалистов по реверс-инжинирингу, которым нужен ИИ-поддерживаемый рабочий процесс для анализа вредоносного ПО, проверки игровых бинарников и сетевой форензики без выхода из среды DSH.
