DeepSeek Harness（DSH）デスクトップ AI アシスタント向けのプラグインバンドルで、外部ツール連携と自動化機能を拡張します。コレクションには、PyGhidra サーバー経由でバイナリのインポート、関数の逆コンパイル、文字列とクロスリファレンスの照会を行う Ghidra ブリッジに加え、radare2、RetDec、Wireshark tshark、mitmproxy をラップしてバイナリ解析とパケットキャプチャを行うフォレンジック ブリッジが含まれます。agent-bridge プラグインにより、DSH はローカルの Claude Code、OpenAI Codex、Tencent Marvis エージェントへタスクを委譲し、ストリーミングのバックグラウンドジョブを実行できます。主に JavaScript で記述され、Ghidra や Web スクレイピング用アダプターには Python スクリプトを使用し、Windows 上で DSH バンドルプロファイルとしてインストールされます。DSH 環境を離れずに、マルウェア解析、ゲームバイナリ調査、ネットワークフォレンジックを AI 支援ワークフローで行いたいセキュリティ研究者とリバースエンジニアを対象としています。
