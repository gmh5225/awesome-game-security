这是面向 DeepSeek Harness（DSH）桌面 AI 助手的插件包，为其扩展外部工具集成与自动化能力。该集合包含 Ghidra 桥接插件，可通过 PyGhidra 服务器导入二进制文件、反编译函数并查询字符串与交叉引用；还包含取证桥接插件，封装 radare2、RetDec、Wireshark tshark 和 mitmproxy，用于二进制分析与数据包捕获。agent-bridge 插件允许 DSH 将任务委派给本地 Claude Code、OpenAI Codex 或腾讯 Marvis 代理，并支持流式后台作业。插件主要使用 JavaScript 编写，Ghidra 与网页抓取适配器采用 Python 脚本，在 Windows 上以 DSH bundle profile 形式安装。面向希望在 DSH 环境中完成恶意软件分析、游戏二进制检查与网络取证，且无需切换工作环境的 AI 辅助安全研究人员与逆向工程师。
