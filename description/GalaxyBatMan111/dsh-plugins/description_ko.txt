DeepSeek Harness(DSH) 데스크톱 AI 어시스턴트용 플러그인 번들로, 외부 도구 통합과 자동화 기능을 확장합니다. 이 모음에는 PyGhidra 서버를 통해 바이너리를 가져오고 함수를 디컴파일하며 문자열과 교차 참조를 조회하는 Ghidra 브리지와, radare2, RetDec, Wireshark tshark, mitmproxy를 래핑하여 바이너리 분석 및 패킷 캡처를 수행하는 포렌식 브리지가 포함됩니다. agent-bridge 플러그인을 통해 DSH는 로컬 Claude Code, OpenAI Codex, Tencent Marvis 에이전트에 작업을 위임하고 스트리밍 백그라운드 작업을 실행할 수 있습니다. 주로 JavaScript로 작성되었으며 Ghidra 및 웹 스크래핑 어댑터에는 Python 스크립트를 사용하고, Windows에서 DSH 번들 프로필로 설치됩니다. DSH 환경을 벗어나지 않고 AI 지원 워크플로로 멀웨어 분석, 게임 바이너리 검사, 네트워크 포렌식을 수행하려는 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
