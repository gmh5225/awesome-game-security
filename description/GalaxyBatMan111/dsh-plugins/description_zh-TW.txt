這是面向 DeepSeek Harness（DSH）桌面 AI 助手的插件套件，為其擴充外部工具整合與自動化能力。此集合包含 Ghidra 橋接插件，可透過 PyGhidra 伺服器匯入二進位檔、反編譯函式並查詢字串與交叉參考；另含取證橋接插件，封裝 radare2、RetDec、Wireshark tshark 與 mitmproxy，用於二進位分析與封包擷取。agent-bridge 插件可讓 DSH 將任務委派給本機 Claude Code、OpenAI Codex 或騰訊 Marvis 代理，並支援串流背景作業。插件主要以 JavaScript 撰寫，Ghidra 與網頁擷取適配器則使用 Python 腳本，在 Windows 上以 DSH bundle profile 形式安裝。面向希望在 DSH 環境中完成惡意軟體分析、遊戲二進位檢查與網路取證，且無需離開工作環境的 AI 輔助安全研究人員與逆向工程師。
