Questo è un bundle di plugin per l'assistente IA desktop DeepSeek Harness (DSH) che lo estende con integrazione di strumenti esterni e automazione. La raccolta include un bridge Ghidra per importare binari, decompilare funzioni e interrogare stringhe e riferimenti incrociati tramite un server PyGhidra, oltre a un bridge forense che avvolge radare2, RetDec, Wireshark tshark e mitmproxy per l'analisi binaria e la cattura di pacchetti. Un plugin agent-bridge consente a DSH di delegare attività ad agenti locali Claude Code, OpenAI Codex o Tencent Marvis con job in background in streaming. Scritti principalmente in JavaScript con script Python per Ghidra e adattatori di web scraping, i plugin si installano come profili bundle DSH su Windows. È rivolto a ricercatori di sicurezza e reverse engineer che desiderano un flusso di lavoro assistito dall'IA per l'analisi di malware, l'ispezione di binari di giochi e la forensics di rete senza uscire dall'ambiente DSH.
