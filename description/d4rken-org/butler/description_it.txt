Butler è un file explorer e gestore di app per Android che offre navigazione approfondita del filesystem, ispezione dei pacchetti e accesso privilegiato all'archiviazione sui dispositivi mobili. Scritto principalmente in Kotlin con Jetpack Compose, Hilt e Room, combina un explorer multipannello con gestione degli archivi, recupero dal cestino, un editor di testo integrato e un'area di lavoro per le app installate per metadati APK, dettagli dei componenti e query sui processi in esecuzione. L'app può elevare l'accesso tramite root, Shizuku, ADB e backend shell per raggiungere percorsi protetti come Android/data ed eseguire operazioni su pacchetti e file che le normali API di archiviazione non possono eseguire. È destinata a ricercatori di sicurezza Android, ingegneri del reverse engineering e analisti di sicurezza dei giochi che necessitano di uno strumento avanzato per ispezionare i dati delle app, manipolare file di gioco e verificare le applicazioni installate su dispositivi rootati o debuggabili.
