Butler 是一款 Android 檔案瀏覽器和應用程式管理器，可在行動裝置上提供深度檔案系統瀏覽、套件檢查和特權儲存存取。它主要使用 Kotlin 編寫，採用 Jetpack Compose、Hilt 和 Room，將多窗格資源管理器與封存處理、回收站復原、內建文字編輯器以及已安裝應用程式工作區相結合，用於檢視 APK 中繼資料、元件詳細資訊和執行中程序查詢。此應用程式可透過 root、Shizuku、ADB 和 shell 後端提升存取權限，以存取 Android/data 等受保護路徑，並執行一般儲存 API 無法完成的套件和檔案操作。它面向需要進階工具來檢查應用程式資料、操作遊戲檔案以及在已 root 或可除錯裝置上稽核已安裝應用程式的 Android 安全研究人員、逆向工程師和遊戲安全分析師。
