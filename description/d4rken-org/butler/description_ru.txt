Butler — это файловый проводник и менеджер приложений для Android, обеспечивающий глубокий просмотр файловой системы, инспекцию пакетов и привилегированный доступ к хранилищу на мобильных устройствах. Написанное преимущественно на Kotlin с использованием Jetpack Compose, Hilt и Room, приложение сочетает многопанельный проводник с обработкой архивов, восстановлением из корзины, встроенным текстовым редактором и рабочей областью для установленных приложений с метаданными APK, сведениями о компонентах и запросами к запущенным процессам. Приложение может повышать уровень доступа через root, Shizuku, ADB и shell-бэкенды для доступа к защищённым путям, таким как Android/data, и выполнения операций с пакетами и файлами, недоступных обычным API хранилища. Оно предназначено для исследователей безопасности Android, специалистов по реверс-инжинирингу и аналитиков игровой безопасности, которым нужен продвинутый инструмент для инспекции данных приложений, работы с игровыми файлами и аудита установленных приложений на root-устройствах или устройствах с отладкой.
