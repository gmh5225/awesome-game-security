Butler is an Android file explorer and app manager that provides deep filesystem browsing, package inspection, and privileged storage access on mobile devices. Written primarily in Kotlin with Jetpack Compose, Hilt, and Room, it combines a multi-pane explorer with archive handling, trash recovery, a built-in text editor, and an installed-apps workspace for APK metadata, component details, and running-process queries. The app can escalate access through root, Shizuku, ADB, and shell backends to reach protected paths such as Android/data and to run package and file operations that normal storage APIs cannot perform. It is aimed at Android security researchers, reverse engineers, and game security analysts who need a power-user tool for inspecting app data, manipulating game files, and auditing installed applications on rooted or debuggable devices.
