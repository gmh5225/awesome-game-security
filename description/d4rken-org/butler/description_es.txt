Butler es un explorador de archivos y gestor de aplicaciones para Android que ofrece navegación profunda del sistema de archivos, inspección de paquetes y acceso privilegiado al almacenamiento en dispositivos móviles. Escrito principalmente en Kotlin con Jetpack Compose, Hilt y Room, combina un explorador multipanel con gestión de archivos comprimidos, recuperación de la papelera, un editor de texto integrado y un espacio de trabajo para aplicaciones instaladas con metadatos APK, detalles de componentes y consultas de procesos en ejecución. La aplicación puede elevar el acceso mediante root, Shizuku, ADB y backends de shell para alcanzar rutas protegidas como Android/data y ejecutar operaciones de paquetes y archivos que las API de almacenamiento normales no pueden realizar. Está dirigida a investigadores de seguridad de Android, ingenieros de ingeniería inversa y analistas de seguridad de juegos que necesitan una herramienta avanzada para inspeccionar datos de aplicaciones, manipular archivos de juegos y auditar aplicaciones instaladas en dispositivos rooteados o depurables.
