Butler 是一款 Android 文件浏览器和应用管理器，可在移动设备上提供深度文件系统浏览、包检查和特权存储访问。它主要使用 Kotlin 编写，采用 Jetpack Compose、Hilt 和 Room，将多窗格资源管理器与归档处理、回收站恢复、内置文本编辑器以及已安装应用工作区相结合，用于查看 APK 元数据、组件详情和运行进程查询。该应用可通过 root、Shizuku、ADB 和 shell 后端提升访问权限，以访问 Android/data 等受保护路径，并执行普通存储 API 无法完成的包和文件操作。它面向需要高级工具来检查应用数据、操作游戏文件以及在已 root 或可调试设备上审计已安装应用的 Android 安全研究人员、逆向工程师和游戏安全分析师。
