Vk-Engine es un motor de juegos 3D basado en Vulkan, escrito principalmente en el lenguaje de programación Jai, con pegamento C/C++ para bibliotecas de terceros.
Ofrece un runtime al estilo entidad-componente, pipelines de escenas y assets para mallas, materiales, animaciones y LODs, y escenas de ejemplo para iluminación, sombras, paralaje y pruebas de física.
El proyecto integra Dear ImGui para la UI del editor y los gizmos, y Jolt Physics mediante bindings personalizados para colisiones y simulación de cuerpos rígidos, con scripts de compilación multiplataforma para Windows y sistemas tipo Unix.
Resulta especialmente útil para desarrolladores de juegos y gráficos que aprenden o prototipan renderizado Vulkan moderno, herramientas de editor y jugabilidad impulsada por física.
