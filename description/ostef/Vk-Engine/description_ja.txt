Vk-Engine は、主に Jai プログラミング言語で書かれた Vulkan ベースの 3D ゲームエンジンで、サードパーティライブラリ向けに C/C++ のグルーコードを用います。
エンティティ・コンポーネント方式のランタイム、メッシュ・マテリアル・アニメーション・LOD 向けのシーン／アセットパイプライン、およびライティング、シャドウ、パララックス、物理テスト用のサンプルシーンを提供します。
エディタ UI とギズモには Dear ImGui を統合し、衝突と剛体シミュレーションには独自バインディング経由で Jolt Physics を利用し、Windows および Unix 系向けのクロスプラットフォーム構築スクリプトも備えます。
現代的な Vulkan レンダリング、エディタツール、物理駆動ゲームプレイの学習やプロトタイピングを行うゲーム／グラフィックス開発者に特に有用です。
