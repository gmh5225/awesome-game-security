Vk-Engine — это 3D-игровой движок на базе Vulkan, написанный в основном на языке программирования Jai, с C/C++ glue для сторонних библиотек.
Он предоставляет runtime в стиле entity-component, конвейеры сцен и ассетов для мешей, материалов, анимаций и LOD, а также примеры сцен для освещения, теней, параллакса и тестов физики.
В проект интегрированы Dear ImGui для UI редактора и гизмо, а также Jolt Physics через собственные привязки для коллизий и симуляции твёрдых тел, с кроссплатформенными скриптами сборки для Windows и Unix-подобных систем.
Он особенно полезен разработчикам игр и графики, изучающим или прототипирующим современный рендеринг на Vulkan, инструменты редактора и геймплей на основе физики.
