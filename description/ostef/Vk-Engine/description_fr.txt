Vk-Engine est un moteur de jeu 3D basé sur Vulkan, écrit principalement en Jai, avec une couche C/C++ pour l’intégration des bibliothèques tierces.
Il offre un runtime de type entité-composant, des pipelines de scènes et d’assets pour les maillages, matériaux, animations et LOD, ainsi que des scènes d’exemple pour l’éclairage, les ombres, le parallaxe et les tests physiques.
Le projet intègre Dear ImGui pour l’interface éditeur et les gizmos, et Jolt Physics via des bindings personnalisés pour les collisions et la simulation de corps rigides, avec des scripts de build multiplateformes pour Windows et les systèmes de type Unix.
Il s’adresse surtout aux développeurs de jeux et de graphisme qui apprennent ou prototypent le rendu Vulkan moderne, les outils d’édition et le gameplay piloté par la physique.
