Vk-Engine is a Vulkan-based 3D game engine written primarily in the Jai programming language, with C/C++ glue for third-party libraries.
It provides an entity-component style runtime, scene and asset pipelines for meshes, materials, animations, and LODs, and sample scenes for lighting, shadows, parallax, and physics testing.
The project integrates Dear ImGui for editor UI and gizmos, and Jolt Physics through custom bindings for collision and rigid-body simulation, with cross-platform build scripts for Windows and Unix-like systems.
It is mainly useful for game and graphics developers learning or prototyping modern Vulkan rendering, editor tooling, and physics-driven gameplay.
