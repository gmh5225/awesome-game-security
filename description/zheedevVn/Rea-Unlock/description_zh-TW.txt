Rea-Unlock 是一款以智能體為導向的逆向工程平台，提供 Model Context Protocol 伺服器與 CLI，讓 AI 程式設計助手能在真實二進位檔與應用程式上驅動結構化分析工作流程。主要以 TypeScript 與 Node.js 實作，並透過 Python、Java、Swift 與 C++ 橋接整合 Ghidra、Hopper、Cutter、IDA 系工具、JEB、JADX、Apktool、Frida、LLDB、pwndbg、pwntools 以及用於流量擷取的 mitmproxy 等反組譯器與除錯器。涵蓋範圍包括原生 PE、ELF、Mach-O 二進位及特殊 ISA，Android 與 Harmony 行動套件、Apple 應用套件、Electron 與 JavaScript 產物還原、WASM 與 EVM 位元組碼、韌體、Flutter AOT 以及受管 .NET NativeAOT，並支援封包、pcap 與瀏覽器網路觀測。本專案鎖定安全研究人員、惡意軟體分析師與遊戲安全工程師，他們需要借助 LLM 對用戶端、通訊協定與防篡改邏輯進行深度檢視，而非僅依賴臨時腳本。
