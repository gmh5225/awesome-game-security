Rea-Unlock은 에이전트 지향 리버스 엔지니어링 플랫폼으로, Model Context Protocol 서버와 CLI를 제공해 AI 코딩 어시스턴트가 실제 바이너리와 애플리케이션에서 구조화된 분석 워크플로를 수행할 수 있게 합니다. 주로 TypeScript와 Node.js로 구현되며, Python, Java, Swift, C++ 브리지를 통해 Ghidra, Hopper, Cutter, IDA 계열 도구, JEB, JADX, Apktool, Frida, LLDB, pwndbg, pwntools, 트래픽 캡처용 mitmproxy 등 디스어셈블러와 디버거를 통합합니다. 네이티브 PE, ELF, Mach-O 바이너리와 특수 ISA, Android 및 Harmony 모바일 패키지, Apple 번들, Electron 및 JavaScript 아티팩트 복구, WASM 및 EVM 바이트코드, 펌웨어, Flutter AOT, 관리형 .NET NativeAOT를 다루며, 패킷, pcap, 브라우저 네트워크 관측도 지원합니다. 이 프로젝트는 클라이언트, 프로토콜, 변조 방지 로직을 LLM 지원으로 깊이 검사해야 하는 보안 연구자, 멀웨어 분석가, 게임 보안 엔지니어를 대상으로 하며, 임시 스크립트만으로는 부족한 경우를 위한 것입니다.
