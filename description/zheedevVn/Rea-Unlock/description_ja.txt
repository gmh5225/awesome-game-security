Rea-Unlock はエージェント指向のリバースエンジニアリングプラットフォームで、Model Context Protocol サーバーと CLI を提供し、AI コーディングアシスタントが実バイナリやアプリケーション上で構造化された分析ワークフローを駆動できるようにします。主に TypeScript と Node.js で実装され、Python、Java、Swift、C++ のブリッジ経由で Ghidra、Hopper、Cutter、IDA 系ツール、JEB、JADX、Apktool、Frida、LLDB、pwndbg、pwntools、トラフィック取得用の mitmproxy などの逆アセンブラとデバッガを統合します。対象はネイティブ PE、ELF、Mach-O バイナリと特殊 ISA、Android および Harmony のモバイルパッケージ、Apple バンドル、Electron と JavaScript アーティファクトの復元、WASM と EVM バイトコード、ファームウェア、Flutter AOT、マネージド .NET NativeAOT に加え、パケット、pcap、ブラウザによるネットワーク観測まで及びます。本プロジェクトは、クライアント、プロトコル、改ざん防止ロジックを LLM 支援で深く調査する必要があるセキュリティ研究者、マルウェアアナリスト、ゲームセキュリティエンジニアを対象としており、場当たり的なスクリプトだけに頼る用途ではありません。
