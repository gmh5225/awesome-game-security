Rea-Unlock (REA) is an agent-oriented reverse engineering platform that exposes a Model Context Protocol server and CLI so AI coding assistants can drive structured analysis workflows on real binaries and applications. It is implemented mainly in TypeScript and Node.js, with Python, Java, Swift, and C++ bridges that integrate disassemblers and debuggers including Ghidra, Hopper, Cutter, IDA-family tooling, JEB, JADX, Apktool, Frida, LLDB, pwndbg, pwntools, and mitmproxy for traffic capture. Coverage spans native PE/ELF/Mach-O and specialty ISAs, Android and Harmony mobile packages, Apple bundles, Electron and JavaScript artifact recovery, WASM and EVM bytecode, firmware, Flutter AOT, and managed .NET NativeAOT, plus packet, pcap, and browser network observation. The project targets security researchers, malware analysts, and game security engineers who need LLM-assisted deep inspection of clients, protocols, and anti-tamper logic rather than ad hoc scripting alone.
