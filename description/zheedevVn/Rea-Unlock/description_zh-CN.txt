Rea-Unlock 是一款面向智能体的逆向工程平台，提供 Model Context Protocol 服务器与 CLI，使 AI 编程助手能在真实二进制与应用程序上驱动结构化分析工作流。主要使用 TypeScript 与 Node.js 实现，并通过 Python、Java、Swift 与 C++ 桥接集成 Ghidra、Hopper、Cutter、IDA 系工具、JEB、JADX、Apktool、Frida、LLDB、pwndbg、pwntools 以及用于流量抓取的 mitmproxy 等反汇编器与调试器。覆盖范围包括原生 PE、ELF、Mach-O 二进制及特殊 ISA，Android 与 Harmony 移动包、Apple 应用包、Electron 与 JavaScript 产物恢复、WASM 与 EVM 字节码、固件、Flutter AOT 以及托管 .NET NativeAOT，并支持报文、pcap 与浏览器网络观测。项目面向安全研究人员、恶意软件分析师与游戏安全工程师，他们需要借助 LLM 对客户端、协议与防篡改逻辑进行深度检视，而非仅依赖临时脚本。
