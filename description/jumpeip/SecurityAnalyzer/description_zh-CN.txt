SecurityAnalyzer 是一款 Ghidra 扩展，帮助逆向工程师对二进制文件进行防御性分类分析，涵盖漏洞、恶意软件行为、密码学与混淆。该工具使用 Java 编写、以 Gradle 构建，提供基于 P-code 的分析器，可检查危险的 API 用法、格式串与整数溢出模式、反调试与进程注入迹象、密码学常量特征、XOR 循环、熵窗口以及栈上字符串恢复。分析结果会以程序内书签与注释形式记录，在可停靠面板中展示，并可导出为 Markdown、JSON 或漏洞说明模板。配套的 headless 脚本支持批量扫描，使该插件适用于恶意软件分析、安全研究与围绕逆向工程和二进制加固的文档工作流，而非漏洞利用开发。
