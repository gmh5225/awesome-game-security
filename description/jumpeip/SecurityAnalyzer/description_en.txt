SecurityAnalyzer is a Ghidra extension that helps reverse engineers perform defensive triage on binaries for vulnerabilities, malware behavior, cryptography, and obfuscation. Written in Java and built with Gradle, it provides P-code–based analyzers that inspect dangerous API usage, format-string and integer-overflow patterns, anti-debug and process-injection indicators, crypto constant signatures, XOR loops, entropy windows, and stack-string recovery. Findings are recorded as in-program bookmarks and comments, surfaced in a dockable panel, and exportable as Markdown, JSON, or vulnerability writeup templates. A companion headless script supports batch scanning, making the plugin suited to malware analysis, security research, and documentation workflows around reverse engineering and binary hardening rather than exploit development.
