SecurityAnalyzer は Ghidra 向け拡張機能で、リバースエンジニアがバイナリに対する防御的トリアージ（脆弱性、マルウェアの挙動、暗号処理、難読化の観点）を行うのを支援します。Java で記述され Gradle でビルドされ、P-code ベースのアナライザにより危険な API の使用、フォーマット文字列や整数オーバーフローのパターン、反デバッグやプロセスインジェクションの兆候、暗号定数シグネチャ、XOR ループ、エントロピウィンドウ、スタック文字列の復元などを検査します。検出結果はプログラム内のブックマークとコメントとして記録され、ドッキング可能なパネルに表示され、Markdown、JSON、または脆弱性レポート用テンプレートとしてエクスポートできます。headless 用の補助スクリプトで一括スキャンにも対応し、エクスプロイト開発より、マルウェア解析、セキュリティ研究、リバースエンジニアリングとバイナリ強化に関するドキュメント作業向けのワークフローに適しています。
