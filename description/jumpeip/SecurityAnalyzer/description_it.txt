SecurityAnalyzer è un’estensione per Ghidra che aiuta gli ingegneri del reverse engineering a eseguire un triage difensivo sui binari per vulnerabilità, comportamento del malware, crittografia e offuscamento. Scritta in Java e costruita con Gradle, fornisce analizzatori basati sul P-code che ispezionano l’uso di API pericolose, pattern di format string e integer overflow, indicatori di anti-debug e iniezione di processo, firme di costanti crittografiche, loop XOR, finestre di entropia e recupero di stringhe sullo stack. I risultati vengono registrati come segnalibri e commenti nel programma, mostrati in un pannello agganciabile ed esportabili in Markdown, JSON o modelli di writeup sulle vulnerabilità. Uno script headless companion supporta la scansione in batch, rendendo il plugin adatto all’analisi del malware, alla ricerca sulla sicurezza e ai flussi di documentazione legati al reverse engineering e al hardening dei binari, piuttosto che allo sviluppo di exploit.
