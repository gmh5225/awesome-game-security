SecurityAnalyzer 是一款 Ghidra 延伸功能，協助逆向工程師對二進位檔進行防禦性分級分析，涵蓋漏洞、惡意軟體行為、密碼學與混淆。該工具以 Java 撰寫、以 Gradle 建置，提供基於 P-code 的分析器，可檢查危險的 API 用法、格式字串與整數溢位模式、反除錯與程序注入跡象、密碼學常數特徵、XOR 迴圈、熵視窗以及堆疊字串復原。分析結果會以程式內書籤與註解形式記錄，在可停駐面板中呈現，並可匯出為 Markdown、JSON 或漏洞說明範本。配套的 headless 指令碼支援批次掃描，使該外掛適用於惡意軟體分析、安全研究與圍繞逆向工程和二進位強化的文件工作流，而非漏洞利用開發。
