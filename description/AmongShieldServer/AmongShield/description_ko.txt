AmongShield는 Among Us용 무료 커뮤니티 안티치트 서버로, 클라이언트 모드를 설치하지 않고 사용자 지정 게임 지역을 선택해 접속합니다. 수정된 오픈 소스 Impostor 서버를 기반으로 하며 ESP 기만을 사용해 역할을 드러내는 치트 메뉴에는 여러 가짜 임포스터가 보이게 하고 정상 플레이어는 일반적인 플레이를 경험합니다. 서버는 불가능한 행동을 감시하고 알려진 치트 메뉴 클라이언트를 추방하며, 적발 시 로비 채팅으로 알립니다. 로비 호스트는 채팅 명령으로 시야를 조정할 수 있고 공개 게임에서 자동 호스트 교체를 사용할 수 있으며, 소형 PowerShell 지역 목록 도우미, 수동 regionInfo 편집, 모바일 딥링크 설정 페이지로 구성을 지원합니다. 게임 클라이언트를 수정하지 않고 실용적인 Among Us 안티치트와 치트 메뉴 완화를 원하는 플레이어와 커뮤니티를 대상으로 합니다.
