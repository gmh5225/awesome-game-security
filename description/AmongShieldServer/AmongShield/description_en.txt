AmongShield is a free community anti-cheat game server for Among Us that players reach by selecting a custom region instead of official North America, Europe, or Asia servers. The backend is built on a modified Impostor open-source Among Us server, while this repository supplies client onboarding through a short PowerShell script that edits regionInfo.json, JSON region definitions, and a static HTML setup page with mobile deep links. Server-side protections feed role-ESP cheat menus multiple decoy impostors, detect impossible actions and self-advertising menus to kick offenders with lobby chat callouts, and post truthful impostor summaries after each round. Hosts can tune lobby vision via chat commands and use automatic host rotation in public games. It targets PC and mobile players who want vanilla Among Us with stronger resistance to menus such as MalumMenu and Sicko Menu, without installing game mods or patching client binaries.
