AmongShield is a free community anti-cheat server for Among Us that players reach by selecting a custom game region instead of installing client mods. It is based on a modified Impostor open-source server and uses ESP deception so role-revealing cheat menus see multiple fake impostors while legitimate players experience normal gameplay. The server monitors matches for impossible actions, kicks known cheat-menu clients, and notifies the lobby in chat when someone is caught. Lobby hosts can adjust vision via chat commands and use automatic host rotation in public games, and setup is supported through a small PowerShell region-list helper, manual regionInfo edits, and a mobile deep-link setup page. It is aimed at players and communities who want practical Among Us anti-cheat and cheat-menu mitigation without modifying the game client.
