精選的 Agent Skills 合集，為 AI 程式設計代理提供遊戲開發專業知識，並透過路由器依當前引擎與任務載入合適的技能。專案約含 66 個純文字 SKILL.md 能力包，涵蓋 Godot、Unity、Unreal、Phaser、PixiJS、three.js、Bevy、pygame、LÖVE、Roblox 等引擎，以及跨引擎學科、類型與上線流程。技能遵循開放的 Agent Skills 格式（含 YAML frontmatter），與聲明的引擎版本鎖定，並由 Python 驗證器檢查。主路由器透過指紋辨識專案引擎，並選擇匹配的概念或類型技能，使代理在相關指導下撰寫程式碼。主要用途是幫助開發者藉助 Cursor、Claude Code 及其他相容工具建構遊戲，而無需手動命名或轉換技能。
