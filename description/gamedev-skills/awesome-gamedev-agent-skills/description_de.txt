Eine kuratierte Sammlung von Agent Skills, die KI-Coding-Agenten Expertise in der Spieleentwicklung vermitteln, mit einem Router, der für die jeweilige Engine und Aufgabe die passende Skill lädt. Enthalten sind etwa 66 schlichte SKILL.md-Fähigkeitspakete für Engines wie Godot, Unity, Unreal, Phaser, PixiJS, three.js, Bevy, pygame, LÖVE und Roblox sowie engineübergreifende Disziplinen, Genres und Publishing-Workflows. Die Skills folgen dem offenen Agent-Skills-Format mit YAML-Frontmatter, sind an angegebene Engine-Releases versioniert und werden von einem Python-Validator geprüft. Ein Master-Router erkennt die Projekt-Engine anhand von Fingerprints und wählt passende Konzept- oder Genre-Skills, damit Agenten mit relevanter Anleitung Code schreiben. Der Hauptanwendungsfall ist, Entwicklern beim Bau von Spielen mit KI-Assistenten wie Cursor, Claude Code und anderen kompatiblen Tools zu helfen, ohne Skills manuell benennen oder konvertieren zu müssen.
