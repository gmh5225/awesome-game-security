精选的 Agent Skills 合集，为 AI 编程代理提供游戏开发专业知识，并通过路由器按当前引擎与任务加载合适的技能。项目约含 66 个纯文本 SKILL.md 能力包，涵盖 Godot、Unity、Unreal、Phaser、PixiJS、three.js、Bevy、pygame、LÖVE、Roblox 等引擎，以及跨引擎学科、类型与上线流程。技能遵循开放的 Agent Skills 格式（含 YAML frontmatter），与声明的引擎版本锁定，并由 Python 校验器检查。主路由器通过指纹识别项目引擎，并选择匹配的概念或类型技能，使代理在相关指导下编写代码。主要用途是帮助开发者借助 Cursor、Claude Code 及其他兼容工具构建游戏，而无需手动命名或转换技能。
