Una raccolta curata di Agent Skills che fornisce agli agenti di coding IA competenza nello sviluppo di giochi, con un router che carica la skill giusta per il motore e il compito in corso. Include circa 66 pacchetti di capacità SKILL.md in testo semplice che coprono motori come Godot, Unity, Unreal, Phaser, PixiJS, three.js, Bevy, pygame, LÖVE e Roblox, oltre a discipline cross-engine, generi e flussi di pubblicazione. Le skill seguono il formato aperto Agent Skills con frontmatter YAML, sono ancorate alle release del motore indicate e vengono verificate da un validatore Python. Un router master rileva il motore del progetto dalle impronte digitali e seleziona le skill di concetto o genere corrispondenti, così gli agenti scrivono codice con una guida pertinente. Il caso d'uso principale è aiutare gli sviluppatori a creare giochi con assistenti IA come Cursor, Claude Code e altri strumenti compatibili senza dover nominare o convertire manualmente le skill.
