AIコーディングエージェントにゲーム開発の専門知識を与える Agent Skills の厳選コレクションで、対象のエンジンとタスクに合わせて適切なスキルを読み込むルーターを備えています。Godot、Unity、Unreal、Phaser、PixiJS、three.js、Bevy、pygame、LÖVE、Roblox などのエンジンに加え、エンジン横断の分野、ジャンル、出荷ワークフローをカバーする約66個のプレーンな SKILL.md 能力パックを同梱します。スキルは YAML frontmatter 付きのオープンな Agent Skills 形式に従い、記載のエンジンリリースにバージョン固定され、Python バリデータで検証されます。マスタールーターはフィンガープリントからプロジェクトのエンジンを検出し、一致するコンセプトまたはジャンルのスキルを選ぶため、エージェントは関連するガイダンスのもとでコードを書けます。主な用途は、Cursor、Claude Code、その他互換ツールでゲームを作る際に、スキルを手動で指定・変換せずに開発者を支援することです。
