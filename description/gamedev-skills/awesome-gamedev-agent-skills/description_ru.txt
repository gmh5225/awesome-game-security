Курируемая коллекция Agent Skills, дающая ИИ-агентам кодирования экспертизу в разработке игр, с маршрутизатором, который загружает нужный навык для текущего движка и задачи. В комплекте около 66 простых пакетов возможностей SKILL.md для движков Godot, Unity, Unreal, Phaser, PixiJS, three.js, Bevy, pygame, LÖVE и Roblox, а также междвижковых дисциплин, жанров и процессов релиза. Навыки следуют открытому формату Agent Skills с YAML frontmatter, привязаны к указанным версиям движков и проверяются Python-валидатором. Главный маршрутизатор определяет движок проекта по отпечаткам и выбирает подходящие навыки по концепциям или жанрам, чтобы агенты писали код с релевантными подсказками. Основной сценарий — помогать разработчикам создавать игры с ИИ-ассистентами вроде Cursor, Claude Code и других совместимых инструментов без ручного указания или преобразования навыков.
