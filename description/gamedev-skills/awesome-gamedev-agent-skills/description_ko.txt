AI 코딩 에이전트에 게임 개발 전문 지식을 제공하는 Agent Skills 큐레이션 모음으로, 현재 엔진과 작업에 맞는 스킬을 로드하는 라우터를 갖추고 있습니다. Godot, Unity, Unreal, Phaser, PixiJS, three.js, Bevy, pygame, LÖVE, Roblox 등 엔진과 엔진 공통 분야, 장르, 출시 워크플로를 다루는 약 66개의 일반 SKILL.md 역량 팩을 제공합니다. 스킬은 YAML frontmatter가 있는 개방형 Agent Skills 형식을 따르며, 명시된 엔진 릴리스에 버전이 고정되고 Python 검증기로 검사됩니다. 마스터 라우터는 핑거프린트로 프로젝트 엔진을 감지하고 일치하는 개념 또는 장르 스킬을 선택하여, 에이전트가 관련 가이드에 따라 코드를 작성하게 합니다. 주요 사용 사례는 Cursor, Claude Code 및 기타 호환 도구로 게임을 만들 때 스킬을 수동으로 지정하거나 변환할 필요 없이 개발자를 돕는 것입니다.
