Una colección curada de Agent Skills que aporta a los agentes de codificación con IA experiencia en desarrollo de juegos, con un enrutador que carga la habilidad adecuada según el motor y la tarea en curso. Incluye unos 66 paquetes de capacidades SKILL.md en texto plano que cubren motores como Godot, Unity, Unreal, Phaser, PixiJS, three.js, Bevy, pygame, LÖVE y Roblox, además de disciplinas entre motores, géneros y flujos de publicación. Las habilidades siguen el formato abierto Agent Skills con frontmatter YAML, están ancladas a las versiones de motor indicadas y se comprueban con un validador de Python. Un enrutador maestro detecta el motor del proyecto a partir de huellas digitales y selecciona habilidades de concepto o género coincidentes para que los agentes escriban código con orientación pertinente. El caso de uso principal es ayudar a los desarrolladores a crear juegos con asistentes de IA como Cursor, Claude Code y otras herramientas compatibles sin tener que nombrar o convertir habilidades manualmente.
