PerfOverlay Supreme 是一款适用于 Windows 10/11 的游戏内性能叠加层，可在运行中的游戏上方显示 FPS、帧时间、帧时间最低值，以及 CPU、GPU、内存和系统传感器的详细读数，且无需向游戏进程注入代码。该项目使用 C++、CMake 与 MSVC 实现，通过 Windows ETW Present 事件捕获帧，并以 Direct3D 11、DirectComposition 和 Direct2D 绘制独立的可穿透点击叠加层。工具支持按游戏自动检测与配置文件、RTSS 风格的布局编辑器、导入并渲染 RivaTuner OverlayEditor 预设，以及来自 NVML、性能计数器、HWiNFO 或 LibreHardwareMonitor 的可选数据源。面向 PC 玩家、跑分用户，以及研究依托公开 API 而非钩子实现的叠加层技术的人员；在评估与反作弊及竞技游戏的兼容性时，这一点尤为重要。
