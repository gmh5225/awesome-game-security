PerfOverlay Supreme は Windows 10/11 向けのゲーム内パフォーマンスオーバーレイで、実行中のゲームの上に FPS、フレームタイム、フレームタイムの低下値、および CPU・GPU・RAM・各種システムセンサーの詳細な読み取り値を表示します。ゲームプロセスへのインジェクションは行いません。C++、CMake、MSVC で実装され、Windows ETW の Present イベントでフレームを取得し、Direct3D 11、DirectComposition、Direct2D でクリック透過の独立オーバーレイを描画します。ゲームごとの自動検出とプロファイル、RTSS 風レイアウトエディタ、RivaTuner OverlayEditor プリセットのインポートと描画、NVML・パフォーマンスカウンター・HWiNFO・LibreHardwareMonitor からの任意フィードに対応します。PC ゲーマー、ベンチマーク利用者、およびフックではなく公開 API に依存するオーバーレイ技法を学ぶ人向けで、アンチチートや競技タイトルとの互換性を評価する際に重要です。
