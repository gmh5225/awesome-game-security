PerfOverlay Supreme — внутриигровой оверлей производительности для Windows 10/11, который показывает FPS, время кадра, провалы frametime и подробные показания CPU, GPU, ОЗУ и системных датчиков поверх запущенных игр без внедрения в процессы игр. Реализован на C++ с CMake и MSVC, захватывает кадры через события Present ETW в Windows и рисует отдельный прозрачный для кликов оверлей с Direct3D 11, DirectComposition и Direct2D. Поддерживаются автоопределение и профили по играм, редактор раскладки в стиле RTSS, импорт и отрисовка пресетов RivaTuner OverlayEditor, а также необязательные данные из NVML, счётчиков производительности, HWiNFO или LibreHardwareMonitor. Ориентирован на ПК-геймеров, любителей бенчмарков и тех, кто изучает техники оверлея на публичных API, а не на хуках — это важно при оценке совместимости с античитом и соревновательными играми.
