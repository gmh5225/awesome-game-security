PerfOverlay Supreme is a Windows 10/11 in-game performance overlay that displays FPS, frame time, frametime lows, and rich CPU, GPU, RAM, and system sensor readouts above running games without injecting into game processes. It is implemented in C++ with CMake and MSVC, capturing frames via Windows ETW Present events and drawing a separate click-through overlay with Direct3D 11, DirectComposition, and Direct2D. The tool supports per-game auto-detection and profiles, an RTSS-style layout editor, import and rendering of RivaTuner OverlayEditor presets, and optional feeds from NVML, performance counters, HWiNFO, or LibreHardwareMonitor. It is aimed at PC gamers, benchmarkers, and anyone studying overlay techniques that rely on public APIs rather than hooks, which matters when evaluating compatibility with anti-cheat and competitive titles.
