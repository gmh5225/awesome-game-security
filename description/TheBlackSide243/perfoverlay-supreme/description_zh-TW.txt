PerfOverlay Supreme 是一款適用於 Windows 10/11 的遊戲內效能疊加層，可在執行中的遊戲上方顯示 FPS、幀時間、幀時間最低值，以及 CPU、GPU、記憶體與系統感測器的詳細讀數，且無需向遊戲程序注入程式碼。此專案以 C++、CMake 與 MSVC 實作，透過 Windows ETW Present 事件擷取畫面，並以 Direct3D 11、DirectComposition 與 Direct2D 繪製獨立的可穿透點擊疊加層。工具支援依遊戲自動偵測與設定檔、RTSS 風格的版面編輯器、匯入並渲染 RivaTuner OverlayEditor 預設，以及來自 NVML、效能計數器、HWiNFO 或 LibreHardwareMonitor 的可選資料來源。面向 PC 玩家、跑分使用者，以及研究依賴公開 API 而非 Hook 的疊加層技術者；在評估與反作弊及競技遊戲的相容性時，這一點尤為重要。
