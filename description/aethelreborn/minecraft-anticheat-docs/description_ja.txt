本プロジェクトは、Minecraft のアンチチートがマルチプレイで改変クライアントをどのように検出・抑制するかを解説する教育向けドキュメント集です。Markdown で書かれ、クライアント・サーバー構成、ネットワークパケット、チートの分類、サーバー側およびハイブリッド検知モデルを順を追って説明します。移動予測エンジン、戦闘・リーチ解析、パケット検証、ヒューリスティクスと機械学習、執行、レイテンシ補正、および Java Edition の GrimAC、Vulcan、Matrix などの有名プラグインも扱います。想定読者はサーバー運営者、アンチチート・プラグイン開発者、およびネットワークゲームセキュリティを研究するうえで防御的な概念理解を求め、チート開発の手引きではない研究者です。
