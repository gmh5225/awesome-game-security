SCVK is a native Vulkan renderer delivered as a 32-bit DLL plugin for SimCity 4, replacing the aging DirectX 7 and unfinished OpenGL drivers through the game’s GZCOM graphics driver slot. It is written primarily in C++ with GLSL shaders compiled to SPIR-V, and it emulates the game’s fixed-function cIGZGDriver API via cached Vulkan pipelines and ubershaders rather than acting as a thin API translator. Notable capabilities include terrain and UI rendering, day/night lighting, optional live True3D shadows, ReShade add-on integration with correct depth, built-in FPS and presentation tuning, and exported frame callbacks for third-party overlays. The project targets players and mod authors who want modern GPU performance and compatibility on Windows and Linux (via Wine), and it exemplifies deep reverse-engineering of a legacy commercial game’s rendering and plugin interfaces for community-driven engine replacement.
