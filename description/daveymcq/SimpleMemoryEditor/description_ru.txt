SimpleMemoryEditor — это портативный сканер и редактор памяти для Windows, созданный как полнофункциональная утилита для читов в играх. Написан на C с пользовательским рантаймом NCRT и Win32 GUI, он подключается к запущенным процессам, перечисляет доступные для записи области памяти и сканирует целочисленные, вещественные или double-значения с помощью фильтров поиска «равно», «увеличилось» или «уменьшилось». Поддерживает изменение значений в реальном времени, заморозку адресов, мониторинг процессов и собирается в статически слинкованные 32- и 64-битные исполняемые файлы для Windows XP — Windows 10. Проект полезен для гейм-хакинга, реверс-инжиниринга внутриигровых переменных и изучения техник внешнего редактирования памяти, актуальных для безопасности игр и исследований античитов.
