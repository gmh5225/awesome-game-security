Kuna — это бинарный декомпилятор с приоритетом агентов, написанный на Rust, изначально портированный с C++-движка Ghidra и предназначенный для итеративного улучшения LLM-агентами. Он включает полный порт на Rust декомпилятора Ghidra и компилятора наборов инструкций SLEIGH, поддерживает встроенные спецификации процессоров для многих архитектур и предоставляет настраиваемый поэтапный конвейер с опциями декомпиляции, конфигурируемыми во время выполнения. Проект поставляется как CLI-инструмент, декомпилятор WebAssembly в браузере и плагин Ghidra, заменяющий штатное ядро декомпилятора при сохранении в основном совместимого вывода. Он ориентирован на специалистов по реверс-инжинирингу, исследователей безопасности и автоматизированные рабочие процессы анализа, где LLM-агенты декомпилируют и анализируют бинарные файлы для исследования уязвимостей, анализа вредоносного ПО и расследований в области безопасности игр.
