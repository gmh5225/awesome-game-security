Kuna 是一款以智慧型代理優先理念撰寫的 Rust 二進位反編譯器，最初從 Ghidra 的 C++ 引擎移植而來，旨在由 LLM 智慧型代理持續迭代改進。它包含 Ghidra 反編譯器與 SLEIGH 指令集編譯器的完整 Rust 移植，支援多種架構的內嵌處理器規範，並提供可調的階段性管線及執行時期設定的反編譯選項。專案以 CLI 工具、瀏覽器內 WebAssembly 反編譯器以及 Ghidra 外掛形式發布，後者可替換原生反編譯器核心並保持大致相容的輸出。面向逆向工程師、安全研究人員及自動化分析流程，供 LLM 智慧型代理反編譯並分析二進位檔案，用於漏洞研究、惡意軟體分析與遊戲安全調查。
