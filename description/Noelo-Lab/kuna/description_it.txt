Kuna è un decompilatore binario agent-first scritto in Rust, originariamente portato dal motore C++ di Ghidra e progettato per essere migliorato iterativamente da agenti LLM. Include un port completo in Rust del decompilatore di Ghidra e del compilatore di set di istruzioni SLEIGH, supporta specifiche di processori incluse per molte architetture ed espone una pipeline a fasi regolabile con opzioni di decompilazione configurabili a runtime. Il progetto è distribuito come strumento CLI, decompilatore WebAssembly nel browser e plugin Ghidra che sostituisce il core del decompilatore originale mantenendo un output largamente compatibile. È rivolto a ingegneri del reverse engineering, ricercatori di sicurezza e flussi di analisi automatizzata in cui agenti LLM decompilano e analizzano binari per la ricerca di vulnerabilità, l'analisi di malware e le indagini sulla sicurezza dei giochi.
