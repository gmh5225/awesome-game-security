Kuna は Rust で書かれたエージェントファーストのバイナリ逆コンパイラで、もともと Ghidra の C++ エンジンから移植され、LLM エージェントによる反復的な改善を想定して設計されています。Ghidra の逆コンパイラと SLEIGH 命令セットコンパイラの完全な Rust 移植を含み、多くのアーキテクチャ向けに同梱されたプロセッサ仕様をサポートし、実行時に設定可能な逆コンパイルオプションを備えた調整可能なフェーズベースのパイプラインを提供します。CLI ツール、ブラウザ内 WebAssembly 逆コンパイラ、および標準の逆コンパイラコアを置き換えつつ出力の互換性をおおむね維持する Ghidra プラグインとして提供されます。逆コンパイルエンジニア、セキュリティ研究者、および LLM エージェントがバイナリを逆コンパイル・解析して脆弱性調査、マルウェア分析、ゲームセキュリティ調査を行う自動化分析ワークフローを対象としています。
