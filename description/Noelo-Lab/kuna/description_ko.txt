Kuna는 Rust로 작성된 에이전트 우선 바이너리 디컴파일러로, 원래 Ghidra의 C++ 엔진에서 포팅되었으며 LLM 에이전트가 반복적으로 개선하도록 설계되었습니다. Ghidra 디컴파일러와 SLEIGH 명령어 집합 컴파일러의 완전한 Rust 포팅을 포함하며, 다양한 아키텍처용 내장 프로세서 사양을 지원하고, 런타임에 구성 가능한 디컴파일 옵션을 갖춘 조정 가능한 단계 기반 파이프라인을 제공합니다. CLI 도구, 브라우저 내 WebAssembly 디컴파일러, 그리고 기본 디컴파일러 코어를 대체하면서 출력 호환성을 대체로 유지하는 Ghidra 플러그인으로 제공됩니다. 역공학가, 보안 연구자, LLM 에이전트가 바이너리를 디컴파일하고 분석하여 취약점 연구, 멀웨어 분석, 게임 보안 조사를 수행하는 자동화 분석 워크플로를 대상으로 합니다.
