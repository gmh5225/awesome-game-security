Kuna is an agent-first binary decompiler written in Rust, originally ported from Ghidra's C++ engine and designed to be iteratively improved by LLM agents. It includes a full Rust port of Ghidra's decompiler and SLEIGH instruction-set compiler, supports vendored processor specifications for many architectures, and exposes a tunable phase-based pipeline with runtime-configurable decompilation options. The project ships as a CLI tool, a WebAssembly in-browser decompiler, and a Ghidra plugin that replaces the stock decompiler core while keeping largely compatible output. It targets reverse engineers, security researchers, and automated analysis workflows where LLM agents decompile and analyze binaries for vulnerability research, malware analysis, and game security investigations.
