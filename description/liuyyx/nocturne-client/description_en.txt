Nocturne Client is a JVM injection-based Minecraft client packaged as one jar that serves as both an external injector and an in-process Java agent attached to a live game process. It supports a wide span of releases from 1.8.9 through 26.3 by loading per-version mapping tables for vanilla, Fabric, Forge, and NeoForge runtime names while keeping gameplay code on Mojmap-style identifiers instead of a traditional mod entry. The implementation is primarily Java (Java 8 bytecode for injectable modules), built with Gradle, and relies on ASM bytecode transformers for frame hooks, draw callbacks, and input blocking, plus Python utilities to generate and verify mapping JSON. A modular client layer provides cheat-style features such as ESP, tracers, storage search overlays, and a custom ClickGUI rendered through LWJGL2 fixed pipeline, modern GL core, or the game’s own GUI extractor on newer stacks. It is relevant to game security, anti-cheat, and reverse-engineering work that studies JVM attach, dynamic instrumentation, obfuscation bridging, and how injected clients hook rendering and input.
