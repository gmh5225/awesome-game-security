Nocturne Client 是一款基于 JVM 注入的 Minecraft 客户端，打包为单个 jar，同时充当外部注入器与附着于运行中游戏进程的内联 Java Agent。它支持从 1.8.9 到 26.3 的广泛版本，通过为原版、Fabric、Forge 与 NeoForge 加载各版本映射表以解析运行时名称，同时游戏逻辑代码仍使用 Mojmap 风格标识符而非传统 mod 入口。实现以 Java 为主（可注入模块为 Java 8 字节码），使用 Gradle 构建，依赖 ASM 字节码转换器实现帧钩子、绘制回调与输入拦截，并用 Python 工具生成与校验映射 JSON。模块化客户端层提供类似作弊的功能，如 ESP、追踪线、存储搜索叠加层，以及通过 LWJGL2 固定管线、现代 GL 核心或较新栈上游戏自带 GUI 提取器渲染的自定义 ClickGUI。它与研究 JVM 附着、动态插桩、混淆桥接以及注入客户端如何挂钩渲染与输入的游戏安全、反作弊与逆向工程工作相关。
