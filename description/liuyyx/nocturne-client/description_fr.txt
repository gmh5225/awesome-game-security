Nocturne Client est un client Minecraft basé sur l’injection JVM, empaqueté en un seul jar qui sert à la fois d’injecteur externe et d’agent Java in-process attaché au processus de jeu en cours d’exécution. Il prend en charge un large éventail de versions de 1.8.9 à 26.3 en chargeant des tables de mapping par version pour les noms d’exécution vanilla, Fabric, Forge et NeoForge, tout en conservant le code de gameplay sur des identifiants de style Mojmap plutôt qu’une entrée mod traditionnelle. L’implémentation est principalement en Java (bytecode Java 8 pour les modules injectables), construite avec Gradle, et s’appuie sur des transformateurs de bytecode ASM pour les hooks de frames, les callbacks de dessin et le blocage d’entrée, plus des utilitaires Python pour générer et vérifier le JSON de mapping. Une couche client modulaire fournit des fonctionnalités de type triche telles que l’ESP, les tracers, les overlays de recherche de stockage et un ClickGUI personnalisé rendu via le pipeline fixe LWJGL2, le cœur GL moderne ou l’extracteur GUI du jeu sur les stacks plus récentes. Il est pertinent pour la sécurité des jeux, l’anti-triche et le reverse engineering qui étudient l’attache JVM, l’instrumentation dynamique, le pont d’obfuscation et la façon dont les clients injectés accrochent le rendu et l’entrée.
