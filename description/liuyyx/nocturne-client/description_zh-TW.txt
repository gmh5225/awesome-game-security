Nocturne Client 是一款以 JVM 注入為基礎的 Minecraft 用戶端，打包成單一 jar，同時作為外部注入器與附著於執行中遊戲程序的程序內 Java Agent。它支援自 1.8.9 至 26.3 的廣泛版本，透過為原版、Fabric、Forge 與 NeoForge 載入各版本對照表以解析執行時名稱，同時遊戲邏輯程式碼仍使用 Mojmap 風格識別符而非傳統 mod 入口。實作以 Java 為主（可注入模組為 Java 8 位元組碼），以 Gradle 建置，依賴 ASM 位元組碼轉換器實作影格掛鉤、繪製回呼與輸入攔截，並以 Python 工具產生與驗證對照 JSON。模組化用戶端層提供類似外掛的功能，如 ESP、追蹤線、儲存搜尋疊加層，以及透過 LWJGL2 固定管線、現代 GL 核心或較新堆疊上遊戲自帶 GUI 擷取器渲染的自訂 ClickGUI。它與研究 JVM 附著、動態插樁、混淆橋接以及注入用戶端如何掛鉤渲染與輸入的遊戲安全、反作弊與逆向工程工作相關。
