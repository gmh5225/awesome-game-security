This project is a standalone ASI plugin that adds modern gamepad support to the PC release of Need for Speed: Most Wanted (2005) version 1.3. It is implemented in C++ using reverse-engineered game logic from IDA Pro, runtime function hooks, and helper utilities for safe in-process memory patching. The mod injects Xbox and PlayStation button glyphs through the game’s FEng UI, auto-detects controllers by USB vendor ID, replaces opaque DirectInput labels in the controls menu, and offers configurable stick deadzones, trigger filtering, hotplug handling, and in-game controller mode toggles. Users load it with a standard ASI loader alongside optional INI and packaged texture assets. It is aimed at mod authors, reverse engineers, and players who want to study or extend legacy EA Black Box title input, UI, and scripting integration without external remapping tools.
