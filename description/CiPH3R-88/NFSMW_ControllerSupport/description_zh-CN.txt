本项目是一款独立的 ASI 插件，为 PC 版《极品飞车：最高通缉》（2005）1.3 版本添加现代手柄支持。它使用 C++ 实现，依托 IDA Pro 逆向得到的游戏逻辑、运行时函数挂钩以及用于安全进程内内存补丁的辅助工具。该模组通过游戏的 FEng UI 注入 Xbox 与 PlayStation 按键图标，按 USB 厂商 ID 自动识别手柄，在控制菜单中用直观标签替换不透明的 DirectInput 名称，并提供可配置的摇杆死区、扳机滤波、热插拔处理以及游戏内手柄模式切换。用户可通过标准 ASI 加载器加载，并配合可选的 INI 与打包纹理资源使用。面向模组作者、逆向工程师以及希望研究或扩展 EA Black Box 经典作品输入、UI 与脚本集成、且无需外部重映射工具的玩家。
