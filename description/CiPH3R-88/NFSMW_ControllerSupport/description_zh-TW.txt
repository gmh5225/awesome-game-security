本專案是一款獨立的 ASI 外掛，為 PC 版《極速快感：辣車風雲》（2005）1.3 版本加入現代手把支援。它以 C++ 實作，仰賴 IDA Pro 逆向取得的遊戲邏輯、執行階段函式 Hook，以及用於安全程序內記憶體修補的輔助工具。此模組透過遊戲的 FEng UI 注入 Xbox 與 PlayStation 按鍵圖示，依 USB 廠商 ID 自動偵測控制器，在控制選單中以清楚標籤取代不透明的 DirectInput 名稱，並提供可設定的搖桿死區、扳機機濾波、熱插拔處理與遊戲內手把模式切換。使用者可搭配標準 ASI 載入器，以及可選的 INI 與打包紋理資源來載入。目標對象為模組作者、逆向工程師，以及想研究或擴充 EA Black Box 經典作品輸入、UI 與腳本整合、且不需外部重對應工具的玩家。
