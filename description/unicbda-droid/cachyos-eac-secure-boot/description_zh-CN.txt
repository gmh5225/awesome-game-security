本仓库是一份分步指南，介绍如何在启用 UEFI Secure Boot 的日常使用场景下，于 CachyOS 上运行 Easy Anti-Cheat Linux v2。文档采用双启动路径设计：GRUB 与日常内核使用个人 sbctl 密钥签名，另有一条仅固件入口通过 systemd-boot 启动经 CachyOS 签名的 linux-cachyos-eac 内核，并启用 lockdown=integrity、模块签名强制及其他 EAC v2 所需设置。指南涵盖 sbctl 密钥注册（含 CachyOS EAC CA）、重建内嵌模块的 GRUB、ESP 分区布局、通过 pacman 钩子同步 EAC 内核、使用 eac-status 验证以及固件故障排查。面向准备在受支持发行版上原生运行 Fortnite 的 Linux 玩家与系统搭建者，侧重反作弊启动完整性而非绕过保护。内容以文档为主，附带 shell 与配置片段，并非独立应用代码库。
