このリポジトリは、UEFI Secure Boot を有効にしたまま CachyOS 上で Easy Anti-Cheat Linux v2 を動かすためのステップバイステップのガイドです。GRUB と日常用カーネルは個人の sbctl 鍵で署名し、別のファームウェア専用エントリから systemd-boot 経由で CachyOS 署名の linux-cachyos-eac カーネルを起動し、lockdown=integrity、モジュール署名の強制、その他 EAC v2 が求める設定を適用する二重ブートパス設計を文書化しています。ガイドでは sbctl 鍵の登録（CachyOS EAC CA を含む）、組み込みモジュール付き GRUB の再ビルド、ESP レイアウト、pacman フックによる EAC カーネルの同期、eac-status による検証、ファームウェアのトラブルシューティングを扱います。対応ディストリビューションでネイティブ Fortnite を用意する Linux ゲーマーとシステム構築者向けで、保護の回避ではなくアンチチート起動の整合性に焦点を当てています。内容は主にドキュメントと shell・設定スニペットであり、スタンドアロンのアプリケーションコードベースではありません。
