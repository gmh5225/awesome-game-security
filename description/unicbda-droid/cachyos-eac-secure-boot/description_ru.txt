Этот репозиторий — пошаговое руководство по запуску Easy Anti-Cheat Linux v2 на CachyOS при сохранении включённого UEFI Secure Boot в повседневной работе. Описана схема с двумя путями загрузки: GRUB и повседневные ядра подписываются личными ключами sbctl, а отдельная запись только на уровне прошивки загружает подписанное CachyOS ядро linux-cachyos-eac через systemd-boot с lockdown=integrity, принудительной проверкой подписи модулей и другими настройками, которые ожидает EAC v2. Руководство охватывает регистрацию ключей sbctl (включая CA EAC CachyOS), пересборку GRUB со встроенными модулями, разметку ESP, хуки pacman для синхронизации ядра EAC, проверку с eac-status и устранение неполадок прошивки. Оно предназначено для Linux-геймеров и сборщиков систем, готовящих нативный Fortnite на поддерживаемых дистрибутивах, с упором на целостность загрузки античита, а не на обход защиты. Содержимое в основном — документация со фрагментами shell и конфигурации, а не автономная кодовая база приложения.
