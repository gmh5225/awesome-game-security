Este repositorio es una guía paso a paso para ejecutar Easy Anti-Cheat Linux v2 en CachyOS manteniendo UEFI Secure Boot activado en el uso diario. Documenta un diseño de doble ruta de arranque: GRUB y los kernels habituales siguen firmados con claves sbctl personales, y una entrada solo de firmware arranca un kernel linux-cachyos-eac firmado por CachyOS mediante systemd-boot con lockdown=integrity, aplicación de firma de módulos y otros ajustes que EAC v2 espera. La guía cubre el registro de claves sbctl (incluida la CA EAC de CachyOS), la reconstrucción de GRUB con módulos embebidos, el diseño de la ESP, hooks de pacman para sincronizar el kernel EAC, verificación con eac-status y resolución de problemas de firmware. Está dirigida a jugadores de Linux y montadores de sistemas que preparan Fortnite nativo en distribuciones compatibles, con énfasis en la integridad de arranque anti-trampas en lugar de eludir protecciones. El contenido es principalmente documentación con fragmentos de shell y configuración, no una base de código de aplicación independiente.
