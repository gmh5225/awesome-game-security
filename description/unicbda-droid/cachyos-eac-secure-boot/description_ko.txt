이 저장소는 UEFI Secure Boot를 일상 사용 중에도 유지한 채 CachyOS에서 Easy Anti-Cheat Linux v2를 실행하는 단계별 가이드입니다. GRUB과 일상 커널은 개인 sbctl 키로 서명하고, 별도의 펌웨어 전용 항목은 systemd-boot로 CachyOS 서명 linux-cachyos-eac 커널을 부팅하며 lockdown=integrity, 모듈 서명 강제 및 EAC v2가 요구하는 기타 설정을 적용하는 이중 부트 경로 설계를 문서화합니다. 가이드는 sbctl 키 등록(CachyOS EAC CA 포함), 내장 모듈 GRUB 재빌드, ESP 레이아웃, pacman 훅으로 EAC 커널 동기화, eac-status로 검증, 펌웨어 문제 해결을 다룹니다. 지원 배포판에서 네이티브 Fortnite를 준비하는 Linux 게이머와 시스템 구축자를 대상으로 하며, 보호 우회가 아닌 안티치트 부팅 무결성에 초점을 둡니다. 내용은 주로 문서와 shell 및 구성 스니펫이며, 독립형 애플리케이션 코드베이스는 아닙니다.
