本儲存庫是一份逐步指南，說明如何在啟用 UEFI Secure Boot 的日常使用情境下，於 CachyOS 上執行 Easy Anti-Cheat Linux v2。文件採用雙啟動路徑設計：GRUB 與日常核心以個人 sbctl 金鑰簽署，另有一條僅韌體入口透過 systemd-boot 啟動經 CachyOS 簽署的 linux-cachyos-eac 核心，並啟用 lockdown=integrity、模組簽署強制及其他 EAC v2 所需設定。指南涵蓋 sbctl 金鑰註冊（含 CachyOS EAC CA）、重建內嵌模組的 GRUB、ESP 分割區配置、透過 pacman 掛鉤同步 EAC 核心、使用 eac-status 驗證以及韌體疑難排解。面向準備在受支援發行版上原生執行 Fortnite 的 Linux 玩家與系統建置者，著重反作弊啟動完整性而非繞過保護。內容以文件為主，附帶 shell 與設定片段，並非獨立應用程式程式碼庫。
