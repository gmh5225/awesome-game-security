This repository is a step-by-step guide for running Easy Anti-Cheat Linux v2 on CachyOS while keeping UEFI Secure Boot enabled for everyday use. It documents a dual boot-path design where GRUB and daily kernels stay signed with personal sbctl keys, and a separate firmware-only entry boots a CachyOS-signed linux-cachyos-eac kernel via systemd-boot with lockdown=integrity, module signature enforcement, and other settings EAC v2 expects. The guide covers sbctl key enrollment including the CachyOS EAC CA, rebuilding embedded-module GRUB, ESP layout, pacman hooks to sync the EAC kernel, verification with eac-status, and firmware troubleshooting. It is aimed at Linux gamers and system builders preparing for native Fortnite on supported distributions, with a focus on anti-cheat boot integrity rather than bypassing protections. The content is primarily documentation with shell and configuration snippets rather than a standalone application codebase.
