AntiCheatMod は、7 Days to Die の専用マルチプレイサーバー向けのサーバー側アンチチート MOD で、非管理者プレイヤーによる一般的なチートを検出・防止します。C# で .NET Framework 4.8 向けに書かれており、不正なコンソールおよびチャットのチートコマンドをブロックし、設定可能な距離・速度・持続時間の閾値を用いて、飛行、テレポート、スピードハック、ゴッドモードなどのプレイヤー行動を監視します。定義された管理者権限レベル以下のプレイヤーは免除され、警告からキック、BAN まで段階的な処罰が適用され、オンラインの管理者に通知し、詳細な検出結果を専用ログファイルに記録します。Easy Anti-Cheat を有効にしていない 7DTD サーバーを運用する管理者向けの、軽量で設定可能なサーバー側チート対策です。
