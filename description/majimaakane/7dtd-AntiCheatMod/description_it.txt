AntiCheatMod è una mod anti-cheat lato server per server multigiocatore dedicati di 7 Days to Die che rileva e previene i cheating comuni da parte di giocatori non amministratori. Scritta in C# per .NET Framework 4.8, blocca comandi cheat non autorizzati in console e chat e monitora il comportamento dei giocatori per volo, teletrasporto, speed hack e god mode utilizzando soglie configurabili di distanza, velocità e durata. La mod esenta i giocatori con un livello di permesso amministratore definito o inferiore, applica sanzioni progressive da avvertimenti a espulsioni fino ai ban, notifica gli amministratori online e scrive rilevamenti dettagliati in un file di log dedicato. È pensata per gli operatori di server 7DTD senza Easy Anti-Cheat abilitato che necessitano di una protezione anti-cheat lato server leggera e configurabile.
