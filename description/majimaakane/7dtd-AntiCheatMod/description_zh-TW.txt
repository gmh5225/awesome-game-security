AntiCheatMod 是一款適用於《七日殺》（7 Days to Die）專用多人遊戲伺服器的反作弊模組，可在伺服器端偵測並阻止非管理員玩家的常見作弊行為。該模組以 C# 撰寫，運行於 .NET Framework 4.8，能夠攔截未授權的控制台與聊天作弊指令，並透過可配置的距離、速度與持續時間閾值監控玩家是否存在飛行、傳送、速度作弊與無敵模式等行為。模組對處於指定管理員權限等級及以下的玩家予以豁免，並實施從警告、踢出到封禁的遞增懲罰，同時通知線上管理員，並將詳細偵測記錄寫入專用日誌檔案。它適用於未啟用 Easy Anti-Cheat 的 7DTD 伺服器營運者，提供輕量且可配置的伺服器端作弊防護。
