AntiCheatMod is a server-side anti-cheat mod for 7 Days to Die dedicated multiplayer servers that detects and prevents common cheating by non-administrative players. Written in C# for .NET Framework 4.8, it blocks unauthorized console and chat cheat commands and monitors player behavior for flying, teleportation, speed hacking, and god mode using configurable distance, speed, and duration thresholds. The mod exempts players at or below a defined admin permission level, applies escalating penalties from warnings through kicks to bans, notifies online administrators, and writes detailed detections to a dedicated log file. It is intended for server operators running 7DTD without Easy Anti-Cheat enabled who need lightweight, configurable server-side cheat protection.
