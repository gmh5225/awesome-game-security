MeatyEFTRelease は、DMA ハードウェアを介してライブのゲーム状態を読み取り、Escape From Tarkov 向けの外部レーダーとオーバーレイを提供する Windows 向け C++ デスクトップクライアントです。LeechCore と MemProcFS（VMMDLL）を用いてプロセス外メモリアクセスを行い、Unity 向けモジュールでプレイヤー、ルート、脱出地点、クエスト、爆発物、カメラ、その他のゲーム内エンティティを追跡します。レンダリングは DirectX 11 と Direct2D のフューザーオーバーレイと ImGui インターフェースで処理され、エイムビュー、マップ、読み取り専用エイムモジュール、Makcu デバイス連携も備えています。クライアントはクラウドの DogTag API と通信し、tarkov.dev のデータを照会し、libcurl 経由で SHA-256 ハッシュによりダウンロードを検証する自動アップデーターも同梱しています。ゲームセキュリティ研究、リバースエンジニアリング、外部 DMA ベースのチート手法およびアンチチート対策の研究を目的としています。
