MeatyEFTRelease는 DMA 하드웨어를 통해 실시간 게임 상태를 읽어 Escape From Tarkov용 외부 레이더와 오버레이를 제공하는 Windows C++ 데스크톱 클라이언트입니다. LeechCore와 MemProcFS(VMMDLL)를 사용해 프로세스 외 메모리 접근을 수행하며, Unity 지향 모듈로 플레이어, 전리품, 탈출 지점, 퀘스트, 폭발물, 카메라 및 기타 게임 내 엔티티를 추적합니다. 렌더링은 DirectX 11과 Direct2D 퓨저 오버레이와 ImGui 인터페이스로 처리되며, 에임 뷰, 맵, 읽기 전용 에임 모듈과 Makcu 장치 연동도 포함합니다. 클라이언트는 클라우드 DogTag API와 통신하고 tarkov.dev 데이터를 조회하며, libcurl을 통해 SHA-256 해시로 다운로드를 검증하는 자동 업데이터도 제공합니다. 게임 보안 연구, 리버스 엔지니어링, 외부 DMA 기반 치트 기법 및 안티치트 대응책 연구를 목적으로 합니다.
