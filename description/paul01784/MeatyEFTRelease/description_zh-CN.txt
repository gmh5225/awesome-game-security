MeatyEFTRelease 是一款 Windows C++ 桌面客户端，通过 DMA 硬件读取实时游戏状态，为《逃离塔科夫》（Escape From Tarkov）提供外部雷达与叠加层。它使用 LeechCore 和 MemProcFS（VMMDLL）进行进程外内存访问，并包含面向 Unity 的模块，用于追踪玩家、战利品、撤离点、任务、爆炸物、摄像头及其他游戏内实体。渲染由 DirectX 11 与 Direct2D 融合叠加层配合 ImGui 界面完成，同时还提供瞄准视图、地图与只读瞄准模块，并集成 Makcu 设备。该客户端还会连接云端 DogTag API、查询 tarkov.dev 数据，并内置自动更新器，通过 libcurl 以 SHA-256 哈希校验下载内容。本项目面向游戏安全研究、逆向工程，以及对外部 DMA 作弊技术与反作弊对抗手段的学习与分析。
