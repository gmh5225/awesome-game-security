MeatyEFTRelease is a Windows C++ desktop client that provides an external radar and overlay for Escape From Tarkov by reading live game state through DMA hardware. It uses LeechCore and MemProcFS (VMMDLL) for out-of-process memory access, with Unity-oriented modules that track players, loot, exfil points, quests, explosives, cameras, and other in-game entities. Rendering is handled by a DirectX 11 and Direct2D fuser overlay with an ImGui interface, alongside aim view, map, and read-only aim modules, plus Makcu device integration. The client also talks to a cloud DogTag API, queries tarkov.dev data, and ships an auto-updater that verifies downloads with SHA-256 hashes over libcurl. It is aimed at game security research, reverse engineering, and studying external DMA-based cheat techniques and anti-cheat countermeasures.
