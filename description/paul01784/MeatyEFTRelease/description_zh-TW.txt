MeatyEFTRelease 是一款 Windows C++ 桌面用戶端，透過 DMA 硬體讀取即時遊戲狀態，為《逃離塔科夫》（Escape From Tarkov）提供外部雷達與疊加層。它使用 LeechCore 和 MemProcFS（VMMDLL）進行程序外記憶體存取，並包含面向 Unity 的模組，用於追蹤玩家、戰利品、撤離點、任務、爆炸物、攝影機及其他遊戲內實體。渲染由 DirectX 11 與 Direct2D 融合疊加層配合 ImGui 介面完成，同時還提供瞄準視圖、地圖與唯讀瞄準模組，並整合 Makcu 裝置。該用戶端還會連接雲端 DogTag API、查詢 tarkov.dev 資料，並內建自動更新器，透過 libcurl 以 SHA-256 雜湊驗證下載內容。本專案面向遊戲安全研究、逆向工程，以及對外部 DMA 作弊技術與反作弊對抗手段的學習與分析。
