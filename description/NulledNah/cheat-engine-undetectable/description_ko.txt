이 프로젝트는 학술적 사이버 보안 연구 및 리버스 엔지니어링 교육을 위해 다층 안티치트 회피 기능을 추가한 Cheat Engine 수정 빌드입니다. 주로 Free Pascal(Lazarus)로 작성되었으며, PowerShell 빌드 및 후처리 스크립트가 상류 Cheat Engine을 클론하고 패치를 적용하여 스텔스 컴파일된 바이너리를 생성합니다. Tier 1 사용자 모드 기법에는 표면 난독화, 후킹된 ntdll 루틴을 우회하는 직접 NT 시스템 호출 스텁, Rich Header 제거 및 섹션 이름 변경과 같은 PE 메타데이터 변경이 포함됩니다. Tier 2 커널 브리지 기능은 일반적인 안티치트 엔진을 감지하며, 서명된 취약 드라이버가 사용 가능할 때 CR3 기반 페이지 테이블 메모리 접근, ObCallback 우회, 대상 핸들을 열지 않는 프로세스 은닉을 수행합니다. 이 저장소는 실제 게임 치팅이 아닌 안티치트 아키텍처, Windows 커널 내부, 회피 방법을 연구하는 연구자를 대상으로 하며, 하이퍼바이저 수준의 DMA 우회는 문서화되어 있으나 구현되지 않았습니다.
