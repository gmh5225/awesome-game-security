Sunset 是 Horizon 的原生实用客户端；Horizon 是基于 Rust 的 Minecraft 26.3 重写项目。Sunset 以 Meteor Client 为参考模型，作为 Horizon 原生 mod 发布，并集成大量 mixin 钩子。项目主要用 Rust 实现，功能划分为战斗、移动、玩家、渲染与世界等模块，包含面向 PvP 的能力，例如 kill aura、水晶与锚点 aura、脚手架、速度调整、ESP 以及可配置的点击 GUI。开发依赖 Horizon 的 mixin 工具链、安装脚本、Python 验证与打包工具，以及文档化的反作弊扫描矩阵，用于对照常见服务端反作弊比较各模块行为。项目面向需要功能丰富的 Horizon 客户端的玩家与研究人员，并提供结构化材料，用于研究客户端修改如何与反作弊及多人服务器规则执行的交互。
