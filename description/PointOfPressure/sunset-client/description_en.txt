Sunset is a native utility client for Horizon, a Rust-based Minecraft 26.3 rewrite, modeled after Meteor Client and shipped as a horizon-native mod with extensive mixin hooks. It is implemented primarily in Rust and organizes features into combat, movement, player, render, and world modules, including PvP-oriented capabilities such as kill aura, crystal and anchor aura, scaffold, velocity tweaks, ESP, and a configurable click GUI. Development relies on Horizon’s mixin toolchain, install scripts, Python verification and packaging tools, and documented anticheat sweep matrices that compare module behavior against common server anticheats. The project targets players and researchers who need a feature-rich Horizon client and structured material for studying how client-side modifications interact with anticheat and multiplayer server enforcement.
