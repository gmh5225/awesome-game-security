Sunset は Horizon 向けのネイティブユーティリティクライアントです。Horizon は Rust ベースの Minecraft 26.3 リライトで、Meteor Client を手本にした Horizon ネイティブ mod として配布され、多数の mixin フックを備えています。主に Rust で実装され、機能は combat、movement、player、render、world などのモジュールに整理され、PvP 向けの kill aura、crystal および anchor aura、scaffold、velocity 調整、ESP、設定可能なクリック GUI などを含みます。開発は Horizon の mixin ツールチェーン、インストールスクリプト、Python による検証・パッケージングツール、および一般的なサーバー anticheat とのモジュール挙動比較用の文書化された anticheat スイープ行列に依存しています。機能豊富な Horizon クライアントを必要とするプレイヤーや研究者、およびクライアント側改変が anticheat やマルチプレイサーバー enforcement とどう相互作用するかを研究するための整理された資料を対象としています。
