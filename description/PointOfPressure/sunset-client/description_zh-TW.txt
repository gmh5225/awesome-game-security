Sunset 是 Horizon 的原生實用客戶端；Horizon 是以 Rust 為基礎的 Minecraft 26.3 重寫專案。Sunset 以 Meteor Client 為參考模型，作為 Horizon 原生 mod 發布，並整合大量 mixin 鉤子。專案主要以 Rust 實作，功能劃分為戰鬥、移動、玩家、渲染與世界等模組，包含面向 PvP 的能力，例如 kill aura、水晶與錨點 aura、鷹架、速度調整、ESP 以及可設定的點擊 GUI。開發依賴 Horizon 的 mixin 工具鏈、安裝腳本、Python 驗證與打包工具，以及文件化的反作弊掃描矩陣，用於對照常見伺服器反作弊比較各模組行為。專案面向需要功能豐富的 Horizon 客戶端的玩家與研究人員，並提供結構化材料，用於研究客戶端修改如何與反作弊及多人伺服器規則執行的互動。
