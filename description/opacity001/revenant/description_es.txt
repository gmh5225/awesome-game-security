REVENANT es una plataforma unificada de orquestación de ingeniería inversa que integra elevación de binarios, desvirtualización, análisis estático y análisis dinámico sigiloso en un flujo de trabajo coherente. Está implementada principalmente en TypeScript sobre Node.js, con componentes nativos en C++ compilados con CMake y enlaces N-API opcionales que impulsan herramientas como revng para elevación a LLVM IR, NoVmp para VMProtect y unthemidator para desempaquetar Themida y WinLicense. El mismo motor se expone mediante una biblioteca núcleo, una CLI sin interfaz gráfica, un servidor MCP para análisis automatizado y una extensión de VS Code con vistas de desensamblado, descompilación, CFG y desvirtualización. Puede cargar binarios PE, ELF y Mach-O, construir grafos de flujo de control y referencias cruzadas, y aprovisionar VMs de análisis basadas en QEMU endurecidas frente a la detección habitual de máquinas virtuales para ejecución instrumentada mediante un agente invitado. Está dirigida a investigadores de seguridad, analistas de malware e ingenieros que trabajan en interoperabilidad, auditoría autorizada de software y análisis de ejecutables fuertemente protegidos, como los del ámbito de seguridad en juegos y anti-manipulación.
