REVENANT은 바이너리 리프팅, 디버추얼라이제이션, 정적 분석, 스텔스 동적 분석을 하나의 일관된 워크플로로 묶는 통합 리버스 엔지니어링 오케스트레이션 플랫폼입니다. 주로 Node.js 위의 TypeScript로 구현되며, CMake로 빌드한 네이티브 C++ 컴포넌트와 선택적 N-API 바인딩으로 revng을 통한 LLVM IR 리프팅, NoVmp를 통한 VMProtect 처리, unthemidator를 통한 Themida 및 WinLicense 언패킹 같은 도구를 구동합니다. 동일 엔진은 코어 라이브러리, 헤드리스 CLI, 자동 분석용 MCP 서버, 디스어셈블리·디컴파일·CFG·디버추얼라이즈 뷰를 제공하는 VS Code 확장을 통해 노출됩니다. PE, ELF, Mach-O 바이너리를 로드하고 제어 흐름 그래프와 교차 참조를 구축하며, 일반적인 VM 탐지에 강화된 QEMU 기반 분석 VM을 프로비저닝해 게스트 에이전트를 통한 계측 실행을 지원합니다. 보안 연구자, 멀웨어 분석가, 상호운용성 연구, 승인된 소프트웨어 감사, 게임 보안 및 안티탬퍼 작업에서 흔한 강력 보호 실행 파일 분석에 종사하는 엔지니어를 대상으로 합니다.
