REVENANT — единая платформа оркестрации реверс-инжиниринга, объединяющая подъём бинарников, девиртуализацию, статический и скрытный динамический анализ в одном согласованном рабочем процессе. Реализована в основном на TypeScript в Node.js, с нативными компонентами C++, собираемыми CMake, и опциональными привязками N-API, которые управляют такими инструментами, как revng для подъёма в LLVM IR, NoVmp для VMProtect и unthemidator для распаковки Themida и WinLicense. Тот же движок доступен через основную библиотеку, headless CLI, MCP-сервер для автоматизированного анализа и расширение VS Code с представлениями дизассемблирования, декомпиляции, CFG и девиртуализации. Платформа может загружать бинарники PE, ELF и Mach-O, строить графы потока управления и перекрёстные ссылки, а также разворачивать аналитические ВМ на базе QEMU, закалённые против типичного обнаружения виртуальных машин, для инструментированного выполнения через гостевой агент. Ориентирована на исследователей безопасности, аналитиков вредоносного ПО и инженеров, занимающихся исследованием совместимости, авторизованным аудитом ПО и анализом сильно защищённых исполняемых файлов, встречающихся в области безопасности игр и антитамперной работы.
