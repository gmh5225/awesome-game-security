REVENANT は、バイナリリフティング、デバーチャライズ、静的解析、ステルス型動的解析を一貫したワークフローにまとめた統合逆コンパイルオーケストレーションプラットフォームです。主に Node.js 上の TypeScript で実装され、CMake でビルドしたネイティブ C++ コンポーネントと任意の N-API バインディングにより、revng による LLVM IR リフティング、NoVmp による VMProtect 対応、unthemidator による Themida および WinLicense のアンパックなどのツールを駆動します。同一エンジンはコアライブラリ、ヘッドレス CLI、自動解析用 MCP サーバー、逆アセンブル・逆コンパイル・CFG・デバーチャライズビューを備えた VS Code 拡張から提供されます。PE・ELF・Mach-O バイナリの読み込み、制御フローグラフとクロスリファレンスの構築、一般的な VM 検知に耐性を持たせた QEMU ベースの解析 VM のプロビジョニング、ゲストエージェント経由のインストルメント実行に対応します。セキュリティ研究者、マルウェアアナリスト、相互運用性研究、認可されたソフトウェア監査、ゲームセキュリティやアンチタンパー作業で見られる強保護実行ファイルの解析に携わるエンジニアを対象としています。
