REVENANT is a unified reverse engineering orchestration platform that ties together binary lifting, devirtualization, static analysis, and stealth dynamic analysis behind one coherent workflow. It is implemented mainly in TypeScript on Node.js, with CMake-built native C++ components and optional N-API bindings that drive tools such as revng for LLVM IR lifting, NoVmp for VMProtect, and unthemidator for Themida and WinLicense unpacking. The project exposes the same engine through a core library, a headless CLI, an MCP server for automated analysis, and a VS Code extension with disassembly, decompilation, CFG, and devirt views. It can load PE, ELF, and Mach-O binaries, build control-flow graphs and cross-references, and provision QEMU-based analysis VMs hardened against common virtual-machine detection for instrumented execution via a guest agent. It is aimed at security researchers, malware analysts, and engineers working on interoperability research, authorized software auditing, and analysis of heavily protected executables such as those encountered in game security and anti-tamper work.
