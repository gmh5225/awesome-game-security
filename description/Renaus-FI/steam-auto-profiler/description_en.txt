Steam Auto-Profiler is a context-aware heuristic game classifier and pre-launch orchestrator for Steam on Linux, aimed at Wayland desktops such as KDE and GNOME. Written primarily in Bash, it inspects the local Steam installation, reads library manifests, and scans installed game directories to assign each title to one of four profiles: competitive anti-cheat, native FSR, legacy upscaler, or a standard low-latency default. Detection combines known competitive AppIDs with filesystem signatures for runtimes including EasyAntiCheat, BattlEye, and related anti-cheat libraries, then applies safe launch defaults such as disabling optional upscaler bridges where anti-cheat is present and enabling an optional online network profile. Companion tools synchronize Steam launch options in localconfig, wrap the actual game command for orchestrated launches, and optionally apply session-level network tuning without bundling overlays or injection libraries. It serves Linux gamers and security-minded users who need predictable Proton behavior around anti-cheat and upscaler stacks, and doubles as a reference for how heuristic anti-cheat presence checks can drive launch policy on open platforms.
