cheat-mcp es un servidor Model Context Protocol nativo de Windows que permite a los asistentes de IA interactuar con procesos de juego en ejecución mediante JSON-RPC sobre la entrada y salida estándar. Desarrollado en C++17, expone decenas de herramientas para inspección de procesos y módulos, lectura y escritura de memoria entre procesos, escaneo de valores y arrays de bytes al estilo Cheat Engine, resolución de punteros, parcheo de bytes e inyección de DLL o shellcode mediante loadlibrary, manual map, APC y otros métodos. También admite reconocimiento anti-cheat detectando módulos en modo usuario y controladores de kernel asociados con productos como EasyAntiCheat, BattlEye y Vanguard, junto con comprobaciones de depurador, enumeración de handles ajenos y captura o inyección de red. Los auxiliares de tiempo de ejecución adicionales incluyen bucles de congelación y vigilancia de memoria, hooking IAT y hooks de escalado temporal para manipulación de velocidad. El proyecto está dirigido a investigadores de seguridad de juegos, ingenieros de ingeniería inversa y analistas anti-cheat que necesitan automatización impulsada por LLM para análisis de memoria de juegos en Windows y evaluación de seguridad.
