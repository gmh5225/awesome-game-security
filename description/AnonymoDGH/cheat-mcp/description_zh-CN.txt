cheat-mcp 是一个 Windows 原生 Model Context Protocol 服务器，通过标准输入输出上的 JSON-RPC 让 AI 助手与正在运行的游戏进程交互。该项目采用 C++17 构建，提供数十种工具，用于进程与模块检查、跨进程内存读写、Cheat Engine 风格的数值与字节数组扫描、指针解析、字节补丁，以及通过 loadlibrary、manual map、APC 等方式进行 DLL 或 shellcode 注入。它还支持反作弊侦察，可检测与 EasyAntiCheat、BattlEye、Vanguard 等产品相关的用户态模块和内核驱动，并提供调试器检测、外部句柄枚举以及网络捕获或注入功能。其他运行时辅助功能包括内存冻结与监视循环、IAT hook，以及用于变速的时间缩放 hook。该项目面向需要进行 Windows 游戏内存分析与安全评估、并希望借助 LLM 实现自动化的游戏安全研究人员、逆向工程师和反作弊分析师。
