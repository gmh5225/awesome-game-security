cheat-mcp — это нативный для Windows сервер Model Context Protocol, который позволяет AI-ассистентам взаимодействовать с запущенными игровыми процессами через JSON-RPC по стандартному вводу и выводу. Написанный на C++17, он предоставляет десятки инструментов для инспекции процессов и модулей, межпроцессного чтения и записи памяти, сканирования значений и массивов байтов в стиле Cheat Engine, разрешения указателей, патчинга байтов, а также инъекции DLL или shellcode с помощью loadlibrary, manual map, APC и других методов. Также поддерживается разведка античитов: обнаружение пользовательских модулей и драйверов ядра, связанных с продуктами вроде EasyAntiCheat, BattlEye и Vanguard, проверки отладчика, перечисление чужих дескрипторов, захват или инъекция сетевого трафика. Дополнительные средства времени выполнения включают циклы заморозки и наблюдения за памятью, IAT-хукинг и хуки масштабирования времени для изменения скорости. Проект ориентирован на исследователей игровой безопасности, reverse-инженеров и аналитиков античитов, которым нужна автоматизация на базе LLM для анализа памяти игр в Windows и оценки безопасности.
