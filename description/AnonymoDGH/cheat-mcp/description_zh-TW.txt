cheat-mcp 是一個 Windows 原生 Model Context Protocol 伺服器，透過標準輸入輸出上的 JSON-RPC 讓 AI 助手與正在執行的遊戲程序互動。該專案以 C++17 建置，提供數十種工具，用於程序與模組檢查、跨程序記憶體讀寫、Cheat Engine 風格的數值與位元組陣列掃描、指標解析、位元組修補，以及透過 loadlibrary、manual map、APC 等方式進行 DLL 或 shellcode 注入。它還支援反作弊偵察，可偵測與 EasyAntiCheat、BattlEye、Vanguard 等產品相關的使用者模式模組和核心驅動程式，並提供除錯器檢查、外部控制代碼列舉以及網路擷取或注入功能。其他執行階段輔助功能包括記憶體凍結與監視迴圈、IAT hook，以及用於變速的時間縮放 hook。該專案面向需要進行 Windows 遊戲記憶體分析與安全評估、並希望借助 LLM 實現自動化的遊戲安全研究人員、逆向工程師和反作弊分析師。
