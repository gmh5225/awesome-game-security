cheat-mcp는 표준 입출력을 통한 JSON-RPC로 AI 어시스턴트가 실행 중인 게임 프로세스와 상호작용할 수 있게 하는 Windows 네이티브 Model Context Protocol 서버입니다. C++17로 구축되었으며, 프로세스 및 모듈 검사, 프로세스 간 메모리 읽기/쓰기, Cheat Engine 스타일의 값 및 바이트 배열 스캔, 포인터 해석, 바이트 패치, loadlibrary, manual map, APC 등을 이용한 DLL 또는 shellcode 주입을 위한 수십 가지 도구를 제공합니다. EasyAntiCheat, BattlEye, Vanguard 등의 제품과 관련된 사용자 모드 모듈 및 커널 드라이버 탐지, 디버거 검사, 외부 핸들 열거, 네트워크 캡처 또는 주입 등 안티치트 정찰도 지원합니다. 추가 런타임 헬퍼에는 메모리 동결 및 감시 루프, IAT 후킹, 속도 조작을 위한 시간 스케일링 후크가 포함됩니다. 이 프로젝트는 Windows 게임 메모리 분석 및 보안 평가를 LLM 기반 자동화로 수행해야 하는 게임 보안 연구자, 리버스 엔지니어, 안티치트 분석가를 대상으로 합니다.
