cheat-mcp は、標準入出力上の JSON-RPC を通じて AI アシスタントが実行中のゲームプロセスと対話できる Windows ネイティブの Model Context Protocol サーバーです。C++17 で構築され、プロセスおよびモジュールの検査、プロセス間メモリの読み書き、Cheat Engine 方式の値およびバイト配列スキャン、ポインタ解決、バイトパッチ、loadlibrary、manual map、APC などによる DLL または shellcode 注入のための数十のツールを提供します。EasyAntiCheat、BattlEye、Vanguard などの製品に関連するユーザーモードモジュールやカーネルドライバの検出、デバッガーチェック、外部ハンドルの列挙、ネットワークキャプチャまたは注入など、アンチチート偵察もサポートします。その他のランタイムヘルパーには、メモリフリーズおよびウォッチループ、IAT フック、速度操作のための時間スケーリングフックが含まれます。本プロジェクトは、Windows ゲームのメモリ分析とセキュリティ評価を LLM 駆動の自動化で行う必要がある、ゲームセキュリティ研究者、リバースエンジニア、アンチチートアナリストを対象としています。
