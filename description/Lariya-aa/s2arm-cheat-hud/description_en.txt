S2ArmCheatHUD is a standalone macOS application that provides a lightweight, non-intrusive in-game cheat overlay for S2Arm, the native Switch ARM64-to-Metal runtime on Apple Silicon. It is written primarily in Swift using AppKit, SwiftUI, the GameController framework, and Carbon hotkey registration, and it stays fully external to S2Arm without process injection or binary tampering. The HUD uses a non-activating NSPanel that can be summoned during fullscreen play via L3+R3 or Option+Z, syncs cheat toggles with S2Arm’s cheat engine through enabled.txt and status.txt, and supports safer one-shot pulse injection plus hook-address conflict detection for Atmosphere-style cheat files. Specialized injectors include dynamic pointer chains for The Legend of Zelda: Ocarina of Time, and a small Python utility helps normalize cheat definitions. It targets players and researchers who want console-style in-game cheat menus on macOS while managing S2Arm cheats in real time, in the spirit of classic handheld tools such as CWCheat, VitaCheat, and EdiZon overlays.
