S2ArmCheatHUD 是一款独立的 macOS 应用，为 S2Arm（Apple Silicon 上原生 Switch ARM64 转 Metal 运行时）提供轻量、不干扰游戏的作弊叠层。主要使用 Swift 编写，依托 AppKit、SwiftUI、GameController 框架与 Carbon 热键注册，完全独立于 S2Arm，无需进程注入或篡改二进制。HUD 采用非激活的 NSPanel，可在全屏游戏中通过 L3+R3 或 Option+Z 呼出，经由 enabled.txt 与 status.txt 与 S2Arm 作弊引擎同步开关，并支持更安全的一次性脉冲注入以及针对 Atmosphere 风格作弊文件的钩子地址冲突检测。专用注入器包含《塞尔达传说：时之笛》的动态指针链，另有小型 Python 工具用于规范化作弊定义。面向希望在 macOS 上获得掌机式游戏内作弊菜单、并实时管理 S2Arm 作弊的玩家与研究者，理念贴近 CWCheat、VitaCheat、EdiZon 等经典掌机工具叠层。
