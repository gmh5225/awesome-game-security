S2ArmCheatHUD は、Apple Silicon 上のネイティブ Switch ARM64 から Metal へのランタイムである S2Arm 向けに、軽量で邪魔にならないゲーム内チートオーバーレイを提供するスタンドアロンの macOS アプリケーションです。主に Swift で書かれ、AppKit、SwiftUI、GameController フレームワーク、Carbon のホットキー登録を用い、プロセス注入やバイナリ改ざんなしに S2Arm から完全に外部で動作します。HUD は非アクティブ化の NSPanel を使い、フルスクリーン中に L3+R3 または Option+Z で呼び出せ、enabled.txt と status.txt 経由で S2Arm のチートエンジンとトグルを同期し、より安全なワンショットパルス注入と Atmosphere 形式チートファイル向けのフックアドレス競合検出をサポートします。専用インジェクターには『ゼルダの伝説 時のオカリナ』向けの動的ポインタチェーンがあり、小型の Python ユーティリティでチート定義の正規化も支援します。macOS でコンソール風のゲーム内チートメニューを求め、S2Arm のチートをリアルタイムに管理したいプレイヤーや研究者向けで、CWCheat、VitaCheat、EdiZon など古典的な携帯機ツールのオーバーレイ精神に近いものです。
