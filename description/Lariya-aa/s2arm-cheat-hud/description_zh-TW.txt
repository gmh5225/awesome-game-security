S2ArmCheatHUD 是一款獨立的 macOS 應用程式，為 S2Arm（Apple Silicon 上原生 Switch ARM64 轉 Metal 執行環境）提供輕量、不干擾遊戲的作弊疊層。主要以 Swift 撰寫，使用 AppKit、SwiftUI、GameController 框架與 Carbon 熱鍵註冊，完全獨立於 S2Arm，無需行程注入或篡改二進位檔。HUD 採用非啟用的 NSPanel，可在全螢幕遊玩時以 L3+R3 或 Option+Z 喚出，透過 enabled.txt 與 status.txt 與 S2Arm 作弊引擎同步開關，並支援更安全的一次性脈衝注入以及針對 Atmosphere 風格作弊檔的鉤子位址衝突偵測。專用注入器包含《薩爾達傳說：時之笛》的動態指標鏈，另有小型 Python 工具協助正規化作弊定義。面向希望在 macOS 上享有主機式遊戲內作弊選單、並即時管理 S2Arm 作弊的玩家與研究者，精神貼近 CWCheat、VitaCheat、EdiZon 等經典掌機工具疊層。
