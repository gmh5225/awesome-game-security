SniParInject는 네트워크 패킷을 스니핑하고 파싱하여 온라인 게임에서 구조화된 정보를 추출하는 Python 툴킷입니다. Sniffer, Parser, Inject에서 이름을 따왔으며, 선택한 인터페이스에서 Scapy로 트래픽을 캡처하고 서버 IP와 포트로 필터링한 뒤, YAML 설정을 통해 프로토콜 옵코드를 읽기 쉬운 필드로 매핑합니다(소스 코드 수정 불필요). 규칙으로 정수, short, 문자 시퀀스 등의 바이너리 구조를 정의할 수 있으며, 호스트와 노드 트래픽 모두에 대해 16진수 또는 포맷된 출력을 제공합니다. 패킷 인젝션은 계획되어 있으나 아직 완료되지 않았습니다. Mana Plus 예시처럼, 실시간 게임 프로토콜 트래픽을 검사하고 디코딩해야 하는 게임 보안 연구원과 리버스 엔지니어를 대상으로 합니다.
