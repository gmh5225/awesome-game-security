SniParInject は、ネットワークパケットをスニッフィングして解析し、オンラインゲームから構造化情報を抽出する Python ツールキットです。Sniffer、Parser、Inject に由来する名前で、選択したインターフェース上で Scapy によりトラフィックをキャプチャし、サーバー IP とポートでフィルタしたうえで、YAML 設定によりプロトコルのオペコードを読みやすいフィールドへ対応付けます（ソースコードの変更は不要）。ルールでは整数、short、文字シーケンスなどのバイナリ構造体を定義でき、ホストおよびノード双方のトラフィックを十六進または整形出力で表示できます。パケットインジェクションは計画中ですが、まだ完了していません。Mana Plus の例に示されるように、ライブのゲームプロトコル通信を検査・復号したいゲームセキュリティ研究者やリバースエンジニアを対象としています。
