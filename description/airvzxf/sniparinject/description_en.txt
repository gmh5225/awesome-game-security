SniParInject is a Python toolkit that sniffs and parses network packets to extract structured information from online games. Named for Sniffer, Parser, and Inject, it captures traffic with Scapy on a chosen interface and filters by server IP and port, then maps protocol opcodes to readable fields through YAML settings without changing source code. Rules can define binary structs such as integers, shorts, and character sequences with hex or formatted output for both host and node traffic. Packet injection is planned but not yet complete. It is aimed at game security researchers and reverse engineers who need to inspect and decode live game protocol traffic, as shown with Mana Plus.
