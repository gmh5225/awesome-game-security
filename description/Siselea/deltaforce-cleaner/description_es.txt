Delta Force Cleaner es un desinstalador completo orientado a Windows para Delta Force (三角洲行动) que elimina el juego y restos del stack antitrampas ACE (AntiCheatExpert) de Tencent. Está implementado en Python 3.9+ usando solo la biblioteca estándar, con una GUI basada en Tk, modo CLI y un módulo motor sin interfaz respaldado por pruebas unitarias y soporte de dry-run. El escáner apunta a controladores de kernel ACE y servicios versionados, rutas de instalación en Program Files y ProgramData, carpetas del juego en todas las unidades, claves de registro de desinstalación, restos relacionados con WeGame y accesos directos del lanzador, excluyendo explícitamente controladores de almacenamiento de Windows que coinciden falsamente con nombres ACE y carpetas compartidas de Tencent usadas por WeChat o QQ. Las reglas de detección están documentadas y diseñadas para que cada objetivo de eliminación sea demostrablemente propiedad de ACE o del juego, con listas protegidas para no dañar el SO u otras aplicaciones de Tencent. Está dirigido a jugadores, investigadores y profesionales de seguridad que necesitan una forma revisable y repetible de purgar por completo un antitrampas persistente a nivel de kernel tras una desinstalación normal del juego.
