Delta Force Cleaner は Windows 向けの徹底アンインストーラーで、Delta Force（三角洲行动）本体と Tencent の ACE（AntiCheatExpert）アンチチート基盤の残骸を除去します。Python 3.9 以降と標準ライブラリのみで実装され、Tk ベースの GUI、CLI モード、単体テストとドライラン対応のヘッドレスエンジンモジュールを備えます。スキャナは ACE カーネルドライバとバージョン付きサービス、Program Files および ProgramData のインストールパス、各ドライブ上のゲームフォルダ、アンインストール用レジストリキー、WeGame 関連の残骸、ランチャーのショートカットを対象とし、ACE の名前に誤って一致する Windows ストレージドライバや WeChat・QQ が使う共有 Tencent フォルダは明示的に除外します。検出ルールは文書化され、各削除対象が ACE またはゲーム固有であることを検証可能に設計され、保護リストで OS や他の Tencent アプリを損なわないようにしています。通常のアンインストール後も残るカーネルレベルのアンチチートを、監査可能で再現性のある方法で完全に除去したいプレイヤー、研究者、セキュリティ担当者向けです。
