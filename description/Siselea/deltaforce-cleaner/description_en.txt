Delta Force Cleaner is a Windows-oriented clean uninstaller for Delta Force (三角洲行动) that removes the game and leftover traces of Tencent’s ACE (AntiCheatExpert) anti-cheat stack. It is implemented in Python 3.9+ using only the standard library, with a Tk-based GUI, a CLI mode, and a headless engine module backed by unit tests and dry-run support. The scanner targets ACE kernel drivers and versioned services, Program Files and ProgramData install paths, game folders across drives, uninstall registry keys, WeGame-related remnants, and launcher shortcuts, while explicitly excluding Windows storage drivers that falsely match ACE naming and shared Tencent folders used by WeChat or QQ. Detection rules are documented and designed so each removal target is provably ACE- or game-owned, with protected lists to avoid damaging the OS or other Tencent applications. It is aimed at players, researchers, and security practitioners who need a reviewable, repeatable way to fully purge persistent kernel-level anti-cheat after a normal game uninstall.
