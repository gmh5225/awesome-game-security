Delta Force Cleaner 是一款面向 Windows 的徹底解除安裝工具，用於移除《三角洲行動》（Delta Force）及騰訊 ACE（AntiCheatExpert）反作弊體系的殘留。專案以 Python 3.9+ 實作，僅使用標準函式庫，提供 Tk 圖形介面、CLI 模式，以及由單元測試與 dry-run 支援的無介面引擎模組。掃描器會鎖定 ACE 核心驅動與帶版本號的服務、Program Files 與 ProgramData 安裝路徑、各磁碟上的遊戲資料夾、解除安裝登錄機碼、WeGame 相關殘留與啟動器捷徑，同時明確排除因命名與 ACE 相似而被誤判的 Windows 儲存驅動，以及 WeChat、QQ 等共用的騰訊目錄。偵測規則均有文件說明，旨在讓每一項移除目標皆可證明屬於 ACE 或遊戲本體，並以保護清單避免損害作業系統或其他騰訊應用。適合需要可審查、可重複地完全清除一般解除安裝後仍殘留的核心層級反作弊的玩家、研究人員與安全從業者。
