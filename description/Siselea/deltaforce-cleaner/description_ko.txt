Delta Force Cleaner는 Windows용 완전 제거 도구로, Delta Force(三角洲行动)와 Tencent의 ACE(AntiCheatExpert) 안티치트 스택 잔여물을 제거합니다. Python 3.9 이상과 표준 라이브러리만으로 구현되었으며, Tk 기반 GUI, CLI 모드, 단위 테스트와 dry-run을 지원하는 헤드리스 엔진 모듈을 제공합니다. 스캐너는 ACE 커널 드라이버와 버전이 있는 서비스, Program Files 및 ProgramData 설치 경로, 드라이브 전역의 게임 폴더, 제거 레지스트리 키, WeGame 관련 잔여물, 런처 바로 가기를 대상으로 하며, ACE 명명과 잘못 일치하는 Windows 스토리지 드라이버와 WeChat·QQ가 쓰는 공유 Tencent 폴더는 명시적으로 제외합니다. 탐지 규칙은 문서화되어 있으며 각 제거 대상이 ACE 또는 게임 소유임을 입증할 수 있도록 설계되었고, 보호 목록으로 OS나 다른 Tencent 애플리케이션을 손상하지 않습니다. 일반 게임 제거 후에도 남는 커널 수준 안티치트를 검토 가능하고 반복 가능한 방식으로 완전히 제거해야 하는 플레이어, 연구자, 보안 실무자를 위한 도구입니다.
