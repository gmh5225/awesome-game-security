Delta Force Cleaner 是一款面向 Windows 的彻底卸载工具，用于卸载《三角洲行动》（Delta Force）并清除腾讯 ACE（AntiCheatExpert）反作弊体系的残留。项目基于 Python 3.9+，仅使用标准库，提供 Tk 图形界面、CLI 模式以及由单元测试与 dry-run 支持的无界面引擎模块。扫描器会定位 ACE 内核驱动与带版本号的服务、Program Files 与 ProgramData 安装路径、各盘符下的游戏目录、卸载注册表项、WeGame 相关残留与启动器快捷方式，同时明确排除因命名与 ACE 相似而被误识别的 Windows 存储驱动，以及 WeChat、QQ 等共用的腾讯目录。检测规则均有文档说明，力求每一项删除目标均可证明归属 ACE 或游戏本体，并借助保护列表避免破坏操作系统或其他腾讯应用。面向需要可审查、可重复地彻底清除普通卸载后仍存留的内核级反作弊的玩家、研究人员与安全从业者。
