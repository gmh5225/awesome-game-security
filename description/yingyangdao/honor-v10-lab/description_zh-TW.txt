本儲存庫記錄如何將執行 EMUI 9 的已鎖定榮耀 V10（BKL-AL20）改造成已 root、常駐連線的 Android 實驗機，供開發、除錯與流量分析使用。內容涵蓋完整解鎖與 root 路徑——包括無需官方碼的軟體測試點 bootloader 解鎖——以及因應華為特有限制的做法，例如嚴格的 SELinux 與 frida-server 異常。環境以 Magisk 20.1、EdXposed、Frida Gadget 注入、用於 MITM 的系統 CA 信任、Termux tcpdump，以及可選的 root 隱藏與廣告攔截模組為核心。配套材料包含逐步指南、踩坑說明、HwOUC 逆向筆記、可重複使用的 PowerShell 與 shell 自動化腳本，以及日常控機用的 harness skill。面向行動安全研究人員、逆向工程師，以及需要可重現的榮耀或華為 Kirin 測試平台以進行 hook、封包擷取與應用程式行為分析（含遊戲用戶端與防篡改檢查）的讀者。
