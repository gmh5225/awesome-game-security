本仓库记录如何将运行 EMUI 9 的已锁定荣耀 V10（BKL-AL20）改造成已 root、常在线的 Android 实验机，用于开发、调试与流量分析。内容涵盖完整解锁与 root 路径——包括无需官方码的软件测试点 bootloader 解锁——以及如何应对华为特有约束，例如严格的 SELinux 与 frida-server 异常。环境以 Magisk 20.1、EdXposed、Frida Gadget 注入、用于 MITM 的系统 CA 信任、Termux tcpdump 以及可选的 root 隐藏与广告拦截模块为核心。配套材料包括分步指南、踩坑说明、HwOUC 逆向笔记、可复用的 PowerShell 与 shell 自动化脚本，以及日常控机用的 harness skill。面向移动安全研究人员、逆向工程师，以及需要可复现的荣耀或华为 Kirin 测试平台以进行 hook、抓包与应用行为分析（含游戏客户端与防篡改检测）的读者。
