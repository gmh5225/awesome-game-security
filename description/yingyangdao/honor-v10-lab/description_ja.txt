本リポジトリは、EMUI 9 上のロックされた Honor V10（BKL-AL20）を、開発・デバッグ・トラフィック解析向けの root 済み常時接続 Android ラボ端末へ作り変える手順を記録している。公式コード不要のソフトウェアテストポイントによる bootloader アンロックを含む完全なアンロック・root 手順や、厳格な SELinux や動作不良の frida-server といった Huawei 固有の制約への対処法を網羅する。構成の中心は Magisk 20.1、EdXposed、Frida Gadget 注入、MITM 用のシステム CA 信頼、Termux tcpdump、および root 隠蔽や広告ブロック用の任意モジュールである。ステップバイステップのガイド、落とし穴メモ、HwOUC リバースエンジニアリングノート、再利用可能な PowerShell と shell 自動化、日常の端末制御用 harness skill などの支援資料も含む。モバイルセキュリティ研究者、リバースエンジニア、および hook、パケットキャプチャ、アプリ挙動解析（ゲームクライアントや改ざん検知を含む）のための再現可能な Honor または Huawei Kirin テストベッドを必要とする読者を対象とする。
