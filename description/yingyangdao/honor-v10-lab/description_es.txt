Este repositorio documenta cómo convertir un Honor V10 (BKL-AL20) bloqueado con EMUI 9 en un dispositivo Android de laboratorio con root y conexión permanente para desarrollo, depuración y análisis de tráfico. Recoge la ruta completa de desbloqueo y root —incluido el desbloqueo del bootloader por punto de prueba de software sin código oficial— y cómo sortear limitaciones propias de Huawei, como un SELinux estricto y un frida-server defectuoso. La configuración se centra en Magisk 20.1, EdXposed, inyección de Frida Gadget, confianza de CA del sistema para MITM, Termux tcpdump y módulos opcionales para ocultar root y bloquear anuncios. El material de apoyo incluye guías paso a paso, notas sobre trampas, apuntes de ingeniería inversa de HwOUC, automatización reutilizable en PowerShell y shell, y una skill harness para el control diario del dispositivo. Está dirigido a investigadores de seguridad móvil, ingenieros inversos y quienes necesiten un banco de pruebas Honor o Huawei Kirin reproducible para hooking, captura de paquetes y análisis del comportamiento de aplicaciones —incluidos clientes de juegos y comprobaciones anti-manipulación.
