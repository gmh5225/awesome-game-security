This is a reverse engineering and learning project for Far Cry 6 that injects a C++ DLL to read live game memory and reuse engine systems such as aim-assist targets, animated skeletons, Havok collision queries, and item functions. It implements an aimbot with ballistics and line-of-sight checks, skeleton ESP, a Direct2D overlay with HUD and menu, and inventory manipulation, plus an external injector, memory probe executable, and dozens of Python research scripts for scanning, tracing, and calibration. Development emphasizes techniques like signature and pattern scanning, hardware breakpoint hooks without patching game code, shared-memory IPC, and documented structure offsets for a specific game build. The primary audience is researchers and students studying game internals, memory analysis, and in-process overlay design for offline single-player experimentation, not multiplayer or anti-cheat evasion.
