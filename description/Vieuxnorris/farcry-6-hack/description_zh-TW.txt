這是一個針對《極地戰慄 6》的逆向工程與學習專案，透過注入 C++ DLL 讀取即時遊戲記憶體，並重用引擎系統，例如輔助瞄準目標、動畫骨架、Havok 碰撞查詢以及物品相關功能。專案實作了含彈道與視線檢查的自動瞄準、骨架 ESP、附 HUD 與選單的 Direct2D 疊加層、背包操控，以及外部注入器、記憶體探測可執行檔和大量用於掃描、追蹤與校準的 Python 研究腳本。開發強調簽名與特徵碼掃描、在不修補遊戲程式碼的情況下使用硬體中斷點掛鉤、共享記憶體 IPC，以及針對特定遊戲版本的已文件化結構偏移。主要對象為研究遊戲內部機制、記憶體分析與進程內疊加層設計的研究者與學生，供離線單人實驗使用，而非多人對戰或反作弊規避。
