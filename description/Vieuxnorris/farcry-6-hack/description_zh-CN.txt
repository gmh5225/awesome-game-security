这是一个针对《孤岛惊魂 6》的逆向工程与学习项目，通过注入 C++ DLL 读取实时游戏内存，并复用引擎系统，例如辅助瞄准目标、动画骨骼、Havok 碰撞查询以及物品相关功能。项目实现了带弹道与视线检测的自瞄、骨骼 ESP、带 HUD 与菜单的 Direct2D 叠加层、背包操控，以及外部注入器、内存探测可执行文件和大量用于扫描、追踪与校准的 Python 研究脚本。开发侧重签名与特征码扫描、在不修改游戏代码的情况下使用硬件断点挂钩、共享内存 IPC，以及针对特定游戏版本的已文档化结构体偏移。主要面向研究游戏内部机制、内存分析与进程内叠加层设计的学习者与研究人员，用于离线单人实验，而非多人对战或反作弊规避。
