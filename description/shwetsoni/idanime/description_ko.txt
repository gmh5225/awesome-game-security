idanime는 IDA Pro 9.x용 애니메이션 스타일 컬러 테마 모음으로, 디스어셈블리·의사코드·그래프 뷰에 어울리는 배경 아트워크를 추가합니다. 열두 개의 이름 있는 테마를 사용자가 설치할 수 있는 CSS 패키지로 제공하며 테마별 아트 에셋을 포함하고, 네이티브 테마로는 불가능한 그래프 캔버스에 이미지를 오버레이·블렌딩하는 PySide6 기반 IDAPython 플러그인도 함께 제공합니다. 텍스트 뷰는 CustomIDAMemo 스타일과 투명한 줄 배경에 고정된 이미지를 사용하고, 플러그인은 lighten·darken 블렌딩, HiDPI 에셋, IDA 스타일시트의 테마 감지로 노드와 코드 가독성을 유지합니다. Windows, Linux, macOS를 지원하며 IDA에서 오랜 세션을 보내는 리버스 엔지니어, 멀웨어 분석가, 게임 보안 연구자가 워크플로 성능을 해치지 않고 시각 테마를 맞춤 설정할 수 있도록 만들어졌습니다.
