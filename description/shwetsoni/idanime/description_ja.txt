idanime は IDA Pro 9.x 向けのアニメ調カラーテーマ集で、逆アセンブル・疑似コード・グラフビューに合わせた背景アートを追加します。12 の名前付きテーマをユーザーがインストール可能な CSS パッケージとして提供し、テーマごとのアセットに加え、ネイティブテーマでは対応できないグラフキャンバス上で画像を重ねてブレンドする PySide6 ベースの IDAPython プラグインも同梱しています。テキストビューは CustomIDAMemo のスタイルと透明な行背景にアンカーされた画像で構成し、プラグインは lighten／darken ブレンド、HiDPI アセット、IDA のスタイルシートからのテーマ検出によりノードとコードの可読性を保ちます。Windows、Linux、macOS を対象とし、IDA で長時間作業するリバースエンジニア、マルウェア解析者、ゲームセキュリティ研究者向けに、ワークフローのパフォーマンスを損なわずに視覚テーマをカスタマイズできるように設計されています。
