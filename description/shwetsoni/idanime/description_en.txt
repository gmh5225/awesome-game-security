idanime is a collection of anime-styled color themes for IDA Pro 9.x that adds matching background artwork to disassembly, pseudocode, and graph views. It ships twelve named themes implemented as user-installable CSS packages with per-theme art assets, plus an IDAPython plugin built on PySide6 that overlays and blends images on the graph canvas where native theming cannot. Text views rely on CustomIDAMemo styling and transparent line backgrounds with anchored images, while the plugin uses lighten or darken blending, HiDPI assets, and theme detection from IDA’s stylesheet to keep nodes and code readable. The stack targets Windows, Linux, and macOS and is meant for reverse engineers, malware analysts, and game security researchers who spend long sessions in IDA and want customizable visual themes without hurting workflow performance.
