idanime 是一套面向 IDA Pro 9.x 的动漫风格配色主题，为反汇编、伪代码和图形视图配以相匹配的背景插画。项目提供十二个具名主题，以用户可安装的 CSS 包形式交付，并附带各主题的美术资源；另含基于 PySide6 的 IDAPython 插件，在原生主题无法覆盖的图形画布上叠加并混合图像。文本视图通过 CustomIDAMemo 样式与透明行背景加锚定图像实现；插件采用变亮或变暗混合、HiDPI 资源，并从 IDA 样式表检测主题，以保持节点与代码可读。支持 Windows、Linux 与 macOS，面向在 IDA 中长时间作业的逆向工程师、恶意软件分析师与游戏安全研究者，在不影响工作流性能的前提下自定义视觉主题。
