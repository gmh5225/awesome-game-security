Unturned-Godot est un port expérimental Godot 4.7 qui charge de vraies cartes, terrains, objets, audio et personnages Unturned directement depuis une installation Steam locale et les affiche dans un runtime jouable. Le projet réimplémente de zéro les formats d'assets Unturned et Unity en C#, y compris l'extraction des master bundles, l'analyse DAT, les heightmaps, les navmeshes, les meshes compressés et le décodage audio FSB5, validés octet par octet par rapport aux données officielles du jeu en utilisant l'U3-SDK comme référence de sérialisation. Il comprend une bibliothèque core indépendante du moteur avec une couverture xUnit étendue, un front-end Godot pour la construction de mondes et le multijoueur, ainsi que des outils d'éditeur pour prévisualiser les cartes et précharger les caches d'assets. La base de code s'adresse aux chercheurs et développeurs étudiant les formats de fichiers Unturned, les structures de bundles Unity et l'extraction de données de jeu, plutôt qu'à la publication d'un jeu autonome.
