BSAntiCheat 是一款輕量級、注重降低誤判的 Minecraft Paper 1.21.10+ 伺服器反作弊外掛，完整支援 Folia。此外掛以 Java 撰寫，可偵測移動、戰鬥、世界互動、物品欄、載具及封包層級的作弊行為，例如加速、飛行、攻擊距離、KillAura、Nuker、自動點擊器與 X-Ray 挖礦等。外掛採用基於交易的延遲補償、可設定的違規等級懲罰（可選回退）、SQLite 日誌記錄，並與 PacketEvents、Discord Webhook、PlaceholderAPI 和 LuckPerms 整合。它面向希望取得啟發式、可調式作弊偵測，並能針對自身環境進行校準、而非預設誤判正常玩家的伺服器管理員。
