BSAntiCheat 是一款轻量级、注重降低误报的 Minecraft Paper 1.21.10+ 服务器反作弊插件，完整支持 Folia。该插件使用 Java 编写，可检测移动、战斗、世界交互、物品栏、载具及数据包层面的作弊行为，例如加速、飞行、攻击距离、KillAura、Nuker、自动点击器和 X-Ray 挖矿等。插件采用基于事务的延迟补偿、可配置的违规等级惩罚（可选回退）、SQLite 日志记录，并与 PacketEvents、Discord Webhook、PlaceholderAPI 和 LuckPerms 集成。它面向希望获得启发式、可调式作弊检测，并能针对自身环境进行校准、而非默认误伤正常玩家的服务器管理员。
