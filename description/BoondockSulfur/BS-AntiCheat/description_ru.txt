BSAntiCheat — лёгкий античит-плагин для серверов Minecraft Paper 1.21.10+ с акцентом на снижение ложных срабатываний и полной поддержкой Folia. Написан на Java и обнаруживает читы в движении, бою, взаимодействии с миром, инвентаре, транспорте и на уровне пакетов: speed, fly, reach, KillAura, Nuker, autoclicker и X-Ray-добычу. Плагин использует компенсацию задержки на основе транзакций, настраиваемые наказания по уровням нарушений с опциональным откатом, логирование в SQLite, а также интеграции с PacketEvents, Discord webhooks, PlaceholderAPI и LuckPerms. Он предназначен для администраторов серверов, которым нужно эвристическое, настраиваемое обнаружение читов, калибруемое под их окружение, а не помечающее легитимных игроков по умолчанию.
