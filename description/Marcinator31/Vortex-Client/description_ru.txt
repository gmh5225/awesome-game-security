Vortex Client — это мод Fabric для Minecraft, расширяющий игровой клиент настраиваемыми HUD-элементами, ESP, точками маршрута, скинами и инструментами производительности, управляемыми через внутриигровое меню. Проект создан на Java с использованием Fabric Loader, Mixins и Gradle и включает боевые оверлеи, предпросмотр траектории снарядов, помощники для поиска баз, свободную камеру, макросы и общие предустановленные профили. Он также предоставляет модули автоматизации боя, такие как aimbot, auto-totem, полёт и no-fall, которые разработчики прямо отмечают как легко обнаруживаемые античит-системами. Предназначен для сообщества моддинга Minecraft и исследователей игровой безопасности, которым нужен эталонный клиент для изучения клиентских хуков рендеринга, информационных оверлеев и того, как реализуются и помечаются функции, близкие к читам.
