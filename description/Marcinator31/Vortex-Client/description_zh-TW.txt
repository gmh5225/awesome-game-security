Vortex Client 是一款面向 Minecraft 的 Fabric 模組，透過遊戲內選單提供可設定的 HUD 元素、ESP、路徑點、外觀與效能工具，擴展遊戲用戶端功能。該專案以 Java 為基礎，使用 Fabric Loader、Mixins 與 Gradle 建置，包含戰鬥覆蓋層、彈道軌跡預覽、尋基地輔助、自由視角、巨集以及可分享的預設設定檔。專案還提供 aimbot、自動圖騰、飛行與防摔等戰鬥自動化模組，維護者明確指出這些功能極易被反作弊系統偵測。它面向 Minecraft 模組開發者與遊戲安全研究人員，可作為研究用戶端渲染掛鉤、資訊覆蓋層，以及作弊類功能如何實作與標記的參考用戶端。
