Vortex Client is a Fabric mod for Minecraft that extends the game client with configurable HUD elements, ESP, waypoints, skins, and performance tools managed through an in-game menu. Built in Java with Fabric Loader, Mixins, and Gradle, it includes combat overlays, projectile path previews, base-hunting helpers, freecam, macros, and shareable preset profiles. The project also exposes combat-automation modules such as aimbot, auto-totem, fly, and no-fall that the maintainers explicitly mark as easily detected by anti-cheat systems. It serves Minecraft modding audiences and game-security researchers who need a reference client for studying client-side rendering hooks, information overlays, and how cheat-adjacent features are implemented and flagged.
