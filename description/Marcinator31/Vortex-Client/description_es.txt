Vortex Client es un mod de Fabric para Minecraft que amplía el cliente del juego con elementos HUD configurables, ESP, puntos de ruta, skins y herramientas de rendimiento gestionadas a través de un menú dentro del juego. Desarrollado en Java con Fabric Loader, Mixins y Gradle, incluye superposiciones de combate, vistas previas de trayectorias de proyectiles, ayudas para buscar bases, cámara libre, macros y perfiles predefinidos compartibles. El proyecto también expone módulos de automatización de combate como aimbot, auto-totem, vuelo y anti-caída, que los mantenedores señalan explícitamente como fácilmente detectables por los sistemas anti-cheat. Está dirigido a la comunidad de modding de Minecraft e investigadores de seguridad en videojuegos que necesitan un cliente de referencia para estudiar hooks de renderizado del lado del cliente, superposiciones informativas y cómo se implementan y marcan las funciones relacionadas con trampas.
