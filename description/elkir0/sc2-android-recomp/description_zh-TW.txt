本專案是一套工具包與成文方法論，用於將遺留的 x86-32 Windows 遊戲引擎靜態重編譯為原生 ARM64，並以 Android 版 StarCraft II 為參考目標。儲存庫僅包含原創輔助程式碼，不含遊戲二進位或資源，使用者需從合法安裝在本機產生 lifted C 與執行時期產物。核心元件包括：借助 Unicorn 的逐函式差分測試、離線 D3D9 SM2/3 位元組碼到 SPIR-V 的翻譯、Android Bionic 與 Vulkan 移植輔助、MPQ 提取工具，以及針對 atomics、MMX 與 SSE 邊界情況的增量 pcrecomp 提升器修補。實作涵蓋 Python、C/C++、ARM64 組合語言及與 NDK、Vulkan 堆疊搭配的 shell 指令碼。適合研究 PE 提升、二進位翻譯正確性、圖形與音訊互操作，以及離線個人用途引擎移植的研究者與工程師，而非線上反作弊繞過。
