Este proyecto es un conjunto de herramientas y una metodología documentada para recompilar estáticamente un motor de juego Windows x86-32 heredado a ARM64 nativo, con StarCraft II en Android como objetivo de referencia. Solo incluye código auxiliar original—sin binarios ni recursos del juego—y espera que los usuarios generen localmente C elevado y artefactos de tiempo de ejecución a partir de una instalación legítima. Los componentes principales incluyen pruebas diferenciales por función frente a Unicorn, traducción offline de bytecode D3D9 SM2/3 a SPIR-V, ayudas de portado a Android Bionic y Vulkan, utilidades de extracción MPQ y parches incrementales del lifter pcrecomp para atomics, MMX y casos límite de SSE. La implementación abarca Python, C y C++, ensamblador ARM64 y scripts shell ligados a la pila NDK y Vulkan. Está pensado para investigadores e ingenieros que estudian el lifting PE, la corrección de la traducción binaria, la interoperabilidad gráfica y de audio y el portado offline de motores para uso personal, no para eludir anti-cheat en línea.
