This project is a toolkit and documented methodology for statically recompiling a legacy x86-32 Windows game engine to native ARM64, with StarCraft II on Android as the reference target. It ships only original helper code—no game binaries or assets—and expects users to generate lifted C and runtime artifacts locally from a legitimate install. Core components include per-function differential testing against Unicorn, offline D3D9 SM2/3 bytecode to SPIR-V translation, Android Bionic and Vulkan porting helpers, MPQ extraction utilities, and incremental pcrecomp lifter patches for atomics, MMX, and SSE edge cases. Implementation spans Python, C and C++, ARM64 assembly, and shell scripts tied to the NDK and Vulkan stack. It suits researchers and engineers studying PE lifting, binary translation correctness, graphics and audio interoperability, and offline personal-use engine porting rather than online anti-cheat bypass.
