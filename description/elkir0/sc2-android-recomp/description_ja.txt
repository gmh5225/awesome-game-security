本プロジェクトは、レガシーな x86-32 Windows ゲームエンジンをネイティブ ARM64 へ静的再コンパイルするためのツールキットと文書化された方法論であり、Android 版 StarCraft II を参照ターゲットとする。配布物は独自のヘルパーコードのみで、ゲームバイナリやアセットは含まず、利用者は正規インストールから lifted C とランタイム成果物をローカルで生成する必要がある。中核要素には、Unicorn による関数単位の差分テスト、オフラインの D3D9 SM2/3 バイトコードから SPIR-V への変換、Android Bionic と Vulkan 向け移植ヘルパー、MPQ 抽出ユーティリティ、および atomics、MMX、SSE のエッジケース向けの段階的 pcrecomp リフター修正が含まれる。実装は Python、C/C++、ARM64 アセンブリ、NDK と Vulkan スタックに紐づくシェルスクリプトにまたがる。PE リフティング、バイナリ翻訳の正しさ、グラフィックスとオーディオの相互運用、オフライン個人利用のエンジンポートを学ぶ研究者やエンジニア向けであり、オンラインアンチチート回避向けではない。
