本项目是一套工具包与成文方法论，用于将遗留的 x86-32 Windows 游戏引擎静态重编译为原生 ARM64，并以 Android 版 StarCraft II 为参考目标。仓库仅包含原创辅助代码，不含游戏二进制或资源，用户需从合法安装本地生成 lifted C 与运行时产物。核心组件包括：借助 Unicorn 的逐函数差分测试、离线 D3D9 SM2/3 字节码到 SPIR-V 的翻译、Android Bionic 与 Vulkan 移植辅助、MPQ 提取工具，以及针对 atomics、MMX 与 SSE 边界情况的增量 pcrecomp 提升器补丁。实现涉及 Python、C/C++、ARM64 汇编及与 NDK、Vulkan 栈配套的 shell 脚本。适合研究 PE 提升、二进制翻译正确性、图形与音频互操作，以及离线个人用途引擎移植的研究者与工程师，而非在线反作弊绕过。
