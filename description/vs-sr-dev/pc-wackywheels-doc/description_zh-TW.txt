本專案是一項針對 Wacky Wheels 的文件整理與逆向工程工作；該作是 Beavis Soft 與 Apogee Software 於 1994 年推出的 DOS 卡丁車賽車遊戲。專案分析 1994 年原版零售版中的遊戲資料，涵蓋 WACKY.DAT 壓縮包、賽道與精靈圖格式、偽 3D 地面渲染器所用的定點查表、音訊資源，以及存檔與設定檔。以純 Python 3 搭配 numpy 與 Pillow 的工具可解析並提取這些格式、重建世界紋理，並與 Skunny Kart 等相關作品進行交叉對照。這項工作具有考古性質，依據實際發行的檔案而非粉絲重建版本，面向復古遊戲逆向工程師以及研究經典 DOS 遊戲引擎與資料結構的研究者。
