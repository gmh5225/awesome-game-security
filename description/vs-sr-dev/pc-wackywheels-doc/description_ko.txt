이 프로젝트는 Beavis Soft와 Apogee Software의 1994년 DOS 카트 레이서 Wacky Wheels에 초점을 맞춘 문서화 및 리버스 엔지니어링 작업입니다. 1994년 오리지널 빌드의 정식 판매 게임 데이터를 분석하며, WACKY.DAT 아카이브, 트랙 및 스프라이트 형식, 의사 3D 바닥 렌더러용 고정소수점 룩업 테이블, 오디오 에셋, 세이브 및 설정 파일 등을 다룹니다. numpy와 Pillow를 사용하는 순수 Python 3 도구가 이러한 형식을 파싱하고 추출하며, 월드 텍스처를 재구성하고 Skunny Kart 같은 관련 타이틀과 상호 참조합니다. 이 작업은 팬 재구성이 아닌 출하 파일에서 도출된 고고학적 성격을 지니며, 클래식 DOS 게임 엔진과 데이터 구조를 연구하는 레트로 게임 리버스 엔지니어 및 연구자를 대상으로 합니다.
