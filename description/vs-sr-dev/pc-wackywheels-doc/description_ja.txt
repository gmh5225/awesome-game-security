このプロジェクトは、Beavis Soft と Apogee Software による 1994 年の DOS カートレーサー Wacky Wheels に焦点を当てたドキュメント化とリバースエンジニアリングの取り組みです。1994 年のオリジナルビルドの小売版ゲームデータを分析し、WACKY.DAT アーカイブ、トラックおよびスプライト形式、疑似 3D フロアレンダラー用の定点ルックアップテーブル、オーディオアセット、セーブおよび設定ファイルなどを扱います。numpy と Pillow を用いた純粋な Python 3 ツールがこれらの形式を解析・抽出し、ワールドテクスチャを再構築し、Skunny Kart など関連タイトルとの相互参照も行います。この作業は考古学的な性質を持ち、ファンによる再構築ではなく出荷ファイルに基づいており、クラシック DOS ゲームエンジンとデータ構造を研究するレトロゲームのリバースエンジニアおよび研究者を対象としています。
