This project is a documentation and reverse-engineering effort focused on Wacky Wheels, the 1994 DOS kart racer from Beavis Soft and Apogee Software. It analyzes the retail game data from the original 1994 build, including the WACKY.DAT archive, track and sprite formats, fixed-point lookup tables for the pseudo-3D floor renderer, audio assets, and save and configuration files. Pure Python 3 tools with numpy and Pillow parse and extract these formats, rebuild world textures, and cross-reference related titles such as Skunny Kart. The work is archaeological in nature, derived from shipped files rather than fan reconstructions, and is aimed at retro game reverse engineers and researchers studying classic DOS game engines and data structures.
