本项目是一项针对 Wacky Wheels 的文档整理与逆向工程工作；该作是 Beavis Soft 与 Apogee Software 于 1994 年推出的 DOS 卡丁车赛车游戏。项目分析 1994 年原版零售版中的游戏数据，涵盖 WACKY.DAT 压缩包、赛道与精灵图格式、伪 3D 地面渲染器所用的定点查表、音频资源，以及存档与配置文件。基于纯 Python 3，配合 numpy 与 Pillow 的工具可解析并提取这些格式、重建世界纹理，并与 Skunny Kart 等相关作品进行交叉对照。这项工作具有考古性质，依据实际发行的文件而非粉丝重建版本，面向复古游戏逆向工程师以及研究经典 DOS 游戏引擎与数据结构的研究者。
