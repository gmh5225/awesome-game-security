Saturnkit es un conjunto de herramientas independiente del juego para la ingeniería inversa de Sega Saturn y la creación de ports nativos para PC de juegos de Saturn. Proporciona módulos Python puros para analizar imágenes de disco, decodificar y analizar ejecutables SH-2, mapear registros de hardware, descubrir funciones, comparar código entre programas y recompilar estáticamente binarios SH-2 a C++. Un runtime C++20 emula el hardware de Saturn, incluidas ambas CPUs SH-2, los gráficos VDP1 y VDP2, el SCU, el SMPC, el bloque CD y el subsistema de sonido SCSP con un Musashi 68000, y ejecuta el juego recompilado en una ventana SDL3 y OpenGL con soporte para mando. El conjunto de herramientas está diseñado para integrarse como submódulo en proyectos de port por juego, manteniendo separado el conocimiento compartido de la plataforma Saturn de la lógica específica de cada título. Está dirigido a ingenieros de ingeniería inversa y desarrolladores que portan o analizan títulos de Sega Saturn.
