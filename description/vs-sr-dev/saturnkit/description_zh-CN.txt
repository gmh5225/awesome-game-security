Saturnkit 是一款与具体游戏无关的工具包，用于世嘉 Saturn 的逆向工程以及构建 Saturn 游戏的原生 PC 移植。它提供纯 Python 模块，用于解析光盘镜像、解码与分析 SH-2 可执行文件、映射硬件寄存器、发现函数、在多个程序之间匹配代码，以及将 SH-2 二进制文件静态重编译为 C++。C++20 运行时会模拟 Saturn 硬件，包括两颗 SH-2 CPU、VDP1 与 VDP2 图形、SCU、SMPC、CD block 和带 Musashi 68000 的 SCSP 音频子系统，并在支持手柄的 SDL3 与 OpenGL 窗口中运行重编译后的游戏。该工具包设计为嵌入各游戏移植项目的子模块，将 Saturn 平台的通用知识与各游戏专属逻辑分离。它面向逆向工程师以及移植或分析世嘉 Saturn 游戏的开发者。
