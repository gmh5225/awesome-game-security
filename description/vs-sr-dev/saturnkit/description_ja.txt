Saturnkit は、Sega Saturn のリバースエンジニアリングおよび Saturn ゲームのネイティブ PC 移植向けの、ゲーム非依存ツールキットです。ディスクイメージの解析、SH-2 実行ファイルのデコードと解析、ハードウェアレジスタのマッピング、関数の発見、プログラム間のコード照合、SH-2 バイナリの C++ への静的再コンパイルなどを行う純粋な Python モジュールを提供します。C++20 ランタイムは、2 つの SH-2 CPU、VDP1 および VDP2 グラフィックス、SCU、SMPC、CD block、Musashi 68000 を備えた SCSP サウンドサブシステムを含む Saturn ハードウェアをエミュレートし、再コンパイルされたゲームをゲームパッド対応の SDL3 および OpenGL ウィンドウで実行します。このツールキットは、ゲームごとの移植プロジェクトにサブモジュールとして組み込むことを想定しており、Saturn プラットフォームの共通知識とタイトル固有のロジックを分離します。Sega Saturn タイトルの移植や解析を行うリバースエンジニアおよび開発者を対象としています。
