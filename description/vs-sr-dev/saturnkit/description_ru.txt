Saturnkit — это независимый от конкретной игры набор инструментов для реверс-инжиниринга Sega Saturn и создания нативных PC-портов игр для Saturn. Он предоставляет чистые модули на Python для разбора образов дисков, декодирования и анализа исполняемых файлов SH-2, сопоставления аппаратных регистров, обнаружения функций, сопоставления кода между программами и статической перекомпиляции бинарников SH-2 в C++. Среда выполнения на C++20 эмулирует аппаратуру Saturn, включая оба процессора SH-2, графику VDP1 и VDP2, SCU, SMPC, CD block и звуковую подсистему SCSP с Musashi 68000, и запускает перекомпилированную игру в окне SDL3 и OpenGL с поддержкой геймпада. Набор инструментов предназначен для встраивания в качестве подмодуля в проекты портирования отдельных игр, отделяя общие знания о платформе Saturn от логики, специфичной для каждого тайтла. Он ориентирован на специалистов по реверс-инжинирингу и разработчиков, которые портируют или анализируют игры для Sega Saturn.
