Saturnkit is a game-agnostic toolkit for Sega Saturn reverse engineering and building native PC ports of Saturn games. It provides pure Python modules for parsing disc images, decoding and analyzing SH-2 executables, mapping hardware registers, discovering functions, matching code across programs, and statically recompiling SH-2 binaries to C++. A C++20 runtime emulates the Saturn hardware, including both SH-2 CPUs, VDP1 and VDP2 graphics, the SCU, SMPC, CD block, and SCSP sound subsystem with a Musashi 68000, and runs the recompiled game in an SDL3 and OpenGL window with gamepad support. The toolkit is designed to be embedded as a submodule in per-game port projects, keeping shared Saturn platform knowledge separate from title-specific logic. It is aimed at reverse engineers and developers porting or analyzing Sega Saturn titles.
