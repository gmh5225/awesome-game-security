UAMT（Ultimate Auto Android App Modding Toolkit）是一款基于 Termux 的工具包，可在无需 root 的设备上直接对 Android APK 进行修补、重打包和签名。该工具使用 Python 编写，提供全屏交互式 TUI，用于注入 Frida Gadget 和自定义 native 库，并通过智能自动检测，根据 libil2cpp.so、libunity.so 等目标选择通过 patchelf 进行 native 注入或通过 APKEditor 进行 smali 注入。它可自动完成依赖安装、多 ABI 的 Frida Gadget 下载、zipalign 以及 v1/v2/v3 APK 签名，并包含自动添加缺失 INTERNET 权限等防护措施，以减少常见的 modding 失败。该工具面向 Termux 环境下的 Android APK modding、动态插桩、逆向工程和移动安全研究工作流。
