UAMT（Ultimate Auto Android App Modding Toolkit）是一款基於 Termux 的工具包，可在無需 root 的裝置上直接對 Android APK 進行修補、重打包與簽署。此工具以 Python 撰寫，提供全螢幕互動式 TUI，用於注入 Frida Gadget 與自訂 native 函式庫，並透過智慧自動偵測，依 libil2cpp.so、libunity.so 等目標選擇透過 patchelf 進行 native 注入，或透過 APKEditor 進行 smali 注入。它可自動完成相依套件安裝、多 ABI 的 Frida Gadget 下載、zipalign 以及 v1/v2/v3 APK 簽署，並包含自動新增缺失 INTERNET 權限等防護措施，以減少常見的 modding 失敗。此工具面向 Termux 環境下的 Android APK modding、動態插樁、逆向工程與行動安全研究工作流程。
