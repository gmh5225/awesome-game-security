UAMT（Ultimate Auto Android App Modding Toolkit）は、Termux ベースのツールキットで、root 不要でデバイス上から Android APK のパッチ適用、再ビルド、署名を直接行えます。Python で書かれており、Frida Gadget やカスタムネイティブライブラリの注入用に全画面の対話型 TUI を提供し、libil2cpp.so や libunity.so などのターゲットに応じて、patchelf によるネイティブ注入か APKEditor による smali 注入かを自動検出して選択します。依存関係のセットアップ、マルチ ABI の Frida Gadget ダウンロード、zipalign、v1/v2/v3 APK 署名を自動化し、不足している INTERNET 権限の追加などの安全策により、一般的な modding の失敗を減らします。Termux 上での Android APK modding、動的インストルメンテーション、リバースエンジニアリング、モバイルセキュリティ研究のワークフローを対象としています。
