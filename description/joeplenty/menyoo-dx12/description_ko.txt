Menyoo DX12는 DirectX 12 스왑체인 위에 전체 Menyoo 스타일 인터페이스를 합성하는 순수 Rust 인게임 Mod 메뉴 및 트레이너 오버레이로, 최신 DXGI/D3D12 호스트에서 실행되는 GTA를 대상으로 합니다. 1080p UI용 내장 소프트웨어 래스터라이저, 단일 패스 전체 화면 삼각형 업로드 경로, 플로팅 미리보기 카드, 실시간 Post-FX 스튜디오, 외부 GUI crate 없이 절차적 WinMM 오디오를 제공합니다. 런타임 동작은 외부 Schema v11.0 rvas.json으로 구동되며, 핫 리로드 가능한 RVA, 선택적 x64 콜사이트 후킹, 의상·차량·Spooner 씬의 JSON 영속화를 라이브러리의 하드코딩된 바이너리 오프셋 대신 사용합니다. 이 스택은 Windows 10/11 Mod 개발자, 그래픽 통합 담당자, DXGI 오버레이 주입·트레이너 프레임워크·스키마 기반 클린룸 게임 스크립팅을 연구하는 리버스 엔지니어를 대상으로 합니다.
