Menyoo DX12 是一款纯 Rust 编写的游戏内 Mod 菜单与训练器叠加层，将完整的 Menyoo 风格界面合成到 DirectX 12 交换链上，面向在现代 DXGI/D3D12 环境下运行的 GTA。它内置 1080p UI 的软件光栅化器、单遍全屏三角形上传路径、浮动预览卡片、实时 Post-FX 工作室，以及不依赖外部 GUI crate 的过程式 WinMM 音频。运行时由外部 Schema v11.0 的 rvas.json 驱动，支持可热重载的 RVA、可选的 x64 调用点挂钩，以及服装、载具与 Spooner 场景的 JSON 持久化，而非在库中硬编码二进制偏移。该栈面向 Windows 10/11 的 Mod 开发者、图形集成者与逆向工程师，用于研究 DXGI 叠加注入、训练器框架及基于 schema 的洁净室式游戏脚本。
