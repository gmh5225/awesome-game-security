Menyoo DX12 is a pure Rust in-game mod menu and trainer overlay that composites a full Menyoo-style interface onto a DirectX 12 swapchain, aimed at GTA on modern DXGI/D3D12 hosts. It ships a built-in software rasterizer for 1080p UI, a single-pass fullscreen triangle upload path, floating preview cards, a real-time Post-FX studio, and procedural WinMM audio without external GUI crates. Runtime behavior is driven by an external Schema v11.0 rvas.json with hot-reloadable RVAs, optional x64 callsite hooking, and JSON persistence for outfits, vehicles, and Spooner scenes instead of hardcoded binary offsets in the library. The stack targets Windows 10/11 mod developers, graphics integrators, and reverse engineers who study DXGI overlay injection, trainer frameworks, and cleanroom schema-based game scripting.
