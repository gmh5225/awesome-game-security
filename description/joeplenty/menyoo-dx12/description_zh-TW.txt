Menyoo DX12 是一款純 Rust 撰寫的遊戲內 Mod 選單與訓練器疊加層，將完整的 Menyoo 風格介面合成到 DirectX 12 交換鏈上，面向在現代 DXGI/D3D12 環境下運行的 GTA。它內建 1080p UI 的軟體光柵化器、單遍全螢幕三角形上傳路徑、浮動預覽卡片、即時 Post-FX 工作室，以及不依賴外部 GUI crate 的程序式 WinMM 音訊。執行時由外部 Schema v11.0 的 rvas.json 驅動，支援可熱重載的 RVA、可選的 x64 呼叫點掛鉤，以及服裝、載具與 Spooner 場景的 JSON 持久化，而非在函式庫中硬編碼二進位偏移。此技術棧面向 Windows 10/11 的 Mod 開發者、圖形整合者與逆向工程師，用於研究 DXGI 疊加注入、訓練器框架及以 schema 為基礎的潔淨室式遊戲腳本。
