Menyoo DX12 は、DirectX 12 スワップチェーン上にフル Menyoo スタイルの UI を合成する純 Rust のゲーム内 Mod メニュー兼トレーナーオーバーレイで、最新の DXGI/D3D12 ホスト上の GTA を対象としています。1080p UI 用の組み込みソフトウェアラスタライザ、単一パス全画面トライアングルアップロード経路、フローティングプレビューカード、リアルタイム Post-FX スタジオ、外部 GUI crate に依存しない手続き型 WinMM オーディオを同梱します。実行時は外部 Schema v11.0 の rvas.json により駆動され、ホットリロード可能な RVA、オプションの x64 コールサイトフック、衣装・車両・Spooner シーンの JSON 永続化をライブラリ内のハードコードされたバイナリオフセットの代わりに提供します。本スタックは Windows 10/11 の Mod 開発者、グラフィックス統合担当者、DXGI オーバーレイ注入・トレーナーフレームワーク・クリーンルーム型 schema ベースのゲームスクリプトを研究するリバースエンジニア向けです。
