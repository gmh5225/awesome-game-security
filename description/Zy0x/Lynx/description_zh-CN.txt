Lynx 是一款面向已 root 设备的 Android 配套应用，专注于深度性能与系统调优，主要面向手机游戏负载。Kotlin 客户端与打包的原生守护进程及 shell 自动化配合，可读写内核参数、CPU 与 GPU 调度、联发科 GED 与 FPSGO 等厂商图形栈、温控策略、块设备 I/O 调度器以及用于降低网络延迟的 TCP sysctl 设置。它提供针对 CPU 集群、GPU 芯片、电池、内存、热状态与遥测的丰富仪表盘与仓库，另有带叠加层、录制辅助、连击与自动化功能的悬浮游戏 HUD，并涉及常见游戏引擎与库的调优。面向希望在原厂限制之外获得细粒度控制、且能接受侵入式内核与厂商层改动的进阶用户与手游玩家。
