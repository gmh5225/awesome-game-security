Lynx 是一款針對已 root 裝置的 Android 配套應用程式，專注於深度效能與系統調校，主要面向行動遊戲工作負載。Kotlin 客戶端與封裝的原生常駐程式及 shell 自動化協作，可讀寫核心參數、CPU 與 GPU 排程、聯發科 GED 與 FPSGO 等廠商繪圖堆疊、溫控政策、區塊裝置 I/O 排程器，以及用於降低網路延遲的 TCP sysctl 設定。它提供針對 CPU 叢集、GPU 晶片、電池、記憶體、熱狀態與遙測的豐富儀表板與儲存庫，另有含疊層、錄製輔助、連擊與自動化功能的懸浮遊戲 HUD，並涵蓋常見遊戲引擎與函式庫的調校。面向希望在原廠限制之外取得細緻控制、且能接受侵入式核心與廠商層變更的進階使用者與手遊玩家。
