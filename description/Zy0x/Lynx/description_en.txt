Lynx is an Android companion application for deep performance and system tuning on rooted devices, focused on mobile gaming workloads. The Kotlin client works with a packaged native daemon and shell automation that read and write kernel knobs, CPU and GPU scheduling, vendor graphics stacks such as MediaTek GED and FPSGO, thermal policy, block I/O schedulers, and TCP sysctl settings for lower network latency. It offers rich dashboards and repositories for CPU clusters, GPU silicon, battery, memory, thermal state, and telemetry, plus a floating game HUD with overlays, recording helpers, combo and automation features, and touches on tuning for common game engines and libraries. It is intended for advanced users and mobile gamers who want granular control beyond stock OEM limits and who are comfortable applying invasive kernel- and vendor-level changes.
