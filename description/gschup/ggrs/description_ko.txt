GGRS(Good Game Rollback System)는 온라인 멀티플레이어 게임을 위한 GGPO 스타일의 P2P 롤백 네트워킹을 재구현한 Rust 라이브러리입니다. safe Rust로만 작성되었으며, 기존 콜백 기반 API를 라이브러리가 save, load, advance 작업을 반환하고 게임이 이를 수행하는 더 단순한 요청 기반 제어 흐름으로 대체합니다. P2P 및 관전 세션, 구성 가능한 입력 예측과 lockstep 모드, 선택적 사용자 정의 소켓을 지원하는 UDP 전송, 결정론적 시뮬레이션을 검증하는 내장 SyncTestSession 및 체크섬 기반 디싱크 감지를 제공합니다. 낮은 지연 시간의 netcode가 필요하고 클라이언트 간 게임 로직 동기화를 확인하려는 게임 개발자를 대상으로 하며, 공정한 온라인 플레이와 치트에 강한 네트워크 시뮬레이션에 필수적입니다.
