GGRS（Good Game Rollback System）是一個 Rust 函式庫，為線上多人遊戲重新實作了 GGPO 風格的點對點回滾網路。它完全以 safe Rust 撰寫，將原有的回呼驅動 API 替換為更簡潔的請求式控制流程，由函式庫回傳 save、load 與 advance 操作供遊戲執行。此函式庫支援 P2P 與觀戰連線、可設定的輸入預測與 lockstep 模式、UDP 傳輸及可選的自訂通訊端，並內建 SyncTestSession 與基於校驗和的不同步偵測，用於驗證確定性模擬。它面向需要低延遲網路程式碼、並希望確認遊戲邏輯在客戶端之間保持同步的開發者，這對公平的線上對戰與抗作弊的網路模擬至關重要。
