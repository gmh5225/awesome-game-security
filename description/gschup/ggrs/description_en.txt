GGRS (Good Game Rollback System) is a Rust library that reimplements GGPO-style peer-to-peer rollback networking for online multiplayer games. Written entirely in safe Rust, it replaces the original callback-driven API with a simpler request-based control flow where the library returns save, load, and advance operations for the game to fulfill. It supports P2P and spectator sessions, configurable input prediction and lockstep modes, UDP transport with optional custom sockets, and built-in SyncTestSession and checksum-based desync detection to validate deterministic simulation. The library targets game developers who need low-latency netcode and want to verify that game logic stays synchronized across clients, which is essential for fair online play and cheat-resistant networked simulations.
