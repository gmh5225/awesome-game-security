GGRS（Good Game Rollback System）是一个 Rust 库，为在线多人游戏重新实现了 GGPO 风格的点对点回滚网络。它完全使用 safe Rust 编写，将原有的回调驱动 API 替换为更简洁的基于请求的控制流，由库返回 save、load 和 advance 操作供游戏执行。该库支持 P2P 与观战会话、可配置的输入预测与 lockstep 模式、UDP 传输及可选的自定义套接字，并内置 SyncTestSession 与基于校验和的不同步检测，用于验证确定性模拟。它面向需要低延迟网络代码、并希望确认游戏逻辑在客户端之间保持同步的开发者，这对公平在线对战和抗作弊的网络模拟至关重要。
