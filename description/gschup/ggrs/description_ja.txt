GGRS（Good Game Rollback System）は、オンライン対戦ゲーム向けに GGPO スタイルのピアツーピア・ロールバック・ネットワークを再実装した Rust ライブラリです。safe Rust のみで書かれており、従来のコールバック駆動 API を、ライブラリが save・load・advance 操作を返しゲーム側が実行する、よりシンプルなリクエストベースの制御フローに置き換えます。P2P および観戦セッション、設定可能な入力予測と lockstep モード、カスタムソケット対応の UDP トランスポート、決定論的シミュレーションを検証する SyncTestSession とチェックサムによるデシンク検出を内蔵しています。低レイテンシの netcode を必要とし、クライアント間でゲームロジックが同期し続けることを確認したいゲーム開発者向けで、公平なオンライン対戦とチート耐性のあるネットワークシミュレーションに不可欠です。
