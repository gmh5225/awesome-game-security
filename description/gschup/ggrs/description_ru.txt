GGRS (Good Game Rollback System) — библиотека на Rust, реализующая одноранговую сеть с откатом в стиле GGPO для онлайн-мультиплеерных игр. Написанная полностью на safe Rust, она заменяет исходный API на основе обратных вызовов более простым потоком управления на запросах: библиотека возвращает операции save, load и advance, которые выполняет игра. Поддерживаются P2P- и зрительские сессии, настраиваемое предсказание ввода и режимы lockstep, транспорт UDP с необязательными пользовательскими сокетами, а также встроенные SyncTestSession и обнаружение рассинхронизации по контрольным суммам для проверки детерминированной симуляции. Библиотека предназначена для разработчиков игр, которым нужен netcode с низкой задержкой и которые хотят убедиться, что игровая логика остаётся синхронизированной между клиентами — это важно для честной онлайн-игры и устойчивых к читам сетевых симуляций.
