r2SMT is a Rust toolkit that integrates radare2 with SMT solvers to analyze conditional branches in compiled binaries and identify obfuscation such as opaque predicates, dead branches, and constant conditions. It lifts disassembly through a typed intermediate representation, backward slicing, and SSA form before querying Z3, CVC5, or Bitwuzla for sound, fail-closed verdicts on whether each branch can truly be taken both ways. The tool supports x86, x86_64, AArch64, and AArch32 (including Thumb), cross-checks multiple lifting paths via differential equivalence checking, and can annotate radare2 sessions or apply reversible byte patches with rollback manifests. Batch mode enables directory-wide sweeps with JSON and Markdown reporting. It is aimed at reverse engineers and security researchers deobfuscating protected or tamper-resistant binaries, including game anti-cheat and malware analysis workflows.
