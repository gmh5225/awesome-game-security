r2SMT は、radare2 と SMT ソルバーを統合した Rust 製ツールキットで、コンパイル済みバイナリ内の条件分岐を解析し、不透明述語、デッド分岐、定数条件などの難読化を特定します。型付き中間表現、後方スライシング、SSA 形式によるリフトを経て、Z3、CVC5、Bitwuzla に問い合わせ、各分岐が本当に双方向に実行可能かどうかについて、健全かつ失敗時に安全側に倒れる判定を行います。x86、x86_64、AArch64、AArch32（Thumb を含む）をサポートし、差分等価性チェックで複数のリフト経路を相互検証でき、radare2 セッションへ注釈を付けるか、ロールバック用マニフェスト付きの可逆バイトパッチを適用できます。バッチモードではディレクトリ全体のスイープと JSON および Markdown レポートが可能です。保護されたバイナリや改ざん耐性バイナリの難読化解除、ゲームアンチチートやマルウェア解析のワークフローを行うリバースエンジニアやセキュリティ研究者向けです。
