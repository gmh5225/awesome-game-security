r2SMT는 radare2와 SMT 솔버를 통합한 Rust 툴킷으로, 컴파일된 바이너리의 조건 분기를 분석하고 불투명 술어, 데드 분기, 상수 조건 같은 난독화를 식별합니다. 타입이 지정된 중간 표현, 역방향 슬라이싱, SSA 형태를 통해 디스어셈블리를 리프팅한 뒤 Z3, CVC5, Bitwuzla에 질의하여 각 분기가 실제로 양방향으로 실행될 수 있는지에 대해 신뢰할 수 있고 실패 시 안전하게 닫히는 판정을 제공합니다. x86, x86_64, AArch64, AArch32(Thumb 포함)를 지원하며, 차분 등가성 검사로 여러 리프팅 경로를 교차 검증하고 radare2 세션에 주석을 달거나 롤백 매니페스트와 함께 가역 바이트 패치를 적용할 수 있습니다. 배치 모드에서는 디렉터리 전체 스윕과 JSON 및 Markdown 보고가 가능합니다. 보호되거나 변조 방지 기능이 있는 바이너리의 난독화 해제, 게임 안티치트 및 멀웨어 분석 워크플로를 수행하는 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
