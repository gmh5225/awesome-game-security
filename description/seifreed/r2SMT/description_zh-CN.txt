r2SMT 是一个 Rust 工具包，将 radare2 与 SMT 求解器集成，用于分析已编译二进制文件中的条件分支并识别混淆，例如不透明谓词、死分支和常量条件。它通过类型化中间表示、后向切片和 SSA 形式提升反汇编，再向 Z3、CVC5 或 Bitwuzla 查询，对每个分支是否真正可以双向执行给出可靠、失败即关闭的判定。该工具支持 x86、x86_64、AArch64 和 AArch32（含 Thumb），通过差分等价性检查交叉验证多种提升路径，并可标注 radare2 会话或应用可逆字节补丁及回滚清单。批处理模式支持对整个目录进行扫描，并生成 JSON 和 Markdown 报告。它面向逆向工程师和安全研究人员，用于去混淆受保护或防篡改的二进制文件，包括游戏反作弊和恶意软件分析工作流。
