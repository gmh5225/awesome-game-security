r2SMT 是一個 Rust 工具包，將 radare2 與 SMT 求解器整合，用於分析已編譯二進位檔中的條件分支並識別混淆，例如不透明謂詞、死分支和常數條件。它透過型別化中介表示、後向切片和 SSA 形式提升反組譯，再向 Z3、CVC5 或 Bitwuzla 查詢，對每個分支是否真正可以雙向執行給出可靠、失敗即關閉的判定。此工具支援 x86、x86_64、AArch64 和 AArch32（含 Thumb），透過差分等價性檢查交叉驗證多種提升路徑，並可標註 radare2 工作階段或套用可逆位元組修補及回滾清單。批次模式支援對整個目錄進行掃描，並產生 JSON 和 Markdown 報告。它面向逆向工程師和安全研究人員，用於去混淆受保護或防竄改的二進位檔，包括遊戲反作弊和惡意軟體分析工作流程。
