XrefGen — это плагин для IDA Pro, который генерирует перекрёстные ссылки и косвенные ссылки на поток управления с высокой достоверностью, которые стандартный анализ IDA может пропустить, и предназначен для расширения рабочих процессов Mandiant XRefer. Написанный на Python, он использует модульные анализаторы для отслеживания taint в потоке данных, анализа графа вызовов, обнаружения обфускации, включая выравнивание потока управления и непрозрачные предикаты, а также разрешения регистров между архитектурами x86, x64, ARM, ARM64, MIPS и экспериментальным WebAssembly. Он экспортирует проверенные кандидаты потока управления в формате, совместимом с XRefer, с оценкой достоверности, отслеживанием доказательств и инкрементальным повторным анализом с кэшированием. Инструмент предназначен для специалистов по обратной разработке и исследователей вредоносного ПО, анализирующих современные компилируемые языки, упакованные бинарные файлы и сильно обфусцированный код, актуальный для безопасности игр и исследований античит-систем.
