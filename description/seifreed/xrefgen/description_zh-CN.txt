XrefGen 是一款 IDA Pro 插件，可生成高置信度的交叉引用和间接控制流引用，弥补标准 IDA 分析可能遗漏的内容，旨在扩展 Mandiant XRefer 工作流。该工具使用 Python 编写，采用模块化分析器，支持数据流污点跟踪、调用图分析、混淆检测（包括控制流平坦化和不透明谓词），以及跨 x86、x64、ARM、ARM64、MIPS 和实验性 WebAssembly 的寄存器解析。它以 XRefer 兼容格式导出经过验证的控制流候选，并提供置信度评分、证据追踪和增量缓存重分析。该工具面向逆向工程师和恶意软件研究人员，用于分析现代编译语言、加壳二进制文件和高度混淆的代码，适用于游戏安全与反作弊研究。
