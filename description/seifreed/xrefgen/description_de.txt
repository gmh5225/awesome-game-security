XrefGen ist ein IDA-Pro-Plugin, das hochvertrauenswürdige Cross-References und indirekte Kontrollfluss-Referenzen erzeugt, die die Standard-IDA-Analyse möglicherweise übersieht, und Mandiant-XRefer-Workflows erweitern soll. In Python geschrieben, nutzt es modulare Analysatoren für Data-Flow-Taint-Tracking, Call-Graph-Analyse, Obfuskationserkennung einschließlich Control-Flow-Flattening und undurchsichtiger Prädikate sowie registerübergreifende Auflösung über x86, x64, ARM, ARM64, MIPS und experimentelles WebAssembly. Es exportiert validierte Kontrollfluss-Kandidaten im XRefer-kompatiblen Format mit Konfidenzbewertung, Nachverfolgung von Belegen und inkrementeller Zwischenspeicher-Neuanalyse. Das Tool richtet sich an Reverse Engineers und Malware-Forscher, die moderne kompilierte Sprachen, gepackte Binaries und stark verschleierte Code analysieren, relevant für Game Security und Anti-Cheat-Forschung.
