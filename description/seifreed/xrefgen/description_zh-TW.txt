XrefGen 是一款 IDA Pro 外掛，可產生高置信度的交叉參考與間接控制流參考，補足標準 IDA 分析可能遺漏的內容，旨在擴展 Mandiant XRefer 工作流程。此工具以 Python 撰寫，採用模組化分析器，支援資料流污点追蹤、呼叫圖分析、混淆偵測（包含控制流平坦化與不透明述詞），以及跨 x86、x64、ARM、ARM64、MIPS 與實驗性 WebAssembly 的暫存器解析。它以 XRefer 相容格式匯出經驗證的控制流候選，並提供置信度評分、證據追蹤與增量快取重分析。此工具面向逆向工程師與惡意軟體研究人員，用於分析現代編譯語言、加殼二進位檔與高度混淆的程式碼，適用於遊戲安全與反作弊研究。
