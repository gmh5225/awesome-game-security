GoldSrc 및 WON 시대 Half-Life 기간의 Valve Anti-Cheat 1(VAC1) 보안 모듈을 역공학으로 재구성한 프로젝트로, 클라이언트 ModuleC와 서버 ModuleS 구성 요소를 다룹니다. 이 프로젝트는 경량 네이티브 DLL이 샌드박스화된 바이트코드 가상 머신으로 동작하며, 치트 스캐너를 직접 내장하는 대신 네트워크를 통해 탐지 프로그램을 수신하는 원래 아키텍처를 문서화하고 재구현합니다. 모듈 프레임워크와 VM 인터프리터용 C++ 소스, 전송 중인 VAC 컨테이너를 복호화·재구성·재패킹하는 Python 유틸리티, blob 암호화, 엔진 콜백 인터페이스, 메모리 무결성 검사, 서버 측 UDP 네트워크 계층에 대한 상세한 메모가 포함됩니다. Visual Studio 6 프로젝트 파일을 통해 원본 고정 베이스 PE 레이아웃과 일치하는 바이너리를 빌드할 수 있습니다. 이 작업은 초기 상용 안티치트 설계와 GoldSrc 엔진 보호를 연구하는 게임 보안 연구자 및 리버스 엔지니어를 대상으로 합니다.
