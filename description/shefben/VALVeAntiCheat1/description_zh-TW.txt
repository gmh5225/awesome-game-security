這是對 GoldSrc 與 WON 時代《半衰期》時期 Valve Anti-Cheat 1（VAC1）安全模組的逆向工程重建，涵蓋用戶端 ModuleC 與伺服器端 ModuleS 元件。該專案記錄並重新實作了原始架構：輕量級原生 DLL 充當沙箱化位元組碼虛擬機器，透過網路接收偵測程式，而非直接嵌入作弊掃描器。專案包含模組框架與 VM 直譯器的 C++ 原始碼、用於解密、重建和重新封裝線上 VAC 容器的 Python 工具，以及關於 blob 加密、引擎回呼介面、記憶體完整性檢查和伺服器端 UDP 網路層的詳盡說明。Visual Studio 6 專案檔可用於建置與原始固定基址 PE 配置相符的二進位檔。此工作面向研究早期商業反作弊設計與 GoldSrc 引擎保護的遊戲安全研究人員和逆向工程師。
