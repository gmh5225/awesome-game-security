A reverse-engineered reconstruction of Valve Anti-Cheat 1 (VAC1) security modules from the GoldSrc and WON-era Half-Life period, covering the client ModuleC and server ModuleS components. The project documents and reimplements the original architecture in which thin native DLLs act as sandboxed bytecode virtual machines that receive detection programs over the network rather than embedding cheat scanners directly. It includes C++ source for the module framework and VM interpreter, Python utilities to decrypt, rebuild, and repack on-the-wire VAC containers, and extensive notes on blob encryption, engine callback interfaces, memory integrity checks, and the server-side UDP network layer. Visual Studio 6 project files allow building binaries that match the original fixed-base PE layout. The work is aimed at game security researchers and reverse engineers studying early commercial anti-cheat design and GoldSrc engine protection.
