这是对 GoldSrc 与 WON 时代《半条命》时期 Valve Anti-Cheat 1（VAC1）安全模块的逆向工程重建，涵盖客户端 ModuleC 与服务器端 ModuleS 组件。该项目记录并重新实现了原始架构：轻量级原生 DLL 充当沙箱化字节码虚拟机，通过网络接收检测程序，而非直接嵌入作弊扫描器。项目包含模块框架与 VM 解释器的 C++ 源码、用于解密、重建和重新打包在线 VAC 容器的 Python 工具，以及关于 blob 加密、引擎回调接口、内存完整性检查和服务器端 UDP 网络层的详尽说明。Visual Studio 6 项目文件可用于构建与原始固定基址 PE 布局匹配的二进制文件。该工作面向研究早期商业反作弊设计与 GoldSrc 引擎保护的游戏安全研究人员和逆向工程师。
