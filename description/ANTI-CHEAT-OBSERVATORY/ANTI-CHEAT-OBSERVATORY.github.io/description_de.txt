Anti-Cheat Observatory ist eine statische Referenzseite, die kommerzielle Anti-Cheat-Systeme und die öffentliche Forschung dazu mit versionsbezogenen, quellenbelegten Aussagen katalogisiert – statt informeller Artikel oder Bypass-Schlagzeilen. Sie ist mit Astro und TypeScript gebaut, speichert kuratiertes Wissen in Git-gestütztem JSON mit Schema-Validierung und veröffentlicht eine durchsuchbare statische Site mit Pagefind auf GitHub Pages. Das Projekt strukturiert System-Dossiers, Mechanismus-Arbeitsblätter, Build-Vergleiche, Beziehungsgraphen und eine Discovery-Pipeline, die genehmigte RSS-, GitHub- und Dokumentenquellen abfragt und dabei Herkunft, Review-Aktivität und Claim-Status getrennt hält. Node.js-Wartungsskripte validieren Querverweise, importieren redaktionelle Vorschläge und synchronisieren Metadaten, ohne ungeprüfte Feeds als verifizierte Befunde zu behandeln. Zielgruppe sind Game-Security-Forscher, Anti-Cheat-Analysten und Reverse Engineers, die eine evidenzorientierte Landkarte von Produkten wie BattlEye, Easy Anti-Cheat, Vanguard und zugehörigen Kernel- und Client-Grenzen benötigen.
