Anti-Cheat Observatory is a static reference site that catalogs commercial anti-cheat systems and the public research about them using version-scoped, source-backed claims rather than informal articles or bypass headlines. It is built with Astro and TypeScript, stores curated knowledge in Git-backed JSON with schema validation, and publishes as a searchable static site with Pagefind on GitHub Pages. The project organizes system dossiers, mechanism worksheets, build comparisons, relationship graphs, and a discovery pipeline that polls approved RSS, GitHub, and document sources while keeping provenance, review activity, and claim state separate. Node.js maintenance scripts validate cross-references, import editorial proposals, and sync metadata without treating unreviewed feeds as verified findings. It targets game security researchers, anti-cheat analysts, and reverse engineers who need an evidence-oriented map of products such as BattlEye, Easy Anti-Cheat, Vanguard, and related kernel and client boundaries.
