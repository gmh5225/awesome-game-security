Anti-Cheat Observatory es un sitio de referencia estático que cataloga sistemas anti-trampas comerciales y la investigación pública sobre ellos mediante afirmaciones acotadas por versión y respaldadas por fuentes, en lugar de artículos informales o titulares de bypass. Está construido con Astro y TypeScript, almacena conocimiento curado en JSON respaldado por Git con validación de esquema y publica un sitio estático buscable con Pagefind en GitHub Pages. El proyecto organiza dossiers de sistemas, hojas de mecanismos, comparaciones de builds, grafos de relaciones y una canalización de descubrimiento que consulta fuentes RSS, GitHub y documentales aprobadas, manteniendo separados la procedencia, la actividad de revisión y el estado de las afirmaciones. Scripts de mantenimiento en Node.js validan referencias cruzadas, importan propuestas editoriales y sincronizan metadatos sin tratar feeds no revisados como hallazgos verificados. Está dirigido a investigadores de seguridad en juegos, analistas anti-trampas e ingenieros inversos que necesitan un mapa orientado a evidencias de productos como BattlEye, Easy Anti-Cheat, Vanguard y los límites de kernel y cliente relacionados.
