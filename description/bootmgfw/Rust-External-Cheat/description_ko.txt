이 프로젝트는 Rust 서바이벌 게임용 C++ 외부 치트로, 클라이언트 외부에서 프로세스 메모리를 읽고 투명 오버레이 창을 통해 기능을 렌더링합니다. 이 솔루션은 IOCTL을 통한 크로스 프로세스 메모리 읽기·쓰기·할당 및 모듈 베이스 주소 조회를 수행하는 Windows 커널 모드 WDM 드라이버와 Rust SDK, 엔티티 업데이트 루프, 게임 오프셋 처리를 구현한 사용자 모드 DLL을 함께 사용합니다. ESP 및 시각적 그리기, 에임봇 로직, DirectX 9와 Win32 기반 Dear ImGui 메뉴, DirectXMath 월드-투-스크린 변환 헬퍼, 소켓 기반 통신을 포함하며, 탐지 회피를 목표로 한 드라이버 흔적 정리 및 커널 후킹 기법도 제공합니다. Rust 및 유사 Unity 타이틀에 대한 외부 치트 아키텍처, 커널 지원 메모리 접근, 안티치트 회피를 연구하는 게임 보안 연구자 및 리버스 엔지니어를 대상으로 합니다.
