這是一個針對 Rust 生存遊戲的 C++ 外部作弊程式，從用戶端外部讀取程序記憶體，並透過透明疊加視窗渲染各項功能。此方案將 Windows 核心模式 WDM 驅動程式（透過 IOCTL 實現跨程序記憶體讀寫、配置及模組基底位址查詢）與使用者模式 DLL（實現 Rust SDK、實體更新迴圈及遊戲偏移處理）相結合。功能包含 ESP 與視覺繪製、自瞄邏輯、以 DirectX 9 和 Win32 為基礎的 Dear ImGui 選單、DirectXMath 世界座標到螢幕座標轉換輔助，以及基於通訊端子的通訊，同時還包含驅動程式痕跡清理和核心 Hook 等旨在規避偵測的技術。本專案面向研究外部作弊架構、核心輔助記憶體存取，以及針對 Rust 及類似 Unity 遊戲的反作弊規避的遊戲安全研究人員和逆向工程師。
