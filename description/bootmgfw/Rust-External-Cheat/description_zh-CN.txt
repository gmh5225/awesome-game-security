这是一个针对 Rust 生存游戏的 C++ 外部作弊程序，从客户端外部读取进程内存，并通过透明叠加窗口渲染各项功能。该方案将 Windows 内核模式 WDM 驱动（通过 IOCTL 实现跨进程内存读写、分配及模块基址查询）与用户态 DLL（实现 Rust SDK、实体更新循环及游戏偏移处理）相结合。功能包括 ESP 与视觉绘制、自瞄逻辑、基于 DirectX 9 和 Win32 的 Dear ImGui 菜单、DirectXMath 世界坐标到屏幕坐标转换辅助，以及基于套接字的通信，同时还包含驱动痕迹清理和内核 Hook 等旨在规避检测的技术。本项目面向研究外部作弊架构、内核辅助内存访问，以及针对 Rust 及类似 Unity 游戏的反作弊规避的游戏安全研究人员和逆向工程师。
