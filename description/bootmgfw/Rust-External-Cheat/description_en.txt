This is a C++ external cheat for the Rust survival game that reads process memory from outside the client and renders features through a transparent overlay window. The solution pairs a Windows kernel-mode WDM driver for cross-process memory read, write, allocation, and module-base queries via IOCTLs with a user-mode DLL that implements a Rust SDK, entity update loops, and game offset handling. It includes ESP and visual drawing, aimbot logic, a Dear ImGui menu backed by DirectX 9 and Win32, DirectXMath world-to-screen helpers, and socket-based communication, along with driver trace cleanup and kernel hooking techniques aimed at evading detection. It is intended for game security researchers and reverse engineers studying external cheat architecture, kernel-assisted memory access, and anti-cheat evasion against Rust and similar Unity titles.
