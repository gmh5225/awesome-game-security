Это внешний чит на C++ для survival-игры Rust, который читает память процессов извне клиента и отображает функции через прозрачное оверлейное окно. Решение сочетает драйвер WDM в режиме ядра Windows для межпроцессного чтения, записи, выделения памяти и запросов баз модулей через IOCTL с пользовательской DLL, реализующей Rust SDK, циклы обновления сущностей и обработку игровых смещений. Включает ESP и визуальную отрисовку, логику аимбота, меню Dear ImGui на базе DirectX 9 и Win32, вспомогательные функции DirectXMath для преобразования world-to-screen и сокетную коммуникацию, а также техники очистки следов драйвера и перехвата в ядре, направленные на обход обнаружения. Предназначен для исследователей игровой безопасности и реверс-инженеров, изучающих архитектуру внешних читов, доступ к памяти с помощью ядра и обход античита в Rust и аналогичных играх на Unity.
