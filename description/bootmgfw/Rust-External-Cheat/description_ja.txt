これは Rust サバイバルゲーム向けの C++ 外部チートで、クライアント外からプロセスメモリを読み取り、透明オーバーレイウィンドウを通じて各種機能を描画します。本ソリューションは、IOCTL によるクロスプロセスのメモリ読み書き・割り当て・モジュールベースアドレス取得を行う Windows カーネルモード WDM ドライバと、Rust SDK、エンティティ更新ループ、ゲームオフセット処理を実装したユーザーモード DLL を組み合わせています。ESP とビジュアル描画、エイムボットロジック、DirectX 9 と Win32 を基盤とした Dear ImGui メニュー、DirectXMath によるワールド座標からスクリーン座標への変換ヘルパー、ソケットベースの通信に加え、検出回避を目的としたドライバトレースのクリーンアップやカーネルフック手法も含まれます。Rust や類似の Unity タイトルに対する外部チートアーキテクチャ、カーネル支援メモリアクセス、反チート回避を研究するゲームセキュリティ研究者およびリバースエンジニア向けです。
