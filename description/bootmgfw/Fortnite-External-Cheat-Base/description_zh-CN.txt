这是一个用于构建 Fortnite 外部作弊程序的 C++ 入门模板，可在进程外读取游戏内存，并在游戏窗口上方渲染叠加层。它通过 IOCTL 与内核驱动通信，以执行物理内存读写、解析进程基址、绕过 Easy Anti-Cheat 使用的 CR3 保护，并注入合成鼠标输入。代码库包含 Unreal Engine SDK 辅助工具（含偏移定义）、加密的 UWorld 指针解码、玩家与实体缓存、基于骨骼的世界坐标到屏幕坐标转换，以及通过 ImGui 与 DirectX 11 叠加层实现的 ESP 渲染（带可见性着色的 2D 边界框）。在附加到 FortniteClient-Win64-Shipping.exe 后，窗口劫持与可配置菜单驱动主渲染循环。该项目面向研究外部作弊架构、内核辅助内存访问及反作弊规避技术的游戏安全研究人员与逆向工程师。
