これは Fortnite 向けの外部チートを構築するための C++ スターターテンプレートで、プロセス外からゲームメモリを読み取り、ゲームウィンドウ上にオーバーレイを描画します。IOCTL 経由でカーネルドライバーと通信し、物理メモリの読み書き、プロセスのベースアドレス解決、Easy Anti-Cheat が使用する CR3 保護の回避、合成マウス入力の注入を行います。コードベースには Unreal Engine SDK ヘルパー（オフセット定義付き）、暗号化された UWorld ポインタのデコード、プレイヤーとエンティティのキャッシュ、ボーンベースのワールド座標からスクリーン座標への変換、ImGui と DirectX 11 オーバーレイによる可視性に応じた色分け 2D バウンディングボックス付き ESP レンダリングが含まれます。FortniteClient-Win64-Shipping.exe にアタッチした後、ウィンドウハイジャックと設定可能なメニューがメインレンダーループを駆動します。外部チートアーキテクチャ、カーネル支援メモリアクセス、反チート回避手法を研究するゲームセキュリティ研究者およびリバースエンジニア向けです。
