Это стартовый шаблон на C++ для создания внешнего чита для Fortnite, который читает память игры извне процесса и отображает оверлей поверх игрового окна. Он взаимодействует с драйвером ядра через IOCTL для выполнения чтения и записи физической памяти, определения базовых адресов процессов, обхода защиты CR3, используемой Easy Anti-Cheat, и внедрения синтетического ввода мыши. Кодовая база включает вспомогательные средства Unreal Engine SDK с определениями смещений, декодирование зашифрованного указателя UWorld, кэширование игроков и сущностей, преобразование world-to-screen на основе костей, а также ESP-рендеринг с 2D ограничивающими рамками, окрашенными по видимости, через оверлей ImGui и DirectX 11. Перехват окна и настраиваемое меню управляют основным циклом рендеринга после подключения к FortniteClient-Win64-Shipping.exe. Предназначен для исследователей игровой безопасности и reverse-инженеров, изучающих архитектуру внешних читов, доступ к памяти с помощью ядра и методы обхода античита.
