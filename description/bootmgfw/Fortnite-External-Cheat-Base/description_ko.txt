이 프로젝트는 Fortnite용 외부 치트를 구축하기 위한 C++ 스타터 템플릿으로, 프로세스 외부에서 게임 메모리를 읽고 게임 창 위에 오버레이를 렌더링합니다. IOCTL을 통해 커널 드라이버와 통신하여 물리 메모리 읽기/쓰기, 프로세스 기본 주소 해석, Easy Anti-Cheat가 사용하는 CR3 보호 우회, 합성 마우스 입력 주입을 수행합니다. 코드베이스에는 Unreal Engine SDK 헬퍼(오프셋 정의 포함), 암호화된 UWorld 포인터 디코딩, 플레이어 및 엔티티 캐싱, 본 기반 월드-투-스크린 변환, ImGui 및 DirectX 11 오버레이를 통한 가시성 색상 2D 바운딩 박스 ESP 렌더링이 포함됩니다. FortniteClient-Win64-Shipping.exe에 연결한 후 창 하이재킹과 구성 가능한 메뉴가 메인 렌더 루프를 구동합니다. 외부 치트 아키텍처, 커널 지원 메모리 접근, 안티치트 회피 기법을 연구하는 게임 보안 연구자 및 리버스 엔지니어를 대상으로 합니다.
