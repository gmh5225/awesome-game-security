這是一個用於建構 Fortnite 外部作弊程式的 C++ 入門範本，可在程序外讀取遊戲記憶體，並在遊戲視窗上方渲染疊加層。它透過 IOCTL 與核心驅動程式通訊，以執行實體記憶體讀寫、解析程序基底位址、繞過 Easy Anti-Cheat 使用的 CR3 保護，並注入合成滑鼠輸入。程式碼庫包含 Unreal Engine SDK 輔助工具（含偏移定義）、加密的 UWorld 指標解碼、玩家與實體快取、基於骨骼的世界座標到螢幕座標轉換，以及透過 ImGui 與 DirectX 11 疊加層實現的 ESP 渲染（含可見性著色的 2D 邊界框）。在附加到 FortniteClient-Win64-Shipping.exe 後，視窗劫持與可設定選單驅動主渲染迴圈。本專案面向研究外部作弊架構、核心輔助記憶體存取及反作弊規避技術的遊戲安全研究人員與逆向工程師。
