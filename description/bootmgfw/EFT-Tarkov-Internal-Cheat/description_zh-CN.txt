这是一个面向《逃离塔科夫》的 C++ 内部作弊源码，以 Windows DLL 形式注入，并在进程内挂钩 Unity/Mono 游戏客户端。它围绕 Unity 引擎类型、Mono 运行时钩子、特征码扫描和直接系统调用构建模块化 SDK，并通过 Kiero 与 MinHook 使用 DirectX 11 配合 Dear ImGui 渲染游戏内菜单与叠加层。功能模块包括可配置的 ESP（玩家、Scav、Boss、战利品、撤离点、容器、尸体）、带静默瞄准与骨骼瞄准的 aimbot、武器与移动修改器、雷达，以及基于 JSON 的配置。面向研究内部作弊架构、Unity/Mono 挂钩与反作弊规避技术的游戏安全研究人员和逆向工程师。
