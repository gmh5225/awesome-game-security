Escape From Tarkov 向けの C++ 内部チートソースで、Windows DLL として注入し、プロセス内から Unity/Mono ゲームクライアントをフックします。Unity エンジン型、Mono ランタイムフック、パターンスキャン、直接システムコールを中心にモジュラー SDK を構築し、Kiero と MinHook 経由で DirectX 11 上の Dear ImGui によりゲーム内メニューとオーバーレイを描画します。機能モジュールには、プレイヤー、Scav、ボス、ルート、脱出地点、コンテナ、死体向けの設定可能な ESP、サイレントエイムとボーンターゲティング付き aimbot、武器・移動モディファイア、レーダー、JSON ベースの設定が含まれます。内部チートアーキテクチャ、Unity/Mono フック、反チート回避手法を研究するゲームセキュリティ研究者およびリバースエンジニア向けです。
