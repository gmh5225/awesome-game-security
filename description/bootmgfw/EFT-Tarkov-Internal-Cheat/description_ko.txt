Escape From Tarkov용 C++ 내부 치트 소스로, Windows DLL로 주입되어 프로세스 내부에서 Unity/Mono 게임 클라이언트를 후킹합니다. Unity 엔진 타입, Mono 런타임 후크, 패턴 스캐닝, 직접 시스템 호출을 중심으로 모듈형 SDK를 구축하며, Kiero와 MinHook을 통해 DirectX 11에서 Dear ImGui로 인게임 메뉴와 오버레이를 렌더링합니다. 기능 모듈에는 플레이어, Scav, 보스, 전리품, 탈출 지점, 컨테이너, 시체에 대한 설정 가능한 ESP, 사일런트 에임과 본 타겟팅이 포함된 aimbot, 무기 및 이동 수정자, 레이더, JSON 기반 설정이 포함됩니다. 내부 치트 아키텍처, Unity/Mono 후킹, 안티치트 회피 기법을 연구하는 게임 보안 연구자 및 리버스 엔지니어를 대상으로 합니다.
