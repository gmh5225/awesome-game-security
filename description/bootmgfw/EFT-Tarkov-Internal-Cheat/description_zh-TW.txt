這是一個面向《逃離塔科夫》的 C++ 內部作弊原始碼，以 Windows DLL 形式注入，並在行程內掛鉤 Unity/Mono 遊戲用戶端。它圍繞 Unity 引擎類型、Mono 執行階段鉤子、特徵碼掃描與直接系統呼叫建構模組化 SDK，並透過 Kiero 與 MinHook 使用 DirectX 11 配合 Dear ImGui 渲染遊戲內選單與疊加層。功能模組包括可設定的 ESP（玩家、Scav、Boss、戰利品、撤離點、容器、屍體）、含靜默瞄準與骨骼瞄準的 aimbot、武器與移動修改器、雷達，以及以 JSON 為後端的設定。面向研究內部作弊架構、Unity/Mono 掛鉤與反作弊規避技術的遊戲安全研究人員與逆向工程師。
