VEX — это внешний чит с открытым исходным кодом для Valorant, реализованный в виде модульного приложения Windows на C++20 под названием VEX. Он считывает состояние игры Unreal Engine 5 извне процесса через абстракцию драйвера ядра, поддерживающую межпроцессный доступ к памяти, поиск паттернов и ввод мыши, в сочетании с SDK для UWorld, акторов, костей и данных камеры. Функциональные модули включают aimbot с привязкой к костям и выбором FOV, triggerbot, помощники по расстановке способностей и оверлейный GUI на DirectX 11, построенный с ImGui, а выделенная система VGK обрабатывает специфичные для Valorant смещения и зашифрованные игровые данные. Архитектура разделяет жизненный цикл приложения, драйвер, рендеринг и игровую логику за инъекцируемыми интерфейсами, а релизные сборки добавляют обфускацию на основе LLVM. В первую очередь полезен для исследований безопасности игр, анализа античитов и изучения проектирования внешних читов против игр, защищённых Vanguard.
