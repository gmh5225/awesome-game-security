VEX는 Valorant용 오픈 소스 외부 치트로, VEX라는 이름의 모듈형 C++20 Windows 애플리케이션으로 구현되었습니다. 크로스 프로세스 메모리 액세스, 패턴 스캔, 마우스 입력을 지원하는 커널 드라이버 추상화를 통해 프로세스 외부에서 Unreal Engine 5 게임 상태를 읽으며, UWorld, 액터, 본, 카메라 데이터용 SDK와 함께 사용됩니다. 기능 모듈에는 본 매핑 및 FOV 선택이 포함된 에임봇, 트리거봇, 스킬 라인업 헬퍼, ImGui로 구축된 DirectX 11 오버레이 GUI가 포함되며, 전용 VGK 시스템이 Valorant 전용 오프셋과 암호화된 게임 데이터를 처리합니다. 아키텍처는 주입 가능한 인터페이스 뒤에 애플리케이션 수명 주기, 드라이버, 렌더링, 게임 로직을 분리하며, 릴리스 빌드에는 LLVM 기반 난독화가 추가됩니다. 주로 게임 보안 연구, 안티치트 분석, Vanguard로 보호되는 타이틀에 대한 외부 치트 설계 연구에 유용합니다.
