Это внешний чит на C++ для Apex Legends, который читает память игры извне процесса и отображает функции через экранный оверлей. Проект Echo_Apex создан для 64-битной Windows с использованием Visual Studio и C++17, включает Dear ImGui с бэкендами DirectX 11 и Win32 для меню и отрисовки ESP. Он организован вокруг взаимодействия с драйвером ядра, определений игровых офсетов, типов хитбоксов, утилит шифрования строк и отдельного модуля оверлея, а релизная сборка требует прав администратора. Предназначен для исследователей игровой безопасности и реверс-инженеров, изучающих проектирование внешних читов, доступ к памяти с помощью ядра и обход античита в Apex Legends.
