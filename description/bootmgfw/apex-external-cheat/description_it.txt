Si tratta di un cheat esterno in C++ per Apex Legends che legge la memoria di gioco dall'esterno del processo e renderizza le funzionalità tramite un overlay sullo schermo. Il progetto Echo_Apex è sviluppato per Windows a 64 bit con Visual Studio e C++17, integrando Dear ImGui con backend DirectX 11 e Win32 per menu e disegno ESP. È organizzato attorno alla comunicazione con un driver kernel, definizioni di offset di gioco, tipi di hitbox, utility di crittografia delle stringhe e un modulo overlay dedicato, e la build di release richiede privilegi di amministratore. È destinato a ricercatori di sicurezza dei giochi e reverse engineer che studiano la progettazione di cheat esterni, l'accesso alla memoria assistito dal kernel e l'evasione dell'anti-cheat in Apex Legends.
