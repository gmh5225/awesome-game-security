Este es un SDK RASP (Runtime Application Self-Protection) de nivel empresarial para aplicaciones móviles React Native en Android e iOS. Proporciona detección de root y jailbreak, detección de emuladores y simuladores, detección de hooks de Frida/Xposed/Magisk, comprobaciones de firma de la aplicación e integridad del APK, monitorización de VPN/proxy y captura de pantalla, utilidades de SSL pinning, y un motor de riesgo de dispositivo configurable con eventos de seguridad en tiempo real. Las implementaciones nativas están escritas en Kotlin y Swift y se exponen mediante una API TypeScript-first construida sobre Nitro Modules para la New Architecture de React Native, permitiendo llamadas JSI directas sin serialización del bridge. Está pensado para desarrolladores que crean aplicaciones móviles sensibles a la seguridad, incluidas banca, fintech y juegos que necesitan protecciones anti-manipulación y anti-trampas del lado del cliente.
