這是一款面向 Android 與 iOS 平台 React Native 行動應用程式的企業級執行階段應用程式自我保護（RASP）SDK。它提供 root 與越獄偵測、模擬器偵測、Frida/Xposed/Magisk 鉤子偵測、應用程式簽章與 APK 完整性檢查、VPN/代理與螢幕錄製監控、SSL 固定輔助工具，以及可設定的裝置風險引擎與即時安全事件。原生實作以 Kotlin 與 Swift 撰寫，透過基於 Nitro Modules 的 TypeScript 優先 API 公開，適配 React Native 新架構，支援 JSI 直接呼叫而無需橋接序列化。適用於開發安全敏感型行動應用程式，包括銀行、金融科技以及需要用戶端防篡改與反作弊保護的遊戲。
