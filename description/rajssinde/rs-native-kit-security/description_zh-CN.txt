这是一款面向 Android 和 iOS 平台 React Native 移动应用的企业级运行时应用自我保护（RASP）SDK。它提供 root 与越狱检测、模拟器检测、Frida/Xposed/Magisk 钩子检测、应用签名与 APK 完整性校验、VPN/代理与屏幕录制监控、SSL 固定辅助工具，以及可配置的设备风险引擎与实时安全事件。原生实现采用 Kotlin 和 Swift 编写，通过基于 Nitro Modules 的 TypeScript 优先 API 暴露，适配 React Native 新架构，支持 JSI 直接调用而无需桥接序列化。适用于开发安全敏感型移动应用，包括银行、金融科技以及需要客户端防篡改与反作弊保护的游戏。
