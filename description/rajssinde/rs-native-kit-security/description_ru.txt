Это SDK RASP (Runtime Application Self-Protection) корпоративного уровня для мобильных приложений React Native на Android и iOS. Он обеспечивает обнаружение root и jailbreak, обнаружение эмуляторов и симуляторов, обнаружение хуков Frida/Xposed/Magisk, проверку подписи приложения и целостности APK, мониторинг VPN/прокси и захвата экрана, вспомогательные средства SSL pinning, а также настраиваемый движок оценки риска устройства с событиями безопасности в реальном времени. Нативные реализации написаны на Kotlin и Swift и доступны через API с приоритетом TypeScript, построенный на Nitro Modules для New Architecture React Native, что позволяет выполнять прямые вызовы JSI без сериализации через bridge. Предназначен для разработчиков мобильных приложений с повышенными требованиями к безопасности, включая банковские, финтех-приложения и игры, которым нужна клиентская защита от вмешательства и читерства.
