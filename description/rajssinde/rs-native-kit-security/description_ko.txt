Android 및 iOS용 React Native 모바일 앱을 위한 엔터프라이즈급 런타임 애플리케이션 자기 보호(RASP) SDK입니다. root 및 탈옥 탐지, 에뮬레이터 및 시뮬레이터 탐지, Frida/Xposed/Magisk 후킹 탐지, 앱 서명 및 APK 무결성 검사, VPN/프록시 및 화면 캡처 모니터링, SSL pinning 헬퍼, 구성 가능한 디바이스 위험 엔진과 실시간 보안 이벤트를 제공합니다. 네이티브 구현은 Kotlin과 Swift로 작성되며, React Native New Architecture용 Nitro Modules 기반 TypeScript 우선 API를 통해 노출되어 브리지 직렬화 없이 JSI 직접 호출을 지원합니다. 은행, 핀테크, 클라이언트 측 변조 방지 및 안티치트 보호가 필요한 게임 등 보안에 민감한 모바일 애플리케이션을 개발하는 개발자를 위한 것입니다.
