Dies ist ein RASP-SDK (Runtime Application Self-Protection) auf Enterprise-Niveau für React-Native-Mobile-Apps auf Android und iOS. Es bietet Root- und Jailbreak-Erkennung, Emulator- und Simulator-Erkennung, Frida/Xposed/Magisk-Hook-Erkennung, App-Signatur- und APK-Integritätsprüfungen, VPN/Proxy- und Bildschirmaufnahme-Überwachung, SSL-Pinning-Hilfsmittel sowie eine konfigurierbare Geräterisiko-Engine mit Echtzeit-Sicherheitsereignissen. Native Implementierungen sind in Kotlin und Swift geschrieben und über eine TypeScript-first-API auf Basis von Nitro Modules für die New Architecture von React Native verfügbar, wodurch JSI-Direktaufrufe ohne Bridge-Serialisierung möglich sind. Es richtet sich an Entwickler sicherheitskritischer mobiler Anwendungen, einschließlich Banking, Fintech und Spiele, die clientseitigen Anti-Tamper- und Anti-Cheat-Schutz benötigen.
