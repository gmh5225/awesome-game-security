Android および iOS 向け React Native モバイルアプリ向けのエンタープライズグレードのランタイムアプリケーション自己保護（RASP）SDK です。root および jailbreak 検出、エミュレーター・シミュレーター検出、Frida/Xposed/Magisk フック検出、アプリ署名および APK 整合性チェック、VPN/プロキシおよび画面キャプチャ監視、SSL ピンニングヘルパー、設定可能なデバイスリスクエンジンとリアルタイムセキュリティイベントを提供します。ネイティブ実装は Kotlin と Swift で記述され、React Native の New Architecture 向け Nitro Modules 上に構築された TypeScript ファースト API を通じて公開され、ブリッジシリアル化なしの JSI 直接呼び出しを可能にします。銀行、フィンテック、クライアント側の改ざん防止およびアンチチート保護が必要なゲームなど、セキュリティに敏感なモバイルアプリケーションを開発する開発者向けです。
