Si tratta di un SDK RASP (Runtime Application Self-Protection) di livello enterprise per app mobili React Native su Android e iOS. Fornisce rilevamento di root e jailbreak, rilevamento di emulatori e simulatori, rilevamento di hook Frida/Xposed/Magisk, verifiche della firma dell'app e dell'integrità dell'APK, monitoraggio VPN/proxy e cattura dello schermo, utility per SSL pinning e un motore di rischio dispositivo configurabile con eventi di sicurezza in tempo reale. Le implementazioni native sono scritte in Kotlin e Swift ed esposte tramite un'API TypeScript-first basata su Nitro Modules per la New Architecture di React Native, consentendo chiamate JSI dirette senza serializzazione del bridge. È destinato a sviluppatori che creano applicazioni mobili sensibili alla sicurezza, inclusi banking, fintech e giochi che richiedono protezioni anti-manomissione e anti-cheat lato client.
