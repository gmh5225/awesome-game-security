GDPatch è un loader di mod multipiattaforma e multi-versione per giochi Godot Engine, costruito attorno al patching e all'hooking di script a runtime. Scritto principalmente in Rust, si inietta nei processi di gioco tramite un loader nativo e intercetta l'accesso al filesystem per fornire asset di gioco modificati o virtualizzati. Il progetto include parser e tokenizer GDScript per Godot 3.x e 4.x, scripting di mod basato su Lua e hook API in user mode su Windows, Linux e macOS. È destinato a sviluppatori di mod Godot e reverse engineer che devono patchare GDScript distribuito, sovrascrivere file pack ed estendere titoli Godot closed-source a runtime.
