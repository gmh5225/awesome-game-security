GDPatch is a cross-platform, cross-version mod loader for Godot Engine games built around runtime script patching and hooking. Written primarily in Rust, it injects into game processes through a native loader and intercepts filesystem access to serve modified or virtualized game assets. The project includes GDScript parsers and tokenizers for Godot 3.x and 4.x, Lua-based mod scripting, and usermode API hooks on Windows, Linux, and macOS. It is aimed at Godot mod developers and reverse engineers who need to patch shipped GDScript, override pack files, and extend closed-source Godot titles at runtime.
