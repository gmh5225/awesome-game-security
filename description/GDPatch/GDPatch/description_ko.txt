GDPatch는 런타임 스크립트 패칭 및 후킹을 중심으로 구축된 Godot Engine 게임용 크로스 플랫폼, 크로스 버전 Mod 로더입니다. 주로 Rust로 작성되었으며, 네이티브 로더를 통해 게임 프로세스에 주입하고 파일 시스템 접근을 가로채 수정되거나 가상화된 게임 에셋을 제공합니다. 이 프로젝트에는 Godot 3.x 및 4.x용 GDScript 파서와 토크나이저, Lua 기반 Mod 스크립팅, Windows, Linux, macOS에서의 사용자 모드 API 후크가 포함됩니다. 배포된 GDScript를 패치하고, pack 파일을 덮어쓰며, 런타임에 폐쇄형 Godot 게임을 확장해야 하는 Godot Mod 개발자 및 리버스 엔지니어를 대상으로 합니다.
