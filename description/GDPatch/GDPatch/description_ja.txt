GDPatch は、ランタイムのスクリプトパッチングとフックを中心に構築された、Godot Engine ゲーム向けのクロスプラットフォーム・クロスバージョン対応の Mod ローダーです。主に Rust で記述され、ネイティブローダーを介してゲームプロセスに注入し、ファイルシステムアクセスを傍受して変更済みまたは仮想化されたゲームアセットを提供します。本プロジェクトには Godot 3.x および 4.x 向けの GDScript パーサーとトークナイザー、Lua ベースの Mod スクリプト、Windows・Linux・macOS 上のユーザーモード API フックが含まれます。出荷済み GDScript のパッチ、pack ファイルの上書き、クローズドソースの Godot タイトルをランタイムで拡張する必要がある Godot Mod 開発者やリバースエンジニアを対象としています。
