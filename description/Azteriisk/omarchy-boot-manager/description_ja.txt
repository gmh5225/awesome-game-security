Omarchy Boot and Secure Boot Manager は、Windows と Linux のデュアルブートを簡素化しつつ、両 OS で UEFI Secure Boot を有効に保つ Omarchy Linux 向けプラグインです。sbctl を用いてカスタム Secure Boot キーを Microsoft OEM 証明書とともに登録し、Limine ブートローダーとカーネルイメージに署名し、検出された Windows EFI パーティション向けの Limine チェーンロードエントリを自動設定します。GTK4 GUI、Python CLI ツール、Omarchy メニュー統合を備え、efibootmgr 経由で Windows や BIOS 設定へのワンショット再起動が可能です。Windows 側コンパニオンは bcdedit とスケジュールタスクで UAC なしに Omarchy へ戻せます。Vanguard、EasyAntiCheat、FACEIT などのアンチチート要件を満たす Secure Boot が必要な Linux ゲーマーとデュアルブートユーザー向けです。
