Omarchy Boot and Secure Boot Manager es un complemento de Omarchy Linux que simplifica el arranque dual de Windows y Linux manteniendo UEFI Secure Boot habilitado en ambos sistemas operativos. Registra claves Secure Boot personalizadas junto con certificados OEM de Microsoft mediante sbctl, firma los cargadores de arranque e imágenes del kernel de Limine y configura automáticamente entradas de cadena Limine para las particiones EFI de Windows detectadas. El proyecto ofrece una interfaz GTK4, herramientas CLI en Python e integración con el menú de Omarchy para reinicios directos a Windows o la configuración del BIOS vía efibootmgr, además de un complemento para Windows que usa bcdedit y una tarea programada para volver a Omarchy sin UAC. Está dirigido a jugadores de Linux y usuarios de arranque dual que necesitan Secure Boot para cumplir con sistemas anti-cheat como Vanguard, EasyAntiCheat y FACEIT sin desactivar las protecciones de firmware para Linux.
