Omarchy Boot and Secure Boot Manager is an Omarchy Linux plugin that simplifies Windows and Linux dual-booting while keeping UEFI Secure Boot enabled for both operating systems. It enrolls custom Secure Boot keys alongside Microsoft OEM certificates using sbctl, signs Limine bootloaders and kernel images, and automatically configures Limine chainload entries for detected Windows EFI partitions. The project provides a GTK4 GUI, Python CLI tools, and Omarchy menu integration for one-shot reboots into Windows or BIOS setup via efibootmgr, plus a Windows companion that uses bcdedit and a scheduled task for zero-UAC swaps back to Omarchy. It targets Linux gamers and dual-boot users who need Secure Boot to satisfy anti-cheat systems such as Vanguard, EasyAntiCheat, and FACEIT without disabling firmware protections for Linux.
