Omarchy Boot and Secure Boot Manager 是 Omarchy Linux 的一款外掛，可在 Windows 與 Linux 雙系統開機時，同時保持 UEFI Secure Boot 為兩個作業系統啟用。它透過 sbctl 將自訂 Secure Boot 金鑰與 Microsoft OEM 憑證一併註冊，為 Limine 開機載入程式與核心映像簽署，並自動為偵測到的 Windows EFI 分割區設定 Limine 鏈式載入項目。此專案提供 GTK4 圖形介面、Python 命令列工具，以及 Omarchy 選單整合，可透過 efibootmgr 一鍵重新開機進入 Windows 或 BIOS 設定；另有 Windows 配套元件，使用 bcdedit 與排程工作實現零 UAC 切換回 Omarchy。它面向需要在不禁用 Linux 韌體保護的情況下，以 Secure Boot 滿足 Vanguard、EasyAntiCheat、FACEIT 等反作弊系統要求的 Linux 遊戲玩家與雙系統使用者。
