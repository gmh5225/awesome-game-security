Omarchy Boot and Secure Boot Manager è un plugin per Omarchy Linux che semplifica il dual-boot di Windows e Linux mantenendo UEFI Secure Boot abilitato per entrambi i sistemi operativi. Registra chiavi Secure Boot personalizzate insieme ai certificati OEM Microsoft tramite sbctl, firma i bootloader e le immagini del kernel Limine e configura automaticamente le voci di chainload Limine per le partizioni EFI Windows rilevate. Il progetto offre una GUI GTK4, strumenti CLI Python e integrazione con il menu Omarchy per riavvii immediati in Windows o nella configurazione del BIOS via efibootmgr, oltre a un companion per Windows che usa bcdedit e un'attività pianificata per tornare a Omarchy senza UAC. È pensato per gamer Linux e utenti dual-boot che necessitano di Secure Boot per soddisfare sistemi anti-cheat come Vanguard, EasyAntiCheat e FACEIT senza disabilitare le protezioni firmware per Linux.
