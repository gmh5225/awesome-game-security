Omarchy Boot and Secure Boot Manager est un plugin Omarchy Linux qui simplifie le dual-boot Windows et Linux tout en conservant UEFI Secure Boot activé pour les deux systèmes d'exploitation. Il enregistre des clés Secure Boot personnalisées aux côtés des certificats OEM Microsoft via sbctl, signe les chargeurs d'amorçage et images noyau Limine, et configure automatiquement les entrées de chaînage Limine pour les partitions EFI Windows détectées. Le projet propose une interface GTK4, des outils CLI Python et une intégration au menu Omarchy pour redémarrer en un clic vers Windows ou la configuration du BIOS via efibootmgr, ainsi qu'un compagnon Windows utilisant bcdedit et une tâche planifiée pour revenir à Omarchy sans UAC. Il s'adresse aux joueurs Linux et aux utilisateurs en dual-boot qui ont besoin de Secure Boot pour satisfaire les systèmes anti-triche tels que Vanguard, EasyAntiCheat et FACEIT, sans désactiver les protections firmware pour Linux.
