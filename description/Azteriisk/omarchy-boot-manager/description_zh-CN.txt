Omarchy Boot and Secure Boot Manager 是 Omarchy Linux 的一款插件，可在保持 UEFI Secure Boot 为 Windows 与 Linux 同时启用的前提下，简化双系统引导。它通过 sbctl 将自定义 Secure Boot 密钥与 Microsoft OEM 证书一同注册，为 Limine 引导加载程序与内核镜像签名，并自动为检测到的 Windows EFI 分区配置 Limine 链式加载项。该项目提供 GTK4 图形界面、Python 命令行工具，以及 Omarchy 菜单集成，可通过 efibootmgr 一键重启进入 Windows 或 BIOS 设置；另有 Windows 配套组件，使用 bcdedit 与计划任务实现零 UAC 切换回 Omarchy。它面向需要在不禁用 Linux 固件保护的情况下，通过 Secure Boot 满足 Vanguard、EasyAntiCheat、FACEIT 等反作弊系统要求的 Linux 游戏玩家与双系统用户。
