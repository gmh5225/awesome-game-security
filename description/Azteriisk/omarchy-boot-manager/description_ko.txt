Omarchy Boot and Secure Boot Manager는 Windows와 Linux 듀얼 부팅을 단순화하면서 두 운영체제 모두에서 UEFI Secure Boot를 유지하는 Omarchy Linux 플러그인입니다. sbctl을 사용해 사용자 정의 Secure Boot 키를 Microsoft OEM 인증서와 함께 등록하고, Limine 부트로더와 커널 이미지에 서명하며, 감지된 Windows EFI 파티션에 대한 Limine 체인로드 항목을 자동으로 구성합니다. GTK4 GUI, Python CLI 도구, Omarchy 메뉴 통합을 제공하며 efibootmgr로 Windows 또는 BIOS 설정으로 원클릭 재부팅이 가능합니다. Windows 동반 도구는 bcdedit과 예약 작업으로 UAC 없이 Omarchy로 되돌아갈 수 있습니다. Linux용 펌웨어 보호를 비활성화하지 않고 Vanguard, EasyAntiCheat, FACEIT 같은 안티치트 요구를 충족하는 Secure Boot가 필요한 Linux 게이머와 듀얼 부팅 사용자를 대상으로 합니다.
