Omarchy Boot and Secure Boot Manager — это плагин для Omarchy Linux, который упрощает двойную загрузку Windows и Linux, сохраняя UEFI Secure Boot включённым для обеих операционных систем. Он регистрирует пользовательские ключи Secure Boot вместе с OEM-сертификатами Microsoft через sbctl, подписывает загрузчики и образы ядра Limine и автоматически настраивает записи цепочечной загрузки Limine для обнаруженных EFI-разделов Windows. Проект предоставляет GUI на GTK4, CLI-инструменты на Python и интеграцию с меню Omarchy для быстрой перезагрузки в Windows или настройки BIOS через efibootmgr, а также Windows-компаньон, использующий bcdedit и запланированную задачу для возврата в Omarchy без UAC. Он ориентирован на Linux-геймеров и пользователей двойной загрузки, которым нужен Secure Boot для соответствия античит-системам вроде Vanguard, EasyAntiCheat и FACEIT без отключения защиты прошивки для Linux.
