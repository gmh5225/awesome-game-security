Omarchy Boot and Secure Boot Manager ist ein Omarchy-Linux-Plugin, das den Dual-Boot von Windows und Linux vereinfacht und dabei UEFI Secure Boot für beide Betriebssysteme aktiviert lässt. Es registriert benutzerdefinierte Secure-Boot-Schlüssel neben Microsoft-OEM-Zertifikaten mit sbctl, signiert Limine-Bootloader und Kernel-Images und konfiguriert automatisch Limine-Chainload-Einträge für erkannte Windows-EFI-Partitionen. Das Projekt bietet eine GTK4-GUI, Python-CLI-Tools und Omarchy-Menüintegration für Ein-Klick-Neustarts in Windows oder die BIOS-Einrichtung über efibootmgr sowie einen Windows-Begleiter, der mit bcdedit und einer geplanten Aufgabe ohne UAC zurück zu Omarchy wechselt. Es richtet sich an Linux-Gamer und Dual-Boot-Nutzer, die Secure Boot benötigen, um Anti-Cheat-Systeme wie Vanguard, EasyAntiCheat und FACEIT zu erfüllen, ohne die Firmware-Schutzmechanismen für Linux zu deaktivieren.
