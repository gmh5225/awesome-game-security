NavroProxy ist ein Anti-Cheat-Proxy für Minecraft Bedrock Edition, der Spielerverbindungen vor einem Backend-Server beendet, Welt- und Spielerzustand spiegelt und Bewegungs- sowie Gameplay-Pakete validiert, bevor sie den Spieleserver erreichen. Die Kernimplementierung nutzt Java 21 mit Gradle, optional ein Go-basiertes NetherNet-Frontend sowie Bridge-Plugins für BDS, Geyser/Floodgate, Nukkit und PocketMine-MP. Es bietet Dutzende Paket- und Vorhersageprüfungen (Bewegung, Sprint, Timer, Platzierung, Elytra, fehlerhafte Pakete usw.), konfigurierbare Toleranzen und verstoßbasierte Sanktionen per YAML sowie Betriebsmodi für Live-Erkennung oder passive Protokollinspektion über RakNet oder NetherNet. Betreiber können es unter Windows oder Linux einsetzen, um öffentliche Bedrock-Netzwerke zu härten, indem das echte Backend auf einer privaten Listen-Adresse bleibt und der Proxy Cheats auf Protokollebene unterbindet.
