NavroProxy は Minecraft Bedrock Edition 向けの反チートプロキシで、バックエンドのゲームサーバーの手前でプレイヤー接続を終端し、ワールドとプレイヤー状態をミラーリングし、ゲームサーバーに届く前に移動およびゲームプレイ用パケットを検証します。コア実装は Java 21 と Gradle で構築され、オプションで Go 製の NetherNet フロントエンドに対応し、BDS、Geyser/Floodgate、Nukkit、PocketMine-MP 向けのブリッジプラグインも利用できます。移動、スプリント、タイマー、設置、エリトラ、不正パケット系など多数のパケット検査と予測チェックを備え、YAML による許容値と違反ベースの処罰設定、RakNet または NetherNet 上でのライブ検知またはパッシブなプロトコル検査モードを提供します。Windows または Linux 上で運用し、実バックエンドを非公開のリッスンアドレスに置いたまま、プロキシがプロトコル層でチートを封じることで公開 Bedrock ネットワークを強化できます。
