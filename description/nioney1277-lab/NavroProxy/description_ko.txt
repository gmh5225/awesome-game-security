NavroProxy는 Minecraft Bedrock Edition용 안티치트 프록시로, 백엔드 게임 서버 앞에서 플레이어 연결을 종단하고 월드 및 플레이어 상태를 미러링하며 게임 서버에 도달하기 전에 이동 및 게임플레이 패킷을 검증합니다. 핵심 구현은 Java 21과 Gradle로 빌드되며, 선택적으로 Go 기반 NetherNet 프론트엔드를 지원하고 BDS, Geyser/Floodgate, Nukkit, PocketMine-MP용 브리지 플러그인을 제공합니다. 이동, 달리기, 타이머, 배치, 겉날개, 잘못된 패킷 계열 등 수십 가지 패킷 및 예측 검사를 탑재하고, YAML로 허용 오차와 위반 기반 처벌을 설정할 수 있으며 RakNet 또는 NetherNet에서 실시간 탐지 또는 수동 프로토콜 검사 모드를 운용할 수 있습니다. Windows 또는 Linux에서 실행하여 실제 백엔드를 비공개 수신 주소에 두고 프록시가 프로토콜 계층에서 치트를 차단함으로써 공개 Bedrock 네트워크를 강화할 수 있습니다.
