NavroProxy is a Minecraft Bedrock Edition anti-cheat proxy that terminates player connections in front of a backend server, mirrors world and player state, and validates movement and gameplay packets before they reach the game server. The core implementation is Java 21 built with Gradle, with optional Go-based NetherNet frontend support and bridge plugins for BDS, Geyser/Floodgate, Nukkit, and PocketMine-MP. It ships dozens of packet and prediction checks (movement, sprint, timer, placement, elytra, and bad-packet families), configurable tolerances and violation-based punishments via YAML, and operating modes for live detection or passive protocol inspection over RakNet or NetherNet. Operators run it on Windows or Linux to harden public Bedrock networks by keeping the real backend on a private listen address while the proxy enforces cheats at the protocol layer.
