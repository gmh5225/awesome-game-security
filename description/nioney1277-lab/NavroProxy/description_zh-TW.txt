NavroProxy 是一款 Minecraft 基岩版反作弊代理，在後端遊戲伺服器前方終止玩家連線，鏡像世界與玩家狀態，並在封包抵達遊戲伺服器之前驗證移動與玩法封包。核心以 Java 21 搭配 Gradle 建置，可選用基於 Go 的 NetherNet 前端，並提供與 BDS、Geyser/Floodgate、Nukkit、PocketMine-MP 的橋接外掛。內建數十種封包與預測檢查（移動、衝刺、計時、放置、鞘翅與異常封包等），可透過 YAML 設定容差與以違規為基礎的懲處，並支援在 RakNet 或 NetherNet 上進行即時偵測或被動協定檢視。營運者可在 Windows 或 Linux 上部署，將真實後端保留於私有監聽位址，由代理在協定層強制反作弊，以加固對外公開的基岩版網路。
