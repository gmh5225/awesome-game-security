NavroProxy 是一款 Minecraft 基岩版反作弊代理，在后台游戏服务器前端终止玩家连接，镜像世界与玩家状态，并在数据包抵达游戏服之前校验移动与玩法相关数据包。核心由 Java 21 与 Gradle 构建，可选基于 Go 的 NetherNet 前端，并支持与 BDS、Geyser/Floodgate、Nukkit、PocketMine-MP 的桥接插件。内置数十种数据包与预测类检测（移动、疾跑、计时、放置、鞘翅及异常数据包等），可通过 YAML 配置容差与基于违规的处罚，并支持在 RakNet 或 NetherNet 上进行实时检测或被动协议检查。运维可在 Windows 或 Linux 上部署，将真实后台保留在私有监听地址，由代理在协议层拦截作弊，从而加固面向公众的基岩版网络。
