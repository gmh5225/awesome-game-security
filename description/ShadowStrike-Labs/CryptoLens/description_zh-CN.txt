CryptoLens 是一款用于在 x86 与 x64 Windows 二进制文件中定位密码学、哈希及相关代码的 IDA Pro 插件，同时也是可独立使用的 Python 包。它将对常量、查找表、指令模式与函数结构的静态扫描与可选的 Hex-Rays 反编译分析、API 名称哈希解析、库与密钥指纹、熵映射以及在调试器中从内存恢复活体密钥与密码状态相结合。内置目录涵盖 SHA-2、MD5、BLAKE2、Keccak、AES、ChaCha、RC4、MurmurHash、xxHash、FNV、SipHash 以及众多 CRC 与 PRNG 家族等大量算法，并配有能降低孤立常量匹配误报率的精确规则。结果可在 IDA 中浏览、写入数据库标注，或导出为 JSON 或 HTML；同一套引擎也可在无 IDA 环境下通过命令行界面使用。面向需要在受保护可执行文件、作弊程序、恶意软件及其他 Windows 二进制中快速定位密码学与哈希用法的逆向工程师与安全研究人员。
