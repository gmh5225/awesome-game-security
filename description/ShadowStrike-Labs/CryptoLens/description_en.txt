CryptoLens is an IDA Pro plugin and standalone Python package for locating cryptographic, hashing, and related code in x86 and x64 Windows binaries. It combines static scans of constants, lookup tables, instruction patterns, and function structure with optional Hex-Rays decompiler analysis, API-name hash resolution, library and key fingerprinting, entropy mapping, and debugger memory recovery for live keys and cipher state. The built-in catalog covers a wide range of algorithms including SHA-2, MD5, BLAKE2, Keccak, AES, ChaCha, RC4, MurmurHash, xxHash, FNV, SipHash, and many CRC and PRNG families, with precision rules that reduce false positives from isolated constant matches. Results can be browsed in IDA, annotated in the database, or exported as JSON or HTML, and the same engines are available from a command-line interface without IDA. It is aimed at reverse engineers and security researchers who need to quickly pinpoint crypto and hash usage in protected executables, cheats, malware, and other Windows binaries.
