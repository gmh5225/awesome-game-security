CryptoLens は、x86 および x64 の Windows バイナリ内で暗号処理、ハッシュ、その関連コードを特定するための IDA Pro プラグインであり、スタンドアロンの Python パッケージでもあります。定数、ルックアップテーブル、命令パターン、関数構造の静的スキャンに、任意の Hex-Rays 逆コンパイラ解析、API 名ハッシュ解決、ライブラリおよび鍵のフィンガープリント、エントロピーマッピング、デバッガによるメモリからのライブ鍵と暗号状態の復元を組み合わせます。組み込みカタログは SHA-2、MD5、BLAKE2、Keccak、AES、ChaCha、RC4、MurmurHash、xxHash、FNV、SipHash など多くの CRC および PRNG 系を含む幅広いアルゴリズムをカバーし、孤立した定数一致による誤検知を減らす精度ルールを備えています。結果は IDA 内で閲覧・データベースへ注釈付け、または JSON や HTML としてエクスポートでき、同じエンジンは IDA なしのコマンドラインからも利用できます。保護された実行ファイル、チート、マルウェア、その他の Windows バイナリで暗号とハッシュの使用箇所を素早く特定する必要があるリバースエンジニアおよびセキュリティ研究者向けです。
