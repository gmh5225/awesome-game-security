CryptoLens — плагин для IDA Pro и автономный пакет Python для поиска криптографического, хеширующего и связанного кода в бинарниках Windows для x86 и x64. Он сочетает статическое сканирование констант, таблиц подстановки, шаблонов инструкций и структуры функций с опциональным анализом декомпилятора Hex-Rays, разрешением хешей имён API, отпечатками библиотек и ключей, картированием энтропии и восстановлением из памяти отладчика живых ключей и состояния шифра. Встроенный каталог охватывает широкий спектр алгоритмов, включая SHA-2, MD5, BLAKE2, Keccak, AES, ChaCha, RC4, MurmurHash, xxHash, FNV, SipHash и многие семейства CRC и PRNG, с правилами точности, снижающими ложные срабатывания из‑за изолированных совпадений констант. Результаты можно просматривать в IDA, помечать в базе данных или экспортировать в JSON или HTML; те же движки доступны из интерфейса командной строки без IDA. Инструмент ориентирован на специалистов по реверс-инжинирингу и исследователей безопасности, которым нужно быстро находить использование криптографии и хешей в защищённых исполняемых файлах, читах, вредоносном ПО и других бинарниках Windows.
