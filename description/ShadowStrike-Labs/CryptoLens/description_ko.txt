CryptoLens는 x86 및 x64 Windows 바이너리에서 암호화, 해싱 및 관련 코드를 찾기 위한 IDA Pro 플러그인이며 독립 실행형 Python 패키지이기도 합니다. 상수, 룩업 테이블, 명령 패턴, 함수 구조에 대한 정적 스캔을 선택적 Hex-Rays 디컴파일러 분석, API 이름 해시 해석, 라이브러리 및 키 지문, 엔트로피 매핑, 디버거 메모리 복구를 통한 라이브 키와 암호 상태 복원과 결합합니다. 내장 카탈로그는 SHA-2, MD5, BLAKE2, Keccak, AES, ChaCha, RC4, MurmurHash, xxHash, FNV, SipHash 및 다양한 CRC 및 PRNG 계열을 포함한 광범위한 알고리즘을 다루며, 고립된 상수 일치로 인한 오탐을 줄이는 정밀 규칙을 제공합니다. 결과는 IDA에서 탐색하거나 데이터베이스에 주석으로 남기거나 JSON 또는 HTML로 내보낼 수 있으며, 동일한 엔진은 IDA 없이 명령줄 인터페이스에서도 사용할 수 있습니다. 보호된 실행 파일, 치트, 멀웨어 및 기타 Windows 바이너리에서 암호화 및 해시 사용을 빠르게 특정해야 하는 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
