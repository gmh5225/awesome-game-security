CryptoLens 是一款用於在 x86 與 x64 Windows 二進位檔中定位密碼學、雜湊及相關程式碼的 IDA Pro 外掛，同時也是可獨立使用的 Python 套件。它將對常數、查閱表、指令模式與函式結構的靜態掃描，與可選的 Hex-Rays 反編譯分析、API 名稱雜湊解析、程式庫與金鑰指紋、熵對應，以及在除錯器中從記憶體復原即時金鑰與密文狀態相結合。內建目錄涵蓋 SHA-2、MD5、BLAKE2、Keccak、AES、ChaCha、RC4、MurmurHash、xxHash、FNV、SipHash 以及眾多 CRC 與 PRNG 家族等廣泛演算法，並配有能降低孤立常數匹配誤報率的精確規則。結果可在 IDA 中瀏覽、寫入資料庫註解，或匯出為 JSON 或 HTML；同一套引擎亦可在無 IDA 環境下透過命令列介面使用。面向需要在受保護可執行檔、作弊程式、惡意軟體及其他 Windows 二進位檔中快速鎖定密碼學與雜湊用法的逆向工程師與安全研究人員。
