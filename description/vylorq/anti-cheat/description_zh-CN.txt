Vigil 是一款面向 Minecraft 1.21.11 的服务端 Fabric 模组，为多人世界提供反作弊检测与全面的服务器保护。它采用 Java 编写，核心模块可测试，涵盖移动上限预测、针对攻击距离、自瞄与自动连点的延迟补偿战斗检测，以及反 X 光矿石隐藏；违规行为会被记分为管理员审核案件并附带证据片段，而非自动封禁。除检测功能外，还集成员工与管理工具，包括领地、屏障、监狱、PvP 竞技场、安全玩家交易、监视列表、回滚以及 GUI 驱动的 Vigil Panel，并可选支持 Geyser 与 Floodgate 以实现 Java 与 Bedrock 跨平台联机。它面向希望在 Fabric 服务器上获得可配置、以审核为先的反作弊检测与集成世界保护的 Minecraft 服主。
