Vigil は Minecraft 1.21.11 向けのサーバーサイド Fabric モッドで、マルチプレイワールド向けにアンチチート検知と幅広いサーバー保護を提供します。Java で記述され、テスト可能なコアモジュールを備え、移動上限予測、reach・aim・オートクリック向けのラグ補正コンバットチェック、anti-x-ray による鉱石非表示を実行し、自動 BAN ではなく管理員レビュー用の証拠クリップ付き案件として違反をスコア化します。検知以外にも、クレーム、バリア、監獄、PvP アリーナ、安全なプレイヤー取引、ウォッチリスト、ロールバック、GUI 駆動の Vigil Panel などのスタッフ・モデレーションツールを同梱し、オプションで Geyser と Floodgate による Java と Bedrock のクロスプレイにも対応します。Fabric サーバー上で設定可能なレビュー優先型のアンチチート検知と統合されたワールド保護を求める Minecraft サーバー管理者を対象としています。
