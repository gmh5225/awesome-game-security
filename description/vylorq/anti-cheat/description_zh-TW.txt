Vigil 是一款面向 Minecraft 1.21.11 的伺服器端 Fabric 模組，為多人世界提供反作弊偵測與全面的伺服器保護。它以 Java 撰寫，核心模組可測試，涵蓋移動上限預測、針對攻擊距離、自瞄與自動連點的延遲補償戰鬥檢查，以及反 X 光礦石隱藏；違規行為會被計入管理員審核案件並附上證據片段，而非自動封禁。除偵測功能外，還整合員工與管理工具，包括領地、屏障、監獄、PvP 競技場、安全玩家交易、監視名單、回滾以及 GUI 驅動的 Vigil Panel，並可選支援 Geyser 與 Floodgate 以實現 Java 與 Bedrock 跨平台遊玩。它面向希望在 Fabric 伺服器上取得可設定、以審核為先的反作弊偵測與整合世界保護的 Minecraft 伺服器管理員。
