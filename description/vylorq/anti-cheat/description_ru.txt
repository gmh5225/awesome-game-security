Vigil — серверный мод Fabric для Minecraft 1.21.11, обеспечивающий античит-детекцию и широкую защиту сервера в многопользовательских мирах. Написан на Java с тестируемым основным модулем; выполняет предсказание верхней границы движения, лаг-компенсированные боевые проверки reach, aim и autoclicking, а также скрытие руд anti-x-ray, фиксируя нарушения в делах для проверки администраторами с фрагментами доказательств вместо автоматических банов. Помимо детекции, включает инструменты для персонала и модерации: claims, барьеры, тюрьмы, PvP-арены, безопасную торговлю между игроками, списки наблюдения, откат (rollback) и Vigil Panel с GUI, с опциональной поддержкой Geyser и Floodgate для кроссплея Java и Bedrock. Рассчитан на администраторов серверов Minecraft, которым нужна настраиваемая античит-детекция с приоритетом ручной проверки и интегрированная защита мира на серверах Fabric.
