Vigil è una mod Fabric lato server per Minecraft 1.21.11 che offre rilevamento anti-cheat e ampia protezione del server per mondi multiplayer. Scritta in Java con un modulo core testabile, esegue previsione del limite superiore di movimento, controlli di combattimento compensati per il lag su reach, aim e autoclicking, e occultamento minerali anti-x-ray, registrando le violazioni in casi di revisione amministrativa con clip di prove anziché ban automatici. Oltre al rilevamento, include strumenti per staff e moderazione come claims, barriere, carceri, arene PvP, scambio sicuro tra giocatori, watchlist, rollback e il Vigil Panel guidato da GUI, con supporto opzionale di Geyser e Floodgate per crossplay Java e Bedrock. È pensato per gli amministratori di server Minecraft che desiderano rilevamento cheat configurabile, con priorità alla revisione, e protezione integrata del mondo su server Fabric.
