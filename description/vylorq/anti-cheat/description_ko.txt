Vigil은 Minecraft 1.21.11용 서버 측 Fabric 모드로, 멀티플레이 월드에 대한 안티 치트 탐지와 폭넓은 서버 보호 기능을 제공합니다. Java로 작성되었으며 테스트 가능한 코어 모듈을 갖추고, 이동 상한 예측, reach·aim·오토클릭에 대한 렉 보정 전투 검사, anti-x-ray 광물 숨김을 수행하며, 자동 밴 대신 증거 클립이 포함된 관리자 검토 사건으로 위반을 점수화합니다. 탐지 외에도 클레임, 배리어, 감옥, PvP 아레나, 안전한 플레이어 거래, 워치리스트, 롤백, GUI 기반 Vigil Panel 등 스태프·모더레이션 도구를 포함하며, Geyser와 Floodgate를 통한 Java·Bedrock 크로스플레이도 선택 지원합니다. Fabric 서버에서 구성 가능하고 검토 우선 방식의 치트 탐지와 통합 월드 보호를 원하는 Minecraft 서버 관리자를 대상으로 합니다.
