OpenLeaderboard è un backend per classifiche open source multi-tenant pensato per gli sviluppatori di giochi che necessitano di query di posizione rapide e alto throughput di scrittura su board molto grandi. Il server è scritto in Go e ruota attorno a un motore di ranking Redis sorted-set alimentato da un log di ingestione persistente per scritture idempotenti, replay e ricostruzione della cache, con supporto per finestre temporali, segmenti, rank relativi agli amici e ranking approssimativo in coda profonda. L’anti-cheat opzionale per app usa invii di punteggio firmati HMAC con finestra di replay, affiancato da chiavi API pubblicabili e segrete separate e token giocatore, così che le credenziali esposte sul client non possano moderare completamente né impersonare i giocatori. Include una dashboard web, SDK di riferimento Go e TypeScript, client Unity, deployment orientato a Docker, Terraform e AWS, con monitoraggio Prometheus e Grafana. Usatelo per ospitare o self-hostare leaderboard di produzione rafforzando l’invio dei punteggi e l’isolamento dei tenant per giochi live.
