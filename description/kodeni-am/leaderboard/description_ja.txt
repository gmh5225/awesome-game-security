OpenLeaderboard は、超大規模ボードで高速な順位照会と高い書き込みスループットが必要なゲーム開発者向けの、オープンソースのマルチテナント型リーダーボードバックエンドです。サーバーは Go で実装され、Redis のソート済みセットによるランキングエンジンを中核とし、永続的な ingest ログから冪等な書き込み、リプレイ、キャッシュ再構築を行い、時間ウィンドウ、セグメント、フレンド相対順位、近似ディープテールランキングに対応します。任意の per-app 反チートはリプレイウィンドウ付き HMAC 署名スコア提出を用い、公開可能な API キーと秘密 API キー、プレイヤートークンを分離し、クライアントに露出した認証情報では完全なモデレーションやプレイヤーなりすましができないようにします。Web ダッシュボード、Go および TypeScript 参照 SDK、Unity クライアント、Docker・Terraform・AWS 向けデプロイ、Prometheus と Grafana による監視が同梱されています。本番リーダーボードのホスティングやセルフホストに使い、ライブゲーム向けにスコア提出の強化とテナント分離を実現できます。
