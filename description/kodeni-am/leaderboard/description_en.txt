OpenLeaderboard is an open-source, multi-tenant leaderboard backend aimed at game developers who need fast rank queries and high write throughput on very large boards. The server is written in Go and centers on a Redis sorted-set ranking engine fed by a durable ingest log for idempotent writes, replay, and cache rebuilds, with support for time windows, segments, friend-relative ranks, and approximate deep-tail ranking. Optional per-app anti-cheat uses HMAC-signed score submissions with a replay window, complemented by split publishable and secret API keys and player tokens so client-exposed credentials cannot fully moderate or impersonate players. It ships with a web dashboard, reference Go and TypeScript SDKs, a Unity client, and Docker, Terraform, and AWS-oriented deployment with Prometheus and Grafana monitoring. Use it to host or self-run production leaderboards while hardening score submission and tenant isolation for live games.
