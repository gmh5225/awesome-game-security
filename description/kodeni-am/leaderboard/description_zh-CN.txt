OpenLeaderboard 是一款开源的多租户排行榜后端，面向需要在超大规模榜单上实现快速排名查询与高写入吞吐的游戏开发者。服务端采用 Go 编写，核心是基于 Redis 有序集合的排名引擎，由持久化 ingest 日志驱动，支持幂等写入、回放与缓存重建，并具备时间窗口、分段、好友相对排名及近似长尾排名等功能。可选的按应用反作弊通过带重放窗口的 HMAC 签名成绩提交实现，并配合可公开的 API 密钥、私密 API 密钥与玩家令牌分离，避免暴露在客户端的凭据具备完整管理权限或冒充玩家。项目附带 Web 仪表盘、Go 与 TypeScript 参考 SDK、Unity 客户端，以及面向 Docker、Terraform 与 AWS 的部署方案及 Prometheus 与 Grafana 监控。可用于托管或自建生产级排行榜，并强化在线游戏的分数提交与租户隔离。
