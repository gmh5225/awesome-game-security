OpenLeaderboard 是一款開源的多租戶排行榜後端，面向需要在超大規模榜單上實現快速排名查詢與高寫入吞吐的遊戲開發者。伺服器以 Go 撰寫，核心為基於 Redis 有序集合的排名引擎，由持久化 ingest 日誌驅動，支援冪等寫入、回放與快取重建，並具備時間視窗、分段、好友相對排名及近似長尾排名等功能。可選的按應用反作弊透過帶重放視窗的 HMAC 簽名成績提交實現，並搭配可公開的 API 金鑰、私密 API 金鑰與玩家權杖分離，避免暴露在客戶端的憑證具備完整管理權限或冒充玩家。專案附帶 Web 儀表板、Go 與 TypeScript 參考 SDK、Unity 客戶端，以及面向 Docker、Terraform 與 AWS 的部署方案及 Prometheus 與 Grafana 監控。可用於託管或自建生產級排行榜，並強化線上遊戲的分數提交與租戶隔離。
