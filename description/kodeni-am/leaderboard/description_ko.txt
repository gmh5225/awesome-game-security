OpenLeaderboard는 매우 큰 보드에서 빠른 순위 조회와 높은 쓰기 처리량이 필요한 게임 개발자를 위한 오픈 소스 멀티 테넌트 리더보드 백엔드입니다. 서버는 Go로 작성되었으며 Redis sorted-set 기반 랭킹 엔진을 중심으로, 내구성 있는 ingest 로그로 멱등 쓰기, 재생, 캐시 재구축을 지원하고 시간 창, 세그먼트, 친구 상대 순위, 근사 deep-tail 랭킹을 제공합니다. 선택적 per-app 안티치트는 재생 창이 있는 HMAC 서명 점수 제출을 사용하며, 공개 가능한 API 키와 비밀 API 키, 플레이어 토큰을 분리해 클라이언트에 노출된 자격 증명으로는 전체 관리 권한이나 플레이어 사칭이 불가능합니다. 웹 대시보드, Go 및 TypeScript 참조 SDK, Unity 클라이언트, Docker·Terraform·AWS 중심 배포, Prometheus와 Grafana 모니터링이 포함됩니다. 라이브 게임에서 점수 제출과 테넌트 격리를 강화하면서 프로덕션 리더보드를 호스팅하거나 자체 운영하는 데 사용할 수 있습니다.
