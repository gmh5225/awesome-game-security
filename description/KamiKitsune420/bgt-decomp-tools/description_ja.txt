BlastBay Gaming Toolkit（BGT）またはそのオープンソース後継 NVGT でビルドされた Windows 実行ファイルから、AngelScript ソース、バイトコード、アセットパックを復元する Python ツールキットです。PE オーバーレイから AES-256-CBC 復号と LZ77 展開を経て、AngelScript モジュールの逆アセンブルとリフトまで、抽出チェーン全体を自動化します。試行復号と自己検証フォーマットチェックで適応するエンジン固有リーダーを備えます。NVGT の逆コンパイルとライブラリ復元、オペコードテーブル抽出のための UPX ランタイムアンパック、出荷バイナリからリーダーを拡張するオプションの Ghidra ヘッドレスワークフロー、CLI とスクリーンリーダー向け GUI の両方のエントリポイントをカバーする付属モジュールも含みます。ゲームごとの手動 RE なしに、標準 BGT/NVGT タイトルの再現可能でタイトル非依存の逆コンパイルを必要とするリバースエンジニア、アクセシビリティゲーム研究者、保存活動者を対象としています。
