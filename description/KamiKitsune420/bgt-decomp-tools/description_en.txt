This is a Python toolkit for recovering AngelScript source, bytecode, and asset packs from Windows executables built with the BlastBay Gaming Toolkit (BGT) or its open-source successor NVGT. It automates the full extraction chain from PE overlays through AES-256-CBC decryption and LZ77 decompression, then disassembles and lifts AngelScript modules with engine-specific readers that adapt via trial decryption and self-verifying format checks. Companion modules cover NVGT decompilation and library recovery, UPX runtime unpacking for opcode-table extraction, optional Ghidra headless workflows for extending readers from shipped binaries, and both CLI and screen-reader-friendly GUI entry points. The project targets reverse engineers, accessibility-game researchers, and preservationists who need reproducible, title-agnostic decompilation of stock BGT and NVGT games without per-game manual RE.
