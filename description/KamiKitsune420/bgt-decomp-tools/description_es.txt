Kit de herramientas en Python para recuperar código fuente AngelScript, bytecode y paquetes de assets de ejecutables Windows compilados con BlastBay Gaming Toolkit (BGT) o su sucesor de código abierto NVGT. Automatiza toda la cadena de extracción desde overlays PE pasando por descifrado AES-256-CBC y descompresión LZ77, hasta desensamblar y elevar módulos AngelScript con lectores específicos del motor que se adaptan mediante descifrado de prueba y comprobaciones de formato autoverificables. Módulos complementarios cubren decompilación NVGT y recuperación de bibliotecas, desempaquetado en runtime UPX para extracción de tablas de opcodes, flujos opcionales headless de Ghidra para ampliar lectores a partir de binarios distribuidos, y puntos de entrada CLI y GUI accesibles para lectores de pantalla. El proyecto está dirigido a ingenieros inversos, investigadores de juegos accesibles y preservacionistas que necesitan decompilación reproducible e independiente del título de juegos BGT y NVGT estándar sin RE manual por juego.
