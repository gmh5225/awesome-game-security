這是一個 Python 工具包，用於從使用 BlastBay Gaming Toolkit（BGT）或其開源後繼 NVGT 建置的 Windows 可執行檔中還原 AngelScript 原始碼、位元組碼與資源包。它自動化完整擷取流程：從 PE 覆蓋資料經 AES-256-CBC 解密與 LZ77 解壓縮，再到反組譯並提升 AngelScript 模組；引擎專用讀取器透過試解密與自我驗證格式檢查進行適配。配套模組涵蓋 NVGT 反編譯與函式庫還原、用於擷取 opcode 表的 UPX 執行期解包、可選的 Ghidra 無頭工作流程以從出貨二進位擴展讀取器，以及 CLI 與螢幕閱讀器友善的 GUI 入口。專案面向需要可重現、與特定標題無關地反編譯原版 BGT 與 NVGT 遊戲、而無需逐作手動逆向的逆向工程師、無障礙遊戲研究者與保存工作者。
