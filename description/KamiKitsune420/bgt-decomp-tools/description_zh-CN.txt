这是一个 Python 工具包，用于从使用 BlastBay Gaming Toolkit（BGT）或其开源后继 NVGT 构建的 Windows 可执行文件中恢复 AngelScript 源码、字节码和资源包。它自动化完整提取流程：从 PE 附加数据经 AES-256-CBC 解密与 LZ77 解压，再到反汇编并提升 AngelScript 模块；引擎专用读取器通过试解密与自校验格式检查进行适配。配套模块涵盖 NVGT 反编译与库恢复、用于提取 opcode 表的 UPX 运行时解包、可选的 Ghidra 无头工作流以从发行二进制扩展读取器，以及 CLI 与屏幕阅读器友好的 GUI 入口。项目面向需要可复现、与具体标题无关地反编译原版 BGT 与 NVGT 游戏、而无需逐作手动逆向的逆向工程师、无障碍游戏研究者与游戏保存工作者。
