BlastBay Gaming Toolkit(BGT) 또는 오픈소스 후속 NVGT로 빌드된 Windows 실행 파일에서 AngelScript 소스, 바이트코드, 에셋 팩을 복구하는 Python 툴킷입니다. PE 오버레이에서 AES-256-CBC 복호화와 LZ77 압축 해제를 거쳐 AngelScript 모듈을 디스어셈블하고 리프트하는 전체 추출 체인을 자동화합니다. 시험 복호화와 자기 검증 형식 검사로 적응하는 엔진별 리더를 사용합니다. NVGT 디컴파일 및 라이브러리 복구, opcode 테이블 추출을 위한 UPX 런타임 언패킹, 배포 바이너리에서 리더를 확장하는 선택적 Ghidra 헤드리스 워크플로, CLI와 스크린 리더 친화 GUI 진입점을 다루는 동반 모듈도 포함합니다. 게임별 수동 RE 없이 표준 BGT·NVGT 타이틀의 재현 가능하고 타이틀에 구애받지 않는 디컴파일이 필요한 리버스 엔지니어, 접근성 게임 연구자, 보존 활동가를 대상으로 합니다.
