MemDbg 是一款面向已 root 的 Android aarch64 设备的 Cheat Engine 风格内存调试器，将 Vulkan 全屏覆盖层、Dear ImGui 与原生 root 内存引擎集成于单一可部署的 ELF 二进制文件中。主要使用 C++ 编写，并内嵌 Lua 5.4 脚本，支持进程附加、多类型内存扫描、指针与结构体分析、十六进制浏览、硬件与软件断点、变速、Auto Assemble，以及带数值冻结的训练器式作弊表。该工具还提供反汇编、监视点、远程调用、共享库注入、热键，以及用于触控交互的屏幕软键盘。它面向需要在 Android 上于 root 或 Termux 环境下进行深度进程内检查与自动化的安全研究人员、逆向工程师及游戏 Mod 开发者。
