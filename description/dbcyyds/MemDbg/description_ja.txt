MemDbg は、root 化された Android aarch64 デバイス向けの Cheat Engine 風メモリデバッガーで、Vulkan フルスクリーンオーバーレイ、Dear ImGui、ネイティブ root メモリエンジンを単一のデプロイ可能な ELF バイナリに統合しています。主に C++ で記述され、Lua 5.4 スクリプトが組み込まれており、プロセスアタッチ、多種類のメモリスキャン、ポインタおよび構造体解析、16 進数ブラウジング、ハードウェアおよびソフトウェアブレークポイント、スピードハック、Auto Assemble、値凍結付きトレーナー形式のチートテーブルをサポートします。さらに逆アセンブル、ウォッチポイント、リモートコール、共有オブジェクト注入、ホットキー、タッチ操作向けの画面上ソフトキーボードも提供します。root または Termux 環境下の Android で、プロセス内の詳細な検査と自動化を必要とするセキュリティ研究者、リバースエンジニア、ゲーム mod 制作者を対象としています。
