MemDbg 是一款面向已 root 的 Android aarch64 裝置的 Cheat Engine 風格記憶體除錯器，將 Vulkan 全螢幕覆蓋層、Dear ImGui 與原生 root 記憶體引擎整合於單一可部署的 ELF 二進位檔中。主要使用 C++ 撰寫，並內嵌 Lua 5.4 腳本，支援程序附加、多類型記憶體掃描、指標與結構分析、十六進位瀏覽、硬體與軟體中斷點、變速、Auto Assemble，以及含數值凍結的訓練器式作弊表。此工具還提供反組譯、監視點、遠端呼叫、共享物件注入、熱鍵，以及用於觸控互動的螢幕軟鍵盤。它面向需要在 Android 上於 root 或 Termux 環境下進行深度程序內檢查與自動化的安全研究人員、逆向工程師及遊戲 Mod 開發者。
