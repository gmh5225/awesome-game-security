VirgolaAntiCheat è un plugin anti-cheat lato server per server Minecraft Paper che rileva i cheat client più comuni durante il gioco. È scritto in Java (Maven, Java 21) e intercetta il traffico di rete tramite PacketEvents insieme agli eventi Bukkit di movimento, combattimento e posizionamento blocchi. I controlli integrati coprono fly, speed, scaffold, Jesus (camminata sull’acqua), no-fall, pacchetti non validi e abusi di combattimento in stile KillAura come reach, angoli di mira e pattern di swing, con compensazione del lag e tracciamento delle violazioni per giocatore. Lo staff può gestire i rilevamenti con comandi in-game, una GUI di configurazione, freeze dei giocatori, avvisi e notifiche webhook Discord opzionali. È pensato per gli operatori di server multigiocatore che vogliono prevenzione leggera dei cheat e strumenti di moderazione piuttosto che stack anti-cheat a livello kernel o commerciali.
