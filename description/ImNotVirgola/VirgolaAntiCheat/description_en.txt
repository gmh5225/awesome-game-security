VirgolaAntiCheat is a server-side anti-cheat plugin for Minecraft Paper servers that detects common client cheats during gameplay. It is written in Java (Maven, Java 21) and hooks network traffic through PacketEvents alongside Bukkit movement, combat, and block-placement events. Built-in checks cover fly, speed, scaffold, Jesus (water walking), no-fall, invalid packets, and KillAura-style combat abuse such as reach, aim angles, and swing patterns, with lag compensation and per-player violation tracking. Staff can manage detections through in-game commands, a configuration GUI, player freeze, alerts, and optional Discord webhook notifications. It is aimed at multiplayer server operators who want lightweight cheat prevention and moderation tooling rather than kernel-level or commercial anti-cheat stacks.
