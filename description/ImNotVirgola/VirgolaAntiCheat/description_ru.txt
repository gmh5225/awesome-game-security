VirgolaAntiCheat — серверный античит-плагин для серверов Minecraft Paper, который обнаруживает распространённые клиентские читы во время игры. Написан на Java (Maven, Java 21) и перехватывает сетевой трафик через PacketEvents, а также события Bukkit перемещения, боя и установки блоков. Встроенные проверки охватывают fly, speed, scaffold, Jesus (ходьба по воде), no-fall, недопустимые пакеты и боевые злоупотребления в стиле KillAura — reach, углы прицеливания и паттерны замаха — с компенсацией лага и учётом нарушений по игрокам. Персонал может управлять срабатываниями через игровые команды, GUI настроек, заморозку игроков, оповещения и опциональные уведомления через Discord webhook. Рассчитан на операторов многопользовательских серверов, которым нужна лёгкая защита от читов и инструменты модерации, а не античит на уровне ядра или коммерческие стеки.
