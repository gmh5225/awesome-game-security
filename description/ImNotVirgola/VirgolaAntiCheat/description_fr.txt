VirgolaAntiCheat est un plugin anti-triche côté serveur pour les serveurs Minecraft Paper qui détecte les triches client courantes pendant le jeu. Il est écrit en Java (Maven, Java 21) et intercepte le trafic réseau via PacketEvents, ainsi que les événements Bukkit de déplacement, de combat et de placement de blocs. Les contrôles intégrés couvrent le vol, la vitesse, le scaffold, Jesus (marche sur l’eau), l’absence de chute, les paquets invalides et les abus de combat de type KillAura (portée, angles de visée, motifs de swing), avec compensation du lag et suivi des violations par joueur. Le staff peut gérer les détections via des commandes en jeu, une interface de configuration, le gel des joueurs, des alertes et des notifications webhook Discord optionnelles. Il s’adresse aux opérateurs de serveurs multijoueur qui veulent une prévention légère des triches et des outils de modération plutôt qu’une pile anti-triche au niveau noyau ou commerciale.
