VirgolaAntiCheat는 Minecraft Paper 서버용 서버 측 안티치트 플러그인으로, 게임 중 흔한 클라이언트 치트를 감지합니다. Java(Maven, Java 21)로 작성되었으며 PacketEvents로 네트워크 트래픽을 후킹하고 Bukkit의 이동, 전투, 블록 배치 이벤트에도 연동합니다. 내장 검사는 fly, speed, scaffold, Jesus(물 위 걷기), no-fall, 잘못된 패킷, KillAura류 reach·조준 각도·스윙 패턴 등 전투 남용을 다루며 지연 보상과 플레이어별 위반 추적을 제공합니다. 운영진은 게임 내 명령, 설정 GUI, 플레이어 동결, 알림, 선택적 Discord Webhook 알림으로 감지를 관리할 수 있습니다. 커널 수준이나 상용 안티치트 스택이 아니라 가벼운 치트 방지와 모더레이션 도구를 원하는 멀티플레이 서버 운영자를 대상으로 합니다.
