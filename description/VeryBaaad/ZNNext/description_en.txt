ZNNext is an open-source, from-scratch Magisk-style Android module that loads third-party modules built for the ZygiskNext API instead of implementing generic Zygisk. Its core is a native C++ loader injected into processes and wired to many inline and PLT hook backends, coordinated by a Rust daemon that can drive injection with optional kernel-assisted process tracking such as tracefs, the proc connector, or eBPF. The project also ships a KernelSU WebUI built with Vue and TypeScript for managing configuration from the root manager, plus build and packaging scripts that produce installable zips for Magisk, KernelSU, or APatch on a wide range of Android and kernel versions. It is aimed at Android modding and development audiences who need programmable hooking and runtime injection on rooted devices, including reverse engineering and security research workflows that sit alongside mobile game tooling ecosystems.
