ZNNext 是一款从零实现的开源、Magisk 风格 Android 模块，用于加载面向 ZygiskNext API 构建的第三方模块，而非实现通用 Zygisk。其核心是一个注入到进程中的原生 C++ 加载器，并连接多种 inline 与 PLT hook 后端，由 Rust 守护进程协调注入，并可选借助内核辅助的进程跟踪（如 tracefs、proc connector 或 eBPF）。项目还附带基于 Vue 与 TypeScript 的 KernelSU WebUI，便于从 root 管理器侧管理配置，以及用于构建与打包的脚本，可生成适用于多种 Android 与内核版本、在 Magisk、KernelSU 或 APatch 上可安装的 zip。面向需要在已 root 设备上进行可编程 hook 与运行时注入的 Android 魔改与开发人群，包括与移动游戏工具生态并存的逆向与安全研究工作流。
