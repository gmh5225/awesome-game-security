ZNNext — открытый с нуля модуль Android в духе Magisk, который загружает сторонние модули, собранные под API ZygiskNext, вместо реализации «универсального» Zygisk. В его основе — нативный C++-лоадер, внедряемый в процессы и связанный со множеством inline- и PLT-hook бэкендов; координацию выполняет демон на Rust, который может управлять внедрением с опциональным ядровым отслеживанием процессов через tracefs, proc connector или eBPF. В проекте также есть WebUI для KernelSU на Vue и TypeScript для настройки из root-менеджера и скрипты сборки и упаковки, формирующие устанавливаемые zip для Magisk, KernelSU или APatch на широком диапазоне версий Android и ядра. Аудитория — модификация и разработка под Android тем, кому нужны программируемые хуки и инъекция в рантайме на рутованных устройствах, включая реверс-инжиниринг и исследования безопасности в контексте экосистем инструментов для мобильных игр.
