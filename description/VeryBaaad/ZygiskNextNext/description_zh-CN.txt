Zygisk Next Next 是一款开源 Magisk 模块，从零重新实现 ZygiskNext 模块 API，使第三方模块可在不依赖闭源 ZygiskNext 运行时的情况下加载。注入目标进程的原生 C++ 加载器会加载匹配的模块，并通过 Dobby、ShadowHook、rv64hook、LSPlt、ByteHook、xHook、PLTI 等后端提供 inline 与 PLT 挂钩能力，还支持 HyperOS Runtime 以应对高级注入场景。Rust 编写的注入守护进程负责进程注入与控制，包括基于 ptrace 的操作以及可选的 eBPF 辅助功能，Gradle 则将产物打包供 Magisk、KernelSU 或 APatch 在 Android 5 至当前版本上使用。面向在已 root 的 Android 上开发或研究 ZygiskNext 风格挂钩模块的开发者与研究人员，涵盖游戏修改、运行时插桩以及移动端逆向等相关工作。
