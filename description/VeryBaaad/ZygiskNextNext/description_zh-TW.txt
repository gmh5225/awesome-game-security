Zygisk Next Next 是一款開源 Magisk 模組，從零重新實作 ZygiskNext 模組 API，使第三方模組可在不依賴閉源 ZygiskNext 執行環境的情況下載入。注入目標程序的原生 C++ 載入器會載入相符的模組，並透過 Dobby、ShadowHook、rv64hook、LSPlt、ByteHook、xHook、PLTI 等後端提供 inline 與 PLT 掛鉤能力，另支援 HyperOS Runtime 以應對進階注入情境。以 Rust 撰寫的注入守護程序負責程序注入與控制，包含基於 ptrace 的操作以及可選的 eBPF 輔助功能，Gradle 則將產物打包供 Magisk、KernelSU 或 APatch 在 Android 5 至目前版本上使用。面向在已 root 的 Android 上開發或研究 ZygiskNext 風格掛鉤模組的開發者與研究人員，涵蓋遊戲修改、執行期插樁以及行動端逆向等相關工作。
