Zygisk Next Next は、クローズドソースの ZygiskNext ランタイムに依存せずサードパーティモジュールを読み込めるよう、ZygiskNext モジュール API を一から再実装したオープンソースの Magisk モジュールです。対象プロセスに注入されたネイティブ C++ ローダーが一致するモジュールを読み込み、Dobby、ShadowHook、rv64hook、LSPlt、ByteHook、xHook、PLTI などのバックエンドを通じてインラインおよび PLT フックを提供し、高度な注入シナリオ向けに HyperOS Runtime もサポートします。Rust 製のインジェクターデーモンがプロセス注入と制御（ptrace ベースの操作やオプションの eBPF ヘルパーを含む）を担い、Gradle が Magisk、KernelSU、APatch 向けに Android 5 から現行版までパッケージ化します。root 済み Android 上で ZygiskNext 系フックモジュールを開発・研究する開発者や研究者向けで、ゲーム改造、ランタイム計装、モバイル上のリバースエンジニアリングなどを対象とします。
