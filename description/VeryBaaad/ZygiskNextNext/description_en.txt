Zygisk Next Next is an open-source Magisk module that reimplements the ZygiskNext module API from scratch so third-party modules can be loaded without relying on the closed-source ZygiskNext runtime. A native C++ loader injected into target processes loads matching modules and exposes inline and PLT hooking through backends such as Dobby, ShadowHook, rv64hook, LSPlt, ByteHook, xHook, and PLTI, plus HyperOS Runtime support for advanced injection scenarios. A Rust injector daemon handles process injection and control, including ptrace-based operations and optional eBPF helpers, while Gradle packages the result for Magisk, KernelSU, or APatch on Android 5 through current releases. It is aimed at rooted Android developers and researchers who build or study ZygiskNext-style hook modules, including work around game modding, runtime instrumentation, and reverse engineering on mobile.
