Zygisk Next Next는 폐쇄형 ZygiskNext 런타임에 의존하지 않고 서드파티 모듈을 로드할 수 있도록 ZygiskNext 모듈 API를 처음부터 다시 구현한 오픈 소스 Magisk 모듈입니다. 대상 프로세스에 주입된 네이티브 C++ 로더가 일치하는 모듈을 로드하고, Dobby, ShadowHook, rv64hook, LSPlt, ByteHook, xHook, PLTI 같은 백엔드를 통해 인라인 및 PLT 후킹을 제공하며, 고급 주입 시나리오를 위해 HyperOS Runtime도 지원합니다. Rust로 작성된 인젝터 데몬이 ptrace 기반 작업과 선택적 eBPF 헬퍼를 포함한 프로세스 주입 및 제어를 담당하고, Gradle이 Android 5부터 최신 버전까지 Magisk, KernelSU 또는 APatch용으로 결과물을 패키징합니다. 루팅된 Android에서 ZygiskNext 스타일 후크 모듈을 만들거나 연구하는 개발자와 연구자를 대상으로 하며, 게임 모딩, 런타임 계측, 모바일 리버스 엔지니어링 등과 관련된 작업을 포함합니다.
