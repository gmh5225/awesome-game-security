本プロジェクトは、ネイティブの libc コードと Java/ART ランタイムの両方をフックすることで、Android で一般的な root 検知と動的インストルメンテーション検知を回避する Frida 用 JavaScript スクリプトです。ネイティブ側のインターセプターは /proc maps 読み取りから Frida 関連のエントリを除外し、システムプロパティの偽装、典型的な su や Magisk パスへのアクセス阻止、マウントテーブルのサニタイズが可能です。Java 側のフックは Build フィールドの偽装、su 関連シェルコマンドの拒否、PackageManager および Binder API から root マネージャーパッケージを隠します。Magisk、KernelSU、APatch、SuperSU、LSPosed、Frida 自体を整合性検査や改ざん防止チェックで探すアプリ向けの環境を想定しています。root 済みテスト端末や gadget 注入ビルドで Frida の spawn モードで読み込むことを想定し、モバイル逆コンパイルエンジニア、セキュリティ研究者、ゲームやアプリのアンチチートおよび root 検知ロジックを研究する実務者を対象としています。実装は Apache 2.0 ライセンスの単一 JavaScript モジュールとして提供されます。
