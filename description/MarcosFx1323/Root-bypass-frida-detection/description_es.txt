Este proyecto es un script JavaScript de Frida que evade las comprobaciones habituales de root e instrumentación dinámica en Android al hacer hook tanto del código libc nativo como del runtime Java/ART. Los interceptores nativos filtran entradas relacionadas con Frida en las lecturas de /proc maps y pueden falsificar propiedades del sistema, bloquear el acceso a rutas típicas de su y Magisk y sanear tablas de montaje, mientras que los hooks del lado Java falsifican campos Build, deniegan comandos shell relacionados con su y ocultan paquetes de gestores root ante PackageManager y las API Binder. Está orientado a entornos donde las aplicaciones buscan Magisk, KernelSU, APatch, SuperSU, LSPosed y Frida en sí durante comprobaciones de integridad o anti-manipulación. El script está pensado para cargarse con Frida en modo spawn en un dispositivo de prueba con root o builds con gadget inyectado, y va dirigido a ingenieros inversos móviles, investigadores de seguridad y profesionales que estudian la lógica anti-trampas y de detección de root en juegos o aplicaciones. La implementación se entrega como un único módulo JavaScript bajo licencia Apache 2.0.
