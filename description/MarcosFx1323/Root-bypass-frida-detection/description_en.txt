This project is a Frida JavaScript script that evades common Android root and dynamic instrumentation checks by hooking both native libc code and the Java/ART runtime. Native interceptors filter Frida-related entries from /proc maps reads and can spoof system properties, block access to typical su and Magisk paths, and sanitize mount tables, while Java-side hooks spoof Build fields, deny su-related shell commands, and hide root manager packages from PackageManager and Binder APIs. It targets environments where apps probe for Magisk, KernelSU, APatch, SuperSU, LSPosed, and Frida itself during integrity or anti-tamper checks. The script is meant to be loaded with Frida in spawn mode on a rooted test device or gadget-injected builds, and is aimed at mobile reverse engineers, security researchers, and practitioners studying game or app anti-cheat and root-detection logic. Implementation is delivered as a single JavaScript module under the Apache 2.0 license.
