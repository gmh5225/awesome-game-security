Ce projet est un script JavaScript Frida qui contourne les contrôles courants de root et d’instrumentation dynamique sur Android en hookant à la fois le code libc natif et le runtime Java/ART. Les intercepteurs natifs filtrent les entrées liées à Frida lors des lectures de /proc maps, peuvent falsifier les propriétés système, bloquer l’accès aux chemins typiques de su et Magisk, et assainir les tables de montage, tandis que les hooks côté Java falsifient les champs Build, refusent les commandes shell liées à su et masquent les paquets de gestionnaires root pour PackageManager et les API Binder. Il cible les environnements où les applications recherchent Magisk, KernelSU, APatch, SuperSU, LSPosed et Frida lui-même lors de contrôles d’intégrité ou anti-altération. Le script est conçu pour être chargé avec Frida en mode spawn sur un appareil de test rooté ou des builds injectés par gadget, et s’adresse aux ingénieurs reverse mobile, chercheurs en sécurité et praticiens qui étudient la logique anti-triche et de détection de root dans les jeux ou applications. L’implémentation est livrée comme un module JavaScript unique sous licence Apache 2.0.
