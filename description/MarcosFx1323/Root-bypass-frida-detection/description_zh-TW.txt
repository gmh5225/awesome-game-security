本專案是一個 Frida JavaScript 腳本，透過同時 hook 原生 libc 程式碼與 Java/ART 執行階段，規避 Android 上常見的 root 與動態插樁檢測。原生層攔截器會從 /proc maps 讀取中過濾與 Frida 相關的條目，並可偽造系統屬性、阻止存取典型的 su 與 Magisk 路徑並清理掛載表；Java 側 hook 則偽造 Build 欄位、攔截與 su 相關的 shell 命令，並從 PackageManager 與 Binder API 中隱藏 root 管理器套件。它面向應用程式在完整性或防篡改檢查中探測 Magisk、KernelSU、APatch、SuperSU、LSPosed 及 Frida 本身的環境。腳本設計為在已 root 的測試裝置或使用 gadget 注入的建置上，以 Frida spawn 模式載入，供行動端逆向工程師、安全研究人員以及研究遊戲或應用程式反作弊與 root 檢測邏輯的從業者使用。實作為單一 JavaScript 模組，採用 Apache 2.0 授權
