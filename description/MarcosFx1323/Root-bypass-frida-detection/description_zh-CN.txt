本项目是一个 Frida JavaScript 脚本，通过同时 hook 原生 libc 代码与 Java/ART 运行时，规避 Android 上常见的 root 与动态插桩检测。原生层拦截器会从 /proc maps 读取中过滤与 Frida 相关的条目，并可伪造系统属性、阻止访问典型的 su 与 Magisk 路径并清理挂载表；Java 侧 hook 则伪造 Build 字段、拦截与 su 相关的 shell 命令，并从 PackageManager 与 Binder API 中隐藏 root 管理器包。它面向应用在完整性或防篡改检查中探测 Magisk、KernelSU、APatch、SuperSU、LSPosed 及 Frida 本身的环境。脚本设计为在已 root 的测试设备或使用 gadget 注入的构建上，以 Frida spawn 模式加载，供移动端逆向工程师、安全研究人员以及研究游戏或应用反作弊与 root 检测逻辑的从业者使用。实现为单一 JavaScript 模块，采用 Apache 2.0 许可证。
