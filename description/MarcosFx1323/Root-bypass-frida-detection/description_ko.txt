이 프로젝트는 네이티브 libc 코드와 Java/ART 런타임을 모두 후킹하여 Android에서 흔한 루트 및 동적 계측 검사를 우회하는 Frida JavaScript 스크립트입니다. 네이티브 인터셉터는 /proc maps 읽기에서 Frida 관련 항목을 걸러 내고, 시스템 속성을 위조하고, 일반적인 su 및 Magisk 경로 접근을 차단하며 마운트 테이블을 정리할 수 있습니다. Java 쪽 후크는 Build 필드를 위조하고, su 관련 셸 명령을 거부하며, PackageManager와 Binder API에서 루트 관리자 패키지를 숨깁니다. 앱이 무결성 또는 변조 방지 검사 중 Magisk, KernelSU, APatch, SuperSU, LSPosed 및 Frida 자체를 탐지하는 환경을 대상으로 합니다. 루팅된 테스트 기기나 gadget 주입 빌드에서 Frida spawn 모드로 로드하도록 설계되었으며, 모바일 리버스 엔지니어, 보안 연구자, 게임 또는 앱 안티치트 및 루트 탐지 로직을 연구하는 실무자를 위한 것입니다. 구현은 Apache 2.0 라이선스 하의 단일 JavaScript 모듈로 제공됩니다.
