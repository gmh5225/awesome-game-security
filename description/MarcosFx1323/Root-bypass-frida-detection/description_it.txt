Questo progetto è uno script JavaScript per Frida che elude i controlli comuni su root e strumentazione dinamica su Android agganciando sia il codice libc nativo sia il runtime Java/ART. Gli interceptor nativi filtrano le voci legate a Frida dalle letture di /proc maps e possono falsificare le proprietà di sistema, bloccare l’accesso ai percorsi tipici di su e Magisk e sanificare le tabelle di mount, mentre gli hook lato Java falsificano i campi Build, negano comandi shell legati a su e nascondono i pacchetti dei gestori root da PackageManager e dalle API Binder. È pensato per ambienti in cui le app cercano Magisk, KernelSU, APatch, SuperSU, LSPosed e Frida stesso durante controlli di integrità o anti-manomissione. Lo script è destinato a essere caricato con Frida in modalità spawn su un dispositivo di test con root o build con gadget iniettato, ed è rivolto a reverse engineer mobile, ricercatori sulla sicurezza e professionisti che studiano la logica anti-cheat e di rilevamento root in giochi o app. L’implementazione è fornita come singolo modulo JavaScript con licenza Apache 2.0.
