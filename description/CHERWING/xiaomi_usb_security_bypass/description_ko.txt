MIUI 또는 HyperOS를 실행하는 루팅된 Xiaomi 및 Redmi 휴대폰용 Magisk 모듈로, Mi 계정이나 SIM 카드 없이 USB 디버깅 보안 설정, USB 설치, FASTBOOT 플래싱을 활성화합니다. 부팅 시 system.prop과 폴백용 service.sh를 통해 Magisk resetprop으로 persist.security.adbinput, persist.security.adbinstall, persist.fastboot.enable 등의 persist 속성을 1로 강제 설정하며, SELinux가 쓰기를 차단하면 setprop에서 resetprop으로 단계적으로 전환합니다. 이 모듈은 scrcpy, Total Control, monkey, uiautomator 같은 도구를 위한 ADB 입력 주입을 잠금 해제하고, USB를 통한 원격 마우스 및 키보드 제어를 막는 INJECT_EVENTS 권한 오류를 수정합니다. 구현은 주로 셸 스크립트로 이루어지며, 플래시 가능한 모듈 zip을 패키징하는 소형 Python 헬퍼 build_zip.py가 포함되어 있습니다. 벤더 계정 인증 없이 MIUI 기기에서 완전한 USB 디버깅과 입력 주입이 필요한 모바일 개발자, 리버스 엔지니어, 보안 연구자를 대상으로 합니다.
