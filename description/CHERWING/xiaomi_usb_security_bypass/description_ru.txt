Это модуль Magisk для рутированных смартфонов Xiaomi и Redmi с MIUI или HyperOS, который включает настройки безопасности USB-отладки, установку по USB и прошивку через FASTBOOT без аккаунта Mi и SIM-карты. При загрузке он принудительно устанавливает persist-свойства, такие как persist.security.adbinput, persist.security.adbinstall и persist.fastboot.enable, в значение 1 с помощью resetprop Magisk через system.prop и резервного service.sh, который при блокировке записи SELinux переключается с setprop на resetprop. Модуль разблокирует ввод через ADB для инструментов вроде scrcpy, Total Control, monkey и uiautomator, устраняя ошибки разрешения INJECT_EVENTS, которые иначе мешают удалённому управлению мышью и клавиатурой по USB. Реализован в основном на shell-скриптах с небольшим Python-вспомогательным скриптом build_zip.py для упаковки прошиваемого zip-архива модуля. Предназначен для мобильных разработчиков, специалистов по реверс-инжинирингу и исследователей безопасности, которым нужна полная USB-отладка и инъекция ввода на устройствах MIUI без проверки аккаунта производителя.
