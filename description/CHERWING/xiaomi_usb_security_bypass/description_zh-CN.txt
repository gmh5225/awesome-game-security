这是一个适用于已 root 的小米和 Redmi 手机（运行 MIUI 或 HyperOS）的 Magisk 模块，可在无需小米账号或 SIM 卡的情况下启用 USB 调试安全设置、USB 安装以及 FASTBOOT 刷机。它通过 system.prop 和作为备选的 service.sh，在启动时使用 Magisk 的 resetprop 将 persist.security.adbinput、persist.security.adbinstall 和 persist.fastboot.enable 等 persist 属性强制设为 1；当 SELinux 阻止写入时，会降级从 setprop 切换到 resetprop。该模块为 scrcpy、Total Control、monkey 和 uiautomator 等工具解锁 ADB 输入注入，修复 INJECT_EVENTS 权限错误，从而解决通过 USB 进行远程鼠标和键盘控制时遇到的问题。实现主要以 shell 脚本为主，并附带一个小型 Python 辅助脚本 build_zip.py 用于打包可刷写的模块 zip。面向需要在 MIUI 设备上获得完整 USB 调试和输入注入能力、且无需厂商账号验证的移动开发者、逆向工程师和安全研究人员。
