這是一個適用於已 root 的小米與 Redmi 手機（執行 MIUI 或 HyperOS）的 Magisk 模組，可在無需小米帳號或 SIM 卡的情況下啟用 USB 偵錯安全設定、USB 安裝以及 FASTBOOT 刷機。它透過 system.prop 與作為備援的 service.sh，在開機時使用 Magisk 的 resetprop 將 persist.security.adbinput、persist.security.adbinstall 和 persist.fastboot.enable 等 persist 屬性強制設為 1；當 SELinux 阻止寫入時，會降級從 setprop 切換至 resetprop。此模組為 scrcpy、Total Control、monkey 和 uiautomator 等工具解鎖 ADB 輸入注入，修復 INJECT_EVENTS 權限錯誤，從而解決透過 USB 進行遠端滑鼠與鍵盤控制時遇到的問題。實作主要以 shell 腳本為主，並附帶一個小型 Python 輔助腳本 build_zip.py 用於打包可刷寫的模組 zip。面向需要在 MIUI 裝置上取得完整 USB 偵錯與輸入注入能力、且無需廠商帳號驗證的行動開發者、逆向工程師與安全研究人員。
