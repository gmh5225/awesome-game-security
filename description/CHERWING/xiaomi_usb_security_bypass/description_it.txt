Si tratta di un modulo Magisk per smartphone Xiaomi e Redmi con root che eseguono MIUI o HyperOS, che abilita le impostazioni di sicurezza del debug USB, l'installazione USB e il flashing FASTBOOT senza account Mi o scheda SIM. All'avvio imposta a 1 proprietà persist come persist.security.adbinput, persist.security.adbinstall e persist.fastboot.enable tramite resetprop di Magisk, usando system.prop e un fallback service.sh che passa da setprop a resetprop quando SELinux blocca le scritture. Il modulo sblocca l'iniezione di input ADB per strumenti come scrcpy, Total Control, monkey e uiautomator, correggendo errori di permesso INJECT_EVENTS che altrimenti impedirebbero il controllo remoto di mouse e tastiera via USB. È implementato principalmente in script shell, con un piccolo helper Python build_zip.py per impacchettare lo zip del modulo flashabile. È rivolto a sviluppatori mobile, reverse engineer e ricercatori di sicurezza che necessitano di debug USB completo e iniezione di input su dispositivi MIUI senza verifica dell'account del produttore.
