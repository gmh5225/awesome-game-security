これは、MIUI または HyperOS を実行する root 済み Xiaomi および Redmi 端末向けの Magisk モジュールで、Mi アカウントや SIM カードなしで USB デバッグのセキュリティ設定、USB インストール、FASTBOOT フラッシュを有効にします。起動時に system.prop とフォールバック用の service.sh を通じて Magisk の resetprop により persist.security.adbinput、persist.security.adbinstall、persist.fastboot.enable などの persist プロパティを 1 に強制設定し、SELinux が書き込みをブロックした場合は setprop から resetprop へと段階的に切り替えます。本モジュールは scrcpy、Total Control、monkey、uiautomator などのツール向けに ADB 入力注入を解除し、USB 経由のリモートマウス・キーボード操作を妨げる INJECT_EVENTS 権限エラーを修正します。実装は主にシェルスクリプトで行われ、フラッシュ可能なモジュール zip をパッケージ化する小さな Python ヘルパー build_zip.py が付属します。ベンダーアカウント認証なしで MIUI 端末上の完全な USB デバッグと入力注入を必要とするモバイル開発者、リバースエンジニア、セキュリティ研究者を対象としています。
