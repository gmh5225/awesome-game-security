This is a Magisk module for rooted Xiaomi and Redmi phones running MIUI or HyperOS that enables USB debugging security settings, USB install, and FASTBOOT flashing without requiring a Mi account or SIM card. It forces persist properties such as persist.security.adbinput, persist.security.adbinstall, and persist.fastboot.enable to 1 at boot using Magisk resetprop through system.prop and a service.sh fallback that degrades from setprop to resetprop when SELinux blocks writes. The module unlocks ADB input injection for tools like scrcpy, Total Control, monkey, and uiautomator, fixing INJECT_EVENTS permission errors that otherwise prevent remote mouse and keyboard control over USB. It is implemented mainly in shell scripts with a small Python build_zip.py helper to package the flashable module zip. It is aimed at mobile developers, reverse engineers, and security researchers who need full USB debugging and input injection on MIUI devices without vendor account verification.
