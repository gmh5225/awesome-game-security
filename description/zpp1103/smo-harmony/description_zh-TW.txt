smo-harmony 是一個研究與工程工作區，旨在透過高階模擬（HLE）宿主將 Nintendo Switch 版 Super Mario Odyssey 移植到 HarmonyOS NEXT：該宿主執行經翻譯的 ARM64 遊戲模組，並以原生程式碼實作 Horizon 系統服務。專案以 DevEco HAP 應用為核心，包含 C/C++ 宿主層、ArkTS 外殼與 NAPI 橋接，以及將 NVN 圖形 API 回放路徑翻譯為 OpenHarmony 上 Vulkan 的管線。它建立在 NSO 提取與修補工作流程之上，透過組譯嵌入修補後的二進位檔，並以 Python 與 shell 腳本提供大量啟動、分析與建置自動化，用於迭代引導與鑑識。程式庫還記錄了並行的 TotK 相關工作及衍生的中繼資料慣例，面向逆向工程師與平台移植者，研究 Switch 二進位翻譯、主機 GPU API 墊片層與跨平台遊戲執行階段重託管，而非交付可玩的零售版本。
