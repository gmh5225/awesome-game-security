smo-harmony は、Nintendo Switch 版 Super Mario Odyssey を HarmonyOS NEXT へ移植するための研究・エンジニアリングワークスペースであり、翻訳済み ARM64 ゲームモジュールを実行しつつ Horizon システムサービスをネイティブコードで実装する高レベルエミュレーション（HLE）ホストを用いる。プロジェクトの中心は DevEco HAP アプリケーションで、C/C++ ホスト層、ArkTS シェルと NAPI ブリッジ、および NVN グラフィックス API のリプレイ経路を OpenHarmony 上の Vulkan へ翻訳するパスで構成される。NSO の抽出・パッチワークフローを基盤とし、アセンブリ経由でパッチ済みバイナリを埋め込み、Python とシェルスクリプトによる起動・解析・ビルドの自動化を豊富に同梱し、反復的なブリングアップとフォレンジックを支援する。コードベースは並行する TotK 取り組みと派生メタデータ規約も文書化しており、Switch バイナリ翻訳、コンソール GPU API シム層、クロスプラットフォームゲームランタイムのリホスティングを研究するリバースエンジニアとプラットフォーム移植者を対象とし、プレイ可能なリテールビルドの提供を目的としない。
