smo-harmony는 Nintendo Switch Super Mario Odyssey를 HarmonyOS NEXT로 이식하기 위한 연구 및 엔지니어링 워크스페이스로, 번역된 ARM64 게임 모듈을 실행하면서 Horizon 시스템 서비스를 네이티브 코드로 구현하는 고수준 에뮬레이션(HLE) 호스트를 사용한다. 프로젝트는 DevEco HAP 애플리케이션을 중심으로 C/C++ 호스트 계층, ArkTS 셸 및 NAPI 브리지, NVN 그래픽 API 재생 경로를 OpenHarmony에서 Vulkan으로 번역하는 경로로 구성된다. NSO 추출 및 패치 워크플로를 기반으로 하며, 어셈블리를 통해 패치된 바이너리를 내장하고 Python 및 셸 스크립트로 광범위한 부팅·분석·빌드 자동화를 제공하여 반복적인 브링업과 포렌식을 지원한다. 코드베이스는 병렬 TotK 작업과 파생 메타데이터 규약도 문서화하며, Switch 바이너리 번역, 콘솔 GPU API 심 레이어, 크로스 플랫폼 게임 런타임 리호스팅을 연구하는 리버스 엔지니어와 플랫폼 포터를 대상으로 하며, 플레이 가능한 리테일 빌드 배포를 목표로 하지 않는다.
