smo-harmony 是一个研究与工程工作区，旨在通过高级仿真（HLE）宿主将 Nintendo Switch 版 Super Mario Odyssey 移植到 HarmonyOS NEXT：该宿主运行经翻译的 ARM64 游戏模块，并以原生代码实现 Horizon 系统服务。项目以 DevEco HAP 应用为核心，包含 C/C++ 宿主层、ArkTS 外壳与 NAPI 桥接，以及将 NVN 图形 API 回放路径翻译为 OpenHarmony 上 Vulkan 的管线。它基于 NSO 提取与修补工作流，通过汇编嵌入修补后的二进制，并以 Python 与 shell 脚本提供大量启动、分析与构建自动化，用于迭代引导和取证。代码库还记录了并行的 TotK 相关工作及衍生的元数据约定，面向逆向工程师与平台移植者，研究 Switch 二进制翻译、主机 GPU API 垫片层与跨平台游戏运行时重托管，而非交付可玩的零售版本。
