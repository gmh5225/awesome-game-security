smo-harmony es un espacio de investigación e ingeniería para portar Super Mario Odyssey de Nintendo Switch a HarmonyOS NEXT mediante un host de emulación de alto nivel (HLE) que ejecuta módulos de juego ARM64 traducidos e implementa los servicios del sistema Horizon en código nativo. El proyecto se centra en una aplicación HAP de DevEco con capas host en C y C++, una shell ArkTS y un puente NAPI, y una ruta de reproducción de la API gráfica NVN traducida a Vulkan en OpenHarmony. Se apoya en flujos de extracción y parcheo NSO, incorpora binarios parcheados vía ensamblador y ofrece automatización amplia de arranque, análisis y compilación en Python y scripts shell para bring-up iterativo y forense. La base de código también documenta un esfuerzo TotK en paralelo y convenciones de metadatos derivadas, y está dirigida a ingenieros inversos y portadores de plataforma que estudian la traducción binaria de Switch, capas shim de API GPU de consola y rehosting de runtime de juegos multiplataforma, en lugar de entregar una build retail jugable.
