smo-harmony is a research and engineering workspace for porting Nintendo Switch Super Mario Odyssey to HarmonyOS NEXT using a high-level emulation (HLE) host that runs translated ARM64 game modules while implementing Horizon system services in native code. The project centers on a DevEco HAP application with C and C++ host layers, an ArkTS shell and NAPI bridge, and an NVN graphics API replay path translated to Vulkan on OpenHarmony. It builds on NSO extraction and patching workflows, embeds patched binaries via assembly, and ships extensive boot, analysis, and build automation in Python and shell scripts for iterative bring-up and forensics. The codebase also documents a parallel TotK effort and derived metadata conventions, and it is aimed at reverse engineers and platform porters studying Switch binary translation, console GPU API shim layers, and cross-platform game runtime rehosting rather than at shipping a playable retail build.
