VDBackup は root 化された Android 向けモジュールで、KernelSU・APatch・Magisk 上でブラウザベースの WebUI からインストール済みアプリとそのデータのバックアップとリストアを行います。実装は主に POSIX シェルスクリプトで、素の JavaScript フロントエンド、任意の Kotlin コンパニオン、自動化用の JSON 駆動ヘルパー API で構成されています。完全な tar.zst アーカイブ、暗号化 restic スナップショット、rclone または rsync ミラーに対応し、APK 分割、プライベートおよび外部アプリデータ、OBB、権限、AppOps、root が許す場合は任意の SSAID も取得します。任意のポータブル暗号化、整合性チェック、選択的リストア、スケジューリング、Neo-Backup および Android-DataBackup からのインポート経路により、root 端末上でゲームインストールや保護されたモバイルアプリ状態の信頼できる移行とオフラインコピーを必要とする研究者やパワーユーザーに適しています。
