VDBackup은 루팅된 Android용 모듈로, KernelSU·APatch·Magisk 환경에서 브라우저 기반 WebUI를 통해 설치된 앱과 데이터를 백업·복원합니다. 구현은 주로 POSIX 셸 스크립트이며, 순수 JavaScript 프런트엔드, 선택적 Kotlin 컴패니언, 자동화용 JSON 기반 헬퍼 API로 구성됩니다. 전체 tar.zst 아카이브, 암호화된 restic 스냅샷, rclone 또는 rsync 미러를 지원하고 APK 분할, 비공개·외부 앱 데이터, OBB, 권한, AppOps, 루트가 허용할 때 선택적 SSAID를 포착합니다. 선택적 휴대용 암호화, 무결성 검사, 선택적 복원, 예약, Neo-Backup 및 Android-DataBackup에서의 가져오기 경로를 통해 루팅 기기에서 게임 설치와 보호된 모바일 앱 상태의 안정적인 이전 및 오프라인 사본이 필요한 연구자와 고급 사용자에게 적합합니다.
