VDBackup est un module Android rooté qui sauvegarde et restaure les applications installées et leurs données via une WebUI basée sur le navigateur sous KernelSU, APatch ou Magisk. Il est implémenté principalement en scripts shell POSIX avec un front-end JavaScript vanilla, des composants Kotlin optionnels et une API d’aide pilotée par JSON pour l’automatisation. L’outil prend en charge les archives tar.zst complètes, les instantanés restic chiffrés et les miroirs rclone ou rsync, tout en capturant les splits APK, les données privées et externes des apps, les OBB, les permissions, les AppOps et éventuellement le SSAID lorsque le root le permet. Le chiffrement portable optionnel, les contrôles d’intégrité, la restauration sélective, la planification et les chemins d’import depuis Neo-Backup et Android-DataBackup le rendent adapté aux chercheurs et utilisateurs avancés qui ont besoin d’une migration fiable et de copies hors ligne des installations de jeux et de l’état d’applications mobiles protégées sur appareils rootés.
