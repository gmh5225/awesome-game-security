VDBackup es un módulo de Android con root que respalda y restaura aplicaciones instaladas y sus datos mediante una WebUI basada en el navegador en KernelSU, APatch o Magisk. Está implementado principalmente como scripts shell POSIX con un front-end en JavaScript vanilla, piezas complementarias opcionales en Kotlin y una API auxiliar impulsada por JSON para automatización. La herramienta admite archivos tar.zst completos, instantáneas restic cifradas y espejos rclone o rsync, capturando splits de APK, datos privados y externos de apps, OBB, permisos, AppOps y SSAID opcional cuando el root lo permite. El cifrado portable opcional, comprobaciones de integridad, restauración selectiva, programación y rutas de importación desde Neo-Backup y Android-DataBackup lo hacen adecuado para investigadores y usuarios avanzados que necesitan migración fiable y copias sin conexión de instalaciones de juegos y del estado de apps móviles protegidas en dispositivos con root.
