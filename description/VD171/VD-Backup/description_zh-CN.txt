VDBackup 是一款面向已 root 的 Android 模块，可在 KernelSU、APatch 或 Magisk 环境下通过基于浏览器的 WebUI 备份与恢复已安装应用及其数据。实现上主要由 POSIX shell 脚本构成，辅以原生 JavaScript 前端、可选的 Kotlin 组件，以及用于自动化的 JSON 驱动辅助 API。该工具支持完整的 tar.zst 归档、加密的 restic 快照，以及 rclone 或 rsync 镜像，并会捕获 APK 分包、应用私有与外部数据、OBB、权限、AppOps，以及在 root 允许时的可选 SSAID。可选的可移植加密、完整性校验、选择性恢复、计划任务，以及从 Neo-Backup 与 Android-DataBackup 导入的路径，使其适合需要在已 root 设备上可靠迁移游戏安装包并离线保存受保护移动应用状态的研究者与高级用户。
