VDBackup — модуль для Android с root-доступом, который создаёт резервные копии установленных приложений и их данных и восстанавливает их через браузерную WebUI на KernelSU, APatch или Magisk. Реализован в основном на POSIX shell-скриптах с фронтендом на чистом JavaScript, опциональными компонентами на Kotlin и вспомогательным API на JSON для автоматизации. Инструмент поддерживает полные архивы tar.zst, зашифрованные снимки restic и зеркала rclone или rsync, захватывая split APK, приватные и внешние данные приложений, OBB, разрешения, AppOps и при возможности опциональный SSAID при наличии root. Опциональное переносимое шифрование, проверки целостности, выборочное восстановление, планирование и импорт из Neo-Backup и Android-DataBackup делают его подходящим для исследователей и продвинутых пользователей, которым нужна надёжная миграция и офлайн-копии игровых установок и защищённого состояния мобильных приложений на устройствах с root.
