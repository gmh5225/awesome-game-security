VDBackup is a rooted Android module that backs up and restores installed applications and their data through a browser-based WebUI on KernelSU, APatch, or Magisk. It is implemented mainly as POSIX shell scripts with a vanilla JavaScript front end, optional Kotlin companion pieces, and a JSON-driven helper API for automation. The tool supports full tar.zst archives, encrypted restic snapshots, and rclone or rsync mirrors while capturing APK splits, private and external app data, OBB, permissions, AppOps, and optional SSAID when root allows. Optional portable encryption, integrity checks, selective restore, scheduling, and import paths from Neo-Backup and Android-DataBackup make it suited for researchers and power users who need reliable migration and offline copies of game installs and protected mobile app state on rooted devices.
