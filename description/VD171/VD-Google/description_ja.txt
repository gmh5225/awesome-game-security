VD Google は root 済み Android アプリおよび任意のフラッシュ可能な WebUI モジュールで、ネットワークを使わずに Google が RCS メッセージ、Google Wallet、DroidGuard、Play Integrity についてローカルに記録している内容を調査します。主に Kotlin と Jetpack Compose、Material 3 で構築され、スーパーユーザー権限でシステム保護されたデータベースとキャッシュを読み取り、デバイス上でのクエリ用に同梱の sqlite3 ヘルパーを提供します。RCS と Wallet の認証状態、Play Protect 認証、有効期限付きのキャッシュされた整合性認証、最近 Play Integrity チェックを要求したアプリを表示し、平易な説明と JSON エクスポートで自動デバイスレビューに対応します。権限は一切宣言せず（インターネットも含めない）、KernelSU、APatch、Magisk 環境を想定し、セキュリティ研究者、プライバシー重視の上級ユーザー、Android のモバイル認証と不正利用対策シグナルを分析する人向けです。
