Universal Modder는 보유한 PC 게임용 MOD를 AI 코딩 에이전트가 계획·구축·검증할 수 있게 하는 툴킷이자 공유 지식 베이스입니다. 핵심은 uv로 설치하는 Python um CLI로, 설치본·엔진 스캔, 세이브 백업, fal 또는 ComfyUI로 아트 생성·처리, Blender 기반 3D→스프라이트 렌더링, Windows 실행·캡처 자동화, 배포 전 검사를 수행합니다. Agent Skills에는 MOD 제작 전체 루프와 엔진별 플레이북, 웹 조사, 에셋 파이프라인, 매시업 MOD, Ghidra·ILSpy·Cheat Engine·Frida 등을 쓰는 리버스 엔지니어링 워크플로가 문서화되어 있습니다. 검색 가능한 지식 베이스는 이전 MOD의 현장 메모를 모아 에이전트가 경로·버전·검증 단계를 재사용하게 합니다. 합법적인 싱글플레이 및 자체 호스트 MOD·연구를 대상으로 하며, 안티치트·DRM 우회나 온라인 치팅은 명시적으로 금지합니다.
