Universal Modder 是一套工具包與共享知識庫，讓 AI 程式設計代理能為你已擁有的 PC 遊戲規劃、建置並驗證模組。其核心是透過 uv 安裝的 Python um CLI，用於掃描安裝與引擎、備份存檔、以 fal 或 ComfyUI 產生與處理美術資源、基於 Blender 的 3D 轉 sprite 渲染、Windows 啟動與擷取自動化，以及發布前檢查。Agent Skills 記載完整的模組製作流程，以及各引擎操作手冊、網路研究、資產管線、混搭模組與逆向工程工作流程，涉及 Ghidra、ILSpy、Cheat Engine、Frida 等工具。可搜尋的知識庫彙整過往模組的實地筆記，供代理重用路徑、版本與驗證步驟。鎖定合法的單機與自架模組製作與研究，並明確禁止繞過反作弊、DRM 或線上多人作弊。
