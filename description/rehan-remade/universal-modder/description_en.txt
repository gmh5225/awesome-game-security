Universal Modder is a toolkit and shared knowledge base that lets AI coding agents plan, build, and verify mods for PC games you own. It centers on a Python um CLI (installed via uv) for scanning installs and engines, backing up saves, generating and processing art with fal or ComfyUI, Blender-based 3D-to-sprite rendering, Windows launch and capture automation, and publishing checks. Agent Skills document a full modding loop plus engine playbooks, web research, asset pipelines, mashup mods, and reverse-engineering workflows using tools such as Ghidra, ILSpy, Cheat Engine, and Frida. A searchable knowledge base collects field notes from prior mods so agents can reuse routes, versions, and verification steps. It targets legitimate single-player and self-hosted modding and research, with explicit rules against bypassing anti-cheat, DRM, or cheating in online play.
