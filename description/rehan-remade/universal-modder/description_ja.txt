Universal Modder は、所有する PC ゲーム向けに AI コーディングエージェントが MOD の計画・構築・検証を行えるツールキット兼共有ナレッジベースです。中核は uv 経由でインストールする Python の um CLI で、インストールとエンジンのスキャン、セーブのバックアップ、fal や ComfyUI によるアート生成・処理、Blender ベースの 3D からスプライトへのレンダリング、Windows の起動・キャプチャ自動化、公開前チェックを担います。Agent Skills には MOD 制作の一連のループに加え、エンジン別プレイブック、Web 調査、アセットパイプライン、マッシュアップ MOD、Ghidra・ILSpy・Cheat Engine・Frida などを用いたリバースエンジニアリングのワークフローが文書化されています。検索可能なナレッジベースは過去 MOD の現場メモを集約し、エージェントがルート・バージョン・検証手順を再利用できます。合法的なシングルプレイおよび自己ホスト型の MOD 制作・研究を対象とし、アンチチートや DRM の回避、オンラインでの不正行為は明示的に禁止しています。
