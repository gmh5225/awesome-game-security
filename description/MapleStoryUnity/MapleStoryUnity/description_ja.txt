MapleStoryUnity は Unity ベースの MapleStory ゲームクライアント再実装で、公式 WZ アセットアーカイブを読み込み、MapleStory 互換サーバーに接続します。主に C# で記述され、暗号化 WZ ファイルの解析に WzLib、AES および MapleStory 独自のパケット暗号化に MapleCryptoLib、2D キャラクター操作・UI・クライアント側ネットワーキング（パケットエンコーダー、デコーダー、ログインハンドラー付き）に JCSUnity フレームワークを統合しています。プロジェクトにはマップとサウンドの読み込み、キャラクター能力値管理、コアゲームプレイシステムが含まれ、Unity 内で MapleStory クライアントの挙動を再現します。MapleStory クライアントアーキテクチャ、ネットワークプロトコル、アセット形式を研究するリバースエンジニア、プライベートサーバー開発者、ゲームセキュリティ研究者向けです。
