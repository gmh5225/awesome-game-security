hiumod — внешний вспомогательный инструмент для Hell Is Us на PC, который во время игры добавляет живую миникарту, трекер квестов, сюжетный гид, ответы на сейфы и головоломки, чек-листы коллекционных предметов и необязательные читы для одиночной игры. Написан на Rust, подключается к процессу игры и читает или записывает память Unreal Engine на лету, не изменяя файлы на диске. Он находит состояние игры, сканируя структуры движка, такие как name pool и GEngine, затем использует рефлексию UObject для определения атрибутов игрока по имени, а не по фиксированным смещениям, с графическим оверлеем, диагностическими CLI-командами и инструментом обследования на C#, построенным на CUE4Parse для данных гида. Предназначен для игроков, которым нужна улучшенная навигация и помощь в прохождении, а также для разработчиков, изучающих внешнее подключение к процессам и интроспекцию памяти Unreal Engine в офлайн-играх для одного игрока.
