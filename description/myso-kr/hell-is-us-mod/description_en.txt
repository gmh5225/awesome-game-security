hiumod is an external companion tool for Hell Is Us on PC that adds a live minimap, quest tracker, story guide, vault and puzzle answers, collectible checklists, and optional single-player cheats while the game runs. Written in Rust, it attaches to the game process and reads or writes Unreal Engine memory in place without changing any files on disk. It locates game state by scanning for engine structures such as the name pool and GEngine, then follows UObject reflection to resolve player attributes by name instead of fixed offsets, with a graphical overlay, diagnostic CLI commands, and a C# survey tool built on CUE4Parse for guide data. It serves players who want enhanced navigation and completion aids, and developers studying external process attachment and Unreal Engine memory introspection for offline, single-player games.
