Peak Sentinel is a prototype anti-cheat BepInEx 5 plugin for the multiplayer game PEAK that detects and optionally blocks illegitimate item manipulation by attributing actions to the Photon network message sender, which the server assigns and clients cannot spoof. It is implemented in C# for Unity and uses Harmony to hook Photon RPC execution and network instantiation, applying RpcAudit and InstantiateAudit rules for spawn-in-hand cheats, forged pickups, inventory rewrites, clones, and suspicious creates. When the local player is host, configurable protection can refuse cheat and spawner-mod requests while allowing vanilla grants such as airport passports and legitimate host spawns. Reporting includes an F6 manager window with scrollable findings, in-game connection-feed alerts, BepInEx logging, and an optional debug trace file. It targets PEAK hosts and mod users who want lightweight host-side game security against item-spawn cheats rather than kernel-level or commercial anti-cheat stacks.
