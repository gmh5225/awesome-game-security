Peak Sentinel 是一款面向多人游戏 PEAK 的反作弊 BepInEx 5 插件原型，通过将行为归因于 Photon 网络消息发送方（由服务器分配、客户端无法伪造）来检测并可选择阻止非法物品操作。它以 C# 为 Unity 实现，使用 Harmony 挂钩 Photon RPC 执行与网络实例化，并应用 RpcAudit 与 InstantiateAudit 规则，应对手持刷物、伪造拾取、背包改写、克隆及可疑创建等作弊。当本地玩家为主机时，可配置的保护可拒绝作弊与刷物模组请求，同时仍允许机场护照等原版发放及合法主机生成。报告功能包括带可滚动结果的 F6 管理窗口、游戏内连接 feed 提醒、BepInEx 日志以及可选的调试追踪文件。它面向 PEAK 主机与模组用户，提供轻量级主机侧物品刷取类作弊防护，而非内核级或商业反作弊方案。
