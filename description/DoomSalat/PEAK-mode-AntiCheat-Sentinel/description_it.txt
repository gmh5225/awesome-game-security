Peak Sentinel è un prototipo di plugin anti-cheat BepInEx 5 per il gioco multigiocatore PEAK che rileva e opzionalmente blocca la manipolazione illegittima degli oggetti attribuendo le azioni al mittente dei messaggi di rete Photon, assegnato dal server e non falsificabile dai client. È implementato in C# per Unity e usa Harmony per intercettare l’esecuzione delle RPC Photon e l’instanziazione di rete, applicando le regole RpcAudit e InstantiateAudit contro cheat di spawn in mano, raccolte falsificate, riscritture dell’inventario, cloni e creazioni sospette. Quando il giocatore locale è host, una protezione configurabile può rifiutare richieste di cheat e mod spawner consentendo concessioni vanilla come passaporti aeroportuali e spawn legittimi dell’host. I report includono una finestra manager F6 con risultati scorrevoli, avvisi nel feed di connessione in gioco, logging BepInEx e un file di trace di debug opzionale. È rivolto ad host PEAK e utenti di mod che vogliono sicurezza leggera lato host contro cheat di spawn oggetti, piuttosto che stack anti-cheat a livello kernel o commerciali.
