Peak Sentinel は、マルチプレイゲーム PEAK 向けの反チート BepInEx 5 プラグインのプロトタイプで、Photon ネットワークメッセージの送信者（サーバーが割り当て、クライアントは偽装不可）に行為を帰属させ、不正なアイテム操作を検出し、必要に応じてブロックします。Unity 向けに C# で実装され、Harmony で Photon RPC 実行とネットワークインスタンス化をフックし、手元スポーン、偽造ピックアップ、インベントリ書き換え、クローン、疑わしい生成などに RpcAudit と InstantiateAudit ルールを適用します。ローカルプレイヤーがホストのとき、設定可能な保護によりチートやスポナーモッドの要求を拒否しつつ、空港パスポートなどのバニラ付与や正当なホストスポーンは許可できます。報告には、スクロール可能な結果付き F6 管理ウィンドウ、ゲーム内接続フィード通知、BepInEx ログ、任意のデバッグトレースファイルが含まれます。カーネルレベルや商用反チートスタックではなく、PEAK ホストと MOD 利用者向けの、軽量なホスト側アイテムスポーン系チート対策を目指しています。
