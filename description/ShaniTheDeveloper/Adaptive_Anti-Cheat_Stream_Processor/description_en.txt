Adaptive Anti-Cheat Stream Processor is a desktop system that analyzes simulated gameplay telemetry in real time to flag potentially suspicious competitive-gaming behavior. It is implemented in C++17 with a Qt 6 widget-based dashboard that presents logs, alerts, and processing statistics while a stream-processing engine ingests events continuously. The design applies data structures and algorithms such as Bloom filters, count-min sketches, sliding time windows, queues, circular buffers, and hash-based indexing for memory-efficient signature checks, frequency estimation, and temporal pattern analysis. It supports anomaly scoring with configurable thresholds, detection of rapid or repeated inputs, movement velocity and aim-vector monitoring, and performance metrics including throughput, latency, and memory use. The project targets game security and anti-cheat education and prototyping, treating alerts as investigation hints rather than definitive cheat verdicts.
