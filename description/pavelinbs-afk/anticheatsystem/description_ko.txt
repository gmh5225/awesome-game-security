Counter-Strike 2용 서버 측 안티치트 플러그인으로, 전용 Linux 게임 서버에서 MetaMod:Source 2 네이티브 모듈로 실행됩니다. C++17과 CMake로 작성되었으며, 에임 스냅, 월핵 가시성, 이동 속도, 세션 통계, 클라이언트 무결성 검사 등을 모듈형 분석기로 탐지한 뒤 결과를 설정 가능한 의심 점수로 집계합니다. 임계값에 도달하면 AdminPlugin 및 PlaytimeReporter 연동을 통해 경고 기록, 모더레이션 신고 제출, 또는 밴 적용을 자동으로 수행하며, 서버 관리 도구와 동일한 제재 및 티켓 API를 사용합니다. JSON 설정으로 탐지 모듈과 점수 한도를 조정할 수 있으며, HL2SDK-CS2 대상 Docker 기반 빌드를 지원해 linuxsteamrt64 호환 배포가 가능합니다. 클라이언트 측이나 외부 서비스에만 의존하지 않고, 프로세스 내에서 서버 권위적으로 치트를 탐지하려는 CS2 서버 운영자를 대상으로 합니다.
