Plugin anti-cheat lato server per Counter-Strike 2 che gira come modulo nativo MetaMod:Source 2 su server di gioco Linux dedicati. Scritto in C++17 con CMake, rileva i cheat tramite analizzatori modulari per aim snapping, visibilità wallhack, velocità di movimento, statistiche di sessione e controlli di integrità del client, quindi aggrega i risultati in un punteggio di sospetto configurabile. Al raggiungimento delle soglie, registra automaticamente avvisi, invia segnalazioni di moderazione o applica ban integrandosi con AdminPlugin e PlaytimeReporter tramite le stesse API di sanzioni e ticket usate dagli strumenti di amministrazione del server. Gli operatori regolano moduli di rilevamento e limiti di punteggio tramite configurazione JSON, e il progetto supporta build basate su Docker contro HL2SDK-CS2 per un deploy compatibile con linuxsteamrt64. È pensato per i proprietari di server CS2 che vogliono un rilevamento cheat in-process e con autorità del server, invece di affidarsi solo al client o a servizi esterni.
