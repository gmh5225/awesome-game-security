A server-side anti-cheat plugin for Counter-Strike 2 that runs as a MetaMod:Source 2 native module on dedicated Linux game servers. Written in C++17 with CMake, it detects cheating through modular analyzers for aim snapping, wallhack visibility, movement speed, session statistics, and client integrity checks, then aggregates findings into a configurable suspicion score. When thresholds are reached, it automatically logs warnings, files moderation reports, or applies bans by integrating with AdminPlugin and PlaytimeReporter over the same sanction and ticket APIs used by server administration tools. Operators tune detection modules and scoring limits through JSON configuration, and the project supports Docker-based builds against HL2SDK-CS2 for compatible linuxsteamrt64 deployment. It is aimed at CS2 server owners who want in-process, server-authoritative cheat detection rather than relying solely on client-side or external services.
