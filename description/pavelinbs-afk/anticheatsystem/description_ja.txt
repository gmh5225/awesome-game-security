Counter-Strike 2 向けのサーバー側アンチチートプラグインで、専用 Linux ゲームサーバー上で MetaMod:Source 2 ネイティブモジュールとして動作します。C++17 と CMake で実装され、エイムスナップ、ウォールハック可視性、移動速度、セッション統計、クライアント整合性チェックなどをモジュール化されたアナライザーで検出し、結果を設定可能な疑わしさスコアに集約します。閾値に達すると、AdminPlugin と PlaytimeReporter 連携により警告の記録、モデレーション報告の提出、または BAN の適用を自動で行い、サーバー管理ツールと同じ制裁・チケット API を利用します。JSON 設定で検出モジュールとスコア上限を調整でき、HL2SDK-CS2 向けの Docker ビルドにより linuxsteamrt64 互換デプロイをサポートします。クライアント側や外部サービスだけに頼らず、プロセス内でサーバー権威的にチート検出を行いたい CS2 サーバー運営者向けです。
