Plugin anti-triche côté serveur pour Counter-Strike 2, exécuté comme module natif MetaMod:Source 2 sur des serveurs de jeu Linux dédiés. Écrit en C++17 avec CMake, il détecte la triche via des analyseurs modulaires pour le snap de visée, la visibilité type wallhack, la vitesse de déplacement, les statistiques de session et les contrôles d'intégrité client, puis agrège les résultats en un score de suspicion configurable. Lorsque les seuils sont atteints, il enregistre automatiquement des avertissements, dépose des rapports de modération ou applique des bannissements en s'intégrant à AdminPlugin et PlaytimeReporter via les mêmes API de sanctions et de tickets que les outils d'administration serveur. Les opérateurs règlent les modules de détection et les limites de score via une configuration JSON, et le projet prend en charge des builds Docker basés sur HL2SDK-CS2 pour un déploiement compatible linuxsteamrt64. Il s'adresse aux propriétaires de serveurs CS2 qui veulent une détection de triche in-process et autoritaire côté serveur, plutôt que de s'appuyer uniquement sur le client ou des services externes.
