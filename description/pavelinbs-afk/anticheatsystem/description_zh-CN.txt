面向 Counter-Strike 2 的服务端反作弊插件，在专用 Linux 游戏服务器上以 MetaMod:Source 2 原生模块运行。项目使用 C++17 与 CMake 编写，通过模块化分析器检测瞄准瞬移、透视可见性、移动速度、会话统计及客户端完整性检查等作弊行为，并将结果汇总为可配置的嫌疑分数。达到阈值后，可通过 AdminPlugin 与 PlaytimeReporter 集成，自动记录警告、提交 moderation 报告或执行封禁，复用与服务器管理工具相同的处罚与工单 API。运维人员可通过 JSON 配置调整检测模块与评分阈值；项目支持基于 Docker 的构建，面向 HL2SDK-CS2 以兼容 linuxsteamrt64 部署。适用于希望在进程内、以服务器权威方式检测作弊，而非仅依赖客户端或外部服务的 CS2 服主。
