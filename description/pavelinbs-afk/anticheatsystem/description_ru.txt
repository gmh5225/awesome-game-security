Серверный античит-плагин для Counter-Strike 2, работающий как нативный модуль MetaMod:Source 2 на выделенных Linux-игровых серверах. Написан на C++17 с CMake; обнаруживает читерство через модульные анализаторы прицеливания (aim snapping), видимости через стены (wallhack), скорости движения, статистики сессии и проверок целостности клиента, затем объединяет результаты в настраиваемый балл подозрительности. При достижении порогов автоматически записывает предупреждения, подаёт отчёты модерации или применяет баны через интеграцию с AdminPlugin и PlaytimeReporter по тем же API санкций и тикетов, что и инструменты администрирования сервера. Операторы настраивают модули обнаружения и лимиты оценки через JSON-конфигурацию; проект поддерживает сборку на Docker против HL2SDK-CS2 для совместимого развёртывания linuxsteamrt64. Предназначен для владельцев CS2-серверов, которым нужно обнаружение читов в процессе с серверной авторитетностью, а не только клиентские или внешние сервисы.
