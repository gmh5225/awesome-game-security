面向 Counter-Strike 2 的伺服器端反作弊外掛，在專用 Linux 遊戲伺服器上以 MetaMod:Source 2 原生模組執行。專案以 C++17 與 CMake 撰寫，透過模組化分析器偵測瞄準瞬移、透視可見性、移動速度、工作階段統計及用戶端完整性檢查等作弊行為，並將結果彙整為可設定的嫌疑分數。達到閾值後，可透過 AdminPlugin 與 PlaytimeReporter 整合，自動記錄警告、提交 moderation 報告或執行封禁，沿用與伺服器管理工具相同的處罰與工單 API。營運者可透過 JSON 設定調整偵測模組與評分上限；專案支援以 Docker 建置，面向 HL2SDK-CS2 以相容 linuxsteamrt64 部署。適合希望在程序內、以伺服器權威方式偵測作弊，而非僅依賴用戶端或外部服務的 CS2 服主。
