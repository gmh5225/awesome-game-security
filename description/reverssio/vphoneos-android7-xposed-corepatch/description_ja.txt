本リポジトリは、VPhoneOS Android 7.1.2 仮想デバイス上で Xposed Framework v89 を構築するための、検証済みドキュメント、シェル自動化、チェックサム、および SDK 25 向けパッチ済み CorePatch ビルドを提供する。ゲストの system パーティションへの Xposed のフラッシュ、Xposed Installer のインストール、APK 署名検査をバイパスして ADB 経由で未署名パッケージをインストールできる CorePatch フックの有効化までを解説する。同梱の Java Xposed モジュールは PackageParser の証明書収集および関連する暗号検証パスを差し替え、Magisk や Zygisk なしでバックアップ、フラッシュ、有効化、段階的検証のための bash スクリプトも用意している。改変済みまたは未署名のゲーム・アプリパッケージを解析する再現可能な隔離 Android 7 サンドボックスを必要とし、物理端末に危険な整合性変更を持ち込みたくないセキュリティ研究者およびリバースエンジニア向けである。
