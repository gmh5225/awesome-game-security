本仓库提供经核实的文档、Shell 自动化脚本、校验和，以及面向 SDK 25 的 CorePatch 构建，用于在 VPhoneOS Android 7.1.2 虚拟设备上部署 Xposed Framework v89。内容涵盖向来宾系统分区刷入 Xposed、安装 Xposed Installer，以及启用可绕过 APK 签名校验的 CorePatch 钩子，从而通过 ADB 安装未签名包。所附 Java Xposed 模块重定向 PackageParser 证书收集及相关加密校验路径；项目还提供用于备份、刷写、启用与分阶段验证的 bash 脚本，且无需 Magisk 或 Zygisk。面向需要在可复现、隔离的 Android 7 沙箱中分析被修改或未签名的游戏与应用包、同时避免在实体硬件上实施高风险完整性改动的安全研究人员与逆向工程师。
