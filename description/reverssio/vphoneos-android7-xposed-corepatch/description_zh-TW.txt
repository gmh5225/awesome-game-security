本儲存庫提供經核實的文件、Shell 自動化腳本、校驗和，以及面向 SDK 25 的 CorePatch 建置，用於在 VPhoneOS Android 7.1.2 虛擬裝置上部署 Xposed Framework v89。內容涵蓋向來賓系統分割區刷入 Xposed、安裝 Xposed Installer，以及啟用可繞過 APK 簽章驗證的 CorePatch 鉤子，從而透過 ADB 安裝未簽章套件。所附 Java Xposed 模組重新導向 PackageParser 憑證收集及相關密碼學驗證路徑；專案並提供用於備份、刷寫、啟用與分階段驗證的 bash 腳本，且無需 Magisk 或 Zygisk。面向需要在可重現、隔離的 Android 7 沙箱中分析遭修改或未簽章的遊戲與應用套件、同時避免在實體硬體上實施高風險完整性變更的安全研究人員與逆向工程師。
