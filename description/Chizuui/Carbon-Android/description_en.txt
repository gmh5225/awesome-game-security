Carbon for Android is an unofficial native Android port of the original Xbox edition of Need for Speed: Carbon, produced by statically recompiling the game's x86 XBE executable into C++ rather than emulating the console. The stack combines the XboxXBE-Recomp SDK portable runtime (Xbox kernel and XDK high-level emulation, Direct3D 8) with a custom arm64 host that renders through Vulkan 1.1 and handles windowing, audio, and input via SDL3. The Android layer is built with Gradle and Java, while CMake compiles extensive native C++ including hook and symbol configuration driven by TOML for the recompiler. It ships touch layouts, controller and keyboard remapping, an ImGui settings overlay, and developer-oriented tooling such as log export and optional performance tracing. The project suits reverse engineers and game-security researchers who want a concrete reference for Xbox binary recompilation, graphics API translation, and bringing legacy retail titles to mobile without a full emulator.
