Carbon for Android 是原版 Xbox 版《極速快感：玩命山道》的非官方原生 Android 移植，透過將遊戲的 x86 XBE 可執行檔靜態重編譯為 C++ 實現，而非模擬主機。技術棧結合了 XboxXBE-Recomp SDK 可攜執行階段（Xbox 核心與 XDK 高階模擬、Direct3D 8）與自訂 arm64 宿主，經 Vulkan 1.1 渲染，並透過 SDL3 處理視窗、音訊與輸入。Android 層使用 Gradle 與 Java 建置，CMake 編譯大量原生 C++，重編譯器的掛鉤與符號設定由 TOML 驅動。專案提供觸控版面、手把與鍵盤重對應、ImGui 設定疊層，以及面向開發者的日誌匯出與可選效能追蹤等工具。適合逆向工程師與遊戲安全研究者，作為 Xbox 二進位重編譯、圖形 API 轉換，以及無需完整模擬器便將舊版零售遊戲帶到行動裝置的實例參考。
