Carbon for Android 是原版 Xbox 版《极品飞车：卡本峡谷》的非官方原生 Android 移植，通过将游戏的 x86 XBE 可执行文件静态重编译为 C++ 实现，而非模拟主机。技术栈结合了 XboxXBE-Recomp SDK 便携运行时（Xbox 内核与 XDK 高层模拟、Direct3D 8）与自定义 arm64 宿主，经 Vulkan 1.1 渲染，并通过 SDL3 处理窗口、音频与输入。Android 层使用 Gradle 与 Java 构建，CMake 编译大量原生 C++，重编译器的挂钩与符号配置由 TOML 驱动。项目提供触摸布局、手柄与键盘重映射、ImGui 设置叠层，以及面向开发者的日志导出与可选性能追踪等工具。适合逆向工程师与游戏安全研究者，作为 Xbox 二进制重编译、图形 API 转换以及无需完整模拟器便将遗留零售游戏带到移动端的实例参考。
