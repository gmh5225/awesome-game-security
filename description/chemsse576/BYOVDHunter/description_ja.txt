BYOVD Hunter は、インストール済みおよび読み込み済みのカーネルドライバをスキャンし、Bring Your Own Vulnerable Driver（BYOVD）悪用の兆候を検出する Windows コンソールツールです。C# で .NET Framework 4.8 向けに書かれており、ドライバファイルを LOLDrivers ナレッジベース、Microsoft ブロックリストデータ、カスタムヒューリスティクスと照合し、PE イメージを解析して IRP ディスパッチハンドラ、IOCTL コード、バッファ検証、およびユーザーモードのデバイスパスから物理メモリマッピングやコールバック登録解除など危険なカーネルインポートへの到達可能性をマッピングします。HVCI、ドライバ署名の強制、Secure Boot、VBS、ブロックリスト状態などローカルのハードニング状況も要約し、情報から重大まで所見をランク付けし、任意で JSON または CSV レポートを出力します。カーネルセキュリティ研究、エンドポイント強化、マシン上の悪用可能な署名付きドライバを棚卸しする必要があるアンチチートやゲームセキュリティチームを対象としています。
