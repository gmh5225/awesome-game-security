BYOVD Hunter 是一款 Windows 控制台工具，用于扫描已安装和已加载的内核驱动，以发现 Bring Your Own Vulnerable Driver（BYOVD）滥用的迹象。该工具使用 C# 编写，面向 .NET Framework 4.8，将驱动文件与 LOLDrivers 知识库、Microsoft 阻止列表数据及自定义启发式规则进行交叉比对，同时解析 PE 映像以映射 IRP 分发处理程序、IOCTL 代码、缓冲区校验，以及从用户态设备路径到危险内核导入（如物理内存映射与回调注销）的可触达性。它还会汇总本地加固上下文，包括 HVCI、驱动程序签名强制、Secure Boot、VBS 与阻止列表状态，并按信息级至严重级对发现项排序，可选输出 JSON 或 CSV 报告。本项目面向内核安全研究、终端加固，以及需要盘点机器上可被利用的已签名驱动的反作弊或游戏安全团队。
