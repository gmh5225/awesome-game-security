BYOVD Hunter 是一款 Windows 主控台工具，用於掃描已安裝與已載入的核心驅動程式，以找出 Bring Your Own Vulnerable Driver（BYOVD）濫用的跡象。以 C# 撰寫並針對 .NET Framework 4.8，它會將驅動檔案與 LOLDrivers 知識庫、Microsoft 封鎖清單資料及自訂啟發式規則交叉比對，同時解析 PE 映像以對應 IRP 分派處理常式、IOCTL 代碼、緩衝區驗證，以及從使用者模式裝置路徑到危險核心匯入（如實體記憶體對應與回呼註銷）的可達性。另會彙整本機強化情境，包含 HVCI、驅動程式簽章強制、Secure Boot、VBS 與封鎖清單狀態，並將發現項目由資訊級至嚴重級排序，可選擇 JSON 或 CSV 報告。本專案面向核心安全研究、端點強化，以及需要盤點機器上可被利用之已簽章驅動的反作弊或遊戲安全團隊。
