BYOVD Hunter는 설치 및 로드된 커널 드라이버를 검사하여 Bring Your Own Vulnerable Driver(BYOVD) 남용 징후를 찾는 Windows 콘솔 도구입니다. C#으로 .NET Framework 4.8용으로 작성되었으며, 드라이버 파일을 LOLDrivers 지식 베이스, Microsoft 차단 목록 데이터 및 사용자 정의 휴리스틱과 대조하고 PE 이미지를 구문 분석하여 IRP 디스패치 핸들러, IOCTL 코드, 버퍼 검증, 사용자 모드 장치 경로에서 물리 메모리 매핑 및 콜백 등록 해제 같은 위험한 커널 import까지의 도달 가능성을 매핑합니다. HVCI, 드라이버 서명 강제, Secure Boot, VBS, 차단 목록 상태 등 로컬 강화 컨텍스트도 요약하고, 정보 수준부터 심각까지 발견 사항을 순위화하며 선택적으로 JSON 또는 CSV 보고를 제공합니다. 커널 보안 연구, 엔드포인트 강화, 머신에서 악용 가능한 서명된 드라이버를 목록화해야 하는 안티치트 또는 게임 보안 팀을 대상으로 합니다.
