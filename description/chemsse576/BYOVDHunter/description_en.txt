BYOVD Hunter is a Windows console tool that scans installed and loaded kernel drivers to find signs of Bring Your Own Vulnerable Driver (BYOVD) abuse. Written in C# for .NET Framework 4.8, it cross-checks driver files against the LOLDrivers knowledge base, Microsoft blocklist data, and custom heuristics while parsing PE images to map IRP dispatch handlers, IOCTL codes, buffer validation, and reachability from user-mode device paths to dangerous kernel imports such as physical memory mapping and callback unregistration. It also summarizes local hardening context including HVCI, driver signature enforcement, Secure Boot, VBS, and blocklist state, then ranks findings from informational through critical with optional JSON or CSV reporting. The project targets kernel security research, endpoint hardening, and anti-cheat or game-security teams who need to inventory exploitable signed drivers on a machine.
