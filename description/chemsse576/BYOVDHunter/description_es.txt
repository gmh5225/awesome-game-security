BYOVD Hunter es una herramienta de consola para Windows que escanea controladores de kernel instalados y cargados para detectar indicios de abuso de Bring Your Own Vulnerable Driver (BYOVD). Escrita en C# para .NET Framework 4.8, contrasta archivos de controladores con la base de conocimiento LOLDrivers, datos de listas de bloqueo de Microsoft y heurísticas personalizadas, mientras analiza imágenes PE para mapear manejadores de despacho IRP, códigos IOCTL, validación de búferes y alcanzabilidad desde rutas de dispositivo en modo usuario hacia importaciones peligrosas del kernel como mapeo de memoria física y anulación de registro de callbacks. También resume el contexto local de endurecimiento, incluidos HVCI, aplicación de firma de controladores, Secure Boot, VBS y estado de listas de bloqueo, y clasifica hallazgos de informativo a crítico con informes opcionales en JSON o CSV. El proyecto está dirigido a investigación de seguridad del kernel, endurecimiento de endpoints y equipos anti-cheat o de seguridad en juegos que necesitan inventariar controladores firmados explotables en una máquina.
