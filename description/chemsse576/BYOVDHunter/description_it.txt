BYOVD Hunter è uno strumento console per Windows che analizza i driver kernel installati e caricati per individuare segni di abuso di Bring Your Own Vulnerable Driver (BYOVD). Scritto in C# per .NET Framework 4.8, incrocia i file driver con la knowledge base LOLDrivers, i dati delle blocklist Microsoft e euristiche personalizzate, analizzando al contempo le immagini PE per mappare handler di dispatch IRP, codici IOCTL, validazione dei buffer e raggiungibilità dai percorsi dispositivo in user mode verso import kernel pericolosi come il mapping della memoria fisica e la deregistrazione delle callback. Riassume anche il contesto locale di hardening, inclusi HVCI, enforcement delle firme dei driver, Secure Boot, VBS e stato delle blocklist, quindi classifica i risultati da informativo a critico con report opzionali JSON o CSV. Il progetto è rivolto alla ricerca sulla sicurezza del kernel, al hardening degli endpoint e ai team anti-cheat o di game security che devono inventariare driver firmati sfruttabili su una macchina.
