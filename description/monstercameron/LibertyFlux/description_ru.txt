LibertyFlux — исследовательский проект по переписыванию движка Grand Theft Auto IV на Rust, функция за функцией, с целью запуска игры как нативной 64-разрядной программы на Windows, Windows on ARM и macOS. Кодовая база организована как Rust Cargo workspace с крейтами подсистем движка, парсерами бинарных форматов для архивов, моделей, аудио, коллизий и других ассетов, а также специализированными инструментами для верификации и замены функций на лету. Переписанные функции проверяются параллельно с оригинальным поведением с помощью checker workers и анализа на основе Ghidra, затем подменяются в работающей игре через hooking и инъекцию proxy DLL. Проект ориентирован на специалистов по реверс-инжинирингу, исследователей игровых движков и сообщества моддеров, интересующихся архитектурой игр, портированием legacy-систем и добросовестной современной переимплементацией без распространения проприетарного игрового контента.
