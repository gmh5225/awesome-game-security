LibertyFlux is a research project to rewrite Grand Theft Auto IV's engine in Rust one function at a time, with the goal of running the game as a native 64-bit program on Windows, Windows on ARM, and macOS. The codebase is organized as a Rust Cargo workspace with engine subsystem crates, binary format parsers for archives, models, audio, collision, and other assets, plus dedicated tooling for verification and live function replacement. Rewritten functions are validated side by side against the original behavior using checker workers and Ghidra-based analysis, then swapped into the running game through hooking and proxy DLL injection. It targets reverse engineers, engine researchers, and modding communities interested in game architecture, legacy porting, and faithful modern reimplementation without distributing proprietary game content.
