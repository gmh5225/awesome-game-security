LibertyFlux 是一個研究專案，旨在使用 Rust 逐個函式地重寫 Grand Theft Auto IV 的引擎，目標是在 Windows、Windows on ARM 和 macOS 上以原生 64 位元程式形式執行遊戲。程式碼庫以 Rust Cargo 工作區組織，包含引擎子系統 crate、用於解析封存、模型、音訊、碰撞及其他資產的二進位格式解析器，以及用於驗證和即時函式替換的專用工具。重寫的函式透過 checker worker 與基於 Ghidra 的分析，與原始行為進行並行驗證，然後透過 hooking 和代理 DLL 注入替換到執行中的遊戲內。該專案面向對遊戲架構、舊版移植以及在不分發專有遊戲內容的前提下進行忠實現代重實現感興趣的逆向工程師、引擎研究人員和 modding 社群。
