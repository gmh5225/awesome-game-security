Questo progetto è un modulo root basato su Zygisk che inietta in modo persistente il frida-gadget ufficiale nelle app Android selezionate senza ripacchettare gli APK né usare l’attach ptrace. Fornisce codice nativo C e C++ per il loader Zygisk insieme a funzionalità di stealth come il remap della memoria del gadget nelle mappe di processo, percorsi di libreria e dati neutri, mascheramento opzionale del nome dei thread e output di log silenzioso, abbinati a script shell di installazione, un’interfaccia web di gestione, esempi di hook JavaScript e strumenti di supporto Python sul PC. La configurazione è testo chiave-valore semplice e copre le modalità script rispetto a listen, whitelist per app, ritardo di iniezione e interruttori per il comportamento anti-fingerprint oltre a comandi per verificare le installazioni e gestire i target dal dispositivo o dal desktop. Lo stack allinea le versioni di gadget e toolchain a una release Frida specifica così che il client frida host corrisponda al gadget iniettato su target arm64 e ARM a 32 bit su dispositivi rootati con implementazioni Zygisk comuni. È pensato per ricercatori della sicurezza, reverse engineer e analisti che necessitano di strumentazione dinamica prolungata e per singola app su giochi mobili induriti o anti-tamper e altro software Android dove conta ridurre artefatti evidenti di Frida e del gadget.
