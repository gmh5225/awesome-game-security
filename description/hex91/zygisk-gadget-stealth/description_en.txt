This project is a Zygisk-based root module that persistently injects the official frida-gadget into selected Android apps without repackaging APKs or using ptrace attach. It ships native C and C++ code for the Zygisk loader plus stealth features such as remapping gadget memory in process maps, neutral library and data paths, optional thread name masking, and quiet log output, while pairing those with shell install scripts, a Web management UI, and JavaScript hook examples with Python helper tools on the PC. Configuration is plain key-value text and covers script versus listen modes, per-app whitelists, injection delay, and toggles for anti-fingerprinting behavior alongside commands to verify installs and manage targets from the device or desktop. The stack aligns gadget and tooling versions with a specific frida release so the host frida client matches the injected gadget across arm64 and 32-bit ARM targets on rooted devices running common Zygisk implementations. It is aimed at security researchers, reverse engineers, and analysts who need long-running, app-scoped dynamic instrumentation on hardened or anti-tamper mobile games and other Android software where reducing obvious frida and gadget artifacts matters.
