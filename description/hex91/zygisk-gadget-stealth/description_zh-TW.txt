本專案是一個以 Zygisk 為基礎的 root 模組，可在不重打包 APK、也不使用 ptrace 附加的情況下，將官方 frida-gadget 持續注入到所選的 Android 應用程式中。內含 Zygisk 載入器用的原生 C 與 C++ 程式碼，以及隱蔽功能，例如在程序對應中重對應 gadget 記憶體、中性化的函式庫與資料路徑、可選的執行緒名稱遮罩與安靜的日誌輸出，並搭配 shell 安裝指令稿、Web 管理介面、JavaScript 掛鉤範例，以及 PC 上的 Python 輔助工具。設定為純鍵值文字，涵蓋 script 與 listen 模式、依應用程式的白名單、注入延遲、反指紋行為的開關，以及從裝置或桌面驗證安裝與管理目標的命令。整套堆疊將 gadget 與工具鏈版本與特定 Frida 發行版對齊，使主機 frida 用戶端與已注入的 gadget 在執行常見 Zygisk 實作的 root 裝置上，於 arm64 與 32 位元 ARM 目標間相符。適合需要在強化或反竄改行動遊戲及其他 Android 軟體上進行長時間、依應用範圍的動態插桩，並須降低明顯 frida 與 gadget 跡象的安全研究者、逆向工程師與分析人員。
