이 프로젝트는 Zygisk 기반 root 모듈로, APK를 재패키징하거나 ptrace attach를 쓰지 않고도 선택한 Android 앱에 공식 frida-gadget을 지속적으로 주입합니다. Zygisk 로더용 네이티브 C 및 C++ 코드와 함께 프로세스 맵에서 gadget 메모리 재매핑, 중립적인 라이브러리 및 데이터 경로, 선택적 스레드 이름 마스킹, 조용한 로그 출력 등 스텔스 기능을 제공하며, 셸 설치 스크립트, 웹 관리 UI, JavaScript 훅 예제, PC용 Python 보조 도구와 결합합니다. 설정은 단순 키-값 텍스트로, script와 listen 모드, 앱별 화이트리스트, 주입 지연, 반지문 채취 동작 토글과 장치 또는 데스크톱에서 설치 확인 및 대상 관리 명령을 다룹니다. 스택은 gadget과 도구 버전을 특정 Frida 릴리스에 맞춰 호스트 frida 클라이언트와 주입된 gadget이 일반적인 Zygisk 구현이 돌아가는 루팅 기기에서 arm64와 32비트 ARM 대상 모두에서 맞도록 합니다. 강화되거나 무결성 보호가 적용된 모바일 게임 및 기타 Android 소프트웨어에서 장기간 앱 단위 동적 계측이 필요하고 Frida와 gadget 흔적을 덜 드러내고 싶은 보안 연구자, 리버스 엔지니어, 분석가를 대상으로 합니다.
