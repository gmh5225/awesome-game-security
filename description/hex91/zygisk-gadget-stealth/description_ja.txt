本プロジェクトは Zygisk ベースの root 用モジュールで、APK を再パッケージしたり ptrace でアタッチしたりせず、選択した Android アプリに公式の frida-gadget を永続的に注入します。Zygisk ローダー向けのネイティブ C/C++ コードに加え、プロセスマップ上での gadget メモリのリマップ、中立なライブラリとデータパス、任意のスレッド名マスキング、静かなログ出力といったステルス機能を備え、シェルインストールスクリプト、Web 管理 UI、JavaScript フックの例、PC 側の Python 補助ツールと組み合わせています。設定は単純なキー・バリュー形式で、script モードと listen モード、アプリごとのホワイトリスト、注入遅延、反フィンガープリント動作の切り替え、端末やデスクトップからのインストール検証とターゲット管理コマンドをカバーします。スタックは gadget とツールチェーンのバージョンを特定の Frida リリースに揃え、一般的な Zygisk 実装を動かす root 済みデバイス上で、arm64 と 32 ビット ARM の両方でホストの frida クライアントと注入された gadget が一致するようにします。強化されたり改ざん対策のモバイルゲームやその他の Android ソフトで、長期かつアプリ単位の動的計測が必要で、Frida と gadget の痕跡を目立たなくしたいセキュリティ研究者、リバースエンジニア、アナリスト向けです。
