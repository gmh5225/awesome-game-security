Este proyecto es un módulo root basado en Zygisk que inyecta de forma persistente el frida-gadget oficial en aplicaciones Android seleccionadas sin volver a empaquetar APK ni usar adjunción ptrace. Incluye código nativo en C y C++ para el cargador Zygisk y funciones de sigilo como remap de la memoria del gadget en los mapas de proceso, rutas de biblioteca y datos neutras, enmascaramiento opcional del nombre de hilos y salida de registro silenciosa, junto con scripts de instalación en shell, una interfaz web de administración, ejemplos de hooks en JavaScript y herramientas auxiliares en Python en el PC. La configuración es texto clave-valor sencillo y abarca modos script frente a escucha, listas blancas por aplicación, retraso de inyección y conmutadores de comportamiento anti-huella, además de comandos para verificar instalaciones y gestionar objetivos desde el dispositivo o el escritorio. La pila alinea las versiones del gadget y del tooling con una versión concreta de Frida para que el cliente frida del host coincida con el gadget inyectado en objetivos arm64 y ARM de 32 bits en dispositivos con root que ejecutan implementaciones habituales de Zygisk. Va dirigido a investigadores de seguridad, ingenieros inversos y analistas que necesitan instrumentación dinámica de larga duración y acotada por aplicación en juegos móviles endurecidos o antimanipulación y otro software Android donde importa reducir artefactos evidentes de Frida y del gadget.
