本项目是一个基于 Zygisk 的 root 模块，可在不重打包 APK、也不使用 ptrace 附加的情况下，将官方 frida-gadget 持久注入到所选 Android 应用中。它包含用于 Zygisk 加载器的原生 C/C++ 代码及隐蔽能力，例如在进程映射中重映射 gadget 内存、使用中性库与数据路径、可选的线程名掩蔽以及静默日志输出，同时配套 shell 安装脚本、Web 管理界面、JavaScript 挂钩示例以及 PC 端 Python 辅助工具。配置为普通键值文本，涵盖 script 与 listen 模式、按应用白名单、注入延迟、反指纹识别相关开关，以及从设备或桌面验证安装与管理目标的命令。整套栈将 gadget 与工具链版本与特定 Frida 发行版对齐，使主机 frida 客户端与已注入的 gadget 在运行常见 Zygisk 实现的 root 设备上，于 arm64 与 32 位 ARM 目标间保持一致。面向需要在加固或反篡改移动游戏及其他 Android 软件上进行长期、按应用范围的动态插桩，并需降低明显 frida 与 gadget 痕迹的安全研究者、逆向工程师与分析人员。
