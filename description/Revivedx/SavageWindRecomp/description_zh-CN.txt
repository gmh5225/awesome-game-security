Savage Wind Recomp 是一个静态重编译移植项目，可将《塞尔达传说：旷野之息》的 Nintendo Switch 可执行文件转换为由宿主运行时驱动的原生 PC 游戏库。工具链加载 Switch NSO 模块，提升 AArch64 指令，应用版本感知补丁，并生成 C 代码，玩家可使用自己提取的游戏文件在本地构建。运行时提供 Switch 服务的高级仿真、Maxwell 着色器翻译，以及在 Windows 和 Linux 上的 Vulkan 渲染，还可选 Metal 支持及包含 Capstone、Unicorn 和 Ghidra 辅助工具的 Python 工具，用于分析与代码生成。项目还集成性能分析、内存扫描及大量玩法与图形自定义功能，供研究与 Mod 使用，面向逆向工程师、移植研究人员以及研究主机二进制翻译、客户机到宿主 ABI 映射及大规模静态重编译流程的高级玩家。
