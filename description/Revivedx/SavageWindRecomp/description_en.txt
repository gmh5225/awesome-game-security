Savage Wind Recomp is a static recompilation port that turns Nintendo Switch executables from The Legend of Zelda: Breath of the Wild into a native PC game library driven by a host runtime. The toolchain loads Switch NSO modules, lifts AArch64 instructions, applies version-aware patches, and generates C that players build locally from their own extracted game files. The runtime provides high-level emulation of Switch services, Maxwell shader translation, and Vulkan rendering on Windows and Linux, with optional Metal support and Python utilities including Capstone, Unicorn, and Ghidra helpers for analysis and codegen. It also bundles profiling, memory scanning, and extensive gameplay and graphics customization for research and modding. The project is aimed at reverse engineers, porting researchers, and advanced players studying console binary translation, guest-to-host ABI mapping, and large-scale static recompilation workflows.
