Savage Wind Recomp는 《젤다의 전설 야생의 숨결》 Nintendo Switch 실행 파일을 호스트 런타임이 구동하는 네이티브 PC 게임 라이브러리로 바꾸는 정적 재컴파일 포트입니다. 툴체인은 Switch NSO 모듈을 로드하고 AArch64 명령을 리프팅하며 버전 인식 패치를 적용한 뒤 C 코드를 생성하며, 플레이어는 자신이 추출한 게임 파일로 로컬에서 빌드합니다. 런타임은 Switch 서비스의 고수준 에뮬레이션, Maxwell 셰이더 변환, Windows 및 Linux에서의 Vulkan 렌더링을 제공하고, 선택적 Metal 지원과 분석 및 코드 생성을 위한 Capstone, Unicorn, Ghidra 헬퍼를 포함한 Python 유틸리티를 제공합니다. 프로파일링, 메모리 스캔, 광범위한 게임플레이 및 그래픽 커스터마이징도 포함되어 연구와 모딩에 활용되며, 리버스 엔지니어, 포팅 연구자, 콘솔 바이너리 번역, 게스트-호스트 ABI 매핑, 대규모 정적 재컴파일 워크플로를 연구하는 고급 플레이어를 대상으로 한다.
