Savage Wind Recomp 是一套靜態重編譯移植專案，可將《薩爾達傳說：曠野之息》的 Nintendo Switch 可執行檔轉為由宿主執行階段驅動的原生 PC 遊戲函式庫。工具鏈載入 Switch NSO 模組，提升 AArch64 指令，套用版本感知修補，並產生 C 程式碼，玩家能以自行提取的遊戲檔案在本地建置。執行階段提供 Switch 服務的高階模擬、Maxwell 著色器轉譯，以及在 Windows 與 Linux 上的 Vulkan 渲染，並可選用 Metal 支援及含 Capstone、Unicorn、Ghidra 輔助工具的 Python 工具，用於分析與程式碼產生。專案亦整合效能分析、記憶體掃描及豐富的玩法與圖形自訂功能，供研究與 Mod 使用，面向逆向工程師、移植研究人員以及研究主機二進位翻譯、客體到宿主 ABI 對應與大規模靜態重編譯流程的進階玩家。
