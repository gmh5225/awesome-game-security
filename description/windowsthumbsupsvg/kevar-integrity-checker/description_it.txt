Kevar Integrity Checker è un'utilità Windows open source che consente a organizzatori di tornei, community competitive e giocatori di verificare che le principali funzioni di sicurezza della piattaforma siano abilitate prima di giocare. Esegue controlli in sola lettura su UEFI Secure Boot, Kernel DMA Protection, HVCI (integrità della memoria) e TPM 2.0 tramite variabili firmware, NtQuerySystemInformation e query WMI. Sono fornite implementazioni in C++ e PowerShell, incluso un flusso PowerShell opzionale senza file per esecuzioni rapide sulla macchina senza lasciare tracce. Lo strumento è rivolto alla sicurezza dei giochi e agli scenari anti-cheat in cui i titoli mancano di una protezione robusta a livello kernel, aiutando a bloccare configurazioni di cheat comuni che dipendono da driver non firmati, firmware DMA debole o integrità della memoria disabilitata.
