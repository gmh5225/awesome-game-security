Kevar Integrity Checker는 토너먼트 주최자, 경쟁 커뮤니티, 플레이어가 플레이 전에 핵심 플랫폼 보안 기능이 켜져 있는지 확인할 수 있는 오픈 소스 Windows 유틸리티입니다. 펌웨어 변수, NtQuerySystemInformation, WMI 쿼리를 사용해 UEFI Secure Boot, Kernel DMA Protection, HVCI(메모리 무결성), TPM 2.0을 읽기 전용으로 검사합니다. C++ 및 PowerShell 구현이 제공되며, 선택적 파일리스 PowerShell 워크플로로 대상 머신에서 흔적 없이 빠르게 실행할 수 있습니다. 이 도구는 강력한 커널 수준 보호가 부족한 게임의 보안 및 안티치트 시나리오를 대상으로 하며, 서명되지 않은 드라이버, 취약한 DMA 펌웨어, 비활성화된 메모리 무결성에 의존하는 일반적인 치트 환경을 차단하는 데 도움이 됩니다.
