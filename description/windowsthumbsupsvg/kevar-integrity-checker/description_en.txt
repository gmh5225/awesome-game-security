Kevar Integrity Checker is an open-source Windows utility that lets tournament hosts, competitive communities, and players verify that key platform security features are enabled before play. It performs read-only checks for UEFI Secure Boot, Kernel DMA Protection, HVCI (Memory Integrity), and TPM 2.0 using firmware variables, NtQuerySystemInformation, and WMI queries. Implementations are provided in C++ and PowerShell, including an optional fileless PowerShell workflow for quick on-machine runs without leaving artifacts. The tool targets game security and anti-cheat scenarios where titles lack strong kernel-level protection, helping block common cheat setups that depend on unsigned drivers, weak DMA firmware, or disabled memory integrity.
