Kevar Integrity Checker 是一款開源 Windows 工具，供賽事主辦方、競技社群與玩家在對戰前確認關鍵平台安全功能是否已啟用。它透過韌體變數、NtQuerySystemInformation 與 WMI 查詢，以唯讀方式檢查 UEFI Secure Boot、Kernel DMA Protection、HVCI（記憶體完整性）與 TPM 2.0。提供 C++ 與 PowerShell 實作，並包含可選的無檔案 PowerShell 流程，便於在目標機器上快速執行且不留痕跡。此工具鎖定遊戲安全與反作弊情境——許多遊戲缺乏強力的核心層級防護——有助於阻擋依賴未簽署驅動程式、薄弱 DMA 韌體或關閉記憶體完整性的常見作弊環境。
