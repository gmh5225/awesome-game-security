Kevar Integrity Checker は、トーナメント主催者、競技コミュニティ、プレイヤーが対戦前に主要なプラットフォームのセキュリティ機能が有効かどうかを確認できるオープンソースの Windows ユーティリティです。ファームウェア変数、NtQuerySystemInformation、WMI クエリを用いて、UEFI Secure Boot、Kernel DMA Protection、HVCI（メモリ整合性）、TPM 2.0 を読み取り専用でチェックします。C++ と PowerShell の実装があり、任意のファイルレス PowerShell ワークフローにより、対象マシン上で痕跡を残さず素早く実行できます。カーネルレベルの保護が弱いタイトルが多いゲームセキュリティやアンチチートの場面を想定し、未署名ドライバ、脆弱な DMA ファームウェア、メモリ整合性の無効化に依存する一般的なチート構成を防ぐのに役立ちます。
