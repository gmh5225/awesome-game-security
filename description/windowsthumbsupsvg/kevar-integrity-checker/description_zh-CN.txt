Kevar Integrity Checker 是一款开源 Windows 工具，供赛事主办方、竞技社区与玩家在开局前核实关键平台安全功能是否已启用。它通过固件变量、NtQuerySystemInformation 与 WMI 查询，以只读方式检查 UEFI Secure Boot、Kernel DMA Protection、HVCI（内存完整性）与 TPM 2.0。提供 C++ 与 PowerShell 实现，并包含可选的无文件 PowerShell 流程，便于在目标机器上快速运行且不留痕迹。该工具面向游戏安全与反作弊场景——许多游戏缺乏强力的内核级防护——有助于阻止依赖未签名驱动、薄弱 DMA 固件或关闭内存完整性的常见作弊环境。
