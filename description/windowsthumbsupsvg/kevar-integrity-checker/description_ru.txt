Kevar Integrity Checker — это утилита Windows с открытым исходным кодом, которая позволяет организаторам турниров, соревновательным сообществам и игрокам перед игрой убедиться, что ключевые функции безопасности платформы включены. Она выполняет проверки только для чтения UEFI Secure Boot, Kernel DMA Protection, HVCI (целостность памяти) и TPM 2.0 с помощью переменных прошивки, NtQuerySystemInformation и WMI-запросов. Реализации на C++ и PowerShell включают опциональный бесфайловый сценарий PowerShell для быстрого запуска на машине без следов. Инструмент ориентирован на безопасность игр и сценарии античита, когда у игр нет надёжной защиты на уровне ядра, и помогает блокировать типичные читерские конфигурации, зависящие от неподписанных драйверов, слабой DMA-прошивки или отключённой целостности памяти.
