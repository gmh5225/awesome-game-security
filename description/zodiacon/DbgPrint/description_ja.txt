DbgPrint は、ユーザーモードとカーネルモードの両方からのデバッグ出力をリアルタイムで表示する Windows デスクトップユーティリティです。OutputDebugString メッセージ（.NET の Debug.Write および Trace.Write の出力を含む）をキャプチャし、カスタムドライバーをインストールせずに DbgPrint および DbgPrintEx のカーネルメッセージも表示できます。C++ WTL アプリケーションは、フィルタリング、ハイライト、ログの永続化に加え、レジストリの編集や再起動なしで、必要に応じてすべてのカーネルデバッグコンポーネントを有効にする機能を提供します。x86、x64、ARM64 ビルドに対応し、現在のセッションまたは Session 0 からの出力をキャプチャできます。分析やトラブルシューティング中にアプリケーションおよびドライバーのデバッグトレースを監視する必要がある Windows 開発者、セキュリティ研究者、リバースエンジニア向けのツールです。
