DbgPrint 是一款 Windows 桌面实用工具，可实时查看来自用户态和内核态的调试打印输出。它捕获 OutputDebugString 消息，包括 .NET 的 Debug.Write 和 Trace.Write 输出，并可在不安装自定义驱动的情况下显示 DbgPrint 和 DbgPrintEx 内核消息。这款基于 C++ WTL 的应用提供过滤、高亮、日志持久化等功能，还可按需启用所有内核调试组件，无需修改注册表或重启。它支持 x86、x64 和 ARM64 构建，可捕获当前会话或 Session 0 的输出。该工具面向需要在分析或故障排查过程中监控应用程序和驱动程序调试跟踪的 Windows 开发者、安全研究人员和逆向工程师。
