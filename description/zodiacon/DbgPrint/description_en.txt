DbgPrint is a Windows desktop utility for viewing debug print output from both user-mode and kernel-mode sources in real time. It captures OutputDebugString messages, including .NET Debug.Write and Trace.Write output, and can display DbgPrint and DbgPrintEx kernel messages without installing a custom driver. The C++ WTL application offers filtering, highlighting, log persistence, and controls to enable all kernel debug components on demand without registry edits or reboots. It supports x86, x64, and ARM64 builds and can capture output from the current session or Session 0. The tool is aimed at Windows developers, security researchers, and reverse engineers who need to monitor application and driver debug traces during analysis or troubleshooting.
