DbgPrint 是一款 Windows 桌面公用程式，可即時檢視來自使用者模式與核心模式的除錯列印輸出。它會擷取 OutputDebugString 訊息，包括 .NET 的 Debug.Write 與 Trace.Write 輸出，並可在不安裝自訂驅動程式的情況下顯示 DbgPrint 與 DbgPrintEx 核心訊息。這款以 C++ WTL 建置的應用程式提供篩選、醒目標示、日誌持久化等功能，還可按需啟用所有核心除錯元件，無需修改登錄檔或重新開機。它支援 x86、x64 與 ARM64 建置，可擷取目前工作階段或 Session 0 的輸出。此工具面向需要在分析或疑難排解過程中監控應用程式與驅動程式除錯追蹤的 Windows 開發人員、安全研究人員與逆向工程師。
