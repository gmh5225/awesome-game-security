DbgPrint — это настольная утилита для Windows, предназначенная для просмотра отладочного вывода из источников как пользовательского, так и режима ядра в реальном времени. Она перехватывает сообщения OutputDebugString, включая вывод .NET Debug.Write и Trace.Write, и может отображать сообщения ядра DbgPrint и DbgPrintEx без установки пользовательского драйвера. Приложение на C++ WTL предлагает фильтрацию, подсветку, сохранение журналов и элементы управления для включения всех компонентов отладки ядра по требованию без правок реестра или перезагрузки. Поддерживаются сборки x86, x64 и ARM64, а также захват вывода из текущего сеанса или Session 0. Инструмент предназначен для разработчиков Windows, исследователей безопасности и специалистов по реверс-инжинирингу, которым необходимо отслеживать отладочные трассировки приложений и драйверов во время анализа или устранения неполадок.
