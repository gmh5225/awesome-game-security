PoolMonX v3 — это настольная утилита для Windows, которая в реальном времени отслеживает теги выделения пула ядра и показывает статистику использования постраничной и непостраничной памяти в сортируемом списке. Реализована на C++ с Visual Studio, WTL и WIL; данные собираются через NtQuerySystemInformation, при необходимости теги дополняются именами источников и описаниями из pooltag.txt WinDbg. Интерфейс поддерживает быструю фильтрацию, паузу и возобновление обновлений, цветовую индикацию различий между обновлениями, тёмную тему и управление с панели инструментов. Предназначена для отладки ядра, анализа драйверов и низкоуровневой работы по безопасности Windows, в том числе для выявления необычных потребителей пула, связанных с драйверами или компонентами античита.
