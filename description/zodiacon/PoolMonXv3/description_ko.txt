PoolMonX v3는 Windows 데스크톱 유틸리티로, 라이브 커널 풀 할당 태그를 모니터링하고 페이징 및 비페이징 사용 통계를 정렬 가능한 목록 보기로 표시합니다. C++와 Visual Studio, WTL, WIL로 구현되었으며 NtQuerySystemInformation을 통해 데이터를 수집하고, 선택적으로 WinDbg의 pooltag.txt에서 태그에 소스 이름과 설명을 보강합니다. 인터페이스는 빠른 필터링, 업데이트 일시 중지 및 재개, 새로 고침 간 색으로 구분된 델타, 다크 모드, 툴바 기반 제어를 지원합니다. 커널 디버깅, 드라이버 분석, 드라이버나 안티치트 구성 요소와 연관된 비정상적인 풀 소비자를 찾는 등 저수준 Windows 보안 작업을 대상으로 합니다.
