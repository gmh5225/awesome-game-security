PoolMonX v3 es una utilidad de escritorio para Windows que supervisa en vivo las etiquetas de asignación del pool del kernel y muestra estadísticas de uso paginado y no paginado en una vista de lista ordenable. Está implementada en C++ con Visual Studio, WTL y WIL, y recopila datos mediante NtQuerySystemInformation mientras enriquece opcionalmente las etiquetas desde pooltag.txt de WinDbg con nombres de origen y descripciones. La interfaz admite filtrado rápido, pausar y reanudar actualizaciones, deltas codificados por color entre actualizaciones, modo oscuro y controles desde la barra de herramientas. Está orientada a la depuración del kernel, el análisis de controladores y el trabajo de seguridad de Windows de bajo nivel, como detectar consumidores de pool inusuales vinculados a controladores o componentes antitrampas.
