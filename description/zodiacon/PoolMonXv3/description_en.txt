PoolMonX v3 is a Windows desktop utility that monitors live kernel pool allocation tags and shows paged and non-paged usage statistics in a sortable list view. It is implemented in C++ with Visual Studio, WTL, and WIL, and gathers data through NtQuerySystemInformation while optionally enriching tags from WinDbg’s pooltag.txt with source names and descriptions. The interface supports quick filtering, pause and resume updates, color-coded deltas between refreshes, dark mode, and toolbar-driven controls. It targets kernel debugging, driver analysis, and low-level Windows security work such as spotting unusual pool consumers tied to drivers or anti-cheat components.
