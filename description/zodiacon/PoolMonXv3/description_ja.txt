PoolMonX v3 は、Windows デスクトップ向けユーティリティで、カーネルプールの割り当てタグをリアルタイム監視し、ページングおよび非ページングの使用統計をソート可能なリストビューで表示します。C++ と Visual Studio、WTL、WIL で実装され、NtQuerySystemInformation 経由でデータを取得し、必要に応じて WinDbg の pooltag.txt からタグにソース名と説明を付加できます。UI ではクイックフィルタ、更新の一時停止・再開、更新間の差分の色分け、ダークモード、ツールバー操作に対応しています。カーネルデバッグ、ドライバ分析、ドライバやアンチチートコンポーネントに紐づく異常なプール利用者の特定など、低レベルの Windows セキュリティ作業を想定しています。
