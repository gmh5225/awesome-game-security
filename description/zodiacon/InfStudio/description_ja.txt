INF Studio は、カーネルモードおよびユーザーモードのドライバーをパッケージ化・インストールする際に使うドライバーインストール（INF）ファイルの表示・編集向けのネイティブ Windows デスクトップアプリケーションです。Scintilla ベースのテキストエディターと、Version、Manufacturer and Models、AddReg、CopyFiles といった INF セクションを分解表示できるナビゲーション可能なツリーを組み合わせ、共有ライブラリ InfCore 経由で Windows SetupAPI によりファイルを解析します。プロジェクトは C++20、Windows Template Library、Lexilla、カスタム INF 構文レキサーで構築され、検索・置換、ダークモード、ANSI・UTF-8・UTF-16 間のエンコーディング処理に対応します。Windows Driver Kit の infverif ツールで Windows ドライバーおよび WHQL の検証を実行でき、一般的な KMDF、UMDF、USB、仮想デバイス向けのスターターテンプレートと、バージョンメタデータやセクション名を一覧する DumpInf コンソールユーティリティも同梱されます。Windows ドライバーパッケージの調査や作成を行うドライバー開発者、リバースエンジニア、セキュリティ研究者が、システム上でドライバーがどのように宣言・コピー・登録されるかを学ぶ際に役立ちます。
