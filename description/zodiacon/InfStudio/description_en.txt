INF Studio is a native Windows desktop application for viewing and editing driver installation (INF) files used when packaging and installing kernel-mode and user-mode drivers. It pairs a Scintilla-based text editor with a navigable tree that breaks down INF sections such as Version, Manufacturer and Models, AddReg, and CopyFiles, and it parses files through Windows SetupAPI via the shared InfCore library. The project is built in C++20 with the Windows Template Library, Lexilla, and a custom INF syntax lexer, and it supports find and replace, dark mode, and encoding handling between ANSI, UTF-8, and UTF-16. It can run the Windows Driver Kit infverif tool for Windows Driver and WHQL validation and ships starter templates for common KMDF, UMDF, USB, and virtual device scenarios, plus a small DumpInf console utility for listing version metadata and section names. Driver developers, reverse engineers, and security researchers who need to inspect or author Windows driver packages will find it useful when studying how drivers are declared, copied, and registered on the system.
