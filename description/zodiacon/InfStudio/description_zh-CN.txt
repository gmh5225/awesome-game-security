INF Studio 是一款原生 Windows 桌面应用，用于查看和编辑驱动程序安装（INF）文件，适用于打包和安装内核模式与用户模式驱动程序。它将基于 Scintilla 的文本编辑器与可导航的树形结构相结合，可分解 Version、Manufacturer and Models、AddReg、CopyFiles 等 INF 区段，并通过共享库 InfCore 借助 Windows SetupAPI 解析文件。项目使用 C++20、Windows Template Library、Lexilla 以及自定义 INF 语法分析器构建，支持查找替换、深色模式，以及 ANSI、UTF-8 与 UTF-16 之间的编码处理。可运行 Windows Driver Kit 的 infverif 工具进行 Windows 驱动与 WHQL 验证，并提供常见 KMDF、UMDF、USB 与虚拟设备场景的入门模板，另附 DumpInf 控制台实用程序用于列出版本元数据与区段名称。需要检查或编写 Windows 驱动程序包的驱动开发人员、逆向工程师与安全研究人员，在研究驱动如何在系统上声明、复制与注册时会很有用。
