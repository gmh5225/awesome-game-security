INF Studio est une application de bureau Windows native pour consulter et modifier les fichiers d’installation de pilotes (INF) utilisés lors de l’empaquetage et de l’installation de pilotes en mode noyau et en mode utilisateur. Elle associe un éditeur de texte basé sur Scintilla à une arborescence navigable qui décompose les sections INF telles que Version, Manufacturer and Models, AddReg et CopyFiles, et analyse les fichiers via l’API Setup de Windows grâce à la bibliothèque partagée InfCore. Le projet est développé en C++20 avec la Windows Template Library, Lexilla et un analyseur lexical INF personnalisé ; il prend en charge la recherche et le remplacement, le mode sombre et la gestion des encodages ANSI, UTF-8 et UTF-16. Il peut exécuter l’outil infverif du Windows Driver Kit pour la validation des pilotes Windows et WHQL, et fournit des modèles de démarrage pour les scénarios courants KMDF, UMDF, USB et périphériques virtuels, ainsi qu’un utilitaire console DumpInf pour lister les métadonnées de version et les noms de sections. Les développeurs de pilotes, ingénieurs en rétro-ingénierie et chercheurs en sécurité qui doivent inspecter ou rédiger des packages de pilotes Windows y trouveront un outil utile pour étudier comment les pilotes sont déclarés, copiés et enregistrés sur le système.
