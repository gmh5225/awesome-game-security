INF Studio es una aplicación de escritorio nativa de Windows para ver y editar archivos de instalación de controladores (INF) usados al empaquetar e instalar controladores en modo kernel y en modo usuario. Combina un editor de texto basado en Scintilla con un árbol navegable que desglosa secciones INF como Version, Manufacturer and Models, AddReg y CopyFiles, y analiza los archivos mediante la API Setup de Windows a través de la biblioteca compartida InfCore. El proyecto está construido en C++20 con Windows Template Library, Lexilla y un analizador léxico INF personalizado, y admite buscar y reemplazar, modo oscuro y gestión de codificación entre ANSI, UTF-8 y UTF-16. Puede ejecutar la herramienta infverif del Windows Driver Kit para validación de controladores Windows y WHQL, e incluye plantillas iniciales para escenarios habituales de KMDF, UMDF, USB y dispositivos virtuales, además de una utilidad de consola DumpInf para listar metadatos de versión y nombres de sección. Desarrolladores de controladores, ingenieros de ingeniería inversa e investigadores de seguridad que necesiten inspeccionar o crear paquetes de controladores Windows lo encontrarán útil al estudiar cómo se declaran, copian y registran los controladores en el sistema.
