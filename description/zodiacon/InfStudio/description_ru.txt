INF Studio — нативное настольное приложение Windows для просмотра и редактирования файлов установки драйверов (INF), используемых при упаковке и установке драйверов режима ядра и пользовательского режима. Оно сочетает текстовый редактор на базе Scintilla с навигационным деревом, разбивающим разделы INF вроде Version, Manufacturer and Models, AddReg и CopyFiles, и разбирает файлы через Windows SetupAPI с помощью общей библиотеки InfCore. Проект написан на C++20 с Windows Template Library, Lexilla и пользовательским лексером синтаксиса INF; поддерживаются поиск и замена, тёмная тема и работа с кодировками ANSI, UTF-8 и UTF-16. Можно запускать утилиту infverif из Windows Driver Kit для проверки драйверов Windows и WHQL; поставляются стартовые шаблоны для типичных сценариев KMDF, UMDF, USB и виртуальных устройств, а также небольшая консольная утилита DumpInf для вывода метаданных версии и имён разделов. Разработчикам драйверов, специалистам по реверс-инжинирингу и исследователям безопасности, которым нужно изучать или создавать пакеты драйверов Windows, приложение поможет разобраться, как драйверы объявляются, копируются и регистрируются в системе.
