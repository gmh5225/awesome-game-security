Questo progetto è Object Explorer, uno strumento GUI per Windows per esplorare e ispezionare lo spazio dei nomi dell'Object Manager del kernel, i tipi di oggetto, gli handle e la proprietà degli oggetti per processo. Utilizza un driver kernel incluso per accedere ai dati dell'Object Manager e decodifica le strutture del kernel in memoria con simboli di debug PDB tramite una libreria di supporto DIA (Debug Interface Access). L'applicazione C++/WTL offre viste per le proprietà degli oggetti, i descrittori di sicurezza, la decodifica delle maschere di accesso, l'enumerazione degli handle e il rilevamento dei processi zombie. È rivolta a ricercatori di internals di Windows, reverse engineer e analisti di sicurezza che necessitano di una visibilità approfondita sugli oggetti del kernel per il debug, la forensics e la ricerca anti-cheat.
