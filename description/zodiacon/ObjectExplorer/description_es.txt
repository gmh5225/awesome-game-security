Este proyecto es Object Explorer, una herramienta GUI de Windows para explorar e inspeccionar el espacio de nombres del administrador de objetos del kernel, los tipos de objetos, los handles y la propiedad de objetos por proceso. Utiliza un controlador de kernel incluido para acceder a los datos del administrador de objetos y decodifica estructuras del kernel en memoria con símbolos de depuración PDB mediante una biblioteca auxiliar DIA (Debug Interface Access). La aplicación C++/WTL ofrece vistas de propiedades de objetos, descriptores de seguridad, decodificación de máscaras de acceso, enumeración de handles y detección de procesos zombi. Está dirigida a investigadores de internals de Windows, ingenieros de ingeniería inversa y analistas de seguridad que necesitan una visibilidad profunda de los objetos del kernel para depuración, análisis forense e investigación antitrampas.
