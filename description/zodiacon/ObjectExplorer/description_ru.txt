Этот проект — Object Explorer, графический инструмент для Windows, предназначенный для просмотра и анализа пространства имён диспетчера объектов ядра, типов объектов, дескрипторов и принадлежности объектов процессам. Он использует встроенный драйвер ядра для доступа к данным диспетчера объектов и декодирует структуры ядра в памяти с помощью отладочных символов PDB через вспомогательную библиотеку DIA (Debug Interface Access). Приложение на C++/WTL предоставляет представления свойств объектов, дескрипторов безопасности, декодирования масок доступа, перечисления дескрипторов и обнаружения процессов-зомби. Оно предназначено для исследователей внутреннего устройства Windows, специалистов по реверс-инжинирингу и аналитиков по безопасности, которым нужна глубокая видимость объектов ядра для отладки, форензики и исследований в области античитов.
