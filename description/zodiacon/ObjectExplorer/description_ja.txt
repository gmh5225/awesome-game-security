このプロジェクトは Object Explorer であり、カーネルのオブジェクトマネージャー名前空間、オブジェクト型、ハンドル、およびプロセスごとのオブジェクト所有権を参照・調査するための Windows GUI ツールです。同梱のカーネルドライバーでオブジェクトマネージャーのデータにアクセスし、DIA（Debug Interface Access）ヘルパーライブラリを通じて PDB デバッグシンボルを用いてメモリ上のカーネル構造体をデコードします。C++/WTL アプリケーションは、オブジェクトのプロパティ、セキュリティ記述子、アクセスマスクのデコード、ハンドル列挙、ゾンビプロセス検出などのビューを提供します。デバッグ、フォレンジック、チート対策の研究のためにカーネルオブジェクトを深く可視化する必要がある Windows 内部構造の研究者、リバースエンジニア、セキュリティアナリスト向けです。
