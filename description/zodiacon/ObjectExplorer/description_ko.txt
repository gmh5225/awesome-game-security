이 프로젝트는 Object Explorer로, 커널 Object Manager 네임스페이스, 객체 유형, 핸들, 프로세스별 객체 소유권을 탐색하고 검사하는 Windows GUI 도구입니다. 번들된 커널 드라이버로 Object Manager 데이터에 접근하며, DIA(Debug Interface Access) 헬퍼 라이브러리를 통해 PDB 디버그 심볼로 메모리상 커널 구조체를 디코딩합니다. C++/WTL 애플리케이션은 객체 속성, 보안 설명자, 액세스 마스크 디코딩, 핸들 열거, 좀비 프로세스 탐지 등의 뷰를 제공합니다. 디버깅, 포렌식, 안티치트 연구를 위해 커널 객체에 대한 깊은 가시성이 필요한 Windows 내부 구조 연구자, 리버스 엔지니어, 보안 분석가를 대상으로 합니다.
