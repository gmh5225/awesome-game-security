Questo repository contiene il codice sorgente di accompagnamento alla seconda edizione di Windows Kernel Programming, organizzato in soluzioni Visual Studio capitolo per capitolo per insegnare lo sviluppo di driver in modalità kernel in modo pratico. Gli esempi sono principalmente driver WDM in C e C++ costruiti con il Windows Driver Kit, insieme a client in modalità utente che esercitano dispositivi, IOCTL e buffer condivisi tramite pattern come Boost e Booster. La copertura va da DriverEntry, scaricamento e dispatch degli IRP di base a primitive di sincronizzazione, enumerazione dei processi, componenti di monitoraggio e protezione, callback e timer del kernel, minifiltri del file system per backup e protezione dalla cancellazione, esempi di Windows Filtering Platform e driver di monitoraggio dei dispositivi. Una libreria di template kernel condivisa ktl fornisce helper riutilizzabili per lock, memoria, stringhe e collezioni usati nei progetti. La raccolta è pensata per autori di driver Windows e ricercatori di sicurezza che necessitano di campioni kernel pratici per monitoraggio, filtraggio e controllo degli accessi, fondamento di anti-cheat e ingegneria di sicurezza di sistema a basso livello.
