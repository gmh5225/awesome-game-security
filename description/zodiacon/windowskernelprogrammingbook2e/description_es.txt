Este repositorio es el código fuente de acompañamiento de la segunda edición de Windows Kernel Programming, organizado en soluciones de Visual Studio capítulo por capítulo que enseñan el desarrollo de controladores en modo kernel de forma práctica. Las muestras son principalmente controladores WDM en C y C++ compilados con el Windows Driver Kit, junto con clientes en modo usuario que ejercitan dispositivos, IOCTL y búferes compartidos mediante patrones como Boost y Booster. La cobertura abarca desde DriverEntry, descarga y despacho de IRP básicos hasta primitivas de sincronización, enumeración de procesos, componentes de supervisión y protección, devoluciones de llamada y temporizadores del kernel, minifiltros del sistema de archivos para copia de seguridad y protección contra borrado, ejemplos de Windows Filtering Platform y controladores de supervisión de dispositivos. Una biblioteca de plantillas de kernel compartida ktl ofrece ayudantes reutilizables para bloqueos, memoria, cadenas y colecciones usados en los proyectos. La colección está pensada para autores de controladores de Windows e investigadores de seguridad que necesitan muestras prácticas de kernel para supervisión, filtrado y control de acceso, base del antitrampas y de la ingeniería de seguridad de sistemas de bajo nivel.
