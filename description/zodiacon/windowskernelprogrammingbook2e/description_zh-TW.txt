本儲存庫是《Windows 核心程式設計》第二版的配套原始碼，依章節組織為 Visual Studio 解決方案，以實作方式教授核心模式驅動程式開發。範例主要為使用 Windows Driver Kit 建置的 C/C++ WDM 驅動程式，並附有使用者模式用戶端，透過 Boost、Booster 等模式演練裝置、IOCTL 與共用緩衝區。內容涵蓋從基本的 DriverEntry、卸載與 IRP 分派，到同步原語、處理序列舉、監控與保護元件、核心回呼與計時器、用於備份與刪除保護的檔案系統迷你篩選器、Windows Filtering Platform 範例，以及裝置監控驅動程式。共用的 ktl 核心範本程式庫為各專案提供鎖定、記憶體、字串與集合等可重複使用的輔助工具。此集合適合需要實用核心範例以從事監控、篩選與存取控制工作的 Windows 驅動程式作者與安全研究人員，是反作弊與低階系統安全工程的基礎。
