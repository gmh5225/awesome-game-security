Этот репозиторий — сопутствующий исходный код ко второму изданию Windows Kernel Programming, организованный по главам в виде решений Visual Studio для практического изучения разработки драйверов в режиме ядра. Примеры — в основном драйверы WDM на C и C++, собранные с помощью Windows Driver Kit, а также пользовательские клиенты, которые работают с устройствами, IOCTL и общими буферами по шаблонам вроде Boost и Booster. Охват простирается от базовых DriverEntry, выгрузки и диспетчеризации IRP до примитивов синхронизации, перечисления процессов, компонентов мониторинга и защиты, обратных вызовов и таймеров ядра, минифильтров файловой системы для резервного копирования и защиты от удаления, примеров Windows Filtering Platform и драйверов мониторинга устройств. Общая библиотека шаблонов ядра ktl предоставляет переиспользуемые вспомогательные средства для блокировок, памяти, строк и коллекций во всех проектах. Сборка предназначена для авторов драйверов Windows и исследователей безопасности, которым нужны практические образцы кода ядра для мониторинга, фильтрации и контроля доступа — основы античитов и низкоуровневой инженерии системной безопасности.
