This repository is the companion source code for the second edition of Windows Kernel Programming, organized as chapter-by-chapter Visual Studio solutions that teach kernel-mode driver development hands on. The samples are primarily C and C++ WDM drivers built with the Windows Driver Kit, alongside user-mode clients that exercise devices, IOCTLs, and shared buffers through patterns such as Boost and Booster. Coverage runs from basic DriverEntry, unload, and IRP dispatch through synchronization primitives, process enumeration, monitoring and protection components, kernel callbacks and timers, file-system minifilters for backup and delete protection, Windows Filtering Platform examples, and device monitoring drivers. A shared ktl kernel template library supplies reusable helpers for locks, memory, strings, and collections used across the projects. The collection is intended for Windows driver authors and security researchers who need practical kernel samples for monitoring, filtering, and access-control work at the foundation of anti-cheat and low-level system security engineering.
