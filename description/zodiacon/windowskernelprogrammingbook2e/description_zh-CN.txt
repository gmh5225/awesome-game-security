本仓库是《Windows 内核编程》第二版的配套源代码，按章节组织为 Visual Studio 解决方案，以动手方式讲授内核模式驱动开发。示例主要为使用 Windows Driver Kit 构建的 C/C++ WDM 驱动，并配有用户模式客户端，通过 Boost、Booster 等模式练习设备、IOCTL 与共享缓冲区。内容从基础的 DriverEntry、卸载与 IRP 分发，到同步原语、进程枚举、监控与保护组件、内核回调与定时器、用于备份与删除保护的文件系统迷你筛选器、Windows Filtering Platform 示例以及设备监控驱动。共享的 ktl 内核模板库为各项目提供锁、内存、字符串与集合等可复用辅助工具。该集合面向需要实用内核示例以开展监控、过滤与访问控制工作的 Windows 驱动作者与安全研究人员，是反作弊与底层系统安全工程的基础。
