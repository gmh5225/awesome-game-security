本リポジトリは『Windows Kernel Programming』第2版の付属ソースコードで、章ごとに整理された Visual Studio ソリューションとして、カーネルモードドライバ開発を実践的に学べます。サンプルは主に Windows Driver Kit でビルドした C/C++ の WDM ドライバで、Boost や Booster などのパターンを通じてデバイス、IOCTL、共有バッファを操作するユーザーモードクライアントも含みます。DriverEntry、アンロード、IRP ディスパッチの基礎から、同期プリミティブ、プロセス列挙、監視・保護コンポーネント、カーネルコールバックとタイマー、バックアップと削除保護向けファイルシステムミニフィルター、Windows Filtering Platform の例、デバイス監視ドライバまでを扱います。共有の ktl カーネルテンプレートライブラリが、ロック、メモリ、文字列、コレクションなどプロジェクト横断で使えるヘルパーを提供します。監視、フィルタリング、アクセス制御の実用的なカーネルサンプルを必要とする Windows ドライバ作者やセキュリティ研究者、アンチチートや低レベルシステムセキュリティ工学の基盤を対象としたコレクションです。
