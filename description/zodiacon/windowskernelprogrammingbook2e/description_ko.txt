이 저장소는 『Windows Kernel Programming』 2판의 동반 소스 코드로, 장별로 구성된 Visual Studio 솔루션을 통해 커널 모드 드라이버 개발을 실습으로 학습합니다. 샘플은 주로 Windows Driver Kit으로 빌드한 C/C++ WDM 드라이버이며, Boost와 Booster 같은 패턴으로 장치, IOCTL, 공유 버퍼를 다루는 사용자 모드 클라이언트가 함께 제공됩니다. 기본적인 DriverEntry, 언로드, IRP 디스패치부터 동기화 프리미티브, 프로세스 열거, 모니터링 및 보호 구성 요소, 커널 콜백과 타이머, 백업 및 삭제 보호용 파일 시스템 미니필터, Windows Filtering Platform 예제, 장치 모니터링 드라이버까지 다룹니다. 공유 ktl 커널 템플릿 라이브러리가 프로젝트 전반에서 사용하는 잠금, 메모리, 문자열, 컬렉션용 재사용 가능한 헬퍼를 제공합니다. 모니터링, 필터링, 액세스 제어 작업에 실용적인 커널 샘플이 필요한 Windows 드라이버 작성자와 보안 연구자, 안티치트 및 저수준 시스템 보안 엔지니어링의 기초를 위한 컬렉션입니다.
