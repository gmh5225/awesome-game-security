ZAMR is a curated Android root module repository that indexes and distributes packages for Magisk, KernelSU, APatch, and the MMRL module manager. It bundles integrity and anti-detection tooling such as Play Integrity Fix, TEESimulator, Tricky Addon, Zygisk Assistant, HMA-OSS Zygisk, and SUSFS for KernelSU, alongside Zygisk runtimes and assorted utility modules. Module metadata is published as JSON track and update manifests, served through a JavaScript-driven GitHub Pages catalog that GitHub Actions refreshes hourly from upstream releases. The project is aimed at Android root users and mobile security researchers who need a maintained, one-stop source for Play Integrity bypass, root hiding, and related modules used when testing app and game protection on rooted devices.
