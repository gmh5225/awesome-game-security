ZAMR 是一个精选的 Android root 模块仓库，为 Magisk、KernelSU、APatch 和 MMRL 模块管理器索引并分发软件包。它集成了完整性验证与反检测工具，包括 Play Integrity Fix、TEESimulator、Tricky Addon、Zygisk Assistant、HMA-OSS Zygisk，以及面向 KernelSU 的 SUSFS，同时还包含 Zygisk 运行时及各类实用模块。模块元数据以 JSON 格式的 track 与 update 清单发布，通过由 JavaScript 驱动的 GitHub Pages 目录提供服务，GitHub Actions 每小时从上游 release 刷新内容。该项目面向 Android root 用户和移动安全研究人员，提供维护良好的一站式来源，用于获取 Play Integrity 绕过、root 隐藏及相关模块，以便在已 root 设备上测试应用与游戏保护机制。
