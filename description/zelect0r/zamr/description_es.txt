ZAMR es un repositorio curado de módulos root para Android que indexa y distribuye paquetes para Magisk, KernelSU, APatch y el gestor de módulos MMRL. Reúne herramientas de integridad y anti-detección como Play Integrity Fix, TEESimulator, Tricky Addon, Zygisk Assistant, HMA-OSS Zygisk y SUSFS para KernelSU, junto con runtimes Zygisk y diversos módulos de utilidad. Los metadatos de los módulos se publican como manifiestos JSON de seguimiento y actualización, servidos a través de un catálogo de GitHub Pages impulsado por JavaScript que GitHub Actions actualiza cada hora desde las versiones upstream. El proyecto está dirigido a usuarios root de Android e investigadores de seguridad móvil que necesitan una fuente única y mantenida para el bypass de Play Integrity, el ocultamiento de root y módulos relacionados utilizados al probar la protección de aplicaciones y juegos en dispositivos con root.
