ZAMR 是一個精選的 Android root 模組儲存庫，為 Magisk、KernelSU、APatch 和 MMRL 模組管理器索引並分發軟體套件。它整合了完整性驗證與反偵測工具，包括 Play Integrity Fix、TEESimulator、Tricky Addon、Zygisk Assistant、HMA-OSS Zygisk，以及面向 KernelSU 的 SUSFS，同時還包含 Zygisk 執行階段及各式實用模組。模組中繼資料以 JSON 格式的 track 與 update 清單發布，透過由 JavaScript 驅動的 GitHub Pages 目錄提供服務，GitHub Actions 每小時從上游 release 刷新內容。該專案面向 Android root 使用者與行動安全研究人員，提供維護良好的一站式來源，用於取得 Play Integrity 繞過、root 隱藏及相關模組，以便在已 root 裝置上測試應用與遊戲保護機制。
