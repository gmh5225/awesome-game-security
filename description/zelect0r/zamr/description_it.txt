ZAMR è un repository curato di moduli root per Android che indicizza e distribuisce pacchetti per Magisk, KernelSU, APatch e il gestore moduli MMRL. Raggruppa strumenti di integrità e anti-rilevamento come Play Integrity Fix, TEESimulator, Tricky Addon, Zygisk Assistant, HMA-OSS Zygisk e SUSFS per KernelSU, insieme a runtime Zygisk e vari moduli di utilità. I metadati dei moduli sono pubblicati come manifest JSON di track e aggiornamento, serviti tramite un catalogo GitHub Pages basato su JavaScript che GitHub Actions aggiorna ogni ora dalle release upstream. Il progetto è rivolto agli utenti root Android e ai ricercatori di sicurezza mobile che necessitano di una fonte unica e mantenuta per il bypass di Play Integrity, il nascondimento del root e moduli correlati utilizzati nel test della protezione di app e giochi su dispositivi rootati.
