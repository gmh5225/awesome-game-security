ZAMR — это курируемый репозиторий root-модулей для Android, который индексирует и распространяет пакеты для Magisk, KernelSU, APatch и менеджера модулей MMRL. В него входят инструменты проверки целостности и обхода обнаружения, такие как Play Integrity Fix, TEESimulator, Tricky Addon, Zygisk Assistant, HMA-OSS Zygisk и SUSFS для KernelSU, а также среды выполнения Zygisk и различные утilitарные модули. Метаданные модулей публикуются в виде JSON-манифестов track и update и доступны через каталог GitHub Pages на JavaScript, который GitHub Actions ежечасно обновляет из upstream-релизов. Проект ориентирован на пользователей root Android и исследователей мобильной безопасности, которым нужен поддерживаемый единый источник для обхода Play Integrity, скрытия root и связанных модулей, используемых при тестировании защиты приложений и игр на устройствах с root.
