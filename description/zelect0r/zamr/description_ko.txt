ZAMR는 Magisk, KernelSU, APatch, MMRL 모듈 관리자용 패키지를 색인하고 배포하는 엄선된 Android root 모듈 저장소입니다. Play Integrity Fix, TEESimulator, Tricky Addon, Zygisk Assistant, HMA-OSS Zygisk, KernelSU용 SUSFS 등 무결성 및 탐지 회피 도구와 Zygisk 런타임 및 각종 유틸리티 모듈을 함께 제공합니다. 모듈 메타데이터는 JSON track 및 update 매니페스트로 게시되며, JavaScript 기반 GitHub Pages 카탈로그를 통해 제공되고 GitHub Actions가 상류 릴리스에서 매시간 갱신합니다. 이 프로젝트는 root된 기기에서 앱 및 게임 보호를 테스트할 때 사용하는 Play Integrity 우회, root 숨김 및 관련 모듈에 대한 유지보수된 원스톱 소스가 필요한 Android root 사용자 및 모바일 보안 연구자를 대상으로 합니다.
