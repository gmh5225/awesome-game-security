ZAMR は、Magisk、KernelSU、APatch、MMRL モジュールマネージャー向けのパッケージを索引・配布する、厳選された Android root モジュールリポジトリです。Play Integrity Fix、TEESimulator、Tricky Addon、Zygisk Assistant、HMA-OSS Zygisk、KernelSU 向け SUSFS などの整合性検証・検出回避ツールに加え、Zygisk ランタイムや各種ユーティリティモジュールも同梱しています。モジュールのメタデータは JSON 形式の track および update マニフェストとして公開され、JavaScript 駆動の GitHub Pages カタログ経由で提供されます。GitHub Actions が上流リリースから毎時更新します。本プロジェクトは、root 化端末上でアプリやゲーム保護のテストに用いる Play Integrity バイパス、root 隠蔽、関連モジュールの保守されたワンストップソースを必要とする Android root ユーザーおよびモバイルセキュリティ研究者を対象としています。
