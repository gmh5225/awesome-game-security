Fission Plugin API は、主要なリバースエンジニアリング向けプラットフォーム用に書かれたスクリプトを、それらのネイティブ製品の代わりに Fission 解析エンジン上で動かせる、実験的な Rust ファーストのヘッドレスプラグイン SDK およびクロスツール互換ランタイムです。Rust ホスト（フィクスチャデータまたは Fission CLI）と、IDA Pro Python、Ghidra、Binary Ninja、angr 向けのプロファイル別シムの間では、バージョン付き JSON-lines ワイヤプロトコルで通信します。能力は明示的にネゴシエーションされ、未サポートの呼び出しはサイレントなスタブではなくエラーで失敗します。実関数の発見には Fission の contract API を使え、フィクスチャモードでは開発用にマップ済みバイト読み取りをサポートします。ワークスペースにはプロトコル crate、SDK、Python エントリポイント、適合テストが含まれます。既存の RE 自動化やプラグインスクリプトを、バイナリ解析・リバースエンジニアリングおよび関連するゲームセキュリティワークフロー向けの統一されたヘッドレスパイプラインで再利用したい開発者とセキュリティ研究者を対象としています。
