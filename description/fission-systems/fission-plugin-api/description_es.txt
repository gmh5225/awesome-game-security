Fission Plugin API es un SDK de plugins headless experimental, con prioridad en Rust, y un runtime de compatibilidad entre herramientas que permite ejecutar scripts escritos para las principales plataformas de ingeniería inversa contra el motor de análisis Fission en lugar de esos productos nativos. Utiliza un protocolo de cableado JSON-lines versionado entre un host Rust (datos de fixture o la CLI de Fission) y shims específicos por perfil para IDA Pro Python, Ghidra, Binary Ninja y angr. Las capacidades se negocian de forma explícita, las llamadas no admitidas fallan con errores en lugar de stubs silenciosos, y el descubrimiento real de funciones puede usar la API contract de Fission mientras que el modo fixture admite lecturas de bytes mapeados para desarrollo. El espacio de trabajo incluye crates de protocolo, un SDK, puntos de entrada en Python y pruebas de conformidad. Está dirigido a desarrolladores e investigadores de seguridad que quieren reutilizar la automatización RE y los scripts de plugins existentes en una canalización headless unificada para análisis binario, ingeniería inversa y flujos de trabajo relacionados con la seguridad en juegos.
