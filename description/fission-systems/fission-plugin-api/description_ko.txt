Fission Plugin API는 주요 리버스 엔지니어링 플랫폼용으로 작성된 스크립트를 해당 네이티브 제품 대신 Fission 분석 엔진에서 실행할 수 있게 하는 실험적인 Rust 우선 헤드리스 플러그인 SDK 및 크로스 도구 호환 런타임입니다. Rust 호스트(픽스처 데이터 또는 Fission CLI)와 IDA Pro Python, Ghidra, Binary Ninja, angr용 프로필별 심 사이에서는 버전이 있는 JSON-lines 와이어 프로토콜로 통신합니다. 기능은 명시적으로 협상되며, 지원되지 않는 호출은 조용한 스텁이 아니라 오류로 실패합니다. 실제 함수 탐색에는 Fission의 contract API를 사용할 수 있고, 픽스처 모드는 개발을 위해 매핑된 바이트 읽기를 지원합니다. 워크스페이스에는 프로토콜 crate, SDK, Python 진입점, 적합성 테스트가 포함됩니다. 바이너리 분석, 리버스 엔지니어링 및 관련 게임 보안 워크플로를 위한 통합된 헤드리스 파이프라인에서 기존 RE 자동화 및 플러그인 스크립트를 재사용하려는 개발자와 보안 연구자를 대상으로 합니다.
