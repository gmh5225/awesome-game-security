Fission Plugin API — экспериментальный headless SDK плагинов с приоритетом Rust и кросс-инструментальная среда совместимости, позволяющая запускать скрипты, написанные для основных платформ реверс-инжиниринга, на движке анализа Fission вместо нативных продуктов. Между Rust-хостом (фикстурные данные или Fission CLI) и профильными шимами для IDA Pro Python, Ghidra, Binary Ninja и angr используется версионированный проводной протокол JSON-lines. Возможности согласуются явно, неподдерживаемые вызовы завершаются ошибками, а не тихими заглушками; обнаружение реальных функций может опираться на contract API Fission, а режим фикстур поддерживает отображённые чтения байтов для разработки. Рабочее пространство включает crates протокола, SDK, точки входа на Python и тесты соответствия. Ориентирован на разработчиков и исследователей безопасности, которые хотят переиспользовать существующую RE-автоматизацию и скрипты плагинов в едином headless-конвейере для бинарного анализа, реверс-инжиниринга и связанных с игровой безопасностью рабочих процессов.
