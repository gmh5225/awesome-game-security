Fission Plugin API is an experimental Rust-first, headless plugin SDK and cross-tool compatibility runtime that lets scripts written for major reverse-engineering platforms run against the Fission analysis engine instead of those native products. It speaks a versioned JSON-lines wire protocol between a Rust host (fixture data or the Fission CLI) and profile-specific shims for IDA Pro Python, Ghidra, Binary Ninja, and angr. Capabilities are negotiated explicitly, unsupported calls fail with errors rather than silent stubs, and real function discovery can use Fission’s contract API while fixture mode supports mapped byte reads for development. The workspace includes protocol crates, an SDK, Python entry points, and conformance tests. It targets developers and security researchers who want to reuse existing RE automation and plugin scripts in a unified, headless pipeline for binary analysis, reverse engineering, and related game-security workflows.
