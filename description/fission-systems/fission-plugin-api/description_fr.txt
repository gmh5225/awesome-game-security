Fission Plugin API est un SDK de plugins headless expérimental, axé sur Rust, et un runtime de compatibilité multi-outils qui permet d’exécuter des scripts écrits pour les principales plateformes de reverse engineering sur le moteur d’analyse Fission plutôt que sur ces produits natifs. Il utilise un protocole filaire JSON-lines versionné entre un hôte Rust (données de fixture ou CLI Fission) et des shims spécifiques aux profils pour IDA Pro Python, Ghidra, Binary Ninja et angr. Les capacités sont négociées explicitement, les appels non pris en charge échouent avec des erreurs plutôt que des stubs silencieux, et la découverte réelle de fonctions peut s’appuyer sur l’API contract de Fission tandis que le mode fixture prend en charge les lectures d’octets mappés pour le développement. L’espace de travail comprend des crates de protocole, un SDK, des points d’entrée Python et des tests de conformité. Il s’adresse aux développeurs et chercheurs en sécurité qui souhaitent réutiliser l’automatisation RE et les scripts de plugins existants dans un pipeline headless unifié pour l’analyse binaire, le reverse engineering et les flux de travail liés à la sécurité des jeux.
