VulkanWallhack 是一款可在 Windows 上注入的 DLL，通过挂钩 Vulkan 图形 API，在使用 Vulkan 渲染器的游戏中实现穿墙显示玩家或几何体。项目为 Visual Studio C++ 工程，使用 MinHook 进行 x86/x64 函数劫持，并内置 Vulkan 头文件以便在进程启动早期拦截渲染管线。运行时热键可切换穿墙、备用着色与调试日志；逗号与句号键可暴力尝试顶点缓冲步长，以在引擎布局不同时定位绘制数据。文档中的默认步长针对 Valheim 式模型识别，说明步长猜测如何与 API 挂钩结合以操纵深度或可见性。本项目面向游戏安全、反作弊与逆向工程受众，用于研究底层 Vulkan 挂钩如何促成客户端视觉作弊，以及防御方需要监控的内容。
