VulkanWallhack は Windows 向けの注入可能な DLL で、Vulkan グラフィックス API をフックし、Vulkan レンダラーを使うゲームで壁越しにプレイヤーやジオメトリを表示します。Visual Studio の C++ プロジェクトとして構築され、MinHook による x86/x64 関数デトアー、およびプロセス起動直後にレンダーパイプラインを横取りするための同梱 Vulkan ヘッダを利用します。実行時ホットキーでウォールハック、代替カラーリング、デバッグログを切り替え、カンマとピリオドキーで頂点バッファのストライドを総当たりし、エンジンごとに異なるレイアウトから描画データを特定します。文書化されたデフォルトストライドは Valheim 風のモデル認識向けで、ストライド推測が API フックと組み合わさって深度や可視性を操作する仕組みを示しています。本プロジェクトはゲームセキュリティ、反チート、リバースエンジニアリングの学習者向けに、低レベル Vulkan フックがクライアント側の視覚チートを可能にする方法と、防御側が監視すべき点を研究するためのものです。
