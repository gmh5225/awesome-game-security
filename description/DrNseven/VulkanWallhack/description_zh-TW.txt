VulkanWallhack 是一款可在 Windows 上注入的 DLL，透過掛鉤 Vulkan 圖形 API，在使用 Vulkan 渲染器的遊戲中實現穿牆顯示玩家或幾何體。專案為 Visual Studio C++ 工程，使用 MinHook 進行 x86/x64 函式攔截，並內建 Vulkan 標頭檔以便在程序啟動早期攔截渲染管線。執行時熱鍵可切換穿牆、備用著色與偵錯日誌；逗號與句號鍵可暴力嘗試頂點緩衝步長，以在引擎配置不同時定位繪製資料。文件中的預設步長針對 Valheim 式模型辨識，說明步長猜測如何與 API 掛鉤結合以操縱深度或可見性。本專案面向遊戲安全、反作弊與逆向工程受眾，用於研究底層 Vulkan 掛鉤如何促成用戶端視覺作弊，以及防禦方需要監控的內容。
