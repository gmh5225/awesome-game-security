VulkanWallhack — инжектируемая DLL для Windows, перехватывающая графические API Vulkan, чтобы показывать игроков или геометрию сквозь стены в играх с рендерером Vulkan. Проект собран в Visual Studio на C++ и использует MinHook для перехвата функций x86/x64, с поставляемыми заголовками Vulkan для раннего перехвата конвейера рендеринга при запуске процесса. Горячие клавиши в рантайме переключают wallhack, альтернативную раскраску и отладочное логирование, а клавиши запятой и точки перебирают шаг vertex buffer, чтобы найти данные отрисовки при разных раскладках движка. Документированный шаг по умолчанию ориентирован на распознавание моделей в духе Valheim и показывает, как подбор stride сочетается с API-хуками для управления глубиной или видимостью. Проект предназначен для специалистов по игровой безопасности, античиту и reverse engineering, изучающих, как низкоуровневый перехват Vulkan даёт клиентские визуальные читы и что должны отслеживать защитники.
