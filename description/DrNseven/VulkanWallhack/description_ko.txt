VulkanWallhack은 Windows에 주입 가능한 DLL로, Vulkan 그래픽 API를 후킹하여 Vulkan 렌더러를 사용하는 게임에서 벽 너머로 플레이어나 지오메트리를 노출합니다. Visual Studio C++ 프로젝트로 구축되었으며 MinHook으로 x86/x64 함수 디투어를 수행하고, 프로세스 시작 초기에 렌더 파이프라인을 가로채기 위해 Vulkan 헤더를 번들로 포함합니다. 런타임 단축키로 월핵, 대체 색상, 디버그 로깅을 전환하고, 쉼표와 마침표 키로 정점 버퍼 stride를 무차별 시도해 엔진 레이아웃이 다를 때 그리기 데이터를 찾습니다. 문서화된 기본 stride는 Valheim 스타일 모델 인식을 대상으로 하며, stride 추측이 API 후킹과 결합해 깊이나 가시성을 조작하는 방식을 보여 줍니다. 이 프로젝트는 게임 보안, 안티치트, 리버스 엔지니어링 대상으로, 저수준 Vulkan 후킹이 클라이언트 측 시각 치트를 어떻게 가능하게 하는지와 방어 측이 무엇을 모니터해야 하는지 연구하기 위한 것입니다.
