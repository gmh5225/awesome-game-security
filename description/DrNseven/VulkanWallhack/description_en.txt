VulkanWallhack is a Windows injectable DLL that hooks Vulkan graphics APIs to expose players or geometry through walls in games that use the Vulkan renderer. It is built as a Visual Studio C++ project and uses MinHook for x86/x64 function detours, with bundled Vulkan headers for intercepting the render pipeline early in process startup. Runtime hotkeys toggle wallhack, alternate coloring, and debug logging, while comma and period keys brute-force vertex buffer strides to locate draw data when engine layouts differ. A documented default stride targets Valheim-style model recognition, illustrating how stride guessing couples with API hooks to manipulate depth or visibility. The project serves game security, anti-cheat, and reverse-engineering audiences studying how low-level Vulkan hooking enables client-side visual cheats and what defenders must monitor.
