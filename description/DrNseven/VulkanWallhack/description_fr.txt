VulkanWallhack est une DLL injectable sous Windows qui accroche les API graphiques Vulkan pour révéler les joueurs ou la géométrie à travers les murs dans les jeux utilisant le moteur de rendu Vulkan. Le projet est une solution Visual Studio C++ et s’appuie sur MinHook pour les détours de fonctions x86/x64, avec des en-têtes Vulkan fournis pour intercepter le pipeline de rendu dès le démarrage du processus. Des raccourcis à l’exécution activent le wallhack, une coloration alternative et la journalisation de débogage, tandis que les touches virgule et point testent systématiquement les pas de tampon de sommets pour localiser les données de dessin lorsque les mises en page moteur diffèrent. Un pas par défaut documenté vise la reconnaissance de modèles de type Valheim, illustrant comment la recherche de pas s’associe aux hooks API pour manipuler la profondeur ou la visibilité. Le projet s’adresse à la sécurité des jeux, à l’anti-triche et au reverse engineering pour étudier comment le hooking Vulkan bas niveau permet des triches visuelles côté client et ce que les défenseurs doivent surveiller.
