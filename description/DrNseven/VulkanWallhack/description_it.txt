VulkanWallhack è una DLL iniettabile su Windows che aggancia le API grafiche Vulkan per mostrare giocatori o geometria attraverso i muri nei giochi che usano il renderer Vulkan. È un progetto C++ di Visual Studio e usa MinHook per i detour di funzioni x86/x64, con header Vulkan inclusi per intercettare la pipeline di rendering all’avvio del processo. Tasti di scelta rapida a runtime attivano wallhack, colorazione alternativa e log di debug, mentre i tasti virgola e punto provano a forza gli stride del buffer dei vertici per individuare i dati di disegno quando i layout del motore differiscono. Uno stride predefinito documentato mira al riconoscimento di modelli in stile Valheim, mostrando come l’indovinare lo stride si combina con gli hook API per manipolare profondità o visibilità. Il progetto è rivolto a sicurezza dei giochi, anti-cheat e reverse engineering per studiare come l’hooking Vulkan a basso livello abilita cheat visivi lato client e cosa devono monitorare i difensori.
