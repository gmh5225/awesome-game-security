AnyWhere ist eine leichtgewichtige Android-App zur Simulation von GPS-Standorten, die dem Debuggen standortbasierter Dienste und dem Testen dient, wie Apps geografische Daten verarbeiten. In Java geschrieben und mit einem Gradle-basierten Android-Build erstellt, nutzt sie OpenStreetMap zur Kartenauswahl, einen schwebenden Overlay-Joystick zur Simulation von Geh-, Lauf- oder Radfahrgeschwindigkeiten und speichert den Standortverlauf mit optionaler IP-basierter Koordinatensuche. Zudem enthält sie ein LSPosed/Xposed-Modul, das das System hookt, um Mock-Location-Flags zu verbergen und gängige Spoofing-Prüfungen zu umgehen. Das Projekt ist nützlich für Entwickler, Reverse Engineers und Sicherheitsforscher, die Location-Spoofing, Mock-GPS-Erkennung und Anti-Cheat-Mechanismen in mobilen Spielen und LBS-Apps untersuchen.
