AnyWhere는 GPS 위치를 시뮬레이션하는 경량 Android 앱으로, 위치 기반 서비스를 디버깅하고 앱이 지리 데이터를 어떻게 처리하는지 테스트하는 데 목적이 있습니다. Java로 작성되었으며 Gradle 기반 Android 빌드를 사용하고, OpenStreetMap으로 지도에서 위치를 선택하며, 플로팅 오버레이 조이스틱으로 걷기·달리기·자전거 속도를 시뮬레이션하고, 위치 기록을 저장하며 IP 기반 좌표 조회도 선택적으로 제공합니다. 또한 LSPosed/Xposed 모듈을 포함하여 시스템을 후킹해 모의 위치 플래그를 숨기고 일반적인 스푸핑 검사를 우회합니다. 이 프로젝트는 모바일 게임과 LBS 앱에서 위치 스푸핑, 모의 GPS 탐지, 안티치트 메커니즘을 연구하는 개발자, 리버스 엔지니어, 보안 연구자에게 유용합니다.
