AnyWhere es una aplicación Android ligera para simular la ubicación GPS, orientada a depurar servicios basados en la ubicación y probar cómo las aplicaciones gestionan los datos geográficos. Escrita en Java con una compilación Android basada en Gradle, utiliza OpenStreetMap para seleccionar puntos en el mapa, un joystick flotante superpuesto para simular velocidades de caminar, correr o andar en bicicleta, y guarda el historial de ubicaciones con búsqueda opcional de coordenadas por IP. También incluye un módulo LSPosed/Xposed que engancha el sistema para ocultar las marcas de ubicación simulada y eludir las comprobaciones habituales de suplantación. El proyecto resulta útil para desarrolladores, ingenieros inversos e investigadores de seguridad que estudian la suplantación de ubicación, la detección de GPS simulado y los mecanismos antitrampas en juegos móviles y aplicaciones LBS.
