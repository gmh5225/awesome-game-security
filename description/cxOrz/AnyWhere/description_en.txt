AnyWhere is a lightweight Android app for simulating GPS location, aimed at debugging location-based services and testing how apps handle geographic data. Written in Java with a Gradle-based Android build, it uses OpenStreetMap for map picking, a floating overlay joystick to simulate walking, running, or cycling speeds, and stores location history with optional IP-based coordinate lookup. It also ships an LSPosed/Xposed module that hooks the system to hide mock-location flags and bypass common spoofing checks. The project is useful for developers, reverse engineers, and security researchers studying location spoofing, mock-GPS detection, and anti-cheat mechanisms in mobile games and LBS apps.
