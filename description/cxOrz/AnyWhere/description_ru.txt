AnyWhere — это лёгкое Android-приложение для симуляции GPS-позиции, предназначенное для отладки сервисов на основе геолокации и проверки того, как приложения обрабатывают географические данные. Написано на Java с использованием Android-сборки на Gradle; для выбора точки на карте используется OpenStreetMap, плавающий оверлей-джойстик имитирует скорость ходьбы, бега или езды на велосипеде, а история местоположений сохраняется с опциональным поиском координат по IP. Также в комплекте модуль LSPosed/Xposed, который перехватывает системные вызовы, чтобы скрыть флаги mock-location и обойти типичные проверки на подмену координат. Проект полезен разработчикам, reverse-инженерам и исследователям безопасности, изучающим подмену геолокации, обнаружение mock-GPS и античит-механизмы в мобильных играх и LBS-приложениях.
