ServerGuard è una mod server per Vintage Story che rafforza i server multigiocatore contro i cheat lato client intercettando i dati del mondo prima che raggiungano i giocatori. Scritta in C#, usa patch Harmony sullo stack di rete del server per nascondere blocchi di minerale completamente racchiusi e sostituire parte del minerale visibile con esche nella roccia ospite, mitigando exploit di risorse in stile x-ray. Filtra anche la visibilità delle entità con raycast lato server così che creature occluse e, opzionalmente, giocatori non vengano inviati ai client, e può generare esche di creature configurabili per confondere ulteriormente gli strumenti wallhack. Gli amministratori regolano occultamento del minerale, densità delle esche, caching dei chunk, budget di raggi delle entità e conteggi delle esche tramite ModConfig e monitorano la protezione con il comando /serverguard. È rivolto agli operatori di server Vintage Story che necessitano di difese anti-cheat pratiche senza modificare il client di gioco.
