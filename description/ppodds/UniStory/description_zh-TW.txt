UniStory 是一款基於 Unity 的 MapleStory 客戶端重實作，可載入官方 MapleStory WZ 資源包，並在現代引擎中渲染地圖、角色及相關遊戲內容。專案以 C# 撰寫，依賴 WzComparerR2.WzLib 解析 KMS/TMS 格式的 WZ 資料，並實作 MapleStory 風格的地圖圖層、foothold 物理、傳送門、精靈動畫，以及從提取資源中播放 BGM。該專案整合了 Unity 2D 渲染、用於音訊解碼的 NAudio，以及透過模組化載入器支援 Character、Map、Mob、Npc、Skill 等標準 WZ 類別的 LZ4 壓縮 WZ 支援。它面向搭建私服、研究 MapleStory 客戶端機制，或從 WZ 檔案進行逆向工程與資源分析的開發者。
