UniStory は Unity ベースの MapleStory クライアント再実装で、公式 MapleStory の WZ アセットアーカイブを読み込み、現代のエンジンでマップ、キャラクター、その他のゲームコンテンツを描画します。C# で書かれており、WzComparerR2.WzLib を使用して KMS/TMS 形式の WZ データを解析し、MapleStory 風のマップレイヤー、foothold 物理、ポータル、スプライトアニメーション、抽出アセットからの BGM 再生を実装しています。本プロジェクトは Unity 2D レンダリング、音声デコード用の NAudio、Character、Map、Mob、Npc、Skill など標準 WZ カテゴリ向けモジュール式ローダーによる LZ4 圧縮 WZ サポートを統合しています。プライベートサーバー構築、MapleStory クライアントの仕組みの研究、WZ ファイルからのリバースエンジニアリングおよびゲームアセット分析を行う開発者を対象としています。
