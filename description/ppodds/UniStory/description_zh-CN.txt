UniStory 是一款基于 Unity 的 MapleStory 客户端重实现，可加载官方 MapleStory WZ 资源包，并在现代引擎中渲染地图、角色及相关游戏内容。项目使用 C# 编写，依赖 WzComparerR2.WzLib 解析 KMS/TMS 格式的 WZ 数据，并实现 MapleStory 风格的地图层级、foothold 物理、传送门、精灵动画以及从提取资源中播放 BGM。该项目集成了 Unity 2D 渲染、用于音频解码的 NAudio，以及通过模块化加载器支持 Character、Map、Mob、Npc、Skill 等标准 WZ 类别的 LZ4 压缩 WZ 支持。它面向搭建私服、研究 MapleStory 客户端机制，或从 WZ 文件进行逆向工程与资源分析的开发者。
