Этот проект — нативный движок ремастера для Linux игры Moorhuhn Adventure 2, который статически перекомпилирует оригинальный исполняемый файл Windows x86-32 2005 года в C и запускает его через чистый слой совместимости Win32 и DirectX без Wine и эмулятора. Автономный Python-лифтер на базе Capstone разбирает PE-бинарник, обнаруживает тысячи функций и таблиц переходов и генерирует C, а C-рантайм эмулирует плоскую гостевую память, поведение сопроцессора x87 FPU и API DirectDraw, DirectInput, DirectSound и видео в стиле DirectShow за рендерером OpenGL 3.3 Core на SDL2 и FFmpeg. Сопутствующие Python-утилиты распаковывают игровые архивы, применяют нейросетевой 4K-апскейлинг фонов и спрайтов и собирают переносимые сборки для Linux. Он ориентирован на специалистов по реверс-инжинирингу и исследователей сохранения игр, интересующихся статическим подъёмом бинарников, внутренностями унаследованных Win32-игр и сквозной перекомпиляцией коммерческих PE-исполняемых файлов.
