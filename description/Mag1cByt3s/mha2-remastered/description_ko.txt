이 프로젝트는 Moorhuhn Adventure 2용 네이티브 Linux 리마스터 엔진으로, 2005년 Windows x86-32 실행 파일을 정적으로 재컴파일해 C로 변환하고 Wine이나 에뮬레이터 없이 클린룸 Win32 및 DirectX 호환 계층을 통해 실행합니다. Capstone을 사용하는 독립형 Python 리프터가 PE 바이너리를 파싱해 수천 개의 함수와 스위치 테이블을 찾아 C를 생성하며, C 런타임은 평탄한 게스트 메모리, x87 FPU 동작, DirectDraw·DirectInput·DirectSound 및 DirectShow 스타일 비디오 API를 에뮬레이트하고 OpenGL 3.3 Core 렌더러는 SDL2와 FFmpeg로 구축됩니다. 동봉 Python 도구는 게임 아카이브를 풀고, 배경과 스프라이트에 신경망 4K 업스케일을 적용하며, 이식 가능한 Linux 빌드를 패키징합니다. 정적 바이너리 리프팅, 레거시 Win32 게임 내부, 상용 PE 실행 파일의 종단 간 재컴파일에 관심 있는 리버스 엔지니어와 보존 연구자를 대상으로 합니다.
