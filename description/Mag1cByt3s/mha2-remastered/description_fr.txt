Ce projet est un moteur de remastérisation Linux natif pour Moorhuhn Adventure 2 qui recompile statiquement l'exécutable Windows x86-32 original de 2005 en C et l'exécute via une couche de compatibilité Win32 et DirectX en clean room, sans Wine ni émulateur. Un lifter Python autonome utilisant Capstone analyse le binaire PE pour découvrir des milliers de fonctions et de tables de branchement et émet du C généré, tandis que le runtime C émule la mémoire invitée plate, le comportement du coprocesseur x87 FPU et les API DirectDraw, DirectInput, DirectSound et vidéo de type DirectShow, derrière un moteur de rendu OpenGL 3.3 Core construit avec SDL2 et FFmpeg. Des outils Python compagnons décompressent les archives du jeu, appliquent un upscaling neuronal 4K pour les arrière-plans et les sprites, et empaquettent des builds Linux portables. Il s'adresse aux ingénieurs en rétro-ingénierie et aux chercheurs en préservation intéressés par le lifting binaire statique, les internes des jeux Win32 hérités et la recompilation de bout en bout d'exécutables PE commerciaux.
