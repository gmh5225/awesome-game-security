本プロジェクトは Moorhuhn Adventure 2 向けのネイティブ Linux リマスターエンジンで、2005 年の Windows x86-32 実行ファイルを静的再コンパイルして C に変換し、Wine やエミュレータを使わずクリーンルームの Win32 および DirectX 互換レイヤー上で動かします。Capstone を用いたスタンドアロンの Python リフターが PE バイナリを解析し、数千の関数とスイッチテーブルを検出して C を生成します。C ランタイムはフラットなゲストメモリ、x87 FPU の挙動、DirectDraw・DirectInput・DirectSound および DirectShow 風の動画 API をエミュレートし、SDL2 と FFmpeg で構築した OpenGL 3.3 Core レンダラーがバックエンドを担います。付属の Python ツールはゲームアーカイブの展開、背景とスプライトのニューラル 4K アップスケール、ポータブル Linux ビルドのパッケージ化を行います。静的バイナリリフティング、レガシー Win32 ゲームの内部、商用 PE 実行ファイルのエンドツーエンド再コンパイルに関心のあるリバースエンジニアおよび保存・保全研究者を対象としています。
