Este proyecto es un motor de remasterización nativo para Linux de Moorhuhn Adventure 2 que recompila estáticamente el ejecutable original de Windows x86-32 de 2005 a C y lo ejecuta mediante una capa de compatibilidad Win32 y DirectX en clean room, sin Wine ni emulador. Un elevador Python independiente que usa Capstone analiza el binario PE para descubrir miles de funciones y tablas de salto y emitir C generado, mientras el tiempo de ejecución en C emula memoria de invitado plana, el comportamiento de la FPU x87 y las API de DirectDraw, DirectInput, DirectSound y vídeo al estilo DirectShow, detrás de un renderizador OpenGL 3.3 Core construido con SDL2 y FFmpeg. Herramientas Python complementarias descomprimen archivos del juego, aplican escalado neuronal 4K a fondos y sprites, y empaquetan compilaciones portables para Linux. Está dirigido a ingenieros inversores e investigadores de preservación interesados en el lifting binario estático, los internos de juegos Win32 heredados y la recompilación de extremo a extremo de ejecutables PE comerciales.
