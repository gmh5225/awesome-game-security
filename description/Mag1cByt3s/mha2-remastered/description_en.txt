This project is a native Linux remaster engine for Moorhuhn Adventure 2 that statically recompiles the original 2005 Windows x86-32 executable into C and runs it through a clean-room Win32 and DirectX compatibility layer without Wine or an emulator. A standalone Python lifter using Capstone parses the PE binary to discover thousands of functions and switch tables and emit generated C, while the C runtime emulates flat guest memory, x87 FPU behavior, and DirectDraw, DirectInput, DirectSound, and DirectShow-style video APIs behind an OpenGL 3.3 Core renderer built with SDL2 and FFmpeg. Companion Python tools unpack game archives, apply neural 4K upscaling for backgrounds and sprites, and package portable Linux builds. It is aimed at reverse engineers and preservation researchers interested in static binary lifting, legacy Win32 game internals, and end-to-end recompilation of commercial PE executables.
