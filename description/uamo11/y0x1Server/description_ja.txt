本プロジェクトは、piqueserver および pyspades スタック上に構築され、PySnip を系譜とし継続的なメンテナンスと機能追加が行われている、カスタマイズ可能な Ace of Spades 0.75 専用ゲームサーバーです。実装は主に Python 3.10 以降で、パフォーマンスが重要なネットワーク処理とボクセルロジックは Cython と C++ で記述されています。サーバーにはマップローテーション、Docker デプロイ、リモート SSH コンソール、BAN の subscribe/publish、多数のオプションスクリプトなど、充実した管理ツールが同梱されています。ゲームセキュリティ面ではサーバー側バリデーション、設定可能なスピードハック検出、anticheat・エイムボットヒューリスティクス・メモリチェックツールなどの反悪用拡張に加え、votekick や trusted ロールといったモデレーション機能を重視しています。コミュニティサーバー運営者や開発者が AoS マッチをホストしつつ、チート、グリーフ、クライアント側エクスプロイトを抑止するために向けられています。
