Questo progetto è un server di gioco dedicato Ace of Spades 0.75 personalizzabile, costruito sullo stack piqueserver e pyspades, discendente da PySnip con manutenzione continua e sviluppo di funzionalità. È implementato principalmente in Python 3.10 o versioni successive, con networking e logica voxel critiche per le prestazioni in Cython e C++. Il server include strumenti di amministrazione estesi: rotazione mappe, deployment Docker, console SSH remota, subscribe e publish dei ban, e una vasta libreria di script opzionali. Per la sicurezza di gioco enfatizza la validazione lato server, il rilevamento configurabile dello speedhack ed estensioni anti-abuso come anticheat, euristiche anti-aimbot e strumenti di controllo memoria, insieme a funzioni di moderazione come votekick e ruoli fidati. È rivolto a operatori e sviluppatori di server di community che devono ospitare match AoS limitando cheat, griefing ed exploit lato client.
