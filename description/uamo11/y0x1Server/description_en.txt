This project is a customizable Ace of Spades 0.75 dedicated game server built on the piqueserver and pyspades stack, descended from PySnip with ongoing maintenance and feature work. It is implemented primarily in Python 3.10 or newer, with performance-critical networking and voxel logic in Cython and C++. The server bundles extensive administration tooling, including map rotation, Docker deployment, remote SSH console, ban subscribe and publish, and a large library of optional scripts. For game security, it emphasizes server-side validation, configurable speedhack detection, and bundled anti-abuse extensions such as anticheat, aimbot heuristics, and memory-check tooling alongside moderation features like votekick and trusted roles. It is aimed at community server operators and developers who need to host AoS matches while limiting cheating, griefing, and client-side exploits.
