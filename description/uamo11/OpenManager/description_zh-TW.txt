OpenManager 是一款開源的 Android 檔案管理器與逆向工程工作台，面向在裝置上進行的高階套件與檔案系統工作流程。專案主要以 Kotlin 與 Java 搭配 Android Gradle 工具鏈建置，並輔以用於 JNI 與底層系統呼叫探測的原生 C/C++ 元件。核心能力包含 root 環境下的檔案存取、針對 smali 及相關格式的語法高亮編輯器、DEX 與 ARSC 編輯器、APK 工具鏈、腳本自動化、FTP 伺服器支援，以及用於 APK 修改的 toast 對話框注入輔助功能。它適用於在已 root 硬體上修補、檢查與分析 Android 應用程式與遊戲客戶端的行動逆向工程師、模組作者與遊戲安全研究人員。
