OpenManager 是一款开源的 Android 文件管理器与逆向工程工作台，面向在设备上进行的高级包与文件系统工作流。项目主要使用 Kotlin 与 Java 配合 Android Gradle 工具链构建，并辅以用于 JNI 与底层系统调用探测的本地 C/C++ 组件。核心能力包括 root 环境下的文件访问、针对 smali 及相关格式的语法高亮编辑器、DEX 与 ARSC 编辑器、APK 工具链、脚本自动化、FTP 服务器支持，以及用于 APK 修改的 toast 对话框注入辅助功能。它面向在已 root 硬件上修补、检查与分析 Android 应用与游戏客户端的移动逆向工程师、模组作者与游戏安全研究人员。
