OpenManager is an open-source Android file manager and reverse-engineering workbench aimed at advanced on-device package and filesystem workflows. The project is built mainly in Kotlin and Java with the Android Gradle toolchain, with supporting native C/C++ components for JNI and low-level syscall probing. Key capabilities include rooted file access, a syntax-highlighted editor for smali and related formats, DEX and ARSC editors, APK tooling, script automation, FTP server support, and toast-dialog injection helpers for APK modification. It is intended for mobile reverse engineers, modders, and game security researchers who patch, inspect, and analyze Android apps and game clients on rooted hardware.
