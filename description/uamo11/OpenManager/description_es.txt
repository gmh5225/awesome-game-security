OpenManager es un administrador de archivos Android de código abierto y un banco de trabajo de ingeniería inversa orientado a flujos avanzados de paquetes y del sistema de archivos en el propio dispositivo. El proyecto está desarrollado principalmente en Kotlin y Java con la cadena de herramientas Android Gradle, con componentes nativos en C/C++ para JNI y sondeo de llamadas al sistema de bajo nivel. Las capacidades clave incluyen acceso a archivos con root, un editor con resaltado de sintaxis para smali y formatos relacionados, editores DEX y ARSC, herramientas APK, automatización mediante scripts, soporte de servidor FTP y ayudas de inyección de diálogos toast para modificar APK. Está pensado para ingenieros inversos móviles, modders e investigadores de seguridad en juegos que parchean, inspeccionan y analizan apps Android y clientes de juegos en hardware con root.
