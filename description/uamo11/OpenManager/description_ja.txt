OpenManager は、デバイス上での高度なパッケージおよびファイルシステムワークフローを対象とした、オープンソースの Android ファイルマネージャー兼リバースエンジニアリング作業環境です。プロジェクトは主に Kotlin と Java で Android Gradle ツールチェーンを用いて構築され、JNI や低レベルなシステムコール調査のためのネイティブ C/C++ コンポーネントも含みます。主な機能には、root 済み環境でのファイルアクセス、smali などのシンタックスハイライト付きエディター、DEX および ARSC エディター、APK ツール群、スクリプト自動化、FTP サーバー対応、APK 改変向けの toast ダイアログ注入ヘルパーがあります。root 済み端末上で Android アプリやゲームクライアントのパッチ適用、検査、解析を行うモバイル向けリバースエンジニア、モッダー、ゲームセキュリティ研究者を想定しています。
