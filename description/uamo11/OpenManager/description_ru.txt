OpenManager — это менеджер файлов Android с открытым исходным кодом и рабочая среда для реверс-инжиниринга, ориентированная на продвинутые сценарии работы с пакетами и файловой системой непосредственно на устройстве. Проект в основном реализован на Kotlin и Java с инструментарием Android Gradle, с нативными компонентами на C/C++ для JNI и низкоуровневого зондирования системных вызовов. Ключевые возможности включают доступ к файлам с root, редактор с подсветкой синтаксиса для smali и родственных форматов, редакторы DEX и ARSC, инструменты для APK, автоматизацию сценариями, поддержку FTP-сервера и вспомогательные средства инъекции toast-диалогов для модификации APK. Он предназначен для мобильных реверс-инженеров, моддеров и исследователей безопасности игр, которые патчат, проверяют и анализируют Android-приложения и игровые клиенты на устройствах с root.
