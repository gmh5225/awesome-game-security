OpenManager è un file manager Android open source e un ambiente di lavoro per il reverse engineering pensato per flussi avanzati di gestione dei pacchetti e del filesystem direttamente sul dispositivo. Il progetto è costruito principalmente in Kotlin e Java con la toolchain Android Gradle, con componenti nativi C/C++ per JNI e sonde a basso livello sulle syscall. Le funzionalità principali includono accesso ai file con root, un editor con evidenziazione della sintassi per smali e formati correlati, editor DEX e ARSC, strumenti APK, automazione tramite script, supporto server FTP e helper per l'iniezione di dialoghi toast nelle modifiche agli APK. È destinato a reverse engineer mobile, modder e ricercatori di sicurezza nei giochi che applicano patch, ispezionano e analizzano app Android e client di gioco su hardware con root.
