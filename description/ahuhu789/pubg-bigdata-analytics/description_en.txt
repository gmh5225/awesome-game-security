This project is an end-to-end big data pipeline that ingests large-scale PlayerUnknown's Battlegrounds match records and flags player performances that look statistically abnormal in an esports anti-cheat context. It is implemented primarily in Python using PySpark for cleansing, Spark SQL match analytics, and MLlib K-Means clustering combined with game-physics rule checks such as extreme headshot rates or implausible movement. Processed results are stored in Apache Parquet and loaded into Apache Cassandra for query-oriented access, with an optional Docker Compose stack for the database. A Streamlit dashboard summarizes infrastructure status, match analytics, ranked anomaly alerts with explanations, and lookup by match or player identifiers. It suits researchers and practitioners exploring server-side or offline cheat detection, unsupervised anomaly scoring, and big-data tooling for competitive shooter telemetry rather than live client enforcement.
