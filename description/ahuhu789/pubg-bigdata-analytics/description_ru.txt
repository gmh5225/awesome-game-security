Этот проект — сквозной конвейер big data, который загружает крупномасштабные записи матчей PlayerUnknown's Battlegrounds и помечает показатели игроков, выглядящие статистически аномальными в контексте киберспортивного античита. Реализован в основном на Python: PySpark для очистки, Spark SQL для аналитики матчей и кластеризация K-Means в MLlib в сочетании с проверками игровой физики, например экстремальной долей хедшотов или неправдоподобного перемещения. Обработанные результаты сохраняются в Apache Parquet и загружаются в Apache Cassandra для запросного доступа; для базы данных опционально доступен стек Docker Compose. Панель Streamlit суммирует состояние инфраструктуры, аналитику матчей, ранжированные оповещения об аномалиях с пояснениями и поиск по идентификаторам матча или игрока. Подходит исследователям и практикам, изучающим серверное или офлайн-обнаружение читов, неконтролируемую оценку аномалий и инструменты big data для телеметрии соревновательных шутеров, а не для принудительного контроля на клиенте в реальном времени.
