이 프로젝트는 대규모 PlayerUnknown's Battlegrounds(PUBG) 매치 기록을 수집하고, e스포츠 안티치트 맥락에서 통계적으로 비정상적으로 보이는 플레이어 성과를 표시하는 엔드투엔드 빅데이터 파이프라인입니다. 주로 Python으로 구현되며, PySpark로 정제하고 Spark SQL로 매치 분석을 수행하고, MLlib K-Means 클러스터링과 극단적인 헤드샷 비율이나 비현실적인 이동 같은 게임 물리 규칙 검사를 결합합니다. 처리 결과는 Apache Parquet에 저장한 뒤 Apache Cassandra에 적재해 쿼리 중심 접근을 지원하며, 데이터베이스용 Docker Compose 스택은 선택 사항입니다. Streamlit 대시보드는 인프라 상태, 매치 분석, 설명이 포함된 순위형 이상 알림, 매치 또는 플레이어 식별자 조회를 요약합니다. 라이브 클라이언트 단속이 아니라, 서버 측 또는 오프라인 치트 탐지, 비지도 이상 점수화, 경쟁 슈터 원격 측정을 위한 빅데이터 도구를 탐구하는 연구자와 실무자에게 적합합니다.
