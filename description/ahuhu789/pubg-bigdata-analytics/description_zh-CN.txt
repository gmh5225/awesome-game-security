本项目是一条端到端的大数据流水线，摄取大规模《绝地求生》（PlayerUnknown's Battlegrounds）对局记录，并在电竞反作弊场景下标记统计上异常的玩家表现。实现以 Python 为主，使用 PySpark 做清洗、Spark SQL 做对局分析，并结合 MLlib 的 K-Means 聚类与游戏物理规则校验（如极端爆头率或不合理移动）。处理结果写入 Apache Parquet，再加载到 Apache Cassandra 以支持查询访问，数据库可选用 Docker Compose 一键部署。Streamlit 仪表盘汇总基础设施状态、对局分析、带解释的有序异常告警，以及按对局或玩家 ID 检索。适合研究者和实践者探索服务端或离线作弊检测、无监督异常评分，以及面向竞技射击遥测的大数据工具链，而非实时客户端侧强制处置。
