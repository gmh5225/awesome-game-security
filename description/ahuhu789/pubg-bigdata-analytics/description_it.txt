Questo progetto è una pipeline big data end-to-end che acquisisce record di partite di PlayerUnknown's Battlegrounds su larga scala e segnala prestazioni dei giocatori statisticamente anomale in un contesto anti-cheat esport. È implementato principalmente in Python con PySpark per la pulizia, Spark SQL per l'analisi delle partite e clustering K-Means di MLlib combinato con controlli basati sulla fisica di gioco, come tassi di headshot estremi o movimenti implausibili. I risultati elaborati sono memorizzati in Apache Parquet e caricati in Apache Cassandra per accesso orientato alle query, con uno stack Docker Compose opzionale per il database. Una dashboard Streamlit riassume lo stato dell'infrastruttura, l'analitica delle partite, alert di anomalie ordinate con spiegazioni e ricerca per identificativi di partita o giocatore. È adatto a ricercatori e professionisti che esplorano rilevamento cheat lato server o offline, scoring di anomalie non supervisionato e strumenti big data per telemetria di sparatutto competitivi, piuttosto che enforcement live sul client.
