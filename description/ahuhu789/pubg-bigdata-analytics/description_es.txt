Este proyecto es una canalización de big data de extremo a extremo que ingiere registros de partidas de PlayerUnknown's Battlegrounds a gran escala y marca rendimientos de jugadores que parecen estadísticamente anómalos en un contexto antitrampas de esports. Está implementado principalmente en Python con PySpark para la limpieza, Spark SQL para analítica de partidas y clustering K-Means de MLlib combinado con comprobaciones de reglas de física del juego, como tasas de headshot extremas o movimiento implausible. Los resultados procesados se almacenan en Apache Parquet y se cargan en Apache Cassandra para acceso orientado a consultas, con una pila Docker Compose opcional para la base de datos. Un panel Streamlit resume el estado de la infraestructura, analítica de partidas, alertas de anomalías ordenadas con explicaciones y búsqueda por identificadores de partida o jugador. Está pensado para investigadores y profesionales que exploran detección de trampas en servidor u offline, puntuación de anomalías no supervisada y herramientas big data para telemetría de shooters competitivos, más que para aplicación en vivo en el cliente.
