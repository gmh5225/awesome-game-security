本プロジェクトは、大規模な PlayerUnknown's Battlegrounds（PUBG）のマッチ記録を取り込み、eスポーツ向けアンチチートの文脈で統計的に異常に見えるプレイヤー成績をフラグ付けするエンドツーエンドのビッグデータパイプラインです。主に Python で実装され、PySpark によるクレンジング、Spark SQL によるマッチ分析、MLlib の K-Means クラスタリングと、極端なヘッドショット率や不自然な移動などゲーム物理ルールに基づくチェックを組み合わせています。処理結果は Apache Parquet に保存し、Apache Cassandra にロードしてクエリ指向のアクセスを可能にし、データベース用の Docker Compose スタックは任意です。Streamlit ダッシュボードではインフラ状態、マッチ分析、説明付きのランク付き異常アラート、マッチまたはプレイヤー ID による検索をまとめて表示します。ライブクライアントでの強制執行ではなく、サーバー側またはオフラインのチート検知、教師なし異常スコアリング、競技系シューターのテレメトリ向けビッグデータツールを探る研究者や実務者向けです。
