本專案是一條端到端的大數據管線，擷取大規模《絕地求生》（PlayerUnknown's Battlegrounds）對戰紀錄，並在電競反作弊情境下標記統計上異常的玩家表現。實作以 Python 為主，使用 PySpark 進行清洗、Spark SQL 進行對戰分析，並結合 MLlib 的 K-Means 分群與遊戲物理規則檢查（如極端爆頭率或不合理移動）。處理結果寫入 Apache Parquet，再載入 Apache Cassandra 以支援查詢存取，資料庫可選用 Docker Compose 部署。Streamlit 儀表板彙總基礎設施狀態、對戰分析、附說明的排序異常告警，以及依對戰或玩家識別碼查詢。適合研究者與實務者探索伺服器端或離線作弊偵測、無監督異常評分，以及競技射擊遙測的大數據工具，而非即時用戶端強制執行。
