The Goodmans Kernel is a signed Windows WDM driver that embeds the wasm3 WebAssembly interpreter to load unsigned wasm32 modules and expose direct FFI to NT/HAL kernel exports. Developers can write kernel logic in C or Rust, compile to WebAssembly, and hot-load modules through IOCTLs without rebuilding or re-signing the driver on each iteration. Key capabilities include per-module permission manifests, SEH-guarded kernel memory access, InfinityHook trampolines, process and image notify callbacks, watchdog and trace rings, plus CLI, Qt6 GUI, and WinDbg tooling. Built primarily in C and C++ with Visual Studio and the WDK, it targets HVCI-compliant kernel research, reverse engineering, and game security scenarios such as hooking, process tracing, and introspection.
