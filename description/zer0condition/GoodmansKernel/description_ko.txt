Goodmans Kernel은 wasm3 WebAssembly 인터프리터를 내장한 서명된 Windows WDM 드라이버로, 서명되지 않은 wasm32 모듈을 로드하고 NT/HAL 커널 내보내기 함수에 대한 직접 FFI를 제공합니다. 개발자는 C 또는 Rust로 커널 로직을 작성하고 WebAssembly로 컴파일한 뒤, IOCTL을 통해 모듈을 핫로드할 수 있으며 매 반복마다 드라이버를 다시 빌드하거나 재서명할 필요가 없습니다. 주요 기능으로는 모듈별 권한 매니페스트, SEH로 보호된 커널 메모리 접근, InfinityHook 트램폴린, 프로세스 및 이미지 알림 콜백, 워치독 및 추적 링 버퍼, CLI, Qt6 GUI, WinDbg 도구 등이 있습니다. Visual Studio와 WDK를 사용해 주로 C 및 C++로 구축되었으며, HVCI 호환 커널 연구, 리버스 엔지니어링, 후킹, 프로세스 추적, 인트로스펙션 등 게임 보안 시나리오를 대상으로 합니다.
