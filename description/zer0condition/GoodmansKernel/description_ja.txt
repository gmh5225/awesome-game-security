Goodmans Kernel は、wasm3 WebAssembly インタープリタを組み込んだ署名済み Windows WDM ドライバーで、未署名の wasm32 モジュールを読み込み、NT/HAL カーネルエクスポートへの直接 FFI を公開します。開発者は C または Rust でカーネルロジックを記述し、WebAssembly にコンパイルして、IOCTL 経由でモジュールをホットロードでき、反復ごとにドライバーの再ビルドや再署名は不要です。主な機能には、モジュールごとの権限マニフェスト、SEH 保護によるカーネルメモリアクセス、InfinityHook トランポリン、プロセスおよびイメージ通知コールバック、ウォッチドッグとトレースリング、CLI、Qt6 GUI、WinDbg ツール群が含まれます。Visual Studio と WDK を用いた C/C++ を中心に構築され、HVCI 準拠のカーネル研究、リバースエンジニアリング、フック、プロセス追跡、イントロスペクションなどのゲームセキュリティ用途を対象としています。
