Goodmans Kernel 是一个已签名的 Windows WDM 驱动程序，内嵌 wasm3 WebAssembly 解释器，用于加载未签名的 wasm32 模块，并直接通过 FFI 暴露 NT/HAL 内核导出函数。开发者可以用 C 或 Rust 编写内核逻辑，编译为 WebAssembly，并通过 IOCTL 热加载模块，而无需在每次迭代时重新构建或重新签名驱动程序。主要功能包括每模块权限清单、SEH 保护的内核内存访问、InfinityHook 跳板、进程与映像通知回调、看门狗与跟踪环形缓冲区，以及 CLI、Qt6 GUI 和 WinDbg 工具链。该项目主要使用 C 和 C++ 开发，基于 Visual Studio 和 WDK 构建，面向符合 HVCI 的内核研究、逆向工程以及游戏安全场景，如挂钩、进程跟踪和内省分析。
