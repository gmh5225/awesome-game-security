Goodmans Kernel 是一個已簽署的 Windows WDM 驅動程式，內嵌 wasm3 WebAssembly 解釋器，用於載入未簽署的 wasm32 模組，並直接透過 FFI 暴露 NT/HAL 核心匯出函式。開發者可以使用 C 或 Rust 撰寫核心邏輯，編譯為 WebAssembly，並透過 IOCTL 熱載入模組，無需在每次迭代時重新建置或重新簽署驅動程式。主要功能包括每模組權限清單、SEH 保護的核心記憶體存取、InfinityHook 跳板、程序與映像通知回呼、看門狗與追蹤環形緩衝區，以及 CLI、Qt6 GUI 和 WinDbg 工具鏈。該專案主要以 C 和 C++ 開發，使用 Visual Studio 與 WDK 建置，面向符合 HVCI 的核心研究、逆向工程以及遊戲安全情境，如掛鉤、程序追蹤與內省分析。
