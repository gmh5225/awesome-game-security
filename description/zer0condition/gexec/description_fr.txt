Ce projet est un interprète de bytecode à machine à registres conçu pour être intégré dans des pilotes noyau Windows, implémenté en C sans compilateur JIT. Il inclut un assembleur textuel (gasm), un releveur PE x86-64 (gvmlift) basé sur Zydis, ainsi que des API de chargement, de vérification et d'exécution que les pilotes peuvent intégrer via une table de fonctions hôte. Le bytecode utilise des instructions fixes de 16 octets avec environ 180 opcodes couvrant l'arithmétique entière et flottante, les opérations mémoire, la gestion structurée des exceptions, les opérations atomiques et les rappels hôte. Il s'adresse à la recherche en sécurité en mode noyau et au développement anti-triche, lorsque une logique portable et actualisable doit s'exécuter dans un pilote plutôt que sous forme de code compilé natif.
