Dieses Projekt ist ein Register-Maschinen-Bytecode-Interpreter zur Einbettung in Windows-Kernel-Treiber, implementiert in C ohne JIT-Compiler. Es enthält einen Text-Assembler (gasm), einen x86-64-PE-Lifter (gvmlift) auf Basis von Zydis sowie Loader-, Verifier- und Ausführungs-APIs, die Treiber über eine Host-Funktionstabelle integrieren können. Der Bytecode verwendet feste 16-Byte-Anweisungen mit rund 180 Opcodes für Integer- und Gleitkomma-Arithmetik, Speicheroperationen, strukturierte Ausnahmebehandlung, Atomics und Host-Callbacks. Es richtet sich an Kernel-Mode-Sicherheitsforschung und Anti-Cheat-Entwicklung, wenn aktualisierbare, portable Logik innerhalb eines Treibers statt als nativ kompilierter Code ausgeführt werden muss.
