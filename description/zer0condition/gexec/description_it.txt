Questo progetto è un interprete di bytecode a macchina a registri per l'integrazione nei driver del kernel Windows, implementato in C senza compilatore JIT. Include un assembler testuale (gasm), un lifter PE x86-64 (gvmlift) basato su Zydis, e API di caricamento, verifica ed esecuzione che i driver possono integrare tramite una tabella di funzioni host. Il bytecode utilizza istruzioni fisse da 16 byte con circa 180 opcode che coprono aritmetica intera e in virgola mobile, operazioni di memoria, gestione strutturata delle eccezioni, operazioni atomiche e callback host. È destinato alla ricerca sulla sicurezza in modalità kernel e allo sviluppo anti-cheat, dove logica aggiornabile e portabile deve essere eseguita all'interno di un driver anziché come codice compilato nativo.
