本プロジェクトは、Windows カーネルドライバーに組み込むためのレジスタマシン型バイトコードインタプリタで、C 言語で実装され、JIT コンパイラは含まれません。テキストアセンブラ（gasm）、Zydis ベースの x86-64 PE リフター（gvmlift）、およびドライバーがホスト関数テーブル経由で統合できるローダー、検証器、実行 API が同梱されています。バイトコードは固定 16 バイト命令形式で、約 180 のオペコードにより整数・浮動小数点演算、メモリ操作、構造化例外処理、アトミック操作、ホストコールバックをカバーします。ネイティブコンパイルコードではなく、ドライバー内で更新可能かつ移植性のあるロジックを実行する必要がある、カーネルモードのセキュリティ研究やアンチチート開発を対象としています。
