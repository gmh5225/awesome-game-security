Этот проект представляет собой интерпретатор байткода для регистровой машины, предназначенный для встраивания в драйверы ядра Windows; реализован на C без JIT-компилятора. В состав входят текстовый ассемблер (gasm), подниматель PE x86-64 (gvmlift) на базе Zydis, а также API загрузки, верификации и выполнения, которые драйверы могут интегрировать через таблицу функций хоста. Байткод использует фиксированные 16-байтовые инструкции с примерно 180 опкодами, охватывающими целочисленную и операции с плавающей точкой, работу с памятью, структурированную обработку исключений, атомарные операции и обратные вызовы хоста. Проект ориентирован на исследования безопасности в режиме ядра и разработку античитов, где обновляемая переносимая логика должна выполняться внутри драйвера, а не в виде нативного скомпилированного кода.
