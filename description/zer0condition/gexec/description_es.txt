Este proyecto es un intérprete de bytecode de máquina de registros para integrar en controladores del kernel de Windows, implementado en C sin compilador JIT. Incluye un ensamblador de texto (gasm), un elevador PE x86-64 (gvmlift) basado en Zydis, y APIs de carga, verificación y ejecución que los controladores pueden integrar mediante una tabla de funciones host. El bytecode utiliza instrucciones fijas de 16 bytes con unos 180 opcodes que cubren aritmética entera y de punto flotante, operaciones de memoria, manejo estructurado de excepciones, operaciones atómicas y callbacks host. Está orientado a la investigación de seguridad en modo kernel y al desarrollo anti-cheat, donde la lógica portable y actualizable debe ejecutarse dentro de un controlador en lugar de como código compilado nativo.
