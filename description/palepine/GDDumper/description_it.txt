Cheat Engine Godot Dumper è uno script Lua per Cheat Engine che ispeziona ed estrae dati runtime da applicazioni Godot tramite l'API di Cheat Engine. Supporta Godot 3.x e 4.x su Windows x86-64 e x86-32, con risoluzione automatica degli offset, dump di SceneTree e nodi nell'Address List, analisi della struttura del nodo radice e aggiornamenti dell'elenco dei simboli. Il toolkit include anche un disassemblatore GDScriptFunction basato su strutture, una API GD-to-CE di base e funzionalità sperimentali per chiamate arbitrarie a GDFunction e hot-reload di GDScript o ScriptInstance. È pensato per reverse engineering, modding e debug di giochi Godot basati su GDScript a scopo educativo e di ricerca.
