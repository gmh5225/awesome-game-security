Cheat Engine Godot Dumper は、Cheat Engine API を通じて Godot アプリケーションのランタイムデータを検査・抽出する Cheat Engine の Lua スクリプトです。Windows x86-64 および x86-32 上の Godot 3.x / 4.x をサポートし、オフセットの自動解決、SceneTree とノードの Address List へのダンプ、ルートノード構造の解析、シンボルリストの更新に対応します。このツールキットには、構造ベースの GDScriptFunction 逆アセンブラ、基本的な GD-to-CE API、任意の GDFunction 呼び出しや GDScript / ScriptInstance のホットリロードといった実験的機能も含まれます。教育・研究目的で、GDScript ベースの Godot ゲームのリバースエンジニアリング、改造、デバッグを対象としています。
