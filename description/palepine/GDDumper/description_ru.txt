Cheat Engine Godot Dumper — это Lua-скрипт для Cheat Engine, который анализирует и извлекает данные времени выполнения приложений Godot через API Cheat Engine. Он поддерживает Godot 3.x и 4.x на Windows x86-64 и x86-32, с автоматическим разрешением смещений, дампом SceneTree и узлов в Address List, разбором структуры корневого узла и обновлением списка символов. В набор также входят структурный дизассемблер GDScriptFunction, базовый API GD-to-CE и экспериментальные возможности произвольного вызова GDFunction и горячей перезагрузки GDScript или ScriptInstance. Инструмент предназначен для реверс-инжиниринга, моддинга и отладки игр Godot на GDScript в образовательных и исследовательских целях.
