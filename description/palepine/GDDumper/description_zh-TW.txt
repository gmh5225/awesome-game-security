Cheat Engine Godot Dumper 是一個 Cheat Engine Lua 腳本，可透過 Cheat Engine API 檢查並擷取 Godot 應用程式的執行時期資料。它支援 Windows x86-64 與 x86-32 上的 Godot 3.x 和 4.x，具備自動偏移解析、將 SceneTree 與節點傾印至 Address List、根節點結構剖析以及符號列表更新等功能。該工具包還包含基於結構的 GDScriptFunction 反組譯器、基礎 GD-to-CE API，以及用於任意 GDFunction 呼叫和 GDScript 或 ScriptInstance 熱重載的實驗性功能。面向基於 GDScript 的 Godot 遊戲的逆向工程、模組製作與除錯，供教育與研究使用。
