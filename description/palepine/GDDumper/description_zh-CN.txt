Cheat Engine Godot Dumper 是一个 Cheat Engine Lua 脚本，可通过 Cheat Engine API 检查并提取 Godot 应用程序的运行时数据。它支持 Windows x86-64 与 x86-32 上的 Godot 3.x 和 4.x，具备自动偏移解析、将 SceneTree 与节点转储到 Address List、根节点结构剖析以及符号列表更新等功能。该工具包还包含基于结构的 GDScriptFunction 反汇编器、基础 GD-to-CE API，以及用于任意 GDFunction 调用和 GDScript 或 ScriptInstance 热重载的实验性功能。面向基于 GDScript 的 Godot 游戏的逆向工程、模组制作与调试，供教育与研究使用。
