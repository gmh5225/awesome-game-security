Cheat Engine Godot Dumper es un script Lua de Cheat Engine que inspecciona y extrae datos en tiempo de ejecución de aplicaciones Godot mediante la API de Cheat Engine. Es compatible con Godot 3.x y 4.x en Windows x86-64 y x86-32, con resolución automática de offsets, volcado de SceneTree y nodos en la Address List, disección de la estructura del nodo raíz y actualizaciones de la lista de símbolos. El conjunto de herramientas también incluye un desensamblador GDScriptFunction basado en estructuras, una API básica GD-to-CE y funciones experimentales para llamadas arbitrarias a GDFunction y recarga en caliente de GDScript o ScriptInstance. Está orientado a la ingeniería inversa, el modding y la depuración de juegos Godot basados en GDScript con fines educativos y de investigación.
