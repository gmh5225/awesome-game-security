Cheat Engine Godot Dumper is a Cheat Engine Lua script that inspects and extracts runtime data from Godot applications through the Cheat Engine API. It supports Godot 3.x and 4.x on Windows x86-64 and x86-32, with automatic offset resolution, SceneTree and node dumping into the Address List, root node structure dissecting, and symbol list updates. The toolkit also includes a structure-based GDScriptFunction disassembler, a basic GD-to-CE API, and experimental features for arbitrary GDFunction calling and GDScript or ScriptInstance hot-reloading. It is aimed at reverse engineering, modding, and debugging of GDScript-based Godot games for educational and research purposes.
