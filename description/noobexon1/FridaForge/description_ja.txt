FridaForge は、IDA Pro または Binary Ninja における現在の解析コンテキストから、すぐ使える Frida のインストルメンテーションスクリプトを生成する逆アセンブラプラグインです。主に Python と JavaScript の Frida テンプレートで実装され、共有コアと薄いホストアダプターにより、両ツールで同じメニュー、ホットキー、アクションを提供します。関数および dlopen フック、メモリセクションの保護属性の変更、ARM64 および x86/x64 での条件分岐の反転などのワークフローに対応し、スニペットは組み合わせやネストでより複雑な構成が可能です。生成されたスクリプトはクリップボードにコピーされ、モジュール名やアドレスなどの詳細が自動入力されます。ゲームやモバイルターゲットを含むネイティブバイナリの動的解析を、繰り返しの Frida ボイラープレートを手書きせずに高速化したいリバースエンジニアとセキュリティ研究者向けです。
