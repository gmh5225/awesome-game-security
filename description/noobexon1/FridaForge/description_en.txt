FridaForge is a disassembler plugin that generates ready-to-use Frida instrumentation scripts from your current analysis context in IDA Pro or Binary Ninja. It is implemented primarily in Python with JavaScript Frida templates, using a shared core and thin host adapters so both tools offer the same menus, hotkeys, and actions. Supported workflows include function and dlopen hooks, changing memory section protections, and flipping conditional branches on ARM64 and x86/x64, with snippets designed to compose and nest for more complex setups. Generated scripts are copied to the clipboard with module names, addresses, and other details filled in automatically. It targets reverse engineers and security researchers who want faster dynamic analysis of native binaries, including games and mobile targets, without hand-writing repetitive Frida boilerplate.
