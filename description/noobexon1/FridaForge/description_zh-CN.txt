FridaForge 是一款反汇编器插件，可根据你在 IDA Pro 或 Binary Ninja 中的当前分析上下文，生成可直接使用的 Frida 插桩脚本。它主要用 Python 实现，配合 JavaScript Frida 模板，采用共享核心与轻量宿主适配层，使两款工具提供相同的菜单、快捷键与操作。支持的工作流包括函数与 dlopen 钩子、修改内存段保护属性，以及在 ARM64 与 x86/x64 上翻转条件分支；片段可组合与嵌套以构建更复杂的场景。生成的脚本会复制到剪贴板，并自动填入模块名、地址等细节。面向希望更快对原生二进制（含游戏与移动目标）做动态分析、又不必手写重复 Frida 样板代码的逆向工程师与安全研究人员。
