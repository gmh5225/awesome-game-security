This is a Cheat Engine extension that integrates large language model assistance into memory analysis and reverse engineering workflows through an in-app AI dialog and registered tool callbacks. Implemented mainly in Lua with a Lazarus form-based UI, it connects to Google Gemini models using public, Patreon, or personal API keys and lets the AI drive native CE capabilities such as memory scanning, disassembly, watchpoints, pointer chains, and Auto Assembler script creation and validation. A skills framework supplies on-demand expert prompts and references for specialized tasks including structure dissection, pointer scanning, Mono and IL2CPP runtime scripting, and Unreal Engine object traversal. It targets reverse engineers, modders, and game security researchers who want conversational AI help building stable cheats and analyzing running game processes from within Cheat Engine.
