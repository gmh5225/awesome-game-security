Cheat Engine 확장으로, 앱 내 AI 대화창과 등록된 도구 콜백을 통해 대규모 언어 모델 지원을 메모리 분석 및 리버스 엔지니어링 워크플로에 통합합니다. 주로 Lua로 구현되었으며 Lazarus 폼 기반 UI를 사용하고, 공개·Patreon·개인 API 키로 Google Gemini 모델에 연결하여 AI가 메모리 스캔, 디스어셈블리, 와치포인트, 포인터 체인, Auto Assembler 스크립트 생성 및 검증 등 CE 네이티브 기능을 구동합니다. 스킬 프레임워크는 구조체 해석, 포인터 스캔, Mono 및 IL2CPP 런타임 스크립팅, Unreal Engine 객체 순회 등 전문 작업에 대해 필요 시 전문가 프롬프트와 참고 자료를 제공합니다. Cheat Engine 내에서 대화형 AI 도움으로 안정적인 치트를 만들고 실행 중인 게임 프로세스를 분석하려는 리버스 엔지니어, 모더, 게임 보안 연구자를 대상으로 합니다.
