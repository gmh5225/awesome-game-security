這是 Cheat Engine 的擴充功能，透過應用程式內 AI 對話與註冊工具回呼，將大型語言模型輔助整合至記憶體分析與逆向工程工作流程中。主要以 Lua 實作，採用基於 Lazarus 表單的使用者介面，可連線至 Google Gemini 模型（支援公開、Patreon 或個人 API 金鑰），並讓 AI 驅動 CE 原生功能，如記憶體掃描、反組譯、監視點、指標鏈以及 Auto Assembler 腳本的建立與驗證。技能框架為結構解析、指標掃描、Mono 與 IL2CPP 執行階段指令碼以及 Unreal Engine 物件遍歷等專門任務提供隨需專家提示與參考資料。面向希望在 Cheat Engine 內獲得對話式 AI 協助、以建構穩定外掛並分析執行中遊戲程序的逆向工程師、Mod 作者與遊戲安全研究人員。
