Cheat Engine 向けの拡張機能で、アプリ内 AI ダイアログと登録済みツールコールバックを通じて、大規模言語モデルによる支援をメモリ解析とリバースエンジニアリングのワークフローに統合します。主に Lua で実装され、Lazarus フォームベースの UI を備え、公開・Patreon・個人の API キーを使って Google Gemini モデルに接続し、AI がメモリスキャン、逆アセンブル、ウォッチポイント、ポインタチェーン、Auto Assembler スクリプトの作成と検証など CE ネイティブ機能を駆動します。スキルフレームワークは、構造体解析、ポインタスキャン、Mono および IL2CPP ランタイムスクリプティング、Unreal Engine オブジェクト走査などの専門タスク向けに、必要に応じたエキスパートプロンプトと参考資料を提供します。Cheat Engine 内から対話型 AI の支援を受けながら、安定したチートの構築や実行中のゲームプロセスの解析を行いたいリバースエンジニア、Modder、ゲームセキュリティ研究者向けです。
