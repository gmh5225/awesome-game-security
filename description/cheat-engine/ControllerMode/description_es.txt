Controller Mode es un complemento de Cheat Engine que permite operar la interfaz de escritorio completa de Cheat Engine con un mando de juego en lugar de teclado y ratón. Escrito principalmente en Lua, asigna las entradas de un mando al estilo Xbox a acciones de la interfaz: navegación con la cruceta en listas, vistas de árbol y editores hexadecimales, A/B para confirmar y cancelar, cambio de pestañas y apertura de procesos o tablas de trucos. Añade paneles de ayuda en pantalla para el mando en los formularios, incluye un selector de archivos apto para mando para cargar tablas .CT y ofrece soporte experimental de teclado en pantalla para Steam Deck mediante C embebido y la API de Steam. El proyecto está dirigido a ingenieros inversos y analistas de memoria que ejecutan Cheat Engine en configuraciones portátiles o de salón como Steam Deck durante la investigación de seguridad de juegos y la edición de memoria en vivo.
