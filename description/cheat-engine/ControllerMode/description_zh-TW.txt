Controller Mode 是 Cheat Engine 的附加元件，讓使用者能以遊戲手把而非鍵盤和滑鼠操作完整的 Cheat Engine 桌面介面。此外掛主要以 Lua 撰寫，將 Xbox 風格手把輸入對應至 UI 操作，例如在清單、樹狀檢視和十六進位編輯器中以方向鍵導覽，以 A/B 鍵確認與取消、切換分頁，以及開啟處理程序或作弊表。它為表單加入螢幕手把提示面板，包含便於手把操作的檔案選擇器以載入 .CT 表，並透過嵌入 C 程式碼與 Steam API 提供實驗性的 Steam Deck 螢幕鍵盤支援。本專案面向在 Steam Deck 等掌機或沙發環境中執行 Cheat Engine、從事遊戲安全研究與即時記憶體編輯的逆向工程師與記憶體分析人員。
