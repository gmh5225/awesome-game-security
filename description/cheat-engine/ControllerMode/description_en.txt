Controller Mode is a Cheat Engine add-on that lets users operate the full Cheat Engine desktop interface with a gamepad instead of a keyboard and mouse. Written primarily in Lua, it maps Xbox-style controller inputs to UI actions such as D-pad navigation in lists, tree views, and hex editors, A/B for confirm and cancel, tab switching, and opening processes or cheat tables. It adds on-screen controller hint panels to forms, includes a controller-friendly file picker for loading .CT tables, and provides experimental Steam Deck on-screen keyboard support via embedded C and the Steam API. The project targets reverse engineers and memory analysts who run Cheat Engine on handheld or couch setups like the Steam Deck during game security research and live memory editing.
