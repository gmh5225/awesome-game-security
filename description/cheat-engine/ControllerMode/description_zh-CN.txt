Controller Mode 是 Cheat Engine 的附加组件，允许用户使用游戏手柄而非键盘和鼠标来操作完整的 Cheat Engine 桌面界面。该插件主要使用 Lua 编写，将 Xbox 风格手柄输入映射到 UI 操作，例如在列表、树视图和十六进制编辑器中使用方向键导航，用 A/B 键确认和取消，切换标签页，以及打开进程或作弊表。它为窗体添加了屏幕控制器提示面板，包含便于手柄操作的文件选择器用于加载 .CT 表，并通过嵌入 C 代码和 Steam API 提供实验性的 Steam Deck 屏幕键盘支持。该项目面向在游戏安全研究和实时内存编辑过程中，于 Steam Deck 等掌机或沙发环境中运行 Cheat Engine 的逆向工程师和内存分析人员。
