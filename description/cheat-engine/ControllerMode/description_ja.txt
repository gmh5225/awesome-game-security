Controller Mode は、キーボードとマウスの代わりにゲームパッドで Cheat Engine のデスクトップ UI 全体を操作できるアドオンです。主に Lua で書かれており、Xbox 形式のコントローラー入力を UI 操作に割り当てます。リストやツリービュー、ヘックスエディタでの十字キーによる移動、A/B による確定とキャンセル、タブ切り替え、プロセスやチートテーブルの開く操作などに対応します。フォームに画面上のコントローラーヒントパネルを追加し、.CT テーブルを読み込むためのコントローラー向けファイルピッカーを備え、埋め込み C コードと Steam API による実験的な Steam Deck 画面上キーボードサポートも提供します。Steam Deck などのハンドヘルドやソファ環境で Cheat Engine を使う、ゲームセキュリティ研究やライブメモリ編集を行うリバースエンジニアとメモリアナリストを対象としています。
