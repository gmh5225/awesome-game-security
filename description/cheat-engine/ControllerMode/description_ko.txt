Controller Mode는 키보드와 마우스 대신 게임패드로 Cheat Engine 데스크톱 UI 전체를 조작할 수 있게 해 주는 Cheat Engine 애드온입니다. 주로 Lua로 작성되었으며, Xbox 스타일 컨트롤러 입력을 UI 동작에 매핑합니다. 목록, 트리 뷰, 헥스 에디터에서 D-pad로 이동하고, A/B로 확인 및 취소, 탭 전환, 프로세스 또는 치트 테이블 열기 등을 지원합니다. 폼에 화면상 컨트롤러 힌트 패널을 추가하고, .CT 테이블을 불러올 수 있는 컨트롤러 친화적 파일 선택기를 포함하며, 내장 C 코드와 Steam API를 통한 실험적 Steam Deck 화상 키보드 지원도 제공합니다. Steam Deck 같은 휴대형 또는 소파 환경에서 Cheat Engine을 실행하며 게임 보안 연구와 실시간 메모리 편집을 수행하는 리버스 엔지니어와 메모리 분석가를 대상으로 합니다.
