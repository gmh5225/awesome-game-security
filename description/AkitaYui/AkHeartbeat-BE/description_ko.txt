이 프로젝트는 Grand Theft Auto V Enhanced용 외부 C++ 도구로, BattlEye가 비활성화되거나 우회된 상태에서 D3D11 오버레이 메뉴와 실시간 게임 메모리 조작을 제공합니다. 게임에 인젝션하지 않고 별도 프로세스로 실행되며, ReadProcessMemory와 WriteProcessMemory를 AOB 패턴 스캔과 함께 사용해 월드 포인터, 스크립트 글로벌, 세션 상태, BattlEye 관련 플래그를 해석합니다. 이 도구는 stat, 스크립트 글로벌, 스크립트 로컬 편집기, 텔레포트 보조 기능, BattlEye 탐지 루틴을 무력화하는 런타임 패치를 제공하며, 문서에서는 사용자 모드 클라이언트와 BEDaisy 커널 드라이버 아키텍처를 설명합니다. BattlEye 통합, 외부 치트 설계, Rockstar 타이틀의 안티치트 우회 기법을 연구하는 게임 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
