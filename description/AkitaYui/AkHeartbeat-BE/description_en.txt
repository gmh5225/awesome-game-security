This project is an external C++ tool for Grand Theft Auto V Enhanced that provides a D3D11 overlay menu and live game memory manipulation while BattlEye is disabled or bypassed. It runs as a separate process without injecting into the game, using ReadProcessMemory and WriteProcessMemory together with AOB pattern scanning to resolve world pointers, script globals, session state, and BattlEye-related flags. The tool offers stat, script global, and script local editors, teleportation helpers, and runtime patches that neutralize BattlEye detection routines, and its documentation maps the user-mode client and BEDaisy kernel driver architecture. It is aimed at game security researchers and reverse engineers studying BattlEye integration, external cheat design, and anti-cheat bypass techniques in Rockstar titles.
