MacShade is a macOS application that brings ReShade-style real-time post-processing and shader overlays to games running on Mac hardware. It combines a Swift-based launcher with game discovery, bundled ReShade FX collections, and per-title presets for classic FPS ports such as Doom, Quake, Unreal Tournament, and related titles. Under the hood it builds on a ReShade-derived runtime with native macOS bridges for Metal, OpenGL, and Vulkan via MoltenVK, exposing libmacshade.dylib and a helper filter tool that can attach to a game process for overlay and effects control. Primary languages include Swift, C++, and Objective-C++, with CMake used for the native library and injection-oriented platform code. It targets players and modders who want enhanced visuals on Mac, and it illustrates the same frame-capture and in-process graphics hooking patterns that game security and anti-cheat research often study.
