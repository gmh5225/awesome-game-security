KnoxPatch 是一個 LSPosed Xposed 模組，用於在已 root 的三星 Galaxy 裝置上還原三星應用程式及 Knox 保護功能。該專案主要使用 Kotlin 撰寫，面向 Android 平台，透過 hook 目標三星應用程式來繞過 root 偵測、偽造關鍵系統屬性、停用 Knox SDK 與 Samsung Attestation Key 檢查，並修補 Samsung Keystore 與 Knox Matrix API。配套的 KnoxPatch Enhancer Magisk 或 KernelSU 模組提供系統層級修補，以修復僅靠執行階段 hook 無法解決的功能，例如舊版 One UI 裝置上的安全資料夾。它支援 Android 9 至 16 的 One UI，可啟用 Samsung Health、安全資料夾、SmartThings 和 Samsung Cloud 等應用程式。該專案面向行動安全研究、逆向分析三星 Knox 完整性機制，以及研究 OEM root 與 attestation 檢查在已修改裝置上的行為。
