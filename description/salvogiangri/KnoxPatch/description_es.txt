KnoxPatch es un módulo LSPosed Xposed que restaura aplicaciones de Samsung y funciones protegidas por Knox en dispositivos Samsung Galaxy con root. Escrito principalmente en Kotlin para Android, engancha aplicaciones Samsung objetivo para eludir la detección de root, falsificar propiedades críticas del sistema, desactivar las comprobaciones de Knox SDK y Samsung Attestation Key, y parchear las API de Samsung Keystore y Knox Matrix. Un módulo complementario KnoxPatch Enhancer para Magisk o KernelSU añade parches a nivel de sistema para funciones que los hooks en tiempo de ejecución no pueden corregir por sí solos, como Secure Folder en dispositivos One UI antiguos. Es compatible con One UI desde Android 9 hasta 16 y habilita aplicaciones como Samsung Health, Secure Folder, SmartThings y Samsung Cloud. El proyecto está orientado a la investigación en seguridad móvil, la ingeniería inversa de los mecanismos de integridad de Samsung Knox y el estudio del comportamiento de las comprobaciones de root y attestation del OEM en dispositivos modificados.
