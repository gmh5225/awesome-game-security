KnoxPatch 是一个 LSPosed Xposed 模块，用于在已 root 的三星 Galaxy 设备上恢复三星应用及 Knox 保护功能。该项目主要使用 Kotlin 编写，面向 Android 平台，通过 hook 目标三星应用来绕过 root 检测、伪造关键系统属性、禁用 Knox SDK 与 Samsung Attestation Key 检查，并修补 Samsung Keystore 与 Knox Matrix API。配套的 KnoxPatch Enhancer Magisk 或 KernelSU 模块提供系统级补丁，以修复仅靠运行时 hook 无法解决的功能，例如旧版 One UI 设备上的安全文件夹。它支持 Android 9 至 16 的 One UI，可启用 Samsung Health、安全文件夹、SmartThings 和 Samsung Cloud 等应用。该项目面向移动安全研究、逆向分析三星 Knox 完整性机制，以及研究 OEM root 与 attestation 检查在已修改设备上的行为。
