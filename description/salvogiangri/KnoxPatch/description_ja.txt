KnoxPatch は LSPosed Xposed モジュールで、root 化された Samsung Galaxy 端末上で Samsung アプリおよび Knox 保護機能を復元します。主に Kotlin で Android 向けに書かれており、対象の Samsung アプリをフックして root 検出を回避し、重要なシステムプロパティを偽装し、Knox SDK および Samsung Attestation Key のチェックを無効化し、Samsung Keystore と Knox Matrix API をパッチします。付属の KnoxPatch Enhancer Magisk または KernelSU モジュールは、レガシー One UI 端末での Secure Folder など、ランタイムフックだけでは修正できない機能向けにシステムレベルのパッチを追加します。Android 9 から 16 までの One UI をサポートし、Samsung Health、Secure Folder、SmartThings、Samsung Cloud などのアプリを有効化します。本プロジェクトは、モバイルセキュリティ研究、Samsung Knox 整合性メカニズムのリバースエンジニアリング、および改変端末における OEM の root および attestation チェックの挙動の研究を目的としています。
