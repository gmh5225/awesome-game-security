KnoxPatch は、root 化された Samsung Galaxy 端末で Samsung アプリと Knox 保護機能を復元する LSPosed Xposed モジュールです。主に Kotlin で Android 向けに書かれており、対象の Samsung アプリにフックを仕掛けて root 検出の回避、重要なシステムプロパティの偽装、Knox SDK および Samsung Attestation Key チェックの無効化、Samsung Keystore と Knox Matrix API のパッチを行います。付属の KnoxPatch Enhancer Magisk または KernelSU モジュールは、ランタイムフックだけでは修正できない機能（旧 One UI 端末での Secure Folder など）向けにシステムレベルのパッチを追加します。Android 9 から 16 までの One UI をサポートし、Samsung Health、Secure Folder、SmartThings、Samsung Cloud などのアプリを有効化します。本プロジェクトは、モバイルセキュリティ研究、Samsung Knox 整合性メカニズムのリバースエンジニアリング、および改変端末における OEM root および attestation チェックの挙動の調査を目的としています。
