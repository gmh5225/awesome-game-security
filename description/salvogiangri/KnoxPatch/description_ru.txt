KnoxPatch — это модуль LSPosed Xposed, который восстанавливает приложения Samsung и функции, защищённые Knox, на рутированных устройствах Samsung Galaxy. Написанный в основном на Kotlin для Android, он перехватывает целевые приложения Samsung, чтобы обходить обнаружение root, подменять критические системные свойства, отключать проверки Knox SDK и Samsung Attestation Key, а также патчить API Samsung Keystore и Knox Matrix. Сопутствующий модуль KnoxPatch Enhancer для Magisk или KernelSU добавляет системные патчи для функций, которые нельзя исправить только runtime-хуками, например Secure Folder на устаревших устройствах One UI. Поддерживается One UI с Android 9 по 16 и включаются приложения Samsung Health, Secure Folder, SmartThings и Samsung Cloud. Проект предназначен для исследований мобильной безопасности, реверс-инжиниринга механизмов целостности Samsung Knox и изучения поведения OEM-проверок root и attestation на модифицированных устройствах.
