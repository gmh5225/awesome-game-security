KnoxPatch는 LSPosed Xposed 모듈로, 루팅된 Samsung Galaxy 기기에서 Samsung 앱과 Knox 보호 기능을 복원합니다. 주로 Kotlin으로 Android용으로 작성되었으며, 대상 Samsung 앱을 후킹하여 root 탐지를 우회하고, 중요한 시스템 속성을 위조하며, Knox SDK 및 Samsung Attestation Key 검사를 비활성화하고, Samsung Keystore와 Knox Matrix API를 패치합니다. 동반 모듈인 KnoxPatch Enhancer Magisk 또는 KernelSU 모듈은 레거시 One UI 기기의 Secure Folder처럼 런타임 후킹만으로는 해결할 수 없는 기능을 위해 시스템 수준 패치를 추가합니다. Android 9부터 16까지의 One UI를 지원하며 Samsung Health, Secure Folder, SmartThings, Samsung Cloud 등의 앱을 사용할 수 있게 합니다. 이 프로젝트는 모바일 보안 연구, Samsung Knox 무결성 메커니즘의 리버스 엔지니어링, 그리고 수정된 기기에서 OEM root 및 attestation 검사가 어떻게 동작하는지 연구하는 데 목적이 있습니다.
