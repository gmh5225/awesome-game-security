KnoxPatch는 root된 Samsung Galaxy 기기에서 Samsung 앱과 Knox 보호 기능을 복원하는 LSPosed Xposed 모듈입니다. 주로 Kotlin으로 Android용으로 작성되었으며, 대상 Samsung 애플리케이션에 후킹하여 root 탐지 우회, 중요 시스템 속성 위조, Knox SDK 및 Samsung Attestation Key 검사 비활성화, Samsung Keystore 및 Knox Matrix API 패치를 수행합니다. 함께 제공되는 KnoxPatch Enhancer Magisk 또는 KernelSU 모듈은 런타임 후크만으로는 해결할 수 없는 기능(구형 One UI 기기의 Secure Folder 등)에 대한 시스템 수준 패치를 추가합니다. Android 9부터 16까지의 One UI를 지원하며 Samsung Health, Secure Folder, SmartThings, Samsung Cloud 등의 앱을 사용할 수 있게 합니다. 이 프로젝트는 모바일 보안 연구, Samsung Knox 무결성 메커니즘 리버스 엔지니어링, 그리고 수정된 기기에서 OEM root 및 attestation 검사가 어떻게 동작하는지 연구하는 것을 목적으로 합니다.
