Detect-Any 是一款开源的 Android 环境完整性框架，用于扫描设备是否遭入侵或篡改，并生成带可复现证据的加权风险评分。项目主要以 Kotlin 实现，采用多模块 Gradle 结构，辅以 JNI 原生探测、并行采集流水线、JSON 规则，以及基于 Jetpack Compose 的应用，支持快速、完整与深度三级扫描。检测范围涵盖 root 与 hook 栈（Magisk、KernelSU、Zygisk、LSPosed）、证明伪造、模拟器与云手机、Frida 等动态插桩，以及 VPN、悬浮窗与屏幕共享等行为信号，并由可热更新的 Ed25519 签名数据库支撑。置信度分级与并行编排旨在在安全工程师、移动反欺诈团队以及 Android 游戏或应用完整性研究中，兼顾可审计性与较低误报率。
