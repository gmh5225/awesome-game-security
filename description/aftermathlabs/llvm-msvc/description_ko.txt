이 프로젝트는 llvm-msvc로, LLVM 모노레포의 포크이며 BOLT 링크 후 바이너리 최적화기와 Clang C/C++ 컴파일러 프런트엔드 등 툴체인 구성 요소를 묶어 제공합니다. 트리는 주로 C와 C++로 구현되며 CMake 기반 빌드, compiler-rt 런타임 지원, 업스트림 LLVM에 전형적인 광범위한 Clang 테스트 및 정적 분석 체커를 포함합니다. 여기의 Clang에는 Microsoft Visual C++ 호환 작업(MSVC 지향 드라이버, 크로스 Windows 툴체인 지원, MSVC 전용 가변 인자 처리 등)이 포함되어 MSVC 생태계에 맞춘 LLVM 기반 컴파일러로 Windows 네이티브 코드를 빌드하는 것을 목표로 합니다. BOLT는 x86, AArch64, RISC-V 실행 파일을 대상으로 바이너리 재작성, 프로파일링, 최적화 패스를 제공합니다. 독점 Microsoft 툴체인에만 의존하지 않고 MSVC와 유사한 호환성 하에 Clang과 LLVM 기능을 원하는 Windows 네이티브 개발자, 리버스 엔지니어, 게임 보안 연구자를 위한 것입니다.
