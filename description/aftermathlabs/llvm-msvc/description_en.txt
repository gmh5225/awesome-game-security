This project is llvm-msvc, a fork of the LLVM monorepo that packages toolchain components including the BOLT post-link binary optimizer and the Clang C and C++ compiler frontend. The tree is implemented primarily in C and C++, with CMake-based builds, compiler-rt runtime support, and extensive Clang tests and static analyzer checkers typical of upstream LLVM. Clang here includes Microsoft Visual C++ compatibility work such as an MSVC-oriented driver, cross-Windows toolchain support, and MSVC-specific varargs handling, aimed at building Windows-native code with an LLVM-based compiler that aligns with the MSVC ecosystem. BOLT provides binary rewriting, profiling, and optimization passes targeting x86, AArch64, and RISC-V executables. It is intended for Windows native developers, reverse engineers, and game-security researchers who want Clang and LLVM capabilities with MSVC-like compatibility rather than relying solely on the proprietary Microsoft toolchain.
