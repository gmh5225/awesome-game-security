本项目为 llvm-msvc，是 LLVM 单体仓库的分支，打包了 BOLT 链接后二进制优化器以及 Clang C/C++ 编译器前端等工具链组件。代码树主要用 C 和 C++ 实现，采用基于 CMake 的构建、compiler-rt 运行时支持，以及上游 LLVM 典型的丰富 Clang 测试与静态分析检查器。此处的 Clang 包含面向 Microsoft Visual C++ 的兼容工作，例如 MSVC 导向的驱动、跨 Windows 工具链支持以及 MSVC 特有的可变参数处理，旨在用基于 LLVM 的编译器构建 Windows 原生代码并与 MSVC 生态对齐。BOLT 提供针对 x86、AArch64 和 RISC-V 可执行文件的二进制重写、性能分析与优化 pass。面向希望在 MSVC 式兼容下使用 Clang 与 LLVM 能力、而非仅依赖微软专有工具链的 Windows 原生开发者、逆向工程师与游戏安全研究人员。
