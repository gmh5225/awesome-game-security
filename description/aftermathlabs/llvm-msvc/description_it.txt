Questo progetto è llvm-msvc, un fork del monorepo LLVM che impacchetta componenti della toolchain, inclusi l’ottimizzatore binario post-link BOLT e il frontend del compilatore C e C++ Clang. L’albero è implementato principalmente in C e C++, con build basate su CMake, supporto runtime compiler-rt e test Clang estesi e checker dell’analizzatore statico tipici di LLVM upstream. Clang qui include lavoro di compatibilità con Microsoft Visual C++, come un driver orientato a MSVC, supporto toolchain Windows cross e gestione varargs specifica di MSVC, mirato a compilare codice nativo Windows con un compilatore basato su LLVM allineato all’ecosistema MSVC. BOLT fornisce riscrittura binaria, profiling e pass di ottimizzazione per eseguibili x86, AArch64 e RISC-V. È destinato a sviluppatori nativi Windows, reverse engineer e ricercatori di game security che vogliono le capacità di Clang e LLVM con compatibilità simile a MSVC piuttosto che affidarsi solo alla toolchain proprietaria Microsoft.
