Этот проект — llvm-msvc, форк монорепозитория LLVM, который объединяет компоненты toolchain, включая постлинковый бинарный оптимизатор BOLT и фронтенд компилятора C и C++ Clang. Дерево в основном реализовано на C и C++, со сборками на CMake, поддержкой runtime compiler-rt и обширными тестами Clang и чекерами статического анализатора, типичными для upstream LLVM. Clang здесь включает работу по совместимости с Microsoft Visual C++: драйвер, ориентированный на MSVC, поддержку кросс-платформенной Windows toolchain и обработку varargs, специфичную для MSVC, с целью сборки нативного Windows-кода компилятором на базе LLVM, согласованным с экосистемой MSVC. BOLT обеспечивает переписывание бинарников, профилирование и проходы оптимизации для исполняемых файлов x86, AArch64 и RISC-V. Предназначен для нативных Windows-разработчиков, reverse engineers и исследователей безопасности игр, которым нужны возможности Clang и LLVM с совместимостью, близкой к MSVC, а не только проприетарная toolchain Microsoft.
