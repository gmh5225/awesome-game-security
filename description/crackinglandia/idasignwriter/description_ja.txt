IDA SigWriter は、解析者の選択範囲からバイト単位のコードパターンを組み立て、ドッキング可能な GUI で細かいワイルドカード制御付きで表示する IDA Pro プラグインです。Python（IDAPython）で実装され、IDA 8.2 では PyQt5、IDA 9.3 以降では PySide6 を使用し、ジャンプ、コール、グローバル参照や RIP 相対参照、即値、フィックスアップ、ARM や MIPS などのアーキテクチャにおける曖昧なオペランドを自動的にワイルドカード化できます。パターンはコピーしたり、スタンドアロンの IDA または x64dbg/Cheat Engine 文字列、マスク付き C/C++ 配列、YARA ルールや生の十六進、マスク付きバイナリブロブとして保存でき、データベース内の一致を検索することも可能です。コンパニオンの .NET 版はマネージドバイナリから CIL パターンを生成し、同じエクスポートオプションを提供するため、ビルドをまたいで関数やコード領域を特定するための信頼できるシグネチャを必要とするリバースエンジニアやゲームセキュリティ研究者に有用です。
