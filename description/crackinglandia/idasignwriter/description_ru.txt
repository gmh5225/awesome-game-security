IDA SigWriter — плагин для IDA Pro, который строит байтовые шаблоны кода по выделению аналитика и показывает их в пристыковываемом GUI с тонкой настройкой подстановочных символов. Реализован на Python (IDAPython): PyQt5 в IDA 8.2 и PySide6 в IDA 9.3 и новее; автоматически обобщает переходы, вызовы, глобальные и RIP-относительные ссылки, непосредственные значения, фиксации и неоднозначные операнды на архитектурах вроде ARM и MIPS. Шаблоны можно копировать или сохранять как отдельные строки для IDA или x64dbg/Cheat Engine, массивы C/C++ с масками, правила YARA или сырой hex, двоичные блоки с масками, а инструмент умеет искать совпадения в базе. Сопутствующий вариант на .NET формирует шаблоны CIL из управляемых бинарников с теми же параметрами экспорта, поэтому набор полезен реверс-инженерам и исследователям игровой безопасности, которым нужны надёжные сигнатуры для поиска функций и участков кода в разных сборках.
