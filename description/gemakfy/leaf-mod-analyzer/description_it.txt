Leaf Mod Analyzer è un analizzatore statico autonomo per file JAR di mod Minecraft che ispeziona il bytecode delle classi Java senza richiedere JVM o decompilazione. È costruito principalmente in Rust come strumento da riga di comando con un’estensione Python opzionale, combinando un parser classfile nativo, scansione JAR, euristiche di entropia e offuscamento e un motore di regole guidato da JSON. Lo strumento supporta scansioni su singolo file e batch di directory, directory di regole personalizzate e report su misura per i loader Fabric, Forge e NeoForge. Le euristiche mirano a offuscamento, rinomina aggressiva, identificatori omoglifi, pool di stringhe crittografate e pattern di bytecode sospetti tipici dei client cheat. È pensato per operatori di server, flussi anti-cheat e moderazione, e ricercatori che necessitano di un triage offline rapido di mod di terze parti.
