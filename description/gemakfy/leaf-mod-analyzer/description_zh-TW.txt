Leaf Mod Analyzer 是一款獨立的 Minecraft 模組 JAR 靜態分析器，可在無需 JVM 或反編譯的情況下檢查 Java 類別位元組碼。它主要以 Rust 建構，作為命令列工具，並提供可選的 Python 擴充，結合原生 classfile 解析器、JAR 掃描、熵與混淆啟發式分析，以及以 JSON 驅動的規則引擎。該工具支援單一檔案與批次目錄掃描、自訂規則目錄，以及針對 Fabric、Forge 與 NeoForge 載入器的報告。啟發式偵測鎖定混淆、激進重新命名、同形異義字識別符、加密字串池，以及作弊客戶端中常見的可疑位元組碼模式。面向伺服器營運者、反作弊與審核流程，以及需要快速離線初篩第三方模組的研究人員。
