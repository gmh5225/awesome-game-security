Leaf Mod Analyzer는 JVM이나 디컴파일 없이 Java 클래스 바이트코드를 검사하는 Minecraft mod JAR 파일용 독립형 정적 분석기입니다. 주로 Rust로 만들어진 CLI 도구이며 선택적 Python 확장을 제공하고, 네이티브 classfile 파서, JAR 스캔, 엔트로피 및 난독화 휴리스틱, JSON 기반 규칙 엔진을 결합합니다. 단일 파일 및 디렉터리 일괄 스캔, 사용자 정의 규칙 디렉터리, Fabric·Forge·NeoForge 로더에 맞춘 보고를 지원합니다. 휴리스틱은 난독화, 과도한 이름 변경, 호모글리프 식별자, 암호화된 문자열 풀, 치트 클라이언트에서 흔한 의심스러운 바이트코드 패턴을 겨냥합니다. 서버 운영자, 안티치트 및 모더레이션 워크플로, 서드파티 mod를 빠르게 오프라인으로 선별해야 하는 연구자를 대상으로 합니다.
