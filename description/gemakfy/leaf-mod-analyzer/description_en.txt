Leaf Mod Analyzer is a standalone static analyzer for Minecraft mod JAR files that inspects Java class bytecode without requiring a JVM or decompilation. It is built primarily in Rust as a command-line tool with an optional Python extension, combining a native classfile parser, JAR scanning, entropy and obfuscation heuristics, and a JSON-driven rule engine. The tool supports single-file and batch directory scans, custom rule directories, and reporting tailored to Fabric, Forge, and NeoForge loaders. Heuristics target obfuscation, aggressive renaming, homoglyph identifiers, encrypted string pools, and suspicious bytecode patterns common in cheat clients. It is aimed at server operators, anti-cheat and moderation workflows, and researchers who need fast offline triage of third-party mods.
