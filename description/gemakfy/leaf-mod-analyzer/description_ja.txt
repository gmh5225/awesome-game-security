Leaf Mod Analyzer は、JVM や逆コンパイルを必要とせず Java クラスのバイトコードを検査する、Minecraft mod の JAR ファイル向けスタンドアロン静的アナライザです。主に Rust で構築された CLI ツールで、オプションの Python 拡張を備え、ネイティブ classfile パーサー、JAR スキャン、エントロピーと難読化のヒューリスティック、JSON 駆動のルールエンジンを組み合わせています。単一ファイルおよびディレクトリのバッチスキャン、カスタムルールディレクトリ、Fabric・Forge・NeoForge ローダー向けのレポートに対応します。ヒューリスティックは難読化、過度なリネーム、ホモグリフ識別子、暗号化された文字列プール、チートクライアントに多い疑わしいバイトコードパターンを対象とします。サーバー運営者、反チート・モデレーションのワークフロー、第三者 mod を高速にオフラインでトリアージする必要がある研究者向けです。
