Leaf Mod Analyzer 是一款面向 Minecraft 模组 JAR 文件的独立静态分析器，可在无需 JVM 或反编译的情况下检查 Java 类字节码。它主要由 Rust 构建，作为命令行工具，并提供可选的 Python 扩展，结合了原生 classfile 解析器、JAR 扫描、熵与混淆启发式分析以及基于 JSON 的规则引擎。该工具支持单文件与批量目录扫描、自定义规则目录，以及针对 Fabric、Forge 与 NeoForge 加载器的报告。启发式检测针对混淆、激进重命名、同形异义标识符、加密字符串池以及作弊客户端中常见的可疑字节码模式。适用于服主、反作弊与审核流程，以及需要快速离线筛查第三方模组的研究人员。
