ttd-capa è un estrattore di capacità compatibile con capa che analizza le tracce Microsoft Time Travel Debugging (TTD) per far emergere comportamenti di malware e programmi che le scansioni statiche dei file non possono rilevare. Scritto principalmente in C++ con script wrapper Python, riproduce le tracce di esecuzione registrate tramite un estrattore nativo basato sul TTD SDK, decodifica gli argomenti delle chiamate API usando indici di metadati Win32 e API native, e confronta i risultati con le regole capa tramite una reimplementazione capa ad alte prestazioni in C++. Le funzionalità principali includono l'estrazione dinamica delle chiamate API, la scansione opzionale delle regioni di codice per recuperare capacità da codice decompattato o generato a runtime, report cronologici sull'esecuzione delle capacità e una DLL incorporabile per l'integrazione in strumenti di analisi personalizzati. È rivolto a reverse engineer, analisti di malware e ricercatori di sicurezza dei giochi che necessitano di rilevamento comportamentale delle capacità da registrazioni TTD di processo completo, anziché basarsi solo su binari statici.
