ttd-capa는 capa 호환 기능 추출기로, Microsoft Time Travel Debugging(TTD) 트레이스를 분석하여 정적 파일 스캔으로는 확인할 수 없는 악성코드 및 프로그램 동작을 드러냅니다. 주로 C++로 작성되었으며 Python 래퍼 스크립트를 함께 제공합니다. 기록된 실행 트레이스를 TTD SDK 기반 네이티브 추출기로 재생하고, Win32 및 네이티브 API 메타데이터 인덱스를 사용해 API 호출 인수를 디코딩한 뒤, 고성능 C++ capa 재구현을 통해 결과를 capa 규칙과 대조합니다. 주요 기능으로는 동적 API 호출 추출, 선택적 코드 영역 스캔(언팩 또는 런타임 생성 코드에서 기능 복구), 기능 실행 타임라인 보고, 사용자 정의 분석 도구 통합용 임베드 가능 DLL이 있습니다. 정적 바이너리뿐 아니라 전체 프로세스 TTD 녹화본에서 행위 기반 기능 탐지가 필요한 리버스 엔지니어, 악성코드 분석가, 게임 보안 연구자를 대상으로 합니다.
