ttd-capa es un extractor de capacidades compatible con capa que analiza trazas de Microsoft Time Travel Debugging (TTD) para revelar comportamientos de malware y programas que los análisis estáticos de archivos no pueden detectar. Escrito principalmente en C++ con scripts envoltorio en Python, reproduce trazas de ejecución grabadas mediante un extractor nativo basado en el TTD SDK, decodifica los argumentos de las llamadas a API usando índices de metadatos de Win32 y API nativas, y compara los resultados con reglas capa mediante una reimplementación capa de alto rendimiento en C++. Entre sus funciones clave se incluyen la extracción dinámica de llamadas a API, el escaneo opcional de regiones de código para recuperar capacidades de código desempaquetado o generado en tiempo de ejecución, informes cronológicos de cuándo se ejecutaron las capacidades, y una DLL integrable para incorporarla en herramientas de análisis personalizadas. Está dirigido a ingenieros de ingeniería inversa, analistas de malware e investigadores de seguridad en juegos que necesitan detección comportamental de capacidades a partir de grabaciones TTD de procesos completos, y no solo de binarios estáticos.
