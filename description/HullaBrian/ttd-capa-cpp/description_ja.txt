ttd-capa は capa 互換のケイパビリティ抽出ツールで、Microsoft Time Travel Debugging（TTD）トレースを解析し、静的ファイルスキャンでは見えないマルウェアやプログラムの挙動を浮き彫りにします。主に C++ で実装され、Python ラッパースクリプトも提供されます。記録された実行トレースを TTD SDK 上に構築されたネイティブ抽出器で再生し、Win32 およびネイティブ API のメタデータインデックスを用いて API 呼び出し引数をデコードし、高性能な C++ 版 capa 再実装を通じて結果を capa ルールと照合します。主な機能には、動的 API 呼び出し抽出、オプションのコード領域スキャン（アンパック済みまたは実行時生成コードからケイパビリティを復元）、ケイパビリティ実行タイムラインのレポート、カスタム分析ツールへの組み込み用 DLL があります。静的バイナリだけでなく、プロセス全体の TTD 記録から行動ベースのケイパビリティ検出が必要なリバースエンジニア、マルウェアアナリスト、ゲームセキュリティ研究者を対象としています。
