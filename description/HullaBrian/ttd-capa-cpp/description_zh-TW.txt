ttd-capa 是一款與 capa 相容的能力提取器，透過分析 Microsoft Time Travel Debugging（TTD）追蹤來揭露靜態檔案掃描無法發現的惡意軟體與程式行為。此專案主要以 C++ 撰寫，並輔以 Python 包裝腳本；它將錄製的執行追蹤回放到基於 TTD SDK 建構的原生提取器中，利用 Win32 與原生 API 中繼資料索引解碼 API 呼叫參數，再透過高效能 C++ 版 capa 重實作將結果與 capa 規則進行比對。主要功能包括動態 API 呼叫提取、可選的程式碼區域掃描（用於從解包或執行階段產生的程式碼中還原能力）、能力執行時間軸報告，以及可嵌入自訂分析工具的 DLL。它面向需要基於完整程序 TTD 錄製進行行為能力偵測，而不僅依賴靜態二進位檔的逆向工程師、惡意軟體分析師與遊戲安全研究人員。
