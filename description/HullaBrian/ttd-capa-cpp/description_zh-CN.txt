ttd-capa 是一款与 capa 兼容的能力提取器，通过分析 Microsoft Time Travel Debugging（TTD）跟踪来揭示静态文件扫描无法发现的恶意软件与程序行为。该项目主要使用 C++ 编写，并辅以 Python 包装脚本；它将录制的执行跟踪回放到基于 TTD SDK 构建的原生提取器中，利用 Win32 与原生 API 元数据索引解码 API 调用参数，再通过高性能 C++ 版 capa 重实现将结果与 capa 规则进行匹配。主要功能包括动态 API 调用提取、可选的代码区域扫描（用于从解包或运行时生成的代码中恢复能力）、能力执行时间线报告，以及可嵌入自定义分析工具的 DLL。它面向需要基于完整进程 TTD 录制进行行为能力检测，而不仅依赖静态二进制文件的逆向工程师、恶意软件分析师和游戏安全研究人员。
