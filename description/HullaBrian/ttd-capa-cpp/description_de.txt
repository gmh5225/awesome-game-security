ttd-capa ist ein capa-kompatibler Fähigkeits-Extraktor, der Microsoft Time Travel Debugging (TTD)-Traces analysiert, um Malware- und Programmverhalten sichtbar zu machen, das statische Dateiscans nicht erfassen können. Hauptsächlich in C++ geschrieben und mit Python-Wrapper-Skripten ergänzt, spielt er aufgezeichnete Ausführungstraces über einen nativen Extraktor auf Basis des TTD SDK ab, dekodiert API-Aufrufargumente mithilfe von Win32- und nativen API-Metadatenindizes und gleicht die Ergebnisse über eine leistungsstarke C++-capa-Neuimplementierung mit capa-Regeln ab. Zu den wichtigsten Funktionen gehören die dynamische Extraktion von API-Aufrufen, optionales Scannen von Codebereichen zur Wiederherstellung von Fähigkeiten aus entpacktem oder zur Laufzeit erzeugtem Code, Zeitachsenberichte über die Ausführung von Fähigkeiten sowie eine einbettbare DLL zur Integration in benutzerdefinierte Analysetools. Es richtet sich an Reverse Engineers, Malware-Analysten und Game-Security-Forscher, die verhaltensbasierte Fähigkeitserkennung aus vollständigen Prozess-TTD-Aufzeichnungen benötigen, statt sich allein auf statische Binärdateien zu stützen.
