ttd-capa — совместимый с capa экстрактор возможностей, который анализирует трассировки Microsoft Time Travel Debugging (TTD), чтобы выявлять поведение вредоносного ПО и программ, недоступное для статического сканирования файлов. Написанный преимущественно на C++ с Python-обёртками, он воспроизводит записанные трассировки выполнения через нативный экстрактор на базе TTD SDK, декодирует аргументы вызовов API с помощью индексов метаданных Win32 и нативных API и сопоставляет результаты с правилами capa через высокопроизводительную C++-реализацию capa. Ключевые возможности включают динамическое извлечение вызовов API, опциональное сканирование областей кода для восстановления возможностей из распакованного или сгенерированного во время выполнения кода, отчёты с временной шкалой выполнения возможностей и встраиваемую DLL для интеграции в пользовательские инструменты анализа. Предназначен для специалистов по реверс-инжинирингу, аналитиков вредоносного ПО и исследователей безопасности игр, которым нужно поведенческое обнаружение возможностей по полным TTD-записям процессов, а не только по статическим бинарным файлам.
