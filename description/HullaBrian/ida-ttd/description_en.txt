ida-ttd is an IDA Pro plugin that loads time-travel debugging recordings as a full debugger session inside IDA, so analysts can step forward and backward through execution and query the entire trace. It supports Microsoft TTD .run files via the TTD Replay SDK and Sogen .sogttd traces through a modular C++ backend architecture, with companion Python scripting for automation. Key capabilities include bookmarks and timelines, API and pattern call logging with decoded Win32 arguments, memory read/write/execute searches, value origin tracing, syscall and handle inspection, coverage and heatmap views, and recovered strings and buffers, plus fork-and-compare replay on Sogen recordings. The project targets Windows x64 reverse engineers and malware or anti-cheat researchers who want IDA’s disassembly and decompiler tied to recorded execution instead of live-only debugging.
