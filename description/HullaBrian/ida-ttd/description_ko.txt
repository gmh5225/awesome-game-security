ida-ttd는 IDA Pro 플러그인으로, 타임 트래블 디버깅 기록을 IDA 안의 전체 디버거 세션으로 불러와 분석자가 실행을 앞뒤로 스텝하고 전체 추적을 조회할 수 있게 합니다. Microsoft TTD .run 파일은 TTD Replay SDK로, Sogen .sogttd 추적은 모듈형 C++ 백엔드로 지원하며 자동화를 위한 Python 스크립트도 제공합니다. 주요 기능에는 북마크와 타임라인, 디코딩된 Win32 인수가 포함된 API 및 패턴 호출 로깅, 메모리 읽기·쓰기·실행 검색, 값 출처 추적, 시스템 호출 및 핸들 검사, 커버리지와 히트맵 보기, 복구된 문자열과 버퍼, Sogen 기록에서의 포크 후 비교 재생이 있습니다. 이 프로젝트는 라이브 디버깅만이 아니라 기록된 실행을 IDA 디스어셈블리 및 디컴파일러와 연결하려는 Windows x64 리버스 엔지니어와 멀웨어 또는 안티치트 연구자를 대상으로 합니다.
