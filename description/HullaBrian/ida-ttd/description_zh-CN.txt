ida-ttd 是一款 IDA Pro 插件，可将时间旅行调试录制作为完整调试会话载入 IDA，使分析人员能够向前或向后单步执行并查询完整跟踪。它通过 TTD Replay SDK 支持 Microsoft TTD 的 .run 文件，并以模块化 C++ 后端支持 Sogen 的 .sogttd 跟踪，同时提供配套 Python 脚本以实现自动化。主要能力包括书签与时间线、带 Win32 参数解码的 API 与模式调用日志、内存读/写/执行搜索、值来源追踪、系统调用与句柄检查、覆盖率与热力图视图，以及恢复的字符串与缓冲区，并可在 Sogen 录制上进行分叉对比回放。本项目面向希望在 IDA 反汇编与反编译中绑定已记录执行而非仅依赖现场调试的 Windows x64 逆向工程师以及恶意软件或反作弊研究人员。
