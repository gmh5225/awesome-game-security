ida-ttd は IDA Pro 向けプラグインで、タイムトラベルデバッグの記録を IDA 内のフルデバッガセッションとして読み込み、解析者が実行を前後にステップし、トレース全体を照会できるようにします。Microsoft TTD の .run ファイルは TTD Replay SDK 経由で、Sogen の .sogttd トレースはモジュラーな C++ バックエンドで扱い、自動化用の Python スクリプトも備えています。主な機能はブックマークとタイムライン、Win32 引数をデコードした API およびパターン呼び出しログ、メモリの読み書き・実行検索、値の発生源トレース、システムコールとハンドル検査、カバレッジとヒートマップ表示、復元された文字列とバッファ、および Sogen 記録上のフォーク比較リプレイです。本プロジェクトは、ライブデバッグだけでなく記録された実行を IDA の逆アセンブルとデコンパイラに結びつけたい Windows x64 のリバースエンジニア、マルウェアおよびアンチチート研究者を対象としています。
