ida-ttd es un complemento de IDA Pro que carga grabaciones de depuración de viaje en el tiempo como una sesión de depurador completa dentro de IDA, de modo que los analistas pueden avanzar y retroceder en la ejecución y consultar todo el rastro. Admite archivos .run de Microsoft TTD mediante el TTD Replay SDK y trazas .sogttd de Sogen a través de una arquitectura backend modular en C++, con scripts Python complementarios para automatización. Las capacidades clave incluyen marcadores y líneas de tiempo, registro de llamadas a API y patrones con argumentos Win32 decodificados, búsquedas de lectura/escritura/ejecución en memoria, rastreo del origen de valores, inspección de llamadas al sistema y handles, vistas de cobertura y mapas de calor, cadenas y búferes recuperados, además de reproducción fork-and-compare en grabaciones Sogen. El proyecto está dirigido a ingenieros inversos de Windows x64 e investigadores de malware o anti-cheat que quieren enlazar el desensamblado y el descompilador de IDA con la ejecución grabada en lugar de depender solo del depurado en vivo.
