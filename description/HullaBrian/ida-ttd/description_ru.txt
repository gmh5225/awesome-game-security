ida-ttd — плагин для IDA Pro, который загружает записи отладки с путешествием во времени как полноценную сессию отладчика в IDA, чтобы аналитики могли шагать вперёд и назад по выполнению и запрашивать всю трассировку. Поддерживаются файлы Microsoft TTD .run через TTD Replay SDK и трассы Sogen .sogttd на модульной C++-бэкенд-архитектуре, с сопутствующими Python-скриптами для автоматизации. Ключевые возможности: закладки и временные шкалы, журналирование вызовов API и по шаблонам с декодированными аргументами Win32, поиск операций чтения/записи/выполнения в памяти, отслеживание происхождения значений, просмотр системных вызовов и дескрипторов, представления покрытия и тепловых карт, восстановленные строки и буферы, а также fork-and-compare воспроизведение на записях Sogen. Проект ориентирован на реверс-инженеров Windows x64 и исследователей вредоносного ПО или античита, которым нужно связать дизассемблирование и декомпилятор IDA с записанным выполнением, а не только с отладкой «вживую».
