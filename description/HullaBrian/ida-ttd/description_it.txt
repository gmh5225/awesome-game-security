ida-ttd è un plugin per IDA Pro che carica le registrazioni di debug time-travel come una sessione di debugger completa in IDA, così gli analisti possono avanzare e tornare indietro nell’esecuzione e interrogare l’intera traccia. Supporta i file .run Microsoft TTD tramite il TTD Replay SDK e le tracce .sogttd Sogen tramite un’architettura backend C++ modulare, con script Python di supporto per l’automazione. Le funzionalità principali includono segnalibri e timeline, log delle chiamate API e di pattern con argomenti Win32 decodificati, ricerche in memoria di lettura/scrittura/esecuzione, tracciamento dell’origine dei valori, ispezione di syscall e handle, viste di copertura e heatmap, stringhe e buffer recuperati, oltre al replay fork-and-compare sulle registrazioni Sogen. Il progetto è rivolto a reverse engineer Windows x64 e ricercatori di malware o anti-cheat che vogliono legare disassemblaggio e decompilatore di IDA all’esecuzione registrata invece che al solo debug in tempo reale.
