ida-ttd 是一款 IDA Pro 外掛，可將時間旅行偵錯錄製載入為 IDA 內的完整偵錯工作階段，讓分析人員能向前或向後逐步執行並查詢完整追蹤。它透過 TTD Replay SDK 支援 Microsoft TTD 的 .run 檔，並以模組化 C++ 後端支援 Sogen 的 .sogttd 追蹤，同時提供配套的 Python 指令碼以實現自動化。主要功能包含書籤與時間軸、附 Win32 引數解碼的 API 與模式呼叫記錄、記憶體讀寫與執行搜尋、數值來源追蹤、系統呼叫與控制代碼檢視、覆蓋率與熱力圖檢視，以及還原的字串與緩衝區，並可在 Sogen 錄製上進行分叉比對重播。本專案鎖定希望在 IDA 反組譯與反編譯中結合已記錄執行、而非僅限即時偵錯的 Windows x64 逆向工程師，以及惡意軟體或反作弊研究人員。
