Lightyear は、Bevy ゲームエンジンを用いてサーバー権威型のマルチプレイヤーゲームを構築する Rust ライブラリで、WebTransport による WebAssembly サポートも含みます。aeronet 経由で UDP、WebSocket、Steam、WebTransport にわたるトランスポート非依存のネットワーキングを提供し、メッセージチャネル、パケット分割、postcard ベースのシリアライゼーションを備えています。高度なレプリケーション機能には、ロールバック付きクライアント側予測、スナップショット補間、決定論的入力レプリケーション、ラグ補償、帯域幅管理、bevy_replicon によるワールドレプリケーションが含まれます。クライアント-サーバー、ピアツーピア、ホスト-クライアントの各トポロジに対応し、tick 同期の入力処理や、Avian や Leafwing などの物理・入力 crate との統合もサポートします。ゲーム開発者や、権威型マルチプレイヤーアーキテクチャ、ネットコード設計、およびアンチチートやエクスプロイト分析の基盤となるクライアント-サーバー間の信頼境界を研究するセキュリティ研究者を対象としています。
