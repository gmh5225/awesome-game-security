Lightyear는 Bevy 게임 엔진으로 서버 권한형 멀티플레이어 게임을 구축하는 Rust 라이브러리이며, WebTransport를 통한 WebAssembly 지원도 포함합니다. aeronet을 통해 UDP, WebSocket, Steam, WebTransport에 걸친 전송 계층에 독립적인 네트워킹을 제공하며, 메시지 채널, 패킷 분할, postcard 기반 직렬화를 갖추고 있습니다. 고급 복제 기능으로는 롤백을 포함한 클라이언트 측 예측, 스냅샷 보간, 결정론적 입력 복제, 지연 보상, 대역폭 관리, bevy_replicon을 통한 월드 복제가 있습니다. 클라이언트-서버, 피어 투 피어, 호스트-클라이언트 토폴로지를 지원하며 tick 동기화 입력 처리와 Avian, Leafwing 같은 물리 및 입력 crate 통합을 제공합니다. 게임 개발자와 권한형 멀티플레이어 아키텍처, 넷코드 설계, 그리고 안티치트 및 익스플로잇 분석의 기반이 되는 클라이언트-서버 신뢰 경계를 연구하는 보안 연구자를 대상으로 합니다.
