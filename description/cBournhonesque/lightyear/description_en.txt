Lightyear is a Rust library for building server-authoritative multiplayer games with the Bevy game engine, including WebAssembly support through WebTransport. It provides transport-agnostic networking over UDP, WebSocket, Steam, and WebTransport via aeronet, with message channels, packet fragmentation, and postcard-based serialization. Advanced replication features include client-side prediction with rollback, snapshot interpolation, deterministic input replication, lag compensation, bandwidth management, and world replication through bevy_replicon. The library supports client-server, peer-to-peer, and host-client topologies with tick-synchronized input handling and integrations for physics and input crates such as Avian and Leafwing. It is aimed at game developers and security researchers studying authoritative multiplayer architecture, netcode design, and the client-server trust boundaries that underpin anti-cheat and exploit analysis.
