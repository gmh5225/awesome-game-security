This is a curated collection of code and binary obfuscation tools and projects. It organizes resources into three categories: binary-code obfuscators that transform executables and shellcode, compile-time obfuscators that protect source code during the build process, and compiler-based obfuscators built on LLVM or GCC toolchains. The list spans C and C++ libraries, x86 assembly transformers, Go and Rust tooling, and virtual machine-based protectors. It serves developers and security researchers working on anti-reverse-engineering, anti-tampering, and software protection for native binaries and game security applications.
