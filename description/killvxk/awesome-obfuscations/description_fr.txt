Il s'agit d'une collection organisée d'outils et de projets d'obfuscation de code et binaire. Elle classe les ressources en trois catégories : les obfuscateurs de code binaire qui transforment les exécutables et le shellcode, les obfuscateurs à la compilation qui protègent le code source pendant le processus de build, et les obfuscateurs basés sur le compilateur construits sur les chaînes d'outils LLVM ou GCC. La liste couvre les bibliothèques C et C++, les transformateurs d'assembleur x86, les outils Go et Rust, ainsi que les protecteurs basés sur des machines virtuelles. Elle s'adresse aux développeurs et chercheurs en sécurité travaillant sur l'anti-rétro-ingénierie, l'anti-altération et la protection logicielle pour les binaires natifs et les applications de sécurité des jeux.
