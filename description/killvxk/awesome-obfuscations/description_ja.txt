これは、コードおよびバイナリ難読化ツールとプロジェクトを厳選したコレクションです。リソースは3つのカテゴリに整理されています。実行ファイルやシェルコードを変換するバイナリコード難読化ツール、ビルドプロセス中にソースコードを保護するコンパイル時難読化ツール、LLVM または GCC ツールチェーン上に構築されたコンパイラベースの難読化ツールです。このリストには、C および C++ ライブラリ、x86 アセンブリ変換ツール、Go および Rust 向けツール、仮想マシンベースのプロテクターが含まれます。ネイティブバイナリやゲームセキュリティアプリケーションに向けた、リバースエンジニアリング対策、改ざん防止、ソフトウェア保護に取り組む開発者やセキュリティ研究者向けです。
