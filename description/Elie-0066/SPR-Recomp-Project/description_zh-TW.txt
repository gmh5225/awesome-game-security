SPR Recomp 是一項非官方的靜態重編譯專案，將 Nintendo Switch 2 上《Splatoon Raiders》的 ARM64 遊戲程式碼提升並建置為基於 Vulkan 渲染器的原生 Windows x86-64 可執行檔。工具鏈以 Python 提升器與建置編排為核心（包括依使用者提供的 dump 進行程式碼產生與修補套用），輔以大型 C 執行階段來模擬 Switch 系統服務、音訊、輸入與圖形，並將 NVN2/Maxwell 著色器翻譯為 PC GPU 路徑所用的 SPIR-V。其架構繼承自先前的《薩爾達傳說：王國之淚》與《大金剛 Bananza》重編譯工作，內建可在本機編譯提升輸出的安裝器，並使用 Unicorn 等差分測試工具在不散佈專有遊戲資產的前提下驗證提升器。主要面向希望從合法取得的 dump 中研究或在 PC 上執行 Switch 2 二進位檔的逆向工程師與注重保存的開發者，而非商業反作弊或遊戲安全產品整合。
