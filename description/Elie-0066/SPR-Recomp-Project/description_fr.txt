SPR Recomp est un projet officieux de recompilation statique qui extrait le code de jeu ARM64 de Splatoon Raiders sur Nintendo Switch 2 et produit un exécutable Windows x86-64 natif avec un moteur de rendu basé sur Vulkan. La chaîne d’outils repose sur des lifters Python et l’orchestration de build (y compris la génération de code et l’application de correctifs à partir de dumps fournis par l’utilisateur), un grand runtime C qui émule les services du système Switch, l’audio, les entrées et le graphisme, ainsi que la traduction des shaders de NVN2/Maxwell vers SPIR-V pour le chemin GPU PC. Il reprend l’architecture des précédents efforts de recomp pour TotK et Donkey Kong Bananza, inclut un installateur qui compile localement la sortie relevée, et utilise des outils de test différentiel comme Unicorn pour valider le lifter sans distribuer d’actifs de jeu propriétaires. Le public visé est principalement les ingénieurs en rétro-ingénierie et les développeurs soucieux de préservation qui souhaitent étudier ou exécuter des binaires Switch 2 sur PC à partir de dumps obtenus légalement, et non l’intégration commerciale anti-triche ou produits de sécurité de jeux.
