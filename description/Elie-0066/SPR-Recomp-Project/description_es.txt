SPR Recomp es un proyecto no oficial de recompilación estática que eleva el código de juego ARM64 de Splatoon Raiders en Nintendo Switch 2 y construye un ejecutable nativo Windows x86-64 con un renderizador basado en Vulkan. La cadena de herramientas se centra en lifters en Python y orquestación de compilación (incluida generación de código y aplicación de parches a partir de volcados proporcionados por el usuario), un amplio runtime en C que emula servicios del sistema Switch, audio, entrada y gráficos, y traducción de shaders de NVN2/Maxwell a SPIR-V para la ruta GPU en PC. Hereda la arquitectura de esfuerzos previos de recomp para TotK y Donkey Kong Bananza, incluye un instalador que compila localmente la salida elevada y usa herramientas de prueba diferencial como Unicorn para validar el lifter sin distribuir activos de juego propietarios. El público principal son ingenieros inversos y desarrolladores orientados a la preservación que quieren estudiar o ejecutar binarios de Switch 2 en PC a partir de volcados obtenidos legalmente, no la integración comercial de anti-cheat o productos de seguridad de juegos.
