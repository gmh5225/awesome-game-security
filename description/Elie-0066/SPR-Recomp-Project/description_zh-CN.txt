SPR Recomp 是一项非官方的静态重编译项目，将 Nintendo Switch 2 上《Splatoon Raiders》的 ARM64 游戏代码提升并构建为基于 Vulkan 渲染器的原生 Windows x86-64 可执行文件。工具链以 Python 提升器与构建编排为核心（包括根据用户提供的 dump 进行代码生成与补丁应用），辅以大型 C 运行时来模拟 Switch 系统服务、音频、输入与图形，并将 NVN2/Maxwell 着色器翻译为 PC GPU 路径所用的 SPIR-V。其架构继承自先前的《塞尔达传说：王国之泪》与《大金刚 Bananza》重编译工作，捆绑可在本地编译提升输出的安装器，并使用 Unicorn 等差分测试工具在不分发专有游戏资源的前提下验证提升器。主要面向希望从合法获得的 dump 中研究或在 PC 上运行 Switch 2 二进制文件的逆向工程师与注重保存的开发者，而非商业反作弊或游戏安全产品集成。
