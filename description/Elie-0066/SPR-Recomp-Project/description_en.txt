SPR Recomp is an unofficial static recompilation project that lifts Nintendo Switch 2 ARM64 game code for Splatoon Raiders and builds a native Windows x86-64 executable with a Vulkan-based renderer. The toolchain centers on Python lifters and build orchestration (including codegen and patch application from user-supplied dumps), a large C runtime that emulates Switch OS services, audio, input, and graphics, and shader translation from NVN2/Maxwell to SPIR-V for the PC GPU path. It inherits architecture from prior TotK and Donkey Kong Bananza recomp efforts, bundles an installer that compiles the lifted output locally, and uses differential testing tools such as Unicorn to validate the lifter without shipping proprietary game assets. The primary audience is reverse engineers and preservation-minded developers who want to study or run Switch 2 binaries on PC from legally obtained dumps, not commercial anti-cheat or game-security product integration.
