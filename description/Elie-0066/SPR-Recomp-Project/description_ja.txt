SPR Recomp は、Nintendo Switch 2 版 Splatoon Raiders の ARM64 ゲームコードを静的再コンパイルして持ち上げ、Vulkan ベースのレンダラー付きネイティブ Windows x86-64 実行ファイルを構築する非公式プロジェクトです。ツールチェーンは Python リフターとビルドオーケストレーション（ユーザー提供ダンプからのコード生成とパッチ適用を含む）を中心に、Switch OS サービス・オーディオ・入力・グラフィックスをエミュレートする大規模な C ランタイム、および PC GPU 向けに NVN2/Maxwell から SPIR-V へのシェーダー翻訳で構成されます。TotK や Donkey Kong Bananza の先行再コンパイル作業のアーキテクチャを引き継ぎ、持ち上げた出力をローカルでコンパイルするインストーラを同梱し、Unicorn などの差分テストツールでプロプライエタリなゲームアセットを配布せずにリフターを検証します。主な対象は、合法的に入手したダンプから Switch 2 バイナリを PC で研究・実行したいリバースエンジニアや保存志向の開発者であり、商用アンチチートやゲームセキュリティ製品への統合を目的としたものではありません。
