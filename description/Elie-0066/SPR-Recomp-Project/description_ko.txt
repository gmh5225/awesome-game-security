SPR Recomp은 Nintendo Switch 2용 Splatoon Raiders ARM64 게임 코드를 정적 재컴파일로 끌어올려 Vulkan 기반 렌더러가 포함된 네이티브 Windows x86-64 실행 파일을 만드는 비공식 프로젝트입니다. 툴체인은 Python 리프터와 빌드 오케스트레이션(사용자가 제공한 덤프에서 코드 생성 및 패치 적용 포함)을 중심으로, Switch OS 서비스·오디오·입력·그래픽을 에뮬레이션하는 대형 C 런타임, PC GPU 경로를 위한 NVN2/Maxwell에서 SPIR-V로의 셰이더 변환으로 구성됩니다. 이전 TotK 및 Donkey Kong Bananza 재컴파일 작업의 아키텍처를 물려받으며, 리프팅된 출력을 로컬에서 컴파일하는 설치 프로그램을 포함하고, Unicorn 같은 차분 테스트 도구로 독점 게임 자산을 배포하지 않고 리프터를 검증합니다. 주요 대상은 합법적으로 획득한 덤프로 Switch 2 바이너리를 연구하거나 PC에서 실행하려는 리버스 엔지니어와 보존 지향 개발자이며, 상용 안티치트나 게임 보안 제품 통합용이 아닙니다.
