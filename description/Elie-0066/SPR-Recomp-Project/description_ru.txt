SPR Recomp — неофициальный проект статической перекомпиляции, который поднимает ARM64-игровой код Splatoon Raiders для Nintendo Switch 2 и собирает нативный исполняемый файл Windows x86-64 с рендерером на базе Vulkan. Цепочка инструментов опирается на Python-лифтеры и оркестрацию сборки (включая генерацию кода и применение патчей из предоставленных пользователем дампов), крупную C-рантайм-среду, эмулирующую службы ОС Switch, аудио, ввод и графику, а также перевод шейдеров с NVN2/Maxwell в SPIR-V для GPU-пути на ПК. Архитектура унаследована от прежних работ по рекомпиляции TotK и Donkey Kong Bananza; в комплекте установщик, который локально компилирует поднятый вывод, и инструменты дифференциального тестирования вроде Unicorn для проверки лифтера без распространения проприетарных игровых ресурсов. Основная аудитория — специалисты по обратной разработке и разработчики, ориентированные на сохранение, которые хотят изучать или запускать бинарники Switch 2 на ПК из законно полученных дампов, а не коммерческая интеграция античитов или продуктов игровой безопасности.
