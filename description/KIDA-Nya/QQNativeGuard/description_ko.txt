QQ Native Guard는 Android LSPosed 모듈로, Java 계층 QQ 탐지 우회를 확장하고 Tencent QQ의 환경 및 기기 무결성 검사를 겨냥한 네이티브 훅을 제공합니다. Gradle로 빌드하며 앱 측은 Java/Kotlin, 네이티브는 C++(NDK)이고 ByteHook 인라인 훅으로 libc와 fekit, MSF, Turing 등 QQ 관련 라이브러리를 걸치며 시스템 속성, proc/sysfs 읽기, 식별자, HTTP User-Agent 위조를 조율해 여러 보고 채널이 일관되게 유지되도록 합니다. 설정 기반 신원 프로파일, 트래픽 및 리스크 원격 측정 관찰 모드, 검증 스크립트, 탐지 표면과 데이터 노출에 대한 상세 감사가 포함됩니다. 모바일 클라이언트 방변조, root 및 Xposed 탐지, Android 다채널 기기 지문 연구에 종사하는 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
