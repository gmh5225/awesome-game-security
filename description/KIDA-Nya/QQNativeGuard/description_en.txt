QQ Native Guard is an Android LSPosed module that extends a Java-layer QQ detection bypass with native hooks aimed at Tencent QQ’s environment and device-integrity checks. It is built with Gradle, Java/Kotlin on the app side and C++ (NDK) using ByteHook inline hooks across libc and QQ-specific libraries such as fekit, MSF, and Turing, plus coordinated spoofing of system properties, proc and sysfs reads, identifiers, and HTTP user-agent strings so multiple reporting channels stay consistent. The project includes configuration-driven identity profiles, observation modes for traffic and risk telemetry, verification scripts, and detailed audits of detection surfaces and data exposure. It targets security researchers and reverse engineers studying mobile client anti-tamper, root and Xposed detection, and multi-channel device fingerprinting on Android.
