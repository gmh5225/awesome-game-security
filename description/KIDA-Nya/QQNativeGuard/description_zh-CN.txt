QQ Native Guard 是一款 Android LSPosed 模块，在 Java 层 QQ 检测绕过之上，通过原生 Hook 针对腾讯 QQ 的环境与设备完整性校验。项目采用 Gradle 构建，应用侧为 Java/Kotlin，原生侧为 C++（NDK），借助 ByteHook 内联 Hook 覆盖 libc 及 fekit、MSF、Turing 等 QQ 相关库，并协同伪造系统属性、proc/sysfs 读取、标识符与 HTTP User-Agent，使多条上报链路保持一致。工程提供可配置的身份档案、流量与风控遥测的观察模式、校验脚本，以及对检测面与数据暴露的详细审计。面向研究移动端客户端防篡改、Root 与 Xposed 检测及 Android 多渠道设备指纹的安全研究人员与逆向工程师。
