QQ Native Guard は Android 向け LSPosed モジュールで、Java 層の QQ 検知バイパスを拡張し、Tencent QQ の環境検査とデバイス整合性チェックを対象としたネイティブフックを提供します。Gradle でビルドし、アプリ側は Java/Kotlin、ネイティブ側は C++（NDK）で、ByteHook によるインラインフックで libc や fekit、MSF、Turing など QQ 関連ライブラリを横断し、システムプロパティ、proc/sysfs 読み取り、識別子、HTTP ユーザーエージェントの偽装を連携させ、複数の報告経路の一貫性を保ちます。設定駆動の ID プロファイル、トラフィックとリスクテレメトリの観察モード、検証スクリプト、検知面とデータ露出の詳細監査を含みます。モバイルクライアントの改ざん対策、root および Xposed 検知、Android におけるマルチチャネル端末フィンガープリンティングを研究するセキュリティ研究者とリバースエンジニア向けです。
