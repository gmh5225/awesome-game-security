QQ Native Guard 是一款 Android LSPosed 模組，在 Java 層 QQ 偵測繞過之上，透過原生 Hook 針對騰訊 QQ 的環境與裝置完整性檢查。專案以 Gradle 建置，應用端為 Java/Kotlin，原生端為 C++（NDK），使用 ByteHook 內聯 Hook 涵蓋 libc 以及 fekit、MSF、Turing 等 QQ 相關函式庫，並協同偽造系統屬性、proc/sysfs 讀取、識別碼與 HTTP User-Agent，使多條回報管道保持一致。專案提供可設定的身分設定檔、流量與風控遙測的觀察模式、驗證腳本，以及對偵測面與資料暴露的詳細稽核。面向研究行動端用戶端防竄改、Root 與 Xposed 偵測及 Android 多渠道裝置指紋的安全研究人員與逆向工程師。
