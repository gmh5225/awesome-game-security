QQ Native Guard es un módulo LSPosed para Android que extiende un bypass de detección de QQ en la capa Java con hooks nativos orientados a las comprobaciones de entorno e integridad del dispositivo de Tencent QQ. Se compila con Gradle, Java/Kotlin en la aplicación y C++ (NDK) con hooks inline de ByteHook sobre libc y bibliotecas específicas de QQ como fekit, MSF y Turing, además de suplantación coordinada de propiedades del sistema, lecturas de proc y sysfs, identificadores y cadenas user-agent HTTP para mantener coherentes varios canales de informe. El proyecto incluye perfiles de identidad basados en configuración, modos de observación para tráfico y telemetría de riesgo, scripts de verificación y auditorías detalladas de superficies de detección y exposición de datos. Está dirigido a investigadores de seguridad e ingenieros inversos que estudian anti-manipulación en clientes móviles, detección de root y Xposed, y huella digital multi-canal en Android.
