QQ Native Guard — модуль LSPosed для Android, который дополняет обход обнаружения QQ на уровне Java нативными хуками, нацеленными на проверки окружения и целостности устройства в Tencent QQ. Собирается Gradle, на стороне приложения Java/Kotlin, нативно — C++ (NDK) с инлайн-хуками ByteHook в libc и библиотеках QQ, таких как fekit, MSF и Turing, плюс согласованная подмена системных свойств, чтений proc и sysfs, идентификаторов и строк HTTP User-Agent, чтобы несколько каналов отчётности оставались согласованными. В проекте есть профили личности по конфигурации, режимы наблюдения за трафиком и телеметрией рисков, скрипты проверки и подробный аудит поверхностей обнаружения и утечки данных. Ориентирован на исследователей безопасности и реверс-инженеров, изучающих антивзлом клиентов на мобильных платформах, обнаружение root и Xposed и мультиканальное снятие отпечатков устройства на Android.
