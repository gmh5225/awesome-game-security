Quen is a Model Context Protocol server and command-line tool that lets coding agents control a single live game session for mod development, testing, and troubleshooting. It is implemented mainly in Rust, with a Witcher 3 game-side package in C++ and WitcherScript that bridges the running title to the host. The tool can launch the game with temporary settings and mod parking, load saves, capture screenshots, run PresentMon A/B performance measurements, and persist sessions, captures, and evidence in a local SQLite ledger while restoring the game folder on every exit path. It integrates with MCP clients such as Claude Code, VS Code, and Cursor, and can work alongside profiling and graphics tooling including Tracy, Nsight, RenderDoc, and ReShade. Its primary audience is Witcher 3 mod authors and researchers who want repeatable, agent-driven in-game workflows rather than manual click-through testing.
