Quen è un server Model Context Protocol e uno strumento da riga di comando che consente agli agenti di coding di controllare una singola sessione di gioco live per lo sviluppo di mod, i test e la risoluzione dei problemi. È implementato principalmente in Rust, con un pacchetto lato gioco per The Witcher 3 in C++ e WitcherScript che collega il titolo in esecuzione all’host. Lo strumento può avviare il gioco con impostazioni temporanee e parcheggio delle mod, caricare salvataggi, catturare screenshot, eseguire misurazioni delle prestazioni A/B con PresentMon e persistere sessioni, catture e prove in un registro SQLite locale ripristinando la cartella di gioco a ogni uscita. Si integra con client MCP come Claude Code, VS Code e Cursor e può essere usato insieme a strumenti di profiling e grafica tra cui Tracy, Nsight, RenderDoc e ReShade. Il pubblico principale sono autori di mod e ricercatori di The Witcher 3 che vogliono flussi di lavoro in-game ripetibili guidati da agenti invece di test manuali click-by-click.
