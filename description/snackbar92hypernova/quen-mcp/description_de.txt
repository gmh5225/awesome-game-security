Quen ist ein Model Context Protocol-Server und Kommandozeilenwerkzeug, mit dem Coding-Agenten eine einzelne Live-Spielsitzung für Mod-Entwicklung, Tests und Fehlerbehebung steuern können. Es ist überwiegend in Rust implementiert, mit einem Witcher-3-Spielseiten-Paket in C++ und WitcherScript, das das laufende Spiel mit dem Host verbindet. Das Werkzeug kann das Spiel mit temporären Einstellungen und Mod-Parken starten, Saves laden, Screenshots erfassen, PresentMon-A/B-Leistungsmessungen ausführen und Sitzungen, Aufnahmen und Belege in einem lokalen SQLite-Ledger speichern, während der Spieleordner bei jedem Beenden wiederhergestellt wird. Es lässt sich in MCP-Clients wie Claude Code, VS Code und Cursor einbinden und kann neben Profiling- und Grafik-Tools wie Tracy, Nsight, RenderDoc und ReShade eingesetzt werden. Die Zielgruppe sind vor allem Witcher-3-Mod-Autoren und Forscher, die wiederholbare, agentengesteuerte In-Game-Workflows statt manueller Klick-Tests wünschen.
