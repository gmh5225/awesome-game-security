Quen 是一个 Model Context Protocol 服务器与命令行工具，让编程智能体在单个实时游戏会话中完成模组开发、测试与排错。实现以 Rust 为主，并包含用 C++ 与 WitcherScript 编写的《巫师 3》游戏侧包，将运行中的游戏与主机桥接。该工具可启动游戏并应用临时设置与模组暂存、加载存档、截屏、运行 PresentMon A/B 性能测量，并在每次退出时恢复游戏目录的同时，将会话、截图与证据持久化到本地 SQLite 账本。可与 Claude Code、VS Code、Cursor 等 MCP 客户端集成，并与 Tracy、Nsight、RenderDoc、ReShade 等分析与图形工具配合使用。主要面向希望用可重复、由智能体驱动的游戏内工作流替代手动点测的《巫师 3》模组作者与研究人员。
