Quen は Model Context Protocol サーバーおよびコマンドラインツールで、コーディングエージェントが単一のライブゲームセッションを制御し、MOD 開発・テスト・トラブルシューティングを行えるようにします。主に Rust で実装され、C++ と WitcherScript による Witcher 3 ゲーム側パッケージが実行中のタイトルとホストを橋渡しします。一時設定と MOD の退避付きでゲームを起動し、セーブを読み込み、スクリーンショットを取得し、PresentMon による A/B 性能計測を実行し、あらゆる終了経路でゲームフォルダを復元しつつ、セッション・キャプチャ・証拠をローカルの SQLite 台帳に永続化します。Claude Code、VS Code、Cursor などの MCP クライアントと統合でき、Tracy、Nsight、RenderDoc、ReShade などのプロファイリング・グラフィックスツールとも併用できます。主な利用者は、手動のクリック操作テストの代わりに再現可能なエージェント駆動のゲーム内ワークフローを求める Witcher 3 MOD 作者と研究者です。
