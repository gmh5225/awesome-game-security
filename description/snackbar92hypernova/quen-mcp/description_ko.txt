Quen은 Model Context Protocol 서버 및 명령줄 도구로, 코딩 에이전트가 단일 라이브 게임 세션을 제어해 모드 개발, 테스트, 문제 해결을 할 수 있게 합니다. 주로 Rust로 구현되며, C++와 WitcherScript로 작성된 Witcher 3 게임 측 패키지가 실행 중인 타이틀과 호스트를 연결합니다. 이 도구는 임시 설정과 모드 보관과 함께 게임을 실행하고, 세이브를 불러오며, 스크린샷을 캡처하고, PresentMon A/B 성능 측정을 실행하며, 모든 종료 경로에서 게임 폴더를 복원하면서 세션, 캡처, 증거를 로컬 SQLite 원장에 영구 저장합니다. Claude Code, VS Code, Cursor 같은 MCP 클라이언트와 통합되며 Tracy, Nsight, RenderDoc, ReShade 등 프로파일링 및 그래픽 도구와 함께 사용할 수 있습니다. 주요 대상은 수동 클릭 테스트 대신 반복 가능한 에이전트 주도 인게임 워크플로를 원하는 Witcher 3 모드 제작자와 연구자입니다.
