Quen — сервер Model Context Protocol и инструмент командной строки, позволяющий coding-агентам управлять одной живой игровой сессией для разработки модов, тестирования и устранения неполадок. Реализован в основном на Rust, с игровым пакетом для The Witcher 3 на C++ и WitcherScript, который связывает запущенную игру с хостом. Инструмент может запускать игру с временными настройками и «парковкой» модов, загружать сохранения, делать скриншоты, выполнять A/B-замеры производительности PresentMon и сохранять сессии, снимки и доказательства в локальной SQLite-ledger, восстанавливая папку игры при любом выходе. Интегрируется с MCP-клиентами, такими как Claude Code, VS Code и Cursor, и может работать вместе с профилировщиками и графическими инструментами, включая Tracy, Nsight, RenderDoc и ReShade. Основная аудитория — авторы модов и исследователи The Witcher 3, которым нужны воспроизводимые игровые сценарии под управлением агента вместо ручного тестирования кликами.
