Quen 是一個 Model Context Protocol 伺服器與命令列工具，讓程式設計代理在單一即時遊戲工作階段中進行模組開發、測試與疑難排解。實作以 Rust 為主，並包含以 C++ 與 WitcherScript 撰寫的《巫師 3》遊戲端套件，將執行中的遊戲與主機橋接。此工具可啟動遊戲並套用暫時設定與模組暫存、載入存檔、擷取螢幕截圖、執行 PresentMon A/B 效能測量，並在每次結束時還原遊戲目錄，同時將工作階段、擷取內容與證據持久化至本機 SQLite 帳本。可與 Claude Code、VS Code、Cursor 等 MCP 用戶端整合，並可與 Tracy、Nsight、RenderDoc、ReShade 等分析與繪圖工具並用。主要對象是希望以可重複、由代理驅動的遊戲內工作流程取代手動點擊測試的《巫師 3》模組作者與研究人員。
