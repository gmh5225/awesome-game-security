Wiz3D 是一套 Windows 立體 3D 驅動堆疊，透過封裝與攔截遊戲圖形 API，使基於 DirectX、OpenGL 與 Vulkan 的平面遊戲能為 3D 顯示器與眼鏡分別渲染左右眼視圖。程式碼庫主要以 C++ 撰寫，並配有 C# 控制中心，提供廠商代理 DLL、虛表掛鉤，以及從 D3D9 到 D3D12 與 DXGI 的完整封裝層，還包含著色器分析、修補與大量依遊戲劃分的設定功能。它整合 NVIDIA 3D Vision 式直連模式、iZ3D 快門硬體與 AMD HD3D 相關代理，並附診斷、安裝元件與自動化測試套件。此專案適合研究真實場景下圖形掛鉤、交換鏈與裝置代理以及著色器級攔截的開發者——這些正是遊戲安全、反作弊與逆向工程工作中常需偵測或加固的層面。
