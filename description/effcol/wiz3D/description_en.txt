Wiz3D is a Windows stereoscopic 3D driver stack that wraps and intercepts game graphics APIs so flat DirectX, OpenGL, and Vulkan titles can render separate left- and right-eye views for 3D displays and glasses. The codebase is built mainly in C++ with a C# control center, and it ships vendor proxy DLLs, vtable hooks, and extensive D3D9 through D3D12 and DXGI wrapper layers alongside shader analysis, patching, and many per-game profile features. It integrates NVIDIA 3D Vision-style direct mode, iZ3D shutter hardware, and AMD HD3D-related proxies, plus diagnostics, installer components, and automated test packs. The project suits developers studying real-world graphics hooking, swap-chain and device proxying, and shader-level interception—the same surfaces that game security, anti-cheat, and reverse-engineering work often has to detect or harden against.
