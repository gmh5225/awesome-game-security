Wiz3D は Windows 向けのステレオ 3D ドライバスタックで、ゲームのグラフィックス API をラップして傍受し、DirectX・OpenGL・Vulkan のフラットなタイトルが 3D ディスプレイやメガネ向けに左右それぞれの視点を描画できるようにします。コードベースは主に C++ で、C# のコントロールセンター付きで、ベンダープロキシ DLL、vtable フック、D3D9 から D3D12 および DXGI までの広範なラッパー層に加え、シェーダ解析・パッチ、ゲーム別プロファイル機能を多数同梱します。NVIDIA 3D Vision 風のダイレクトモード、iZ3D シャッター機器、AMD HD3D 関連プロキシを統合し、診断、インストーラー、自動テストパックも含みます。実運用のグラフィックスフック、スワップチェーンとデバイスプロキシ、シェーダレベルの傍受を学ぶ開発者向けで、ゲームセキュリティ、反チート、リバースエンジニアリングで検知や硬化の対象となりがちな領域と同じです。
