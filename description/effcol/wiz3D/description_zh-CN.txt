Wiz3D 是一套 Windows 立体 3D 驱动栈，通过封装与拦截游戏图形 API，使基于 DirectX、OpenGL 和 Vulkan 的平面游戏能为 3D 显示器与眼镜分别渲染左右眼视图。代码库主要用 C++ 编写，并配有 C# 控制中心，提供厂商代理 DLL、虚表钩子，以及从 D3D9 到 D3D12 与 DXGI 的完整封装层，还包含着色器分析、补丁及大量按游戏划分的配置功能。它集成 NVIDIA 3D Vision 式直连模式、iZ3D 快门硬件与 AMD HD3D 相关代理，并附带诊断、安装组件与自动化测试包。该项目适合研究真实场景下的图形钩子、交换链与设备代理以及着色器级拦截的开发者——这些正是游戏安全、反作弊与逆向工程工作中常需检测或加固的层面。
