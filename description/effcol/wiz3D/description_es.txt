Wiz3D es una pila de controladores estereoscópicos 3D para Windows que envuelve e intercepta las API gráficas de juegos para que títulos planos en DirectX, OpenGL y Vulkan puedan renderizar vistas separadas para ojo izquierdo y derecho en pantallas 3D y gafas. La base de código está construida principalmente en C++ con un centro de control en C#, e incluye DLL proxy de fabricantes, hooks de vtable y amplias capas envolventes desde D3D9 hasta D3D12 y DXGI, junto con análisis y parches de shaders y muchas funciones de perfiles por juego. Integra modo directo al estilo NVIDIA 3D Vision, hardware de obturador iZ3D y proxies relacionados con AMD HD3D, además de diagnósticos, componentes de instalación y paquetes de pruebas automatizadas. El proyecto conviene a desarrolladores que estudian el hooking gráfico en entornos reales, el proxy de swap chain y dispositivo y la interceptación a nivel de shader — las mismas superficies que la seguridad de juegos, el anti-cheat y la ingeniería inversa suelen tener que detectar o endurecer.
