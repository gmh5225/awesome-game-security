molt-DEX は、通常の APK から高度に難読化されたビルドまで、Android アプリのリバースエンジニアリング、Mod、セキュリティ評価向けの段階的で証拠優先の Claude スキルおよびドキュメントパイプラインです。取得と apktool による smali デコードから静的マッピング、シークレットスイープ、adb・scrcpy・DexKit によるランタイム解決、Xposed API と LSPosed・LSPatch・Frida によるフックを用いたオンデバイス確認まで、アーティファクトを順にたどります。中核手法は、難読化された名前ではなく安定した文字列、メソッド形状、クラス関係でコードを特定することで、文字列インデックス、マニフェスト要約、デバイスワークフロー用の Shell および Python ヘルパースクリプトを備えます。参考資料には認可境界、R8 からパッカー・アンチタンパーまでの難読化ラダー、検証済み所見のレポートテンプレートが含まれます。許可された Android リバースエンジニアリング、脆弱性評価、名称・文字列難読化に耐える Mod 開発を行う実務者向けです。
