molt-DEX 是一套分階段、以證據為先的 Claude 技能與文件管線，用於從一般 APK 到重度混淆建置的 Android 應用程式之逆向工程、Mod 與安全評估。它引導工件從取得與以 apktool 為基礎的 smali 解碼，經靜態對應、機密掃描，到可選的以 adb、scrcpy、DexKit 執行時期解析，以及透過 Xposed API 搭配 LSPosed、LSPatch 或 Frida 的 Hook 進行裝置端確認。核心作法是透過穩定字串、方法形狀與類別關係解析程式碼，而非混淆後的名稱，並提供用於字串索引、資訊清單摘要與裝置工作流程的 Shell 與 Python 輔助腳本。支援參考涵蓋授權邊界、從 R8 到加殼與防竄改的混淆階梯，以及已驗證發現的報告範本。面向從事授權 Android 逆向、弱點評估，以及對抗名稱與字串混淆之 resilient modding 的實務者。
