molt-DEX is a staged, evidence-first Claude skill and documentation pipeline for reverse-engineering, modding, and security assessment of Android applications from plain APKs through heavily obfuscated builds. It walks artifacts from acquisition and apktool-based smali decoding through static mapping, secrets sweeps, and optional on-device confirmation using adb, scrcpy, DexKit runtime resolution, and hooking via the Xposed API with LSPosed, LSPatch, or Frida. A core technique is resolving code by stable strings, method shape, and class relationships rather than obfuscated names, with helper shell and Python scripts for string indexing, manifest summaries, and device workflows. Supporting references cover authorization boundaries, an obfuscation ladder from R8 through packers and anti-tamper, and report templates for verified findings. It targets practitioners doing authorized Android reverse engineering, vulnerability assessment, and resilient modding against name and string obfuscation.
