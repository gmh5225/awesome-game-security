molt-DEX 是一套分阶段、以证据为先的 Claude 技能与文档流水线，用于从普通 APK 到重度混淆构建的 Android 应用的逆向工程、Mod 与安全评估。它引导工件从获取与基于 apktool 的 smali 解码，经静态映射、密钥扫描，到可选的 adb、scrcpy、DexKit 运行时解析以及通过 Xposed API 配合 LSPosed、LSPatch 或 Frida 的 Hook 进行设备端确认。核心思路是通过稳定字符串、方法形态与类关系定位代码，而非依赖混淆后的名称，并提供用于字符串索引、清单摘要与设备工作流的 Shell 与 Python 辅助脚本。配套参考涵盖授权边界、从 R8 到加壳与防篡改的混淆阶梯，以及已验证发现的报告模板。面向从事授权 Android 逆向、漏洞评估，以及对抗名称与字符串混淆的 resilient modding 的从业者。
