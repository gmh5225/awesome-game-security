NZeyMod Manager 是一款轻量级 Android 配套启动器，用于在 NZey Master（基于 Virtual Master 重打包、运行 Android 11 并采用 Pixel 5 设备配置的环境）中准备、校验并导入 NZeyMod 自定义 ROM。应用完全使用 Java 编写、不依赖 Gradle，通过手动 Android SDK 构建流程编译，并附带基于 HTML 与服务 worker 的 Web 原型。核心功能包括对完整或分片 ROM 镜像的 SHA-256 校验、合并多部分压缩包、生成并持久化带 Luhn 合法 IMEI 的伪造设备身份、按配置切换 Magisk 相关模块，以及管理用于 Play Integrity 流程的 keybox。面向在已 root 或搭载 Magisk 的虚拟 Android 实例上进行完整性绕过测试、Mod 及相关移动安全实验的研究者与进阶用户，而非独立模拟器或虚拟机管理程序。
