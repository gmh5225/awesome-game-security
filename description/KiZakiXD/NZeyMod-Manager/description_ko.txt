NZeyMod Manager는 NZey Master(Virtual Master를 재패키징하여 Android 11과 Pixel 5 기기 프로필로 실행하는 환경)에 NZeyMod 커스텀 ROM을 준비·검증·가져오는 경량 Android 동반 런처입니다. 앱은 Gradle 없이 Java로만 작성되었으며, 수동 Android SDK 파이프라인으로 빌드되고 HTML과 서비스 워커를 사용하는 웹 프로토타입도 포함합니다. 핵심 기능으로는 전체 또는 분할 ROM 이미지의 SHA-256 검증, 다중 파트 아카이브 병합, Luhn 유효 IMEI가 포함된 위조 기기 신원 생성·저장, 프로필별 Magisk 관련 모듈 토글, Play Integrity 워크플로용 keybox 관리가 있습니다. 단독 에뮬레이터나 하이퍼바이저가 아니라, 루팅 또는 Magisk가 적용된 가상 Android 인스턴스에서 무결성 우회 테스트, 모딩 및 관련 모바일 보안 실험을 수행하는 연구자와 고급 사용자를 대상으로 합니다.
