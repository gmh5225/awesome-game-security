이 프로젝트는 AssaultCube 1.3.0.2에서 ESP(초감각 지각) 오버레이를 그리는, 주입 가능한 DLL로 컴파일된 Rust 라이브러리입니다. 32비트 클라이언트의 엔티티 목록, 체력, 뷰 행렬을 프로세스 내 고정 메모리 오프셋에서 읽고, 머리와 발 위치를 화면 좌표로 투영한 뒤 게임과 정렬된 Direct2D 오버레이 창으로 바운딩 박스를 렌더링합니다. 코드베이스는 Win32 API에 Rust windows crate를 사용하며, i686 Windows 대상 cdylib로 빌드되고, 실제 주입과 분리된 오버레이 단위 테스트를 포함합니다. 외부 메모리 읽기, 월드-투-스크린 변환, 경량 FPS 클라이언트의 투명 오버레이 기법을 연구하는 리버스 엔지니어 및 게임 보안 연구자를 대상으로 합니다.
