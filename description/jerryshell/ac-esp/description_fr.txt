Ce projet est une bibliothèque Rust compilée en DLL injectable qui affiche une surcouche ESP (extra-sensory perception) sur AssaultCube version 1.3.0.2. Il lit la liste d’entités, la santé et la matrice de vue du client 32 bits à partir d’offsets mémoire fixes en processus, projette les positions tête et pieds en coordonnées écran et dessine des boîtes englobantes via une fenêtre de surcouche Direct2D alignée sur le jeu. Le code s’appuie sur la crate windows de Rust pour les API Win32, est livré en cdylib pour cibles Windows i686, et inclut des tests unitaires de la surcouche distincts de l’injection en direct. Il s’adresse aux ingénieurs reverse et chercheurs en sécurité jeu étudiant les lectures mémoire externes, le passage monde-écran et les techniques de surcouche transparente sur un client FPS léger.
