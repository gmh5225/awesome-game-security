Este proyecto es una biblioteca en Rust compilada como DLL inyectable que dibuja una superposición ESP (percepción extrasensorial) sobre AssaultCube versión 1.3.0.2. Lee la lista de entidades, la salud y la matriz de vista del cliente de 32 bits desde desplazamientos de memoria fijos en el proceso, proyecta las posiciones de cabeza y pies a coordenadas de pantalla y renderiza cajas delimitadoras mediante una ventana de superposición Direct2D alineada con el juego. El código usa la crate windows de Rust para las API Win32, se distribuye como cdylib compilada para objetivos Windows i686 e incluye pruebas unitarias del overlay separadas de la inyección en vivo. Está dirigido a ingenieros inversos e investigadores de seguridad en juegos que estudian lecturas de memoria externa, matemáticas mundo-a-pantalla y técnicas de superposición transparente en un cliente FPS ligero.
