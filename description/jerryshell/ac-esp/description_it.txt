Questo progetto è una libreria Rust compilata come DLL iniettabile che disegna un overlay ESP (extra-sensory perception) su AssaultCube versione 1.3.0.2. Legge l’elenco entità, la salute e la matrice di vista del client a 32 bit da offset di memoria fissi in-processo, proietta le posizioni di testa e piedi in coordinate schermo e renderizza riquadri di delimitazione tramite una finestra overlay Direct2D allineata al gioco. Il codice usa la crate windows di Rust per le API Win32, viene distribuito come cdylib per target Windows i686 e include test unitari dell’overlay separati dall’injection live. È pensato per reverse engineer e ricercatori di game security che studiano letture di memoria esterna, matematica world-to-screen e tecniche di overlay trasparente in un client FPS leggero.
