本專案是一個編譯為可注入 DLL 的 Rust 函式庫，在 AssaultCube 1.3.0.2 上繪製 ESP（透視）疊加層。它從行程內固定記憶體偏移讀取 32 位元用戶端的實體清單、生命值與檢視矩陣，將頭部與腳部位置投影到螢幕座標，並透過與遊戲對齊的 Direct2D 疊加視窗渲染邊界框。程式碼使用 Rust 的 windows crate 呼叫 Win32 API，以面向 i686 Windows 目標的 cdylib 形式建置，並包含與實機注入分離的疊加層單元測試。面向研究外部記憶體讀取、世界座標到螢幕座標變換以及透明疊加技術的逆向工程師與遊戲安全研究人員，範例為輕量級 FPS 用戶端。
