Этот проект — библиотека на Rust, собранная как инжектируемая DLL, которая рисует ESP-оверлей (extra-sensory perception) в AssaultCube версии 1.3.0.2. Она читает список сущностей, здоровье и матрицу вида 32-битного клиента по фиксированным смещениям в памяти процесса, проецирует позиции головы и ног в экранные координаты и отрисовывает ограничивающие рамки через оконный оверлей Direct2D, выровненный с игрой. Код использует crate windows для Win32 API, поставляется как cdylib под цели i686 Windows и включает модульные тесты оверлея отдельно от живой инъекции. Предназначен для reverse-инженеров и исследователей игровой безопасности, изучающих чтение внешней памяти, преобразование world-to-screen и прозрачные оверлеи в лёгком FPS-клиенте.
