本プロジェクトは、AssaultCube 1.3.0.2 上に ESP（エクストラセンサリー知覚）オーバーレイを描画する、注入可能な DLL としてコンパイルされた Rust ライブラリです。32 ビットクライアントのエンティティリスト、体力、ビュー行列をプロセス内の固定メモリオフセットから読み取り、頭部と足部の位置をスクリーン座標へ投影し、ゲームに合わせた Direct2D オーバーレイウィンドウ経由でバウンディングボックスを描画します。コードベースは Win32 API に Rust の windows crate を用い、i686 Windows ターゲット向け cdylib としてビルドし、ライブ注入とは切り離したオーバーレイのユニットテストを含みます。外部メモリ読み取り、ワールドからスクリーンへの座標変換、軽量 FPS クライアントにおける透明オーバーレイ手法を学ぶリバースエンジニアおよびゲームセキュリティ研究者向けです。
