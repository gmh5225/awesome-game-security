This project is a Rust library compiled as an injectable DLL that draws an ESP (extra-sensory perception) overlay on AssaultCube version 1.3.0.2. It reads the 32-bit client’s entity list, health, and view matrix from fixed in-process memory offsets, projects head and foot positions to screen coordinates, and renders bounding boxes through a Direct2D overlay window aligned with the game. The codebase uses the Rust windows crate for Win32 APIs, ships as a cdylib built for i686 Windows targets, and includes overlay unit tests separate from live injection. It is aimed at reverse engineers and game-security researchers studying external-memory reads, world-to-screen math, and transparent overlay techniques in a lightweight FPS client.
