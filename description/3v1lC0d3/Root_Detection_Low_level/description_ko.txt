이 프로젝트는 Android 애플리케이션을 위한 Frida 기반 동적 분석 스크립트로, 런타임에 의심스러운 파일 시스템 활동과 시스템 명령 실행을 모니터링합니다. java.io.File과 java.lang.Runtime.exec()를 후킹하여 su, bin, apk와 같은 키워드를 포함하는 경로를 탐지하고, runtime shell을 통해 실행된 명령을 기록합니다. 의심스러운 파일 작업이 발생하면 스크립트는 Java 스택 트레이스를 캡처하여 어떤 코드가 해당 동작을 트리거했는지 추적하는 데 도움을 줍니다. JavaScript로 작성된 Frida 스크립트로, Android 보안 테스트, 멀웨어 분석, 리버스 엔지니어링, 앱이 root 탐지 및 기타 저수준 런타임 검사를 수행하는 방식을 조사하는 데 목적이 있습니다.
