Dieses Projekt ist ein Frida-basiertes Skript zur dynamischen Analyse von Android-Anwendungen, das verdächtige Dateisystemaktivitäten und die Ausführung von Systembefehlen zur Laufzeit überwacht. Es hookt java.io.File und java.lang.Runtime.exec(), um Pfade zu erkennen, die Schlüsselwörter wie su, bin und apk enthalten, und protokolliert über die Runtime-Shell ausgeführte Befehle. Bei verdächtigen Dateioperationen erfasst das Skript Java-Stack-Traces, um nachzuverfolgen, welcher Code das Verhalten ausgelöst hat. Als in JavaScript geschriebenes Frida-Skript richtet es sich an Android-Sicherheitstests, Malware-Analyse, Reverse Engineering und die Untersuchung, wie Apps Root-Erkennung und andere Low-Level-Laufzeitprüfungen durchführen.
