Этот проект представляет собой скрипт динамического анализа на основе Frida для Android-приложений, который отслеживает подозрительную активность файловой системы и выполнение системных команд во время работы. Он перехватывает java.io.File и java.lang.Runtime.exec() для обнаружения путей, содержащих ключевые слова, такие как su, bin и apk, а также для регистрации команд, выполняемых через runtime shell. При подозрительных операциях с файлами скрипт захватывает Java stack trace, чтобы помочь определить, какой код вызвал такое поведение. Написанный как Frida-скрипт на JavaScript, он предназначен для тестирования безопасности Android, анализа malware, reverse engineering и исследования того, как приложения выполняют обнаружение root и другие низкоуровневые проверки во время выполнения.
