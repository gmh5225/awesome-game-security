Questo progetto è uno script di analisi dinamica basato su Frida per applicazioni Android che monitora l'attività sospetta del filesystem e l'esecuzione di comandi di sistema a runtime. Intercetta java.io.File e java.lang.Runtime.exec() per rilevare percorsi contenenti parole chiave come su, bin e apk, e per registrare i comandi eseguiti tramite la shell runtime. Quando si verificano operazioni su file sospette, lo script cattura stack trace Java per aiutare a tracciare quale codice ha innescato il comportamento. Scritto come script Frida in JavaScript, è rivolto ai test di sicurezza Android, all'analisi di malware, al reverse engineering e all'indagine su come le app eseguono il rilevamento di root e altri controlli runtime di basso livello.
