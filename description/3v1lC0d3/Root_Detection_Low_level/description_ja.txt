本プロジェクトは、Android アプリケーション向けの Frida ベースの動的解析スクリプトであり、実行時に疑わしいファイルシステム操作やシステムコマンドの実行を監視します。java.io.File と java.lang.Runtime.exec() をフックし、su、bin、apk などのキーワードを含むパスを検出するとともに、runtime shell 経由で実行されたコマンドを記録します。疑わしいファイル操作が発生した場合、スクリプトは Java スタックトレースを取得し、どのコードがその動作をトリガーしたかを追跡するのに役立てます。JavaScript で書かれた Frida スクリプトとして実装されており、Android セキュリティテスト、マルウェア解析、リバースエンジニアリング、アプリが root 検出やその他の低レベル実行時チェックをどのように行うかの調査を目的としています。
