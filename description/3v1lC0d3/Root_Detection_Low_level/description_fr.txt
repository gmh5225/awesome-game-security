Ce projet est un script d'analyse dynamique basé sur Frida pour les applications Android, qui surveille l'activité suspecte du système de fichiers et l'exécution de commandes système à l'exécution. Il accroche java.io.File et java.lang.Runtime.exec() pour détecter les chemins contenant des mots-clés tels que su, bin et apk, et pour journaliser les commandes exécutées via le shell runtime. Lorsque des opérations de fichiers suspectes se produisent, le script capture les traces de pile Java afin d'aider à retracer le code à l'origine du comportement. Écrit sous forme de script Frida en JavaScript, il est destiné aux tests de sécurité Android, à l'analyse de malware, à l'ingénierie inverse et à l'étude de la façon dont les applications effectuent la détection de root et d'autres vérifications runtime de bas niveau.
