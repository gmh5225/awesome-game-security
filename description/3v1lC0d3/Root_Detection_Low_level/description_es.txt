Este proyecto es un script de análisis dinámico basado en Frida para aplicaciones Android que monitoriza la actividad sospechosa del sistema de archivos y la ejecución de comandos del sistema en tiempo de ejecución. Engancha java.io.File y java.lang.Runtime.exec() para detectar rutas que contienen palabras clave como su, bin y apk, y para registrar los comandos ejecutados a través del shell de runtime. Cuando se producen operaciones de archivos sospechosas, el script captura trazas de pila de Java para ayudar a rastrear qué código desencadenó el comportamiento. Escrito como un script Frida en JavaScript, está orientado a pruebas de seguridad en Android, análisis de malware, ingeniería inversa e investigación de cómo las aplicaciones realizan detección de root y otras comprobaciones de runtime de bajo nivel.
