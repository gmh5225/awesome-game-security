Sky-CotL-Scripts is a curated resource hub for modifying and researching Sky: Children of the Light on Android and PC. It bundles GameGuardian Lua scripts for runtime memory editing (teleports, map coordinates, cosmetics, winged light, game speed, FPS tweaks, and related cheats), plus Canvas mod-loader documentation, native libraries such as libTSM, and helper APKs for app cloning and virtual multi-account spaces. PC utilities include a Frida JavaScript hook for intercepting the game’s HTTP traffic during analysis. The repository also preserves legacy Lua with documented memory offsets and educational notes on server-side outfit validation and mod safety. It targets reverse engineers, security researchers, and advanced players studying client behavior, memory layout, and live-service anti-abuse limits rather than shipping a single standalone application.
