Sky-CotL-Scripts は、Android と PC 向け『Sky: Children of the Light』の改造・調査のためのキュレーション型リソースハブです。実行時メモリ編集用の GameGuardian Lua スクリプト（テレポート、マップ座標、コスメ、光の翼、ゲーム速度、FPS 調整などのチート関連機能）、Canvas モッドローダーのドキュメント、libTSM などのネイティブライブラリ、アプリクローンや仮想マルチアカウント用の補助 APK をまとめています。PC 向けには、解析時にゲームの HTTP 通信を傍受する Frida JavaScript フックも含まれます。リポジトリには、メモリオフセットを文書化したレガシー Lua や、サーバー側アウトフィット検証と mod の安全性に関する解説も残されています。単体アプリの提供ではなく、クライアント挙動、メモリレイアウト、ライブサービスの不正利用対策の限界を学ぶリバースエンジニア、セキュリティ研究者、上級プレイヤーを対象としています。
