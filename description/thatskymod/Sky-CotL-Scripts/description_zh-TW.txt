Sky-CotL-Scripts 是針對 Android 與 PC 平台《光·遇》（Sky: Children of the Light）進行修改與研究整理的資源中心。其中包含用於執行時期記憶體編輯的 GameGuardian Lua 腳本（傳送、地圖座標、外觀、光翼、遊戲速度、幀率調整及相關作弊功能），以及 Canvas 模組載入器文件、libTSM 等原生函式庫，還有用於應用程式克隆與虛擬多帳號環境的輔助 APK。PC 端工具包括用於分析時攔截遊戲 HTTP 流量的 Frida JavaScript 鉤子。儲存庫亦保留附已文件化記憶體偏移的舊版 Lua，以及關於伺服器端裝扮驗證與模組安全性的說明。面向逆向工程師、安全研究人員及希望研究用戶端行為、記憶體配置與線上服務反濫用機制的高階玩家，而非提供單一獨立應用程式。
