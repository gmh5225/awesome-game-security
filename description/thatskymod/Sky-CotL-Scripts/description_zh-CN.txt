Sky-CotL-Scripts 是针对 Android 与 PC 平台《光·遇》（Sky: Children of the Light）进行修改与研究整理的资源中心。其中包含用于运行时内存编辑的 GameGuardian Lua 脚本（传送、地图坐标、外观、光翼、游戏速度、帧率调整及相关作弊功能），以及 Canvas 模组加载器文档、libTSM 等原生库，还有用于应用克隆与虚拟多账号环境的辅助 APK。PC 端工具包括用于分析时拦截游戏 HTTP 流量的 Frida JavaScript 钩子。仓库还保留附带已文档化内存偏移的旧版 Lua，以及关于服务端装扮校验与模组安全性的说明。面向逆向工程师、安全研究人员及希望研究客户端行为、内存布局与在线服务反滥用机制的高级玩家，而非提供单一独立应用。
