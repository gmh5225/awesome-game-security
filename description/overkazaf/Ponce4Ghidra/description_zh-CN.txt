Ponce4Ghidra 是面向 Ghidra 逆向工程平台的交互式符号执行插件，用于找出满足程序路径约束的具体输入值。它将 Java 版 Ghidra 扩展与基于 angr 框架和 Z3 SMT 求解器的 Python 后端配对，通过 JSON/TCP 通信来探索二进制并枚举解。用户可对命令行参数、函数参数、寄存器或内存进行符号化，在反编译器或列表视图中设置 Find 与 Avoid 目标，并求解密码、许可证密钥、flag 或其他秘密，而无需暴力破解。该插件支持 Mach-O、ELF 和 Android 原生库，覆盖 x86-64、ARM、ARM64 和 MIPS，并提供 veritesting、可选的 Unicorn 支持的 concrete execution、约束可视化以及会话保存/恢复等功能。它面向处理 crackme、许可证校验、反作弊检测及其他约束密集型二进制分析任务的逆向工程师与游戏安全分析师。
