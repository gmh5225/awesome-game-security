Ponce4Ghidra는 Ghidra 리버스 엔지니어링 플랫폼용 대화형 심볼릭 실행 플러그인으로, 프로그램 경로 제약을 만족하는 구체적인 입력값을 찾습니다. Java Ghidra 확장과 angr 프레임워크 및 Z3 SMT 솔버 기반 Python 백엔드를 결합하여 JSON/TCP로 통신하며 바이너리를 탐색하고 해를 열거합니다. 사용자는 명령줄 인수, 함수 매개변수, 레지스터, 메모리를 심볼화하고, 디컴파일러나 리스팅에서 Find 및 Avoid 대상을 설정하여 무차별 대입 없이 비밀번호, 라이선스 키, 플래그 또는 기타 비밀값을 구할 수 있습니다. Mach-O, ELF, Android 네이티브 라이브러리를 지원하며 x86-64, ARM, ARM64, MIPS를 다룹니다. veritesting, 선택적 Unicorn 기반 concrete execution, 제약 조건 시각화, 세션 저장/복원 등의 기능을 제공합니다. crackme, 라이선스 검증, 안티치트 검사 및 기타 제약이 많은 바이너리 분석 작업을 수행하는 리버스 엔지니어와 게임 보안 분석가를 대상으로 합니다.
