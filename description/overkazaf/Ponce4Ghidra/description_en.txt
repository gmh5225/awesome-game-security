Ponce4Ghidra is an interactive symbolic execution plugin for the Ghidra reverse engineering platform that finds concrete input values satisfying program path constraints. It pairs a Java Ghidra extension with a Python backend powered by the angr framework and the Z3 SMT solver, communicating over JSON/TCP to explore binaries and enumerate solutions. Users can symbolize command-line arguments, function parameters, registers, or memory, set Find and Avoid targets in the decompiler or listing, and solve for passwords, license keys, flags, or other secrets without brute force. The plugin supports Mach-O, ELF, and Android native libraries across x86-64, ARM, ARM64, and MIPS, with features such as veritesting, optional Unicorn-backed concrete execution, constraint visualization, and session save/restore. It is aimed at reverse engineers and game security analysts tackling crackmes, license validation, anti-cheat checks, and other constraint-heavy binary analysis tasks.
