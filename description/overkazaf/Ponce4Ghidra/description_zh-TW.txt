Ponce4Ghidra 是面向 Ghidra 逆向工程平台的互動式符號執行外掛，用於找出滿足程式路徑約束的具體輸入值。它將 Java 版 Ghidra 擴充功能與基於 angr 框架和 Z3 SMT 求解器的 Python 後端配對，透過 JSON/TCP 通訊來探索二進位檔並列舉解。使用者可對命令列參數、函式參數、暫存器或記憶體進行符號化，在反編譯器或清單檢視中設定 Find 與 Avoid 目標，並求解密碼、授權金鑰、flag 或其他秘密，而無需暴力破解。此外掛支援 Mach-O、ELF 和 Android 原生函式庫，涵蓋 x86-64、ARM、ARM64 和 MIPS，並提供 veritesting、可選的 Unicorn 支援 concrete execution、約束視覺化以及工作階段儲存/還原等功能。它面向處理 crackme、授權驗證、反作弊檢查及其他約束密集型二進位分析任務的逆向工程師與遊戲安全分析師。
