VulnHunter4Ghidra 是 Ghidra 擴充功能與配套工具，透過對 ELF、PE 與 Mach-O 二進位檔執行 source-to-sink 污點分析，在原生可執行檔中找出安全缺陷。Java 外掛從 Ghidra 擷取函式中繼資料，經 TCP 與以 angr 與 Z3 為基礎的 Python 分析引擎通訊；該引擎建構控制流程圖、在可設定的呼叫深度上傳播污點，並可符號化檢驗不可信輸入能否抵達危險 API。發現項目附帶 CWE 編號與嚴重程度，涵蓋緩衝區溢位、格式字串、命令注入與 use-after-free 等問題。支援在 Ghidra 內互動審查，或無頭 CLI 工作流程並輸出 JSON 及適於 CI 的結束代碼，有助逆向工程師與安全研究人員稽核原生遊戲客戶端、載入器以及反作弊或 DRM 元件。
