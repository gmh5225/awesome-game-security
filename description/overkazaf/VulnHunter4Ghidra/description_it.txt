VulnHunter4Ghidra è un’estensione per Ghidra e strumenti di supporto per individuare falle di sicurezza negli eseguibili nativi eseguendo analisi di taint source-to-sink su binari ELF, PE e Mach-O. Un plugin Java recupera i metadati delle funzioni da Ghidra e comunica via TCP con un motore di analisi Python basato su angr e Z3, che costruisce grafi del flusso di controllo, propaga il taint con una profondità di chiamate configurabile e può verificare simbolicamente se input non attendibili possono raggiungere API pericolose. I risultati sono etichettati con ID CWE e gravità per problemi come buffer overflow, format string, command injection e use-after-free. Supporta revisione interattiva in Ghidra o workflow CLI headless con output JSON e codici di uscita adatti alla CI, risultando utile per reverse engineer e ricercatori di sicurezza che verificano client di gioco nativi, loader e componenti anti-cheat o DRM.
