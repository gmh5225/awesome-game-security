VulnHunter4Ghidra は、ELF・PE・Mach-O バイナリに対する source-to-sink 汚染解析によりネイティブ実行ファイルのセキュリティ欠陥を見つける Ghidra 拡張および補助ツールです。Java プラグインが Ghidra から関数メタデータを取得し、TCP 経由で angr と Z3 上に構築された Python 解析エンジンと連携します。エンジンは制御フローグラフを構築し、設定可能な呼び出し深度で汚染を伝播し、信頼できない入力が危険な API に到達しうるかを記号的に検証できます。検出結果には CWE ID と重大度が付与され、バッファオーバーフロー、フォーマット文字列、コマンドインジェクション、use-after-free などを扱います。Ghidra 内での対話的レビュー、または JSON 出力と CI 向け終了コードを備えたヘッドレス CLI ワークフローに対応し、ネイティブゲームクライアント、ローダー、反チートや DRM コンポーネントを監査するリバースエンジニアやセキュリティ研究者に有用です。
