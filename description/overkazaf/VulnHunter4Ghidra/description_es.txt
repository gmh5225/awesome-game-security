VulnHunter4Ghidra es una extensión de Ghidra y herramientas complementarias para encontrar fallos de seguridad en ejecutables nativos mediante análisis de contaminación source-to-sink en binarios ELF, PE y Mach-O. Un complemento Java obtiene metadatos de funciones desde Ghidra y se comunica por TCP con un motor de análisis en Python basado en angr y Z3, que construye grafos de flujo de control, propaga la contaminación con una profundidad de llamadas configurable y puede comprobar simbólicamente si una entrada no confiable puede alcanzar APIs peligrosas. Los hallazgos se etiquetan con identificadores CWE y gravedad para problemas como desbordamientos de búfer, cadenas de formato, inyección de comandos y use-after-free. Admite revisión interactiva dentro de Ghidra o flujos CLI sin interfaz con salida JSON y códigos de salida aptos para CI, lo que resulta útil para ingenieros inversos e investigadores de seguridad que auditan clientes de juegos nativos, cargadores y componentes anti-cheat o DRM.
