VulnHunter4Ghidra 是 Ghidra 扩展及配套工具，通过对 ELF、PE 与 Mach-O 二进制执行 source-to-sink 污点分析，在原生可执行文件中发现安全缺陷。Java 插件从 Ghidra 提取函数元数据，经 TCP 与基于 angr 和 Z3 的 Python 分析引擎通信；该引擎构建控制流图、在可配置调用深度上传播污点，并可符号化检验不可信输入能否到达危险 API。发现项附带 CWE 编号与严重程度，涵盖缓冲区溢出、格式串、命令注入与释放后使用等问题。支持在 Ghidra 内交互审查，或无头 CLI 工作流并输出 JSON 及适于 CI 的退出码，便于逆向工程师与安全研究人员审计原生游戏客户端、加载器以及反作弊或 DRM 组件。
