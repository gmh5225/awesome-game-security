VulnHunter4Ghidra is a Ghidra extension and companion tooling for finding security flaws in native executables by performing source-to-sink taint analysis on ELF, PE, and Mach-O binaries. A Java plugin pulls function metadata from Ghidra and talks over TCP to a Python analysis engine built on angr and Z3, which builds control-flow graphs, propagates taint across configurable call depth, and can symbolically check whether untrusted input can reach dangerous APIs. Findings are labeled with CWE IDs and severity for issues such as buffer overflows, format strings, command injection, and use-after-free. It supports interactive review inside Ghidra or headless CLI workflows with JSON output and CI-friendly exit codes, making it useful for reverse engineers and security researchers auditing native game clients, loaders, and anti-cheat or DRM components.
