VulnHunter4Ghidra는 ELF, PE, Mach-O 바이너리에 대한 source-to-sink 오염 분석으로 네이티브 실행 파일의 보안 결함을 찾는 Ghidra 확장 및 보조 도구입니다. Java 플러그인이 Ghidra에서 함수 메타데이터를 가져오고 TCP로 angr과 Z3 기반 Python 분석 엔진과 통신합니다. 엔진은 제어 흐름 그래프를 구축하고 구성 가능한 호출 깊이에서 오염을 전파하며, 신뢰할 수 없는 입력이 위험한 API에 도달할 수 있는지 기호적으로 검사할 수 있습니다. 발견 항목에는 CWE ID와 심각도가 붙으며 버퍼 오버플로, 포맷 문자열, 명령 주입, use-after-free 등을 다룹니다. Ghidra 내 대화형 검토 또는 JSON 출력과 CI 친화적 종료 코드를 갖춘 헤드리스 CLI 워크플로를 지원하여, 네이티브 게임 클라이언트, 로더, 안티치트 또는 DRM 구성 요소를 감사하는 리버스 엔지니어와 보안 연구자에게 유용합니다.
