D810G est un framework complet de désobfuscation pour la plateforme de rétro-ingénierie Ghidra, qui automatise la récupération de code lisible à partir de binaires fortement obfusqués. Il repose sur une architecture hybride Java et Python : un plugin Ghidra assure l'intégration à l'interface et le patch binaire, tandis qu'un moteur Python alimenté par Z3, Unicorn, Capstone et Keystone effectue une analyse approfondie. Les principales fonctionnalités incluent le déaplatissement du flux de contrôle pour OLLVM et Tigress, la simplification MBA avec des règles vérifiées par Z3, la suppression des prédicats opaques et du flux de contrôle factice, l'élimination du code mort, le déchiffrement de chaînes et la dévirtualisation de VM via un pipeline multipasse. Le projet peut s'exécuter en CLI autonome ou comme analyseur Ghidra intégré pour une désobfuscation en un clic. Il s'adresse aux ingénieurs en rétro-ingénierie et aux chercheurs en sécurité qui analysent des logiciels malveillants obfusqués, des protections de jeux et d'autres logiciels protégés.
