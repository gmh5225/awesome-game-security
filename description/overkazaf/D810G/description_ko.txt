D810G는 Ghidra 리버스 엔지니어링 플랫폼을 위한 종합 디난독화 프레임워크로, 강하게 난독화된 바이너리에서 읽기 가능한 코드를 자동으로 복원합니다. Java와 Python 하이브리드 아키텍처를 사용하며, Ghidra 플러그인이 UI 통합과 바이너리 패치를 담당하고 Z3, Unicorn, Capstone, Keystone으로 구동되는 Python 엔진이 심층 분석을 수행합니다. 주요 기능으로는 OLLVM 및 Tigress용 제어 흐름 디플래트화, Z3 검증 규칙을 이용한 MBA 단순화, 불투명 술어 및 가짜 제어 흐름 제거, 데드 코드 제거, 문자열 복호화, 다중 패스 파이프라인을 통한 VM 디가상화가 있습니다. 이 프로젝트는 독립형 CLI로 실행하거나 통합 Ghidra 분석기로 원클릭 디난독화를 수행할 수 있으며, 난독화된 멀웨어, 게임 보호 및 기타 보호된 소프트웨어를 분석하는 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
