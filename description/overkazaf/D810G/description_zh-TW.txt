D810G 是面向 Ghidra 逆向工程平台的綜合去混淆框架，可自動從高度混淆的二進位檔中恢復可讀程式碼。它採用 Java 與 Python 混合架構：Ghidra 外掛提供 UI 整合與二進位修補，而由 Z3、Unicorn、Capstone 和 Keystone 驅動的 Python 引擎執行深度分析。主要功能包括針對 OLLVM 與 Tigress 的控制流去平坦化、以 Z3 驗證規則進行的 MBA 化簡、不透明謂詞與虛假控制流移除、死碼消除、字串解密，以及透過多階段管線實現的虛擬機去虛擬化。此專案可作為獨立 CLI 執行，也可作為整合式 Ghidra 分析器實現一鍵去混淆，供分析混淆惡意軟體、遊戲保護及其他受保護軟體的逆向工程師與安全研究人員使用。
