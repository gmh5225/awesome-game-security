D810G 是面向 Ghidra 逆向工程平台的综合去混淆框架，可自动从重混淆二进制文件中恢复可读代码。它采用 Java 与 Python 混合架构：Ghidra 插件负责 UI 集成与二进制补丁，而由 Z3、Unicorn、Capstone 和 Keystone 驱动的 Python 引擎执行深度分析。主要功能包括针对 OLLVM 与 Tigress 的控制流去平坦化、基于 Z3 验证规则的 MBA 化简、不透明谓词与虚假控制流移除、死代码消除、字符串解密，以及通过多遍流水线实现的虚拟机去虚拟化。该项目可作为独立 CLI 运行，也可作为集成 Ghidra 分析器实现一键去混淆，面向分析混淆恶意软件、游戏保护及其他受保护软件的逆向工程师与安全研究人员。
