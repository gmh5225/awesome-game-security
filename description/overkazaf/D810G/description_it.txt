D810G è un framework completo di deoffuscazione per la piattaforma di reverse engineering Ghidra che automatizza il recupero di codice leggibile da binari fortemente offuscati. Utilizza un'architettura ibrida Java e Python: un plugin Ghidra fornisce integrazione con l'interfaccia e patching binario, mentre un motore Python basato su Z3, Unicorn, Capstone e Keystone esegue analisi approfondite. Le funzionalità principali includono il deflattening del flusso di controllo per OLLVM e Tigress, semplificazione MBA con regole verificate da Z3, rimozione di predicati opachi e flusso di controllo fittizio, eliminazione del codice morto, decifratura delle stringhe e devirtualizzazione VM tramite una pipeline multipassaggio. Il progetto può essere eseguito come CLI autonoma o come analizzatore Ghidra integrato per la deoffuscazione con un clic. È destinato a reverse engineer e ricercatori di sicurezza che analizzano malware offuscati, protezioni di giochi e altro software protetto.
