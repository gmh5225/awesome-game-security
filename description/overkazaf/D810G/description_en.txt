D810G is a comprehensive deobfuscation framework for the Ghidra reverse engineering platform that automates recovery of readable code from heavily obfuscated binaries. It uses a hybrid Java and Python architecture: a Ghidra plugin provides UI integration and binary patching, while a Python engine powered by Z3, Unicorn, Capstone, and Keystone performs deep analysis. Key capabilities include control-flow deflattening for OLLVM and Tigress, MBA simplification with Z3-verified rules, opaque predicate and bogus control-flow removal, dead code elimination, string decryption, and VM devirtualization through a multi-pass pipeline. The project can run as a standalone CLI or as an integrated Ghidra analyzer for one-click deobfuscation. It is intended for reverse engineers and security researchers analyzing obfuscated malware, game protection, and other protected software.
