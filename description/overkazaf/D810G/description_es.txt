D810G es un framework integral de desofuscación para la plataforma de ingeniería inversa Ghidra que automatiza la recuperación de código legible a partir de binarios fuertemente ofuscados. Utiliza una arquitectura híbrida de Java y Python: un complemento de Ghidra proporciona integración con la interfaz y parches binarios, mientras que un motor Python impulsado por Z3, Unicorn, Capstone y Keystone realiza un análisis profundo. Las capacidades clave incluyen aplanamiento de flujo de control para OLLVM y Tigress, simplificación MBA con reglas verificadas por Z3, eliminación de predicados opacos y flujo de control falso, eliminación de código muerto, descifrado de cadenas y desvirtualización de VM mediante un pipeline multipaso. El proyecto puede ejecutarse como CLI independiente o como analizador integrado de Ghidra para desofuscación con un solo clic. Está destinado a ingenieros de ingeniería inversa e investigadores de seguridad que analizan malware ofuscado, protección de juegos y otro software protegido.
