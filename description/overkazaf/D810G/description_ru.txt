D810G — это комплексный фреймворк деобфускации для платформы реверс-инжиниринга Ghidra, автоматизирующий восстановление читаемого кода из сильно обфусцированных бинарных файлов. Он использует гибридную архитектуру на Java и Python: плагин Ghidra обеспечивает интеграцию с интерфейсом и патчинг бинарников, а движок на Python на базе Z3, Unicorn, Capstone и Keystone выполняет глубокий анализ. Ключевые возможности включают дефлаттенинг потока управления для OLLVM и Tigress, упрощение MBA с правилами, проверенными Z3, удаление непрозрачных предикатов и ложного потока управления, устранение мёртвого кода, расшифровку строк и девirtualизацию VM через многоэтапный конвейер. Проект может работать как автономный CLI или как интегрированный анализатор Ghidra для деобфускации в один клик. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности, анализирующих обфусцированное вредоносное ПО, защиту игр и другое защищённое программное обеспечение.
