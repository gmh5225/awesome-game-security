D810G は Ghidra リバースエンジニアリングプラットフォーム向けの包括的な難読化解除フレームワークで、高度に難読化されたバイナリから可読なコードを自動的に復元します。Java と Python のハイブリッドアーキテクチャを採用しており、Ghidra プラグインが UI 統合とバイナリパッチを担当し、Z3、Unicorn、Capstone、Keystone を用いた Python エンジンが深層分析を実行します。主な機能には、OLLVM および Tigress 向けの制御フロー・デフラット化、Z3 検証ルールによる MBA 簡略化、不透明述語および偽制御フローの除去、デッドコード除去、文字列復号、マルチパスパイプラインによる VM デバーチャライズが含まれます。本プロジェクトはスタンドアロン CLI として実行でき、Ghidra 統合アナライザーとしてワンクリック難読化解除も可能です。難読化されたマルウェア、ゲーム保護、その他の保護されたソフトウェアを分析するリバースエンジニアおよびセキュリティ研究者向けに設計されています。
