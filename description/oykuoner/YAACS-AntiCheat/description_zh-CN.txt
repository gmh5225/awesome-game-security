YAACS 是一个服务端反作弊研究框架，通过分析比赛 demo 中的 pitch 与 yaw 瞄准遥测数据来检测 Counter-Strike 中的自瞄辅助，而非探测客户端内存。该项目使用 Python 编写，借助 NumPy、pandas、demoparser2 和 scikit-learn 构建合成与真实数据集，对诚实玩家、顶尖职业选手、硬件自瞄以及人类化规避作弊进行建模。流水线从 100 tick 窗口提取时空特征——基于 Fitts 定律与 Minimum Jerk Model 的速度、加速度和角度变化量——并将静态启发式规则引擎与 Random Forest 分类器进行对比。它面向需要一种隐私友好、可解释、可替代内核级客户端监控的 FPS 自瞄检测方案的游戏安全研究人员和反作弊开发者。
