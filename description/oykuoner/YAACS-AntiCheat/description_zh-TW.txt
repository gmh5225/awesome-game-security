YAACS 是一個伺服器端反作弊研究框架，透過分析比賽 demo 中的 pitch 與 yaw 瞄準遙測資料來偵測 Counter-Strike 中的自瞄輔助，而非探測用戶端記憶體。該專案使用 Python 撰寫，借助 NumPy、pandas、demoparser2 和 scikit-learn 建構合成與真實資料集，對誠實玩家、頂尖職業選手、硬體自瞄以及擬人化規避作弊進行建模。管線從 100 tick 視窗提取時空特徵——基於 Fitts 定律與 Minimum Jerk Model 的速度、加速度與角度變化量——並將靜態啟發式規則引擎與 Random Forest 分類器進行比較。它面向需要一種隱私友善、可解釋、可替代核心層級用戶端監控的 FPS 自瞄偵測方案之遊戲安全研究人員與反作弊開發者。
