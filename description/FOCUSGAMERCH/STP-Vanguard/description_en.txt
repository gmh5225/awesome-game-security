STP-Vanguard is a client–server anti-cheat stack built for Grand Theft Auto: San Andreas Multiplayer (SA-MP). The client ships as a Windows ASI module written in C++ that hooks the game’s RakNet path, performs hardware identity collection, memory integrity checks, filesystem scanning, and detection of injected modules and known cheat artifacts. The server side is a native SA-MP plugin plus Pawn gamemode includes and optional SQL-backed signature data, exchanging custom handshake and detection packets with connected clients. It supports CLEO-allowed and no-CLEO client variants, compile-time string obfuscation, and callbacks for bans, timeouts, and dynamic file hashing. The project targets multiplayer server operators and researchers who need practical anti-cheat enforcement and instrumentation around the SA-MP ecosystem.
