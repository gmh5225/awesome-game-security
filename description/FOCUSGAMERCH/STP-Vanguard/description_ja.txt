STP-Vanguard は Grand Theft Auto: San Andreas Multiplayer（SA-MP）向けに構築されたクライアント–サーバー型アンチチートスタックである。クライアントは C++ で書かれた Windows 用 ASI モジュールとして配布され、ゲームの RakNet 経路をフックし、ハードウェア識別の収集、メモリ整合性チェック、ファイルシステムスキャン、注入モジュールや既知のチート痕跡の検出を行う。サーバー側はネイティブな SA-MP プラグインに加え、Pawn ゲームモード用インクルードと任意の SQL ベースのシグネチャデータを備え、接続中のクライアントとカスタムのハンドシェイクおよび検出パケットを交換する。CLEO 許可版と CLEO 非許可版のクライアント変種、コンパイル時の文字列難読化、BAN・タイムアウト・動的ファイルハッシュ用のコールバックをサポートする。本プロジェクトは、SA-MP エコシステム周辺で実用的なアンチチートの執行と計測を必要とするマルチプレイサーバー運営者と研究者を対象としている。
