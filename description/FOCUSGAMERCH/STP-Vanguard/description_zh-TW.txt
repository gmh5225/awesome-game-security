STP-Vanguard 是一款面向《俠盜獵車手：聖安地列斯》多人模組（SA-MP）的客戶端–伺服器反作弊套件。客戶端以 Windows 上的 C++ ASI 模組形式發布，會掛鉤遊戲的 RakNet 路徑，執行硬體身分採集、記憶體完整性檢查、檔案系統掃描，以及注入模組與已知作弊痕跡的偵測。伺服器端為原生 SA-MP 外掛，輔以 Pawn 遊戲模式包含檔及可選的 SQL 簽章資料，與已連線客戶端交換自訂握手與偵測封包。支援允許 CLEO 與禁用 CLEO 的客戶端變體、編譯期字串混淆，以及封鎖、逾時與動態檔案雜湊等回呼。本專案面向需要在其 SA-MP 環境中進行實用反作弊執法與觀測的多人伺服器營運者與研究人員。
