STP-Vanguard 是一款面向《侠盗猎车手：圣安地列斯》多人模组（SA-MP）的客户端–服务端反作弊套件。客户端以 Windows 上的 C++ ASI 模块形式发布，会挂钩游戏的 RakNet 路径，执行硬件身份采集、内存完整性检查、文件系统扫描，以及注入模块与已知作弊痕迹的检测。服务端为原生 SA-MP 插件，辅以 Pawn 游戏模式包含文件及可选的 SQL 签名数据，与已连接客户端交换自定义握手与检测数据包。支持允许 CLEO 与禁用 CLEO 的客户端变体、编译期字符串混淆，以及封禁、超时与动态文件哈希等回调。本项目面向需要在其 SA-MP 环境中进行实用反作弊执法与观测的多人服务器运营者与研究人员。
