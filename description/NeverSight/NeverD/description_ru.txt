NeverD — это движок нативного бинарного анализа и декомпиляции, выполняющий поэтапное поднятие скомпилированных исполняемых файлов на уровне инструкций один к одному с целью полной семантической точности. Написан преимущественно на C++20 и доступен через чистый C API (libneverd); загружает бинарные файлы PE, ELF и Mach-O на архитектурах x86-64, i386, AArch64 и ARM32, декодирует с помощью Capstone и поднимает через четырёхэтапный IR-конвейер, построенный на кастомном форке LLVM. Единый конвейер поддерживает поднятие в LLVM IR, декомпиляцию в структурированный C или перезапись машинного кода на месте; строгий режим отклоняет неподдерживаемые инструкции, а не угадывает их молча. Набор инструментов включает единый CLI для дизасsemblирования, анализа CFG, сопоставления сигнатур и патчинга бинарников, а также поддержку плагинов и вывод в формате JSON, подходящий для автоматизации и рабочих процессов реверс-инжиниринга с помощью ИИ. Предназначен для исследователей, интеграторов и специалистов по безопасности, анализирующих нативный код для триажа вредоносного ПО, исследования уязвимостей и реверс-инжиниринга игр или античитов.
