NeverD は、コンパイル済み実行ファイルを一対一の命令レベルでリフティングし、完全な意味論的忠実性を目指すネイティブバイナリ解析・逆コンパイルエンジンです。主に C++20 で実装され、純粋な C API（libneverd）を通じて公開されており、x86-64、i386、AArch64、ARM32 上の PE、ELF、Mach-O バイナリを読み込み、Capstone によるデコードと、カスタム LLVM フォーク上に構築された四段階 IR パイプラインによるリフティングを行います。単一のパイプラインで LLVM IR へのリフティング、構造化 C への逆コンパイル、またはインプレースでの機械語書き換えをサポートし、厳格モードでは未対応命令を黙って推測せず拒否します。ツールキットには、逆アセンブル、CFG 解析、シグネチャマッチング、バイナリパッチングのための統合 CLI に加え、プラグイン対応と JSON 指向の出力が含まれ、自動化や AI 支援の逆コンパイルワークフローに適しています。マルウェアトリアージ、脆弱性調査、ゲームやアンチチートの逆コンパイルのためにネイティブコードを解析する研究者、インテグレーター、セキュリティ実務者を対象としています。
