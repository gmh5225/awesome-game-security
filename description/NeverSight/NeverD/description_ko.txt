NeverD는 컴파일된 실행 파일을 일대일 명령어 수준으로 리프팅하여 완전한 의미론적 충실도를 목표로 하는 네이티브 바이너리 분석 및 디컴파일 엔진입니다. 주로 C++20로 작성되었으며 순수 C API(libneverd)를 통해 노출되며, x86-64, i386, AArch64, ARM32에서 PE, ELF, Mach-O 바이너리를 로드하고 Capstone으로 디코딩한 뒤 커스텀 LLVM 포크 기반의 4단계 IR 파이프라인을 통해 리프팅합니다. 단일 파이프라인은 LLVM IR로의 리프팅, 구조화된 C로의 디컴파일, 또는 제자리 기계 코드 재작성을 지원하며, 엄격 모드는 지원되지 않는 명령어를 조용히 추측하지 않고 거부합니다. 툴킷에는 디스어셈블리, CFG 분석, 시그니처 매칭, 바이너리 패칭을 위한 통합 CLI와 플러그인 지원, 자동화 및 AI 지원 리버스 엔지니어링 워크플로에 적합한 JSON 지향 출력이 포함됩니다. 멀웨어 분류, 취약점 연구, 게임 또는 안티치트 리버스 엔지니어링을 위해 네이티브 코드를 분석하는 연구자, 통합 개발자, 보안 실무자를 대상으로 합니다.
