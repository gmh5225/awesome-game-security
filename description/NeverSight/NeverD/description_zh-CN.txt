NeverD 是一款原生二进制分析与反编译引擎，对编译后的可执行文件进行一对一的指令级提升，以实现完整的语义保真。它主要使用 C++20 编写，通过纯 C API（libneverd）对外提供接口，可加载 x86-64、i386、AArch64 和 ARM32 架构下的 PE、ELF 和 Mach-O 二进制文件，借助 Capstone 解码，并通过基于定制 LLVM 分支的四阶段 IR 流水线完成提升。单一流水线支持提升至 LLVM IR、反编译为结构化 C 代码，或就地重写机器码；严格模式会拒绝不支持的指令，而非静默猜测。工具包提供统一的 CLI，用于反汇编、CFG 分析、特征匹配和二进制补丁，并支持插件及面向 JSON 的输出，适用于自动化与 AI 辅助的逆向工程工作流。面向分析原生代码的研究人员、集成开发者及安全从业者，适用于恶意软件分类、漏洞研究以及游戏或反作弊逆向工程。
