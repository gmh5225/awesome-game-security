NeverC は、カスタマイズされた LLVM バックエンド上に構築された、セキュリティ指向の C コンパイラおよびツールチェーンであり、Windows、Linux、Android 向けにハード化されたネイティブバイナリを生成します。主に C と C++ で書かれており、暗号化文字列ビルトイン、文字列ハッシュ、mimalloc などのコンパイル時保護機能に加え、カーネルモード利用を含む位置独立ランタイムコード生成のための DynCode パイプラインを提供します。本プロジェクトは、プリプロセス、AST および意味解析、IR および MIR パス、LTO リンク、カスタム呼び出し規約にわたる拡張可能なプラグイン API を公開しており、ユーザーモード実行ファイルや DLL、Windows カーネルドライバ、Android カーネルモジュールなどのサンプルを含みます。ゲームセキュリティ研究者、リバースエンジニア、難読化、回避、クロスプラットフォームのネイティブコード生成が必要な低レベルツールを構築する開発者を対象としています。
