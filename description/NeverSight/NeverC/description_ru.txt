NeverC — это ориентированный на безопасность компилятор C и набор инструментов, построенный на настраиваемом бэкенде LLVM для создания защищённых нативных бинарников под Windows, Linux и Android. Написанный преимущественно на C и C++, он включает защиту на этапе компиляции, такую как встроенные функции для зашифрованных строк, хеширование строк и mimalloc, а также конвейер DynCode для генерации независимого от позиции кода во время выполнения, включая использование в режиме ядра. Проект предоставляет расширяемый API плагинов для препроцессинга, AST- и семантического анализа, проходов IR и MIR, LTO-линковки и пользовательских соглашений о вызовах, с примерами для пользовательских исполняемых файлов и DLL, драйверов ядра Windows и модулей ядра Android. Он ориентирован на исследователей безопасности игр, специалистов по реверс-инжинирингу и разработчиков низкоуровневых инструментов, где требуются обфускация, обход защиты и кроссплатформенная генерация нативного кода.
