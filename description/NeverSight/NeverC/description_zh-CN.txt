NeverC 是一款面向安全的 C 编译器和工具链，基于定制的 LLVM 后端，可在 Windows、Linux 和 Android 上生成加固的原生二进制文件。它主要使用 C 和 C++ 编写，提供编译时保护功能，包括加密字符串内建函数、字符串哈希和 mimalloc，以及用于位置无关运行时代码生成（包括内核模式）的 DynCode 流水线。该项目在预处理、AST 与语义分析、IR 与 MIR 传递、LTO 链接和自定义调用约定等环节提供可扩展的插件 API，示例涵盖用户态可执行文件与 DLL、Windows 内核驱动以及 Android 内核模块。它面向游戏安全研究人员、逆向工程师以及需要混淆、规避和跨平台原生代码生成的底层工具开发者。
