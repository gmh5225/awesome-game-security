NeverC es un compilador C y cadena de herramientas orientada a la seguridad, construida sobre un backend LLVM personalizado para producir binarios nativos reforzados en Windows, Linux y Android. Escrito principalmente en C y C++, incluye protecciones en tiempo de compilación como builtins de cadenas cifradas, hash de cadenas y mimalloc, junto con una canalización DynCode para generación de código en tiempo de ejecución independiente de posición, incluido el uso en modo kernel. El proyecto expone una API de plugins extensible en preprocesamiento, análisis AST y semántico, pasadas IR y MIR, enlazado LTO y convenciones de llamada personalizadas, con ejemplos que abarcan ejecutables y DLL en modo usuario, controladores de kernel de Windows y módulos de kernel de Android. Está dirigido a investigadores de seguridad de juegos, ingenieros de ingeniería inversa y desarrolladores que construyen herramientas de bajo nivel donde se requieren ofuscación, evasión y generación de código nativo multiplataforma.
