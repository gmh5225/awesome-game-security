UE4SS Launcher 是一款 Windows 桌面应用，面向单机 Unreal Engine 4 与 5 游戏，内置游戏内编辑器，用于注入并管理 UE4SS，使 Lua 与 C++ 模组能在运行中的游戏进程内执行。项目主要以 C++ 编写，界面采用 Dear ImGui 与 DirectX 11，并捆绑 UE4SS 资源、LauncherBridge Lua 模组，以及启动、附加注入、按游戏修复签名与设置、模组开关等工具。除注入外，它还提供自由视角、作弊与玩家参数调整、地图与调试菜单发现、类似 Unreal Editor 的游戏内关卡编辑快捷键，以及常见网格格式的 3D 资源导入导出，包括加密或 Oodle 压缩包。本项目面向模组开发者、逆向工程师与研究人员，作为 UE4SS 脚本、运行时对象检视与离线 Unreal 游戏实操实验的实用前端，而非面向正式运营的多人对战作品。
