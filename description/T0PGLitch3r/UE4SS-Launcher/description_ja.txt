UE4SS Launcher は、シングルプレイ向け Unreal Engine 4 および 5 タイトル向けの統合インゲームエディタ付き Windows デスクトップアプリで、UE4SS の注入と管理を行い、Lua および C++ モッドを稼働中のゲームプロセス内で動かすために作られています。主に C++ で記述され、Dear ImGui と DirectX 11 の UI を備え、UE4SS アセット、LauncherBridge Lua モッド、起動、アタッチ注入、ゲーム別シグネチャと設定の修正、モッドの切り替えなどのツールを同梱します。注入に加え、フリーカメラ、チートとプレイヤー調整、マップとデバッグメニューの探索、Unreal Editor 風のインゲームレベル編集ホットキー、暗号化や Oodle パックされたアーカイブを含む一般的なメッシュ形式での 3D アセットの入出力を提供します。本プロジェクトは、本番のマルチプレイタイトルではなくオフラインの Unreal ゲーム上で、UE4SS スクリプティング、ランタイムオブジェクト検査、実地実験のための実用的なフロントエンドを必要とするモッド開発者、リバースエンジニア、研究者を対象としています。
