UE4SS Launcher 是一款 Windows 桌面應用程式，面向單機 Unreal Engine 4 與 5 遊戲，內建遊戲內編輯器，用於注入並管理 UE4SS，使 Lua 與 C++ 模組能在執行中的遊戲程序內運作。專案主要以 C++ 撰寫，介面採用 Dear ImGui 與 DirectX 11，並內含 UE4SS 資源、LauncherBridge Lua 模組，以及啟動、附加注入、依遊戲修復簽章與設定、模組開關等工具。除注入外，它還提供自由視角、作弊與玩家參數調整、地圖與偵錯選單探索、類似 Unreal Editor 的遊戲內關卡編輯快速鍵，以及常見網格格式的 3D 資源匯入匯出，含加密或 Oodle 壓縮封存檔。本專案面向模組開發者、逆向工程師與研究人員，作為 UE4SS 腳本、執行階段物件檢視與離線 Unreal 遊戲實作實驗的實用前端，而非面向正式營運的多人對戰作品。
