UE4SS Launcher is a Windows desktop application with an integrated in-game editor for single-player Unreal Engine 4 and 5 titles, built to inject and manage UE4SS so Lua and C++ mods can run inside a live game process. It is written primarily in C++ with a Dear ImGui and DirectX 11 interface, and ships bundled UE4SS assets, a LauncherBridge Lua mod, and tooling for launch, attach-injection, per-game signature and settings fixes, and mod toggling. Beyond injection, it exposes free camera, cheat and player tweaks, map and debug-menu discovery, Unreal-Editor-style level editing hotkeyed in-game, and import or export of 3D assets across common mesh formats including encrypted or Oodle-packed archives. The project targets mod developers, reverse engineers, and researchers who need a practical front end for UE4SS scripting, runtime object inspection, and hands-on experimentation on offline Unreal games rather than production multiplayer titles.
