DLSS Unlocked は、Windows および Proton 経由の Linux 上で、GeForce RTX 20xx から 40xx GPU を搭載した環境において、対応する DirectX 12 タイトルで NVIDIA DLSS 3 のフレーム生成、マルチフレーム生成、ニューラルレンダリングを有効にするゲーム MOD 兼インストーラーです。ゲームプロセスにプロキシ DLL を注入し、NVIDIA NGX および Streamline の呼び出しを傍受し、オプションでフレーム生成を OptiScaler および FSR 3.1 バックエンドへブリッジしつつ、レジストリパッチまたは同梱ライブラリの置換により NVIDIA ドライバーの署名チェックを回避します。Inno Setup インストーラー、スタンドアロンパッケージ、ASI および DXGI ローダー各種、上流の OptiScaler および DLSS-NR コンポーネントをパッケージ化する PowerShell ビルドスクリプトを提供します。DLL インジェクション、Microsoft Detours 方式の API フック、ベンダーグラフィックスライブラリの傍受といった、ゲーム改造およびセキュリティ分析に関連する手法に関心のある MOD 開発者および研究者を対象としています。
