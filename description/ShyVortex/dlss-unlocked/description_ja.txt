DLSS Unlocked は、Windows および Proton 経由の Linux 上で、GeForce RTX 20xx から 40xx GPU に対応した DirectX 12 タイトルにおいて、NVIDIA DLSS 3 のフレーム生成、マルチフレーム生成、ニューラルレンダリングを有効にするゲーム MOD とインストーラーです。ゲームプロセスにプロキシ DLL を注入し、NVIDIA NGX および Streamline の呼び出しを傍受し、オプションでフレーム生成を OptiScaler および FSR 3.1 バックエンドにブリッジし、レジストリパッチまたは同梱ライブラリの置換により NVIDIA ドライバーの署名チェックをバイパスします。Inno Setup インストーラー、スタンドアロンパッケージ、ASI および DXGI ローダー各種、上流 OptiScaler および DLSS-NR コンポーネントをパッケージ化する PowerShell ビルドスクリプトを提供します。DLL インジェクション、Microsoft Detours スタイルの API フック、ゲーム MOD およびセキュリティ分析に関連するベンダーグラフィックスライブラリ傍受手法に関心のある MOD 開発者および研究者を対象としています。
