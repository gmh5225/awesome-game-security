DLSS Unlocked 是一款遊戲模組與安裝程式，可在 Windows 及透過 Proton 執行的 Linux 上，為 GeForce RTX 20xx 至 40xx 顯示卡所支援的部分 DirectX 12 遊戲啟用 NVIDIA DLSS 3 幀生成、多幀生成與神經渲染功能。它透過向遊戲程序注入代理 DLL，並攔截 NVIDIA NGX 與 Streamline 呼叫，可選地將幀生成橋接至 OptiScaler 與 FSR 3.1 後端，同時透過登錄表修補或捆綁函式庫替換繞過 NVIDIA 驅動程式簽章檢查。該專案提供 Inno Setup 安裝程式、獨立套件、ASI 與 DXGI 載入器變體，以及用於打包上游 OptiScaler 與 DLSS-NR 元件的 PowerShell 建置腳本。它面向對 DLL 注入、Microsoft Detours 風格 API 掛鉤，以及與遊戲修改和安全分析相關的廠商圖形函式庫攔截技術感興趣的模組開發者與研究人員。
