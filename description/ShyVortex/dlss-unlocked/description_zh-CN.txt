DLSS Unlocked 是一款游戏模组与安装程序，可在 Windows 以及通过 Proton 运行的 Linux 上，为 GeForce RTX 20xx 至 40xx 显卡在支持的 DirectX 12 游戏中启用 NVIDIA DLSS 3 帧生成、多帧生成和神经渲染。它向游戏进程注入代理 DLL，并拦截 NVIDIA NGX 与 Streamline 调用，可选地将帧生成桥接至 OptiScaler 与 FSR 3.1 后端，同时通过注册表补丁或捆绑库替换绕过 NVIDIA 驱动签名检查。该项目提供 Inno Setup 安装程序、独立软件包、ASI 与 DXGI 加载器变体，以及用于打包上游 OptiScaler 与 DLSS-NR 组件的 PowerShell 构建脚本。它面向对 DLL 注入、Microsoft Detours 风格 API 挂钩以及厂商图形库拦截技术感兴趣、从事游戏修改与安全分析的模组开发者与研究人员。
