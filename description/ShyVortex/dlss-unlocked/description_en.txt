DLSS Unlocked is a game mod and installer that enables NVIDIA DLSS 3 frame generation, multi-frame generation, and neural rendering in supported DirectX 12 titles on GeForce RTX 20xx through 40xx GPUs on Windows and Linux via Proton. It injects proxy DLLs into game processes and intercepts NVIDIA NGX and Streamline calls, optionally bridging frame generation to OptiScaler and FSR 3.1 backends while bypassing NVIDIA driver signature checks through registry patches or bundled library replacements. The project provides an Inno Setup installer, standalone packages, ASI and DXGI loader variants, and PowerShell build scripts that package upstream OptiScaler and DLSS-NR components. It targets mod developers and researchers interested in DLL injection, Microsoft Detours-style API hooking, and vendor graphics library interception techniques relevant to game modification and security analysis.
