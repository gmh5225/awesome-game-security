SpoofingCollection은 root된 Android 기기가 다른 제조사, 모델, 빌드 지문을 보고하도록 하는 Android 기기 ID 스푸핑 도구 모음입니다. 각 프로필은 부팅 시 시스템 속성을 다시 쓰는 Magisk 모듈과 Java로 작성된 LSPosed Xposed 모듈이 쌍으로 제공되며, 후자는 MANUFACTURER, MODEL, DEVICE, PRODUCT 등 런타임 Build API 필드를 후킹합니다. 프로필은 Samsung Galaxy S26 Ultra, OnePlus 15, Galaxy Tab S10 Ultra, Google Pixel 10 Pro XL, Pixel Tablet, Xiaomi 17 Pro Max 등 플래그십 기기를 포함하며, 해당되는 경우 attestation 관련 속성도 포함합니다. 이 프로젝트는 모바일 안티치트, Play Integrity, root된 Android에서의 기기 attestation을 연구하는 보안 연구자, 또는 앱이 하드웨어를 어떻게 지문화하는지와 속성 계층 및 API 계층 모두에서 해당 검사에 어떻게 영향을 줄 수 있는지 분석하는 사람을 대상으로 합니다.
