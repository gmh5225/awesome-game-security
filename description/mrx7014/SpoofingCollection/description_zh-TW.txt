SpoofingCollection 是一套精選的 Android 裝置身分偽裝工具，可使已 root 的手機回報不同的製造商、型號和建置指紋。每個設定檔包含一對元件：一個在開機時重寫系統屬性的 Magisk 模組，以及一個以 Java 撰寫的 LSPosed Xposed 模組，用於 hook 執行階段 Build API 欄位（如 MANUFACTURER、MODEL、DEVICE 和 PRODUCT）。設定檔涵蓋多款旗艦機型，包括 Samsung Galaxy S26 Ultra、OnePlus 15、Galaxy Tab S10 Ultra、Google Pixel 10 Pro XL、Pixel Tablet 和 Xiaomi 17 Pro Max，並在適用情況下包含與 attestation 相關的屬性。本專案面向研究行動端反作弊、Play Integrity 以及已 root Android 裝置 attestation 的安全研究人員，或任何分析應用程式如何對硬體進行指紋辨識、以及如何在屬性層與 API 層影響這些檢測的人士。
