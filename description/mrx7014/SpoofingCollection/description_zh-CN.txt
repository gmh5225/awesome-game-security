SpoofingCollection 是一套精选的 Android 设备身份伪装工具，可使已 root 的手机上报不同的制造商、型号和构建指纹。每个配置文件包含一对组件：一个在启动时重写系统属性的 Magisk 模块，以及一个用 Java 编写的 LSPosed Xposed 模块，用于 hook 运行时 Build API 字段（如 MANUFACTURER、MODEL、DEVICE 和 PRODUCT）。配置文件涵盖多款旗舰机型，包括 Samsung Galaxy S26 Ultra、OnePlus 15、Galaxy Tab S10 Ultra、Google Pixel 10 Pro XL、Pixel Tablet 和 Xiaomi 17 Pro Max，并在适用情况下包含与 attestation 相关的属性。该项目面向研究移动端反作弊、Play Integrity 以及已 root Android 设备 attestation 的安全研究人员，或任何分析应用如何对硬件进行指纹识别、以及如何在属性层与 API 层影响这些检测的人士。
