SpoofingCollection is a curated set of Android device-identity spoofing tools that make a rooted phone report a different manufacturer, model, and build fingerprint. Each profile ships as a paired Magisk module that rewrites system properties at boot and an LSPosed Xposed module written in Java that hooks runtime Build API fields such as MANUFACTURER, MODEL, DEVICE, and PRODUCT. Profiles cover flagship targets including Samsung Galaxy S26 Ultra, OnePlus 15, Galaxy Tab S10 Ultra, Google Pixel 10 Pro XL, Pixel Tablet, and Xiaomi 17 Pro Max, with attestation-related properties included where applicable. The project is aimed at security researchers studying mobile anti-cheat, Play Integrity, and device attestation on rooted Android, or anyone analyzing how apps fingerprint hardware and how those checks can be influenced at both the property and API layers.
