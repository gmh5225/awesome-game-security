SpoofingCollection は、root 済み Android 端末が異なるメーカー、モデル、ビルドフィンガープリントを報告するようにする、Android デバイス ID 偽装ツールの厳選コレクションです。各プロファイルは、起動時にシステムプロパティを書き換える Magisk モジュールと、Java で書かれた LSPosed Xposed モジュールのペアで構成され、後者は MANUFACTURER、MODEL、DEVICE、PRODUCT などのランタイム Build API フィールドをフックします。プロファイルは Samsung Galaxy S26 Ultra、OnePlus 15、Galaxy Tab S10 Ultra、Google Pixel 10 Pro XL、Pixel Tablet、Xiaomi 17 Pro Max などのフラッグシップ機種をカバーし、該当する場合は attestation 関連プロパティも含みます。本プロジェクトは、モバイルアンチチート、Play Integrity、root 済み Android でのデバイス attestation を研究するセキュリティ研究者、またはアプリがハードウェアをどのようにフィンガープリントし、プロパティ層と API 層の両方でその検査にどう影響を与えられるかを分析する人を対象としています。
