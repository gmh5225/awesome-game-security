SpoofingCollection es un conjunto seleccionado de herramientas de suplantación de identidad de dispositivos Android que hacen que un teléfono con root informe un fabricante, modelo y huella de compilación distintos. Cada perfil incluye un módulo Magisk emparejado que reescribe las propiedades del sistema al arrancar y un módulo LSPosed Xposed escrito en Java que intercepta campos de la API Build en tiempo de ejecución como MANUFACTURER, MODEL, DEVICE y PRODUCT. Los perfiles cubren dispositivos insignia como Samsung Galaxy S26 Ultra, OnePlus 15, Galaxy Tab S10 Ultra, Google Pixel 10 Pro XL, Pixel Tablet y Xiaomi 17 Pro Max, con propiedades relacionadas con attestation cuando corresponde. El proyecto está dirigido a investigadores de seguridad que estudian anti-cheat móvil, Play Integrity y attestation de dispositivos en Android con root, o a quienes analicen cómo las aplicaciones identifican el hardware y cómo esas comprobaciones pueden influirse tanto a nivel de propiedades como de API.
