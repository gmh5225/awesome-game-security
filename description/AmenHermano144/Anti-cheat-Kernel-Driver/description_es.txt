Core_ac es un controlador anti-trampas en modo kernel WDM de Windows x64 orientado a juegos multijugador competitivos, ofrecido como implementación de referencia modular y no como producto de producción. Está escrito en C y se compila con Visual Studio 2022 y el Windows Driver Kit, usa Windows CNG (BCrypt) para criptografía y un canal IOCTL en modo usuario reforzado sellado con AES-GCM por sesión. Las funciones de detección e integridad incluyen listas negras BYOVD y de marcas de tiempo de controladores, inventario de módulos del kernel y escaneo de regiones ejecutables, monitorización de manipulación de PiDDBCache y MmUnloadedDrivers, vigilancia de procesos basada en PML4, watchdog NMI y comprobaciones de entorno, e integridad de la ruta de entrada para controladores de clase ratón y teclado. El diseño aplaza la inicialización pesada fuera de DriverEntry, aplica DACL de dispositivo estrictas y transmite telemetría a un compañero en modo usuario de nivel SYSTEM mediante un búfer circular de eventos. Es adecuado para ingenieros de seguridad de juegos e investigadores anti-trampas autorizados que buscan técnicas de detección en kernel legibles y verificables y una base para estudiar cómo se estructuran los anti-trampas modernos en kernel.
