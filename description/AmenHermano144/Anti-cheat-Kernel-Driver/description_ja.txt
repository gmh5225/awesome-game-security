Core_ac は競技型マルチプレイヤーゲーム向けの Windows x64 WDM カーネルモードアンチチートドライバーで、本番製品ではなくモジュール化された参考実装として提供されています。C 言語で記述され、Visual Studio 2022 と Windows Driver Kit でビルドし、Windows CNG（BCrypt）で暗号処理を行い、セッションごとの AES-GCM で保護された強化ユーザーモード IOCTL チャネルを使用します。検知と整合性機能には、BYOVD およびドライバタイムスタンプのブラックリスト、カーネルモジュールのインベントリと実行可能領域のスキャン、PiDDBCache と MmUnloadedDrivers の改ざん監視、PML4 ベースのプロセス監視、NMI ウォッチドッグと環境チェック、マウスおよびキーボードクラスドライバ向けの入力経路整合性が含まれます。設計上は DriverEntry から重い初期化を遅延させ、厳格なデバイス DACL を適用し、イベントリングバッファ経由で SYSTEM レベルのユーザーモードコンパニオンへテレメトリをストリーミングします。読みやすく検証可能なカーネル検知手法と、現代のカーネルアンチチートの構成を学ぶためのベースラインを求めるゲームセキュリティエンジニアおよび許可されたアンチチート研究者向けです。
