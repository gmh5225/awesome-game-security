Core_ac 是一款面向竞技类多人游戏的 Windows x64 WDM 内核模式反作弊驱动，以模块化参考实现的形式提供，而非面向生产环境的产品。它使用 C 语言编写，通过 Visual Studio 2022 与 Windows Driver Kit 构建，采用 Windows CNG（BCrypt）实现密码学功能，并通过以每会话 AES-GCM 封装的加固用户态 IOCTL 通道进行通信。检测与完整性能力包括 BYOVD 与驱动时间戳黑名单、内核模块清单与可执行区域扫描、PiDDBCache 与 MmUnloadedDrivers 篡改监控、基于 PML4 的进程监视、NMI 看门狗与环境检查，以及针对鼠标与键盘类驱动的输入路径完整性校验。设计上将繁重初始化从 DriverEntry 延后执行，应用严格的设备 DACL，并通过事件环形缓冲区向 SYSTEM 级用户态配套程序流式传输遥测数据。适合希望了解可读、可验证的内核检测技术，并研究现代内核反作弊架构基线的游戏安全工程师与经授权的反作弊研究人员。
