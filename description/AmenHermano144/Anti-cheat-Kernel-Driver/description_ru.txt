Core_ac — это драйвер античита в режиме ядра WDM для Windows x64, ориентированный на соревновательные многопользовательские игры; он предлагается как модульная эталонная реализация, а не как продукт для промышленной эксплуатации. Написан на C, собирается в Visual Studio 2022 и Windows Driver Kit, использует Windows CNG (BCrypt) для криптографии и усиленный пользовательский канал IOCTL, защищённый AES-GCM для каждой сессии. Функции обнаружения и целостности включают чёрные списки BYOVD и меток времени драйверов, инвентаризацию модулей ядра и сканирование исполняемых областей, мониторинг подмены PiDDBCache и MmUnloadedDrivers, наблюдение за процессами на основе PML4, сторож NMI и проверки окружения, а также целостность пути ввода для классовых драйверов мыши и клавиатуры. Архитектура откладывает тяжёлую инициализацию из DriverEntry, применяет строгие DACL устройств и передаёт телеметрию пользовательскому компаньону уровня SYSTEM через кольцевой буфер событий. Подходит инженерам по безопасности игр и авторизованным исследователям античита, которым нужны понятные, проверяемые методы обнаружения в ядре и базовая линия для изучения структуры современных kernel-античитов.
