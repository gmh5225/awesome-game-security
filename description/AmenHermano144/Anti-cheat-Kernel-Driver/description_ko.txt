Core_ac는 경쟁형 멀티플레이어 게임을 대상으로 한 Windows x64 WDM 커널 모드 안티치트 드라이버로, 상용 제품이 아니라 모듈형 참조 구현으로 제공됩니다. C 언어로 작성되었으며 Visual Studio 2022와 Windows Driver Kit로 빌드하고, Windows CNG(BCrypt)로 암호화를 처리하며 세션별 AES-GCM으로 봉인된 강화된 사용자 모드 IOCTL 채널을 사용합니다. 탐지 및 무결성 기능에는 BYOVD 및 드라이버 타임스탬프 블랙리스트, 커널 모듈 인벤토리 및 실행 가능 영역 스캔, PiDDBCache 및 MmUnloadedDrivers 변조 모니터링, PML4 기반 프로세스 감시, NMI 워치독 및 환경 검사, 마우스·키보드 클래스 드라이버용 입력 경로 무결성이 포함됩니다. 설계상 DriverEntry에서 무거운 초기화를 미루고, 엄격한 장치 DACL을 적용하며, 이벤트 링 버퍼를 통해 SYSTEM 수준 사용자 모드 동반 프로그램으로 원격 측정을 스트리밍합니다. 읽기 쉽고 검증 가능한 커널 탐지 기법과 현대 커널 안티치트 구조를 연구하기 위한 기준선을 원하는 게임 보안 엔지니어 및 승인된 안티치트 연구자에게 적합합니다.
