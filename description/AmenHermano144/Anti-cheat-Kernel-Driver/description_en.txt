Core_ac is a Windows x64 WDM kernel-mode anti-cheat driver aimed at competitive multiplayer games, offered as a modular reference implementation rather than a production product. It is written in C and built with Visual Studio 2022 and the Windows Driver Kit, using Windows CNG (BCrypt) for cryptography and a hardened user-mode IOCTL channel sealed with per-session AES-GCM. Detection and integrity features include BYOVD and driver timestamp blacklists, kernel module inventory and executable-region scanning, PiDDBCache and MmUnloadedDrivers tamper monitoring, PML4-based process watching, NMI watchdog and environment checks, and input-path integrity for mouse and keyboard class drivers. The design defers heavy initialization from DriverEntry, applies strict device DACLs, and streams telemetry to a SYSTEM-level user-mode companion via an event ring buffer. It suits game security engineers and authorized anti-cheat researchers who want readable, verifiable kernel detection techniques and a baseline for studying how modern kernel anti-cheats are structured.
