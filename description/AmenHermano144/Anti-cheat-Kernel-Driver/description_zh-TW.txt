Core_ac 是一款面向競技類多人遊戲的 Windows x64 WDM 核心模式反作弊驅動程式，以模組化參考實作的形式提供，而非面向生產環境的產品。它使用 C 語言撰寫，透過 Visual Studio 2022 與 Windows Driver Kit 建置，採用 Windows CNG（BCrypt）實作密碼學功能，並透過以每工作階段 AES-GCM 封裝的強化使用者模式 IOCTL 通道進行通訊。偵測與完整性能力包括 BYOVD 與驅動程式時間戳記黑名單、核心模組清單與可執行區域掃描、PiDDBCache 與 MmUnloadedDrivers 竄改監控、基於 PML4 的行程監視、NMI 看門狗與環境檢查，以及針對滑鼠與鍵盤類別驅動程式的輸入路徑完整性驗證。設計上將繁重初始化從 DriverEntry 延後執行，套用嚴格的裝置 DACL，並透過事件環形緩衝區向 SYSTEM 層級使用者模式配套程式串流傳輸遙測資料。適合希望了解可讀、可驗證的核心偵測技術，並研究現代核心反作弊架構基線的遊戲安全工程師與經授權的反作弊研究人員。
