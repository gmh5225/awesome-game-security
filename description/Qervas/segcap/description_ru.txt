segcap — это исследовательский инструмент для Windows, который внедряется в работающие игры на Direct3D 12 и захватывает покадрово выровненные с отрендеренным изображением попиксельные маски сегментации по ID объектов. Реализованный на C++ с оркестрацией на Python, он использует MinHook для перехвата отправки команд D3D12 и инспектирует Unreal Engine 4 и 5 во время выполнения, назначая стабильные метки через проход CustomDepth движка вместо перестройки состояния конвейера рендеринга. Он выполняет полностью автоматизированные сеансы захвата на выпущенных розничных играх, управляя меню через виртуальный геймпад и экспортируя маски, RGB-кадры и JSON sidecar для проверки и анализа. Проект ориентирован на специалистов по обратной разработке и исследователей безопасности игр, которым нужна эталонная сегментация и глубокая видимость закрытого рендеринга UE без исходного кода и символов.
