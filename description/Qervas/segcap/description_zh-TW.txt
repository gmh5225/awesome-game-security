segcap 是一款 Windows 研究工具，可注入執行中的 Direct3D 12 遊戲，並擷取與渲染影像逐幀對齊的逐像素物件 ID 分割遮罩。此工具以 C++ 實作，由 Python 編排，使用 MinHook 攔截 D3D12 命令提交，並在執行時期內省 Unreal Engine 4 和 5，透過引擎的 CustomDepth 通道指派穩定標籤，而無需重建渲染器管線狀態。它能在已發售的零售版遊戲上執行全自動擷取工作階段，使用虛擬手把驅動選單，並匯出遮罩、RGB 影格和 JSON sidecar 檔案以供驗證與分析。本專案面向需要真實分割標註以及對閉源 UE 渲染進行深度洞察、且無需原始碼或符號的反編譯工程師和遊戲安全研究人員。
