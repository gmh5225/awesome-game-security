segcap 是一款 Windows 研究工具，可注入运行中的 Direct3D 12 游戏，并捕获与渲染图像逐帧对齐的逐像素对象 ID 分割掩码。该工具采用 C++ 实现，由 Python 编排，使用 MinHook 拦截 D3D12 命令提交，并在运行时内省 Unreal Engine 4 和 5，通过引擎的 CustomDepth 通道分配稳定标签，而无需重建渲染器管线状态。它能在已发售的零售版游戏上运行全自动捕获会话，使用虚拟手柄驱动菜单，并导出掩码、RGB 帧和 JSON sidecar 文件以供验证和分析。该项目面向需要真实分割标注以及对闭源 UE 渲染进行深度洞察、且无需源代码或符号的反编译工程师和游戏安全研究人员。
