segcap は、実行中の Direct3D 12 ゲームに注入し、レンダリング画像とフレーム単位で整列したピクセル単位のオブジェクト ID セグメンテーションマスクをキャプチャする Windows 向け研究ツールです。C++ で実装され Python によりオーケストレーションされ、MinHook を用いて D3D12 コマンド送信を傍受し、実行時に Unreal Engine 4 および 5 を内省して、レンダラーパイプライン状態を再構築することなくエンジンの CustomDepth パスを通じて安定したラベルを割り当てます。リテール版の出荷済みタイトル上で完全自動化されたキャプチャセッションを実行し、仮想ゲームパッドでメニューを操作し、検証と分析のためにマスク、RGB フレーム、JSON サイドカーをエクスポートします。本プロジェクトは、ソースコードやシンボルなしで、グラウンドトゥルースのセグメンテーションとクローズドソース UE レンダリングへの深い可視性を必要とするリバースエンジニアおよびゲームセキュリティ研究者を対象としています。
