StrataDMA is a cross-platform C++17 library that wraps MemProcFS and VMMDLL for authorized direct memory access inspection of live Windows targets from a 64-bit Windows or Linux host. It offers configurable device initialization, process attachment by name or PID, strict typed memory read APIs with scatter batches and frame caching, module and symbol tooling, signature scanning, CR3 recovery, PE dumping, registry and VFS access, rich OS inspection tables, and optional input polling. The project ships as a static library with CMake and Visual Studio builds, vendors LeechCore and MemProcFS headers, and includes mock-backed tests that do not require DMA hardware. It is aimed at security researchers, reverse engineers, and game-security practitioners who need a structured, production-oriented facade over FPGA or similar DMA setups for forensic and analysis workflows.
