StrataDMA 是一款跨平台 C++17 函式庫，封裝 MemProcFS 與 VMMDLL，用於在經授權的 64 位元 Windows 或 Linux 主機上對執行中的 Windows 目標進行直接記憶體存取與檢查。它提供可設定的裝置初始化、依名稱或 PID 附加程序、含 scatter 批次與 frame 快取的嚴格型別化記憶體讀取 API、模組與符號工具、特徵碼掃描、CR3 還原、PE 傾印、登錄檔與 VFS 存取、豐富的 OS 檢查表，以及可選的輸入輪詢。專案以靜態函式庫形式交付，支援 CMake 與 Visual Studio 建置，內建 LeechCore 與 MemProcFS 標頭，並包含不需 DMA 硬體的 mock 測試。面向需要面向 FPGA 或類似 DMA 設定、用於鑑識與分析工作流程的結構化、生產導向封裝之安全研究人員、逆向工程師與遊戲安全從業者。
