StrataDMA è una libreria C++17 multipiattaforma che incapsula MemProcFS e VMMDLL per l’ispezione autorizzata tramite accesso diretto alla memoria di target Windows live da un host Windows o Linux a 64 bit. Offre inizializzazione dispositivo configurabile, collegamento ai processi per nome o PID, API di lettura memoria tipizzate rigorose con batch scatter e caching per frame, strumenti moduli e simboli, scansione firme, recupero CR3, dump PE, accesso a registro e VFS, tabelle ricche di ispezione OS e polling input opzionale. Il progetto è distribuito come libreria statica con build CMake e Visual Studio, include header LeechCore e MemProcFS e test basati su mock che non richiedono hardware DMA. È rivolto a ricercatori di sicurezza, reverse engineer e professionisti della sicurezza dei giochi che necessitano di una facciata strutturata e orientata alla produzione sopra configurazioni DMA FPGA o simili per workflow forensi e di analisi.
