StrataDMA es una biblioteca C++17 multiplataforma que envuelve MemProcFS y VMMDLL para la inspección autorizada mediante acceso directo a memoria de objetivos Windows en vivo desde un host Windows o Linux de 64 bits. Ofrece inicialización de dispositivo configurable, adjunción de procesos por nombre o PID, API estrictas de lectura de memoria tipadas con lotes scatter y caché por fotograma, herramientas de módulos y símbolos, escaneo de firmas, recuperación de CR3, volcado PE, acceso al registro y al VFS, tablas ricas de inspección del SO y sondeo de entrada opcional. El proyecto se distribuye como biblioteca estática con builds CMake y Visual Studio, incluye cabeceras de LeechCore y MemProcFS, y pruebas respaldadas por mocks que no requieren hardware DMA. Está dirigido a investigadores de seguridad, ingenieros inversos y profesionales de seguridad en juegos que necesitan una fachada estructurada y orientada a producción sobre configuraciones DMA FPGA o similares para flujos forenses y de análisis.
