StrataDMA は MemProcFS と VMMDLL をラップするクロスプラットフォームの C++17 ライブラリで、64 ビット Windows または Linux ホストから、許可されたライブ Windows ターゲットへの直接メモリアクセス検査を行います。設定可能なデバイス初期化、名前または PID によるプロセス接続、scatter バッチとフレームキャッシュ付きの厳密な型付きメモリ読み取り API、モジュールとシンボルツール、シグネチャスキャン、CR3 復元、PE ダンプ、レジストリと VFS アクセス、豊富な OS 検査テーブル、任意の入力ポーリングを提供します。プロジェクトは静的ライブラリとして CMake と Visual Studio ビルドで提供され、LeechCore と MemProcFS ヘッダを同梱し、DMA ハードウェアを必要としないモックベースのテストを含みます。フォレンジックおよび分析ワークフロー向けに FPGA や類似の DMA 構成の上に構造化された本番向けファサードを必要とするセキュリティ研究者、リバースエンジニア、ゲームセキュリティ実務者を対象としています。
