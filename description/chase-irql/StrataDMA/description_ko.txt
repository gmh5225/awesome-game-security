StrataDMA는 MemProcFS와 VMMDLL을 감싸는 크로스 플랫폼 C++17 라이브러리로, 64비트 Windows 또는 Linux 호스트에서 승인된 라이브 Windows 대상에 대한 직접 메모리 접근 검사를 수행합니다. 구성 가능한 장치 초기화, 이름 또는 PID로 프로세스 연결, scatter 배치 및 프레임 캐싱이 있는 엄격한 타입화 메모리 읽기 API, 모듈 및 심볼 도구, 시그니처 스캔, CR3 복구, PE 덤프, 레지스트리 및 VFS 접근, 풍부한 OS 검사 테이블, 선택적 입력 폴링을 제공합니다. 프로젝트는 CMake 및 Visual Studio 빌드로 정적 라이브러리 형태로 제공되며 LeechCore와 MemProcFS 헤더를 포함하고, DMA 하드웨어가 필요 없는 mock 기반 테스트를 포함합니다. 포렌식 및 분석 워크플로를 위해 FPGA 또는 유사 DMA 구성 위에 구조화되고 프로덕션 지향적인 파사드를 필요로 하는 보안 연구자, 리버스 엔지니어, 게임 보안 실무자를 대상으로 합니다.
