StrataDMA 是一款跨平台 C++17 库，封装 MemProcFS 与 VMMDLL，用于在经授权的 64 位 Windows 或 Linux 主机上对运行中的 Windows 目标进行直接内存访问与检查。它提供可配置的设备初始化、按名称或 PID 附加进程、带 scatter 批量与帧缓存的严格类型化内存读取 API、模块与符号工具、特征码扫描、CR3 恢复、PE 转储、注册表与 VFS 访问、丰富的 OS 检查表，以及可选的输入轮询。项目以静态库形式交付，支持 CMake 与 Visual Studio 构建，内置 LeechCore 与 MemProcFS 头文件，并包含不依赖 DMA 硬件的 mock 测试。面向需要面向 FPGA 或类似 DMA 配置、用于取证与分析工作流的结构化、生产级封装的安全研究人员、逆向工程师与游戏安全从业者。
