Treb3rAntiCheater is a high-performance Paper Minecraft server plugin that combines anti-ESP occlusion, packet-level anti-xray, and anti-freecam defenses in one package. Written in Java for Paper 1.21.x, it uses voxel ray marching and multi-tier perimeter sampling to hide entities behind walls while preserving vanilla nametags through TextDisplay when appropriate. Its anti-xray engine injects into Paper’s chunk packet controller via reflection to obfuscate or mask underground ores in outgoing chunk packets without editing paper-world.yml. A separate anti-freecam module periodically forces client camera sync with NMS packets and blocks interactions through walls beyond configured reach. It targets server operators who need server-side cheat mitigation for wallhack, x-ray, and freecam on survival multiplayer worlds.
