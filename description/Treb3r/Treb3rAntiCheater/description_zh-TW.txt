Treb3rAntiCheater 是一款高效能的 Paper Minecraft 伺服器外掛，將反 ESP 遮擋、封包層級反 X 光與反自由視角防護整合於單一套件。以 Java 撰寫，適用 Paper 1.21.x，採用體素光線步進與多層周界取樣，在牆後隱藏實體，並在適當時透過 TextDisplay 保留原版名稱標籤。其反 X 光引擎透過反射注入 Paper 的區塊封包控制器，在送出的區塊封包中對地下礦石進行混淆或遮蔽，無需編輯 paper-world.yml。獨立的反自由視角模組會定期以 NMS 封包強制客戶端相機同步，並阻擋超出設定攻擊距離時的穿牆互動。面向需要在生存多人世界中以伺服器端方式緩解透視、X 光與自由視角作弊的伺服器營運者。
