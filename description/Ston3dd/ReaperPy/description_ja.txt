ReaperPy は、ps5debug-NG ペイロード経由で jailbreak 済み PlayStation 5 に接続し、同一ネットワーク上の PC から Cheat Engine 風のメモリスキャン、パッチ、デバッグを提供する Python デスクトップツールキットです。Keystone でアセンブルした x86-64 コードケーブ、ポインタスキャン、ハードウェアウォッチポイント、Capstone によるライブ hex と逆アセンブリ表示、書き込みを取り消せるジャーナルをサポートします。Unreal Engine と Unity IL2CPP のワークフローでは、ライブオブジェクトブラウジング、SDK 駆動のチートメニュー、dumper 出力を利用する静的解析ヘルパーを含みます。スクリプトは組み込み ps5 API でコンソールを操作でき、パッチは GoldHEN および etaHEN のチート形式（JSON、SHN、暗号化 MC4 を含む）としてエクスポートまたはインポートできます。本プロジェクトは、オンラインアンチチート回避ではなく、自身のハードウェア上での深いインプロセス検査、トレーナー開発、オフラインシングルプレイ実験を必要とする研究者や mod 作者を対象としています。
