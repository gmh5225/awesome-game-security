ReaperPy is a Python desktop toolkit that connects to a jailbroken PlayStation 5 through the ps5debug-NG payload and provides Cheat Engine-style memory scanning, patching, and debugging from a PC on the same network. It supports byte patches and x86-64 code caves assembled with Keystone, pointer scanning, hardware watchpoints, live hex and disassembly views via Capstone, and a journal that can undo writes. Unreal Engine and Unity IL2CPP workflows include live object browsing, SDK-driven cheat menus, and static analysis helpers that consume dumper output. Scripts can drive the console through a built-in ps5 API, and patches can be exported or imported as GoldHEN and etaHEN cheat formats including JSON, SHN, and encrypted MC4. The project targets researchers and mod authors who need deep in-process inspection, trainer development, and offline single-player experimentation on their own hardware rather than online anti-cheat bypasses.
