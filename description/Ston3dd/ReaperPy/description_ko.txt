ReaperPy는 ps5debug-NG 페이로드를 통해 탈옥된 PlayStation 5에 연결하고, 같은 네트워크의 PC에서 Cheat Engine 스타일의 메모리 스캔, 패치, 디버깅을 제공하는 Python 데스크톱 툴킷입니다. Keystone으로 조립한 x86-64 코드 케이브, 포인터 스캔, 하드웨어 워치포인트, Capstone을 통한 실시간 hex 및 디스어셈블리 뷰, 쓰기를 되돌릴 수 있는 저널을 지원합니다. Unreal Engine 및 Unity IL2CPP 워크플로에는 라이브 객체 탐색, SDK 기반 치트 메뉴, dumper 출력을 소비하는 정적 분석 헬퍼가 포함됩니다. 스크립트는 내장 ps5 API로 콘솔을 제어할 수 있으며, 패치는 JSON, SHN, 암호화 MC4를 포함한 GoldHEN 및 etaHEN 치트 형식으로 내보내거나 가져올 수 있습니다. 이 프로젝트는 온라인 안티치트 우회가 아니라, 자신의 하드웨어에서 깊은 인프로세스 검사, 트레이너 개발, 오프라인 싱글플레이 실험이 필요한 연구자와 mod 제작자를 대상으로 합니다.
