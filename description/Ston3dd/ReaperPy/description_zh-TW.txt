ReaperPy 是一款 Python 桌面工具套件，透過 ps5debug-NG 載荷連接已越獄的 PlayStation 5，並在同一網路的 PC 上提供類似 Cheat Engine 的記憶體掃描、修補與除錯功能。它支援位元組修補以及以 Keystone 組裝的 x86-64 程式碼洞、指標掃描、硬體監視點、透過 Capstone 的即時十六進位與反組譯檢視，以及可復原寫入的日誌。Unreal Engine 與 Unity IL2CPP 工作流程包含即時物件瀏覽、由 SDK 驅動的作弊選單，以及消費 dumper 輸出的靜態分析輔助工具。腳本可透過內建 ps5 API 驅動主機，修補可匯出或匯入為 GoldHEN 與 etaHEN 作弊格式，包括 JSON、SHN 及加密的 MC4。本專案面向需要在自有硬體上進行深度行程內檢查、訓練器開發與離線單人實驗的研究者與模組作者，而非線上反作弊繞過。
