ReaperPy è un toolkit desktop Python che si connette a una PlayStation 5 jailbreakata tramite il payload ps5debug-NG e offre da un PC sulla stessa rete scansione memoria, patching e debug in stile Cheat Engine. Supporta patch di byte e code cave x86-64 assemblate con Keystone, scansione di puntatori, watchpoint hardware, viste hex e disassembly live via Capstone e un journal che può annullare le scritture. I flussi Unreal Engine e Unity IL2CPP includono browsing di oggetti live, menu cheat guidati da SDK e helper di analisi statica che consumano l’output dei dumper. Gli script possono controllare la console tramite un’API ps5 integrata e le patch possono essere esportate o importate nei formati cheat GoldHEN ed etaHEN, inclusi JSON, SHN e MC4 crittografato. Il progetto è rivolto a ricercatori e autori di mod che necessitano di ispezione in-process approfondita, sviluppo di trainer e sperimentazione offline single-player sul proprio hardware, piuttosto che aggirare l’anti-cheat online.
