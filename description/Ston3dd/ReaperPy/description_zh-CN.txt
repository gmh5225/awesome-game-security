ReaperPy 是一款 Python 桌面工具包，通过 ps5debug-NG 载荷连接已越狱的 PlayStation 5，并在同一网络的 PC 上提供类似 Cheat Engine 的内存扫描、补丁与调试功能。它支持字节补丁以及用 Keystone 组装的 x86-64 代码洞、指针扫描、硬件监视点、通过 Capstone 实现的实时十六进制与反汇编视图，以及可撤销写入的日志。Unreal Engine 与 Unity IL2CPP 工作流包括实时对象浏览、由 SDK 驱动的作弊菜单，以及消费 dumper 输出的静态分析辅助工具。脚本可通过内置 ps5 API 驱动主机，补丁可导出或导入为 GoldHEN 与 etaHEN 作弊格式，包括 JSON、SHN 及加密的 MC4。本项目面向需要在自有硬件上进行深度进程内检查、训练器开发与离线单人实验的研究者与模组作者，而非在线反作弊绕过。
