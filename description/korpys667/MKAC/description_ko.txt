MKAC는 Paper 및 Folia Minecraft 서버용 무료 오픈소스 전투 안티치트 플러그인으로, 머신러닝을 통해 플레이어 입력 패턴에서 killaura, aim assist 같은 조준 관련 치트를 표시합니다. 주로 Kotlin으로 구현되었으며 Java 21을 대상으로 하는 Gradle 빌드를 사용하고, 패킷 수준 검사, 위반 로깅, 구성 가능한 처벌, 선택적 SQLite·MySQL·Redis 기반 저장 및 크로스 서버 알림을 결합합니다. 운영자는 플러그인을 호스팅된 추론 API에 연결하고 YAML 설정을 조정하며, 게임 내 명령으로 실시간 모니터링, 의심 행위 검토, 데이터 수집, 스태프 알림을 사용할 수 있습니다. 본 프로젝트는 전통적인 시그니처 전용 클라이언트 모드 차단기가 아니라 AI 보조 전투 중심 억제를 원하는 멀티플레이 서버 운영자와 안티치트 연구자에게 적합합니다.
