MKAC è un plugin anti-cheat da combattimento gratuito e open source per server Minecraft Paper e Folia che usa il machine learning per segnalare cheat legati alla mira, come killaura e aim assist, a partire dai pattern di input dei giocatori. È implementato principalmente in Kotlin con una build Gradle per Java 21 e combina controlli a livello di pacchetti, registrazione delle violazioni, punizioni configurabili e archiviazione opzionale con SQLite, MySQL o Redis, oltre ad avvisi cross-server. Gli operatori collegano il plugin a un’API di inferenza ospitata, regolano la configurazione YAML e usano comandi in-game per monitoraggio live, revisione dei sospetti, raccolta dati e alert per lo staff. Il progetto è adatto a proprietari di server multigiocatore e ricercatori anti-cheat che desiderano un deterrente focalizzato sul combattimento assistito dall’IA piuttosto che un tradizionale blocco di mod client basato solo su firme.
