MKAC は Paper および Folia 向け Minecraft サーバー用の無料オープンソース戦闘アンチチートプラグインで、機械学習によりプレイヤーの入力パターンから killaura や aim assist など照準系チートを検出します。主に Kotlin で実装され、Java 21 をターゲットとする Gradle ビルドを採用し、パケットレベルの検査、違反ログ、設定可能な処罰、および任意の SQLite・MySQL・Redis バックエンドによるストレージとクロスサーバー通知を組み合わせています。運用者はプラグインをホスト型推論 API に接続し、YAML 設定を調整し、ゲーム内コマンドでライブ監視、疑わしい行為の確認、データ収集、スタッフ向けアラートを行えます。本プロジェクトは、従来のシグネチャのみのクライアント MOD ブロックではなく、AI 支援の戦闘特化型抑止を望むマルチプレイサーバー運営者やアンチチート研究者向けです。
