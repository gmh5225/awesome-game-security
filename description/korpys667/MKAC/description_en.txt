MKAC is a free, open-source combat anti-cheat plugin for Paper and Folia Minecraft servers that uses machine learning to flag aim-related cheats such as killaura and aim assist from player input patterns. It is implemented primarily in Kotlin with a Gradle build targeting Java 21, and combines packet-level checks, violation logging, configurable punishments, and optional SQLite, MySQL, or Redis-backed storage and cross-server alerting. Operators connect the plugin to a hosted inference API, tune YAML configuration, and use in-game commands for live monitoring, suspicion review, data collection, and staff alerts. The project suits multiplayer server owners and anti-cheat researchers who want an AI-assisted, combat-focused deterrent rather than a traditional signature-only client mod blocker.
