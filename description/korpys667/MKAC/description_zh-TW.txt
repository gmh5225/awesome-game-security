MKAC 是一款面向 Paper 與 Folia Minecraft 伺服器的免費開源戰鬥反作弊外掛，透過機器學習依玩家輸入模式標記 Killaura、自瞄等瞄準相關作弊行為。專案主要以 Kotlin 實作，採用目標為 Java 21 的 Gradle 建置，並整合封包層級檢查、違規記錄、可設定處罰，以及可選的 SQLite、MySQL 或 Redis 儲存與跨伺服器告警。營運者可將外掛連接至託管推論 API、調整 YAML 設定，並使用遊戲內指令進行即時監控、嫌疑審查、資料收集與工作人員告警。本專案適合希望採用 AI 輔助、聚焦戰鬥威懾的多人伺服器擁有者與反作弊研究人員，而非傳統僅依特徵簽名的客戶端模組阻擋方案。
