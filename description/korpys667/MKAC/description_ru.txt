MKAC — бесплатный open-source плагин античита для боёвки на серверах Minecraft Paper и Folia, который с помощью машинного обучения помечает читы, связанные с прицеливанием (killaura, aim assist и т. п.), по паттернам ввода игрока. Реализован в основном на Kotlin, сборка через Gradle под Java 21; сочетает проверки на уровне пакетов, журналирование нарушений, настраиваемые наказания, а также опциональное хранение в SQLite, MySQL или Redis и межсерверные оповещения. Администраторы подключают плагин к размещённому API инференса, настраивают YAML и используют внутриигровые команды для мониторинга в реальном времени, проверки подозрений, сбора данных и оповещения персонала. Проект подходит владельцам мультиплеерных серверов и исследователям античита, которым нужен ИИ-усиленный боевой сдерживающий механизм, а не классическая блокировка клиентских модов только по сигнатурам.
