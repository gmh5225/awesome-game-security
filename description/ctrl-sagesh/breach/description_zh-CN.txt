BREACH 是一款基于浏览器的黑客终端游戏，玩家接受自由职业任务以渗透模拟网络，并在安全、虚构的环境中练习真实的进攻性安全概念。项目采用 Next.js 与 TypeScript 构建，提供具备补全、管道与命令历史等功能的 Kali 风格 Shell，以及剧情战役、每日挑战、成就与复盘，将谜题与现实中的常见失误（弱凭据、不良哈希、SQL 注入等）相联系。排行榜的公正性依赖服务端回放：客户端仅提交命令日志与时间戳，Supabase Edge Functions 会重新运行同一确定性游戏引擎来评分并拒绝不合理或遭篡改的提交。该项目面向希望动手进行渗透式解题、又不必接触真实系统的学习者与安全爱好者，并对任务、回放校验与反作弊逻辑提供广泛的 Vitest 测试覆盖。
