BREACH is a browser-based hacking terminal game where players take freelance missions to breach simulated networks and practice real offensive security concepts in a safe, fictional environment. Built with Next.js and TypeScript, it offers a Kali-style shell with completion, piping, and command history, plus a story campaign, daily challenges, achievements, and debriefs that tie puzzles to real-world mistakes such as weak credentials, bad hashing, and SQL injection. Leaderboard integrity relies on server-side replay: the client sends only command logs and timing, and Supabase Edge Functions re-run the same deterministic game engine to score runs and reject implausible or tampered submissions. The project is aimed at learners and security enthusiasts who want hands-on penetration-style problem solving without touching real systems, and it includes extensive Vitest coverage of missions, replay validation, and anti-cheat logic.
