BREACH 是一款以瀏覽器為基礎的黑客終端遊戲，玩家承接自由接案任務以入侵模擬網路，並在安全、虛構的環境中練習真實的攻擊性安全概念。專案以 Next.js 與 TypeScript 建構，提供具備補全、管線與命令歷史等功能的 Kali 風格 Shell，以及劇情戰役、每日挑戰、成就與檢討，將謎題與現實中的常見錯誤（弱憑證、不良雜湊、SQL 注入等）相連結。排行榜的公信力仰賴伺服器端重播：用戶端僅傳送命令記錄與時間，Supabase Edge Functions 會重新執行同一套確定性遊戲引擎來計分，並拒絕不合理或遭竄改的提交。本專案面向希望動手進行滲透式解題、又不必接觸真實系統的學習者與安全愛好者，並對任務、重播驗證與反作弊邏輯提供廣泛的 Vitest 測試覆蓋。
