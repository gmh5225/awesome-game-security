BREACH는 브라우저 기반 해킹 터미널 게임으로, 플레이어가 프리랜스 미션을 수행하며 시뮬레이션 네트워크를 침투하고 안전한 가상 환경에서 실제 공격적 보안 개념을 연습할 수 있습니다. Next.js와 TypeScript로 제작되었으며, 자동 완성·파이프·명령 기록을 갖춘 Kali 스타일 셸과 스토리 캠페인, 일일 챌린지, 업적, 약한 자격 증명·잘못된 해싱·SQL 인젝션 같은 실제 실수와 연결되는 디브리핑을 제공합니다. 리더보드 무결성은 서버 측 리플레이에 의존하며, 클라이언트는 명령 로그와 타이밍만 전송하고 Supabase Edge Functions가 동일한 결정론적 게임 엔진을 재실행해 점수를 매기고 비현실적이거나 변조된 제출을 거부합니다. 본 프로젝트는 실제 시스템을 건드리지 않고 침투 테스트형 문제 해결을 직접 해보고 싶은 학습자와 보안 애호가를 대상으로 하며, 미션·리플레이 검증·안티치트 로직에 대한 광범위한 Vitest 테스트 커버리지를 포함합니다.
