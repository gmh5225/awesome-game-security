This project documents research on obfuscating game cheating by using DMA-capable FPGA hardware to read a target game's memory from an external host instead of running cheat code on the game PC. It focuses on the Valve title Deadlock, pulling entity-related data off the machine and visualizing it on a minimap overlay. The approach highlights how direct memory access boards can bypass conventional in-process anti-cheat and software instrumentation. The repository is primarily explanatory material rather than a full software stack, and it is aimed at game security researchers studying hardware-assisted cheating, external memory acquisition, and anti-cheat evasion techniques.
