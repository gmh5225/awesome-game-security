이 프로젝트는 게임 PC에서 치트 코드를 실행하는 대신 DMA 지원 FPGA 하드웨어로 외부 호스트에서 대상 게임 메모리를 읽어 게임 치팅을 난독화하는 연구를 문서화합니다. Valve 타이틀 Deadlock에 초점을 맞추어 엔티티 관련 데이터를 머신에서 가져와 미니맵 오버레이로 시각화합니다. 이 접근 방식은 직접 메모리 액세스 보드가 기존의 프로세스 내 안티치트 및 소프트웨어 계측을 우회할 수 있음을 보여 줍니다. 저장소는 완전한 소프트웨어 스택보다는 주로 설명 자료이며, 하드웨어 지원 치팅, 외부 메모리 획득, 안티치트 회피 기법을 연구하는 게임 보안 연구자를 대상으로 합니다.
