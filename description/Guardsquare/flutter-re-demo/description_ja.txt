このリポジトリは、Flutter モバイルアプリケーションのリバースエンジニアリングに関する研究実験を再現するためのスクリプトとサンプル資料を提供します。reFlutter または DWARF デバッグ出力の解析、Dart 関数のリネーム、Flutter VM メモリダンプのインポート、Dart オブジェクト構造の作成、クロスリファレンスの追加、スタックポインタのパッチ適用とマイクロコードフックによる逆コンパイルの改善などを行う IDA Pro 向け Python ツールを含みます。Frida スクリプトで実行時の Flutter メモリを取得でき、Flutter ゲーム由来の難読化済みおよび非難読化のサンプル APK により実践的なテストが可能です。本プロジェクトは、Flutter アプリ保護、Dart 逆コンパイルの課題、静的・動的解析に対する難読化の限界を研究するセキュリティ研究者を対象としています。
