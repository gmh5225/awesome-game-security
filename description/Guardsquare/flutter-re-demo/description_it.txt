Questo repository fornisce script e materiali di esempio per riprodurre esperimenti di ricerca sull'ingegneria inversa di applicazioni mobili Flutter. Include strumenti Python per IDA Pro che analizzano l'output di debug di reFlutter o DWARF, rinominano le funzioni Dart, importano dump di memoria della VM Flutter, creano strutture di oggetti Dart, aggiungono riferimenti incrociati e migliorano la decompilazione tramite patch del puntatore allo stack e hook al microcodice. Uno script Frida cattura la memoria Flutter a runtime, e APK di esempio offuscati e non offuscati di un gioco Flutter supportano test pratici. Il progetto è rivolto a ricercatori di sicurezza che studiano la protezione delle app Flutter, le sfide della decompilazione Dart e i limiti dell'offuscamento rispetto all'analisi statica e dinamica.
