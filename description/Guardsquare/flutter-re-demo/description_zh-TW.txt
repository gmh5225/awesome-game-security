本儲存庫提供腳本與範例材料，用於重現針對 Flutter 行動應用程式逆向工程的研究實驗。其中包含面向 IDA Pro 的 Python 工具，可解析 reFlutter 或 DWARF 除錯輸出、重新命名 Dart 函式、匯入 Flutter VM 記憶體傾印、建立 Dart 物件結構、新增交叉參考，並透過堆疊指標修補與微碼掛鉤改善反編譯效果。Frida 腳本用於擷取執行時期的 Flutter 記憶體，來自某 Flutter 遊戲的混淆與非混淆範例 APK 則便於實際測試。本專案面向研究 Flutter 應用程式防護、Dart 反編譯難題，以及混淆在靜態與動態分析面前局限性的資安研究人員。
