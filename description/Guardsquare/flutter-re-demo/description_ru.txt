Этот репозиторий предоставляет скрипты и примеры материалов для воспроизведения исследовательских экспериментов по реверс-инжинирингу мобильных приложений Flutter. В него входят Python-инструменты для IDA Pro, которые разбирают отладочный вывод reFlutter или DWARF, переименовывают функции Dart, импортируют дампы памяти Flutter VM, создают структуры объектов Dart, добавляют перекрёстные ссылки и улучшают декомпиляцию с помощью патчинга указателя стека и хуков микрокода. Скрипт Frida захватывает память Flutter во время выполнения, а примеры обфусцированных и необфусцированных APK из Flutter-игры позволяют проводить практические тесты. Проект предназначен для исследователей безопасности, изучающих защиту приложений Flutter, трудности декомпиляции Dart и пределы обфускации при статическом и динамическом анализе.
