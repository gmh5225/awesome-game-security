이 저장소는 Flutter 모바일 애플리케이션 리버스 엔지니어링 연구 실험을 재현하기 위한 스크립트와 샘플 자료를 제공합니다. reFlutter 또는 DWARF 디버그 출력을 파싱하고, Dart 함수 이름을 변경하며, Flutter VM 메모리 덤프를 가져오고, Dart 객체 구조를 생성하고, 교차 참조를 추가하며, 스택 포인터 패치와 마이크로코드 훅을 통해 디컴파일을 개선하는 IDA Pro용 Python 도구를 포함합니다. Frida 스크립트는 런타임 Flutter 메모리를 캡처하며, Flutter 게임의 난독화 및 비난독화 샘플 APK가 실습 테스트를 지원합니다. 이 프로젝트는 Flutter 앱 보호, Dart 디컴파일의 어려움, 정적 및 동적 분석에 대한 난독화의 한계를 연구하는 보안 연구자를 대상으로 합니다.
