PasVulkan 是面向 Object Pascal 的 Vulkan 头文件生成器及面向对象 Vulkan API 封装与框架，支持 Free Pascal 与现代 Delphi。它通过 vkxml2pas 提供自动生成的 C 风格 Vulkan.pas 绑定，并包含用于内存管理、原生纹理与字体加载、精灵图集及相关 Vulkan 工具的 OOP 框架单元。基于 SDL 2 的应用层负责交换链设置、表面恢复，以及 Windows、Linux 与 Android 上的跨平台窗口，并可选通过 MoltenVK 支持 Apple 平台。主要用途是在不依赖 VCL、LCL 或外部图像库的前提下，用 Object Pascal 构建基于 Vulkan 的游戏与图形应用。
