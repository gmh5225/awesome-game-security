PasVulkan 是面向 Object Pascal 的 Vulkan 標頭檔產生器及物件導向 Vulkan API 封裝與框架，支援 Free Pascal 與現代 Delphi。它透過 vkxml2pas 提供自動產生的 C 風格 Vulkan.pas 繫結，並包含用於記憶體管理、原生紋理與字型載入、精靈圖集及相關 Vulkan 工具的 OOP 框架單元。基於 SDL 2 的應用層負責交換鏈設定、表面復原，以及 Windows、Linux 與 Android 上的跨平台視窗，並可選透過 MoltenVK 支援 Apple 平台。主要用途是在不依賴 VCL、LCL 或外部影像函式庫的前提下，用 Object Pascal 建構基於 Vulkan 的遊戲與圖形應用。
