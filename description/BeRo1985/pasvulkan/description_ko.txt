PasVulkan은 Object Pascal을 위한 Vulkan 헤더 생성기이자 객체 지향 Vulkan API 래퍼 및 프레임워크로, Free Pascal과 최신 Delphi를 대상으로 합니다. vkxml2pas를 통해 자동 생성된 C 스타일 Vulkan.pas 바인딩과 함께 메모리 관리, 네이티브 텍스처·폰트 로더, 스프라이트 아틀라스 및 관련 Vulkan 유틸리티용 OOP 프레임워크 유닛을 제공합니다. SDL 2 기반 애플리케이션 계층이 스왑 체인 설정, 서피스 복구, Windows·Linux·Android의 크로스 플랫폼 윈도잉을 처리하며, Apple 플랫폼용으로 선택적 MoltenVK 경로도 지원합니다. 주요 용도는 VCL, LCL 또는 외부 이미지 라이브러리에 의존하지 않고 Object Pascal로 Vulkan 기반 게임 및 그래픽 애플리케이션을 구축하는 것입니다.
