PasVulkan es un generador de encabezados Vulkan y un wrapper y framework orientados a objetos de la API Vulkan para Object Pascal, orientado a Free Pascal y Delphi moderno. Proporciona un binding Vulkan.pas de estilo C generado automáticamente mediante vkxml2pas, además de unidades de framework OOP para gestión de memoria, cargadores nativos de texturas y fuentes, atlas de sprites y utilidades Vulkan relacionadas. Una capa de aplicación basada en SDL 2 gestiona la configuración del swap-chain, la recuperación de superficies y el ventanado multiplataforma en Windows, Linux y Android, con rutas MoltenVK opcionales para plataformas Apple. Su uso principal es crear juegos y aplicaciones gráficas basadas en Vulkan en Object Pascal sin depender de VCL, LCL ni bibliotecas de imágenes externas.
