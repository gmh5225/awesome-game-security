PasVulkan — генератор заголовков Vulkan и объектно-ориентированная обёртка и фреймворк API Vulkan для Object Pascal, рассчитанные на Free Pascal и современный Delphi. Он предоставляет автоматически сгенерированную C-подобную привязку Vulkan.pas через vkxml2pas, а также OOP-модули фреймворка для управления памятью, нативных загрузчиков текстур и шрифтов, спрайтовых атласов и связанных утилит Vulkan. Прикладной слой на базе SDL 2 отвечает за настройку swap-chain, восстановление поверхности и кроссплатформенное оконное управление в Windows, Linux и Android, с опциональными путями MoltenVK для платформ Apple. Основное назначение — создание игр и графических приложений на Vulkan на Object Pascal без зависимости от VCL, LCL или внешних библиотек изображений.
