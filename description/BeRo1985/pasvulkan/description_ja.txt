PasVulkan は、Object Pascal 向けの Vulkan ヘッダー生成器およびオブジェクト指向 Vulkan API ラッパー／フレームワークで、Free Pascal と最新の Delphi を対象とします。vkxml2pas による自動生成の C スタイル Vulkan.pas バインディングに加え、メモリ管理、ネイティブなテクスチャ／フォントローダー、スプライトアトラス、関連 Vulkan ユーティリティ用の OOP フレームワークユニットを提供します。SDL 2 ベースのアプリケーション層がスワップチェーン設定、サーフェス復旧、Windows／Linux／Android のクロスプラットフォームウィンドウ処理を担い、Apple 向けには任意で MoltenVK パスも利用できます。主な用途は、VCL・LCL・外部画像ライブラリに依存せず、Object Pascal で Vulkan ベースのゲームやグラフィックスアプリケーションを構築することです。
