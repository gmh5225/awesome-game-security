本專案是針對 Windows 核心與使用者模式 3D 圖形堆疊的建置與驗證框架，設計在 QEMU/KVM 虛擬機中執行，支援硬體加速 GPU 直通以及 virtio/virgl 主機整合。它透過交叉編譯工具鏈、Shell 與 Python 封裝腳本以及以 Docker 為基礎的建置環境，組裝已簽署的顯示驅動程式、Mesa OpenGL、D3D12 元件與 Vulkan SDK 片段，大部分執行階段程式碼為 C 與 C++。儲存庫包含針對 Windows 10 與 11、在 AMD 與 NVIDIA 主機上執行的廣泛自動化驗收與相容性證據，涵蓋 Direct3D 9 至 12、OpenGL 與 Vulkan，透過探測、基準測試與商業遊戲工作負載進行驗證，並包含對 fence 時序、DMA 延遲、DWM 堆積使用、dmabuf 共享以及安全開機下驅動程式固定等實驗。面向需要可重現、隔離的 Windows 圖形實驗環境以大規模研究遊戲、核心驅動程式與虛擬化 GPU 行為的遊戲安全研究人員、逆向工程師與反作弊開發者。
