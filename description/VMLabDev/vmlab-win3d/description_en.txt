This project is a build and validation framework for a Windows kernel- and user-mode 3D graphics stack designed to run in QEMU/KVM virtual machines with hardware-accelerated GPU passthrough and virtio/virgl host integration. It assembles signed display drivers, Mesa OpenGL, D3D12 components, and Vulkan SDK pieces using cross-compilation toolchains, shell and Python packaging scripts, and Docker-based build environments, with most runtime code in C and C++. The repository includes extensive automated acceptance and compatibility evidence for Windows 10 and 11 on AMD and NVIDIA hosts, covering Direct3D 9 through 12, OpenGL, and Vulkan via probes, benchmarks, and commercial game workloads, plus experiments on fence timing, DMA latency, DWM heap usage, dmabuf sharing, and driver pinning under secure boot. It is aimed at game security researchers, reverse engineers, and anti-cheat developers who need reproducible, isolated Windows graphics labs to study titles, kernel drivers, and virtualized GPU behavior at scale.
