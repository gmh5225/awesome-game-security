本项目是针对 Windows 内核与用户态 3D 图形栈的构建与验证框架，设计在 QEMU/KVM 虚拟机中运行，支持硬件加速 GPU 直通以及 virtio/virgl 主机集成。它通过交叉编译工具链、Shell 与 Python 打包脚本以及基于 Docker 的构建环境，组装已签名的显示驱动、Mesa OpenGL、D3D12 组件和 Vulkan SDK 片段，大部分运行时代码为 C 与 C++。仓库包含针对 Windows 10 与 11、在 AMD 与 NVIDIA 主机上运行的广泛自动化验收与兼容性证据，涵盖 Direct3D 9 至 12、OpenGL 与 Vulkan，通过探测、基准测试与商业游戏负载进行验证，并包含对 fence 时序、DMA 延迟、DWM 堆使用、dmabuf 共享以及安全启动下驱动固定等实验。面向需要可复现、隔离的 Windows 图形实验环境以大规模研究游戏、内核驱动与虚拟化 GPU 行为的游戏安全研究人员、逆向工程师与反作弊开发者。
