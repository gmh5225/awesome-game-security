Этот проект — фреймворк сборки и проверки для стека 3D-графики Windows в режимах ядра и пользователя, рассчитанный на работу в виртуальных машинах QEMU/KVM с аппаратным ускорением GPU passthrough и интеграцией хоста virtio/virgl. Он собирает подписанные дисплейные драйверы, Mesa OpenGL, компоненты D3D12 и части Vulkan SDK с помощью кросс-компиляционных toolchain, shell- и Python-скриптов упаковки и Docker-сред сборки; большая часть runtime-кода на C и C++. Репозиторий содержит обширные автоматизированные доказательства приёмки и совместимости для Windows 10 и 11 на хостах AMD и NVIDIA: Direct3D 9–12, OpenGL и Vulkan через пробы, бенчмарки и нагрузки коммерческих игр, а также эксперименты с таймингом fence, задержкой DMA, использованием кучи DWM, разделением dmabuf и закреплением драйверов при Secure Boot. Ориентирован на исследователей безопасности игр, reverse-инженеров и разработчиков античита, которым нужны воспроизводимые изолированные графические лаборатории Windows для изучения игр, драйверов ядра и поведения виртуализированного GPU в масштабе.
