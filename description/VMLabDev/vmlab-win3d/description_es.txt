Este proyecto es un marco de compilación y validación para una pila gráfica 3D de Windows en modo kernel y usuario, diseñada para ejecutarse en máquinas virtuales QEMU/KVM con passthrough de GPU acelerado por hardware e integración de host virtio/virgl. Ensambla controladores de pantalla firmados, Mesa OpenGL, componentes D3D12 y piezas del Vulkan SDK mediante cadenas de herramientas de compilación cruzada, scripts de empaquetado en shell y Python, y entornos de compilación basados en Docker, con la mayor parte del código en tiempo de ejecución en C y C++. El repositorio incluye amplia evidencia automatizada de aceptación y compatibilidad para Windows 10 y 11 en hosts AMD y NVIDIA, cubriendo Direct3D 9 a 12, OpenGL y Vulkan mediante sondas, benchmarks y cargas de trabajo de juegos comerciales, además de experimentos sobre temporización de fences, latencia DMA, uso del heap DWM, compartición dmabuf y fijación de controladores bajo Secure Boot. Está dirigido a investigadores de seguridad en juegos, ingenieros inversos y desarrolladores de anti-cheat que necesitan laboratorios gráficos de Windows reproducibles y aislados para estudiar títulos, controladores de kernel y comportamiento de GPU virtualizada a escala.
