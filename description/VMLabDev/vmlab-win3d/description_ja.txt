本プロジェクトは、QEMU/KVM 仮想マシン上で動作し、ハードウェアアクセラレーション付き GPU パススルーおよび virtio/virgl ホスト統合を前提とした、Windows カーネル／ユーザーモード 3D グラフィックススタック向けのビルドおよび検証フレームワークです。クロスコンパイルツールチェーン、シェルおよび Python パッケージングスクリプト、Docker ベースのビルド環境を用いて、署名済みディスプレイドライバ、Mesa OpenGL、D3D12 コンポーネント、Vulkan SDK 部品を組み立て、ランタイムコードの大半は C と C++ で書かれています。リポジトリには、AMD および NVIDIA ホスト上の Windows 10/11 向けの広範な自動受入および互換性エビデンスが含まれ、Direct3D 9 から 12、OpenGL、Vulkan をプローブ、ベンチマーク、商用ゲームワークロードでカバーし、fence タイミング、DMA レイテンシ、DWM ヒープ使用、dmabuf 共有、Secure Boot 下のドライバ固定などの実験も含みます。ゲームセキュリティ研究者、リバースエンジニア、反チート開発者向けで、タイトル、カーネルドライバ、仮想化 GPU 挙動を大規模に調査するための再現可能で隔離された Windows グラフィックスラボが必要な用途を想定しています。
