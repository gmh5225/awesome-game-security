이 프로젝트는 QEMU/KVM 가상 머신에서 하드웨어 가속 GPU 패스스루 및 virtio/virgl 호스트 통합과 함께 실행되도록 설계된 Windows 커널 및 사용자 모드 3D 그래픽 스택을 위한 빌드 및 검증 프레임워크입니다. 교차 컴파일 툴체인, 셸 및 Python 패키징 스크립트, Docker 기반 빌드 환경을 사용해 서명된 디스플레이 드라이버, Mesa OpenGL, D3D12 구성 요소, Vulkan SDK 조각을 조립하며, 대부분의 런타임 코드는 C와 C++로 작성되어 있습니다. 저장소에는 AMD 및 NVIDIA 호스트에서 Windows 10과 11에 대한 광범위한 자동화된 수용 및 호환성 증거가 포함되어 Direct3D 9부터 12, OpenGL, Vulkan을 프로브, 벤치마크, 상용 게임 워크로드로 다루며, fence 타이밍, DMA 지연, DWM 힙 사용, dmabuf 공유, Secure Boot 하 드라이버 고정 등의 실험도 포함합니다. 게임 보안 연구자, 리버스 엔지니어, 안티치트 개발자를 대상으로 하며, 타이틀, 커널 드라이버, 가상화 GPU 동작을 대규모로 연구하기 위해 재현 가능하고 격리된 Windows 그래픽 랩이 필요한 경우를 위한 것입니다.
