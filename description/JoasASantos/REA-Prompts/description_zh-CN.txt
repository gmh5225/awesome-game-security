REA Investigation Prompts 是一套精选的可复制粘贴提示词库，用于引导 AI 编程代理在二进制、固件、游戏、移动应用和 Web 客户端上执行 REA（Reverse Engineer Anything，逆向分析一切）工作流。内容涵盖功能追踪、原生二进制初步分析、洁净室行为克隆、游戏逻辑与引擎映射、WASM 可移植性、内核与固件分析、漏洞研究、Electron 与 JavaScript 检查，以及防御性反作弊、DMA 与保护机制研究。提示词强调以证据为依据的回答、区分已确认事实与假设、优先静态分析，以及在安全研究、互操作性、CTF 与加固自有软件等场景下的有限负责任使用。该仓库仅为文档（Markdown），不含应用代码，面向希望获得结构化代理指令而非临时聊天提问的逆向工程师与游戏安全研究人员。
