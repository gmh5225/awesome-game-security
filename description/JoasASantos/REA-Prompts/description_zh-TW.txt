REA Investigation Prompts 是一套精選的可複製貼上提示詞庫，用於引導 AI 程式設計代理在二進位、韌體、遊戲、行動應用與 Web 用戶端上執行 REA（Reverse Engineer Anything，逆向分析一切）工作流程。內容涵蓋功能追蹤、原生二進位初步分析、潔淨室行為克隆、遊戲邏輯與引擎對應、WASM 可移植性、核心與韌體分析、漏洞研究、Electron 與 JavaScript 檢查，以及防禦性反作弊、DMA 與保護機制研究。提示詞強調以證據為依據的回答、區分已確認事實與假設、優先靜態分析，以及在安全研究、互通性、CTF 與強化自有軟體等情境下的有限負責任使用。此儲存庫僅為文件（Markdown），不含應用程式碼，面向希望取得結構化代理指令而非臨時聊天提問的逆向工程師與遊戲安全研究人員。
