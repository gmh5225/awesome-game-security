REA Investigation Prompts is a curated library of copy-paste prompts for driving AI coding agents through REA (Reverse Engineer Anything) workflows on binaries, firmware, games, mobile apps, and web clients. The collection spans feature tracing, native binary triage, clean-room behavioral cloning, game logic and engine mapping, WASM portability, kernel and firmware analysis, vulnerability research, Electron and JavaScript inspection, and defensive anti-cheat, DMA, and protection research. Prompts emphasize evidence-backed answers, separating confirmed facts from hypotheses, static analysis first, and scoped responsible use for security research, interoperability, CTFs, and hardening your own software. The repository is documentation-only (Markdown) with no application code, aimed at reverse engineers and game-security researchers who want structured agent instructions rather than ad hoc chat questions.
