REA Investigation Prompts は、バイナリ、ファームウェア、ゲーム、モバイルアプリ、Web クライアントに対する REA（Reverse Engineer Anything）ワークフローを AI コーディングエージェントに実行させるための、コピー＆ペースト可能なプロンプトを厳選したライブラリです。機能トレース、ネイティブバイナリのトリアージ、クリーンルームによる挙動クローン、ゲームロジックとエンジンマッピング、WASM の移植性、カーネルとファームウェア解析、脆弱性調査、Electron と JavaScript の検査、防御的なアンチチート・DMA・保護機構の研究などを網羅しています。プロンプトは根拠に基づく回答、確認済み事実と仮説の分離、静的解析を優先すること、およびセキュリティ研究、相互運用性、CTF、自社ソフトウェアのハードニング向けの範囲を限定した責任ある利用を重視します。本リポジトリはアプリケーションコードを含まないドキュメントのみ（Markdown）で、場当たり的なチャット質問ではなく構造化されたエージェント指示を求めるリバースエンジニアとゲームセキュリティ研究者向けです。
