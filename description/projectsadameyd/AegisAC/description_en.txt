AegisAC is a conservative, alert-first anti-cheat plugin for Paper Minecraft servers (1.21.11) that detects common client cheats through server-side event analysis rather than packet-level simulation. It is implemented in Java 21 and ships as a standard Paper plugin with checks for Speed, Fly, Timer, Reach, AutoClicker, FastPlace, and Velocity, plus combat and movement analyzers that use heuristic scores and sustained evidence before escalating. Remote block break, placement, and interaction beyond server-side reach are canceled to limit freecam-style abuse, while an optional VPN gate can reject joins using proxycheck.io during pre-login. Staff get alerts, console audit logs, and configurable staged enforcement from kicks through temporary login blocks, with optional permanent IP bans reserved for remote-interaction evidence. It targets private and public Paper server operators who want lightweight anti-cheat tooling with explicit enforcement controls and appeal-friendly sanction ladders.
