WepAC 是面向 Minecraft Spigot 與 Paper 伺服器的混合式反作弊外掛，將以規則為基礎的違規檢查與完全以 Java 訓練的自學習神經網路結合。它透過內嵌的 Netty 封包處理器檢查玩家流量，模擬移動物理以抓出細微的飛行與加速作弊，並執行涵蓋戰鬥、移動、方塊與背包的廣泛偵測，包括 KillAura、攻擊距離、自動點擊、腳手架與類 X 光行為。小型 MLP 為每位玩家評估作弊機率，個別調整檢查閾值，從處罰、管理員標註以及過濾後的合法 PvP 對局中線上學習，並在重啟後持久保存模型權重。它還會從 Minecraft 頻道握手中標記可疑客戶端品牌，並支援管理員告警、錄影與可設定的處罰。本專案面向希望在確定性遊戲安全檢查之上獲得自適應、伺服器本地機器學習的伺服器營運者與反作弊研究人員。
