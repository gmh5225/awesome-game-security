WepAC 是面向 Minecraft Spigot 与 Paper 服务器的混合式反作弊插件，将基于规则的违规检测与完全用 Java 训练的自学习神经网络相结合。它通过内嵌的 Netty 数据包处理器检查玩家流量，模拟移动物理以发现细微的飞行与加速作弊，并运行涵盖战斗、移动、方块与背包的广泛检测，包括 KillAura、攻击距离、自动点击、脚手架与类 X 光行为。小型 MLP 为每位玩家评估作弊概率，单独调整检测阈值，从处罚、管理员标注以及过滤后的合法 PvP 对局中在线学习，并在重启后持久保存模型权重。它还会从 Minecraft 频道握手中标记可疑客户端品牌，并支持管理员告警、录像与可配置的处罚。本项目面向希望在确定性游戏安全检测之上获得自适应、服务器本地机器学习的服务器运营者与反作弊研究人员。
