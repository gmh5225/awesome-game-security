FFNx is a replacement graphics and modding driver for the Windows releases of Final Fantasy VII and Final Fantasy VIII, extending the lineage of the classic FF7 OpenGL patch into a full mod platform. It is implemented primarily in C++ with CMake and hooks the games through a shared DLL that rebuilds rendering with bgfx, offering DirectX 11, DirectX 12, Vulkan, and OpenGL backends while adding modern audio, input, widescreen, and texture pipelines. Modders and researchers can inspect draws with RenderDoc, debug engine state through ImGui, apply Hext-style binary patches, redirect assets via TOML configuration, and replace hardcoded EXE data, VRAM pages, movies, music, and shaders. The project targets players and technical mod authors who need deep control over legacy Square Enix PC executables, and it is equally useful for reverse engineering and game-security study of how commercial titles are extended via injected rendering layers and in-process memory patching.
