FFNx 是面向 Windows 版《最终幻想 VII》与《最终幻想 VIII》的替代图形与模组驱动，将经典 FF7 OpenGL 补丁的脉络延伸为完整的模组平台。项目主要以 C++ 与 CMake 实现，通过共享 DLL 挂钩游戏，并用 bgfx 重建渲染，支持 DirectX 11、DirectX 12、Vulkan 与 OpenGL 后端，同时提供现代音频、输入、宽屏与纹理管线。模组作者与研究人员可用 RenderDoc 检视绘制、借 ImGui 调试引擎状态、应用 Hext 式二进制补丁、通过 TOML 配置重定向资源，并替换硬编码的 EXE 数据、VRAM 页、影片、音乐与着色器。本项目面向需要对旧版史克威尔艾尼克斯 PC 可执行文件进行深度控制的玩家与技术向模组作者，同样适用于研究商业游戏如何通过注入式渲染层与进程内内存补丁进行扩展的逆向工程与游戏安全分析。
