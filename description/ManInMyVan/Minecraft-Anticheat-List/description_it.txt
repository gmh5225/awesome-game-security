Un catalogo curato e un sito web interattivo che elenca plugin e mod anti-cheat pubblici per ogni edizione principale di Minecraft e piattaforma server. Il progetto è costruito con Kotlin/JS e Gradle, memorizzando centinaia di voci JSON validate compilate in una tabella ricercabile che mostra piattaforma, versioni supportate, prezzi, link e stato di manutenzione di ogni soluzione. A runtime arricchisce le voci interrogando le API GitHub e Spigot per dedurre se i progetti sono attivi, discontinuati o non disponibili. La copertura abbraccia gli ecosistemi Java e Bedrock, inclusi Bukkit, Sponge, Fabric, Forge, Nukkit e PocketMine. È rivolto agli operatori di server, ai ricercatori anti-cheat e a chiunque valuti o confronti le opzioni di rilevamento cheat lato server per Minecraft.
