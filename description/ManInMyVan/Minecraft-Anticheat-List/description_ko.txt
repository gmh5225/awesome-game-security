주요 Minecraft 에디션과 서버 플랫폼용 공개 안티치트 플러그인 및 모드를 나열하는 엄선 카탈로그 겸 인터랙티브 웹사이트입니다. Kotlin/JS와 Gradle로 구축되었으며, 검증된 JSON 항목 수백 개를 저장하고 각 솔루션의 플랫폼, 지원 버전, 가격, 링크, 유지보수 상태를 보여주는 검색 가능한 표로 컴파일합니다. 실행 시 GitHub 및 Spigot API를 조회해 항목 정보를 보강하고, 프로젝트가 활성 상태인지, 중단되었는지, 이용 불가능한지를 추론합니다. Bukkit, Sponge, Fabric, Forge, Nukkit, PocketMine을 포함한 Java 및 Bedrock 생태계를 포괄합니다. 서버 운영자, 안티치트 연구자, Minecraft 서버 측 치트 탐지 옵션을 평가하거나 비교하려는 모든 사용자를 대상으로 합니다.
