A curated catalog and interactive website that lists public anti-cheat plugins and mods for every major Minecraft edition and server platform. The project is built with Kotlin/JS and Gradle, storing hundreds of validated JSON entries that are compiled into a searchable table showing each solution's platform, supported versions, pricing, links, and maintenance status. At runtime it enriches entries by querying the GitHub and Spigot APIs to infer whether projects are active, discontinued, or unavailable. Coverage spans Java and Bedrock ecosystems including Bukkit, Sponge, Fabric, Forge, Nukkit, and PocketMine. It is aimed at server operators, anti-cheat researchers, and anyone evaluating or comparing Minecraft server-side cheat detection options.
