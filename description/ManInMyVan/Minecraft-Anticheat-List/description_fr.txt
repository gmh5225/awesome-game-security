Un catalogue sélectionné et un site web interactif répertoriant les plugins et mods anti-triche publics pour chaque édition majeure de Minecraft et plateforme serveur. Le projet est construit avec Kotlin/JS et Gradle, stockant des centaines d'entrées JSON validées compilées en un tableau consultable affichant la plateforme, les versions prises en charge, les tarifs, les liens et l'état de maintenance de chaque solution. À l'exécution, il enrichit les entrées en interrogeant les API GitHub et Spigot pour déterminer si les projets sont actifs, abandonnés ou indisponibles. La couverture englobe les écosystèmes Java et Bedrock, notamment Bukkit, Sponge, Fabric, Forge, Nukkit et PocketMine. Il s'adresse aux administrateurs de serveurs, aux chercheurs en anti-triche et à toute personne souhaitant évaluer ou comparer les options de détection de triche côté serveur pour Minecraft.
