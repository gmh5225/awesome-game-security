主要な Minecraft エディションとサーバープラットフォーム向けの公開アンチチートプラグイン・Mod を一覧する、厳選カタログ兼インタラクティブサイトです。Kotlin/JS と Gradle で構築され、検証済みの JSON エントリを数百件保存し、各ソリューションのプラットフォーム、対応バージョン、価格、リンク、メンテナンス状況を示す検索可能な表にコンパイルします。実行時には GitHub および Spigot API を照会してエントリを拡充し、プロジェクトがアクティブか、開発停止か、利用不可かを推定します。Bukkit、Sponge、Fabric、Forge、Nukkit、PocketMine を含む Java 版と Bedrock 版のエコシステムを網羅します。サーバー運営者、アンチチート研究者、Minecraft サーバー側のチート検出オプションを評価・比較するすべての方を対象としています。
