Курируемый каталог и интерактивный веб-сайт, перечисляющий публичные античит-плагины и моды для каждого основного издания Minecraft и серверной платформы. Проект построен на Kotlin/JS и Gradle, хранит сотни проверенных JSON-записей, которые компилируются в поисковую таблицу с указанием платформы, поддерживаемых версий, цен, ссылок и статуса сопровождения каждого решения. Во время выполнения записи дополняются запросами к API GitHub и Spigot, чтобы определить, активны ли проекты, прекращены или недоступны. Охват включает экосистемы Java и Bedrock, в том числе Bukkit, Sponge, Fabric, Forge, Nukkit и PocketMine. Предназначен для администраторов серверов, исследователей античитов и всех, кто оценивает или сравнивает серверные средства обнаружения читов в Minecraft.
