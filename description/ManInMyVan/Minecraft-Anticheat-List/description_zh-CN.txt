一份精选目录与交互式网站，收录各大 Minecraft 版本与服务器平台上公开的反作弊插件与模组。项目采用 Kotlin/JS 与 Gradle 构建，存储数百条经校验的 JSON 条目，并编译为可搜索表格，展示各方案的平台、支持版本、定价、链接与维护状态。运行时通过查询 GitHub 与 Spigot API 丰富条目信息，推断项目是否活跃、已停更或不可用。覆盖 Java 与 Bedrock 生态，包括 Bukkit、Sponge、Fabric、Forge、Nukkit 与 PocketMine。面向服务器管理员、反作弊研究者，以及评估或对比 Minecraft 服务端作弊检测方案的用户。
