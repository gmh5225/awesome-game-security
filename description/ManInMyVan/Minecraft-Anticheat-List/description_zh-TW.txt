一份精選目錄與互動式網站，收錄各大 Minecraft 版本與伺服器平台上的公開反作弊外掛與模組。專案以 Kotlin/JS 與 Gradle 建置，儲存數百筆經驗證的 JSON 條目，並編譯為可搜尋表格，呈現各方案的平台、支援版本、定價、連結與維護狀態。執行時透過查詢 GitHub 與 Spigot API 豐富條目資訊，推斷專案是否活躍、已停更或不可用。涵蓋 Java 與 Bedrock 生態，包括 Bukkit、Sponge、Fabric、Forge、Nukkit 與 PocketMine。面向伺服器管理員、反作弊研究者，以及評估或比較 Minecraft 伺服器端作弊偵測方案的使用者。
