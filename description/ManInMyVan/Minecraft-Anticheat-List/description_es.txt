Un catálogo curado y un sitio web interactivo que enumera plugins y mods anti-trampa públicos para cada edición principal de Minecraft y plataforma de servidor. El proyecto está construido con Kotlin/JS y Gradle, almacenando cientos de entradas JSON validadas que se compilan en una tabla buscable que muestra la plataforma, versiones compatibles, precios, enlaces y estado de mantenimiento de cada solución. En tiempo de ejecución enriquece las entradas consultando las API de GitHub y Spigot para inferir si los proyectos están activos, discontinuados o no disponibles. La cobertura abarca los ecosistemas Java y Bedrock, incluyendo Bukkit, Sponge, Fabric, Forge, Nukkit y PocketMine. Está dirigido a operadores de servidores, investigadores de anti-trampas y cualquier persona que evalúe o compare opciones de detección de trampas del lado del servidor en Minecraft.
