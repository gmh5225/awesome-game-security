이 프로젝트는 Last War: Survival Game 모바일 클라이언트의 네트워크 스택을 Go로 처음부터 다시 구현한 것으로, 디컴파일된 APK를 리버스 엔지니어링하여 Unity 앱 없이 TCP 위에서 세션을 실행할 수 있게 합니다. GSL RSA 및 AES 부트스트랩 암호화, SmartFoxServer SFS2X 프레이밍과 압축, SFSObject 바이너리 코덱을 구현했으며, 로그인, 자원 수집, 동맹 작업 및 관련 계정 작업을 위한 CLI 자동화도 제공합니다. 동반 도구는 캡처한 PCAP 로그인 트래픽을 재사용 가능한 세션 JSON으로 디코딩하고, 방대한 문서가 와이어 프로토콜, 명령 집합, 엔티티 ID 및 프로덕션 서버에 대한 실검증 동작을 정리합니다. 주 대상은 호환 가능한 헤드리스 클라이언트와 모바일 게임 프로토콜 분석을 위한 상세 참고 자료가 필요한 게임 보안 및 리버스 엔지니어링 연구자이며, ShuMei 사기 방지 필드와 세션 복구 워크플로를 포함합니다.
