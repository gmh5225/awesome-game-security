Этот проект — реализация с нуля на Go сетевого стека мобильного клиента Last War: Survival Game, созданная методами reverse engineering декомпилированного APK, чтобы сессии могли работать по TCP без приложения Unity. Реализованы bootstrap-криптография GSL RSA и AES, фрейминг и сжатие SmartFoxServer SFS2X, бинарный кодек SFSObject, а также CLI-автоматизация входа, сбора ресурсов, действий альянса и связанных задач аккаунта. Сопутствующие инструменты декодируют захваченный PCAP-трафик входа в переиспользуемый JSON сессии, а обширная документация систематизирует wire-протокол, набор команд, ID сущностей и поведение, проверенное на боевых серверах. Основная аудитория — исследователи game security и reverse engineering, которым нужен совместимый headless-клиент и подробный справочник по анализу протоколов мобильных игр, включая поля антифрода ShuMei и сценарии восстановления сессии.
