本项目是从零用 Go 重写的《Last War: Survival Game》手游客户端网络栈，通过对反编译 APK 的逆向工程实现，使会话可在不依赖 Unity 应用的情况下经 TCP 运行。实现了 GSL RSA 与 AES 引导加密、SmartFoxServer SFS2X 帧格式与压缩，以及 SFSObject 二进制编解码，并提供用于登录、资源采集、联盟操作及相关账号任务的 CLI 自动化。配套工具将抓取的 PCAP 登录流量解码为可复用的会话 JSON，详尽文档梳理了线缆协议、命令集、实体 ID 及针对生产服务器的实机验证行为。主要面向需要兼容无头客户端及手游协议分析详细参考的游戏安全与逆向研究人员，涵盖数美反欺诈字段与会话恢复流程。
