本專案是從零以 Go 重寫的《Last War: Survival Game》手遊用戶端網路堆疊，透過對反編譯 APK 的逆向工程，使工作階段可在不依賴 Unity 應用程式的情況下經 TCP 運作。實作了 GSL RSA 與 AES 引導式密碼學、SmartFoxServer SFS2X 封框與壓縮，以及 SFSObject 二進位編解碼器，並提供用於登入、資源採集、聯盟操作及相關帳號任務的 CLI 自動化。配套工具將擷取的 PCAP 登入流量解碼為可重複使用的工作階段 JSON，詳盡文件整理線路協定、命令集、實體 ID 及針對正式伺服器的實地驗證行為。主要對象為需要相容無頭用戶端及手遊協定分析詳細參考的遊戲安全與逆向研究人員，涵蓋數美反詐欺欄位與工作階段恢復流程。
