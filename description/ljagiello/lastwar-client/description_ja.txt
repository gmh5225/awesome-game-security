本プロジェクトは、Last War: Survival Game モバイルクライアントのネットワークスタックを Go で一から再実装したもので、逆コンパイルした APK のリバースエンジニアリングにより、Unity アプリなしで TCP 上でセッションを動かせます。GSL RSA および AES によるブートストラップ暗号、SmartFoxServer SFS2X のフレーミングと圧縮、SFSObject バイナリコーデックを実装し、ログイン、リソース収集、同盟操作などアカウント関連タスク向けの CLI 自動化も備えています。補助ツールは取得した PCAP のログイン通信を再利用可能なセッション JSON にデコードし、詳細なドキュメントがワイヤプロトコル、コマンドセット、エンティティ ID、本番サーバーに対する実検証済みの挙動を体系化しています。主な対象は、互換性のあるヘッドレスクライアントとモバイルゲームプロトコル分析の詳細な参照を必要とするゲームセキュリティおよびリバースエンジニアリング研究者で、ShuMei 不正検知フィールドやセッション復旧ワークフローも含みます。
