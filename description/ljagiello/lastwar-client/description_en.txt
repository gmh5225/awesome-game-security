This project is a from-scratch Go reimplementation of the Last War: Survival Game mobile client’s network stack, built by reverse engineering the decompiled APK so sessions can run over TCP without the Unity app. It implements GSL RSA and AES bootstrap cryptography, SmartFoxServer SFS2X framing and compression, and the SFSObject binary codec, plus CLI automation for login, resource collection, alliance actions, and related account tasks. Companion tooling decodes captured PCAP login traffic into reusable session JSON, and extensive documentation catalogs the wire protocol, command set, entity IDs, and live-validated behavior against production servers. The primary audience is game security and reverse engineering researchers who need a compatible headless client and a detailed reference for mobile game protocol analysis, including ShuMei anti-fraud fields and session recovery workflows.
