Process Injection Detection Lab is a defender-focused Windows lab that teaches how process injection appears in telemetry and how to engineer detections for it, without building or running malicious injectors. It uses Sysinternals tools (Process Explorer, Process Monitor, VMMap) together with a narrowly scoped Sysmon configuration that emphasizes Process Create, ProcessAccess, CreateRemoteThread, and Image Load events aligned to MITRE ATT&CK T1055. The repository ships Splunk SPL and Microsoft Sentinel or Defender KQL queries plus detection rule notes covering suspicious GrantedAccess masks, allowlists for debuggers and security tools, and optional correlation with remote-thread events. It is aimed at detection engineers, blue-team practitioners, and anyone studying anti-cheat or EDR-style monitoring, including how external game cheats rely on the same OpenProcess and WriteProcessMemory primitives that these rules watch for.
