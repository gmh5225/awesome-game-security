Process Injection Detection Lab 是面向防禦方的 Windows 實驗環境，說明程序注入在遙測中的呈現方式以及如何設計相關偵測規則，且無需建置或執行惡意注入器。它結合 Sysinternals 工具（Process Explorer、Process Monitor、VMMap）與範圍精簡的 Sysmon 設定，著重與 MITRE ATT&CK T1055 對應的 Process Create、ProcessAccess、CreateRemoteThread 和 Image Load 事件。儲存庫提供 Splunk SPL 以及 Microsoft Sentinel 或 Defender 的 KQL 查詢，並附偵測規則說明，涵蓋可疑 GrantedAccess 遮罩、偵錯器與安全工具的允許清單，以及可選的遠端執行緒事件關聯。面向偵測工程師、藍隊從業者，以及研究反作弊或 EDR 式監控的讀者，包括外部遊戲作弊如何依賴與本規則所監控相同的 OpenProcess 與 WriteProcessMemory 原語。
