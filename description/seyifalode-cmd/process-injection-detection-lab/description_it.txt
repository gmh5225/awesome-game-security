Process Injection Detection Lab è un laboratorio Windows orientato alla difesa che insegna come l'injection di processo compare nella telemetria e come progettare rilevamenti, senza costruire o eseguire injector malevoli. Utilizza gli strumenti Sysinternals (Process Explorer, Process Monitor, VMMap) insieme a una configurazione Sysmon circoscritta che enfatizza gli eventi Process Create, ProcessAccess, CreateRemoteThread e Image Load allineati a MITRE ATT&CK T1055. Il repository include query Splunk SPL e KQL per Microsoft Sentinel o Defender, più note sulle regole di rilevamento che coprono maschere GrantedAccess sospette, allowlist per debugger e strumenti di sicurezza e correlazione opzionale con eventi di thread remoto. È rivolto a detection engineer, professionisti blue team e a chi studia anti-cheat o monitoraggio in stile EDR, incluso come i cheat esterni per giochi si appoggiano alle stesse primitive OpenProcess e WriteProcessMemory che queste regole monitorano.
