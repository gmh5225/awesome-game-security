Process Injection Detection Lab は、防御者向けの Windows ラボで、プロセスインジェクションがテレメトリ上でどう現れるか、悪意のあるインジェクタを構築・実行することなく検知を設計する方法を学べます。Sysinternals ツール（Process Explorer、Process Monitor、VMMap）と、Process Create、ProcessAccess、CreateRemoteThread、Image Load イベントを MITRE ATT&CK T1055 に沿って重視する範囲を絞った Sysmon 設定を組み合わせています。リポジトリには Splunk SPL と Microsoft Sentinel または Defender 向け KQL クエリ、疑わしい GrantedAccess マスク、デバッガーとセキュリティツールの許可リスト、リモートスレッドイベントとの任意の相関を扱う検知ルールのメモが同梱されています。検知エンジニア、ブルーチーム実務者、反チートや EDR 型監視を学ぶ方を対象としており、外部ゲームチートがこれらのルールが監視する OpenProcess および WriteProcessMemory と同じプリミティブに依存する仕組みも含みます。
