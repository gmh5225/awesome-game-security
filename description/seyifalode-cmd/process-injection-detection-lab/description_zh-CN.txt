Process Injection Detection Lab 是一个面向防御方的 Windows 实验环境，讲解进程注入在遥测中的呈现方式以及如何设计相关检测规则，且无需构建或运行恶意注入器。它结合 Sysinternals 工具（Process Explorer、Process Monitor、VMMap）与范围精简的 Sysmon 配置，重点关注与 MITRE ATT&CK T1055 对应的 Process Create、ProcessAccess、CreateRemoteThread 和 Image Load 事件。仓库提供 Splunk SPL 以及 Microsoft Sentinel 或 Defender 的 KQL 查询，并附带检测规则说明，涵盖可疑 GrantedAccess 掩码、调试器与安全工具的允许列表，以及可选的远程线程事件关联。面向检测工程师、蓝队从业者，以及研究反作弊或 EDR 式监控的读者，包括外部游戏作弊如何依赖与本规则所监控相同的 OpenProcess 与 WriteProcessMemory 原语。
