Process Injection Detection Lab은 방어자 중심의 Windows 실습 환경으로, 프로세스 인젝션이 원격 측정(telemetry)에서 어떻게 나타나는지, 악성 인젝터를 만들거나 실행하지 않고도 이를 탐지하도록 설계하는 방법을 가르칩니다. Sysinternals 도구(Process Explorer, Process Monitor, VMMap)와 MITRE ATT&CK T1055에 맞춘 Process Create, ProcessAccess, CreateRemoteThread, Image Load 이벤트를 강조하는 범위가 좁은 Sysmon 구성을 함께 사용합니다. 저장소에는 Splunk SPL과 Microsoft Sentinel 또는 Defender용 KQL 쿼리, 의심스러운 GrantedAccess 마스크, 디버거 및 보안 도구 허용 목록, 원격 스레드 이벤트와의 선택적 상관 분석을 다루는 탐지 규칙 메모가 포함되어 있습니다. 탐지 엔지니어, 블루팀 실무자, 안티치트 또는 EDR 스타일 모니터링을 공부하는 이들을 대상으로 하며, 외부 게임 치트가 이러한 규칙이 감시하는 OpenProcess 및 WriteProcessMemory와 동일한 기본 API에 의존하는 방식도 다룹니다.
