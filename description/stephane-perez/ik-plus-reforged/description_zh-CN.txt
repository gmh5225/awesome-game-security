IK+ Reforged 是一个补丁与工具项目，通过向用户自行提供的 International Karate +（Atari ST 版）游戏副本应用经过严格验证的二进制修复来增强该游戏。该项目结合 Motorola 68000 汇编加载器与钩子，以及 Python 补丁脚本：提取游戏镜像、在修改前校验校验和与原始字节，并可选择启用 STE 专用增强功能，例如 DMA 音效与基于 blitter 的格斗角色渲染。它通过并口或 Jaguar 手柄实现三人同时游玩，修复 STE 与 Mega STE 硬件上的崩溃问题，并附带 JOYTEST 工具用于诊断手柄接线。本仓库面向希望研究或扩展经典 ST 游戏二进制文件、同时避免分发受版权保护游戏数据的复古计算爱好者与逆向工程师。开发与验证依赖 vasm 汇编器、Hatari 模拟器以及基于 Capstone 的反汇编工具。
