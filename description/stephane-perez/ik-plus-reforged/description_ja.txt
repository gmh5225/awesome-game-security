IK+ Reforged は、Atari ST 版 International Karate + を、ユーザーが用意したゲームコピーに慎重に検証済みのバイナリ修正を適用して強化するパッチおよびツール群プロジェクトです。Motorola 68000 アセンブリのローダーとフックに加え、ゲームイメージの抽出、変更前のチェックサムとオリジナルバイトの検証、および DMA サウンドや blitter ベースの格闘家描画といった STE 向け拡張の任意有効化を行う Python パッチスクリプトを組み合わせています。パラレルポートまたは Jaguar ジョイスティックによる 3 人同時プレイ対応、STE および Mega STE ハードウェア上のクラッシュ修正、コントローラ配線診断用 JOYTEST ユーティリティの同梱も含まれます。本リポジトリは、著作権で保護されたゲームデータを配布せずにクラシック ST ゲームのバイナリを研究・拡張したいレトロコンピューティング愛好家およびリバースエンジニアを対象としています。開発と検証には vasm アセンブラ、Hatari エミュレーション、Capstone ベースの逆アセンブルユーティリティを使用しています。
