IK+ Reforged is a patch and tooling project that enhances International Karate + for the Atari ST by applying carefully verified binary fixes to a user-supplied copy of the game. The work combines Motorola 68000 assembly loaders and hooks with Python patch scripts that extract the game image, validate checksums and original bytes before modification, and optionally enable STE-specific enhancements such as DMA sound and blitter-based fighter rendering. It adds simultaneous three-player support via parallel-port or Jaguar joysticks, fixes crashes on STE and Mega STE hardware, and ships a JOYTEST utility for diagnosing controller wiring. The repository is aimed at retro computing enthusiasts and reverse engineers who want to study or extend classic ST game binaries without distributing copyrighted game data. Development and validation rely on the vasm assembler, Hatari emulation, and Capstone-based disassembly utilities.
