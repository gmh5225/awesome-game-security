BizHawk 是一款多系統復古遊戲模擬器，主要面向工具輔助速通（TAS）與確定性的逐幀回放。它以 C# 撰寫，基於 .NET，並整合原生 C/C++ 模擬核心，支援 NES、SNES、Game Boy、GBA、Genesis、N64、Nintendo DS、PlayStation，以及透過 MAME 接入的街機系統等數十個平台。功能包括用於錄影與編輯的 TAStudio、具記憶體與輸入 API 的 Lua 腳本、RAM 搜尋與監看工具、十六進位編輯器、附反組譯器的 CPU 除錯器、追蹤記錄、即時存檔、倒帶，以及對 Game Genie 與 GameShark 作弊碼的解碼。此模擬器面向 TAS 作者、遊戲安全研究人員與逆向工程師，可在可重現環境中精確控制模擬遊戲狀態，以分析機制、開發或測試作弊，並研究復古遊戲內部實作。
