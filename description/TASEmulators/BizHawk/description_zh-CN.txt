BizHawk 是一款多系统复古游戏模拟器，主要面向工具辅助速通（TAS）和确定性的逐帧回放。它以 C# 编写，基于 .NET，并集成原生 C/C++ 模拟核心，支持 NES、SNES、Game Boy、GBA、Genesis、N64、Nintendo DS、PlayStation 以及通过 MAME 接入的街机系统等数十个平台。功能包括用于录像与编辑的 TAStudio、带内存与输入 API 的 Lua 脚本、RAM 搜索与监视工具、十六进制编辑器、带反汇编器的 CPU 调试器、跟踪日志、即时存档、倒带，以及对 Game Genie 与 GameShark 作弊码的解码。该模拟器面向 TAS 作者、游戏安全研究人员和逆向工程师，可在可复现环境中精确控制模拟游戏状态，以分析机制、开发或测试作弊，并研究复古游戏内部实现。
