BizHawk は、主にツールアシスト（TAS）や決定論的なフレーム単位の再生を目的としたマルチシステム向けレトロゲームエミュレータです。C# と .NET を基盤とし、ネイティブの C/C++ エミュレーションコアを組み合わせ、NES、SNES、Game Boy、GBA、Genesis、N64、Nintendo DS、PlayStation、MAME 経由のアーケードなど数十のプラットフォームをサポートします。機能には、ムービーの録画・編集用 TAStudio、メモリおよび入力 API 付き Lua スクリプト、RAM 検索・ウォッチツール、16 進エディタ、逆アセンブラ付き CPU デバッガ、トレースログ、セーブステート、巻き戻し、Game Genie や GameShark コードのデコーダなどがあります。TAS 制作者、ゲームセキュリティ研究者、リバースエンジニア向けに設計され、再現可能な環境でエミュレートされたゲーム状態を精密に制御し、仕組みの分析、チートの開発・テスト、レトロゲーム内部の調査が可能です。
