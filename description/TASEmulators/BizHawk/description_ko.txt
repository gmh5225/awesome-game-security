BizHawk는 주로 툴 어시스트 스피드런(TAS)과 결정론적 프레임 단위 재생을 위해 만들어진 다중 시스템 레트로 게임 에뮬레이터입니다. C#과 .NET 기반으로 작성되었으며 네이티브 C/C++ 에뮬레이션 코어를 사용해 NES, SNES, Game Boy, GBA, Genesis, N64, Nintendo DS, PlayStation, MAME을 통한 아케이드 등 수십 개 플랫폼을 지원합니다. 기능으로는 동영상 녹화·편집용 TAStudio, 메모리 및 입력 API가 있는 Lua 스크립팅, RAM 검색·감시 도구, 16진 편집기, 디스어셈블러가 있는 CPU 디버거, 트레이스 로깅, 세이브스테이트, 되감기, Game Genie 및 GameShark 코드 디코더 등이 있습니다. TAS 제작자, 게임 보안 연구자, 리버스 엔지니어를 대상으로 하며, 재현 가능한 환경에서 에뮬레이션된 게임 상태를 정밀하게 제어해 메커니즘 분석, 치트 개발·테스트, 레트로 게임 내부 연구에 활용할 수 있습니다.
