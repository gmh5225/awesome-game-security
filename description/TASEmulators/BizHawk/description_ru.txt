BizHawk — многоплатформенный эмулятор ретро-игр, созданный в первую очередь для tool-assisted speedrun (TAS) и детерминированного покадрового воспроизведения. Написан в основном на C# под .NET с нативными ядрами эмуляции на C и C++; поддерживает десятки платформ, включая NES, SNES, Game Boy, GBA, Genesis, N64, Nintendo DS, PlayStation и аркадные системы через MAME. В числе возможностей — TAStudio для записи и редактирования роликов, скрипты на Lua с API памяти и ввода, инструменты поиска и наблюдения за RAM, hex-редактор, отладчики CPU с disassemblers, трассировка, savestates, перемотка и декодеры кодов Game Genie и GameShark. Эмулятор ориентирован на авторов TAS, исследователей безопасности игр и reverse engineers, которым нужен точный контроль над эмулируемым состоянием игры для анализа механик, разработки и тестирования читов и изучения внутреннего устройства ретро-игр в воспроизводимой среде.
