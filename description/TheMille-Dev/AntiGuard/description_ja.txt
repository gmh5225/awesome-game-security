AntiGuard は、Minecraft Paper および Purpur SMP サーバー向けの自己完結型アンチチートプラグインで、外部サービスを必要とせずに一般的なクライアント側チートを検出します。主に Java で書かれており、単一の drop-in jar として提供され、fly、speed、reach、kill aura、auto-click、no-swing、no-fall、fast-break などの行為に対して物理ベースのチェックを行い、誤検知を抑える研究に基づいた閾値を使用します。プラグインは SQLite ベースのストレージ（LuckPerms データベースが存在する場合は再利用）を内蔵し、フラグ、BAN、キックを永続化し、ライブ監視と設定のための組み込み Web ダッシュボードと REST API を提供します。マルチプレイヤーのサバイバルやミニゲーム環境向けに、軽量なサーバー内チート検出と執行を求めるサーバー運営者や管理者向けです。リポジトリには、以前の集中型フラグ報告ワークフロー向けのレガシー Python コンポーネント（FastAPI レポートサーバーと参照エージェント）も含まれます。
