AntiGuard es un complemento antitrampas autónomo para servidores SMP de Minecraft Paper y Purpur que detecta trampas comunes del lado del cliente sin requerir servicios externos. Escrito principalmente en Java, se distribuye como un único archivo jar listo para usar con comprobaciones basadas en física para fly, speed, reach, kill aura, auto-click, no-swing, no-fall y fast-break, utilizando umbrales respaldados por investigación orientados a un bajo índice de falsos positivos. El complemento incorpora su propio almacenamiento basado en SQLite (o reutiliza la base de datos de LuckPerms cuando está presente) para persistir flags, bans y kicks, y expone un panel web integrado y una API REST para monitorización en vivo y configuración. Está pensado para operadores y administradores de servidores que desean una detección y aplicación de trampas ligera y en el propio servidor para entornos multijugador de supervivencia y minijuegos. El repositorio también incluye componentes Python heredados — un servidor de informes FastAPI y un agente de referencia — para flujos de trabajo anteriores de informes centralizados de flags.
