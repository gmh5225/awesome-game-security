AntiGuard — это автономный античит-плагин для SMP-серверов Minecraft Paper и Purpur, который обнаруживает распространённые клиентские читы без необходимости во внешних сервисах. Написанный преимущественно на Java, он поставляется в виде одного jar-файла, готового к установке, с проверками на основе физики для fly, speed, reach, kill aura, auto-click, no-swing, no-fall и fast-break, используя исследовательски обоснованные пороги для минимизации ложных срабатываний. Плагин включает собственное хранилище на базе SQLite (или повторно использует базу данных LuckPerms, если она доступна) для сохранения флагов, банов и киков, а также предоставляет встроенную веб-панель и REST API для мониторинга в реальном времени и настройки. Он предназначен для операторов и администраторов серверов, которым нужно лёгкое серверное обнаружение и пресечение читов в многопользовательских survival- и minigame-средах. Репозиторий также содержит устаревшие Python-компоненты — сервер отчётов на FastAPI и эталонный агент — для более ранних централизованных рабочих процессов отправки флагов.
