AntiGuard 是一款面向 Minecraft Paper 与 Purpur SMP 服务器的独立反作弊插件，可在无需外部服务的情况下检测常见客户端作弊行为。该插件主要使用 Java 编写，以单个即插即用的 jar 包形式提供，基于物理规则检测飞行、加速、攻击距离、杀戮光环、自动点击、无挥臂、无摔落伤害和快速破坏等行为，并采用经过研究验证的阈值以降低误报率。插件内置基于 SQLite 的存储（若存在 LuckPerms 数据库则复用），用于持久化标记、封禁和踢出记录，并提供内置 Web 仪表盘和 REST API，支持实时监控与配置。它面向需要轻量级、服务器端作弊检测与处置的服务器运营者和管理员，适用于多人生存与 minigame 环境。该仓库还包含旧版 Python 组件——FastAPI 报告服务器和参考 agent——用于早期的集中式标记上报工作流。
