AntiGuard est un plugin anti-triche autonome pour les serveurs SMP Minecraft Paper et Purpur qui détecte les triches côté client courantes sans nécessiter de services externes. Principalement écrit en Java, il se livre sous forme d'un unique fichier jar prêt à l'emploi avec des contrôles basés sur la physique pour le fly, la vitesse, la portée, le kill aura, l'auto-click, le no-swing, le no-fall et le fast-break, en utilisant des seuils fondés sur la recherche visant un faible taux de faux positifs. Le plugin intègre son propre stockage SQLite (ou réutilise la base de données LuckPerms si elle est présente) pour persister les signalements, bans et kicks, et expose un tableau de bord web intégré et une API REST pour la surveillance en direct et la configuration. Il s'adresse aux opérateurs et administrateurs de serveurs qui souhaitent une détection et une application légères des triches directement sur le serveur pour les environnements multijoueur survival et minigames. Le dépôt inclut également des composants Python hérités — un serveur de signalement FastAPI et un agent de référence — pour les anciens flux de travail centralisés de signalement.
