AntiGuard 是一款適用於 Minecraft Paper 與 Purpur SMP 伺服器的獨立反作弊外掛，可在無需外部服務的情況下偵測常見的用戶端作弊行為。外掛主要以 Java 撰寫，以單一即插即用的 jar 套件形式提供，透過物理規則檢查飛行、加速、攻擊距離、kill aura、自動點擊、無揮臂、無摔落傷害與快速破壞等行為，並採用經研究驗證的閾值以降低誤報率。外掛內建基於 SQLite 的儲存（若存在 LuckPerms 資料庫則可複用），用於持久化標記、封禁與踢出紀錄，並提供內建 Web 儀表板與 REST API，支援即時監控與設定。它面向需要輕量、伺服器端作弊偵測與處置的伺服器營運者與管理員，適用於多人生存與 minigame 環境。此儲存庫另含舊版 Python 元件——FastAPI 報告伺服器與參考 agent——用於早期的集中式標記上報工作流程。
