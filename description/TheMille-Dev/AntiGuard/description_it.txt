AntiGuard è un plugin anti-cheat autonomo per server SMP Minecraft Paper e Purpur che rileva i cheat lato client più comuni senza richiedere servizi esterni. Scritto principalmente in Java, viene distribuito come un unico file jar plug-and-play con controlli basati sulla fisica per fly, speed, reach, kill aura, auto-click, no-swing, no-fall e fast-break, utilizzando soglie supportate da ricerche mirate a un basso tasso di falsi positivi. Il plugin integra una propria archiviazione basata su SQLite (o riutilizza il database LuckPerms se presente) per persistere flag, ban e kick, ed espone una dashboard web integrata e un'API REST per monitoraggio in tempo reale e configurazione. È destinato a operatori e amministratori di server che desiderano un rilevamento e un'applicazione leggeri dei cheat direttamente sul server per ambienti multigiocatore survival e minigame. Il repository include anche componenti Python legacy — un server di segnalazione FastAPI e un agente di riferimento — per i precedenti flussi di lavoro centralizzati di segnalazione flag.
