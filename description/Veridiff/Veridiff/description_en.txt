Veridiff is a dynamic branch divergence engine that finds the exact conditional branch instruction where two executions of the same native code first take different paths. It uses Frida Stalker to trace basic-block sequences from two runs, then applies a longest-common-prefix diff and in-agent Capstone disassembly to pinpoint the deciding cmp, jump, or branch. The project ships as a Python module and a Rust library crate with identical APIs, including resync heuristics tuned for OLLVM-style control-flow flattening, optional warm-up to avoid dynamic-linker false positives, and cross-architecture branch classification on x86 and ARM64. It is aimed at reverse engineers analyzing license checks, anti-cheat heuristics, and other obfuscated control flow where manually comparing two disassembly traces does not scale.
