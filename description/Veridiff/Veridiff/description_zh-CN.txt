Veridiff 是一个动态分支分歧引擎，可在同一段原生代码的两次执行首次走上不同路径时，定位导致差异的确切条件分支指令。它使用 Frida Stalker 追踪两次运行的基本块序列，再通过最长公共前缀 diff 与进程内 Capstone 反汇编，精确锁定决定性的 cmp、跳转或分支。项目以 Python 模块与 Rust 库 crate 形式提供，二者 API 一致，包含针对 OLLVM 风格控制流平坦化的 resync 启发式、可选 warm-up 以避免动态链接器误报，以及在 x86 与 ARM64 上的跨架构分支分类。面向分析授权校验、反作弊启发式及其他混淆控制流的逆向工程师——在这些场景中，手工对比两份反汇编追踪难以扩展。
