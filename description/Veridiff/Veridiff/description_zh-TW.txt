Veridiff 是一個動態分支分歧引擎，可在同一段原生程式碼的兩次執行首次走上不同路徑時，定位導致差異的確切條件分支指令。它使用 Frida Stalker 追蹤兩次執行的基本區塊序列，再套用最長公共前綴 diff 與程序內 Capstone 反組譯，精確鎖定決定性的 cmp、跳轉或分支。專案以 Python 模組與 Rust 函式庫 crate 形式提供，兩者 API 一致，包含針對 OLLVM 風格控制流平坦化的 resync 啟發式、可選 warm-up 以避免動態連結器誤報，以及在 x86 與 ARM64 上的跨架構分支分類。面向分析授權檢查、反作弊啟發式及其他混淆控制流的逆向工程師——在此類情境中，手動比對兩份反組譯追蹤難以擴展。
