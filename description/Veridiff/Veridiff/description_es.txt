Veridiff es un motor de divergencia de ramas dinámico que localiza la instrucción exacta de salto condicional en la que dos ejecuciones del mismo código nativo toman por primera vez caminos distintos. Usa Frida Stalker para rastrear secuencias de bloques básicos de dos ejecuciones, y luego aplica un diff de prefijo común más largo y desensamblado Capstone in-agent para señalar el cmp, salto o rama decisiva. El proyecto se distribuye como módulo de Python y crate de biblioteca Rust con APIs idénticas, incluyendo heurísticas de resincronización ajustadas al aplanamiento de flujo de control al estilo OLLVM, calentamiento opcional para evitar falsos positivos del enlazador dinámico, y clasificación trans-arquitectura de ramas en x86 y ARM64. Está dirigido a ingenieros de ingeniería inversa que analizan comprobaciones de licencia, heurísticas anti-trampas y otro flujo de control ofuscado donde comparar manualmente dos trazas de desensamblado no escala.
