Veridiff — это движок динамического расхождения веток, который находит точную инструкцию условного перехода, где два выполнения одного и того же нативного кода впервые расходятся по разным путям. Он использует Frida Stalker для трассировки последовательностей базовых блоков из двух запусков, затем применяет diff по наибольшему общему префиксу и дизасsemblинг Capstone внутри агента, чтобы точно определить решающий cmp, jump или branch. Проект поставляется как модуль Python и crate библиотеки Rust с идентичными API, включая эвристики resync, настроенные для control-flow flattening в стиле OLLVM, опциональный warm-up для избежания ложных срабатываний от dynamic linker и кросс-архитектурную классификацию веток на x86 и ARM64. Он предназначен для reverse engineers, анализирующих проверки лицензий, античит-эвристики и другой обфусцированный control flow, где ручное сравнение двух трассировок дизасsemblинга не масштабируется.
