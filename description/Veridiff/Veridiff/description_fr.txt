Veridiff est un moteur de divergence de branches dynamique qui identifie l'instruction de branchement conditionnel exacte où deux exécutions du même code natif empruntent pour la première fois des chemins différents. Il utilise Frida Stalker pour tracer les séquences de blocs de base issues de deux exécutions, puis applique un diff par préfixe commun le plus long et un désassemblage Capstone in-agent pour repérer le cmp, le saut ou la branche décisionnelle. Le projet est distribué sous forme de module Python et de crate de bibliothèque Rust avec des API identiques, incluant des heuristiques de resynchronisation adaptées à l'aplatissement de flux de contrôle de style OLLVM, un warm-up optionnel pour éviter les faux positifs du dynamic linker, et une classification trans-architecture des branches sur x86 et ARM64. Il s'adresse aux ingénieurs en rétro-ingénierie qui analysent les vérifications de licence, les heuristiques anti-triche et d'autres flux de contrôle obfusqués où la comparaison manuelle de deux traces de désassemblage ne passe pas à l'échelle.
