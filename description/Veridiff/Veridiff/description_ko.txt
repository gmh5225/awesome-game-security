Veridiff는 동일한 네이티브 코드를 두 번 실행할 때 처음으로 서로 다른 경로를 택하는 정확한 조건 분기 명령어를 찾는 동적 분기 분기 엔진입니다. Frida Stalker로 두 실행의 기본 블록 시퀀스를 추적한 뒤, 최장 공통 접두사 diff와 에이전트 내 Capstone 디스어셈블리를 적용해 결정적인 cmp, 점프 또는 분기를 특정합니다. 프로젝트는 동일한 API를 제공하는 Python 모듈과 Rust 라이브러리 crate로 배포되며, OLLVM 스타일 제어 흐름 평탄화에 맞춘 resync 휴리스틱, 동적 링커 오탐을 피하기 위한 선택적 warm-up, x86 및 ARM64에서의 크로스 아키텍처 분기 분류를 포함합니다. 라이선스 검사, 안티치트 휴리스틱 및 기타 난독화된 제어 흐름을 분석하는 리버스 엔지니어를 대상으로 하며, 두 디스어셈블리 추적을 수동으로 비교하는 방식으로는 확장하기 어려운 경우에 적합합니다.
