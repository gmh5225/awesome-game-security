SpeedTester は、設定可能な速度でプレイヤーを動かしサーバーの応答を観察することで、公開済みゲームの移動アンチチートを評価する Roblox LocalScript です。Lua で書かれ、速度コントロール、ステータス表示、ロールバック表示付きのゲーム内 GUI を構築し、Humanoid の歩行速度、RunService の heartbeat ループ、クライアント側 translation などの Roblox サービスを使って移動テストを行います。このツールは不正な移動スパイクをシミュレートし、サーバーがロールバックやキャラクター修正を行うか観察できるため、アンチチート強化を目指す開発者や移動検証の弱点を調べるセキュリティ研究に有用です。Roblox Studio の StarterPlayerScripts から、または移動強制の挙動をテストする際にライブサーバー上で実行することを想定しています。
