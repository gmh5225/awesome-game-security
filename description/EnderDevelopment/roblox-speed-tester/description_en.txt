SpeedTester is a Roblox LocalScript that helps evaluate movement anti-cheat in published games by driving the player at configurable speeds and watching how the server responds. It is written in Lua and builds an in-game GUI with speed controls, status readouts, and rollback indicators, using Roblox services such as Humanoid walk speed, RunService heartbeat loops, and client-side translation for movement tests. The tool can simulate unauthorized movement spikes and observe whether the server rolls back or corrects the character, which makes it useful for developers hardening anti-cheat and for security research into movement validation weaknesses. It is intended to run from StarterPlayerScripts in Roblox Studio or on live servers when testing movement enforcement behavior.
