SpeedTester는 설정 가능한 속도로 플레이어를 움직이며 서버 응답을 관찰해 공개된 게임의 이동 안티치트를 평가하는 Roblox LocalScript입니다. Lua로 작성되며 속도 제어, 상태 표시, 롤백 표시가 있는 게임 내 GUI를 구성하고 Humanoid 보행 속도, RunService heartbeat 루프, 클라이언트 측 translation 등 Roblox 서비스로 이동 테스트를 수행합니다. 이 도구는 무단 이동 스파이크를 시뮬레이션하고 서버가 롤백하거나 캐릭터를 교정하는지 관찰할 수 있어 안티치트를 강화하는 개발자와 이동 검증 취약점을 연구하는 보안 연구에 유용합니다. Roblox Studio의 StarterPlayerScripts에서 또는 이동 강제 적용 동작을 테스트할 때 라이브 서버에서 실행하도록 설계되었습니다.
