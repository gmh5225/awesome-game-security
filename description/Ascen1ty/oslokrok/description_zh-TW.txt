Oslokrok 是一款適用於 Vector 或 LSPosed 的 Android Xposed 風格模組，可在已 root 裝置上於 PayPal 行動應用觸發裝置端防篡改偵測時阻止其當機。該模組主要以 Java 實作，採用 Gradle 建置的應用程式模組形式，透過將新版啟動階段 AppVerifier 完整性檢查邏輯與舊版 root 偵測訊號路徑改為空操作，來掛鉤 PayPal 行程內 RASP 檢查。掛鉤目標在執行時借助 DexKit，以套件與方法特徵為錨點進行探索；動態搜尋不可用時則回退至硬編碼的類別與方法。面向已 root、具備可用 Xposed 框架且已另行設定 root 隱藏的 arm64-v8a 裝置，用於逆向工程及圍繞 RASP 與防篡改繞過（而非伺服器端 attestation）的行動用戶端防護研究。
