Oslokrok — Android-модуль в стиле Xposed для Vector или LSPosed, который не даёт мобильному приложению PayPal падать на устройствах с root при срабатывании антивмешательства на устройстве. В основном реализован на Java как модуль приложения, собираемый Gradle; перехватывает внутрипроцессные проверки RASP PayPal, обнуляя логику целостности AppVerifier при запуске на новых сборках и устаревший путь сигнала обнаружения root на старых. Цели хуков находятся во время выполнения с помощью DexKit по якорям пакета и формы методов, с запасными захардкоженными классами и методами, если динамический поиск недоступен. Рассчитан на устройства arm64-v8a с root, работающим фреймворком Xposed и отдельной настройкой сокрытия root; предназначен для реверс-инжиниринга и исследований защиты мобильного клиента вокруг обхода RASP и антивмешательства, а не серверной аттестации.
