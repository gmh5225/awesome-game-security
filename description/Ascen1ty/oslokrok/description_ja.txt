Oslokrok は、Vector または LSPosed 向けの Android Xposed スタイルモジュールで、root 済み端末で PayPal モバイルアプリがオンデバイス改ざん検知を実行した際にクラッシュしないようにします。主に Java で実装され、Gradle でビルドするアプリケーションモジュールとして、PayPal プロセス内の RASP チェックをフックし、新しいビルドでは起動時の AppVerifier 整合性ロジックを、古いビルドでは従来の root 検知シグナル経路を no-op 化します。フック対象は実行時に DexKit でパッケージとメソッド形状のアンカーを用いて探索し、動的検索が使えない場合はハードコードされたクラスとメソッドにフォールバックします。root、動作する Xposed フレームワーク、別途の root 隠蔽設定を備えた arm64-v8a 端末を対象とし、サーバー側アテステーションではなく RASP および改ざん検知回避を中心としたモバイルクライアント保護のリバースエンジニアリングと研究を目的としています。
