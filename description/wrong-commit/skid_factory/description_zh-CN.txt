skid_factory 是一个 Node.js 编排框架，通过 Model Context Protocol 将大语言模型与底层调试工具连接起来，从而自动化视频游戏逆向工程与作弊客户端开发。项目主要使用 TypeScript 编写，并辅以 Lua 和 Python 桥接脚本，集成 Cheat Engine、x64dbg 和 Ghidra，用于扫描内存、监控硬件写入断点、追踪指针链至静态基址，以及修改游戏内数值。其概念验证工作流包含用于数值扫描与基址解析的交互式 REPL，以及通过 Cursor CLI 迭代引导自主内存发现与补丁的 advise 命令。该项目面向希望借助 LLM 自动化离线游戏内存分析、指针链重建与作弊原型开发的研究人员与逆向工程师，而非依赖手动脚本编写。
