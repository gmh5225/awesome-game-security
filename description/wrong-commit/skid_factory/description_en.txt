skid_factory is a Node.js orchestration framework that automates video game reverse engineering and cheat client development by connecting large language models to low-level debugging tools through the Model Context Protocol. Written primarily in TypeScript with Lua and Python bridge scripts, it integrates Cheat Engine, x64dbg, and Ghidra to scan memory, monitor hardware write breakpoints, trace pointer chains to static base addresses, and patch in-game values. Its proof-of-concept workflow includes an interactive REPL for value scanning and base-address resolution, plus an advise command that uses the Cursor CLI to iteratively guide autonomous memory discovery and patching. The project targets researchers and reverse engineers who want LLM-assisted automation for offline game memory analysis, pointer chain reconstruction, and cheat prototyping rather than manual scripting.
