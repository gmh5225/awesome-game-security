skid_factory는 Model Context Protocol을 통해 대규모 언어 모델과 저수준 디버깅 도구를 연결하여 비디오 게임 리버스 엔지니어링 및 치트 클라이언트 개발을 자동화하는 Node.js 오케스트레이션 프레임워크입니다. 주로 TypeScript로 작성되었으며 Lua 및 Python 브리지 스크립트를 포함하고, Cheat Engine, x64dbg, Ghidra와 통합하여 메모리 스캔, 하드웨어 쓰기 중단점 모니터링, 정적 기본 주소로의 포인터 체인 추적, 게임 내 값 패치를 수행합니다. 개념 증명 워크플로에는 값 스캔 및 기본 주소 해석을 위한 대화형 REPL과 Cursor CLI를 사용하여 자율적 메모리 탐색 및 패치를 반복적으로 안내하는 advise 명령이 포함됩니다. 이 프로젝트는 수동 스크립트 작성 대신 오프라인 게임 메모리 분석, 포인터 체인 재구성, 치트 프로토타이핑에 LLM 지원 자동화를 원하는 연구자 및 리버스 엔지니어를 대상으로 합니다.
