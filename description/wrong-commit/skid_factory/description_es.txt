skid_factory es un framework de orquestación en Node.js que automatiza la ingeniería inversa de videojuegos y el desarrollo de clientes de trucos conectando grandes modelos de lenguaje con herramientas de depuración de bajo nivel mediante el Model Context Protocol. Escrito principalmente en TypeScript con scripts puente en Lua y Python, integra Cheat Engine, x64dbg y Ghidra para escanear memoria, monitorizar puntos de interrupción de escritura por hardware, rastrear cadenas de punteros hasta direcciones base estáticas y modificar valores del juego. Su flujo de trabajo de prueba de concepto incluye un REPL interactivo para escaneo de valores y resolución de direcciones base, además de un comando advise que utiliza la Cursor CLI para guiar de forma iterativa el descubrimiento autónomo de memoria y el parcheo. El proyecto está dirigido a investigadores e ingenieros de ingeniería inversa que desean automatización asistida por LLM para análisis de memoria de juegos offline, reconstrucción de cadenas de punteros y prototipado de trucos, en lugar de scripting manual.
