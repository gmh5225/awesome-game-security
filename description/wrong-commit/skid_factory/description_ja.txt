skid_factory は、Model Context Protocol を介して大規模言語モデルと低レベルデバッグツールを接続し、ビデオゲームのリバースエンジニアリングおよびチートクライアント開発を自動化する Node.js オーケストレーションフレームワークです。主に TypeScript で書かれ、Lua と Python のブリッジスクリプトを備え、Cheat Engine、x64dbg、Ghidra と統合してメモリのスキャン、ハードウェア書き込みブレークポイントの監視、静的ベースアドレスへのポインタチェーンのトレース、ゲーム内値のパッチを行います。概念実証ワークフローには、値スキャンとベースアドレス解決のための対話型 REPL と、Cursor CLI を用いて自律的なメモリ探索とパッチ適用を反復的にガイドする advise コマンドが含まれます。本プロジェクトは、手動スクリプトではなく、オフラインゲームのメモリ分析、ポインタチェーン再構築、チートのプロトタイピングに LLM 支援の自動化を求める研究者およびリバースエンジニアを対象としています。
