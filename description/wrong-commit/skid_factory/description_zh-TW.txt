skid_factory 是一個 Node.js 編排框架，透過 Model Context Protocol 將大型語言模型與底層除錯工具連接起來，從而自動化電子遊戲逆向工程與作弊用戶端開發。專案主要使用 TypeScript 撰寫，並輔以 Lua 和 Python 橋接腳本，整合 Cheat Engine、x64dbg 和 Ghidra，用於掃描記憶體、監控硬體寫入中斷點、追蹤指標鏈至靜態基底位址，以及修改遊戲內數值。其概念驗證工作流程包含用於數值掃描與基底位址解析的互動式 REPL，以及透過 Cursor CLI 迭代引導自主記憶體探索與修補的 advise 命令。此專案面向希望借助 LLM 自動化離線遊戲記憶體分析、指標鏈重建與作弊原型開發的研究人員與逆向工程師，而非依賴手動腳本撰寫。
