skid_factory — это фреймворк оркестрации на Node.js, который автоматизирует реверс-инжиниринг видеоигр и разработку чит-клиентов, связывая большие языковые модели с инструментами низкоуровневой отладки через Model Context Protocol. Написанный преимущественно на TypeScript с мостовыми скриптами на Lua и Python, он интегрирует Cheat Engine, x64dbg и Ghidra для сканирования памяти, мониторинга аппаратных точек останова на запись, трассировки цепочек указателей до статических базовых адресов и патчинга игровых значений. Рабочий процесс proof-of-concept включает интерактивный REPL для сканирования значений и определения базовых адресов, а также команду advise, которая использует Cursor CLI для итеративного управления автономным обнаружением памяти и патчингом. Проект ориентирован на исследователей и специалистов по реверс-инжинирингу, которым нужна автоматизация с помощью LLM для офлайн-анализа памяти игр, восстановления цепочек указателей и прототипирования читов, а не ручное написание скриптов.
