Reliquary Archiver는 Rust로 작성된 도구로, 「붕괴: 스타레일」 네트워크 트래픽을 캡처·파싱해 유물과 광추 데이터를 JSON으로 내보냅니다. GUI 또는 헤드리스 CLI를 제공하며, Npcap 또는 libpcap(Windows에서는 Windows Packet Monitor)으로 실시간 캡처하거나 기존 .pcap, .pcapng, .etl 파일을 처리할 수 있습니다. 게임 패킷은 reliquary protobuf 라이브러리로 디코딩되며, 출력은 HSR-Scanner 형식과 일치하고, 선택적 WebSocket 서버가 업데이트를 스트리밍해 Fribbels HSR Optimizer로 실시간 가져오기를 지원합니다. 장비 최적화를 자동화하는 플레이어를 대상으로 하며, 라이브 온라인 게임에서 클라이언트—서버 패킷 검사와 프로토콜 리버스 엔지니어링의 실용적인 예시이기도 합니다.
