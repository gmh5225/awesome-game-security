Reliquary Archiver は Rust 製のツールで、『崩壊：スターレイル』のネットワークトラフィックをキャプチャして解析し、遺物と光円錐のデータを JSON でエクスポートします。GUI またはヘッドレス CLI を提供し、Npcap や libpcap（Windows では Windows Packet Monitor も）によるライブキャプチャや、既存の .pcap、.pcapng、.etl ファイルの処理に対応します。ゲームパケットは reliquary protobuf ライブラリでデコードされ、出力は HSR-Scanner 形式に準拠し、オプションの WebSocket サーバーが更新をストリームして Fribbels HSR Optimizer へのライブインポートを可能にします。装備最適化を自動化するプレイヤー向けであり、ライブオンラインゲームにおけるクライアント—サーバー型パケット検査とプロトコルリバースエンジニアリングの実践例でもあります。
