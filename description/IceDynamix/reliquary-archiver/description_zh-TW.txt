Reliquary Archiver 是一款 Rust 工具，用於擷取並解析《崩壞：星穹鐵道》的網路流量，將遺器與光錐資料匯出為 JSON。它提供圖形介面或無介面 CLI，可透過 Npcap 或 libpcap（在 Windows 上亦可使用 Windows Packet Monitor）進行即時擷取，也能處理既有的 .pcap、.pcapng 或 .etl 檔案。遊戲封包藉由 reliquary protobuf 函式庫解碼，輸出格式與 HSR-Scanner 一致，可選的 WebSocket 伺服器可串流更新，便於即時匯入 Fribbels HSR Optimizer。面向希望自動化裝備最佳化的玩家，同時也是在線遊戲中客戶端—伺服器封包檢視與協定逆向的實用範例。
