Reliquary Archiver is a Rust tool that captures and parses Honkai: Star Rail network traffic to export relic and light cone data as JSON. It offers a GUI or headless CLI, performs live capture via Npcap or libpcap (and Windows Packet Monitor on Windows), and can process existing .pcap, .pcapng, or .etl files. Game packets are decoded with the reliquary protobuf library, output matches the HSR-Scanner format, and an optional WebSocket server streams updates for live import into Fribbels HSR Optimizer. It targets players automating gear optimization and serves as a practical example of client-server packet inspection and protocol reverse engineering for a live online game.
