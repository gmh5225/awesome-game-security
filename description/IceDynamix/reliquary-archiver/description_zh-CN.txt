Reliquary Archiver 是一款 Rust 工具，用于捕获并解析《崩坏：星穹铁道》的网络流量，将遗器与光锥数据导出为 JSON。它提供图形界面或无界面 CLI，可通过 Npcap 或 libpcap（在 Windows 上还可使用 Windows Packet Monitor）进行实时抓包，也能处理已有的 .pcap、.pcapng 或 .etl 文件。游戏数据包借助 reliquary protobuf 库解码，输出格式与 HSR-Scanner 一致，可选的 WebSocket 服务器可推送更新，便于实时导入 Fribbels HSR Optimizer。面向希望自动化装备优化的玩家，同时也是在线游戏中客户端—服务端抓包分析与协议逆向的实用范例。
