DrillAndJoin es una biblioteca C++17 solo de cabeceras que implementa el algoritmo de síntesis Drill & Join para recuperar expresiones booleanas y de vectores de bits simplificadas a partir de predicados ofuscados. Combina síntesis exacta de dominio finito sobre Forma Normal Algebraica (ANF) con un flujo de trabajo respaldado por SMT usando Bitwuzla para simplificar de forma sólida predicados opacos de 64 bits, incluidos casos de ofuscación estilo MBA y funciones punto, sin buscar exhaustivamente en todo el espacio de entrada de 64 bits. El pipeline realiza reducción de dependencias de bits guiada por SMT, ejecuta Drill & Join sobre el soporte reducido y acepta reemplazos solo cuando Bitwuzla demuestra equivalencia bajo restricciones de ruta opcionales de ejecución concolica. Incluye demos, ejemplos de trazas y una CLI de síntesis por tabla de verdad para investigadores e ingenieros inversos que desofuscan predicados opacos, condiciones de ramificación y expresiones MBA en binarios protegidos o relacionados con juegos.
