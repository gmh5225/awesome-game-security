DrillAndJoin is a C++17 header-only library that implements the Drill & Join synthesis algorithm for recovering simplified Boolean and bit-vector expressions from obfuscated predicates. It combines exact finite-domain synthesis over Algebraic Normal Form with an SMT-backed workflow using Bitwuzla to soundly simplify 64-bit opaque predicates, including MBA-style obfuscation and point-function cases, without exhaustively searching the full 64-bit input space. The pipeline performs SMT-guided bit dependency reduction, runs Drill & Join on the reduced support, and accepts replacements only when Bitwuzla proves equivalence under optional path constraints from concolic execution. Demos, trace examples, and a truth-table synthesis CLI are included for researchers and reverse engineers deobfuscating opaque predicates, branch conditions, and MBA expressions in protected or game-related binaries.
