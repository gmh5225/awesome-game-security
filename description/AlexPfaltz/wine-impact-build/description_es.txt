Este proyecto aporta parches y automatización para compilar un módulo Wine ntoskrnl.exe modificado de modo que los anti-trampas de estilo kernel Impact y MRAC, usados en juegos como Allods Online, puedan ejecutarse con Wine o Proton en Linux. Los parches amplían el shim del kernel NT de Wine con comportamientos que los controladores reales esperan: asignación MDL y de páginas bloqueadas, copia de memoria virtual, rutinas de notificación de creación de procesos, nombres de imagen y marcas de tiempo de procesos, ayudas de suplantación de seguridad y manejo del hilo actual KPCR x86_64 mediante estado TEB relativo a gs. Un conjunto de parches más completo también mejora el despacho IRP resolviendo identificadores en modo usuario desde el proceso cliente cuando el contexto del administrador de dispositivos rompería la E/S del controlador. Los cambios de código son principalmente C sobre la implementación ntoskrnl de Wine, con ayudas de despliegue en shell y flujos opcionales de GitHub Actions que generan artefactos de compilación descargables. Está dirigido a jugadores e investigadores que necesitan compatibilidad en Linux con pilas anti-trampas propietarias, no a un producto independiente de trampas o bypass.
