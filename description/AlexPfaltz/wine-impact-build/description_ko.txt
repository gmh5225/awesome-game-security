이 프로젝트는 Allods Online 같은 게임에서 쓰이는 Impact·MRAC 같은 커널형 안티치트가 Linux에서 Wine 또는 Proton으로 실행되도록, 수정된 Wine ntoskrnl.exe 모듈을 빌드하기 위한 패치와 자동화를 제공한다. 패치는 Wine의 NT 커널 심을 확장해 MDL 및 잠긴 페이지 매핑, 가상 메모리 복사, 프로세스 생성 알림 루틴, 프로세스 이미지 이름과 타임스탬프, 보안 가장 헬퍼, gs 상대 TEB 상태를 통한 x86_64 KPCR 현재 스레드 처리 등 실제 드라이버가 기대하는 동작을 구현한다. 더 완전한 패치 세트는 장치 관리자 컨텍스트가 드라이버 I/O를 깨뜨릴 수 있는 경우 클라이언트 프로세스에서 사용자 모드 핸들을 해석해 IRP 디스패치를 개선한다. 소스 변경은 주로 Wine ntoskrnl 구현에 대한 C이며, 셸 배포 헬퍼와 다운로드 가능한 빌드 아티팩트를 만드는 선택적 GitHub Actions 워크플로가 있다. 독자형 치트나 우회 제품이 아니라, 독점 안티치트 스택과 Linux 호환성이 필요한 플레이어와 연구자를 대상으로 한다.
