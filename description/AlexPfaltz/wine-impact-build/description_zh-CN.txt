本项目提供补丁与自动化流程，用于构建修改版 Wine 的 ntoskrnl.exe 模块，使 Allods Online 等游戏所用的 Impact、MRAC 等内核风格反作弊可在 Linux 上通过 Wine 或 Proton 运行。补丁扩展 Wine 的 NT 内核垫片，实现真实驱动所依赖的行为，包括 MDL 与锁定页映射、虚拟内存复制、进程创建通知例程、进程映像名称与时间戳、安全模拟辅助例程，以及通过 gs 相对 TEB 状态处理 x86_64 KPCR 当前线程。更完整的补丁集还会在设备管理器上下文否则会破坏驱动 I/O 时，从客户端进程解析用户态句柄以改进 IRP 分发。源码改动主要针对 Wine 的 ntoskrnl 实现的 C 代码，并配有 shell 部署脚本和可选的 GitHub Actions 工作流以生成可下载的构建产物。面向需要在 Linux 上与专有反作弊栈兼容的玩家与研究人员，而非独立作弊或绕过工具。
