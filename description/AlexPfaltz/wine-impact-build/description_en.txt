This project supplies patches and automation to build a modified Wine ntoskrnl.exe module so Impact and MRAC kernel-style anti-cheat used by games such as Allods Online can run under Wine or Proton on Linux. The patches extend Wine’s NT kernel shim with behaviors real drivers expect, including MDL and locked-page mapping, virtual memory copy, process creation notify routines, process image names and timestamps, security impersonation helpers, and x86_64 KPCR current-thread handling via gs-relative TEB state. A fuller patch set also improves IRP dispatch by resolving user-mode handles from the client process when device manager context would otherwise break driver I/O. Source changes are primarily C against Wine’s ntoskrnl implementation, with shell deployment helpers and optional GitHub Actions workflows that produce downloadable build artifacts. It targets players and researchers who need Linux compatibility with proprietary anti-cheat stacks, not a standalone cheat or bypass product.
