Questo progetto fornisce patch e automazione per compilare un modulo Wine ntoskrnl.exe modificato così che anti-cheat in stile kernel come Impact e MRAC, usati da giochi come Allods Online, possano girare sotto Wine o Proton su Linux. Le patch estendono lo shim del kernel NT di Wine con comportamenti attesi dai driver reali: mapping MDL e pagine bloccate, copia della memoria virtuale, routine di notifica alla creazione di processi, nomi immagine e timestamp dei processi, helper per l’impersonazione di sicurezza e gestione del thread corrente KPCR x86_64 tramite stato TEB relativo a gs. Un set di patch più completo migliora anche il dispatch IRP risolvendo handle in user mode dal processo client quando il contesto del device manager altrimenti comprometterebbe le I/O del driver. Le modifiche al sorgente sono soprattutto C contro l’implementazione ntoskrnl di Wine, con helper di deploy in shell e workflow GitHub Actions opzionali che producono artefatti di build scaricabili. È rivolto a giocatori e ricercatori che necessitano compatibilità Linux con stack anti-cheat proprietari, non a un prodotto autonomo di cheat o bypass.
