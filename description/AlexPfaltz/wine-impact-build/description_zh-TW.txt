本專案提供修補程式與自動化流程，用以建置修改版 Wine 的 ntoskrnl.exe 模組，使 Allods Online 等遊戲所使用的 Impact、MRAC 等核心風格反作弊可在 Linux 上透過 Wine 或 Proton 執行。修補程式擴充 Wine 的 NT 核心墊片，實作真實驅動程式所預期的行為，包含 MDL 與鎖定頁面對應、虛擬記憶體複製、程序建立通知常式、程序映像名稱與時間戳記、安全性模擬輔助常式，以及透過 gs 相對 TEB 狀態處理 x86_64 KPCR 目前執行緒。更完整的修補組合亦會在裝置管理員內容否則會破壞驅動程式 I/O 時，從用戶端程序解析使用者模式控制代碼以改善 IRP 分派。原始碼變更主要為針對 Wine ntoskrnl 實作的 C 語言，並附有 shell 部署輔助工具與可選的 GitHub Actions 工作流程以產生可下載的建置成品。對象為需要在 Linux 上與專屬反作弊堆疊相容的玩家與研究人員，而非獨立的作弊或繞過產品。
