本プロジェクトは、Allods Online などのゲームで使われる Impact や MRAC といったカーネル型アンチチートを、Linux 上で Wine または Proton 経由で動かせるよう、改変した Wine の ntoskrnl.exe モジュールをビルドするためのパッチと自動化を提供する。パッチは Wine の NT カーネルシムを拡張し、実ドライバが前提とする挙動（MDL とロック済みページのマッピング、仮想メモリのコピー、プロセス作成通知ルーチン、プロセスイメージ名とタイムスタンプ、セキュリティ偽装ヘルパー、gs 相対 TEB 状態による x86_64 KPCR の現在スレッド処理など）を実装する。より完全なパッチセットは、デバイスマネージャのコンテキストがドライバ I/O を壊してしまう場合に、クライアントプロセスからユーザーモードハンドルを解決して IRP ディスパッチを改善する。ソース変更は主に Wine の ntoskrnl 実装に対する C で、シェルによるデプロイ補助と、ダウンロード可能なビルド成果物を生成する任意の GitHub Actions ワークフローを含む。Linux でプロプライエタリなアンチチートスタックとの互換性が必要なプレイヤーと研究者向けであり、単体のチートやバイパス製品ではない。
