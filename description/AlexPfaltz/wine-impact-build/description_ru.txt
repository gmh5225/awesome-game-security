Проект поставляет патчи и автоматизацию для сборки модифицированного модуля Wine ntoskrnl.exe, чтобы античиты ядерного типа Impact и MRAC, используемые в играх вроде Allods Online, могли работать под Wine или Proton в Linux. Патчи расширяют NT-ядровой шим Wine поведением, которого ожидают настоящие драйверы: отображение MDL и заблокированных страниц, копирование виртуальной памяти, процедуры уведомления о создании процессов, имена образов и метки времени процессов, вспомогательные функции олицетворения безопасности и обработка текущего потока KPCR x86_64 через состояние TEB относительно gs. Более полный набор патчей также улучшает диспетчеризацию IRP, разрешая пользовательские дескрипторы из клиентского процесса, когда контекст диспетчера устройств иначе ломал бы ввод-вывод драйвера. Изменения в исходниках в основном на C к реализации ntoskrnl в Wine, с shell-скриптами развёртывания и опциональными рабочими процессами GitHub Actions, создающими скачиваемые артефакты сборки. Целевая аудитория — игроки и исследователи, которым нужна совместимость Linux с проприетарными античит-стеками, а не самостоятельный чит или средство обхода.
