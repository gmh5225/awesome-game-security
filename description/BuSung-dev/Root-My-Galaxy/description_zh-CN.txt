Root My Galaxy 是一款 Android 应用，为明确支持的 Samsung Galaxy 固件版本提供一键 root 功能。该应用主要使用 Kotlin 编写，采用 Jetpack Compose UI，并通过 Android NDK 集成原生 C 组件；它会根据内核版本、Build ID、SDK 级别、ABI 和页大小自动匹配设备，然后从外部源下载并应用针对特定设备的 exploit 载荷和 KernelSU 组件。安装程序与敏感的 exploit 代码、内存偏移量和 root 载荷相互隔离，并包含用于内核攻击面枚举、KASLR 时序分析和权限提升验证的原生探测功能。高级模式支持手动选择配置文件，并对内核版本和 Build 不匹配分别发出警告。本工具面向从事 Android 内核漏洞利用、root 流程及相关移动安全研究的安全研究人员和授权测试人员。
