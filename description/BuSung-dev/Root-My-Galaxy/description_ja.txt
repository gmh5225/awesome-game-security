Root My Galaxy は、明示的にサポートされた Samsung Galaxy ファームウェアビルド向けにワンクリック root を提供する Android アプリケーションです。主に Kotlin で記述され、Jetpack Compose UI と Android NDK 経由のネイティブ C コンポーネントを備え、カーネルリリース、Build ID、SDK レベル、ABI、ページサイズでデバイスを自動的に照合したうえで、外部フィードからデバイス固有の exploit ペイロードと KernelSU アーティファクトをダウンロードして適用します。インストーラーは機微な exploit コード、メモリオフセット、root ペイロードから分離されており、カーネル攻撃面の列挙、KASLR タイミング解析、権限昇格の検証のためのネイティブプローブを含みます。高度なモードでは手動でプロファイルを選択でき、カーネルリリースとビルドの不一致について個別の警告が表示されます。Android カーネル exploit、root ワークフロー、関連するモバイルセキュリティ研究に取り組むセキュリティ研究者および認可されたテスター向けです。
