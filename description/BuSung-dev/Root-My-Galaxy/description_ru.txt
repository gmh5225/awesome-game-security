Root My Galaxy — это Android-приложение, обеспечивающее root в один клик для явно поддерживаемых сборок прошивки Samsung Galaxy. Написано преимущественно на Kotlin с интерфейсом Jetpack Compose и нативными компонентами на C через Android NDK; автоматически сопоставляет устройства по версии ядра, Build ID, уровню SDK, ABI и размеру страницы, после чего загружает и применяет специфичные для устройства exploit-полезные нагрузки и артефакты KernelSU из внешнего источника. Установщик отделён от чувствительного exploit-кода, смещений в памяти и root-полезных нагрузок и включает нативные зонды для перечисления поверхности атаки ядра, анализа таймингов KASLR и проверки повышения привилегий. Расширенный режим позволяет вручную выбирать профиль с отдельными предупреждениями о несовпадении версии ядра и сборки. Предназначено для исследователей безопасности и авторизованных тестировщиков, работающих над эксплуатацией ядра Android, процессами root и связанными исследованиями мобильной безопасности.
