Root My Galaxy 是一款 Android 應用程式，為明確支援的 Samsung Galaxy 韌體版本提供一鍵 root 功能。該應用程式主要使用 Kotlin 撰寫，採用 Jetpack Compose UI，並透過 Android NDK 整合原生 C 元件；它會根據核心版本、Build ID、SDK 級別、ABI 和頁面大小自動比對裝置，然後從外部來源下載並套用針對特定裝置的 exploit 載荷和 KernelSU 元件。安裝程式與敏感的 exploit 程式碼、記憶體偏移量和 root 載荷相互隔離，並包含用於核心攻擊面列舉、KASLR 時序分析和權限提升驗證的原生探測功能。進階模式支援手動選擇設定檔，並對核心版本和 Build 不匹配分別發出警告。本工具面向從事 Android 核心漏洞利用、root 流程及相關行動安全研究的安全研究人員和授權測試人員。
