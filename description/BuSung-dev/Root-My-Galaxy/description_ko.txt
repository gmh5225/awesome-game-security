Root My Galaxy는 명시적으로 지원되는 Samsung Galaxy 펌웨어 빌드에 대해 원클릭 root를 제공하는 Android 애플리케이션입니다. 주로 Kotlin으로 작성되었으며 Jetpack Compose UI와 Android NDK를 통한 네이티브 C 구성 요소를 갖추고, 커널 릴리스, Build ID, SDK 수준, ABI, 페이지 크기로 기기를 자동으로 매칭한 뒤 외부 피드에서 기기별 exploit 페이로드와 KernelSU 아티팩트를 다운로드하여 적용합니다. 설치 프로그램은 민감한 exploit 코드, 메모리 오프셋, root 페이로드와 분리되어 있으며, 커널 공격 표면 열거, KASLR 타이밍 분석, 권한 상승 검증을 위한 네이티브 프로브를 포함합니다. 고급 모드에서는 프로필을 수동으로 선택할 수 있으며, 커널 릴리스 및 빌드 불일치에 대한 별도의 경고를 제공합니다. Android 커널 exploit, root 워크플로, 관련 모바일 보안 연구를 수행하는 보안 연구원 및 승인된 테스터를 대상으로 합니다.
