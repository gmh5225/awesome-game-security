這是一個用於教學的 C++23 示範專案，展示如何在程序記憶體內對多態資料進行解密、使用並重新加密載荷。它封裝了 Windows 與 Linux 上的跨平台頁面保護 API，使用 VirtualProtect 和 mprotect 並配合頁邊界對齊，並透過以 std::span 與 std::expected 建構的統一介面實現型別安全的錯誤處理。ProtectedData 類別採用位置相關的 XOR 變換，並透過亂數產生器實現動態金鑰輪換，隨後在退出前恢復原始記憶體權限並對緩衝區進行清零。此專案面向研究者與開發者，用於學習二進位機制、記憶體配置操作，以及與反作弊和遊戲安全工程相關的縱深防禦技術。專案使用 CMake 建置，目標為支援 C++23 標準的現代編譯器。
