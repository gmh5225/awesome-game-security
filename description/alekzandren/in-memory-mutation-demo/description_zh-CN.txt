这是一个用于教学的 C++23 演示项目，展示如何在进程内存内对多态数据进行解密、使用并重新加密载荷。它封装了 Windows 与 Linux 上的跨平台页面保护 API，使用 VirtualProtect 和 mprotect 并配合页边界对齐，并通过基于 std::span 与 std::expected 构建的统一接口实现类型安全的错误处理。ProtectedData 类采用位置相关的 XOR 变换，并通过随机数生成器实现动态密钥轮换，随后在退出前恢复原始内存权限并对缓冲区进行清零。该项目面向研究者和开发者，用于学习二进制机制、内存布局操作，以及与反作弊和游戏安全工程相关的纵深防御技术。项目使用 CMake 构建，面向支持 C++23 标准的现代编译器。
