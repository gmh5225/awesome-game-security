이 프로젝트는 프로세스 메모리 내에서 페이로드를 복호화하고 사용한 뒤 다시 암호화하는 메모리 내 다형 데이터 변조를 보여 주는 교육용 C++23 데모입니다. Windows와 Linux의 크로스 플랫폼 페이지 보호 API를 래핑하며, VirtualProtect와 mprotect를 페이지 경계 정렬과 함께 사용하고, std::span과 std::expected로 구축한 통합 인터페이스를 통해 타입 안전한 오류 처리를 제공합니다. ProtectedData 클래스는 위치 의존 XOR 변환을 적용하고 난수 생성기를 통한 동적 키 순환을 수행한 뒤, 종료 전에 원래 메모리 권한을 복원하고 버퍼를 제로화합니다. 이 프로젝트는 바이너리 메커니즘, 메모리 레이아웃 조작, 그리고 안티치트 및 게임 보안 엔지니어링과 관련된 심층 방어 기법을 연구하는 연구자와 개발자를 대상으로 합니다. CMake로 빌드되며 C++23 표준을 지원하는 최신 컴파일러를 대상으로 합니다.
