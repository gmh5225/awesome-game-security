これは、プロセスメモリ内でペイロードを復号・使用・再暗号化する、メモリ内多態データ変換の教育的な C++23 デモンストレーションです。Windows と Linux 向けのクロスプラットフォームなページ保護 API をラップし、VirtualProtect と mprotect をページ境界アライメントとともに使用し、std::span と std::expected で構築した統一インターフェースにより型安全なエラー処理を提供します。ProtectedData クラスは位置依存の XOR 変換を適用し、乱数生成器による動的キーローテーションを行い、終了前に元のメモリ権限を復元してバッファをゼロ化します。本プロジェクトは、バイナリの仕組み、メモリレイアウト操作、およびアンチチートやゲームセキュリティエンジニアリングに関連する多層防御手法を学ぶ研究者や開発者を対象としています。CMake でビルドされ、C++23 標準をサポートする最新コンパイラをターゲットとしています。
