Это учебная демонстрация на C++23 полиморфной мутации данных в памяти, которая расшифровывает, использует и повторно шифрует полезную нагрузку целиком в памяти процесса. Она оборачивает кросс-платформенные API защиты страниц в Windows и Linux, используя VirtualProtect и mprotect с выравниванием по границам страниц, и предоставляет единый интерфейс на основе std::span и std::expected для типобезопасной обработки ошибок. Класс ProtectedData применяет зависящие от позиции XOR-преобразования с динамической ротацией ключей через генератор случайных чисел, затем восстанавливает исходные права доступа к памяти и обнуляет буфер перед завершением. Проект предназначен для исследователей и разработчиков, изучающих бинарную механику, манипуляции с размещением в памяти и методы многоуровневой защиты, актуальные для античита и инженерии безопасности игр. Сборка выполняется с помощью CMake; целевые компиляторы — современные, поддерживающие стандарт C++23.
