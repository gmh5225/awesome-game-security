This is an educational C++23 demonstration of in-memory polymorphic data mutation that decrypts, uses, and re-encrypts a payload entirely within process memory. It wraps cross-platform page protection APIs on Windows and Linux, using VirtualProtect and mprotect with page-boundary alignment, and exposes a unified interface built with std::span and std::expected for type-safe error handling. The ProtectedData class applies position-dependent XOR transformations with dynamic key rotation via a random number generator, then restores original memory permissions and zeroizes the buffer before exit. The project is intended for researchers and developers studying binary mechanics, memory layout manipulation, and defense-in-depth techniques relevant to anti-cheat and game security engineering. It is built with CMake and targets modern compilers supporting the C++23 standard.
