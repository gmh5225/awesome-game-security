本仓库是一份西班牙语研究笔记，从系统层面记录商业内核模式反作弊与终端安全软件的工作原理。它说明典型的三层模型（ring 0 内核驱动、ring 3 用户态服务，以及服务端 AI 或机器学习监控），并对比 BattlEye、Easy Anti-Cheat 与 Riot Vanguard，涵盖驱动行为、回调、白名单及 BSOD 等已知故障模式。第二部分分析 2024 年 7 月 CrowdStrike Falcon 大规模中断，包括 File 291 配置不匹配、缓冲区溢出、全球影响与补救措施。内容以 Markdown 撰写并附精选外部参考，而非可执行代码，适合研究游戏安全、反作弊架构以及 Windows 内核级防护更广泛风险的读者。
