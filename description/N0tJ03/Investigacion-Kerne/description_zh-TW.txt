本儲存庫是一份西班牙語研究筆記，從系統層面記錄商業核心模式反作弊與端點安全軟體的運作原理。它說明典型的三層模型（ring 0 核心驅動程式、ring 3 使用者模式服務，以及伺服器端 AI 或機器學習監控），並比較 BattlEye、Easy Anti-Cheat 與 Riot Vanguard，涵蓋驅動程式行為、回呼、白名單及 BSOD 等已知故障模式。第二部分分析 2024 年 7 月 CrowdStrike Falcon 大規模中斷，包括 File 291 設定不符、緩衝區溢位、全球影響與補救措施。內容以 Markdown 撰寫並附精選外部參考，而非可執行程式碼，適合研究遊戲安全、反作弊架構以及 Windows 核心層防護更廣泛風險的讀者。
