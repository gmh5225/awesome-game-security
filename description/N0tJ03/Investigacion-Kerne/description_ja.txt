このリポジトリは、商用カーネルモードのアンチチートおよびエンドポイントセキュリティソフトがシステムレベルでどのように動作するかを記録したスペイン語の研究ノートブックです。典型的な三層モデル（ring 0 のカーネルドライバ、ring 3 のユーザーモードサービス、AI または機械学習を用いたサーバー側監視）を説明し、BattlEye、Easy Anti-Cheat、Riot Vanguard を比較し、ドライバの挙動、コールバック、ホワイトリスト、BSOD などの既知の障害モードも扱います。第二部では 2024 年 7 月の CrowdStrike Falcon 大規模障害を分析し、File 291 の設定不一致、バッファオーバーフロー、世界的な影響、修復手順を述べます。内容は Markdown で書かれ、実行可能なコードではなく厳選された外部参照が中心で、ゲームセキュリティ、アンチチートアーキテクチャ、Windows におけるカーネルレベル保護の広いリスクを学ぶ読者向けです。
