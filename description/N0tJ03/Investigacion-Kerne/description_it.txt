Questo repository è un quaderno di ricerca in spagnolo che documenta a livello di sistema il funzionamento del software commerciale anti-cheat in modalità kernel e di sicurezza degli endpoint. Spiega il tipico modello a tre livelli (driver kernel in ring 0, servizi in user mode in ring 3 e monitoraggio lato server con IA o machine learning) e confronta BattlEye, Easy Anti-Cheat e Riot Vanguard, inclusi comportamento dei driver, callback, whitelist e modi di guasto noti come i BSOD. Una seconda sezione analizza l’interruzione di CrowdStrike Falcon del luglio 2024, coprendo la discrepanza di configurazione del File 291, il buffer overflow, l’impatto globale e i passi di remediation. Il materiale è scritto in Markdown con riferimenti esterni curati piuttosto che codice eseguibile, ed è adatto a chi studia la sicurezza dei giochi, l’architettura anti-cheat e i rischi più ampi della protezione a livello kernel su Windows.
