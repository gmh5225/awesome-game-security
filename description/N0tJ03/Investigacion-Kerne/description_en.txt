This repository is a Spanish-language research notebook that documents how commercial kernel-mode anti-cheat and endpoint security software works at a systems level. It explains the typical three-layer model (kernel drivers in ring 0, user-mode services in ring 3, and server-side monitoring with AI or machine learning) and compares BattlEye, Easy Anti-Cheat, and Riot Vanguard, including driver behavior, callbacks, whitelisting, and known failure modes such as BSODs. A second section analyzes the July 2024 CrowdStrike Falcon outage, covering the File 291 configuration mismatch, buffer overflow, global impact, and remediation steps. The material is written in Markdown with curated external references rather than executable code. It suits readers studying game security, anti-cheat architecture, and the broader risks of kernel-level protection on Windows.
