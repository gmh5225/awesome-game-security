FIREAC is a free, lightweight anti-cheat resource for FiveM multiplayer servers, combining client-side and server-side checks with straightforward setup and administration. It is implemented primarily in Lua as a FiveM resource, with a web-based admin panel (HTML, CSS, and JavaScript) and MySQL persistence via oxmysql. The client layer detects common GTA V mod menu abuses such as god mode, teleporting, weapon and health tampering, spectating, noclip, and related cheats, while the server layer blocks spam, blacklisted events and explosions, injection, unauthorized admin actions, and similar exploits. It integrates with ESX, QBCore, and standalone server frameworks, supports whitelisting, bans, Discord webhook notifications, and optional screenshot evidence through discord-screenshot. The project targets FiveM server owners and administrators who need practical game security and cheat deterrence without a heavy commercial anti-cheat stack.
