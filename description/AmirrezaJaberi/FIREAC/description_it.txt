FIREAC è una risorsa anti-cheat gratuita e leggera per server multiplayer FiveM, che combina controlli lato client e lato server con configurazione e amministrazione semplici. È implementata principalmente in Lua come risorsa FiveM, con un pannello di amministrazione web (HTML, CSS e JavaScript) e persistenza MySQL tramite oxmysql. Il livello client rileva abusi comuni dei menu mod di GTA V come god mode, teletrasporto, manomissione di armi e salute, spectate, noclip e cheat correlati, mentre il livello server blocca spam, eventi ed esplosioni in blacklist, injection, azioni amministrative non autorizzate e exploit simili. Si integra con ESX, QBCore e framework server standalone, supporta whitelist, ban, notifiche webhook Discord e prove opzionali con screenshot tramite discord-screenshot. Il progetto è rivolto a proprietari e amministratori di server FiveM che necessitano di sicurezza di gioco pratica e deterrenza contro i cheat senza uno stack anti-cheat commerciale pesante.
