FIREAC 是一款面向 FiveM 多人服务器的免费、轻量级反作弊资源，将客户端与服务端检测相结合，配置与管理简单直观。它主要以 Lua 实现为 FiveM 资源，配有基于 Web 的管理面板（HTML、CSS、JavaScript），并通过 oxmysql 实现 MySQL 持久化。客户端可检测常见 GTA V 修改菜单滥用，如无敌、传送、武器与生命篡改、旁观、穿墙及类似作弊；服务端可拦截刷屏、黑名单事件与爆炸、注入、未授权管理操作等类似利用。可与 ESX、QBCore 及独立服务器框架集成，支持白名单、封禁、Discord Webhook 通知，以及通过 discord-screenshot 可选的截图取证。该项目面向需要实用游戏安全与防作弊、又不想承担沉重商业反作弊方案的 FiveM 服主与管理员。
