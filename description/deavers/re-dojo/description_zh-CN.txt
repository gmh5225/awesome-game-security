ReDojo 是一个面向逆向工程、二进制审计与离线单机游戏改动的开源、游戏化学堂。项目提供十八个可编译的 C++20 练习靶标——十个递进式内存与 Hook 实验以及八个 crackme——并附带 Cheat Engine 表、修改器模板、内部 DLL 骨架，以及用于 PE 扫描、AOB 模式与 Z3 符号求解的 Python 工具。学习者通过分层 RPG 战役，从基础数值扫描与指针链进阶到共享代码过滤、VMT 与 ReClass 风格类分析、世界坐标到屏幕坐标换算、代码注入、完整性绕过练习、控制流混淆与反调试挑战。基于浏览器的 Web 仪表盘与 Python RPG 管理器跟踪任务完成情况，自动化产物评分器则从架构、间接层深度、Hook 复杂度、保护等级与权限边界等维度为提交打分。本项目面向在本地教育靶标上自学、培养实用逆向与游戏安全技能的学生与爱好者，而非在线反作弊规避。
