ReDojo is an open-source, gamified academy for reverse engineering, binary auditing, and offline single-player game hacking. It ships eighteen compilable C++20 practice targets—ten progressive memory and hooking labs plus eight crackmes—alongside Cheat Engine tables, trainer templates, internal DLL skeletons, and Python utilities for PE scanning, AOB patterns, and Z3 symbolic solving. Learners advance through a tiered RPG campaign from basic value scans and pointer chains to shared-code filters, VMT and ReClass-style class work, world-to-screen math, code injection, integrity bypass exercises, control-flow obfuscation, and anti-debug challenges. A browser-based web dashboard and Python RPG manager track quest completion, while an automated artifact grader scores submissions on architecture, indirection depth, hook complexity, protection level, and privilege boundary. The project is aimed at self-paced students and hobbyists building practical RE and game-security skills on local, educational targets rather than online anti-cheat evasion.
