ReDojo 是一個面向逆向工程、二進位稽核與離線單機遊戲改動的開源、遊戲化學院。專案提供十八個可編譯的 C++20 練習標的——十個遞進式記憶體與 Hook 實驗以及八個 crackme——並附帶 Cheat Engine 表、修改器範本、內部 DLL 骨架，以及用於 PE 掃描、AOB 模式與 Z3 符號求解的 Python 工具。學習者透過分層 RPG 戰役，從基礎數值掃描與指標鏈進階到共享程式碼過濾、VMT 與 ReClass 風格類別分析、世界座標到螢幕座標換算、程式碼注入、完整性繞過練習、控制流混淆與反除錯挑戰。基於瀏覽器的 Web 儀表板與 Python RPG 管理器追蹤任務完成情況，自動化產物評分器則從架構、間接層深度、Hook 複雜度、保護等級與權限邊界等維度為提交評分。本專案面向在本地教育標的上自學、培養實用逆向與遊戲安全技能的學生與愛好者，而非線上反作弊規避。
