ReDojo は、リバースエンジニアリング、バイナリ監査、オフラインのシングルプレイヤーゲームハッキング向けのオープンソースでゲーミフィケーションされたアカデミーです。コンパイル可能な C++20 の練習ターゲットを十八個——段階的なメモリとフックのラボ十個と crackme 八個——同梱し、Cheat Engine テーブル、トレーナーテンプレート、内部 DLL スケルトン、PE スキャン、AOB パターン、Z3 による記号実行用の Python ユーティリティも提供します。学習者は段階制 RPG キャンペーンで、基本的な値スキャンとポインタチェーンから、共有コードフィルタ、VMT と ReClass 風のクラス作業、ワールドからスクリーン座標変換、コード注入、整合性バイパス演習、制御フロー難読化、反デバッグ課題まで進みます。ブラウザベースの Web ダッシュボードと Python RPG マネージャーがクエスト完了を追跡し、自動アーティファクト採点器がアーキテクチャ、間接参照の深さ、フックの複雑さ、保護レベル、権限境界に基づいて提出物を評価します。本プロジェクトは、オンラインのアンチチート回避ではなく、ローカルの教育用ターゲットで実践的な RE とゲームセキュリティスキルを身につける自習型の学習者と趣味人を対象としています。
