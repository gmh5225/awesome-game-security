Android Kernel Kit is a pure Bash workflow toolkit that takes Android kernel source from build through repack, flash, and on-device verification. It automates clean, compile, boot image repacking via Android Image Kitchen or magiskboot, ADB flashing, log capture, and debug bundle collection, including automatic DTB handling and schema-driven per-project configuration. Toolchains, build streaming in tmux, and guided setup for missing dependencies are integrated so repeated kernel iterations stay predictable without manual AVB signing or full boot image rebuilds. It targets developers and security researchers working on custom Android kernels for device bring-up, low-level debugging, and environments where kernel changes support reverse engineering or mobile platform security work.
