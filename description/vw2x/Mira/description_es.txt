Mira es un banco de trabajo de detección en tiempo de ejecución móvil para iOS y Android que convierte casos en dispositivos reales en flujos de trabajo reutilizables y notas de detección. Las apps anfitrionas ofrecen shell en sandbox, PTY, captura de pantalla y herramientas de archivos; Frida admite hooks Java y nativos con RPC para análisis puntual en runtime. Un servidor relé Python y una consola web conectan dispositivos por LAN o mediante exposición por relé, y un servidor MCP permite que asistentes de IA trabajen en las mismas sesiones remotas. El código abarca Java en Android, Swift en iOS con una capa de compatibilidad basada en iSH, código PTY nativo compartido y una UI de control en Next.js. Está dirigido a investigadores de seguridad móvil, ingenieros inversos y equipos de anti-cheat o integridad que exploran canales auxiliares como root, emulador, proyección, Magisk, LSPosed e indicadores de jailbreak.
