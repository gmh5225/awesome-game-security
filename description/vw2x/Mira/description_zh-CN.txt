Mira 是一款面向 iOS 与 Android 的移动运行时检测工作台，可将真机案例整理为可复用的工作流与检测笔记。宿主应用提供沙箱化 Shell、PTY、屏幕采集与文件工具；Frida 支持 Java 与 native 钩子，并通过 RPC 进行一次性运行时分析。Python 中继服务器与 Web 控制台经局域网或中继暴露连接设备，MCP 服务器则让 AI 助手在同一远程会话中协作。代码库涵盖 Android Java、带 iSH 兼容层的 iOS Swift、共享 native PTY 代码，以及 Next.js 控制界面。面向移动安全研究人员、逆向工程师，以及探索 root、模拟器、投屏、Magisk、LSPosed、越狱等侧信道指标的反作弊或完整性团队。
