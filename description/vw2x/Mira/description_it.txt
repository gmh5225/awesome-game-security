Mira è un workbench di rilevamento runtime mobile per iOS e Android che trasforma casi su dispositivo reale in workflow riutilizzabili e note di rilevamento. Le app host forniscono shell in sandbox, PTY, cattura schermo e strumenti file, mentre Frida supporta hook Java e nativi con RPC per analisi runtime occasionali. Un server relay Python e una console web collegano i dispositivi in LAN o tramite esposizione relay, e un server MCP consente agli assistenti IA di lavorare nelle stesse sessioni remote. Il codice copre Java su Android, Swift su iOS con un layer di compatibilità basato su iSH, codice PTY nativo condiviso e un’interfaccia di controllo Next.js. È rivolto a ricercatori di sicurezza mobile, reverse engineer e team anti-cheat o integrità che esplorano canali laterali come root, emulatore, proiezione, Magisk, LSPosed e indicatori di jailbreak.
