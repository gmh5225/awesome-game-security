Mira は iOS と Android 向けのモバイルランタイム検知ワークベンチで、実機ケースを再利用可能なワークフローと検知メモに変換します。ホストアプリはサンドボックス化されたシェル、PTY、画面キャプチャ、ファイルツールを提供し、Frida は Java とネイティブフックおよび RPC による都度のランタイム分析をサポートします。Python リレーサーバーと Web コンソールが LAN またはリレー経由でデバイスに接続し、MCP サーバーにより AI アシスタントが同じリモートセッションで作業できます。コードベースは Android Java、iSH ベース互換レイヤ付き iOS Swift、共有ネイティブ PTY コード、Next.js 制御 UI に及びます。モバイルセキュリティ研究者、リバースエンジニア、root・エミュレータ・ミラーリング・Magisk・LSPosed・ジェイルブレイクなどのサイドチャネル指標を調査するアンチチートまたは整合性チームを対象としています。
