Mira est un banc de travail de détection runtime mobile pour iOS et Android qui transforme les cas sur appareil réel en workflows réutilisables et notes de détection. Les applications hôtes fournissent un shell sandboxé, PTY, capture d’écran et outils fichiers, tandis que Frida prend en charge les hooks Java et natifs avec RPC pour une analyse runtime ponctuelle. Un serveur relais Python et une console web connectent les appareils sur le LAN ou via une exposition relais, et un serveur MCP permet aux assistants IA de travailler dans les mêmes sessions distantes. La base de code couvre Java Android, Swift iOS avec une couche de compatibilité basée sur iSH, du code PTY natif partagé et une interface de contrôle Next.js. Elle s’adresse aux chercheurs en sécurité mobile, ingénieurs reverse et équipes anti-triche ou intégrité explorant des canaux auxiliaires tels que root, émulateur, projection, Magisk, LSPosed et indicateurs de jailbreak.
