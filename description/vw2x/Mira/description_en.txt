Mira is a mobile runtime detection workbench for iOS and Android that turns live device cases into reusable workflows and detection notes. Host apps provide sandboxed shell, PTY, screen capture, and file tooling, while Frida supports Java and native hooks with RPC for one-off runtime analysis. A Python relay server and web console connect devices over the LAN or through relay exposure, and an MCP server lets AI assistants work in the same remote sessions. The codebase spans Android Java, iOS Swift with an iSH-based compatibility layer, shared native PTY code, and a Next.js control UI. It targets mobile security researchers, reverse engineers, and anti-cheat or integrity teams exploring side channels such as root, emulator, projection, Magisk, LSPosed, and jailbreak indicators.
