Mira는 iOS와 Android용 모바일 런타임 탐지 워크벤치로, 실기기 사례를 재사용 가능한 워크플로와 탐지 노트로 정리합니다. 호스트 앱은 샌드박스 셸, PTY, 화면 캡처, 파일 도구를 제공하고, Frida는 Java 및 네이티브 후크와 RPC를 통한 일회성 런타임 분석을 지원합니다. Python 릴레이 서버와 웹 콘솔이 LAN 또는 릴레이 노출을 통해 기기에 연결하며, MCP 서버로 AI 어시스턴트가 동일한 원격 세션에서 작업할 수 있습니다. 코드베이스는 Android Java, iSH 기반 호환 계층이 있는 iOS Swift, 공유 네이티브 PTY 코드, Next.js 제어 UI를 포함합니다. 모바일 보안 연구자, 리버스 엔지니어, root·에뮬레이터·미러링·Magisk·LSPosed·탈옥 등 사이드 채널 지표를 탐색하는 안티치트 또는 무결성 팀을 대상으로 합니다.
