Двухэтапный конвейер распаковки для исполняемых файлов Windows, сочетающих защиту Themida или WinLicense с упаковкой Nuitka onefile. Написан на Python: сначала динамически снимается слой Themida с помощью unlicense, затем статически извлекается встроенная полезная нагрузка Nuitka KAX или KAY с помощью nuthem, который поддерживает как несжатые, так и сжатые zstd архивы, необязательные поля контрольных сумм и безопасное извлечение файлов с защитой от path traversal на основе манифестов SHA-256. Опциональный третий этап может быть связан с вспомогательными инструментами для восстановления Python-артефактов из внутреннего скомпилированного бинарника. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности, анализирующих дважды защищённые приложения Nuitka — например образцы вредоносного ПО или усиленные инструменты, связанные с играми, — когда ни один существующий распаковщик не обрабатывает оба слоя защиты.
