Themida 또는 WinLicense 보호와 Nuitka onefile 패키징이 결합된 Windows 실행 파일을 위한 2단계 언패킹 파이프라인입니다. Python으로 작성되었으며, 먼저 unlicense를 사용해 Themida 계층을 동적으로 제거한 다음, nuthem으로 내장된 Nuitka KAX 또는 KAY 페이로드를 정적으로 추출합니다. nuthem은 압축되지 않은 아카이브와 zstd 압축 아카이브, 선택적 체크섬 필드, SHA-256 매니페스트를 이용한 경로 탐색(path-traversal) 방지 파일 추출을 지원합니다. 선택적인 3단계에서는 연동 도구에 연결해 내부 컴파일된 바이너리에서 Python 아티팩트를 복구할 수 있습니다. 기존 단일 언패커로는 두 보호 계층을 모두 처리할 수 없는, 이중 보호된 Nuitka 애플리케이션(악성 코드 샘플이나 강화된 게임 관련 도구 등)을 분석하는 리버스 엔지니어 및 보안 연구자를 대상으로 합니다.
