Pipeline di decompressione in due fasi per eseguibili Windows che combinano protezione Themida o WinLicense con impacchettamento Nuitka onefile. Scritto in Python, rimuove prima dinamicamente il layer Themida usando unlicense, poi estrae staticamente il payload Nuitka KAX o KAY incorporato con nuthem, che gestisce archivi non compressi e compressi con zstd, campi checksum opzionali ed estrazione file sicura contro path traversal con manifest SHA-256. Una terza fase opzionale può collegarsi a strumenti complementari per recuperare artefatti Python dal binario compilato interno. È rivolto a reverse engineer e ricercatori di sicurezza che analizzano applicazioni Nuitka con doppia protezione, come campioni di malware o strumenti correlati ai giochi irrobustiti, dove nessun unpacker esistente gestisce entrambi i layer di protezione.
