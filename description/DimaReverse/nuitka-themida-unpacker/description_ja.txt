Windows 実行可能ファイル向けの二段階アンパックパイプラインで、Themida または WinLicense による保護と Nuitka onefile パッケージングが組み合わされたものが対象です。Python で実装され、まず unlicense を用いて Themida 層を動的に剥がし、続いて nuthem により内包された Nuitka KAX または KAY ペイロードを静的に抽出します。nuthem は非圧縮および zstd 圧縮アーカイブ、任意のチェックサムフィールド、SHA-256 マニフェストによるパストラバーサル安全なファイル抽出に対応します。オプションの第三段階では、連携ツールにチェーンして内部のコンパイル済みバイナリから Python アーティファクトを復元できます。既存の単一アンパッカーでは両方の保護層を扱えない、二重保護された Nuitka アプリケーション（マルウェアサンプルや強化されたゲーム関連ツールなど）を解析するリバースエンジニアおよびセキュリティ研究者向けです。
