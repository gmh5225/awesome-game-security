適用於 Windows 可執行檔的兩階段脫殼管線，用於同時採用 Themida 或 WinLicense 保護與 Nuitka onefile 封裝的程式。本工具以 Python 撰寫，首先透過 unlicense 動態剝除 Themida 層，再使用 nuthem 靜態提取內嵌的 Nuitka KAX 或 KAY 載荷；nuthem 支援未壓縮與 zstd 壓縮的封存、選用校驗和欄位，以及基於 SHA-256 清單的路徑穿越安全檔案提取。可選的第三階段可串接配套工具，從內部編譯的二進位檔中還原 Python 產物。面向需要分析雙重保護 Nuitka 應用的逆向工程師與安全研究人員，例如惡意軟體樣本或加固的遊戲相關工具，且現有單一脫殼器無法同時處理兩層保護的情境。
