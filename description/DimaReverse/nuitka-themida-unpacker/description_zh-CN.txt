用于 Windows 可执行文件的两阶段脱壳流水线，适用于同时采用 Themida 或 WinLicense 保护与 Nuitka onefile 打包的程序。该工具以 Python 编写，首先通过 unlicense 动态剥离 Themida 层，随后使用 nuthem 静态提取内嵌的 Nuitka KAX 或 KAY 载荷；nuthem 支持未压缩与 zstd 压缩的归档、可选校验和字段，以及基于 SHA-256 清单的路径穿越安全文件提取。可选的第三阶段可链接配套工具，从内部编译二进制中恢复 Python 工件。面向需要分析双重保护 Nuitka 应用的逆向工程师与安全研究人员，例如恶意软件样本或加固的游戏相关工具，且现有单一脱壳器无法同时处理两层保护的场景。
