ACID MAZE는 브라우저 기반 레트로 미로 추격 아케이드 게임으로, 오리지널 그래픽과 오디오, 80년대 클래식 아케이드 캐비닛을 연상시키는 여러 플레이 모드를 제공합니다. 스택은 Gunicorn과 gevent로 서빙하는 Python Flask 백엔드, JavaScript 클라이언트, static/core.js의 공유 결정론적 게임 코어, 점수용 SQLite, 배포용 Docker와 QuickJS로 구성됩니다. 리더보드 무결성은 서버 검증 런에 달려 있으며, 클라이언트는 틱마다 입력을 기록하고 백엔드는 동일한 고정 타임스텝 시뮬레이션으로 리플레이한 뒤 점수를 수락하며, 변조·재사용·미완료·과대 제출을 거부하고 주소별 속도 제한을 적용합니다. 시뮬레이션은 시드 PRNG와 고정소수점 연산으로 리플레이를 재현 가능하게 하며, 자동화 테스트가 API 리플레이와 치팅 시나리오를 검증합니다. 커널 수준의 안티치트가 아니라 웹 게임용 실용적 안티치트·점수 검증 패턴을 공부하는 개발자에게 적합합니다.
