ACID MAZE はブラウザ上で動くレトロな迷路チェイス系アーケードゲームで、オリジナルのグラフィックと音声、80 年代の筐体を思わせる複数のプレイモードを備えます。スタックは Gunicorn と gevent で提供する Python Flask バックエンド、JavaScript クライアント、static/core.js にある共有の決定論的ゲームコア、スコア用 SQLite、デプロイ用の Docker と QuickJS で構成されます。リーダーボードの信頼性はサーバー検証ランに依存し、クライアントはティックごとの入力を記録し、バックエンドは同じ固定タイムステップのシミュレーションでリプレイしてからスコアを受理し、改ざん・再利用・不完全・サイズ超過の送信を拒否し、アドレスごとのレート制限も行います。シミュレーションはシード付き PRNG と固定小数点演算でリプレイを再現可能にし、自動テストが API リプレイとチートシナリオを検証します。カーネルレベルの反チートではなく、Web ゲーム向けの実用的な反チートとスコア検証パターンを学ぶ開発者向けです。
