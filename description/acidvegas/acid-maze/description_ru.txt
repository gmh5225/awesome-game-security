ACID MAZE — ретро-аркада погони в лабиринте в браузере с оригинальной графикой, звуком и несколькими режимами, напоминающими классические автоматы 80-х. Стек включает бэкенд на Python Flask с Gunicorn и gevent, JavaScript-клиент и общее детерминированное игровое ядро в static/core.js, SQLite для очков и Docker с QuickJS для развёртывания. Целостность таблицы лидеров обеспечивается серверной проверкой заходов: клиент логирует ввод по тикам, бэкенд воспроизводит их в той же симуляции с фиксированным шагом времени перед принятием результата, отклоняя подделанные, повторно использованные, неполные или слишком большие отправки, а также лимитируя частоту по адресу. Симуляция использует PRNG с сидом и фиксированную арифметику для воспроизводимых реплеев; автоматические тесты проверяют API-реплей и сценарии читерства. Подходит разработчикам, изучающим практические схемы античита и проверки очков для веб-игр, а не инструменты античита уровня ядра.
