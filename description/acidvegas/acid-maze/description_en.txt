ACID MAZE is a browser-based retro maze chase arcade game with original graphics, audio, and multiple play modes reminiscent of classic 80s cabinets. The stack combines a Python Flask backend served with Gunicorn and gevent, a JavaScript client and shared deterministic game core in static/core.js, SQLite for scores, and Docker with QuickJS for deployment. Leaderboard integrity comes from server-verified runs: the client logs per-tick inputs, and the backend replays them through the same fixed-timestep simulation before accepting a score, rejecting tampered, reused, incomplete, or oversized submissions along with per-address rate limits. The simulation uses seeded PRNGs and fixed-point math so replays are reproducible, and automated tests exercise API replay and cheating scenarios. It suits developers studying practical anti-cheat and score-validation patterns for web games rather than kernel-level anti-cheat tooling.
