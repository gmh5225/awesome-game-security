ACID MAZE 是一款基于浏览器的复古迷宫追逐街机游戏，拥有原创画面与音效，并提供多种游玩模式，令人联想到 80 年代经典街机柜。技术栈包括以 Gunicorn 与 gevent 部署的 Python Flask 后端、JavaScript 客户端及位于 static/core.js 的共享确定性游戏核心、用于成绩的 SQLite，以及用于部署的 Docker 与 QuickJS。排行榜完整性依赖服务端校验对局：客户端记录每帧输入，后端在采纳成绩前用相同固定时间步模拟重放，并拒绝被篡改、重复使用、不完整或过大的提交，同时对每个地址实施速率限制。模拟使用带种子的 PRNG 与定点运算以保证重放可复现，自动化测试覆盖 API 重放与作弊场景。该项目适合开发者研究网页游戏的实用反作弊与成绩校验模式，而非内核级反作弊工具。
