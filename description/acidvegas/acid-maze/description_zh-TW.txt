ACID MAZE 是一款以瀏覽器運行的復古迷宮追逐街機遊戲，具原創圖形與音效，並提供多種遊玩模式，令人聯想 80 年代經典街機櫃。技術堆疊包含以 Gunicorn 與 gevent 提供的 Python Flask 後端、JavaScript 用戶端，以及位於 static/core.js 的共用確定性遊戲核心、用於分數的 SQLite，以及用於部署的 Docker 與 QuickJS。排行榜完整性依賴伺服器驗證的局次：用戶端記錄每個 tick 的輸入，後端在接受分數前以相同的固定時間步模擬重放，並拒絕遭竄改、重複使用、不完整或過大的提交，同時對每個位址實施速率限制。模擬使用有種子的 PRNG 與定點運算，使重放可重現，自動化測試涵蓋 API 重放與作弊情境。適合開發者研究網頁遊戲的實用反作弊與分數驗證模式，而非核心層級的反作弊工具。
