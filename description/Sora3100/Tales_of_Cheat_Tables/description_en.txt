This project is a curated library of Cheat Engine tables for many entries in Bandai Namco's Tales series across PC, console, and emulator builds. Each table is an XML cheat table that uses Auto Assembler and embedded Lua to resolve process-specific bases, AOB scans, and fixed offsets so players and researchers can view and edit party, stats, skills, items, and other in-memory game state. The repository also ships companion patches and configs for PCSX2, RPCS3, PPSSPP, and PlayStation Vita tooling, including YAML RPCS3 patches, pnach and ini files, and Vita multiplayer or vitacheat assets. It is aimed at modders and reverse engineers who study JRPG save and runtime data layouts, prototype trainers, or explore how classic Tales binaries expose mutable state under emulation.
