本プロジェクトは、バンダイナムコのテイルズシリーズ多数のタイトル向けに、PC・本体・エミュレータ版を横断して収録した Cheat Engine テーブルのキュレーションライブラリです。各テーブルは XML 形式のチートテーブルで、Auto Assembler と組み込み Lua によりプロセス固有のベース、アオブスキャン、固定オフセットを解決し、プレイヤーや研究者がパーティー、ステータス、スキル、アイテムその他のメモリ上ゲーム状態を参照・編集できるようにします。リポジトリには PCSX2、RPCS3、PPSSPP、PlayStation Vita 向けツール用のパッチと設定も同梱され、RPCS3 用 YAML パッチ、pnach や ini、Vita マルチプレイや vitacheat 向けアセットを含みます。JRPG のセーブデータやランタイムデータレイアウトを調べる mod 作者やリバースエンジニア、プロトタイプのトレーナー作成、エミュレーション下で古典的なテイルズ系バイナリがどのように可変状態を露出するかを探る用途を想定しています。
