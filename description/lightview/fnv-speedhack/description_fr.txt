Ce projet apporte un contrôle de vitesse de jeu façon Cheat Engine pour Fallout: New Vegas, permettant de faire tourner le jeu du ralenti jusqu’à environ dix fois la vitesse normale via raccourcis clavier ou entrée manette. Il prend la forme d’une petite DLL Windows qui utilise MinHook pour intercepter des API de temps telles que QueryPerformanceCounter, GetTickCount, GetTickCount64 et timeGetTime dans le processus du jeu et mettre à l’échelle le temps écoulé, sans modifier l’exécutable ni poursuivre des adresses mémoire propres au jeu. La même base de code produit soit un plugin NVSE, soit un proxy dinput8 placé à côté de l’exécutable du jeu (avec des instructions d’override Proton pour Linux), ainsi qu’un plugin facultatif Decky Loader pour Steam Deck qui installe le proxy et lit les palettes arrière via hidraw avec une IPC fichier basée sur INI. La configuration prend en charge les raccourcis clavier, le cycle de préréglages, des combos de boutons XInput optionnels, un retour par bips et la journalisation. Il s’adresse aux joueurs solo et aux moddeurs sous Windows et Steam Deck qui veulent un réglage de vitesse pratique et des outils pour étudier le comportement des hooks de timing dans les titres de l’ère Gamebryo.
