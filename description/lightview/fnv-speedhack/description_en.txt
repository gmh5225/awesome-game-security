This project provides Cheat Engine–style game speed control for Fallout: New Vegas, letting you run the game from slow motion up to ten times normal speed from hotkeys or controller input. It is implemented as a small Windows DLL that uses MinHook to intercept timing APIs such as QueryPerformanceCounter, GetTickCount, GetTickCount64, and timeGetTime inside the game process and scale elapsed time, without patching the executable or chasing game-specific memory addresses. The same codebase builds either an NVSE plugin or a dinput8 proxy dropped next to the game executable (with Proton override instructions for Linux), plus an optional Decky Loader plugin for Steam Deck that installs the proxy and reads back-paddle input via hidraw with INI-based file IPC. Configuration supports keyboard hotkeys, preset cycling, optional XInput button combos, beep feedback, and logging. It is aimed at single-player players and modders on Windows and Steam Deck who want convenient speed control and tooling for research into how timing hooks behave in Gamebryo-era titles.
