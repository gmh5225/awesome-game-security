Este proyecto ofrece control de velocidad de juego al estilo Cheat Engine para Fallout: New Vegas, permitiendo ir desde cámara lenta hasta unas diez veces la velocidad normal mediante teclas de acceso rápido o entrada de mando. Está implementado como una DLL pequeña de Windows que usa MinHook para interceptar APIs de tiempo como QueryPerformanceCounter, GetTickCount, GetTickCount64 y timeGetTime dentro del proceso del juego y escalar el tiempo transcurrido, sin parchear el ejecutable ni perseguir direcciones de memoria específicas del juego. La misma base de código compila como plugin de NVSE o como proxy dinput8 colocado junto al ejecutable del juego (con instrucciones de override de Proton para Linux), más un plugin opcional de Decky Loader para Steam Deck que instala el proxy y lee la entrada de paletas traseras vía hidraw con IPC por archivo basado en INI. La configuración admite atajos de teclado, ciclo de ajustes predefinidos, combinaciones opcionales de botones XInput, retroalimentación por pitido y registro. Está pensado para jugadores en un solo jugador y modders en Windows y Steam Deck que quieren control de velocidad cómodo y herramientas para investigar cómo se comportan los hooks de temporización en títulos de la era Gamebryo.
