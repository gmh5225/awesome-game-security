이 프로젝트는 Fallout: New Vegas에 Cheat Engine 스타일의 게임 속도 제어를 제공하며, 핫키나 컨트롤러 입력으로 슬로우 모션부터 정상 속도의 최대 약 10배까지 조절할 수 있습니다. 작은 Windows DLL로 구현되었으며 MinHook으로 게임 프로세스 안의 QueryPerformanceCounter, GetTickCount, GetTickCount64, timeGetTime 등 타이밍 API를 가로채 경과 시간을 스케일링하고, 실행 파일 패치나 게임 전용 메모리 주소 추적은 하지 않습니다. 동일 코드베이스로 NVSE 플러그인 또는 게임 실행 파일 옆에 두는 dinput8 프록시(Linux용 Proton 오버라이드 안내 포함)를 빌드할 수 있으며, Steam Deck용 선택적 Decky Loader 플러그인으로 프록시를 설치하고 hidraw로 후면 패들 입력을 읽으며 INI 기반 파일 IPC를 사용합니다. 설정은 키보드 핫키, 프리셋 순환, 선택적 XInput 버튼 조합, 삐 소리 피드백, 로깅을 지원합니다. Windows와 Steam Deck에서 편리한 속도 제어와 Gamebryo 시대 작품에서 타이밍 훅이 어떻게 동작하는지 연구하기 위한 도구를 원하는 싱글 플레이어 플레이어와 모더를 대상으로 합니다.
