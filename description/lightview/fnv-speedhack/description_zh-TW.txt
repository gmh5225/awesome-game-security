本專案為《異塵餘生：新維加斯》提供類似 Cheat Engine 的遊戲速度控制，可透過熱鍵或手把輸入將遊戲從慢動作調到最高約十倍正常速度。實作為小型 Windows DLL，使用 MinHook 攔截遊戲程序內的 QueryPerformanceCounter、GetTickCount、GetTickCount64、timeGetTime 等計時 API 並縮放經過時間，無需修改執行檔或追蹤遊戲專用記憶體位址。同一代碼庫可建置為 NVSE 外掛，或作為放在遊戲執行檔旁的 dinput8 代理（附 Linux 上 Proton 覆寫說明），另可選用 Decky Loader 外掛供 Steam Deck，用於安裝該代理並透過 hidraw 讀取背板按鍵輸入，採以 INI 為基礎的檔案 IPC。設定支援鍵盤熱鍵、預設循環、可選的 XInput 組合鍵、嗶聲回饋與記錄。對象為 Windows 與 Steam Deck 上的單機玩家與模組作者，便於調速並研究 Gamebryo 時代遊戲中計時攔截的行為。
