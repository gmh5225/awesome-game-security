本プロジェクトは『Fallout: New Vegas』向けに Cheat Engine 風のゲーム速度制御を提供し、ホットキーやコントローラー入力でスローモーションから通常速の最大約 10 倍まで調整できます。小さな Windows DLL として実装され、MinHook でゲームプロセス内の QueryPerformanceCounter、GetTickCount、GetTickCount64、timeGetTime などのタイミング API をフックして経過時間をスケールし、実行ファイルのパッチやゲーム固有アドレスの追跡は不要です。同じコードベースから NVSE プラグイン、またはゲーム実行ファイルと同じ場所に置く dinput8 プロキシ（Linux 向け Proton オーバーライド手順付き）のいずれかをビルドでき、Steam Deck 向けにはオプションの Decky Loader プラグインでプロキシを導入し、hidraw で背面パドル入力を読み取り、INI ベースのファイル IPC を行います。設定ではキーボードホットキー、プリセット切替、任意の XInput ボタンコンボ、ビープ音フィードバック、ログに対応しています。Windows および Steam Deck でのシングルプレイヤー向けプレイヤーとモッダー向けに、手軽な速度調整と、Gamebryo 世代タイトルにおけるタイミングフックの挙動を調べるためのツールとして位置づけられています。
