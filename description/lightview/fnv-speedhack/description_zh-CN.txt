本项目为《辐射：新维加斯》提供类似 Cheat Engine 的游戏速度控制，可通过热键或手柄输入将游戏从慢动作调节到最高约十倍正常速度。实现为小型 Windows DLL，使用 MinHook 拦截游戏进程内的 QueryPerformanceCounter、GetTickCount、GetTickCount64、timeGetTime 等计时 API 并缩放经过时间，无需修改可执行文件或追踪游戏专属内存地址。同一代码库可编译为 NVSE 插件，或作为放在游戏可执行文件旁的 dinput8 代理（附带 Linux 下 Proton 覆盖说明），另可选 Decky Loader 插件供 Steam Deck 使用，用于安装该代理并通过 hidraw 读取背键输入，以基于 INI 文件的 IPC 通信。配置支持键盘热键、预设循环、可选的 XInput 组合键、蜂鸣反馈与日志。面向 Windows 与 Steam Deck 上的单机玩家和模组作者，便于调速并研究 Gamebryo 时代游戏中计时钩子如何表现。
