Этот проект даёт управление скоростью игры в духе Cheat Engine для Fallout: New Vegas и позволяет переключаться от замедленной съёмки примерно до десятикратной нормальной скорости с помощью горячих клавиш или ввода с геймпада. Реализовано как небольшая DLL для Windows с MinHook, которая перехватывает API времени вроде QueryPerformanceCounter, GetTickCount, GetTickCount64 и timeGetTime внутри процесса игры и масштабирует прошедшее время, без патча исполняемого файла и без поиска игровых адресов в памяти. Из того же кода собирается либо плагин NVSE, либо прокси dinput8 рядом с исполняемым файлом игры (с инструкциями по override Proton для Linux), плюс опциональный плагин Decky Loader для Steam Deck, устанавливающий прокси и читающий ввод задних пэдлов через hidraw с IPC через INI-файлы. Настройки поддерживают горячие клавиши, перебор пресетов, опциональные комбинации кнопок XInput, звуковой сигнал и логирование. Рассчитан на одиночных игроков и моддеров под Windows и Steam Deck, которым нужны удобный контроль скорости и средства для исследования поведения хуков времени в играх эпохи Gamebryo.
