Darwin-vm 是一個以 QEMU 為基礎的環境，可在無需越獄或核心修補的情況下，將輕量、可除錯的 iOS 與 macOS（Darwin）系統開機至 root shell。它透過支援 SPTM、TXM 與以 MIE 為基礎之核心的自訂 qemu-sptm 分支，模擬從 iPhone 12 到 iPhone 17 以及 M1 到 M5 Mac 的 Apple Silicon 裝置。Python 與 shell 指令碼可自動完成 IPSW 擷取、檔案系統修補、trust-cache 簽署與虛擬機器啟動，同時 GDB 或 LLDB 可附加以進行核心與使用者空間除錯。研究人員可編譯並執行自訂 root 層級程式，替換 Apple Kernel Debug Kits 中的開發核心，並檢查或修補核心、dyld、launchd 及其他底層 Darwin 元件。它面向需要快速、可重現沙箱以研究 Apple 平台內部機制的安全研究人員、逆向工程師與核心開發者。
