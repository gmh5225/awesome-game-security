Darwin-vm は、脱獄やカーネルパッチなしで、軽量かつデバッグ可能な iOS および macOS（Darwin）システムを root シェルまで起動できる QEMU ベースの環境です。SPTM、TXM、MIE ベースのカーネルをサポートするカスタム qemu-sptm フォークを用いて、iPhone 12 から iPhone 17、M1 から M5 Mac までの Apple Silicon デバイスをエミュレートします。Python とシェルスクリプトが IPSW 抽出、ファイルシステムのパッチ適用、trust-cache 署名、VM 起動を自動化し、GDB や LLDB をアタッチしてカーネルおよびユーザースペースのデバッグが可能です。研究者はカスタムの root レベルプログラムをコンパイル・実行し、Apple Kernel Debug Kits から開発用カーネルを差し替え、カーネル、dyld、launchd などの低レベル Darwin コンポーネントを調査・パッチ適用できます。Apple プラットフォームの内部を研究するための高速で再現可能なサンドボックスを必要とするセキュリティ研究者、リバースエンジニア、カーネル開発者を対象としています。
