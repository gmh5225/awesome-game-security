Darwin-vm is a QEMU-based environment for booting lightweight, debuggable iOS and macOS (Darwin) systems to a root shell without a jailbreak or kernel patches. It emulates Apple Silicon devices from iPhone 12 through iPhone 17 and M1 through M5 Macs using a custom qemu-sptm fork that supports SPTM, TXM, and MIE-based kernels. Python and shell scripts automate IPSW extraction, filesystem patching, trust-cache signing, and VM launch, while GDB or LLDB can attach for kernel and userspace debugging. Researchers can compile and run custom root-level programs, swap in development kernels from Apple Kernel Debug Kits, and inspect or patch the kernel, dyld, launchd, and other low-level Darwin components. It targets security researchers, reverse engineers, and kernel developers who need a fast, reproducible sandbox for studying Apple platform internals.
