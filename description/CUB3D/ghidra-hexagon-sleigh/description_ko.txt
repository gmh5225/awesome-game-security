이 프로젝트는 SLEIGH를 사용하여 Qualcomm Hexagon QDSP6 아키텍처의 디스어셈블리 및 디컴파일을 구현하는 Ghidra 프로세서 모듈 및 확장 기능입니다. Hexagon v81 명령어를 지원하며, 대부분의 연산에 pcode를 제공하고, 하드웨어 루프, predicate 처리, System/Monitor 및 System/Guest 모드를 지원합니다. 확장 기능에는 Java 분석기, QDB 로그 뷰어, Python 스크립트가 포함되어 QMI 핸들러 탐색, QuRT 태스크 식별, RTTI 주석, 에뮬레이션을 통한 Q6Zip 또는 DLPager 압축 해제 등 Qualcomm 특화 작업을 수행합니다. SLEIGH, Java, Python, Gradle로 구축되었으며, 게임 보안 및 모바일 보안 연구에서 Qualcomm 펌웨어와 바이너리를 분석하는 리버스 엔지니어를 대상으로 합니다.
