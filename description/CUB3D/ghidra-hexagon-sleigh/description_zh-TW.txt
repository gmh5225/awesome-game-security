本專案是一個 Ghidra 處理器模組與擴充功能，使用 SLEIGH 實作 Qualcomm Hexagon QDSP6 架構的反組譯與反編譯。它支援 Hexagon v81 指令，為大多數操作提供 pcode，並涵蓋硬體迴圈、述詞處理以及 System/Monitor 與 System/Guest 模式。此擴充功能包含 Java 分析器、QDB 日誌檢視器以及 Python 指令碼，用於 Qualcomm 特定工作，例如 QMI 處理器探索、QuRT 任務識別、RTTI 標註，以及透過模擬進行 Q6Zip 或 DLPager 解壓縮。以 SLEIGH、Java、Python 和 Gradle 建置，面向在遊戲安全與行動安全研究中分析 Qualcomm 韌體與二進位檔案的逆向工程師。
