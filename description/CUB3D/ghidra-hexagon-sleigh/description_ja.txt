このプロジェクトは、SLEIGH を用いて Qualcomm Hexagon QDSP6 アーキテクチャの逆アセンブルと逆コンパイルを実装する Ghidra プロセッサモジュールおよび拡張機能です。Hexagon v81 命令をサポートし、ほとんどの操作に pcode を提供し、ハードウェアループ、述語処理、System/Monitor および System/Guest モードに対応します。拡張機能には Java アナライザ、QDB ログビューア、Python スクリプトが含まれ、QMI ハンドラ探索、QuRT タスク識別、RTTI アノテーション、エミュレーションによる Q6Zip または DLPager の解凍など、Qualcomm 固有のタスクに対応します。SLEIGH、Java、Python、Gradle で構築され、ゲームセキュリティおよびモバイルセキュリティ研究における Qualcomm ファームウェアとバイナリの解析を行うリバースエンジニア向けです。
