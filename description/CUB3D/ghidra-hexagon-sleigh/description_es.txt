Este proyecto es un módulo de procesador y extensión de Ghidra que implementa la arquitectura Qualcomm Hexagon QDSP6 en SLEIGH para desensamblado y descompilación. Admite instrucciones Hexagon v81 con pcode para la mayoría de las operaciones, bucles de hardware, manejo de predicados y modos System/Monitor y System/Guest. La extensión incluye analizadores Java, un visor de registros QDB y scripts Python para tareas específicas de Qualcomm, como descubrimiento de manejadores QMI, identificación de tareas QuRT, anotación RTTI y descompresión Q6Zip o DLPager mediante emulación. Construido con SLEIGH, Java, Python y Gradle, está dirigido a ingenieros de ingeniería inversa que analizan firmware y binarios Qualcomm en investigación de seguridad de juegos y seguridad móvil.
