该项目是一个 Ghidra 处理器模块与扩展，使用 SLEIGH 实现 Qualcomm Hexagon QDSP6 架构的反汇编与反编译。它支持 Hexagon v81 指令，为大多数操作提供 pcode，并涵盖硬件循环、谓词处理以及 System/Monitor 与 System/Guest 模式。该扩展包含 Java 分析器、QDB 日志查看器以及 Python 脚本，用于 Qualcomm 特定任务，例如 QMI 处理器发现、QuRT 任务识别、RTTI 标注，以及通过模拟实现 Q6Zip 或 DLPager 解压。基于 SLEIGH、Java、Python 和 Gradle 构建，面向在游戏安全与移动安全研究中分析 Qualcomm 固件与二进制文件的逆向工程师。
