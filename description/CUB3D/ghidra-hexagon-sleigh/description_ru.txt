Этот проект представляет собой модуль процессора и расширение Ghidra, реализующее архитектуру Qualcomm Hexagon QDSP6 в SLEIGH для дизасsemblирования и декомпиляции. Поддерживаются инструкции Hexagon v81 с pcode для большинства операций, аппаратные циклы, обработка предикатов, а также режимы System/Monitor и System/Guest. Расширение включает Java-анализаторы, просмотрщик логов QDB и Python-скрипты для задач, специфичных для Qualcomm, таких как обнаружение обработчиков QMI, идентификация задач QuRT, аннотация RTTI и распаковка Q6Zip или DLPager через эмуляцию. Создан с использованием SLEIGH, Java, Python и Gradle; предназначен для специалистов по обратной разработке, анализирующих прошивки и бинарные файлы Qualcomm в исследованиях безопасности игр и мобильных устройств.
