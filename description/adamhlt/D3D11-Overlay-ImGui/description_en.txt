D3D11 Overlay ImGui is a Windows C++ sample that draws an ImGui interface in a transparent, topmost overlay on top of a running game or application. It uses DirectX 11 for rendering and can be built as an external EXE with a window picker or as an injectable DLL that attaches to a process main window, in both x86 and x64. The overlay tracks the target window position, size, and focus, supports click-through when the menu is hidden, and implements techniques to hide the overlay from OBS and similar capture tools. Developers customize the UI in Drawing code and use it as a starter for external or internal overlays common in game tooling, modding, and game security research.
