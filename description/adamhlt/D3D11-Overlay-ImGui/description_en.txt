D3D11 Overlay ImGui is a Windows C++ sample that renders an ImGui interface in a transparent, topmost layer above a chosen game or application. It uses DirectX 11 with the official ImGui Win32 and DX11 backends, and tracks the target window's position, size, and focus so the overlay works even when the host does not use DirectX. The same source builds as a standalone EXE with a window picker for external overlays or as an injectable DLL that attaches to a process's main window, in both x86 and x64. Notable behavior includes click-through when the menu is hidden, automatic shutdown when the target closes, and techniques to hide the overlay from OBS and common screen-capture tools. It is aimed at developers exploring game overlays, injection-based tooling, and related reverse engineering or game-security research on Windows.
