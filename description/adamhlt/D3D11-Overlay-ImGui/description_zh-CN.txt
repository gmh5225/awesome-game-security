D3D11 Overlay ImGui 是一款 Windows C++ 示例，在指定游戏或应用上方以透明、置顶图层渲染 ImGui 界面。它使用 DirectX 11 及官方 ImGui Win32 与 DX11 后端，并跟踪目标窗口的位置、尺寸与焦点，因此即使宿主程序不使用 DirectX，叠加层仍可正常工作。同一源码可编译为带窗口选择器的独立 EXE（用于外部叠加），或可注入 DLL（附着到进程主窗口），均支持 x86 与 x64。特性包括菜单隐藏时点击穿透、目标关闭时自动退出，以及规避 OBS 等常见录屏工具捕获叠加层的手段。面向研究游戏叠加层、基于注入的工具，以及 Windows 上相关逆向与游戏安全开发的开发者。
