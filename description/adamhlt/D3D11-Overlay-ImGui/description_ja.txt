D3D11 Overlay ImGui は、選択したゲームやアプリケーションの上に透明で最前面のレイヤーとして ImGui インターフェースを描画する Windows 向け C++ サンプルです。DirectX 11 と公式の ImGui Win32・DX11 バックエンドを用い、対象ウィンドウの位置・サイズ・フォーカスを追跡するため、ホストが DirectX を使っていなくてもオーバーレイが動作します。同じソースから、ウィンドウ選択付きのスタンドアロン EXE（外部オーバーレイ用）と、プロセスのメインウィンドウにアタッチする注入可能な DLL の両方を x86・x64 でビルドできます。メニュー非表示時のクリックスルー、対象終了時の自動シャットダウン、OBS や一般的な画面キャプチャツールからオーバーレイを隠す手法などが特徴です。ゲームオーバーレイ、注入ベースのツール、Windows 上のリバースエンジニアリングやゲームセキュリティ研究に取り組む開発者向けです。
