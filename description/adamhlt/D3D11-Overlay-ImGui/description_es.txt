D3D11 Overlay ImGui es un ejemplo en C++ para Windows que renderiza una interfaz ImGui en una capa transparente y siempre visible encima de un juego o aplicación elegidos. Usa DirectX 11 con los backends oficiales de ImGui para Win32 y DX11, y sigue la posición, el tamaño y el foco de la ventana objetivo para que la superposición funcione aunque el proceso anfitrión no use DirectX. El mismo código se compila como EXE independiente con selector de ventana para overlays externos o como DLL inyectable que se adjunta a la ventana principal del proceso, en x86 y x64. Comportamientos destacados: clic a través cuando el menú está oculto, cierre automático al cerrar el objetivo y técnicas para ocultar el overlay a OBS y herramientas habituales de captura de pantalla. Está orientado a desarrolladores que exploran overlays de juegos, herramientas basadas en inyección e ingeniería inversa o investigación de seguridad en juegos en Windows.
