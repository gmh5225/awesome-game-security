D3D11 Overlay ImGui는 선택한 게임이나 애플리케이션 위에 투명하고 항상 위에 표시되는 레이어로 ImGui 인터페이스를 렌더링하는 Windows용 C++ 샘플입니다. DirectX 11과 공식 ImGui Win32·DX11 백엔드를 사용하며 대상 창의 위치, 크기, 포커스를 추적해 호스트가 DirectX를 쓰지 않아도 오버레이가 동작합니다. 동일한 소스로 창 선택기가 있는 독립 EXE(외부 오버레이) 또는 프로세스 메인 창에 붙는 주입 가능 DLL을 x86·x64 모두에서 빌드할 수 있습니다. 메뉴 숨김 시 클릭 통과, 대상 종료 시 자동 종료, OBS 및 일반 화면 캡처 도구에서 오버레이를 숨기는 기법 등이 특징입니다. 게임 오버레이, 주입 기반 도구, Windows에서의 역공학 및 게임 보안 연구를 탐구하는 개발자를 대상으로 합니다.
