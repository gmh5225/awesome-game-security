D3D11 Overlay ImGui 是一款 Windows C++ 範例，在指定遊戲或應用程式上方以透明、置頂圖層渲染 ImGui 介面。它使用 DirectX 11 及官方 ImGui Win32 與 DX11 後端，並追蹤目標視窗的位置、大小與焦點，因此即使宿主程式不使用 DirectX，疊加層仍可正常運作。同一原始碼可編譯為附視窗選擇器的獨立 EXE（用於外部疊加），或可注入 DLL（附著到行程主視窗），皆支援 x86 與 x64。值得注意的行為包含選單隱藏時點擊穿透、目標關閉時自動結束，以及躲避 OBS 等常見螢幕擷取工具的手法。供探索遊戲疊加層、以注入為基礎的工具，以及 Windows 上相關逆向與遊戲安全研究的開發者使用。
