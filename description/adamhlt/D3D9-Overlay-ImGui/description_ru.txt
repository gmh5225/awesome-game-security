Этот проект — стартовый шаблон для Windows, позволяющий рисовать интерфейс Dear ImGui и пользовательскую графику поверх другого приложения с помощью Direct3D 9. Написан на C++ для Visual Studio, поставляется с бэкендами ImGui для D3D9 и Win32 и линкуется с d3d9.lib. Его можно собрать как автономный исполняемый файл, который перечисляет открытые окна и подключает оверлей к выбранной цели, или как DLL через отдельные конфигурации решения. Пример кода отделяет отрисовку меню ImGui от «сырой» отрисовки D3D9, переключает интерфейс клавишей Insert и содержит вспомогательные функции, например очистку залитым прямоугольником. Ориентирован на разработчиков, изучающих внешние оверлеи, инструменты для игр или рабочие процессы реверс-инжиниринга на старых играх с D3D9.
