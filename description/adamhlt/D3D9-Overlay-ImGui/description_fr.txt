Ce projet est un modèle de démarrage Windows pour dessiner une interface Dear ImGui et des graphismes personnalisés par-dessus une autre application via Direct3D 9. Il est écrit en C++ pour Visual Studio et inclut les backends ImGui D3D9 et Win32, avec liaison contre d3d9.lib. Vous pouvez le compiler en exécutable autonome qui liste les fenêtres ouvertes et attache l’overlay à une cible choisie, ou en DLL via des configurations de solution dédiées. Le code d’exemple sépare le rendu du menu ImGui du dessin D3D9 brut, bascule l’interface avec la touche Insert et fournit des aides comme le remplissage par rectangles. Il s’adresse aux développeurs qui apprennent les overlays externes, les outils pour jeux ou les flux de travail de rétro-ingénierie sur d’anciens titres D3D9.
