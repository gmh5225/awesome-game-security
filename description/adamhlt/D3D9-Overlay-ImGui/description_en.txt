This project is a Visual Studio C++ template for rendering a Dear ImGui interface and custom Direct3D 9 graphics on top of another Windows application's existing D3D9 swap chain. It can be built as a standalone executable that lists open windows and lets you pick a target HWND before starting the overlay, or as a DLL configuration for in-process attachment. Sample code separates ImGui menu drawing from optional raw IDirect3DDevice9 calls, toggles visibility with the INSERT key, and bundles the standard Win32 and D3D9 ImGui backends. It is aimed at reverse engineers, overlay developers, and game security researchers who want a minimal starting point for studying or prototyping in-process D3D9 hooks and on-screen debug or tooling UIs.
