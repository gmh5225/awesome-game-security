This project is a Windows starter template for drawing a Dear ImGui interface and custom graphics on top of another application using Direct3D 9. It is written in C++ for Visual Studio and ships with the D3D9 and Win32 ImGui backends, linking against d3d9.lib. You can build it as a standalone executable that lists open windows and attaches the overlay to a chosen target, or as a DLL via dedicated solution configurations. The sample code separates ImGui menu rendering from raw D3D9 drawing, toggles the UI with the Insert key, and includes helpers such as filled-rectangle clears. It is aimed at developers learning external overlays, game tooling, or reverse-engineering workflows on older D3D9 titles.
