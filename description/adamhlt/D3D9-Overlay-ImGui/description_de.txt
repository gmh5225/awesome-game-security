Dieses Projekt ist eine Windows-Startervorlage zum Zeichnen einer Dear-ImGui-Oberfläche und eigener Grafik über einer anderen Anwendung mit Direct3D 9. Es ist in C++ für Visual Studio geschrieben und enthält die D3D9- und Win32-ImGui-Backends mit Verknüpfung gegen d3d9.lib. Sie können es als eigenständige ausführbare Datei bauen, die offene Fenster auflistet und das Overlay an ein gewähltes Ziel anbindet, oder per dedizierter Projektmappen-Konfiguration als DLL. Der Beispielcode trennt ImGui-Menü-Rendering von rohem D3D9-Zeichnen, schaltet die UI mit der Insert-Taste um und bietet Helfer wie gefüllte Rechteck-Clears. Es richtet sich an Entwickler, die externe Overlays, Game-Tooling oder Reverse-Engineering-Workflows bei älteren D3D9-Titeln erlernen.
