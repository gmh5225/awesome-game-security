本プロジェクトは、Direct3D 9 を使って別のアプリケーションの上に Dear ImGui の UI とカスタムグラフィックスを描画するための Windows 向けスターターテンプレートです。C++ で Visual Studio 向けに書かれており、D3D9 および Win32 用 ImGui バックエンドを同梱し、d3d9.lib にリンクします。開いているウィンドウを一覧表示して選択したターゲットにオーバーレイをアタッチするスタンドアロン実行ファイルとしても、専用のソリューション構成で DLL としてもビルドできます。サンプルコードは ImGui メニューの描画と生の D3D9 描画を分離し、Insert キーで UI を切り替え、塗りつぶし矩形によるクリアなどのヘルパーも含みます。外部オーバーレイ、ゲーム向けツール、旧来の D3D9 タイトルでのリバースエンジニアリングワークフローを学ぶ開発者向けです。
