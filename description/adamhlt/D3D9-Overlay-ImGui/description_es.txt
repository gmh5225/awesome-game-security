Este proyecto es una plantilla inicial para Windows que sirve para dibujar una interfaz Dear ImGui y gráficos personalizados encima de otra aplicación mediante Direct3D 9. Está escrito en C++ para Visual Studio e incluye los backends ImGui de D3D9 y Win32, enlazando contra d3d9.lib. Puede compilarse como ejecutable independiente que lista las ventanas abiertas y adjunta la superposición a un destino elegido, o como DLL mediante configuraciones de solución dedicadas. El código de ejemplo separa el renderizado del menú ImGui del dibujo D3D9 en bruto, alterna la interfaz con la tecla Insert e incluye utilidades como limpiezas con rectángulos rellenos. Está pensado para desarrolladores que aprenden superposiciones externas, herramientas para juegos o flujos de trabajo de ingeniería inversa en títulos antiguos de D3D9.
