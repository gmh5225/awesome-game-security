Questo progetto è un modello iniziale per Windows per disegnare un’interfaccia Dear ImGui e grafica personalizzata sopra un’altra applicazione tramite Direct3D 9. È scritto in C++ per Visual Studio e include i backend ImGui D3D9 e Win32, con collegamento a d3d9.lib. Può essere compilato come eseguibile autonomo che elenca le finestre aperte e associa l’overlay a un target scelto, oppure come DLL tramite configurazioni di soluzione dedicate. Il codice di esempio separa il rendering del menu ImGui dal disegno D3D9 grezzo, attiva o disattiva l’interfaccia con il tasto Insert e include utility come le cancellazioni con rettangoli riempiti. È rivolto a sviluppatori che imparano overlay esterni, strumenti per giochi o flussi di lavoro di reverse engineering su titoli D3D9 più datati.
