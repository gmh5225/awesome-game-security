이 프로젝트는 Direct3D 9를 사용해 다른 애플리케이션 위에 Dear ImGui 인터페이스와 사용자 정의 그래픽을 그리는 Windows용 스타터 템플릿입니다. C++로 작성되었으며 Visual Studio용이며, D3D9 및 Win32 ImGui 백엔드를 포함하고 d3d9.lib에 링크합니다. 열린 창을 나열하고 선택한 대상에 오버레이를 붙이는 독립 실행 파일로 빌드할 수도 있고, 전용 솔루션 구성을 통해 DLL로 빌드할 수도 있습니다. 샘플 코드는 ImGui 메뉴 렌더링과 순수 D3D9 드로잉을 분리하고, Insert 키로 UI를 토글하며, 채워진 사각형 클리어 같은 헬퍼도 포함합니다. 외부 오버레이, 게임 도구, 구형 D3D9 타이틀에서의 리버스 엔지니어링 워크플로를 배우는 개발자를 대상으로 합니다.
