D3D9 Hook ImGui is a Windows injectable DLL template that intercepts IDirect3DDevice9 EndScene and Reset to draw an ImGui overlay inside any DirectX 9 application. It is built in C++ with Visual Studio for x86 and x64, obtains the device virtual table via the dummy-device technique, and applies hooks using Microsoft Detours. The scaffold handles window resize, fullscreen resets, keyboard toggles, and safe unload so developers mainly customize the menu in source. It suits reverse engineering, game modding, and graphics-hook research where you need a ready-made Direct3D 9 and ImGui integration point.
