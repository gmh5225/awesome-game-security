D3D9 Hook ImGui — это шаблон инжектируемой DLL для Windows, перехватывающий EndScene и Reset IDirect3DDevice9 для отрисовки оверлея ImGui в любом приложении DirectX 9. Проект на C++ в Visual Studio для x86 и x64: виртуальная таблица устройства получается методом фиктивного устройства, хуки ставятся через Microsoft Detours. Каркас обрабатывает изменение размера окна, сбросы в полноэкранном режиме, переключение с клавиатуры и безопасную выгрузку, поэтому разработчикам в основном нужно настроить меню в исходниках. Подходит для реверс-инжиниринга, моддинга игр и исследований графических хуков, когда нужна готовая точка интеграции Direct3D 9 и ImGui.
