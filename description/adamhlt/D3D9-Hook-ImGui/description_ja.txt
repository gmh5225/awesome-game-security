D3D9 Hook ImGui は、IDirect3DDevice9 の EndScene と Reset をフックして任意の DirectX 9 アプリケーション内に ImGui オーバーレイを描画する、Windows 向け注入可能な DLL テンプレートです。C++ と Visual Studio で x86 および x64 向けにビルドし、ダミーデバイス手法でデバイスの仮想テーブルを取得し、Microsoft Detours でフックを適用します。ウィンドウのリサイズ、フルスクリーン時のリセット、キーボードトグル、安全なアンロードを扱うため、開発者は主にソース内のメニューをカスタマイズすれば足ります。逆コンパイル、ゲーム mod、グラフィックスフック研究など、すぐ使える Direct3D 9 と ImGui の統合ポイントが必要な用途に向いています。
