D3D9 Hook ImGui est un modèle de DLL injectable pour Windows qui intercepte EndScene et Reset d'IDirect3DDevice9 pour dessiner une superposition ImGui dans toute application DirectX 9. Il est développé en C++ avec Visual Studio pour x86 et x64, obtient la table virtuelle du périphérique via la technique du faux périphérique et applique les hooks avec Microsoft Detours. L'échafaudage gère le redimensionnement de fenêtre, les réinitialisations en plein écran, les bascules clavier et le déchargement sûr, de sorte que les développeurs personnalisent surtout le menu dans les sources. Il convient à l'ingénierie inverse, au modding de jeux et à la recherche sur les hooks graphiques lorsque vous avez besoin d'un point d'intégration Direct3D 9 et ImGui prêt à l'emploi.
