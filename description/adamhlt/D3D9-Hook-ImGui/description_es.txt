D3D9 Hook ImGui es una plantilla de DLL inyectable para Windows que intercepta EndScene y Reset de IDirect3DDevice9 para dibujar una superposición ImGui dentro de cualquier aplicación DirectX 9. Está escrita en C++ con Visual Studio para x86 y x64, obtiene la tabla virtual del dispositivo mediante la técnica del dispositivo ficticio y aplica hooks con Microsoft Detours. El andamiaje gestiona el cambio de tamaño de ventana, reinicios a pantalla completa, conmutación por teclado y descarga segura, de modo que los desarrolladores personalizan sobre todo el menú en el código fuente. Sirve para ingeniería inversa, modding de juegos e investigación de hooks gráficos cuando necesitas un punto de integración listo de Direct3D 9 e ImGui.
