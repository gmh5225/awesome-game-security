deREferencing — это плагин для IDA Pro, добавляющий расширенные окна отладчика для регистров и стека при анализе бинарных файлов в реальном времени. Написанный на Python с использованием API плагинов IDA, он разыменовывает указатели, применяет цветовые аннотации памяти и отображает контекстную информацию о значениях, подобно расширениям GDB, таким как PEDA, GEF и pwndbg. Поддерживаются x86, x86-64, ARM, ARM64, MIPS32 и MIPS64, а поведение настраивается через модуль параметров. Плагин предназначен для специалистов по обратной разработке и исследователей безопасности, которым нужна более полная видимость регистров, содержимого стека и цепочек указателей при отладке бинарных файлов в IDA Pro.
