deREferencing is an IDA Pro plugin that adds enhanced register and stack debugger windows for live binary analysis. Written in Python using the IDA plugin API, it dereferences pointers, applies color-coded memory annotations, and surfaces contextual value information in ways similar to GDB extensions such as PEDA, GEF, and pwndbg. It supports x86, x86-64, ARM, ARM64, MIPS32, and MIPS64, with configurable behavior through its settings module. The plugin is aimed at reverse engineers and security researchers who need richer visibility into registers, stack contents, and pointer chains while debugging binaries in IDA Pro.
