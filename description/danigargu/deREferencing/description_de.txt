deREferencing ist ein IDA-Pro-Plugin, das erweiterte Debugger-Fenster für Register und Stack zur Live-Binäranalyse hinzufügt. In Python unter Verwendung der IDA-Plugin-API geschrieben, dereferenziert es Zeiger, wendet farbcodierte Speicherannotationen an und zeigt kontextbezogene Wertinformationen in einer Weise an, die an GDB-Erweiterungen wie PEDA, GEF und pwndbg erinnert. Es unterstützt x86, x86-64, ARM, ARM64, MIPS32 und MIPS64, wobei das Verhalten über ein Einstellungsmodul konfigurierbar ist. Das Plugin richtet sich an Reverse Engineers und Sicherheitsforscher, die beim Debuggen von Binärdateien in IDA Pro eine umfassendere Sicht auf Register, Stack-Inhalte und Zeigerketten benötigen.
