deREferencing は、ライブバイナリ解析向けに拡張されたレジスタおよびスタックデバッガーウィンドウを追加する IDA Pro プラグインです。Python と IDA プラグイン API で実装され、ポインタのデリファレンス、色分けされたメモリアノテーション、PEDA、GEF、pwndbg などの GDB 拡張に似た形式でのコンテキスト付き値情報の表示を行います。x86、x86-64、ARM、ARM64、MIPS32、MIPS64 をサポートし、設定モジュールによる動作のカスタマイズが可能です。IDA Pro でバイナリをデバッグする際に、レジスタ、スタック内容、ポインタチェーンへの可視性を高めたいリバースエンジニアおよびセキュリティ研究者向けのプラグインです。
