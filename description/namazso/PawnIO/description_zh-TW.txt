PawnIO 是一個 Windows 核心驅動程式，在核心模式下嵌入 Pawn 指令碼虛擬機器，讓使用者模式用戶端能夠載入已簽署的 AMX 位元組碼模組，並透過裝置 IOCTL 執行其中的函式。此驅動程式公開了廣泛的底層 native 介面，用於硬體與核心互動，包括實體與虛擬記憶體存取、MSR 與 PCI 設定的讀寫、CPUID、控制與偵錯暫存器、I/O 連接埠，以及在 x64 上呼叫 SMM。它以 Windows Driver Kit 搭配 C++20 與平台專用組合語言建置，並在執行前以 SHA-256 雜湊與可信公鑰驗證模組真實性。配套的使用者模式函式庫與 Pawn 標頭檔支援開發並簽署在驅動程式內執行的指令碼。它面向需要可指令碼化介面以進行底層 Windows 硬體、記憶體與驅動程式研究的核心與遊戲安全研究人員。
