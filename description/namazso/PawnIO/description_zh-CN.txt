PawnIO 是一个 Windows 内核驱动，在内核模式下嵌入 Pawn 脚本虚拟机，使用户态客户端能够加载已签名的 AMX 字节码模块，并通过设备 IOCTL 执行其中的函数。该驱动公开了广泛的底层 native 接口，用于硬件与内核交互，包括物理内存与虚拟内存访问、MSR 与 PCI 配置的读写、CPUID、控制与调试寄存器、I/O 端口，以及在 x64 上调用 SMM。它使用 Windows Driver Kit 以 C++20 编写，并配合平台相关汇编实现，在执行前通过 SHA-256 哈希与可信公钥验证模块真实性。配套的用户态库与 Pawn 头文件支持开发并签名在驱动内运行的脚本。它面向需要可脚本化接口以进行底层 Windows 硬件、内存与驱动研究的内核与游戏安全研究人员。
