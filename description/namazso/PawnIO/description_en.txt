PawnIO is a Windows kernel driver that embeds a Pawn scripting virtual machine in kernel mode, allowing user-mode clients to load signed AMX bytecode modules and execute their functions through device IOCTLs. The driver exposes a broad set of low-level natives for hardware and kernel interaction, including physical and virtual memory access, MSR and PCI configuration reads and writes, CPUID, control and debug registers, I/O ports, and SMM invocation on x64. It is built with the Windows Driver Kit in C++20 with platform-specific assembly, and verifies module authenticity using SHA-256 hashing and trusted public keys before execution. Companion user-mode libraries and Pawn include files support developing and signing scripts that run inside the driver. It is aimed at kernel and game security researchers who need a scriptable interface for low-level Windows hardware, memory, and driver research.
