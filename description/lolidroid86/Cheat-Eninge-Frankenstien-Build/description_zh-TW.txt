Cheat Engine Frankenstein 是以公開原始碼樹為基礎客製的 Cheat Engine 7.5 建置，將較新的自動組譯與指令碼能力回溯移植到舊版引擎上。它新增用於內聯程式碼鉤子的 HOOK 與 UNHOOK、條件 {$ifdef} 區塊，以及用於符號作用域模式掃描的 AOBSCANFUNCTION，透過對 autoassembler.pas 與 SynHighlighterAA.pas 的修補實作，並以 Lazarus 與 Free Pascal 建置。第 3 版將修補過的 7.5 可執行檔與 CE 7.7.3 支援檔及 Lua 相容層搭配，使現代 autorun 指令碼可在不出現缺少函式錯誤的情況下載入。儲存庫另提供 Inno Setup 安裝指令碼、自動組譯表示例，以及針對 AITools 等工具的可選擴充載入。適合希望在可從開放 Pascal 原始碼自行編譯的建置上使用 CE 7.7 風格指令碼，進行記憶體編輯、遊戲修改與逆向工程工作流程的開發者。
