Cheat Engine Frankenstein — это пользовательская сборка Cheat Engine 7.5 из открытого дерева исходников, которая переносит на старый движок более новые возможности Auto-Assembler и сценариев. Добавлены HOOK и UNHOOK для встроенных перехватов кода, условные блоки {$ifdef} и AOBSCANFUNCTION для поиска шаблонов в области символов, реализованные патчами в autoassembler.pas и SynHighlighterAA.pas, собранные с Lazarus и Free Pascal. Версия 3 сочетает пропатченный исполняемый файл 7.5 с файлами поддержки CE 7.7.3 и слоем совместимости Lua, чтобы современные autorun-скрипты загружались без ошибок отсутствующих функций. В репозитории также есть скрипты установщика Inno Setup, примеры таблиц Auto-Assembler и опциональная загрузка расширений для таких инструментов, как AITools. Ориентирован на редактирование памяти, моддинг игр и реверс-инжиниринг, когда нужен скриптинг в стиле CE 7.7 на сборке, которую можно скомпилировать из открытых Pascal-исходников.
