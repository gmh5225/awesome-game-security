Cheat Engine Frankenstein è una build personalizzata di Cheat Engine 7.5 dall’albero sorgente pubblico che riporta sul motore più vecchio capacità più recenti di Auto-Assembler e scripting. Aggiunge HOOK e UNHOOK per hook di codice inline, blocchi condizionali {$ifdef} e AOBSCANFUNCTION per scansioni di pattern con ambito simbolico, implementati come patch su autoassembler.pas e SynHighlighterAA.pas, compilati con Lazarus e Free Pascal. La versione 3 abbina l’eseguibile 7.5 patchato ai file di supporto CE 7.7.3 e a uno strato di compatibilità Lua così gli script autorun moderni si caricano senza errori per funzioni mancanti. Il repository include anche script installer Inno Setup, tabelle Auto-Assembler di esempio e caricamento opzionale di estensioni per strumenti come AITools. È pensato per flussi di modifica memoria, modding di giochi e reverse engineering in cui si desidera scripting in stile CE 7.7 su una build compilabile da sorgenti Pascal aperte.
