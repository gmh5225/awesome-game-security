Cheat Engine Frankenstein ist ein individueller Build von Cheat Engine 7.5 aus dem öffentlichen Quellbaum, der neuere Auto-Assembler- und Skriptfunktionen auf die ältere Engine zurückportiert. Er ergänzt HOOK und UNHOOK für Inline-Code-Hooks, bedingte {$ifdef}-Blöcke und AOBSCANFUNCTION für musterscans im Symbolbereich, umgesetzt als Patches in autoassembler.pas und SynHighlighterAA.pas, gebaut mit Lazarus und Free Pascal. Version 3 kombiniert die gepatchte 7.5-Executable mit CE-7.7.3-Unterstützungsdateien und einer Lua-Kompatibilitätsschicht, damit moderne Autorun-Skripte ohne Fehler wegen fehlender Funktionen laden. Das Repository enthält zudem Inno-Setup-Installationsskripte, Auto-Assembler-Tabellenbeispiele und optionales Laden von Erweiterungen für Tools wie AITools. Es richtet sich an Speicherbearbeitung, Game-Modding und Reverse-Engineering-Workflows, in denen Entwickler CE-7.7-artiges Skripting auf einem aus offenen Pascal-Quellen kompilierbaren Build wünschen.
