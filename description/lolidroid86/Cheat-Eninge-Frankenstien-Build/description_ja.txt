Cheat Engine Frankenstein は公開ソースツリーからカスタムビルドした Cheat Engine 7.5 で、新しい Auto-Assembler およびスクリプト機能を旧エンジンへバックポートしたものです。インラインコードフック用の HOOK と UNHOOK、条件付き {$ifdef} ブロック、シンボルスコープのパターンスキャン用 AOBSCANFUNCTION を追加し、autoassembler.pas と SynHighlighterAA.pas へのパッチとして実装し、Lazarus と Free Pascal でビルドします。バージョン 3 ではパッチ適用済み 7.5 実行ファイルに CE 7.7.3 サポートファイルと Lua 互換レイヤーを組み合わせ、現行の autorun スクリプトが欠落関数エラーなしで読み込めます。リポジトリには Inno Setup インストーラスクリプト、Auto-Assembler テーブルの例、AITools など向けの任意拡張読み込みも同梱しています。オープンな Pascal ソースからコンパイル可能なビルドで CE 7.7 スタイルのスクリプトを使いたい、メモリ編集・ゲーム改造・リバースエンジニアリングのワークフロー向けです。
