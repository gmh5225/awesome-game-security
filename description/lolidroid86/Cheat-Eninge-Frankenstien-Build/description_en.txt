Cheat Engine Frankenstein is a custom build of Cheat Engine 7.5 from the public source tree that backports newer Auto-Assembler and scripting capabilities onto the older engine. It adds HOOK and UNHOOK for inline code hooks, conditional {$ifdef} blocks, and AOBSCANFUNCTION for symbol-scoped pattern scans, implemented as patches to autoassembler.pas and SynHighlighterAA.pas built with Lazarus and Free Pascal. Version 3 pairs the patched 7.5 executable with CE 7.7.3 support files and a Lua compatibility layer so modern autorun scripts load without missing-function errors. The repository also ships Inno Setup installer scripts, example Auto-Assembler tables, and optional extension loading for tools such as AITools. It is aimed at memory editing, game modding, and reverse-engineering workflows where developers want CE 7.7-style scripting on a build they can compile from open Pascal sources.
