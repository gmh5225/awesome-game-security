Cheat Engine Frankenstein 是基于公开源码树定制的 Cheat Engine 7.5 构建，将较新的自动汇编与脚本能力回移植到旧版引擎上。它增加了用于内联代码钩子的 HOOK 与 UNHOOK、条件 {$ifdef} 块，以及用于符号作用域模式扫描的 AOBSCANFUNCTION，通过对 autoassembler.pas 与 SynHighlighterAA.pas 的补丁实现，并使用 Lazarus 与 Free Pascal 编译。第 3 版将打过补丁的 7.5 可执行文件与 CE 7.7.3 支持文件及 Lua 兼容层搭配，使现代 autorun 脚本可在不出现缺失函数错误的情况下加载。仓库还提供 Inno Setup 安装脚本、自动汇编表示例，以及针对 AITools 等工具的可选扩展加载。面向希望在可从开放 Pascal 源码自行编译的构建上使用 CE 7.7 风格脚本进行内存编辑、游戏修改与逆向工程工作流的开发者。
