Cheat Engine Frankenstein est une compilation personnalisée de Cheat Engine 7.5 issue de l’arborescence source publique, qui rétroporte des capacités plus récentes d’Auto-Assembler et de script vers l’ancien moteur. Elle ajoute HOOK et UNHOOK pour les hooks de code inline, des blocs conditionnels {$ifdef}, et AOBSCANFUNCTION pour les scans de motifs à portée de symboles, implémentés comme correctifs dans autoassembler.pas et SynHighlighterAA.pas, compilés avec Lazarus et Free Pascal. La version 3 associe l’exécutable 7.5 patché aux fichiers de support CE 7.7.3 et à une couche de compatibilité Lua afin que les scripts autorun modernes se chargent sans erreurs de fonctions manquantes. Le dépôt fournit aussi des scripts d’installation Inno Setup, des exemples de tables Auto-Assembler et un chargement d’extensions optionnel pour des outils comme AITools. Il s’adresse aux flux mémoire, modding de jeux et reverse engineering où l’on veut du scriptage style CE 7.7 sur une build compilable à partir de sources Pascal ouvertes.
