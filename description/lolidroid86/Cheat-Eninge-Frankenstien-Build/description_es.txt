Cheat Engine Frankenstein es una compilación personalizada de Cheat Engine 7.5 a partir del árbol de fuentes público que retroporta capacidades más nuevas de Auto-Assembler y scripting al motor antiguo. Añade HOOK y UNHOOK para hooks de código inline, bloques condicionales {$ifdef} y AOBSCANFUNCTION para búsquedas de patrones con alcance de símbolos, implementados como parches en autoassembler.pas y SynHighlighterAA.pas, compilados con Lazarus y Free Pascal. La versión 3 combina el ejecutable 7.5 parcheado con archivos de soporte CE 7.7.3 y una capa de compatibilidad Lua para que los scripts autorun modernos carguen sin errores por funciones ausentes. El repositorio incluye scripts de instalador Inno Setup, tablas Auto-Assembler de ejemplo y carga opcional de extensiones para herramientas como AITools. Está orientado a flujos de edición de memoria, modding de juegos e ingeniería inversa donde se quiere scripting al estilo CE 7.7 en una build compilable desde fuentes Pascal abiertas.
