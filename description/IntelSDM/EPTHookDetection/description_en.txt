EPT Hook Detection is an LLVM 19 compiler pass plugin for Windows x64 that instruments application code at build time to detect hypervisor-based EPT memory hooks without relying on separate JIT stubs. It injects three complementary techniques: a customized ERMSB-based probe that catches shadow debug-register behavior missed by older checks, in-page LODSD-style gadgets that only execute on the real physical pages, and optional HyperDOS inline pause loops that severely slow execution on hooked pages while barely affecting normal machines. Developers opt functions in or out and register a detection callback using LLVM function annotations, and the pass is designed to work alongside obfuscation so probes live next to protected code on the same pages. The primary use case is game security, anti-cheat, and anti-tamper tooling that must spot EPT hooking used by tools such as HyperDBG or DBVM from usermode binaries.
