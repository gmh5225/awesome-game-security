EPT Hook Detection è un plugin di compiler pass LLVM 19 per Windows x64 che strumenta il codice applicativo in fase di build per rilevare hook di memoria EPT basati su hypervisor senza affidarsi a stub JIT separati. Inietta tre tecniche complementari: una sonda personalizzata basata su ERMSB che intercetta il comportamento shadow dei registri di debug sfuggito ai controlli precedenti, gadget in stile LODSD in-page che si eseguono solo sulle pagine fisiche reali e loop pause inline HyperDOS opzionali che rallentano molto l’esecuzione sulle pagine agganciate incidendo appena sulle macchine normali. Gli sviluppatori includono o escludono funzioni e registrano una callback di rilevamento tramite annotazioni di funzione LLVM; il pass è progettato per funzionare insieme all’offuscamento così che le sonde restino accanto al codice protetto sulle stesse pagine. Il caso d’uso principale è sicurezza dei giochi, anti-cheat e strumenti anti-manomissione che devono individuare l’hooking EPT usato da tool come HyperDBG o DBVM da binari in user mode.
