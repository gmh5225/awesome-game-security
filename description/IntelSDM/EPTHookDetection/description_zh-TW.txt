EPT Hook Detection 是一款面向 Windows x64 的 LLVM 19 編譯器 pass 外掛，在建置時對應用程式碼進行插樁，在不依賴獨立 JIT 存根的前提下偵測以虛擬化監視器為基礎的 EPT 記憶體掛鉤。它注入三種互補技術：客製化的 ERMSB 式探測，可捕捉舊有檢查容易漏掉的影子除錯暫存器行為；僅在真實實體頁面上才會執行的頁內 LODSD 風格 gadget；以及可選的 HyperDOS 內聯 pause 迴圈，在被掛鉤頁面上會嚴重拖慢執行，對一般機器則幾乎無影響。開發者可用 LLVM 函式註解選擇納入或排除函式，並註冊偵測回呼；此 pass 可與混淆並用，使探測與受保護程式碼位於同一頁面。主要用於遊戲安全、反作弊與防篡改工具，須在使用者模式二進位中辨識 HyperDBG、DBVM 等工具所使用的 EPT 掛鉤。
