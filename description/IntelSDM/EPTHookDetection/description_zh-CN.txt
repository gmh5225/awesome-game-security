EPT Hook Detection 是一款面向 Windows x64 的 LLVM 19 编译器 pass 插件，在构建时对应用代码进行插桩，在不依赖独立 JIT 存根的前提下检测基于虚拟化监视器的 EPT 内存挂钩。它注入三种互补技术：定制的基于 ERMSB 的探测，用于捕获旧有检查易漏掉的影子调试寄存器行为；仅在真实物理页上才会执行的页内 LODSD 风格 gadget；以及可选的 HyperDOS 内联 pause 循环，在被挂钩页面上会严重拖慢执行，而对正常机器影响极小。开发者可通过 LLVM 函数注解选择纳入或排除函数，并注册检测回调；该 pass 可与混淆协同工作，使探测代码与受保护代码位于同一页面。主要面向游戏安全、反作弊与防篡改工具，需要在用户态二进制中识别 HyperDBG、DBVM 等工具所用的 EPT 挂钩。
