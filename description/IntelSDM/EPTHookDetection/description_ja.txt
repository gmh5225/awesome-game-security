EPT Hook Detection は Windows x64 向けの LLVM 19 コンパイラ pass プラグインで、ビルド時にアプリケーションコードへ計装を入れ、独立した JIT スタブに頼らずハイパーバイザベースの EPT メモリフックを検出します。3 つの相補的な手法を注入します。カスタマイズした ERMSB ベースのプローブで、従来のチェックが見逃しがちなシャドウデバッグレジスタの挙動を捉えます。実物理ページ上でのみ実行されるページ内 LODSD 風ガジェット。任意の HyperDOS インライン pause ループで、フックされたページ上では実行を著しく遅らせ、通常のマシンにはほとんど影響しません。開発者は LLVM 関数アノテーションで関数の対象内外を選び、検出コールバックを登録できます。この pass は難読化と併用するよう設計されており、プローブは保護コードと同じページ上に置けます。主な用途はゲームセキュリティ、チート対策、改ざん防止向けツールで、HyperDBG や DBVM などが使う EPT フックをユーザーモードバイナリから見つける必要がある場合です。
