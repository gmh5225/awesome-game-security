EPT Hook Detection — плагин прохода компилятора LLVM 19 для Windows x64, который инструментирует код приложения на этапе сборки для обнаружения EPT-хуков памяти на базе гипервизора без отдельных JIT-заглушек. Внедряются три взаимодополняющих техники: настраиваемый проб на основе ERMSB, выявляющий поведение «теневых» отладочных регистров, которое пропускали старые проверки; in-page гаджеты в стиле LODSD, выполняющиеся только на реальных физических страницах; и опциональные встроенные циклы pause HyperDOS, сильно замедляющие выполнение на захуканных страницах и почти не затрагивающие обычные машины. Разработчики подключают или исключают функции и регистрируют callback обнаружения через аннотации функций LLVM; проход рассчитан на работу рядом с обфускацией, чтобы пробы располагались рядом с защищённым кодом на тех же страницах. Основной сценарий — безопасность игр, античит и антивзломные средства, которым нужно находить EPT-хукинг, используемый такими инструментами, как HyperDBG или DBVM, из пользовательских бинарников.
