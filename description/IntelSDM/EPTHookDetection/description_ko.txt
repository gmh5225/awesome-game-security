EPT Hook Detection은 Windows x64용 LLVM 19 컴파일러 pass 플러그인으로, 빌드 시 애플리케이션 코드에 계측을 넣어 별도의 JIT 스텁 없이 하이퍼바이저 기반 EPT 메모리 훅을 감지합니다. 세 가지 상호 보완 기법을 주입합니다. 맞춤형 ERMSB 기반 프로브로 이전 검사가 놓치기 쉬운 섀도 디버그 레지스터 동작을 잡고, 실제 물리 페이지에서만 실행되는 페이지 내 LODSD 스타일 가젯, 선택적 HyperDOS 인라인 pause 루프로 훅된 페이지에서는 실행을 크게 늦추지만 일반 머신에는 거의 영향을 주지 않습니다. 개발자는 LLVM 함수 어노테이션으로 함수 포함 여부를 정하고 감지 콜백을 등록합니다. 이 pass는 난독화와 함께 쓰도록 설계되어 프로브가 보호된 코드와 같은 페이지에 위치할 수 있습니다. 주 용도는 게임 보안, 안티치트, 안티탬퍼 도구로, HyperDBG나 DBVM 같은 도구가 쓰는 EPT 훅을 사용자 모드 바이너리에서 찾아야 할 때입니다.
