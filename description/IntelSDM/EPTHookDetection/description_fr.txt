EPT Hook Detection est un plugin de passe compilateur LLVM 19 pour Windows x64 qui instrumente le code applicatif au moment de la compilation afin de détecter les hooks mémoire EPT basés sur un hyperviseur, sans s’appuyer sur des stubs JIT séparés. Il injecte trois techniques complémentaires : une sonde ERMSB personnalisée qui repère le comportement furtif des registres de débogage que les anciens contrôles manquaient, des gadgets de style LODSD en page qui ne s’exécutent que sur les pages physiques réelles, et des boucles pause inline HyperDOS optionnelles qui ralentissent fortement l’exécution sur les pages hookées tout en affectant à peine les machines normales. Les développeurs incluent ou excluent des fonctions et enregistrent un rappel de détection via les annotations de fonctions LLVM ; la passe est conçue pour fonctionner avec l’obfuscation afin que les sondes restent à côté du code protégé sur les mêmes pages. Le cas d’usage principal est la sécurité des jeux, l’anti-triche et les outils anti-altération qui doivent repérer le hooking EPT utilisé par des outils tels qu’HyperDBG ou DBVM depuis des binaires en mode utilisateur.
