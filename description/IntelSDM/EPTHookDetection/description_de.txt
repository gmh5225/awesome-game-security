EPT Hook Detection ist ein LLVM-19-Compiler-Pass-Plugin für Windows x64, das Anwendungscode zur Build-Zeit instrumentiert, um hypervisorbasierte EPT-Speicherhooks zu erkennen, ohne auf separate JIT-Stubs angewiesen zu sein. Es injiziert drei ergänzende Techniken: eine angepasste ERMSB-basierte Sonde, die Schatten-Debugregister-Verhalten erfasst, das ältere Prüfungen übersehen, In-Page-LODSD-artige Gadgets, die nur auf den echten physischen Seiten ausgeführt werden, und optionale HyperDOS-Inline-Pause-Schleifen, die die Ausführung auf gehookten Seiten stark verlangsamen, normale Maschinen aber kaum beeinträchtigen. Entwickler schalten Funktionen per LLVM-Funktionsannotationen ein oder aus und registrieren einen Erkennungs-Callback; der Pass ist für den Einsatz neben Obfuskation ausgelegt, sodass Sonden neben geschütztem Code auf denselben Seiten liegen. Der Hauptanwendungsfall ist Spielsicherheit, Anti-Cheat und Anti-Tamper-Werkzeuge, die EPT-Hooking erkennen müssen, wie es Tools wie HyperDBG oder DBVM nutzen, aus Usermode-Binaries heraus.
