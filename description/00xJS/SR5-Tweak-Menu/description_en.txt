SR5 Tweak Menu is an in-game tweak and cheat menu for Saints Row (2022) on PC, modeled after earlier Saints Row tweak menus and aimed at the Epic DirectX 12 build. A C host built as dinput8.dll loads beside the game executable, detours the main loop, and runs a Lua 5.4 menu that drives the title’s own Lua interface through injected scripts while exposing memory read and write helpers for live tuning. The menu spans player stats, weapons, vehicles, teleport, world and AI controls, visuals, and built-in phone cheats, with optional persistence and a save-clean mode that avoids marking saves when using certain in-game cheat flags. Python utilities and research notes document reflection offsets, vtables, archive extraction, and probing workflows for reverse engineering and extending behavior in single-player modding and security research contexts.
