SR5 Tweak Menu는 PC용 Saints Row(2022)를 위한 게임 내 tweak 및 치트 메뉴로, 이전 Saints Row tweak 메뉴를 본떠 Epic DirectX 12 빌드를 대상으로 합니다. dinput8.dll로 빌드된 C 호스트가 게임 실행 파일 옆에서 로드되어 메인 루프를 detour하고 Lua 5.4 메뉴를 실행하며, 주입 스크립트로 타이틀 고유 Lua 인터페이스를 구동하면서 실시간 조정을 위한 메모리 읽기·쓰기 헬퍼를 제공합니다. 메뉴는 플레이어 스탯, 무기, 차량, 텔레포트, 월드 및 AI 제어, 비주얼, 내장 폰 치트를 포함하며, 선택적 영속화와 특정 게임 내 치트 플래그 사용 시 세이브에 흔적을 남기지 않는 save-clean 모드를 제공합니다. Python 유틸리티와 연구 노트는 반사 오프셋, vtable, 아카이브 추출, 프로빙 워크플로를 문서화하여 싱글플레이 modding 및 보안 연구 맥락에서의 리버스 엔지니어링과 동작 확장을 돕습니다.
