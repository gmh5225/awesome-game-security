Этот проект — нативная реализация игрового движка Kabus 22 для Linux, восстановленная методом reverse engineering, включая автономную среду выполнения, которая читает собственные оригинальные скрипты и ресурсы игрока без Wine и Windows-бинарника. Ядро написано на C++20 и собирается CMake; в центре — runtime скриптов WDL с физикой ODE, окнами SDL2, медиа FFmpeg и рендерингом OpenGL или Vulkan с опциональным аппаратным ray tracing, PBR и апскейлингом FSR. Также есть установщик GTK, лаунчер и обновлятор с подписью Ed25519, а также подробные заметки по reverse engineering исполняемых файлов, структур данных и форматов ресурсов. Проект для reverse-инженеров, разработчиков портов движка и исследователей, желающих изучать или запускать эту legacy-игру под Windows нативно на Linux с легально приобретённых носителей.
