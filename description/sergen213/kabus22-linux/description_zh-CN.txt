本项目是对 Kabus 22 游戏引擎的逆向工程原生 Linux 实现，包含独立运行时，可在无需 Wine 或 Windows 可执行文件的情况下读取玩家自有的原始脚本与资源。核心采用 C++20 编写，通过 CMake 构建，以 WDL 脚本运行时为中心，集成 ODE 物理、SDL2 窗口、FFmpeg 媒体，以及 OpenGL 或 Vulkan 渲染，并可选硬件光追、PBR 与 FSR 超分。此外还提供 GTK 安装器、启动器与 Ed25519 签名的更新器，以及关于可执行文件、数据结构与资源格式的详细逆向笔记。面向逆向工程师、引擎移植者与研究人员，便于在 Linux 上从合法持有的游戏介质原生研究或运行这款 legacy Windows 作品。
