Ce projet est une implémentation Linux native rétro-ingéniérée du moteur de jeu Kabus 22, avec un runtime autonome qui lit les scripts et assets originaux du joueur sans Wine ni binaire Windows. Le cœur est écrit en C++20 et construit avec CMake, centré sur un runtime de scripts WDL avec physique ODE, fenêtrage SDL2, média FFmpeg et rendu OpenGL ou Vulkan, avec en option le ray tracing matériel, le PBR et l’upscaling FSR. Il fournit aussi un installateur GTK, un lanceur et un outil de mise à jour signé Ed25519, ainsi que des notes détaillées de rétro-ingénierie sur les exécutables, structures de données et formats de ressources. Il s’adresse aux rétro-ingénieurs, porteurs de moteur et chercheurs qui veulent étudier ou exécuter nativement sur Linux ce titre Windows legacy à partir de supports de jeu légalement possédés.
