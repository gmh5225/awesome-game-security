本プロジェクトは Kabus 22 ゲームエンジンのリバースエンジニアリングによるネイティブ Linux 実装で、Wine や Windows バイナリなしにプレイヤー自身のオリジナルスクリプトとアセットを読み込むスタンドアロンランタイムを含みます。コアは C++20 で CMake ビルドされ、WDL スクリプトランタイムを中心に ODE 物理、SDL2 ウィンドウ、FFmpeg メディア、OpenGL または Vulkan レンダリングを備え、オプションでハードウェアレイトレーシング、PBR、FSR アップスケーリングに対応します。GTK インストーラー、ランチャー、Ed25519 署名付きアップデーターに加え、実行ファイル、データ構造、リソース形式に関する詳細なリバースエンジニアリングノートも提供します。リバースエンジニア、エンジンポーター、研究者向けで、合法に所有したゲームメディアからこのレガシー Windows タイトルを Linux 上でネイティブに研究・実行するためのものです。
