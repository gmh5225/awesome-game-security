本專案為 Kabus 22 遊戲引擎的逆向工程原生 Linux 實作，包含獨立執行環境，可在無需 Wine 或 Windows 執行檔的情況下讀取玩家自有的原始腳本與資源。核心以 C++20 撰寫，透過 CMake 建置，以 WDL 腳本執行環境為中心，整合 ODE 物理、SDL2 視窗、FFmpeg 媒體，以及 OpenGL 或 Vulkan 渲染，並可選硬體光線追蹤、PBR 與 FSR 升頻。另提供 GTK 安裝程式、啟動器與 Ed25519 簽署的更新器，以及關於可執行檔、資料結構與資源格式的詳細逆向筆記。面向逆向工程師、引擎移植者與研究人員，便於在 Linux 上從合法持有的遊戲媒體原生研究或執行這款 legacy Windows 作品。
