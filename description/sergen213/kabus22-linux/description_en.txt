This project is a reverse-engineered native Linux implementation of the Kabus 22 game engine, including a standalone runtime that reads the player's own original scripts and assets without Wine or the Windows binary. The core is written in C++20 and built with CMake, centering on a WDL script runtime with ODE physics, SDL2 windowing, FFmpeg media, and OpenGL or Vulkan rendering with optional hardware ray tracing, PBR, and FSR upscaling. It also provides a GTK installer, launcher, and Ed25519-signed updater, along with detailed reverse-engineering notes on executables, data structures, and resource formats. It is aimed at reverse engineers, engine porters, and researchers who want to study or run this legacy Windows title natively on Linux from legally owned game media.
