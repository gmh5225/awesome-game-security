Questo progetto è un’implementazione Linux nativa ricostruita per reverse engineering del motore di gioco Kabus 22, con un runtime autonomo che legge script e asset originali del giocatore senza Wine né il binario Windows. Il nucleo è scritto in C++20 e compilato con CMake, centrato su un runtime di script WDL con fisica ODE, finestre SDL2, media FFmpeg e rendering OpenGL o Vulkan, con opzionali ray tracing hardware, PBR e upscaling FSR. Fornisce inoltre un installer GTK, launcher e updater firmato Ed25519, oltre a note dettagliate di reverse engineering su eseguibili, strutture dati e formati delle risorse. È pensato per reverse engineer, portatori di motori e ricercatori che vogliono studiare o eseguire nativamente su Linux questo titolo Windows legacy da supporti di gioco posseduti legalmente.
