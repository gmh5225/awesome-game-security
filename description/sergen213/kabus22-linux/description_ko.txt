이 프로젝트는 Kabus 22 게임 엔진의 리버스 엔지니어링 기반 네이티브 Linux 구현으로, Wine이나 Windows 바이너리 없이 플레이어가 보유한 원본 스크립트와 에셋을 읽는 독립 런타임을 포함합니다. 핵심은 C++20과 CMake로 작성·빌드되며 WDL 스크립트 런타임을 중심으로 ODE 물리, SDL2 창 관리, FFmpeg 미디어, OpenGL 또는 Vulkan 렌더링을 제공하고, 선택적으로 하드웨어 레이 트레이싱, PBR, FSR 업스케일링을 지원합니다. GTK 설치 프로그램, 런처, Ed25519 서명 업데이터와 실행 파일·데이터 구조·리소스 형식에 대한 상세 리버스 엔지니어링 노트도 제공합니다. 리버스 엔지니어, 엔진 포터, 연구자가 합법적으로 소유한 게임 미디어로 이 레거시 Windows 타이틀을 Linux에서 네이티브로 연구·실행하려는 목적입니다.
