這是一款原生 Android 模組，透過執行時注入共享函式庫（而非修改遊戲 APK）為 Farming Simulator 12 新增多人連線支援。使用 C++ 撰寫，並透過 Android NDK 針對舊版 armeabi 目標平台建置；借助 Substrate 框架，透過硬編碼二進位偏移攔截原生選單、GUI 與更新函式。該模組實作 UDP 區域網路探索與 TCP 同步以交換玩家資料，在 OpenGL ES 2 上使用 Dear ImGui 渲染遊戲內覆蓋層，並提供自動產生可注入 libmultiplayermod.so 函式庫的 GitHub Actions 管線。面向研究原生遊戲 hook、舊版 Android ABI 相容以及閉源行動遊戲引擎執行時改動的逆向工程師與 Mod 開發者。
