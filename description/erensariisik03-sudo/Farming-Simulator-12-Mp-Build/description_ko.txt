이것은 게임 APK를 수정하는 대신 런타임에 공유 라이브러리를 주입하여 Farming Simulator 12에 멀티플레이어 지원을 추가하는 네이티브 Android 모드입니다. C++로 작성되었으며 레거시 armeabi 타깃을 위해 Android NDK로 빌드되며, Substrate 후킹 프레임워크를 사용해 하드코딩된 바이너리 오프셋으로 네이티브 메뉴, GUI, 업데이트 함수를 가로챕니다. 이 모드는 플레이어 데이터 교환을 위해 UDP LAN 검색과 TCP 동기화를 구현하고, OpenGL ES 2에서 Dear ImGui로 게임 내 오버레이를 렌더링하며, 주입 가능한 libmultiplayermod.so 라이브러리를 생성하는 자동 GitHub Actions 파이프라인을 포함합니다. 네이티브 게임 후킹, 레거시 Android ABI 호환성, 폐쇄형 모바일 게임 엔진의 런타임 수정을 연구하는 리버스 엔지니어와 모더를 대상으로 합니다.
