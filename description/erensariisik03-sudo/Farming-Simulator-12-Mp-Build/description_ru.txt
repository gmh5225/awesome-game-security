Это нативный Android-мод, добавляющий поддержку мультиплеера в Farming Simulator 12 путём инъекции разделяемой библиотеки во время выполнения, а не модификации APK игры. Написан на C++ и собран с Android NDK для legacy-целей armeabi; использует фреймворк хукинга Substrate для перехвата нативных функций меню, GUI и обновления через захардкоженные бинарные смещения. Мод реализует обнаружение по LAN через UDP и синхронизацию по TCP для обмена данными игроков, отображает внутриигровой оверлей с Dear ImGui на OpenGL ES 2 и включает автоматизированный pipeline GitHub Actions, который собирает инжектируемую библиотеку libmultiplayermod.so. Предназначен для reverse engineers и моддеров, изучающих нативный хукинг игр, совместимость с legacy Android ABI и модификацию закрытых мобильных игровых движков во время выполнения.
