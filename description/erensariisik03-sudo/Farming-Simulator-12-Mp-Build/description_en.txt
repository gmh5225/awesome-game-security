This is a native Android mod that adds multiplayer support to Farming Simulator 12 by injecting a shared library at runtime rather than modifying the game APK. Written in C++ and built with the Android NDK for legacy armeabi targets, it uses the Substrate hooking framework to intercept native menu, GUI, and update functions via hardcoded binary offsets. The mod implements UDP LAN discovery and TCP synchronization for player data exchange, renders an in-game overlay with Dear ImGui on OpenGL ES 2, and ships an automated GitHub Actions pipeline that produces the injectable libmultiplayermod.so library. It is aimed at reverse engineers and modders studying native game hooking, legacy Android ABI compatibility, and runtime modification of closed-source mobile game engines.
