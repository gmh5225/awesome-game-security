これは、ゲーム APK を変更する代わりに実行時に共有ライブラリを注入することで、Farming Simulator 12 にマルチプレイ対応を追加するネイティブ Android モッドです。C++ で記述され、レガシー armeabi ターゲット向けに Android NDK でビルドされており、Substrate フックフレームワークを使用して、ハードコードされたバイナリオフセット経由でネイティブのメニュー、GUI、更新関数をインターセプトします。モッドはプレイヤーデータ交換のために UDP LAN 検出と TCP 同期を実装し、OpenGL ES 2 上で Dear ImGui によるゲーム内オーバーレイをレンダリングし、注入可能な libmultiplayermod.so ライブラリを生成する自動 GitHub Actions パイプラインも同梱しています。ネイティブゲームフッキング、レガシー Android ABI 互換性、クローズドソースモバイルゲームエンジンの実行時改変を研究するリバースエンジニアおよびモッダー向けです。
