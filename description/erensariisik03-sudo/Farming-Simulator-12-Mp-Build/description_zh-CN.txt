这是一款原生 Android 模组，通过运行时注入共享库（而非修改游戏 APK）为 Farming Simulator 12 添加多人联机支持。使用 C++ 编写，并通过 Android NDK 面向旧版 armeabi 目标平台构建；借助 Substrate 框架，通过硬编码二进制偏移拦截原生菜单、GUI 和更新函数。该模组实现 UDP 局域网发现与 TCP 同步以交换玩家数据，在 OpenGL ES 2 上使用 Dear ImGui 渲染游戏内叠加层，并提供自动生成可注入 libmultiplayermod.so 库的 GitHub Actions 流水线。面向研究原生游戏 hook、旧版 Android ABI 兼容以及闭源移动游戏引擎运行时改动的逆向工程师与 Mod 开发者。
