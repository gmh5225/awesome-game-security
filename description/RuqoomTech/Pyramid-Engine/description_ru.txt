Pyramid Engine — игровой движок на C++17 на стадии pre-alpha, предоставляющий цикл приложения Win32/OpenGL, графическое устройство, систему сцен и модульные библиотеки поддержки для разработки игр. Ориентирован на OpenGL 3.3 core с шейдерами GLSL 3.30 и включает прямые и отложенные проходы рендеринга, shadow mapping, отсечение по frustum с октодеревом, сцены entity-component с сериализацией, а также кэши ресурсов для мешей, шейдеров, текстур и материалов. Отдельные пакеты охватывают математику (включая SIMD), действия ввода, загрузку изображений PNG/JPEG, импорт моделей OBJ/MTL, собственные инструменты TrueType/шрифтов, вёрстку текста и UI. Собирается с CMake для Windows через MSYS2 MinGW-w64 (Clang также проверен) и рассчитан на разработчиков, прототипирующих Windows-проекты; ближайший продуктовый фокус — вертикальный срез в стиле RTS.
