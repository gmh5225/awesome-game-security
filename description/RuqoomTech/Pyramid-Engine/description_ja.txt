Pyramid Engine は、Win32/OpenGL アプリケーションループ、グラフィックスデバイス、シーンシステム、およびゲーム構築向けのモジュール式サポートライブラリを提供する pre-alpha 段階の C++17 ゲームエンジンです。OpenGL 3.3 core と GLSL 3.30 シェーダーを対象とし、フォワード／ディファードレンダーパス、シャドウマッピング、オクトツリーによる視錐台カリング、シリアライズ対応のエンティティ・コンポーネントシーン、メッシュ・シェーダー・テクスチャ・マテリアルのリソースキャッシュを含みます。スタンドアロンパッケージは数学（SIMD 含む）、入力アクション、PNG/JPEG 画像読み込み、OBJ/MTL モデルインポート、独自の TrueType／フォントツール、テキストレイアウト、UI をカバーします。CMake で Windows 向けに MSYS2 MinGW-w64 経由でビルドされ（Clang も検証済み）、Windows タイトルのプロトタイピングを行うゲーム開発者向けで、短期的な製品フォーカスは RTS 風のバーティカルスライスです。
