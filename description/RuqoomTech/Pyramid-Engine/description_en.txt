Pyramid Engine is a pre-alpha C++17 game engine that provides a Win32/OpenGL application loop, graphics device, scene system, and modular support libraries for building games. It targets OpenGL 3.3 core with GLSL 3.30 shaders and includes forward and deferred render passes, shadow mapping, frustum culling with an octree, entity-component scenes with serialization, and resource caches for meshes, shaders, textures, and materials. Standalone packages cover math (including SIMD), input actions, PNG/JPEG image loading, OBJ/MTL model import, owned TrueType/font tooling, text layout, and UI. Built with CMake for Windows via MSYS2 MinGW-w64 (Clang also validated), it is aimed at game developers prototyping Windows titles, with an RTS-style vertical slice as the near-term product focus.
