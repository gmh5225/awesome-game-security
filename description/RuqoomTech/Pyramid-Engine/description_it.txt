Pyramid Engine è un motore di gioco C++17 in pre-alpha che fornisce un loop applicativo Win32/OpenGL, un dispositivo grafico, un sistema di scene e librerie di supporto modulari per creare giochi. Mira a OpenGL 3.3 core con shader GLSL 3.30 e include pass di rendering forward e deferred, shadow mapping, frustum culling con un octree, scene entity-component con serializzazione e cache di risorse per mesh, shader, texture e materiali. Pacchetti autonomi coprono matematica (incluso SIMD), azioni di input, caricamento immagini PNG/JPEG, import di modelli OBJ/MTL, tooling TrueType/font proprietario, layout del testo e UI. Compilato con CMake per Windows tramite MSYS2 MinGW-w64 (Clang anche validato), è rivolto agli sviluppatori che prototipano titoli Windows, con uno vertical slice in stile RTS come focus di prodotto a breve termine.
