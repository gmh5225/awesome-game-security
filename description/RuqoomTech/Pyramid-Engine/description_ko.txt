Pyramid Engine은 Win32/OpenGL 애플리케이션 루프, 그래픽 디바이스, 씬 시스템, 그리고 게임 제작을 위한 모듈형 지원 라이브러리를 제공하는 pre-alpha 단계의 C++17 게임 엔진입니다. OpenGL 3.3 core와 GLSL 3.30 셰이더를 대상으로 하며, 포워드 및 디퍼드 렌더 패스, 섀도 매핑, 옥트리 기반 프러스텀 컬링, 직렬화를 지원하는 엔티티-컴포넌트 씬, 메시·셰이더·텍스처·머티리얼용 리소스 캐시를 포함합니다. 독립 패키지는 수학(SIMD 포함), 입력 액션, PNG/JPEG 이미지 로딩, OBJ/MTL 모델 임포트, 자체 TrueType/폰트 도구, 텍스트 레이아웃, UI를 다룹니다. CMake로 Windows용 MSYS2 MinGW-w64를 통해 빌드되며(Clang도 검증됨), Windows 타이틀을 프로토타이핑하는 게임 개발자를 대상으로 하고, 단기 제품 초점은 RTS 스타일 버티컬 슬라이스입니다.
