Pyramid Engine 是一款預發布（pre-alpha）的 C++17 遊戲引擎，提供 Win32/OpenGL 應用程式迴圈、圖形裝置、場景系統，以及用於開發遊戲的模組化支援函式庫。它面向 OpenGL 3.3 core 與 GLSL 3.30 著色器，包含正向與延遲渲染通道、陰影貼圖、搭配八叉樹的視錐體剔除、具序列化的實體—元件場景，以及網格、著色器、紋理與材質的資源快取。獨立套件涵蓋數學（含 SIMD）、輸入動作、PNG/JPEG 影像載入、OBJ/MTL 模型匯入、自有的 TrueType/字型工具、文字排版與 UI。透過 CMake 面向 Windows（經 MSYS2 MinGW-w64，亦驗證過 Clang）建置，面向在 Windows 上原型開發的遊戲開發者，近期產品重點是 RTS 風格的垂直切片。
