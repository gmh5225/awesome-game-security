Pyramid Engine 是一款预发布（pre-alpha）的 C++17 游戏引擎，提供 Win32/OpenGL 应用循环、图形设备、场景系统以及用于开发游戏的模块化支持库。它面向 OpenGL 3.3 core 与 GLSL 3.30 着色器，包含前向与延迟渲染通道、阴影映射、基于八叉树的视锥体剔除、带序列化的实体—组件场景，以及网格、着色器、纹理和材质的资源缓存。独立包涵盖数学（含 SIMD）、输入动作、PNG/JPEG 图像加载、OBJ/MTL 模型导入、自有的 TrueType/字体工具、文本排版与 UI。通过 CMake 面向 Windows（经 MSYS2 MinGW-w64，亦验证过 Clang）构建，面向在 Windows 上原型开发的游戏开发者，近期产品重点是 RTS 风格的垂直切片。
