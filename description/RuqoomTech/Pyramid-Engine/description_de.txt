Pyramid Engine ist eine Pre-Alpha-C++17-Spiel-Engine, die eine Win32/OpenGL-Anwendungsschleife, ein Grafikgerät, ein Szenensystem sowie modulare Support-Bibliotheken zum Spielebau bereitstellt. Sie zielt auf OpenGL 3.3 Core mit GLSL-3.30-Shadern und umfasst Forward- und Deferred-Render-Passes, Shadow Mapping, Frustum Culling mit einem Octree, Entity-Component-Szenen mit Serialisierung sowie Ressourcen-Caches für Meshes, Shader, Texturen und Materialien. Eigenständige Pakete decken Mathematik (inkl. SIMD), Eingabeaktionen, PNG/JPEG-Bildladen, OBJ/MTL-Modellimport, eigene TrueType-/Font-Werkzeuge, Textlayout und UI ab. Mit CMake für Windows über MSYS2 MinGW-w64 gebaut (Clang ebenfalls validiert), richtet sie sich an Spieleentwickler, die Windows-Titel prototypisieren, mit einem RTS-artigen Vertical Slice als kurzfristigem Produktfokus.
