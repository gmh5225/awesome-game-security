HikariSystem HexCore — это интегрированная среда разработки на базе VS Code для бинарного анализа, исследования вредоносного ПО и реверс-инжиниринга. Она объединяет десятки расширений HexCore, написанных преимущественно на TypeScript с нативными движками C++ Node-API, включая дизассемблирование Capstone, эмуляцию CPU Unicorn, подъём Remill в LLVM IR, декompиляцию Rellic, супероптимизацию Souper и сканирование YARA со встроенными правилами антиотладки и обфускации. Платформа охватывает разбор PE и ELF, hex-редактирование, расшифровку строк и XOR, анализ энтропии, проверку minidump, извлечение IOC и семантический запросный слой HQL для обнаружения антианалитических паттернов, таких как хеширование API и проверки VM. Безголовый конвейер автоматизации, управляемый JSON-файлами заданий hexcore, поддерживает пакетное дизассемблирование, эмуляцию и формирование отчётов. Он предназначен для аналитиков вредоносного ПО, специалистов по реверс-инжинирингу и исследователей безопасности, которым нужна единая настольная среда — от статической инспекции до динамической эмуляции и декompиляции.
