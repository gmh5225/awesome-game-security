HikariSystem HexCore는 바이너리 분석, 멀웨어 연구, 리버스 엔지니어링을 위한 VS Code 기반 통합 개발 환경입니다. 주로 TypeScript로 작성되고 C++ Node-API 네이티브 엔진과 함께 구성된 수십 개의 HexCore 확장 기능을 포함하며, Capstone 디스어셈블리, Unicorn CPU 에뮬레이션, Remill을 통한 LLVM IR 리프팅, Rellic 디컴파일, Souper 슈퍼최적화, 내장 안티디버그 및 난독화 규칙이 포함된 YARA 스캔 등을 제공합니다. 이 플랫폼은 PE 및 ELF 파싱, 헥스 편집, 문자열 및 XOR 복호화, 엔트로피 분석, minidump 검사, IOC 추출, API 해싱 및 VM 검사와 같은 안티분석 패턴 탐지를 위한 HQL 시맨틱 쿼리 계층을 다룹니다. hexcore 작업 JSON 파일로 구동되는 헤드리스 자동화 파이프라인은 일괄 디스어셈블리, 에뮬레이션, 보고 워크플로를 지원합니다. 정적 검사부터 동적 에뮬레이션 및 디컴파일까지 통합된 데스크톱 환경이 필요한 멀웨어 분석가, 리버스 엔지니어, 보안 연구자를 대상으로 합니다.
