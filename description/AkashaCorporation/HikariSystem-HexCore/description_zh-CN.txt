HikariSystem HexCore 是一款基于 VS Code 的集成开发环境，面向二进制分析、恶意软件研究与逆向工程。它集成了数十个主要用 TypeScript 编写、并搭配 C++ Node-API 原生引擎的 HexCore 扩展，包括 Capstone 反汇编、Unicorn CPU 模拟、Remill 提升至 LLVM IR、Rellic 反编译、Souper 超级优化，以及带内置反调试与混淆规则的 YARA 扫描。该平台涵盖 PE 与 ELF 解析、十六进制编辑、字符串与 XOR 解密、熵分析、minidump 检查、IOC 提取，以及用于检测 API 哈希、虚拟机检测等反分析模式的 HQL 语义查询层。由 hexcore 作业 JSON 文件驱动的无头自动化流水线支持批量反汇编、模拟与报告工作流。它面向需要统一桌面环境、从静态检查到动态模拟与反编译的恶意软件分析师、逆向工程师与安全研究人员。
