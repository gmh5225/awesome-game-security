HikariSystem HexCore は、バイナリ解析、マルウェア研究、リバースエンジニアリング向けの VS Code ベースの統合開発環境です。主に TypeScript で記述され、C++ Node-API ネイティブエンジンと組み合わされた数十の HexCore 拡張機能を同梱しており、Capstone 逆アセンブル、Unicorn CPU エミュレーション、Remill による LLVM IR へのリフティング、Rellic 逆コンパイル、Souper 超最適化、組み込みの反デバッグおよび難読化ルール付き YARA スキャンなどを含みます。このプラットフォームは PE および ELF 解析、十六進編集、文字列と XOR 復号、エントロピー分析、minidump 検査、IOC 抽出、API ハッシュや VM チェックなどの反解析パターン検出用 HQL セマンティッククエリ層をカバーします。hexcore ジョブ JSON ファイルによって駆動されるヘッドレス自動化パイプラインは、バッチ逆アセンブル、エミュレーション、レポート生成ワークフローをサポートします。静的検査から動的エミュレーション、逆コンパイルまで統一されたデスクトップ環境を必要とするマルウェアアナリスト、リバースエンジニア、セキュリティ研究者を対象としています。
