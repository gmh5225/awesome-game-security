HikariSystem HexCore es un entorno de desarrollo integrado basado en VS Code para análisis binario, investigación de malware e ingeniería inversa. Integra decenas de extensiones HexCore escritas principalmente en TypeScript con motores nativos C++ Node-API, incluidos desensamblado Capstone, emulación de CPU Unicorn, elevación Remill a LLVM IR, descompilación Rellic, superoptimización Souper y escaneo YARA con reglas integradas anti-depuración y de ofuscación. La plataforma cubre análisis PE y ELF, edición hexadecimal, descifrado de cadenas y XOR, análisis de entropía, inspección de minidumps, extracción de IOC y una capa de consultas semánticas HQL para detectar patrones anti-análisis como hashing de API y comprobaciones de VM. Un pipeline de automatización headless impulsado por archivos JSON de trabajos hexcore admite flujos de trabajo de desensamblado, emulación e informes por lotes. Está dirigido a analistas de malware, ingenieros de ingeniería inversa e investigadores de seguridad que necesitan un entorno de escritorio unificado, desde la inspección estática hasta la emulación dinámica y la descompilación.
