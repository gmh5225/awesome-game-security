HikariSystem HexCore 是一款以 VS Code 為基礎的整合開發環境，適用於二進位分析、惡意軟體研究與逆向工程。它整合了數十個主要以 TypeScript 撰寫、並搭配 C++ Node-API 原生引擎的 HexCore 擴充功能，包括 Capstone 反組譯、Unicorn CPU 模擬、Remill 提升至 LLVM IR、Rellic 反編譯、Souper 超級最佳化，以及內建反除錯與混淆規則的 YARA 掃描。此平台涵蓋 PE 與 ELF 解析、十六進位編輯、字串與 XOR 解密、熵分析、minidump 檢查、IOC 擷取，以及用於偵測 API 雜湊、虛擬機器檢查等反分析模式的 HQL 語意查詢層。由 hexcore 工作 JSON 檔案驅動的無頭自動化管線支援批次反組譯、模擬與報告工作流程。它面向需要統一桌面環境、從靜態檢查到動態模擬與反編譯的惡意軟體分析師、逆向工程師與安全研究人員。
