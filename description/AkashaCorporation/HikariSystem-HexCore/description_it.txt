HikariSystem HexCore è un ambiente di sviluppo integrato basato su VS Code per l'analisi binaria, la ricerca su malware e il reverse engineering. Integra decine di estensioni HexCore scritte principalmente in TypeScript con motori nativi C++ Node-API, tra cui disassemblaggio Capstone, emulazione CPU Unicorn, lifting Remill verso LLVM IR, decompilazione Rellic, superottimizzazione Souper e scansione YARA con regole integrate anti-debug e di offuscamento. La piattaforma copre parsing PE ed ELF, editing esadecimale, decifratura di stringhe e XOR, analisi dell'entropia, ispezione di minidump, estrazione di IOC e un livello di query semantiche HQL per rilevare pattern anti-analisi come hashing delle API e controlli VM. Una pipeline di automazione headless guidata da file JSON di job hexcore supporta flussi di lavoro di disassemblaggio, emulazione e reporting in batch. È rivolto ad analisti di malware, reverse engineer e ricercatori di sicurezza che necessitano di un ambiente desktop unificato, dall'ispezione statica all'emulazione dinamica e alla decompilazione.
