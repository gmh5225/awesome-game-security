Ringo is a modular Windows anti-cheat stack built for learning, combining a kernel driver, a user-mode client, and a C++ backend server without injecting code into the game process. The WDM driver uses process, thread, image-load, and object callbacks plus a randomized scheduler to gather telemetry, detect manual-mapped kernel drivers and BYOVD abuse, verify module and section integrity, and apply red-pill style checks for hypervisors and emulated environments. It also records hardware identity and platform posture such as HVCI, VBS, Secure Boot, TPM, test signing, and kernel debugging, while hardening its device interface with caller signature checks and HMAC-protected IOCTLs. The client loads the driver and forwards reports to the server, which stores data in its own database and runs rule-based analysis to produce player risk verdicts. It targets game security researchers and operators who want an readable, non-injected anti-cheat suitable for community-managed servers and similar environments where in-process modules are undesirable.
