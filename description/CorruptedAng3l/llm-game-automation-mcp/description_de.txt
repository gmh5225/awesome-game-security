LLM Game Automation MCP ist ein Windows-Stack, mit dem LLM-Agenten oder Skripte Singleplayer-Spiele im Hintergrund steuern können, indem in jeden Spielprozess eine vinput-DLL injiziert und die Steuerung über einen Model Context Protocol-Server bereitgestellt wird. Der Kern ist in C++ mit MSVC geschrieben und nutzt API-Hooking (einschließlich MinHook), um virtuelle Tastatur-, Maus- und Gamepad-Eingaben auf denselben Kanälen wie die Spiele zu liefern, Fokus vorzutäuschen, damit Titel ohne Vordergrund weiter rendern, und Frames aus der Spiel-Swapchain über Direct3D, OpenGL und Vulkan zu erfassen. Ein TypeScript-Node.js-MCP-Server kapselt die vinput-CLI mit Werkzeugen für Start, Capture, OCR-basierte Textinteraktion, Skripting und Input-Tracing. Eingebaute Anti-Cheat-Schutzmechanismen verweigern die Injektion, wenn bekannte Online-Anti-Cheat-Komponenten oder -Prozesse vorhanden sind; das Projekt eignet sich daher eher zum Studium prozessbezogener Input-Injektion, Grafikerfassung und defensiver Ablehnungslogik in Offline-Automatisierung, Tests und Sicherheitsforschung als für Live-Multiplayer-Cheating.
