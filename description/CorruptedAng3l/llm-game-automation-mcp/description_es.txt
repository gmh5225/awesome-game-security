LLM Game Automation MCP es una pila para Windows que permite a agentes LLM o scripts controlar juegos para un jugador en segundo plano inyectando una DLL vinput en cada proceso del juego y exponiendo el control mediante un servidor Model Context Protocol. El núcleo está escrito en C++ con MSVC y usa hooking de API (incluido MinHook) para enviar entrada virtual de teclado, ratón y mando por los mismos canales que leen los juegos, simular el foco para que los títulos sigan renderizando sin estar en primer plano y capturar fotogramas desde la swapchain del juego en Direct3D, OpenGL y Vulkan. Un servidor MCP Node.js en TypeScript envuelve la CLI vinput con herramientas de lanzamiento, captura, interacción de texto basada en OCR, scripting y trazado de entradas. Las protecciones anti-trampas integradas rechazan la inyección cuando hay componentes o procesos anti-trampas en línea conocidos, lo que hace útil el proyecto para estudiar inyección de entrada por proceso, captura gráfica y lógica de rechazo defensivo en automatización offline, pruebas e investigación de seguridad, más que para trampas multijugador en vivo.
