LLM Game Automation MCP è uno stack Windows che consente ad agenti LLM o script di guidare giochi single-player in background iniettando una DLL vinput in ogni processo di gioco ed esponendo il controllo tramite un server Model Context Protocol. Il nucleo è scritto in C++ con MSVC e usa l’hooking delle API (incluso MinHook) per fornire input virtuali da tastiera, mouse e gamepad sugli stessi canali letti dai giochi, simulare il focus affinché i titoli continuino a renderizzare senza essere in primo piano e catturare frame dalla swapchain del gioco su Direct3D, OpenGL e Vulkan. Un server MCP Node.js in TypeScript avvolge la CLI vinput con strumenti per avvio, cattura, interazione testuale basata su OCR, scripting e tracciamento degli input. Guardie anti-cheat integrate rifiutano l’iniezione quando sono presenti componenti o processi anti-cheat online noti, rendendo il progetto utile per studiare iniezione di input per processo, cattura grafica e logica di rifiuto difensivo in automazione offline, test e ricerca sulla sicurezza piuttosto che cheating multigiocatore live.
