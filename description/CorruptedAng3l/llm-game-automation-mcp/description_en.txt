LLM Game Automation MCP is a Windows stack that lets LLM agents or scripts drive single-player games in the background by injecting a vinput DLL into each game process and exposing control through a Model Context Protocol server. The core is written in C++ with MSVC and uses API hooking (including MinHook) to deliver virtual keyboard, mouse, and gamepad input on the same channels games read, fake focus so titles keep rendering without the foreground, and capture frames from the game swapchain across Direct3D, OpenGL, and Vulkan. A TypeScript Node.js MCP server wraps the vinput CLI with tools for launch, capture, OCR-based text interaction, scripting, and input tracing. Built-in anti-cheat guards refuse injection when known online anti-cheat components or processes are present, which makes the project useful for studying per-process input injection, graphics capture, and defensive refusal logic in offline automation, testing, and security research contexts rather than live multiplayer cheating.
