LLM Game Automation MCP — стек для Windows, позволяющий LLM-агентам или скриптам управлять одиночными играми в фоне: в каждый игровой процесс внедряется DLL vinput, а управление доступно через сервер Model Context Protocol. Ядро написано на C++ с MSVC и использует перехват API (включая MinHook) для виртуального ввода с клавиатуры, мыши и геймпада по тем же каналам, что и игры, подмены фокуса, чтобы игры продолжали рендеринг без активного окна, и захвата кадров из swapchain игры в Direct3D, OpenGL и Vulkan. MCP-сервер на TypeScript и Node.js оборачивает CLI vinput инструментами запуска, захвата, текстового взаимодействия через OCR, сценариев и трассировки ввода. Встроенные античит-ограничения отказывают во внедрении при обнаружении известных онлайн-античит-компонентов или процессов, поэтому проект полезен для изучения по-процессной инъекции ввода, захвата графики и защитной логики отказа в офлайн-автоматизации, тестировании и исследованиях безопасности, а не для читов в живом мультиплеере.
