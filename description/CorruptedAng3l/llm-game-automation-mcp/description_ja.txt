LLM Game Automation MCP は Windows 向けスタックで、各ゲームプロセスに vinput DLL を注入し、Model Context Protocol サーバー経由で制御を公開することにより、LLM エージェントやスクリプトがバックグラウンドでシングルプレイゲームを操作できるようにします。コアは C++ と MSVC で書かれ、API フック（MinHook を含む）でゲームが読み取るのと同じ経路に仮想キーボード・マウス・ゲームパッド入力を送り、フォアグラウンドでなくても描画を続けるためのフォーカス偽装、Direct3D・OpenGL・Vulkan のスワップチェーンからのフレーム取得を行います。TypeScript の Node.js MCP サーバーが vinput CLI をラップし、起動、キャプチャ、OCR によるテキスト操作、スクリプティング、入力トレース用ツールを提供します。組み込みの反チート保護は既知のオンライン反チートコンポーネントやプロセスを検出すると注入を拒否するため、本プロジェクトはライブマルチプレイでの不正より、オフライン自動化・テスト・セキュリティ研究におけるプロセス単位の入力注入、グラフィックスキャプチャ、防御的拒否ロジックの学習に適しています。
