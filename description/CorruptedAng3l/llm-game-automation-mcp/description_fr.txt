LLM Game Automation MCP est une pile Windows qui permet à des agents LLM ou des scripts de piloter des jeux solo en arrière-plan en injectant une DLL vinput dans chaque processus de jeu et en exposant le contrôle via un serveur Model Context Protocol. Le cœur est écrit en C++ avec MSVC et utilise le hooking d’API (dont MinHook) pour fournir une saisie clavier, souris et manette virtuelle sur les mêmes canaux que les jeux, simuler le focus pour que les titres continuent à s’afficher sans être au premier plan, et capturer des images depuis la swapchain du jeu sur Direct3D, OpenGL et Vulkan. Un serveur MCP Node.js en TypeScript encapsule la CLI vinput avec des outils pour le lancement, la capture, l’interaction textuelle par OCR, le scripting et le traçage des entrées. Des garde-fous anti-triche intégrés refusent l’injection lorsque des composants ou processus anti-triche en ligne connus sont présents, ce qui rend le projet utile pour étudier l’injection d’entrées par processus, la capture graphique et la logique de refus défensif dans l’automatisation hors ligne, les tests et la recherche en sécurité plutôt que la triche multijoueur en direct.
