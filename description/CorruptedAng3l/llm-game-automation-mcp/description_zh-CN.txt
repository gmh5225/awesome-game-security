LLM Game Automation MCP 是一套 Windows 技术栈，通过向每个游戏进程注入 vinput DLL，并以 Model Context Protocol 服务器暴露控制接口，使 LLM 智能体或脚本能在后台驱动单机游戏。核心由 C++ 与 MSVC 编写，采用 API 挂钩（含 MinHook），在与游戏相同的输入通道上提供虚拟键盘、鼠标与手柄输入，伪造焦点以便非前台时仍继续渲染，并从游戏交换链抓取 Direct3D、OpenGL 与 Vulkan 画面。TypeScript Node.js MCP 服务器封装 vinput CLI，提供启动、截屏、基于 OCR 的文本交互、脚本与输入追踪等工具。内置反作弊防护会在检测到已知在线反作弊组件或进程时拒绝注入，因此该项目更适合用于离线自动化、测试与安全研究中学习逐进程输入注入、图形捕获与防御性拒绝逻辑，而非用于在线多人作弊。
