LLM Game Automation MCP는 Windows 스택으로, 각 게임 프로세스에 vinput DLL을 주입하고 Model Context Protocol 서버를 통해 제어를 노출하여 LLM 에이전트나 스크립트가 백그라운드에서 싱글플레이 게임을 구동할 수 있게 합니다. 핵심은 C++와 MSVC로 작성되었으며 API 후킹(MinHook 포함)으로 게임이 읽는 것과 동일한 경로에 가상 키보드·마우스·게임패드 입력을 제공하고, 전경이 아니어도 렌더링이 계속되도록 포커스를 위조하며 Direct3D, OpenGL, Vulkan 스왑체인에서 프레임을 캡처합니다. TypeScript Node.js MCP 서버가 vinput CLI를 감싸 실행, 캡처, OCR 기반 텍스트 상호작용, 스크립팅, 입력 추적 도구를 제공합니다. 내장 반치트 가드는 알려진 온라인 반치트 구성 요소나 프로세스가 있으면 주입을 거부하므로, 이 프로젝트는 라이브 멀티플레이 치팅보다 오프라인 자동화·테스트·보안 연구 맥락에서 프로세스별 입력 주입, 그래픽 캡처, 방어적 거부 로직을 연구하는 데 유용합니다.
