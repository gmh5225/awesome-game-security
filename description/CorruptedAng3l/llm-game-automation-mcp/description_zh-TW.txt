LLM Game Automation MCP 是一套 Windows 技術堆疊，透過向每個遊戲程序注入 vinput DLL，並以 Model Context Protocol 伺服器暴露控制介面，讓 LLM 代理或腳本能在背景驅動單人遊戲。核心以 C++ 與 MSVC 撰寫，採用 API 掛鉤（含 MinHook），在與遊戲相同的輸入通道上提供虛擬鍵盤、滑鼠與手把輸入，偽造焦點使非前景時仍能繼續渲染，並從遊戲交換鏈擷取 Direct3D、OpenGL 與 Vulkan 畫面。TypeScript Node.js MCP 伺服器封裝 vinput CLI，提供啟動、截圖、基於 OCR 的文字互動、腳本與輸入追蹤等工具。內建反作弊防護會在偵測到已知線上反作弊元件或程序時拒絕注入，因此本專案更適合在離線自動化、測試與安全研究中學習逐程序輸入注入、圖形擷取與防禦性拒絕邏輯，而非用於線上多人作弊。
