Triton es una biblioteca de análisis binario dinámico para construir herramientas de análisis de programas, automatizar la ingeniería inversa, verificar software y emular código. Ofrece ejecución simbólica dinámica, análisis de taint dinámico, síntesis de expresiones y simplificación SMT, con semántica ISA para x86, x86-64, ARM32, AArch64 y RISC-V 32/64. La biblioteca puede elevar código a LLVM y Z3 (y a la inversa) y se comunica con solvers SMT como Z3 y Bitwuzla. Implementada principalmente en C++ con enlaces Python, está dirigida a ingenieros inversos, investigadores de seguridad y analistas que necesitan análisis binario simbólico y basado en taint programable.
