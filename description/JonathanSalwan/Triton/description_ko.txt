Triton은 프로그램 분석 도구 구축, 리버스 엔지니어링 자동화, 소프트웨어 검증, 코드 에뮬레이션을 위한 동적 바이너리 분석 라이브러리입니다. 동적 심볼릭 실행, 동적 테인트 분석, 표현식 합성, SMT 간소화를 제공하며 x86, x86-64, ARM32, AArch64, RISC-V 32/64 ISA 시맨틱을 지원합니다. 코드를 LLVM과 Z3로 리프트(및 역변환)할 수 있고 Z3, Bitwuzla 같은 SMT 솔버와 연동합니다. 주로 C++로 구현되고 Python 바인딩을 제공하며, 스크립트 가능한 심볼릭·테인트 기반 바이너리 분석이 필요한 리버스 엔지니어, 보안 연구자, 분석가를 대상으로 합니다.
