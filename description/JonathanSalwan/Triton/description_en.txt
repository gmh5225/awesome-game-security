Triton is a dynamic binary analysis library for building program analysis tools, automating reverse engineering, verifying software, and emulating code. It offers dynamic symbolic execution, dynamic taint analysis, expression synthesis, and SMT simplification, with ISA semantics for x86, x86-64, ARM32, AArch64, and RISC-V 32/64. The library can lift code to LLVM and Z3 (and back) and talks to SMT solvers such as Z3 and Bitwuzla. Implemented mainly in C++ with Python bindings, it is aimed at reverse engineers, security researchers, and analysts who need scriptable symbolic and taint-based binary analysis.
