Triton は、プログラム分析ツールの構築、リバースエンジニアリングの自動化、ソフトウェア検証、コードエミュレーションのための動的バイナリ解析ライブラリです。動的シンボリック実行、動的テイント解析、式合成、SMT 簡略化を提供し、x86、x86-64、ARM32、AArch64、RISC-V 32/64 の ISA セマンティクスに対応します。コードを LLVM や Z3 にリフト（および逆変換）でき、Z3 や Bitwuzla などの SMT ソルバと連携します。主に C++ で実装され Python バインディングを備え、スクリプト可能なシンボリック／テイントベースのバイナリ解析を必要とするリバースエンジニア、セキュリティ研究者、アナリスト向けです。
