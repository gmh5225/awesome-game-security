Triton — библиотека динамического анализа бинарного кода для создания инструментов анализа программ, автоматизации реверс-инжиниринга, верификации ПО и эмуляции кода. Она предоставляет динамическое символьное выполнение, динамический taint-анализ, синтез выражений и упрощение SMT, а также семантику ISA для x86, x86-64, ARM32, AArch64 и RISC-V 32/64. Библиотека может поднимать код до LLVM и Z3 (и обратно) и взаимодействует с SMT-решателями, такими как Z3 и Bitwuzla. Реализована в основном на C++ с привязками Python и предназначена для реверс-инженеров, исследователей безопасности и аналитиков, которым нужен скриптуемый символьный и taint-анализ бинарного кода.
