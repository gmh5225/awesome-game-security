GDMaim — это плагин редактора Godot Engine, который автоматически обфусцирует исходный код GDScript при экспорте проекта, существенно усложняя реверс-инжиниринг выпущенных сборок. Написанный преимущественно на GDScript, он переименовывает идентификаторы, инлайнит константы и перечисления, удаляет комментарии и форматирование и может перемешивать объявления верхнего уровня, не затрагивая исходные файлы проекта. Включает генератор и просмотрщик source map для отладки обфусцированных сборок, директивы препроцессора для тонкой настройки и теги функций шаблонов экспорта для фильтрации или отключения обфускации по платформам. Плагин интегрирует нативную библиотеку GDBC для дополнительной защиты строк и ориентирован на разработчиков игр Godot 4.x, которым нужно сдерживать инструменты декомпиляции и повышать планку для авторов читов, анализирующих клиентскую многопользовательскую логику.
