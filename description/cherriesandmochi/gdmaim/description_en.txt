GDMaim is a Godot Engine editor plugin that automatically obfuscates GDScript source code when a project is exported, making reverse engineering of shipped builds significantly harder. Written primarily in GDScript, it renames identifiers, inlines constants and enums, strips comments and formatting, and can shuffle top-level declarations while leaving the original project files untouched. It includes a source map generator and viewer for debugging obfuscated builds, preprocessor hints for fine-grained control, and export-template feature tags to filter or disable obfuscation per platform. The plugin integrates the GDBC native library for additional string protection and targets Godot 4.x game developers who need to deter decompilation tools and raise the bar against cheat authors analyzing client-side multiplayer logic.
