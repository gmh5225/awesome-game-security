GDMaim은 Godot Engine 에디터 플러그인으로, 프로젝트를 내보낼 때 GDScript 소스 코드를 자동으로 난독화하여 배포 빌드의 리버스 엔지니어링을 크게 어렵게 만듭니다. 주로 GDScript로 작성되었으며, 식별자 이름 변경, 상수와 열거형 인라인화, 주석 및 서식 제거, 최상위 선언 순서 섞기를 수행하면서 원본 프로젝트 파일은 그대로 둡니다. 난독화된 빌드 디버깅용 source map 생성기와 뷰어, 세밀한 제어를 위한 전처리기 힌트, 플랫폼별로 난독화를 필터링하거나 비활성화하는 내보내기 템플릿 기능 태그를 포함합니다. 추가 문자열 보호를 위해 GDBC 네이티브 라이브러리를 통합하며, 디컴파일 도구를 막고 클라이언트 측 멀티플레이어 로직을 분석하는 치트 제작자에 대한 진입 장벽을 높이려는 Godot 4.x 게임 개발자를 대상으로 합니다.
