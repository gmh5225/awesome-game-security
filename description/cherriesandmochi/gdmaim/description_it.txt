GDMaim è un plugin per l'editor di Godot Engine che offusca automaticamente il codice sorgente GDScript durante l'esportazione di un progetto, rendendo l'ingegneria inversa delle build distribuite significativamente più difficile. Scritto principalmente in GDScript, rinomina gli identificatori, inline costanti ed enumerazioni, rimuove commenti e formattazione e può mescolare le dichiarazioni di livello superiore lasciando intatti i file originali del progetto. Include un generatore e un visualizzatore di source map per il debug delle build offuscate, hint del preprocessore per un controllo granulare e tag delle funzionalità dei template di esportazione per filtrare o disabilitare l'offuscamento per piattaforma. Il plugin integra la libreria nativa GDBC per una protezione aggiuntiva delle stringhe ed è rivolto agli sviluppatori di giochi Godot 4.x che devono scoraggiare strumenti di decompilazione e alzare l'asticella contro autori di cheat che analizzano la logica multigiocatore lato client.
