これは独立したシステムセキュリティ研究プロジェクトであり、仮想化を主要な手段とせずに、Windows と同等のセキュリティ水準でカーネルアンチチートコンポーネントをホストできる、ベンダー非依存の Linux 互換レイヤーに関する文献調査およびアーキテクチャ実現可能性調査を文書化するものです。本調査は公開情報に基づきカーネルアンチチートが Windows カーネルに求める要件を分析し、LSM、カーネルモジュール、署名、分離、ABI 制約を含む Linux の能力と限界を評価し、厳密な反証可能性の下で非仮想化設計オプションを検討します。成果物として、出荷コードではなくエンジニアリング仕様として意図された調査報告書とナレッジグラフを生成し、クローズドバイナリのリバースエンジニアリング、バイパス手法、ゲーム固有のエクスプロイトは明示的に対象外とします。リポジトリは初期セットアップ段階にあり実装はまだなく、アンチチートアーキテクチャおよび Linux ゲームセキュリティに取り組む研究者とエンジニアを対象としています。
