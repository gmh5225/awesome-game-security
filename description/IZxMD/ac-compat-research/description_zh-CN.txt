这是一个独立的系统安全研究项目，旨在记录一项文献与架构可行性研究：构建一个与厂商无关的 Linux 兼容层，在不以虚拟化作为主要方案的前提下，能够以与 Windows 相当的安全级别承载内核反作弊组件。该研究基于公开资料分析内核反作弊对 Windows 内核的需求，评估 Linux 的能力与局限（包括 LSM、内核模块、签名、隔离与 ABI 约束），并探索可经受严格证伪检验的非虚拟化设计方案。项目将产出一份档案与知识图谱，作为工程规范而非可交付代码，并明确排除对闭源二进制进行逆向、绕过技术或针对特定游戏的漏洞利用。仓库目前处于早期搭建阶段，尚无实现，面向从事反作弊架构与 Linux 游戏安全工作的研究人员和工程师。
