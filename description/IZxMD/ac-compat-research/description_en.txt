This is an independent systems-security research project that documents a literature and architecture feasibility study for a vendor-agnostic Linux compatibility layer capable of hosting kernel anti-cheat components with security equivalence to Windows, without relying on virtualization as the primary approach. The study analyzes what kernel anti-cheats require from a Windows kernel using public sources, evaluates Linux capabilities and limitations including LSM, kernel modules, signing, isolation, and ABI constraints, and explores non-virtualized design options subject to rigorous falsification. It produces a dossier and knowledge graph intended as an engineering specification rather than shipping code, and explicitly excludes reverse-engineering closed binaries, bypass techniques, or game-specific exploits. The repository is in early setup phase with no implementation yet, targeting researchers and engineers working on anti-cheat architecture and Linux game security.
