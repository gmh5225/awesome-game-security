這是一個獨立的系統安全研究專案，旨在記錄一項文獻與架構可行性研究：建構一個與廠商無關的 Linux 相容層，在不以虛擬化作為主要方案的前提下，能夠以與 Windows 相當的安全等級承載核心反作弊元件。該研究基於公開資料分析核心反作弊對 Windows 核心的需求，評估 Linux 的能力與侷限（包括 LSM、核心模組、簽章、隔離與 ABI 約束），並探索可經受嚴格證偽檢驗的非虛擬化設計方案。專案將產出一份檔案與知識圖譜，作為工程規範而非可交付程式碼，並明確排除對閉源二進位進行逆向、繞過技術或針對特定遊戲的漏洞利用。儲存庫目前處於早期建置階段，尚無實作，面向從事反作弊架構與 Linux 遊戲安全工作的研究人員和工程師。
