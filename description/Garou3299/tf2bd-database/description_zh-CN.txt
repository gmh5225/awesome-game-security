这是一个由社区维护的数据库，收录 Team Fortress 2 中的作弊者、可疑玩家和诈骗者，以 JSON 玩家列表和自定义检测规则的形式分发，供 TF2 Bot Detector（TF2BD）客户端使用。数据遵循 PazerOP 的 TF2BD v3 玩家列表与规则模式，为 Steam 账号打上作弊者、种族主义者或诈骗者等标签，并记录最后出现时间及可用证据。其中包含主玩家列表、独立的诈骗者列表，以及用于自动标记种族主义言论的自定义聊天词过滤规则。用户可将 JSON 文件导入 TF2BD 或兼容分支，在游戏过程中对已知不良行为者发出提醒；贡献者可通过项目讨论提交新条目并附上视频证据。该仓库面向寻求轻量级客户端反作弊与社区管理支持的 TF2 玩家和服务器社区，而非传统的逆向工程或内核级反作弊开发。
