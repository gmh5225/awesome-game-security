This is a community-curated database of cheaters, suspicious players, and scammers for Team Fortress 2, distributed as JSON player lists and custom detection rules for the TF2 Bot Detector (TF2BD) client. The data follows PazerOP's TF2BD v3 playerlist and rules schemas, tagging Steam accounts with attributes such as cheater, racist, or scammer and recording last-seen metadata and supporting proof where available. It includes a main player list, a separate scammer list, and custom chat word-filter rules that automatically mark racist behavior. Users import the JSON files into TF2BD or compatible forks to alert on known bad actors during gameplay, and contributors can submit new entries with video evidence via project discussions. The repository is aimed at TF2 players and server communities seeking lightweight, client-side anti-cheat and moderation support rather than traditional reverse engineering or kernel anti-cheat development.
