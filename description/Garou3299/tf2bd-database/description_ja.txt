Team Fortress 2 のチーター、不審なプレイヤー、詐欺師をまとめたコミュニティ管理データベースで、JSON 形式のプレイヤーリストとカスタム検出ルールとして TF2 Bot Detector（TF2BD）クライアント向けに配布されています。データは PazerOP の TF2BD v3 プレイヤーリストおよびルールスキーマに準拠し、Steam アカウントにチーター、人種差別者、詐欺師などの属性タグを付け、最終確認日時や利用可能な証拠も記録します。メインプレイヤーリスト、詐欺師専用リスト、人種差別的な発言を自動的に検出するカスタムチャット単語フィルタールールが含まれます。ユーザーは JSON ファイルを TF2BD または互換フォークにインポートし、ゲーム中に既知の問題プレイヤーを警告できます。貢献者はプロジェクトのディスカッションから動画証拠付きで新規エントリを提出できます。このリポジトリは、従来のリバースエンジニアリングやカーネルレベルのアンチチート開発ではなく、軽量なクライアントサイドのアンチチートおよびモデレーション支援を求める TF2 プレイヤーやサーバーコミュニティを対象としています。
