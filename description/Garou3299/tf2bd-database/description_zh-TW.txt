這是一個由社群維護的資料庫，收錄 Team Fortress 2 中的作弊者、可疑玩家和詐騙者，以 JSON 玩家清單和自訂偵測規則的形式分發，供 TF2 Bot Detector（TF2BD）用戶端使用。資料遵循 PazerOP 的 TF2BD v3 玩家清單與規則結構，為 Steam 帳號標記作弊者、種族歧視者或詐騙者等屬性，並記錄最後出現時間及可用證據。其中包含主要玩家清單、獨立的詐騙者清單，以及用於自動標記種族歧視言論的自訂聊天詞過濾規則。使用者可將 JSON 檔案匯入 TF2BD 或相容分支，在遊戲過程中對已知不良行為者發出提醒；貢獻者可透過專案討論提交新條目並附上影片證據。此儲存庫面向尋求輕量級用戶端反作弊與社群管理支援的 TF2 玩家和伺服器社群，而非傳統的逆向工程或核心層級反作弊開發。
