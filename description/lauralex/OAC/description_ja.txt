OAC は、Windows 向けのオンデマンド起動型の防御的アンチチートフレームワークで、カーネルモードドライバーとユーザーモードクライアントを組み合わせ、起動前の整合性ゲートと継続的なランタイム監視によってゲームプロセスを保護します。主に C と C++ で書かれており、ドライバーは CPU 状態スナップショット、ハードウェアブレークポイント検出、ハイパーバイザーおよび整合性チェック、起動後のドライバー読み込みゲート、任意の MmUnloadedDrivers および PiDDB トレース解析などのカーネルスキャンを実行します。クライアントはプリフライト、サスペンド起動、プロセス保護、ハンドルポリシーの適用、HVCI やコード整合性ステータスなどのプラットフォームセキュリティテレメトリを統括します。また、相互に裏付けられたシステムシグナルからプライバシーを保護した複合ハードウェア ID を構築し、監査、テスト、本番の各デプロイメントモード、設定可能な重大度しきい値、任意の反デバッグ強化、サーバー発行のチャレンジバインディングをサポートします。プロジェクトにはテスト署名、ドライバーポリシー管理、Hyper-V ベースの検証向けの PowerShell および Python ツールが含まれ、Windows 上でカーネル支援型アンチチートを構築するゲームセキュリティエンジニアと研究者を対象としています。
