OAC는 Windows용 수요 기반 방어형 안티치트 프레임워크로, 커널 모드 드라이버와 사용자 모드 클라이언트를 결합하여 사전 실행 무결성 게이트와 지속적인 런타임 모니터링을 통해 게임 프로세스를 보호합니다. 주로 C와 C++로 작성되었으며, 드라이버는 CPU 상태 스냅샷, 하드웨어 중단점 탐지, 하이퍼바이저 및 무결성 검사, 시작 후 드라이버 로드 게이팅, 선택적 MmUnloadedDrivers 및 PiDDB 추적 분석 등 커널 스캔을 수행합니다. 클라이언트는 사전 점검, 일시 중지된 실행, 프로세스 보호, 핸들 정책 적용, HVCI 및 코드 무결성 상태와 같은 플랫폼 보안 원격 측정을 조율합니다. 또한 상호 검증된 시스템 신호로부터 개인정보를 보호하는 복합 하드웨어 ID를 구성하고, 감사, 테스트, 프로덕션 배포 모드, 구성 가능한 심각도 임계값, 선택적 안티디버그 강화, 서버 발급 챌린지 바인딩을 지원합니다. 이 프로젝트에는 테스트 서명, 드라이버 정책 관리, Hyper-V 기반 검증을 위한 PowerShell 및 Python 도구가 포함되어 있으며, Windows에서 커널 지원 안티치트를 구축하는 게임 보안 엔지니어와 연구자를 대상으로 합니다.
