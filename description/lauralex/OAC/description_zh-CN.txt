OAC 是一个按需启动的 Windows 防御型反作弊框架，通过内核模式驱动与用户模式客户端协同，以启动前完整性门禁和持续运行时监控来保护游戏进程。项目主要使用 C 和 C++ 编写；驱动执行内核扫描，包括 CPU 状态快照、硬件断点检测、虚拟机监控程序与完整性检查、启动后驱动加载门禁，以及可选的 MmUnloadedDrivers 与 PiDDB 痕迹分析；客户端则负责预检、挂起启动、进程保护、句柄策略执行，以及 HVCI 与代码完整性状态等平台安全遥测。它还会基于相互印证的系统信号构建隐私保护的复合硬件身份，并支持审计、测试与生产部署模式，可配置严重级别阈值、可选的反调试加固，以及服务器签发的挑战绑定。项目包含用于测试签名、驱动策略管理和基于 Hyper-V 验证的 PowerShell 与 Python 工具，面向在 Windows 上构建内核辅助反作弊方案的游戏安全工程师与研究人员。
