OAC is a demand-start defensive anti-cheat framework for Windows that pairs a kernel-mode driver with a user-mode client to protect game processes through pre-launch integrity gates and continuous runtime monitoring. Written primarily in C and C++, the driver performs kernel scans including CPU state snapshots, hardware breakpoint detection, hypervisor and integrity checks, post-start driver-load gating, and optional MmUnloadedDrivers and PiDDB trace analysis, while the client orchestrates preflight, suspended launch, process protection, handle policy enforcement, and platform security telemetry such as HVCI and code integrity status. It also builds a privacy-preserving composite hardware identity from corroborated system signals and supports audit, test, and production deployment modes with configurable severity thresholds, optional anti-debug hardening, and server-issued challenge binding. The project includes PowerShell and Python tooling for test-signing, driver policy management, and Hyper-V based validation, targeting game security engineers and researchers building kernel-assisted anti-cheat on Windows.
