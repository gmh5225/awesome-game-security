OAC 是一個按需啟動的 Windows 防禦型反作弊框架，透過核心模式驅動程式與使用者模式用戶端協同，以啟動前完整性閘門與持續執行階段監控來保護遊戲程序。專案主要以 C 與 C++ 撰寫；驅動程式執行核心掃描，包括 CPU 狀態快照、硬體中斷點偵測、Hypervisor 與完整性檢查、啟動後驅動程式載入閘門，以及可選的 MmUnloadedDrivers 與 PiDDB 痕跡分析；用戶端則負責預檢、暫停啟動、程序保護、控制代碼原則執行，以及 HVCI 與程式碼完整性狀態等平台安全遙測。它還會依據相互印證的系統訊號建立隱私保護的複合硬體身分，並支援稽核、測試與正式部署模式，可設定嚴重程度閾值、可選的反除錯強化，以及伺服器核發的挑戰綁定。專案包含用於測試簽署、驅動程式原則管理與以 Hyper-V 為基礎驗證的 PowerShell 與 Python 工具，面向在 Windows 上建構核心輔助反作弊方案的遊戲安全工程師與研究人員。
