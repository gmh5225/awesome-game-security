Kernel-AC is a kernel-level anti-cheat system for Windows that pairs a KMDF driver with a user-mode launcher to protect a running game process. The driver registers ObRegisterCallbacks on process and thread handle create and duplicate operations, strips dangerous access rights from untrusted callers, and enforces a whitelist of trusted process names such as explorer.exe and discord.exe. A C++ console client loads the driver through the Service Control Manager, communicates via IOCTLs to register the protected game PID, and is intended as an educational graduation project for learning Windows kernel anti-cheat and game security techniques.
