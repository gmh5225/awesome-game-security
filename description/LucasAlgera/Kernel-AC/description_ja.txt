Kernel-AC は、KMDF ドライバーとユーザーモードのランチャーを組み合わせ、実行中のゲームプロセスを保護する Windows 向けカーネルレベルのアンチチートシステムです。ドライバーはプロセスおよびスレッドハンドルの作成・複製操作に ObRegisterCallbacks を登録し、信頼されていない呼び出し元から危険なアクセス権を剥奪し、explorer.exe や discord.exe などの信頼済みプロセス名のホワイトリストを適用します。C++ コンソールクライアントはサービス制御マネージャー経由でドライバーをロードし、IOCTL 経由で保護対象ゲームの PID を登録して通信します。Windows カーネルアンチチートおよびゲームセキュリティ技術の学習を目的とした教育用卒業プロジェクトとして設計されています。
