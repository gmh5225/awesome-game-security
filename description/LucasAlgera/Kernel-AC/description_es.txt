Kernel-AC es un sistema antitrampas a nivel de kernel para Windows que combina un controlador KMDF con un lanzador en modo usuario para proteger un proceso de juego en ejecución. El controlador registra ObRegisterCallbacks en las operaciones de creación y duplicación de handles de procesos e hilos, elimina los derechos de acceso peligrosos de los llamadores no confiables y aplica una lista blanca de nombres de procesos de confianza como explorer.exe y discord.exe. Un cliente de consola en C++ carga el controlador a través del Administrador de control de servicios, se comunica mediante IOCTLs para registrar el PID del juego protegido y está pensado como un proyecto de graduación educativo para aprender técnicas de antitrampas en kernel de Windows y seguridad en juegos.
