Kernel-AC는 KMDF 드라이버와 사용자 모드 런처를 결합하여 실행 중인 게임 프로세스를 보호하는 Windows 커널 수준 안티치트 시스템입니다. 드라이버는 프로세스 및 스레드 핸들 생성 및 복제 작업에 ObRegisterCallbacks를 등록하여 신뢰할 수 없는 호출자로부터 위험한 액세스 권한을 제거하고, explorer.exe 및 discord.exe와 같은 신뢰할 수 있는 프로세스 이름의 화이트리스트를 적용합니다. C++ 콘솔 클라이언트는 서비스 제어 관리자를 통해 드라이버를 로드하고, IOCTL을 통해 보호 대상 게임 PID를 등록하여 통신하며, Windows 커널 안티치트 및 게임 보안 기술 학습을 위한 교육용 졸업 프로젝트로 제작되었습니다.
