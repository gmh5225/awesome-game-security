Kernel-AC est un système anti-triche au niveau noyau pour Windows qui associe un pilote KMDF à un lanceur en mode utilisateur pour protéger un processus de jeu en cours d'exécution. Le pilote enregistre ObRegisterCallbacks sur les opérations de création et de duplication de handles de processus et de threads, supprime les droits d'accès dangereux pour les appelants non fiables et applique une liste blanche de noms de processus de confiance tels qu'explorer.exe et discord.exe. Un client console C++ charge le pilote via le Gestionnaire de services, communique par IOCTLs pour enregistrer le PID du jeu protégé, et est conçu comme un projet de fin d'études éducatif pour apprendre les techniques d'anti-triche noyau Windows et de sécurité des jeux.
