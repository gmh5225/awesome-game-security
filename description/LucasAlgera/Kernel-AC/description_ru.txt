Kernel-AC — это античит-система уровня ядра для Windows, которая сочетает драйвер KMDF с пользовательским лаунчером для защиты запущенного игрового процесса. Драйвер регистрирует ObRegisterCallbacks на операциях создания и дублирования дескрипторов процессов и потоков, лишает недоверенных вызывающих сторон опасных прав доступа и применяет белый список доверенных имён процессов, таких как explorer.exe и discord.exe. Консольный клиент на C++ загружает драйвер через диспетчер управления службами, обменивается данными через IOCTL для регистрации PID защищаемой игры и предназначен как образовательный дипломный проект для изучения техник античита на уровне ядра Windows и безопасности игр.
