Zygisk-Il2CppFucker 是一个 Zygisk Magisk 模块，可注入 Android Unity IL2CPP 游戏进程，将正在运行的游戏转变为可脚本化的进程内逆向工程引擎。该项目 fork 自 Zygisk-Il2CppDumper，可将 IL2CPP 元数据导出至 dump.cs（包括 HybridCLR 热更新类），按名称解析类、字段和方法，并支持内存读写、实例扫描以及通过 il2cpp_runtime_invoke 调用游戏方法。它内嵌 Lua 5.4 引擎，支持可热重载的 init.lua 与 run.lua 脚本、基于文件的 .cmd 命令通道，以及用于实时分析的 overlay 绘制输出，无需外部 attach 工具。主要使用 C++ 构建，采用基于 Gradle 的 Android 模块打包，并提供可选的 Python 辅助工具，面向需要在目标进程内部检查与操控受保护移动游戏逻辑的安全研究人员与逆向工程师。
