Zygisk-Il2CppFucker は、Android の Unity IL2CPP ゲームプロセスに注入し、実行中のゲームをスクリプト可能なプロセス内リバースエンジニアリングエンジンに変換する Zygisk Magisk モジュールです。Zygisk-Il2CppDumper からフォークされ、IL2CPP メタデータを dump.cs にダンプし（HybridCLR のホットアップデートクラスを含む）、名前によるクラス・フィールド・メソッドの解決、メモリの読み書き、インスタンススキャン、il2cpp_runtime_invoke によるゲームメソッドの呼び出しをサポートします。Lua 5.4 エンジンを内蔵し、ホットリロード可能な init.lua と run.lua スクリプト、ファイルベースの .cmd コマンドチャネル、外部 attach ツールなしでライブ分析できる overlay 描画出力を備えています。主に C++ で構築され、Gradle ベースの Android モジュールパッケージングとオプションの Python ヘルパーを提供し、ターゲットプロセス内部から保護されたモバイルゲームロジックを検査・操作する必要があるセキュリティ研究者とリバースエンジニア向けです。
