Zygisk-Il2CppFucker is a Zygisk Magisk module that injects into Android Unity IL2CPP game processes to turn the running game into a scriptable in-process reverse-engineering engine. Forked from Zygisk-Il2CppDumper, it dumps IL2CPP metadata to dump.cs (including HybridCLR hot-update classes), resolves classes, fields, and methods by name, and supports memory read/write, instance scanning, and invoking game methods via il2cpp_runtime_invoke. It embeds a Lua 5.4 engine with hot-reloadable init.lua and run.lua scripts, a file-based .cmd command channel, and an overlay drawing output for live analysis without external attach tools. Built primarily in C++ with Gradle-based Android module packaging and optional Python helpers, it is aimed at security researchers and reverse engineers who need to inspect and manipulate protected mobile game logic from inside the target process.
