Zygisk-Il2CppFucker는 Android Unity IL2CPP 게임 프로세스에 주입하여 실행 중인 게임을 스크립트 가능한 프로세스 내 리버스 엔지니어링 엔진으로 전환하는 Zygisk Magisk 모듈입니다. Zygisk-Il2CppDumper에서 포크되었으며, IL2CPP 메타데이터를 dump.cs로 덤프하고(HybridCLR 핫 업데이트 클래스 포함), 이름으로 클래스·필드·메서드를 해석하며, 메모리 읽기/쓰기, 인스턴스 스캔, il2cpp_runtime_invoke를 통한 게임 메서드 호출을 지원합니다. Lua 5.4 엔진을 내장하고, 핫 리로드 가능한 init.lua 및 run.lua 스크립트, 파일 기반 .cmd 명령 채널, 외부 attach 도구 없이 실시간 분석을 위한 overlay 그리기 출력을 제공합니다. 주로 C++로 구축되었으며 Gradle 기반 Android 모듈 패키징과 선택적 Python 헬퍼를 포함하며, 대상 프로세스 내부에서 보호된 모바일 게임 로직을 검사하고 조작해야 하는 보안 연구자 및 리버스 엔지니어를 대상으로 합니다.
