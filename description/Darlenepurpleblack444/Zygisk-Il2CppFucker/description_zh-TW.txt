Zygisk-Il2CppFucker 是一個 Zygisk Magisk 模組，可注入 Android Unity IL2CPP 遊戲程序，將正在執行的遊戲轉變為可腳本化的程序內逆向工程引擎。此專案 fork 自 Zygisk-Il2CppDumper，可將 IL2CPP 中繼資料傾印至 dump.cs（包含 HybridCLR 熱更新類別），依名稱解析類別、欄位與方法，並支援記憶體讀寫、執行個體掃描，以及透過 il2cpp_runtime_invoke 呼叫遊戲方法。它內嵌 Lua 5.4 引擎，提供可熱重載的 init.lua 與 run.lua 腳本、以檔案為基礎的 .cmd 命令通道，以及用於即時分析的 overlay 繪製輸出，無需外部 attach 工具。主要以 C++ 建置，採用 Gradle 式 Android 模組封裝，並提供選用的 Python 輔助工具，面向需要在目標程序內部檢查與操控受保護行動遊戲邏輯的安全研究人員與逆向工程師。
