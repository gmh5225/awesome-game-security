Accel-virt는 확장 virtio-gpu 장치를 QEMU와 통합하여 게스트 Windows 렌더링 환경과 호스트 측 실행기를 짝지은 가상화 그래픽 가속 스택입니다. 코드베이스는 주로 C와 C++로 작성되었으며 CMake로 빌드되며, 커널 모드 DXGI/DXGK 배관과 Direct3D 9/11/12, Vulkan, OpenGL, OpenCL용 사용자 모드 심을 구현합니다. 게스트 RAM 대여, 세션 기록 및 재생, 추적 및 검사 도구, Direct3D·OpenGL·Vulkan 및 오버레이형 프레젠테이션 경로용 전용 프로브 모듈을 지원합니다. 대규모 퍼즈 코퍼스와 적합성 테스트는 virtio 명령 스트림, 페이징, API 레코드 레이아웃을 대상으로 합니다. 이 프로젝트는 격리된 VM 그래픽 랩에서 드라이버 동작을 연구하거나 GPU API 트래픽을 캡처·재생하거나, 안티치트 설계와 관련된 오버레이 및 계층화 장치 상호작용을 분석해야 하는 게임 보안 연구자에게 적합합니다.
