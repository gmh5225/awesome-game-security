Accel-virt 是一套虛擬化圖形加速堆疊，透過擴充的 virtio-gpu 裝置與 QEMU 整合，將訪客 Windows 渲染環境與主機端執行器配對運作。程式碼庫主要為 C 與 C++，使用 CMake 建置，實作了核心模式 DXGI/DXGK 管線以及面向 Direct3D 9/11/12、Vulkan、OpenGL 與 OpenCL 的使用者模式墊片。它支援訪客記憶體借出、工作階段錄製與重播、追蹤與檢查工具，以及針對 Direct3D、OpenGL、Vulkan 與疊層式呈現路徑的專用探測模組。大型模糊測試語料與一致性測試涵蓋 virtio 命令串流、分頁與 API 記錄版面。本專案適合需要隔離虛擬機圖形實驗室的遊戲安全研究人員，用於研究驅動程式行為、擷取與重播 GPU API 流量，或分析與反作弊設計相關的疊層與分層裝置互動。
