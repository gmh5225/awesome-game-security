Accel-virt は仮想化グラフィックス加速スタックで、拡張 virtio-gpu デバイスを QEMU と統合し、ゲスト側の Windows レンダリング環境とホスト側の実行体を組み合わせます。コードベースは主に C と C++ で CMake によりビルドされ、カーネルモードの DXGI/DXGK 配管と、Direct3D 9/11/12、Vulkan、OpenGL、OpenCL 向けのユーザーモードシムを実装しています。ゲスト RAM の貸し出し、セッションの記録と再生、トレースおよび検査ツール、Direct3D・OpenGL・Vulkan およびオーバーレイ型プレゼンテーション経路向けの専用プローブモジュールをサポートします。大規模なファズコーパスと適合性テストは virtio コマンドストリーム、ページング、API レコードレイアウトを対象とします。本プロジェクトは、隔離された VM グラフィックスラボでドライバ挙動を調査したり、GPU API トラフィックをキャプチャ・再生したり、反チート設計に関係するオーバーレイやレイヤードデバイス相互作用を分析したいゲームセキュリティ研究者に適しています。
