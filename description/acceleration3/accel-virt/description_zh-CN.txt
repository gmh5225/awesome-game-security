Accel-virt 是一套虚拟化图形加速栈，通过扩展的 virtio-gpu 设备与 QEMU 集成，将访客 Windows 渲染环境与宿主机侧执行器配对运行。代码库主要为 C 与 C++，使用 CMake 构建，实现了内核模式 DXGI/DXGK 管线以及面向 Direct3D 9/11/12、Vulkan、OpenGL 和 OpenCL 的用户模式垫片。它支持访客内存借出、会话录制与回放、跟踪与检查工具，以及针对 Direct3D、OpenGL、Vulkan 和叠层式呈现路径的专用探测模块。大型模糊测试语料与一致性测试覆盖 virtio 命令流、分页与 API 记录布局。该项目适合需要隔离虚拟机图形实验室的游戏安全研究人员，用于研究驱动行为、捕获与回放 GPU API 流量，或分析与反作弊设计相关的叠层与分层设备交互。
