Accel-virt — виртуализированный стек ускорения графики, который связывает гостевую среду рендеринга Windows с исполнителем на стороне хоста через расширенное устройство virtio-gpu, интегрированное с QEMU. Кодовая база в основном на C и C++, собирается CMake, реализует связку DXGI/DXGK в режиме ядра и пользовательские shims для Direct3D 9/11/12, Vulkan, OpenGL и OpenCL. Поддерживаются одолжение гостевой RAM, запись и воспроизведение сеансов, средства трассировки и инспекции, а также выделенные модули зондирования для Direct3D, OpenGL, Vulkan и путей представления в стиле overlay. Крупные корпуса фаззинга и тесты соответствия нацелены на потоки команд virtio, страничную организацию и раскладки записей API. Проект подходит исследователям безопасности игр, которым нужна изолированная VM-графическая лаборатория для изучения поведения драйверов, захвата и воспроизведения трафика GPU API или анализа взаимодействий overlay и многослойных устройств, важных для проектирования античитов.
