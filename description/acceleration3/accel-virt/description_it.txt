Accel-virt è uno stack di accelerazione grafica virtualizzata che abbina un ambiente di rendering Windows guest a un esecutore lato host tramite un dispositivo virtio-gpu esteso integrato con QEMU. Il codice è principalmente C e C++, costruito con CMake, e implementa il plumbing DXGI/DXGK in kernel mode più shim in user mode per Direct3D 9/11/12, Vulkan, OpenGL e OpenCL. Supporta il prestito di RAM guest, registrazione e replay di sessioni, strumenti di trace e ispezione e moduli probe dedicati per Direct3D, OpenGL, Vulkan e percorsi di presentazione in stile overlay. Ampi corpora di fuzzing e test di conformità mirano a flussi di comandi virtio, paging e layout di record API. Il progetto è adatto a ricercatori di sicurezza dei giochi che necessitano di un laboratorio grafico VM isolato per studiare il comportamento dei driver, catturare e riprodurre il traffico API GPU o analizzare interazioni overlay e dispositivi a strati rilevanti per la progettazione anti-cheat.
