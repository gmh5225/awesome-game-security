Accel-virt es una pila de aceleración gráfica virtualizada que empareja un entorno de renderizado Windows invitado con un ejecutor en el host mediante un dispositivo virtio-gpu extendido integrado con QEMU. La base de código es principalmente C y C++, construida con CMake, e implementa la tubería DXGI/DXGK en modo kernel más shims en modo usuario para Direct3D 9/11/12, Vulkan, OpenGL y OpenCL. Admite préstamo de RAM del invitado, grabación y reproducción de sesiones, herramientas de trazado e inspección, y módulos de sondeo dedicados para Direct3D, OpenGL, Vulkan y rutas de presentación tipo overlay. Grandes corpora de fuzzing y pruebas de conformidad apuntan a flujos de comandos virtio, paginación y diseños de registros de API. El proyecto encaja con investigadores de seguridad en juegos que necesitan un laboratorio gráfico VM aislado para estudiar el comportamiento de controladores, capturar y reproducir tráfico de API GPU, o analizar interacciones de overlay y dispositivos en capas relevantes para el diseño anti-trampas.
