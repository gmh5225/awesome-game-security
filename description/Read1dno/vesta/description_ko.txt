Vesta는 Counter-Strike 2용 기능 완비형 외부 치트로, 게임 프로세스 외부에서 실행되며 코드 주입이나 커널 드라이버 없이 동작합니다. Windows x64용 C++23로 작성되었으며, 프로세스 메모리 API를 통해 실시간 게임 상태를 읽고 DirectX 11 오버레이로 ESP, chams, 메뉴를 렌더링하며 외부 Windows 입력 게이트웨이를 통해 입력을 전송합니다. 에임봇, 트리거봇, 플레이어 및 월드 ESP, 수류탄 예측, 게임 내 레이더, 웹 기반 레이더 같은 확장을 위한 샌드박스화된 Lua 5.4 스크립팅 API를 포함합니다. 코드베이스는 전투 및 시각화 기능을 뒷받침하는 탄도, 관통, 충돌 시뮬레이션도 구현합니다. 외부 치트 아키텍처, 안티치트 회피 기법, CS2 클라이언트 상태 재구성을 연구하는 게임 보안 연구자를 대상으로 합니다.
