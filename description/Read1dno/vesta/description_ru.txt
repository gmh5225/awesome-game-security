Vesta — это полнофункциональный внешний чит для Counter-Strike 2, работающий вне игрового процесса без инъекции кода или драйверов ядра. Написан на C++23 для Windows x64, читает актуальное состояние игры через API памяти процессов, отрисовывает ESP, chams и меню через оверлей DirectX 11 и отправляет ввод через внешний шлюз ввода Windows. Включает aimbot, triggerbot, ESP игроков и мира, предсказание гранат, внутриигровой радар и песочницу для скриптов Lua 5.4 с API для расширений, таких как веб-радар. Кодовая база также реализует симуляцию баллистики, пробития и столкновений, лежащую в основе боевых и визуальных функций. Предназначен для исследователей безопасности игр, изучающих архитектуры внешних читов, методы обхода античита и реконструкцию клиентского состояния CS2.
