Vesta 是一款功能完整的 Counter-Strike 2 外部作弊工具，在游戏进程外运行，无需代码注入或内核驱动。它使用 C++23 编写，面向 Windows x64，通过进程内存 API 读取实时游戏状态，借助 DirectX 11 叠加层渲染 ESP、chams 和菜单，并通过外部 Windows 输入网关发送输入。功能包括自瞄、扳机、玩家与世界 ESP、手雷预测、游戏内雷达，以及用于扩展（如基于 Web 的雷达）的沙盒化 Lua 5.4 脚本 API。代码库还实现了弹道、穿透与碰撞模拟，支撑其战斗与可视化功能。该项目面向研究外部作弊架构、反作弊规避技术以及 CS2 客户端状态重建的游戏安全研究人员。
