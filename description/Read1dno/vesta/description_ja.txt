Vesta は Counter-Strike 2 向けの機能完備型外部チートで、ゲームプロセス外で動作し、コード注入やカーネルドライバーを必要としません。Windows x64 向けに C++23 で書かれ、プロセスメモリ API 経由でライブなゲーム状態を読み取り、DirectX 11 オーバーレイで ESP、chams、メニューを描画し、外部 Windows 入力ゲートウェイを通じて入力を送信します。aimbot、triggerbot、プレイヤーおよびワールド ESP、グレネード予測、ゲーム内レーダー、Web ベースのレーダーなどの拡張向けサンドボックス化 Lua 5.4 スクリプティング API を備えています。コードベースは弾道、貫通、衝突シミュレーションも実装し、戦闘および可視化機能を支えています。外部チートアーキテクチャ、Anti-Cheat 回避手法、CS2 クライアント状態の再構築を研究するゲームセキュリティ研究者向けです。
