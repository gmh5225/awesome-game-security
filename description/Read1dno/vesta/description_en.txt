Vesta is a feature-complete external cheat for Counter-Strike 2 that runs outside the game process without code injection or kernel drivers. Written in C++23 for Windows x64, it reads live game state through process memory APIs, renders ESP, chams, and menus via a DirectX 11 overlay, and sends input through the external Windows input gateway. It includes aimbot, triggerbot, player and world ESP, grenade prediction, in-game radar, and a sandboxed Lua 5.4 scripting API for extensions such as web-based radar. The codebase also implements ballistics, penetration, and collision simulation that underpin its combat and visualization features. It is aimed at game security researchers studying external cheat architectures, anti-cheat evasion techniques, and CS2 client state reconstruction.
