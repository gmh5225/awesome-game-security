Vesta 是一款功能完整的 Counter-Strike 2 外部作弊工具，在遊戲程序外執行，無需程式碼注入或核心驅動程式。它以 C++23 撰寫，面向 Windows x64，透過程序記憶體 API 讀取即時遊戲狀態，並以 DirectX 11 覆蓋層渲染 ESP、chams 與選單，再經由外部 Windows 輸入閘道傳送輸入。功能包含自瞄、扳機、玩家與世界 ESP、手榴彈預測、遊戲內雷達，以及用於擴充（如基於 Web 的雷達）的沙箱化 Lua 5.4 腳本 API。程式碼庫亦實作彈道、穿透與碰撞模擬，支撐其戰鬥與視覺化功能。本專案面向研究外部作弊架構、反作弊規避技術以及 CS2 用戶端狀態重建的遊戲安全研究人員。
