Jidr는 root된 Android 가상 기기를 실행하고 제어하는 오픈 소스 데스크톱 플랫폼으로, Genymotion의 클린룸 대안으로 자리 잡고 있습니다. 주로 Rust로 구현되며, gRPC·telnet 콘솔·ADB로 AOSP 에뮬레이터를 구동하는 데몬이고 Slint GUI, CLI, MCP 서버는 경량 JSON-RPC 클라이언트입니다. adb 또는 Magisk ramdisk 패치를 통한 원클릭 root, 빌드 속성 스푸핑, 스냅샷, GPS·센서·네트워크·미디어 캡처·개발자 도구용 풍부한 디바이스 위젯 등 내장 프로바이더를 제공합니다. Android SDK 캐시와 AVD 수명 주기를 자체 관리하며 기존 Android Studio 설치는 읽기 전용으로 취급합니다. 재현 가능하고 완전히 root된 에뮬레이터가 필요한 앱 테스트, 계측, Android 중심 리버스 엔지니어링 워크플로에 적합한 모바일 개발자와 보안 연구자를 위한 프로젝트입니다.
