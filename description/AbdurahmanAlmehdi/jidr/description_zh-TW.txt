Jidr 是一款開源桌面平台，用於執行與控制已 root 的 Android 虛擬裝置，定位為 Genymotion 的潔淨室替代方案。它主要以 Rust 實作，以守護程式透過 gRPC、telnet 主控台與 ADB 驅動 AOSP 模擬器，Slint GUI、CLI 與 MCP 伺服器則為輕量 JSON-RPC 用戶端。內建功能涵蓋透過 adb 或 Magisk ramdisk 修補一鍵 root、建置屬性偽裝、快照，以及 GPS、感測器、網路、媒體擷取與開發者工具等豐富裝置元件。它自行管理 Android SDK 快取與 AVD 生命週期，並將既有 Android Studio 安裝視為唯讀。本專案適合需要可重現、完全 root 模擬器以進行應用測試、插樁與 Android 逆向工程工作流程的行動開發者與安全研究人員。
