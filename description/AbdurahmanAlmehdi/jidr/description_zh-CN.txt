Jidr 是一款开源桌面平台，用于运行和控制已 root 的 Android 虚拟设备，定位为 Genymotion 的洁净室替代方案。它主要用 Rust 实现，以守护进程形式通过 gRPC、telnet 控制台和 ADB 驱动 AOSP 模拟器，Slint GUI、CLI 与 MCP 服务器作为轻量 JSON-RPC 客户端。内置能力包括通过 adb 或 Magisk ramdisk 补丁一键 root、构建属性伪装、快照，以及 GPS、传感器、网络、媒体采集与开发者工具等丰富设备控件。它自行管理 Android SDK 缓存与 AVD 生命周期，并将现有 Android Studio 安装视为只读。该项目适合需要可复现、完全 root 模拟器进行应用测试、插桩与 Android 逆向工程工作流的移动开发者与安全研究人员。
