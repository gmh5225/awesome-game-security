Jidr is an open-source desktop platform for running and controlling rooted Android virtual devices, positioned as a clean-room alternative to Genymotion. It is implemented primarily in Rust as a daemon that drives the AOSP emulator over gRPC, the telnet console, and ADB, with a Slint GUI, CLI, and MCP server as thin JSON-RPC clients. Built-in providers cover one-click root via adb or Magisk ramdisk patching, build-property spoofing, snapshots, and rich device widgets for GPS, sensors, network, media capture, and developer tooling. It manages its own Android SDK cache and AVD lifecycle while treating an existing Android Studio install as read-only. The project suits mobile developers and security researchers who need reproducible, fully rooted emulators for app testing, instrumentation, and Android-focused reverse engineering workflows.
