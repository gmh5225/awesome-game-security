Jidr は、root 済み Android 仮想デバイスの実行と制御のためのオープンソースのデスクトッププラットフォームで、Genymotion のクリーンルーム代替として位置づけられています。主に Rust で実装され、gRPC、telnet コンソール、ADB 経由で AOSP エミュレータを駆動するデーモンとして動作し、Slint GUI、CLI、MCP サーバーは薄い JSON-RPC クライアントです。adb や Magisk ramdisk パッチによるワンクリック root、ビルドプロパティの偽装、スナップショット、GPS・センサー・ネットワーク・メディアキャプチャ・開発者ツール向けの豊富なデバイスウィジェットなどの組み込みプロバイダーを備えます。Android SDK キャッシュと AVD のライフサイクルを自前で管理し、既存の Android Studio インストールは読み取り専用として扱います。再現可能で完全 root 化されたエミュレータが必要なアプリテスト、計装、Android 向けリバースエンジニアリングワークフロー向けに、モバイル開発者とセキュリティ研究者に適したプロジェクトです。
