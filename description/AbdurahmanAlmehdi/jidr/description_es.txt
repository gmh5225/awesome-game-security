Jidr es una plataforma de escritorio de código abierto para ejecutar y controlar dispositivos virtuales Android con root, planteada como alternativa de sala limpia a Genymotion. Está implementada principalmente en Rust como un daemon que controla el emulador AOSP mediante gRPC, la consola telnet y ADB, con una GUI Slint, CLI y servidor MCP como clientes JSON-RPC ligeros. Los proveedores integrados cubren root con un clic vía adb o parcheo de ramdisk Magisk, suplantación de propiedades de build, instantáneas y widgets ricos para GPS, sensores, red, captura de medios y herramientas de desarrollo. Gestiona su propia caché del SDK de Android y el ciclo de vida de AVD mientras trata una instalación existente de Android Studio como solo lectura. El proyecto encaja con desarrolladores móviles e investigadores de seguridad que necesitan emuladores reproducibles y completamente rootados para pruebas de apps, instrumentación y flujos de ingeniería inversa centrados en Android.
