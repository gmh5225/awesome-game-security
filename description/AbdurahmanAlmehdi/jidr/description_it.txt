Jidr è una piattaforma desktop open source per eseguire e controllare dispositivi virtuali Android con root, proposta come alternativa clean room a Genymotion. È implementata principalmente in Rust come daemon che guida l’emulatore AOSP tramite gRPC, console telnet e ADB, con GUI Slint, CLI e server MCP come client JSON-RPC leggeri. I provider integrati coprono root con un clic via adb o patch del ramdisk Magisk, spoofing delle proprietà di build, snapshot e widget ricchi per GPS, sensori, rete, acquisizione media e strumenti per sviluppatori. Gestisce la propria cache dell’SDK Android e il ciclo di vita degli AVD trattando un’installazione esistente di Android Studio come sola lettura. Il progetto è adatto a sviluppatori mobile e ricercatori di sicurezza che necessitano di emulatori riproducibili e completamente rootati per test delle app, strumentazione e workflow di reverse engineering orientati ad Android.
