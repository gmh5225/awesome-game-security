Jidr — это настольная платформа с открытым исходным кодом для запуска и управления виртуальными устройствами Android с root-доступом, позиционируемая как «чистая» альтернатива Genymotion. В основном реализована на Rust в виде демона, управляющего эмулятором AOSP через gRPC, telnet-консоль и ADB; GUI на Slint, CLI и MCP-сервер выступают лёгкими JSON-RPC-клиентами. Встроенные провайдеры включают root в один клик через adb или патч ramdisk Magisk, подмену build-свойств, снимки состояния и богатые виджеты устройства для GPS, датчиков, сети, захвата медиа и инструментов разработчика. Платформа самостоятельно управляет кэшем Android SDK и жизненным циклом AVD, а существующую установку Android Studio использует только для чтения. Проект подходит мобильным разработчикам и исследователям безопасности, которым нужны воспроизводимые полностью root-эмуляторы для тестирования приложений, инструментирования и рабочих процессов reverse engineering под Android.
