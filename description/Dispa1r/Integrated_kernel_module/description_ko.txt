Integrated Kernel Module은 커스텀 커널 드라이버와 Zygisk 인젝션 모듈을 결합한 게임 리버스 엔지니어링용 Android ARM64 툴킷입니다. lsdriver 커널 모듈은 PTE 리매핑을 통한 프로세스 메모리 읽기/쓰기, 하드웨어 및 PTE 브레이크포인트, 싱글스텝 디버깅, 시스템 콜 모니터링, 그리고 가상 터치·자이로스코프·GNSS 인젝션을 제공합니다. W^X Shadow Hook(wxshadow)을 통합하여 섀도 페이지 테이블을 사용하므로 무결성 검사는 원본 코드를 보고, 실행은 수정된 섀도 페이지에서 이루어집니다. rfrida_zygisk 컴포넌트는 커스텀 ELF 링커와 익명 mmap으로 Frida 호환 에이전트를 로드하여 ptrace 및 dlopen 흔적을 피합니다. 유저스페이스 툴링 레이어와 선택적 MCP 서버 래퍼와 함께, 루팅된 Android 게임 리버스 엔지니어링 및 안티치트 연구 워크플로를 대상으로 합니다.
