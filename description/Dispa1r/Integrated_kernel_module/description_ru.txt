Integrated Kernel Module — это инструментарий для Android ARM64, сочетающий пользовательский драйвер ядра и модуль инъекции Zygisk для реверс-инжиниринга игр. Модуль ядра lsdriver обеспечивает чтение/запись памяти процессов через переназначение PTE, аппаратные и PTE-точки останова, пошаговую отладку, мониторинг системных вызовов, а также инъекцию виртуального касания, гироскопа и GNSS. Он интегрирует W^X Shadow Hook (wxshadow), использующий теневые таблицы страниц: проверки целостности видят исходный код, а выполнение идёт на изменённой теневой странице. Компонент rfrida_zygisk загружает Frida-совместимый агент через пользовательский ELF-линкер с анонимным mmap, избегая следов ptrace и dlopen. Вместе со слоем userspace-инструментов и опциональными обёртками MCP-сервера он ориентирован на реверс-инжиниринг рутованных Android-игр и исследование античита.
