Integrated Kernel Module 是一个 Android ARM64 工具包，将自定义内核驱动与 Zygisk 注入模块相结合，用于游戏逆向工程。lsdriver 内核模块通过 PTE 重映射提供进程内存读写、硬件与 PTE 断点、单步调试、系统调用监控，以及虚拟触摸、陀螺仪和 GNSS 注入。它集成了 W^X Shadow Hook（wxshadow），利用影子页表使完整性检查看到原始代码，而执行则运行修改后的影子页。rfrida_zygisk 组件通过自定义 ELF 链接器以匿名 mmap 加载 Frida 兼容代理，从而避免 ptrace 与 dlopen 痕迹。配合用户空间工具层和可选的 MCP 服务器封装，面向已 root 的 Android 游戏逆向与反作弊研究工作流。
