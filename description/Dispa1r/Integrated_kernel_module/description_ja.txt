Integrated Kernel Module は、カスタムカーネルドライバと Zygisk インジェクションモジュールを組み合わせた、ゲームリバースエンジニアリング向けの Android ARM64 ツールキットです。lsdriver カーネルモジュールは、PTE リマッピングによるプロセスメモリの読み書き、ハードウェアおよび PTE ブレークポイント、シングルステップデバッグ、システムコール監視、ならびに仮想タッチ・ジャイロスコープ・GNSS の注入を提供します。W^X Shadow Hook（wxshadow）を統合し、シャドウページテーブルを用いて整合性チェックには元のコードを見せつつ、実行は改変したシャドウページ上で行います。rfrida_zygisk コンポーネントは、カスタム ELF リンカと匿名 mmap により Frida 互換エージェントをロードし、ptrace や dlopen の痕跡を回避します。ユーザスペースのツール層と任意の MCP サーバラッパーと合わせて、root 化された Android ゲームのリバースエンジニアリングおよびアンチチート研究ワークフローを対象とします。
