Integrated Kernel Module 是一套 Android ARM64 工具包，將自訂核心驅動與 Zygisk 注入模組結合，用於遊戲逆向工程。lsdriver 核心模組透過 PTE 重映射提供行程記憶體讀寫、硬體與 PTE 中斷點、單步除錯、系統呼叫監控，以及虛擬觸控、陀螺儀與 GNSS 注入。它整合了 W^X Shadow Hook（wxshadow），利用影子頁表讓完整性檢查看到原始程式碼，而執行則運行修改後的影子頁。rfrida_zygisk 元件透過自訂 ELF 連結器以匿名 mmap 載入 Frida 相容代理，從而避免 ptrace 與 dlopen 痕跡。搭配使用者空間工具層與可選的 MCP 伺服器封裝，面向已 root 的 Android 遊戲逆向與反作弊研究工作流程。
