Integrated Kernel Module è un toolkit Android ARM64 che combina un driver kernel personalizzato con un modulo di iniezione Zygisk per il reverse engineering di giochi. Il modulo kernel lsdriver fornisce lettura/scrittura della memoria di processo tramite remapping PTE, breakpoint hardware e PTE, debug single-step, monitoraggio delle system call e iniezione di tocco virtuale, giroscopio e GNSS. Integra W^X Shadow Hook (wxshadow), che usa tabelle delle pagine shadow affinché i controlli di integrità vedano il codice originale mentre l'esecuzione avviene su una pagina shadow modificata. Il componente rfrida_zygisk carica un agent compatibile con Frida tramite un linker ELF personalizzato con mmap anonimo, evitando tracce di ptrace e dlopen. Insieme a uno strato di tooling in userspace e wrapper opzionali del server MCP, è pensato per flussi di reverse engineering di giochi Android rootati e ricerca anti-cheat.
