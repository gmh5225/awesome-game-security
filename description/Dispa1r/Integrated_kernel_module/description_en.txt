Integrated Kernel Module is an Android ARM64 toolkit that combines a custom kernel driver with a Zygisk injection module for game reverse engineering. The lsdriver kernel module provides process memory read/write via PTE remapping, hardware and PTE breakpoints, single-step debugging, system-call monitoring, and virtual touch, gyroscope, and GNSS injection. It integrates W^X Shadow Hook (wxshadow), which uses shadow page tables so integrity checks see original code while execution runs a modified shadow page. The rfrida_zygisk component loads a Frida-compatible agent through a custom ELF linker with anonymous mmap, avoiding ptrace and dlopen traces. Together with a userspace tooling layer and optional MCP server wrappers, it targets rooted Android game reverse engineering and anti-cheat research workflows.
