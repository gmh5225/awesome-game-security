Integrated Kernel Module es un kit de herramientas Android ARM64 que combina un controlador de kernel personalizado con un módulo de inyección Zygisk para la ingeniería inversa de juegos. El módulo de kernel lsdriver ofrece lectura/escritura de memoria de procesos mediante remapeo PTE, puntos de interrupción de hardware y PTE, depuración paso a paso, supervisión de llamadas al sistema e inyección de toque virtual, giroscopio y GNSS. Integra W^X Shadow Hook (wxshadow), que usa tablas de páginas sombra para que las comprobaciones de integridad vean el código original mientras la ejecución corre en una página sombra modificada. El componente rfrida_zygisk carga un agente compatible con Frida mediante un enlazador ELF personalizado con mmap anónimo, evitando rastros de ptrace y dlopen. Junto con una capa de herramientas en espacio de usuario y wrappers opcionales de servidor MCP, está orientado a flujos de ingeniería inversa de juegos Android con root e investigación anti-trampas.
