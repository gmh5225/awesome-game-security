Integrated Kernel Module est une boîte à outils Android ARM64 qui combine un pilote noyau personnalisé et un module d'injection Zygisk pour la rétro-ingénierie de jeux. Le module noyau lsdriver fournit lecture/écriture mémoire de processus via remappage PTE, points d'arrêt matériels et PTE, débogage pas à pas, surveillance des appels système, ainsi que l'injection de toucher virtuel, gyroscope et GNSS. Il intègre W^X Shadow Hook (wxshadow), qui utilise des tables de pages shadow afin que les contrôles d'intégrité voient le code d'origine tandis que l'exécution s'effectue sur une page shadow modifiée. Le composant rfrida_zygisk charge un agent compatible Frida via un linker ELF personnalisé avec mmap anonyme, évitant les traces de ptrace et dlopen. Avec une couche d'outils en espace utilisateur et des wrappers MCP optionnels, il cible les workflows de rétro-ingénierie de jeux Android rootés et de recherche anti-triche.
