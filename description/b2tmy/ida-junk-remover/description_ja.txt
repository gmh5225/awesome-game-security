IDA Junk Remover は IDA Pro 向けの単一ファイル Python プラグインで、逆アセンブルと Hex-Rays 逆コンパイルを壊すジャンクコード難読化を自動検出・修復します。別命令の途中へのジャンプ、命令の重なり、デッドな自己ジャンプ、定数畳み込み条件分岐、call-pop EIP トリックなどのパターンを認識し、修正適用前にドライランのプレビューも任意で行えます。修復はオンディスクのバイナリをパッチするのではなく、IDB 上で不正なバイト定義を解除して解析を再構築する方式ですが、データベース内の定数条件ジャンプを書き換えるオプションモードもあります。IDA Pro 7.4 から 9.x、x86 コードを対象とし、ライブの IDA セッションなしでも検証できる mock ベースのユニットテストとデモ用サンプルジェネレータを同梱しています。パッカー型のバイトレベル難読化がかかった保護実行ファイルを扱うリバースエンジニアやマルウェア／ゲームセキュリティ分析者向けのツールです。
