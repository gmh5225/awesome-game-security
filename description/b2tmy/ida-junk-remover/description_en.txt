IDA Junk Remover is a single-file Python plugin for IDA Pro that automatically detects and repairs junk-code obfuscation that breaks disassembly and Hex-Rays decompilation. It recognizes patterns such as jumps landing inside another instruction, overlapping instructions, dead self-jumps, constant-folded conditional branches, and call-pop EIP tricks, with optional dry-run preview before applying fixes. Repairs work by undefining bogus bytes and rebuilding analysis in the IDB rather than patching the on-disk binary, though an optional mode can rewrite constant-condition jumps in the database. It targets IDA Pro 7.4 through 9.x on x86 code and includes mock-based unit tests and a demo sample generator for validation without a live IDA session. The tool is aimed at reverse engineers and malware or game-security analysts working through packer-style byte-level obfuscation on protected executables.
