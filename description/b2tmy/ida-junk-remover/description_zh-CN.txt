IDA Junk Remover 是面向 IDA Pro 的单文件 Python 插件，可自动检测并修复破坏反汇编与 Hex-Rays 反编译的 junk-code 混淆。它能识别诸如跳转移入另一条指令内部、指令重叠、无效自跳转、常量折叠条件分支以及 call-pop EIP 技巧等模式，并在应用修复前可选地进行试运行预览。修复方式是在 IDB 中取消错误字节的定义并重建分析，而非修补磁盘上的二进制文件；另有可选模式可在数据库中重写常量条件跳转。该工具面向 IDA Pro 7.4 至 9.x 上的 x86 代码，并包含基于 mock 的单元测试与演示样本生成器，以便在无运行中的 IDA 会话时进行验证。适用于逆向工程师以及处理受保护可执行文件中打包器式字节级混淆的恶意软件或游戏安全分析人员。
