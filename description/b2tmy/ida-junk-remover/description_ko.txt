IDA Junk Remover는 IDA Pro용 단일 파일 Python 플러그인으로, 디스어셈블리와 Hex-Rays 디컴파일을 망가뜨리는 junk-code 난독화를 자동으로 탐지하고 복구합니다. 다른 명령어 안으로 들어가는 점프, 겹치는 명령어, 죽은 자기 점프, 상수 폴딩 조건 분기, call-pop EIP 트릭 같은 패턴을 인식하며, 수정 적용 전 선택적으로 드라이런 미리보기를 제공합니다. 복구는 디스크상 바이너리를 패치하는 대신 IDB에서 잘못된 바이트 정의를 해제하고 분석을 다시 구축하는 방식이며, 데이터베이스에서 상수 조건 점프를 다시 쓰는 선택 모드도 있습니다. IDA Pro 7.4부터 9.x까지 x86 코드를 대상으로 하며, live IDA 세션 없이 검증할 수 있는 mock 기반 단위 테스트와 데모 샘플 생성기를 포함합니다. 보호된 실행 파일의 패커 스타일 바이트 수준 난독화를 다루는 리버스 엔지니어와 멀웨어 또는 게임 보안 분석가를 위한 도구입니다.
