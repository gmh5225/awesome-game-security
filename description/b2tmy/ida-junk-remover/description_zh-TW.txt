IDA Junk Remover 是面向 IDA Pro 的單一檔案 Python 外掛，可自動偵測並修復破壞反組譯與 Hex-Rays 反編譯的 junk-code 混淆。它能辨識諸如跳轉落在另一條指令內部、指令重疊、無效自跳轉、常數摺疊條件分支以及 call-pop EIP 技巧等模式，並可在套用修復前選擇性進行試執行預覽。修復方式是在 IDB 中取消錯誤位元組的定義並重建分析，而非修補磁碟上的二進位檔；另有選用模式可在資料庫中重寫常數條件跳轉。此工具適用於 IDA Pro 7.4 至 9.x 上的 x86 程式碼，並包含以 mock 為基礎的單元測試與示範樣本產生器，以便在沒有執行中的 IDA 工作階段時驗證。主要對象為逆向工程師，以及處理受保護可執行檔中打包器式位元組層混淆的惡意程式或遊戲安全分析人員。
