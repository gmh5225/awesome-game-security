本專案提供文件、一個小型 Python 輔助模組，以及靜態 HTML 頁面，圍繞在受 Faceit 核心層級反作弊保護的環境中針對 Counter-Strike 2 所採用的外部直接記憶體存取（DMA）工作流程；重點在於 PCIe DMA 硬體與獨立輔助機，而非向遊戲行程注入程式碼。README 說明面向 Windows、以 CMake 與 Microsoft 工具鏈建構的發行版本，可選的第二台電腦疊加顯示傳輸，以及 DMA 記憶體讀取、類合成器視覺化、與 ESP 及瞄準相關的模組概念，以及可設定的 PCIe 韌體身分偽裝，並結合面向行為的調參。配套資源包括 SVG 圖檔與 Markdown，說明安裝步驟、硬體預期，以及各類偵測或繞過說法是如何陳述的。本資料主要適用於研究競技反作弊設計、遊戲安全威脅模型，以及硬體輔助外部記憶體存取的研究人員與實務工作者。
