本专案提供文档、一个小型 Python 辅助模块，以及静态 HTML 页面，围绕在受 Faceit 内核级反作弊保护的环境中针对 Counter-Strike 2 所采用的外部直接内存存取（DMA）工作流程；重点在于 PCIe DMA 硬件与独立辅助机，而非向游戏进程注入代码。README 说明面向 Windows、以 CMake 与 Microsoft 工具链构建的发行版，可选的第二台电脑叠加显示传输，以及 DMA 内存读取、类合成器可视化、与 ESP 及瞄准相关的模块概念，以及可配置的 PCIe 固件身份伪装，并结合面向行为的调参。配套资源包括 SVG 图档与 Markdown，说明安装步骤、硬件预期，以及各类侦测或绕过说法是如何陈述的。本资料主要适用于研究竞技反作弊设计、游戏安全威胁模型，以及硬件辅助外部内存访问的研究人员与实务工作者。
