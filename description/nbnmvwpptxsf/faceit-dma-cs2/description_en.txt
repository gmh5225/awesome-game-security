This project presents documentation, a small Python helper module, and a static HTML page around an external direct-memory-access workflow for Counter-Strike 2 in environments protected by Faceit’s kernel anti-cheat, emphasizing PCIe DMA hardware and a separate helper machine instead of injecting into the game process. The README describes a Windows-oriented distribution built with CMake and the Microsoft toolchain, optional secondary-PC overlay transport, and features such as DMA memory reads, compositor-style visualization, ESP- and aim-related module concepts, and configurable PCIe firmware identity spoofing paired with behaviour-oriented tuning. Supporting assets include SVG graphics and Markdown that walk through setup, hardware expectations, and how various detection or bypass claims are framed. The material is primarily relevant to researchers and practitioners studying competitive anti-cheat design, game security threat models, and hardware-assisted external memory access.
