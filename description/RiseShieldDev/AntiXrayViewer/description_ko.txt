AntiXrayViewer는 Minecraft Paper 서버 플러그인으로, 의심스러운 X-ray 치트를 자동으로 감지하고 나중에 검토할 수 있도록 플레이어 활동을 기록합니다. Java 21로 작성되었으며 Gradle로 빌드되며, 다이아몬드와 고대 잔해 등의 광석 채굴 패턴을 모니터링하고, 구성 가능한 임계값 알림을 트리거하며, 약 3분간의 이동, 시선 방향, 블록 파괴 또는 설치 이벤트를 캡처합니다. 서버 관리자는 부드러운 카메라 보간을 사용해 용의자의 1인칭 시점으로 세션을 재생할 수 있으며, 저장된 녹화본을 나열, 보기, 삭제 및 관리하는 전용 명령어도 제공합니다. 이 플러그인은 휴리스틱에만 의존하지 않고 채굴 치트에 대한 증거 기반 조사가 필요한 Minecraft 서버 운영자와 안티치트 워크플로를 대상으로 합니다.
