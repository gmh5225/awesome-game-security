AntiXrayViewer — это плагин для сервера Minecraft Paper, который автоматически обнаруживает подозрительное X-ray-читерство и записывает активность игроков для последующего просмотра. Написан на Java 21 и собран с помощью Gradle, он отслеживает шаблоны добычи руды, такие как алмаз и древние обломки, срабатывает при достижении настраиваемых пороговых значений и записывает примерно три минуты перемещений, направления взгляда, а также событий разрушения или установки блоков. Администраторы сервера могут воспроизводить сессии от первого лица подозреваемого с плавной интерполяцией камеры и использовать специальные команды для просмотра списка, просмотра, удаления и управления сохранёнными записями. Плагин предназначен для операторов серверов Minecraft и рабочих процессов античита, которым нужно расследование читов при добыче на основе доказательств, а не только эвристики.
