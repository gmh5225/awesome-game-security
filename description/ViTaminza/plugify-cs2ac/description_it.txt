Questo progetto è un port Plugify e s2sdk dell’anti-cheat lato server CS2AC per Counter-Strike 2, riscritto dal plugin Metamod:Source originale preservandone il comportamento. Sul game server ispeziona comandi utente, movimento, mira, colpi, cronologia input e impostazioni client, e può segnalare o punire un’ampia gamma di cheat — aimbot, triggerbot, exploit di movimento, cvar non validi e anomalie correlate — con modalità di telemetria specifiche del fork. Il rilevamento combina detour Polyhook sulle routine libserver.so risolte via gamedata per usercmd e dati di movimento, con hook s2sdk per eventi, messaggi di rete, cvar client e accesso allo schema. L’applicazione delle sanzioni integra ban opzionali admin_system, comandi kick configurabili, log JSONL, webhook Discord e localizzazione estesa. È pensato per operatori e amministratori di server dedicati CS2 che vogliono anti-cheat e strumenti di moderazione con autorità lato server, non protezione client o workflow di reverse engineering.
