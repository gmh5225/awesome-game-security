本项目是 Counter-Strike 2 服务端反作弊 CS2AC 的 Plugify 与 s2sdk 移植版，在保留原有行为的前提下自原版 Metamod:Source 插件重写而来。它在游戏服务器上检查用户命令、移动、瞄准、射击、输入历史与客户端设置，并可上报或处罚多种作弊行为，包括自瞄、扳机 bot、移动 exploit、无效 cvar 及相关异常，并支持 fork 特有的遥测模式。检测机制结合 Polyhook 对 gamedata 解析的 libserver.so 例程（usercmd 与移动数据）的 detour，以及 s2sdk 对事件、网络消息、客户端 cvar 与 schema 访问的 hook。处罚执行可选集成 admin_system 封禁、可配置的踢人命令、JSONL 检测日志、Discord webhook 与丰富的本地化。面向希望采用服务端权威反作弊与 moderation 管理工具、而非客户端防护或逆向工程工作流的 CS2 专用服务器运营者与管理员。
