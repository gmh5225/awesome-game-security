This project is a Plugify and s2sdk port of the CS2AC server-side anti-cheat for Counter-Strike 2, rewritten from the original Metamod:Source plugin while preserving its behavior. It inspects user commands, movement, aim, shots, input history, and client settings on the game server and can report or punish a broad set of cheat behaviors including aimbots, triggerbots, movement exploits, invalid cvars, and related anomalies, with additional fork-specific telemetry modes. Detection combines Polyhook detours on gamedata-resolved libserver.so routines for usercmd and movement data with s2sdk hooks for events, net messages, client cvars, and schema access. Enforcement integrates optional admin_system bans, configurable kick commands, JSONL detection logs, Discord webhooks, and extensive localization. It is aimed at CS2 dedicated server operators and admins who want server-authoritative anti-cheat and moderation tooling rather than client-side protection or reverse engineering workflows.
