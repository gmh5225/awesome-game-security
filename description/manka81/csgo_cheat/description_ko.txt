Windows에서 Counter-Strike: Global Offensive 외부 오버레이를 구축하고 게임 프로세스 메모리를 읽고 쓰는 모듈형 C++17 프레임워크입니다. MemoryReader 모듈과 패턴 스캔 및 오프셋 자동 감지(hazedumper 프리셋 포함), 3D 월드-투-스크린 변환, DirectX 11 기반 투명 Dear ImGui 오버레이를 결합하여 ESP 박스, 스켈레톤, 스냅라인, HUD 요소를 렌더링합니다. WriteProcessMemory와 SendInput을 통해 에임 어시스트, 트리거봇, 반동 보정, 버니 홉, 카메라 회전을 구현하며, 설정은 INI 파일에 저장됩니다. 주로 C++로 작성되었으며 메모리 작업을 위한 소규모 Python 헬퍼를 포함하며, 외부 치트 기법과 클라이언트 측 메모리 조작을 연구하는 게임 보안 연구자, 리버스 엔지니어, 안티치트 분석가를 대상으로 합니다.
