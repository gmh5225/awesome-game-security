一个模块化的 C++17 框架，用于在 Windows 上构建 Counter-Strike: Global Offensive 外部覆盖层，读写游戏进程内存。它结合了 MemoryReader 模块（支持特征码扫描与偏移自动检测，包括 hazedumper 预设）、3D 世界坐标到屏幕坐标转换，以及基于 DirectX 11 的透明 Dear ImGui 覆盖层，用于渲染 ESP 方框、骨骼、瞄准线和 HUD 元素。该项目通过 WriteProcessMemory 和 SendInput 实现自瞄、扳机机器人、无后坐力补偿、连跳和视角旋转，配置保存在 INI 文件中。主要使用 C++ 编写，并附带少量用于内存操作的 Python 辅助脚本，面向研究外部作弊技术与客户端内存操作的游戏安全研究人员、逆向工程师和反作弊分析师。
