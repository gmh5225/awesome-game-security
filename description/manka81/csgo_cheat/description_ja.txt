Windows 上で Counter-Strike: Global Offensive の外部オーバーレイを構築し、ゲームプロセスのメモリを読み書きするためのモジュラー C++17 フレームワークです。MemoryReader モジュールにパターンスキャンとオフセット自動検出（hazedumper プリセットを含む）、3D ワールド座標からスクリーン座標への変換、DirectX 11 による透明な Dear ImGui オーバーレイを組み合わせ、ESP ボックス、スケルトン、スナップライン、HUD 要素を描画します。WriteProcessMemory と SendInput によるエイムアシスト、トリガーボット、リコイル補正、バニーホップ、カメラ回転を実装し、設定は INI ファイルに永続化されます。主に C++ で記述され、メモリ操作のための小さな Python ヘルパーを含み、外部チート手法とクライアント側メモリ操作を研究するゲームセキュリティ研究者、リバースエンジニア、アンチチート分析者を対象としています。
