一個模組化的 C++17 框架，用於在 Windows 上建構 Counter-Strike: Global Offensive 外部覆蓋層，讀寫遊戲程序記憶體。它結合了 MemoryReader 模組（支援特徵碼掃描與偏移自動偵測，包括 hazedumper 預設）、3D 世界座標到螢幕座標轉換，以及基於 DirectX 11 的透明 Dear ImGui 覆蓋層，用於渲染 ESP 方框、骨骼、瞄準線和 HUD 元素。該專案透過 WriteProcessMemory 和 SendInput 實現自瞄、扳機機器人、無後座力補償、連跳和視角旋轉，設定儲存在 INI 檔案中。主要使用 C++ 編寫，並附帶少量用於記憶體操作的 Python 輔助腳本，面向研究外部作弊技術與用戶端記憶體操作的遊戲安全研究人員、逆向工程師和反作弊分析師。
