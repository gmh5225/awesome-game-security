This project documents and analyzes the Tencent client-side protection engine known as ANOGS, including how the native anti-abuse library fits into the broader protection stack alongside integrity checks and server-side adjudication. The materials explain detection and self-defense behaviors such as memory map scanning, hook and debugger detection, syscall monitoring, anti-debug and anti-dump techniques, and how violations trigger process termination, fake crashes, or delayed reporting. Documentation mixes Thai and English and references Android native components and runtime signals like JNI bridges, background monitoring threads, and state-machine style checks. The repository also includes C# code related to specific game builds, suggesting supplemental tooling or experiments for inspecting or decrypting ANOGS-related data. It is aimed at researchers and practitioners in game security, anti-cheat analysis, and mobile reverse engineering who need a structured overview of how this class of protection behaves on the client.
