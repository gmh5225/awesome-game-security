Vocem Overlay 是一款 Linux 应用程序，可在游戏自身的 framebuffer 中渲染 Discord 语音频道成员、发言与静音状态以及私信，而非作为独立的 compositor 窗口。它使用 C++ 编写，配有 Qt/QML 设置界面，通过 Vulkan 隐式层和 OpenGL LD_PRELOAD 注入器注入游戏进程，支持 32 位和 64 位游戏；同时独立守护进程通过 localhost RPC 维持 Discord 连接，并通过共享内存发布语音状态。它支持 HDR swapchain、Flatpak 沙盒游戏、常见启动器的自动检测，以及无需重启游戏即可生效的实时配置更新。该设计将网络访问与头像解码移出注入代码，在守护进程中隔离 Discord I/O。它适用于研究反作弊系统所针对的进程内图形 hook 与 overlay 注入技术，但尚未针对商业反作弊进行测试，也不试图隐藏自身。
