Vocem Overlay — это Linux-приложение, которое отображает участников голосовых каналов Discord, статус речи и отключения микрофона, а также личные сообщения внутри собственного framebuffer игры, а не в отдельном окне compositor. Написано на C++ с GUI настроек Qt/QML; внедряется в процессы игр через implicit layer Vulkan и interposer OpenGL LD_PRELOAD, поддерживая как 32-, так и 64-битные игры, в то время как автономный daemon поддерживает подключение к Discord через localhost RPC и публикует голосовое состояние через shared memory. Поддерживаются HDR swapchain, игры в песочнице Flatpak, автоматическое обнаружение через распространённые лаунчеры и обновление конфигурации на лету без перезапуска игры. Архитектура выносит сетевой доступ и декодирование аватаров из внедряемого кода, изолируя Discord I/O в daemon. Полезно для изучения техник in-process graphics hooking и overlay injection, на которые нацелены системы anti-cheat, хотя против коммерческого anti-cheat не тестировалось и не пытается скрываться.
