Vocem Overlay 是一款 Linux 應用程式，可在遊戲自身的 framebuffer 中渲染 Discord 語音頻道成員、發言與靜音狀態以及私訊，而非作為獨立的 compositor 視窗。它以 C++ 撰寫，配有 Qt/QML 設定介面，透過 Vulkan 隱式層和 OpenGL LD_PRELOAD 注入器注入遊戲程序，支援 32 位元與 64 位元遊戲；同時獨立守護程序透過 localhost RPC 維持 Discord 連線，並透過共享記憶體發布語音狀態。它支援 HDR swapchain、Flatpak 沙盒遊戲、常見啟動器的自動偵測，以及無需重新啟動遊戲即可生效的即時設定更新。此設計將網路存取與頭像解碼移出注入程式碼，在守護程序中隔離 Discord I/O。它適用於研究反作弊系統所針對的程序內圖形 hook 與 overlay 注入技術，但尚未針對商業反作弊進行測試，也不試圖隱藏自身。
