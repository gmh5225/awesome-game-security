Vocem Overlay is a Linux application that renders Discord voice channel members, speaking and mute status, and direct messages inside a game's own framebuffer instead of as a separate compositor window. Written in C++ with a Qt/QML settings GUI, it injects into game processes through a Vulkan implicit layer and an OpenGL LD_PRELOAD interposer supporting both 32-bit and 64-bit titles, while a standalone daemon maintains the Discord connection via localhost RPC and publishes voice state through shared memory. It supports HDR swapchains, Flatpak sandboxed games, automatic detection across common launchers, and live configuration updates without restarting the game. The design keeps network access and avatar decoding out of injected code, isolating Discord I/O in the daemon. It is useful for studying in-process graphics hooking and overlay injection techniques that anti-cheat systems target, though it has not been tested against commercial anti-cheat and does not attempt to hide itself.
