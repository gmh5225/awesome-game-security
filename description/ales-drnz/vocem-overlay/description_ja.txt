Vocem Overlay は、Discord のボイスチャンネルメンバー、発話・ミュート状態、ダイレクトメッセージを、別の compositor ウィンドウではなくゲーム自身の framebuffer 内に描画する Linux アプリケーションです。C++ で書かれ、Qt/QML 設定 GUI を備え、Vulkan 暗黙レイヤーと OpenGL LD_PRELOAD インターポーザーを通じてゲームプロセスに注入し、32 ビットおよび 64 ビットタイトルの両方をサポートします。スタンドアロンのデーモンが localhost RPC 経由で Discord 接続を維持し、共有メモリを通じてボイス状態を公開します。HDR swapchain、Flatpak サンドボックス化ゲーム、一般的なランチャーでの自動検出、ゲーム再起動なしのライブ設定更新に対応しています。設計上、ネットワークアクセスとアバターデコードは注入コードから分離され、Discord I/O はデーモン内に隔離されています。アンチチートシステムが標的とするプロセス内グラフィックスフックおよびオーバーレイ注入手法の研究に有用ですが、商用アンチチートに対するテストは行われておらず、自身を隠そうともしません。
