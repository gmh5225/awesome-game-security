GameApiDetector is a Windows desktop utility that scans installed game libraries and reports which graphics APIs each title actually uses at runtime. Written in Rust with an egui interface, it enumerates loaded modules in running game processes to classify Vulkan, DirectX 9 through 12, and OpenGL based on standard system DLLs such as vulkan-1.dll, d3d11.dll, and opengl32.dll. It discovers games from major storefronts including Steam, Epic, GOG, EA, Ubisoft, Battle.net, and Xbox, supports manually added executables, and can detect DXVK by reading version metadata in game-local D3D DLLs with options to install, restore, or launch with Vulkan-related arguments. The tool is aimed at PC gamers and compatibility researchers who need a clear view of rendering stacks and DXVK status, including awareness of risks when altering binaries on titles protected by anti-cheat.
