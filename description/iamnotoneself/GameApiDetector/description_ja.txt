GameApiDetector は、インストール済みのゲームライブラリをスキャンし、各タイトルが実行時に実際に使用しているグラフィックス API を報告する Windows 向けデスクトップユーティリティです。Rust と egui で実装され、実行中のゲームプロセスに読み込まれたモジュールを列挙し、vulkan-1.dll、d3d11.dll、opengl32.dll などの標準システム DLL に基づいて Vulkan、DirectX 9〜12、OpenGL を分類します。Steam、Epic、GOG、EA、Ubisoft、Battle.net、Xbox など主要ストアからゲームを検出し、手動で実行ファイルを追加でき、ゲームローカルの D3D DLL のバージョン メタデータを読み取って DXVK を検出し、インストール・復元・Vulkan 関連引数での起動などのオプションを提供します。レンダリングスタックと DXVK の状態を把握したい PC ゲーマーや互換性調査者向けで、アンチチート保護されたタイトルのバイナリを変更する際のリスクにも言及します。
