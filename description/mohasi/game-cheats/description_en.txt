This project is a large collection of PlayStation 3 game cheat definitions organized as plain text files keyed by official title IDs. It maintains parallel source and compiled trees that cover thousands of retail and PSN releases across North America, Europe, Asia, and Japan, using familiar ID prefixes such as BLUS, BLES, BCES, BCAS, and NPUx variants. The layout is data-centric rather than code-driven, so the cheats can be browsed, diffed, or imported into PS3 homebrew cheat tools and memory patch workflows. It serves modders, custom-firmware users, and reverse engineers who study or apply in-game memory modifications on legacy PS3 titles.
