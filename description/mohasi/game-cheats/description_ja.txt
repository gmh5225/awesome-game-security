本プロジェクトは、PlayStation 3 向けゲームのチート定義を公式タイトル ID で索引付けした大規模なコレクションで、プレーンテキストファイルとして整理されています。北米、欧州、アジア、日本向けの小売版および PSN 配信タイトルを数千本規模でカバーするソースツリーとコンパイル済みツリーを並行して維持し、BLUS、BLES、BCES、BCAS、NPUx 系などおなじみの ID プレフィックスを用いています。レイアウトはコード中心ではなくデータ中心のため、チートの閲覧、差分比較、PS3 ホームブリュー向けチートツールやメモリパッチワークフローへの取り込みが容易です。レガシー PS3 タイトルにおけるゲーム内メモリ改変の研究や適用を行うモッダー、カスタムファームウェア利用者、リバースエンジニア向けのリソースです。
