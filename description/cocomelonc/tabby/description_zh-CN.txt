Tabby 是一个面向 Windows x64 的极简、位置无关 shellcode 微框架，让开发者用 C 而非汇编编写 shellcode，并可在 Linux 上编译成可用于进程注入的平坦 raw 二进制文件。它使用 mingw-w64 和 NASM 生成无 PE 头、导入表或 CRT 的 PIC 二进制，通过 PEB 和以 FNV-1a 哈希为键的导出表遍历在运行时解析 Windows API。该框架实现间接 NT 系统调用，跳转至 ntdll 中的 gadget，使调用栈对具备调用栈感知能力的 EDR 产品显得合法。它作为道德恶意软件开发与进攻性安全培训的教学工具，在大约 500 行可读 C 与汇编代码中展示每种规避技术——基址恢复、基于哈希的 API 解析以及 SSN 提取。
