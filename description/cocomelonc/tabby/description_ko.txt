Tabby는 Windows x64용 최소한의 위치 독립적 shellcode 마이크로 프레임워크로, 개발자가 어셈블리 대신 C로 shellcode를 작성하고 Linux에서 프로세스 주입에 사용할 수 있는 평탄한 raw 바이너리로 컴파일할 수 있게 한다. mingw-w64와 NASM을 사용해 PE 헤더, 임포트 테이블, CRT 없이 PIC 바이너리를 생성하며, PEB와 FNV-1a 해시를 키로 한 export table 순회를 통해 Windows API를 런타임에 해석한다. 이 프레임워크는 간접 NT syscall을 구현해 ntdll gadget으로 점프하여 호출 스택 인식 EDR 제품에 합법적인 호출 스택처럼 보이게 한다. 윤리적 멀웨어 개발 및 공격적 보안 교육을 위한 교학용 도구로 설계되었으며, 베이스 주소 복구, 해시 기반 API 해석, SSN 추출 등 각 회피 기법을 약 500줄의 읽기 쉬운 C와 어셈블리로 드러낸다.
