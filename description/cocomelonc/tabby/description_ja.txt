Tabby は Windows x64 向けの最小限で位置独立な shellcode マイクロフレームワークであり、開発者がアセンブリではなく C で shellcode を記述し、Linux 上でプロセス注入用のフラットな raw バイナリとしてコンパイルできる。mingw-w64 と NASM を用いて PE ヘッダー、インポートテーブル、CRT のない PIC バイナリを生成し、PEB と FNV-1a ハッシュをキーとしたエクスポートテーブル走査により Windows API を実行時に解決する。フレームワークは間接 NT システムコールを実装し、ntdll のガジェットへジャンプすることで、コールスタックを意識する EDR 製品に対して正当なコールスタックに見せる。倫理的なマルウェア開発と攻撃的セキュリティ訓練の教材として設計され、ベースアドレス取得、ハッシュベースの API 解決、SSN 抽出といった各回避手法を、約 500 行の読みやすい C とアセンブリで公開している。
