Tabby is a minimal, position-independent shellcode micro-framework for Windows x64 that lets developers write shellcode in C rather than assembly and compile it on Linux into a flat raw binary ready for process injection. It uses mingw-w64 and NASM to produce PIC binaries with no PE header, import table, or CRT, resolving Windows APIs at runtime through PEB and export table walks keyed by FNV-1a hashes. The framework implements indirect NT syscalls that jump into ntdll gadgets so call stacks appear legitimate to call-stack-aware EDR products. Designed as a teaching tool for ethical malware development and offensive security training, it exposes each evasion technique—base address recovery, hash-based API resolution, and SSN extraction—in roughly 500 lines of readable C and assembly.
