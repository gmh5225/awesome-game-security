Tabby è un microframework shellcode minimale e indipendente dalla posizione per Windows x64 che consente agli sviluppatori di scrivere shellcode in C anziché in assembly e compilarlo su Linux in un binario raw piatto pronto per l'injection di processi. Utilizza mingw-w64 e NASM per produrre binari PIC senza header PE, tabella di importazione o CRT, risolvendo le API Windows a runtime tramite il PEB e percorsi nelle tabelle di export indicizzati da hash FNV-1a. Il framework implementa syscall NT indirette che saltano nei gadget di ntdll così che gli stack di chiamate appaiano legittimi ai prodotti EDR sensibili allo stack di chiamate. Progettato come strumento didattico per lo sviluppo etico di malware e la formazione in sicurezza offensiva, espone ogni tecnica di evasione—recupero dell'indirizzo base, risoluzione API basata su hash ed estrazione SSN—in circa 500 righe di C e assembly leggibili.
