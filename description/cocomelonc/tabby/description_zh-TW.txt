Tabby 是一個面向 Windows x64 的極簡、位置無關 shellcode 微框架，讓開發者以 C 而非組合語言撰寫 shellcode，並可在 Linux 上編譯成可用於行程注入的平坦 raw 二進位檔。它使用 mingw-w64 和 NASM 產生無 PE 標頭、匯入表或 CRT 的 PIC 二進位，透過 PEB 與以 FNV-1a 雜湊為鍵的匯出表遍歷在執行時期解析 Windows API。該框架實作間接 NT 系統呼叫，跳轉至 ntdll 中的 gadget，使呼叫堆疊對具備呼叫堆疊感知能力的 EDR 產品顯得合法。它作為道德惡意軟體開發與攻擊性安全培訓的教學工具，在大約 500 行可讀 C 與組合語言程式碼中展示每種規避技術——基址恢復、基於雜湊的 API 解析以及 SSN 提取。
