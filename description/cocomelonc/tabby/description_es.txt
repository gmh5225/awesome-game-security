Tabby es un microframework shellcode mínimo e independiente de posición para Windows x64 que permite a los desarrolladores escribir shellcode en C en lugar de ensamblador y compilarlo en Linux en un binario raw plano listo para la inyección de procesos. Utiliza mingw-w64 y NASM para producir binarios PIC sin cabecera PE, tabla de importaciones ni CRT, resolviendo las API de Windows en tiempo de ejecución mediante recorridos del PEB y de tablas de exportación indexados por hashes FNV-1a. El framework implementa syscalls NT indirectos que saltan a gadgets de ntdll para que las pilas de llamadas parezcan legítimas ante productos EDR conscientes de la pila de llamadas. Diseñado como herramienta didáctica para el desarrollo ético de malware y la formación en seguridad ofensiva, expone cada técnica de evasión—recuperación de dirección base, resolución de API basada en hashes y extracción de SSN—en unas 500 líneas de C y ensamblador legibles.
