Tabby — это минималистичный, позиционно-независимый микрофреймворк shellcode для Windows x64, позволяющий разработчикам писать shellcode на C, а не на ассемблере, и компилировать его в Linux в плоский raw-бинарник, готовый для инъекции в процесс. Он использует mingw-w64 и NASM для создания PIC-бинарников без PE-заголовка, таблицы импорта и CRT, разрешая Windows API во время выполнения через обход PEB и таблиц экспорта по ключам FNV-1a-хешей. Фреймворк реализует косвенные NT-системные вызовы с переходом в gadget'ы ntdll, чтобы стеки вызовов выглядели легитимно для EDR-продуктов, анализирующих стек вызовов. Разработан как учебный инструмент для этичной разработки malware и обучения offensive security; каждая техника уклонения — восстановление базового адреса, разрешение API по хешам и извлечение SSN — представлена примерно в 500 строках читаемого C и ассемблера.
