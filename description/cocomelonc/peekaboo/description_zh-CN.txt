Peekaboo 是一个模块化框架，用于安全地模拟恶意软件行为，以复现命令与控制通信、持久化和横向移动等威胁场景，且不包含破坏性载荷。它结合了基于 Python 的工具（CLI、TUI、Flask 仪表板和离线 LLM 工作流管道）以及用于注入、加密、持久化和数据外泄的可移植 C/C++ 模块，并可通过 API 哈希和字符串加密自动生成混淆载荷。该仪表板集成了 MITRE ATT&CK 研究、Malpedia 威胁情报、带有 Sigma 规则覆盖的 APT 活动管道、YARA 规则生成以及 VirusTotal 扫描以进行检出验证。它面向安全研究人员、红蓝队成员和检测工程师，用于提供可预测、可复现的威胁样本，以支持操作员培训、紫队演练和防御规则开发。
