Peekaboo 是一個模組化框架，用於安全地模擬惡意軟體行為，以重現命令與控制通訊、持久化與橫向移動等威脅情境，且不包含破壞性載荷。它結合了以 Python 為基礎的工具（CLI、TUI、Flask 儀表板與離線 LLM 工作管線），以及用於注入、加密、持久化與資料外洩的可攜式 C/C++ 模組，並可透過 API 雜湊與字串加密自動產生混淆載荷。儀表板整合了 MITRE ATT&CK 研究、Malpedia 威脅情報、附帶 Sigma 規則涵蓋範圍的 APT 活動管線、YARA 規則產生，以及 VirusTotal 掃描以進行偵測驗證。它面向安全研究人員、紅藍隊成員與偵測工程師，提供可預測、可重現的威脅產物，以支援操作員訓練、紫隊演練與防禦規則開發。
