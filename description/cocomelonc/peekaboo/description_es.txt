Peekaboo es un framework modular para emular de forma segura el comportamiento de malware y reproducir escenarios de amenaza como la comunicación de comando y control, la persistencia y el movimiento lateral, sin cargas útiles destructivas. Combina herramientas basadas en Python (CLI, TUI, panel Flask y pipeline de trabajo LLM offline) con módulos portátiles en C/C++ para inyección, cifrado, persistencia y exfiltración de datos, y puede generar automáticamente cargas ofuscadas mediante hash de API y cifrado de cadenas. El panel integra investigación MITRE ATT&CK, inteligencia de amenazas de Malpedia, un pipeline de campañas APT con cobertura de reglas Sigma, generación de reglas YARA y escaneo con VirusTotal para validar la detección. Está diseñado para investigadores de seguridad, equipos rojo y azul e ingenieros de detección que necesitan artefactos de amenaza predecibles y reproducibles para la formación de operadores, ejercicios purple team y el desarrollo de reglas defensivas.
