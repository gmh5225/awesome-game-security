Peekaboo는 파괴적 페이로드 없이 C2 통신, 지속성, 측면 이동 등 위협 시나리오를 재현하기 위해 악성코드 동작을 안전하게 에뮬레이션하는 모듈형 프레임워크입니다. Python 기반 도구(CLI, TUI, Flask 대시보드, 오프라인 LLM 워커 파이프라인)와 주입, 암호화, 지속성, 데이터 유출을 위한 휴대용 C/C++ 모듈을 결합하며, API 해싱과 문자열 암호화를 사용해 난독화된 페이로드를 자동 생성할 수 있습니다. 대시보드는 MITRE ATT&CK 연구, Malpedia 위협 인텔리전스, Sigma 규칙 적용 범위를 갖춘 APT 캠페인 파이프라인, YARA 규칙 생성, 탐지 검증을 위한 VirusTotal 스캔을 통합합니다. 보안 연구원, 레드·블루 팀, 탐지 엔지니어를 위해 설계되었으며, 운영자 교육, 퍼플 팀 연습, 방어 규칙 개발을 위해 예측 가능하고 재현 가능한 위협 아티팩트를 제공합니다.
