Peekaboo — это модульный фреймворк для безопасной эмуляции поведения вредоносного ПО с целью воспроизведения сценариев угроз, таких как связь с центром управления, закрепление в системе и горизонтальное перемещение, без разрушительных полезных нагрузок. Он сочетает инструменты на Python (CLI, TUI, панель Flask и офлайн-пайплайн LLM-воркеров) с переносимыми модулями на C/C++ для инъекции, шифрования, закрепления и эксфилтрации данных, а также может автоматически генерировать обфусцированные полезные нагрузки с помощью хеширования API и шифрования строк. Панель интегрирует исследования MITRE ATT&CK, разведданные Malpedia, пайплайн APT-кампаний с покрытием правил Sigma, генерацию правил YARA и сканирование VirusTotal для проверки обнаружения. Он предназначен для исследователей безопасности, участников red и blue team, а также инженеров по обнаружению, которым нужны предсказуемые и воспроизводимые артефакты угроз для обучения операторов, purple-team-упражнений и разработки защитных правил.
