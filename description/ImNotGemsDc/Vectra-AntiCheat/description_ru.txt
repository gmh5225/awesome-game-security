Vectra — серверный античит-плагин для Minecraft, который отслеживает поведение игроков и сетевой трафик, чтобы выявлять распространённые клиентские моды и взломанные клиенты. Написан на Java и собирается Maven для API Paper (Java 21), сочетая слушатели событий Bukkit с перехватом пакетов на основе PacketEvents для движения, боя и проверки протокола. Плагин реализует широкий набор проверок: полёт и эксплойты движения, kill aura и reach, scaffold и читы взаимодействия с блоками, timer и blink, автокликер, злоупотребление инвентарём и различные схемы подмены пакетов, используя трассировку лучей, ограничивающие параллелепипеды и отслеживание состояния по игрокам с порогами с учётом пинга. Персонал получает внутриигровые оповещения о нарушениях с убывающим счётчиком уровня нарушений, повторных нарушителей можно автоматически кикать, а операторы могут включать и отключать оповещения и выдавать права обхода. Он предназначен для администраторов серверов Minecraft и специалистов по безопасности игр, которым нужен лёгкий и прозрачный античит для survival- или PvP-серверов, совместимых с Paper.
