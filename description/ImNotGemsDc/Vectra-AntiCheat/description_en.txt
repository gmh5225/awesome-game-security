Vectra is a server-side anti-cheat plugin for Minecraft that monitors player behavior and network traffic to detect common client mods and hacked clients. It is written in Java and built with Maven for the Paper API (Java 21), combining Bukkit event listeners with PacketEvents-based packet hooks for movement, combat, and protocol validation. The plugin implements a broad set of checks including fly and movement exploits, kill aura and reach, scaffold and block interaction cheats, timer and blink, autoclicker, inventory abuse, and various packet-spoofing patterns, using ray tracing, bounding boxes, and per-player state tracking with ping-aware thresholds. Staff receive in-game violation alerts with a decaying violation-level counter, and repeat offenders can be kicked automatically, while operators can toggle alerts and grant bypass permissions. It is aimed at Minecraft server administrators and game-security practitioners who want a lightweight, inspectable anti-cheat for Paper-compatible survival or PvP servers.
