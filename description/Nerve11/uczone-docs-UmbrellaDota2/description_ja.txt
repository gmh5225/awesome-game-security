本プロジェクトは、Umbrella Dota 2 スクリプトプラットフォームで使われる UCZONE API v2.0 のドキュメントを集約し、オフラインで参照できる単一の資料にまとめます。Python ユーティリティが厳選した GitBook の Markdown ページ一覧をクロールし、目次付きの構造化ドキュメントに統合して、検索や LLM による読解を容易にします。内容は Lua ベースのチート API を扱い、スクリプトコールバック、メニューと UI ウィジェット、ゲームエンティティとエンジンアクセサ、レンダリングと Panorama フック、HTTP・Steam・protobuf などのネットワーク補助機能を含みます。第三者の Dota 2 自動化・オーバーレイツールがゲーム内状態やクライアントシステムとどう連携するかを、携帯可能で検索しやすい形で知りたい開発者やセキュリティ研究者向けです。
