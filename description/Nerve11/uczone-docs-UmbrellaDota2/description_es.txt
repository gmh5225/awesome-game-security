Este proyecto recopila y consolida la documentación de la API UCZONE v2.0 utilizada por la plataforma de scripts Umbrella para Dota 2 en una única referencia sin conexión. Una utilidad en Python recorre una lista seleccionada de páginas Markdown de GitBook y las fusiona en un documento estructurado con tabla de contenidos para facilitar la búsqueda y la lectura asistida por LLM. El material documenta la API de trampas basada en Lua, incluidos callbacks de script, widgets de menú e interfaz, accesores de entidades de juego y del motor, hooks de renderizado y Panorama, y ayudas de red como HTTP, Steam y protobuf. Está dirigido a desarrolladores e investigadores de seguridad que necesitan una guía portátil y consultable sobre cómo las herramientas de automatización y superposición de Dota 2 de terceros interactúan con el estado en el juego y los sistemas del cliente.
