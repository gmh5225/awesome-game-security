This project collects and consolidates the UCZONE API v2.0 documentation used by the Umbrella Dota 2 scripting platform into a single offline reference. A Python utility crawls a curated list of GitBook Markdown pages and merges them into one structured document with a table of contents for easier search and LLM-assisted reading. The material documents the Lua-based cheat API, including script callbacks, menu and UI widgets, game entity and engine accessors, rendering and Panorama hooks, and networking helpers such as HTTP, Steam, and protobuf. It is aimed at developers and security researchers who need a portable, searchable guide to how third-party Dota 2 automation and overlay tools interact with in-game state and client systems.
