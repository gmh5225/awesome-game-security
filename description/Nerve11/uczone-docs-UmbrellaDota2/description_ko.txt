이 프로젝트는 Umbrella Dota 2 스크립팅 플랫폼에서 사용하는 UCZONE API v2.0 문서를 모아 오프라인으로 참조할 수 있는 단일 자료로 통합합니다. Python 유틸리티가 선별된 GitBook Markdown 페이지 목록을 크롤링하여 목차가 있는 구조화된 문서로 병합하므로 검색과 LLM 보조 읽기가 쉽습니다. 자료는 Lua 기반 치트 API를 다루며, 스크립트 콜백, 메뉴 및 UI 위젯, 게임 엔티티와 엔진 접근자, 렌더링 및 Panorama 훅, HTTP·Steam·protobuf 같은 네트워킹 헬퍼를 포함합니다. 서드파티 Dota 2 자동화 및 오버레이 도구가 인게임 상태와 클라이언트 시스템과 어떻게 상호작용하는지를 휴대 가능하고 검색 가능한 가이드로 필요로 하는 개발자와 보안 연구자를 대상으로 합니다.
