Этот проект собирает и объединяет документацию UCZONE API v2.0, используемую платформой скриптов Umbrella для Dota 2, в единый офлайн-справочник. Утилита на Python обходит подобранный список страниц Markdown в GitBook и сливает их в один структурированный документ с оглавлением для удобного поиска и чтения с помощью LLM. Материал описывает Lua-ориентированный cheat API: колбэки скриптов, виджеты меню и UI, доступ к игровым сущностям и движку, хуки рендеринга и Panorama, а также сетевые вспомогательные средства вроде HTTP, Steam и protobuf. Ориентирован на разработчиков и исследователей безопасности, которым нужно портативное, с поиском руководство о том, как сторонние средства автоматизации и оверлеев Dota 2 взаимодействуют с игровым состоянием и клиентскими системами.
