pfnwatch is a Windows proof-of-concept that detects unauthorized kernel-mode reads of a protected process by scanning page table entries for physical page frames owned by that process. It consists of a kernel driver and a C++ user-mode console client that communicate over IOCTLs to build a PFN bitmap from the target's page tables, periodically scan kernel page tables for matching PTEs, and report kernel virtual addresses, PTE flags, and resolved target addresses. The technique targets remote memory access paths that must create a PTE mapping, including MmCopyMemory, MmMapIoSpace and MmMapIoSpaceEx, and direct PTE manipulation, while filtering prototype and inactive pages to reduce false positives. Written in C++ for x64 with Visual Studio, it is aimed at game security and anti-cheat researchers exploring kernel-level cheat detection that is harder to evade than PFN reference count or pool tag monitoring.
