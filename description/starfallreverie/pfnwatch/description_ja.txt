pfnwatch は、保護されたプロセスが所有する物理ページフレームについてページテーブルエントリをスキャンし、そのプロセスに対する不正なカーネルモード読み取りを検出する Windows 概念実証です。カーネルドライバと C++ ユーザーモードコンソールクライアントで構成され、IOCTL 経由で通信し、対象のページテーブルから PFN ビットマップを構築し、カーネルページテーブルを定期的にスキャンして一致する PTE を検出し、カーネル仮想アドレス、PTE フラグ、解決済みの対象アドレスを報告します。この手法は PTE マッピングを作成する必要があるリモートメモリアクセス経路を対象とし、MmCopyMemory、MmMapIoSpace および MmMapIoSpaceEx、直接 PTE 操作を含み、プロトタイプページと非アクティブページをフィルタリングして誤検知を減らします。C++ で x64 向けに Visual Studio を用いて記述され、PFN 参照カウントやプールタグ監視より回避が困難なカーネルレベルのチート検出を探求するゲームセキュリティおよびアンチチート研究者向けです。
