pfnwatch 是一個 Windows 概念驗證專案，透過掃描頁表項目中屬於受保護程序的實體頁框，偵測對該程序的未授權核心模式讀取。它由核心驅動程式與 C++ 使用者模式主控台用戶端組成，兩者透過 IOCTL 通訊，從目標程序的頁表建立 PFN 位元圖，定期掃描核心頁表以尋找相符的 PTE，並回報核心虛擬位址、PTE 旗標以及解析後的目標位址。此技術針對必須建立 PTE 對應的遠端記憶體存取路徑，包括 MmCopyMemory、MmMapIoSpace 與 MmMapIoSpaceEx，以及直接 PTE 操作，同時過濾原型頁與非作用中頁面以減少誤判。專案以 C++ 針對 x64 平台撰寫，使用 Visual Studio 建置，面向遊戲安全與反作弊研究人員，探索比 PFN 參考計數或集區標籤監控更難規避的核心層級作弊偵測方法。
