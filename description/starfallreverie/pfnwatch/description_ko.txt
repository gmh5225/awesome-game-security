pfnwatch는 보호된 프로세스가 소유한 물리 페이지 프레임에 대한 페이지 테이블 항목을 스캔하여 해당 프로세스에 대한 무단 커널 모드 읽기를 감지하는 Windows 개념 증명입니다. 커널 드라이버와 C++ 사용자 모드 콘솔 클라이언트로 구성되며, IOCTL을 통해 통신하여 대상의 페이지 테이블에서 PFN 비트맵을 구축하고, 커널 페이지 테이블을 주기적으로 스캔하여 일치하는 PTE를 찾으며, 커널 가상 주소, PTE 플래그 및 해석된 대상 주소를 보고합니다. 이 기법은 PTE 매핑을 생성해야 하는 원격 메모리 접근 경로를 대상으로 하며, MmCopyMemory, MmMapIoSpace 및 MmMapIoSpaceEx, 직접 PTE 조작을 포함하고, 프로토타입 및 비활성 페이지를 필터링하여 오탐을 줄입니다. C++로 x64용 Visual Studio 환경에서 작성되었으며, PFN 참조 카운트나 풀 태그 모니터링보다 회피하기 어려운 커널 수준 치트 감지를 탐구하는 게임 보안 및 안티치트 연구자를 대상으로 합니다.
