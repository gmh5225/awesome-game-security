pfnwatch es una prueba de concepto para Windows que detecta lecturas no autorizadas en modo kernel de un proceso protegido escaneando entradas de tabla de páginas en busca de marcos de página física pertenecientes a ese proceso. Consta de un controlador de kernel y un cliente de consola en modo usuario en C++ que se comunican mediante IOCTLs para construir un mapa de bits PFN a partir de las tablas de páginas del objetivo, escanear periódicamente las tablas de páginas del kernel en busca de PTE coincidentes, e informar direcciones virtuales del kernel, indicadores PTE y direcciones de destino resueltas. La técnica se dirige a rutas de acceso remoto a memoria que deben crear un mapeo PTE, incluidos MmCopyMemory, MmMapIoSpace y MmMapIoSpaceEx, y la manipulación directa de PTE, filtrando páginas prototipo e inactivas para reducir falsos positivos. Escrito en C++ para x64 con Visual Studio, está dirigido a investigadores de seguridad en juegos y anti-cheat que exploran la detección de trampas a nivel kernel más difícil de evadir que el monitoreo del recuento de referencias PFN o las etiquetas de pool.
