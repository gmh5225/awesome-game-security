pfnwatch 是一个 Windows 概念验证项目，通过扫描页表项中属于受保护进程的物理页帧，检测对该进程的未授权内核模式读取。它由内核驱动和 C++ 用户态控制台客户端组成，二者通过 IOCTL 通信，从目标进程的页表构建 PFN 位图，定期扫描内核页表以查找匹配的 PTE，并报告内核虚拟地址、PTE 标志以及解析后的目标地址。该技术针对必须创建 PTE 映射的远程内存访问路径，包括 MmCopyMemory、MmMapIoSpace 和 MmMapIoSpaceEx，以及直接 PTE 操作，同时过滤原型页和非活动页以减少误报。项目使用 C++ 针对 x64 平台编写，基于 Visual Studio 构建，面向游戏安全与反作弊研究人员，探索比 PFN 引用计数或池标签监控更难规避的内核级作弊检测方法。
