pfnwatch — это proof-of-concept для Windows, который обнаруживает несанкционированное чтение защищённого процесса в режиме ядра путём сканирования записей таблицы страниц на предмет физических фреймов страниц, принадлежащих этому процессу. Он состоит из драйвера ядра и консольного клиента пользовательского режима на C++, которые взаимодействуют через IOCTL для построения битовой карты PFN из таблиц страниц цели, периодического сканирования таблиц страниц ядра на совпадающие PTE и сообщения виртуальных адресов ядра, флагов PTE и разрешённых целевых адресов. Техника нацелена на пути удалённого доступа к памяти, которые должны создавать отображение PTE, включая MmCopyMemory, MmMapIoSpace и MmMapIoSpaceEx, а также прямую манипуляцию PTE, при этом фильтруя прототипные и неактивные страницы для снижения ложных срабатываний. Написан на C++ для x64 с использованием Visual Studio и предназначен для исследователей игровой безопасности и античита, изучающих обнаружение читов на уровне ядра, которое сложнее обойти, чем мониторинг счётчика ссылок PFN или pool tag.
