Apk Signature Verification Patch は、Android 向けの root 用フラッシュ可能モジュールで、システムレベルの APK 署名検証を無効化し、改変または再署名したアプリを別のバイパスツールなしでインストールできるようにします。インストール時に、端末上で APKEditor ベースのオンデバイス処理により framework.jar、services.jar、必要に応じて miui-services.jar を書き換え、指定した sdcard フォルダに置いたカスタム JAR ファイルのオプションのパッチにも対応します。Magisk、KernelSU、APatch を対象とし、Android 13 以降（Android 16 および ColorOS ROM を含む）で動作し、完全オフラインで小さなフットプリントで動くよう設計されています。パッチ済みアプリのサイドロードや、フレームワーク層でのパッケージ整合性の強制について調べる必要があるモッダー、リバースエンジニア、セキュリティ研究者向けのモジュールです。
