Apk Signature Verification Patch 是一款适用于 Android 的可刷写 root 模块，用于在系统层禁用 APK 签名校验，使修改或重签名的应用可在不借助额外绕过工具的情况下安装。安装时它在设备上通过基于 APKEditor 的本地流程重写 framework.jar、services.jar，并可选择处理 miui-services.jar；也可对置于指定 sdcard 目录下的自定义 JAR 进行可选补丁。面向 Magisk、KernelSU 与 APatch，支持 Android 13 及更新版本（含 Android 16 与 ColorOS ROM），设计为完全离线运行且占用资源小。该模块面向需要侧载已补丁应用或研究 Android 在框架层如何强制执行包完整性的模组作者、逆向工程师与安全研究人员。
