Apk Signature Verification Patch 是一款適用於 Android 的可刷寫 root 模組，用於在系統層停用 APK 簽章驗證，使修改或重新簽名的應用程式可在不借助額外繞過工具的情況下安裝。安裝時它在裝置上透過以 APKEditor 為基礎的本機流程改寫 framework.jar、services.jar，並可選擇處理 miui-services.jar；也可對置於指定 sdcard 資料夾下的自訂 JAR 進行可選修補。目標為 Magisk、KernelSU 與 APatch，支援 Android 13 及更新版本（含 Android 16 與 ColorOS ROM），設計為完全離線運作且佔用資源小。此模組面向需要側載已修補應用或研究 Android 在框架層如何強制執行套件完整性的模組作者、逆向工程師與安全研究人員。
