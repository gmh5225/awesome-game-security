Secure Boot & TPM 2.0 Check — утилита Windows только для чтения, которая сообщает, соответствует ли ПК настройкам прошивки и безопасности, которые многие античиты на уровне ядра требуют перед запуском игр. Реализована на PowerShell с необязательным графическим интерфейсом WPF (XAML) и простым пакетным launcher; проверяет режим загрузки UEFI и legacy, разметку диска GPT и MBR, состояние Secure Boot и ключей, готовность TPM 2.0 и статус ключа восстановления BitLocker без изменения BIOS, дисков или TPM. При сбое объясняет вероятную причину и даёт упорядоченные, готовые к копированию инструкции по исправлению с учётом обнаруженной марки ПК или материнской платы, включая случаи, когда оборудование принципиально не поддерживает Secure Boot или TPM. Предназначена для геймеров и специалистов поддержки, устраняющих проблемы на ПК с Windows 10 и 11, заблокированных требованиями античита к Secure Boot и TPM, а не для разработки или обхода античита.
