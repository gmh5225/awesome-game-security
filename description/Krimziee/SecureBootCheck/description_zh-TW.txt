Secure Boot & TPM 2.0 Check 是一款唯讀的 Windows 公用程式，用於回報 PC 是否符合許多核心層級反作弊系統在允許遊戲啟動前所要求的韌體與安全設定。它以 PowerShell 實作，可選用 WPF 圖形介面（XAML）與簡易批次啟動器，會檢查 UEFI 與 Legacy 開機模式、GPT 與 MBR 磁碟配置、Secure Boot 狀態與金鑰健康、TPM 2.0 就緒程度以及 BitLocker 復原金鑰狀態，且不會修改 BIOS、磁碟或 TPM。當某項檢查未通過時，它會說明可能原因，並依偵測到的 PC 或主機板品牌提供有序、可複製貼上的修復步驟，包含硬體根本無法支援 Secure Boot 或 TPM 的情況。面向因反作弊對 Secure Boot 與 TPM 的要求而無法執行遊戲的 Windows 10 與 Windows 11 玩家及技術支援人員排除問題，而非用於開發或繞過反作弊軟體。
