Secure Boot & TPM 2.0 Check 是一款只读的 Windows 实用工具，用于报告 PC 是否满足许多内核级反作弊系统在允许游戏启动前所要求的固件与安全设置。它使用 PowerShell 实现，可选 WPF 图形界面（XAML）和简易批处理启动器，会检查 UEFI 与 Legacy 启动模式、GPT 与 MBR 磁盘布局、Secure Boot 状态与密钥健康状况、TPM 2.0 就绪情况以及 BitLocker 恢复密钥状态，且不会修改 BIOS、磁盘或 TPM。当某项检查未通过时，它会说明可能原因，并按检测到的 PC 或主板品牌给出有序、可复制粘贴的修复步骤，包括硬件根本无法支持 Secure Boot 或 TPM 的情况。面向因反作弊对 Secure Boot 与 TPM 的要求而无法运行游戏的 Windows 10 与 Windows 11 玩家及技术支持人员排查问题，而非用于开发或绕过反作弊软件。
