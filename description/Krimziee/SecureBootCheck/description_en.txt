Secure Boot & TPM 2.0 Check is a read-only Windows utility that reports whether a PC meets the firmware and security settings many kernel-level anti-cheat systems require before games will launch. It is implemented in PowerShell with an optional WPF graphical interface (XAML) and a simple batch launcher, and it inspects UEFI versus legacy boot mode, GPT versus MBR disk layout, Secure Boot state and key health, TPM 2.0 readiness, and BitLocker recovery-key status without modifying BIOS, disks, or the TPM. When something fails, it explains the likely cause and gives ordered, copyable fix instructions tailored to the detected PC or motherboard brand, including cases where the hardware cannot support Secure Boot or TPM at all. It is aimed at gamers and support staff troubleshooting Windows 10 and Windows 11 PCs blocked by anti-cheat Secure Boot and TPM requirements rather than at building or bypassing anti-cheat software.
