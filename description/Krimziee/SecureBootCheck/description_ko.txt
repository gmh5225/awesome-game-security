Secure Boot & TPM 2.0 Check는 게임 실행 전 많은 커널 수준 안티치트가 요구하는 펌웨어 및 보안 설정을 PC가 충족하는지 보고하는 읽기 전용 Windows 유틸리티입니다. PowerShell로 구현되었으며 선택적 WPF 그래픽 인터페이스(XAML)와 간단한 배치 런처가 있으며, BIOS·디스크·TPM을 수정하지 않고 UEFI와 레거시 부팅, GPT와 MBR 디스크 구성, Secure Boot 상태 및 키 상태, TPM 2.0 준비 여부, BitLocker 복구 키 상태를 검사합니다. 항목이 실패하면 가능한 원인을 설명하고, 감지된 PC 또는 메인보드 브랜드에 맞춘 순서대로 복사 가능한 수정 안내를 제공하며, 하드웨어가 Secure Boot나 TPM을 전혀 지원하지 않는 경우도 다룹니다. 안티치트의 Secure Boot 및 TPM 요구로 막힌 Windows 10·Windows 11 PC를 게이머와 지원 담당자가 문제 해결하는 데 초점을 두었으며, 안티치트를 만들거나 우회하는 용도가 아닙니다.
