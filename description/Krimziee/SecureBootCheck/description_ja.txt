Secure Boot & TPM 2.0 Check は、ゲーム起動前に多くのカーネルレベルアンチチートが要求するファームウェアとセキュリティ設定を PC が満たしているかを報告する、読み取り専用の Windows ユーティリティです。PowerShell で実装され、オプションの WPF グラフィカル UI（XAML）とシンプルなバッチ起動器があり、UEFI とレガシーブート、GPT と MBR のディスク構成、Secure Boot の状態とキーの健全性、TPM 2.0 の準備状況、BitLocker 回復キーの状態を、BIOS・ディスク・TPM を変更せずに調べます。問題がある場合は想定原因を説明し、検出した PC やマザーボードのブランドに合わせた、順序付きでコピー可能な修正手順を示します。Secure Boot や TPM をハードウェアがサポートできないケースも含みます。アンチチートの Secure Boot と TPM 要件でブロックされた Windows 10 および Windows 11 PC を、ゲーマーやサポート担当がトラブルシュートするためのツールであり、アンチチートの構築や回避を目的としたものではありません。
