CemuTap is a free, open-source memory scanner and editor built for the Cemu Wii U emulator, positioned as an alternative to Cheat Engine for emulated Wii U titles. It is implemented in Python with a Tkinter desktop UI and uses pymem to read and write the emulator process memory, including MEM2 guest addresses. Users can run first and next scans across byte widths, floats, doubles, and unknown initial values, apply filters such as changed or increased, and work with address tables, live editing, value freezing, vector grouping, and pointer scans. Scan results and named address tables can be exported and imported via custom file formats, and extensible Python plugins can hook memory access, scans, and custom tabs through a documented Plugin API. It suits reverse engineering, game research, and offline modding workflows where developers need to locate and manipulate in-game variables under Cemu on Windows or Linux.
