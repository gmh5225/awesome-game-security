CemuTap 是一款面向 Cemu Wii U 模擬器的免費開源記憶體掃描與編輯工具，可作為在模擬 Wii U 遊戲上替代 Cheat Engine 的方案。它以 Python 實作，採用 Tkinter 桌面介面，並透過 pymem 讀寫模擬器行程記憶體，包含 MEM2 客體位址。使用者可在位元組寬度、浮點、雙精度及未知初始值等類型上進行首次與下次掃描，套用已變更或已增加等篩選條件，並支援位址表、即時編輯、數值凍結、向量分組與指標掃描。掃描結果與命名位址表可透過自訂檔案格式匯入匯出，可延伸的 Python 外掛可透過文件化的 Plugin API 掛接記憶體存取、掃描與自訂分頁。適用於在 Windows 或 Linux 上於 Cemu 中定位並操控遊戲內變數的逆向工程、遊戲研究與離線修改工作流程。
