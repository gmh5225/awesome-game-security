CemuTap は Cemu Wii U エミュレータ向けの無料オープンソースのメモリスキャナー兼エディタで、エミュレートした Wii U タイトルにおける Cheat Engine の代替として位置づけられています。Python と Tkinter によるデスクトップ UI で実装され、pymem を使ってエミュレータプロセスのメモリ（MEM2 ゲストアドレスを含む）を読み書きします。ユーザーはバイト幅、float、double、未知の初期値などに対してファーストスキャンとネクストスキャンを実行し、変更・増加などのフィルタを適用し、アドレステーブル、ライブ編集、値のフリーズ、ベクトルグループ化、ポインタスキャンに対応できます。スキャン結果と名前付きアドレステーブルは独自ファイル形式でエクスポート・インポートでき、拡張可能な Python プラグインが文書化された Plugin API 経由でメモリアクセス、スキャン、カスタムタブにフックできます。Windows または Linux 上の Cemu でゲーム内変数を特定・操作するリバースエンジニアリング、ゲーム研究、オフライン MOD 制作のワークフローに適しています。
