CemuTap 是一款面向 Cemu Wii U 模拟器的免费开源内存扫描与编辑工具，可作为在模拟 Wii U 游戏上替代 Cheat Engine 的方案。它使用 Python 实现，采用 Tkinter 桌面界面，并通过 pymem 读写模拟器进程内存，包括 MEM2 客户机地址。用户可在字节宽度、浮点、双精度及未知初始值等类型上进行首次与下次扫描，应用已变更或已增加等筛选条件，并支持地址表、实时编辑、数值冻结、向量分组与指针扫描。扫描结果与命名地址表可通过自定义文件格式导入导出，可扩展的 Python 插件可通过文档化的 Plugin API 挂钩内存访问、扫描与自定义标签页。适用于在 Windows 或 Linux 上于 Cemu 中定位并操控游戏内变量的逆向工程、游戏研究与离线修改工作流。
