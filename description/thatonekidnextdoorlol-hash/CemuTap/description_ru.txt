CemuTap — бесплатный сканер и редактор памяти с открытым исходным кодом для эмулятора Cemu Wii U, позиционируемый как альтернатива Cheat Engine для эмулируемых игр Wii U. Реализован на Python с настольным интерфейсом Tkinter и использует pymem для чтения и записи памяти процесса эмулятора, включая гостевые адреса MEM2. Пользователи могут выполнять первичное и последующее сканирование по ширине байта, float, double и неизвестным начальным значениям, применять фильтры вроде «изменилось» или «увеличилось», работать с таблицами адресов, редактированием в реальном времени, заморозкой значений, векторной группировкой и поиском указателей. Результаты сканирования и именованные таблицы адресов можно экспортировать и импортировать в пользовательских форматах файлов, а расширяемые плагины на Python могут перехватывать доступ к памяти, сканирование и пользовательские вкладки через документированный Plugin API. Подходит для реверс-инжиниринга, исследования игр и офлайн-моддинга, когда разработчикам нужно находить и изменять игровые переменные в Cemu под Windows или Linux.
