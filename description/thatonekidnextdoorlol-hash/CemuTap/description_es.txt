CemuTap es un escáner y editor de memoria gratuito y de código abierto diseñado para el emulador Cemu de Wii U, planteado como alternativa a Cheat Engine en títulos de Wii U emulados. Está implementado en Python con una interfaz de escritorio Tkinter y usa pymem para leer y escribir la memoria del proceso del emulador, incluidas direcciones invitado MEM2. Los usuarios pueden ejecutar primeros y siguientes escaneos sobre anchos de byte, flotantes, dobles y valores iniciales desconocidos, aplicar filtros como cambiado o aumentado, y trabajar con tablas de direcciones, edición en vivo, congelación de valores, agrupación vectorial y escaneos de punteros. Los resultados de escaneo y las tablas de direcciones con nombre pueden exportarse e importarse mediante formatos de archivo personalizados, y plugins Python extensibles pueden enganchar el acceso a memoria, los escaneos y pestañas personalizadas a través de una Plugin API documentada. Es adecuado para flujos de trabajo de ingeniería inversa, investigación de juegos y modding offline cuando los desarrolladores necesitan localizar y manipular variables del juego bajo Cemu en Windows o Linux.
