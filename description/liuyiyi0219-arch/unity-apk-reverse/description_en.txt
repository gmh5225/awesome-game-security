This is a hands-on reverse engineering course for Unity Android APK games, structured as a 40-chapter progressive curriculum with runnable demos and auto-graded homework. It walks learners through every layer of a Unity mobile game, from APK unpacking and signature bypass through IL2CPP metadata recovery, Lua and puerts/QuickJS script extraction, DEX decompilation, and AssetBundle resource analysis. The stack centers on Python and Go tooling (a course builder and local HTTP loader), with practical use of Frida, frida-gadget, unidbg, jadx, and related mobile RE utilities across sample target APKs. It is aimed at beginners and practitioners who want structured, authorized practice in mobile game security and Unity APK reverse engineering.
