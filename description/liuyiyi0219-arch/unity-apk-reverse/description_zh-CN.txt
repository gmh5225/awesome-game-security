这是一门面向 Unity Android APK 游戏的实战逆向工程课程，采用 40 章渐进式课程结构，配有可运行的演示和自动批改的作业。课程带领学习者逐层剖析 Unity 手游，涵盖 APK 解包与签名校验绕过、IL2CPP 元数据恢复、Lua 及 puerts/QuickJS 脚本提取、DEX 反编译以及 AssetBundle 资源分析。技术栈以 Python 和 Go 工具（课程构建器与本地 HTTP 加载器）为核心，并在示例目标 APK 上实际运用 Frida、frida-gadget、unidbg、jadx 等移动逆向相关工具。适合希望在移动游戏安全与 Unity APK 逆向工程领域进行系统化、合规练习的初学者与从业者。
