這是一門面向 Unity Android APK 遊戲的實戰逆向工程課程，採用 40 章漸進式課程結構，配有可執行的示範與自動批改的作業。課程帶領學習者逐層剖析 Unity 手遊，涵蓋 APK 解包與簽名繞過、IL2CPP 中繼資料還原、Lua 及 puerts/QuickJS 腳本提取、DEX 反編譯，以及 AssetBundle 資源分析。技術棧以 Python 與 Go 工具（課程建構器與本機 HTTP 載入器）為核心，並在範例目標 APK 上實際運用 Frida、frida-gadget、unidbg、jadx 等行動逆向相關工具。適合希望在行動遊戲安全與 Unity APK 逆向工程領域進行系統化、合規練習的初學者與從業者。
