これは Unity Android APK ゲーム向けの実践的なリバースエンジニアリングコースで、40章の段階的カリキュラムとして構成され、実行可能なデモと自動採点の宿題が付属します。APK の展開と署名チェックのバイパスから、IL2CPP メタデータの復元、Lua および puerts/QuickJS スクリプトの抽出、DEX の逆コンパイル、AssetBundle リソースの分析まで、Unity モバイルゲームの各レイヤーを学習者が順に学びます。技術スタックは Python と Go のツール（コースビルダーとローカル HTTP ローダー）を中心とし、サンプル対象 APK 上で Frida、frida-gadget、unidbg、jadx などのモバイル RE 関連ユーティリティを実践的に使用します。モバイルゲームセキュリティと Unity APK リバースエンジニアリングにおいて、体系的かつ許可された実習を目指す初心者と実務者を対象としています。
