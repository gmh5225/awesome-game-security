Nakagawa Recomp는 PlayStation Portable 게임 바이너리를 네이티브 C로 변환해 전용 런처와 플레이어를 통해 Windows에서 빌드하고 실행할 수 있게 하는 정적 재컴파일 프로젝트입니다. sal063 PSP 재컴파일 계보에서 포크했으며, MIPS 게스트 런타임, VFPU 지원 데이터, Vulkan 렌더링, SDL3 기반 UI로 설정, 컨트롤러 매핑, 재컴파일된 타이틀 실행을 제공합니다. 엔진 대부분은 C로 작성되었고, Python 도구는 코드 생성, 파이프라인 테스트, 기준 인터프리터와의 코시뮬레이션, decomp.me 내보내기, 실제 PSP 하드웨어에 대한 선택적 검증을 담당합니다. 일반 에뮬레이터에만 의존하지 않고 PSP 실행 파일을 분석하고 플레이 가능한 네이티브 포트를 내놓으려는 개발자, 보존 활동가, 리버스 엔지니어를 대상으로 합니다.
