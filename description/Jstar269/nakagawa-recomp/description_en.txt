Nakagawa Recomp is a static recompilation project that turns PlayStation Portable game binaries into native C you can build and play on Windows through its own launcher and player. Forked from the sal063 PSP recompilation lineage, it combines a MIPS guest runtime, VFPU support data, Vulkan rendering, and an SDL3-based UI for setup, controller mapping, and running recompiled titles. Most of the engine is written in C, with Python tools for codegen, pipeline tests, cosimulation against a reference interpreter, decomp.me export, and optional verification against real PSP hardware. It is aimed at developers, preservationists, and reverse engineers who want to analyze PSP executables and ship playable native ports instead of relying on a conventional emulator alone.
