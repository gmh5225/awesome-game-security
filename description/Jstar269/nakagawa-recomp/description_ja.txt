Nakagawa Recomp は、PlayStation Portable のゲームバイナリをネイティブ C に変換し、専用ランチャーとプレイヤー経由で Windows 上にビルドしてプレイできる静的再コンパイルプロジェクトです。sal063 の PSP 再コンパイル系譜をフォークしたもので、MIPS ゲストランタイム、VFPU サポートデータ、Vulkan レンダリング、および SDL3 ベースの UI により、セットアップ、コントローラーマッピング、再コンパイル済みタイトルの実行を行います。エンジンの大部分は C で書かれ、Python ツールはコード生成、パイプライン試験、参照インタプリタとのコシミュレーション、decomp.me エクスポート、実機 PSP ハードウェアとの任意の照合検証を担います。従来のエミュレーターだけに頼らず、PSP 実行ファイルを解析し、プレイ可能なネイティブ移植版を届けたい開発者、保存活動家、リバースエンジニア向けです。
