Nakagawa Recomp 是一项静态重编译项目，可将 PlayStation Portable 游戏二进制文件转换为可编译的原生 C 代码，并通过自带的启动器与播放器在 Windows 上构建和运行。该项目 fork 自 sal063 的 PSP 重编译分支，集成了 MIPS 客户机运行时、VFPU 支持数据、Vulkan 渲染以及基于 SDL3 的界面，用于配置、手柄映射和运行重编译后的游戏。引擎主体以 C 编写，Python 工具负责代码生成、流水线测试、与参考解释器的协同仿真、decomp.me 导出，以及可选的与真实 PSP 硬件对照验证。面向希望分析 PSP 可执行文件并交付可玩原生移植版、而非仅依赖传统模拟器的开发者、游戏保存爱好者与逆向工程师。
