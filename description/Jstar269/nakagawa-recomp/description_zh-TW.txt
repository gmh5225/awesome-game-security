Nakagawa Recomp 是一項靜態重編譯專案，可將 PlayStation Portable 遊戲二進位檔轉換為可編譯的原生 C 程式碼，並透過內建啟動器與播放器在 Windows 上建置與遊玩。本專案 fork 自 sal063 的 PSP 重編譯脈絡，整合 MIPS 客體執行環境、VFPU 支援資料、Vulkan 渲染，以及以 SDL3 為基礎的介面，供設定、手把對應與執行重編譯後的標題使用。引擎大多以 C 撰寫，Python 工具負責程式碼產生、管線測試、與參考直譯器的協同模擬、decomp.me 匯出，以及可選的與真實 PSP 硬體對照驗證。面向希望分析 PSP 可執行檔並交付可玩原生移植版、而非僅依賴傳統模擬器的開發者、保存工作者與逆向工程師。
