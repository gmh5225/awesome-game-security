Nakagawa Recomp — проект статической перекомпиляции, который превращает бинарники игр PlayStation Portable в нативный C, который можно собрать и запустить в Windows через собственный лаунчер и проигрыватель. Форк линии PSP-перекомпиляции sal063: в нём сочетаются гостевой runtime MIPS, данные поддержки VFPU, рендеринг Vulkan и интерфейс на SDL3 для настройки, сопоставления геймпада и запуска перекомпилированных игр. Большая часть движка написана на C; инструменты на Python отвечают за генерацию кода, тесты конвейера, косимуляцию с эталонным интерпретатором, экспорт в decomp.me и опциональную проверку на реальном железе PSP. Проект рассчитан на разработчиков, энтузиастов сохранения и reverse engineers, которым нужно разбирать исполняемые файлы PSP и выпускать играбельные нативные порты, а не полагаться только на обычный эмулятор.
