FIRERPA（LAMDA）是一款一体化的 Android 设备控制与自动化平台，在设备上运行服务端，并提供统一的 Python 客户端 API。它将 UI 自动化、基于 WebRTC 的远程桌面投屏、一键 MITM 流量捕获、内置 Frida hook、网络代理以及 AI/MCP 智能体支持整合在一起，无需再分别拼装 Appium、mitmproxy、frida-server 和 adb。该方案在多种 Android 版本上支持有 root 或无 root 使用，支持虚拟显示以实现后台自动化，并内置 frida-tools、tcpdump 及逆向工程库等设备端分析工具。主要应用场景包括移动安全测试、逆向工程、协议分析、合规检查以及多设备集群自动化。
