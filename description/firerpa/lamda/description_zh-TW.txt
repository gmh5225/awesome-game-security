FIRERPA（LAMDA）是一款一體化的 Android 裝置控制與自動化平台，在裝置上執行伺服器，並提供統一的 Python 用戶端 API。它將 UI 自動化、基於 WebRTC 的遠端桌面螢幕鏡像、一鍵 MITM 流量擷取、內建 Frida hook、網路代理以及 AI/MCP 代理支援整合在一起，無需再分別拼裝 Appium、mitmproxy、frida-server 和 adb。該方案在多種 Android 版本上支援有 root 或無 root 使用，支援虛擬顯示器以實現背景自動化，並內建 frida-tools、tcpdump 及逆向工程函式庫等裝置端分析工具。主要應用場景包括行動安全測試、逆向工程、協定分析、合規檢查以及多裝置機群自動化。
