FIRERPA(LAMDA)는 기기에서 서버를 실행하고 통합 Python 클라이언트 API를 제공하는 올인원 Android 기기 제어 및 자동화 플랫폼입니다. UI 자동화, WebRTC 화면 미러링 기반 원격 데스크톱, 원클릭 MITM 트래픽 캡처, 내장 Frida 후킹, 네트워크 프록시, AI/MCP 에이전트 지원을 하나로 묶어 Appium, mitmproxy, frida-server, adb를 따로 조합할 필요가 없습니다. 다양한 Android 버전에서 루트 유무와 관계없이 동작하며, 백그라운드 자동화를 위한 가상 디스플레이를 지원하고 frida-tools, tcpdump, 리버스 엔지니어링 라이브러리 등 기기 내 분석 도구를 포함합니다. 주요 사용 사례는 모바일 보안 테스트, 리버스 엔지니어링, 프로토콜 분석, 컴플라이언스 점검, 다중 기기 플릿 자동화입니다.
