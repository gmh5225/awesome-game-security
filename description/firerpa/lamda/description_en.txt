FIRERPA (LAMDA) is an all-in-one Android device control and automation platform that runs a server on the device and exposes a unified Python client API. It combines UI automation, remote desktop with WebRTC screen mirroring, one-click MITM traffic capture, built-in Frida hooking, network proxying, and AI/MCP agent support without stitching together Appium, mitmproxy, frida-server, and adb separately. The stack works with or without root across many Android versions, supports virtual displays for background automation, and includes on-device analysis tools such as frida-tools, tcpdump, and reverse-engineering libraries. Primary use cases include mobile security testing, reverse engineering, protocol analysis, compliance inspection, and multi-device fleet automation.
