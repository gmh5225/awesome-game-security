FIRERPA（LAMDA）は、デバイス上でサーバーを動作させ、統一された Python クライアント API を提供するオールインワンの Android デバイス制御・自動化プラットフォームです。UI 自動化、WebRTC によるリモートデスクトップ画面ミラーリング、ワンクリック MITM トラフィックキャプチャ、組み込み Frida フッキング、ネットワークプロキシ、AI/MCP エージェント対応を統合し、Appium、mitmproxy、frida-server、adb を個別に組み合わせる必要がありません。多くの Android バージョンで root あり・なしの両方に対応し、バックグラウンド自動化向けの仮想ディスプレイをサポートし、frida-tools、tcpdump、リバースエンジニアリング用ライブラリなどのオンデバイス分析ツールを含みます。主な用途はモバイルセキュリティテスト、リバースエンジニアリング、プロトコル解析、コンプライアンス検査、複数デバイスのフリート自動化です。
