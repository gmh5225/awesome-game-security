Katapult — это клиент-серверный античит-мод для Minecraft 1.21.1 на NeoForge, который обеспечивает целостность игры путём проверки установленных клиентских модов и наборов ресурсов по серверным белым спискам. Он вычисляет контрольные суммы SHA-256 из физических файлов .jar и .zip на клиенте и сравнивает их с хешами, сгенерированными из серверных модов и одобренного администратором дополнительного клиентского контента, отключая игроков, загружающих неодобренные или изменённые файлы. Мониторинг наборов ресурсов обнаруживает переименованные или поддельные паки, такие как скрытые текстуры X-ray, с проверками в реальном времени при входе и перезагрузке. Серверная часть поддерживает конфигурацию с горячей перезагрузкой, регенерацию белого списка и повторную проверку в реальном времени через команды без перезапуска. Написан на Java с использованием сетевых полезных нагрузок NeoForge и управления белым списком на основе Gson, он ориентирован на операторов серверов Minecraft, которым необходимо обеспечение целостности на модифицированных многопользовательских серверах.
