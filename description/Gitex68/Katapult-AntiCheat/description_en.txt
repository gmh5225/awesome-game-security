Katapult is a client-server anti-cheat mod for Minecraft 1.21.1 on NeoForge that enforces game integrity by validating installed client mods and resource packs against server-side whitelists. It computes SHA-256 checksums from physical .jar and .zip files on the client and compares them to hashes generated from server mods and administrator-approved optional client content, disconnecting players who load unapproved or modified files. Resource pack monitoring detects renamed or spoofed packs such as hidden X-ray textures, with real-time checks on join and reload. The server side supports hot-reloadable configuration, whitelist regeneration, and live re-validation via commands without restarting. Written in Java with NeoForge networking payloads and Gson-based whitelist management, it targets Minecraft server operators who need integrity enforcement on modded multiplayer servers.
