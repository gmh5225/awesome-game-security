Katapult è una mod anti-cheat client-server per Minecraft 1.21.1 su NeoForge che impone l'integrità del gioco validando le mod client e i resource pack installati rispetto alle whitelist lato server. Calcola checksum SHA-256 dai file fisici .jar e .zip sul client e li confronta con hash generati dalle mod server e dai contenuti client opzionali approvati dall'amministratore, disconnettendo i giocatori che caricano file non approvati o modificati. Il monitoraggio dei resource pack rileva pacchetti rinominati o contraffatti, come texture X-ray nascoste, con controlli in tempo reale all'accesso e al ricaricamento. Lato server supporta configurazione hot-reloadable, rigenerazione della whitelist e rivalidazione live tramite comandi senza riavvio. Scritto in Java con payload di rete NeoForge e gestione whitelist basata su Gson, è rivolto agli operatori di server Minecraft che necessitano di applicazione dell'integrità su server multigiocatore moddati.
