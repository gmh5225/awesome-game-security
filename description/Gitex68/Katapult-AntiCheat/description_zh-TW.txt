Katapult 是一款適用於 NeoForge 上 Minecraft 1.21.1 的用戶端-伺服器反作弊模組，透過將已安裝的用戶端模組和資源包與伺服器端白名單進行驗證來維護遊戲完整性。它會根據用戶端上的實體 .jar 和 .zip 檔案計算 SHA-256 校驗和，並與由伺服器模組及管理員核准的可選用戶端內容產生的雜湊值進行比對，中斷載入未核准或已修改檔案的玩家連線。資源包監控可偵測重新命名或偽裝的資源包（例如隱藏的 X-ray 紋理），並在加入和重新載入時進行即時檢查。伺服器端支援熱重載設定、白名單重新產生以及透過指令進行即時重新驗證，無需重新啟動。該模組以 Java 編寫，採用 NeoForge 網路承載和基於 Gson 的白名單管理，面向需要在模組化多人伺服器上實施完整性強制的 Minecraft 伺服器營運者。
