Fall Guys モバイル版向けの Android モッドメニューで、Frida による動的インストルメンテーションを使って実行時に設定可能なオーバーレイ UI を注入します。主に TypeScript で書かれており、frida-il2cpp-bridge で Unity IL2CPP ゲームエンジンをフックし、frida-java-menu で Java ベースのオーバーレイ UI を構築します。APK のパッチは Objection と APKEditor で行います。モジュラー設計により、移動操作、ラウンド別ヘルパー、テレポート、BAN 回避、プラットフォーム偽装、ネットワークやアナリティクスのデバッグツールなどのゲームプレイ改変機能を提供します。逆アセンブルエンジニア、モバイルゲームセキュリティ研究者、IL2CPP フック、チート対策回避、Android ゲーム改変技術を教育・研究目的で学ぶ開発者を対象としています。
