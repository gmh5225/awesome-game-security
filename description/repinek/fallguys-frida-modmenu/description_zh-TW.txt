這是針對 Fall Guys 行動遊戲的 Android 模組選單，透過 Frida 動態插樁在執行時注入可設定的覆蓋介面。專案主要使用 TypeScript 撰寫，透過 frida-il2cpp-bridge 對 Unity IL2CPP 遊戲引擎進行 Hook，並借助 frida-java-menu 建構基於 Java 的覆蓋 UI，APK 修補則由 Objection 和 APKEditor 完成。模組化設計提供了多種遊戲玩法調整功能，包括移動操控、回合專用輔助、傳送、封禁繞過、平台偽造以及網路或分析除錯工具。面向逆向工程師、行動遊戲安全研究人員以及學習 IL2CPP Hook、反作弊繞過和 Android 遊戲修改技術的開發者，用於教育與研究目的。
