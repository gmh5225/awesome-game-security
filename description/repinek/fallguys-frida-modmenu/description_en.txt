This is an Android mod menu for the Fall Guys mobile game that injects a configurable overlay interface at runtime using Frida dynamic instrumentation. Written primarily in TypeScript, it hooks the Unity IL2CPP game engine through frida-il2cpp-bridge and builds a Java-based overlay UI via frida-java-menu, with APK patching handled through Objection and APKEditor. The modular design exposes gameplay tweaks such as movement manipulation, round-specific helpers, teleports, ban bypass, platform spoofing, and network or analytics debugging tools. It targets reverse engineers, mobile game security researchers, and developers studying IL2CPP hooking, anti-cheat bypass, and Android game modification techniques for educational and research purposes.
