Это Android mod menu для мобильной игры Fall Guys, которое внедряет настраиваемый оверлейный интерфейс во время выполнения с помощью динамической инструментации Frida. Написано в основном на TypeScript, перехватывает игровой движок Unity IL2CPP через frida-il2cpp-bridge и строит Java-based overlay UI через frida-java-menu; патчинг APK выполняется с помощью Objection и APKEditor. Модульная архитектура предоставляет игровые модификации: манипуляция движением, помощники для конкретных раундов, телепорты, обход бана, подмена платформы, а также инструменты отладки сети и аналитики. Предназначено для специалистов по реверс-инжинирингу, исследователей безопасности мобильных игр и разработчиков, изучающих IL2CPP hooking, обход античита и методы модификации Android-игр в образовательных и исследовательских целях.
