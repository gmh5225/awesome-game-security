Fall Guys 모바일 게임용 Android 모드 메뉴로, Frida 동적 계측을 사용해 런타임에 구성 가능한 오버레이 인터페이스를 주입합니다. 주로 TypeScript로 작성되었으며, frida-il2cpp-bridge를 통해 Unity IL2CPP 게임 엔진을 후킹하고, frida-java-menu로 Java 기반 오버레이 UI를 구축합니다. APK 패치는 Objection과 APKEditor로 처리합니다. 모듈식 설계로 이동 조작, 라운드별 헬퍼, 텔레포트, 밴 우회, 플랫폼 스푸핑, 네트워크 또는 분석 디버깅 도구 등의 게임플레이 조정 기능을 제공합니다. 역공학자, 모바일 게임 보안 연구자, IL2CPP 후킹, 안티치트 우회, Android 게임 수정 기법을 교육 및 연구 목적으로 학습하는 개발자를 대상으로 합니다.
