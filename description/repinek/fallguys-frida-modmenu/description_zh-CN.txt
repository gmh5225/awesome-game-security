这是针对 Fall Guys 移动游戏的 Android 模组菜单，通过 Frida 动态插桩在运行时注入可配置的叠加界面。项目主要使用 TypeScript 编写，通过 frida-il2cpp-bridge 对 Unity IL2CPP 游戏引擎进行 Hook，并借助 frida-java-menu 构建基于 Java 的叠加 UI，APK 修补由 Objection 和 APKEditor 完成。模块化设计提供了多种游戏玩法调整功能，包括移动操控、回合专用辅助、传送、封禁绕过、平台伪造以及网络或分析调试工具。面向逆向工程师、移动游戏安全研究人员以及学习 IL2CPP Hook、反作弊绕过和 Android 游戏修改技术的开发者，用于教育与研究目的。
