AUSP-3DS 是一款可直接嵌入的 C 库，用于在 Nintendo 3DS 自制软件游戏中检测作弊与插件加载器，且无需读取 SD 卡或文件系统。它通过系统内存查询服务遍历进程内存，并匹配与 NTR、3GX、CTRPluginFramework、Luma 插件及类似工具相关的字节特征；还可选择将 Nimbus 与 Pretendo 视为无害，以免误封联机玩家。集成方调用单一启动例程即可显示 citro2d 启动画面、执行扫描，随后展示可配置警告界面、调用自定义回调、退出进程，或组合这些反应。面向希望在 libctru、citro2d 与 citro3d 之上实现轻量级进程内反作弊与防篡改保护的 3DS 自制软件作者。
