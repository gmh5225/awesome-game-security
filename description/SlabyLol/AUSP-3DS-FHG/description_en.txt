AUSP-3DS is a drop-in C library that detects cheat and plugin loaders on Nintendo 3DS homebrew titles without reading the SD card or filesystem. It walks process memory with the system memory query service and matches byte signatures associated with NTR, 3GX, CTRPluginFramework, Luma plugins, and similar tooling, while optionally treating Nimbus and Pretendo as benign so online players are not blocked. Integrators call a single startup routine to show a citro2d splash screen, run the scan, and then either display a configurable warning UI, invoke a custom callback, exit the process, or combine those reactions. It is aimed at 3DS homebrew authors who want lightweight in-process anti-cheat and anti-tamper protection built on libctru, citro2d, and citro3d.
