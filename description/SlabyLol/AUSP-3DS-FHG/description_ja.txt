AUSP-3DS は、Nintendo 3DS の homebrew 向けタイトルで、SD カードやファイルシステムを読まずにチートやプラグインローダーを検出する、組み込み可能な C ライブラリです。システムのメモリ照会サービスでプロセスメモリを走査し、NTR、3GX、CTRPluginFramework、Luma プラグインなどに関連するバイトシグネチャと照合します。オプションで Nimbus と Pretendo を良性とみなし、オンラインプレイヤーをブロックしないようにできます。統合側は単一の起動ルーチンを呼び出すだけで、citro2d のスプラッシュを表示し、スキャンを実行したのち、設定可能な警告 UI の表示、カスタムコールバックの呼び出し、プロセス終了、またはそれらの組み合わせを行えます。libctru、citro2d、citro3d 上で軽量なプロセス内アンチチート・アンチ改ざん保護を求める 3DS homebrew 作者向けです。
