本リポジトリは、VMProtect、Themida などのカスタム仮想マシン難読化で保護されたコードを静的・動的にデバーチャライズするための、構造化されたエージェントスキルとワークフローガイドを提供する。ドキュメントは Markdown で書かれており、VM の再実装ではなく元のプログラム意味の復元を中心に、PE 読み込み、制御実行、IR リフティング、式解析の主エンジンとして Miasm を用い、デバッガおよび Capstone、Triton、Z3、IDA を補助的に扱う。仮想化領域の特定、VM コンテキストと仮想レジスタのアンカー、ハンドラ分類、テイントと後向きスライシング、任意のシャドウ IR、シンボリックパス制約、VMProtect 3.9 向けバイト由来追跡、復元した疑似コードの検証までを順を追って説明する。言語モデルがツール選定、仮説と確定事実の区別、実行時挙動と食い違う場合の分析絞り込みをどう行うかも専章で示す。商業用 VM 系パッカーや改ざん防止を、再現可能かつツールに根ざした手順でアンパックしたいリバースエンジニアやゲーム・ソフトウェア保護研究者向けである。
