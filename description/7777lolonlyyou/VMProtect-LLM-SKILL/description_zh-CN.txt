本仓库提供一套结构化的智能体技能与工作流指南，用于对经 VMProtect、Themida 及同类自定义虚拟机混淆器保护的代码进行静态与动态去虚拟化。文档以 Markdown 编写，侧重还原原始程序语义而非重新实现虚拟机，并以 Miasm 作为主要引擎，完成 PE 加载、受控执行、IR 提升与表达式分析，辅以调试器以及 Capstone、Triton、Z3 和 IDA。内容涵盖定位虚拟化区域、锚定 VM 上下文与虚拟寄存器、对 handler 分类、污点分析与反向切片、可选的影子 IR、符号路径约束、针对 VMProtect 3.9 的字节来源追踪，以及对恢复伪代码的校验。专门章节说明语言模型应如何选择工具、区分假设与已确认事实，并在结果与运行时行为不一致时收窄分析范围。面向需要可重复、工具驱动方式解包商业 VM 加壳与防篡改方案的反工程师及游戏或软件保护研究人员。
