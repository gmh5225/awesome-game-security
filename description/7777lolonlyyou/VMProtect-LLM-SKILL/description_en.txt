This repository provides a structured agent skill and workflow guide for statically and dynamically devirtualizing code protected by VMProtect, Themida, and similar custom virtual-machine obfuscators. The documentation is written in Markdown and centers on recovering original program semantics rather than reimplementing the VM, using Miasm as the primary engine for PE loading, controlled execution, IR lifting, and expression analysis, with auxiliary support from debuggers, Capstone, Triton, Z3, and IDA. It walks through locating virtualized regions, anchoring VM context and virtual registers, classifying handlers, taint and backward slicing, optional shadow IR, symbolic path constraints, byte-provenance tracking for VMProtect 3.9, and validation of recovered pseudocode. Dedicated sections spell out how language models should choose tools, preserve hypotheses versus confirmed facts, and narrow analysis when results disagree with runtime behavior. It is aimed at reverse engineers and game or software protection researchers who need a repeatable, tool-grounded approach to unpacking commercial VM-based packers and anti-tamper schemes.
