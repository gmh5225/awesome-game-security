本儲存庫提供一套結構化的智慧代理技能與工作流程指南，用於對經 VMProtect、Themida 及同類自訂虛擬機混淆器保護的程式碼進行靜態與動態去虛擬化。文件以 Markdown 撰寫，著重於還原原始程式語意而非重新實作虛擬機，並以 Miasm 作為主要引擎，完成 PE 載入、受控執行、IR 提升與運算式分析，輔以除錯器以及 Capstone、Triton、Z3 和 IDA。內容涵蓋定位虛擬化區域、錨定 VM 內容與虛擬暫存器、對 handler 分類、汙點分析與反向切片、可選的影子 IR、符號路徑約束、針對 VMProtect 3.9 的位元組來源追蹤，以及對恢復偽程式碼的驗證。專門章節說明語言模型應如何選擇工具、區分假設與已確認事實，並在結果與執行期行為不一致時縮小分析範圍。面向需要可重複、工具導向方式解包商業 VM 加殼與防篡改方案的反組譯工程師及遊戲或軟體保護研究人員。
