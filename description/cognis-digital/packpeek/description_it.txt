Packpeek è un fingerprinter binario statico privo di dipendenze, scritto in C, che determina se un eseguibile è impacchettato e identifica il packer o il protettore responsabile. Analizza i file alla ricerca di marcatori documentati di packer runtime comuni come UPX, ASPack, Themida, VMProtect, MPRESS e altri, calcolando l'entropia di Shannon per segnalare regioni ad alta casualità tipiche del codice compresso o offuscato. Lo strumento è agnostico rispetto al formato per PE, ELF, Mach-O e blob di firmware grezzi, emette risultati JSON strutturati e si affianca a un companion Python per generare regole YARA distribuibili e output SARIF per pipeline CI e flussi di scansione del codice. Progettato per triage difensivo e analisi statica, legge i file localmente senza eseguirli né effettuare chiamate di rete, risultando utile per analisti di malware, reverse engineer e ricercatori di sicurezza dei giochi che valutano binari protetti o sospetti.
