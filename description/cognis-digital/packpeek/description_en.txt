Packpeek is a dependency-free static binary fingerprinter written in C that determines whether an executable is packed and identifies the packer or protector responsible. It scans files for documented markers of common runtime packers such as UPX, ASPack, Themida, VMProtect, MPRESS, and others, while computing Shannon entropy to flag high-randomness regions typical of compressed or obfuscated code. The tool is format-agnostic across PE, ELF, Mach-O, and raw firmware blobs, emits structured JSON results, and pairs with a Python companion to generate deployable YARA rules and SARIF output for CI pipelines and code scanning workflows. Designed for defensive triage and static analysis, it reads files locally without executing them or making network calls, making it useful for malware analysts, reverse engineers, and game security researchers assessing protected or suspicious binaries.
