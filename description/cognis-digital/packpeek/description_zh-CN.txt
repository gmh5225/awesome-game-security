Packpeek 是一款用 C 语言编写的无依赖静态二进制指纹工具，用于判断可执行文件是否被加壳，并识别对应的加壳器或保护器。它会扫描文件中常见运行时加壳器（如 UPX、ASPack、Themida、VMProtect、MPRESS 等）的已知标记，同时计算 Shannon 熵以标记压缩或混淆代码中常见的高随机性区域。该工具对 PE、ELF、Mach-O 及原始固件 blob 等格式通用，输出结构化 JSON 结果，并配有 Python 配套工具，可生成可部署的 YARA 规则及 SARIF 输出，供 CI 流水线与代码扫描工作流使用。面向防御性分诊与静态分析，它在本地读取文件，不执行程序、不发起网络请求，适合恶意软件分析人员、逆向工程师及评估受保护或可疑二进制文件的游戏安全研究人员使用。
