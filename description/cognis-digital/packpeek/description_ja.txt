Packpeek は C 言語で書かれた依存関係のない静的バイナリフィンガープリントツールで、実行ファイルがパックされているかどうかを判定し、該当するパッカーまたはプロテクタを特定します。UPX、ASPack、Themida、VMProtect、MPRESS など一般的なランタイムパッカーの既知マーカーをファイルからスキャンし、Shannon エントロピーを計算して圧縮または難読化されたコードに典型的な高ランダム性領域を検出します。このツールは PE、ELF、Mach-O、生のファームウェア blob など形式に依存せず、構造化された JSON 結果を出力し、Python コンパニオンと連携して CI パイプラインやコードスキャンワークフロー向けに展開可能な YARA ルールおよび SARIF 出力を生成します。防御的トリアージと静的解析向けに設計され、ファイルをローカルで読み取るだけで実行やネットワーク呼び出しは行わないため、保護されたまたは疑わしいバイナリを評価するマルウェアアナリスト、リバースエンジニア、ゲームセキュリティ研究者に有用です。
