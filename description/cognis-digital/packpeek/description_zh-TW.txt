Packpeek 是一款以 C 語言撰寫、無外部依賴的靜態二進位指紋工具，用於判斷可執行檔是否被加殼，並識別對應的加殼器或保護器。它會掃描檔案中常見執行階段加殼器（如 UPX、ASPack、Themida、VMProtect、MPRESS 等）的已知標記，同時計算 Shannon 熵以標記壓縮或混淆程式碼中常見的高隨機性區域。此工具對 PE、ELF、Mach-O 及原始韌體 blob 等格式通用，輸出結構化 JSON 結果，並配有 Python 配套工具，可產生可部署的 YARA 規則及 SARIF 輸出，供 CI 管線與程式碼掃描工作流程使用。面向防禦性分診與靜態分析，它在本地讀取檔案，不執行程式、不發起網路請求，適合惡意軟體分析人員、逆向工程師及評估受保護或可疑二進位檔案的遊戲安全研究人員使用。
