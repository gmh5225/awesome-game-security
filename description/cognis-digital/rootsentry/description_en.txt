RootSentry is a mobile runtime-integrity detection framework that evaluates whether an Android or iOS device environment can be trusted by scoring on-device telemetry against a catalog of compromise indicators. Written primarily in Python with zero external dependencies, it matches evidence snapshots for root and jailbreak artifacts, emulator fingerprints, hooking frameworks such as Frida and Xposed, and tamper signals, then returns a weighted posture verdict from TRUSTED through CRITICAL. The tool ships a CLI and library for single-device evaluation, fleet-scale cohort analysis, and MITRE ATT&CK for Mobile technique mapping, plus reference Kotlin and Swift collectors and polyglot example detectors in several languages. It is designed for defensive RASP-style self-protection, backend attestation pipelines, and authorized security assessments where apps need to detect compromised or instrumented runtimes before allowing high-risk actions.
