RootSentry 是一个移动设备运行时完整性检测框架，通过将设备端遥测数据与一系列入侵指标进行比对评分，评估 Android 或 iOS 设备环境是否可信。该工具主要使用 Python 编写，无外部依赖，可匹配 root 与越狱痕迹、模拟器指纹、Frida 和 Xposed 等 Hook 框架以及篡改信号的证据快照，并返回从 TRUSTED 到 CRITICAL 的加权态势判定。它提供 CLI 和库，支持单设备评估、大规模设备群组分析以及 MITRE ATT&CK for Mobile 技术映射，还包含 Kotlin 和 Swift 参考采集器及多种语言的示例检测器。该框架面向防御性 RASP 式自我保护、后端证明流水线以及授权安全评估场景，帮助应用在允许高风险操作前检测已遭入侵或被插桩的运行环境。
