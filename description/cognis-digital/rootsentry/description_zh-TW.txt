RootSentry 是一個行動裝置執行階段完整性偵測框架，透過將裝置端遙測資料與一系列入侵指標進行比對評分，評估 Android 或 iOS 裝置環境是否可信。此工具主要以 Python 撰寫，無外部相依性，可比對 root 與越獄痕跡、模擬器指紋、Frida 和 Xposed 等 Hook 框架以及竄改訊號的證據快照，並回傳從 TRUSTED 到 CRITICAL 的加權態勢判定。它提供 CLI 和函式庫，支援單一裝置評估、大規模裝置群組分析以及 MITRE ATT&CK for Mobile 技術對應，並包含 Kotlin 和 Swift 參考收集器及多種語言的範例偵測器。此框架適用於防禦性 RASP 式自我保護、後端證明管線以及授權安全評估，協助應用程式在允許高風險操作前偵測已遭入侵或被插樁的執行環境。
