RootSentry は、Android または iOS デバイス環境が信頼できるかどうかを、端末上のテレメトリを侵害指標のカタログと照合してスコアリングするモバイル向けランタイム整合性検出フレームワークです。主に Python で書かれ、外部依存はなく、root や jailbreak の痕跡、エミュレータのフィンガープリント、Frida や Xposed などのフックフレームワーク、改ざんシグナルに関する証拠スナップショットを照合し、TRUSTED から CRITICAL までの重み付き姿勢判定を返します。CLI とライブラリにより単一デバイス評価、フリート規模のコホート分析、MITRE ATT&CK for Mobile のテクニックマッピングに対応し、Kotlin と Swift の参照コレクターおよび複数言語のサンプル検出器も同梱されています。防御的な RASP 型の自己保護、バックエンドのアテステーションパイプライン、高リスク操作を許可する前に侵害または計装されたランタイムを検出する必要がある承認済みセキュリティ評価向けに設計されています。
