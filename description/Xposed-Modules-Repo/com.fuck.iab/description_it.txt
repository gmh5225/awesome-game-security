FKIAB è un modulo Xposed per Android che intercetta e personalizza la fatturazione in-app su Google Play, Bazaar e Myket. È sviluppato principalmente in Kotlin con helper Java e uno strato nativo C++ che incorpora Frida Gum per eseguire script TypeScript compilati per ogni pacchetto target. Le funzionalità principali includono l'intercettazione dei binder del servizio di fatturazione, il ripristino degli articoli acquistati in precedenza e il caricamento di script globali o specifici per app per aggirare i controlli d'acquisto o sbloccare contenuti premium. Il progetto è rivolto a reverse engineer mobile e ricercatori di sicurezza dei giochi che devono analizzare o testare i flussi di acquisti in-app su dispositivi Android con root.
