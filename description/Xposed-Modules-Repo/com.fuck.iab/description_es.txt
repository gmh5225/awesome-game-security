FKIAB es un módulo Xposed para Android que intercepta y personaliza la facturación in-app en las tiendas Google Play, Bazaar y Myket. Está desarrollado principalmente en Kotlin con helpers en Java y una capa nativa en C++ que integra Frida Gum para ejecutar scripts TypeScript compilados por paquete objetivo. Las capacidades principales incluyen interceptar binders del servicio de facturación, restaurar artículos comprados previamente y cargar scripts globales o específicos de cada app para omitir verificaciones de compra o desbloquear contenido premium. El proyecto está dirigido a ingenieros de ingeniería inversa móvil e investigadores de seguridad de juegos que necesitan analizar o probar flujos de compras integradas en dispositivos Android con root.
