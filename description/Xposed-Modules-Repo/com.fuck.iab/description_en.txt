FKIAB is an Android Xposed module that hooks and customizes in-app billing across Google Play, Bazaar, and Myket storefronts. It is built primarily in Kotlin with Java helpers and a C++ native layer that embeds Frida Gum to run compiled TypeScript scripts per target package. Core capabilities include intercepting billing service binders, restoring previously purchased items, and loading global or app-specific scripts to bypass purchase checks or unlock premium content. The project targets mobile reverse engineers and game security researchers who need to analyze or test in-app purchase flows on rooted Android devices.
