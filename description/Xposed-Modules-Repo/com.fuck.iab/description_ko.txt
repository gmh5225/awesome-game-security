FKIAB는 Google Play, Bazaar, Myket 스토어의 앱 내 결제(IAB)를 후킹하고 사용자 정의하는 Android Xposed 모듈입니다. 주로 Kotlin으로 작성되었으며 Java 헬퍼와 Frida Gum을 내장한 C++ 네이티브 계층을 통해 대상 패키지별로 컴파일된 TypeScript 스크립트를 실행합니다. 핵심 기능으로는 billing service binder 가로채기, 이전에 구매한 항목 복원, 구매 확인 우회 또는 프리미엄 콘텐츠 잠금 해제를 위한 전역 또는 앱별 스크립트 로딩이 포함됩니다. rooted Android 기기에서 앱 내 구매 흐름을 분석하거나 테스트해야 하는 모바일 리버스 엔지니어 및 게임 보안 연구자를 대상으로 합니다.
