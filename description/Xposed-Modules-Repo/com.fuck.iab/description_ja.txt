FKIAB は、Google Play、Bazaar、Myket の各ストアにおけるアプリ内課金（IAB）をフックしてカスタマイズする Android 向け Xposed モジュールです。主に Kotlin で構築され、Java のヘルパーと Frida Gum を組み込んだ C++ ネイティブ層により、対象パッケージごとにコンパイル済み TypeScript スクリプトを実行します。主な機能は、billing service binder の傍受、以前に購入したアイテムの復元、購入チェックの回避やプレミアムコンテンツの解除のためのグローバルまたはアプリ固有スクリプトの読み込みです。root 化済み Android デバイス上でアプリ内購入フローを分析・テストする必要がある、モバイルリバースエンジニアおよびゲームセキュリティ研究者を対象としています。
