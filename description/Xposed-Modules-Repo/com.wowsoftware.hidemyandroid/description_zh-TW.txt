HideMyAndroid 是一款以隱私為導向的 Xposed/LSPosed 模組，適用於已 root 的 Android 9+ 裝置。它會攔截目標應用程式的識別碼與環境查詢，並回傳以設定檔為基礎的偽造值，以減少追蹤與裝置指紋辨識。支援遮蔽 Android ID、GAID、IMEI、Widevine DRM ID 等裝置識別碼，隱藏 root、LSPosed、VPN、代理與開發者模式，偽造 SIM、Wi-Fi、藍牙、GPS、時區與瀏覽器指紋，並依設定檔隔離帳戶與代理設定。基於 Xposed 鉤子框架建構，採用設定檔式配置系統，支援備份、還原與裝置模擬。面向研究或繞過應用程式層級反偵測與指紋檢查的使用者，涵蓋行動遊戲安全、反作弊規避及 Android 逆向工程研究等相關情境。
