HideMyAndroid 是一款面向隐私的 Xposed/LSPosed 模块，适用于已 root 的 Android 9+ 设备。它会拦截目标应用发起的标识符与环境查询，并返回基于配置文件的伪造值，以降低跟踪与设备指纹采集。该模块支持遮蔽 Android ID、GAID、IMEI、Widevine DRM ID 等设备标识，隐藏 root、LSPosed、VPN、代理与开发者模式，伪造 SIM、Wi-Fi、蓝牙、GPS、时区与浏览器指纹，并按配置文件隔离账户与代理设置。基于 Xposed 钩子框架构建，采用配置文件式配置系统，支持备份、恢复与设备模拟。面向研究或绕过应用级反检测与指纹校验的用户，涵盖与移动游戏安全、反作弊规避及 Android 逆向工程研究相关的场景。
