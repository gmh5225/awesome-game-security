Advanced-Anticheat is a client-server anti-cheat framework for Roblox games that detects movement exploits, executor injection, and environment tampering. Written in Luau, it combines a server-side movement watchdog with speed and fly detection, rubberbanding, and a client-side watchdog that monitors LogService and ScriptContext hooks, unauthorized GUI injection, ESP overlays, field-of-view changes, and common exploit executor signatures. The system uses remote handshakes, honeypot traps, service name obfuscation, configurable flag or immediate-ban enforcement, and ProfileStore-backed persistence for player flags, bans, and error logs. It is aimed at Roblox developers who want a drop-in anti-cheat layer with account-age gating, remote rate limiting, and detailed violation logging for live game security.
