Rootect 是一款 Android 函式庫，用於收集有關已 root 裝置、執行階段插樁、遭竄改應用程式以及不安全執行階段條件的環境完整性證據。它結合 Kotlin API 與原生 C++ 偵測器，後者透過原始系統呼叫和混淆字串來探測 Magisk、KernelSU、Frida、Xposed、重打包、除錯器與模擬器，並將偵測結果彙整為帶評分的風險報告。可選的 Android Key Attestation 支援可產生硬體簽署的憑證鏈，後端 attestation 伺服器可搭配裝置端訊號進行驗證。此函式庫不含任何第三方相依性，並包含範例應用程式與參考伺服器，方便整合與驗證流程。它面向開發行動遊戲與安全敏感 Android 應用的開發者，提供竄改與作弊偵測能力，而非單一的裝置端判定結果。
