Rootect 是一款 Android 库，用于收集有关已 root 设备、运行时插桩、被篡改应用以及不安全运行时条件的环境完整性证据。它将 Kotlin API 与原生 C++ 检测器相结合，后者通过原始系统调用和混淆字符串来探测 Magisk、KernelSU、Frida、Xposed、重打包、调试器和模拟器，并将检测结果汇总为带评分的风控报告。可选的 Android Key Attestation 支持可生成硬件签名的证书链，后端 attestation 服务器可结合设备端信号进行验证。该库不依赖任何第三方库，并包含示例应用和参考服务器，便于集成与验证流程。它面向开发移动游戏和安全敏感 Android 应用的开发者，提供篡改与作弊检测能力，而非单一的设备端判定结果。
