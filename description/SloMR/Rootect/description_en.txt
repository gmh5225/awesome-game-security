Rootect is an Android library that gathers environment-integrity evidence about rooted devices, runtime instrumentation, tampered apps, and unsafe runtime conditions. It combines Kotlin APIs with native C++ detectors that use raw syscalls and obfuscated strings to probe for Magisk, KernelSU, Frida, Xposed, repackaging, debuggers, and emulators, then aggregates findings into scored risk reports. Optional Android Key Attestation support produces hardware-signed certificate chains that a backend attestation server can verify alongside on-device signals. The library ships with no third-party dependencies and includes a sample app and reference server for integration and verification workflows. It targets developers building mobile games and security-sensitive Android apps who need tamper and cheat detection rather than a single on-device verdict.
