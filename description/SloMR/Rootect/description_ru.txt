Rootect — это библиотека для Android, которая собирает доказательства целостности среды, связанные с root-устройствами, инструментированием во время выполнения, подменёнными приложениями и небезопасными условиями выполнения. Она сочетает API на Kotlin с нативными детекторами на C++, использующими raw syscalls и обфусцированные строки для обнаружения Magisk, KernelSU, Frida, Xposed, репаковки, отладчиков и эмуляторов, а затем агрегирует результаты в оценённые отчёты о рисках. Опциональная поддержка Android Key Attestation формирует аппаратно подписанные цепочки сертификатов, которые сервер attestation на бэкенде может проверить вместе с сигналами с устройства. Библиотека поставляется без сторонних зависимостей и включает демонстрационное приложение и эталонный сервер для сценариев интеграции и проверки. Она ориентирована на разработчиков мобильных игр и Android-приложений с повышенными требованиями к безопасности, которым нужно обнаружение подмены и читов, а не единственный вердикт на устройстве.
