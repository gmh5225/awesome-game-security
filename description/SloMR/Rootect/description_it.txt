Rootect è una libreria Android che raccoglie prove sull'integrità dell'ambiente relative a dispositivi con root, strumentazione in runtime, app manomesse e condizioni di runtime non sicure. Combina API Kotlin con rilevatori nativi in C++ che usano syscall raw e stringhe offuscate per rilevare Magisk, KernelSU, Frida, Xposed, repackaging, debugger ed emulatori, quindi aggrega i risultati in report di rischio con punteggio. Il supporto opzionale di Android Key Attestation produce catene di certificati firmate dall'hardware che un server di attestation backend può verificare insieme ai segnali sul dispositivo. La libreria viene fornita senza dipendenze di terze parti e include un'app di esempio e un server di riferimento per flussi di integrazione e verifica. È rivolta agli sviluppatori che creano giochi mobile e app Android sensibili alla sicurezza e necessitano di rilevamento di manomissione e cheat piuttosto che di un singolo verdetto sul dispositivo.
