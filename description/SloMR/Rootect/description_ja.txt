Rootect は、root 化されたデバイス、ランタイム計装、改ざんされたアプリ、安全でないランタイム条件に関する環境整合性の証拠を収集する Android ライブラリです。Kotlin API と、raw syscall と難読化された文字列を用いて Magisk、KernelSU、Frida、Xposed、再パッケージ化、デバッガ、エミュレータを検知するネイティブ C++ 検出器を組み合わせ、検出結果をスコア付きのリスクレポートに集約します。オプションの Android Key Attestation サポートにより、バックエンドの attestation サーバーがデバイス上のシグナルとあわせて検証できる、ハードウェア署名付き証明書チェーンを生成できます。本ライブラリは第三者依存関係を持たず、サンプルアプリと参照サーバーを同梱し、統合および検証ワークフローに対応します。単一のデバイス上判定ではなく、改ざんおよびチート検知を必要とするモバイルゲームやセキュリティに敏感な Android アプリを開発する開発者を対象としています。
