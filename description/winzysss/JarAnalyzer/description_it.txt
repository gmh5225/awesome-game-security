Jar Analyzer è uno strumento desktop per Windows per rilevare cheat di Minecraft durante gli screenshare. Scansiona tutte le unità alla ricerca di file JAR tramite letture rapide della Master File Table NTFS, ispeziona il pool di costanti di ogni classe rispetto a una blacklist configurabile di termini legati ai cheat e segnala archivi offuscati, crittografati o camuffati come sospetti senza richiedere decompilazione. Lo strumento cerca anche nel cestino, analizza i processi Java in esecuzione per percorsi di cheat caricati e decomprime JAR annidati fino a due livelli di profondità. Sviluppato principalmente in Java con CFR per la decompilazione, ASM per l'analisi del bytecode e JNA per le API Windows, include uno scanner GUI e da riga di comando che esporta report di prove in formati testo, JSON e HTML.
