Jar Analyzer is a Windows desktop tool for detecting Minecraft cheats during screenshares. It scans every drive for JAR files using fast NTFS Master File Table reads, inspects each class constant pool against a configurable blacklist of cheat-related terms, and flags obfuscated, encrypted, or disguised archives as suspicious without requiring decompilation. The tool also searches the recycle bin, probes running Java processes for loaded cheat paths, and unpacks nested JARs up to two levels deep. Built primarily in Java with CFR for decompilation, ASM for bytecode analysis, and JNA for Windows APIs, it includes a GUI and command-line scanner that export evidence reports in text, JSON, and HTML formats.
