Jar Analyzer es una herramienta de escritorio para Windows que detecta trampas de Minecraft durante screenshares. Escanea todas las unidades en busca de archivos JAR mediante lecturas rápidas de la tabla maestra de archivos (MFT) de NTFS, inspecciona el pool de constantes de cada clase frente a una lista negra configurable de términos relacionados con trampas, y marca como sospechosos los archivos ofuscados, cifrados o disfrazados sin necesidad de descompilación. La herramienta también busca en la papelera de reciclaje, examina procesos Java en ejecución en busca de rutas de trampas cargadas y descomprime JAR anidados hasta dos niveles de profundidad. Desarrollada principalmente en Java con CFR para descompilación, ASM para análisis de bytecode y JNA para las API de Windows, incluye un escáner con GUI y línea de comandos que exporta informes de evidencia en formatos de texto, JSON y HTML.
