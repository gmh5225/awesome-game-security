Jar Analyzer 是一款 Windows 桌面工具，用于在屏幕共享审查期间检测 Minecraft 作弊程序。它通过快速读取 NTFS 主文件表（Master File Table）扫描所有驱动器中的 JAR 文件，将每个类的常量池与可配置的作弊相关术语黑名单进行比对，并在无需反编译的情况下标记混淆、加密或伪装的归档文件为可疑项。该工具还会搜索回收站、探测正在运行的 Java 进程中加载的作弊路径，并最多两层深度解包嵌套的 JAR 文件。主要使用 Java 构建，集成 CFR 用于反编译、ASM 用于字节码分析、JNA 用于 Windows API 调用，提供 GUI 和命令行扫描器，可导出文本、JSON 和 HTML 格式的证据报告。
