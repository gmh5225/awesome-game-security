Jar Analyzer — настольный инструмент для Windows, предназначенный для обнаружения читов Minecraft во время screenshare-проверок. Он сканирует все диски на наличие JAR-файлов с помощью быстрого чтения главной таблицы файлов (MFT) NTFS, проверяет пул констант каждого класса по настраиваемому чёрному списку терминов, связанных с читами, и без декомпиляции помечает обфусцированные, зашифрованные или замаскированные архивы как подозрительные. Инструмент также просматривает корзину, проверяет запущенные процессы Java на загруженные пути к читам и распаковывает вложенные JAR до двух уровней вглубь. Написан в основном на Java с использованием CFR для декомпиляции, ASM для анализа байткода и JNA для Windows API; включает GUI- и консольный сканер, экспортирующий отчёты с доказательствами в форматах text, JSON и HTML.
