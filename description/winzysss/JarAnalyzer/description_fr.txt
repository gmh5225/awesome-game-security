Jar Analyzer est un outil de bureau Windows conçu pour détecter les triches Minecraft lors des screenshares. Il analyse tous les lecteurs à la recherche de fichiers JAR grâce à une lecture rapide de la table des fichiers maîtres (MFT) NTFS, compare le pool de constantes de chaque classe à une liste noire configurable de termes liés aux triches, et signale les archives obfusquées, chiffrées ou dissimulées comme suspectes sans décompilation. L'outil recherche également la corbeille, sonde les processus Java en cours d'exécution pour détecter des chemins de triche chargés, et décompresse les JAR imbriqués sur deux niveaux au maximum. Développé principalement en Java avec CFR pour la décompilation, ASM pour l'analyse de bytecode et JNA pour les API Windows, il comprend un scanner GUI et en ligne de commande exportant des rapports de preuves aux formats texte, JSON et HTML.
