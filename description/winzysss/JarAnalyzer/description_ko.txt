Jar Analyzer는 스크린샤어 중 Minecraft 치트를 탐지하는 Windows 데스크톱 도구입니다. 빠른 NTFS 마스터 파일 테이블(MFT) 읽기를 통해 모든 드라이브에서 JAR 파일을 스캔하고, 각 클래스의 상수 풀을 구성 가능한 치트 관련 용어 블랙리스트와 대조하며, 난독화·암호화·위장된 아카이브를 디컴파일 없이도 의심스러운 항목으로 표시합니다. 또한 휴지통을 검색하고, 실행 중인 Java 프로세스에서 로드된 치트 경로를 조사하며, 중첩된 JAR을 최대 2단계 깊이까지 풀어냅니다. 주로 Java로 작성되었으며 CFR로 디컴파일, ASM으로 바이트코드 분석, JNA로 Windows API를 활용하고, GUI 및 명령줄 스캐너를 통해 텍스트, JSON, HTML 형식의 증거 보고서를 내보낼 수 있습니다.
