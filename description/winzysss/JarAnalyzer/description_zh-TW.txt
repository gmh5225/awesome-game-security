Jar Analyzer 是一款 Windows 桌面工具，用於在螢幕共享審查期間偵測 Minecraft 作弊程式。它透過快速讀取 NTFS 主檔案表（Master File Table）掃描所有磁碟機中的 JAR 檔案，將每個類別的常數池與可設定的作弊相關術語黑名單進行比對，並在無需反編譯的情況下標記混淆、加密或偽裝的封存檔為可疑項目。此工具還會搜尋資源回收筒、探測正在執行的 Java 程序中載入的作弊路徑，並最多兩層深度解壓縮嵌套的 JAR 檔案。主要使用 Java 建構，整合 CFR 用於反編譯、ASM 用於位元組碼分析、JNA 用於 Windows API 呼叫，提供 GUI 和命令列掃描器，可匯出文字、JSON 和 HTML 格式的證據報告。
