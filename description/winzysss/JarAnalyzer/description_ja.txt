Jar Analyzer は、スクリーンシェア中に Minecraft のチートを検出するための Windows デスクトップツールです。高速な NTFS マスターファイルテーブル読み取りを用いて全ドライブから JAR ファイルをスキャンし、各クラスの定数プールを設定可能なチート関連用語のブラックリストと照合し、難読化・暗号化・偽装されたアーカイブを逆コンパイルなしで疑わしいものとしてフラグ付けします。またごみ箱を検索し、実行中の Java プロセスから読み込まれたチートパスを調査し、ネストされた JAR を最大 2 階層まで展開します。主に Java で構築され、CFR による逆コンパイル、ASM によるバイトコード解析、JNA による Windows API 呼び出しを備え、GUI およびコマンドラインスキャナーからテキスト、JSON、HTML 形式の証拠レポートを出力できます。
