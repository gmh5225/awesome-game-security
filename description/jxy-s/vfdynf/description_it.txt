vfdynf è un provider di Windows Application Verifier che implementa Dynamic Fault Injection (DynFault), un'alternativa basata sull'hash dello stack ai test Low Resource Simulation integrati per simulare sistematicamente i fallimenti da scarsità di risorse e fare fuzzing dell'accesso alle risorse del sistema operativo. Scritto principalmente in C e C++, intercetta le API wait, heap, virtual memory, registry, file, event, section e OLE, e può opzionalmente fare fuzzing dei buffer di registry, file, section mapping e network read per esporre errori logici e vulnerabilità time-of-check-time-of-use. A differenza del LowRes randomizzato, DynFault traccia stack di chiamate univoci per migliorare la copertura e supporta esclusioni tramite espressioni regolari PCRE2, così percorsi di codice specifici, come le allocazioni di iteratori di debug MSVC, possono essere esclusi dall'iniezione di fault. Si integra con Application Verifier tramite vfdynf.dll ed è rivolto a sviluppatori e ricercatori di sicurezza che necessitano di iniezione di fault e fuzzing Windows configurabili per test di robustezza, carichi di stress e scoperta di vulnerabilità.
