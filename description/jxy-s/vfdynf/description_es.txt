vfdynf es un proveedor de Windows Application Verifier que implementa Dynamic Fault Injection (DynFault), una alternativa basada en hash de pila a las pruebas Low Resource Simulation integradas para simular sistemáticamente fallos por escasez de recursos y hacer fuzzing del acceso a recursos del sistema operativo. Escrito principalmente en C y C++, engancha las API wait, heap, virtual memory, registry, file, event, section y OLE, y puede fuzzear opcionalmente los búferes de registry, file, section mapping y network read para exponer errores lógicos y vulnerabilidades time-of-check-time-of-use. A diferencia del LowRes aleatorizado, DynFault rastrea pilas de llamadas únicas para mejorar la cobertura y admite exclusiones con expresiones regulares PCRE2, de modo que rutas de código específicas, como las asignaciones de iteradores de depuración de MSVC, pueden omitirse de la inyección de fallos. Se integra con Application Verifier mediante vfdynf.dll y está dirigido a desarrolladores e investigadores de seguridad que necesitan inyección de fallos y fuzzing configurables en Windows para pruebas de robustez, cargas de estrés y descubrimiento de vulnerabilidades.
