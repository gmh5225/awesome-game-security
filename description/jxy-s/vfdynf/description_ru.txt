vfdynf — это провайдер Windows Application Verifier, реализующий Dynamic Fault Injection (DynFault), альтернативу встроенным тестам Low Resource Simulation на основе хеширования стека для систематической симуляции сбоев при нехватке ресурсов и фаззинга доступа к ресурсам ОС. Написанный преимущественно на C и C++, он перехватывает API wait, heap, virtual memory, registry, file, event, section и OLE и может опционально фаззить буферы registry, file, section mapping и network read, выявляя логические ошибки и уязвимости time-of-check-time-of-use. В отличие от рандомизированного LowRes, DynFault отслеживает уникальные стеки вызовов для улучшения покрытия и поддерживает исключения по регулярным выражениям PCRE2, позволяя исключать из инъекции сбоев определённые пути кода, например выделения отладочных итераторов MSVC. Интегрируется с Application Verifier через vfdynf.dll и предназначен для разработчиков и исследователей безопасности, которым нужна настраиваемая инъекция сбоев и фаззинг Windows для тестов устойчивости, стрессовых нагрузок и поиска уязвимостей.
