vfdynf は Windows Application Verifier プロバイダーで、Dynamic Fault Injection（DynFault）を実装しています。これは組み込みの Low Resource Simulation テストに代わるスタックハッシュベースの方式で、低リソース障害を体系的にシミュレートし、OS リソースアクセスをファジングします。主に C と C++ で書かれ、wait、heap、virtual memory、registry、file、event、section、OLE などの API をフックし、オプションで registry、file、section mapping、network read バッファをファジングして、ロジックエラーや time-of-check-time-of-use 脆弱性を露呈できます。ランダム化された LowRes とは異なり、DynFault は一意のコールスタックを追跡してカバレッジを向上させ、PCRE2 正規表現による除外をサポートするため、MSVC デバッグイテレーター割り当てなど特定のコードパスを故障注入から除外できます。vfdynf.dll 経由で Application Verifier と統合され、堅牢性テスト、ストレスワークロード、脆弱性発見のために、設定可能な Windows 故障注入とファジングを必要とする開発者やセキュリティ研究者向けです。
