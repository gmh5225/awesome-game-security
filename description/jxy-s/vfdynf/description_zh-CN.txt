vfdynf 是一个 Windows Application Verifier 提供程序，实现了 Dynamic Fault Injection（DynFault），这是一种基于栈哈希的替代方案，用于替代内置的 Low Resource Simulation 测试，以系统化地模拟低资源故障并对 OS 资源访问进行模糊测试。它主要用 C 和 C++ 编写，挂钩 wait、heap、virtual memory、registry、file、event、section 和 OLE 等 API，并可选择对 registry、file、section mapping 和 network read 缓冲区进行模糊测试，以暴露逻辑错误和 time-of-check-time-of-use 漏洞。与随机化的 LowRes 不同，DynFault 跟踪唯一调用栈以提高覆盖率，并支持 PCRE2 正则表达式排除，从而可省略特定代码路径（例如 MSVC 调试迭代器分配）的故障注入。它通过 vfdynf.dll 与 Application Verifier 集成，面向需要可配置 Windows 故障注入与模糊测试的开发者和安全研究人员，用于健壮性测试、压力负载和漏洞发现。
