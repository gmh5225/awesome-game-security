vfdynf is a Windows Application Verifier provider that implements Dynamic Fault Injection (DynFault), a stack-hash-based alternative to the built-in Low Resource Simulation tests for systematically simulating low-resource failures and fuzzing OS resource access. Written primarily in C and C++, it hooks wait, heap, virtual memory, registry, file, event, section, and OLE APIs, and can optionally fuzz registry, file, section mapping, and network read buffers to expose logic errors and time-of-check-time-of-use vulnerabilities. Unlike randomized LowRes, DynFault tracks unique call stacks to improve coverage and supports PCRE2 regular-expression exclusions so specific code paths, such as MSVC debug iterator allocations, can be omitted from fault injection. It integrates with Application Verifier via vfdynf.dll and is aimed at developers and security researchers who need configurable Windows fault injection and fuzzing for robustness testing, stress workloads, and vulnerability discovery.
