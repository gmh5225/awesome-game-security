vfdynf는 Windows Application Verifier 프로바이더로, Dynamic Fault Injection(DynFault)을 구현합니다. 이는 내장 Low Resource Simulation 테스트를 대체하는 스택 해시 기반 방식으로, 저자원 장애를 체계적으로 시뮬레이션하고 OS 리소스 접근을 퍼징합니다. 주로 C와 C++로 작성되었으며 wait, heap, virtual memory, registry, file, event, section, OLE API를 후킹하고, 선택적으로 registry, file, section mapping, network read 버퍼를 퍼징하여 논리 오류와 time-of-check-time-of-use 취약점을 드러낼 수 있습니다. 무작위 LowRes와 달리 DynFault는 고유 호출 스택을 추적해 커버리지를 높이며, PCRE2 정규식 제외를 지원하여 MSVC 디버그 이터레이터 할당과 같은 특정 코드 경로를 결함 주입에서 제외할 수 있습니다. vfdynf.dll을 통해 Application Verifier와 통합되며, 견고성 테스트, 스트레스 워크로드, 취약점 발견을 위해 구성 가능한 Windows 결함 주입 및 퍼징이 필요한 개발자와 보안 연구자를 대상으로 합니다.
