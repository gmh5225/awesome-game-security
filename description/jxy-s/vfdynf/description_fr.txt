vfdynf est un fournisseur Windows Application Verifier qui implémente Dynamic Fault Injection (DynFault), une alternative basée sur le hachage de pile aux tests Low Resource Simulation intégrés pour simuler systématiquement les défaillances liées aux faibles ressources et fuzzer l'accès aux ressources du système d'exploitation. Écrit principalement en C et C++, il intercepte les API wait, heap, virtual memory, registry, file, event, section et OLE, et peut optionnellement fuzzer les tampons de registry, file, section mapping et network read afin de révéler des erreurs logiques et des vulnérabilités time-of-check-time-of-use. Contrairement au LowRes randomisé, DynFault suit les piles d'appels uniques pour améliorer la couverture et prend en charge les exclusions par expressions régulières PCRE2 afin d'omettre l'injection de fautes sur des chemins de code spécifiques, comme les allocations d'itérateurs de débogage MSVC. Il s'intègre à Application Verifier via vfdynf.dll et s'adresse aux développeurs et chercheurs en sécurité qui ont besoin d'une injection de fautes et d'un fuzzing Windows configurables pour les tests de robustesse, les charges de stress et la découverte de vulnérabilités.
