NimJump는 최소한의 클라이언트 권한 설계로 암호화폐 보상을 안전하게 배포하도록 만든 브라우저 기반 캐주얼 플랫폼 게임입니다. Godot 4 클라이언트는 WebAssembly 내보내기로 실행되며, Go 백엔드는 결정론적 맵 생성과 서버 측 리플레이 검증(네이티브 replay-verifier 빌드)으로 게임플레이를 검증합니다. 오프라인 세션은 서버 서명 시드 배치, 서명된 클라이언트 API 요청, 속도 제한·IP 보상 검사·실패 리플레이 및 분석용 관리 도구 등의 보호 장치에 의존합니다. Next.js 관리 대시보드는 플레이어, 세션, 리더보드, 리플레이 무결성을 모니터링합니다. 본 프로젝트는 반치트, 리플레이 증명, 보상 남용 방지에 대한 실제 프로덕션 수준 참고 자료를 원하는 게임 보안 실무자를 대상으로 합니다.
