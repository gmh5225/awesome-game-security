NimJump is a browser-based casual platformer built to distribute cryptocurrency rewards safely through a minimal client-authority design. The Godot 4 client runs as a WebAssembly export while a Go backend validates gameplay using deterministic map generation and server-side replay verification with a native replay-verifier build. Offline sessions rely on batches of server-signed seeds, signed client API requests, and supporting guards such as rate limits, IP reward checks, and admin tooling for failed replays and analytics. A Next.js admin dashboard monitors players, sessions, leaderboards, and replay integrity. The project is aimed at game security practitioners who want a real production-style reference for anti-cheat, replay attestation, and reward abuse prevention.
