NimJump — браузерный казуальный платформер, созданный для безопасной раздачи криптовалютных наград за счёт архитектуры с минимальной клиентской авторитетностью. Клиент Godot 4 работает как WebAssembly-экспорт, а бэкенд на Go проверяет геймплей с помощью детерминированной генерации карт и серверной верификации реплеев с нативной сборкой replay-verifier. Офлайн-сессии опираются на пакеты серверно подписанных сидов, подписанные клиентские API-запросы и защитные меры: лимиты частоты, проверки наград по IP и админ-инструменты для неудачных реплеев и аналитики. Админ-панель на Next.js отслеживает игроков, сессии, таблицы лидеров и целостность реплеев. Проект ориентирован на специалистов по безопасности игр, которым нужен близкий к продакшену образец античита, аттестации реплеев и защиты от злоупотребления наградами.
