NimJump は、最小限のクライアント権威設計により暗号資産報酬を安全に配布するブラウザ向けカジュアルプラットフォーマーです。Godot 4 クライアントは WebAssembly エクスポートとして動作し、Go バックエンドは決定論的マップ生成とサーバー側リプレイ検証（ネイティブ replay-verifier ビルド）でゲームプレイを検証します。オフラインセッションは、サーバー署名済みシードのバッチ、署名付きクライアント API リクエスト、レート制限・IP 報酬チェック・失敗リプレイと分析用の管理ツールなどのガードに依存します。Next.js の管理ダッシュボードでプレイヤー、セッション、リーダーボード、リプレイ整合性を監視します。本プロジェクトは、反チート、リプレイ証明、報酬悪用防止の実運用に近い参考例を求めるゲームセキュリティ実務者向けです。
