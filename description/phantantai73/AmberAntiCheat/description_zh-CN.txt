AmberAntiCheat 是一款面向 Paper 与 Spigot 服务端插件，为 Minecraft 多人生存世界集成反作弊、反 X 射线与反 ESP 防护。项目使用 Java 21 与 Maven 构建，结合 Paper API 与 PacketEvents，检测移动与战斗数据包中的攻击距离、每秒点击次数及计时类违规。服务端模块包含异步遮挡引擎、针对 X 射线与方块 ESP 的矿石与箱子隐藏、按 Y 层与视线分割的玩家可见性规则，以及 watch、freeze、reload、七模块设置 GUI 与嫌疑名单流程等游戏内管理工具。面向希望以一体化、20 TPS 导向加固方案替代独立 PC 客户端反作弊的 SMP 服主与管理人员。
