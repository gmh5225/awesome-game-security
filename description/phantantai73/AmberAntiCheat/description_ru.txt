AmberAntiCheat — плагин для серверов Paper и Spigot, объединяющий античит, защиту от X-ray и anti-ESP для многопользовательских миров выживания в Minecraft. Написан на Java 21 с Maven, использует Paper API и PacketEvents для проверки пакетов движения и боя на reach, CPS и нарушения типа timer. Серверные модули включают асинхронный движок окклюзии, скрытие руд и сундуков против X-ray и block ESP, правила видимости игроков по слою Y и линии обзора, а также внутриигровые админ-инструменты: watch, freeze, reload, GUI настроек из семи модулей и workflow списка подозреваемых. Ориентирован на операторов и персонал SMP, которым нужен единый стек усиления с упором на 20 TPS, а не отдельный античит для PC-клиента.
