AmberAntiCheat is a Paper and Spigot server plugin that bundles anti-cheat, anti-x-ray, and anti-ESP protections for Minecraft multiplayer survival worlds. It is written in Java 21 with Maven and integrates the Paper API plus PacketEvents to inspect movement and combat packets for reach, clicks-per-second, and timer-style violations. Server-side modules include an asynchronous occlusion engine, ore and chest hiding to counter x-ray and block ESP, player visibility rules split by Y layer and line-of-sight, and in-game admin tools such as watch, freeze, reload, a seven-module settings GUI, and a suspect list workflow. It targets SMP operators and staff who want an all-in-one, 20 TPS-oriented hardening stack rather than a standalone PC game client anti-cheat.
