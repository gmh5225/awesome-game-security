本仓库是一套 Android 系统修改方案，面向已 root 的手机，将无系统 Magisk 与 KernelSU 模块同 LSPosed 钩子模块结合使用。它提供一体化的 Play Integrity 与 Tricky Store 套件，用于伪造构建属性与硬件密钥库 attestation；通过运行时 Java 钩子实现 Microsoft 工作应用的 Intune 与 MAM 合规绕过；并包含 AOD 亮度稳定、在 AOSP 风格 ROM 上移除键盘下巴等额外调整。多数组件用 Java 与 Gradle 为 Android 构建，模块交付依赖 shell 安装脚本、Zygisk 原生注入以及用于打包的小型 Python 辅助工具。面向 HyperOS、MIUI 及自定义 AOSP ROM 用户，用于研究或规避设备完整性、企业合规与 attestation——这些信号也被许多手游与反作弊栈用来判定 root 或修改过的设备。
