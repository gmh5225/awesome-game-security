Este repositorio es un conjunto de modificaciones del sistema Android que combina módulos Magisk y KernelSU sin modificar el sistema con módulos de hook LSPosed para teléfonos con root. Incluye paquetes todo en uno de Play Integrity y Tricky Store para falsificar propiedades de compilación y la attestation del almacén de claves de hardware, una omisión de cumplimiento Intune y MAM para aplicaciones de trabajo de Microsoft mediante hooks Java en tiempo de ejecución, y ajustes adicionales como la estabilización del brillo AOD y la eliminación del «chin» del teclado en ROMs al estilo AOSP. La mayoría de los componentes se construyen con Java y Gradle para Android, mientras que la entrega de módulos depende de instaladores shell, inyección nativa Zygisk y un pequeño auxiliar en Python para empaquetar. Está dirigido a usuarios de HyperOS, MIUI y ROM AOSP personalizadas que estudian o eluden la integridad del dispositivo, el cumplimiento empresarial y la attestation — las mismas señales que muchos juegos móviles y stacks antitrampas usan para juzgar dispositivos con root o modificados.
