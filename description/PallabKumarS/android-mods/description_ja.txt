本リポジトリは、root 済み端末向けに、システムレスの Magisk および KernelSU モジュールと LSPosed フックモジュールを組み合わせた Android システム改変スイートです。ビルドプロパティやハードウェアキーストアの attestation を偽装する Play Integrity および Tricky Store のオールインワンパッケージ、実行時 Java フックによる Microsoft 業務アプリ向け Intune・MAM コンプライアンス回避、AOSP 系 ROM での AOD 輝度安定化やキーボード chin 除去などの追加 tweak を同梱します。主要コンポーネントは Java と Gradle で Android 向けにビルドされ、モジュール配布は shell インストーラ、Zygisk ネイティブ注入、パッケージング用の小さな Python ヘルパーに依存します。HyperOS、MIUI、カスタム AOSP ROM の利用者を対象とし、デバイス整合性、エンタープライズコンプライアンス、attestation の研究や回避を目的とします——これらは多くのモバイルゲームやアンチチートが root や改変端末を判定する際に用いる信号と同種です。
