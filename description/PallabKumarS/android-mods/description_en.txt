This repository is a suite of Android system modifications that combines systemless Magisk and KernelSU modules with LSPosed hook modules for rooted phones. It ships all-in-one Play Integrity and Tricky Store packages to spoof build properties and hardware keystore attestation, an Intune and MAM compliance bypass for Microsoft work apps via runtime Java hooks, and additional tweaks such as AOD brightness stabilization and removal of the keyboard chin on AOSP-style ROMs. Most components are built with Java and Gradle for Android, while module delivery relies on shell installers, Zygisk native injection, and a small Python helper for packaging. It is aimed at users of HyperOS, MIUI, and custom AOSP ROMs who study or work around device integrity, enterprise compliance, and attestation—the same signals many mobile games and anti-cheat stacks use to judge rooted or modified devices.
