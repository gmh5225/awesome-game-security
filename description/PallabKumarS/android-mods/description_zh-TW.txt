本儲存庫是一套 Android 系統修改方案，面向已 root 的手機，將無系統 Magisk 與 KernelSU 模組同 LSPosed 鉤子模組結合使用。它提供一體化的 Play Integrity 與 Tricky Store 套件，用於偽造建置屬性與硬體金鑰庫 attestation；透過執行階段 Java 鉤子實現 Microsoft 工作應用的 Intune 與 MAM 合規繞過；並包含 AOD 亮度穩定、在 AOSP 風格 ROM 上移除鍵盤下巴等額外調整。多數元件以 Java 與 Gradle 為 Android 建置，模組交付依賴 shell 安裝腳本、Zygisk 原生注入以及用於封裝的小型 Python 輔助工具。面向 HyperOS、MIUI 及自訂 AOSP ROM 使用者，用於研究或規避裝置完整性、企業合規與 attestation——這些訊號也被許多手遊與反作弊堆疊用來判定 root 或修改過的裝置。
