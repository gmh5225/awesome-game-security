It is a Windows x64 command-line protector that hardens PE executables and writes a new protected binary. Protection is driven by TOML project files and optional Lua hooks for compile-time scripting, with per-procedure modes such as virtualization, mutation, and ultra plus tuning for segments, resources, and imports. Embedded resources can be compressed with LZMA or Zstandard, and the tool supports licensing parameters, watermarks, build dates, and a license manager configuration. It targets developers who need client-side binary obfuscation and anti-tamper style hardening for game security, anti-cheat research, and reverse-engineering defense on authorized software.
