VPN Hide は、Android の root 権限を利用し、多層の隠蔽アーキテクチャによってユーザーが選択したアプリからアクティブな VPN 接続を隠すツールです。system_server の Binder レベルで VPN 関連データをフィルタリングする LSPosed モジュールと、kretprobes を用いた GKI カーネルモジュール、非 GKI カーネル向けの KernelPatch モジュール、または Zygisk フォールバックといったネイティブバックエンドを組み合わせ、ioctl、netlink、/proc/net などの検出経路を結果が対象プロセスに届く前に傍受します。オプションの ports モジュールは、Clash や sing-box などのローカル VPN やプロキシデーモンを検出するための localhost プローブをブロックします。Kotlin を主に用い、Rust と C のネイティブコンポーネントを含むコンパニオンアプリは、アプリごとの Java、Native、Apps、Ports ロール設定、組み込み診断、およびアプリによる VPN 検出の試行に関する統計を提供します。銀行、政府、小売などの堅牢化された Android アプリにおけるクライアント側 VPN フィンガープリンティングを、対象プロセスへのフック注入なしに回避する必要があるユーザーと研究者を対象としています。
