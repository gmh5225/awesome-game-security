VPN Hide is an Android root-based tool that hides an active VPN connection from user-selected apps through a multi-layered hiding architecture. It combines an LSPosed module that filters VPN-related data at the system_server Binder level with native backends—a GKI kernel module using kretprobes, a KernelPatch Module for non-GKI kernels, or a Zygisk fallback—that intercept ioctl, netlink, and /proc/net detection paths before results reach target processes. An optional ports module blocks localhost probing used to detect local VPN or proxy daemons such as Clash and sing-box. The companion app, written primarily in Kotlin with Rust and C native components, provides per-app Java, Native, Apps, and Ports role configuration, built-in diagnostics, and statistics on how apps attempt VPN detection. It is aimed at users and researchers who need to bypass client-side VPN fingerprinting in banking, government, retail, and similarly hardened Android apps without injecting hooks into the target process.
