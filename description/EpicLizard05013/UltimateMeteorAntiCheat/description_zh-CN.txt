UltimateMeteorAntiCheat 是一款基于 Java 的 Minecraft Paper 服务器插件，为多人联机生存服务器提供反作弊检测与防复制保护。它实现战斗检测，包括攻击距离（reach）、自动点击（autoclicker）和瞄准取模（aim-modulo）检测，移动检测涵盖飞行、加速、无摔落（nofall）和水上行走（jesus）等漏洞，世界检测则针对快速放置（fastplace）和脚手架滥用。该插件还通过库存交易审计、嵌套容器限制和数据包不同步缓解措施，阻断常见的物品复制途径。违规行为通过可配置的升级阶梯进行跟踪，支持日志记录、白名单、管理员命令以及可选的 Discord webhook 通知。面向需要在 Paper 1.21.x 上实现服务端作弊与漏洞防护的服务器管理员。
