UltimateMeteorAntiCheat 是一款以 Java 為基礎的 Minecraft Paper 伺服器外掛，為多人連線生存伺服器結合反作弊偵測與防複製保護。它實作戰鬥檢查，包括攻擊距離（reach）、自動點擊（autoclicker）和瞄準取模（aim-modulo）偵測，移動檢查涵蓋飛行、加速、無摔落（nofall）和水上行走（jesus）等漏洞，世界檢查則針對快速放置（fastplace）和鷹架濫用。此外，外掛透過背包交易稽核、嵌套容器限制及封包不同步緩解措施，阻斷常見的物品複製途徑。違規行為以可設定的升級階梯追蹤，支援記錄、白名單、管理員指令及選用的 Discord webhook 通知。適合需要在 Paper 1.21.x 上進行伺服器端作弊與漏洞防護的伺服器營運者。
