Этот проект представляет собой 32-битную DLL-плагин античита для Windows, интегрирующую Easy Anti-Cheat через SDK Epic Online Services (EOS) для использования в качестве промежуточного ПО в сетевых многопользовательских играх. Написан на C++20 и собирается с помощью CMake, реализует интерфейс плагина хост-игры для инициализации, регистрации игроков, управления сессиями и обработки нарушений целостности и требуемых действий игроков через callback-механизм. Плагин также обеспечивает собственный защищённый игровой транспорт, маршрутизируя игровой и античит-трафик через P2P-сеть EOS, включая отслеживание состояния соединений, измерение задержки и аутентификацию пиров. Разработчики настраивают учётные данные продукта и развёртывания EOS на этапе компиляции и должны отдельно предоставить x86 SDK EOS. Предназначен для разработчиков игр и мод-команд, добавляющих античит и защищённую сеть производственного уровня в унаследованные или пользовательские онлайн-проекты.
