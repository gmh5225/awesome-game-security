This project is a Windows 32-bit anti-cheat plugin DLL that integrates Easy Anti-Cheat through the Epic Online Services (EOS) SDK for use as middleware in online multiplayer games. Written in C++20 and built with CMake, it implements the host game's plugin interface for initialization, player registration, session management, and callback-driven handling of integrity violations and required player actions. The plugin also provides its own secure game transport by routing both gameplay and anti-cheat traffic over EOS P2P networking, including connection state tracking, latency measurement, and peer authentication. Developers configure EOS product and deployment credentials at compile time and must supply the x86 EOS SDK separately. It is intended for game developers and mod teams adding production-grade anti-cheat and secure networking to legacy or custom online titles.
