Bemaniutils is a Python toolkit for analyzing, modifying, and emulating Konami BEMANI arcade rhythm games and their eAmusement network services. It includes utilities to unpack and repack proprietary asset formats such as IFS, 2DX, AFP/BSI animations, and encrypted NVRAM data, along with libraries that implement the binary eAmusement wire protocol. The project provides network analysis and reverse engineering tools including packet sniffers, MITM proxies, traffic replay, and psmap-based response generators for black-box protocol research. It also ships a full hobby eAmusement server stack with game backends for titles like Beatmania IIDX, DDR, Pop'n Music, and Sound Voltex, aimed at preservationists and researchers studying legacy arcade game security and networking.
