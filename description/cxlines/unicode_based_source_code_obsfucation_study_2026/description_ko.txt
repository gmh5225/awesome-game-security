이 저장소는 Python 소스 코드에서 Unicode 기반 난독화에 대한 읽기 전용 정적 탐지기를 비교하는 재현 가능한 실증 벤치마크 및 연구 패키지입니다. 코드 포인트 단위 스캔에서 어휘 토큰 검사, AST 및 심볼 테이블 인식 규칙까지 단계적으로 강화하는 분석기를 구현하며, 혼합 스크립트 및 문맥 텍스트 처리를 포함한 확장 변형도 제공하고, CPython 3.14.7과 Unicode 16.0.0 표에서 고정된 Ruff linter 구성에 대해 벤치마크합니다. 연구는 양방향 제어 문자, 혼동 가능 식별자, 기본 무시 가능 문자, NFKC 관련 철자를 다루는 수작업 비활성 픽스처와 샘플링한 상류 릴리스 아카이브를 짝지어 로컬라이제이션 및 경고 지표를 부트스트랩 구간과 함께 기록하고, 잠금 입력 가져오기, 코퍼스 재구축, 테스트 실행, 원고 그림 재생성 스크립트를 제공하며 분석 대상 제3자 소스는 실행하지 않습니다. 공급망 및 코드 리뷰 워크플로에서 동형 문자·서식 공격 탐지와 합법적인 다국어 또는 테스트 데이터에 대한 오경보 사이의 정량적 트레이드오프가 필요한 보안 연구자, 정적 분석 엔지니어, 리뷰어를 대상으로 한다.
