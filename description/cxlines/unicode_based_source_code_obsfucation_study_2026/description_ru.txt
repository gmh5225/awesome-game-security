Это воспроизводимый эмпирический бенчмарк и исследовательский пакет, сравнивающий статические детекторы только для чтения, нацеленные на обфускацию на основе Unicode в исходном коде Python. Реализованы нарастающие по сложности анализаторы — от построчного сканирования кодовых точек через проверки лексических токенов до правил с учётом AST и таблицы символов, включая расширенный вариант со смешанными письменностями и контекстной обработкой текста; они сопоставляются с фиксированной конфигурацией линтера Ruff на CPython 3.14.7 с таблицами Unicode 16.0.0. Исследование сочетает вручную подготовленные инертные фикстуры (двунаправленные управляющие символы, спутываемые идентификаторы, игнорируемые по умолчанию символы и написания, связанные с NFKC) с выборочными архивами upstream-релизов, фиксирует метрики локализации и предупреждений с bootstrap-интервалами и поставляет сценарии для загрузки зафиксированных входных данных, пересборки корпусов, запуска тестов и регенерации иллюстраций рукописи без выполнения анализируемых сторонних исходников. Адресовано исследователям безопасности, инженерам статического анализа и рецензентам, которым нужны количественные компромиссы между обнаружением гомоглифных и форматирующих атак и ложными срабатываниями на легитимных многоязычных или тестовых данных в цепочках поставок и процессах ревью кода.
