This is a reproducible empirical benchmark and research package that compares read-only static detectors for Unicode-based obfuscation in Python source code. It implements escalating analyzers from per-code-point scans through lexical token checks to AST and symbol-table aware rules, including an extended variant with mixed-script and contextual text handling, and benchmarks them against a fixed Ruff linter configuration on CPython 3.14.7 with Unicode 16.0.0 tables. The study pairs handcrafted inert fixtures covering bidirectional controls, confusable identifiers, default-ignorable characters, and NFKC-related spellings with sampled upstream release archives, records localization and alert metrics with bootstrap intervals, and ships scripts to fetch locked inputs, rebuild corpora, run tests, and regenerate manuscript figures without executing the analyzed third-party sources. It targets security researchers, static-analysis engineers, and reviewers who need quantified tradeoffs between catching homoglyph and formatting attacks and false alerts on legitimate multilingual or test data in supply-chain and code-review workflows.
