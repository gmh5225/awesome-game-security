本リポジトリは、Python ソースコードにおける Unicode ベースの難読化に対する読み取り専用静的検出器を比較する、再現可能な実証ベンチマークおよび研究パッケージである。コードポイント単位の走査から字句トークン検査、AST およびシンボルテーブル対応ルールまで段階的に強化するアナライザを実装し、混合スクリプトおよび文脈テキスト処理を含む拡張版も備え、CPython 3.14.7 と Unicode 16.0.0 表上で固定の Ruff linter 設定に対してベンチマークする。研究では、双方向制御文字、紛らわしい識別子、デフォルト無視可能文字、NFKC 関連綴りをカバーする手作りの非活性フィクスチャと、サンプリングした上流リリースアーカイブを組み合わせ、ローカライゼーションとアラート指標をブートストラップ区間付きで記録し、ロック済み入力の取得、コーパス再構築、テスト実行、原稿図の再生成を行うスクリプトを同梱する（分析対象の第三者ソースは実行しない）。サプライチェーンやコードレビューのワークフローにおいて、ホモグリフ攻撃や書式攻撃の検出と、正当な多言語データやテストデータに対する誤検知の定量的トレードオフを必要とするセキュリティ研究者、静的解析エンジニア、査読者を対象とする。
