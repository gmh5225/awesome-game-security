這是一套可重現的實證基準與研究套件，用於比較針對 Python 原始碼中基於 Unicode 的混淆之唯讀靜態偵測器。其實作了從逐碼點掃描、詞法 token 檢查到 AST 與符號表感知規則的逐級強化分析器，包括具混合書寫體與脈絡文字處理的擴充變體，並在 CPython 3.14.7 與 Unicode 16.0.0 表上對固定 Ruff linter 設定進行基準測試。研究將手工打造的惰性夾具（涵蓋雙向控制符、易混淆識別碼、預設可忽略字元及 NFKC 相關拼寫）與取樣的上游發行封存配對，記錄在地化與警示指標及 bootstrap 信賴區間，並提供指令碼以取得鎖定輸入、重建語料、執行測試並重新產生文稿圖表，且無需執行被分析的第三方原始碼。面向需要在供應鏈與程式碼審查流程中量化「捕捉同形字與格式攻擊」與「對合法多語言或測試資料的誤報」之間權衡的安全研究人員、靜態分析工程師與審稿人。
