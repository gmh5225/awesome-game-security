这是一套可复现的实证基准与研究包，用于比较针对 Python 源代码中基于 Unicode 的混淆的只读静态检测器。其实现了从逐码点扫描、词法 token 检查到 AST 与符号表感知规则的逐级增强分析器，包括带混合书写体与上下文文本处理的扩展变体，并在 CPython 3.14.7 与 Unicode 16.0.0 表上对固定 Ruff linter 配置进行基准测试。研究将手工构造的惰性夹具（覆盖双向控制符、易混淆标识符、默认可忽略字符及 NFKC 相关拼写）与采样的上游发布归档配对，记录本地化与告警指标及 bootstrap 置信区间，并提供脚本以获取锁定输入、重建语料库、运行测试并重新生成手稿图表，且无需执行被分析的第三方源码。面向需要在供应链与代码审查流程中量化「捕捉同形字与格式攻击」与「对合法多语言或测试数据的误报」之间权衡的安全研究人员、静态分析工程师与审稿人。
