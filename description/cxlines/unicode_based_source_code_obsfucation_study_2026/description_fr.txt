Il s’agit d’un benchmark empirique reproductible et d’un paquet de recherche qui compare des détecteurs statiques en lecture seule pour l’obfuscation fondée sur Unicode dans le code source Python. Il met en œuvre des analyseurs par paliers, des analyses point par point de code aux contrôles de jetons lexicaux, jusqu’aux règles tenant compte de l’AST et de la table des symboles, y compris une variante étendue avec gestion de scripts mixtes et de texte contextuel, et les évalue face à une configuration fixe du linter Ruff sur CPython 3.14.7 avec les tables Unicode 16.0.0. L’étude associe des fixtures inertes artisanales couvrant les contrôles bidirectionnels, les identifiants confusables, les caractères ignorables par défaut et les graphies liées à NFKC à des archives de versions upstream échantillonnées, enregistre les métriques de localisation et d’alerte avec intervalles bootstrap, et fournit des scripts pour récupérer des entrées verrouillées, reconstruire les corpus, exécuter les tests et régénérer les figures du manuscrit sans exécuter les sources tierces analysées. Il s’adresse aux chercheurs en sécurité, aux ingénieurs en analyse statique et aux relecteurs qui ont besoin de compromis quantifiés entre la détection d’attaques par homoglyphes et de formatage et les fausses alertes sur des données multilingues ou de test légitimes dans les chaînes d’approvisionnement et les flux de revue de code.
