ApexSU 是 KernelSU 的加固分支，KernelSU 是一种基于内核的 Android root 方案，通过系统调用钩子与 UID 白名单授予超级用户权限，而无需修补 system 分区。它将用户空间组件用 Rust 重写，包括 ksud 守护进程与 JNI 桥接，可加载内核模块仍用 C 编写，负责 SELinux 策略注入、应用配置与模块管理。隐蔽性改进包括：通过伪装成 io_uring 的匿名 inode 进行 IOCTL 通信，不在 proc、sys 或 dev 中留下条目，以及更严格的模块校验与内置 ksud 诊断。基于 Kotlin 与 Jetpack Compose 的管理应用提供超级用户控制、模块安装，以及对 Android 12 及以上 GKI 2.0 设备的启动镜像修补。面向研究内核辅助 root、root 检测规避与加固 root 框架设计的 Android 安全研究人员与游戏反作弊分析人员。
