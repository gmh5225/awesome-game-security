ApexSU は KernelSU の強化フォークであり、KernelSU はシステムパーティションをパッチせず、システムコールフックと UID 許可リストでスーパーユーザー権限を付与するカーネルベースの Android root ソリューションです。ユーザー空間コンポーネント（ksud デーモンや JNI ブリッジを含む）を Rust で書き直し、ロード可能なカーネルモジュールは C のままで、SELinux ポリシー注入、アプリプロファイル、モジュール管理を担当します。ステルス面の改善として、io_uring に偽装した匿名 inode 経由の IOCTL 通信、proc・sys・dev エントリの不在、より厳格なモジュール検証、組み込み ksud 診断が含まれます。Kotlin と Jetpack Compose のマネージャーアプリは、Android 12 以降の GKI 2.0 デバイス向けにスーパーユーザー制御、モジュールインストール、ブートイメージパッチを提供します。カーネル支援 root、root 検出回避、強化 root フレームワーク設計を研究する Android セキュリティ研究者とゲームアンチチート分析者向けです。
