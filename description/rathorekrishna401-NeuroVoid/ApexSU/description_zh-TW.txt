ApexSU 是 KernelSU 的強化分支，KernelSU 是一種以核心為基礎的 Android root 方案，透過系統呼叫掛鉤與 UID 白名單授予超級使用者權限，而無需修補 system 分割區。它將使用者空間元件以 Rust 重寫，包括 ksud 守護程式與 JNI 橋接，可載入的核心模組仍以 C 撰寫，負責 SELinux 策略注入、應用程式設定檔與模組管理。隱匿性改進包括：透過偽裝成 io_uring 的匿名 inode 進行 IOCTL 通訊，不在 proc、sys 或 dev 中留下項目，以及更嚴格的模組驗證與內建 ksud 診斷。以 Kotlin 與 Jetpack Compose 建置的管理應用程式提供超級使用者控制、模組安裝，以及對 Android 12 及以上 GKI 2.0 裝置的開機映像修補。面向研究核心輔助 root、root 偵測規避與強化 root 框架設計的 Android 安全研究人員與遊戲反作弊分析人員。
