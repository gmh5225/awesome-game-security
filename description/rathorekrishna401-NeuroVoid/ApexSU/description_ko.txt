ApexSU는 KernelSU의 강화 포크로, KernelSU는 시스템 파티션을 패치하지 않고 시스템 콜 후크와 UID 허용 목록을 통해 슈퍼유저 권한을 부여하는 커널 기반 Android root 솔루션입니다. ksud 데몬과 JNI 브리지를 포함한 사용자 공간 구성 요소를 Rust로 재작성했으며, 로드 가능한 커널 모듈은 C로 유지되어 SELinux 정책 주입, 앱 프로필, 모듈 관리를 담당합니다. 은닉 개선 사항으로는 io_uring으로 위장한 익명 inode를 통한 IOCTL 통신, proc·sys·dev 항목 부재, 더 엄격한 모듈 검증, 내장 ksud 진단이 포함됩니다. Kotlin과 Jetpack Compose로 만든 관리 앱은 Android 12 이상 GKI 2.0 기기용 슈퍼유저 제어, 모듈 설치, 부트 이미지 패치를 제공합니다. 커널 지원 root, root 탐지 회피, 강화된 root 프레임워크 설계를 연구하는 Android 보안 연구자와 게임 안티치트 분석가를 대상으로 합니다.
