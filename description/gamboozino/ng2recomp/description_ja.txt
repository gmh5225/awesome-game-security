Ninja Gaiden II Recompiled は、Xbox 360 版タイトルの PowerPC マシンコードをフルシステムエミュレータ内で実行するのではなく、ホスト向けバイナリへ静的再コンパイルする Linux および Windows 向けネイティブポートです。ReXGlue SDK 上に C++23 と CMake で構築され、ゲームの Direct3D 利用をカスタム Vulkan レンダラーにフックし、ビルド時にパッチ適用済み XenosRecomp で Xenos GPU シェーダーを SPIR-V へ事前変換します。コードベースでは Ghidra で XEX イメージを読み込み D3D 呼び出し箇所をマッピングするなどのリバースエンジニアリング手順や、ユーザー提供のゲームアセットからシェーダーを抽出するツールを文書化しています。コンソールバイナリ変換、グラフィックスパイプラインの再利用、小売ゲーム実行ファイルの実用的な静的再コンパイルを研究する開発者・研究者向けです。
