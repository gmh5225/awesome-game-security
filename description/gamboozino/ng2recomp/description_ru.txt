Ninja Gaiden II Recompiled — нативный порт для Linux и Windows, который статически перекомпилирует машинный код PowerPC версии игры для Xbox 360 в бинарники хоста, а не запускает его в полносистемном эмуляторе. Проект построен на ReXGlue SDK с C++23 и CMake, перенаправляет использование Direct3D игры в собственный Vulkan-рендерер и на этапе сборки заранее переводит шейдеры GPU Xenos в SPIR-V с помощью пропатченного XenosRecomp. В кодовой базе описаны рабочие процессы реверс-инжиниринга: загрузка образа XEX в Ghidra, сопоставление точек вызовов D3D, а также инструменты извлечения шейдеров из игровых ресурсов, предоставленных пользователем. Проект предназначен для исследователей и разработчиков, изучающих трансляцию консольных бинарников, повторное использование графического конвейера и практическую статическую перекомпиляцию исполняемых файлов розничных игр.
