Ninja Gaiden II Recompiled is a native Linux and Windows port that statically recompiles the Xbox 360 title’s PowerPC machine code into host binaries instead of running it inside a full-system emulator. It is built on the ReXGlue SDK with C++23 and CMake, hooks the game’s Direct3D usage into a custom Vulkan renderer, and pre-translates Xenos GPU shaders to SPIR-V using patched XenosRecomp at build time. The codebase documents reverse-engineering workflows such as loading the XEX image in Ghidra and mapping D3D call sites, along with tooling to extract shaders from user-supplied game assets. It serves researchers and developers studying console binary translation, graphics pipeline reuse, and practical static recompilation of retail game executables.
