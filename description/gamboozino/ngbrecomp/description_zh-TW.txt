Ninja Gaiden Black Recompiled 是 2005 年 Xbox 版《忍者外傳 黑》的原生 PC 移植，在 Linux、Windows 與 macOS 上透過靜態重編譯執行遊戲自身的機器碼，而非全系統模擬。專案主要以 C 與 C++ 撰寫，使用 CMake 建置，依賴 xboxrecomp 工具鏈將零售版 XBE 提升為產生的 C 程式碼，並以自訂執行時期取代 Xbox 核心、音訊、輸入與圖形堆疊。渲染攔截遊戲的 Direct3D 呼叫並驅動 Vulkan 後端（可選 xemu NV2A 參考路徑），移植另加入高解析度、寬螢幕版面以及鍵盤滑鼠等現代 PC 功能。面向擁有光碟的玩家以取得高效能再發行體驗，也面向研究 Xbox 二進位提升、執行時期重建以及如何將經典作品適配當代硬體的逆向工程師與保存社群。
