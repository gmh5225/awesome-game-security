PokeDaisy 是一款在模拟器中游玩 Pokémon Game Boy、GBA 及相关作品的伴侣叠加层，在游戏运行时实时展示队伍、对战、背包、地图、图鉴与攻略信息。主代码库为采用 Kotlin 与 Jetpack Compose 的 Android 应用，通过 JNI 暴露可移植的共享 C 核心，另有基于 libmGBA 的 Nintendo 3DS 自制软件移植版，并包含大量无头模拟与夹具测试。它通过 SHA-1 与美术指纹识别 ROM 与改版，按各游戏布局读取模拟 WRAM 与存档数据，借助 pret 风格反编译知识解析 ROM 内表，并以专用存档校验逻辑管理 mGBA 格式金手指。项目面向需要在模拟过程中深入、准确观察第一至第三代 Pokémon 运行时状态、存档完整性与第三方 ROM 行为的玩家、ROM 研究者与逆向工程师。
