PokeDaisy 是一款在模擬器中遊玩 Pokémon Game Boy、GBA 及相關作品的伴侶疊加層，在遊戲執行時即時顯示隊伍、對戰、背包、地圖、圖鑑與攻略資訊。主要程式庫為採用 Kotlin 與 Jetpack Compose 的 Android 應用程式，透過 JNI 暴露可攜的共用 C 核心，另有基於 libmGBA 的 Nintendo 3DS 自制軟體移植版，並包含大量無頭模擬與夾具測試。它透過 SHA-1 與美術指紋識別 ROM 與改版，依各遊戲配置讀取模擬 WRAM 與存檔資料，借助 pret 風格反編譯知識解析 ROM 內資料表，並以專用存檔驗證邏輯管理 mGBA 格式金手指。專案面向需要在模擬過程中深入、準確觀察第一至第三代 Pokémon 執行時狀態、存檔完整性與第三方 ROM 行為的玩家、ROM 研究者與逆向工程師。
