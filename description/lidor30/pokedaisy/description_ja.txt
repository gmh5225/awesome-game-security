PokeDaisy は、エミュレータ上で Pokémon の Game Boy・GBA 系タイトルをプレイする際のコンパニオンオーバーレイで、ゲーム実行中にパーティ、バトル、バッグ、マップ、図鑑、攻略情報をライブ表示します。本体は Kotlin と Jetpack Compose による Android アプリで、JNI 経由で共有のポータブル C コアを公開し、libmGBA ベースの Nintendo 3DS ホームブリュー版、大規模なヘッドレスシミュレーションとフィクスチャテストも含みます。SHA-1 とアート指紋で ROM やハックを識別し、ゲーム別レイアウトでエミュレートされた WRAM とセーブデータを読み取り、pret スタイルのデコンパ知識で ROM 内テーブルを解析し、専用のセーブ検証ロジック付きで mGBA 形式のチートを管理します。エミュレーション中の第1～3世代 Pokémon のランタイム状態、セーブ整合性、サードパーティ ROM の挙動を深く正確に把握したいプレイヤー、ROM 研究者、リバースエンジニア向けのプロジェクトです。
