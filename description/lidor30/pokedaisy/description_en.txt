PokeDaisy is a companion overlay for playing Pokémon Game Boy, GBA, and related titles inside emulators, surfacing live party, battle, bag, map, Pokédex, and guide information while the game runs. The main codebase is a Kotlin and Jetpack Compose Android app with a shared portable C core exposed through JNI, plus a Nintendo 3DS homebrew port built on libmGBA and extensive headless simulation and fixture tests. It identifies ROMs and hacks by SHA-1 and art fingerprints, reads emulated WRAM and save data through game-specific layouts, parses in-ROM tables via pret-style decomp knowledge, and manages mGBA-format cheats with dedicated save-verification logic. The project targets players, ROM researchers, and reverse engineers who need deep, accurate visibility into Gen 1–3 Pokémon runtime state, save integrity, and third-party ROM behavior during emulation.
