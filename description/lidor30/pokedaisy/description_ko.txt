PokeDaisy는 에뮬레이터에서 Pokémon Game Boy, GBA 및 관련 타이틀을 플레이할 때 쓰는 동반 오버레이로, 게임 실행 중 파티, 배틀, 가방, 맵, 도감, 공략 정보를 실시간으로 표시합니다. 핵심 코드베이스는 Kotlin과 Jetpack Compose Android 앱이며 JNI로 공유 포터블 C 코어를 노출하고, libmGBA 기반 Nintendo 3DS 홈브류 포트와 광범위한 헤드리스 시뮬레이션·픽스처 테스트를 포함합니다. SHA-1과 아트 지문으로 ROM과 해킹을 식별하고, 게임별 레이아웃으로 에뮬레이트된 WRAM과 세이브 데이터를 읽으며, pret 스타일 디컴파일 지식으로 ROM 내 테이블을 파싱하고, 전용 세이브 검증 로직으로 mGBA 형식 치트를 관리합니다. 에뮬레이션 중 1~3세대 Pokémon 런타임 상태, 세이브 무결성, 서드파티 ROM 동작을 깊고 정확하게 보려는 플레이어, ROM 연구자, 리버스 엔지니어를 대상으로 합니다.
