Aetheris Quantum Core は、高度な Windows システム計測のための統合 PyQt6 デスクトップワークスペースであり、プロセス・メモリフォレンジクス、ストレージ分析、ライブネットワークおよびファイアウォール制御、レジストリエンジニアリング、自然言語による自動化を一つのダッシュボードに統合します。主に Python で記述され、MemProcFS、Capstone、Keystone、PCILeech-FPGA などのオプションのネイティブエンジンにより物理メモリアクセスを提供し、Authenticode 検証付きプロセス解剖、MFT 解析、GeoIP 拡張接続監視、サービスおよび永続化監査、保護された DMA 読み書き操作などのモジュールを備えます。本スイートは、ハッシュチェーン付きログ、グローバル dry-run リハーサル、Omega Rollback による取り消し、破壊的操作に対する確認ゲートを備えた、監査可能で可逆的な信頼モデルを重視します。プラグイン API、スケジュールされたフォレンジック取得用のヘッドレス CLI を含み、セキュリティ研究者、システム管理者、および自身が管理するマシン上のマルウェア、永続化、権限昇格、ライブシステム動作を分析するパワーユーザーを対象としています。
