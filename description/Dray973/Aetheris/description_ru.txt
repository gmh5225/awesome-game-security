Aetheris Quantum Core — единая настольная рабочая среда на PyQt6 для продвинутой инструментализации систем Windows, объединяющая форензику процессов и памяти, анализ хранилища, управление сетью и брандмауэром в реальном времени, работу с реестром и автоматизацию на естественном языке в одной панели. Написанный преимущественно на Python с опциональными нативными движками, такими как MemProcFS, Capstone, Keystone и PCILeech-FPGA для доступа к физической памяти, он предоставляет модули для вскрытия процессов с проверкой Authenticode, разбора MFT, мониторинга соединений с обогащением GeoIP, аудита служб и персистентности, а также защищённых операций чтения и записи DMA. Набор делает упор на проверяемую, обратимую модель доверия с хеш-цепочкой журналирования, глобальной репетицией dry-run, откатом Omega Rollback и подтверждением деструктивных действий. Включает API плагинов, headless CLI для запланированного форензического сбора данных и ориентирован на исследователей безопасности, системных администраторов и опытных пользователей, анализирующих контролируемые ими машины на предмет вредоносного ПО, персистентности, повышения привилегий и поведения системы в реальном времени.
