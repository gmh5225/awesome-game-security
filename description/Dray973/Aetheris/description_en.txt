Aetheris Quantum Core is a unified PyQt6 desktop workspace for advanced Windows systems instrumentation that combines process and memory forensics, storage analysis, live network and firewall control, registry engineering, and natural-language automation into one dashboard. Written primarily in Python with optional native engines such as MemProcFS, Capstone, Keystone, and PCILeech-FPGA for physical memory access, it provides modules for process autopsy with Authenticode verification, MFT parsing, GeoIP-enriched connection monitoring, service and persistence auditing, and guarded DMA read and write operations. The suite emphasizes an auditable, reversible trust model with hash-chained logging, global dry-run rehearsal, Omega Rollback undo, and confirmation gates on destructive actions. It includes a plugin API, a headless CLI for scheduled forensic capture, and targets security researchers, systems administrators, and power users analyzing machines they control for malware, persistence, privilege escalation, and live system behavior.
