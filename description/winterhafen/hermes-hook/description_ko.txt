Hermes Hook은 Linux, Windows, 그리고 Wine 또는 Proton을 통한 Windows 게임에서 실행 중인 게임의 메모리를 검사하고 조작하는 데스크톱 애플리케이션입니다. 주로 Python으로 작성되었으며 JavaScript 후크 스크립트를 사용하고, Frida, ptrace, Capstone으로 부착, 추적, 디스어셈블리를 수행합니다. 이 도구는 메모리 및 포인터 스캔, 읽기·쓰기 감시, 스크립트에서 값을 변환하는 명령 수준 후크와 함께 Unity Mono 및 IL2CPP, Unreal Engine에 대한 클래스 카탈로그, 추적, 메서드 후크, 게임 코드로의 스크립트 호출 등 엔진별 지원을 제공합니다. 온라인 안티치트 우회가 아니라 오프라인 또는 싱글플레이 게임 분석, 학습, 메모리 기반 모딩에 종사하는 연구자, 모더, 리버스 엔지니어를 대상으로 합니다.
