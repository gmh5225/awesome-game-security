Hermes Hook は、Linux、Windows、および Wine や Proton 経由の Windows タイトルで実行中のゲームのメモリを調査・操作するためのデスクトップアプリケーションです。主に Python で構築され、JavaScript のフックスクリプトを用い、Frida、ptrace、Capstone によってアタッチ、トレース、逆アセンブルを行います。メモリおよびポインタスキャン、読み書きウォッチ、スクリプト内で値を変換する命令レベルのフックに加え、Unity Mono と IL2CPP、Unreal Engine 向けのクラスカタログ、トレース、メソッドフック、ゲームコードへのスクリプト呼び出しなどエンジン固有のサポートを提供します。オンライン向けアンチチート回避ではなく、オフラインやシングルプレイの分析、学習、メモリベースの mod 開発に取り組む研究者、modder、リバースエンジニアを対象としています。
