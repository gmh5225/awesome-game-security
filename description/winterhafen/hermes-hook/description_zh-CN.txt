Hermes Hook 是一款桌面应用程序，用于在 Linux、Windows 以及通过 Wine 或 Proton 运行的 Windows 游戏上检查和操控运行中游戏的内存。它主要使用 Python 编写，配合 JavaScript 钩子脚本，并借助 Frida、ptrace 和 Capstone 实现附加、跟踪与反汇编。该工具提供内存与指针扫描、读写监视、可在脚本中转换数值的指令级钩子，以及对 Unity Mono 与 IL2CPP、Unreal Engine 的引擎专项支持，包括类目录、跟踪、方法钩子以及向游戏代码发起脚本化调用。它面向从事离线或单机游戏分析、训练与基于内存的模组开发的科研人员、模组作者和逆向工程师，而非用于在线反作弊绕过。
