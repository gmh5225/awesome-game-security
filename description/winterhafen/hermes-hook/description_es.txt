Hermes Hook es una aplicación de escritorio para inspeccionar y manipular la memoria de juegos en ejecución en Linux, Windows y títulos de Windows mediante Wine o Proton. Está construida principalmente en Python con scripts de hooks en JavaScript y utiliza Frida, ptrace y Capstone para la conexión, el rastreo y el desensamblado. La herramienta ofrece escaneo de memoria y punteros, vigilancia de lectura y escritura, hooks a nivel de instrucción que transforman valores en script y soporte específico de motor para Unity Mono e IL2CPP y Unreal Engine, incluidos catálogos de clases, rastreo, hooks de métodos y llamadas scriptadas al código del juego. Está dirigida a investigadores, modders e ingenieros inversos que trabajan en análisis, formación y modding basado en memoria de juegos offline o para un jugador, no en la evasión de anti-cheat en línea.
