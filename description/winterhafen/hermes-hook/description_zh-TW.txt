Hermes Hook 是一款桌面應用程式，用於在 Linux、Windows 以及透過 Wine 或 Proton 執行的 Windows 遊戲上檢查與操控執行中遊戲的記憶體。它主要以 Python 撰寫，搭配 JavaScript 鉤子腳本，並使用 Frida、ptrace 與 Capstone 進行附加、追蹤與反組譯。此工具提供記憶體與指標掃描、讀寫監視、可在腳本中轉換數值的指令層級鉤子，以及針對 Unity Mono 與 IL2CPP、Unreal Engine 的引擎專屬支援，包含類別目錄、追蹤、方法鉤子與對遊戲程式碼的腳本化呼叫。它面向從事離線或單人遊戲分析、訓練與記憶體導向模組開發的研究人員、模組作者與逆向工程師，而非用於繞過線上反作弊。
