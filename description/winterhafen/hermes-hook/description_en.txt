Hermes Hook is a desktop application for inspecting and manipulating the memory of running games on Linux, Windows, and Windows titles through Wine or Proton. It is built primarily in Python with JavaScript hook scripts and uses Frida, ptrace, and Capstone for attachment, tracing, and disassembly. The tool offers memory and pointer scanning, read and write watches, instruction-level hooks that transform values in script, and engine-specific support for Unity Mono and IL2CPP and Unreal Engine including class catalogs, tracing, method hooks, and scripted calls into game code. It targets researchers, modders, and reverse engineers working on offline or single-player game analysis, training, and memory-based modding rather than online anti-cheat bypass.
