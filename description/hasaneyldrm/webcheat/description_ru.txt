WebCheat — расширение для Chrome, которое переносит сканирование и редактирование памяти в стиле Cheat Engine в браузерные игры, построенные на WebAssembly. Оно перехватывает инстанцирование WebAssembly для захвата линейной памяти игры и поддерживает классические рабочие процессы сканирования и сужения для целочисленных и чисел с плавающей точкой, с чтением, записью и заморозкой на частоте 60 Гц для найденных адресов. Расширение также предоставляет управление временем через виртуальные часы для изменения скорости, паузы и пошагового продвижения по кадрам и может нацеливаться на игры, встроенные в cross-origin iframe. Написано на JavaScript как расширение Manifest V3 с content script в мирах MAIN и ISOLATED, работает полностью в браузере без внешнего сервера или подключения отладчика. Предназначено для разработчиков игр и исследователей безопасности, анализирующих клиентское состояние в проектах Unity, Godot и Emscripten WebGL.
