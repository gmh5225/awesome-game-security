WebCheat は Chrome 拡張機能で、WebAssembly で構築されたブラウザゲームに Cheat Engine 風のメモリスキャンと編集機能を提供します。WebAssembly のインスタンス化をフックしてゲームの線形メモリを取得し、整数型および浮動小数点型に対する古典的なスキャンと絞り込みワークフローをサポートします。発見したアドレスに対して読み取り、書き込み、60 Hz でのフリーズが可能です。拡張機能は仮想クロックによる時間制御も提供し、速度調整、一時停止、1 フレームずつのステップ実行ができます。クロスオリジン iframe に埋め込まれたゲームも対象にできます。JavaScript で書かれた Manifest V3 拡張機能で、MAIN および ISOLATED の両 world で content script を実行し、外部サーバーやデバッガー接続なしに完全にブラウザ内で動作します。Unity、Godot、Emscripten WebGL タイトルのクライアント側状態を分析するゲーム開発者およびセキュリティ研究者向けです。
