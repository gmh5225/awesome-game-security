WebCheat 是一款 Chrome 擴充功能，為以 WebAssembly 建構的瀏覽器遊戲帶來 Cheat Engine 風格的記憶體掃描與編輯功能。它 hook WebAssembly 實例化過程以擷取遊戲的線性記憶體，並支援對整數與浮點類型進行經典的掃描與逐步縮小工作流程，可對發現的位址進行讀取、寫入以及 60 Hz 凍結。此擴充功能亦提供虛擬時鐘時間控制，用於調速、暫停與單幀步進，並可鎖定嵌入於跨來源 iframe 中的遊戲。它以 JavaScript 撰寫，採用 Manifest V3 擴充功能，在 MAIN 與 ISOLATED 兩個 world 中執行 content script，完全在瀏覽器內運行，無需外部伺服器或除錯器附加。面向遊戲開發者與安全研究人員，用於分析 Unity、Godot 及 Emscripten WebGL 遊戲的用戶端狀態。
