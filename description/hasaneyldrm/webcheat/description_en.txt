WebCheat is a Chrome extension that brings Cheat Engine-style memory scanning and editing to browser-based games built with WebAssembly. It hooks WebAssembly instantiation to capture the game's linear memory and supports classic scan-and-narrow workflows across integer and floating-point types, with read, write, and 60 Hz freeze on discovered addresses. The extension also provides virtual clock time control for speed adjustment, pause, and single-frame stepping, and can target games embedded in cross-origin iframes. Written in JavaScript as a Manifest V3 extension with content scripts in both MAIN and ISOLATED worlds, it runs entirely in the browser with no external server or debugger attachment. It is aimed at game developers and security researchers analyzing client-side state in Unity, Godot, and Emscripten WebGL titles.
