WebCheat 是一款 Chrome 扩展，为基于 WebAssembly 构建的浏览器游戏带来 Cheat Engine 风格的内存扫描与编辑功能。它 hook WebAssembly 实例化过程以捕获游戏的线性内存，并支持对整数和浮点类型进行经典的扫描与逐步缩小工作流，可对发现的地址进行读取、写入以及 60 Hz 冻结。该扩展还提供虚拟时钟时间控制，用于调速、暂停和单帧步进，并可针对嵌入在跨源 iframe 中的游戏。它以 JavaScript 编写，采用 Manifest V3 扩展，在 MAIN 和 ISOLATED 两个 world 中运行 content script，完全在浏览器内运行，无需外部服务器或调试器附加。面向游戏开发者和安全研究人员，用于分析 Unity、Godot 及 Emscripten WebGL 游戏的客户端状态。
