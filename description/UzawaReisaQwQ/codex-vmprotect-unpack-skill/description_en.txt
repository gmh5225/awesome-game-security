This repository is an agent skill for AI coding assistants that guides analysis and recovery of VMProtect-protected native Windows PE executables and DLLs. It documents structured unpacking workflows that integrate the vmp-lazy-unpack tracer with Python helpers for PE inventory, import-evidence auditing, run comparison, progress logging, and x86 or WinStation compatibility shims where samples need them. The skill targets authorized reverse engineering and malware or software-protection research: restoring unpacked images, rebuilding import tables, recovering strings, and reasoning about anti-debug and anti-virtualization checks, while clearly separating unpack success from full devirtualization. A bundled C++ sample application protected with VMProtect serves as a training target, with version-specific reference notes for roughly VMProtect 3.5.0 through 3.10.4 on x64 and selected x86 builds. It is aimed at practitioners studying packer behavior, anti-tamper schemes, and practical unpacking on Windows rather than end users seeking a one-click generic deobfuscator.
