Dieses Repository ist eine Agent Skill für KI-Coding-Assistenten, die Analyse und Wiederherstellung von mit VMProtect geschützten nativen Windows-PE-Executables und DLLs anleitet. Es dokumentiert strukturierte Unpacking-Workflows, die den vmp-lazy-unpack-Tracer mit Python-Hilfen für PE-Inventar, Import-Nachweis-Audit, Laufvergleich, Fortschrittsprotokollierung sowie x86- oder WinStation-Kompatibilitätsshims integrieren, wenn Proben sie benötigen. Die Skill richtet sich an autorisierte Reverse Engineering und Malware- oder Softwareschutz-Forschung: Wiederherstellung entpackter Images, Neuaufbau von Importtabellen, String-Rückgewinnung und Analyse von Anti-Debug- und Anti-Virtualisierungsprüfungen, wobei Unpacking-Erfolg klar von vollständiger Devirtualisierung getrennt wird. Eine mitgelieferte, mit VMProtect geschützte C++-Beispielanwendung dient als Trainingsziel, mit versionsspezifischen Referenzhinweisen für etwa VMProtect 3.5.0 bis 3.10.4 auf x64 und ausgewählten x86-Builds. Sie richtet sich an Praktiker, die Packer-Verhalten, Anti-Tamper-Schemata und praktisches Unpacking unter Windows studieren, nicht an Endnutzer, die einen generischen Ein-Klick-Deobfuscator suchen.
