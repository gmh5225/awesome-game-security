Этот репозиторий — agent skill для ИИ-ассистентов по программированию, которая направляет анализ и восстановление нативных PE-исполняемых файлов и DLL Windows, защищённых VMProtect. В нём описаны структурированные рабочие процессы распаковки с интеграцией трассировщика vmp-lazy-unpack и Python-утилит для инвентаризации PE, аудита доказательств импорта, сравнения запусков, журналирования прогресса и при необходимости совместимости x86 или WinStation для образцов. Skill ориентирована на санкционированный реверс-инжиниринг и исследование вредоносного ПО или защиты программ: восстановление распакованных образов, пересборка таблиц импорта, извлечение строк и анализ антиотладочных и антивиртуализационных проверок с чётким разделением успешной распаковки и полной девиртуализации. В комплекте — пример приложения на C++, защищённый VMProtect, в качестве учебной цели, со справочными заметками по версиям примерно VMProtect 3.5.0–3.10.4 для x64 и отдельных сборок x86. Она предназначена практикам, изучающим поведение пакеров, схемы антивзлома и практическую распаковку в Windows, а не конечным пользователям, ищущим универсальный деобфускатор в один клик.
