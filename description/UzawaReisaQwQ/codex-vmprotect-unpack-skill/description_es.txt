Este repositorio es una agent skill para asistentes de codificación con IA que guía el análisis y la recuperación de ejecutables PE nativos de Windows y DLL protegidos con VMProtect. Documenta flujos de desempaquetado estructurados que integran el rastreador vmp-lazy-unpack con ayudantes en Python para inventario PE, auditoría de evidencia de importaciones, comparación de ejecuciones, registro de progreso y shims de compatibilidad x86 o WinStation cuando las muestras los requieren. La skill está dirigida a ingeniería inversa autorizada e investigación de malware o protección de software: restaurar imágenes desempaquetadas, reconstruir tablas de importación, recuperar cadenas y razonar sobre comprobaciones anti-depuración y anti-virtualización, distinguiendo claramente el éxito del desempaquetado de la desvirtualización completa. Una aplicación de ejemplo en C++ protegida con VMProtect sirve como objetivo de entrenamiento, con notas de referencia por versión para aproximadamente VMProtect 3.5.0 a 3.10.4 en x64 y compilaciones x86 seleccionadas. Está pensada para profesionales que estudian el comportamiento de packers, esquemas anti-manipulación y desempaquetado práctico en Windows, no para usuarios finales que buscan un desofuscador genérico de un clic.
