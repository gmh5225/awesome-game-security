本儲存庫是一份面向 AI 程式設計助手的 agent skill，用於指導分析與還原經 VMProtect 保護的 Windows 原生 PE 可執行檔與 DLL。它記載的結構化脫殼流程整合了 vmp-lazy-unpack 追蹤器，以及用於 PE 清單、匯入證據稽核、執行比對、進度記錄，以及在樣本需要時提供 x86 或 WinStation 相容性墊片的 Python 輔助腳本。此 skill 面向經授權的逆向工程與惡意軟體或軟體保護研究：還原脫殼映像、重建匯入表、回收字串，並分析反除錯與反虛擬化檢查，同時清楚區分脫殼成功與完整去虛擬化。內附的 C++ 範例應用程式以 VMProtect 加殼，作為訓練標的，並附有約 VMProtect 3.5.0 至 3.10.4 在 x64 及部分 x86 建置上的版本參考說明。它面向研究加殼行為、防篡改方案及 Windows 上實用脫殼技術的從業者，而非尋求一鍵通用去混淆的終端使用者。
