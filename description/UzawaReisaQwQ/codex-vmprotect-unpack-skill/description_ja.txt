本リポジトリは、VMProtect で保護された Windows ネイティブの PE 実行ファイルおよび DLL の分析と復元を案内する、AI コーディングアシスタント向けの agent skill です。構造化されたアンパック手順を文書化し、vmp-lazy-unpack トレーサと、PE インベントリ、インポート証拠の監査、実行比較、進捗ログ、サンプルに必要な場合の x86 または WinStation 互換シム用 Python ヘルパーを統合しています。この skill は、許可されたリバースエンジニアリングおよびマルウェアやソフトウェア保護の研究を対象とし、アンパック済みイメージの復元、インポートテーブルの再構築、文字列の回収、反デバッグおよび反仮想化チェックの考察を行い、アンパック成功と完全なデバーチャライゼーションを明確に区別します。VMProtect で保護された C++ サンプルアプリケーションが訓練用ターゲットとして同梱され、x64 および一部の x86 ビルド向けにおおよそ VMProtect 3.5.0 から 3.10.4 までのバージョン別参照メモが付いています。ワンクリックの汎用デオブフスケーターを求めるエンドユーザー向けではなく、パッカー挙動、改ざん防止スキーム、Windows 上の実用的なアンパックを学ぶ実務者向けです。
