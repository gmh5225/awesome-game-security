本仓库是一份面向 AI 编程助手的 agent skill，用于指导分析和恢复经 VMProtect 保护的 Windows 原生 PE 可执行文件与 DLL。它记载的结构化解壳流程结合了 vmp-lazy-unpack 跟踪器，以及用于 PE 清单、导入证据审计、运行对比、进度记录，以及在样本需要时提供 x86 或 WinStation 兼容性垫片的 Python 辅助脚本。该 skill 面向经授权的反向工程与恶意软件或软件保护研究：恢复脱壳镜像、重建导入表、回收字符串，并分析反调试与反虚拟化检查，同时明确区分脱壳成功与完整去虚拟化。附带的 C++ 示例程序使用 VMProtect 加壳，作为训练靶标，并附有约 VMProtect 3.5.0 至 3.10.4 在 x64 及部分 x86 构建上的版本参考说明。它面向研究壳行为、防篡改方案及 Windows 上实用脱壳技术的从业者，而非寻求一键通用去混淆的终端用户。
