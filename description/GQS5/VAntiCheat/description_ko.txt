VAntiCheat는 Paper 및 Folia용 서버 측 Minecraft 플러그인으로, 이동이나 전투 휴리스틱이 아니라 설정 기반 프로브를 통해 특정 클라이언트 mod 및 치트 관련 클라이언트를 탐지합니다. Java 21로 구현되었으며 모듈형 탐지 레지스트리, 인바운드 plugin-message 채널의 수동 관찰, 번역 키 지문용 선택적 대화형 표지판 편집 프로토콜, 확인된 신원에 대한 뒷받침 규칙 및 중앙 집중식 킥·밴 집행을 제공합니다. 스택은 Apollo를 통해 Lunar Client와 통합하고, Geyser와 Floodgate로 Java 대 Bedrock 플레이어를 분류하며, 신뢰 플레이어 면제, Forge mod 목록 거부 목록, 프로젝트에 문서화된 지형 마스크 관련 패킷 처리를 지원합니다. 자동 접속 검사는 기본적으로 비대화형 수동 프로브로 설정되어 매 로그인마다 플레이어에게 프롬프트하지 않으며, 운영자는 수동 스캔과 YAML 설정으로 정책을 조정할 수 있습니다. 프록시나 클라이언트 구성 요소를 묶지 않고 modded 1.21.x 네트워크에서 명시적이고 증거 기반의 mod 및 클라이언트 식별이 필요한 서버 관리자와 게임 보안 실무자를 대상으로 합니다.
