VAntiCheat 是一款面向 Paper 与 Folia 的服务端 Minecraft 插件，通过配置驱动的探测而非移动或战斗启发式来检测特定客户端 mod 与作弊相关客户端。它以 Java 21 实现，采用模块化检测注册表、对入站 plugin-message 通道的被动观察，以及可选的交互式告示牌编辑协议用于翻译键指纹，并配合佐证规则与集中式踢出或封禁对已确认身份执行处置。该方案通过 Apollo 集成 Lunar Client，借助 Geyser 与 Floodgate 区分 Java 与 Bedrock 玩家，支持受信玩家豁免、Forge mod 列表黑名单，以及项目中文档化的与地形掩码相关的数据包处理。自动加入检查默认采用非交互式被动探测，避免每次登录都提示玩家，管理员可手动扫描并通过 YAML 配置调整策略。它面向需要在 mod 化 1.21.x 网络上进行明确、基于证据的 mod 与客户端识别、且无需捆绑代理或客户端组件的服务器管理员与游戏安全从业者。
