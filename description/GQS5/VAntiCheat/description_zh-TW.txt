VAntiCheat 是一款面向 Paper 與 Folia 的伺服器端 Minecraft 外掛，透過設定驅動的探測而非移動或戰鬥啟發式來偵測特定用戶端 mod 與作弊相關用戶端。它以 Java 21 實作，採用模組化偵測註冊表、對入站 plugin-message 通道的被動觀察，以及可選的互動式告示牌編輯協定用於翻譯鍵指紋，並搭配佐證規則與集中式踢出或封禁對已確認身分執行處置。此方案透過 Apollo 整合 Lunar Client，借助 Geyser 與 Floodgate 區分 Java 與 Bedrock 玩家，支援受信玩家豁免、Forge mod 清單黑名單，以及專案中文件化的與地形遮罩相關的封包處理。自動加入檢查預設採非互動式被動探測，避免每次登入都提示玩家，管理員可手動掃描並透過 YAML 設定調整策略。它面向需要在 mod 化 1.21.x 網路上進行明確、基於證據的 mod 與用戶端識別、且無需捆綁代理或用戶端元件的伺服器管理員與遊戲安全從業者。
