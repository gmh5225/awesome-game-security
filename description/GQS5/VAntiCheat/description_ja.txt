VAntiCheat は Paper および Folia 向けのサーバー側 Minecraft プラグインで、移動や戦闘のヒューリスティクスではなく、設定駆動のプローブにより特定のクライアント mod やチート関連クライアントを検出します。Java 21 で実装され、モジュール化された検出レジストリ、インバウンド plugin-message チャネルの受動的監視、翻訳キー指紋用の任意の対話型看板エディタプロトコル、および確定した ID に対する裏付けルールと集中型のキック・BAN 執行を備えています。スタックは Apollo 経由で Lunar Client と連携し、Geyser と Floodgate で Java プレイヤーと Bedrock プレイヤーを分類し、信頼プレイヤー免除、Forge mod リストの拒否リスト、プロジェクトで文書化された地形マスク関連のパケット処理をサポートします。自動参加チェックはデフォルトで非対話型の受動プローブとなり、ログインのたびにプレイヤーを促さず、オペレーターは手動スキャンと YAML 設定によるポリシー調整が可能です。プロキシやクライアントコンポーネントを同梱せず、mod 化 1.21.x ネットワーク上で明示的かつ証拠に基づく mod とクライアント識別を必要とするサーバー管理者およびゲームセキュリティ実務者向けです。
