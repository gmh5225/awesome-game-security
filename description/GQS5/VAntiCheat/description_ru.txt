VAntiCheat — серверный плагин Minecraft для Paper и Folia, который обнаруживает определённые клиентские моды и клиенты, связанные с читами, с помощью настраиваемых проб, а не эвристик движения или боя. Реализован на Java 21 с модульным реестром обнаружения, пассивным наблюдением за входящими каналами plugin-message и опциональным интерактивным протоколом редактора табличек для отпечатков ключей перевода, а также правилами подтверждения и централизованным киком или баном для установленных личностей. Стек интегрируется с Lunar Client через Apollo, классифицирует игроков Java и Bedrock через Geyser и Floodgate, поддерживает исключения для доверенных игроков, чёрные списки списков модов Forge и обработку пакетов, связанную с маской местности, описанную в проекте. Автоматические проверки при входе по умолчанию используют неинтерактивные пассивные пробы, чтобы не запрашивать игроков при каждом логине; операторы могут запускать ручные сканирования и настраивать политику через конфигурацию YAML. Ориентирован на администраторов серверов и специалистов по безопасности игр, которым нужна явная, основанная на доказательствах идентификация модов и клиентов в modded-сетях 1.21.x без прокси или клиентского компонента в комплекте.
