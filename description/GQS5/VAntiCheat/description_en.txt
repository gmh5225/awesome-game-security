VAntiCheat is a server-side Minecraft plugin for Paper and Folia that detects specific client mods and cheat-related clients through configuration-driven probes rather than movement or combat heuristics. It is implemented in Java 21 with a modular detection registry, passive observation of inbound plugin-message channels, and an optional interactive sign-editor protocol for translation-key fingerprinting, plus corroboration rules and centralized kick or ban enforcement for confirmed identities. The stack integrates Lunar Client via Apollo, classifies Java versus Bedrock players through Geyser and Floodgate, supports trusted-player exemptions, Forge mod-list denylisting, and terrain-mask related packet handling documented in the project. Automatic join checks default to non-interactive passive probes so players are not prompted on every login, while operators can run manual scans and tune policy through YAML configuration. It targets server administrators and game-security practitioners who need explicit, evidence-based mod and client identification on modded 1.21.x networks without bundling a proxy or client component.
