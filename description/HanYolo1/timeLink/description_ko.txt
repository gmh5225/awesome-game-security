timeLink는 정적 재컴파일 프로젝트로, 지원되는 Nintendo Switch 타이틀에서 AArch64 코드를 추출해 C로 올리고 Windows 또는 Linux용 네이티브 프로그램을 빌드합니다. Horizon OS와 NVN2를 재구현하며 콘솔을 에뮬레이션하는 대신 Vulkan에서 GPU 명령을 재생합니다. 저장소에는 덤프·리프트·컴파일용 Python nx2 파이프라인, C/C++ 호스트 및 Vulkan 렌더 레이어, 선택적 업스케일링·프레임 생성 경로, 사용자 로컬 게임 파일만으로 바이너리를 만드는 런처 또는 빌더가 포함됩니다. 기여자는 자동 테스트, Unicorn 기반 명령 검증, 셰이더 저하 및 SPIR-V 도구, 파이프라인 캐싱, 메시 셰이더 폴백을 포함한 광범위한 GPU 호환 작업으로 동작을 검증합니다. 리버스 엔지니어, 그래픽·플랫폼 연구자, 저작권 게임 데이터를 배포하지 않고 대형 상용 Switch 소프트웨어를 감사 가능한 네이티브 코드로 옮기는 방법을 연구하는 preservation 지향 개발자를 대상으로 합니다.
