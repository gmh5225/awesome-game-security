timeLink 是一项静态重编译工作：从受支持的 Nintendo Switch 游戏中提取 AArch64 代码并提升为 C，进而构建可在 Windows 或 Linux 上运行的原生程序；它重新实现 Horizon OS 与 NVN2，在 Vulkan 上回放 GPU 命令，而非模拟主机。本仓库提供用于转储、提升与编译游戏的 Python nx2 流水线，C/C++ 宿主层与 Vulkan 渲染层，可选的上采样与帧生成路径，以及仅凭用户本地游戏文件即可生成二进制文件的启动器或构建器。贡献者通过自动化测试、基于 Unicorn 的指令校验、着色器降级与 SPIR-V 工具、流水线缓存，以及包括网格着色器回退在内的广泛 GPU 兼容性工作来验证行为。项目面向逆向工程师、图形与平台研究人员，以及关注如何将大型商业 Switch 软件译为可审计原生代码、且不分发受版权游戏数据的 preservation 开发者。
