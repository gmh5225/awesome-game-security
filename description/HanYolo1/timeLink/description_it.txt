timeLink è un progetto di ricompilazione statica che eleva il codice AArch64 da un titolo Nintendo Switch supportato a C e costruisce un programma nativo per Windows o Linux, reimplementando Horizon OS e NVN2 e riproducendo i comandi GPU su Vulkan anziché emulare la console. Il repository fornisce una pipeline Python nx2 per dump, lifting e compilazione del gioco, layer host C/C++ e di rendering Vulkan, percorsi opzionali di upscaling e generazione di frame, e un launcher o builder che produce binari interamente dai file di gioco locali dell’utente. I contributori convalidano il comportamento con test automatizzati, controlli delle istruzioni basati su Unicorn, lowering degli shader e strumenti SPIR-V, caching delle pipeline e ampio lavoro di compatibilità GPU inclusi fallback per mesh shader. È rivolto a reverse engineer, ricercatori di grafica e piattaforme, e sviluppatori orientati alla preservation che studiano come tradurre grandi software Switch commerciali in codice nativo verificabile senza distribuire dati di gioco protetti da copyright.
