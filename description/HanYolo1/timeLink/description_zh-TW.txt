timeLink 是一項靜態重編譯工作：從受支援的 Nintendo Switch 遊戲中擷取 AArch64 程式碼並提升為 C，進而建置可在 Windows 或 Linux 上執行的原生程式；它重新實作 Horizon OS 與 NVN2，在 Vulkan 上重播 GPU 命令，而非模擬主機。本儲存庫提供用於傾印、提升與編譯遊戲的 Python nx2 管線，C/C++ 主機層與 Vulkan 渲染層，可選的上採樣與幀生成路徑，以及僅憑使用者本機遊戲檔案即可產生二進位檔的啟動器或建置器。貢獻者透過自動化測試、以 Unicorn 為後端的指令檢查、著色器降階與 SPIR-V 工具、管線快取，以及包含網格著色器回退在內的廣泛 GPU 相容性工作來驗證行為。專案面向逆向工程師、圖形與平台研究人員，以及關注如何將大型商業 Switch 軟體譯為可審計原生程式碼、且不散佈受版權遊戲資料的 preservation 開發者。
