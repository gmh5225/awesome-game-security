timeLink は静的再コンパイルプロジェクトで、対応する Nintendo Switch タイトルから AArch64 コードを抽出して C にリフトし、Windows または Linux 向けのネイティブプログラムをビルドします。Horizon OS と NVN2 を再実装し、コンソールをエミュレートするのではなく Vulkan 上で GPU コマンドを再生します。リポジトリには、ダンプ・リフト・コンパイル用の Python nx2 パイプライン、C/C++ のホスト層と Vulkan レンダー層、任意のアップスケーリングとフレーム生成経路、およびユーザーのローカルゲームファイルだけからバイナリを生成するランチャーまたはビルダーが含まれます。貢献者は自動テスト、Unicorn ベースの命令検証、シェーダー低減と SPIR-V ツール、パイプラインキャッシュ、メッシュシェーダーフォールバックを含む広範な GPU 互換作業で動作を検証します。リバースエンジニア、グラフィックス・プラットフォーム研究者、著作権で保護されたゲームデータを配布せずに大規模な商用 Switch ソフトを監査可能なネイティブコードへ翻訳する方法を研究する preservation 志向の開発者を対象としています。
