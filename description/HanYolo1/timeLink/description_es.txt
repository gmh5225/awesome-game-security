timeLink es un esfuerzo de recompilación estática que eleva código AArch64 de un título compatible de Nintendo Switch a C y construye un programa nativo para Windows o Linux, reimplementando Horizon OS y NVN2 mientras reproduce órdenes GPU en Vulkan en lugar de emular la consola. El repositorio ofrece una canalización Python nx2 para volcado, elevación y compilación del juego, capas host en C/C++ y de renderizado Vulkan, rutas opcionales de escalado y generación de fotogramas, y un lanzador o constructor que produce binarios únicamente a partir de los archivos locales del juego del usuario. Los colaboradores validan el comportamiento con pruebas automatizadas, comprobaciones de instrucciones respaldadas por Unicorn, reducción de sombreadores y herramientas SPIR-V, caché de tuberías y un amplio trabajo de compatibilidad GPU que incluye alternativas de mesh shader. Está dirigido a ingenieros inversos, investigadores de gráficos y plataformas, y desarrolladores orientados a la preservación que estudian cómo traducir software comercial grande de Switch a código nativo auditable sin distribuir datos de juego con copyright.
