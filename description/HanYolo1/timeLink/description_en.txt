timeLink is a static recompilation effort that lifts AArch64 code from a supported Nintendo Switch title into C and builds a native Windows or Linux program, reimplementing Horizon OS and NVN2 while replaying GPU commands on Vulkan rather than emulating the console. The repository provides a Python nx2 pipeline for dumping, lifting, and compiling the game, C and C++ host and Vulkan render layers, optional upscaling and frame-generation paths, and a launcher or builder that produces binaries entirely from the user’s local game files. Contributors validate behavior with automated tests, Unicorn-backed instruction checks, shader lowering and SPIR-V tooling, pipeline caching, and broad GPU compatibility work including mesh-shader fallbacks. It is aimed at reverse engineers, graphics and platform researchers, and preservation-minded developers studying how large commercial Switch software can be translated into auditable native code without shipping copyrighted game data.
