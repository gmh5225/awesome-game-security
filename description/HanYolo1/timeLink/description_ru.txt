timeLink — проект статической перекомпиляции: из поддерживаемого Nintendo Switch-релиза поднимается код AArch64 в C и собирается нативная программа для Windows или Linux с реализацией Horizon OS и NVN2 и воспроизведением GPU-команд через Vulkan вместо эмуляции консоли. Репозиторий содержит конвейер Python nx2 для дампа, подъёма и компиляции игры, хост-слои на C/C++ и слой рендеринга Vulkan, опциональные пути апскейлинга и генерации кадров, а также лаунчер или сборщик, создающий бинарники исключительно из локальных файлов игры пользователя. Участники проверяют поведение автоматизированными тестами, проверками инструкций на Unicorn, понижением шейдеров и инструментами SPIR-V, кэшированием конвейеров и широкой работой по совместимости GPU, включая откаты для mesh shader. Проект ориентирован на специалистов по реверс-инжинирингу, исследователей графики и платформ и разработчиков, занимающихся preservation и изучающих, как перевести крупное коммерческое ПО для Switch в проверяемый нативный код без распространения защищённых авторским правом игровых данных.
