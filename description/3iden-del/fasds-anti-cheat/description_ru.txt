fasd's Anti Cheat — клиентский мод Fabric для Minecraft 1.21.11, который эвристически помечает подозрительное поведение ближайших игроков, используя только те данные, которые сервер уже отправляет вашему клиенту. Написан на Java с Fabric Loader, Fabric API и Gradle Loom и накапливает уровни нарушений по категориям: скорость, полёт или зависание, высокий прыжок, хождение по воде, увеличенная дистанция, kill aura или резкое наведение, частота ударов автокликера. Игроки нажимают клавишу, чтобы вывести ранжированный отчёт о читах, и другую — чтобы сбросить сохранённые метки; опционально уровни со временем затухают, чтобы уменьшить устаревшие предупреждения. Подходит игрокам в мультиплеере, модераторам и исследователям, которым нужна лёгкая клиентская осведомлённость о читах, а не авторитетный серверный античит; в README указано, что результаты эвристические и при лаге или необычной механике возможны ложные срабатывания.
