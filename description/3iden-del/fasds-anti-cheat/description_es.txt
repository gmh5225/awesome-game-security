fasd's Anti Cheat es un mod cliente de Fabric para Minecraft 1.21.11 que marca de forma heurística comportamientos sospechosos en jugadores cercanos usando solo los datos que el servidor ya envía a tu cliente. Está escrito en Java con Fabric Loader, Fabric API y Gradle Loom, y acumula niveles de infracción para categorías como velocidad, vuelo o flotación, saltos altos, caminar sobre el agua, alcance extendido, kill aura o encaje brusco de puntería, y ritmos de clic automático. Los jugadores pulsan una tecla para imprimir un informe de trampas ordenado y otra para borrar las marcas almacenadas, con decaimiento opcional en el tiempo para reducir alertas obsoletas. Sirve a jugadores multijugador, moderadores o investigadores que quieren conciencia ligera de trampas en el cliente en lugar de un anti-cheat autoritativo en el servidor; el README indica que los resultados son heurísticos y pueden dar falsos positivos con lag o mecánicas poco habituales.
