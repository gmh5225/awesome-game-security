fasd's Anti Cheat 是一款面向 Minecraft 1.21.11 的 Fabric 用戶端模組，僅依據伺服器已傳送到用戶端的資料，以啟發式規則標記附近玩家的可疑行為。專案以 Java 撰寫，使用 Fabric Loader、Fabric API 與 Gradle Loom，並為速度、飛行或懸停、高跳、水上行走、超距攻擊、殺戮光環或準星瞬移、自動連點揮擊頻率等類別累積違規等級。玩家可按鍵輸出排序後的作弊報告，或清除已儲存的標記；可選隨時間衰減以降低過時告警。適合多人玩家、管理員或研究者，在客戶端側取得輕量級作弊感知，而非作為權威伺服器反作弊；README 說明結果為啟發式判定，在延遲或非常規機制下可能出現誤報。
