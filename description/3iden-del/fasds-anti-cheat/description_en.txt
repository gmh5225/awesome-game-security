fasd's Anti Cheat is a Fabric client mod for Minecraft 1.21.11 that heuristically flags suspicious behavior in nearby players using only data the server already sends to your client. It is written in Java with Fabric Loader, Fabric API, and Gradle Loom, and accumulates violation levels for categories such as speed, flight or hover, high jump, water walking, extended reach, kill aura or aim snapping, and autoclicker swing rates. Players press a key to print a ranked cheat report and another to clear stored flags, with optional decay over time to reduce stale alerts. It suits multiplayer players, moderators, or researchers who want lightweight, client-side cheat awareness rather than authoritative server anti-cheat, and the README notes that results are heuristic and can false-positive on lag or unusual mechanics.
