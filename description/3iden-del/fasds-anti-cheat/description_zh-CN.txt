fasd's Anti Cheat 是一款面向 Minecraft 1.21.11 的 Fabric 客户端模组，仅依据服务器已下发到客户端的数据，通过启发式规则标记附近玩家的可疑行为。项目使用 Java 编写，基于 Fabric Loader、Fabric API 与 Gradle Loom，并为速度、飞行或悬停、高跳、水上行走、超距攻击、杀戮光环或准星瞬移、自动连点挥击频率等类别累积违规等级。玩家可按键输出排序后的作弊报告，或清除已存储的标记；可选随时间衰减以降低过时告警。适合多人玩家、管理员或研究者，在客户端侧获得轻量级作弊感知，而非作为权威服务器反作弊；README 说明结果为启发式判定，在延迟或非常规机制下可能出现误报。
