fasd's Anti Cheat est un mod client Fabric pour Minecraft 1.21.11 qui signale de façon heuristique les comportements suspects des joueurs proches en n'utilisant que les données que le serveur envoie déjà à votre client. Il est écrit en Java avec Fabric Loader, Fabric API et Gradle Loom, et accumule des niveaux de violation pour des catégories comme la vitesse, le vol ou la lévitation, les sauts élevés, la marche sur l'eau, la portée étendue, le kill aura ou le snap de visée, et les cadences de clic automatique. Les joueurs peuvent appuyer sur une touche pour afficher un rapport de triche classé et sur une autre pour effacer les signalements stockés, avec une décroissance optionnelle dans le temps pour réduire les alertes obsolètes. Il convient aux joueurs multijoueur, modérateurs ou chercheurs qui veulent une détection légère côté client plutôt qu'un anti-triche serveur faisant autorité ; le README précise que les résultats sont heuristiques et peuvent produire des faux positifs en cas de lag ou de mécaniques inhabituelles.
