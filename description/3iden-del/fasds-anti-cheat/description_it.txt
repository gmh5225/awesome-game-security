fasd's Anti Cheat è un mod client Fabric per Minecraft 1.21.11 che segnala in modo euristico comportamenti sospetti dei giocatori vicini usando solo i dati che il server invia già al tuo client. È scritto in Java con Fabric Loader, Fabric API e Gradle Loom, e accumula livelli di violazione per categorie come velocità, volo o hover, salti alti, camminata sull'acqua, reach esteso, kill aura o snap della mira, e frequenze di swing da autoclicker. I giocatori premendo un tasto stampano un report cheat classificato e con un altro cancellano i flag memorizzati, con decadimento opzionale nel tempo per ridurre avvisi obsoleti. È adatto a giocatori multiplayer, moderatori o ricercatori che vogliono consapevolezza leggera dei cheat lato client piuttosto che un anti-cheat server autorevole; il README segnala che i risultati sono euristici e possono dare falsi positivi con lag o meccaniche insolite.
