fasd's Anti Cheat ist ein Fabric-Client-Mod für Minecraft 1.21.11, der verdächtiges Verhalten naher Spieler heuristisch markiert und dabei nur Daten nutzt, die der Server ohnehin an deinen Client sendet. Er ist in Java mit Fabric Loader, Fabric API und Gradle Loom geschrieben und sammelt Verstoßstufen für Kategorien wie Geschwindigkeit, Flug oder Schweben, hohe Sprünge, Wasserlaufen, erweiterte Reichweite, Kill Aura oder Aim-Snapping sowie Autoclicker-Schwungraten. Spieler können eine Taste drücken, um einen sortierten Cheat-Bericht auszugeben, und eine andere, um gespeicherte Markierungen zu löschen; optional verfallen Werte mit der Zeit, um veraltete Warnungen zu reduzieren. Er eignet sich für Multiplayer-Spieler, Moderatoren oder Forscher, die leichte clientseitige Cheat-Erkennung statt autoritativer Server-Anti-Cheat-Lösung wollen; die README weist darauf hin, dass die Ergebnisse heuristisch sind und bei Lag oder ungewöhnlichen Mechaniken falsch positiv sein können.
