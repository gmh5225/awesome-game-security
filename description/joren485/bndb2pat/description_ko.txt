bndb2pat는 Binary Ninja에서 연 바이너리로부터 IDA Pro FLIRT .pat 패턴 파일을 생성하는 Binary Ninja 플러그인입니다. Python으로 작성되었으며, Binary Ninja의 저수준 IL을 사용해 함수를 순회하고 가변 피연산자에 대한 와일드카드 마스킹, CRC16 체크섬, FLIRT 형식의 public 및 named 심볼 참조가 포함된 바이트 마스크를 구축합니다. 생성된 .pat 파일은 sigmake와 같은 FLAIR 도구로 처리하여 IDA Pro에 로드할 .sig 시그니처 라이브러리를 만들 수 있습니다. Mandiant FLARE의 idb2pat와 Kaspersky의 hrtng에서 영감을 받아 Binary Ninja와 IDA 사이의 시그니처 생성 워크플로를 연결합니다. 스트립되었거나 알 수 없는 바이너리에서 함수를 식별해야 하는 역공학자와 보안 연구자를 대상으로 하며, 게임 및 멀웨어 분석 시나리오를 포함합니다.
