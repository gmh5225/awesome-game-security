bndb2pat is a Binary Ninja plugin that generates IDA Pro FLIRT .pat pattern files from binaries opened in Binary Ninja. Written in Python, it iterates over functions using Binary Ninja's low-level IL to build byte masks with wildcard masking for variable operands, CRC16 checksums, and public and named symbol references in the FLIRT format. The resulting .pat files can be processed with FLAIR tools such as sigmake to produce .sig signature libraries for loading into IDA Pro. Inspired by Mandiant FLARE's idb2pat and Kaspersky's hrtng, it bridges signature creation workflows between Binary Ninja and IDA. It is aimed at reverse engineers and security researchers who need to identify functions in stripped or unknown binaries, including game and malware analysis scenarios.
