bndb2pat — это плагин для Binary Ninja, который генерирует файлы шаблонов FLIRT .pat для IDA Pro из бинарных файлов, открытых в Binary Ninja. Написанный на Python, он перебирает функции с использованием низкоуровневого IL Binary Ninja для построения байтовых масок с маскированием подстановочных символов для переменных операндов, контрольных сумм CRC16 и ссылок на публичные и именованные символы в формате FLIRT. Полученные файлы .pat можно обработать с помощью инструментов FLAIR, таких как sigmake, чтобы создать библиотеки сигнатур .sig для загрузки в IDA Pro. Вдохновлённый idb2pat от Mandiant FLARE и hrtng от Kaspersky, он связывает рабочие процессы создания сигнатур между Binary Ninja и IDA. Предназначен для инженеров по обратной разработке и исследователей безопасности, которым нужно идентифицировать функции в бинарниках без символов или неизвестного происхождения, включая сценарии анализа игр и вредоносного ПО.
