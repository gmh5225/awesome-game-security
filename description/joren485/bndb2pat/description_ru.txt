bndb2pat — это плагин для Binary Ninja, который генерирует файлы шаблонов FLIRT .pat для IDA Pro из бинарных файлов, открытых в Binary Ninja. Написанный на Python, он перебирает функции с использованием низкоуровневого IL Binary Ninja, формируя байтовые маски с подстановочным маскированием для переменных операндов, контрольные суммы CRC16 и ссылки на публичные и именованные символы в формате FLIRT. Полученные файлы .pat можно обработать инструментами FLAIR, такими как sigmake, чтобы создать библиотеки сигнатур .sig для загрузки в IDA Pro. Вдохновлённый idb2pat от Mandiant FLARE и hrtng от Kaspersky, он связывает рабочие процессы создания сигнатур между Binary Ninja и IDA. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности, которым нужно идентифицировать функции в бинарниках без символов или неизвестного происхождения, включая сценарии анализа игр и вредоносного ПО.
