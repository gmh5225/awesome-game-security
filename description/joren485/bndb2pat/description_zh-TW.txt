bndb2pat 是一款 Binary Ninja 外掛，可從在 Binary Ninja 中開啟的二進位檔產生 IDA Pro FLIRT .pat 模式檔。此工具以 Python 撰寫，透過 Binary Ninja 的低階 IL 遍歷函式，建立含可變運算元萬用字元遮罩的位元組遮罩、CRC16 校驗和，以及 FLIRT 格式中的公開與命名符號參考。產生的 .pat 檔可使用 FLAIR 工具（如 sigmake）處理，以產生可載入 IDA Pro 的 .sig 簽名庫。受 Mandiant FLARE 的 idb2pat 與 Kaspersky 的 hrtng 啟發，它在 Binary Ninja 與 IDA 之間銜接簽名建立工作流程。面向需要在剝離符號或未知二進位中識別函式的逆向工程師與安全研究人員，適用於遊戲與惡意軟體分析等情境。
