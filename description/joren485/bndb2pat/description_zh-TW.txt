bndb2pat 是一款 Binary Ninja 外掛，可從在 Binary Ninja 中開啟的二進位檔產生 IDA Pro FLIRT .pat 模式檔。此工具以 Python 撰寫，透過 Binary Ninja 的低階 IL 遍歷函式，為可變運算元建立含萬用字元遮罩的位元組遮罩，並產生 CRC16 校驗和以及 FLIRT 格式中的公開與命名符號參考。產生的 .pat 檔可用 FLAIR 工具（如 sigmake）處理，以建立可載入 IDA Pro 的 .sig 簽章庫。本工具受 Mandiant FLARE 的 idb2pat 與 Kaspersky 的 hrtng 啟發，用於銜接 Binary Ninja 與 IDA 之間的簽章建立工作流程。它面向需要在已剝除符號或未知二進位檔中識別函式的逆向工程師與資安研究人員，適用於遊戲與惡意軟體分析等情境。
