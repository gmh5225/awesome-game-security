bndb2pat 是一款 Binary Ninja 插件，可从在 Binary Ninja 中打开的二进制文件生成 IDA Pro FLIRT .pat 模式文件。该插件用 Python 编写，通过 Binary Ninja 的低层 IL 遍历函数，为可变操作数构建带通配符掩码的字节掩码，并生成 CRC16 校验和以及 FLIRT 格式中的公共与命名符号引用。生成的 .pat 文件可用 FLAIR 工具（如 sigmake）处理，以生成可加载到 IDA Pro 的 .sig 签名库。该工具受 Mandiant FLARE 的 idb2pat 与 Kaspersky 的 hrtng 启发，用于衔接 Binary Ninja 与 IDA 之间的签名创建工作流。它面向需要在已剥离符号或未知二进制中识别函数的逆向工程师与安全研究人员，适用于游戏与恶意软件分析等场景。
