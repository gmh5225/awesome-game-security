bndb2pat 是一款 Binary Ninja 插件，可从在 Binary Ninja 中打开的二进制文件生成 IDA Pro FLIRT .pat 模式文件。该插件使用 Python 编写，通过 Binary Ninja 的低级 IL 遍历函数，构建带有可变操作数通配符掩码的字节掩码、CRC16 校验和，以及 FLIRT 格式中的公共和命名符号引用。生成的 .pat 文件可使用 FLAIR 工具（如 sigmake）处理，以生成可加载到 IDA Pro 的 .sig 签名库。受 Mandiant FLARE 的 idb2pat 和 Kaspersky 的 hrtng 启发，它在 Binary Ninja 与 IDA 之间搭建了签名创建工作流。面向需要在剥离符号或未知二进制中识别函数的反汇编工程师和安全研究人员，适用于游戏与恶意软件分析等场景。
