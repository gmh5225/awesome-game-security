bndb2pat は、Binary Ninja で開いたバイナリから IDA Pro 用の FLIRT .pat パターンファイルを生成する Binary Ninja プラグインです。Python で実装され、Binary Ninja の低レベル IL を用いて関数を走査し、可変オペランド向けのワイルドカードマスク付きバイトマスク、CRC16 チェックサム、および FLIRT 形式の公開・命名シンボル参照を構築します。生成された .pat ファイルは sigmake などの FLAIR ツールで処理し、IDA Pro に読み込める .sig シグネチャライブラリを作成できます。Mandiant FLARE の idb2pat と Kaspersky の hrtng に触発され、Binary Ninja と IDA 間のシグネチャ作成ワークフローを橋渡しします。シンボルが除去されたバイナリや未知のバイナリで関数を特定する必要があるリバースエンジニアやセキュリティ研究者向けで、ゲーム解析やマルウェア解析などの用途を想定しています。
