bndb2pat は、Binary Ninja で開いたバイナリから IDA Pro の FLIRT .pat パターンファイルを生成する Binary Ninja プラグインです。Python で書かれており、Binary Ninja の低レベル IL を用いて関数を走査し、可変オペランドのワイルドカードマスク、CRC16 チェックサム、FLIRT 形式の public および named シンボル参照を含むバイトマスクを構築します。生成された .pat ファイルは、sigmake などの FLAIR ツールで処理し、IDA Pro に読み込める .sig シグネチャライブラリを作成できます。Mandiant FLARE の idb2pat および Kaspersky の hrtng に触発され、Binary Ninja と IDA 間のシグネチャ作成ワークフローを橋渡しします。シンボルが除去された、または未知のバイナリで関数を特定する必要がある逆アセンブラやセキュリティ研究者向けで、ゲームやマルウェア解析などのシナリオを想定しています。
