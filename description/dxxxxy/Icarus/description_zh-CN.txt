Icarus 是一款面向 Minecraft 模组的轻量级 GUI 与配置库，可将带注解的静态字段转为游戏内设置菜单。模组作者用 Java 注解声明页面、分组、滑块、下拉框与按键绑定，库负责构建菜单 UI、持久化 JSON 配置，并支持变更回调、HUD 元素与 toast 提示。它提供与 Minecraft 无关的 Java 8 核心，以及针对 Forge、Fabric 和 NeoForge 的精简适配层，覆盖多个 Minecraft 版本，使用 Gradle 与 Unimined 构建。内置主题高度还原流行的 CS:GO 风格客户端菜单设计，因而适用于 Minecraft 模组工具开发，也适合在游戏安全与逆向工程场景中研究作弊客户端界面。
