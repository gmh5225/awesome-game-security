Icarus는 Minecraft 모드용 경량 GUI 및 설정 라이브러리로, 주석이 달린 정적 필드를 게임 내 설정 메뉴로 바꿉니다. 모드 제작자는 Java 어노테이션으로 페이지, 그룹, 슬라이더, 드롭다운, 키 바인딩을 선언하고, 라이브러리가 메뉴 UI 구성, JSON 설정 영속화, 변경 콜백, HUD 요소, 토스트를 지원합니다. Minecraft와 무관한 Java 8 코어와 Forge, Fabric, NeoForge용 얇은 어댑터를 제공하며 여러 Minecraft 버전을 Gradle과 Unimined로 빌드합니다. 포함된 테마는 인기 있는 CS:GO 스타일 클라이언트 메뉴 디자인을 밀접하게 재현해 Minecraft 모드 도구 개발과 게임 보안·리버스 엔지니어링 맥락에서 치트 클라이언트 인터페이스 연구에 유용합니다.
