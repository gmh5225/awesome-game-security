Icarus is a lightweight GUI and configuration library for Minecraft mods that turns annotated static fields into in-game settings menus. Mod authors declare pages, groups, sliders, dropdowns, and keybinds with Java annotations, and the library builds the menu UI, persists JSON configs, and supports change callbacks, HUD elements, and toasts. It ships a Minecraft-independent Java 8 core with thin per-target adapters for Forge, Fabric, and NeoForge across many Minecraft versions, built with Gradle and Unimined. Included themes closely recreate popular CS:GO-style client menu designs, so it is useful for Minecraft mod tooling and for studying cheat-client interfaces in game-security and reverse-engineering contexts.
