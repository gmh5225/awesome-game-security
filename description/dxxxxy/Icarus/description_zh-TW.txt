Icarus 是一款面向 Minecraft 模組的輕量級 GUI 與設定庫，可將帶註解的靜態欄位轉為遊戲內設定選單。模組作者以 Java 註解宣告頁面、群組、滑桿、下拉選單與按鍵綁定，函式庫負責建構選單 UI、持久化 JSON 設定，並支援變更回呼、HUD 元素與 toast 提示。它提供與 Minecraft 無關的 Java 8 核心，以及針對 Forge、Fabric 與 NeoForge 的精簡適配層，涵蓋多個 Minecraft 版本，以 Gradle 與 Unimined 建置。內建主題高度還原流行的 CS:GO 風格客戶端選單設計，因而適用於 Minecraft 模組工具開發，也適合在遊戲安全與逆向工程情境中研究作弊客戶端介面。
