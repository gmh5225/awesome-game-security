Icarus è una libreria leggera di GUI e configurazione per mod di Minecraft che trasforma campi statici annotati in menu di impostazioni in gioco. Gli autori di mod dichiarano pagine, gruppi, slider, menu a tendina e keybind con annotazioni Java; la libreria costruisce l’interfaccia del menu, persiste configurazioni JSON e supporta callback di modifica, elementi HUD e toast. Include un core Java 8 indipendente da Minecraft con adapter sottili per Forge, Fabric e NeoForge su molte versioni di Minecraft, compilato con Gradle e Unimined. I temi inclusi ricreano fedelmente popolari design di menu client in stile CS:GO, risultando utili per il tooling delle mod Minecraft e per lo studio di interfacce di client cheat in contesti di game security e reverse engineering.
