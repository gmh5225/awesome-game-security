Icarus は Minecraft 向けモッド用の軽量 GUI・設定ライブラリで、アノテーション付き静的フィールドをゲーム内設定メニューに変換します。作者は Java アノテーションでページ、グループ、スライダー、ドロップダウン、キーバインドを宣言し、ライブラリがメニュー UI の構築、JSON 設定の永続化、変更コールバック、HUD 要素、トーストを担当します。Minecraft に依存しない Java 8 コアと、Forge・Fabric・NeoForge 向けの薄いアダプタを備え、多数の Minecraft バージョンを Gradle と Unimined でビルドします。同梱テーマは人気の CS:GO 風クライアントメニューデザインを忠実に再現するため、Minecraft モッド開発ツールとしても、ゲームセキュリティやリバースエンジニアリングでチートクライアント UI を研究する場面でも有用です。
