本プロジェクトは、稼働中の Android プロセスへのリモート共有ライブラリ注入と、Rust によるランタイム API フックを示します。ptrace でアタッチし、メモリをマップして対象 PID で dlopen を呼び出すインジェクタと、32/64 ビット ARM で GOT 書き換えまたはインライン・トランポリン・パッチにより関数を横取りできるフックライブラリが含まれます。フックモジュールはビルド時に自動検出され、Makefile は Android ABI 向けクロスコンパイルと adb によるテストバイナリのプッシュをサポートします。モバイルリバースエンジニアリングとセキュリティ研究向けのスタックであり、ゲームやその他のネイティブ Android アプリがインストルメンテーション下でどう振る舞うかの調査も想定しています。
