This project demonstrates remote shared-library injection into live Android processes and runtime API hooking from Rust. It bundles an injector that uses ptrace to attach, map memory, and call dlopen in a target PID, plus a hook library that can intercept functions through GOT rewriting or inline trampoline patches on 32- and 64-bit ARM. Hook modules are discovered automatically at build time, and a Makefile supports cross-compiling for Android ABIs and pushing test binaries with adb. The stack is aimed at mobile reverse engineering and security research, including studying how games and other native Android apps behave under instrumentation.
