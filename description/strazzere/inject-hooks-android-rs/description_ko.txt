이 프로젝트는 실행 중인 Android 프로세스에 원격으로 공유 라이브러리를 주입하고 Rust로 런타임 API 후킹을 수행하는 방법을 보여 줍니다. ptrace로 대상에 부착해 메모리를 매핑하고 지정 PID에서 dlopen을 호출하는 인젝터와, 32·64비트 ARM에서 GOT 재작성 또는 인라인 트램폴린 패치로 함수를 가로채는 후크 라이브러리가 포함됩니다. 후크 모듈은 빌드 시 자동으로 탐색되며, Makefile은 Android ABI용 크로스 컴파일과 adb로 테스트 바이너리를 푸시하는 것을 지원합니다. 이 스택은 모바일 리버스 엔지니어링과 보안 연구를 위해 설계되었으며, 게임 및 기타 네이티브 Android 앱이 계측 환경에서 어떻게 동작하는지 연구하는 데도 쓰입니다.
