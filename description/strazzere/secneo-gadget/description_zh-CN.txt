SecNeo Gadget 是基于 Frida 的工具包，用于调试、转储和分析经 SecNeo 加壳保护的 Android 应用。项目主要用 TypeScript 实现，编译为可注入的 Frida agent，对 Java 层与 native 层进行 hook，涵盖 DexClassLoader 逻辑、libDexHelper 以及 ART 原生库加载。功能包括反调试绕过 hook、运行时 DEX 转储、强制加载解密后的字节码、JDWP 与 jdb 附加流程，以及配套研究脚本和 IDA 标注辅助工具。面向需要解包或研究 SecNeo 加固应用的逆向工程师与移动安全研究人员，包括依赖该保护方案的游戏与无人机控制类软件。
