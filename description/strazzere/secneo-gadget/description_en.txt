SecNeo Gadget is a Frida-based toolkit for debugging, dumping, and analyzing Android applications protected by the SecNeo packer. It is implemented primarily in TypeScript, compiled into injectable Frida agents that hook Java and native layers, including DexClassLoader logic, libDexHelper, and ART native-library loading. The project includes anti-debug bypass hooks, on-the-fly DEX dumping, forced class loading for decrypted bytecode, JDWP and jdb attach workflows, and supporting research scripts plus IDA annotation helpers. It targets reverse engineers and mobile security researchers who need to unpack or study SecNeo-hardened apps, including game and drone-control software that relies on this protection.
