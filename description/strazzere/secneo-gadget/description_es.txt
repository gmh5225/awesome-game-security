SecNeo Gadget es un kit de herramientas basado en Frida para depurar, volcar y analizar aplicaciones Android protegidas por el packer SecNeo. Está implementado principalmente en TypeScript, compilado en agentes Frida inyectables que enganchan capas Java y nativas, incluida la lógica de DexClassLoader, libDexHelper y la carga de bibliotecas nativas ART. El proyecto incluye hooks de bypass anti-depuración, volcado DEX sobre la marcha, carga forzada de clases para bytecode descifrado, flujos de trabajo de adjunción JDWP y jdb, y scripts de investigación de apoyo más ayudas de anotación para IDA. Está dirigido a ingenieros inversos e investigadores de seguridad móvil que necesitan desempaquetar o estudiar apps endurecidas con SecNeo, incluidos juegos y software de control de drones que dependen de esta protección.
