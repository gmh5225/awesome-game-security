SecNeo Gadget은 SecNeo 패커로 보호된 Android 애플리케이션의 디버깅, 덤프, 분석을 위한 Frida 기반 툴킷입니다. 주로 TypeScript로 구현되며 주입 가능한 Frida 에이전트로 컴파일되어 DexClassLoader 로직, libDexHelper, ART 네이티브 라이브러리 로딩을 포함해 Java 계층과 네이티브 계층을 후킹합니다. 안티 디버그 우회 후크, 실행 중 DEX 덤프, 복호화된 바이트코드의 강제 클래스 로딩, JDWP 및 jdb attach 워크플로, 연구용 스크립트와 IDA 주석 헬퍼를 제공합니다. SecNeo로 강화된 앱의 언팩 또는 분석이 필요한 리버스 엔지니어와 모바일 보안 연구자를 대상으로 하며, 해당 보호에 의존하는 게임 및 드론 제어 소프트웨어 등을 포함합니다.
