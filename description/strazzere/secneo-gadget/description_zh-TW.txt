SecNeo Gadget 是以 Frida 為基礎的工具組，用於除錯、傾印與分析受 SecNeo 加殼保護的 Android 應用程式。專案主要以 TypeScript 實作，編譯為可注入的 Frida agent，對 Java 層與 native 層進行 hook，涵蓋 DexClassLoader 邏輯、libDexHelper 以及 ART 原生函式庫載入。功能包含反除錯繞過 hook、即時 DEX 傾印、強制載入解密後的位元組碼、JDWP 與 jdb 附加流程，以及配套研究腳本與 IDA 註解輔助工具。面向需要解包或研究 SecNeo 加固應用的逆向工程師與行動安全研究人員，包括依賴此保護方案的遊戲與無人機控制類軟體。
