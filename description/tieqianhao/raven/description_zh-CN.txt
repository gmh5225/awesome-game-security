Raven 是一款面向游戏与动漫社区的可复现内容风控引擎，用于识别黑市类帖子，例如外挂销售、代练、账号交易以及站外引流。项目主要以 Python 实现，并附带 JavaScript 浏览器端演示；仅依赖 NumPy 与 Pillow，即可在 CPU 上离线运行从合成数据生成、训练、评估、报告到仿真的完整流程，且可通过单一入口脚本启动。文本链路通过可追溯的规范化流水线将对抗性拼写折叠为规范形式，再应用字符 n-gram 特征、手写的 SGD 逻辑回归模型，以及基于置信度的分级处置规则融合。配套的图像取证模块采用 ELA、噪声残差与 JPEG ghost 启发式方法，并结合块级定位，用于粗粒度的篡改筛查。适合研究游戏社区信任与安全、反滥用工程，以及零宽插入、同音字与逐字混淆等规避手段的科研人员与从业者。
