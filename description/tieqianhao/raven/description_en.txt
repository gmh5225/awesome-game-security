Raven is a reproducible content risk-control engine aimed at gaming and anime communities, built to detect black-market posts such as cheat sales, boosting services, account trading, and off-platform solicitation. It is implemented primarily in Python with a browser-side demo in JavaScript, using only NumPy and Pillow so the full pipeline from synthetic data generation through training, evaluation, reporting, and simulation can run offline on the CPU via a single entry script. The text path folds adversarial spellings into a canonical form through a traceable normalization pipeline, then applies character n-gram features, a hand-rolled SGD logistic regression model, and rule fusion with confidence-based tiered enforcement. A complementary image forensics module applies ELA, noise-residual, and JPEG-ghost heuristics with block-level localization for coarse tamper screening. It suits researchers and practitioners working on game-community trust and safety, anti-abuse engineering, and studying evasion techniques such as zero-width insertion, homophones, and per-character obfuscation.
