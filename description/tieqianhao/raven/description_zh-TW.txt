Raven 是一款面向遊戲與動漫社群的可重現內容風控引擎，用於偵測黑市類貼文，例如外掛販售、代練、帳號交易以及站外引流。專案主要以 Python 實作，並附帶 JavaScript 瀏覽器端示範；僅依賴 NumPy 與 Pillow，即可在 CPU 上離線執行從合成資料生成、訓練、評估、報告到模擬的完整流程，且可透過單一入口腳本啟動。文字路徑透過可追溯的正規化管線將對抗性拼字折疊為規範形式，再套用字元 n-gram 特徵、手寫的 SGD 邏輯迴歸模型，以及依信賴度分級執行的規則融合。配套的影像鑑識模組採用 ELA、雜訊殘差與 JPEG ghost 啟發式方法，並結合區塊級定位，用於粗粒度的竄改篩查。適合研究遊戲社群信任與安全、反濫用工程，以及零寬插入、同音字與逐字混淆等規避手段的研究人員與從業者。
