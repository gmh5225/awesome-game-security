Raven はゲームおよびアニメコミュニティ向けの再現可能なコンテンツリスク管理エンジンであり、チート販売、ブースティング、垢売買、プラットフォーム外への誘導といった闇市系投稿の検出を目的としています。主に Python で実装され、JavaScript によるブラウザ側デモも含み、NumPy と Pillow のみに依存するため、合成データ生成から学習、評価、レポート、シミュレーションまでの一連のパイプラインを CPU 上でオフライン実行でき、単一のエントリスクリプトから起動できます。テキスト経路では、追跡可能な正規化パイプラインにより対抗的表記を正規形に畳み込み、文字 n-gram 特徴、手実装の SGD ロジスティック回帰、信頼度に基づく段階的執行とルール融合を適用します。補完的な画像フォレンジクスモジュールは ELA、ノイズ残差、JPEG ghost ヒューリスティックとブロック単位の局在化により、粗い改ざんスクリーニングを行います。ゲームコミュニティのトラスト＆セーフティ、悪用対策エンジニアリング、ゼロ幅挿入・同音異義語・文字単位の難読化などの回避手法の研究に携わる研究者や実務者に適しています。
