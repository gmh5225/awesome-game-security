Raven — воспроизводимый движок контроля рисков контента для игровых и аниме-сообществ, предназначенный для выявления «чёрнорыночных» публикаций: продажи читов, бустинг-услуг, торговли аккаунтами и увода пользователей за пределы платформы. Реализован в основном на Python с демонстрацией в браузере на JavaScript; используются только NumPy и Pillow, поэтому весь конвейер — от генерации синтетических данных до обучения, оценки, отчётов и симуляции — может работать офлайн на CPU через один входной сценарий. Текстовый путь сводит противоборствующие написания к канонической форме через прослеживаемый конвейер нормализации, затем применяет признаки символьных n-грамм, вручную написанную логистическую регрессию с SGD и слияние правил с поэтапным применением по уровню уверенности. Дополнительный модуль цифровой криминалистики изображений использует эвристики ELA, остатка шума и JPEG ghost с локализацией на уровне блоков для грубого скрининга подделок. Подходит исследователям и практикам в области доверия и безопасности игровых сообществ, антиабьюз-инженерии и изучения техник обхода, таких как вставка нулевой ширины, омофоны и посимвольная обфускация.
