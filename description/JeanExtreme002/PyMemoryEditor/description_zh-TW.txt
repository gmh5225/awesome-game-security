PyMemoryEditor 是一個純 Python 程式庫，可在 Windows、Linux 和 macOS 上透過作業系統層級 API 讀取、寫入並搜尋執行中程序的記憶體。它以 ctypes 為基礎建構，並支援可選的 NumPy 加速掃描，提供 Cheat Engine 風格的數值搜尋、AOB 模式掃描、多層指標鏈以及反向指標掃描。此專案包含一個 PySide6（Qt）GUI，鏡像 Cheat Engine 的附加與掃描工作流程；另提供可選的 Model Context Protocol 伺服器，讓 AI 助手能執行完整的掃描與精煉循環。它適用於遊戲修改、逆向工程，以及需要跨平台程序記憶體分析的遊戲安全研究。
