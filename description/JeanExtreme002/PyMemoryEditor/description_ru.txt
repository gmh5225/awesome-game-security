PyMemoryEditor — это чистая Python-библиотека для чтения, записи и поиска в памяти запущенных процессов через API уровня ОС в Windows, Linux и macOS. Построена на ctypes с опциональным ускоренным сканированием через NumPy и поддерживает поиск значений в стиле Cheat Engine, сканирование AOB-паттернов, многоуровневые цепочки указателей и обратное сканирование указателей. Проект включает GUI на PySide6 (Qt), повторяющий рабочий процесс подключения и сканирования Cheat Engine, а также опциональный сервер Model Context Protocol, позволяющий ИИ-ассистентам выполнять полный цикл сканирования и уточнения. Предназначена для модификации игр, реверс-инжиниринга и исследований в области безопасности игр, где требуется кроссплатформенный анализ памяти процессов.
