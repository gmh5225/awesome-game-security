PyMemoryEditor は、Windows、Linux、macOS 上で OS レベルの API を通じて実行中プロセスのメモリを読み書き・検索できる純粋な Python ライブラリです。ctypes を基盤とし、オプションで NumPy による高速スキャンに対応し、Cheat Engine 風の値検索、AOB パターンスキャン、多段ポインタチェーン、逆ポインタスキャンをサポートします。プロジェクトには Cheat Engine のアタッチ＆スキャンワークフローを再現する PySide6（Qt）GUI と、AI アシスタントがスキャンと絞り込みの一連のループを実行できるオプションの Model Context Protocol サーバーが含まれます。クロスプラットフォームのプロセスメモリ解析が必要なゲーム改造、リバースエンジニアリング、ゲームセキュリティ研究を対象としています。
