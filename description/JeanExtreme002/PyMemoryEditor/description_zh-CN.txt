PyMemoryEditor 是一个纯 Python 库，可在 Windows、Linux 和 macOS 上通过操作系统级 API 读取、写入并搜索运行中进程的内存。它基于 ctypes 构建，并支持可选的 NumPy 加速扫描，实现了 Cheat Engine 风格的数值搜索、AOB 模式扫描、多级指针链以及逆向指针扫描。该项目包含一个 PySide6（Qt）GUI，复现了 Cheat Engine 的附加与扫描工作流程；还提供可选的 Model Context Protocol 服务器，使 AI 助手能够运行完整的扫描与精化循环。它面向游戏修改、逆向工程以及需要跨平台进程内存分析的游戏安全研究。
