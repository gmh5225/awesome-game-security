PyMemoryEditor는 Windows, Linux, macOS에서 OS 수준 API를 통해 실행 중인 프로세스의 메모리를 읽고, 쓰고, 검색할 수 있는 순수 Python 라이브러리입니다. ctypes 기반으로 구축되었으며 선택적으로 NumPy 가속 스캔을 지원하고, Cheat Engine 스타일의 값 검색, AOB 패턴 스캔, 다단계 포인터 체인, 역방향 포인터 스캔을 제공합니다. 이 프로젝트에는 Cheat Engine의 연결 및 스캔 워크플로를 재현하는 PySide6(Qt) GUI와 AI 어시스턴트가 전체 스캔 및 정제 루프를 실행할 수 있게 하는 선택적 Model Context Protocol 서버가 포함되어 있습니다. 크로스 플랫폼 프로세스 메모리 분석이 필요한 게임 모딩, 리버스 엔지니어링, 게임 보안 연구를 대상으로 합니다.
