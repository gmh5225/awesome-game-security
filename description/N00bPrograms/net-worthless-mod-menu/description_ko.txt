Net Worthless Mod Menu는 Godot 4.7 라이프 시뮬레이션 게임 Net Worthless용 인게임 치트 오버레이로, Insert 키로 토글하며 게임 자체 autoload 및 orchestrator 시스템에 연결됩니다. GDScript로 구현되었으며 Godot의 override.cfg autoload 훅을 통해 설치 폴더에 넣으면 실행 파일을 패치하지 않고도 메뉴가 지속적인 Node로 동작합니다. 플레이어 탭에서는 현금 지급·잠금, 체력·행복 전체 또는 고정, 스킬 슬라이더, 월 건너뛰기와 이벤트 자동 선택, 나이 변경, 무료 이사, 마켓플레이스 리롤 등을 제공합니다. 설정에서 월말·게임 오버 신호와 업적 시스템 연결을 끊어 Steam 및 로컬 업적 기록을 막을 수 있고, 선택적 개발 모드는 텍스트 파일의 스크립트 명령을 읽어 자동화와 스크린샷에 쓸 수 있습니다. Godot 클라이언트 측 mod 주입, 런타임 UI 레이어링, 내부 게임 API 호출에 대한 실용적 참고 자료이며, 연구·개인 플레이·싱글플레이 치트와 플랫폼 업적 통합을 살펴보기에 적합합니다.
