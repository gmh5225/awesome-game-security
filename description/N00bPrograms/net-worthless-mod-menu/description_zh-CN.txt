Net Worthless Mod Menu 是面向 Godot 4.7 生活模拟游戏 Net Worthless 的内置作弊叠加层，按 Insert 键开关，并挂接到游戏自身的 autoload 与 orchestrator 系统。它以 GDScript 实现，通过 Godot 的 override.cfg autoload 钩子放入安装目录，使菜单作为持久 Node 运行，无需修补可执行文件。玩家标签页提供现金发放与锁定、满血或锁定健康与幸福、技能滑条、按月跳过并自动选择事件、修改年龄、免费搬家、以及市场重 roll 等功能。设置项可将成就系统从月末与游戏结束信号断开，以阻止 Steam 与本地成就记录；可选开发者模式从文本文件读取脚本命令，便于自动化与截图。该项目是 Godot 客户端模组注入、运行时 UI 分层及调用内部游戏 API 的实用参考，适用于研究、私下游玩或了解单机作弊如何与平台成就交互。
