Net Worthless Mod Menu は、Godot 4.7 の生活シミュレーション『Net Worthless』向けのゲーム内チートオーバーレイで、Insert キーで切り替え、ゲーム本体の autoload と orchestrator システムに接続されています。GDScript で実装され、Godot の override.cfg による autoload フックでインストールフォルダに配置するだけで、実行ファイルをパッチせずにメニューを永続的な Node として動かせます。プレイヤータブでは現金付与とロック、体力・幸福の満タンまたは固定、スキルスライダー、月スキップとイベント自動選択、年齢変更、無料引越し、マーケットのリロールなどが使えます。設定では月末やゲームオーバー信号から実績システムを切り離し、Steam およびローカル実績の記録を防げ、任意の開発モードではテキストファイルからスクリプトコマンドを読み込み、自動化やスクリーンショットに対応します。Godot によるクライアント側 mod 注入、ランタイム UI レイヤリング、内部ゲーム API の呼び出しについて、研究・私的プレイ・シングルプレイチートとプラットフォーム実績の関係を学ぶ際の実践的な参考になります。
