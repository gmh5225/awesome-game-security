Net Worthless Mod Menu is an in-game cheat overlay for the Godot 4.7 life-simulation title Net Worthless, toggled with Insert and wired into the game’s own autoloads and orchestrator systems. It is implemented in GDScript and drops into the install folder via Godot’s override.cfg autoload hook so the menu runs as a persistent Node without patching the executable. Player tabs expose cash grants and locks, full or locked health and happiness, skill sliders, month skipping with automatic event choices, age changes, free housing moves, and marketplace rerolls. A settings option disconnects the achievement system from month-end and game-over signals to block Steam and local achievement recording, and an optional dev mode reads scripted commands from a text file for automation and screenshots. The project is a practical reference for Godot client-side mod injection, runtime UI layering, and calling internal game APIs for research, private play, or studying how single-player cheats integrate with platform achievements.
