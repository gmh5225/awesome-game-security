Net Worthless Mod Menu es una superposición de trampas en el juego para el título de simulación de vida Net Worthless en Godot 4.7, que se activa con Insert y se conecta a los autoloads y al orquestador del propio juego. Está implementado en GDScript y se coloca en la carpeta de instalación mediante el gancho autoload override.cfg de Godot, de modo que el menú se ejecuta como un Node persistente sin parchear el ejecutable. Las pestañas de jugador exponen concesiones y bloqueos de dinero, salud y felicidad completas o fijadas, controles deslizantes de habilidades, salto de meses con elección automática de eventos, cambios de edad, mudanzas de vivienda gratuitas y rerolls del mercado. Una opción de ajustes desconecta el sistema de logros de las señales de fin de mes y game over para bloquear Steam y el registro local de logros, y un modo dev opcional lee comandos scripteados desde un archivo de texto para automatización y capturas. El proyecto es una referencia práctica para inyección de mods en el cliente Godot, capas de UI en tiempo de ejecución y llamadas a API internas del juego, ya sea para investigación, juego privado o estudiar cómo las trampas en un jugador se integran con los logros de la plataforma.
