Net Worthless Mod Menu 是面向 Godot 4.7 生活模擬遊戲 Net Worthless 的遊戲內作弊疊加層，以 Insert 鍵切換，並連接至遊戲自身的 autoload 與 orchestrator 系統。它以 GDScript 實作，透過 Godot 的 override.cfg autoload 掛鉤放入安裝資料夾，使選單作為持久 Node 執行，無需修補可執行檔。玩家分頁提供現金發放與鎖定、滿血或鎖定健康與幸福、技能滑桿、按月跳過並自動選擇事件、變更年齡、免費搬家，以及市場重抽等功能。設定選項可將成就系統自月末與遊戲結束訊號斷開，以阻擋 Steam 與本機成就記錄；可選開發者模式從文字檔讀取腳本命令，利於自動化與截圖。本專案是 Godot 用戶端模組注入、執行時期 UI 分層及呼叫內部遊戲 API 的實用參考，適合研究、私下遊玩或了解單機作弊如何與平台成就整合。
