CantorDust — инструмент визуализации бинарных данных, который помогает специалистам по реверс-инжинирингу увидеть структуру в сырых байтах файла и перейти напрямую к смещениям, дающим интересные закономерности. Реализован в основном на Java как расширение и скрипт для Ghidra, со сборкой через Gradle и небольшой утилитой на Python для очистки при разработке; также может работать как автономное настольное приложение со встроенными визуализациями. Режимы визуализации включают графики значений байтов, облака диграмм и триграмм, метрические карты вдоль space-filling curves, линейные растровые карты и представления частоты байтов, со слайдерами для фокусировки на фрагментах больших файлов. В Ghidra щелчок по точке на визуализации переносит листинг CodeBrowser к соответствующим байтам; автономная сборка даёт те же представления с интегрированной hex-панелью. Предназначен для анализа вредоносного ПО, проверки прошивок и исполняемых файлов и других сценариев реверс-инжиниринга, где распознавание паттернов человеком ускоряет поиск кода, данных и встроенных артефактов.
