CantorDust 是一款二進位視覺化工具，協助逆向工程師在原始檔案位元組中看見結構，並直接跳轉至產生有趣模式的偏移位置。它主要以 Java 實作，作為 Ghidra 擴充功能與指令碼，採用 Gradle 建置，並附帶用於開發清理的小型 Python 工具；也可作為獨立桌面應用程式執行，內建視覺化功能。視覺化模式包含位元組值圖、二元與三元語法雲、沿空間填充曲線的度量圖、線性點陣圖以及位元組頻率檢視，並以滑桿聚焦大型檔案中的區域。在 Ghidra 中，點選視覺化上的點即可將 CodeBrowser 清單跳轉至對應位元組；獨立版本提供相同檢視並整合十六進位窗格。適用於惡意軟體分析、韌體與可執行檔檢查，以及其他依賴人工模式辨識以更快定位程式碼、資料與嵌入式構件的逆向工程工作流程。
