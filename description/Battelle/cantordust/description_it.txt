CantorDust è uno strumento di visualizzazione binaria che aiuta gli ingegneri del reverse engineering a individuare struttura nei byte grezzi di un file e a passare direttamente agli offset che producono pattern interessanti. È implementato principalmente in Java come estensione e script Ghidra, con build Gradle e una piccola utilità Python per la pulizia in sviluppo, e può anche essere eseguito come applicazione desktop autonoma con visualizzazioni incluse. Le modalità visive includono grafici dei valori di byte, nuvole di digrammi e trigrammi, mappe metriche lungo curve di riempimento dello spazio, bitmap lineari e viste di frequenza dei byte, con cursori per concentrarsi su regioni di file grandi. In Ghidra, un clic su un punto della visualizzazione sposta l’elenco del CodeBrowser ai byte corrispondenti; la build standalone offre le stesse viste con un riquadro hex integrato. È pensato per l’analisi malware, l’ispezione di firmware ed eseguibili e altri flussi di reverse engineering in cui il riconoscimento umano dei pattern accelera il ritrovamento di codice, dati e artefatti incorporati.
