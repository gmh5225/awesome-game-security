CantorDust is a binary visualization tool that helps reverse engineers see structure in raw file bytes and navigate directly to the offsets that produce interesting patterns. It is implemented primarily in Java as a Ghidra extension and script, with Gradle builds and a small Python utility for development cleanup, and it can also run as a standalone desktop app with bundled visualizations. Visual modes include byte-value plots, digraph and trigram clouds, metric maps along space-filling curves, linear bitmaps, and byte-frequency views, with sliders to focus on regions of large files. In Ghidra, clicking a visualization point jumps the CodeBrowser listing to the corresponding bytes; the standalone build offers the same views with an integrated hex pane. It targets malware analysis, firmware and executable inspection, and other reverse-engineering workflows where human pattern recognition speeds up finding code, data, and embedded artifacts.
