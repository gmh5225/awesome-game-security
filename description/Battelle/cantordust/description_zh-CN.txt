CantorDust 是一款二进制可视化工具，帮助逆向工程师在原始文件字节中发现结构，并直接跳转到产生有趣模式的偏移位置。它主要用 Java 实现，作为 Ghidra 扩展与脚本，采用 Gradle 构建，并附带用于开发清理的小型 Python 工具；也可作为独立桌面应用运行，内置可视化功能。可视化模式包括字节值图、二元和三元语法云、沿空间填充曲线的度量图、线性位图以及字节频率视图，并通过滑块聚焦大文件中的区域。在 Ghidra 中，点击可视化上的点即可将 CodeBrowser 列表跳转到对应字节；独立版本提供相同视图并集成十六进制窗格。适用于恶意软件分析、固件与可执行文件检查，以及其他依赖人工模式识别以更快定位代码、数据和嵌入式构件的逆向工程工作流。
