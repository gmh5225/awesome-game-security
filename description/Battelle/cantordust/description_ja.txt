CantorDust は、生のファイルバイトから構造を把握し、興味深いパターンを生むオフセットへ直接移動できるようにする、逆アセンブリ向けのバイナリ可視化ツールです。主に Java で実装され、Ghidra 拡張とスクリプトとして動作し、Gradle ビルドと開発用クリーンアップの小さな Python ユーティリティを備え、バンドルされた可視化付きのスタンドアロン desktop アプリとしても実行できます。可視化モードにはバイト値プロット、ダイグラフおよびトライグラムクラウド、空間充填曲線に沿ったメトリックマップ、線形ビットマップ、バイト頻度ビューがあり、大きなファイルの領域に絞り込むスライダーも用意されています。Ghidra では可視化上の点をクリックすると CodeBrowser のリスティングが対応するバイトへジャンプし、スタンドアロンビルドでも同じビューと統合された hex ペインを提供します。マルウェア解析、ファームウェアおよび実行ファイルの調査、その他、人間のパターン認識でコード、データ、埋め込みアーティファクトの発見を加速する逆アセンブリワークフローを対象としています。
