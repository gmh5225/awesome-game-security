AntiCheat-detection is a research repository that documents how major commercial game anti-cheat systems work, based on static and dynamic reverse engineering of their client and kernel components. It provides long-form reference write-ups for BattlEye, Easy Anti-Cheat, Riot Vanguard, FACEIT, EA AntiCheat, Denuvo, and related modules, covering kernel callbacks, memory and syscall scanning, hypervisor and DMA detection, HWID and ban telemetry, and forensic cleanup traces. The tree also includes reconstructed C implementations and Visual Studio projects that model Vanguard user-mode and kernel services and an Easy Anti-Cheat EOS-style kernel driver for side-by-side study with the markdown analyses. Material is aimed at game security researchers, reverse engineers, and defenders who need structured, technical insight into real-world anti-cheat architecture rather than marketing summaries. Content is offered for educational study of detection mechanics and platform behavior on Windows.
