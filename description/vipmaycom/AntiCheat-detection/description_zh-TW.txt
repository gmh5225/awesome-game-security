AntiCheat-detection 是一個研究型儲存庫，透過對主流商業遊戲反作弊系統的用戶端與核心元件進行靜態與動態逆向，記錄其運作方式。其中包含 BattlEye、Easy Anti-Cheat、Riot Vanguard、FACEIT、EA AntiCheat、Denuvo 及相關模組的長篇參考文件，涵蓋核心回呼、記憶體與系統呼叫掃描、Hypervisor 與 DMA 偵測、HWID 與封禁遙測，以及鑑識清理痕跡等主題。儲存庫另提供重建的 C 實作與 Visual Studio 專案，用於建模 Vanguard 使用者模式與核心服務，以及 Easy Anti-Cheat 的 EOS 風格核心驅動程式，便於與 Markdown 分析對照研讀。內容面向需要結構化、技術性視角以理解真實反作弊架構（而非行銷式概述）的遊戲安全研究人員、逆向工程師與防禦方。材料僅供在 Windows 上從教育角度研究偵測機制與平台行為之用。
