AntiCheat-detection 是一个研究型仓库，通过对主流商业游戏反作弊系统的客户端与内核组件进行静态与动态逆向，记录其工作原理。其中包含 BattlEye、Easy Anti-Cheat、Riot Vanguard、FACEIT、EA AntiCheat、Denuvo 及相关模块的长篇参考文档，涵盖内核回调、内存与系统调用扫描、虚拟机监控与 DMA 检测、HWID 与封禁遥测，以及取证清理痕迹等主题。仓库还提供重建的 C 实现与 Visual Studio 工程，用于建模 Vanguard 用户态与内核服务以及 Easy Anti-Cheat 的 EOS 风格内核驱动，便于与 Markdown 分析对照研读。内容面向需要结构化、技术性视角以理解真实反作弊架构（而非营销式概述）的游戏安全研究人员、逆向工程师与防御方。材料仅供在 Windows 上从教育角度研究检测机制与平台行为之用。
