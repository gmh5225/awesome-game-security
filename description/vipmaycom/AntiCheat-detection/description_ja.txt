AntiCheat-detection は、主要な商用ゲームアンチチートのクライアントおよびカーネルコンポーネントを静的・動的リバースエンジニアリングし、その仕組みを文書化する研究用リポジトリです。BattlEye、Easy Anti-Cheat、Riot Vanguard、FACEIT、EA AntiCheat、Denuvo など関連モジュールについて、カーネルコールバック、メモリおよびシステムコールスキャン、ハイパーバイザーと DMA 検知、HWID と BAN テレメトリ、フォレンジック上のクリーンアップ痕跡などを扱う長文の参考解説を提供します。リポジトリには、Vanguard のユーザーモードおよびカーネルサービス、Easy Anti-Cheat の EOS 形式カーネルドライバーをモデル化した再構成 C 実装と Visual Studio プロジェクトも含まれ、Markdown による分析と並べて学べます。マーケティング的な概要ではなく、実運用のアンチチートアーキテクチャを構造的かつ技術的に理解したいゲームセキュリティ研究者、リバースエンジニア、防御側向けの内容です。Windows 上の検知メカニズムとプラットフォーム挙動を教育目的で学ぶための資料として提供されています。
