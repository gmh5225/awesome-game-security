Hack The Web는 브라우저 기반 퍼즐 플랫폼을 위한 셀프 호스팅 가능한 소스로, 플레이어가 인터랙티브 어드벤처 안에서 웹 보안 및 해킹 테마의 챌린지를 진행합니다. Express와 EJS 템플릿을 사용하는 Node.js 애플리케이션으로 구축되었으며, Sequelize로 데이터베이스에 접근하고 JWT 및 쿠키 기반 세션, CSRF 보호, Socket.io를 통한 실시간 기능을 제공합니다. 저장소에는 브라우저 내 챌린지 스크립트, 퀴즈, 맵, 편집기 도구의 방대한 라이브러리가 포함되며, 스포일러 답은 별도 secrets 파일에 두고 운영자가 과제를 풀은 뒤 채웁니다. 교육자, CTF 애호가, 보안 학습자가 로컬 또는 자체 인프라에서 완전한 웹 해킹 훈련 사이트를 학습하거나 운영하기에 적합합니다.
