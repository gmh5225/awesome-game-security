Hack The Web è il codice sorgente auto-ospitabile di una piattaforma di puzzle basata sul browser, in cui i giocatori affrontano sfide sulla sicurezza web e sul hacking all’interno di un’avventura interattiva. È realizzato come applicazione Node.js con Express e template EJS, Sequelize per l’accesso al database, sessioni basate su JWT e cookie, protezione CSRF e Socket.io per le funzionalità in tempo reale. Il repository include una vasta libreria di script di sfide in-browser, quiz, mappe e strumenti di editing, mentre le risposte spoiler restano in un file secrets separato che gli operatori compilano dopo aver risolto le prove. È adatto a docenti, appassionati di CTF e studenti di sicurezza che vogliano studiare o gestire un sito completo di formazione al web hacking in locale o sulla propria infrastruttura.
