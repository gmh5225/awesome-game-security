Hack The Web is the self-hostable source for a browser-based puzzle platform where players work through web security and hacking-themed challenges inside an interactive adventure. It is built as a Node.js application using Express and EJS templates, with Sequelize for database access, JWT and cookie-based sessions, CSRF protection, and Socket.io for real-time features. The repository bundles a large library of in-browser challenge scripts, quizzes, maps, and editor tooling, while keeping spoiler answers in a separate secrets file that operators populate after solving tasks. It suits educators, CTF enthusiasts, and security learners who want to study or run a full web-hacking training site locally or on their own infrastructure.
