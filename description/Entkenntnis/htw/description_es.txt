Hack The Web es el código fuente autoalojable de una plataforma de puzzles en el navegador en la que los jugadores avanzan por retos de seguridad web y temática de hacking dentro de una aventura interactiva. Está construido como aplicación Node.js con Express y plantillas EJS, Sequelize para el acceso a la base de datos, sesiones basadas en JWT y cookies, protección CSRF y Socket.io para funciones en tiempo real. El repositorio incluye una amplia biblioteca de scripts de retos en el navegador, cuestionarios, mapas y herramientas de edición, mientras que las respuestas con spoilers permanecen en un archivo secrets aparte que los operadores completan tras resolver las tareas. Es adecuado para educadores, entusiastas del CTF y aprendices de seguridad que quieran estudiar o ejecutar un sitio completo de entrenamiento en hacking web de forma local o en su propia infraestructura.
