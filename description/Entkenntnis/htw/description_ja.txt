Hack The Web は、ブラウザ上のパズルプラットフォーム向けのセルフホスト可能なソースで、プレイヤーがインタラクティブなアドベンチャーの中で Web セキュリティやハッキングをテーマにしたチャレンジに取り組めます。Node.js アプリケーションとして Express と EJS テンプレートで構築され、Sequelize でデータベースにアクセスし、JWT と Cookie ベースのセッション、CSRF 保護、Socket.io によるリアルタイム機能を備えています。リポジトリにはブラウザ内チャレンジ用スクリプト、クイズ、マップ、エディタツールの大規模なライブラリが同梱され、ネタバレの答えは別の secrets ファイルに分離され、運用者が課題を解いた後に記入します。教育者、CTF 愛好家、セキュリティ学習者が、ローカルまたは自前のインフラで Web ハッキング訓練サイトを学習・運用するのに適しています。
