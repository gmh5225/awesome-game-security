Este proyecto es un conjunto de scripts Python para IDA Pro que detectan, descifran y anotan automáticamente cadenas ofuscadas en bibliotecas compartidas de Tencent Anogs y ACE (Anti-Cheat Expert), como libanogs.so en títulos móviles incluido PUBG Mobile. Un script maestro de entrada enruta binarios ARM de 32 y 64 bits a motores específicos por versión, localiza de forma heurística funciones de descifrado y acceso mediante referencias cruzadas y puede inferir ubicaciones de tablas de cadenas a partir de instrucciones ADR y ADRL en ARM64. El texto plano descifrado se aplica como comentarios en línea en el desensamblado y el pseudocódigo Hex-Rays, y puede exportarse como texto formateado y JSON con metadatos de sitios de llamada. Está dirigido a ingenieros inversos e investigadores de seguridad en juegos que necesitan cadenas legibles al analizar código antitrampas y de protección en binarios de juegos Android ARM.
