本プロジェクトは、Tencent Anogs および ACE（Anti-Cheat Expert）の共有ライブラリ（PUBG Mobile などのモバイルタイトルに含まれる libanogs.so など）内の難読化された文字列を自動検出・復号し、注釈付けする IDA Pro 用 Python スクリプト群です。マスター入口スクリプトが 32 ビットおよび 64 ビット ARM バイナリをバージョン別エンジンに振り分け、クロスリファレンスで復号器およびアクセサ関数をヒューリスティックに特定し、ARM64 では ADR および ADRL 命令から文字列テーブル位置を推定できます。復号された平文は逆アセンブリおよび Hex-Rays 疑似コードにインラインコメントとして反映され、呼び出しサイトのメタデータ付きで整形テキストおよび JSON としてエクスポート可能です。ARM Android ゲームバイナリ内の反チートおよび保護コードを解析する際に可読な文字列が必要なリバースエンジニアおよびゲームセキュリティ研究者向けです。
