Ce projet est un ensemble de scripts Python pour IDA Pro qui détectent, déchiffrent et annotent automatiquement les chaînes obfusquées dans les bibliothèques partagées Tencent Anogs et ACE (Anti-Cheat Expert), notamment libanogs.so dans des titres mobiles comme PUBG Mobile. Un script maître achemine les binaires ARM 32 et 64 bits vers des moteurs adaptés à chaque version, repère de façon heuristique les fonctions de déchiffrement et d’accès via les références croisées, et peut inférer l’emplacement des tables de chaînes à partir des instructions ADR et ADRL sur ARM64. Le texte en clair déchiffré est appliqué sous forme de commentaires inline dans le désassemblage et le pseudocode Hex-Rays, et peut être exporté en texte formaté et JSON avec les métadonnées des sites d’appel. Il s’adresse aux ingénieurs en rétro-ingénierie et chercheurs en sécurité des jeux qui ont besoin de chaînes lisibles lors de l’analyse du code anti-triche et de protection dans les binaires de jeux Android ARM.
