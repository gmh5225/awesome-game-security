Этот проект — набор Python-скриптов для IDA Pro, которые автоматически обнаруживают, расшифровывают и помечают обфусцированные строки в общих библиотеках Tencent Anogs и ACE (Anti-Cheat Expert), например libanogs.so из мобильных игр вроде PUBG Mobile. Главный входной скрипт направляет 32- и 64-битные ARM-бинарники в движки под конкретные версии, эвристически находит функции расшифровки и доступа через перекрёстные ссылки и на ARM64 может выводить расположение таблиц строк по инструкциям ADR и ADRL. Расшифрованный открытый текст добавляется inline-комментариями в дизассемблер и псевдокод Hex-Rays и может экспортироваться в форматированный текст и JSON с метаданными мест вызова. Предназначен для инженеров по реверсу и исследователей игровой безопасности, которым нужны читаемые строки при разборе античита и защитного кода в ARM-бинарниках Android-игр.
