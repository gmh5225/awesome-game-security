本專案是一組 IDA Pro Python 腳本，可在騰訊 Anogs 與 ACE（Anti-Cheat Expert）等共用函式庫（例如 PUBG Mobile 等手遊中的 libanogs.so）中自動偵測、解密並標註被混淆的字串。主入口腳本會將 32 位元與 64 位元 ARM 二進位檔分別導向對應版本的引擎，透過交叉參考啟發式尋找解密與存取函式，並可在 ARM64 上依 ADR、ADRL 指令推斷字串表位置。解密後的明文會以行內註解形式套用於反組譯與 Hex-Rays 偽程式碼，並可連同呼叫點中繼資料匯出為格式化文字與 JSON。面向需要在 ARM Android 遊戲二進位檔中分析反作弊與保護程式碼、並希望取得可讀字串的逆向工程師與遊戲安全研究人員。
