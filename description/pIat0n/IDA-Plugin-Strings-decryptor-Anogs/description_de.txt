Dieses Projekt ist eine Sammlung von IDA-Pro-Python-Skripten, die verschleierte Strings in den Shared Libraries von Tencent Anogs und ACE (Anti-Cheat Expert) — etwa libanogs.so aus mobilen Titeln wie PUBG Mobile — automatisch erkennen, entschlüsseln und annotieren. Ein Master-Einstiegsskript leitet 32- und 64-Bit-ARM-Binaries an versionsspezifische Engines weiter, findet Entschlüsseler- und Zugriffsfunktionen heuristisch über Querverweise und kann auf ARM64 Stringtabellenpositionen aus ADR- und ADRL-Anweisungen ableiten. Entschlüsselter Klartext wird als Inline-Kommentare in Disassembly und Hex-Rays-Pseudocode eingetragen und kann mit Aufrufstellen-Metadaten als formatierter Text und JSON exportiert werden. Es richtet sich an Reverse Engineers und Game-Security-Forscher, die beim Analysieren von Anti-Cheat- und Schutzcode in ARM-Android-Spielbinaries lesbare Strings benötigen.
