本项目是一组 IDA Pro Python 脚本，可在腾讯 Anogs 与 ACE（Anti-Cheat Expert）等共享库（例如 PUBG Mobile 等手游中的 libanogs.so）中自动检测、解密并标注被混淆的字符串。主入口脚本将 32 位与 64 位 ARM 二进制分别路由到对应版本的引擎，通过交叉引用启发式定位解密与访问函数，并可在 ARM64 上根据 ADR、ADRL 指令推断字符串表位置。解密后的明文会以行内注释形式写入反汇编与 Hex-Rays 伪代码，并可连同调用点元数据导出为格式化文本与 JSON。面向需要在 ARM Android 游戏二进制中分析反作弊与保护代码、并希望获得可读字符串的逆向工程师与游戏安全研究人员。
