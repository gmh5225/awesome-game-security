This project is a set of IDA Pro Python scripts that automatically detect, decrypt, and annotate obfuscated strings in Tencent Anogs and ACE (Anti-Cheat Expert) shared libraries such as libanogs.so from mobile titles including PUBG Mobile. A master entry script routes 32-bit and 64-bit ARM binaries to version-specific engines, heuristically finds decryptor and accessor functions via cross-references, and can infer string table locations from ADR and ADRL instructions on ARM64. Decrypted plaintext is applied as inline comments in disassembly and Hex-Rays pseudocode, and can be exported as formatted text and JSON with call-site metadata. It is aimed at reverse engineers and game security researchers who need readable strings when analyzing anti-cheat and protection code in ARM Android game binaries.
