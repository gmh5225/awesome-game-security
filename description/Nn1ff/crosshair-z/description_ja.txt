Crosshair Z は、ボーダーレスまたはウィンドウモードのゲーム向けに、透明で常に前面に表示されるオーバーレイ上にカスタマイズ可能な照準を描画する軽量 Windows デスクトップアプリです。Electron と JavaScript で構築され、必要に応じて koffi ネイティブバインディングで低レベルのマウス入力を扱い、ランタイム依存を最小限に抑えたポータブル実行ファイルとして配布されます。オーバーレイにはピクセルグリッドデザイナーがあり、線・輪郭・中心点・円・画像レイヤーに加え、発射時の拡散アニメーション、照準ごとのホットキー、共有コード、ローカル保存の Crosshair X プロファイルのインポートに対応します。意図的に DLL インジェクションやゲーム内フックを避け、通常のトップレベルウィンドウのみを提示するため、一般的なアンチチートの想定と両立しつつ、より重い照準ツールに代わるオフライン優先の選択肢をプレイヤーに提供します。
