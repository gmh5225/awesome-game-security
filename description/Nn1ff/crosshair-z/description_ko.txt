Crosshair Z는 테두리 없는 창 또는 창 모드 게임을 위해 투명하고 항상 위에 표시되는 오버레이에 사용자 지정 크로스헤어를 그리는 경량 Windows 데스크톱 앱입니다. Electron과 JavaScript로 만들어졌으며, 필요할 때 koffi 네이티브 바인딩으로 저수준 마우스 입력을 처리하고, 런타임 의존성을 최소화한 휴대용 실행 파일로 제공됩니다. 오버레이에는 픽셀 그리드 디자이너가 있어 선, 외곽선, 중심점, 원, 이미지 레이어와 함께 사격 확산 애니메이션, 크로스헤어별 단축키, 공유 코드, 로컬에 저장된 Crosshair X 프로필 가져오기를 지원합니다. DLL 주입과 게임 내 후크를 의도적으로 피하고 일반 최상위 창만 표시하므로 일반적인 안티치트 기대와 호환되면서, 더 무거운 크로스헤어 도구 대신 오프라인 우선 대안을 플레이어에게 제공합니다.
