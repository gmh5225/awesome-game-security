Crosshair Z — лёгкое настольное приложение для Windows, которое рисует настраиваемый прицел в прозрачном оверлее поверх всех окон для игр в безрамочном или оконном режиме. Оно создано на Electron и JavaScript, при необходимости использует нативную привязку koffi для низкоуровневого ввода мыши и поставляется как портативный исполняемый файл с минимальными зависимостями среды выполнения. Оверлей включает конструктор на пиксельной сетке с линиями, контурами, центральными точками, кругами и слоями изображений, а также анимацию разброса при стрельбе, горячие клавиши для каждого прицела, коды для обмена и импорт локально сохранённых профилей Crosshair X. Приложение намеренно не использует инъекцию DLL и внутриигровые хуки, показывая только обычное окно верхнего уровня, поэтому остаётся совместимым с типичными ожиданиями античита и даёт игрокам автономную альтернативу более тяжёлым инструментам прицеливания.
