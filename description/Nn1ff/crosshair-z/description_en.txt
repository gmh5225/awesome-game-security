Crosshair Z is a lightweight Windows desktop app that draws a customizable crosshair in a transparent, always-on-top overlay for borderless or windowed games. It is built with Electron and JavaScript, uses the koffi native binding for low-level mouse input where needed, and ships as a portable executable with minimal runtime dependencies. The overlay includes a pixel-grid designer with lines, outlines, center dots, circles, and image layers, plus firing spread animation, per-crosshair hotkeys, share codes, and import of locally saved Crosshair X profiles. It deliberately avoids DLL injection and in-game hooks, presenting only a plain top-level window so it stays compatible with typical anti-cheat expectations while giving players an offline-first alternative to heavier crosshair tools.
