本项目是一套在主机端运行的工具集，可从已越狱的 iPhone 或 iPad 上运行的应用中拉取完整解密的 IPA 包。Python 驱动程序通过 Frida 附加进程，注入 JavaScript 代理，利用 Objective-C 桥接在 FairPlay 加密被剥离后转储内存中的 Mach-O 二进制文件及内嵌框架，随后通过 USB 或 SSH 上的并行 SFTP 传输重新打包应用 bundle。它支持按显示名称或 bundle 标识符列出已安装应用，兼容 Frida 17 并内置 frida-objc-bridge 编译，以及包括 SSH 配置别名与密钥在内的灵活认证方式。该工作流面向需要可分析 iOS 二进制文件以进行静态检查、补丁流程或研究受保护游戏与应用在设备上行为的移动安全研究人员与逆向工程师。
