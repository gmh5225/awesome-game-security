本專案是一套在主機端運行的工具集，可從已越獄的 iPhone 或 iPad 上執行的應用程式中拉取完整解密的 IPA 套件。Python 驅動程式透過 Frida 附加程序，注入 JavaScript 代理，利用 Objective-C 橋接在 FairPlay 加密被剝離後傾印記憶體中的 Mach-O 二進位檔與內嵌框架，隨後透過 USB 或 SSH 上的並行 SFTP 傳輸重新封裝應用程式 bundle。它支援依顯示名稱或 bundle 識別碼列出已安裝應用程式，相容 Frida 17 並內建 frida-objc-bridge 編譯，以及包含 SSH 設定別名與金鑰在內的彈性驗證方式。此工作流程面向需要可分析 iOS 二進位檔以進行靜態檢查、修補流程或研究受保護遊戲與應用程式在裝置上行為的行動安全研究人員與逆向工程師。
