Este proyecto es un conjunto de herramientas en el host que extrae paquetes IPA totalmente descifrados de aplicaciones en ejecución en un iPhone o iPad con jailbreak. Un controlador en Python se adjunta con Frida, inyecta un agente JavaScript que usa el puente Objective-C para volcar binarios Mach-O en memoria y frameworks embebidos tras eliminar el cifrado FairPlay, y reempaqueta el bundle con transferencias SFTP en paralelo por USB o SSH. Permite listar apps instaladas por nombre visible o identificador de bundle, admite Frida 17 con compilación incluida de frida-objc-bridge y autenticación flexible con alias y claves de configuración SSH. El flujo de trabajo está pensado para investigadores de seguridad móvil e ingenieros inversores que necesitan binarios iOS analizables para inspección estática, flujos de parcheo o estudiar el comportamiento en dispositivo de juegos y apps protegidos.
