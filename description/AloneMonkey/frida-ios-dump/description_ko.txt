이 프로젝트는 탈옥된 iPhone 또는 iPad에서 실행 중인 앱으로부터 완전히 복호화된 IPA 패키지를 가져오는 호스트 측 툴킷입니다. Python 드라이버가 Frida로 attach하고 JavaScript 에이전트를 주입하여 Objective-C 브리지로 FairPlay 암호화가 제거된 상태에서 메모리상 Mach-O 바이너리와 내장 프레임워크를 덤프한 뒤, USB 또는 SSH를 통한 병렬 SFTP 전송으로 번들을 다시 패키징합니다. 표시 이름 또는 bundle 식별자로 설치된 앱 목록 조회, Frida 17 및 번들된 frida-objc-bridge 컴파일, SSH 설정 별칭과 키를 포함한 유연한 인증을 지원합니다. 이 워크플로는 정적 분석, 패치 작업 또는 보호된 게임과 앱의 기기상 동작 연구를 위해 분석 가능한 iOS 바이너리가 필요한 모바일 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
