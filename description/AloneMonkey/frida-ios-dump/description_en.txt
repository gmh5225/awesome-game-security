This project is a host-side toolkit that pulls fully decrypted IPA packages from apps running on a jailbroken iPhone or iPad. A Python driver attaches with Frida, injects a JavaScript agent that uses the Objective-C bridge to dump in-memory Mach-O binaries and embedded frameworks while FairPlay encryption is stripped, then repackages the bundle with parallel SFTP transfers over USB or SSH. It supports listing installed apps by display name or bundle identifier, Frida 17 with bundled frida-objc-bridge compilation, and flexible authentication including SSH config aliases and keys. The workflow is aimed at mobile security researchers and reverse engineers who need analyzable iOS binaries for static inspection, patching workflows, or studying how protected games and apps behave on device.
