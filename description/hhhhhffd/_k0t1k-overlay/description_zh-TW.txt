本專案為 Minecraft Java 版提供類似 Steam 的遊戲內疊加層，以單一 fat JAR 形式交付，透過 Java agent 掛載而非作為模組載入。它使用 Byte Buddy 掛鉤 LWJGL 的 swap、present 與輸入呼叫，在成品畫面上繪製並擷取輸入，無需修改 Minecraft 類別，支援從約 1.8 到目前版本的 vanilla、Fabric、Forge 與 NeoForge，可在 OpenGL 或 Vulkan 上執行。疊加層整合聊天紀錄搜尋、持久化筆記、模組列表、效能 HUD、可選 JCEF Chromium 瀏覽、GPU 回放片段及相關工具，透過遊戲自帶的 LWJGL 堆疊以 GLSL 或 SPIR-V 渲染。面向希望取得跨版本疊加功能的玩家與啟動器整合方，也可作為 JVM 插樁、圖形 API 掛鉤及用戶端疊加注入等逆向與遊戲安全研究實務的參考。
