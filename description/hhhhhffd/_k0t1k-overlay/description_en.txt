This project is a Steam-style in-game overlay for Minecraft Java Edition, delivered as a single fat JAR that attaches through a Java agent rather than as a mod. It uses Byte Buddy to hook LWJGL swap, present, and input calls so it can draw over the finished frame and capture input without modifying Minecraft classes, supporting vanilla, Fabric, Forge, and NeoForge from roughly 1.8 through current releases on OpenGL or Vulkan. The overlay bundles chat history search, persistent notes, mod listings, performance HUD, optional JCEF Chromium browsing, GPU-backed replay clips, and related utilities, with GLSL or SPIR-V rendering via the game’s own LWJGL stack. It is aimed at players and launcher integrators who want cross-version overlay features, and it serves as a practical reference for JVM instrumentation, graphics API hooking, and client-side overlay injection techniques relevant to reverse engineering and game security research.
