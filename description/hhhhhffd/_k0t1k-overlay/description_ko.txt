이 프로젝트는 Minecraft Java Edition용 Steam 스타일 인게임 오버레이로, 모드가 아니라 Java 에이전트를 통해 부착되는 단일 fat JAR로 제공된다. Byte Buddy로 LWJGL의 swap, present 및 입력 호출을 후킹해 완성된 프레임 위에 그리며 입력을 캡처하므로 Minecraft 클래스를 수정하지 않고, OpenGL 또는 Vulkan에서 대략 1.8부터 최신 릴리스까지 vanilla, Fabric, Forge, NeoForge를 지원한다. 오버레이에는 채팅 기록 검색, 영구 메모, 모드 목록, 성능 HUD, 선택적 JCEF Chromium 브라우징, GPU 기반 리플레이 클립 및 관련 유틸리티가 포함되며, 게임 자체 LWJGL 스택을 통해 GLSL 또는 SPIR-V로 렌더링한다. 크로스 버전 오버레이 기능을 원하는 플레이어와 런처 통합자를 대상으로 하며, JVM 계측, 그래픽 API 후킹, 클라이언트 측 오버레이 주입 등 리버스 엔지니어링 및 게임 보안 연구와 관련된 실용적 참고 자료 역할을 한다.
