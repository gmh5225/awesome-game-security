Ce projet est une surcouche in-game de style Steam pour Minecraft Java Edition, livrée sous la forme d’un seul fat JAR qui s’attache via un agent Java plutôt qu’en tant que mod. Il utilise Byte Buddy pour intercepter les appels swap, present et d’entrée de LWJGL afin de dessiner par-dessus l’image finale et de capturer les entrées sans modifier les classes Minecraft, en prenant en charge vanilla, Fabric, Forge et NeoForge d’environ la 1.8 jusqu’aux versions actuelles sur OpenGL ou Vulkan. La surcouche regroupe recherche dans l’historique de chat, notes persistantes, listes de mods, HUD de performances, navigation Chromium JCEF optionnelle, clips de replay accélérés GPU et utilitaires associés, avec rendu GLSL ou SPIR-V via la pile LWJGL du jeu. Elle s’adresse aux joueurs et intégrateurs de lanceurs qui veulent des fonctionnalités d’overlay multi-versions, et sert de référence pratique pour l’instrumentation JVM, le hooking d’API graphiques et les techniques d’injection de surcouche côté client pertinentes pour l’ingénierie inverse et la recherche en sécurité des jeux.
