本プロジェクトは Minecraft Java Edition 向けの Steam 風インゲームオーバーレイで、モッドではなく Java エージェント経由でアタッチする単一の fat JAR として提供される。Byte Buddy で LWJGL の swap、present、入力呼び出しをフックし、完成フレーム上に描画して入力を取得するため Minecraft クラスを改変せず、OpenGL または Vulkan 上でおおよそ 1.8 から現行リリースまでの vanilla、Fabric、Forge、NeoForge をサポートする。オーバーレイにはチャット履歴検索、永続メモ、Mod 一覧、パフォーマンス HUD、任意の JCEF Chromium ブラウジング、GPU バックのリプレイクリップなどが含まれ、ゲーム本体の LWJGL スタック経由で GLSL または SPIR-V レンダリングを行う。クロスバージョンのオーバーレイ機能を求めるプレイヤーやランチャー統合者向けであり、JVM インストルメンテーション、グラフィックス API フック、クライアント側オーバーレイ注入など、リバースエンジニアリングとゲームセキュリティ研究に関わる実践的な参考となる。
