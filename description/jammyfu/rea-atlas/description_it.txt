REA Atlas è una mappa multilingue e curata di progetti open source di reverse engineering che copre decompilazioni di giochi, ricompilazioni statiche, port, strumenti di estrazione asset e lavori RE più ampi su app, protocolli, firmware e sicurezza. Ogni progetto elencato è contrassegnato in base all’uso del workflow Reverse Engineer Anything (rea); «Yes» è riservato ai casi supportati da documentazione pubblica. Le voci sono raggruppate per console o piattaforma, dai sistemi retro all’hardware moderno e al PC, e mantenute in JSON strutturato con un renderer Python che rigenera le tabelle README localizzate. È pensato per reverse engineer, preservationisti e ricercatori che vogliono un unico indice di sforzi legittimi di decomp e RE, non crack o strumenti di pirateria.
