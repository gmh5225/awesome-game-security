REA Atlas is a curated, multilingual map of open reverse-engineering projects spanning game decompilations, static recompilations, ports, asset-extraction tools, and broader app, protocol, firmware, and security-related RE work. Each listed project is tagged with whether it uses the Reverse Engineer Anything (rea) workflow, with Yes reserved for cases backed by public documentation. Entries are grouped by console or platform from retro systems through modern hardware and PC, and maintained as structured JSON with a Python renderer that regenerates the localized README tables. It is aimed at reverse engineers, preservationists, and researchers who want a single index of legitimate decomp and RE efforts rather than cracks or piracy tooling.
