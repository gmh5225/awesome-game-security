REA Atlas는 게임 디컴파일, 정적 재컴파일, 포팅, 에셋 추출 도구, 그리고 앱·프로토콜·펌웨어·보안 관련 RE 작업 등에 이르는 오픈 리버스 엔지니어링 프로젝트의 다국어 큐레이션 지도입니다. 나열된 각 프로젝트는 Reverse Engineer Anything(rea) 워크플로를 사용하는지 여부로 태그되며, 「Yes」는 공개 문서로 뒷받침된 경우에만 부여됩니다. 항목은 레트로 시스템부터 최신 하드웨어 및 PC에 이르까지 콘솔 또는 플랫폼별로 묶이며, 구조화된 JSON과 Python 렌더러로 현지화된 README 표를 재생성하는 방식으로 유지됩니다. 크랙이나 불법 복제 도구가 아니라 합법적인 디컴파일 및 RE 노력의 단일 색인을 원하는 리버스 엔지니어, 보존주의자, 연구자를 대상으로 합니다.
