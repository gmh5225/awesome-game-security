Teach Me Assembly is a fully offline IDAPython plugin for IDA Pro that adds Chinese semantic comments to each disassembled instruction in the current function. It uses IDA’s decode results and local rule logic only, with no AI, cloud services, or cross-instruction data-flow inference. Built-in coverage spans x86 conditionals, stack and call idioms, and common ARM, MIPS, and RISC-V load, store, arithmetic, and branch mnemonics, with operand-aware explanations of registers, immediates, and memory references. Users can extend or override behavior by editing a companion JSON mnemonic map that is reloaded on each run. It is aimed at reverse engineers and game security analysts who want faster, per-line readability of assembly while dissecting binaries in IDA.
