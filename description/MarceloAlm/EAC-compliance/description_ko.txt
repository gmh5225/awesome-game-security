이 저장소는 Arch Linux를 Easy Anti-Cheat Linux v2 요구 사항에 맞추기 위한 프로덕션 지향 가이드 및 도구 모음입니다. UEFI Secure Boot, TPM 2.0 measured boot, 서명된 커널 및 DKMS 모듈, 무결성 모드의 커널 lockdown, kexec 비활성화, IOMMU 격리, LSM BPF를 다루며, NVIDIA 등 out-of-tree 드라이버를 계속 사용할 수 있도록 Shim과 MOK 이중 키링 방식도 포함합니다. 포함된 check-eac-compliance.sh Bash 스크립트는 sysfs와 procfs를 통해 커널 보안 인터페이스를 직접 감사하여, 상위 수준 배포판 도구에 의존하지 않고 준비 상태를 검증합니다. 동반 하드닝 문서는 CIS 스타일의 Debian VM 잠금과 방어적 서버 자세를 위한 Ansible 보안 청사진을 다룹니다. Epic의 Linux 안티치트 스택이 기대하는 OS 신뢰 체인을 이해하거나 구현해야 하는 Linux 게이머, 관리자, 보안 연구자를 대상으로 합니다.
