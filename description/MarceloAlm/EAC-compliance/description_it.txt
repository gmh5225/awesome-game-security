Questo repository è una guida e una raccolta di strumenti orientati alla produzione per portare Arch Linux in conformità con i requisiti di Easy Anti-Cheat Linux v2. Illustra UEFI Secure Boot, avvio misurato TPM 2.0, kernel e moduli DKMS firmati, lockdown del kernel in modalità integrità, kexec disabilitato, isolamento IOMMU e LSM BPF, incluso un approccio a doppio keyring Shim e MOK affinché driver out-of-tree come NVIDIA restino utilizzabili. Lo script Bash incluso check-eac-compliance.sh controlla direttamente le interfacce di sicurezza del kernel tramite sysfs e procfs per convalidare la prontezza senza affidarsi a strumenti di distro di alto livello. Documenti di hardening complementari coprono il lockdown di VM Debian in stile CIS e un blueprint di sicurezza Ansible per una postura server difensiva. È rivolto a gamer Linux, amministratori e ricercatori di sicurezza che devono comprendere o implementare la catena di fiducia del SO attesa dallo stack anti-cheat Linux di Epic.
