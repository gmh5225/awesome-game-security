本仓库是一份面向生产的指南与工具集，用于使 Arch Linux 符合 Easy Anti-Cheat Linux v2 的要求。内容涵盖 UEFI 安全启动、TPM 2.0 度量启动、已签名内核与 DKMS 模块、完整性模式下的内核 lockdown、禁用 kexec、IOMMU 隔离以及 LSM BPF，并采用 Shim 与 MOK 双密钥环方案，以便 NVIDIA 等树外驱动仍可正常使用。附带的 check-eac-compliance.sh Bash 脚本通过 sysfs 与 procfs 直接审计内核安全接口，在不依赖高层发行版工具的情况下验证就绪状态。配套的加固文档包括 CIS 风格的 Debian 虚拟机锁定，以及用于防御性服务器态势的 Ansible 安全蓝图。面向需要理解或实现 Epic Linux 反作弊栈所期望的 OS 信任链的 Linux 玩家、管理员与安全研究人员。
