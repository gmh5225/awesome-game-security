本儲存庫是一份面向生產環境的指南與工具集，用於使 Arch Linux 符合 Easy Anti-Cheat Linux v2 的要求。內容涵蓋 UEFI 安全啟動、TPM 2.0 度量啟動、已簽章核心與 DKMS 模組、完整性模式下的核心 lockdown、停用 kexec、IOMMU 隔離以及 LSM BPF，並採用 Shim 與 MOK 雙金鑰環方案，以便 NVIDIA 等樹外驅動仍可正常使用。附帶的 check-eac-compliance.sh Bash 腳本透過 sysfs 與 procfs 直接稽核核心安全介面，在不依賴高階發行版工具的情況下驗證就緒狀態。配套的強化文件包括 CIS 風格的 Debian 虛擬機鎖定，以及用於防禦性伺服器態勢的 Ansible 安全藍圖。面向需要理解或實作 Epic Linux 反作弊堆疊所期望的 OS 信任鏈的 Linux 玩家、管理員與安全研究人員。
