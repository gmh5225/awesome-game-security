Este repositorio es una guía y colección de herramientas orientadas a producción para adaptar Arch Linux a los requisitos de Easy Anti-Cheat Linux v2. Recorre UEFI Secure Boot, arranque medido TPM 2.0, kernels y módulos DKMS firmados, lockdown del kernel en modo integridad, kexec deshabilitado, aislamiento IOMMU y LSM BPF, incluido un enfoque de doble llavero Shim y MOK para que controladores fuera del árbol como NVIDIA sigan siendo utilizables. El script Bash incluido check-eac-compliance.sh audita las interfaces de seguridad del kernel directamente vía sysfs y procfs para validar la preparación sin depender de herramientas de distro de alto nivel. Documentos complementarios de endurecimiento cubren el bloqueo de VM Debian al estilo CIS y un plan de seguridad Ansible para una postura defensiva en servidores. Está dirigido a jugadores de Linux, administradores e investigadores de seguridad que necesitan entender o implementar la cadena de confianza del SO que espera la pila anti-trampas de Linux de Epic.
