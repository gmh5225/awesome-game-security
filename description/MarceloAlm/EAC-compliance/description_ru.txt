Этот репозиторий — ориентированное на продакшен руководство и набор инструментов для приведения Arch Linux в соответствие с требованиями Easy Anti-Cheat Linux v2. В нём разобраны UEFI Secure Boot, измеряемая загрузка TPM 2.0, подписанные ядра и модули DKMS, lockdown ядра в режиме целостности, отключённый kexec, изоляция IOMMU и LSM BPF, включая подход с двойным связкой ключей Shim и MOK, чтобы драйверы вне дерева, например NVIDIA, оставались пригодными к использованию. Включённый Bash-скрипт check-eac-compliance.sh проверяет интерфейсы безопасности ядра напрямую через sysfs и procfs, чтобы подтвердить готовность без опоры на высокоуровневые инструменты дистрибутива. Сопутствующие документы по усилению охватывают блокировку ВМ Debian в стиле CIS и схему безопасности Ansible для оборонительной конфигурации сервера. Адресован геймерам на Linux, администраторам и исследователям безопасности, которым нужно понять или внедрить цепочку доверия ОС, которую ожидает античит-стек Epic для Linux.
