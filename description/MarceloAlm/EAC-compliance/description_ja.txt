このリポジトリは、Arch Linux を Easy Anti-Cheat Linux v2 の要件に適合させるための本番向けガイドとツール集です。UEFI Secure Boot、TPM 2.0 による measured boot、署名済みカーネルと DKMS モジュール、整合性モードのカーネル lockdown、kexec の無効化、IOMMU 分離、LSM BPF を解説し、NVIDIA などの out-of-tree ドライバを使い続けられるよう Shim と MOK のデュアルキーリング方式も含みます。同梱の check-eac-compliance.sh Bash スクリプトは、sysfs と procfs からカーネルセキュリティインターフェースを直接監査し、高レベルなディストロツールに頼らず準備状況を検証します。関連するハードニング文書では、CIS スタイルの Debian VM ロックダウンと、防御的サーバー姿勢のための Ansible セキュリティ設計が扱われます。Epic の Linux アンチチートスタックが想定する OS 信頼チェーンを理解または実装する必要がある Linux ゲーマー、管理者、セキュリティ研究者向けです。
