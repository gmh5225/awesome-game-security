This repository is a production-oriented guide and tooling collection for bringing Arch Linux into compliance with Easy Anti-Cheat Linux v2 requirements. It walks through UEFI Secure Boot, TPM 2.0 measured boot, signed kernels and DKMS modules, kernel lockdown in integrity mode, disabled kexec, IOMMU isolation, and LSM BPF, including a Shim and MOK dual-keyring approach so NVIDIA and other out-of-tree drivers remain usable. The included check-eac-compliance.sh Bash script audits kernel security interfaces directly via sysfs and procfs to validate readiness without relying on high-level distro tools. Companion hardening documents cover CIS-style Debian VM lockdown and an Ansible security blueprint for defensive server posture. It targets Linux gamers, administrators, and security researchers who need to understand or implement the OS trust chain that Epic’s Linux anti-cheat stack expects.
