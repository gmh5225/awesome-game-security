BSimVis es una plataforma de análisis de similitud binaria que usa Ghidra y su complemento BSim (Behavioral Similarity) para comparar funciones descompiladas y vectores de características en grandes colecciones de binarios. Almacena el código descompilado y los metadatos en una base de datos personalizada basada en Kvrocks con colas de trabajos Redis y, opcionalmente, Milvus para búsqueda vectorial, exponiendo tanto una API REST como una interfaz web. Las capacidades clave incluyen búsqueda de similitud con filtrado por puntuación, diff de funciones basado en BSim, clustering familiar HDBSCAN con visualización de dendrograma, navegación del grafo de llamadas, etiquetado, notas de analista y resúmenes locales opcionales con LLM. El proyecto está escrito principalmente en Python con un frontend en JavaScript y está orientado a ingenieros inversos y analistas de malware que necesitan análisis escalable de similitud entre binarios más allá de la base de datos BSim integrada de Ghidra.
