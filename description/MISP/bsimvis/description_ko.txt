BSimVis는 Ghidra와 그 BSim(Behavioral Similarity) 플러그인을 사용해 대규모 바이너리 모음에서 디컴파일된 함수와 특징 벡터를 비교하는 바이너리 유사성 분석 플랫폼입니다. 디컴파일된 코드와 메타데이터를 Kvrocks 기반 맞춤 데이터베이스에 저장하고 Redis 작업 큐를 함께 쓰며, 선택적으로 Milvus로 벡터 검색을 지원하고 REST API와 웹 UI를 모두 제공합니다. 주요 기능으로는 점수 필터링이 있는 유사성 검색, BSim 기반 함수 diff, HDBSCAN 패밀리 클러스터링과 덴드로그램 시각화, 호출 그래프 탐색, 태깅, 분석가 메모, 선택적 로컬 LLM 요약이 있습니다. 이 프로젝트는 주로 Python으로 작성되었고 JavaScript 프론트엔드를 갖추며, Ghidra 내장 BSim 데이터베이스를 넘는 확장 가능한 교차 바이너리 유사성 분석이 필요한 리버스 엔지니어와 멀웨어 분석가를 대상으로 합니다.
