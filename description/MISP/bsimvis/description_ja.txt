BSimVis は、Ghidra とその BSim（Behavioral Similarity）プラグインを用いて、大規模なバイナリ集合にわたる逆コンパイル関数と特徴ベクトルを比較するバイナリ類似性分析プラットフォームです。逆コンパイルコードとメタデータを Kvrocks ベースの独自データベースに保存し、Redis ジョブキューを併用、オプションでベクトル検索に Milvus を利用でき、REST API と Web UI の両方を提供します。主な機能には、スコアフィルタ付き類似性検索、BSim ベースの関数差分、HDBSCAN によるファミリクラスタリングとデンドログラム可視化、コールグラフのナビゲーション、タグ付け、アナリストメモ、オプションのローカル LLM 要約があります。プロジェクトは主に Python で書かれ、JavaScript フロントエンドを備え、Ghidra 組み込みの BSim データベースを超えるスケーラブルなクロスバイナリ類似性分析を必要とするリバースエンジニアやマルウェアアナリストを対象としています。
