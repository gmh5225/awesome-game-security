BSimVis è una piattaforma di analisi della similarità binaria che usa Ghidra e il suo plugin BSim (Behavioral Similarity) per confrontare funzioni decompilate e vettori di caratteristiche su grandi raccolte di binari. Memorizza il codice decompilato e i metadati in un database personalizzato basato su Kvrocks con code di lavoro Redis e, opzionalmente, Milvus per la ricerca vettoriale, esponendo sia una REST API sia una web UI. Le capacità principali includono ricerca di similarità con filtro per punteggio, diff di funzioni basato su BSim, clustering familiare HDBSCAN con visualizzazione a dendrogramma, navigazione del call-graph, tagging, note dell'analista e riepiloghi LLM locali opzionali. Il progetto è scritto principalmente in Python con un frontend JavaScript ed è rivolto a reverse engineer e analisti di malware che necessitano di un'analisi di similarità cross-binary scalabile oltre al database BSim integrato di Ghidra.
