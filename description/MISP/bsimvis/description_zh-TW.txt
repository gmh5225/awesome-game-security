BSimVis 是一個二進位相似性分析平台，它利用 Ghidra 及其 BSim（Behavioral Similarity，行為相似性）外掛，在大規模二進位集合中比較反編譯函式與特徵向量。它將反編譯程式碼與中繼資料儲存在基於 Kvrocks 的自訂資料庫中，並搭配 Redis 工作佇列，還可選用 Milvus 進行向量搜尋，同時提供 REST API 與 Web UI。主要能力包括帶分數過濾的相似性搜尋、基於 BSim 的函式差異比對、HDBSCAN 家族叢集及樹狀圖視覺化、呼叫圖導覽、標籤、分析師備註，以及可選的本機 LLM 摘要。此專案主要以 Python 撰寫，並配有 JavaScript 前端，面向需要可擴展跨二進位相似性分析、且超出 Ghidra 內建 BSim 資料庫能力的逆向工程師與惡意軟體分析人員。
