BSimVis est une plateforme d'analyse de similarité binaire qui utilise Ghidra et son plugin BSim (Behavioral Similarity) pour comparer des fonctions décompilées et des vecteurs de caractéristiques sur de vastes collections de binaires. Elle stocke le code décompilé et les métadonnées dans une base de données personnalisée basée sur Kvrocks, avec des files de tâches Redis, et éventuellement Milvus pour la recherche vectorielle, en exposant à la fois une API REST et une interface web. Les capacités clés incluent la recherche de similarité avec filtrage par score, le diff de fonctions basé sur BSim, le clustering familial HDBSCAN avec visualisation en dendrogramme, la navigation dans le graphe d'appels, le tagging, les notes d'analyste et des résumés LLM locaux optionnels. Le projet est principalement écrit en Python avec une interface JavaScript et s'adresse aux ingénieurs en rétro-ingénierie et aux analystes de malware qui ont besoin d'une analyse de similarité inter-binaires évolutive au-delà de la base BSim intégrée de Ghidra.
