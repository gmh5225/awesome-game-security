BSimVis — платформа анализа сходства бинарных файлов, которая использует Ghidra и её плагин BSim (Behavioral Similarity) для сравнения декомпилированных функций и векторов признаков по большим коллекциям бинарников. Она хранит декомпилированный код и метаданные в собственной базе на базе Kvrocks с очередями заданий Redis и опционально Milvus для векторного поиска, предоставляя REST API и веб-интерфейс. Ключевые возможности включают поиск сходства с фильтрацией по оценке, сравнение функций на основе BSim, семейную кластеризацию HDBSCAN с визуализацией дендрограммы, навигацию по графу вызовов, тегирование, заметки аналитика и опциональные локальные сводки LLM. Проект написан преимущественно на Python с фронтендом на JavaScript и рассчитан на реверс-инженеров и аналитиков вредоносного ПО, которым нужен масштабируемый межбинарный анализ сходства за пределами встроенной базы BSim в Ghidra.
