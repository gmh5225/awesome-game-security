BSimVis 是一个二进制相似性分析平台，它利用 Ghidra 及其 BSim（Behavioral Similarity，行为相似性）插件，在大规模二进制集合中比较反编译函数与特征向量。它将反编译代码与元数据存储在基于 Kvrocks 的自定义数据库中，并配合 Redis 任务队列，还可选用 Milvus 进行向量检索，同时提供 REST API 与 Web UI。主要能力包括带分数过滤的相似性搜索、基于 BSim 的函数差异对比、HDBSCAN 家族聚类及树状图可视化、调用图导航、标签、分析师备注，以及可选的本地 LLM 摘要。该项目主要为 Python 编写，配有 JavaScript 前端，面向需要可扩展跨二进制相似性分析、且超出 Ghidra 内置 BSim 数据库能力的逆向工程师与恶意软件分析人员。
