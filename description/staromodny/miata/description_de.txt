Miata ist ein kostenloser, quelloffener externer Radar-Hack für Counter-Strike 2, der Feind- und Teammitgliedspositionen in einem separaten Overlay-Fenster darstellt. Er ist in modernem C++ für Windows mit CMake gebaut und liest den Live-Spielzustand aus dem CS2-Clientprozess über konfigurierbare Speicher-Offsets, die aus einer Offsets-Datei geladen werden, die zu gängigen Dump-Tools passt. Das Rendering nutzt Direct3D 9 zusammen mit der Header-only-Bibliothek Daisy für ein Minimap-Radar, dessen Größe, Position, vertikale Synchronisation und Sichtbarkeit bei Aufnahmen über eine einfache Textkonfiguration gesteuert werden. Der Code bündelt Prozessspeicherzugriff, Entity- und Pawn-Strukturen im Valve-Stil sowie eine dedizierte D3D-Geräteschicht in einer kleinen standalone ausführbaren Datei. Er eignet sich für Game-Security-Forscher, Reverse Engineers und Anti-Cheat-Entwickler, die eine gut lesbare Referenz für externe Speicher-Radar-Techniken in CS2 suchen.
