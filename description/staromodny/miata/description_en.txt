Miata is a free, open-source external radar hack for Counter-Strike 2 that draws enemy and teammate positions on a separate overlay window. It is built in modern C++ for Windows and uses CMake, reading live game state from the CS2 client process via configurable memory offsets loaded from an offsets file aligned with common dump tooling. Rendering uses Direct3D 9 together with the header-only Daisy library to show a minimap-style radar whose size, position, vertical sync, and capture visibility are controlled through a simple text config. The code organizes process memory access, Valve-style entity and pawn structures, and a dedicated D3D device layer in a small standalone executable. It suits game security researchers, reverse engineers, and anti-cheat developers who want a readable reference for external memory radar techniques on CS2.
