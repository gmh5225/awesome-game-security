Miata — бесплатный открытый внешний радар для Counter-Strike 2, который отображает позиции врагов и союзников в отдельном оконном оверлее. Проект написан на современном C++ для Windows с CMake и читает актуальное состояние игры из процесса клиента CS2 через настраиваемые смещения в памяти, загружаемые из файла offsets, согласованного с распространёнными инструментами дампа. Отрисовка выполняется через Direct3D 9 и header-only библиотеку Daisy: радар в стиле миникарты, размер, положение, вертикальная синхронизация и видимость при захвате экрана задаются простым текстовым конфигом. Код объединяет доступ к памяти процесса, структуры сущностей и pawn в стиле Valve и отдельный слой D3D-устройства в небольшом автономном исполняемом файле. Подходит исследователям игровой безопасности, реверс-инженерам и разработчикам античита, которым нужна наглядная справка по техникам внешнего радара через память в CS2.
