Miata는 Counter-Strike 2용 무료 오픈 소스 외부 레이더 핵으로, 별도 오버레이 창에 적과 팀원 위치를 그립니다. Windows용 모던 C++와 CMake로 빌드되며, 일반적인 덤프 도구와 맞춘 offsets 파일에서 불러온 설정 가능한 메모리 오프셋을 통해 CS2 클라이언트 프로세스에서 실시간 게임 상태를 읽습니다. 렌더링은 Direct3D 9와 헤더 전용 Daisy 라이브러리를 사용해 미니맵 스타일 레이더를 표시하며, 크기·위치·수직 동기화·캡처 가시성은 간단한 텍스트 설정으로 제어됩니다. 코드는 프로세스 메모리 접근, Valve 스타일 엔티티 및 pawn 구조, 전용 D3D 디바이스 계층을 작은 독립 실행 파일로 구성합니다. CS2에서 외부 메모리 레이더 기법을 읽기 쉬운 참고 자료로 원하는 게임 보안 연구자, 리버스 엔지니어, 안티치트 개발자에게 적합합니다.
