RootAtlas는 서버리스 연합 인덱스로 Android root 모듈 카탈로그를 집계해 MMRL 및 KernelSU Next용 통합 피드를 제공합니다. Python 도구가 상류 MMRL JSON, KernelSU 매니페스트, 큐레이션된 연합 소스, GitHub 저장소를 탐색·검증한 뒤 결과를 병합·중복 제거·캐시하며, 바이너리를 재호스팅하지 않고 상류 다운로드 링크를 유지합니다. GitHub Actions가 매일 자동으로 발견 메타데이터를 갱신하고, 계약 검증을 실행하며, 다수의 플래시 가능 ZIP에서 module.prop 구조를 검사하고, 생성된 JSON과 실시간 커버리지·출처 보고서를 게시합니다. root된 기기 연구자, 모듈 유지 관리자, 고급 사용자를 위해 Magisk, KernelSU, Zygisk 및 관련 root 도구를 단일 유지 브리지로 탐색할 수 있게 하며, 수십 개의 별도 저장소를 수동으로 연결할 필요를 없앱니다.
