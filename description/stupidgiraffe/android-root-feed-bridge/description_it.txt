RootAtlas è un indice federato serverless che aggrega i cataloghi di moduli root Android in feed unificati per MMRL e KernelSU Next. Strumenti Python scoprono e convalidano JSON MMRL a monte, manifest KernelSU, fonti federate curate e repository GitHub, quindi uniscono, deduplicano e memorizzano in cache i risultati preservando i link di download a monte invece di riospitare i binari. L’automazione quotidiana di GitHub Actions aggiorna i metadati di scoperta, esegue la validazione del contratto, ispeziona molte ZIP flashabili per la struttura module.prop e pubblica JSON generato più report live su copertura e provenienza. È pensato per ricercatori su dispositivi con root, maintainer di moduli e utenti esperti che necessitano di un unico ponte mantenuto per esplorare Magisk, KernelSU, Zygisk e strumenti root correlati senza collegare manualmente decine di repository separati.
