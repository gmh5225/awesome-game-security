RootAtlas 是一种无服务器的联邦索引，将各 Android root 模块目录聚合为面向 MMRL 与 KernelSU Next 的统一 feed。Python 工具链发现并校验上游 MMRL JSON、KernelSU 清单、精选联邦来源与 GitHub 仓库，随后合并、去重并缓存结果，同时保留上游下载链接而不重新托管二进制文件。GitHub Actions 每日自动刷新发现元数据、执行契约校验、检查大量可刷写 ZIP 中的 module.prop 结构，并发布生成的 JSON 以及实时覆盖率与溯源报告。它面向已 root 设备的研究人员、模块维护者与高级用户，作为单一维护入口浏览 Magisk、KernelSU、Zygisk 及相关 root 工具，而无需手动对接数十个独立仓库。
