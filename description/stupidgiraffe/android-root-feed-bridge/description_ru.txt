RootAtlas — это бессерверный федеративный индекс, который объединяет каталоги Android root-модулей в единые ленты для MMRL и KernelSU Next. Инструменты на Python находят и проверяют восходящие MMRL JSON, манифесты KernelSU, курируемые федеративные источники и репозитории GitHub, затем сливают, дедуплицируют и кэшируют результаты, сохраняя восходящие ссылки на загрузку вместо повторного хостинга бинарников. Ежедневная автоматизация GitHub Actions обновляет метаданные обнаружения, выполняет проверку контрактов, инспектирует множество прошиваемых ZIP на структуру module.prop и публикует сгенерированный JSON, а также актуальные отчёты о покрытии и происхождении. Проект ориентирован на исследователей с root-устройствами, сопровождающих модулей и опытных пользователей, которым нужен единый поддерживаемый мост для просмотра Magisk, KernelSU, Zygisk и связанных root-инструментов без ручного подключения десятков отдельных репозиториев.
