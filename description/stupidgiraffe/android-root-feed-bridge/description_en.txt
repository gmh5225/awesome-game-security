RootAtlas is a serverless federated index that aggregates Android root module catalogs into unified feeds for MMRL and KernelSU Next. Python tooling discovers and validates upstream MMRL JSON, KernelSU manifests, curated federation sources, and GitHub repositories, then merges, deduplicates, and caches the results while preserving upstream download links instead of rehosting binaries. Daily GitHub Actions automation refreshes discovery metadata, runs contract validation, inspects many flashable ZIPs for module.prop structure, and publishes generated JSON plus live coverage and provenance reports. It is aimed at rooted-device researchers, module maintainers, and power users who need a single maintained bridge to browse Magisk, KernelSU, Zygisk, and related root tooling without wiring dozens of separate repos by hand.
