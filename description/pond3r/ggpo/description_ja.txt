GGPO は、ピアツーピア型オンラインマルチプレイヤーゲーム向けにロールバックネットコードを実装する C++ ネットワーク SDK です。従来の入力遅延方式に代わり、入力予測と投機的実行を用い、プレイヤー入力を即座に送信し、予測が食い違った場合にロールバックすることで、オフライン時のタイミング感と応答性をオンライン対戦にも引き継ぎます。本ライブラリは UDP ベースの P2P 通信を採用し、決定論的なゲーム状態のシリアル化、セーブ・ロードコールバック、入力同期、タイムシンク処理を備え、P2P・観戦・同期テスト用バックエンドと 2～4 人向けサンプルアプリ Vector War を同梱しています。CMake で Windows 向けにビルド可能（Linux 対応は開発中）で、ggponet.h 経由のコールバック駆動 API により、新規または既存のゲームエンジンへロールバックネットワークを統合できます。主な対象は格闘ゲームなど、低遅延で同期されたネットコードが不可欠な、レイテンシに敏感な対戦型マルチプレイタイトルを開発するゲーム開発者です。
