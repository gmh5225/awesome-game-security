GGPO는 피어 투 피어 온라인 멀티플레이어 게임을 위한 롤백 넷코드를 구현하는 C++ 네트워킹 SDK입니다. 기존의 입력 지연 방식 대신 입력 예측과 투기적 실행을 사용하여 플레이어 입력을 즉시 전송하고, 예측이 어긋날 때 롤백함으로써 오프라인에서의 타이밍과 반응성을 온라인 플레이에도 그대로 이어 줍니다. 이 라이브러리는 UDP 기반 P2P 통신을 사용하며, 결정론적 게임 상태 직렬화, 저장·로드 콜백, 입력 동기화, 시간 동기화 처리를 제공하고, P2P·관전·동기화 테스트 백엔드와 2~4인용 샘플 앱 Vector War를 함께 제공합니다. CMake로 Windows용으로 빌드되며(Linux 플랫폼 지원은 진행 중), ggponet.h를 통한 콜백 기반 API로 신규 또는 기존 게임 엔진에 롤백 네트워킹을 통합할 수 있습니다. 주요 대상은 격투 게임처럼 저지연 동기화 넷코드가 필수적인, 지연에 민감한 경쟁형 멀티플레이어 타이틀을 개발하는 게임 개발자입니다.
