GGPO — это сетевой SDK на C++, реализующий rollback netcode для одноранговых онлайн-мультиплеерных игр. Он заменяет традиционные методы задержки ввода предсказанием ввода и спекулятивным выполнением: ввод игрока отправляется немедленно, а при расхождении прогнозов выполняется откат, благодаря чему тайминг и отзывчивость офлайн-игры сохраняются в онлайне. Библиотека использует P2P-связь на базе UDP с детерминированной сериализацией состояния игры, callback-функциями сохранения и загрузки, синхронизацией ввода и обработкой синхронизации времени, а также поставляется с P2P-, зрительским и тестовым backend'ами синхронизации и демонстрационным приложением Vector War для 2–4 игроков. Собрана с помощью CMake для Windows (поддержка Linux в разработке) и предоставляет callback-ориентированный API через ggponet.h для интеграции rollback-сетевого кода в новые или существующие игровые движки. Основная аудитория — разработчики соревновательных мультиплеерных проектов, чувствительных к задержкам, таких как файтинги, где критически важен синхронизированный netcode с низкой задержкой.
