GGPO is a C++ networking SDK that implements rollback netcode for peer-to-peer online multiplayer games. It replaces traditional input-delay techniques with input prediction and speculative execution, sending player inputs immediately and rolling back when predictions diverge so offline timing and responsiveness carry over to online play. The library uses UDP-based P2P communication with deterministic game state serialization, save and load callbacks, input synchronization, and time-sync handling, and ships with P2P, spectator, and sync-test backends plus the Vector War sample app for 2 to 4 players. Built with CMake for Windows (with Linux platform support underway), it exposes a callback-driven API through ggponet.h for integrating rollback networking into new or existing game engines. The primary audience is game developers building latency-sensitive competitive multiplayer titles such as fighting games, where low-latency synchronized netcode is essential.
