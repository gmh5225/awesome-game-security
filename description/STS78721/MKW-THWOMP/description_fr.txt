MKW-THWOMP est une recompilation statique en cours qui porte Mario Kart World (Nintendo Switch 2, mise à jour 1.8.0) vers Windows natif à l’aide de Vulkan. Le pipeline de recompilation élève le code machine ARM64 du jeu en C, tandis qu’un runtime hôte émule les services Switch 2 et mappe l’API graphique NVN 2 sur Vulkan, avec entrées, audio et système de fichiers via SDL. La compilation et l’empaquetage reposent sur des outils Python et des scripts batch sous Windows avec MSYS2, Clang et un GPU Vulkan 1.3 ; les utilisateurs fournissent leurs propres ressources exefs et romfs extraites légalement. Le projet s’adresse aux ingénieurs reverse, aux acteurs de la préservation et aux chercheurs qui étudient les binaires Switch 2, les API graphiques et la recompilation statique à grande échelle, plutôt qu’à livrer un port commercial complet.
