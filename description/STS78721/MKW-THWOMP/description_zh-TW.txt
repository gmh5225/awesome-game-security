MKW-THWOMP 是一項進行中的靜態重編譯專案，使用 Vulkan 將《瑪利歐賽車 世界》（Nintendo Switch 2，更新 1.8.0）移植至原生 Windows。重編譯管線將遊戲的 ARM64 機器碼提升為 C 程式碼，主機執行階段則在 Vulkan 上映射 NVN 2 圖形 API 並模擬 Switch 2 系統服務，並透過以 SDL 為基礎的輸入、音訊與檔案系統支援完成整合。在 Windows 上藉由 MSYS2、Clang、支援 Vulkan 1.3 的 GPU，以及 Python 工具與批次指令碼驅動建置與封裝；使用者需自行提供合法轉儲的 exefs 與 romfs 資源。本專案鎖定逆向工程師、數位保存工作者，以及研究 Switch 2 二進位、圖形 API 與大規模靜態重編譯技術的研究人員，而非推出完整的商業級移植成品。
