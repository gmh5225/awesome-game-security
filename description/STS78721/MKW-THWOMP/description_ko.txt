MKW-THWOMP은 Vulkan을 사용해 Mario Kart World(Nintendo Switch 2, 업데이트 1.8.0)를 네이티브 Windows로 이식하는 진행 중인 정적 재컴파일 프로젝트입니다. 재컴파일 파이프라인은 게임의 ARM64 기계어를 C로 끌어올리고, 호스트 런타임은 Switch 2 서비스를 에뮬레이트하며 NVN 2 그래픽 API를 Vulkan에 매핑하고 SDL 기반 입력·오디오·파일 시스템을 지원합니다. Windows에서 MSYS2, Clang, Vulkan 1.3 GPU, Python 도구 및 배치 스크립트로 빌드와 패키징을 수행하며, 사용자는 합법적으로 덤프한 exefs 및 romfs 자산을 직접 제공해야 합니다. 완성된 상용 포트를 내놓기보다 Switch 2 바이너리, 그래픽 API, 대규모 정적 재컴파일 기법을 연구하는 리버스 엔지니어, 보존 활동가, 연구자를 대상으로 합니다.
