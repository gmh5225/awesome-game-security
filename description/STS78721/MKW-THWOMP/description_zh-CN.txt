MKW-THWOMP 是一项进行中的静态重编译项目，使用 Vulkan 将《马力欧卡丁车世界》（Nintendo Switch 2，更新 1.8.0）移植到原生 Windows。重编译流水线将游戏的 ARM64 机器码提升为 C 代码，而主机运行时在 Vulkan 上映射 NVN 2 图形 API 并模拟 Switch 2 系统服务，并通过基于 SDL 的输入、音频与文件系统支持完成整合。在 Windows 上借助 MSYS2、Clang、支持 Vulkan 1.3 的 GPU 以及 Python 工具与批处理脚本完成构建与打包；用户需自行提供合法转储的 exefs 与 romfs 资源。项目面向逆向工程师、数字保存工作者以及研究 Switch 2 二进制、图形 API 与大规模静态重编译技术的研究人员，而非交付完整的商业级移植版本。
