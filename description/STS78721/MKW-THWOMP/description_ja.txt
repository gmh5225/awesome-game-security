MKW-THWOMP は、Vulkan を用いて Mario Kart World（Nintendo Switch 2、更新 1.8.0）をネイティブ Windows へ移植する進行中の静的再コンパイルプロジェクトです。再コンパイルパイプラインはゲームの ARM64 機械語を C にリフトし、ホストランタイムが Switch 2 サービスをエミュレートして NVN 2 グラフィックス API を Vulkan にマッピングし、SDL ベースの入力・音声・ファイルシステムを提供します。ビルドとパッケージングは、Windows 上の MSYS2、Clang、Vulkan 1.3 対応 GPU、Python ツールおよびバッチスクリプトで行い、ユーザーは独自に合法にダンプした exefs および romfs アセットを用意します。完成した商用ポートの提供ではなく、Switch 2 バイナリ、グラフィックス API、大規模静的再コンパイル技法を研究するリバースエンジニア、保存活動家、研究者を対象としています。
