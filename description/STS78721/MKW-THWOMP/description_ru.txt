MKW-THWOMP — разрабатываемый проект статической перекомпиляции, переносящий Mario Kart World (Nintendo Switch 2, обновление 1.8.0) на нативный Windows с использованием Vulkan. Конвейер перекомпиляции поднимает машинный код ARM64 игры в C, а хост-рантайм эмулирует сервисы Switch 2 и отображает графический API NVN 2 на Vulkan, с вводом, звуком и файловой системой на базе SDL. Сборка и упаковка выполняются с помощью Python-инструментов и пакетных сценариев в Windows с MSYS2, Clang и GPU с Vulkan 1.3; пользователи предоставляют собственные легально сдампленные ресурсы exefs и romfs. Проект ориентирован на реверс-инженеров, специалистов по сохранению и исследователей, изучающих бинарники Switch 2, графические API и крупномасштабную статическую перекомпиляцию, а не на выпуск полноценного коммерческого порта.
