MKW-THWOMP is a work-in-progress static recompilation that ports Mario Kart World (Nintendo Switch 2, update 1.8.0) to native Windows using Vulkan. The recomp pipeline lifts the game’s ARM64 machine code to C, while a host runtime emulates Switch 2 services and maps the NVN 2 graphics API onto Vulkan, with SDL-based input, audio, and filesystem support. Build and packaging are driven by Python tooling and batch scripts on Windows with MSYS2, Clang, and a Vulkan 1.3 GPU, and users supply their own legally dumped exefs and romfs assets. It is aimed at reverse engineers, preservationists, and researchers studying Switch 2 binaries, graphics APIs, and large-scale static recompilation techniques rather than shipping a complete commercial port.
