이 프로젝트는 Arch Linux 및 Microsoft 서명 boot shim을 제공하지 않는 롤링·DIY 계열 유사 배포판에서 UEFI Secure Boot를 활성화하고 유지하는 방법을 다루는 초보자 친화적 문서 가이드입니다. sbctl로 사용자 정의 키를 생성·등록하고, GRUB·systemd-boot·rEFInd·통합 커널 이미지용 커널과 부트로더에 서명하며, 패키지 업데이트 후에도 서명이 유효하도록 자동 hook을 설정하는 과정을 안내합니다. Riot Vanguard가 포함된 Valorant, FACEIT처럼 Secure Boot가 필요한 경쟁 게임을 OS를 바꿀 때마다 펌웨어 설정을 건드리지 않고 실행하려면 Windows 10 또는 11과의 듀얼 부팅 구성을 강조합니다. UEFI 사전 요건, BitLocker 복구 시 주의사항, 일반적인 부팅 실패 문제 해결, Linux 전용 PC에서 bootkit 및 승인되지 않은 커널 이전 코드에 대한 Secure Boot 방어까지 다룹니다. 내용은 애플리케이션 소스 코드가 아니라 예시 Bash 명령이 포함된 Markdown으로 작성되어 있습니다.
