This project is a beginner-friendly documentation guide for enabling and maintaining UEFI Secure Boot on Arch Linux and similar rolling or DIY distributions that do not ship Microsoft-signed boot shims. It walks through generating and enrolling custom keys with sbctl, signing kernels and bootloaders for GRUB, systemd-boot, rEFInd, and unified kernel images, and keeping signatures valid across package updates via automatic hooks. The guide emphasizes dual-boot setups with Windows 10 or 11 so competitive titles that require Secure Boot, such as Valorant with Riot Vanguard and FACEIT, can run without toggling firmware settings each time you switch OSes. It also covers UEFI prerequisites, BitLocker recovery precautions, troubleshooting common boot failures, and Secure Boot as defense against bootkits and unauthorized pre-kernel code on Linux-only machines. Content is written as Markdown with illustrative Bash commands rather than application source code.
