本项目是一份面向初学者的文档指南，介绍如何在 Arch Linux 及类似、未预装微软签名 boot shim 的滚动发行版或 DIY 发行版上启用并维护 UEFI Secure Boot。内容涵盖使用 sbctl 生成并注册自定义密钥、为 GRUB、systemd-boot、rEFInd 及统一内核镜像签名内核与引导加载程序，以及通过自动 hook 在软件包更新后保持签名有效。指南侧重与 Windows 10 或 11 的双系统配置，以便在需要 Secure Boot 的竞技游戏（如搭载 Riot Vanguard 的 Valorant 与 FACEIT）中运行，而无需每次切换系统时改动固件设置。此外还涉及 UEFI 前置条件、BitLocker 恢复注意事项、常见启动故障排查，以及在纯 Linux 机器上将 Secure Boot 作为抵御 bootkit 与未授权内核前代码的防线。内容以 Markdown 编写，附示例 Bash 命令，而非应用程序源代码。
