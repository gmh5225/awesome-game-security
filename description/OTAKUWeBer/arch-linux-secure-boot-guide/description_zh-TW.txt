本專案是一份面向初學者的文件指南，說明如何在 Arch Linux 及類似、未預裝微軟簽署 boot shim 的滾動發行版或 DIY 發行版上啟用並維護 UEFI Secure Boot。內容涵蓋使用 sbctl 產生並註冊自訂金鑰、為 GRUB、systemd-boot、rEFInd 及統一核心映像簽署核心與開機載入程式，以及透過自動 hook 在套件更新後保持簽章有效。指南著重與 Windows 10 或 11 的雙系統設定，以便在需要 Secure Boot 的競技遊戲（如搭載 Riot Vanguard 的 Valorant 與 FACEIT）中執行，而無需每次切換系統時變更韌體設定。此外也涉及 UEFI 前置條件、BitLocker 復原注意事項、常見開機失敗疑難排解，以及在純 Linux 機器上將 Secure Boot 作為抵禦 bootkit 與未授權核心前程式碼的防線。內容以 Markdown 撰寫，附示範 Bash 指令，而非應用程式原始碼。
