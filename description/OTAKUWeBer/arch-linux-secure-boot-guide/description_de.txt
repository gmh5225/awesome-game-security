Dieses Projekt ist eine einsteigerfreundliche Dokumentationsanleitung zum Aktivieren und Beibehalten von UEFI Secure Boot auf Arch Linux und ähnlichen Rolling- oder DIY-Distributionen, die keine von Microsoft signierten Boot-Shims mitliefern. Es führt durch das Erzeugen und Registrieren eigener Schlüssel mit sbctl, das Signieren von Kerneln und Bootloadern für GRUB, systemd-boot, rEFInd und Unified Kernel Images sowie das Aufrechterhalten gültiger Signaturen über Paketupdates hinweg per automatischer Hooks. Der Leitfaden betont Dual-Boot-Setups mit Windows 10 oder 11, damit wettbewerbsorientierte Titel mit Secure Boot-Pflicht, etwa Valorant mit Riot Vanguard und FACEIT, laufen, ohne bei jedem OS-Wechsel die Firmware-Einstellungen umzuschalten. Außerdem behandelt er UEFI-Voraussetzungen, BitLocker-Wiederherstellungsvorkehrungen, typische Boot-Fehler und Secure Boot als Schutz vor Bootkits und unautorisiertem Code vor dem Kernel auf reinen Linux-Rechnern. Der Inhalt ist als Markdown mit illustrativen Bash-Befehlen verfasst, nicht als Anwendungsquellcode.
