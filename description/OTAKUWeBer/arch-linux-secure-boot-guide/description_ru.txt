Этот проект — документация для начинающих о включении и поддержке UEFI Secure Boot в Arch Linux и похожих rolling- или DIY-дистрибутивах, которые не поставляют boot shim с подписью Microsoft. В ней описаны генерация и регистрация пользовательских ключей через sbctl, подпись ядер и загрузчиков для GRUB, systemd-boot, rEFInd и unified kernel images, а также сохранение действительности подписей после обновления пакетов с помощью автоматических hook. Руководство делает акцент на dual-boot с Windows 10 или 11, чтобы соревновательные игры с требованием Secure Boot, такие как Valorant с Riot Vanguard и FACEIT, работали без переключения настроек прошивки при каждой смене ОС. Также рассмотрены требования UEFI, меры предосторожности при восстановлении BitLocker, устранение типичных сбоев загрузки и Secure Boot как защита от bootkit и несанкционированного кода до ядра на машинах только с Linux. Материал оформлен в Markdown с иллюстративными командами Bash, а не как исходный код приложения.
