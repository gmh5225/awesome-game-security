本プロジェクトは、Arch Linux および Microsoft 署名付き boot shim を同梱しないローリング系・DIY 系の類似ディストリビューションで UEFI Secure Boot を有効化し維持するための、初心者向けドキュメントガイドです。sbctl によるカスタム鍵の生成と登録、GRUB・systemd-boot・rEFInd・統合カーネルイメージ向けのカーネルとブートローダーの署名、パッケージ更新後も署名を有効に保つ自動 hook までを順を追って説明します。Riot Vanguard 付き Valorant や FACEIT など Secure Boot を要求する競技タイトルを、OS 切り替えのたびにファームウェア設定をいじらずに動かすため、Windows 10 または 11 とのデュアルブート構成を重視しています。UEFI の前提条件、BitLocker 復旧時の注意、一般的な起動失敗のトラブルシュート、Linux のみのマシンにおける bootkit やカーネル前の不正コードに対する Secure Boot の防御も扱います。内容はアプリケーションのソースコードではなく、説明用 Bash コマンド付きの Markdown です。
