Este proyecto es una guía documental para principiantes sobre cómo habilitar y mantener UEFI Secure Boot en Arch Linux y distribuciones rolling o DIY similares que no incluyen boot shims firmados por Microsoft. Recorre la generación e inscripción de claves personalizadas con sbctl, la firma de kernels y cargadores de arranque para GRUB, systemd-boot, rEFInd e imágenes de kernel unificadas, y cómo conservar firmas válidas tras actualizaciones de paquetes mediante hooks automáticos. La guía enfatiza configuraciones de arranque dual con Windows 10 u 11 para que títulos competitivos que exigen Secure Boot, como Valorant con Riot Vanguard y FACEIT, funcionen sin cambiar la configuración del firmware cada vez que cambies de SO. También cubre requisitos previos de UEFI, precauciones de recuperación de BitLocker, resolución de fallos de arranque habituales y Secure Boot como defensa frente a bootkits y código no autorizado previo al kernel en equipos solo con Linux. El contenido está escrito en Markdown con comandos Bash de ejemplo, no como código fuente de aplicación.
