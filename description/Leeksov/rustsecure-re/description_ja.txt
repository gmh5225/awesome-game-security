本リポジトリは、ゲーム Rust で使用されるクライアント側アンチチートエージェント RustSecure の静的リバースエンジニアリング分析を文書化したものです。ローダー、暗号化ペイロード配信、ネイティブ CLR ブリッジ、Core DLL アーキテクチャを整理し、反デバッグ、反 VM、直接 NT システムコール、HWID 収集、BepInEx および kdmapper 検出、スクリーンショット取得、WebSocket テレメトリを含む 13 の検出モジュールを網羅しています。プロジェクトには、文字列復号、難読化解除、ペイロード解析のための Python および C# ツール、詳細なバイパス解説、研究時に検出を無効化するためのオプションの静的・ランタイムパッチユーティリティが含まれます。作業はすべて ILSpy、dnfile、IDA Pro などのツールによる静的解析で行われ、元のバイナリは実行しません。アンチチート設計、クライアント側保護機構、執行手法を研究するゲームセキュリティ研究者向けです。
