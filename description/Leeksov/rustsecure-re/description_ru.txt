Этот репозиторий документирует статический реверс-инжиниринг RustSecure — клиентского античит-агента, используемого в игре Rust. В нём описаны загрузчик, доставка зашифрованного payload, нативный CLR-мост и архитектура Core DLL, включая тринадцать модулей обнаружения: анти-отладка, анти-VM, прямые NT-системные вызовы, сбор HWID, обнаружение BepInEx и kdmapper, захват скриншотов и телеметрия WebSocket. Проект включает инструменты на Python и C# для расшифровки строк, деобфускации и анализа payload, подробные описания обходов, а также опциональные утилиты статических и runtime-патчей для отключения обнаружений в ходе исследований. Работа выполняется исключительно статическим анализом с помощью ILSpy, dnfile и IDA Pro без запуска оригинальных бинарников. Предназначен для исследователей безопасности игр, изучающих проектирование античитов, механизмы клиентской защиты и методы принуждения.
