本仓库记录了对 RustSecure 的静态逆向工程分析；RustSecure 是用于游戏 Rust 的客户端反作弊代理。文档梳理了加载器、加密载荷投递、原生 CLR 桥接以及 Core DLL 架构，并涵盖十三个检测模块，包括反调试、反虚拟机、直接 NT 系统调用、HWID 采集、BepInEx 与 kdmapper 检测、截图捕获以及 WebSocket 遥测。项目提供用于字符串解密、去混淆与载荷分析的 Python 和 C# 工具，以及详细的绕过说明，以及可选的静态与运行时补丁工具，便于在研究期间禁用检测。全部工作均通过静态分析完成，使用 ILSpy、dnfile 和 IDA Pro 等工具，而非执行原始二进制文件。面向研究反作弊设计、客户端保护机制与执法手段的游戏安全研究人员。
