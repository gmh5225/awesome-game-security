Este repositorio documenta un análisis estático de ingeniería inversa de RustSecure, un agente anti-cheat del lado del cliente utilizado con el juego Rust. Describe el cargador, la entrega de payload cifrado, el puente CLR nativo y la arquitectura Core DLL, incluidos trece módulos de detección que abarcan anti-debug, anti-VM, llamadas directas al sistema NT, recopilación de HWID, detección de BepInEx y kdmapper, captura de pantalla y telemetría WebSocket. El proyecto incluye herramientas en Python y C# para descifrado de cadenas, desofuscación y análisis de payload, además de guías detalladas de bypass y utilidades opcionales de parche estático y en tiempo de ejecución para desactivar detecciones durante la investigación. El trabajo se realiza íntegramente mediante análisis estático con herramientas como ILSpy, dnfile e IDA Pro, sin ejecutar los binarios originales. Está destinado a investigadores de seguridad en juegos que estudian el diseño anti-cheat, los mecanismos de protección del cliente y las técnicas de aplicación.
