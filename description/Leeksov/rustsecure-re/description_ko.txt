이 저장소는 게임 Rust에서 사용되는 클라이언트 측 안티치트 에이전트 RustSecure에 대한 정적 리버스 엔지니어링 분석을 문서화합니다. 로더, 암호화된 페이로드 전달, 네이티브 CLR 브리지, Core DLL 아키텍처를 정리하며, 안티 디버그, 안티 VM, 직접 NT 시스템 호출, HWID 수집, BepInEx 및 kdmapper 탐지, 스크린샷 캡처, WebSocket 원격 측정을 포함한 13개의 탐지 모듈을 다룹니다. 프로젝트에는 문자열 복호화, 난독화 해제, 페이로드 분석을 위한 Python 및 C# 도구, 상세한 우회 설명, 연구 중 탐지를 비활성화하기 위한 선택적 정적 및 런타임 패치 유틸리티가 포함됩니다. 작업은 ILSpy, dnfile, IDA Pro 등의 도구를 사용한 정적 분석으로만 수행되며 원본 바이너리는 실행하지 않습니다. 안티치트 설계, 클라이언트 측 보호 메커니즘, 집행 기법을 연구하는 게임 보안 연구자를 대상으로 합니다.
