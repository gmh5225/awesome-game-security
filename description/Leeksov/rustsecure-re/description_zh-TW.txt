本儲存庫記錄了對 RustSecure 的靜態逆向工程分析；RustSecure 是用於遊戲 Rust 的用戶端反作弊代理。文件梳理了載入器、加密載荷投遞、原生 CLR 橋接以及 Core DLL 架構，並涵蓋十三個偵測模組，包括反除錯、反虛擬機、直接 NT 系統呼叫、HWID 收集、BepInEx 與 kdmapper 偵測、螢幕截圖擷取以及 WebSocket 遙測。專案提供用於字串解密、去混淆與載荷分析的 Python 和 C# 工具，以及詳細的繞過說明，以及可選的靜態與執行階段修補工具，便於在研究期間停用偵測。全部工作均透過靜態分析完成，使用 ILSpy、dnfile 和 IDA Pro 等工具，而非執行原始二進位檔。面向研究反作弊設計、用戶端保護機制與執法手段的遊戲安全研究人員。
