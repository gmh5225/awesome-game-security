本儲存庫記錄對騰訊 ACE（Anti-Cheat Expert）開發者主控台及其相關 CDN、驗證與 ibox 微服務基礎設施所進行的結構化安全評估。其中收錄已確認與遭阻斷的發現，例如遊戲 SDK 密鑰與管理元資料的 IDOR 暴露、未經驗證的 CDN 承載內容、OAuth 設定不當，以及其他主控台與後端弱點，並附詳細重現步驟與影響分析。配套的 Python 工具可自動執行閘道健康監控、遊戲 ID 列舉、IDOR 掃描與 CDN 通道探索，JSON 資料集與 Markdown 附錄則用於對應服務、通道與攻擊面。此工作面向遊戲安全研究人員、反作弊工程師，以及研究商業反作弊平台與負責任揭露流程的攻擊性安全實務者。
