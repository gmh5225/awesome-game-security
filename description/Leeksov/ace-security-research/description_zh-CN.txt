本仓库记录了对腾讯 ACE（Anti-Cheat Expert）开发者控制台及其相关 CDN、认证与 ibox 微服务基础设施所进行的结构化安全评估。其中收录了已确认与被阻断的发现，例如游戏 SDK 密钥与管理元数据的 IDOR 暴露、未经认证的 CDN 载荷、OAuth 配置不当，以及其他控制台与后端弱点，并附有详细的复现步骤与影响分析。配套的 Python 工具可自动执行网关健康监控、游戏 ID 枚举、IDOR 扫描与 CDN 通道发现，JSON 数据集与 Markdown 附录则用于梳理服务、通道与攻击面。该工作面向游戏安全研究人员、反作弊工程师，以及研究商业反作弊平台与负责任披露流程的攻击性安全从业者。
