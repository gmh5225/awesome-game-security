This repository documents a structured security assessment of Tencent’s ACE (Anti-Cheat Expert) developer console and its related CDN, auth, and ibox microservice infrastructure. It catalogs confirmed and blocked findings such as IDOR exposure of game SDK secret keys and admin metadata, unauthenticated CDN payloads, OAuth misconfigurations, and other console and backend weaknesses, with detailed reproduction steps and impact analysis. Supporting Python utilities automate gateway health monitoring, game ID enumeration, IDOR scanning, and CDN channel discovery, while JSON datasets and markdown appendices map services, channels, and attack surfaces. The work is aimed at game security researchers, anti-cheat engineers, and offensive security practitioners studying commercial anti-cheat platforms and responsible disclosure workflows.
