本リポジトリは、Tencent の ACE（Anti-Cheat Expert）開発者コンソールと、関連する CDN・認証・ibox マイクロサービス基盤に対する体系的なセキュリティ評価を文書化しています。ゲーム SDK のシークレットキーと管理者メタデータの IDOR 露出、未認証の CDN ペイロード、OAuth の誤設定、その他コンソールおよびバックエンドの弱点など、確認済みおよびブロックされた所見を整理し、再現手順と影響分析を詳述しています。補助的な Python ユーティリティはゲートウェイのヘルス監視、ゲーム ID の列挙、IDOR スキャン、CDN チャネル探索を自動化し、JSON データセットと Markdown 付録でサービス・チャネル・攻撃面をマッピングします。本成果は、ゲームセキュリティ研究者、アンチチートエンジニア、商用アンチチートプラットフォームと責任ある開示フローを研究するオフェンシブセキュリティの実務者を対象としています。
