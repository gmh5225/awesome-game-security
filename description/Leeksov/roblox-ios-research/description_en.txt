This project documents reverse-engineering research on anti-tamper, bytecode integrity, and server-side validation in the Roblox iOS client library for 64-bit ARM. The repository is documentation-only, produced through static analysis in IDA Pro using string anchors, import audits, cross-references, and call-graph tracing against a shipping RobloxLib build. It maps Luau bytecode signature verification with GF(2^128) Galois hashing, DataModel patch signing with Blake2b and Blake3, US14116 challenge-response flows, Apple App Attest device checks, FFlags, telemetry disconnect codes, and clarifies that common frameworks such as Reaper are analytics rather than client anti-cheat. It is aimed at security researchers and reverse engineers studying mobile game integrity, patch tampering, and how enforcement is split between the binary and the server rather than traditional on-device anti-cheat scanning.
