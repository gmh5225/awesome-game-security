This is a C++ cheat framework for Call of Duty: Modern Warfare 2 that injects as a DLL and hooks the game's DirectX 12 swap chain to render an in-game overlay. It implements ESP with world-to-screen projection, bone skeleton drawing, and visibility checks, plus an aimbot with configurable FOV, bone targeting, and target priority. The project uses ImGui for its menu, Kiero for graphics API hooking, MinHook for function interception, and includes lazy importing, direct syscalls, XOR string obfuscation, and custom NtUserSendInput assembly to reduce detection surface. Separate offset and SDK modules support both Battle.net and Steam builds of the game. It is aimed at reverse engineers and game security researchers studying client-side cheat techniques and anti-cheat evasion methods.
