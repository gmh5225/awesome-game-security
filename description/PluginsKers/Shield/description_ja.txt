Shield は Paper、Folia、Purpur 向けの Minecraft サーバープラグインで、プレイヤーの移動・戦闘・インタラクションイベントを収集し、アンチチートと行動監視に利用します。Kotlin で記述され、Gradle で Java 21 向けにビルドされ、ProtocolLib によりパケット指向の取得、レート制限、ローカルキューイングを行い、リモート Shield 分析サービスへの HTTPS 配信が失敗した場合はディスク永続化による再試行を行います。プラグインはイベントに署名してバッチ化し、リモート推論と人手によるレビューに送り、設定可能な警告や許可されたキックなどサーバー側の介入を適用しますが、BAN は意図的に行いません。サーバー運営者は Shield ダッシュボードで登録しサーバーキーを設定します。行動分析はサーバー上のオフライン推論ではなく、そのクラウドサービスに依存します。
