Shield — плагин сервера Minecraft для Paper, Folia и Purpur, который собирает события перемещения, боя и взаимодействия игроков для античита и мониторинга поведения. Написан на Kotlin и собирается Gradle под Java 21; использует ProtocolLib для пакетной фиксации, ограничения частоты и локальной очереди с повторными попытками на диске при сбое HTTPS-доставки на удалённый сервис анализа Shield. Плагин подписывает и пакетирует события для удалённого вывода и ручной проверки, затем применяет серверные меры — настраиваемые предупреждения и разрешённые кики, намеренно не используя баны. Операторы регистрируются через панель Shield и настраивают ключ сервера; анализ поведения опирается на это облачное обслуживание, а не на офлайн-вывод на сервере.
