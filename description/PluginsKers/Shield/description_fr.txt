Shield est un plugin serveur Minecraft pour Paper, Folia et Purpur qui collecte les déplacements, combats et interactions des joueurs pour la lutte anti-triche et la surveillance comportementale. Écrit en Kotlin et construit avec Gradle pour Java 21, il s’appuie sur ProtocolLib pour la capture orientée paquets, la limitation de débit et une file locale avec nouvelles tentatives persistées sur disque lorsque la livraison HTTPS vers le service d’analyse Shield distant échoue. Le plugin signe et regroupe les événements pour l’inférence distante et la revue humaine, puis applique des interventions côté serveur telles que des avertissements configurables et des expulsions autorisées, en évitant délibérément les bannissements. Les opérateurs s’inscrivent via le tableau de bord Shield et configurent une clé serveur ; l’analyse comportementale dépend de ce service cloud plutôt que d’une inférence hors ligne sur le serveur.
