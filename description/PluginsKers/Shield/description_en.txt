Shield is a Minecraft server plugin for Paper, Folia, and Purpur that collects player movement, combat, and interaction events for anti-cheat and behavior monitoring. Written in Kotlin and built with Gradle for Java 21, it uses ProtocolLib for packet-oriented capture, rate limiting, and local queuing with disk-backed retry when HTTPS delivery to the remote Shield analysis service fails. The plugin signs and batches events for remote inference and human review, then applies server-side interventions such as configurable warnings and authorized kicks while deliberately avoiding bans. Server operators register through the Shield dashboard and configure a server key; behavior analysis depends on that cloud service rather than offline inference on the server.
