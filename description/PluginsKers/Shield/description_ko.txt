Shield는 Paper, Folia, Purpur용 Minecraft 서버 플러그인으로, 플레이어 이동·전투·상호작용 이벤트를 수집해 안티치트 및 행동 모니터링에 활용합니다. Kotlin으로 작성되었고 Gradle로 Java 21용으로 빌드되며, ProtocolLib로 패킷 중심 캡처, 속도 제한, 로컬 큐잉을 수행하고, 원격 Shield 분석 서비스로 HTTPS 전송이 실패하면 디스크 기반 재시도를 사용합니다. 플러그인은 이벤트에 서명해 배치 처리한 뒤 원격 추론과 사람 검토를 위해 보내고, 구성 가능한 경고와 허가된 킥 등 서버 측 개입을 적용하되 밴은 의도적으로 하지 않습니다. 서버 운영자는 Shield 대시보드에서 등록하고 서버 키를 설정합니다. 행동 분석은 서버에서의 오프라인 추론이 아니라 해당 클라우드 서비스에 의존합니다.
