Shield 是适用于 Paper、Folia 和 Purpur 的 Minecraft 服务端插件，用于采集玩家移动、战斗与交互事件，以支持反作弊与行为监控。项目以 Kotlin 编写，使用 Gradle 面向 Java 21 构建，借助 ProtocolLib 进行面向数据包的采集、速率限制以及本地队列；当向远程 Shield 分析服务通过 HTTPS 投递失败时，会采用磁盘持久化重试。插件对事件进行签名与批量处理，供远程推理与人工审核，并在服务端执行可配置的警告与授权踢出等干预，刻意避免封禁。服主通过 Shield 控制台注册并配置服务器密钥；行为分析依赖该云服务，而非在服务器上进行离线推理。
