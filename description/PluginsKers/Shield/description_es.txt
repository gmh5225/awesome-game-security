Shield es un complemento de servidor de Minecraft para Paper, Folia y Purpur que recopila eventos de movimiento, combate e interacción de jugadores para antitrampas y monitorización de comportamiento. Escrito en Kotlin y compilado con Gradle para Java 21, usa ProtocolLib para captura orientada a paquetes, limitación de velocidad y cola local con reintentos respaldados en disco cuando falla la entrega HTTPS al servicio remoto de análisis Shield. El complemento firma y agrupa eventos para inferencia remota y revisión humana, y aplica intervenciones en el servidor como advertencias configurables y expulsiones autorizadas, evitando deliberadamente los baneos. Los operadores se registran en el panel Shield y configuran una clave de servidor; el análisis de comportamiento depende de ese servicio en la nube y no de inferencia offline en el servidor.
