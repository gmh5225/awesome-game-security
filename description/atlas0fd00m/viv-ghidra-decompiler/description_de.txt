Dieses Projekt ist eine Vivisect-Erweiterung, die Vivisects symbolische Analyse mit dem Ghidra-Decompiler verbindet, indem symbolik-Effekte in Ghidra-p-Code übersetzt und über JSON-RPC/TCP mit einem headless Ghidra-Backend kommuniziert wird. Die Python-Seite extrahiert Symbole, Funktionssignaturen und Analysen aus Vivisect und zeigt dekompilierten C-Pseudocode in einem Qt-Dock-Widget an, während das Java-Ghidra-Plugin angereicherte Symbole anwendet und optional vor der Dekompilierung benutzerdefinierten p-Code einschleust. Im primären Modus werden von Vivisect abgeleitete Symbolnamen, Typen und Signaturen an Ghidra gesendet, um die Dekompilierung zu verbessern; ein experimenteller Fallback injiziert übersetzten p-Code, wenn Vivisects Analyse von Ghidras Sleigh-Lifting abweicht. In Python und Java geschrieben, richtet es sich an Reverse Engineers und Binäranalysten, die Vivisects symbolisches Schließen mit Ghidras hochwertiger Dekompilierungsausgabe für Game Security, Anti-Cheat und allgemeine Malware-Forschungsworkflows kombinieren möchten.
