Этот проект — расширение Vivisect, которое связывает символический анализ Vivisect с декомпилятором Ghidra, переводя эффекты symbolik в p-code Ghidra и взаимодействуя с headless-бэкендом Ghidra по JSON-RPC/TCP. Python-часть извлекает символы, сигнатуры функций и результаты анализа из Vivisect и отображает декомпилированный C-псевдокод в dock-виджете Qt, а Java-плагин Ghidra применяет обогащённые символы и при необходимости внедряет пользовательский p-code перед декомпиляцией. Основной режим отправляет в Ghidra имена символов, типы и сигнатуры, полученные из Vivisect, для улучшения декомпиляции; экспериментальный запасной вариант внедряет переведённый p-code, когда анализ Vivisect расходится с Sleigh-лифтингом Ghidra. Написан на Python и Java и предназначен для reverse engineers и бинарных аналитиков, которые хотят объединить символическое рассуждение Vivisect с высококачественным выводом декомпиляции Ghidra для задач игровой безопасности, античита и общих исследований вредоносного ПО.
