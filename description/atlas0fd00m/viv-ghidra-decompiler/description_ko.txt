이 프로젝트는 Vivisect 확장 기능으로, symbolik 효과를 Ghidra p-code로 변환하고 JSON-RPC/TCP를 통해 헤드리스 Ghidra 백엔드와 통신함으로써 Vivisect의 심볼릭 분석과 Ghidra 디컴파일러를 연결합니다. Python 측은 Vivisect에서 심볼, 함수 시그니처, 분석 결과를 추출하고 Qt 도크 위젯에 디컴파일된 C 의사 코드를 표시합니다. Java Ghidra 플러그인은 보강된 심볼을 적용하며, 디컴파일 전에 선택적으로 사용자 정의 p-code를 주입할 수 있습니다. 주요 모드는 Vivisect에서 도출한 심볼 이름, 타입, 시그니처를 Ghidra로 전송하여 디컴파일 품질을 개선하는 것이며, Vivisect 분석이 Ghidra의 Sleigh 리프팅과 일치하지 않을 때 변환된 p-code를 주입하는 실험적 대체 방식도 제공합니다. Python과 Java로 작성되었으며, Vivisect의 심볼릭 추론과 Ghidra의 고품질 디컴파일 출력을 결합하여 게임 보안, 안티치트, 일반 악성코드 연구 워크플로에 활용하려는 리버스 엔지니어와 바이너리 분석가를 대상으로 합니다.
