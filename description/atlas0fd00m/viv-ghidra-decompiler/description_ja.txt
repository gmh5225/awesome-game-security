本プロジェクトは Vivisect 拡張機能であり、symbolik 効果を Ghidra の p-code に変換し、JSON-RPC/TCP 経由でヘッドレス Ghidra バックエンドと通信することで、Vivisect のシンボリック解析と Ghidra のデコンパイラを橋渡しします。Python 側は Vivisect からシンボル、関数シグネチャ、解析結果を抽出し、Qt ドックウィジェットにデコンパイルされた C 疑似コードを表示します。Java 製 Ghidra プラグインは拡張されたシンボルを適用し、デコンパイル前に任意でカスタム p-code を注入できます。主なモードでは、Vivisect 由来のシンボル名、型、シグネチャを Ghidra に送り、デコンパイル品質を向上させます。Vivisect の解析が Ghidra の Sleigh リフティングと一致しない場合には、変換した p-code を注入する実験的なフォールバックも用意されています。Python と Java で書かれており、Vivisect のシンボリック推論と Ghidra の高品質なデコンパイル出力を組み合わせ、ゲームセキュリティ、アンチチート、一般的なマルウェア研究のワークフローに活用したいリバースエンジニアやバイナリ解析者を対象としています。
