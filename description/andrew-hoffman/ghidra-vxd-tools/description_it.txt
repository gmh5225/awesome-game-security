Script Jython per Ghidra che migliorano il disassemblaggio e l'annotazione dei binari VxD (Virtual Device Driver) di Windows 9x all'interno di Ghidra. Lo script principale analizza le sequenze di chiamate VxD INT 20h, sostituisce i byte grezzi con una struttura VxDCall tipizzata e aggiunge etichette e commenti leggibili decodificando gli ID VxD e di servizio rispetto a un ampio database derivato da VMDisp9x vmm.h. Gestisce anche payload inline speciali, come stringhe di debug e parole di flag per i comuni servizi di debug VMM. Scritti in Jython usando l'API Ghidra, gli script si installano nel gestore script di Ghidra nella categoria Windows9x e sono destinati a ingegneri del reverse engineering e ricercatori della sicurezza che analizzano driver legacy in modalità kernel di Windows 9x, inclusi componenti storici di protezione dei giochi e anti-cheat.
