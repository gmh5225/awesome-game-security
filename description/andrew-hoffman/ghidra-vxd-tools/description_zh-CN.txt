用于改进 Ghidra 内 Windows 9x VxD（虚拟设备驱动程序）二进制文件反汇编与标注的 Ghidra Jython 脚本。主脚本扫描 INT 20h VxD 调用序列，将原始字节替换为带类型的 VxDCall 结构，并通过对照源自 VMDisp9x vmm.h 的大型数据库解码 VxD 与服务 ID，添加可读性强的标签与注释。它还能处理特殊内联载荷，例如常见 VMM 调试服务的调试字符串与标志字。脚本使用 Jython 编写，基于 Ghidra API，安装于 Ghidra 脚本管理器的 Windows9x 分类下，面向分析遗留 Windows 9x 内核模式驱动的逆向工程师与安全研究人员，包括历史上的游戏保护与反作弊组件。
