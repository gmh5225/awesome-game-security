Scripts Jython de Ghidra que mejoran el desensamblado y la anotación de binarios VxD (Virtual Device Driver) de Windows 9x dentro de Ghidra. El script principal busca secuencias de llamadas VxD INT 20h, reemplaza bytes en bruto con una estructura VxDCall tipada y añade etiquetas y comentarios legibles decodificando los ID de VxD y de servicio frente a una gran base de datos derivada de VMDisp9x vmm.h. También gestiona cargas útiles en línea especiales, como cadenas de depuración y palabras de bandera para servicios de depuración VMM habituales. Escritos en Jython con la API de Ghidra, los scripts se instalan en el administrador de scripts de Ghidra bajo la categoría Windows9x y están destinados a ingenieros de ingeniería inversa e investigadores de seguridad que analizan controladores en modo kernel heredados de Windows 9x, incluidos componentes históricos de protección de juegos y anti-cheat.
