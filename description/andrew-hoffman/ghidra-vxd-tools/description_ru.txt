Скрипты Ghidra на Jython, улучшающие дизасsemblирование и аннотирование бинарных файлов VxD (Virtual Device Driver) Windows 9x в Ghidra. Основной скрипт сканирует последовательности вызовов VxD INT 20h, заменяет сырые байты типизированной структурой VxDCall и добавляет понятные метки и комментарии, декодируя идентификаторы VxD и сервисов по обширной базе данных, полученной из VMDisp9x vmm.h. Он также обрабатывает специальные встроенные полезные нагрузки, такие как отладочные строки и слова флагов для распространённых отладочных служб VMM. Написанные на Jython с использованием API Ghidra, скрипты устанавливаются в менеджер скриптов Ghidra в категории Windows9x и предназначены для специалистов по реверс-инжинирингу и исследователей безопасности, анализирующих устаревшие драйверы Windows 9x в режиме ядра, включая исторические компоненты защиты игр и античит-систем.
