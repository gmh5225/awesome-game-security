Ghidra 内の Windows 9x VxD（Virtual Device Driver）バイナリの逆アセンブルと注釈付けを改善する Ghidra Jython スクリプト。メインスクリプトは INT 20h VxD 呼び出しシーケンスをスキャンし、生バイトを型付き VxDCall 構造体に置き換え、VMDisp9x vmm.h 由来の大規模データベースに対して VxD およびサービス ID をデコードすることで、人間が読みやすいラベルとコメントを追加する。また、一般的な VMM デバッグサービス向けのデバッグ文字列やフラグワードなど、特殊なインラインペイロードにも対応する。Ghidra API を用いた Jython で記述され、Ghidra スクリプトマネージャーの Windows9x カテゴリにインストールされ、レガシー Windows 9x カーネルモードドライバ（歴史的なゲーム保護およびアンチチートコンポーネントを含む）を解析するリバースエンジニアおよびセキュリティ研究者向けに設計されている。
