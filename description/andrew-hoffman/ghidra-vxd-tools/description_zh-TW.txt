用於改進 Ghidra 內 Windows 9x VxD（虛擬裝置驅動程式）二進位檔反組譯與標註的 Ghidra Jython 指令碼。主要指令碼掃描 INT 20h VxD 呼叫序列，將原始位元組替換為具類型的 VxDCall 結構，並透過對照源自 VMDisp9x vmm.h 的大型資料庫解碼 VxD 與服務 ID，新增易讀的標籤與註解。它也能處理特殊內嵌承載，例如常見 VMM 偵錯服務的偵錯字串與旗標字。指令碼以 Jython 撰寫，使用 Ghidra API，安裝於 Ghidra 指令碼管理器的 Windows9x 分類下，供分析舊版 Windows 9x 核心模式驅動程式的逆向工程師與安全研究人員使用，包括歷史上的遊戲保護與反作弊元件。
