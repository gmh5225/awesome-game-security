LSPosed Universal Template は、LSPosed および LSPatch フックモジュールを構築するためのクイックスタート Android モジュールの足場であり、許可されたテストおよび迅速なプロトタイピング向けです。最新の libxposed API 102 をターゲットに、Java フック、ランタイム機能レジストリ、移動可能なオーバーレイ mod メニュー、およびパターンスキャンとモジュール検索のための ShadowHook および JNI メモリユーティリティによるオプションのネイティブフックを提供します。主に Java と C++ で Gradle および CMake を使用して構築され、Unity、Unreal、Cocos2d-x、Godot のエンジン検出、一般的なアンチチート衛星プロセスをスキップするプロセスフィルター、IL2CPP およびネイティブゲームワークフロー向けの Frida 偵察スクリプトとドキュメントを含みます。このテンプレートは、フックおよび分析のための構造化された出発点を必要とする Android リバースエンジニアおよびゲームセキュリティ研究者を対象としています。
