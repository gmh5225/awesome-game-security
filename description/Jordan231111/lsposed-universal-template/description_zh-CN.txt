LSPosed Universal Template 是一个快速入门的 Android 模块脚手架，用于构建 LSPosed 和 LSPatch 钩子模块，适用于授权测试和快速原型开发。它面向现代 libxposed API 102，提供 Java 钩子、运行时功能注册表、可移动的 overlay 模组菜单，以及通过 ShadowHook 和 JNI 内存工具实现的可选原生钩子，用于模式扫描和模块查找。项目主要使用 Java 和 C++ 编写，配合 Gradle 和 CMake 构建，包含 Unity、Unreal、Cocos2d-x 和 Godot 引擎检测、跳过常见反作弊卫星进程的进程过滤器，以及用于 IL2CPP 和原生游戏工作流的 Frida 侦察脚本与文档。该模板面向需要结构化起点来钩取和分析其获授权测试的移动游戏与应用 Android 逆向工程师和游戏安全研究人员。
