LSPosed Universal Template — это быстрый стартовый каркас Android-модуля для создания hook-модулей LSPosed и LSPatch для авторизованного тестирования и быстрого прототипирования. Он ориентирован на современный libxposed API 102 с Java-хукингом, реестром функций во время выполнения, перемещаемым overlay mod-меню и опциональными нативными хуками через ShadowHook и JNI-утилиты памяти для сканирования паттернов и поиска модулей. Создан преимущественно на Java и C++ с Gradle и CMake, включает определение движков Unity, Unreal, Cocos2d-x и Godot, фильтры процессов, пропускающие распространённые спутниковые процессы античита, а также разведывательные скрипты Frida и документацию для рабочих процессов IL2CPP и нативных игр. Шаблон предназначен для Android reverse-инженеров и исследователей безопасности игр, которым нужна структурированная отправная точка для хукинга и анализа мобильных игр и приложений, которые они уполномочены тестировать.
