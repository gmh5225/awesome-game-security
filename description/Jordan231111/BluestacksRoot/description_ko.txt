BlueStackRoot는 Android 9, 11, 13에서 BlueStacks 5 및 MSI App Player 인스턴스에 Magisk Delta(Kitsune)로 root 권한을 부여하는 단일 파일 Windows 자동화 도구입니다. 주로 PowerShell 및 배치 스크립트로 구현되며, 네이티브 C setuid 헬퍼를 포함하고 Magisk APK, 부트 패치 유틸리티, 디스크 편집 도구를 하나의 자급형 blueStackRoot.cmd 런처에 내장합니다. 워크플로는 게스트 VHD/VHDX 이미지 패치, BlueStacks bindmount 동작 수정, ADB를 통한 Magisk 설치, 감지 흔적을 최소화하기 위해 BlueStacks 공장 root 토글을 끈 상태에서 콜드 부팅 지속성 검증을 수행합니다. 진단 기능, 실행 취소 및 unroot 경로, 앱 denylist 숨김 가이드, 프로덕션 강화를 위한 대규모 자동화 테스트 스위트도 포함합니다. 이 프로젝트는 모바일 게임 보안 연구, 모딩, 리버스 엔지니어링, Android 에뮬레이터에서의 안티치트 또는 무결성 검사 우회 테스트를 위해 신뢰할 수 있는 root 접근이 필요한 에뮬레이터 사용자를 대상으로 합니다.
