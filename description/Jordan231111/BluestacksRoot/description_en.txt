BlueStackRoot is a single-file Windows automation tool that roots BlueStacks 5 and MSI App Player instances with Magisk Delta (Kitsune) on Android 9, 11, and 13. It is implemented primarily in PowerShell and batch scripts, with a native C setuid helper, and embeds the Magisk APK, boot-patching utilities, and disk-editing tools inside one self-contained blueStackRoot.cmd launcher. The workflow patches guest VHD/VHDX images, modifies BlueStacks bindmount behavior, installs Magisk through ADB, and verifies cold-boot persistence while leaving BlueStacks factory root toggles off to minimize detectable traces. It includes diagnostics, undo and unroot paths, app-denylist hiding guidance, and a large automated test suite for production hardening. The project targets emulator users who need reliable root access for mobile game security research, modding, reverse engineering, and anti-cheat or integrity-check bypass testing on Android emulators.
