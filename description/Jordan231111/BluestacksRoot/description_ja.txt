BlueStackRoot は、Android 9、11、13 上の BlueStacks 5 および MSI App Player インスタンスに Magisk Delta（Kitsune）で root 権限を付与する、単一ファイルの Windows 自動化ツールです。主に PowerShell とバッチスクリプトで実装され、ネイティブ C の setuid ヘルパーを備え、Magisk APK、ブートパッチユーティリティ、ディスク編集ツールを単一の自己完結型 blueStackRoot.cmd ランチャー内に同梱しています。ワークフローはゲスト VHD/VHDX イメージのパッチ適用、BlueStacks の bindmount 動作の変更、ADB による Magisk のインストール、および検出痕跡を最小限に抑えるため BlueStacks の工場出荷 root トグルをオフのままにしながらコールドブートの永続性を検証します。診断機能、元に戻す・unroot 手順、アプリ denylist 非表示ガイド、本番環境向けの大規模自動テストスイートも含まれます。本プロジェクトは、モバイルゲームのセキュリティ研究、modding、リバースエンジニアリング、および Android エミュレーター上でのアンチチートや整合性チェック回避テストのために、信頼性の高い root アクセスを必要とするエミュレーターユーザーを対象としています。
