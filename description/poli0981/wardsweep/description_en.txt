WardSweep is a Windows tool for uninstalling games that ship kernel-mode anti-cheat software and cleaning up the drivers, services, registry entries, and files those titles leave behind. It combines a Rust elevated broker and CLI with a C# WPF user interface, using a signed TOML catalog to detect products such as Vanguard, Easy Anti-Cheat, BattlEye, and ACE. Core workflows include read-only auditing, game removal through official uninstallers, and orphan sweeps for anti-cheat residue after games are gone, with quarantine, rollback manifests, path deny-lists, and a split-privilege IPC design to limit destructive actions. The project is aimed at legitimate system cleanup rather than bypassing or disabling anti-cheat while games remain playable, and it explicitly rejects ban evasion, runtime tampering, and hardware identifier modification.
