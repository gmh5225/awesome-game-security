WardSweep 是一款 Windows 工具，用于卸载附带内核模式反作弊软件的游戏，并清理这些游戏留下的驱动程序、服务、注册表项和文件。它将 Rust 编写的提权 broker 与 CLI 和 C# WPF 用户界面相结合，通过签名的 TOML 目录检测 Vanguard、Easy Anti-Cheat、BattlEye 和 ACE 等产品。核心工作流包括只读审计、通过官方卸载程序移除游戏，以及游戏删除后对反作弊残留进行孤立清理，并具备隔离、回滚清单、路径拒绝列表和分权 IPC 设计以限制破坏性操作。该项目旨在进行合法的系统清理，而非在游戏仍可游玩时绕过或禁用反作弊，并明确拒绝封号规避、运行时篡改和硬件标识符修改。
