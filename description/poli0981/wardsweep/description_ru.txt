WardSweep — это инструмент для Windows, предназначенный для удаления игр с античитом в режиме ядра и очистки драйверов, служб, записей реестра и файлов, которые оставляют эти игры. Он сочетает повышенный broker и CLI на Rust с пользовательским интерфейсом C# WPF, используя подписанный каталог TOML для обнаружения продуктов, таких как Vanguard, Easy Anti-Cheat, BattlEye и ACE. Основные рабочие процессы включают аудит только для чтения, удаление игр через официальные деинсталляторы и очистку остатков античита-сирот после удаления игр, с карантином, манифестами отката, списками запрета путей и архитектурой IPC с разделением привилегий для ограничения разрушительных действий. Проект направлен на законную очистку системы, а не на обход или отключение античита при работающих играх, и явно отвергает обход банов, вмешательство во время выполнения и изменение аппаратных идентификаторов.
