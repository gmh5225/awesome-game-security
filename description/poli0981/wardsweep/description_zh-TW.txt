WardSweep 是一款 Windows 工具，用於解除安裝附帶核心模式反作弊軟體的遊戲，並清理這些遊戲留下的驅動程式、服務、登錄項目和檔案。它結合以 Rust 撰寫的提權 broker 與 CLI，以及 C# WPF 使用者介面，透過簽署的 TOML 目錄偵測 Vanguard、Easy Anti-Cheat、BattlEye 和 ACE 等產品。核心工作流程包括唯讀稽核、透過官方解除安裝程式移除遊戲，以及遊戲刪除後對反作弊殘留進行孤立清理，並具備隔離、回滾清單、路徑拒絕清單和分權 IPC 設計以限制破壞性操作。本專案旨在進行合法的系統清理，而非在遊戲仍可遊玩時繞過或停用反作弊，並明確拒絕封禁規避、執行階段竄改和硬體識別碼修改。
