This repository is independent applied machine learning research on how to design, evaluate, and operate anti-cheat detection in a multiplayer shooter setting, using Counter-Strike 2 as illustrative gameplay context rather than live game or vendor telemetry. It centers on Jupyter notebooks and Python utilities that work with fully synthetic player and match telemetry to explore individual and coordinated cheating, investigation-label bias, concept drift, skill-segment fairness, calibrated risk scoring, and human-review capacity. Core techniques include temporal validation, logistic regression and Isolation Forest baselines, probability calibration and threshold trade-offs, NetworkX-based co-play graphs for coordinated behavior, and simulations of throughput, backlogs, and safe fallbacks when data or models are unavailable. Supporting scripts generate reproducible synthetic datasets, run an offline evaluation baseline with fairness-by-skill metrics, and ship architecture and limitations documentation that separates research signals from enforcement. The audience is game security engineers, anti-cheat researchers, and data scientists studying trustworthy detection pipelines without claiming a production anti-cheat or automatic banning system.
