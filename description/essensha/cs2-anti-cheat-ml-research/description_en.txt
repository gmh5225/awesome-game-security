This is an applied machine learning research project that explores cheat detection for Counter-Strike 2 using synthetic player telemetry rather than live game data. It is implemented primarily in Python with Jupyter notebooks and supporting scripts built on pandas, NumPy, and scikit-learn. The work covers supervised and anomaly baselines, temporal train-test splits, calibration and class-imbalance handling, skill-segment false-positive analysis, graph-based coordinated-cheating scenarios, adversarial concept drift, and illustrative production-throughput modeling. A reproducible pipeline generates labeled synthetic match features, runs logistic regression and isolation forest evaluations, and documents architecture limits and responsible evaluation practices. It is intended for researchers, data scientists, and game-security practitioners studying anti-cheat ML design and evaluation, not as a deployable anti-cheat product.
