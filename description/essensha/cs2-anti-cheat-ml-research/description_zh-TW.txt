這是一項應用機器學習研究專案，藉由合成玩家遙測資料而非即時對局資料，探索《絕對武力 2》中的作弊偵測。實作主要以 Python 為主，搭配 Jupyter 筆記本及基於 pandas、NumPy 和 scikit-learn 的輔助腳本。工作涵蓋監督學習與異常偵測基線、依時間劃分的訓練測試集、校準與類別不平衡處理、依技能分段分析誤報、以圖為基礎的協同作弊情境、對抗性概念漂移，以及生產吞吐量的示意性建模。可重現管線產生帶標籤的合成對局特徵、執行邏輯迴歸與孤立森林評估，並記錄架構局限與負責任的評估實務。面向研究反作弊機器學習設計與評估的研究人員、資料科學家與遊戲安全從業者，而非可作為產品部署的反作弊系統。
