SAC (Super Anti Cheat) ist ein serverseitiges algorithmisches Anti-Cheat-Plugin für Counter-Strike 2, das auf Metamod:Source und CounterStrikeSharp läuft. In C# für .NET 8 geschrieben, enthält es 17 Erkennungsmodule für Aimbot, Silent Aim, Bhop, DLL-Injection, ungültige Eingaben und verwandte Cheat-Verhaltensweisen. Das Plugin bietet Ingame-Spielermeldungen, ein vierstufiges progressives Warn- und Bannsystem, erhöhte Massenprüf-Sensitivität nach mehreren Meldungen, optionale Demo-Aufzeichnung und anonymisierte Ereignisprotokollierung zur Analyse. Es richtet sich an Betreiber von CS2-Dedicated-Servern, die autonome, regelbasierte Cheat-Erkennung ohne externe Dienste oder KI-Integrationen wünschen.
