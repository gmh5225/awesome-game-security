SAC(Super Anti Cheat)는 Metamod:Source 및 CounterStrikeSharp에서 실행되는 Counter-Strike 2용 서버 측 알고리즘형 안티치트 플러그인입니다. C#으로 작성되었으며 .NET 8을 대상으로 하며, aimbot, silent aim, bhop, DLL injection, 잘못된 입력 및 관련 치트 행위를 탐지하는 17개의 탐지 모듈을 포함합니다. 이 플러그인은 게임 내 플레이어 신고, 4단계 점진적 경고 및 밴 시스템, 다수 신고 후 대량 검사 민감도 향상, 선택적 데모 녹화, 분석을 위한 익명화된 이벤트 로깅 기능을 제공합니다. 외부 서비스나 AI 연동 없이 자율적이고 규칙 기반의 치트 탐지를 원하는 CS2 전용 서버 운영자를 대상으로 합니다.
