SAC (Super Anti Cheat) — серверный алгоритмический античит-плагин для Counter-Strike 2, работающий на Metamod:Source и CounterStrikeSharp. Написан на C# для .NET 8 и включает 17 модулей обнаружения, покрывающих aimbot, silent aim, bhop, DLL-инъекцию, недопустимый ввод и связанное читерское поведение. Плагин добавляет внутриигровые жалобы на игроков, четырёхэтапную прогрессивную систему предупреждений и банов, повышенную чувствительность массовых проверок после нескольких жалоб, опциональную запись демо и анонимизированное логирование событий для анализа. Он предназначен для операторов выделенных серверов CS2, которым нужно автономное обнаружение читов на основе правил без внешних сервисов и интеграций с ИИ.
