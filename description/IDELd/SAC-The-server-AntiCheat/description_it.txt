SAC (Super Anti Cheat) è un plugin anti-cheat algoritmico lato server per Counter-Strike 2 che gira su Metamod:Source e CounterStrikeSharp. Scritto in C# per .NET 8, include 17 moduli di rilevamento che coprono aimbot, silent aim, bhop, iniezione di DLL, input non validi e comportamenti cheat correlati. Il plugin aggiunge segnalazioni dei giocatori in-game, un sistema progressivo di avvisi e ban in quattro fasi, maggiore sensibilità nei controlli di massa dopo più segnalazioni, registrazione opzionale delle demo e logging anonimizzato degli eventi per l'analisi. È rivolto agli operatori di server dedicati CS2 che desiderano un rilevamento cheat autonomo e basato su regole, senza servizi esterni o integrazioni con IA.
