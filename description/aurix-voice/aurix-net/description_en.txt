Aurix Net is a self-hostable, game-agnostic multiplayer backend that combines relay, server-authoritative sync, and deterministic lockstep rooms on a single node. It is implemented mainly in Rust with QUIC and WebTransport datagram transport, a Postgres and Redis multi-node control plane, and client SDKs for the web, Unity, C++, and Godot, plus a React operator console. Lockstep play can run with an optional WASM referee that simulates room logic on the server as the source of truth, alongside predict-and-rollback, lag-compensation history, desync detection, and matchmaking with operator-facing quotas, API keys, grants, and audit logging. The bundled deterministic simulation stack uses fixed-point math and WASM so native and browser builds stay hash-aligned for physics, navigation, and bot logic. It targets developers who need production-grade netcode and server-side authority to limit cheating and keep competitive multiplayer state consistent.
