Aurix Net は、単一ノード上でリレー、サーバー権威型同期、決定的 lockstep ルームを組み合わせた、自ホスト可能でゲーム非依存のマルチプレイヤーバックエンドです。主に Rust で実装され、QUIC と WebTransport のデータグラム転送、Postgres と Redis によるマルチノード制御プレーン、Web・Unity・C++・Godot 向けクライアント SDK、および React 製オペレーターコンソールを備えます。Lockstep プレイでは、サーバー上でルームロジックをシミュレートし唯一の真実の源とする任意の WASM リファリーを利用でき、予測とロールバック、ラグ補償履歴、デシンク検出、オペレーター向けクォータ・API キー・グラント・監査ログ付きマッチメイキングと併用できます。同梱の決定的シミュレーションスタックは固定小数点演算と WASM を用い、ネイティブ版とブラウザ版が物理・ナビゲーション・ボットロジックでハッシュ整合を保ちます。本番品質のネットコードとサーバー側権威によってチートを抑え、競技型マルチプレイヤーの状態を一貫させたい開発者を対象としています。
