Aurix Net은 단일 노드에서 릴레이, 서버 권위 동기화, 결정적 lockstep 룸을 결합한 자체 호스팅 가능·게임 무관 멀티플레이어 백엔드입니다. 주로 Rust로 구현되며 QUIC·WebTransport 데이터그램 전송, Postgres와 Redis 다중 노드 제어 평면, 웹·Unity·C++·Godot용 클라이언트 SDK, React 기반 운영자 콘솔을 제공합니다. Lockstep 플레이는 서버에서 룸 로직을 시뮬레이션해 단일 진실 공급원으로 삼는 선택적 WASM 심판과 함께 동작하며, 예측·롤백, 래그 보정 이력, 디싱크 감지, 운영자용 할당량·API 키·권한 부여·감사 로깅이 포함된 매치메이킹을 지원합니다. 번들된 결정적 시뮬레이션 스택은 고정소수점 연산과 WASM을 사용해 네이티브·브라우저 빌드가 물리·내비게이션·봇 로직에서 해시 정합을 유지합니다. 프로덕션급 넷코드와 서버 측 권위로 치팅을 제한하고 경쟁 멀티플레이어 상태를 일관되게 유지하려는 개발자를 대상으로 합니다.
