Aurix Net 是一款可自托管、与具体游戏无关的多人后端，在单节点上同时提供中继、服务器权威同步与确定性 lockstep 房间。主要使用 Rust 实现，采用 QUIC 与 WebTransport 数据报传输，配合 Postgres 与 Redis 多节点控制平面，并提供面向 Web、Unity、C++ 与 Godot 的客户端 SDK，以及基于 React 的运维控制台。Lockstep 对局可选配 WASM 裁判，在服务器上模拟房间逻辑作为唯一真相来源，并支持预测与回滚、延迟补偿历史、不同步检测，以及带运维侧配额、API 密钥、授权与审计日志的匹配。内置确定性模拟栈使用定点数学与 WASM，使原生与浏览器构建在物理、导航与 Bot 逻辑上保持哈希一致。面向需要生产级网络代码与服务器端权威、以遏制作弊并保持竞技多人状态一致的开发者。
