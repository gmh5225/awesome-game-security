Aurix Net 是一款可自架、與特定遊戲無關的多人後端，在單一節點上結合中繼、伺服器權威同步與確定性 lockstep 房間。主要以 Rust 實作，採用 QUIC 與 WebTransport 資料報傳輸，搭配 Postgres 與 Redis 多節點控制平面，並提供適用於 Web、Unity、C++ 與 Godot 的客戶端 SDK，以及以 React 建置的維運主控台。Lockstep 對局可選用 WASM 裁判，在伺服器上模擬房間邏輯作為唯一真相來源，並支援預測與回滾、延遲補償歷史、不同步偵測，以及面向維運的配額、API 金鑰、授權與稽核日誌之配對。內建確定性模擬堆疊使用定點數學與 WASM，使原生與瀏覽器建置在物理、導航與 Bot 邏輯上維持雜湊一致。面向需要生產級網路程式碼與伺服器端權威、以限制作弊並保持競技多人狀態一致的開發者。
