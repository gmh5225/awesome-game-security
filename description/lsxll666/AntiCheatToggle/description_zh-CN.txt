AntiCheatToggle 是一款小型 Windows 实用工具，提供图形界面和命令行界面，用于停止并禁用游戏反作弊内核驱动及相关服务，以便 VirtualBox 启动虚拟机时不会遇到 supR3HardenedWinReSpawn VERR_INVALID_NAME (-104) 错误。该工具使用 C# 编写，作为单个 WinForms 可执行文件，通过 .NET Framework 编译器构建，针对 Perfect World Arena、Tencent ACE 和 Reason CyberSecurity 的驱动与服务，通过停止它们、可选地终止匹配的用户态进程，并将注册表中的 Start 值改为禁用状态来实现。该工具在首次使用时会备份原始的服务启动类型，可通过一键操作或使用 --on 参数恢复，并支持 --off 和 --status 参数以便脚本化使用，且不会修改 VirtualBox 本身。它面向需要在虚拟化环境中临时绕过内核级反作弊干扰的 Windows 用户和安全研究人员，需理解在保护被禁用期间，受影响的游戏和平台可能拒绝运行。
