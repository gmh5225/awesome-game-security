AntiCheatToggle 是一款小型 Windows 實用工具，提供圖形介面與命令列介面，用於停止並停用遊戲反作弊核心驅動及相關服務，使 VirtualBox 啟動虛擬機器時不會觸發 supR3HardenedWinReSpawn VERR_INVALID_NAME (-104) 錯誤。該工具以 C# 撰寫，為單一 WinForms 可執行檔，透過 .NET Framework 編譯器建置，針對 Perfect World Arena、Tencent ACE 與 Reason CyberSecurity 的驅動與服務，透過停止它們、可選地終止相符的使用者模式程序，並將登錄中的 Start 值改為停用狀態來運作。工具在首次使用時會備份原始服務啟動類型，可一鍵或使用 --on 參數還原，並支援 --off 與 --status 供指令碼使用，且不會修改 VirtualBox 本身。它面向需要在虛擬化環境中暫時繞過核心層反作弊干擾的 Windows 使用者與安全研究人員，需了解在保護停用期間，受影響的遊戲與平台可能無法執行。
