AntiCheatToggle는 GUI와 명령줄 인터페이스를 갖춘 소형 Windows 유틸리티로, 게임 안티치트 커널 드라이버와 관련 서비스를 중지하고 비활성화하여 VirtualBox가 가상 머신을 실행할 때 supR3HardenedWinReSpawn VERR_INVALID_NAME (-104) 오류가 발생하지 않도록 합니다. C#으로 작성되었으며 .NET Framework 컴파일러로 빌드된 단일 WinForms 실행 파일로, Perfect World Arena, Tencent ACE, Reason CyberSecurity의 드라이버와 서비스를 대상으로 중지하고, 선택적으로 일치하는 사용자 모드 프로세스를 종료하며, 레지스트리 Start 값을 비활성으로 변경합니다. 이 도구는 최초 사용 시 원래 서비스 시작 유형을 백업하며, 원클릭 또는 --on으로 복원할 수 있고 VirtualBox 자체는 수정하지 않은 채 --off 및 --status를 통해 스크립트 사용을 지원합니다. 가상화 환경에서 커널 수준 안티치트 간섭을 일시적으로 우회해야 하는 Windows 사용자와 보안 연구자를 대상으로 하며, 보호가 비활성화된 동안 영향을 받는 게임과 플랫폼이 실행을 거부할 수 있음을 이해하고 사용해야 합니다.
