AntiCheatToggle — небольшая утилита для Windows с графическим интерфейсом и командной строкой, которая останавливает и отключает античит-драйверы ядра игр и связанные службы, чтобы VirtualBox мог запускать виртуальные машины без ошибок supR3HardenedWinReSpawn VERR_INVALID_NAME (-104). Написана на C# как единый исполняемый файл WinForms, собранный компилятором .NET Framework; воздействует на драйверы и службы Perfect World Arena, Tencent ACE и Reason CyberSecurity, останавливая их, при необходимости завершая соответствующие пользовательские процессы и изменяя значения Start в реестре на «отключено». При первом использовании инструмент сохраняет исходные типы запуска служб и может восстановить их одним щелчком или через --on, а также поддерживает --off и --status для сценариев без изменения самого VirtualBox. Предназначена для пользователей Windows и исследователей безопасности, которым нужно временно обойти вмешательство античита на уровне ядра при виртуализации, с пониманием того, что затронутые игры и платформы могут отказаться запускаться, пока защита отключена.
