AntiCheatToggle is a small Windows utility with a GUI and command-line interface that stops and disables game anti-cheat kernel drivers and related services so VirtualBox can launch virtual machines without hitting supR3HardenedWinReSpawn VERR_INVALID_NAME (-104) errors. Written in C# as a single WinForms executable built with the .NET Framework compiler, it targets drivers and services from Perfect World Arena, Tencent ACE, and Reason CyberSecurity by stopping them, optionally killing matching user-mode processes, and changing their registry Start values to disabled. The tool backs up original service start types on first use and can restore them with one click or via --on, and it supports --off and --status for scripting without modifying VirtualBox itself. It is aimed at Windows users and security researchers who need to temporarily bypass kernel-level anti-cheat interference with virtualization, with the understanding that affected games and platforms may refuse to run while protection is disabled.
