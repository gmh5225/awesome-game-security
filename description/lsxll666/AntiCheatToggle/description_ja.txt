AntiCheatToggle は、GUI とコマンドラインの両方を備えた小型の Windows ユーティリティで、ゲームのアンチチート用カーネルドライバーと関連サービスを停止・無効化し、VirtualBox が仮想マシンを起動する際に supR3HardenedWinReSpawn VERR_INVALID_NAME (-104) エラーが発生しないようにします。C# で記述され、.NET Framework コンパイラーでビルドされた単一の WinForms 実行ファイルとして、Perfect World Arena、Tencent ACE、Reason CyberSecurity のドライバーとサービスを対象に、停止、一致するユーザーモードプロセスの任意終了、レジストリの Start 値を無効に変更する操作を行います。初回使用時に元のサービス起動タイプをバックアップし、ワンクリックまたは --on で復元でき、VirtualBox 自体を変更することなく --off および --status によるスクリプト操作にも対応します。仮想化におけるカーネルレベルのアンチチート干渉を一時的に回避する必要がある Windows ユーザーとセキュリティ研究者向けのツールであり、保護が無効な間は対象のゲームやプラットフォームが起動を拒否する場合がある点を理解した上での利用が前提です。
