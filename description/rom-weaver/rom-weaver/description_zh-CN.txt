Rom-weaver 是一款面向 ROM 镜像与光盘格式的本地优先工具包，可在单一工作流中完成检查、提取、压缩以及应用或创建补丁。它基于共享的 Rust 核心构建，提供原生 CLI 以及由 React 离线 PWA 驱动的多线程 WASM 版本，文件始终保留在用户本机。它支持 21 种补丁格式，包括 IPS、BPS、UPS、xdelta/VCDIFF、PPF 和 Dreamcast DCP，并可处理 ZIP、7z、CHD、RVZ 等多种归档与光盘镜像容器。校验和验证与头部修复、有序多补丁链、金手指代码烘焙、裁剪/还原以及可共享的工作流包进一步完善了功能集。它面向需要端到端补丁、校验与重新打包流程且无需云端上传的复古游戏模组作者、ROM 黑客与数字保存工作者。
