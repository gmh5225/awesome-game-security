Rom-weaver は、ROM イメージとディスク形式向けのローカルファーストなツールキットで、単一のワークフローで検査、抽出、圧縮、パッチの適用や作成を行えます。共有 Rust コアを基盤とし、ネイティブ CLI と React オフライン PWA が駆動するマルチスレッド WASM ビルドを提供するため、ファイルはユーザーのマシン上に留まります。IPS、BPS、UPS、xdelta/VCDIFF、PPF、Dreamcast DCP など 21 種類のパッチ形式に加え、ZIP、7z、CHD、RVZ など多数のアーカイブおよびディスクイメージコンテナにも対応します。チェックサム検証とヘッダー修復、順序付きマルチパッチチェーン、チートコードの焼き込み、トリム/復元、共有可能なワークフローバンドルが機能セットを完成させます。クラウドへのアップロードなしで、パッチ適用から検証、再パックまでを一貫して行いたいレトロゲームの MOD 制作者、ROM ハッカー、保存活動家向けのツールです。
