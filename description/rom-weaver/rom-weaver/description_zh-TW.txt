Rom-weaver 是一款面向 ROM 映像與光碟格式的本地優先工具包，可在單一工作流程中完成檢查、提取、壓縮以及套用或建立修補檔。它基於共用的 Rust 核心建構，提供原生 CLI 以及由 React 離線 PWA 驅動的多執行緒 WASM 版本，檔案始終保留在使用者本機。它支援 21 種修補格式，包括 IPS、BPS、UPS、xdelta/VCDIFF、PPF 和 Dreamcast DCP，並可處理 ZIP、7z、CHD、RVZ 等多種封存與光碟映像容器。校驗和驗證與標頭修復、有序多修補鏈、金手指代碼烘焙、裁剪/還原以及可共享的工作流程包進一步完善了功能集。它面向需要端到端修補、驗證與重新封裝流程且無需雲端上傳的復古遊戲模組作者、ROM 駭客與數位保存工作者。
