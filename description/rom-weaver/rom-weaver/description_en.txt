Rom-weaver is a local-first toolkit for ROM images and disc formats that inspects, extracts, compresses, and applies or creates patches in a single workflow. It is built around a shared Rust core delivered as a native CLI and as a threaded WASM build driven by a React offline PWA, so files stay on the user's machine. It supports 21 patch formats including IPS, BPS, UPS, xdelta/VCDIFF, PPF, and Dreamcast DCP, plus container handling for ZIP, 7z, CHD, RVZ, and many other archive and disc image types. Checksum verification with header repair, ordered multi-patch chains, cheat-code baking, trim/restore, and shareable workflow bundles round out the feature set. It is aimed at retro game modders, ROM hackers, and preservationists who need end-to-end patch, verify, and repack pipelines without cloud uploads.
