UltimateAntiGamingChair (UAGC) 是一款面向 PaperMC Minecraft 伺服器的上下文感知反作弊平台，以 Java 外掛形式實作。它提供模組化檢測引擎，涵蓋移動、戰鬥、互動及協定違規（如 reach 作弊、速度修改、快速破壞和 timer 濫用），並採用置信度模型，綜合考量合法遊戲機制與伺服器上下文以降低誤報。內建管理員工具包括豁免、基於權限的繞過、證據歷史、警報、自動與手動處罰、持久玩家凍結，以及供可信外掛上報授權行為的整合 API。該專案面向 PaperMC 1.21 至 1.21.11（Java 21），使用 Gradle 建置，面向需要伺服端檢測與執行以應對客戶端作弊的多人伺服器營運者。
