UltimateAntiGamingChair (UAGC) is a context-aware anti-cheat platform implemented as a Java plugin for PaperMC Minecraft servers. It provides a modular check engine covering movement, combat, interaction, and protocol violations such as reach hacks, speed modifications, fast break, and timer abuse, using a confidence model that weighs legitimate game mechanics and server context to reduce false positives. Built-in staff tooling includes exemptions, permission-based bypass, evidence history, alerts, automatic and manual punishments, persistent player freeze, and an integration API for trusted plugins to report authorized behavior. The project targets PaperMC 1.21 through 1.21.11 on Java 21 and is built with Gradle. It is intended for multiplayer server operators who need server-side detection and enforcement against client-side cheating.
