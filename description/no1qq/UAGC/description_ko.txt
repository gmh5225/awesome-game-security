UltimateAntiGamingChair(UAGC)는 PaperMC Minecraft 서버용 Java 플러그인으로 구현된 컨텍스트 인식 안티치트 플랫폼입니다. 이동, 전투, 상호작용 및 프로토콜 위반(리치 핵, 속도 수정, 빠른 파괴, 타이머 남용 등)을 다루는 모듈형 검사 엔진을 제공하며, 정당한 게임 메커니즘과 서버 컨텍스트를 가중하는 신뢰도 모델을 사용해 오탐을 줄입니다. 내장된 스태프 도구에는 면제, 권한 기반 우회, 증거 기록, 알림, 자동 및 수동 처벌, 지속적인 플레이어 동결, 신뢰할 수 있는 플러그인이 허가된 행동을 보고하는 통합 API가 포함됩니다. 이 프로젝트는 Java 21에서 PaperMC 1.21부터 1.21.11을 대상으로 하며 Gradle로 빌드됩니다. 클라이언트 측 치트에 대한 서버 측 탐지 및 집행이 필요한 멀티플레이 서버 운영자를 위한 것입니다.
