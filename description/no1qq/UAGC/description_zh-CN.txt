UltimateAntiGamingChair (UAGC) 是一款面向 PaperMC Minecraft 服务器的上下文感知反作弊平台，以 Java 插件形式实现。它提供模块化检测引擎，涵盖移动、战斗、交互及协议违规（如 reach 作弊、速度修改、快速破坏和 timer 滥用），并采用置信度模型，综合考量合法游戏机制与服务器上下文以降低误报。内置管理员工具包括豁免、基于权限的绕过、证据历史、警报、自动与手动处罚、持久玩家冻结，以及供可信插件上报授权行为的集成 API。该项目面向 PaperMC 1.21 至 1.21.11（Java 21），使用 Gradle 构建，面向需要服务端检测与执行以应对客户端作弊的多人服务器运营者。
