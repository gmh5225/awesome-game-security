UltimateAntiGamingChair (UAGC) è una piattaforma anti-cheat sensibile al contesto, implementata come plugin Java per server Minecraft PaperMC. Fornisce un motore di controllo modulare che copre movimento, combattimento, interazione e violazioni di protocollo come hack di reach, modifiche alla velocità, rottura rapida e abuso del timer, utilizzando un modello di confidenza che pondera le meccaniche di gioco legittime e il contesto del server per ridurre i falsi positivi. Gli strumenti integrati per lo staff includono esenzioni, bypass basato sui permessi, cronologia delle prove, avvisi, punizioni automatiche e manuali, congelamento persistente dei giocatori e un'API di integrazione per consentire a plugin fidati di segnalare comportamenti autorizzati. Il progetto è destinato a PaperMC 1.21 fino a 1.21.11 su Java 21 ed è costruito con Gradle. È pensato per gli operatori di server multigiocatore che necessitano di rilevamento ed enforcement lato server contro i cheat lato client.
