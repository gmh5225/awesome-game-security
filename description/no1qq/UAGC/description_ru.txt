UltimateAntiGamingChair (UAGC) — это платформа античита с учётом контекста, реализованная как Java-плагин для серверов Minecraft на PaperMC. Она предоставляет модульный движок проверок, охватывающий нарушения движения, боя, взаимодействия и протокола, такие как reach-хаки, модификация скорости, быстрое разрушение блоков и злоупотребление таймером, используя модель уверенности, которая учитывает легитимную игровую механику и контекст сервера для снижения ложных срабатываний. Встроенные инструменты для персонала включают исключения, обход на основе прав, историю доказательств, оповещения, автоматические и ручные наказания, постоянную заморозку игроков и API интеграции для доверенных плагинов, сообщающих об авторизованном поведении. Проект ориентирован на PaperMC 1.21–1.21.11 под Java 21 и собирается с помощью Gradle. Предназначен для операторов многопользовательских серверов, которым нужно серверное обнаружение и принудительное применение мер против клиентских читов.
