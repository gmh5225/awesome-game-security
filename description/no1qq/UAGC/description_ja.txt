UltimateAntiGamingChair（UAGC）は、PaperMC Minecraft サーバー向けの Java プラグインとして実装された、コンテキストを考慮したアンチチートプラットフォームです。移動、戦闘、インタラクション、プロトコル違反（リーチハック、速度改変、高速破壊、タイマー悪用など）をカバーするモジュール式チェックエンジンを提供し、正当なゲームメカニクスとサーバーコンテキストを考慮した信頼度モデルにより誤検知を低減します。組み込みのスタッフツールには、免除、権限ベースのバイパス、証拠履歴、アラート、自動・手動の処罰、永続的なプレイヤーフリーズ、信頼されたプラグインが許可された動作を報告するための統合 API が含まれます。本プロジェクトは Java 21 上の PaperMC 1.21 から 1.21.11 を対象とし、Gradle でビルドされます。クライアント側のチートに対してサーバー側での検出と執行が必要なマルチプレイサーバー運営者向けです。
