UltimateAntiGamingChair (UAGC) es una plataforma anti-trampas consciente del contexto, implementada como complemento Java para servidores Minecraft PaperMC. Proporciona un motor de comprobación modular que cubre movimiento, combate, interacción y violaciones de protocolo como hacks de alcance, modificaciones de velocidad, rotura rápida y abuso de timer, utilizando un modelo de confianza que pondera las mecánicas legítimas del juego y el contexto del servidor para reducir falsos positivos. Las herramientas integradas para el staff incluyen exenciones, bypass basado en permisos, historial de evidencias, alertas, castigos automáticos y manuales, congelación persistente de jugadores y una API de integración para que complementos de confianza informen de comportamientos autorizados. El proyecto está orientado a PaperMC 1.21 hasta 1.21.11 en Java 21 y se construye con Gradle. Está pensado para operadores de servidores multijugador que necesitan detección y aplicación del lado del servidor contra trampas del lado del cliente.
