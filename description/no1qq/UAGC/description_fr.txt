UltimateAntiGamingChair (UAGC) est une plateforme anti-triche sensible au contexte, implémentée sous forme de plugin Java pour les serveurs Minecraft PaperMC. Elle fournit un moteur de vérification modulaire couvrant les violations de mouvement, de combat, d'interaction et de protocole telles que les hacks de portée, les modifications de vitesse, la casse rapide et l'abus de timer, en utilisant un modèle de confiance qui pondère les mécaniques de jeu légitimes et le contexte serveur pour réduire les faux positifs. Les outils intégrés pour le staff incluent les exemptions, le contournement basé sur les permissions, l'historique des preuves, les alertes, les sanctions automatiques et manuelles, le gel persistant des joueurs, ainsi qu'une API d'intégration permettant aux plugins de confiance de signaler des comportements autorisés. Le projet cible PaperMC 1.21 à 1.21.11 sur Java 21 et est construit avec Gradle. Il s'adresse aux opérateurs de serveurs multijoueurs qui ont besoin d'une détection et d'une application côté serveur contre la triche côté client.
