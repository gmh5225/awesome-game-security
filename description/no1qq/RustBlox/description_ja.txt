RustBlox は、Rust で完全に書かれた Roblox 向けの最新 Windows デスクトップクライアント兼ランチャーです。公式 CDN から Roblox の隔離コピーをダウンロードしてインストールし、FastFlags とゲーム内設定を管理します。egui と eframe で構築されたグラフィカルダッシュボードにより、起動設定、MOD、ショートカットを提供します。目立つセキュリティ機能は TheWatcher で、Roblox 実行中にバックグラウンドで動作するアンチチートウォッチドッグであり、外部チートツール、DLL インジェクション、スクリプトエグゼキューターを監視します。本プロジェクトは Discord Rich Presence、自動バックアップ付きのカスタムフォントとテクスチャ、roblox: および roblox-player: URI のディープリンク処理にも対応しています。デフォルトクライアントだけに頼らず、組み込みセッション保護機能を備えた自己完結型ランチャーを求める Roblox プレイヤーとセキュリティ意識の高いユーザー向けです。
