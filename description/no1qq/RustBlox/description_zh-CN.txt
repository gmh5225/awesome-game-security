RustBlox 是一款完全用 Rust 编写的现代 Windows 桌面 Roblox 客户端与启动器。它从官方 CDN 下载并安装 Roblox 的隔离副本，管理 FastFlags 与游戏内设置，并提供基于 egui 和 eframe 构建的图形化仪表板，用于启动配置、模组和快捷方式。其突出的安全功能是 TheWatcher——一款在 Roblox 运行时于后台工作的反作弊看门狗，可监控外部作弊工具、DLL 注入和脚本执行器。该项目还支持 Discord Rich Presence、带自动备份的自定义字体与纹理，以及对 roblox: 和 roblox-player: URI 的深度链接处理。它面向希望拥有自带会话保护的一体化启动器、而非仅依赖默认客户端的 Roblox 玩家与注重安全的用户。
