RustBlox is a modern Windows desktop client and launcher for Roblox, written entirely in Rust. It downloads and installs an isolated copy of Roblox from the official CDN, manages FastFlags and in-game settings, and provides a graphical dashboard built with egui and eframe for launch configuration, mods, and shortcuts. Its standout security feature is TheWatcher, a background anti-cheat watchdog that runs while Roblox is active and monitors for external cheat tools, DLL injection, and script executors. The project also supports Discord Rich Presence, custom fonts and textures with automatic backups, and deep-link handling for roblox: and roblox-player: URIs. It is aimed at Roblox players and security-minded users who want a self-contained launcher with built-in session protection rather than relying on the default client alone.
