ArgusAC는 Minecraft 서버용 모듈형 안티치트 플러그인으로, 구성 가능한 이동·전투·블록 상호작용·패킷 검사를 통해 치팅을 탐지합니다. Java 17로 작성되었고 Maven으로 빌드하며, Bukkit·Spigot·Paper에서 Minecraft 1.12.2부터 1.21.x까지 실행되며, 서버 버전별로 검사를 맞추는 호환 계층과 패킷 분석용 선택적 ProtocolLib를 제공합니다. 주요 기능으로 ElytraFly 탐지 모음, 마지막으로 확인된 정당한 위치로의 HARD 및 SOFT setback, 위반 추적과 스태프 알림·처벌, JSON Lines 로그·SHA-256 해시 체인 검증·로그 조회·이동 재생을 포함한 감사 도구가 있습니다. 연구 전용 도구가 아니라 실용적인 게임 내 안티치트 집행과 조사 가능한 위반 기록이 필요한 서버 운영자를 대상으로 합니다.
