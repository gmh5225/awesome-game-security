ArgusAC is a modular anti-cheat plugin for Minecraft servers that detects cheating through configurable movement, combat, block interaction, and packet checks. It is written in Java 17, built with Maven, and runs on Bukkit, Spigot, and Paper from Minecraft 1.12.2 through 1.21.x, with a compatibility layer that adapts checks to each server version and optional ProtocolLib for packet analysis. Notable capabilities include an ElytraFly detection suite, HARD and SOFT setbacks to last known legitimate positions, violation tracking with staff alerts and punishments, and audit tooling with JSON Lines logs, SHA-256 hash-chain verification, log queries, and movement replay. It is aimed at server operators who need practical in-game anti-cheat enforcement and investigatable violation history rather than research-only tooling.
