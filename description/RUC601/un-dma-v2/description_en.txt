Unleashed DMA V2 is a C++ Overwatch 2 companion that reads game state through external DMA hardware instead of running inside the game process. It is built with CMake on Windows, integrates LeechCore and VMM for memory access, and ships example configs for FPGA, FT601, FT2232H, kernel drivers, and other common DMA back ends. The V2 codebase adds a launcher workflow, ImGui-based UI, fixed high-rate capture, and modular features such as entity visuals, hitbox overlays, aim smoothing, and skill alerts backed by Overwatch-specific game logic. The project is aimed at researchers and defenders studying DMA-assisted cheating, remote memory acquisition, and how anti-cheat systems must reason about out-of-process read paths and companion tooling.
