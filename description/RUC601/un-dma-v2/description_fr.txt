Unleashed DMA V2 est un compagnon C++ pour Overwatch 2 qui lit l'état du jeu via un matériel DMA externe plutôt qu'en s'exécutant dans le processus du jeu. Il est construit avec CMake sous Windows, intègre LeechCore et VMM pour l'accès mémoire, et fournit des configurations d'exemple pour FPGA, FT601, FT2232H, pilotes noyau et autres backends DMA courants. La base de code V2 ajoute un flux de lancement, une interface ImGui, une capture à haut débit stable et des fonctionnalités modulaires telles que la visualisation des entités, les superpositions de hitbox, le lissage de visée et les alertes de compétences, appuyées sur une logique de jeu propre à Overwatch. Le projet s'adresse aux chercheurs et défenseurs qui étudient la triche assistée par DMA, l'acquisition mémoire à distance et la façon dont les anti-triches doivent raisonner sur les lectures hors processus et les outils compagnons.
