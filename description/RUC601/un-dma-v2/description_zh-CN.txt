Unleashed DMA V2 是一款 C++ 编写的《守望先锋 2》外挂式伴生工具，通过外部 DMA 硬件读取游戏状态，而非注入游戏进程。项目在 Windows 上使用 CMake 构建，集成 LeechCore 与 VMM 实现内存访问，并提供面向 FPGA、FT601、FT2232H、内核驱动及其他常见 DMA 后端的示例配置。V2 代码库新增启动器工作流、基于 ImGui 的界面、稳定高帧率采集，以及模块化功能，包括实体透视、命中框叠加、瞄准平滑与技能提醒，并依托守望先锋专属游戏逻辑。本项目面向研究与防护人员，用于分析 DMA 辅助作弊、远程内存获取，以及反作弊系统如何研判进程外读取路径与伴生工具。
