Unleashed DMA V2 — C++-компаньон для Overwatch 2, который читает состояние игры через внешнее DMA-оборудование, а не внутри игрового процесса. Собирается CMake под Windows, использует LeechCore и VMM для доступа к памяти и поставляется с примерами конфигураций для FPGA, FT601, FT2232H, драйверов ядра и других распространённых DMA-бэкендов. В кодовой базе V2 добавлены рабочий процесс с лаунчером, интерфейс на ImGui, стабильный высокочастотный захват и модульные возможности: визуализация сущностей, оверлеи хитбоксов, сглаживание прицеливания и оповещения о навыках на основе игровой логики Overwatch. Проект предназначен для исследователей и защитников, изучающих читинг с DMA, удалённое получение памяти и то, как античит должен учитывать чтение вне процесса и сопутствующие инструменты.
