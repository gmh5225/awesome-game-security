Unleashed DMA V2 は、ゲームプロセス内ではなく外部 DMA ハードウェア経由でゲーム状態を読み取る C++ 製の Overwatch 2 コンパニオンツールです。Windows 上で CMake を用いてビルドし、メモリアクセスに LeechCore と VMM を統合しています。FPGA、FT601、FT2232H、カーネルドライバーなど一般的な DMA バックエンド向けの設定例も同梱されています。V2 コードベースではランチャーワークフロー、ImGui ベースの UI、安定した高レートキャプチャ、エンティティ表示、ヒットボックスオーバーレイ、エイムスムージング、スキルアラートなどのモジュール機能が追加され、Overwatch 固有のゲームロジックに支えられています。DMA 支援型チート、リモートメモリ取得、プロセス外読み取り経路やコンパニオンツールについてアンチチートがどう判断すべきかを研究する調査者と防御側を対象としています。
