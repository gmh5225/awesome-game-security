Unleashed DMA V2 是一款以 C++ 撰寫的《鬥陣特攻 2》伴生工具，透過外部 DMA 硬體讀取遊戲狀態，而非在遊戲程序內執行。專案在 Windows 上以 CMake 建置，整合 LeechCore 與 VMM 進行記憶體存取，並提供適用於 FPGA、FT601、FT2232H、核心驅動程式及其他常見 DMA 後端的範例設定。V2 程式碼庫新增啟動器工作流程、基於 ImGui 的使用者介面、穩定高頻率擷取，以及模組化功能，包含實體視覺化、命中框疊加、瞄準平滑與技能提醒，並以鬥陣特攻專屬遊戲邏輯為後盾。本專案供研究與防禦人員分析 DMA 輔助作弊、遠端記憶體取得，以及反作弊系統如何推理程序外讀取路徑與伴生工具。
