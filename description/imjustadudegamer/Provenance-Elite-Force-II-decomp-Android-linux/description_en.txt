This project is a decompiled, rebuildable source tree for the Star Trek: Elite Force II shooter, organized to build and run on Android and on Linux. Most of the work is in C and C++, with CMake driving the native game and engine code and Gradle wrapping an Android application around JNI and game assets. It wires in common game stack pieces such as SDL, OpenAL, zlib, and image/font libraries, and provides GLES3 and Vulkan-oriented renderer configuration alongside classic Quake-family modules for client, server, cgame, and bot AI. Build and packaging helpers include scripts for Android APKs, Linux AppImage layout, and PK3-style asset packaging, plus provenance and third-party license documentation. It is aimed at reverse engineers, porting developers, and preservation efforts that need inspectable code and repeatable builds rather than shipping anti-cheat or multiplayer security tools.
