本プロジェクトは『Star Trek: Elite Force II』シューティングゲーム向けに反コンパイルされ再ビルド可能なソースツリーで、Android と Linux でのビルドと実行ができるよう整理されています。主な実装は C および C++ で、CMake がネイティブのゲームおよびエンジンコードを駆動し、Gradle が JNI とゲームアセットをまとめて Android アプリケーションを包みます。SDL、OpenAL、zlib、画像・フォント系ライブラリなど一般的なゲームスタックを組み込み、GLES3 と Vulkan 志向のレンダラー設定に加え、クライアント、サーバー、cgame、ボット AI 向けの古典的な Quake 系モジュールを提供します。ビルドとパッケージングの補助として、Android APK、Linux の AppImage レイアウト、PK3 形式のアセットパッケージング用スクリプトに加え、provenance と第三者ライセンスのドキュメントが含まれます。アンチチートやマルチプレイ向けセキュリティツールを配布するのではなく、検査可能なコードと再現可能なビルドを必要とするリバースエンジニア、移植開発者、アーカイブ・保存の取り組みを対象としています。
