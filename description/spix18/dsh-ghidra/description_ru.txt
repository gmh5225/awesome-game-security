dsh-ghidra — это плагин DeepSeek Harness (DSH), который подключает ИИ-агентов к Ghidra для интерактивного бинарного реверс-инжиниринга. Написан преимущественно на JavaScript и Python, предоставляет более 200 инструментов DSH для импорта и анализа исполняемых файлов, декомпиляции функций, просмотра строк, сегментов, импортов, экспортов, перекрёстных ссылок и графов вызовов, а также для сохранения правок вроде переименований, комментариев, прототипов и меток функций. Добавляет возможности комплексного анализа и триажа малвари, включая обнаружение криптоконстант, поведенческие эвристики API, извлечение IOC и сканирование антианализных паттернов, с опциональной интеграцией с REST-интерфейсом GhidraMCP для расширенных инструментов. Плагин работает кроссплатформенно на Windows, Linux и macOS через PyGhidra, включает диагностику окружения и навык агента, подсказывающий, когда уместно использовать Ghidra, и предназначен для реверс-инженеров, аналитиков малвари и исследователей безопасности игр, которым нужны LLM-управляемые рабочие процессы над нативными бинарниками.
