dsh-ghidra es un complemento de DeepSeek Harness (DSH) que conecta agentes de IA con Ghidra para ingeniería inversa binaria interactiva. Escrito principalmente en JavaScript y Python, expone más de 200 herramientas DSH para importar y analizar ejecutables, descompilar funciones, explorar cadenas, segmentos, importaciones, exportaciones, referencias cruzadas y grafos de llamadas, y para persistir ediciones como renombrados, comentarios, prototipos y etiquetas de funciones. Añade capacidades de análisis compuesto y triaje de malware, incluyendo detección de constantes criptográficas, heurísticas de API conductuales, extracción de IOC y escaneo de patrones anti-análisis, con integración opcional a la superficie REST de GhidraMCP para herramientas extendidas. El complemento funciona multiplataforma en Windows, Linux y macOS mediante PyGhidra, incluye diagnósticos de entorno y una habilidad de agente que orienta cuándo Ghidra es apropiado, y está dirigido a ingenieros de ingeniería inversa, analistas de malware e investigadores de seguridad de juegos que desean flujos de trabajo impulsados por LLM sobre binarios nativos.
