dsh-ghidra 是一款 DeepSeek Harness（DSH）外掛，將 AI 代理連接至 Ghidra，用於互動式二進位逆向工程。專案主要以 JavaScript 和 Python 撰寫，提供超過 200 個 DSH 工具，支援匯入與分析可執行檔、反編譯函式、瀏覽字串、區段、匯入表、匯出表、交叉參考與呼叫圖，以及持久化重新命名、註解、原型與函式標籤等編輯操作。它還提供複合分析與惡意軟體分類能力，包括加密常數偵測、行為 API 啟發式分析、IOC 提取與反分析模式掃描，並可選擇整合 GhidraMCP REST 介面以擴展工具鏈。此外掛透過 PyGhidra 跨平台運行於 Windows、Linux 和 macOS，內建環境診斷功能及指導何時使用 Ghidra 的代理技能，面向希望在原生二進位檔上實現 LLM 驅動工作流程的逆向工程師、惡意軟體分析師與遊戲安全研究人員。
