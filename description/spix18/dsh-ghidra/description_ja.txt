dsh-ghidra は、AI エージェントを Ghidra に接続し、インタラクティブなバイナリリバースエンジニアリングを可能にする DeepSeek Harness（DSH）プラグインです。主に JavaScript と Python で書かれており、200 以上の DSH ツールを提供し、実行ファイルのインポートと解析、関数のデコンパイル、文字列・セグメント・インポート・エクスポート・クロスリファレンス・コールグラフの参照、およびリネーム、コメント、プロトタイプ、関数ラベルなどの編集の永続化に対応します。暗号定数検出、行動 API ヒューリスティクス、IOC 抽出、反解析パターンのスキャンなど、複合解析とマルウェアトリアージ機能も備え、拡張ツール用に GhidraMCP REST インターフェースとのオプション統合も可能です。PyGhidra 経由で Windows、Linux、macOS 上でクロスプラットフォームに動作し、環境診断と Ghidra の適切な使用タイミングを案内するエージェントスキルを含み、ネイティブバイナリに対する LLM 駆動ワークフローを求めるリバースエンジニア、マルウェアアナリスト、ゲームセキュリティ研究者向けです。
