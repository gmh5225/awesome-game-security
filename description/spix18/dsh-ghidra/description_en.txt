dsh-ghidra is a DeepSeek Harness (DSH) plugin that connects AI agents to Ghidra for interactive binary reverse engineering. Written primarily in JavaScript and Python, it exposes over 200 DSH tools for importing and analyzing executables, decompiling functions, browsing strings, segments, imports, exports, cross-references, and call graphs, and for persisting edits such as renames, comments, prototypes, and function labels. It adds composite analysis and malware triage capabilities including crypto-constant detection, behavioral API heuristics, IOC extraction, and anti-analysis pattern scanning, with optional integration to the GhidraMCP REST surface for extended tooling. The plugin runs cross-platform on Windows, Linux, and macOS via PyGhidra, includes environment diagnostics and an agent skill that guides when Ghidra is appropriate, and is aimed at reverse engineers, malware analysts, and game security researchers who want LLM-driven workflows over native binaries.
