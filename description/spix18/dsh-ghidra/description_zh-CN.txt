dsh-ghidra 是一款 DeepSeek Harness（DSH）插件，将 AI 智能体接入 Ghidra，用于交互式二进制逆向工程。项目主要使用 JavaScript 和 Python 编写，提供 200 多个 DSH 工具，支持导入与分析可执行文件、反编译函数、浏览字符串、段、导入表、导出表、交叉引用和调用图，以及持久化重命名、注释、原型和函数标签等编辑操作。它还提供复合分析与恶意软件分类能力，包括加密常量检测、行为 API 启发式分析、IOC 提取和反分析模式扫描，并可选集成 GhidraMCP REST 接口以扩展工具链。该插件通过 PyGhidra 跨平台运行于 Windows、Linux 和 macOS，内置环境诊断功能及指导何时使用 Ghidra 的智能体技能，面向希望在原生二进制文件上实现 LLM 驱动工作流的逆向工程师、恶意软件分析师和游戏安全研究人员。
