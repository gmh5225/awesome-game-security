dsh-ghidra ist ein DeepSeek Harness (DSH)-Plugin, das KI-Agenten mit Ghidra für interaktives binäres Reverse Engineering verbindet. Hauptsächlich in JavaScript und Python geschrieben, stellt es über 200 DSH-Tools bereit zum Importieren und Analysieren von Executables, Dekompilieren von Funktionen, Durchsuchen von Strings, Segmenten, Imports, Exports, Querverweisen und Aufrufgraphen sowie zum Persistieren von Bearbeitungen wie Umbenennungen, Kommentaren, Prototypen und Funktionslabels. Es ergänzt zusammengesetzte Analyse- und Malware-Triage-Funktionen, darunter Krypto-Konstantenerkennung, verhaltensbasierte API-Heuristiken, IOC-Extraktion und Anti-Analyse-Musterscanning, mit optionaler Integration in die GhidraMCP-REST-Oberfläche für erweiterte Werkzeuge. Das Plugin läuft plattformübergreifend unter Windows, Linux und macOS via PyGhidra, enthält Umgebungsdiagnostik und eine Agent-Fähigkeit, die bei der Entscheidung hilft, wann Ghidra geeignet ist, und richtet sich an Reverse Engineers, Malware-Analysten und Game-Security-Forscher, die LLM-gesteuerte Workflows für native Binaries wünschen.
