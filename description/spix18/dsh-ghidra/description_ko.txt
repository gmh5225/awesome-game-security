dsh-ghidra는 AI 에이전트를 Ghidra에 연결하여 대화형 바이너리 리버스 엔지니어링을 가능하게 하는 DeepSeek Harness(DSH) 플러그인입니다. 주로 JavaScript와 Python으로 작성되었으며, 200개 이상의 DSH 도구를 제공하여 실행 파일 가져오기 및 분석, 함수 디컴파일, 문자열·세그먼트·임포트·익스포트·교차 참조·호출 그래프 탐색, 이름 변경·주석·프로토타입·함수 레이블 등 편집 내용의 영구 저장을 지원합니다. 암호화 상수 탐지, 행동 API 휴리스틱, IOC 추출, 안티분석 패턴 스캔 등 복합 분석 및 멀웨어 분류 기능을 추가하며, 확장 도구를 위해 GhidraMCP REST 인터페이스와의 선택적 통합도 제공합니다. PyGhidra를 통해 Windows, Linux, macOS에서 크로스 플랫폼으로 실행되며, 환경 진단 및 Ghidra 사용 시점을 안내하는 에이전트 스킬을 포함하여, 네이티브 바이너리에 LLM 기반 워크플로를 적용하려는 리버스 엔지니어, 멀웨어 분석가, 게임 보안 연구자를 대상으로 합니다.
