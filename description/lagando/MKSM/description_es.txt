MKSM es un proyecto de investigación e ingeniería que recompila estáticamente Mortal Kombat: Shaolin Monks (PlayStation 2, SLUS_210.87) a código nativo de host mediante la cadena de herramientas PS2Recomp, de modo que el título pueda ejecutarse en PC modernas sin el bucle habitual de un emulador. El trabajo está implementado principalmente en C++, con scripts shell de compilación, sombreadores opcionales de GPU (cómputo y vértices) para el Graphics Synthesizer y una capa de parches que aplica cambios de tiempo de ejeción personalizados sobre un clon local de PS2Recomp. Emula o acelera subsistemas de PS2 como EE, IOP, DMA, VIF, microcódigo VU0/VU1 (con JIT x86-64), renderizado GIF/GS, audio mediante módulos IOP reales y ganchos de emulación de alto nivel específicos del juego para CDVD, matemáticas de libc y el arranque. El repositorio incluye notas de arquitectura extensas, pruebas de regresión, ajuste de rendimiento y automatización para extraer archivos del juego desde una ISO de propiedad del usuario, lo que lo hace útil para ingenieros inversos y preservacionistas que estudian cómo un complejo juego de acción de PS2 se mapea a un entorno de ejecución recompilado orientado al determinismo.
