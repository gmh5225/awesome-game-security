MKSM è un progetto di ricerca e ingegneria che ricompila staticamente Mortal Kombat: Shaolin Monks (PlayStation 2, SLUS_210.87) in codice nativo host tramite la toolchain PS2Recomp, così che il titolo possa girare su PC moderni senza il consueto ciclo di un emulatore. L’implementazione è soprattutto in C++, con script shell di build, shader GPU opzionali (compute e vertici) per il Graphics Synthesizer e uno strato di patch che applica modifiche personalizzate a runtime sopra un clone locale di PS2Recomp. Emula o accelera i sottosistemi PS2, tra cui EE, IOP, DMA, VIF, microcodice VU0/VU1 (con JIT x86-64), rendering GIF/GS, audio tramite moduli IOP reali e hook di emulazione ad alto livello specifici del gioco per CDVD, matematica libc e avvio. Il repository raccoglie ampie note di architettura, test di regressione, ottimizzazione delle prestazioni e automazione per estrarre i file di gioco da un ISO di proprietà dell’utente, risultando utile per reverse engineer e operatori di conservazione che studiano come un complesso gioco d’azione PS2 si mappa su un runtime ricompilato orientato al determinismo.
