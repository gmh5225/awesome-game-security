MKSM 是一項研究與工程專案，藉由 PS2Recomp 工具鏈將《真人快打：少林武僧》（PlayStation 2，SLUS_210.87）靜態重編譯為原生主機程式碼，使該作品能在現代 PC 上執行而無需傳統模擬器主迴圈。實作主要以 C++ 為主，並搭配 shell 建置腳本、針對 Graphics Synthesizer 的可選 GPU 運算與頂點著色器，以及在本地 PS2Recomp 克隆之上套用自訂執行階段變更的修補層。它模擬或加速 PS2 子系統，包括 EE、IOP、DMA、VIF、VU0/VU1 微碼（含 x86-64 JIT）、GIF/GS 繪圖、透過真實 IOP 模組的音訊，以及針對 CDVD、libc 數學與開機流程的遊戲專屬高階模擬鉤子。儲存庫彙整大量架構說明、迴歸測試、效能調校，以及從使用者自有 ISO 擷取遊戲檔案的自動化流程，對研究複雜 PS2 動作遊戲如何對應到以確定性為導向的重編譯執行階段的逆向工程師與保存工作者具有參考價值。
