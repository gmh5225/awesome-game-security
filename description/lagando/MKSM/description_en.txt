MKSM is a research and engineering project that statically recompiles Mortal Kombat: Shaolin Monks (PlayStation 2, SLUS_210.87) into native host code using the PS2Recomp toolchain so the title can run on modern PCs without a conventional emulator loop. The work is implemented mainly in C++, with shell build scripts, optional GPU compute and vertex shaders for the Graphics Synthesizer, and a patch layer that applies custom runtime changes on top of a local PS2Recomp clone. It emulates or accelerates PS2 subsystems including the EE, IOP, DMA, VIF, VU0/VU1 microcode (with x86-64 JIT), GIF/GS rendering, audio via real IOP modules, and game-specific high-level emulation hooks for CDVD, libc math, and boot flow. The repository bundles extensive architecture notes, regression tests, performance tuning, and automation for extracting game files from a user-owned ISO, making it useful for reverse engineers and preservationists studying how a complex PS2 action game maps onto a determinism-oriented recompiled runtime.
