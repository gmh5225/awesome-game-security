MKSM est un projet de recherche et d’ingénierie qui recompile statiquement Mortal Kombat: Shaolin Monks (PlayStation 2, SLUS_210.87) en code natif hôte via la chaîne d’outils PS2Recomp, afin que le titre puisse tourner sur PC modernes sans boucle d’émulateur classique. Le travail est surtout en C++, avec des scripts shell de compilation, des shaders GPU optionnels (calcul et sommets) pour le Graphics Synthesizer, et une couche de correctifs qui applique des modifications d’exécution personnalisées au-dessus d’un clone local de PS2Recomp. Il émule ou accélère les sous-systèmes PS2, dont l’EE, l’IOP, le DMA, le VIF, le microcode VU0/VU1 (avec JIT x86-64), le rendu GIF/GS, l’audio via de vrais modules IOP, et des hooks d’émulation de haut niveau spécifiques au jeu pour le CDVD, les maths libc et le démarrage. Le dépôt regroupe d’importantes notes d’architecture, des tests de régression, du réglage des performances et de l’automatisation pour extraire les fichiers du jeu depuis une ISO appartenant à l’utilisateur, ce qui en fait une ressource utile pour les ingénieurs inverse et les acteurs de la préservation qui étudient comment un jeu d’action PS2 complexe se transpose sur un runtime recompilé orienté déterminisme.
