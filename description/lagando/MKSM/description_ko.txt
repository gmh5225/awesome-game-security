MKSM은 PS2Recomp 툴체인으로 Mortal Kombat: Shaolin Monks(PlayStation 2, SLUS_210.87)를 정적으로 재컴파일해 네이티브 호스트 코드로 옮기는 연구·엔지니어링 프로젝트로, 기존 에뮬레이터 메인 루프 없이 현대 PC에서 실행할 수 있게 한다. 구현은 주로 C++이며, 셸 빌드 스크립트, Graphics Synthesizer용 선택적 GPU 컴퓨트·버텍스 셰이더, 로컬 PS2Recomp 클론 위에 사용자 정의 런타임 변경을 적용하는 패치 계층으로 이루어진다. EE, IOP, DMA, VIF, VU0/VU1 마이크로코드(x86-64 JIT 포함), GIF/GS 렌더링, 실제 IOP 모듈을 통한 오디오, CDVD·libc 수학·부트 플로우용 게임별 HLE 훅 등 PS2 하위 시스템을 에뮬레이트하거나 가속한다. 저장소에는 광범위한 아키텍처 노트, 회귀 테스트, 성능 튜닝, 사용자 소유 ISO에서 게임 파일을 추출하는 자동화가 포함되어, 복잡한 PS2 액션 게임이 결정론 지향 재컴파일 런타임에 어떻게 매핑되는지 연구하는 리버스 엔지니어와 보존 연구자에게 유용하다.
