Apple Silicon Port Factory は、ユーザー提供の Windows x86-64 PE 実行ファイルと DLL を読み込み、Wine・CrossOver・D3DMetal にランタイムで依存せず、Apple Silicon 上の macOS および iOS でネイティブに実行する実験的研究フレームワーク兼ランタイムである。主に Rust で実装され、iced-x86 ベースの x86-64 インタプリタ、ブロック JIT、ディスク永続 AOT キャッシュとクリーンルーム Win32 層を組み合わせ、Direct3D 11/12 と Vulkan グラフィックスは Metal 4 と MetalFX 経由でルーティングし、DXIL から Metal へのシェーダーツールも備える。ファクトリ CLI と ops データベースは、PE スキャン、Win32 インポートと命令カバレッジ監査、ランタイムハザードチェック、アンチチート互換性レポート、オフライン AOT プレウォーム、ポート作業向け差分 x86 検証をサポートする。本 monorepo は、正当に所有した Windows ゲームを Apple Silicon に持ち込む分析・監査・実験を行いたい開発者と研究者向けで、任意のゲーム別マニフェストや Overwatch、Alan Wake 2 などの深度ターゲットに対応する。
