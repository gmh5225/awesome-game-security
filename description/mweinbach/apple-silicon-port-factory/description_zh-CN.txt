Apple Silicon Port Factory 是一套实验性研究框架与运行时，可在 Apple Silicon 版 macOS 与 iOS 上原生加载并运行用户提供的 Windows x86-64 PE 可执行文件与 DLL，运行期不依赖 Wine、CrossOver 或 D3DMetal。项目主要用 Rust 实现，结合基于 iced-x86 的 x86-64 解释器、块级 JIT 与磁盘持久化 AOT 缓存，以及洁净室 Win32 层；Direct3D 11/12 与 Vulkan 图形经 Metal 4 与 MetalFX 路由，并配备 DXIL 转 Metal 着色器工具。工厂 CLI 与运维数据库支持 PE 扫描、Win32 导入与指令覆盖审计、运行时风险检查、反作弊兼容性报告、离线 AOT 预热，以及面向移植工作流的差分 x86 校验。该 monorepo 面向希望分析、审计并实验将合法拥有的 Windows 游戏带到 Apple Silicon 的开发者和研究人员，支持可选的逐游戏清单及 Overwatch、Alan Wake 2 等深度目标。
