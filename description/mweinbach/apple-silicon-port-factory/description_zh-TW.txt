Apple Silicon Port Factory 是一套實驗性研究框架與執行階段環境，可在 Apple Silicon 版 macOS 與 iOS 上原生載入並執行使用者提供的 Windows x86-64 PE 可執行檔與 DLL，執行時不依賴 Wine、CrossOver 或 D3DMetal。專案主要以 Rust 實作，結合基於 iced-x86 的 x86-64 直譯器、區塊 JIT 與磁碟持久化 AOT 快取，以及潔淨室 Win32 層；Direct3D 11/12 與 Vulkan 圖形經由 Metal 4 與 MetalFX 路由，並具備 DXIL 轉 Metal 著色器工具。工廠 CLI 與維運資料庫支援 PE 掃描、Win32 匯入與指令涵蓋稽核、執行階段風險檢查、反作弊相容性報告、離線 AOT 預熱，以及面向移植工作流程的差分 x86 驗證。此 monorepo 鎖定希望分析、稽核並實驗將合法擁有的 Windows 遊戲帶到 Apple Silicon 的開發者與研究人員，支援可選的逐遊戲清單及 Overwatch、Alan Wake 2 等深度目標。
