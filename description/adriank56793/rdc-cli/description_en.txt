rdc-cli is a scriptable command-line interface that exposes RenderDoc GPU capture files as text streams and a virtual filesystem so frame data can be inspected from the terminal. Written in Python and built on the RenderDoc replay module, it lists draw calls, disassembles shaders, exports textures and buffers, and supports pixel-level debugging without opening the RenderDoc GUI. Output is tab-separated or JSON by default, so captures pipe cleanly into grep, awk, sort, diff, and jq, and a long-running daemon avoids reloading captures on every query. It includes CI-oriented assertions, two-frame diffs, local and split remote replay, and Android capture workflows for automated graphics validation. The tool suits game security and reverse engineering work where researchers need repeatable, scriptable analysis of rendering behavior, shader logic, and frame-to-frame GPU state changes.
