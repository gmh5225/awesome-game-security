rdc-cli 是一种可脚本化的命令行接口，将 RenderDoc GPU 捕获文件暴露为文本流和虚拟文件系统，便于在终端中检查帧数据。该工具用 Python 编写，基于 RenderDoc 回放模块，可列出 draw call、反汇编着色器、导出纹理与缓冲区，并支持像素级调试而无需打开 RenderDoc GUI。默认输出为制表符分隔或 JSON，捕获结果可顺畅接入 grep、awk、sort、diff 和 jq；长期运行的守护进程可避免每次查询都重新加载捕获。它包含面向 CI 的断言、两帧差异对比、本地与分片远程回放，以及用于自动化图形验证的 Android 捕获工作流。该工具适合游戏安全与逆向工程场景，研究人员需要对渲染行为、着色器逻辑及帧间 GPU 状态变化进行可重复、可脚本化的分析。
