rdc-cli 是一種可腳本化的命令列介面，將 RenderDoc GPU 擷取檔暴露為文字串流與虛擬檔案系統，便於在終端機中檢視幀資料。此工具以 Python 撰寫，建構於 RenderDoc 回放模組之上，可列出 draw call、反組譯著色器、匯出紋理與緩衝區，並支援像素級除錯而無需開啟 RenderDoc GUI。預設輸出為 Tab 分隔或 JSON，擷取結果可順暢接入 grep、awk、sort、diff 與 jq；長期執行的常駐程式可避免每次查詢都重新載入擷取。它包含面向 CI 的斷言、兩幀差異比對、本機與分片遠端回放，以及用於自動化圖形驗證的 Android 擷取工作流程。此工具適合遊戲安全與逆向工程，研究人員需要對渲染行為、著色器邏輯及幀間 GPU 狀態變化進行可重複、可腳本化的分析。
