rdc-cli は、RenderDoc の GPU キャプチャファイルをテキストストリームと仮想ファイルシステムとして公開する、スクリプト可能なコマンドラインインターフェースです。ターミナルからフレームデータを調査できます。Python で書かれ、RenderDoc のリプレイモジュール上に構築され、draw call の一覧、シェーダの逆アセンブル、テクスチャとバッファのエクスポート、RenderDoc GUI を開かないピクセル単位のデバッグをサポートします。出力はデフォルトでタブ区切りまたは JSON のため、キャプチャは grep、awk、sort、diff、jq にそのままパイプでき、常駐デーモンによりクエリのたびにキャプチャを再読み込みする必要がありません。CI 向けアサーション、2 フレーム差分、ローカルおよび分割リモートリプレイ、自動グラフィックス検証用の Android キャプチャワークフローを含みます。レンダリング挙動、シェーダロジック、フレーム間の GPU 状態変化を再現可能かつスクリプト可能に分析する必要があるゲームセキュリティやリバースエンジニアリングの研究に適したツールです。
