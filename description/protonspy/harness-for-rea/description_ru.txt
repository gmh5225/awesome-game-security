Harness for REA — настольное приложение и терминальный интерфейс, которые оркестрируют глубокий анализ ПО с помощью ИИ для программ, которые вам разрешено изучать, включая реверс-инжиниринг бинарников, отладку и разбор унаследованных кодовых баз. Вы описываете цели в чате, планирующий оркестратор (OpenRouter, DeepSeek или другие модели, совместимые с OpenAI) разбивает работу на шаги, а изолированный специалист с Claude Code в Docker выполняет аккуратный анализ через MCP-сервер реверс-инжиниринга REA и root-оболочку. Анализ выполняется в изолированных контейнерах с read-only копиями целей, журналированием событий в SQLite, проверенными контрактами анализа с тестовыми векторами и опциональной интеграцией с хостом, например read-only мостом памяти Cheat Engine для live-процессов Windows. Стек в основном TypeScript и Electron с настольной оболочкой React и shadcn/ui, терминальным UI на Bun и контейнеризованными песочницами специалистов. Для реверс-инженеров, исследователей безопасности и разработчиков, которым нужны структурированные, подкреплённые доказательствами RE-процессы без прямого размещения полных целей на хосте.
