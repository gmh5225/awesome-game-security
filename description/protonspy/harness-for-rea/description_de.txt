Harness for REA ist eine Desktop-Anwendung und Terminal-UI, die KI-gestützte Tiefenanalyse von Software orchestriert, die Sie autorisiert untersuchen dürfen – einschließlich Reverse Engineering von Binaries, Debugging und dem Verstehen veralteter Codebasen. Sie beschreiben Ziele im Chat, während ein Planungs-Orchestrator (OpenRouter, DeepSeek oder andere OpenAI-kompatible Modelle) die Arbeit in Schritte zerlegt und ein sandboxed Spezialist mit Claude Code in Docker sorgfältige Analysen mit dem REA-Reverse-Engineering-MCP-Server und einer Root-Shell durchführt. Die Analyse läuft in isolierten Containern mit schreibgeschützten Zielkopien, SQLite-gestütztem Event-Logging, validierten Analyseverträgen mit Testvektoren und optionalen Host-Integrationen wie einer schreibgeschützten Cheat-Engine-Speicherbrücke für live Windows-Prozesse. Der Stack basiert hauptsächlich auf TypeScript und Electron mit einer React- und shadcn/ui-Desktop-Hülle, einer Bun-basierten Terminal-UI und containerisierten Spezialisten-Sandboxes. Zielgruppe sind Reverse Engineers, Sicherheitsforscher und Entwickler, die strukturierte, evidenzbasierte RE-Workflows brauchen, ohne vollständige Ziele direkt auf dem Host preiszugeben.
