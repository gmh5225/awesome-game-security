Harness for REA 是一款桌面应用与终端 UI，用于编排经 AI 辅助的深度软件分析（仅限你有权研究的软件），涵盖逆向二进制、调试与理解遗留代码库。你在聊天中描述目标，规划编排器（OpenRouter、DeepSeek 或其他 OpenAI 兼容模型）将工作拆成步骤，在 Docker 中运行的沙箱化专家通过 REA 逆向工程 MCP 服务器与 root shell 执行审慎分析。分析在隔离容器中进行，目标为只读副本，具备 SQLite 事件日志、带测试向量的已验证分析契约，以及可选的主机集成（例如针对 live Windows 进程的只读 Cheat Engine 内存桥）。技术栈主要为 TypeScript 与 Electron 桌面壳（React 与 shadcn/ui）、基于 Bun 的终端 UI，以及容器化专家沙箱。面向需要结构化、有证据支撑的逆向工作流、且不愿在主机上直接暴露完整目标的逆向工程师、安全研究人员与开发者。
