Harness for REA は、分析権限のあるソフトウェア（バイナリのリバースエンジニアリング、デバッグ、レガシーコードベースの理解を含む）に対する AI 支援の深い分析を編成するデスクトップアプリとターミナル UI です。チャットで目標を述べると、計画オーケストレータ（OpenRouter、DeepSeek、その他 OpenAI 互換モデル）が作業を段階に分解し、Docker 上で動くサンドボックス化されたスペシャリストが REA リバースエンジニアリング MCP サーバーと root シェルで慎重な分析を行います。分析は隔離コンテナ内で実行され、ターゲットは読み取り専用コピー、SQLite によるイベントログ、テストベクトル付きの検証済み分析契約、および live な Windows プロセス向けの読み取り専用 Cheat Engine メモリブリッジなどのオプションのホスト連携があります。スタックは主に TypeScript と Electron、React と shadcn/ui のデスクトップシェル、Bun ベースのターミナル UI、コンテナ化されたスペシャリストサンドボックスです。ホスト上にターゲット全体を直接晒さず、構造化され証拠に裏付けられた RE ワークフローが必要なリバースエンジニア、セキュリティ研究者、開発者向けです。
