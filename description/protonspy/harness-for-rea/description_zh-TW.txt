Harness for REA 是一款桌面應用程式與終端 UI，用於編排經 AI 輔助的深度軟體分析（僅限您獲授權研究的軟體），涵蓋逆向二進位、除錯與理解遺留程式碼庫。您在聊天中描述目標，規劃編排器（OpenRouter、DeepSeek 或其他 OpenAI 相容模型）將工作拆成步驟，在 Docker 中執行的沙箱化專家透過 REA 逆向工程 MCP 伺服器與 root shell 執行審慎分析。分析在隔離容器中進行，目標為唯讀副本，具備 SQLite 事件日誌、附測試向量的已驗證分析契約，以及可選的主機整合（例如針對 live Windows 程序的唯讀 Cheat Engine 記憶體橋接）。技術棧主要為 TypeScript 與 Electron 桌面殼（React 與 shadcn/ui）、以 Bun 為基礎的終端 UI，以及容器化專家沙箱。面向需要結構化、有證據支撐的逆向工作流程、且不願在主機上直接暴露完整目標的逆向工程師、安全研究人員與開發者。
