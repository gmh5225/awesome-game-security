Harness for REA est une application de bureau et une interface terminal qui orchestrent une analyse approfondie assistée par l’IA de logiciels que vous êtes autorisé à étudier, y compris l’ingénierie inverse de binaires, le débogage et la compréhension de bases de code héritées. Vous décrivez vos objectifs dans le chat tandis qu’un orchestrateur de planification (OpenRouter, DeepSeek ou d’autres modèles compatibles OpenAI) découpe le travail en étapes et un spécialiste isolé exécutant Claude Code dans Docker effectue une analyse prudente avec le serveur MCP d’ingénierie inverse REA et un shell root. L’analyse s’exécute dans des conteneurs isolés avec des copies cibles en lecture seule, une journalisation d’événements SQLite, des contrats d’analyse validés avec vecteurs de test, et des intégrations hôte optionnelles comme un pont mémoire Cheat Engine en lecture seule pour les processus Windows live. La pile repose principalement sur TypeScript et Electron avec une coque bureau React et shadcn/ui, une UI terminal basée sur Bun, et des sandboxes spécialistes conteneurisées. Elle s’adresse aux ingénieurs reverse, chercheurs en sécurité et développeurs qui ont besoin de flux RE structurés et étayés par des preuves sans exposer les cibles complètes directement sur l’hôte.
