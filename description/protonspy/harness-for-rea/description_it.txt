Harness for REA è un’applicazione desktop e un’interfaccia terminale che orchestrano l’analisi approfondita assistita dall’IA di software che sei autorizzato a studiare, inclusi reverse engineering di binari, debug e comprensione di codebase legacy. Descrivi gli obiettivi in chat mentre un orchestratore di pianificazione (OpenRouter, DeepSeek o altri modelli compatibili OpenAI) scompone il lavoro in passi e uno specialista in sandbox che esegue Claude Code in Docker esegue un’analisi accurata con il server MCP di reverse engineering REA e una shell root. L’analisi gira in container isolati con copie di target in sola lettura, logging eventi su SQLite, contratti di analisi validati con vettori di test e integrazioni host opzionali come un bridge memoria Cheat Engine in sola lettura per processi Windows live. Lo stack è principalmente TypeScript ed Electron con shell desktop React e shadcn/ui, UI terminale basata su Bun e sandbox di specialisti containerizzate. È rivolto a reverse engineer, ricercatori di sicurezza e sviluppatori che necessitano flussi RE strutturati e supportati da evidenze senza esporre interi target direttamente sull’host.
