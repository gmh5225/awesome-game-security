Harness for REA is a desktop application and terminal UI that orchestrates AI-assisted deep analysis of software you are authorized to study, including reverse engineering binaries, debugging, and understanding legacy codebases. You describe goals in chat while a planning orchestrator (OpenRouter, DeepSeek, or other OpenAI-compatible models) breaks work into steps and a sandboxed specialist running Claude Code in Docker performs careful analysis with the REA reverse-engineering MCP server and a root shell. Analysis runs in isolated containers with read-only target copies, SQLite-backed event logging, validated analysis contracts with test vectors, and optional host integrations such as a read-only Cheat Engine memory bridge for live Windows processes. The stack is primarily TypeScript and Electron with a React and shadcn/ui desktop shell, a Bun-based terminal UI, and containerized specialist sandboxes. It targets reverse engineers, security researchers, and developers who need structured, evidence-backed RE workflows without exposing full targets directly on the host.
