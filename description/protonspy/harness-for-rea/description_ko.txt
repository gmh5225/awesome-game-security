Harness for REA는 분석 권한이 있는 소프트웨어(바이너리 리버스 엔지니어링, 디버깅, 레거시 코드베이스 이해 포함)에 대한 AI 보조 심층 분석을 조율하는 데스크톱 애플리케이션과 터미널 UI입니다. 채팅에서 목표를 설명하면 계획 오케스트레이터(OpenRouter, DeepSeek 또는 기타 OpenAI 호환 모델)가 작업을 단계로 나누고, Docker에서 실행되는 샌드박스 전문가가 REA 리버스 엔지니어링 MCP 서버와 root 셸로 신중한 분석을 수행합니다. 분석은 격리된 컨테이너에서 실행되며 대상은 읽기 전용 복사본, SQLite 기반 이벤트 로깅, 테스트 벡터가 있는 검증된 분석 계약, live Windows 프로세스용 읽기 전용 Cheat Engine 메모리 브리지 등 선택적 호스트 통합을 제공합니다. 스택은 주로 TypeScript와 Electron, React 및 shadcn/ui 데스크톱 셸, Bun 기반 터미널 UI, 컨테이너화된 전문가 샌드박스로 구성됩니다. 호스트에 전체 대상을 직접 노출하지 않고 구조화되고 증거 기반 RE 워크플로가 필요한 리버스 엔지니어, 보안 연구자, 개발자를 대상으로 합니다.
