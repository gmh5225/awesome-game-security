Harness for REA es una aplicación de escritorio y una interfaz de terminal que orquesta el análisis profundo asistido por IA de software que está autorizado a estudiar, incluida la ingeniería inversa de binarios, la depuración y la comprensión de bases de código heredadas. Describe objetivos en el chat mientras un orquestador de planificación (OpenRouter, DeepSeek u otros modelos compatibles con OpenAI) divide el trabajo en pasos y un especialista en sandbox que ejecuta Claude Code en Docker realiza un análisis cuidadoso con el servidor MCP de ingeniería inversa REA y un shell root. El análisis se ejecuta en contenedores aislados con copias de objetivo de solo lectura, registro de eventos respaldado por SQLite, contratos de análisis validados con vectores de prueba e integraciones opcionales en el host, como un puente de memoria de solo lectura de Cheat Engine para procesos Windows en vivo. La pila es principalmente TypeScript y Electron con un shell de escritorio React y shadcn/ui, una UI de terminal basada en Bun y sandboxes de especialistas contenedorizados. Está dirigido a ingenieros de reversa, investigadores de seguridad y desarrolladores que necesitan flujos RE estructurados y respaldados por evidencia sin exponer objetivos completos directamente en el host.
