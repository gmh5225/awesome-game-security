WFB-Driver は、ユーザーモードのアンチチートが通常の ReadProcessMemory および WriteProcessMemory を遮断しているときに、カーネルモードから別プロセスの仮想メモリを読み書きする最小構成の Windows カーネルドライバーです。ドライバーは MmCopyVirtualMemory と KeStackAttachProcess を基盤とした IOCTL ベースの読み書き操作を公開し、自己テスト、マジックバイトスキャン、コミット済みプライベート領域の完全ダンプ用の C ユーティリティが付属しています。主に C で記述され、MinGW-w64 と Windows DDK でビルドし、x64 の Windows 10/11 でテスト署名デプロイを想定しています。Warface 系クライアント、ドライバーの ObCallback フィルタリングの影響、プロセス内アンチチート blob の調査を行うゲームセキュリティ研究者およびリバースエンジニア向けであり、本番バイパスやチート作成向けではありません。
