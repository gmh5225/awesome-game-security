WFB-Driver is a minimal Windows kernel driver that reads and writes another process's virtual memory from kernel mode when userspace anti-cheat blocks normal ReadProcessMemory and WriteProcessMemory access. The driver exposes IOCTL-based read and write operations built on MmCopyVirtualMemory and KeStackAttachProcess, with companion C utilities for self-tests, magic-byte scanning, and full dumps of committed private regions. It is written primarily in C and built with MinGW-w64 against the Windows DDK for test-signed deployment on x64 Windows 10/11. The project targets game-security researchers and reverse engineers studying Warface-style clients, impact driver ObCallback filtering, and live in-process anti-cheat blobs, not production bypass or cheat authoring.
