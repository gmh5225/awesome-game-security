Paksmith is a cross-platform Rust toolkit for exploring and extracting Unreal Engine game assets, designed as a rewrite of FModel. It provides a core library that reads UE pak archives (versions v3 through v11), parses UAsset packages including name/import/export tables and typed properties, and exports assets to common formats such as PNG textures, glTF meshes, WAV/OGG audio, and CSV/JSON data tables. The project ships a CLI for listing and inspecting packages, with an Iced-based GUI planned, plus support for zlib/LZ4 decompression, SHA-1 integrity checks, and bounded parsing against adversarial input. It is aimed at reverse engineers, modders, and game-security researchers who need to analyze or extract assets from Unreal Engine games.
