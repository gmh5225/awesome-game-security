Paksmith is a cross-platform Rust toolkit for exploring and extracting Unreal Engine game assets, written as a rewrite of FModel. It provides a core library that reads UE pak archives (versions v3–v11) with zlib/LZ4 decompression, optional SHA-1 verification, and UAsset parsing including name, import, and export tables plus a full property system. Export handlers convert textures, static and skeletal meshes, audio, and data tables into common formats such as PNG, glTF, WAV/OGG, CSV, and JSON. A CLI and planned Iced-based GUI sit on top of the library for listing, inspecting, searching, and extracting packaged content. It is aimed at reverse engineers, modders, and game-security researchers who need to analyze Unreal Engine packaged assets offline.
