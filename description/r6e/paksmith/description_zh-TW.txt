Paksmith 是一個跨平台的 Rust 工具包，用於瀏覽與擷取 Unreal Engine 遊戲資源，作為 FModel 的重寫版本。它提供核心函式庫，可讀取 UE pak 封存（v3–v11），支援 zlib/LZ4 解壓、可選的 SHA-1 驗證，以及包含名稱表、匯入表、匯出表與完整屬性系統的 UAsset 解析。匯出處理器可將貼圖、靜態網格與骨骼網格、音訊與資料表轉換為 PNG、glTF、WAV/OGG、CSV、JSON 等常見格式。CLI 以及規劃中的基於 Iced 的 GUI 建構於該函式庫之上，用於列出、檢查、搜尋與擷取封裝內容。面向需要離線分析 Unreal Engine 封裝資源的逆向工程師、模組作者與遊戲安全研究人員。
