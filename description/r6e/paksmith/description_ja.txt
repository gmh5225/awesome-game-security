Paksmith は、Unreal Engine のゲームアセットを探索・抽出するためのクロスプラットフォームな Rust ツールキットであり、FModel の書き換えとして書かれています。コアライブラリは UE pak アーカイブ（v3–v11）を読み取り、zlib/LZ4 展開、オプションの SHA-1 検証、および名前・インポート・エクスポートテーブルと完全なプロパティシステムを含む UAsset 解析を提供します。エクスポートハンドラはテクスチャ、静的／スケルタルメッシュ、オーディオ、データテーブルを PNG、glTF、WAV/OGG、CSV、JSON などの一般的な形式に変換します。CLI と計画中の Iced ベース GUI がライブラリ上に乗り、パッケージ内容の一覧表示、検査、検索、抽出を行います。オフラインで Unreal Engine のパッケージ済みアセットを分析するリバースエンジニア、モッダー、ゲームセキュリティ研究者向けです。
