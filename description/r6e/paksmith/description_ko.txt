Paksmith는 Unreal Engine 게임 에셋을 탐색하고 추출하기 위한 크로스플랫폼 Rust 툴킷으로, FModel을 재작성한 프로젝트입니다. 핵심 라이브러리는 UE pak 아카이브(v3–v11)를 읽고 zlib/LZ4 압축 해제, 선택적 SHA-1 검증, 그리고 이름·임포트·익스포트 테이블과 전체 프로퍼티 시스템을 포함한 UAsset 파싱을 제공합니다. 익스포트 핸들러는 텍스처, 정적·스켈레탈 메시, 오디오, 데이터 테이블을 PNG, glTF, WAV/OGG, CSV, JSON 같은 일반 형식으로 변환합니다. CLI와 계획 중인 Iced 기반 GUI가 라이브러리 위에 올라가 패키지 콘텐츠를 나열·검사·검색·추출합니다. 오프라인으로 Unreal Engine 패키지 에셋을 분석해야 하는 리버스 엔지니어, 모더, 게임 보안 연구자를 대상으로 합니다.
