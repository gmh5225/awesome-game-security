Paksmith 是一个跨平台的 Rust 工具包，用于浏览和提取 Unreal Engine 游戏资源，作为 FModel 的重写版本。它提供核心库，可读取 UE pak 归档（v3–v11），支持 zlib/LZ4 解压、可选的 SHA-1 校验，以及包含名称表、导入表、导出表和完整属性系统的 UAsset 解析。导出处理器可将纹理、静态网格与骨骼网格、音频和数据表转换为 PNG、glTF、WAV/OGG、CSV、JSON 等常见格式。CLI 以及计划中的基于 Iced 的 GUI 构建在该库之上，用于列出、检查、搜索和提取打包内容。面向需要离线分析 Unreal Engine 打包资源的逆向工程师、模组作者和游戏安全研究人员。
