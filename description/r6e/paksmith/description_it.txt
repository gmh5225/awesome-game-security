Paksmith è un toolkit Rust multipiattaforma per esplorare ed estrarre asset di giochi Unreal Engine, scritto come riscrittura di FModel. Fornisce una libreria core che legge gli archivi pak UE (versioni v3–v11) con decompressione zlib/LZ4, verifica SHA-1 opzionale e parsing UAsset che include tabelle di nomi, import ed export oltre a un sistema completo di proprietà. Gli handler di export convertono texture, mesh statiche e skeletal, audio e data table in formati comuni come PNG, glTF, WAV/OGG, CSV e JSON. Una CLI e una GUI basata su Iced (pianificata) si appoggiano alla libreria per elencare, ispezionare, cercare ed estrarre il contenuto pacchettizzato. È rivolto a reverse engineer, modder e ricercatori di game security che devono analizzare offline gli asset pacchettizzati di Unreal Engine.
