Paksmith es un kit de herramientas Rust multiplataforma para explorar y extraer assets de juegos Unreal Engine, escrito como una reescritura de FModel. Proporciona una biblioteca central que lee archivos pak de UE (versiones v3–v11) con descompresión zlib/LZ4, verificación SHA-1 opcional y análisis UAsset que incluye tablas de nombres, importaciones y exportaciones, además de un sistema completo de propiedades. Los controladores de exportación convierten texturas, mallas estáticas y esqueléticas, audio y data tables a formatos comunes como PNG, glTF, WAV/OGG, CSV y JSON. Una CLI y una GUI basada en Iced (planificada) se apoyan en la biblioteca para listar, inspeccionar, buscar y extraer contenido empaquetado. Está dirigido a ingenieros inversos, modders e investigadores de seguridad en juegos que necesitan analizar offline assets empaquetados de Unreal Engine.
