Paksmith — кроссплатформенный набор инструментов на Rust для просмотра и извлечения игровых ассетов Unreal Engine, написанный как переработка FModel. Он предоставляет основную библиотеку, которая читает архивы UE pak (версии v3–v11) с распаковкой zlib/LZ4, опциональной проверкой SHA-1 и разбором UAsset, включая таблицы имён, импортов и экспортов, а также полную систему свойств. Обработчики экспорта преобразуют текстуры, статические и скелетные меши, аудио и таблицы данных в распространённые форматы: PNG, glTF, WAV/OGG, CSV и JSON. CLI и планируемый GUI на Iced работают поверх библиотеки для просмотра списков, инспекции, поиска и извлечения упакованного содержимого. Инструмент предназначен для реверс-инженеров, моддеров и исследователей игровой безопасности, которым нужно офлайн анализировать упакованные ассеты Unreal Engine.
