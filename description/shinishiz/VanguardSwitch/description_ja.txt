VanguardSwitch は、プレイしていないときに Riot Vanguard をオフにし、フル再起動なしで元に戻す Windows デスクトップユーティリティです。C# で .NET Framework 4.8 向けに書かれ、WinForms の UI を備え、vgc サービスの停止とブロック、オプションで vgk カーネルドライバをロードしたままにする処理、Riot Client と関連ゲームの終了、および各ステップを明示的に検証しながらそれらを元に戻す機能を提供します。Windows サービス制御、起動エントリの変更、Riot プロセス終了前の WinVerifyTrust 署名検証、オプションの GitHub リリース更新と SHA-256 検証を利用します。Riot 公式の Vanguard On-Demand モードが使えない Windows 10 または 11 のプレイヤーと研究者向けで、プレイ外では Vanguard を非アクティブに保ちつつ、VAN 57 やドライバのブート状態のエッジケースを扱いたい場合に適しています。
