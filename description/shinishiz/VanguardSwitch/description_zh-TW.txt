VanguardSwitch 是一款 Windows 桌面工具：在不玩遊戲時關閉 Riot Vanguard，並在無需完整重新開機的情況下還原。以 C# 撰寫，目標為 .NET Framework 4.8，採用 WinForms 介面；它會停止並封鎖 vgc 服務，可選擇維持 vgk 核心驅動程式載入，關閉 Riot Client 與相關遊戲，並透過逐步明確檢查還原上述步驟。工具使用 Windows 服務控制、啟動項目變更、在終止 Riot 程序前進行 WinVerifyTrust 簽章驗證，以及可選的 GitHub 發行更新與 SHA-256 驗證。面向無法使用 Riot 官方 Vanguard 隨選模式的 Windows 10 或 11 玩家與研究人員，希望在非遊戲時段讓 Vanguard 保持非作用中，並處理 VAN 57 與驅動程式開機狀態等邊界情況。
