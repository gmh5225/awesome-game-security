VanguardSwitch는 게임을 하지 않을 때 Riot Vanguard를 끄고 전체 재부팅 없이 복구하는 Windows 데스크톱 유틸리티입니다. C#으로 .NET Framework 4.8용으로 작성되었으며 WinForms UI를 사용하고, vgc 서비스를 중지·차단하고 선택적으로 vgk 커널 드라이버를 로드된 상태로 유지하며 Riot Client와 관련 게임을 종료한 뒤 각 단계를 명시적으로 검사하며 되돌립니다. Windows 서비스 제어, 시작 항목 변경, Riot 프로세스 종료 전 WinVerifyTrust 서명 검증, 선택적 GitHub 릴리스 업데이트와 SHA-256 검증을 사용합니다. Riot 공식 Vanguard On-Demand 모드를 쓸 수 없는 Windows 10 또는 11의 플레이어와 연구자를 대상으로, 플레이 세션 밖에서는 Vanguard를 비활성 상태로 두면서 VAN 57 및 드라이버 부팅 상태 엣지 케이스를 관리하려는 경우를 위한 도구입니다.
