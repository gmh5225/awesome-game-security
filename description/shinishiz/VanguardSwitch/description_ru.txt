VanguardSwitch — настольная утилита для Windows, которая отключает Riot Vanguard, когда вы не играете, и восстанавливает его без полной перезагрузки. Написана на C# для .NET Framework 4.8 с интерфейсом WinForms: останавливает и блокирует службу vgc, при необходимости оставляет загруженным драйвер ядра vgk, закрывает Riot Client и связанные игры и откатывает эти шаги с явной проверкой на каждом этапе. Используются управление службами Windows, изменение записей автозагрузки, проверка подписи WinVerifyTrust перед завершением процессов Riot и необязательные обновления с релизов GitHub с проверкой SHA-256. Инструмент ориентирован на игроков и исследователей в Windows 10 или 11, которые не могут использовать официальный режим Vanguard On-Demand от Riot и хотят держать Vanguard неактивным вне игровых сессий, управляя пограничными случаями VAN 57 и состоянием загрузки драйвера.
