VanguardSwitch es una utilidad de escritorio para Windows que desactiva Riot Vanguard cuando no estás jugando y lo restaura sin un reinicio completo. Escrita en C# para .NET Framework 4.8 con interfaz WinForms, detiene y bloquea el servicio vgc, opcionalmente mantiene cargado el controlador de kernel vgk, cierra Riot Client y juegos relacionados, y revierte esos pasos con comprobaciones explícitas en cada etapa. Usa control de servicios de Windows, cambios en entradas de inicio, verificación de firma WinVerifyTrust antes de terminar procesos de Riot, y actualizaciones opcionales desde GitHub con verificación SHA-256. La herramienta está pensada para jugadores e investigadores en Windows 10 u 11 que no pueden usar el modo oficial Vanguard On-Demand de Riot y quieren mantener Vanguard inactivo fuera de las sesiones de juego mientras gestionan casos límite de VAN 57 y el estado de arranque del controlador.
