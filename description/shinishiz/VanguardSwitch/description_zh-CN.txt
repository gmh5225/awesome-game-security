VanguardSwitch 是一款 Windows 桌面工具：在不玩游戏时关闭 Riot Vanguard，并在无需完整重启的情况下恢复。采用 C# 编写，面向 .NET Framework 4.8，使用 WinForms 界面；它会停止并阻止 vgc 服务，可选保持 vgk 内核驱动加载，关闭 Riot Client 及相关游戏，并通过逐步显式检查撤销上述操作。工具使用 Windows 服务控制、启动项修改、在终止 Riot 进程前进行 WinVerifyTrust 签名验证，以及可选的 GitHub 发布更新与 SHA-256 校验。面向无法使用 Riot 官方 Vanguard 按需模式的 Windows 10 或 11 玩家与研究人员，希望在非游戏时段保持 Vanguard 处于非激活状态，并处理 VAN 57 与驱动启动状态等边界情况。
