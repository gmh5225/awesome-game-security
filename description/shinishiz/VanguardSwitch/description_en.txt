VanguardSwitch is a Windows desktop utility that turns Riot Vanguard off when you are not playing and restores it without a full reboot. Written in C# for .NET Framework 4.8 with a WinForms user interface, it stops and blocks the vgc service, optionally keeps the vgk kernel driver loaded, closes Riot Client and related games, and reverses those steps with explicit per-step checks. It uses Windows service control, startup entry changes, WinVerifyTrust signature verification before terminating Riot processes, and optional GitHub release updates with SHA-256 verification. The tool targets players and researchers on Windows 10 or 11 who cannot use Riot's official Vanguard On-Demand mode and want Vanguard inactive outside play sessions while managing VAN 57 and driver boot-state edge cases.
