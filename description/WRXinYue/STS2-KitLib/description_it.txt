KitLib è un mod toolkit di sviluppo modulare per Slay the Spire 2 che offre pannelli di debug in-game, utility per cheat e introspezione a runtime per autori di mod e tester. Scritto principalmente in C# con patching IL Harmony, utilizza un host centrale più moduli satellite opzionali per strumenti utente, IA, cheat e funzionalità di sviluppo. Tra le capacità principali figurano una console per sviluppatori basata su browser per log in tempo reale e telemetria di combattimento, un ponte MCP per query automatizzate sullo stato di gioco e azioni scriptate, analisi dei patch Harmony ed esportazione ZIP diagnostica per feedback sui mod. Con automazione di build Python e un viewer di sviluppo TypeScript/Vue, è rivolto a sviluppatori di mod STS2, reverse engineer e chiunque automatizzi o sottoponga a stress test il comportamento di gioco.
