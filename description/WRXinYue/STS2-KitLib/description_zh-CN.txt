KitLib 是《杀戮尖塔 2》（Slay the Spire 2）的一款模块化开发者工具包 Mod，为 Mod 作者和测试人员提供游戏内调试面板、作弊工具以及运行时自省能力。项目主要使用 C# 编写，并通过 Harmony IL 补丁实现，采用核心宿主加可选卫星模块的架构，涵盖用户工具、AI、作弊与开发功能。主要能力包括基于浏览器的开发者控制台（用于实时日志与战斗遥测）、用于自动化游戏状态查询与脚本化操作的 MCP 桥接、Harmony 补丁分析，以及用于 Mod 反馈的诊断 ZIP 导出。项目还支持 Python 构建自动化与 TypeScript/Vue 开发查看器，面向 STS2 Mod 开发者、逆向工程师，以及需要自动化或压力测试游戏行为的用户。
