KitLib — модульный набор инструментов разработчика для Slay the Spire 2, предоставляющий внутриигровые панели отладки, утилиты для читов и интроспекцию во время выполнения для авторов модов и тестировщиков. Написан в основном на C# с использованием IL-патчинга Harmony; включает центральный хост и опциональные спутниковые модули для пользовательских инструментов, ИИ, читов и функций разработки. Среди ключевых возможностей — браузерная консоль разработчика для живых логов и боевой телеметрии, MCP-мост для автоматизированных запросов состояния игры и скриптовых действий, анализ патчей Harmony и экспорт диагностического ZIP для обратной связи по модам. Поддерживает автоматизацию сборки на Python и просмотрщик разработки TypeScript/Vue; предназначен для разработчиков модов STS2, специалистов по реверс-инжинирингу и всех, кто автоматизирует или стресс-тестирует поведение игры.
