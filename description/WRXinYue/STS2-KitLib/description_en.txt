KitLib is a modular developer toolkit mod for Slay the Spire 2 that provides in-game debugging panels, cheat utilities, and runtime introspection for mod authors and testers. Written primarily in C# with Harmony IL patching, it uses a core host plus optional satellite modules for user tools, AI, cheats, and development features. Notable capabilities include a browser-based developer console for live logs and combat telemetry, an MCP bridge for automated game-state queries and scripted actions, Harmony patch analysis, and diagnostic ZIP export for mod feedback. Supporting Python build automation and a TypeScript/Vue dev viewer, it is aimed at STS2 mod developers, reverse engineers, and anyone automating or stress-testing game behavior.
