KitLib 是《殺戮尖塔 2》（Slay the Spire 2）的一款模組化開發者工具包 Mod，為 Mod 作者與測試人員提供遊戲內除錯面板、作弊工具以及執行階段自省能力。專案主要使用 C# 撰寫，並透過 Harmony IL 修補實作，採用核心宿主加可選衛星模組的架構，涵蓋使用者工具、AI、作弊與開發功能。主要能力包括以瀏覽器為基礎的開發者主控台（用於即時日誌與戰鬥遙測）、用於自動化遊戲狀態查詢與腳本化操作的 MCP 橋接、Harmony 修補分析，以及用於 Mod 回饋的診斷 ZIP 匯出。專案還支援 Python 建置自動化與 TypeScript/Vue 開發檢視器，面向 STS2 Mod 開發者、逆向工程師，以及需要自動化或壓力測試遊戲行為的使用者。
