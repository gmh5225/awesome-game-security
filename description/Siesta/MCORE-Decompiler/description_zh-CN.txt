MCORE-Decompiler 是一款面向 Motorola M·CORE 二进制文件的独立反编译器，以 IDA Pro 9.4 插件形式发布。该工具采用 C++17 编写，将 IDA 内置 MCORE 处理器模块的反汇编结果提升为自定义中间表示，随后执行优化、控制流结构化、栈帧恢复和调用参数分析，最终生成与 F5 绑定的可读 C 伪代码。由于 Hex-Rays 未提供 M·CORE 反编译后端，本项目实现了不依赖 Hex-Rays 反编译 API 的独立流水线。它面向分析嵌入式固件和功能机二进制文件的逆向工程师，例如广泛采用 M·CORE 但此前缺乏原生反编译能力的 Motorola E1000。
