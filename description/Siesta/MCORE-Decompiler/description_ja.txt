MCORE-Decompiler は、Motorola M·CORE バイナリ向けのスタンドアロン逆コンパイラで、IDA Pro 9.4 プラグインとして提供されます。C++17 で書かれており、IDA 組み込みの MCORE プロセッサモジュールから得た逆アセンブリを独自の中間表現へ持ち上げ、最適化、制御フロー構造化、スタックフレーム復元、呼び出し引数解析を経て、F5 に紐づく読みやすい C 疑似コードを出力します。Hex-Rays には M·CORE 用の逆コンパイラバックエンドがないため、本プロジェクトは Hex-Rays 逆コンパイラ API に依存しない独立したパイプラインを実装しています。M·CORE が一般的に使われていたがネイティブな逆コンパイルがこれまで提供されていなかった、Motorola E1000 などの組み込みファームウェアやフィーチャーフォン向けバイナリを解析するリバースエンジニアを対象としています。
