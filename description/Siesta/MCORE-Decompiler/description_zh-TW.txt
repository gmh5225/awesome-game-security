MCORE-Decompiler 是一款面向 Motorola M·CORE 二進位檔的獨立反編譯器，以 IDA Pro 9.4 外掛形式發布。此工具以 C++17 撰寫，將 IDA 內建 MCORE 處理器模組的反組譯結果提升為自訂中間表示，隨後執行最佳化、控制流程結構化、堆疊框架還原與呼叫參數分析，最終產生與 F5 綁定的可讀 C 虛擬碼。由於 Hex-Rays 未提供 M·CORE 反編譯後端，本專案實作了不依賴 Hex-Rays 反編譯 API 的獨立管線。它面向分析嵌入式韌體與功能型手機二進位檔的逆向工程師，例如廣泛採用 M·CORE 但此前缺乏原生反編譯能力的 Motorola E1000。
