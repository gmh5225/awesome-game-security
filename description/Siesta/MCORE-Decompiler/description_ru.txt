MCORE-Decompiler — это автономный декомпилятор для бинарных файлов Motorola M·CORE, поставляемый в виде плагина для IDA Pro 9.4. Написанный на C++17, он поднимает дизассемблированный код встроенного процессора MCORE в IDA до пользовательского промежуточного представления, затем выполняет оптимизацию, структурирование потока управления, восстановление стековых фреймов и анализ аргументов вызовов, после чего генерирует читаемый C-псевдокод, привязанный к F5. Поскольку Hex-Rays не предоставляет бэкенд декомпиляции для M·CORE, проект реализует независимый конвейер без опоры на API декомпилятора Hex-Rays. Он предназначен для инженеров по реверс-инжинирингу, анализирующих встроенную прошивку и бинарники feature phone, например Motorola E1000, где M·CORE широко использовался, но нативная декомпиляция ранее была недоступна.
