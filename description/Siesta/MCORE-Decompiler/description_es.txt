MCORE-Decompiler es un descompilador autónomo para binarios Motorola M·CORE que se distribuye como complemento de IDA Pro 9.4. Escrito en C++17, eleva el desensamblado del procesador MCORE integrado en IDA a una representación intermedia personalizada, y luego ejecuta optimización, estructuración del flujo de control, recuperación de marcos de pila y análisis de argumentos de llamada antes de emitir pseudocódigo C legible vinculado a F5. Como Hex-Rays no proporciona un backend de descompilación para M·CORE, el proyecto implementa una canalización independiente sin depender de las API de descompilación de Hex-Rays. Está dirigido a ingenieros de ingeniería inversa que analizan firmware embebido y binarios de teléfonos básicos, como el Motorola E1000, donde M·CORE se usaba con frecuencia pero la descompilación nativa no estaba disponible.
