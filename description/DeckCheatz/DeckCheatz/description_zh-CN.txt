DeckCheatz 是一款面向 Steam Deck 及其他 Linux 系统的便携游戏修改器界面，以 Steam Proton 兼容工具包装器实现，简化了在 Wine 与 Proton 下运行修改器软件的过程。核心应用使用 Rust 编写，基于 Tokio、Clap、Serde 构建，并可选 SQLite 存储，通过特性开关支持 Steam 库发现、Steamworks 绑定、proton-call 以及 Decky 集成。发行以 Flatpak 与 Nix 为主，便于将工具安装到 Steam 兼容工具目录并与 Steam 运行时并存。它面向在 Proton 游戏环境中使用或研究 WeMod、PLITCH 等第三方修改器的 Linux 玩家与研究人员，提供可重复的方式启动和管理这些工具，而无需手动配置 Wine 前缀。
