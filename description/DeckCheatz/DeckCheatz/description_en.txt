DeckCheatz is a portable game trainer interface for Steam Deck and other Linux systems, implemented as a Steam Proton compatibility tool wrapper that simplifies running trainer software under Wine and Proton. The core application is written in Rust and built with Tokio, Clap, Serde, and optional SQLite storage, with feature flags for Steam library discovery, Steamworks bindings, proton-call, and Decky integration. Distribution focuses on Flatpak and Nix so the tool installs into Steam’s compatibility tools directory alongside the Steam runtime. It is aimed at Linux gamers and researchers who use or study third-party trainers such as WeMod and PLITCH, and who need a repeatable way to launch and manage those tools in a Proton gaming environment rather than hand-configuring Wine prefixes.
