DeckCheatz は Steam Deck やその他の Linux 向けのポータブルなゲームトレーナー用インターフェースで、Steam Proton 互換ツールのラッパーとして実装され、Wine と Proton 上でトレーナーソフトを動かす手順を簡素化します。コアアプリは Rust で書かれ、Tokio、Clap、Serde を用いて構築され、オプションで SQLite ストレージを備え、Steam ライブラリ検出、Steamworks バインディング、proton-call、Decky 連携などを機能フラグで切り替えられます。配布は Flatpak と Nix を中心とし、Steam の互換ツールディレクトリに Steam ランタイムと並べてインストールできるようにしています。WeMod や PLITCH などのサードパーティトレーナーを Proton のゲーム環境で使う、または研究する Linux ゲーマーと研究者向けで、Wine プレフィックスを手作業で設定する代わりに、それらのツールを起動・管理する再現可能な方法を提供します。
