本專案提供基於 Frida 的邊界 Hook 框架，用於動態分析與繞過受 VMP 和 OLLVM 混淆保護的 Android 原生函式庫。它不依賴靜態去混淆扁平化控制流程或虛擬機器位元組碼，而是透過 Hook libc、JNI 及 Java 層 API，記錄每一次外部副作用，並標註加固共享物件內的呼叫者位址。附帶的 JavaScript 腳本面向已 root 裝置或模擬器上的 spawn 模式注入，可從主控台輸出重建環境檢測、防篡改邏輯及其他安全敏感呼叫鏈。核心技術包括三層邊界監控、與 IDA 等反組譯器聯動的呼叫者位址交叉引用，以及在定位檢測函式後對參數或回傳值進行針對性篡改。適用於經授權的反組譯分析、手遊安全研究、反作弊分析及對您擁有或獲准檢測的應用程式進行 CTF 式安全測試。
