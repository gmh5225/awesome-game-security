Este proyecto proporciona un harness de hooks en los límites basado en Frida para analizar dinámicamente y eludir bibliotecas nativas de Android protegidas con ofuscación VMP y OLLVM. En lugar de desofuscar estáticamente flujos de control aplanados o bytecode de máquina virtual, engancha las API de libc, JNI y la capa Java para registrar cada efecto secundario externo junto con la dirección del llamador dentro del objeto compartido endurecido. El script JavaScript incluido está diseñado para inyección en modo spawn en dispositivos con root o emuladores, lo que permite reconstruir comprobaciones de entorno, lógica anti-manipulación y otras cadenas de llamadas sensibles a la seguridad a partir de la salida de consola. Las técnicas clave incluyen monitorización de límites en tres capas, referencia cruzada de direcciones de llamada con desensambladores como IDA, y manipulación selectiva de argumentos o valores de retorno una vez identificadas las funciones de detección. Está destinado a ingeniería inversa autorizada, investigación de seguridad en juegos móviles, análisis anti-trampas y pruebas de seguridad tipo CTF en aplicaciones que posea o tenga permiso para examinar.
