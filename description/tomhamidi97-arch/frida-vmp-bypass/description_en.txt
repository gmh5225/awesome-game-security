This project provides a Frida-based boundary-hook harness for dynamically analyzing and bypassing Android native libraries protected with VMP and OLLVM obfuscation. Instead of deobfuscating flattened control flow or virtual-machine bytecode statically, it hooks libc, JNI, and Java-layer APIs to log every external side effect along with the caller address inside the hardened shared object. The included JavaScript script is designed for spawn-mode injection on rooted devices or emulators, enabling reconstruction of environment checks, anti-tamper logic, and other security-sensitive call chains from console output. Key techniques include three-layer boundary monitoring, caller-address cross-referencing with disassemblers such as IDA, and targeted argument or return-value tampering once detection functions are identified. It is intended for authorized reverse engineering, mobile game security research, anti-cheat analysis, and CTF-style security testing of apps you own or are permitted to examine.
