Этот проект предоставляет основанный на Frida каркас пограничных хуков для динамического анализа и обхода нативных библиотек Android, защищённых обфускацией VMP и OLLVM. Вместо статической деобфускации сплющенных потоков управления или байткода виртуальной машины он перехватывает API libc, JNI и Java-слоя, чтобы фиксировать каждый внешний побочный эффект вместе с адресом вызывающего кода внутри защищённого разделяемого объекта. Включённый JavaScript-скрипт предназначен для инъекции в режиме spawn на устройствах с root-доступом или эмуляторах, что позволяет восстанавливать проверки окружения, логику анти-подделки и другие цепочки вызовов, связанные с безопасностью, по выводу консоли. Ключевые методы включают трёхуровневый мониторинг границ, перекрёстное сопоставление адресов вызывающего кода с disassembler'ами, такими как IDA, и целенаправленное изменение аргументов или возвращаемых значений после идентификации функций обнаружения. Предназначен для авторизованного реверс-инжиниринга, исследований безопасности мобильных игр, анализа античит-систем и тестирования безопасности в стиле CTF приложений, которыми вы владеете или которые вам разрешено исследовать.
