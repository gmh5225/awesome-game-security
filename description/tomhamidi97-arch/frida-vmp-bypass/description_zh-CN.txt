本项目提供基于 Frida 的边界 Hook 框架，用于动态分析与绕过受 VMP 和 OLLVM 混淆保护的 Android 原生库。它不依赖静态去混淆扁平化控制流或虚拟机字节码，而是通过 Hook libc、JNI 及 Java 层 API，记录每一次外部副作用，并标注加固共享对象内的调用者地址。附带的 JavaScript 脚本面向已 root 设备或模拟器上的 spawn 模式注入，可从控制台输出重建环境检测、防篡改逻辑及其他安全敏感调用链。核心技术包括三层边界监控、与 IDA 等反汇编器联动的调用者地址交叉引用，以及在定位检测函数后对参数或返回值进行针对性篡改。适用于经授权的反汇编分析、手游安全研究、反作弊分析及对您拥有或获准检测的应用进行 CTF 式安全测试。
