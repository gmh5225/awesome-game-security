Questo progetto fornisce un harness di hook ai confini basato su Frida per analizzare dinamicamente e bypassare librerie native Android protette con offuscamento VMP e OLLVM. Invece di deoffuscare staticamente flussi di controllo appiattiti o bytecode di macchina virtuale, aggancia le API di libc, JNI e del layer Java per registrare ogni effetto collaterale esterno insieme all'indirizzo del chiamante all'interno dell'oggetto condiviso indurito. Lo script JavaScript incluso è progettato per l'iniezione in modalità spawn su dispositivi con root o emulatori, consentendo di ricostruire controlli sull'ambiente, logica anti-manomissione e altre catene di chiamate sensibili alla sicurezza dall'output della console. Le tecniche chiave includono il monitoraggio ai confini su tre livelli, il riferimento incrociato degli indirizzi dei chiamanti con disassemblatori come IDA e la manipolazione mirata di argomenti o valori di ritorno una volta identificate le funzioni di rilevamento. È destinato a reverse engineering autorizzato, ricerca sulla sicurezza dei giochi mobile, analisi anti-cheat e test di sicurezza in stile CTF su app di cui si è proprietari o che si è autorizzati a esaminare.
