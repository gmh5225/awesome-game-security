이 프로젝트는 VMP 및 OLLVM 난독화로 보호된 Android 네이티브 라이브러리를 동적으로 분석하고 우회하기 위한 Frida 기반 경계 후크 하네스를 제공합니다. 평탄화된 제어 흐름이나 가상 머신 바이트코드를 정적으로 디난독화하는 대신, libc, JNI, Java 계층 API를 후크하여 강화된 공유 객체 내부의 호출자 주소와 함께 모든 외부 부작용을 기록합니다. 포함된 JavaScript 스크립트는 루팅된 기기 또는 에뮬레이터에서 spawn 모드 주입을 위해 설계되었으며, 콘솔 출력을 통해 환경 검사, 변조 방지 로직 및 기타 보안 민감 호출 체인을 재구성할 수 있습니다. 주요 기법에는 3계층 경계 모니터링, IDA와 같은 disassembler와의 호출자 주소 상호 참조, 탐지 함수 식별 후 인자 또는 반환값의 대상별 변조가 포함됩니다. 승인된 리버스 엔지니어링, 모바일 게임 보안 연구, 안티치트 분석, 그리고 소유하거나 검사 허가를 받은 앱에 대한 CTF 형식의 보안 테스트를 목적으로 합니다.
