本プロジェクトは、VMP および OLLVM 難読化で保護された Android ネイティブライブラリを動的に解析・バイパスするための、Frida ベースの境界フックハーネスを提供します。平坦化された制御フローや仮想マシンバイトコードを静的に難読化解除するのではなく、libc、JNI、Java 層 API をフックして、硬化された共有オブジェクト内の呼び出し元アドレスとともに、すべての外部副作用を記録します。同梱の JavaScript スクリプトは、root 化済みデバイスまたはエミュレータ上での spawn モード注入向けに設計されており、コンソール出力から環境チェック、改ざん防止ロジック、その他のセキュリティ関連呼び出しチェーンの再構築を可能にします。主な手法には、3 層境界モニタリング、IDA などの逆アセンブラとの呼び出し元アドレス相互参照、検出関数の特定後の引数または戻り値のターゲット改ざんが含まれます。許可されたリバースエンジニアリング、モバイルゲームセキュリティ研究、アンチチート解析、および所有または検査許可のあるアプリに対する CTF 形式のセキュリティテストを目的としています。
