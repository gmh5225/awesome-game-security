An educational guide and hands-on lab for analyzing Virtual Machine Protection on Android native libraries, walking through how VMP replaces native code with custom bytecode and how to reverse that process. The project includes a reproducible mini-VM built in C with a switch-based dispatcher, plus Python tooling to disassemble bytecode and lift it back to readable logic. It covers the full devirtualization workflow—locating dispatchers, enumerating handlers, symbolic lifting, trace-driven analysis, and differential testing—using tools such as QBDI, Unicorn, Triton, Frida, IDA, Ghidra, and angr. The material also surveys real-world protectors (VMProtect, OLLVM forks, Tigress, mobile packers) and companion obfuscations like control-flow flattening, MBA, and anti-debug techniques. It is aimed at authorized security researchers, reverse engineers, and CTF participants studying native anti-tamper and obfuscation on Android and related game-security targets.
