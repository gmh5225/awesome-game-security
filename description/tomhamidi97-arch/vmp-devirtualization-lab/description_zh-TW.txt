這是一份面向 Android 原生函式庫上虛擬機器保護（VMP）分析的教育指南與動手實驗，逐步講解 VMP 如何用自訂位元組碼取代原生程式碼，以及如何逆向該過程。專案包含一個以 C 語言建構、採用基於 switch 的分派器的可重現迷你虛擬機，以及用於反組譯位元組碼並將其提升為可讀邏輯的 Python 工具。內容涵蓋完整的去虛擬化工作流程——定位分派器、列舉處理器、符號提升、以 trace 驅動的分析與差分測試——並使用 QBDI、Unicorn、Triton、Frida、IDA、Ghidra 和 angr 等工具。材料還綜述了真實世界的保護器（VMProtect、OLLVM 分支、Tigress、行動端 packer）以及控制流平坦化、MBA 和反偵錯等配套混淆技術。面向經授權的安全研究人員、逆向工程師以及研究 Android 及相關遊戲安全目標上原生防篡改與混淆的 CTF 參與者。
