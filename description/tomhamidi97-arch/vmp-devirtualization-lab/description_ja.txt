Android ネイティブライブラリにおける Virtual Machine Protection（VMP）の解析を学ぶ教育ガイド兼ハンズオンラボで、VMP がネイティブコードをカスタムバイトコードに置き換える仕組みと、その逆解析方法を順を追って解説します。プロジェクトには、switch ベースのディスパッチャーを備えた C 言語製の再現可能なミニ VM と、バイトコードを逆アセンブルして読みやすいロジックへリフトバックする Python ツールが含まれます。ディスパッチャーの特定、ハンドラの列挙、シンボリックリフティング、トレース駆動解析、差分テストといった去仮想化の一連のワークフローを、QBDI、Unicorn、Triton、Frida、IDA、Ghidra、angr などのツールを用いてカバーします。VMProtect、OLLVM フォーク、Tigress、モバイルパッカーなどの実際のプロテクターと、制御フローフラット化、MBA、反デバッグ手法などの付随難読化についても概観します。Android および関連するゲームセキュリティ対象におけるネイティブ改ざん防止と難読化を学ぶ、許可を得たセキュリティ研究者、リバースエンジニア、CTF 参加者向けです。
