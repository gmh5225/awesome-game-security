Android 네이티브 라이브러리에서 Virtual Machine Protection(VMP)을 분석하는 교육 가이드이자 실습 랩으로, VMP가 네이티브 코드를 사용자 정의 바이트코드로 대체하는 방식과 이를 역추적하는 방법을 단계별로 설명합니다. 프로젝트에는 switch 기반 디스패처로 구현된 C 언어 미니 VM과, 바이트코드를 디스어셈블하여 읽기 쉬운 로직으로 되돌리는 Python 도구가 포함되어 있습니다. 디스패처 탐색, 핸들러 열거, 심볼릭 리프팅, 트레이스 기반 분석, 차분 테스트 등 전체 디가상화 워크플로를 QBDI, Unicorn, Triton, Frida, IDA, Ghidra, angr 같은 도구로 다룹니다. VMProtect, OLLVM 포크, Tigress, 모바일 패커 등 실제 프로텍터와 제어 흐름 평탄화, MBA, 안티 디버그 기법 같은 부수 난독화도 소개합니다. Android 및 관련 게임 보안 대상의 네이티브 안티 탬퍼 및 난독화를 연구하는 승인된 보안 연구자, 리버스 엔지니어, CTF 참가자를 대상으로 합니다.
