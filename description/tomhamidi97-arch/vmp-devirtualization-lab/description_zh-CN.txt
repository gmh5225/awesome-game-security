这是一份面向 Android 原生库上虚拟机保护（VMP）分析的教育指南与动手实验，逐步讲解 VMP 如何用自定义字节码替换原生代码，以及如何逆向该过程。项目包含一个用 C 语言构建、采用基于 switch 的分发器的可复现迷你虚拟机，以及用于反汇编字节码并将其提升为可读逻辑的 Python 工具。内容涵盖完整的去虚拟化工作流——定位分发器、枚举处理器、符号提升、基于 trace 的分析与差分测试——并使用 QBDI、Unicorn、Triton、Frida、IDA、Ghidra 和 angr 等工具。材料还综述了真实世界的保护器（VMProtect、OLLVM 分支、Tigress、移动端 packer）以及控制流平坦化、MBA 和反调试等配套混淆技术。面向经授权的安全研究人员、逆向工程师以及研究 Android 及相关游戏安全目标上原生防篡改与混淆的 CTF 参与者。
