XCX Recomp statically recompiles Xenoblade Chronicles X: Definitive Edition from Nintendo Switch ARM64 binaries into a native Windows x86-64 program with a Vulkan-based renderer, without running a full Switch emulator. A Python lifter and code generator translate NSO modules into C that is never hand-edited, with jumptable handling and version-specific patch tables, and changes are verified using differential tests against the Unicorn CPU emulator. The C and C++ host runtime emulates Nintendo SDK services, maps NVN graphics calls to Vulkan (including Maxwell-oriented behavior documented for debugging), and covers audio, input, filesystem, and configuration via an included setup tool that builds from user-supplied game dumps. The codebase inherits techniques from TotK Recomp, LAS Recomp, and related porting projects at the scale of a large commercial title. It targets reverse engineers and preservation-minded developers studying static binary translation, console module layout, and API re-hosting rather than anti-cheat or live online security work.
