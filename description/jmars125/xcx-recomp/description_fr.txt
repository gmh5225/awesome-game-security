XCX Recomp recompile statiquement Xenoblade Chronicles X: Definitive Edition à partir des binaires ARM64 Nintendo Switch en un programme Windows x86-64 natif avec un moteur de rendu basé sur Vulkan, sans exécuter un émulateur Switch complet. Un lifter Python et un générateur de code traduisent les modules NSO en C jamais édité à la main, avec gestion des tables de saut et tables de correctifs spécifiques aux versions, et les changements sont vérifiés par des tests différentiels contre l’émulateur CPU Unicorn. Le runtime hôte C et C++ émule les services du SDK Nintendo, mappe les appels graphiques NVN vers Vulkan (y compris un comportement orienté Maxwell documenté pour le débogage), et couvre l’audio, l’entrée, le système de fichiers et la configuration via un outil de configuration inclus qui se compile à partir de dumps de jeu fournis par l’utilisateur. La base de code hérite des techniques de TotK Recomp, LAS Recomp et de projets de portage connexes à l’échelle d’un grand titre commercial. Elle s’adresse aux ingénieurs inverse et aux développeurs soucieux de préservation qui étudient la traduction binaire statique, la disposition des modules console et la ré-hébergement d’API, plutôt qu’à la lutte anti-triche ou à la sécurité en ligne en direct.
