AIMr 是一款以 Python 為基礎、由 AI 驅動的外部自瞄程式，運用電腦視覺在螢幕上偵測人形目標，並在渲染此類模型的遊戲中自動瞄準。技術堆疊以 OpenCV、YOLO 風格物件偵測、螢幕擷取（含 bettercam）與 CustomTkinter GUI 為核心，擴充版本可選 DirectML 加速以及 Arduino 或 KMBOX 等硬體輸入路徑。它提供常見作弊功能，包括扳機機器人、後座力控制、靜默自瞄、目標預測、平滑擬人化瞄準以及可設定的 FOV 或偵測疊加層，專案定位圍繞規避偵測。它主要供遊戲安全與反作弊研究人員使用，以研究基於視覺的作弊、輸入注入以及防禦系統必須辨識的行為。
