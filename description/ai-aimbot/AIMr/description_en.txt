AIMr is a Python-based, AI-driven external aimbot that uses computer vision to detect human-shaped targets on screen and automate aiming across games that render such models. The stack centers on OpenCV, YOLO-style object detection, screen capture (including bettercam), and a CustomTkinter GUI, with optional DirectML acceleration and hardware input paths such as Arduino or KMBOX in extended builds. It exposes typical cheat features including triggerbot, recoil control, silent aim, target prediction, smooth humanized aim, and configurable FOV or detection overlays, and the project positions itself around evading detection. It is primarily useful for game security and anti-cheat researchers studying vision-based cheating, input injection, and the behaviors defensive systems must recognize.
