AIMr는 Python 기반 AI 구동 외부 에임봇으로, 컴퓨터 비전으로 화면의 사람 형태 타깃을 감지하고 그러한 모델을 렌더링하는 게임 전반에서 조준을 자동화합니다. 스택은 OpenCV, YOLO 스타일 객체 감지, 화면 캡처(bettercam 포함), CustomTkinter GUI를 중심으로 하며, 확장 빌드에서는 DirectML 가속과 Arduino 또는 KMBOX 같은 하드웨어 입력 경로를 선택할 수 있습니다. 트리거봇, 반동 제어, 사일런트 에임, 타깃 예측, 부드러운 인간형 조준, 설정 가능한 FOV 또는 감지 오버레이 등 일반적인 치트 기능을 제공하며, 프로젝트는 탐지 회피를 전제로 합니다. 게임 보안 및 안티치트 연구자가 비전 기반 치트, 입력 주입, 방어 시스템이 인식해야 할 행위를 연구하는 데 주로 유용합니다.
