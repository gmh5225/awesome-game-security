AIMr は Python ベースの AI 駆動型外部エイムボットで、コンピュータビジョンにより画面上の人型ターゲットを検出し、そのようなモデルを描画するゲーム全体で照準を自動化します。スタックの中心は OpenCV、YOLO 系オブジェクト検出、画面キャプチャ（bettercam を含む）、CustomTkinter GUI で、拡張ビルドでは DirectML 加速や Arduino や KMBOX などのハードウェア入力経路がオプションです。トリガーボット、リコイル制御、サイレントエイム、ターゲット予測、滑らかな人間らしいエイム、設定可能な FOV や検出オーバーレイなど典型的なチート機能を備え、プロジェクトは検知回避を前提に位置づけられています。主にゲームセキュリティおよびアンチチート研究者向けで、ビジョン系チート、入力注入、防御システムが認識すべき挙動の研究に有用です。
