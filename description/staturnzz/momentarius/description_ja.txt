momentarius は、IOMobileFramebuffer GPU ファームウェアを悪用して A12 および A13 Apple Silicon デバイス上の Apple Page Protection Layer (PPL) をバイパスする C ライブラリです。IOSurface を通じて物理メモリをマップし、ARM64 ページテーブルと PTE を操作し、AArch64 シェルコードを GPU ファームウェアに注入し、カーネルレジスタ読み取りをフックして、制御可能なカーネル読み書きプリミティブを獲得します。A12（Vortex/Tempest）および A13（Lightning/Thunder）CPU ファミリー向けに別々の初期化パスを備え、IOMFB のサスペンド/レジュームと GPU バイナリシグネチャに対するパッチファインディングを使用します。iOS カーネルセキュリティ研究者および PPL バイパス手法と Apple プラットフォームの低レベル保護機構を研究するエクスプロイト開発者向けです。
