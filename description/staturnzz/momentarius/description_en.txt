momentarius is a C library that bypasses Apple's Page Protection Layer (PPL) on A12 and A13 Apple Silicon devices by exploiting the IOMobileFramebuffer GPU firmware. It maps physical memory through IOSurface, manipulates ARM64 page tables and PTEs, injects AArch64 shellcode into GPU firmware, and hooks kernel register reads to gain controlled kernel read/write primitives. Separate initialization paths target the A12 (Vortex/Tempest) and A13 (Lightning/Thunder) CPU families, using IOMFB suspend/resume and patchfinding against GPU binary signatures. It is intended for iOS kernel security researchers and exploit developers studying PPL bypass techniques and low-level Apple platform protections.
