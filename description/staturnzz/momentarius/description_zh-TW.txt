momentarius 是一個 C 語言函式庫，透過利用 IOMobileFramebuffer GPU 韌體，在 A12 與 A13 Apple Silicon 裝置上繞過 Apple 的 Page Protection Layer (PPL)。它透過 IOSurface 對應實體記憶體，操作 ARM64 頁表與 PTE，將 AArch64 shellcode 注入 GPU 韌體，並 hook 核心暫存器讀取，以取得可控的核心讀/寫原語。針對 A12（Vortex/Tempest）與 A13（Lightning/Thunder）CPU 系列分別有獨立的初始化路徑，使用 IOMFB 暫停/恢復以及對 GPU 二進位簽名的 patchfinding。此函式庫面向 iOS 核心安全研究人員與漏洞利用開發者，用於研究 PPL 繞過技術及 Apple 平台底層防護機制。
