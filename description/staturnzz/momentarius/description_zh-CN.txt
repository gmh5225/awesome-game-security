momentarius 是一个 C 语言库，通过利用 IOMobileFramebuffer GPU 固件，在 A12 和 A13 Apple Silicon 设备上绕过 Apple 的 Page Protection Layer (PPL)。它通过 IOSurface 映射物理内存，操纵 ARM64 页表和 PTE，将 AArch64 shellcode 注入 GPU 固件，并 hook 内核寄存器读取，从而获得可控的内核读/写原语。针对 A12（Vortex/Tempest）和 A13（Lightning/Thunder）CPU 系列分别有独立的初始化路径，使用 IOMFB 挂起/恢复以及对 GPU 二进制签名的 patchfinding。该库面向 iOS 内核安全研究人员和漏洞利用开发者，用于研究 PPL 绕过技术及 Apple 平台底层防护机制。
