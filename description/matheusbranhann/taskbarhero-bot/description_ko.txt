TaskbarHero Bot은 Unity IL2CPP 게임 TaskbarHero를 위한 Windows 트레이너 및 자동화 봇으로, WPF 대시보드가 포함된 독립형 C#/.NET 10 애플리케이션으로 제공됩니다. 실행 중인 게임 프로세스에 연결하여 배치 메모리 읽기, AOB 스캔, IL2CPP 오프셋 해석을 통해 저장 데이터, 스탯, 인벤토리, 룬, 스테이지 진행 상황을 읽고 수정합니다. 주요 기능으로 ACTk 안티치트 우회, 무적 모드 및 스탯 편집, ObscuredInt 읽기/쓰기, 자동 박스 개봉, 자동 보관, 자동 융합, 충돌 후 자동 재시작 등의 스크립트 자동화가 있습니다. 프로젝트는 Steam 커뮤니티 마켓을 통한 시장 가격 조회(선택적 OCR 오버레이), 빌드 해시 기반 오프셋 캐싱, CLI 하네스에서 테스트 가능한 헤드리스 코어 라이브러리도 제공합니다. Unity IL2CPP 메모리 편집, 클라이언트 측 보호 우회, 외부 트레이너 아키텍처를 연구하는 리버스 엔지니어 및 게임 보안 연구자를 대상으로 합니다.
