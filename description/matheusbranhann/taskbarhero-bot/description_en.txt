TaskbarHero Bot is a Windows trainer and automation bot for the Unity IL2CPP game TaskbarHero, delivered as a self-contained C#/.NET 10 application with a WPF dashboard. It attaches to the running game process and uses batch memory reads, AOB scanning, and IL2CPP offset resolution to read and modify save data, stats, inventory, runes, and stage progression. Key capabilities include ACTk anti-cheat bypass, god mode and stat editing, ObscuredInt read/write, and scripted automations such as auto-boxing, auto-stash, auto-fuse, and auto-restart after crashes. The project also provides market price lookup via the Steam Community Market with optional OCR overlay, build-hash-based offset caching, and a headless core library testable from a CLI harness. It is aimed at reverse engineers and game security researchers studying Unity IL2CPP memory editing, client-side protection bypass, and external trainer architecture.
