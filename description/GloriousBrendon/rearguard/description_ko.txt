Rearguard는 엔진 플러그인과 서버 모듈로 구성된 오픈소스 제로 액세스 안티치트 SDK로, 커널 드라이버 없이 실행되며 Linux와 Windows에서 동일하게 동작합니다. 마우스 감도, 반동 등 게임플레이 신호에 서버가 시드한 비밀 프로브를 심어 두고, 클라이언트가 이러한 숨겨진 단서에 어떻게 반응하는지 관찰하여 에임봇, 반동 매크로 같은 입력 치트를 탐지합니다. 프로젝트는 주로 Rust로 작성되었으며, Godot 4 GDExtension 바인딩과 데모, 서버 측 탐지기, 텔레메트리 파이프라인, 시뮬레이션 하네스, 평가 도구를 포함해 탐지율과 오탐률을 함께 보고합니다. 침습적인 커널 기반 보호 대신 사용자 모드 대안을 원하는 게임 개발자와 안티치트 연구자를 대상으로 하지만, 현재는 입력 치트 탐지 계층에 초점을 맞춘 초기 프로토타입입니다.
