Rearguard is an open-source, zero-access anti-cheat SDK made up of an engine plugin and a server module that runs without kernel drivers and behaves the same on Linux and Windows. It plants secret, server-seeded probes in gameplay signals such as mouse sensitivity and recoil, then detects input cheats like aimbots and recoil macros by watching which clients react to those hidden cues. The project is built primarily in Rust, with a Godot 4 GDExtension binding and demo, plus a server-side detector, telemetry pipeline, simulation harness, and evaluation tooling that reports detection and false-positive rates together. It is aimed at game developers and anti-cheat researchers who want a user-mode alternative to invasive kernel-based protections, though it remains an early prototype focused on the input-cheat detection layer.
