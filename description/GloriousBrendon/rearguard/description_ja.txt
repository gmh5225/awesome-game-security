Rearguard は、エンジンプラグインとサーバーモジュールから成るオープンソースのゼロアクセス型アンチチート SDK で、カーネルドライバーなしで動作し、Linux と Windows で同じ挙動を示します。マウス感度やリコイルなどのゲームプレイ信号に、サーバー側でシードされた秘密のプローブを埋め込み、クライアントがその隠し手がかりにどう反応するかを監視することで、エイムボットやリコイルマクロといった入力系チートを検出します。プロジェクトは主に Rust で構築され、Godot 4 GDExtension バインディングとデモ、サーバー側検出器、テレメトリパイプライン、シミュレーションハーネス、評価ツールを備え、検出率と誤検知率をまとめて報告します。侵入的なカーネルベースの保護に代わるユーザーモードの選択肢を求めるゲーム開発者やアンチチート研究者向けですが、現時点では入力チート検出レイヤーに焦点を当てた初期プロトタイプです。
