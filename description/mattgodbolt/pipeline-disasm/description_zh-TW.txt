本專案是對 1988 年 BBC Micro 益智遊戲 PIPELINE 的完整從原始碼重建反組譯，產出的磁碟與磁通量映像與原版零售發行逐位元組一致。每個二進位檔皆以附註的 6502 組合語言（以 baron 組譯）及重建的 BBC BASIC 取代，並由 Python 與 Node.js 工具支援反組譯、磁碟配置、比對，以及透過 jsbeeb 的無介面模擬。工作記錄了 Superior Software 的拷貝保護，包括存放在未編目磁區且帶已刪資料位址標記的程式、隱藏樁載入器，以及自我解密的隱藏公用程式。符號傾印與執行追蹤支援除錯器標籤，並驗證每一步重組譯與零售光碟保持一致。面向希望研究經典遊戲引擎、任務資料格式，以及 BBC Micro 上復古反盜版機制的保存者與逆向工程師。
