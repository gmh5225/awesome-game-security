本プロジェクトは、1988 年の BBC Micro 向けパズルゲーム PIPELINE をソースから完全に再構築した逆アセンブリで、生成するディスクおよびフルックスイメージは当初の小売版とバイト単位で一致する。各バイナリは注釈付き 6502 アセンブリ（baron でアセンブル）と再構築した BBC BASIC に置き換えられ、逆アセンブリ、ディスクレイアウト、比較、jsbeeb によるヘッドレスエミュレーションを担う Python および Node.js ツール群が支える。Superior Software のコピー保護（未カタログ化セクターに格納され削除済みデータアドレスマークを持つプログラム、隠しスタブローダ、自己復号する隠しユーティリティなど）を文書化している。シンボルダンプと実行トレースはデバッガラベルと、再アセンブリの各段階が小売ディスクと同一であることの検証を支援する。BBC Micro 上のクラシックゲームエンジン、ミッションデータ形式、レトロな海賊版対策の研究を望む保存活動者とリバースエンジニア向けである。
