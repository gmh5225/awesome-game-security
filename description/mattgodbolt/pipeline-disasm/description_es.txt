Este proyecto es una desensamblación completa reconstruida desde el código fuente de PIPELINE, el juego de puzzles para BBC Micro de 1988, que produce imágenes de disco y de flujo idénticas byte a byte al lanzamiento comercial original. Sustituye cada binario por ensamblador 6502 anotado (ensamblado con baron) y BBC BASIC reconstruido, respaldado por herramientas en Python y Node.js para desensamblado, disposición del disco, comparación y emulación sin interfaz mediante jsbeeb. El trabajo documenta la protección anticopia de Superior Software, incluidos programas almacenados en sectores no catalogados con marcas de dirección de datos borradas, cargadores stub ocultos y una utilidad oculta autodescifrante. Volcados de símbolos y trazas de ejecución apoyan etiquetas del depurador y verifican que cada paso de reensamblado coincida con el disco de venta. Está pensado para preservacionistas e ingenieros inversos que quieran estudiar motores de juegos clásicos, formatos de datos de misiones y mecánicas retro antipiratería en el BBC Micro.
