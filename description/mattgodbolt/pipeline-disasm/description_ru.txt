Этот проект — полная пересборка из исходников на основе дизасsemblирования игры-головоломки PIPELINE (1988) для BBC Micro; получающиеся образы диска и потока совпадают с оригинальным розничным изданием побайтно. Каждый бинарный файл заменён аннотированным ассемблером 6502 (сборка baron) и восстановленным BBC BASIC, с поддержкой инструментов на Python и Node.js для дизасsemblирования, разметки диска, сравнения и эмуляции без интерфейса через jsbeeb. Работа документирует защиту от копирования Superior Software, включая программы в некаталогизированных секторах с метками удалённых адресов данных, скрытые stub-загрузчики и скрытую саморасшифровывающуюся утилиту. Дампы символов и трассировки выполнения поддерживают метки отладчика и проверку, что каждый шаг пересборки совпадает с розничным диском. Проект для специалистов по сохранению ПО и инженеров по обратной разработке, изучающих классические игровые движки, форматы данных миссий и ретро-механизмы антипиратства на BBC Micro.
