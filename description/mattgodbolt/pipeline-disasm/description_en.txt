This project is a full rebuild-from-source disassembly of PIPELINE, the 1988 BBC Micro puzzle game, producing disc and flux images that match the original release byte for byte. It replaces each binary with annotated 6502 assembly (assembled with baron) and reconstructed BBC BASIC, backed by Python and Node.js tools for disassembly, disc layout, comparison, and headless emulation via jsbeeb. The work documents Superior Software’s copy protection, including programs stored in uncatalogued sectors with deleted data address marks, hidden stub loaders, and a self-decrypting hidden utility. Symbol dumps and execution traces support debugger labels and verification that every reassembly step stays identical to the retail disc. It serves preservationists and reverse engineers who want to study classic game engines, mission data formats, and retro anti-piracy mechanics on the BBC Micro.
