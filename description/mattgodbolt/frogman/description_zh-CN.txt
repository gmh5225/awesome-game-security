FROGMAN 是一项保护与逆向工程工作，将 1993 年 BBC Micro 上的翻屏平台游戏重建为带完整注释、字节级精确的 6502 汇编，并可重新汇编为可启动的磁盘映像。该项目记录了原版如何通过基于 VIA 定时器计时的多阶段 XOR 加载器发布，在从模拟器捕获解密代码之前会阻碍静态分析。源码以 BeebASM 组织，并配有 BBC BASIC 启动加载器、校验脚本，以及用于内存转储、反汇编和基于 Tiled 的关卡编辑的 Python 工具。方法包括 radare2 反汇编、运行时内存提取，以及系统化二进制比对以匹配原版引擎与游戏代码。面向复古计算爱好者、逆向工程师，以及研究经典拷贝保护、体积受限游戏引擎与 8 位平台底层设计的人。
