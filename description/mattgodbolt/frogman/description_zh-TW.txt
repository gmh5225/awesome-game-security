FROGMAN 是一項保存與逆向工程工作，將 1993 年 BBC Micro 上的翻屏平台遊戲重建為附完整註解、位元組級精確的 6502 組合語言，並可重新組譯成可開機的磁碟映像。此專案記錄原版如何透過以 VIA 計時器計時為依據的多階段 XOR 載入器發行，在從模擬器擷取解密程式碼之前會阻礙靜態分析。原始碼以 BeebASM 組織，並配有 BBC BASIC 開機載入器、驗證腳本，以及用於記憶體傾印、反組譯與以 Tiled 為基礎的關卡編輯的 Python 工具。手法包括 radare2 反組譯、執行期記憶體擷取，以及系統化二進位比對以符合原版引擎與遊戲程式碼。適合復古運算愛好者、逆向工程師，以及研究經典拷貝保護、容量受限遊戲引擎與 8 位元平台底層設計的人。
