FROGMAN은 1993년 BBC Micro용 플립 스크린 플랫폼 게임을 완전히 주석이 달린 바이트 단위로 정확한 6502 어셈블리로 재구성해 다시 조립하면 부팅 가능한 디스크 이미지로 만들 수 있게 하는 보존 및 리버스 엔지니어링 프로젝트이다. 원본이 VIA 타이머 타이밍에 연동된 다단계 XOR 로더와 함께 배포되어, 에뮬레이터에서 복호화된 코드를 확보하기 전까지는 정적 분석을 막는 방식을 문서화한다. 소스는 BeebASM으로 정리되어 있으며 BBC BASIC 부트 로더, 검증 스크립트, 메모리 덤프·디스어셈블리·Tiled 기반 레벨 편집용 Python 유틸리티를 포함한다. radare2 디스어셈블리, 런타임 메모리 추출, 원본 엔진 및 게임 코드와 맞추기 위한 체계적 바이너리 비교 등의 기법을 사용한다. 레트로 컴퓨팅 애호가, 리버스 엔지니어, 고전 복사 보호·용량 제약 게임 엔진·8비트 플랫폼 저수준 설계를 공부하는 이들에게 유용하다.
