FROGMAN is a preservation and reverse-engineering effort that rebuilds a 1993 BBC Micro flip-screen platformer as fully annotated, byte-exact 6502 assembly that can be reassembled into a bootable disc image. The work documents how the original shipped with a multi-stage XOR loader keyed off VIA timer timing, which blocks static analysis until decrypted code is captured from an emulator. Sources are organized in BeebASM with supporting BBC BASIC boot loaders, verification scripts, and Python utilities for memory dumping, disassembly, and Tiled-based level editing. Techniques include radare2 disassembly, runtime memory extraction, and systematic binary comparison to match the original engine and game code. It serves retro-computing enthusiasts, reverse engineers, and anyone studying classic copy protection, size-constrained game engines, and low-level 8-bit platform design.
