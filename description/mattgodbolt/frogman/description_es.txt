FROGMAN es un esfuerzo de preservación e ingeniería inversa que reconstruye un juego de plataformas de pantalla volteada de 1993 para BBC Micro como ensamblador 6502 totalmente anotado y exacto byte a byte, que puede reensamblarse en una imagen de disco arrancable. El trabajo documenta cómo el original se distribuía con un cargador XOR de varias etapas ligado al temporizador VIA, lo que impide el análisis estático hasta capturar el código descifrado desde un emulador. Las fuentes están organizadas en BeebASM con cargadores de arranque BBC BASIC, scripts de verificación y utilidades Python para volcado de memoria, desensamblado y edición de niveles basada en Tiled. Las técnicas incluyen desensamblado con radare2, extracción de memoria en tiempo de ejecución y comparación binaria sistemática para igualar el motor y el código del juego originales. Está pensado para entusiastas del retrocomputing, ingenieros inversos y quien estudie protección clásica contra copias, motores de juego con límites de tamaño y diseño de plataformas de 8 bits a bajo nivel.
