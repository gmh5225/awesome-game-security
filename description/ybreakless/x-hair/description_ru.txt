X-Hair — кроссплатформенное настольное приложение, которое рисует прозрачный, пропускающий клики прицельный оверлей в центре экрана для FPS-игр. Реализовано на Rust как модульное Cargo-пространство с нативными оверлеями ОС под Windows, X11 и Wayland, пассивным вводом через Windows Raw Input и Linux evdev и студией по запросу на базе egui для создания и управления прицелами. В инструменте много встроенных тактических пресетов, профили по играм и слотам оружия с поведением ADS и стрельбы, переносимые коды для обмена, проверка JSON Schema, экспорт PNG и SVG и каталог сообщества с синхронизацией через GitHub, без чтения памяти игры, инъекции кода и перехвата графических API. Ориентировано на соревновательных шутеров и тех, кто изучает прицельные подсказки на основе оверлеев, и предлагает лёгкую альтернативу, спроектированную так, чтобы обходить типичные поверхности обнаружения античита.
