X-Hair è un’applicazione desktop multipiattaforma che disegna un overlay a mirino trasparente e attraversabile dal clic al centro dello schermo per giochi FPS. È implementata in Rust come workspace Cargo modulare, con overlay nativi del sistema su Windows, X11 e Wayland, input passivo tramite Windows Raw Input e Linux evdev, e uno studio on demand basato su egui per progettare e gestire i reticoli. Lo strumento include molti preset tattici integrati, profili per gioco e slot arma con comportamento ADS e fuoco, codici condivisibili portatili, validazione JSON Schema, esportazione PNG e SVG, e un catalogo community sincronizzato via GitHub, senza leggere la memoria di gioco, iniettare codice o agganciare le API grafiche. È rivolto a tiratori competitivi e a chi studia ausili alla mira basati su overlay, offrendo un’alternativa leggera progettata per evitare le comuni superfici di rilevamento anti-cheat.
