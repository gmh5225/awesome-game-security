X-Hair は、FPS 向けに画面中央へ透明でクリック透過のクロスヘアオーバーレイを描画するクロスプラットフォームのデスクトップアプリです。Rust で実装され、モジュラーな Cargo ワークスペースとして構成され、Windows・X11・Wayland では OS ネイティブのオーバーレイ、Windows Raw Input と Linux evdev によるパッシブ入力、需要に応じた egui ベースのスタジオでレティクルの設計・管理が可能です。多数の組み込み戦術プリセット、ゲーム別武器スロットプロファイル（ADS・発射挙動）、ポータブル共有コード、JSON Schema 検証、PNG・SVG エクスポート、GitHub 同期のコミュニティカタログを備え、ゲームメモリの読取り、コード注入、グラフィックス API のフックは行いません。競技系シューティングやオーバーレイベースの照準補助を研究する人向けに、軽量な代替手段を提供し、一般的なアンチチート検知面を避けるよう設計されています。
