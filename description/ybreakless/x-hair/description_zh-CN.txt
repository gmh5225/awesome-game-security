X-Hair 是一款跨平台桌面应用，在屏幕中央绘制透明、可穿透点击的准星叠加层，用于 FPS 游戏。它以 Rust 实现，采用模块化 Cargo 工作区，在 Windows、X11 与 Wayland 上使用各系统原生叠加层，通过 Windows Raw Input 与 Linux evdev 进行被动输入，并提供基于 egui 的按需工作室以设计与管理准星样式。工具内置大量战术预设、按游戏与武器槽位的配置（含开镜与开火行为）、可分享的便携代码、JSON Schema 校验、PNG 与 SVG 导出，以及经 GitHub 同步的社区目录，且不读取游戏内存、不注入代码、不挂钩图形 API。面向竞技射击玩家及研究基于叠加层瞄准辅助的用户，提供轻量替代方案，并在工程上尽量避免常见反作弊检测面。
