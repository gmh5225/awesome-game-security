X-Hair 是一款跨平台桌面應用程式，在螢幕中央繪製透明、可穿透點擊的準星疊加層，供 FPS 遊戲使用。它以 Rust 實作，採用模組化 Cargo 工作區，在 Windows、X11 與 Wayland 上使用各系統原生疊加層，透過 Windows Raw Input 與 Linux evdev 進行被動輸入，並提供以 egui 為基礎的按需工作室以設計與管理準星樣式。工具內建大量戰術預設、依遊戲與武器槽位的設定檔（含開鏡與開火行為）、可分享的便攜代碼、JSON Schema 驗證、PNG 與 SVG 匯出，以及經 GitHub 同步的社群目錄，且不讀取遊戲記憶體、不注入程式碼、不掛鉤圖形 API。面向競技射擊玩家及研究以疊加層為基礎的瞄準輔助者，提供輕量替代方案，並在工程上盡量避免常見反作弊偵測面。
