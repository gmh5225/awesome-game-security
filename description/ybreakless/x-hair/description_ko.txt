X-Hair은 FPS 게임을 위해 화면 중앙에 투명하고 클릭이 통과되는 십자선 오버레이를 그리는 크로스 플랫폼 데스크톱 애플리케이션입니다. Rust로 구현되었으며 모듈형 Cargo 워크스페이스로 구성되고, Windows·X11·Wayland에서는 OS 네이티브 오버레이, Windows Raw Input과 Linux evdev를 통한 수동 입력, 필요 시 egui 기반 스튜디오로 조준선 설계·관리를 지원합니다. 다수의 내장 전술 프리셋, 게임별 무기 슬롯 프로필(ADS·발사 동작), 휴대용 공유 코드, JSON Schema 검증, PNG·SVG 내보내기, GitHub 동기화 커뮤니티 카탈로그를 제공하며 게임 메모리 읽기, 코드 주입, 그래픽 API 후킹은 하지 않습니다. 경쟁 슈팅 게이머와 오버레이 기반 조준 보조를 연구하는 이들을 대상으로 하며, 흔한 안티치트 탐지 표면을 피하도록 설계된 경량 대안입니다.
