X-Hair is a cross-platform desktop application that draws a transparent, click-through crosshair overlay at the center of the screen for FPS games. It is implemented in Rust as a modular Cargo workspace with OS-native overlays on Windows, X11, and Wayland, passive input via Windows Raw Input and Linux evdev, and an on-demand egui-based studio for designing and managing reticles. The tool ships with many built-in tactical presets, per-game weapon-slot profiles with ADS and fire behavior, portable share codes, JSON Schema validation, PNG and SVG export, and a GitHub-synced community catalog without reading game memory, injecting code, or hooking graphics APIs. It targets competitive shooters and anyone studying overlay-based aiming aids who need a lightweight alternative that is engineered to avoid common anti-cheat detection surfaces.
