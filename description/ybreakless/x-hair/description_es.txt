X-Hair es una aplicación de escritorio multiplataforma que dibuja una superposición de cruz transparente y permeable al clic en el centro de la pantalla para juegos FPS. Está implementada en Rust como un espacio de trabajo Cargo modular, con superposiciones nativas del SO en Windows, X11 y Wayland, entrada pasiva mediante Windows Raw Input y Linux evdev, y un estudio bajo demanda basado en egui para diseñar y gestionar retículas. La herramienta incluye muchos ajustes tácticos integrados, perfiles por juego y ranura de arma con comportamiento de ADS y disparo, códigos portátiles para compartir, validación JSON Schema, exportación PNG y SVG, y un catálogo comunitario sincronizado con GitHub, sin leer memoria del juego, inyectar código ni enganchar APIs gráficas. Está dirigida a tiradores competitivos y a quienes estudian ayudas de puntería basadas en superposición, ofreciendo una alternativa ligera diseñada para evitar superficies habituales de detección anti-trampas.
