X-Hair ist eine plattformübergreifende Desktop-Anwendung, die für FPS-Spiele ein transparentes, klickdurchlässiges Fadenkreuz-Overlay in der Bildschirmmitte zeichnet. Sie ist in Rust als modulares Cargo-Workspace umgesetzt, mit nativen OS-Overlays unter Windows, X11 und Wayland, passivem Input über Windows Raw Input und Linux evdev sowie einem bedarfsbasierten egui-Studio zum Entwerfen und Verwalten von Visieren. Das Tool bringt viele eingebaute taktische Voreinstellungen, pro-Spiel-Waffenslot-Profile mit ADS- und Feuerverhalten, portable Share-Codes, JSON-Schema-Validierung, PNG- und SVG-Export sowie einen per GitHub synchronisierten Community-Katalog mit, ohne Spielspeicher zu lesen, Code zu injizieren oder Grafik-APIs zu hooken. Es richtet sich an Wettkampf-Shooter und alle, die overlaybasierte Zielhilfen untersuchen, und bietet eine leichte Alternative, die darauf ausgelegt ist, gängige Anti-Cheat-Erkennungsflächen zu vermeiden.
