이 프로젝트는 시리얼 번호를 읽거나 타이머에 의존하지 않고 CUDA 작업의 수치 결과만으로 물리적으로 동일한 NVIDIA GPU를 구분하기 위한 연구용 코드베이스입니다. 하드웨어가 결정하는 원자적 경합 순서로 칩 지문을 만드는 능동 CuPy 프로브, 일반 연산 출력에서 동일한 식별 정보를 유출할 수 있는 수동 PyTorch index_add 채널, 분리·위조·재부팅 안정성·방어 실험을 재현하는 CPU 측 Python 분석 스크립트와 번들 측정 데이터를 제공합니다. 구현은 주로 Python이며 CuPy를 통한 CUDA 커널과 선택적 PyTorch 프로브, 호스트 간 지문 수집을 위한 Docker 및 원격 SSH 헬퍼를 포함합니다. GPU 인스턴스 바인딩, 클라우드 테넌트 식별, 공유 GPU 플릿의 사이드 채널, 결정론적 PyTorch 모드 대 커스텀 커널 차단 같은 완화책을 연구하는 보안 및 안티치트 연구자를 대상으로 합니다.
