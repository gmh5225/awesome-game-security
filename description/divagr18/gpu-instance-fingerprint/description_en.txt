This project is a research codebase for telling apart physically identical NVIDIA GPUs using only the numerical results of CUDA work, without reading serial numbers or relying on timers. It ships an active CuPy probe that fingerprints chips from hardware-decided atomic contention order, a passive PyTorch index_add channel that can leak the same identity from ordinary op output, and CPU-side Python analysis scripts with bundled measurement data to reproduce separation, forgery, reboot stability, and defense experiments. Implementation is primarily Python with CUDA kernels via CuPy and optional PyTorch probes, plus Docker and remote SSH helpers for collecting fingerprints across hosts. It targets security and anti-cheat researchers who need to study GPU instance binding, cloud-tenant identification, side channels in shared GPU fleets, and mitigations such as deterministic PyTorch modes versus blocking custom kernels.
