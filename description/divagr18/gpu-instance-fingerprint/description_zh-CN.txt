本项目是一个研究代码库，旨在仅通过 CUDA 运算的数值结果区分物理上相同的 NVIDIA GPU，无需读取序列号或依赖计时器。它提供主动 CuPy 探针，从硬件决定的原子争用顺序提取芯片指纹；被动 PyTorch index_add 通道可从常规算子输出泄露相同身份；并附带 CPU 端 Python 分析脚本与捆绑测量数据，用于复现分离、伪造、重启稳定性及防御实验。实现以 Python 为主，通过 CuPy 调用 CUDA 内核，可选 PyTorch 探针，另有 Docker 与远程 SSH 辅助工具，便于跨主机采集指纹。面向需要研究 GPU 实例绑定、云租户识别、共享 GPU 集群侧信道及缓解措施（如确定性 PyTorch 模式与阻塞自定义内核）的安全与反作弊研究人员。
