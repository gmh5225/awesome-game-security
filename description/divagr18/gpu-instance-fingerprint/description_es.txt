Este proyecto es una base de código de investigación para distinguir GPU NVIDIA físicamente idénticas usando solo los resultados numéricos del trabajo CUDA, sin leer números de serie ni depender de temporizadores. Incluye una sonda CuPy activa que obtiene huellas de los chips a partir del orden de contención atómica decidido por el hardware, un canal pasivo PyTorch index_add que puede filtrar la misma identidad desde la salida de operaciones ordinarias, y scripts de análisis Python en CPU con datos de medición incluidos para reproducir experimentos de separación, falsificación, estabilidad tras reinicio y defensa. La implementación es principalmente Python con kernels CUDA vía CuPy y sondas PyTorch opcionales, más ayudas Docker y SSH remotas para recopilar huellas entre hosts. Está dirigido a investigadores de seguridad y anti-cheat que necesitan estudiar vinculación de instancias GPU, identificación de inquilinos en la nube, canales laterales en flotas GPU compartidas y mitigaciones como modos PyTorch deterministas frente al bloqueo de kernels personalizados.
