Этот проект — исследовательская кодовая база для различения физически идентичных GPU NVIDIA только по числовым результатам работы CUDA, без чтения серийных номеров и без опоры на таймеры. В неё входит активный зонд CuPy, формирующий отпечаток чипов по порядку атомарных конфликтов, определяемому аппаратурой, пассивный канал PyTorch index_add, способный утечь той же идентичностью из обычного вывода операций, а также Python-скрипты анализа на CPU с включёнными данными измерений для воспроизведения экспериментов по разделению, подделке, стабильности после перезагрузки и защите. Реализация в основном на Python с CUDA-ядрами через CuPy и опциональными зондами PyTorch, плюс Docker и удалённые SSH-утилиты для сбора отпечатков на разных хостах. Ориентирован на исследователей безопасности и античита, изучающих привязку экземпляров GPU, идентификацию облачных арендаторов, побочные каналы в общих GPU-кластерах и меры смягчения, такие как детерминированные режимы PyTorch против блокировки пользовательских ядер.
