本專案是一個研究程式碼庫，旨在僅透過 CUDA 運算的數值結果區分實體上相同的 NVIDIA GPU，無需讀取序號或依賴計時器。它提供主動 CuPy 探針，從硬體決定的原子爭用順序提取晶片指紋；被動 PyTorch index_add 通道可從一般算子輸出洩漏相同身分；並附帶 CPU 端 Python 分析腳本與捆綁測量資料，用於重現分離、偽造、重開機穩定性及防禦實驗。實作以 Python 為主，透過 CuPy 呼叫 CUDA 核心，可選 PyTorch 探針，另有 Docker 與遠端 SSH 輔助工具，便於跨主機採集指紋。面向需要研究 GPU 執行個體綁定、雲端租戶識別、共享 GPU 叢集側信道及緩解措施（如確定性 PyTorch 模式與阻塞自訂核心）的安全與反作弊研究人員。
