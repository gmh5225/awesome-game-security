本プロジェクトは、シリアル番号の読み取りやタイマーに頼らず、CUDA 演算の数値結果だけで物理的に同一の NVIDIA GPU を識別するための研究用コードベースです。ハードウェアが決めるアトミック競合順序からチップを指紋化する能動的 CuPy プローブ、通常の演算出力から同じ同一性を漏らし得る受動的 PyTorch index_add チャネル、分離・偽造・再起動安定性・防御実験を再現する CPU 側 Python 解析スクリプトと同梱計測データを提供します。実装は主に Python で、CuPy 経由の CUDA カーネルと任意の PyTorch プローブに加え、ホスト間で指紋を収集する Docker およびリモート SSH ヘルパーを含みます。GPU インスタンスバインディング、クラウドテナント識別、共有 GPU フリートにおけるサイドチャネル、決定論的 PyTorch モードとカスタムカーネルブロックなどの緩和策を調査するセキュリティおよびアンチチート研究者向けです。
