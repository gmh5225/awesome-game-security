Ce projet est une base de code de recherche pour distinguer des GPU NVIDIA physiquement identiques en s’appuyant uniquement sur les résultats numériques de travail CUDA, sans lire les numéros de série ni s’appuyer sur des minuteries. Il fournit une sonde CuPy active qui fingerprinte les puces à partir de l’ordre de contention atomique décidé par le matériel, un canal passif PyTorch index_add capable de fuiter la même identité depuis la sortie d’opérations ordinaires, ainsi que des scripts d’analyse Python côté CPU avec des données de mesure fournies pour reproduire séparation, falsification, stabilité après redémarrage et expériences de défense. L’implémentation est principalement en Python avec des noyaux CUDA via CuPy et des sondes PyTorch optionnelles, plus des helpers Docker et SSH distants pour collecter des empreintes entre hôtes. Il s’adresse aux chercheurs en sécurité et anti-triche qui étudient la liaison d’instances GPU, l’identification de locataires cloud, les canaux auxiliaires dans des flottes GPU partagées et des atténuations comme les modes PyTorch déterministes face au blocage de noyaux personnalisés.
