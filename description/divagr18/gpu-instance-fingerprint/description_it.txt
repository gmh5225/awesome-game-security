Questo progetto è una codebase di ricerca per distinguere GPU NVIDIA fisicamente identiche usando solo i risultati numerici del lavoro CUDA, senza leggere numeri di serie né affidarsi ai timer. Include una sonda CuPy attiva che imprime l’impronta dei chip dall’ordine di contesa atomica deciso dall’hardware, un canale passivo PyTorch index_add che può far trapelare la stessa identità dall’output di operazioni ordinarie, e script di analisi Python lato CPU con dati di misura inclusi per riprodurre separazione, falsificazione, stabilità al riavvio ed esperimenti di difesa. L’implementazione è principalmente Python con kernel CUDA via CuPy e sonde PyTorch opzionali, più helper Docker e SSH remoti per raccogliere impronte tra host. È rivolto a ricercatori di sicurezza e anti-cheat che devono studiare il binding di istanze GPU, l’identificazione dei tenant cloud, canali laterali in flotte GPU condivise e mitigazioni come modalità PyTorch deterministiche rispetto al blocco di kernel personalizzati.
