Zero es un banco de trabajo de memoria para Windows moderno y ligero que reimplementa un flujo al estilo Cheat Engine — escanear, localizar, vigilar, modificar — en una única aplicación de escritorio sin conexión. Está construido con Rust y egui y se distribuye como ejecutable portable con escaneo de valores y AOB, cadenas de punteros, desensamblado x86-64 integrado, parches de código reversibles, control de velocidad, scripting Lua e importación o exportación de tablas CT de Cheat Engine. Una canalización de triaje y observación en el dispositivo clasifica candidatos con puntuación explicable y aprendizaje por retroalimentación opcional, y puede exponer el motor a asistentes de IA locales mediante un servidor HTTP MCP en localhost. Está dirigido a ingenieros inversos, analistas de memoria de juegos e investigadores de seguridad que necesitan control local completo sin nube ni telemetría al trabajar con procesos Windows x64.
