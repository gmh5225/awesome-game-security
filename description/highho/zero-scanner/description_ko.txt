Zero는 Cheat Engine 스타일의 스캔·위치 지정·감시·수정 워크플로를 단일 오프라인 데스크톱 애플리케이션에 다시 구현한 현대적이고 가벼운 Windows 메모리 워크벤치입니다. Rust와 egui로 만들어졌으며 휴대용 실행 파일로 배포되며, 값 및 AOB 스캔, 포인터 체인, 내장 x86-64 디스어셈블리, 가역 코드 패치, 속도 제어, Lua 스크립팅, Cheat Engine CT 테이블 가져오기 및 내보내기를 지원합니다. 장치 내 트리아지 및 관찰 파이프라인이 설명 가능한 점수와 선택적 피드백 학습으로 후보를 순위화하며, localhost의 MCP HTTP 서버를 통해 로컬 AI 어시스턴트에 엔진을 노출할 수 있습니다. Windows x64 프로세스 작업 시 클라우드나 원격 측정 없이 완전한 로컬 제어가 필요한 리버스 엔지니어, 게임 메모리 분석가, 보안 연구자를 대상으로 합니다.
