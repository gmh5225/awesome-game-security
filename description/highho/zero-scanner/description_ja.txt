Zero は、Cheat Engine スタイルのスキャン・特定・監視・変更ワークフローを単一のオフライン向けデスクトップアプリに再実装した、モダンで軽量な Windows メモリワークベンチです。Rust と egui で構築され、ポータブル実行ファイルとして配布され、値スキャンと AOB スキャン、ポインタチェーン、内蔵 x86-64 逆アセンブラ、可逆コードパッチ、速度制御、Lua スクリプト、Cheat Engine CT テーブルのインポート／エクスポートを備えます。デバイス上のトリアージと観察パイプラインが、説明可能なスコアリングとオプションのフィードバック学習で候補を順位付けし、localhost 上の MCP HTTP サーバー経由でローカル AI アシスタントにエンジンを公開できます。Windows x64 プロセスを扱う際にクラウドやテレメトリなしで完全なローカル制御が必要なリバースエンジニア、ゲームメモリ解析者、セキュリティ研究者を対象としています。
