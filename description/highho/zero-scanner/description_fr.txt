Zero est un banc de travail mémoire Windows moderne et léger qui réimplémente un flux de type Cheat Engine — analyser, localiser, surveiller, modifier — dans une seule application de bureau hors ligne. Construit avec Rust et egui, il se livre comme exécutable portable avec analyse de valeurs et AOB, chaînes de pointeurs, désassemblage x86-64 intégré, correctifs de code réversibles, contrôle de vitesse, scripts Lua et import ou export de tables CT Cheat Engine. Un pipeline de tri et d’observation sur l’appareil classe les candidats grâce à un scoring explicable et un apprentissage par retour optionnel, et peut exposer le moteur aux assistants IA locaux via un serveur HTTP MCP sur localhost. Il s’adresse aux ingénieurs en rétro-ingénierie, analystes de mémoire de jeux et chercheurs en sécurité qui ont besoin d’un contrôle local complet sans cloud ni télémétrie pour les processus Windows x64.
