Zero è un workbench di memoria per Windows moderno e leggero che reimplementa un flusso in stile Cheat Engine — scansione, individuazione, monitoraggio, modifica — in un’unica applicazione desktop offline. Realizzato con Rust ed egui, si distribuisce come eseguibile portatile con scansione di valori e AOB, catene di puntatori, disassemblaggio x86-64 integrato, patch di codice reversibili, controllo della velocità, scripting Lua e importazione o esportazione di tabelle CT di Cheat Engine. Una pipeline di triage e osservazione sul dispositivo classifica i candidati con punteggio spiegabile e apprendimento da feedback opzionale, e può esporre il motore ad assistenti IA locali tramite un server HTTP MCP su localhost. È rivolto a reverse engineer, analisti di memoria di giochi e ricercatori di sicurezza che necessitano di pieno controllo locale senza cloud o telemetria sui processi Windows x64.
