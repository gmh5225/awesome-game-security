Zero 是一款现代、轻量的 Windows 内存工作台，在单一离线桌面应用中重新实现了类似 Cheat Engine 的扫描—定位—监视—修改工作流。它使用 Rust 与 egui 构建，以便携可执行文件形式发布，支持数值与 AOB 扫描、指针链、内置 x86-64 反汇编、可逆代码补丁、速度控制、Lua 脚本以及 Cheat Engine CT 表的导入与导出。设备端的分诊与观察流水线通过可解释的评分与可选的反馈学习对候选结果排序，并可通过 localhost 上的 MCP HTTP 服务器向本地 AI 助手暴露引擎能力。面向需要在工作于 Windows x64 进程时完全本地掌控、且不依赖云端或遥测的逆向工程师、游戏内存分析师与安全研究人员。
