Zero is a modern, lightweight Windows memory workbench that reimplements a Cheat Engine–style scan–locate–watch–modify workflow in a single offline desktop application. It is built with Rust and egui and ships as a portable executable with value and AOB scanning, pointer chains, built-in x86-64 disassembly, reversible code patches, speed control, Lua scripting, and import or export of Cheat Engine CT tables. An on-device triage and observation pipeline ranks candidates with explainable scoring and optional feedback learning, and it can expose the engine to local AI assistants via an MCP HTTP server on localhost. It targets reverse engineers, game memory analysts, and security researchers who need full local control without cloud or telemetry when working on Windows x64 processes.
