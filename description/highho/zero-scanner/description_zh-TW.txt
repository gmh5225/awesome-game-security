Zero 是一款現代、輕量的 Windows 記憶體工作台，在單一離線桌面應用程式中重新實作了類似 Cheat Engine 的掃描—定位—監視—修改工作流程。它以 Rust 與 egui 建構，以可攜式執行檔形式發佈，支援數值與 AOB 掃描、指標鏈、內建 x86-64 反組譯、可逆程式碼修補、速度控制、Lua 腳本以及 Cheat Engine CT 表的匯入與匯出。裝置端的分診與觀察管線透過可解釋的評分與可選的迴饋學習對候選結果排序，並可透過 localhost 上的 MCP HTTP 伺服器向本機 AI 助理公開引擎能力。面向需要在處理 Windows x64 程序時完全本機掌控、且不依賴雲端或遙測的逆向工程師、遊戲記憶體分析師與安全研究人員。
