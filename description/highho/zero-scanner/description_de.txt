Zero ist eine moderne, leichtgewichtige Windows-Speicher-Workbench, die einen Cheat-Engine-ähnlichen Scan–Finden–Beobachten–Ändern-Workflow in einer einzigen Offline-Desktopanwendung neu implementiert. Mit Rust und egui gebaut, wird es als portables Programm mit Wert- und AOB-Scan, Pointer-Ketten, integriertem x86-64-Disassembler, reversiblen Code-Patches, Geschwindigkeitskontrolle, Lua-Skripten sowie Import und Export von Cheat-Engine-CT-Tabellen ausgeliefert. Eine geräteinterne Triage- und Beobachtungspipeline ordnet Kandidaten mit erklärbarem Scoring und optionalem Feedback-Lernen ein und kann die Engine lokalen KI-Assistenten über einen MCP-HTTP-Server auf localhost bereitstellen. Es richtet sich an Reverse Engineers, Spiele-Speicheranalysten und Sicherheitsforscher, die bei Windows-x64-Prozessen volle lokale Kontrolle ohne Cloud oder Telemetrie benötigen.
