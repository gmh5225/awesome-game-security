Zero — современная лёгкая рабочая среда для памяти Windows, которая заново реализует рабочий процесс в духе Cheat Engine — сканирование, поиск, наблюдение, изменение — в одном автономном настольном приложении. Создана на Rust и egui, поставляется как портативный исполняемый файл со сканированием значений и AOB, цепочками указателей, встроенным дизассемблером x86-64, обратимыми патчами кода, управлением скоростью, скриптами Lua и импортом или экспортом таблиц CT Cheat Engine. Конвейер триажа и наблюдения на устройстве ранжирует кандидатов с объяснимой оценкой и необязательным обучением с обратной связью и может открывать движок локальным ИИ-ассистентам через HTTP-сервер MCP на localhost. Ориентирована на специалистов по реверс-инжинирингу, аналитиков игровой памяти и исследователей безопасности, которым нужен полный локальный контроль без облака и телеметрии при работе с процессами Windows x64.
