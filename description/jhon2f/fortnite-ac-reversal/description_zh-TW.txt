本專案是針對《要塞英雄》完整反作弊體系的結構化逆向工程知識庫，以傳統版與 EOS 版 Easy Anti-Cheat（EAC）為核心，並涵蓋 Epic 在 UE5 端的完整性與伺服器驗證。文件記載核心與使用者模式元件、管道協定、規則二進位檔、HWID 與裝置指紋介面、信任評分、遙測，以及 ETW-TI 等相關 Windows 核心風險，並包含現行版本驅動程式的位元組級偏移說明。儲存庫主要以 Markdown 技術參考資料撰寫，並附上一個用於離線或私服式情境、模擬最小 EAC 整合的小型 C 概念驗證樁 DLL，以及對真實模擬器架構的分析。對象為需要《要塞英雄》與 EAC 互動架構地圖的遊戲安全研究者、反作弊分析師與逆向工程師，而非提供可運作的即時繞過工具組。
