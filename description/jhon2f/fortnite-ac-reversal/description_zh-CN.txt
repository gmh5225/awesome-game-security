本项目是针对《堡垒之夜》完整反作弊体系的结构化逆向工程知识库，以经典版与 EOS 版 Easy Anti-Cheat（EAC）为核心，并涵盖 Epic 在 UE5 侧的完整性与服务器校验。文档涵盖内核与用户态组件、管道协议、规则二进制、HWID 与设备指纹面、信任评分、遥测，以及 ETW-TI 等相关 Windows 内核风险点，并包含当前版本驱动的字节级偏移说明。仓库主要以 Markdown 技术参考资料形式编写，并附带一个用于离线或私服式场景、模拟最小 EAC 集成的小型 C 语言概念验证桩 DLL，以及对真实模拟器架构的分析。面向需要了解《堡垒之夜》与 EAC 交互架构图的游戏安全研究者、反作弊分析师与逆向工程师，而非提供可用的实时绕过工具包。
