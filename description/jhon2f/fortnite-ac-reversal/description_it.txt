Questo progetto è una knowledge base strutturata di reverse engineering per l’intero stack anti-cheat di Fortnite, incentrata su Easy Anti-Cheat nelle forme classica ed EOS, oltre ai controlli di integrità lato UE5 di Epic e alle verifiche lato server. Documenta componenti kernel e user-mode, protocolli pipe, binari delle regole, superfici HWID e fingerprint, trust scoring, telemetria e rischi correlati del kernel Windows come ETW-TI, con note sugli offset a livello di byte per i driver delle build correnti. Il repository è scritto soprattutto come riferimenti tecnici Markdown e include una piccola DLL stub proof-of-concept in C che emula un’integrazione EAC minima per lavoro offline o in stile server privato, insieme ad analisi di architetture di emulatori reali. È rivolto a ricercatori di game security, analisti anti-cheat e reverse engineer che necessitano di una mappa architetturale di come Fortnite ed EAC interagiscono, non di un toolkit di bypass operativo.
