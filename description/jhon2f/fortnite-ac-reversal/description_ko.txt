이 프로젝트는 Fortnite의 전체 안티치트 스택을 대상으로 한 구조화된 리버스 엔지니어링 지식 베이스로, 클래식 및 EOS 형태의 Easy Anti-Cheat(EAC)를 중심으로 Epic의 UE5 측 무결성 검사와 서버 검증까지 다룬다. 커널·사용자 모드 구성 요소, 파이프 프로토콜, 규칙 바이너리, HWID 및 지문 표면, 신뢰 점수, 원격 측정, ETW-TI 등 관련 Windows 커널 위험 요소와 현재 빌드용 드라이버의 바이트 단위 오프셋 정보를 문서화한다. 저장소는 주로 Markdown 기술 참고 자료로 작성되었으며, 오프라인 또는 프라이빗 서버 스타일 작업을 위해 최소 EAC 연동을 에뮬레이트하는 소규모 C 개념 증명 스텁 DLL과 실제 에뮬레이터 아키텍처 분석을 포함한다. Fortnite와 EAC가 어떻게 상호작용하는지에 대한 아키텍처 지도가 필요한 게임 보안 연구자, 안티치트 분석가, 리버스 엔지니어를 대상으로 하며, 실시간 우회 툴킷이 아니다.
