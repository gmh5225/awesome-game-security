This project is a structured reverse-engineering knowledge base for Fortnite’s full anti-cheat stack, centered on Easy Anti-Cheat in classic and EOS forms plus Epic’s UE5-side integrity and server checks. It documents kernel and user-mode components, pipe protocols, rules binaries, HWID and fingerprint surfaces, trust scoring, telemetry, and related Windows kernel hazards such as ETW-TI, with byte-level driver offset notes for current builds. The repository is written mainly as Markdown technical references and includes a small C proof-of-concept stub DLL that emulates minimal EAC integration for offline or private-server style work, along with analyses of real-world emulator architectures. It is aimed at game security researchers, anti-cheat analysts, and reverse engineers who need an architectural map of how Fortnite and EAC interact rather than a live bypass toolkit.
