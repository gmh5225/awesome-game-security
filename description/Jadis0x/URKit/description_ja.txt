URKit は、Windows x64 向け Unity および Unreal Engine ゲーム用の C++ モッディングフレームワークで、対象ゲームの実行ファイルからそのままビルド可能な CMake プロジェクトを生成します。プロキシ DLL ローダーまたはインジェクター経由でアタッチし、Mono および IL2CPP の Unity バックエンドをサポートし、実験的な Unreal ランタイム探索、ProcessEvent フック、型付きヘッダー生成も提供します。モッド開発者はゲームオブジェクトの検索・変更、ネイティブメソッドの呼び出し、SafetyHook による関数フック、シーン変更への応答、ImGui オーバーレイの描画が可能です。リリース用ツールチェーンには SDK ジェネレーター、プロジェクトアップデーター、およびビルド・デプロイ・ランタイム検査用のゲーム内 DevBridge を備えたオプションの MCP 開発サーバーが含まれます。商業 Windows タイトル向けのゲーム MOD 制作、リバースエンジニアリング、セキュリティ研究を目的としています。
