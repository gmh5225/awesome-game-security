URKit è un framework di modding C++ per giochi Unity e Unreal Engine su Windows x64 che genera progetti CMake pronti per la compilazione a partire dall'eseguibile di un gioco target. Si collega tramite loader proxy di DLL o un injector, supporta i backend Unity Mono e IL2CPP, e offre scoperta sperimentale del runtime Unreal, hook di ProcessEvent e generazione di header tipizzati. Gli sviluppatori di mod possono trovare e modificare oggetti di gioco, chiamare metodi nativi, agganciare funzioni con SafetyHook, reagire ai cambiamenti di scena e disegnare overlay ImGui. La toolchain di release include un generatore SDK, un aggiornatore di progetto e un server di sviluppo MCP opzionale con DevBridge in-game per build, deploy e ispezione runtime. È destinato al modding di giochi, reverse engineering e ricerca sulla sicurezza di titoli commerciali Windows.
