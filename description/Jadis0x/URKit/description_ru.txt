URKit — это C++-фреймворк для моддинга игр Unity и Unreal Engine под Windows x64, который генерирует готовые к сборке проекты CMake из исполняемого файла целевой игры. Он подключается через прокси-загрузчики DLL или инжектор, поддерживает бэкенды Unity Mono и IL2CPP, а также предлагает экспериментальное обнаружение runtime Unreal, перехват ProcessEvent и генерацию типизированных заголовков. Разработчики модов могут находить и изменять игровые объекты, вызывать нативные методы, перехватывать функции с помощью SafetyHook, реагировать на смену сцен и рисовать оверлеи ImGui. В набор инструментов релиза входят генератор SDK, обновляющая утилита проекта и опциональный сервер разработки MCP с игровым DevBridge для сборки, развёртывания и проверки во время выполнения. Он предназначен для моддинга игр, реверс-инжиниринга и исследований безопасности коммерческих игр под Windows.
