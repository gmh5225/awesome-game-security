URKit 是一款面向 Windows x64 平台 Unity 与 Unreal Engine 游戏的 C++ 模组开发框架，可从目标游戏可执行文件生成可直接构建的 CMake 项目。它通过代理 DLL 加载器或注入器附加到游戏进程，支持 Mono 与 IL2CPP 两种 Unity 后端，并提供实验性的 Unreal 运行时发现、ProcessEvent 挂钩以及类型化头文件生成功能。模组开发者可以查找并修改游戏对象、调用原生方法、使用 SafetyHook 挂钩函数、响应场景变化，并绘制 ImGui 叠加层。发布工具链包含 SDK 生成器、项目更新器，以及可选的 MCP 开发服务器与游戏内 DevBridge，用于构建、部署和运行时检查。它面向商业 Windows 游戏的模组开发、逆向工程与安全研究。
