URKit은 Windows x64 Unity 및 Unreal Engine 게임용 C++ 모딩 프레임워크로, 대상 게임 실행 파일에서 바로 빌드 가능한 CMake 프로젝트를 생성합니다. 프록시 DLL 로더 또는 인젝터를 통해 게임에 연결하며, Mono 및 IL2CPP Unity 백엔드를 지원하고, 실험적인 Unreal 런타임 탐색, ProcessEvent 후킹, 타입화된 헤더 생성 기능을 제공합니다. 모드 개발자는 게임 객체를 찾고 변경하고, 네이티브 메서드를 호출하며, SafetyHook으로 함수를 후킹하고, 씬 변경에 반응하며, ImGui 오버레이를 그릴 수 있습니다. 릴리스 도구체인에는 SDK 생성기, 프로젝트 업데이터, 그리고 빌드·배포·런타임 검사를 위한 게임 내 DevBridge가 포함된 선택적 MCP 개발 서버가 포함됩니다. 상용 Windows 게임의 모딩, 리버스 엔지니어링, 보안 연구를 목표로 합니다.
