URKit 是一款面向 Windows x64 平台 Unity 與 Unreal Engine 遊戲的 C++ 模組開發框架，可從目標遊戲可執行檔產生可直接建置的 CMake 專案。它透過代理 DLL 載入器或注入器附加到遊戲程序，支援 Mono 與 IL2CPP 兩種 Unity 後端，並提供實驗性的 Unreal 執行階段探索、ProcessEvent 掛鉤以及型別化標頭檔生成功能。模組開發者可以尋找並修改遊戲物件、呼叫原生方法、使用 SafetyHook 掛鉤函式、回應場景變更，並繪製 ImGui 疊加層。發佈工具鏈包含 SDK 產生器、專案更新器，以及可選的 MCP 開發伺服器與遊戲內 DevBridge，用於建置、部署與執行階段檢查。它面向商業 Windows 遊戲的模組開發、逆向工程與安全研究。
