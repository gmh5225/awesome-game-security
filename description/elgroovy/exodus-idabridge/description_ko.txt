IdaBridge는 Exodus 에뮬레이터 확장으로 IDA Pro를 라이브 Sega Mega Drive 세션에 연결해 디스어셈블러에서 에뮬레이트된 ROM 실행을 디버깅할 수 있게 합니다. smd_ida_tools2의 gRPC 기반 디버거 프로토콜을 구현하며 기존 Gensida IDA 플러그인과 함께 동작하고, 이전 Gens 백엔드를 Exodus로 대체합니다. 브리지는 68000 및 VDP 상태, 메모리 읽기·쓰기, DMA 정보, 브레이크포인트와 워치포인트, 스텝 실행, 호출 스택, 실행 추적을 IDA에 노출해 코드 탐색을 지원합니다. C++로 Windows용으로 작성되었고 Visual Studio 플러그인으로 빌드되며 vcpkg로 gRPC와 Protocol Buffers를 사용하며, 사이클 정확 에뮬레이터에서 Mega Drive 게임을 분석하는 리버스 엔지니어와 연구자를 대상으로 합니다.
