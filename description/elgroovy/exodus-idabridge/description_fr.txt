IdaBridge est une extension d’émulateur Exodus qui relie IDA Pro à une session Sega Mega Drive en direct pour déboguer l’exécution d’une ROM émulée depuis le désassembleur. Il met en œuvre le protocole de débogueur basé sur gRPC de smd_ida_tools2 et fonctionne avec le plugin IDA Gensida existant, en remplaçant l’ancien backend Gens par Exodus. Le pont expose l’état du 68000 et du VDP, la lecture et l’écriture mémoire, les informations DMA, les points d’arrêt et de surveillance, le pas à pas, les piles d’appels et le traçage d’exécution pour la découverte de code dans IDA. Il est écrit en C++ pour Windows, compilé comme plugin Visual Studio avec gRPC et Protocol Buffers via vcpkg, et s’adresse aux ingénieurs en rétro-ingénierie et chercheurs qui analysent des jeux Mega Drive dans un émulateur cycle-accurate.
