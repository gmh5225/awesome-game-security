IdaBridge — расширение эмулятора Exodus, которое подключает IDA Pro к активной сессии Sega Mega Drive, чтобы отлаживать выполнение эмулируемой ROM из дизассемблера. Реализует отладочный протокол на gRPC из smd_ida_tools2 и работает с существующим плагином IDA Gensida, заменяя старый бэкенд Gens на Exodus. Мост предоставляет в IDA состояние 68000 и VDP, чтение и запись памяти, сведения о DMA, точки останова и наблюдения, пошаговое выполнение, стеки вызовов и трассировку выполнения для поиска кода. Написан на C++ для Windows, собирается как плагин Visual Studio с gRPC и Protocol Buffers через vcpkg и предназначен для специалистов по реверс-инжинирингу и исследователей, анализирующих игры Mega Drive в cycle-accurate эмуляторе.
