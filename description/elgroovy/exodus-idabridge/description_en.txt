IdaBridge is an Exodus emulator extension that connects IDA Pro to a live Sega Mega Drive session so you can debug emulated ROM execution from the disassembler. It implements the gRPC-based debugger protocol from smd_ida_tools2 and works with the existing Gensida IDA plugin, replacing the older Gens backend with Exodus. The bridge exposes 68000 and VDP state, memory read and write, DMA information, breakpoints and watchpoints, stepping, call stacks, and execution tracing for code discovery in IDA. It is written in C++ for Windows, built as a Visual Studio plugin with gRPC and Protocol Buffers via vcpkg, and targets reverse engineers and researchers analyzing Mega Drive games in a cycle-accurate emulator.
