IdaBridge 是 Exodus 模拟器扩展，将 IDA Pro 连接到实时的 Sega Mega Drive 会话，使您能够从反汇编器中调试模拟 ROM 的执行。它实现了 smd_ida_tools2 中基于 gRPC 的调试器协议，可与现有 Gensida IDA 插件配合使用，以 Exodus 替换旧的 Gens 后端。该桥接器在 IDA 中暴露 68000 与 VDP 状态、内存读写、DMA 信息、断点与监视点、单步、调用栈以及执行跟踪，便于发现代码。项目以 C++ 编写，面向 Windows，作为 Visual Studio 插件构建，通过 vcpkg 集成 gRPC 与 Protocol Buffers，面向在周期精确模拟器中分析 Mega Drive 游戏的逆向工程师与研究人员。
