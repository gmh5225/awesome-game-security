IdaBridge 是 Exodus 模擬器擴充功能，將 IDA Pro 連接到即時的 Sega Mega Drive 工作階段，讓您能從反組譯器中偵錯模擬 ROM 的執行。它實作了 smd_ida_tools2 中以 gRPC 為基礎的偵錯器協定，可與現有的 Gensida IDA 外掛搭配使用，以 Exodus 取代舊的 Gens 後端。此橋接器在 IDA 中公開 68000 與 VDP 狀態、記憶體讀寫、DMA 資訊、中斷點與監看點、單步、呼叫堆疊以及執行追蹤，便於探索程式碼。專案以 C++ 撰寫，面向 Windows，作為 Visual Studio 外掛建置，透過 vcpkg 整合 gRPC 與 Protocol Buffers，面向在週期精確模擬器中分析 Mega Drive 遊戲的逆向工程師與研究人員。
