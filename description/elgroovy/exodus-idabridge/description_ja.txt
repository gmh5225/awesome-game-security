IdaBridge は Exodus エミュレータ拡張で、IDA Pro をライブの Sega Mega Drive セッションに接続し、逆アセンブラからエミュレートされた ROM 実行をデバッグできます。smd_ida_tools2 の gRPC ベースのデバッガプロトコルを実装し、既存の Gensida IDA プラグインと連携し、従来の Gens バックエンドを Exodus に置き換えます。ブリッジは 68000 と VDP の状態、メモリの読み書き、DMA 情報、ブレークポイントとウォッチポイント、ステップ実行、コールスタック、実行トレースを IDA に公開し、コード探索を支援します。C++ で Windows 向けに記述され、Visual Studio プラグインとしてビルドし、vcpkg 経由で gRPC と Protocol Buffers を利用し、サイクル精度エミュレータで Mega Drive ゲームを解析するリバースエンジニアや研究者を対象としています。
