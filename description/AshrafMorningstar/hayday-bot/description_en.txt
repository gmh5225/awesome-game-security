This is an in-memory automation bot for the Hay Day mobile game that harvests, replants, and sells crops by calling internal game functions instead of relying on screen capture or click macros. It is built primarily in Python for deployment and control, with Frida JavaScript hooks, TypeScript anti-telemetry modules, and a native C++ engine that manipulates in-process memory on LDPlayer 9. The suite bypasses Promon SHIELD anti-tamper through patched Frida gadget injection, blocks Quago behavioral anti-cheat telemetry, and hides emulator and root artifacts via runtime hooks and device fingerprint spoofing. It also ships reverse-engineering utilities for analyzing libg.so, patching gadgets, and probing JNI and native registration. The project is aimed at researchers and developers studying mobile game automation, anti-cheat evasion, and dynamic instrumentation of protected Supercell titles.
