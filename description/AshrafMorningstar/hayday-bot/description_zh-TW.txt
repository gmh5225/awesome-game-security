這是一款針對 Hay Day 行動遊戲的記憶體內自動化機器人，透過呼叫遊戲內部函式來收割、重新種植並出售作物，而非依賴螢幕截圖或點擊巨集。專案主要使用 Python 進行部署與控制，並整合 Frida JavaScript 鉤子、TypeScript 反遙測模組，以及可在 LDPlayer 9 上操作程序內記憶體的原生 C++ 引擎。此套件透過修補後的 Frida gadget 注入繞過 Promon SHIELD 防篡改機制，攔截 Quago 行為反作弊遙測，並透過執行時期鉤子與裝置指紋偽造隱藏模擬器與 root 痕跡。它還附帶用於分析 libg.so、修補 gadget 以及探測 JNI 與 native 註冊的逆向工程工具。本專案面向研究行動遊戲自動化、反作弊規避以及對受保護 Supercell 遊戲進行動態插樁的研究人員與開發者。
