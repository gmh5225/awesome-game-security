Hay Day モバイルゲーム向けのインメモリ自動化ボットで、画面キャプチャやクリックマクロに頼らず、内部ゲーム関数を呼び出して作物の収穫、再植え付け、販売を行います。デプロイと制御は主に Python で構築され、Frida JavaScript フック、TypeScript によるアンチテレメトリモジュール、LDPlayer 9 上でプロセス内メモリを操作するネイティブ C++ エンジンで構成されています。このスイートはパッチ済み Frida gadget 注入により Promon SHIELD の改ざん防止を回避し、Quago の行動ベースアンチチートテレメトリをブロックし、ランタイムフックとデバイスフィンガープリント偽装によりエミュレーターおよび root の痕跡を隠します。libg.so の解析、gadget のパッチ、JNI およびネイティブ登録のプローブ用のリバースエンジニアリングユーティリティも同梱されています。本プロジェクトは、モバイルゲーム自動化、アンチチート回避、保護された Supercell タイトルの動的インストルメンテーションを研究する開発者と研究者を対象としています。
