这是一款针对 Hay Day 移动游戏的内存内自动化机器人，通过调用游戏内部函数来收割、重新种植并出售作物，而非依赖屏幕截图或点击宏。项目主要使用 Python 进行部署与控制，并集成 Frida JavaScript 钩子、TypeScript 反遥测模块，以及可在 LDPlayer 9 上操作进程内内存的原生 C++ 引擎。该套件通过修补后的 Frida gadget 注入绕过 Promon SHIELD 防篡改机制，拦截 Quago 行为反作弊遥测，并通过运行时钩子与设备指纹伪造隐藏模拟器和 root 痕迹。它还附带用于分析 libg.so、修补 gadget 以及探测 JNI 与 native 注册的反编译工具。本项目面向研究移动游戏自动化、反作弊规避以及对受保护 Supercell 游戏进行动态插桩的研究人员与开发者。
