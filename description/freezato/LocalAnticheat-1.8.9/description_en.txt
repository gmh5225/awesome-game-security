LocalAntiCheat is a client-side Minecraft Forge mod for version 1.8.9 that monitors network packets the game client sends and receives to detect common combat and movement cheats without modifying traffic or reporting to servers. Written in Java and built with Gradle, it implements eleven automated checks including AutoClicker, KillAura, Reach, Speed, Fly, Velocity, NoFall, Timer, FastPlace, FastBreak, and Scaffold, drawing on server-side anti-cheat design principles such as monotonic timing and knockback vector analysis. Detection results are displayed only in the player's local chat through configurable flag formats, and the mod can evaluate both the local player and other visible players on a server. It integrates with OneConfig for settings and is intended for PvP players and security researchers who want on-client cheat awareness on multiplayer servers where server-side anti-cheat may be limited or absent.
