NHL Legacy Remaster 是针对 EA Sports NHL Legacy Edition（Xbox 360）的 Windows 移植与现代化项目，通过 ReXGlue SDK 将原版游戏重编译为 x86-64，而非模拟主机运行。代码库以 C++ 与 CMake 为主，用于移植层、启动器与运行时钩子，并配有大型 Python 工具链，用于解析 EA 归档格式、阵容数据库、球衣以及 Frostbite 时代的 NHL 24 资源。项目记录并实现逆向工程工作流，例如基于 default.xex 的清单驱动代码生成、函数挂钩、存档与 franchise 数据补丁，以及针对二进制、纹理与游戏数据库的研究工具。该工作面向研究 legacy 体育游戏二进制、移植技术与客户端 mod 流水线的开发者与研究人员，而非在线反作弊。终端用户将合法拥有的 Xbox 360 游戏文件与构建好的 mod 结合，在 PC 上通过 DirectX 12 或 Vulkan 体验更新后的 franchise 玩法。
