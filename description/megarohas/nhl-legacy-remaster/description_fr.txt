NHL Legacy Remaster est un projet de portage Windows et de modernisation pour EA Sports NHL Legacy Edition (Xbox 360), recompilant le jeu original en x86-64 avec le ReXGlue SDK plutôt que d’émuler la console. La base de code repose surtout sur C++ et CMake pour le port, le lanceur et les hooks d’exécution, avec une importante chaîne d’outils Python pour analyser les formats d’archives EA, les bases de données de rosters, les maillots et les assets NHL 24 de l’ère Frostbite. Il documente et met en œuvre des workflows de reverse engineering tels que la génération de code pilotée par manifeste à partir de default.xex, le hooking de fonctions, le patch des sauvegardes et des données franchise, ainsi que des utilitaires de recherche pour binaires, textures et bases de données de jeu. Le travail s’adresse aux développeurs et chercheurs qui étudient les binaires de jeux sportifs legacy, les techniques de portage et les pipelines de modding côté client, plutôt qu’à l’anti-triche en ligne. Les utilisateurs finaux combinent des fichiers de jeu Xbox 360 légalement possédés avec des mods compilés pour jouer à une expérience franchise mise à jour sur PC avec DirectX 12 ou Vulkan.
