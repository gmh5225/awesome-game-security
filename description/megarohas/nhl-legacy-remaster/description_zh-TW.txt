NHL Legacy Remaster 是針對 EA Sports NHL Legacy Edition（Xbox 360）的 Windows 移植與現代化專案，透過 ReXGlue SDK 將原版遊戲重編譯為 x86-64，而非模擬主機執行。程式碼庫以 C++ 與 CMake 為主，用於移植層、啟動器與執行階段掛鉤，並配有大型 Python 工具鏈，用於解析 EA 歸檔格式、名單資料庫、球衣以及 Frostbite 時代的 NHL 24 資源。專案記錄並實作逆向工程工作流程，例如以 default.xex 為基礎的 manifest 驅動程式碼產生、函式掛鉤、存檔與 franchise 資料修補，以及針對二進位、紋理與遊戲資料庫的研究工具。此工作面向研究 legacy 體育遊戲二進位、移植技術與用戶端 mod 管線的開發者與研究人員，而非線上反作弊。終端使用者將合法擁有的 Xbox 360 遊戲檔案與建置好的 mod 結合，在 PC 上透過 DirectX 12 或 Vulkan 體驗更新後的 franchise 玩法。
