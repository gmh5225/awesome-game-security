Cobra is a modern web-based Snake arcade game built with TypeScript, Next.js, and React, featuring HTML5 Canvas rendering at 60 FPS and rich visual and audio game juice effects. Its cloud-backed global Top 10 leaderboard includes server-side anti-cheat that uses signed game sessions, score plausibility validation, and submission rate limits to silently reject forged scores. The project also offers 40-plus emoji power-ups, responsive desktop and mobile controls, and persistent leaderboard storage via LibSQL with a localStorage fallback when database credentials are unavailable. It serves as a practical reference for implementing lightweight server-side anti-cheat and score validation in browser-based games.
