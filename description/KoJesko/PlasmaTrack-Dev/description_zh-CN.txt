PlasmaTrack 是面向 Euro Truck Simulator 2 与 American Truck Simulator 的任务追踪系统，可记录游戏内遥测数据、从玩家机器上传，并在服务端重建与评分每次运输任务。基于 SCS 与 TruckersMP 遥测 SDK 构建的 C++ 游戏插件将数据流式传输至后台客户端，在本地以 SQLite 记录并上传原始数据块；共享 Rust 核心负责时间线重建、评分规则以及在客户端与服务端上的一致回放。后端包含数据摄取、公开与管理 API、面向 Discord 机器人的 Webhook，以及使用 D1、R2、队列与 Durable Objects 的 Cloudflare Workers 部署，另提供基于 Electron 的 Windows 安装程序。服务端反作弊检查会将可疑任务标记以供人工审核，适合需要可信任务校验而非依赖客户端计分的虚拟卡车社区与运营方。
