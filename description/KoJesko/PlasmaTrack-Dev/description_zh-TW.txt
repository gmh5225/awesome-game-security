PlasmaTrack 是面向 Euro Truck Simulator 2 與 American Truck Simulator 的任務追蹤系統，可記錄遊戲內遙測資料、從玩家機器上傳，並在伺服器端重建與評分每次運輸任務。基於 SCS 與 TruckersMP 遙測 SDK 建構的 C++ 遊戲外掛將資料串流傳輸至背景用戶端，在本機以 SQLite 記錄並上傳原始資料區塊；共用 Rust 核心負責時間軸重建、評分規則以及在用戶端與伺服器上的一致重播。後端包含資料擷取、公開與管理 API、面向 Discord 機器人的 Webhook，以及使用 D1、R2、佇列與 Durable Objects 的 Cloudflare Workers 部署，另提供以 Electron 為基礎的 Windows 安裝程式。伺服器端反作弊檢查會將可疑任務標記以供人工審核，適合需要可信任務驗證而非依賴用戶端計分的虛擬卡車社群與營運方。
