PlasmaTrack は Euro Truck Simulator 2 および American Truck Simulator 向けのジョブ追跡システムで、ゲーム内テレメトリを記録し、プレイヤー端末からアップロードし、サーバー上で各配送を再構築してスコア付けします。SCS および TruckersMP テレメトリ SDK 上に構築された C++ ゲームプラグインがデータをバックグラウンドクライアントへストリーミングし、ローカルで SQLite に記録して生チャンクをアップロードします。共有 Rust コアはタイムライン再構築、採点ルール、クライアントとサーバー双方での一貫したリプレイを担当します。バックエンドには取り込み、公開・管理 API、Discord ボット用 Webhook、D1・R2・キュー・Durable Objects を用いた Cloudflare Workers デプロイ、および Windows 向け Electron ベースのインストーラが含まれます。サーバー側のアンチチート検査が疑わしいジョブを手動レビュー用にフラグ付けするため、クライアント信頼のスコア記録ではなく信頼できるジョブ検証が必要なバーチャルトラックコミュニティと運営者に適しています。
