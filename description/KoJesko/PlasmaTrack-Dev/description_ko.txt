PlasmaTrack은 Euro Truck Simulator 2 및 American Truck Simulator용 작업 추적 시스템으로, 게임 내 텔레메트리를 기록하고 플레이어 PC에서 업로드한 뒤 서버에서 각 운송 작업을 재구성하고 점수를 매깁니다. SCS 및 TruckersMP 텔레메트리 SDK 기반 C++ 게임 플러그인이 데이터를 백그라운드 클라이언트로 스트리밍하고, 로컬에서 SQLite로 기록하며 원시 청크를 업로드합니다. 공유 Rust 코어는 타임라인 재구성, 채점 규칙, 클라이언트와 서버 양쪽에서의 일관된 리플레이를 처리합니다. 백엔드에는 수집(ingest), 공개 및 관리 API, Discord 봇용 Webhook, D1·R2·큐·Durable Objects를 사용하는 Cloudflare Workers 배포, Windows용 Electron 기반 설치 프로그램이 포함됩니다. 서버 측 안티치트 검사가 의심스러운 작업을 수동 검토용으로 표시하므로, 클라이언트 신뢰 점수 기록이 아닌 신뢰할 수 있는 작업 검증이 필요한 가상 트럭 커뮤니티와 운영자에 적합합니다.
