PlasmaTrack è un sistema di tracciamento dei lavori per Euro Truck Simulator 2 e American Truck Simulator che registra la telemetria in gioco, la carica dal PC del giocatore e ricostruisce e valuta ogni trasporto sul server. Un plugin di gioco in C++ basato sugli SDK telemetria SCS e TruckersMP invia i dati in streaming a un client in background che registra localmente in SQLite e carica blocchi grezzi, mentre un core Rust condiviso gestisce la ricostruzione della timeline, le regole di punteggio e la riproduzione coerente su client e server. Il backend include ingestione, API pubbliche e di amministrazione, webhook per bot Discord e un deployment Cloudflare Workers con D1, R2, code e durable objects, oltre a un installer per Windows basato su Electron. Controlli anticheat lato server segnalano lavori sospetti per revisione manuale, rendendolo adatto a comunità di trucking virtuale e operatori che richiedono una validazione affidabile dei lavori piuttosto che punteggi basati sulla fiducia nel client.
