PlasmaTrack is a job-tracking system for Euro Truck Simulator 2 and American Truck Simulator that records in-game telemetry, uploads it from the player machine, and rebuilds and scores each haul on the server. A C++ game plugin built on the SCS and TruckersMP telemetry SDKs streams data to a background client that logs locally in SQLite and uploads raw chunks, while a shared Rust core handles timeline reconstruction, scoring rules, and consistent replay on both client and server. The backend includes ingest, public and admin APIs, webhooks for Discord bots, and a Cloudflare Workers deployment using D1, R2, queues, and durable objects, plus an Electron-based installer for Windows. Server-side anti-cheat checks flag suspicious jobs for manual review, making it suited to virtual trucking communities and operators who need trustworthy job validation rather than client-trusted scorekeeping.
