ZyvenAntiCheat 是一款面向 Minecraft Paper 服务端的服务器端反作弊插件，可在无需修改客户端的情况下检测并应对常见客户端作弊行为。它使用 Java 编写，通过 Maven 针对 Paper 1.21 API 构建，以事件驱动方式检测移动、战斗、挖矿、载具与物品使用，并配合违规等级以及可配置的管理员告警与踢出命令。移动与实用模块涵盖飞行、加速、无摔落伤害、鞘翅与船滥用、攻击距离、杀戮光环、自动点击、水晶与重生锚光环、快速进食与自动图腾；挖矿检测则强制执行破坏时机与速度上限。突出技术包括视线内实体隐藏与每名玩家的诱饵实体，用于对抗 ESP 与自由视角，以及仅客户端可见的诱饵方块，用于诱捕方块 ESP 与基地查找类工具。面向希望在标准 Bukkit 或 Paper 主机上获得轻量、可配置游戏安全防护的生存与 PvP 服主。
