ZyvenAntiCheat is a server-side anti-cheat plugin for Minecraft Paper servers that detects and responds to common client cheats without requiring a modified client. It is written in Java and built with Maven against the Paper 1.21 API, using event-driven checks for movement, combat, mining, vehicles, and item use together with violation levels and configurable staff alerts and kick commands. Movement and utility modules cover fly, speed, no-fall, elytra and boat abuse, reach, killaura, autoclick, crystal and anchor auras, fast eat and auto-totem, while mining checks enforce break timing and speed limits. Standout techniques include line-of-sight entity hiding and per-player decoy entities to counter ESP and freecam, plus client-only bait blocks that trap block-ESP and base-finder tools. It is aimed at survival and PvP server operators who want lightweight, configurable game security on a standard Bukkit or Paper host.
