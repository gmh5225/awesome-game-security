ZyvenAntiCheat 是一款面向 Minecraft Paper 伺服器端的伺服器端反作弊外掛，可在無需修改用戶端的情況下偵測並因應常見用戶端作弊行為。它以 Java 撰寫，透過 Maven 針對 Paper 1.21 API 建置，以事件驅動方式檢查移動、戰鬥、採礦、載具與物品使用，並搭配違規等級以及可設定的管理員警示與踢除指令。移動與實用模組涵蓋飛行、加速、無摔落傷害、鞘翅與船濫用、攻擊距離、自動攻擊、自動點擊、水晶與重生錨光環、快速進食與自動圖圖騰；採礦檢查則強制破壞時機與速度上限。亮點技術包括視線內實體隱藏與每位玩家的誘餌實體，用以對抗 ESP 與自由視角，以及僅用戶端可見的誘餌方塊，用以誘捕方塊 ESP 與基地搜尋類工具。適合希望在標準 Bukkit 或 Paper 主機上取得輕量、可設定遊戲安全防護的生存與 PvP 伺服器營運者。
