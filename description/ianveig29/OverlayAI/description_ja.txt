OverlayAI は、プロセス外からゲームメモリを読み書きしながら ImGui で DirectX 11 オーバーレイを描画する外部型 Counter-Strike 2 チートです。Windows 向け C++ で実装され、ESP、エイムアシスト、トリガーボット、グロー、移動支援、ビジュアルバイパス機能に加え、注入されたブリッジ DLL、名前付きパイプ IPC、Panorama UI 連携を用い、SOCache 操作でクライアント側スキンとロードアウトを適用するモジュラー型インベントリチェンジャーを備えています。コードベースはダンプした schema オフセット、メモリユーティリティ、Panorama とインベントリに関する広範な調査を中心に構成され、CS2 の更新追従を目的としています。外部オーバーレイチート、メモリ操作、CS2 におけるインベントリ偽装手法を研究するゲームセキュリティ研究者やアンチチート開発者向けのリソースです。
