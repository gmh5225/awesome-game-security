OverlayAI — внешний чит для Counter-Strike 2, который рендерит оверлей DirectX 11 с ImGui, одновременно читая и изменяя память игры извне процесса. Написан на C++ для Windows и включает ESP, aim assist, triggerbot, glow, помощники движения и функции визуального обхода, а также модульный сменщик инвентаря, использующий инжектированную bridge DLL, IPC через именованный канал и интеграцию с Panorama UI для применения клиентских скинов и loadout через манипуляцию SOCache. Кодовая база организована вокруг дампнутых schema offsets, утилит памяти и обширных исследований Panorama и инвентаря для отслеживания обновлений CS2. В основном полезен исследователям игровой безопасности и разработчикам античитов, изучающим внешние оверлей-читы, манипуляции памятью и техники подмены инвентаря в CS2.
