OverlayAI 是一款外部 Counter-Strike 2 作弊工具，在程序外讀取並修改遊戲記憶體的同時，使用 ImGui 渲染 DirectX 11 疊加層。此工具以 C++ 為 Windows 編寫，包含 ESP、自瞄、扳機機器人、發光、移動輔助與視覺繞過等功能，以及模組化庫存更換器——透過注入橋接 DLL、具名管道 IPC 和 Panorama UI 整合，利用 SOCache 操作套用用戶端皮膚與裝備。程式碼庫圍繞傾印出的 schema 偏移、記憶體工具，以及大量 Panorama 與庫存相關研究組織，以便追蹤 CS2 更新。它主要面向研究外部疊加層作弊、記憶體操作和 CS2 庫存欺騙技術的遊戲安全研究人員與反作弊開發者。
