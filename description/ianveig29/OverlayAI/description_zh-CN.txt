OverlayAI 是一款外部 Counter-Strike 2 作弊工具，在进程外读取并修改游戏内存的同时，使用 ImGui 渲染 DirectX 11 叠加层。该工具使用 C++ 为 Windows 编写，包含 ESP、自瞄、扳机机器人、发光、移动辅助和视觉绕过等功能，以及模块化库存更换器——通过注入桥接 DLL、命名管道 IPC 和 Panorama UI 集成，利用 SOCache 操作应用客户端皮肤与装备。代码库围绕转储的 schema 偏移、内存工具，以及大量 Panorama 与库存相关研究组织，以便跟踪 CS2 更新。它主要面向研究外部叠加层作弊、内存操作和 CS2 库存欺骗技术的游戏安全研究人员与反作弊开发者。
