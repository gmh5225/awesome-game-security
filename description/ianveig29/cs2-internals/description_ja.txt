これは、プログラミングやリバースエンジニアリングの経験がなくても学べる Counter-Strike 2 と Valve の Source 2 エンジンを基礎から理解するための教育ガイド兼ドキュメント wiki です。Markdown ベースのカリキュラムでは、コンピュータの基礎、PE と仮想メモリの概念、Source 2 のモジュールアーキテクチャ、オフセットとシグネチャ、Schema と Entity システム、レンダリング、入力とネットワーク、VPK と KV3 リソース、静的リバースエンジニアリングの方法論を扱います。内容は段階的な学習パスとハンズオンラボで構成され、ライブマッチメイキングではなく公開 dump、デモ、練習用バイナリに依存します。サイトは MkDocs と Python で公開され、プロジェクトはアンチチート回避や実用的なチート開発を意図的に除外しています。ゲームセキュリティ研究者、MOD 開発者、再現可能で根拠付きのドキュメントを通じて CS2 の内部を学ぶすべての人を対象としています。
