This repository is a detailed technical issue report documenting a Rainbow Six Siege (Steam) launch failure after the Y11S3 update, where the client terminates during the BattlEye and Ubisoft Sentinel anti-cheat handshake when launched through standard paths but runs normally when started via RainbowSixHelper.exe. The report compiles Windows System event logs, Ubisoft Connect launcher and game-starter logs, BattlEye service and BEDaisy kernel driver telemetry, byte-identical executable checksum comparisons, and a structured timeline of troubleshooting steps including service re-registration and quickboot staging clears. It hypothesizes that the failure stems from standard launch-path bootstrapping and a possible server-side security or version negotiation rejection rather than corrupted game files or blocked drivers. Written as Markdown documentation, it is aimed at game security researchers, anti-cheat analysts, and support engineers investigating BattlEye and dual-anti-cheat launch regressions on Windows.
