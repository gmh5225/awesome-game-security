本リポジトリは、Y11S3 アップデート後に Rainbow Six Siege（Steam 版）が起動に失敗する問題を詳細に記録した技術レポートです。通常の起動パスでは BattlEye と Ubisoft Sentinel のアンチチート握手の最中にクライアントが終了しますが、RainbowSixHelper.exe 経由では正常に動作します。レポートには Windows システムイベントログ、Ubisoft Connect ランチャーおよびゲーム起動ログ、BattlEye サービスと BEDaisy カーネルドライバーのテレメトリ、バイト単位で同一の実行ファイルチェックサム比較、サービスの再登録や quickboot ステージングのクリアを含む構造化されたトラブルシューティングのタイムラインがまとめられています。障害の原因は、破損したゲームファイルやブロックされたドライバーではなく、標準起動パスのブートストラップ処理と、サーバー側のセキュリティまたはバージョン交渉の拒否の可能性があると推測されています。Markdown 形式で書かれており、ゲームセキュリティ研究者、アンチチート分析者、Windows 上の BattlEye およびデュアルアンチチート起動リグレッションを調査するサポートエンジニアを対象としています。
