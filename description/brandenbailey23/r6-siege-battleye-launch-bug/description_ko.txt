이 저장소는 Y11S3 업데이트 이후 Rainbow Six Siege(Steam)의 실행 실패 문제를 상세히 기록한 기술 이슈 보고서입니다. 일반 경로로 실행하면 BattlEye와 Ubisoft Sentinel 안티치트 핸드셰이크 중 클라이언트가 종료되지만, RainbowSixHelper.exe를 통해 시작하면 정상적으로 실행됩니다. 보고서에는 Windows 시스템 이벤트 로그, Ubisoft Connect 런처 및 게임 시작 로그, BattlEye 서비스와 BEDaisy 커널 드라이버 원격 측정, 바이트 단위로 동일한 실행 파일 체크섬 비교, 서비스 재등록 및 quickboot 스테이징 초기화를 포함한 구조화된 문제 해결 타임라인이 수집되어 있습니다. 손상된 게임 파일이나 차단된 드라이버가 아니라, 표준 실행 경로의 부트스트래핑과 서버 측 보안 또는 버전 협상 거부 가능성에서 실패가 발생한다고 가정합니다. Markdown 문서로 작성되었으며, 게임 보안 연구자, 안티치트 분석가, Windows에서 BattlEye 및 이중 안티치트 실행 회귀를 조사하는 지원 엔지니어를 대상으로 합니다.
