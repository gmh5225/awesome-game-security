Renamaida 是一款 IDA Pro 插件，可通过对已知开源或静态链接库中预生成的指令签名进行匹配，自动重命名固件二进制文件中的未识别函数。该插件使用 Python 编写，将每个函数编码为特定于架构的指令令牌序列，并使用 Jaro-Winkler 相似度算法比较这些签名，对相似度超过 0.83 且至少包含十条指令的匹配项进行重命名。用户可使用附带的生成器脚本，通过编译带有完整调试符号的目标库来构建自定义 JSON 签名数据库；仓库中还提供了 ARMv5TE 平台上 strongSwan VPN 库的示例签名。它面向需要在 IDA Pro 中分析嵌入式或静态链接二进制文件并恢复有意义函数名称的逆向工程师和固件分析人员。
