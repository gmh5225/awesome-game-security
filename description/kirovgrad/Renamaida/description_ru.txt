Renamaida — это плагин для IDA Pro, который автоматически переименовывает неидентифицированные функции в прошивочных бинарниках путём сопоставления их с заранее сгенерированными сигнатурами инструкций из известных библиотек с открытым исходным кодом или статически связанных библиотек. Написанный на Python, он кодирует каждую функцию как последовательность архитектурно-специфичных токенов инструкций и сравнивает эти сигнатуры с помощью алгоритма схожести Jaro-Winkler, переименовывая совпадения с порогом схожести выше 0,83 и содержащие не менее десяти инструкций. Пользователи могут создавать пользовательские базы данных сигнатур JSON с помощью включённого скрипта-генератора, компилируя целевые библиотеки с полными отладочными символами; репозиторий также содержит примеры сигнатур для библиотек strongSwan VPN на ARMv5TE. Он предназначен для специалистов по обратной разработке и аналитиков прошивок, которым необходимо восстановить осмысленные имена функций при разборе встроенных или статически связанных бинарников в IDA Pro.
