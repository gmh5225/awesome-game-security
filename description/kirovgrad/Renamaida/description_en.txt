Renamaida is an IDA Pro plugin that automatically renames unidentified functions in firmware binaries by matching them against pre-generated instruction signatures from known open-source or statically linked libraries. Written in Python, it encodes each function as a sequence of architecture-specific instruction tokens and compares those signatures using the Jaro-Winkler similarity algorithm, renaming matches that exceed a 0.83 similarity threshold and contain at least ten instructions. Users can build custom JSON signature databases with an included generator script by compiling target libraries with full debug symbols, and the repository ships with sample signatures for strongSwan VPN libraries on ARMv5TE. It is aimed at reverse engineers and firmware analysts who need to recover meaningful function names when dissecting embedded or statically linked binaries in IDA Pro.
