Renamaida ist ein IDA Pro-Plugin, das nicht identifizierte Funktionen in Firmware-Binärdateien automatisch umbenennt, indem es sie mit vorab generierten Befehls-Signaturen aus bekannten Open-Source- oder statisch verlinkten Bibliotheken abgleicht. In Python geschrieben, kodiert es jede Funktion als Sequenz architekturspezifischer Befehls-Token und vergleicht diese Signaturen mit dem Jaro-Winkler-Ähnlichkeitsalgorithmus, wobei Übereinstimmungen mit einer Ähnlichkeit über 0,83 und mindestens zehn Befehlen umbenannt werden. Benutzer können mit einem enthaltenen Generator-Skript benutzerdefinierte JSON-Signaturdatenbanken erstellen, indem sie Zielbibliotheken mit vollständigen Debug-Symbolen kompilieren; das Repository enthält Beispielsignaturen für strongSwan-VPN-Bibliotheken auf ARMv5TE. Es richtet sich an Reverse Engineers und Firmware-Analysten, die beim Analysieren eingebetteter oder statisch verlinkter Binärdateien in IDA Pro aussagekräftige Funktionsnamen wiederherstellen müssen.
