Renamaida 是一款 IDA Pro 外掛，可透過比對已知開源或靜態連結函式庫中預先生成的指令簽章，自動重新命名韌體二進位檔中的未識別函式。該外掛以 Python 撰寫，將每個函式編碼為特定架構的指令權杖序列，並使用 Jaro-Winkler 相似度演算法比較這些簽章，對相似度超過 0.83 且至少包含十條指令的匹配項目重新命名。使用者可使用內附的產生器指令碼，透過編譯帶有完整除錯符號的目標函式庫來建立自訂 JSON 簽章資料庫；存放庫中亦提供 ARMv5TE 平台上 strongSwan VPN 函式庫的範例簽章。它面向需要在 IDA Pro 中剖析嵌入式或靜態連結二進位檔並還原有意義函式名稱的逆向工程師與韌體分析人員。
