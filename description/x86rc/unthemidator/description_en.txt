Unthemidator is a universal unpacker and runtime protection removal tool for Windows binaries protected with Themida and Code Virtualizer. It unpacks PE images through CPU emulation without running the target on the host or calling its APIs, then rebuilds a runnable, debuggable PE with restored imports, resources, and decompressed virtual-machine code. The project is written in C++20 and uses the Unicorn emulator and Zydis disassembler to support 32-bit and 64-bit executables, DLLs, drivers, and related modules. It can identify Themida and Code Virtualizer VM versions, locate protection entry points, and targets reverse engineers and security researchers analyzing commercially packed software such as games and other applications shielded by these protectors.
