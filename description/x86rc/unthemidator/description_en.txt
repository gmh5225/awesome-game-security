Unthemidator is a universal unpacker and runtime protection removal tool for Windows binaries protected with Themida and Code Virtualizer. It unpacks PE images through CPU emulation rather than executing the target or invoking its APIs on the host, then rebuilds a runnable, debuggable PE with restored imports, resources, and decompressed virtual-machine code. The project is implemented in C++20 and relies on the Unicorn emulator and Zydis disassembler for instruction analysis and controlled unpacking of 32-bit and 64-bit executables, DLLs, drivers, and similar modules. It can identify Themida and Code Virtualizer VM versions, locate protection entry points, and supports a range of Themida 3.x builds. The tool targets reverse engineers and security researchers who need static analysis of commercially packed software, including games and other applications shielded by these protectors.
