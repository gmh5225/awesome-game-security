Unthemidator は、Themida および Code Virtualizer で保護された Windows バイナリ向けの汎用アンパッカー兼ランタイム保護除去ツールです。ホスト上でターゲットを実行したり API を呼び出したりするのではなく CPU エミュレーションによって PE イメージをアンパックし、インポート、リソース、解凍された仮想マシンコードを復元したうえで実行可能かつデバッグ可能な PE を再構築します。本プロジェクトは C++20 で実装され、命令解析と制御されたアンパックのために Unicorn エミュレータと Zydis 逆アセンブラに依存し、32 ビットおよび 64 ビットの実行ファイル、DLL、ドライバーなどのモジュールに対応します。Themida と Code Virtualizer の VM バージョンの特定、保護エントリポイントの特定、各種 Themida 3.x ビルドのサポートが可能です。ゲームを含む商用パッカーで保護されたソフトウェアの静的解析を必要とするリバースエンジニアおよびセキュリティ研究者向けのツールです。
