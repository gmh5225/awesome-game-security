Unthemidator는 Themida 및 Code Virtualizer로 보호된 Windows 바이너리용 범용 언패커 및 런타임 보호 제거 도구입니다. 호스트에서 대상을 실행하거나 API를 호출하는 대신 CPU 에뮬레이션을 통해 PE 이미지를 언팩한 뒤, 가져오기·리소스·압축 해제된 가상 머신 코드를 복원하여 실행 가능하고 디버깅 가능한 PE를 재구성합니다. 프로젝트는 C++20로 구현되었으며, 명령어 분석과 제어된 언패킹을 위해 Unicorn 에뮬레이터와 Zydis 디스어sembler에 의존하며 32비트 및 64비트 실행 파일, DLL, 드라이버 및 유사 모듈을 지원합니다. Themida와 Code Virtualizer VM 버전 식별, 보호 진입점 탐색, 다양한 Themida 3.x 빌드 지원이 가능합니다. 게임을 포함해 이러한 프로텍터로 보호된 상용 패킹 소프트웨어의 정적 분석이 필요한 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
