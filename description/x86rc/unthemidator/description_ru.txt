Unthemidator — универсальный распаковщик и инструмент снятия runtime-защиты для Windows-бинарников, защищённых Themida и Code Virtualizer. Он распаковывает PE-образы через эмуляцию CPU, а не путём запуска цели или вызова её API на хосте, затем восстанавливает исполняемый и отлаживаемый PE с восстановленными импортами, ресурсами и распакованным кодом виртуальной машины. Проект реализован на C++20 и опирается на эмулятор Unicorn и дизассемблер Zydis для анализа инструкций и контролируемой распаковки 32- и 64-битных исполняемых файлов, DLL, драйверов и подобных модулей. Может определять версии VM Themida и Code Virtualizer, находить точки входа защиты и поддерживает различные сборки Themida 3.x. Инструмент предназначен для reverse-инженеров и исследователей безопасности, которым нужен статический анализ коммерчески упакованного ПО, включая игры и другие приложения, защищённые этими протекторами.
