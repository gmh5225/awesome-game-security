Unthemidator 是一款面向受 Themida 与 Code Virtualizer 保护的 Windows 二进制的通用脱壳与运行时保护移除工具。它通过 CPU 仿真而非在主机上执行目标或调用其 API 来解包 PE 映像，随后重建可运行、可调试的 PE，并恢复导入表、资源与解压缩后的虚拟机代码。项目采用 C++20 实现，依赖 Unicorn 模拟器与 Zydis 反汇编器进行指令分析与受控脱壳，支持 32 位与 64 位可执行文件、DLL、驱动及类似模块。该工具可识别 Themida 与 Code Virtualizer 的 VM 版本、定位保护入口点，并支持多种 Themida 3.x 构建；面向需要对商业加壳软件（含游戏及其他受此类保护器防护的应用）进行静态分析的逆向工程师与安全研究人员。
