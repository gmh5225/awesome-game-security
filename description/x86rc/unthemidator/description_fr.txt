Unthemidator est un outil universel de dépackage et de suppression de protection runtime pour les binaires Windows protégés par Themida et Code Virtualizer. Il dépack les images PE par émulation CPU plutôt qu’en exécutant la cible ou en appelant ses API sur l’hôte, puis reconstruit un PE exécutable et déboguable avec imports, ressources et code de machine virtuelle décompressé restaurés. Le projet est implémenté en C++20 et s’appuie sur l’émulateur Unicorn et le désassembleur Zydis pour l’analyse d’instructions et le dépackage contrôlé d’exécutables, DLL, pilotes et modules similaires en 32 et 64 bits. Il peut identifier les versions de VM Themida et Code Virtualizer, localiser les points d’entrée de protection et prend en charge diverses builds Themida 3.x. L’outil s’adresse aux ingénieurs reverse et chercheurs en sécurité qui ont besoin d’une analyse statique de logiciels packés commercialement, y compris des jeux et autres applications protégées par ces protecteurs.
