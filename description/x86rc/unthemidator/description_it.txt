Unthemidator è uno strumento universale di unpacking e rimozione della protezione runtime per binari Windows protetti con Themida e Code Virtualizer. Esegue l’unpack delle immagini PE tramite emulazione CPU anziché eseguire il target o invocarne le API sull’host, quindi ricostruisce un PE eseguibile e debuggabile con import, risorse e codice della macchina virtuale decompresso ripristinati. Il progetto è implementato in C++20 e si affida all’emulatore Unicorn e al disassemblatore Zydis per l’analisi delle istruzioni e l’unpacking controllato di eseguibili, DLL, driver e moduli simili a 32 e 64 bit. Può identificare le versioni VM di Themida e Code Virtualizer, individuare i punti di ingresso della protezione e supporta varie build Themida 3.x. Lo strumento è rivolto a reverse engineer e ricercatori di sicurezza che necessitano di analisi statica di software impacchettato commercialmente, inclusi giochi e altre applicazioni protette da questi protector.
