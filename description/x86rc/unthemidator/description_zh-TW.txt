Unthemidator 是一款面向受 Themida 與 Code Virtualizer 保護的 Windows 二進位檔的通用脫殼與執行階段保護移除工具。它透過 CPU 模擬而非在主機上執行目標或呼叫其 API 來解包 PE 映像，隨後重建可執行、可偵錯的 PE，並還原匯入表、資源與解壓縮後的虛擬機器程式碼。專案以 C++20 實作，依賴 Unicorn 模擬器與 Zydis 反組譯器進行指令分析與受控脫殼，支援 32 位元與 64 位元可執行檔、DLL、驅動程式及類似模組。此工具可識別 Themida 與 Code Virtualizer 的 VM 版本、定位保護進入點，並支援多種 Themida 3.x 建置；面向需要對商業加殼軟體（含遊戲及其他受此類保護器防護的應用程式）進行靜態分析的逆向工程師與安全研究人員。
