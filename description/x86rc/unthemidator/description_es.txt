Unthemidator es una herramienta universal de desempaquetado y eliminación de protección en tiempo de ejecución para binarios de Windows protegidos con Themida y Code Virtualizer. Desempaqueta imágenes PE mediante emulación de CPU en lugar de ejecutar el objetivo o invocar sus API en el host, y reconstruye un PE ejecutable y depurable con importaciones, recursos y código de máquina virtual descomprimido restaurados. El proyecto está implementado en C++20 y depende del emulador Unicorn y del desensamblador Zydis para el análisis de instrucciones y el desempaquetado controlado de ejecutables, DLL, controladores y módulos similares de 32 y 64 bits. Puede identificar versiones de VM de Themida y Code Virtualizer, localizar puntos de entrada de protección y admite diversas compilaciones de Themida 3.x. La herramienta está dirigida a ingenieros inversos e investigadores de seguridad que necesitan análisis estático de software empaquetado comercialmente, incluidos juegos y otras aplicaciones protegidas por estos protectores.
