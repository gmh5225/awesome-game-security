Pew Game은 Stardew Valley의 Journey of the Prairie King에서 영감을 받은 브라우저 기반 픽셀 아트 트윈 스틱 슈터로, 온라인 리더보드가 있는 풀스택 웹 게임으로 구축되었습니다. TypeScript, Next.js, Bun, Tailwind CSS 및 이미지 에셋 없이 모든 스프라이트를 절차적으로 그리는 순수 TypeScript canvas 게임 엔진으로 구현되었습니다. 프로젝트에는 서버 측 안티치트 계층이 포함되어 게임 시작 시 HMAC 서명된 세션 토큰을 발급하고, 점수 제출 시 서명 무결성, 점수·웨이브·플레이 시간의 타당성, 리플레이 방지를 검증합니다. better-sqlite3를 통한 SQLite가 리더보드 데이터를 저장하며, 코드베이스에는 게임플레이 메커니즘과 안티치트 검증을 다루는 광범위한 단위 테스트와 E2E 테스트가 포함되어 있습니다. 클라이언트 측 브라우저 게임 점수를 보호하고 온라인 리더보드를 변조로부터 지키는 실용적인 참고 자료입니다.
