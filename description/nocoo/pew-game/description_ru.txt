Pew Game — это браузерный twin-stick шутер в пиксельной графике, вдохновлённый Journey of the Prairie King из Stardew Valley, созданный как full-stack веб-игра с онлайн-таблицей лидеров. Реализован на TypeScript с Next.js, Bun, Tailwind CSS и чистым TypeScript canvas-движком, где все спрайты рисуются процедурно без использования изображений. Проект включает серверный античит-слой, который выдаёт HMAC-подписанные сессионные токены при старте игры и проверяет отправку очков на целостность подписи, правдоподобность счёта, волны и длительности, а также защиту от повторной отправки. SQLite через better-sqlite3 хранит данные лидерборда, а кодовая база содержит обширные unit- и end-to-end тесты, охватывающие игровую механику и проверку античита. Это практический ориентир для защиты клиентских браузерных игровых результатов и онлайн-таблиц лидеров от подделки.
