Pew Game は、Stardew Valley の Journey of the Prairie King に着想を得た、ブラウザ向けピクセルアートのツインスティックシューターで、オンラインランキング付きのフルスタック Web ゲームとして構築されています。TypeScript、Next.js、Bun、Tailwind CSS、および画像アセットを使わず全スプライトを手続き的に描画する純 TypeScript の canvas ゲームエンジンで実装されています。プロジェクトにはサーバー側の反チート層があり、ゲーム開始時に HMAC 署名付きセッショントークンを発行し、スコア送信時に署名の整合性、スコア・ウェーブ・プレイ時間の妥当性、リプレイ防止を検証します。better-sqlite3 経由の SQLite がランキングデータを保存し、コードベースにはゲームプレイ機構と反チート検証を網羅する包括的なユニットテストと E2E テストが含まれます。クライアント側ブラウザゲームのスコアを保護し、オンラインランキングの改ざんから守る実践的な参考例となります。
