Pew Game 是一款基于浏览器的像素艺术双摇杆射击游戏，灵感来自《星露谷物语》中的《草原王之冒险》，作为具备在线排行榜的全栈 Web 游戏构建。它使用 TypeScript 实现，采用 Next.js、Bun、Tailwind CSS 以及纯 TypeScript 画布游戏引擎，所有精灵均为程序化绘制，无需图片资源。项目包含服务端反作弊层，在游戏开始时签发 HMAC 签名的会话令牌，并验证分数提交时的签名完整性、分数、波次和时长合理性，以及防重放。通过 better-sqlite3 使用 SQLite 存储排行榜数据，代码库包含覆盖游戏机制与反作弊验证的大量单元测试和端到端测试。它是保护客户端浏览器游戏分数、防止在线排行榜被篡改的实用参考。
