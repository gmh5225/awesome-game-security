Pew Game 是一款以瀏覽器為基礎的像素藝術雙搖桿射擊遊戲，靈感來自《星露谷物語》中的《草原王之冒險》，建構為具備線上排行榜的全端 Web 遊戲。它以 TypeScript 實作，採用 Next.js、Bun、Tailwind CSS 以及純 TypeScript canvas 遊戲引擎，所有精靈圖均以程序化方式繪製，無需影像資源。專案包含伺服器端反作弊層，在遊戲開始時簽發 HMAC 簽名的工作階段權杖，並驗證分數提交時的簽章完整性、分數、波次與時長合理性，以及防重放。透過 better-sqlite3 使用 SQLite 儲存排行榜資料，程式碼庫包含涵蓋遊戲機制與反作弊驗證的大量單元測試與端對端測試。它是保護用戶端瀏覽器遊戲分數、防止線上排行榜遭竄改的實用參考。
