Pew Game is a browser-based pixel art twin-stick shooter inspired by Stardew Valley's Journey of the Prairie King, built as a full-stack web game with an online leaderboard. It is implemented in TypeScript with Next.js, Bun, Tailwind CSS, and a pure TypeScript canvas game engine where all sprites are drawn procedurally without image assets. The project includes a server-side anti-cheat layer that issues HMAC-signed session tokens at game start and validates score submissions for signature integrity, score, wave, and duration plausibility, and replay prevention. SQLite via better-sqlite3 stores leaderboard data, and the codebase includes extensive unit and end-to-end tests covering gameplay mechanics and anti-cheat validation. It serves as a practical reference for securing client-side browser game scores and protecting online leaderboards from tampering.
