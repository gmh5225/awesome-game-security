Pew Game es un shooter twin-stick de pixel art basado en navegador, inspirado en Journey of the Prairie King de Stardew Valley, desarrollado como un juego web full-stack con un marcador en línea. Está implementado en TypeScript con Next.js, Bun, Tailwind CSS y un motor de juego canvas en TypeScript puro, donde todos los sprites se dibujan de forma procedural sin recursos de imagen. El proyecto incluye una capa anti-trampas del lado del servidor que emite tokens de sesión firmados con HMAC al iniciar el juego y valida los envíos de puntuación por integridad de firma, plausibilidad de puntuación, oleada y duración, y prevención de replay. SQLite mediante better-sqlite3 almacena los datos del marcador, y la base de código incluye amplias pruebas unitarias y end-to-end que cubren la mecánica de juego y la validación anti-trampas. Sirve como referencia práctica para proteger puntuaciones de juegos de navegador del lado del cliente y defender los marcadores en línea contra manipulaciones.
