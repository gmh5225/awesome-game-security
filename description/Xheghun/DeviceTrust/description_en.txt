DeviceTrust is an Android library that collects local device integrity signals to assess whether a handset may be rooted, hooked, emulated, or otherwise compromised. It combines a Kotlin coroutine-based API with native NDK checks written in C++ to scan for root artifacts, runtime instrumentation frameworks such as Frida and Xposed, emulator fingerprints, and weakened system integrity indicators including bootloader state and SELinux enforcement. Assessments produce a weighted risk score and categorized evidence that apps can use with configurable review and high-risk thresholds, or export raw signals for server-side scoring. The library ships native binaries for ARM64, ARMv7, x86, and x86_64 and is intended for mobile developers building fraud prevention, authentication hardening, or game anti-cheat controls on Android.
