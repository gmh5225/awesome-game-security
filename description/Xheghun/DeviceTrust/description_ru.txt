DeviceTrust — это библиотека для Android, которая собирает локальные сигналы целостности устройства, чтобы оценить, может ли телефон быть рутирован, подвергнут hook-ингу, эмулироваться или иным образом скомпрометирован. Она сочетает API на основе корутин Kotlin с нативными проверками NDK, написанными на C++, для поиска артефактов root, фреймворков инструментирования времени выполнения, таких как Frida и Xposed, отпечатков эмуляторов, а также ослабленных индикаторов целостности системы, включая состояние загрузчика и принудительное применение SELinux. Оценки формируют взвешенный показатель риска и категоризированные доказательства, которые приложения могут использовать с настраиваемыми порогами проверки и высокого риска или экспортировать необработанные сигналы для серверного скоринга. Библиотека поставляется с нативными бинарниками для ARM64, ARMv7, x86 и x86_64 и предназначена для мобильных разработчиков, создающих средства предотвращения мошенничества, усиления аутентификации или античит-контроля в играх на Android.
