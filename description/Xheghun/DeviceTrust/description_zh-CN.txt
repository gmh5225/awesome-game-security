DeviceTrust 是一款 Android 库，用于收集本地设备完整性信号，以评估手机是否可能已被 root、被 hook、运行在模拟器中，或存在其他被篡改的风险。它将基于 Kotlin 协程的 API 与使用 C++ 编写的原生 NDK 检测相结合，扫描 root 痕迹、Frida 与 Xposed 等运行时插桩框架、模拟器指纹，以及包括引导加载程序状态和 SELinux 强制模式在内的系统完整性弱化指标。评估结果会生成加权风险评分和分类证据，应用可据此配置审查与高风险阈值，也可导出原始信号供服务端评分。该库提供 ARM64、ARMv7、x86 和 x86_64 的原生二进制文件，面向在 Android 上构建欺诈防护、身份验证加固或游戏反作弊控制的移动开发者。
