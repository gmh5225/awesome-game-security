DeviceTrust は、端末が root 化、フック、エミュレーション、またはその他の方法で改ざんされている可能性があるかを評価するため、ローカルのデバイス整合性シグナルを収集する Android ライブラリです。Kotlin コルーチンベースの API と C++ で書かれたネイティブ NDK チェックを組み合わせ、root の痕跡、Frida や Xposed などのランタイム計装フレームワーク、エミュレータのフィンガープリント、ブートローダー状態や SELinux 強制などのシステム整合性の低下指標をスキャンします。評価では加重リスクスコアと分類された証拠が生成され、アプリは設定可能なレビューおよび高リスク閾値とともに利用できるほか、生のシグナルをサーバー側スコアリング用にエクスポートすることもできます。本ライブラリは ARM64、ARMv7、x86、x86_64 向けのネイティブバイナリを同梱し、Android 上で不正防止、認証強化、ゲームアンチチート制御を構築するモバイル開発者向けに設計されています。
