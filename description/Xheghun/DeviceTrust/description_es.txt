DeviceTrust es una biblioteca de Android que recopila señales locales de integridad del dispositivo para evaluar si un teléfono puede estar rooteado, con hooks, emulado o comprometido de otro modo. Combina una API basada en corrutinas de Kotlin con comprobaciones nativas NDK escritas en C++ para detectar artefactos de root, frameworks de instrumentación en tiempo de ejecución como Frida y Xposed, huellas de emulador e indicadores de integridad del sistema debilitados, incluidos el estado del bootloader y la aplicación de SELinux. Las evaluaciones generan una puntuación de riesgo ponderada y evidencia categorizada que las aplicaciones pueden usar con umbrales configurables de revisión y alto riesgo, o exportar señales en bruto para puntuación en el servidor. La biblioteca incluye binarios nativos para ARM64, ARMv7, x86 y x86_64 y está pensada para desarrolladores móviles que implementan prevención de fraude, endurecimiento de autenticación o controles antitrampas en juegos para Android.
