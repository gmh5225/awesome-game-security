DeviceTrust 是一款 Android 程式庫，用於收集本機裝置完整性訊號，以評估手機是否可能已被 root、被 hook、執行於模擬器中，或存在其他遭竄改的風險。它結合以 Kotlin 協程為基礎的 API 與以 C++ 撰寫的原生 NDK 檢查，掃描 root 痕跡、Frida 與 Xposed 等執行階段插樁框架、模擬器指紋，以及包含開機載入程式狀態與 SELinux 強制模式在內的系統完整性弱化指標。評估結果會產生加權風險評分與分類證據，應用程式可據此設定審查與高風險閾值，也可匯出原始訊號供伺服器端評分。此程式庫提供 ARM64、ARMv7、x86 與 x86_64 的原生二進位檔，供在 Android 上建構詐欺防護、身分驗證強化或遊戲反作弊控制的行動開發者使用。
