xCam 是一款通用的 Android Xposed 模組，可將預錄影片與靜態影像注入到即時相機預覽、拍照以及眾多第三方應用程式內的影片錄製流程中。它攔截 Camera1、Camera2、ImageReader、MediaRecorder、WebRTC 及相關媒體路徑，透過 MediaCodec 表面轉碼以及 YUV 或 JPEG 合成，使預覽與錄製輸出在 Android 9 至 16 上保持一致。程式碼庫主要以 Kotlin 與 Java 撰寫，基於 LibXposed API，面向搭配 LSPosed 類載入器的 root 環境，或透過 LSPatch 等工具進行非 root 修補的情境。其他元件提供管線遙測、旋轉與鏡像、同步虛擬音訊，以及可選的裝置或位置偽裝輔助功能。適用於需要評估依賴相機與裝置完整性訊號的防詐欺、反作弊與身分驗證控件的行動安全研究人員與測試人員。
