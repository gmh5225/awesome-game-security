xCam is a universal Android Xposed module that injects pre-recorded videos and still images into live camera previews, still photo capture, and in-app video recording across many third-party applications. It intercepts Camera1, Camera2, ImageReader, MediaRecorder, WebRTC, and related media paths, using MediaCodec surface transcoding and YUV or JPEG synthesis so preview and recorded output stay aligned on Android 9 through 16. The codebase is built mainly in Kotlin and Java on the LibXposed API and targets rooted setups with LSPosed-style loaders or non-root patching via tools such as LSPatch. Additional components provide pipeline telemetry, rotation and mirroring, synchronized virtual audio, and optional device or location spoofing helpers. It is aimed at mobile security researchers and testers who need to evaluate anti-fraud, anti-cheat, and identity-verification controls that rely on camera and device integrity signals.
