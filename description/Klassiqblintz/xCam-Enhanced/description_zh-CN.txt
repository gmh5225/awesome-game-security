xCam 是一款通用的 Android Xposed 模块，可将预录视频与静态图像注入到实时相机预览、拍照以及众多第三方应用内的视频录制流程中。它拦截 Camera1、Camera2、ImageReader、MediaRecorder、WebRTC 及相关媒体路径，通过 MediaCodec 表面转码以及 YUV 或 JPEG 合成，使预览与录制输出在 Android 9 至 16 上保持一致。代码库主要以 Kotlin 与 Java 编写，基于 LibXposed API，面向配合 LSPosed 类加载器的 root 环境，或通过 LSPatch 等工具进行非 root 修补的场景。其他组件提供流水线遥测、旋转与镜像、同步虚拟音频，以及可选的设备或位置伪装辅助功能。适用于需要评估依赖相机与设备完整性信号的防欺诈、反作弊与身份核验控件的移动安全研究人员与测试人员。
