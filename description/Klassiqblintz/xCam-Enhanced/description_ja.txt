xCam は汎用の Android 向け Xposed モジュールで、事前録画した動画や静止画をライブカメラプレビュー、静止画撮影、多数のサードパーティアプリ内での動画録画に注入します。Camera1、Camera2、ImageReader、MediaRecorder、WebRTC および関連するメディア経路を横取りし、MediaCodec のサーフェス変換と YUV または JPEG 合成により、Android 9 から 16 までプレビューと録画出力の整合を保ちます。コードベースは主に Kotlin と Java で LibXposed API 上に構築され、LSPosed 系ローダーを使う root 環境や、LSPatch などによる非 root パッチを想定しています。追加コンポーネントはパイプラインのテレメトリ、回転・ミラーリング、同期仮想オーディオ、任意のデバイスや位置偽装ヘルパーを提供します。カメラおよびデバイス整合性シグナルに依存する不正防止、アンチチート、本人確認コントロールを評価する必要があるモバイルセキュリティ研究者やテスター向けです。
