WonTree RBLX Dumper is a universal Roblox game analysis tool that decompiles reachable scripts and exports structured reports for reverse-engineering a live game. Written in Luau as a single injectable script, it runs on UNC-compatible executors such as Xeno, Wave, Solara, Delta, and Codex, with a Rayfield Gen2 UI and a native fallback. It combines a four-layer decompile pipeline, full client and server instance scanning, remote call graphs with an optional live FireServer and InvokeServer logger, framework detection, and anti-cheat keyword scanning into markdown and CSV outputs. The tool filters executor noise, handles protected scripts gracefully, and scales to large games with configurable script limits and memory caps. It is intended for game security researchers and reverse engineers who need a practical reference map of a Roblox experience's scripts, remotes, assets, and security-relevant code paths.
