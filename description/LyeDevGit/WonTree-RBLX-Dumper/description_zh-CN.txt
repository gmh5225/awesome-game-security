WonTree RBLX Dumper 是一款通用的 Roblox 游戏分析工具，可反编译可访问的脚本并导出结构化报告，用于对在线游戏进行逆向工程。它以 Luau 编写为单一可注入脚本，可在 Xeno、Wave、Solara、Delta、Codex 等兼容 UNC 的执行器上运行，提供 Rayfield Gen2 界面及原生备用界面。该工具整合四层反编译流水线、完整的客户端与服务器实例扫描、远程调用图及可选的实时 FireServer 与 InvokeServer 日志记录、框架检测和反作弊关键词扫描，输出为 Markdown 与 CSV 格式。工具会过滤执行器噪声、妥善处理受保护脚本，并通过可配置的脚本数量限制与内存上限适配大型游戏。它面向需要 Roblox 体验中脚本、远程事件、资源及安全相关代码路径实用参考地图的游戏安全研究人员与逆向工程师。
