WonTree RBLX Dumper は、到達可能なスクリプトを逆コンパイルし、稼働中のゲームをリバースエンジニアリングするための構造化レポートを出力する汎用 Roblox ゲーム分析ツールです。Luau で単一の注入可能スクリプトとして書かれており、Xeno、Wave、Solara、Delta、Codex など UNC 互換エグゼキュータ上で動作し、Rayfield Gen2 UI とネイティブフォールバックを備えています。4 層の逆コンパイルパイプライン、クライアントおよびサーバーインスタンスの完全スキャン、オプションのライブ FireServer および InvokeServer ロガー付きリモート呼び出しグラフ、フレームワーク検出、反チートキーワードスキャンを組み合わせ、Markdown と CSV 形式で出力します。エグゼキュータのノイズをフィルタリングし、保護されたスクリプトを適切に処理し、設定可能なスクリプト上限とメモリ上限により大規模ゲームにも対応します。Roblox 体験のスクリプト、リモート、アセット、セキュリティ関連コードパスの実用的な参照マップを必要とするゲームセキュリティ研究者およびリバースエンジニア向けです。
