FPGA DMA Multi Tool은 DMA 하드웨어와 함께 사용하는 지원 Artix-7 FPGA 보드를 감지·구성·테스트하기 위한 コンパ트한 Windows 유틸리티입니다. Go로 작성되고 Fyne 기반 GUI를 제공하며, IDCODE와 공장 DNA로 장치를 식별하고, openFPGALoader를 통해 비트스트림을 SRAM 또는 영구 플래시에 로드하며, DMA 메모리 읽기 및 읽기/쓰기 성능을 측정합니다. 번들로 제공되는 CH347, FTDI D3XX, RS232 라이터 드라이버를 관리하고, CH347 또는 지원되는 FTDI/Digilent JTAG 라이터로 보드를 프로그래밍하며, Windows 장치 기록과 VT-x/AMD-V, VT-d/AMD-Vi, Secure Boot, PCIe 링크 폭 같은 시스템 세부 정보를 표시합니다. 주요 사용 사례는 Windows 10/11에서 게임 보안 연구, 안티치트 분석 및 관련 하드웨어 워크플로를 위해 FPGA DMA 보드를 설정하고 검증하는 것입니다.
