FPGA DMA Multi Tool 是一款精简的 Windows 工具，用于检测、配置和测试配合 DMA 硬件使用的受支持 Artix-7 FPGA 开发板。采用 Go 编写，并基于 Fyne 构建 GUI，可通过 IDCODE 与出厂 DNA 识别设备，借助 openFPGALoader 将比特流加载到 SRAM 或持久 Flash，并测量 DMA 内存读取与读写性能。它还管理捆绑的 CH347、FTDI D3XX 与 RS232 烧录驱动，通过 CH347 或受支持的 FTDI/Digilent JTAG 烧录器对开发板编程，并展示 Windows 设备历史以及 VT-x/AMD-V、VT-d/AMD-Vi、Secure Boot、PCIe 链路宽度等系统信息。主要用途是在 Windows 10/11 上为游戏安全研究、反作弊分析及相关硬件工作流完成 FPGA DMA 开发板的配置与验证。
