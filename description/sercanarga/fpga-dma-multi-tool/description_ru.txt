FPGA DMA Multi Tool — компактная утилита для Windows, предназначенная для обнаружения, настройки и тестирования поддерживаемых плат Artix-7 FPGA, используемых с DMA-оборудованием. Написана на Go с GUI на базе Fyne: определяет устройства по IDCODE и заводскому DNA, загружает битстримы в SRAM или постоянную flash через openFPGALoader и измеряет производительность чтения и чтения/записи памяти DMA. Также управляет поставляемыми драйверами программаторов CH347, FTDI D3XX и RS232, программирует платы через CH347 или поддерживаемые JTAG-программаторы FTDI/Digilent и показывает историю устройств Windows, а также сведения о системе: VT-x/AMD-V, VT-d/AMD-Vi, Secure Boot и ширину PCIe-канала. Основной сценарий — настройка и проверка плат FPGA DMA для исследований игровой безопасности, анализа античитов и связанных аппаратных рабочих процессов в Windows 10/11.
