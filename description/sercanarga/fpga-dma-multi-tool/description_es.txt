FPGA DMA Multi Tool es una utilidad compacta de Windows para detectar, configurar y probar placas FPGA Artix-7 compatibles usadas con hardware DMA. Escrita en Go con una GUI basada en Fyne, identifica dispositivos por IDCODE y DNA de fábrica, carga bitstreams en SRAM o flash persistente mediante openFPGALoader y mide el rendimiento de lectura y lectura/escritura de memoria DMA. También gestiona los controladores de grabación CH347, FTDI D3XX y RS232 incluidos, programa placas a través de CH347 o grabadores JTAG FTDI/Digilent compatibles, y muestra el historial de dispositivos de Windows junto con detalles del sistema como VT-x/AMD-V, VT-d/AMD-Vi, Secure Boot y el ancho del enlace PCIe. El caso de uso principal es configurar y validar placas FPGA DMA para investigación de seguridad en juegos, análisis anti-trampas y flujos de trabajo de hardware relacionados en Windows 10/11.
