FPGA DMA Multi Tool は、DMA ハードウェアと併用する対応 Artix-7 FPGA ボードの検出、設定、テスト向けのコンパクトな Windows ユーティリティです。Go で書かれ、Fyne ベースの GUI を備え、IDCODE と工場出荷時 DNA でデバイスを識別し、openFPGALoader 経由でビットストリームを SRAM または永続フラッシュへ読み込み、DMA メモリの読み取りおよび読み書き性能を測定します。同梱の CH347、FTDI D3XX、RS232 ライター用ドライバを管理し、CH347 または対応の FTDI/Digilent JTAG ライターでボードをプログラムし、Windows のデバイス履歴に加え VT-x/AMD-V、VT-d/AMD-Vi、Secure Boot、PCIe リンク幅などのシステム情報も表示します。主な用途は、Windows 10/11 上でゲームセキュリティ研究、アンチチート解析、関連ハードウェア作業向けに FPGA DMA ボードをセットアップし検証することです。
