FPGA DMA Multi Tool 是一款精簡的 Windows 工具，用於偵測、設定與測試搭配 DMA 硬體使用的受支援 Artix-7 FPGA 開發板。以 Go 撰寫，並基於 Fyne 打造 GUI，可透過 IDCODE 與出廠 DNA 辨識裝置，藉由 openFPGALoader 將位元流載入 SRAM 或持久 Flash，並測量 DMA 記憶體讀取與讀寫效能。它也管理隨附的 CH347、FTDI D3XX 與 RS232 燒錄驅動程式，透過 CH347 或受支援的 FTDI/Digilent JTAG 燒錄器對開發板進行程式設計，並顯示 Windows 裝置歷程以及 VT-x/AMD-V、VT-d/AMD-Vi、Secure Boot、PCIe 連結寬度等系統資訊。主要用途是在 Windows 10/11 上為遊戲安全研究、反作弊分析及相關硬體工作流程完成 FPGA DMA 開發板的設定與驗證。
