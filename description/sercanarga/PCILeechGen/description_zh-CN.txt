PCILeechGen 是一款面向 PCILeech FPGA DMA 板的自定义固件生成器，可克隆真实 PCI/PCIe 供体设备的身份并生成可直接烧录的比特流。该工具主要用 Go 编写，通过 Linux VFIO 与 IOMMU 读取供体硬件，采集配置空间、BAR 布局与能力信息，随后生成用于 Xilinx Vivado 综合的 SystemVerilog 与 COE 产物。它支持 NVMe 控制器行为、MSI-X 表、配置空间清理、BAR 分析、MMIO 追踪以及面向时序的 TLP 延迟调优等设备仿真功能，兼容多种 FPGA 开发板。该工具面向研究 PCIe DMA 攻击、硬件身份欺骗，以及针对内存访问作弊硬件的反作弊与游戏安全防御的安全研究人员。
