PCILeechGen は、PCILeech FPGA DMA ボード向けのカスタムファームウェア生成ツールで、実在の PCI/PCIe ドナーデバイスの ID を複製し、フラッシュ可能なビットストリームを生成します。主に Go で書かれており、Linux VFIO と IOMMU を通じてドナーハードウェアを読み取り、コンフィグスペース、BAR レイアウト、ケイパビリティを取得したうえで、Xilinx Vivado による合成用の SystemVerilog および COE アーティファクトを生成します。NVMe コントローラの挙動、MSI-X テーブル、コンフィグスペースのスクラビング、BAR プロファイリング、MMIO トレース、タイミング指向の TLP レイテンシ調整などのデバイスエミュレーション機能を備え、多数の FPGA ボードをサポートします。PCIe DMA 攻撃、ハードウェア ID スプーフィング、メモリアクセス型チートハードウェアに対するアンチチートやゲームセキュリティ防御を研究するセキュリティ研究者向けのツールです。
