PCILeechGen は、PCILeech FPGA DMA ボード向けのカスタムファームウェア生成ツールで、実在の PCI/PCIe ドナーデバイスの ID を複製し、フラッシュ可能なビットストリームを生成します。主に Go で書かれており、Linux VFIO と IOMMU を介してドナーハードウェアを読み取り、コンフィグレーションスペース、BAR レイアウト、ケイパビリティを取得したうえで、Xilinx Vivado による合成用の SystemVerilog および COE アーティファクトを生成します。NVMe コントローラの挙動、MSI-X テーブル、コンフィグスペースのスクラブ、BAR プロファイリング、MMIO トレース、タイミング指向の TLP レイテンシ調整など、多数の FPGA ボードに対応したデバイスエミュレーション機能をサポートします。PCIe DMA 攻撃、ハードウェア ID スプーフィング、メモリアクセス型チートハードウェアに対するアンチチートやゲームセキュリティ防御を研究するセキュリティ研究者向けのツールです。
