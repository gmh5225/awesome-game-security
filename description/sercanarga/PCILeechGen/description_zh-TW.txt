PCILeechGen 是一款面向 PCILeech FPGA DMA 開發板的自訂韌體產生器，可複製真實 PCI/PCIe 捐贈裝置的身分，並產生可直接燒錄的位元流。此工具主要以 Go 撰寫，透過 Linux VFIO 與 IOMMU 讀取捐贈硬體，擷取設定空間、BAR 配置與能力資訊，接著產生供 Xilinx Vivado 綜合使用的 SystemVerilog 與 COE 產物。它支援 NVMe 控制器行為、MSI-X 表、設定空間清理、BAR 分析、MMIO 追蹤，以及面向時序的 TLP 延遲調校等多種裝置模擬功能，相容眾多 FPGA 開發板。此工具面向研究 PCIe DMA 攻擊、硬體身分偽造，以及針對記憶體存取作弊硬體的反作弊與遊戲安全防禦的安全研究人員。
