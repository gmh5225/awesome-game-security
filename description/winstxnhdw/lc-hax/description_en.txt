lc-hax is a portable Windows internal mod for Lethal Company that injects a C# assembly into the game process via a CLI launcher and exposes a large set of always-on mods plus chat-triggered commands. It is built on .NET with runtime Harmony-style patches, helper modules for players and enemies, and optional Roslyn source analysers that validate command definitions. Capabilities span ESP, anti-kick, god mode, noclip, enemy possession, infinite resources, lobby and connection manipulation, and host-only privileged controls, with private command input and keyboard binds for toggles and teleportation. The project suits game security and anti-cheat research into Unity mono injection, client-side trust boundaries, and how feature-rich internal cheats are structured and maintained.
