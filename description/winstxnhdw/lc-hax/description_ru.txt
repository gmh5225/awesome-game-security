lc-hax — портативный внутренний мод для Windows для Lethal Company, который через CLI-лаунчер внедряет сборку C# в процесс игры и предоставляет большой набор постоянно активных модов и команд, запускаемых из чата. Построен на .NET с патчами в стиле Harmony во время выполнения, вспомогательными модулями для игроков и врагов и опциональными анализаторами исходного кода Roslyn, проверяющими определения команд. Возможности включают ESP, защиту от кика, god mode, noclip, вселение во врагов, бесконечные ресурсы, манипуляции с лобби и подключениями и привилегированные элементы управления только для хоста, с приватным вводом команд и привязками клавиш для переключений и телепортации. Проект подходит для исследований в области безопасности игр и античита: инъекция Unity mono, границы доверия на стороне клиента и структура с сопровождением функционально богатых внутренних читов.
