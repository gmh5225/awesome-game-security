LarpingAntiCheat è un plugin anti-cheat pronto per la produzione per server Minecraft Paper 1.21, pensato per ambienti SMP personalizzati che necessitano di un rilevamento affidabile dei cheat con pochissimi falsi positivi. Scritto in Java 21, implementa controlli modulari di movimento, combattimento e mondo come volo, velocità, reach, kill aura, scaffold e fast break, utilizzando snapshot fisici autoritativi lato server e tracciamento delle violazioni per giocatore con decadimento. Il plugin include il rilevamento honeypot ed ESP tramite entità esca e basi false opzionali a livello di pacchetti, oltre a un analizzatore di capacità che adatta i controlli a modificatori e incantamenti personalizzati comuni sui server SMP moddati. È destinato a operatori di server e sviluppatori che vogliono sicurezza di gioco lato server e strumenti anti-cheat su Paper senza componenti lato client.
