Conglomerate-CS2 is an internal Counter-Strike 2 cheat framework built as a Windows DLL that hooks into the game process and renders an in-game configuration menu. Written primarily in C++ with Visual Studio, it uses Kiero and MinHook to intercept DirectX 11 rendering, Dear ImGui for the overlay UI, and pattern scanning, vfunc calls, and Source 2 schema parsing to locate game interfaces and entity data. Feature modules include aim assistance, chams, movement tweaks, spectator lists, visual overlays such as anti-flash and FOV changes, and world modifications, with JSON-backed configuration and keybind support. The codebase also reverse engineers CS2 structures such as CGameEntitySystem, player pawns, weapons, and engine client interfaces. It is aimed at game security researchers and reverse engineers studying internal cheat architecture, memory hooking techniques, and the behaviors anti-cheat systems must detect in CS2.
