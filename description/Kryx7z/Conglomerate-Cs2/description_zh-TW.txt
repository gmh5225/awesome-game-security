Conglomerate-CS2 是一個內部 Counter-Strike 2 作弊框架，以 Windows DLL 形式建構，可注入遊戲程序並渲染遊戲內設定選單。專案主要使用 C++ 和 Visual Studio 撰寫，透過 Kiero 和 MinHook 攔截 DirectX 11 渲染，使用 Dear ImGui 建構覆蓋層 UI，並透過特徵碼掃描、虛函式呼叫和 Source 2 schema 解析來定位遊戲介面與實體資料。功能模組包括自瞄輔助、chams、移動調整、旁觀者清單、視覺覆蓋層（如防閃光和 FOV 修改）以及世界修改，支援 JSON 設定和按鍵綁定。程式碼庫還對 CS2 結構進行逆向分析，如 CGameEntitySystem、玩家 pawn、武器和引擎用戶端介面。該專案面向研究內部作弊架構、記憶體 Hook 技術及反作弊系統需偵測行為的遊戲安全研究人員和逆向工程師。
