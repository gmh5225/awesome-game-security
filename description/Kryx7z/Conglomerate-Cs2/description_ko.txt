Conglomerate-CS2는 게임 프로세스에 후킹하여 게임 내 설정 메뉴를 렌더링하는 Windows DLL로 구축된 Counter-Strike 2용 내부 치트 프레임워크입니다. 주로 C++와 Visual Studio로 작성되었으며, Kiero와 MinHook을 사용해 DirectX 11 렌더링을 가로채고, Dear ImGui로 오버레이 UI를 제공합니다. 패턴 스캔, vfunc 호출, Source 2 스키마 파싱을 통해 게임 인터페이스와 엔티티 데이터를 찾습니다. 기능 모듈에는 에임 보조, chams, 이동 조정, 관전자 목록, 안티 플래시 및 FOV 변경 같은 시각 오버레이, 월드 수정이 포함되며 JSON 기반 설정과 키 바인딩을 지원합니다. 코드베이스는 CGameEntitySystem, 플레이어 pawn, 무기, 엔진 클라이언트 인터페이스 등 CS2 구조체를 역공학합니다. CS2에서 내부 치트 아키텍처, 메모리 후킹 기법, 그리고 안티치트 시스템이 탐지해야 하는 동작을 연구하는 게임 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
