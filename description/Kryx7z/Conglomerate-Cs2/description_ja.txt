Conglomerate-CS2 は、Windows DLL として構築された Counter-Strike 2 向けの internal チートフレームワークで、ゲームプロセスにフックしてゲーム内設定メニューを描画します。主に C++ と Visual Studio で記述され、Kiero と MinHook を使用して DirectX 11 レンダリングを傍受し、Dear ImGui でオーバーレイ UI を提供します。パターンスキャン、vfunc 呼び出し、Source 2 スキーマ解析によりゲームインターフェースとエンティティデータを特定します。機能モジュールにはエイム支援、chams、移動調整、スペクテーターリスト、視覚オーバーレイ（アンチフラッシュや FOV 変更など）、ワールド変更が含まれ、JSON 設定とキーバインドをサポートします。コードベースは CGameEntitySystem、プレイヤー pawn、武器、エンジンクライアントインターフェースなど CS2 構造体のリバースエンジニアリングも行います。internal チートアーキテクチャ、メモリフック手法、および CS2 でアンチチートシステムが検出すべき動作を研究するゲームセキュリティ研究者とリバースエンジニアを対象としています。
