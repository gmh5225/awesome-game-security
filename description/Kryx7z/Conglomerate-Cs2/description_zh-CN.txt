Conglomerate-CS2 是一个内部 Counter-Strike 2 作弊框架，以 Windows DLL 形式构建，可注入游戏进程并渲染游戏内配置菜单。项目主要使用 C++ 和 Visual Studio 编写，通过 Kiero 和 MinHook 拦截 DirectX 11 渲染，使用 Dear ImGui 构建覆盖层 UI，并通过特征码扫描、虚函数调用和 Source 2 schema 解析来定位游戏接口与实体数据。功能模块包括自瞄辅助、chams、移动调整、旁观者列表、视觉覆盖层（如防闪光和 FOV 修改）以及世界修改，支持 JSON 配置和按键绑定。代码库还对 CS2 结构进行逆向分析，如 CGameEntitySystem、玩家 pawn、武器和引擎客户端接口。该项目面向研究内部作弊架构、内存 Hook 技术及反作弊系统需检测行为的游戏安全研究人员和逆向工程师。
