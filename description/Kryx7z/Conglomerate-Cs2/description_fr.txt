Conglomerate-CS2 est un framework de triche interne pour Counter-Strike 2, construit sous forme de DLL Windows qui s'accroche au processus du jeu et affiche un menu de configuration en jeu. Écrit principalement en C++ avec Visual Studio, il utilise Kiero et MinHook pour intercepter le rendu DirectX 11, Dear ImGui pour l'interface de superposition, ainsi que le scan de motifs, les appels vfunc et l'analyse de schéma Source 2 pour localiser les interfaces du jeu et les données d'entités. Les modules fonctionnels incluent l'assistance à la visée, les chams, les ajustements de mouvement, les listes de spectateurs, les superpositions visuelles comme l'anti-flash et les modifications de FOV, ainsi que les modifications du monde, avec une configuration basée sur JSON et le support des raccourcis clavier. La base de code reverse également les structures CS2 telles que CGameEntitySystem, les pawns de joueurs, les armes et les interfaces client du moteur. Il s'adresse aux chercheurs en sécurité des jeux et aux ingénieurs en reverse ingénierie étudiant l'architecture des triches internes, les techniques de hooking mémoire et les comportements que les systèmes anti-triche doivent détecter dans CS2.
