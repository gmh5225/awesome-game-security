Sonekk Guard is a free client-server anti-cheat stack aimed at standalone VR titles on Quest- and Pico-class Android headsets. A C++17 native library embedded in the game APK collects evidence of rooting, Frida and other hooking frameworks, active debuggers, and tampering with the APK signature, pinned library hashes, in-memory code, and function prologues, then ships a privacy-conscious signed JSON report to your backend. A Unity runtime package drives periodic collection and upload, while an optional dependency-free Node.js reference server issues single-use challenges, verifies HMAC signatures, optionally validates hardware Keystore attestation chains, and scores findings into watch, review, or block verdicts that only the server applies. The design keeps ban and enforcement logic off the device so patched clients cannot silently self-clear, making it a practical integrity layer for small studios that want mod and cheat resistance without kernel drivers or third-party telemetry services.
