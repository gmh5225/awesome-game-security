Sonekk Guard 是一套免费的客户端-服务端反作弊方案，面向 Quest 与 Pico 等 Android 独立 VR 游戏。嵌入游戏 APK 的 C++17 原生库会收集 root、Frida 等 hook 框架、活跃调试器，以及对 APK 签名、库哈希固定、内存代码与函数序言的篡改证据，并以注重隐私的签名 JSON 报告发送至你的后端。Unity 运行时包驱动定期采集与上传；可选的无依赖 Node.js 参考服务器会下发一次性挑战、验证 HMAC 签名、可选验证硬件 Keystore attestation 链，并将发现项评分为 watch、review 或 block，仅由服务器应用裁决。该设计将封禁与执行逻辑保留在设备外，使被篡改的客户端无法静默自行清场，为希望在无需内核驱动或第三方遥测服务的情况下获得 mod 与作弊防护的小团队提供实用的完整性层。
