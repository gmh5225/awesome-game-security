Sonekk Guard は、Quest や Pico クラスの Android スタンドアロン VR 向けの無料クライアント・サーバー型アンチチートスタックです。ゲーム APK に組み込まれた C++17 ネイティブライブラリが、root 化、Frida などのフックフレームワーク、アクティブなデバッガー、APK 署名・ピン留めされたライブラリハッシュ・メモリ内コード・関数プロローグの改ざんの証拠を収集し、プライバシーに配慮した署名付き JSON レポートをバックエンドへ送信します。Unity ランタイムパッケージが定期的な収集とアップロードを駆動し、依存関係のない任意の Node.js 参照サーバーが使い捨てチャレンジの発行、HMAC 署名の検証、任意でハードウェア Keystore アテステーションチェーンの検証、所見の watch・review・block へのスコアリングを行い、判定はサーバー側のみが適用します。BAN と執行ロジックを端末外に置く設計により、改ざんクライアントが黙って自己クリアできず、カーネルドライバーや第三者テレメトリなしで mod やチート耐性を求める小規模スタジオ向けの実用的な整合性レイヤーとなります。
