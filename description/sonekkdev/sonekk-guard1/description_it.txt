Sonekk Guard è uno stack anti-cheat client-server gratuito pensato per titoli VR standalone su visori Android di classe Quest e Pico. Una libreria nativa C++17 integrata nell’APK del gioco raccoglie prove di root, Frida e altri framework di hooking, debugger attivi e manomissioni della firma APK, hash di librerie pinati, codice in memoria e prologhi di funzione, quindi invia al backend un report JSON firmato e attento alla privacy. Un pacchetto runtime Unity gestisce raccolta e upload periodici, mentre un server di riferimento Node.js opzionale senza dipendenze emette sfide monouso, verifica firme HMAC, opzionalmente valida catene di attestation Keystore hardware e classifica i riscontri in verdetto watch, review o block applicato solo lato server. Il design tiene ban ed enforcement fuori dal dispositivo così i client patchati non possono auto-assolversi in silenzio: uno strato di integrità pratico per piccoli studio che vogliono resistenza a mod e cheat senza driver kernel o servizi di telemetria di terze parti.
