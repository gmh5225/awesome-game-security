Sonekk Anti-Cheat is a modular integrity and anti-cheat stack aimed at standalone Android VR titles, especially fan games in the Gorilla Tag style. It ships four optional layers you can deploy separately: Guard runs a C++ native library inside the APK to detect root, Frida, debuggers, and code hooks, then sends HMAC-signed reports to a Node reference server that scores findings and can verify Android Keystore attestation; Motion validates player movement on the server for impossible speed, flight, and teleports; Seal builds and checks ZIP manifest fingerprints of shipped APKs to catch repacks and injected libraries; and AntiADB watches mid-session settings changes that suggest ADB tampering without punishing developer mode alone. JavaScript powers the server-side modules and CLI tooling, Unity packages integrate Guard and movement reporting on device, and the design keeps bans and enforcement policy on your backend rather than trusting the client. It is intended for small studios that want practical, layered game security on Quest- and Pico-class headsets without kernel drivers or a hosted telemetry service.
