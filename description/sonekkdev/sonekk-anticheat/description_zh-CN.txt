Sonekk Anti-Cheat 是一套面向独立 Android VR 游戏（尤其是 Gorilla Tag 风格同人作品）的模块化完整性与反作弊栈。它提供四个可单独部署的可选层：Guard 在 APK 内运行 C++ 原生库，检测 root、Frida、调试器与代码 hook，并将经 HMAC 签名的报告发往 Node 参考服务器，由后者对发现项打分并可选验证 Android Keystore attestation；Motion 在服务端校验玩家移动，识别不可能的速度、飞行与瞬移；Seal 构建并校验已发布 APK 的 ZIP 清单指纹，以发现重打包与注入库；AntiADB 监控会话中暗示 ADB 篡改的系统设置变更，且不会因仅开启开发者模式而处罚。JavaScript 驱动服务端模块与 CLI 工具，Unity 包在设备上集成 Guard 与移动上报，设计将封禁与执行策略放在你的后端而非信任客户端。面向希望在 Quest、Pico 等设备上获得实用分层游戏安全、又无需内核驱动或托管遥测服务的小型工作室。
