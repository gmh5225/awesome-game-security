Sonekk Anti-Cheat는 독립형 Android VR 타이틀, 특히 Gorilla Tag 스타일 팬 게임을 겨냥한 모듈형 무결성 및 안티치트 스택입니다. 네 가지 선택적 레이어를 각각 따로 배포할 수 있습니다. Guard는 APK 내부에서 C++ 네이티브 라이브러리를 실행해 root, Frida, 디버거, 코드 후크를 탐지하고 HMAC 서명된 보고를 Node 참조 서버로 보내며, 서버가 발견 사항을 점수화하고 Android Keystore attestation 검증을 수행할 수 있습니다. Motion은 서버에서 플레이어 이동을 검증해 불가능한 속도, 비행, 텔레포트를 잡습니다. Seal은 배포 APK의 ZIP 매니페스트 지문을 만들고 검사해 리패킹과 주입 라이브러리를 탐지합니다. AntiADB는 세션 중 ADB 조작을 시사하는 설정 변경을 감시하며 개발자 모드만으로는 처벌하지 않습니다. JavaScript가 서버 측 모듈과 CLI 도구를 구동하고, Unity 패키지가 기기에서 Guard와 이동 보고를 통합합니다. 설계상 밴과 enforcement 정책은 클라이언트를 신뢰하지 않고 백엔드에 둡니다. 커널 드라이버나 호스팅 원격 측정 서비스 없이 Quest·Pico급 헤드셋에서 실용적인 계층형 게임 보안을 원하는 소규모 스튜디오를 위한 것입니다.
