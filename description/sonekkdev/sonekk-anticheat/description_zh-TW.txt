Sonekk Anti-Cheat 是一套面向獨立 Android VR 遊戲（尤其是 Gorilla Tag 風格同人作品）的模組化完整性與反作弊堆疊。它提供四個可單獨部署的可選層：Guard 在 APK 內執行 C++ 原生函式庫，偵測 root、Frida、除錯器與程式碼 hook，並將經 HMAC 簽署的報告送往 Node 參考伺服器，由後者對發現項目評分並可選驗證 Android Keystore attestation；Motion 在伺服器端驗證玩家移動，識別不可能的速度、飛行與瞬移；Seal 建立並檢查已發行 APK 的 ZIP 清單指紋，以抓出重打包與注入函式庫；AntiADB 監看連線階段中暗示 ADB 竄改的系統設定變更，且不會僅因開啟開發者模式而處罰。JavaScript 驅動伺服器端模組與 CLI 工具，Unity 套件在裝置上整合 Guard 與移動回報，設計將封禁與執行策略放在你的後端而非信任用戶端。適合希望在 Quest、Pico 等級頭戴裝置上取得實用分層遊戲安全、又無需核心驅動或託管遙測服務的小型工作室。
