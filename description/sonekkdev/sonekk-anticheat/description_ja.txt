Sonekk Anti-Cheat は、スタンドアロンの Android VR タイトル、とくに Gorilla Tag 系ファンゲーム向けのモジュール型インテグリティおよびアンチチートスタックです。四つの任意レイヤーを個別に展開できます。Guard は APK 内で C++ ネイティブライブラリを動かし、root、Frida、デバッガ、コードフックを検出し、HMAC 署名付きレポートを Node 参照サーバーへ送り、サーバー側で所見をスコア化し Android Keystore attestation の検証も可能にします。Motion はサーバー上でプレイヤー移動を検証し、不可能な速度、飛行、テレポートを検知します。Seal は配布 APK の ZIP マニフェスト指紋を構築・照合し、再パックや注入ライブラリを検出します。AntiADB はセッション中の設定変更のうち ADB 改ざんを示唆するものを監視し、開発者モードのみでは罰しない設計です。JavaScript がサーバー側モジュールと CLI ツールを担い、Unity パッケージが端末上で Guard と移動レポートを統合します。BAN と enforcement ポリシーはクライアントを信頼せずバックエンド側に置く設計です。カーネルドライバやホスト型テレメトリサービスなしで、Quest や Pico クラスのヘッドセット向けに実用的な多層ゲームセキュリティを求める小規模スタジオ向けです。
