Hyperion Engine 是一款開源遊戲引擎發行版，將跨平台建置腳本與捆綁的編輯器及執行階段內容相結合。程式碼庫以 C++ 為主（含 Clang 格式化與 tidy 設定），透過 JSON 引擎與全域設定驅動桌面與行動平台，並支援著色器與裝置分級設定。創作端提供編輯器 Gizmo、場景實體圖示（光照、相機、探針、霧、光照貼圖與粒子等），以及自訂 .hmf 資源格式，用於材質、Prefab 與網格資料，並包含索引緩衝、頂點緩衝與 BVH 資料區塊。執行階段範例側重骨骼動畫，透過命名片段與逐骨骼關鍵影格軌道呈現移動、戰鬥與武器操作。面向希望建構或檢視完整用戶端技術棧的遊戲開發者與引擎程式設計師，以及研究現代遊戲如何組織資源與動畫資料的學習者。
