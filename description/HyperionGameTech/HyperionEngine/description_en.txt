Hyperion Engine is an open-source game engine distribution that pairs cross-platform build scripts with bundled editor and runtime content. The tree shows a C++-oriented codebase (Clang format and tidy configs) driven by JSON engine and global settings for desktop and mobile, plus shader and device-tier configuration. Authoring support includes editor gizmos, scene-entity icons for lighting, cameras, probes, fog, lightmaps, and particles, and a custom .hmf asset format for materials, prefabs, and mesh data with index buffers, vertex buffers, and BVH blobs. Runtime samples emphasize skeletal animation through named clips and per-bone keyframe tracks for locomotion, combat, and weapon handling. It is aimed at game developers and engine programmers who want to build or inspect a full client stack, including those studying how modern games structure assets and animation data.
