Hyperion Engine は、クロスプラットフォーム向けビルドスクリプトと同梱のエディタおよびランタイムコンテンツを組み合わせたオープンソースのゲームエンジン配布版です。コードベースは C++ 中心（Clang の format および tidy 設定付き）で、デスクトップとモバイル向けに JSON のエンジン設定とグローバル設定が駆動し、シェーダーとデバイスティアの構成も含みます。制作支援としてエディタのギズモ、ライティング・カメラ・プローブ・フォグ・ライトマップ・パーティクルなどのシーンエンティティアイコン、およびマテリアル・プレハブ・メッシュデータ（インデックスバッファ、頂点バッファ、BVH ブロブ）向けのカスタム .hmf アセット形式があります。ランタイムサンプルはスケルタルアニメーションを重視し、移動・戦闘・武器操作向けの名前付きクリップとボーン単位のキーフレームトラックを示します。フルクライアントスタックの構築や調査を行うゲーム開発者・エンジンプログラマ、および現代ゲームにおけるアセットとアニメーションデータの構成を学ぶ人を対象としています。
