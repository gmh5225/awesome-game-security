RainInjectable은 Rain Anti-Cheat 패시브 옵저버를 Minecraft 1.8.9 Forge 및 Badlion Client 프로세스에 로드하는 주입 가능한 Windows 런타임입니다. C++/CMake 기반 네이티브 인젝터와 JNI 부트스트랩, Java 8 탐지 런타임을 결합하여 다른 플레이어의 killaura, 오토 블록, scaffold, 에임 관련 행동을 감시하며, 서버로 데이터를 전송하거나 게임플레이를 변경하지 않습니다. 주요 구성 요소로는 시간적 분석, 관찰 엔진, 증거 내보내기, 구성 가능한 GUI 오버레이가 있으며, 자동 밴 대신 로컬에서 검토 후보를 표시합니다. 이 프로젝트는 방어적 게임 보안 연구와 레거시 1.8.9 멀티플레이에서 클라이언트 측 치트 탐지 및 증거 수집이 필요한 승인된 환경을 대상으로 합니다.
