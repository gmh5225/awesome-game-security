RainInjectable 是一个可注入的 Windows 运行时，用于将 Rain Anti-Cheat 被动观察者加载到 Minecraft 1.8.9 Forge 与 Badlion Client 进程中。它结合了基于 C++/CMake 的原生注入器与 JNI 引导，以及 Java 8 检测运行时，用于监视其他玩家的 killaura、自动格挡、脚手架和瞄准相关行为，且不会向服务器发送数据或改变游戏玩法。核心组件包括时序分析、观察引擎、证据导出，以及可配置的 GUI 叠加层，在本地展示待审查候选对象，而非自动封禁。该项目面向防御性游戏安全研究，以及需要在旧版 1.8.9 多人环境中进行客户端作弊检测与证据收集的授权场景。
