RainInjectable 是一個可注入的 Windows 執行階段，用於將 Rain Anti-Cheat 被動觀察者載入 Minecraft 1.8.9 Forge 與 Badlion Client 程序中。它結合了以 C++/CMake 建置的原生注入器與 JNI 引導，以及 Java 8 偵測執行階段，用於監視其他玩家的 killaura、自動格擋、鷹架與瞄準相關行為，且不會向伺服器傳送資料或改變遊戲玩法。核心元件包括時序分析、觀察引擎、證據匯出，以及可設定的 GUI 覆蓋層，在本地端呈現待審查候選對象，而非自動封禁。此專案面向防禦性遊戲安全研究，以及需要在舊版 1.8.9 多人環境中進行用戶端作弊偵測與證據收集的授權場景。
