RainInjectable est un runtime Windows injectable qui charge l'observateur passif Rain Anti-Cheat dans les processus Minecraft 1.8.9 Forge et Badlion Client. Il combine un injecteur natif C++/CMake et un bootstrap JNI avec un runtime de détection Java 8 qui surveille les autres joueurs pour détecter le killaura, l'auto-block, le scaffold et les comportements liés à la visée, sans envoyer de données aux serveurs ni modifier le gameplay. Les composants clés incluent l'analyse temporelle, un moteur d'observation, l'export de preuves et des superpositions GUI configurables qui présentent localement les candidats à examen plutôt que d'émettre des bannissements automatiques. Le projet s'adresse à la recherche défensive en sécurité des jeux et aux environnements autorisés où la détection de triche côté client et la collecte de preuves sur le multijoueur legacy 1.8.9 sont nécessaires.
