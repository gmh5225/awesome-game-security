RainInjectable — это инжектируемая среда выполнения Windows, которая загружает пассивный наблюдатель Rain Anti-Cheat в процессы Minecraft 1.8.9 Forge и Badlion Client. Она сочетает нативный инжектор на C++/CMake и JNI-загрузчик с Java 8 runtime для обнаружения, который отслеживает других игроков на предмет killaura, auto-block, scaffold и поведения, связанного с прицеливанием, не отправляя данные на серверы и не изменяя геймплей. Ключевые компоненты включают временной анализ, движок наблюдения, экспорт доказательств и настраиваемые GUI-оверлеи, которые локально показывают кандидатов на проверку, а не выносят автоматические баны. Проект предназначен для исследований в области защитной безопасности игр и авторизованных сред, где требуется клиентское обнаружение читов и сбор доказательств в legacy-мультиплеере 1.8.9.
