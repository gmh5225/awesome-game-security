RainInjectable è un runtime Windows iniettabile che carica l'osservatore passivo Rain Anti-Cheat nei processi di Minecraft 1.8.9 Forge e Badlion Client. Combina un iniettore nativo C++/CMake e bootstrap JNI con un runtime di rilevamento Java 8 che monitora gli altri giocatori per killaura, auto-block, scaffold e comportamenti legati alla mira, senza inviare dati ai server né modificare il gameplay. I componenti principali includono analisi temporale, un motore di osservazione, esportazione delle prove e overlay GUI configurabili che presentano localmente i candidati da revisionare anziché emettere ban automatici. Il progetto è rivolto alla ricerca difensiva sulla sicurezza dei giochi e ad ambienti autorizzati in cui servono rilevamento delle cheat lato client e raccolta di prove nel multigiocatore legacy 1.8.9.
