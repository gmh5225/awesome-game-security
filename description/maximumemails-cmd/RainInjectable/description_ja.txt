RainInjectable は、Rain Anti-Cheat のパッシブオブザーバーを Minecraft 1.8.9 Forge および Badlion Client プロセスに読み込む、注入可能な Windows ランタイムです。C++/CMake 製のネイティブインジェクターと JNI ブートストラップ、Java 8 検出ランタイムを組み合わせ、他プレイヤーの killaura、オートブロック、scaffold、エイム関連の挙動を監視します。サーバーへのデータ送信やゲームプレイの変更は行いません。主要コンポーネントには、時間的分析、観察エンジン、証拠のエクスポート、設定可能な GUI オーバーレイがあり、自動 BAN ではなくローカルでレビュー候補を提示します。本プロジェクトは、防御的なゲームセキュリティ研究および、レガシー 1.8.9 マルチプレイでのクライアント側チート検出と証拠収集が必要な、許可された環境を対象としています。
