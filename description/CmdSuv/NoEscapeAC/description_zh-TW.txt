本專案是一套適用於 Linux 與 Windows 的使用者模式（ring 3）反作弊與執行時期完整性框架，用於保護競技多人連線遊戲與啟動器，且不仰賴核心驅動程式。它以 C++20 與 CMake 建置，並提供精簡的 C 取向 API，支援靜態與共用函式庫建置，方便嵌入遊戲客戶端。引擎分層整合 SIMD 加速的模式掃描、具 JVM JIT 區域感知的記憶體與注入鑑識、內嵌鉤子的自動修復、覆蓋層與繪圖管線檢查、類似 PCIe DMA 的硬體訊號，以及用於偵測可疑瞄準行為的滑鼠運動學啟發式。加密的診斷黑盒傾印、供已驗證回報使用的加密工具，以及反除錯與時序檢查，共同構成深度防禦式的執行時期監控。適合需要跨平台、使用者空間反作弊工具組（含測試與示範工具）而非完整商業後端的安全開發人員與研究人員。
