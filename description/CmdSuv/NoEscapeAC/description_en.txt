This project is a user-mode (ring 3) anti-cheat and runtime integrity framework for Linux and Windows, meant to protect competitive multiplayer games and launchers without relying on kernel drivers. It is built with C++20 and CMake, and exposes a compact C-oriented API with static and shared library builds for embedding in game clients. The engine layers SIMD-accelerated pattern scanning, memory and injection forensics with awareness of JVM JIT regions, automatic inline hook repair, overlay and graphics-pipeline checks, PCIe DMA-style hardware signals, and mouse kinematics heuristics for suspicious aim behavior. Encrypted diagnostic blackbox dumps, crypto utilities for authenticated reporting, anti-debug and timing checks round out defense-in-depth runtime monitoring. It suits game security developers and researchers who want a cross-platform, user-space anti-cheat toolkit with tests and demo tooling rather than a full commercial backend.
