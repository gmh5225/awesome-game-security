本项目是一套面向 Linux 与 Windows 的用户态（ring 3）反作弊与运行时完整性框架，旨在保护竞技类多人游戏与启动器，且不依赖内核驱动。它基于 C++20 与 CMake 构建，提供面向 C 的精简 API，并支持静态库与动态库形态，便于嵌入游戏客户端。引擎分层实现 SIMD 加速的模式扫描、具备对 JVM JIT 区域感知的内存与注入取证、内联钩子的自动修复、覆盖层与图形管线检查、类 PCIe DMA 的硬件信号，以及用于识别可疑自瞄行为的鼠标运动学启发式。加密的诊断黑盒转储、用于已认证上报的加密工具，以及反调试与时序检测共同构成纵深防御式的运行期监控。适合希望获得跨平台、用户空间反作弊工具包（含测试与演示工具）而非完整商业化后端的游戏安全开发人员与研究人员。
