本プロジェクトは、Linux と Windows 向けのユーザーモード（ring 3）アンチチートおよびランタイム整合性フレームワークで、競技型マルチプレイとランチャーをカーネルドライバに依存せず保護することを目的としています。C++20 と CMake で構築され、ゲームクライアントへの組み込み向けに静的・共有ライブラリビルドを備えたコンパクトな C 指向 API を提供します。エンジンは SIMD 高速化されたパターンスキャン、JVM JIT 領域を意識したメモリおよびインジェクションのフォレンジック、インラインフックの自動修復、オーバーレイとグラフィックスパイプラインの検査、PCIe DMA 方式のハードウェアシグナル、不審なエイム挙動向けのマウス運動学ヒューリスティックを重ね合わせています。暗号化された診断用ブラックボックスダンプ、認証済みレポート用の暗号ユーティリティ、デバッグ対策とタイミング検査が、多層防御のランタイム監視を補います。商用バックエンド一式ではなく、テストとデモツールを含むクロスプラットフォームのユーザースペース向けアンチチートツールキットを求めるゲームセキュリティ開発者および研究者向けです。
