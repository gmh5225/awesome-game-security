ROM Shifter は、root 済みデバイス上でカスタム ROM のフラッシュ、バックアップ、移行を簡素化する統合 Android アプリケーションです。Kotlin と Jetpack Compose のフロントエンドと高速なカスタム shell バックエンドエンジンを組み合わせ、ROM フラッシュワークフロー、一括 APK インストール、パーティションのバックアップと復元、アプリまたはデバイスデータの移行を軽量ツール一つで処理します。主要機能には、順序付き ZIP フラッシュとワイプの自動フラッシュウィザード、並列処理による詳細なアプリのバックアップと復元、SMS、連絡先、Wi-Fi および関連設定のデバイスデータバックアップ、デブロートやアプリのシステム化、パーティションイメージ管理などのメンテナンスユーティリティが含まれます。Magisk、KernelSU、APatch、または互換フォークによる root アクセスが必要で、ROM 移行とフラッシュ後のシステムメンテナンスをローカルでオールインワン制御したい上級ユーザーおよびカスタム ROM 愛好家向けです。
