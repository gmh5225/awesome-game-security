ROM Shifter 是一款统一的 Android 应用，简化在已 Root 设备上刷机、备份以及在自定义 ROM 之间迁移的操作。它将 Kotlin 与 Jetpack Compose 前端和高速自定义 shell 后端引擎相结合，在一个轻量级工具中处理 ROM 刷写流程、批量 APK 安装、分区备份与恢复以及应用或设备数据迁移。主要功能包括用于按序刷入 ZIP 与执行擦除的自动化刷机向导、支持并行处理的细粒度应用备份与恢复、短信、联系人、Wi-Fi 及相关设置的设备数据备份，以及卸载预装、将应用系统化和分区镜像管理等维护工具。应用需要通过 Magisk、KernelSU、APatch 或兼容分支获取 Root 权限，面向需要本地一站式控制 ROM 切换与刷机后系统维护的高级用户和自定义 ROM 爱好者。
