Simple Flag Secure is a lightweight Android root module that bypasses FLAG_SECURE restrictions so users can take screenshots and record the screen in apps that normally block capture. At install time it patches the system services.jar with a standalone Java dexlib2 smali patcher, avoiding Zygisk, LSPosed, or other in-process hook frameworks. It also suppresses screenshot detection on Android 14 and newer, provides a toggleable privacy mode via volume keys, and supports Magisk, KernelSU, and APatch across many OEM ROMs. Because it modifies the Android system framework rather than injecting into individual apps, it stays compatible with root hiding and banking-app denylists while using no background services or runtime overhead. It is intended for rooted Android users and security researchers who need reliable screen capture in protected apps for testing, debugging, or mobile security analysis.
