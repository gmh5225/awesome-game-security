Simple Flag Secure は、FLAG_SECURE 制限をバイパスし、通常はキャプチャをブロックするアプリでもスクリーンショットや画面録画ができる軽量な Android root モジュールです。インストール時に、独立した Java dexlib2 smali パッチャーで system services.jar をパッチし、Zygisk、LSPosed、その他のプロセス内フックフレームワークは不要です。Android 14 以降ではスクリーンショット検出も抑制し、音量キーで切り替え可能なプライバシーモードを提供し、Magisk、KernelSU、APatch に対応して多くの OEM ROM で動作します。個々のアプリへ注入するのではなく Android システムフレームワークを変更するため、root 隠蔽や銀行アプリの拒否リストと両立し、バックグラウンドサービスや実行時オーバーヘッドもありません。保護されたアプリでのテスト、デバッグ、モバイルセキュリティ分析のために確実な画面キャプチャが必要な root ユーザーとセキュリティ研究者向けです。
