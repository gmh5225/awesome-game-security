Simple Flag Secure 是一款輕量級 Android root 模組，可繞過 FLAG_SECURE 限制，讓使用者在通常禁止截圖的應用程式中截圖和錄製螢幕。安裝時它會以獨立的 Java dexlib2 smali 修補工具修改 system services.jar，無需 Zygisk、LSPosed 或其他程序內 hook 框架。它還會在 Android 14 及更新版本上抑制截圖偵測，透過音量鍵提供可切換的隱私模式，並支援 Magisk、KernelSU 和 APatch，相容多種 OEM ROM。由於它修改的是 Android 系統框架而非注入個別應用程式，因此可與 root 隱藏和銀行類應用黑名單共存，且不占用背景服務或執行時開銷。它面向需要在受保護應用程式中進行測試、除錯或行動安全分析時可靠截圖的 root 使用者與安全研究人員。
