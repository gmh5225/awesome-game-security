Simple Flag Secure 是一款轻量级 Android root 模块，可绕过 FLAG_SECURE 限制，让用户在通常禁止截屏的应用中截图和录屏。安装时它会用独立的 Java dexlib2 smali 补丁工具修改 system services.jar，无需 Zygisk、LSPosed 或其他进程内 hook 框架。它还会在 Android 14 及更高版本上抑制截屏检测，通过音量键提供可切换的隐私模式，并支持 Magisk、KernelSU 和 APatch，兼容多种 OEM ROM。由于它修改的是 Android 系统框架而非注入单个应用，因此可与 root 隐藏和银行类应用黑名单共存，且不占用后台服务或运行时开销。它面向需要在对受保护应用进行测试、调试或移动安全分析时可靠截屏的 root 用户和安全研究人员。
