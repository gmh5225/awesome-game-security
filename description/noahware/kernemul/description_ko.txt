Kernemul은 커널 API를 재구현하고 게스트 실행을 호스트 측 핸들러로 리디렉션하여 Windows x86-64 및 ARM64 커널 드라이버와 사용자 모드 애플리케이션을 실행하는 크로스 플랫폼 에뮬레이터입니다. C++로 작성되었으며 380개 이상의 커널 함수(약 120개의 시스템 호출 포함)를 구현하고, Windows 타입 레이아웃은 커널 버전 26100의 ntoskrnl PDB 심볼에서 파생되었습니다. 두 가지 실행 백엔드를 제공합니다. Unicorn은 Linux와 Windows에서 이식 가능한 명령어 에뮬레이션과 멀티스레드 vCPU 지원을 제공하고, Windows Hypervisor Platform은 x64 Windows 호스트에서 더 빠른 네이티브 실행을 가능하게 합니다. 두 아키텍처 모두에 대해 사전 구성된 게스트 파일 시스템이 제공되어 커널 구성 요소를 수동으로 추출하지 않고도 바이너리를 에뮬레이션할 수 있습니다. 이 도구는 리버스 엔지니어링, 커널 드라이버 분석, 게임 보안 연구(제어된 샌드박스에서 안티치트 등 커널 모드 소프트웨어를 연구하는 용도 등)를 목적으로 합니다.
