Kernemul è un emulatore multipiattaforma che esegue driver kernel Windows x86-64 e ARM64 e applicazioni in user mode reimplementando le API del kernel e reindirizzando l'esecuzione guest verso handler lato host. Scritto in C++, implementa oltre 380 funzioni kernel, incluse circa 120 syscall, con layout dei tipi Windows derivati dai simboli PDB di ntoskrnl per la versione kernel 26100. Offre due backend di esecuzione: Unicorn per l'emulazione portatile delle istruzioni con supporto vCPU multithread su Linux e Windows, e Windows Hypervisor Platform per un'esecuzione nativa più rapida su host Windows x64. Sono forniti filesystem guest preconfigurati per entrambe le architetture, così i binari possono essere emulati senza estrarre manualmente i componenti del kernel. Lo strumento è pensato per reverse engineering, analisi dei driver kernel e ricerca sulla sicurezza dei giochi, ad esempio per studiare anti-cheat e altro software in kernel mode in una sandbox controllata.
