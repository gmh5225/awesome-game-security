Kernemul 是一款跨平台模拟器，通过重新实现内核 API 并将客户机执行重定向到宿主机侧处理程序，来运行 Windows x86-64 与 ARM64 内核驱动及用户态应用程序。该工具使用 C++ 编写，实现了 380 多个内核函数（含约 120 个系统调用），Windows 类型布局基于内核版本 26100 的 ntoskrnl PDB 符号推导。它提供两种执行后端：Unicorn 用于在 Linux 与 Windows 上进行可移植指令模拟并支持多线程 vCPU，Windows Hypervisor Platform 则用于在 x64 Windows 宿主机上实现更快的原生执行。两种架构均提供预置客户机文件系统，无需手动提取内核组件即可模拟二进制文件。该工具适用于逆向工程、内核驱动分析以及游戏安全研究，例如在受控沙箱中分析反作弊等内核态软件。
