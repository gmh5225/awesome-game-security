Kernemul ist ein plattformübergreifender Emulator, der Windows-x86-64- und ARM64-Kerneltreiber sowie Anwendungen im Usermode ausführt, indem er Kernel-APIs neu implementiert und die Gastausführung an Handler auf dem Host umleitet. In C++ geschrieben, implementiert er über 380 Kernelfunktionen, darunter rund 120 Syscalls, wobei Windows-Typlayouts aus ntoskrnl-PDB-Symbolen für Kernelversion 26100 abgeleitet werden. Es stehen zwei Ausführungs-Backends zur Verfügung: Unicorn für portable Befehlsemulation mit multithreaded vCPU-Unterstützung unter Linux und Windows sowie die Windows Hypervisor Platform für schnellere native Ausführung auf x64-Windows-Hosts. Vorgefertigte Gast-Dateisysteme werden für beide Architekturen bereitgestellt, sodass Binaries ohne manuelles Extrahieren von Kernelkomponenten emuliert werden können. Das Tool ist für Reverse Engineering, Kernel-Treiberanalyse und Spiele-Sicherheitsforschung gedacht, etwa zum Untersuchen von Anti-Cheat- und anderer Kernel-Mode-Software in einer kontrollierten Sandbox.
