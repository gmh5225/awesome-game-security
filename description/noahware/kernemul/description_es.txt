Kernemul es un emulador multiplataforma que ejecuta controladores de kernel Windows x86-64 y ARM64 y aplicaciones en modo usuario reimplementando las API del kernel y redirigiendo la ejecución del invitado a manejadores del lado del host. Escrito en C++, implementa más de 380 funciones del kernel, incluidas unas 120 llamadas al sistema, con diseños de tipos de Windows derivados de los símbolos PDB de ntoskrnl para la versión de kernel 26100. Ofrece dos backends de ejecución: Unicorn para emulación portable de instrucciones con soporte multihilo de vCPU en Linux y Windows, y Windows Hypervisor Platform para una ejecución nativa más rápida en hosts Windows x64. Se proporcionan sistemas de archivos de invitado prediseñados para ambas arquitecturas, de modo que los binarios pueden emularse sin extraer manualmente componentes del kernel. La herramienta está pensada para ingeniería inversa, análisis de controladores de kernel e investigación en seguridad de juegos, como estudiar anti-cheat y otro software en modo kernel en un entorno aislado controlado.
