Kernemul — кроссплатформенный эмулятор, который запускает драйверы ядра Windows x86-64 и ARM64 и пользовательские приложения, реимплементируя API ядра и перенаправляя выполнение гостя на обработчики на стороне хоста. Написан на C++, реализует более 380 функций ядра, включая около 120 системных вызовов, а раскладки типов Windows получены из символов PDB ntoskrnl для версии ядра 26100. Доступны два бэкенда выполнения: Unicorn для переносимой эмуляции инструкций с многопоточной поддержкой vCPU в Linux и Windows и Windows Hypervisor Platform для более быстрого нативного выполнения на хостах Windows x64. Для обеих архитектур предоставлены готовые гостевые файловые системы, поэтому бинарные файлы можно эмулировать без ручного извлечения компонентов ядра. Инструмент предназначен для реверс-инжиниринга, анализа драйверов ядра и исследований в области безопасности игр, например для изучения античитов и другого программного обеспечения в режиме ядра в контролируемой песочнице.
