Kernemul is a cross-platform emulator that runs Windows x86-64 and ARM64 kernel drivers and usermode applications by reimplementing kernel APIs and redirecting guest execution to host-side handlers. Written in C++, it implements over 380 kernel functions including roughly 120 syscalls, with Windows type layouts derived from ntoskrnl PDB symbols for kernel version 26100. It offers two execution backends: Unicorn for portable instruction emulation with multithreaded vCPU support on Linux and Windows, and the Windows Hypervisor Platform for faster native execution on x64 Windows hosts. Premade guest filesystems are provided for both architectures so binaries can be emulated without manually extracting kernel components. The tool is intended for reverse engineering, kernel driver analysis, and game security research such as studying anti-cheat and other kernel-mode software in a controlled sandbox.
