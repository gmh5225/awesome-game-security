Kernemul 是一款跨平台模擬器，透過重新實作核心 API 並將客體執行重新導向至主機端處理常式，來執行 Windows x86-64 與 ARM64 核心驅動程式及使用者模式應用程式。此工具以 C++ 撰寫，實作了 380 多個核心函式（含約 120 個系統呼叫），Windows 型別配置源自核心版本 26100 的 ntoskrnl PDB 符號。它提供兩種執行後端：Unicorn 用於在 Linux 與 Windows 上進行可攜式指令模擬並支援多執行緒 vCPU，Windows Hypervisor Platform 則用於在 x64 Windows 主機上實現更快的原生執行。兩種架構均提供預製客體檔案系統，無需手動提取核心元件即可模擬二進位檔。此工具適用於逆向工程、核心驅動程式分析以及遊戲安全研究，例如在受控沙箱中研究反作弊等核心模式軟體。
