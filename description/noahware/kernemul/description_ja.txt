Kernemul は、カーネル API を再実装し、ゲストの実行をホスト側ハンドラへリダイレクトすることで、Windows x86-64 および ARM64 のカーネルドライバとユーザーモードアプリケーションを実行するクロスプラットフォームエミュレータです。C++ で書かれており、380 以上のカーネル関数（約 120 のシステムコールを含む）を実装し、Windows の型レイアウトはカーネルバージョン 26100 の ntoskrnl PDB シンボルから導出しています。実行バックエンドは 2 種類あり、Unicorn は Linux と Windows 上で移植性の高い命令エミュレーションとマルチスレッド vCPU サポートを提供し、Windows Hypervisor Platform は x64 Windows ホスト上でより高速なネイティブ実行を可能にします。両アーキテクチャ向けに用意済みのゲストファイルシステムも提供され、カーネルコンポーネントを手動で抽出しなくてもバイナリをエミュレートできます。本ツールはリバースエンジニアリング、カーネルドライバ解析、ゲームセキュリティ研究（アンチチートなどのカーネルモードソフトウェアを制御されたサンドボックスで調査する用途など）を目的としています。
