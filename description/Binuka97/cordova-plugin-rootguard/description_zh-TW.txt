面向 Android 與 iOS Cordova 應用的外掛，盡力提供 root、越獄及執行時期插樁偵測。它將 Java 與 Objective-C 原生檢查與 JavaScript 橋接結合，尋找 su 以及 Magisk、KernelSU、APatch 等 root 管理器，並偵測 Frida、Frida Gadget、Gum、偵錯器狀態及相關程序痕跡。結果採用 SAFE、COMPROMISED、UNKNOWN 三態模型，避免將逾時或受限制的作業系統能力視為已遭破壞的證據，並可選用詳細證據遙測。它定位為行動應用安全與反竄改流程中的本機風險感測器，通常與伺服器端平台證明搭配使用，而非單獨用於高價值授權。
