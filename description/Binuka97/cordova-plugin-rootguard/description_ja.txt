Android および iOS 向け Cordova アプリに対し、ルート、ジェイルブレイク、ランタイム計装の検出をベストエフォートで提供する Cordova プラグインです。Java と Objective-C によるネイティブチェックを JavaScript ブリッジと組み合わせ、su や Magisk、KernelSU、APatch などのルート管理ツール、ならびに Frida、Frida Gadget、Gum、デバッガ状態、関連するプロセス痕跡を調べます。結果は SAFE、COMPROMISED、UNKNOWN の三状態モデルで示され、タイムアウトや制限された OS 機能を侵害の証明とはみなさず、任意で詳細な証拠テレメトリも利用できます。モバイルアプリのセキュリティと改ざん防止ワークフロー向けのローカルリスクセンサーとして設計されており、通常はサーバー側のプラットフォーム認証と併用し、高価値の認可に単独では用いません。
