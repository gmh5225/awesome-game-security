面向 Android 与 iOS Cordova 应用的插件，尽力提供 root、越狱及运行时插桩检测。它将 Java 与 Objective-C 原生检查与 JavaScript 桥接结合，查找 su 以及 Magisk、KernelSU、APatch 等 root 管理器，并检测 Frida、Frida Gadget、Gum、调试器状态及相关进程痕迹。结果采用 SAFE、COMPROMISED、UNKNOWN 三态模型，避免将超时或受限制的操作系统能力视为已遭破坏的证据，并可选用详细证据遥测。它定位为移动应用安全与反篡改流程中的本地风险传感器，通常与服务端平台证明配合使用，而非单独用于高价值授权。
