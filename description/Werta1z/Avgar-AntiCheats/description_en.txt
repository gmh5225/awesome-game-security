Avgar AntiCheat is a Windows-focused forensic and runtime scanner aimed at Minecraft screenshare and integrity checks. It combines PowerShell orchestration with an inline, multi-threaded C# engine loaded at runtime so administrators can run deep audits without shipping separate binaries. The tool uses WinAPI memory reads to hunt ghost-client strings, unbacked PE and manual-map style DLL injections in javaw.exe, and suspicious JVM bytecode patterns in in-memory JAR data such as Mixin or reflection hooks around combat and hitbox logic. It also correlates host artifacts including BAM registry entries, Prefetch, execution history, DNS resolver cache, and broad filesystem sweeps against large signature lists of known clients, loaders, and trace-cleaning utilities. It is intended for server staff, moderators, and game-security reviewers who need a fast, zero-dependency local triage workflow during live or post-session investigations.
