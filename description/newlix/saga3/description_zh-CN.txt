Saga3 是一个面向逆向工程与重制的项目空间，聚焦于经粉丝改版的超级任天堂《浪漫沙加3》ROM，长期目标是在原始卡带二进制之外重新实现该游戏。仓库以 Go 命令行工具为核心，用于应用 IPS 与 xdelta 补丁、反汇编 65816 事件虚拟机，并将地图、对话、战斗、精灵图及相关游戏数据导出为结构化 JSON，供分析与运行时使用。项目记录了 ROM 构建链、一致性校验门，以及大量关于战斗公式、触发器与虚拟机语义的笔记，并通过 Go 与 Ebitengine 运行可玩的壳层，配合可替换的本地化表，而非分发受版权保护的 ROM 镜像。适合需要针对经典 JRPG 二进制进行可复现提取、校验与本地化流程的 ROM 黑客、逆向工程师与游戏保存研究者。
