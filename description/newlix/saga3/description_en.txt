Saga3 is a reverse-engineering and recreation workspace focused on a fan-hacked Super Famicom Romancing SaGa 3 ROM, with the long-term goal of reimplementing the game outside the original cartridge binary. The repository is built around Go command-line tools that apply IPS and xdelta patches, disassemble the 65816 event virtual machine, and export maps, dialogue, battles, sprites, and related game data into structured JSON for analysis and runtime use. It documents ROM build chains, parity gates, and extensive notes on battle formulas, triggers, and VM semantics, and it runs a playable shell via Go and Ebitengine with swappable localization tables rather than shipping copyrighted ROM images. The project suits ROM hackers, reverse engineers, and preservationists who need reproducible extraction, verification, and localization workflows for classic JRPG binaries.
