Saga3 は、ファン改変版のスーパーファミコン『ロマンシング サ・ガ3』ROM を対象としたリバースエンジニアリングおよび再実装の作業空間であり、長期目標は元のカートリッジバイナリ以外でゲームを再構築することにある。リポジトリは Go のコマンドラインツールを中心に構築され、IPS および xdelta パッチの適用、65816 イベント仮想マシンの逆アセンブル、マップ・台詞・戦闘・スプライトおよび関連ゲームデータの構造化 JSON へのエクスポートを行い、解析とランタイム利用に供する。ROM ビルドチェーン、パリティゲート、戦闘式・トリガー・VM 意味論に関する詳細なメモを文書化し、著作権で保護された ROM イメージを配布するのではなく、Go と Ebitengine による差し替え可能なローカライズ表付きのプレイ可能なシェルを動かす。クラシック JRPG バイナリに対する再現可能な抽出・検証・ローカライズワークフローを必要とする ROM ハッカー、リバースエンジニア、保存活動家に適する。
