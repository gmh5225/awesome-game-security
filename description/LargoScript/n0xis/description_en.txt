N0xis is an agent-native reverse-engineering toolkit for x64 Windows game binaries that fuses static disassembly and decompilation with live process memory analysis in one deterministic pipeline. Written in Rust, it exposes capabilities through a stable CLI and MCP server that return versioned JSON artifacts for human review or autonomous agent workflows. Static analysis covers CFG recovery, SSA optimization, type inference, pseudo-C decompilation, and cross-references, while dynamic features include value and AOB scanning, pointer-path discovery, struct dissection, code injection, hooks, and persistent cheat tables. The same core analyzes PE files on disk and live processes via pluggable adapters, with additional support for Unity IL2CPP metadata, Lua and LuaJIT bytecode, and a config-driven N0xHUD companion window. It is aimed at game security researchers, reverse engineers, and AI agents who need explainable, reproducible analysis bridging traditional RE tools and Cheat Engine-style runtime manipulation.
