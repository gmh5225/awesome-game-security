N0xis は x64 Windows 向けゲームバイナリ用の agent ネイティブ逆解析ツールキットで、静的逆アセンブル・逆コンパイルとライブプロセスのメモリ解析を単一の決定論的パイプラインに統合します。Rust で実装され、安定した CLI と MCP サーバー経由で機能を提供し、人間によるレビューや自律 agent ワークフロー向けにバージョン付き JSON アーティファクトを返します。静的解析は CFG 復元、SSA 最適化、型推論、疑似 C 逆コンパイル、クロスリファレンスをカバーし、動的機能には値スキャンと AOB スキャン、ポインタパス探索、構造体解析、コード注入、フック、永続チートテーブルが含まれます。同一コアがプラグ可能なアダプターでディスク上の PE ファイルとライブプロセスの両方を解析し、Unity IL2CPP メタデータ、Lua および LuaJIT バイトコード、設定駆動の N0xHUD コンパニオンウィンドウにも対応します。従来の RE ツールと Cheat Engine 的なランタイム操作を橋渡しする、説明可能で再現可能な解析を必要とするゲームセキュリティ研究者、逆解析エンジニア、AI agent を対象としています。
