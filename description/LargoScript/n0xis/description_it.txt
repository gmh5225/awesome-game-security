N0xis è un toolkit di reverse engineering nativo per agent, pensato per i binari di giochi x64 su Windows, che unisce disassemblaggio e decompilazione statici con l'analisi della memoria di processi live in un'unica pipeline deterministica. Scritto in Rust, espone le capacità tramite una CLI stabile e un server MCP che restituiscono artefatti JSON versionati per revisione umana o workflow di agent autonomi. L'analisi statica copre il recupero CFG, l'ottimizzazione SSA, l'inferenza dei tipi, la decompilazione pseudo-C e i riferimenti incrociati, mentre le funzionalità dinamiche includono scansione di valori e AOB, scoperta di percorsi di puntatori, dissezione di struct, iniezione di codice, hook e tabelle cheat persistenti. Lo stesso core analizza file PE su disco e processi live tramite adapter collegabili, con supporto aggiuntivo per metadati Unity IL2CPP, bytecode Lua e LuaJIT, e una finestra companion N0xHUD guidata da configurazione. È rivolto a ricercatori di sicurezza dei giochi, reverse engineer e agent IA che necessitano di analisi spiegabili e riproducibili, a ponte tra strumenti RE tradizionali e manipolazione runtime in stile Cheat Engine.
