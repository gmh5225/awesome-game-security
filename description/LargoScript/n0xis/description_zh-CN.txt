N0xis 是一款面向 x64 Windows 游戏二进制文件的 agent 原生逆向工程工具包，在单一确定性流水线中将静态反汇编与反编译和实时进程内存分析融为一体。该工具使用 Rust 编写，通过稳定的 CLI 和 MCP 服务器暴露能力，并返回带版本号的 JSON 产物，供人工审阅或自主 agent 工作流使用。静态分析涵盖 CFG 恢复、SSA 优化、类型推断、伪 C 反编译和交叉引用；动态功能包括数值与 AOB 扫描、指针路径发现、结构体剖析、代码注入、Hook 以及持久化作弊表。同一核心通过可插拔适配器分析磁盘上的 PE 文件和实时进程，并额外支持 Unity IL2CPP 元数据、Lua 与 LuaJIT 字节码，以及由配置驱动的 N0xHUD 伴随窗口。它面向需要可解释、可复现分析的游戏安全研究人员、逆向工程师和 AI agent，在传统 RE 工具与 Cheat Engine 式运行时操控之间架起桥梁。
