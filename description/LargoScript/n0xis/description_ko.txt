N0xis는 x64 Windows 게임 바이너리를 위한 agent 네이티브 역공학 툴킷으로, 정적 디스어셈블리·디컴파일과 라이브 프로세스 메모리 분석을 하나의 결정론적 파이프라인으로 통합합니다. Rust로 작성되었으며, 안정적인 CLI와 MCP 서버를 통해 기능을 제공하고 사람의 검토나 자율 agent 워크플로를 위해 버전이 지정된 JSON 아티팩트를 반환합니다. 정적 분석은 CFG 복구, SSA 최적화, 타입 추론, 의사 C 디컴파일, 교차 참조를 다루며, 동적 기능에는 값 및 AOB 스캔, 포인터 경로 탐색, 구조체 분석, 코드 주입, 후크, 영구 치트 테이블이 포함됩니다. 동일한 코어가 플러그형 어댑터로 디스크의 PE 파일과 라이브 프로세스를 모두 분석하며, Unity IL2CPP 메타데이터, Lua 및 LuaJIT 바이트코드, 설정 기반 N0xHUD 동반 창도 지원합니다. 전통적인 RE 도구와 Cheat Engine 스타일의 런타임 조작을 잇는 설명 가능하고 재현 가능한 분석이 필요한 게임 보안 연구자, 역공학자, AI agent를 대상으로 합니다.
