N0xis 是一款面向 x64 Windows 遊戲二進位檔的 agent 原生逆向工程工具包，在單一確定性管線中將靜態反組譯與反編譯和即時行程記憶體分析融為一體。此工具以 Rust 撰寫，透過穩定的 CLI 與 MCP 伺服器提供能力，並回傳具版本號的 JSON 產物，供人工審閱或自主 agent 工作流程使用。靜態分析涵蓋 CFG 恢復、SSA 最佳化、型別推斷、偽 C 反編譯與交叉參考；動態功能包括數值與 AOB 掃描、指標路徑探索、結構體剖析、程式碼注入、Hook 以及持久化作弊表。同一核心透過可插拔適配器分析磁碟上的 PE 檔案與即時行程，並額外支援 Unity IL2CPP 中繼資料、Lua 與 LuaJIT 位元組碼，以及由設定驅動的 N0xHUD 伴隨視窗。它面向需要可解釋、可重現分析的遊戲安全研究人員、逆向工程師與 AI agent，在傳統 RE 工具與 Cheat Engine 式執行階段操控之間架起橋樑。
