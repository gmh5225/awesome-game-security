Astral AntiCheat is a Java plugin for Paper 1.21.11 servers that detects and mitigates cheating and automation in Minecraft multiplayer. It rebuilds vanilla movement physics from per-tick client data and ClientTickEndEvent, analyzes packet ordering to catch silent rotations and swaps, and runs lag-compensated combat checks for reach, auras, aim, and related exploits. Coverage spans movement, world interaction, player packets, and macros such as auto-clickers and silent hotbar swaps, with configurable block mode that cancels illegal actions and setbacks players instead of auto-kicking or banning. Staff get compact grouped alerts and detailed logs, plus commands and a GUI for monitoring, while built-in minigame handling reduces false positives from teleports, rides, and launch mechanics. The project is built with Maven and Java 21 and includes simulation tests that exercise known cheat-client behavior, making it aimed at server operators who want server-side game security rather than kernel-level anti-cheat.
