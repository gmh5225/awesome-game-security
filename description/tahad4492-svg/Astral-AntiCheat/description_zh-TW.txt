Astral AntiCheat 是一款面向 Paper 1.21.11 伺服器的 Java 外掛，用於在 Minecraft 多人遊戲中偵測並緩解作弊與自動化行為。它依每 tick 的用戶端資料與 ClientTickEndEvent 重建原版移動物理，分析封包順序以抓出靜默旋轉與物品欄切換，並對 reach、光環、自瞄等相關 exploit 執行含延遲補償的戰鬥檢查。涵蓋移動、世界互動、玩家封包以及自動連點、靜默快捷列切換等巨集行為；可設定的攔截模式會取消非法操作並對玩家 setback，而非自動踢出或封禁。工作人員可取得精簡的分組警示與詳細日誌，以及用於監控的指令與 GUI；內建的小遊戲處理可減少傳送、騎乘與發射機制造成的誤判。專案以 Maven 與 Java 21 建置，並包含針對已知作弊用戶端行為的模擬測試，面向希望採用伺服器端遊戲安全而非核心層反作弊的伺服器營運者。
