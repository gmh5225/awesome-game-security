Astral AntiCheat는 Paper 1.21.11 서버용 Java 플러그인으로, Minecraft 멀티플레이에서 치팅과 자동화를 탐지하고 완화합니다. tick 단위 클라이언트 데이터와 ClientTickEndEvent로 바닐라 이동 물리를 재구성하고, 패킷 순서를 분석해 무음 회전과 스왑을 잡으며, reach, 오라, 에임 등 관련 exploit에 대해 지연 보상 전투 검사를 수행합니다. 이동, 월드 상호작용, 플레이어 패킷, 오토클리커·무음 핫바 스왑 같은 매크로까지 다루며, 설정 가능한 차단 모드는 불법 행위를 취소하고 플레이어를 setback하며 자동 추방이나 밴은 하지 않습니다. 스태프는 간결한 그룹 알림과 상세 로그, 모니터링용 명령과 GUI를 사용할 수 있고, 내장 미니게임 처리로 텔레포트, 탑승, 발사 메커니즘에서 오탐을 줄입니다. Maven과 Java 21로 빌드되며 알려진 치트 클라이언트 동작을 검증하는 시뮬레이션 테스트를 포함해, 커널 수준이 아닌 서버 측 게임 보안을 원하는 운영자를 대상으로 합니다.
