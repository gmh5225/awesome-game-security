Astral AntiCheat 是一款面向 Paper 1.21.11 服务器的 Java 插件，用于在 Minecraft 多人游戏中检测并缓解作弊与自动化行为。它根据每 tick 的客户端数据与 ClientTickEndEvent 重建原版移动物理，分析数据包顺序以发现静默旋转与物品栏切换，并对 reach、光环、自瞄等相关 exploit 执行带延迟补偿的战斗检测。覆盖范围包括移动、世界交互、玩家数据包以及自动连点、静默快捷栏切换等宏类行为；可配置的拦截模式会取消非法操作并对玩家进行回退，而非自动踢出或封禁。管理员可获得紧凑的分组告警与详细日志，以及用于监控的命令与 GUI；内置的小游戏处理可减轻传送、骑乘与弹射机制带来的误报。项目使用 Maven 与 Java 21 构建，并包含针对已知作弊客户端行为的仿真测试，面向希望采用服务端游戏安全而非内核级反作弊的服务器运营者。
