Astral AntiCheat は Paper 1.21.11 サーバー向けの Java プラグインで、Minecraft マルチプレイにおけるチートや自動化を検出・抑止します。毎 tick のクライアントデータと ClientTickEndEvent からバニラの移動物理を再構築し、パケット順序を解析してサイレント回転やスワップを検出し、reach、オーラ、エイムなど関連 exploit に対してラグ補正付きの戦闘チェックを実行します。移動、ワールド操作、プレイヤーパケット、オートクリッカーやサイレントホットバースワップなどのマクロまでカバーし、設定可能なブロックモードでは違法な行為をキャンセルしてプレイヤーを setback し、自動キックや BAN は行いません。スタッフ向けにコンパクトなグループ化アラートと詳細ログ、監視用コマンドと GUI を提供し、組み込みのミニゲーム処理でテレポート、乗り物、打ち上げ系の誤検知を抑えます。Maven と Java 21 で構築され、既知のチートクライアント挙動を検証するシミュレーションテストを含み、カーネルレベルではなくサーバー側のゲームセキュリティを求める運営者向けです。
