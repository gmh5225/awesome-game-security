WaferACA is a Minecraft Forge 1.20.1 anti-cheat mod that detects cheating client mods used by other players on multiplayer servers and alerts when specific cheat mods are present. Written in Java with Gradle, it uses a dual-mode architecture: server-cooperative mode extracts accurate mod lists via Forge FML handshake data and custom network packets, while a fallback client-only mode applies heuristic aimbot detection by analyzing rotation smoothness, flick patterns, and tracking behavior. It can broadcast cheat alerts in public chat, expose per-player mod lists through commands and key bindings, and is aimed at Minecraft server operators and players who need lightweight anti-cheat for mod-based cheating and aim-assist in Forge environments.
