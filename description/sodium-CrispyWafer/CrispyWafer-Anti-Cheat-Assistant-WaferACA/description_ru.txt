WaferACA — это античит-мод для Minecraft Forge 1.20.1, который обнаруживает читерские клиентские моды, используемые другими игроками на мультиплеерных серверах, и предупреждает о наличии конкретных чит-модов. Написан на Java с использованием Gradle, он использует двухрежимную архитектуру: в серверно-кооперативном режиме извлекаются точные списки модов через данные рукопожатия Forge FML и пользовательские сетевые пакеты, а в резервном клиентском режиме применяется эвристическое обнаружение аимбота путём анализа плавности поворотов, паттернов флика и поведения слежения. Мод может транслировать предупреждения о читах в общий чат, показывать списки модов для каждого игрока через команды и привязки клавиш и предназначен для операторов серверов Minecraft и игроков, которым нужна лёгкая защита от читов на основе модов и aim-assist в среде Forge.
