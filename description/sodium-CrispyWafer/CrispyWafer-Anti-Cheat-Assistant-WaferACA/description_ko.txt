WaferACA는 Minecraft Forge 1.20.1용 안티치트 모드로, 멀티플레이 서버에서 다른 플레이어가 사용하는 치트 클라이언트 모드를 탐지하고 특정 치트 모드가 있을 때 경고합니다. Java와 Gradle로 작성되었으며 이중 모드 아키텍처를 사용합니다. 서버 협력 모드는 Forge FML 핸드셰이크 데이터와 사용자 지정 네트워크 패킷을 통해 정확한 모드 목록을 추출하고, 폴백 클라이언트 전용 모드는 회전 부드러움, 플릭 패턴, 추적 행동 분석을 통한 휴리스틱 에임봇 탐지를 적용합니다. 공개 채팅에 치트 경고를 방송하고, 명령어와 키 바인딩을 통해 플레이어별 모드 목록을 노출하며, Forge 환경에서 모드 기반 치트와 에임 보조에 대한 경량 안티치트가 필요한 Minecraft 서버 운영자와 플레이어를 대상으로 합니다.
