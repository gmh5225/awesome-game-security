WaferACA è un mod anti-cheat per Minecraft Forge 1.20.1 che rileva i mod client per il cheating utilizzati da altri giocatori sui server multigiocatore e avvisa quando sono presenti mod cheat specifici. Scritto in Java con Gradle, utilizza un'architettura dual-mode: la modalità cooperativa con il server estrae elenchi accurati di mod tramite dati di handshake FML di Forge e pacchetti di rete personalizzati, mentre una modalità fallback solo client applica il rilevamento euristico dell'aimbot analizzando la fluidità delle rotazioni, i pattern di flick e il comportamento di tracking. Può trasmettere avvisi di cheat nella chat pubblica, esporre elenchi di mod per giocatore tramite comandi e tasti associati, ed è rivolto agli operatori di server Minecraft e ai giocatori che necessitano di un anti-cheat leggero contro il cheating basato su mod e l'assistenza alla mira negli ambienti Forge.
