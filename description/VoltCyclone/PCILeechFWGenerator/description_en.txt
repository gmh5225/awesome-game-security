PCILeechFWGenerator is a Linux toolchain that builds custom PCIe DMA firmware bitstreams by cloning the configuration and behavior of a real donor PCI device. Written primarily in Python, it runs a three-stage pipeline that captures device identity, BARs, capabilities, and MSI-X data through VFIO and optional MMIO tracing, renders Jinja2 templates into SystemVerilog and board support files, and synthesizes the result with Xilinx Vivado for PCILeech-class FPGA hardware. It includes MSI-X emulation, register-learning from native drivers, Podman-based builds, a Textual TUI, and flashing helpers for common DMA boards. The project targets security researchers and developers working on PCIe DMA, hardware-assisted memory access, anti-cheat evasion analysis, and related reverse-engineering or firmware research on isolated lab systems.
