PCILeechFWGenerator 是一款 Linux 工具链，通过克隆真实供体 PCI 设备的配置与行为来构建自定义 PCIe DMA 固件比特流。项目主要以 Python 编写，运行三阶段流水线：借助 VFIO 与可选的 MMIO 跟踪捕获设备标识、BAR、能力与 MSI-X 数据，将 Jinja2 模板渲染为 SystemVerilog 及板级支持文件，并使用 Xilinx Vivado 为 PCILeech 类 FPGA 硬件进行综合。它包含 MSI-X 仿真、基于原生驱动的寄存器学习、基于 Podman 的构建、Textual TUI 以及面向常见 DMA 板的烧录辅助工具。该项目面向在隔离实验环境中从事 PCIe DMA、硬件辅助内存访问、反作弊规避分析及相关逆向或固件研究的安全研究人员与开发者。
