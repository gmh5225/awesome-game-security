PCILeechFWGenerator は、実在するドナー PCI デバイスの構成と挙動を複製することで、カスタム PCIe DMA ファームウェアビットストリームを構築する Linux 向けツールチェーンです。主に Python で書かれ、VFIO と任意の MMIO トレースでデバイス ID、BAR、ケイパビリティ、MSI-X データを取得し、Jinja2 テンプレートから SystemVerilog とボードサポートファイルを生成し、Xilinx Vivado で PCILeech クラスの FPGA ハードウェア向けに合成する三段階パイプラインを実行します。MSI-X エミュレーション、ネイティブドライバーによるレジスタ学習、Podman ベースのビルド、Textual TUI、一般的な DMA ボード向けフラッシュ補助機能を備えています。隔離されたラボ環境で PCIe DMA、ハードウェア支援メモリアクセス、アンチチート回避の分析、および関連するリバースエンジニアリングやファームウェア研究に取り組むセキュリティ研究者と開発者を対象としています。
