AvAAntiCheat est un plugin anti-triche léger pour les serveurs Minecraft Java basés sur l’API Bukkit/Spigot, conçu pour préserver l’équité en multijoueur. Écrit en Java et construit avec Maven, il détecte les triches courantes telles que le vol, l’escalade de murs, le combat logging, l’auto-clic, le spam de chat et certains exploits de manipulation de paquets, via un compteur de violations et une journalisation locale. Il propose des contrôles de mouvement et de combat configurables, un profilage matériel intelligent qui alterne entre calculs vectoriels stricts et contrôles plus légers selon les performances du serveur, ainsi qu’une indulgence Bedrock optionnelle via Geyser pour réduire les faux positifs. Les opérateurs de serveur l’utilisent pour surveiller, journaliser et expulser ou sanctionner les tricheurs.
