AvAAntiCheat は、Bukkit/Spigot API 上で動作する Minecraft Java サーバー向けの軽量アンチチートプラグインで、マルチプレイの公平性を保つことを目的としています。Java で記述され Maven でビルドされ、違反カウンターとローカルログを用いて、飛行、壁登り、コンバットログ、オートクリック、チャットスパム、一部のパケット操作系チートなどを検知します。設定可能な移動・戦闘チェック、サーバー性能に応じて厳密なベクトル演算と軽量チェックを切り替えるスマートなハードウェアプロファイリング、誤検知を減らすためのオプションの Geyser ベース Bedrock 緩和機能を備えています。サーバー運営者はこれを使ってチート行為を監視・記録し、キックや処罰を行えます。
