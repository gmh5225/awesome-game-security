AvAAntiCheat — лёгкий античит-плагин для серверов Minecraft Java на API Bukkit/Spigot, предназначенный для честной многопользовательской игры. Написан на Java и собирается с помощью Maven; с помощью счётчика нарушений и локального логирования обнаруживает распространённые читы: полёт, лазание по стенам, combat logging, автоклик, спам в чате и отдельные эксплойты манипуляции пакетами. Включает настраиваемые проверки движения и боя, умный профилинг оборудования, переключающийся между строгой векторной математикой и более лёгкими проверками в зависимости от производительности сервера, а также опциональную снисходительность для Bedrock через Geyser для снижения ложных срабатываний. Операторы серверов используют его для мониторинга, логирования и кика или наказания читеров.
