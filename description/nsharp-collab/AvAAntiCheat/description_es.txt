AvAAntiCheat es un plugin anticheat ligero para servidores Minecraft Java que usan la API Bukkit/Spigot, orientado a mantener el juego multijugador justo. Escrito en Java y construido con Maven, detecta trampas habituales como volar, trepar paredes, combat logging, auto-clic, spam de chat y ciertos exploits de manipulación de paquetes mediante un contador de infracciones y registro local. Incluye comprobaciones configurables de movimiento y combate, perfilado inteligente de hardware que alterna entre matemáticas vectoriales estrictas y comprobaciones más ligeras según el rendimiento del servidor, y una indulgencia opcional para Bedrock basada en Geyser para reducir falsos positivos. Los operadores lo usan para supervisar, registrar y expulsar o sancionar a los tramposos en servidores de Minecraft.
