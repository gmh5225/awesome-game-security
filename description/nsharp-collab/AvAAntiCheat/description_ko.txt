AvAAntiCheat는 Bukkit/Spigot API 기반 Minecraft Java 서버를 위한 경량 안티치트 플러그인으로, 멀티플레이어 플레이의 공정성을 유지하는 것을 목표로 합니다. Java로 작성되고 Maven으로 빌드되며, 위반 카운터와 로컬 로깅을 사용해 비행, 벽 오르기, 전투 중 로그아웃, 오토클릭, 채팅 스팸, 일부 패킷 조작 익스플로잇 등 일반적인 치트를 탐지합니다. 구성 가능한 이동 및 전투 검사, 서버 성능에 따라 엄격한 벡터 연산과 가벼운 검사 사이를 전환하는 스마트 하드웨어 프로파일링, 오탐을 줄이기 위한 선택적 Geyser 기반 Bedrock 관용 기능을 포함합니다. 서버 운영자는 이를 사용해 치터를 모니터링·기록하고 킥 또는 제재를 적용할 수 있습니다.
