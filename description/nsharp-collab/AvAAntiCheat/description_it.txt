AvAAntiCheat è un plugin anti-cheat leggero per server Minecraft Java basati sull’API Bukkit/Spigot, pensato per mantenere equo il gioco multiplayer. Scritto in Java e costruito con Maven, rileva cheat comuni come il volo, la scalata di muri, il combat logging, l’auto-click, lo spam in chat e alcuni exploit di manipolazione dei pacchetti tramite un contatore di violazioni e logging locale. Include controlli di movimento e combattimento configurabili, un profiling hardware intelligente che passa tra matematica vettoriale rigorosa e controlli più leggeri in base alle prestazioni del server, e un’opzionale indulgenza Bedrock basata su Geyser per ridurre i falsi positivi. Gli operatori lo usano per monitorare, registrare e kickare o punire i cheater sui server Minecraft.
