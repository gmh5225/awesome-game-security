AvAAntiCheat is a lightweight anti-cheat plugin for Minecraft Java servers that run on the Bukkit/Spigot API, aimed at keeping multiplayer play fair. Written in Java and built with Maven, it detects common cheats such as flying, wall climbing, combat logging, auto-clicking, chat spam, and selected packet-manipulation exploits using a violation counter and local logging. It includes configurable movement and combat checks, smart hardware profiling that switches between strict vector math and lighter checks based on server performance, and optional Geyser-based Bedrock leniency to reduce false positives. Server operators use it to monitor, log, and kick or punish cheaters on Minecraft servers.
