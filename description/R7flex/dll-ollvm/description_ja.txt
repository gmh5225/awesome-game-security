LLVMObfuscationx は、コード生成前の中間表現（IR）段階で Windows バイナリを難読化する LLVM 18 New Pass Manager プラグインです。C++ で実装され、clang、opt、llc ツールチェーンに統合して、命令置換、偽制御フロー、制御フローの平坦化、および manual-map 互換のためにグローバルコンストラクタを除去するサイズ削減パスを適用します。プリセットの tess-obf パイプラインはこれらの変換を順に実行し、per-function アノテーションマーカーにより、選択したコードの難読化をスキップ、保護、または強制できます。CRT 起動やグローバル初期化子が実行されない注入シナリオで使用される手動マップ DLL 向けに設計・テストされており、ゲームセキュリティ、Anti-Cheat、リバースエンジニアリング対策のワークフローに適しています。
