LLVMObfuscationx 是一款 LLVM 18 New Pass Manager 插件，在代码生成前的中间表示（IR）阶段对 Windows 二进制文件进行混淆。该工具用 C++ 编写，可集成到 clang、opt 和 llc 工具链中，应用指令替换、虚假控制流、控制流平坦化以及裁剪全局构造函数以适配 manual-map 的体积优化 pass。预设的 tess-obf 流水线会按顺序执行这些变换，并支持通过 per-function 注解标记对选定代码跳过、保护或强制混淆。它面向并经过手动映射 DLL 的测试，适用于注入场景下不执行 CRT 启动和全局初始化器的场景，可用于游戏安全、反作弊和逆向工程加固工作流。
