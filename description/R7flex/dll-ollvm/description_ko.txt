LLVMObfuscationx는 코드 생성 전 중간 표현(IR) 단계에서 Windows 바이너리를 난독화하는 LLVM 18 New Pass Manager 플러그인입니다. C++로 작성되었으며 clang, opt, llc 툴체인에 통합되어 명령 치환, 가짜 제어 흐름, 제어 흐름 평탄화, manual-map 호환을 위해 전역 생성자를 제거하는 크기 축소 pass를 적용합니다. 사전 설정된 tess-obf 파이프라인은 이러한 변환을 순차적으로 실행하며, per-function 주석 마커를 통해 선택한 코드의 난독화를 건너뛰거나 보호하거나 강제할 수 있습니다. CRT 시작 및 전역 초기화가 실행되지 않는 주입 시나리오에서 사용되는 수동 매핑 DLL용으로 설계·테스트되었으며, 게임 보안, 안티치트, 리버스 엔지니어링 강화 워크플로에 적합합니다.
