LLVMObfuscationx es un plugin de LLVM 18 New Pass Manager que ofusca binarios de Windows en la etapa de representación intermedia, antes de la generación de código. Escrito en C++, se integra en la cadena de herramientas clang, opt y llc para aplicar sustitución de instrucciones, flujo de control falso, aplanamiento de flujo de control y passes de reducción de tamaño que eliminan constructores globales para compatibilidad con manual-map. El pipeline preset tess-obf ejecuta estas transformaciones en secuencia, con marcadores de anotación por función para omitir, proteger o forzar la ofuscación en código seleccionado. Está diseñado y probado para DLL mapeadas manualmente usadas en escenarios de inyección donde no se ejecutan el arranque CRT ni los inicializadores globales, lo que lo hace adecuado para flujos de trabajo de seguridad en juegos, anti-cheat y endurecimiento contra ingeniería inversa.
