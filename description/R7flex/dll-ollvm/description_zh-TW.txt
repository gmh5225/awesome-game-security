LLVMObfuscationx 是一款 LLVM 18 New Pass Manager 外掛，在程式碼產生前的中間表示（IR）階段對 Windows 二進位檔案進行混淆。此工具以 C++ 撰寫，可整合至 clang、opt 與 llc 工具鏈，套用指令替換、虛假控制流、控制流平坦化，以及移除全域建構函式以相容 manual-map 的體積精簡 pass。預設的 tess-obf 管線會依序執行這些轉換，並支援透過 per-function 註解標記，對選定程式碼跳過、保護或強制混淆。它專為並已針對手動映射 DLL 進行測試，適用於注入情境中不執行 CRT 啟動與全域初始化器的場景，可用於遊戲安全、反作弊與逆向工程強化工作流程。
