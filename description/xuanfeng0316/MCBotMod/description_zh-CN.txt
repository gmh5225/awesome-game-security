MCBotMod 是面向 Minecraft Java 版的 Fabric 模组，通过 TCP 与 JSON 远程 API 暴露实时游戏客户端，而非模拟数据包或运行无头客户端。任何支持套接字的语言编写的外部程序均可驱动移动、视角、方块、实体、物品栏、聊天、服务器连接及相关操作，调用游戏原生客户端方法的同时保持完整渲染与 UI。实现主要采用 Kotlin 与 Java，配合 Fabric Mixins，包含 A* 寻路与并发任务处理，使人工键盘输入与自动化指令可在同一会话中共存。示例 Python 与 shell 脚本演示了通过 OpenAI 兼容工具接口进行 AI 驱动控制。面向研究机器人行为、客户端自动化，以及真实客户端自动化与多人游戏安全及反作弊系统交互方式的开发者。
