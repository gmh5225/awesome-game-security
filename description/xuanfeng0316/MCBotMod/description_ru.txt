MCBotMod — мод Fabric для Minecraft Java Edition, который предоставляет доступ к живому игровому клиенту через удалённый API на TCP и JSON, а не имитирует пакеты или работает без интерфейса. Внешние программы на любом языке с поддержкой сокетов могут управлять движением, камерой, блоками, сущностями, инвентарём, чатом, подключением к серверу и связанными действиями, вызывая нативные методы клиента игры при сохранении полного рендеринга и интерфейса. Реализация в основном на Kotlin и Java с Fabric Mixins, включает поиск пути A* и параллельную обработку задач; ввод с клавиатуры и автоматические команды могут сосуществовать в одной сессии. Примеры на Python и shell демонстрируют управление с помощью ИИ через интерфейс инструментов, совместимый с OpenAI. Предназначен для разработчиков, изучающих поведение ботов, автоматизацию клиента и взаимодействие автоматизации реального клиента с безопасностью мультиплеера и античит-системами.
