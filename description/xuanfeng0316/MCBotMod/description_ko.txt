MCBotMod는 Minecraft Java Edition용 Fabric 모드로, 패킷을 시뮬레이션하거나 헤드리스로 실행하는 대신 TCP와 JSON 원격 API를 통해 라이브 게임 클라이언트를 노출합니다. 소켓을 지원하는 모든 언어로 작성된 외부 프로그램이 전체 렌더링과 UI를 유지한 채 게임의 네이티브 클라이언트 메서드를 호출하여 이동, 카메라, 블록, 엔티티, 인벤토리, 채팅, 서버 연결 및 관련 동작을 구동할 수 있습니다. 구현은 주로 Kotlin과 Java, Fabric Mixins로 이루어지며 A* 경로 탐색과 동시 작업 처리를 포함하고, 사람의 키보드 입력과 자동화 명령이 같은 세션에서 공존합니다. 샘플 Python 및 shell 스크립트는 OpenAI 호환 도구 인터페이스를 통한 AI 기반 제어를 보여 줍니다. 봇 행동, 클라이언트 자동화, 실제 클라이언트 자동화가 멀티플레이 게임 보안 및 안티치트 시스템과 어떻게 상호작용하는지 연구하는 개발자를 대상으로 합니다.
