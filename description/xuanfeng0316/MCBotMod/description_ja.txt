MCBotMod は Minecraft Java Edition 向けの Fabric モッドで、パケットのシミュレーションやヘッドレス実行ではなく、TCP と JSON のリモート API を通じてライブのゲームクライアントを公開します。ソケット対応の任意の言語で書かれた外部プログラムが、完全なレンダリングと UI を維持したまま、ゲームのネイティブクライアントメソッドを呼び出して移動、カメラ、ブロック、エンティティ、インベントリ、チャット、サーバー接続などを操作できます。実装は主に Kotlin と Java と Fabric Mixins で構成され、A* 経路探索と並行タスク処理を含み、人間のキーボード入力と自動コマンドを同一セッションで共存させます。サンプルの Python と shell スクリプトは、OpenAI 互換のツールインターフェースによる AI 駆動制御を示しています。ボット挙動、クライアント自動化、および実クライアント自動化がマルチプレイのセキュリティやアンチチートとどう相互作用するかを研究する開発者向けです。
