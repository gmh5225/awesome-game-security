MCBotMod ist ein Fabric-Mod für Minecraft Java Edition, der den laufenden Spielclient über eine TCP- und JSON-Fern-API bereitstellt, statt Pakete zu simulieren oder headless zu laufen. Externe Programme in jeder Sprache mit Socket-Unterstützung können Bewegung, Kamera, Blöcke, Entitäten, Inventar, Chat, Serververbindung und verwandte Aktionen steuern, indem sie die nativen Clientmethoden des Spiels aufrufen, während vollständiges Rendering und UI erhalten bleiben. Die Implementierung basiert hauptsächlich auf Kotlin und Java mit Fabric Mixins, umfasst A*-Pfadfindung und gleichzeitige Aufgabenverarbeitung und lässt menschliche Tastatureingabe und automatisierte Befehle in derselben Sitzung koexistieren. Beispiel-Python- und Shell-Skripte demonstrieren KI-gesteuerte Steuerung über eine OpenAI-kompatible Tool-Schnittstelle. Es richtet sich an Entwickler, die Bot-Verhalten, Client-Automatisierung und die Wechselwirkung echter Client-Automatisierung mit Multiplayer-Sicherheit und Anti-Cheat-Systemen erforschen.
