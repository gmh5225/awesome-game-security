MCBotMod is a Fabric mod for Minecraft Java Edition that exposes the live game client through a TCP and JSON remote API instead of simulating packets or running headless. External programs in any language with socket support can drive movement, camera, blocks, entities, inventory, chat, server connection, and related actions by calling the game’s native client methods while full rendering and UI stay intact. The implementation is built mainly in Kotlin and Java with Fabric Mixins, includes A* pathfinding and concurrent task handling, and lets human keyboard input and automated commands coexist on the same session. Sample Python and shell scripts demonstrate AI-driven control via an OpenAI-compatible tool interface. It targets developers researching bot behavior, client automation, and how real-client automation interacts with multiplayer game security and anti-cheat systems.
