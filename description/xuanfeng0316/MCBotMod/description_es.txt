MCBotMod es un mod de Fabric para Minecraft Java Edition que expone el cliente de juego en vivo mediante una API remota TCP y JSON, en lugar de simular paquetes o ejecutarse sin interfaz. Programas externos en cualquier lenguaje con soporte de sockets pueden controlar movimiento, cámara, bloques, entidades, inventario, chat, conexión al servidor y acciones relacionadas invocando los métodos nativos del cliente del juego, manteniendo el renderizado y la interfaz completos. La implementación está construida principalmente en Kotlin y Java con Fabric Mixins, incluye pathfinding A* y manejo concurrente de tareas, y permite que la entrada de teclado humana y los comandos automatizados coexistan en la misma sesión. Scripts de ejemplo en Python y shell demuestran control impulsado por IA mediante una interfaz de herramientas compatible con OpenAI. Está dirigido a desarrolladores que investigan el comportamiento de bots, la automatización del cliente y cómo la automatización de un cliente real interactúa con la seguridad multijugador y los sistemas antitrampas.
