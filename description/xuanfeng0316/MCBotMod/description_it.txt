MCBotMod è una mod Fabric per Minecraft Java Edition che espone il client di gioco live tramite un’API remota TCP e JSON, invece di simulare pacchetti o eseguire in modalità headless. Programmi esterni in qualsiasi linguaggio con supporto socket possono guidare movimento, camera, blocchi, entità, inventario, chat, connessione al server e azioni correlate chiamando i metodi nativi del client di gioco, mantenendo rendering e interfaccia completi. L’implementazione è costruita principalmente in Kotlin e Java con Fabric Mixins, include pathfinding A* e gestione concorrente delle attività, e consente a input da tastiera umani e comandi automatizzati di coesistere nella stessa sessione. Script di esempio in Python e shell dimostrano il controllo guidato dall’IA tramite un’interfaccia strumenti compatibile con OpenAI. È rivolto a sviluppatori che studiano il comportamento dei bot, l’automazione del client e come l’automazione di un client reale interagisce con la sicurezza multigiocatore e i sistemi anti-cheat.
