本專案透過將 Nintendo Switch 的 AArch64 可執行檔靜態重編譯為 C 程式碼並連結至自訂主機執行環境，建置 Super Mario Odyssey 的原生 Windows x64 版本，而非模擬主機。以 Python 為基礎的 lifter 會預先轉譯每個遊戲函式；Clang 編譯產物，並與 Unicorn 進行差分測試以驗證指令保真度。執行環境重新實作了 Switch 系統函式庫、檔案 I/O、音訊、透過 SDL3 的輸入，以及基於 Vulkan 的 NVN 風格圖形與 Maxwell 至 SPIR-V 的著色器轉換器。專案不包含遊戲資源，需自行提供已解密的 dump，適合研究靜態重編譯、Switch 二進位結構，以及商業遊戲如何在不使用 CPU 解譯器或 JIT 的情況下完成移植。
