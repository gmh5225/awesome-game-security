本プロジェクトは、Nintendo Switch の AArch64 実行ファイルを静的再コンパイルして C に変換し、カスタムホストランタイムにリンクすることで、コンソールをエミュレートするのではなく Super Mario Odyssey のネイティブ Windows x64 版を構築します。Python ベースの lifter が各ゲーム関数を事前にリフトし、Clang が結果をコンパイルし、Unicorn との差分テストで命令の忠実度を検証します。ランタイムは Switch システムライブラリ、ファイル I/O、オーディオ、SDL3 経由の入力、および Vulkan 上の NVN 風グラフィックスと Maxwell から SPIR-V へのシェーダー変換器を再実装しています。ゲームアセットは同梱せず、復号済みダンプを自分で用意する必要があり、静的再コンパイル、Switch バイナリ構造、CPU インタプリタや JIT なしで商用タイトルを移植する方法の研究に役立ちます。
