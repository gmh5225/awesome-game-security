Este proyecto construye una versión nativa de Super Mario Odyssey para Windows x64 recompilando estáticamente el ejecutable AArch64 de Nintendo Switch a C y enlazándolo con un runtime host personalizado, en lugar de emular la consola. Un lifter basado en Python traduce cada función del juego por adelantado; Clang compila el resultado mientras pruebas diferenciales contra Unicorn validan la fidelidad de las instrucciones. El runtime reimplementa bibliotecas del sistema Switch, E/S de archivos, audio, entrada mediante SDL3 y gráficos al estilo NVN sobre Vulkan con un traductor de shaders de Maxwell a SPIR-V. No incluye recursos del juego y espera que aportes tu propio volcado descifrado, lo que resulta útil para estudiar la recompilación estática, la estructura binaria de Switch y cómo pueden portarse títulos comerciales sin intérprete de CPU ni JIT.
