Questo progetto costruisce una versione nativa Windows x64 di Super Mario Odyssey ricompilando staticamente l’eseguibile AArch64 Nintendo Switch in C e collegandolo a un runtime host personalizzato, invece di emulare la console. Un lifter basato su Python traduce ogni funzione di gioco in anticipo; Clang compila il risultato mentre test differenziali contro Unicorn convalidano la fedeltà delle istruzioni. Il runtime reimplementa le librerie di sistema Switch, I/O su file, audio, input tramite SDL3 e grafica in stile NVN su Vulkan con un traduttore di shader da Maxwell a SPIR-V. Non include asset di gioco e presuppone che fornisca un dump decrittato proprio, risultando utile per studiare la ricompilazione statica, la struttura binaria Switch e come titoli commerciali possano essere portati senza interprete CPU o JIT.
