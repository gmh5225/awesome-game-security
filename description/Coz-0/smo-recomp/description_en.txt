This project builds a native Windows x64 version of Super Mario Odyssey by statically recompiling the Nintendo Switch AArch64 executable into C and linking it against a custom host runtime, rather than emulating the console. A Python-based lifter translates each game function ahead of time; Clang compiles the result while differential tests against Unicorn validate instruction fidelity. The runtime reimplements Switch system libraries, file I/O, audio, input via SDL3, and NVN-style graphics on Vulkan with a Maxwell-to-SPIR-V shader translator. It ships no game assets and expects you to supply your own decrypted dump, making it useful for studying static recompilation, Switch binary structure, and how commercial titles can be ported without a CPU interpreter or JIT.
