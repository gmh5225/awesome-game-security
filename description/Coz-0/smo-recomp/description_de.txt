Dieses Projekt erstellt eine native Windows-x64-Version von Super Mario Odyssey, indem die Nintendo-Switch-AArch64-Ausführungsdatei statisch nach C recompiliert und mit einer eigenen Host-Laufzeit verknüpft wird, statt die Konsole zu emulieren. Ein Python-basierter Lifter übersetzt jede Spielfunktion im Voraus; Clang kompiliert das Ergebnis, während Differentialtests gegen Unicorn die Befehlstreue prüfen. Die Laufzeit implementiert Switch-Systembibliotheken, Datei-I/O, Audio, Eingabe über SDL3 sowie NVN-ähnliche Grafik auf Vulkan mit einem Maxwell-zu-SPIR-V-Shader-Übersetzer neu. Es werden keine Spiele-Assets mitgeliefert; Sie müssen einen eigenen entschlüsselten Dump bereitstellen, was es nützlich macht, statische Recompilation, Switch-Binarstruktur und die Portierung kommerzieller Titel ohne CPU-Interpreter oder JIT zu untersuchen.
