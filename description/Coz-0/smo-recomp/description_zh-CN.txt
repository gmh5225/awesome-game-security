本项目通过将 Nintendo Switch 的 AArch64 可执行文件静态重编译为 C 代码并链接到自定义主机运行时，构建 Super Mario Odyssey 的原生 Windows x64 版本，而非模拟主机。基于 Python 的 lifter 会预先翻译每个游戏函数；Clang 编译生成代码，并与 Unicorn 进行差分测试以验证指令保真度。运行时重新实现了 Switch 系统库、文件 I/O、音频、通过 SDL3 的输入，以及基于 Vulkan 的 NVN 风格图形与 Maxwell 到 SPIR-V 的着色器转换器。项目不包含游戏资源，需自行提供已解密的 dump，适合研究静态重编译、Switch 二进制结构，以及商业游戏如何在不使用 CPU 解释器或 JIT 的情况下完成移植。
