Этот проект создаёт нативную версию Super Mario Odyssey для Windows x64, статически перекомпилируя исполняемый файл Nintendo Switch AArch64 в C и связывая его с пользовательской хост-средой выполнения, а не эмулируя консоль. Подниматель на Python заранее переводит каждую игровую функцию; Clang компилирует результат, а дифференциальные тесты с Unicorn проверяют точность инструкций. Среда выполнения заново реализует системные библиотеки Switch, файловый ввод-вывод, аудио, ввод через SDL3 и графику в стиле NVN на Vulkan с транслятором шейдеров Maxwell в SPIR-V. Игровые ресурсы не поставляются — нужен собственный расшифрованный дамп; проект полезен для изучения статической перекомпиляции, структуры бинарников Switch и переноса коммерческих игр без CPU-интерпретатора или JIT.
