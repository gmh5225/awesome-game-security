이 프로젝트는 Nintendo Switch AArch64 실행 파일을 정적으로 재컴파일하여 C로 변환하고 사용자 정의 호스트 런타임에 링크함으로써, 콘솔을 에뮬레이션하는 대신 Super Mario Odyssey의 네이티브 Windows x64 버전을 만듭니다. Python 기반 lifter가 각 게임 함수를 사전에 리프트하고, Clang이 결과를 컴파일하며, Unicorn과의 차분 테스트로 명령어 충실도를 검증합니다. 런타임은 Switch 시스템 라이브러리, 파일 I/O, 오디오, SDL3 입력, Vulkan 기반 NVN 스타일 그래픽 및 Maxwell–SPIR-V 셰이더 변환기를 재구현합니다. 게임 에셋은 포함하지 않으며 복호화된 덤프를 직접 제공해야 하며, 정적 재컴파일, Switch 바이너리 구조, CPU 인터프리터나 JIT 없이 상용 타이틀을 포팅하는 방법을 연구하는 데 유용합니다.
