Ce projet produit une version native Windows x64 de Super Mario Odyssey en recompilant statiquement l’exécutable AArch64 Nintendo Switch en C et en le liant à un runtime hôte personnalisé, plutôt qu’en émulant la console. Un lifter Python traduit chaque fonction du jeu à l’avance ; Clang compile le résultat tandis que des tests différentiels avec Unicorn valident la fidélité des instructions. Le runtime réimplémente les bibliothèques système Switch, les E/S fichiers, l’audio, l’entrée via SDL3 et des graphismes de style NVN sur Vulkan avec un traducteur de shaders Maxwell vers SPIR-V. Il n’inclut aucun asset de jeu et suppose que vous fournissez votre propre dump décrypté, ce qui le rend utile pour étudier la recompilation statique, la structure binaire Switch et la façon dont des titres commerciaux peuvent être portés sans interpréteur CPU ni JIT.
