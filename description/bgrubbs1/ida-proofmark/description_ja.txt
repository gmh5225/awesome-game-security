Proofmark は Hex-Rays IDA 向けの実験的 IDAPython プラグインで、分析者の結論を現在のカーソルアドレス上の検証可能なバイトアンカーに結び付けます。マッチングロジックは別の Python コアライブラリで実装し、各レコードの主張・メモ・最大16バイトの証拠を IDB を変更せずネットワークも使わず、データベース横の JSON サイドカーに保存します。結論の記録、一覧表示、オープンイメージに対する検証、バイナリ変更時の過去サイドカーとの比較、およびアンカーが不変または一意に再配置された場合のアドレスへのジャンプが可能です。検証は初期化済み IDB バイトを進捗表示とキャンセル付きでスキャンし、各レコードを未変更、移動候補、曖昧、未検出、不完全に分類します。ビルドやパッチをまたいで根拠となる機械語が以前の分析と一致するか追跡したいリバースエンジニアやセキュリティ研究者に適しています。
