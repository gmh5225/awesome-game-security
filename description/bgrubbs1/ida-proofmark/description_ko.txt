Proofmark는 Hex-Rays IDA용 실험적 IDAPython 플러그인으로, 분석가의 결론을 현재 커서 주소의 검증 가능한 바이트 앵커에 연결합니다. 매칭 로직은 별도의 Python 코어 라이브러리로 구현되며, 각 기록의 주장·메모·최대 16바이트 증거를 IDB를 수정하거나 네트워크를 쓰지 않고 데이터베이스 옆 JSON 사이드카에 저장합니다. 결론 캡처, 목록 조회, 열린 이미지에 대한 기록 검증, 바이너리 변경 시 이전 사이드카 비교, 앵커가 변하지 않았거나 고유하게 재배치된 경우 주소로 이동이 가능합니다. 검증은 초기화된 IDB 바이트를 진행률 표시와 취소와 함께 스캔하여 각 기록을 변경 없음, 이동 후보, 모호, 미발견, 불완전으로 분류합니다. 빌드나 패치에 걸쳐 뒷받침하는 기계어가 이전 분석과 여전히 일치하는지 추적해야 하는 리버스 엔지니어와 보안 연구자에게 적합합니다.
