Proofmark 是一款面向 Hex-Rays IDA 的實驗性 IDAPython 外掛，可將分析結論綁定到目前游標位址處可校驗的位元組錨點。核心比對邏輯由獨立的 Python 函式庫實作，每筆記錄將主張、備註及最多十六位元組的證據存入資料庫旁的 JSON 側車檔案，不修改 IDB，也不使用網路。使用者可記錄結論、列出並對照目前映像驗證記錄、在二進位檔變更時比較先前側車，並在錨點未變或唯一重定位時跳轉至對應位址。驗證過程會掃描已初始化的 IDB 位元組（支援進度顯示與取消），將每筆記錄歸類為未變更、疑似遷移、歧義、找不到或不完整。適合需要在不同建置或修補間追蹤支撐機器碼是否仍與先前分析一致之逆向工程師與安全研究人員。
