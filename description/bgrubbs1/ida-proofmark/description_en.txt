Proofmark is an experimental IDAPython plugin for Hex-Rays IDA that binds analyst conclusions to checkable byte anchors at the current cursor address. Written in Python with a separate core library for matching logic, it stores claims, notes, and up to sixteen bytes of evidence per record in a JSON sidecar beside the database without modifying the IDB or using the network. Users can capture conclusions, list and verify records against the open image, compare prior sidecars when binaries change, and jump to addresses when anchors are unchanged or uniquely relocated. Verification classifies each record as unchanged, moved candidate, ambiguous, not found, or incomplete after scanning initialized IDB bytes with progress and cancellation. It suits reverse engineers and security researchers who need to track whether supporting machine code still matches an earlier analysis across builds or patches.
