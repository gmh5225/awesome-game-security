Proofmark es un complemento experimental de IDAPython para Hex-Rays IDA que vincula las conclusiones del analista a anclas de bytes comprobables en la dirección actual del cursor. Escrito en Python con una biblioteca central aparte para la lógica de coincidencia, guarda afirmaciones, notas y hasta dieciséis bytes de evidencia por registro en un JSON auxiliar junto a la base de datos, sin modificar el IDB ni usar la red. El usuario puede capturar conclusiones, listar y verificar registros contra la imagen abierta, comparar sidecars previos cuando cambian los binarios y saltar a direcciones cuando las anclas no cambian o se reubican de forma única. La verificación clasifica cada registro como sin cambios, candidato movido, ambiguo, no encontrado o incompleto tras escanear bytes IDB inicializados con progreso y cancelación. Es adecuado para ingenieros de ingeniería inversa e investigadores de seguridad que necesitan comprobar si el código máquina de respaldo sigue coincidiendo con un análisis anterior entre compilaciones o parches.
