Proofmark è un plugin sperimentale IDAPython per Hex-Rays IDA che lega le conclusioni dell’analista ad ancore di byte verificabili all’indirizzo del cursore corrente. Scritto in Python con una libreria core separata per la logica di corrispondenza, memorizza affermazioni, note e fino a sedici byte di evidenza per record in un sidecar JSON accanto al database, senza modificare l’IDB né usare la rete. Gli utenti possono registrare conclusioni, elencare e verificare i record sull’immagine aperta, confrontare sidecar precedenti quando i binari cambiano e saltare agli indirizzi quando le ancore sono invariate o traslocate in modo univoco. La verifica classifica ogni record come invariato, candidato spostato, ambiguo, non trovato o incompleto dopo la scansione dei byte IDB inizializzati con avanzamento e annullamento. È adatto a reverse engineer e ricercatori di sicurezza che devono tracciare se il codice macchina di supporto corrisponde ancora a un’analisi precedente tra build o patch.
