Proofmark 是一款面向 Hex-Rays IDA 的实验性 IDAPython 插件，可将分析结论绑定到当前光标地址处可校验的字节锚点。核心匹配逻辑由独立的 Python 库实现，每条记录将主张、备注及最多十六字节的证据存入数据库旁的 JSON 侧车文件，不修改 IDB，也不使用网络。用户可记录结论、列出并对照当前映像校验记录、在二进制变更时比较历史侧车，并在锚点未变或唯一重定位时跳转到对应地址。校验过程会扫描已初始化的 IDB 字节（支持进度显示与取消），将每条记录归类为未变更、疑似迁移、歧义、未找到或不完整。适合需要在不同构建或补丁间追踪支撑机器码是否仍与先前分析一致逆向工程师与安全研究人员。
