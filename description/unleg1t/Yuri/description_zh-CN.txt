Yuri 是一个基于 Java 和 Gradle 的项目，用于构建自定义 Minecraft 1.8 客户端，内置启动环境与完整游戏资源。该仓库在其 launch 文件夹下包含完整的 1.8 资源索引、blockstates、models、shaders、textures、对象存储以及缓存的玩家皮肤目录。项目使用标准 Gradle wrapper 工具链，并随附 README 与 LICENSE 文件，客户端运行时布局符合基于 MCP 的 Minecraft 修改项目的典型结构。本项目面向游戏安全研究人员与开发者，用于研究 Minecraft 客户端修改、作弊客户端架构，以及在旧版 1.8.x 多人服务器上的反作弊分析。
