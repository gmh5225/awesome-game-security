Yuri 是一個以 Java 與 Gradle 建置的專案，用於打造自訂 Minecraft 1.8 用戶端，內建啟動環境與完整遊戲資源。此儲存庫在其 launch 資料夾下包含完整的 1.8 資源索引、blockstates、models、shaders、textures、物件儲存，以及快取的玩家皮膚目錄。專案使用標準 Gradle wrapper 工具鏈，並附帶 README 與 LICENSE 檔案，用戶端執行時期配置符合以 MCP 為基礎的 Minecraft 修改專案典型結構。本專案面向遊戲安全研究人員與開發者，用於研究 Minecraft 用戶端修改、作弊用戶端架構，以及在舊版 1.8.x 多人伺服器上的反作弊分析。
