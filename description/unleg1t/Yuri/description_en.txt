Yuri is a Java and Gradle project that builds a custom Minecraft 1.8 client with a bundled launch environment and complete game assets. The repository includes a full 1.8 resource index, blockstates, models, shaders, textures, object storage, and a cached player skins directory under its launch folder. It uses standard Gradle wrapper tooling and ships with README and LICENSE files alongside the client runtime layout typical of MCP-based Minecraft modifications. The project is aimed at game security researchers and developers studying Minecraft client modification, cheat client architecture, and anti-cheat analysis on legacy 1.8.x multiplayer servers.
