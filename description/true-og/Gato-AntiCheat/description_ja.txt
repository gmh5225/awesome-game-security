Gato AntiCheat は、Fabric でホストされるワールド上で戦闘ルールを強制するサーバー側 Minecraft mod で、当初 Nexia の CTS（コンバットテストスナップショット）環境向けに構築されました。Java で書かれ、Fabric Loader、Fabric API、SpongePowered Mixins を用いて、専用サーバー上で攻撃、インタラクションパケット、エンティティダメージを傍受します。mod はラグを考慮した被弾者の当たり判定履歴でリーチを検査し、攻撃角度と視線を検証し、一般的なクライアントチートの落下距離に基づいて不審なクリティカルヒットをフラグ付けします。リーチ、不正角度、クリティカルなど関連検知向けに Fabric イベントを公開し、運営者がキック、ログ、カスタム制裁を組み込めます。1.16 系コンバットスナップショットを運用するサーバー所有者や PvP 管理者は、商用クライアント attestation スタックの代わりに、軽量な参考用アンチチートおよびヒット登録ヘルパーとして利用します。
