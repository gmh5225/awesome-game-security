Gato AntiCheat — серверный мод для Minecraft, который принудительно применяет правила боя на мирах под Fabric; изначально создан для среды CTS (combat test snapshot) Nexia. Написан на Java и использует Fabric Loader, Fabric API и SpongePowered Mixins для перехвата атак, пакетов взаимодействия и урона сущностям на выделенном сервере. Мод проверяет дистанцию удара с учётом лага по истории ограничивающих параллелепipedов жертвы, проверяет углы атаки и прямую видимость и помечает подозрительные критические удары по типичным высотам падения клиентских читов. Он предоставляет события Fabric для reach, неверного угла, критов и связанных детекций, чтобы администраторы могли подключать кики, логирование или свои санкции. Владельцы серверов и администраторы PvP на боевых снапшотах в духе 1.16 используют его как лёгкий эталонный античит и помощник регистрации попаданий, а не полный коммерческий стек attestation клиента.
