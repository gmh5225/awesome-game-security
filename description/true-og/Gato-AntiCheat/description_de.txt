Gato AntiCheat ist ein serverseitiger Minecraft-Mod, der Kampfregeln auf unter Fabric gehosteten Welten durchsetzt und ursprünglich für Nexias CTS-Umgebung (Combat Test Snapshot) entwickelt wurde. Er ist in Java geschrieben und nutzt Fabric Loader, Fabric API und SpongePowered Mixins, um Angriffe, Interaktionspakete und Entity-Schaden auf dem Dedicated Server abzufangen. Der Mod prüft Reichweite anhand einer lag-bewussten Historie der Opfer-Bounding-Boxes, validiert Angriffswinkel und Sichtlinie und markiert verdächtige kritische Treffer anhand typischer Fallhöhen von Client-Cheats. Er stellt Fabric-Events für Reichweite, falsche Winkel, Crits und verwandte Erkennungen bereit, damit Betreiber Kicks, Logging oder eigene Sanktionen anbinden können. Serverbesitzer und PvP-Administratoren mit 1.16-Combat-Snapshots nutzen ihn als leichtgewichtige Referenz-Anti-Cheat- und Hit-Registrierungs-Hilfe statt eines vollständigen kommerziellen Client-Attestation-Stacks.
