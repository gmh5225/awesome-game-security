Gato AntiCheat è una mod Minecraft lato server che impone le regole di combattimento su mondi ospitati con Fabric, originariamente creata per l’ambiente CTS (combat test snapshot) di Nexia. È scritta in Java e usa Fabric Loader, Fabric API e SpongePowered Mixins per intercettare attacchi, pacchetti di interazione e danni alle entità sul server dedicato. La mod controlla la reach con una cronologia lag-aware delle bounding box delle vittime, valida angoli d’attacco e linea di vista e segnala colpi critici sospetti in base alle distanze di caduta tipiche dei cheat client. Espone eventi Fabric per reach, angolo errato, critici e rilevamenti correlati così gli operatori possono collegare kick, logging o sanzioni personalizzate. Proprietari di server e amministratori PvP su snapshot di combattimento in stile 1.16 la usano come anti-cheat di riferimento leggero e aiuto alla registrazione dei colpi, piuttosto che uno stack commerciale completo di attestation del client.
