Gato AntiCheat 是一款伺服器端 Minecraft 模組，在 Fabric 託管的世界中強制執行戰鬥規則，最初為 Nexia 的 CTS（戰鬥測試快照）環境而建置。它以 Java 撰寫，使用 Fabric Loader、Fabric API 與 SpongePowered Mixins，在專用伺服器上攔截攻擊、互動封包與實體傷害。模組以考量延遲的受害者碰撞箱歷史紀錄檢查攻擊距離，驗證攻擊角度與視線，並依常見用戶端作弊的下落距離標記可疑暴擊。它透過 Fabric 事件公開距離、錯誤角度、暴擊及相關偵測，方便營運者接入踢除、記錄或自訂制裁。執行 1.16 風格戰鬥快照的伺服器擁有者與 PvP 管理員將其作為輕量級參考反作弊與命中判定輔助，而非完整的商業用戶端 attestation 方案。
