Gato AntiCheat es un mod de Minecraft del lado del servidor que aplica reglas de combate en mundos alojados con Fabric, creado originalmente para el entorno CTS (combat test snapshot) de Nexia. Está escrito en Java y usa Fabric Loader, Fabric API y SpongePowered Mixins para interceptar ataques, paquetes de interacción y daño a entidades en el servidor dedicado. El mod comprueba el alcance con un historial de cajas delimitadoras de la víctima sensible al lag, valida ángulos de ataque y línea de visión, y marca golpes críticos sospechosos según distancias de caída habituales en trampas de cliente. Expone eventos de Fabric para alcance, ángulo incorrecto, críticos y detecciones relacionadas para que los operadores puedan conectar expulsiones, registro o sanciones personalizadas. Dueños de servidores y administradores PvP que ejecutan snapshots de combate estilo 1.16 lo usan como anti-cheat de referencia ligero y ayuda al registro de impactos, no como una pila comercial completa de attestation de cliente.
