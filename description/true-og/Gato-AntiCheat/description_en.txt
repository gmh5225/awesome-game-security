Gato AntiCheat is a server-side Minecraft mod that enforces combat rules on Fabric-hosted worlds, originally built for Nexia’s CTS (combat test snapshot) environment. It is written in Java and uses Fabric Loader, Fabric API, and SpongePowered Mixins to intercept attacks, interaction packets, and entity damage on the dedicated server. The mod checks reach with lag-aware history of victim bounding boxes, validates attack angles and line of sight, and flags suspicious critical hits based on common client cheat fall distances. It exposes Fabric events for reach, bad angle, criticals, and related detections so operators can plug in kicks, logging, or custom sanctions. Server owners and PvP administrators running 1.16-style combat snapshots use it as a lightweight reference anti-cheat and hit-registration helper rather than a full commercial client attestation stack.
