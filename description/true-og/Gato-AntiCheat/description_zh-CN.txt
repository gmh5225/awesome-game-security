Gato AntiCheat 是一款服务端 Minecraft 模组，在 Fabric 托管的世界中强制执行战斗规则，最初为 Nexia 的 CTS（战斗测试快照）环境而构建。它使用 Java 编写，依赖 Fabric Loader、Fabric API 和 SpongePowered Mixins，在专用服务器上拦截攻击、交互数据包与实体伤害。该模组通过考虑延迟的受害者碰撞箱历史记录检测攻击距离，验证攻击角度与视线，并根据常见客户端作弊的下落距离标记可疑暴击。它通过 Fabric 事件暴露距离、错误角度、暴击及相关检测，便于服主接入踢出、日志或自定义处罚。运行 1.16 风格战斗快照的服务器服主与 PvP 管理员将其用作轻量级参考反作弊与命中判定辅助，而非完整的商业客户端 attestation 方案。
