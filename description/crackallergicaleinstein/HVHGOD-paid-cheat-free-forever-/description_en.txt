This repository publishes a reconstructed, largely decompiled drop of the HVHGOD commercial game cheat that was formerly sold as paid software. The bulk of the tree is thousands of Ghidra-style C translation units split across numbered decompiled folders, together with a Windows build.ps1 script and a data/offsets.genuine.bridge file that carries game-specific memory offsets. The naming and layout point to x64 Windows user-mode client code recovered from the original binary rather than a from-scratch rewrite. It is aimed at reverse engineers and game-security researchers who want to study how a real-world cheat client is structured, how it wires offsets, and what techniques a production cheating product used.
