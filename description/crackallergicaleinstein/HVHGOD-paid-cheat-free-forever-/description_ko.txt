이 저장소는 과거 유료 소프트웨어로 판매되던 HVHGOD 상용 게임 치트의 재구성·대규모 디컴파일 공개본을 제공한다. 트리 대부분은 번호가 매겨진 디컴파일 폴더에 나뉜 수천 개의 Ghidra 스타일 C 번역 단위로 이루어져 있으며, Windows용 build.ps1 스크립트와 게임별 메모리 오프셋을 담는 data/offsets.genuine.bridge 파일이 함께 있다. 이름과 구조는 처음부터 다시 작성한 것이 아니라 원본 바이너리에서 복원된 x64 Windows 사용자 모드 클라이언트 코드를 가리킨다. 실제 치트 클라이언트 구조, 오프셋 연결 방식, 상용 치트 제품이 쓴 기법을 연구하려는 리버스 엔지니어와 게임 보안 연구자를 대상으로 한다.
