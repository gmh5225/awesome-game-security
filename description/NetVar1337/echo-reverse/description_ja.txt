Echo-reverse は、Echo バックエンド経由で稼働中のゲームやアプリケーションに接続する Windows 向けデスクトップ逆アセンブリ・リバースエンジニアリング用ワークベンチです。フロントエンドは Tauri と React、バックエンドはローカル WebSocket リレー上の AngelScript エージェントで、逆アセンブル、PE・文字列解析、メモリスキャンとウォッチ、関数エミュレーション、Unreal・Unity IL2CPP・Source 2 向けエンジン固有ツールを一つの環境に統合します。AngelScript 開発（標準テンプレート付き）、オーバーレイ設計、Frida 連携、難読化解除ヘルパー、外部エージェントが解析ワークフローを自動化できる MCP エンドポイントをサポートします。ゲームセキュリティや逆解析の現場で、ライブメモリアクセス、コード探索、スクリプト駆動の自動化を単一ワークスペースで行いたい研究者・開発者向けのプロジェクトです。
