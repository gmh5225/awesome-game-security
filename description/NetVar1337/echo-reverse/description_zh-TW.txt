Echo-reverse 是一款 Windows 桌面逆向工程工作台，透過 Echo 後端連接正在執行的遊戲與應用程式目標。前端以 Tauri 與 React 建置，後端經本地 WebSocket 中繼使用 AngelScript 代理，將反組譯、PE 與字串分析、記憶體掃描與監視、函式模擬，以及面向 Unreal、Unity IL2CPP 與 Source 2 的引擎專用工具整合在同一環境中。它支援 AngelScript 開發（含內建範本）、疊加層設計、Frida 整合、去混淆輔助，以及 MCP 端點，便於外部代理自動化分析流程。本專案面向需要在遊戲安全與逆向工作中，於單一工作區內完成即時記憶體存取、程式碼探索與腳本驅動自動化的研究人員與開發者。
