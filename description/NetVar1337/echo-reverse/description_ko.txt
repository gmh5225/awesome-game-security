Echo-reverse는 Echo 백엔드를 통해 실행 중인 게임 및 애플리케이션 대상에 연결하는 Windows 데스크톱 리버스 엔지니어링 워크벤치입니다. 프론트엔드는 Tauri와 React로, 백엔드는 로컬 WebSocket 릴레이 위의 AngelScript 에이전트로 구성되며, 디스어셈블리, PE 및 문자열 분석, 메모리 스캔과 워치, 함수 에뮬레이션, Unreal·Unity IL2CPP·Source 2용 엔진별 도구를 하나의 환경에 통합합니다. AngelScript 개발(기본 템플릿 포함), 오버레이 설계, Frida 연동, 난독화 해제 헬퍼, 외부 에이전트가 분석 워크플로를 자동화할 수 있는 MCP 엔드포인트를 지원합니다. 게임 보안 및 리버스 엔지니어링 작업에서 실시간 메모리 접근, 코드 탐색, 스크립트 기반 자동화를 단일 작업 공간에서 필요로 하는 연구자와 개발자를 대상으로 합니다.
