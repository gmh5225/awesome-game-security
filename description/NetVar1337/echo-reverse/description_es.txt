Echo-reverse es un banco de trabajo de ingeniería inversa para Windows que se conecta a juegos y aplicaciones en ejecución mediante el backend Echo. Con Tauri y React en el front-end y agentes AngelScript sobre un relé WebSocket local, unifica desensamblado, análisis de PE y cadenas, escaneo y vigilancia de memoria, emulación de funciones y herramientas específicas para Unreal, Unity IL2CPP y Source 2. Admite desarrollo en AngelScript con plantillas incluidas, diseño de overlays, integración con Frida, ayudas de desofuscación y un endpoint MCP para que agentes externos automaticen flujos de análisis. El proyecto está pensado para investigadores y desarrolladores que necesitan un único espacio de trabajo con acceso a memoria en vivo, exploración de código y automatización basada en scripts en seguridad de juegos e ingeniería inversa.
