Echo-reverse is a Windows desktop reverse-engineering workbench that connects to live game and application targets through the Echo backend. Built with Tauri and React on the front end and AngelScript agents over a local WebSocket relay, it unifies disassembly, PE and string analysis, memory scanning and watches, function emulation, and engine-specific tooling for Unreal, Unity IL2CPP, and Source 2. It supports AngelScript development with stock templates, overlay design, Frida integration, deobfuscation helpers, and an MCP endpoint so external agents can automate analysis workflows. The project targets researchers and developers who need a single workspace for live memory access, code exploration, and script-driven automation during game security and reverse-engineering work.
