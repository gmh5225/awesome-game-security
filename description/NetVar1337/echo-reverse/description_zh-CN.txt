Echo-reverse 是一款 Windows 桌面逆向工程工作台，通过 Echo 后端连接正在运行的游戏与应用程序目标。前端基于 Tauri 与 React，后端经本地 WebSocket 中继使用 AngelScript 代理，将反汇编、PE 与字符串分析、内存扫描与监视、函数仿真，以及面向 Unreal、Unity IL2CPP 与 Source 2 的引擎专用工具整合在同一环境中。它支持 AngelScript 开发（含内置模板）、叠加层设计、Frida 集成、去混淆辅助，以及 MCP 端点，便于外部代理自动化分析流程。本项目面向需要在游戏安全与逆向工作中，于单一工作区内完成实时内存访问、代码探索与脚本驱动自动化的研究人员与开发者。
