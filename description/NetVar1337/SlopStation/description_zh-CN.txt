SlopStation 是一款面向 PlayStation 4 逆向工程与游戏安全研究的 Windows 桌面工作台，在同一环境中整合主机与本地进程分析。C++ 分析引擎支持实时内存检视、Cheat Engine 风格的扫描、基于 ps4debug-NG 协议的调试、对 ELF、PE 及相关二进制文件的静态分析、基于 Hyperion 的反编译，以及基于 Unicorn 的 x86-64 仿真，用于去虚拟化与切片。配套的 Tauri v2 与 React 前端通过 Lua 5.4 脚本、内置 MCP 服务器实现自动化、主机侧抓包以及面向主机工具的 HTTP 载荷托管，暴露上述能力。面向需要经授权的主机调试、模块转储、补丁流程，以及在 PS4 及相关目标上进行脚本化或代理驱动的逆向的研究人员与分析员，并可通过 ps5debug-NG 选配 PS5 支持。
