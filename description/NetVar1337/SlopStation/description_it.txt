SlopStation è un workbench desktop Windows per il reverse engineering PlayStation 4 e la ricerca sulla sicurezza dei giochi, che unifica l'analisi della console e dei processi locali in un unico ambiente. Un motore di analisi C++ gestisce ispezione della memoria in tempo reale, scansione in stile Cheat Engine, debug tramite il protocollo ps4debug-NG, analisi statica di ELF, PE e binari correlati, decompilazione basata su Hyperion ed emulazione x86-64 basata su Unicorn per devirtualizzazione e slicing. Il front-end Tauri v2 e React fornito espone le stesse capacità tramite scripting Lua 5.4, un server MCP integrato per l'automazione, cattura pacchetti lato host e un host HTTP di payload per strumenti sulla console. È rivolto a ricercatori e analisti che necessitano di debug autorizzato sulla console, dump di moduli, flussi di patch e RE guidata da script o agenti su PS4 e target correlati, con supporto PS5 opzionale tramite ps5debug-NG.
