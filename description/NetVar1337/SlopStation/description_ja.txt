SlopStation は、PlayStation 4 のリバースエンジニアリングとゲームセキュリティ研究向けの Windows デスクトップ用ワークベンチで、コンソールとローカルプロセスの分析を一つの環境に統合します。C++ 分析エンジンがライブメモリ検査、Cheat Engine 風スキャン、ps4debug-NG プロトコル経由のデバッグ、ELF・PE など関連バイナリの静的解析、Hyperion ベースの逆コンパイル、および去仮想化とスライシング向けの Unicorn ベース x86-64 エミュレーションを担います。同梱の Tauri v2 と React フロントエンドは、Lua 5.4 スクリプト、自動化用の組み込み MCP サーバー、ホスト側パケットキャプチャ、コンソール向けツール用 HTTP ペイロードホストを通じて同じ機能を提供します。認可されたコンソールデバッグ、モジュールダンプ、パッチワークフロー、PS4 および関連ターゲット上のスクリプトまたはエージェント駆動の RE が必要な研究者とアナリスト向けで、ps5debug-NG による任意の PS5 サポートも備えます。
