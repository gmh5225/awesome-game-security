SlopStation은 PlayStation 4 리버스 엔지니어링과 게임 보안 연구를 위한 Windows 데스크톱 워크벤치로, 콘솔과 로컬 프로세스 분석을 하나의 환경에서 통합합니다. C++ 분석 엔진이 실시간 메모리 검사, Cheat Engine 스타일 스캔, ps4debug-NG 프로토콜을 통한 디버깅, ELF·PE 및 관련 바이너리 정적 분석, Hyperion 기반 디컴파일, 비가상화 및 슬라이싱을 위한 Unicorn 기반 x86-64 에뮬레이션을 수행합니다. 제공되는 Tauri v2 및 React 프런트엔드는 Lua 5.4 스크립팅, 자동화용 내장 MCP 서버, 호스트 측 패킷 캡처, 콘솔 도구용 HTTP 페이로드 호스트를 통해 동일한 기능을 제공합니다. 승인된 콘솔 디버깅, 모듈 덤핑, 패칭 워크플로, PS4 및 관련 대상에서 스크립트 또는 에이전트 기반 리버스 엔지니어링이 필요한 연구자와 분석가를 대상으로 하며, ps5debug-NG를 통한 선택적 PS5 지원을 포함합니다.
