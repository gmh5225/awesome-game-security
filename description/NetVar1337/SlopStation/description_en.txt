SlopStation is a Windows desktop workbench for PlayStation 4 reverse engineering and game security research that unifies console and local process analysis in one environment. A C++ analysis engine drives live memory inspection, Cheat Engine-style scanning, debugging over the ps4debug-NG protocol, static analysis of ELF, PE, and related binaries, Hyperion-based decompilation, and Unicorn-based x86-64 emulation for devirtualization and slicing. The shipped Tauri v2 and React front end exposes the same capabilities through Lua 5.4 scripting, a built-in MCP server for automation, host-side packet capture, and an HTTP payload host for on-console tooling. It targets researchers and analysts who need authorized console debugging, module dumping, patching workflows, and scripted or agent-driven RE on PS4 and related targets, with optional PS5 support via ps5debug-NG.
