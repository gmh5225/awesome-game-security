SlopStation 是一款面向 PlayStation 4 逆向工程與遊戲安全研究的 Windows 桌面工作台，在同一環境中整合主機與本機程序分析。C++ 分析引擎支援即時記憶體檢視、Cheat Engine 風格的掃描、透過 ps4debug-NG 協定的除錯、對 ELF、PE 及相關二進位檔的靜態分析、基於 Hyperion 的反編譯，以及基於 Unicorn 的 x86-64 模擬，用於去虛擬化與切片。隨附的 Tauri v2 與 React 前端透過 Lua 5.4 腳本、內建 MCP 伺服器實現自動化、主機端封包擷取，以及供主機工具使用的 HTTP 酬載託管，呈現上述能力。適合需要經授權的主機除錯、模組傾印、修補流程，以及在 PS4 與相關目標上進行腳本化或代理驅動逆向的研究人員與分析師，並可透過 ps5debug-NG 選用 PS5 支援。
