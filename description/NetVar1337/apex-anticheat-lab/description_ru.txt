Защитная исследовательская лаборатория античита для FPS, которая помогает командам безопасности наблюдать, оценивать и объяснять подозрительное поведение игроков в многоуровневом стеке обнаружения. Модули на Python извлекают серверные поведенческие метрики из телеметрии ввода — кинематику прицеливания, время реакции, регулярность отдачи и сигнатуры триггерботов — затем подгоняют базовые линии по когортам и ранжируют игроков для проверки аналитиками, а не для автоматического наказания. Репозиторий также содержит эвристические правила YARA для загрузчиков читов и HWID-спуферов, аудит хоста на PowerShell только для чтения драйверов, устройств PCIe и совпадений с блок-листом уязвимых драйверов, а также SQL-схемы и KPI-запросы для анализа целостности матчей и злоупотреблений аккаунтами. Документация охватывает таксономию читов в FPS и методологию обнаружения, включая калибровку порогов и требования к объяснимости. Предназначен для инженеров по безопасности игр, разработчиков античита и исследователей обнаружения, создающих конвейеры проверки на основе телеметрии для соревновательных шутеров.
