보안 팀이 계층형 탐지 스택 전반에서 의심스러운 플레이어 행동을 관찰·점수화·설명할 수 있도록 돕는 방어적 FPS 안티치트 연구 랩입니다. Python 모듈은 입력 원격 측정 데이터에서 서버 측 행동 지표(에임 키네마틱스, 반응 시간, 반동 규칙성, 트리거봇 시그니처)를 추출한 뒤 코호트별 기준선을 적합화하고, 자동 징계 대신 분석가 검토를 위해 플레이어를 순위화합니다. 이 저장소에는 치트 로더 및 HWID 스푸퍼용 휴리스틱 YARA 규칙, 드라이버·PCIe 장치·취약 드라이버 차단 목록 일치 여부를 확인하는 읽기 전용 PowerShell 호스트 조사 도구, 경기 무결성 및 계정 남용 분석용 SQL 스키마와 KPI 쿼리도 포함됩니다. 문서는 FPS 치트 분류 체계와 탐지 방법론(임계값 보정 및 설명 가능성 요건 포함)을 다룹니다. 경쟁형 슈팅 게임을 위한 원격 측정 기반 검토 파이프라인을 구축하는 게임 보안 엔지니어, 안티치트 개발자, 탐지 연구자를 대상으로 합니다.
