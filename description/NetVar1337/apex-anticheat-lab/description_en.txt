A defensive FPS anti-cheat research lab that helps security teams observe, score, and explain suspicious player behavior across a layered detection stack. Python modules extract server-side behavioral metrics from input telemetry—aim kinematics, reaction times, recoil regularity, and triggerbot signatures—then fit per-cohort baselines and rank players for analyst review rather than automatic enforcement. The repository also ships heuristic YARA rules for cheat loaders and HWID spoofers, a read-only PowerShell host survey for drivers, PCIe devices, and vulnerable-driver blocklist matches, plus SQL schemas and KPI queries for match-integrity and account-abuse analysis. Documentation covers FPS cheat taxonomy and detection methodology, including threshold calibration and explainability requirements. It is aimed at game security engineers, anti-cheat developers, and detection researchers building telemetry-driven review pipelines for competitive shooters.
