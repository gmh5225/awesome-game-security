cheat-intel 是一套開放知識庫與報告實務，用於監測公開作弊社群，並將其揭露轉化為可執行的遊戲安全情報。本儲存庫著重於 Markdown 方法論、蒐集作業手冊與週期性態勢報告，而非交付執行期軟體，但規範了以日期標記的 JSONL 或 SQLite 等結構化紀錄方式。它定義如何觀察論壇、商品列表、修補說明與官方反作弊通訊；如何依一手證據與佐證層級為主張分級；以及如何將趨勢轉為附帶信心水準與可證偽條件的具體偵測與流程行動。強調僅限合法 OSINT、歸因衛生，以及涵蓋載入器、欺騙器、DMA 與週邊作弊、訂閱交付與帳號市場的情報—偵測回饋迴路。適合需要跟上作弊市場節奏、又不仰賴謠言或未經驗證論壇傳聞的反作弊工程師、威脅研究員與執法團隊。
