drelay is a research toolkit for observing and steering live sessions of Darza's Dominion through two separate components: a Java local TCP relay that binds game server addresses on loopback to decode, log, and optionally rewrite packets before forwarding to the real server, and an in-process C++ and .NET hook injected before Main that detours targets matched by SHA-256 hashes of their IL bytes. The relay ships as a self-updating jar with operator scripts and protocol documentation, while the hook bundles MinHook, a managed bootstrap with dodge and escape solvers, and build-gated verification tied to a pinned game fingerprint so it refuses mismatched client builds. Implementation spans Java for the proxy, C++ and C# on Windows with MSVC and the .NET SDK, plus PowerShell build and offline test harnesses. It is aimed at reverse engineers and game-security researchers who need wire-level session visibility, client memory instrumentation, and documented analysis of latency-sensitive in-frame decision making rather than a modified game installation.
