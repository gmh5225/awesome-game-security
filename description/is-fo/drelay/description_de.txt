drelay ist ein Forschungs-Toolkit zum Beobachten und Steuern live laufender Sessions von Darza's Dominion über zwei getrennte Komponenten: ein lokales Java-TCP-Relais, das Spielserver-Adressen auf Loopback bindet, Pakete dekodiert, protokolliert und optional umschreibt, bevor es an den echten Server weiterleitet, sowie ein in-process C++- und .NET-Hook, der vor Main injiziert wird und Ziele per SHA-256-Hashes ihrer IL-Bytes detoured. Das Relais wird als selbstaktualisierendes Jar mit Operator-Skripten und Protokolldokumentation ausgeliefert; der Hook bündelt MinHook, ein verwaltetes Bootstrap mit Dodge- und Escape-Solvern sowie buildgebundene Verifikation an einen festen Spiel-Fingerprint, sodass abweichende Client-Builds abgelehnt werden. Die Umsetzung umfasst Java für den Proxy, C++ und C# unter Windows mit MSVC und dem .NET SDK sowie PowerShell-Build- und Offline-Test-Harnesses. Es richtet sich an Reverse Engineers und Game-Security-Forscher, die Sichtbarkeit auf Wire-Ebene, Client-Speicher-Instrumentierung und dokumentierte Analyse latenzsensitiver Entscheidungen innerhalb eines Frames brauchen – nicht an eine modifizierte Spielinstallation.
