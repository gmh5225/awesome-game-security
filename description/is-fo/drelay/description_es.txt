drelay es un kit de herramientas de investigación para observar y dirigir sesiones en vivo de Darza's Dominion mediante dos componentes separados: un relé TCP local en Java que enlaza las direcciones del servidor de juego en loopback para decodificar, registrar y opcionalmente reescribir paquetes antes de reenviarlos al servidor real, y un hook in-process en C++ y .NET inyectado antes de Main que desvía objetivos identificados por hashes SHA-256 de sus bytes IL. El relé se distribuye como un jar autoactualizable con scripts de operador y documentación de protocolo; el hook incluye MinHook, un arranque administrado con solvers dodge y escape, y verificación de compilación ligada a una huella de juego fijada, rechazando builds de cliente no coincidentes. La implementación abarca Java para el proxy, C++ y C# en Windows con MSVC y el SDK de .NET, más harnesses de compilación y pruebas offline en PowerShell. Está pensado para ingenieros inversos e investigadores de seguridad en juegos que necesitan visibilidad de sesión a nivel de cable, instrumentación de memoria del cliente y análisis documentado de decisiones sensibles a la latencia dentro del frame, no una instalación de juego modificada.
