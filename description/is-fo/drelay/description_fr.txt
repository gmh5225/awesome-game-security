drelay est une boîte à outils de recherche pour observer et orienter les sessions en direct de Darza's Dominion via deux composants distincts : un relais TCP local en Java qui lie les adresses du serveur de jeu sur la boucle locale pour décoder, journaliser et éventuellement réécrire les paquets avant de les transmettre au serveur réel, et un hook C++ et .NET in-process injecté avant Main qui détourne les cibles identifiées par des hachages SHA-256 de leurs octets IL. Le relais est livré sous forme de jar auto-mis à jour avec des scripts opérateur et une documentation de protocole ; le hook regroupe MinHook, un bootstrap managé avec des solveurs dodge et escape, et une vérification de build liée à une empreinte de jeu figée, refusant les builds client incompatibles. L'implémentation couvre Java pour le proxy, C++ et C# sous Windows avec MSVC et le SDK .NET, plus des scripts PowerShell de build et des bancs de test hors ligne. Il s'adresse aux ingénieurs reverse et chercheurs en sécurité jeu qui ont besoin d'une visibilité session au niveau fil, d'instrumentation mémoire client et d'une analyse documentée des décisions sensibles à la latence dans la frame, plutôt qu'une installation de jeu modifiée.
