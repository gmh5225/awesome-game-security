drelay — исследовательский набор инструментов для наблюдения и управления живыми сессиями Darza's Dominion через два отдельных компонента: локальное Java TCP-ретранслятор, привязывающий адреса игрового сервера на loopback для декодирования, логирования и при необходимости перезаписи пакетов перед пересылкой на реальный сервер, и in-process хук на C++ и .NET, внедряемый до Main и перехватывающий цели по SHA-256 хешам их IL-байтов. Ретранслятор поставляется как самообновляемый jar со скриптами оператора и документацией протокола; хук объединяет MinHook, управляемый bootstrap с солверами dodge и escape и проверку сборки, привязанную к зафиксированному отпечатку игры, отклоняя несовпадающие клиентские сборки. Реализация охватывает Java для прокси, C++ и C# под Windows с MSVC и .NET SDK, а также PowerShell-сборку и офлайн-тестовые стенды. Предназначен для reverse-инженеров и исследователей игровой безопасности, которым нужна видимость сессии на уровне провода, инструментирование памяти клиента и документированный разбор решений, чувствительных к задержке внутри кадра, а не модифицированная установка игры.
