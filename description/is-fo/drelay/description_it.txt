drelay è un toolkit di ricerca per osservare e guidare sessioni live di Darza's Dominion tramite due componenti distinti: un relay TCP locale in Java che lega gli indirizzi del server di gioco su loopback per decodificare, registrare e opzionalmente riscrivere i pacchetti prima di inoltrarli al server reale, e un hook in-process in C++ e .NET iniettato prima di Main che devia target individuati tramite hash SHA-256 dei loro byte IL. Il relay è distribuito come jar auto-aggiornante con script operativi e documentazione di protocollo; l'hook include MinHook, un bootstrap gestito con solver dodge ed escape, e verifica di build legata a un'impronta di gioco fissata, rifiutando build client non corrispondenti. L'implementazione copre Java per il proxy, C++ e C# su Windows con MSVC e .NET SDK, più harness PowerShell per build e test offline. È rivolto a reverse engineer e ricercatori di game security che necessitano visibilità di sessione a livello wire, strumentazione della memoria client e analisi documentata delle decisioni sensibili alla latenza intra-frame, piuttosto che un'installazione di gioco modificata.
