drelay는 Darza's Dominion의 라이브 세션을 관찰하고 조종하기 위한 연구용 툴킷으로, 두 개의 독립 컴포넌트로 구성된다. 하나는 루프백에서 게임 서버 주소에 바인드하는 Java 로컬 TCP 릴레이로, 패킷을 디코드·기록하고 필요 시 수정한 뒤 실제 서버로 전달한다. 다른 하나는 Main 이전에 주입되는 프로세스 내 C++ 및 .NET 훅으로, IL 바이트의 SHA-256 해시로 일치하는 대상을 detour한다. 릴레이는 자동 갱신 jar, 운영 스크립트, 프로토콜 문서를 제공한다. 훅은 MinHook, dodge 및 escape 솔버가 있는 관리형 부트스트랩, 고정된 게임 지문에 묶인 빌드 검증을 포함하며, 맞지 않는 클라이언트 빌드는 거부한다. 구현은 Java 프록시, Windows의 C++ 및 C#(MSVC 및 .NET SDK), PowerShell 빌드 및 오프라인 테스트 하네스에 이른다. 수정된 게임 설치가 아니라, 와이어 수준 세션 가시성, 클라이언트 메모리 계측, 프레임 내 지연에 민감한 의사결정에 대한 문서화된 분석이 필요한 리버스 엔지니어와 게임 보안 연구자를 대상으로 한다.
