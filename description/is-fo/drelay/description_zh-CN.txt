drelay 是一套研究工具，用于观察并干预《Darza's Dominion》的在线会话，由两个独立组件构成：一个在本地环回上绑定游戏服务器地址的 Java TCP 中继，可对数据包解码、记录并在转发至真实服务器前选择性改写；以及一个在 Main 之前注入的进程内 C++ 与 .NET 钩子，通过 IL 字节的 SHA-256 哈希匹配目标并 detour。中继以可自更新的 jar 形式提供，附带运维脚本与协议文档；钩子集成 MinHook、带 dodge 与 escape 求解器的托管引导程序，以及绑定固定游戏指纹的构建校验，对不匹配的客户端版本会拒绝加载。实现涵盖 Java 代理、Windows 上的 C++ 与 C#（MSVC 与 .NET SDK），以及 PowerShell 构建与离线测试框架。面向需要线路级会话可见性、客户端内存插桩，以及对帧内延迟敏感决策有文档化分析能力的安全与逆向研究人员，而非修改版游戏安装。
