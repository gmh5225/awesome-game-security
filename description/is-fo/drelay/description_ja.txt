drelay は Darza's Dominion のライブセッションを観察・誘導するための研究用ツールキットで、二つの独立コンポーネントから成る。一つはループバック上でゲームサーバーアドレスにバインドする Java 製ローカル TCP リレーで、パケットをデコード・ログし、必要なら書き換えてから本物のサーバーへ転送する。もう一つは Main より前に注入するプロセス内 C++ と .NET フックで、IL バイトの SHA-256 ハッシュで一致したターゲットを detour する。リレーは自己更新可能な jar とオペレータ用スクリプト、プロトコル文書を同梱する。フックは MinHook、dodge と escape ソルバー付きマネージドブートストラップ、固定ゲームフィンガープリントに紐づくビルド検証を束ね、不一致のクライアントビルドは拒否する。実装は Java プロキシ、Windows 上の C++ と C#（MSVC と .NET SDK）、PowerShell によるビルドとオフラインテストハーネスに及ぶ。改変インストールではなく、ワイヤレベルのセッション可視性、クライアントメモリ計装、フレーム内のレイテンシ敏感な意思決定の文書化分析を必要とするリバースエンジニアとゲームセキュリティ研究者向けである。
