drelay 是一套研究工具，用於觀察並引導《Darza's Dominion》的即時連線，由兩個獨立元件構成：一個在本地迴圈上綁定遊戲伺服器位址的 Java TCP 中繼，可對封包解碼、記錄並在轉發至真實伺服器前選擇性改寫；以及一個在 Main 之前注入的行程內 C++ 與 .NET 掛鉤，透過 IL 位元組的 SHA-256 雜湊比對目標並 detour。中繼以可自更新的 jar 形式提供，附帶維運腳本與協定文件；掛鉤整合 MinHook、含 dodge 與 escape 求解器的受控啟動程序，以及綁定固定遊戲指紋的建置驗證，對不符的用戶端版本會拒絕載入。實作涵蓋 Java 代理、Windows 上的 C++ 與 C#（MSVC 與 .NET SDK），以及 PowerShell 建置與離線測試框架。面向需要線路層級連線可見性、用戶端記憶體插樁，以及對幀內延遲敏感決策有文件化分析能力的資安與逆向研究人員，而非修改版遊戲安裝。
