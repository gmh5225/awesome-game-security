Dragons-vs-VMs は、VMProtect で保護された x64 バイナリの解析とデバーチャライズを行う研究プロジェクトおよびツールキットであり、VMProtect で保護されたシリアルチェックのサンプルを題材に実演されています。Binary Ninja と連携する Python スクリプトを提供し、仮想マシンのトレース、256 個すべての VM ハンドラのカタログ化とリネーム、dragon-tales パイプラインによるハンドラセマンティクスの IGNIL および LLVM IR へのリフト、Z3 による記号実行による簡略化された効果の復元を行います。リポジトリには、デバーチャライズされた LLVM 出力、x86・中間表現・記号ビューを備えたハンドラドキュメント、再コンパイルおよび制約求解用のユーティリティが含まれます。商用 VM ベースのコード保護の解包、理解、回避が必要なリバースエンジニアおよびゲームセキュリティ研究者を対象としています。
