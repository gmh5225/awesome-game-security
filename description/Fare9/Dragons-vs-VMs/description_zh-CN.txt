Dragons-vs-VMs 是一个用于分析和去虚拟化 VMProtect 保护的 x64 二进制文件的研究项目与工具包，以受 VMProtect 保护的序列号校验样本作为演示。它提供与 Binary Ninja 集成的 Python 脚本，用于追踪虚拟机、编目并重命名全部 256 个 VM 处理程序，通过 dragon-tales 流水线将处理程序语义提升为 IGNIL 与 LLVM IR，并使用 Z3 进行符号执行以恢复简化后的效果。该仓库包含去虚拟化后的 LLVM 输出、附带 x86、中间表示与符号视图的处理程序文档，以及用于重新编译与约束求解的实用工具。它面向需要解包、理解或绕过商业 VM 代码保护技术的逆向工程师与游戏安全研究人员。
