Dragons-vs-VMs 是一個用於分析與去虛擬化 VMProtect 保護之 x64 二進位檔的研究專案與工具包，以受 VMProtect 保護的序號驗證範例作為示範。它提供與 Binary Ninja 整合的 Python 腳本，用於追蹤虛擬機器、編目並重新命名全部 256 個 VM 處理常式，透過 dragon-tales 管線將處理常式語意提升為 IGNIL 與 LLVM IR，並使用 Z3 進行符號執行以還原簡化後的效果。此儲存庫包含去虛擬化後的 LLVM 輸出、附帶 x86、中間表示與符號檢視的處理常式文件，以及用於重新編譯與約束求解的實用工具。它面向需要解包、理解或繞過商業 VM 程式碼保護技術的逆向工程師與遊戲安全研究人員。
