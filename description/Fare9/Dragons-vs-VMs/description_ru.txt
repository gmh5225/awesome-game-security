Dragons-vs-VMs — это исследовательский проект и набор инструментов для анализа и девиртуализации x64-бинарников, защищённых VMProtect, продемонстрированный на образце проверки серийного номера с защитой VMProtect. Он предоставляет Python-скрипты, интегрирующиеся с Binary Ninja для трассировки виртуальной машины, каталогизации и переименования всех 256 обработчиков VM, подъёма семантики обработчиков через конвейер dragon-tales в IGNIL и LLVM IR, а также символического выполнения с Z3 для восстановления упрощённых эффектов. Репозиторий включает девиртуализированный вывод LLVM, документацию обработчиков с представлениями x86, промежуточными и символическими, а также утилиты для перекомпиляции и решения ограничений. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности игр, которым необходимо распаковать, понять или обойти коммерческую защиту кода на основе виртуальных машин.
