Vulcan AntiCheat Built — оригинальный плагин для сервера Minecraft, реализующий обнаружение читов на стороне клиента с нуля, а не форк существующего коммерческого античита. Написан на Java для Paper и Spigot 1.21.4+, выполняет проверки движения и боя — fly, speed, kill aura, reach, auto-clicker, no-fall — с отслеживанием игроков в памяти и настраиваемыми порогами нарушений. Персонал получает оповещения в реальном времени в консоли и в игре, поэтапные кики и баны, телепорты, откатывающие подозрительное движение, и обход по правам для доверенных игроков. Maven собирает развёртываемый JAR плагина с YAML-конфигурацией для настройки детекции, оповещений и наказаний — для владельцев серверов и разработчиков, которым нужен прозрачный, расширяемый античит, который можно изучать и изменять.
