Vulcan AntiCheat Built 是一款原创的 Minecraft 服务端插件，从零实现客户端作弊检测，而非 fork 现有商业反作弊。使用 Java 编写，面向 Paper 与 Spigot 1.21.4+，执行移动与战斗检测，包括飞行、加速、Kill Aura、距离、自动点击与无摔落等，依托内存中的玩家追踪与可配置的违规阈值。管理员可获得控制台与游戏内实时告警、分级踢出与封禁、将可疑移动拉回的安全传送，以及对受信任玩家的基于权限 bypass。Maven 构建可部署的插件 JAR，YAML 配置用于调优检测、告警与处罚，面向希望拥有透明、可扩展且可学习修改的反作弊的服务器主与开发者。
