Vulcan AntiCheat Built is an original Minecraft server plugin that implements client-side cheat detection from scratch rather than forking an existing commercial anti-cheat. Written in Java for Paper and Spigot 1.21.4+, it runs movement and combat checks including fly, speed, kill aura, reach, auto-clicker, and no-fall, backed by in-memory player tracking and configurable violation thresholds. Staff get real-time console and in-game alerts, graduated kicks and bans, teleports that setback suspicious movement, and permission-based bypass for trusted players. Maven builds a deployable plugin JAR with YAML configuration for tuning detections, alerts, and punishments, aimed at server owners and developers who want a transparent, extensible anti-cheat they can study and modify.
