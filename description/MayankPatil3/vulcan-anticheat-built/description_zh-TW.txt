Vulcan AntiCheat Built 是一款原創的 Minecraft 伺服器端插件，從零實作客戶端作弊偵測，而非 fork 現有商業反作弊。以 Java 撰寫，適用於 Paper 與 Spigot 1.21.4+，執行移動與戰鬥檢查，包含飛行、加速、Kill Aura、距離、自動點擊與無摔落等，以記憶體內的玩家追蹤與可設定的違規閾值為後援。管理員可獲得主控台與遊戲內即時警示、分級踢出與封禁、將可疑移動拉回的安全傳送，以及對受信任玩家的權限式 bypass。Maven 建置可部署的插件 JAR，以 YAML 設定調整偵測、警示與處罰，面向希望擁有透明、可擴充且可研讀修改的反作弊之伺服器主與開發者。
