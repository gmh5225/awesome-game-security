Vulcan AntiCheat Built は、既存の商用アンチチートをフォークするのではなく、一からクライアント側チート検知を実装したオリジナルの Minecraft サーバープラグインです。Java で書かれ、Paper および Spigot 1.21.4+ 向けで、フライ、スピード、Kill Aura、リーチ、オートクリッカー、ノーフォールなどの移動・戦闘チェックを、メモリ上のプレイヤー追跡と設定可能な違反閾値で支えます。スタッフはコンソールとゲーム内のリアルタイム通知、段階的なキックと BAN、疑わしい移動を巻き戻すテレポート、信頼できるプレイヤー向けの権限ベース bypass を利用できます。Maven でデプロイ可能なプラグイン JAR をビルドし、YAML で検知・アラート・処罰を調整。透明で拡張可能、学習・改変できるアンチチートを求めるサーバー運営者と開発者向けです。
