Vulcan AntiCheat Built es un plugin original para servidores Minecraft que implementa la detección de trampas del lado del cliente desde cero, en lugar de hacer fork de un anti-cheat comercial existente. Escrito en Java para Paper y Spigot 1.21.4+, ejecuta comprobaciones de movimiento y combate — fly, speed, kill aura, reach, auto-clicker, no-fall — con seguimiento de jugadores en memoria y umbrales de infracción configurables. El staff recibe alertas en tiempo real por consola y en el juego, expulsiones y baneos graduados, teletransportes que revierten movimientos sospechosos y bypass basado en permisos para jugadores de confianza. Maven genera un JAR de plugin desplegable con configuración YAML para ajustar detecciones, alertas y sanciones, orientado a dueños de servidores y desarrolladores que quieren un anti-cheat transparente y extensible que puedan estudiar y modificar.
