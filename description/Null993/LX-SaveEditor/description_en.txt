LX-SaveEditor is a standalone Android application for reading and modifying local offline role save data for the game package local.lx.offline.game. It is implemented mainly in Java as a root-privileged APK, with Python utilities for building, catalog extraction, compatibility testing, and UI regression checks against the Android SDK. The editor validates saves by JSON schema and format rules rather than pinning a single game version, and it can adjust currency, growth, inventory, equipment enhancement stars, cultivation systems, and related progress files while preserving unknown fields and server-compatible structure. Saves and restores use game-process stops, hash checks, SHA-256 backup manifests, and transactional file replacement with rollback and ZIP-based backup import and export. It targets modders, players with rooted devices, and researchers who study client-side save formats, integrity boundaries, and how offline RPG data is stored and edited outside the official client.
