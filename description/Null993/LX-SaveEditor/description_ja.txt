LX-SaveEditor は、ゲームパッケージ local.lx.offline.game のローカルオフライン役割セーブデータの読み取りと変更を行うスタンドアロンの Android アプリケーションです。主に Java で実装された root 権限付き APK であり、ビルド、カタログ抽出、互換性テスト、Android SDK に対する UI 回帰チェック用の Python ユーティリティを備えています。エディターは単一のゲームバージョンに固定せず、JSON スキーマとフォーマット規則でセーブを検証し、未知のフィールドとサーバー互換の構造を保ちながら、通貨、成長、インベントリ、装備強化の星、育成システム、関連する進行ファイルを調整できます。保存と復元ではゲームプロセスの停止、ハッシュチェック、SHA-256 バックアップマニフェスト、ロールバック付きのトランザクション型ファイル置換、および ZIP ベースのバックアップのインポートとエクスポートを行います。MOD 作者、root 化端末のプレイヤー、クライアント側セーブ形式、整合性の境界、公式クライアント外でのオフライン RPG データの保存と編集を研究する研究者を対象としています。
