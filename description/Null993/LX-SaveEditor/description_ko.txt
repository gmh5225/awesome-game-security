LX-SaveEditor는 게임 패키지 local.lx.offline.game의 로컬 오프라인 역할 저장 데이터를 읽고 수정하는 독립형 Android 애플리케이션입니다. 주로 Java로 구현된 root 권한 APK이며, 빌드, 카탈로그 추출, 호환성 테스트, Android SDK 대상 UI 회귀 검사를 위한 Python 유틸리티를 포함합니다. 편집기는 단일 게임 버전에 고정하지 않고 JSON 스키마와 형식 규칙으로 저장 파일을 검증하며, 알 수 없는 필드와 서버 호환 구조를 유지한 채 화폐, 성장, 인벤토리, 장비 강화 별, 육성 시스템 및 관련 진행 파일을 조정할 수 있습니다. 저장 및 복원 시 게임 프로세스 중지, 해시 검사, SHA-256 백업 매니페스트, 롤백이 있는 트랜잭션 방식 파일 교체, ZIP 기반 백업 가져오기 및 내보내기를 사용합니다. 모드 제작자, root 기기 사용자, 클라이언트 측 저장 형식·무결성 경계·공식 클라이언트 밖에서 오프라인 RPG 데이터가 어떻게 저장·편집되는지 연구하는 연구자를 대상으로 합니다.
