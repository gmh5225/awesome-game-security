LX Save Manager — автономное Android-приложение для резервного копирования, восстановления и управления файлами офлайн-прогресса, хранящимися в каталоге приватных данных игры на Unity. В основном оно реализовано на Java как Android-приложение, с Python-скриптами для сборки, тестирования и проверки релизов без сетевых загрузок через Gradle. Пользователи могут просматривать актуальные характеристики персонажа, вести библиотеку сохранений с метками, начинать новых персонажей после автоматического резервирования, а также импортировать и экспортировать несколько сохранений в виде ZIP-архивов, при этом импорт никогда не перезаписывает активный игровой слот. Для операций требуется root-доступ и интеграция с распространёнными root-менеджерами; резервные копии фиксируют полные манифесты файлов, проверки схемы и хеши SHA-256, с транзакционным восстановлением и откатом при сбое записи. Инструмент ориентирован на игроков и исследователей, которым нужен контролируемый доступ на уровне root к локальным данным сохранений, а не на изменение бинарника игры или систем античита.
