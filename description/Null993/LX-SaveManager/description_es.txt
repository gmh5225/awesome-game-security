LX Save Manager es una aplicación Android independiente para respaldar, restaurar y gestionar archivos de progreso offline almacenados en el directorio de datos privados de un juego basado en Unity. Está implementada principalmente en Java como app Android, con scripts en Python para compilar, probar y verificar releases sin descargas de red de Gradle. Los usuarios pueden inspeccionar estadísticas de personajes en vivo, mantener una biblioteca de partidas etiquetadas, empezar personajes nuevos tras copias automáticas, e importar o exportar varias partidas como archivos ZIP, sin que las importaciones sobrescriban la ranura activa en el juego. Las operaciones requieren acceso root e integración con gestores root habituales; las copias registran manifiestos completos de archivos, comprobaciones de esquema y hashes SHA-256, con restauración transaccional y reversión si fallan las escrituras. La herramienta va dirigida a jugadores e investigadores que necesitan acceso controlado a nivel root a datos locales de partida, en lugar de modificar el binario del juego o sistemas antitrampa.
