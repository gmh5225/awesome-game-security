LX Save Manager는 Unity 기반 게임의 비공개 데이터 디렉터리에 저장된 오프라인 게임 진행 파일을 백업·복원·관리하는 독립형 Android 애플리케이션입니다. 주로 Java로 Android 앱으로 구현되었으며, Gradle 네트워크 다운로드 없이 빌드·테스트·릴리스 검증을 수행하는 Python 스크립트도 포함합니다. 사용자는 실시간 캐릭터 스탯을 확인하고, 라벨이 붙은 세이브 라이브러리를 유지하며, 자동 백업 후 새 캐릭터를 시작할 수 있고, 여러 세이브를 ZIP 아카이브로 가져오거나 내보낼 수 있습니다. 가져오기는 게임 내 활성 슬롯을 덮어쓰지 않습니다. 작업에는 root 권한이 필요하며 일반적인 root 관리 도구와 연동됩니다. 백업은 전체 파일 매니페스트, 스키마 검사, SHA-256 해시를 기록하고, 쓰기 실패 시 트랜잭션 방식 복원과 롤백을 지원합니다. 이 도구는 게임 바이너리나 안티치트 시스템을 수정하기보다, 로컬 세이브 데이터에 대한 제어된 root 수준 접근이 필요한 플레이어와 연구자를 대상으로 합니다.
