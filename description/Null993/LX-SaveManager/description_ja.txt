LX Save Manager は、Unity ベースのゲームのプライベートデータディレクトリに保存されたオフラインのゲーム進行ファイルをバックアップ、復元、管理するためのスタンドアロン Android アプリです。主に Java で Android アプリとして実装され、Gradle のネットワークダウンロードなしでビルド、テスト、リリース検証を行う Python スクリプトも含みます。ユーザーは稼働中のキャラクター統計を確認し、ラベル付きのセーブライブラリを維持し、自動バックアップ後に新規キャラクターを開始でき、複数のセーブを ZIP アーカイブとしてインポート・エクスポートできます。インポートはゲーム内で使用中のスロットを上書きしません。操作には root 権限が必要で、一般的な root マネージャーと連携します。バックアップは完全なファイルマニフェスト、スキーマチェック、SHA-256 ハッシュを記録し、書き込み失敗時はトランザクション的な復元とロールバックを行います。本ツールは、ゲームバイナリやアンチチートを改変するのではなく、ローカルセーブデータへ root レベルで制御されたアクセスが必要なプレイヤーと研究者を対象としています。
