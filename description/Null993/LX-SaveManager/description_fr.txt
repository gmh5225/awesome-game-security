LX Save Manager est une application Android autonome pour sauvegarder, restaurer et gérer les fichiers de progression hors ligne stockés dans le répertoire de données privées d’un jeu basé sur Unity. Elle est implémentée principalement en Java comme application Android, avec des scripts Python pour la compilation, les tests et la vérification des releases sans téléchargements réseau via Gradle. Les utilisateurs peuvent consulter les statistiques de personnage en direct, maintenir une bibliothèque de sauvegardes étiquetées, démarrer de nouveaux personnages après des sauvegardes automatiques, et importer ou exporter plusieurs sauvegardes sous forme d’archives ZIP, sans que les importations n’écrasent l’emplacement actif en jeu. Les opérations nécessitent un accès root et s’intègrent aux gestionnaires root courants ; les sauvegardes enregistrent des manifestes complets de fichiers, des contrôles de schéma et des hachages SHA-256, avec restauration transactionnelle et retour arrière en cas d’échec d’écriture. L’outil s’adresse aux joueurs et chercheurs qui ont besoin d’un accès contrôlé au niveau root aux données de sauvegarde locales, plutôt que de modifier le binaire du jeu ou les systèmes anti-triche.
