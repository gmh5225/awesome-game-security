RescueX es un módulo root de Android para Magisk, KernelSU y APatch que monitoriza el comportamiento de arranque y recupera automáticamente el dispositivo cuando reinicios repetidos o tiempos de espera de inicio indican un bucle de arranque. Aplica acciones de rescate por niveles, como deshabilitar módulos sospechosos, deshabilitación completa de módulos con soporte de lista blanca, instantáneas y reversión de módulos, y un modo seguro único con restauración precisa. El proyecto está construido principalmente con scripts shell y una WebUI en JavaScript, e incluye opcionalmente un watchdog nativo en C para arm64, además de tiempos de espera de arranque adaptativos, detección de OTA y parches, comprobaciones locales de integridad SHA-256 y exportación de diagnósticos depurados. Está pensado para usuarios de Android con root y desarrolladores de módulos que necesitan una recuperación fiable sin conexión cuando módulos experimentales o defectuosos impiden que el sistema arranque correctamente.
