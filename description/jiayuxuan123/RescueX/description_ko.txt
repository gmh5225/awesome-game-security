RescueX는 Magisk, KernelSU, APatch용 Android root 모듈로, 부팅 동작을 모니터링하고 반복적인 재부팅이나 시작 타임아웃이 부팅 루프를 나타낼 때 기기를 자동으로 복구합니다. 의심 모듈 비활성화, 화이트리스트 지원 전체 모듈 비활성화, 모듈 스냅샷 및 롤백, 정밀 복원이 가능한 일회성 안전 모드 등 단계별 구조 조치를 적용합니다. 이 프로젝트는 주로 shell 스크립트와 JavaScript WebUI로 구축되었으며, 선택적으로 arm64 네이티브 C 워치독을 포함하고, 적응형 부팅 타임아웃, OTA 및 패치 감지, 로컬 SHA-256 무결성 검사, 정제된 진단 내보내기 기능을 제공합니다. 실험적이거나 결함 있는 모듈로 인해 시스템이 정상적으로 부팅되지 않을 때 신뢰할 수 있는 오프라인 복구가 필요한 root Android 사용자 및 모듈 개발자를 위한 것입니다.
