RescueX は、Magisk、KernelSU、APatch 向けの Android root モジュールで、起動動作を監視し、再起動の繰り返しや起動タイムアウトが boot loop を示す場合にデバイスを自動復旧します。疑わしいモジュールの無効化、ホワイトリスト対応の全モジュール無効化、モジュールスナップショットとロールバック、正確な復元付きのワンタイムセーフモードなど、段階的なレスキュー操作を適用します。プロジェクトは主に shell スクリプトと JavaScript WebUI で構築され、オプションで arm64 ネイティブ C ウォッチドッグを含み、適応型起動タイムアウト、OTA およびパッチ検出、ローカル SHA-256 整合性チェック、サニタイズされた診断エクスポートも提供します。実験的または故障したモジュールによりシステムが正常に起動できない場合に、信頼性の高いオフライン復旧を必要とする root 済み Android ユーザーとモジュール開発者向けです。
