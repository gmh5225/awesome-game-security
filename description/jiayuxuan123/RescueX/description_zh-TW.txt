RescueX 是一款適用於 Magisk、KernelSU 與 APatch 的 Android root 模組，可監控開機行為，並在反覆重啟或啟動逾時顯示存在開機迴圈時自動恢復裝置。它採用分層救援機制，包括停用可疑模組、支援白名單的完整模組停用、模組快照與回復，以及一次性安全模式與精確還原。專案主要使用 shell 腳本與 JavaScript WebUI 建構，可選包含 arm64 原生 C 看門狗，並提供自適應開機逾時、OTA 與修補程式偵測、本地 SHA-256 完整性檢查，以及脫敏診斷匯出。面向需要可靠離線恢復能力的已 root Android 使用者與模組開發者，適用於實驗性或故障模組導致系統無法正常開機的情境。
