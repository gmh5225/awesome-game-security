RescueX 是一款适用于 Magisk、KernelSU 和 APatch 的 Android root 模块，可监控启动行为，并在反复重启或启动超时表明存在启动循环时自动恢复设备。它采用分层救援机制，包括禁用可疑模块、支持白名单的完全模块禁用、模块快照与回滚，以及一次性安全模式与精确恢复。项目主要使用 shell 脚本和 JavaScript WebUI 构建，可选包含 arm64 原生 C 看门狗，并提供自适应启动超时、OTA 与补丁检测、本地 SHA-256 完整性校验以及脱敏诊断导出。面向需要可靠离线恢复能力的已 root Android 用户和模块开发者，适用于实验性或故障模块导致系统无法正常启动的场景。
