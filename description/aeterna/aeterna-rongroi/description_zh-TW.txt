Aeterna-rongroi 是一款面向 FiveM 社群的離線、唯讀、開源 PC 檢測工具，用於掃描 Windows 電腦上的作弊痕跡和存在風險的系統配置。它將取證結果呈現為 Found、NotFound 或 Unmeasured，而非直接給出清白或有罪的裁決，以便玩家可以自行檢測或在管理員螢幕分享會話中分享結果。該專案主要使用 Rust 建構，採用 Tauri 2 桌面應用程式和 React/TypeScript UI，並提供支援自檢和螢幕分享模式的 CLI，具備路徑遮罩和同意流程。檢測由嵌入式 YAML 規則引擎和唯讀採集器驅動，檢查 Secure Boot 配置等工件，且不對主機進行寫入或網路通訊。它面向遊戲安全人員、伺服器管理員和玩家，提供在 FiveM PC 檢測過程中透明且注重隱私的作弊痕跡檢查。
