Aeterna-rongroi は、FiveM コミュニティ向けのオフライン・読み取り専用・オープンソースの PC チェックツールで、Windows マシン上のチート痕跡やリスクのあるマシン状態をスキャンします。フォレンジック証拠を Found、NotFound、Unmeasured の結果として提示し、クリーンまたは有罪の判定を下すのではなく、プレイヤーが自己チェックしたり、管理者のスクリーンシェアセッション中に結果を共有したりできるようにします。本プロジェクトは主に Rust で構築され、Tauri 2 デスクトップアプリと React/TypeScript UI に加え、自己チェックとスクリーンシェアモード、パス秘匿、同意フローをサポートする CLI を提供します。検出は、Secure Boot の状態などのアーティファクトをホストへの書き込みやネットワーク通信なしに検査する、組み込み YAML ルールエンジンと読み取り専用コレクターによって駆動されます。FiveM の PC チェック時に、透明性がありプライバシーに配慮したチート痕跡検査を必要とするゲームセキュリティスタッフ、サーバー管理者、プレイヤーを対象としています。
