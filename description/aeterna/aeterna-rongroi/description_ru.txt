Aeterna-rongroi — это автономный инструмент проверки ПК с открытым исходным кодом, работающий только в режиме чтения, для сообществ FiveM; он сканирует компьютер с Windows на следы читов и рискованную конфигурацию системы. Он представляет форензические данные в виде результатов Found, NotFound или Unmeasured, а не выносит вердикт о невиновности или виновности, чтобы игроки могли проверить себя самостоятельно или поделиться результатами во время сеансов демонстрации экрана с администраторами. Проект в основном написан на Rust и включает настольное приложение на Tauri 2 с интерфейсом на React/TypeScript, а также CLI с поддержкой режимов самопроверки и демонстрации экрана, маскированием путей и процедурами согласия. Обнаружение обеспечивается встроенным движком правил YAML и сборщиками данных только для чтения, которые проверяют артефакты, такие как состояние Secure Boot, без записи на хост и без сетевого взаимодействия. Он предназначен для сотрудников игровой безопасности, модераторов серверов и игроков, которым нужна прозрачная и учитывающая конфиденциальность проверка следов читов при проверках ПК в FiveM.
