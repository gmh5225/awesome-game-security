Aeterna-rongroi is an offline, read-only, open-source PC-check tool for FiveM communities that scans a Windows machine for cheat traces and risky machine posture. It presents forensic evidence as Found, NotFound, or Unmeasured results rather than issuing a clean or guilty verdict, so players can self-check or share results during admin screenshare sessions. The project is built primarily in Rust with a Tauri 2 desktop app and React/TypeScript UI, plus a CLI supporting self-check and screenshare modes with path redaction and consent flows. Detection is driven by an embedded YAML rules engine and read-only collectors that inspect artifacts such as Secure Boot posture without writing to or networking with the host. It targets game security staff, server moderators, and players who need transparent, privacy-conscious cheat-trace inspection during FiveM PC checks.
