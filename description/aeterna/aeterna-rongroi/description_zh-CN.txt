Aeterna-rongroi 是一款面向 FiveM 社区的离线、只读、开源 PC 检测工具，用于扫描 Windows 机器上的作弊痕迹和存在风险的系统配置。它将取证结果呈现为 Found、NotFound 或 Unmeasured，而非直接给出清白或有罪的判决，以便玩家可以自行检测或在管理员屏幕共享会话中分享结果。该项目主要使用 Rust 构建，采用 Tauri 2 桌面应用和 React/TypeScript UI，并提供支持自检和屏幕共享模式的 CLI，具备路径脱敏和同意流程。检测由嵌入式 YAML 规则引擎和只读采集器驱动，检查 Secure Boot 配置等工件，且不对主机进行写入或网络通信。它面向游戏安全人员、服务器管理员和玩家，提供在 FiveM PC 检测过程中透明且注重隐私的作弊痕迹检查。
