Architectography es un lanzador y panel de control de escritorio para Windows, creado con Python y PyWebView, para auditar rápidamente un equipo en busca de software de terceros o no autorizado. Integra descarga y ejecución con un clic de utilidades forenses y del sistema habituales, entre ellas Everything, visores NirSoft para prefetch, USB, historial del navegador, listas de salto y datos UserAssist, además de Process Hacker, JournalTrace y System Informer. La aplicación ofrece enumeración de procesos en vivo mediante psutil con búsqueda y filtrado por nombres y rutas de ejecutables y bibliotecas, resúmenes detallados de hardware y del sistema operativo, y accesos directos a servicios en línea de análisis de malware y URL. Investigadores, personal antitrampas y analistas de seguridad pueden usarlo como único centro gráfico al revisar PCs o hosts de jugadores en busca de trampas, inyectores y otros programas no deseados.
