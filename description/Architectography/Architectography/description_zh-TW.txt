Architectography 是一款以 Python 與 PyWebView 建構的 Windows 桌面啟動器與控制台，用於快速稽核機器上的第三方或未授權軟體。它整合常見鑑識與系統工具的一鍵下載與啟動，包括 Everything、用於 prefetch、USB、瀏覽器歷史、跳轉清單及 UserAssist 資料的 NirSoft 檢視器，以及 Process Hacker、JournalTrace 與 System Informer。應用程式透過 psutil 提供即時程序列舉，支援依可執行檔與程式庫的名稱與路徑搜尋與篩選，並呈現詳細的硬體與作業系統摘要，以及通往線上惡意軟體與 URL 分析服務的捷徑。鑑識人員、反作弊人員與安全分析師可將其作為單一圖形化中樞，在篩查玩家 PC 或主機上的作弊程式、注入器及其他不需要的程式時使用。
