Architectography は、Python と PyWebView で構築された Windows 向けデスクトップランチャー兼コントロールパネルで、マシン上のサードパーティ製または不正なソフトウェアを素早く監査するために使います。Everything、prefetch・USB・ブラウザ履歴・ジャンプリスト・UserAssist データ用の NirSoft ビューア、Process Hacker、JournalTrace、System Informer など、一般的なフォレンジック・システムユーティリティのワンクリックダウンロードと起動を統合しています。psutil によるライブなプロセス列挙、実行ファイルやライブラリの名前・パスに対する検索とフィルタ、詳細なハードウェアおよび OS の概要、オンラインのマルウェア・URL 分析サービスへのショートカットを提供します。調査担当者、アンチチートスタッフ、セキュリティアナリストが、プレイヤー PC やホストをチート、インジェクター、その他の不要なプログラムについてスクリーニングする際の単一のグラフィカルハブとして利用できます。
