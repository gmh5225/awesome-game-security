Architectography is a Windows desktop launcher and control panel built with Python and PyWebView for quickly auditing a machine for third-party or unauthorized software. It integrates one-click download and launch of common forensic and system utilities, including Everything, NirSoft viewers for prefetch, USB, browser history, jump lists, and user assist data, plus Process Hacker, JournalTrace, and System Informer. The app exposes live process enumeration via psutil with search and filtering on executable and library names and paths, detailed hardware and OS summaries, and shortcuts to online malware and URL analysis services. Investigators, anti-cheat staff, and security analysts can use it as a single graphical hub when screening player PCs or hosts for cheats, injectors, and other unwanted programs.
