Architectography 是一款基于 Python 与 PyWebView 构建的 Windows 桌面启动器与控制面板，用于快速审计机器上的第三方或未授权软件。它集成常见取证与系统工具的一键下载与启动，包括 Everything、用于 prefetch、USB、浏览器历史、跳转列表及 UserAssist 数据的 NirSoft 查看器，以及 Process Hacker、JournalTrace 和 System Informer。应用通过 psutil 提供实时进程枚举，支持按可执行文件与库的名称和路径搜索与筛选，并展示详细的硬件与操作系统摘要，以及指向在线恶意软件与 URL 分析服务的快捷入口。调查人员、反作弊工作人员与安全分析师可将其作为统一图形化枢纽，在筛查玩家 PC 或主机上的作弊程序、注入器及其他不需要的程序时使用。
