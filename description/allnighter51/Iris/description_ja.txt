Iris は Windows 向けデスクトップユーティリティで、ボーダーレスおよびウィンドウモードのゲーム上に透明な PNG と WebP のオーバーレイを描画し、CPU と GPU の負荷を抑えたモジュラー HUD コンポジターとして動作します。ネイティブ側は Rust と Tauri 2、UI は React と TypeScript で構築され、ゲームプロセスへの注入やゲームメモリの読み取りは行わず、Win32 のレイヤード最前面ウィンドウを使用します。Vault はオーバーレイアセットの保存とキャリブレーション、Layering Studio は多層 HUD レイアウトの重ね合わせと配置、Display Controller はモニター指定、スケーリング、ゲーム検出時のプロファイル自動切り替えを担当します。クリックスルー透過で入力はゲームに渡り、任意の WDA_EXCLUDEFROMCAPTURE ストリーマーモードでオーバーレイをキャプチャソフトから隠せます。Vanguard、Easy Anti-Cheat、BattlEye、Ricochet など一般的なアンチチートを起動させずにカスタム画面 HUD が必要なプレイヤーとクリエイター向けの設計です。
