Iris 是一款 Windows 桌面工具，可在無邊框與視窗化遊戲之上渲染透明 PNG 與 WebP 疊加層，作為模組化 HUD 合成器，CPU 與 GPU 開銷極低。原生層採用 Rust 與 Tauri 2，介面為 React 與 TypeScript，透過 Win32 分層置頂視窗實現，無需注入遊戲行程或讀取遊戲記憶體。Vault 用於儲存與校準疊加資源，Layering Studio 可堆疊並定位多層 HUD 版面，Display Controller 負責顯示器選擇、縮放以及在偵測到遊戲時自動切換設定檔。點擊穿透保持輸入交給遊戲，可選的 WDA_EXCLUDEFROMCAPTURE 實況主模式可讓疊加層不被擷取軟體捕獲；面向需要自訂螢幕 HUD、又希望避免觸發 Vanguard、Easy Anti-Cheat、BattlEye 或 Ricochet 等常見反作弊系統的玩家與創作者。
