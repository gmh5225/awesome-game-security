Iris 是一款 Windows 桌面工具，可在无边框与窗口化游戏之上渲染透明 PNG 与 WebP 叠加层，作为模块化 HUD 合成器，CPU 与 GPU 开销极低。原生层采用 Rust 与 Tauri 2，界面为 React 与 TypeScript，通过 Win32 分层置顶窗口实现，无需注入游戏进程或读取游戏内存。Vault 用于存储与校准叠加资源，Layering Studio 可堆叠并定位多层 HUD 布局，Display Controller 负责显示器选择、缩放以及在检测到游戏时自动切换配置。点击穿透保持输入交给游戏，可选的 WDA_EXCLUDEFROMCAPTURE 主播模式可让叠加层不被采集软件捕获；面向需要自定义屏幕 HUD、又希望避免触发 Vanguard、Easy Anti-Cheat、BattlEye 或 Ricochet 等常见反作弊系统的玩家与创作者。
