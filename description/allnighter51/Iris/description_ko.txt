Iris는 Windows 데스크톱 유틸리티로, 테두리 없는 창과 창 모드 게임 위에 투명 PNG 및 WebP 오버레이를 렌더링하며 CPU와 GPU 부하를 최소화한 모듈형 HUD 합성기로 동작합니다. 네이티브는 Rust와 Tauri 2, UI는 React와 TypeScript로 구성되며, 게임 프로세스 주입이나 게임 메모리 읽기 없이 Win32 레이어드 최상위 창을 사용합니다. Vault는 오버레이 에셋 저장 및 보정, Layering Studio는 다층 HUD 레이아웃의 쌓기와 배치, Display Controller는 모니터 지정, 스케일링, 게임 감지 시 프로필 자동 전환을 담당합니다. 클릭 스루 투명도로 입력은 게임으로 전달되며, 선택적 WDA_EXCLUDEFROMCAPTURE 스트리머 모드로 오버레이를 캡처 소프트웨어에서 숨길 수 있습니다. Vanguard, Easy Anti-Cheat, BattlEye, Ricochet 등 일반적인 안티치트를 유발하지 않고 맞춤 화면 HUD가 필요한 플레이어와 크리에이터를 대상으로 설계되었습니다.
