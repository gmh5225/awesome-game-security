Iris is a Windows desktop utility that renders transparent PNG and WebP overlays on top of borderless and windowed games while acting as a modular HUD compositor with minimal CPU and GPU overhead. It is built with Rust and Tauri 2 on the native side and React with TypeScript on the UI, using Win32 layered topmost windows instead of injecting into game processes or reading game memory. The Vault stores and calibrates overlay assets, the Layering Studio stacks and positions multi-layer HUD layouts, and the Display Controller handles monitor targeting, scaling, and automatic profile switching when games are detected. Click-through transparency keeps input routed to the game, optional WDA_EXCLUDEFROMCAPTURE streamer mode hides overlays from capture software, and the design targets players and creators who need custom on-screen HUDs without triggering common anti-cheat systems such as Vanguard, Easy Anti-Cheat, BattlEye, or Ricochet.
