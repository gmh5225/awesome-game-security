Nexora è un network manager Minecraft self-hosted che centralizza amministrazione e intelligence sui giocatori per reti multi-server basate su proxy Velocity e server di gioco Paper. È distribuito come stack Docker Compose con API NestJS e TypeScript, dashboard web Next.js e plugin Java per proxy e backend che usano richieste firmate HMAC, heartbeat e sincronizzazione eventi in buffer. Gli operatori ottengono moderazione su tutta la rete, profili e statistiche dei giocatori, monitoraggio server, modifica inventari con cronologia revisioni, controllo accessi basato sui ruoli, log di audit e aggiornamenti dashboard in tempo reale tramite stream su Redis. Un livello anti-cheat dedicato espone un’API Java per plugin affidabili di rilevamento cheat, motori di regole nella dashboard con soglie di violazione e punizioni automatiche, e flussi di enforcement collegati alle prove. La piattaforma è rivolta a proprietari e staff di reti Minecraft che necessitano operazioni in stile produzione, integrazione plugin attenta alla sicurezza e strumenti unificati anti-cheat e moderazione anziché silos per singolo server.
