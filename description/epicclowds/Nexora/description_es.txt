Nexora es un administrador de red Minecraft autoalojado que centraliza la administración y la inteligencia de jugadores en redes multiservidor construidas sobre proxies Velocity y servidores de juego Paper. Se distribuye como una pila Docker Compose con una API NestJS en TypeScript, un panel web Next.js y plugins Java de proxy y backend que usan solicitudes firmadas con HMAC, latidos y sincronización de eventos en búfer. Los operadores obtienen moderación en toda la red, perfiles y estadísticas de jugadores, monitorización de servidores, edición de inventarios con historial de revisiones, control de acceso basado en roles, registro de auditoría y actualizaciones del panel en tiempo real mediante flujos respaldados por Redis. Una capa antitrampas dedicada expone una API Java para plugins de confianza de detección de trampas, motores de reglas en el panel con umbrales de infracción y castigos automatizados, y flujos de aplicación vinculados a pruebas. La plataforma está dirigida a propietarios y personal de redes Minecraft que necesitan operaciones de estilo producción, integración de plugins con mentalidad de seguridad y herramientas unificadas de antitrampas y moderación en lugar de silos por servidor.
