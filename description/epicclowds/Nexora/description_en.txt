Nexora is a self-hosted Minecraft Network Manager that centralizes administration and player intelligence for multi-server networks built on Velocity proxies and Paper game servers. It ships as a Docker Compose stack with a NestJS and TypeScript API, a Next.js web dashboard, and Java proxy and backend plugins that use HMAC-signed requests, heartbeats, and buffered event sync. Operators get network-wide moderation, player profiles and statistics, server monitoring, inventory editing with revision history, role-based access control, audit logging, and real-time dashboard updates over Redis-backed streams. A dedicated anti-cheat layer exposes a Java API for trusted cheat-detection plugins, dashboard rule engines with violation thresholds and automated punishments, and evidence-linked enforcement workflows. The platform targets Minecraft network owners and staff who need production-style operations, security-minded plugin integration, and unified anti-cheat and moderation tooling rather than per-server silos.
