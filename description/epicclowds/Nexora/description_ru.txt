Nexora — самохостируемый менеджер сети Minecraft, который централизует администрирование и аналитику игроков для мультисерверных сетей на базе прокси Velocity и игровых серверов Paper. Поставляется как стек Docker Compose с API на NestJS и TypeScript, веб-панелью Next.js и Java-плагинами для прокси и бэкенда, использующими запросы с HMAC-подписью, heartbeat и буферизованную синхронизацию событий. Операторы получают модерацию по всей сети, профили и статистику игроков, мониторинг серверов, редактирование инвентаря с историей изменений, ролевой контроль доступа, аудит-логирование и обновления панели в реальном времени через потоки на Redis. Выделенный античит-слой предоставляет Java API для доверенных плагинов обнаружения читов, движки правил в панели с порогами нарушений и автоматическими наказаниями, а также рабочие процессы применения санкций со ссылкой на доказательства. Платформа ориентирована на владельцев и персонал сетей Minecraft, которым нужны эксплуатация уровня продакшена, безопасная интеграция плагинов и единые инструменты античита и модерации вместо изолированных решений на каждом сервере.
