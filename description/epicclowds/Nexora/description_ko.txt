Nexora는 Velocity 프록시와 Paper 게임 서버 기반 멀티 서버 네트워크의 관리와 플레이어 인텔리전스를 중앙에서 다루는 자체 호스팅 Minecraft 네트워크 관리자입니다. Docker Compose 스택으로 제공되며 NestJS·TypeScript API, Next.js 웹 대시보드, HMAC 서명 요청·하트비트·버퍼링된 이벤트 동기화를 사용하는 Java 프록시 및 백엔드 플러그인으로 구성됩니다. 운영자는 네트워크 전역 모더레이션, 플레이어 프로필과 통계, 서버 모니터링, 수정 이력이 있는 인벤토리 편집, 역할 기반 접근 제어, 감사 로깅, Redis 스트림 기반 실시간 대시보드 업데이트를 이용할 수 있습니다. 전용 안티치트 계층은 신뢰된 치트 탐지 플러그인용 Java API, 위반 임계값과 자동 처벌이 있는 대시보드 규칙 엔진, 증거 연계 집행 워크플로를 제공합니다. 이 플랫폼은 서버별 고립이 아닌 통합 안티치트·모더레이션 도구, 보안을 고려한 플러그인 통합, 프로덕션 수준 운영이 필요한 Minecraft 네트워크 소유자와 스태프를 대상으로 합니다.
