X360GameHack は、Xbox 360 の RGH/JTAG、Bad Update、Bad Avatar、および開発キット本体向けに、個人バックアップしたゲームのインストールと管理を行うオープンソースの Windows オールインワンデスクトップアプリで、オリジナル Xbox の ISO および XBE ファイルにも対応しています。C# と .NET Framework による WinForms GUI として実装され、XEX の暗号化/復号/圧縮やコンソールターゲットへのパッチ適用、パッケージおよび DLC のアンロック、Title ID と Media ID の変更、RGH または開発キット向けセーブコンテナ変換など、一般的な改造ワークフローをまとめています。ISO から GOD/STFS への変換、Xbox や他コンソールへの FTP 転送、一括 ISO 展開ヘルパー、USB インストール支援も備え、Xbox Neighborhood なしでゲームコンテンツの準備と展開が可能です。主な用途は改造コンソール向けの Xbox 360 ホームブリューおよびリバースエンジニアリング支援で、バックアップ導入や XEX/パッケージのパッチ作業を初心者から RGH 販売者まで使いやすくすることを目指しています。
