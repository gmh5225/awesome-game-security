X360GameHack is an open-source Windows all-in-one desktop app for installing and managing personally backed-up games on Xbox 360 RGH/JTAG, Bad Update, Bad Avatar, and devkit consoles, with additional support for original Xbox ISO and XBE files. Written in C# for .NET Framework as a WinForms GUI, it wraps common modding workflows such as XEX encrypt/decrypt/compress and console-target patching, package and DLC unlock tools, Title ID and Media ID changes, and save-container conversion for RGH or devkit. It also includes ISO-to-GOD/STFS conversion, FTP file transfer to Xbox and other consoles, bulk ISO extraction helpers, and USB install helpers so users can prepare and deploy game content without Xbox Neighborhood. The primary use case is Xbox 360 homebrew and reverse-engineering tooling for modded consoles, aimed at making backup installation and XEX/package patching accessible to both beginners and RGH sellers.
