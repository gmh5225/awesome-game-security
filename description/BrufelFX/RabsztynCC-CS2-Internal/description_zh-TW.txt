RabsztynCC 是一個針對 64 位元 Windows 上 Counter-Strike 2 的內部 C++ 框架與研究平台，以 DLL 形式注入遊戲程序。它實作了 ESP、chams、triggerbot、aimbot 和 bunny hop 等遊戲功能，透過 DirectX 11 Present 掛鉤與 ImGui 疊加選單進行渲染。程式碼庫著重於反作弊與規避偵測技術，包括直接 NT 系統呼叫、PE 標頭擦除、特徵碼破壞、執行緒隱藏，以及可選的具共享記憶體 IPC 的核心驅動程式。配套的載入器負責 DLL 注入，而 Offsets.h 與輕量級 SDK 提供 CS2 實體結構與記憶體偏移。本專案旨在用於遊戲內部機制、逆向工程與反作弊安全方面的教育性研究，而非線上競技用途。
