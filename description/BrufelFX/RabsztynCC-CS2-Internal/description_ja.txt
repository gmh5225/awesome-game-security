RabsztynCC は、64 ビット Windows 上の Counter-Strike 2 向けの内部 C++ フレームワークおよび研究プラットフォームで、DLL としてゲームプロセスにインジェクトされます。ESP、chams、triggerbot、aimbot、bunny hop などのゲームプレイ機能を実装し、DirectX 11 Present フックと ImGui オーバーレイメニューで描画します。コードベースは、直接 NT シスコール、PE ヘッダー消去、シグネチャ破壊、スレッド非表示、共有メモリ IPC を備えたオプションのカーネルドライバーなど、反チートおよび検出回避技術を重視しています。付属のローダーが DLL インジェクションを処理し、Offsets.h と軽量 SDK が CS2 のエンティティ構造体とメモリオフセットを提供します。本プロジェクトは、ライブ競技での使用ではなく、ゲーム内部、リバースエンジニアリング、反チートセキュリティの教育的研究を目的としています。
