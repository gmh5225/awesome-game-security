RabsztynCC is an internal C++ framework and research platform for Counter-Strike 2 on 64-bit Windows that injects as a DLL into the game process. It implements gameplay features such as ESP, chams, triggerbot, aimbot, and bunny hop, rendered through a DirectX 11 Present hook with an ImGui overlay menu. The codebase emphasizes anti-cheat and detection evasion techniques including direct NT syscalls, PE header wiping, signature busting, thread hiding, and an optional kernel driver with shared-memory IPC. A companion loader handles DLL injection, while Offsets.h and a lightweight SDK provide CS2 entity structures and memory offsets. The project is intended for educational study of game internals, reverse engineering, and anti-cheat security research rather than live competitive use.
