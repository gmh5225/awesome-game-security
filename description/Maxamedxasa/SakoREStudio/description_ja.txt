Sako RE Studio は Android 向けのモバイルファーストなリバースエンジニアリングスイートで、インタラクティブな逆アセンブラ、IR ベースの逆コンパイラ、コールグラフエクスプローラー、ptrace デバッガー、APK アナライザー、拡張可能なプラグインシステムを単一のオフラインアプリに統合しています。ネイティブ C++17 エンジンは Capstone による逆アセンブルに対応し、ARM64 および x86-64 上の APK、ELF、PE、DEX バイナリをサポートし、Kotlin Jetpack Compose UI ではアセンブリビュー、疑似 C 逆コンパイル、制御フローグラフ、SQLite によるプロジェクト永続化を提供します。組み込みの SakoScript プラグインはセキュリティ監査、ARM 解析、DEX 検査、文字列ハンティングを自動化し、オプションの AI アシスタントはローカルまたは OpenAI 互換エンドポイント経由で関数を説明できます。スマートフォンやタブレット上で IDA Pro や Ghidra に近い機能を、バイナリをデバイス外に送信せずに必要とするリバースエンジニア、モバイルセキュリティ研究者、アナリストを対象としています。
