Sako RE Studio 是一款面向 Android 的移动优先逆向工程套件，在单一离线应用中集成了交互式反汇编器、基于 IR 的反编译器、调用图浏览器、ptrace 调试器、APK 分析器以及可扩展的插件系统。其原生 C++17 引擎使用 Capstone 进行反汇编，支持 ARM64 和 x86-64 上的 APK、ELF、PE 和 DEX 二进制文件，Kotlin Jetpack Compose 界面提供汇编视图、伪 C 反编译、控制流图以及基于 SQLite 的项目持久化。内置 SakoScript 插件可自动化安全审计、ARM 分析、DEX 检查和字符串搜索，可选的 AI 助手可在本地或通过 OpenAI 兼容端点解释函数。它面向需要在手机或平板上获得类似 IDA Pro 或 Ghidra 能力、且无需将二进制文件发送到设备外的逆向工程师、移动安全研究人员和分析人员。
