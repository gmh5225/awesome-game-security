Quarterhood Engine は、ブラウザ報告のスコアを鵜呑みにしないブロックチェーン上のスキルアーケード Quarterhood を支える、オープンソースの決定論的ゲームロジックおよびラン検証器である。サーバーは各ランにシードを与え、フレーム単位の入力イベントのみを保存し、共有 TypeScript シミュレーションでそれらの入力をリプレイしてスコア、フレーム数、誰でもローカルで再現できる最終状態の暗号ハッシュを導出する。コードベースは xorshift32 RNG と整数のみの物理を備えた複数ミニゲーム向けリプレイコアを中心に、Node 検証 CLI と各 JavaScript エンジン間で期待結果を固定するゴールデンフィクスチャを含む。併設の Solidity コントラクトは週次リーダーボード行をリプレイハッシュに紐づく不変の Merkle ルートとして Robinhood Chain にコミットし、公開の反スクリプトフラグが疑わしいランを人的審査へ送る。クライアント–サーバー型ゲームの整合性、検証可能なスコアリング、競技オンライン向け透明なアンチチートを学ぶ開発者向けである。
