Quarterhood Engine est le moteur open source de logique de jeu déterministe et de vérification des parties qui soutient Quarterhood, une arcade d’adresse hébergée sur blockchain où les scores ne sont jamais pris pour argent comptant depuis le navigateur. Le serveur amorce chaque partie et ne stocke que les événements d’entrée par image ; il rejoue ensuite ces entrées via des simulations TypeScript partagées pour en déduire le score, le nombre d’images et un hachage cryptographique de l’état final que chacun peut reproduire en local. La base de code s’articule autour d’un noyau de relecture avec RNG xorshift32 et physique en entiers uniquement sur plusieurs mini-jeux, ainsi qu’une CLI de vérification Node et des jeux de référence dorés qui figent les résultats attendus selon les moteurs JavaScript. Un contrat Solidity associé engage chaque semaine les lignes du classement sur Robinhood Chain sous forme de racines Merkle immuables liées aux hachages de relecture, et des indicateurs publics anti-script bloquent les parties suspectes pour examen humain. Il s’adresse aux développeurs qui étudient l’intégrité client–serveur, la notation vérifiable et l’anti-triche transparent pour le jeu compétitif en ligne.
