Quarterhood Engine 是 Quarterhood 背后开源的确定性游戏逻辑与对局校验器；Quarterhood 是一款区块链托管的技巧街机，分数从不轻信浏览器上报。服务器为每局生成种子并仅存储逐帧输入事件，随后通过共享的 TypeScript 模拟重放这些输入，得出分数、帧数以及最终状态的可复现加密哈希。代码库以重放核心为中心，采用 xorshift32 随机数与纯整数物理，涵盖多款小游戏，并配有 Node 校验 CLI 与黄金固定用例，以锁定各 JavaScript 引擎下的预期结果。配套的 Solidity 合约将每周排行榜行以不可变 Merkle 根形式提交到 Robinhood Chain，并与重放哈希绑定；公开的防脚本标记会对可疑对局进行人工审核拦截。面向研究客户端–服务器游戏完整性、可验证计分与竞技在线透明反作弊的开发者。
