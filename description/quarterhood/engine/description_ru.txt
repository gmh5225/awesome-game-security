Quarterhood Engine — это открытый движок детерминированной игровой логики и проверки заходов, лежащий в основе Quarterhood: skill-аркады на блокчейне, где очки никогда не принимаются на веру из браузера. Сервер задаёт сид каждому заходу и хранит только покадровые события ввода; затем проигрывает эти вводы через общие симуляции на TypeScript, выводя счёт, число кадров и криптографический хеш финального состояния, который любой может воспроизвести локально. Кодовая база сосредоточена вокруг ядра реплея с ГПСЧ xorshift32 и физикой только на целых числах для нескольких мини-игр, плюс CLI верификации на Node и эталонные фикстуры, фиксирующие ожидаемые результаты в разных движках JavaScript. Сопутствующий контракт Solidity еженедельно фиксирует строки таблицы лидеров в Robinhood Chain как неизменяемые корни Меркла, привязанные к хешам реплея; публичные флаги анти-скриптинга направляют подозрительные заходы на ручную проверку. Предназначен для разработчиков, изучающих целостность клиент–серверных игр, верифицируемый подсчёт очков и прозрачный античит в соревновательной онлайн-игре.
