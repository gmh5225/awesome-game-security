Quarterhood Engine is the open-source deterministic game logic and run verifier behind Quarterhood, a blockchain-hosted skill arcade where scores are never taken from the browser at face value. The server seeds each run and stores only per-frame input events; it then replays those inputs through shared TypeScript simulations to derive score, frame count, and a cryptographic hash of final state that anyone can reproduce locally. The codebase centers on a replay core with xorshift32 RNG and integer-only physics across multiple mini-games, plus a Node verifier CLI and golden fixtures that lock expected outcomes across JavaScript engines. A companion Solidity contract commits weekly leaderboard rows to Robinhood Chain as immutable Merkle roots tied to replay hashes, and public anti-scripting flags gate suspicious runs for human review. It is aimed at developers studying client–server game integrity, verifiable scoring, and transparent anti-cheat for competitive online play.
