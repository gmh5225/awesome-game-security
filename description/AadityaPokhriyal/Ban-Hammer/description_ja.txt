Ban-Hammer は、マッチのテレメトリから得たプレイヤーごとの行動・戦闘統計を分析し、Counter-Strike 2 におけるチート行為を検出する機械学習パイプラインです。主に Python と Jupyter ノートブック、特徴抽出スクリプトで実装され、Parquet 形式の tick データと JSON イベントログからラベル付きデータセットを構築します。チーターのグラウンドトゥルースに加え、ラウンドごとのキル・デス、K/D 比、ヘッドショット率、移動速度、精度ペナルティ、ラウンドあたりダメージ、スモーク越し・盲目時・空中での文脈付きキル比などの派生シグナルを含みます。学習には scikit-learn パイプラインとロジスティック回帰、ランダムフォレスト、XGBoost 分類器を用い、グループを意識した検証と閾値調整を行い、シリアル化したモデルでホールドアウトマッチを評価します。ゲームセキュリティ研究者やアンチチート実務者向けに、クライアント側フックだけでなく、ゲーム内データから疑わしい aimbot 様・spinbot 様のプレイを統計に基づいて再現可能にフラグするアプローチを提供します。
