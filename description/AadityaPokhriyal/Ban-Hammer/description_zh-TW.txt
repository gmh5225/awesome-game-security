Ban-Hammer 是一套機器學習流水線，透過分析對局遙測中每名玩家的行為與戰鬥統計資料來偵測《Counter-Strike 2》中的作弊行為。專案主要以 Python 實作，搭配 Jupyter 筆記本與特徵擷取腳本，從 Parquet 格式的 tick 資料及配套的 JSON 事件日誌建構帶標籤資料集，內含作弊者真值及衍生訊號，例如每回合擊殺與死亡、K/D 比、爆頭率、移動速度、精度懲罰、每回合傷害，以及穿煙、致盲或空中擊殺的脈絡擊殺比。訓練採用 scikit-learn 流水線，使用邏輯迴歸、隨機森林與 XGBoost 分類器，並結合按組劃分的驗證與閾值調校，序列化模型用於在留出對局上評估。面向遊戲安全研究人員與反作弊從業者，提供可重現、以統計為驅動的方案，從局內資料標記可疑的類 aimbot 或類 spinbot 行為，而非僅依賴客戶端鉤子。
