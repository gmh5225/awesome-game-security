Ban-Hammer 是一套机器学习流水线，通过分析对局遥测中每名玩家的行为与战斗统计数据来检测《Counter-Strike 2》中的作弊行为。项目主要以 Python 实现，配合 Jupyter 笔记本与特征提取脚本，从 Parquet 格式的 tick 数据及配套的 JSON 事件日志构建带标签数据集，内含作弊者真值及衍生信号，例如每回合击杀与死亡、K/D 比、爆头率、移动速度、精度惩罚、每回合伤害，以及穿烟、致盲或空中击杀的上下文击杀比。训练采用 scikit-learn 流水线，使用逻辑回归、随机森林与 XGBoost 分类器，并结合按组划分的验证与阈值调优，序列化模型用于在留出对局上评估。面向游戏安全研究人员与反作弊从业者，提供可复现、以统计为驱动的方案，从局内数据标记可疑的类 aimbot 或类 spinbot 行为，而非仅依赖客户端钩子。
