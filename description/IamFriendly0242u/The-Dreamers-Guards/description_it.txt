The Dreamers Guards è una mod Fabric che fornisce protezione anti-cheat lato client e lato server per server multigiocatore di Minecraft. Scritta in Java, convalida l'integrità del client al momento dell'accesso tramite payload di rete personalizzati crittografati e analizza le mod installate rispetto a una blacklist di client cheat e utility di exploit noti. Il server applica le infrazioni con un sistema progressivo di sospensione in quattro fasi, controlli anti-elusione per impedire bypass tramite disconnessione, e comandi operatore per kick, ban, condono e gestione della fiducia manuali. Eventi di sicurezza e azioni di enforcement possono essere inoltrati a Discord tramite integrazione webhook. È rivolto agli amministratori di server Fabric che necessitano di rilevamento automatico dei cheat, verifica delle mod e enforcement dell'integrità del gameplay su mondi multigiocatore pubblici o privati.
