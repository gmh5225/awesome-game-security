The Dreamers Guards — это мод Fabric, обеспечивающий клиентскую и серверную защиту от читов для многопользовательских серверов Minecraft. Написанный на Java, он проверяет целостность клиента при входе с помощью зашифрованных пользовательских сетевых полезных нагрузок и сканирует установленные моды по чёрному списку известных чит-клиентов и эксплойт-утилит. Сервер применяет санкции через прогрессивную четырёхфазную систему блокировок, проверки против обхода для предотвращения ухода с сервера, а также команды оператора для ручных киков, банов, помилований и управления доверием. События безопасности и меры принуждения можно пересылать в Discord через интеграцию webhook. Он предназначен для администраторов серверов Fabric, которым нужны автоматическое обнаружение читов, проверка модов и обеспечение целостности геймплея в публичных или приватных многопользовательских мирах.
