Deadline Research Client は、自分が所有する、またはテストを許可されたプレイス上でクライアント側のエクスプロイト手法を調査し、アンチチートの応答を検証するためのモジュール型 Roblox Lua テストハーネスです。エイム支援、ESP およびスケルトンオーバーレイ、移動や空中ジャンプの速度実験、トリガーボットの挙動、ビジュアル、WalkSpeed 読み取りの偽装やクライアント違反シグナルの抑制など、限定的なバイパスプローブを含むオプションの研究モジュールを同梱しています。キーバインドと JSON プロファイル付きの設定可能なゲーム内 UI と、本番向けアンチチートの提供ではなくサーバー側検知・リスク・テスト計画に関する ANTICHEAT_RESEARCH.md のガイダンスを組み合わせています。tests 配下の Python および Lua 5.4 のモックランナーで、プラットフォーム外でもモジュールロジックを検証できます。本プロジェクトはゲームセキュリティ研究者、Roblox 開発者、クライアントの信頼境界とサーバー権威の緩和策をレッドチーム的に評価する用途を対象としています。
