Deadline Research Client is a modular Roblox Lua test harness for exploring client-side exploit techniques and validating anti-cheat responses on places you own or are authorized to test. It packages optional research modules for aim assistance, ESP and skeleton overlays, movement and air-jump speed experiments, trigger bot behavior, visuals, and narrowly scoped bypass probes such as spoofed WalkSpeed reads and suppressed client violation signals. A configurable in-game UI with keybinds and JSON profiles is paired with ANTICHEAT_RESEARCH.md guidance on server-side detection, risks, and test plans rather than shipping a production anti-cheat. Python and Lua 5.4 mock runners under tests exercise module logic off-platform. The project targets game security researchers, Roblox developers, and red-team style evaluation of client trust boundaries and server-authoritative mitigations.
