Deadline Research Client 是一款模組化的 Roblox Lua 測試框架，用於在你擁有或經授權測試的場所中探索用戶端利用技術並驗證反作弊回應。它提供可選研究模組，涵蓋瞄準輔助、ESP 與骨架疊加層、移動與空中跳躍速度實驗、扳機機器人行為、視覺效果，以及範圍較窄的繞過探測（例如偽造 WalkSpeed 讀取與抑制用戶端違規訊號）。可設定的遊戲內 UI（含按鍵綁定與 JSON 設定檔）搭配 ANTICHEAT_RESEARCH.md 中關於伺服器端偵測、風險與測試計畫的說明，而非交付生產級反作弊方案。tests 目錄下的 Python 與 Lua 5.4 模擬執行器可在平台外演練模組邏輯。該專案面向遊戲安全研究人員、Roblox 開發者，以及以紅隊方式評估用戶端信任邊界與伺服器權威緩解措施的需求。
