Deadline Research Client 是一款模块化的 Roblox Lua 测试框架，用于在你拥有或经授权测试的场所中探索客户端利用技术并验证反作弊响应。它提供可选研究模块，涵盖瞄准辅助、ESP 与骨骼叠加层、移动与空中跳跃速度实验、扳机机器人行为、视觉效果，以及范围较窄的绕过探测（例如伪造 WalkSpeed 读取与抑制客户端违规信号）。可配置的游戏内 UI（含按键绑定与 JSON 配置文件）搭配 ANTICHEAT_RESEARCH.md 中关于服务器端检测、风险与测试计划的说明，而非交付生产级反作弊方案。tests 目录下的 Python 与 Lua 5.4 模拟运行器可在平台外演练模块逻辑。该项目面向游戏安全研究人员、Roblox 开发者，以及以红队方式评估客户端信任边界与服务器权威缓解措施的需求。
