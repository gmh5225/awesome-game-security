Rooted Android Game VM — это настольное приложение для Windows 11, которое предоставляет эмулятор Android с root-доступом и интегрированную отладочную среду для запуска, тестирования и анализа Android-игр и приложений без использования командной строки. Созданное в основном на C# и .NET с WPF-лаунчером, JSON CLI и установщиком Inno Setup, оно автоматизирует загрузку и проверку Android SDK, эмулятора, системного образа и инструментов root Magisk в изолированном виртуальном устройстве. Рабочая среда поддерживает установку и обновление APK, просмотр и экспорт приватных каталогов приложений, root-диагностику, контрольные точки, передачу файлов и удобные для автоматизации отладочные операции через общий слой сервисов GUI и CLI. Оно предназначено для реверс-инжиниринга Android, исследований безопасности игр и авторизованного анализа приложений в Windows, однако не гарантирует совместимость с Play Integrity, а также с защитой от эмуляторов или root.
