This project is a native PC port of God of War for PlayStation 2 (NTSC-U) that turns retail MIPS binaries into runnable native code through static recompilation rather than full-system emulation. A Rust workspace implements the recompiler, ELF and R5900 tooling, parity checks against reference output, ISO-based installer helpers, and developer validation utilities, while C++ with CMake provides the in-process runtime, IOP subsystem, and game-specific overrides. The stack includes function mapping, VU1 handling, texture replacement hooks, and PC-side features such as a Tauri and React launcher, widescreen support, and an in-game cheat menu. It targets developers and researchers studying binary translation, legacy console bring-up, and deep inspection of a commercial title’s code paths when you supply your own legally obtained game disc data.
