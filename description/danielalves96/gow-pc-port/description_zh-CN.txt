本项目是 PlayStation 2（NTSC-U）版《战神》的原生 PC 移植，通过静态重编译将零售版 MIPS 二进制转为可运行的原生代码，而非全系统模拟。Rust 工作区实现重编译器、ELF 与 R5900 工具链、与参考输出的 parity 校验、基于 ISO 的安装辅助及开发者验证工具；C++ 与 CMake 提供进程内运行时、IOP 子系统及游戏相关覆盖。技术栈涵盖函数映射、VU1 处理、纹理替换钩子，以及 PC 端功能（Tauri 与 React 启动器、宽屏支持与游戏内作弊菜单）。面向研究二进制翻译、旧主机 bring-up 及深入分析商业游戏代码路径的开发者与研究人员；需自行提供合法取得的 disc 数据。
