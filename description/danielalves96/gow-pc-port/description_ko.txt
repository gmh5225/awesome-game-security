이 프로젝트는 PlayStation 2(NTSC-U)용 God of War의 네이티브 PC 포트로, 전체 시스템 에뮬레이션이 아니라 정적 재컴파일을 통해 소매용 MIPS 바이너리를 실행 가능한 네이티브 코드로 변환합니다. Rust 워크스페이스는 재컴파일러, ELF 및 R5900 도구, 기준 출력과의 parity 검사, ISO 기반 설치 도우미, 개발자 검증 유틸리티를 구현하고, C++와 CMake는 프로세스 내 런타임, IOP 서브시스템, 게임별 오버라이드를 제공합니다. 함수 매핑, VU1 처리, 텍스처 교체 훅, Tauri와 React 런처, 와이드스크린 지원, 게임 내 치트 메뉴 등 PC 기능을 포함합니다. 바이너리 번역, 레거시 콘솔 bring-up, 상용 타이틀 코드 경로 심층 분석을 연구하는 개발자와 연구자를 대상으로 하며, 합법적으로 구입한 게임 디스크 데이터는 사용자가 직접 제공해야 합니다.
