ACP-Reloaded is a Windows PC mod that rebuilds Ubisoft's Animus Control Panel for Assassin's Creed Origins as a standalone in-game overlay, restoring live access to the game's developer tuning parameters in Hacked Animus saves without the deprecated Uplay overlay. It is implemented mainly in C++ with CMake and MSVC, loading via a dinput8.dll proxy or ASI plugin and using DirectX 11 hooks, window and XInput interception, Uplay event bridging, and an ImGui-based panel with optional Origins-themed UI. The mod exposes all 109 ACP parameters with presets, search, undo, character portraits, and controller navigation, plus quality-of-life features such as frame limiting, sharpening, and save backups, along with opt-in experimental helpers for time, weather, teleportation, and progression on a verified game build. Supporting Python tools generate parameter tables, and the codebase includes tests for pacing, input filtering, sync, and the proxy loader. It is aimed at modders, reverse engineers, and game security researchers studying how triple-A clients expose simulation state and how third-party code hooks graphics, input, and platform services to manipulate that state at runtime.
