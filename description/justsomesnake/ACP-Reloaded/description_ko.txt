ACP-Reloaded는 Windows PC용 모드로, Ubisoft의 『어쌔신 크리드 오리진』에 있던 Animus Control Panel을 독립형 인게임 오버레이로 재구축하여, 더 이상 쓰이지 않는 Uplay 오버레이 없이 Hacked Animus 세이브에서 게임 개발자 튜닝 매개변수에 대한 실시간 접근을 복원합니다. 주로 C++과 CMake, MSVC로 구현되며 dinput8.dll 프록시 또는 ASI 플러그인으로 로드되고, DirectX 11 후킹, 창 및 XInput 가로채기, Uplay 이벤트 브리징, ImGui 기반 패널(선택적 Origins 테마 UI)을 사용합니다. 이 모드는 109개 ACP 매개변수를 프리셋, 검색, 실행 취소, 캐릭터 초상, 컨트롤러 탐색과 함께 노출하고, 프레임 제한, 샤프닝, 세이브 백업 등 QoL 기능과 검증된 빌드에서 시간, 날씨, 순간이동, 진행에 대한 옵트인 실험적 헬퍼를 제공합니다. 보조 Python 도구로 매개변수 표를 생성하며, 코드베이스에는 페이싱, 입력 필터링, 동기화, 프록시 로더용 테스트가 포함됩니다. AAA 클라이언트가 시뮬레이션 상태를 어떻게 노출하는지, 서드파티 코드가 그래픽·입력·플랫폼 서비스를 후킹해 런타임에 그 상태를 조작하는 방식을 연구하는 모더, 리버스 엔지니어, 게임 보안 연구자를 대상으로 합니다.
