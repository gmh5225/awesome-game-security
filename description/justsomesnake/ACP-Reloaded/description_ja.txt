ACP-Reloaded は Windows PC 向けモッドで、Ubisoft の『アサシン クリード オリジン』にあった Animus Control Panel をスタンドアロンのゲーム内オーバーレイとして再構築し、非推奨の Uplay オーバーレイなしで Hacked Animus セーブから開発者向けチューニングパラメータへのライブアクセスを復元します。主に C++ と CMake、MSVC で実装され、dinput8.dll プロキシまたは ASI プラグイン経由で読み込まれ、DirectX 11 フック、ウィンドウおよび XInput の傍受、Uplay イベントのブリッジ、ImGui ベースのパネル（オプションで Origins テーマ UI）を用います。モッドは 109 個すべての ACP パラメータをプリセット、検索、取り消し、キャラクター肖像、コントローラー操作とともに公開し、フレーム制限、シャープニング、セーブバックアップなどの QoL 機能に加え、検証済みビルド上での時間・天候・テレポート・進行に関するオプトインの実験的ヘルパーも提供します。補助的な Python ツールでパラメータ表を生成し、コードベースにはペーシング、入力フィルタ、同期、プロキシローダー向けのテストが含まれます。AAA クライアントがシミュレーション状態をどう露出するか、第三者コードがグラフィックス・入力・プラットフォームサービスをフックして実行時にその状態を操作するかを研究するモッダー、リバースエンジニア、ゲームセキュリティ研究者向けです。
