ACP-Reloaded es un mod para PC con Windows que reconstruye el Animus Control Panel de Ubisoft para Assassin’s Creed Origins como una superposición independiente en el juego, restableciendo el acceso en vivo a los parámetros de ajuste de desarrollador en partidas Hacked Animus sin el overlay Uplay obsoleto. Está implementado principalmente en C++ con CMake y MSVC, se carga mediante un proxy dinput8.dll o un plugin ASI y usa hooks de DirectX 11, intercepción de ventana y XInput, puente de eventos Uplay y un panel basado en ImGui con interfaz opcional con temática de Origins. El mod expone los 109 parámetros ACP con presets, búsqueda, deshacer, retratos de personajes y navegación con mando, además de mejoras de calidad de vida como limitación de fotogramas, nitidez y copias de seguridad de guardados, junto con ayudas experimentales opt-in para tiempo, clima, teletransporte y progresión en una build verificada. Herramientas Python auxiliares generan tablas de parámetros, y el código incluye pruebas de ritmo, filtrado de entrada, sincronización y el cargador proxy. Está dirigido a modders, ingenieros inversos e investigadores de seguridad de juegos que estudian cómo los clientes AAA exponen el estado de simulación y cómo el código de terceros engancha gráficos, entrada y servicios de plataforma para manipular ese estado en tiempo de ejecución.
