ACP-Reloaded 是一款 Windows PC 模組，將育碧《刺客教條：起源》中的 Animus Control Panel 重建為獨立的遊戲內疊加層，在 Hacked Animus 存檔中無需已棄用的 Uplay 疊加層即可恢復對遊戲開發者調參的即時存取。它主要以 C++ 實作，搭配 CMake 與 MSVC，透過 dinput8.dll 代理或 ASI 外掛載入，並使用 DirectX 11 鉤子、視窗與 XInput 攔截、Uplay 事件橋接以及基於 ImGui 的可選 Origins 主題介面。此模組公開全部 109 個 ACP 參數，提供預設、搜尋、復原、角色肖像與控制器導覽，以及幀率限制、銳化、存檔備份等便利功能，並在經驗證的遊戲版本上提供可選的實驗性時間、天氣、傳送與進度輔助。配套的 Python 工具用於產生參數表，程式碼庫包含針對節奏、輸入過濾、同步與代理載入器的測試。面向模組作者、逆向工程師及遊戲安全研究者，用於研究 AAA 客戶端如何暴露模擬狀態，以及第三方程式碼如何鉤住圖形、輸入與平台服務以在執行時操縱該狀態。
