ACP-Reloaded 是一款 Windows PC 模组，将育碧《刺客信条：起源》中的 Animus Control Panel 重建为独立的游戏内叠加层，在 Hacked Animus 存档中无需已弃用的 Uplay 叠加层即可恢复对游戏开发者调参的实时访问。它主要以 C++ 实现，配合 CMake 与 MSVC，通过 dinput8.dll 代理或 ASI 插件加载，并使用 DirectX 11 钩子、窗口与 XInput 拦截、Uplay 事件桥接以及基于 ImGui 的可选 Origins 主题界面。该模组公开全部 109 个 ACP 参数，提供预设、搜索、撤销、角色肖像与手柄导航，以及帧率限制、锐化、存档备份等便利功能，并在经验证的游戏版本上提供可选的实验性时间、天气、传送与进度辅助。配套的 Python 工具用于生成参数表，代码库包含针对节奏、输入过滤、同步与代理加载器的测试。面向模组作者、逆向工程师及游戏安全研究者，用于研究 AAA 客户端如何暴露模拟状态，以及第三方代码如何钩住图形、输入与平台服务以在运行时操纵该状态。
