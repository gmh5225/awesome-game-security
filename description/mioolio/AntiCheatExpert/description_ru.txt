AntiCheatExpert — репозиторий исследований в области безопасности, документирующий и реверс-инжинирующий всю коммерческую suite AntiCheatExpert: драйверы ядра, сервисы пользовательского режима, плагины и связанные PE-компоненты, с инструментами для побайтовой пересборки каждого бинарника из восстановленного ассемблера. Рабочий процесс опирается на утилиты Python для разбора PE, дизассемблирования с Capstone, отчётов о различиях, извлечения таблиц IOCTL и анализа шифрования логов, в паре с Microsoft MASM (ml64) и пользовательским COFF-линкером для сходимости пересобранных образов с оригиналами, включая раскладку Authenticode. В репозитории — структурированные исходники на ассемблере, метаданные паков, отчёты по компонентам и углублённые материалы на китайском о возможностях, протоколах, взаимодействии компонентов и матрицах анализа с упором на обход. Он предназначен для исследователей и преподавателей, изучающих внутренности игрового античита, поведение драйверов и защиту целостности, и распространяет только текстовые артефакты, без подписанных исполняемых файлов и образцов.
