AntiCheatExpert は、商用 AntiCheatExpert スイート（カーネルドライバ、ユーザーモードサービス、プラグイン、関連 PE コンポーネント）全体の文書化とリバースエンジニアリングを行うセキュリティ研究リポジトリであり、復元したアセンブリから各バイナリをバイト単位で再構築するツールを備えています。ワークフローは、PE 解析、Capstone による逆アセンブル、差分レポート、IOCTL テーブル抽出、ログ暗号解析のための Python ユーティリティを中心に、Microsoft MASM（ml64）とカスタム COFF リンカを組み合わせ、Authenticode レイアウトを含めオリジナルと一致する再構築イメージに収束させます。リポジトリには構造化されたアセンブリソース、パックメタデータ、コンポーネント別レポート、機能・プロトコル・コンポーネント連携・バイパス志向の分析マトリクスに関する中国語の詳細解説が含まれます。ゲームアンチチートの内部、ドライバ挙動、整合性保護を学ぶ研究者・教育者向けで、署名付き実行ファイルやサンプルではなくテキスト成果物のみを配布します。
