AntiCheatExpert 是一个安全研究仓库，针对商业版 AntiCheatExpert 套件（涵盖内核驱动、用户态服务、插件及相关 PE 组件）进行文档化与逆向，并提供工具以便从恢复的汇编逐字节重建各二进制。工作流以 Python 工具为主，涵盖 PE 解析、Capstone 反汇编、差异报告、IOCTL 表提取与日志加密分析，并结合 Microsoft MASM（ml64）与自定义 COFF 链接器，使重建镜像在 Authenticode 布局等方面与原版一致。仓库提供结构化汇编源码、打包元数据、各组件报告，以及关于能力、协议、组件交互与绕过导向分析矩阵的中文深度解读。面向研究游戏反作弊内部机制、驱动行为与完整性保护的研究者与教育者，仅分发文本类产物，不提供签名可执行文件或样本。
