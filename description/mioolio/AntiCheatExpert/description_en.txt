AntiCheatExpert is a security research repository that documents and reverse-engineers the full commercial AntiCheatExpert suite spanning kernel drivers, user-mode services, plugins, and related PE components, with tooling to rebuild each binary byte-for-byte from recovered assembly. The workflow centers on Python utilities for PE parsing, disassembly with Capstone, diff reporting, IOCTL table extraction, and log-crypto analysis, paired with Microsoft MASM (ml64) and a custom COFF linker to converge rebuilt images that match originals including Authenticode layout. The repo ships structured assembly sources, pack metadata, per-component reports, and Chinese-language deep dives into capabilities, protocols, component interaction, and bypass-oriented analysis matrices. It is aimed at researchers and educators studying game anti-cheat internals, driver behavior, and integrity protection, and it distributes only text artifacts rather than signed executables or samples.
