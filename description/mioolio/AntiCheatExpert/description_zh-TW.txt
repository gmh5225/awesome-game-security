AntiCheatExpert 是一個安全研究儲存庫，針對商業版 AntiCheatExpert 套件（涵蓋核心驅動程式、使用者模式服務、外掛程式及相關 PE 元件）進行文件化與逆向工程，並提供工具以便從還原的組合語言逐位元組重建各二進位檔。工作流程以 Python 工具為中心，包含 PE 剖析、Capstone 反組譯、差異報告、IOCTL 表擷取與記錄加密分析，並搭配 Microsoft MASM（ml64）與自訂 COFF 連結器，使重建映像檔在 Authenticode 配置等方面與原版一致。儲存庫提供結構化組合語言原始碼、封裝中繼資料、各元件報告，以及關於能力、通訊協定、元件互動與繞過導向分析矩陣的中文深度說明。目標讀者為研究遊戲反作弊內部機制、驅動程式行為與完整性保護的研究者與教育者，僅散佈文字類產物，不提供簽署可執行檔或樣本。
