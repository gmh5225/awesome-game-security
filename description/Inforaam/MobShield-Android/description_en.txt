MobShield Android is an open-source runtime application self-protection library that hardens mobile apps by running modular on-device detectors and aggregating their results into weighted threat events. It is implemented primarily in Kotlin with native C/C++ checks across optional modules for root and platform integrity (including Magisk, Zygisk, and KernelSU), hook frameworks (Frida, LSPosed, and Xposed), debuggers, emulators and automation, and APK or signature integrity. The core engine scores and reports posture through listeners, supports optional process termination policies, and can sign attested reports for server verification via Android Keystore or Play Integrity, with a Gradle plugin that personalizes native builds per app release. Coverage is documented against OWASP MASVS resilience controls and is aimed at developers who need auditable client-side anti-tampering and anti-analysis signals for games and high-risk Android apps, as one layer of defense in depth alongside backend checks.
