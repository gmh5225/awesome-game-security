discord-dpi-bridge は、WinDivert などのカーネルパケット傍受ドライバーをインストールすることなく（Denuvo Anti-Cheat や Easy Anti-Cheat などのアンチチートがこれらを拒否することが多い）、DPI ブロック下でも Discord がインターネットに接続できる Windows 向けセットアップです。ByeDPI をユーザースペース SOCKS5 プロキシとして、Discord アップデーター向けの PowerShell TCP-to-SOCKS5 リレー、ISP の DNS ハイジャック回避のための DNS over HTTPS、および hosts ファイルと Chromium プロキシフラグを組み合わせ、Discord のチャットクライアントとアップデーターの両方が接続できるようにしています。プロジェクトは JSON 設定付きの PowerShell インストール・状態確認・修復・アンインストールスクリプトとして提供され、Python などの追加ランタイムを必要とせず、Windows 組み込みの PowerShell のみで動作します。Discord がブロックされている地域で、ARC Raiders などのアンチチート保護付きゲームと Discord を同時に使いたいが、従来の GoodbyeDPI 方式のカーネルバイパスツールではゲームが起動しなくなるようなゲーマー向けです。
