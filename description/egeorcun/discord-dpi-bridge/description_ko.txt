discord-dpi-bridge는 WinDivert 같은 커널 패킷 가로채기 드라이버를 설치하지 않고도(Denuvo Anti-Cheat, Easy Anti-Cheat 등 안티치트가 이를 거부하는 경우가 많음) DPI 차단 환경에서 Discord가 인터넷에 접속할 수 있게 하는 Windows 설정입니다. ByeDPI를 사용자 공간 SOCKS5 프록시로, Discord 업데이터용 PowerShell TCP-to-SOCKS5 릴레이, ISP DNS 하이재킹 우회를 위한 DNS over HTTPS, 그리고 hosts 파일과 Chromium 프록시 플래그를 결합하여 Discord 채팅 클라이언트와 업데이터 모두 연결할 수 있게 합니다. 프로젝트는 JSON 구성이 포함된 PowerShell 설치, 상태 확인, 수정, 제거 스크립트로 제공되며, Python 등 추가 런타임 없이 Windows 내장 PowerShell만 필요합니다. Discord가 차단된 지역에서 ARC Raiders 같은 안티치트 보호 게임과 Discord를 동시에 사용해야 하지만, 기존 GoodbyeDPI 방식의 커널 우회 도구는 게임 실행을 막는 게이머를 대상으로 합니다.
