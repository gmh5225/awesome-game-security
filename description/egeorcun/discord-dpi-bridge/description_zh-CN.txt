discord-dpi-bridge 是一套 Windows 配置方案，可让 Discord 在深度包检测（DPI）封锁环境下访问互联网，且无需安装 WinDivert 等内核级数据包拦截驱动——这类驱动通常会被 Denuvo Anti-Cheat、Easy Anti-Cheat 等反作弊系统拒绝。它将 ByeDPI 作为用户空间 SOCKS5 代理、用于 Discord 更新程序的 PowerShell TCP-to-SOCKS5 中继、DNS over HTTPS 以绕过 ISP 的 DNS 劫持，以及 hosts 文件与 Chromium 代理标记，使 Discord 聊天客户端和更新程序均可正常连接。项目以 PowerShell 安装、状态查看、修复和卸载脚本及 JSON 配置形式提供，仅依赖 Windows 内置 PowerShell，无需 Python 或其他运行时。面向 Discord 遭封锁地区、需要同时使用 Discord 与 ARC Raiders 等受反作弊保护的游戏、而又无法使用会阻止游戏启动的 GoodbyeDPI 式内核绕过工具的玩家。
