discord-dpi-bridge est une configuration Windows qui permet à Discord d'accéder à Internet malgré le blocage DPI, sans installer de pilotes d'interception de paquets au niveau noyau tels que WinDivert, que les systèmes anti-triche comme Denuvo Anti-Cheat et Easy Anti-Cheat refusent couramment. Il combine ByeDPI en tant que proxy SOCKS5 en espace utilisateur, un relais PowerShell TCP-to-SOCKS5 pour le programme de mise à jour de Discord, DNS over HTTPS pour contourner le détournement DNS des FAI, ainsi que des entrées hosts et des drapeaux de proxy Chromium afin que le client de chat et le programme de mise à jour de Discord puissent tous deux se connecter. Le projet est livré sous forme de scripts PowerShell d'installation, d'état, de correction et de désinstallation avec configuration JSON, et ne nécessite que PowerShell Windows intégré, sans Python ni autre dépendance d'exécution. Il s'adresse aux joueurs dans les régions où Discord est bloqué et qui ont besoin d'utiliser Discord et des jeux protégés par anti-triche tels qu'ARC Raiders simultanément, lorsque les outils de contournement noyau de type GoodbyeDPI empêcheraient le jeu de se lancer.
