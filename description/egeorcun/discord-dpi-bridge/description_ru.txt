discord-dpi-bridge — это конфигурация для Windows, которая позволяет Discord выходить в интернет при блокировке DPI без установки драйверов перехвата пакетов на уровне ядра, таких как WinDivert, которые системы античита вроде Denuvo Anti-Cheat и Easy Anti-Cheat обычно отклоняют. Решение объединяет ByeDPI в качестве SOCKS5-прокси в пользовательском пространстве, PowerShell-реле TCP-to-SOCKS5 для программы обновления Discord, DNS over HTTPS для обхода подмены DNS провайдером, а также записи hosts и флаги прокси Chromium, чтобы и клиент чата Discord, и программа обновления могли подключаться. Проект поставляется в виде PowerShell-скриптов установки, проверки статуса, исправления и удаления с конфигурацией JSON и требует только встроенный Windows PowerShell без Python и других зависимостей среды выполнения. Он предназначен для геймеров в регионах, где Discord заблокирован, и которым нужно одновременно использовать Discord и игры с античитом, такие как ARC Raiders, когда традиционные инструменты обхода на уровне ядра в стиле GoodbyeDPI мешают запуску игры.
