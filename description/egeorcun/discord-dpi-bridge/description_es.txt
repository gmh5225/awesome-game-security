discord-dpi-bridge es una configuración para Windows que permite a Discord acceder a Internet a través del bloqueo DPI sin instalar controladores de interceptación de paquetes en el kernel como WinDivert, que sistemas anti-cheat como Denuvo Anti-Cheat y Easy Anti-Cheat suelen rechazar. Combina ByeDPI como proxy SOCKS5 en espacio de usuario, un relé PowerShell TCP-to-SOCKS5 para el actualizador de Discord, DNS over HTTPS para eludir el secuestro de DNS del ISP, y entradas hosts más indicadores de proxy de Chromium para que tanto el cliente de chat como el actualizador de Discord puedan conectarse. El proyecto se distribuye como scripts de PowerShell para instalación, estado, reparación y desinstalación con configuración JSON, y solo requiere PowerShell integrado de Windows, sin Python ni otras dependencias de tiempo de ejecución. Está dirigido a jugadores en regiones donde Discord está bloqueado y necesitan usar Discord y juegos protegidos por anti-cheat como ARC Raiders al mismo tiempo, cuando las herramientas tradicionales de bypass en el kernel al estilo GoodbyeDPI impedirían que el juego se inicie.
