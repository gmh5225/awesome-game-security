discord-dpi-bridge is a Windows setup that lets Discord reach the internet through DPI blocking without installing kernel packet-interception drivers such as WinDivert, which anti-cheat systems like Denuvo Anti-Cheat and Easy Anti-Cheat commonly reject. It combines ByeDPI as a user-space SOCKS5 proxy, a PowerShell TCP-to-SOCKS5 relay for Discord's updater, DNS over HTTPS to bypass ISP DNS hijacking, and hosts plus Chromium proxy flags so both Discord's chat client and updater can connect. The project ships as PowerShell install, status, fix, and uninstall scripts with JSON configuration, and requires only built-in Windows PowerShell with no Python or other runtime dependencies. It is aimed at gamers in regions where Discord is blocked who need Discord and anti-cheat-protected games such as ARC Raiders to run at the same time, when traditional GoodbyeDPI-style kernel bypass tools would prevent the game from launching.
