DetourAPIHook 是一個模組化的 Windows API 掛鉤框架，透過 16 個獨立掛鉤模組攔截約 130 個系統呼叫，以繞過遊戲反作弊保護。該專案主要使用 C++ 編寫，基於 Microsoft Detours 建構，以 dinput8.dll 代理形式部署，可透明地透過 DLL 劫持注入到 x64 和 x86 遊戲程序中。核心功能包括程序與模組隱藏、反除錯中和、硬體與網路身分偽裝、記憶體完整性繞過、多執行個體支援，以及呼叫端檢查引擎——該引擎可選擇性攔截來自已知保護模組的請求。此框架針對 NGS、BlackCipher、HackShield、XignCode、GameGuard 和 TenProtect 等商業反作弊系統，適用於遊戲安全研究、逆向工程以及研究用戶端保護機制的運作方式。
