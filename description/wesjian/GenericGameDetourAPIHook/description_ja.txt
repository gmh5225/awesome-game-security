DetourAPIHook は、16 個の独立したフックモジュールで約 130 個のシステムコールを傍受し、ゲームのアンチチート保護を回避するモジュール型 Windows API フックフレームワークです。主に C++ で記述され、Microsoft Detours でビルドされ、dinput8.dll プロキシとして展開され、x64 および x86 ゲームプロセスへの透過的な DLL ハイジャック注入を実現します。主な機能には、プロセスおよびモジュールの隠蔽、反デバッグの無効化、ハードウェアおよびネットワーク ID の偽装、メモリ整合性のバイパス、マルチインスタンス対応、既知の保護モジュールからのリクエストを選択的にブロックする呼び出し元チェックエンジンが含まれます。このフレームワークは NGS、BlackCipher、HackShield、XignCode、GameGuard、TenProtect などの商用アンチチートシステムを対象とし、ゲームセキュリティ研究、リバースエンジニアリング、クライアント側保護の動作を調査する目的で設計されています。
