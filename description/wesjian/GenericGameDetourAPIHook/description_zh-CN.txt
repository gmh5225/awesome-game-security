DetourAPIHook 是一个模块化的 Windows API 挂钩框架，通过 16 个独立挂钩模块拦截约 130 个系统调用，以绕过游戏反作弊保护。该项目主要使用 C++ 编写，基于 Microsoft Detours 构建，以 dinput8.dll 代理形式部署，可透明地通过 DLL 劫持注入到 x64 和 x86 游戏进程中。核心功能包括进程与模块隐藏、反调试中和、硬件与网络身份伪装、内存完整性绕过、多实例支持，以及调用方检查引擎——该引擎可选择性拦截来自已知保护模块的请求。该框架针对 NGS、BlackCipher、HackShield、XignCode、GameGuard 和 TenProtect 等商业反作弊系统，适用于游戏安全研究、逆向工程以及研究客户端保护机制的运行方式。
