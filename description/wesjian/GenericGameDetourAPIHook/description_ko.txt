DetourAPIHook은 16개의 독립적인 후크 모듈을 통해 약 130개의 시스템 호출을 가로채 게임 안티치트 보호를 우회하는 모듈형 Windows API 후킹 프레임워크입니다. 주로 C++로 작성되었으며 Microsoft Detours로 빌드되며, dinput8.dll 프록시로 배포되어 x64 및 x86 게임 프로세스에 투명한 DLL 하이재킹 주입을 수행합니다. 주요 기능으로는 프로세스 및 모듈 숨김, 안티디버그 무력화, 하드웨어 및 네트워크 ID 스푸핑, 메모리 무결성 우회, 다중 인스턴스 지원, 알려진 보호 모듈의 요청을 선택적으로 차단하는 호출자 검사 엔진이 있습니다. 이 프레임워크는 NGS, BlackCipher, HackShield, XignCode, GameGuard, TenProtect 등 상용 안티치트 시스템을 대상으로 하며, 게임 보안 연구, 리버스 엔지니어링, 클라이언트 측 보호 메커니즘의 동작 방식 연구를 목적으로 합니다.
