DetourAPIHook is a modular Windows API hooking framework that bypasses game anti-cheat protections by intercepting roughly 130 system calls across 16 independent hook modules. Written primarily in C++ and built with Microsoft Detours, it deploys as a dinput8.dll proxy for transparent DLL hijack injection into x64 and x86 game processes. Key capabilities include process and module hiding, anti-debug neutralization, hardware and network identity spoofing, memory integrity bypass, multi-instance support, and a caller-check engine that selectively blocks requests from known protection modules. The framework targets commercial anti-cheat systems such as NGS, BlackCipher, HackShield, XignCode, GameGuard, and TenProtect, and is intended for game security research, reverse engineering, and studying how client-side protections operate.
