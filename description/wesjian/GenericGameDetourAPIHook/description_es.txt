DetourAPIHook es un framework modular de hooking de API de Windows que elude las protecciones anti-cheat de los juegos interceptando aproximadamente 130 llamadas al sistema distribuidas en 16 módulos de hook independientes. Escrito principalmente en C++ y compilado con Microsoft Detours, se despliega como un proxy de dinput8.dll para una inyección transparente mediante secuestro de DLL en procesos de juegos x64 y x86. Sus capacidades clave incluyen ocultación de procesos y módulos, neutralización anti-debug, suplantación de identidad de hardware y red, bypass de integridad de memoria, soporte multi-instancia y un motor de verificación de llamadores que bloquea selectivamente solicitudes de módulos de protección conocidos. El framework está dirigido a sistemas anti-cheat comerciales como NGS, BlackCipher, HackShield, XignCode, GameGuard y TenProtect, y está pensado para investigación en seguridad de juegos, ingeniería inversa y el estudio del funcionamiento de las protecciones del lado del cliente.
