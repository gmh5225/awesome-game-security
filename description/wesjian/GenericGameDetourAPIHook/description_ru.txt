DetourAPIHook — модульный фреймворк для перехвата API Windows, обходящий античит-защиту игр путём перехвата примерно 130 системных вызовов через 16 независимых модулей хуков. Написан преимущественно на C++ и собран с помощью Microsoft Detours, развёртывается как прокси dinput8.dll для прозрачной инъекции через DLL hijacking в игровые процессы x64 и x86. Ключевые возможности включают скрытие процессов и модулей, нейтрализацию антиотладки, подмену аппаратной и сетевой идентичности, обход проверки целостности памяти, поддержку нескольких экземпляров и движок проверки вызывающей стороны, который избирательно блокирует запросы от известных защитных модулей. Фреймворк нацелен на коммерческие античит-системы, такие как NGS, BlackCipher, HackShield, XignCode, GameGuard и TenProtect, и предназначен для исследований безопасности игр, реверс-инжиниринга и изучения работы клиентских защитных механизмов.
