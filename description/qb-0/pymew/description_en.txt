Pymew is a Python library for external game memory manipulation and transparent overlays. It exposes a high-level API to open processes, enumerate modules and memory regions, read and write typed values, and define struct layouts, including helpers for common game string formats. The overlay stack supports drawing primitives, fonts, colors, input capture, and global hotkeys, with optional ImGui integration for building on-screen tools. The runtime is implemented primarily in Nim and ships as a pip-installable extension with type stubs for editors and static checkers. It targets Windows and Linux and is aimed at developers building external cheat prototypes, ESP-style visuals, and similar game security or reverse-engineering experiments in 64-bit Python 3.7+.
