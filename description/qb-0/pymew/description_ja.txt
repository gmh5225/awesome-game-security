Pymew は、外部からゲームメモリを操作し透明オーバーレイを描画するための Python ライブラリです。プロセスのオープン、モジュールとメモリ領域の列挙、型付き値の読み書き、構造体レイアウトの定義に加え、一般的なゲーム用文字列形式向けのヘルパーを高水準 API で提供します。オーバーレイスタックは描画プリミティブ、フォント、色、入力キャプチャ、グローバルホットキーをサポートし、画面上のツール構築用に ImGui 連携も任意で利用できます。ランタイムは主に Nim で実装され、pip でインストール可能な拡張として配布され、エディタや静的解析向けの型スタブも同梱されます。Windows と Linux を対象とし、64 ビット Python 3.7 以降で外部チートのプロトタイプ、ESP 系の可視化、同種のゲームセキュリティやリバースエンジニアリング実験を行う開発者向けです。
