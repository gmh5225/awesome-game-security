Pymew — библиотека Python для внешней работы с памятью игр и прозрачных оверлеев. Она предоставляет высокоуровневый API для открытия процессов, перечисления модулей и областей памяти, чтения и записи типизированных значений и описания раскладок структур, включая вспомогательные средства для распространённых строковых форматов в играх. Стек оверлея поддерживает примитивы рисования, шрифты, цвета, захват ввода и глобальные горячие клавиши, с опциональной интеграцией ImGui для построения экранных инструментов. Среда выполнения в основном реализована на Nim и поставляется как расширение, устанавливаемое через pip, со стабами типов для редакторов и статических анализаторов. Поддерживаются Windows и Linux; ориентирована на разработчиков, создающих внешние прототипы читов, визуализацию в стиле ESP и подобные эксперименты в области безопасности игр и реверс-инжиниринга на 64-разрядном Python 3.7+.
