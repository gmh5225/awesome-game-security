Pymew는 외부 게임 메모리 조작과 투명 오버레이를 위한 Python 라이브러리입니다. 프로세스 열기, 모듈 및 메모리 영역 열거, 형식이 지정된 값 읽기·쓰기, 구조체 레이아웃 정의를 위한 고수준 API를 제공하며, 흔한 게임 문자열 형식용 헬퍼도 포함합니다. 오버레이 스택은 그리기 원시 요소, 글꼴, 색상, 입력 캡처, 전역 단축키를 지원하고, 화면 도구 구축을 위해 ImGui 연동을 선택적으로 사용할 수 있습니다. 런타임은 주로 Nim으로 구현되며 pip으로 설치 가능한 확장 형태로 배포되고, 편집기와 정적 검사기용 타입 스텁을 제공합니다. Windows와 Linux를 대상으로 하며, 64비트 Python 3.7 이상 환경에서 외부 치트 프로토타입, ESP 스타일 시각화, 유사한 게임 보안·리버스 엔지니어링 실험을 만드는 개발자를 위한 도구입니다.
