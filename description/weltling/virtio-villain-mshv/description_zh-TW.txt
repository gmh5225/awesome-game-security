本儲存庫是針對 Linux Microsoft Hypervisor (MSHV) 使用者空間 API 的測試套件，聚焦分割區生命週期與虛擬處理器行為。它整合 Virtio Villain 框架，在巢狀 Hyper-V 下透過 Cloud Hypervisor（MSHV）或 OpenVMM（KVM 與巢狀虛擬化）啟動自訂 Linux 核心與 initramfs。套件主要以 C 實作來賓內測試，以 Python 建置開機映像、取得 ESP 與 OpenVMM 韌體元件，並透過 Make 編排流程。涵蓋生命週期邊界、隔離、來賓記憶體、IRQ eventfd 以及 VP 暫存器或 CPUID 操作等結構化案例，並包含建置管線的主機端自測。面向需要可重複、以 appliance 為基礎的 MSHV 根分割區支援及 hypervisor UAPI 正確性驗證的虛擬化與平台安全研究人員，目標平台為 x86-64。
