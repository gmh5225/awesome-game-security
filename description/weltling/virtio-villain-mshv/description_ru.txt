Этот репозиторий — набор тестов для userspace API Linux Microsoft Hypervisor (MSHV) с упором на жизненный цикл разделов и поведение виртуального процессора. Он подключается к фреймворку Virtio Villain для загрузки пользовательского ядра Linux и initramfs во вложенном Hyper-V через Cloud Hypervisor с MSHV или OpenVMM с KVM и вложенной виртуализацией. Набор в основном реализован на C для тестов внутри гостя и на Python для сборки загрузочных образов, получения компонентов прошивки ESP и OpenVMM и оркестрации через Make. Включены структурированные сценарии для граничных случаев жизненного цикла, изоляции, памяти гостя, IRQ eventfd и операций с регистрами VP или CPUID, а также host-side selftests для конвейера сборки. Целевая аудитория — исследователи виртуализации и безопасности платформ, которым нужна воспроизводимая appliance-ориентированная проверка поддержки корневого раздела MSHV и корректности hypervisor UAPI на x86-64.
