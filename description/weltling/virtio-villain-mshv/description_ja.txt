本リポジトリは、Linux Microsoft Hypervisor (MSHV) のユーザースペース API 向けテストスイートで、パーティションのライフサイクルと仮想プロセッサの挙動に焦点を当てています。Virtio Villain フレームワークに組み込まれ、ネストした Hyper-V 上で Cloud Hypervisor（MSHV）または OpenVMM（KVM とネスト仮想化）を使ってカスタム Linux カーネルと initramfs を起動します。スイートは主に C でゲスト内テストを、Python でブートイメージのビルド、ESP および OpenVMM ファームウェアコンポーネントの取得、Make によるオーケストレーションを実装しています。ライフサイクルのエッジケース、隔離、ゲストメモリ、IRQ eventfd、VP レジスタや CPUID 操作などの構造化されたケースを含み、ビルドパイプライン向けのホスト側セルフテストも備えています。MSHV ルートパーティション対応と hypervisor UAPI の正しさを、再現可能な appliance ベースで検証したい仮想化およびプラットフォームセキュリティ研究者向けで、x86-64 を対象としています。
