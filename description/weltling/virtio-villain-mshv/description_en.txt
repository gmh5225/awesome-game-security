This repository is a test suite for the Linux Microsoft Hypervisor (MSHV) userspace API, focused on partition lifecycle and virtual processor behavior. It plugs into the Virtio Villain framework to boot a custom Linux kernel and initramfs under nested Hyper-V using Cloud Hypervisor with MSHV or OpenVMM with KVM and nested virtualization. The suite is implemented mainly in C for in-guest tests and Python for building boot images, fetching ESP and OpenVMM firmware components, and orchestration via Make. It includes structured cases for lifecycle edge cases, isolation, guest memory, IRQ eventfds, and VP register or CPUID operations, with host-side selftests for the build pipeline. It targets virtualization and platform security researchers who need repeatable, appliance-based validation of MSHV root-partition support and hypervisor UAPI correctness on x86-64.
