本仓库是针对 Linux Microsoft Hypervisor (MSHV) 用户空间 API 的测试套件，侧重分区生命周期与虚拟处理器行为。它接入 Virtio Villain 框架，在嵌套 Hyper-V 下通过 Cloud Hypervisor（MSHV）或 OpenVMM（KVM 与嵌套虚拟化）启动自定义 Linux 内核与 initramfs。套件主要用 C 实现来宾内测试，用 Python 构建启动镜像、获取 ESP 与 OpenVMM 固件组件，并通过 Make 编排流程。涵盖生命周期边界、隔离、来宾内存、IRQ eventfd 以及 VP 寄存器或 CPUID 操作等结构化用例，并包含构建流水线的主机端自测。面向需要可重复、基于 appliance 的 MSHV 根分区支持及 hypervisor UAPI 正确性验证的虚拟化与平台安全研究人员，目标平台为 x86-64。
