Este repositorio es una suite de pruebas para la API de espacio de usuario de Linux Microsoft Hypervisor (MSHV), centrada en el ciclo de vida de particiones y el comportamiento del procesador virtual. Se integra en el framework Virtio Villain para arrancar un kernel Linux e initramfs personalizados bajo Hyper-V anidado mediante Cloud Hypervisor con MSHV u OpenVMM con KVM y virtualización anidada. La suite está implementada principalmente en C para pruebas dentro del invitado y en Python para construir imágenes de arranque, obtener componentes de firmware ESP y OpenVMM, y la orquestación vía Make. Incluye casos estructurados para casos límite del ciclo de vida, aislamiento, memoria del invitado, eventfd de IRQ, y operaciones de registro VP o CPUID, con autopruebas en el host para la canalización de compilación. Está dirigida a investigadores de virtualización y seguridad de plataforma que necesitan validación repetible basada en appliance del soporte de partición raíz MSHV y la corrección de la UAPI del hipervisor en x86-64.
