Questo repository è una suite di test per l’API userspace Linux Microsoft Hypervisor (MSHV), incentrata sul ciclo di vita delle partizioni e sul comportamento del processore virtuale. Si integra nel framework Virtio Villain per avviare un kernel Linux e initramfs personalizzati sotto Hyper-V annidato tramite Cloud Hypervisor con MSHV o OpenVMM con KVM e virtualizzazione annidata. La suite è implementata principalmente in C per i test in guest e in Python per costruire le immagini di avvio, recuperare i componenti firmware ESP e OpenVMM e l’orchestrazione via Make. Include casi strutturati per casi limite del ciclo di vita, isolamento, memoria guest, eventfd IRQ e operazioni su registro VP o CPUID, con selftest lato host per la pipeline di build. È rivolta a ricercatori di virtualizzazione e sicurezza di piattaforma che necessitano di una validazione ripetibile basata su appliance del supporto partizione root MSHV e della correttezza dell’UAPI dell’ipervisore su x86-64.
