dmn_minigame 是一套包含十二款可嵌入浏览器小游戏的合集，配有全球排行榜；分数在服务端计算，而非信任客户端。浏览器仅以与 tick 对齐的日志记录玩家输入；API 使用与 Web 客户端和 Fastify 后端共享的相同种子、位级一致的仿真回放每一次运行，因此无法通过简单的 HTTP POST 伪造提交分数。游戏逻辑以 TypeScript 编写，遵循严格确定性规则（固定 tick 率、受控随机性、无可移植性问题的数学运算），UI 使用 React 与 Vite，持久化使用 SQLite，并具备会话令牌、日志校验、速率限制与一次性会话消耗。面向学习或实现线上分数游戏安全与反作弊模式的开发者，可嵌入网页或游戏客户端（例如 FiveM NUI iframe）。
