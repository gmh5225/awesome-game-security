dmn_minigame 是一套包含十二款可嵌入瀏覽器小遊戲的合輯，配有全球排行榜；分數在伺服端計算，而非信任客戶端。瀏覽器僅以與 tick 對齊的日誌記錄玩家輸入；API 使用與 Web 客戶端和 Fastify 後端共享的相同種子、位元級一致的模擬回放每一次執行，因此無法透過簡單的 HTTP POST 偽造提交分數。遊戲邏輯以 TypeScript 撰寫，遵循嚴格確定性規則（固定 tick 率、受控隨機性、無可移植性問題的數學運算），UI 使用 React 與 Vite，持久化使用 SQLite，並具備工作階段權杖、日誌驗證、速率限制與一次性工作階段消耗。面向學習或實作線上分數遊戲安全與反作弊模式的開發者，可嵌入網頁或遊戲客戶端（例如 FiveM NUI iframe）。
