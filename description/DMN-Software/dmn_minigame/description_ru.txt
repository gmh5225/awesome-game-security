dmn_minigame — коллекция из двенадцати встраиваемых браузерных мини-игр с глобальной таблицей лидеров, где очки вычисляются на сервере, а не доверяются клиенту. Браузер записывает только ввод игрока в виде логов, выровненных по тикам; API воспроизводит каждый забег той же сидированной, побитово идентичной симуляцией, общей для веб-клиента и бэкенда Fastify, поэтому отправленные очки нельзя подделать простым HTTP POST. Игровая логика написана на TypeScript с жёсткими правилами детерминизма (фиксированная частота тиков, контролируемая случайность, без непереносимой математики), UI на React и Vite, хранение в SQLite, плюс токены сессий, проверка логов, лимиты частоты и одноразовое использование сессии. Проект для разработчиков, изучающих или внедряющих безопасность игр и античит для онлайн-очков; его можно встраивать в страницы или игровые клиенты, например iframe FiveM NUI.
