dmn_minigame is a self-contained embeddable web platform with twelve classic-style minigames and a global leaderboard. Instead of trusting client-submitted scores, the browser records a tick-by-tick input log and a Fastify API replays that log through the same deterministic TypeScript simulation shared between web and server to compute every ranking. The design enforces bit-identical cross-runtime behavior with strict rules on RNG, timing, and math, plus session tokens, log validation, atomic one-time submission, rate limits, and SQLite-backed storage. It is built with React and Vite on the frontend, Node 24 with node:sqlite on the backend, and ships with Docker deployment, replay tests, and documentation of the model’s limits. The project is a practical reference for server-authoritative scoring, anti-tamper leaderboards, and game-security patterns in browser and iframe-embedded contexts.
