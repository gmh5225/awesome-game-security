dmn_minigame is a collection of twelve embeddable browser minigames with a global leaderboard that derives scores on the server instead of trusting the client. The browser records only player inputs as tick-aligned logs; the API replays each run with the same seeded, bit-identical simulation shared between the web client and Fastify backend, so submitted scores cannot be forged with a simple HTTP POST. Game logic is written in TypeScript under strict determinism rules (fixed tick rate, controlled randomness, no non-portable math), with React and Vite for the UI and SQLite for persistence, plus session tokens, log validation, rate limits, and one-time session consumption. It targets developers learning or implementing game security and anti-cheat patterns for online scores, and can be embedded in pages or game clients such as FiveM NUI iframes.
