dmn_minigame は、グローバルリーダーボード付きの埋め込み可能なブラウザミニゲーム 12 種のコレクションで、クライアントを信頼するのではなくサーバー側でスコアを算出します。ブラウザはプレイヤー入力のみを tick 揃えのログとして記録し、API は Web クライアントと Fastify バックエンドで共有する同一シード・ビット同一のシミュレーションで各プレイを再生するため、単純な HTTP POST では送信スコアを偽造できません。ゲームロジックは TypeScript で厳格な決定性ルール（固定 tick レート、制御された乱数、非ポータブルな数学演算なし）の下で書かれ、UI に React と Vite、永続化に SQLite を使い、セッショントークン、ログ検証、レート制限、一度きりのセッション消費も備えます。オンラインスコア向けのゲームセキュリティやアンチチートパターンを学ぶ・実装する開発者向けで、ページや FiveM NUI iframe などのゲームクライアントに埋め込めます。
