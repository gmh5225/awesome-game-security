dmn_minigame 은 전역 리더보드가 있는 열두 가지 임베드 가능 브라우저 미니게임 모음으로, 클라이언트를 신뢰하지 않고 서버에서 점수를 계산합니다. 브라우저는 플레이어 입력만 tick 에 맞춘 로그로 기록하고, API 는 웹 클라이언트와 Fastify 백엔드가 공유하는 동일 시드·비트 단위 동일 시뮬레이션으로 각 플레이를 재생하므로 단순 HTTP POST 로 제출 점수를 위조할 수 없습니다. 게임 로직은 TypeScript 로 엄격한 결정론 규칙(고정 tick 속도, 제어된 난수, 이식 불가 수학 없음) 아래 작성되며, UI 에는 React 와 Vite, 영속성에는 SQLite 를 쓰고 세션 토큰, 로그 검증, 속도 제한, 일회성 세션 소비도 포함합니다. 온라인 점수용 게임 보안 및 안티치트 패턴을 배우거나 구현하는 개발자를 대상으로 하며, 페이지나 FiveM NUI iframe 같은 게임 클라이언트에 임베드할 수 있습니다.
