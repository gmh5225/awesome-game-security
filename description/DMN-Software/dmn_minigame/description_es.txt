dmn_minigame es una colección de doce minijuegos de navegador integrables con una tabla de clasificación global que calcula las puntuaciones en el servidor en lugar de confiar en el cliente. El navegador registra solo las entradas del jugador como registros alineados con ticks; la API reproduce cada partida con la misma simulación con semilla compartida e idéntica a nivel de bits entre el cliente web y el backend Fastify, de modo que las puntuaciones enviadas no pueden falsificarse con un simple POST HTTP. La lógica del juego está escrita en TypeScript bajo reglas estrictas de determinismo (tasa de tick fija, aleatoriedad controlada, sin matemáticas no portables), con React y Vite para la interfaz y SQLite para persistencia, además de tokens de sesión, validación de registros, límites de tasa y consumo único de sesión. Está dirigido a desarrolladores que aprenden o implementan patrones de seguridad de juegos y anti-trampas para puntuaciones en línea, y puede integrarse en páginas o clientes de juego como iframes de FiveM NUI.
