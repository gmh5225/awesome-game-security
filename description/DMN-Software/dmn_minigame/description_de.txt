dmn_minigame ist eine Sammlung von zwölf einbettbaren Browser-Minispielen mit einer globalen Bestenliste, die Punkte serverseitig berechnet, statt dem Client zu vertrauen. Der Browser protokolliert nur Spielereingaben als tick-ausgerichtete Logs; die API spielt jeden Lauf mit derselben geseedeten, bitidentischen Simulation nach, die Web-Client und Fastify-Backend teilen, sodass eingereichte Scores nicht per einfachem HTTP-POST gefälscht werden können. Die Spiellogik ist in TypeScript unter strengen Determinismusregeln geschrieben (feste Tick-Rate, kontrollierte Zufälligkeit, keine nicht portierbare Mathematik), mit React und Vite für die UI und SQLite für Persistenz, plus Session-Tokens, Log-Validierung, Ratenlimits und einmaligen Session-Verbrauch. Es richtet sich an Entwickler, die Spielesicherheit und Anti-Cheat-Muster für Online-Scores lernen oder umsetzen, und kann in Seiten oder Spielclients wie FiveM-NUI-Iframes eingebettet werden.
