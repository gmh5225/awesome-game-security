Silent AntiCheat — это мод античита только для сервера и только с оповещениями для Minecraft 26.2, построенный на загрузчике Fabric. Написанный на Java, он обнаруживает подозрительный полёт или зависание, читы на скорость или телепорт, а также reach, никогда не кикая, не баня и не применяя rubberbanding к игрокам, вместо этого отправляя стилизованные предупреждения в консоль сервера и онлайн-операторам. Обнаружение выполняется полностью на сервере через отслеживание движения каждый tick и проверки дистанции атаки или разрушения блоков, с консервативными настраиваемыми порогами для снижения ложных срабатываний. Проект использует хуки Fabric API для серверного tick и событий игроков и поставляется как мод, собранный Gradle, который обычным подключающимся игрокам не нужно устанавливать. Он ориентирован на операторов серверов Minecraft и специалистов по безопасности игр, которым нужен лёгкий, безнаказательный мониторинг читов на серверах Fabric.
