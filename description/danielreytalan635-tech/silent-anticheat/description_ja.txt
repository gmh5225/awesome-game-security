Silent AntiCheat は、Fabric loader 上に構築された Minecraft 26.2 向けのサーバー専用・警告のみの anticheat モッドです。Java で記述されており、疑わしいフライトやホバー、スピードやテレポート、reach チートを検出しますが、キック、BAN、rubberbanding（引き戻し）は一切行わず、代わりにスタイル付きの警告メッセージをサーバーコンソールとオンラインのオペレーターへ送信します。検出はサーバー上で完全に実行され、毎 tick の移動追跡および攻撃・ブロック破壊の距離チェックにより動作し、誤検知を抑えるため保守的で調整可能な閾値を備えています。本プロジェクトは Fabric API のサーバー tick およびプレイヤーイベントフックを使用し、Gradle でビルドされたモッドとして提供されるため、通常の接続プレイヤーはインストール不要です。Fabric サーバーで軽量かつ非罰則型のチート監視を求める Minecraft サーバーオペレーターやゲームセキュリティ担当者を対象としています。
