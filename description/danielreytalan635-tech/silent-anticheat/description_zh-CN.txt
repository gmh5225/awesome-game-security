Silent AntiCheat 是一款基于 Fabric loader、面向 Minecraft 26.2 的纯服务端、仅告警反作弊模组。该模组使用 Java 编写，可检测可疑的飞行或悬浮、加速或传送以及 reach 作弊行为，但不会对玩家执行踢出、封禁或 rubberbanding 操作，而是向服务器控制台和在线管理员发送格式化的告警消息。检测完全在服务端运行，通过每 tick 移动追踪以及攻击或破坏方块的距离检查实现，并采用保守且可调节的阈值来降低误报。项目使用 Fabric API 的服务端 tick 与玩家事件钩子，以 Gradle 构建的模组形式发布，普通连接的玩家无需安装。它面向希望在 Fabric 服务器上实现轻量级、非惩罚式作弊监控的 Minecraft 服务器管理员和游戏安全人员。
