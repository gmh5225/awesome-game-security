Silent AntiCheat는 Fabric loader 기반의 Minecraft 26.2용 서버 전용 알림 전용 anti-cheat 모드입니다. Java로 작성되었으며, 의심스러운 비행·호버, 속도·순간이동, reach 치트를 감지하지만 플레이어를 추방, 차단 또는 rubberbanding하지 않고, 대신 서버 콘솔과 온라인 운영자에게 스타일이 적용된 경고 메시지를 전송합니다. 감지는 서버에서 매 tick 이동 추적 및 공격·블록 파괴 거리 검사를 통해 전적으로 실행되며, 오탐을 줄이기 위해 보수적이고 조정 가능한 임계값을 사용합니다. 이 프로젝트는 Fabric API 서버 tick 및 플레이어 이벤트 훅을 사용하며, Gradle로 빌드된 모드로 제공되어 일반 접속 플레이어는 설치할 필요가 없습니다. Fabric 서버에서 가볍고 비처벌적인 치트 모니터링을 원하는 Minecraft 서버 운영자 및 게임 보안 담당자를 대상으로 합니다.
