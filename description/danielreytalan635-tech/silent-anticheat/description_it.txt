Silent AntiCheat è un mod anti-cheat solo lato server e solo di allerta per Minecraft 26.2, basato sul loader Fabric. Scritto in Java, rileva cheat sospetti di volo o hover, velocità o teletrasporto e reach, senza mai espellere, bannare o applicare rubberbanding ai giocatori, inviando invece messaggi di allerta stilizzati alla console del server e agli operatori online. Il rilevamento viene eseguito interamente sul server tramite tracciamento del movimento per tick e controlli di distanza per attacchi o rottura dei blocchi, con soglie conservative e regolabili per limitare i falsi positivi. Il progetto utilizza gli hook Fabric API per tick del server ed eventi dei giocatori e viene distribuito come mod compilato con Gradle che i giocatori che si connettono non devono installare. È rivolto agli operatori di server Minecraft e al personale di sicurezza dei giochi che desiderano un monitoraggio dei cheat leggero e non punitivo sui server Fabric.
