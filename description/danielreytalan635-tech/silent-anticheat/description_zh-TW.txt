Silent AntiCheat 是一款基於 Fabric loader、適用於 Minecraft 26.2 的純伺服器端、僅告警反作弊模組。以 Java 撰寫，可偵測可疑的飛行或懸浮、加速或傳送以及 reach 作弊行為，但絕不踢人、封禁或 rubberbanding 玩家，而是向伺服器主控台與線上管理員傳送格式化的告警訊息。偵測完全在伺服器端執行，透過每 tick 移動追蹤以及攻擊或破壞方塊的距離檢查來完成，並採用保守且可調整的閾值以降低誤報。專案使用 Fabric API 的伺服器端 tick 與玩家事件 hook，以 Gradle 建置的模組形式釋出，一般連線玩家無需安裝。它面向希望在 Fabric 伺服器上進行輕量、非懲罰式作弊監控的 Minecraft 伺服器管理員與遊戲安全人員。
