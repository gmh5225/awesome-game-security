This project is a unified client loader for injecting third-party cheat modules into many popular multiplayer games under a subscription license model. The repository root builds a C++20 CMake project named Osiris with optional assembly sources and includes a packaged Electron-style app bundle plus Node package lock metadata for the user interface. Public documentation highlights fast hot-injection into running games, large per-game module sets such as aim assistance and ESP, hardware-ID-bound licensing with periodic resets, and rapid patches after anti-cheat signature changes. It targets Windows with administrator rights and a supported .NET Framework runtime, with install steps that call for disabling real-time antivirus during setup. The primary use case is distributing and updating game cheats while attempting to stay ahead of anti-cheat systems, which matters for studying adversarial tooling and game security defenses.
