Questo progetto è un dossier di reverse engineering basato esclusivamente su memflow che documenta una build esatta del driver kernel Easy Anti-Cheat di Fortnite, catturata dall'esterno di una VM Windows. Utilizzando acquisizioni passive di memoria fisica e layout PDB del kernel Windows corrispondenti, mappa le superfici kernel registrate di EAC, inclusi callback di processo, thread e immagine, la policy degli handle dell'Object Manager, callback del registro, un minifiltro Filter Manager, IPC del dispositivo e contesti di callback privati per thread. Il repository raccoglie approfondimenti narrativi, appendici tecniche e affermazioni etichettate con evidenze, con strumenti di validazione Python e regole di derivazione riproducibili che escludono materiale di bypass o exploit. È rivolto a ricercatori di sicurezza dei giochi, ingegneri anti-cheat e reverse engineer del kernel Windows che studiano come Easy Anti-Cheat monitora ciclo di vita, persistenza, mappatura degli eseguibili e stato della piattaforma.
