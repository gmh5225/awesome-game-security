本プロジェクトは memflow のみを用いたリバースエンジニアリング資料で、Windows VM の外部から取得した特定の Easy Anti-Cheat Fortnite カーネルドライバービルドを文書化しています。受動的な物理メモリ取得と対応する Windows カーネル PDB レイアウトを用いて、EAC が登録したカーネルインターフェースをマッピングします。対象には、プロセス・スレッド・イメージコールバック、Object Manager のハンドルポリシー、レジストリコールバック、Filter Manager ミニフィルター、デバイス IPC、スレッドごとのプライベートコールバックコンテキストが含まれます。リポジトリには、叙述的な詳細分析、技術付録、Python 検証ツールと再現可能な導出ルール（バイパスや exploit 資料を除外）を伴う根拠付きの主張がまとめられています。Easy Anti-Cheat がライフサイクル、永続化、実行可能イメージのマッピング、プラットフォーム状態をどのように監視するかを研究する、ゲームセキュリティ研究者、アンチチートエンジニア、Windows カーネルリバースエンジニア向けです。
