This project is a memflow-only reverse engineering dossier that documents one exact Easy Anti-Cheat Fortnite kernel driver build captured from outside a Windows VM. Using passive physical-memory acquisitions and matched Windows kernel PDB layouts, it maps EAC's registered kernel surfaces including process, thread, and image callbacks, Object Manager handle policy, registry callbacks, a Filter Manager minifilter, device IPC, and private per-thread callback contexts. The repository packages narrative deep dives, technical appendices, and evidence-labeled claims with Python validation tooling and reproducible derivation rules that exclude bypass or exploit material. It is aimed at game security researchers, anti-cheat engineers, and Windows kernel reverse engineers studying how Easy Anti-Cheat monitors lifecycle, persistence, executable mapping, and platform state.
