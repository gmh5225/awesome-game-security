이 프로젝트는 memflow만을 사용한 리버스 엔지니어링 자료로, Windows VM 외부에서 캡처한 특정 Easy Anti-Cheat Fortnite 커널 드라이버 빌드를 문서화합니다. 수동적 물리 메모리 획득과 일치하는 Windows 커널 PDB 레이아웃을 사용하여 EAC가 등록한 커널 인터페이스를 매핑합니다. 여기에는 프로세스, 스레드, 이미지 콜백, Object Manager 핸들 정책, 레지스트리 콜백, Filter Manager 미니필터, 디바이스 IPC, 스레드별 프라이빗 콜백 컨텍스트가 포함됩니다. 저장소에는 서술형 심층 분석, 기술 부록, Python 검증 도구 및 재현 가능한 유도 규칙(우회 또는 exploit 자료 제외)과 함께 증거가 표시된 주장이 담겨 있습니다. Easy Anti-Cheat가 수명 주기, 지속성, 실행 가능 이미지 매핑, 플랫폼 상태를 어떻게 모니터링하는지 연구하는 게임 보안 연구자, 안티치트 엔지니어, Windows 커널 리버스 엔지니어를 대상으로 합니다.
