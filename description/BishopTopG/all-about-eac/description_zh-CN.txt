本项目是一份仅基于 memflow 的逆向工程档案，记录从 Windows 虚拟机外部捕获的某一特定 Easy Anti-Cheat Fortnite 内核驱动构建版本。借助被动物理内存采集及与之匹配的 Windows 内核 PDB 布局，它映射了 EAC 已注册的内核接口，包括进程、线程与映像回调、Object Manager 句柄策略、注册表回调、Filter Manager 微型过滤器、设备 IPC 以及私有的每线程回调上下文。该仓库包含叙述性深度分析、技术附录，以及带有 Python 验证工具与可复现推导规则（排除绕过或 exploit 材料）的证据标注声明。适用于研究 Easy Anti-Cheat 如何监控系统生命周期、持久化、可执行映像映射及平台状态的游戏安全研究人员、反作弊工程师及 Windows 内核逆向工程师。
