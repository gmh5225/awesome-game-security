本專案是一份僅基於 memflow 的逆向工程檔案，記錄自 Windows 虛擬機外部擷取的某一特定 Easy Anti-Cheat Fortnite 核心驅動程式建置版本。藉由被動式實體記憶體擷取及與之配對的 Windows 核心 PDB 配置，它對映了 EAC 已註冊的核心介面，包括行程、執行緒與映像回呼、Object Manager 句柄原則、登錄回呼、Filter Manager 迷你篩選器、裝置 IPC 以及私有的每執行緒回呼內容。此儲存庫包含敘述性深度分析、技術附錄，以及配有 Python 驗證工具與可重現推導規則（排除繞過或 exploit 材料）的證據標註聲明。適合研究 Easy Anti-Cheat 如何監控系統生命週期、持久化、可執行映像對映及平台狀態的遊戲安全研究人員、反作弊工程師及 Windows 核心逆向工程師。
