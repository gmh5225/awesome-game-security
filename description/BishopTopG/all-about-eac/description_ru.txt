Этот проект — досье по реверс-инжинирингу, основанное исключительно на memflow, которое документирует одну конкретную сборку драйвера ядра Easy Anti-Cheat для Fortnite, захваченную извне виртуальной машины Windows. С помощью пассивного захвата физической памяти и соответствующих раскладок PDB ядра Windows он отображает зарегистрированные интерфейсы ядра EAC, включая callback-и процессов, потоков и образов, политику дескрипторов Object Manager, callback-и реестра, minifilter Filter Manager, IPC устройства и приватные контексты callback-ов для каждого потока. Репозиторий содержит повествовательные углублённые разборы, технические приложения и утверждения с пометками доказательств, инструменты валидации на Python и воспроизводимые правила вывода, исключающие материалы обхода или эксплуатации. Он предназначен для исследователей безопасности игр, инженеров античита и специалистов по реверс-инжинирингу ядра Windows, изучающих, как Easy Anti-Cheat отслеживает жизненный цикл, персистентность, отображение исполняемых файлов и состояние платформы.
