FilterTap은 이더넷 프레임 계층에서 네트워크 메타데이터를 수동적으로 캡처하는 경량 Windows Filtering Platform 커널 드라이버입니다. C++와 Windows Driver Kit로 작성되었으며, 인바운드 및 아웃바운드 WFP callout 필터를 등록하여 통과하는 트래픽에서 로컬 NIC MAC 및 IP, 게이트웨이 MAC, 평문 DNS 쿼리 호스트명을 추출합니다. 로컬 및 게이트웨이 식별자가 수집되면 드라이버는 커널 디버그 출력을 통해 로깅하며, L2 검사의 부수적 효과로 DNS 조회를 관찰할 수도 있습니다. 이 프로젝트는 Easy Anti-Cheat와 같은 안티치트 시스템이 사용자 모드 MAC 스푸핑 API를 우회하고 커널 공간에서 프레임을 직접 읽어 하드웨어 식별자를 획득하는 방법에 대한 개념 증명 역할을 합니다. 안티치트 네트워크 핑거프린팅 및 WFP 기반 원격 측정을 연구하는 게임 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
