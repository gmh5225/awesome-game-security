FilterTap 是一款輕量級 Windows Filtering Platform 核心驅動程式，在乙太網路幀層被動擷取網路中繼資料。該專案以 C++ 和 Windows Driver Kit 撰寫，註冊入站與出站 WFP callout 過濾規則，從經過的流量中擷取本機網卡 MAC 和 IP 位址、閘道 MAC 位址以及明文 DNS 查詢主機名稱。收集到本機與閘道識別碼後，驅動程式透過核心偵錯輸出記錄這些資訊，並可作為 L2 層檢測的附帶效果觀測 DNS 查詢。此專案作為概念驗證，展示 Easy Anti-Cheat 等反作弊系統如何透過在核心空間直接讀取幀來取得硬體識別碼，從而繞過使用者模式 MAC 欺騙 API。面向研究反作弊網路指紋識別與基於 WFP 遙測的遊戲安全研究人員和逆向工程師。
