FilterTap — лёгкий драйвер ядра Windows Filtering Platform, который пассивно перехватывает сетевые метаданные на уровне Ethernet-кадров. Написан на C++ с использованием Windows Driver Kit и регистрирует входящие и исходящие callout-фильтры WFP для извлечения MAC и IP локального сетевого адаптера, MAC шлюза и имён хостов из DNS-запросов в открытом виде из проходящего трафика. После сбора локальных идентификаторов и идентификатора шлюза драйвер логирует их через вывод отладки ядра и при необходимости может отслеживать DNS-запросы как побочный эффект инспекции на L2. Проект служит proof-of-concept демонстрацией того, как античит-системы вроде Easy Anti-Cheat получают аппаратные идентификаторы, читая кадры напрямую в пространстве ядра, обходя пользовательские API подмены MAC. Он предназначен для исследователей игровой безопасности и реверс-инженеров, изучающих сетевое фингерпринтирование античита и телеметрию на базе WFP.
