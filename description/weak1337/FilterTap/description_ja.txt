FilterTap は、イーサネットフレーム層でネットワークメタデータをパッシブにキャプチャする軽量な Windows Filtering Platform カーネルドライバです。C++ と Windows Driver Kit で記述され、インバウンドおよびアウトバウンドの WFP callout フィルターを登録して、通過するトラフィックからローカル NIC の MAC と IP、ゲートウェイ MAC、平文 DNS クエリのホスト名を抽出します。ローカルおよびゲートウェイ識別子が収集されると、ドライバーはカーネルデバッグ出力でログを記録し、L2 検査の副次効果として DNS ルックアップの監視も行えます。このプロジェクトは、Easy Anti-Cheat などのアンチチートシステムが、ユーザーモード MAC スプーフィング API をバイパスしてカーネル空間でフレームを直接読み取りハードウェア識別子を取得する方法の概念実証として機能します。アンチチートのネットワークフィンガープリントと WFP ベースのテレメトリを研究するゲームセキュリティ研究者およびリバースエンジニア向けです。
