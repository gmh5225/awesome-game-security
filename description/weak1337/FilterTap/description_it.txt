FilterTap è un driver kernel leggero della Windows Filtering Platform che cattura passivamente i metadati di rete a livello dello strato frame Ethernet. Scritto in C++ con il Windows Driver Kit, registra filtri callout WFP in ingresso e in uscita per estrarre il MAC e l'IP della NIC locale, il MAC del gateway e i nomi host delle query DNS in chiaro dal traffico in transito. Una volta raccolti gli identificativi locali e del gateway, il driver li registra tramite output di debug del kernel e può opzionalmente osservare le ricerche DNS come effetto collaterale dell'ispezione L2. Il progetto funge da proof-of-concept su come sistemi anti-cheat come Easy Anti-Cheat ottengono identificativi hardware leggendo i frame direttamente nello spazio kernel, aggirando le API di spoofing MAC in user mode. È destinato a ricercatori di sicurezza dei giochi e reverse engineer che studiano il fingerprinting di rete anti-cheat e la telemetria basata su WFP.
