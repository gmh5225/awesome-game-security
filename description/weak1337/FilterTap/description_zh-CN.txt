FilterTap 是一款轻量级 Windows Filtering Platform 内核驱动，在以太网帧层被动捕获网络元数据。该项目使用 C++ 和 Windows Driver Kit 编写，注册入站和出站 WFP callout 过滤规则，从经过的流量中提取本地网卡 MAC 和 IP 地址、网关 MAC 地址以及明文 DNS 查询主机名。收集到本地和网关标识符后，驱动通过内核调试输出记录这些信息，并可作为 L2 层检测的附带效果观测 DNS 查询。该项目作为概念验证，展示了 Easy Anti-Cheat 等反作弊系统如何通过在内核空间直接读取帧来获取硬件标识符，从而绕过用户态 MAC 欺骗 API。面向研究反作弊网络指纹识别和基于 WFP 遥测的游戏安全研究人员和逆向工程师。
