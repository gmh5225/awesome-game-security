Eigen은 Paper와 Folia용 Minecraft 서버 플러그인으로 제공되는 오픈 소스 머신러닝 기반 전투 안티치트입니다. 주로 Scala 3로 작성되었으며 sbt로 빌드되고, PacketEvents로 각 플레이어의 네트워크 트래픽을 관찰해 지연 보상된 조준 기하와 감도와 무관한 마우스 입력을 포함해 클라이언트가 보는 화면을 재구성합니다. 클라이언트 tick마다 특징 행이 생기며, 이 행들은 전투 창과 기준선 창으로 묶여 인증된 WebSocket을 통해 별도 백엔드로 스트리밍되어 라벨이 붙은 데이터셋 수집과 추론에 사용됩니다. 코드베이스는 플랫폼에 독립적인 시뮬레이션, 스키마, 와이어 인코딩을 core 모듈에 두고 Paper 어댑터와 분리하며, GrimAC·Shard 같은 프로젝트의 트랜잭션 기반 지연 보상과 ML 지향 tick 특징 기법을 반영합니다. 순수 휴리스틱이 아닌 ML 기반 전투 치트 탐지를 원하는 서버 운영자와 안티치트 개발자를 대상으로 합니다.
