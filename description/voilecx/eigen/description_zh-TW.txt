Eigen 是一款開源的機器學習戰鬥反作弊系統，以 Minecraft 伺服器外掛形式運行於 Paper 與 Folia。專案主要使用 Scala 3 撰寫，透過 sbt 建置，借助 PacketEvents 觀測每位玩家的網路流量並重建用戶端視角，包括延遲補償的瞄準幾何與獨立於靈敏度的滑鼠輸入。每個用戶端 tick 對應一列特徵；這些列被分組為戰鬥視窗與基線視窗，經認證的 WebSocket 串流傳輸至獨立後端，用於帶標籤資料集採集與推論。程式碼庫在 core 模組中分離與平台無關的模擬、結構描述與線路編碼，Paper 適配層單獨實作，並借鑑 GrimAC、Shard 等專案的以交易為基礎的延遲補償與面向 ML 的 tick 特徵技術。面向希望採用 ML 驅動戰鬥作弊偵測而非純啟發式規則的伺服器營運者與反作弊開發者。
