Eigen is an open-source machine-learning combat anti-cheat delivered as a Minecraft server plugin for Paper and Folia. Written primarily in Scala 3 and built with sbt, it uses PacketEvents to observe each player’s network traffic and reconstruct what their client sees, including lag-compensated aim geometry and sensitivity-independent mouse input. Every client tick becomes a feature row; those rows are grouped into combat and baseline windows and streamed over an authenticated WebSocket to a separate backend for labeled dataset collection and inference. The codebase separates platform-agnostic simulation, schema, and wire encoding in a core module from the Paper adapter, and it incorporates techniques from projects such as GrimAC and Shard for transaction-based lag compensation and ML-oriented tick features. It is aimed at server operators and anti-cheat developers who want ML-driven combat cheat detection rather than purely heuristic checks.
