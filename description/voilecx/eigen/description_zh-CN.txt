Eigen 是一款开源的机器学习战斗反作弊系统，以 Minecraft 服务器插件形式运行于 Paper 与 Folia。项目主要使用 Scala 3 编写，通过 sbt 构建，借助 PacketEvents 观测每位玩家的网络流量并重建客户端视角，包括滞后补偿的瞄准几何与独立于灵敏度的鼠标输入。每个客户端 tick 对应一行特征；这些行被分组为战斗窗口与基线窗口，经认证的 WebSocket 流式传输至独立后端，用于带标签数据集采集与推理。代码库在 core 模块中分离与平台无关的仿真、模式与线协议编码，Paper 适配层单独实现，并借鉴 GrimAC、Shard 等项目的基于事务的滞后补偿与面向 ML 的 tick 特征技术。面向希望采用 ML 驱动战斗作弊检测而非纯启发式规则的服务器运营者与反作弊开发者。
