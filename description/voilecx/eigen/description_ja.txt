Eigen は、Paper および Folia 向け Minecraft サーバープラグインとして提供される、オープンソースの機械学習ベースのコンバットアンチチートです。主に Scala 3 で書かれ sbt でビルドされ、PacketEvents で各プレイヤーのネットワークトラフィックを監視し、ラグ補償された照準ジオメトリや感度に依存しないマウス入力を含む、クライアントが見ている状態を再構成します。クライアントの各 tick が特徴量の1行となり、それらはコンバット窓とベースライン窓にグループ化され、認証付き WebSocket 経由で別バックエンドへストリーミングされ、ラベル付きデータセット収集と推論に使われます。コードベースは、プラットフォーム非依存のシミュレーション、スキーマ、ワイヤエンコーディングを core モジュールに分離し、Paper アダプタとは別にし、GrimAC や Shard などのプロジェクト由来の、トランザクションベースのラグ補償と ML 向け tick 特徴の手法を取り入れています。純粋なヒューリスティックではなく ML 駆動のコンバットチート検知を求めるサーバー運営者とアンチチート開発者向けです。
