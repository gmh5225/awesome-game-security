Фреймворк ближнего боя для Roblox, полностью написанный на Luau: серверно-авторитетные попадания сочетаются с компенсацией задержки и клиентским предсказанием для отзывчивых онлайн-схваток. В комплекте комбо M1, блок и парирование с guard break, уклонения с кадрами неуязвимости, набор из четырёх способностей, регдоллы и тренировочные манекены; общая логика хитбоксов синхронизирует клиентский превью с подтверждением сервера. Сервер хранит историю позиций для отката целей при проверке попаданий, валидирует боевые запросы схемой и киками по ударам, оценивает движение в скользящем окне и корректирует допустимую задержку снап-бэками, а не наказаниями. Процедурная анимация R15, единый пайплайн ударов для игроков и манекенов и десятки автоматизированных тестов в Studio дополняют реализацию. Для разработчиков Roblox и тех, кто изучает сетевой экшен, особенно античит с допуском лага и устойчивую к эксплойтам проверку боя.
