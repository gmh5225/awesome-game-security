Luau で一から書かれた Roblox 向け近接戦闘フレームワークで、サーバー権威のヒット判定にラグ補償とクライアント側予測を組み合わせ、オンライン対戦の手応えを高めます。M1 コンボ、ガードブレイク付きのブロックとパリィ、無敵時間付きドッジダッシュ、4 スキル構成、ラグドール、トレーニングダミーを備え、共有ヒットボックスロジックによりクライアントのプレビューとサーバー確認が一致します。サーバーは位置履歴を保持してターゲットを巻き戻してヒット判定し、スキーマ検証とストライクベースのキックで戦闘リクエストを検証し、スライディングウィンドウ上で移動を判定するため、正当なレイテンシはペナルティではなくスナップバックで補正されます。手続き型 R15 アニメーション、プレイヤーとダミー共通の統一ヒットパイプライン、多数の Studio 自動テストが実装を完成させます。Roblox 開発者やネットワーク型アクションゲーム設計、とくにラグ耐性のあるアンチチートとエクスプロイト耐性のある戦闘検証を学ぶ人向けです。
