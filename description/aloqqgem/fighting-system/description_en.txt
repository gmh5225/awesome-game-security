This is a Roblox melee combat framework written entirely in Luau that combines server-authoritative hits with lag compensation and client-side prediction for responsive online fights. It ships M1 combos, blocking and parrying with guard breaks, dodge dashes with invincibility frames, a four-ability kit, ragdolls, and training dummies, all driven by shared hitbox logic so client previews align with server confirmation. The server maintains position history to rewind targets for hit tests, validates combat requests with schema checks and strike-based kicks, and judges movement over a sliding window so legitimate latency is corrected with snap-backs instead of punishments. Procedural R15 animation, a unified hit pipeline for players and dummies, and dozens of automated Studio tests round out the implementation. It targets Roblox developers and anyone studying networked action-game design, especially lag-tolerant anti-cheat and exploit-resistant combat validation.
