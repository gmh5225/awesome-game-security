這是一個完全以 Luau 撰寫的 Roblox 近戰戰鬥框架，結合伺服器權威命中判定、延遲補償與客戶端預測，讓線上對戰既靈敏又可信。內建 M1 連擊、格擋與招架（含破防）、附無敵幀的閃避衝刺、四套技能、布娃娃物理與訓練假人，皆以共用碰撞箱邏輯驅動，使客戶端預覽與伺服器確認一致。伺服器維護位置歷史以對目標進行回溯命中檢測，透過結構驗證與以打擊為依據的踢出驗證戰鬥請求，並在滑動時間窗內判定移動，對合理延遲以拉回修正而非懲罰。程序化 R15 動畫、玩家與假人共用的統一受擊管線，以及數十項 Studio 自動化測試構成完整實作。面向 Roblox 開發者及研究網路化動作遊戲設計者，尤其著重容忍延遲的反作弊與抗利用的戰鬥校驗。
