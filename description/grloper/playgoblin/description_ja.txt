PlayGoblin はオープンソースの自動 QA ボットで、常駐テスターのようにゲームをプレイし、問題を記録してキャプチャした実行を根拠付きのバグレポートに変換します。Unity パッケージと実験的な Unreal C++ プラグインがプレイヤーをレベルやメニューを操作させ、構造化された実行ログを出力し、Python CLI がクラッシュ、無反応 UI ボタン、ナビゲーションの停止、落下、空白フレーム、デバッグ残骸、任意の FPS 低下に対して決定論的チェックを適用します。所見はイベント、フレーム、ログ行に紐づけられ、HTML または Markdown レポートとして出力でき、必要に応じて GitHub issue として起票可能です。AI コーディングエージェント向けの MCP サーバーと JSON CLI 出力も用意されています。アンチチートや本番セキュリティ監視ではなく、ローカルビルドでの再現可能な夜間プレイテストと回帰発見を求めるゲーム開発者と QA ワークフローを対象としています。
