PlayGoblin is an open-source automated QA bot that plays a game like a persistent tester, records what goes wrong, and turns captured runs into evidence-backed bug reports. A Unity package and an experimental Unreal C++ plugin drive the player through levels, crawl menus, and emit structured run logs, while a Python CLI applies deterministic checks for crashes, dead UI buttons, stuck navigation, falls, blank frames, debug leftovers, and optional FPS regressions. Findings are tied to events, frames, or log lines and can be rendered as HTML or Markdown reports and optionally filed as GitHub issues, with an MCP server and JSON CLI output aimed at AI coding agents. It targets game developers and QA workflows who want repeatable overnight playtesting and regression discovery on local builds rather than anti-cheat or live security monitoring.
