PlayGoblin es un bot de QA automatizado de código abierto que juega un juego como un tester persistente, registra lo que falla y convierte las ejecuciones capturadas en informes de errores respaldados por evidencia. Un paquete de Unity y un complemento experimental en C++ para Unreal guían al jugador por niveles y menús y emiten registros de ejecución estructurados, mientras una CLI en Python aplica comprobaciones deterministas de cierres inesperados, botones de UI inactivos, navegación atascada, caídas, fotogramas en blanco, restos de depuración y regresiones opcionales de FPS. Los hallazgos se vinculan a eventos, fotogramas o líneas de log y pueden renderizarse como informes HTML o Markdown y, opcionalmente, archivarse como issues de GitHub, con un servidor MCP y salida CLI JSON orientados a agentes de codificación con IA. Está dirigido a desarrolladores de juegos y flujos de QA que quieren playtesting nocturno repetible y detección de regresiones en builds locales, no anti-cheat ni monitorización de seguridad en vivo.
