PlayGoblin 是一款開源自動化 QA 機器人，像常駐測試員一樣遊玩遊戲，記錄異常並將擷取的執行過程轉成有證據支撐的缺陷報告。Unity 套件與實驗性 Unreal C++ 外掛可驅動玩家通關關卡、遍歷選單並輸出結構化執行日誌，Python CLI 則對當機、失效 UI 按鈕、導航卡住、墜落、空白畫面、除錯殘留以及可選的 FPS 退步進行確定性檢查。發現項目與事件、影格或日誌列關聯，可渲染為 HTML 或 Markdown 報告，並可選提交為 GitHub issue；另提供面向 AI 程式設計助手的 MCP 伺服器與 JSON CLI 輸出。面向希望在本地建置上進行可重複的通宵試玩與回歸發現的遊戲開發者與 QA 流程，而非反作弊或線上安全監控。
