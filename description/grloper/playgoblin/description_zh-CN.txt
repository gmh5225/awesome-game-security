PlayGoblin 是一款开源自动化 QA 机器人，像常驻测试员一样游玩游戏，记录异常并将捕获的运行过程转化为有证据支撑的缺陷报告。Unity 包与实验性 Unreal C++ 插件可驱动玩家通关关卡、遍历菜单并输出结构化运行日志，Python CLI 则对崩溃、失效 UI 按钮、导航卡住、坠落、空白帧、调试残留以及可选的 FPS 回退进行确定性检查。发现项与事件、帧或日志行关联，可渲染为 HTML 或 Markdown 报告，并可选提交为 GitHub issue；还提供面向 AI 编程助手的 MCP 服务器与 JSON CLI 输出。面向希望在本地构建上进行可重复的通宵试玩与回归发现的游戏开发者与 QA 流程，而非反作弊或线上安全监控。
