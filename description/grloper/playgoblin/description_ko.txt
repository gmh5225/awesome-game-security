PlayGoblin은 오픈 소스 자동 QA 봇으로, 상주 테스터처럼 게임을 플레이하고 문제를 기록하며 캡처한 실행을 근거가 있는 버그 리포트로 바꿉니다. Unity 패키지와 실험적 Unreal C++ 플러그인이 플레이어를 레벨과 메뉴를 탐색하게 하고 구조화된 실행 로그를 내며, Python CLI는 크래시, 동작하지 않는 UI 버튼, 내비게이션 정지, 낙하, 빈 프레임, 디버그 잔여물, 선택적 FPS 저하에 대해 결정론적 검사를 적용합니다. 발견 사항은 이벤트, 프레임 또는 로그 줄과 연결되며 HTML 또는 Markdown 리포트로 렌더링할 수 있고, 필요 시 GitHub issue로 등록할 수 있습니다. AI 코딩 에이전트를 위한 MCP 서버와 JSON CLI 출력도 제공합니다. 안티치트나 라이브 보안 모니터링이 아니라 로컬 빌드에서 반복 가능한 야간 플레이테스트와 회귀 발견을 원하는 게임 개발자와 QA 워크플로를 대상으로 합니다.
