PlayGoblin è un bot QA automatizzato open source che gioca a un titolo come un tester permanente, registra i malfunzionamenti e trasforma le esecuzioni catturate in segnalazioni di bug supportate da evidenze. Un pacchetto Unity e un plugin sperimentale Unreal in C++ guidano il giocatore attraverso livelli e menu ed emettono log di esecuzione strutturati, mentre una CLI Python applica controlli deterministici su crash, pulsanti UI morti, navigazione bloccata, cadute, frame vuoti, residui di debug e regressioni FPS opzionali. I risultati sono collegati a eventi, frame o righe di log e possono essere resi come report HTML o Markdown e, facoltativamente, archiviati come issue GitHub, con un server MCP e output CLI JSON pensati per agenti di coding IA. È rivolto a sviluppatori di giochi e workflow QA che vogliono playtest notturni ripetibili e individuazione delle regressioni su build locali, non anti-cheat o monitoraggio di sicurezza in produzione.
