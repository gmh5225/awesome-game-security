一個可重複使用的技能套件與開箱即用的遊戲內 Mod 選單，用於修改 Unity IL2CPP 遊戲 Terraria 的 Android 版本。它記錄並實作了以成員名稱而非固定位址進行 IL2CPP Hook 的方法，使用 Frida 與基於 JsHook 的 JavaScript 注入，並在 UpdateEquips、PlayerFrame 等 Player 方法上設定逐幀 Hook。Mod 選單以原生 Android 系統 UI 視圖建構，避免觸控事件穿透至遊戲，並附帶 Python 工具，用於離線 APK 解包、物品圖示圖集提取與名稱表生成。主要用途包括逆向工程、手遊 Mod 開發，以及在 arm64 Android 裝置上進行單人模式記憶體編輯研究。
