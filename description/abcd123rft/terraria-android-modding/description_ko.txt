Unity IL2CPP 게임 Terraria의 Android 빌드를 수정하기 위한 재사용 가능한 스킬 패키지와 즉시 실행 가능한 인게임 mod 메뉴입니다. 고정 주소가 아닌 멤버 이름으로 IL2CPP 후킹하는 방법을 문서화하고 구현하며, Frida와 JsHook 기반 JavaScript 주입을 통해 UpdateEquips, PlayerFrame 같은 Player 메서드에 프레임 단위 후크를 겁니다. mod 메뉴는 터치가 게임으로 전달되지 않도록 네이티브 Android 시스템 UI 뷰로 만들어졌으며, 오프라인 APK 언패킹, 아이템 아이콘 아틀라스 추출, 이름 테이블 생성을 위한 Python 유틸리티도 포함합니다. 주요 용도는 역공학, 모바일 게임 modding, arm64 Android 기기에서의 싱글플레이 메모리 편집 연구입니다.
