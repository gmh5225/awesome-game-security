Terraria の Android 版（Unity IL2CPP ゲーム）を改変するための、再利用可能なスキルパッケージと、すぐに使えるゲーム内 mod メニューです。固定アドレスではなくメンバー名による IL2CPP フックを文書化・実装しており、Frida と JsHook ベースの JavaScript 注入により、UpdateEquips や PlayerFrame など Player メソッドへのフレーム単位のフックを行います。mod メニューはネイティブの Android システム UI ビューで構築され、タッチがゲームに透過しないようになっており、オフラインでの APK 展開、物品アイコンアトラスの抽出、名称テーブル生成用の Python ユーティリティも含まれます。主な用途は、リバースエンジニアリング、モバイルゲームの mod 制作、arm64 Android デバイス上でのシングルプレイ向けメモリ編集研究です。
