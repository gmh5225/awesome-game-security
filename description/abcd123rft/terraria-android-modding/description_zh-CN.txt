一个可重复使用的技能包与开箱即用的游戏内 Mod 菜单，用于修改 Unity IL2CPP 游戏 Terraria 的 Android 版本。它记录并实现了以成员名称而非固定地址进行 IL2CPP Hook 的方法，使用 Frida 与基于 JsHook 的 JavaScript 注入，并在 UpdateEquips、PlayerFrame 等 Player 方法上设置逐帧 Hook。Mod 菜单采用原生 Android 系统 UI 视图构建，避免触摸事件穿透到游戏，并附带 Python 工具，用于离线 APK 解包、物品图标图集提取与名称表生成。主要用途包括逆向工程、手游 Mod 开发，以及在 arm64 Android 设备上进行单人模式内存编辑研究。
