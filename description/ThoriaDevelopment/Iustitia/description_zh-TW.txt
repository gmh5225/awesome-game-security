Iustitia 是一款面向 Minecraft Java 的用戶端 Fabric 模組，透過分析伺服器轉發的封包被動偵測其他玩家的作弊行為，無需伺服器外掛，也不會向外回報。它主要以 Kotlin 在 Gradle 上實作，借助 Fabric mixin 觀察戰鬥與移動，涵蓋 1.8 傳統風格與 1.21 時代常見的 reach、kill aura、fly、speed、scaffold 等外掛及相關戰鬥異常。模組提供大量可設定檢查、違規等級計分、從日常遊玩到嚴格管理的預設設定檔、遊戲內指令、HUD 與名牌指示，以及回放工具——可將近期玩家移動重建為世界內的幽靈模型供管理員審查。面向伺服器管理員、反作弊研究者，以及需要本地查驗與取證而非自動踢人或封禁的 Minecraft 用戶端遊戲安全學習者。
