Iustitia は Minecraft Java 向けのクライアント側 Fabric mod で、サーバーが再配信するパケットを解析して他プレイヤーのチートを受動的に検出します。サーバー用プラグインも外向きの通報も不要です。主に Kotlin と Gradle で実装され、Fabric mixin で戦闘と移動を監視し、レガシー 1.8 系から現行 1.21 時代の reach、kill aura、fly、speed、scaffold などのハックや関連する戦闘異常をカバーします。多数の設定可能なチェック、違反レベルスコア、日常プレイから厳格なモデレーションまでのプリセット、ゲーム内コマンド、HUD とネームタグ表示、直近のプレイヤー移動をワールド内のゴーストモデルとして再構成するリプレイツールを備え、スタッフの確認に使えます。サーバー運営者、anticheat 研究者、自動キックや BAN ではなくローカルでの検査と証拠が必要な Minecraft クライアント側ゲームセキュリティの学習者向けです。
