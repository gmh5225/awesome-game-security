Iustitia 是一款面向 Minecraft Java 的客户端 Fabric 模组，通过分析服务器转发的数据包被动检测其他玩家的作弊行为，无需服务端插件，也不会向外上报。它主要用 Kotlin 在 Gradle 上实现，借助 Fabric mixin 观察战斗与移动，覆盖 1.8 传统风格与 1.21 时代常见的 reach、kill aura、fly、speed、scaffold 等外挂及相关战斗异常。模组提供大量可配置检测、违规等级计分、从日常游玩到严格管理的预设配置、游戏内命令、HUD 与名牌指示，以及回放工具——可将近期玩家运动重建为世界内的幽灵模型供管理人员审查。面向服主与管理员、反作弊研究者，以及需要本地查验与取证而非自动踢人或封禁的 Minecraft 客户端游戏安全学习者。
