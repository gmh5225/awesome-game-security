Этот репозиторий описывает практическую лабораторную работу по динамическому изменению памяти и анализу во время выполнения в офлайн-FPS AssaultCube в Windows. В нём разбираются сценарии работы в Cheat Engine: поиск по точному значению, фильтрация после изменения состояния в игре и патчинг RAM для изменения здоровья, боеприпасов и связанных параметров игрока. Материал также охватывает глобальный speedhack, сопоставление смещений через Structure Spider вокруг известных базовых адресов и просмотр дизассемблированного кода и опкодов клиента игры в Memory Viewer. Он ориентирован на тех, кто изучает безопасность игр, реверс-инжиниринг и кибербезопасность и хочет структурированно понять, как переменные времени выполнения в ОЗУ отражаются в видимом поведении игры.
