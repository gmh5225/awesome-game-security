本リポジトリは、Windows 上のオフライン FPS ゲーム AssaultCube を対象に、動的メモリ操作とランタイム解析を行うハンズオンのラボを文書化しています。Cheat Engine を使った完全一致スキャン、ゲーム内状態変化後のフィルタリング、RAM のパッチによる体力・弾薬などプレイヤーステータスの変更といったワークフローを順を追って説明します。さらにグローバルなスピードハック、既知のベースアドレス周辺での Structure Spider によるオフセットマッピング、Memory Viewer によるゲームクライアントの逆アセンブリとオペコードの確認も扱います。ゲームセキュリティ、リバースエンジニアリング、サイバーセキュリティ研修の学習者向けに、RAM 上のランタイム変数が画面上のゲーム挙動とどう対応するかを体系的に学ぶ入門資料です。
