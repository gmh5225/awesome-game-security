이 저장소는 Windows에서 오프라인 FPS 게임 AssaultCube를 대상으로 동적 메모리 조작과 런타임 분석을 다루는 실습 랩을 문서화합니다. Cheat Engine 워크플로—정확한 값 스캔, 인게임 상태 변경 후 필터링, RAM 패치로 체력·탄약 및 관련 플레이어 스탯 변경—을 단계별로 안내합니다. 또한 전역 스피드핵, 알려진 베이스 주소 주변의 Structure Spider 오프셋 매핑, Memory Viewer에서 게임 클라이언트의 디스어셈블리와 opcode 검사도 다룹니다. 게임 보안, 리버스 엔지니어링, 사이버 보안 교육을 배우는 이들에게 RAM의 런타임 변수가 보이는 게임 동작과 어떻게 연결되는지 구조적으로 소개하는 자료입니다.
