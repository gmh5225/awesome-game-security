This repository documents a hands-on lab on dynamic memory manipulation and runtime analysis in the offline FPS AssaultCube on Windows. It walks through Cheat Engine workflows including exact-value scanning, filtering after in-game state changes, and patching RAM to alter health, ammunition, and related player stats. The material also covers global speedhacking, Structure Spider offset mapping around known base addresses, and Memory Viewer inspection of disassembly and opcodes in the game client. It is aimed at learners in game security, reverse engineering, and cyber security training who want a structured introduction to how runtime variables in RAM map to visible game behavior.
