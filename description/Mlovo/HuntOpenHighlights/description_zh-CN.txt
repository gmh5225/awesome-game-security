HuntReplay Studio 是一款面向《猎杀：对决 1896》的独立片段录制工具，会根据游戏官方 Highlights SDK 事件自动保存击杀、死亡与倒地片段。它通过标准 NVIDIA MessageBus IPC 管道监听，并采用经 Authenticode 验证的 MessageBus 集成，而非向游戏注入或模拟输入，因此可与 Easy Anti-Cheat 兼容。采集使用 Windows Graphics Capture，并通过 NVENC、AMD AMF、Intel QSV 或 x264 进行硬件编码；片段从内存环形缓冲区裁剪，支持关键帧精确修剪，保存时无需重新编码。技术栈包含基于 .NET 8 WPF 的桌面应用、基于 FFmpeg 的原生 C++ 媒体层，以及用于总线消息的 Protocol Buffers，并以便携单可执行文件形式发布，内置图库与播放器。适合希望自动高光录制的玩家，以及研究 Windows 上合法、反作弊安全的游戏事件与 overlay IPC 的研究人员。
