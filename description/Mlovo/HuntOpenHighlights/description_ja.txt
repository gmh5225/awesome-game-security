HuntReplay Studio は Hunt: Showdown 1896 向けのスタンドアロンクリップ録画ツールで、ゲーム公式 Highlights SDK イベントからキル、デス、ダウンを自動保存します。標準の NVIDIA MessageBus IPC パイプで待ち受け、Authenticode 検証済みの MessageBus 連携を用い、ゲームへの注入や入力エミュレーションは行わないため Easy Anti-Cheat と互換性があります。キャプチャは Windows Graphics Capture を使い、NVENC、AMD AMF、Intel QSV、または x264 によるハードウェアエンコードを行い、クリップはメモリ内リングバッファから切り出し、キーフレーム精度のトリミングで保存時の再エンコードは不要です。スタックは .NET 8 WPF デスクトップアプリと FFmpeg 上のネイティブ C++ メディア層、バスメッセージ用 Protocol Buffers を組み合わせ、組み込みギャラリーとプレイヤー付きのポータブル単一実行ファイルとして配布されます。自動ハイライトを求めるプレイヤーや、Windows 上の正当でアンチチート安全なゲームイベントおよび overlay IPC を研究する研究者向けです。
