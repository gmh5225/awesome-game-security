HuntReplay Studio is a standalone clip recorder for Hunt: Showdown 1896 that automatically saves kills, deaths, and downs from the game’s official Highlights SDK events. It listens on the standard NVIDIA MessageBus IPC pipe with Authenticode-verified MessageBus integration instead of injecting into the game or emulating input, which keeps it compatible with Easy Anti-Cheat. Capture uses Windows Graphics Capture with hardware encoding through NVENC, AMD AMF, Intel QSV, or x264, and clips are cut from an in-memory ring buffer with keyframe-accurate trimming without re-encoding on save. The stack combines a .NET 8 WPF desktop app with a native C++ media layer built on FFmpeg, plus Protocol Buffers for bus messaging, and ships as a portable single executable with a built-in gallery and player. It suits players who want automatic highlights and researchers studying legitimate, anti-cheat-safe game event and overlay IPC on Windows.
