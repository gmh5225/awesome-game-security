HuntReplay Studio는 Hunt: Showdown 1896용 독립형 클립 녹화 도구로, 게임 공식 Highlights SDK 이벤트에서 킬, 데스, 다운을 자동 저장합니다. 표준 NVIDIA MessageBus IPC 파이프에서 수신하며 Authenticode 검증 MessageBus 통합을 사용하고, 게임에 주입하거나 입력을 에뮬레이션하지 않아 Easy Anti-Cheat와 호환됩니다. 캡처는 Windows Graphics Capture를 사용하고 NVENC, AMD AMF, Intel QSV 또는 x264로 하드웨어 인코딩하며, 클립은 메모리 링 버퍼에서 잘라 키프레임 정확도로 트리밍해 저장 시 재인코딩이 필요 없습니다. 스택은 .NET 8 WPF 데스크톱 앱, FFmpeg 기반 네이티브 C++ 미디어 계층, 버스 메시징용 Protocol Buffers를 결합하며, 내장 갤러리와 플레이어가 있는 휴대용 단일 실행 파일로 제공됩니다. 자동 하이라이트를 원하는 플레이어와 Windows에서 합법적이고 안티치트에 안전한 게임 이벤트 및 overlay IPC를 연구하는 연구자에게 적합합니다.
