HuntReplay Studio — автономный рекордер клипов для Hunt: Showdown 1896, который автоматически сохраняет убийства, смерти и нокдауны по официальным событиям Highlights SDK игры. Он слушает стандартный IPC-канал NVIDIA MessageBus с интеграцией MessageBus, проверенной Authenticode, без инъекций в игру и эмуляции ввода, что сохраняет совместимость с Easy Anti-Cheat. Захват использует Windows Graphics Capture с аппаратным кодированием через NVENC, AMD AMF, Intel QSV или x264; клипы вырезаются из кольцевого буфера в памяти с точной обрезкой по ключевым кадрам без перекодирования при сохранении. Стек объединяет настольное приложение .NET 8 WPF с нативным медиаслоем на C++ на базе FFmpeg и Protocol Buffers для шинной рассылки сообщений; поставляется как портативный один исполняемый файл со встроенной галереей и плеером. Подходит игрокам, которым нужны автоматические хайлайты, и исследователям, изучающим легитимный и безопасный для античита IPC игровых событий и оверлеев в Windows.
