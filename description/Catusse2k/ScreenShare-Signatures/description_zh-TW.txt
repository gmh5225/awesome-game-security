ScreenShare Forensic Scanner 是一套用於在 FiveM 與 Minecraft 等受監管的螢幕共享工作階段中分析 Windows 主機的防禦性簽章資料庫與文件。核心產物是按威脅類別分組的結構化 JSON 檔，涵蓋 DMA 硬體與 PCILeech 類工具、核心對應器與易受攻擊驅動程式濫用、韌體與 UEFI 指標、遊戲專用作弊痕跡、輸入模擬硬體，以及日誌清除等反規避痕跡。規則針對處理序、記憶體字串、登錄機碼、事件記錄、PnP ID、路徑與程序檢查，並帶有嚴重度權重、置信度及允許清單，以降低合法管理工具造成的誤報。整合方將資料庫載入自有掃描器，在採取行動前關聯多次命中；README 展示了簡單的 Python 字串比對，並說明計畫中的 YARA 轉換與更深度的鑑識自動化。面向需要在經同意之螢幕共享中識別核心作弊、DMA 配置與繞過嘗試的伺服器管理員及注重安全的工作人員，提供可社群維護、可更新的指標。
