ScreenShare Forensic Scanner is a defensive signature database and documentation for analyzing Windows machines during moderated screenshare sessions on FiveM and Minecraft. The core artifact is a structured JSON file grouped by threat category, covering DMA hardware and PCILeech-style tooling, kernel mappers and vulnerable-driver abuse, firmware and UEFI indicators, game-specific cheat artifacts, input-emulation hardware, and anti-evasion traces such as log wiping. Rules target processes, memory strings, registry keys, event logs, PnP IDs, paths, and procedural checks, with severity weights, confidence levels, and an allowlist to reduce false positives from legitimate admin tools. Integrators load the database into their own scanner and correlate multiple hits before acting; the README illustrates simple Python string matching and notes planned YARA conversion and deeper forensic automation. It is aimed at server moderators and security-minded staff who need community-sourced, updatable indicators for kernel cheats, DMA setups, and bypass attempts during consent-based screenshares.
