ScreenShare Forensic Scanner 是一套用于在 FiveM 与 Minecraft 等受监管的屏幕共享会话中分析 Windows 主机的防御性签名库与文档。核心产物是按威胁类别分组的结构化 JSON 文件，涵盖 DMA 硬件与 PCILeech 类工具、内核映射器与易受攻击驱动滥用、固件与 UEFI 指标、游戏专用作弊痕迹、输入模拟硬件，以及日志清除等反规避痕迹。规则针对进程、内存字符串、注册表项、事件日志、PnP ID、路径与流程检查，并带有严重度权重、置信度及允许列表，以降低合法管理工具造成的误报。集成方将数据库载入自有扫描器，在采取行动前关联多次命中；README 展示了简单的 Python 字符串匹配，并说明计划中的 YARA 转换与更深度的取证自动化。面向需要在经同意的屏幕共享中识别内核作弊、DMA 配置与绕过尝试的服务器管理员及注重安全的工作人员，提供可社区维护、可更新的指标。
