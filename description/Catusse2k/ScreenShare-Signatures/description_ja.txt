ScreenShare Forensic Scanner は、FiveM や Minecraft 上のモデレート付き画面共有セッション中に Windows マシンを分析するための防御的シグネチャデータベースとドキュメントです。中核となる成果物は脅威カテゴリ別に整理された JSON で、DMA ハードウェアや PCILeech 系ツール、カーネルマッパーと脆弱ドライバの悪用、ファームウェアと UEFI の指標、ゲーム固有のチート痕跡、入力エミュレーション用ハードウェア、ログ消去などの回避対策の痕跡をカバーします。ルールはプロセス、メモリ内文字列、レジストリキー、イベントログ、PnP ID、パス、手順チェックを対象とし、重大度の重み、信頼度、正当な管理ツールによる誤検知を減らす許可リストを備えます。統合側はデータベースを自前のスキャナに読み込み、対応前に複数ヒットを相関させます。README では単純な Python 文字列マッチの例を示し、YARA 変換やより深いフォレンジック自動化の予定にも触れています。同意に基づく画面共有中にカーネルチート、DMA 構成、バイパス試行を検知する必要があるサーバーモデレーターやセキュリティ意識の高いスタッフ向けに、コミュニティ由来で更新可能なインジケータを提供します。
