Hyapk 是一款面向 Android 應用與遊戲的保護與加固打包工具，透過命令列工具鏈在 native 層與 dex 層施加防護。CLI 主要使用 Kotlin 撰寫，native 執行階段以 C 撰寫；它可將選定方法轉換為產生的 C 程式碼（Dex2C）或自訂 HyVm 虛擬機位元組碼，並支援依建置重新排列操作碼以及 ChaCha20-Poly1305 加密。此外也提供簽章驗證與 dex 完整性檢查、防篡改與反除錯、smali 重新命名、資源加密，以及反 Frida、反 root 與模擬器偵測等啟發式策略。此工具面向需要提高 Android 遊戲與應用在逆向、篡改與作弊方面成本的合法應用擁有者。
