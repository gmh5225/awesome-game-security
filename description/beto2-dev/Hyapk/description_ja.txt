Hyapk は、Android アプリやゲーム向けの保護・ハードニング用パッカーで、コマンドラインのツールチェーンを通じてネイティブ層と dex 層の防御を適用します。CLI は主に Kotlin、ネイティブランタイムは C で記述されており、選択したメソッドを生成された C コード（Dex2C）またはカスタム HyVm 仮想マシンのバイトコードへ変換し、ビルドごとのオペコード並べ替えと ChaCha20-Poly1305 暗号化に対応します。また、署名および dex の整合性チェック、改ざん防止とデバッグ対策、smali のリネーム、暗号化されたアセット、anti-Frida・anti-root、エミュレータ検知のヒューリスティックなども含みます。Android ゲームやアプリに対するリバースエンジニアリング、改ざん、チートのコストを引き上げる必要がある正当なアプリ所有者向けのツールです。
