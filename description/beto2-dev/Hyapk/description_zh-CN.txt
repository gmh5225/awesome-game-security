Hyapk 是一款面向 Android 应用与游戏的保护与加固打包工具，通过命令行工具链在 native 层与 dex 层施加防护。CLI 主要用 Kotlin 编写，native 运行时用 C 编写；它可将选定方法转换为生成的 C 代码（Dex2C）或自定义 HyVm 虚拟机字节码，并支持按构建随机排列操作码以及 ChaCha20-Poly1305 加密。此外还提供签名校验与 dex 完整性检查、防篡改与反调试、smali 重命名、资源加密，以及反 Frida、反 root 与模拟器检测等启发式策略。该工具面向需要提高 Android 游戏与应用在逆向、篡改与作弊方面成本的合法应用所有者。
