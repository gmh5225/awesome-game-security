MobSentry — локальный анализатор безопасности мобильных приложений, выполняющий статический анализ с приоритетом доказательств для файлов APK Android и IPA iOS. Написан на Python с веб-интерфейсом Flask и headless CLI, использует androguard и разбор Mach-O/plist для сбора локализованных фрагментов кода, после чего преобразует их в градуированные находки, метки достоверности и опциональную корреляцию с помощью ИИ по базе доказательств. Инструмент проверяет стеки SSL pinning, обнаружение root и jailbreak, антиотладку и инструментирование Frida, секреты и утечки Firebase, ошибочные конфигурации манифеста и сетевой безопасности, обфускацию, проблемы подписи и сторонние трекеры, а затем предоставляет рекомендации по обходу с учётом стека с фрагментами Frida и objection. Инструмент выводит интерактивные веб-отчёты и экспорт в PDF для авторизованных пентестеров, реверс-инженеров и исследователей, оценивающих защиту мобильных приложений и игр.
