MobSentry is a local mobile app security analyzer that performs evidence-first static analysis on Android APK and iOS IPA files. Written in Python with a Flask web UI and headless CLI, it uses androguard and Mach-O/plist parsing to collect located snippets before turning them into graded findings, confidence labels, and optional AI-assisted correlation over the evidence database. It inspects SSL pinning stacks, root and jailbreak detection, anti-debug and Frida instrumentation, secrets and Firebase exposure, manifest and network security misconfigurations, obfuscation, signing issues, and third-party trackers, then provides stack-aware bypass guidance with Frida and objection snippets. The tool outputs interactive web reports and PDF exports for authorized penetration testers, reverse engineers, and researchers evaluating mobile app and game protections.
