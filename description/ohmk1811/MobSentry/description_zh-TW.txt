MobSentry 是一款本機行動應用程式安全分析工具，對 Android APK 與 iOS IPA 檔案執行以證據為先的靜態分析。以 Python 撰寫，提供 Flask Web 介面與無頭 CLI，使用 androguard 及 Mach-O/plist 解析收集定位程式碼片段，再轉為分級發現、置信度標籤，並可選擇透過 AI 對證據資料庫進行關聯分析。它檢查 SSL pinning 堆疊、root 與越獄偵測、反除錯與 Frida 插樁、機密資訊與 Firebase 暴露、manifest 與網路安全錯誤設定、混淆、簽章問題及第三方追蹤器，並提供依技術堆疊而定的繞過指引及 Frida 與 objection 程式碼片段。此工具為獲授權的滲透測試人員、逆向工程師，以及評估行動應用與遊戲防護的研究人員，產生互動式 Web 報告與 PDF 匯出。
