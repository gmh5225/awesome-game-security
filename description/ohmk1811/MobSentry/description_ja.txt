MobSentry は、Android APK および iOS IPA ファイルに対してエビデンスファーストの静的解析を行うローカル型モバイルアプリセキュリティ分析ツールです。Python で実装され、Flask Web UI とヘッドレス CLI を備え、androguard および Mach-O/plist 解析により特定位置のコードスニペットを収集し、それらを段階付けされた所見、信頼度ラベル、およびエビデンスデータベースに対する任意の AI 支援相関分析に変換します。SSL ピニングスタック、root/jailbreak 検知、反デバッグおよび Frida インストルメンテーション、シークレットと Firebase の露出、マニフェストとネットワークセキュリティの設定ミス、難読化、署名の問題、サードパーティトラッカーを検査し、Frida および objection のスニペットを用いたスタック対応のバイパスガイダンスを提供します。本ツールは、モバイルアプリやゲームの保護機能を評価する、許可されたペネトレーションテスター、リバースエンジニア、研究者向けにインタラクティブな Web レポートと PDF エクスポートを出力します。
