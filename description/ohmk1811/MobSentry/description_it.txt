MobSentry è un analizzatore locale di sicurezza per app mobili che esegue analisi statica basata sulle evidenze su file APK Android e IPA iOS. Scritto in Python con un'interfaccia web Flask e una CLI headless, utilizza androguard e il parsing Mach-O/plist per raccogliere snippet localizzati prima di convertirli in risultati graduati, etichette di confidenza e correlazione opzionale assistita dall'IA sul database delle evidenze. Ispeziona stack di SSL pinning, rilevamento di root e jailbreak, anti-debug e strumentazione Frida, segreti ed esposizione Firebase, misconfigurazioni del manifest e della sicurezza di rete, offuscamento, problemi di firma e tracker di terze parti, quindi fornisce indicazioni di bypass consapevoli dello stack con snippet Frida e objection. Lo strumento produce report web interattivi ed esportazioni PDF per penetration tester autorizzati, ingegneri del reverse engineering e ricercatori che valutano le protezioni di app mobili e giochi.
