MobSentry 是一款本地移动应用安全分析工具，对 Android APK 和 iOS IPA 文件执行以证据为先的静态分析。该工具使用 Python 编写，提供 Flask Web 界面和无头 CLI，利用 androguard 以及 Mach-O/plist 解析来收集定位代码片段，随后将其转化为分级发现、置信度标签，并可选择借助 AI 对证据数据库进行关联分析。它会检查 SSL pinning 栈、root 与越狱检测、反调试与 Frida 插桩、密钥与 Firebase 暴露、manifest 与网络安全错误配置、混淆、签名问题以及第三方追踪器，并提供基于技术栈的绕过指导及 Frida 与 objection 代码片段。该工具为获得授权的渗透测试人员、逆向工程师以及评估移动应用与游戏防护的研究人员输出交互式 Web 报告和 PDF 导出。
