NtCall64는 64비트 Windows 7 이상에서 커널 서비스 테이블에 스트레스 테스트를 수행하는 Windows NT x64 시스템 호출 퍼저입니다. 주로 C 언어와 최소한의 어셈블리로 작성되었으며, 고전적인 NtCall 방식을 확장하여 ntoskrnl 시스템 호출을 퍼징하고 선택적으로 win32k Shadow SSDT도 대상으로 합니다. 선택적 휴리스틱으로 무작위 매개변수를 생성하며 호출당 패스 횟수를 구성할 수 있습니다. INI 파일을 통해 위험한 서비스를 블랙리스트에 등록하고, 개별 syscall ID를 지정하며, 매개변수를 파일이나 직렬 포트에 기록하고, LocalSystem으로 권한을 높여 더 깊은 커버리지를 얻을 수 있습니다. 이 도구는 Windows 드라이버와 시스템 호출 취약점, 안정성 버그, 권한 상승 문제를 찾는 커널 보안 연구자와 리버스 엔지니어를 대상으로 하며, win32k와 ntoskrnl 핸들러의 결함 발견에도 사용되었습니다.
