NtCall64 是一款 Windows NT x64 系统调用模糊测试工具，用于在 64 位 Windows 7 及更高版本上对内核服务表进行压力测试。该工具主要使用 C 语言编写，辅以少量汇编，它扩展了经典的 NtCall 方法，以模糊测试 ntoskrnl 系统调用，并可选择性地测试 win32k Shadow SSDT，通过可选的启发式算法生成随机参数，并可为每次调用配置通过次数。它支持通过 INI 文件将危险服务列入黑名单、针对特定 syscall ID 进行测试、将参数记录到文件或串口，以及以 LocalSystem 权限提升运行以获得更深覆盖。该工具面向内核安全研究员和逆向工程师，用于发现 Windows 驱动程序与系统调用漏洞、稳定性缺陷以及权限提升问题，并已被用于发现 win32k 和 ntoskrnl 处理程序中的缺陷。
