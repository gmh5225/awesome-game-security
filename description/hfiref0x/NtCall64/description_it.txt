NtCall64 è un fuzzer di system call Windows NT x64 che sottopone a stress test le tabelle dei servizi del kernel su Windows a 64 bit 7 e versioni successive. Scritto principalmente in C con un minimo di assembly, estende l'approccio classico NtCall per fuzzare le syscall di ntoskrnl e, facoltativamente, la Shadow SSDT di win32k, generando parametri randomizzati con euristiche opzionali e conteggi di passaggi configurabili per chiamata. Supporta la blacklist dei servizi pericolosi tramite file INI, il targeting di singoli ID di syscall, la registrazione dei parametri su file o porta seriale e l'esecuzione con privilegi elevati come LocalSystem per una copertura più profonda. Lo strumento è rivolto a ricercatori di sicurezza del kernel e reverse engineer alla ricerca di vulnerabilità in driver e syscall Windows, bug di stabilità e problemi di escalation dei privilegi, ed è stato usato per scoprire difetti nei gestori win32k e ntoskrnl.
