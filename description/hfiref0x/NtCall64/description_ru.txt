NtCall64 — это фаззер системных вызовов Windows NT x64, который проводит нагрузочное тестирование таблиц ядерных служб в 64-разрядных Windows 7 и более поздних версиях. Написанный в основном на C с минимальным использованием ассемблера, он расширяет классический подход NtCall для фаззинга системных вызовов ntoskrnl и, при необходимости, Shadow SSDT win32k, генерируя случайные параметры с опциональными эвристиками и настраиваемым числом проходов на вызов. Поддерживается занесение опасных служб в чёрный список через INI-файл, выбор отдельных идентификаторов syscall, запись параметров в файл или на последовательный порт, а также запуск с повышением привилегий от имени LocalSystem для более глубокого охвата. Инструмент предназначен для исследователей безопасности ядра и специалистов по реверс-инжинирингу, ищущих уязвимости драйверов и системных вызовов Windows, ошибки стабильности и проблемы повышения привилегий; с его помощью уже обнаруживали недостатки в обработчиках win32k и ntoskrnl.
