NtCall64 是一款 Windows NT x64 系統呼叫模糊測試工具，用於在 64 位元 Windows 7 及更高版本上對核心服務表進行壓力測試。此工具主要以 C 語言撰寫，輔以少量組合語言，它擴展了經典的 NtCall 方法，以模糊測試 ntoskrnl 系統呼叫，並可選擇性地測試 win32k Shadow SSDT，透過可選的啟發式演算法產生隨機參數，並可為每次呼叫設定通過次數。它支援透過 INI 檔將危險服務列入黑名單、針對特定 syscall ID 進行測試、將參數記錄到檔案或序列埠，以及以 LocalSystem 權限提升執行以獲得更深覆蓋。此工具面向核心安全研究人員和逆向工程師，用於發現 Windows 驅動程式與系統呼叫漏洞、穩定性缺陷以及權限提升問題，並已被用於發現 win32k 和 ntoskrnl 處理常式中的缺陷。
