NtCall64 は、64 ビット Windows 7 以降のカーネルサービス表に対してストレステストを行う Windows NT x64 システムコールファザーです。主に C 言語と最小限のアセンブリで書かれており、クラシックな NtCall アプローチを拡張して ntoskrnl のシステムコールをファズし、オプションで win32k の Shadow SSDT も対象とできます。任意のヒューリスティクスでランダムなパラメータを生成し、コールごとにパス回数を設定可能です。INI ファイルで危険なサービスをブラックリストに登録し、個別の syscall ID を指定したり、パラメータをファイルやシリアルポートにログ記録したり、LocalSystem として昇格してより深いカバレッジを得たりできます。本ツールは、Windows ドライバーやシステムコールの脆弱性、安定性の不具合、権限昇格の問題を探すカーネルセキュリティ研究者やリバースエンジニア向けであり、win32k と ntoskrnl ハンドラーにおける欠陥の発見にも利用されています。
