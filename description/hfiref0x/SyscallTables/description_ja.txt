このプロジェクトは、ネイティブ API 関数名と syscall 番号を複数の OS ビルドとアーキテクチャにわたって対応付ける、包括的な Windows システムコール テーブルを維持しています。Windows Vista から Windows 11 までの x86-64 および ARM64 向けに、ntoskrnl、win32k、IUM サービスに対する事前生成済みテーブルが含まれ、Zydis ディスアセンブラを用いて ntdll または win32u からテーブルを抽出し、HTML または Markdown の統合リファレンス出力を生成するツールも備えています。scg テーブル ダンパーは C 言語、sstComposer テーブル ジェネレーターは C# で記述されています。直接システムコールの実装、カーネルとのやり取りの分析、ユーザーモード フッキングやアンチチート回避手法の研究を行うリバース エンジニアとセキュリティ研究者を対象としています。
