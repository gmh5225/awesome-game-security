此專案維護全面的 Windows 系統呼叫表，將 native API 函式名稱對應到 syscall 編號，涵蓋多個 OS 版本與架構。它包含針對 ntoskrnl、win32k 和 IUM 服務的預先生成表，涵蓋從 Windows Vista 到 Windows 11 的 x86-64 與 ARM64 平台，並提供工具，可使用 Zydis 反組譯器從 ntdll 或 win32u 提取表，並產生組合的 HTML 或 Markdown 參考輸出。scg 表傾印器以 C 撰寫，sstComposer 表產生器以 C# 撰寫。面向實作直接系統呼叫、分析核心互動或研究使用者模式挂钩與反作弊規避技術的逆向工程師與安全研究人員。
