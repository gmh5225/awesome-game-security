Questo progetto mantiene tabelle complete delle system call di Windows che mappano i nomi delle funzioni dell'API nativa ai rispettivi numeri di syscall su numerose build del sistema operativo e architetture. Include tabelle pre-generate per ntoskrnl, win32k e servizi IUM, da Windows Vista a Windows 11 su x86-64 e ARM64, con strumenti per estrarre tabelle da ntdll o win32u usando il disassemblatore Zydis e comporre output di riferimento combinati in HTML o Markdown. Il dumper di tabelle scg è scritto in C e il generatore di tabelle sstComposer in C#. È rivolto a reverse engineer e ricercatori di sicurezza che implementano syscall dirette, analizzano l'interazione con il kernel o studiano l'hooking in user mode e le tecniche di evasione anti-cheat.
