该项目维护全面的 Windows 系统调用表，将 native API 函数名映射到 syscall 编号，涵盖多个 OS 版本和架构。它包含针对 ntoskrnl、win32k 和 IUM 服务的预生成表，覆盖从 Windows Vista 到 Windows 11 的 x86-64 和 ARM64 平台，并提供工具，可使用 Zydis 反汇编器从 ntdll 或 win32u 提取表，并生成组合的 HTML 或 Markdown 参考输出。scg 表转储器用 C 编写，sstComposer 表生成器用 C# 编写。面向实现直接系统调用、分析内核交互或研究用户态挂钩与反作弊绕过技术的逆向工程师和安全研究人员。
