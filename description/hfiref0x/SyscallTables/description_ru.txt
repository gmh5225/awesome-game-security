Этот проект поддерживает полные таблицы системных вызовов Windows, сопоставляющие имена функций native API с номерами syscall для множества сборок ОС и архитектур. Он включает предварительно сгенерированные таблицы для ntoskrnl, win32k и служб IUM, охватывающие Windows Vista — Windows 11 на x86-64 и ARM64, а также инструменты для извлечения таблиц из ntdll или win32u с помощью дизассемблера Zydis и формирования объединённого справочного вывода в HTML или Markdown. Дампер таблиц scg написан на C, генератор таблиц sstComposer — на C#. Проект предназначен для специалистов по реверс-инжинирингу и исследователей безопасности, которые реализуют прямые syscalls, анализируют взаимодействие с ядром или изучают перехват в пользовательском режиме и методы обхода античита.
