이 프로젝트는 네이티브 API 함수 이름을 여러 OS 빌드와 아키텍처에 걸쳐 syscall 번호에 매핑하는 포괄적인 Windows 시스템 호출 테이블을 유지합니다. Windows Vista부터 Windows 11까지 x86-64 및 ARM64에서 ntoskrnl, win32k, IUM 서비스에 대한 사전 생성 테이블을 포함하며, Zydis 디스어셈블러를 사용해 ntdll 또는 win32u에서 테이블을 추출하고 HTML 또는 Markdown 통합 참조 출력을 생성하는 도구도 제공합니다. scg 테이블 덤퍼는 C로, sstComposer 테이블 생성기는 C#으로 작성되었습니다. 직접 syscall 구현, 커널 상호작용 분석, 사용자 모드 후킹 및 안티치트 우회 기법 연구를 수행하는 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
