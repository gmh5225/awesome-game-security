Este proyecto mantiene tablas completas de llamadas al sistema de Windows que asignan los nombres de funciones de la API nativa a sus números de syscall en numerosas compilaciones del sistema operativo y arquitecturas. Incluye tablas pregeneradas para ntoskrnl, win32k y servicios IUM, desde Windows Vista hasta Windows 11 en x86-64 y ARM64, con herramientas para extraer tablas de ntdll o win32u mediante el desensamblador Zydis y generar salida de referencia combinada en HTML o Markdown. El volcador de tablas scg está escrito en C y el generador de tablas sstComposer en C#. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad que implementan syscalls directos, analizan la interacción con el kernel o estudian el hooking en modo usuario y técnicas de evasión anti-cheat.
