XRay AntiCheat 是一款面向 Spigot Minecraft 伺服器的統計型反作弊外掛，透過比對正常採礦行為與「知曉礦石位置」的採礦模式，偵測透視礦與 X-ray 類作弊。專案為 Maven 多模組 Java 工程，將不依賴 Minecraft 的分析核心與 JDBC 持久化、內嵌 Web 管理面板以及監聽採礦事件的 Spigot 外掛分離。引擎從埋藏與裸露礦石發現、隧道幾何、瞄準模式及發現間隔等訊號累積似然比證據，隨後透過遊戲內指令、GUI 及可選的封禁波次規劃，向管理員呈現判定、置信度與通俗說明。預設策略優先人工複核而非自動封禁，適合希望獲得可解釋、資料驅動遊戲安全而非簡單方塊計數閾值的伺服器營運者與管理人員。
