XRay AntiCheat is a statistical anti-cheat plugin for Spigot Minecraft servers that detects ore-vision and X-ray style cheating by comparing legitimate mining behavior to ore-informed mining. Built as a Maven multi-module Java project, it separates a Minecraft-free analytical core from JDBC persistence, an embedded web administration panel, and the Spigot plugin that listens to mining events. The engine accumulates likelihood-ratio evidence from signals such as buried versus exposed ore discoveries, tunnel geometry, targeting patterns, and inter-discovery timing, then presents verdicts, confidence, and plain-language breakdowns to moderators through in-game commands, a GUI, and optional ban-wave planning. Default enforcement favors human review over automatic bans, making it suited to server operators and staff who want explainable, data-driven game security rather than simple block-count thresholds.
