XRay AntiCheat は Spigot 向け Minecraft サーバー用の統計的反チートプラグインで、正当な採掘行動と鉱石位置を知った採掘を比較し、鉱石透視や X-ray 系の不正を検出します。Maven マルチモジュールの Java プロジェクトとして、Minecraft 非依存の分析コア、JDBC 永続化、組み込み Web 管理パネル、採掘イベントを監視する Spigot プラグインを分離しています。エンジンは埋蔵・露出した鉱石の発見、トンネル形状、照準パターン、発見間隔などの信号から尤度比証拠を蓄積し、ゲーム内コマンド、GUI、任意の BAN ウェーブ計画を通じてモデレーターに判定、信頼度、平易な説明を提示します。既定の執行は自動 BAN より人間によるレビューを優先し、単純なブロック数閾値ではなく説明可能でデータ駆動のゲームセキュリティを求めるサーバー運営者とスタッフ向けです。
