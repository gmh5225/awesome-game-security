XRay AntiCheat 是一款面向 Spigot Minecraft 服务器的统计型反作弊插件，通过对比正常采矿行为与“知晓矿石位置”的采矿模式，检测透视矿与 X-ray 类作弊。项目为 Maven 多模块 Java 工程，将不依赖 Minecraft 的分析核心与 JDBC 持久化、内嵌 Web 管理面板以及监听采矿事件的 Spigot 插件分离。引擎从埋藏与裸露矿石发现、隧道几何、瞄准模式及发现间隔等信号累积似然比证据，随后通过游戏内命令、GUI 及可选的封禁波次规划，向管理员呈现判定、置信度与通俗说明。默认策略优先人工复核而非自动封禁，适合希望获得可解释、数据驱动游戏安全而非简单方块计数阈值的服务器运营者与管理人员。
