XRay AntiCheat는 Spigot Minecraft 서버용 통계 기반 안티치트 플러그인으로, 정상적인 채굴 행동과 광석 위치를 알고 있는 채굴 패턴을 비교해 광석 투시 및 X-ray류 치팅을 탐지합니다. Maven 멀티 모듈 Java 프로젝트로, Minecraft에 의존하지 않는 분석 코어와 JDBC 영속화, 내장 웹 관리 패널, 채굴 이벤트를 수신하는 Spigot 플러그인을 분리했습니다. 엔진은 매몰·노출 광석 발견, 터널 기하, 조준 패턴, 발견 간격 등 신호에서 우도비 증거를 누적하고, 게임 내 명령, GUI, 선택적 밴 웨이브 계획을 통해 운영진에게 판정, 신뢰도, 이해하기 쉬운 설명을 제공합니다. 기본 집행은 자동 밴보다 사람 검토를 우선하여, 단순 블록 수 임계값이 아닌 설명 가능하고 데이터 기반의 게임 보안을 원하는 서버 운영자와 스태프에 적합합니다.
