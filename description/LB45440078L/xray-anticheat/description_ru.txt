XRay AntiCheat — статистический античит-плагин для серверов Minecraft на Spigot, который выявляет читы с «видением руды» и в стиле X-ray, сравнивая законное поведение при добыче с добычей, основанной на знании расположения руды. Проект на Java с несколькими модулями Maven разделяет аналитическое ядро без зависимости от Minecraft, JDBC-персистентность, встроенную веб-панель администрирования и плагин Spigot, который слушает события добычи. Движок накапливает доказательства в виде отношения правдоподобия по сигналам вроде обнаружения зарытой и открытой руды, геометрии туннелей, паттернов наведения и интервалов между находками, затем показывает модераторам вердикты, уверенность и понятные разборы через игровые команды, GUI и опциональное планирование волн банов. По умолчанию приоритет у ручной проверки, а не автоматических банов — подходит операторам и персоналу, которым нужна объяснимая, основанная на данных игровая безопасность, а не простые пороги по числу блоков.
