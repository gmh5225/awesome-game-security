Pocket cheat picker — настольное приложение для выбора и развёртывания чит-кодов на SD-карту Analogue Pocket для ядер openFPGA Game Boy и Game Boy Color. Написано на Python с tkinter и предоставляет трёхпанельный интерфейс для просмотра систем, игр и читов из базы данных libretro, после чего одним действием записывает файлы .cht непосредственно на карту. Инструмент разбирает форматы Game Genie и GameShark, сопоставляет читы с дампами ROM или вручную введёнными названиями картриджей и отмечает, применяется ли каждый код как безопасный патч чтения CPU или как прямая запись в RAM. Он использует общий с ядром openfpga-GBC-cheats парсер файлов читов и включает CLI-утилиты для проверки сравниваемых байтов Game Genie по образам ROM. Предназначен для энтузиастов ретро-железа и пользователей, ориентированных на реверс-инжиниринг, которые управляют читами на реальном оборудовании Analogue Pocket, а не в эмуляторах.
