Pocket cheat picker는 Game Boy 및 Game Boy Color openFPGA 코어용 치트 코드를 선택하여 Analogue Pocket SD 카드에 배포하는 데스크톱 애플리케이션입니다. Python과 tkinter로 작성되었으며, libretro 데이터베이스에서 시스템, 게임, 치트를 탐색할 수 있는 세 패널 인터페이스를 제공하고 한 번의 작업으로 .cht 파일을 카드에 직접 기록합니다. Game Genie 및 GameShark 형식을 구문 분석하고, 치트를 ROM 덤프 또는 수동으로 입력한 카트리지 이름과 매칭하며, 각 코드가 안전한 CPU 읽기 패치로 적용되는지 직접 RAM 쓰기인지 표시합니다. 치트 파일 파서는 openfpga-GBC-cheats 코어와 공유되며, ROM 이미지에 대해 Game Genie 비교 바이트를 검증하는 CLI 유틸리티도 포함합니다. 에뮬레이터가 아닌 실제 Analogue Pocket 하드웨어에서 치트를 관리하는 레트로 하드웨어 애호가 및 리버스 엔지니어링 지향 사용자를 대상으로 합니다.
