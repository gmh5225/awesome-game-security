Pocket cheat picker is a desktop application for selecting and deploying cheat codes onto an Analogue Pocket SD card for Game Boy and Game Boy Color openFPGA cores. Written in Python with tkinter, it provides a three-pane interface to browse systems, games, and cheats from the libretro database, then writes .cht files directly to the card with a single action. The tool parses Game Genie and GameShark formats, matches cheats to ROM dumps or manually entered cartridge names, and flags whether each code is applied as a safe CPU read patch or a direct RAM write. It shares its cheat file parser with the openfpga-GBC-cheats core and includes CLI utilities to verify Game Genie compare bytes against ROM images. It is aimed at retro hardware enthusiasts and reverse-engineering-minded users who manage cheats on real Analogue Pocket hardware rather than in emulators.
