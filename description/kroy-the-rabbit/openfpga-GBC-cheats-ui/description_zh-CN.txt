Pocket cheat picker 是一款桌面应用程序，用于为 Game Boy 与 Game Boy Color 的 openFPGA 核心选择并部署作弊码到 Analogue Pocket SD 卡。该工具使用 Python 与 tkinter 编写，提供三栏界面，可浏览 libretro 数据库中的系统、游戏与作弊项，并通过一次操作将 .cht 文件直接写入存储卡。它解析 Game Genie 与 GameShark 格式，将作弊码与 ROM 转储或手动输入的卡带名称匹配，并标记每条代码是以安全的 CPU 读取补丁还是直接 RAM 写入方式应用。其作弊文件解析器与 openfpga-GBC-cheats 核心共用，并包含用于对照 ROM 镜像验证 Game Genie 比较字节的 CLI 工具。面向在真实 Analogue Pocket 硬件上管理作弊码、而非在模拟器中操作的复古硬件爱好者与逆向工程用户。
