Pocket cheat picker ist eine Desktop-Anwendung zum Auswählen und Bereitstellen von Cheat-Codes auf einer Analogue-Pocket-SD-Karte für Game-Boy- und Game-Boy-Color-openFPGA-Cores. In Python mit tkinter geschrieben, bietet sie eine dreiteilige Oberfläche zum Durchsuchen von Systemen, Spielen und Cheats aus der libretro-Datenbank und schreibt .cht-Dateien mit einer einzigen Aktion direkt auf die Karte. Das Tool parst Game-Genie- und GameShark-Formate, ordnet Cheats ROM-Dumps oder manuell eingegebenen Modulnamen zu und kennzeichnet, ob jeder Code als sicherer CPU-Lese-Patch oder als direkter RAM-Schreibvorgang angewendet wird. Es teilt sich seinen Cheat-Datei-Parser mit dem openfpga-GBC-cheats-Core und enthält CLI-Hilfsprogramme zur Überprüfung von Game-Genie-Vergleichsbytes gegen ROM-Abbilder. Es richtet sich an Retro-Hardware-Enthusiasten und reverse-engineering-orientierte Nutzer, die Cheats auf echter Analogue-Pocket-Hardware statt in Emulatoren verwalten.
