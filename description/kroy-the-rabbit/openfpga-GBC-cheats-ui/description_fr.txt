Pocket cheat picker est une application de bureau pour sélectionner et déployer des codes triche sur une carte SD Analogue Pocket pour les cœurs openFPGA Game Boy et Game Boy Color. Écrite en Python avec tkinter, elle propose une interface à trois volets pour parcourir les systèmes, les jeux et les triches de la base de données libretro, puis écrit directement les fichiers .cht sur la carte en une seule action. L'outil analyse les formats Game Genie et GameShark, associe les triches aux dumps ROM ou aux noms de cartouches saisis manuellement, et indique si chaque code est appliqué comme un patch de lecture CPU sûr ou une écriture RAM directe. Il partage son analyseur de fichiers de triche avec le cœur openfpga-GBC-cheats et inclut des utilitaires CLI pour vérifier les octets de comparaison Game Genie par rapport aux images ROM. Il s'adresse aux passionnés de matériel rétro et aux utilisateurs orientés rétro-ingénierie qui gèrent les triches sur du matériel Analogue Pocket réel plutôt que dans des émulateurs.
