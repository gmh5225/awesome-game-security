Pocket cheat picker è un'applicazione desktop per selezionare e distribuire codici cheat su una scheda SD Analogue Pocket per i core openFPGA di Game Boy e Game Boy Color. Scritta in Python con tkinter, offre un'interfaccia a tre pannelli per esplorare sistemi, giochi e cheat dal database libretro, quindi scrive i file .cht direttamente sulla scheda con un'unica azione. Lo strumento analizza i formati Game Genie e GameShark, abbina i cheat ai dump ROM o ai nomi delle cartucce inseriti manualmente e segnala se ogni codice viene applicato come patch sicura di lettura CPU o come scrittura diretta in RAM. Condivide il parser dei file cheat con il core openfpga-GBC-cheats e include utility CLI per verificare i byte di confronto Game Genie rispetto alle immagini ROM. È rivolto agli appassionati di hardware retro e agli utenti orientati al reverse engineering che gestiscono i cheat su hardware Analogue Pocket reale anziché negli emulatori.
