Pocket cheat picker は、Game Boy および Game Boy Color 向け openFPGA コア用のチートコードを選択し、Analogue Pocket の SD カードへ展開するためのデスクトップアプリケーションです。Python と tkinter で書かれており、libretro データベースからシステム、ゲーム、チートを閲覧できる三ペインのインターフェースを提供し、ワンアクションで .cht ファイルをカードに直接書き込みます。Game Genie および GameShark 形式を解析し、チートを ROM ダンプまたは手入力したカートリッジ名と照合し、各コードが安全な CPU 読み取りパッチとして適用されるか、直接 RAM 書き込みかを示します。チートファイルパーサーは openfpga-GBC-cheats コアと共有され、ROM イメージに対して Game Genie の比較バイトを検証する CLI ユーティリティも含まれます。エミュレータではなく実機 Analogue Pocket 上でチートを管理するレトロハードウェア愛好家やリバースエンジニアリング志向のユーザー向けです。
