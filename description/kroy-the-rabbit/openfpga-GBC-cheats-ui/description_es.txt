Pocket cheat picker es una aplicación de escritorio para seleccionar e implementar códigos de trucos en una tarjeta SD de Analogue Pocket para los núcleos openFPGA de Game Boy y Game Boy Color. Escrita en Python con tkinter, ofrece una interfaz de tres paneles para explorar sistemas, juegos y trucos de la base de datos libretro, y luego escribe archivos .cht directamente en la tarjeta con una sola acción. La herramienta analiza los formatos Game Genie y GameShark, empareja los trucos con volcados ROM o nombres de cartuchos introducidos manualmente, e indica si cada código se aplica como un parche seguro de lectura de CPU o una escritura directa en RAM. Comparte su analizador de archivos de trucos con el núcleo openfpga-GBC-cheats e incluye utilidades CLI para verificar los bytes de comparación de Game Genie frente a imágenes ROM. Está dirigida a entusiastas del hardware retro y usuarios orientados a la ingeniería inversa que gestionan trucos en hardware Analogue Pocket real en lugar de en emuladores.
