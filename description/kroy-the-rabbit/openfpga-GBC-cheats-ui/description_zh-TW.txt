Pocket cheat picker 是一款桌面應用程式，用於為 Game Boy 與 Game Boy Color 的 openFPGA 核心選擇並部署作弊碼到 Analogue Pocket SD 卡。此工具以 Python 與 tkinter 撰寫，提供三欄介面，可瀏覽 libretro 資料庫中的系統、遊戲與作弊項目，並透過一次操作將 .cht 檔直接寫入記憶卡。它解析 Game Genie 與 GameShark 格式，將作弊碼與 ROM 轉儲或手動輸入的卡帶名稱比對，並標示每條代碼是以安全的 CPU 讀取修補還是直接 RAM 寫入方式套用。其作弊檔解析器與 openfpga-GBC-cheats 核心共用，並包含用於對照 ROM 映像驗證 Game Genie 比較位元組的 CLI 工具。面向在真實 Analogue Pocket 硬體上管理作弊碼、而非在模擬器中操作的復古硬體愛好者與逆向工程使用者。
