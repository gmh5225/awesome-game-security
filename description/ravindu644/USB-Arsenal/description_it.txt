USB Arsenal è uno strumento che richiede root per Android e Linux che assembla gadget USB compositi tramite l’interfaccia configfs del kernel, così che un telefono o un container possa presentare più classi di dispositivo all’host contemporaneamente. Il nucleo in C gestisce storage di massa (volumi scrivibili ed emulazione ISO o CD-ROM), tethering USB via NCM o RNDIS con DHCP e NAT, ed endpoint HID tastiera e mouse configurabili, quindi rilascia il controller affinché ADB e MTP normali possano tornare. Il progetto si distribuisce come modulo Magisk o KernelSU con patch al kernel per bug comuni del gadget Android, più un’app Kotlin Jetpack Compose per configurazione, sondaggio delle capacità, profili di identità e controllo live del gadget. È adatto a ricerca sulla sicurezza, reverse engineering e test hardware-adjacent quando serve emulare periferiche USB personalizzate o multifunzione e osservare il comportamento dell’host senza hardware BadUSB dedicato.
