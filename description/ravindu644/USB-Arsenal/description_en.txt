USB Arsenal is a root-required tool for Android and Linux that assembles composite USB gadgets through the kernel configfs interface so a phone or container can present several device classes to a host at once. Its C core drives mass storage (writable volumes and ISO or CD-ROM emulation), USB tethering via NCM or RNDIS with DHCP and NAT, and configurable HID keyboard and mouse endpoints, then releases the controller so normal ADB and MTP can return. The project distributes as a Magisk or KernelSU module with kernel patches for common Android gadget bugs, plus a Kotlin Jetpack Compose app for setup, capability probing, identity profiles, and live gadget control. It suits security research, reverse engineering, and hardware-adjacent testing where you need to emulate custom or multi-function USB peripherals and observe host behavior without dedicated BadUSB hardware.
