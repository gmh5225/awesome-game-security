USB Arsenal은 root 권한이 필요한 Android 및 Linux용 도구로, 커널 configfs 인터페이스를 통해 복합 USB 가젯을 구성하여 휴대폰이나 컨테이너가 호스트에 여러 장치 클래스를 동시에 노출할 수 있게 합니다. C 코어는 대용량 저장소(쓰기 가능 볼륨 및 ISO 또는 CD-ROM 에뮬레이션), NCM 또는 RNDIS를 통한 USB 테더링(DHCP 및 NAT 포함), 구성 가능한 HID 키보드 및 마우스 엔드포인트를 구동한 뒤 컨트롤러를 해제하여 일반 ADB와 MTP를 복구합니다. 프로젝트는 Magisk 또는 KernelSU 모듈로 배포되며, 일반적인 Android 가젯 버그용 커널 패치와 설정, 기능 탐지, ID 프로필, 실시간 가젯 제어를 위한 Kotlin Jetpack Compose 앱을 제공합니다. 보안 연구, 리버스 엔지니어링, 하드웨어 인접 테스트에 적합하며, 전용 BadUSB 하드웨어 없이 사용자 정의 또는 다기능 USB 주변 장치를 에뮬레이션하고 호스트 동작을 관찰할 수 있습니다.
