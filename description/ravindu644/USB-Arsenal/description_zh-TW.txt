USB Arsenal 是一款需要 root 權限的 Android 與 Linux 工具，透過核心 configfs 介面組裝複合 USB gadget，使手機或容器能同時向主機呈現多種裝置類別。其 C 語言核心驅動大量儲存（可寫入磁區及 ISO 或 CD-ROM 模擬）、透過 NCM 或 RNDIS 的 USB 網路共享（含 DHCP 與 NAT），以及可設定的 HID 鍵盤與滑鼠端點，隨後釋放控制器以便恢復一般 ADB 與 MTP。專案以 Magisk 或 KernelSU 模組形式發佈，並附帶針對常見 Android gadget 問題的核心修補程式，以及用於設定、能力探測、身分設定檔與即時 gadget 控制的 Kotlin Jetpack Compose 應用程式。適用於安全研究、逆向工程及硬體相關測試，在無需專用 BadUSB 硬體的情況下模擬自訂或多功能 USB 週邊並觀察主機行為。
