USB Arsenal es una herramienta que requiere root para Android y Linux que ensambla gadgets USB compuestos mediante la interfaz configfs del kernel, de modo que un teléfono o contenedor pueda presentar varias clases de dispositivo al host a la vez. Su núcleo en C controla almacenamiento masivo (volúmenes escribibles y emulación ISO o CD-ROM), anclaje USB vía NCM o RNDIS con DHCP y NAT, y endpoints HID de teclado y ratón configurables, y luego libera el controlador para que ADB y MTP normales vuelvan. El proyecto se distribuye como módulo Magisk o KernelSU con parches de kernel para errores habituales del gadget en Android, más una app Kotlin Jetpack Compose para configuración, sondeo de capacidades, perfiles de identidad y control en vivo del gadget. Sirve para investigación de seguridad, ingeniería inversa y pruebas cercanas al hardware cuando necesitas emular periféricos USB personalizados o multifunción y observar el comportamiento del host sin hardware BadUSB dedicado.
