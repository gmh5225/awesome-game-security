USB Arsenal 是一款需要 root 权限的 Android 与 Linux 工具，通过内核 configfs 接口组装复合 USB gadget，使手机或容器能同时向主机呈现多种设备类。其 C 语言核心驱动大容量存储（可写卷及 ISO 或 CD-ROM 模拟）、通过 NCM 或 RNDIS 的 USB 网络共享（含 DHCP 与 NAT），以及可配置的 HID 键盘与鼠标端点，随后释放控制器以便恢复常规 ADB 与 MTP。项目以 Magisk 或 KernelSU 模块形式分发，并附带针对常见 Android gadget 问题的内核补丁，以及用于设置、能力探测、身份配置与实时 gadget 控制的 Kotlin Jetpack Compose 应用。适用于安全研究、逆向工程及硬件相关测试，在无需专用 BadUSB 硬件的情况下模拟自定义或多功能 USB 外设并观察主机行为。
