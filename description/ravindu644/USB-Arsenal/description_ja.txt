USB Arsenal は root 権限が必要な Android および Linux 向けツールで、カーネルの configfs インターフェース経由で複合 USB ガジェットを組み立て、スマートフォンやコンテナがホストに複数のデバイスクラスを同時に提示できるようにします。C 言語コアは大容量ストレージ（書き込み可能ボリュームおよび ISO または CD-ROM エミュレーション）、NCM または RNDIS による USB テザリング（DHCP と NAT 付き）、設定可能な HID キーボードおよびマウスエンドポイントを駆動し、その後コントローラを解放して通常の ADB と MTP を復帰させます。プロジェクトは Magisk または KernelSU モジュールとして配布され、一般的な Android ガジェット不具合向けのカーネルパッチに加え、セットアップ、能力プローブ、ID プロファイル、ライブガジェット制御用の Kotlin Jetpack Compose アプリを同梱します。セキュリティ研究、リバースエンジニアリング、ハードウェアに近いテストに適し、専用の BadUSB ハードウェアなしでカスタムまたは多機能 USB 周辺機器をエミュレートし、ホストの挙動を観察できます。
