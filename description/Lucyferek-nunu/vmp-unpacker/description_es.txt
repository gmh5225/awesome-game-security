Herramienta C++ para Windows que desempaqueta ejecutables y DLL PE protegidos con VMProtect y reconstruye sus tablas de importación. Inicia o se adjunta a un proceso protegido mediante la API de depuración Win32, elude las comprobaciones anti-depuración habituales de VMProtect parcheando el PEB y enganchando rutinas de ntdll, y detecta el punto de entrada original mediante guardias de la sección de código, instantáneas temporizadas o activadores manuales. Tras suspender el proceso, vuelca la memoria descifrada en un nuevo archivo PE, reconstruye sitios de llamada IAT estándar y mutados, y puede resolver importaciones ofuscadas de forma dinámica o mediante adjunción pasiva sin APIs de depuración. Está dirigida a ingenieros inversores e investigadores de seguridad que analizan software empaquetado con VMProtect, incluidos juegos y otros binarios protegidos.
