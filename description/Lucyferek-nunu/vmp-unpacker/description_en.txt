A Windows C++ tool that unpacks VMProtect-protected PE executables and DLLs and rebuilds their import tables. It launches or attaches to a protected process under the Win32 debugger API, bypasses common VMProtect anti-debug checks by patching the PEB and hooking ntdll routines, and detects the original entry point via text-section guards, timed snapshots, or manual triggers. After suspending the process, it dumps decrypted memory to a new PE file, reconstructs standard and mutated IAT call sites, and can resolve obfuscated imports dynamically or via passive attach without debugger APIs. It is aimed at reverse engineers and security researchers analyzing VMProtect-packed software, including games and other protected binaries.
