Windows 向け C++ ツールで、VMProtect で保護された PE 実行ファイルおよび DLL のアンパックとインポートテーブルの再構築を行います。Win32 デバッガー API で保護されたプロセスを起動またはアタッチし、PEB のパッチと ntdll ルーチンのフックにより VMProtect の一般的なアンチデバッグ検査を回避し、テキストセクションのガード、時間指定スナップショット、または手動トリガーで元のエントリポイントを検出します。プロセスを一時停止した後、復号されたメモリを新しい PE ファイルにダンプし、標準および変異した IAT 呼び出しサイトを再構築し、難読化されたインポートを動的に、またはデバッガー API を使わないパッシブアタッチで解決できます。VMProtect でパックされたソフトウェア（ゲームやその他の保護されたバイナリを含む）を解析するリバースエンジニアおよびセキュリティ研究者向けです。
