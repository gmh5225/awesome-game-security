Strumento C++ per Windows che decompatta eseguibili e DLL PE protetti da VMProtect e ricostruisce le loro tabelle di importazione. Avvia o si collega a un processo protetto tramite l'API del debugger Win32, aggira i comuni controlli anti-debug di VMProtect patchando il PEB e agganciando routine ntdll, e rileva il punto di ingresso originale tramite guardie della sezione di codice, snapshot temporizzati o trigger manuali. Dopo aver sospeso il processo, scarica la memoria decifrata in un nuovo file PE, ricostruisce i siti di chiamata IAT standard e mutati, e può risolvere import offuscati dinamicamente o tramite attach passivo senza API del debugger. È destinato a ingegneri del reverse engineering e ricercatori di sicurezza che analizzano software impacchettato con VMProtect, inclusi giochi e altri binari protetti.
