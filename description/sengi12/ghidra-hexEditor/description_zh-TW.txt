Ghidra-HexEditor 是一款以 Ghidra 腳格外掛形式實作的十六進位編輯器，讓分析人員能夠檢視並修補在 Ghidra 中載入的程式原始位元組。它主要使用 Java 撰寫，採用從 javadev/hexeditor 分叉而來的 Swing 介面，可作為可停靠的 Ghidra 視窗與 Listing 和 Decompiler 並排開啟，或在無法停靠時回退至獨立視窗。此編輯器支援原地位元組編輯、二進位搜尋、透過 Ghidra 的 BinaryExporter 儲存修改後的可執行檔，並自動符合 Ghidra 的外觀與風格，包括可選的深色模式。它面向逆向工程與遊戲安全工作流程，供研究人員在不離開 Ghidra 環境的情況下檢查並修補二進位檔案。
