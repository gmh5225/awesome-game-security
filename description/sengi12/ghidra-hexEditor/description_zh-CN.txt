Ghidra-HexEditor 是一款以 Ghidra 脚本插件形式实现的十六进制编辑器，使分析人员能够查看并修补在 Ghidra 中加载的程序的原始字节。它主要使用 Java 编写，基于从 javadev/hexeditor 分叉的 Swing 界面，可作为可停靠的 Ghidra 窗口与 Listing 和 Decompiler 并排打开，或在无法停靠时回退到独立窗口。该编辑器支持原地字节编辑、二进制搜索、通过 Ghidra 的 BinaryExporter 保存修改后的可执行文件，并自动匹配 Ghidra 的外观与风格，包括可选的深色模式。它面向逆向工程和游戏安全工作流，供研究人员在不离开 Ghidra 环境的情况下检查和修补二进制文件。
