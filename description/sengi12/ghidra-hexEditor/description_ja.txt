Ghidra-HexEditor は、Ghidra スクリプトプラグインとして実装された十六進エディタで、分析者が Ghidra に読み込んだプログラムの生バイトを表示・パッチできます。主に Java で書かれ、javadev/hexeditor からフォークした Swing ベースの UI を備え、Listing および Decompiler の横にドッキング可能な Ghidra ウィンドウとして開くか、ドッキングが利用できない場合はスタンドアロンウィンドウにフォールバックします。エディタはインプレースのバイト編集、バイナリ検索、Ghidra の BinaryExporter による変更済み実行ファイルの保存をサポートし、オプションのダークモードを含め Ghidra のルックアンドフィールに自動的に合わせます。Ghidra 環境を離れずにバイナリを調査・パッチする必要があるリバースエンジニアリングやゲームセキュリティのワークフロー向けです。
