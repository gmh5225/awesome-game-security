This is an independent research project that decompiles and reconstructs Farming Simulator 15 and its GIANTS Engine 6 runtime from native binaries and game assets. The work is implemented mainly in C++17 with CMake, backed by Python validation scripts, PowerShell build tooling, and a LuaJIT-based script host that re-hosts hundreds of recovered Lua modules. It systematically recovers engine subsystems such as scene graphs, file streams, animation, OpenGL draw paths, and Bullet-backed vehicle physics, and compares reconstructed behavior against original code through large fixture-based differential tests. A parallel track runs original GE6 x64 instructions on Linux under controlled VMs and platform adapters to study startup, rendering, and scripting without replacing the commercial executable wholesale. It targets reverse engineers, engine researchers, and analysts who need reproducible evidence and tooling for studying proprietary game engine internals, boot paths, and script-native boundaries.
