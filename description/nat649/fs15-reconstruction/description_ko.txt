네이티브 바이너리와 게임 에셋에서 Farming Simulator 15와 GIANTS Engine 6 런타임을 디컴파일하고 재구성하는 독립 연구 프로젝트입니다. 구현은 주로 C++17과 CMake로 이루어지며, Python 검증 스크립트, PowerShell 빌드 도구, LuaJIT 기반 스크립트 호스트가 뒷받침하고, 복구된 수백 개의 Lua 모듈을 다시 호스팅합니다. 씬 그래프, 파일 스트림, 애니메이션, OpenGL 드로우 경로, Bullet 기반 차량 물리 등 엔진 하위 시스템을 체계적으로 복원하고, 대규모 fixture 기반 차분 테스트로 재구성된 동작을 원본 코드와 비교합니다. 병렬 트랙에서는 제어된 VM과 플랫폼 어댑터 아래 Linux에서 원본 GE6 x64 명령을 실행하여 상용 실행 파일을 통째로 교체하지 않고 시작, 렌더링, 스크립팅을 연구합니다. 독점 게임 엔진 내부, 부트 경로, 스크립트-네이티브 경계를 연구하기 위해 재현 가능한 근거와 도구가 필요한 리버스 엔지니어, 엔진 연구자, 분석가를 대상으로 합니다.
