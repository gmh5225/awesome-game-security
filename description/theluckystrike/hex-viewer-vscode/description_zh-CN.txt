Hex Viewer 是一款 Visual Studio Code 扩展，可在编辑器内直接将原始二进制文件以十六进制显示和编辑，包括多 GB 的镜像与转储，而无需整文件载入内存。扩展使用 JavaScript 实现，基于标准 VS Code 扩展与 webview API，支持按范围读取、按需渲染行，并严格采用离线、无遥测设计。核心能力包括跳转到偏移、支持通配符的十六进制与文本搜索、用于整数、浮点、GUID 及常见时间格式的数据检查器，以及以十六进制、C 数组、Python bytes 或 base64 复制/导出、带撤销的覆写模式字节编辑，并可从文件头快速识别 PE、ELF、PNG、ZIP 等格式。面向逆向工程师、恶意软件分析师与游戏安全从业者，在 IDE 工作流中检视固件、内存转储、ROM 及其他二进制数据。
