Hex Viewer — расширение для Visual Studio Code, которое отображает и редактирует сырые двоичные файлы в шестнадцатеричном виде прямо в редакторе, в том числе многогигабайтные образы и дампы без полной загрузки в память. Реализовано на JavaScript с использованием стандартных API расширений и webview VS Code, с чтением по диапазонам, отрисовкой строк по требованию и строгой офлайн-моделью без телеметрии. Основные возможности: переход к смещению, поиск по hex и тексту с подстановочными знаками, инспектор данных для целых, float, GUID и распространённых форматов времени, копирование/экспорт в hex, C-массивы, байты Python или base64, редактирование байтов в режиме перезаписи с отменой, быстрое определение форматов PE, ELF, PNG и ZIP по заголовкам файлов. Ориентировано на реверс-инженеров, аналитиков вредоносного ПО и специалистов по безопасности игр, которым нужно разбирать прошивки, дампы памяти, ROM и другие бинарники, не выходя из привычного IDE-процесса.
