Hex Viewer is a Visual Studio Code extension that displays and edits raw binary files as hex directly inside the editor, including multi-gigabyte images and dumps without loading them entirely into memory. It is implemented in JavaScript using the standard VS Code extension and webview APIs, with range-based reads, on-demand row rendering, and a strict offline, no-telemetry design. Core capabilities include go-to-offset navigation, hex and text search with wildcards, a data inspector for integers, floats, GUIDs and common time formats, copy/export as hex, C arrays, Python bytes or base64, overwrite-mode byte editing with undo, and quick recognition of formats such as PE, ELF, PNG, and ZIP from file headers. It targets reverse engineers, malware analysts, and game-security practitioners who need to inspect firmware, memory dumps, ROMs, and other binaries while staying in their IDE workflow.
