Hex Viewer は Visual Studio Code 用拡張機能で、エディター内で生のバイナリファイルを十六進表示・編集でき、数ギガバイト規模のイメージやダンプもメモリへ丸ごと読み込まずに扱えます。JavaScript で実装し、標準の VS Code 拡張および webview API を利用し、範囲読み取り・オンデマンドの行レンダリング、厳格なオフライン・テレメトリなし設計を採用しています。主な機能はオフセットへのジャンプ、ワイルドカード付き十六進・テキスト検索、整数・浮動小数・GUID・一般的な時刻形式向けデータインスペクター、十六進・C 配列・Python bytes・base64 としてのコピー/エクスポート、元に戻せる上書きモードのバイト編集、PE・ELF・PNG・ZIP などファイルヘッダからの形式判定です。ファームウェア、メモリダンプ、ROM などのバイナリを IDE のワークフローのまま調べたいリバースエンジニア、マルウェア解析者、ゲームセキュリティ実務者向けです。
