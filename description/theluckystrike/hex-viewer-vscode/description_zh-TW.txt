Hex Viewer 是一款 Visual Studio Code 延伸功能，可在編輯器內直接以十六進位顯示與編輯原始二進位檔，包含多 GB 的映像與傾印，無需將整個檔案載入記憶體。以 JavaScript 實作，採用標準 VS Code 延伸與 webview API，具備範圍式讀取、按需列渲染，以及嚴格的離線、無遙測設計。核心功能包含跳至偏移、支援萬用字元的十六進位與文字搜尋、用於整數、浮點數、GUID 與常見時間格式的資料檢視器，以及以十六進位、C 陣列、Python bytes 或 base64 複製/匯出、具復原的覆寫模式位元組編輯，並可從檔案標頭快速辨識 PE、ELF、PNG、ZIP 等格式。適合逆向工程師、惡意軟體分析師與遊戲安全實務者，在 IDE 工作流程中檢視韌體、記憶體傾印、ROM 及其他二進位資料。
