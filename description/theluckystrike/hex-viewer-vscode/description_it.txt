Hex Viewer è un’estensione per Visual Studio Code che visualizza e modifica file binari grezzi in esadecimale direttamente nell’editor, incluse immagini e dump da più gigabyte senza caricarli interamente in memoria. È implementata in JavaScript con le API standard di estensione e webview di VS Code, con letture per intervalli, rendering delle righe su richiesta e un design rigorosamente offline e senza telemetria. Le funzionalità principali includono navigazione a offset, ricerca esadecimale e testuale con jolly, un ispettore dati per interi, float, GUID e formati orari comuni, copia/esportazione come hex, array C, byte Python o base64, modifica byte in modalità sovrascrittura con annulla, e rapido riconoscimento di formati come PE, ELF, PNG e ZIP dalle intestazioni dei file. È pensata per reverse engineer, analisti di malware e professionisti della sicurezza nei giochi che devono ispezionare firmware, dump di memoria, ROM e altri binari restando nel flusso di lavoro dell’IDE.
