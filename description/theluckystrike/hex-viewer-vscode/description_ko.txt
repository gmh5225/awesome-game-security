Hex Viewer는 Visual Studio Code 확장으로, 에디터 안에서 원시 바이너리 파일을 16진수로 표시·편집할 수 있으며 수 기가바이트 규모의 이미지와 덤프도 전체를 메모리에 올리지 않고 다룹니다. JavaScript로 구현했고 표준 VS Code 확장 및 webview API를 사용하며, 범위 기반 읽기, 요청 시 행 렌더링, 엄격한 오프라인·무보고(telemetry 없음) 설계를 따릅니다. 핵심 기능으로는 오프셋 이동, 와일드카드를 지원하는 16진·텍스트 검색, 정수·부동소수·GUID·일반적인 시간 형식용 데이터 검사기, 16진·C 배열·Python bytes·base64로 복사/내보내기, 실행 취소가 가능한 덮어쓰기 모드 바이트 편집, PE·ELF·PNG·ZIP 등 파일 헤더로 형식 빠른 인식이 있습니다. 펌웨어, 메모리 덤프, ROM 등 바이너리를 IDE 워크플로 안에서 살펴봐야 하는 리버스 엔지니어, 멀웨어 분석가, 게임 보안 실무자를 대상으로 합니다.
