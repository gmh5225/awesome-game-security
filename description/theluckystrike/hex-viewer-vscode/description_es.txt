Hex Viewer es una extensión de Visual Studio Code que muestra y edita archivos binarios en bruto en hexadecimal directamente en el editor, incluidas imágenes y volcados de varios gigabytes sin cargarlos por completo en memoria. Está implementada en JavaScript mediante las API estándar de extensiones y webview de VS Code, con lecturas por rangos, renderizado de filas bajo demanda y un diseño estrictamente sin conexión y sin telemetría. Las capacidades principales incluyen ir a un desplazamiento, búsqueda hexadecimal y de texto con comodines, un inspector de datos para enteros, flotantes, GUID y formatos de tiempo habituales, copiar/exportar como hex, matrices C, bytes de Python o base64, edición de bytes en modo sobrescritura con deshacer, y reconocimiento rápido de formatos como PE, ELF, PNG y ZIP a partir de las cabeceras. Está dirigida a ingenieros inversos, analistas de malware y profesionales de seguridad en juegos que necesitan inspeccionar firmware, volcados de memoria, ROM y otros binarios sin salir de su flujo de trabajo en el IDE.
