osu! 向けの Windows 外部エイムアシストツールで、ゲームプロセスへ注入せずにゲームと並行して動作します。Python で実装され、ctypes 経由の Windows API で相対・絶対カーソル移動、SendInput によるキーボードとマウス入力、高頻度タブレットペン向けの任意の低レベルマウスフックを提供します。曲の再生位置、ビートマップのパス、アクティブな Mod は tosu または gosumemory からローカル WebSocket で取得し、ヒットオブジェクトのタイミングと座標は標準の .osu ビートマップファイルから解析します。設定可能なエイム補正、任意の Relax 風自動タップタイミング、CustomTkinter のコントロールパネル、SHA-256 検証付き HTTPS マニフェスト更新を備えます。リズムゲームのチート、外部入力の自動化、OS レベルのイベントと公開ビートマップデータだけでクライアントを支援する方法を研究する開発者・研究者向けです。
