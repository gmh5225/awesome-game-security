osu!용 Windows 외부 에임 보조 도구로, 게임 프로세스에 주입하지 않고 게임과 함께 실행됩니다. Python으로 작성되었으며 ctypes를 통한 Windows API로 상대·절대 커서 이동, SendInput을 이용한 키보드·마우스 입력, 고주파 타블릿 펜을 위한 선택적 저수준 마우스 후크를 사용합니다. 곡 재생 위치, 비트맵 경로, 활성 모드는 tosu 또는 gosumemory에서 로컬 WebSocket으로 가져오고, 히트 오브젝트의 타이밍과 좌표는 표준 .osu 비트맵 파일에서 파싱합니다. 설정 가능한 에임 보정, 선택적 Relax 스타일 자동 탭 타이밍, CustomTkinter 제어 패널, SHA-256 검증이 포함된 HTTPS 매니페스트 업데이트를 제공합니다. 리듬 게임 치트, 외부 입력 자동화, OS 수준 이벤트와 공개 비트맵 데이터만으로 클라이언트를 보조하는 방식을 연구하는 개발자와 연구자를 대상으로 합니다.
