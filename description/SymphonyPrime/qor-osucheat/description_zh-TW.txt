這是一款面向 osu! 的 Windows 外部輔助瞄準工具，可與遊戲並行執行且無需向遊戲行程注入程式碼。專案以 Python 撰寫，透過 ctypes 呼叫 Windows API 實現相對與絕對游標移動，並以 SendInput 處理鍵盤與滑鼠輸入，亦可選用低階滑鼠 Hook 以支援高頻數位板筆輸入。歌曲進度、譜面路徑與啟用中的 Mod 等資訊由 tosu 或 gosumemory 經本地 WebSocket 提供，打擊物件的時機與座標則自標準 .osu 譜面檔解析。功能包含可設定的瞄準修正、可選的 Relax 式自動點擊節奏、CustomTkinter 控制面板，以及附 SHA-256 驗證的 HTTPS 清單更新。適合研究節奏遊戲作弊、外部輸入自動化，以及如何僅依賴作業系統層級事件與公開譜面資料輔助客戶端的開發者與研究人員。
