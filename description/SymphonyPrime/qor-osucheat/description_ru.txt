Внешний инструмент помощи при прицеливании для osu! под Windows, работающий вместе с игрой без внедрения в её процесс. Написан на Python и использует Windows API через ctypes для относительного и абсолютного перемещения курсора, ввод с клавиатуры и мыши через SendInput, а также необязательный низкоуровневый перехват мыши для высокочастотных планшетных перьев. Текущая позиция в песне, путь к карте и активные моды приходят от tosu или gosumemory по локальному WebSocket, а время и координаты hit objects разбираются из стандартных файлов beatmap .osu. Есть настраиваемая коррекция прицела, опциональный автоматический тайминг нажатий в духе Relax, панель управления на CustomTkinter и обновления манифеста по HTTPS с проверкой SHA-256. Предназначен для исследователей и разработчиков, изучающих читерство в ритм-играх, внешнюю автоматизацию ввода и помощь клиентам только за счёт событий уровня ОС и публичных данных beatmap.
