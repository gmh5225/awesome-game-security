This is a Windows external aim-assist tool for osu! that runs alongside the game without injecting into its process. It is written in Python and uses the Windows API through ctypes for relative and absolute cursor movement, keyboard and mouse input via SendInput, and an optional low-level mouse hook for high-frequency tablet pens. Live song position, beatmap path, and active mods come from tosu or gosumemory over a local WebSocket, while hit-object timing and coordinates are parsed from standard .osu beatmap files. Configurable aim correction, optional Relax-style automatic tap timing, a CustomTkinter control panel, and HTTPS manifest updates with SHA-256 verification are included. It is aimed at researchers and developers studying rhythm-game cheating, external input automation, and how clients can be assisted using only OS-level events and public beatmap data.
