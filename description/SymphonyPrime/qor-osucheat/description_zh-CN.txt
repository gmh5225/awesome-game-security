这是一款面向 osu! 的 Windows 外部辅助瞄准工具，可与游戏并行运行且无需向游戏进程注入代码。项目使用 Python 编写，通过 ctypes 调用 Windows API 实现相对与绝对光标移动，借助 SendInput 处理键盘与鼠标输入，并可选用低级鼠标钩子以支持高频数位板笔输入。歌曲进度、谱面路径与当前 Mod 等信息由 tosu 或 gosumemory 经本地 WebSocket 提供，击打物时机与坐标则来自标准 .osu 谱面文件的解析。功能包括可配置的瞄准修正、可选的 Relax 式自动敲击节奏、CustomTkinter 控制面板，以及带 SHA-256 校验的 HTTPS 清单更新。面向研究节奏游戏作弊、外部输入自动化，以及如何仅依赖操作系统级事件与公开谱面数据辅助客户端的开发者和研究人员。
