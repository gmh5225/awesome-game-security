TMSRecomp는 Nintendo Switch 빌드인 『도쿄 미라지 세션즈 #FE Encore』를 정적으로 재컴파일하여 플레이어가 보유한 게임 에셋으로 Windows 또는 Linux 데스크톱에서 실행되는 네이티브 프로그램으로 만든다. Python AArch64-to-C++ 리프터가 Switch 실행 코드를 변환하고, C++ 런타임이 콘솔 커널, IPC, 파일시스템, 오디오, 동영상 서비스를 에뮬레이션하며 NVN 그래픽을 Vulkan에 매핑하고 선택적으로 DLSS 및 FSR 업스케일링을 지원한다. CMake, Clang, SDL3, SPIR-V 셰이더 도구 및 보조 Python 유틸리티가 설정, 패키징, 자막, 명령어 수준 diff 테스트 같은 검증을 처리한다. 이 프로젝트는 정적 재컴파일, 콘솔 HLE, 독점 게임 엔진의 고성능 PC 포팅을 연구하는 리버스 엔지니어와 포팅 연구자에 적합하며, 라이브 안티치트나 온라인 보안 작업용이 아니다.
