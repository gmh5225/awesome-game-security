TMSRecomp は Nintendo Switch 版『東京ミラージュセッションズ #FE Encore』を静的再コンパイルし、プレイヤー自身のゲームアセットを使って Windows または Linux デスクトップで動作するネイティブプログラムに変換する。Python の AArch64 から C++ へのリフターが Switch 実行コードを変換し、C++ ランタイムがコンソールカーネル、IPC、ファイルシステム、オーディオ、動画サービスをエミュレートし、NVN グラフィックスを Vulkan にマッピングする（DLSS と FSR によるアップスケールは任意）。CMake、Clang、SDL3、SPIR-V シェーダーツール、および補助 Python ユーティリティがセットアップ、パッケージング、字幕、命令レベルの差分テストなどの検証を担う。本プロジェクトは静的再コンパイル、コンソール HLE、プロプライエタリゲームエンジンの高性能 PC 移植を研究するリバースエンジニアやポート研究向けであり、ライブアンチチートやオンラインセキュリティ業務向けではない。
