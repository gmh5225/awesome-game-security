TMSRecomp 将 Nintendo Switch 版《东京迷城 #FE Encore》静态重编译为可在 Windows 或 Linux 桌面运行的原生程序，并使用玩家自有的游戏资源。Python AArch64 到 C++ 的提升器翻译 Switch 可执行代码，C++ 运行时则模拟主机内核、IPC、文件系统、音频与影片服务，并将 NVN 图形映射到 Vulkan，可选 DLSS 与 FSR 超分。CMake、Clang、SDL3、SPIR-V 着色器工具及配套 Python 工具负责搭建、打包、字幕与验证（如指令级差异测试）。该项目面向研究静态重编译、主机 HLE 与将专有游戏引擎高性能移植到 PC 的逆向工程师与移植研究者，而非实时反作弊或在线安全相关工作。
