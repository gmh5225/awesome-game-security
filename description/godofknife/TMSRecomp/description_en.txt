TMSRecomp statically recompiles the Nintendo Switch build of Tokyo Mirage Sessions #FE Encore into a native Windows or Linux desktop program that runs against the player’s own game assets. A Python AArch64-to-C++ lifter translates Switch executable code while a C++ runtime emulates the console kernel, IPC, filesystem, audio, and movie services and maps NVN graphics to Vulkan with optional DLSS and FSR upscaling. CMake, Clang, SDL3, SPIR-V shader tooling, and supporting Python utilities handle setup, packaging, subtitles, and validation such as instruction-level diff tests. The project suits reverse engineers and porting researchers studying static recompilation, console HLE, and high-performance PC adaptations of proprietary game engines rather than live anti-cheat or online security work.
