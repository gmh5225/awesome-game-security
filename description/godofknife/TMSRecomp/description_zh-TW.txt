TMSRecomp 將 Nintendo Switch 版《東京幻影物語 #FE Encore》靜態重編譯為可在 Windows 或 Linux 桌面執行的原生程式，並使用玩家自有的遊戲資源。Python AArch64 至 C++ 的提升器轉譯 Switch 可執行程式碼，C++ 執行階段則模擬主機核心、IPC、檔案系統、音訊與影片服務，並將 NVN 圖形對應至 Vulkan，可選用 DLSS 與 FSR 超解析。CMake、Clang、SDL3、SPIR-V 著色器工具及配套 Python 工具負責建置、封裝、字幕與驗證（如指令級差異測試）。本專案適合研究靜態重編譯、主機 HLE 與將專有遊戲引擎高效移植至 PC 的逆向工程師與移植研究者，而非即時反作弊或線上安全相關工作。
