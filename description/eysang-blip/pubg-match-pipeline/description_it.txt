Questo progetto è una pipeline dati end-to-end che recupera la telemetria delle partite PUBG dall’API ufficiale, la carica in SQLite e classifica le prestazioni dei giocatori che meritano una revisione manuale anti-cheat. Script Python orchestrano il campionamento degli ID partita, la raccolta incrementale di JSON con gestione dei rate limit, ricostruzioni deterministiche del database e un gate di validazione a nove controlli che blocca l’analisi quando la qualità dei dati non è sufficiente. Il livello analitico usa viste e query SQL per filtrare i giocatori umani in squadra, calcolare z-score del danno al minuto per partita e outlier del tasso di headshot, ed esportare candidati prioritari per la revisione. È pensato per chi lavora nella sicurezza dei giochi e nell’anti-cheat e desidera un flusso riproducibile guidato dalle statistiche per individuare gioco sospetto dai riepiloghi pubblici delle partite anziché dalla telemetria in-client.
