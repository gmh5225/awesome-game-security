Este proyecto es una canalización de datos de extremo a extremo que obtiene la telemetría de partidas de PUBG desde la API oficial, la carga en SQLite y clasifica el rendimiento de jugadores que merecen revisión manual anti-trampas. Scripts en Python orquestan el muestreo de identificadores de partida, la recopilación incremental de JSON con manejo de límites de tasa, reconstrucciones deterministas de la base de datos y una puerta de validación de nueve comprobaciones que bloquea el análisis si falla la calidad de los datos. La capa analítica usa vistas y consultas SQL para filtrar jugadores humanos en escuadra, calcular z-scores de daño por minuto por partida y valores atípicos de tasa de headshot, y exportar candidatos prioritarios para revisión. Está dirigido a profesionales de seguridad en juegos y anti-trampas que quieren un flujo reproducible basado en estadísticas para detectar juego sospechoso a partir de resúmenes públicos de partidas en lugar de telemetría en el cliente.
