이 프로젝트는 공식 API에서 PUBG 매치 텔레메트리를 가져와 SQLite에 적재하고, 수동 안티치트 검토가 필요한 플레이어 성과를 순위화하는 end-to-end 데이터 파이프라인입니다. Python 스크립트가 매치 ID 샘플링, 속도 제한 처리가 포함된 증분 JSON 수집, 결정적 데이터베이스 재구축, 데이터 품질이 기준에 못 미치면 분석을 차단하는 아홉 단계 검증 게이트를 조율합니다. 분석 계층은 SQL 뷰와 쿼리로 스쿼드 인간 플레이어를 필터링하고, 매치별 분당 피해량 z-점수와 헤드샷 비율 이상치를 계산하며 우선 검토 후보를 내보냅니다. 클라이언트 내 텔레메트리가 아닌 공개 매치 요약에서 의심스러운 플레이를 재현 가능하고 통계 기반 워크플로로 찾고자 하는 게임 보안 및 안티치트 실무자를 대상으로 합니다.
