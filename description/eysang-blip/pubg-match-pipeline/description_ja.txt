本プロジェクトは、公式 API から PUBG のマッチテレメトリを取得し SQLite にロードし、手動のアンチチート審査に値するプレイヤー成績をランク付けするエンドツーエンドのデータパイプラインです。Python スクリプトがマッチ ID のサンプリング、レート制限対応の増分 JSON 収集、決定的なデータベース再構築、データ品質が不十分な場合に分析を止める九段階の検証ゲートを統括します。分析層は SQL ビューとクエリでスクワッドの人間プレイヤーを絞り込み、マッチごとの分あたりダメージの z スコアとヘッドショット率の外れ値を算出し、優先審査候補をエクスポートします。公開マッチサマリーから疑わしいプレイを統計に基づく再現可能なワークフローでスカウトしたい、ゲームセキュリティおよびアンチチートの実務者向けです。
