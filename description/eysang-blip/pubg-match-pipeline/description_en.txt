This project is an end-to-end data pipeline that pulls PUBG match telemetry from the official API, loads it into SQLite, and ranks player performances that merit manual anti-cheat review. Python scripts orchestrate match ID sampling, incremental JSON collection with rate-limit handling, deterministic database rebuilds, and a nine-check validation gate that blocks analysis when data quality fails. The analytical layer uses SQL views and queries to filter squad human players, compute per-match damage-per-minute z-scores and headshot-rate outliers, and export prioritized review candidates. It is aimed at game security and anti-cheat practitioners who want a reproducible, statistics-driven workflow for scouting suspicious play from public match summaries rather than relying on in-client telemetry.
