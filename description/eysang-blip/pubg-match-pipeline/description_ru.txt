Этот проект — сквозной конвейер данных: он загружает телеметрию матчей PUBG из официального API в SQLite и ранжирует показатели игроков, заслуживающих ручной проверки на читы. Скрипты на Python координируют выборку ID матчей, инкрементальный сбор JSON с учётом лимитов запросов, детерминированные пересборки базы и девятиступенчатый контроль качества, блокирующий анализ при плохих данных. Аналитический слой использует представления и запросы SQL для отбора живых игроков в отрядах, расчёта z-оценок урона в минуту по матчам и выбросов по доле хедшотов, а также экспорта приоритетных кандидатов на проверку. Он предназначен для специалистов по игровой безопасности и античиту, которым нужен воспроизводимый статистически обоснованный процесс поиска подозрительной игры по публичным сводкам матчей, а не по внутриигровой телеметрии.
