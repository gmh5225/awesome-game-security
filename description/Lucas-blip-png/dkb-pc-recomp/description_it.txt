DKB Recomp ricompila staticamente Donkey Kong Bananza (Nintendo Switch 2 ARM64) in un eseguibile Windows x86-64 nativo con un renderer basato su Vulkan. Un lifter Python in recomp/ traduce i moduli main e SDK dumpati in C generato compilato da Clang, mentre il runtime C e C++ emula i servizi Switch, implementa un front-end grafico NVN 2 e abbassa gli shader Ampere a Maxwell tramite Eglantine. Il progetto estende i pattern di TotK Recomp e LAS Recomp con patch binarie specifiche per versione, gestione delle jump table e test differenziali basati su Unicorn per convalidare il lifting rispetto al comportamento ARM64 originale. È rivolto a reverse engineer, ricercatori di preservazione e sviluppatori che studiano binari Switch 2, API GPU proprietarie e pipeline di ricompilazione statica, non alla distribuzione di asset di gioco.
