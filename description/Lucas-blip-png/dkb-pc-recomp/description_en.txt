DKB Recomp statically recompiles Donkey Kong Bananza (Nintendo Switch 2 ARM64) into a native Windows x86-64 executable with a Vulkan-based renderer. A Python lifter in recomp/ translates dumped main and SDK modules into generated C that Clang compiles, while the C and C++ runtime emulates Switch services, implements an NVN 2 graphics front end, and lowers Ampere shaders to Maxwell via Eglantine. The project extends TotK Recomp and LAS Recomp patterns with version-specific binary patches, jumptable handling, and Unicorn-backed differential tests to validate lifting against the original ARM64 behavior. It targets reverse engineers, preservation researchers, and developers studying Switch 2 binaries, proprietary GPU APIs, and static recompilation pipelines rather than distributing game assets.
