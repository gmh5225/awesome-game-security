DKB Recomp статически рекомпилирует Donkey Kong Bananza (Nintendo Switch 2 ARM64) в нативный исполняемый файл Windows x86-64 с рендерером на базе Vulkan. Python-лифтер в recomp/ переводит дампнутые main- и SDK-модули в сгенерированный C, который компилирует Clang; среда выполнения на C и C++ эмулирует сервисы Switch, реализует графический фронтенд NVN 2 и понижает шейдеры Ampere до Maxwell через Eglantine. Проект расширяет подходы TotK Recomp и LAS Recomp версионно-специфичными бинарными патчами, обработкой таблиц переходов и дифференциальными тестами на Unicorn для проверки лифтинга относительно исходного поведения ARM64. Он ориентирован на reverse-инженеров, исследователей сохранения и разработчиков, изучающих бинарники Switch 2, проприетарные GPU API и конвейеры статической рекомпиляции, а не на распространение игровых ассетов.
