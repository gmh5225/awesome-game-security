DKB Recomp recompile statiquement Donkey Kong Bananza (Nintendo Switch 2 ARM64) en un exécutable Windows x86-64 natif avec un moteur de rendu basé sur Vulkan. Un lifter Python dans recomp/ traduit les modules main et SDK dumpés en C généré compilé par Clang, tandis que le runtime C et C++ émule les services Switch, implémente une couche graphique NVN 2 et abaisse les shaders Ampere vers Maxwell via Eglantine. Le projet étend les modèles TotK Recomp et LAS Recomp avec des correctifs binaires spécifiques aux versions, la gestion des tables de saut et des tests différentiels basés sur Unicorn pour valider le lifting face au comportement ARM64 d’origine. Il s’adresse aux ingénieurs reverse, chercheurs en préservation et développeurs étudiant les binaires Switch 2, les API GPU propriétaires et les pipelines de recompilation statique, et non à la distribution d’actifs de jeu.
