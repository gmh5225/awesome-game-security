DKB Recomp は Donkey Kong Bananza（Nintendo Switch 2 ARM64）を静的再コンパイルし、Vulkan ベースのレンダラーを備えたネイティブ Windows x86-64 実行ファイルに変換する。recomp/ 内の Python リフターがダンプした main および SDK モジュールを生成 C に翻訳し、Clang がコンパイルする。C/C++ ランタイムは Switch サービスをエミュレートし、NVN 2 グラフィックスフロントエンドを実装し、Eglantine 経由で Ampere シェーダーを Maxwell にロワリングする。TotK Recomp と LAS Recomp のパターンを拡張し、バージョン固有のバイナリパッチ、ジャンプテーブル処理、Unicorn ベースの差分テストでリフティングを元の ARM64 動作と照合検証する。Switch 2 バイナリ、プロプライエタリ GPU API、静的再コンパイルパイプラインを研究するリバースエンジニア、保存研究者、開発者向けであり、ゲームアセットの配布を目的としない。
