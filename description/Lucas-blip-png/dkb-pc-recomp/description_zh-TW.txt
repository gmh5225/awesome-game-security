DKB Recomp 將《大金剛 Bananza》（Nintendo Switch 2 ARM64）靜態重編譯為基於 Vulkan 渲染器的原生 Windows x86-64 可執行檔。recomp/ 中的 Python 提升器將傾印的主模組與 SDK 模組轉譯為產生的 C 程式碼，再由 Clang 編譯；C/C++ 執行階段則模擬 Switch 服務、實作 NVN 2 圖形前端，並透過 Eglantine 將 Ampere 著色器降級為 Maxwell。專案在 TotK Recomp 與 LAS Recomp 模式之上擴充了版本特定的二進位修補、跳轉表處理，以及以 Unicorn 為後端的差分測試，以對照原始 ARM64 行為驗證提升結果。面向逆向工程師、保存研究者，以及研究 Switch 2 二進位、專有 GPU API 與靜態重編譯流水線的開發者，而非用於散佈遊戲資產。
