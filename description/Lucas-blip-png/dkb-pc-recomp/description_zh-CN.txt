DKB Recomp 将《大金刚 Bananza》（Nintendo Switch 2 ARM64）静态重编译为基于 Vulkan 渲染器的原生 Windows x86-64 可执行文件。recomp/ 中的 Python 提升器将转储的主模块与 SDK 模块翻译为生成的 C 代码，再由 Clang 编译；C/C++ 运行时则模拟 Switch 服务、实现 NVN 2 图形前端，并通过 Eglantine 将 Ampere 着色器降级为 Maxwell。项目在 TotK Recomp 与 LAS Recomp 模式之上扩展了版本特定的二进制补丁、跳转表处理，以及基于 Unicorn 的差分测试，以对照原始 ARM64 行为验证提升结果。面向逆向工程师、游戏保存研究者，以及研究 Switch 2 二进制、专有 GPU API 与静态重编译流水线的开发者，而非用于分发游戏资产。
