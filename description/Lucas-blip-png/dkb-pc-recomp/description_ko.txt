DKB Recomp는 Donkey Kong Bananza(Nintendo Switch 2 ARM64)를 정적 재컴파일하여 Vulkan 기반 렌더러를 갖춘 네이티브 Windows x86-64 실행 파일로 만든다. recomp/의 Python 리프터가 덤프된 main 및 SDK 모듈을 생성된 C로 변환하고 Clang이 컴파일하며, C/C++ 런타임은 Switch 서비스를 에뮬레이션하고 NVN 2 그래픽스 프런트엔드를 구현하며 Eglantine을 통해 Ampere 셰이더를 Maxwell로 로워링한다. TotK Recomp와 LAS Recomp 패턴을 확장하여 버전별 바이너리 패치, 점프 테이블 처리, Unicorn 기반 차분 테스트로 리프팅을 원본 ARM64 동작과 대조 검증한다. Switch 2 바이너리, 독점 GPU API, 정적 재컴파일 파이프라인을 연구하는 리버스 엔지니어, 보존 연구자, 개발자를 대상으로 하며 게임 에셋 배포용이 아니다.
