Firebreak is a Python command-line tool that unlocks and reflashes the Amazon Echo Dot (2nd Generation, codename biscuit) over USB from macOS, Linux, or Windows. It automates transitions between stock Fire OS builds and several amonet-based rooted targets with custom bootloaders and TWRP recovery, using fastboot, adb, MediaTek bootrom USB download, and partition writes under recovery or bootrom. The codebase implements plugin-driven unlock plans, GPT and boot image handling, OTA-aware layouts, and optional hardware recovery via eMMC shorting when the device shows no boot indication. It includes diagnostic modes for support reporting and eMMC versus cable failure isolation, plus a simulator for exercising flows without physical hardware. It is aimed at researchers and enthusiasts working on embedded device security, bootloader trust, and practical unlock or restore workflows on MediaTek-based smart speakers.
