Firebreak は Python 製のコマンドラインツールで、macOS、Linux、Windows から USB 経由で Amazon Echo Dot（第2世代、コードネーム biscuit）のロック解除と再フラッシュを行います。純正 Fire OS と、カスタムブートローダーおよび TWRP リカバリを備えた複数の amonet ベースの root 化ターゲット間の切り替えを自動化し、fastboot、adb、MediaTek bootrom の USB ダウンロード、recovery または bootrom 下でのパーティション書き込みを利用します。コードベースはプラグイン駆動の unlock プラン、GPT および boot イメージ処理、OTA 対応レイアウト、起動兆候のない端末向けの eMMC ショートによる任意のハードウェア復旧を実装しています。サポート報告用および eMMC とケーブル障害の切り分け用の診断モード、実機なしでフローを試せるシミュレータも含みます。組み込みデバイスセキュリティ、ブートローダーの信頼、MediaTek ベースのスマートスピーカーにおける実用的な unlock またはリストアワークフローに取り組む研究者と愛好家向けです。
