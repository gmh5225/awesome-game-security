Firebreak 是一款 Python 命令列工具，可透過 USB 在 macOS、Linux 或 Windows 上解鎖並重刷 Amazon Echo Dot（第二代，代號 biscuit）。它可在原廠 Fire OS 與多種基於 amonet 的已 root 目標（含自訂開機載入程式與 TWRP 恢復環境）之間自動切換，並借助 fastboot、adb、MediaTek bootrom USB 下載，以及在 recovery 或 bootrom 下的分割區寫入完成操作。程式碼庫採用外掛驅動的解鎖方案，支援 GPT 與 boot 映像處理、OTA 感知配置，以及在裝置無任何開機跡象時透過 eMMC 短接進行可選硬體恢復。此外還提供用於支援回報與區分 eMMC 與線纜故障的診斷模式，以及無需實體硬體即可演練流程的模擬器。面向從事嵌入式裝置安全、開機載入程式信任鏈，以及在 MediaTek 智慧音箱上實踐解鎖或恢復流程的研究者與愛好者。
