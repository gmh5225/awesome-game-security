Firebreak 是一款 Python 命令行工具，可通过 USB 在 macOS、Linux 或 Windows 上解锁并重刷 Amazon Echo Dot（第二代，代号 biscuit）。它可在原厂 Fire OS 与多种基于 amonet 的已 root 目标（含自定义引导加载程序与 TWRP 恢复环境）之间自动切换，并借助 fastboot、adb、MediaTek bootrom USB 下载，以及在 recovery 或 bootrom 下的分区写入完成操作。代码库采用插件驱动的解锁方案，支持 GPT 与 boot 镜像处理、OTA 感知布局，以及在设备无任何启动迹象时通过 eMMC 短接进行可选硬件恢复。此外还提供用于支持报告与区分 eMMC 与线缆故障的诊断模式，以及无需实体硬件即可演练流程的模拟器。面向从事嵌入式设备安全、引导加载程序信任链，以及在 MediaTek 智能音箱上实践解锁或恢复流程的研究者与爱好者。
