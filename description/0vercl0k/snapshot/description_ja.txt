Snapshot は Rust で書かれた WinDbg 拡張機能で、実行中の仮想マシンの完全なスナップショットを取得し、オフライン分析やファジングに利用できます。CPU 状態（汎用レジスタ、セグメント記述子、MSR、FPU スタックエントリ、SSE レジスタ）を JSON ファイルにシリアライズし、物理メモリのクラッシュダンプも併せて書き出します。拡張機能はフルカーネルおよびアクティブカーネルのダンプモードに対応し、dbgeng crate 経由で Windows DbgEng API を用いて構築され、ライブ x64 カーネルデバッグセッションに読み込む cdylib を生成します。主にスナップショットベースのファジングワークフロー（wtf などのツールとの連携を想定）向けに設計されており、Rust で WinDbg 拡張を実装する際の参考にもなります。セキュリティ研究者やリバースエンジニアが、Windows ターゲット上でのカーネルおよびユーザーモードの脆弱性調査のために VM の実行状態を凍結するのに使われます。
