Snapshot — расширение WinDbg, написанное на Rust, которое создаёт полный снимок работающей виртуальной машины для офлайн-анализа и фаззинга. Оно сериализует состояние CPU — включая регистры общего назначения, дескрипторы сегментов, MSR, записи стека FPU и регистры SSE — в JSON-файл и параллельно записывает crash dump физической памяти. Расширение поддерживает режимы дампа полного ядра и активного ядра и построено на Windows DbgEng API через crate dbgeng, создавая cdylib для загрузки в живые сессии отладки ядра x64. Оно предназначено в первую очередь для workflow фаззинга на основе снимков, особенно с инструментами вроде wtf, и служит справочником по реализации расширений WinDbg на Rust. Исследователи безопасности и reverse engineers используют его, чтобы «заморозить» состояние выполнения VM при исследовании уязвимостей ядра и пользовательского режима на целях Windows.
