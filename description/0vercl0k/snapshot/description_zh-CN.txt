Snapshot 是一款用 Rust 编写的 WinDbg 扩展，可捕获运行中虚拟机的完整快照，用于离线分析与模糊测试。它将 CPU 状态（包括通用寄存器、段描述符、MSR、FPU 栈项和 SSE 寄存器）序列化为 JSON 文件，并同时写入物理内存崩溃转储。该扩展支持完整内核与活动内核转储模式，通过 dbgeng crate 基于 Windows DbgEng API 构建，生成可加载到实时 x64 内核调试会话中的 cdylib。它主要面向基于快照的模糊测试工作流（尤其与 wtf 等工具配合），也可作为用 Rust 实现 WinDbg 扩展的参考。安全研究人员与逆向工程师用它冻结虚拟机执行状态，在 Windows 目标上进行内核与用户态漏洞研究。
