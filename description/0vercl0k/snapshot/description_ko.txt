Snapshot은 Rust로 작성된 WinDbg 확장으로, 실행 중인 가상 머신의 전체 스냅샷을 캡처해 오프라인 분석 및 퍼징에 사용합니다. 범용 레지스터, 세그먼트 디스크립터, MSR, FPU 스택 항목, SSE 레지스터를 포함한 CPU 상태를 JSON 파일로 직렬화하고, 물리 메모리 크래시 덤프도 함께 기록합니다. 이 확장은 전체 커널 및 활성 커널 덤프 모드를 지원하며, dbgeng crate를 통해 Windows DbgEng API로 구축되어 라이브 x64 커널 디버깅 세션에 로드되는 cdylib를 생성합니다. 주로 스냅샷 기반 퍼징 워크플로(특히 wtf 같은 도구와 함께)를 위해 설계되었으며, Rust로 WinDbg 확장을 구현하는 참고 자료로도 활용됩니다. 보안 연구자와 리버스 엔지니어가 Windows 대상에서 커널 및 사용자 모드 취약점 연구를 위해 VM 실행 상태를 고정하는 데 사용합니다.
