Snapshot è un'estensione WinDbg scritta in Rust che cattura uno snapshot completo di una macchina virtuale in esecuzione per analisi offline e fuzzing. Serializza lo stato della CPU — inclusi registri a uso generale, descrittori di segmento, MSR, voci dello stack FPU e registri SSE — in un file JSON e scrive accanto un crash dump della memoria fisica. L'estensione supporta modalità di dump full-kernel e active-kernel ed è costruita con l'API Windows DbgEng tramite il crate dbgeng, producendo una cdylib caricata nelle sessioni di debug del kernel x64 live. È pensata principalmente per workflow di fuzzing basati su snapshot, soprattutto con strumenti come wtf, e funge da riferimento per implementare estensioni WinDbg in Rust. Ricercatori di sicurezza e reverse engineer la usano per congelare lo stato di esecuzione della VM nella ricerca di vulnerabilità kernel e user-mode su target Windows.
