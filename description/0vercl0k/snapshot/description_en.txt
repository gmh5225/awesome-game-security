Snapshot is a WinDbg extension written in Rust that captures a complete snapshot of a running virtual machine for offline analysis and fuzzing. It serializes CPU state—including general-purpose registers, segment descriptors, MSRs, FPU stack entries, and SSE registers—into a JSON file, and writes a physical memory crash dump alongside it. The extension supports full-kernel and active-kernel dump modes and is built with the Windows DbgEng API via the dbgeng crate, producing a cdylib loaded into live x64 kernel debugging sessions. It is designed primarily for snapshot-based fuzzing workflows, especially with tools like wtf, and serves as a reference for implementing WinDbg extensions in Rust. Security researchers and reverse engineers use it to freeze VM execution state for kernel and user-mode vulnerability research on Windows targets.
