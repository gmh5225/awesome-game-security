Snapshot 是一款以 Rust 撰寫的 WinDbg 擴充功能，可擷取執行中虛擬機的完整快照，供離線分析與模糊測試使用。它會將 CPU 狀態（包含通用暫存器、段描述符、MSR、FPU 堆疊項目與 SSE 暫存器）序列化為 JSON 檔案，並同時寫入實體記憶體當機傾印。此擴充功能支援完整核心與作用中核心傾印模式，透過 dbgeng crate 以 Windows DbgEng API 建置，產生可載入即時 x64 核心除錯工作階段的 cdylib。它主要面向以快照為基礎的模糊測試工作流程（尤其與 wtf 等工具搭配），也可作為以 Rust 實作 WinDbg 擴充功能的參考。安全研究人員與逆向工程師用它凍結虛擬機執行狀態，在 Windows 目標上進行核心與使用者模式漏洞研究。
