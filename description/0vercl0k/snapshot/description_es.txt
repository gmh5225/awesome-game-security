Snapshot es una extensión de WinDbg escrita en Rust que captura una instantánea completa de una máquina virtual en ejecución para análisis offline y fuzzing. Serializa el estado de la CPU —incluidos registros de propósito general, descriptores de segmento, MSR, entradas de la pila FPU y registros SSE— en un archivo JSON, y escribe junto a él un volcado de memoria física tipo crash dump. La extensión admite modos de volcado de kernel completo y kernel activo, y está construida con la API Windows DbgEng mediante el crate dbgeng, produciendo una cdylib que se carga en sesiones de depuración de kernel x64 en vivo. Está diseñada principalmente para flujos de trabajo de fuzzing basados en instantáneas, especialmente con herramientas como wtf, y sirve como referencia para implementar extensiones de WinDbg en Rust. Investigadores de seguridad e ingenieros inversos la usan para congelar el estado de ejecución de la VM en investigación de vulnerabilidades en kernel y modo usuario sobre objetivos Windows.
