kdmp-parser — это библиотека на Rust без внешних зависимостей для разбора аварийных дампов ядра Windows, создаваемых операционной системой и WinDbg. Она обеспечивает кросс-платформенный доступ только для чтения к содержимому дампа, включая страницы физической памяти, контекст регистров CPU и исключений, а также списки загруженных пользовательских и модулей ядра. Виртуальные адреса разрешаются обходом таблиц страниц через выделенные средства чтения физической и виртуальной памяти, с опциональной строгой отчётностью об ошибках, когда страницы не были захвачены в дампе. В комплекте пример CLI может выгружать заголовки, записи контекста, модули и память с использованием отображения в память или файлового ввода-вывода. Crate подходит для отладки ядра, криминалистики сбоев и reverse engineering, когда нужно исследовать файлы дампов вне стека отладчиков Windows.
