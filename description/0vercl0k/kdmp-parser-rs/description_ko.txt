kdmp-parser는 운영 체제와 WinDbg가 생성한 Windows 커널 크래시 덤프를 파싱하는 의존성 없는 Rust 라이브러리입니다. 물리 메모리 페이지, CPU 레지스터 및 예외 컨텍스트, 로드된 사용자 및 커널 모듈 목록을 포함해 덤프 내용에 대한 크로스 플랫폼 읽기 전용 접근을 제공합니다. 전용 물리 및 가상 메모리 리더로 페이지 테이블을 순회해 가상 주소를 해석하며, 덤프에 캡처되지 않은 페이지에 대해 선택적으로 엄격한 오류 보고를 할 수 있습니다. 포함된 예제 CLI는 메모리 매핑 또는 파일 기반 I/O로 헤더, 컨텍스트 레코드, 모듈 및 메모리를 덤프할 수 있습니다. Windows 디버거 스택 밖에서 덤프 파일을 검사해야 하는 커널 디버깅, 크래시 포렌식 및 리버스 엔지니어링 워크플로에 적합한 crate입니다.
