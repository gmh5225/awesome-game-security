kdmp-parser es una biblioteca Rust sin dependencias para analizar volcados de bloqueo del kernel de Windows generados por el sistema operativo y WinDbg. Ofrece acceso multiplataforma de solo lectura al contenido del volcado, incluidas páginas de memoria física, contexto de registros de CPU y excepciones, y listas de módulos de usuario y kernel cargados. Las direcciones virtuales se resuelven recorriendo tablas de páginas mediante lectores de memoria física y virtual dedicados, con informe opcional de errores estricto cuando las páginas no se capturaron en el volcado. Un CLI de ejemplo incluido puede volcar encabezados, registros de contexto, módulos y memoria mediante E/S mapeada en memoria o basada en archivos. La crate es adecuada para depuración de kernel, análisis forense de bloqueos e ingeniería inversa que necesiten inspeccionar archivos de volcado fuera del stack de depuradores de Windows.
