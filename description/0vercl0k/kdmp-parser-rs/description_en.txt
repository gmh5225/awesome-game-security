kdmp-parser is a dependency-free Rust library for parsing Windows kernel crash dumps produced by the operating system and WinDbg. It offers cross-platform read-only access to dump contents, including physical memory pages, CPU register and exception context, and loaded user and kernel module lists. Virtual addresses are resolved by walking page tables through dedicated physical and virtual memory readers, with optional strict error reporting when pages were not captured in the dump. A bundled example CLI can dump headers, context records, modules, and memory using memory-mapped or file-based I/O. The crate suits kernel debugging, crash forensics, and reverse engineering workflows that need to inspect dump files outside the Windows debugger stack.
