kdmp-parser è una libreria Rust priva di dipendenze per analizzare i crash dump del kernel Windows prodotti dal sistema operativo e da WinDbg. Offre accesso multipiattaforma in sola lettura al contenuto del dump, incluse pagine di memoria fisica, contesto di registri CPU ed eccezioni, ed elenchi di moduli utente e kernel caricati. Gli indirizzi virtuali vengono risolti percorrendo le tabelle delle pagine tramite lettori di memoria fisica e virtuale dedicati, con segnalazione opzionale rigorosa degli errori quando le pagine non sono state catturate nel dump. Un CLI di esempio incluso può estrarre header, record di contesto, moduli e memoria usando I/O mappato in memoria o basato su file. La crate è adatta a debug del kernel, forensics dei crash e flussi di reverse engineering che devono ispezionare file dump al di fuori dello stack dei debugger Windows.
