kdmp-parser は、OS と WinDbg が生成する Windows カーネルクラッシュダンプを解析する、依存関係のない Rust ライブラリです。物理メモリページ、CPU レジスタと例外コンテキスト、読み込まれたユーザー／カーネルモジュール一覧など、ダンプ内容へのクロスプラットフォームな読み取り専用アクセスを提供します。専用の物理・仮想メモリリーダーでページテーブルを辿り仮想アドレスを解決し、ダンプに含まれなかったページについては厳格なエラー報告を任意で有効にできます。同梱のサンプル CLI は、メモリマップまたはファイルベースの I/O でヘッダー、コンテキストレコード、モジュール、メモリをダンプできます。Windows デバッガースタック外でダンプファイルを調べるカーネルデバッグ、クラッシュフォレンジクス、リバースエンジニアリングのワークフローに適した crate です。
