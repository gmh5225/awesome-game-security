Florida-zygisk 是一個適用於 Magisk、KernelSU 和 APatch 的 root 模組，可在裝置啟動時自動啟動 Florida——一個經過反偵測修補處理的 frida-server 建置版本。它封裝了透過套用 Ylarod 原始碼層級 Frida 修補所建置的各架構 Florida 二進位檔，並附帶補充性的 Python carry-fix 腳本，以確保 RPC 混淆和反反 Frida agent 重新命名功能在 Frida 新版本釋出後仍能正常運作。此模組源自 magisk-frida 範本，包含 shell 服務腳本，可在隨機連接埠上啟動伺服器、在模組中繼資料中暴露執行時狀態，並允許透過 KernelSU Action 按鈕切換伺服器開關。主要使用 Python 進行建置與修補，使用 shell 進行安裝和開機時管理。面向需要在已 root 裝置上取得持久、更難被偵測的 Frida 插樁能力，以進行動態分析並繞過常見反 Frida 與反作弊啟發式偵測的 Android 逆向工程師和遊戲安全研究人員。
