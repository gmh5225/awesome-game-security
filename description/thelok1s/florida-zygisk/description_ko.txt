Florida-zygisk는 Magisk, KernelSU, APatch용 root 모듈로, 기기 부팅 시 탐지 회피 패치가 적용된 frida-server 빌드인 Florida를 자동으로 실행합니다. Ylarod의 소스 수준 Frida 패치를 적용해 빌드한 아키텍처별 Florida 바이너리를 포함하며, Frida 신규 릴리스에서도 RPC 난독화와 anti-anti-Frida 에이전트 이름 변경이 계속 동작하도록 보조 Python carry-fix 스크립트를 제공합니다. 이 모듈은 magisk-frida 템플릿에서 파생되었으며, 무작위 포트에서 서버를 시작하고 모듈 메타데이터에 런타임 상태를 노출하며, KernelSU Action 버튼으로 서버를 켜고 끌 수 있는 shell 서비스 스크립트를 포함합니다. 주요 언어는 빌드 및 패치에 Python, 설치 및 부팅 시 관리에 shell입니다. 루팅된 Android 기기에서 지속적이고 탐지하기 어려운 Frida 계측이 필요한 동적 분석 및 일반적인 anti-Frida·anti-cheat 휴리스틱 우회를 위한 Android 리버스 엔지니어와 게임 보안 연구자를 대상으로 합니다.
