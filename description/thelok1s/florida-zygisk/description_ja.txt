Florida-zygisk は、Magisk、KernelSU、APatch 向けの root モジュールで、デバイス起動時に Florida（反検知パッチを適用した frida-server ビルド）を自動起動します。Ylarod のソースレベル Frida パッチを適用してビルドしたアーキテクチャ別 Florida バイナリを同梱し、Frida の新リリースでも RPC 難読化と anti-anti-Frida エージェントのリネームが動作し続けるよう、補助的な Python carry-fix スクリプトも含まれています。本モジュールは magisk-frida テンプレートをベースにしており、ランダムポートでサーバーを起動し、モジュールメタデータにランタイム状態を公開し、KernelSU Action ボタンでサーバーのオン/オフを切り替えられる shell サービススクリプトも備えています。主な言語は、ビルドとパッチ適用に Python、インストールと起動時管理に shell です。root 済み Android 端末で検出されにくい永続的な Frida 計装を必要とする、動的解析や一般的な anti-Frida・anti-cheat ヒューリスティクスの回避を行う Android リバースエンジニアおよびゲームセキュリティ研究者を対象としています。
