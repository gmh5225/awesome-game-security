Florida-zygisk ist ein Root-Modul für Magisk, KernelSU und APatch, das beim Gerätestart automatisch Florida startet – einen gepatchten, schwerer erkennbaren Build von frida-server. Es enthält architekturspezifische Florida-Binaries, die durch Anwendung von Ylarods Frida-Patches auf Quellcodeebene erstellt wurden, sowie ergänzende Python-carry-fix-Skripte, damit RPC-Obfuskation und das Umbenennen von Anti-Anti-Frida-Agenten auch bei neuen Frida-Versionen funktionieren. Das Modul basiert auf der magisk-frida-Vorlage und umfasst Shell-Service-Skripte, die den Server auf einem zufälligen Port starten, den Laufzeitstatus in Modul-Metadaten bereitstellen und das Ein- und Ausschalten des Servers über eine KernelSU-Action-Schaltfläche ermöglichen. Hauptsprachen sind Python für Build und Patches sowie Shell für Installation und Verwaltung beim Boot. Es richtet sich an Android-Reverse-Engineers und Game-Security-Forscher, die persistente, schwerer zu erkennende Frida-Instrumentierung auf gerooteten Geräten für dynamische Analyse und das Umgehen gängiger Anti-Frida- und Anti-Cheat-Heuristiken benötigen.
