Florida-zygisk — root-модуль для Magisk, KernelSU и APatch, который автоматически запускает Florida, патченную anti-detection-сборку frida-server, при загрузке устройства. Он включает бинарники Florida для разных архитектур, собранные с применением исходных патчей Frida от Ylarod, а также дополнительные Python-скрипты carry-fix, чтобы обфускация RPC и переименование anti-anti-Frida-агентов продолжали работать в новых релизах Frida. Модуль основан на шаблоне magisk-frida и содержит shell-сервисные скрипты, которые запускают сервер на случайном порту, отображают состояние выполнения в метаданных модуля и позволяют включать и отключать сервер через кнопку KernelSU Action. Основные языки — Python для сборки и патчей и shell для установки и управления при загрузке. Предназначен для Android-реверс-инженеров и исследователей игровой безопасности, которым нужна постоянная, более трудно обнаруживаемая Frida-инструментация на рутованных устройствах для динамического анализа и обхода распространённых anti-Frida и anti-cheat-эвристик.
