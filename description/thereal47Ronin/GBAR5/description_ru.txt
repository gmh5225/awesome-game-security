GBAR5 — нативное homebrew-приложение для PlayStation 5, обеспечивающее эмуляцию Game Boy Advance через пользовательский фронтенд на базе стека boilerplate нативных приложений PS5. Ядро эмулятора — реализация mGBA libretro, слинкованная как статический архив вместе с выводом через Vulkan (RADV), опциональной генерацией кадров в стиле AMD FSR и кодовой базой на C и C++ с инструментами Python и shell для сборки, индексации ресурсов и синхронизации библиотеки. Приложение поддерживает управление игровой библиотекой, читы, интеграцию RetroAchievements через rcheevos, сетевую загрузку по SMB и NFS, сценарии самообновления и повышение песочницы на базе Lapy для доступа к пользовательским путям данных в jailbreak-окружениях вроде etaHEN. Ориентировано на исследователей и энтузиастов, занимающихся homebrew на PS5, экосистемами эксплойтов консолей и разработкой низкоуровневых нативных полезных нагрузок, а не на коммерческий античит или безопасность онлайн-игр.
