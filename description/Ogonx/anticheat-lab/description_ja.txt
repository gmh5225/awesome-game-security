Anticheat-lab は、著者自身のビルドと練習用バイナリ上で攻撃と防御を交互に行いながら学ぶ、ゲームアンチチート向けの体系的なハンズオン学習プロジェクトです。x64 アセンブリと C++ のメモリレイアウト、リバースエンジニアリングツール、意図的にチート可能なマルチプレイヤー試作、サーバー権威、統計検知、クライアント側チェックを網羅する六か月のカリキュラムとして構成されています。初期段階では C++ のサンプルプログラム、最適化前後の逆アセンブリ比較のための Compiler Explorer、Visual Studio によるデバッグと Windows x64 呼び出し規約・シャドウスペース・スタックフレームに沿ったスタックとレジスタの追跡を用います。日々の進捗と技術メモは devlog に残し、月ごとの演習と write-up フォルダと併せて公開しています。ライブの商用タイトルを標的にするのではなく、倫理的な VM ベースの低レベルゲームセキュリティの基礎を身につけたい開発者とセキュリティ学習者向けです。
