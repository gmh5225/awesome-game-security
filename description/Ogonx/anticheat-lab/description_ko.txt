Anticheat-lab은 작성자가 직접 만든 빌드와 연습용 바이너리에서 공격과 방어를 번갈아 수행하며 게임 안티치트를 배우는 구조화된 실습형 학습 프로젝트입니다. x64 어셈블리와 C++ 메모리 레이아웃, 리버스 엔지니어링 도구, 의도적으로 치트가 가능한 멀티플레이어 프로토타입, 서버 권한, 통계 기반 탐지, 클라이언트 측 검사를 다루는 6개월 커리큘럼으로 구성되어 있습니다. 초기에는 C++ 샘플 프로그램, 최적화 전후 디스어셈블리를 비교하는 Compiler Explorer, Visual Studio 디버깅과 Windows x64 호출 규약·섀도우 스페이스·스택 프레임에 대한 스택 및 레지스터 추적을 사용합니다. 일일 진행 상황과 기술 노트는 devlog에 남기며, 월별 연습과 write-up 폴더와 함께 제공됩니다. 상용 라이브 타이틀을 겨냥하기보다 VM 기반의 윤리적인 저수준 게임 보안 기초를 원하는 개발자와 보안 학습자를 대상으로 합니다.
