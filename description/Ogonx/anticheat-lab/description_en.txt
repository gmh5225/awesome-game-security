Anticheat-lab is a structured, hands-on learning project for game anti-cheat by alternating attack and defense on the author’s own builds and practice binaries. It is organized as a six-month curriculum covering x64 assembly and C++ memory layout, reverse engineering tools, a deliberately cheatable multiplayer prototype, server authority, statistical detection, and client-side checks. Early work uses C++ sample programs, Compiler Explorer to compare unoptimized and optimized disassembly, and Visual Studio debugging with stack and register tracing on Windows x64 calling conventions, shadow space, and stack frames. Daily progress and technical notes live in a devlog alongside monthly folders of exercises and write-ups. It is aimed at developers and security learners who want ethical, VM-based foundations in low-level game security rather than targeting live commercial titles.
