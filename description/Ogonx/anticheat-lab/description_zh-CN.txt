Anticheat-lab 是一个结构化的游戏反作弊动手学习项目，通过在作者自建的构建与练习二进制上交替进行攻击与防御来实践。它以六个月课程组织，涵盖 x64 汇编与 C++ 内存布局、逆向工程工具、刻意可作弊的多人原型、服务端权威、统计检测以及客户端校验。前期使用 C++ 示例程序、Compiler Explorer 对比未优化与优化后的反汇编，以及在 Visual Studio 中调试并追踪 Windows x64 调用约定、影子空间与栈帧。日常进展与技术笔记记录在 devlog 中，并配有按月划分的练习与 write-up 文件夹。面向希望在虚拟机环境中打下低层游戏安全基础、以合乎伦理的方式学习而非针对线上商业游戏的开发者与安全学习者。
