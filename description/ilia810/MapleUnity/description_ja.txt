MapleUnity は Unity ベースの MapleStory v83 クライアント再実装で、公式 NX ゲームデータを読み込み、現代的なエンジン上でマップ、キャラクター、ゲームプレイシステムを再現します。主に C# で書かれ、reNX と NXWrapper バインディングで NX アセットを解析し、foothold ベースの衝突判定を備えたプレイ可能なマップシーンを生成し、オリジナルの C++ クライアント由来の attachment-point 演算でレイヤー化されたキャラクタースプライトを描画します。プロジェクトには物理、インベントリ、スキル、およびレガシーサーバープロトコルに合致するパケットシリアライゼーションと AES 暗号化を備えたネットワーク層を含むモジュラーなゲームスタックが含まれます。Unity Editor の充実した診断機能により、NX ノード構造、タイルセット、装備レイアウト、レンダリング挙動の探索を支援します。MapleStory クライアントの仕組みとプロトコル挙動について、読みやすくテスト可能な参照が必要なリバースエンジニア、プライベートサーバー開発者、ゲームセキュリティ研究者向けです。
