本プロジェクトは静的解析に基づく Frida スクリプト生成ツールで、Android APK または iOS IPA を検査し、SSL ピンニングおよび root / ジェイルブレイク検出を回避する実行可能なスクリプトを生成します。主に Python で書かれており、既知のセキュリティフレームワークのバイナリシグネチャを走査し、検出したものに対してのみ対象を絞った Frida フックを出力します。OkHttp、TrustKit、Flutter、gRPC など多くの SSL スタックに加え、RootBeer、Play Integrity、商用 SDK などの root / ジェイルブレイク対策をカバーし、Android 12 以降で安定動作する三層インジェクション設計を採用しています。セキュリティテスターやリバースエンジニアは、ターゲットごとにクラスを手作業で探すことなく、モバイルアプリのバイパススクリプト作成を自動化できます。
