本專案是一款以靜態分析驅動的 Frida 腳本產生器，可檢查 Android APK 或 iOS IPA，並產出可用於繞過 SSL 釘選以及 root 或越獄偵測的即用腳本。主要以 Python 撰寫，會掃描二進位特徵以辨識已知安全框架，並僅針對發現的內容產生定向 Frida hook。涵蓋 OkHttp、TrustKit、Flutter、gRPC 等多種 SSL 堆疊，以及 RootBeer、Play Integrity 與商業 SDK 等 root/越獄防護，採三層注入設計，在 Android 12 及更新系統上穩定可用。安全測試人員與逆向工程師可用它自動產生行動應用繞過腳本，無需為每個目標手動尋找類別。
