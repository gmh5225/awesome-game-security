本项目是一款基于静态分析的 Frida 脚本生成器，可检查 Android APK 或 iOS IPA，并生成可用于绕过 SSL 固定以及 root 或越狱检测的即用脚本。主要使用 Python 编写，它会扫描二进制特征以识别已知安全框架，并仅针对发现的内容生成定向 Frida hook。覆盖 OkHttp、TrustKit、Flutter、gRPC 等多种 SSL 栈，以及 RootBeer、Play Integrity 和商业 SDK 等 root/越狱防护，采用三层注入设计，在 Android 12 及更新系统上稳定可用。安全测试人员与逆向工程师可用它自动生成移动应用绕过脚本，无需为每个目标手动查找类。
