OpenGL32 Enhancer es un proxy opengl32.dll listo para usar que añade postprocesado GPU al estilo ReShade a juegos OpenGL de 32 bits en Windows, sin modificar el código fuente del juego ni usar un inyector. Escrito en C++ con CMake y compute shaders de OpenGL 4.3, reenvía cada llamada a la biblioteca OpenGL real del sistema mientras intercepta wglSwapBuffers para ejecutar una cadena configurable de efectos antes de presentar cada fotograma. Las etapas compatibles incluyen escalado AMD FSR, antialiasing SMAA y TAA, nitidez CAS, bloom, mapeo tonal ACES, gradación de color LUT, SSAO, profundidad de campo y muchos otros filtros, controlados mediante opengl32_enhancer.ini o un editor de configuración ImGui incluido. Está dirigido a jugadores y modders que desean modernizar títulos OpenGL heredados, y demuestra técnicas de hooking por proxy DLL útiles para interceptación gráfica, ingeniería inversa e investigación en mejora de juegos.
