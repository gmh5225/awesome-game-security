OpenGL32 Enhancer is a drop-in opengl32.dll proxy that adds ReShade-style GPU post-processing to 32-bit OpenGL games on Windows without modifying game source code or using an injector. Written in C++ with CMake and OpenGL 4.3 compute shaders, it forwards every call to the real system OpenGL library while hooking wglSwapBuffers to run a configurable chain of effects before each frame is presented. Supported stages include AMD FSR upscaling, SMAA and TAA anti-aliasing, CAS sharpening, bloom, ACES tone mapping, LUT color grading, SSAO, depth of field, and many other filters controlled through opengl32_enhancer.ini or an included ImGui config editor. It is aimed at players and modders who want to modernize legacy OpenGL titles, and it demonstrates DLL proxy hooking techniques useful for graphics interception, reverse engineering, and game enhancement research.
