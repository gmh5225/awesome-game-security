OpenGL32 Enhancer — это готовый к использованию прокси opengl32.dll, который добавляет GPU-постобработку в стиле ReShade в 32-битные OpenGL-игры под Windows без изменения исходного кода игры и без использования инжектора. Написан на C++ с CMake и compute shaders OpenGL 4.3; он перенаправляет каждый вызов в настоящую системную библиотеку OpenGL, перехватывая wglSwapBuffers для запуска настраиваемой цепочки эффектов перед выводом каждого кадра. Поддерживаемые этапы включают масштабирование AMD FSR, сглаживание SMAA и TAA, повышение резкости CAS, bloom, тональное отображение ACES, цветокоррекцию LUT, SSAO, глубину резкости и множество других фильтров, управляемых через opengl32_enhancer.ini или встроенный редактор конфигурации ImGui. Проект ориентирован на игроков и моддеров, желающих модернизировать устаревшие OpenGL-игры, и демонстрирует техники хукинга через DLL-прокси, полезные для перехвата графики, реверс-инжиниринга и исследований в области улучшения игр.
