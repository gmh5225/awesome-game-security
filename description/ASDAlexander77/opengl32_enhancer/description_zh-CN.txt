OpenGL32 Enhancer 是一个即插即用的 opengl32.dll 代理，可在 Windows 上为 32 位 OpenGL 游戏添加 ReShade 风格的 GPU 后处理，无需修改游戏源代码或使用注入器。该项目使用 C++、CMake 和 OpenGL 4.3 计算着色器编写，将所有调用转发至真实的系统 OpenGL 库，同时挂钩 wglSwapBuffers，在每一帧呈现前运行可配置的效果链。支持的阶段包括 AMD FSR 升采样、SMAA 与 TAA 抗锯齿、CAS 锐化、泛光、ACES 色调映射、LUT 调色、SSAO、景深以及许多其他滤镜，可通过 opengl32_enhancer.ini 或内置的 ImGui 配置编辑器进行控制。它面向希望现代化旧版 OpenGL 游戏的玩家和模组作者，并展示了适用于图形拦截、逆向工程和游戏增强研究的 DLL 代理挂钩技术。
