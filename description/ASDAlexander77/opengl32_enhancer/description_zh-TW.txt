OpenGL32 Enhancer 是一個即插即用的 opengl32.dll 代理，可在 Windows 上為 32 位元 OpenGL 遊戲加入 ReShade 風格的 GPU 後製處理，無需修改遊戲原始碼或使用注入器。此專案以 C++、CMake 與 OpenGL 4.3 計算著色器撰寫，將所有呼叫轉送至真實的系統 OpenGL 函式庫，同時掛鉤 wglSwapBuffers，在每一幀呈現前執行可設定的效果鏈。支援的階段包括 AMD FSR 升採樣、SMAA 與 TAA 反鋸齒、CAS 銳化、泛光、ACES 色調映射、LUT 調色、SSAO、景深以及許多其他濾鏡，可透過 opengl32_enhancer.ini 或內建的 ImGui 設定編輯器控制。它面向希望現代化舊版 OpenGL 遊戲的玩家與模組作者，並展示了適用於圖形攔截、逆向工程與遊戲增強研究的 DLL 代理掛鉤技術。
