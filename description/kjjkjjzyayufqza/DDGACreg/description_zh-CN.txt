DDGACreg 是针对本地 TG4AC 5.80.02 列车街机版 Windows x64 的非官方 Hook，以 version.dll 代理形式与游戏可执行文件同目录加载。项目主要用 C++ 与 CMake 构建，采用 MinHook 做 API 挂钩、MASM thunk 转发 DLL 导出，并用 HLSL 合成着色器支持超宽屏、16:9 或单屏多面板机台显示。功能模块涵盖投币输入、键盘 NESiCA 刷卡、进程内 NESYS 管道处理、自由相机、隐藏 HUD、电影级画质覆盖、全线线路流式加载以及提高加载预算；另有基于 C++ 与 SQLite 的本地 localhost 内容服务器，通过环回 HTTP 提供卡片、任务与排行榜类内容。适合研究街机 PC 移植、DLL 代理、游戏 Hook 链以及机台在线服务如何离线仿真的研究者与爱好者。
