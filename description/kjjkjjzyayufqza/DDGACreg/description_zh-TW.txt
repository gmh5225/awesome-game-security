DDGACreg 是針對本機 TG4AC 5.80.02 列車街機版 Windows x64 的非官方 Hook，以 version.dll 代理形式與遊戲可執行檔同目錄載入。專案主要以 C++ 與 CMake 建置，使用 MinHook 進行 API 掛鉤、MASM thunk 轉送 DLL 匯出，並以 HLSL 合成著色器支援超寬螢幕、16:9 或單螢幕多面板機台顯示。功能模組涵蓋投幣輸入、鍵盤 NESiCA 刷卡、程序內 NESYS 管線處理、自由相機、隱藏 HUD、電影級畫質覆寫、全線路線串流載入以及提高載入預算；另有以 C++ 與 SQLite 建置的本地 localhost 內容伺服器，透過環回 HTTP 提供卡片、任務與排行榜類內容。適合研究街機 PC 移植、DLL 代理、遊戲 Hook 鏈以及機台線上服務如何離線仿真的研究者與愛好者。
