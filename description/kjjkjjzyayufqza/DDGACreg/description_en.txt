DDGACreg is an unofficial Windows x64 hook for a local copy of the TG4AC 5.80.02 train arcade title, delivered as a version.dll proxy loaded beside the game executable. It is built primarily in C++ with CMake, uses MinHook for API hooking, MASM thunks for DLL forwarding, and HLSL compositor shaders for multi-panel cabinet display on ultrawide, 16:9, or single-screen layouts. Feature modules cover coin input, keyboard NESiCA card taps, in-process NESYS pipe handling, free camera, HUD hiding, cinematic quality overrides, full-line route streaming, and raised load budgets, while a companion localhost content server in C++ with SQLite backs cards, missions, and leaderboard-style content over loopback HTTP. The project suits researchers and hobbyists studying arcade PC ports, DLL proxying, game hook chains, and how cabinet online services are emulated offline for home play.
