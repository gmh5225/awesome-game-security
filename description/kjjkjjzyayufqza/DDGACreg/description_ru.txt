DDGACreg — неофициальный хук Windows x64 для локальной копии аркадного железнодорожного тайтла TG4AC 5.80.02, поставляемый как прокси version.dll, загружаемый рядом с исполняемым файлом игры. Собран в основном на C++ с CMake, использует MinHook для перехвата API, MASM-thunk для форвардинга DLL и HLSL-комpositor-шейдеры для многопанельного кабинетного дисплея на ultrawide, 16:9 или одном экране. Модули охватывают ввод монет, нажатия карты NESiCA с клавиатуры, обработку NESYS pipe в процессе, свободную камеру, скрытие HUD, cinematic-переопределения качества, потоковую подгрузку полной линии и повышенные бюджеты загрузки; сопутствующий localhost-сервер контента на C++ с SQLite обеспечивает карты, миссии и контент в духе таблицы лидеров по loopback HTTP. Проект подходит исследователям и энтузиастам, изучающим PC-порты аркад, DLL-проксирование, цепочки игровых хуков и офлайн-эмуляцию онлайн-сервисов кабинета для домашней игры.
