DDGACreg は、ローカルに置いた TG4AC 5.80.02 鉄道系アーケードタイトル向けの非公式 Windows x64 フックで、ゲーム実行ファイル横に配置する version.dll プロキシとして配布される。主に C++ と CMake で構築し、API フックに MinHook、DLL 転送に MASM thunk、ウルトラワイド・16:9・単一画面レイアウト向けの多パネル筐体表示に HLSL コンポジットシェーダーを用いる。機能モジュールはコイン入力、キーボードによる NESiCA カードタップ、プロセス内 NESYS パイプ処理、フリーカメラ、HUD 非表示、シネマティック画質オーバーライド、全線ルートのストリーミング、読み込み予算の引き上げをカバーする。C++ と SQLite の localhost コンテンツサーバーがループバック HTTP でカード、ミッション、リーダーボード系コンテンツを支え、筐体オンラインサービスのオフラインエミュレーションや DLL プロキシ、ゲームフックチェーンを調べる研究者・ホビイスト向けのプロジェクトである。
