This project is a native recompilation port that runs The Legend of Zelda: The Wind Waker HD from player-supplied Wii U game files on modern hardware rather than full-system emulation. The codebase is built mainly in C++ with CMake, backed by Python pipelines that decompile the original PowerPC binaries, recompile them into a native runtime, extract and verify assets, and benchmark builds on real consoles. Graphics work centers on translating Wii U Latte shaders to Vulkan or deko3D, with tooling for shader manifests, optional profile-guided optimization, and a TCP debug server on Nintendo Switch for live logs, warps, and deployment during development. It also ships Android and Meta Quest clients, SDL-based input, mod SDK and world-editor workflows, and desktop installers in C#. The stack is aimed at reverse engineers and game-security researchers who want to study large-scale commercial decompilation, encrypted disc archives, GPU shader recovery, and runtime introspection on closed platforms.
