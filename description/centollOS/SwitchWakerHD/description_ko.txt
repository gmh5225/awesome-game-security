이 프로젝트는 전체 시스템 에뮬레이션이 아니라, 플레이어가 제공한 Wii U 게임 파일로 『젤다의 전설: 바람의 택트 HD』를 현대 하드웨어에서 실행하는 네이티브 재컴파일 포트이다. 코드베이스는 주로 C++와 CMake로 구축되며, Python 파이프라인이 원본 PowerPC 바이너리를 디컴파일해 네이티브 런타임으로 재컴파일하고, 에셋을 추출·검증하며, 실제 콘솔에서 빌드를 벤치마킹한다. 그래픽 작업은 Wii U Latte 셰이더를 Vulkan 또는 deko3D로 변환하는 데 중점을 두며, 셰이더 매니페스트, 선택적 프로파일 유도 최적화, 개발 중 라이브 로그·워프·배포를 위한 Nintendo Switch용 TCP 디버그 서버 등의 도구를 제공한다. Android 및 Meta Quest 클라이언트, SDL 기반 입력, Mod SDK와 월드 에디터 워크플로, C# 데스크톱 설치 프로그램도 포함한다. 이 스택은 대규모 상용 디컴파일, 암호화 디스크 아카이브, GPU 셰이더 복구, 폐쇄형 플랫폼에서의 런타임 인트로스펙션을 연구하려는 리버스 엔지니어와 게임 보안 연구자를 대상으로 한다.
