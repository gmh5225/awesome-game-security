This project reverse engineers the classic 1988 Amiga shoot-em-up Menace and builds a native modern x86 port. It combines annotated Motorola 68000 disassembly, ADF disk analysis, and Python utilities to extract planar graphics, sprites, audio samples, and related assets from the original binary. The playable reimplementation is written in C++ with CMake, SDL2, and SDL2_mixer for rendering, input, and sound on current desktop platforms. Documentation covers bootblock and game-code analysis, hardware register behavior, and integrating recovered assets into the port. It is aimed at retro-game researchers, preservationists, and reverse engineers studying Amiga-era game formats and interoperability rather than commercial anti-cheat or live game security.
