이 프로젝트는 1988년 클래식 Amiga 슈팅 게임 Menace를 리버스 엔지니어링하고 네이티브 현대 x86 포트를 만든다. 주석이 달린 Motorola 68000 디스어셈블리, ADF 디스크 분석, Python 유틸리티를 결합해 원본 바이너리에서 planar 그래픽, 스프라이트, 오디오 샘플 및 관련 에셋을 추출한다. 플레이 가능한 재구현은 C++와 CMake, SDL2, SDL2_mixer로 현재 데스크톱 플랫폼에서 렌더링, 입력, 사운드를 처리한다. 문서는 부트블록과 게임 코드 분석, 하드웨어 레지스터 동작, 복구한 에셋을 포트에 통합하는 방법을 다룬다. 레트로 게임 연구자, 보존 활동가, Amiga 시대 게임 포맷과 상호운용성을 연구하는 리버스 엔지니어를 대상으로 하며, 상용 안티치트나 라이브 게임 보안용이 아니다.
