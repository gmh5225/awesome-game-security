本專案記錄並實作一條本機權限提升鏈：在小米 Mi Box 3S 上，利用 Amlogic Mali-400 Utgard GPU 驅動程式中未驗證的外部記憶體綁定缺陷，將無特權的 adb shell 提升至完整 root，並使 SELinux 處於 permissive 模式。漏洞透過 GPU 取得任意實體記憶體寫入能力，修補 sys_call_table 中未使用的槽位以將系統呼叫重新導向至攻擊者可控或已解析的核心輔助常式，隨後關閉 SELinux 強制模式並觸發 coredump 處理常式以 root 權限執行輔助腳本，核心改動面小，且不依賴 ROP、堆噴灑或獨立 CVE。程式碼主要以 C 撰寫，含 aarch64 與 armv7 交叉編譯工具、Shell 自動化，以及關於快取一致性、ion 變通方案與鎖定韌體上核心符號探索的詳細說明。面向研究 Android 核心利用、在舊款 Amlogic 機上盒上以 GPU 輔助的 LPE，以及 Mali Utgard 驅動弱點的安全研究人員與逆向工程師。
