本プロジェクトは、Xiaomi Mi Box 3S 上で権限のない adb shell を、Amlogic Mali-400 Utgard GPU ドライバの検証されていない外部メモリバインドを悪用して SELinux を permissive にした完全な root へと持ち上げるローカル権限昇格チェーンを文書化し実装する。エクスプロイトは GPU 経由で任意の物理メモリ書き込みを得、未使用の sys_call_table スロットをパッチしてシステムコールを攻撃者制御または解決済みカーネルヘルパへリダイレクトし、SELinux の強制を無効化して coredump ハンドラから root ヘルパースクリプトを最小のカーネルフットプリントで実行する。ROP、ヒープスプレー、別 CVE には依存しない。主に C で書かれ、aarch64 および armv7 向けクロスコンパイルユーティリティ、シェル自動化、キャッシュコヒーレンシ、ion の回避策、ロックダウン済みファームウェア上のカーネルシンボル探索に関する詳細メモを含む。Android カーネル悪用、レガシー Amlogic セットトップボックス上の GPU 支援 LPE、Mali Utgard ドライバの弱点を調べるセキュリティ研究者とリバースエンジニア向けである。
