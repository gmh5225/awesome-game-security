이 프로젝트는 Xiaomi Mi Box 3S에서 권한 없는 adb shell을 Amlogic Mali-400 Utgard GPU 드라이버의 검증되지 않은 외부 메모리 바인딩을 악용하여 SELinux를 permissive로 둔 채 완전한 root로 올리는 로컬 권한 상승 체인을 문서화하고 구현한다. 익스플로잇은 GPU를 통해 임의의 물리 메모리 쓰기를 얻고, 사용하지 않는 sys_call_table 슬롯을 패치해 시스템 호출을 공격자 제어 또는 해석된 커널 헬퍼로 리다이렉트한 뒤 SELinux 강제를 끄고 coredump 핸들러로 최소한의 커널 흔적으로 root 헬퍼 스크립트를 실행한다. ROP, 힙 스프레이, 별도 CVE에 의존하지 않는다. 주로 C로 작성되었으며 aarch64 및 armv7 교차 컴파일 유틸리티, 셸 자동화, 캐시 일관성, ion 우회, 잠긴 펌웨어에서의 커널 심볼 탐색에 대한 상세 메모를 포함한다. Android 커널 익스플로잇, 레거시 Amlogic 셋톱에서 GPU 보조 LPE, Mali Utgard 드라이버 취약점을 연구하는 보안 연구자와 리버스 엔지니어를 대상으로 한다.
