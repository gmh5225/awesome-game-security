This project documents and implements a local privilege escalation chain that elevates an unprivileged adb shell on the Xiaomi Mi Box 3S to full root with SELinux permissive, by abusing the Amlogic Mali-400 Utgard GPU driver’s unvalidated external memory binding. The exploit obtains arbitrary physical memory writes through the GPU, patches unused sys_call_table slots to redirect syscalls into attacker-controlled or resolved kernel helpers, then disables SELinux enforcement and triggers a coredump handler to run a root helper script with a minimal kernel footprint and without relying on ROP, heap spray, or a separate CVE. It is written primarily in C with aarch64 and armv7 cross-compiled utilities, shell automation, and detailed notes on cache coherency, ion workarounds, and kernel symbol discovery on locked-down firmware. Security researchers and reverse engineers studying Android kernel exploitation, GPU-assisted LPE on legacy Amlogic set-top boxes, and Mali Utgard driver weaknesses are the intended audience.
