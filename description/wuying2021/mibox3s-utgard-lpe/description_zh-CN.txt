本项目记录并实现了一条本地提权链：在小米 Mi Box 3S 上，利用 Amlogic Mali-400 Utgard GPU 驱动中未校验的外部内存绑定缺陷，将无特权的 adb shell 提升至完全 root，并使 SELinux 处于 permissive 模式。漏洞通过 GPU 获得任意物理内存写能力，修补 sys_call_table 中未使用的槽位以将系统调用重定向到攻击者可控或已解析的内核辅助例程，随后关闭 SELinux 强制模式并触发 coredump 处理程序以 root 权限运行辅助脚本，内核改动面小，且不依赖 ROP、堆喷射或单独 CVE。代码主要为 C，含 aarch64 与 armv7 交叉编译工具、Shell 自动化，以及关于缓存一致性、ion 变通方案与锁定固件上内核符号发现的详细说明。面向研究 Android 内核利用、在老旧 Amlogic 机顶盒上借助 GPU 的 LPE，以及 Mali Utgard 驱动缺陷的安全研究人员与逆向工程师。
