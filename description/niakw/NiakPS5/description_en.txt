NiakPS5 is a native, full-screen home interface for homebrew-enabled PlayStation 5 consoles that presents a custom game and app library with DualSense navigation. It discovers locally installed titles, launches them through a loopback-only broker on 127.0.0.1, and shows animated three-dimensional PS4 and PS5-style case art with optional LaunchBox CDN artwork fetched only when a game is selected. The project is built around a GPL-licensed native PS5 title in C and C++, Python scripts and tests for packaging and metadata, and OpenGL rendering validated in CI. It is aimed at PS5 homebrew users and researchers who want a self-contained library shell that respects Sony launch and licensing boundaries rather than replacing system shell components.
