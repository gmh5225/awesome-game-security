NiakPS5 是一款面向已启用 homebrew 的 PlayStation 5 主机的原生全屏主界面，通过 DualSense 导航展示自定义游戏与应用库。它会发现本地已安装的游戏，经仅限回环地址 127.0.0.1 上的 broker 启动它们，并展示带动画的三维 PS4 与 PS5 风格盒装封面，可在选中某款游戏时可选从 LaunchBox CDN 获取封面图。项目以 GPL 许可的原生 PS5 C/C++ 程序为核心，辅以用于打包与元数据的 Python 脚本与测试，以及经 CI 验证的 OpenGL 渲染。面向希望拥有自包含库外壳、在 Sony 启动与许可边界内运作而非替换系统 shell 组件的 PS5 homebrew 用户与研究人员。
