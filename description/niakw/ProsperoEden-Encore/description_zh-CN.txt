Prospero.Eden Encore 是一款 PS5 自制应用，将 ProsperoEden 模拟器栈移植到原生主机启动器中，以运行任天堂 Switch 游戏。项目主要使用 C++ 实现，采用 Makefile 构建，并配有大量用于校验与分发的 Python 工具；图形路径围绕 Vulkan 及在 PlayStation 硬件上类似 RADV 的 GPU 集成方案构建。该分支面向已验证的 PS5 系统固件 13.60，强调有界缓存、可复现发布、CodeQL 驱动的安全审查，以及与越狱或授权破解的明确区分。功能包括面向电视的启动器、DualSense 输入、多语言界面目录、灵活的固件与密钥存储（用于 Switch 系统转储），以及对常见 Switch 游戏容器及相关原生加载器格式的支持。本项目适合研究主机自制部署、在封闭平台上强化模拟器，以及底层图形与 CPU JIT 行为的研究者与开发者，而非在线反作弊绕过工作。
