Prospero.Eden Encore は PS5 向けホームブリューアプリで、ProsperoEden エミュレータスタックをネイティブのコンソールランチャー上に移植し、Nintendo Switch タイトルを起動できるようにします。主に C++ で実装され、Makefile によるビルド、検証とステージング用の広範な Python ツール、PlayStation ハードウェア上で Vulkan と RADV 風 GPU 統合を中心としたグラフィックス経路を備えています。このフォークは検証済み PS5 システムファームウェア 13.60 を対象とし、境界付きキャッシュ、再現可能なリリース、CodeQL によるセキュリティレビュー、ジェイルブレイクやエンタイトルメント悪用からの明確な分離を重視します。機能には TV 向けランチャー、DualSense 入力、多言語 UI カタログ、Switch システムダンプ向けの柔軟なファームウェアとキー保存、一般的な Switch ゲームコンテナおよび関連ネイティブローダ形式のサポートがあります。コンソールホームブリュー展開、閉鎖プラットフォーム上のエミュレータ強化、低レベルグラフィックスと CPU JIT の挙動を研究する研究者・開発者向けであり、オンラインアンチチート回避作業を目的としません。
