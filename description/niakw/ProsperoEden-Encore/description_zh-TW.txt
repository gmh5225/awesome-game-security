Prospero.Eden Encore 是一款 PS5 自製應用程式，將 ProsperoEden 模擬器堆疊移植到原生主機啟動器，以執行任天堂 Switch 遊戲。專案主要以 C++ 實作，採用 Makefile 建置，並配有大量用於驗證與分發的 Python 工具；圖形路徑圍繞 Vulkan 及在 PlayStation 硬體上類似 RADV 的 GPU 整合方案構建。此分支鎖定已驗證的 PS5 系統韌體 13.60，強調有界快取、可重現發行、CodeQL 驅動的安全審查，以及與越獄或授權破解的明確區隔。功能包含面向電視的啟動器、DualSense 輸入、多語言介面目錄、彈性的韌體與金鑰儲存（用於 Switch 系統傾印），以及對常見 Switch 遊戲容器與相關原生載入器格式的支援。本專案適合研究主機自製部署、在封閉平台上強化模擬器，以及底層圖形與 CPU JIT 行為的研究者與開發者，而非線上反作弊繞過工作。
