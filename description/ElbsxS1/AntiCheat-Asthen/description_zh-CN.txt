AsthenGuard 是一款基于 Maven 构建的 Java 插件，为 Minecraft Paper 26.3 提供服务端反作弊保护。它会对移动与战斗行为执行检测，包括加速、飞行、无摔落伤害、穿墙、攻击距离、各类杀戮光环、连点、范围破坏、快速放置等，通过随时间衰减的违规等级可触发管理员告警、踢人或可选封禁。统计型 X 光监控会在矿石与石头比例异常时提醒运维；附带的 Paper 世界 YAML 可在主世界、下界与末地启用引擎模式反 X 光矿石混淆。插件与 Floodgate、Geyser 集成以支持基岩版玩家，在传送与世界切换后给予宽限期，并提供管理命令用于告警、违规查看与配置重载，适合希望以轻量、低误报方式做作弊检测并配合 Paper 原生 X 光加固的 Paper 服主。
