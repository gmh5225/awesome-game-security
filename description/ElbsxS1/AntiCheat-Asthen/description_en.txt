AsthenGuard is a Maven-built Java plugin that adds server-side anti-cheat protections for Minecraft Paper 26.3. It runs movement and combat checks such as speed, flight, no-fall, phase, reach, kill aura variants, autoclick, nuker, and fast place, using violation levels that decay over time and can trigger staff alerts, kicks, or optional bans. A statistical x-ray monitor warns operators when ore-to-stone ratios look suspicious, while bundled Paper world YAML files enable engine-mode anti-xray ore obfuscation across the Overworld, Nether, and End. The plugin integrates with Floodgate and Geyser for Bedrock players, grants grace periods after teleports and world changes, and exposes admin commands for alerts, violation inspection, and configuration reload. It is aimed at Paper server owners who want lightweight, low false-positive cheat detection alongside native Paper x-ray hardening.
