AsthenGuard is a Minecraft server anti-cheat plugin built for Paper 26.3 on Java 25, combining in-game movement and combat checks with an x-ray behavior monitor and bundled Paper anti-xray world configuration. It is implemented in Java with Maven and detects cheats such as speed, flight, false fall, phase, extended reach, kill aura, autoclick, nuker, and fast block placement, using a violation-level system that decays over time and can trigger staff alerts, kicks, or optional bans. The plugin is tuned to reduce false positives for legitimate Java and Bedrock players via Floodgate and Geyser integration, grace periods after teleports, and ping-aware reach checks, while staff can manage alerts and player violation levels through in-game commands. Packaged anti-xray YAML files document how to enable Paper’s engine-mode ore obfuscation for real x-ray prevention, with the plugin’s x-ray monitor serving as a statistical early-warning tool for server operators and moderation teams.
