AsthenGuard は Maven でビルドする Java プラグインで、Minecraft Paper 26.3 向けにサーバー側のアンチチート保護を追加します。移動と戦闘について速度、飛行、ノーフォール、フェーズ、リーチ、各種 Kill Aura、オートクリック、ヌーカー、高速設置などのチェックを行い、時間とともに減衰する違反レベルでスタッフ通知、キック、任意の BAN を発動できます。統計的な X 線モニターは鉱石対石の比率が不審な場合にオペレーターへ警告し、同梱の Paper ワールド用 YAML でオーバーワールド、ネザー、エンド全体にエンジンモードのアンチ X 線による鉱石の難読化を有効化できます。Floodgate および Geyser と連携して Bedrock プレイヤーに対応し、テレポートやワールド変更後の猶予期間を設け、管理コマンドでアラート、違反確認、設定のリロードを提供します。軽量で誤検知の少ないチート検知と Paper ネイティブの X 線対策を求める Paper サーバー運営者向けです。
