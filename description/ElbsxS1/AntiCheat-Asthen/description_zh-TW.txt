AsthenGuard 是一款以 Maven 建置的 Java 外掛，為 Minecraft Paper 26.3 提供伺服器端反作弊保護。它會對移動與戰鬥行為執行檢查，包含加速、飛行、無摔落傷害、穿牆、攻擊距離、各類殺戮光環、連點、範圍破壞、快速放置等，透過隨時間衰減的違規等級可觸發管理員警示、踢人或可選封禁。統計型 X 光監控會在礦石與石頭比例異常時提醒營運者；內附的 Paper 世界 YAML 可在主世界、地獄與終界啟用引擎模式反 X 光礦石混淆。外掛與 Floodgate、Geyser 整合以支援基岩版玩家，在傳送與世界切換後給予寬限期，並提供管理指令用於警示、違規檢視與設定重新載入，適合希望以輕量、低誤報方式做作弊偵測並搭配 Paper 原生 X 光加固的 Paper 伺服器擁有者。
