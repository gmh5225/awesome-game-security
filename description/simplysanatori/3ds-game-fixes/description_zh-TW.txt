本專案彙整用於修復任天堂 3DS 遊戲畫面異常與生活品質問題的修補檔與作弊碼，可在模擬器上使用，也可在搭載 Luma3DS 的實機上使用。各遊戲依地區整理，同時提供針對解壓後 ExeFS 程式碼段的 IPS 修補檔，以及配套的 Action Replay 風格作弊碼；版本守衛確保僅在預期位元組存在時才寫入。修復透過反組譯與追蹤 ARM 遊戲程式碼開發，並藉由無頭模擬器測試框架、GPU 追蹤以及修復前後截圖進行驗證。機器可讀目錄與各遊戲技術說明記錄具體缺陷的發現方式及被修改的指令。面向在 Azahar、Citra 或 Zakuro 上以更高內部分辨率遊玩的玩家，以及希望取得有文件、輕量二進位修補而非大規模紋理或 ROM 替換的逆向工程師。
