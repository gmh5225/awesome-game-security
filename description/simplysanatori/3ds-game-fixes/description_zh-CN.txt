本项目汇总用于修复任天堂 3DS 游戏画面故障与体验问题的补丁和作弊码，可在模拟器上使用，也可在搭载 Luma3DS 的实机上使用。各游戏按地区整理，同时提供针对解压后 ExeFS 代码段的 IPS 补丁，以及配套的 Action Replay 风格作弊码；版本校验确保仅在预期字节存在时才写入。修复通过反汇编与追踪 ARM 游戏代码开发，并借助无头模拟器测试框架、GPU 跟踪以及修复前后截图进行验证。机器可读目录与各游戏技术说明记录具体缺陷的发现方式及被修改的指令。面向在 Azahar、Citra 或 Zakuro 上以更高内部分辨率游玩的玩家，以及希望获得有文档、轻量二进制补丁而非大规模纹理或 ROM 替换的逆向工程师。
