This project collects patches and cheat codes that fix graphics glitches and quality-of-life issues in Nintendo 3DS games for use on emulators and on real hardware with Luma3DS. Each title is organized by region and ships both an IPS patch against the decompressed ExeFS code segment and matching Action Replay-style cheats with version guards so writes apply only when the expected bytes are present. Fixes are developed through disassembly and tracing of ARM game code, with validation via headless emulator harnesses, GPU traces, and before-and-after screenshots. A machine-readable catalog and per-game technical notes document how specific bugs were found and what instructions were changed. It is aimed at players running Azahar, Citra, or Zakuro at higher internal resolutions and at reverse engineers who want documented, lightweight binary patches rather than broad texture or ROM replacements.
