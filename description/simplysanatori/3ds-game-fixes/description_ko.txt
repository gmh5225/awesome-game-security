이 프로젝트는 에뮬레이터와 Luma3DS가 설치된 실기에서 닌텐도 3DS 게임의 그래픽 결함과 QoL 문제를 고치는 패치와 치트 코드를 모읍니다. 각 타이틀은 지역별로 정리되며, 압축 해제된 ExeFS 코드 세그먼트용 IPS 패치와 짝이 맞는 Action Replay 스타일 치트를 함께 제공합니다. 버전 가드로 예상 바이트가 있을 때만 쓰기가 적용됩니다. 수정은 ARM 게임 코드의 디스어셈블리와 추적으로 개발하며, 헤드리스 에뮬레이터 하네스, GPU 트레이스, 수정 전후 스크린샷으로 검증합니다. 기계 판독 가능한 카탈로그와 게임별 기술 노트에 특정 버그의 발견 과정과 변경된 명령을 기록합니다. Azahar, Citra, Zakuro에서 더 높은 내부 해상도로 플레이하는 사용자와, 광범위한 텍스처나 ROM 교체 대신 문서화된 경량 바이너리 패치를 원하는 리버스 엔지니어를 대상으로 합니다.
