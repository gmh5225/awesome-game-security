本プロジェクトは、エミュレータや Luma3DS 入り実機向けに、任天堂 3DS ゲームのグラフィック不具合や QoL 問題を直すパッチとチートコードをまとめたものです。タイトルごとにリージョン別に整理され、展開済み ExeFS コードセグメント向けの IPS パッチと、対応する Action Replay 風チートの両方を同梱します。バージョンガードにより、期待するバイトが存在するときだけ書き込みが行われます。修正は ARM ゲームコードの逆アセンブルとトレースで開発し、ヘッドレスエミュレータハーネス、GPU トレース、修正前後のスクリーンショットで検証します。機械可読なカタログとゲーム別の技術メモで、特定のバグの発見経緯と変更した命令を記録しています。Azahar、Citra、Zakuro で内部解像度を上げてプレイするユーザーと、大規模なテクスチャや ROM 差し替えではなく、文書化された軽量バイナリパッチを求めるリバースエンジニア向けです。
