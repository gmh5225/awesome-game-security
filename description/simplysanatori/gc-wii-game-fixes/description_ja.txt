GameCube and Wii Game Fixes は、小売版 GameCube および Wii タイトル向けの Dolphin 向けパッチ、チート、グラフィック修正、Riivolution モッド、HD テクスチャパックをまとめたキュレーションカタログです。各ゲームは六文字のディスク ID をキーとした構造化 JSON エントリで記述され、Python ビルドスクリプトがそれらを検証し、アプリやインストーラが利用できる機械可読カタログを出力します。エントリには Gecko、Action Replay、on-frame コード、Dolphin 組み込み INI 設定、GitHub や GameBanana などから第三者テクスチャを取得するためのリモートダウンロードメタデータが含まれ、著作物の再ホスティングは行いません。プロジェクトは適切な作者表記、リビジョン固有のコード、ワイドスクリーン、フレームレート、互換性の回避策といったエミュレーション向け改善を重視しています。商業的アンチチートやライブオンラインセキュリティではなく、Dolphin 内でゲームごとのパッチを維持・適用する保存志向のプレイヤーとリバースエンジニアを対象としています。
