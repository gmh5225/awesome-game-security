GameCube and Wii Game Fixes — это курируемый каталог патчей, читов, графических исправлений, модов Riivolution и HD-текстур для Dolphin, ориентированный на розничные игры GameCube и Wii. Каждая игра описана в структурированных JSON-записях с шестисимвольными ID дисков; скрипт сборки на Python проверяет эти записи и формирует машиночитаемые каталоги для приложений и установщиков. Записи охватывают коды Gecko, Action Replay и on-frame, встроенные настройки INI Dolphin, а также метаданные удалённой загрузки сторонних текстур с GitHub, GameBanana и других площадок без повторного хостинга объектов, защищённых авторским правом. Проект делает упор на корректную атрибуцию авторов, коды для конкретных ревизий и улучшения для эмуляции: широкоэкранный режим, частота кадров и обходные решения для совместимости. Он предназначен для игроков, заботящихся о сохранении, и инженеров по обратной разработке, которые ведут или применяют патчи по играм в Dolphin, а не для коммерческого античита или безопасности живого онлайна.
