GameCube 与 Wii 游戏修复集是一份面向 Dolphin 的精选目录，收录零售版 GameCube 与 Wii 游戏的补丁、金手指、图形修复、Riivolution 模组以及 HD 纹理包。每款游戏以六字符光盘 ID 为键，在结构化 JSON 条目中描述；Python 构建脚本会校验这些条目并生成可供应用或安装程序读取的机器可读目录。条目涵盖 Gecko、Action Replay 与 on-frame 代码、Dolphin 内置 INI 设置，以及从 GitHub、GameBanana 等站点拉取第三方纹理的远程下载元数据，且不转托管受版权保护的资源。项目强调正确的作者署名、特定修订版代码，以及面向仿真的改进，例如宽屏、帧率与兼容性变通方案。面向注重存档的玩家与逆向工程师，他们在 Dolphin 内维护或应用逐游戏补丁，而非面向商业反作弊或在线实时安全。
