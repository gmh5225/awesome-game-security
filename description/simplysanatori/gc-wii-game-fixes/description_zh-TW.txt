GameCube 與 Wii 遊戲修復集是一份面向 Dolphin 的精選目錄，收錄零售版 GameCube 與 Wii 遊戲的修補檔、金手指、圖形修復、Riivolution 模組以及 HD 紋理包。每款遊戲以六字元光碟 ID 為鍵，於結構化 JSON 條目中描述；Python 建置腳本會驗證這些條目並產生可供應用程式或安裝程式讀取的機器可讀目錄。條目涵蓋 Gecko、Action Replay 與 on-frame 程式碼、Dolphin 內建 INI 設定，以及從 GitHub、GameBanana 等網站取得第三方紋理的遠端下載中繼資料，且不重新託管受版權保護的資產。專案強調正確的作者署名、特定修訂版程式碼，以及以模擬為導向的改進，例如寬螢幕、影格率與相容性因應作法。對象為注重保存的玩家與逆向工程師，他們在 Dolphin 內維護或套用逐遊戲修補，而非商業反作弊或即時線上安全。
