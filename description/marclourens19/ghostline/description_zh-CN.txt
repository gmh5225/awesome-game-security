Ghostline 是一款俯视角 2D 竞技场射击游戏，演示权威服务器端回放校验，使排行榜分数无法仅由客户端单方面可信。Godot 4 C# 客户端将每 tick 的玩家输入记录为紧凑的二进制 GHST 回放流，ASP.NET Core API 接收这些回放，在边界检查、SHA-256 去重与速率限制之后，于无头确定性模拟器中重跑对局。共享 C# 模拟引擎采用整数定点数学与圆形物理，使 Windows 客户端与 Linux 服务器对结果一致，已验证的运行存入 PostgreSQL。零依赖 HTML5 回放检视器在浏览器中解析 GHST 帧，支持按 tick 拖拽检视与遥测审查。面向游戏安全与反作弊研究、确定性网络代码以及抗作弊在线计分架构。
