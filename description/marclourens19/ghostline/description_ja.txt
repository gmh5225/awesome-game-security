Ghostline は、権威あるサーバー側リプレイ検証を示すトップダウン 2D アリーナシューターで、リーダーボードのスコアをクライアントだけでは信頼できないようにする。Godot 4 C# クライアントは tick ごとのプレイヤー入力をコンパクトなバイナリ GHST リプレイストリームに記録し、ASP.NET Core API がそれらを取り込み、境界チェック、SHA-256 による重複排除、レート制限の後、ヘッドレスの決定論的シミュレータでマッチを再実行する。共有 C# シミュレーションエンジンは整数固定小数点演算と円形物理を用い、Windows クライアントと Linux サーバーが結果で一致し、検証済みランは PostgreSQL に保存される。依存関係ゼロの HTML5 リプレイインスペクターがブラウザで GHST フレームを解析し、tick スクラブとテレメトリ確認ができる。ゲームセキュリティとアンチチート研究、決定論的ネットコード、チート耐性のあるオンラインスコアリングアーキテクチャを対象とする。
