Ghostline 是一款俯視角 2D 競技場射擊遊戲，示範權威伺服器端回放驗證，使排行榜分數無法僅由用戶端單方面可信。Godot 4 C# 用戶端將每 tick 的玩家輸入記錄為緊湊的二進位 GHST 回放串流，ASP.NET Core API 接收這些回放，在邊界檢查、SHA-256 去重與速率限制之後，於無頭確定性模擬器中重跑對局。共用 C# 模擬引擎採用整數定點數學與圓形物理，使 Windows 用戶端與 Linux 伺服器對結果一致，已驗證的執行存入 PostgreSQL。零依賴 HTML5 回放檢視器在瀏覽器中解析 GHST 影格，支援依 tick 拖曳檢視與遙測審查。面向遊戲安全與反作弊研究、確定性網路程式碼以及抗作弊線上計分架構。
