Ghostline is a top-down 2D arena shooter that demonstrates authoritative server-side replay verification so leaderboard scores cannot be trusted from the client alone. The Godot 4 C# client records per-tick player inputs into a compact binary GHST replay stream, and an ASP.NET Core API ingests those replays, applies bounds checks, SHA-256 deduplication, and rate limiting before re-running the match in a headless deterministic simulator. The shared C# simulation engine uses integer fixed-point math and circular physics so Windows clients and Linux servers agree on outcomes, with verified runs stored in PostgreSQL. A zero-dependency HTML5 replay inspector parses GHST frames in the browser for tick scrubbing and telemetry review. It targets game security and anti-cheat research, deterministic netcode, and cheat-resistant online scoring architectures.
