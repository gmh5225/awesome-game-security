Ghostline — арена-шутер с видом сверху в 2D, демонстрирующий авторитетную серверную проверку реплеев, чтобы очки в таблице лидеров нельзя было доверять только клиенту. Клиент Godot 4 на C# записывает ввод игрока по тикам в компактный бинарный поток реплеев GHST, а API ASP.NET Core принимает эти реплеи, выполняет проверки границ, дедупликацию SHA-256 и ограничение частоты, после чего заново прогоняет матч в headless детерминированном симуляторе. Общий движок симуляции на C# использует целочисленную фиксированную арифметику и круговую физику, чтобы клиенты Windows и серверы Linux сходились в результатах; проверенные прогоны хранятся в PostgreSQL. HTML5-инспектор реплеев без зависимостей разбирает кадры GHST в браузере для перемотки по тикам и просмотра телеметрии. Ориентирован на исследования безопасности игр и античита, детерминированный netcode и архитектуры онлайн-скоринга, устойчивые к читам.
