Ghostline est un arena shooter 2D vue du dessus qui illustre une vérification de relecture côté serveur autoritaire, de sorte que les scores du classement ne peuient pas reposer sur le seul client. Le client Godot 4 C# enregistre les entrées joueur tick par tick dans un flux binaire compact GHST, et une API ASP.NET Core ingère ces relectures, applique des contrôles de limites, une déduplication SHA-256 et une limitation de débit avant de relancer le match dans un simulateur déterministe headless. Le moteur de simulation C# partagé utilise l’arithmétique en virgule fixe entière et une physique circulaire pour que clients Windows et serveurs Linux convergent sur les résultats, les exécutions vérifiées étant stockées dans PostgreSQL. Un inspecteur de relecture HTML5 sans dépendance parse les trames GHST dans le navigateur pour le scrubbing par tick et l’analyse télémétrique. Il vise la recherche en sécurité de jeux et anti-triche, le netcode déterministe et les architectures de score en ligne résistantes à la triche.
