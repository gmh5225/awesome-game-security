AxHunter は、Wellbia XIGNCODE3 アンチチートの特権カーネルドライバーを悪用する Rust 製概念実証スイートで、xhunter1.sys と CVE-2026-15430 に関連する新しい xhunter2.sys の両方を対象としています。各 PoC は WriteFile ベースのコマンドフレームでドライバーと通信し、認証チェックを回避して PPL 回避可能なプロセスハンドルを取得し、ユーザーモードから任意のプロセスメモリを読み取ります。共有 crate は lsass.exe を走査して LSA 資格情報を抽出し、BCrypt 3DES キーを復元して LogonSessionList および WDigest エントリを復号し、NT/SHA1 ハッシュと平文パスワードを取得します。追加モードでは Windows Defender などの保護されたプロセス内のハンドルを強制終了し、winlogon.exe 経由で SYSTEM シェルへ権限昇格できます。本プロジェクトは、カーネルドライバーの弱点、ドライバー悪用、Windows 資格情報窃取プリミティブを分析するゲームセキュリティおよびアンチチート研究者向けです。
