AxHunter — это набор proof-of-concept на Rust, эксплуатирующий привилегированные драйверы ядра из античита Wellbia XIGNCODE3, охватывая как xhunter1.sys, так и более новый xhunter2.sys, связанный с CVE-2026-15430. Каждый PoC взаимодействует с драйвером через командные фреймы на основе WriteFile, обходя проверки аутентификации, получая дескрипторы процессов с обходом PPL и читая произвольную память процессов из пользовательского режима. Общий crate выполняет извлечение учётных данных LSA, обходя lsass.exe, восстанавливая ключи BCrypt 3DES и расшифровывая записи LogonSessionList и WDigest для получения хешей NT/SHA1 и паролей в открытом виде. Дополнительные режимы могут принудительно закрывать дескрипторы в защищённых процессах, таких как Windows Defender, и повышать привилегии до SYSTEM shell через winlogon.exe. Проект предназначен для исследователей игровой безопасности и античита, анализирующих уязвимости драйверов ядра, эксплуатацию драйверов и примитивы кражи учётных данных Windows.
