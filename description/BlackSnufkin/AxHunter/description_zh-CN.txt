AxHunter 是一套 Rust 概念验证套件，利用 Wellbia XIGNCODE3 反作弊中的特权内核驱动，涵盖 xhunter1.sys 以及与 CVE-2026-15430 相关的新版 xhunter2.sys。每个 PoC 通过基于 WriteFile 的命令帧与驱动通信，绕过身份验证检查、获取可绕过 PPL 的进程句柄，并从用户模式读取任意进程内存。共享 crate 通过遍历 lsass.exe 执行 LSA 凭据提取，恢复 BCrypt 3DES 密钥，并解密 LogonSessionList 与 WDigest 条目以获取 NT/SHA1 哈希及明文密码。其他模式可强制关闭 Windows Defender 等受保护进程中的句柄，并通过 winlogon.exe 提升至 SYSTEM shell。该项目面向分析内核驱动弱点、驱动利用及 Windows 凭据窃取原语的游戏安全与反作弊研究人员。
