AxHunter 是一套 Rust 概念驗證套件，利用 Wellbia XIGNCODE3 反作弊中的特權核心驅動程式，涵蓋 xhunter1.sys 以及與 CVE-2026-15430 相關的新版 xhunter2.sys。每個 PoC 透過基於 WriteFile 的命令框架與驅動程式通訊，繞過身分驗證檢查、取得可繞過 PPL 的行程控制代碼，並從使用者模式讀取任意行程記憶體。共用 crate 透過遍歷 lsass.exe 執行 LSA 憑證擷取，還原 BCrypt 3DES 金鑰，並解密 LogonSessionList 與 WDigest 項目以取得 NT/SHA1 雜湊及明文密碼。其他模式可強制關閉 Windows Defender 等受保護行程中的控制代碼，並透過 winlogon.exe 提升至 SYSTEM shell。本專案面向分析核心驅動程式弱點、驅動程式利用及 Windows 憑證竊取原語的遊戲安全與反作弊研究人員。
