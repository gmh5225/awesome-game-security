AxHunter es una suite de prueba de concepto en Rust que explota controladores de kernel con privilegios del anti-cheat Wellbia XIGNCODE3, abarcando tanto xhunter1.sys como el más reciente xhunter2.sys asociado al CVE-2026-15430. Cada PoC se comunica con el controlador mediante tramas de comando basadas en WriteFile para eludir las comprobaciones de autenticación, obtener handles de proceso que evaden PPL y leer memoria de procesos arbitrarios desde el modo usuario. Una crate compartida realiza extracción de credenciales LSA recorriendo lsass.exe, recuperando claves BCrypt 3DES y descifrando entradas de LogonSessionList y WDigest para obtener hashes NT/SHA1 y contraseñas en texto plano. Modos adicionales pueden cerrar forzosamente handles en procesos protegidos como Windows Defender y escalar a un shell SYSTEM mediante winlogon.exe. El proyecto está destinado a investigadores de seguridad de juegos y anti-cheat que analizan debilidades en controladores de kernel, explotación de controladores y primitivas de robo de credenciales de Windows.
