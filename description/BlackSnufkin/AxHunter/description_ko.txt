AxHunter는 Wellbia XIGNCODE3 안티치트의 권한 있는 커널 드라이버를 악용하는 Rust 개념 증명(PoC) 스위트로, xhunter1.sys와 CVE-2026-15430과 관련된 최신 xhunter2.sys를 모두 다룹니다. 각 PoC는 WriteFile 기반 명령 프레임을 통해 드라이버와 통신하여 인증 검사를 우회하고, PPL 우회가 가능한 프로세스 핸들을 획득하며, 사용자 모드에서 임의 프로세스 메모리를 읽습니다. 공유 crate는 lsass.exe를 순회하여 LSA 자격 증명을 추출하고, BCrypt 3DES 키를 복구한 뒤 LogonSessionList 및 WDigest 항목을 복호화하여 NT/SHA1 해시와 평문 비밀번호를 획득합니다. 추가 모드는 Windows Defender 같은 보호된 프로세스의 핸들을 강제로 닫고, winlogon.exe를 통해 SYSTEM 셸로 권한을 상승할 수 있습니다. 이 프로젝트는 커널 드라이버 취약점, 드라이버 악용, Windows 자격 증명 탈취 프리미티브를 분석하는 게임 보안 및 안티치트 연구자를 위한 것입니다.
