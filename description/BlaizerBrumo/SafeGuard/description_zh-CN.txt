SafeGuard 是一款面向 Minecraft 基岩版的行为包附加组件，用于检测常见的客户端作弊，并为服主提供游戏内管理工具。它主要使用 JavaScript 与基岩版 Script API（Beta APIs）实现，并配合 mcfunction 资源、JSON 实体定义，以及游戏内管理面板物品来切换模块与编辑设置。检测范围涵盖战斗类滥用（如 killaura、高 CPS、无挥击攻击、FOV 异常、自动图腾、自动水晶、战斗下线等），以及世界与背包滥用（如方块核爆、脚手架与空中放置、无效装备或耐久、名称伪装等），并可选用聊天刷屏与数据包防护。员工工具包括封禁与禁言流程、冻结与隐身、背包检查、世界边界控制、设备封禁、矿石挖掘告警，以及玩家重复违规时的 AutoMod 升级处理。面向需要轻量、可配置反作弊与管理工具、且无需独立后端服务的基岩版 Realm 与专用服运营者。
