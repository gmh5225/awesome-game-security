SafeGuard 是一款面向 Minecraft 基岩版的行为包附加元件，用於偵測常見的用戶端作弊，並為伺服器擁有者提供遊戲內管理工具。它主要使用 JavaScript 與基岩版 Script API（Beta APIs）實作，並搭配 mcfunction 資源、JSON 實體定義，以及遊戲內管理面板物品來切換模組與編輯設定。偵測範圍涵蓋戰鬥類濫用（如 killaura、高 CPS、無揮擊攻擊、FOV 異常、自動圖騰、自動水晶、戰鬥登出等），以及世界與背包濫用（如方塊核爆、鷹架與空中放置、無效裝備或耐久、名稱偽裝等），並可選用聊天刷屏與封包防護。管理員工具包括封禁與禁言流程、凍結與隱身、背包檢查、世界邊界控制、裝置封禁、礦石挖掘告警，以及玩家重複違規時的 AutoMod 升級處理。面向需要輕量、可設定反作弊與管理工具、且無需獨立後端服務的基岩版 Realm 與專用伺服器營運者。
