SafeGuard — аддон behavior pack для Minecraft Bedrock Edition, который обнаруживает распространённые клиентские читы и даёт владельцам серверов инструменты модерации внутри мира. Реализован в основном на JavaScript с Bedrock Script API (Beta APIs), а также mcfunction-ресурсами, JSON-определениями сущностей и предметом внутриигровой админ-панели для переключения модулей и редактирования настроек. Обнаружение охватывает боевые злоупотребления: killaura, высокий CPS, атаки без взмаха, аномалии FOV, auto-totem, auto-crystal и combat logging, плюс злоупотребления миром и инвентарём — block nuking, леса и установка в воздухе, недопустимая экипировка или прочность, подмена имени, с опциональной защитой от спама в чате и пакетов. Утилиты для персонала: бан и мут, freeze и vanish, просмотр инвентаря, контроль границы мира, баны по устройству, оповещения о добыче руды и эскалация AutoMod при повторных нарушениях. Ориентирован на операторов Bedrock Realm и выделенных серверов, которым нужны лёгкий настраиваемый античит и админ-инструменты без отдельного backend-сервиса.
