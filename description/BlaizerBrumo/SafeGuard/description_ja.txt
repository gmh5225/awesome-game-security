SafeGuard は Minecraft Bedrock Edition 向けのビヘイビアパックアドオンで、一般的なクライアント側チートを検出し、サーバー管理者にワールド内モデレーションツールを提供します。主に JavaScript と Bedrock Script API（Beta APIs）で実装され、mcfunction アセット、JSON エンティティ定義、モジュールの切り替えや設定編集用のゲーム内管理パネルアイテムも含みます。検出対象は killaura、高 CPS、スイングなし攻撃、FOV 異常、オートトーテム、オートクリスタル、コンバットログなどの戦闘悪用に加え、ブロックヌーク、足場・空中設置、不正装備や耐久、ネーム偽装などのワールド・インベントリ悪用、任意のチャットスパム・パケット保護もカバーします。スタッフ向け機能には BAN・ミュート、フリーズ・バニッシュ、インベントリ確認、ワールドボーダー制御、デバイス BAN、鉱石採掘アラート、違反の繰り返しに対する AutoMod エスカレーションがあります。別バックエンド不要の軽量で設定可能なアンチチートと管理ツールを求める Bedrock Realm および専用サーバー運営者向けです。
