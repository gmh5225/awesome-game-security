SafeGuard is a Minecraft Bedrock Edition behavior-pack add-on that detects common client-side cheats and gives server owners in-world moderation tools. It is implemented mainly in JavaScript using the Bedrock Script API (Beta APIs), alongside mcfunction assets, JSON entity definitions, and an in-game admin panel item for toggling modules and editing settings. Detection covers combat abuse such as killaura, high CPS, no-swing attacks, FOV anomalies, auto-totem, auto-crystal, and combat logging, plus world and inventory abuse including block nuking, scaffold and air-place placement, invalid equipment or durability, and name spoofing, with optional chat spam and packet protections. Staff utilities include ban and mute workflows, freeze and vanish, inventory inspection, world border control, device bans, ore mining alerts, and AutoMod escalation when players repeat violations. It is aimed at Bedrock realm and dedicated-server operators who need lightweight, configurable anti-cheat and admin tooling without a separate backend service.
