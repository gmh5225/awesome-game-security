本專案為 Angry Birds PC 執行階段引擎的非官方從零重寫實作，藉由將其 C++ 原始碼與原始零售可執行檔的 Ghidra 反編譯結果對照而重建。使用 CMake 以 C++ 建置，依賴 SDL2、OpenGL 1.x、嵌入式 Lua 5.1 以及內附的 Box2D 2.1 與 2.2；各作品原有的 Lua 腳本透過暴露腳本預期的原生 API 執行，而非重寫遊戲邏輯。主要能力包含與反編譯 Box2D 程式路徑相符的物理行為、透過 unluac 的 Lua 位元組碼解密與反編譯、關卡編輯器與存檔狀態支援、除錯疊加層、可選的可執行檔替換，以及於 docs 文件中說明的腳本與 Mod 掛勾。面向逆向工程師、保存工作者與研究人員，便於在合法取得遊戲資源的前提下研究、除錯或擴充經典 Angry Birds PC 及相關移植版。
