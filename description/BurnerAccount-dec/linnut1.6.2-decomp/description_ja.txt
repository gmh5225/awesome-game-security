本プロジェクトは Angry Birds PC ランタイムエンジンの非公式な一からの再実装であり、C++ ソースを原版小売用実行ファイルの Ghidra 逆コンパイル結果と照合して再構築したものです。CMake により C++ でビルドし、SDL2、OpenGL 1.x、組み込み Lua 5.1、同梱の Box2D 2.1 および 2.2 を用い、各タイトル固有の Lua スクリプトはゲームロジックを書き換えず、スクリプトが期待するネイティブ API を公開して実行します。主な機能には、逆コンパイルされた Box2D コードパスに合わせた物理挙動、unluac による Lua バイトコードの復号と逆コンパイル、レベルエディタとセーブステート対応、デバッグオーバーレイ、オプションの実行ファイル差し替え、docs に記載されたスクリプトと Mod 用フックが含まれます。合法に取得したゲームアセットを用いて、クラシックな Angry Birds PC および関連ポートを研究・デバッグ・拡張したいリバースエンジニア、保存活動家、研究者を対象としています。
