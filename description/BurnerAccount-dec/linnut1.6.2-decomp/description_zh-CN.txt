本项目是对 Angry Birds PC 运行时引擎的非官方从零重写实现，通过将其 C++ 源码与原始零售可执行文件的 Ghidra 反编译结果对照而重建。使用 CMake 以 C++ 构建，依赖 SDL2、OpenGL 1.x、嵌入式 Lua 5.1 以及内嵌的 Box2D 2.1 与 2.2；各作原有 Lua 脚本通过暴露脚本所期望的原生 API 运行，而非重写游戏逻辑。主要能力包括与反编译 Box2D 代码路径对齐的物理行为、借助 unluac 的 Lua 字节码解密与反编译、关卡编辑器与存档状态支持、调试叠加层、可选的可执行文件替换，以及文档（docs）中说明的脚本与 Mod 钩子。面向逆向工程师、存档保护者与研究人员，便于在合法取得游戏资源的前提下研究、调试或扩展经典 Angry Birds PC 及相关移植版。
