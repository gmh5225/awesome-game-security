This project is an unofficial from-scratch reimplementation of the Angry Birds PC runtime engine, reconstructed by comparing its C++ sources to Ghidra decompilations of the original retail executables. It is built with CMake using C++, SDL2, OpenGL 1.x, embedded Lua 5.1, and vendored Box2D 2.1 and 2.2, and it runs each title’s original Lua scripts by exposing the native APIs those scripts expect rather than rewriting game logic. Notable capabilities include physics behavior tuned to match decompiled Box2D code paths, Lua bytecode decryption and decompilation via unluac, level editors and save-state support, debug overlays, optional executable replacement, and hooks for scripting and modding documented under docs. It is aimed at reverse engineers, preservationists, and researchers who want to study, debug, or extend classic Angry Birds PC and related ports using legally obtained game assets.
