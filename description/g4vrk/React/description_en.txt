React is an aim-focused anti-cheat plugin for Minecraft Paper and Folia servers that analyzes player rotation patterns to judge whether aiming behavior is physically plausible. Written in Java, it runs heuristic checks locally using GCD-error scoring, acceleration-delta tracking, and mode-averaged rotation quantization instead of brittle static thresholds. An optional machine-learning verdict layer can batch rotation samples to a separate inference service for confidence-scored aimbot detection, while the core plugin remains fully standalone. It includes configurable checks, streak-based violation buffering with decay, async packet processing via PacketEvents, and staff alerts rather than automatic bans. The project targets server operators who need specialized combat aim protection for PvP environments.
