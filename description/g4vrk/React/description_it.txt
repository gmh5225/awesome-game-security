React è un plugin anti-cheat incentrato sulla mira per server Minecraft Paper e Folia, che analizza i pattern di rotazione dei giocatori per valutare se il comportamento di puntamento sia fisicamente plausibile. Scritto in Java, esegue controlli euristici in locale utilizzando punteggio di errore GCD, tracciamento dei delta di accelerazione e quantizzazione della rotazione mediata per moda, invece di soglie statiche fragili. Un livello opzionale di verdetto basato sul machine learning può inviare in batch campioni di rotazione a un servizio di inferenza separato per il rilevamento di aimbot con punteggio di confidenza, mentre il plugin principale resta completamente autonomo. Include controlli configurabili, buffering delle violazioni basato su serie con decadimento, elaborazione asincrona dei pacchetti tramite PacketEvents e avvisi allo staff anziché ban automatici. Il progetto è rivolto agli operatori di server che necessitano di protezione specializzata della mira in combattimento per ambienti PvP.
