React 是一款以瞄準為核心的反作弊外掛，適用於 Minecraft Paper 與 Folia 伺服器，透過分析玩家旋轉模式來判斷瞄準行為是否在物理上合理。此專案以 Java 撰寫，在本地端執行啟發式檢查，採用 GCD 誤差評分、加速度增量追蹤，以及以眾數平均的旋轉量化，而非僵化的靜態閾值。可選的機器學習判定層可將旋轉樣本批次傳送至獨立推理服務，以置信度評分偵測自瞄；核心外掛本身可完全獨立運作。它提供可設定的檢查項目、具衰減機制的連續違規緩衝、透過 PacketEvents 的非同步封包處理，以及面向管理員的警示而非自動封禁。本專案面向需要在 PvP 環境中提供專門戰鬥瞄準防護的伺服器營運者。
