React ist ein zielgerichtetes Anti-Cheat-Plugin für Minecraft-Paper- und Folia-Server, das Rotationsmuster von Spielern analysiert, um zu beurteilen, ob das Zielverhalten physikalisch plausibel ist. In Java geschrieben, führt es lokale heuristische Prüfungen mit GCD-Fehlerscore, Beschleunigungs-Delta-Tracking und modusgemittelter Rotationsquantisierung durch, anstatt auf brüchige statische Schwellenwerte zu setzen. Eine optionale Machine-Learning-Urteilsschicht kann Rotationssamples stapelweise an einen separaten Inferenzdienst senden, um Aimbot-Erkennung mit Konfidenzwerten zu ermöglichen, während das Kern-Plugin vollständig eigenständig bleibt. Es bietet konfigurierbare Prüfungen, serienbasiertes Verstoß-Puffering mit Abklingzeit, asynchrone Paketverarbeitung über PacketEvents und Benachrichtigungen für das Team statt automatischer Bans. Das Projekt richtet sich an Serverbetreiber, die spezialisierten Kampf-Zielschutz für PvP-Umgebungen benötigen.
