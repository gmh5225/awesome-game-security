React — античит-плагин для серверов Minecraft Paper и Folia, ориентированный на обнаружение прицеливания и анализирующий паттерны вращения игроков, чтобы оценить, насколько физически правдоподобно их поведение при наведении. Написан на Java и локально выполняет эвристические проверки с использованием оценки ошибки GCD, отслеживания дельт ускорения и квантования вращения, усреднённого по моде, вместо хрупких статических порогов. Дополнительный слой вердикта на основе машинного обучения может пакетно отправлять образцы вращения на отдельный сервис вывода для обнаружения аимботов с оценкой уверенности, при этом основной плагин остаётся полностью автономным. Включает настраиваемые проверки, буферизацию нарушений по сериям с затуханием, асинхронную обработку пакетов через PacketEvents и оповещения персонала вместо автоматических банов. Проект предназначен для операторов серверов, которым нужна специализированная защита боевого прицеливания в PvP-средах.
