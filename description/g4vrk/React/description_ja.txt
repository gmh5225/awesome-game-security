React は、Minecraft Paper および Folia サーバー向けの照準検知特化型アンチチートプラグインで、プレイヤーの回転パターンを分析し、照準行動が物理的に妥当かどうかを判定します。Java で実装され、GCD 誤差スコアリング、加速度デルタ追跡、モード平均による回転量子化といったヒューリスティック検査をローカルで実行し、脆い静的閾値に頼りません。オプションの機械学習判定レイヤーは回転サンプルを別の推論サービスへバッチ送信し、信頼度スコア付きのエイムボット検知を行えますが、コアプラグインは完全にスタンドアロンで動作します。設定可能なチェック、減衰付き連続違反バッファリング、PacketEvents による非同期パケット処理、自動 BAN ではなくスタッフ向けアラートを備えています。PvP 環境向けの専門的な戦闘照準保護を必要とするサーバー運営者を対象としています。
