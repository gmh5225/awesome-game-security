Droid-arsenal은 APK 패치, 시스템 변경, 불필요한 Frida 사용을 피해 간섭을 최소화하면서 Android 애플리케이션(특히 게임)을 분석·수정할 수 있는, 기기에서 재현 가능한 툴킷입니다. Python CLI를 중심으로 정찰, 백업·복원, 실시간 메모리 스캔, 세이브 파일 스니핑, IL2CPP 덤핑, FakeBinder 스타일 결제 훅을 이용한 인앱 구매 테스트, LSPosed 모듈 스코핑, mitmproxy와 앱별 SNI 라우팅을 통한 선택적 TLS 가로채기를 조율합니다. 앱별 설정은 소형 TOML 타깃 파일에 두고, runbook과 선언적 레시피가 메모리 편집, IAP 위조, MITM 검증 우회, KernelSU 또는 Magisk를 쓰는 루팅 기기에서의 깨끗한 롤백 등 워크플로를 문서화합니다. 이 프로젝트는 자신이 통제하는 하드웨어에서 구조화되고 반복 가능한 Android 게임 리버스 엔지니어링과 안티치트·결제 연구가 필요한 보안 연구자와 숙련 플레이어를 대상으로 합니다.
