Droid-arsenal 是一套可在设备上复现的工具包，用于分析与修改 Android 应用（尤其是游戏），并通过避免 APK 补丁、系统改动以及不必要的 Frida 使用来尽量降低干扰。它以 Python CLI 为核心，统一调度侦察、备份与恢复、实时内存扫描、存档嗅探、IL2CPP 转储、借助 FakeBinder 风格计费钩子的内购测试、LSPosed 模块作用域，以及通过 mitmproxy 按应用 SNI 路由进行的选择性 TLS 拦截。各应用的配置保存在小型 TOML 目标文件中，runbook 与声明式配方则记录内存修改、IAP 伪造、MITM 校验绕过，以及在采用 KernelSU 或 Magisk 的 root 设备上干净回滚等工作流。本项目面向需要在其自有硬件上进行结构化、可重复的 Android 游戏逆向，以及反作弊或计费相关研究的安全研究人员与高级玩家。
