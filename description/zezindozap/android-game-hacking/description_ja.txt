Droid-arsenal は、APK のパッチ、システム変更、不要な Frida 利用を避けることで干渉を抑えながら、Android アプリ（特にゲーム）の解析と改変を行う、デバイス上で再現可能なツールキットです。Python CLI を中心に、偵察、バックアップと復元、ライブメモリスキャン、セーブファイルのスニッフィング、IL2CPP ダンプ、FakeBinder 方式の課金フックによるアプリ内課金テスト、LSPosed モジュールのスコープ設定、mitmproxy によるアプリごとの SNI ルーティングを用いた選択的 TLS 傍受を統合します。アプリごとの設定は小さな TOML ターゲットファイルに格納され、runbook と宣言的レシピがメモリ編集、IAP 偽造、MITM 検証バイパス、KernelSU または Magisk を使った root 端末でのクリーンなロールバックなどのワークフローを文書化します。本プロジェクトは、自身が管理するハードウェア上で、構造化され再現可能な Android ゲームのリバースエンジニアリングや、アンチチート・課金調査を必要とするセキュリティ研究者および上級プレイヤー向けです。
