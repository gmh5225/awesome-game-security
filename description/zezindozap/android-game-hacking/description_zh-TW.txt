Droid-arsenal 是一套可在裝置上重現的工具組，用於分析與修改 Android 應用程式（尤其是遊戲），並透過避免 APK 修補、系統變更以及不必要的 Frida 使用來盡量降低干擾。它以 Python CLI 為核心，統籌偵察、備份與還原、即時記憶體掃描、存檔嗅探、IL2CPP 傾印、搭配 FakeBinder 風格計費掛鉤的內購測試、LSPosed 模組作用域，以及透過 mitmproxy 依應用程式 SNI 路由進行的選擇性 TLS 攔截。各應用程式的設定保存在小型 TOML 目標檔中，runbook 與宣告式配方則記錄記憶體編輯、IAP 偽造、MITM 驗證繞過，以及在採用 KernelSU 或 Magisk 的 root 裝置上乾淨回滾等工作流程。本專案面向需要在其自有硬體上進行結構化、可重複的 Android 遊戲逆向，以及反作弊或計費相關研究的安全研究人員與進階玩家。
