Droid-arsenal is a reproducible on-device toolkit for analyzing and modifying Android applications, especially games, while keeping interference low by avoiding APK patches, system changes, and unnecessary Frida use. It centers on a Python CLI that orchestrates reconnaissance, backup and restore, live memory scanning, save-file sniffing, IL2CPP dumping, in-app purchase testing with FakeBinder-style billing hooks, LSPosed module scoping, and selective TLS interception via mitmproxy with per-app SNI routing. Per-application settings live in small TOML target files, while runbooks and declarative recipes document workflows for memory edits, IAP forgery, MITM validation bypass, and clean rollback on rooted devices using KernelSU or Magisk. The project is aimed at security researchers and advanced players who need structured, repeatable Android game reverse engineering and anti-cheat or billing research on hardware they control.
