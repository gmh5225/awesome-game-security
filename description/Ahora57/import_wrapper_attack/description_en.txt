This is a Windows research tool that demonstrates how to attack import wrappers used by VMProtect, Themida, and WinLicense instead of hooking the transition from application code into the protector. It is implemented in C++ as a Visual Studio solution that scans protected processes, disassembles wrapper stubs with Zydis, and emulates obfuscated decode sequences with the Unicorn engine to recover real API targets. Supporting modules handle import detection, protector identification, and x86/x64 instruction analysis for jmp and call patterns that reference hidden imports. The project illustrates hooking shielded imports such as MessageBoxW and is aimed at reverse engineers and security researchers studying packer import obfuscation and related anti-tamper defenses.
