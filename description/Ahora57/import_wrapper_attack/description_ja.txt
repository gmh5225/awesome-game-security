これは Windows 向けの研究用ツールで、VMProtect、Themida、WinLicense が用いるインポートラッパーを、アプリケーションコードからプロテクタへ遷移する箇所にフックを仕掛けるのではなく、ラッパー自体を攻撃する方法を示します。C++ で実装された Visual Studio ソリューションとして、保護されたプロセスをスキャンし、Zydis でラッパースタブを逆アセンブルし、Unicorn エンジンで難読化されたデコード列をエミュレートして実際の API ターゲットを復元します。補助モジュールはインポート検出、プロテクタ識別、および隠されたインポートを参照する jmp や call パターン向けの x86/x64 命令解析を担当します。MessageBoxW などシールドされたインポートのフック例を示し、パッカーのインポート難読化や関連する改ざん防止策を研究するリバースエンジニアやセキュリティ研究者を対象としています。
