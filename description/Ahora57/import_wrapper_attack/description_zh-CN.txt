这是一款 Windows 研究工具，演示如何攻击 VMProtect、Themida 和 WinLicense 所使用的导入包装器，而不是在应用程序代码进入保护壳的过渡点处挂钩。项目以 C++ 实现，采用 Visual Studio 解决方案，扫描受保护进程，使用 Zydis 反汇编包装器桩代码，并用 Unicorn 引擎模拟混淆的解码序列以恢复真实的 API 目标。配套模块负责导入检测、保护壳识别以及对引用隐藏导入的 jmp 和 call 模式的 x86/x64 指令分析。该项目展示了如何挂钩被屏蔽的导入（如 MessageBoxW），面向逆向工程师与安全研究人员，用于研究加壳器的导入混淆及相关防篡改防护。
