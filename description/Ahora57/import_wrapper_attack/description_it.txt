È uno strumento di ricerca per Windows che dimostra come attaccare i wrapper di import usati da VMProtect, Themida e WinLicense, invece di intercettare la transizione dal codice applicativo al protettore. Implementato in C++ come soluzione Visual Studio, analizza i processi protetti, disassembla gli stub dei wrapper con Zydis ed emula sequenze di decodifica offuscate con il motore Unicorn per recuperare i veri target delle API. I moduli di supporto gestiscono il rilevamento delle import, l’identificazione del protettore e l’analisi delle istruzioni x86/x64 per i pattern jmp e call che referenziano import nascoste. Il progetto illustra l’hooking di import schermate come MessageBoxW ed è rivolto a reverse engineer e ricercatori di sicurezza che studiano l’offuscamento delle import nei packer e le difese anti-manomissione correlate.
