Это исследовательский инструмент для Windows, демонстрирующий атаку на обёртки импорта, которые используют VMProtect, Themida и WinLicense, вместо перехвата перехода от кода приложения к протектору. Реализован на C++ в виде решения Visual Studio: сканирует защищённые процессы, дизассемблирует заглушки обёрток с помощью Zydis и эмулирует обфусцированные последовательности декодирования движком Unicorn, чтобы восстановить реальные цели API. Вспомогательные модули отвечают за обнаружение импортов, идентификацию протектора и анализ инструкций x86/x64 для шаблонов jmp и call, ссылающихся на скрытые импорты. Проект показывает перехват защищённых импортов, таких как MessageBoxW, и предназначен для реверс-инженеров и исследователей безопасности, изучающих обфускацию импортов в пакерах и связанные антивзломные механизмы.
