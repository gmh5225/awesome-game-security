這是一款 Windows 研究工具，示範如何攻擊 VMProtect、Themida 與 WinLicense 所使用的匯入包裝器，而非在應用程式碼進入保護殼的過渡點掛鉤。專案以 C++ 實作，採用 Visual Studio 解決方案，掃描受保護程序，使用 Zydis 反組譯包裝器樁程式碼，並以 Unicorn 引擎模擬混淆的解碼序列以還原真實的 API 目標。支援模組負責匯入偵測、保護殼識別，以及針對引用隱藏匯入之 jmp 與 call 模式的 x86/x64 指令分析。本專案說明如何掛鉤受遮蔽的匯入（如 MessageBoxW），供逆向工程師與安全研究人員研究加殼器的匯入混淆及相關防竄改防護。
