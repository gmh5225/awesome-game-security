CS2KAC は Counter-Strike 2 向けのクライアント側カーネルレベルのアンチチートコンポーネントで、CS2AC や CS2FOW などのサーバー側プラグインを補完し、ゲームサーバーがプレイヤーのマシン上では観測できないプロセス、モジュール、ハンドルの整合性シグナルを公開します。Windows KMDF カーネルドライバーを C で実装し、C++ のユーザーモードサービスと組み合わせてドライバーの読み込み、cs2.exe への接続、カスタム IOCTL による検出レポートのポーリングを行います。ドライバーの骨格には ObRegisterCallbacks、イメージおよびプロセス通知ルーチン、スレッド作成監視など標準の WDK フックが組み込まれ、未署名モジュール、疑わしいプロセス間ハンドル、隠蔽されたスレッドエントリポイント、手動マップドライバー、デバッガー、コード整合性の不一致、ハートビートタイムアウトなどの検出カテゴリをカバーします。レポートはリングバッファにキューイングされ、署名付きアテステーションチャネル経由でサーバーへ転送され、ドキュメントには Discord webhook やブリッジ統合のオプションも記載されています。本プロジェクトは、サーバー側の行動分析と特権クライアント側の整合性チェックを組み合わせた CS2 ハイブリッド保護を構築するゲームセキュリティ研究者およびアンチチート開発者を対象としています。
