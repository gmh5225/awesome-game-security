CS2KAC 是 Counter-Strike 2 的用戶端核心層級反作弊元件，可與 CS2AC、CS2FOW 等伺服器端外掛程式搭配使用，向遊戲伺服器揭露其無法在玩家機器上觀測到的程序、模組與控制代碼完整性訊號。該專案以 C 語言實作的 Windows KMDF 核心驅動程式為核心，並搭配 C++ 使用者模式服務，負責載入驅動程式、附加至 cs2.exe，並透過自訂 IOCTL 輪詢偵測報告。驅動程式骨架接入了 ObRegisterCallbacks、映像與程序通知常式、執行緒建立監控等標準 WDK 掛鉤，偵測類別涵蓋未簽章模組、可疑跨程序控制代碼、隱藏執行緒進入點、手動對映驅動程式、除錯器、程式碼完整性不符以及心跳逾時。報告寫入環形緩衝區，經簽章認證通道轉發至伺服器，文件亦說明 Discord webhook 與橋接整合方案。本專案面向遊戲安全研究人員及反作弊開發者，用於建構結合伺服器端行為分析與特權用戶端完整性檢查的 CS2 混合防護方案。
