CS2KAC is a client-side, kernel-level anti-cheat component for Counter-Strike 2 that complements server-side plugins such as CS2AC and CS2FOW by exposing process, module, and handle integrity signals the game server cannot observe on the player's machine. It is implemented as a Windows KMDF kernel driver in C paired with a C++ user-mode service that loads the driver, attaches to cs2.exe, and polls detection reports over custom IOCTLs. The driver skeleton wires standard WDK hooks including ObRegisterCallbacks, image and process notify routines, and thread creation monitoring, with detection categories covering unsigned modules, suspicious cross-process handles, hidden thread entry points, manual-mapped drivers, debuggers, code integrity mismatches, and heartbeat timeouts. Reports are queued in a ring buffer and forwarded toward the server via a signed attestation channel, with documentation outlining Discord webhook and bridge integration options. The project targets game security researchers and anti-cheat developers building hybrid CS2 protection that combines server-side behavioral analysis with privileged client-side integrity checks.
