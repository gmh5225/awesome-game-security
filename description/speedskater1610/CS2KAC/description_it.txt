CS2KAC è un componente anti-cheat lato client a livello kernel per Counter-Strike 2 che integra plugin lato server come CS2AC e CS2FOW esponendo segnali di integrità di processi, moduli e handle che il server di gioco non può osservare sulla macchina del giocatore. È implementato come driver kernel Windows KMDF in C, abbinato a un servizio in modalità utente in C++ che carica il driver, si collega a cs2.exe e interroga i report di rilevamento tramite IOCTL personalizzati. Lo scheletro del driver collega hook WDK standard tra cui ObRegisterCallbacks, routine di notifica di immagini e processi e monitoraggio della creazione dei thread, con categorie di rilevamento che coprono moduli non firmati, handle sospetti tra processi, punti di ingresso di thread nascosti, driver mappati manualmente, debugger, incongruenze di integrità del codice e timeout del heartbeat. I report vengono accodati in un buffer circolare e inoltrati al server tramite un canale di attestazione firmato, con documentazione che illustra le opzioni di integrazione tramite webhook Discord e bridge. Il progetto è rivolto a ricercatori di sicurezza dei giochi e sviluppatori di anti-cheat che costruiscono una protezione ibrida per CS2 che combina l'analisi comportamentale lato server con controlli di integrità privilegiati lato client.
