CS2KAC 是 Counter-Strike 2 的客户端内核级反作弊组件，可与 CS2AC、CS2FOW 等服务端插件配合使用，向游戏服务器暴露其无法在玩家机器上观测到的进程、模块与句柄完整性信号。该项目以 C 语言实现的 Windows KMDF 内核驱动为核心，并搭配 C++ 用户态服务，负责加载驱动、附加到 cs2.exe，并通过自定义 IOCTL 轮询检测报告。驱动骨架接入了 ObRegisterCallbacks、映像与进程通知例程、线程创建监控等标准 WDK 钩子，检测类别涵盖未签名模块、可疑跨进程句柄、隐藏线程入口点、手动映射驱动、调试器、代码完整性不匹配以及心跳超时。报告写入环形缓冲区，经签名认证通道转发至服务器，文档还说明了 Discord webhook 与桥接集成方案。本项目面向游戏安全研究人员及反作弊开发者，用于构建将服务端行为分析与特权客户端完整性检查相结合的 CS2 混合防护方案。
