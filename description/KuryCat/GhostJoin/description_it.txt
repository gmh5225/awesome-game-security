GhostJoin è un client minimale del protocollo Minecraft Java Edition scritto in puro Python che si connette a un server e resta online senza rendering né interazione in gioco. Implementa l’intero flusso di connessione moderno—Handshake, Login, Configuration e Play—usando solo la libreria standard (socket, struct, hashlib, zlib), inclusa la generazione di UUID in modalità offline, la compressione dei pacchetti, Client Information, messaggi plugin del brand e risposte Keep Alive. Gli ID dei pacchetti mirano alle versioni di protocollo intorno a 773–776, con logging di debug opzionale per adattarsi ad altre versioni. È pensato per test autorizzati di sistemi anti-bot e anti-cheat di Minecraft su server in modalità offline di cui sei proprietario o per i quali hai un permesso esplicito di sondaggio.
