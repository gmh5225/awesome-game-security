GhostJoin est un client de protocole Minecraft Java Edition minimal écrit en Python pur, qui se connecte à un serveur et reste en ligne sans rendu ni interaction en jeu. Il implémente le flux de connexion moderne complet—Handshake, Login, Configuration et Play—en n’utilisant que la bibliothèque standard (socket, struct, hashlib, zlib), y compris la génération d’UUID en mode hors ligne, la compression des paquets, Client Information, les messages de plugin de marque et les réponses Keep Alive. Les identifiants de paquets ciblent les versions de protocole autour de 773–776, avec un journal de débogage optionnel pour faciliter l’adaptation à d’autres versions. Il est destiné aux tests autorisés des systèmes anti-bot et anti-cheat Minecraft sur des serveurs en mode hors ligne que vous possédez ou pour lesquels vous avez une permission explicite de sonder.
