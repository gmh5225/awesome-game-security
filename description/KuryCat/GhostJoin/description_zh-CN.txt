GhostJoin 是一个用纯 Python 编写的极简 Minecraft Java Edition 协议客户端，可连接服务器并保持在线，无需渲染或游戏内交互。它仅使用标准库（socket、struct、hashlib、zlib）实现完整的现代连接流程——Handshake、Login、Configuration 与 Play——包括离线模式 UUID 生成、数据包压缩、Client Information、品牌插件消息以及 Keep Alive 回复。数据包 ID 面向约 773–776 的协议版本，并提供可选调试日志以便适配其他版本。该工具用于在您拥有或明确获准探测的离线模式服务器上，对 Minecraft 反机器人与反作弊系统进行授权测试。
