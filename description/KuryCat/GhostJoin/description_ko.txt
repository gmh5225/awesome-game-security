GhostJoin은 순수 Python으로 작성된 최소 Minecraft Java Edition 프로토콜 클라이언트로, 렌더링이나 인게임 상호작용 없이 서버에 연결해 온라인 상태를 유지합니다. 표준 라이브러리만으로(socket, struct, hashlib, zlib) Handshake, Login, Configuration, Play의 전체 현대 연결 흐름을 구현하며, 오프라인 모드 UUID 생성, 패킷 압축, Client Information, 브랜드 플러그인 메시지, Keep Alive 응답을 포함합니다. 패킷 ID는 프로토콜 버전 약 773–776을 대상으로 하며, 다른 버전에 맞추기 위한 선택적 디버그 로깅을 제공합니다. 본인이 소유하거나 명시적 허가를 받은 오프라인 모드 서버에서 Minecraft 안티봇·안티치트 시스템을 인가된 방식으로 테스트하기 위한 도구입니다.
