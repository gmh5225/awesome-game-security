GhostJoin 是一個以純 Python 撰寫的極簡 Minecraft Java Edition 協定用戶端，可連線至伺服器並保持在線，無需渲染或遊戲內互動。它僅使用標準函式庫（socket、struct、hashlib、zlib）實作完整的現代連線流程——Handshake、Login、Configuration 與 Play——包括離線模式 UUID 產生、封包壓縮、Client Information、品牌外掛訊息以及 Keep Alive 回覆。封包 ID 針對約 773–776 的協定版本，並提供可選除錯記錄以便適配其他版本。此工具用於在您擁有或明確獲准探測的離線模式伺服器上，對 Minecraft 反機器人與反作弊系統進行授權測試。
