GhostJoin は、純粋な Python で書かれた最小限の Minecraft Java Edition プロトコルクライアントで、レンダリングやゲーム内操作なしにサーバーへ接続してオンライン状態を維持します。標準ライブラリのみ（socket、struct、hashlib、zlib）で、Handshake、Login、Configuration、Play という現代的な接続フロー全体を実装し、オフラインモードの UUID 生成、パケット圧縮、Client Information、ブランドプラグインメッセージ、Keep Alive 応答も含みます。パケット ID はプロトコルバージョン約 773–776 を対象とし、他バージョンへの対応を助ける任意のデバッグログも用意されています。自分が所有する、または明示的な許可を得たオフラインモードサーバー上で、Minecraft のアンチボット／アンチチートシステムを正当にテストするためのツールです。
