GhostJoin es un cliente mínimo del protocolo de Minecraft Java Edition escrito en Python puro que se conecta a un servidor y permanece en línea sin renderizado ni interacción en el juego. Implementa el flujo de conexión moderno completo—Handshake, Login, Configuration y Play—usando solo la biblioteca estándar (socket, struct, hashlib, zlib), incluida la generación de UUID en modo offline, la compresión de paquetes, Client Information, mensajes de plugin de marca y respuestas Keep Alive. Los ID de paquete apuntan a las versiones de protocolo alrededor de 773–776, con registro de depuración opcional para adaptar a otras versiones. Está pensado para pruebas autorizadas de sistemas antibot y anticheat de Minecraft en servidores en modo offline que poseas o para los que tengas permiso explícito de sondeo.
