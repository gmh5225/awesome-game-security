Cheat Agent 是一款跨平台自主 AI 系统，用于逆向分析游戏内存，并为经授权的单机离线游戏及受控测试进程生成经核验的训练器。它将用于进程附加、多遍内存扫描、字节数组模式匹配与指针链解析的原生 C/C++20 引擎，与负责会话编排、SQLite 持久化存储及代码生成的 Rust 工作区相结合。五阶段闭环验证器发现作弊项、确认游戏内行为、重启目标进程以应对 ASLR、生成独立的 C++、Rust 或 Cheat Engine 表输出，并重新运行训练器以证明持久性。它既可作为标准输入输出 Model Context Protocol 服务器运行于兼容 MCP 的编程智能体中，也可作为独立 CLI，驱动 OpenAI、Anthropic、OpenRouter 或本地 Ollama 模型达成明确目标。本项目面向需要可复现、与工具链原生集成的训练器工作流，而非仅依赖交互式内存编辑器的游戏安全研究人员、教育者与 QA 团队。
