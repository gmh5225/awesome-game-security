Cheat Agent is a cross-platform autonomous AI system for reverse engineering game memory and producing verified trainers for authorized offline single-player games and controlled test processes. It pairs a native C and C++20 engine for process attachment, multi-pass memory scanning, array-of-bytes pattern matching, and pointer-chain resolution with a Rust workspace that orchestrates sessions, SQLite-backed storage, and code generation. A five-stage closed-loop verifier discovers cheats, confirms in-game behavior, restarts the target to survive ASLR, builds standalone C++, Rust, or Cheat Engine table outputs, and re-runs the trainer to prove persistence. It runs either as a stdio Model Context Protocol server inside MCP-compatible coding agents or as a standalone CLI that drives OpenAI, Anthropic, OpenRouter, or local Ollama models toward explicit goals. The project targets game security researchers, educators, and QA teams who need reproducible, toolchain-native trainer workflows rather than interactive-only memory editors.
