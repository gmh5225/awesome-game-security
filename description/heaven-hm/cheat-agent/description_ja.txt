Cheat Agent は、ゲームメモリのリバースエンジニアリングと、許可されたオフラインシングルプレイゲームおよび管理下のテストプロセス向けに検証済みトレーナーを生成するための、クロスプラットフォーム自律型 AI システムです。プロセスアタッチ、複数パスメモリスキャン、バイト列パターンマッチ、ポインタチェーン解決を担うネイティブ C/C++20 エンジンと、セッション制御、SQLite 永続化、コード生成を行う Rust ワークスペースを組み合わせています。五段階の閉ループ検証器がチートを発見し、ゲーム内挙動を確認し、ASLR に耐えるためターゲットを再起動し、スタンドアロンの C++、Rust、または Cheat Engine テーブル出力を構築し、トレーナーを再実行して永続性を証明します。MCP 対応コーディングエージェント内の stdio Model Context Protocol サーバーとして動作するほか、OpenAI、Anthropic、OpenRouter、またはローカル Ollama モデルを明示的な目標に向けて駆動するスタンドアロン CLI としても利用できます。対話型メモリエディタだけでなく、再現可能でツールチェーンにネイティブに統合されたトレーナーワークフローを必要とするゲームセキュリティ研究者、教育者、QA チームを対象としています。
