Cheat Agent는 게임 메모리 리버스 엔지니어링과 허가된 오프라인 싱글플레이 게임 및 통제된 테스트 프로세스용 검증된 트레이너 생성을 위한 크로스 플랫폼 자율 AI 시스템입니다. 프로세스 부착, 다중 패스 메모리 스캔, 바이트 배열 패턴 매칭, 포인터 체인 해석을 담당하는 네이티브 C/C++20 엔진과 세션 오케스트레이션, SQLite 기반 저장, 코드 생성을 수행하는 Rust 워크스페이스를 결합합니다. 5단계 폐루프 검증기는 치트를 발견하고, 게임 내 동작을 확인하며, ASLR에 대응하기 위해 대상을 재시작하고, 독립 실행형 C++, Rust 또는 Cheat Engine 테이블 출력을 빌드한 뒤 트레이너를 다시 실행해 지속성을 입증합니다. MCP 호환 코딩 에이전트 내부의 stdio Model Context Protocol 서버로 동작하거나, OpenAI, Anthropic, OpenRouter 또는 로컬 Ollama 모델을 명시적 목표로 구동하는 독립 CLI로도 실행할 수 있습니다. 대화형 메모리 에디터만이 아니라 재현 가능하고 툴체인에 네이티브하게 맞는 트레이너 워크플로가 필요한 게임 보안 연구자, 교육자, QA 팀을 대상으로 합니다.
