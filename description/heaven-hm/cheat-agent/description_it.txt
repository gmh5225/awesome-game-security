Cheat Agent è un sistema di IA autonomo multipiattaforma per il reverse engineering della memoria dei giochi e la produzione di trainer verificati per giochi single-player offline autorizzati e processi di test controllati. Abbina un motore nativo C/C++20 per l’attach ai processi, la scansione memoria multipassaggio, il pattern matching su array di byte e la risoluzione di catene di puntatori a un workspace Rust che orchestra sessioni, persistenza SQLite e generazione di codice. Un verificatore a loop chiuso in cinque fasi scopre i cheat, conferma il comportamento in gioco, riavvia il target per sopravvivere all’ASLR, costruisce output autonomi in C++, Rust o tabelle Cheat Engine e riesegue il trainer per dimostrare la persistenza. Può essere eseguito come server Model Context Protocol stdio all’interno di agenti di coding compatibili MCP o come CLI autonoma che guida modelli OpenAI, Anthropic, OpenRouter o Ollama locali verso obiettivi espliciti. Il progetto è rivolto a ricercatori di sicurezza dei giochi, docenti e team QA che necessitano di workflow di trainer riproducibili e nativi della toolchain piuttosto che di editor di memoria solo interattivi.
