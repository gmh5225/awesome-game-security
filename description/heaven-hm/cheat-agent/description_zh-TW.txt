Cheat Agent 是一款跨平台自主 AI 系統，用於逆向分析遊戲記憶體，並為經授權的單機離線遊戲及受控測試程序產生經驗證的訓練器。它將用於程序附加、多遍記憶體掃描、位元組陣列模式比對與指標鏈解析的原生 C/C++20 引擎，與負責工作階段編排、SQLite 持久化儲存及程式碼產生的 Rust 工作區相結合。五階段閉環驗證器探索作弊項、確認遊戲內行為、重新啟動目標程序以因應 ASLR、建置獨立的 C++、Rust 或 Cheat Engine 表輸出，並重新執行訓練器以證明持久性。它既可作為標準輸入輸出 Model Context Protocol 伺服器運行於相容 MCP 的程式設計代理中，也可作為獨立 CLI，驅動 OpenAI、Anthropic、OpenRouter 或本機 Ollama 模型達成明確目標。本專案面向需要可重現、與工具鏈原生整合的訓練器工作流程，而非僅依賴互動式記憶體編輯器的遊戲安全研究人員、教育者與 QA 團隊。
