Cheat Agent — автономная кроссплатформенная система ИИ для реверс-инжиниринга памяти игр и создания проверенных тренеров для авторизованных офлайн-одиночных игр и контролируемых тестовых процессов. Она сочетает нативный движок на C/C++20 для подключения к процессам, многопроходного сканирования памяти, поиска по шаблонам массивов байтов и разрешения цепочек указателей с рабочим пространством на Rust, которое управляет сессиями, хранением в SQLite и генерацией кода. Пятиступенчатый верификатор с замкнутым циклом обнаруживает читы, подтверждает поведение в игре, перезапускает цель для устойчивости к ASLR, собирает автономные выходные данные на C++, Rust или таблицы Cheat Engine и повторно запускает тренер для доказательства устойчивости. Работает либо как stdio-сервер Model Context Protocol внутри MCP-совместимых coding-агентов, либо как автономный CLI, направляющий модели OpenAI, Anthropic, OpenRouter или локальный Ollama к явным целям. Проект ориентирован на исследователей безопасности игр, преподавателей и QA-команды, которым нужны воспроизводимые, нативные для toolchain рабочие процессы тренеров, а не только интерактивные редакторы памяти.
