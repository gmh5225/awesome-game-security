Cheat Agent es un sistema de IA autónomo multiplataforma para ingeniería inversa de la memoria de juegos y la producción de trainers verificados para juegos single-player offline autorizados y procesos de prueba controlados. Combina un motor nativo en C/C++20 para adjuntar procesos, escaneo de memoria multipaso, coincidencia de patrones de arrays de bytes y resolución de cadenas de punteros con un workspace en Rust que orquesta sesiones, almacenamiento respaldado en SQLite y generación de código. Un verificador de bucle cerrado en cinco etapas descubre cheats, confirma el comportamiento en el juego, reinicia el objetivo para sobrevivir al ASLR, genera salidas autónomas en C++, Rust o tablas de Cheat Engine y vuelve a ejecutar el trainer para demostrar persistencia. Funciona como servidor Model Context Protocol por stdio dentro de agentes de codificación compatibles con MCP o como CLI independiente que dirige modelos de OpenAI, Anthropic, OpenRouter u Ollama local hacia objetivos explícitos. El proyecto está dirigido a investigadores de seguridad en juegos, educadores y equipos de QA que necesitan flujos de trabajo de trainers reproducibles e integrados en la toolchain en lugar de editores de memoria únicamente interactivos.
