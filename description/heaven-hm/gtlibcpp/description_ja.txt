GTLibCpp は C++17 ライブラリで、スコープ付きのプロセスメモリ操作とローカル JSON-RPC エージェントを提供し、テスト用プロセス向けに認可されたオフラインゲームトレーナーと自動化を構築できます。現行の gtlibcpp コアは型付き MemorySession の読み書き、ポインタチェーン解決、復元付き値フリーズ、監査とキルスイッチを備えたポリシーゲート、厳密な Cheat Engine 7.x チートテーブルパーサーを備え、Windows 専用バックエンドと名前付きパイプトランスポートが x86 および x64 で実ターゲットへの接続を扱います。後方互換のため、チートテーブル解析とデモトレーナーを含むレガシー GTLibc トレーナー層も残っていますが、サポート対象は gtlibcpp API です。CMake はクロスプラットフォームのコアと Windows 用ライブラリを別々にビルドし、例、回帰テスト、ドキュメントはオンライン不正ではなく、ゲームメモリ研究、トレーナー開発、ローカルセキュリティテスト向けです。
