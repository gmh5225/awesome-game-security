GTLibCpp 是一个 C++17 库，提供作用域内的进程内存操作以及本地 JSON-RPC 代理，用于针对测试进程构建经授权的离线游戏修改器与自动化工具。现代 gtlibcpp 核心提供带类型的 MemorySession 读写、指针链解析、可恢复的值冻结、带审计与紧急关停的策略门控，以及严格的 Cheat Engine 7.x 作弊表解析器；Windows 专用后端与命名管道传输则在 x86 与 x64 上处理真实目标进程的附加。旧版 GTLibc 修改器层（含作弊表解析与示例修改器）仍保留以兼容旧代码，但 gtlibcpp API 为官方支持路径。CMake 分别构建跨平台核心库与 Windows 库，并附带示例、回归测试与文档，面向游戏内存研究、修改器开发与本地安全测试，而非在线作弊。
