GTLibCpp 是一個 C++17 函式庫，提供作用域內的行程記憶體操作以及本機 JSON-RPC 代理，用於針對測試行程建構經授權的離線遊戲訓練器與自動化工具。現代 gtlibcpp 核心提供具型別的 MemorySession 讀寫、指標鏈解析、可還原的數值凍結、附稽核與緊急停止的策略閘門，以及嚴格的 Cheat Engine 7.x 作弊表解析器；Windows 專用後端與命名管道傳輸則在 x86 與 x64 上處理真實目標的附加。舊版 GTLibc 訓練器層（含作弊表解析與示範訓練器）仍保留以向後相容，但 gtlibcpp API 為官方支援路徑。CMake 分別建置跨平台核心與 Windows 函式庫，並附範例、迴歸測試與文件，面向遊戲記憶體研究、訓練器開發與本機安全測試，而非線上作弊。
