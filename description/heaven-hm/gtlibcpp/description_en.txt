GTLibCpp is a C++17 library that provides scoped process memory operations and a local JSON-RPC agent for building authorized offline game trainers and automation against test processes. The modern gtlibcpp core offers typed MemorySession reads and writes, pointer-chain resolution, value freezing with restore, policy gates with audit and kill-switch controls, and a strict Cheat Engine 7.x cheat-table parser, while a Windows-specific backend and named-pipe transport handle real target attachment on x86 and x64. A legacy GTLibc trainer layer with cheat-table parsing and demo trainers remains for backward compatibility but the gtlibcpp API is the supported path. CMake builds separate cross-platform core and Windows libraries, with examples, regression tests, and documentation oriented toward game memory research, trainer development, and local security testing rather than online cheating.
