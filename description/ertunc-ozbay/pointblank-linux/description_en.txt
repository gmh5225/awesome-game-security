Point Blank Linux is a standalone community launcher that runs the Zepetto and TAM Point Blank client on Linux using unmodified official game files and the native CheatBlocker anti-cheat, without bypassing or disabling protection. It is built in Rust with a Slint-based GUI and shell helpers, and it manages an isolated Wine prefix, a TLS-aligned Wine 11 or Wine-GE runner, and Winetricks provisioning for Visual C++ runtimes, DirectX 9 and 11 components, and Edge WebView2 for login. The project addresses game-specific compatibility needs such as 16-byte TLS alignment for DirectX 11, legacy D3DX9 shader DLLs for DirectX 9, Linux asset path symlinks, and verification that official CheatBlocker binaries remain intact. It targets players and researchers who want legitimate Linux play and a reproducible Wine environment while keeping official anti-cheat behavior, rather than cheat development or anti-cheat evasion.
