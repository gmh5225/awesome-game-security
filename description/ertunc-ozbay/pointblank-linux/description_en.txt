Point Blank Linux is a standalone community launcher that runs the Zepetto Point Blank client on Linux using unmodified official game files and the native CheatBlocker anti-cheat, without third-party game launchers or anti-cheat bypasses. It is implemented in Rust with a Slint-based GUI and shell provisioning scripts, and it manages an isolated Wine prefix, Winetricks runtime dependencies, and optional Wine-GE runner downloads. A custom Wine wrapper aligns 32-bit TLS allocations to 16 bytes so DirectX 11 and DirectX 9 modes run reliably, and it installs legacy D3DX9 components, MSVC redistributables, and Edge WebView2 for login. An integrity checker validates the official CheatBlocker bundle and fixes case-sensitive asset paths on Linux. It targets players and compatibility researchers who want legitimate Linux play with official anti-cheat rather than cheat development or evasion tooling.
