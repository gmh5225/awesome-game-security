Point Blank Linux は、変更していない公式ゲームファイルとネイティブの CheatBlocker アンチチートを用いて、Linux 上で Zepetto Point Blank クライアントを起動するスタンドアロンのコミュニティランチャーです。サードパーティのゲームランチャーやアンチチート回避は不要です。Rust で実装され、Slint ベースの GUI とシェルによるプロビジョニングスクリプトを備え、隔離された Wine プレフィックス、Winetricks のランタイム依存関係、任意の Wine-GE ランナーのダウンロードを管理します。カスタム Wine ラッパーは 32 ビット TLS の割り当てを 16 バイト境界に揃え、DirectX 11 と DirectX 9 モードを安定して動作させ、レガシー D3DX9 コンポーネント、MSVC 再頒布可能パッケージ、ログイン用の Edge WebView2 をインストールします。整合性チェッカーは公式 CheatBlocker バンドルを検証し、Linux 上の大文字小文字を区別するアセットパスを修正します。チート開発や回避ツールではなく、公式アンチチートによる正当な Linux プレイを求めるプレイヤーと互換性研究者向けです。
