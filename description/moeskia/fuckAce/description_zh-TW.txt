fuckAce 是一款 Windows 主控台公用程式，透過限制 CPU 使用率來降低 Tencent ACE 反作弊程序對系統的影響。此工具以 C 語言撰寫，使用 MinGW-w64 建置，會掃描 SGuard64.exe 與 SGuardSvc64.exe，並對每個相符的行程套用三項緩解措施：將行程優先順序降至 idle、將處理器親和性固定到最後一個邏輯 CPU，以及透過 ProcessPowerThrottling 啟用 EcoQoS。此工具在本地以系統管理員權限和 SeDebugPrivilege 執行，在格式化的主控台表格中顯示結果，並在 ACE 自我保護機制阻擋部分操作時會自動重試。它不會連接網路或修改磁碟上的檔案。此工具面向研究者與使用者，用於研究或緩解 Windows 系統上反作弊軟體的資源消耗。
