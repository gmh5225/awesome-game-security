fuckAce は、Tencent ACE 反チートプロセスの CPU 使用率を制限することで、システムへの影響を軽減する Windows コンソールユーティリティです。C 言語で記述され MinGW-w64 でビルドされており、SGuard64.exe と SGuardSvc64.exe をスキャンし、一致した各プロセスに 3 つの緩和策を適用します。プロセス優先度を idle に下げる、プロセッサアフィニティを最後の論理 CPU に固定する、ProcessPowerThrottling 経由で EcoQoS を有効にする、の 3 つです。このツールは管理者権限と SeDebugPrivilege を用いてローカルで実行され、整形されたコンソール表に結果を表示し、ACE の自己保護により一部の操作がブロックされた場合は自動的に再試行します。ネットワークには接続せず、ディスク上のファイルも変更しません。Windows 上の反チートによるリソース消費を調査または緩和する研究者やユーザー向けです。
