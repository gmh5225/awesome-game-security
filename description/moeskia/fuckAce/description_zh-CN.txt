fuckAce 是一款 Windows 控制台实用工具，通过限制 CPU 使用率来降低 Tencent ACE 反作弊进程对系统的影响。该工具使用 C 语言编写，基于 MinGW-w64 构建，会扫描 SGuard64.exe 和 SGuardSvc64.exe，并对每个匹配的进程应用三项缓解措施：将进程优先级降至 idle、将处理器亲和性固定到最后一个逻辑 CPU，以及通过 ProcessPowerThrottling 启用 EcoQoS。该工具在本地以管理员权限和 SeDebugPrivilege 运行，在格式化的控制台表格中显示结果，并在 ACE 自我保护机制阻止部分操作时会自动重试。它不会连接网络或修改磁盘上的文件。该工具面向研究者和用户，用于研究或缓解 Windows 系统上反作弊软件的资源消耗。
