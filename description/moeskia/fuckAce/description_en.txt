fuckAce is a Windows console utility that reduces the system impact of Tencent ACE anti-cheat processes by throttling their CPU usage. Written in C and built with MinGW-w64, it scans for SGuard64.exe and SGuardSvc64.exe and applies three mitigations to each match: lowering process priority to idle, pinning affinity to the last logical CPU, and enabling EcoQoS via ProcessPowerThrottling. The tool runs locally with administrator privileges and SeDebugPrivilege, displays results in a formatted console table, and automatically retries when ACE self-protection blocks some operations. It does not connect to the network or modify files on disk. It is aimed at researchers and users studying or mitigating anti-cheat resource consumption on Windows systems.
