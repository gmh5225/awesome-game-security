fuckAce는 Tencent ACE 안티치트 프로세스의 CPU 사용량을 제한하여 시스템 영향을 줄이는 Windows 콘솔 유틸리티입니다. C 언어로 작성되었으며 MinGW-w64로 빌드되며, SGuard64.exe와 SGuardSvc64.exe를 검색한 뒤 일치하는 각 프로세스에 세 가지 완화 조치를 적용합니다. 프로세스 우선순위를 idle로 낮추고, 프로세서 친화성을 마지막 논리 CPU에 고정하며, ProcessPowerThrottling을 통해 EcoQoS를 활성화합니다. 이 도구는 관리자 권한과 SeDebugPrivilege로 로컬에서 실행되며, 형식화된 콘솔 표에 결과를 표시하고 ACE 자기 보호 기능이 일부 작업을 차단할 때 자동으로 재시도합니다. 네트워크에 연결하거나 디스크의 파일을 수정하지 않습니다. Windows 시스템에서 안티치트의 리소스 소비를 연구하거나 완화하려는 연구자와 사용자를 대상으로 합니다.
