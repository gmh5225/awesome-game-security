FlashKit 是一款以 Termux 為基礎的 Android 圖形介面工具，可將已 root 的手機變成口袋型刷機站，透過 OTG 連接第二台裝置，無需 PC。專案主要以 Python 實作，搭配 shell 安裝腳本，經 Termux:GUI 介面驅動 adb 與 fastboot，提供即時日誌、確認步驟與可取消的工作。使用者可 sideload ROM 壓縮檔、刷寫分割區映像、分階段安裝 GSI、修復 adb 或 fastboot 連線、處理常見 recovery 黑屏，並在兩台手機上管理檔案（含壓縮檔內編輯）。專案提供一行式安裝、與簽章相符的 Termux:GUI 與 Termux:API 外掛安裝，以及 doctor、update、plugin 檢查等 CLI 輔助指令。面向需要在 Magisk 或 KernelSU root 手機上進行韌體救磚、sideload 與底層裝置維護的 Android 玩家、維護者與研究人員。
