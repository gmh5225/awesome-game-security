FlashKit is a Termux-based Android GUI that turns a rooted phone into a pocket flashing station for a second device connected over OTG, without needing a PC. It is implemented primarily in Python with shell installers and drives adb and fastboot through a Termux:GUI interface with live logs, confirmations, and cancelable jobs. Users can sideload ROM zips, flash partition images, run staged GSI installs, repair adb or fastboot links, fix common recovery black-screen issues, and manage files on both phones including in-archive zip editing. The project bundles one-line setup, signature-matched Termux:GUI and Termux:API plugin installation, and CLI helpers such as doctor, update, and plugin checks. It targets Android modders, maintainers, and researchers who need on-device firmware rescue, sideloading, and low-level device maintenance from Magisk or KernelSU rooted handsets.
