FlashKit 是一款基于 Termux 的 Android 图形界面工具，可将已 root 的手机变成口袋级刷机站，通过 OTG 连接第二台设备，无需 PC。项目主要用 Python 实现，配合 shell 安装脚本，经 Termux:GUI 界面驱动 adb 与 fastboot，提供实时日志、确认步骤和可取消的任务。用户可 sideload ROM 压缩包、刷写分区镜像、分阶段安装 GSI、修复 adb 或 fastboot 连接、处理常见 recovery 黑屏，并在两台手机上管理文件（含压缩包内编辑）。项目提供一行式安装、与签名匹配的 Termux:GUI 与 Termux:API 插件安装，以及 doctor、update、plugin 检查等 CLI 辅助命令。面向需要在 Magisk 或 KernelSU root 手机上进行固件救砖、sideload 与底层设备维护的 Android 玩家、维护者与研究人员。
