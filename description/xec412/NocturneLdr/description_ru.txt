Nocturne — исследовательский загрузчик shellcode для Windows x64, созданный для формирования чистых, полностью подкреплённых стеков вызовов, неотличимых от легитимных потоков Windows при проверке EDR и форензике. Написан на C++20 с ассемблером MASM x64, без CRT, с разрешением API во время выполнения через PEB на основе compile-time хеширования DJB2 и маскировкой benign USER32 IAT. Ключевая техника — CET-совместимый stack spoofing: код внедряется в подписанный модуль, например windows.storage.dll, и регистрируются реальные donor unwind-метаданные, чтобы и программные обходы стека, и Intel CET shadow stacks проходили проверку как легитимные. Также включены обфускация сна Zilean с ROP-шифрованием образа и дублированием стека, маскирование кучи и обход EAF через чтения на основе гаджетов ntdll. Проект предназначен для исследователей offensive security, изучающих продвинутый stack spoofing, обход EDR и обнаружение целостности call stack.
