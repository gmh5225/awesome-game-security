Nocturne 是一款面向研究的 Windows x64 shellcode 加载器，旨在生成干净、完全有真实支撑的调用栈，在 EDR 与取证检查下与合法 Windows 线程难以区分。使用 C++20 与 MASM x64 汇编编写，无 CRT，通过编译期 DJB2 哈希基于 PEB 进行运行时 API 解析，并以良性 USER32 IAT 伪装。其核心技术是兼容 CET 的栈欺骗：将代码注入到 windows.storage.dll 等已签名模块，并注册真实的捐赠者 unwind 元数据，使软件栈遍历与 Intel CET 影子栈均校验为合法。项目还包含基于 ROP 的映像加密与栈复制的 Zilean sleep 混淆、堆掩码，以及利用 ntdll gadget 读取的 EAF 绕过。该项目面向研究高级栈欺骗、EDR 规避与调用栈完整性检测的攻防安全研究者。
