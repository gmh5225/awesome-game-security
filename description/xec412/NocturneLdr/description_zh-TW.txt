Nocturne 是一款以研究為導向的 Windows x64 shellcode 載入器，旨在產生乾淨、完全有真實支撐的呼叫堆疊，在 EDR 與鑑識檢查下與合法 Windows 執行緒難以區分。以 C++20 與 MASM x64 組語撰寫，無 CRT，透過編譯期 DJB2 雜湊基於 PEB 進行執行時期 API 解析，並以良性 USER32 IAT 偽裝。其核心技術是相容 CET 的堆疊偽裝：將程式碼注入 windows.storage.dll 等已簽章模組，並註冊真實的捐贈者 unwind 中繼資料，使軟體堆疊走訪與 Intel CET 影子堆疊均驗證為合法。專案亦包含以 ROP 為基礎的映像加密與堆疊複製的 Zilean sleep 混淆、堆積遮罩，以及利用 ntdll gadget 讀取的 EAF 繞過。此專案面向研究進階堆疊偽裝、EDR 規避與呼叫堆疊完整性偵測的攻防安全研究者。
