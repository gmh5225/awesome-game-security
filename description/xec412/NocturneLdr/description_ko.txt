Nocturne은 EDR 및 포렌식 검사에서 정상적인 Windows 스레드와 구별하기 어려운, 깨끗하고 완전히 뒷받침된 호출 스택을 생성하도록 설계된 연구 지향 Windows x64 shellcode 로더입니다. C++20과 MASM x64 어셈블리로 작성되었으며 CRT 없이, 컴파일 타임 DJB2 해싱을 통한 PEB 기반 런타임 API 해석과 무해한 USER32 IAT 위장을 사용합니다. 핵심 기법은 CET 호환 스택 스푸핑으로, windows.storage.dll과 같은 서명된 모듈에 코드를 주입하고 실제 도너 unwind 메타데이터를 등록하여 소프트웨어 스택 워크와 Intel CET 섀도 스택 모두가 정상으로 검증되게 합니다. ROP 기반 이미지 암호화와 스택 복제를 쓰는 Zilean sleep 난독화, 힙 마스킹, ntdll 가젯 기반 읽기를 이용한 EAF 우회도 포함합니다. 이 프로젝트는 고급 스택 스푸핑, EDR 회피, 호출 스택 무결성 탐지를 연구하는 공격적 보안 연구자를 대상으로 합니다.
