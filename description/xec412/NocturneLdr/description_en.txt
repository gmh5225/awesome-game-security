Nocturne is a research-oriented Windows x64 shellcode loader designed to produce clean, fully backed call stacks that appear indistinguishable from legitimate Windows threads under EDR and forensic inspection. Written in C++20 with MASM x64 assembly, it is built CRT-free with runtime PEB-based API resolution via compile-time DJB2 hashing and benign USER32 IAT camouflage. Its core technique is CET-compatible stack spoofing that injects code into a signed module such as windows.storage.dll and registers real donor unwind metadata so both software stack walks and Intel CET shadow stacks validate as legitimate. It also includes Zilean sleep obfuscation with ROP-based image encryption and stack duplication, heap masking, and an EAF bypass using ntdll gadget-based reads. The project targets offensive security researchers studying advanced stack spoofing, EDR evasion, and call-stack integrity detection.
