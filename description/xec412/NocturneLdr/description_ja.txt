Nocturne は、EDR やフォレンジック検査下で正当な Windows スレッドと区別しにくい、クリーンで完全に裏付けられたコールスタックを生成するよう設計された、研究志向の Windows x64 shellcode ローダーです。C++20 と MASM x64 アセンブリで記述され、CRT 非依存で、コンパイル時 DJB2 ハッシュによる PEB ベースの実行時 API 解決と、無害な USER32 IAT カモフラージュを備えます。中核技術は CET 互換のスタックスプーフィングで、windows.storage.dll などの署名済みモジュールにコードを注入し、本物のドナー unwind メタデータを登録することで、ソフトウェアのスタックウォークと Intel CET シャドウスタックの双方が正当と検証されます。ROP ベースのイメージ暗号化とスタック複製による Zilean sleep 難読化、ヒープマスキング、ntdll ガジェット読み取りによる EAF バイパスも含みます。本プロジェクトは、高度なスタックスプーフィング、EDR 回避、コールスタック完全性検出を研究する攻撃的セキュリティ研究者を対象としています。
