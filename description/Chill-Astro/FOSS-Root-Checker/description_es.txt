FOSS Root Checker es una aplicación Android de código abierto que comprueba el acceso de superusuario y la instalación de BusyBox en dispositivos con root o modificados. Está desarrollada con Kotlin y Jetpack Compose con theming Material, y ofrece variantes APK oficiales y sin conexión para que el usuario elija entre un actualizador integrado o una compilación sin red. La app escanea más de cuarenta rutas del sistema en busca de rastros de root, ejecuta comprobaciones como su -c id para confirmar privilegios en vivo y está orientada a configuraciones con Magisk, KernelSU, APatch y métodos de root heredados. Va dirigida a investigadores de seguridad móvil, usuarios avanzados y quien necesite una herramienta transparente y de bajo impacto para auditar el estado root en Android, útil también al estudiar cómo los juegos y los sistemas anti-trampas detectan entornos comprometidos.
