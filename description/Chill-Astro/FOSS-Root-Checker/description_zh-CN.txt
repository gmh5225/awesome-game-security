FOSS Root Checker 是一款开源 Android 应用，用于在已 root 或修改过的设备上验证超级用户权限及 BusyBox 是否已安装。该应用基于 Kotlin 与 Jetpack Compose 开发，采用 Material 主题，并提供官方版与离线版 APK，用户可在集成自助更新器与无需联网的构建之间选择。应用会扫描四十余条系统路径以查找 root 痕迹，并执行诸如 su -c id 等检查以实时确认权限，适用于 Magisk、KernelSU、APatch 及传统 root 方案。面向移动安全研究人员、高级用户及任何需要透明、低占用工具来审计 Android root 状态的人员；在研究游戏与反作弊系统如何检测受侵害环境时，该工具同样具有参考价值。
