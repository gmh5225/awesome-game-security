FOSS Root Checker 是一款開源 Android 應用程式，用於在已 root 或修改過的裝置上驗證超級使用者權限及 BusyBox 是否已安裝。該應用程式以 Kotlin 與 Jetpack Compose 建置，採用 Material 主題，並提供官方版與離線版 APK，使用者可選擇整合自助更新器或無需連網的建置。應用程式會掃描四十多條系統路徑以尋找 root 痕跡，並執行諸如 su -c id 等檢查以即時確認權限，適用於 Magisk、KernelSU、APatch 及傳統 root 方案。面向行動安全研究人員、進階使用者，以及任何需要透明、低佔用工具來稽核 Android root 狀態的人；在研究遊戲與反作弊系統如何偵測受侵害環境時，此工具同樣具有參考價值。
