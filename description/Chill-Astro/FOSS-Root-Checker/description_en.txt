FOSS Root Checker is an open-source Android application that verifies superuser access and BusyBox installation on rooted or modified devices. It is built with Kotlin and Jetpack Compose using Material theming, and ships as official and offline APK variants so users can choose between an integrated self-updater or a network-free build. The app scans more than forty system paths for root traces, runs checks such as su -c id for live privilege confirmation, and targets setups using Magisk, KernelSU, APatch, and legacy rooting methods. It is aimed at mobile security researchers, power users, and anyone who needs a transparent, low-footprint tool to audit Android root state, which is also useful context when studying how games and anti-cheat systems detect compromised environments.
