FOSS Root Checker は、root 化または改変されたデバイス上でスーパーユーザー権限と BusyBox のインストールを検証するオープンソースの Android アプリです。Kotlin と Jetpack Compose、Material テーマで構築され、公式 APK とオフライン APK のバリアントを提供しており、統合型セルフアップデーター付きか、ネットワーク不要のビルドかを選べます。40 以上のシステムパスをスキャンして root の痕跡を探し、su -c id などのチェックで実行時の権限を確認し、Magisk、KernelSU、APatch および従来の root 手法向けに設計されています。モバイルセキュリティ研究者、パワーユーザー、Android の root 状態を透明かつ軽量に監査したいユーザー向けで、ゲームやアンチチートが侵害された環境をどう検出するかを調べる際の文脈としても有用です。
