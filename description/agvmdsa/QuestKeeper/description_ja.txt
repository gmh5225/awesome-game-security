Questkeeper は AdventureQuest Worlds 向けの非公式 Windows コンパニオンで、PC 上でゲームの TCP トラフィックを受動的に監視し、プレイ中にキャラクタープロフィール、派閥の評判、インベントリ情報を一つのダッシュボードにまとめて表示します。C# と .NET で実装され、Avalonia のデスクトップ UI を用い、Npcap でライブパケットキャプチャを行い、フレーム解析、TCP ストリームの再構成、ローカル LiteDB による永続化に支えられた構造化ゲームデータ抽出を通じてサーバーメッセージをデコードします。ゲームに対する操作は読み取り専用で、クライアントからサーバーへのログインデータの無視、任意のデータ消去、外向きテレメトリなしなどプライバシー配慮の処理を行います。進行状況を一覧で追いたいプレイヤーや、MMORPG クライアントプロトコルの観察や Windows 上の受動的ネットワークトラフィック解析を学習・ツール化したい人に適しています。
