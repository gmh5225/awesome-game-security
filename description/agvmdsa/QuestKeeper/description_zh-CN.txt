Questkeeper 是 AdventureQuest Worlds 的非官方 Windows 伴侣工具，可在本机被动监听游戏的 TCP 流量，并在你游玩时于单一仪表板中展示角色档案、派系声望与背包信息。它以 C# 与 .NET 实现，采用 Avalonia 桌面界面，通过 Npcap 进行实时抓包，并借助帧解析、TCP 流重组与结构化游戏数据提取（辅以本地 LiteDB 持久化）解码服务端消息。对游戏仅为只读访问，并注重隐私，例如忽略客户端到服务器的登录数据、可选的数据清除，以及不向外部发送遥测。适合希望集中追踪进度的玩家，以及研究或开发 MMORPG 客户端协议观察与 Windows 上被动网络流量分析的人士。
