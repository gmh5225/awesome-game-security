Questkeeper is an unofficial Windows companion for AdventureQuest Worlds that passively listens to the game’s TCP traffic on your PC and presents character profile, faction reputation, and inventory information in a single dashboard while you play. It is implemented in C# on .NET with an Avalonia desktop UI, uses Npcap for live packet capture, and decodes server messages through frame parsing, TCP stream reassembly, and structured game-data extraction backed by local LiteDB persistence. Operation is read-only toward the game, with privacy-minded handling such as ignoring client-to-server login data, optional data forgetting, and no outbound telemetry. It suits players who want consolidated progress tracking and anyone studying or tooling around MMORPG client protocol observation and passive network traffic analysis on Windows.
