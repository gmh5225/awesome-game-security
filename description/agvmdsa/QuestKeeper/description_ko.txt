Questkeeper는 AdventureQuest Worlds용 비공식 Windows 동반 도구로, PC에서 게임의 TCP 트래픽을 수동적으로 수신하며 플레이 중 캐릭터 프로필, 세력 평판, 인벤토리 정보를 하나의 대시보드에 보여 줍니다. C#과 .NET으로 구현되었으며 Avalonia 데스크톱 UI를 사용하고, Npcap으로 실시간 패킷 캡처를 하며 프레임 파싱, TCP 스트림 재조립, 로컬 LiteDB 영속화를 뒷받침하는 구조화된 게임 데이터 추출을 통해 서버 메시지를 디코딩합니다. 게임에 대한 동작은 읽기 전용이며, 클라이언트에서 서버로의 로그인 데이터 무시, 선택적 데이터 삭제, 외부 원격 측정 없음 등 개인정보를 고려한 처리를 합니다. 진행 상황을 한곳에서 추적하려는 플레이어와 MMORPG 클라이언트 프로토콜 관찰 및 Windows에서의 수동 네트워크 트래픽 분석을 연구하거나 도구로 다루려는 사람에게 적합합니다.
