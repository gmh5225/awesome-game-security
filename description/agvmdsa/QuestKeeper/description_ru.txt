Questkeeper — неофициальный Windows-компаньон для AdventureQuest Worlds, который пассивно прослушивает TCP-трафик игры на вашем ПК и во время игры показывает профиль персонажа, репутацию фракций и инвентарь на единой панели. Реализован на C# и .NET с настольным интерфейсом Avalonia, использует Npcap для захвата пакетов в реальном времени и декодирует сообщения сервера через разбор кадров, сборку TCP-потоков и структурированное извлечение игровых данных с локальным хранением в LiteDB. Работа с игрой только для чтения, с учётом конфиденциальности: игнорирование данных входа клиент–сервер, опциональное удаление данных и отсутствие исходящей телеметрии. Подходит игрокам, которым нужен сводный учёт прогресса, а также тем, кто изучает или создаёт инструменты для наблюдения за клиентским протоколом MMORPG и пассивного анализа сетевого трафика в Windows.
