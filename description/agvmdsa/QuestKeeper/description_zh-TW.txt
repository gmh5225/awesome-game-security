Questkeeper 是 AdventureQuest Worlds 的非官方 Windows 伴侶工具，可在本機被動監聽遊戲的 TCP 流量，並在你遊玩時於單一儀表板中呈現角色檔案、派系聲望與背包資訊。它以 C# 與 .NET 實作，採用 Avalonia 桌面介面，透過 Npcap 進行即時封包擷取，並藉由幀解析、TCP 串流重組與結構化遊戲資料擷取（輔以本地 LiteDB 持久化）解碼伺服端訊息。對遊戲僅為唯讀存取，並注重隱私，例如忽略用戶端到伺服器的登入資料、可選的資料清除，以及不向外部傳送遙測。適合希望集中追蹤進度的玩家，以及研究或開發 MMORPG 用戶端協定觀察與 Windows 上被動網路流量分析的人士。
