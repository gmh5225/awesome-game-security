RX25 is a hardware and software stack for high-throughput PCIe DMA reads of host physical memory, aimed at researchers who need out-of-band memory access from an FPGA card. The design spans custom SystemVerilog RTL with Vivado build flows, a Windows kernel driver with batched capture, transport, snapshot, and completion-queue interfaces, and a LeechCore device plugin on the analysis machine. It integrates Corundum-style 25G Ethernet and deep PCIe TLP and BAR plumbing for ordered reads, sessions, and diagnostics. The repository is suited to game security, anti-cheat research, forensic imaging, and reverse engineering workflows that depend on reliable DMA-based memory acquisition rather than in-process hooks.
