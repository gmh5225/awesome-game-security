Plugin per Binary Ninja che si connette a un repository Ghidra Server e sincronizza l'analisi di reverse engineering tra Binary Ninja e Ghidra sullo stesso binario. Utilizza un plugin per barra laterale in C++ e Qt6 che comunica con un sottoprocesso bridge Java 17 tramite un protocollo JSON TCP locale, mentre il bridge mantiene la connessione RMI al Ghidra Server. La sincronizzazione bidirezionale copre simboli, nomi di funzioni, commenti, firme, parametri, tipi di dati, equivalenze, segnalibri ed elementi di dati tipizzati, così i team possono importare il lavoro di progetto Ghidra in Binary Ninja o inviare indietro le modifiche senza copia e incolla manuale. Il percorso di scrittura applica gli aggiornamenti tramite le API di modello del programma di alto livello di Ghidra per evitare la corruzione del database. È rivolto a ingegneri del reverse engineering e ricercatori di sicurezza dei giochi che vogliono combinare il flusso di lavoro di Binary Ninja con repository collaborativi Ghidra Server.
