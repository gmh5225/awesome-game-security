Plugin Binary Ninja qui se connecte à un dépôt Ghidra Server et synchronise l'analyse de rétro-ingénierie entre Binary Ninja et Ghidra sur le même binaire. Il utilise un plugin de barre latérale C++ et Qt6 qui communique avec un sous-processus pont Java 17 via un protocole JSON TCP local, tandis que le pont maintient la connexion RMI au Ghidra Server. La synchronisation bidirectionnelle couvre les symboles, noms de fonctions, commentaires, signatures, paramètres, types de données, équivalences, signets et éléments de données typés, afin que les équipes puissent importer le travail de projet Ghidra dans Binary Ninja ou renvoyer les modifications sans copier-coller manuel. Le chemin d'écriture applique les mises à jour via les API de modèle de programme de haut niveau de Ghidra pour éviter la corruption de la base de données. Il s'adresse aux ingénieurs en rétro-ingénierie et aux chercheurs en sécurité des jeux qui souhaitent combiner le flux de travail de Binary Ninja avec des dépôts collaboratifs Ghidra Server.
