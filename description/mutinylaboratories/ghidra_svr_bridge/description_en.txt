A Binary Ninja plugin that connects to a Ghidra Server repository and synchronizes reverse-engineering analysis between Binary Ninja and Ghidra on the same binary. It uses a C++ and Qt6 sidebar plugin that talks to a Java 17 bridge subprocess over a local TCP JSON protocol, while the bridge maintains the Ghidra Server RMI connection. Bidirectional sync covers symbols, function names, comments, signatures, parameters, data types, equates, bookmarks, and typed data items, so teams can import Ghidra project work into Binary Ninja or check changes back without manual copy-paste. The write path applies updates through Ghidra’s high-level program-model APIs to avoid database corruption. It is aimed at reverse engineers and game security researchers who want to combine Binary Ninja’s workflow with collaborative Ghidra Server repositories.
