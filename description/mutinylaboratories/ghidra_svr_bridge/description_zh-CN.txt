Binary Ninja 插件，用于连接 Ghidra Server 仓库，并在 Binary Ninja 与 Ghidra 之间对同一二进制文件同步逆向工程分析结果。它采用基于 C++ 和 Qt6 的侧边栏插件，通过本地 TCP JSON 协议与 Java 17 桥接子进程通信，而桥接进程负责维护与 Ghidra Server 的 RMI 连接。双向同步涵盖符号、函数名、注释、签名、参数、数据类型、等值定义、书签以及带类型的数据项，使团队可以将 Ghidra 项目工作导入 Binary Ninja，或将更改回传，而无需手动复制粘贴。写入路径通过 Ghidra 的高级程序模型 API 应用更新，以避免数据库损坏。面向希望将 Binary Ninja 工作流与协作式 Ghidra Server 仓库结合使用的逆向工程师与游戏安全研究人员。
