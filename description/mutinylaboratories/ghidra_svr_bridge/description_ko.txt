Binary Ninja 플러그인으로, Ghidra Server 저장소에 연결하여 동일한 바이너리에 대한 Binary Ninja와 Ghidra 간 역공학 분석을 동기화합니다. C++ 및 Qt6 사이드바 플러그인이 로컬 TCP JSON 프로토콜을 통해 Java 17 브리지 하위 프로세스와 통신하고, 브리지가 Ghidra Server RMI 연결을 유지합니다. 양방향 동기화는 심볼, 함수 이름, 주석, 시그니처, 매개변수, 데이터 타입, 등가(equate), 북마크, 타입이 지정된 데이터 항목을 포함하며, 팀은 Ghidra 프로젝트 작업을 Binary Ninja로 가져오거나 수동 복사-붙여넣기 없이 변경 사항을 되돌려 보낼 수 있습니다. 쓰기 경로는 Ghidra의 고수준 program-model API를 통해 업데이트를 적용하여 데이터베이스 손상을 방지합니다. Binary Ninja 워크플로와 협업용 Ghidra Server 저장소를 함께 사용하려는 역공학자 및 게임 보안 연구자를 대상으로 합니다.
