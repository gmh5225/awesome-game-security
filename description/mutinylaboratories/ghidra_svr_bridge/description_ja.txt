Binary Ninja プラグインで、Ghidra Server リポジトリに接続し、同一バイナリに対する Binary Ninja と Ghidra 間のリバースエンジニアリング分析を同期します。C++ と Qt6 のサイドバープラグインが、ローカルの TCP JSON プロトコル経由で Java 17 のブリッジ子プロセスと通信し、ブリッジが Ghidra Server の RMI 接続を維持します。双方向同期はシンボル、関数名、コメント、シグネチャ、パラメータ、データ型、等値、ブックマーク、型付きデータ項目をカバーし、チームは Ghidra プロジェクトの作業を Binary Ninja に取り込んだり、変更を手動コピー＆ペーストなしで反映し返したりできます。書き込みパスは Ghidra の高レベル program-model API を通じて更新を適用し、データベースの破損を防ぎます。Binary Ninja のワークフローと共同作業向け Ghidra Server リポジトリを組み合わせたいリバースエンジニアおよびゲームセキュリティ研究者向けです。
