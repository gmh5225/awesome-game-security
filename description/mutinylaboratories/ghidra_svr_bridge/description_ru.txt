Плагин для Binary Ninja, который подключается к репозиторию Ghidra Server и синхронизирует результаты реверс-инжиниринга между Binary Ninja и Ghidra для одного и того же бинарного файла. Он использует боковую панель на C++ и Qt6, которая обменивается данными с дочерним процессом-мостом на Java 17 по локальному протоколу TCP JSON, в то время как мост поддерживает RMI-подключение к Ghidra Server. Двунаправленная синхронизация охватывает символы, имена функций, комментарии, сигнатуры, параметры, типы данных, эквиваленты (equates), закладки и типизированные элементы данных, чтобы команды могли импортировать работу из проектов Ghidra в Binary Ninja или отправлять изменения обратно без ручного копирования. Путь записи применяет обновления через высокоуровневые API модели программы Ghidra, чтобы избежать повреждения базы данных. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности игр, которые хотят совместить рабочий процесс Binary Ninja с совместными репозиториями Ghidra Server.
