Complemento de Binary Ninja que se conecta a un repositorio de Ghidra Server y sincroniza el análisis de ingeniería inversa entre Binary Ninja y Ghidra sobre el mismo binario. Utiliza un complemento de barra lateral en C++ y Qt6 que se comunica con un subproceso puente en Java 17 mediante un protocolo JSON TCP local, mientras el puente mantiene la conexión RMI con Ghidra Server. La sincronización bidireccional abarca símbolos, nombres de funciones, comentarios, firmas, parámetros, tipos de datos, equivalencias, marcadores y elementos de datos tipados, de modo que los equipos pueden importar el trabajo de proyectos Ghidra a Binary Ninja o devolver cambios sin copiar y pegar manualmente. La ruta de escritura aplica las actualizaciones a través de las API de modelo de programa de alto nivel de Ghidra para evitar la corrupción de la base de datos. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad de juegos que desean combinar el flujo de trabajo de Binary Ninja con repositorios colaborativos de Ghidra Server.
