VMP_DEVIRT 是一套面向研究的集成框架，用于分析、脱壳并对采用商业虚拟机混淆器（如 VMProtect 3.x、Themida 3.x 和 Tigress）保护的 64 位二进制进行去虚拟化。它融合选定指令攻击（Chosen-Instruction Attack）知识提取、VPC 敏感符号追踪、基于 Triton 的混合具体/符号执行，以及混合布尔算术（Mixed Boolean-Arithmetic）化简，从受保护代码中恢复 handler 语义与虚拟控制流。AETHER 流水线执行代数预归约、虚拟栈消除，并通过 LLVM IR 提升与编译器优化 pass 生成可读的原生 x64 代码。实现以 Python 与 C++ 为主，含 CMake 构建组件、Z3 SMT 证明，以及用于 CIA 自动化、基准数据集和相关学术工具链的可选子模块。面向需要自动化去混淆软件保护与防篡改场景中虚拟化壳的逆向工程师、恶意软件分析师与安全研究人员。
