VMP_DEVIRT — интегрированный исследовательский каркас для анализа, распаковки и девиртуализации 64-битных бинарников, защищённых коммерческими обфускаторами на основе виртуальных машин, такими как VMProtect 3.x, Themida 3.x и Tigress. Он сочетает извлечение знаний методом Chosen-Instruction Attack, VPC-чувствительное символическое трассирование, konkolic-выполнение на базе Triton и упрощение Mixed Boolean-Arithmetic для восстановления семантики обработчиков и виртуального потока управления из защищённого кода. Конвейер AETHER выполняет алгебраическую предварительную редукцию, устранение виртуального стека и подъём в LLVM IR с проходами оптимизации компилятора для получения читаемого нативного x64-кода. Реализация в основном на Python и C++, с компонентами, собираемыми CMake, доказательствами Z3 SMT и опциональными подмодулями для автоматизации CIA, наборов данных для бенчмарков и связанных академических toolchain. Предназначен для reverse-инженеров, аналитиков вредоносного ПО и исследователей безопасности, которым нужна автоматическая деобфускация виртуализирующих упаковщиков в сценариях защиты ПО и противодействия вмешательству.
