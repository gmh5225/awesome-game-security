VMP_DEVIRT は、VMProtect 3.x、Themida 3.x、Tigress などの商用 VM ベース難読化で保護された 64 ビットバイナリの解析、アンパック、デバーチャライズを行う統合研究フレームワークです。Chosen-Instruction Attack による知識抽出、VPC 敏感なシンボリックトレース、Triton ベースのコンコリック実行、Mixed Boolean-Arithmetic 簡約を組み合わせ、保護コードからハンドラ意味論と仮想制御フローを復元します。AETHER パイプラインは代数的事前縮約、仮想スタック除去、LLVM IR リフティングとコンパイラ最適化パスにより、読みやすいネイティブ x64 コードを生成します。実装は主に Python と C++ で、CMake ビルドコンポーネント、Z3 SMT 証明、CIA 自動化・ベンチマークデータセット・関連学術ツールチェーン用のオプションサブモジュールを含みます。ソフトウェア保護や改ざん防止で使われる仮想化パッカーの自動デオブフスケーションが必要なリバースエンジニア、マルウェアアナリスト、セキュリティ研究者向けです。
