VMP_DEVIRT는 VMProtect 3.x, Themida 3.x, Tigress 같은 상용 VM 기반 난독화로 보호된 64비트 바이너리를 분석·언패킹·디버추얼라이즈하는 통합 연구 프레임워크입니다. Chosen-Instruction Attack 기반 지식 추출, VPC 민감 심볼릭 추적, Triton 기반 konkolic 실행, Mixed Boolean-Arithmetic 단순화를 결합해 보호된 코드에서 핸들러 의미와 가상 제어 흐름을 복구합니다. AETHER 파이프라인은 대수 사전 축약, 가상 스택 제거, LLVM IR 리프팅과 컴파일러 최적화 패스로 읽기 쉬운 네이티브 x64 코드를 생성합니다. 구현은 주로 Python과 C++이며, CMake 빌드 구성 요소, Z3 SMT 증명, CIA 자동화·벤치마크 데이터셋·관련 학술 툴체인용 선택적 서브모듈을 포함합니다. 소프트웨어 보호 및 변조 방지 시나리오에서 사용되는 가상화 패커의 자동 디난독화가 필요한 리버스 엔지니어, 멀웨어 분석가, 보안 연구자를 대상으로 합니다.
