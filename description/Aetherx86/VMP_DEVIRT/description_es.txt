VMP_DEVIRT es un marco de investigación integrado para analizar, desempaquetar y desvirtualizar binarios de 64 bits protegidos por ofuscadores comerciales basados en máquinas virtuales, como VMProtect 3.x, Themida 3.x y Tigress. Combina extracción de conocimiento mediante Chosen-Instruction Attack, trazado simbólico sensible al VPC, ejecución concolica basada en Triton y simplificación Mixed Boolean-Arithmetic para recuperar la semántica de los handlers y el flujo de control virtual del código protegido. La canalización AETHER realiza prereducción algebraica, eliminación de pila virtual y elevación a LLVM IR con pasadas de optimización del compilador para emitir código nativo x64 legible. La implementación es principalmente en Python y C++, con componentes construidos con CMake, pruebas Z3 SMT y submódulos opcionales para automatización CIA, conjuntos de datos de referencia y toolchains académicas relacionadas. Está dirigido a ingenieros inversores, analistas de malware e investigadores de seguridad que necesitan desofuscación automatizada de packers de virtualización usados en protección de software y escenarios anti-manipulación.
