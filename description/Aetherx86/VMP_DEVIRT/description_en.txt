VMP_DEVIRT is an integrated research framework for analyzing, unpacking, and devirtualizing 64-bit binaries protected by commercial VM-based obfuscators such as VMProtect 3.x, Themida 3.x, and Tigress. It combines Chosen-Instruction Attack knowledge extraction, VPC-sensitive symbolic tracing, Triton-based concolic execution, and Mixed Boolean-Arithmetic simplification to recover handler semantics and virtual control flow from protected code. The AETHER pipeline performs algebraic pre-reduction, virtual stack elimination, and LLVM IR lifting with compiler optimization passes to emit readable native x64 code. Implementation is primarily in Python and C++, with CMake-built components, Z3 SMT proofs, and optional submodules for CIA automation, benchmarking datasets, and related academic toolchains. It is aimed at reverse engineers, malware analysts, and security researchers who need automated deobfuscation of virtualization packers used in software protection and anti-tamper scenarios.
