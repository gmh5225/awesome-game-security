VMP_DEVIRT 是一套整合式研究框架，用於分析、脫殼並對採用商業虛擬機混淆器（如 VMProtect 3.x、Themida 3.x 與 Tigress）保護的 64 位元二進位進行去虛擬化。它結合 Chosen-Instruction Attack 知識擷取、VPC 敏感符號追蹤、以 Triton 為基礎的混合具體/符號執行，以及 Mixed Boolean-Arithmetic 化簡，從受保護程式碼中還原 handler 語意與虛擬控制流程。AETHER 管線執行代數預歸約、虛擬堆疊消除，並透過 LLVM IR 提升與編譯器最佳化 pass 產生可讀的原生 x64 程式碼。實作以 Python 與 C++ 為主，含 CMake 建置元件、Z3 SMT 證明，以及用於 CIA 自動化、基準資料集與相關學術工具鏈的可選子模組。面向需要自動化去混淆軟體保護與防篡改情境中虛擬化加殼工具的逆向工程師、惡意軟體分析師與安全研究人員。
