REA（Reverse Engineer Anything）は、ソースコードなしでソフトウェアを調査するための統合ツールキットを AI コーディングエージェントに接続する Model Context Protocol サーバーおよび CLI です。主に Node.js 上の TypeScript で実装され、Hopper、Ghidra、IDA Pro、JADX、pwntools、mitmproxy などの外部アナライザーへブリッジします。ネイティブバイナリ、JavaScript および Electron アプリ、.NET アセンブリ、Web サイトとネットワークキャプチャ、Android APK、ファームウェアイメージ、プロセスのランタイム挙動、ELF レイアウトや記録されたクラッシュ証拠などのオフライン診断をサポートします。分析はローカルで実行され、明示的な根拠と限界を伴う結果を返すため、エージェントやターミナル利用者が機能を追跡し、挙動を説明し、再実装を導けます。バイナリ、マネージドコード、Web やモバイルアプリの深い可視性が必要なリバースエンジニア、セキュリティ研究者、分析・研究・第三者の挙動理解のための開発者を対象としています。
