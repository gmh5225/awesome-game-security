REA(Reverse Engineer Anything)는 소스 코드 없이 소프트웨어를 조사하기 위한 통합 툴킷을 AI 코딩 에이전트에 연결하는 Model Context Protocol 서버 및 CLI입니다. 주로 Node.js 위의 TypeScript로 구현되며 Hopper, Ghidra, IDA Pro, JADX, pwntools, mitmproxy 등 외부 분석기와 연동합니다. 네이티브 바이너리, JavaScript 및 Electron 앱, .NET 어셈블리, 웹사이트와 네트워크 캡처, Android APK, 펌웨어 이미지, 프로세스 런타임 동작, ELF 레이아웃 및 기록된 크래시 증거 같은 오프라인 진단을 지원합니다. 분석은 로컬에서 실행되며 명시적 근거와 한계가 포함된 결과를 반환해 에이전트나 터미널 사용자가 기능을 추적하고 동작을 설명하며 재구현을 안내할 수 있습니다. 바이너리, 관리 코드, 웹·모바일 애플리케이션에 대한 깊은 가시성이 필요한 리버스 엔지니어, 보안 연구자, 분석·연구·서드파티 동작 이해를 위한 개발자를 대상으로 합니다.
