REA（Reverse Engineer Anything）是一个 Model Context Protocol 服务器与 CLI，将 AI 编程代理连接到统一工具集，用于在无源代码的情况下调查软件。它主要用 TypeScript 在 Node.js 上实现，并桥接 Hopper、Ghidra、IDA Pro、JADX、pwntools、mitmproxy 等外部分析器。平台支持原生二进制、JavaScript 与 Electron 应用、.NET 程序集、网站与网络抓包、Android APK、固件镜像、进程运行时行为，以及 ELF 布局与记录的崩溃证据等相关离线诊断。分析在本地运行，返回附带明确证据与已知局限的结论，便于代理或终端用户追踪功能、解释行为并指导重新实现。面向逆向工程师、安全研究人员以及需要对二进制、托管代码与 Web 或移动应用进行深度可见性以进行分析、研究与理解第三方行为的开发者。
