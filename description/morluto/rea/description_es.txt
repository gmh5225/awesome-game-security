REA (Reverse Engineer Anything) es un servidor Model Context Protocol y una CLI que conecta agentes de codificación con IA a un conjunto de herramientas unificado para investigar software sin código fuente. Está implementado principalmente en TypeScript sobre Node.js, con puentes hacia Hopper, Ghidra, IDA Pro, JADX, pwntools, mitmproxy y otros analizadores externos. La plataforma admite binarios nativos, aplicaciones JavaScript y Electron, ensamblados .NET, sitios web y capturas de red, APK de Android, imágenes de firmware, comportamiento en tiempo de ejecución de procesos y diagnósticos offline relacionados, como el diseño ELF y evidencia registrada de fallos. El análisis se ejecuta de forma local y devuelve hallazgos respaldados por pruebas explícitas y limitaciones indicadas, de modo que agentes o usuarios de terminal puedan rastrear funciones, explicar el comportamiento y orientar la reimplementación. Está dirigido a ingenieros inversos, investigadores de seguridad y desarrolladores que necesitan visibilidad profunda sobre binarios, código administrado y aplicaciones web o móviles para análisis, investigación y comprensión del comportamiento de terceros.
