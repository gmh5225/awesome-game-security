REA（Reverse Engineer Anything）是一個 Model Context Protocol 伺服器與 CLI，將 AI 程式設計代理連接到統一工具集，用於在沒有原始碼的情況下調查軟體。它主要以 TypeScript 在 Node.js 上實作，並橋接 Hopper、Ghidra、IDA Pro、JADX、pwntools、mitmproxy 等外部分析器。平台支援原生二進位、JavaScript 與 Electron 應用、.NET 組件、網站與網路擷取、Android APK、韌體映像、程序執行階段行為，以及 ELF 配置與記錄的當機證據等相關離線診斷。分析在本機執行，回傳附有明確證據與已知限制的結論，方便代理或終端使用者追蹤功能、解釋行為並指導重新實作。面向逆向工程師、安全研究人員以及需要對二進位、受控程式碼與 Web 或行動應用進行深度可見性以進行分析、研究與理解第三方行為的開發者。
