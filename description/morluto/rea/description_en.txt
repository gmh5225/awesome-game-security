REA (Reverse Engineer Anything) is a Model Context Protocol server and CLI that connects AI coding agents to a unified toolkit for investigating software without source code. It is implemented primarily in TypeScript on Node.js, with bridges to Hopper, Ghidra, IDA Pro, JADX, pwntools, mitmproxy, and other external analyzers. The platform supports native binaries, JavaScript and Electron apps, .NET assemblies, websites and network captures, Android APKs, firmware images, process runtime behavior, and related offline diagnostics such as ELF layout and recorded crash evidence. Analysis runs locally and returns findings backed by explicit evidence and stated limitations, so agents or terminal users can trace features, explain behavior, and guide reimplementation. It targets reverse engineers, security researchers, and developers who need deep visibility into binaries, managed code, and web or mobile applications for analysis, research, and understanding third-party behavior.
