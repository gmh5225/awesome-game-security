Lenrete 是一款面向 Minecraft 26.2 的客户端 Fabric 实用工具与作弊客户端，提供模块化游戏内菜单，在战斗、移动、渲染、世界交互、玩家自动化和 HUD 等类别中包含数十项可配置功能。它基于 Java 25 编写，使用官方 Mojang mappings，包含 43 个通过注解发现的模块，例如 KillAura、ESP、Reach、Flight 以及基于数据包的 Blinker，并配有可主题化的点击 GUI、可自定义 HUD 叠加层、配置档案和聊天命令。其架构依赖少量 fail-soft Mixins、基于反射且支持 JSON 持久化的设置，以及用于叠加层的 2D 屏幕投影渲染。它面向单人游戏和私服实验，是研究客户端游戏修改、数据包操作，以及服务器端反作弊系统如何在公共服务器上检测或拦截常见作弊技术的实用参考。
