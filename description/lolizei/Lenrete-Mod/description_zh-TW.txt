Lenrete 是一款面向 Minecraft 26.2 的用戶端 Fabric 工具與作弊用戶端，提供模組化遊戲內選單，在戰鬥、移動、渲染、世界互動、玩家自動化與 HUD 等類別下包含數十項可設定功能。以 Java 25 撰寫，採用官方 Mojang mappings，內建 43 個以註解發現的模組，如 KillAura、ESP、Reach、Flight 及以封包為基礎的 Blinker，並提供可主題化的點擊 GUI、可自訂的 HUD 疊加層、設定檔與聊天指令。架構依賴少量 fail-soft Mixins、以反射驅動且支援 JSON 持久化的設定，以及用於疊加層的 2D 螢幕投影渲染。它適用於單人遊戲與私人伺服器實驗，可作為研究用戶端遊戲修改、封包操作，以及伺服器端反作弊系統如何在公開伺服器上偵測或阻擋常見作弊技術的實用參考。
