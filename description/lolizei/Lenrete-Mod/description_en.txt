Lenrete is a client-side Fabric utility and cheat client for Minecraft 26.2 that exposes a modular in-game menu with dozens of configurable features across combat, movement, rendering, world interaction, player automation, and HUD categories. Written in Java 25 against official Mojang mappings, it ships 43 annotation-discovered modules such as KillAura, ESP, Reach, Flight, and packet-based Blinker, backed by a themeable click GUI, customizable HUD overlays, config profiles, and chat commands. The architecture relies on a minimal set of fail-soft Mixins, reflection-driven settings with JSON persistence, and 2D screen-projected rendering for overlays. It is intended for singleplayer and private-server experimentation, making it a practical reference for studying client-side game modification, packet manipulation, and how server-side anti-cheat systems detect or block common cheat techniques on public servers.
