SPF Ghidra Pattern Helper est un script Ghidra basé sur Java qui génère et recherche des signatures d'octets directement dans un binaire chargé. Il fournit une interface graphique avec les onglets Pattern Generator et Pattern Finder, transformant les séquences d'instructions sélectionnées en modèles de type SPF, signatures hexadécimales masquées, modèles étendus basés sur des plages, et octets bruts compatibles avec le PatternFinder C++ de SPF-Framework. Le PatternEngine intégré prend en charge une syntaxe de recherche flexible incluant les jokers, plages d'octets, octets optionnels, alternances et masquage automatique des déplacements, ainsi qu'une vérification automatique optionnelle pour contrôler l'unicité des signatures. Conçu pour les ingénieurs en reverse engineering et les développeurs de mods de jeux, il simplifie le prototypage et les tests de signatures lors du développement de plugins pour des titres tels qu'American Truck Simulator et Euro Truck Simulator 2.
