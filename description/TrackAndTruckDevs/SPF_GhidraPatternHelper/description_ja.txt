SPF Ghidra Pattern Helper は、Java ベースの Ghidra スクリプトで、読み込んだバイナリ内でバイトシグネチャを直接生成・検索します。Pattern Generator と Pattern Finder タブを備えた GUI から、選択した命令列を SPF スタイルのテンプレートパターン、マスク付き16進シグネチャ、範囲ベースの拡張パターン、および SPF-Framework の C++ PatternFinder と互換性のある生バイトに変換できます。組み込みの PatternEngine は、ワイルドカード、バイト範囲、オプションバイト、交替、自動ディスプレースメントマスキングなど柔軟な検索構文をサポートし、シグネチャの一意性を確認するオプションの自動検証も提供します。リバースエンジニアやゲーム MOD 開発者向けに設計され、American Truck Simulator や Euro Truck Simulator 2 などのタイトル向けプラグイン開発におけるシグネチャのプロトタイピングとテストを効率化します。
