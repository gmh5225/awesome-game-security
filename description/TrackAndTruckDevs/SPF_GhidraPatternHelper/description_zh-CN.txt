SPF Ghidra Pattern Helper 是一款基于 Java 的 Ghidra 脚本，可在已加载的二进制文件中直接生成并搜索字节特征码。它提供带有 Pattern Generator 和 Pattern Finder 选项卡的图形界面，将选定的指令序列转换为 SPF 风格的模板模式、带掩码的十六进制特征码、基于范围的扩展模式，以及与 SPF-Framework 中 C++ PatternFinder 兼容的原始字节。内置的 PatternEngine 支持灵活的搜索语法，包括通配符、字节范围、可选字节、交替匹配和自动位移掩码，还可选自动验证以检查特征码的唯一性。该工具面向逆向工程师和游戏模组开发者，可简化在 American Truck Simulator 和 Euro Truck Simulator 2 等游戏插件开发过程中的特征码原型设计与测试工作。
