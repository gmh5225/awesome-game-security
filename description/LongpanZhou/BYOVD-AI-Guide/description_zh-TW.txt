BYOVD AI Guide 是一份面向教學的 Windows 核心驅動程式研究資料庫，並提供逐步方法論，用於發現暴露危險核心記憶體寫入原語的已簽署驅動程式。它彙整數百個採集的驅動程式二進位檔，附帶靜態稽核報告、去重與 blocklist 過濾閘道，以及用於從廠商安裝套件中收集、篩選並產生新候選清單的 PowerShell 工具。工作流程面向 AI 輔助分析：使用無頭 Ghidra 或 IDA 審查 IOCTL 與分派例程，隨後在可拋棄的 VMware 訪客機中以 WinDbg 做分診式概念驗證，而無需在宿主機上直接操作即時核心記憶體。文件與 agent 提示定義嚴重等級、稽核範圍，以及從驅動採集經 LOLDrivers 與 Microsoft blocklist 檢查到動態驗證的可重複循環。面向在受控實驗環境中研究 BYOVD 濫用、權限提升與核心攻擊面的安全研究人員、反作弊分析師與逆向工程師。
