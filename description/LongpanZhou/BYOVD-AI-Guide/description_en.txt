BYOVD AI Guide is an educational Windows kernel driver research corpus and step-by-step methodology for discovering signed drivers that expose dangerous kernel memory-write primitives. It bundles hundreds of harvested driver binaries with static audit reports, deduplication and blocklist gates, and PowerShell tooling to collect, filter, and manifest new candidates from vendor installers. The workflow is designed for AI-assisted analysis using headless Ghidra or IDA for IOCTL and dispatch review, followed by proof-of-concept verification in a disposable VMware guest with WinDbg triage, without touching live kernel memory on a host. Documentation and agent prompts define severity tiers, audit scope, and a repeatable loop from driver harvest through LOLDrivers and Microsoft blocklist checks to dynamic validation. It targets security researchers, anti-cheat analysts, and reverse engineers studying BYOVD abuse, privilege escalation, and kernel attack surface in controlled lab environments.
