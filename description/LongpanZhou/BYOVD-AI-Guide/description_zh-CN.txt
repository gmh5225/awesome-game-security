BYOVD AI Guide 是一份面向教学的 Windows 内核驱动研究资料库，并提供逐步方法论，用于发现暴露危险内核内存写入原语的已签名驱动。它汇集数百个采集的驱动二进制文件，附带静态审计报告、去重与 blocklist 过滤门控，以及用于从厂商安装包中收集、筛选并生成新候选清单的 PowerShell 工具。工作流面向 AI 辅助分析：使用无头 Ghidra 或 IDA 审查 IOCTL 与分发例程，随后在可丢弃的 VMware 来宾机中用 WinDbg 做分诊式概念验证，而无需在宿主机上直接操作实时内核内存。文档与 agent 提示定义严重等级、审计范围，以及从驱动采集经 LOLDrivers 与 Microsoft blocklist 检查到动态验证的可重复循环。面向在受控实验环境中研究 BYOVD 滥用、权限提升与内核攻击面的安全研究人员、反作弊分析师与逆向工程师。
