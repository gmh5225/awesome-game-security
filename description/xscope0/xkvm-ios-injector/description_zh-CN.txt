xKVM 是一款纯 Go 编写的命令行与 TUI 工具，用于通过向 IPA、TIPA 或 .app 软件包注入 tweak 并重新打包以生成正确的代码签名，从而实现 iOS 应用侧载。本项目是对 cyan/pyzule-rw 注入器的从零重写，并恢复了 Azule 的功能，支持 dylib 与 .deb 注入、tweak 提取、rootful、rootless 与 roothide 格式之间的越狱包转换，以及 App Store IPA 解密。它内嵌 ElleKit、CydiaSubstrate、Orion 等 hook 运行时，应用侧载修复补丁，通过 Canister 或 MobileAPT 从 Cydia 源获取软件包，并在安装前验证 bundle 完整性。该工具链采用纯 Go 的 Mach-O 操作与 Apple 格式的 ad-hoc 签名，以实现确定性、可复现的构建。面向需要修改侧载应用或研究注入代码如何在运行时加载的 iOS tweak 开发者、逆向工程师与安全研究人员。
