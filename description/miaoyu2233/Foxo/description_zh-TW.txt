Foxo 是一款適用於 Windows 的 PC 遊戲介面即時原位疊加翻譯工具：以 OCR 擷取螢幕文字，在不修改遊戲行程的前提下於原始介面上方呈現中文譯文。以 Python 實作，UI 採用 PySide6，畫面擷取使用 DXGI 或 mss，OCR 為 DirectML 加速的 Japan PP-OCRv4、WinRT 或 CPU 版 RapidOCR 混合堆疊，機器翻譯則透過相容 OpenAI 的串流 API。核心工程選擇包含可穿透點擊的透明疊加層、以 SetWindowDisplayAffinity 排除疊加層於螢幕擷取迴圈之外、可設定且支援模糊比對的遊戲術語包，以及以 SQLite 為後端的翻譯快取。對象為需要低延遲介面翻譯、且相對於會標記注入、記憶體存取與渲染掛鉤的內核反作弊系統盡量不具侵入性的日文及其他外語 PC 遊戲玩家與在地化人員。
