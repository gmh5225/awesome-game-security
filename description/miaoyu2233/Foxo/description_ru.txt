Foxo — переводчик с наложением в реальном времени поверх интерфейса PC-игр в Windows: захватывает текст на экране через OCR и выводит китайский перевод над исходным UI, не изменяя процесс игры. Реализован на Python: UI на PySide6, захват кадров через DXGI или mss, гибридный OCR-стек с DirectML-ускоренным Japan PP-OCRv4, WinRT или CPU RapidOCR, машинный перевод — через совместимые с OpenAI потоковые API. Ключевые решения: прозрачные оверлеи с прохождением кликов, SetWindowDisplayAffinity для исключения оверлея из циклов захвата экрана, настраиваемые игровые терминологические пакеты с нечётким сопоставлением и кэш переводов на SQLite. Инструмент для игроков и локализаторов японских и других иностранноязычных PC-игр, которым нужен низколатентный перевод UI при максимальной ненавязчивости по отношению к ядерным античитам, помечающим инъекции, доступ к памяти и перехват рендеринга.
