Foxo는 Windows용 PC 게임 UI 실시간 인플레이스 오버레이 번역 도구로, OCR로 화면 텍스트를 캡처하고 게임 프로세스를 수정하지 않은 채 원본 인터페이스 위에 중국어 번역을 렌더링한다. Python으로 구현되었으며 UI는 PySide6, 프레임 캡처는 DXGI 또는 mss, OCR은 DirectML 가속 Japan PP-OCRv4, WinRT 또는 CPU RapidOCR 하이브리드 스택, 기계 번역은 OpenAI 호환 API 스트리밍을 사용한다. 핵심 설계에는 클릭 통과 투명 오버레이, SetWindowDisplayAffinity로 화면 캡처 루프에서 오버레이 제외, 퍼지 매칭이 있는 설정 가능한 게임 용어 팩, SQLite 기반 번역 캐시가 포함된다. 주입, 메모리 접근, 렌더 후킹을 플래그하는 커널 안티치트에 비해 최대한 비침습적으로 낮은 지연의 UI 번역이 필요한 일본어 및 기타 외국어 PC 게임 플레이어와 현지화 담당자를 대상으로 한다.
