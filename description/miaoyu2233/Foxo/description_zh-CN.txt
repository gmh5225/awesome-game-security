Foxo 是一款面向 Windows PC 游戏界面的实时原地叠加翻译工具：通过 OCR 抓取屏幕文字，在不修改游戏进程的前提下于原界面之上渲染中文译文。实现上采用 Python，界面为 PySide6，帧捕获使用 DXGI 或 mss，OCR 为 DirectML 加速的 Japan PP-OCRv4、WinRT 或 CPU 版 RapidOCR 的混合栈，机器翻译则对接兼容 OpenAI 的流式 API。核心设计包括可穿透点击的透明叠加层、用 SetWindowDisplayAffinity 使叠加层不被录屏循环收录、可配置且支持模糊匹配的游戏术语包，以及基于 SQLite 的翻译缓存。面向需要低延迟界面翻译、且希望相对内核反作弊（会标记注入、内存访问与渲染挂钩）而言尽可能不侵入的日本语及其他外语 PC 游戏玩家与本地化人员。
