Foxo は、Windows 向けの PC ゲーム UI 用リアルタイム・インプレイス・オーバーレイ翻訳ツールで、OCR で画面上の文字を取得し、ゲームプロセスを変更せずに元のインターフェース上へ中国語訳を描画する。Python 実装で、UI は PySide6、フレーム取得は DXGI または mss、OCR は DirectML 加速の Japan PP-OCRv4、WinRT、または CPU 版 RapidOCR のハイブリッド構成、機械翻訳は OpenAI 互換 API のストリーミングを利用する。クリック透過の透明オーバーレイ、SetWindowDisplayAffinity による画面キャプチャループからのオーバーレイ除外、ファジーマッチ付きの設定可能なゲーム用語パック、SQLite ベースの翻訳キャッシュなどが中核の設計である。注入・メモリアクセス・レンダフックを検知するカーネル系アンチチートに対してできる限り非侵襲的に、低遅延の UI 翻訳を必要とする日本語他外国語 PC ゲームのプレイヤーやローカライザーを対象とする。
