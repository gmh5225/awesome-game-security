Foxo is a Windows real-time in-place overlay translator for PC game UIs that captures on-screen text with OCR and renders Chinese translations above the original interface without modifying the game process. It is implemented in Python using PySide6 for the UI, DXGI or mss for frame capture, and a hybrid OCR stack with DirectML-accelerated Japan PP-OCRv4, WinRT, or CPU RapidOCR, plus OpenAI-compatible APIs for streaming machine translation. Core engineering choices include click-through transparent overlays, SetWindowDisplayAffinity to exclude the overlay from screen capture loops, configurable game terminology packs with fuzzy matching, and SQLite-backed translation caching. The tool targets players and localizers of Japanese and other foreign-language games who need low-latency UI translation while remaining non-invasive relative to kernel anti-cheat systems that flag injection, memory access, and render hooking.
