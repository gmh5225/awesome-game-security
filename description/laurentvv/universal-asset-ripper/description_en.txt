Universal Asset Ripper is a high-performance, engine-agnostic platform for extracting game assets from packaged binaries and orchestrating AI-assisted reverse engineering workflows. It is implemented primarily in TypeScript on Node.js and ships pure native parsers for Godot PCK archives, Unreal Engine PAK and IoStore containers, Unity asset bundles and IL2CPP metadata, and Windows PE resource sections including icons and Delphi forms. The CLI supports automatic engine and framework detection, full asset cataloging, category- and pattern-filtered extraction, Shannon entropy scanning to hunt for AES keys, and structured evidence bundles for downstream analysis tools. An integrated Model Context Protocol server exposes those capabilities to coding agents, making it useful for modders, game developers, and security researchers who need fast reconnaissance on commercial game packages within a broader software reverse engineering toolchain.
