Universal Asset Ripper — высокопроизводительная, независимая от движка платформа для извлечения игровых ассетов из упакованных бинарных файлов и оркестрации рабочих процессов обратной разработки с поддержкой ИИ. Реализована в основном на TypeScript под Node.js и включает чистые нативные парсеры для архивов Godot PCK, контейнеров Unreal Engine PAK и IoStore, бандлов ассетов Unity и метаданных IL2CPP, а также секций ресурсов Windows PE, включая иконки и формы Delphi. CLI поддерживает автоматическое определение движка и фреймворка, полный каталог ассетов, извлечение с фильтрацией по категориям и шаблонам, сканирование энтропии Шеннона для поиска ключей AES и структурированные пакеты доказательств для последующих инструментов анализа. Встроенный сервер Model Context Protocol предоставляет эти возможности coding-агентам, что полезно моддерам, разработчикам игр и исследователям безопасности, которым нужна быстрая разведка коммерческих игровых пакетов в рамках более широкой цепочки инструментов обратной разработки ПО.
