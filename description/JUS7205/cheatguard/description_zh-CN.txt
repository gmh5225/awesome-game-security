Cheatguard 是一个与引擎无关的反作弊检测工具包，可扫描目标进程已加载的模块，并评估其运行作弊软件的可能性。该项目使用 Rust 编写，采用由 JSON 驱动的规则集，使检测签名以数据形式存在而非硬编码逻辑，并可配置已知作弊名称、可疑模块名模式、异常加载路径、未签名模块及模块数量异常等信号的权重。在 Windows 上，它通过 Win32 API 执行真实的模块枚举，在 JSON 报告中输出确定性的 0–100 风险评分，并给出 CLEAN、SUSPICIOUS 或 MALICIOUS 判定；其他平台则返回诚实的“不支持”占位结果，而非伪造数据。项目同时提供库与 CLI（cheatguard scan <pid>），适用于蓝队游戏安全研究、防御性进程完整性检查，以及构建自定义反作弊或取证工作流。
