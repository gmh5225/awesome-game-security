Cheatguard ist ein engine-unabhängiges Anti-Cheat-Erkennungstoolkit, das die geladenen Module eines Zielprozesses scannt und bewertet, wie wahrscheinlich es ist, dass Cheat-Software ausgeführt wird. In Rust geschrieben, nutzt es einen JSON-gesteuerten Regelsatz, sodass Erkennungssignaturen als Daten statt als fest codierte Logik vorliegen, mit konfigurierbaren Gewichtungen für Signale wie bekannte Cheat-Namen, verdächtige Modulnamenmuster, unerwartete Ladepfade, unsignierte Module und Anomalien bei der Modulanzahl. Unter Windows führt es eine echte Modulaufzählung über Win32-APIs durch und erzeugt einen deterministischen Risikowert von 0–100 mit den Urteilen CLEAN, SUSPICIOUS oder MALICIOUS in einem JSON-Bericht; auf anderen Plattformen liefert es ehrlich einen Unsupported-Stub statt fabrizierter Ergebnisse. Das Projekt wird sowohl als Bibliothek als auch als CLI (cheatguard scan <pid>) bereitgestellt und eignet sich für Blue-Team-Spielsicherheitsforschung, defensive Prozessintegritätsprüfungen sowie den Aufbau benutzerdefinierter Anti-Cheat- oder Forensik-Workflows.
