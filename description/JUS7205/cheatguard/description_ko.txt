Cheatguard는 엔진에 구애받지 않는 안티치트 탐지 툴킷으로, 대상 프로세스에 로드된 모듈을 스캔하여 치트 소프트웨어가 실행 중일 가능성을 점수화합니다. Rust로 작성되었으며 JSON 기반 규칙 집합을 사용해 탐지 시그니처를 하드코딩된 로직이 아닌 데이터로 관리하고, 알려진 치트 이름, 의심스러운 모듈 이름 패턴, 예상치 못한 로드 경로, 서명되지 않은 모듈, 모듈 수 이상 등 신호에 대한 가중치를 설정할 수 있습니다. Windows에서는 Win32 API를 통해 실제 모듈 열거를 수행하고 JSON 보고서에 결정적인 0–100 위험 점수와 CLEAN, SUSPICIOUS, MALICIOUS 판정을 생성합니다. 다른 플랫폼에서는 조작된 결과 대신 정직하게 미지원 스텁을 반환합니다. 라이브러리와 CLI(cheatguard scan <pid>) 모두로 제공되어 블루팀 게임 보안 연구, 방어적 프로세스 무결성 검사, 맞춤형 안티치트 또는 포렌식 워크플로 구축에 적합합니다.
