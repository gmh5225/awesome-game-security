Cheatguard はエンジン非依存の反チート検出ツールキットで、対象プロセスに読み込まれたモジュールをスキャンし、チートソフトウェアが動作している可能性をスコア化します。Rust で実装され、JSON 駆動のルールセットにより検出シグネチャをハードコードされたロジックではなくデータとして扱い、既知のチート名、疑わしいモジュール名パターン、想定外のロードパス、未署名モジュール、モジュール数の異常などのシグナルに対する重みを設定できます。Windows では Win32 API による実際のモジュール列挙を行い、JSON レポートで決定論的な 0–100 のリスクスコアと CLEAN、SUSPICIOUS、MALICIOUS の判定を出力します。他のプラットフォームでは偽の結果ではなく、正直に非対応であることを示すスタブを返します。ライブラリと CLI（cheatguard scan <pid>）の両方として提供され、ブルーチームのゲームセキュリティ研究、防御的なプロセス整合性チェック、カスタム反チートやフォレンジックワークフローの構築に適しています。
