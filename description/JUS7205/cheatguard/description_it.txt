Cheatguard è un toolkit di rilevamento anti-cheat indipendente dal motore che analizza i moduli caricati di un processo target e valuta la probabilità che sia in esecuzione un software cheat. Scritto in Rust, utilizza un set di regole guidato da JSON in modo che le firme di rilevamento siano dati anziché logica hard-coded, con pesi configurabili per segnali come nomi di cheat noti, pattern sospetti nei nomi dei moduli, percorsi di caricamento imprevisti, moduli non firmati e anomalie nel conteggio dei moduli. Su Windows esegue una reale enumerazione dei moduli tramite le API Win32 e produce un punteggio di rischio deterministico da 0 a 100 con verdetto CLEAN, SUSPICIOUS o MALICIOUS in un report JSON; su altre piattaforme restituisce onestamente uno stub di non supporto anziché risultati fabbricati. Il progetto è distribuito sia come libreria sia come CLI (cheatguard scan <pid>), rendendolo adatto alla ricerca sulla sicurezza dei giochi in blue team, ai controlli difensivi dell'integrità dei processi e alla creazione di workflow anti-cheat o forensi personalizzati.
