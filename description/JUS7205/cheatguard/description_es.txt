Cheatguard es un kit de herramientas de detección anti-trampas independiente del motor que escanea los módulos cargados de un proceso objetivo y evalúa la probabilidad de que se esté ejecutando software de trampas. Escrito en Rust, utiliza un conjunto de reglas basado en JSON para que las firmas de detección sean datos en lugar de lógica codificada de forma rígida, con pesos configurables para señales como nombres de trampas conocidos, patrones sospechosos en nombres de módulos, rutas de carga inesperadas, módulos sin firmar y anomalías en el recuento de módulos. En Windows realiza una enumeración real de módulos mediante las API Win32 y produce una puntuación de riesgo determinista de 0–100 con veredictos CLEAN, SUSPICIOUS o MALICIOUS en un informe JSON; en otras plataformas devuelve un stub honesto de no compatibilidad en lugar de resultados fabricados. El proyecto se distribuye tanto como biblioteca como CLI (cheatguard scan <pid>), lo que lo hace adecuado para investigación de seguridad de juegos en equipos blue team, comprobaciones defensivas de integridad de procesos y la creación de flujos de trabajo personalizados de anti-trampas o forenses.
