Cheatguard 是一個與引擎無關的反作弊偵測工具包，可掃描目標程序已載入的模組，並評估其執行作弊軟體的可能性。該專案以 Rust 撰寫，採用由 JSON 驅動的規則集，使偵測簽章以資料形式存在而非硬編碼邏輯，並可設定已知作弊名稱、可疑模組名稱模式、異常載入路徑、未簽章模組及模組數量異常等訊號的權重。在 Windows 上，它透過 Win32 API 執行真實的模組列舉，在 JSON 報告中輸出確定性的 0–100 風險評分，並給出 CLEAN、SUSPICIOUS 或 MALICIOUS 判定；其他平台則回傳誠實的「不支援」占位結果，而非偽造資料。專案同時提供函式庫與 CLI（cheatguard scan <pid>），適用於藍隊遊戲安全研究、防禦性程序完整性檢查，以及建構自訂反作弊或鑑識工作流。
