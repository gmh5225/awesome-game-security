Cheatguard is an engine-agnostic anti-cheat detection toolkit that scans a target process's loaded modules and scores how likely it is running cheating software. Written in Rust, it uses a JSON-driven ruleset so detection signatures are data rather than hard-coded logic, with configurable weights for signals such as known cheat names, suspicious module name patterns, unexpected load paths, unsigned modules, and module-count anomalies. On Windows it performs real module enumeration via Win32 APIs and produces a deterministic 0–100 risk score with CLEAN, SUSPICIOUS, or MALICIOUS verdicts in a JSON report; other platforms return an honest unsupported stub rather than fabricated results. The project ships as both a library and a CLI (`cheatguard scan <pid>`), making it suitable for blue-team game security research, defensive process-integrity checks, and building custom anti-cheat or forensics workflows.
