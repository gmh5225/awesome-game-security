Sephile is a rooted Android application for runtime memory analysis and live editing of other processes, aimed at beginners and researchers who want a modern alternative to classic game-memory tools. The UI is built with Kotlin and Jetpack Compose, while a C++ NDK layer uses ptrace and proc maps to attach, scan for typed values, refine searches, edit and freeze addresses, and inspect memory with a live hex-style viewer. It includes a process browser, optional Lua scripting hooks for automation, and root integration via su for ptrace access. The project is positioned as an educational and research tool for reverse engineering and studying how mobile games and apps hold state in memory, not for bypassing online anti-cheat on live services.
