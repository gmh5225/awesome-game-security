Spartan AntiCheat in Rewrite è una riscrittura Java in corso del plugin anti-cheat Spartan per server multigiocatore Minecraft. Realizzato come progetto Maven per le API Spigot, Paper e Folia, si concentra su un framework di controlli modulare con runner, tracciamento delle violazioni per singola rilevazione, punizioni configurabili e comandi per lo staff. Il codice distingue client Java e Bedrock, supporta modalità di rilevamento orientate a Bukkit e pacchetti, e integra Floodgate, ViaVersion, webhook Discord e scheduling server multi-versione. È rivolto a operatori di server e sviluppatori di plugin che desiderano una base moderna per il rilevamento cheat lato server Minecraft e l’ingegneria anti-cheat.
