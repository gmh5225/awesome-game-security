Spartan AntiCheat in Rewrite 是針對 Minecraft 多人遊戲伺服器的 Spartan 反作弊外掛之進行中 Java 重寫版本。此專案以 Maven 建置，目標為 Spigot、Paper 與 Folia API，核心是模組化檢測框架，含執行器、依各檢測項目追蹤違規，以及可設定的懲處與管理員指令。程式碼區分 Java 與基岩版用戶端，支援 Bukkit 與封包導向檢測模式，並整合 Floodgate、ViaVersion、Discord webhook 與多版本伺服器排程。適合希望以現代化基礎進行 Minecraft 伺服器端作弊檢測與反作弊工程的伺服器營運者與外掛開發者。
