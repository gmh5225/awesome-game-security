Spartan AntiCheat in Rewrite es una reescritura en Java en curso del complemento anti-trampas Spartan para servidores multijugador de Minecraft. Desarrollado como proyecto Maven para las API de Spigot, Paper y Folia, se centra en un marco de comprobaciones modular con ejecutores, seguimiento de infracciones por detección, y castigos y comandos de staff configurables. El código distingue clientes Java y Bedrock, admite modos de detección orientados a Bukkit y paquetes, e integra Floodgate, ViaVersion, webhooks de Discord y planificación de servidor multi-versión. Está dirigido a operadores de servidores y desarrolladores de plugins que buscan una base moderna para la detección de trampas en el lado del servidor de Minecraft y la ingeniería anti-trampas.
