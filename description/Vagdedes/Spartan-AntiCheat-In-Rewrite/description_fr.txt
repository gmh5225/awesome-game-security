Spartan AntiCheat in Rewrite est une réécriture Java en cours du plugin anti-triche Spartan pour les serveurs multijoueur Minecraft. Construit comme projet Maven pour les API Spigot, Paper et Folia, il repose sur un cadre de vérifications modulaire avec des exécuteurs, un suivi des violations par détection, ainsi que des sanctions et commandes staff configurables. Le code distingue les clients Java et Bedrock, prend en charge les modes de détection orientés Bukkit et paquets, et intègre Floodgate, ViaVersion, les webhooks Discord et la planification multi-versions côté serveur. Il s’adresse aux opérateurs de serveurs et aux développeurs de plugins qui souhaitent une base moderne pour la détection de triche côté serveur Minecraft et l’ingénierie anti-triche.
