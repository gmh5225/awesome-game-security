Spartan AntiCheat in Rewrite 是针对 Minecraft 多人游戏服务器的 Spartan 反作弊插件的进行中 Java 重写版本。该项目基于 Maven，面向 Spigot、Paper 与 Folia API 构建，核心是可模块化检测框架，包含运行器、按检测项记录的违规追踪，以及可配置的处罚与管理员命令。代码库区分 Java 与基岩版客户端，支持 Bukkit 与面向数据包的检测模式，并集成 Floodgate、ViaVersion、Discord webhook 及多版本服务端调度。面向希望以现代架构开展 Minecraft 服务端作弊检测与反作弊工程的服务器运营者与插件开发者。
