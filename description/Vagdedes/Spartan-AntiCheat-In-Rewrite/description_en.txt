Spartan AntiCheat in Rewrite is a work-in-progress Java rewrite of the Spartan anti-cheat plugin for Minecraft multiplayer servers. Built as a Maven project against Spigot, Paper, and Folia APIs, it centers on a modular check framework with runners, per-detection violation tracking, and configurable punishments and staff commands. The codebase distinguishes Java and Bedrock clients, supports Bukkit- and packet-oriented detection modes, and integrates Floodgate, ViaVersion, Discord webhooks, and multi-version server scheduling. It is aimed at server operators and plugin developers who want a modern foundation for Minecraft server-side cheat detection and anti-cheat engineering.
