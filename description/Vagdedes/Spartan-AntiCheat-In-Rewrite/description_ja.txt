Spartan AntiCheat in Rewrite は、Minecraft マルチプレイサーバー向け Spartan アンチチートプラグインの Java による書き直し（進行中）です。Maven プロジェクトとして Spigot、Paper、Folia API に対応して構築され、ランナー、検出ごとの違反追跡、設定可能な処罰とスタッフコマンドを備えたモジュラー検査フレームワークが中心です。コードベースは Java と Bedrock クライアントを区別し、Bukkit およびパケット指向の検出モードをサポートし、Floodgate、ViaVersion、Discord webhook、マルチバージョンサーバーのスケジューリングを統合しています。Minecraft サーバー側のチート検出とアンチチート設計のための現代的な基盤を求めるサーバー運営者とプラグイン開発者向けです。
