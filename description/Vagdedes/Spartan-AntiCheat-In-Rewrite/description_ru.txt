Spartan AntiCheat in Rewrite — это находящаяся в разработке переписка на Java плагина античита Spartan для многопользовательских серверов Minecraft. Проект собран как Maven-приложение под API Spigot, Paper и Folia; в его основе модульный каркас проверок с раннерами, учётом нарушений по каждому срабатыванию и настраиваемыми наказаниями и командами для персонала. Код различает клиентов Java и Bedrock, поддерживает режимы детекции на основе Bukkit и пакетов, а также интегрирует Floodgate, ViaVersion, вебхуки Discord и планирование задач на серверах разных версий. Ориентирован на администраторов серверов и разработчиков плагинов, которым нужна современная база для серверного обнаружения читов и разработки античита в Minecraft.
