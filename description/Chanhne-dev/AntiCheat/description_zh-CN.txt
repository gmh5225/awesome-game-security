AntiCheat 是一款基于 Java 的 Minecraft 服务器插件，可在 Paper 和 Folia 服务器上检测并拦截常见作弊行为。它实现了移动与行为检测，包括飞行检测、非法物品扫描，以及针对 Meteor Client、TrouserStreak、NoraTweaks 等流行作弊客户端的专用模块。该插件采用周期性扫描任务、违规记录、可配置的处罚机制、Discord Webhook 告警，以及可选的移动日志，供服务器管理员使用。文档还介绍了集成实体剔除 anti-ESP 逻辑，用于隐藏玩家视线之外的实体。它面向需要服务端反作弊而非内核级或商业游戏防护方案的 Minecraft 服务器运营者。
