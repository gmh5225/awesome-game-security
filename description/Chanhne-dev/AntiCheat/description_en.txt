AntiCheat is a Java-based Minecraft server plugin that detects and blocks common cheating on Paper and Folia servers. It implements movement and behavior checks such as fly detection, illegal item scanning, and targeted modules for popular hacked clients including Meteor Client, TrouserStreak, and NoraTweaks. The plugin uses periodic scan tasks, violation tracking, configurable enforcement, Discord webhook alerts, and optional movement logging for server administrators. Documentation also covers integrating entity-culling anti-ESP logic that hides entities outside a player's line of sight. It is aimed at Minecraft server operators who need server-side anti-cheat rather than kernel-level or commercial game protection.
