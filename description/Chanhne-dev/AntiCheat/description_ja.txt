AntiCheat は Java ベースの Minecraft サーバー向けプラグインで、Paper および Folia サーバー上の一般的なチート行為を検出してブロックします。飛行検知、不正アイテムのスキャン、Meteor Client、TrouserStreak、NoraTweaks など人気のハッククライアント向けの専用モジュールなど、移動および行動チェックを実装しています。プラグインは定期的なスキャンタスク、違反の追跡、設定可能な執行、Discord Webhook アラート、サーバー管理者向けの任意の移動ログを使用します。ドキュメントには、プレイヤーの視界外のエンティティを非表示にする entity-culling anti-ESP ロジックの統合についても記載されています。カーネルレベルや商用ゲーム保護ではなく、サーバー側のアンチチートを必要とする Minecraft サーバー運営者を対象としています。
