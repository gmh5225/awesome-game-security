AntiCheat 是一款以 Java 為基礎的 Minecraft 伺服器外掛，可在 Paper 與 Folia 伺服器上偵測並封鎖常見作弊行為。它實作了移動與行為檢查，包括飛行偵測、非法物品掃描，以及針對 Meteor Client、TrouserStreak、NoraTweaks 等熱門作弊用戶端的專用模組。此外掛使用週期性掃描任務、違規追蹤、可設定的處罰機制、Discord Webhook 告警，以及可選的移動日誌，供伺服器管理員使用。文件也涵蓋整合實體剔除 anti-ESP 邏輯，以隱藏玩家視線範圍外的實體。它面向需要伺服器端反作弊，而非核心層級或商業遊戲防護方案的 Minecraft 伺服器營運者。
