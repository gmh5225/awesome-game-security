AntiCheat è un plugin per server Minecraft basato su Java che rileva e blocca i cheat più comuni sui server Paper e Folia. Implementa controlli di movimento e comportamento come il rilevamento del volo, la scansione di oggetti illegali e moduli mirati per client hack popolari, tra cui Meteor Client, TrouserStreak e NoraTweaks. Il plugin utilizza attività di scansione periodiche, tracciamento delle violazioni, applicazione configurabile, avvisi tramite webhook Discord e registrazione opzionale dei movimenti per gli amministratori del server. La documentazione copre anche l'integrazione di logica anti-ESP con entity-culling che nasconde le entità al di fuori del campo visivo del giocatore. È rivolto agli operatori di server Minecraft che necessitano di anti-cheat lato server anziché di protezione a livello kernel o commerciale per i giochi.
