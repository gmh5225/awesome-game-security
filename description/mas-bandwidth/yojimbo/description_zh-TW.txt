Yojimbo 是一款用於即時多人遊戲的 C++ 用戶端/伺服器網路函式庫，專為競技類遊戲（如第一人稱射擊遊戲）而設計。它建構於內建的 netcode、reliable 與 serialize 元件之上，提供加密且簽署的 UDP 傳輸、連線權杖驗證、連線管理、封包分片與重組，以及可靠有序與不可靠無序兩種訊息通道。此函式庫包含 bitpacker 序列化系統、大型資料區塊支援、逐連線的延遲與封包遺失統計，以及伺服器端逐用戶端的 TLSF 堆積隔離。主要以 C++ 撰寫，採用 CMake 建置流程，並對不可信的網路解析器進行廣泛的模糊測試，面向需要生產級、注重安全性的 netcode 層、支援約 100 名玩家的用戶端/伺服器遊戲開發者。
