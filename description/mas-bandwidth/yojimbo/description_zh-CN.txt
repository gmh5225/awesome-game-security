Yojimbo 是一款用于实时多人游戏的 C++ 客户端/服务器网络库，面向竞技类游戏（如第一人称射击游戏）而设计。它基于内置的 netcode、reliable 和 serialize 组件，提供加密且签名的 UDP 传输、连接令牌认证、连接管理、数据包分片与重组，以及可靠有序与不可靠无序两种消息通道。该库包含 bitpacker 序列化系统、大型数据块支持、按连接的延迟与丢包统计，以及服务器端按客户端的 TLSF 堆隔离。主要使用 C++ 编写，采用基于 CMake 的构建流程，并对不可信的网络解析器进行广泛的模糊测试，面向需要生产级、注重安全的 netcode 层、支持约 100 名玩家的客户端/服务器游戏的开发者。
