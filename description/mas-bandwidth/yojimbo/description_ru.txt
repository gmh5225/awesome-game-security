Yojimbo — это сетевая библиотека клиент/сервер на C++ для многопользовательских игр в реальном времени, созданная для соревновательных проектов, таких как шутеры от первого лица. Она опирается на встроенные компоненты netcode, reliable и serialize и обеспечивает шифрованный и подписанный UDP-транспорт, аутентификацию по connect-токенам, управление соединениями, фрагментацию и сборку пакетов, а также каналы сообщений с гарантированной доставкой по порядку и без гарантий доставки без порядка. Библиотека включает систему сериализации bitpacker, поддержку крупных блоков данных, статистику задержки и потерь пакетов для каждого соединения, а также изоляцию TLSF-кучи для каждого клиента на сервере. Написана в основном на C++, использует сборку на базе CMake и обширное фазз-тестирование недоверенных сетевых парсеров; предназначена для разработчиков игр, которым нужен готовый к продакшену, ориентированный на безопасность слой netcode для клиент/серверных игр с числом игроков до примерно 100.
