Schema は Go ベースのコンパイラおよびデータ定義言語であり、.schema ファイルで定数、列挙型、型、テーブル、ネットワークメッセージのレイアウトを記述すると、多数のターゲット言語向けに対応するシリアライザを生成できる。内部のコード生成パイプラインはビットパックされたパケットおよびテーブル用コーデックを出力し、C、C++、C#、Dart、Elixir、Go、Java、JavaScript、Lobster、Lua、Luau、Python、Ruby、Rust、Squirrel など関連ポート向けの専用ランタイムを備え、大規模な適合性テスト、ファズテスト、敵対的ワイヤ回帰スイートで支えられている。リポジトリには厳密なクロス言語ベンチハーネスが同梱され、読み書きパフォーマンスをプロファイルするほか、ワイヤ上のバージョニング、固定レコード、整合性チェックを扱うエディタツールとサンプルも含まれる。ゲームおよびリアルタイムネットワーク向け開発者を対象とし、クライアント・サーバープロトコルやセキュリティ上敏感なデシリアライズ経路に適した、高速で決定的なバイナリ形式と厳格なパース動作を求める用途向けである。
