Schema is a Go-based compiler and data-definition language in which you describe constants, enums, types, tables, and network message layouts in .schema files and emit matching serializers across many target languages. Its internal codegen pipeline generates bit-packed packet and table codecs with dedicated runtimes for C, C++, C#, Dart, Elixir, Go, Java, JavaScript, Lobster, Lua, Luau, Python, Ruby, Rust, Squirrel, and related ports, backed by large conformance, fuzz, and hostile-wire regression suites. The repository ships a rigorous cross-language bench harness that profiles read and write performance, plus editor tooling and examples that exercise versioning, fixed records, and integrity checks on the wire. It targets game and realtime networking developers who need fast, deterministic binary formats with strict parsing behavior suitable for client-server protocols and security-sensitive deserialization paths.
