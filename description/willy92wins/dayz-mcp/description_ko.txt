DayZ-MCP는 AI 에이전트가 수십 개의 타입화된 도구를 통해 실행 중인 DayZ 게임 또는 서버를 프로그래밍 방식으로 제어할 수 있게 해 주는 Model Context Protocol 서버입니다. Windows의 Python 데몬과 MCP 서버는 게임 내 Enforce Script 브리지 모드와 통신하여 키보드 입력이나 OCR 없이 월드 설정, 플레이어 및 차량 조작, 원격 측정, 로깅, 장면 관찰을 위한 서버 권한 명령을 전달합니다. 에이전트가 애드온을 패키징하고, 테스트 인스턴스를 실행하며, 엔티티를 배치하고, 차량을 운전하고, 스크린샷을 캡처하며, 구조화된 엔진 상태에 대해 어설션할 수 있는 자율 모드 개발 루프를 지원합니다. 세션 임대, localhost 전용 바인딩, 자격 증명 관리, 감사 추적이 로컬 테스트 및 서버 관리를 위한 제어된 자동화 인터페이스를 제공합니다. 이 프로젝트는 개발, QA, 운영 워크플로를 위해 게임 엔진과 반복 가능하고 스크립트 가능한 상호작용이 필요한 DayZ 모드 개발자, 서버 운영자, 연구자를 대상으로 합니다.
