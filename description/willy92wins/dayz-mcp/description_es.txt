DayZ-MCP es un servidor Model Context Protocol que permite a los agentes de IA controlar de forma programática un juego o servidor DayZ en ejecución mediante decenas de herramientas tipadas. Un daemon Python y un servidor MCP en Windows se comunican con un mod puente Enforce Script en el juego que ejecuta comandos con autoridad del servidor para la configuración del mundo, la manipulación de jugadores y vehículos, la telemetría, el registro y la observación de escenas, sin entrada de teclado ni OCR. Admite un bucle autónomo de desarrollo de mods en el que un agente puede empaquetar addons, lanzar instancias de prueba, colocar entidades, conducir vehículos, capturar capturas de pantalla y realizar aserciones sobre el estado estructurado del motor. Los arrendamientos de sesión, el enlace exclusivo a localhost, la gestión de credenciales y las pistas de auditoría proporcionan una superficie de automatización controlada para pruebas locales y administración de servidores. El proyecto está dirigido a desarrolladores de mods de DayZ, operadores de servidores e investigadores que necesitan interacción repetible y scriptable con el motor del juego para flujos de desarrollo, QA y operaciones.
