DayZ-MCP — это сервер Model Context Protocol, который позволяет ИИ-агентам программно управлять запущенной игрой или сервером DayZ через десятки типизированных инструментов. Python-демон и MCP-сервер под Windows взаимодействуют с внутриигровым мостовым модом Enforce Script, который отправляет серверные команды для настройки мира, управления игроками и транспортом, телеметрии, логирования и наблюдения за сценой без ввода с клавиатуры и OCR. Поддерживается автономный цикл разработки модов, в котором агент может упаковывать аддоны, запускать тестовые экземпляры, размещать сущности, управлять транспортом, делать скриншоты и проверять структурированное состояние движка. Аренда сессий, привязка только к localhost, управление учётными данными и журналы аудита обеспечивают контролируемую автоматизацию для локального тестирования и администрирования сервера. Проект ориентирован на разработчиков модов DayZ, операторов серверов и исследователей, которым нужно повторяемое, скриптуемое взаимодействие с игровым движком для разработки, QA и операционных процессов.
