DayZ-MCP 是一个 Model Context Protocol 服务器，让 AI 智能体通过数十种类型化工具以编程方式控制正在运行的 DayZ 游戏或服务器。Windows 上的 Python 守护进程与 MCP 服务器通过游戏内 Enforce Script 桥接模组通信，无需键盘输入或 OCR 即可下发服务器权威命令，用于世界配置、玩家与载具操作、遥测、日志记录和场景观察。它支持自主模组开发循环：智能体可打包插件、启动测试实例、放置实体、驾驶载具、截取屏幕截图，并对结构化引擎状态进行断言。会话租约、仅绑定 localhost、凭据管理和审计追踪为本地测试与服务器管理提供了可控的自动化接口。该项目面向需要可重复、可脚本化方式与游戏引擎交互以支持开发、QA 与运维流程的 DayZ 模组开发者、服务器运营者和研究人员。
