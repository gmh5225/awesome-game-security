DayZ-MCP は Model Context Protocol サーバーで、AI エージェントが数十の型付きツールを通じて実行中の DayZ ゲームまたはサーバーをプログラム的に制御できるようにします。Windows 上の Python デーモンと MCP サーバーは、ゲーム内の Enforce Script ブリッジ MOD と通信し、キーボード入力や OCR なしで、ワールド設定、プレイヤーおよび車両の操作、テレメトリ、ログ記録、シーン観察のためのサーバー権威コマンドを発行します。アドオンをパッケージ化し、テストインスタンスを起動し、エンティティを配置し、車両を運転し、スクリーンショットを取得し、構造化されたエンジン状態に対してアサーションを行う自律的な MOD 開発ループをサポートします。セッションロック、localhost のみのバインド、認証情報管理、監査証跡により、ローカルテストとサーバー管理向けの制御された自動化インターフェースを提供します。本プロジェクトは、開発、QA、運用ワークフロー向けにゲームエンジンと反復可能かつスクリプト可能なやり取りを必要とする DayZ MOD 開発者、サーバー運用者、研究者を対象としています。
