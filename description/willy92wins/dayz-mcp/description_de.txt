DayZ-MCP ist ein Model Context Protocol-Server, der es KI-Agenten ermöglicht, ein laufendes DayZ-Spiel oder einen Server programmatisch über Dutzende typisierter Tools zu steuern. Ein Python-Daemon und MCP-Server unter Windows kommunizieren mit einem In-Game-Enforce-Script-Bridge-Mod, der serverautoritative Befehle für Welteinrichtung, Spieler- und Fahrzeugmanipulation, Telemetrie, Protokollierung und Szenenbeobachtung ohne Tastatureingabe oder OCR ausführt. Es unterstützt eine autonome Mod-Entwicklungsschleife, in der ein Agent Addons packen, Testinstanzen starten, Entitäten platzieren, Fahrzeuge fahren, Screenshots aufnehmen und strukturierte Engine-Zustände prüfen kann. Sitzungs-Leases, reine Localhost-Bindung, Anmeldedatenverwaltung und Audit-Trails bieten eine kontrollierte Automatisierungsoberfläche für lokales Testen und Serveradministration. Das Projekt richtet sich an DayZ-Mod-Entwickler, Serverbetreiber und Forscher, die wiederholbare, skriptbare Interaktion mit der Spiel-Engine für Entwicklungs-, QA- und Betriebs-Workflows benötigen.
