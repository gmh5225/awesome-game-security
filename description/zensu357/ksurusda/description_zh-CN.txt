KsuRusda 是一款 Android Zygisk 模块，可在使用 KernelSU、Magisk 或 APatch 的已 root 设备上，向指定应用注入隐蔽、反检测的 Frida gadget。它内置 Rusda 补丁版 Frida 内核，可去除线程名称、RPC 标识符和 memfd 映射等常见 Frida 指纹，同时保持与标准 Frida 客户端和脚本的兼容。该模块支持 TCP 监听模式以便在 PC 端进行动态调试，以及无需网络权限即可加载本地 JavaScript 的离线脚本模式，可通过响应式 WebUI 或 JSON 配置进行管理。注入在 Zygisk postAppSpecialize 阶段完成，不修改 APK 签名，通过库重映射隐藏映射路径、可选启动延迟和子进程门控来规避基于 ptrace 和启动阶段的反调试检测。它面向需要 hook 并分析受保护 Android 应用（包括具备反 Frida 防护的游戏）的移动安全研究人员、逆向工程师和审计人员。
