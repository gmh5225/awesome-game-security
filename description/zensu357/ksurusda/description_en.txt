KsuRusda is an Android Zygisk module that injects a stealth, anti-detection Frida gadget into selected apps on rooted devices using KernelSU, Magisk, or APatch. It bundles the Rusda patched Frida kernel, which strips common Frida fingerprints such as thread names, RPC identifiers, and memfd mappings while staying compatible with standard Frida clients and scripts. The module supports TCP listen mode for PC-side dynamic debugging and an offline script mode that loads local JavaScript without network permissions, managed through a responsive WebUI or JSON configuration. Injection happens at the Zygisk postAppSpecialize stage without modifying APK signatures, using library remapping to hide mapped paths, optional startup delays, and child-process gating to evade ptrace-based and startup anti-debug checks. It is aimed at mobile security researchers, reverse engineers, and auditors who need to hook and analyze protected Android applications, including games with anti-Frida defenses.
