KsuRusda 是一款 Android Zygisk 模組，可在使用 KernelSU、Magisk 或 APatch 的已 root 裝置上，向指定應用程式注入隱蔽、反偵測的 Frida gadget。它內建 Rusda 修補版 Frida 核心，可移除執行緒名稱、RPC 識別碼和 memfd 對應等常見 Frida 指紋，同時保持與標準 Frida 用戶端和腳本的相容性。此模組支援 TCP 監聽模式以便在 PC 端進行動態除錯，以及無需網路權限即可載入本機 JavaScript 的離線腳本模式，可透過回應式 WebUI 或 JSON 設定進行管理。注入發生於 Zygisk postAppSpecialize 階段，不修改 APK 簽章，透過函式庫重對應隱藏映射路徑、可選的啟動延遲和子程序門控來規避基於 ptrace 與啟動階段的反除錯檢查。它面向需要 hook 並分析受保護 Android 應用程式（包括具備反 Frida 防護的遊戲）的行動安全研究人員、逆向工程師和稽核人員。
