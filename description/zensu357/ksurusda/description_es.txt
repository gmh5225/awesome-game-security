KsuRusda es un módulo Zygisk para Android que inyecta un gadget Frida sigiloso y anti-detección en aplicaciones seleccionadas en dispositivos con root mediante KernelSU, Magisk o APatch. Incluye el kernel Frida parcheado Rusda, que elimina huellas comunes de Frida como nombres de hilos, identificadores RPC y mapeos memfd, manteniendo la compatibilidad con clientes y scripts Frida estándar. El módulo admite el modo de escucha TCP para depuración dinámica desde el PC y un modo de script sin conexión que carga JavaScript local sin permisos de red, gestionado mediante una WebUI responsive o configuración JSON. La inyección ocurre en la etapa postAppSpecialize de Zygisk sin modificar las firmas APK, utilizando remapeo de bibliotecas para ocultar rutas mapeadas, retrasos de inicio opcionales y control de procesos hijos para evadir comprobaciones anti-depuración basadas en ptrace y en el arranque. Está dirigido a investigadores de seguridad móvil, ingenieros inversores y auditores que necesitan hacer hook y analizar aplicaciones Android protegidas, incluidos juegos con defensas anti-Frida.
