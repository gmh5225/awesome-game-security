KsuRusda は、KernelSU、Magisk、または APatch を使用した root 化端末上で、選択したアプリにステルス型の検知回避 Frida gadget を注入する Android Zygisk モジュールです。Rusda パッチ適用版 Frida カーネルを同梱し、スレッド名、RPC 識別子、memfd マッピングなどの一般的な Frida フィンガープリントを除去しつつ、標準 Frida クライアントおよびスクリプトとの互換性を維持します。TCP リッスンモードによる PC 側での動的デバッグ、およびネットワーク権限なしでローカル JavaScript を読み込むオフラインスクリプトモードをサポートし、レスポンシブ WebUI または JSON 設定で管理できます。注入は Zygisk の postAppSpecialize 段階で行われ、APK 署名を変更せず、ライブラリのリマッピングによるマップパスの隠蔽、任意の起動遅延、子プロセスゲートにより ptrace ベースおよび起動時の反デバッグチェックを回避します。モバイルセキュリティ研究者、リバースエンジニア、監査担当者向けで、反 Frida 防御を備えたゲームを含む保護された Android アプリケーションのフックと解析を目的としています。
