Chess Anti-Cheat Detection es un pipeline de aprendizaje automático que marca partidas probablemente asistidas por motor analizando las secuencias de jugadas y los tiempos de reflexión de cada jugador. Está implementado en Python con TensorFlow y Keras, usando un modelo multimodal que combina embeddings de jugadas, capas LSTM bidireccionales, extracción de patrones Conv1D y color del jugador para puntuar el riesgo de trampas. Scripts de apoyo obtienen partidas PGN desde la API de Lichess, convierten muestras etiquetadas de jugadores honestos y tramposos en un conjunto de datos HDF5, preprocesan el vocabulario, entrenan el clasificador y ejecutan predicciones interactivas o programáticas con explicaciones detalladas de factores de riesgo. El diseño enfatiza etiquetas a nivel de jugador, divisiones entrenamiento/validación por jugador para limitar fugas, y características temporales derivadas de anotaciones del reloj para detectar juego anormalmente uniforme o de baja varianza. Está dirigido a operadores de plataformas de ajedrez en línea, investigadores anti-trampas y desarrolladores orientados a la seguridad que buscan una línea base reproducible para recopilación de datos, entrenamiento de modelos y cribado de trampas en tiempo real.
