Chess Anti-Cheat Detection is a machine learning pipeline that flags likely engine-assisted play by analyzing individual players’ move sequences and think times. It is implemented in Python with TensorFlow and Keras, using a multi-modal model that combines move embeddings, bidirectional LSTM layers, Conv1D pattern extraction, and player color to score cheating risk. Supporting scripts pull PGN games from the Lichess API, convert labeled honest and cheater samples into an HDF5 dataset, preprocess vocabulary, train the classifier, and run interactive or programmatic predictions with detailed risk-factor explanations. The design emphasizes player-level labels, train/validation splits by player to limit leakage, and timing features derived from clock annotations to catch unnaturally consistent or low-variance play. It targets online chess platform operators, anti-cheat researchers, and security-minded developers who want a reproducible baseline for data collection, model training, and real-time cheat screening.
