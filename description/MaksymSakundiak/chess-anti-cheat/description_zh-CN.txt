Chess Anti-Cheat Detection 是一套机器学习流水线，通过分析每位棋手的着法序列与思考时间，标记疑似借助引擎的对局。项目以 Python 实现，基于 TensorFlow 与 Keras，采用多模态模型：结合着法嵌入、双向 LSTM、Conv1D 模式提取以及棋手执棋颜色，对作弊风险打分。配套脚本从 Lichess API 拉取 PGN 对局，将标注的诚实与作弊样本转为 HDF5 数据集，预处理词表、训练分类器，并支持交互式或程序化预测及详细风险因素说明。设计侧重棋手级标签、按棋手划分训练/验证集以降低泄漏，以及从时钟注释衍生的用时特征，以识别不自然的一致或低方差对局。面向在线象棋平台运营方、反作弊研究人员及注重安全的开发者，提供可复现的数据采集、模型训练与实时作弊筛查基线。
