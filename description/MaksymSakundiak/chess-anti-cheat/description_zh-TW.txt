Chess Anti-Cheat Detection 是一套機器學習管線，透過分析每位棋手的著法序列與思考時間，標記疑似借助引擎的對局。專案以 Python 實作，基於 TensorFlow 與 Keras，採用多模態模型：結合著法嵌入、雙向 LSTM、Conv1D 模式擷取以及棋手執棋顏色，對作弊風險評分。配套腳本從 Lichess API 拉取 PGN 對局，將標註的誠實與作弊樣本轉為 HDF5 資料集，預處理詞彙、訓練分類器，並支援互動式或程式化預測及詳細風險因素說明。設計著重棋手級標籤、依棋手劃分訓練/驗證集以降低洩漏，以及從時鐘註解衍生的用時特徵，以識別不自然的一致或低變異對局。面向線上象棋平台營運方、反作弊研究人員及注重安全的開發者，提供可重現的資料蒐集、模型訓練與即時作弊篩檢基線。
