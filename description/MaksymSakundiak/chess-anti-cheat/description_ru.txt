Chess Anti-Cheat Detection — это конвейер машинного обучения, который помечает вероятную игру с помощью движка, анализируя последовательности ходов и время обдумывания отдельных игроков. Реализован на Python с TensorFlow и Keras; многомодальная модель объединяет эмбеддинги ходов, двунаправленные слои LSTM, извлечение паттернов Conv1D и цвет фигур игрока для оценки риска читерства. Вспомогательные скрипты загружают партии PGN через API Lichess, преобразуют размеченные честные и читерские выборки в набор данных HDF5, предобрабатывают словарь, обучают классификатор и выполняют интерактивные или программные предсказания с подробными пояснениями факторов риска. В архитектуре акцент на метках на уровне игрока, разбиении train/validation по игрокам против утечки и временных признаках из аннотаций часов для выявления неестественно ровной или низкодисперсной игры. Целевая аудитория — операторы онлайн-шахматных платформ, исследователи античита и разработчики, заботящиеся о безопасности и нуждающиеся в воспроизводимой базовой линии для сбора данных, обучения модели и скрининга читерства в реальном времени.
