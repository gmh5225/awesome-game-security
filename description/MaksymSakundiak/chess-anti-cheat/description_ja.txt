Chess Anti-Cheat Detection は、各プレイヤーの指し手列と思考時間を分析し、エンジン支援の疑いがある対局を検出する機械学習パイプラインです。Python と TensorFlow、Keras で実装され、指し手埋め込み、双方向 LSTM、Conv1D によるパターン抽出、先手後手の色を組み合わせたマルチモーダルモデルで不正リスクをスコア化します。補助スクリプトは Lichess API から PGN 棋譜を取得し、ラベル付きの正常・不正サンプルを HDF5 データセットに変換し、語彙の前処理、分類器の学習、対話型またはプログラムからの予測と詳細なリスク要因の説明を行います。設計ではプレイヤー単位のラベル、リークを抑えるプレイヤー別の学習/検証分割、時計注釈から得る時間特徴により、不自然に一貫した低分散のプレイを捉えます。オンライン将棋プラットフォーム運営者、不正検知研究者、セキュリティを意識する開発者向けに、データ収集・モデル学習・リアルタイム不正スクリーニングの再現可能なベースラインを提供します。
