This repository is a curated collection of small, per-game hacking and modding utilities for console and PC titles, spanning archive extractors, script disassemblers and assemblers, translation workflows, and one emulator integration patch. Most entries are implemented in Python, with a Windows C project that uses DLL injection and SCSI emulation hooks to let the SSF Saturn emulator boot CHD disc images, plus a browser-based JavaScript helper for Keep Talking and Nobody Explodes. Individual folders target games such as Clock Tower, Ys: Memories of Celceta, Culdcept, Castlevania Lords of Shadow, and others using techniques like bytecode reverse engineering, custom cipher and compression handling, archive format carving, and differencing VHD layers for DOSBox-X. The repository ships no copyrighted game assets; every tool expects files from a legally obtained copy you provide. It is aimed at hobbyists doing reverse engineering, fan translation, save editing, and hands-on file-format research rather than commercial anti-cheat or live-service security work.
