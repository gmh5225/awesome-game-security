BatteryShark Writeup Archive — это сайт GitHub Pages на Jekyll, служащий каноническим домом для развёрнутых статей по исследованию безопасности и реверс-инжинирингу. Коллекция охватывает взлом игр, патчи совместимости для классических ПК, внутреннее устройство Windows, разбор аппаратных донглов и аркадных платформ, а также практические руководства по инструментам, часто с встроенными фрагментами Python и заметками по дизассемблированию для IDA. Публикации организованы по фиксированным темам и многотомным сериям, включая серию Masterpiece о консолизации PC-игр и новые материалы об отладке ядра с QEMU-GDB и управлении безопасностью ИИ. Сайт построен на Ruby, Markdown и SCSS и ориентирован на реверс-инженеров, исследователей безопасности игр и специалистов, работающих с устаревшим ПО, аркадным железом и низкоуровневыми системами.
