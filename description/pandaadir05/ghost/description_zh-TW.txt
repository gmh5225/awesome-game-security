Ghost 是一款以 Rust 撰寫的跨平台程序注入偵測框架，可掃描執行中的程序，偵測程式碼注入、記憶體竄改，以及惡意軟體與未授權注入程式碼常用的其他規避技術。它能偵測可疑的 RWX 記憶體區域、shellcode 特徵、API 與函式庫 hook、程序挖空、執行緒異常，以及可選的 YARA 規則比對，並將發現對應至 MITRE ATT&CK 技術。專案提供 CLI 與互動式終端 UI，支援持續監看模式、基線差異比對、可設定的 TOML 設定與 webhook 告警，另含可選的 Python 機器學習模組，用於行為與 shellcode 分類。可在 Windows、Linux 與 macOS 上執行，面向需要即時端點偵測注入型威脅的安全研究人員、防禦人員與遊戲反作弊分析人員。
