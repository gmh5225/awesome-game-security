Ghost 是一款用 Rust 编写的跨平台进程注入检测框架，可扫描正在运行的进程，查找代码注入、内存篡改以及恶意软件与未授权注入代码常用的其他规避技术。它能检测可疑的 RWX 内存区域、shellcode 特征、API 与库挂钩、进程挖空、线程异常以及可选的 YARA 规则匹配，并将发现映射到 MITRE ATT&CK 技术。项目提供 CLI 和交互式终端 UI，支持持续监视模式、基线差异对比、可配置的 TOML 设置和 webhook 告警，另含可选的 Python 机器学习模块用于行为与 shellcode 分类。可在 Windows、Linux 和 macOS 上运行，面向需要实时端点检测注入类威胁的安全研究人员、防御者与游戏反作弊分析人员。
