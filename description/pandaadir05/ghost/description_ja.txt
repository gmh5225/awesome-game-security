Ghost は Rust で書かれたクロスプラットフォームのプロセスインジェクション検出フレームワークで、実行中のプロセスをスキャンし、コードインジェクション、メモリ改ざん、マルウェアや不正な注入コードで一般的に用いられるその他の回避手法を検出します。疑わしい RWX メモリ領域、シェルコードパターン、API およびライブラリフック、プロセスホローイング、スレッド異常、オプションの YARA ルール一致を検出し、所見を MITRE ATT&CK 技法にマッピングします。プロジェクトには CLI と対話型ターミナル UI が同梱され、継続監視モード、ベースライン差分、設定可能な TOML、webhook アラートをサポートし、さらに行動およびシェルコード分類用のオプション Python 機械学習モジュールも備えています。Windows、Linux、macOS 上で動作し、インジェクション系脅威のライブなエンドポイント検出を必要とするセキュリティ研究者、防御担当者、ゲームアンチチート分析者を対象としています。
