Ghost는 Rust로 작성된 크로스 플랫폼 프로세스 인젝션 탐지 프레임워크로, 실행 중인 프로세스를 스캔하여 코드 인젝션, 메모리 변조, 악성코드 및 무단 인젝션 코드에서 흔히 사용하는 기타 회피 기법을 찾습니다. 의심스러운 RWX 메모리 영역, 셸코드 패턴, API 및 라이브러리 후킹, 프로세스 할로잉, 스레드 이상, 선택적 YARA 규칙 일치를 탐지하고, 발견 사항을 MITRE ATT&CK 기법에 매핑합니다. 프로젝트에는 CLI와 대화형 터미널 UI가 포함되어 지속 감시 모드, 기준선 차분, 구성 가능한 TOML 설정, webhook 알림을 지원하며, 행동 및 셸코드 분류를 위한 선택적 Python 머신러닝 모듈도 제공합니다. Windows, Linux, macOS에서 실행되며, 인젝션 기반 위협에 대한 실시간 엔드포인트 탐지가 필요한 보안 연구자, 방어 담당자, 게임 안티치트 분석가를 대상으로 합니다.
