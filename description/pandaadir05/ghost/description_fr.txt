Ghost est un framework multiplateforme de détection d'injection de processus écrit en Rust qui analyse les processus en cours d'exécution pour repérer l'injection de code, la falsification de mémoire et d'autres techniques d'évasion couramment utilisées par les logiciels malveillants et le code injecté non autorisé. Il détecte les régions mémoire RWX suspectes, les motifs de shellcode, les hooks d'API et de bibliothèques, le process hollowing, les anomalies de threads et les correspondances optionnelles de règles YARA, en mappant les résultats aux techniques MITRE ATT&CK. Le projet inclut une CLI et une interface terminal interactive prenant en charge le mode de surveillance continue, la comparaison différentielle par rapport à une baseline, une configuration TOML et des alertes webhook, ainsi qu'un module optionnel d'apprentissage automatique Python pour la classification comportementale et des shellcodes. Il fonctionne sous Windows, Linux et macOS et s'adresse aux chercheurs en sécurité, aux défenseurs et aux analystes anti-triche de jeux qui ont besoin d'une détection en temps réel sur endpoint des menaces basées sur l'injection.
