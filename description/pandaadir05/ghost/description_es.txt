Ghost es un framework multiplataforma de detección de inyección de procesos escrito en Rust que analiza los procesos en ejecución en busca de inyección de código, manipulación de memoria y otras técnicas de evasión comúnmente usadas por malware y código inyectado no autorizado. Detecta regiones de memoria RWX sospechosas, patrones de shellcode, hooks de API y bibliotecas, process hollowing, anomalías en hilos y coincidencias opcionales de reglas YARA, mapeando los hallazgos a técnicas MITRE ATT&CK. El proyecto incluye una CLI y una interfaz de terminal interactiva con modo de vigilancia continua, diferenciación de línea base, configuración TOML y alertas webhook, además de un módulo opcional de aprendizaje automático en Python para clasificación comportamental y de shellcode. Funciona en Windows, Linux y macOS y está pensado para investigadores de seguridad, defensores y analistas de anti-cheat de juegos que necesitan detección en vivo en el endpoint de amenazas basadas en inyección.
