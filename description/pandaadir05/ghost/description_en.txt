Ghost is a cross-platform process injection detection framework written in Rust that scans running processes for code injection, memory tampering, and other evasion techniques commonly used by malware and unauthorized injected code. It detects suspicious RWX memory regions, shellcode patterns, API and library hooks, process hollowing, thread anomalies, and optional YARA rule matches, mapping findings to MITRE ATT&CK techniques. The project ships with a CLI and interactive terminal UI supporting continuous watch mode, baseline differencing, configurable TOML settings, and webhook alerts, plus an optional Python machine learning module for behavioral and shellcode classification. It runs on Windows, Linux, and macOS and is intended for security researchers, defenders, and game anti-cheat analysts who need live endpoint detection of injection-based threats.
