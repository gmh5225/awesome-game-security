Ghost — это кроссплатформенный фреймворк обнаружения инъекций в процессы, написанный на Rust, который сканирует запущенные процессы на предмет инъекции кода, подмены памяти и других техник уклонения, часто используемых вредоносным ПО и несанкционированным инжектированным кодом. Он выявляет подозрительные области памяти RWX, шаблоны shellcode, перехваты API и библиотек, process hollowing, аномалии потоков и необязательные совпадения с правилами YARA, сопоставляя находки с техниками MITRE ATT&CK. Проект поставляется с CLI и интерактивным терминальным UI, поддерживающими непрерывный режим наблюдения, сравнение с базовой линией, настраиваемые параметры TOML и webhook-оповещения, а также необязательным модулем машинного обучения на Python для поведенческой классификации и классификации shellcode. Работает в Windows, Linux и macOS и предназначен для исследователей безопасности, защитников и аналитиков античита в играх, которым нужно обнаружение угроз на основе инъекций в реальном времени на конечных точках.
