Ghost ist ein plattformübergreifendes Framework zur Erkennung von Prozessinjektionen, geschrieben in Rust, das laufende Prozesse auf Code-Injektion, Speichermanipulation und andere Ausweichtechniken scannt, die von Malware und unbefugtem injiziertem Code häufig genutzt werden. Es erkennt verdächtige RWX-Speicherbereiche, Shellcode-Muster, API- und Bibliotheks-Hooks, Process Hollowing, Thread-Anomalien und optionale YARA-Regel-Treffer und ordnet Befunde den MITRE-ATT&CK-Techniken zu. Das Projekt bietet eine CLI und eine interaktive Terminal-UI mit kontinuierlichem Überwachungsmodus, Baseline-Differenzierung, konfigurierbaren TOML-Einstellungen und Webhook-Benachrichtigungen sowie ein optionales Python-Machine-Learning-Modul zur Verhaltens- und Shellcode-Klassifizierung. Es läuft unter Windows, Linux und macOS und richtet sich an Sicherheitsforscher, Verteidiger und Game-Anti-Cheat-Analysten, die eine Live-Endpoint-Erkennung injektionsbasierter Bedrohungen benötigen.
