IDA Bridge 是一个 Python 框架，可将 AI 智能体连接到 IDA Pro，通过 WebSocket 桥接服务器实现 IDAPython 执行以及对实时 IDA 数据库的 SQL 查询。它既支持通过插件使用 IDA 界面，也支持无界面 idalib 工作流，并提供 CLI 用于列出已连接实例、运行代码以及通过 supervisor 命令管理 IDA 生命周期。SQL 接口可暴露函数、反汇编、反编译输出、类型、交叉引用及其他 IDB 数据，使智能体无需依赖易出错的 IDAPython API 知识即可分析二进制文件。主要功能包括有状态与无状态 exec 会话、一次性 exec-idb 无界面运行、dyld 共享缓存单模块提取以及可复用的分析代码片段。面向希望借助 AI 进行二进制分析、标注与探索的逆向工程师与游戏安全研究人员，适用于 IDA Pro 9.0 及更高版本。
