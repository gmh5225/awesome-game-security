IDA Bridge は、AI エージェントを IDA Pro に接続する Python フレームワークで、WebSocket ブリッジサーバー経由で IDAPython の実行とライブ IDA データベースに対する SQL クエリを可能にします。IDA UI 向けプラグインとヘッドレス idalib ワークフローの両方をサポートし、接続済みインスタンスの一覧表示、コード実行、supervisor コマンドによる IDA ライフサイクル管理を行う CLI も備えています。SQL インターフェースは関数、逆アセンブリ、デコンパイラ出力、型、クロスリファレンス、その他の IDB データを公開し、エージェントが不安定な IDAPython API の知識に頼らずバイナリを分析できるようにします。主な機能には、ステートフルおよびステートレスな exec セッション、ワンショット exec-idb ヘッドレス実行、dyld 共有キャッシュからの単一モジュール抽出、再利用可能な分析スニペットが含まれます。IDA Pro 9.0 以降で、AI 支援によるバイナリ分析、アノテーション、実行ファイルの探索を求めるリバースエンジニアとゲームセキュリティ研究者を対象としています。
