IDA Bridge est un framework Python qui connecte les agents IA à IDA Pro, permettant l'exécution IDAPython et des requêtes SQL sur des bases de données IDA en direct via un serveur pont WebSocket. Il prend en charge l'interface IDA via un plugin ainsi que les workflows idalib headless, avec une CLI pour lister les instances connectées, exécuter du code et gérer le cycle de vie d'IDA via des commandes supervisor. Une interface SQL expose les fonctions, le désassemblage, la sortie du décompilateur, les types, les références croisées et autres données IDB afin que les agents puissent analyser les binaires sans dépendre d'une connaissance fragile de l'API IDAPython. Les capacités clés incluent des sessions exec stateful et stateless, des exécutions headless exec-idb en one-shot, l'extraction d'un module unique depuis le cache partagé dyld et des extraits d'analyse réutilisables. Il s'adresse aux ingénieurs en rétro-ingénierie et chercheurs en sécurité des jeux qui souhaitent une analyse binaire assistée par IA, l'annotation et l'exploration d'exécutables dans IDA Pro 9.0 et versions ultérieures.
