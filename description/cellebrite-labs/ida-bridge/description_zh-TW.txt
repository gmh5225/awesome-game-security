IDA Bridge 是一個 Python 框架，可將 AI 代理連接至 IDA Pro，透過 WebSocket 橋接伺服器實現 IDAPython 執行以及對即時 IDA 資料庫的 SQL 查詢。它同時支援透過外掛程式使用 IDA 介面與無介面 idalib 工作流程，並提供 CLI 用於列出已連線執行個體、執行程式碼，以及透過 supervisor 指令管理 IDA 生命週期。SQL 介面可公開函式、反組譯、反編譯輸出、型別、交叉參考及其他 IDB 資料，讓代理無需依賴易出錯的 IDAPython API 知識即可分析二進位檔。主要功能包含有狀態與無狀態 exec 工作階段、一次性 exec-idb 無介面執行、dyld 共享快取單模組擷取，以及可重複使用的分析程式碼片段。面向希望借助 AI 進行二進位分析、標註與探索的逆向工程師與遊戲安全研究人員，適用於 IDA Pro 9.0 及更高版本。
