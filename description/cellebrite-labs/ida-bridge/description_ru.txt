IDA Bridge — это Python-фреймворк, который подключает ИИ-агентов к IDA Pro, обеспечивая выполнение IDAPython и SQL-запросы к активным базам данных IDA через WebSocket-мостовой сервер. Он поддерживает как интерфейс IDA через плагин, так и headless-рабочие процессы idalib, с CLI для перечисления подключённых экземпляров, запуска кода и управления жизненным циклом IDA через команды supervisor. SQL-интерфейс предоставляет доступ к функциям, дизассемблированию, выводу декомпилятора, типам, перекрёстным ссылкам и другим данным IDB, чтобы агенты могли анализировать бинарники без опоры на хрупкие знания API IDAPython. Ключевые возможности включают stateful и stateless exec-сессии, одноразовые headless-запуски exec-idb, извлечение отдельного модуля из dyld shared cache и переиспользуемые фрагменты анализа. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности игр, которым нужен ИИ-поддерживаемый анализ бинарников, аннотирование и исследование исполняемых файлов в IDA Pro 9.0 и новее.
