IDA Bridge는 AI 에이전트를 IDA Pro에 연결하는 Python 프레임워크로, WebSocket 브리지 서버를 통해 IDAPython 실행과 라이브 IDA 데이터베이스에 대한 SQL 쿼리를 가능하게 합니다. IDA UI용 플러그인과 헤드리스 idalib 워크플로를 모두 지원하며, 연결된 인스턴스 나열, 코드 실행, supervisor 명령을 통한 IDA 수명 주기 관리를 위한 CLI도 제공합니다. SQL 인터페이스는 함수, 디스어셈블리, 디컴파일러 출력, 타입, 교차 참조 및 기타 IDB 데이터를 노출하여 에이전트가 불안정한 IDAPython API 지식에 의존하지 않고 바이너리를 분석할 수 있게 합니다. 주요 기능에는 상태 유지 및 무상태 exec 세션, 일회성 exec-idb 헤드리스 실행, dyld 공유 캐시 단일 모듈 추출, 재사용 가능한 분석 스니펫이 포함됩니다. IDA Pro 9.0 이상에서 AI 지원 바이너리 분석, 주석 작성 및 실행 파일 탐색을 원하는 리버스 엔지니어와 게임 보안 연구자를 대상으로 합니다.
