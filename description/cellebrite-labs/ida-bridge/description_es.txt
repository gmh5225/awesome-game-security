IDA Bridge es un framework de Python que conecta agentes de IA con IDA Pro, permitiendo la ejecución de IDAPython y consultas SQL contra bases de datos IDA en vivo a través de un servidor puente WebSocket. Admite tanto la interfaz de IDA mediante un plugin como flujos de trabajo headless con idalib, con una CLI para listar instancias conectadas, ejecutar código y gestionar el ciclo de vida de IDA mediante comandos supervisor. Una interfaz SQL expone funciones, desensamblado, salida del descompilador, tipos, referencias cruzadas y otros datos IDB para que los agentes puedan analizar binarios sin depender de un conocimiento frágil de la API IDAPython. Las capacidades clave incluyen sesiones exec con y sin estado, ejecuciones headless exec-idb de un solo uso, extracción de un módulo único de la caché compartida dyld y fragmentos de análisis reutilizables. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad de juegos que desean análisis binario asistido por IA, anotación y exploración de ejecutables en IDA Pro 9.0 y versiones posteriores.
