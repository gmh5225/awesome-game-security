IDA Bridge è un framework Python che collega agenti IA a IDA Pro, consentendo l'esecuzione IDAPython e query SQL su database IDA live tramite un server bridge WebSocket. Supporta sia l'interfaccia IDA tramite plugin sia workflow idalib headless, con una CLI per elencare le istanze connesse, eseguire codice e gestire il ciclo di vita di IDA tramite comandi supervisor. Un'interfaccia SQL espone funzioni, disassembly, output del decompilatore, tipi, cross-reference e altri dati IDB affinché gli agenti possano analizzare i binari senza affidarsi a una conoscenza fragile dell'API IDAPython. Le capacità principali includono sessioni exec stateful e stateless, esecuzioni headless exec-idb one-shot, estrazione di un singolo modulo dalla shared cache dyld e snippet di analisi riutilizzabili. È destinato a reverse engineer e ricercatori di sicurezza dei giochi che desiderano analisi binaria assistita da IA, annotazione ed esplorazione di eseguibili in IDA Pro 9.0 e versioni successive.
