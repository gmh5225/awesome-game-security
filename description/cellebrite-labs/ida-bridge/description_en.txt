IDA Bridge is a Python framework that connects AI agents to IDA Pro, enabling IDAPython execution and SQL queries against live IDA databases through a WebSocket bridge server. It supports both the IDA UI via a plugin and headless idalib workflows, with a CLI for listing connected instances, running code, and managing IDA lifecycle through supervisor commands. A SQL interface exposes functions, disassembly, decompiler output, types, cross-references, and other IDB data so agents can analyze binaries without relying on fragile IDAPython API knowledge. Key capabilities include stateful and stateless exec sessions, one-shot exec-idb headless runs, dyld shared cache single-module extraction, and reusable analysis snippets. It is aimed at reverse engineers and game security researchers who want AI-assisted binary analysis, annotation, and exploration of executables in IDA Pro 9.0 and later.
