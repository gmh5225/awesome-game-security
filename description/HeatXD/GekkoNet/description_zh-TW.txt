GekkoNet 是一個用於建構確定性、幀同步多人遊戲的 C/C++ 回滾與 lockstep 網路程式碼函式庫。它提供 C API，用於管理工作階段、交換玩家輸入，以及驅動回滾過程中使用的儲存/載入事件，並支援可設定的輸入預測、runahead、本地輸入延遲，以及可選的純 lockstep 模式。此函式庫內建基於 ASIO 的 UDP 介面卡，還提供觀戰支援、壓縮重播錄製與播放、基於校驗和的 desync 偵測，以及 ping 和 jitter 等網路統計資訊。基於 SDL3 的範例涵蓋本地、線上、觀戰和壓力測試工作階段，專案可透過 CMake 和 Visual Studio 建置為靜態或共享函式庫。它面向需要可靠點對點網路程式碼，以及用於偵測、重現和除錯用戶端狀態分歧的實用工具的遊戲開發者與研究人員。
