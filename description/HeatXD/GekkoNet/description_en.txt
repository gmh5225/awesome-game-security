GekkoNet is a C/C++ rollback and lockstep netcode library for building deterministic, frame-synchronized multiplayer games. It exposes a C API for managing sessions, exchanging player inputs, and driving save/load events used during rollback, with configurable input prediction, runahead, local input delay, and optional lockstep-only play. The library ships with a built-in UDP adapter powered by ASIO, plus spectator support, compressed replay recording and playback, checksum-based desync detection, and network statistics such as ping and jitter. SDL3-based examples cover local, online, spectator, and stress-test sessions, and the project builds as static or shared libraries with CMake and Visual Studio. It is intended for game developers and researchers who need reliable peer-to-peer netcode and practical tooling to detect, reproduce, and debug client state divergence.
