GekkoNet 是一个用于构建确定性、帧同步多人游戏的 C/C++ 回滚与 lockstep 网络代码库。它提供 C API，用于管理会话、交换玩家输入，以及驱动回滚过程中使用的保存/加载事件，并支持可配置的输入预测、runahead、本地输入延迟，以及可选的纯 lockstep 模式。该库内置基于 ASIO 的 UDP 适配器，还提供观战支持、压缩回放录制与播放、基于校验和的 desync 检测，以及 ping 和 jitter 等网络统计信息。基于 SDL3 的示例涵盖本地、在线、观战和压力测试会话，项目可通过 CMake 和 Visual Studio 构建为静态或共享库。它面向需要可靠点对点网络代码，以及用于检测、复现和调试客户端状态分歧的实用工具的游戏开发者和研究人员。
