GekkoNet は、決定論的でフレーム同期型のマルチプレイヤーゲームを構築するための C/C++ ロールバックおよび lockstep ネットコードライブラリです。セッション管理、プレイヤー入力の交換、ロールバック時に使用するセーブ/ロードイベントの駆動を行う C API を提供し、入力予測、runahead、ローカル入力遅延の設定、および lockstep のみのプレイも選択できます。ASIO ベースの組み込み UDP アダプターに加え、観戦サポート、圧縮リプレイの記録と再生、チェックサムによる desync 検出、ping や jitter などのネットワーク統計も備えています。SDL3 ベースのサンプルはローカル、オンライン、観戦、ストレステストの各セッションをカバーし、CMake と Visual Studio で静的または共有ライブラリとしてビルドできます。信頼性の高い P2P ネットコードと、クライアント状態の乖離を検出・再現・デバッグする実用的なツールを必要とするゲーム開発者や研究者向けです。
