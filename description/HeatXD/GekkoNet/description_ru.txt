GekkoNet — это библиотека сетевого кода на C/C++ с rollback и lockstep для создания детерминированных многопользовательских игр с покадровой синхронизацией. Она предоставляет C API для управления сессиями, обмена вводом игроков и обработки событий сохранения/загрузки, используемых при rollback, с настраиваемым предсказанием ввода, runahead, локальной задержкой ввода и опциональной игрой только в режиме lockstep. Библиотека включает встроенный UDP-адаптер на базе ASIO, а также поддержку зрителей, сжатую запись и воспроизведение реплеев, обнаружение рассинхронизации по контрольным суммам и сетевую статистику, такую как ping и jitter. Примеры на базе SDL3 охватывают локальные, онлайн-, зрительские и стресс-тестовые сессии, а проект собирается как статические или разделяемые библиотеки с помощью CMake и Visual Studio. Она предназначена для разработчиков игр и исследователей, которым нужен надёжный peer-to-peer netcode и практичные инструменты для обнаружения, воспроизведения и отладки расхождений состояния клиентов.
