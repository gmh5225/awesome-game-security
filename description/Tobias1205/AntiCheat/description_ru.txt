ShieldGuard — плагин сервера Minecraft для Paper 1.21.x, усиливающий защиту многопользовательского выживания от читов на стороне клиента за счёт перезаписи исходящих пакетов чанков и блоков для каждого игрока. Написан на Java 21 и собран Maven; интегрируется с PacketEvents, чтобы маскировать глубокий подземный рельеф от freecam, заменять всю руду камнем или глубинным сланцем, пока игрок не окажется в настраиваемом радиусе с прямой видимостью, и скрывать блоки хранения и связанные сущности против x-ray и ESP по сундукам. Также есть рабочий процесс жалоб для персонала: команды в игре, GUI управления, опциональные Discord webhook и обход по правам для тестирования. Основная аудитория — администраторы игровых серверов на Paper, которым нужны практичные средства античита и модерации без клиентских модов.
