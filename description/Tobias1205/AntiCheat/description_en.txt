ShieldGuard is a Paper 1.21.x Minecraft server plugin that hardens survival multiplayer against client-side cheating by rewriting outbound chunk and block packets per player. Written in Java 21 and built with Maven, it integrates PacketEvents to mask deep underground terrain against freecam, replace all ores with stone or deepslate until the player is within a configurable radius with clear line of sight, and hide storage blocks and related entities to block x-ray and storage ESP. It also ships a staff-facing report workflow with in-game commands, a management GUI, optional Discord webhooks, and permission-based bypass for testing. Server operators running Paper-based game servers who need practical anti-cheat and moderation tooling without client mods are the primary audience.
