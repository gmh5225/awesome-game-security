ShieldGuard 是一款適用於 Paper 1.21.x 的 Minecraft 伺服器外掛，透過依玩家重寫出站區塊與方塊封包，強化生存多人模式對用戶端作弊的防護。以 Java 21 撰寫並以 Maven 建置，整合 PacketEvents：在地下深處對 freecam 進行地形遮蔽、在玩家進入可設定半徑且視線暢通之前將所有礦石替換為石頭或深板岩，並隱藏儲物方塊及相關實體以阻擋 x-ray 與儲物 ESP。此外提供面向管理員的檢舉流程（遊戲內指令、管理 GUI、可選 Discord webhook）以及基於權限的 bypass 便於測試。主要對象為營運 Paper 系遊戲伺服器、需要實用反作弊與管理工具且無需用戶端模組的伺服器管理者。
