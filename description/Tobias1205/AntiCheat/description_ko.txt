ShieldGuard는 Paper 1.21.x용 Minecraft 서버 플러그인으로, 플레이어별로 나가는 청크 및 블록 패킷을 다시 써서 서바이벌 멀티플레이를 클라이언트 측 치팅으로부터 강화합니다. Java 21로 작성되었고 Maven으로 빌드하며, PacketEvents와 통합해 지하 깊은 지형을 freecam에 대해 가리고, 플레이어가 설정 가능한 반경 안에 들어와 시야가 확보될 때까지 모든 광석을 돌이나 심층암으로 바꾸며, 저장 블록과 관련 엔티티를 숨겨 x-ray 및 저장 ESP를 막습니다. 또한 스태프용 신고 워크플로(게임 내 명령, 관리 GUI, 선택적 Discord webhook)와 테스트용 권한 기반 bypass를 제공합니다. Paper 기반 게임 서버를 운영하며 클라이언트 모드 없이 실용적인 안티치트 및 모더레이션 도구가 필요한 서버 운영자가 주 대상입니다.
