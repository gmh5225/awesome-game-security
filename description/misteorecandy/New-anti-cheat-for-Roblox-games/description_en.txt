Shadow Nextbot Anti-Cheat is a Roblox Studio anti-cheat package that punishes suspected exploiters with a psychological horror chase instead of an immediate kick. It is implemented in Luau as paired server and local scripts: the server monitors movement on Heartbeat to flag speed hacks and prolonged flight, while the client dims lighting, spawns a wall-passing shadow Nextbot, and plays whisper audio that escalates to a fullscreen jumpscare before the player is removed. Communication uses a ReplicatedStorage RemoteEvent and configurable thresholds such as maximum speed and air time. The project targets Roblox developers who want lightweight, server-authoritative cheat detection with an immersive deterrent for game security and anti-exploit enforcement.
