Shadow Nextbot Anti-Cheat は、疑わしいチーターに即座のキックではなく心理的ホラーによる追跡で応答する Roblox Studio 向けアンチチートパッケージです。Luau で実装され、サーバー用とローカル用のスクリプトが対になっています。サーバーは Heartbeat 上で移動を監視しスピードハックや長時間の飛行を検知し、クライアントは照明を暗くし、壁を通過する影の Nextbot を出現させ、ささやき音声が全画面ジャンプスケアへとエスカレートしてからプレイヤーを排除します。通信には ReplicatedStorage の RemoteEvent を使い、最大速度や空中時間などの閾値を設定できます。軽量でサーバー権威型のチート検知と没入感のある抑止力でゲームセキュリティとアンチエクスプロイトを強化したい Roblox 開発者向けです。
