Ceasta 是一款集反組譯器、反編譯器與除錯器於一體的二進位分析工具，支援 Windows 與 Linux。此工具以 C++17 撰寫，可載入 PE 與 ELF 可執行檔與函式庫，自動進行函式與交叉參考分析，並以 IDA 風格的列表呈現類 C 偽程式碼、控制流程圖，以及具備中斷點、單步執行與即時記憶體檢視功能的 x64dbg 風格除錯器。它支援 Lua 腳本與外掛、二進位差異比對、函式庫特徵簽名比對，以及用於自動化的命令列介面，並內建 MCP 伺服器，讓 AI 助手能對已開啟的二進位檔進行反編譯、重新命名與引導式除錯。此工具面向需要獨立、自包含環境來檢查、追蹤與理解原生程式碼（如遊戲用戶端、反作弊模組及其他受保護二進位檔）的逆向工程師與資安研究人員。
