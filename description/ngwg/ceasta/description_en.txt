Ceasta is an all-in-one binary analysis tool that combines a disassembler, decompiler, and debugger for Windows and Linux. Written in C++17, it loads PE and ELF executables and libraries, performs automated function and cross-reference analysis, and presents an IDA-style listing with C-like pseudocode, a control-flow graph, and an x64dbg-style debugger with breakpoints, stepping, and live memory inspection. It supports Lua scripting and plugins, binary diffing, library signature matching, and a command-line interface for automation, plus a built-in MCP server that lets AI assistants interact with open binaries for decompilation, renaming, and guided debugging. The tool is aimed at reverse engineers and security researchers who need a self-contained, vendored environment to inspect, trace, and understand native code such as game clients, anti-cheat modules, and other protected binaries.
