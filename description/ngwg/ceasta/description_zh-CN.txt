Ceasta 是一款集反汇编器、反编译器和调试器于一体的二进制分析工具，支持 Windows 和 Linux。该工具使用 C++17 编写，可加载 PE 和 ELF 可执行文件与库，自动进行函数与交叉引用分析，并以 IDA 风格的列表展示 C 语言式伪代码、控制流图，以及具备断点、单步和实时内存查看功能的 x64dbg 风格调试器。它支持 Lua 脚本与插件、二进制差异对比、库特征签名匹配，以及用于自动化的命令行界面，还内置 MCP 服务器，使 AI 助手能够对已打开的二进制文件进行反编译、重命名和引导式调试。该工具面向需要独立、自包含环境来检查、追踪和理解原生代码（如游戏客户端、反作弊模块及其他受保护二进制文件）的逆向工程师和安全研究人员。
