windbg-tool is a Windows-first command-line tool and Model Context Protocol server that automates WinDbg-oriented debugging workflows, with a primary focus on Microsoft Time Travel Debugging trace replay. Written mainly in Rust with a native C++ bridge to the TTD Replay API, it lets analysts open and navigate .run traces, inspect registers and memory, disassemble code, resolve symbols, and triage user or kernel crash dumps without manual debugger interaction. It can also record new TTD traces, run one-shot live probes such as startup and managed breakpoints, and expose stable JSON-oriented commands plus an MCP server so AI agents and scripts can drive analysis programmatically. The tool includes a long-lived local daemon for replay sessions, DbgEng remote-server helpers, and utilities to install, update, and launch WinDbg. It targets reverse engineers, security researchers, and game-security analysts who need repeatable, automatable Windows debugging for crash investigation, behavioral analysis, and anti-cheat or malware research.
