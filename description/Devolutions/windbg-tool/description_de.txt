windbg-tool ist ein Windows-orientiertes Kommandozeilenwerkzeug und Model Context Protocol (MCP)-Server, das WinDbg-orientierte Debugging-Workflows automatisiert, mit Schwerpunkt auf der Wiedergabe von Microsoft Time Travel Debugging (TTD)-Traces. Hauptsächlich in Rust geschrieben und mit einer nativen C++-Brücke zur TTD Replay API, ermöglicht es Analysten, .run-Traces zu öffnen und zu navigieren, Register und Speicher zu untersuchen, Code zu disassemblieren, Symbole aufzulösen sowie User- oder Kernel-Crash-Dumps zu triagieren – ohne manuelle Debugger-Interaktion. Es kann auch neue TTD-Traces aufzeichnen, einmalige Live-Sonden wie Start- und Managed-Breakpoints ausführen und stabile JSON-orientierte Befehle sowie einen MCP-Server bereitstellen, damit KI-Agenten und Skripte Analysen programmatisch steuern können. Das Tool umfasst einen langlebigen lokalen Daemon für Replay-Sitzungen, DbgEng-Remoteserver-Helfer und Dienstprogramme zum Installieren, Aktualisieren und Starten von WinDbg. Es richtet sich an Reverse Engineers, Sicherheitsforscher und Game-Security-Analysten, die wiederholbares, automatisierbares Windows-Debugging für Crash-Untersuchungen, Verhaltensanalysen sowie Anti-Cheat- oder Malware-Forschung benötigen.
