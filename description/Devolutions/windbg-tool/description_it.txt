windbg-tool è uno strumento a riga di comando orientato a Windows e un server Model Context Protocol (MCP) che automatizza i flussi di lavoro di debug basati su WinDbg, con focus principale sulla riproduzione delle tracce Microsoft Time Travel Debugging (TTD). Scritto principalmente in Rust con un ponte nativo C++ verso l'API TTD Replay, consente agli analisti di aprire e navigare tracce .run, ispezionare registri e memoria, disassemblare codice, risolvere simboli e classificare dump di crash utente o kernel senza interazione manuale con il debugger. Può anche registrare nuove tracce TTD, eseguire sonde live una tantum come breakpoint di avvio e gestiti, ed esporre comandi stabili orientati a JSON più un server MCP affinché agenti IA e script guidino l'analisi in modo programmatico. Lo strumento include un demone locale a lunga durata per sessioni di riproduzione, helper per server remoto DbgEng e utilità per installare, aggiornare e avviare WinDbg. È rivolto a reverse engineer, ricercatori di sicurezza e analisti di sicurezza dei giochi che necessitano di debug Windows ripetibile e automatizzabile per indagini su crash, analisi comportamentale e ricerca anti-cheat o su malware.
