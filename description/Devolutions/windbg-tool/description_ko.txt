windbg-tool은 Windows 우선 명령줄 도구이자 Model Context Protocol(MCP) 서버로, WinDbg 중심 디버깅 워크플로를 자동화하며 Microsoft Time Travel Debugging(TTD) 추적 재생에 주력합니다. 주로 Rust로 작성되었고 TTD Replay API에 대한 네이티브 C++ 브리지를 통해, 분석가가 디버거를 수동으로 조작하지 않고도 .run 추적을 열고 탐색하며 레지스터와 메모리를 검사하고, 코드를 디스어셈블하고, 심볼을 해석하고, 사용자 또는 커널 크래시 덤프를 분류할 수 있습니다. 새 TTD 추적을 기록하고, 시작 및 관리형 중단점과 같은 일회성 라이브 프로브를 실행하며, 안정적인 JSON 지향 명령과 MCP 서버를 제공하여 AI 에이전트와 스크립트가 프로그래밍 방식으로 분석을 수행할 수 있습니다. 이 도구에는 재생 세션용 장기 실행 로컬 데몬, DbgEng 원격 서버 헬퍼, WinDbg 설치·업데이트·실행 유틸리티가 포함됩니다. 크래시 조사, 행동 분석, 안티치트 또는 멀웨어 연구를 위해 반복 가능하고 자동화 가능한 Windows 디버깅이 필요한 리버스 엔지니어, 보안 연구원, 게임 보안 분석가를 대상으로 합니다.
