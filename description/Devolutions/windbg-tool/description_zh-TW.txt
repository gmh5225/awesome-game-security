windbg-tool 是一款以 Windows 為優先的命令列工具，也是 Model Context Protocol（MCP）伺服器，用於自動化面向 WinDbg 的除錯工作流程，主要聚焦於 Microsoft Time Travel Debugging（TTD）追蹤回放。此工具主要以 Rust 撰寫，並透過原生 C++ 橋接 TTD Replay API，使分析人員無需手動操作除錯器即可開啟並瀏覽 .run 追蹤、檢查暫存器與記憶體、反組譯程式碼、解析符號，以及分類使用者模式或核心模式當機傾印。它還可錄製新的 TTD 追蹤、執行一次性即時探測（如啟動與受控中斷點），並提供穩定的 JSON 導向命令及 MCP 伺服器，以便 AI 代理與腳本以程式化方式驅動分析。此工具包含用於回放工作階段的長駐本機守護程序、DbgEng 遠端伺服器輔助元件，以及安裝、更新與啟動 WinDbg 的實用工具。面向需要可重複、可自動化 Windows 除錯的逆向工程師、安全研究人員與遊戲安全分析師，適用於當機調查、行為分析以及反作弊或惡意軟體研究。
