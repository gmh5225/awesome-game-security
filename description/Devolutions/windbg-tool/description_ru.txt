windbg-tool — это ориентированный на Windows инструмент командной строки и сервер Model Context Protocol (MCP), автоматизирующий рабочие процессы отладки в WinDbg с основным акцентом на воспроизведение трасс Microsoft Time Travel Debugging (TTD). Написанный преимущественно на Rust с нативным C++-мостом к TTD Replay API, он позволяет аналитикам открывать и просматривать .run-трассы, исследовать регистры и память, дизассемблировать код, разрешать символы и сортировать пользовательские или ядерные дампы сбоев без ручного взаимодействия с отладчиком. Он также может записывать новые TTD-трассы, выполнять одноразовые живые пробы, такие как точки останова при запуске и управляемые точки останова, и предоставлять стабильные команды на основе JSON и MCP-сервер, чтобы ИИ-агенты и скрипты могли программно управлять анализом. Инструмент включает долгоживущий локальный демон для сессий воспроизведения, вспомогательные средства удалённого сервера DbgEng и утилиты для установки, обновления и запуска WinDbg. Он предназначен для специалистов по реверс-инжинирингу, исследователей безопасности и аналитиков игровой безопасности, которым нужна повторяемая и автоматизируемая отладка Windows для расследования сбоев, анализа поведения и исследований античит-систем или вредоносного ПО.
