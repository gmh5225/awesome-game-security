windbg-tool 是一款以 Windows 为先的命令行工具，也是 Model Context Protocol（MCP）服务器，用于自动化面向 WinDbg 的调试工作流，主要聚焦于 Microsoft Time Travel Debugging（TTD）跟踪回放。该工具主要用 Rust 编写，并通过原生 C++ 桥接 TTD Replay API，使分析人员无需手动操作调试器即可打开并浏览 .run 跟踪、检查寄存器与内存、反汇编代码、解析符号，以及分类用户态或内核崩溃转储。它还可录制新的 TTD 跟踪、运行一次性实时探测（如启动与托管断点），并提供稳定的 JSON 导向命令及 MCP 服务器，以便 AI 智能体与脚本以编程方式驱动分析。该工具包含用于回放会话的长驻本地守护进程、DbgEng 远程服务器辅助组件，以及安装、更新与启动 WinDbg 的实用工具。面向需要可重复、可自动化 Windows 调试的逆向工程师、安全研究人员与游戏安全分析师，适用于崩溃调查、行为分析以及反作弊或恶意软件研究。
