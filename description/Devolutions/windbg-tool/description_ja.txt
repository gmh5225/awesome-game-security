windbg-tool は Windows 向けのコマンドラインツールおよび Model Context Protocol（MCP）サーバーで、WinDbg 向けのデバッグワークフローを自動化し、主に Microsoft Time Travel Debugging（TTD）トレースのリプレイに焦点を当てています。主に Rust で書かれ、TTD Replay API へのネイティブ C++ ブリッジを備え、分析者が手動でデバッガを操作することなく .run トレースを開いて移動し、レジスタやメモリを調査し、コードを逆アセンブルし、シンボルを解決し、ユーザーモードまたはカーネルモードのクラッシュダンプをトリアージできます。新しい TTD トレースの記録、起動やマネージドブレークポイントなどのワンショットのライブプローブの実行、安定した JSON 指向コマンドおよび MCP サーバーの提供により、AI エージェントやスクリプトがプログラム的に分析を駆動できます。リプレイセッション用の長寿命ローカルデーモン、DbgEng リモートサーバーヘルパー、WinDbg のインストール・更新・起動ユーティリティも含まれます。クラッシュ調査、挙動分析、反チートやマルウェア研究のために、再現可能で自動化可能な Windows デバッグを必要とするリバースエンジニア、セキュリティ研究者、ゲームセキュリティアナリストを対象としています。
