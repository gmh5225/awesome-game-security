windbg-tool es una herramienta de línea de comandos orientada a Windows y un servidor Model Context Protocol (MCP) que automatiza flujos de trabajo de depuración basados en WinDbg, con enfoque principal en la reproducción de trazas de Microsoft Time Travel Debugging (TTD). Escrito principalmente en Rust con un puente nativo en C++ hacia la API TTD Replay, permite a los analistas abrir y navegar trazas .run, inspeccionar registros y memoria, desensamblar código, resolver símbolos y clasificar volcados de crash de usuario o kernel sin interacción manual con el depurador. También puede grabar nuevas trazas TTD, ejecutar sondas en vivo puntuales como puntos de interrupción de inicio y administrados, y exponer comandos estables orientados a JSON más un servidor MCP para que agentes de IA y scripts impulsen el análisis de forma programática. La herramienta incluye un demonio local de larga duración para sesiones de reproducción, ayudantes de servidor remoto DbgEng y utilidades para instalar, actualizar y lanzar WinDbg. Está dirigida a ingenieros inversos, investigadores de seguridad y analistas de seguridad en juegos que necesitan depuración Windows repetible y automatizable para investigación de fallos, análisis de comportamiento e investigación antitrampas o de malware.
