PowerAC 是一款 Minecraft 服务器插件，作为本地反作弊系统，专注于检测自瞄模块及类似辅助瞄准的作弊行为。它使用 Java 编写，适用于 Paper 与 Spigot（调度兼容 Folia），并在插件内部完整运行卷积神经网络，在固定时间窗口内分析玩家视角旋转遥测数据，无需依赖外部服务或许可证服务器。内置的旋转模型可通过游戏内训练命令在服务器上微调：收集带标签样本并异步重训；数据包监听器跟踪移动与旋转，管理员可监控检测、记录违规并通过 Discord Webhook 接收告警。小型公开 API 与事件可暴露玩家快照与检测告警，便于与其他插件集成。面向希望在本地轻量自建、针对战斗相关瞄准作弊进行检测，而非依赖云端商业反作弊的 Minecraft 服主。
