PowerAC 是一款 Minecraft 伺服器外掛，作為本地反作弊系統，專注於偵測自瞄模組及類似輔助瞄準的作弊行為。它以 Java 撰寫，適用於 Paper 與 Spigot（排程相容 Folia），並在外掛內部完整執行卷積神經網路，在固定時間視窗內分析玩家視角旋轉遙測資料，無需依賴外部服務或授權伺服器。內建的旋轉模型可透過遊戲內訓練指令在伺服器上微調：收集標記樣本並非同步重訓；封包監聽器追蹤移動與旋轉，管理員可監控偵測、記錄違規並透過 Discord Webhook 接收告警。小型公開 API 與事件可暴露玩家快照與偵測告警，便於與其他外掛整合。面向希望在本地輕量自建、針對戰鬥相關瞄準作弊進行偵測，而非依賴雲端商業反作弊的 Minecraft 服主。
