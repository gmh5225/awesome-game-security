PowerAC è un plugin per server Minecraft che funge da anti-cheat locale, incentrato sul rilevamento di moduli aimbot e cheat in stile aim-assist. È scritto in Java per Paper e Spigot (con scheduling compatibile Folia) ed esegue interamente una rete neurale convoluzionale all’interno del plugin, analizzando la telemetria delle rotazioni del giocatore in finestre fisse senza affidarsi a servizi esterni o server di licenze. Il modello di rotazione incluso può essere affinato sul server tramite comandi di training in-game che raccolgono campioni etichettati e riaddestrano in modo asincrono; i listener sui pacchetti tracciano movimento e rotazioni e lo staff può monitorare le rilevazioni, registrare le violazioni e ricevere avvisi via webhook Discord. Una piccola API pubblica ed eventi espongono snapshot dei giocatori e alert di rilevamento per l’integrazione con altri plugin. È rivolto agli operatori di server Minecraft che vogliono un rilevamento cheat leggero e self-hosted per imbroglio di mira in combattimento, anziché un anti-cheat commerciale basato sul cloud.
