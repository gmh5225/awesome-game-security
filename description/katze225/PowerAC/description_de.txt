PowerAC ist ein Minecraft-Server-Plugin als lokales Anti-Cheat, das sich auf die Erkennung von Aimbot-Modulen und Aim-Assist-artigen Cheats konzentriert. Es ist in Java für Paper und Spigot (mit Folia-kompatibler Planung) geschrieben und führt ein faltendes neuronales Netz vollständig im Plugin aus, analysiert Rotations-Telemetrie der Spieler in festen Fenstern und benötigt weder externen Dienst noch Lizenzserver. Das mitgelieferte Rotationsmodell kann auf dem Server per Ingame-Trainingsbefehlen feinjustiert werden, die beschriftete Samples sammeln und asynchron nachtrainieren; Paket-Listener verfolgen Bewegung und Rotationen, und das Team kann Erkennungen überwachen, Verstöße protokollieren sowie Discord-Webhook-Benachrichtigungen erhalten. Eine kleine öffentliche API und Events stellen Spieler-Snapshots und Erkennungsalarme für die Integration mit anderen Plugins bereit. Es richtet sich an Minecraft-Serverbetreiber, die leichte, selbst gehostete Cheat-Erkennung für zielbezogenes Cheating im Kampf wollen statt eines cloudbasierten kommerziellen Anti-Cheats.
