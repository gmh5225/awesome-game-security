PowerAC is a Minecraft server plugin that acts as a local anti-cheat focused on detecting aimbot modules and aim-assist style cheats. It is written in Java for Paper and Spigot (with Folia-compatible scheduling) and runs a convolutional neural network entirely inside the plugin, analyzing player rotation telemetry in fixed windows without relying on an external service or license server. The bundled rotation model can be fine-tuned on the server using in-game training commands that collect labeled samples and retrain asynchronously, while packet listeners track movement and rotations and staff can monitor detections, log violations, and receive Discord webhook alerts. A small public API and events expose player snapshots and detection alerts for integration with other plugins. It is aimed at Minecraft server operators who want lightweight, self-hosted cheat detection for combat-related aim cheating rather than a cloud-backed commercial anti-cheat.
