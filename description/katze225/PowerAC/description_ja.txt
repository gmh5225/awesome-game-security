PowerAC は Minecraft サーバー向けプラグインで、ローカル反チートとして aimbot 系モジュールやエイムアシスト型の不正を検知することに特化しています。Java で書かれ、Paper および Spigot（Folia 互換のスケジューリング）向けで、外部サービスやライセンスサーバーに頼らず、プラグイン内で畳み込みニューラルネットワークを完結実行し、固定ウィンドウでプレイヤーの視点回転テレメトリを解析します。同梱の回転モデルは、ゲーム内トレーニングコマンドでラベル付きサンプルを収集し非同期に再学習することでサーバー上でファインチューン可能です。パケットリスナーが移動と回転を追跡し、スタッフは検知の監視、違反のログ、Discord Webhook によるアラートを受け取れます。小さな公開 API とイベントでプレイヤースナップショットと検知アラートを公開し、他プラグインとの連携に使えます。クラウド型の商用アンチチートではなく、戦闘まわりのエイム不正を自前ホストで軽量に検知したい Minecraft サーバー運営者向けです。
