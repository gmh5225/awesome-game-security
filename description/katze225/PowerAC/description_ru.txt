PowerAC — плагин для сервера Minecraft, работающий как локальный античит и ориентированный на обнаружение модулей aimbot и читов типа aim-assist. Написан на Java для Paper и Spigot (с планированием, совместимым с Folia) и полностью запускает свёрточную нейросеть внутри плагина, анализируя телеметрию поворотов игрока в фиксированных окнах без внешних сервисов и сервера лицензий. Встроенную модель поворотов можно дообучать на сервере игровыми командами обучения, которые собирают размеченные образцы и асинхронно переобучают модель; слушатели пакетов отслеживают движение и повороты, а персонал может мониторить срабатывания, логировать нарушения и получать оповещения через Discord webhook. Небольшой публичный API и события отдают снимки игроков и алерты детекции для интеграции с другими плагинами. Рассчитан на администраторов серверов Minecraft, которым нужно лёгкое самохостинговое обнаружение читов на прицеливание в бою, а не облачный коммерческий античит.
