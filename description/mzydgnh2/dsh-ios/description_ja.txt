dsh-ios は、公式 DeepSeek エージェントハーネスをワンクリックでローカル展開できるようにパッケージ化した iOS アプリで、ジェイルブレイク済みの iPhone および iPad 向けです。SwiftUI シェルがデプロイ、ワークスペース、ログ、ヘルスチェック、バックグラウンド維持を担当し、デバイス上でクロスコンパイルされた Node.js 26 ランタイムを起動して変更のない dsh Web スタックを動かします。リポジトリには大規模な Node の iOS 移植が含まれ、JIT 無効実行、WASM と libffi 互換パッチ、fork がブロックされる場合のプロセス内シェルなどの POSIX 回避策、および同一ネットワーク上の他端末から UI に届くためのオプションの LAN TCP リレーがあります。TrollStore、サイドロード、rootless/rootful ジェイルブレイク向けの未署名または ad-hoc 署名 IPA として提供されます。モバイル上で DeepSeek コーディングエージェントをセルフホストしたい開発者・研究者向けで、iOS サンドボックスとジェイルブレイク制約の中で複雑なサーバー型ツールを動かす実践的パターンが必要な方を対象としています。
