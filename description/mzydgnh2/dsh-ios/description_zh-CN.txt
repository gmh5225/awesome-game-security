dsh-ios 是一款 iOS 应用，将官方 DeepSeek 智能体运行环境打包为一键本地部署，适用于已越狱的 iPhone 与 iPad。SwiftUI 外壳负责部署、工作区、日志、健康检查与后台保活，并在设备上启动交叉编译的 Node.js 26 运行时，以运行未经修改的 dsh Web 技术栈。本仓库包含大规模 Node iOS 移植，禁用 JIT 执行，并带有 WASM 与 libffi 兼容补丁、POSIX 变通方案（例如在 fork 被阻断时使用进程内 shell），以及可选的局域网 TCP 中继，使同一网络上的其他设备可访问 UI。产物为未签名或 ad-hoc 签名的 IPA，面向 TrollStore、侧载或 rootless/rootful 越狱安装。项目面向希望在移动硬件上自托管 DeepSeek 编程智能体、并需要掌握在 iOS 沙箱与越狱约束下运行复杂服务端式工具的实践模式的开发者与研究人员。
