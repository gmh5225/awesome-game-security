dsh-ios is an iOS application that packages the official DeepSeek agent harness for one-click local deployment on jailbroken iPhones and iPads. A SwiftUI shell handles deployment, workspaces, logging, health checks, and background keep-alive while spawning a cross-compiled Node.js 26 runtime on device to run the unmodified dsh web stack. The repository includes a substantial iOS port of Node with JIT-disabled execution, WASM and libffi compatibility patches, POSIX workarounds such as an in-process shell where fork is blocked, and optional LAN TCP relay so other devices on the same network can reach the UI. It ships as unsigned or ad-hoc signed IPAs intended for TrollStore, sideloading, or rootless and rootful jailbreak installs. The project targets developers and researchers who want a self-hosted DeepSeek coding agent on mobile hardware and need practical patterns for running complex server-style tooling inside iOS sandbox and jailbreak constraints.
