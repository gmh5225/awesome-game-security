dsh-ios ist eine iOS-Anwendung, die das offizielle DeepSeek-Agent-Harness für die lokale Ein-Klick-Bereitstellung auf jailbroken iPhones und iPads bündelt. Eine SwiftUI-Hülle übernimmt Bereitstellung, Workspaces, Logging, Health-Checks und Hintergrund-Keep-Alive und startet auf dem Gerät eine cross-kompilierte Node.js-26-Laufzeit, um den unveränderten dsh-Web-Stack auszuführen. Das Repository enthält einen umfangreichen iOS-Port von Node mit deaktiviertem JIT, WASM- und libffi-Kompatibilitätspatches, POSIX-Workarounds wie einer In-Process-Shell, wenn fork blockiert ist, sowie ein optionales LAN-TCP-Relay, damit andere Geräte im gleichen Netz die UI erreichen können. Ausgeliefert wird es als unsignierte oder ad-hoc-signierte IPAs für TrollStore, Sideloading oder rootless- und rootful-Jailbreak-Installationen. Das Projekt richtet sich an Entwickler und Forscher, die einen selbst gehosteten DeepSeek-Coding-Agenten auf mobiler Hardware wollen und praktische Muster zum Betrieb komplexer serverähnlicher Tools innerhalb der iOS-Sandbox und Jailbreak-Einschränkungen benötigen.
