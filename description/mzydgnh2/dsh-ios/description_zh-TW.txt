dsh-ios 是一款 iOS 應用程式，將官方 DeepSeek 智慧體執行環境打包為一鍵本機部署，適用於已越獄的 iPhone 與 iPad。SwiftUI 外殼負責部署、工作區、記錄、健康檢查與背景保活，並在裝置上啟動交叉編譯的 Node.js 26 執行階段，以執行未經修改的 dsh Web 技術堆疊。本儲存庫包含大規模 Node iOS 移植，停用 JIT 執行，並附帶 WASM 與 libffi 相容修補、POSIX 變通方案（例如在 fork 被阻斷時使用程序內 shell），以及可選的區域網路 TCP 中繼，讓同一網路上的其他裝置可存取 UI。成品為未簽署或 ad-hoc 簽署的 IPA，供 TrollStore、側載或 rootless/rootful 越獄安裝。專案鎖定希望在行動硬體上自行託管 DeepSeek 程式設計智慧體、並需要掌握在 iOS 沙箱與越獄限制下執行複雜伺服器型工具的實務模式的開發者與研究人員。
