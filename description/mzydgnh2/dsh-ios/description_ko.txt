dsh-ios는 공식 DeepSeek 에이전트 하네스를 원클릭 로컬 배포용으로 패키징한 iOS 애플리케이션으로, 탈옥된 iPhone 및 iPad에서 사용합니다. SwiftUI 셸이 배포, 워크스페이스, 로깅, 헬스 체크, 백그라운드 유지를 담당하며, 기기에서 크로스 컴파일된 Node.js 26 런타임을 띄워 수정되지 않은 dsh 웹 스택을 실행합니다. 저장소에는 JIT 비활성 실행, WASM 및 libffi 호환 패치, fork가 차단될 때 프로세스 내 셸 같은 POSIX 우회, 동일 네트워크의 다른 기기가 UI에 접근할 수 있는 선택적 LAN TCP 릴레이 등 대규모 Node iOS 포팅이 포함됩니다. TrollStore, 사이드로드, rootless·rootful 탈옥 설치용으로 서명되지 않았거나 ad-hoc 서명된 IPA로 배포됩니다. 모바일 하드웨어에서 DeepSeek 코딩 에이전트를 자체 호스팅하고 iOS 샌드박스와 탈옥 제약 안에서 복잡한 서버형 도구를 돌리는 실용적 패턴이 필요한 개발자와 연구자를 대상으로 합니다.
