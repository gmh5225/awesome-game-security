Epsilon は、NeoForge と Fabric 向けのモダンなマルチローダー Minecraft ユーティリティクライアントで、モジュラーアーキテクチャを通じて設定可能なゲームプレイモジュールを提供します。主に Java で記述され、Gradle Kotlin ビルドスクリプトを使用し、mixin とカスタムイベントバスでクライアントにフックして、tick、パケット、レンダリング、プレイヤー操作をインターセプトします。コードベースには、戦闘、移動、プレイヤー自動化、レンダリングモジュール、拡張可能なアドオンシステム、Lua スクリプトサポート、およびカスタム HUD と UI レンダリング用の Lumin と PrismRHI ベースのグラフィックススタックが含まれます。ゲームセキュリティ研究者やアンチチート開発者が、高度な Minecraft クライアントがパケット操作、回転システム、クライアント側バイパス手法をどのように実装しているかを研究するために向けられています。
