Epsilon — это современный мультизагрузочный утилитарный клиент Minecraft для NeoForge и Fabric, предоставляющий настраиваемые игровые модули через модульную архитектуру. Написан преимущественно на Java со скриптами сборки Gradle Kotlin, подключается к клиенту через mixins и пользовательскую шину событий для перехвата тиков, пакетов, рендеринга и действий игрока. Кодовая база включает модули боя, движения, автоматизации игрока и рендеринга, расширяемую систему аддонов, поддержку скриптинга Lua и графический стек на базе Lumin и PrismRHI для пользовательского рендеринга HUD и UI. Предназначен для исследователей безопасности игр и разработчиков античитов, изучающих, как продвинутые клиенты Minecraft реализуют манипуляцию пакетами, системы ротации и техники обхода на стороне клиента.
