Epsilon 是一款面向 NeoForge 與 Fabric 的現代多載入器 Minecraft 實用客戶端，透過模組化架構提供可設定的遊戲玩法模組。程式碼主要使用 Java 編寫，並採用 Gradle Kotlin 建置腳本，透過 mixins 和自訂事件匯流排掛接客戶端，以攔截 tick、封包、渲染和玩家操作。程式碼庫包含戰鬥、移動、玩家自動化和渲染模組，可擴充的附加元件系統、Lua 腳本支援，以及基於 Lumin 和 PrismRHI 的圖形堆疊，用於自訂 HUD 和 UI 渲染。它面向遊戲安全研究人員和反作弊開發者，用於研究進階 Minecraft 客戶端如何實作封包操控、旋轉系統和客戶端繞過技術。
