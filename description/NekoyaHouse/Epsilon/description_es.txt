Epsilon es un cliente utilitario de Minecraft multi-loader moderno para NeoForge y Fabric que expone módulos de jugabilidad configurables a través de una arquitectura modular. Escrito principalmente en Java con scripts de compilación Gradle Kotlin, engancha el cliente mediante mixins y un bus de eventos personalizado para interceptar ticks, paquetes, renderizado y acciones del jugador. La base de código incluye módulos de combate, movimiento, automatización del jugador y renderizado, un sistema de complementos extensible, soporte de scripting Lua, y una pila gráfica basada en Lumin y PrismRHI para renderizado personalizado de HUD y UI. Está dirigido a investigadores de seguridad de juegos y desarrolladores de anti-cheat que estudian cómo los clientes avanzados de Minecraft implementan manipulación de paquetes, sistemas de rotación y técnicas de bypass del lado del cliente.
