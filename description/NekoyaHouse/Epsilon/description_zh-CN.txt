Epsilon 是一款面向 NeoForge 和 Fabric 的现代多加载器 Minecraft 实用客户端，通过模块化架构提供可配置的游戏玩法模块。代码主要使用 Java 编写，并采用 Gradle Kotlin 构建脚本，通过 mixins 和自定义事件总线挂接客户端，以拦截 tick、数据包、渲染和玩家操作。代码库包含战斗、移动、玩家自动化和渲染模块，可扩展的插件系统、Lua 脚本支持，以及基于 Lumin 和 PrismRHI 的图形栈，用于自定义 HUD 和 UI 渲染。它面向游戏安全研究人员和反作弊开发者，用于研究高级 Minecraft 客户端如何实现数据包操控、旋转系统和客户端绕过技术。
