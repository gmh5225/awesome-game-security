一款小型 Windows 實用工具，利用 Direct3D 11 和 Desktop Window Manager (DWM) 重新導向表面擷取目前焦點視窗，並將結果儲存為 PNG 檔案。它透過未公開的 DWM 匯出介面取得 GPU 支援的視窗表面，將共用紋理複製到 staging 資源，將像素讀回 CPU，並使用 Windows Imaging Component (WIC) 編碼輸出，從而避免傳統的 BitBlt 螢幕擷取。此工具以 C++17 編寫，使用 D3D11 裝置建立、COM 初始化以及全域快速鍵 (Alt+Insert)，可隨時對前景視窗進行快照。此工具面向研究 Windows 圖形內部機制、螢幕擷取技術以及遊戲安全議題（例如受保護或 GPU 加速的視窗如何在標準 GDI 路徑之外仍被擷取）的研究人員。
