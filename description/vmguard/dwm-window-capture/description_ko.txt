Direct3D 11과 Desktop Window Manager (DWM) 리디렉션 표면을 사용하여 현재 포커스된 창을 캡처하고 결과를 PNG 파일로 저장하는 소형 Windows 유틸리티입니다. 전통적인 BitBlt 화면 캡처를 피하기 위해 문서화되지 않은 DWM 내보내기를 통해 GPU 기반 창 표면을 얻고, 공유 텍스처를 staging 리소스에 복사한 다음 CPU로 픽셀을 읽어 와 Windows Imaging Component (WIC)로 출력을 인코딩합니다. C++17로 작성되었으며, D3D11 장치 생성, COM 초기화, 전역 단축키(Alt+Insert)를 사용하여 필요할 때 전경 창의 스냅샷을 저장합니다. Windows 그래픽 내부 동작, 화면 캡처 기법, 보호되거나 GPU 가속된 창을 표준 GDI 경로 밖에서도 어떻게 캡처할 수 있는지와 같은 게임 보안 주제를 연구하는 연구자를 대상으로 합니다.
