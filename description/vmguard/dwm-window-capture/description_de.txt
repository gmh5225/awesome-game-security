Ein kleines Windows-Dienstprogramm, das das aktuell fokussierte Fenster mithilfe von Direct3D 11 und Desktop Window Manager (DWM)-Umleitungsoberflächen erfasst und das Ergebnis als PNG-Datei speichert. Es vermeidet die traditionelle BitBlt-Bildschirmaufnahme, indem es über undokumentierte DWM-Exporte GPU-gestützte Fensterflächen erhält, die gemeinsame Textur in eine Staging-Ressource kopiert, Pixel zurück zum CPU liest und die Ausgabe mit der Windows Imaging Component (WIC) codiert. In C++17 geschrieben, nutzt es D3D11-Geräteerstellung, COM-Initialisierung und einen globalen Hotkey (Alt+Insert), um bei Bedarf eine Momentaufnahme des Vordergrundfensters zu erstellen. Das Tool richtet sich an Forscher, die Windows-Grafik-Internals, Bildschirmaufnahmetechniken und Spielesicherheitsthemen untersuchen, etwa wie geschützte oder GPU-beschleunigte Fenster außerhalb der Standard-GDI-Pfade dennoch erfasst werden können.
