Небольшая утилита для Windows, которая захватывает текущее активное окно с помощью Direct3D 11 и поверхностей перенаправления Desktop Window Manager (DWM), затем сохраняет результат в файл PNG. Она обходит традиционный захват экрана через BitBlt, получая поверхности окон с поддержкой GPU через недокументированные экспорты DWM, копируя общую текстуру в staging-ресурс, считывая пиксели обратно на CPU и кодируя вывод с помощью Windows Imaging Component (WIC). Написана на C++17, использует создание устройства D3D11, инициализацию COM и глобальную горячую клавишу (Alt+Insert) для мгновенного снимка окна на переднем плане по запросу. Инструмент предназначен для исследователей, изучающих внутреннее устройство графической подсистемы Windows, методы захвата экрана и темы безопасности игр, в том числе то, как защищённые или GPU-ускоренные окна всё ещё могут быть захвачены вне стандартных путей GDI.
