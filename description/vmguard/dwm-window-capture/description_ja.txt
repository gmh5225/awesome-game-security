Direct3D 11 と Desktop Window Manager (DWM) のリダイレクトサーフェスを用いて現在フォーカスされているウィンドウをキャプチャし、結果を PNG ファイルとして保存する小型の Windows ユーティリティです。従来の BitBlt による画面キャプチャを避けるため、未文書化の DWM エクスポートから GPU バックのウィンドウサーフェスを取得し、共有テクスチャを staging リソースにコピーして CPU にピクセルを読み戻し、Windows Imaging Component (WIC) で出力をエンコードします。C++17 で記述されており、D3D11 デバイスの作成、COM の初期化、およびグローバルホットキー (Alt+Insert) により、必要に応じてフォアグラウンドウィンドウのスナップショットを取得できます。Windows グラフィックス内部、画面キャプチャ手法、ゲームセキュリティ（保護されたウィンドウや GPU アクセラレーションのウィンドウが標準 GDI 経路外でどのようにキャプチャできるかなど）を研究する目的向けです。
