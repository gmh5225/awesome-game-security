A small Windows utility that captures the currently focused window using Direct3D 11 and Desktop Window Manager (DWM) redirection surfaces, then saves the result as a PNG file. It avoids traditional BitBlt screen capture by obtaining GPU-backed window surfaces through undocumented DWM exports, copying the shared texture to a staging resource, reading pixels back to the CPU, and encoding output with the Windows Imaging Component (WIC). Written in C++17, it uses D3D11 device creation, COM initialization, and a global hotkey (Alt+Insert) to snapshot the foreground window on demand. The tool is aimed at researchers studying Windows graphics internals, screen capture techniques, and game security topics such as how protected or GPU-accelerated windows can still be captured outside standard GDI paths.
