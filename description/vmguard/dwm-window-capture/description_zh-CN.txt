一款小型 Windows 实用工具，利用 Direct3D 11 和 Desktop Window Manager (DWM) 重定向表面捕获当前焦点窗口，并将结果保存为 PNG 文件。它通过未公开的 DWM 导出接口获取 GPU 支持的窗口表面，将共享纹理复制到 staging 资源，将像素读回 CPU，并使用 Windows Imaging Component (WIC) 编码输出，从而避免传统的 BitBlt 屏幕捕获。该工具采用 C++17 编写，使用 D3D11 设备创建、COM 初始化以及全局热键 (Alt+Insert)，可随时对前台窗口进行快照。该工具面向研究 Windows 图形内部机制、屏幕捕获技术以及游戏安全议题（例如受保护或 GPU 加速的窗口如何在标准 GDI 路径之外仍被捕获）的研究人员。
