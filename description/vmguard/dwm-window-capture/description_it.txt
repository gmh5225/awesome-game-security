Una piccola utilità Windows che cattura la finestra attualmente focalizzata usando Direct3D 11 e superfici di reindirizzamento del Desktop Window Manager (DWM), quindi salva il risultato come file PNG. Evita la cattura dello schermo tradizionale con BitBlt ottenendo superfici di finestra supportate dalla GPU tramite export DWM non documentati, copiando la texture condivisa in una risorsa di staging, rileggendo i pixel sulla CPU e codificando l'output con Windows Imaging Component (WIC). Scritto in C++17, utilizza la creazione del dispositivo D3D11, l'inizializzazione COM e un tasto di scelta rapida globale (Alt+Insert) per acquisire su richiesta un'istantanea della finestra in primo piano. Lo strumento è destinato a ricercatori che studiano gli internals grafici di Windows, le tecniche di cattura dello schermo e argomenti di sicurezza dei giochi, come le finestre protette o accelerate dalla GPU possano essere catturate al di fuori dei percorsi GDI standard.
