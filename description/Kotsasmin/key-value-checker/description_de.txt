KeyValueChecker ist ein leichtgewichtiges Anti-Cheat-Plugin für Minecraft-Server, das clientseitige Cheat-Mods erkennt, die für den Server ansonsten unsichtbar sind. Es nutzt Minecraft-Übersetzungskomponenten, indem es über die PacketEvents-Bibliothek gefälschte Schilder mit bekannten Mod-Sprachschlüsseln einschleust und den zurückgegebenen UpdateSign-Pakettext vergleicht, um nachzuweisen, ob ein Client diese Schlüssel aufgelöst hat. Das Plugin bietet konfigurierbare Blacklist- und Whitelist-Gruppen für beliebte Cheat-Clients und Utility-Mods wie Meteor Client, Freecam und AutoTotem und kann markierte Spieler kicken sowie optional Discord-Webhook-Benachrichtigungen senden. In Java für Paper/Spigot 1.21+ geschrieben, richtet es sich an Serveradministratoren, die eine Technik auf Paketebene suchen, um unerlaubte Client-Modifikationen beim Spielerbeitritt zu erkennen.
