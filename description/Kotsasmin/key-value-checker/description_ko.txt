KeyValueChecker는 서버에서 일반적으로 감지할 수 없는 클라이언트 측 치트 mod를 탐지하는 경량 Minecraft 서버 안티치트 플러그인입니다. Minecraft 번역 구성 요소를 이용해 PacketEvents 라이브러리를 통해 알려진 mod 언어 키가 포함된 가짜 표지판을 주입하고, 반환된 UpdateSign 패킷 텍스트를 비교하여 클라이언트가 해당 키를 해석했는지 여부를 확인합니다. Meteor Client, Freecam, AutoTotem 등 인기 치트 클라이언트 및 유틸리티 mod를 대상으로 하는 구성 가능한 블랙리스트 및 화이트리스트 그룹을 제공하며, 플래그가 지정된 플레이어를 추방하고 선택적으로 Discord webhook 알림을 보낼 수 있습니다. Java로 작성되었으며 Paper/Spigot 1.21+용으로, 플레이어 접속 시 패킷 수준 기법을 통해 허용되지 않은 클라이언트 수정을 식별하려는 서버 관리자를 대상으로 합니다.
