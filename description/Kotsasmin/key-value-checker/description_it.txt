KeyValueChecker è un plugin anti-cheat leggero per server Minecraft che rileva mod di cheat lato client altrimenti invisibili al server. Sfrutta i componenti di traduzione di Minecraft iniettando tramite la libreria PacketEvents cartelli falsi con chiavi di lingua di mod note, quindi confronta il testo dei pacchetti UpdateSign restituiti per dimostrare se un client ha risolto quelle chiavi. Il plugin include gruppi configurabili di blacklist e whitelist rivolti a client di cheat e mod di utilità popolari come Meteor Client, Freecam e AutoTotem, e può espellere i giocatori segnalati inviando opzionalmente avvisi tramite webhook Discord. Scritto in Java per Paper/Spigot 1.21+, è rivolto agli amministratori di server che cercano una tecnica a livello di pacchetti per identificare modifiche client non consentite durante il join dei giocatori.
