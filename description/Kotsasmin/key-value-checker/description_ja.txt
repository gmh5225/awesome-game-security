KeyValueChecker は、サーバー側では通常検出できないクライアント側のチート mod を検出する軽量な Minecraft サーバー用アンチチートプラグインです。Minecraft の翻訳コンポーネントを利用し、PacketEvents ライブラリ経由で既知の mod 言語キーを持つ偽の看板を注入し、返ってきた UpdateSign パケットのテキストを比較して、クライアントがそれらのキーを解決したかどうかを証明します。Meteor Client、Freecam、AutoTotem などの人気チートクライアントやユーティリティ mod を標的とする設定可能なブラックリストとホワイトリストグループを同梱し、フラグが立ったプレイヤーをキックできるほか、必要に応じて Discord webhook 通知を送信できます。Java で記述され、Paper/Spigot 1.21+ 向けで、プレイヤー参加時にパケットレベルの手法で許可されていないクライアント改造を特定したいサーバー管理者を対象としています。
