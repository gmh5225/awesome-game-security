KeyValueChecker is a lightweight Minecraft server anti-cheat plugin that detects client-side cheat mods that are otherwise invisible to the server. It exploits Minecraft translation components by injecting fake signs with known mod language keys via the PacketEvents library, then comparing returned UpdateSign packet text to prove whether a client resolved those keys. The plugin ships with configurable blacklist and whitelist groups targeting popular cheat clients and utility mods such as Meteor Client, Freecam, and AutoTotem, and can kick flagged players while optionally sending Discord webhook alerts. Written in Java for Paper/Spigot 1.21+, it is aimed at server administrators seeking a packet-level technique to identify disallowed client modifications during player join.
