KeyValueChecker 是一款輕量級的 Minecraft 伺服器反作弊外掛，可偵測伺服器端通常無法發現的用戶端作弊 mod。它利用 Minecraft 的翻譯元件，透過 PacketEvents 函式庫注入帶有已知 mod 語言鍵的假告示牌，並比對返回的 UpdateSign 封包文字，以驗證用戶端是否解析了這些鍵。此外掛內建可設定的黑名單與白名單群組，針對 Meteor Client、Freecam 和 AutoTotem 等熱門作弊用戶端與實用 mod；偵測到可疑玩家時可踢出，並可選擇發送 Discord webhook 告警。以 Java 撰寫，適用於 Paper/Spigot 1.21+，面向希望在玩家加入時透過封包層級技術識別禁用用戶端修改的伺服器管理員。
