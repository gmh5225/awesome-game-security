KeyValueChecker es un plugin anti-trampas ligero para servidores de Minecraft que detecta mods de trampa del lado del cliente que de otro modo serían invisibles para el servidor. Aprovecha los componentes de traducción de Minecraft inyectando carteles falsos con claves de idioma de mods conocidas mediante la biblioteca PacketEvents, y luego compara el texto de los paquetes UpdateSign devueltos para demostrar si un cliente resolvió esas claves. El plugin incluye grupos configurables de lista negra y lista blanca dirigidos a clientes de trampa y mods utilitarios populares como Meteor Client, Freecam y AutoTotem, y puede expulsar a jugadores marcados mientras envía opcionalmente alertas mediante webhook de Discord. Escrito en Java para Paper/Spigot 1.21+, está dirigido a administradores de servidores que buscan una técnica a nivel de paquetes para identificar modificaciones de cliente no permitidas durante la conexión de jugadores.
