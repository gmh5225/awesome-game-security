KeyValueChecker 是一款轻量级的 Minecraft 服务器反作弊插件，可检测服务端通常无法发现的客户端作弊 mod。它利用 Minecraft 的翻译组件，通过 PacketEvents 库注入带有已知 mod 语言键的假告示牌，并将返回的 UpdateSign 数据包文本进行比对，以验证客户端是否解析了这些键。该插件内置可配置的黑名单和白名单组，针对 Meteor Client、Freecam 和 AutoTotem 等流行作弊客户端与实用 mod；检测到可疑玩家时可踢出，并可选发送 Discord webhook 告警。使用 Java 编写，适用于 Paper/Spigot 1.21+，面向希望在玩家加入时通过数据包级技术识别禁用客户端修改的服务器管理员。
