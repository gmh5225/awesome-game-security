KeyValueChecker — это лёгкий античит-плагин для сервера Minecraft, обнаруживающий клиентские чит-моды, которые иначе невидимы для сервера. Он использует компоненты перевода Minecraft, внедряя через библиотеку PacketEvents поддельные таблички с известными языковыми ключами модов, а затем сравнивает текст возвращённых пакетов UpdateSign, чтобы доказать, разрешил ли клиент эти ключи. Плагин поставляется с настраиваемыми группами чёрного и белого списков, нацеленными на популярные чит-клиенты и утилитарные моды, такие как Meteor Client, Freecam и AutoTotem, и может исключать помеченных игроков, опционально отправляя уведомления через webhook Discord. Написан на Java для Paper/Spigot 1.21+ и предназначен для администраторов серверов, которым нужна техника на уровне пакетов для выявления запрещённых клиентских модификаций при входе игроков.
