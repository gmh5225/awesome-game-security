Android Security Wizard は、Android モバイルセキュリティ評価向けの総合的な研究コーパスおよび実践的スキルリファレンスであり、統合ガイド 1 本と評価ワークフロー全体を扱う 20 の詳細な補助ドキュメントを組み合わせています。Frida、Objection、Ghidra、ADB/Shizuku などのツールを用いた APK、DEX、ネイティブライブラリの静的・動的解析、DexGuard や Bangcle などの商用パッカー・プロテクタ回避手法を網羅しています。コーパスには、エクスプロイト特定ワークフロー、ARM64 カーネルエクスプロイト開発、マルウェア検出と C2 帰属、Android 14 から 18 にわたるプラットフォームセキュリティの変更も記載されています。リバースエンジニア、モバイルセキュリティ研究者、および Android デバイス上のアプリ保護、インストルメンテーション防御、脅威行動を評価する実務者を対象としています。
