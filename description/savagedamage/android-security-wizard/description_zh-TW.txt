Android Security Wizard 是一份面向 Android 行動安全評估的綜合研究資料庫與實戰技能參考，將一份整合指南與二十篇深度配套文件相結合，涵蓋完整評估工作流程。內容包含使用 Frida、Objection、Ghidra 以及 ADB/Shizuku 等工具對 APK、DEX 及 native 函式庫進行靜態與動態分析，以及針對 DexGuard、梆梆加固等商業加殼與保護方案的繞過技術。資料庫亦記錄了漏洞識別工作流程、ARM64 核心漏洞利用開發、惡意軟體偵測與 C2 歸因，以及 Android 14 至 18 各版本的平台安全變更。面向逆向工程師、行動安全研究人員，以及評估應用程式防護、插樁防禦與 Android 裝置上威脅行為的從業人員。
