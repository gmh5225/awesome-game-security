Android Security Wizard 是一份面向 Android 移动安全评估的综合研究资料库与实战技能参考，将一份整合指南与二十篇深度配套文档相结合，覆盖完整评估工作流。内容涵盖使用 Frida、Objection、Ghidra 以及 ADB/Shizuku 等工具对 APK、DEX 及 native 库进行静态与动态分析，以及针对 DexGuard、梆梆加固等商业加壳与保护方案的绕过技术。资料库还记录了漏洞识别工作流、ARM64 内核漏洞利用开发、恶意软件检测与 C2 归因，以及 Android 14 至 18 各版本的平台安全变更。面向逆向工程师、移动安全研究人员，以及评估应用防护、插桩防御与 Android 设备上威胁行为的从业者。
