android_imgui_menu 是一個 Rust 共享函式庫，可在 ARM64 裝置上將 Dear ImGui 覆蓋層選單注入到正在執行的 Android 應用程式中。它透過掛鉤圖形 API，在遊戲和應用程式之上渲染互動式 UI，並透過攔截 libvulkan.so 與 libEGL.so 同時支援 Vulkan 與 OpenGL ES 後端。該專案採用 ARM64 內聯掛鉤、透過 xdl 進行動態符號解析，以及為 ImGui、Vulkan 與 Android 輸入處理量身定製的 Rust 綁定。它透過建構函式掛鉤自動載入，為在 Android 上建構程序內除錯面板、Mod 選單與逆向工程工具提供了模組化基礎。
