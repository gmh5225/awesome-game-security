android_imgui_menu es una biblioteca compartida en Rust que inyecta menús superpuestos de Dear ImGui en aplicaciones Android en ejecución en dispositivos ARM64. Intercepta las API gráficas para renderizar una interfaz interactiva sobre juegos y aplicaciones, compatible con los backends Vulkan y OpenGL ES mediante la interceptación de libvulkan.so y libEGL.so. El proyecto utiliza hooking inline en ARM64, resolución dinámica de símbolos mediante xdl y bindings personalizados en Rust para ImGui, Vulkan y el manejo de entrada en Android. Se carga automáticamente mediante un hook de constructor y proporciona una base modular para crear paneles de depuración in-process, menús de mods y herramientas de ingeniería inversa en Android.
