android_imgui_menu — это общая библиотека на Rust, которая внедряет оверлейные меню Dear ImGui в работающие Android-приложения на устройствах ARM64. Она перехватывает графические API для отрисовки интерактивного интерфейса поверх игр и приложений, поддерживая бэкенды Vulkan и OpenGL ES через перехват libvulkan.so и libEGL.so. Проект использует inline-хукинг ARM64, динамическое разрешение символов через xdl и пользовательские Rust-привязки для ImGui, Vulkan и обработки ввода на Android. Библиотека автоматически загружается через хук конструктора и предоставляет модульную основу для создания внутрипроцессных отладочных панелей, mod-меню и инструментов реверс-инжиниринга на Android.
