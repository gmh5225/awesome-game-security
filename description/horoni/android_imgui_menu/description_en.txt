android_imgui_menu is a Rust shared library that injects Dear ImGui overlay menus into running Android applications on ARM64 devices. It hooks graphics APIs to render interactive UI on top of games and apps, supporting both Vulkan and OpenGL ES backends through libvulkan.so and libEGL.so interception. The project uses ARM64 inline hooking, dynamic symbol resolution via xdl, and custom Rust bindings for ImGui, Vulkan, and Android input handling. It auto-loads through a constructor hook and provides a modular foundation for building in-process debug panels, mod menus, and reverse-engineering tools on Android.
