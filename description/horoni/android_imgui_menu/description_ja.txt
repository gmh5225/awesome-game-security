android_imgui_menu は、ARM64 デバイス上で実行中の Android アプリケーションに Dear ImGui のオーバーレイメニューを注入する Rust 共有ライブラリです。グラフィックス API をフックしてゲームやアプリの上にインタラクティブな UI を描画し、libvulkan.so と libEGL.so のインターセプトを通じて Vulkan と OpenGL ES の両バックエンドをサポートします。本プロジェクトは ARM64 インラインフック、xdl による動的シンボル解決、ImGui・Vulkan・Android 入力処理向けのカスタム Rust バインディングを使用します。コンストラクタフックで自動ロードされ、Android 上でインプロセスのデバッグパネル、Mod メニュー、リバースエンジニアリングツールを構築するためのモジュール式基盤を提供します。
