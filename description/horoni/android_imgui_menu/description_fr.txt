android_imgui_menu est une bibliothèque partagée Rust qui injecte des menus overlay Dear ImGui dans les applications Android en cours d'exécution sur des appareils ARM64. Elle intercepte les API graphiques pour afficher une interface utilisateur interactive par-dessus les jeux et les applications, en prenant en charge les backends Vulkan et OpenGL ES via l'interception de libvulkan.so et libEGL.so. Le projet utilise le hooking inline ARM64, la résolution dynamique des symboles via xdl, et des bindings Rust personnalisés pour ImGui, Vulkan et la gestion des entrées Android. Il se charge automatiquement via un hook de constructeur et fournit une base modulaire pour construire des panneaux de débogage in-process, des menus de mods et des outils de reverse engineering sur Android.
