android_imgui_menu 是一个 Rust 共享库，可在 ARM64 设备上将 Dear ImGui 覆盖层菜单注入到正在运行的 Android 应用中。它通过挂钩图形 API，在游戏和应用之上渲染交互式 UI，并通过对 libvulkan.so 和 libEGL.so 的拦截同时支持 Vulkan 与 OpenGL ES 后端。该项目采用 ARM64 内联挂钩、通过 xdl 进行动态符号解析，以及为 ImGui、Vulkan 和 Android 输入处理定制的 Rust 绑定。它通过构造函数挂钩自动加载，为在 Android 上构建进程内调试面板、Mod 菜单和逆向工程工具提供了模块化基础。
