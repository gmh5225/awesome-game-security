android_imgui_menu è una libreria condivisa Rust che inietta menu overlay Dear ImGui nelle applicazioni Android in esecuzione su dispositivi ARM64. Intercetta le API grafiche per renderizzare un'interfaccia utente interattiva sopra giochi e app, supportando i backend Vulkan e OpenGL ES tramite l'intercettazione di libvulkan.so e libEGL.so. Il progetto utilizza inline hooking ARM64, risoluzione dinamica dei simboli tramite xdl e binding Rust personalizzati per ImGui, Vulkan e la gestione degli input su Android. Si carica automaticamente tramite un hook del costruttore e fornisce una base modulare per costruire pannelli di debug in-process, menu mod e strumenti di reverse engineering su Android.
