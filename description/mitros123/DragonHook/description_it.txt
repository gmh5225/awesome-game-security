DragonHook è un plugin per Ghidra che collega l'analisi statica in Ghidra con l'instrumentazione dinamica a runtime tramite Frida. Espone funzioni, commenti e riferimenti incrociati del database Ghidra agli agent Frida tramite un'API HTTP localhost, fornendo anche una GUI per avviare e configurare sessioni Frida dall'interno di Ghidra. Le funzionalità principali includono la risoluzione dei target di chiamate indirette dinamiche a runtime e l'aggiornamento live di Ghidra con commenti e xref, backtracing personalizzato usando i nomi simbolo di Ghidra, tracciamento delle chiamate di funzione, risoluzione dei riferimenti alle stringhe e monitoraggio sperimentale dei watchpoint hardware. L'implementazione è principalmente in Java per l'estensione Ghidra, con agent Frida in JavaScript e uno script launcher Python. È destinato a reverse engineer e analisti di binari che devono combinare il disassemblaggio statico con l'introspezione live dei processi per analisi di malware, ricerca di vulnerabilità e lavoro sulla sicurezza dei giochi.
