DragonHook is a Ghidra plugin that bridges static analysis in Ghidra with dynamic runtime instrumentation through Frida. It exposes Ghidra database functions, comments, and cross-references to Frida agents via a localhost HTTP API, while providing a GUI to launch and configure Frida sessions from within Ghidra. Key capabilities include resolving dynamic indirect call targets at runtime and live-updating Ghidra with comments and xrefs, custom backtracing using Ghidra symbol names, function call tracing, string reference resolution, and experimental hardware watchpoint monitoring. The implementation is primarily Java for the Ghidra extension, with JavaScript Frida agents and a Python launcher script. It targets reverse engineers and binary analysts who need to combine static disassembly with live process introspection for malware analysis, vulnerability research, and game security work.
