DragonHook — это плагин для Ghidra, который связывает статический анализ в Ghidra с динамической инструментацией во время выполнения через Frida. Он предоставляет агентам Frida функции, комментарии и перекрёстные ссылки из базы данных Ghidra через HTTP API на localhost, а также предоставляет GUI для запуска и настройки сеансов Frida из Ghidra. Ключевые возможности включают разрешение динамических косвенных целей вызовов во время выполнения и обновление Ghidra в реальном времени комментариями и xref, пользовательскую трассировку назад с использованием имён символов Ghidra, отслеживание вызовов функций, разрешение ссылок на строки и экспериментальный мониторинг аппаратных точек наблюдения (hardware watchpoints). Реализация в основном на Java для расширения Ghidra, с агентами Frida на JavaScript и скриптом запуска на Python. Он предназначен для специалистов по обратной разработке и аналитиков бинарных файлов, которым необходимо совмещать статическое дизассемблирование с интроспекцией процессов в реальном времени для анализа вредоносного ПО, исследования уязвимостей и работы по безопасности игр.
