DragonHook は、Frida による動的ランタイム計装と Ghidra における静的解析を橋渡しする Ghidra プラグインです。localhost HTTP API を介して Ghidra データベースの関数、コメント、クロスリファレンスを Frida エージェントに公開し、Ghidra 内から Frida セッションを起動・設定する GUI も提供します。主な機能には、実行時の動的間接呼び出し先の解決、コメントと xref による Ghidra のライブ更新、Ghidra シンボル名を用いたカスタムバックトレース、関数呼び出しトレース、文字列参照の解決、実験的なハードウェアウォッチポイント監視が含まれます。実装は主に Ghidra 拡張機能が Java、Frida エージェントが JavaScript、Python ランチャースクリプトで構成されています。静的逆アセンブリとライブプロセス内省を組み合わせる必要がある逆エンジニアやバイナリ解析者を対象としており、マルウェア解析、脆弱性調査、ゲームセキュリティの作業に適しています。
