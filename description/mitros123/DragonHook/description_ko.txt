DragonHook은 Frida를 통해 Ghidra의 정적 분석과 동적 런타임 계측을 연결하는 Ghidra 플러그인입니다. localhost HTTP API를 통해 Ghidra 데이터베이스의 함수, 주석, 교차 참조를 Frida 에이전트에 노출하고, Ghidra 내에서 Frida 세션을 시작하고 구성할 수 있는 GUI를 제공합니다. 주요 기능으로는 런타임에 동적 간접 호출 대상을 해석하고 주석과 xref로 Ghidra를 실시간 업데이트하며, Ghidra 심볼 이름을 사용한 사용자 정의 백트레이싱, 함수 호출 추적, 문자열 참조 해석, 실험적인 하드웨어 watchpoint 모니터링이 포함됩니다. 구현은 주로 Ghidra 확장 기능이 Java, Frida 에이전트가 JavaScript, Python 런처 스크립트로 구성됩니다. 정적 디스어셈블리와 실시간 프로세스 인트로스펙션을 결합해야 하는 리버스 엔지니어와 바이너리 분석가를 대상으로 하며, 멀웨어 분석, 취약점 연구, 게임 보안 작업에 적합합니다.
