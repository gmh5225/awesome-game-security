DragonHook 是一款 Ghidra 外掛，透過 Frida 將 Ghidra 中的靜態分析與動態執行階段插樁連接起來。它透過 localhost HTTP API 向 Frida agent 暴露 Ghidra 資料庫中的函式、註解和交叉參考，並提供 GUI 以便在 Ghidra 內啟動和設定 Frida 工作階段。主要功能包括在執行階段解析動態間接呼叫目標，並以註解和 xref 即時更新 Ghidra，使用 Ghidra 符號名稱進行自訂回溯，函式呼叫追蹤，字串參考解析，以及實驗性的硬體 watchpoint 監控。實作上，Ghidra 擴充功能主要使用 Java，Frida agent 使用 JavaScript，並配有 Python 啟動腳本。它面向需要將靜態反組譯與即時程序內省相結合的逆向工程師和二進位分析師，適用於惡意軟體分析、漏洞研究和遊戲安全工作。
