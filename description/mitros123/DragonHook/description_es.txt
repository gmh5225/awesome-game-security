DragonHook es un complemento de Ghidra que conecta el análisis estático en Ghidra con la instrumentación dinámica en tiempo de ejecución mediante Frida. Expone funciones, comentarios y referencias cruzadas de la base de datos de Ghidra a los agentes Frida a través de una API HTTP localhost, mientras proporciona una GUI para iniciar y configurar sesiones Frida desde Ghidra. Las capacidades clave incluyen resolver objetivos de llamadas indirectas dinámicas en tiempo de ejecución y actualizar Ghidra en vivo con comentarios y xrefs, backtracing personalizado usando nombres de símbolos de Ghidra, rastreo de llamadas a funciones, resolución de referencias de cadenas y monitorización experimental de puntos de observación de hardware (hardware watchpoints). La implementación es principalmente Java para la extensión de Ghidra, con agentes Frida en JavaScript y un script de lanzamiento en Python. Está dirigido a ingenieros de ingeniería inversa y analistas de binarios que necesitan combinar el desensamblado estático con la introspección de procesos en vivo para análisis de malware, investigación de vulnerabilidades y trabajo de seguridad en juegos.
