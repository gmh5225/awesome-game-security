DragonHook 是一款 Ghidra 插件，通过 Frida 将 Ghidra 中的静态分析与动态运行时插桩连接起来。它通过 localhost HTTP API 向 Frida agent 暴露 Ghidra 数据库中的函数、注释和交叉引用，并提供 GUI 以便在 Ghidra 内启动和配置 Frida 会话。主要功能包括在运行时解析动态间接调用目标，并以注释和 xref 实时更新 Ghidra，使用 Ghidra 符号名进行自定义回溯，函数调用跟踪，字符串引用解析，以及实验性的硬件 watchpoint 监控。实现上，Ghidra 扩展主要使用 Java，Frida agent 使用 JavaScript，并配有 Python 启动脚本。它面向需要将静态反汇编与实时进程内省相结合的逆向工程师和二进制分析师，适用于恶意软件分析、漏洞研究和游戏安全工作。
