DragonHook ist ein Ghidra-Plugin, das statische Analyse in Ghidra mit dynamischer Laufzeit-Instrumentierung über Frida verbindet. Es stellt Ghidra-Datenbankfunktionen, Kommentare und Querverweise Frida-Agenten über eine localhost-HTTP-API bereit und bietet eine GUI zum Starten und Konfigurieren von Frida-Sitzungen innerhalb von Ghidra. Zu den Hauptfunktionen gehören das Auflösen dynamischer indirekter Aufrufziele zur Laufzeit und die Live-Aktualisierung von Ghidra mit Kommentaren und Xrefs, benutzerdefiniertes Backtracing mit Ghidra-Symbolnamen, Funktionsaufruf-Tracing, Auflösung von String-Referenzen und experimentelle Hardware-Watchpoint-Überwachung. Die Implementierung besteht hauptsächlich aus Java für die Ghidra-Erweiterung, mit JavaScript-Frida-Agenten und einem Python-Startskript. Es richtet sich an Reverse Engineers und Binäranalysten, die statisches Disassembling mit Live-Prozess-Introspektion für Malware-Analyse, Schwachstellenforschung und Game-Security-Arbeit kombinieren müssen.
