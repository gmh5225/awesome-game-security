getIPA is a command-line tool that connects to a jailbroken iPhone over SSH, lists installed App Store apps, and packages a chosen app as a ready-to-use IPA in one workflow. It is implemented as a Python 3 script using only the standard library plus the system OpenSSH client, and it can optionally invoke the bundled bagbak tool (Node.js) with Frida on the device to produce decrypted binaries instead of FairPlay-encrypted copies. The tool supports interactive selection or scripted flags, sorts recent user apps while filtering system bundles, and can emit an app report covering permissions, entitlements, ATS settings, URL schemes, frameworks, and encryption status for extracted or local IPAs. Remote data is handled defensively with path validation, safe tar extraction, and sanitized filenames because the phone is treated as untrusted input. It is aimed at security researchers and reverse engineers who own the device and are authorized to analyze iOS applications, including inspecting client-side protections relevant to mobile game security.
