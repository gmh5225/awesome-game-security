getIPA 是一款命令行工具，通过 SSH 连接已越狱的 iPhone，列出已安装的 App Store 应用，并在一条工作流中将所选应用打包为可直接使用的 IPA。它以 Python 3 脚本实现，仅依赖标准库与系统 OpenSSH 客户端；也可选调用设备上的 bagbak（Node.js）配合 Frida，生成解密后的二进制，而非 FairPlay 加密的副本。工具支持交互式选择或脚本化参数，对近期用户应用排序并过滤系统包，还可为已提取或本地 IPA 生成应用报告，涵盖权限、entitlements、ATS 设置、URL scheme、框架与加密状态。因将手机视为不可信输入，对远程数据采用路径校验、安全 tar 解压与文件名清理等防御性处理。面向拥有设备且获授权分析 iOS 应用的安全研究人员与逆向工程师，包括检视与移动游戏安全相关的客户端防护。
