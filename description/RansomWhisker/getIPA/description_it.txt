getIPA è uno strumento a riga di comando che si connette a un iPhone jailbroken via SSH, elenca le app App Store installate e impacchetta l’app scelta come IPA pronto all’uso in un unico flusso di lavoro. È implementato come script Python 3 usando solo la libreria standard e il client OpenSSH di sistema; può opzionalmente invocare lo strumento bagbak incluso (Node.js) con Frida sul dispositivo per produrre binari decriptati invece di copie cifrate FairPlay. Lo strumento supporta selezione interattiva o flag per script, ordina le app utente recenti filtrando i bundle di sistema e può emettere un report dell’app con permessi, entitlements, impostazioni ATS, URL scheme, framework e stato di cifratura per IPA estratti o locali. I dati remoti sono gestiti in modo difensivo con validazione dei percorsi, estrazione tar sicura e nomi file sanificati, perché il telefono è trattato come input non attendibile. È rivolto a ricercatori di sicurezza e reverse engineer che possiedono il dispositivo e sono autorizzati ad analizzare applicazioni iOS, incluso l’ispezione delle protezioni lato client rilevanti per la sicurezza dei giochi mobile.
