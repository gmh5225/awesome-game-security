getIPA — утилита командной строки, которая по SSH подключается к iPhone с jailbreak, перечисляет установленные приложения из App Store и в одном рабочем процессе упаковывает выбранное приложение в готовый к использованию IPA. Реализована как скрипт на Python 3 с использованием только стандартной библиотеки и системного клиента OpenSSH; опционально может вызывать встроенный инструмент bagbak (Node.js) с Frida на устройстве, чтобы получить расшифрованные бинарники вместо копий с шифрованием FairPlay. Поддерживаются интерактивный выбор и флаги для скриптов, сортировка недавних пользовательских приложений с отсеиванием системных bundle, а также отчёт о приложении с правами, entitlements, настройками ATS, URL-схемами, фреймворками и статусом шифрования для извлечённых или локальных IPA. Удалённые данные обрабатываются с осторожностью: проверка путей, безопасное извлечение tar и санитизация имён файлов, поскольку телефон считается недоверенным источником ввода. Предназначена для исследователей безопасности и reverse engineers, которые владеют устройством и уполномочены анализировать приложения iOS, в том числе изучать клиентские защиты, актуальные для безопасности мобильных игр.
