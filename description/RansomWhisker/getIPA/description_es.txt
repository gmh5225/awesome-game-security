getIPA es una herramienta de línea de comandos que se conecta a un iPhone con jailbreak por SSH, enumera las apps de App Store instaladas y empaqueta la app elegida como un IPA listo para usar en un solo flujo de trabajo. Está implementada como script en Python 3 usando solo la biblioteca estándar y el cliente OpenSSH del sistema, y puede invocar opcionalmente la herramienta bagbak incluida (Node.js) con Frida en el dispositivo para producir binarios descifrados en lugar de copias cifradas con FairPlay. La herramienta admite selección interactiva o flags para scripts, ordena apps de usuario recientes filtrando bundles del sistema, y puede emitir un informe de la app con permisos, entitlements, ajustes ATS, esquemas URL, frameworks y estado de cifrado para IPAs extraídos o locales. Los datos remotos se tratan de forma defensiva con validación de rutas, extracción tar segura y nombres de archivo saneados, porque el teléfono se considera entrada no confiable. Está dirigida a investigadores de seguridad e ingenieros inversos que poseen el dispositivo y están autorizados a analizar aplicaciones iOS, incluida la inspección de protecciones del lado cliente relevantes para la seguridad de juegos móviles.
