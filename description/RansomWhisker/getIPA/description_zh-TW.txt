getIPA 是一款命令列工具，透過 SSH 連線至已越獄的 iPhone，列出已安裝的 App Store 應用程式，並在單一工作流程中將所選應用打包成可直接使用的 IPA。它以 Python 3 腳本實作，僅使用標準函式庫與系統 OpenSSH 用戶端；亦可選擇在裝置上搭配 Frida 呼叫內建的 bagbak（Node.js），產生解密後的二進位檔，而非 FairPlay 加密的副本。工具支援互動式選取或腳本化旗標，對近期使用者應用排序並過濾系統套件，還能為已提取或本機 IPA 產生應用報告，涵蓋權限、entitlements、ATS 設定、URL scheme、框架與加密狀態。因將手機視為不可信輸入，對遠端資料採路徑驗證、安全 tar 解壓與檔名清理等防禦性處理。面向擁有裝置且獲授權分析 iOS 應用的資安研究人員與逆向工程師，包括檢視與行動遊戲安全相關的用戶端防護。
