AppInitHook は、AppInit_DLLs レジストリ機構を利用してプロセス起動時にカスタムモジュールを読み込む、Windows 向け DLL インジェクションおよび API フッキングフレームワークです。ディスパッチャ DLL が INI 設定を読み取り、どのプロセス固有モジュールを読み込むかを決定し、HookDll ヘルパーは MinHook をマクロでラップして、エクスポート API やプロセスエントリポイントのフックを支援します。プロジェクトは C/C++ で記述され、CMake と cmkr で MSVC 向けにビルドされ、プロセス制御や挙動調整用のサンプルモジュールが同梱されています。デバッグ、研究、ゲームセキュリティ関連の作業で、Windows 上の早期かつ設定可能なプロセスインジェクションとフッキングを必要とするリバースエンジニアや開発者を対象としています。
