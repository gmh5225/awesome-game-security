AppInitHook — это фреймворк для внедрения DLL и перехвата API в Windows, использующий механизм реестра AppInit_DLLs для загрузки пользовательских модулей при запуске процессов. Диспетчерская DLL читает INI-конфигурацию, чтобы определить, какой модуль для конкретного процесса загрузить, а вспомогательный HookDll оборачивает MinHook макросами для перехвата экспортируемых API или точек входа процессов. Проект написан на C/C++, собирается с помощью CMake и cmkr для MSVC и поставляется с примерами модулей для управления процессами и настройки поведения. Он предназначен для реверс-инженеров и разработчиков, которым нужна ранняя настраиваемая инъекция и перехват процессов в Windows для отладки, исследований или работ, связанных с безопасностью игр.
