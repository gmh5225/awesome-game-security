AppInitHook è un framework di iniezione DLL e API hooking per Windows che usa il meccanismo di registro AppInit_DLLs per caricare moduli personalizzati all'avvio dei processi. Una DLL dispatcher legge una configurazione INI per decidere quale modulo specifico del processo caricare, e un helper HookDll avvolge MinHook con macro per intercettare API esportate o punti di ingresso dei processi. Il progetto è scritto in C/C++, costruito con CMake e cmkr per MSVC, e include moduli di esempio per il controllo dei processi e regolazioni del comportamento. È rivolto a reverse engineer e sviluppatori che necessitano di iniezione e hooking di processi precoci e configurabili su Windows per debugging, ricerca o lavoro legato alla sicurezza dei giochi.
