AppInitHook는 AppInit_DLLs 레지스트리 메커니즘을 사용해 프로세스 시작 시 사용자 지정 모듈을 로드하는 Windows DLL 인젝션 및 API 후킹 프레임워크입니다. 디스패처 DLL이 INI 설정을 읽어 어떤 프로세스별 모듈을 로드할지 결정하며, HookDll 헬퍼는 MinHook을 매크로로 감싸 내보내기 API나 프로세스 진입점을 후킹합니다. 프로젝트는 C/C++로 작성되었고 CMake와 cmkr로 MSVC용으로 빌드되며, 프로세스 제어 및 동작 조정용 예제 모듈이 포함되어 있습니다. 디버깅, 연구 또는 게임 보안 관련 작업을 위해 Windows에서 조기에 설정 가능한 프로세스 인젝션과 후킹이 필요한 리버스 엔지니어와 개발자를 대상으로 합니다.
