AppInitHook es un framework de inyección de DLL y hooking de API en Windows que usa el mecanismo de registro AppInit_DLLs para cargar módulos personalizados al iniciar los procesos. Una DLL dispatcher lee una configuración INI para decidir qué módulo específico del proceso cargar, y un helper HookDll envuelve MinHook con macros para enganchar APIs exportadas o puntos de entrada de procesos. El proyecto está escrito en C/C++, se construye con CMake y cmkr para MSVC, e incluye módulos de ejemplo para control de procesos y ajustes de comportamiento. Está dirigido a ingenieros inversos y desarrolladores que necesitan inyección y hooking de procesos tempranos y configurables en Windows para depuración, investigación o trabajo relacionado con la seguridad de juegos.
