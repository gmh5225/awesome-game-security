IDA Nexus Docker runner 是一個可棄用的容器執行框架，用於配合 IDA Pro、Pi 編碼代理和 Hex Rays IDA Nexus 進行自動化靜態二進位分析。每次執行會將樣本複製到隔離工作區，以獨立的 Pi 工作階段執行一系列由 LLM 驅動的提示，並將 IDA Nexus 語意追蹤、Pi 對話紀錄和 worker 日誌打包成可攜式 ZIP 稽核封存。此方案結合 Docker、Python 編排、Shell 進入點以及基於 Node 的 Pi 工具，模型提供者設定在執行時提供，而非寫入映像。它面向需要可重現、提示驅動工作流程的逆向工程師和惡意軟體分析師，例如解包、API 與字串復原、設定擷取和 IDB 標註，同時將樣本視為不可信，並將憑證與主機路徑隔離在容器之外。
