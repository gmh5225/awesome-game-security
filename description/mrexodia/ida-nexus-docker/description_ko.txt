IDA Nexus Docker runner는 IDA Pro, Pi 코딩 에이전트, Hex Rays IDA Nexus를 사용한 자동화된 정적 바이너리 분석을 위한 일회용 컨테이너 하네스입니다. 각 실행에서는 샘플을 격리된 작업 공간에 복사하고, LLM 기반 프롬프트를 별도의 Pi 세션으로 실행하며, IDA Nexus 시맨틱 트레이스, Pi 트랜스크립트, worker 로그를 휴대 가능한 ZIP 감사 아카이브로 패키징합니다. 이 스택은 Docker, Python 오케스트레이션, 셸 진입점, Node 기반 Pi 도구를 결합하며, 모델 제공자 설정은 이미지에 포함하지 않고 런타임에 제공됩니다. 언패킹, API 및 문자열 복구, 구성 추출, IDB 마크업과 같은 재현 가능한 프롬프트 기반 워크플로를 원하는 리버스 엔지니어와 멀웨어 분석가를 대상으로 하며, 샘플을 적대적으로 취급하고 자격 증명과 호스트 경로를 컨테이너 밖에 유지합니다.
