IDA Nexus Docker runner è un ambiente container monouso per eseguire analisi binaria statica automatizzata con IDA Pro, l'agente di coding Pi e Hex Rays IDA Nexus. Ogni esecuzione copia i campioni in uno spazio di lavoro isolato, esegue una sequenza di prompt guidati da LLM come sessioni Pi separate e impacchetta tracce semantiche IDA Nexus, trascrizioni Pi e log worker in un archivio di audit ZIP portatile. Lo stack combina Docker, orchestrazione Python, entrypoint shell e strumenti Pi basati su Node, con impostazioni del provider di modelli fornite a runtime anziché incorporate nell'immagine. È rivolto a reverse engineer e analisti di malware che desiderano flussi di lavoro riproducibili e guidati da prompt, come unpacking, recupero di API e stringhe, estrazione di configurazione e markup IDB, trattando i campioni come ostili e mantenendo credenziali e percorsi host fuori dal container.
