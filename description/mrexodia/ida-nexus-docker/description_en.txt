IDA Nexus Docker runner is a disposable container harness for running automated static binary analysis with IDA Pro, the Pi coding agent, and Hex Rays IDA Nexus. Each run copies samples into an isolated workspace, executes a sequence of LLM-driven prompts as separate Pi sessions, and packages IDA Nexus semantic traces, Pi transcripts, and worker logs into a portable ZIP audit archive. The stack combines Docker, Python orchestration, shell entrypoints, and Node-based Pi tooling, with model provider settings supplied at runtime rather than baked into the image. It is aimed at reverse engineers and malware analysts who want reproducible, prompt-driven workflows such as unpacking, API and string recovery, configuration extraction, and IDB markup while treating samples as hostile and keeping credentials and host paths out of the container.
