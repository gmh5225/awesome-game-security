IDA Nexus Docker runner 是一个可弃用的容器运行框架，用于配合 IDA Pro、Pi 编码代理和 Hex Rays IDA Nexus 进行自动化静态二进制分析。每次运行会将样本复制到隔离工作区，以独立的 Pi 会话执行一系列由 LLM 驱动的提示，并将 IDA Nexus 语义追踪、Pi 对话记录和 worker 日志打包成可移植的 ZIP 审计归档。该方案结合了 Docker、Python 编排、Shell 入口点以及基于 Node 的 Pi 工具，模型提供商配置在运行时提供，而非写入镜像。它面向需要可重现、提示驱动工作流的逆向工程师和恶意软件分析师，例如解包、API 与字符串恢复、配置提取和 IDB 标注，同时将样本视为不可信，并将凭据与主机路径隔离在容器之外。
