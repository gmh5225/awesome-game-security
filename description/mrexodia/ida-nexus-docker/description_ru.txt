IDA Nexus Docker runner — это одноразовая контейнерная оболочка для автоматизированного статического бинарного анализа с IDA Pro, агентом кодирования Pi и Hex Rays IDA Nexus. При каждом запуске образцы копируются в изолированное рабочее пространство, выполняется последовательность LLM-управляемых промптов в отдельных сессиях Pi, а семантические следы IDA Nexus, транскрипты Pi и журналы worker упаковываются в переносимый ZIP-архив аудита. Стек объединяет Docker, оркестрацию на Python, shell-точки входа и инструменты Pi на Node, при этом настройки провайдера моделей передаются во время выполнения, а не встраиваются в образ. Он предназначен для специалистов по реверс-инжинирингу и аналитиков вредоносного ПО, которым нужны воспроизводимые, управляемые промптами рабочие процессы — распаковка, восстановление API и строк, извлечение конфигурации и разметка IDB — при обращении с образцами как с враждебными и хранении учётных данных и путей хоста вне контейнера.
