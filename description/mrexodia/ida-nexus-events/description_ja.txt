IDA Nexus Event Viewer は、ローカルに公開された IDA Nexus データベースを検出し、選択したインスタンスからライブ IDB フックイベントをストリーミングするスタンドアロンのターミナルアプリケーションです。Python 3.11+ で記述され、Textual TUI フレームワークと ida-nexus クライアントライブラリを使用し、利用可能なデータベースの閲覧と到着する構造化 /idb_events の監視のための分割ペインインターフェースを提供します。各イベント行にはタイムスタンプ、リビジョン、イベント名、実行の由来、コールバック固有フィールドが含まれ、リネーム、関数、セグメント、型、パッチ、コメント、Python スクリプト操作には色分けが施されます。Nexus Code Mode プラグイン付き IDA Pro を利用するリバースエンジニアやゲームセキュリティアナリスト向けで、データベース変更とそのトリガーをリアルタイムで把握できます。
