IDA Nexus Event Viewer 是一款独立的终端应用程序，可发现本地发布的 IDA Nexus 数据库，并从所选实例流式传输实时 IDB 钩子事件。该工具基于 Python 3.11+ 编写，采用 Textual TUI 框架和 ida-nexus 客户端库，提供分屏界面用于浏览就绪的数据库并实时查看到达的结构化 /idb_events 事件。每条事件行包含时间戳、修订版本、事件名称、执行来源及回调专用字段，对重命名、函数、段、类型、补丁、注释和 Python 脚本操作采用颜色编码区分。它面向使用 IDA Pro 配合 Nexus Code Mode 插件的逆向工程师和游戏安全分析师，帮助实时掌握数据库变更及其触发原因。
