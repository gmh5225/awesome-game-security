IDA Nexus Event Viewer — это автономное терминальное приложение, которое обнаруживает локально опубликованные базы данных IDA Nexus и транслирует в реальном времени события IDB hook из выбранного экземпляра. Написано на Python 3.11+ с фреймворком Textual TUI и клиентской библиотекой ida-nexus, оно предоставляет интерфейс с разделёнными панелями для просмотра готовых баз данных и наблюдения за структурированными /idb_events по мере их поступления. Каждая строка события включает метки времени, ревизии, имена событий, происхождение выполнения и поля, специфичные для callback, с цветовой кодировкой для переименований, функций, сегментов, типов, патчей, комментариев и операций Python-скриптов. Оно предназначено для инженеров по реверс-инжинирингу и аналитиков игровой безопасности, использующих IDA Pro с плагином Nexus Code Mode и нуждающихся в оперативной видимости изменений базы данных и того, что их вызвало.
