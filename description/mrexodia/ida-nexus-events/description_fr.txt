IDA Nexus Event Viewer est une application terminal autonome qui découvre les bases de données IDA Nexus publiées localement et diffuse en direct les événements de hook IDB depuis une instance sélectionnée. Écrite en Python 3.11+ avec le framework Textual TUI et la bibliothèque cliente ida-nexus, elle propose une interface à panneaux fractionnés pour parcourir les bases de données disponibles et suivre les /idb_events structurés au fil de leur arrivée. Chaque ligne d'événement inclut des horodatages, des révisions, des noms d'événements, la provenance d'exécution et des champs spécifiques aux callbacks, avec un codage couleur pour les renommages, fonctions, segments, types, correctifs, commentaires et opérations de scripts Python. Elle s'adresse aux ingénieurs en rétro-ingénierie et analystes en sécurité des jeux utilisant IDA Pro avec le plugin Nexus Code Mode qui ont besoin d'une visibilité en temps réel sur les changements de base de données et ce qui les a déclenchés.
