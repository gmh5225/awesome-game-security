IDA Nexus Event Viewer es una aplicación de terminal independiente que detecta bases de datos de IDA Nexus publicadas localmente y transmite en vivo eventos de hook IDB desde una instancia seleccionada. Escrita en Python 3.11+ con el framework Textual TUI y la biblioteca cliente ida-nexus, presenta una interfaz de paneles divididos para explorar bases de datos disponibles y observar /idb_events estructurados a medida que llegan. Cada fila de evento incluye marcas de tiempo, revisiones, nombres de eventos, procedencia de ejecución y campos específicos de callback, con codificación por colores para renombrados, funciones, segmentos, tipos, parches, comentarios y operaciones de scripts Python. Está dirigida a ingenieros de ingeniería inversa y analistas de seguridad de juegos que usan IDA Pro con el complemento Nexus Code Mode y necesitan visibilidad en tiempo real de los cambios en la base de datos y qué los provocó.
