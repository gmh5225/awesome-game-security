REToolSync 是一个用于协作逆向工程的同步框架，可使多个分析与调试工具在同一内存地址和选区上保持对齐。一个基于 Python Tornado 的 WebSocket 中央服务器协调 IDA Pro、Binary Ninja、x64dbg、WinDbg 的插件，以及一个 VS Code 扩展；在终端中 Ctrl+点击十六进制地址即可一次性跳转所有已连接的工具。客户端会广播光标与选区更新，并响应 goto 等共享导航命令，使分析人员能在静态反汇编、实时调试和脚本环境之间无缝切换。代码库涵盖用于服务器与反汇编器集成的 Python、用于 VS Code 客户端的 TypeScript，以及用于调试器插件的 C++。它面向经常在同一目标二进制文件上使用多种 RE 工具的逆向工程师与游戏安全研究人员。
