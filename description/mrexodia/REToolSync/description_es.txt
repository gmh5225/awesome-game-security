REToolSync es un framework de sincronización para ingeniería inversa colaborativa que mantiene alineadas varias herramientas de análisis y depuración en la misma dirección de memoria y selección. Un servidor central Python Tornado WebSocket coordina complementos para IDA Pro, Binary Ninja, x64dbg, WinDbg y una extensión de VS Code que permite Ctrl+clic en direcciones hexadecimales en la terminal para saltar a todas las herramientas conectadas a la vez. Los clientes difunden actualizaciones del cursor y la selección y responden a comandos de navegación compartidos como goto, de modo que los analistas pueden moverse sin interrupciones entre el desensamblado estático, la depuración en vivo y los entornos de scripting. La base de código abarca Python para el servidor e integraciones con desensambladores, TypeScript para el cliente de VS Code y C++ para complementos de depuradores. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad de juegos que trabajan habitualmente con varias herramientas RE sobre el mismo binario objetivo.
