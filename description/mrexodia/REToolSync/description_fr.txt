REToolSync est un framework de synchronisation pour l'ingénierie inverse collaborative qui maintient plusieurs outils d'analyse et de débogage alignés sur la même adresse mémoire et la même sélection. Un serveur central Python Tornado WebSocket coordonne des plugins pour IDA Pro, Binary Ninja, x64dbg, WinDbg et une extension VS Code qui permet de Ctrl+cliquer des adresses hexadécimales dans le terminal pour faire sauter tous les outils connectés en une fois. Les clients diffusent les mises à jour du curseur et de la sélection et répondent aux commandes de navigation partagées telles que goto, afin que les analystes puissent passer sans interruption entre le désassemblage statique, le débogage en direct et les environnements de script. La base de code couvre Python pour le serveur et les intégrations de désassembleurs, TypeScript pour le client VS Code et C++ pour les plugins de débogueur. Il s'adresse aux ingénieurs en ingénierie inverse et aux chercheurs en sécurité des jeux qui travaillent régulièrement avec plusieurs outils RE sur le même binaire cible.
