REToolSync — это фреймворк синхронизации для совместной обратной разработки, который поддерживает согласованность нескольких инструментов анализа и отладки по одному и тому же адресу памяти и выделению. Центральный сервер Python Tornado WebSocket координирует плагины для IDA Pro, Binary Ninja, x64dbg, WinDbg и расширение VS Code, позволяющее Ctrl+щелкнуть по шестнадцатеричным адресам в терминале, чтобы одновременно перейти во все подключённые инструменты. Клиенты транслируют обновления курсора и выделения и реагируют на общие команды навигации, такие как goto, поэтому аналитики могут беспрепятственно переключаться между статическим дизассемблированием, отладкой в реальном времени и средами скриптинга. Кодовая база включает Python для сервера и интеграций с дизассемблерами, TypeScript для клиента VS Code и C++ для плагинов отладчиков. Он предназначен для специалистов по обратной разработке и исследователей безопасности игр, которые регулярно работают с несколькими RE-инструментами над одним и тем же целевым бинарным файлом.
