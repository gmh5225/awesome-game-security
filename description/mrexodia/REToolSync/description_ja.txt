REToolSync は、協調的なリバースエンジニアリングのための同期フレームワークで、複数の分析・デバッグツールを同じメモリアドレスと選択範囲で揃えます。中央の Python Tornado WebSocket サーバーが、IDA Pro、Binary Ninja、x64dbg、WinDbg 向けプラグインと VS Code 拡張機能を統括し、ターミナルで 16 進アドレスを Ctrl+クリックすると、接続中のすべてのツールが一度にジャンプします。クライアントはカーソルと選択範囲の更新をブロードキャストし、goto などの共有ナビゲーションコマンドに応答するため、分析者は静的逆アセンブリ、ライブデバッグ、スクリプト環境の間をシームレスに移動できます。コードベースは、サーバーと逆アセンブラ統合用の Python、VS Code クライアント用の TypeScript、デバッガープラグイン用の C++ で構成されています。同一の対象バイナリに対して複数の RE ツールを日常的に使うリバースエンジニアとゲームセキュリティ研究者を対象としています。
