REToolSync는 협업 역공학을 위한 동기화 프레임워크로, 여러 분석 및 디버깅 도구가 동일한 메모리 주소와 선택 영역에서 정렬되도록 유지합니다. 중앙 Python Tornado WebSocket 서버가 IDA Pro, Binary Ninja, x64dbg, WinDbg용 플러그인과 VS Code 확장을 조율하며, 터미널에서 16진 주소를 Ctrl+클릭하면 연결된 모든 도구가 한 번에 이동합니다. 클라이언트는 커서 및 선택 영역 업데이트를 브로드캐스트하고 goto와 같은 공유 탐색 명령에 응답하므로, 분석가는 정적 디스어셈블리, 실시간 디버깅, 스크립팅 환경 사이를 원활하게 전환할 수 있습니다. 코드베이스는 서버 및 디스어셈블러 통합용 Python, VS Code 클라이언트용 TypeScript, 디버거 플러그인용 C++로 구성됩니다. 동일한 대상 바이너리에 대해 여러 RE 도구를 일상적으로 사용하는 역공학자와 게임 보안 연구자를 대상으로 합니다.
