REToolSync è un framework di sincronizzazione per il reverse engineering collaborativo che mantiene allineati più strumenti di analisi e debug sullo stesso indirizzo di memoria e sulla stessa selezione. Un server centrale Python Tornado WebSocket coordina plugin per IDA Pro, Binary Ninja, x64dbg, WinDbg e un'estensione VS Code che consente di Ctrl+cliccare indirizzi esadecimali nel terminale per saltare a tutti gli strumenti connessi in una sola volta. I client trasmettono aggiornamenti di cursore e selezione e rispondono a comandi di navigazione condivisi come goto, così gli analisti possono spostarsi senza interruzioni tra disassemblaggio statico, debug live e ambienti di scripting. La codebase comprende Python per il server e le integrazioni con i disassemblatori, TypeScript per il client VS Code e C++ per i plugin dei debugger. È rivolto a reverse engineer e ricercatori di sicurezza dei giochi che lavorano regolarmente con più strumenti RE sullo stesso binario target.
