Railroader Cheat Menu is an open-source mod that adds a host-only in-game debug and cheat menu for Railroader 0.6.x Experimental. It is implemented in C# against the official Railroader modding contract, with a Unity IMGUI front end, centralized game manipulation logic, and optional HarmonyLib runtime patches for derailment protection, speed-based damage, and tunable physics multipliers. The menu exposes session tools for company cash and reputation, locomotive and car repair, fueling and cargo handling, track and maintenance-of-way yard restocking, wear and oil toggles, and player or simulation speed adjustments, with multilingual UI strings. A PowerShell build script compiles the assembly with dotnet and packages it as a distributable mod. It suits developers and researchers studying Unity game modding, host-authoritative cheat surfaces, and reflective or Harmony-based runtime hooking rather than production anti-cheat design.
