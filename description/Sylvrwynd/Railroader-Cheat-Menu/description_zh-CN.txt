Railroader Cheat Menu 是一款开源模组，为 Railroader 0.6.x Experimental 添加仅主机可用的游戏内调试与作弊菜单。它以 C# 实现，遵循官方 Railroader 模组契约，采用 Unity IMGUI 前端、集中式游戏操控逻辑，以及可选的 HarmonyLib 运行时补丁，用于脱轨保护、基于速度的伤害及可调物理倍率。菜单提供会话级工具：公司现金与声望、机车与车辆维修、加油与货物处理、轨道与养路场补给、磨损与机油开关，以及玩家或模拟速度调节，并支持多语言 UI 字符串。PowerShell 构建脚本使用 dotnet 编译程序集并打包为可分发的模组。适合开发者和研究者学习 Unity 游戏模组、主机权威作弊界面，以及反射或 Harmony 运行时挂钩，而非面向生产的反作弊设计。
