DeepGuard — это античит-плагин для Minecraft Paper на базе ИИ, который выявляет подозрительное поведение игроков, особенно механические читы bridging в стиле scaffold. Он сочетает традиционные проверки движения с серверным выводом ONNX Runtime по коротким последовательностям поведения, построенным из углов взгляда, позиции, размещения и флагов движения. Сопутствующий плагин BehaviorRecorder собирает размеченные нормальные и читерские образцы, а скрипты на Python готовят данные и обучают 1D CNN (PyTorch), экспортируемую как модель ONNX для детекции в реальном времени. Администраторы могут запускать по расписанию тихие сканы или вручную анализировать отчёты с настраиваемыми порогами оповещения и наказания. Проект ориентирован на операторов серверов Minecraft и исследователей, изучающих античит на основе машинного обучения.
