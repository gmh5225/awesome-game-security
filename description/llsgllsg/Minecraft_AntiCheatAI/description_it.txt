DeepGuard è un plugin anti-cheat Minecraft Paper basato sull'IA che rileva comportamenti sospetti dei giocatori, in particolare i cheat di bridging meccanico in stile scaffold. Combina controlli di movimento tradizionali con inferenza ONNX Runtime sul server su brevi sequenze comportamentali costruite da angoli di sguardo, posizione, piazzamento e flag di movimento. Un plugin companion BehaviorRecorder raccoglie campioni etichettati normali e di cheat, mentre script Python preparano i dati e addestrano una CNN 1D (PyTorch) esportata come modello ONNX per il rilevamento in tempo reale. Gli admin possono eseguire scansioni silenziose a tempo o analisi manuali dei report con soglie configurabili di alert e punizione. Il progetto è rivolto agli operatori di server Minecraft e ai ricercatori che esplorano l'anti-cheat basato sul machine learning.
