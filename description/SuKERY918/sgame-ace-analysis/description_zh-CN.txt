本仓库记录了对腾讯 ACE 反作弊体系的一次完整逆向研究，研究对象为某特定《王者荣耀》Android 版本内集成的实现，重点围绕原生库 libtersafe.so 与 libtprt.so。文档涵盖静态架构、云端控制的规则与算子、向 anticheatexpert 端点的非 TLS 上报、经 RSA 校验的热加载检测数据块，以及通过 libqimei 等相关库进行的伴随指纹采集。一套大型 Python 工具链可自动完成 ELF 检查、加密字符串表恢复、调用图与数据块分析；另附 Frida 脚本用于在真机上追踪设备身份与遥测。在 arm64 硬件上的真机测试验证了检测时机、本地拦截弹窗以及调试器或 Hook 框架的触发行为。面向需要基于证据深入理解生产级移动端反作弊实现的游戏安全研究人员、反作弊分析师与移动逆向工程师。
