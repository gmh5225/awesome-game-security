이 저장소는 특정 王者荣耀(왕자영요) Android 빌드에 포함된 Tencent ACE 안티치트 스택에 대한 전면적인 리버스 엔지니어링 연구를 문서화하며, 네이티브 라이브러리 libtersafe.so와 libtprt.so를 중심으로 다룬다. 글에서는 정적 아키텍처, 클라우드 제어 규칙과 연산자, anticheatexpert 엔드포인트로의 비 TLS 리포팅, RSA 검증 핫로드 탐지 blob, libqimei 및 관련 라이브러리를 통한 동반 핑거프린팅을 다룬다. 대규모 Python 툴킷은 ELF 검사, 암호화 문자열 테이블 복구, 호출 그래프 및 blob 분석을 자동화하고, Frida 스크립트는 기기에서 디바이스 식별자와 원격 측정 추적을 지원한다. arm64 하드웨어에서의 온디바이스 테스트로 탐지 시점, 로컬 가로채기 대화상자, 디버거나 후크 프레임워크 트리거를 검증한다. 프로덕션 모바일 안티치트 구현을 근거 기반으로 깊이 이해하려는 게임 보안 연구자, 안티치트 분석가, 모바일 리버스 엔지니어를 대상으로 한다.
