This repository documents a full reverse-engineering study of Tencent’s ACE anti-cheat stack as shipped inside a specific Honor of Kings (王者荣耀) Android build, centered on the native libraries libtersafe.so and libtprt.so. The write-ups cover static architecture, cloud-controlled rules and operators, non-TLS reporting to anticheatexpert endpoints, RSA-verified hot-loaded detection blobs, and companion fingerprinting through libqimei and related libraries. A large Python toolkit automates ELF inspection, encrypted string-table recovery, call-graph and blob analysis, while a Frida script supports on-device tracing of device identity and telemetry. On-device tests on arm64 hardware validate detection timing, local intercept dialogs, and debugger or hook framework triggers. It is aimed at game security researchers, anti-cheat analysts, and mobile reverse engineers who need a deep, evidence-based map of a production mobile anti-cheat implementation.
