本儲存庫記錄對騰訊 ACE 反作弊體系的一次完整逆向研究，研究對象為某特定《王者榮耀》Android 版本內整合的實作，重點圍繞原生函式庫 libtersafe.so 與 libtprt.so。內容涵蓋靜態架構、雲端控制的規則與運算子、向 anticheatexpert 端點的非 TLS 上報、經 RSA 驗證的熱載入偵測資料區塊，以及透過 libqimei 等相關函式庫進行的伴隨指紋採集。一套大型 Python 工具鏈可自動完成 ELF 檢查、加密字串表復原、呼叫圖與資料區塊分析；另附 Frida 腳本用於在實機上追蹤裝置身分與遙測。在 arm64 硬體上的實機測試驗證了偵測時機、本機攔截對話框以及除錯器或 Hook 框架的觸發行為。適合需要以證據為基礎深入理解正式環境行動端反作弊實作的遊戲安全研究人員、反作弊分析師與行動逆向工程師。
