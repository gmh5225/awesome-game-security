本リポジトリは、特定の『王者栄耀』Android ビルドに同梱された Tencent ACE アンチチートスタックの包括的なリバースエンジニアリング研究をまとめたもので、ネイティブライブラリ libtersafe.so および libtprt.so を中心に扱う。記述は静的アーキテクチャ、クラウド制御のルールとオペレータ、anticheatexpert エンドポイントへの非 TLS レポート、RSA 検証付きホットロード検出 blob、libqimei など関連ライブラリによる端末フィンガープリンティングを含む。大規模な Python ツールキットは ELF 解析、暗号化文字列テーブル復元、コールグラフと blob 分析を自動化し、Frida スクリプトはデバイス上でデバイス ID とテレメトリのトレースを支援する。arm64 ハードウェア上の実機テストでは検出タイミング、ローカルインターセプトダイアログ、デバッガやフックフレームワークのトリガーを検証している。本番モバイルアンチチート実装を証拠に基づいて深く把握したいゲームセキュリティ研究者、アンチチートアナリスト、モバイル RE エンジニア向けである。
