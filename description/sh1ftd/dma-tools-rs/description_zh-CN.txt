dma-tools-rs 是一款 Windows 桌面应用程序，用于在通过 JTAG 连接的 DMA 硬件环境中，对 Xilinx Artix-7 FPGA（35T、75T 和 100T）进行 SPI 闪存比特流编程并读取设备 DNA。该程序使用 Rust 编写，采用 egui 和 eframe 图形界面，协调内置的 OpenOCD 构建版本以及针对 CH347 和 FTDI RS232 JTAG 适配器的项目专用 TAP、闪存和 DNA 脚本，并在 UI 中集成进度解析与固件发现功能。主要功能包括比特流编程、唯一设备 DNA 提取、FTDI 与 CH347 驱动栈的提权安装辅助、对内置 OpenOCD 及工具包的运行时校验，以及通过 memflow-base 进行的 PCILeech 完整性检查。该项目面向在游戏安全研究、逆向工程及相关硬件工作流中配置和维护基于 FPGA 的 DMA 卡的操作人员。
