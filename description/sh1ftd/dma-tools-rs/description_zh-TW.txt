dma-tools-rs 是一款 Windows 桌面應用程式，用於在透過 JTAG 連接的 DMA 硬體環境中，對 Xilinx Artix-7 FPGA（35T、75T 和 100T）進行 SPI 快閃記憶體位元流程式設計並讀取裝置 DNA。該程式以 Rust 撰寫，採用 egui 與 eframe 圖形介面，協調內建的 OpenOCD 建置版本以及針對 CH347 和 FTDI RS232 JTAG 轉接器的專案專用 TAP、快閃記憶體與 DNA 腳本，並在 UI 中整合進度解析與韌體探索功能。主要功能包括位元流程式設計、唯一裝置 DNA 擷取、FTDI 與 CH347 驅動堆疊的提權安裝輔助、對內建 OpenOCD 及工具套件的執行階段驗證，以及透過 memflow-base 進行的 PCILeech 完整性檢查。該專案面向在遊戲安全研究、逆向工程及相關硬體工作流程中設定與維護基於 FPGA 的 DMA 卡的操作人員。
