dma-tools-rs は、JTAG 経由で接続された DMA ハードウェア環境において、Xilinx Artix-7 FPGA（35T、75T、100T）の SPI フラッシュビットストリームの書き込みとデバイス DNA の読み取りを行う Windows デスクトップアプリケーションです。Rust で実装され、egui と eframe によるグラフィカル UI を備え、同梱の OpenOCD ビルドおよび CH347 および FTDI RS232 JTAG アダプター向けのプロジェクト固有の TAP、フラッシュ、DNA スクリプトを統合的に制御し、UI には進捗解析とファームウェア検出機能が組み込まれています。主な機能には、ビットストリームの書き込み、固有デバイス DNA の抽出、FTDI および CH347 スタック向けの管理者権限ドライバーインストール支援、同梱 OpenOCD およびツールペイロードの実行時検証、memflow-base による PCILeech サニティチェックが含まれます。本プロジェクトは、ゲームセキュリティ研究、リバースエンジニアリング、および関連するハードウェアワークフローにおいて FPGA ベースの DMA カードを設定・保守するオペレーターを対象としています。
