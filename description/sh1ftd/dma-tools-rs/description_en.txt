dma-tools-rs is a Windows desktop application for programming SPI flash bitstreams and reading device DNA on Xilinx Artix-7 FPGAs (35T, 75T, and 100T) connected over JTAG in DMA hardware setups. Written in Rust with an egui and eframe graphical interface, it orchestrates bundled OpenOCD builds and project-specific TAP, flash, and DNA scripts for CH347 and FTDI RS232 JTAG adapters, with progress parsing and firmware discovery built into the UI. Key capabilities include bitstream programming, unique device DNA extraction, elevated driver installation helpers for FTDI and CH347 stacks, runtime validation of bundled OpenOCD and tools payloads, and a PCILeech sanity check via memflow-base. The project is aimed at operators configuring and maintaining FPGA-based DMA cards in game security research, reverse engineering, and related hardware workflows.
