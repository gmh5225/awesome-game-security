Mac Game Library Advisor is a packaged agent skill that audits a Steam library on macOS and classifies each title by whether it runs natively, works through a compatibility layer, is unlikely to work, or lacks reliable public data. It grades real-world performance and mod framework viability (BepInEx, Workshop, script extenders), and explicitly flags risks from kernel-level anti-cheat (Easy Anti-Cheat, BattlEye, Vanguard, Ricochet) and third-party launchers that commonly block Wine-style environments. The workflow is defined in Markdown skill instructions and a distributable .skill bundle, and it mandates fresh lookups across AppleGamingWiki, PCGamingWiki, ProtonDB, and community reports rather than static allowlists. It is aimed at Mac players who want to avoid wasted setup time, and at anyone studying how commercial anti-cheat and platform checks interact with compatibility layers and unofficial runtimes on Apple hardware.
