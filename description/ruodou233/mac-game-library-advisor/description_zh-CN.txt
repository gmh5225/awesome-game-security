Mac Game Library Advisor 是一款打包的 agent skill，用于在 macOS 上审计 Steam 游戏库，并将每款游戏分类为：原生可运行、通过兼容层可玩、不太可能运行，或缺乏可靠公开数据。它会对实际运行表现以及模组框架（BepInEx、Workshop、脚本扩展器）的可用性进行评级，并明确标注来自内核级反作弊（Easy Anti-Cheat、BattlEye、Vanguard、Ricochet）以及常会阻止 Wine 类环境的第三方启动器的风险。工作流程由 Markdown skill 说明及可分发 .skill 包定义，并要求通过 AppleGamingWiki、PCGamingWiki、ProtonDB 与社区报告进行实时查询，而非依赖静态白名单。面向希望避免无效配置时间的 Mac 玩家，以及研究商业反作弊与平台检测如何与兼容层及非官方运行时在校验 Apple 硬件上交互的人群。
