Mac Game Library Advisor は、macOS 上の Steam ライブラリを監査し、各タイトルをネイティブ実行可能、互換レイヤー経由で動作、動作困難、または信頼できる公開データなしのいずれかに分類するパッケージ化されたエージェントスキルです。実運用でのパフォーマンスと Mod フレームワーク（BepInEx、Workshop、スクリプトエクステンダー）の実現可能性を評価し、カーネルレベルのアンチチート（Easy Anti-Cheat、BattlEye、Vanguard、Ricochet）や Wine 系環境を妨げがちなサードパーティランチャーによるリスクを明示的に示します。ワークフローは Markdown のスキル手順と配布可能な .skill バンドルで定義され、静的な許可リストではなく AppleGamingWiki、PCGamingWiki、ProtonDB、コミュニティ報告を横断した最新調査を必須とします。セットアップ時間の無駄を避けたい Mac プレイヤーや、商用アンチチートとプラットフォーム検査が互換レイヤーや非公式ランタイムと Apple ハードウェア上でどう相互作用するかを研究する人向けです。
