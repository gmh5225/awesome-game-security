Mac Game Library Advisor는 macOS에서 Steam 라이브러리를 감사하고 각 타이틀을 네이티브 실행 가능, 호환 레이어로 동작, 실행 어려움, 신뢰할 수 있는 공개 데이터 부재 중 하나로 분류하는 패키징된 에이전트 스킬입니다. 실제 성능과 모드 프레임워크(BepInEx, Workshop, 스크립트 익스텐더) 실현 가능성을 평가하고, 커널 수준 안티치트(Easy Anti-Cheat, BattlEye, Vanguard, Ricochet) 및 Wine 계열 환경을 흔히 차단하는 서드파티 런처로 인한 위험을 명시적으로 표시합니다. 워크플로는 Markdown 스킬 지침과 배포 가능한 .skill 번들로 정의되며, 정적 허용 목록 대신 AppleGamingWiki, PCGamingWiki, ProtonDB 및 커뮤니티 보고서를 통한 최신 조회를 의무화합니다. 불필요한 설정 시간을 피하고 싶은 Mac 플레이어와 상용 안티치트 및 플랫폼 검사가 호환 레이어 및 비공식 런타임과 Apple 하드웨어에서 어떻게 상호작용하는지 연구하는 이들을 대상으로 합니다.
