Mac Game Library Advisor 是一款封裝的 agent skill，用於在 macOS 上稽核 Steam 遊戲庫，並將每款遊戲分類為：原生可執行、透過相容層可玩、不太可能執行，或缺乏可靠公開資料。它會對實際執行表現以及模組框架（BepInEx、Workshop、腳本擴充器）的可用性進行評級，並明確標註來自核心層級反作弊（Easy Anti-Cheat、BattlEye、Vanguard、Ricochet）以及常會阻擋 Wine 類環境的第三方啟動器的風險。工作流程由 Markdown skill 說明及可散佈 .skill 套件定義，並要求透過 AppleGamingWiki、PCGamingWiki、ProtonDB 與社群報告進行即時查詢，而非依賴靜態白名單。面向希望避免無效設定時間的 Mac 玩家，以及研究商業反作弊與平台檢測如何與相容層及非官方執行環境在 Apple 硬體上互動的人群。
