Root My Pixel — это Android-приложение, которое автоматизирует получение временного root-доступа на поддерживаемых устройствах Google Pixel через установку в один нажатие. Оно использует эксплойт ядра NebuSec IonStack (CVE-2026-43499) вместе с ReSukiSU и KernelSU, применяя Shizuku для получения повышенных привилегий shell без предварительного root и развёртывания нативных payload-бинарников из встроенных ресурсов. Приложение в основном написано на Kotlin с нативным зондированием через JNI/C для профилирования устройств, сопоставляя версии прошивки и интерфейсов модулей ядра с поддерживаемыми профилями сборок перед выполнением эксплойта и запуском late-load KernelSU. Ключевые возможности включают логирование эксплойта в реальном времени, мягкую перезагрузку system_server и экспорт логов для отладки на устройствах семейства Pixel 7 — Pixel 10. Оно предназначено для исследователей мобильной безопасности, специалистов по реверс-инжинирингу и практиков игровой безопасности, которым нужно root-устройство Pixel для анализа приложений, поведения ядра и механизмов античита или обнаружения root.
