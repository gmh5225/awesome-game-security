Root My Pixel 是一款 Android 應用程式，透過一鍵安裝流程在受支援的 Google Pixel 裝置上自動取得暫時性 root 權限。它利用 NebuSec IonStack 核心漏洞（CVE-2026-43499），結合 ReSukiSU 與 KernelSU，透過 Shizuku 在無需預先 root 的情況下取得提升的 shell 權限，並從內建資源中部署原生 payload 二進位檔。此應用程式主要使用 Kotlin 編寫，並透過 JNI/C 原生探測進行裝置剖析，在執行漏洞利用並觸發 KernelSU 延遲載入之前，將韌體與核心模組介面版本與受支援的建置設定檔進行比對。主要功能包括即時漏洞利用日誌、對 system_server 的軟重啟，以及用於除錯的日誌匯出，支援 Pixel 7 至 Pixel 10 系列裝置。它面向需要已 root 的 Pixel 硬體來分析應用程式、核心行為以及反作弊或 root 偵測機制的行動安全研究人員、逆向工程師與遊戲安全從業者。
