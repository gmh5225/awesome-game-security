Root My Pixel 是一款 Android 应用，通过一键安装流程在受支持的 Google Pixel 设备上自动获取临时 root 权限。它利用 NebuSec IonStack 内核漏洞（CVE-2026-43499），结合 ReSukiSU 与 KernelSU，通过 Shizuku 在无需预先 root 的情况下获取提升的 shell 权限，并从内置资源中部署原生 payload 二进制文件。该应用主要使用 Kotlin 编写，并通过 JNI/C 原生探测进行设备画像，在执行漏洞利用并触发 KernelSU 延迟加载之前，将固件与内核模块接口版本与受支持的构建配置进行匹配。主要功能包括实时漏洞利用日志、对 system_server 的软重启，以及用于调试的日志导出，支持 Pixel 7 至 Pixel 10 系列设备。它面向需要已 root 的 Pixel 硬件来分析应用、内核行为以及反作弊或 root 检测机制的移动安全研究人员、逆向工程师和游戏安全从业者。
