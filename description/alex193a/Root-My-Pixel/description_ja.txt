Root My Pixel は、ワンタップのインストール手順で対応 Google Pixel デバイス上の一時的な root 権限取得を自動化する Android アプリです。NebuSec IonStack カーネルエクスプロイト（CVE-2026-43499）を ReSukiSU および KernelSU と組み合わせ、Shizuku 経由で事前の root なしに昇格された shell 権限を取得し、同梱アセットからネイティブ payload バイナリを配置します。アプリは主に Kotlin で構築され、JNI/C によるネイティブプロービングでデバイスプロファイリングを行い、エクスプロイト実行と KernelSU の late-load トリガー前に、ファームウェアおよびカーネルモジュールインターフェースのバージョンを対応ビルドプロファイルと照合します。主な機能には、リアルタイムのエクスプロイトログ、system_server のソフトリブート、デバッグ用ログエクスポートがあり、Pixel 7 から Pixel 10 ファミリーのデバイスに対応しています。アプリ解析、カーネル動作、およびアンチチートや root 検出メカニズムの分析のために root 済み Pixel ハードウェアを必要とする、モバイルセキュリティ研究者、リバースエンジニア、ゲームセキュリティ実務者を対象としています。
