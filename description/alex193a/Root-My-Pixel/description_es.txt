Root My Pixel es una aplicación Android que automatiza el acceso root temporal en dispositivos Google Pixel compatibles mediante un flujo de instalación con un solo toque. Aprovecha el exploit de kernel NebuSec IonStack (CVE-2026-43499) junto con ReSukiSU y KernelSU, usando Shizuku para obtener privilegios de shell elevados sin root previo y desplegar binarios payload nativos desde los assets incluidos. La app está desarrollada principalmente en Kotlin con sondeo nativo JNI/C para perfilado de dispositivos, comparando las versiones del firmware y de las interfaces de módulos del kernel con perfiles de compilación compatibles antes de ejecutar el exploit y activar la carga tardía de KernelSU. Las capacidades clave incluyen registro del exploit en tiempo real, reinicio suave de system_server y exportación de logs para depuración en dispositivos de la familia Pixel 7 a Pixel 10. Está dirigida a investigadores de seguridad móvil, ingenieros inversos y profesionales de seguridad en juegos que necesitan hardware Pixel con root para analizar aplicaciones, comportamiento del kernel y mecanismos anti-cheat o de detección de root.
