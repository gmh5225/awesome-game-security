Samurai's Scripts（SSV2）は、Grand Theft Auto V 向けのモジュール型 Lua 5.4 フレームワークおよびスクリプト群で、YimMenu モッドメニューに読み込み、ImGui インターフェース、コマンドコンソール、整理された機能モジュールでゲームプレイを拡張します。SmallBase テンプレート上に構築され、リバースエンジニアリングされた GTA V クラスバインディング、ネイティブとポインタ抽象、スクリプトグローバル、大規模静的データセットに加え、ビジネス管理、強盗編集、ステータス制御、カジノ支援などのオンラインツールや、車両・自身・ワールド向けの拡張を組み合わせています。バックエンドのライフサイクル、サービス、再利用可能なライブラリ、フロントエンドタブに分割された構成により、UI とゲームロジックを混在させずに挙動を追加できます。メニュー Lua がメモリ上の構造、マルチプレイヤースクリプト状態、YimMenu スクリプト API とどう連携するかの参照として、対応する Legacy および Online ビルド向けに、モッド作者とリバースエンジニアリング研究者を対象としています。
