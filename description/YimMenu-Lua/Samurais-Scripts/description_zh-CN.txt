Samurai's Scripts（SSV2）是一套面向《侠盗猎车手 V》的模块化 Lua 5.4 框架与脚本套件，加载到 YimMenu 模组菜单中，通过 ImGui 界面、命令控制台以及分模块组织的功能扩展玩法。它基于 SmallBase 模板构建，整合了逆向得到的 GTA V 类绑定、native 与指针抽象、脚本全局变量及大型静态数据集，并提供线上工具（如产业管理、抢劫编辑、属性控制、赌场辅助）以及载具、角色与世界相关增强。架构将后端生命周期、服务、可复用库与前端标签页分离，便于贡献者在不混用 UI 与游戏逻辑的前提下添加行为。面向希望了解菜单 Lua 如何与内存结构、多人脚本状态及 YimMenu 脚本 API 交互的模组作者与逆向研究人员，可作为在受支持的 Legacy 与 Online 版本上的参考。
