Samurai's Scripts（SSV2）是一套面向《俠盜獵車手 V》的模組化 Lua 5.4 框架與腳本套件，載入 YimMenu 模組選單後，以 ImGui 介面、命令主控台與分模組整理的功能擴充玩法。它建構於 SmallBase 範本之上，結合逆向取得的 GTA V 類別繫結、native 與指標抽象、腳本全域變數及大型靜態資料集，並提供線上工具（如產業管理、搶劫編輯、數值控制、賭場輔助）以及載具、自身與世界相關增強。架構將後端生命週期、服務、可重用函式庫與前端分頁分離，讓貢獻者能在不混用 UI 與遊戲邏輯的情況下新增行為。面向希望了解選單 Lua 如何與記憶體結構、多人腳本狀態及 YimMenu 腳本 API 互動的模組作者與逆向研究人員，可作為在受支援的 Legacy 與 Online 版本上的參考。
