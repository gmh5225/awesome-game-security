Samurai's Scripts (SSV2) is a modular Lua 5.4 framework and script suite for Grand Theft Auto V that loads into the YimMenu mod menu to extend gameplay with an ImGui interface, command console, and organized feature modules. It is built on the SmallBase template and combines reverse-engineered GTA V class bindings, native and pointer abstractions, script globals, and large static data sets with online tools such as business managers, heist editing, stat control, and casino helpers, plus vehicle, self, and world enhancements. The architecture splits backend lifecycle, services, reusable libraries, and frontend tabs so contributors can add behavior without mixing UI and game logic. It is aimed at mod authors and reverse-engineering researchers who want a reference for how menu Lua interacts with in-memory structures, multiplayer script state, and the YimMenu scripting API on supported Legacy and Online builds.
