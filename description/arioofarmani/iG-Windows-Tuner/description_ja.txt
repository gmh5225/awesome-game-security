iG Windows Tuner は、競技ゲーム向けに最適化しつつシステムを堅牢化し、カーネル型アンチチート基盤との互換性を保つ、監査可能で元に戻せる Windows 11 最適化ツールです。主に PowerShell で実装され、読み取り専用の WPF GUI とデータ駆動エンジンを備え、電源・グラフィックス・入力・ネットワーク・プライバシー・セキュリティ設定を網羅する JSON スキーマに基づくカタログ化された tweak を適用します。変更はすべてベンダー文書に照らした証拠レベルで記録され、JSON スナップショットとシステムの復元ポイントで捕捉され、個別または一括で元に戻せます。ハードウェアプロファイル向けプリセットに加え、ヘルスおよびアンチチート準備状況レポート、Defender の攻撃面削減管理、セキュリティスコアリング、カーネルおよび電源インスペクター、安全なシステムメンテナンスユーティリティを提供します。Defender、仮想化ベースのセキュリティ、Secure Boot、現代のアンチチートが要求するその他の条件を無効にせず、測定可能なパフォーマンス改善を求めるゲーマーと PC チューナー向けです。
