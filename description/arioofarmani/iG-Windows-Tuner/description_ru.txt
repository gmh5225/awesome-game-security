iG Windows Tuner — проверяемый и обратимый инструмент оптимизации Windows 11 для соревновательного гейминга при сохранении усиленной системы и совместимости с платформами античита на уровне ядра. Реализован в основном на PowerShell с GUI на WPF только для чтения и движком на основе данных, который применяет каталогизированные твики из JSON-схем для питания, графики, ввода, сети, конфиденциальности и безопасности. Каждое изменение имеет уровень доказательности по документации вендора, фиксируется в JSON-снимках с точками восстановления системы и может быть отменено по отдельности или массово. Помимо пресетов под профили железа, доступны отчёты о состоянии и готовности к античиту, управление сокращением поверхности атаки Defender, оценка безопасности, инспекторы ядра и питания и безопасные утилиты обслуживания системы. Предназначен для геймеров и настройщиков ПК, которым нужны измеримые приросты производительности без отключения Defender, безопасности на основе виртуализации, Secure Boot и других требований современных античитов.
