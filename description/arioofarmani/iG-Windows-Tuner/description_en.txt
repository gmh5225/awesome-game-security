iG Windows Tuner is an auditable, reversible Windows 11 optimization tool aimed at competitive gaming while keeping the system hardened and compatible with kernel anti-cheat platforms. It is implemented primarily in PowerShell with a read-only WPF GUI and a data-driven engine that applies cataloged tweaks from JSON schemas covering power, graphics, input, network, privacy, and security settings. Every change is evidence-tiered against vendor documentation, captured in JSON snapshots with System Restore points, and can be reverted individually or in bulk. Beyond presets tuned to hardware profiles, it offers health and anti-cheat readiness reports, Defender attack surface reduction management, security scoring, kernel and power inspectors, and safe system maintenance utilities. It is intended for gamers and PC tuners who want measurable performance tweaks without disabling Defender, virtualization-based security, Secure Boot, or other requirements enforced by modern anti-cheat.
