Este proyecto es un espacio de investigación para desarrollar plugins cargables en tiempo de ejecución que extienden el descompilador de Ghidra sin requerir cambios permanentes en las fuentes upstream de Ghidra. Aplica un parche al ejecutable del descompilador para añadir un gestor de plugins y, a continuación, compila con Bazel bibliotecas compartidas experimentales que registran Rules, Actions y funciones builtin personalizadas a través de la API del descompilador. El plugin de prueba de concepto para vectores RISC-V reconoce secuencias de instrucciones vectorizadas y las eleva a llamadas de mayor nivel como vector_memcpy, vector_memset y vector_strlen, reduciendo el ruido y mejorando la legibilidad de la salida descompilada. El desarrollo se realiza principalmente en C++ con herramientas Python y utiliza el framework datatest del descompilador para ciclos rápidos de compilación y prueba independientes de la GUI de Ghidra. Está dirigido a usuarios de Ghidra e ingenieros de ingeniería inversa que analizan binarios RISC-V, firmware embebido y otros programas que usan extensiones ISA, donde una salida de descompilación más clara acelera el trabajo de análisis de seguridad y binario.
