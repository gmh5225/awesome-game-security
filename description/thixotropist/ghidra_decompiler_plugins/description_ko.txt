이 프로젝트는 상류 Ghidra 소스에 지속적인 변경 없이 Ghidra 디컴파일러를 확장하는 런타임 로드 가능 플러그인을 개발하기 위한 연구용 작업 공간입니다. 디컴파일러 실행 파일에 패치를 적용해 플러그인 관리자를 추가한 뒤, Bazel로 실험적 공유 라이브러리를 빌드하여 디컴파일러 API를 통해 사용자 정의 Rules, Actions 및 내장 함수를 등록합니다. 개념 증명용 RISC-V 벡터 플러그인은 벡터화된 명령어 시퀀스를 인식하고 vector_memcpy, vector_memset, vector_strlen 같은 고수준 호출로 끌어올려 디컴파일 출력의 잡음을 줄이고 가독성을 높입니다. 개발은 주로 C++와 Python 도구로 이루어지며, Ghidra GUI와 무관하게 빠른 컴파일-테스트 주기를 위해 디컴파일러 datatest 프레임워크를 사용합니다. Ghidra 사용자 및 RISC-V 바이너리, 임베디드 펌웨어, ISA 확장을 사용하는 기타 프로그램을 분석하는 리버스 엔지니어를 대상으로 하며, 더 명확한 디컴파일 출력이 보안 및 바이너리 분석 작업을 가속합니다.
