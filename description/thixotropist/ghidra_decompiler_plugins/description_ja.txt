本プロジェクトは、上流の Ghidra ソースコードに永続的な変更を加えることなく Ghidra のデコンパイラを拡張する、実行時ロード可能なプラグインを開発するための研究用ワークスペースです。デコンパイラ実行ファイルにパッチを当ててプラグインマネージャを追加し、Bazel で実験的な共有ライブラリをビルドして、デコンパイラ API 経由でカスタム Rules、Actions、組み込み関数を登録します。概念実証の RISC-V ベクトルプラグインは、ベクトル化された命令列を認識し、vector_memcpy、vector_memset、vector_strlen などの高レベル呼び出しへ持ち上げ、逆コンパイル出力の冗長さを減らし可読性を向上させます。開発は主に C++ と Python ツールで行い、Ghidra GUI に依存しない高速なコンパイル・テストサイクルのためにデコンパイラの datatest フレームワークを使用します。Ghidra ユーザーおよび RISC-V バイナリ、組み込みファームウェア、その他 ISA 拡張を利用するプログラムを分析するリバースエンジニアを対象としており、より明瞭なデコンパイル出力がセキュリティおよびバイナリ解析作業を加速します。
