Этот проект представляет собой исследовательскую рабочую среду для разработки подключаемых во время выполнения плагинов, расширяющих декомпилятор Ghidra без необходимости вносить постоянные изменения в исходный код upstream Ghidra. Он патчит исполняемый файл декомпилятора, добавляя менеджер плагинов, затем с помощью Bazel собирает экспериментальные разделяемые библиотеки, регистрирующие пользовательские Rules, Actions и встроенные функции через API декомпилятора. Плагин proof-of-concept для векторов RISC-V распознаёт векторизованные последовательности инструкций и поднимает их до вызовов более высокого уровня, таких как vector_memcpy, vector_memset и vector_strlen, уменьшая шум и повышая читаемость декомпилированного вывода. Разработка ведётся преимущественно на C++ с инструментами на Python и использует фреймворк datatest декомпилятора для быстрых циклов компиляции и тестирования независимо от GUI Ghidra. Проект предназначен для пользователей Ghidra и специалистов по обратной разработке, анализирующих бинарники RISC-V, встроенную прошивку и другие программы с расширениями ISA, где более ясный вывод декомпилятора ускоряет работу по безопасности и бинарному анализу.
