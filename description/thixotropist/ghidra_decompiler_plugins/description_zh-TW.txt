本專案是一個研究工作區，用於開發可在執行時載入的外掛，以擴展 Ghidra 的反編譯器，且無需對上游 Ghidra 原始碼進行持久性修改。它對反編譯器可執行檔進行修補以加入外掛管理器，接著使用 Bazel 建置實驗性共享函式庫，透過反編譯器 API 註冊自訂 Rules、Actions 與內建函式。概念驗證用的 RISC-V 向量外掛能夠識別向量化指令序列，並將其提升為 vector_memcpy、vector_memset、vector_strlen 等更高層級的呼叫，從而減少雜亂並提高反編譯輸出的可讀性。開發主要使用 C++ 及 Python 工具鏈，並採用反編譯器 datatest 框架進行快速編譯測試循環，無需依賴 Ghidra GUI。面向 Ghidra 使用者及逆向工程師，用於分析 RISC-V 二進位檔、嵌入式韌體以及其他使用 ISA 擴展的程式，在這些場景下更清晰的反編譯輸出能夠加速安全與二進位分析工作。
