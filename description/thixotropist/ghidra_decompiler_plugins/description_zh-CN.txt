本项目是一个研究工作区，用于开发可在运行时加载的插件，以扩展 Ghidra 的反编译器，且无需对上游 Ghidra 源码进行持久性修改。它对反编译器可执行文件进行补丁以添加插件管理器，然后使用 Bazel 构建实验性共享库，通过反编译器 API 注册自定义 Rules、Actions 和内置函数。概念验证用的 RISC-V 向量插件能够识别向量化指令序列，并将其提升为 vector_memcpy、vector_memset、vector_strlen 等更高级别的调用，从而减少杂乱并提高反编译输出的可读性。开发主要使用 C++ 及 Python 工具链，并采用反编译器 datatest 框架进行快速编译测试循环，无需依赖 Ghidra GUI。面向 Ghidra 用户及逆向工程师，用于分析 RISC-V 二进制文件、嵌入式固件以及其他使用 ISA 扩展的程序，在这些场景下更清晰的反编译输出能够加速安全与二进制分析工作。
