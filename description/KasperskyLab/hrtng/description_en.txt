hrtng is an IDA Pro plugin that extends the Hex-Rays decompiler with a large collection of reverse-engineering helpers for day-to-day analysis. Written mainly in C++ against the IDA SDK (with supporting scripts), it covers automation such as variable renaming and auto-comments, interactive pseudocode recasting, string and data decryption, and type or structure building. It also targets obfuscated binaries with control-flow unflattening, de-inlining, API-hash scanning, microcode signatures, and virtual or indirect call assistance, plus UI and patching utilities. The primary audience is reverse engineers and malware analysts who need to speed up IDA and Hex-Rays workflows on complex or protected code.
