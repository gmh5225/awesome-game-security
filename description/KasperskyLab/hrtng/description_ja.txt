hrtng は、日々の解析向けに豊富なリバースエンジニアリング支援機能で Hex-Rays デコンパイラを拡張する IDA Pro プラグインです。主に IDA SDK 向けの C++（補助スクリプト付き）で書かれ、変数のリネームや自動コメント、対話的な疑似コードの再キャスト、文字列・データの復号、型や構造体の構築といった自動化をカバーします。さらに難読化バイナリ向けに、制御フローのアンフラット化、デインライン、API ハッシュ走査、マイクロコードシグネチャ、仮想／間接呼び出し支援、UI とパッチユーティリティも提供します。主な利用者は、複雑または保護されたコード上で IDA と Hex-Rays の作業を高速化したいリバースエンジニアおよびマルウェアアナリストです。
