hrtng는 일상적인 분석을 위한 다양한 리버스 엔지니어링 도우미로 Hex-Rays 디컴파일러를 확장하는 IDA Pro 플러그인입니다. 주로 IDA SDK용 C++로 작성되었으며(지원 스크립트 포함), 변수 이름 변경과 자동 주석, 대화형 의사코드 재캐스팅, 문자열·데이터 복호화, 타입·구조체 구축 같은 자동화를 다룹니다. 난독화된 바이너리를 위해 제어 흐름 언플랫닝, 디인라인, API 해시 스캔, 마이크로코드 시그니처, 가상·간접 호출 지원과 UI·패치 유틸리티도 제공합니다. 주요 대상은 복잡하거나 보호된 코드에서 IDA와 Hex-Rays 워크플로를 가속하려는 리버스 엔지니어와 악성코드 분석가입니다.
