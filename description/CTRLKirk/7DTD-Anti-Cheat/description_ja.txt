7 Days to Die 専用サーバー向けのサーバー側アンチチート MOD で、クライアントへのインストール不要のまま、ホスト上でプレイヤーのネットワークトラフィックと移動を検証します。C# と .NET Framework 4.8 で実装され、Harmony によりゲームのネットワーク処理とインベントリハンドラにパッチを当て、移動モニターと検知サービスがゴッドモード、テレポート、スピード・フライハック、ノークリップ、不正または oversized アイテム、過大ダメージと近接リーチ、疑わしいレベルジャンプなどをチェックします。各検知は XML で調整でき、ログ記録からキック・BAN までの処置に加え、管理者アラート、任意の Discord Webhook、設定の再読み込みや最近のフラグ確認用コンソールコマンドに対応します。EasyAntiCheat と併用できる軽量なチート検知を求めるマルチプレイサーバー運営者向けで、倍率と免除リストにより MOD 入りサーバーへも拡張できます。
