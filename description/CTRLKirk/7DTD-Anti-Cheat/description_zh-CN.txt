这是一款面向《七日杀》专用服务器的服务端反作弊模组，在主机上校验玩家网络流量与移动，无需在客户端安装。采用 C# 编写，目标框架为 .NET Framework 4.8，通过 Harmony 对游戏网络与背包处理逻辑打补丁，并由移动监控与检测服务执行对上帝模式、传送、加速与飞行作弊、穿墙、非法或超大尺寸物品、过高伤害与近战攻击距离、可疑等级跳跃等检查。每项检测可在 XML 中配置，动作从记录日志到踢出或封禁，并支持管理员告警、可选 Discord Webhook，以及用于重载设置与查看近期标记的控制台命令。面向希望在 EasyAntiCheat 之外运行轻量级作弊检测、并可通过倍率与豁免列表适配模组化服务器的多人服运营者。
