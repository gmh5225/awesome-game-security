這是一款面向《七日殺》專用伺服器的伺服器端反作弊模組，在主機上驗證玩家網路流量與移動，無需在客戶端安裝。以 C# 實作，目標框架為 .NET Framework 4.8，透過 Harmony 修補遊戲網路與背包處理邏輯，並由移動監控與偵測服務執行對上帝模式、傳送、加速與飛行外掛、穿牆、非法或超大尺寸物品、過高傷害與近戰攻擊距離、可疑等級跳躍等檢查。每項偵測可在 XML 中調整，動作從記錄日誌到踢出或封禁，並支援管理員告警、可選 Discord Webhook，以及用於重載設定與檢視近期標記的主控台命令。面向希望在 EasyAntiCheat 之外執行輕量級作弊偵測、並可透過倍率與豁免清單擴展至模組化伺服器的多人服營運者。
