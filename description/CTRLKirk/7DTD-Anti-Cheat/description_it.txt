È una mod anti-cheat lato server per server dedicati di 7 Days to Die che convalida il traffico di rete e i movimenti dei giocatori sull’host senza richiedere installazione sul client. È implementata in C# per .NET Framework 4.8 e usa Harmony per patchare il networking di gioco e i gestori dell’inventario, mentre un monitor dei movimenti e un servizio di rilevamento applicano controlli su god mode, teletrasporto, hack di velocità e volo, noclip, oggetti illegali o oversized, danni eccessivi e portata in mischia, e salti di livello sospetti. Ogni rilevamento è configurabile in XML con azioni dal logging fino a kick o ban, più avvisi admin, webhook Discord opzionali e comandi console per ricaricare le impostazioni e rivedere i flag recenti. È pensata per gli operatori di server multiplayer che vogliono un rilevamento cheat leggero accanto a EasyAntiCheat, scalabile su server moddati tramite moltiplicatori ed elenchi di esenzione.
