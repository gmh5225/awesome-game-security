This is a server-side anti-cheat mod for 7 Days to Die dedicated servers that validates player network traffic and movement on the host without requiring a client install. It is implemented in C# for .NET Framework 4.8 and uses Harmony to patch game networking and inventory handlers while a movement monitor and detection service enforce checks for god mode, teleporting, speed and fly hacks, noclip, illegal or oversized items, excessive damage and melee reach, and suspicious level jumps. Each detection can be tuned in XML with actions from logging through kick or ban, plus admin alerts, optional Discord webhooks, and console commands to reload settings and review recent flags. It is aimed at multiplayer server operators who want lightweight cheat detection that runs alongside EasyAntiCheat and can be scaled for modded servers via multipliers and exemption lists.
