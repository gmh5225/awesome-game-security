ClassRevive recovers readable Java source from compiled bytecode and measures how much of that output is structurally correct. It is a Java application built with Gradle that runs CFR, Vineflower, Procyon, and JADX in isolated worker JVMs, recompiles each candidate with javac, and selects the best result per file and per method using signature and round-trip checks against the original classes. It accepts class files, JARs, multi-release archives, Android APK and DEX inputs, and executables with embedded jars, and it profiles obfuscation, applies automatic reversals for Skidfuscator and Aidsfuscator, and can restore names from ProGuard or R8 mappings. A Swing desktop workbench and a command-line tool produce HTML and JSON confidence reports, IDE project exports, and optional native-library triage with Ghidra. It targets reverse engineers and security researchers who need evidence-backed decompilation of obfuscated or packaged Java, including game clients and protectors, without executing the analyzed code.
