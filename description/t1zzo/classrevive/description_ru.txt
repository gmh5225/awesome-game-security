ClassRevive восстанавливает читаемый исходный код Java из скомпилированного байткода и измеряет, насколько эта выдача структурно корректна. Это Java-приложение на Gradle, которое запускает CFR, Vineflower, Procyon и JADX в изолированных worker JVM, перекомпилирует каждый кандидат через javac и выбирает лучший результат по файлу и по методу с помощью проверок сигнатур и round-trip относительно исходных классов. Поддерживаются class-файлы, JAR, multi-release архивы, входы Android APK и DEX, а также исполняемые файлы со встроенными jar; профилируется обфускация, применяются автоматические обращения для Skidfuscator и Aidsfuscator, имена можно восстановить из маппингов ProGuard или R8. Настольный workbench на Swing и утилита командной строки формируют отчёты уверенности в HTML и JSON, экспорт проектов для IDE и опциональный triage нативных библиотек с Ghidra. Ориентирован на reverse-инженеров и исследователей безопасности, которым нужна обоснованная доказательствами декомпиляция обфусцированного или упакованного Java, включая игровые клиенты и protector’ы, без выполнения анализируемого кода.
