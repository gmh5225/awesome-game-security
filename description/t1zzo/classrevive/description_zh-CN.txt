ClassRevive 从已编译的字节码中恢复可读的 Java 源码，并衡量输出在结构上的正确程度。这是一款用 Gradle 构建的 Java 应用，在隔离的 worker JVM 中运行 CFR、Vineflower、Procyon 和 JADX，用 javac 重新编译每个候选结果，并通过对原始 class 的签名与往返校验，按文件和方法选出最佳结果。它支持 class 文件、JAR、多版本归档、Android APK 与 DEX 输入，以及内嵌 jar 的可执行文件；可分析混淆特征，自动逆向 Skidfuscator 与 Aidsfuscator，并可根据 ProGuard 或 R8 映射恢复名称。Swing 桌面工作台与命令行工具可生成 HTML 与 JSON 置信度报告、IDE 工程导出，以及可选的、借助 Ghidra 的原生库 triage。面向需要证据支撑的反混淆或打包 Java 反编译（含游戏客户端与 protector）且无需执行被分析代码的逆向工程师与安全研究人员。
