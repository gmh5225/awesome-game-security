ClassRevive recupera sorgente Java leggibile da bytecode compilato e misura quanto quell’output sia strutturalmente corretto. È un’applicazione Java costruita con Gradle che esegue CFR, Vineflower, Procyon e JADX in JVM worker isolate, ricompila ogni candidato con javac e seleziona il miglior risultato per file e per metodo usando controlli di firma e round-trip rispetto alle classi originali. Accetta file class, JAR, archivi multi-release, input APK e DEX Android ed eseguibili con jar incorporati; profila l’offuscamento, applica inversioni automatiche per Skidfuscator e Aidsfuscator e può ripristinare i nomi da mapping ProGuard o R8. Un workbench desktop Swing e uno strumento a riga di comando producono report di confidenza HTML e JSON, export di progetti IDE e triage opzionale delle librerie native con Ghidra. È rivolto a reverse engineer e ricercatori di sicurezza che necessitano decompilazione supportata da evidenze di Java offuscato o impacchettato, inclusi client di gioco e protector, senza eseguire il codice analizzato.
