ClassRevive 從已編譯的位元組碼中還原可讀的 Java 原始碼，並衡量輸出在結構上的正確程度。這是一款以 Gradle 建置的 Java 應用程式，在隔離的 worker JVM 中執行 CFR、Vineflower、Procyon 與 JADX，以 javac 重新編譯每個候選結果，並透過對原始 class 的簽章與往返驗證，依檔案與方法選出最佳結果。它支援 class 檔、JAR、多版本封存、Android APK 與 DEX 輸入，以及內嵌 jar 的可執行檔；可剖析混淆特徵，自動逆向 Skidfuscator 與 Aidsfuscator，並可依 ProGuard 或 R8 對應表還原名稱。Swing 桌面工作台與命令列工具可產生 HTML 與 JSON 置信度報告、IDE 專案匯出，以及可選的、借助 Ghidra 的原生函式庫 triage。面向需要證據支撐的反混淆或封裝 Java 反編譯（含遊戲用戶端與 protector）且無需執行被分析程式碼的逆向工程師與安全研究人員。
