ClassRevive はコンパイル済みバイトコードから読みやすい Java ソースを復元し、その出力が構造的にどれだけ正しいかを測定します。Gradle で構築した Java アプリケーションで、隔離された worker JVM 上で CFR、Vineflower、Procyon、JADX を実行し、各候補を javac で再コンパイルし、元のクラスに対するシグネチャとラウンドトリップ検証によりファイル単位・メソッド単位で最良の結果を選びます。class ファイル、JAR、マルチリリースアーカイブ、Android APK と DEX、埋め込み jar を含む実行ファイルを受け付け、難読化をプロファイルし、Skidfuscator と Aidsfuscator の自動復元を適用し、ProGuard または R8 マッピングから名前を復元できます。Swing デスクトップワークベンチとコマンドラインツールは HTML と JSON の信頼度レポート、IDE プロジェクトのエクスポート、Ghidra によるオプションのネイティブライブラリ triage を生成します。難読化またはパッケージ化された Java（ゲームクライアントや protector を含む）の、実行せずに根拠付きで逆コンパイルが必要なリバースエンジニアとセキュリティ研究者向けです。
