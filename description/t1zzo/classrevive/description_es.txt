ClassRevive recupera código fuente Java legible a partir de bytecode compilado y mide en qué medida esa salida es estructuralmente correcta. Es una aplicación Java construida con Gradle que ejecuta CFR, Vineflower, Procyon y JADX en JVM worker aisladas, recompila cada candidato con javac y selecciona el mejor resultado por archivo y por método mediante comprobaciones de firma e ida y vuelta frente a las clases originales. Acepta archivos class, JAR, archivos multi-release, entradas APK y DEX de Android y ejecutables con jars incrustados; perfila la ofuscación, aplica reversiones automáticas para Skidfuscator y Aidsfuscator y puede restaurar nombres a partir de mapas ProGuard o R8. Un workbench de escritorio Swing y una herramienta de línea de comandos generan informes de confianza en HTML y JSON, exportaciones de proyectos para IDE y triage opcional de bibliotecas nativas con Ghidra. Está dirigido a ingenieros inversos e investigadores de seguridad que necesitan descompilación respaldada por evidencias de Java ofuscado o empaquetado, incluidos clientes de juegos y protectores, sin ejecutar el código analizado.
