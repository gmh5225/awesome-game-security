ClassRevive는 컴파일된 바이트코드에서 읽기 쉬운 Java 소스를 복구하고, 그 출력이 구조적으로 얼마나 올바른지 측정합니다. Gradle로 빌드한 Java 애플리케이션으로, 격리된 worker JVM에서 CFR, Vineflower, Procyon, JADX를 실행하고 각 후보를 javac로 재컴파일한 뒤, 원본 클래스에 대한 서명 및 왕복 검증으로 파일·메서드별 최적 결과를 선택합니다. class 파일, JAR, 멀티 릴리스 아카이브, Android APK 및 DEX 입력, jar가 내장된 실행 파일을 지원하며, 난독화를 프로파일링하고 Skidfuscator와 Aidsfuscator에 대한 자동 역변환을 적용하며 ProGuard 또는 R8 매핑에서 이름을 복원할 수 있습니다. Swing 데스크톱 워크벤치와 명령줄 도구는 HTML 및 JSON 신뢰도 보고서, IDE 프로젝트 내보내기, Ghidra를 이용한 선택적 네이티브 라이브러리 triage를 생성합니다. 분석 대상 코드를 실행하지 않고 난독화되거나 패키징된 Java(게임 클라이언트 및 protector 포함)에 대한 근거 기반 역컴파일이 필요한 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
