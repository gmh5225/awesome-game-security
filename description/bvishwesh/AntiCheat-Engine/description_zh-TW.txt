Anti-Cheat Detection Engine 是一款面向多人遊戲的行為異常偵測系統，透過工作階段遙測資料標記可疑玩家，而非依賴靜態特徵簽章。實作採用 Python，搭配 scikit-learn 的 Isolation Forest 模型，僅以正常玩家輪廓訓練，從速度、命中率、爆頭率與每秒操作數等指標識別新型作弊，例如自瞄、加速與刷分或巨集機器人。FastAPI 服務提供即時分析端點，配套模組加入多場次信心評分以降低誤封、對標記帳號的影子大廳隔離檢疫，以及具自適應偵測閾值的動態配對。HTML 維運儀表板與資料模擬器支援展示與 SecOps 風格監控。適合遊戲安全工程師與反作弊研究人員建構以機器學習與遙測為基礎的執法管線原型。
