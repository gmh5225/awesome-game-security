Anti-Cheat Detection Engine は、マルチプレイヤーゲーム向けの行動異常検知システムで、静的シグネチャではなくセッションテレメトリから疑わしいプレイヤーをフラグ付けします。Python で実装し、scikit-learn の Isolation Forest を正常プレイヤープロファイルのみで学習し、移動速度・命中率・ヘッドショット率・每秒アクション数などの指標からエイムボット、スピードハック、スコア稼ぎやマクロボットといった新種のチートを検出します。FastAPI サービスがライブ分析 API を公開し、補助モジュールはマルチセッション信頼度スコアで誤 BAN を抑え、フラグ付きアカウントのシャドウロビー隔離、適応的検知閾値による動的マッチメイキングを提供します。HTML の運用ダッシュボードとデータシミュレータがデモと SecOps 風モニタリングを支援します。ゲームセキュリティエンジニアやアンチチート研究者が ML 駆動・テレメトリ基盤の執行パイプラインを試作するのに適しています。
