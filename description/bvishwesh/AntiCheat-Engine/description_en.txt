Anti-Cheat Detection Engine is a behavioral anomaly detection system for multiplayer games that flags suspicious players from session telemetry instead of relying on static signatures. It is implemented in Python using scikit-learn Isolation Forest models trained only on normal player profiles to spot novel cheats such as aimbots, speedhacks, and score-farming or macro bots from metrics like velocity, accuracy, headshot rate, and actions per second. A FastAPI service exposes live analysis endpoints, while companion modules add multi-session confidence scoring to limit false bans, shadow-lobby quarantine for flagged accounts, and dynamic matchmaking with adaptive detection thresholds. An HTML operations dashboard and a data simulator support demos and SecOps-style monitoring. It suits game security engineers and anti-cheat researchers prototyping ML-driven, telemetry-based enforcement pipelines.
