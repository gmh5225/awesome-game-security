Anti-Cheat Detection Engine — система поведенческого обнаружения аномалий для многопользовательских игр, которая помечает подозрительных игроков по телеметрии сессий, а не по статическим сигнатурам. Реализована на Python с моделями Isolation Forest из scikit-learn, обученными только на профилях нормальных игроков, чтобы выявлять новые читы вроде аимботов, спидхаков и ботов для накрутки очков или макросов по метрикам скорости, точности, доли хедшотов и действий в секунду. Сервис FastAPI предоставляет конечные точки анализа в реальном времени; сопутствующие модули добавляют оценку уверенности по нескольким сессиям против ложных банов, карантин в теневом лобби для помеченных аккаунтов и динамический матчмейкинг с адаптивными порогами детекции. HTML-панель эксплуатации и симулятор данных помогают в демонстрациях и мониторинге в духе SecOps. Подходит инженерам по безопасности игр и исследователям античита для прототипирования ML-ориентированных конвейеров принудительного применения правил на основе телеметрии.
