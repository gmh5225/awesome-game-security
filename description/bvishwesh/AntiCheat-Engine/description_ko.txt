Anti-Cheat Detection Engine은 멀티플레이어 게임을 위한 행동 이상 탐지 시스템으로, 정적 시그니처 대신 세션 원격 측정 데이터로 의심스러운 플레이어를 표시합니다. Python과 scikit-learn Isolation Forest로 구현되며, 정상 플레이어 프로필만으로 학습해 이동 속도, 명중률, 헤드샷 비율, 초당 행동 수 같은 지표에서 에임봇, 스피드핵, 점수 농사 및 매크로 봇 등 새로운 치트를 찾습니다. FastAPI 서비스가 실시간 분석 엔드포인트를 제공하고, 동반 모듈은 다중 세션 신뢰도 점수로 오탐 밴을 줄이며, 표시된 계정의 섀도 로비 격리와 적응형 탐지 임계값이 있는 동적 매치메이킹을 추가합니다. HTML 운영 대시보드와 데이터 시뮬레이터가 데모와 SecOps 스타일 모니터링을 지원합니다. 게임 보안 엔지니어와 안티치트 연구자가 ML 기반·원격 측정 중심의 집행 파이프라인을 프로토타이핑하기에 적합합니다.
