Anti-Cheat Detection Engine es un sistema de detección de anomalías conductuales para juegos multijugador que marca jugadores sospechosos a partir de telemetría de sesión en lugar de firmas estáticas. Está implementado en Python con modelos Isolation Forest de scikit-learn entrenados solo con perfiles de jugadores normales para detectar trampas nuevas como aimbots, speedhacks y bots de farmeo de puntuación o macros mediante métricas como velocidad, precisión, tasa de headshots y acciones por segundo. Un servicio FastAPI expone endpoints de análisis en vivo, mientras módulos complementarios añaden puntuación de confianza multisesión para limitar bans erróneos, cuarentena en lobby sombra para cuentas marcadas y emparejamiento dinámico con umbrales de detección adaptativos. Un panel operativo HTML y un simulador de datos apoyan demos y monitorización al estilo SecOps. Encaja para ingenieros de seguridad en juegos e investigadores antitrampas que prototipan pipelines de aplicación basados en ML y telemetría.
