Anti-Cheat Detection Engine 是一款面向多人游戏的行为异常检测系统，通过会话遥测数据标记可疑玩家，而非依赖静态特征签名。该方案以 Python 实现，使用 scikit-learn 的 Isolation Forest 模型，仅基于正常玩家档案训练，以便从速度、命中率、爆头率和每秒操作数等指标识别新型作弊，例如自瞄、加速和刷分或宏脚本机器人。FastAPI 服务提供实时分析接口，配套模块支持多局置信度评分以降低误封、对标记账号的影子大厅隔离检疫，以及带自适应检测阈值的动态匹配。HTML 运维看板与数据模拟器便于演示及类 SecOps 监控。适用于游戏安全工程师与反作弊研究人员搭建基于机器学习、遥测驱动的执法流水线原型。
