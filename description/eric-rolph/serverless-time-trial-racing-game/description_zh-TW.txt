Serverless Time-Trial Racing 是一款邊緣權威的異步模擬賽車遊戲：玩家在本地跑圈，由 Cloudflare Worker 重新模擬每次提交的成績以判定該圈是否在物理上有效。基於 Box3D 的同一物理核心一次性編譯為 WebAssembly，在 Rust 原生客戶端（wasmtime）與 TypeScript 裁判端（V8）上以固定 400 Hz 執行，從而藉助位元級精確的確定性，伺服器可透過重放已簽名的輸入日誌來驗證圈速，而無需信任客戶端狀態。圈速記錄透過 Ed25519 簽名的圈日誌、附狀態雜湊比對的 WASM 重放以及針對輔助輸入工具的遙測啟發式進行保護；每週程序化賽道透過自動化部署。技術堆疊包括：物理核心用 C、客戶端與提交流程用 Rust、Workers 上的 TypeScript 與 KV 排行榜、賽道生成用 Python。適合研究伺服端反作弊、確定性模擬以及信任最小化競技賽車架構的開發者。
