Serverless Time-Trial Racing is an edge-authoritative async sim racing game where players run laps locally and a Cloudflare Worker re-simulates each submitted run to decide whether the lap was physically valid. The same Box3D-based physics kernel is compiled once to WebAssembly and executed at a fixed 400 Hz on the Rust native client (wasmtime) and on the TypeScript referee (V8), so bit-exact determinism lets the server verify laps by replaying signed input logs instead of trusting client state. Laps are protected with Ed25519-signed lap logs, WASM replay with state-hash comparison, and telemetry heuristics aimed at tool-assisted input, with weekly procedural tracks deployed via automation. The stack spans C for the physics kernel, Rust for the client and submission pipeline, TypeScript on Workers with KV leaderboards, and Python for track generation. It is aimed at developers studying server-side anti-cheat, deterministic simulation, and trust-minimized competitive racing architectures.
