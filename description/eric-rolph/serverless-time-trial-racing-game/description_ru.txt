Serverless Time-Trial Racing — асинхронная симуляционная гоночная игра с авторитетом на периферии: игроки проходят круги локально, а Cloudflare Worker повторно симулирует каждый отправленный заезд, чтобы определить, был ли круг физически корректен. Один и тот же физический движок на базе Box3D один раз компилируется в WebAssembly и выполняется с фиксированной частотой 400 Гц в нативном клиенте на Rust (wasmtime) и в арбитре на TypeScript (V8), поэтому побитовая детерминированность позволяет серверу проверять круги воспроизведением подписанных журналов ввода, а не доверием к состоянию клиента. Круги защищены журналами с подписью Ed25519, воспроизведением WASM со сравнением хеша состояния и эвристиками телеметрии против ввода с помощью инструментов; еженедельные процедурные трассы развёртываются автоматизацией. Стек: C для физического ядра, Rust для клиента и конвейера отправки, TypeScript на Workers с таблицами лидеров KV, Python для генерации трасс. Ориентирован на разработчиков, изучающих серверный античит, детерминированную симуляцию и соревновательные гоночные архитектуры с минимальным доверием.
