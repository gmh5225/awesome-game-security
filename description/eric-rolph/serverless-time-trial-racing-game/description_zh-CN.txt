Serverless Time-Trial Racing 是一款边缘权威的异步模拟赛车游戏：玩家在本地跑圈，由 Cloudflare Worker 重新模拟每次提交的成绩以判定该圈是否在物理上有效。基于 Box3D 的同一物理内核一次性编译为 WebAssembly，在 Rust 原生客户端（wasmtime）与 TypeScript 裁判端（V8）上以固定 400 Hz 执行，从而借助位级精确的确定性，服务器可通过重放已签名的输入日志来验证圈速，而无需信任客户端状态。圈速记录通过 Ed25519 签名的圈日志、带状态哈希比对的 WASM 重放以及针对辅助输入工具的遥测启发式进行保护；每周程序化赛道通过自动化部署。技术栈包括：物理内核用 C、客户端与提交流程用 Rust、Workers 上的 TypeScript 与 KV 排行榜、赛道生成用 Python。适合研究服务端反作弊、确定性模拟以及信任最小化竞技赛车架构的开发者。
