Serverless Time-Trial Racing은 플레이어가 로컬에서 랩을 돌고 Cloudflare Worker가 제출된 각 주행을 재시뮬레이션하여 해당 랩이 물리적으로 유효한지 판정하는 엣지 권위형 비동기 시뮬레이션 레이싱 게임입니다. 동일한 Box3D 기반 물리 커널을 한 번 WebAssembly로 컴파일하여 Rust 네이티브 클라이언트(wasmtime)와 TypeScript 심판(V8)에서 고정 400 Hz로 실행하므로, 비트 단위 결정론으로 서버는 클라이언트 상태를 신뢰하지 않고 서명된 입력 로그 재생으로 랩을 검증할 수 있습니다. 랩은 Ed25519 서명 랩 로그, 상태 해시 비교가 있는 WASM 재생, 도구 보조 입력을 겨냥한 원격 측정 휴리스틱으로 보호되며, 주간 절차적 트랙은 자동화로 배포됩니다. 스택은 물리 커널에 C, 클라이언트와 제출 파이프라인에 Rust, KV 리더보드가 있는 Workers의 TypeScript, 트랙 생성에 Python을 사용합니다. 서버 측 안티치트, 결정론적 시뮬레이션, 신뢰 최소화 경쟁 레이싱 아키텍처를 공부하는 개발자를 대상으로 합니다.
