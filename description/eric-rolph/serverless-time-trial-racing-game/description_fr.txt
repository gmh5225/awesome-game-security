Serverless Time-Trial Racing est un jeu de course en simulation asynchrone à autorité en périphérie : les joueurs tournent en local et un Cloudflare Worker re-simule chaque run soumis pour décider si le tour était physiquement valide. Le même noyau physique basé sur Box3D est compilé une fois en WebAssembly et exécuté à 400 Hz fixes sur le client natif Rust (wasmtime) et l’arbitre TypeScript (V8), ce qui permet au serveur, grâce à un déterminisme bit à bit, de vérifier les tours en rejouant des journaux d’entrée signés plutôt qu’en faisant confiance à l’état client. Les tours sont protégés par des journaux signés Ed25519, un replay WASM avec comparaison de hash d’état et des heuristiques télémétriques ciblant les entrées assistées par outils, avec des circuits procéduraux hebdomadaires déployés par automatisation. La pile couvre le C pour le noyau physique, Rust pour le client et le pipeline de soumission, TypeScript sur Workers avec classements KV, et Python pour la génération de circuits. Il s’adresse aux développeurs qui étudient l’anti-triche côté serveur, la simulation déterministe et les architectures de course compétitive à confiance minimisée.
