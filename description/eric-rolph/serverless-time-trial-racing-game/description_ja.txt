Serverless Time-Trial Racing は、プレイヤーがローカルで周回し、Cloudflare Worker が提出された各走行を再シミュレーションしてラップが物理的に妥当かどうかを判定する、エッジ権威型の非同期シミュレーションレースゲームです。同じ Box3D ベースの物理カーネルを一度 WebAssembly にコンパイルし、Rust ネイティブクライアント（wasmtime）と TypeScript のレフェリー（V8）上で固定 400 Hz で実行するため、ビット単位で一致する決定性により、サーバーはクライアント状態を信頼せず、署名付き入力ログのリプレイでラップを検証できます。ラップは Ed25519 署名付きラップログ、状態ハッシュ比較付き WASM リプレイ、ツール支援入力を狙ったテレメトリヒューリスティックで保護され、週次の手続き型トラックは自動化でデプロイされます。スタックは物理カーネルに C、クライアントと提出パイプラインに Rust、KV リーダーボード付き Workers 上の TypeScript、トラック生成に Python を使用します。サーバー側アンチチート、決定性シミュレーション、信頼最小化の競技レースアーキテクチャを学ぶ開発者向けです。
