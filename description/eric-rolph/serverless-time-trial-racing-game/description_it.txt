Serverless Time-Trial Racing è un gioco di corse in simulazione asincrono con autorità edge: i giocatori completano i giri in locale e un Cloudflare Worker ri-simula ogni gara inviata per stabilire se il giro era fisicamente valido. Lo stesso kernel fisico basato su Box3D viene compilato una volta in WebAssembly ed eseguito a 400 Hz fissi sul client nativo Rust (wasmtime) e sull’arbitro TypeScript (V8), così il determinismo bit-perfect consente al server di verificare i giri riproducendo log di input firmati invece di fidarsi dello stato client. I giri sono protetti con log di giro firmati Ed25519, replay WASM con confronto hash di stato ed euristiche telemetriche mirate agli input assistiti da strumenti, con tracciati procedurali settimanali distribuiti via automazione. Lo stack comprende C per il kernel fisico, Rust per client e pipeline di invio, TypeScript su Workers con classifiche KV e Python per la generazione dei tracciati. È rivolto a sviluppatori che studiano anti-cheat lato server, simulazione deterministica e architetture di gare competitive a fiducia minimizzata.
