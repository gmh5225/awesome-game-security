OMEGA es un motor de pruebas de seguridad estática de aplicaciones JavaScript sin dependencias que analiza bundles de producción minificados, con muchos frameworks y ofuscados mediante un pipeline de varias fases. Implementado en Node.js sin bibliotecas externas, combina análisis AST manual, seguimiento de taint interprocedural, fingerprinting de ofuscadores y deofuscación de esquemas como arrays de cadenas de obfuscator.io, aplanamiento de flujo de control, JSFuck, AAEncode y JJEncode. Detecta XSS, inyecciones, credenciales hardcodeadas, problemas de postura CSRF, patrones ReDoS y otras fallas de seguridad del lado del cliente, reconociendo la salida de Angular, React, Vue, Webpack y bundlers relacionados. Los hallazgos se exportan como HTML, JSON, Markdown y SARIF para flujos de CI, con resúmenes de taint listos para LLM y backward slices opcionales para una revisión manual más profunda. La herramienta está dirigida a investigadores de seguridad e ingenieros de reverse engineering que necesitan auditar o deofuscar JavaScript del lado del cliente fuertemente protegido, incluidos clientes de juegos y otros activos web ofuscados.
