OMEGA 是一款零依賴的 JavaScript 靜態應用程式安全測試引擎，透過多階段管線分析經過壓縮、框架密集且經過混淆的生產環境打包檔案。此工具以 Node.js 實作且不依賴任何外部函式庫，結合了手寫 AST 分析、程序間污点追蹤、混淆器指紋辨識，以及針對 obfuscator.io 字串陣列、控制流平坦化、JSFuck、AAEncode 和 JJEncode 等方案的解混淆能力。它能偵測 XSS、注入、硬編碼憑證、CSRF 設定問題、ReDoS 模式及其他用戶端安全缺陷，同時識別 Angular、React、Vue、Webpack 及相關打包工具的輸出。掃描結果可匯出為 HTML、JSON、Markdown 和 SARIF 格式以用於 CI 工作流程，並提供可選的 LLM 就緒污点摘要和反向切片以便深入人工審查。此工具面向需要審計或解混淆高度受保護的用戶端 JavaScript 的安全研究人員和逆向工程師，包括遊戲用戶端及其他混淆的 Web 資產。
