OMEGA 是一款零依赖的 JavaScript 静态应用安全测试引擎，通过多阶段流水线分析经过压缩、框架密集且经过混淆的生产环境打包文件。该工具基于 Node.js 实现且不依赖任何外部库，结合了手写 AST 分析、过程间污点追踪、混淆器指纹识别，以及针对 obfuscator.io 字符串数组、控制流平坦化、JSFuck、AAEncode 和 JJEncode 等方案的解混淆能力。它能检测 XSS、注入、硬编码凭据、CSRF 配置问题、ReDoS 模式及其他客户端安全缺陷，同时识别 Angular、React、Vue、Webpack 及相关打包工具的输出。扫描结果可导出为 HTML、JSON、Markdown 和 SARIF 格式以用于 CI 工作流，并提供可选的 LLM 就绪污点摘要和反向切片以便深入人工审查。该工具面向需要审计或解混淆高度受保护的客户端 JavaScript 的安全研究人员和逆向工程师，包括游戏客户端及其他混淆的 Web 资产。
