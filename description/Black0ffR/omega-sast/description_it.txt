OMEGA è un motore di test di sicurezza statica delle applicazioni JavaScript senza dipendenze che analizza bundle di produzione minificati, ricchi di framework e offuscati tramite una pipeline multi-fase. Implementato in Node.js senza librerie esterne, combina analisi AST scritta a mano, tracciamento del taint interprocedurale, fingerprinting degli offuscatori e deoffuscazione di schemi come array di stringhe obfuscator.io, appiattimento del flusso di controllo, JSFuck, AAEncode e JJEncode. Rileva XSS, injection, credenziali hardcoded, problemi di postura CSRF, pattern ReDoS e altre vulnerabilità lato client, riconoscendo l'output di Angular, React, Vue, Webpack e bundler correlati. I risultati vengono esportati in HTML, JSON, Markdown e SARIF per i workflow CI, con riepiloghi di taint pronti per LLM e backward slice opzionali per una revisione manuale approfondita. Lo strumento è rivolto a ricercatori di sicurezza e reverse engineer che devono auditare o deoffuscare JavaScript lato client fortemente protetto, inclusi client di giochi e altri asset web offuscati.
