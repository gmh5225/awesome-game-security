OMEGA is a zero-dependency JavaScript static application security testing engine that analyzes minified, framework-heavy, and obfuscated production bundles through a multi-phase pipeline. Implemented in Node.js with no external libraries, it combines hand-rolled AST analysis, inter-procedural taint tracking, obfuscator fingerprinting, and deobfuscation for schemes such as obfuscator.io string arrays, control-flow flattening, JSFuck, AAEncode, and JJEncode. It detects XSS, injection, hardcoded credentials, CSRF posture issues, ReDoS patterns, and other client-side security flaws while recognizing Angular, React, Vue, Webpack, and related bundler output. Findings are exported as HTML, JSON, Markdown, and SARIF for CI workflows, with optional LLM-ready taint summaries and backward slices for deeper manual review. The tool is aimed at security researchers and reverse engineers who need to audit or deobfuscate heavily protected client-side JavaScript, including game clients and other obfuscated web assets.
