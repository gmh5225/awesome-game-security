OMEGA-5.0 is a zero-dependency static analysis engine for JavaScript bundles, built in Node.js for security researchers who need to inspect minified, framework-heavy, or obfuscated production code. It runs a multi-phase pipeline that combines hand-rolled AST parsing, inter-procedural taint tracking, obfuscator fingerprinting, and deobfuscation techniques such as string-array decoding, control-flow flattening recovery, and optional JSFuck or AAEncode payload extraction. The tool detects XSS, injection, credential leaks, broken crypto, CSRF weaknesses, ReDoS patterns, and other client-side security issues, then emits HTML, JSON, Markdown, and SARIF reports with CI-friendly exit codes. It also generates LLM-ready taint contracts and backward slices to support deeper manual review of complex bundles. The project is aimed at reverse engineering and security assessment workflows where understanding hidden logic in heavily protected JavaScript is essential, including game clients and anti-cheat-related web assets.
