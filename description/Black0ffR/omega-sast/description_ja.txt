OMEGA は、ゼロ依存の JavaScript 静的アプリケーションセキュリティテスト（SAST）エンジンであり、多段階パイプラインを通じて minify 済み、フレームワーク依存が高く、難読化された本番バンドルを解析します。Node.js で実装され外部ライブラリを一切使用せず、手書きの AST 解析、手続き間 taint 追跡、難読化ツールのフィンガープリンティング、obfuscator.io の文字列配列、制御フロー平坦化、JSFuck、AAEncode、JJEncode などのスキームに対する deobfuscation を組み合わせています。XSS、インジェクション、ハードコードされた認証情報、CSRF 設定上の問題、ReDoS パターン、その他のクライアントサイドのセキュリティ欠陥を検出し、Angular、React、Vue、Webpack および関連バンドラーの出力を認識します。検出結果は HTML、JSON、Markdown、SARIF として CI ワークフロー向けにエクスポートでき、オプションで LLM 対応の taint サマリーと backward slice による詳細な手動レビューも可能です。本ツールは、ゲームクライアントやその他の難読化された Web アセットを含む、高度に保護されたクライアントサイド JavaScript の監査や deobfuscation を必要とするセキュリティ研究者およびリバースエンジニアを対象としています。
