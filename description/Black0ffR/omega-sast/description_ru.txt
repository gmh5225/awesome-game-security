OMEGA — это движок статического тестирования безопасности JavaScript-приложений (SAST) без внешних зависимостей, который анализирует минифицированные, насыщенные фреймворками и обфусцированные production-бандлы через многофазный конвейер. Реализован на Node.js без внешних библиотек и сочетает ручной AST-анализ, межпроцедурное отслеживание taint, отпечатки обфускаторов и деобфускацию схем вроде строковых массивов obfuscator.io, выравнивания потока управления, JSFuck, AAEncode и JJEncode. Обнаруживает XSS, инъекции, захардкоженные учётные данные, проблемы с настройкой CSRF, паттерны ReDoS и другие уязвимости на стороне клиента, распознавая вывод Angular, React, Vue, Webpack и связанных бандлеров. Результаты экспортируются в HTML, JSON, Markdown и SARIF для CI-процессов, с опциональными сводками taint, готовыми для LLM, и backward slice для углублённого ручного анализа. Инструмент предназначен для исследователей безопасности и reverse-инженеров, которым нужно аудировать или деобфусцировать сильно защищённый клиентский JavaScript, включая игровые клиенты и другие обфусцированные веб-активы.
