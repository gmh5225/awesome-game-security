OMEGA는 외부 의존성 없이 동작하는 JavaScript 정적 애플리케이션 보안 테스트(SAST) 엔진으로, 다단계 파이프라인을 통해 minify된 프레임워크 중심의 난독화된 프로덕션 번들을 분석합니다. Node.js로 구현되었으며 외부 라이브러리 없이 수작업 AST 분석, 절차 간 taint 추적, 난독화 도구 핑거프린팅, obfuscator.io 문자열 배열, 제어 흐름 평탄화, JSFuck, AAEncode, JJEncode 등의 스킴에 대한 deobfuscation을 결합합니다. XSS, 인젝션, 하드코딩된 자격 증명, CSRF 구성 문제, ReDoS 패턴 및 기타 클라이언트 측 보안 결함을 탐지하며 Angular, React, Vue, Webpack 및 관련 번들러 출력을 인식합니다. 발견 사항은 CI 워크플로용 HTML, JSON, Markdown, SARIF로 내보낼 수 있으며, 선택적으로 LLM 준비 taint 요약과 backward slice를 통해 심층 수동 검토를 지원합니다. 이 도구는 게임 클라이언트 및 기타 난독화된 웹 자산을 포함해 강력히 보호된 클라이언트 측 JavaScript를 감사하거나 deobfuscation해야 하는 보안 연구자 및 리버스 엔지니어를 대상으로 합니다.
