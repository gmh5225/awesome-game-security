lm32dec es un descompilador que recupera C legible a partir de firmware y binarios compilados para el procesador software RISC LatticeMico32 (LM32) de 32 bits. Escrito en Python, se distribuye como complemento interactivo al estilo Hex-Rays para IDA Pro 8.x y 9.x, y como elevador autónomo sin interfaz que puede emitir C sin tener IDA instalado. La canalización abarca la decodificación de instrucciones para imágenes big-endian y little-endian, elevación IR personalizada, estructuración del flujo de control, recuperación de marcos de pila y de la convención de llamadas LM32 EABI, análisis def-use al estilo SSA, y generación de código C con variables locales virtuales, intrínsecos CSR de hardware y recuperación de tablas de salto de switch. Está dirigido a ingenieros inversos e investigadores de seguridad que analizan softcores FPGA, firmware embebido, objetivos QEMU LM32 y coprocesadores de seguridad embebidos propietarios little-endian donde el código LM32 debe comprenderse a nivel de fuente.
