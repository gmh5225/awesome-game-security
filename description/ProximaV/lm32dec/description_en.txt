lm32dec is a decompiler that recovers readable C from firmware and binaries built for the 32-bit LatticeMico32 (LM32) RISC soft processor. Written in Python, it ships as a Hex-Rays-style interactive plugin for IDA Pro 8.x and 9.x and as a standalone headless lifter that can emit C without IDA installed. The pipeline covers instruction decoding for big- and little-endian images, custom IR lifting, control-flow structuring, stack frame and LM32 EABI calling-convention recovery, SSA-style def-use analysis, and C code generation with virtual locals, hardware CSR intrinsics, and switch jump-table recovery. It targets reverse engineers and security researchers analyzing FPGA softcores, embedded firmware, QEMU LM32 targets, and proprietary little-endian embedded security coprocessors where LM32 code must be understood at source level.
