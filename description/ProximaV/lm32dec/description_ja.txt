lm32dec は、32 ビット LatticeMico32（LM32）RISC ソフトプロセッサ向けにビルドされたファームウェアやバイナリから読みやすい C を復元するデコンパイラです。Python で書かれており、IDA Pro 8.x および 9.x 向けの Hex-Rays 風インタラクティブプラグインとしても、IDA をインストールせずに C を出力できるスタンドアロンのヘッドレスリフターとしても提供されます。パイプラインは、ビッグエンディアンとリトルエンディアンイメージの命令デコード、カスタム IR リフティング、制御フロー構造化、スタックフレームと LM32 EABI 呼び出し規約の復元、SSA 形式の def-use 解析、仮想ローカル変数・ハードウェア CSR イントリンシック・switch ジャンプテーブル復元を伴う C コード生成をカバーします。FPGA ソフトコア、組み込みファームウェア、QEMU LM32 ターゲット、LM32 コードをソースレベルで理解する必要があるプロプライエタリなリトルエンディアン組み込みセキュリティコプロセッサを分析するリバースエンジニアとセキュリティ研究者を対象としています。
