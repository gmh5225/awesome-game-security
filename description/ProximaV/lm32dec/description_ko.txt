lm32dec는 32비트 LatticeMico32(LM32) RISC 소프트 프로세서용으로 빌드된 펌웨어와 바이너리에서 읽기 쉬운 C 코드를 복원하는 디컴파일러입니다. Python으로 작성되었으며, IDA Pro 8.x 및 9.x용 Hex-Rays 스타일 대화형 플러그인으로도, IDA 없이 C를 출력할 수 있는 독립형 헤드리스 리프터로도 제공됩니다. 파이프라인은 빅엔디언 및 리틀엔디언 이미지의 명령 디코딩, 사용자 정의 IR 리프팅, 제어 흐름 구조화, 스택 프레임 및 LM32 EABI 호출 규약 복원, SSA 스타일 def-use 분석, 가상 지역 변수·하드웨어 CSR 인트린식·switch 점프 테이블 복원을 포함한 C 코드 생성을 다룹니다. FPGA 소프트코어, 임베디드 펌웨어, QEMU LM32 대상, LM32 코드를 소스 수준에서 이해해야 하는 독점 리틀엔디언 임베디드 보안 코프로세서를 분석하는 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
