lm32dec 是一款反編譯器，可從面向 32 位元 LatticeMico32（LM32）RISC 軟核處理器建置的韌體與二進位檔中還原可讀的 C 程式碼。它以 Python 撰寫，既可作為適用於 IDA Pro 8.x 與 9.x 的 Hex-Rays 風格互動式外掛，也可作為無需安裝 IDA 的獨立無頭提升器並輸出 C 程式碼。其管線涵蓋大端與小端映像的指令解碼、自訂 IR 提升、控制流結構化、堆疊框架與 LM32 EABI 呼叫慣例還原、SSA 風格的 def-use 分析，以及含虛擬區域變數、硬體 CSR 內建函式與 switch 跳轉表還原的 C 程式碼產生。適用於分析 FPGA 軟核、嵌入式韌體、QEMU LM32 目標以及專有小端嵌入式安全協處理器的逆向工程師與安全研究人員，在這些情境中需要將 LM32 程式碼理解到原始碼層級。
