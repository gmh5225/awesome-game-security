lm32dec 是一款反编译器，可从面向 32 位 LatticeMico32（LM32）RISC 软核处理器构建的固件与二进制文件中恢复可读的 C 代码。它以 Python 编写，既可作为适用于 IDA Pro 8.x 与 9.x 的 Hex-Rays 风格交互式插件，也可作为无需安装 IDA 的独立无头提升器并输出 C 代码。其流程涵盖大端与小端映像的指令解码、自定义 IR 提升、控制流结构化、栈帧与 LM32 EABI 调用约定恢复、SSA 风格的 def-use 分析，以及带虚拟局部变量、硬件 CSR 内建函数与 switch 跳转表恢复的 C 代码生成。适用于分析 FPGA 软核、嵌入式固件、QEMU LM32 目标以及专有小端嵌入式安全协处理器的逆向工程师与安全研究人员，在这些场景中需要将 LM32 代码理解到源码级。
