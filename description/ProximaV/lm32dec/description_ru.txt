lm32dec — это декомпилятор, восстанавливающий читаемый C из прошивок и бинарников, собранных для 32-разрядного программного RISC-процессора LatticeMico32 (LM32). Написан на Python; поставляется как интерактивный плагин в стиле Hex-Rays для IDA Pro 8.x и 9.x и как автономный headless-лифтер, способный выдавать C без установленного IDA. Конвейер охватывает декодирование инструкций для образов big-endian и little-endian, пользовательский подъём IR, структурирование потока управления, восстановление стековых кадров и соглашения о вызовах LM32 EABI, SSA-подобный def-use-анализ и генерацию C с виртуальными локальными переменными, аппаратными CSR-интринсиками и восстановлением jump-таблиц switch. Предназначен для инженеров по реверсу и исследователей безопасности, анализирующих softcore FPGA, встроенную прошивку, цели QEMU LM32 и проприетарные little-endian встроенные копроцессоры безопасности, где код LM32 нужно понимать на уровне исходников.
