dmaguard è uno strumento di audit da riga di comando in sola lettura che valuta se i dispositivi collegati potrebbero leggere la memoria di sistema tramite DMA ispezionando le protezioni DMA di firmware e sistema operativo. Scritto in Rust per Windows e Linux x64, analizza internamente le tabelle ACPI DMAR e IVRS e le correla con lo stato IOMMU in tempo reale, i parametri di avvio del kernel, i livelli di sicurezza Thunderbolt e la Windows Kernel DMA Protection. Emette risultati strutturati con codici di gravità (ad esempio IOMMU mancante, modalità passthrough o opt-in DMA pre-boot disabilitato) e supporta output JSON e SARIF, snapshot Linux offline e dump ACPI autonomi. È pensato per operatori blue team, revisori della sicurezza hardware e chiunque voglia irrigidire workstation o laptop contro superfici di attacco DMA PCIe e Thunderbolt esterne.
