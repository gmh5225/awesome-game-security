dmaguard は読み取り専用のコマンドライン監査ツールで、ファームウェアと OS の DMA 保護を調べ、接続中のデバイスがシステムメモリを DMA 読み取りできる可能性があるかを評価します。Rust で Windows および Linux x64 向けに実装され、ACPI DMAR 表と IVRS 表をツリー内で解析し、稼働中の IOMMU 状態、カーネル起動パラメータ、Thunderbolt セキュリティレベル、Windows Kernel DMA Protection と突き合わせます。欠落 IOMMU、パススルーモード、プリブート DMA opt-in 無効など、重大度コード付きの構造化された所見を出力し、JSON と SARIF 出力、Linux オフラインスナップショット、単体の ACPI 表ダンプに対応します。ブルーチーム、ハードウェアセキュリティレビュアー、外部 PCIe および Thunderbolt の DMA 攻撃面を抑えるワークステーションやノート PC の強化を行うユーザー向けです。
