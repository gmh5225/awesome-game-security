dmaguard is a read-only command-line auditor that assesses whether plugged-in devices could DMA-read system memory by inspecting firmware and OS DMA protections. Written in Rust for Windows and Linux x64, it parses ACPI DMAR and IVRS tables in-tree and correlates them with live IOMMU state, kernel boot parameters, Thunderbolt security levels, and Windows Kernel DMA Protection. It emits structured findings with severity codes (for example missing IOMMU, passthrough mode, or disabled pre-boot DMA opt-in) and supports JSON and SARIF output, offline Linux snapshots, and standalone ACPI table dumps. The tool targets blue-team operators, hardware security reviewers, and anyone hardening workstations or laptops against external PCIe and Thunderbolt DMA attack surfaces.
