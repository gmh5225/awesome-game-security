dmaguard 是一款只读命令行审计工具，通过检查固件与操作系统层面的 DMA 防护机制，评估已接入设备是否可能以 DMA 方式读取系统内存。该工具使用 Rust 编写，支持 Windows 与 Linux x64，在代码内直接解析 ACPI DMAR 与 IVRS 表，并与当前 IOMMU 状态、内核启动参数、Thunderbolt 安全级别以及 Windows 内核 DMA 保护进行关联分析。它会输出带严重级别编码的结构化发现结果（例如缺少 IOMMU、直通模式或未启用预启动 DMA 选择加入），并支持 JSON 与 SARIF 输出、Linux 离线快照以及独立的 ACPI 表导出。面向蓝队运维、硬件安全评审人员，以及希望加固工作站或笔记本、降低外部 PCIe 与 Thunderbolt DMA 攻击面的用户。
