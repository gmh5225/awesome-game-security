dmaguard — утилита аудита командной строки только для чтения, которая по проверке защиты DMA в прошивке и ОС оценивает, могут ли подключённые устройства читать системную память через DMA. Написана на Rust для Windows и Linux x64, разбирает таблицы ACPI DMAR и IVRS внутри дерева и сопоставляет их с текущим состоянием IOMMU, параметрами загрузки ядра, уровнями безопасности Thunderbolt и Windows Kernel DMA Protection. Выдаёт структурированные находки с кодами серьёзности (например, отсутствие IOMMU, режим passthrough или отключённый pre-boot DMA opt-in) и поддерживает вывод JSON и SARIF, офлайн-снимки Linux и автономные дампы таблиц ACPI. Инструмент рассчитан на blue team, ревьюеров аппаратной безопасности и тех, кто усиливает защиту рабочих станций и ноутбуков от внешних поверхностей атаки DMA через PCIe и Thunderbolt.
