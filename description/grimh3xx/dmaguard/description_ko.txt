dmaguard는 읽기 전용 명령줄 감사 도구로, 펌웨어와 OS의 DMA 보호를 검사하여 연결된 장치가 시스템 메모리를 DMA로 읽을 수 있는지 평가합니다. Rust로 Windows 및 Linux x64용으로 작성되었으며, ACPI DMAR 및 IVRS 테이블을 트리 내에서 파싱하고 라이브 IOMMU 상태, 커널 부트 매개변수, Thunderbolt 보안 수준, Windows Kernel DMA Protection과 상관 분석합니다. IOMMU 누락, 패스스루 모드, 사전 부팅 DMA opt-in 비활성화 등 심각도 코드가 있는 구조화된 발견 사항을 출력하며 JSON·SARIF 출력, Linux 오프라인 스냅샷, 독립 ACPI 테이블 덤프를 지원합니다. 블루팀 운영자, 하드웨어 보안 검토자, 외부 PCIe 및 Thunderbolt DMA 공격 표면을 줄이려는 워크스테이션이나 노트북 강화 담당자를 대상으로 합니다.
