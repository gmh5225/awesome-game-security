dmaguard 是一款唯讀命令列稽核工具，透過檢查韌體與作業系統層級的 DMA 防護機制，評估已連接裝置是否可能以 DMA 方式讀取系統記憶體。該工具以 Rust 撰寫，支援 Windows 與 Linux x64，在程式內直接解析 ACPI DMAR 與 IVRS 表，並與即時 IOMMU 狀態、核心啟動參數、Thunderbolt 安全等級以及 Windows 核心 DMA 防護進行關聯分析。它會輸出附嚴重程度代碼的結構化發現結果（例如缺少 IOMMU、直通模式或未啟用開機前 DMA 選擇加入），並支援 JSON 與 SARIF 輸出、Linux 離線快照以及獨立的 ACPI 表傾印。適合藍隊維運人員、硬體安全審查者，以及希望強化工作站或筆記型電腦、降低外部 PCIe 與 Thunderbolt DMA 攻擊面的使用者。
