Chess Assist 是一款客户端浏览器工具包，可在 chess.com 进行中的对局里注入 Stockfish 分析与自动化功能。它以 JavaScript 实现，形式包括用户脚本、书签小工具以及可选的 Chrome 扩展，并为桌面端与移动端 Safari 提供独立构建。该软件可按可配置的延迟与搜索深度自动走引擎着法，叠加最佳着法与对手预测提示，并可在本地存储中保存设置的同时自定义棋盘界面。它还包含检测面板，跟踪厘兵损失、准确度、最佳着法率以及针对你或对手的嫌疑指标，并支持可选的全局复盘。该项目有助于研究基于网页的象棋客户端在对局中如何被增强或滥用，以及启发式引擎相关指标如何近似公平对局监测。
