Chess Assist は、chess.com のライブ対局に Stockfish による解析と自動化を注入するクライアント側ブラウザツールキットです。JavaScript でユーザースクリプト、ブックマークレット、任意の Chrome 拡張として実装され、デスクトップ用とモバイル Safari 用の別ビルドがあります。設定可能な遅延と探索深度でエンジンの手を自動で指し、最善手と相手予測のヒントをオーバーレイ表示し、設定をローカルストレージに保持しながら盤面 UI をカスタマイズできます。センチポーン損失、精度、最善手率、自分または相手向けの疑わしさゲージを追跡する検出パネルと、任意の全局再解析も含みます。本プロジェクトは、Web ベースのチェスクライアントが対局中にどう拡張または悪用され得るか、およびヒューリスティックなエンジン相関メトリクスが公平プレイ監視をどう近似するかを研究するのに有用です。
