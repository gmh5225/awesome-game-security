Chess Assist 是一款用戶端瀏覽器工具包，可在 chess.com 進行中的對局裡注入 Stockfish 分析與自動化功能。它以 JavaScript 實作，形式包含使用者腳本、書籤小工具以及可選的 Chrome 擴充功能，並為桌面與行動版 Safari 提供獨立建置。該軟體可依可設定的延遲與搜尋深度自動走引擎著法，疊加最佳著法與對手預測提示，並可在本地儲存中保存設定的同時自訂棋盤介面。它還包含偵測面板，追蹤厘兵損失、準確度、最佳著法率以及針對你或對手的嫌疑指標，並支援可選的全局複盤。此專案有助於研究網頁版象棋用戶端在對局中如何被增強或濫用，以及啟發式引擎相關指標如何近似公平對局監測。
