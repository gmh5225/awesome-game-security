Chess Assist is a client-side browser toolkit that injects Stockfish analysis and automation into live chess.com games. It is implemented in JavaScript as userscripts, bookmarklets, and an optional Chrome extension, with separate builds for desktop and mobile Safari. The software can auto-play engine moves with configurable delay and depth, overlay best-move and opponent-prediction hints, and customize the board UI while keeping settings in local storage. It also includes a detection panel that tracks centipawn loss, accuracy, best-move rate, and a suspicion gauge for you or your opponent, with optional full-game reanalysis. The project is useful for studying how web-based chess clients can be augmented or abused during play and how heuristic engine-correlation metrics approximate fair-play monitoring.
