Asdf Overlay는 임의의 대상 프로세스 내에서 게임 내 오버레이를 렌더링하는 고성능 Windows 라이브러리입니다. 주로 Rust로 작성되었으며 Rust 및 Node.js/TypeScript 클라이언트 API를 제공합니다. 오버레이 DLL을 주입하여 Microsoft Detours를 사용해 DirectX 9, 11, 12, OpenGL, Vulkan 스왑 체인을 후킹하고, named-pipe IPC를 통해 통신합니다. 프레임워크는 공유 텍스처 표면 렌더링, 커서 관리, 입력 캡처 또는 차단을 지원하며, Electron 기반 인게임 브라우저 및 독립형 Rust 데모 등의 예제가 있습니다. 게임 오버레이를 구축하는 개발자와 오버레이 및 안티치트 연구에서 흔한 프로세스 인젝션, 그래픽 API 후킹, 입력 가로채기 기법을 연구하는 게임 보안 연구자를 대상으로 합니다.
