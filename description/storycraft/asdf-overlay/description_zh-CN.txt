Asdf Overlay 是一款高性能的 Windows 库，用于在任意目标进程内渲染游戏内叠加层。它主要使用 Rust 编写，并通过 Rust 和 Node.js/TypeScript 客户端 API 对外提供能力，注入叠加层 DLL，借助 Microsoft Detours 挂钩 DirectX 9、11 和 12、OpenGL 以及 Vulkan 交换链，并通过命名管道 IPC 进行通信。该框架支持共享纹理表面渲染、光标管理以及输入捕获或拦截，示例包括基于 Electron 的游戏内浏览器以及独立的 Rust 演示程序。它面向构建游戏叠加层的开发者，以及研究进程注入、图形 API 挂钩和输入拦截等叠加层与反作弊研究中常见技术的游戏安全研究人员。
