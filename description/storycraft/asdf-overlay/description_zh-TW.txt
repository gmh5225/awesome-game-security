Asdf Overlay 是一款高效能的 Windows 程式庫，用於在任意目標程序內渲染遊戲內覆蓋層。它主要以 Rust 撰寫，並透過 Rust 與 Node.js/TypeScript 用戶端 API 對外提供能力，注入覆蓋層 DLL，借助 Microsoft Detours 掛鉤 DirectX 9、11 和 12、OpenGL 以及 Vulkan 交換鏈，並透過命名管道 IPC 進行通訊。該框架支援共享紋理表面渲染、游標管理以及輸入擷取或攔截，範例包括基於 Electron 的遊戲內瀏覽器以及獨立的 Rust 示範程式。它面向建構遊戲覆蓋層的開發者，以及研究程序注入、圖形 API 掛鉤和輸入攔截等覆蓋層與反作弊研究中常見技術的遊戲安全研究人員。
