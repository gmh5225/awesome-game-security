Asdf Overlay — это высокопроизводительная библиотека Windows для отрисовки игровых оверлеев внутри произвольных целевых процессов. Она написана преимущественно на Rust и предоставляет клиентские API на Rust и Node.js/TypeScript, внедряя DLL оверлея, которая перехватывает swap chain DirectX 9, 11 и 12, OpenGL и Vulkan с помощью Microsoft Detours, взаимодействуя через IPC по именованным каналам. Фреймворк поддерживает рендеринг поверхностей с общей текстурой, управление курсором и захват или блокировку ввода, с примерами, такими как игровой браузер на базе Electron и автономные демо на Rust. Он предназначен для разработчиков, создающих игровые оверлеи, и для исследователей безопасности игр, изучающих техники инъекции процессов, перехвата графических API и перехвата ввода, распространённые в исследованиях оверлеев и античитов.
