Asdf Overlay は、任意のターゲットプロセス内でゲーム内オーバーレイを描画するための高パフォーマンス Windows ライブラリです。主に Rust で書かれており、Rust および Node.js/TypeScript のクライアント API を提供します。オーバーレイ DLL を注入し、Microsoft Detours を使用して DirectX 9、11、12、OpenGL、Vulkan のスワップチェーンをフックし、名前付きパイプ IPC 経由で通信します。フレームワークは共有テクスチャサーフェス描画、カーソル管理、入力の取得またはブロックをサポートし、Electron ベースのゲーム内ブラウザやスタンドアロンの Rust デモなどの例があります。ゲームオーバーレイを構築する開発者や、オーバーレイおよびアンチチート研究で一般的なプロセスインジェクション、グラフィックス API フック、入力傍受の技術を研究するゲームセキュリティ研究者を対象としています。
