這是一個 Windows 核心驅動動手實驗專案，透過小型、附註解的 KMDF 和 WDM 驅動，講授端點偵測與反作弊背後的底層原語。此集合包含四個漸進式範例：最小 KMDF 框架、透過 PsSetCreateProcessNotifyRoutineEx 監控程序建立與終止、利用 PsSetLoadImageNotifyRoutine 進行過濾的 DLL 與驅動映像載入遙測，以及使用 ObRegisterCallbacks 實作的反作弊式程序記憶體保護，並配有模擬遊戲與讀取器測試框架。驅動程式以 C 語言撰寫，使用 Windows Driver Kit 建置 x64 與 ARM64 版本，並附有 C++ 主控台工具來示範保護行為。本專案面向安全研究人員、遊戲安全工程師與逆向工程師，協助他們在啟用測試簽署的隔離虛擬機器中，學習 EDR 與反作弊元件如何觀察與保護程序。
