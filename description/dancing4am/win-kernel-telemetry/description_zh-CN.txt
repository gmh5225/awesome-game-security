这是一个 Windows 内核驱动动手实验项目，通过小型、带注释的 KMDF 和 WDM 驱动，讲授端点检测与反作弊背后的底层原语。该集合包含四个渐进式示例：最小 KMDF 框架、通过 PsSetCreateProcessNotifyRoutineEx 监控进程创建与退出、利用 PsSetLoadImageNotifyRoutine 进行过滤的 DLL 与驱动映像加载遥测，以及使用 ObRegisterCallbacks 实现的反作弊式进程内存保护，并配有假游戏与读取器测试框架。驱动使用 C 语言编写，通过 Windows Driver Kit 为 x64 和 ARM64 构建，并配有 C++ 控制台工具来演示保护行为。该项目面向安全研究人员、游戏安全工程师和逆向工程师，帮助他们在启用测试签名的隔离虚拟机中学习 EDR 与反作弊组件如何观察和保护进程。
