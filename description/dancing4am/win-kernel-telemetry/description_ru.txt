Это практическая лабораторная работа по драйверам ядра Windows, которая обучает низкоуровневым примитивам, лежащим в основе обнаружения на конечных точках и античита, через небольшие прокомментированные драйверы KMDF и WDM. В коллекции четыре постепенно усложняющихся примера: минимальный каркас KMDF, мониторинг создания и завершения процессов через PsSetCreateProcessNotifyRoutineEx, фильтрованная телеметрия загрузки образов DLL и драйверов с PsSetLoadImageNotifyRoutine и защита памяти процессов в стиле античита с ObRegisterCallbacks, а также фальшивая игра и тестовый стенд для чтения. Драйверы написаны на C и собираются с помощью Windows Driver Kit для x64 и ARM64, с сопутствующими консольными утилитами на C++ для демонстрации поведения защиты. Ориентировано на исследователей безопасности, инженеров игровой безопасности и реверс-инженеров, изучающих, как компоненты EDR и античита наблюдают за процессами и защищают их в изолированной ВМ с включённой тестовой подписью.
