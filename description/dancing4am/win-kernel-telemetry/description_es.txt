Este es un laboratorio práctico de controladores de kernel de Windows que enseña las primitivas de bajo nivel detrás de la detección de endpoints y el anti-cheat mediante controladores KMDF y WDM pequeños y comentados. La colección incluye cuatro ejemplos incrementales: un esqueleto KMDF mínimo, monitorización de creación y salida de procesos mediante PsSetCreateProcessNotifyRoutineEx, telemetría filtrada de carga de imágenes DLL y controladores con PsSetLoadImageNotifyRoutine, y protección de memoria de procesos estilo anti-cheat con ObRegisterCallbacks junto con un juego falso y un banco de pruebas de lectura. Los controladores están escritos en C y compilados con el Windows Driver Kit para x64 y ARM64, con utilidades de consola en C++ complementarias para demostrar el comportamiento de protección. Está dirigido a investigadores de seguridad, ingenieros de seguridad de juegos e ingenieros de ingeniería inversa que aprenden cómo los componentes EDR y anti-cheat observan y protegen procesos en una VM aislada con firma de prueba habilitada.
