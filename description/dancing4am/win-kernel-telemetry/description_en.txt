This is a hands-on Windows kernel driver lab that teaches the low-level primitives behind endpoint detection and anti-cheat through small, commented KMDF and WDM drivers. The collection includes four incremental examples: a minimal KMDF skeleton, process create and exit monitoring via PsSetCreateProcessNotifyRoutineEx, filtered DLL and driver image-load telemetry with PsSetLoadImageNotifyRoutine, and anti-cheat-style process memory protection using ObRegisterCallbacks with a fake game and reader test harness. Drivers are written in C and built with the Windows Driver Kit for x64 and ARM64, with companion C++ console utilities to demonstrate protection behavior. It is aimed at security researchers, game security engineers, and reverse engineers learning how EDR and anti-cheat components observe and protect processes in an isolated VM with test signing enabled.
