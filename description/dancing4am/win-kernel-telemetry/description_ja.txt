これは、小さくコメント付きの KMDF および WDM ドライバーを通じて、エンドポイント検知とアンチチートの背後にある低レベルのプリミティブを学べる Windows カーネルドライバーのハンズオン演習です。コレクションには4つの段階的な例が含まれます。最小限の KMDF スケルトン、PsSetCreateProcessNotifyRoutineEx によるプロセス作成・終了の監視、PsSetLoadImageNotifyRoutine によるフィルタリング付き DLL およびドライバーイメージのロードテレメトリ、ObRegisterCallbacks を使用したアンチチート風のプロセスメモリ保護（偽ゲームとリーダーのテストハーネス付き）です。ドライバーは C で記述され、Windows Driver Kit を用いて x64 および ARM64 向けにビルドされ、保護動作を示す C++ コンソールユーティリティも同梱されています。テスト署名を有効にした隔離 VM 上で、EDR およびアンチチートコンポーネントがプロセスをどのように監視・保護するかを学ぶ、セキュリティ研究者、ゲームセキュリティエンジニア、リバースエンジニア向けの教材です。
