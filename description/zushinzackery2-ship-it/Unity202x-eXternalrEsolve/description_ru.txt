er2 — это header-only фреймворк на C++17, который восстанавливает структуры данных среды выполнения движка Unity из работающего процесса с помощью межпроцессного доступа к памяти только для чтения, без использования таблиц символов, RTTI, чтения файловой системы или инъекции кода. Он ориентирован на Unity 2020–2023 под Windows x64 и автоматически определяет бэкенды Mono и IL2CPP. Основные возможности включают слепое обнаружение GameObjectManager и реестров ID экземпляров, удалённое восстановление метаданных IL2CPP и смещений полей, интроспекцию объектов и компонентов, извлечение Transform и Camera, проекцию world-to-screen и экспорт через DumpSDK артефактов в стиле dump.cs. Библиотека предназначена для академических исследований, авторизованного моддинга и разработки плагинов, а также изучения внутренней структуры игр Unity методами обратной разработки.
