er2 是一個僅標頭檔的 C++17 框架，透過跨程序唯讀記憶體存取，從即時程序中重建 Unity 引擎執行階段資料結構，無需依賴符號表、RTTI、檔案系統讀取或程式碼注入。它支援 Windows x64 上的 Unity 2020 至 2023 版本，可自動偵測 Mono 與 IL2CPP 後端。核心功能包括盲探測 GameObjectManager 與實例 ID 登錄表、遠端重建 IL2CPP 中繼資料與欄位偏移、物件與元件內省、Transform 與 Camera 擷取、世界座標到螢幕座標投影，以及 DumpSDK 匯出 dump.cs 風格產物。此函式庫適用於學術研究、經授權的模組與外掛開發，以及 Unity 遊戲內部機制的逆向工程研究。
