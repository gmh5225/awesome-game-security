er2는 심볼 테이블, RTTI, 파일 시스템 읽기 또는 코드 인젝션에 의존하지 않고, 크로스 프로세스 읽기 전용 메모리 접근을 사용하여 실행 중인 프로세스에서 Unity 엔진 런타임 데이터 구조를 재구성하는 헤더 전용 C++17 프레임워크입니다. Windows x64의 Unity 2020부터 2023을 대상으로 하며 Mono 및 IL2CPP 백엔드를 자동으로 감지합니다. 핵심 기능에는 GameObjectManager 및 인스턴스 ID 레지스트리의 블라인드 탐색, IL2CPP 메타데이터 및 필드 오프셋의 원격 재구성, 객체 및 컴포넌트 인트로스펙션, Transform 및 Camera 추출, 월드-투-스크린 투영, dump.cs 스타일 아티팩트의 DumpSDK 내보내기가 포함됩니다. 이 라이브러리는 학술 연구, 허가된 모딩 및 플러그인 개발, Unity 게임 내부에 대한 리버스 엔지니어링 연구를 위해 설계되었습니다.
