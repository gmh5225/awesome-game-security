er2 は、ヘッダーのみの C++17 フレームワークで、シンボルテーブル、RTTI、ファイルシステム読み取り、コードインジェクションに依存せず、クロスプロセスの読み取り専用メモリアクセスを用いて、実行中プロセスから Unity エンジンのランタイムデータ構造を再構築します。Windows x64 上の Unity 2020 から 2023 を対象とし、Mono および IL2CPP バックエンドを自動検出します。主な機能には、GameObjectManager とインスタンス ID レジストリのブラインド検出、IL2CPP メタデータとフィールドオフセットのリモート再構築、オブジェクトおよびコンポーネントのイントロスペクション、Transform と Camera の抽出、ワールド座標からスクリーン座標への投影、dump.cs 形式のアーティファクトを DumpSDK でエクスポートすることが含まれます。このライブラリは、学術研究、許可された mod およびプラグイン開発、Unity ゲーム内部のリバースエンジニアリング研究向けに設計されています。
