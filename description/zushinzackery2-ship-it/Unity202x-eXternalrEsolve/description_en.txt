er2 is a header-only C++17 framework that reconstructs Unity engine runtime data structures from a live process using cross-process read-only memory access, without relying on symbol tables, RTTI, filesystem reads, or code injection. It targets Unity 2020 through 2023 on Windows x64 and automatically detects Mono and IL2CPP backends. Core capabilities include blind discovery of the GameObjectManager and instance ID registries, remote rebuilding of IL2CPP metadata and field offsets, object and component introspection, transform and camera extraction, world-to-screen projection, and DumpSDK export of dump.cs-style artifacts. The library is designed for academic research, authorized modding and plugin development, and reverse engineering study of Unity game internals.
