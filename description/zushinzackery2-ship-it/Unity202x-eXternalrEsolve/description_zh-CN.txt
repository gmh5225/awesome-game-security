er2 是一个仅头文件的 C++17 框架，通过跨进程只读内存访问从实时进程中重建 Unity 引擎运行时数据结构，无需依赖符号表、RTTI、文件系统读取或代码注入。它面向 Windows x64 上的 Unity 2020 至 2023 版本，可自动检测 Mono 与 IL2CPP 后端。核心功能包括盲发现 GameObjectManager 与实例 ID 注册表、远程重建 IL2CPP 元数据与字段偏移、对象与组件内省、Transform 与 Camera 提取、世界坐标到屏幕坐标投影，以及 DumpSDK 导出 dump.cs 风格产物。该库适用于学术研究、经授权的模组与插件开发，以及 Unity 游戏内部机制的逆向工程研究。
