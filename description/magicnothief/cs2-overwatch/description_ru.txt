Это автономная, щадящая к CPU система проверки читов для Counter-Strike 2, которая анализирует demo-файлы и ранжирует подозрительные игровые моменты с калиброванными оценками подозрительности и текстовыми пояснениями. Написана на Python и прогоняет демо через многослойный конвейер: жёсткие правила для явных читов, геометрический анализ видимости, ML-оценщик поведения, обученный на наборе данных CS2CD, и опциональный дообученный LLM-судья для понятных человеку вердиктов. Проект включает веб-интерфейс в браузере, CLI-инструменты, разбор демо и опциональные визуальные перекрёстные проверки YOLO; вывод выполняют модели ONNX и llama.cpp. Он предназначен для исследователей античита, разработчиков игровой безопасности и тех, кто изучает обнаружение читов по демо без отправки данных за пределы локальной машины.
