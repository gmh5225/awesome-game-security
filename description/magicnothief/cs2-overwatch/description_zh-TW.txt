這是一個面向 Counter-Strike 2 的離線、CPU 友善型作弊審查系統，可分析 demo 檔案，並為可疑的遊戲時刻提供經過校準的可疑度評分與文字說明。專案以 Python 撰寫，透過多層管線處理 demo：針對明顯作弊的硬性規則檢查、基於幾何的可見性分析、在 CS2CD 資料集上訓練的行為機器學習評分器，以及可選的微調 LLM 裁判以產生人類可讀的結論。專案包含基於瀏覽器的 Web UI、CLI 工具、demo 解析，以及可選的 YOLO 視覺交叉驗證，推理由 ONNX 模型與 llama.cpp 驅動。它面向反作弊研究人員、遊戲安全開發者，以及希望探索基於 demo 的作弊偵測、且無需將資料傳出本機的學習者。
