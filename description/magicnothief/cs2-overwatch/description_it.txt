È un sistema offline e a basso impatto sulla CPU per la revisione dei cheat in Counter-Strike 2 che analizza i file demo e classifica i momenti di gioco sospetti con punteggi di sospetto calibrati e spiegazioni scritte. Scritto in Python, elabora le demo attraverso una pipeline multilivello: controlli rigidi per cheat evidenti, analisi della visibilità basata sulla geometria, uno scorer comportamentale di machine learning addestrato sul dataset CS2CD e un giudice LLM opzionale fine-tuned per verdetto leggibile dall'uomo. Il progetto include una Web UI basata su browser, strumenti CLI, parsing delle demo e cross-check visivi opzionali con YOLO, con inferenza alimentata da modelli ONNX e llama.cpp. È rivolto a ricercatori anti-cheat, sviluppatori di sicurezza dei giochi e studenti che esplorano il rilevamento dei cheat basato sulle demo senza inviare dati al di fuori della macchina locale.
