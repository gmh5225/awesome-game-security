Counter-Strike 2 向けのオフラインかつ CPU 負荷の低いチートレビューシステムで、デモファイルを解析し、疑わしいプレイの場面を校正済みの疑わしさスコアと説明文付きでランク付けします。Python で実装され、デモを多層パイプラインで処理します。露骨なチート向けのハードルールチェック、幾何学ベースの視認性解析、CS2CD データセットで学習した機械学習の行動スコアラー、そして人間が読める判定を出す任意のファインチューニング済み LLM ジャッジです。プロジェクトにはブラウザベースの Web UI、CLI ツール、デモ解析、任意の YOLO ビジョンクロスチェックが含まれ、推論は ONNX モデルと llama.cpp によって駆動されます。反チート研究者、ゲームセキュリティ開発者、デモベースのチート検出を学びつつデータをローカルマシン外に送らずに試したい学習者を対象としています。
