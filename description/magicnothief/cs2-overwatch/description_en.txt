This is an offline, CPU-friendly cheat review system for Counter-Strike 2 that analyzes demo files and ranks suspicious gameplay moments with calibrated suspicion scores and written explanations. Written in Python, it runs demos through a multi-layer pipeline: hard rule checks for blatant cheats, geometry-based visibility analysis, a machine learning behavior scorer trained on the CS2CD dataset, and an optional fine-tuned LLM judge for human-readable verdicts. The project includes a browser-based web UI, CLI tooling, demo parsing, and optional YOLO vision cross-checks, with inference powered by ONNX models and llama.cpp. It is aimed at anti-cheat researchers, game security developers, and learners exploring demo-based cheat detection without sending data off the local machine.
