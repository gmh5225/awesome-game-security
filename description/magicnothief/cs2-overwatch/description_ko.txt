Counter-Strike 2용 오프라인·CPU 친화적 치트 검토 시스템으로, 데모 파일을 분석하고 의심스러운 플레이 순간을 보정된 의심 점수와 설명과 함께 순위화합니다. Python으로 작성되었으며, 데모를 다층 파이프라인으로 처리합니다. 노골적인 치트를 위한 하드 룰 검사, 기하학 기반 가시성 분석, CS2CD 데이터셋으로 학습한 머신러닝 행동 점수기, 사람이 읽을 수 있는 판정을 위한 선택적 파인튜닝 LLM 심판이 포함됩니다. 프로젝트에는 브라우저 기반 Web UI, CLI 도구, 데모 파싱, 선택적 YOLO 비전 교차 검증이 포함되며, 추론은 ONNX 모델과 llama.cpp로 구동됩니다. 반치트 연구자, 게임 보안 개발자, 데이터를 로컬 머신 밖으로 보내지 않고 데모 기반 치트 탐지를 탐구하려는 학습자를 대상으로 합니다.
