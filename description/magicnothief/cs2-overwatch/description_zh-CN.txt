这是一个面向 Counter-Strike 2 的离线、CPU 友好型作弊审查系统，可分析 demo 文件，并为可疑的游戏时刻给出经过校准的可疑度评分和文字说明。项目使用 Python 编写，通过多层流水线处理 demo：针对明显作弊的硬性规则检查、基于几何的可见性分析、在 CS2CD 数据集上训练的行为机器学习评分器，以及可选的微调 LLM 裁判以生成人类可读的结论。项目包含基于浏览器的 Web UI、CLI 工具、demo 解析，以及可选的 YOLO 视觉交叉验证，推理由 ONNX 模型和 llama.cpp 驱动。它面向反作弊研究人员、游戏安全开发者和希望探索基于 demo 的作弊检测、且无需将数据发送到本地机器之外的学习者。
