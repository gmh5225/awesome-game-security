EarlyBuffer は Geometry Dash 2.2081 向けの Geode モッドで、タイミング支援を提供します。ジャンプをわずかに早めに押した場合、入力を保持し、内部のシャドウシミュレーションが依然として安全とみなす最初の物理 tick で離します。手動プレイやオートプレイによるクリアを置き換えるものではありません。C++23 と CMake で実装され、Geode 経由でゲームにフックし、trigger-world baking を備えたプランナー、バッファ状態機、オプションのレベル別学習、GDR リプレイのインポート、パフォーマンストレースや開発評価ラボなどのデバッグツールを含みます。ビルドは Windows を主プラットフォームとし、標準的な Geode モジュールとして Windows、macOS、iOS、Android のバイナリをパッケージできます。クライアント側アシスト設計、決定論的入力検証、ゲームセキュリティやアンチチート研究に関連する商用リズムゲームにおける mod フックの研究に有用です。
