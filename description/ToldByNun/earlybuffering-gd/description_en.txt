EarlyBuffer is a Geode mod for Geometry Dash 2.2081 that provides a timing assist: when you press jump slightly early, it holds the input and releases on the first physics tick that an internal shadow simulation still treats as safe, without replacing manual play or autoplaying levels. It is implemented in C++23 with CMake, hooks into the game via Geode, and includes a planner with trigger-world baking, a buffer state machine, optional per-level learning, GDR replay import, and debug tooling such as performance traces and a dev evaluation lab. Builds target Windows as the primary platform and can package Windows, macOS, iOS, and Android binaries as standard Geode modules. The project is useful for studying client-side assist design, deterministic input validation, and mod hooking in a commercial rhythm game context relevant to game security and anti-cheat research.
