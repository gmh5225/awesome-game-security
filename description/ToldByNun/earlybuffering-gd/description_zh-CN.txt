EarlyBuffer 是一款面向 Geometry Dash 2.2081 的 Geode 模组，提供时机辅助：当你略早按下跳跃时，它会保持输入，并在内部影子模拟仍判定为安全的首个物理 tick 上释放，而不会取代手动游玩或自动通关。项目使用 C++23 与 CMake 实现，通过 Geode 挂钩游戏，并包含带 trigger-world baking 的规划器、缓冲状态机、可选的逐关卡学习、GDR 回放导入，以及性能追踪与开发评估实验室等调试工具。构建以 Windows 为主平台，可按标准 Geode 模块打包 Windows、macOS、iOS 与 Android 二进制。该项目适合研究客户端辅助设计、确定性输入校验，以及与游戏安全及反作弊研究相关的商业节奏游戏模组挂钩。
