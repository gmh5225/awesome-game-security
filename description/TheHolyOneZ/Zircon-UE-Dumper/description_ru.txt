Zircon — это набор инструментов для извлечения и анализа reflection Unreal Engine, который восстанавливает полную систему типов игры из работающего процесса, дампа памяти или бинарного файла на диске. Написан на C++20 для Windows, автоматически определяет версии движка от UE 4.22 до 5.7 и выводит смещения layout без жёстко заданных таблиц версий, затем выдаёт результаты в виде C++ SDK, USMAP-сопоставлений, импорта типов для IDA/Ghidra/Binary Ninja, JavaScript-привязок Frida, Python-заглушек, проектов ReClass и других форматов из общего промежуточного представления. Поддерживает внутреннюю инъекцию, внешнее подключение только для чтения, офлайн-анализ minidump и статическое сканирование PE через единую абстракцию памяти, а также включает GUI-браузер для просмотра объектов в реальном времени, редактирования свойств и декомпиляции скриптов Blueprint. Инструмент предназначен для reverse engineers, разработчиков модов и исследователей безопасности игр, которым нужны точные данные reflection, сравнение между сборками и многоинструментальные конвейеры экспорта для проектов Unreal Engine.
