Zircon is an Unreal Engine reflection extraction and analysis toolkit that reconstructs a game's full type system from a live process, memory dump, or on-disk binary. Written in C++20 for Windows, it auto-detects engine versions from UE 4.22 through 5.7 and derives layout offsets without hardcoded version tables, then emits the results as a C++ SDK, USMAP mappings, IDA/Ghidra/Binary Ninja type imports, Frida JavaScript bindings, Python stubs, ReClass projects, and other formats from a shared intermediate representation. It supports internal injection, external read-only attachment, offline minidump analysis, and static PE scanning through a unified memory abstraction, and includes a GUI browser for live object inspection, property editing, and Blueprint script decompilation. The tool is aimed at reverse engineers, mod developers, and game security researchers who need accurate reflection data, cross-build diffing, and multi-tool export pipelines for Unreal Engine titles.
