Zircon 是一款 Unreal Engine 反射提取与分析工具包，可从运行中的进程、内存转储或磁盘二进制文件重建游戏的完整类型系统。该工具使用 C++20 编写，面向 Windows，可自动检测 UE 4.22 至 5.7 的引擎版本，无需硬编码版本表即可推导布局偏移，并以 C++ SDK、USMAP 映射、IDA/Ghidra/Binary Ninja 类型导入、Frida JavaScript 绑定、Python 存根、ReClass 项目及其他格式输出结果，均来自统一的中间表示。它通过统一的内存抽象支持内部注入、外部只读附加、离线 minidump 分析和静态 PE 扫描，并包含用于实时对象检查、属性编辑和 Blueprint 脚本反编译的 GUI 浏览器。该工具面向需要准确反射数据、跨构建差异对比以及多工具导出流程的逆向工程师、模组开发者和游戏安全研究人员。
