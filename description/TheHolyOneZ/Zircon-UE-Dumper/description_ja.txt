Zircon は、実行中のプロセス、メモリダンプ、またはディスク上のバイナリからゲームの完全な型システムを再構築する Unreal Engine 向けのリフレクション抽出・分析ツールキットです。C++20 で Windows 向けに書かれており、UE 4.22 から 5.7 までのエンジンバージョンを自動検出し、ハードコードされたバージョンテーブルなしでレイアウトオフセットを導出し、共有中間表現から C++ SDK、USMAP マッピング、IDA/Ghidra/Binary Ninja 型インポート、Frida JavaScript バインディング、Python スタブ、ReClass プロジェクトなどの形式で結果を出力します。統一されたメモリ抽象化により、内部インジェクション、外部読み取り専用アタッチ、オフライン minidump 分析、静的 PE スキャンをサポートし、ライブオブジェクト検査、プロパティ編集、Blueprint スクリプトの逆コンパイル用 GUI ブラウザも含まれます。正確なリフレクションデータ、ビルド間差分、Unreal Engine タイトル向けのマルチツールエクスポートパイプラインを必要とするリバースエンジニア、MOD 開発者、ゲームセキュリティ研究者を対象としています。
