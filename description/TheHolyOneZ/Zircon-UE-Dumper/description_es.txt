Zircon es un kit de herramientas de extracción y análisis de reflexión para Unreal Engine que reconstruye el sistema de tipos completo de un juego a partir de un proceso en ejecución, un volcado de memoria o un binario en disco. Escrito en C++20 para Windows, detecta automáticamente versiones del motor desde UE 4.22 hasta 5.7 y deriva offsets de diseño sin tablas de versión codificadas, y emite los resultados como SDK de C++, mapeos USMAP, importaciones de tipos para IDA/Ghidra/Binary Ninja, bindings de JavaScript para Frida, stubs de Python, proyectos ReClass y otros formatos a partir de una representación intermedia compartida. Admite inyección interna, adjunción externa de solo lectura, análisis offline de minidumps y escaneo estático de PE mediante una abstracción de memoria unificada, e incluye un navegador GUI para inspección de objetos en vivo, edición de propiedades y descompilación de scripts Blueprint. La herramienta está dirigida a ingenieros de ingeniería inversa, desarrolladores de mods e investigadores de seguridad de juegos que necesitan datos de reflexión precisos, comparación entre builds y pipelines de exportación multi-herramienta para títulos de Unreal Engine.
