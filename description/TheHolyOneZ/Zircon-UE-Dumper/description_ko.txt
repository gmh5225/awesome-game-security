Zircon은 실행 중인 프로세스, 메모리 덤프 또는 디스크 바이너리에서 게임의 전체 타입 시스템을 재구성하는 Unreal Engine 리플렉션 추출 및 분석 툴킷입니다. C++20으로 Windows용으로 작성되었으며, UE 4.22부터 5.7까지의 엔진 버전을 자동 감지하고 하드코딩된 버전 테이블 없이 레이아웃 오프셋을 도출한 뒤, 공유 중간 표현에서 C++ SDK, USMAP 매핑, IDA/Ghidra/Binary Ninja 타입 가져오기, Frida JavaScript 바인딩, Python 스텁, ReClass 프로젝트 등 다양한 형식으로 결과를 출력합니다. 통합 메모리 추상화를 통해 내부 인젝션, 외부 읽기 전용 연결, 오프라인 minidump 분석, 정적 PE 스캔을 지원하며, 라이브 객체 검사, 속성 편집, Blueprint 스크립트 디컴파일을 위한 GUI 브라우저도 포함합니다. 정확한 리플렉션 데이터, 빌드 간 차이 비교, Unreal Engine 타이틀용 다중 도구 내보내기 파이프라인이 필요한 리버스 엔지니어, 모드 개발자, 게임 보안 연구자를 대상으로 합니다.
