Zircon 是一款 Unreal Engine 反射提取與分析工具包，可從執行中的程序、記憶體傾印或磁碟二進位檔重建遊戲的完整型別系統。該工具以 C++20 撰寫，面向 Windows，可自動偵測 UE 4.22 至 5.7 的引擎版本，無需硬編碼版本表即可推導配置偏移，並以 C++ SDK、USMAP 對應、IDA/Ghidra/Binary Ninja 型別匯入、Frida JavaScript 繫結、Python 存根、ReClass 專案及其他格式輸出結果，均來自共用的中間表示。它透過統一的記憶體抽象支援內部注入、外部唯讀附加、離線 minidump 分析與靜態 PE 掃描，並包含用於即時物件檢查、屬性編輯與 Blueprint 指令碼反編譯的 GUI 瀏覽器。該工具面向需要準確反射資料、跨建置差異比對以及多工具匯出流程的逆向工程師、模組開發者與遊戲安全研究人員。
