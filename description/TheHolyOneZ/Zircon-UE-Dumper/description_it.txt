Zircon è un toolkit per l'estrazione e l'analisi della reflection di Unreal Engine che ricostruisce l'intero sistema di tipi di un gioco da un processo attivo, un dump di memoria o un binario su disco. Scritto in C++20 per Windows, rileva automaticamente le versioni del motore da UE 4.22 a 5.7 e deriva gli offset di layout senza tabelle di versione hardcoded, quindi emette i risultati come SDK C++, mapping USMAP, import di tipi per IDA/Ghidra/Binary Ninja, binding JavaScript Frida, stub Python, progetti ReClass e altri formati da una rappresentazione intermedia condivisa. Supporta iniezione interna, collegamento esterno in sola lettura, analisi offline di minidump e scansione statica PE tramite un'astrazione di memoria unificata, e include un browser GUI per l'ispezione di oggetti live, la modifica delle proprietà e la decompilazione di script Blueprint. Lo strumento è rivolto a reverse engineer, sviluppatori di mod e ricercatori di sicurezza dei giochi che necessitano di dati di reflection accurati, confronti tra build e pipeline di export multi-tool per titoli Unreal Engine.
