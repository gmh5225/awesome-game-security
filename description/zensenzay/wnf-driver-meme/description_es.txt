Un controlador de kernel de Windows emparejado con un cliente en modo usuario que intercambia comandos mediante nombres de estado de Windows Notification Facility (WNF) en lugar de rutas de dispositivo convencionales o códigos IOCTL. El controlador admite acceso de lectura y escritura a nivel de kernel a la memoria de procesos arbitrarios por PID, y puede proteger procesos seleccionados registrando hooks ObRegisterCallbacks que eliminan derechos sensibles de handles como lectura/escritura VM, duplicación y suspensión/reanudación. La comunicación se publica mediante claves de registro bajo WnfNotify para que el cliente descubra el canal sin abrir un dispositivo de controlador visible. Escrito en C para los componentes de kernel y en C++ para el cliente, está destinado a investigación de seguridad en juegos, análisis anti-cheat e ingeniería inversa en escenarios donde se exploran la comunicación sigilosa entre privilegios y el endurecimiento de procesos.
