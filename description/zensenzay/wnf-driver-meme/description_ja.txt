Windows カーネルドライバとユーザーモードクライアントのペアで、従来のデバイスパスや IOCTL コードの代わりに Windows Notification Facility (WNF) の状態名を介してコマンドをやり取りします。このドライバは PID 指定で任意のプロセスメモリへのカーネルレベルの読み書きをサポートし、ObRegisterCallbacks フックを登録して選択したプロセスを保護し、VM 読み書き、複製、サスペンド/レジュームなどの機密ハンドル権限を剥奪できます。通信は WnfNotify 配下のレジストリキー経由で公開され、クライアントは可視的なドライバデバイスを開かずにチャネルを発見できます。カーネルコンポーネントは C、クライアントは C++ で記述されており、ステルスな権限横断通信とプロセス強化を探求するゲームセキュリティ研究、アンチチート分析、リバースエンジニアリングのシナリオを想定しています。
