Windows 커널 드라이버와 사용자 모드 클라이언트가 쌍을 이루며, 기존 장치 경로나 IOCTL 코드 대신 Windows Notification Facility (WNF) 상태 이름을 통해 명령을 주고받습니다. 이 드라이버는 PID로 임의 프로세스 메모리에 대한 커널 수준 읽기/쓰기를 지원하며, ObRegisterCallbacks 후크를 등록하여 선택한 프로세스를 보호하고 VM 읽기/쓰기, 복제, 일시 중지/재개 등 민감한 핸들 권한을 제거할 수 있습니다. 통신은 WnfNotify 아래 레지스트리 키를 통해 공개되므로 클라이언트는 눈에 띄는 드라이버 장치를 열지 않고도 채널을 찾을 수 있습니다. 커널 구성 요소는 C, 클라이언트는 C++로 작성되었으며, 은밀한 권한 간 통신과 프로세스 강화를 탐구하는 게임 보안 연구, 안티치트 분석, 리버스 엔지니어링 시나리오를 위한 것입니다.
