Драйвер ядра Windows в паре с клиентом пользовательского режима, обменивающий команды через имена состояний Windows Notification Facility (WNF) вместо обычных путей устройств или кодов IOCTL. Драйвер поддерживает чтение и запись памяти произвольных процессов на уровне ядра по PID и может защищать выбранные процессы, регистрируя хуки ObRegisterCallbacks, которые лишают чувствительных прав дескрипторов, таких как чтение/запись VM, дублирование и приостановка/возобновление. Связь публикуется через ключи реестра в WnfNotify, чтобы клиент мог обнаружить канал без открытия видимого устройства драйвера. Написан на C для компонентов ядра и на C++ для клиента; предназначен для исследований безопасности игр, анализа античитов и сценариев реверс-инжиниринга, где изучаются скрытая межпривилегированная связь и усиление защиты процессов.
