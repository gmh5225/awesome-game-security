A Windows kernel driver paired with a usermode client that exchanges commands through Windows Notification Facility (WNF) state names instead of conventional device paths or IOCTL codes. The driver supports kernel-level read and write access to arbitrary process memory by PID, and can protect selected processes by registering ObRegisterCallbacks hooks that strip sensitive handle rights such as VM read/write, duplicate, and suspend/resume. Communication is published via registry keys under WnfNotify so the client can discover the channel without opening a visible driver device. Written in C for the kernel components and C++ for the client, it is intended for game security research, anti-cheat analysis, and reverse engineering scenarios where stealthy cross-privilege communication and process hardening are explored.
