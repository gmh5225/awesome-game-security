MemFilter は、保護されたプロセス向けにステルス機能とメモリアクセス機能を提供する Windows カーネル minifilter ドライバとユーザーモードクライアントで構成されます。ドライバは主に C、クライアントは C++ で記述されており、Filter Manager フレームワークを用いてディレクトリ照会バッファのスクラブによるファイルおよびディレクトリの隠蔽、Configuration Manager コールバックによるレジストリキーの隠蔽、Object Manager コールバックによる保護プロセスへのハンドルからの仮想メモリ読み書きアクセスの剥奪を行います。また MDL マッピングによるプロセス間メモリ読み書きをサポートし、従来のデバイスオブジェクトや IOCTL インターフェースではなく Filter Manager ポート経由でユーザーモードと通信します。このプロジェクトはゲームセキュリティ研究、チート対策回避、カーネルレベルのリバースエンジニアリング向けであり、実行中のゲームプロセスのメモリ検査を対象としたデモコードを含みます。
