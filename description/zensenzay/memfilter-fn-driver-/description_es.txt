MemFilter es un controlador minifilter del kernel de Windows con un cliente en modo usuario que proporciona capacidades de sigilo y acceso a memoria para procesos protegidos. Escrito principalmente en C para el controlador y en C++ para el cliente, utiliza el framework Filter Manager para ocultar archivos y directorios limpiando los búferes de consulta de directorio, callbacks de Configuration Manager para ocultar claves del registro y callbacks de Object Manager para eliminar el acceso de lectura y escritura a memoria virtual de los handles hacia procesos protegidos. También admite lectura y escritura de memoria entre procesos mediante mapeo MDL y se comunica con el modo usuario a través de un puerto de Filter Manager en lugar de un objeto de dispositivo convencional o una interfaz IOCTL. El proyecto está orientado a la investigación en seguridad de juegos, la evasión de anti-cheat y escenarios de ingeniería inversa a nivel de kernel, con código de demostración dirigido a la inspección de memoria de procesos de juego en ejecución.
