MemFilter는 보호된 프로세스에 대한 은신 및 메모리 접근 기능을 제공하는 Windows 커널 minifilter 드라이버와 사용자 모드 클라이언트입니다. 드라이버는 주로 C로, 클라이언트는 C++로 작성되었으며, Filter Manager 프레임워크를 사용해 디렉터리 쿼리 버퍼를 스크럽하여 파일 및 디렉터리를 숨기고, Configuration Manager 콜백으로 레지스트리 키를 숨기며, Object Manager 콜백으로 보호된 프로세스에 대한 핸들에서 가상 메모리 읽기/쓰기 접근을 제거합니다. 또한 MDL 매핑을 통한 프로세스 간 메모리 읽기/쓰기를 지원하며, 기존의 장치 객체나 IOCTL 인터페이스 대신 Filter Manager 포트를 통해 사용자 모드와 통신합니다. 이 프로젝트는 게임 보안 연구, 안티치트 우회, 커널 수준 리버스 엔지니어링 시나리오를 목표로 하며, 실행 중인 게임 프로세스의 메모리 검사를 대상으로 하는 데모 코드를 포함합니다.
