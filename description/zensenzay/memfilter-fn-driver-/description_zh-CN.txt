MemFilter 是一个 Windows 内核 minifilter 驱动程序，配有用户模式客户端，可为受保护进程提供隐蔽与内存访问能力。驱动主要用 C 编写，客户端用 C++ 编写；它利用 Filter Manager 框架通过 scrub 目录查询缓冲区来隐藏文件和目录，使用 Configuration Manager 回调隐藏注册表项，并使用 Object Manager 回调从受保护进程的句柄中剥离虚拟内存读写访问权限。它还支持通过 MDL 映射进行跨进程内存读写，并通过 Filter Manager 端口而非传统设备对象或 IOCTL 接口与用户模式通信。该项目面向游戏安全研究、反作弊规避和内核级逆向工程场景，包含针对运行中游戏进程内存检查的演示代码。
