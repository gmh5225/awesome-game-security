MemFilter — это minifilter-драйвер ядра Windows с клиентом в пользовательском режиме, обеспечивающий скрытность и доступ к памяти для защищённых процессов. Драйвер написан преимущественно на C, клиент — на C++; он использует фреймворк Filter Manager для сокрытия файлов и каталогов путём очистки буферов запросов каталогов, обратные вызовы Configuration Manager для сокрытия ключей реестра и обратные вызовы Object Manager для лишения дескрипторов доступа на чтение и запись виртуальной памяти к защищённым процессам. Также поддерживается межпроцессное чтение и запись памяти через MDL-отображение, а связь с пользовательским режимом осуществляется через порт Filter Manager, а не через обычный объект устройства или интерфейс IOCTL. Проект ориентирован на исследования безопасности игр, обход античитов и сценарии реверс-инжиниринга на уровне ядра, с демонстрационным кодом для инспекции памяти работающих игровых процессов.
