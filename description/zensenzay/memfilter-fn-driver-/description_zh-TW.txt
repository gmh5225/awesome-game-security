MemFilter 是一款 Windows 核心 minifilter 驅動程式，附帶使用者模式用戶端，可為受保護程序提供隱蔽與記憶體存取能力。驅動程式主要以 C 撰寫，用戶端以 C++ 撰寫；它運用 Filter Manager 框架，透過 scrub 目錄查詢緩衝區來隱藏檔案與目錄，使用 Configuration Manager 回呼隱藏登錄機碼，並以 Object Manager 回呼從受保護程序的控制代碼中移除虛擬記憶體讀寫存取權限。它亦支援透過 MDL 對映進行跨程序記憶體讀寫，並以 Filter Manager 連接埠而非傳統裝置物件或 IOCTL 介面與使用者模式通訊。此專案鎖定遊戲安全研究、反作弊規避與核心層級逆向工程情境，並提供針對執行中遊戲程序記憶體檢查的示範程式碼。
