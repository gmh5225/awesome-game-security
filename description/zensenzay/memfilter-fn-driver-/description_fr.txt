MemFilter est un pilote minifilter du noyau Windows associé à un client en mode utilisateur, qui fournit des capacités de furtivité et d'accès mémoire pour les processus protégés. Écrit principalement en C pour le pilote et en C++ pour le client, il s'appuie sur le framework Filter Manager pour masquer fichiers et répertoires en nettoyant les tampons de requête de répertoire, sur des callbacks Configuration Manager pour masquer les clés de registre, et sur des callbacks Object Manager pour retirer les accès en lecture et écriture à la mémoire virtuelle des handles vers les processus protégés. Il prend également en charge la lecture et l'écriture mémoire interprocessus via le mappage MDL et communique avec le mode utilisateur par un port Filter Manager plutôt qu'un objet périphérique classique ou une interface IOCTL. Le projet vise la recherche en sécurité des jeux, le contournement des anti-triches et l'ingénierie inverse au niveau noyau, avec du code de démonstration ciblant l'inspection de la mémoire de processus de jeu en cours d'exécution.
