MemFilter is a Windows kernel minifilter driver with a user-mode client that provides stealth and memory access capabilities for protected processes. Written primarily in C for the driver and C++ for the client, it uses the Filter Manager framework for file and directory hiding by scrubbing directory query buffers, Configuration Manager callbacks to hide registry keys, and Object Manager callbacks to strip virtual-memory read and write access from handles to protected processes. It also supports cross-process memory read and write through MDL mapping and communicates with user mode over a Filter Manager port rather than a conventional device object or IOCTL interface. The project is aimed at game security research, anti-cheat evasion, and kernel-level reverse engineering scenarios, with demo code that targets live game process memory inspection.
