MemFilter è un driver minifilter del kernel Windows con un client in modalità utente che fornisce capacità di occultamento e accesso alla memoria per processi protetti. Scritto principalmente in C per il driver e in C++ per il client, utilizza il framework Filter Manager per nascondere file e directory ripulendo i buffer di query delle directory, callback del Configuration Manager per nascondere chiavi di registro e callback dell'Object Manager per rimuovere l'accesso in lettura e scrittura alla memoria virtuale dagli handle verso processi protetti. Supporta anche lettura e scrittura della memoria tra processi tramite mappatura MDL e comunica con la modalità utente tramite una porta Filter Manager anziché un oggetto dispositivo convenzionale o un'interfaccia IOCTL. Il progetto è rivolto alla ricerca sulla sicurezza dei giochi, all'evasione degli anti-cheat e a scenari di reverse engineering a livello kernel, con codice dimostrativo finalizzato all'ispezione della memoria di processi di gioco in esecuzione.
