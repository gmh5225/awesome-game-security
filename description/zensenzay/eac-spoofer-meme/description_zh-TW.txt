這是一款面向 Windows 的硬體與系統識別碼欺騙工具，旨在繞過 Easy Anti-Cheat 及類似遊戲反作弊系統的硬體指紋檢測。專案將 C 語言編寫的核心模式驅動程式與使用者模式 C++ 控制器結合，透過自訂 IOCTL 通訊，可改寫 SMBIOS 資料、磁碟與 NVMe 序號、網路 MAC 位址、GPU 與 PCI 識別碼、CPUID 值、EFI 變數、ACPI 表以及大量 Windows 登錄檔機器 ID。進階技術包括磁碟 I/O 完成例程掛鉤、用於透明 PCI 與 USB 別名重導向的登錄檔通知回呼、用於攔截 CPUID 查詢的 VT-x 與 AMD SVM 迷你虛擬機器監控程式，以及可選的殘留清理與行程記憶體注入原語。此專案可作為遊戲安全研究人員與逆向工程師的參考資料，用於研究反作弊系統如何採集硬體指紋，以及核心層級欺騙如何規避這些檢測。
