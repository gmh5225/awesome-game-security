这是一款面向 Windows 的硬件与系统标识符欺骗工具，旨在绕过 Easy Anti-Cheat 及类似游戏反作弊系统的硬件指纹检测。项目将 C 语言编写的内核模式驱动与用户模式 C++ 控制器相结合，通过自定义 IOCTL 通信，可改写 SMBIOS 数据、磁盘与 NVMe 序列号、网络 MAC 地址、GPU 与 PCI 标识符、CPUID 值、EFI 变量、ACPI 表以及大量 Windows 注册表机器 ID。高级技术包括磁盘 I/O 完成例程挂钩、用于透明 PCI 与 USB 别名重定向的注册表通知回调、用于拦截 CPUID 查询的 VT-x 与 AMD SVM 迷你虚拟机监控程序，以及可选的残留清理与进程内存注入原语。该项目可作为游戏安全研究人员与逆向工程师的参考资料，用于研究反作弊系统如何采集硬件指纹，以及内核级欺骗如何规避这些检测。
