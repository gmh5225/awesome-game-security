これは Easy Anti-Cheat や類似のゲームアンチチートによるハードウェア指紋検出を回避することを目的とした、Windows 向けのハードウェアおよびシステム識別子スプーファーです。C で記述されたカーネルモードドライバと、カスタム IOCTL 経由で通信するユーザーモード C++ コントローラを組み合わせ、SMBIOS データ、ディスクおよび NVMe シリアル、ネットワーク MAC アドレス、GPU および PCI 識別子、CPUID 値、EFI 変数、ACPI テーブル、多数の Windows レジストリマシン ID を書き換えます。高度な手法として、ディスク I/O 完了フック、透明な PCI および USB エイリアスリダイレクト用のレジストリ通知コールバック、CPUID クエリを傍受する VT-x および AMD SVM ミニハイパーバイザ、任意のアーティファクトクリーンアップとプロセスメモリ注入プリミティブが含まれます。本プロジェクトは、アンチチートがハードウェア指紋を収集する仕組みと、カーネルレベルのスプーフィングがそれらのチェックを回避する方法を研究する、ゲームセキュリティ研究者およびリバースエンジニア向けの参考資料として機能します。
