Se trata de un spoofer de identificadores de hardware y sistema para Windows orientado a eludir Easy Anti-Cheat y el fingerprinting similar de anti-cheats de juegos. Combina un controlador en modo kernel escrito en C con un controlador C++ en modo usuario que se comunica mediante IOCTL personalizados para reescribir datos SMBIOS, números de serie de discos y NVMe, direcciones MAC de red, identificadores de GPU y PCI, valores CPUID, variables EFI, tablas ACPI y numerosos ID de máquina del registro de Windows. Las técnicas avanzadas incluyen hooking de finalización de E/S de disco, callbacks de notificación del registro para redirección transparente de alias PCI y USB, mini-hipervisores VT-x y AMD SVM para interceptar consultas CPUID, y limpieza opcional de artefactos más primitivas de inyección en memoria de procesos. El proyecto sirve como referencia para investigadores de seguridad en juegos e ingenieros inversos que estudian cómo los anti-cheats recopilan huellas de hardware y cómo el spoofing a nivel de kernel puede evadir esas comprobaciones.
