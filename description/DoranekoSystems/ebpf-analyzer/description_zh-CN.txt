eBPF Analyzer 是一款实验性的 PacketProxy 扩展，在已 root 的 Android x86_64 设备上利用 Linux eBPF 观察网络活动，无需运行代理或修改系统代理设置。基于 Go 的主机端监控程序驱动由 cilium/ebpf 构建的设备端采集器，Java 插件在 PacketProxy 中展示捕获的 TCP 连接、报文副本以及与系统调用相关的 I/O 事件，便于检查并将流量归因到已安装的应用包。可选的 Frida 集成通过配套脚本与 eBPF 辅助功能，为选定进程附加原生与 Java 堆栈跟踪。该方案面向需要在 TLS 载荷仍于线路上保持加密的同时，将实时流量与调用点对齐的移动安全研究人员、逆向工程师与分析人员。开发工作侧重受控模拟器测试，而非面向生产的部署。
