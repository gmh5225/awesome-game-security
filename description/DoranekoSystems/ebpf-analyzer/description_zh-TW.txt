eBPF Analyzer 是一款實驗性的 PacketProxy 擴充功能，在已 root 的 Android x86_64 裝置上利用 Linux eBPF 觀察網路活動，無需執行代理或變更裝置代理設定。以 Go 為基礎的主機端監控程式驅動由 cilium/ebpf 建置的裝置端收集器，Java 外掛在 PacketProxy 中呈現擷取的 TCP 連線、封包副本以及與系統呼叫相關的 I/O 事件，便於檢視並將流量歸因至已安裝的應用套件。可選的 Frida 整合透過配套腳本與 eBPF 輔助功能，為選定程序附加原生與 Java 堆疊追蹤。此方案適合需要在 TLS 承載仍於線路上保持加密時，將即時流量與呼叫點對應的行動安全研究人員、逆向工程師與分析人員。開發工作著重受控模擬器測試，而非面向正式環境的部署。
