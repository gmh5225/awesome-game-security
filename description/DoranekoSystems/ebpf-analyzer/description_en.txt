eBPF Analyzer is an experimental PacketProxy extension that uses Linux eBPF on rooted Android x86_64 devices to observe network activity without running a proxy or changing device proxy settings. A Go-based host monitor drives an on-device collector built with cilium/ebpf, while a Java plugin presents captured TCP connections, packet copies, and syscall-related I/O events in PacketProxy for inspection and attribution to installed packages. Optional Frida integration adds native and Java stack traces for selected processes via companion scripts and eBPF helpers. The stack suits mobile security researchers, reverse engineers, and analysts who need to correlate live traffic with call sites while TLS payloads stay encrypted on the wire. Development has focused on controlled emulator testing rather than production-ready deployment.
