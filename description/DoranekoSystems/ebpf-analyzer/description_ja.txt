eBPF Analyzer は、root 化した Android x86_64 端末上で Linux eBPF を用い、プロキシを起動したり端末のプロキシ設定を変更したりせずにネットワーク活動を観測する実験的な PacketProxy 拡張です。Go ベースのホストモニターが cilium/ebpf で構築した端末上コレクタを駆動し、Java プラグインが PacketProxy 上で捕捉した TCP 接続、パケットコピー、システムコール関連の I/O イベントを表示して検査し、インストール済みパッケージへの帰属付けを可能にします。オプションの Frida 連携により、補助スクリプトと eBPF ヘルパー経由で選択プロセスのネイティブおよび Java スタックトレースを追加できます。TLS ペイロードがワイヤ上で暗号化されたままでも、ライブトラフィックと呼び出しサイトを突き合わせたいモバイルセキュリティ研究者、リバースエンジニア、アナリスト向けのスタックです。開発は本番向け展開より、制御下のエミュレータテストに重点を置いています。
