eBPF Analyzer는 root된 Android x86_64 기기에서 Linux eBPF를 사용해 프록시를 실행하거나 기기 프록시 설정을 바꾸지 않고도 네트워크 활동을 관찰하는 실험적 PacketProxy 확장입니다. Go 기반 호스트 모니터가 cilium/ebpf로 구축한 온디바이스 수집기를 구동하고, Java 플러그인이 PacketProxy에서 포착한 TCP 연결, 패킷 복사본, 시스템 호출 관련 I/O 이벤트를 표시해 검사하고 설치된 패키지에 귀속시킵니다. 선택적 Frida 연동은 동반 스크립트와 eBPF 헬퍼를 통해 선택한 프로세스에 네이티브 및 Java 스택 추적을 추가합니다. TLS 페이로드가 전송 구간에서 암호화된 상태를 유지하면서도 실시간 트래픽과 호출 지점을 상관시켜야 하는 모바일 보안 연구자, 리버스 엔지니어, 분석가에게 적합한 스택입니다. 개발은 프로덕션 배포보다 통제된 에뮬레이터 테스트에 초점을 맞추었습니다.
