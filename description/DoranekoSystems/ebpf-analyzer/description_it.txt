eBPF Analyzer è un’estensione sperimentale per PacketProxy che usa Linux eBPF su dispositivi Android x86_64 con root per osservare l’attività di rete senza eseguire un proxy né modificare le impostazioni proxy del dispositivo. Un monitor host basato su Go guida un collector on-device costruito con cilium/ebpf, mentre un plugin Java presenta in PacketProxy connessioni TCP catturate, copie di pacchetti ed eventi I/O legati alle syscall, per ispezione e attribuzione ai pacchetti installati. L’integrazione opzionale con Frida aggiunge stack trace nativi e Java per processi selezionati tramite script di supporto e helper eBPF. Lo stack è adatto a ricercatori di sicurezza mobile, reverse engineer e analisti che devono correlare il traffico live con i siti di chiamata mentre i payload TLS restano cifrati sul wire. Lo sviluppo si è concentrato su test controllati in emulatore piuttosto che su un deploy pronto per la produzione.
