eBPF Analyzer — экспериментальное расширение PacketProxy, которое использует Linux eBPF на rooted Android x86_64 для наблюдения за сетевой активностью без запуска прокси и без изменения настроек прокси на устройстве. Монитор на хосте на Go управляет сборщиком на устройстве, собранным с cilium/ebpf, а Java-плагин показывает в PacketProxy перехваченные TCP-соединения, копии пакетов и события ввода-вывода, связанные с системными вызовами, для анализа и привязки к установленным пакетам. Опциональная интеграция с Frida добавляет нативные и Java stack trace для выбранных процессов через вспомогательные скрипты и eBPF-хелперы. Стек подходит исследователям мобильной безопасности, reverse-инженерам и аналитикам, которым нужно сопоставлять живой трафик с местами вызовов, пока полезная нагрузка TLS остаётся зашифрованной на проводе. Разработка ориентирована на контролируемое тестирование в эмуляторе, а не на готовность к промышленному развёртыванию.
