eBPF Analyzer est une extension expérimentale pour PacketProxy qui utilise Linux eBPF sur des appareils Android x86_64 rootés pour observer l’activité réseau sans exécuter de proxy ni modifier les réglages proxy de l’appareil. Un moniteur hôte en Go pilote un collecteur sur l’appareil construit avec cilium/ebpf, tandis qu’un plugin Java présente dans PacketProxy les connexions TCP capturées, les copies de paquets et les événements I/O liés aux appels système, pour inspection et attribution aux paquets installés. L’intégration Frida optionnelle ajoute des traces de pile natives et Java pour des processus choisis via des scripts compagnons et des helpers eBPF. La pile convient aux chercheurs en sécurité mobile, ingénieurs inverseurs et analystes qui doivent corréler le trafic en direct avec les sites d’appel tandis que les charges utiles TLS restent chiffrées sur le fil. Le développement a visé des tests sur émulateur contrôlés plutôt qu’un déploiement prêt pour la production.
