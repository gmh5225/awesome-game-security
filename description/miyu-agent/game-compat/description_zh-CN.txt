Game-compat 是 Miyu 代理技能包，用于检查 PC 游戏能否在 Linux（含 Steam Deck）与 Apple Silicon Mac 上运行。基于 Python 3 的命令行脚本汇聚 ProtonDB 玩家报告、AreWeAntiCheatYet 反作弊状态、caniplayonlinux 结论、Valve Steam Deck 认证以及 MacGamingDB 关于原生运行、CrossOver 与 Parallels 的资料。可通过 Steam App ID 或游戏名称（含中文商店名）解析游戏，仅用标准库并行抓取各数据源，并可按芯片筛选 Mac 结果并输出 JSON 供自动化使用。适合规划 Linux 或 Mac 安装的玩家，以及需要快速、有据可查地了解 Proton 兼容性与反作弊是否阻止非 Windows 平台联机的人。
