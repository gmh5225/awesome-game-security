Game-compat 是 Miyu 代理技能套件，用於檢查 PC 遊戲能否在 Linux（含 Steam Deck）與 Apple Silicon Mac 上執行。以 Python 3 撰寫的命令列腳本彙整 ProtonDB 玩家回報、AreWeAntiCheatYet 反作弊狀態、caniplayonlinux 結論、Valve Steam Deck 驗證，以及 MacGamingDB 關於原生執行、CrossOver 與 Parallels 的資料。可透過 Steam App ID 或遊戲名稱（含中文商店名稱）解析遊戲，僅用標準函式庫並行擷取各來源，並可依晶片篩選 Mac 結果、輸出 JSON 供自動化使用。適合規劃 Linux 或 Mac 安裝的玩家，以及需要快速、有出處地了解 Proton 相容性與反作弊是否阻擋非 Windows 平台連線的人。
