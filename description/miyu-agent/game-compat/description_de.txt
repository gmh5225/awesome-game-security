Game-compat ist ein Miyu-Agenten-Skill-Paket, das prüft, ob ein PC-Spiel unter Linux (einschließlich Steam Deck) und auf Apple-Silicon-Macs läuft. Ein Python-3-Kommandozeilenskript bündelt Kompatibilitätsdaten aus ProtonDB-Spielerberichten, dem Anti-Cheat-Status von AreWeAntiCheatYet, caniplayonlinux-Urteilen, der Valve Steam Deck-Verifizierung sowie MacGamingDB-Berichten zu Native Play, CrossOver und Parallels. Spiele werden per Steam App ID oder Titel (einschließlich chinesischer Store-Namen) aufgelöst, Quellen werden parallel nur mit der Standardbibliothek abgerufen, Mac-Ergebnisse können nach Chip gefiltert und JSON für Automatisierung ausgegeben werden. Geeignet für Spieler, die Linux- oder Mac-Installationen planen, und für alle, die schnell belegte Antworten zu Proton-Kompatibilität und Anti-Cheat-Blockaden beim Online-Spiel auf Nicht-Windows-Plattformen brauchen.
