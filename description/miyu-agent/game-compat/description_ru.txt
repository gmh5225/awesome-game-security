Game-compat — пакет навыков агента Miyu, который проверяет, запускается ли игра для ПК в Linux (включая Steam Deck) и на Mac с Apple Silicon. Скрипт командной строки на Python 3 собирает данные о совместимости из отчётов игроков ProtonDB, статуса античита AreWeAntiCheatYet, вердиктов caniplayonlinux, проверки Steam Deck от Valve и отчётов MacGamingDB о нативной игре, CrossOver и Parallels. Игры определяются по Steam App ID или названию (включая китайские имена в магазине), источники запрашиваются параллельно только средствами стандартной библиотеки, результаты для Mac можно фильтровать по чипу и выводить JSON для автоматизации. Подходит геймерам, планирующим установку в Linux или на Mac, и тем, кому нужны быстрые ответы с указанием источников о совместимости с Proton и о том, блокирует ли античит онлайн на платформах, отличных от Windows.
