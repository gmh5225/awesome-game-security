Game-compat는 Miyu 에이전트 스킬 패키지로, PC 게임이 Linux(Steam Deck 포함)와 Apple Silicon Mac에서 실행되는지 확인합니다. Python 3 명령줄 스크립트가 ProtonDB 플레이어 보고, AreWeAntiCheatYet 안티치트 상태, caniplayonlinux 판정, Valve Steam Deck 인증, MacGamingDB의 네이티브 플레이·CrossOver·Parallels 관련 자료를 한곳에 모읍니다. Steam App ID 또는 제목(중국어 스토어 이름 포함)으로 게임을 찾고, 표준 라이브러리만으로 소스를 병렬로 가져오며, Mac 결과를 칩별로 걸러 JSON을 자동화용으로 내보낼 수 있습니다. Linux나 Mac 설치를 계획하는 게이머와 Proton 호환성 및 비 Windows에서 안티치트가 온라인 플레이를 막는지 빠르게 출처와 함께 알고 싶은 사람에게 적합합니다.
