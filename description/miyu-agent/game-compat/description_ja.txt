Game-compat は Miyu エージェント用スキルパッケージで、PC ゲームが Linux（Steam Deck 含む）や Apple Silicon Mac で動作するかを確認します。Python 3 のコマンドラインスクリプトが、ProtonDB のプレイヤー報告、AreWeAntiCheatYet のアンチチート状況、caniplayonlinux の判定、Valve の Steam Deck 認証、MacGamingDB のネイティブプレイ・CrossOver・Parallels に関する情報を集約します。Steam App ID またはタイトル（中国語ストア名を含む）でゲームを解決し、標準ライブラリのみで各ソースを並列取得し、Mac 結果をチップで絞り込み、自動化用の JSON を出力できます。Linux や Mac への導入を検討するゲーマーや、Proton 互換性や非 Windows でオンラインがアンチチートにより阻害されるかを、出典付きで素早く知りたい人向けです。
