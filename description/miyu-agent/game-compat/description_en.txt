Game-compat is a Miyu agent skill package that checks whether a PC game runs on Linux (including Steam Deck) and Apple Silicon Macs. A Python 3 command-line script aggregates compatibility data from ProtonDB player reports, AreWeAntiCheatYet anti-cheat status, caniplayonlinux verdicts, Valve Steam Deck verification, and MacGamingDB reports on native play, CrossOver, and Parallels. It resolves games by Steam App ID or title (including Chinese store names), fetches sources in parallel using only the standard library, and can filter Mac results by chip and emit JSON for automation. It suits gamers planning Linux or Mac installs and anyone who needs quick, sourced answers about Proton compatibility and whether anti-cheat blocks online play on non-Windows platforms.
