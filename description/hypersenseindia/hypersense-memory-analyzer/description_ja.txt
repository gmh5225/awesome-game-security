HyperSense は Windows x64 向けのライブユーザーモードメモリ解析ツールで、オープンソースの Moneta エンジンを Win32 GUI と、任意のクラシック Moneta 風コマンドライン構成でラップしています。主に C++17 で実装され、ユーザーが選択したプロセスを IOC、ALL、REGION、REFERENCED 各モードで侵害指標（IoC）スキャンし、未署名モジュール、メタデータ異常、CLR ヒープ、関連するメモリ属性向けのフィルタを備えます。エンジンは仮想メモリ領域とサブ領域を走査し、PE イメージと .NET 関連レイアウトを解析し、詳細な TXT または HTML レポートの出力に加え、ファイルパスに対する VirusTotal 参照を任意で行えます。セキュリティ研究者、反チートおよびゲーム整合性アナリスト、リバースエンジニア向けで、許可されたシステム上で注入コード、疑わしいマッピング、その他のライブプロセスメモリ異常を検出する用途を想定しています。
