HyperSense는 Windows x64용 라이브 사용자 모드 메모리 분석 도구로, 오픈 소스 Moneta 엔진을 Win32 GUI와 선택 가능한 클래식 Moneta 스타일 명령줄 레이아웃으로 감쌉니다. 주로 C++17로 구현되며, 사용자가 선택한 프로세스를 IOC, ALL, REGION, REFERENCED 모드에서 침해 지표(IoC) 관점으로 스캔하고, 서명되지 않은 모듈, 메타데이터 이상, CLR 힙 및 관련 메모리 속성에 대한 필터를 제공합니다. 엔진은 가상 메모리 영역과 하위 영역을 순회하며 PE 이미지와 .NET 관련 레이아웃을 파싱하고, 상세한 TXT 또는 HTML 보고서를 생성할 수 있으며 파일 경로에 대해 선택적으로 VirusTotal 조회를 수행합니다. 보안 연구자, 안티치트 및 게임 무결성 분석가, 리버스 엔지니어를 대상으로 하며, 승인된 시스템에서 주입 코드, 의심스러운 매핑 및 기타 라이브 프로세스 메모리 이상을 찾는 데 사용합니다.
