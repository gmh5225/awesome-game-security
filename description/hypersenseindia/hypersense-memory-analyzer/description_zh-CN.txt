HyperSense 是一款面向 Windows x64 的用户态实时内存分析工具，将开源 Moneta 引擎封装在 Win32 图形界面中，并提供可选的经典 Moneta 风格命令行布局。它主要用 C++17 实现，可在用户指定的进程中按 IOC、ALL、REGION 和 REFERENCED 等模式扫描入侵指标，并支持对未签名模块、元数据异常、CLR 堆及相关内存属性进行过滤。引擎遍历虚拟内存区域与子区域，解析 PE 映像与 .NET 相关布局，可生成详细的 TXT 或 HTML 报告，并对文件路径可选调用 VirusTotal 查询。面向安全研究人员、反作弊与游戏完整性分析人员以及逆向工程师，用于在授权系统上发现注入代码、可疑映射及其他实时进程内存异常。
