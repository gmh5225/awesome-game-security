HyperSense is a Windows x64 live usermode memory analysis tool that wraps the open-source Moneta engine in a Win32 GUI and an optional classic Moneta-style command-line layout. It is implemented primarily in C++17 and scans a user-selected process for indicators of compromise across IOC, ALL, REGION, and REFERENCED modes, with filters for unsigned modules, metadata anomalies, CLR heaps, and related memory attributes. The engine walks virtual memory regions and subregions, parses PE images and .NET-related layouts, and can emit detailed TXT or HTML reports plus optional VirusTotal lookups on file paths. It targets security researchers, anti-cheat and game-integrity analysts, and reverse engineers who need to spot injected code, suspicious mappings, and other live-process memory anomalies on authorized systems.
