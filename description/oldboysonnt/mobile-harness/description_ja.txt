Mobile Pentest Harness（mph）は、許可された Android アプリケーションのセキュリティテスト向け AI 指向の自動化フレームワークです。主に Python で書かれ、root 済みエミュレータまたは実機に Magisk と rootAVD を導入し、計装の隠蔽、Frida による SSL ピンニング回避、HTTP(S) を Burp Suite 経由にルーティング、JADX によるターゲットの逆コンパイルと分析用コード索引を行います。MCP サーバー経由でデバイスおよび監査機能を公開し、座標ベースの画面操作、検証とレポート付きの静的監査スイープ、攻撃面マッピング・静的レビュー・トラフィック分析・限定動的プローブの多パス AI エージェントの編成に対応します。セキュリティ研究者、バグバウンティテスター、再現可能なモバイル逆解析と評価が必要なラボや CTF ワークフロー向けで、Play Integrity や hardened アプリ・ゲームに関連する一般的なクライアント側保護の確認も含みます。
