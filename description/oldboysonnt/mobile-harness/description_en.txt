Mobile Pentest Harness (mph) is an AI-oriented automation framework for authorized Android application security testing. Written primarily in Python, it provisions rooted emulators or devices with Magisk and rootAVD, hides instrumentation, bypasses SSL pinning via Frida, and routes HTTP(S) through Burp Suite while decompiling targets with JADX and indexing code for analysis. It exposes device and audit capabilities through an MCP server, supports coordinate-based screen control, static audit sweeps with verification and reporting, and can orchestrate multi-pass AI agents for surface mapping, static review, traffic analysis, and bounded dynamic probes. The toolkit targets security researchers, bug bounty testers, and lab or CTF workflows who need repeatable mobile reverse engineering and assessment, including checks around Play Integrity and common client-side protections relevant to hardened apps and games.
