Mobile Pentest Harness（mph）是以 AI 為導向的自動化框架，用於經授權的 Android 應用程式安全測試。主要以 Python 撰寫，可在已 root 的模擬器或實體裝置上配置 Magisk 與 rootAVD，隱藏檢測工具、透過 Frida 繞過 SSL pinning，將 HTTP(S) 流量導向 Burp Suite，並以 JADX 反編譯目標、建立程式碼索引供分析。它透過 MCP 伺服器暴露裝置與稽核能力，支援以座標為基礎的螢幕控制、含驗證與報告的靜態稽核掃描，並可編排多輪 AI 代理進行攻擊面對應、靜態審查、流量分析與有界動態探測。此工具面向安全研究人員、漏洞賞金測試者，以及需要可重複行動逆向與評估流程的實驗室或 CTF 工作流程，包含對 Play Integrity 及 hardened 應用與遊戲中常見用戶端防護的檢查。
