Mobile Pentest Harness（mph）是一款面向 AI 的自动化框架，用于经授权的 Android 应用安全测试。主要使用 Python 编写，可在已 root 的模拟器或真机上配置 Magisk 与 rootAVD，隐藏检测工具、通过 Frida 绕过 SSL pinning，将 HTTP(S) 流量导向 Burp Suite，并用 JADX 反编译目标、建立代码索引以便分析。它通过 MCP 服务器暴露设备与审计能力，支持基于坐标的屏幕控制、带验证与报告的静态审计扫描，并可编排多轮 AI 代理完成攻击面映射、静态审查、流量分析与有界动态探测。该工具面向安全研究人员、漏洞赏金测试者以及需要可重复移动逆向与评估流程的实验环境或 CTF 场景，包括对 Play Integrity 及 hardened 应用与游戏中常见客户端防护的检查。
