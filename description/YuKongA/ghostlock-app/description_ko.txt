GhostLock-App은 커널 pselect 경쟁 조건을 악용하여 지원되는 최신 스마트폰에서 root 권한을 획득하는 Android 애플리케이션입니다. Android NDK로 구축된 네이티브 C 익스플로잇 코어, 원터치 실행을 위한 Java UI, 부트 이미지와 OTA 패키지에서 커널 구조체 오프셋을 추출하는 Rust 오프셋 추출기를 결합합니다. 기기는 정확한 커널 release 문자열로 매칭되며, 빌드별 오프셋 테이블과 런타임 JSON 가져오기를 통해 앱을 재빌드하지 않고도 새 커널을 지원할 수 있습니다. 익스플로잇은 uid 0 획득 후 KernelSU 또는 ReSukiSU와 연동하여 포스트 익스플로잇 모듈을 로드합니다. Android 보안 연구자와 리버스 엔지니어가 커널 취약점, root 우회 기법, 잠금된 하드웨어에서의 게임 안티치트 환경을 연구하기 위한 도구입니다.
