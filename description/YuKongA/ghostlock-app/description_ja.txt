GhostLock-App は、カーネルの pselect 競合状態を悪用して、対応する最新スマートフォンで root 権限を取得する Android アプリケーションです。Android NDK で構築したネイティブ C エクスプロイトコア、ワンタップ実行用の Java UI、ブートイメージと OTA パッケージからカーネル構造体オフセットを導出する Rust オフセット抽出器を組み合わせています。デバイスは正確なカーネル release 文字列で照合され、ビルドごとのオフセットテーブルと実行時 JSON インポートにより、アプリを再ビルドせずに新しいカーネルに対応できます。エクスプロイトは KernelSU または ReSukiSU と連携し、uid 0 取得後にポストエクスプロイト用モジュールをロードします。Android セキュリティ研究者やリバースエンジニアが、カーネル脆弱性、root バイパス手法、ロックダウンされたハードウェア上のゲームアンチチート環境を調査するためのツールです。
