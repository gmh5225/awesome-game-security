GhostLock-App — это Android-приложение, использующее состояние гонки pselect в ядре для получения root-привилегий на поддерживаемых современных смартфонах. Оно объединяет нативное ядро эксплойта на C, собранное с Android NDK, Java-интерфейс для запуска одним нажатием и Rust-экстрактор смещений, который вычисляет смещения структур ядра из boot-образов и OTA-пакетов. Устройства сопоставляются по точным строкам release ядра, с таблицами смещений для каждой сборки и импортом JSON во время выполнения, что позволяет поддерживать новые ядра без пересборки приложения. Эксплойт интегрируется с KernelSU или ReSukiSU для загрузки постэксплуатационных модулей после получения uid 0. Предназначен для исследователей безопасности Android и reverse engineers, изучающих уязвимости ядра, методы обхода root и античит-среды в играх на заблокированном оборудовании.
