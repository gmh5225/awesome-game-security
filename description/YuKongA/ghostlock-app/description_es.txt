GhostLock-App es una aplicación Android que explota una condición de carrera pselect del kernel para obtener privilegios root en smartphones modernos compatibles. Combina un núcleo de explotación nativo en C construido con Android NDK, una interfaz Java para ejecución con un toque, y un extractor de offsets en Rust que deriva los offsets de estructuras del kernel a partir de imágenes de arranque y paquetes OTA. Los dispositivos se identifican mediante cadenas exactas de release del kernel, con tablas de offsets por compilación e importación JSON en tiempo de ejecución, de modo que se pueden soportar nuevos kernels sin recompilar la aplicación. El exploit se integra con KernelSU o ReSukiSU para cargar módulos post-explotación tras obtener uid 0. Está destinado a investigadores de seguridad Android e ingenieros de ingeniería inversa que estudian vulnerabilidades del kernel, técnicas de bypass de root y entornos anti-cheat de juegos en hardware bloqueado.
