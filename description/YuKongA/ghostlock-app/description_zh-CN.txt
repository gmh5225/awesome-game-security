GhostLock-App 是一款 Android 应用，利用内核 pselect 竞态条件在受支持的现代智能手机上获取 root 权限。它集成了基于 Android NDK 构建的原生 C 漏洞利用核心、支持一键执行的 Java 界面，以及从 boot 镜像和 OTA 包中提取内核结构偏移的 Rust 偏移提取器。设备通过精确的内核 release 字符串匹配，配合按构建版本划分的偏移表和运行时 JSON 导入，无需重新编译应用即可支持新内核。漏洞利用成功后，可与 KernelSU 或 ReSukiSU 集成，在获得 uid 0 后加载后续模块。该工具面向 Android 安全研究人员和逆向工程师，用于研究内核漏洞、root 绕过技术，以及锁定硬件上的游戏反作弊环境。
