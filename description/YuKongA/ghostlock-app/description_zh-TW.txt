GhostLock-App 是一款 Android 應用程式，利用核心 pselect 競態條件在受支援的現代智慧型手機上取得 root 權限。它整合了以 Android NDK 建構的原生 C 漏洞利用核心、支援一鍵執行的 Java 介面，以及從 boot 映像檔和 OTA 套件中提取核心結構偏移的 Rust 偏移提取器。裝置透過精確的核心 release 字串比對，配合依建置版本劃分的偏移表和執行時 JSON 匯入，無需重新編譯應用程式即可支援新核心。漏洞利用成功後，可與 KernelSU 或 ReSukiSU 整合，在取得 uid 0 後載入後續模組。此工具面向 Android 安全研究人員和逆向工程師，用於研究核心漏洞、root 繞過技術，以及鎖定硬體上的遊戲反作弊環境。
