GhostLock-App è un'applicazione Android che sfrutta una race condition pselect del kernel per ottenere privilegi root su smartphone moderni supportati. Combina un core di exploit nativo in C costruito con Android NDK, un'interfaccia Java per l'esecuzione con un tocco e un estrattore di offset in Rust che ricava gli offset delle strutture del kernel da immagini di boot e pacchetti OTA. I dispositivi vengono abbinati tramite stringhe esatte di release del kernel, con tabelle di offset per build e importazione JSON a runtime, così da supportare nuovi kernel senza ricompilare l'app. L'exploit si integra con KernelSU o ReSukiSU per il caricamento di moduli post-exploit dopo l'ottenimento di uid 0. È destinato a ricercatori di sicurezza Android e reverse engineer che studiano vulnerabilità del kernel, tecniche di bypass del root e ambienti anti-cheat nei giochi su hardware bloccato.
