CS2AC 是一款面向 Counter-Strike 2 专用服务器的开源服务端反作弊插件。采用 C++ 编写，作为 Metamod:Source 插件运行于 Windows 与 Linux x64，可在无需客户端任何组件的情况下分析玩家瞄准、移动、输入与客户端设置。它内置约十七个检测模块，覆盖 aimbot、aimlock、silent aim、anti-aim、bunny hop、autostrafe、DLL 注入、doubletap、非法 cvar 以及相关计时或输入滥用等作弊行为。检测结果可在聊天与屏幕上公告，执行可配置的踢出或封禁命令，支持玩家白名单，并可选择通过 Discord webhook 上报证据。它面向希望在自有服务器上部署行为式反作弊的社区与专用 CS2 服务器运营者。
