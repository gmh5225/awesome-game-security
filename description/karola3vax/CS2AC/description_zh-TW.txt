CS2AC 是一款面向 Counter-Strike 2 專用伺服器的開源伺服端反作弊外掛。以 C++ 編寫，作為 Metamod:Source 外掛運行於 Windows 與 Linux x64，可在無需用戶端任何元件的情況下分析玩家瞄準、移動、輸入與用戶端設定。它內建約十七個偵測模組，涵蓋 aimbot、aimlock、silent aim、anti-aim、bunny hop、autostrafe、DLL 注入、doubletap、無效 cvar 以及相關計時或輸入濫用等作弊行為。偵測結果可在聊天與螢幕上公告，執行可設定的踢出或封鎖指令，支援玩家白名單，並可選擇透過 Discord webhook 回報證據。它面向希望在自有伺服器上部署行為式反作弊的社群與專用 CS2 伺服器營運者。
