CS2AC è un plugin anti-cheat open source lato server per server dedicati di Counter-Strike 2. Scritto in C++ come plugin Metamod:Source per Windows e Linux x64, analizza mira, movimento, input e impostazioni client dei giocatori senza richiedere nulla sul client. Include circa diciassette moduli di rilevamento che coprono cheat come aimbot, aimlock, silent aim, anti-aim, bunny hop, autostrafe, iniezione DLL, doubletap, cvar non validi e relativi abusi di timing o input. I rilevamenti possono essere annunciati in chat e a schermo, eseguire comandi configurabili di kick o ban, supportare whitelist di giocatori e, opzionalmente, segnalare prove a Discord tramite webhook. È rivolto agli operatori di server CS2 community e dedicati che vogliono un anti-cheat comportamentale sui server che controllano.
