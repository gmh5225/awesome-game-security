이 프로젝트는 Model Context Protocol을 통해 AI 에이전트가 구동할 수 있는 리버스 엔지니어링 및 안티치트 연구용 툴체인을 구축하기 위한 원클릭 Windows 설정을 제공합니다. PowerShell 설치 프로그램은 Scoop을 사용하여 Cheat Engine, Ghidra, x64dbg, DynamoRIO, Wireshark, YARA, ReClass.NET과 같은 메모리 분석, 디버깅, 바이너리 분석, 네트워크 캡처 및 텔레메트리 도구와 Frida, Scapy, PyTorch, OpenCV 등의 Python 패키지를 배포합니다. 또한 읽기 전용 Cheat Engine MCP 서버를 클론하고 구성하며, OpenCode 및 Claude Desktop용 MCP 클라이언트 설정을 작성하고, 연결을 확인하고 일반적인 설치 함정을 피하기 위한 스크립트와 문서를 포함합니다. 주요 언어는 자동화용 PowerShell과 MCP 서버 및 분석 라이브러리용 Python입니다. Windows 10 및 11에서 오프라인 디버깅, 프로세스 분석, 치트 테이블 파싱, MMO 안티치트 실험 작업을 위한 보안 연구자 및 AI 지원 워크플로를 대상으로 합니다.
