Este proyecto proporciona una configuración de Windows con un solo clic para construir una cadena de herramientas de ingeniería inversa e investigación anti-trampas que los agentes de IA pueden controlar a través del Model Context Protocol. Un instalador de PowerShell utiliza Scoop para desplegar herramientas de análisis de memoria, depuración, análisis binario, captura de red y telemetría como Cheat Engine, Ghidra, x64dbg, DynamoRIO, Wireshark, YARA y ReClass.NET, junto con paquetes de Python que incluyen Frida, Scapy, PyTorch y OpenCV. También clona y configura un servidor MCP de Cheat Engine de solo lectura, escribe la configuración del cliente MCP para OpenCode y Claude Desktop, e incluye scripts y documentación para verificar la conectividad y evitar errores comunes de instalación. Los lenguajes principales son PowerShell para la automatización y Python para el servidor MCP y las bibliotecas de análisis. Está dirigido a investigadores de seguridad y flujos de trabajo asistidos por IA para depuración sin conexión, análisis de procesos, análisis de tablas de trampas y trabajo de laboratorio anti-trampas en MMO en Windows 10 y 11.
