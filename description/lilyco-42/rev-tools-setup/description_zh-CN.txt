本项目提供一键式 Windows 设置，用于构建可通过 Model Context Protocol 由 AI 代理驱动的逆向工程与反作弊研究工具链。PowerShell 安装程序通过 Scoop 部署内存分析、调试、二进制分析、网络抓包和遥测工具，包括 Cheat Engine、Ghidra、x64dbg、DynamoRIO、Wireshark、YARA 和 ReClass.NET，以及 Frida、Scapy、PyTorch 和 OpenCV 等 Python 包。它还会克隆并配置只读的 Cheat Engine MCP 服务器，为 OpenCode 和 Claude Desktop 写入 MCP 客户端设置，并提供脚本和文档以验证连接并避免常见安装陷阱。主要语言为用于自动化的 PowerShell 以及用于 MCP 服务器和分析库的 Python。面向安全研究人员和 AI 辅助工作流，支持在 Windows 10 和 11 上进行离线调试、进程分析、作弊表解析和 MMO 反作弊实验工作。
