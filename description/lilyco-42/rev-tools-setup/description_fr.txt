Ce projet fournit une configuration Windows en un clic pour construire une chaîne d'outils de rétro-ingénierie et de recherche anti-triche que des agents IA peuvent piloter via le Model Context Protocol. Un installateur PowerShell utilise Scoop pour déployer des outils d'analyse mémoire, de débogage, d'analyse binaire, de capture réseau et de télémétrie tels que Cheat Engine, Ghidra, x64dbg, DynamoRIO, Wireshark, YARA et ReClass.NET, ainsi que des packages Python incluant Frida, Scapy, PyTorch et OpenCV. Il clone et configure également un serveur MCP Cheat Engine en lecture seule, écrit les paramètres client MCP pour OpenCode et Claude Desktop, et inclut des scripts et de la documentation pour vérifier la connectivité et éviter les pièges d'installation courants. Les langages principaux sont PowerShell pour l'automatisation et Python pour le serveur MCP et les bibliothèques d'analyse. Il s'adresse aux chercheurs en sécurité et aux flux de travail assistés par IA pour le débogage hors ligne, l'analyse de processus, l'analyse de tables de triche et le travail de laboratoire anti-triche MMO sur Windows 10 et 11.
