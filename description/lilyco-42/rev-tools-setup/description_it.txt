Questo progetto fornisce una configurazione Windows con un solo clic per costruire una toolchain di reverse engineering e ricerca anti-cheat che gli agenti IA possono guidare tramite il Model Context Protocol. Un installer PowerShell utilizza Scoop per distribuire strumenti di analisi della memoria, debugging, analisi binaria, cattura di rete e telemetria come Cheat Engine, Ghidra, x64dbg, DynamoRIO, Wireshark, YARA e ReClass.NET, insieme a pacchetti Python tra cui Frida, Scapy, PyTorch e OpenCV. Clona e configura anche un server MCP Cheat Engine in sola lettura, scrive le impostazioni del client MCP per OpenCode e Claude Desktop, e include script e documentazione per verificare la connettività ed evitare le insidie comuni dell'installazione. I linguaggi principali sono PowerShell per l'automazione e Python per il server MCP e le librerie di analisi. È rivolto a ricercatori di sicurezza e flussi di lavoro assistiti dall'IA per il debugging offline, l'analisi dei processi, il parsing delle tabelle cheat e il lavoro di laboratorio anti-cheat MMO su Windows 10 e 11.
