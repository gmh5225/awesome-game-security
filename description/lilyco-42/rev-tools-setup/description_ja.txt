本プロジェクトは、Model Context Protocol を介して AI エージェントが操作できるリバースエンジニアリングおよびアンチチート研究用ツールチェーンを構築するための、ワンクリック Windows セットアップを提供します。PowerShell インストーラーは Scoop を使用して、Cheat Engine、Ghidra、x64dbg、DynamoRIO、Wireshark、YARA、ReClass.NET などのメモリ解析、デバッグ、バイナリ解析、ネットワークキャプチャ、テレメトリツールに加え、Frida、Scapy、PyTorch、OpenCV などの Python パッケージをデプロイします。さらに、読み取り専用の Cheat Engine MCP サーバーをクローンして設定し、OpenCode および Claude Desktop 向けの MCP クライアント設定を書き込み、接続を検証し一般的なインストール上の落とし穴を回避するためのスクリプトとドキュメントも含まれます。主な言語は自動化用の PowerShell と、MCP サーバーおよび解析ライブラリ用の Python です。Windows 10 および 11 上でのオフラインデバッグ、プロセス解析、チートテーブル解析、MMO アンチチートのラボ作業を対象とし、セキュリティ研究者および AI 支援ワークフロー向けに設計されています。
