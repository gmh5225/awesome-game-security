Этот проект предоставляет одношаговую настройку Windows для создания цепочки инструментов реверс-инжиниринга и исследования античитов, которой могут управлять ИИ-агенты через Model Context Protocol. Установщик PowerShell использует Scoop для развёртывания инструментов анализа памяти, отладки, бинарного анализа, захвата сетевого трафика и телеметрии, таких как Cheat Engine, Ghidra, x64dbg, DynamoRIO, Wireshark, YARA и ReClass.NET, а также пакетов Python, включая Frida, Scapy, PyTorch и OpenCV. Он также клонирует и настраивает сервер MCP Cheat Engine только для чтения, записывает параметры клиента MCP для OpenCode и Claude Desktop и включает скрипты и документацию для проверки подключения и избежания типичных ошибок установки. Основные языки — PowerShell для автоматизации и Python для сервера MCP и библиотек анализа. Проект ориентирован на исследователей безопасности и рабочие процессы с поддержкой ИИ для офлайн-отладки, анализа процессов, разбора чит-таблиц и лабораторной работы с античитами MMO в Windows 10 и 11.
