MESIA — слой трансляции на Rust, который нативно запускает на Windows исполняемые файлы розничных игр Xbox Series, загружая собственный x86-64-код игры в переразмещённый процесс Win32, а не эмулируя всю машину целиком. Он эмулирует на высоком уровне ядро и среду выполнения консоли — включая D3D12X, DirectStorage, XAudio с Opus и GameInput — и переводит шейдеры игры в хостовый DXIL с дисковым кешированием, используя путь PC Direct3D 12, рассчитанный на современные GPU класса NVIDIA с mesh shaders и шейдерной моделью 6.6. Рабочая область охватывает загрузку PE, import thunk’и, обработку GPU-команд и дескрипторов, разбор проприетарных форматов и опциональную диагностику: захват кадров, отчёты о сбоях GPU в духе DRED и настройку через переменные окружения. Проект нацелен на сохранение и исследование платформы, реверс привязки игр Series к системным API и изучение границ безопасности и совместимости при запуске неизменённых бинарников игр на настольном Windows без исходного консольного стека.
