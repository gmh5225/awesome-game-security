MESIA는 Rust로 작성된 번역 계층으로, 전체 머신 에뮬레이션 대신 Xbox Series 리테일 타이틀 실행 파일의 x86-64 코드를 재호스트된 Win32 프로세스에 로드하여 Windows에서 네이티브로 실행합니다. D3D12X, DirectStorage, Opus를 쓰는 XAudio, GameInput 등 콘솔 커널 및 런타임 서비스를 고수준 에뮬레이션하고, 타이틀 셰이더를 호스트 DXIL로 변환하며 디스크 캐시를 두고, mesh shader와 셰이더 모델 6.6을 지원하는 최신 NVIDIA급 GPU를 전제로 한 PC Direct3D 12 경로를 구동합니다. 작업 공간에는 PE 로딩, import thunk, GPU 명령 및 디스크립터 처리, 전용 포맷 파서, 프레임 캡처·DRED 스타일 GPU 실패 보고·환경 변수 기반 튜닝 같은 선택적 진단이 포함됩니다. 보존과 플랫폼 연구, Series 타이틀이 시스템 API에 어떻게 묶이는지의 리버스 엔지니어링, 원본 콘솔 스택 없이 수정되지 않은 타이틀 바이너리를 데스크톱 Windows에서 실행할 때의 보안·호환성 경계 연구를 목표로 합니다.
