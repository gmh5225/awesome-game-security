MESIA は Rust 製の翻訳レイヤで、Xbox Series 向けリテールタイトルの実行ファイルを、フルマシンエミュレーションではなく、タイトル自身の x86-64 コードを再ホストした Win32 プロセスに読み込むことで、Windows 上でネイティブに実行します。コンソールのカーネルおよびランタイムサービス（D3D12X、DirectStorage、Opus 対応 XAudio、GameInput など）を高レベルエミュレーションし、タイトルシェーダーをホスト向け DXIL に翻訳してディスクキャッシュしつつ、mesh shader とシェーダーモデル 6.6 を想定した近年の NVIDIA クラス GPU 向け PC Direct3D 12 経路を駆動します。ワークスペースは PE ロード、インポートサンク、GPU コマンドおよびデスクリプタ処理、独自フォーマットパーサ、フレームキャプチャや DRED 風 GPU 障害レポート、環境変数によるチューニングなどの任意診断を含みます。保存とプラットフォーム研究、Series タイトルがシステム API にどう結び付くかのリバースエンジニアリング、および元のコンソールスタックなしで未改変のタイトルバイナリをデスクトップ Windows 上で動かす際のセキュリティと互換性の境界の調査を目的としています。
