MESIA is a Rust translation layer that runs Xbox Series retail title executables natively on Windows by loading the title’s own x86-64 code into a re-hosted Win32 process rather than full-machine emulation. It high-level-emulates console kernel and runtime services—including D3D12X, DirectStorage, XAudio with Opus, and GameInput—and translates title shaders to host DXIL with disk caching while driving a PC Direct3D 12 path that expects recent NVIDIA-class GPUs with mesh shaders and shader model 6.6. The workspace spans PE loading, import thunks, GPU command and descriptor handling, proprietary format parsers, and optional diagnostics such as frame capture, DRED-style GPU failure reporting, and environment-driven tuning knobs. It is aimed at preservation and platform research, reverse engineering how Series titles bind to system APIs, and studying the security and compatibility boundaries of running unmodified title binaries on desktop Windows without the original console stack.
