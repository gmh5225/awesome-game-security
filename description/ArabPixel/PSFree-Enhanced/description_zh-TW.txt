PSFree Enhanced 是一套基於 WebKit 的漏洞利用鏈合集，可透過系統瀏覽器對 PlayStation 4 主機進行越獄。它將 PSFree、Bad Hoist、CSSFontFace 等使用者態漏洞，與 Lapse、NetCtrl 以及 Sleirsgoevy 的 6.7x 等核心提權技術相結合，涵蓋廣泛韌體版本。專案主要以 JavaScript 實作（含 ES 模組，並為舊韌體使用 Babel），並輔以 C 語言核心修補、HTML/CSS 介面，以及用於快取清單的 Python 工具。越獄成功後可載入 HEN 或 GoldHEN 承載，在 9020 連接埠接收承載，並在本機託管時可選擇主機服務或掃描裝置。面向主機安全研究者、逆向工程師，以及需要多韌體 PS4 越獄託管與承載投遞的使用者。
