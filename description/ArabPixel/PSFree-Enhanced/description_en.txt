PSFree Enhanced is a collection of WebKit-based exploit chains for jailbreaking PlayStation 4 consoles through the system browser. It combines userland exploits such as PSFree, Bad Hoist, and CSSFontFace with kernel privilege-escalation techniques including Lapse, NetCtrl, and Sleirsgoevy's 6.7x exploit across a wide range of firmwares. The project is implemented mainly in JavaScript (with ES modules and Babel for older firmwares), plus supporting C kernel patches, HTML/CSS UI, and Python tooling for cache manifests. After a successful jailbreak it can load HEN or GoldHEN payloads, accept payloads on port 9020, and optionally host or scan for devices when served locally. It targets console security researchers, reverse engineers, and users who need multi-firmware PS4 jailbreak hosting and payload delivery.
