PSFree Enhanced — набор цепочек эксплойтов на базе WebKit для джейлбрейка консолей PlayStation 4 через системный браузер. Он сочетает userland-эксплойты вроде PSFree, Bad Hoist и CSSFontFace с техниками повышения привилегий в ядре, включая Lapse, NetCtrl и эксплойт Sleirsgoevy 6.7x, для широкого диапазона прошивок. Проект в основном написан на JavaScript (с ES-модулями и Babel для старых прошивок), а также включает патчи ядра на C, HTML/CSS UI и Python-инструменты для кэш-манифестов. После успешного джейлбрейка он может загружать payload'ы HEN или GoldHEN, принимать payload'ы на порту 9020 и при локальной раздаче опционально хостить или сканировать устройства. Предназначен для исследователей безопасности консолей, реверс-инженеров и пользователей, которым нужен хостинг джейлбрейка PS4 для разных прошивок и доставка payload'ов.
