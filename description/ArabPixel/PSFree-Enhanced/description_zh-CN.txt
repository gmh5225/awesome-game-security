PSFree Enhanced 是一套基于 WebKit 的漏洞利用链合集，可通过系统浏览器对 PlayStation 4 主机进行越狱。它将 PSFree、Bad Hoist、CSSFontFace 等用户态漏洞，与 Lapse、NetCtrl 以及 Sleirsgoevy 的 6.7x 等内核提权技术相结合，覆盖广泛固件版本。项目主要以 JavaScript 实现（含 ES 模块，并为旧固件使用 Babel），并辅以 C 语言内核补丁、HTML/CSS 界面，以及用于缓存清单的 Python 工具。越狱成功后可加载 HEN 或 GoldHEN 载荷，在 9020 端口接收载荷，并在本地托管时可选择主机服务或扫描设备。面向主机安全研究者、逆向工程师，以及需要多固件 PS4 越狱托管与载荷投递的用户。
