PSFree Enhanced は、システムブラウザ経由で PlayStation 4 を脱獄するための WebKit ベースのエクスプロイトチェーン集です。PSFree、Bad Hoist、CSSFontFace などのユーザーランドエクスプロイトと、Lapse、NetCtrl、Sleirsgoevy の 6.7x エクスプロイトなどのカーネル権限昇格手法を組み合わせ、幅広いファームウェアに対応します。実装の中心は JavaScript（ES モジュール、旧ファームウェア向け Babel）で、C によるカーネルパッチ、HTML/CSS UI、キャッシュマニフェスト用 Python ツールも含まれます。脱獄成功後は HEN または GoldHEN ペイロードを読み込み、ポート 9020 でペイロードを受け取り、ローカル配信時にはホストやデバイススキャンも可能です。コンソールセキュリティ研究者、リバースエンジニア、複数ファームウェア向け PS4 脱獄ホスティングとペイロード配信を必要とするユーザーを対象とします。
