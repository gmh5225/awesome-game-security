Amice is an LLVM pass plugin written in Rust that loads into the compiler via clang -fpass-plugin and applies compile-time obfuscation to LLVM IR from C/C++, Rust, and other LLVM-based languages. It implements a broad set of protection transforms including string encryption, control-flow flattening, bogus control flow, mixed boolean-arithmetic (MBA) rewriting, indirect calls and branches, basic-block splitting and shuffling, and instruction-level virtual machine protection (VMP). The project is built with llvm-plugin-rs and inkwell, supports LLVM 11 through 22, and includes Android NDK integration for mobile builds. It is aimed at developers who need to harden native binaries against reverse engineering, tampering, and static analysis in game security, software protection, and anti-cheat contexts.
