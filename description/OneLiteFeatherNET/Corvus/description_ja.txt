Corvus は機械学習ベースのアンチチートプラットフォームで、プレイヤーのネットワークトラフィックを受動的に収集し、自動処罰ではなくスタッフの判断を支援するための、プレイヤーごとのチート可能性スコアを算出します。Java 製 Velocity プロキシプラグインが PacketEvents でパケットを取得し、NATS JetStream 経由で公開します。Python バックエンドがデータを取り込み、エンリッチし、スコアリングし、スタック全体で protobuf スキーマを共有します。キャプチャは S3 互換ストレージ上の Parquet ベースのデータレイクに仮名化して保存され、PostgreSQL でカタログ化されます。整備されたデータセットは scikit-learn、PyTorch、ONNX を用いたオフライン学習・評価パイプラインに供給されます。CPU のみのオンラインスコアリングサービスがプラグイン API でスコアを公開し、Nuxt で構築した管理 UI を提供します。デプロイには Docker Compose と Helm chart があります。プロキシベースのゲーム基盤で証拠に基づくモデレーションワークフローを求める Minecraft ネットワーク運営者とアンチチートチーム向けです。
