Corvus는 머신러닝 기반 안티치트 플랫폼으로, 플레이어 네트워크 트래픽을 수동적으로 수집하고 자동 처벌이 아니라 스태프 의사결정을 돕는 플레이어별 치트 가능성 점수를 산출합니다. Java Velocity 프록시 플러그인이 PacketEvents로 패킷을 캡처해 NATS JetStream으로 발행하고, Python 백엔드 서비스가 protobuf 스키마를 스택 전반에서 공유하며 데이터를 수집·보강·점수화합니다. 캡처는 S3 호환 스토리지의 Parquet 기반 데이터 레이크에 가명으로 저장되고 PostgreSQL로 카탈로그화되며, 정제된 데이터셋은 scikit-learn, PyTorch, ONNX를 사용하는 오프라인 학습·평가 파이프라인에 공급됩니다. CPU 전용 온라인 점수 산출 서비스가 플러그인 API로 점수를 노출하고 Nuxt로 구축한 관리 UI를 제공하며, 배포는 Docker Compose와 Helm chart를 지원합니다. 프록시 기반 게임 인프라에서 근거 있는 모더레이션 워크플로를 원하는 Minecraft 네트워크 운영자와 안티치트 팀을 대상으로 합니다.
