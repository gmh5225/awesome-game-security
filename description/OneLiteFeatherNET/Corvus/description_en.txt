Corvus is a machine-learning anti-cheat platform that passively collects player network traffic and produces per-player likelihood-of-cheating scores as a staff decision aid rather than automatic punishment. A Java Velocity proxy plugin captures packets through PacketEvents and publishes them over NATS JetStream, while Python backend services ingest, enrich, and score the data with protobuf schemas shared across the stack. Captures are stored pseudonymously in a Parquet-based data lake on S3-compatible storage with PostgreSQL cataloging, and curated datasets feed offline training and evaluation pipelines using scikit-learn, PyTorch, and ONNX. A CPU-only online scoring service exposes scores through a plugin API and management UI built with Nuxt, with Docker Compose and Helm charts for deployment. It targets Minecraft network operators and anti-cheat teams who want evidence-backed moderation workflows on proxy-based game infrastructure.
