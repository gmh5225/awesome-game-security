Corvus 是一个基于机器学习的反作弊平台，被动采集玩家网络流量并输出每位玩家的作弊可能性评分，供工作人员决策参考，而非自动处罚。Java 版 Velocity 代理插件通过 PacketEvents 捕获数据包，经 NATS JetStream 发布；Python 后端服务负责接入、丰富化与评分，全栈共享 protobuf 模式。采集数据以假名形式存入基于 Parquet 的数据湖（S3 兼容存储），并由 PostgreSQL 编目；整理后的数据集用于离线训练与评估，采用 scikit-learn、PyTorch 与 ONNX。仅 CPU 的在线评分服务通过插件 API 暴露分数，管理界面基于 Nuxt，部署提供 Docker Compose 与 Helm chart。面向希望在基于代理的游戏基础设施上采用有证据支撑的审核流程的 Minecraft 网络运营方与反作弊团队。
