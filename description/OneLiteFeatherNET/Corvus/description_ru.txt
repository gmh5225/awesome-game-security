Corvus — платформа античита на основе машинного обучения, которая пассивно собирает сетевой трафик игроков и выдаёт по каждому игроку оценку вероятности читерства как подсказку для решений персонала, а не для автоматических наказаний. Плагин прокси Velocity на Java захватывает пакеты через PacketEvents и публикует их в NATS JetStream, а сервисы бэкенда на Python принимают, обогащают и оценивают данные с общими схемами protobuf по всему стеку. Захваты хранятся псевдонимизированно в озере данных на Parquet в S3-совместимом хранилище с каталогизацией в PostgreSQL; подготовленные наборы данных питают офлайн-конвейеры обучения и оценки с scikit-learn, PyTorch и ONNX. Онлайн-сервис скоринга только на CPU отдаёт оценки через API плагина и UI управления на Nuxt; развёртывание — Docker Compose и Helm-чарты. Целевая аудитория — операторы сетей Minecraft и команды античита, которым нужны рабочие процессы модерации с опорой на доказательства на прокси-инфраструктуре игры.
