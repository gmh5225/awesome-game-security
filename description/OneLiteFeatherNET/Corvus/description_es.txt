Corvus es una plataforma antitrampas basada en aprendizaje automático que recopila pasivamente el tráfico de red de los jugadores y genera puntuaciones de probabilidad de trampas por jugador como ayuda a la decisión del staff, no como castigo automático. Un plugin proxy de Velocity en Java captura paquetes mediante PacketEvents y los publica en NATS JetStream, mientras servicios backend en Python ingieren, enriquecen y puntúan los datos con esquemas protobuf compartidos en toda la pila. Las capturas se almacenan de forma seudonimizada en un data lake basado en Parquet sobre almacenamiento compatible con S3, con catalogación en PostgreSQL, y conjuntos de datos curados alimentan pipelines offline de entrenamiento y evaluación con scikit-learn, PyTorch y ONNX. Un servicio de puntuación online solo CPU expone las puntuaciones mediante una API de plugin y una interfaz de gestión hecha con Nuxt, con Docker Compose y charts Helm para el despliegue. Está dirigido a operadores de redes Minecraft y equipos antitrampas que quieren flujos de moderación respaldados por evidencia en infraestructura de juego basada en proxy.
