Corvus 是以機器學習為基礎的反作弊平台，被動收集玩家網路流量並產出每位玩家的作弊可能性評分，供工作人員決策參考，而非自動處罰。Java 版 Velocity 代理外掛透過 PacketEvents 擷取封包，經 NATS JetStream 發布；Python 後端服務負責接入、豐富化與評分，全堆疊共用 protobuf 結構描述。擷取資料以假名形式存入以 Parquet 為基礎的資料湖（S3 相容儲存），並由 PostgreSQL 編目；整理後的資料集供離線訓練與評估，採用 scikit-learn、PyTorch 與 ONNX。僅 CPU 的線上評分服務透過外掛 API 暴露分數，管理介面以 Nuxt 建置，部署提供 Docker Compose 與 Helm chart。面向希望在以代理為基礎的遊戲基礎設施上採用有證據支撐的審核流程的 Minecraft 網路營運方與反作弊團隊。
