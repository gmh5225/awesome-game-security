Corvus est une plateforme anti-triche basée sur l’apprentissage automatique qui collecte passivement le trafic réseau des joueurs et produit, pour chaque joueur, un score de probabilité de triche destiné à aider le staff dans ses décisions plutôt qu’à punir automatiquement. Un plugin proxy Velocity en Java capture les paquets via PacketEvents et les publie sur NATS JetStream, tandis que des services backend Python ingèrent, enrichissent et notent les données avec des schémas protobuf partagés dans toute la pile. Les captures sont stockées de façon pseudonymisée dans un lac de données Parquet sur un stockage compatible S3, avec catalogage PostgreSQL ; des jeux de données curés alimentent des pipelines d’entraînement et d’évaluation hors ligne avec scikit-learn, PyTorch et ONNX. Un service de scoring en ligne CPU-only expose les scores via une API de plugin et une interface de gestion construite avec Nuxt, avec Docker Compose et des chart Helm pour le déploiement. Il s’adresse aux opérateurs de réseaux Minecraft et aux équipes anti-triche qui veulent des workflows de modération étayés par des preuves sur une infrastructure de jeu basée sur un proxy.
