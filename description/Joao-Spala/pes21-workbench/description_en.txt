PES 21 Workbench is a source-driven Cheat Engine cheat table and tooling suite for eFootball PES 2021 that exposes Master League and in-match editing through a custom dark Studio GUI. It is built with Python build scripts, Lua embedded in the cheat table, and JSON data derived from reverse engineering PES2021.exe, including Konami’s OVR weight matrices, scout-list handlers, and targeted memory hooks armed via AOB scans and RVAs. Key capabilities include DNA-preserving overall rating edits, real-RAM scout and shortlist management, player struct snapshots with undo, finance and contract overrides, training and match-time controls, and bilingual PT-BR and English distributions compiled to ready-made .CT files. Automated tests lint the cheat table and GUI DPI behavior. It targets reverse engineers, memory editors, and modding researchers who study or extend PES 2021 client internals and live game state rather than shipping a standalone application.
