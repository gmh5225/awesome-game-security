PES 21 Workbench は、eFootball PES 2021 向けのソース駆動型 Cheat Engine チートテーブルおよびツールスイートで、カスタムのダーク Studio GUI を通じてマスターリーグおよび試合中の編集機能を提供します。Python ビルドスクリプト、チートテーブルに埋め込まれた Lua、PES2021.exe のリバースエンジニアリングに基づく JSON データ（Konami の OVR 重み行列、スカウトリストハンドラ、AOB スキャンと RVA によるメモリフックなど）で構築されています。主な機能には、DNA を保持した総合評価の編集、実 RAM 上のスカウト・ショートリスト管理、元に戻せる選手構造体スナップショット、財務・契約の上書き、トレーニングと試合時間の制御、すぐ使える .CT ファイルにコンパイルされたポルトガル語（ブラジル）と英語の二言語配布があります。自動テストでチートテーブルと GUI の DPI 挙動をリントします。スタンドアロンアプリとして配布するのではなく、PES 2021 クライアント内部とライブゲーム状態の調査・拡張を行うリバースエンジニア、メモリエディタ、MOD 研究者を対象としています。
