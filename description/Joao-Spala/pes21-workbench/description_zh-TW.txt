PES 21 Workbench 是一套面向 eFootball PES 2021 的原始碼驅動型 Cheat Engine 作弊表及工具組，透過自訂深色 Studio 圖形介面公開大師聯賽與比賽內編輯能力。專案採用 Python 建置腳本、嵌入作弊表的 Lua，以及透過對 PES2021.exe 逆向工程所得的 JSON 資料，涵蓋 Konami 的 OVR 權重矩陣、球探清單處理器，以及藉 AOB 掃描與 RVA 啟用的針對性記憶體掛鉤。主要功能包括保留 DNA 的綜合能力值編輯、真實記憶體中的球探與候選名單管理、可復原的球員結構快照、財務與合約覆寫、訓練與比賽時間控制，以及編譯為即用 .CT 檔案的葡語（巴西）與英語雙語發行。自動化測試對作弊表與 GUI DPI 行為進行 lint。面向研究或擴充 PES 2021 用戶端內部機制與即時遊戲狀態的逆向工程師、記憶體編輯者與 MOD 研究者，而非作為獨立應用程式發布。
