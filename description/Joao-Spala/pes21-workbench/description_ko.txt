PES 21 Workbench는 eFootball PES 2021용 소스 기반 Cheat Engine 치트 테이블 및 도구 모음으로, 사용자 정의 다크 Studio GUI를 통해 마스터 리그와 경기 중 편집 기능을 제공합니다. Python 빌드 스크립트, 치트 테이블에 내장된 Lua, PES2021.exe 리버스 엔지니어링에서 파생한 JSON 데이터(Konami의 OVR 가중치 행렬, 스카우트 목록 핸들러, AOB 스캔과 RVA로 무장한 대상 메모리 훅 포함)로 구축되었습니다. 주요 기능으로는 DNA를 보존한 종합 능력치 편집, 실제 RAM 기반 스카우트·숏리스트 관리, 실행 취소 가능한 선수 구조체 스냅샷, 재정·계약 덮어쓰기, 훈련 및 경기 시간 제어, 즉시 사용 가능한 .CT 파일로 컴파일된 포르투갈어(브라질)와 영어 이중 언어 배포가 있습니다. 자동화 테스트가 치트 테이블과 GUI DPI 동작을 린트합니다. 독립 실행형 애플리케이션을 출시하는 것이 아니라 PES 2021 클라이언트 내부와 라이브 게임 상태를 연구하거나 확장하는 리버스 엔지니어, 메모리 편집자, 모딩 연구자를 대상으로 합니다.
