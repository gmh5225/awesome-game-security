PES 21 Workbench 是一套面向 eFootball PES 2021 的源码驱动型 Cheat Engine 作弊表及工具集，通过自定义深色 Studio 图形界面暴露大师联赛与比赛内编辑能力。项目采用 Python 构建脚本、嵌入作弊表的 Lua，以及通过对 PES2021.exe 逆向工程得到的 JSON 数据，涵盖 Konami 的 OVR 权重矩阵、球探列表处理器，以及通过 AOB 扫描与 RVA 启用的针对性内存挂钩。主要功能包括保持 DNA 的综合能力值编辑、真实内存中的球探与候选名单管理、可撤销的球员结构体快照、财务与合同覆盖、训练与比赛时间控制，以及编译为即用 .CT 文件的葡语（巴西）与英语双语分发。自动化测试对作弊表与 GUI DPI 行为进行 lint。面向研究或扩展 PES 2021 客户端内部机制与实时游戏状态的逆向工程师、内存编辑者与 MOD 研究者，而非作为独立应用发布。
