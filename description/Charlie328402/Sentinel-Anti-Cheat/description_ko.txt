Sentinel AntiCheat는 NeoForge Minecraft 서버용 서버 측 안티치트 시스템으로, tick 및 이벤트 기반 검사를 통해 이동, 전투, 월드 치트를 탐지합니다. Java mod는 mixin이나 패킷 가로채기 없이 속도, 비행, 물 위 걷기, reach, KillAura, 오토클리커, X-Ray 채굴 패턴을 모니터링하며 각 위반을 JSONL 파일에 기록합니다. 함께 제공되는 Python Discord 봇은 해당 로그를 tail하고, 형식화된 embed를 채널에 게시하며, 누적 위반 수준이 설정 가능한 임계값을 넘으면 스태프에게 ping하고, 이력을 관계형 데이터베이스에 영구 저장하며 선택적으로 FTP 로그 미러링을 수행합니다. 이 설계는 자동 밴이나 킥을 의도적으로 피하고, 치트가 빈번한 멀티플레이 월드를 관리하는 서버 관리자를 위해 스태프 알림과 감사 추적에 초점을 맞춥니다.
