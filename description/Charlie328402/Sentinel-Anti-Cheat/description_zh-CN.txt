Sentinel AntiCheat 是一款面向 NeoForge Minecraft 服务端的反作弊系统，通过基于 tick 和事件的检测来识别移动、战斗与世界类作弊行为。该 Java 模组在不使用 mixin 或数据包拦截的前提下，监控速度、飞行、水上行走、攻击距离、KillAura、自动点击和 X-Ray 挖矿等模式，并将每次违规记录写入 JSONL 文件。配套的 Python Discord 机器人会跟踪该日志，向频道发送格式化的 embed 消息，在累计违规等级超过可配置阈值时 @ 管理人员，并将历史记录持久化到关系型数据库，还可选通过 FTP 镜像日志。该设计刻意避免自动封禁或踢出，专注于向管理人员告警并提供审计追踪，供管理易受作弊影响的多人世界的服务器管理员使用。
