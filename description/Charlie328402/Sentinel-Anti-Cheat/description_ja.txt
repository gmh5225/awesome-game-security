Sentinel AntiCheat は、NeoForge 版 Minecraft サーバー向けのサーバーサイド反チートシステムで、tick およびイベントベースのチェックにより移動、戦闘、ワールド関連のチートを検出します。Java 製 mod は mixin やパケット傍受を使わず、速度、飛行、水上歩行、リーチ、KillAura、オートクリッカー、X-Ray 採掘パターンを監視し、各違反を JSONL ファイルに記録します。付属の Python 製 Discord ボットがそのログを tail し、フォーマット済み embed をチャンネルに投稿し、累積違反レベルが設定可能なしきい値を超えた際にスタッフに ping し、履歴をリレーショナル DB に永続化し、任意で FTP によるログミラーリングも行います。自動 BAN やキックは意図的に避け、チートが多発しやすいマルチプレイワールドを管理するサーバー管理者向けに、スタッフへの通知と監査証跡に重点を置いています。
