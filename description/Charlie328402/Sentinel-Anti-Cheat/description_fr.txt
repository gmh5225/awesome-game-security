Sentinel AntiCheat est un système anti-triche côté serveur pour les serveurs Minecraft NeoForge qui détecte les triches de mouvement, de combat et de monde via des contrôles basés sur les ticks et les événements. Le mod Java surveille la vitesse, le vol, la marche sur l'eau, la portée, le killaura, l'autoclicker et les schémas de minage X-Ray sans mixins ni interception de paquets, en enregistrant chaque violation dans un fichier JSONL. Un bot Discord Python compagnon suit ce journal, publie des embeds formatés dans un canal, alerte le staff lorsque les niveaux cumulés de violations dépassent un seuil configurable, et persiste l'historique dans une base de données relationnelle avec une mise en miroir optionnelle des logs via FTP. La conception évite délibérément les bannissements ou expulsions automatiques, en se concentrant sur l'alerte du staff et les pistes d'audit pour les administrateurs de serveurs gérant des mondes multijoueurs sujets à la triche.
