Sentinel AntiCheat è un sistema anti-cheat lato server per server Minecraft NeoForge che rileva cheat di movimento, combattimento e mondo tramite controlli basati su tick ed eventi. La mod Java monitora velocità, volo, camminata sull'acqua, reach, killaura, autoclicker e pattern di mining X-Ray senza mixin o intercettazione dei pacchetti, registrando ogni violazione in un file JSONL. Un bot Discord companion in Python segue tale log, pubblica embed formattati in un canale, avvisa lo staff quando i livelli cumulativi di violazione superano una soglia configurabile e persiste la cronologia in un database relazionale con mirror opzionale dei log via FTP. Il design evita deliberatamente ban o kick automatici, concentrandosi su alert allo staff e audit trail per gli amministratori di server che gestiscono mondi multigiocatore soggetti a cheat.
