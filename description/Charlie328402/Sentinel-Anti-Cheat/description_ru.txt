Sentinel AntiCheat — серверная античит-система для Minecraft-серверов на NeoForge, обнаруживающая читы движения, боя и взаимодействия с миром через проверки на основе тиков и событий. Java-мод отслеживает скорость, полёт, хождение по воде, reach, killaura, автокликер и паттерны X-Ray-добычи без mixins и перехвата пакетов, записывая каждое нарушение в JSONL-файл. Сопутствующий Discord-бот на Python отслеживает этот лог, публикует форматированные embed в канал, уведомляет персонал при превышении накопленным уровнем нарушений настраиваемого порога и сохраняет историю в реляционной БД с опциональным зеркалированием логов по FTP. Архитектура намеренно не использует автоматические баны или кики, сосредотачиваясь на оповещении персонала и аудит-трейлах для администраторов серверов с мультиплеерными мирами, склонными к читам.
