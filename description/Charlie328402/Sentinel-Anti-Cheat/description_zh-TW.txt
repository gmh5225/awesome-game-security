Sentinel AntiCheat 是一款面向 NeoForge Minecraft 伺服器的伺服器端反作弊系統，透過以 tick 與事件為基礎的檢查來偵測移動、戰鬥與世界類作弊行為。此 Java 模組在不使用 mixin 或封包攔截的情況下，監控速度、飛行、水上行走、攻擊距離、KillAura、自動點擊與 X-Ray 挖礦等模式，並將每次違規記錄寫入 JSONL 檔案。配套的 Python Discord 機器人會追蹤該日誌，向頻道發送格式化的 embed 訊息，在累計違規等級超過可設定閾值時 ping 管理人員，並將歷史記錄持久化至關聯式資料庫，還可選擇透過 FTP 鏡像日誌。此設計刻意避免自動封禁或踢出，專注於向管理人員告警並提供稽核軌跡，供管理易受作弊影響的多人世界之伺服器管理員使用。
