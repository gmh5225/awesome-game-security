KN Win32 API Monitor는 Windows 10/11용 최신 워크스테이션으로, 사용자 모드 프로세스의 Win32 API 활동을 추적하고 분석합니다. 네이티브 C++ 헬퍼가 동일 비트 수 대상을 실행하거나 연결한 뒤 모니터링 에이전트를 주입하여 IAT 후크와 공유 메모리 이벤트 전송으로 호출을 캡처하며, GetProcAddress 및 LdrGetProcedureAddress에 대한 동적 리졸버 대체도 포함하여 약 30,000개의 런타임 모니터링 가능 API를 지원합니다. 추적은 영구적인 .knapm 재생 세션으로 저장되며, 카탈로그 인덱싱, 타임라인 보기, 필터링, 강조 표시, 전체 텍스트 검색을 제공하고, 생성된 API 정의 메타데이터로 인수 디코딩 및 열거형·플래그 렌더링을 지원합니다. 데스크톱 프런트엔드는 Tauri 2와 React, TypeScript를 사용하며 Rust가 UI와 네이티브 구성 요소 사이의 명령 계층을 처리합니다. 보안 엔지니어링, 리버스 엔지니어링, 디버깅, 안티치트 연구 워크플로에 적합합니다.
