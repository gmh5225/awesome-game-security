KN Win32 API Monitor — это современная рабочая станция для Windows 10/11, предназначенная для трассировки и анализа активности Win32 API в пользовательских процессах. Нативный помощник на C++ запускает или подключается к целям той же разрядности и внедряет агент мониторинга, который перехватывает вызовы через IAT-хуки и транспорт событий через разделяемую память, включая динамическую подмену резолверов для GetProcAddress и LdrGetProcedureAddress среди примерно 30 000 API, доступных для мониторинга во время выполнения. Трассы сохраняются как долговечные сессии воспроизведения .knapm с индексацией каталога, представлениями временной шкалы, фильтрацией, подсветкой и полнотекстовым поиском, опираясь на сгенерированные метаданные определений API для декодирования аргументов и отображения перечислений или флагов. Настольный интерфейс построен на Tauri 2 с React и TypeScript, а Rust обрабатывает командный слой между UI и нативными компонентами. Предназначен для задач инженерии безопасности, реверс-инжиниринга, отладки и исследований античит-систем.
