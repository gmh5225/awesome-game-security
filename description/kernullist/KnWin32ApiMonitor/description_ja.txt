KN Win32 API Monitor は、Windows 10/11 向けのモダンなワークステーションで、ユーザーモードプロセスにおける Win32 API アクティビティのトレースと分析を行います。ネイティブ C++ ヘルパーが同一ビット数のターゲットを起動またはアタッチし、IAT フックと共有メモリによるイベント転送で呼び出しを捕捉する監視エージェントを注入します。GetProcAddress および LdrGetProcedureAddress の動的リゾルバー置換も含み、約 30,000 の実行時監視可能な API に対応します。トレースは永続的な .knapm リプレイセッションとして保存され、カタログインデックス、タイムラインビュー、フィルタリング、ハイライト、全文検索を備え、生成された API 定義メタデータにより引数のデコードや列挙型・フラグのレンダリングを支援します。デスクトップフロントエンドは Tauri 2 と React、TypeScript を使用し、Rust が UI とネイティブコンポーネント間のコマンドレイヤーを担当します。セキュリティエンジニアリング、リバースエンジニアリング、デバッグ、反チート研究のワークフロー向けです。
