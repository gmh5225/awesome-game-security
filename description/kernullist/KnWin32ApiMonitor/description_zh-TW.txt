KN Win32 API Monitor 是一款適用於 Windows 10/11 的現代化工作站，用於追蹤與分析使用者模式程序中的 Win32 API 活動。原生 C++ 輔助程式可啟動或附加至相同位元數的目標程序，並注入監控代理，透過 IAT 掛鉤與共享記憶體事件傳輸擷取呼叫，包括對 GetProcAddress 與 LdrGetProcedureAddress 的動態解析器替換，涵蓋約 30,000 個可在執行階段監控的 API。追蹤資料以持久的 .knapm 重播工作階段形式保存，支援目錄索引、時間軸檢視、篩選、標示與全文搜尋，並以產生的 API 定義中繼資料支援引數解碼及列舉或旗標渲染。桌面前端採用 Tauri 2 搭配 React 與 TypeScript，Rust 負責 UI 與原生元件之間的命令層。適用於安全工程、逆向工程、除錯及反作弊研究等工作流程。
