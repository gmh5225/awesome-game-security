KN Win32 API Monitor 是一款适用于 Windows 10/11 的现代化工作台，用于跟踪和分析用户态进程中的 Win32 API 活动。原生 C++ 辅助程序可启动或附加到相同位宽的目标进程，并注入监控代理，通过 IAT 钩子与共享内存事件传输捕获调用，包括对 GetProcAddress 和 LdrGetProcedureAddress 的动态解析器替换，覆盖约 30,000 个可在运行时监控的 API。跟踪数据以持久的 .knapm 重放会话形式保存，支持目录索引、时间线视图、筛选、高亮和全文搜索，并依托生成的 API 定义元数据实现参数解码及枚举或标志位渲染。桌面前端采用 Tauri 2 配合 React 和 TypeScript，Rust 负责 UI 与原生组件之间的命令层。适用于安全工程、逆向工程、调试及反作弊研究等工作流程。
