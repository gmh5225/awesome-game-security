Apprentice は、サーバー、テレメトリ、常時オンラインのクライアントを必要とせず、PC ゲームのプロセスに直接アタッチできる無料のオープンソース Windows ゲームトレーナー兼オフラインメモリエディターです。Electron、React、TypeScript 上に C++ N-API ネイティブアドオンを組み合わせて構築されており、値のチート、複数の注入モードによるコードパッチ、サンドボックス化された Lua スクリプト、Cheat Engine テーブルのインポートとエクスポートをサポートします。ネイティブ層はメモリスキャン、ポインタチェーン解決、ハードウェアブレークポイントによる書き込み監視、Zydis ベースの逆アセンブル、Unity ベースのゲーム向けの深い Mono JIT イントロスペクションを提供します。同梱の読み取り専用 MCP サーバーは、同じイントロスペクションのプリミティブを AI コーディングエージェントに公開し、ライブなリバースエンジニアリングとチート開発ワークフローを支援します。オフラインのゲーム modding、メモリ解析、リバースエンジニアリングを対象としており、Valheim や Elden Ring などのタイトル向けの既製チートプロファイルも用意されています。
