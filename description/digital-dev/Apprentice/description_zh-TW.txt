Apprentice 是一款免費、開源的 Windows 遊戲修改器與離線記憶體編輯器，可直接附加至 PC 遊戲程序，無需伺服器、遙測或始終連線的用戶端。它基於 Electron、React 和 TypeScript 建構，底層採用 C++ N-API 原生外掛，支援數值修改、多種注入模式的程式碼修補、沙箱化 Lua 腳本，以及 Cheat Engine 資料表的匯入與匯出。原生層提供記憶體掃描、指標鏈解析、硬體中斷點寫入監控、基於 Zydis 的反組譯，以及對 Unity 遊戲的深度 Mono JIT 內省。內建的唯讀 MCP 伺服器將相同的內省原語暴露給 AI 程式設計代理，用於即時逆向工程與修改器開發工作流程。它面向離線遊戲模組、記憶體分析與逆向工程，並為 Valheim、Elden Ring 等遊戲提供現成的修改設定檔。
