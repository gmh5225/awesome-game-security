Apprentice는 서버, 원격 측정, 상시 온라인 클라이언트 없이 PC 게임 프로세스에 직접 연결되는 무료 오픈소스 Windows 게임 트레이너 및 오프라인 메모리 편집기입니다. Electron, React, TypeScript 위에 C++ N-API 네이티브 애드온으로 구축되었으며, 값 치트, 여러 주입 모드를 지원하는 코드 패치, 샌드박스화된 Lua 스크립팅, Cheat Engine 테이블 가져오기 및 내보내기를 지원합니다. 네이티브 계층은 메모리 스캔, 포인터 체인 해석, 하드웨어 브레이크포인트 쓰기 감시, Zydis 기반 디스어셈블리, Unity 기반 게임을 위한 심층 Mono JIT 인트로스펙션을 제공합니다. 번들된 읽기 전용 MCP 서버는 동일한 인트로스펙션 기본 요소를 AI 코딩 에이전트에 노출하여 실시간 리버스 엔지니어링 및 치트 개발 워크플로를 지원합니다. 오프라인 게임 모딩, 메모리 분석, 리버스 엔지니어링을 목표로 하며, Valheim 및 Elden Ring 같은 타이틀을 위한 기성 치트 프로필도 제공합니다.
