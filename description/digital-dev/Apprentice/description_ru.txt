Apprentice — это бесплатный тренер для игр под Windows с открытым исходным кодом и офлайн-редактор памяти, который подключается напрямую к процессам PC-игр без необходимости в сервере, телеметрии или постоянно онлайн-клиенте. Построен на Electron, React и TypeScript с использованием нативного аддона C++ N-API; поддерживает читы на значения, патчи кода с несколькими режимами инъекции, песочничный Lua-скриптинг, а также импорт и экспорт таблиц Cheat Engine. Нативный слой обеспечивает сканирование памяти, разрешение цепочек указателей, отслеживание записей через аппаратные точки останова, дизассемблирование на базе Zydis и глубокую интроспекцию Mono JIT для игр на Unity. Встроенный сервер MCP только для чтения предоставляет те же примитивы интроспекции AI-агентам для кодирования в рамках живых рабочих процессов реверс-инжиниринга и разработки читов. Ориентирован на офлайн-моддинг игр, анализ памяти и реверс-инжиниринг; включает готовые профили читов для таких игр, как Valheim и Elden Ring.
