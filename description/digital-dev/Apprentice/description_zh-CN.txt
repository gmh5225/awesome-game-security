Apprentice 是一款免费、开源的 Windows 游戏修改器与离线内存编辑器，可直接附加到 PC 游戏进程，无需服务器、遥测或始终在线的客户端。它基于 Electron、React 和 TypeScript 构建，底层采用 C++ N-API 原生插件，支持数值修改、多种注入模式的代码补丁、沙箱化 Lua 脚本，以及 Cheat Engine 表的导入与导出。原生层提供内存扫描、指针链解析、硬件断点写入监控、基于 Zydis 的反汇编，以及对 Unity 游戏的深度 Mono JIT 内省。内置的只读 MCP 服务器将相同的内省原语暴露给 AI 编程代理，用于实时逆向工程与修改器开发工作流。它面向离线游戏模组、内存分析与逆向工程，并为 Valheim、Elden Ring 等游戏提供现成的修改配置。
