VMProtect Dumper — автономная консольная утилита для Windows, которая распаковывает PE-файлы (EXE, DLL, OCX и CPL), защищённые VMProtect, из памяти работающего процесса и создаёт дампы, готовые к анализу. Написана на чистом C с использованием только WinAPI: опрашивает память для обнаружения расшифровки секций, восстанавливает исходную точку входа и таблицу адресов импорта через отслеживание thunk и API-хуки, а также собирает динамически выделенные исполняемые области памяти за пределами исходной раскладки образа. Поддерживает перетаскивание, режимы dropper и загрузки DLL, опциональную интеграцию с PE-sieve, извлечение строк IOC, контрмеры против анализа и упаковывает все артефакты в архив, защищённый паролем, для безопасной обработки. Инструмент предназначен для аналитиков вредоносного ПО, специалистов по реверс-инжинирингу и реагированию на инциденты, которым нужно извлекать распакованные образы из образцов, упакованных VMProtect, для статического анализа в IDA, Ghidra и подобных инструментах.
