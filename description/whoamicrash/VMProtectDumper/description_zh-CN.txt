VMProtect Dumper 是一款独立的 Windows 控制台工具，可从运行中的进程内存中解包受 VMProtect 保护的 PE 文件（EXE、DLL、OCX 和 CPL），并生成便于分析的转储。该工具采用纯 C 编写，仅依赖 WinAPI，通过轮询检测区段解密、经 thunk 追踪与 API 钩子重建原始入口点和导入地址表，并收集原始映像布局之外动态分配的可执行内存区域。它支持拖放操作、dropper 与 DLL 加载模式、可选的 PE-sieve 集成、IOC 字符串提取、反分析对策，并将所有产物打包为受密码保护的压缩包以便安全处理。该工具面向需要从 VMProtect 加壳样本中提取解包映像、以便在 IDA 或 Ghidra 等工具中进行静态分析的恶意软件分析师、逆向工程师和事件响应人员。
