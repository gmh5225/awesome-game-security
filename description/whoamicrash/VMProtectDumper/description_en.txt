VMProtect Dumper is a standalone Windows console utility that unpacks VMProtect-protected PE files (EXE, DLL, OCX, and CPL) from live process memory and produces analysis-ready dumps. Written in pure C with WinAPI only, it polls for section decryption, reconstructs the original entry point and import address table via thunk following and API hooks, and harvests dynamically allocated executable memory regions outside the original image layout. It supports drag-and-drop operation, dropper and DLL loading modes, optional PE-sieve integration, IOC string extraction, anti-analysis countermeasures, and packages all artifacts into a password-protected archive for safe handling. The tool targets malware analysts, reverse engineers, and incident responders who need to extract unpacked images from VMProtect-packed samples for static analysis in tools such as IDA or Ghidra.
