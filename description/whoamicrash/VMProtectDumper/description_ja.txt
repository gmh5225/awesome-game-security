VMProtect Dumper は、実行中プロセスのメモリから VMProtect で保護された PE ファイル（EXE、DLL、OCX、CPL）をアンパックし、解析に適したダンプを生成するスタンドアロンの Windows コンソールユーティリティです。純粋な C と WinAPI のみで実装され、セクション復号をポーリングで監視し、thunk 追跡と API フックにより元のエントリポイントとインポートアドレス表を再構築し、元のイメージレイアウト外に動的に割り当てられた実行可能メモリ領域も収集します。ドラッグ＆ドロップ操作、dropper および DLL 読み込みモード、オプションの PE-sieve 連携、IOC 文字列抽出、反解析対策をサポートし、すべての成果物をパスワード保護アーカイブにまとめて安全に扱えます。VMProtect でパックされたサンプルからアンパック済みイメージを抽出し、IDA や Ghidra などのツールで静的解析を行う必要があるマルウェアアナリスト、リバースエンジニア、インシデントレスポンダーを対象としています。
