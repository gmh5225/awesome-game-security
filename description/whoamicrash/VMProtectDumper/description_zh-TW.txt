VMProtect Dumper 是一款獨立的 Windows 主控台工具，可從執行中程序的記憶體解包受 VMProtect 保護的 PE 檔案（EXE、DLL、OCX 與 CPL），並產生便於分析的傾印。此工具以純 C 撰寫，僅使用 WinAPI，透過輪詢偵測區段解密、以 thunk 追蹤與 API 掛鉤重建原始進入點與匯入位址表，並擷取原始映像配置之外動態配置的可執行記憶體區域。它支援拖放操作、dropper 與 DLL 載入模式、可選的 PE-sieve 整合、IOC 字串擷取、反分析對策，並將所有產物封裝為受密碼保護的封存檔以便安全處理。此工具面向需要從 VMProtect 加殼樣本中提取解包映像、以便在 IDA 或 Ghidra 等工具中進行靜態分析的惡意軟體分析師、逆向工程師與事件應變人員。
