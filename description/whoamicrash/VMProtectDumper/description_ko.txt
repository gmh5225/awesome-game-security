VMProtect Dumper는 실행 중인 프로세스 메모리에서 VMProtect로 보호된 PE 파일(EXE, DLL, OCX, CPL)을 언패킹하고 분석에 적합한 덤프를 생성하는 독립형 Windows 콘솔 유틸리티입니다. 순수 C와 WinAPI만으로 작성되었으며, 섹션 복호화를 폴링으로 감지하고, thunk 추적 및 API 후킹을 통해 원래 진입점과 가져오기 주소 테이블을 재구성하며, 원본 이미지 레이아웃 밖에 동적으로 할당된 실행 가능 메모리 영역도 수집합니다. 드래그 앤 드롭, dropper 및 DLL 로딩 모드, 선택적 PE-sieve 연동, IOC 문자열 추출, 반분석 대응을 지원하며, 모든 산출물을 비밀번호로 보호된 아카이브에 패키징하여 안전하게 다룰 수 있습니다. VMProtect로 패킹된 샘플에서 언패킹된 이미지를 추출해 IDA나 Ghidra 같은 도구에서 정적 분석이 필요한 악성코드 분석가, 리버스 엔지니어, 사고 대응 담당자를 대상으로 합니다.
