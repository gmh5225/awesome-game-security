Ghidra RE Workbench 是面向 Antigravity Desktop 的本機自包含逆向工程外掛，可依需求透過 loopback Java 守護程式以無頭方式執行 Ghidra，並透過互動式 Aux Pane 介面與 MCP 代理公開分析功能。它為每個二進位檔維護離線 SQLite 索引（含 FTS5），即使 JVM 已停止，仍可搜尋符號、字串、呼叫圖與快取偽程式碼；即時作業則使用優先順序反編譯器池、CFG 視覺化、同步的 C 與組語檢視，以及批次重新命名、改型別與註解操作。技術堆疊以 Java 承載 Ghidra 守護程式、以 Node.js 擔任 MCP 伺服器與工作台邊車，需要 Ghidra 12.2+、JDK 25+ 與 Node.js 26+。可設定的記憶體層級控制閒置自動卸載與工作執行緒數量，使分析人員與代理輔助工作流程能夠剖析二進位檔、追蹤控制流並維護專案狀態，而無需長期佔用沉重的 Ghidra 程序。
