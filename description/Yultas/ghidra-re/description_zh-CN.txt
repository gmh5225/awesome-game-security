Ghidra RE Workbench 是面向 Antigravity Desktop 的本地自包含逆向工程插件，按需通过 loopback Java 守护进程以无头方式运行 Ghidra，并通过交互式 Aux Pane 界面与 MCP 智能体开放分析能力。它为每个二进制文件维护离线的 SQLite 索引（含 FTS5），即便 JVM 已停止，仍可搜索符号、字符串、调用图与缓存伪代码；实时分析则使用优先级反编译器池、CFG 可视化、同步的 C 与汇编视图，以及批量重命名、改类型与注释操作。技术栈以 Java 承载 Ghidra 守护进程、以 Node.js 承担 MCP 服务器与工作台边车，需要 Ghidra 12.2+、JDK 25+ 与 Node.js 26+。可配置的内存档位控制空闲自动卸载与工作进程数量，使分析人员与智能体辅助工作流能够剖析二进制、追踪控制流并维护项目状态，而无需长期占用沉重的 Ghidra 进程。
