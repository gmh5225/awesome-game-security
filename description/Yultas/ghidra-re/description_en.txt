Ghidra RE Workbench is a self-contained local reverse engineering plugin for Antigravity Desktop that runs headless Ghidra on demand behind a loopback Java daemon and exposes analysis through an interactive Aux Pane UI and MCP agents. It keeps a per-binary offline SQLite index with FTS5 so you can search symbols, strings, call graphs, and cached pseudocode even when the JVM is stopped, while live work uses a priority decompiler pool, CFG visualization, synchronized C and assembly views, and batch rename, retype, and comment operations. The stack combines Java for the Ghidra daemon, Node.js for the MCP server and workbench sidecar, and requires Ghidra 12.2+, JDK 25+, and Node.js 26+. Configurable RAM tiers control idle auto-unload and worker counts so analysts and agent-assisted workflows can dissect binaries, trace control flow, and maintain project state without keeping a heavy Ghidra process running all the time.
