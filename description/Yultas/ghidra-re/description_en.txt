Ghidra RE Workbench is a self-contained plugin that brings headless Ghidra reverse engineering into Antigravity Desktop via a lazily started local JVM daemon, an offline searchable index, MCP tools, and an interactive workbench. The stack centers on Java for the GhidraLaunchable daemon and decompiler pool, plus Node.js for the MCP server, SQLite FTS5 symbol and pseudocode indexing, and a browser-based Aux Pane with synchronized C and assembly views, control-flow graphs, call trees, and inline renaming and comments. It binds the daemon to loopback with bearer authentication, tiers memory and worker priority for UI versus agent workloads, and keeps browsing useful even when the JVM is stopped. The project targets analysts and security researchers who need efficient binary analysis, automation-friendly MCP access, and agent-assisted workflows for game clients, anti-cheat modules, and other native targets.
