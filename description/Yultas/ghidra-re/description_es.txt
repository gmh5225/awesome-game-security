Ghidra RE Workbench es un complemento local autocontenido de ingeniería inversa para Antigravity Desktop que ejecuta Ghidra sin interfaz bajo demanda detrás de un demonio Java en loopback y expone el análisis mediante una UI interactiva Aux Pane y agentes MCP. Mantiene un índice SQLite sin conexión por binario con FTS5 para buscar símbolos, cadenas, grafos de llamadas y pseudocódigo en caché incluso cuando la JVM está detenida, mientras el trabajo en vivo usa un pool de descompiladores con prioridad, visualización CFG, vistas C y ensamblador sincronizadas y operaciones por lotes de renombrado, retipado y comentarios. La pila combina Java para el demonio Ghidra, Node.js para el servidor MCP y el sidecar del workbench, y requiere Ghidra 12.2+, JDK 25+ y Node.js 26+. Niveles de RAM configurables controlan la descarga automática en inactividad y el número de workers para que analistas y flujos asistidos por agentes puedan diseccionar binarios, rastrear el flujo de control y mantener el estado del proyecto sin mantener un proceso Ghidra pesado en ejecución constante.
