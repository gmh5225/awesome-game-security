Ghidra RE Workbench è un plugin locale autonomo di reverse engineering per Antigravity Desktop che esegue Ghidra headless on demand dietro un demone Java in loopback ed espone l’analisi tramite un’interfaccia Aux Pane interattiva e agenti MCP. Mantiene un indice SQLite offline per ogni binario con FTS5 per cercare simboli, stringhe, grafi delle chiamate e pseudocodice in cache anche quando la JVM è ferma, mentre il lavoro live usa un pool di decompilatori prioritari, visualizzazione CFG, viste C e assembly sincronizzate e operazioni batch di rinomina, retyping e commenti. Lo stack combina Java per il demone Ghidra, Node.js per il server MCP e il sidecar del workbench, e richiede Ghidra 12.2+, JDK 25+ e Node.js 26+. Livelli RAM configurabili controllano lo scaricamento automatico in idle e il numero di worker così analisti e flussi assistiti da agenti possono analizzare binari, tracciare il flusso di controllo e mantenere lo stato del progetto senza tenere sempre in esecuzione un processo Ghidra pesante.
