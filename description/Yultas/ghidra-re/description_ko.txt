Ghidra RE Workbench는 Antigravity Desktop용 자체 포함형 로컬 리버스 엔지니어링 플러그인으로, 루프백 Java 데몬 뒤에서 요청 시 헤드리스 Ghidra를 실행하고 대화형 Aux Pane UI와 MCP 에이전트를 통해 분석을 제공합니다. 바이너리마다 FTS5가 포함된 오프라인 SQLite 인덱스를 유지해 JVM이 중지된 상태에서도 심볼, 문자열, 호출 그래프, 캐시된 의사코드를 검색할 수 있으며, 실시간 작업은 우선순위 디컴파일러 풀, CFG 시각화, 동기화된 C 및 어셈블리 뷰, 일괄 이름 변경·타입 변경·주석 작업을 사용합니다. 스택은 Ghidra 데몬에 Java, MCP 서버와 워크벤치 사이드카에 Node.js를 사용하며 Ghidra 12.2+, JDK 25+, Node.js 26+가 필요합니다. 구성 가능한 RAM 티어가 유휴 자동 언로드와 워커 수를 제어해 분석가와 에이전트 보조 워크플로가 무거운 Ghidra 프로세스를 항상 띄우지 않고도 바이너리를 분해하고 제어 흐름을 추적하며 프로젝트 상태를 유지할 수 있습니다.
