Ghidra RE Workbench — автономный локальный плагин реверс-инжиниринга для Antigravity Desktop: по запросу запускает headless Ghidra за Java-демоном на loopback и отдаёт анализ через интерактивный Aux Pane и MCP-агентов. Для каждого бинарника ведётся офлайн-индекс SQLite с FTS5, чтобы искать символы, строки, графы вызовов и кэшированный псевдокод даже при остановленной JVM; живая работа использует пул декомпиляторов с приоритетами, визуализацию CFG, синхронизированные представления C и ассемблера, пакетное переименование, смену типов и комментарии. Стек: Java для демона Ghidra, Node.js для MCP-сервера и sidecar workbench; нужны Ghidra 12.2+, JDK 25+ и Node.js 26+. Настраиваемые уровни RAM управляют авто-выгрузкой в простое и числом воркеров, чтобы аналитики и агентные сценарии разбирали бинарники, отслеживали поток управления и состояние проекта без постоянного тяжёлого процесса Ghidra.
