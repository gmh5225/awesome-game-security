Ghidra RE Workbench は Antigravity Desktop 向けの自己完結型ローカルリバースエンジニアリングプラグインで、ループバック Java デーモン経由でオンデマンドのヘッドレス Ghidra を実行し、インタラクティブな Aux Pane UI と MCP エージェントを通じて解析を提供します。バイナリごとにオフライン SQLite インデックス（FTS5 付き）を保持するため、JVM が停止していてもシンボル、文字列、コールグラフ、キャッシュされた疑似コードを検索できます。ライブ作業では優先度付きデコンパイラプール、CFG 可視化、同期した C とアセンブリビュー、一括のリネーム・型変更・コメント操作を利用します。スタックは Ghidra デーモンに Java、MCP サーバーとワークベンチサイドカーに Node.js を組み合わせ、Ghidra 12.2+、JDK 25+、Node.js 26+ が必要です。設定可能な RAM ティアがアイドル時の自動アンロードとワーカー数を制御し、解析者とエージェント支援ワークフローが、常時重い Ghidra プロセスを動かさずにバイナリを分解し、制御フローを追跡し、プロジェクト状態を維持できます。
