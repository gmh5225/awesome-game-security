Syferit is an open-core build-time code defense engine that hardens applications and binaries before release to resist automated reverse engineering, decompilation, and clean-room logic recovery. The project is a TypeScript and JavaScript monorepo distributed as npm packages and standalone CLI binaries, applying techniques such as non-linear residue entanglement, polynomial mixed boolean-arithmetic obfuscation, polymorphic micro-VM virtualization, opaque control-flow flattening, and runtime tamper attestation. It supports JavaScript, TypeScript, WebAssembly, LLVM IR, native C and C++, Rust, C# and Unity, Python, Electron, and common mobile languages, with integrations for Vite, Webpack, Next.js, and GitHub Actions. Teams in game security, anti-tamper, and anti-cheat workflows can use it to shield proprietary client logic, licensing validation, and other sensitive execution paths from symbolic analysis, SMT solvers, and AI-assisted RE tooling while preserving deterministic runtime behavior.
