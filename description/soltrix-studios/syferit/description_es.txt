Syferit es un motor de defensa de código en tiempo de compilación de núcleo abierto que endurece aplicaciones y binarios antes del lanzamiento para resistir la ingeniería inversa automatizada, la descompilación y la recuperación de lógica en entorno limpio. El proyecto es un monorepo en TypeScript y JavaScript distribuido como paquetes npm y binarios CLI independientes, aplicando técnicas como entrelazado de residuos no lineales, ofuscación booleano-aritmética mixta polinómica, virtualización micro-VM polimórfica, aplanamiento de flujo de control opaco y atestación de manipulación en tiempo de ejecución. Admite JavaScript, TypeScript, WebAssembly, LLVM IR, C y C++ nativos, Rust, C# y Unity, Python, Electron y lenguajes móviles habituales, con integraciones para Vite, Webpack, Next.js y GitHub Actions. Los equipos en seguridad de juegos, anti-manipulación y flujos anti-trampas pueden usarlo para proteger la lógica de cliente propietaria, la validación de licencias y otras rutas de ejecución sensibles frente al análisis simbólico, solvers SMT y herramientas de RE asistidas por IA, preservando un comportamiento determinista en tiempo de ejecución.
