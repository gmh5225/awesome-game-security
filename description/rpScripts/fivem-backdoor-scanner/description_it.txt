FiveM Backdoor Scanner è uno strumento di analisi statica che ispeziona le risorse del server FiveM alla ricerca di backdoor e pattern sospetti prima dell’esecuzione. Scritto in Node.js con moduli ES, analizza il Lua tramite luaparse e decomprime archivi ZIP con fflate scansionando file .lua e .js per loader nascosti, esecuzione remota di codice tramite HTTP e load(), offuscamento, letture di segreti, token trapelati, esecuzione shell e contenuti di pacchetti rischiosi usando un catalogo di regole versionato. Funziona interamente offline senza eseguire né caricare il codice bersaglio, supporta scansioni di cartelle e archivi con report JSON e codici di uscita adatti alla CI, ed espone una piccola API di libreria per strumenti personalizzati. Il pubblico principale sono proprietari e operatori di server FiveM che devono verificare script e pacchetti di risorse di terze parti per la sicurezza del game server e l’igiene della supply chain.
