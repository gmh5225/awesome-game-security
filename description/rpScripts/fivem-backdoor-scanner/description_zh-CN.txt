FiveM Backdoor Scanner 是一款静态分析工具，可在运行前检查 FiveM 服务器资源中的后门与可疑模式。它使用 Node.js 与 ES 模块编写，通过 luaparse 解析 Lua，用 fflate 解压 ZIP 归档，并扫描 .lua 与 .js 文件，依据版本化规则目录检测隐藏加载器、经 HTTP 与 load() 的远程代码执行、混淆、秘密读取、令牌泄露、Shell 执行以及高风险包内容。全程离线运行，不执行也不上传目标代码，支持文件夹与归档扫描，提供 JSON 报告及适合 CI 的退出码，并暴露小型库 API 供自定义工具集成。主要面向需要审查第三方脚本与资源包、保障游戏服务器安全与供应链卫生的 FiveM 服主与运维人员。
