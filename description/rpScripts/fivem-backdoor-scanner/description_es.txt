FiveM Backdoor Scanner es una herramienta de análisis estático que inspecciona los recursos del servidor FiveM en busca de puertas traseras y patrones sospechosos antes de ejecutarlos. Escrita en Node.js con módulos ES, analiza Lua con luaparse y descomprime archivos ZIP con fflate mientras escanea archivos .lua y .js en busca de cargadores ocultos, ejecución remota de código mediante HTTP y load(), ofuscación, lecturas de secretos, tokens filtrados, ejecución de shell y contenidos de paquetes de riesgo mediante un catálogo de reglas versionado. Funciona totalmente sin conexión, sin ejecutar ni subir el código objetivo, admite análisis de carpetas y archivos con informes JSON y códigos de salida aptos para CI, y expone una pequeña API de biblioteca para herramientas personalizadas. El público principal son propietarios y operadores de servidores FiveM que necesitan revisar scripts y paquetes de recursos de terceros para la seguridad del servidor de juego y la higiene de la cadena de suministro.
