FiveM Backdoor Scanner is a static analysis tool that inspects FiveM server resources for backdoors and suspicious patterns before you run them. Written in Node.js with ES modules, it parses Lua via luaparse and unpacks ZIP archives with fflate while scanning .lua and .js files for hidden loaders, remote code execution through HTTP and load(), obfuscation, secret reads, leaked tokens, shell execution, and risky package contents using a versioned rule catalog. It runs entirely offline with no execution or upload of target code, supports folder and archive scans with JSON reporting and CI-friendly exit codes, and exposes a small library API for custom tooling. The primary audience is FiveM server owners and operators who need to vet third-party scripts and resource packs for game server security and supply-chain hygiene.
