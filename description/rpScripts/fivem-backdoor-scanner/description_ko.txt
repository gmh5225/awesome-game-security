FiveM Backdoor Scanner는 FiveM 서버 리소스를 실행하기 전에 백도어와 의심스러운 패턴을 검사하는 정적 분석 도구입니다. Node.js와 ES 모듈로 작성되었으며, luaparse로 Lua를 파싱하고 fflate로 ZIP 아카이브를 풀면서 .lua 및 .js 파일을 스캔합니다. 버전 관리된 규칙 카탈로그를 사용해 숨겨진 로더, HTTP와 load()를 통한 원격 코드 실행, 난독화, 비밀 읽기, 토큰 유출, 셸 실행, 위험한 패키지 내용 등을 탐지합니다. 대상 코드의 실행이나 업로드 없이 완전 오프라인으로 동작하며, 폴더 및 아카이브 스캔, JSON 보고, CI 친화적 종료 코드를 지원하고 맞춤 도구를 위한 소형 라이브러리 API를 제공합니다. 주 이용자는 서드파티 스크립트와 리소스 팩을 검증해 게임 서버 보안과 공급망 위생을 유지해야 하는 FiveM 서버 소유자와 운영자입니다.
