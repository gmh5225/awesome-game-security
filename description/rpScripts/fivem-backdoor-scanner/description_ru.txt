FiveM Backdoor Scanner — инструмент статического анализа, который проверяет ресурсы сервера FiveM на бэкдоры и подозрительные шаблоны до их запуска. Написан на Node.js с ES-модулями: разбирает Lua через luaparse и распаковывает ZIP-архивы с помощью fflate, сканируя файлы .lua и .js на скрытые загрузчики, удалённое выполнение кода через HTTP и load(), обфускацию, чтение секретов, утечки токенов, выполнение shell и рискованное содержимое пакетов по версионированному каталогу правил. Работает полностью офлайн без выполнения и загрузки целевого кода, поддерживает сканирование папок и архивов с отчётами в JSON и кодами выхода, удобными для CI, и предоставляет небольшой API библиотеки для собственных инструментов. Основная аудитория — владельцы и операторы серверов FiveM, которым нужно проверять сторонние скрипты и пакеты ресурсов с точки зрения безопасности игрового сервера и гигиены цепочки поставок.
