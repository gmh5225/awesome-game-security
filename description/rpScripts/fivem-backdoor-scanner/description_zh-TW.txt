FiveM Backdoor Scanner 是一款靜態分析工具，可在執行前檢查 FiveM 伺服器資源中的後門與可疑模式。它以 Node.js 與 ES 模組撰寫，透過 luaparse 解析 Lua，用 fflate 解壓 ZIP 封存，並掃描 .lua 與 .js 檔案，依版本化規則目錄偵測隱藏載入器、經 HTTP 與 load() 的遠端程式碼執行、混淆、秘密讀取、權杖外洩、Shell 執行以及高風險套件內容。全程離線運作，不執行也不上傳目標程式碼，支援資料夾與封存掃描，提供 JSON 報告及適合 CI 的結束碼，並公開小型程式庫 API 供自訂工具整合。主要對象是需要審查第三方腳本與資源包、維護遊戲伺服器安全與供應鏈衛生的 FiveM 服主與維運人員。
