FiveM Backdoor Scanner は、FiveM サーバーリソースを実行前に静的解析し、バックドアや疑わしいパターンを検査するツールです。Node.js と ES モジュールで書かれ、luaparse で Lua を解析し、fflate で ZIP アーカイブを展開しながら、.lua と .js をスキャンします。バージョン管理されたルールカタログにより、隠しローダー、HTTP や load() 経由のリモートコード実行、難読化、シークレット読み取り、トークン漏洩、シェル実行、危険なパッケージ内容などを検出します。対象コードの実行やアップロードは一切行わず完全オフラインで動作し、フォルダとアーカイブのスキャン、JSON レポート、CI 向けの終了コードをサポートし、カスタムツール用の小さなライブラリ API も提供します。主な利用者は、サードパーティスクリプトやリソースパックを精査し、ゲームサーバーのセキュリティとサプライチェーンの衛生を守りたい FiveM サーバー所有者と運用者です。
