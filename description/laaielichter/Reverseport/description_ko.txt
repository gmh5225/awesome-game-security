ReversePort는 전용 게임 및 애플리케이션 포팅 엔진과 CLI 및 Model Context Protocol 서버를 통해 제공되는 심층 리버스 엔지니어링 분석 스택을 결합한 에이전트 지향 툴킷입니다. 포팅 계층은 코드베이스를 스캔하고 의존성 그래프를 구축하며 버전을 비교하고, Godot, Unity, IL2CPP 및 일반적인 게임 아카이브 형식 같은 대상에 엔진 마이그레이션 지식을 적용하며, 에이전트 스킬 팩이 포팅 계획, Godot 마이그레이션, 재빌드, 검증 같은 워크플로를 안내합니다. 분석 측면에서는 Ghidra, IDA Pro, Hopper, Kuna 등 디스어셈블러 및 디컴파일러와 JADX, Frida, LLDB, mitmproxy, pwndbg 같은 모바일·런타임 도구를 통합하고, 브리지는 TypeScript와 JavaScript뿐 아니라 Java 및 Python 헬퍼로 구현됩니다. 리버스 엔지니어, 게임 보안 연구자, AI 코딩 에이전트로 독점 게임 및 네이티브 바이너리를 포팅·재빌드·체계적으로 조사하고자 하는 개발자를 대상으로 합니다.
