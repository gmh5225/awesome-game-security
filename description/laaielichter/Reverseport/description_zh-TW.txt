ReversePort 是一套面向代理程式的工具包，將專用的遊戲與應用程式移植引擎，與透過 CLI 及 Model Context Protocol 伺服器公開的深度逆向分析堆疊整合在一起。移植層掃描程式碼庫、建立相依性圖、比對版本，並針對 Godot、Unity、IL2CPP 及常見遊戲封存格式等目標套用引擎遷移知識，同時代理技能包引導移植規劃、Godot 遷移、重建與驗證等工作流程。分析端整合 Ghidra、IDA Pro、Hopper、Kuna 等反組譯與反編譯工具，以及 JADX、Frida、LLDB、mitmproxy、pwndbg 等行動與執行階段工具，橋接實作採用 TypeScript 與 JavaScript，並輔以 Java 與 Python 輔助模組。面向逆向工程師、遊戲安全研究人員，以及希望借助 AI 程式設計代理完成移植、重建或系統性調查專有遊戲與原生二進位檔的開發者。
