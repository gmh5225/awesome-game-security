ReversePort は、専用のゲーム・アプリケーション移植エンジンと、CLI および Model Context Protocol サーバー経由で提供される深いリバースエンジニアリング分析スタックを一体にした、エージェント指向のツールキットです。移植レイヤはコードベースをスキャンし依存関係グラフを構築し、バージョンを比較し、Godot、Unity、IL2CPP、一般的なゲームアーカイブ形式などのターゲット向けにエンジン移行の知識を適用します。エージェント用スキルパックが移植計画、Godot 移行、再ビルド、検証などのワークフローを案内します。分析側では Ghidra、IDA Pro、Hopper、Kuna などの逆アセンブラ・デコンパイラに加え、JADX、Frida、LLDB、mitmproxy、pwndbg などのモバイル・ランタイムツールを統合し、ブリッジは TypeScript と JavaScript、および Java と Python のヘルパーで実装されています。リバースエンジニア、ゲームセキュリティ研究者、AI コーディングエージェントに移植・再ビルド・独自ゲームやネイティブバイナリの体系的調査を手伝わせたい開発者向けです。
