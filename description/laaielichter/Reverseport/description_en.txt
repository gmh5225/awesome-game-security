ReversePort is an agent-oriented toolkit that combines a dedicated game and application porting engine with a bundled deep reverse-engineering analysis stack exposed through a CLI and Model Context Protocol servers. The porting layer scans codebases, builds dependency graphs, compares versions, and applies engine migration knowledge for targets such as Godot, Unity, IL2CPP, and common game archive formats, while agent skill packs guide workflows like port planning, Godot migrations, rebuilds, and verification. The analysis side integrates disassemblers and decompilers including Ghidra, IDA Pro, Hopper, and Kuna, plus mobile and runtime tooling such as JADX, Frida, LLDB, mitmproxy, and pwndbg, with bridges implemented in TypeScript and JavaScript as well as Java and Python helpers. It is aimed at reverse engineers, game security researchers, and developers who want AI coding agents to help port, rebuild, or systematically investigate proprietary game and native binaries.
