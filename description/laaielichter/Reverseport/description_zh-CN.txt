ReversePort 是一套面向智能体的工具包，将专用的游戏与应用移植引擎与通过 CLI 和 Model Context Protocol 服务器暴露的深度逆向分析栈整合在一起。移植层扫描代码库、构建依赖图、比较版本，并针对 Godot、Unity、IL2CPP 及常见游戏归档格式等目标应用引擎迁移知识，同时智能体技能包引导移植规划、Godot 迁移、重建与验证等工作流。分析侧集成 Ghidra、IDA Pro、Hopper、Kuna 等反汇编与反编译工具，以及 JADX、Frida、LLDB、mitmproxy、pwndbg 等移动与运行时工具，桥接实现采用 TypeScript 与 JavaScript，并辅以 Java 与 Python 辅助模块。面向逆向工程师、游戏安全研究人员以及希望借助 AI 编程智能体完成移植、重建或系统性分析专有游戏与原生二进制文件的开发者。
