Vortex Anti-Cheat is a user-mode client-server anti-cheat system and engine patcher built for CrossFire private servers. It is implemented primarily in C++ and ties into MS SQL Server through stored procedures for session validation, heartbeats, and tiered bans including hardware ID enforcement. The client runs heuristic checks such as Direct3D9 hook inspection, CRC32 memory integrity, process and debugger scanning, and Microsoft Detours-based Win32 API hooks that decrypt protected game assets on the fly. A dedicated validation server uses TCP for authentication and heartbeats, UDP for live screen streaming and VOIP, an embedded HTTP web panel, and Discord WebSocket alerts for administrators. It targets operators who need game security and anti-cheat on legacy CrossFire deployments while also patching client limits and fixing long-standing engine bugs.
