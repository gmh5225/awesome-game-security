Vortex Anti-Cheat は、CrossFire プライベートサーバー向けのユーザーモード型クライアント・サーバー反チートシステムおよびエンジンパッチャーです。主に C++ で実装され、ストアドプロシージャ経由で MS SQL Server と連携し、セッション検証、ハートビート、ハードウェア ID 強制を含む段階的 BAN を行います。クライアントは Direct3D9 フック検査、CRC32 によるメモリ整合性チェック、プロセスおよびデバッガスキャン、Microsoft Detours ベースの Win32 API フックによる保護ゲームアセットのオンザフライ復号などのヒューリスティック検査を実行します。専用検証サーバーは認証とハートビートに TCP、ライブ画面ストリーミングと VOIP に UDP、組み込み HTTP Web パネル、管理者向け Discord WebSocket アラートを備えています。レガシー CrossFire 環境でゲームセキュリティと反チートが必要な運営者向けで、クライアント制限のパッチや長年残るエンジンバグの修正も行います。
