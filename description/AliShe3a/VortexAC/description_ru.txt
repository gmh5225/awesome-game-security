Vortex Anti-Cheat — пользовательская клиент-серверная система античита и патчер движка для частных серверов CrossFire. В основном реализована на C++ и связана с MS SQL Server через хранимые процедуры для проверки сессий, heartbeat и многоуровневых банов, включая принудительную привязку к hardware ID. Клиент выполняет эвристические проверки: инспекция хуков Direct3D9, целостность памяти CRC32, сканирование процессов и отладчиков, а также хуки Win32 API на базе Microsoft Detours, расшифровывающие защищённые игровые ресурсы на лету. Выделенный сервер валидации использует TCP для аутентификации и heartbeat, UDP для трансляции экрана и VOIP, встроенную HTTP веб-панель и оповещения администраторам через Discord WebSocket. Ориентирован на операторов, которым нужны безопасность игры и античит в унаследованных развёртываниях CrossFire, а также патчи лимитов клиента и исправление давних ошибок движка.
