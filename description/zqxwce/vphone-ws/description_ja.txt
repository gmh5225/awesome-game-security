vPhone Workstation は、仮想 iPhone 研究 VM を管理するためのグラフィカルインターフェースを提供するネイティブ macOS SwiftUI アプリケーションです。Apple の Virtualization.framework と PCC 研究ファームウェア上に構築された iOS および cloudOS 仮想マシンの参照、作成、起動、クローン、エクスポート、削除のために vphone-cli コマンドラインツールをラップしています。アプリには作成ウィザードがあり、最小限のハードニング変更から jailbreak や実験的プロファイルまでのセキュリティバリアントを選択でき、基盤となる CLI タスクの進捗をライブストリーミングで表示します。ホストの準備状況チェックでは、VM 起動前に vphone-cli のインストール、研究ゲスト権限、AMFI バイパスなどの前提条件を検証します。プラットフォームセキュリティとモバイルアプリケーションの挙動を分析するための制御された iOS サンドボックスを必要とするセキュリティ研究者、リバースエンジニア、開発者を対象としています。
