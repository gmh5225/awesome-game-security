GhostDebug는 코어 DLL을 주입하고 명명된 파이프를 통해 C# 명령줄 클라이언트로 제어하여 대상 프로세스에 부착하는 은밀한 Windows x64 디버거입니다. 주입 모듈은 Vectored Exception Handler를 통해 디버깅을 구현하며, 소프트웨어 INT3 중단점, 단일 스텝, 레지스터 검사 및 수정, 중단점 스크립팅을 지원하여 안티치트 및 안티디버그 검사에서 일반적으로 탐지하는 Win32 Debug API를 피합니다. CLI는 Iced 디스assembler로 실시간 명령어 뷰를 제공하고 JSON 메시지로 중단점 설정, 실행 재개, 대화형 코드 스텝을 수행합니다. 번들된 TestTarget은 IsDebuggerPresent, PEB BeingDebugged, NtQueryInformationProcess 등 일반적인 디버거 탐지 기법을 실행하여 세션이 보이지 않는 상태를 유지하는지 검증합니다. 보호된 Windows 프로세스를 대화형으로 디버깅해야 하는 게임 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
