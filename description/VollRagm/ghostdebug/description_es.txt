GhostDebug es un depurador sigiloso para Windows x64 que se adjunta a un proceso objetivo inyectando una DLL central y controlándolo desde un cliente de línea de comandos en C# a través de una tubería con nombre. El módulo inyectado implementa la depuración mediante un manejador de excepciones vectorizado con puntos de interrupción INT3 por software, ejecución paso a paso, inspección y modificación de registros, y scripting de puntos de interrupción, evitando la API de depuración Win32 que suelen detectar las comprobaciones anti-trampas y anti-depuración. La CLI utiliza el desensamblador Iced para vistas de instrucciones en vivo y mensajes JSON para establecer puntos de interrupción, reanudar la ejecución y avanzar por el código de forma interactiva. Un TestTarget incluido ejercita técnicas habituales de detección de depuradores como IsDebuggerPresent, PEB BeingDebugged y NtQueryInformationProcess para validar que la sesión permanece invisible. Está dirigido a investigadores de seguridad de juegos e ingenieros de ingeniería inversa que necesitan depuración interactiva de procesos Windows protegidos.
