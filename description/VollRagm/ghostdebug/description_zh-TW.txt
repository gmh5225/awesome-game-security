GhostDebug 是一款隱蔽的 Windows x64 偵錯器，透過注入核心 DLL 並經由命名管道由 C# 命令列用戶端控制，附加到目標程序。注入模組透過向量化例外處理常式實作偵錯，支援軟體 INT3 中斷點、單步執行、暫存器檢視與修改以及中斷點指令碼，從而避開反作弊與反偵錯檢測通常重點關注的 Win32 Debug API。CLI 使用 Iced 反組譯器提供即時指令檢視，並透過 JSON 訊息設定中斷點、恢復執行和互動式單步偵錯。內附的 TestTarget 會演練 IsDebuggerPresent、PEB BeingDebugged 和 NtQueryInformationProcess 等常見偵錯器偵測手段，以驗證工作階段保持不可見。它面向需要互動式偵錯受保護 Windows 程序的遊戲安全研究人員和逆向工程師。
