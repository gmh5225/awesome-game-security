GhostDebug は、コア DLL を注入し、名前付きパイプ経由で C# コマンドラインクライアントから制御することでターゲットプロセスにアタッチする、ステルス型の Windows x64 デバッガーです。注入モジュールは Vectored Exception Handler によるデバッグを実装し、ソフトウェア INT3 ブレークポイント、シングルステップ、レジスタの参照・変更、ブレークポイントスクリプトを提供し、アンチチートやアンチデバッグ検査で通常検出される Win32 Debug API を回避します。CLI は Iced 逆アセンブラでライブ命令ビューを提供し、JSON メッセージでブレークポイント設定、実行再開、対話的なステップ実行を行います。同梱の TestTarget は IsDebuggerPresent、PEB BeingDebugged、NtQueryInformationProcess など一般的なデバッガー検出手法を試し、セッションが不可視のまま維持されることを検証します。保護された Windows プロセスを対話的にデバッグする必要があるゲームセキュリティ研究者やリバースエンジニア向けです。
