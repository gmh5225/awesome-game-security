GhostDebug is a stealth Windows x64 debugger that attaches to a target process by injecting a core DLL and controlling it from a C# command-line client over a named pipe. The injected module implements debugging through a Vectored Exception Handler with software INT3 breakpoints, single-stepping, register inspection and modification, and breakpoint scripting, avoiding the Win32 Debug API that anti-cheat and anti-debug checks typically flag. The CLI uses the Iced disassembler for live instruction views and JSON messaging to set breakpoints, resume execution, and step through code interactively. A bundled TestTarget exercises common debugger-detection techniques such as IsDebuggerPresent, PEB BeingDebugged, and NtQueryInformationProcess to validate that the session stays invisible. It is aimed at game security researchers and reverse engineers who need interactive debugging of protected Windows processes.
