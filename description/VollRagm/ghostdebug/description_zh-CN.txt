GhostDebug 是一款隐蔽的 Windows x64 调试器，通过注入核心 DLL 并经由命名管道由 C# 命令行客户端控制，附加到目标进程。注入模块通过向量化异常处理程序实现调试，支持软件 INT3 断点、单步执行、寄存器查看与修改以及断点脚本，从而避开反作弊与反调试检测通常重点关注的 Win32 Debug API。CLI 使用 Iced 反汇编器提供实时指令视图，并通过 JSON 消息设置断点、恢复执行和交互式单步调试。捆绑的 TestTarget 会演练 IsDebuggerPresent、PEB BeingDebugged 和 NtQueryInformationProcess 等常见调试器检测手段，以验证会话保持不可见。它面向需要交互式调试受保护 Windows 进程的游戏安全研究人员和逆向工程师。
