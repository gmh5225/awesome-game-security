GhostDebug — скрытый отладчик Windows x64, который подключается к целевому процессу путём инъекции основной DLL и управляет им из клиента командной строки на C# через именованный канал. Внедрённый модуль реализует отладку через Vectored Exception Handler с программными точками останова INT3, пошаговым выполнением, просмотром и изменением регистров, а также скриптами точек останова, избегая Win32 Debug API, которую обычно обнаруживают проверки античита и антиотладки. CLI использует дизассемблер Iced для просмотра инструкций в реальном времени и JSON-сообщения для установки точек останова, возобновления выполнения и интерактивного пошагового прохода по коду. В комплекте TestTarget проверяет распространённые методы обнаружения отладчика, такие как IsDebuggerPresent, PEB BeingDebugged и NtQueryInformationProcess, чтобы убедиться, что сеанс остаётся невидимым. Предназначен для исследователей безопасности игр и reverse-инженеров, которым нужна интерактивная отладка защищённых процессов Windows.
