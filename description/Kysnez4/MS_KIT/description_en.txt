MS_KIT is an unofficial mod loader and authoring framework for the Android game Magic Survival, distributed as the side-by-side Zombix client that runs without root. The current stack centers on a C# ModKit core built on MelonLoader with Harmony and Il2CppInterop, providing zip-based mods, in-game enablement UI, hooks, events, and shared libraries for combat, spells, artifacts, effects, and game data. An older Frida-based generation supports TypeScript and JavaScript mods for table and effect tweaks. The repository includes build and deploy tooling, example mods, game table references, and documentation aimed at developers who want to extend or reverse-engineer IL2CPP gameplay on device.
