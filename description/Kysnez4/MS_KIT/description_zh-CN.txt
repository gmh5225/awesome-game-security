MS_KIT 是 Android 游戏 Magic Survival 的非官方模组加载器与创作框架，以无需 root 即可运行的 side-by-side Zombix 客户端形式分发。当前技术栈以基于 MelonLoader、Harmony 与 Il2CppInterop 的 C# ModKit 核心为中心，提供 zip 模组、游戏内启用界面、钩子、事件，以及战斗、法术、神器、效果与游戏数据的共享库。较早一代基于 Frida，支持用 TypeScript 与 JavaScript 编写模组以调整表与效果。仓库包含构建与部署工具、示例模组、游戏表参考及文档，面向希望在设备上扩展或逆向 IL2CPP 玩法的开发者。
