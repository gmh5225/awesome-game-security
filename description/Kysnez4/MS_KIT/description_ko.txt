MS_KIT은 Android 게임 Magic Survival용 비공식 모드 로더 및 제작 프레임워크로, root 없이 실행되는 side-by-side Zombix 클라이언트 형태로 배포됩니다. 현재 스택은 MelonLoader, Harmony, Il2CppInterop 위에 구축된 C# ModKit 코어를 중심으로 zip 기반 모드, 게임 내 활성화 UI, 훅, 이벤트, 전투·주문·유물·효과·게임 데이터용 공유 라이브러리를 제공합니다. 이전 세대는 Frida 기반으로 테이블 및 효과 조정을 위한 TypeScript·JavaScript 모드를 지원합니다. 저장소에는 빌드·배포 도구, 예제 모드, 게임 테이블 참조, 기기에서 IL2CPP 게임플레이를 확장하거나 리버스 엔지니어링하려는 개발자를 위한 문서가 포함되어 있습니다.
