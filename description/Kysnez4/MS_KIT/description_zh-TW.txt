MS_KIT 是 Android 遊戲 Magic Survival 的非官方模組載入器與創作框架，以可免 root 並存的 side-by-side Zombix 用戶端形式發佈。現行技術棧以建構於 MelonLoader、Harmony 與 Il2CppInterop 之上的 C# ModKit 核心為中心，提供 zip 模組、遊戲內啟用介面、掛鉤、事件，以及戰鬥、法術、神器、效果與遊戲資料的共用函式庫。較早一代以 Frida 為基礎，支援以 TypeScript 與 JavaScript 撰寫模組以調整表與效果。儲存庫包含建置與部署工具、範例模組、遊戲表參考及文件，供希望在裝置上擴充或逆向 IL2CPP 玩法的開發者使用。
