MS_KIT — неофициальный загрузчик модов и фреймворк для создания контента к Android-игре Magic Survival, распространяемый как side-by-side клиент Zombix, работающий без root. Текущий стек опирается на ядро ModKit на C#, построенное на MelonLoader с Harmony и Il2CppInterop: zip-моды, UI включения в игре, хуки, события и общие библиотеки для боя, заклинаний, артефактов, эффектов и игровых данных. Более раннее поколение на базе Frida поддерживает моды на TypeScript и JavaScript для правок таблиц и эффектов. В репозитории есть инструменты сборки и развёртывания, примеры модов, справочники по игровым таблицам и документация для разработчиков, которые хотят расширять или реверс-инжинирить IL2CPP-геймплей на устройстве.
