MS_KIT は Android 向けゲーム Magic Survival 用の非公式モッドローダー兼オーサリングフレームワークで、root 不要で動作する side-by-side の Zombix クライアントとして配布されています。現行スタックは MelonLoader、Harmony、Il2CppInterop 上に構築された C# ModKit コアを中心とし、zip ベースのモッド、ゲーム内有効化 UI、フック、イベント、および戦闘・呪文・アーティファクト・効果・ゲームデータ向けの共有ライブラリを提供します。旧世代は Frida ベースで、テーブルや効果の調整向けに TypeScript と JavaScript のモッドをサポートします。リポジトリにはビルド・デプロイ用ツール、サンプルモッド、ゲームテーブル参照、および端末上で IL2CPP ゲームプレイを拡張またはリバースエンジニアリングしたい開発者向けのドキュメントが含まれます。
