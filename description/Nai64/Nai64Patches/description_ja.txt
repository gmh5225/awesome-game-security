Nai's Patches は、Morphe Android APK パッチャー向けに厳選された約100個のユニバーサルパッチのコレクションで、モバイルゲームやアプリの調整、ロック解除、整理を目的としています。パッチは Kotlin と Gradle で実装され、広告除去、ライセンスおよび Play Integrity のバイパス、root およびエミュレータ検出の回避、証明書ピニングのバイパス、テレメトリのブロック、広範なデバイスやマニフェストの偽装などをカバーしています。ユーザーは Morphe 内でオプションのパッチを選択し、報酬型広告のスキップ、デバッガーの非表示、画面向きの強制、アプリのデバッグ可能化、アプリ内課金のロック解除などの変更を加えた APK を再ビルドできます。このプロジェクトは、ライセンス、整合性チェック、改ざん防止、その他のクライアント側セキュリティ制御を強制する Android ゲームを分析または改変する必要があるリバースエンジニア、モバイルセキュリティ研究者、モッダーを対象としています。
