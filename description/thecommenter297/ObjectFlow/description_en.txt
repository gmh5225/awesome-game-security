ObjectFlow is a standalone IDAPython plugin for IDA Pro and the Hex-Rays decompiler that adds smart semantic cross-references on top of ordinary static xrefs. It analyzes decompiler microcode to surface local and interprocedural xrefs, stable variable selection, reaching definitions, pointer and memory relationships, and trace-style evidence, labeling inferred links as static MAY relationships rather than proven data flow. The implementation is a single Python module built on IDAPython APIs and a PyQt5 UI, with hot reload for iterative plugin development. It targets reverse engineers who need richer navigation and data-flow context when dissecting compiled game clients, anti-cheat modules, and other native binaries where Hex-Rays pseudocode is the primary view.
