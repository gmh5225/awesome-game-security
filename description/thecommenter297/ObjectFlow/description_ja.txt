ObjectFlow は IDA Pro と Hex-Rays デコンパイラ向けのスタンドアロン IDAPython プラグインで、通常の静的 xref の上にスマートな意味的クロスリファレンスを追加します。デコンパイラのマイクロコードを解析し、局所および手続き間 xref、安定した変数選択、到達定義、ポインタとメモリの関係、トレース風の根拠を提示し、推論されたリンクを実証済みデータフローではなく静的 MAY 関係としてラベル付けします。実装は IDAPython API と PyQt5 UI 上の単一 Python モジュールで、プラグイン開発の反復にホットリロードを備えます。Hex-Rays 擬似コードが主なビューであるコンパイル済みゲームクライアント、アンチチートモジュール、その他のネイティブバイナリを解析する際に、より豊富なナビゲーションとデータフローの文脈を必要とするリバースエンジニアを対象としています。
