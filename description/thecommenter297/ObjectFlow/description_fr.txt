ObjectFlow est un plugin IDAPython autonome pour IDA Pro et le décompilateur Hex-Rays qui ajoute des références croisées sémantiques intelligentes au-dessus des xrefs statiques ordinaires. Il analyse le microcode du décompilateur pour exposer les xrefs locaux et interprocéduraux, une sélection stable des variables, les définitions atteignables, les relations pointeur-mémoire et des preuves de type trace, en étiquetant les liens inférés comme des relations statiques MAY plutôt que comme un flux de données prouvé. L'implémentation est un module Python unique reposant sur les API IDAPython et une interface PyQt5, avec rechargement à chaud pour le développement itératif du plugin. Il s'adresse aux ingénieurs en rétro-ingénierie qui ont besoin d'une navigation plus riche et d'un contexte de flux de données lors de l'analyse de clients de jeux compilés, de modules anti-triche et d'autres binaires natifs où le pseudocode Hex-Rays est la vue principale.
