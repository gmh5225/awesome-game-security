ObjectFlow es un complemento IDAPython independiente para IDA Pro y el descompilador Hex-Rays que añade referencias cruzadas semánticas inteligentes sobre las xrefs estáticas habituales. Analiza el microcódigo del descompilador para mostrar xrefs locales e interprocedimentales, selección estable de variables, definiciones alcanzables, relaciones puntero-memoria y evidencia al estilo de trazas, etiquetando los enlaces inferidos como relaciones estáticas MAY en lugar de flujo de datos demostrado. La implementación es un único módulo Python basado en las API de IDAPython y una interfaz PyQt5, con recarga en caliente para el desarrollo iterativo del complemento. Está dirigido a ingenieros de ingeniería inversa que necesitan una navegación más rica y contexto de flujo de datos al diseccionar clientes de juego compilados, módulos anti-trampas y otros binarios nativos donde el pseudocódigo Hex-Rays es la vista principal.
