ObjectFlow — автономный плагин IDAPython для IDA Pro и декомпилятора Hex-Rays, который добавляет умные семантические перекрёстные ссылки поверх обычных статических xref. Он анализирует микрокод декомпилятора, чтобы показать локальные и межпроцедурные xref, устойчивый выбор переменных, достижимые определения, связи указателей и памяти и доказательства в стиле трассировки, помечая выведенные связи как статические отношения MAY, а не доказанный поток данных. Реализация — один модуль Python на базе API IDAPython и интерфейса PyQt5 с горячей перезагрузкой для итеративной разработки плагина. Ориентирован на специалистов по реверс-инжинирингу, которым нужна более богатая навигация и контекст потока данных при разборе скомпилированных игровых клиентов, модулей античита и других нативных бинарников, где основным представлением является псевдокод Hex-Rays.
