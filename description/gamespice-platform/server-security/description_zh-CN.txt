GameSpice Server Security 是一款 Godot 插件，通过按运营商设定的规则监控聊天、连接、认证、远程控制台活动以及反作弊信号，来加固专用多人游戏服务器。主要使用 GDScript 编写，采用统一的滑动窗口规则引擎，使检测与游戏事件共享同一套计数器、阶梯、豁免与 dry-run 默认行为，再逐步升级为警告、禁言、静音、踢出与封禁。服务端反作弊区分可证实的违规与仅值得警告的可疑行为；外部封禁列表会并入加入校验，运营商控制台提供 sec_why、sec_status 等命令。面向运行 GameSpice Core 与 GameSpice Server 的在线服主与模组作者，在无需单独惩罚栈的前提下提供可配置的服务器安全与反作弊能力。
