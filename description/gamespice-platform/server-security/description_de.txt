GameSpice Server Security ist ein Godot-Addon, das dedizierte Multiplayer-Server absichert, indem es Chat, Verbindungen, Authentifizierung, Remote-Konsolenaktivität und Anti-Cheat-Signale anhand vom Betreiber festgelegter Regeln überwacht. Es ist vor allem in GDScript geschrieben und nutzt eine einheitliche Sliding-Window-Regelengine, sodass Erkennungen und Spielereignisse dieselben Zähler, Staffeln, Ausnahmen und Dry-Run-Standards teilen, bevor es zu Warnung, Gag, Stummschaltung, Kick und Ban eskaliert. Serverseitiges Anti-Cheat unterscheidet nachweisbare Verstöße von verdächtigem Verhalten, das nur eine Warnung verdient, während externe Banlisten-Feeds in Join-Prüfungen einfließen und Betreiberkonsolen Befehle wie sec_why und sec_status bereitstellen. Es richtet sich an Live-Spielbetreiber und Modder, die GameSpice Core und GameSpice Server betreiben und konfigurierbare Server-Sicherheit und Anti-Cheat ohne separaten Bestrafungs-Stack wünschen.
