GameSpice Server Security — дополнение Godot, которое усиливает выделенные многопользовательские серверы, отслеживая чат, подключения, аутентификацию, активность удалённой консоли и сигналы античита по правилам, заданным оператором. Написано в основном на GDScript и использует единый движок правил со скользящим окном: обнаружения и игровые события разделяют одни и те же счётчики, ступени, исключения и значения по умолчанию в режиме dry-run, прежде чем эскалация дойдёт до предупреждения, gag, mute, кика и бана. Серверный античит отличает доказуемые нарушения от подозрительного поведения, которое заслуживает лишь предупреждения; внешние ленты бан-листов включаются в проверки при входе, а консоли оператора предоставляют команды вроде sec_why и sec_status. Рассчитано на хостеров живых игр и моддеров, которые запускают GameSpice Core и GameSpice Server и хотят настраиваемую безопасность сервера и античит без отдельного стека наказаний.
