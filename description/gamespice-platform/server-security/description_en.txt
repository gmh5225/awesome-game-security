GameSpice Server Security is a Godot addon that hardens dedicated multiplayer servers by watching chat, connections, authentication, remote console activity, and anti-cheat signals against operator-defined rules. Written primarily in GDScript, it uses a unified sliding-window rule engine so detections and game events share the same counters, ladders, exemptions, and dry-run defaults before escalating through warn, gag, mute, kick, and ban. Server-side anti-cheat distinguishes provable violations from suspicious behaviour that only merits warnings, while external ban-list feeds merge into join checks and operator consoles expose commands such as sec_why and sec_status. It targets live game hosts and modders who run GameSpice Core and GameSpice Server and want configurable server security and anti-cheat without a separate punishment stack.
