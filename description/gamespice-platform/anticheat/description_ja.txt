GameSpice Anticheat は Godot 4.7 以降向けアドオンで、プレイヤーごとの疑わしさスコアとクライアントコマンドの妥当性チェックにより、専用マルチプレイゲーム向けのサーバー側アンチチートを提供します。GDScript で実装され GameSpice アドオン群の一員であり、GameSpice Server Security の上に載り、速度・テレポート・エイムスナップ検知を減衰するスコアに変換し、警告・キック・BAN のしきい値を設定可能としつつ、処罰そのものは自前では行いません。DotCommandSanity は信頼できないクライアント入力に対して移動・視線変化率・範囲・コマンド頻度を検証し、DotSuspicionWatch はレポートを集約してエスカレーション信号を発し、ゲームやモデレーション側で対応できます。ヘッドレスサーバー向けに設計され、YAML と環境変数で設定でき、クライアントドライバやカーネルフックは使わない方針です。フルなクライアント改ざん対策ではなく、組み合わせ可能なサーバー権威型アンチチートスコアリング層を求める Godot 開発者向けです。
