GameSpice Anticheat — дополнение для Godot 4.7+, обеспечивающее серверный античит для выделенных многопользовательских игр за счёт оценки подозрительности по игрокам и проверки корректности клиентских команд. Реализовано на GDScript в составе семейства дополнений GameSpice и опирается на GameSpice Server Security, превращая обнаружения скорости, телепортации и мгновенного наведения в затухающие баллы с настраиваемыми порогами предупреждения, кика и бана, не применяя наказания самостоятельно. DotCommandSanity проверяет перемещение, скорость поворота взгляда, дистанции и частоту команд на недоверенном клиентском вводе, а DotSuspicionWatch собирает отчёты и выдаёт сигналы эскалации для игры или стека модерации. Архитектура удобна для headless-серверов, настраивается через YAML и переменные окружения и явно не использует клиентские драйверы или перехваты в ядре. Подходит разработчикам Godot, которым нужен компонуемый серверно-авторитетный слой античит-скоринга, а не полноценный клиентский анти-тампер.
