GameSpice Anticheat은 Godot 4.7 이상용 애드온으로, 플레이어별 의심 점수와 클라이언트 명령 무결성 검사를 통해 전용 멀티플레이 게임에 서버 측 안티치트를 제공합니다. GDScript로 구현되었으며 GameSpice 애드온 패밀리의 일부로, GameSpice Server Security 위에 올라가 속도·순간이동·에임 스냅 탐지를 감쇠하는 점수로 바꾸고 경고·킥·밴 임계값을 설정할 수 있으나 징벌은 스스로 적용하지 않습니다. DotCommandSanity는 신뢰할 수 없는 클라이언트 입력에서 이동, 시야 변화율, 범위, 명령 빈도를 검증하고, DotSuspicionWatch는 보고를 집계해 에스컬레이션 신호를 내보내 게임이나 모더레이션 스택이 처리하게 합니다. 헤드리스 서버에 맞게 설계되었고 YAML과 환경 변수로 설정하며, 클라이언트 드라이버나 커널 후킹은 사용하지 않습니다. 완전한 클라이언트 안티탬퍼 제품이 아니라 조합 가능한 서버 권위형 안티치트 점수 레이어가 필요한 Godot 개발자에게 적합합니다.
