GameSpice Anticheat 是面向 Godot 4.7+ 的插件，通过每名玩家的可疑度评分与客户端命令合理性检查，为专用多人游戏提供服务端反作弊能力。它以 GDScript 实现，属于 GameSpice 插件族，并构建在 GameSpice Server Security 之上，将超速、传送与瞬间瞄准等检测转化为可衰减的分数，并支持可配置的警告、踢出与封禁阈值，但不由自身执行处罚。DotCommandSanity 对不可信客户端输入校验移动、视角变化速率、距离与命令频率；DotSuspicionWatch 汇总报告并发出升级信号，供游戏或 Moderation 栈处理。该设计适合无头服务端，可通过 YAML 与环境变量配置，且明确不依赖客户端驱动或内核挂钩。它适合需要可组合、服务端权威的反作弊评分层，而非完整客户端防篡改方案的 Godot 开发者。
