UsbDetectionBypass est un module LSPosed/Xposed pour Android qui contourne la détection de connexion USB et de débogage USB dans les applications cibles définies dans le scope. Écrit en Kotlin avec un composant natif C++, il masque les signaux Java et natifs afin que le processus cible perçoive un état USB déconnecté et non déboguable. Il intercepte SystemProperties, les API UsbManager, les diffusions USB et batterie, les vérifications de commandes telles que getprop et dumpsys, ainsi que les lectures de fichiers natives sur les chemins sysfs liés à l'USB. La journalisation diagnostique est disponible via LSPosed, logcat et des fichiers journaux par application. Il est destiné à la recherche en sécurité autorisée, à l'ingénierie inverse et aux tests anti-triche sur des appareils rootés où des applications appliquent des contrôles d'intégrité basés sur l'USB ou ADB.
