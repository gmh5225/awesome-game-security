UsbDetectionBypass は、Android 向けの LSPosed/Xposed モジュールで、スコープ指定された対象アプリ内の USB 接続および USB デバッグ検出をバイパスします。Kotlin で記述され、ネイティブ C++ コンポーネントを含み、Java およびネイティブのシグナルをマスクして、対象プロセスには USB が切断されデバッグ不可の状態として見えるようにします。SystemProperties、UsbManager API、USB およびバッテリー関連のブロードキャスト、getprop や dumpsys などのコマンドチェック、USB 関連の sysfs パスに対するネイティブファイル読み取りをフックします。診断ログは LSPosed、logcat、およびアプリごとのログファイルから利用できます。USB または ADB ベースの整合性チェックを行うアプリが存在する root 済みデバイス上での、許可されたセキュリティ研究、リバースエンジニアリング、およびアンチチートテストを目的としています。
