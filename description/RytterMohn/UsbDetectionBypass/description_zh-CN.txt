UsbDetectionBypass 是一款适用于 Android 的 LSPosed/Xposed 模块，可在指定目标应用内绕过 USB 连接与 USB 调试检测。该模块使用 Kotlin 编写并包含原生 C++ 组件，通过屏蔽 Java 与原生层信号，使目标进程感知到 USB 已断开且不可调试的状态。它会 hook SystemProperties、UsbManager API、USB 与电池广播、getprop 和 dumpsys 等命令检查，以及对 USB 相关 sysfs 路径的原生文件读取。可通过 LSPosed、logcat 以及各应用日志文件进行诊断日志记录。适用于已 root 设备上，应用实施 USB 或 ADB 完整性校验场景下的授权安全研究、逆向工程与反作弊测试。
