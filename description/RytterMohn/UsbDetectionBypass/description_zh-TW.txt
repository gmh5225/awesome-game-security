UsbDetectionBypass 是一款適用於 Android 的 LSPosed/Xposed 模組，可在指定目標應用程式內繞過 USB 連線與 USB 偵錯偵測。此模組以 Kotlin 撰寫並包含原生 C++ 元件，透過遮蔽 Java 與原生層訊號，使目標程序感知到 USB 已中斷且不可偵錯的狀態。它會 hook SystemProperties、UsbManager API、USB 與電池廣播、getprop 和 dumpsys 等指令檢查，以及對 USB 相關 sysfs 路徑的原生檔案讀取。可透過 LSPosed、logcat 以及各應用程式日誌檔案進行診斷記錄。適用於已 root 裝置上，應用程式實施 USB 或 ADB 完整性驗證情境下的授權安全研究、逆向工程與反作弊測試。
