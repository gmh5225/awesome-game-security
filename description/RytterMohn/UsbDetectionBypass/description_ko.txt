UsbDetectionBypass는 Android용 LSPosed/Xposed 모듈로, 범위가 지정된 대상 앱 내부의 USB 연결 및 USB 디버깅 감지를 우회합니다. Kotlin으로 작성되었으며 네이티브 C++ 구성 요소를 포함하여 Java 및 네이티브 신호를 마스킹함으로써 대상 프로세스가 USB가 연결 해제되고 디버깅 불가능한 상태로 인식하도록 합니다. SystemProperties, UsbManager API, USB 및 배터리 브로드캐스트, getprop 및 dumpsys와 같은 명령 검사, USB 관련 sysfs 경로에 대한 네이티브 파일 읽기를 후킹합니다. LSPosed, logcat 및 앱별 로그 파일을 통해 진단 로깅을 사용할 수 있습니다. 앱이 USB 또는 ADB 기반 무결성 검사를 시행하는 루팅된 기기에서의 승인된 보안 연구, 리버스 엔지니어링 및 안티치트 테스트를 위해 설계되었습니다.
