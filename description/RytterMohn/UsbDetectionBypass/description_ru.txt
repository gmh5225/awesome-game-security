UsbDetectionBypass — это модуль LSPosed/Xposed для Android, который обходит обнаружение USB-подключения и USB-отладки в целевых приложениях заданной области. Написан на Kotlin с нативным компонентом на C++, он маскирует сигналы Java и нативного уровня, чтобы целевой процесс воспринимал состояние USB как отключённое и недоступное для отладки. Перехватывает SystemProperties, API UsbManager, широковещательные сообщения USB и батареи, проверки команд вроде getprop и dumpsys, а также нативное чтение файлов по путям sysfs, связанным с USB. Диагностическое логирование доступно через LSPosed, logcat и журналы отдельных приложений. Предназначен для авторизованных исследований безопасности, реверс-инжиниринга и тестирования античита на устройствах с root, где приложения применяют проверки целостности на основе USB или ADB.
