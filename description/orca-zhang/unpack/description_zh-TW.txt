Unpack 是一套用於偵測可執行檔加殼器與保護器、解碼壓縮承載內容，並對加殼二進位檔逐層遞迴追蹤的工具鏈。其 Rust 核心為常見壓縮方案實作了原生解碼器，並與官方 UPX 後端整合；Go 驅動將支援擴展至約二十二種格式，包括 ASPack、Themida、VMProtect、MPRESS 及其他以 PE 為主的保護器。使用者可透過命令列介面操作、嵌入 Rust 函式庫，或呼叫捆綁同一分析引擎的 Go SDK 以用於自動化管線。在無法完整脫殼時，靜態復原可修復 PE 結構與進入點；分析的樣本在不執行的情況下完成檢查。此工具面向需要可靠格式識別與多層脫殼的逆向工程師、惡意軟體分析師及遊戲安全研究人員，適用於受保護的 Windows 與跨平台可執行檔。
