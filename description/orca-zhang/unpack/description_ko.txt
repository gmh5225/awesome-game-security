Unpack은 실행 파일 패커와 프로텍터를 탐지하고, 압축된 페이로드를 디코딩하며, 패킹된 바이너리의 각 계층을 재귀적으로 추적하는 툴체인입니다. Rust 코어는 일반적인 압축 방식에 대한 네이티브 디코더를 구현하고 공식 UPX 백엔드와 통합하며, Go 드라이버는 ASPack, Themida, VMProtect, MPRESS 및 기타 PE 중심 프로텍터를 포함해 약 22가지 형식까지 지원을 확장합니다. 사용자는 명령줄 인터페이스, Rust 라이브러리 임베딩, 또는 동일한 분석 엔진을 묶은 Go SDK를 통해 자동화 파이프라인에서 호출할 수 있습니다. 완전한 언패킹이 불가능한 경우에도 정적 복구로 PE 구조와 진입점을 수리할 수 있으며, 분석 대상 샘플은 실행 없이 검사합니다. 보호된 Windows 및 크로스 플랫폼 실행 파일에 대해 신뢰할 수 있는 형식 식별과 계층적 언패킹이 필요한 리버스 엔지니어, 멀웨어 분석가, 게임 보안 연구자를 대상으로 합니다.
