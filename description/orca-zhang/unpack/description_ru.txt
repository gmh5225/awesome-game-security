Unpack — это набор инструментов для обнаружения упаковщиков и протекторов исполняемых файлов, декодирования сжатых полезных нагрузок и рекурсивного прохождения каждого слоя в упакованных бинарниках. Ядро на Rust реализует нативные декодеры для распространённых схем сжатия и интегрируется с официальным бэкендом UPX, а драйверы на Go расширяют поддержку примерно до двадцати двух форматов, включая ASPack, Themida, VMProtect, MPRESS и другие PE-ориентированные протекторы. Работа возможна через командную строку, встраивание Rust-библиотеки или вызов Go SDK с тем же аналитическим движком для автоматизированных конвейеров. Статическое восстановление может исправить структуру PE и точки входа, когда полная распаковка недоступна; образцы анализируются без выполнения. Инструмент ориентирован на специалистов по реверс-инжинирингу, аналитиков вредоносного ПО и исследователей безопасности игр, которым нужна надёжная идентификация форматов и послойная распаковка защищённых исполняемых файлов Windows и кроссплатформенных бинарников.
