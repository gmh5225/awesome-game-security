Unpack は、実行ファイル用パッカーおよびプロテクタの検出、圧縮ペイロードのデコード、パックされたバイナリの各レイヤーを再帰的にたどるためのツールチェーンです。Rust コアは一般的な圧縮方式のネイティブデコーダーを実装し、公式 UPX バックエンドと統合し、Go ドライバーは ASPack、Themida、VMProtect、MPRESS など PE 向けプロテクタを含む約 22 形式への対応を拡張します。コマンドライン、Rust ライブラリの埋め込み、同一分析エンジンを同梱する Go SDK による自動パイプラインから利用できます。完全なアンパックが不可能な場合でも静的復元により PE 構造とエントリポイントを修復でき、分析対象サンプルは実行せずに検査します。保護された Windows およびクロスプラットフォームの実行ファイルについて、信頼できる形式識別と多層アンパックを必要とするリバースエンジニア、マルウェアアナリスト、ゲームセキュリティ研究者を対象としています。
