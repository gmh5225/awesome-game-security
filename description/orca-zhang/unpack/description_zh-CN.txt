Unpack 是一套用于检测可执行文件加壳器与保护器、解码压缩载荷，并对加壳二进制逐层递归追踪的工具链。其 Rust 核心为常见压缩方案实现了原生解码器，并与官方 UPX 后端集成；Go 驱动将支持扩展到约二十二种格式，包括 ASPack、Themida、VMProtect、MPRESS 及其他面向 PE 的保护器。用户可通过命令行界面操作、嵌入 Rust 库，或调用捆绑同一分析引擎的 Go SDK 以用于自动化流水线。在无法完整脱壳时，静态恢复可修复 PE 结构与入口点；分析的样本在不经执行的情况下完成检查。该工具面向需要可靠格式识别与多层脱壳的逆向工程师、恶意软件分析师及游戏安全研究人员，适用于受保护的 Windows 与跨平台可执行文件。
