Unpack is a toolchain for detecting executable packers and protectors, decoding compressed payloads, and tracing each layer recursively through packed binaries. Its Rust core implements native decoders for common compression schemes and integrates with the official UPX backend, while Go drivers extend support to roughly twenty-two formats including ASPack, Themida, VMProtect, MPRESS, and other PE-focused protectors. Users can work through a command-line interface, embed the Rust library, or call a Go SDK that bundles the same analysis engine for automated pipelines. Static recovery can repair PE structure and entry points where full unpacking is not available, and analyzed samples are inspected without execution. It targets reverse engineers, malware analysts, and game-security researchers who need reliable format identification and layered unpacking of protected Windows and cross-platform executables.
