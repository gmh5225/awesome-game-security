Cheat Manager Menu is an Unreal Engine plugin that automatically builds an in-game cheat menu by reflecting over the local player's UCheatManager and any registered cheat manager extensions. Implemented in C++ for Unreal Engine 5.8 on Win64, it discovers native Exec functions and BlueprintCallable cheat extensions at runtime and presents them with parameter-aware controls such as checkboxes, dropdowns, sliders, and text fields, rendered through the experimental SlateIM UI layer. The menu supports keyboard, mouse, and gamepad input, with filtering, favorites, category grouping from UFUNCTION metadata, tooltips from doc comments, and optional confirmation dialogs for destructive cheats. It is compiled out of Shipping builds and is intended for game developers and testers who need a zero-maintenance debug interface for invoking cheat commands during development, play-in-editor, and packaged Development or Test builds.
