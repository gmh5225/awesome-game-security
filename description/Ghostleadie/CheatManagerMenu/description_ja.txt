Cheat Manager Menu は Unreal Engine 用プラグインで、ローカルプレイヤーの UCheatManager および登録済みのチートマネージャー拡張をリフレクションで走査し、ゲーム内チートメニューを自動的に構築します。Win64 向け Unreal Engine 5.8 用に C++ で実装され、実行時にネイティブの Exec 関数と BlueprintCallable チート拡張を検出し、チェックボックス、ドロップダウン、スライダー、テキストフィールドなどパラメータ対応のコントロールで表示します。実験的な SlateIM UI レイヤーで描画されます。メニューはキーボード、マウス、ゲームパッド入力に対応し、フィルタリング、お気に入り、UFUNCTION メタデータによるカテゴリ分類、ドキュメントコメントからのツールチップ、破壊的チート向けの確認ダイアログ（任意）を備えています。Shipping ビルドではコンパイルから除外され、開発中、エディタ内プレイ、パッケージ化された Development または Test ビルドでチートコマンドを呼び出すためのメンテナンス不要のデバッグインターフェースを必要とするゲーム開発者とテスター向けです。
