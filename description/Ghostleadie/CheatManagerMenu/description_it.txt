Cheat Manager Menu è un plugin per Unreal Engine che costruisce automaticamente un menu cheat in-game riflettendo sul UCheatManager del giocatore locale e su qualsiasi estensione registrata del gestore cheat. Implementato in C++ per Unreal Engine 5.8 su Win64, scopre a runtime funzioni Exec native ed estensioni cheat BlueprintCallable e le presenta con controlli consapevoli dei parametri come caselle di controllo, menu a tendina, cursori e campi di testo, renderizzati tramite il layer UI sperimentale SlateIM. Il menu supporta input da tastiera, mouse e gamepad, con filtri, preferiti, raggruppamento per categorie dai metadati UFUNCTION, tooltip dai commenti di documentazione e dialoghi di conferma opzionali per cheat distruttivi. Viene escluso dalla compilazione nelle build Shipping ed è destinato a sviluppatori e tester di giochi che necessitano di un'interfaccia di debug a zero manutenzione per invocare comandi cheat durante lo sviluppo, il play-in-editor e le build Development o Test impacchettate.
