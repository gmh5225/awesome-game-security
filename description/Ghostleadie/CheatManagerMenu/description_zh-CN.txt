Cheat Manager Menu 是一款 Unreal Engine 插件，通过对本地玩家的 UCheatManager 以及所有已注册的作弊管理器扩展进行反射，自动构建游戏内作弊菜单。该插件使用 C++ 实现，面向 Win64 平台的 Unreal Engine 5.8，在运行时发现原生 Exec 函数与 BlueprintCallable 作弊扩展，并以参数感知控件（复选框、下拉菜单、滑块和文本框）呈现，通过实验性的 SlateIM UI 层渲染。菜单支持键盘、鼠标和手柄输入，提供筛选、收藏、基于 UFUNCTION 元数据的分类分组、来自文档注释的工具提示，以及针对破坏性作弊的可选确认对话框。该插件在 Shipping 构建中会被编译排除，面向需要零维护调试界面、以便在开发、编辑器内运行以及打包的 Development 或 Test 构建中调用作弊命令的游戏开发者与测试人员。
