Cheat Manager Menu 是一款 Unreal Engine 外掛，透過對本地玩家的 UCheatManager 以及所有已註冊的作弊管理器擴充進行反射，自動建構遊戲內作弊選單。此插件以 C++ 實作，適用於 Win64 平台的 Unreal Engine 5.8，在執行時期探索原生 Exec 函式與 BlueprintCallable 作弊擴充，並以參數感知控制項（核取方塊、下拉式選單、滑桿和文字欄位）呈現，透過實驗性的 SlateIM UI 層渲染。選單支援鍵盤、滑鼠和遊戲手把輸入，提供篩選、我的最愛、基於 UFUNCTION 中繼資料的分類分組、來自文件註解的工具提示，以及針對破壞性作弊的可選確認對話方塊。此插件在 Shipping 建置中會被編譯排除，面向需要零維護除錯介面、以便在開發、編輯器內執行以及封裝的 Development 或 Test 建置中呼叫作弊指令的遊戲開發者與測試人員。
