Cheat Manager Menu — это плагин для Unreal Engine, который автоматически создаёт внутриигровое меню читов путём рефлексии UCheatManager локального игрока и всех зарегистрированных расширений менеджера читов. Реализован на C++ для Unreal Engine 5.8 под Win64, обнаруживает во время выполнения нативные функции Exec и расширения читов BlueprintCallable и отображает их с элементами управления, учитывающими параметры: флажки, выпадающие списки, ползунки и текстовые поля, отрисовываемые через экспериментальный UI-слой SlateIM. Меню поддерживает ввод с клавиатуры, мыши и геймпада, фильтрацию, избранное, группировку по категориям на основе метаданных UFUNCTION, подсказки из комментариев документации и необязательные диалоги подтверждения для разрушительных читов. Исключается из компиляции в Shipping-сборках и предназначен для разработчиков и тестировщиков игр, которым нужен интерфейс отладки без обслуживания для вызова команд читов во время разработки, play-in-editor и упакованных Development или Test сборок.
