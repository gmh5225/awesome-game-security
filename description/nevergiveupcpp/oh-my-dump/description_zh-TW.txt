Oh My Dump 是一款 IDA Pro 9.x 外掛，可在同一程式的舊版與新版建置之間匯出並重新套用逆向工程標註。它將分析結果序列化為由含萬用字元的位元組特徵碼構成的 JSON 檔，隨後在新 IDB 中定位相符的程式碼與資料，以還原名稱、型別宣告、註解、背景色與中斷點。模式比對可遵循 RIP 相對定址與以偏移為基礎的定址，使標籤在重定位或已修補的二進位檔中仍能保持對齊。此外掛以 C++20、CMake 與 IDA SDK 實作，目標為 x86 與 x86-64 Windows 二進位。適合需要在頻繁更新的遊戲用戶端或反作弊版本中保留手動 IDA 工作的分析人員與遊戲安全研究人員，在僅靠 FLIRT 特徵或 Lumina 中繼資料無法承載完整脈絡時使用。
