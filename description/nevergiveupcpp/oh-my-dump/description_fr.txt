Oh My Dump est un plugin IDA Pro 9.x qui exporte et réapplique les annotations de reverse engineering lorsque vous passez d’anciennes à de nouvelles versions d’un même programme. Il sérialise l’analyse dans des fichiers JSON construits à partir de signatures d’octets avec jokers, puis localise le code et les données correspondants dans une nouvelle IDB pour restaurer noms, déclarations de types, commentaires, couleurs de fond et points d’arrêt. La correspondance de motifs peut suivre l’adressage relatif à RIP et par offset afin que les étiquettes restent alignées sur des binaires rebasés ou patchés. Le plugin est implémenté en C++20 avec CMake et le SDK IDA, et cible les binaires Windows x86 et x86-64. Il convient aux analystes et chercheurs en sécurité des jeux qui doivent conserver le travail manuel dans IDA à travers des mises à jour fréquentes de clients ou d’anti-triche, lorsque les signatures FLIRT ou les métadonnées Lumina seules ne transmettent pas tout le contexte.
