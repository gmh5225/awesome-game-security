Oh My Dump는 IDA Pro 9.x용 플러그인으로, 동일 프로그램의 이전 빌드와 새 빌드 사이에서 리버스 엔지니어링 주석을 내보내고 다시 적용합니다. 분석 결과를 와일드카드가 포함된 바이트 시그니처로 만든 JSON 파일로 직렬화한 뒤, 새 IDB에서 일치하는 코드와 데이터를 찾아 이름, 타입 선언, 주석, 배경색, 중단점을 복원합니다. 패턴 매칭은 RIP 상대 및 오프셋 기반 주소 지정을 따를 수 있어, 리베이스되거나 패치된 바이너리에서도 레이블 정렬을 유지합니다. C++20, CMake, IDA SDK로 구현되었으며 x86 및 x86-64 Windows 바이너리를 대상으로 합니다. FLIRT 시그니처나 Lumina 메타데이터만으로는 전체 맥락을 이어가기 어려운, 잦은 클라이언트·안티치트 업데이트 환경에서 수동 IDA 작업을 보존해야 하는 분석가와 게임 보안 연구자에게 적합합니다.
