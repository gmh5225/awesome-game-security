Oh My Dump 是一款 IDA Pro 9.x 插件，可在同一程序的旧版与新版构建之间导出并重新应用逆向工程标注。它将分析结果序列化为由带通配符的字节特征码构成的 JSON 文件，随后在新 IDB 中定位匹配的代码与数据，以恢复名称、类型声明、注释、背景色和断点。模式匹配可遵循 RIP 相对寻址与基于偏移的寻址，使标签在重定位或打过补丁的二进制文件中仍能对齐。该插件使用 C++20、CMake 与 IDA SDK 实现，面向 x86 与 x86-64 Windows 二进制。适合需要在频繁更新的游戏客户端或反作弊版本中保留手工 IDA 工作的分析人员与游戏安全研究人员，在仅靠 FLIRT 特征或 Lumina 元数据无法承载完整上下文时使用。
