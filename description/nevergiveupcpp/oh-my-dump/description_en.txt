Oh My Dump is an IDA Pro 9.x plugin that exports and re-applies reverse-engineering annotations when you move between older and newer builds of the same program. It serializes analysis into JSON files built from byte signatures with wildcards, then locates matching code and data in a new IDB to restore names, type declarations, comments, background colors, and breakpoints. Pattern matching can follow RIP-relative and offset-based addressing so labels stay aligned across rebased or patched binaries. The plugin is implemented in C++20 with CMake and the IDA SDK, and targets x86 and x86-64 Windows binaries. It suits analysts and game-security researchers who need to preserve manual IDA work across frequent client or anti-cheat updates where FLIRT signatures or Lumina metadata alone do not carry the full context.
