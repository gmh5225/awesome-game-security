Oh My Dump は IDA Pro 9.x 向けプラグインで、同一プログラムの旧ビルドと新ビルドの間で逆アセンブル注釈をエクスポートし、再適用します。解析結果をワイルドカード付きバイトシグネチャから構築した JSON にシリアライズし、新しい IDB 内で一致するコードとデータを特定して、名前、型宣言、コメント、背景色、ブレークポイントを復元します。パターンマッチは RIP 相対およびオフセットベースのアドレッシングに対応し、リベースやパッチ済みバイナリでもラベルの整合を保てます。C++20、CMake、IDA SDK で実装され、x86 および x86-64 の Windows バイナリを対象とします。FLIRT シグネチャや Lumina メタデータだけでは文脈を十分に引き継げない、クライアントやアンチチートの頻繁な更新を跨いで手作業の IDA 作業を残したいアナリストやゲームセキュリティ研究者向けです。
