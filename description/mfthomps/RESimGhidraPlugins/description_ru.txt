Этот проект предоставляет расширения-плагины Ghidra Debugger, интегрирующие Ghidra с платформой обратной разработки RESim и позволяющие аналитикам использовать Ghidra в качестве фронтенда дизассемблера и отладчика для анализа на базе RESim. Написанный преимущественно на Java, набор добавляет окна отладчика и утилиты, специфичные для RESim: закладки, watchmarks, просмотр стека, интерактивную консоль и всплывающие подсказки в списках для регистров и ссылок на память. Подключение к целям RESim выполняется через удалённую отладку gdb-multiarch, включая сессии полносистемного моделирования Simics на порту 9123, и воспроизводит большую часть функциональности, ранее доступной в плагинах IDA Pro для RESim. Плагины предназначены для специалистов по обратной разработке и исследователей безопасности, выполняющих динамический анализ бинарного кода с поддержкой симуляции, а не только статическое дизассемблирование.
