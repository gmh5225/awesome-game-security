本專案提供 Ghidra Debugger 擴充插件，將 Ghidra 與 RESim 逆向工程平台整合，讓分析人員可將 Ghidra 用作 RESim 驅動分析的反組譯器與偵錯器前端。該套件主要以 Java 撰寫，新增了 RESim 專用的偵錯器視窗及工具，支援書籤、監看標記、堆疊檢查、互動式主控台，以及暫存器和記憶體參考的列表懸停輔助功能。它透過 gdb-multiarch 遠端偵錯連接 RESim 目標，包括連接埠 9123 上的 Simics 全系統模擬工作階段，並重現了 RESim 原有 IDA Pro 插件中的大部分功能。這些插件面向需要進行動態、模擬支援的二進位分析（而非僅靜態反組譯）的逆向工程師與安全研究人員。
