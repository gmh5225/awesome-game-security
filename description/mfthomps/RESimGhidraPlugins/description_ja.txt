本プロジェクトは、Ghidra を RESim リバースエンジニアリングプラットフォームと統合する Ghidra Debugger 拡張プラグインを提供し、分析者が RESim 駆動の解析向けに Ghidra を逆アセンブラおよびデバッガのフロントエンドとして利用できるようにします。主に Java で記述されたこのスイートは、ブックマーク、ウォッチマーク、スタック検査、対話型コンソール、レジスタおよびメモリ参照向けのリストホバーヘルパーなど、RESim 専用のデバッガウィンドウとユーティリティを追加します。gdb-multiarch によるリモートデバッグを通じて RESim ターゲットに接続し、ポート 9123 上の Simics フルシステムシミュレーションセッションも含み、以前 RESim の IDA Pro プラグインで提供されていた機能の多くを再現します。これらのプラグインは、静的逆アセンブリだけでなく、動的かつシミュレーション支援によるバイナリ解析を行うリバースエンジニアおよびセキュリティ研究者向けです。
