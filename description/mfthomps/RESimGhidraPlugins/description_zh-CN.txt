本项目提供 Ghidra Debugger 扩展插件，将 Ghidra 与 RESim 逆向工程平台集成，使分析人员可将 Ghidra 用作 RESim 驱动分析的反汇编器与调试器前端。该套件主要使用 Java 编写，添加了 RESim 专用的调试器窗口及实用工具，支持书签、观察标记、栈检查、交互式控制台，以及寄存器和内存引用的列表悬停辅助功能。它通过 gdb-multiarch 远程调试连接 RESim 目标，包括端口 9123 上的 Simics 全系统仿真会话，并复现了 RESim 原有 IDA Pro 插件中的大部分功能。这些插件面向需要进行动态、仿真支持的二进制分析（而非仅静态反汇编）的逆向工程师与安全研究人员。
