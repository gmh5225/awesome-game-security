This project provides Ghidra Debugger extension plugins that integrate Ghidra with the RESim reverse engineering platform, letting analysts use Ghidra as the disassembler and debugger front end for RESim-driven analysis. Written primarily in Java, the suite adds RESim-specific debugger windows and utilities for bookmarks, watchmarks, stack inspection, an interactive console, and listing hover helpers for registers and memory references. It connects to RESim targets through gdb-multiarch remote debugging, including Simics full-system simulation sessions on port 9123, and mirrors much of the functionality previously available in RESim's IDA Pro plugins. The plugins are intended for reverse engineers and security researchers who perform dynamic, simulation-backed binary analysis rather than static disassembly alone.
