CaptureEngine 是一款用于游戏捕获、录制、屏幕叠加、图形覆盖与帧率控制的 Windows 工具。它主要用 C++ 编写，并采用 Python 构建系统，可通过 Windows Graphics Capture、DXGI Desktop Duplication，或注入式 API 感知挂钩路径（拦截 D3D9 至 D3D12、Vulkan、OpenGL 和 DXVK）将视频及多路音频源录制为 Matroska 格式。该工具支持通过 NVENC、AMD AMF、Intel Quick Sync 和 Media Foundation 进行硬件编码，提供支持 HDR 的自定义叠加层及 DLSS 与 FSR 帧生成集成，基于 NVIDIA Reflex 的 FPS 限制，以及针对 V-Sync、各向异性过滤和 DLSS 覆盖的逐应用配置文件。项目明确记录了非注入式捕获模式与注入式挂钩功能之间的反作弊安全边界，因此适用于游戏安全研究、图形 API 逆向工程，以及在可控制注入风险的高级单机捕获工作流中。
