CaptureEngine은 게임 캡처, 녹화, 화면 오버레이, 그래픽 오버라이드 및 프레임 페이싱을 위한 Windows 도구입니다. 주로 C++로 작성되었으며 Python 빌드 시스템을 사용하며, Windows Graphics Capture, DXGI Desktop Duplication 또는 D3D9부터 D3D12, Vulkan, OpenGL, DXVK를 가로채는 주입형 API 인식 후크 경로를 통해 비디오와 여러 오디오 소스를 Matroska 형식으로 기록합니다. NVENC, AMD AMF, Intel Quick Sync, Media Foundation을 통한 하드웨어 인코딩, DLSS 및 FSR 프레임 생성 통합을 갖춘 HDR 인식 사용자 정의 오버레이, NVIDIA Reflex 기반 FPS 제한, V-Sync, 이방성 필터링 및 DLSS 오버라이드를 위한 애플리케이션별 프로필을 제공합니다. 이 프로젝트는 비주입 캡처 모드와 주입 후크 기능 간의 명시적인 안티치트 안전 경계를 문서화하여, 게임 보안 연구, 그래픽 API 리버스 엔지니어링, 주입 위험을 통제할 수 있는 고급 싱글플레이어 캡처 워크플로에 유용합니다.
