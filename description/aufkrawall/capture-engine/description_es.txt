CaptureEngine es una herramienta de Windows para captura de juegos, grabación, superposiciones en pantalla, anulaciones gráficas y control del ritmo de fotogramas. Escrita principalmente en C++ con un sistema de compilación en Python, registra vídeo y múltiples fuentes de audio en Matroska mediante Windows Graphics Capture, DXGI Desktop Duplication o una ruta de hook inyectado consciente de la API que intercepta D3D9 hasta D3D12, Vulkan, OpenGL y DXVK. Ofrece codificación por hardware mediante NVENC, AMD AMF, Intel Quick Sync y Media Foundation, superposiciones personalizadas compatibles con HDR e integración de generación de fotogramas DLSS y FSR, limitación de FPS basada en NVIDIA Reflex y perfiles por aplicación para V-Sync, filtrado anisotrópico y anulaciones de DLSS. El proyecto documenta explícitamente los límites de seguridad anti-trampas entre los modos de captura no inyectados y las funciones de hook inyectado, lo que lo hace relevante para la investigación en seguridad de juegos, ingeniería inversa de API gráficas y flujos avanzados de captura en un jugador donde el riesgo de inyección puede controlarse.
