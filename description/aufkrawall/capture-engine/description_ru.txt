CaptureEngine — инструмент для Windows, предназначенный для захвата игр, записи, экранных оверлеев, графических переопределений и управления темпом кадров. Написан в основном на C++ с системой сборки на Python; записывает видео и несколько аудиоисточников в Matroska с помощью Windows Graphics Capture, DXGI Desktop Duplication или инжектируемого пути перехвата с учётом API, который перехватывает D3D9 через D3D12, Vulkan, OpenGL и DXVK. Поддерживает аппаратное кодирование через NVENC, AMD AMF, Intel Quick Sync и Media Foundation, пользовательские HDR-оверлеи с интеграцией генерации кадров DLSS и FSR, ограничение FPS на базе NVIDIA Reflex, а также профили для отдельных приложений для V-Sync, анизотропной фильтрации и переопределений DLSS. Проект явно документирует границы безопасности античита между режимами захвата без инжекции и функциями инжектируемого хука, что делает его полезным для исследований безопасности игр, реверс-инжиниринга графических API и продвинутых сценариев захвата в одиночной игре, где риск инжекции можно контролировать.
