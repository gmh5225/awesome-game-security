CaptureEngine è uno strumento Windows per la cattura di giochi, la registrazione, le sovrapposizioni a schermo, le override grafiche e il controllo del frame pacing. Scritto principalmente in C++ con un sistema di build Python, registra video e più sorgenti audio in Matroska tramite Windows Graphics Capture, DXGI Desktop Duplication o un percorso hook iniettato consapevole delle API che intercetta D3D9 fino a D3D12, Vulkan, OpenGL e DXVK. Offre codifica hardware tramite NVENC, AMD AMF, Intel Quick Sync e Media Foundation, overlay personalizzati compatibili con HDR con integrazione della generazione di fotogrammi DLSS e FSR, limitazione FPS basata su NVIDIA Reflex e profili per applicazione per V-Sync, filtraggio anisotropico e override DLSS. Il progetto documenta esplicitamente i confini di sicurezza anti-cheat tra le modalità di cattura non iniettate e le funzionalità hook iniettate, rendendolo rilevante per la ricerca sulla sicurezza dei giochi, il reverse engineering delle API grafiche e flussi di lavoro avanzati di cattura single-player in cui il rischio di iniezione può essere controllato.
