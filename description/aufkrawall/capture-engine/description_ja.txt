CaptureEngine は、ゲームのキャプチャ、録画、画面上のオーバーレイ、グラフィックス上書き、フレームペーシング向けの Windows ツールです。主に C++ で書かれ、Python ビルドシステムを用い、Windows Graphics Capture、DXGI Desktop Duplication、または D3D9 から D3D12、Vulkan、OpenGL、DXVK を横取りする注入型 API 対応フック経路により、映像と複数のオーディオソースを Matroska 形式で記録します。NVENC、AMD AMF、Intel Quick Sync、Media Foundation によるハードウェアエンコード、DLSS と FSR フレーム生成統合を備えた HDR 対応カスタムオーバーレイ、NVIDIA Reflex ベースの FPS 制限、V-Sync、異方性フィルタリング、DLSS 上書きの各アプリケーションプロファイルを提供します。非注入キャプチャモードと注入フック機能の間の反チート安全境界を明示的に文書化しており、ゲームセキュリティ研究、グラフィックス API のリバースエンジニアリング、注入リスクを管理できる高度なシングルプレイヤーキャプチャワークフローに適しています。
