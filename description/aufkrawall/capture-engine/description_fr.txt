CaptureEngine est un outil Windows pour la capture de jeux, l'enregistrement, les superpositions à l'écran, les remplacements graphiques et la gestion du rythme d'images. Écrit principalement en C++ avec un système de compilation Python, il enregistre la vidéo et plusieurs sources audio au format Matroska via Windows Graphics Capture, DXGI Desktop Duplication ou un chemin de hook injecté sensible aux API qui intercepte D3D9 jusqu'à D3D12, Vulkan, OpenGL et DXVK. Il propose l'encodage matériel via NVENC, AMD AMF, Intel Quick Sync et Media Foundation, des superpositions personnalisées compatibles HDR avec intégration de génération d'images DLSS et FSR, une limitation FPS basée sur NVIDIA Reflex, ainsi que des profils par application pour V-Sync, le filtrage anisotropique et les remplacements DLSS. Le projet documente explicitement les limites de sécurité anti-triche entre les modes de capture non injectés et les fonctionnalités de hook injecté, ce qui le rend pertinent pour la recherche en sécurité des jeux, l'ingénierie inverse des API graphiques et les workflows avancés de capture en solo où le risque d'injection peut être maîtrisé.
