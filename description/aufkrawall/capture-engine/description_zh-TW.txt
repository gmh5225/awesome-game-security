CaptureEngine 是一款用於遊戲擷取、錄製、螢幕疊加、圖形覆寫與幀率控制的 Windows 工具。它主要以 C++ 編寫，並採用 Python 建置系統，可透過 Windows Graphics Capture、DXGI Desktop Duplication，或注入式 API 感知掛鉤路徑（攔截 D3D9 至 D3D12、Vulkan、OpenGL 和 DXVK）將影片及多路音訊來源錄製為 Matroska 格式。此工具支援透過 NVENC、AMD AMF、Intel Quick Sync 和 Media Foundation 進行硬體編碼，提供支援 HDR 的自訂疊加層及 DLSS 與 FSR 幀生成整合，基於 NVIDIA Reflex 的 FPS 限制，以及針對 V-Sync、各向異性過濾和 DLSS 覆寫的逐應用程式設定檔。專案明確記錄了非注入式擷取模式與注入式掛鉤功能之間的反作弊安全邊界，因此適用於遊戲安全研究、圖形 API 逆向工程，以及在可控制注入風險的進階單機擷取工作流程中。
