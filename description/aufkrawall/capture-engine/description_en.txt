CaptureEngine is a Windows tool for game capture, recording, on-screen overlays, graphics overrides, and frame pacing. Written primarily in C++ with a Python build system, it records video and multiple audio sources to Matroska using Windows Graphics Capture, DXGI Desktop Duplication, or an injected API-aware hook path that intercepts D3D9 through D3D12, Vulkan, OpenGL, and DXVK. It offers hardware encoding through NVENC, AMD AMF, Intel Quick Sync, and Media Foundation, custom HDR-aware overlays with DLSS and FSR frame-generation integration, NVIDIA Reflex-based FPS limiting, and per-application profiles for V-Sync, anisotropic filtering, and DLSS overrides. The project documents explicit anti-cheat safety boundaries between non-injected capture modes and injected hook features, making it relevant for game security research, reverse engineering of graphics APIs, and advanced single-player capture workflows where injection risk can be controlled.
