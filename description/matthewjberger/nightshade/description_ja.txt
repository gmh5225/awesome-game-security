Nightshade は、プラグイン構成の App モデルと段階的なシステムスケジュールを備え、3D および 2D ゲームを構築するための Rust 製ゲームエンジンです。カスタム動的 ECS、wgpu ベースのレンダラー、高水準の nightshade-api ファサードに加え、レンダリング、オーディオ、物理、ナビメッシュ、UI、OpenXR、Steam 向けの低水準エンジンクレートを提供します。ゲームは機能プラグインから組み立てられ、glTF からシーンを読み込み、Trunk などの WASM ツールでデスクトップまたは Web をターゲットにできます。付属のエディタと Rhai スクリプティングにより、対話的なシーン制作とプロトタイピングが可能です。主な用途はゲーム開発とエンジン実験であり、アンチチートやリバースエンジニアリングではありません。
