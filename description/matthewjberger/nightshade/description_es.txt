Nightshade es un motor de juegos en Rust para crear juegos 3D y 2D con un modelo App compuesto por plugins y planificaciones de sistemas por etapas. Ofrece un ECS dinámico personalizado, un renderizador basado en wgpu y una fachada de alto nivel nightshade-api, junto con crates de motor de bajo nivel para renderizado, audio, física, navmesh, UI, OpenXR y Steam. Los juegos se ensamblan a partir de plugins de capacidades, cargan escenas desde glTF y pueden apuntar a escritorio o a la web mediante herramientas WASM como Trunk. Un editor incluido y el scripting Rhai permiten la creación interactiva de escenas y la creación de prototipos. El caso de uso principal es el desarrollo de juegos y la experimentación con motores, no el anti-cheat ni la ingeniería inversa.
