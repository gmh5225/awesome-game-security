Nightshade ist eine Rust-Spiel-Engine zum Erstellen von 3D- und 2D-Spielen mit einem aus Plugins zusammengesetzten App-Modell und gestaffelten System-Schedules. Sie bietet ein eigenes dynamisches ECS, einen wgpu-basierten Renderer sowie eine High-Level-Fassade nightshade-api neben niedrigeren Engine-Crates für Rendering, Audio, Physik, Navmesh, UI, OpenXR und Steam. Spiele werden aus Capability-Plugins zusammengesetzt, laden Szenen aus glTF und können Desktop oder das Web über WASM-Tooling wie Trunk ansteuern. Ein mitgelieferter Editor und Rhai-Scripting unterstützen interaktives Scene-Authoring und Prototyping. Der Hauptzweck ist Spieleentwicklung und Engine-Experimente, nicht Anti-Cheat oder Reverse Engineering.
