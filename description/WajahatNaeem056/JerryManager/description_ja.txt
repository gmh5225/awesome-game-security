JerryManager は、Magisk および KernelSU 向けの Android モジュールで、root 化済みデバイス上で Play Integrity バイパスと root 検出回避を統合的に制御します。主に shell スクリプトで構築され、ブラウザベースの Web UI を備え、Play Integrity Fix、OhMyKeymint、Tricky Store、TEESimulator、Zygisk Next を統合して keybox、証明（attestation）、アプリ単位のターゲティングを管理します。主な機能には、セキュリティパッチおよびブートプロパティの偽装、カスタム ROM フィンガープリントのクリーンアップ、Frida などのフック痕跡を除去するバンキングモード、早期ブート時のプロパティ注入によるロック済み・非デバッグ可能なデバイスプロファイルの提示が含まれます。Google Play Integrity や類似の整合性チェックに依存するアプリやゲームから root、改ざん、計装を隠す必要がある研究者や上級ユーザー向けです。
