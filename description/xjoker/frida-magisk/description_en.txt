This project is a Magisk and KernelSU module that bundles official Frida Android server and Gadget binaries with a custom Zygisk-based injector into flashable ZIP packages for rooted devices. It supports server-only, hybrid, and Gadget-only runtime modes, per-app Gadget injection via configurable package targets, and stable on-device control through shell scripts plus an optional KernelSU WebUI. Build tooling downloads and SHA-256-verifies upstream Frida assets, compiles the native injector for arm64, arm32, x86, and x86_64, and ships CI-driven releases; an optional antidetect flavor supplies renamed assets for environments that fingerprint standard Frida layouts. Primary languages include C++ for the Zygisk injector, shell for module logic, and JavaScript for the WebUI. It targets Android reverse engineers and game security researchers who need reliable Frida deployment and process instrumentation without manual server setup on each device.
