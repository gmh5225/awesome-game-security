Этот проект — модуль Magisk и KernelSU, который объединяет официальные бинарники сервера Frida для Android и Gadget с пользовательским инжектором на базе Zygisk в прошиваемые ZIP-пакеты для устройств с root. Поддерживаются режимы только сервер, гибридный и только Gadget, инъекция Gadget по приложениям через настраиваемые цели пакетов и стабильное управление на устройстве через shell-скрипты и опциональный WebUI KernelSU. Сборочные инструменты загружают upstream-ресурсы Frida и проверяют их SHA-256, компилируют нативный инжектор для arm64, arm32, x86 и x86_64 и публикуют релизы через CI; опциональный antidetect-вариант поставляет переименованные ресурсы для сред, которые отпечатывают стандартные раскладки Frida. Основные языки: C++ для Zygisk-инжектора, shell для логики модуля и JavaScript для WebUI. Ориентирован на Android-реверс-инженеров и исследователей безопасности игр, которым нужно надёжное развёртывание Frida и инструментирование процессов без ручной настройки сервера на каждом устройстве.
