本项目是一个 Magisk 与 KernelSU 模块，将官方 Frida Android 服务端与 Gadget 二进制文件，以及基于 Zygisk 的自定义注入器，打包为适用于已 root 设备的可刷写 ZIP。支持仅服务端、混合与仅 Gadget 三种运行模式，可通过可配置的包名目标实现按应用注入 Gadget，并通过 shell 脚本及可选的 KernelSU WebUI 在设备上稳定控制。构建工具会下载上游 Frida 资源并用 SHA-256 校验，为 arm64、arm32、x86 与 x86_64 编译原生注入器，并发布 CI 驱动的版本；可选的反检测变体提供重命名资源，适用于会指纹化标准 Frida 布局的环境。主要语言包括用于 Zygisk 注入器的 C++、模块逻辑的 shell，以及 WebUI 的 JavaScript。面向需要可靠 Frida 部署与进程插桩、且不想在每台设备上手动配置服务端的 Android 逆向工程师与游戏安全研究人员。
