Questo progetto è un modulo Magisk e KernelSU che raggruppa i binari ufficiali del server Frida Android e Gadget con un iniettore personalizzato basato su Zygisk in pacchetti ZIP flashabili per dispositivi rootati. Supporta modalità runtime solo server, ibride e solo Gadget, iniezione Gadget per app tramite target di pacchetti configurabili e controllo stabile sul dispositivo tramite script shell più una WebUI KernelSU opzionale. Gli strumenti di build scaricano e verificano con SHA-256 le risorse Frida upstream, compilano l'iniettore nativo per arm64, arm32, x86 e x86_64 e rilasciano versioni guidate da CI; una variante antidetect opzionale fornisce risorse rinominate per ambienti che fingerprintano layout Frida standard. I linguaggi principali includono C++ per l'iniettore Zygisk, shell per la logica del modulo e JavaScript per la WebUI. È rivolto a reverse engineer Android e ricercatori di sicurezza dei giochi che necessitano di deployment Frida affidabile e strumentazione dei processi senza configurazione manuale del server su ogni dispositivo.
