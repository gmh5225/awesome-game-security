Este proyecto es un módulo Magisk y KernelSU que empaqueta los binarios oficiales del servidor Frida Android y Gadget con un inyector personalizado basado en Zygisk en paquetes ZIP instalables por flash para dispositivos con root. Admite modos de ejecución solo servidor, híbrido y solo Gadget, inyección de Gadget por aplicación mediante objetivos de paquetes configurables, y control estable en el dispositivo mediante scripts shell más una WebUI opcional de KernelSU. Las herramientas de compilación descargan y verifican con SHA-256 los recursos Frida upstream, compilan el inyector nativo para arm64, arm32, x86 y x86_64, y publican releases impulsadas por CI; una variante antidetect opcional proporciona recursos renombrados para entornos que fingerprintean disposiciones Frida estándar. Los lenguajes principales incluyen C++ para el inyector Zygisk, shell para la lógica del módulo y JavaScript para la WebUI. Está dirigido a ingenieros inversos de Android e investigadores de seguridad de juegos que necesitan despliegue fiable de Frida e instrumentación de procesos sin configuración manual del servidor en cada dispositivo.
