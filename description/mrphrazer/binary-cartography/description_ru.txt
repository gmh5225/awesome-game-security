Binary Cartography — это курируемый репозиторий серии вебинаров, посвящённый практическому реверс-инжинирингу, анализу вредоносного ПО и защите программного обеспечения на реальных бинарных файлах. Каждая папка сессии содержит слайды, образцы бинарных файлов, справочные материалы и автономные Docker-окружения на базе Kali, предварительно настроенные с Ghidra или Binary Ninja, AI-агентами для программирования с подключением через MCP и распространёнными инструментами анализа. Серия исследует агентные рабочие процессы, автоматизирующие инспекцию бинарных файлов, восстановление структуры, триаж вредоносного ПО, эвристическую идентификацию кода и деобфускацию при всё более сложных схемах защиты. Основные технологии включают Python, Docker, Ghidra headless MCP, Binary Ninja headless MCP и фреймворки символического анализа, такие как Miasm и msynth. Предназначен для технических специалистов по безопасности, реверс-инженеров и аналитиков вредоносного ПО, которым нужны практические методы анализа защищённого или обфусцированного программного обеспечения, основанные на рабочих процессах.
