Binary Cartography 是一個精心策劃的網路研討會系列儲存庫，專注於針對真實二進位檔案的實用逆向工程、惡意軟體分析和軟體保護。每個會話資料夾包含簡報、範例二進位檔、參考資料，以及基於 Kali 的獨立 Docker 環境，預先配置 Ghidra 或 Binary Ninja、透過 MCP 連接的 AI 程式設計代理，以及常見分析工具。此系列探索代理式工作流程，可自動化二進位檢查、結構復原、惡意軟體分類、啟發式程式碼識別，以及針對日益複雜保護方案的解混淆。主要技術包括 Python、Docker、Ghidra headless MCP、Binary Ninja headless MCP，以及 Miasm 與 msynth 等符號分析框架。面向希望採用實務性、工作流程驅動方法分析受保護或混淆軟體的技術安全專業人員、逆向工程師與惡意軟體分析師。
