Binary Cartography は、実際のバイナリを対象とした実践的なリバースエンジニアリング、マルウェア分析、ソフトウェア保護に焦点を当てた、厳選されたウェビナーシリーズのリポジトリです。各セッションフォルダには、スライド、サンプルバイナリ、参考文献、Ghidra または Binary Ninja、MCP 接続の AI コーディングエージェント、一般的な分析ツールが事前設定された Kali ベースの独立型 Docker 環境が含まれます。このシリーズでは、バイナリ検査、構造復元、マルウェアトリアージ、ヒューリスティックなコード識別、ますます複雑化する保護方式に対する難読化解除を自動化するエージェント型ワークフローを探求します。主な技術には Python、Docker、Ghidra headless MCP、Binary Ninja headless MCP、Miasm や msynth などのシンボリック分析フレームワークが含まれます。保護されたソフトウェアや難読化されたソフトウェアを分析するための実践的でワークフロー駆動型の手法を求める、技術系セキュリティ専門家、リバースエンジニア、マルウェアアナリストを対象としています。
