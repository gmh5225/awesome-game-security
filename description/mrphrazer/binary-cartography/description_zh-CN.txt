Binary Cartography 是一个精心策划的网络研讨会系列仓库，专注于针对真实二进制文件的实用逆向工程、恶意软件分析和软件保护。每个会话文件夹包含幻灯片、示例二进制文件、参考资料，以及基于 Kali 的独立 Docker 环境，预配置了 Ghidra 或 Binary Ninja、通过 MCP 连接的 AI 编程代理以及常用分析工具。该系列探讨代理式工作流，可自动执行二进制检查、结构恢复、恶意软件分类、启发式代码识别，以及针对日益复杂保护方案的解混淆。主要技术包括 Python、Docker、Ghidra headless MCP、Binary Ninja headless MCP，以及 Miasm 和 msynth 等符号分析框架。面向希望采用实践性、工作流驱动方法分析受保护或混淆软件的技术安全专业人员、逆向工程师和恶意软件分析师。
