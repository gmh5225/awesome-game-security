Binary Cartography is a curated webinar series repository focused on practical reverse engineering, malware analysis, and software protection for real binaries. Each session folder includes slides, sample binaries, references, and self-contained Kali-based Docker environments preconfigured with Ghidra or Binary Ninja, MCP-connected AI coding agents, and common analysis tooling. The series explores agentic workflows that automate binary inspection, structure recovery, malware triage, heuristic code identification, and deobfuscation across increasingly complex protection schemes. Primary technologies include Python, Docker, Ghidra headless MCP, Binary Ninja headless MCP, and symbolic analysis frameworks such as Miasm and msynth. It is aimed at technical security professionals, reverse engineers, and malware analysts who want hands-on, workflow-driven methods for analyzing protected or obfuscated software.
