Binary Cartography는 실제 바이너리를 대상으로 한 실용적인 리버스 엔지니어링, 멀웨어 분석, 소프트웨어 보호에 초점을 맞춘 엄선된 웨비나 시리즈 저장소입니다. 각 세션 폴더에는 슬라이드, 샘플 바이너리, 참고 자료, Ghidra 또는 Binary Ninja, MCP로 연결된 AI 코딩 에이전트, 일반적인 분석 도구가 사전 구성된 Kali 기반 독립형 Docker 환경이 포함됩니다. 이 시리즈는 바이너리 검사, 구조 복구, 멀웨어 분류, 휴리스틱 코드 식별, 점점 복잡해지는 보호 방식에 대한 난독화 해제를 자동화하는 에이전트형 워크플로를 탐구합니다. 주요 기술에는 Python, Docker, Ghidra headless MCP, Binary Ninja headless MCP, Miasm 및 msynth와 같은 심볼릭 분석 프레임워크가 포함됩니다. 보호되거나 난독화된 소프트웨어를 분석하기 위한 실습 중심의 워크플로 기반 방법을 원하는 기술 보안 전문가, 리버스 엔지니어, 멀웨어 분석가를 대상으로 합니다.
