Binary Cartography è un repository di serie di webinar curate, incentrato su reverse engineering pratico, analisi del malware e protezione del software applicati a binari reali. Ogni cartella di sessione include slide, binari di esempio, riferimenti e ambienti Docker autonomi basati su Kali, preconfigurati con Ghidra o Binary Ninja, agenti di coding IA connessi tramite MCP e strumenti di analisi comuni. La serie esplora flussi di lavoro agentici che automatizzano l'ispezione dei binari, il recupero della struttura, il triage del malware, l'identificazione euristica del codice e la deoffuscazione di schemi di protezione sempre più complessi. Le tecnologie principali includono Python, Docker, Ghidra headless MCP, Binary Ninja headless MCP e framework di analisi simbolica come Miasm e msynth. È rivolto a professionisti della sicurezza tecnica, reverse engineer e analisti di malware che desiderano metodi pratici e guidati da flussi di lavoro per analizzare software protetto o offuscato.
