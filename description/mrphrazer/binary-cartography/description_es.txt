Binary Cartography es un repositorio de series de seminarios web seleccionadas, centrado en ingeniería inversa práctica, análisis de malware y protección de software aplicados a binarios reales. Cada carpeta de sesión incluye diapositivas, binarios de ejemplo, referencias y entornos Docker autónomos basados en Kali, preconfigurados con Ghidra o Binary Ninja, agentes de codificación con IA conectados por MCP y herramientas de análisis habituales. La serie explora flujos de trabajo agénticos que automatizan la inspección de binarios, la recuperación de estructuras, el triaje de malware, la identificación heurística de código y la desofuscación frente a esquemas de protección cada vez más complejos. Las tecnologías principales incluyen Python, Docker, Ghidra headless MCP, Binary Ninja headless MCP y marcos de análisis simbólico como Miasm y msynth. Está dirigido a profesionales de seguridad técnica, ingenieros de ingeniería inversa y analistas de malware que buscan métodos prácticos y orientados a flujos de trabajo para analizar software protegido u ofuscado.
