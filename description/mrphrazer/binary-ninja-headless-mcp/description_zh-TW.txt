一個無介面的 Binary Ninja 伺服器，實作了模型上下文協定（MCP），無需 Binary Ninja GUI 即可向 AI 代理程式暴露深度逆向工程能力。以 Python 3.11+ 撰寫，提供涵蓋反組譯、中間語言檢視、修補、型別管理、交叉參考、記憶體檢查、搜尋、腳本編寫以及復原/重做工作流程的 36 個功能群組、共 181 個工具。伺服器支援 stdio 與 TCP 傳輸，預設以唯讀方式執行並提供安全的變更路徑，還包含用於無 Binary Ninja 授權的 CI 與開發的模擬後端模式。專為沙箱容器與虛擬機器中的代理程式驅動逆向工程而設計，支援自動化二進位分析、型別與中繼資料的漸進式優化，以及遊戲安全、反作弊與惡意軟體研究工作流程的互動式引導。
