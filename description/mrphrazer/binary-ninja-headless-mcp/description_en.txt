A headless Binary Ninja server that implements the Model Context Protocol (MCP), exposing deep reverse-engineering capabilities to AI agents without requiring the Binary Ninja GUI. Written in Python 3.11+, it provides 181 tools across 36 feature groups covering disassembly, intermediate language views, patching, type management, cross-references, memory inspection, search, scripting, and undo/redo workflows. The server supports stdio and TCP transports, runs read-only by default with safe mutation paths, and includes a fake backend mode for CI and development without a Binary Ninja license. It is designed for agent-driven reverse engineering in sandboxed containers and VMs, enabling automated binary analysis, incremental refinement of types and metadata, and interactive steering of game security, anti-cheat, and malware research workflows.
