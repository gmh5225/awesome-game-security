Ein headless Binary-Ninja-Server, der das Model Context Protocol (MCP) implementiert und KI-Agenten tiefgreifende Reverse-Engineering-Funktionen bereitstellt, ohne die Binary-Ninja-GUI zu benötigen. In Python 3.11+ geschrieben, bietet er 181 Tools in 36 Funktionsgruppen für Disassemblierung, Zwischensprachen-Ansichten, Patching, Typverwaltung, Querverweise, Speicherinspektion, Suche, Skripting sowie Undo/Redo-Workflows. Der Server unterstützt stdio- und TCP-Transporte, läuft standardmäßig schreibgeschützt mit sicheren Mutationspfaden und enthält einen Fake-Backend-Modus für CI und Entwicklung ohne Binary-Ninja-Lizenz. Er ist für agentengesteuertes Reverse Engineering in sandboxed Containern und VMs konzipiert und ermöglicht automatisierte Binäranalyse, schrittweise Verfeinerung von Typen und Metadaten sowie interaktive Steuerung von Workflows in den Bereichen Spielesicherheit, Anti-Cheat und Malware-Forschung.
