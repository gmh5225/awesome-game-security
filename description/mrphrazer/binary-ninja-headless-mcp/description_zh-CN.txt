一个无界面的 Binary Ninja 服务器，实现了模型上下文协议（MCP），无需 Binary Ninja GUI 即可向 AI 智能体暴露深度逆向工程能力。基于 Python 3.11+ 编写，提供涵盖反汇编、中间语言视图、补丁、类型管理、交叉引用、内存检查、搜索、脚本编写以及撤销/重做工作流的 36 个功能组、共 181 个工具。服务器支持 stdio 与 TCP 传输，默认以只读方式运行并提供安全的变更路径，还包含用于无 Binary Ninja 许可证的 CI 与开发的模拟后端模式。专为沙箱容器与虚拟机中的智能体驱动逆向工程设计，支持自动化二进制分析、类型与元数据的渐进式优化，以及游戏安全、反作弊与恶意软件研究工作流的交互式引导。
