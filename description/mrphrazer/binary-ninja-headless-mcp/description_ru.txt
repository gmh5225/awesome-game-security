Headless-сервер Binary Ninja, реализующий Model Context Protocol (MCP) и предоставляющий ИИ-агентам глубокие возможности реверс-инжиниринга без необходимости в GUI Binary Ninja. Написан на Python 3.11+ и предоставляет 181 инструмент в 36 функциональных группах, охватывающих дизассемблирование, представления промежуточного языка, патчинг, управление типами, перекрёстные ссылки, инспекцию памяти, поиск, скриптинг и рабочие процессы отмены/повтора. Сервер поддерживает транспорты stdio и TCP, по умолчанию работает в режиме только для чтения с безопасными путями изменения и включает режим фиктивного бэкенда для CI и разработки без лицензии Binary Ninja. Предназначен для реверс-инжиниринга под управлением агентов в изолированных контейнерах и виртуальных машинах, обеспечивая автоматизированный бинарный анализ, поэтапное уточнение типов и метаданных, а также интерактивное управление рабочими процессами в области безопасности игр, античита и исследования вредоносного ПО.
