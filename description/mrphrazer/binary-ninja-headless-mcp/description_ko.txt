Model Context Protocol(MCP)을 구현한 헤드리스 Binary Ninja 서버로, Binary Ninja GUI 없이 AI 에이전트에 심층적인 리버스 엔지니어링 기능을 제공합니다. Python 3.11+로 작성되었으며, 디스어셈블리, 중간 언어 뷰, 패치, 타입 관리, 교차 참조, 메모리 검사, 검색, 스크립팅, 실행 취소/다시 실행 워크플로를 아우르는 36개 기능 그룹에 걸쳐 181개의 도구를 제공합니다. 서버는 stdio 및 TCP 전송을 지원하며, 기본적으로 읽기 전용으로 실행되고 안전한 변경 경로를 제공합니다. Binary Ninja 라이선스 없이 CI 및 개발에 사용할 수 있는 가짜 백엔드 모드도 포함됩니다. 샌드박스 컨테이너와 VM에서 에이전트 기반 리버스 엔지니어링을 위해 설계되었으며, 자동화된 바이너리 분석, 타입 및 메타데이터의 점진적 개선, 게임 보안, 안티치트, 멀웨어 연구 워크플로의 대화형 제어를 가능하게 합니다.
