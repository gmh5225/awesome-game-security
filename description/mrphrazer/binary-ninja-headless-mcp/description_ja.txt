Model Context Protocol（MCP）を実装したヘッドレス Binary Ninja サーバーで、Binary Ninja GUI を必要とせず AI エージェントに高度なリバースエンジニアリング機能を提供します。Python 3.11+ で書かれており、逆アセンブル、中間言語ビュー、パッチ適用、型管理、クロスリファレンス、メモリ検査、検索、スクリプト、元に戻す/やり直しワークフローを網羅する 36 の機能グループにわたる 181 のツールを備えています。サーバーは stdio と TCP トランスポートをサポートし、デフォルトでは読み取り専用で動作し、安全な変更パスを提供します。Binary Ninja ライセンスなしで CI や開発に使えるフェイクバックエンドモードも含まれます。サンドボックス化されたコンテナや VM 上でのエージェント駆動型リバースエンジニアリング向けに設計され、自動化されたバイナリ解析、型とメタデータの段階的な改善、ゲームセキュリティ、チート対策、マルウェア研究ワークフローの対話的な制御を可能にします。
