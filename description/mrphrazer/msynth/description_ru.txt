msynth — это Python-фреймворк для деобфускации кода, упрощающий выражения Mixed Boolean-Arithmetic (MBA) путём сведения сложных побитовых и арифметических формул к более коротким эквивалентным формам. Он обходит абстрактные синтаксические деревья выражений и применяет алгебраические и семантические переписывания с поддержкой oracle с использованием больших предвычисленных таблиц поиска либо обучается эквивалентным выражениям через стохастический синтез программ с дополнением Search Modulo Inference Rules (Smir). Построен на Miasm с опциональной интеграцией символического исполнения, включает методы вроде SiMBA и GAMBA, поддерживает параллельную обработку и может проверять упрощения с помощью SMT-решателя. Предназначен для специалистов по реверс-инжинирингу и бинарного анализа, восстанавливающих читаемую семантику из MBA-насыщенной обфускации в защищённом ПО.
