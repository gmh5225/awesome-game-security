msynth는 혼합 불-산술(MBA) 표현식을 단순화하여 복잡한 비트 연산 및 산술 공식을 더 짧은 동치 형태로 축소하는 Python 코드 난독화 해제 프레임워크입니다. 표현식의 추상 구문 트리를 순회하며 대규모 사전 계산 룩업 테이블을 활용한 oracle 기반 대수·의미적 재작성을 적용하거나, Search Modulo Inference Rules(Smir)를 보강한 확률적 프로그램 합성을 통해 동치 표현식을 학습합니다. Miasm 위에 구축되었으며 선택적으로 기호 실행을 통합할 수 있고, SiMBA 및 GAMBA 같은 기법을 포함하며 병렬 처리를 지원하고 SMT 솔버로 단순화 결과를 검증할 수 있습니다. 보호된 소프트웨어의 MBA 중심 난독화에서 읽기 쉬운 의미를 복원하려는 리버스 엔지니어와 바이너리 분석가를 대상으로 합니다.
