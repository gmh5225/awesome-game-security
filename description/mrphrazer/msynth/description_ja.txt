msynth は、混合ブール算術（MBA）式を簡素化し、複雑なビット演算や算術式をより短い等価形に還元する Python 製コード難読化解除フレームワークです。式の抽象構文木を走査し、大規模な事前計算ルックアップテーブルを用いた oracle 支援の代数的・意味的書き換えを適用するか、あるいは Search Modulo Inference Rules（Smir）を組み込んだ確率的プログラム合成により等価式を学習します。Miasm 上に構築され、オプションで記号実行を統合でき、SiMBA や GAMBA などの手法を取り入れ、並列処理に対応し、SMT ソルバーによる簡素化の検証も可能です。保護されたソフトウェアにおける MBA 主体の難読化から読みやすい意味を復元する、リバースエンジニアやバイナリ解析者向けのツールです。
