msynth es un framework de Python para desofuscación de código que simplifica expresiones Mixed Boolean-Arithmetic (MBA) reduciendo fórmulas bitwise y aritméticas complejas a formas equivalentes más cortas. Recorre árboles de sintaxis abstracta de expresiones y aplica reescrituras algebraicas y semánticas respaldadas por oráculos usando grandes tablas de búsqueda precalculadas, o bien aprende expresiones equivalentes mediante síntesis estocástica de programas reforzada con Search Modulo Inference Rules (Smir). Construido sobre Miasm con integración opcional de ejecución simbólica, incorpora técnicas como SiMBA y GAMBA, admite procesamiento en paralelo y puede verificar simplificaciones con un solucionador SMT. Está dirigido a ingenieros de ingeniería inversa y analistas de binarios que buscan recuperar semántica legible de ofuscación con alto contenido de MBA en software protegido.
