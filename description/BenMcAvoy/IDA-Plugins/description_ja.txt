MSVC でビルドされたゲームおよびネイティブバイナリに対する一般的なリバースエンジニアリング作業を自動化するため、まとめてビルド・導入できる IDA Pro および Hex-Rays デコンパイラ向けプラグインのコレクションです。スイートには仮想呼び出しと vtable ナビゲーション、ワンクリックでの再型付けと STL コンテナの整理、インライン化された XXHash32/64 や strlen ループなどの CRT イディオムの折りたたみ、MSVC RTTI に基づくシングルトンと継承解析および構造体レイアウトの合成が含まれます。専用の Lua 関数ファインダは Scrap Mechanic 系バイナリ向けで、luaL_register バインディングの特定、Lua エントリポイントのリネーム、引数個数チェックのボイラープレートを読みやすい疑似コードに折り込みます。プラグインは現行 IDA SDK 向けに C++ と CMake で実装され、小さな Python ドキュメントジェネレータも付属し、Windows ターゲットでの深い静的解析、modding、ゲームセキュリティ研究を行う研究者を想定しています。
