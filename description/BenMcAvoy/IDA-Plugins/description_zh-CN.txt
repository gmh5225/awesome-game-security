这是一套可统一部署的 IDA Pro 与 Hex-Rays 反编译器插件，用于在 MSVC 编写的游戏及原生二进制文件上自动完成常见逆向工程任务。套件涵盖虚调用与 vtable 导航、一键重类型化与 STL 容器清理、折叠内联的 XXHash32/64 及 strlen 循环等 CRT 惯用法，以及基于 MSVC RTTI 的单例与继承分析及结构体布局合成。专用 Lua 函数查找器面向 Scrap Mechanic 类二进制：定位 luaL_register 绑定、重命名 Lua 入口点，并将参数个数检查样板折叠为可读伪代码。插件以 C++ 与 CMake 针对现代 IDA SDK 实现，并附带小型 Python 文档生成器，面向在 Windows 目标上做深度静态分析、模组化与游戏安全工作的研究人员。
