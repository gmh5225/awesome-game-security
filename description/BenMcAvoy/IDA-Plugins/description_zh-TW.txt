這是一套可一併建置與安裝的 IDA Pro 與 Hex-Rays 反編譯器外掛集合，用於在 MSVC 遊戲與原生二進位檔上自動化常見的逆向工程工作。套件包含虛擬呼叫與 vtable 導覽、一鍵重新型別化與 STL 容器清理、摺疊內嵌的 XXHash32/64 以及 strlen 迴圈等 CRT 慣用法，以及以 MSVC RTTI 為基礎的單例與繼承分析及結構配置合成。專用的 Lua 函式尋找器鎖定 Scrap Mechanic 風格的二進位檔，透過定位 luaL_register 繫結、重新命名 Lua 進入點，並將參數個數檢查樣板摺入可讀的虛擬碼。外掛以 C++ 搭配 CMake 針對現代 IDA SDK 實作，並附小型 Python 文件產生器，目標對象為在 Windows 目標上從事深度靜態分析、模組化與遊戲安全研究的研發人員。
