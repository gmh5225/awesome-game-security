A collection of IDA Pro and Hex-Rays decompiler plugins built and installed together to automate common reverse-engineering chores on MSVC game and native binaries. The suite includes utilities for virtual-call and vtable navigation, one-click retyping and cleanup of STL containers, collapsing inlined XXHash32/64 and CRT idioms such as strlen loops, and MSVC RTTI-based singleton and inheritance analysis with struct layout synthesis. A dedicated Lua function finder targets Scrap Mechanic-style binaries by locating luaL_register bindings, renaming Lua entry points, and folding argument-count check boilerplate into readable pseudocode. Plugins are implemented in C++ with CMake against the modern IDA SDK, plus a small Python doc generator, and are aimed at researchers doing deep static analysis, modding, and game security work on Windows targets.
