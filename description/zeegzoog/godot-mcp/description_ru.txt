Godot MCP Server — кроссплатформенный сервер Model Context Protocol, который позволяет AI-ассистентам для программирования осматривать и управлять работающим редактором Godot 4 и запущенными игровыми проектами. Он сочетает нативный бинарник на Rust со stdio JSON-RPC и Tokio с плагином редактора на GDScript, который связывается через локальный WebSocket, применяет изменения сцен и узлов через систему отмены редактора и при закрытом GUI переключается на headless CLI Godot для проверки версий, валидации скриптов и пакетной работы. Доступные инструменты включают деревья сцен и редактирование свойств, снимки viewport, создание скриптов и проверку синтаксиса, запуск и остановку, а также вывод работающей игры, обход дерева, ввод и снимки через удалённый отладчик. Мост привязан к loopback, требует общий токен и проверяет пути проектов и идентификаторы, чтобы снизить риск случайного или межпроцессного злоупотребления. Ориентирован на разработчиков игр и технических пользователей, которые хотят автоматизировать разработку, тестирование и отладку Godot 4.x с помощью MCP-клиентов вроде Cursor или Claude в Windows, Linux и macOS.
