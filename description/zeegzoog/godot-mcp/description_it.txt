Godot MCP Server è un server Model Context Protocol multipiattaforma che consente agli assistenti di coding basati su IA di ispezionare e controllare un editor Godot 4 attivo e progetti di gioco in esecuzione. Combina un binario Rust nativo con stdio JSON-RPC e Tokio con un plugin editor GDScript che fa da ponte su WebSocket locale, applica modifiche a scene e nodi tramite il sistema di annullamento dell’editor e ricorre alla CLI Godot headless per controlli di versione, validazione degli script e lavoro batch quando la GUI è chiusa. Gli strumenti esposti includono alberi di scena e modifica delle proprietà, screenshot del viewport, creazione di script e controlli di sintassi, avvio e arresto, oltre a output del gioco in esecuzione, ispezione dell’albero, input e screenshot tramite il debugger remoto. Il ponte è associato al loopback, richiede un token condiviso e convalida percorsi di progetto e identificatori per ridurre abusi casuali o tra processi. È pensato per sviluppatori di giochi e utenti tecnici che vogliono usare client MCP come Cursor o Claude per automatizzare sviluppo, test e debug live di Godot 4.x su Windows, Linux e macOS.
