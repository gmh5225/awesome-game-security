Godot MCP Server est un serveur Model Context Protocol multiplateforme qui permet aux assistants de codage IA d’inspecter et de contrôler un éditeur Godot 4 actif et des projets de jeu en cours d’exécution. Il associe un binaire Rust natif utilisant stdio JSON-RPC et Tokio à une extension d’éditeur GDScript qui communique via une WebSocket locale, applique les changements de scènes et de nœuds via le système d’annulation de l’éditeur, et bascule vers la CLI Godot sans interface lorsque l’interface graphique est fermée pour les vérifications de version, la validation de scripts et le traitement par lots. Les outils exposés comprennent les arbres de scène et l’édition de propriétés, les captures du viewport, la création de scripts et les contrôles de syntaxe, lecture et arrêt, ainsi que la sortie du jeu en cours, l’inspection de l’arbre, les entrées et les captures via le débogueur distant. Le pont est lié à la boucle locale, exige un jeton partagé et valide les chemins de projet et les identifiants pour limiter les abus opportunistes ou interprocessus. Il s’adresse aux développeurs de jeux et aux utilisateurs techniques qui souhaitent automatiser le développement, les tests et le débogage en direct de Godot 4.x avec des clients MCP tels que Cursor ou Claude sur Windows, Linux et macOS.
