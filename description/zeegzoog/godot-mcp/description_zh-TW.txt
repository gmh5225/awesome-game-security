Godot MCP Server 是一款跨平台的 Model Context Protocol 伺服器，讓 AI 程式設計助手能夠檢查並控制正在執行的 Godot 4 編輯器與遊戲專案。它由以 stdio JSON-RPC 與 Tokio 建構的原生 Rust 二進位程式，以及透過本機 WebSocket 橋接的 GDScript 編輯器外掛組成；後者經編輯器復原系統套用場景與節點變更，並在 GUI 關閉時改以無頭 Godot CLI 進行版本檢查、腳本驗證與批次作業。公開的工具包含場景樹與屬性編輯、視埠截圖、腳本建立與語法檢查、播放與停止，以及透過遠端除錯器取得執行中遊戲的輸出、樹狀檢查、輸入與截圖。橋接綁定至回環位址，需要共用權杖，並驗證專案路徑與識別碼，以降低路過式或跨程序濫用風險。面向希望以 Cursor、Claude 等 MCP 用戶端在 Windows、Linux 與 macOS 上自動化 Godot 4.x 開發、測試與即時除錯的遊戲開發者與技術使用者。
