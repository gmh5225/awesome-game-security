Godot MCP Server는 AI 코딩 어시스턴트가 실행 중인 Godot 4 에디터와 게임 프로젝트를 조사하고 제어할 수 있게 하는 크로스 플랫폼 Model Context Protocol 서버입니다. stdio JSON-RPC와 Tokio를 사용하는 네이티브 Rust 바이너리와 로컬 WebSocket으로 연결하는 GDScript 에디터 플러그인을 결합하며, 에디터 실행 취소 시스템을 통해 씬과 노드 변경을 적용하고 GUI가 닫혀 있을 때는 헤드리스 Godot CLI로 버전 확인, 스크립트 검증, 배치 작업으로 대체합니다. 제공 도구에는 씬 트리와 속성 편집, 뷰포트 스크린샷, 스크립트 생성 및 구문 검사, 재생 및 중지, 원격 디버거를 통한 실행 중 게임 출력, 트리 검사, 입력, 스크린샷이 포함됩니다. 브리지는 루프백에 바인딩되고 공유 토큰을 요구하며 프로젝트 경로와 식별자를 검증해 임의 또는 프로세스 간 남용을 줄입니다. Windows, Linux, macOS에서 Cursor나 Claude 같은 MCP 클라이언트로 Godot 4.x 개발, 테스트, 라이브 디버깅을 자동화하려는 게임 개발자와 기술 사용자를 대상으로 합니다.
