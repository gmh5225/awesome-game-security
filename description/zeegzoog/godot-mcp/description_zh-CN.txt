Godot MCP Server 是一款跨平台的 Model Context Protocol 服务器，让 AI 编程助手能够检查并控制正在运行的 Godot 4 编辑器与游戏项目。它由基于 stdio JSON-RPC 与 Tokio 的原生 Rust 二进制程序，以及通过本地 WebSocket 桥接的 GDScript 编辑器插件组成；后者经编辑器撤销系统应用场景与节点变更，并在 GUI 关闭时回退到无头 Godot CLI 进行版本检查、脚本验证与批处理。暴露的工具包括场景树与属性编辑、视口截图、脚本创建与语法检查、播放与停止，以及通过远程调试器获取运行中游戏的输出、树检查、输入与截图。桥接绑定到回环地址，需要共享令牌，并校验项目路径与标识符，以降低路过式或跨进程滥用风险。面向希望用 Cursor、Claude 等 MCP 客户端在 Windows、Linux 与 macOS 上自动化 Godot 4.x 开发、测试与实时调试的游戏开发者及技术用户。
