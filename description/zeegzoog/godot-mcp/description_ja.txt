Godot MCP Server は、AI コーディングアシスタントが稼働中の Godot 4 エディターと実行中のゲームプロジェクトを調査・制御できるクロスプラットフォームの Model Context Protocol サーバーです。stdio JSON-RPC と Tokio を用いるネイティブ Rust バイナリと、ローカル WebSocket で橋渡しする GDScript エディタープラグインを組み合わせ、エディターの Undo システム経由でシーンとノードの変更を適用し、GUI が閉じているときはヘッドレス Godot CLI にフォールバックしてバージョン確認、スクリプト検証、バッチ処理を行います。公開ツールにはシーンツリーとプロパティ編集、ビューポートのスクリーンショット、スクリプト作成と構文チェック、再生と停止に加え、リモートデバッガー経由の実行中ゲームの出力、ツリー調査、入力、スクリーンショットが含まれます。ブリッジはループバックにバインドし、共有トークンを要求し、プロジェクトパスと識別子を検証して、偶発的またはプロセス間の悪用を抑えます。Windows、Linux、macOS 上で Godot 4.x の開発、テスト、ライブデバッグを Cursor や Claude などの MCP クライアントで自動化したいゲーム開発者と技術ユーザー向けです。
