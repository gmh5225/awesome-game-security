Godot MCP Server es un servidor Model Context Protocol multiplataforma que permite a los asistentes de codificación con IA inspeccionar y controlar un editor Godot 4 en vivo y proyectos de juego en ejecución. Combina un binario nativo en Rust que usa stdio JSON-RPC y Tokio con un complemento de editor GDScript que se conecta mediante WebSocket local, aplica cambios de escenas y nodos a través del sistema de deshacer del editor y recurre a la CLI headless de Godot para comprobaciones de versión, validación de scripts y trabajo por lotes cuando la interfaz gráfica está cerrada. Las herramientas expuestas incluyen árboles de escena y edición de propiedades, capturas del viewport, creación de scripts y comprobaciones de sintaxis, reproducir y detener, además de salida del juego en ejecución, inspección del árbol, entrada y capturas mediante el depurador remoto. El puente se enlaza a loopback, exige un token compartido y valida rutas de proyecto e identificadores para reducir abusos oportunistas o entre procesos. Está dirigido a desarrolladores de juegos y usuarios técnicos que quieren que clientes MCP como Cursor o Claude automaticen el desarrollo, las pruebas y la depuración en vivo de Godot 4.x en Windows, Linux y macOS.
