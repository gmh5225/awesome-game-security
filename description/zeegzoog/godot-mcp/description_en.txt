Godot MCP Server is a cross-platform Model Context Protocol server that lets AI coding assistants inspect and control a live Godot 4 editor and running game projects. It combines a native Rust binary using stdio JSON-RPC and Tokio with a GDScript editor plugin that bridges over a local WebSocket, applies scene and node changes through the editor undo system, and falls back to headless Godot CLI for version checks, script validation, and batch work when the GUI is closed. Exposed tools include scene trees and property editing, viewport screenshots, script creation and syntax checks, play and stop, plus running-game output, tree inspection, input, and screenshots through the remote debugger. The bridge binds to loopback, requires a shared token, and validates project paths and identifiers to reduce drive-by or cross-process abuse. It is aimed at game developers and technical users who want MCP clients such as Cursor or Claude to automate Godot 4.x development, testing, and live debugging on Windows, Linux, and macOS.
