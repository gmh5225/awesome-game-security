TotK Recomp は、『ゼルダの伝説 ティアーズ オブ ザ キングダム』を Nintendo Switch の ARM64 バイナリから、Vulkan ベースのグラフィックスバックエンドを備えたネイティブ Windows x86-64 実行ファイルへ静的再コンパイルする。Python 駆動のリフターとコードジェネレータが NSO モジュールを C に変換し、Unicorn CPU エミュレータとの差分テストで検証する。バージョン別パッチリストが複数の小売版ゲームビルドに対応する。ランタイムは Windows 上で Switch カーネルサービス、NVN グラフィックス、オーディオ、入力、ファイルシステムの挙動をエミュレートし、解像度スケーリング、ウルトラワイドレイアウト、フレームレート制御などのオプション強化も含む。同梱のインストーラとビルドパイプラインが llvm-mingw でリフトしたコードをローカルにコンパイルするため、リポジトリには再コンパイル済みのゲームバイナリは同梱されない。本プロジェクトは、静的再コンパイル、コンソールバイナリリフティング、低レベルなゲーム移植を研究する研究者と開発者を対象とし、著作権で保護されたゲームアセットの配布を目的としない。
