TotK Recomp статически перекомпилирует The Legend of Zelda: Tears of the Kingdom из ARM64-бинарников Nintendo Switch в нативный исполняемый файл Windows x86-64 с графическим бэкендом на Vulkan. Под управлением Python лифтер и генератор кода переводят модули NSO в C с проверкой дифференциальными тестами против эмулятора CPU Unicorn; списки патчей для конкретных версий адаптируют несколько розничных сборок игры. Среда выполнения эмулирует на Windows сервисы ядра Switch, графику NVN, аудио, ввод и поведение файловой системы, включая опциональные улучшения вроде масштабирования разрешения, ultrawide-разметки и управления частотой кадров. В комплекте установщик и конвейер сборки компилируют поднятый код локально с llvm-mingw, поэтому перекомпилированные бинарники игры в репозиторий не поставляются. Проект предназначен для исследователей и разработчиков, изучающих статическую перекомпиляцию, подъём консольных бинарников и низкоуровневый портинг игр, а не для распространения защищённых авторским правом игровых ресурсов.
