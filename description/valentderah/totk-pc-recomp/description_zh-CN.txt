TotK Recomp 将《塞尔达传说：王国之泪》从 Nintendo Switch ARM64 二进制静态重编译为基于 Vulkan 图形后端的原生 Windows x86-64 可执行文件。由 Python 驱动的提升器与代码生成器将 NSO 模块翻译为 C 代码，并通过与 Unicorn CPU 模拟器的差分测试进行验证；版本专用补丁列表则适配多种零售版游戏构建。运行时于 Windows 上模拟 Switch 内核服务、NVN 图形、音频、输入与文件系统行为，并支持分辨率缩放、超宽布局与帧率控制等可选增强。捆绑的安装程序与构建流水线使用 llvm-mingw 在本地编译提升后的代码，因此仓库中不附带重编译后的游戏二进制。本项目面向研究静态重编译、主机二进制提升与底层游戏移植的研究者与开发者，而非用于分发受版权保护的游戏资源。
