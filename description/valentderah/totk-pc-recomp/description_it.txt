TotK Recomp ricompila staticamente The Legend of Zelda: Tears of the Kingdom dai binari ARM64 di Nintendo Switch in un eseguibile Windows x86-64 nativo con backend grafico basato su Vulkan. Un lifter e un generatore di codice guidati da Python traducono i moduli NSO in C, convalidati tramite test differenziali rispetto all’emulatore CPU Unicorn, mentre elenchi di patch specifici per versione adattano più build retail del gioco. Il runtime emula su Windows i servizi kernel Switch, la grafica NVN, audio, input e il comportamento del filesystem, incluse migliorie opzionali come scaling della risoluzione, layout ultrawide e controllo del framerate. Un installer incluso e una pipeline di build compilano il codice sollevato in locale con llvm-mingw, quindi nel repository non vengono distribuiti binari di gioco ricompilati. Il progetto è rivolto a ricercatori e sviluppatori che studiano ricompilazione statica, lifting di binari console e porting di giochi a basso livello, non alla distribuzione di asset di gioco protetti da copyright.
