TotK Recomp는 『젤다의 전설: 티어스 오브 더 킹덤』을 Nintendo Switch ARM64 바이너리에서 Vulkan 기반 그래픽 백엔드를 갖춘 네이티브 Windows x86-64 실행 파일로 정적 재컴파일한다. Python 기반 리프터와 코드 생성기가 NSO 모듈을 C로 변환하며, Unicorn CPU 에뮬레이터와의 차분 테스트로 검증한다. 버전별 패치 목록이 여러 소매용 게임 빌드를 지원한다. 런타임은 Windows에서 Switch 커널 서비스, NVN 그래픽, 오디오, 입력, 파일 시스템 동작을 에뮬레이트하며, 해상도 스케일링, 울트라와이드 레이아웃, 프레임레이트 제어 등 선택적 개선도 포함한다. 번들 설치 프로그램과 빌드 파이프라인이 llvm-mingw로 리프트된 코드를 로컬에서 컴파일하므로, 저장소에는 재컴파일된 게임 바이너리가 포함되지 않는다. 이 프로젝트는 정적 재컴파일, 콘솔 바이너리 리프팅, 저수준 게임 포팅을 연구하는 연구자와 개발자를 대상으로 하며, 저작권으로 보호된 게임 자산 배포를 목적으로 하지 않는다.
