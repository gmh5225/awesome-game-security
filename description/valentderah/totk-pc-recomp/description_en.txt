TotK Recomp statically recompiles The Legend of Zelda: Tears of the Kingdom from Nintendo Switch ARM64 binaries into a native Windows x86-64 executable with a Vulkan-based graphics backend. A Python-driven lifter and code generator translate NSO modules into C that is validated with differential tests against the Unicorn CPU emulator, while version-specific patch lists adapt multiple retail game builds. The runtime emulates Switch kernel services, NVN graphics, audio, input, and filesystem behavior on Windows, including optional enhancements such as resolution scaling, ultrawide layout, and frame-rate controls. A bundled installer and build pipeline compile the lifted code locally with llvm-mingw so no recompiled game binaries are shipped in the repository. The project is aimed at researchers and developers studying static recompilation, console binary lifting, and low-level game porting rather than at distributing copyrighted game assets.
