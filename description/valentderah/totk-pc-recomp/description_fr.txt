TotK Recomp recompile statiquement The Legend of Zelda: Tears of the Kingdom à partir des binaires ARM64 Nintendo Switch en un exécutable Windows x86-64 natif avec un backend graphique basé sur Vulkan. Un lifter et un générateur de code pilotés par Python traduisent les modules NSO en C, validés par des tests différentiels contre l’émulateur CPU Unicorn, tandis que des listes de correctifs spécifiques à chaque version adaptent plusieurs builds retail du jeu. Le runtime émule sur Windows les services noyau Switch, la graphique NVN, l’audio, les entrées et le comportement du système de fichiers, y compris des améliorations optionnelles comme le scaling de résolution, la mise en page ultrawide et le contrôle du framerate. Un installateur fourni et une chaîne de build compilent le code relevé localement avec llvm-mingw, sans binaires de jeu recompilés dans le dépôt. Le projet s’adresse aux chercheurs et développeurs qui étudient la recompilation statique, le lifting de binaires console et le portage bas niveau de jeux, et non à la distribution d’actifs de jeu protégés par le droit d’auteur.
