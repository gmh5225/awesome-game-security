EnesMem is a modern Windows x64 memory scanner and editor for attaching to running processes, narrowing values, and editing or freezing game state in a Cheat Engine–style workflow. It is built with Python and PyQt6 for the GUI, uses pure ctypes for Win32 memory access, and offloads heavy scanning to a Rust native core for large speedups on AOB, pointer, and next-scan operations. Key capabilities include first and next scan with many comparison modes, array-of-byte and wildcard searches, pointer chain resolution, a hex viewer with Capstone disassembly, hardware breakpoint “what writes here” tracing, speedhack, and trainer generation. The interface offers a resizable three-pane workspace with dark and light themes and Turkish or English localization. It targets reverse engineers, solo game modders, and security researchers who need a portable, tested tool for authorized local process analysis rather than production anti-cheat development.
