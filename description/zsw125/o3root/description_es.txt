O3 Root es una aplicación Android impulsada por Shizuku que encadena un exploit de kernel para CVE-2026-98260 y obtiene root temporal en dispositivos Xiaomi HyperOS seleccionados con Linux 6.18. La carga nativa en C activa un use-after-free, recuperación de páginas y una primitiva de escritura en árbol rojo-negro en dos etapas con deslizamiento KASLR; después eleva credenciales y carga un módulo de kernel cargable de la familia KernelSU embebido solo para el arranque actual. La app complementaria en Java orquesta comprobaciones de permisos, filtrado por firmware, ejecución del payload vía modo shell de Shizuku y selección automática entre los módulos incluidos KernelSU, KernelSU-Next o SukiSU mediante resolución kallsyms en tiempo de ejecución o reenlace de símbolos. Herramientas Python y shell cubren compilación de payload y APK, análisis de OTA e imágenes boot y verificación BTF del kernel. Está orientada a la investigación de exploits de kernel móvil, flujos de root en Android y analistas de seguridad que estudian escalada de privilegios, interacción con SELinux y root persistente en arranque frente a root efímero en firmware de consumo endurecido.
