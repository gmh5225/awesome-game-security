O3 Root 是一款由 Shizuku 驱动的 Android 应用，将针对 CVE-2026-98260 的内核漏洞利用串联起来，在部分运行 Linux 6.18 的小米 HyperOS 设备上获得临时 root。C 语言原生载荷触发 use-after-free、页回收，以及带 KASLR 滑动的两阶段红黑树写原语，随后提升凭证并加载内嵌的 KernelSU 系可加载内核模块，且仅对当前启动有效。配套 Java 应用负责权限检查、固件门控、通过 Shizuku shell 模式执行载荷，并借助运行时 kallsyms 解析或符号重链接在捆绑的 KernelSU、KernelSU-Next 或 SukiSU 模块间自动选择。Python 与 shell 工具支持载荷与 APK 构建、OTA 与 boot 镜像分析以及内核 BTF 校验。面向移动内核漏洞研究、Android root 流程，以及研究权限提升、SELinux 交互与加固消费级固件上持久 root 与临时 root 的安全分析人员。
