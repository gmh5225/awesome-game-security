O3 Root is a Shizuku-driven Android application that chains a kernel exploit for CVE-2026-98260 into temporary root on select Xiaomi HyperOS devices running Linux 6.18. The native payload in C drives a use-after-free trigger, page reclaim, and a two-stage red-black tree write primitive with KASLR sliding, then elevates credentials and loads an embedded KernelSU-family loadable kernel module for the current boot only. The companion app is written in Java and orchestrates permission checks, firmware gating, payload execution via Shizuku shell mode, and automatic selection among bundled KernelSU, KernelSU-Next, or SukiSU modules using runtime kallsyms resolution or symbol relinking. Supporting Python and shell tooling covers payload and APK builds, OTA and boot-image analysis, and kernel BTF verification. It targets mobile kernel exploit research, Android rooting workflows, and security analysts studying privilege escalation, SELinux interaction, and boot-persistent versus ephemeral root on hardened consumer firmware.
