O3 Root — Android-приложение на базе Shizuku, которое связывает эксплойт ядра для CVE-2026-98260 с получением временного root на отдельных устройствах Xiaomi HyperOS под Linux 6.18. Нативная полезная нагрузка на C запускает use-after-free, reclaim страниц и двухэтапную примитивную запись в красно-чёрное дерево со сдвигом KASLR, затем повышает учётные данные и загружает встроенный загружаемый модуль ядра семейства KernelSU только для текущей загрузки. Сопутствующее приложение на Java координирует проверки разрешений, фильтрацию по прошивке, выполнение полезной нагрузки через shell-режим Shizuku и автоматический выбор среди bundled-модулей KernelSU, KernelSU-Next или SukiSU с помощью разрешения kallsyms во время выполнения или перелинковки символов. Вспомогательные инструменты на Python и shell охватывают сборку полезной нагрузки и APK, анализ OTA и boot-образов и проверку BTF ядра. Ориентировано на исследование мобильных эксплойтов ядра, сценарии root на Android и аналитиков безопасности, изучающих повышение привилегий, взаимодействие с SELinux и постоянный при загрузке против эфемерного root на упрочнённой потребительской прошивке.
