O3 Root는 Shizuku 기반 Android 앱으로, CVE-2026-98260용 커널 exploit을 연쇄하여 Linux 6.18에서 동작하는 일부 Xiaomi HyperOS 기기에서 임시 root를 얻는다. C 네이티브 페이로드가 use-after-free 트리거, 페이지 회수, KASLR 슬라이딩이 포함된 2단계 레드-블랙 트리 쓰기 프리미티브를 구동한 뒤 자격 증명을 상승시키고 현재 부팅에 한해 내장 KernelSU 계열 로드 가능 커널 모듈을 적재한다. Java 동반 앱은 권한 검사, 펌웨어 게이팅, Shizuku 셸 모드로의 페이로드 실행, 실행 시 kallsyms 해석 또는 심볼 재링크를 통한 번들 KernelSU·KernelSU-Next·SukiSU 모듈 자동 선택을 조율한다. Python 및 shell 도구는 페이로드와 APK 빌드, OTA 및 boot 이미지 분석, 커널 BTF 검증을 다룬다. 모바일 커널 exploit 연구, Android rooting 워크플로, 권한 상승·SELinux 상호작용, 강화된 소비자 펌웨어에서 부팅 지속 root와 일시 root를 연구하는 보안 분석가를 대상으로 한다.
