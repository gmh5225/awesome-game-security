O3 Root 是一款由 Shizuku 驅動的 Android 應用程式，將針對 CVE-2026-98260 的核心漏洞利用串接起來，在部分執行 Linux 6.18 的小米 HyperOS 裝置上取得暫時性 root。C 語言原生載荷觸發 use-after-free、頁面回收，以及含 KASLR 滑動的兩階段紅黑樹寫入原語，隨後提升憑證並載入內嵌的 KernelSU 系可載入核心模組，且僅對目前開機有效。配套 Java 應用程式負責權限檢查、韌體閘控、透過 Shizuku shell 模式執行載荷，並以執行期 kallsyms 解析或符號重連結在捆綁的 KernelSU、KernelSU-Next 或 SukiSU 模組間自動選擇。Python 與 shell 工具涵蓋載荷與 APK 建置、OTA 與 boot 映像分析以及核心 BTF 驗證。面向行動核心漏洞研究、Android root 流程，以及研究權限提升、SELinux 互動與強化消費級韌體上持久 root 與暫時 root 的安全分析人員。
