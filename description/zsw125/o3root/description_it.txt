O3 Root è un’applicazione Android guidata da Shizuku che concatena un exploit kernel per CVE-2026-98260 per ottenere root temporaneo su dispositivi Xiaomi HyperOS selezionati con Linux 6.18. Il payload nativo in C attiva un use-after-free, il reclaim delle pagine e una primitiva di scrittura su albero rosso-nero in due fasi con sliding KASLR, quindi eleva le credenziali e carica un modulo kernel caricabile della famiglia KernelSU incorporato solo per l’avvio corrente. L’app companion in Java orchestra controlli dei permessi, gating del firmware, esecuzione del payload via modalità shell Shizuku e selezione automatica tra i moduli inclusi KernelSU, KernelSU-Next o SukiSU tramite risoluzione kallsyms a runtime o relinking dei simboli. Strumenti Python e shell coprono build di payload e APK, analisi OTA e immagini boot e verifica BTF del kernel. È rivolta alla ricerca su exploit kernel mobile, workflow di rooting Android e analisti di sicurezza che studiano escalation di privilegi, interazione SELinux e root persistente al boot versus root effimero su firmware consumer hardened.
