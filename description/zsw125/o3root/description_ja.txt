O3 Root は Shizuku 連携の Android アプリで、CVE-2026-98260 向けカーネル exploit を連鎖させ、Linux 6.18 上の HyperOS を動かす一部の Xiaomi 端末で一時的な root を得る。C 製ネイティブペイロードが use-after-free の起動、ページ回収、KASLR スライド付き二段階レッドブラック木書き込みプリミティブを駆動し、資格情報を昇格したうえで、現在のブートに限り埋め込み KernelSU 系ロード可能カーネルモジュールを読み込む。Java のコンパニオンアプリが権限チェック、ファームウェアゲート、Shizuku シェルモード経由のペイロード実行、および実行時 kallsyms 解決またはシンボル再リンクによる同梱 KernelSU・KernelSU-Next・SukiSU モジュールの自動選択を統括する。Python と shell ツールはペイロードと APK のビルド、OTA と boot イメージ解析、カーネル BTF 検証をカバーする。モバイルカーネル exploit 研究、Android root ワークフロー、権限昇格・SELinux 相互作用、ハード化されたコンシューマファームウェア上の永続 root と一時 root を調べるセキュリティ分析者向け。
