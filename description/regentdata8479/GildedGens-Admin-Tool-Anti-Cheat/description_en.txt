GildedGens Admin Control System with GILDEDGENS GUARD is a Minecraft Bedrock behavior pack that combines Realm administration tooling with in-world anti-cheat enforcement through the official Script API. It is implemented in JavaScript and provides staff dashboards via native UI forms, role-based permissions, full hotbar and armor inventory inspection, configurable item blacklists with wildcard IDs, and an inventory scanner that supports dry-run logging before live removal. GILDEDGENS GUARD layers heuristic movement, combat, and world-interaction checks such as speed, fly, reach, KillAura, and nuker detection, using violation levels, decay, lag-aware sampling, and escalating punishments from warnings through kicks. Persistent world dynamic properties store audits, bans, and configuration so enforcement survives restarts. It targets Bedrock Realm and dedicated world owners who need server-side moderation and cheat mitigation without external networking or packet-level hooks.
