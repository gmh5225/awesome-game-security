GildedGens Admin Control System と GILDEDGENS GUARD は、公式 Script API を通じて Realm 管理ツールとワールド内アンチチート施行を組み合わせた Minecraft Bedrock のビヘイビアパックです。JavaScript で実装され、ネイティブ UI フォームによるスタッフ用ダッシュボード、ロールベースの権限、ホットバーと防具インベントリの完全検査、ワイルドカード ID 対応の設定可能なアイテムブラックリスト、およびライブ削除前にドライラン記録に対応したインベントリスキャナーを提供します。GILDEDGENS GUARD はスピード、飛行、リーチ、KillAura、nuker 検知などのヒューリスティックな移動・戦闘・ワールド操作チェックを重ね、違反レベル、減衰、ラグを考慮したサンプリング、警告からキックまでの段階的処罰を用います。永続的なワールド動的プロパティに監査、BAN、設定を保存し、再起動後も施行が維持されます。外部ネットワークやパケットレベルのフックなしで、サーバー側のモデレーションとチート対策が必要な Bedrock Realm および専用ワールドオーナー向けです。
