GildedGens 管理控制系統搭配 GILDEDGENS GUARD，是一款 Minecraft 基岩版行為包，透過官方 Script API 將 Realm 管理工具與遊戲內反作弊執法結合。它以 JavaScript 實作，透過原生 UI 表單提供工作人員儀表板、角色權限、快捷欄與盔甲欄完整檢視、支援萬用字元 ID 的可設定物品黑名單，以及在正式移除前支援試跑日誌的物品欄掃描器。GILDEDGENS GUARD 疊加啟發式移動、戰鬥與世界互動檢查，例如速度、飛行、攻擊距離、KillAura 與 nuker 等，採用違規等級、衰減、延遲感知取樣，以及從警告到踢出的漸進處罰。持久化世界動態屬性儲存稽核、封禁與設定，使執法在重啟後仍有效。面向需要伺服器端管理與作弊緩解、且無需外部網路或封包層級鉤子的基岩版 Realm 與專用世界擁有者。
