GildedGens Admin Control System con GILDEDGENS GUARD è un behavior pack di Minecraft Bedrock che unisce strumenti di amministrazione Realm con l’applicazione anti-cheat in mondo tramite la Script API ufficiale. È implementato in JavaScript e offre dashboard per lo staff tramite moduli UI nativi, permessi basati sui ruoli, ispezione completa di hotbar e inventario armature, blacklist di oggetti configurabili con ID con caratteri jolly e uno scanner inventario che supporta logging in dry-run prima della rimozione effettiva. GILDEDGENS GUARD sovrappone controlli euristici su movimento, combattimento e interazione col mondo come rilevamento di speed, fly, reach, KillAura e nuker, usando livelli di violazione, decadimento, campionamento consapevole del lag e punizioni progressive da avvertimenti a kick. Proprietà dinamiche persistenti del mondo memorizzano audit, ban e configurazione così che l’applicazione sopravviva ai riavvii. È rivolto a proprietari di Realm Bedrock e mondi dedicati che necessitano moderazione lato server e mitigazione dei cheat senza networking esterno o hook a livello di pacchetti.
