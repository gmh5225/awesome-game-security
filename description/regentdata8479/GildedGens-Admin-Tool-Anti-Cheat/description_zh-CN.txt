GildedGens 管理控制系统配合 GILDEDGENS GUARD，是一款 Minecraft 基岩版行为包，通过官方 Script API 将 Realm 管理工具与游戏内反作弊执法相结合。它以 JavaScript 实现，通过原生 UI 表单提供员工控制台、基于角色的权限、快捷栏与盔甲栏完整检视、支持通配符 ID 的可配置物品黑名单，以及在正式删除前支持试跑日志的背包扫描器。GILDEDGENS GUARD 叠加启发式移动、战斗与世界交互检测，如速度、飞行、攻击距离、KillAura 与 nuker 等，采用违规等级、衰减、延迟感知采样，以及从警告到踢出的逐级处罚。持久化世界动态属性存储审计、封禁与配置，使执法在重启后仍然有效。面向需要服务端管理与作弊缓解、且无需外部网络或数据包级钩子的基岩版 Realm 与专用世界服主。
