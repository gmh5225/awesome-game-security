GildedGens Admin Control System с GILDEDGENS GUARD — это пакет поведения Minecraft Bedrock, объединяющий инструменты администрирования Realm с внутриигровым античитом через официальный Script API. Реализован на JavaScript и предоставляет панели для персонала через нативные UI-формы, ролевые права, полный осмотр хотбара и инвентаря брони, настраиваемые чёрные списки предметов с подстановочными ID и сканер инвентаря с пробным логированием перед фактическим удалением. GILDEDGENS GUARD накладывает эвристические проверки движения, боя и взаимодействия с миром — скорость, полёт, досягаемость, KillAura и nuker — с уровнями нарушений, затуханием, учётом лагов при выборке и эскалацией наказаний от предупреждений до киков. Постоянные динамические свойства мира хранят аудит, баны и конфигурацию, чтобы применение правил переживало перезапуски. Ориентирован на владельцев Bedrock Realm и выделенных миров, которым нужна серверная модерация и сдерживание читов без внешней сети и перехвата на уровне пакетов.
