GildedGens Admin Control System mit GILDEDGENS GUARD ist ein Minecraft-Bedrock-Verhaltenspaket, das Realm-Administrationstools mit In-World-Anti-Cheat-Durchsetzung über die offizielle Script API verbindet. Es ist in JavaScript implementiert und bietet Mitarbeiter-Dashboards über native UI-Formulare, rollenbasierte Berechtigungen, vollständige Inspektion von Hotbar und Rüstungsinventar, konfigurierbare Item-Blacklists mit Platzhalter-IDs sowie einen Inventarscanner mit Dry-Run-Protokollierung vor der live Entfernung. GILDEDGENS GUARD legt heuristische Bewegungs-, Kampf- und Weltinteraktionsprüfungen wie Speed-, Fly-, Reach-, KillAura- und Nuker-Erkennung darüber und nutzt Verstoßstufen, Abklingen, lag-bewusstes Sampling sowie eskalierende Strafen von Verwarnungen bis zu Kicks. Persistente dynamische Welteigenschaften speichern Audits, Bans und Konfiguration, sodass die Durchsetzung Neustarts überdauert. Zielgruppe sind Bedrock-Realm- und Dedicated-World-Betreiber, die serverseitige Moderation und Cheat-Minderung ohne externes Networking oder Paket-Hooks benötigen.
