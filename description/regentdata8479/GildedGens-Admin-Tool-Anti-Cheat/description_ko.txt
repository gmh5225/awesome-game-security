GildedGens Admin Control System과 GILDEDGENS GUARD는 공식 Script API를 통해 Realm 관리 도구와 게임 내 안티치트 시행을 결합한 Minecraft Bedrock 비헤이비어 팩입니다. JavaScript로 구현되며 네이티브 UI 폼을 통한 스태프 대시보드, 역할 기반 권한, 핫바 및 갑옷 인벤토리 전체 검사, 와일드카드 ID를 지원하는 구성 가능한 아이템 블랙리스트, 실제 제거 전 드라이런 로깅을 지원하는 인벤토리 스캐너를 제공합니다. GILDEDGENS GUARD는 속도, 비행, 리치, KillAura, nuker 탐지 등 휴리스틱 이동·전투·월드 상호작용 검사를 겹치며, 위반 수준, 감쇠, 지연 인식 샘플링, 경고부터 킥까지 단계적 처벌을 사용합니다. 지속적인 월드 동적 속성에 감사, 밴, 설정을 저장해 재시작 후에도 시행이 유지됩니다. 외부 네트워킹이나 패킷 수준 훅 없이 서버 측 관리와 치트 완화가 필요한 Bedrock Realm 및 전용 월드 소유자를 대상으로 합니다.
