Reverse Engineering 4 Fun & Profit 是一個以教學為導向的技術文件儲存庫，系統講解 Windows 逆向工程，從基礎概念到實務分析流程。內容主要以 Markdown 撰寫，並附 C 與組語範例，涵蓋 x86/x64 架構、NASM 與 MASM 語法、Windows 記憶體管理與核心機制，以及可攜式可執行檔（PE）格式，包含標頭、區段、匯入表與匯出表。材料逐步介紹以 IDA、Ghidra、x64dbg、WinDbg、Binary Ninja 和 DnSpy 等工具進行靜態與動態分析，並說明封裝、反除錯及繞過等反分析議題。適合逆向工程、惡意軟體分析與遊戲安全領域的學習者與實務人員，作為結構清晰、適合 Obsidian 使用的工具與技術參考。
