Reverse Engineering 4 Fun & Profit은 Windows 리버스 엔지니어링의 기초부터 실무 분석 워크플로우까지 가르치는 교육용 문서 저장소입니다. 주로 Markdown으로 작성되었으며 C 및 어셈블리 예제를 포함하고, x86/x64 아키텍처, NASM 및 MASM 문법, Windows 메모리 관리와 내부 구조, 헤더·섹션·임포트·익스포트를 포함한 Portable Executable 형식을 다룹니다. IDA, Ghidra, x64dbg, WinDbg, Binary Ninja, DnSpy 등의 도구를 이용한 정적·동적 분석 과정을 안내하며, 패킹, 안티 디버깅, 우회 기법 같은 안티 분석 주제도 설명합니다. 리버스 엔지니어링, 악성코드 분석, 게임 보안 분야의 학습자와 실무자를 위한 체계적이고 Obsidian에 적합한 도구 및 기법 참고 자료입니다.
