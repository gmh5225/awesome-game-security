Reverse Engineering 4 Fun & Profit 是一个面向教学的技术文档仓库，系统讲解 Windows 逆向工程，从基础概念到实际分析流程。内容主要以 Markdown 编写，并配有 C 和汇编示例，涵盖 x86/x64 架构、NASM 与 MASM 语法、Windows 内存管理与内核机制，以及可移植可执行文件（PE）格式，包括头、节、导入表与导出表。材料逐步介绍使用 IDA、Ghidra、x64dbg、WinDbg、Binary Ninja 和 DnSpy 等工具进行静态与动态分析，并讲解打包、反调试及绕过等相关反分析技术。面向逆向工程、恶意软件分析和游戏安全领域的学习者与实践者，提供结构清晰、适合 Obsidian 使用的工具与方法参考。
