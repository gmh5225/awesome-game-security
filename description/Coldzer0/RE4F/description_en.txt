Reverse Engineering 4 Fun & Profit is an educational documentation repository that teaches Windows reverse engineering from fundamentals through practical analysis workflows. Written primarily in Markdown with C and assembly examples, it covers x86/x64 architecture, NASM and MASM syntax, Windows memory management and internals, and the Portable Executable format including headers, sections, imports, and exports. The material walks through static and dynamic analysis using tools such as IDA, Ghidra, x64dbg, WinDbg, Binary Ninja, and DnSpy, and explains anti-analysis topics like packing, anti-debugging, and bypass techniques. It is intended for learners and practitioners in reverse engineering, malware analysis, and game security who want a structured, Obsidian-friendly reference on tools and techniques.
