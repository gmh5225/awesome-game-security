ReverseAI è un motore open source per il reverse engineering statico che ispeziona binari, pacchetti e archivi non attendibili senza eseguirli. È implementato principalmente in Python ed esegue analizzatori pesanti come Ghidra, JADX, LIEF, YARA-X e un parser JavaScript all’interno di container Docker isolati e offline, mentre parser integrati gestiscono ELF, PE, Mach-O, APK e formati correlati sull’host. Ogni fatto riportato è collegato a byte di file esatti, ricalcolato dall’host e classificato come supportato, derivato o non supportato prima che i risultati compaiano in report strutturati. Un’interfaccia a riga di comando e un server MCP consentono ad analisti umani e agenti di coding di porre domande verificate su input approvati, e un modulo hive opzionale può orchestrare la ricostruzione assistita dall’IA di programmi nativi in C o C++ compilabile. È pensato per il lavoro di sicurezza difensiva, come triage di malware, analisi anti-cheat e di client di gioco, e altre attività di reverse engineering in cui l’output degli strumenti non deve essere accettato sulla fede.
