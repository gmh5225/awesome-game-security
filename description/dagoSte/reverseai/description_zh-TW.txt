ReverseAI 是一款用於靜態逆向工程的開源引擎，可在不執行的情況下檢查不受信任的二進位檔、套件與封存檔。它主要以 Python 實作，在隔離的離線 Docker 容器內執行 Ghidra、JADX、LIEF、YARA-X 以及 JavaScript 解析器等重量級分析器，同時內建解析器在主機上處理 ELF、PE、Mach-O、APK 及相關格式。每條報告事實皆對應確切檔案位元組，由主機重新推導，並在發現項目寫入結構化報告之前分類為已支援、推導得出或不支援。命令列介面與 MCP 伺服器讓人類分析師與編碼代理能對經核准輸入提出經核實的問題；可選的 hive 模組可編排由 AI 輔助將原生程式重建為可編譯的 C 或 C++。它鎖定防禦性安全工作，如惡意軟體分級、反作弊與遊戲客戶端分析，以及其他不能輕信工具輸出的逆向工程任務。
