ReverseAI is an open-source engine for static reverse engineering that inspects untrusted binaries, packages, and archives without executing them. It is implemented primarily in Python and runs heavyweight analyzers such as Ghidra, JADX, LIEF, YARA-X, and a JavaScript parser inside locked, offline Docker containers while built-in parsers handle ELF, PE, Mach-O, APK, and related formats on the host. Every reported fact is tied to exact file bytes, re-derived by the host, and classified as supported, derived, or unsupported before findings appear in structured reports. A command-line interface and an MCP server let human analysts and coding agents ask verified questions over approved inputs, and an optional hive module can orchestrate AI-assisted reconstruction of native programs into compilable C or C++. It targets defensive security work such as malware triage, anti-cheat and game-client analysis, and other reverse-engineering tasks where tool output must not be taken on faith.
