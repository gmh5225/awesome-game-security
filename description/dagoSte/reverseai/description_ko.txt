ReverseAI는 신뢰할 수 없는 바이너리, 패키지, 아카이브를 실행하지 않고 검사하는 정적 리버스 엔지니어링용 오픈 소스 엔진입니다. 주로 Python으로 구현되며, Ghidra, JADX, LIEF, YARA-X, JavaScript 파서 같은 무거운 분석기는 격리된 오프라인 Docker 컨테이너 안에서 동작하고, 내장 파서가 호스트에서 ELF, PE, Mach-O, APK 및 관련 형식을 처리합니다. 보고되는 모든 사실은 정확한 파일 바이트에 연결되고 호스트에서 다시 도출되며, 결과가 구조화된 보고서에 나타나기 전에 지원됨, 파생됨, 미지원으로 분류됩니다. 명령줄 인터페이스와 MCP 서버를 통해 인간 분석가와 코딩 에이전트가 승인된 입력에 대해 검증된 질문을 할 수 있으며, 선택적 hive 모듈은 네이티브 프로그램을 컴파일 가능한 C 또는 C++로 AI 보조 재구성하는 작업을 조율할 수 있습니다. 악성코드 분류, 안티치트 및 게임 클라이언트 분석 등 도구 출력을 맹신해서는 안 되는 방어적 보안 작업과 기타 리버스 엔지니어링 과제를 대상으로 합니다.
