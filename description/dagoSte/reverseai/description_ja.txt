ReverseAI は、信頼できないバイナリ、パッケージ、アーカイブを実行せずに検査する静的リバースエンジニアリング向けのオープンソースエンジンです。主に Python で実装され、Ghidra、JADX、LIEF、YARA-X、JavaScript パーサーなどの重量級アナライザを隔離されたオフラインの Docker コンテナ内で動かし、組み込みパーサーがホスト上で ELF、PE、Mach-O、APK および関連フォーマットを処理します。報告される事実はすべて正確なファイルバイトに紐づけられ、ホストで再導出され、所見が構造化レポートに載る前に supported、derived、unsupported に分類されます。コマンドラインインターフェースと MCP サーバーにより、人間のアナリストやコーディングエージェントが承認済み入力に対して検証済みの質問ができ、オプションの hive モジュールはネイティブプログラムをコンパイル可能な C または C++ へ AI 支援で再構成する処理をオーケストレートできます。マルウェアトリアージ、アンチチートやゲームクライアント分析など、ツール出力を盲信してはならない防御的セキュリティ作業やその他のリバースエンジニアリングタスクを対象としています。
