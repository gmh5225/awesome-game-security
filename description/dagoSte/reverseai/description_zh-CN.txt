ReverseAI 是一款用于静态逆向工程的开源引擎，可在不执行的情况下检查不受信任的二进制文件、软件包和归档。它主要用 Python 实现，在隔离的离线 Docker 容器内运行 Ghidra、JADX、LIEF、YARA-X 以及 JavaScript 解析器等重量级分析器，同时内置解析器在宿主机上处理 ELF、PE、Mach-O、APK 及相关格式。每条报告事实均关联到确切文件字节，由宿主机重新推导，并在发现项写入结构化报告之前被归类为已支持、推导得出或不支持。命令行界面与 MCP 服务器让人类分析师和编码智能体能够对经批准输入提出经核实的问题；可选的 hive 模块可编排由 AI 辅助将原生程序重建为可编译的 C 或 C++。它面向防御性安全工作，如恶意软件分类、反作弊与游戏客户端分析，以及其他不能轻信工具输出的逆向工程任务。
