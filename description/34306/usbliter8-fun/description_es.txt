Este proyecto es un kit de herramientas de jailbreak para iOS 27 que usa el exploit SecureROM usbliter8 para poner los dispositivos compatibles en modo PWN DFU y restaurar un firmware personalizado (CFW) parcheado. Se centra en scripts de Python para construir y restaurar CFW, parches de DeviceTree y del kernel, arranque con SSH ramdisk y parcheo binario en userland, con ayudantes en C para redes USB y VNC. La configuración de hardware se basa en una placa RP2350, como una Raspberry Pi Pico 2, conectada a un cable Lightning para activar el exploit en chips A12/A13. Los parches clave omiten USB Restricted Mode, relajan las comprobaciones de sandbox y AMFI trust-cache, y evitan fallos relacionados con SEP para que puedan ejecutarse un bootstrap y un gestor de paquetes. Está orientado a desarrolladores de jailbreak e investigadores de ingeniería inversa de iOS que experimentan en hardware de reserva, y actualmente está documentado para el iPhone 11 Pro.
