本專案是一套 iOS 27 越獄工具包，利用 usbliter8 SecureROM 漏洞將受支援裝置置入 PWN DFU 模式，並刷入已套用修補的自訂韌體（CFW）。核心是用於建置與還原 CFW、DeviceTree 與核心修補、SSH ramdisk 開機以及使用者態二進位修補的 Python 腳本，並輔以用於 USB 連網與 VNC 的 C 輔助程式。硬體方面需使用 RP2350 板卡（如樹莓派 Pico 2）接線至 Lightning 線纜，以在 A12/A13 晶片上觸發漏洞。關鍵修補可繞過 USB Restricted Mode、放寬沙箱與 AMFI trust-cache 檢查，並規避 SEP 相關當機，使引導程式與套件管理器得以運作。面向在備用硬體上實驗的越獄開發者與 iOS 逆向工程研究者，目前文件針對 iPhone 11 Pro。
