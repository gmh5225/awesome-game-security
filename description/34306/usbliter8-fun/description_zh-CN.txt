本项目是一套 iOS 27 越狱工具包，利用 usbliter8 SecureROM 漏洞将受支持设备置入 PWN DFU 模式，并刷入打过补丁的自定义固件（CFW）。核心是用于构建与恢复 CFW、DeviceTree 与内核补丁、SSH ramdisk 启动以及用户态二进制修补的 Python 脚本，并辅以用于 USB 联网与 VNC 的 C 辅助程序。硬件方面需使用 RP2350 板卡（如树莓派 Pico 2）接线至 Lightning 线缆，以在 A12/A13 芯片上触发漏洞。关键补丁可绕过 USB Restricted Mode、放宽沙箱与 AMFI trust-cache 检查，并规避 SEP 相关崩溃，从而使引导程序与包管理器能够运行。面向在备用硬件上实验的越狱开发者与 iOS 逆向研究人员，目前文档针对 iPhone 11 Pro。
