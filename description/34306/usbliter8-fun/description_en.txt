This project is an iOS 27 jailbreak toolkit that uses the usbliter8 SecureROM exploit to put supported devices into PWN DFU mode and restore a patched custom firmware. It centers on Python scripts for building and restoring CFW, DeviceTree and kernel patches, SSH ramdisk boot, and userland binary patching, with supporting C helpers for USB networking and VNC. Hardware setup relies on an RP2350 board such as a Raspberry Pi Pico 2 wired to a Lightning cable to trigger the exploit on A12/A13 chips. Key patches bypass USB Restricted Mode, relax sandbox and AMFI trust-cache checks, and work around SEP-related crashes so a bootstrap and package manager can run. It is aimed at jailbreak developers and iOS reverse-engineering researchers experimenting on spare hardware, currently documented for iPhone 11 Pro.
