本プロジェクトは、usbliter8 SecureROM エクスプロイトを用いて対応デバイスを PWN DFU モードにし、パッチ済みカスタムファームウェア（CFW）を復元する iOS 27 ジェイルブレイク用ツールキットです。中心となるのは CFW のビルドと復元、DeviceTree およびカーネルパッチ、SSH ramdisk ブート、ユーザーランドのバイナリパッチ向け Python スクリプトで、USB ネットワーキングと VNC 用の C ヘルパーが付属します。ハードウェア構成では、RP2350 ボード（Raspberry Pi Pico 2 など）を Lightning ケーブルに接続し、A12/A13 チップでエクスプロイトを発動します。主要パッチは USB Restricted Mode の回避、サンドボックスと AMFI trust-cache チェックの緩和、SEP 関連クラッシュの回避を行い、ブートストラップとパッケージマネージャを動作させます。予備ハードウェアで実験するジェイルブレイク開発者および iOS リバースエンジニアリング研究者向けで、現在は iPhone 11 Pro 向けに文書化されています。
