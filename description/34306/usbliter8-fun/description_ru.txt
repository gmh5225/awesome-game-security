Этот проект — набор инструментов для джейлбрейка iOS 27, который использует эксплойт SecureROM usbliter8, чтобы перевести поддерживаемые устройства в режим PWN DFU и восстановить пропатченную кастомную прошивку (CFW). В центре — Python-скрипты для сборки и восстановления CFW, патчей DeviceTree и ядра, загрузки SSH ramdisk и патчинга бинарников в userland, а также вспомогательные C-программы для USB-сети и VNC. Аппаратная схема опирается на плату RP2350, например Raspberry Pi Pico 2, подключённую к кабелю Lightning для запуска эксплойта на чипах A12/A13. Ключевые патчи обходят USB Restricted Mode, ослабляют проверки sandbox и AMFI trust-cache и обходят связанные с SEP сбои, чтобы могли работать bootstrap и менеджер пакетов. Предназначен для разработчиков джейлбрейка и исследователей реверс-инжиниринга iOS, экспериментирующих на запасном оборудовании; сейчас задокументирован для iPhone 11 Pro.
