SecurityRiskAndroid es una aplicación de ejemplo para Android que implementa un detector de riesgos en tiempo de ejecución por capas para detectar amenazas de manipulación, hooking y root en dispositivos. Combina una interfaz Java con una biblioteca nativa JNI escrita en C que ejecuta comprobaciones sincrónicas rápidas, análisis profundos asíncronos, diagnósticos asistidos por root opcionales y comparaciones de procesos aislados mediante un servicio basado en Messenger. El verificador cubre una amplia gama de señales, incluidos artefactos de Frida y Xposed, conexión de depuradores, mapeos de memoria sospechosos, inconsistencias de ART y visibilidad de paquetes, sondas de KernelSU, indicadores de ubicación simulada y comprobaciones de integridad del código nativo como GOT/PLT, PHDR y verificación de hash disco frente a memoria. Construida con Gradle, Android Gradle Plugin 8.x y CMake/NDK, expone veredictos puntuados y resultados detallados por campo para ayudar a los desarrolladores a estudiar técnicas móviles anti-manipulación y anti-trampas para juegos y otras aplicaciones Android sensibles a la seguridad.
