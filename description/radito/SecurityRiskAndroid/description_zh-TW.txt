SecurityRiskAndroid 是一款 Android 範例應用程式，實作了分層執行階段風險偵測器，用於識別裝置上的篡改、Hook 與 Root 相關威脅。它結合 Java 介面與以 C 語言撰寫的 JNI 原生函式庫，可執行快速的同步檢查、非同步深度掃描、可選的 Root 輔助診斷，以及透過 Messenger 後台服務進行的獨立程序比對。偵測器涵蓋多種信號，包括 Frida 與 Xposed 痕跡、除錯器附加、可疑記憶體對映、ART 與套件可見性不一致、KernelSU 探測、模擬定位指示器，以及 GOT/PLT、PHDR、磁碟與記憶體雜湊驗證等原生程式碼完整性檢查。專案使用 Gradle、Android Gradle Plugin 8.x 和 CMake/NDK 建構，提供含評分的判定結果與詳細欄位輸出，協助開發者研究面向遊戲及其他安全敏感 Android 應用程式的行動防篡改與反作弊技術。
