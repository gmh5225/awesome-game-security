SecurityRiskAndroid は、端末上の改ざん、フック、Root 関連の脅威を検出するための、階層型ランタイムリスク検出器を実装した Android サンプルアプリです。Java UI と C 言語で書かれた JNI ネイティブライブラリを組み合わせ、高速な同期チェック、非同期の詳細スキャン、Root 支援診断（任意）、Messenger ベースのサービスによる独立プロセス比較を実行します。チェッカーは、Frida や Xposed の痕跡、デバッガのアタッチ、不審なメモリマッピング、ART およびパッケージ可視性の不整合、KernelSU プローブ、モック位置情報の兆候、GOT/PLT や PHDR、ディスクとメモリのハッシュ検証など、幅広いシグナルをカバーします。Gradle、Android Gradle Plugin 8.x、CMake/NDK でビルドされ、スコア付きの判定結果と詳細なフィールド結果を公開し、ゲームなどセキュリティに敏感な Android アプリ向けのモバイル改ざん防止・アンチチート手法の研究を支援します。
