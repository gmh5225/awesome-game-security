SecurityRiskAndroid 是一款 Android 示例应用，实现了分层运行时风险检测器，用于识别设备上的篡改、Hook 与 Root 相关威胁。它结合 Java 界面与用 C 编写的 JNI 原生库，可执行快速的同步检查、异步深度扫描、可选的 Root 辅助诊断，以及通过 Messenger 后台服务进行的独立进程对比。检测器覆盖多种信号，包括 Frida 与 Xposed 痕迹、调试器附加、可疑内存映射、ART 与包可见性不一致、KernelSU 探测、模拟位置指示器，以及 GOT/PLT、PHDR、磁盘与内存哈希校验等原生代码完整性检查。项目使用 Gradle、Android Gradle Plugin 8.x 和 CMake/NDK 构建，提供带评分的判定结果与详细字段输出，帮助开发者研究面向游戏及其他安全敏感 Android 应用的移动防篡改与反作弊技术。
