本專案是一套用於 Android 行動安全評估與實作逆向練習的 Frida 掛鉤腳本集合。腳本以 JavaScript 撰寫，執行於 Frida 執行環境，涵蓋 SSL/TLS 憑證釘選繞過（含 OkHttp、TrustManager 以及 Flutter 應用中的原生 BoringSSL）、針對 AndroGoat 與 OWASP UnCrackable App 等實驗目標的 root／越獄偵測繞過，以及透過原生 libc 掛鉤在反插樁檢測中隱藏 Frida 或 Xposed 相關字串。另有輔助腳本在不改變應用行為的前提下記錄網路失敗回呼，便於在動態分析中驗證釘選或 TLS 繞過是否生效。此工具包面向經授權滲透測試人員、安全研究人員及學習者，在已 root 裝置或模擬器上結合靜態分析與 Frida 使用，也適用於 CTF 類 APK 練習，有助於理解遊戲中常見的行動防篡改與用戶端保護機制。
