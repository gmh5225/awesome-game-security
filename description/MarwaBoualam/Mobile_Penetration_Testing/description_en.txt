This project is a collection of Frida hooking scripts for Android mobile security assessments and hands-on reverse engineering practice. The scripts are written in JavaScript for the Frida runtime and cover SSL/TLS certificate pinning bypass (including OkHttp, TrustManager, and native BoringSSL in Flutter apps), root and jailbreak detection bypass for lab targets such as AndroGoat and the OWASP UnCrackable App, and native libc hooks that hide Frida or Xposed strings from anti-instrumentation checks. Additional helpers log network failure callbacks without changing app behavior, which supports validating whether pinning or TLS bypasses actually work during dynamic analysis. The toolkit is aimed at authorized pentesters, security researchers, and learners who combine static analysis with Frida on rooted devices or emulators, including CTF-style APK work relevant to understanding mobile anti-tamper and client-side protections often seen in games.
