本项目是一套用于 Android 移动安全评估与动手逆向练习的 Frida 挂钩脚本集合。脚本以 JavaScript 编写，运行于 Frida 运行时，涵盖 SSL/TLS 证书固定绕过（含 OkHttp、TrustManager 以及 Flutter 应用中的原生 BoringSSL）、针对 AndroGoat 与 OWASP UnCrackable App 等实验目标的 root/越狱检测绕过，以及通过原生 libc 挂钩在反插桩检测中隐藏 Frida 或 Xposed 相关字符串。另有辅助脚本在不改变应用行为的前提下记录网络失败回调，便于在动态分析中验证固定或 TLS 绕过是否生效。该工具包面向经授权渗透测试人员、安全研究人员及学习者，在已 root 设备或模拟器上结合静态分析与 Frida 使用，也适用于 CTF 类 APK 练习，有助于理解游戏中常见的移动防篡改与客户端保护机制。
