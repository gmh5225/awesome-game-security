本プロジェクトは、Android モバイルセキュリティ評価と実践的なリバースエンジニアリング向けの Frida フックスクリプト集です。スクリプトは Frida ランタイム向けの JavaScript で書かれ、SSL/TLS 証明書ピンニングのバイパス（OkHttp、TrustManager、Flutter アプリ内のネイティブ BoringSSL を含む）、AndroGoat や OWASP UnCrackable App などのラボ向けターゲットに対する root／ジェイルブレイク検知の回避、および反インストルメンテーション検査から Frida や Xposed 関連文字列を隠すネイティブ libc フックをカバーします。追加のヘルパーはアプリの挙動を変えずにネットワーク失敗コールバックをログし、動的解析中にピンニングや TLS バイパスが実際に機能しているか検証するのに役立ちます。本ツールキットは、root 済み端末やエミュレータ上で静的解析と Frida を組み合わせる、許可を得たペンテスター、セキュリティ研究者、学習者向けで、ゲームでよく見られるモバイル改ざん防止やクライアント側保護を理解するのに関連する CTF 形式の APK 作業も含みます。
