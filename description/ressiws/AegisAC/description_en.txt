AegisAC is a server-side anti-cheat plugin for Counter-Strike 2 that detects aimbots and unnatural aiming without requiring any client-side software. It is implemented in C# on .NET and integrates with the SwiftlyS2 server framework, using trajectory and angle math, sub-tick user command correlation, and weapon-fire to damage event pairing to flag convergence snaps and automated targeting. Server operators can tune detection strictness, apply modular punishments such as kick or ban, reload configuration live, and receive Discord webhook alerts when players are flagged. The design emphasizes low false positives by aggregating high-confidence evidence over a sliding window before sanctions, making it suited for game server administrators and anti-cheat research on CS2 gameplay telemetry.
