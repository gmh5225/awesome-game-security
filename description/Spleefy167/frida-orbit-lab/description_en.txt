This project is an educational runtime instrumentation playground for studying small, local indie and arcade-style games by observing memory, timing, and game state from outside the process. It is built around Frida-style dynamic analysis: modular, annotated examples demonstrate hooking, scripted and native-module instrumentation, call and timeline tracing, value watching, input logging, frame pacing measurement, and deterministic replay scaffolding, plus shared helpers and validation-oriented tests. A responsive web-based inspector layer gives a live state dashboard with read-only defaults and explicit configuration before any write behavior, alongside multilingual documentation and teach-first comments aimed at learners. It is intended for reverse-engineering hobbyists, students, and developers analyzing software they own or otherwise have permission to study, not for tampering with protected, anti-tamper, or networked titles.
