VkHook は Linux 向けの暗黙的 Vulkan レイヤーで、ゲームとドライバの間でアプリケーションをフックし、スワップチェーン画像への後処理と任意のシーン深度処理を行います。主に C++20 で書かれ Meson でビルドされ、Vulkan 1.3 を対象とし、ネイティブ Vulkan タイトルに加え、Wine や Proton 上で DXVK および vkd3d-proton 経由の Direct3D ゲームにも対応します。中核機能には、対応する NVIDIA ハードウェア上で OpenDLSS-NR ニューラルネットワークに接続した DLSS5 バックエンド、ReShade .fx シェーダーのランタイムコンパイルとチェーン、深度バッファの自動／手動キャプチャ、X11 と Wayland 上で入力ブロック付きの Dear ImGui 設定オーバーレイがあります。x86-64 と 32 ビット Proton 向けレイアウトで提供され、Flatpak の Vulkan レイヤー拡張としてパッケージ化できます。グラフィックスフック研究、MOD 作成、ゲームバイナリを変更せず Vulkan レイヤーがレンダリングをどう変えるかを調べる用途に適しています。
