VkHook is a Linux implicit Vulkan layer that intercepts applications between the game and the driver to run post-processing on swapchain images and optional scene depth. It is written primarily in C++20 and built with Meson, targeting Vulkan 1.3 with support for native Vulkan titles and Direct3D games under Wine or Proton via DXVK and vkd3d-proton. Core capabilities include a DLSS5 backend wired to the OpenDLSS-NR neural network on supported NVIDIA hardware, runtime compilation and chaining of ReShade .fx shaders, automatic or manual depth-buffer capture, and a Dear ImGui configuration overlay with input blocking on X11 and Wayland. The project ships for x86-64 and 32-bit Proton layouts and can be packaged as a Flatpak Vulkan layer extension. It suits graphics hooking research, modding, and studying how Vulkan layers alter rendering without changing game binaries.
