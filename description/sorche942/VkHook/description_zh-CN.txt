VkHook 是一个 Linux 隐式 Vulkan 层，在游戏与驱动之间拦截应用，对交换链图像进行后处理，并可选择处理场景深度。项目主要以 C++20 编写，使用 Meson 构建，面向 Vulkan 1.3，既支持原生 Vulkan 游戏，也支持在 Wine 或 Proton 下通过 DXVK 与 vkd3d-proton 运行的 Direct3D 游戏。核心能力包括在支持的 NVIDIA 硬件上接入 OpenDLSS-NR 神经网络的 DLSS5 后端、运行时编译与串联 ReShade .fx 着色器、自动或手动深度缓冲捕获，以及在 X11 与 Wayland 上带输入屏蔽的 Dear ImGui 配置叠加层。项目提供 x86-64 与 32 位 Proton 布局，并可打包为 Flatpak Vulkan 层扩展。适用于图形 Hook 研究、模组开发，以及研究 Vulkan 层如何在不修改游戏二进制的情况下改变渲染。
