This repository is a work-in-progress fork of VIctory, a compatibility layer that runs Xbox Series X|S game executables natively on Windows using user-supplied game files. The codebase is written in Rust and organized as a workspace with a PE loader, high-level emulation of Xbox runtime services, decoders for console asset formats, and a Direct3D 12 graphics stack that recompiles console shaders to DXIL on demand. This fork tracks upstream VIctory while adding GPU, memory, and rendering fixes aimed at improving in-world playback, frame times, and stability on real hardware. It suits developers and researchers studying Xbox Series platform behavior, native PC porting of console titles, graphics pipeline translation, and reverse engineering of how console games map onto Windows and D3D12.
