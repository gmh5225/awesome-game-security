ReverseLab는 대규모 실행 파일 지식 베이스와 자동화 도구를 결합하여 실습형 보안 분석을 수행하는 오픈소스 리버스 엔지니어링 실험실입니다. Web CTF, Android APK 및 DEX 분석, Windows PE 바이너리, 암호학, 게임 치트 및 안티치트 연구를 위한 보드를 중심으로 180개 이상의 기법 문서와 100개 이상의 MCP 자동화 도구를 제공합니다. 워크플로는 에이전트 네이티브 방식으로, 분석가가 신호를 감지하고 지식 라우터를 통해 관련 공격 체인으로 라우팅한 뒤 Ghidra, Frida, x64dbg, jadx 등 통합 도구로 매핑된 단계를 실행합니다. 주요 구현은 Python으로 스크립트와 MCP 서버를 작성하며, 크로스 플랫폼 설정을 위해 PowerShell, JavaScript, 셸 자동화를 함께 사용합니다. 리버스 엔지니어, 보안 연구원, CTF 참가자, 그리고 승인된 바이너리 분석, 취약점 연구, 멀웨어 또는 게임 보호 조사를 수행하는 AI 에이전트를 대상으로 합니다.
