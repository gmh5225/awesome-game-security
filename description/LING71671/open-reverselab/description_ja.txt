ReverseLab は、大規模な実行ファイル知識ベースと自動化ツールを組み合わせ、実践的なセキュリティ分析を行うオープンソースのリバースエンジニアリングラボです。Web CTF、Android APK および DEX 解析、Windows PE バイナリ、暗号学、ゲームチートやアンチチート研究向けのボードを中心に、180 以上のテクニック記事と 100 以上の MCP 自動化ツールを提供します。ワークフローはエージェントネイティブで、分析者がシグナルを検出し、ナレッジルーターで関連する攻撃チェーンへルーティングし、Ghidra、Frida、x64dbg、jadx などの統合ツールでマッピングされた手順を実行します。主な実装は Python によるスクリプトと MCP サーバーで、クロスプラットフォームのセットアップには PowerShell、JavaScript、シェル自動化を併用します。リバースエンジニア、セキュリティ研究者、CTF プレイヤー、および許可されたバイナリ解析、脆弱性調査、マルウェアやゲーム保護の調査を行う AI エージェントを対象としています。
