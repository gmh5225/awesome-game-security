ReverseLab 是一个开源逆向工程实验室，将大型可执行文件知识库与自动化工具相结合，用于动手进行安全分析。它提供 180 多篇技术文章和 100 多个 MCP 自动化工具，围绕 Web CTF、Android APK 与 DEX 分析、Windows PE 二进制文件、密码学以及游戏作弊或反作弊研究等主题板块组织。其工作流面向智能体：分析人员检测信号，通过知识路由器将其路由到相关攻击链，并通过 Ghidra、Frida、x64dbg 和 jadx 等集成工具执行映射步骤。主要实现语言为 Python，用于脚本和 MCP 服务器，并辅以 PowerShell、JavaScript 和 shell 自动化以支持跨平台部署。面向逆向工程师、安全研究人员、CTF 选手以及执行授权二进制分析、漏洞研究和恶意软件或游戏保护调查的 AI 智能体。
