ReverseLab — это лаборатория обратной разработки с открытым исходным кодом, объединяющая обширную базу знаний об исполняемых файлах с автоматизированными инструментами для практического анализа безопасности. Она предоставляет более 180 статей о техниках и свыше 100 инструментов автоматизации MCP, организованных в разделы для web CTF, анализа Android APK и DEX, бинарных файлов Windows PE, криптографии, а также исследований читов и античитов в играх. Рабочий процесс ориентирован на агентов: аналитики обнаруживают сигналы, направляют их через маршрутизатор знаний к соответствующим цепочкам атак и выполняют сопоставленные шаги с помощью интегрированных инструментов, таких как Ghidra, Frida, x64dbg и jadx. Основная реализация выполнена на Python для скриптов и MCP-серверов, с поддержкой автоматизации на PowerShell, JavaScript и shell для кроссплатформенной настройки. Предназначена для специалистов по обратной разработке, исследователей безопасности, участников CTF и AI-агентов, выполняющих авторизованный анализ бинарных файлов, исследование уязвимостей и расследования в области вредоносного ПО или защиты игр.
