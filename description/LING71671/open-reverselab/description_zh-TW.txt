ReverseLab 是一個開源逆向工程實驗室，結合大型可執行檔知識庫與自動化工具，用於實作安全分析。它提供 180 多篇技術文章和 100 多個 MCP 自動化工具，圍繞 Web CTF、Android APK 與 DEX 分析、Windows PE 二進位檔、密碼學以及遊戲作弊或反作弊研究等主題看板組織。其工作流程面向智慧代理：分析人員偵測訊號，透過知識路由器將其導向相關攻擊鏈，並透過 Ghidra、Frida、x64dbg 和 jadx 等整合工具執行對應步驟。主要實作語言為 Python，用於腳本與 MCP 伺服器，並輔以 PowerShell、JavaScript 和 shell 自動化以支援跨平台部署。面向逆向工程師、安全研究人員、CTF 選手以及執行授權二進位分析、漏洞研究與惡意軟體或遊戲保護調查的 AI 代理。
