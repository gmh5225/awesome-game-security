Oblivion 6（Oblivion Hack Shield）は、Windows 上のオンライン MMO 系ゲームを守ることを目的としたクライアント・サーバー型アンチチート構成です。ゲームクライアントは Visual Studio でビルドした C++ DLL で、プロセスに組み込まれ、デバッガ、インジェクション、IAT フック、不審なメモリ、オーバーレイ、ファイル改ざん、デジタル署名、自己整合性を継続的に検査し、ヒューリスティクスとアンチサスペンドロジックで他プロセスも監視します。検出された違反はネットワーク経由で同伴サーバーに報告され、ハートビートプロトコル、ハードウェア ID 生成、BAN リストによりセッションを認可し、チーターをリモートでキックまたはブロックします。リポジトリには対応するサーバーコンポーネントも含まれ、Windows と Linux 向けビルド、シークレット難読化、ロギング、デプロイ支援により、本番運用やゲームセキュリティ・アンチチート設計の研究に利用できます。
