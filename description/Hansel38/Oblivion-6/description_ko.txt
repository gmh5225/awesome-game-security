Oblivion 6(Oblivion Hack Shield)는 Windows에서 온라인 MMO 스타일 게임을 보호하는 클라이언트-서버 안티치트 스택입니다. 게임 클라이언트는 Visual Studio로 빌드한 C++ DLL로, 프로세스에 통합되어 디버거, 인젝션, IAT 후킹, 의심스러운 메모리, 오버레이, 파일 변조, 디지털 서명, 자체 무결성을 지속적으로 검사하고 휴리스틱과 안티 서스펜드 로직으로 다른 프로세스도 감시합니다. 감지된 위반은 네트워크를 통해 동반 서버로 보고되며, 해당 서버는 하트비트 프로토콜, 하드웨어 ID 생성, 밴 목록으로 세션을 승인하고 치터를 원격으로 킥하거나 차단합니다. 저장소에는 대응하는 서버 구성 요소도 포함되어 Windows 및 Linux 빌드, 시크릿 난독화, 로깅, 배포 도우미를 제공하여 프로덕션에서 쉴드를 운영하거나 게임 보안 및 안티치트 설계를 연구할 수 있습니다.
