Oblivion 6（Oblivion Hack Shield）是一套面向 Windows 平台、用於保護線上 MMO 類遊戲的客戶端-伺服器反作弊架構。遊戲客戶端為使用 Visual Studio 建置的 C++ DLL，整合進行程後持續偵測除錯器、注入、IAT 掛鉤、可疑記憶體、疊加層、檔案竄改、數位簽章與自身完整性，並以啟發式與防掛起邏輯監看其他行程。偵測到的違規行為經網路上報至配套伺服器；該伺服器透過心跳協定、硬體 ID 產生與封鎖清單授權工作階段，並遠端踢出或封鎖作弊者。本儲存庫還包含對應的伺服器元件，提供 Windows 與 Linux 建置、密鑰混淆、日誌及部署輔助，便於在生產環境運行防護或研究遊戲安全與反作弊設計。
