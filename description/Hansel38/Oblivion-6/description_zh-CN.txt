Oblivion 6（Oblivion Hack Shield）是一套面向 Windows 平台、用于保护在线 MMO 类游戏的客户端-服务器反作弊体系。游戏客户端为使用 Visual Studio 构建的 C++ DLL，集成进进程后持续检测调试器、注入、IAT 钩子、可疑内存、叠加层、文件篡改、数字签名与自身完整性，并以启发式与防挂起逻辑监控其他进程。检测到的违规行为经网络上报至配套服务器；该服务器通过心跳协议、硬件 ID 生成与封禁列表授权会话，并远程踢出或封禁作弊者。本仓库还包含匹配的服务器组件，提供 Windows 与 Linux 构建、密钥混淆、日志及部署辅助，便于在生产环境运行防护或研究游戏安全与反作弊设计。
