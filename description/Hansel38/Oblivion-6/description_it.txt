Oblivion 6 (Oblivion Hack Shield) è uno stack anti-cheat client-server pensato per proteggere giochi online in stile MMO su Windows. Il client di gioco è una DLL C++ compilata con Visual Studio che si integra nel processo ed esegue controlli continui su debugger, injection, hook IAT, memoria sospetta, overlay, manomissione dei file, firme digitali e integrità del proprio codice, monitorando altri processi con euristiche e logica anti-suspend. Le violazioni rilevate vengono segnalate in rete a un server companion che usa un protocollo heartbeat, generazione di ID hardware ed elenchi di ban per autorizzare le sessioni ed espellere o bloccare i cheater da remoto. Il repository include anche un componente server corrispondente con build per Windows e Linux, offuscamento dei segreti, logging e utility di deployment per far girare lo scudo in produzione o studiare la sicurezza dei giochi e il design anti-cheat.
