Oblivion 6 (Oblivion Hack Shield) is a client-server anti-cheat stack aimed at protecting online MMO-style games on Windows. The game client is a C++ DLL built with Visual Studio that integrates with the process and runs continuous checks for debuggers, injection, IAT hooks, suspicious memory, overlays, file tampering, digital signatures, and self-integrity while watching other processes with heuristics and anti-suspend logic. Detected violations are reported over the network to a companion server that uses a heartbeat protocol, hardware ID generation, and ban lists to authorize sessions and remotely kick or block cheaters. The repository also includes a matching server component with Windows and Linux builds, secret obfuscation, logging, and deployment helpers for operating the shield in production or studying game-security and anti-cheat design.
