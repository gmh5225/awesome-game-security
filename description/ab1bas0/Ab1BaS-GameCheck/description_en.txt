Ab1BaS GameCheck is a pair of read-only Windows PowerShell tools that help diagnose gaming problems such as crashes, freezes, blue screens, and anti-cheat launch failures. One script focuses on game stability by inspecting Windows event logs, GPU drivers, memory, page file settings, Visual C++ and .NET runtimes, overlays, and recent bugcheck or driver reset events. The other targets anti-cheat compatibility for FACEIT, Riot Vanguard, Easy Anti-Cheat, and BattlEye by reporting boot mode, Secure Boot, TPM, kernel isolation (VBS/HVCI), anti-cheat service status, known conflicting software, and blocked drivers from logs. Both scripts run without administrator rights, do not modify the system or send data online, and save a sanitized report to the desktop and clipboard for support or troubleshooting. They are aimed at players, technicians, and sellers who need quick, transparent system snapshots related to game security and stability.
