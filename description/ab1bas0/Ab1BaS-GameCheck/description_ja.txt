Ab1BaS GameCheck は、クラッシュ、フリーズ、ブルースクリーン、チート対策の起動失敗などのゲーム関連トラブルを診断するための、読み取り専用 Windows PowerShell ツールのペアです。一方のスクリプトはゲームの安定性に焦点を当て、Windows イベントログ、GPU ドライバー、メモリ、ページファイル設定、Visual C++ および .NET ランタイム、オーバーレイ、直近の bugcheck やドライバーリセットイベントを調べます。もう一方は FACEIT、Riot Vanguard、Easy Anti-Cheat、BattlEye 向けのチート対策互換性を対象とし、起動モード、Secure Boot、TPM、カーネル分離（VBS/HVCI）、チート対策サービスの状態、既知の競合ソフトウェア、ログ上のブロックされたドライバーを報告します。両スクリプトは管理者権限なしで実行でき、システムを変更せず、オンラインへデータを送信せず、サポートやトラブルシューティング用にデスクトップとクリップボードへサニタイズされたレポートを保存します。ゲームのセキュリティと安定性に関する迅速で透明なシステムスナップショットを必要とするプレイヤー、技術者、販売者向けです。
