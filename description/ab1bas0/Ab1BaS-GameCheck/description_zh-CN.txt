Ab1BaS GameCheck 是一对只读的 Windows PowerShell 工具，用于诊断游戏相关问题，例如崩溃、卡死、蓝屏以及反作弊启动失败。其中一个脚本侧重游戏稳定性，会检查 Windows 事件日志、GPU 驱动、内存、页面文件设置、Visual C++ 与 .NET 运行时、叠加层，以及近期的 bugcheck 或驱动重置事件。另一个脚本面向 FACEIT、Riot Vanguard、Easy Anti-Cheat 和 BattlEye 的反作弊兼容性，会报告启动模式、Secure Boot、TPM、内核隔离（VBS/HVCI）、反作弊服务状态、已知冲突软件以及日志中的被阻止驱动。两个脚本均无需管理员权限即可运行，不修改系统、不向网络上报数据，并将脱敏报告保存到桌面和剪贴板，便于寻求支持或排障。适用于玩家、技术人员和卖家，需要与游戏安全及稳定性相关的快速、透明的系统快照。
