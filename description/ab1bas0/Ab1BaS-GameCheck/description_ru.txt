Ab1BaS GameCheck — это пара средств Windows PowerShell только для чтения, которые помогают диагностировать игровые проблемы: сбои, зависания, синие экраны и сбои запуска античита. Один сценарий сосредоточен на стабильности игры: он проверяет журналы событий Windows, драйверы GPU, память, настройки файла подкачки, среды Visual C++ и .NET, оверлеи и недавние события bugcheck или сброса драйвера. Другой нацелен на совместимость с античитами FACEIT, Riot Vanguard, Easy Anti-Cheat и BattlEye и сообщает режим загрузки, Secure Boot, TPM, изоляцию ядра (VBS/HVCI), состояние служб античита, известное конфликтующее ПО и заблокированные драйверы из журналов. Оба сценария работают без прав администратора, не изменяют систему и не отправляют данные в сеть; они сохраняют очищенный отчёт на рабочий стол и в буфер обмена для поддержки или устранения неполадок. Они предназначены для игроков, техников и продавцов, которым нужны быстрые и прозрачные снимки системы, связанные с безопасностью и стабильностью игр.
