루팅된 Android 기기용 Magisk 모듈로, ijiami 강화 앱이 일반 휴대폰을 에뮬레이터나 native-bridge 환경으로 잘못 판단해 실행 시 자체 종료하는 것을 막습니다. zygote 마운트 네임스페이스에서 ART의 libnativebridge.so 위에 0바이트 플레이스홀더를 bind-mount하여 패커의 mmap 크기 검사가 실패하게 하고, init 네임스페이스의 실제 파일은 그대로 둡니다. 구현은 주로 shell(service.sh)이며 busybox 마운트, nsenter, --make-rprivate로 마운트 전파를 제어하고 bind 소스에 SELinux 라벨을 신중히 지정합니다. APK 패치, 루트 숨김, 앱 프로세스 후킹 없이 APEX 기반 ART의 Android 10 이상과 Magisk 26+를 대상으로 합니다. 일반적인 루트 숨김이나 Frida로 inline-svc 환경 검사를 우회할 수 없을 때 모바일 보안 연구자와 리버스 엔지니어가 상용 중국 패커 보호 앱을 실행·분석하는 데 사용합니다.
