This is a Magisk module for rooted Android devices that stops ijiami-hardened applications from falsely treating a normal phone as an emulator or native-bridge environment and killing themselves on launch. It bind-mounts a zero-byte placeholder over ART’s libnativebridge.so inside the zygote mount namespace so the packer’s mmap size check fails while the real file stays intact in the init namespace. Implementation is primarily shell (service.sh) with busybox mount operations, nsenter, mount propagation control via --make-rprivate, and careful SELinux labeling on the bind source. It targets Magisk 26+ on Android 10 and newer with APEX-based ART, without patching APKs, hiding root, or hooking the app process. Mobile security researchers and reverse engineers use it to run and analyze commercial Chinese packer protections when standard root-hiding or Frida approaches do not defeat inline-svc environment checks.
