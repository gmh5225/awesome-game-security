WSA-Next는 커뮤니티 프로젝트로, Windows 11에서 Android용 Windows Subsystem for Android를 업그레이드해 AOSP 기반 Android 15를 실행하면서 Microsoft의 기존 Hyper-V 호스트, HAL, 패키지 ID를 재사용합니다. Windows 쪽은 네이티브 C++23 설치·관리 도구와 PowerShell 및 셸 도구이고, Android 쪽은 Java와 C++로 사용자 정의 장치 계층을 추가하고 프레임워크, 통화, Bluetooth, SELinux 정책에 패치를 적용합니다. Google Play 등록, ARM 앱 변환, virtiofs 기반 스토리지, 호스트 경유 하드웨어 비디오 디코드, Windows Hello·Bluetooth·SIM/SMS/MMS 및 요청별 선택적 root 승격을 Android API에 연결하는 브리지를 지원합니다. 보안 지향 설계로 전통적인 su 바이너리 대신 문서화된 uid-0 헬퍼 이름 0을 사용해 일반적인 root 및 안티치트 검사를 피하고, 승격은 Windows Hello로 제한하며 공식 서명 이미지를 유지합니다. 최신 Android 앱과 게임을 Windows에서 필요로 하는 개발자, 리버스 엔지니어, 보안 연구자를 대상으로 하며, 데스크톱 WSA 환경에서 모바일 변조 방지, DRM, root 탐지 동작을 연구하는 용도에도 맞습니다.
