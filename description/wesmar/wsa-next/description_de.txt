WSA-Next ist ein Community-Projekt, das das Windows Subsystem for Android auf Windows 11 so erweitert, dass Android 15 aus AOSP läuft und dabei Microsofts bestehenden Hyper-V-Host, HALs und Paketidentität wiederverwendet. Auf der Windows-Seite gibt es einen nativen C++23-Installer und -Manager mit PowerShell- und Shell-Werkzeugen; auf der Android-Seite kommen benutzerdefinierte Geräteschichten in Java und C++ sowie Patches für Frameworks, Telefonie, Bluetooth und SELinux-Richtlinien hinzu. Unterstützt werden Google-Play-Registrierung, ARM-App-Übersetzung, virtiofs-gestützter Speicher, Hardware-Videodekodierung über den Host sowie Brücken, die Windows Hello, Bluetooth, SIM/SMS/MMS und optionale Root-Erhöhung pro Anfrage auf Android-APIs abbilden. Ein sicherheitsorientiertes Design nutzt einen dokumentierten uid-0-Helfer namens 0 statt einer klassischen su-Binärdatei, sodass übliche Root- und Anti-Cheat-Prüfungen ihn verfehlen, während die Erhöhung über Windows Hello gesteuert wird und offizielle signierte Images erhalten bleiben. Zielgruppe sind Entwickler, Reverse Engineers und Security-Forscher, die aktuelle Android-Apps und -Spiele unter Windows brauchen, einschließlich der Untersuchung von mobilem Anti-Tampering, DRM und Root-Erkennung in einer Desktop-WSA-Umgebung.
