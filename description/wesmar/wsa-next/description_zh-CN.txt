WSA-Next 是一项社区项目，在 Windows 11 上升级适用于 Android 的 Windows 子系统，使其从 AOSP 运行 Android 15，同时复用微软现有的 Hyper-V 主机、HAL 与包身份。Windows 侧为原生 C++23 安装器与管理工具，并配套 PowerShell 与 shell 脚本；Android 侧在 Java 与 C++ 中增加自定义设备层，并对框架、电话、蓝牙与 SELinux 策略进行补丁。项目支持 Google Play 注册、ARM 应用转译、基于 virtiofs 的存储、经宿主硬件视频解码，以及将 Windows Hello、蓝牙、SIM/SMS/MMS 与可选的按请求 root 提升映射到 Android API 的桥接。一项值得关注的安全取向设计采用名为 0 的已文档化 uid-0 辅助程序，而非传统 su 二进制，使常见 root 与反作弊检测难以发现，同时以 Windows Hello 门控提升并保留官方签名镜像。面向需要在 Windows 上使用最新 Android 应用与游戏的开发者、逆向工程师与安全研究人员，包括在桌面 WSA 环境中研究移动防篡改、DRM 与 root 检测的行为。
