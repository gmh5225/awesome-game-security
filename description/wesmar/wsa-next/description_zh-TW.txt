WSA-Next 是一項社群專案，在 Windows 11 上升級適用於 Android 的 Windows 子系統，使其從 AOSP 執行 Android 15，同時複用微軟現有的 Hyper-V 主機、HAL 與套件身分。Windows 側為原生 C++23 安裝器與管理工具，並搭配 PowerShell 與 shell 腳本；Android 側在 Java 與 C++ 中新增自訂裝置層，並對框架、電話、藍牙與 SELinux 原則進行修補。專案支援 Google Play 註冊、ARM 應用轉譯、以 virtiofs 為後端的儲存、經由宿主硬體視訊解碼，以及將 Windows Hello、藍牙、SIM/SMS/MMS 與可選的依請求 root 提升對應到 Android API 的橋接。一項值得注意的資安導向設計採用名為 0 的已文件化 uid-0 輔助程式，而非傳統 su 二進位，使常見 root 與反作弊檢測難以發現，同時以 Windows Hello 門控提升並保留官方簽章映像。面向需要在 Windows 上使用最新 Android 應用與遊戲的開發者、逆向工程師與安全研究人員，包括在桌面 WSA 環境中研究行動防竄改、DRM 與 root 偵測的行為。
