WSA-Next is a community project that upgrades the Windows Subsystem for Android to run Android 15 from AOSP while reusing Microsoft’s existing Hyper-V host, HALs, and package identity on Windows 11. The Windows side is a native C++23 installer and manager with PowerShell and shell tooling, and the Android side adds custom device layers in Java and C++ with patches to frameworks, telephony, Bluetooth, and SELinux policy. It supports Google Play registration, ARM app translation, virtiofs-backed storage, hardware video decode through the host, and bridges that map Windows Hello, Bluetooth, SIM/SMS/MMS, and optional per-request root elevation onto Android APIs. A notable security-oriented design uses a documented uid-0 helper named 0 instead of a traditional su binary so common root and anti-cheat checks miss it, while gating elevation on Windows Hello and keeping official signed images. It targets developers, reverse engineers, and security researchers who need current Android apps and games on Windows, including studying how mobile anti-tamper, DRM, and root-detection behave in a desktop WSA environment.
