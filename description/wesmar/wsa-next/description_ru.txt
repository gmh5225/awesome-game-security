WSA-Next — community-проект, который обновляет подсистему Windows для Android (WSA), чтобы на Windows 11 запускать Android 15 из AOSP с повторным использованием существующего хоста Hyper-V, HAL и идентичности пакета Microsoft. На стороне Windows — нативный установщик и менеджер на C++23 с инструментами PowerShell и shell; на стороне Android — пользовательские слои устройств на Java и C++ и патчи к фреймворкам, телефонии, Bluetooth и политике SELinux. Поддерживаются регистрация Google Play, трансляция ARM-приложений, хранилище на virtiofs, аппаратное декодирование видео через хост и мосты, сопоставляющие Windows Hello, Bluetooth, SIM/SMS/MMS и опциональное повышение root по запросу с API Android. Заметный ориентированный на безопасность подход использует документированный uid-0 helper с именем 0 вместо традиционного бинарника su, поэтому типичные проверки root и античита его не замечают, при этом повышение ограничено Windows Hello и сохраняются официальные подписанные образы. Проект для разработчиков, реверс-инженеров и исследователей безопасности, которым нужны актуальные Android-приложения и игры в Windows, в том числе для изучения мобильной защиты от вмешательства, DRM и обнаружения root в настольной среде WSA.
