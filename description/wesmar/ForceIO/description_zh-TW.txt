ForceIO 是一款 Windows 命令列工具，可強制刪除、重新命名、移動與複製使用者模式 API 無法觸及的檔案與目錄，因為 WdFilter 等迷你篩選器會阻擋一般 I/O。它在短暫的服務工作階段中載入 WHCP 簽署的第三方核心驅動程式，並透過緩衝 IOCTL 在 Filter Manager 堆疊之下執行作業，支援萬用字元、鎖定列舉、登錄設定區快照以及 WOW64 System32 路徑處理。實作為僅使用 Win32 API、不依賴 CRT 的 C 語言，透過 LZX 壓縮的 CAB 資源內嵌驅動程式，並以執行階段數學 stager 滿足驅動程式對呼叫端磁碟校驗和的檢查，同時保持發行二進位檔體積精簡。面向經授權的安全研究與 Windows 核心及反惡意軟體繞過實作，包含在自有或獲准測試的機器上必須操作受保護日誌、Defender 成品或已鎖定的遊戲或系統檔案等情境。
