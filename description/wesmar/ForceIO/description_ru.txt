ForceIO — утилита командной строки для Windows, которая принудительно удаляет, переименовывает, перемещает и копирует файлы и каталоги, недоступные для пользовательских API, потому что минifilter’ы вроде WdFilter блокируют обычный ввод-вывод. Она загружает сторонний подписанный WHCP драйвер ядра в краткой сеансовой службе и отправляет буферизованные IOCTL, чтобы операции выполнялись ниже стека Filter Manager, с поддержкой масок, перечисления блокировок, снимков ульев реестра и обработки путей WOW64 System32. Реализация на C с Win32 API без CRT, драйвер встроен через LZX-сжатые ресурсы CAB, а математический stager во время выполнения удовлетворяет проверкам контрольной суммы вызывающего на диске у драйвера, сохраняя небольшой размер поставляемого бинарника. Предназначена для санкционированных исследований безопасности и практического изучения ядра Windows и обхода антивредоносного ПО, в том числе когда на принадлежащих вам или разрешённых для теста машинах нужно работать с защищёнными журналами, артефактами Defender или заблокированными игровыми и системными файлами.
