ForceIO는 WdFilter 같은 미니필터가 일반 I/O를 막아 사용자 모드 API로는 건드릴 수 없는 파일과 디렉터리를 강제 삭제·이름 변경·이동·복사하는 Windows 명령줄 도구입니다. 짧은 서비스 세션에서 WHCP 서명된 서드파티 커널 드라이버를 로드하고 버퍼 IOCTL을 보내 Filter Manager 스택 아래에서 작업을 수행하며, 와일드카드, 잠금 열거, 레지스트리 하이브 스냅샷, WOW64 System32 경로 처리를 지원합니다. CRT 없이 Win32 API만 쓰는 C로 구현되어 있고, LZX 압축 CAB 리소스로 드라이버를 내장하며 런타임 수학 stager로 드라이버의 디스크 호출자 체크섬 검사를 만족하면서 배포 바이너리 크기를 작게 유지합니다. 승인된 보안 연구와 Windows 커널·안티멀웨어 우회 실습을 목표로 하며, 보호된 로그, Defender 아티팩트, 잠긴 게임·시스템 파일을 본인 소유 또는 테스트 허가된 머신에서 다뤄야 하는 경우 등을 포함합니다.
