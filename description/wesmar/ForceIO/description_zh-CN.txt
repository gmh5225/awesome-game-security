ForceIO 是一款 Windows 命令行工具，可强制删除、重命名、移动和复制用户态 API 无法触及的文件与目录，因为 WdFilter 等微过滤器会阻断常规 I/O。它在短暂的服务会话中加载经 WHCP 签名的第三方内核驱动，并通过缓冲 IOCTL 在 Filter Manager 栈之下执行操作，支持通配符、锁枚举、注册表配置单元快照以及 WOW64 System32 路径处理。实现为仅用 Win32 API、不依赖 CRT 的 C 语言代码，通过 LZX 压缩的 CAB 资源内嵌驱动，并用运行时数学 stager 满足驱动对调用方磁盘校验和的检查，同时保持发布二进制体积较小。面向经授权的安全研究与 Windows 内核及反恶意软件绕过实践，包括在自有或获准测试的机器上处理受保护的日志、Defender 残留物或已锁定的游戏/系统文件等场景。
