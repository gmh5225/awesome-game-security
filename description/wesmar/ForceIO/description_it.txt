ForceIO è uno strumento a riga di comando per Windows che elimina, rinomina, sposta e copia con la forza file e directory che le API in user mode non possono toccare perché minifilter come WdFilter bloccano l’I/O normale. Carica un driver kernel di terze parti firmato WHCP in una breve sessione di servizio e invia IOCTL bufferizzati così che le operazioni avvengano sotto lo stack Filter Manager, con supporto per wildcard, enumerazione dei lock, snapshot delle hive di registro e gestione dei percorsi WOW64 System32. L’implementazione è in C con l’API Win32 senza CRT, incorpora il driver tramite risorse CAB compresse LZX e usa uno stager matematico a runtime per soddisfare i controlli di checksum del chiamante su disco del driver mantenendo il binario distribuito compatto. È pensato per ricerca sulla sicurezza autorizzata e studio pratico del kernel Windows e del bypass antimalware, inclusi i casi in cui log protetti, artefatti di Defender o file di gioco o di sistema bloccati devono essere manipolati su macchine di vostra proprietà o su cui siete autorizzati a testare.
