ForceIO is a Windows command-line tool that force-deletes, renames, moves, and copies files and directories that user-mode APIs cannot touch because minifilters such as WdFilter block normal I/O. It loads a WHCP-signed third-party kernel driver in a short-lived service session and sends buffered IOCTLs so operations run below the Filter Manager stack, with support for wildcards, lock enumeration, registry hive snapshots, and WOW64 System32 path handling. The implementation is C using the Win32 API without the CRT, embeds the driver via LZX-compressed CAB resources, and uses a runtime mathematical stager to satisfy the driver’s on-disk caller checksum checks while keeping the shipped binary small. It is aimed at authorized security research and hands-on Windows kernel and anti-malware bypass study, including cases where protected logs, Defender artifacts, or locked game or system files must be manipulated on machines you own or may test.
