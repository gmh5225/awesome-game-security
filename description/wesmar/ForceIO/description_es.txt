ForceIO es una herramienta de línea de comandos para Windows que elimina, renombra, mueve y copia a la fuerza archivos y directorios que las API en modo usuario no pueden tocar porque minifiltros como WdFilter bloquean la E/S normal. Carga un controlador de kernel de terceros firmado WHCP en una sesión de servicio breve y envía IOCTL con búfer para que las operaciones se ejecuten por debajo de la pila Filter Manager, con soporte para comodines, enumeración de bloqueos, instantáneas de colmenas del registro y manejo de rutas WOW64 System32. La implementación es en C usando la API Win32 sin CRT, incorpora el controlador mediante recursos CAB comprimidos con LZX y usa un stager matemático en tiempo de ejecución para cumplir las comprobaciones de suma de comprobación del llamador en disco del controlador manteniendo el binario distribuido pequeño. Está orientada a la investigación de seguridad autorizada y al estudio práctico del kernel de Windows y la evasión antimalware, incluidos casos en los que hay que manipular registros protegidos, artefactos de Defender o archivos de juego o del sistema bloqueados en máquinas de su propiedad o que puede probar.
