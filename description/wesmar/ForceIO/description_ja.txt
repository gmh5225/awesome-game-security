ForceIO は、WdFilter などのミニフィルターが通常の I/O を妨げるためユーザーモード API では触れないファイルやディレクトリを強制削除・リネーム・移動・コピーする Windows コマンドラインツールです。短命のサービスセッションで WHCP 署名済みの第三者カーネルドライバを読み込み、バッファード IOCTL を送って Filter Manager スタックの下で操作を実行し、ワイルドカード、ロック列挙、レジストリハイブのスナップショット、WOW64 System32 パス処理に対応します。実装は CRT なしの Win32 API を使う C で、LZX 圧縮 CAB リソースでドライバを埋め込み、実行時の数学 stager でドライバのオンディスク呼び出し元チェックサム検証を満たしつつ配布バイナリを小さく保ちます。許可されたセキュリティ研究や Windows カーネル・アンチマルウェア回避の実践向けで、保護されたログ、Defender 成果物、ロックされたゲームやシステムファイルを所有またはテスト可能なマシン上で操作するケースなどを想定しています。
