EfiNtfs は、標準の EFI_SIMPLE_FILE_SYSTEM_PROTOCOL を通じて NTFS ボリュームを公開するネイティブ UEFI x64 NTFS 読み書きファイルシステムドライバーで、完全なオペレーティングシステムを起動せずにプレブート段階でファイル操作を可能にします。プリビルド済み EDK2 静的ライブラリに対して純粋な C11 で記述され、通常の MSVC プロジェクトファイルでビルドされており、B+ ツリー索引、MFT および $MFTMirr の処理、LZNT1 展開、クラスタ割り当て、chkdsk クリーンなアンマウントセマンティクスを含む完全な NTFS エンジンを実装しています。リポジトリには 3 つの EFI バイナリが同梱されています：ntfs.efi（ドライバー）、EC.efi（EFI Commander、統合 FAT32/NTFS VFS を備えたデュアルパネルプレブートファイルマネージャー）、ntfs_probe.efi（機能テストおよびベンチマークハーネス）。低レベルファームウェア研究、オフライン復旧、フォレンジック抽出、Windows 読み込み前のブートローダーパッチ、ドライバーステージング、レジストリやディスク操作などのプレ OS タスクを対象としています。
