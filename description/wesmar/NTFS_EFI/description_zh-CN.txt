EfiNtfs 是一款原生 UEFI x64 NTFS 读写文件系统驱动，通过标准 EFI_SIMPLE_FILE_SYSTEM_PROTOCOL 暴露 NTFS 卷，使您无需启动完整操作系统即可在预启动阶段进行文件操作。该项目以纯 C11 编写，基于预编译的 EDK2 静态库，并使用普通 MSVC 工程文件构建，实现了完整的 NTFS 引擎，包括 B+ 树索引、MFT 与 $MFTMirr 处理、LZNT1 解压、簇分配以及符合 chkdsk 要求的干净卸载语义。仓库提供三个 EFI 二进制文件：ntfs.efi（驱动）、EC.efi（EFI Commander，一款带统一 FAT32/NTFS VFS 的双面板预启动文件管理器）以及 ntfs_probe.efi（功能测试与基准测试工具）。它适用于底层固件研究、离线恢复、取证提取，以及 Windows 加载前的预操作系统任务，例如引导加载程序修补、驱动部署以及注册表或磁盘操作。
