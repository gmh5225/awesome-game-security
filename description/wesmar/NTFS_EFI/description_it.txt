EfiNtfs è un driver nativo del filesystem NTFS in lettura-scrittura per UEFI x64 che espone volumi NTFS tramite il protocollo standard EFI_SIMPLE_FILE_SYSTEM_PROTOCOL, consentendo operazioni sui file in fase pre-boot senza avviare un sistema operativo completo. Scritto in C11 puro su librerie statiche EDK2 precompilate e compilato con normali file di progetto MSVC, implementa un motore NTFS completo che include indicizzazione B+tree, gestione di MFT e $MFTMirr, decompressione LZNT1, allocazione dei cluster e semantica di smontaggio pulito compatibile con chkdsk. Il repository include tre binari EFI: ntfs.efi (il driver), EC.efi (EFI Commander, un file manager pre-boot a doppio pannello con VFS unificato FAT32/NTFS) e ntfs_probe.efi (un harness per test funzionali e benchmark). È pensato per la ricerca firmware a basso livello, il recovery offline, l'estrazione forense e attività pre-OS come patching del bootloader, staging dei driver e manipolazione del registro o del disco prima del caricamento di Windows.
