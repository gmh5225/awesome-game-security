EfiNtfs is a native UEFI x64 NTFS read-and-write filesystem driver that exposes NTFS volumes through the standard EFI_SIMPLE_FILE_SYSTEM_PROTOCOL, enabling pre-boot file operations without booting a full operating system. Written in pure C11 against prebuilt EDK2 static libraries and built with plain MSVC project files, it implements a full NTFS engine including B+tree indexing, MFT and $MFTMirr handling, LZNT1 decompression, cluster allocation, and chkdsk-clean unmount semantics. The repository ships three EFI binaries: ntfs.efi (the driver), EC.efi (EFI Commander, a dual-panel pre-boot file manager with a unified FAT32/NTFS VFS), and ntfs_probe.efi (a functional test and benchmark harness). It is aimed at low-level firmware research, offline recovery, forensic extraction, and pre-OS tasks such as bootloader patching, driver staging, and registry or disk manipulation before Windows loads.
