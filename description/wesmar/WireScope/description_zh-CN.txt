WireScope 是一款原生 Windows 应用程序，在同一 NDIS 数据平面上统一实现二层抓包、按进程流量统计、内核级防火墙策略以及网络损伤仿真。它以现代 C++23 实现为单一自包含可执行文件，通过自定义 IOCTL 协议与自有轻量级 NDIS 6.x 过滤驱动通信，不依赖 Npcap 或其他第三方抓包库。用户可通过 Direct2D 图形界面或可脚本化的 CLI 操作，其方向性规则语言支持地址、端口、协议及按应用程序匹配，并可选择带宽整形、延迟与丢包仿真以及兼容 Wireshark 的 PCAP 导出。已签名的驱动包以压缩资源嵌入二进制内，并通过 SetupAPI 与 INetCfg 按需安装。适用于安全研究、反作弊与游戏流量分析，以及在 Windows 11 x64 上动手逆向分析应用程序的网络行为。
