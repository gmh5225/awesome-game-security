WireScope is a native Windows application that unifies Layer 2 packet capture, per-process traffic accounting, kernel-level firewall enforcement, and network impairment simulation on a single NDIS data plane. It is implemented in modern C++23 as one self-contained executable that talks to its own lightweight NDIS 6.x filter driver over a custom IOCTL protocol, without relying on Npcap or other third-party capture libraries. Users can operate it through a Direct2D GUI or a scriptable CLI with a directional rule language for addresses, ports, protocols, and per-application matching, plus optional bandwidth shaping, delay and loss simulation, and Wireshark-compatible PCAP export. The signed driver package is embedded inside the binary as a compressed resource and installed on demand through SetupAPI and INetCfg. It suits security research, anti-cheat and game-traffic analysis, and hands-on reverse engineering of how applications use the network on Windows 11 x64.
