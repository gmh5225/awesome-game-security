WireScope — нативное приложение для Windows, объединяющее на одном плоскости данных NDIS захват пакетов уровня 2, учёт трафика по процессам, принудительное применение правил межсетевого экрана на уровне ядра и имитацию ухудшения сети. Реализовано на современном C++23 как единый автономный исполняемый файл, обменивающийся данными со своим лёгким фильтрующим драйвером NDIS 6.x по пользовательскому протоколу IOCTL без зависимости от Npcap и других сторонних библиотек захвата. Пользователи работают через графический интерфейс на Direct2D или сценарный CLI с направленным языком правил для адресов, портов, протоколов и сопоставления по приложениям, а также с опциональным ограничением полосы пропускания, имитацией задержки и потерь и экспортом PCAP, совместимым с Wireshark. Подписанный пакет драйвера встроен в двоичный файл как сжатый ресурс и устанавливается по требованию через SetupAPI и INetCfg. Подходит для исследований в области безопасности, анализа античит-трафика и игрового трафика и практического реверс-инжиниринга сетевого поведения приложений в Windows 11 x64.
