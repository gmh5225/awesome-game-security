WireScope는 단일 NDIS 데이터 평면에서 Layer 2 패킷 캡처, 프로세스별 트래픽 집계, 커널 수준 방화벽 적용, 네트워크 손상 시뮬레이션을 하나로 통합한 네이티브 Windows 애플리케이션입니다. 최신 C++23로 구현된 자급자족 단일 실행 파일이며, 자체 경량 NDIS 6.x 필터 드라이버와 사용자 정의 IOCTL 프로토콜로 통신하며 Npcap 등 서드파티 캡처 라이브러리에 의존하지 않습니다. Direct2D GUI 또는 스크립트 가능한 CLI로 사용할 수 있으며, 방향성 규칙 언어로 주소, 포트, 프로토콜, 애플리케이션별 매칭을 지원하고 선택적으로 대역폭 셰이핑, 지연·손실 시뮬레이션, Wireshark 호환 PCAP 내보내기를 제공합니다. 서명된 드라이버 패키지는 바이너리 안에 압축 리소스로 포함되며 SetupAPI와 INetCfg를 통해 필요 시 설치됩니다. 보안 연구, 안티치트 및 게임 트래픽 분석, Windows 11 x64에서 애플리케이션의 네트워크 사용을 직접 리버스 엔지니어링하는 작업에 적합합니다.
