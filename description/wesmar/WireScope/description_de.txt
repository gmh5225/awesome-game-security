WireScope ist eine native Windows-Anwendung, die auf einer einzigen NDIS-Datenebene Layer-2-Paketerfassung, verkehrsbezogene Abrechnung pro Prozess, Firewall-Durchsetzung auf Kernelebene und Simulation von Netzwerkbeeinträchtigungen vereint. Sie ist in modernem C++23 als eine in sich geschlossene ausführbare Datei implementiert, die über ein benutzerdefiniertes IOCTL-Protokoll mit einem eigenen leichtgewichtigen NDIS-6.x-Filtertreiber kommuniziert, ohne Npcap oder andere Drittanbieter-Capture-Bibliotheken. Nutzer bedienen sie über eine Direct2D-GUI oder eine scriptbare CLI mit einer gerichteten Regelsprache für Adressen, Ports, Protokolle und Anwendungszuordnung, optional mit Bandbreiten-Shaping, Verzögerungs- und Verlustsimulation sowie Wireshark-kompatiblem PCAP-Export. Das signierte Treiberpaket ist als komprimierte Ressource in der Binärdatei eingebettet und wird bei Bedarf über SetupAPI und INetCfg installiert. Es eignet sich für Sicherheitsforschung, Anti-Cheat- und Spielverkehrsanalyse sowie praktisches Reverse Engineering, wie Anwendungen unter Windows 11 x64 das Netzwerk nutzen.
