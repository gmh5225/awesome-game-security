WireScope 是一款原生 Windows 應用程式，在同一 NDIS 資料平面上統一實作第二層封包擷取、依處理程序流量統計、核心層防火牆強制與網路損傷模擬。它以現代 C++23 實作成單一自包含可執行檔，透過自訂 IOCTL 通訊協定與自有輕量級 NDIS 6.x 過濾驅動程式通訊，不依賴 Npcap 或其他第三方擷取程式庫。使用者可透過 Direct2D 圖形介面或可腳本化的 CLI 操作，其方向性規則語言支援位址、連接埠、通訊協定及依應用程式比對，並可選擇頻寬整形、延遲與丟包模擬以及相容 Wireshark 的 PCAP 匯出。已簽署的驅動程式套件以壓縮資源嵌入二進位檔內，並透過 SetupAPI 與 INetCfg 依需求安裝。適用於安全研究、反作弊與遊戲流量分析，以及在 Windows 11 x64 上實作逆向工程以了解應用程式的網路使用方式。
