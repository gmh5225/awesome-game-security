WireScope は、単一の NDIS データプレーン上で Layer 2 パケットキャプチャ、プロセス単位のトラフィック集計、カーネルレベルのファイアウォール適用、およびネットワーク劣化シミュレーションを統合したネイティブ Windows アプリケーションです。最新の C++23 で実装された自己完結型の単一実行ファイルとして動作し、独自の軽量 NDIS 6.x フィルタードライバとカスタム IOCTL プロトコルで通信し、Npcap などのサードパーティキャプチャライブラリには依存しません。Direct2D GUI またはスクリプト可能な CLI から操作でき、方向性ルール言語でアドレス、ポート、プロトコル、アプリケーション単位のマッチングに対応し、帯域シェーピング、遅延・損失シミュレーション、Wireshark 互換の PCAP エクスポートをオプションで利用できます。署名済みドライバパッケージは実行ファイル内に圧縮リソースとして埋め込まれ、SetupAPI と INetCfg 経由で必要に応じてインストールされます。セキュリティ研究、チート対策・ゲームトラフィック分析、Windows 11 x64 上でアプリケーションのネットワーク利用を実地でリバースエンジニアリングする用途に適しています。
