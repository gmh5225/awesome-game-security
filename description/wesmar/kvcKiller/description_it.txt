KvcKiller è uno strumento avanzato di gestione dei processi per Windows x64 che termina processi antivirus ed EDR che resistono alle chiamate standard TerminateProcess in user mode. Usa una pipeline kernel in due fasi: un componente fornisce lettura/scrittura memoria kernel e abbassa il Process Protection Level delle destinazioni, un secondo esegue la terminazione dei processi in ring-0 basata su IOCTL, con driver inclusi estratti da un cabinet incorporato e caricati come servizi demand-start. L’applicazione è sviluppata in C++ sia come tool grafico sia come CLI headless, e aggiunge paralisi IFEO, ripristino SCM, elenchi di destinazioni configurabili e fallback in user mode quando le terminazioni kernel vengono rifiutate. È destinata a ricerca sulla sicurezza autorizzata, analisi malware, penetration test e altri ambienti controllati in cui serve comprendere o aggirare il comportamento di software di sicurezza autoprotetto.
