KvcKiller is a Windows x64 advanced process management tool that terminates antivirus and EDR processes that resist standard user-mode TerminateProcess calls. It uses a dual-stage kernel pipeline: one component provides kernel memory read/write and lowers Process Protection Level on targets, and a second issues IOCTL-based ring-0 process termination, with bundled drivers extracted from an embedded cabinet and loaded as demand-start services. The application is built in C++ as both a graphical tool and a headless CLI, and adds IFEO paralyze, SCM restore, configurable target lists, and user-mode fallback when kernel kills are rejected. It is intended for authorized security research, malware analysis, penetration testing, and other controlled environments where understanding or bypassing self-protected security software behavior matters.
