KvcKiller は Windows x64 向けの高度なプロセス管理ツールで、標準のユーザーモード TerminateProcess では終了できないアンチウイルスおよび EDR プロセスを終了します。二段階のカーネルパイプラインを用い、一方のコンポーネントがカーネルメモリの読み書きとターゲットの Process Protection Level の引き下げを行い、もう一方が IOCTL ベースの ring-0 によるプロセス終了を実行します。バンドルされたドライバは埋め込み cabinet から展開され、 demand-start サービスとして読み込まれます。C++ で実装され、GUI とヘッドレス CLI の両方を提供し、IFEO による無効化、SCM 復元、設定可能なターゲット一覧、カーネル終了が拒否された場合のユーザーモードへのフォールバックを備えます。自己保護するセキュリティソフトの挙動を理解または回避する必要がある、承認済みのセキュリティ研究、マルウェア解析、ペネトレーションテスト、その他の統制された環境向けです。
