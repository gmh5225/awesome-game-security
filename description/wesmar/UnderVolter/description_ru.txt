UnderVolter — это нативное UEFI-приложение, которое программирует смещения напряжения, лимиты мощности, коэффициенты турбо и связанные параметры управления питанием процессоров Intel из среды предзагрузки, до загрузки любой операционной системы или гипервизора. Написано преимущественно на C с использованием x64-ассемблера для прямого доступа к MSR и MMIO; применяет настройки на всех ядрах через многопроцессорные службы EFI и поддерживает конфигурацию через INI-профили для процессоров от Sandy Bridge до Arrow Lake. Ключевые возможности включают программирование домена напряжения FIVR через MSR 0x150, патчинг переменных Setup в NVRAM для разблокировки скрытых опций BIOS и самостоятельную регистрацию сертификатов Secure Boot. Поскольку выполняется на этапе загрузки прошивки, обходит фильтрацию MSR со стороны Hyper-V, VBS и аналогичных гипервизоров, а также защиты, блокирующие те же записи из пользовательских или kernel-инструментов. Предназначено для исследователей безопасности прошивок, reverse-инженеров и специалистов по низкоуровневому аппаратному обеспечению, изучающих управление CPU до загрузки ОС, поверхности fault injection напряжения класса Plundervolt и манипуляции цепочкой доверия UEFI.
