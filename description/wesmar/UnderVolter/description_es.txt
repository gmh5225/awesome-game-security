UnderVolter es una aplicación UEFI nativa que programa desplazamientos de voltaje, límites de potencia, ratios turbo y ajustes relacionados de gestión de energía de procesadores Intel desde el entorno de prearranque, antes de que se cargue cualquier sistema operativo o hipervisor. Escrita principalmente en C con ensamblador x64 para acceso directo a MSR y MMIO, utiliza servicios multiprocesador EFI para aplicar la configuración en todos los núcleos y admite perfiles INI para procesadores desde Sandy Bridge hasta Arrow Lake. Entre sus capacidades clave están la programación del dominio de voltaje FIVR mediante MSR 0x150, el parcheo de variables Setup en NVRAM para desbloquear opciones BIOS ocultas y la auto-inscripción de certificados Secure Boot. Al ejecutarse durante el arranque del firmware, evita el filtrado MSR de hipervisores como Hyper-V y VBS, y protecciones similares que bloquean las mismas escrituras desde herramientas en modo usuario o kernel. Está dirigida a investigadores de seguridad de firmware, ingenieros inversos e investigadores de hardware de bajo nivel que estudian el control de CPU en prearranque, superficies de inyección de fallos de voltaje tipo Plundervolt y manipulación de la cadena de confianza UEFI.
