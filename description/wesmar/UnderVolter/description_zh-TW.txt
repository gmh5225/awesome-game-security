UnderVolter 是一款原生 UEFI 應用程式，可在任何作業系統或虛擬機器監控程式載入之前，於預啟動環境中對 Intel CPU 的電壓偏移、功耗限制、Turbo 倍率及相關電源管理設定進行程式設計。此工具主要以 C 語言撰寫，並輔以 x64 組合語言以實現直接的 MSR 與 MMIO 存取；它透過 EFI 多處理器服務將設定套用到所有核心，並支援透過 INI 設定檔為 Sandy Bridge 至 Arrow Lake 處理器進行設定。主要功能包括透過 MSR 0x150 進行 FIVR 電壓域程式設計、修補 NVRAM Setup 變數以解鎖隱藏的 BIOS 選項，以及 Secure Boot 憑證自我註冊。由於它在韌體開機階段執行，可繞過 Hyper-V、VBS 等虛擬機器監控程式的 MSR 過濾，以及會阻止使用者模式或核心工具執行相同寫入的類似保護機制。它面向韌體安全研究人員、逆向工程師，以及研究預啟動 CPU 控制、Plundervolt 類電壓故障注入面與 UEFI 信任鏈操縱的低階硬體研究人員。
