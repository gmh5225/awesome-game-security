UnderVolter は、オペレーティングシステムやハイパーバイザーが読み込まれる前のプリブート環境から、Intel CPU の電圧オフセット、電力制限、ターボ比、および関連する電源管理設定をプログラムするネイティブ UEFI アプリケーションです。主に C 言語で記述され、x64 アセンブリによる直接 MSR および MMIO アクセスを用い、EFI マルチプロセッササービスで全コアに設定を適用し、Sandy Bridge から Arrow Lake までのプロセッサ向け INI プロファイルによる構成をサポートします。主な機能には、MSR 0x150 による FIVR 電圧ドメインのプログラミング、非表示 BIOS オプションの解除のための NVRAM Setup 変数のパッチ、Secure Boot 証明書の自己登録が含まれます。ファームウェア起動時に実行されるため、Hyper-V や VBS などのハイパーバイザーによる MSR フィルタリング、およびユーザーモードやカーネルツールからの同一書き込みをブロックする類似の保護を回避できます。プリブート CPU 制御、Plundervolt クラスの電圧フォルト注入面、UEFI 信頼チェーン操作を研究するファームウェアセキュリティ研究者、リバースエンジニア、低レベルハードウェア研究者を対象としています。
