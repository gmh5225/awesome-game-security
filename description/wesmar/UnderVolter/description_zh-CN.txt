UnderVolter 是一款原生 UEFI 应用程序，可在任何操作系统或虚拟机监控程序加载之前，于预启动环境中对 Intel CPU 的电压偏移、功耗限制、睿频倍率及相关电源管理设置进行编程。该工具主要使用 C 语言编写，并辅以 x64 汇编以实现直接的 MSR 与 MMIO 访问；它通过 EFI 多处理器服务将设置应用到所有核心，并支持通过 INI 配置文件为 Sandy Bridge 至 Arrow Lake 处理器进行配置。主要功能包括通过 MSR 0x150 进行 FIVR 电压域编程、修补 NVRAM Setup 变量以解锁隐藏的 BIOS 选项，以及 Secure Boot 证书自注册。由于它在固件启动阶段运行，可绕过 Hyper-V、VBS 等虚拟机监控程序的 MSR 过滤，以及会阻止用户态或内核工具执行相同写入的类似保护机制。它面向固件安全研究人员、逆向工程师以及研究预启动 CPU 控制、Plundervolt 类电压故障注入面与 UEFI 信任链操纵的低层硬件研究人员。
