VapeRewrite is an actively maintained browser userscript cheat client aimed primarily at Miniblox, with additional packages for other browser-based shooters and sandbox games. It is organized as a TypeScript monorepo that builds a Violentmonkey-compatible script using Bun, Rolldown, and Solid or React UI layers, centered on a shared module framework with configurable HUDs, keybinds, and Brigadier-style in-game commands. Game integration relies on custom runtime hooks for ticks, packets, chat, movement, and rendering rather than brittle early-page code patching, and ships many feature modules spanning combat, movement, world interaction, visuals, inventory automation, and network-oriented tricks. The repository also documents how the target games are bundled and obfuscated, making it a practical reference for reverse engineering browser games and for studying client-side cheating techniques relevant to anti-cheat and game security research.
