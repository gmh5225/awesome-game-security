VapeRewrite — активно поддерживаемый браузерный userscript-клиент для читов, в первую очередь для Miniblox, с дополнительными пакетами для других браузерных шутеров и песочниц. Проект организован как monorepo на TypeScript: с помощью Bun, Rolldown и UI на Solid или React собирается скрипт, совместимый с Violentmonkey, вокруг общего модульного фреймворка с настраиваемыми HUD, привязками клавиш и игровыми командами в стиле Brigadier. Интеграция с игрой опирается на пользовательские runtime-хуки для тиков, пакетов, чата, движения и рендеринга, а не на хрупкие патчи кода на ранней стадии загрузки страницы; включено множество модулей — бой, передвижение, взаимодействие с миром, визуал, автоматизация инвентаря и сетевые приёмы. Репозиторий также описывает, как целевые игры собираются и обфусцируются, что делает его практичным справочником по реверс-инжинирингу браузерных игр и изучению клиентских чит-техник, актуальных для исследований anti-cheat и безопасности игр.
