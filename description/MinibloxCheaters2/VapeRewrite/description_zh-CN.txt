VapeRewrite 是一款持续维护的浏览器用户脚本作弊客户端，主要面向 Miniblox，并为其他基于浏览器的射击与沙盒游戏提供附加包。项目以 TypeScript monorepo 组织，使用 Bun、Rolldown 以及 Solid 或 React UI 层构建与 Violentmonkey 兼容的脚本，核心为共享模块框架，支持可配置的 HUD、按键绑定以及 Brigadier 风格的游戏内命令。游戏集成依赖针对 tick、数据包、聊天、移动与渲染的自定义运行时钩子，而非脆弱的早期页面代码补丁，并包含大量功能模块，涵盖战斗、移动、世界交互、视觉效果、背包自动化及面向网络的技巧。该仓库还记录了目标游戏的打包与混淆方式，可作为逆向浏览器游戏以及研究反作弊与游戏安全相关客户端作弊技术的实用参考。
