RunEXE è uno strumento a riga di comando Python che analizza gli eseguibili PE di Windows e può avviarli su Linux tramite Wine con valutazione automatica della compatibilità. Analizza header eseguibili, tabelle di importazione, manifest incorporati, metadati di versione e indicatori .NET CLR per produrre un report consolidato che copre i backend Wine consigliati, i runtime Winetricks necessari e potenziali ostacoli all'avvio. Lo strumento segnala client anti-cheat noti a livello kernel come Easy Anti-Cheat e BattlEye in base alle firme delle DLL importate e classifica le applicazioni come giochi o software generico mediante euristiche di importazione dell'API Steam e del middleware grafico. Per l'esecuzione, gestisce prefissi Wine per applicazione, installa dipendenze come redistributable VC++ e componenti DirectX ed esegue il binario di destinazione catturando l'output. È rivolto a reverse engineer, ricercatori di sicurezza dei giochi e utenti Linux che necessitano di ispezione PE in sola lettura o di indicazioni pratiche prima di tentare di eseguire giochi e applicazioni Windows protetti.
