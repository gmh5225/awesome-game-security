RunEXE는 Windows PE 실행 파일을 분석하고 자동 호환성 평가와 함께 Wine을 통해 Linux에서 실행할 수 있는 Python 명령줄 도구입니다. 실행 파일 헤더, 가져오기 테이블, 내장 매니페스트, 버전 메타데이터, .NET CLR 지표를 파싱하여 권장 Wine 백엔드, 필요한 Winetricks 런타임, 잠재적 실행 차단 요인을 다루는 통합 보고서를 생성합니다. 이 도구는 가져온 DLL 서명을 기반으로 Easy Anti-Cheat, BattlEye와 같은 알려진 커널 수준 안티치트 클라이언트를 표시하고, Steam API 및 그래픽 미들웨어 가져오기 휴리스틱을 사용해 애플리케이션을 게임 또는 일반 소프트웨어로 분류합니다. 실행 시에는 애플리케이션별 Wine 접두사를 관리하고, VC++ 재배포 가능 패키지 및 DirectX 구성 요소와 같은 종속성을 설치한 뒤 출력을 캡처하면서 대상 바이너리를 실행합니다. 보호된 Windows 게임 및 애플리케이션을 실행하기 전에 읽기 전용 PE 검사 또는 실용적인 안내가 필요한 리버스 엔지니어, 게임 보안 연구자, Linux 사용자를 대상으로 합니다.
