RunEXE 是一款 Python 命令行工具，用于分析 Windows PE 可执行文件，并可通过 Wine 在 Linux 上启动它们，同时自动评估兼容性。它会解析可执行文件头、导入表、内嵌清单、版本元数据以及 .NET CLR 指标，生成一份综合报告，涵盖推荐的 Wine 后端、所需的 Winetricks 运行时以及潜在的启动阻碍因素。该工具根据导入的 DLL 特征识别 Easy Anti-Cheat、BattlEye 等已知内核级反作弊客户端，并借助 Steam API 与图形中间件导入启发式方法，将应用程序分类为游戏或通用软件。在执行阶段，它会管理每个应用的 Wine 前缀，安装 VC++ 可再发行组件和 DirectX 等依赖，并在捕获输出的同时运行目标二进制文件。它面向逆向工程师、游戏安全研究人员以及需要在尝试运行受保护的 Windows 游戏和应用之前进行只读 PE 检查或获取实用指导的 Linux 用户。
