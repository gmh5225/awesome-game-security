RunEXE 是一款 Python 命令列工具，用於分析 Windows PE 可執行檔，並可透過 Wine 在 Linux 上啟動它們，同時自動評估相容性。它會解析可執行檔標頭、匯入表、內嵌資訊清單、版本詮釋資料以及 .NET CLR 指標，產生一份綜合報告，涵蓋建議的 Wine 後端、所需的 Winetricks 執行階段以及潛在的啟動阻礙因素。此工具會根據匯入的 DLL 特徵標記 Easy Anti-Cheat、BattlEye 等已知核心層級反作弊用戶端，並借助 Steam API 與圖形中介軟體匯入啟發式方法，將應用程式分類為遊戲或一般軟體。在執行階段，它會管理每個應用程式的 Wine 前綴，安裝 VC++ 可轉散發套件和 DirectX 等相依元件，並在擷取輸出的同時執行目標二進位檔。它面向逆向工程師、遊戲安全研究人員，以及需要在嘗試執行受保護的 Windows 遊戲與應用程式之前進行唯讀 PE 檢查或取得實用指引的 Linux 使用者。
