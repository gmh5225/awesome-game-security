RunEXE — это инструмент командной строки на Python, который анализирует исполняемые файлы PE Windows и может запускать их в Linux через Wine с автоматической оценкой совместимости. Он разбирает заголовки исполняемых файлов, таблицы импорта, встроенные манифесты, метаданные версии и индикаторы .NET CLR, формируя сводный отчёт с рекомендуемыми бэкендами Wine, необходимыми средами выполнения Winetricks и потенциальными препятствиями при запуске. Инструмент помечает известные античит-клиенты на уровне ядра, такие как Easy Anti-Cheat и BattlEye, по сигнатурам импортируемых DLL и классифицирует приложения как игры или обычное ПО с помощью эвристик импорта Steam API и графического middleware. При выполнении он управляет префиксами Wine для каждого приложения, устанавливает зависимости, такие как распространяемые пакеты VC++ и компоненты DirectX, и запускает целевой бинарный файл с захватом вывода. Он предназначен для специалистов по реверс-инжинирингу, исследователей безопасности игр и пользователей Linux, которым нужна проверка PE в режиме только чтения или практические рекомендации перед попыткой запуска защищённых игр и приложений Windows.
