RunEXE es una herramienta de línea de comandos en Python que analiza ejecutables PE de Windows y puede lanzarlos en Linux a través de Wine con evaluación automática de compatibilidad. Analiza encabezados ejecutables, tablas de importación, manifiestos incrustados, metadatos de versión e indicadores .NET CLR para producir un informe consolidado que cubre los backends Wine recomendados, los runtimes de Winetricks necesarios y posibles obstáculos al lanzamiento. La herramienta señala clientes anti-cheat conocidos a nivel de kernel, como Easy Anti-Cheat y BattlEye, según las firmas de las DLL importadas, y clasifica las aplicaciones como juegos o software general mediante heurísticas de importación de la API de Steam y middleware gráfico. Para la ejecución, gestiona prefijos Wine por aplicación, instala dependencias como redistribuibles de VC++ y componentes de DirectX, y ejecuta el binario objetivo capturando la salida. Está dirigida a ingenieros inversos, investigadores de seguridad en juegos y usuarios de Linux que necesitan inspección PE de solo lectura o orientación práctica antes de intentar ejecutar juegos y aplicaciones protegidos de Windows.
