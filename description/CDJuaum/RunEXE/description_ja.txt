RunEXE は、Windows PE 実行ファイルを解析し、自動的な互換性評価とともに Wine 経由で Linux 上で起動できる Python コマンドラインツールです。実行ファイルヘッダー、インポートテーブル、埋め込みマニフェスト、バージョン メタデータ、.NET CLR 指標を解析し、推奨 Wine バックエンド、必要な Winetricks ランタイム、起動を妨げる可能性のある要因を網羅した統合レポートを生成します。インポートされた DLL シグネチャに基づき Easy Anti-Cheat や BattlEye などの既知のカーネルレベル アンチチート クライアントを検出し、Steam API およびグラフィックス ミドルウェアのインポート ヒューリスティックを用いてアプリケーションをゲームまたは一般ソフトウェアに分類します。実行時にはアプリケーションごとの Wine プレフィックスを管理し、VC++ 再頒布可能パッケージや DirectX コンポーネントなどの依存関係をインストールしたうえで、出力をキャプチャしながら対象バイナリを実行します。保護された Windows ゲームやアプリケーションを実行する前に、読み取り専用の PE 検査や実用的なガイダンスが必要なリバースエンジニア、ゲームセキュリティ研究者、Linux ユーザー向けのツールです。
