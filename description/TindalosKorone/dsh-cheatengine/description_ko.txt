Windows에서 로컬 TCP 브리지를 통해 AI 에이전트가 Cheat Engine을 원격으로 제어할 수 있게 하는 DeepSeek Harness 플러그인입니다. TypeScript로 작성되었으며 Node.js 플러그인으로 구축되어, 프로세스 연결, 메모리 스캔 및 읽기/쓰기, 디스어셈블리, 하드웨어 및 데이터 중단점, 레지스터 검사, 포인터 체인, AOB 패턴, Lua 또는 Auto Assembler 스크립트를 위한 수십 개의 ce_* 도구를 제공합니다. 또한 안티치트 탐지, 모듈 덤프, 스피드핵, 치트 테이블 저장/로드 같은 게임 지향 헬퍼와 가설, 증거, 감사, 실행 취소, 스냅샷을 지원하는 세션 추적 기능을 추가합니다. 에이전트 컨텍스트를 작게 유지하기 위해 도구는 필요 시 잠금 해제되며, 위험한 쓰기 및 스크립트 작업은 명시적 잠금 해제 뒤에만 허용됩니다. 독립적인 치팅이나 정적 분석이 아니라, 승인된 게임 보안 연구, 리버스 엔지니어링, 동적 메모리 분석을 목표로 합니다.
