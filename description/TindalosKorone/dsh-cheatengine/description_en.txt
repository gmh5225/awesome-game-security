This is a DeepSeek Harness plugin that lets AI agents remotely control Cheat Engine on Windows through a local TCP bridge. Written in TypeScript and built as a Node.js plugin, it exposes dozens of ce_* tools for process attachment, memory scanning and read/write, disassembly, hardware and data breakpoints, register inspection, pointer chains, AOB patterns, and Lua or Auto Assembler scripts. It also adds game-oriented helpers such as anti-cheat detection, module dumping, speedhack, and cheat table save/load, plus session tracking with hypothesis, evidence, audit, undo, and snapshot support. Tools are unlocked on demand to keep agent context small, with dangerous write and script operations gated behind explicit unlock. It is aimed at authorized game security research, reverse engineering, and dynamic memory analysis rather than standalone cheating or static analysis.
