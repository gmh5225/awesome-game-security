这是一个 DeepSeek Harness 插件，通过本地 TCP 桥接让 AI 智能体在 Windows 上远程控制 Cheat Engine。该插件使用 TypeScript 编写，以 Node.js 插件形式构建，暴露了数十个 ce_* 工具，用于进程附加、内存扫描与读写、反汇编、硬件与数据断点、寄存器检查、指针链、AOB 模式以及 Lua 或 Auto Assembler 脚本。它还提供了面向游戏的辅助功能，例如反作弊检测、模块转储、变速（speedhack）以及作弊表保存/加载，并支持包含假设、证据、审计、撤销与快照的会话跟踪。工具按需解锁以保持智能体上下文精简，危险的写入与脚本操作需经显式解锁。该项目面向经授权的游戏安全研究、逆向工程与动态内存分析，而非独立作弊或静态分析。
