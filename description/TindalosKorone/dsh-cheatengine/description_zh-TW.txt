這是一個 DeepSeek Harness 外掛，透過本機 TCP 橋接讓 AI 代理在 Windows 上遠端控制 Cheat Engine。以外掛形式以 TypeScript 撰寫並建置為 Node.js 外掛，公開數十個 ce_* 工具，用於行程附加、記憶體掃描與讀寫、反組譯、硬體與資料中斷點、暫存器檢查、指標鏈、AOB 模式以及 Lua 或 Auto Assembler 腳本。此外還提供面向遊戲的輔助功能，例如反作弊偵測、模組傾印、變速（speedhack）以及作弊表儲存/載入，並支援包含假設、證據、稽核、復原與快照的工作階段追蹤。工具按需解鎖以保持代理上下文精簡，危險的寫入與腳本操作需經明確解鎖。本專案面向經授權的遊戲安全研究、逆向工程與動態記憶體分析，而非獨立作弊或靜態分析。
