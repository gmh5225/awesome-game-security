DeepSeek Harness 向けのプラグインで、ローカル TCP ブリッジ経由で AI エージェントが Windows 上の Cheat Engine をリモート制御できるようにします。TypeScript で書かれ、Node.js プラグインとして構築され、プロセスアタッチ、メモリスキャンと読み書き、逆アセンブル、ハードウェアおよびデータブレークポイント、レジスタ検査、ポインタチェーン、AOB パターン、Lua または Auto Assembler スクリプト向けの ce_* ツールを数十種類公開します。アンチチート検出、モジュールダンプ、スピードハック、チートテーブルの保存/読み込みなどゲーム向けヘルパーや、仮説、証拠、監査、取り消し、スナップショットを備えたセッション追跡も追加します。エージェントのコンテキストを小さく保つためツールは必要に応じてアンロックされ、危険な書き込みやスクリプト操作は明示的なアンロックの背後に保護されます。単独のチートや静的解析ではなく、許可されたゲームセキュリティ研究、リバースエンジニアリング、動的メモリ解析を目的としています。
