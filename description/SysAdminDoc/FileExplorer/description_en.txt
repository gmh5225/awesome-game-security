FileExplorer is a full-featured Android file manager written in Kotlin with a Jetpack Compose and Material 3 interface for browsing, editing, and managing files across local storage, archives, network shares, and cloud backends. It offers optional root access via libsu and Shizuku-backed browsing of protected Android/data and Android/obb paths, plus an APK analyzer, hex editor, app manager, and root module browser for Magisk, KernelSU, and APatch. Security-oriented capabilities include encrypted vaults, AES-256 file encryption, secure delete, checksum verification, and SHA-256 integrity monitoring, alongside SMB, SFTP, FTP, WebDAV, and multi-cloud connectivity. The project targets mobile reverse engineers, game security researchers, and advanced users who need deep filesystem inspection, protected app data access, and forensic-style storage analysis on Android.
