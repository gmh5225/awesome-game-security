FileExplorer 是一款功能完整的 Android 文件管理器，采用 Kotlin 编写，基于 Jetpack Compose 与 Material 3 界面，可用于浏览、编辑和管理本地存储、压缩包、网络共享及云存储后端中的文件。它支持通过 libsu 和 Shizuku 可选获取 root 权限，浏览受保护的 Android/data 与 Android/obb 路径，并提供 APK 分析器、十六进制编辑器、应用管理器，以及 Magisk、KernelSU 与 APatch 的 root 模块浏览器。安全相关能力包括加密保险库、AES-256 文件加密、安全删除、校验和验证及 SHA-256 完整性监控，同时支持 SMB、SFTP、FTP、WebDAV 及多种云连接。该项目面向移动逆向工程师、游戏安全研究人员及需要深度文件系统检查、受保护应用数据访问和 Android 端取证式存储分析的高级用户。
