FileExplorer は Kotlin で書かれたフル機能の Android ファイルマネージャーで、Jetpack Compose と Material 3 の UI により、ローカルストレージ、アーカイブ、ネットワーク共有、クラウドバックエンド上のファイルの閲覧、編集、管理が可能です。libsu および Shizuku による任意の root アクセスで保護された Android/data および Android/obb パスを閲覧でき、APK アナライザー、16 進エディター、アプリマネージャー、Magisk・KernelSU・APatch 向け root モジュールブラウザーも備えています。セキュリティ向け機能として暗号化ボルト、AES-256 ファイル暗号化、セキュア削除、チェックサム検証、SHA-256 整合性監視に加え、SMB、SFTP、FTP、WebDAV、マルチクラウド接続に対応します。本プロジェクトは、モバイルリバースエンジニア、ゲームセキュリティ研究者、Android 上で深いファイルシステム調査、保護されたアプリデータへのアクセス、フォレンジック的なストレージ解析を必要とする上級ユーザー向けです。
