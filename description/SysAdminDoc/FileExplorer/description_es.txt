FileExplorer es un administrador de archivos para Android con funciones completas, escrito en Kotlin con una interfaz de Jetpack Compose y Material 3 para explorar, editar y gestionar archivos en almacenamiento local, archivos comprimidos, recursos compartidos de red y backends en la nube. Ofrece acceso root opcional mediante libsu y navegación respaldada por Shizuku de las rutas protegidas Android/data y Android/obb, además de un analizador APK, editor hexadecimal, gestor de aplicaciones y navegador de módulos root para Magisk, KernelSU y APatch. Las capacidades orientadas a la seguridad incluyen bóvedas cifradas, cifrado de archivos AES-256, borrado seguro, verificación de sumas de comprobación y monitorización de integridad SHA-256, junto con conectividad SMB, SFTP, FTP, WebDAV y multi-nube. El proyecto está dirigido a ingenieros de ingeniería inversa móvil, investigadores de seguridad de juegos y usuarios avanzados que necesitan inspección profunda del sistema de archivos, acceso a datos de aplicaciones protegidas y análisis forense del almacenamiento en Android.
