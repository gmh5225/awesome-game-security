A from-scratch reimplementation of Counter-Strike 1.6 written in Rust with the Bevy engine, recreating classic movement, weapons, and economy inside a modern online competitive setup. It loads original GoldSrc maps, models, sounds, and textures through dedicated file readers and splits work across a graphical client, authoritative game servers, and a central lobby for parties, matchmaking, and Docker-based hosting. Matches follow a CS2-style 5v5 format with knife rounds, map vetoes, deathmatch warmup, Steam sign-in, voice chat, and recorded replays, backed by shared simulation and networking crates. Server-side anti-cheat is built into the online stack, which makes the codebase useful for studying competitive FPS architecture, legacy asset pipelines, and practical game-integrity approaches.
