Rust と Bevy エンジンで一から書き直した Counter-Strike 1.6 の再実装で、現代的なオンライン競技環境の中でクラシックな移動・武器・経済を再現する。専用ファイルリーダーでオリジナルの GoldSrc マップ・モデル・サウンド・テクスチャを読み込み、グラフィカルクライアント、権威あるゲームサーバー、パーティ・マッチメイキング・Docker ベースのホスティング用中央ロビーに役割を分ける。試合は CS2 風の 5v5 形式で、ナイフラウンド、マップベト、デスマッチウォームアップ、Steam サインイン、ボイスチャット、リプレイ記録を備え、共有のシミュレーションとネットワーク crate が支える。オンラインスタックにサーバー側アンチチートが組み込まれており、競技 FPS アーキテクチャ、レガシーアセットパイプライン、実践的なゲーム整合性の取り組みを学ぶのに有用なコードベースである。
