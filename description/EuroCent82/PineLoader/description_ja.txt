PineLoader は Windows 向けの mod ローダーで、Unreal Engine 5.8 タイトルの起動より前に動作し、Steam の起動オプションなしで mod を取り付けられます。C# と .NET 10 で構築され、WinForms シェルを持ち、ハードリンクでゲームの Win64-Shipping 実行ファイルを差し替えつつ、元のゲームバイナリは保持します。mod は Mods フォルダ内の DLL プラグインとして配置し、IPineMod を実装して IPineHost API によりログ、任意の Java エージェント、実行中ゲームプロセスへのフックを利用でき、mod ごとの INI 切り替えと再起動を高速化するキャッシュ層があります。失敗した mod は個別にスキップされるためゲームは起動でき、mod 開発者、UE5.8 の研究者、起動時に shipping 実行ファイルをリダイレクトしてマネージド拡張を注入する仕組みを調べる人向けです。
