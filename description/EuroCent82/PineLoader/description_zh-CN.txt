PineLoader 是一款 Windows 模组加载器，在 Unreal Engine 5.8 游戏启动前运行，使模组无需 Steam 启动项即可挂载。它以 C# 与 .NET 10 构建，带 WinForms 界面，通过硬链接替换游戏的 Win64-Shipping 可执行文件，同时保留原始游戏二进制。模组以 DLL 插件形式放在 Mods 文件夹下，实现 IPineMod，并通过 IPineHost API 获得日志、可选 Java 代理以及对运行中游戏进程的钩子；支持按模组 INI 开关和缓存层以加快重启。单个失败的模组会被跳过，游戏仍可启动，适合模组开发者、UE5.8 研究者以及研究如何在启动时重定向 shipping 可执行文件以注入托管扩展的用户。
