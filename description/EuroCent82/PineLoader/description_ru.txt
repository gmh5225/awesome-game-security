PineLoader — загрузчик модов для Windows, который запускается до старта игр на Unreal Engine 5.8, чтобы моды подключались без параметров запуска Steam. Написан на C# под .NET 10 с оболочкой WinForms и заменяет исполняемый файл Win64-Shipping игры жёсткой ссылкой, сохраняя исходный бинарник. Моды — DLL-плагины в папке Mods, реализуют IPineMod и получают API IPineHost для логирования, опциональных Java-агентов и перехватов процесса игры, с переключателями INI на мод и кэшем для более быстрых перезапусков. Сбойные моды пропускаются по отдельности, игра всё равно может запуститься; подходит разработчикам модов, исследователям UE5.8 и тем, кто изучает перенаправление shipping-исполняемого файла для внедрения управляемых расширений при старте.
