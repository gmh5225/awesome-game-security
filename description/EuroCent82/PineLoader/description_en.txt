PineLoader is a Windows mod loader that runs ahead of Unreal Engine 5.8 titles so mods can attach without Steam launch options. It is built in C# on .NET 10 with a WinForms shell and replaces the game’s Win64-Shipping executable via a hard link while preserving the original game binary. Mods live as DLL plugins under a Mods folder, implement IPineMod, and receive an IPineHost API for logging, optional Java agents, and hooks on the running game process, with per-mod INI toggles and a cache layer for faster restarts. Failed mods are skipped individually so the game can still start, which suits mod developers, UE5.8 researchers, and anyone studying how a shipping executable can be redirected to inject managed extensions at launch.
