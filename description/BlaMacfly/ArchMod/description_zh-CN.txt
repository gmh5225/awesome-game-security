ArchMod 是一款面向在 Proton 下运行的 Steam 游戏的 Linux 原生作弊面板，无需 Windows 即可提供类似 WeMod 的体验。它采用 Rust 与 Tauri 2 后端以及 React 前端，可扫描 Steam 游戏库、管理训练器库，并通过 protontricks 及原生备用方案将 Windows 训练器可执行文件注入到正确的 Proton 前缀中。其开发中的原生引擎通过 process_vm_readv 在 Linux 上直接读写游戏内存，支持字节模式扫描、指针链解析、数值冻结、代码钩子以及 Cheat Engine 表解析。社区配置文件让研究人员可以按游戏版本共享内存地址与作弊定义。它面向希望在 Proton 上获得单机训练器支持与内存操作工具的 Linux 玩家和逆向工程师，并对反作弊与多人游戏使用给出明确警告。
