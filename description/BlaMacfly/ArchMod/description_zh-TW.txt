ArchMod 是一款面向在 Proton 下執行的 Steam 遊戲的 Linux 原生作弊面板，無需 Windows 即可提供類似 WeMod 的體驗。它採用 Rust 與 Tauri 2 後端以及 React 前端，可掃描 Steam 遊戲庫、管理訓練器庫，並透過 protontricks 及原生備用方案將 Windows 訓練器可執行檔注入到正確的 Proton 前綴中。其開發中的原生引擎透過 process_vm_readv 在 Linux 上直接讀寫遊戲記憶體，支援位元組模式掃描、指標鏈解析、數值凍結、程式碼掛鉤以及 Cheat Engine 表解析。社群設定檔讓研究人員可以依遊戲版本共享記憶體位址與作弊定義。它面向希望在 Proton 上獲得單機訓練器支援與記憶體操作工具的 Linux 玩家和逆向工程師，並對反作弊與多人遊戲使用給出明確警告。
