ArchMod は Proton 上で動作する Steam ゲーム向けの Linux ネイティブチートパネルで、Windows なしで WeMod のような体験を提供します。Rust と Tauri 2 のバックエンド、React フロントエンドで構築され、Steam ライブラリをスキャンし、トレーナーボルトを管理し、protontricks とネイティブのフォールバックを使って Windows トレーナー実行ファイルを適切な Proton プレフィックスに注入します。開発中のネイティブエンジンは process_vm_readv 経由で Linux 上でゲームメモリを直接読み書きし、バイトパターンスキャン、ポインタチェーン解決、値の固定、コードフック、Cheat Engine テーブルの解析に対応します。コミュニティプロファイルにより、研究者はゲームビルドごとにメモリアドレスとチート定義を共有できます。Proton 上でシングルプレイヤートレーナー支援とメモリ操作ツールを求める Linux ゲーマーとリバースエンジニアを対象とし、アンチチートとマルチプレイヤー利用について明確な警告を示します。
