MCP Reverse 是一個 Model Context Protocol 伺服器，向 AI 程式設計助手公開逆向工程工作流程與工具。核心實作為 Node.js 上的 TypeScript，並透過 sidecar 橋接外掛連接 Ghidra、IDA Pro、Binary Ninja、x64dbg、Cheat Engine、Frida、dnSpy、ILSpy 與 ReClass.NET，讓智能體可從單一樞紐驅動熟悉的反組譯器、除錯器與即時記憶體工具。內建原生模組涵蓋反組譯、反編譯快取、特徵碼與 YARA 掃描、ROP 與記憶體分析、PDB 與 DWARF 支援、遊戲引擎輔助以及 Cheat Engine 伺服器整合，另含用於協調多智能體工作階段的 agent mesh。範例用戶端設定、Docker 與 systemd 部署，以及反編譯、VMProtect 脫殼與 mesh 協作等 cookbook，面向希望在保留既有工具鏈的同時取得 LLM 輔助二進位分析的安全研究人員、惡意軟體分析師、CTF 玩家與遊戲安全工程師。
