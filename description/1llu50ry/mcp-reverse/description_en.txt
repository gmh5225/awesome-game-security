MCP Reverse is a Model Context Protocol server that exposes reverse-engineering workflows and tooling to AI coding assistants. The core implementation is TypeScript on Node.js, with sidecar bridge plugins for Ghidra, IDA Pro, Binary Ninja, x64dbg, Cheat Engine, Frida, dnSpy, ILSpy, and ReClass.NET so agents can drive familiar disassemblers, debuggers, and live-memory tools from one hub. Built-in native modules cover disassembly, decompilation caching, signature and YARA scanning, ROP and memory analysis, PDB and DWARF support, game-engine helpers, and Cheat Engine server integration, plus an agent mesh for coordinated multi-agent sessions. Example client configs, Docker and systemd deployment, and cookbooks for decompilation, VMProtect unpacking, and mesh collaboration target security researchers, malware analysts, CTF players, and game-security engineers who want LLM-assisted binary analysis without leaving their existing toolchain.
