MCP Reverse 是一个 Model Context Protocol 服务器，向 AI 编程助手开放逆向工程工作流与工具链。核心实现为 Node.js 上的 TypeScript，并通过 sidecar 桥接插件对接 Ghidra、IDA Pro、Binary Ninja、x64dbg、Cheat Engine、Frida、dnSpy、ILSpy 与 ReClass.NET，使智能体可从单一枢纽驱动常用反汇编器、调试器与实时内存工具。内置原生模块涵盖反汇编、反编译缓存、特征码与 YARA 扫描、ROP 与内存分析、PDB 与 DWARF 支持、游戏引擎辅助以及 Cheat Engine 服务端集成，另含用于协调多智能体会话的 agent mesh。示例客户端配置、Docker 与 systemd 部署，以及反编译、VMProtect 脱壳与 mesh 协作等 cookbook，面向希望在保留现有工具链的同时获得 LLM 辅助二进制分析的安全研究人员、恶意软件分析师、CTF 选手与游戏安全工程师。
