MCP Reverse는 역공학 워크플로와 도구를 AI 코딩 어시스턴트에 노출하는 Model Context Protocol 서버입니다. 핵심 구현은 Node.js 기반 TypeScript이며, Ghidra, IDA Pro, Binary Ninja, x64dbg, Cheat Engine, Frida, dnSpy, ILSpy, ReClass.NET용 sidecar 브리지 플러그인을 통해 에이전트가 하나의 허브에서 익숙한 disassembler, 디버거, 실시간 메모리 도구를 구동할 수 있습니다. 내장 네이티브 모듈은 disassembly, 디컴파일 캐싱, 시그니처 및 YARA 스캔, ROP 및 메모리 분석, PDB 및 DWARF 지원, 게임 엔진 헬퍼, Cheat Engine 서버 연동을 다루며, 조율된 다중 에이전트 세션을 위한 agent mesh도 제공합니다. 예제 클라이언트 설정, Docker 및 systemd 배포, 디컴파일, VMProtect 언패킹, mesh 협업용 cookbook은 기존 툴체인을 벗어나지 않고 LLM 보조 바이너리 분석을 원하는 보안 연구자, 멀웨어 분석가, CTF 참가자, 게임 보안 엔지니어를 대상으로 합니다.
