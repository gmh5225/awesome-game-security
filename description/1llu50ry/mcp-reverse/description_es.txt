MCP Reverse es un servidor Model Context Protocol que expone flujos de trabajo y herramientas de ingeniería inversa a los asistentes de codificación con IA. La implementación principal es TypeScript en Node.js, con plugins puente sidecar para Ghidra, IDA Pro, Binary Ninja, x64dbg, Cheat Engine, Frida, dnSpy, ILSpy y ReClass.NET para que los agentes puedan controlar desde un único hub desensambladores, depuradores y herramientas de memoria en vivo habituales. Los módulos nativos integrados cubren desensamblado, caché de descompilación, escaneo de firmas y YARA, análisis ROP y de memoria, soporte PDB y DWARF, ayudas para motores de juego e integración con el servidor de Cheat Engine, además de un agent mesh para sesiones multiagente coordinadas. Configuraciones de cliente de ejemplo, despliegue con Docker y systemd, y cookbooks de descompilación, desempaquetado de VMProtect y colaboración mesh están pensados para investigadores de seguridad, analistas de malware, jugadores de CTF e ingenieros de seguridad en juegos que quieren análisis binario asistido por LLM sin abandonar su cadena de herramientas actual.
