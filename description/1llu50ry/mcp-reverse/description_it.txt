MCP Reverse è un server Model Context Protocol che espone flussi di lavoro e strumenti di reverse engineering agli assistenti di coding basati su IA. L’implementazione principale è TypeScript su Node.js, con plugin bridge sidecar per Ghidra, IDA Pro, Binary Ninja, x64dbg, Cheat Engine, Frida, dnSpy, ILSpy e ReClass.NET così che gli agenti possano guidare da un unico hub disassemblatori, debugger e strumenti di memoria live familiari. Moduli nativi integrati coprono disassemblaggio, cache di decompilazione, scansione di firme e YARA, analisi ROP e memoria, supporto PDB e DWARF, helper per motori di gioco e integrazione server Cheat Engine, più un agent mesh per sessioni multi-agente coordinate. Configurazioni client di esempio, deploy Docker e systemd, e cookbook per decompilazione, unpacking VMProtect e collaborazione mesh sono pensati per ricercatori di sicurezza, analisti malware, giocatori CTF e ingegneri game-security che vogliono analisi binaria assistita da LLM senza lasciare la toolchain esistente.
