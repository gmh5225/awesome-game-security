MCP Reverse — это сервер Model Context Protocol, который открывает рабочие процессы и инструменты реверс-инжиниринга для ИИ-ассистентов по программированию. Ядро реализовано на TypeScript в Node.js; sidecar-мостовые плагины для Ghidra, IDA Pro, Binary Ninja, x64dbg, Cheat Engine, Frida, dnSpy, ILSpy и ReClass.NET позволяют агентам управлять привычными disassembler'ами, отладчиками и инструментами работы с памятью в реальном времени из одного центра. Встроенные нативные модули охватывают disassembly, кэширование decompilation, поиск сигнатур и сканирование YARA, анализ ROP и памяти, поддержку PDB и DWARF, помощники для игровых движков и интеграцию с сервером Cheat Engine, а также agent mesh для согласованных мультиагентных сессий. Примеры конфигураций клиента, развёртывание через Docker и systemd и cookbooks по decompilation, распаковке VMProtect и совместной работе в mesh рассчитаны на исследователей безопасности, аналитиков вредоносного ПО, участников CTF и инженеров по безопасности игр, которым нужен бинарный анализ с помощью LLM без отказа от существующей цепочки инструментов.
