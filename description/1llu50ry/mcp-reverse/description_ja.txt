MCP Reverse は、逆アセンブル・リバースエンジニアリングのワークフローとツールを AI コーディングアシスタントに公開する Model Context Protocol サーバーです。コア実装は Node.js 上の TypeScript で、Ghidra、IDA Pro、Binary Ninja、x64dbg、Cheat Engine、Frida、dnSpy、ILSpy、ReClass.NET 向けの sidecar ブリッジプラグインにより、エージェントが一つのハブからおなじみの逆アセンブラ、デバッガ、ライブメモリツールを操作できます。組み込みネイティブモジュールは逆アセンブル、デコンパイルキャッシュ、シグネチャと YARA スキャン、ROP とメモリ解析、PDB と DWARF サポート、ゲームエンジンヘルパー、Cheat Engine サーバー連携をカバーし、協調型マルチエージェントセッション用の agent mesh も備えます。サンプルクライアント設定、Docker と systemd によるデプロイ、デコンパイル、VMProtect アンパック、mesh 協調の cookbook は、既存ツールチェーンを離れずに LLM 支援のバイナリ解析を求めるセキュリティ研究者、マルウェアアナリスト、CTF 参加者、ゲームセキュリティエンジニア向けです。
