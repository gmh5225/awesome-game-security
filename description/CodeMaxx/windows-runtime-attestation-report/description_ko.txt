Windows GetRuntimeAttestationReport API를 호출하여 운영 체제에서 서명된 Runtime Report Packages를 검색, 구문 분석 및 출력하는 C++ 콘솔 샘플입니다. 로드된 모든 커널 드라이버를 이미지 해시, 게시자 인증서 지문, 플래그와 함께 나열하는 드라이버 보고서를 디코딩하고, Microsoft 서명 핫패치가 적용된 커널 모드 이미지의 기본 주소, 이미지 크기, 패치 시퀀스 번호를 보여 주는 핫패치 보고서도 디코딩합니다. Visual Studio 2022 및 Windows SDK 10.0.29648로 x64 및 ARM64용으로 빌드되었으며, 지원되는 Windows 11 빌드에서는 VBS와 HVCI가 필요합니다. 원격 attestation이나 RSA-PSS 서명 검증 없이 런타임 attestation 데이터를 검사해야 하는 보안 연구자, 안티치트 개발자, 커널 무결성 분석가를 위한 도구입니다.
