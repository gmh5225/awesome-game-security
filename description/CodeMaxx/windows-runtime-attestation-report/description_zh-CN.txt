这是一个 C++ 控制台示例，调用 Windows GetRuntimeAttestationReport API，从操作系统获取、解析并打印已签名的 Runtime Report Packages。它会解码驱动程序报告，列出每个已加载的内核驱动程序及其映像哈希、发布者证书指纹和标志；还会解码热补丁报告，展示已应用 Microsoft 签名内核模式热补丁的映像，包括基址、映像大小和补丁序列号。该工具使用 Visual Studio 2022 和 Windows SDK 10.0.29648 构建，支持 x64 与 ARM64，在受支持的 Windows 11 版本上需要启用 VBS 和 HVCI。它面向需要检查运行时证明数据、且无需执行远程证明或 RSA-PSS 签名验证的安全研究人员、反作弊开发者和内核完整性分析人员。
