Esempio di console C++ che chiama l’API Windows GetRuntimeAttestationReport per recuperare, analizzare e stampare Runtime Report Packages firmati dal sistema operativo. Decodifica report dei driver che elencano ogni driver del kernel caricato con hash dell’immagine, impronte digitali del certificato dell’editore e flag, e report hotpatch che mostrano immagini in modalità kernel con hotpatch firmati da Microsoft, inclusi indirizzo base, dimensione dell’immagine e numeri di sequenza delle patch. Compilato con Visual Studio 2022 e Windows SDK 10.0.29648 per x64 e ARM64, lo strumento richiede VBS e HVCI su build Windows 11 supportate. È destinato a ricercatori di sicurezza, sviluppatori di anti-cheat e analisti dell’integrità del kernel che devono ispezionare dati di attestazione runtime senza eseguire attestazione remota o verifica della firma RSA-PSS.
