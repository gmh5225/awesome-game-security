Пример консольного приложения на C++, вызывающий API Windows GetRuntimeAttestationReport для получения, разбора и вывода подписанных Runtime Report Packages из операционной системы. Он декодирует отчёты о драйверах, перечисляющие каждый загруженный драйвер ядра с хешами образов, отпечатками сертификатов издателя и флагами, а также отчёты о hotpatch, показывающие образы в режиме ядра с применёнными подписанными Microsoft hotpatch, включая базовый адрес, размер образа и номера последовательности патчей. Собран с помощью Visual Studio 2022 и Windows SDK 10.0.29648 для x64 и ARM64; на поддерживаемых сборках Windows 11 требуются VBS и HVCI. Предназначен для исследователей безопасности, разработчиков античит-систем и аналитиков целостности ядра, которым нужно изучать данные runtime attestation без удалённой аттестации или проверки подписи RSA-PSS.
