Eine C++-Konsolenbeispielanwendung, die die Windows-API GetRuntimeAttestationReport aufruft, um signierte Runtime Report Packages vom Betriebssystem abzurufen, zu parsen und auszugeben. Sie dekodiert Treiberberichte, die jeden geladenen Kernel-Treiber mit Image-Hashes, Zertifikats-Fingerabdrücken des Herausgebers und Flags auflisten, sowie Hotpatch-Berichte, die Kernel-Mode-Images mit von Microsoft signierten Hotpatches anzeigen, einschließlich Basisadresse, Image-Größe und Patch-Sequenznummern. Mit Visual Studio 2022 und dem Windows SDK 10.0.29648 für x64 und ARM64 erstellt, erfordert das Tool VBS und HVCI auf unterstützten Windows-11-Builds. Es richtet sich an Sicherheitsforscher, Anti-Cheat-Entwickler und Kernel-Integritätsanalysten, die Laufzeit-Attestierungsdaten prüfen müssen, ohne Remote-Attestierung oder RSA-PSS-Signaturprüfung durchzuführen.
