Ejemplo de consola en C++ que llama a la API de Windows GetRuntimeAttestationReport para recuperar, analizar e imprimir Runtime Report Packages firmados del sistema operativo. Decodifica informes de controladores que enumeran cada controlador del kernel cargado con hashes de imagen, huellas digitales del certificado del editor y banderas, e informes de hotpatch que muestran imágenes en modo kernel con hotpatches firmados por Microsoft, incluida la dirección base, el tamaño de la imagen y los números de secuencia del parche. Compilado con Visual Studio 2022 y Windows SDK 10.0.29648 para x64 y ARM64, la herramienta requiere VBS y HVCI en compilaciones compatibles de Windows 11. Está pensada para investigadores de seguridad, desarrolladores de anti-cheat y analistas de integridad del kernel que necesitan inspeccionar datos de atestación en tiempo de ejecución sin realizar atestación remota ni verificación de firma RSA-PSS.
