這是一個 C++ 主控台範例，呼叫 Windows GetRuntimeAttestationReport API，從作業系統取得、解析並列印已簽署的 Runtime Report Packages。它會解碼驅動程式報告，列出每個已載入的核心驅動程式及其映像雜湊、發行者憑證指紋和旗標；也會解碼熱修補報告，顯示已套用 Microsoft 簽署核心模式熱修補的映像，包括基底位址、映像大小和修補序號。此工具使用 Visual Studio 2022 與 Windows SDK 10.0.29648 建置，支援 x64 與 ARM64，在受支援的 Windows 11 版本上需啟用 VBS 與 HVCI。它面向需要檢查執行階段證明資料、且無需執行遠端證明或 RSA-PSS 簽章驗證的安全研究人員、反作弊開發者與核心完整性分析人員。
