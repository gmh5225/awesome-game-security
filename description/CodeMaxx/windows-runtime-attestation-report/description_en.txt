A C++ console sample that calls the Windows GetRuntimeAttestationReport API to retrieve, parse, and print signed Runtime Report Packages from the operating system. It decodes driver reports listing every loaded kernel driver with image hashes, publisher certificate thumbprints, and flags, and hotpatch reports showing kernel-mode images with Microsoft-signed hotpatches applied, including base address, image size, and patch sequence numbers. Built with Visual Studio 2022 and Windows SDK 10.0.29648 for x64 and ARM64, the tool requires VBS and HVCI on supported Windows 11 builds. It is intended for security researchers, anti-cheat developers, and kernel integrity analysts who need to inspect runtime attestation data without performing remote attestation or RSA-PSS signature verification.
