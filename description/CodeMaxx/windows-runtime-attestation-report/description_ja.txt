Windows GetRuntimeAttestationReport API を呼び出し、オペレーティング システムから署名済み Runtime Report Packages を取得・解析・表示する C++ コンソール サンプルです。読み込まれたすべてのカーネル ドライバーを、イメージ ハッシュ、発行者証明書のサムプリント、フラグとともに一覧するドライバー レポートをデコードし、Microsoft 署名のホットパッチが適用されたカーネル モード イメージについて、ベース アドレス、イメージ サイズ、パッチ シーケンス番号を示すホットパッチ レポートもデコードします。Visual Studio 2022 と Windows SDK 10.0.29648 で x64 および ARM64 向けにビルドされ、対応する Windows 11 ビルドでは VBS と HVCI が必要です。リモート アテステーションや RSA-PSS 署名検証を行わずにランタイム アテステーション データを調査する必要がある、セキュリティ研究者、アンチチート開発者、カーネル整合性アナリスト向けです。
