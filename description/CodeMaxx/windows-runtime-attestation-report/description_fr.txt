Exemple de console C++ qui appelle l’API Windows GetRuntimeAttestationReport pour récupérer, analyser et afficher des Runtime Report Packages signés depuis le système d’exploitation. Il décode les rapports de pilotes listant chaque pilote noyau chargé avec les hachages d’image, les empreintes de certificat de l’éditeur et les indicateurs, ainsi que les rapports de correctifs à chaud montrant les images en mode noyau avec des correctifs signés par Microsoft, y compris l’adresse de base, la taille de l’image et les numéros de séquence de correctif. Construit avec Visual Studio 2022 et le Windows SDK 10.0.29648 pour x64 et ARM64, l’outil nécessite VBS et HVCI sur les versions prises en charge de Windows 11. Il s’adresse aux chercheurs en sécurité, aux développeurs d’anti-triche et aux analystes d’intégrité du noyau qui doivent inspecter les données d’attestation d’exécution sans effectuer d’attestation distante ni de vérification de signature RSA-PSS.
