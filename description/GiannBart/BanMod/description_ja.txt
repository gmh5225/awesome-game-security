BanMod は Among Us 向けの BepInEx モデレーションおよびアンチチートプラグインで、ホストがロビーをチーター、チーム行為者、迷惑プレイヤーから守るのに役立ちます。C# で書かれ、Harmony による Unity IL2CPP へのランタイムパッチを用い、サーバー連携の BAN・チーター・チーム行為者リストを同期し、AFK 行為、カメラ乱用、追跡などの不審な行動をゲーム内検知器で監視し、キック、BAN、警告、プレイヤー通報のためのモデレーター UI を提供します。カスタムロール、ロビー検索、チャットおよび会議の制御、リモート API によって制限されるオプションのプレミアム機能、多言語対応も追加します。主な対象は、手動モデレーションだけでなく統合されたアンチチート執行とロビー管理を求める Among Us ホストおよびコミュニティモデレーターです。
