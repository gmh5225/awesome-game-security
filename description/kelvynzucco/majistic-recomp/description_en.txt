Majistic Recomp is an open-source static recompilation effort that ports Majin and the Forsaken Kingdom from Xbox 360 to native Windows by translating PowerPC game code into C++ with the ReXGlue and ReIGlue toolchain derived from Xenia. The repository centers on CMake-driven prototype builds, a large set of ReXGlue patches for Direct3D 12 and Vulkan rendering, XMA audio, and frame-timing diagnostics, plus game-specific fixes for shaders, animation, camera, and UI behavior. A Tauri and Rust desktop launcher with web front-end assets orchestrates setup, save handling, updates, and shader prebuild export tooling backed by SDL3, Dear ImGui, FFmpeg, and Tracy. It targets preservation researchers, porting developers, and reverse engineers studying console-to-PC static recompilation, Xenos GPU translation, and local shader and pipeline reconstruction from retail disc data.
