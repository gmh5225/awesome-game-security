Majistic Recomp 是一項開源靜態重編譯專案，藉由源自 Xenia 的 ReXGlue 與 ReIGlue 工具鏈，將 PowerPC 遊戲程式碼轉譯為 C++，從而將《魔王與墮落王國》（Xbox 360）移植至原生 Windows。此儲存庫以 CMake 驅動的原型建置為核心，涵蓋大量針對 Direct3D 12 與 Vulkan 繪圖、XMA 音訊及幀時序診斷的 ReXGlue 修補，以及著色器、動畫、鏡頭與 UI 行為的遊戲專屬修正。以 Tauri 與 Rust 打造的桌面啟動器搭配 Web 前端資產，負責安裝設定、存檔處理、更新與著色器預先建置匯出工具，底層採用 SDL3、Dear ImGui、FFmpeg 與 Tracy。專案鎖定關注主機到 PC 靜態重編譯、Xenos GPU 轉譯，以及從零售光碟資料重建著色器與管線的 preservation 研究者、移植開發者與逆向工程師。
