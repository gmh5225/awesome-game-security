Majistic Recomp は、Xenia 由来の ReXGlue および ReIGlue ツールチェーンで PowerPC のゲームコードを C++ に翻訳し、Xbox 360 版『Majin and the Forsaken Kingdom』をネイティブ Windows へ移植するオープンソースの静的再コンパイルプロジェクトです。リポジトリは CMake 駆動のプロトタイプビルドを中心に、Direct3D 12 と Vulkan レンダリング、XMA オーディオ、フレームタイミング診断向けの大量の ReXGlue パッチに加え、シェーダー、アニメーション、カメラ、UI 挙動向けのゲーム固有修正を収めています。Tauri と Rust のデスクトップランチャーと Web フロントエンド資産がセットアップ、セーブ処理、アップデート、シェーダー事前ビルドのエクスポートツールを統括し、SDL3、Dear ImGui、FFmpeg、Tracy を基盤としています。コンソールから PC への静的再コンパイル、Xenos GPU 翻訳、小売ディスクデータからのシェーダーとパイプライン再構築を研究する保存・移植開発者およびリバースエンジニアを対象としています。
