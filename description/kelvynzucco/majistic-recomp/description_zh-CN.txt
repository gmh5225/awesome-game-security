Majistic Recomp 是一项开源静态重编译项目，借助源自 Xenia 的 ReXGlue 与 ReIGlue 工具链，将 PowerPC 游戏代码译为 C++，从而把《魔王与堕落王国》（Xbox 360）移植到原生 Windows。本仓库以 CMake 驱动的原型构建为核心，包含大量面向 Direct3D 12 与 Vulkan 渲染、XMA 音频及帧时序诊断的 ReXGlue 补丁，以及针对着色器、动画、相机与 UI 行为的游戏专属修复。基于 Tauri 与 Rust 的桌面启动器配合 Web 前端资源，负责安装配置、存档处理、更新与着色器预编译导出工具，底层依赖 SDL3、Dear ImGui、FFmpeg 与 Tracy。项目面向关注主机到 PC 静态重编译、Xenos GPU 转译以及从零售光盘数据还原着色器与管线的 preservation 研究者、移植开发者与逆向工程师。
