GHIDRApy_FunctionStringAssociate est un script Ghidra qui collecte automatiquement les références de chaînes au sein de chaque fonction d'un binaire chargé et les attache sous forme de commentaires de fonction répétables. Écrit en Python pour l'API de script Ghidra, il parcourt chaque fonction, examine les opérandes d'instruction pour détecter les références de données vers des littéraux de chaînes, et agrège ces chaînes pour annotation. L'outil utilise un modèle de références basé sur des nœuds pour traverser les corps de fonctions et résoudre les données de chaînes aux adresses référencées. Il est destiné aux ingénieurs en rétro-ingénierie et aux analystes en sécurité des jeux qui utilisent Ghidra pour accélérer le triage de binaires inconnus en faisant apparaître directement les chaînes intégrées sur les fonctions qui les utilisent.
