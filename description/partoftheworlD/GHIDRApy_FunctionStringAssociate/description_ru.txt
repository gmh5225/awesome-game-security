GHIDRApy_FunctionStringAssociate — это скрипт Ghidra, который автоматически собирает ссылки на строки внутри каждой функции загруженного бинарного файла и прикрепляет их в виде повторяемых комментариев к функциям. Написанный на Python для API скриптов Ghidra, он обходит каждую функцию, проверяет операнды инструкций на наличие ссылок на данные к строковым литералам и объединяет эти строки для аннотации. Инструмент использует модель ссылок на основе узлов для обхода тел функций и разрешения строковых данных по ссылочным адресам. Он предназначен для специалистов по обратной разработке и аналитиков игровой безопасности, использующих Ghidra, чтобы ускорить первичный анализ неизвестных бинарных файлов, отображая встроенные строки непосредственно на функциях, которые их используют.
