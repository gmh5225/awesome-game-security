GHIDRApy_FunctionStringAssociate ist ein Ghidra-Skript, das automatisch String-Referenzen innerhalb jeder Funktion in einer geladenen Binärdatei sammelt und sie als wiederholbare Funktionskommentare anfügt. In Python für die Ghidra-Scripting-API geschrieben, durchläuft es jede Funktion, untersucht Befehlsoperanden auf Datenreferenzen zu String-Literalen und fasst diese Strings zur Annotation zusammen. Das Tool verwendet ein knotenbasiertes Referenzmodell, um Funktionskörper zu durchlaufen und String-Daten an referenzierten Adressen aufzulösen. Es richtet sich an Reverse Engineers und Game-Security-Analysten, die Ghidra nutzen, um die Triage unbekannter Binärdateien zu beschleunigen, indem eingebettete Strings direkt auf den Funktionen angezeigt werden, die sie verwenden.
