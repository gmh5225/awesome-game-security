GHIDRApy_FunctionStringAssociate es un script de Ghidra que recopila automáticamente las referencias a cadenas dentro de cada función de un binario cargado y las adjunta como comentarios de función repetibles. Escrito en Python para la API de scripting de Ghidra, recorre cada función, inspecciona los operandos de las instrucciones en busca de referencias de datos a literales de cadena y agrega esas cadenas para su anotación. La herramienta utiliza un modelo de referencias basado en nodos para recorrer los cuerpos de las funciones y resolver los datos de cadena en las direcciones referenciadas. Está destinado a ingenieros de ingeniería inversa y analistas de seguridad de juegos que usan Ghidra para acelerar el triaje de binarios desconocidos mostrando directamente las cadenas incrustadas en las funciones que las utilizan.
