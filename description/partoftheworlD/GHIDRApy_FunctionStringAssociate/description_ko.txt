GHIDRApy_FunctionStringAssociate는 로드된 바이너리의 각 함수 내 문자열 참조를 자동으로 수집하여 반복 가능한 함수 주석으로 첨부하는 Ghidra 스크립트입니다. Ghidra 스크립트 API용 Python으로 작성되었으며, 모든 함수를 순회하면서 명령어 피연산자에서 문자열 리터럴에 대한 데이터 참조를 검사하고 주석을 위해 해당 문자열을 집계합니다. 이 도구는 노드 기반 참조 모델을 사용해 함수 본문을 탐색하고 참조된 주소의 문자열 데이터를 해석합니다. Ghidra를 사용하는 리버스 엔지니어와 게임 보안 분석가를 위해 설계되었으며, 알 수 없는 바이너리의 트리아지를 가속화하기 위해 내장된 문자열을 이를 사용하는 함수에 직접 표시합니다.
