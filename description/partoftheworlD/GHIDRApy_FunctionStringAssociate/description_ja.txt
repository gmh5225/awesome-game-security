GHIDRApy_FunctionStringAssociate は、読み込んだバイナリ内の各関数における文字列参照を自動的に収集し、それらを繰り返し可能な関数コメントとして付加する Ghidra スクリプトです。Ghidra スクリプト API 向けに Python で書かれており、すべての関数を走査し、命令オペランド内の文字列リテラルへのデータ参照を調べ、注釈用にそれらの文字列を集約します。このツールはノードベースの参照モデルを用いて関数本体を走査し、参照先アドレスの文字列データを解決します。Ghidra を使うリバースエンジニアやゲームセキュリティアナリスト向けに設計されており、未知のバイナリのトリアージを高速化するため、埋め込まれた文字列をそれを使用する関数上に直接表示します。
