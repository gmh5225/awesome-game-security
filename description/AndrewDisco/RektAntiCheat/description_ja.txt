RektAntiCheat は Java 製の Minecraft サーバー向けプラグインで、一般的なクライアントチートや不正なプレイヤー行為を検出してブロックします。Maven でビルドした Spigot/Bukkit 用 JAR として配布され、PacketEvents と Netty スタイルのパケット傍受によりネットワークトラフィックを検査し、ゲーム内の移動・戦闘状態とあわせて分析します。検出モジュールは kill aura、reach、autoclicker などの戦闘系不正、fly、speed、phase、scaffold などの移動系チート、さらにパケット・インベントリ・timer・クラッシュ関連のチェックをカバーします。オプションの参加時ツールでプロキシや接続メタデータをフラグ付けできます。サーバー運営者や開発者が、マルチプレイのサバイバルや PvP 環境を広く流通する Minecraft ハッククライアントから守るために利用します。
