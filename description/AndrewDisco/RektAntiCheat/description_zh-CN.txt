RektAntiCheat 是一款基于 Java 的 Minecraft 服务端插件，用于检测并拦截常见的客户端作弊与未授权的玩家行为。它以 Maven 构建的 Spigot/Bukkit JAR 形式发布，集成 PacketEvents，通过 Netty 风格的报文拦截检查网络流量，并结合游戏内移动与战斗状态进行分析。检测模块覆盖战斗类滥用（如 kill aura、reach、autoclicker）、移动类作弊（如 fly、speed、phase、scaffold），以及报文、背包、timer 与崩溃相关检查。可选的加入时工具可对代理及相关连接元数据进行标记。服主与开发者用它加固多人生存与 PvP 环境，抵御广泛流传的 Minecraft 作弊客户端。
