RektAntiCheat는 Java 기반 Minecraft 서버 플러그인으로, 흔한 클라이언트 치트와 허가되지 않은 플레이어 행위를 탐지하고 차단합니다. Maven으로 빌드한 Spigot/Bukkit JAR로 제공되며, PacketEvents와 Netty 스타일 패킷 가로채기로 네트워크 트래픽을 검사하고 게임 내 이동·전투 상태와 함께 분석합니다. 탐지 모듈은 kill aura, reach, autoclicker 같은 전투 남용, fly, speed, phase, scaffold 같은 이동 핵, 패킷·인벤토리·timer·크래시 관련 검사까지 다룹니다. 선택적 접속 시 도구로 프록시 및 관련 연결 메타데이터를 표시할 수 있습니다. 서버 운영자와 개발자가 멀티플레이 생존 및 PvP 환경을 널리 퍼진 Minecraft 핵 클라이언트로부터 강화하는 데 사용합니다.
