RektAntiCheat 是一款以 Java 為基礎的 Minecraft 伺服器外掛，用於偵測並封鎖常見的用戶端作弊與未經授權的玩家行為。它以 Maven 建置的 Spigot/Bukkit JAR 形式發佈，整合 PacketEvents，透過 Netty 風格的封包攔截檢查網路流量，並結合遊戲內移動與戰鬥狀態進行分析。偵測模組涵蓋戰鬥類濫用（如 kill aura、reach、autoclicker）、移動類外掛（如 fly、speed、phase、scaffold），以及封包、物品欄、timer 與崩潰相關檢查。可選的加入時工具可標記代理及相關連線中繼資料。伺服器管理員與開發者用它強化多人生存與 PvP 環境，對抗常見的 Minecraft 作弊用戶端。
