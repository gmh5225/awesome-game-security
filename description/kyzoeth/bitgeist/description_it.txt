Bitgeist è un’arena retro di speedrun nel browser in cui i giocatori affrontano sprint brevi contro fino a dieci replay fantasma, con retry istantanei da save state e link condivisibili per sfide uno contro uno. Esegue nel client core Libretro WebAssembly multiconsole (NES, SNES, Genesis, Game Boy, GBA) a 60 FPS e legge in tempo reale posizione del giocatore, camera e stato di arrivo dalla RAM di sistema emulata senza patchare le ROM. Le classifiche fantasma persistono in SQLite con matchmaking per fasce di skill, mentre un vault ROM locale conserva le cartucce solo in IndexedDB sul dispositivo dell’utente. Per l’integrità registra log del joypad codificati a lunghezza di run a 60 Hz, correla i movimenti con regole specifiche del gioco come arrampicate sui muri e dash aerei, e verifica le run tramite replay WASM deterministico in un worker headless. Lo stack è principalmente TypeScript e Next.js lato server con API SQLite di Node, utile per studiare telemetria dell’emulazione lato client, validazione di replay competitivi e pattern anti-cheat leggeri in sfide di gioco ospitate nel browser.
