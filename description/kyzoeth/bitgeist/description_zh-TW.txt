Bitgeist 是一款以瀏覽器為平台的復古速通競技場，玩家可在短距離衝刺中與最多十條幽靈回放競速，支援即時存檔重試與可分享的一對一挑戰連結。用戶端以 60 FPS 執行多主機 Libretro WebAssembly 核心（NES、SNES、Genesis、Game Boy、GBA），無需修補 ROM 即可從模擬系統 RAM 讀取玩家位置、鏡頭與完賽狀態。幽靈排行榜持久化於 SQLite，並提供依技能分級的配對；本地 ROM 保險庫僅將卡帶保存在使用者裝置的 IndexedDB 中。為確保公平，它以 60 Hz 記錄行程長度編碼的手把紀錄，並依攀牆、空中衝刺等遊戲規則關聯移動，於無頭 worker 中透過確定性 WASM 回放驗證成績。伺服器端以 TypeScript 與 Next.js 為主，搭配 Node SQLite API，適合研究用戶端模擬遙測、競技回放驗證，以及瀏覽器託管遊戲挑戰中的輕量反作弊模式。
