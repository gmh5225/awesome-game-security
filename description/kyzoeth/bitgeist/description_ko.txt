Bitgeist는 브라우저 기반 레트로 스피드런 아레나로, 짧은 스프린트에서 최대 열 개의 고스트 리플레이와 경주하며 즉시 세이브 상태 재시도와 공유 가능한 일대일 도전 링크를 제공합니다. 클라이언트에서 NES, SNES, Genesis, Game Boy, GBA용 Libretro WebAssembly 코어를 60 FPS로 실행하고, ROM 패치 없이 에뮬레이션된 시스템 RAM에서 플레이어 위치, 카메라, 완주 상태를 읽습니다. 고스트 리더보드는 SQLite에 영속화되며 스킬 구간별 매치메이킹을 지원하고, 로컬 ROM 볼트는 카트리지를 사용자 기기의 IndexedDB에만 보관합니다. 무결성을 위해 60 Hz로 런 길이 인코딩된 조이패드 로그를 기록하고, 벽 타기·공중 대시 등 게임별 규칙과 이동을 상관시키며, 헤드리스 worker에서 결정론적 WASM 리플레이로 런을 검증합니다. 스택은 서버 측에서 주로 TypeScript와 Next.js, Node SQLite API로 구성되어 클라이언트 측 에뮬레이션 원격 측정, 경쟁 리플레이 검증, 브라우저 호스팅 게임 챌린지의 경량 안티치트 패턴 연구에 유용합니다.
