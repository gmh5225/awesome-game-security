Bitgeist 是一款基于浏览器的复古速通竞技场，玩家可在短距离冲刺中与最多十条幽灵回放竞速，支持即时存档重试和可分享的一对一挑战链接。客户端以 60 FPS 运行多主机 Libretro WebAssembly 核心（NES、SNES、Genesis、Game Boy、GBA），无需修改 ROM 即可从模拟系统 RAM 读取玩家位置、镜头与完赛状态。幽灵排行榜持久化于 SQLite，并支持按技能分档匹配；本地 ROM 保险库仅将卡带保存在用户设备的 IndexedDB 中。为保公平，它以 60 Hz 记录游程长度编码的手柄日志，结合攀墙、空中冲刺等游戏规则校验移动，并在无头 worker 中通过确定性 WASM 回放验证成绩。服务端栈以 TypeScript 与 Next.js 为主，配合 Node SQLite API，适合研究客户端模拟遥测、竞技回放校验以及浏览器托管游戏挑战中的轻量反作弊模式。
