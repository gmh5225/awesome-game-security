Bitgeist is a browser-based retro speedrun arena where players race short sprints against up to ten ghost replays with instant save-state retries and shareable one-on-one dare links. It runs multi-console Libretro WebAssembly cores (NES, SNES, Genesis, Game Boy, GBA) in the client at 60 FPS and reads live player position, camera, and finish state from emulated system RAM without patching ROMs. Ghost leaderboards persist in SQLite with skill-bracketed matchmaking, while local ROM vaulting keeps cartridges in IndexedDB only on the user device. For integrity, it records 60 Hz run-length-encoded joypad logs, correlates movement with game-specific rules such as wall climbs and air dashes, and verifies runs through deterministic WASM replay in a headless worker. The stack is primarily TypeScript and Next.js on the server side with Node SQLite APIs, making it useful for studying client-side emulation telemetry, competitive replay validation, and lightweight anti-cheat patterns in browser-hosted game challenges.
