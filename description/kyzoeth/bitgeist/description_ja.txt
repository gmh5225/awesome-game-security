Bitgeist はブラウザ上のレトロ系スピードランアリーナで、短距離スプリントで最大10本のゴーストリプレイと競い、即時セーブステートリトライと共有可能な1対1ダレリンクに対応します。クライアントでは NES、SNES、Genesis、Game Boy、GBA 向けの Libretro WebAssembly コアを 60 FPS で動かし、ROM をパッチせずにエミュレートされたシステム RAM からプレイヤー位置、カメラ、ゴール状態を読み取ります。ゴーストリーダーボードは SQLite に永続化され、スキル帯別マッチメイキングを備え、ローカル ROM ボルトはカートリッジをユーザ端末の IndexedDB のみに保持します。整合性のため 60 Hz でラン長エンコードされたジョイパッドログを記録し、壁登りやエアダッシュなどゲーム固有ルールと移動を相関させ、ヘッドレス worker 上の決定論的 WASM リプレイでランを検証します。サーバー側は主に TypeScript と Next.js、Node SQLite API で構成され、クライアント側エミュレーションのテレメトリ、競技リプレイ検証、ブラウザホスト型ゲームチャレンジにおける軽量アンチチートパターンの研究に役立ちます。
