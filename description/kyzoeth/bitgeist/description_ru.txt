Bitgeist — ретро-арена спидранов в браузере: игроки соревнуются в коротких спринтах с до десятью призрачными реплеями, с мгновенными повторами через save state и ссылками на дуэли один на один. На клиенте работают мультиконсольные ядра Libretro WebAssembly (NES, SNES, Genesis, Game Boy, GBA) с 60 FPS; позиция игрока, камера и финиш читаются из эмулируемой системной RAM без патчей ROM. Таблицы призраков хранятся в SQLite с подбором по уровню skill, локальное хранилище ROM держит картриджи только в IndexedDB на устройстве пользователя. Для целостности записываются joypad-логи с run-length-кодированием на 60 Гц, движение сопоставляется с правилами игры (лазание по стенам, воздушный dash), прогоны проверяются детерминированным WASM-реплеем в headless worker. Стек в основном TypeScript и Next.js на сервере с Node SQLite API — полезен для изучения телеметрии клиентской эмуляции, валидации соревновательных реплеев и лёгких античит-паттернов в браузерных игровых челленджах.
