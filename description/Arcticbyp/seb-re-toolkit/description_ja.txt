Safe Exam Browser のネイティブ整合性モジュール、すなわち試験の改ざん防止を担う Themida 保護の seb_x64.dll に焦点を当てた Python 向けリバースエンジニアリングツールキットです。コマンドラインとタブ付き GUI のワークフローを組み合わせ、静的 PE 解析（セクション、エントロピー、Rich ヘッダー、インポート、セキュリティフラグ）で DLL を調査し、Themida、VMProtect、Enigma などのパッカーを検出し、鍵導出、VM 検出、Authenticode 検証に関するエクスポート署名を文書化します。BSTR 対応 ctypes と cdecl 呼び出し規約でエクスポートを呼び出せ、呼び出しサイト検証により直接呼び出しがブロックされる場合は Frida フックで実行中の Safe Exam Browser プロセス内のエクスポート利用をトレースします。保護された教育向け試験ソフト、商用パッカー、ランタイムのスクレイピング対策を研究する研究者・エンジニア向けであり、一般的なゲームアンチチート向けではありません。Safe Exam Browser がインストールされた Windows 上で pefile と frida-tools に依存します。
