这是一个面向 Safe Exam Browser 原生完整性模块的 Python 逆向工程工具包，该模块为受 Themida 保护的 seb_x64.dll，用于实施考试防篡改行为。它提供命令行与带标签页的 GUI 工作流，通过静态 PE 分析（节区、熵、Rich 头、导入表与安全标志）检查该 DLL，检测 Themida、VMProtect、Enigma 等壳，并记录与密钥派生、虚拟机检测及 Authenticode 验证相关的导出函数特征。工具可通过支持 BSTR 的 ctypes 以 cdecl 调用约定调用导出函数，并在直接调用被调用点校验阻断时，用 Frida 挂钩在运行中的 Safe Exam Browser 进程内追踪导出函数的使用。面向研究受保护教育考试软件、商业壳与运行时反抓取的研究人员与工程师，而非通用游戏反作弊；在已安装 Safe Exam Browser 的 Windows 上依赖 pefile 与 frida-tools。
