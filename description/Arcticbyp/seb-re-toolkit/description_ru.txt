Набор инструментов на Python для реверс-инжиниринга, сфокусированный на нативном модуле целостности Safe Exam Browser — библиотеке seb_x64.dll, защищённой Themida и обеспечивающей антивмешательство на экзаменах. Он сочетает командную строку и GUI с вкладками для анализа DLL статическим PE-разбором (секции, энтропия, Rich-заголовок, импорты и флаги безопасности), обнаружения упаковщиков вроде Themida, VMProtect и Enigma, а также документирования сигнатур экспорта для вывода ключей, обнаружения VM и проверки Authenticode. Инструмент может вызывать экспорты через ctypes с поддержкой BSTR и соглашением вызова cdecl и подключать хуки Frida для трассировки использования экспортов в работающем процессе Safe Exam Browser, когда прямые вызовы блокируются проверкой места вызова. Ориентирован на исследователей и инженеров, изучающих защищённое образовательное экзаменационное ПО, коммерческие упаковщики и анти-скрейпинг во время выполнения, а не на общий игровой античит; на Windows с установленным Safe Exam Browser использует pefile и frida-tools.
