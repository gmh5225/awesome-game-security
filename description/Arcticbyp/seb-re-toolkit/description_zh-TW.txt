這是一套以 Safe Exam Browser 原生完整性模組為對象的 Python 逆向工程工具包，該模組為受 Themida 保護的 seb_x64.dll，用於落實考試防篡改行為。它結合命令列與分頁式 GUI 工作流程，以靜態 PE 分析（區段、熵、Rich 標頭、匯入表與安全旗標）檢視該 DLL，偵測 Themida、VMProtect、Enigma 等加殼工具，並記錄與金鑰衍生、虛擬機偵測及 Authenticode 驗證相關的匯出函式特徵。工具可透過支援 BSTR 的 ctypes 以 cdecl 呼叫慣例呼叫匯出函式，並在直接呼叫被呼叫點驗證阻擋時，以 Frida 掛鉤在執行中的 Safe Exam Browser 程序內追蹤匯出函式的使用。面向研究受保護教育考試軟體、商業加殼與執行期反抓取的研究人員與工程師，而非一般遊戲反作弊；在已安裝 Safe Exam Browser 的 Windows 上依賴 pefile 與 frida-tools。
