This is a Python reverse engineering toolkit focused on Safe Exam Browser’s native integrity module, the Themida-protected seb_x64.dll used to enforce exam anti-tamper behavior. It combines command-line and tabbed GUI workflows to inspect the DLL with static PE analysis (sections, entropy, Rich header, imports, and security flags), detect packers such as Themida, VMProtect, and Enigma, and document export signatures for key derivation, VM detection, and Authenticode verification. The tool can invoke exports through BSTR-aware ctypes with cdecl calling conventions and attach Frida hooks to trace export usage inside a live Safe Exam Browser process when direct calls are blocked by call-site verification. It targets researchers and engineers studying protected educational exam software, commercial packers, and runtime anti-scraping rather than general game anti-cheat, and relies on pefile and frida-tools on Windows where Safe Exam Browser is installed.
