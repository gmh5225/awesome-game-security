Safe Exam Browser의 네이티브 무결성 모듈, 즉 시험 변조 방지를 수행하는 Themida로 보호된 seb_x64.dll에 초점을 맞춘 Python 리버스 엔지니어링 툴킷입니다. 명령줄과 탭형 GUI 워크플로를 결합해 정적 PE 분석(섹션, 엔트로피, Rich 헤더, 임포트, 보안 플래그)으로 DLL을 검사하고, Themida, VMProtect, Enigma 같은 패커를 탐지하며, 키 유도, VM 탐지, Authenticode 검증과 관련된 내보내기 시그니처를 문서화합니다. BSTR을 인식하는 ctypes와 cdecl 호출 규약으로 내보내기를 호출할 수 있으며, 호출 지점 검증으로 직접 호출이 차단될 때 Frida 후크로 실행 중인 Safe Exam Browser 프로세스 내부의 내보내기 사용을 추적합니다. 보호된 교육용 시험 소프트웨어, 상용 패커, 런타임 스크래핑 방지를 연구하는 연구자와 엔지니어를 대상으로 하며, 일반적인 게임 안티치트용이 아닙니다. Safe Exam Browser가 설치된 Windows에서 pefile과 frida-tools에 의존합니다.
