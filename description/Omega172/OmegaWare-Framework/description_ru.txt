OmegaWare Framework — это Windows C++ основа для создания инжектируемых модификаций игр с внутриигровым overlay-меню ImGui и консолью разработчика. Он ориентирован на Unity, Unreal Engine и другие игры на DirectX через настраиваемые профили движков, автоматическое обнаружение рендереров D3D11 и D3D12, а также хуки графического конвейера и процедуры окна. Плагиноподобная система функций с автоматической регистрацией, JSON-конфигурацией, локализацией, утилитами для работы с памятью и CRC64-хешированием строк на этапе компиляции позволяет разработчикам добавлять модульные возможности без переписывания базовой логики инъекции. Собран с помощью Xmake в архитектуре proxy плюс внутренняя DLL, предназначен для реверс-инженеров и исследователей игровой безопасности, изучающих методы разработки читов и контрмеры античита.
