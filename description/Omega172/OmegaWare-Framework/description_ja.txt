OmegaWare Framework は、ゲーム内 ImGui オーバーレイメニューと開発者コンソールを備えた、注入型ゲーム改造を構築するための Windows C++ 基盤です。設定可能なエンジンプロファイル、D3D11 および D3D12 レンダラーの自動検出、グラフィックスパイプラインおよびウィンドウプロシージャへのフックにより、Unity、Unreal Engine、その他 DirectX ベースのゲームをターゲットにします。自動登録、JSON 設定、ローカライズ、メモリユーティリティ、コンパイル時 CRC64 文字列ハッシュを備えたプラグイン形式の機能システムにより、開発者はコア注入ロジックを書き直すことなくモジュール機能を追加できます。Xmake による proxy 加 internal DLL レイアウトで構築され、チート開発手法とアンチチート対策を研究するリバースエンジニアおよびゲームセキュリティ研究者向けです。
