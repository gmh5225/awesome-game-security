OmegaWare Framework 是一个 Windows C++ 基础框架，用于构建注入式游戏修改，内置游戏内 ImGui 覆盖菜单和开发者控制台。它通过可配置的引擎配置文件、自动 D3D11 和 D3D12 渲染器检测，以及对图形管线和窗口过程的 Hook，支持 Unity、Unreal Engine 及其他基于 DirectX 的游戏。插件式功能系统支持自动注册、JSON 配置、本地化、内存工具以及编译时 CRC64 字符串哈希，使开发者无需重写核心注入逻辑即可添加模块化功能。采用 Xmake 构建，采用代理加内部 DLL 架构，面向研究作弊开发技术与反作弊对策的逆向工程师和游戏安全研究人员。
