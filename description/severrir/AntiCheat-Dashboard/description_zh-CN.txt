AntiCheat Dashboard 是一款面向 Roblox 游戏的服务端反作弊系统，配套基于 Web 的员工控制台，用于监控与执法处置。游戏模块以 Luau 编写，通过信任评分引擎对移动、角色、战斗、网络、时序及客户端完整性进行检查，踢出前需多重佐证，并包含蜜罐、诱饵陷阱及可选的作弊者隔离。控制台基于 React、Vite、Tailwind 和 Three.js 构建，由 Supabase 提供支持，涵盖实时遥测、全局封禁、Discord 通知、3D 踢人回放、任务控制雷达、案件档案及申诉流程。适用于需要生产级作弊检测、无需重新发布即可实时调参，以及人工参与封禁而非全自动处罚的 Roblox 开发者与审核团队。
