AntiCheat Dashboard は、Roblox ゲーム向けのサーバーサイド反チートシステムで、監視と執行のための Web ベースのスタッフコンソールと組み合わせて利用します。ゲームモジュールは Luau で記述され、移動・キャラクター・戦闘・ネットワーク・タイミング・クライアント整合性のチェックを、キック前に裏付けを要求する信頼スコアリングエンジンで実行し、ハニーポット、おとり罠、任意のチーター隔離機能も備えます。ダッシュボードは React、Vite、Tailwind、Three.js で構築され、Supabase によりライブテレメトリ、グローバル BAN、Discord アラート、3D キックリプレイ、ミッションコントロールレーダー、ケースファイル、異議申し立てワークフローを提供します。本番レベルのチート検出、再公開なしのライブチューニング、完全自動の処罰ではなく人間が介在する BAN を必要とする Roblox 開発者およびモデレーションチーム向けです。
