AntiCheat Dashboard is a server-side anti-cheat system for Roblox games paired with a web-based staff console for monitoring and enforcement. The game module is written in Luau and runs movement, character, combat, network, timing, and client integrity checks through a trust-scoring engine that requires corroboration before kicks, plus honeypots, bait traps, and optional cheater isolation. The dashboard is built with React, Vite, Tailwind, and Three.js, backed by Supabase for live telemetry, global bans, Discord alerts, 3D kick replays, mission control radar, case files, and appeal workflows. It targets Roblox developers and moderation teams who need production-grade cheat detection, live tuning without republishing, and human-in-the-loop banning rather than fully automated punishment.
