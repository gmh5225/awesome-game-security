AntiCheat Dashboard — это серверная античит-система для игр Roblox в паре с веб-консолью для персонала, предназначенной для мониторинга и принудительных мер. Игровой модуль написан на Luau и выполняет проверки движения, персонажа, боя, сети, тайминга и целостности клиента через движок оценки доверия, требующий подтверждения перед киками, а также honeypot'ы, приманки-ловушки и опциональную изоляцию читеров. Панель построена на React, Vite, Tailwind и Three.js, с поддержкой Supabase для телеметрии в реальном времени, глобальных банов, оповещений Discord, 3D-воспроизведения киков, радара управления миссиями, дел и процессов обжалования. Ориентирована на разработчиков Roblox и команды модерации, которым нужно продакшен-уровня обнаружение читов, настройка в реальном времени без перепубликации и баны с участием человека, а не полностью автоматизированные наказания.
