AntiCheat Dashboard 是一款面向 Roblox 遊戲的伺服器端反作弊系統，搭配基於 Web 的員工主控台，用於監控與執法處置。遊戲模組以 Luau 撰寫，透過信任評分引擎對移動、角色、戰鬥、網路、時序及客戶端完整性進行檢查，踢出前需多重佐證，並包含蜜罐、誘餌陷阱及可選的作弊者隔離。主控台以 React、Vite、Tailwind 和 Three.js 建構，由 Supabase 提供支援，涵蓋即時遙測、全域封禁、Discord 通知、3D 踢人回放、任務控制雷達、案件檔案及申訴流程。適用於需要生產級作弊偵測、無需重新發布即可即時調參，以及人工參與封禁而非全自動處罰的 Roblox 開發者與審核團隊。
