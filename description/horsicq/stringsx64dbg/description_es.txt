Strings es un complemento de x64dbg que añade una pestaña dedicada para buscar y explorar cadenas dentro de un proceso o módulo en depuración. Está escrito en C++ con una interfaz basada en Qt e se integra mediante el SDK de complementos de x64dbg, exponiendo un SearchStringsWidget para listar y filtrar las cadenas extraídas. El complemento admite compilaciones de 32 y 64 bits y se apoya en las API bridge estándar de x64dbg para las pestañas de la GUI y la interacción con el depurador. Está orientado a ingenieros inversos y analistas de seguridad de juegos que necesitan un descubrimiento de cadenas más completo al depurar con x64dbg.
