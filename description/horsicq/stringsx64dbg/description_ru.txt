Strings — плагин для x64dbg, добавляющий отдельную вкладку для поиска и просмотра строк в отлаживаемом процессе или модуле. Написан на C++ с Qt-интерфейсом и интегрируется через SDK плагинов x64dbg, предоставляя SearchStringsWidget для списка и фильтрации извлечённых строк. Поддерживает сборки для 32 и 64 бит и использует стандартные bridge API x64dbg для вкладок GUI и взаимодействия с отладчиком. Предназначен для reverse-инженеров и аналитиков игровой безопасности, которым нужно более удобное обнаружение строк при отладке в x64dbg.
