Strings è un plugin per x64dbg che aggiunge una scheda dedicata per cercare e sfogliare le stringhe all’interno di un processo o modulo in debug. È scritto in C++ con un’interfaccia basata su Qt e si integra tramite l’SDK dei plugin di x64dbg, esponendo un SearchStringsWidget per elencare e filtrare le stringhe estratte. Il plugin supporta build a 32 e 64 bit e si basa sulle API bridge standard di x64dbg per le schede GUI e l’interazione con il debugger. È pensato per reverse engineer e analisti di sicurezza dei giochi che necessitano di un’esplorazione delle stringhe più ricca durante il debug con x64dbg.
