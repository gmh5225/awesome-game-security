Strings는 디버깅 중인 프로세스나 모듈 안의 문자열을 검색하고 탐색할 수 있는 전용 탭을 추가하는 x64dbg 플러그인입니다. C++로 작성되었으며 Qt 기반 UI를 사용하고, x64dbg 플러그인 SDK를 통해 통합되어 추출된 문자열을 나열하고 필터링하는 SearchStringsWidget을 제공합니다. 32비트와 64비트 빌드를 모두 지원하며, GUI 탭과 디버거 상호작용에는 표준 x64dbg bridge API를 사용합니다. x64dbg로 디버깅할 때 더 풍부한 문자열 탐색이 필요한 리버스 엔지니어와 게임 보안 분석가를 대상으로 합니다.
