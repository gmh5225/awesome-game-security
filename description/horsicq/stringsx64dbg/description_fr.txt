Strings est un plugin x64dbg qui ajoute un onglet dédié pour rechercher et parcourir les chaînes dans un processus ou un module en cours de débogage. Il est écrit en C++ avec une interface basée sur Qt et s’intègre via le SDK de plugins x64dbg, exposant un SearchStringsWidget pour lister et filtrer les chaînes extraites. Le plugin prend en charge les builds 32 bits et 64 bits et s’appuie sur les API bridge standard de x64dbg pour les onglets GUI et l’interaction avec le débogueur. Il s’adresse aux reverse engineers et aux analystes en sécurité des jeux qui ont besoin d’une découverte de chaînes plus riche lors du débogage avec x64dbg.
