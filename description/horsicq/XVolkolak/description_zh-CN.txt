XVolkolak 是一款基于模拟的可执行文件脱壳工具，通过单步执行加壳程序的加载器 stub，直至到达原始入口点，从而重建被加壳的 Windows PE 文件。该项目使用 C++、Qt 和 CMake 构建，基于 XEmulUnpacker 引擎（依赖 XEmulator 用户态 CPU 模拟器）同时提供图形界面应用和控制台工具。用户可选择自动启发式脱壳，或针对 UPX、ASPack、NSPack、MPRESS、PECompact 等格式的 21 种加壳器专用脱壳器之一。图形界面在 worker 线程上执行脱壳，并实时显示引擎日志与进度；控制台则支持面向批处理的输出路径、加壳器选择与详细诊断选项。该工具面向需要从受保护可执行文件中恢复未加壳二进制、以便进行静态分析的逆向工程师与恶意软件分析人员。
