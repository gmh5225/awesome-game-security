XVolkolak — это распаковщик исполняемых файлов на основе эмуляции, который восстанавливает упакованные PE-файлы Windows, пошагово выполняя загрузочный stub упаковщика до достижения исходной точки входа. Создан на C++, Qt и CMake и предоставляет как графическое приложение, так и консольный инструмент на базе движка XEmulUnpacker, который использует пользовательский эмулятор CPU XEmulator. Пользователи могут выбрать автоматическую эвристическую распаковку или один из 21 специализированного распаковщика для форматов UPX, ASPack, NSPack, MPRESS, PECompact и других. GUI выполняет распаковку в рабочем потоке с выводом журнала и прогресса движка в реальном времени, а консоль поддерживает пакетные параметры для путей вывода, выбора упаковщика и подробной диагностики. Инструмент предназначен для специалистов по реверс-инжинирингу и аналитиков вредоносного ПО, которым нужно восстанавливать распакованные бинарники из защищённых исполняемых файлов для статического анализа.
