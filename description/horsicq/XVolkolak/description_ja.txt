XVolkolak は、パッカーのローダー stub をステップ実行し、オリジナルのエントリポイントに到達するまで追跡することで、パックされた Windows PE ファイルを再構築する、エミュレーションベースの実行ファイルアンパッカーです。C++、Qt、CMake で構築され、XEmulator ユーザーモード CPU エミュレーターに依存する XEmulUnpacker エンジンの上に、グラフィカルアプリケーションとコンソールツールの両方を提供します。ユーザーは自動ヒューリスティックアンパック、または UPX、ASPack、NSPack、MPRESS、PECompact などの形式向け 21 種類のパッカー専用アンパッカーのいずれかを選択できます。GUI はワーカースレッド上でアンパックを実行し、エンジンのログと進捗をリアルタイム表示します。コンソールは、出力パス、パッカー選択、詳細診断などのバッチ指向オプションをサポートします。保護された実行ファイルからアンパック済みバイナリを復元し、静的解析を行う必要があるリバースエンジニアやマルウェアアナリスト向けのツールです。
