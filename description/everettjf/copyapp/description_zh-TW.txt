Copy APP 是一款以 Python CLI 與智能體工作流為導向的工具，用於分析已安裝的 iOS 與 macOS 應用程式，並將所選行為重建為可獨立執行的應用。它透過 USB 驅動真實裝置，收集安裝套件、UI 與無障礙樹、沙盒資料及可選的執行期 trace；在相容的越獄路徑上支援 FairPlay 相關解密，也提供無需 SSH 或 Frida 的輕量標準模式 UI 擷取。靜態分析可整合可選的 Ghidra 與 Hopper 反編譯、ARM64 反組譯及 Frida 方法追蹤，並透過可驗證的證據案例、劇本與編碼智能體交接任務進行編排。Swift 元件支援 macOS 收集與範例重建目標；工具鏈強調附引用的報告、功能規格，以及在同一裝置上比對原版與重建流程。面向需要可重現、證據鏈清晰的專有應用行為研究——而非黑箱猜測——的行動逆向工程師、安全研究人員與開發者。
