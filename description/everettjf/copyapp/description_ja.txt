Copy APP は、インストール済みの iOS および macOS アプリケーションを解析し、選択した挙動を独立して実行可能なアプリとして再構築する Python CLI およびエージェント指向のワークフローです。USB 経由で実機を操作し、パッケージ、UI とアクセシビリティツリー、サンドボックスデータ、任意のランタイムトレースを収集します。互換性のある jailbreak 経路では FairPlay 関連の復号に対応し、SSH や Frida なしの軽量な標準モード UI 取得も可能です。静的解析では任意の Ghidra および Hopper による逆コンパイル、ARM64 逆アセンブル、Frida によるメソッドトレースを統合し、検証可能なエビデンスケース、プレイブック、コーディングエージェントへの引き継ぎタスクでオーケストレーションします。Swift コンポーネントは macOS 上の収集とサンプル再構築ターゲットを支え、ツールチェーンは引用付きレポート、機能仕様、同一デバイス上でのオリジナルと再構築フローの比較を重視します。ブラックボックス推測ではなく、再現可能でエビデンスに結び付いた独自アプリ挙動の研究が必要なモバイルリバースエンジニア、セキュリティ研究者、開発者を対象としています。
