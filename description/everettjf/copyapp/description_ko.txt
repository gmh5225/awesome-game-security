Copy APP는 설치된 iOS 및 macOS 애플리케이션을 분석하고 선택한 동작을 독립적으로 실행 가능한 앱으로 재구성하는 Python CLI 및 에이전트 지향 워크플로입니다. USB로 실제 기기를 구동해 패키지, UI 및 접근성 트리, 샌드박스 데이터, 선택적 런타임 trace를 수집하며, 호환되는 탈옥 경로에서는 FairPlay 관련 복호화를 지원하고 SSH나 Frida 없이 더 가벼운 표준 모드 UI 캡처도 제공합니다. 정적 분석은 선택적 Ghidra 및 Hopper 디컴파일, ARM64 디스어셈블리, Frida 메서드 추적을 통합하고, 검증 가능한 증거 케이스, 플레이북, 코딩 에이전트 인수 작업으로 오케스트레이션합니다. Swift 컴포넌트는 macOS 수집 및 샘플 재구성 대상을 지원하며, 툴체인은 인용 보고서, 기능 명세, 동일 기기에서 원본과 재구성 흐름의 비교를 강조합니다. 블랙박스 추측이 아니라 재현 가능하고 증거에 연결된 독점 앱 동작 연구가 필요한 모바일 리버스 엔지니어, 보안 연구자, 개발자를 대상으로 합니다.
