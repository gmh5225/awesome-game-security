Copy APP 是一款面向 Python CLI 与智能体工作流的工具，用于分析已安装的 iOS 与 macOS 应用，并将选定行为重建为可独立运行的应用。它通过 USB 驱动真实设备，采集安装包、UI 与无障碍树、沙盒数据及可选的运行时 trace；在兼容的越狱路径上支持 FairPlay 相关解密，也提供无需 SSH 或 Frida 的轻量标准模式 UI 采集。静态分析可集成可选的 Ghidra 与 Hopper 反编译、ARM64 反汇编及 Frida 方法追踪，并通过可验证的证据用例、剧本与编码智能体交接任务进行编排。Swift 组件支持 macOS 采集与示例重建目标；工具链强调带引用的报告、功能规格说明，以及在同一设备上对比原版与重建流程。面向需要可复现、证据链清晰的专有应用行为研究——而非黑盒猜测——的移动逆向工程师、安全研究人员与开发者。
