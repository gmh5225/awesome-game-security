Copy APP is a Python CLI and agent-oriented workflow for analyzing installed iOS and macOS applications and rebuilding selected behavior as independent, runnable apps. It drives real devices over USB to collect packages, UI and accessibility trees, sandbox data, and optional runtime traces, with support for FairPlay-related decryption on compatible jailbroken paths and lighter standard-mode UI capture without SSH or Frida. Static analysis integrates optional Ghidra and Hopper decompilation, ARM64 disassembly, and Frida method tracing, orchestrated through verifiable evidence cases, playbooks, and coding-agent handoff tasks. Swift components support macOS collection and sample rebuild targets, while the toolchain emphasizes cited reports, feature specifications, and same-device comparison of original versus rebuilt flows. It targets mobile reverse engineers, security researchers, and developers who need reproducible, evidence-linked study of proprietary app behavior rather than black-box guessing.
