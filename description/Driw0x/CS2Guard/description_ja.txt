CS2Guard は、クライアントシステムをスキャンするのではなく、ゲームプレイのテレメトリを分析することで Counter-Strike 2 における疑わしいチート行為を検出する実験的な機械学習プロジェクトです。主に Python で記述され、CS2 の demo ファイルを解析して試合、プレイヤー、tick レベルのデータを抽出し、エイムの動き、クロスヘア配置、ターゲット追跡、反応時間、角速度などの行動特徴量を設計します。プロジェクトには、CS2CD などの外部ラベル付きデータセット用アダプターを備えた再現可能なデータセットビルダー、エイム分析用のユニットテストと可視化ツールが含まれます。検出手法は教師なし異常検出と教師あり分類モデルに及び、長期的な目標は同じ行動分析パイプラインをリアルタイムのサーバー側アンチチートシステムとして展開することです。ゲームセキュリティ研究者、アンチチート開発者、観測可能なゲーム内行動からチートを研究・検出したいアナリストを対象としています。
