CS2Guard 是一個實驗性的機器學習專案，透過分析遊戲玩法遙測資料而非掃描用戶端系統，來偵測 Counter-Strike 2 中的可疑作弊行為。該專案主要以 Python 撰寫，解析 CS2 demo 檔案以擷取比賽、玩家與 tick 層級的資料，並建構諸如瞄準移動、準星放置、目標追蹤、反應時間與角速度等行為特徵。專案包含可重現的資料集建構器，支援 CS2CD 等外部標註資料集的適配器，以及用於瞄準分析的單元測試與視覺化工具。偵測方法涵蓋無監督異常偵測與監督式分類模型，長期目標是將相同的行為分析管線部署為即時伺服器端反作弊系統。此專案面向遊戲安全研究人員、反作弊開發者與分析師，供其研究或從可觀察的遊戲內行為中偵測作弊。
