CS2Guard is an experimental machine learning project that detects suspicious cheating behavior in Counter-Strike 2 by analyzing gameplay telemetry instead of scanning client systems. Written primarily in Python, it parses CS2 demo files to extract match, player, and tick-level data, then engineers behavioral features such as aim movement, crosshair placement, target tracking, reaction time, and angular velocity. The project includes a reproducible dataset builder with adapters for external labeled datasets like CS2CD, along with unit tests and visualization tools for aim analysis. Detection approaches span unsupervised anomaly detection and supervised classification models, with the long-term goal of deploying the same behavioral pipeline as a real-time server-side anti-cheat system. It is aimed at game security researchers, anti-cheat developers, and analysts who want to study or detect cheating from observable in-game behavior.
