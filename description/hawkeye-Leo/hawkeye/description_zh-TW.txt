Hawkeye 是一款面向反作弊分析與即時取證研究的 Windows 核心安全研究主控台，在 Windows 10/11 x64 上由主機原生核心驅動程式提供支援。它提供互動式命令工作台，包含 !probe（即時符號與模組檢查）、!etw（基於 ETW 的執行取樣與呼叫堆疊追蹤）、!kernel_region（虛擬位址分類）以及記憶體讀取與反組譯等工具。開源 Community 版採用 GPL-3.0-or-later 授權，Hawkeye Lab 則新增自動化高風險偵測模擬與 !analyze 工作流程，可針對記憶體對映、活躍頁面與核心注入模式產生帶評分的分析報告。本工具面向獲得授權的核心與反作弊研究人員，用於在其管理的環境中調查驅動程式行為、記憶體存取、反擷取機制及相關作弊技術。
