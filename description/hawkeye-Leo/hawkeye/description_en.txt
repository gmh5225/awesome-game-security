Hawkeye is a Windows kernel security research console for anti-cheat analysis and live forensics, backed by a host-native kernel driver on Windows 10/11 x64. It provides an interactive command bench with tools such as !probe for live symbol and module inspection, !etw for ETW-based execution sampling and call-stack tracing, !kernel_region for virtual address classification, and memory read and disassembly utilities. The open-source Community edition is licensed under GPL-3.0-or-later, while Hawkeye Lab adds automated high-risk detection simulations and an !analyze workflow that produces scored analysis reports across memory mapping, active pages, and kernel injection patterns. It is intended for authorized kernel and anti-cheat researchers investigating driver behavior, memory access, anti-capture mechanisms, and related cheat techniques on systems they administer.
