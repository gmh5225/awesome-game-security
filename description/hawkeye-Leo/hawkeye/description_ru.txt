Hawkeye — это консоль для исследования безопасности ядра Windows, предназначенная для анализа античитов и оперативной форензики, с поддержкой нативного драйвера ядра на Windows 10/11 x64. Она предоставляет интерактивную командную панель с инструментами: !probe для проверки символов и модулей в реальном времени, !etw для выборки выполнения и трассировки стека вызовов на основе ETW, !kernel_region для классификации виртуальных адресов, а также утилиты чтения памяти и дизасsemblирования. Открытая Community-редакция распространяется под лицензией GPL-3.0-or-later, а Hawkeye Lab добавляет автоматизированные симуляции обнаружения высокого риска и рабочий процесс !analyze, формирующий оценённые отчёты по сопоставлению памяти, активным страницам и шаблонам инъекций в ядро. Предназначена для авторизованных исследователей ядра и античитов, изучающих поведение драйверов, доступ к памяти, механизмы anti-capture и связанные техники читов на системах, которыми они управляют.
