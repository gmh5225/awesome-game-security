Hawkeye — это консоль для исследования безопасности ядра Windows, предназначенная для анализа античитов и оперативной криминалистики, работающая с нативным драйвером ядра хоста в Windows 10/11 x64. Она предоставляет интерактивную командную среду с инструментами, такими как !probe для проверки символов и модулей в реальном времени, !etw для выборки выполнения и трассировки стека вызовов на основе ETW, !kernel_region для классификации виртуальных адресов, а также утилитами чтения памяти и дизассемблирования. Открытая Community-редакция распространяется по лицензии GPL-3.0-or-later, а Hawkeye Lab добавляет автоматизированные симуляции обнаружения высокого риска и рабочий процесс !analyze, формирующий оценённые отчёты анализа по сопоставлению памяти, активным страницам и шаблонам инъекций в ядро. Предназначен для авторизованных исследователей ядра и античитов, изучающих поведение драйверов, доступ к памяти, механизмы anti-capture и связанные техники читов на системах, которыми они управляют.
