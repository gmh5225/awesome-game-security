aaoracled は、脱獄済みの iOS または iPadOS デバイスを App Attest オラクルに変換し、任意の App ID に対して鍵の生成とアテステーションの作成を行える研究用ツールです。単一の Debian パッケージとして提供され、OracledDCPatch（Theos 製 tweak で、devicecheckd をフックして呼び出し元が指定した bundle ID を偽装する）と aaoracled（DCAppAttestService を駆動して鍵の生成、アテステーション、署名、削除を行うローカル REST デーモン）を含みます。主に Objective-C で記述され、Ghidra と Frida によるオフセット探索を支援する機能を備えており、侵害されたハードウェア上では App Attest の App ID バインディングが Secure Enclave ではなくユーザースペースで強制されていることを示しています。本プロジェクトは、App Attest への過度な依存がある不正防止・改ざん防止 SDK を評価する、許可を得たセキュリティ研究者を対象としており、示された各脆弱性に対するサーバー側の緩和策のガイダンスも提供します。
