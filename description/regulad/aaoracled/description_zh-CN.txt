aaoracled 是一款研究工具，可将已越狱的 iOS 或 iPadOS 设备转变为 App Attest 预言机，能够为任意 App ID 生成密钥并产出证明。它以一个 Debian 软件包的形式发布，包含 OracledDCPatch（一个 Theos 插件，用于 hook devicecheckd 以伪造调用者指定的 bundle 身份）以及 aaoracled（一个本地 REST 守护进程，驱动 DCAppAttestService 进行密钥生成、证明、签名和删除）。该工具主要使用 Objective-C 编写，并通过 Ghidra 和 Frida 辅助进行偏移发现，展示了在已攻陷的硬件上，App Attest 的 App ID 绑定是在用户空间而非 Secure Enclave 中强制执行的。该工作面向获得授权的安全研究人员，用于评估过度依赖 App Attest 的反欺诈和防篡改 SDK，并为每个展示的漏洞提供服务器端缓解指导。
