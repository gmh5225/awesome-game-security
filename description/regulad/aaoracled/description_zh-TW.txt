aaoracled 是一款研究工具，可將已越獄的 iOS 或 iPadOS 裝置轉變為 App Attest 預言機，能夠為任意 App ID 產生金鑰並產出證明。它以一個 Debian 套件的形式發行，包含 OracledDCPatch（一個 Theos 外掛，用於 hook devicecheckd 以偽造呼叫者指定的 bundle 身分）以及 aaoracled（一個本機 REST 守護程式，驅動 DCAppAttestService 進行金鑰產生、證明、簽署和刪除）。該工具主要使用 Objective-C 撰寫，並透過 Ghidra 和 Frida 輔助進行偏移探索，展示了在已遭攻陷的硬體上，App Attest 的 App ID 綁定是在使用者空間而非 Secure Enclave 中強制執行的。此工作面向獲得授權的安全研究人員，用於評估過度依賴 App Attest 的反詐欺和防篡改 SDK，並為每個展示的漏洞提供伺服器端緩解指引。
