Cryo Interactive の 1997 年製アドベンチャーゲーム Dreams to Reality 向けのリバースエンジニアリング・ツールキットおよび研究プロジェクト。オリジナルのディスクデータを実行し、復元されたゲームロジックとモダンな GPU レンダリングで動作する、ポータブルな C++17 エンジン OpenDreams の構築を目指している。本リポジトリは、ロスレスなアセット抽出とフォーマットデコード（独自のシーン、メッシュ、オーディオ、HNM 動画コンテナ）用の Python CLI、Watcom 製 DOS および Windows バイナリ向けの Ghidra 自動化スクリプト、SDL3 と sokol_gfx で構築中の OpenDreams ランタイムを統合している。Cryo 社内エンジン、CryoLib エクスポート、LZ 圧縮、小売版実行ファイルで検証済みの固定ステップシミュレーション動作を文書化している。DOSBox 外でレガシー商用ゲームエンジンを分析、デコード、最終的に再実装する必要があるゲーム保存者とリバースエンジニア向けのプロジェクトである。
