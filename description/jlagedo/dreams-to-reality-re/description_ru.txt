Набор инструментов для реверс-инжиниринга и исследовательский проект для приключенческой игры Dreams to Reality (1997) от Cryo Interactive, направленный на создание OpenDreams — переносимого движка на C++17, запускающего оригинальные данные с диска с восстановленной игровой логикой и современным GPU-рендерингом. Репозиторий объединяет Python CLI для без потерь извлечения ассетов и декодирования форматов (проприетарные контейнеры сцен, мешей, аудио и HNM-видео), скрипты автоматизации Ghidra для DOS- и Windows-бинарников, собранных Watcom, и формирующуюся среду выполнения OpenDreams на SDL3 и sokol_gfx. Документируются собственный движок Cryo, экспорты CryoLib, LZ-сжатие и поведение симуляции с фиксированным шагом, проверенное на розничных исполняемых файлах. Проект предназначен для специалистов по сохранению игр и реверс-инженеров, которым необходимо анализировать, декодировать и в конечном счёте реализовать заново унаследованный коммерческий игровой движок вне DOSBox.
