Kit de herramientas de ingeniería inversa y proyecto de investigación para el juego de aventuras Dreams to Reality (1997) de Cryo Interactive, orientado a construir OpenDreams, un motor portable en C++17 que ejecuta los datos originales del disco con la lógica de juego recuperada y renderizado GPU moderno. El repositorio combina una CLI de Python para extracción de assets sin pérdida y decodificación de formatos (contenedores propietarios de escenas, mallas, audio y vídeo HNM), scripts de automatización de Ghidra para binarios DOS y Windows compilados con Watcom, y un runtime emergente de OpenDreams construido con SDL3 y sokol_gfx. Documenta el motor interno de Cryo, las exportaciones de CryoLib, la compresión LZ y el comportamiento de simulación de paso fijo verificado contra ejecutables comerciales. El proyecto está dirigido a preservacionistas de videojuegos e ingenieros de reversa que necesitan analizar, decodificar y eventualmente reimplementar un motor de juego comercial heredado fuera de DOSBox.
