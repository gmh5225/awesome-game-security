针对 Cryo Interactive 1997 年冒险游戏 Dreams to Reality 的逆向工程工具包与研究项目，旨在构建 OpenDreams——一个可移植的 C++17 引擎，能够运行原版光盘数据，还原游戏逻辑并采用现代 GPU 渲染。该仓库集成了用于无损资源提取与格式解码的 Python CLI（涵盖专有的场景、网格、音频及 HNM 视频容器）、针对 Watcom 编译的 DOS 与 Windows 二进制的 Ghidra 自动化脚本，以及基于 SDL3 与 sokol_gfx 构建的 OpenDreams 运行时。项目文档化了 Cryo 自研引擎、CryoLib 导出、LZ 压缩以及经零售版可执行文件验证的固定步长模拟行为。本项目面向需要在 DOSBox 之外分析、解码并最终重新实现遗留商业游戏引擎的游戏保护者及逆向工程师。
