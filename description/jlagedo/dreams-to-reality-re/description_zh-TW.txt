針對 Cryo Interactive 1997 年冒險遊戲 Dreams to Reality 的逆向工程工具包與研究專案，旨在建構 OpenDreams——一個可移植的 C++17 引擎，能夠執行原版光碟資料，還原遊戲邏輯並採用現代 GPU 渲染。此儲存庫整合了用於無損資源提取與格式解碼的 Python CLI（涵蓋專有的場景、網格、音訊及 HNM 影片容器）、針對 Watcom 編譯的 DOS 與 Windows 二進位的 Ghidra 自動化腳本，以及基於 SDL3 與 sokol_gfx 建構的 OpenDreams 執行階段。專案記錄了 Cryo 自研引擎、CryoLib 匯出、LZ 壓縮以及經零售版可執行檔驗證的固定步長模擬行為。本專案面向需要在 DOSBox 之外分析、解碼並最終重新實作舊版商業遊戲引擎的遊戲保存者及逆向工程師。
