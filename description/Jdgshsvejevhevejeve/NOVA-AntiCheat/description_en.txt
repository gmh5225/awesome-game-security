NOVA AntiCheat is a lightweight server-side anti-cheat plugin for Minecraft Paper servers that detects common client-side cheats without requiring players to install anything. Written in Java 21 and built with Gradle against Paper 1.21, it monitors movement, combat, and block interactions through Bukkit event handlers. Detection modules cover speed, flight, reach, auto-clicker, no-fall, fast break/place, and suspicious rotation, using buffered thresholds and a violation-level system that decays over time. When thresholds are exceeded, configurable actions warn the player, teleport them to a last-known safe position, or kick them from the server. It is aimed at Minecraft server administrators who need a starter anti-cheat framework with admin commands for alerts, per-player violation info, and config reloads.
