NOVA AntiCheat — это лёгкий серверный античит-плагин для серверов Minecraft Paper, который обнаруживает распространённые клиентские читы без необходимости устанавливать что-либо игрокам. Написан на Java 21 и собран с помощью Gradle для Paper 1.21; отслеживает перемещение, бой и взаимодействие с блоками через обработчики событий Bukkit. Модули обнаружения охватывают скорость, полёт, reach, авто-кликер, no-fall, быстрое разрушение/установку блоков и подозрительное вращение, используя буферизованные пороги и систему уровней нарушений, которая со временем снижается. При превышении порогов настраиваемые действия предупреждают игрока, телепортируют его на последнюю известную безопасную позицию или исключают с сервера. Предназначен для администраторов серверов Minecraft, которым нужен начальный античит-фреймворк с админ-командами для оповещений, информации о нарушениях по игрокам и перезагрузки конфигурации.
