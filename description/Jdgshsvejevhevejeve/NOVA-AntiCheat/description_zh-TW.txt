NOVA AntiCheat 是一款適用於 Minecraft Paper 伺服器的輕量級伺服器端反作弊外掛，可在玩家無需安裝任何客戶端的情況下偵測常見的客戶端作弊行為。它以 Java 21 撰寫，並透過 Gradle 針對 Paper 1.21 建置，透過 Bukkit 事件處理器監控移動、戰鬥與方塊互動。偵測模組涵蓋速度、飛行、攻擊距離、自動點擊、無摔落傷害、快速破壞/放置以及可疑旋轉等，採用緩衝閾值及會隨時間衰減的違規等級系統。超過閾值時可執行可設定的動作：警告玩家、將其傳送回最後已知安全位置或踢出伺服器。本外掛面向需要入門式反作弊框架的 Minecraft 伺服器管理員，提供警報通知、玩家違規資訊與設定重載等管理指令。
