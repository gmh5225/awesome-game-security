NOVA AntiCheat est un plugin anti-triche côté serveur léger pour les serveurs Minecraft Paper, qui détecte les triches client courantes sans exiger que les joueurs installent quoi que ce soit. Écrit en Java 21 et compilé avec Gradle pour Paper 1.21, il surveille les déplacements, les combats et les interactions avec les blocs via des gestionnaires d'événements Bukkit. Les modules de détection couvrent la vitesse, le vol, la portée, l'auto-clic, l'absence de chute, la destruction/placement rapide et les rotations suspectes, en utilisant des seuils tamponnés et un système de niveaux de violation qui diminue avec le temps. Lorsque les seuils sont dépassés, des actions configurables avertissent le joueur, le téléportent vers une dernière position sûre connue ou l'expulsent du serveur. Il s'adresse aux administrateurs de serveurs Minecraft qui ont besoin d'un framework anti-triche de base avec des commandes d'administration pour les alertes, les informations de violation par joueur et le rechargement de la configuration.
