NOVA AntiCheat è un plugin anti-cheat lato server leggero per server Minecraft Paper che rileva i cheat client comuni senza richiedere ai giocatori di installare nulla. Scritto in Java 21 e compilato con Gradle per Paper 1.21, monitora movimento, combattimento e interazioni con i blocchi tramite gestori di eventi Bukkit. I moduli di rilevamento coprono velocità, volo, reach, auto-clicker, no-fall, rottura/piazzamento rapido e rotazione sospetta, usando soglie con buffer e un sistema di livelli di violazione che diminuisce nel tempo. Quando le soglie vengono superate, azioni configurabili avvertono il giocatore, lo teletrasportano in un'ultima posizione sicura nota o lo espellono dal server. È pensato per gli amministratori di server Minecraft che necessitano di un framework anti-cheat di base con comandi admin per avvisi, informazioni sulle violazioni per giocatore e ricarica della configurazione.
