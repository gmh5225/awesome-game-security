本リポジトリは、クリーンな端末から取得した genuine な attestation 証明書チェーンを root 化された解析用端末へ中継することで、Android ハードウェア Key Attestation をバイパスする手法を示す、エンドツーエンドの概念実証です。デモ用クライアントと attestation oracle サーバーの 2 つの Kotlin Android アプリ、nonce を発行し Google ルート CA と失効リストに照らして attestation チェーンを検証する Python バックエンド、およびクライアントの Keystore attestation 呼び出しを hook してクリーン端末からチェーンを取得する TypeScript 製 Frida インストルメンテーションが含まれます。このバイパスは暗号を偽造するのではなく、バックエンドの challenge に紐づいた正当なハードウェアバックのチェーンで置き換えることで、改ざんされた端末でも verified-boot やハードウェアバックの検査を通過させます。Android ハードウェア attestation に依存する改ざん防止・チート対策を研究するモバイルセキュリティ研究者やアナリスト向けの教育資料です。
