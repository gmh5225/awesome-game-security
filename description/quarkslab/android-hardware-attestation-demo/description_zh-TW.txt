本儲存庫是一個端到端概念驗證，示範如何將乾淨裝置上的 genuine attestation 憑證鏈中繼到已 root 的分析手機，以繞過 Android 硬體 Key Attestation。專案包含兩個 Kotlin Android 應用程式（示範用戶端與 attestation oracle 伺服器）、一個用於簽發 nonce 並依 Google 根 CA 與撤銷清單驗證 attestation 憑證鏈的 Python 後端，以及以 TypeScript 撰寫的 Frida 插樁，用來 hook 用戶端 Keystore attestation 呼叫，從乾淨裝置取得憑證鏈。此繞過方式並非偽造密碼學材料，而是以與後端 challenge 綁定的合法硬體背書憑證鏈替換，使已遭竄改的裝置仍可通過 verified-boot 與硬體背書檢查。本專案面向研究依賴 Android 硬體 attestation 的防篡改與反作弊機制的行動安全研究人員與分析人員，具教育用途。
