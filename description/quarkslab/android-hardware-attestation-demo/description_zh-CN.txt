本仓库是一个端到端概念验证，演示如何通过将真实设备上的真实 attestation 证书链中继到已 root 的分析手机，来绕过 Android 硬件 Key Attestation。项目包含两个 Kotlin Android 应用（演示客户端与 attestation oracle 服务端）、一个用于签发 nonce 并依据 Google 根 CA 与吊销列表验证 attestation 证书链的 Python 后端，以及用 TypeScript 编写的 Frida 插桩，用于 hook 客户端 Keystore attestation 调用，从真实设备获取证书链。该绕过方式并不伪造密码学材料，而是用与后端 challenge 绑定的合法硬件背书证书链进行替换，使已遭篡改的设备仍能通过 verified-boot 与硬件背书检查。本项目面向研究依赖 Android 硬件 attestation 的防篡改与反作弊机制的移动安全研究人员与分析人员，具有教育用途。
