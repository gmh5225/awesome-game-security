This project is a lightweight C++ starter template for an external Roblox tool that attaches to RobloxPlayerBeta.exe and reads game state from outside the client process. It locates the player via Toolhelp snapshots, resolves the module base, and performs cross-process memory access through direct NtReadVirtualMemory and NtWriteVirtualMemory syscalls implemented in assembly. A transparent fullscreen overlay uses DirectComposition with a D3D11 flip-sequential swapchain, ImGui, and Win32 layered window flags for low-latency on-screen UI and visuals. The codebase includes Roblox-oriented framework pieces such as offset tables, DataModel and Instance wrappers, entity handling, a visual engine hook-up, and a sample visuals feature module. It targets Windows developers studying game security, reverse engineering Roblox internals, and how external cheat-style tooling interacts with anti-cheat and client protections.
