Wardogs anti-cheat は、Nightwatch ゲームサーバーパネルから転送されるキルおよびプレイヤーイベントを取り込み、チート検知とモデレーション処理をリアルタイムで実行するサーバーサイドの反チートスタックです。主に TypeScript で実装され、イベントフック、スケジュール済み cron、管理用 Web ツール、陣営切り替えガードという四つの連携する Cloudflare Workers と、共有の Cloudflare D1 SQLite データベースで構成されています。検知の中心は karma スコアリングモデルで、極端な K/D、ヘッドショット率、遠距離キル、頻繁な名前変更などの疑わしい統計に対する設定可能なルールに加え、VAC やゲーム BAN 履歴を含む Steam アカウントのリスクチェックを任意で行えます。Nightwatch と連携して BAN、キック、アナウンス、ウィスパー、チーム変更を扱い、オートバランス、クラン友達チェック、ダッシュボード、マッチ経済リーダーボードなどの運用向け機能も備えています。常時稼働の従来型バックエンドを立てずに、自動化されたチートヒューリスティクスと Steam 連動の執行を求めるコミュニティまたはプライベートゲームサーバー運営者向けです。
