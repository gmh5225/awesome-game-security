Wardogs anti-cheat 是一套伺服器端反作弊堆疊，接收從 Nightwatch 遊戲伺服器面板轉發的擊殺與玩家事件，並即時執行作弊偵測與管理動作。其主要以 TypeScript 實作，由四個協同運作的 Cloudflare Workers（事件鉤子、排程 cron、管理 Web 工具與陣營切換守衛）組成，並共用 Cloudflare D1 SQLite 資料庫。偵測核心為 karma 評分模型，可針對極端 K/D、爆頭率、遠距離擊殺、頻繁更名等可疑統計設定規則，並可選擇納入 Steam 帳號風險檢查（含 VAC 與遊戲封鎖紀錄）。系統與 Nightwatch 整合，支援封鎖、踢出、公告、私訊與換隊，並提供自動平衡、戰隊好友驗證、儀表板與對局經濟排行榜等營運功能。面向希望在不運行傳統常駐後端的前提下，實現自動化作弊啟發式偵測與 Steam 連結執法的社群或私服營運者。
