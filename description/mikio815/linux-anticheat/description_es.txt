Este es un sistema anti-trampas a nivel de kernel en desarrollo, diseñado para consolas de juegos Linux como Steam Deck. Utiliza una arquitectura de cuatro capas: un demonio en espacio de usuario escrito en Rust que lanza juegos y procesa eventos de seguridad, programas LSM eBPF para la detección principal que incluye bloqueo de ptrace, aplicación de memoria W^X y monitorización de bpf(), un módulo del kernel en C ligero que protege la integridad de los programas eBPF desde fuera del sandbox, y una capa de hipervisor basada en BitVisor, planificada, para proteger contra escritura las regiones estáticas del kernel mediante Intel VMX/EPT. El proyecto está construido principalmente en Rust y C con el framework Aya eBPF y requiere Linux 5.17+ con información de depuración BTF y BPF LSM habilitado. Está orientado a entornos de consola restringidos donde Secure Boot, el bloqueo del kernel y la attestación TPM hacen práctica la protección profunda del kernel para la investigación y el desarrollo de seguridad en juegos.
