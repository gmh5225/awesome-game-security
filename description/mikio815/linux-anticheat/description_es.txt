Sistema anti-trampas a nivel de kernel en desarrollo, diseñado para consolas de juegos Linux como Steam Deck. Utiliza una arquitectura de cuatro capas: un demonio en espacio de usuario en Rust que lanza juegos y consume eventos de seguridad, programas LSM eBPF para detección central que incluye bloqueo de ptrace, aplicación de memoria W^X y monitorización de bpf(), un módulo del kernel en C delgado que protege la integridad de los programas eBPF desde fuera del sandbox, y una capa de hipervisor basada en BitVisor planificada para proteger por escritura regiones estáticas del kernel mediante Intel VMX/EPT. El proyecto está construido principalmente en Rust y C con el framework Aya eBPF y requiere Linux 5.17+ con información de depuración BTF y BPF LSM habilitado. Está orientado a entornos de consola restringidos donde Secure Boot, el lockdown del kernel y la attestación TPM hacen práctica la protección profunda del kernel para investigación y desarrollo de seguridad en juegos.
