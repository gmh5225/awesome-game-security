Steam Deck などの Linux ゲーミングコンソール向けに設計された、開発中のカーネルレベルアンチチートシステムです。4 層アーキテクチャを採用しています。Rust のユーザースペースデーモンがゲームを起動しセキュリティイベントを処理し、LSM eBPF プログラムが ptrace ブロック、W^X メモリ強制、bpf() 監視などのコア検知を担当します。薄い C カーネルモジュールがサンドボックス外から eBPF プログラムの整合性を保護し、計画中の BitVisor ベースのハイパーバイザー層が Intel VMX/EPT 経由で静的カーネル領域への書き込みを保護します。プロジェクトは主に Rust と C で構築され、Aya eBPF フレームワークを使用し、BTF デバッグ情報と BPF LSM が有効な Linux 5.17+ が必要です。Secure Boot、カーネル lockdown、TPM アテステーションが有効なロックダウンコンソール環境を対象とし、ゲームセキュリティの研究開発において深いカーネル保護を実用的に実現します。
