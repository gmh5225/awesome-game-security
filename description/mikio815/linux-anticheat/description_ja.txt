Steam Deck などの Linux ゲーム機向けに設計された、開発中のカーネルレベルアンチチートシステムです。4 層アーキテクチャを採用しています。Rust 製のユーザースペースデーモンがゲームを起動しセキュリティイベントを処理し、LSM eBPF プログラムが ptrace ブロック、W^X メモリ強制、bpf() 監視などのコア検知を担当します。薄い C カーネルモジュールがサンドボックス外から eBPF プログラムの整合性を保護し、計画中の BitVisor ベースのハイパーバイザー層が Intel VMX/EPT により静的カーネル領域への書き込みを保護します。プロジェクトは主に Rust と C で構築され、Aya eBPF フレームワークを使用し、BTF デバッグ情報と BPF LSM が有効な Linux 5.17 以降を必要とします。Secure Boot、カーネルロックダウン、TPM アテステーションが有効なロックダウン環境を対象とし、ゲームセキュリティの研究開発において深いカーネル保護を実用的に実現します。
