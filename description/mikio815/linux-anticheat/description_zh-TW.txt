這是一套面向 Steam Deck 等 Linux 遊戲主機平台的內核級反作弊系統，目前仍在開發中。它採用四層架構：Rust 使用者空間守護程序負責啟動遊戲並消費安全事件；LSM eBPF 程式負責核心偵測，包括阻止 ptrace、強制執行 W^X 記憶體策略以及監控 bpf()；一個精簡的 C 核心模組在沙箱外保護 eBPF 程式完整性；以及計畫中的基於 BitVisor 的虛擬化層，透過 Intel VMX/EPT 對靜態核心區域實施寫保護。該專案主要使用 Rust 和 C 開發，基於 Aya eBPF 框架，需要 Linux 5.17+ 並啟用 BTF 除錯資訊與 BPF LSM。它面向啟用了 Secure Boot、核心 lockdown 和 TPM 證明的高鎖定主機環境，使深度核心防護在遊戲安全研究與開發中具備實際可行性。
