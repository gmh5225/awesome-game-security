這是一個仍在開發中的核心層級反作弊系統，專為 Steam Deck 等 Linux 遊戲主機而設計。它採用四層架構：以 Rust 撰寫的使用者空間守護程式負責啟動遊戲並處理安全事件；LSM eBPF 程式負責核心偵測，包括阻擋 ptrace、強制執行 W^X 記憶體策略以及監控 bpf() 呼叫；一個精簡的 C 語言核心模組在沙箱外保護 eBPF 程式的完整性；並計畫加入基於 BitVisor 的虛擬機器監控層，透過 Intel VMX/EPT 對靜態核心區域進行寫入保護。專案主要以 Rust 和 C 開發，使用 Aya eBPF 框架，需要 Linux 5.17 以上版本，並啟用 BTF 除錯資訊與 BPF LSM。它鎖定 Secure Boot、核心鎖定與 TPM 認證等機制下的封閉主機環境，使深度核心保護在遊戲安全研究與開發中具備實際可行性。
