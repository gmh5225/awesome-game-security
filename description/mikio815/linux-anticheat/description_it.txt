Sistema anti-cheat a livello kernel in fase di sviluppo, progettato per console di gioco Linux come Steam Deck. Utilizza un'architettura a quattro livelli: un daemon userspace in Rust che avvia i giochi e consuma eventi di sicurezza, programmi LSM eBPF per il rilevamento principale inclusi blocco di ptrace, enforcement della memoria W^X e monitoraggio di bpf(), un sottile modulo kernel in C che protegge l'integrità dei programmi eBPF dall'esterno della sandbox, e un livello hypervisor basato su BitVisor pianificato per proteggere in scrittura le regioni statiche del kernel tramite Intel VMX/EPT. Il progetto è costruito principalmente in Rust e C con il framework Aya eBPF e richiede Linux 5.17+ con informazioni di debug BTF e BPF LSM abilitato. È rivolto ad ambienti console bloccati dove Secure Boot, kernel lockdown e attestazione TPM rendono pratica la protezione profonda del kernel per ricerca e sviluppo sulla sicurezza dei giochi.
