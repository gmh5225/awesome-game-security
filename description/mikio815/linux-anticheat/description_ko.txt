Steam Deck와 같은 Linux 게이밍 콘솔용으로 설계된, 개발 중인 커널 수준 안티치트 시스템입니다. 4계층 아키텍처를 사용합니다. Rust 사용자 공간 데몬이 게임을 실행하고 보안 이벤트를 처리하며, LSM eBPF 프로그램이 ptrace 차단, W^X 메모리 강제, bpf() 모니터링 등 핵심 탐지를 담당합니다. 얇은 C 커널 모듈이 샌드박스 외부에서 eBPF 프로그램 무결성을 보호하고, 계획 중인 BitVisor 기반 하이퍼바이저 계층이 Intel VMX/EPT를 통해 정적 커널 영역에 쓰기 보호를 적용합니다. 프로젝트는 주로 Rust와 C로 구축되었으며 Aya eBPF 프레임워크를 사용하며, BTF 디버그 정보와 BPF LSM이 활성화된 Linux 5.17+가 필요합니다. Secure Boot, 커널 lockdown, TPM 증명이 적용된 잠금 콘솔 환경을 대상으로 하며, 게임 보안 연구 및 개발에서 심층 커널 보호를 실용적으로 구현합니다.
