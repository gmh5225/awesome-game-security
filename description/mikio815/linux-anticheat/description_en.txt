This is a work-in-progress kernel-level anti-cheat system designed for Linux gaming consoles such as the Steam Deck. It uses a four-layer architecture: a Rust userspace daemon that launches games and consumes security events, LSM eBPF programs for core detection including ptrace blocking, W^X memory enforcement, and bpf() monitoring, a thin C kernel module that guards eBPF program integrity from outside the sandbox, and a planned BitVisor-based hypervisor layer to write-protect static kernel regions via Intel VMX/EPT. The project is built primarily in Rust and C with the Aya eBPF framework and requires Linux 5.17+ with BTF debug info and BPF LSM enabled. It targets locked-down console environments where Secure Boot, kernel lockdown, and TPM attestation make deep kernel protection practical for game security research and development.
