这是一个仍在开发中的内核级反作弊系统，面向 Steam Deck 等 Linux 游戏主机。它采用四层架构：用 Rust 编写的用户空间守护进程负责启动游戏并处理安全事件；LSM eBPF 程序负责核心检测，包括阻止 ptrace、强制执行 W^X 内存策略以及监控 bpf() 调用；一个精简的 C 语言内核模块在沙箱外保护 eBPF 程序的完整性；还计划加入基于 BitVisor 的虚拟机监控层，通过 Intel VMX/EPT 对静态内核区域进行写保护。项目主要使用 Rust 和 C 开发，基于 Aya eBPF 框架，需要 Linux 5.17 及以上版本，并启用 BTF 调试信息与 BPF LSM。它面向 Secure Boot、内核锁定和 TPM 认证等机制下的封闭主机环境，使深度内核保护在游戏安全研究与开发中具备实际可行性。
