这是一套面向 Steam Deck 等 Linux 游戏主机平台的内核级反作弊系统，目前仍在开发中。它采用四层架构：Rust 用户态守护进程负责启动游戏并消费安全事件；LSM eBPF 程序负责核心检测，包括阻止 ptrace、强制执行 W^X 内存策略以及监控 bpf()；一个精简的 C 内核模块在沙箱外保护 eBPF 程序完整性；以及计划中的基于 BitVisor 的虚拟化层，通过 Intel VMX/EPT 对静态内核区域实施写保护。该项目主要使用 Rust 和 C 开发，基于 Aya eBPF 框架，需要 Linux 5.17+ 并启用 BTF 调试信息与 BPF LSM。它面向启用了 Secure Boot、内核 lockdown 和 TPM 证明的锁定型主机环境，使深度内核防护在游戏安全研究与开发中具备实际可行性。
