Разрабатываемая система античита на уровне ядра, предназначенная для игровых консолей на Linux, таких как Steam Deck. Использует четырёхуровневую архитектуру: пользовательский демон на Rust, запускающий игры и обрабатывающий события безопасности, программы LSM eBPF для основного обнаружения, включая блокировку ptrace, принудительное W^X для памяти и мониторинг bpf(), тонкий модуль ядра на C, защищающий целостность программ eBPF извне песочницы, и планируемый слой гипервизора на базе BitVisor для защиты от записи статических областей ядра через Intel VMX/EPT. Проект в основном написан на Rust и C с использованием фреймворка Aya eBPF и требует Linux 5.17+ с отладочной информацией BTF и включённым BPF LSM. Ориентирован на изолированные консольные среды, где Secure Boot, блокировка ядра и аттестация TPM делают глубокую защиту ядра практичной для исследований и разработки в области безопасности игр.
