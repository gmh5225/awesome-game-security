fpsdet は、専用ゲームサーバーから JSON 形式の戦闘・移動ログを取り込み、ゲームルール、人間の行動ベースライン、クライアントの可視性制限に基づいて各プレイヤーをスコアリングし、自動 BAN ではなく手動レビュー用のケースファイルを生成する、FPS 向けサーバーサイド反チート証拠エンジンです。ランタイム依存なしの Python 3.11+ で記述されており、取り込み、ベースライン構築、スコアリング、ダッシュボード生成用の CLI パイプラインに加え、JSON スキーマ、ゲームプロファイル、Unity・Unreal・Godot 向けのサンプルエミッターを同梱しています。検査項目は、移動速度・連射速度・反動操作などの装備違反、ランク付けされた人間コホートに対する統計的外れ値、隠しトラッキングやワイヤー対ピクチャエイムなどの情報理論的シグナル、humanizer 署名の共有などのクロスアカウントパターンをカバーします。合成デモ人口、オフライン運用レビューボード、オプションの AI トリアージブリーフ、Grafana・Kibana・Splunk 向けマッピングも含まれます。インディーおよび小規模スタジオ、コミュニティサーバー運営者、誤検知対策を重視したサーバーログベースのチート検出を必要とするゲームセキュリティワークフロー構築者を対象としています。
