fpsdet 是一款面向第一人称射击游戏的服务端反作弊证据引擎，它从专用游戏服务器摄取 JSON 格式的战斗与移动日志，依据游戏规则、人类行为基线和客户端可见性限制为每位玩家打分，并生成供人工审核的案件档案，而非自动封禁。该项目采用纯 Python 3.11+ 编写，无运行时依赖，提供用于摄取、基线构建、评分和仪表盘生成的 CLI 流水线，以及 JSON 模式、游戏配置文件，以及面向 Unity、Unreal 和 Godot 的示例发射器。其检测项涵盖移速、射速和后坐力操控等装备违规，相对排名人类群体的统计异常，隐藏追踪与线框对比画面瞄准等信息论信号，以及共享 humanizer 签名等跨账号模式。项目还包含合成演示人群、离线运营审核面板、可选的 AI 分诊摘要，以及 Grafana、Kibana 和 Splunk 的映射配置。它面向独立和小型工作室、社区服务器运营者，以及任何需要基于服务器日志进行作弊检测并具备强误报防护机制的游戏安全工作流构建者。
