fpsdet is a server-side anti-cheat evidence engine for first-person shooters that ingests JSON combat and movement logs from a dedicated game server, scores each player against game rules, human baselines, and client visibility limits, and produces case files for manual review rather than automatic bans. Written in plain Python 3.11+ with no runtime dependencies, it ships a CLI pipeline for ingest, baseline building, scoring, and dashboard generation, plus JSON schemas, game profiles, and example emitters for Unity, Unreal, and Godot. Its checks cover gear violations such as speed, fire rate, and recoil manipulation, statistical outliers against ranked human cohorts, information-theoretic signals like hidden tracking and wire-versus-picture aim, and cross-account patterns such as shared humanizer signatures. The project includes synthetic demo populations, an offline operations review board, optional AI triage briefs, and mappings for Grafana, Kibana, and Splunk. It targets indie and small studios, community server operators, and anyone building game security workflows who needs server-log-based cheat detection with strong false-positive safeguards.
