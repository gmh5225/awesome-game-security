fpsdet 是一款面向第一人稱射擊遊戲的伺服器端反作弊證據引擎，它從專用遊戲伺服器擷取 JSON 格式的戰鬥與移動日誌，依據遊戲規則、人類行為基線和用戶端可見性限制為每位玩家評分，並產生供人工審核的案件檔案，而非自動封禁。該專案採用純 Python 3.11+ 編寫，無執行時期依賴，提供用於擷取、基線建構、評分和儀表板產生的 CLI 管線，以及 JSON 結構描述、遊戲設定檔，以及面向 Unity、Unreal 和 Godot 的範例發射器。其檢測項目涵蓋移速、射速和後座力操控等裝備違規，相對排名人類群體的統計異常，隱藏追蹤與線框對比畫面瞄準等資訊論訊號，以及共享 humanizer 簽名等跨帳號模式。專案還包含合成示範人群、離線營運審核面板、可選的 AI 分診摘要，以及 Grafana、Kibana 和 Splunk 的對應設定。它面向獨立和小型工作室、社群伺服器營運者，以及任何需要以伺服器日誌進行作弊偵測並具備強誤報防護機制的遊戲安全工作流建構者。
