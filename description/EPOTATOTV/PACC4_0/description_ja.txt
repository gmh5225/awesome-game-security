PACC（Professional Anti-Cheat Client）は、Minecraft Bedrock Edition および Java Edition 向けのプレイヤー側アンチチートプラットフォームで、デバイス上の検知と独立した PTV 制御・管理バックエンドを組み合わせています。メモリ改ざん、実行中のプロセスとモジュール、入力デバイスや USB/HID デバイスなどのローカル信号を検査し、検出結果を記録して全画面の赤画面警告を発し、ゲームサーバーの BAN システムと統合することなく、リモート管理による調査と証拠収集をサポートします。スタックは Java と Spring Boot サービス、React と TypeScript の管理フロントエンド、Python による AI スコアリング、暗号署名と暗号化永続化を備えた Rust イベントパイプライン、Windows、Linux、Android、iOS、HarmonyOS 向けのネイティブプローブおよびカーネルまたはエージェントモジュールで構成されています。Minecraft コミュニティや運営者が、クライアント側のチート抑止、行動分析、フォレンジック監査を行いつつ、管理インフラをゲームサーバーから分離したい場合を対象としています。
