PACC (Professional Anti-Cheat Client) is a player-side anti-cheat platform for Minecraft Bedrock and Java editions that combines on-device detection with a separate PTV control and administration backend. It inspects local signals such as memory tampering, running processes and modules, and input or USB/HID devices, then logs findings, triggers full-screen red-screen warnings, and supports remote admin inspection and evidence collection without integrating game-server ban systems. The stack spans Java and Spring Boot services, a React and TypeScript admin frontend, Python AI scoring, a Rust event pipeline with cryptographic signing and encrypted persistence, and native probes plus kernel or agent modules for Windows, Linux, Android, iOS, and HarmonyOS. It is aimed at Minecraft communities and operators who want client-side cheat deterrence, behavioral analysis, and forensic auditing while keeping management infrastructure isolated from game servers.
