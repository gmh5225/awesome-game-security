PACC（Professional Anti-Cheat Client，專業反作弊用戶端）是一款面向 Minecraft 基岩版與 Java 版的玩家端反作弊平台，將裝置端偵測與獨立的 PTV 控制與管理後端相結合。它會檢查記憶體竄改、執行中的程序與模組，以及輸入或 USB/HID 裝置等本地訊號，隨後記錄發現、觸發全螢幕紅屏警告，並支援遠端管理員檢查與證據蒐集，而無需整合遊戲伺服器封禁系統。技術棧涵蓋 Java 與 Spring Boot 服務、React 與 TypeScript 管理前端、Python AI 評分、具加密簽章與加密持久化的 Rust 事件管線，以及面向 Windows、Linux、Android、iOS 與 HarmonyOS 的原生探針及核心或代理模組。它面向希望實現用戶端作弊威懾、行為分析與鑑識稽核，同時將管理基礎設施與遊戲伺服器隔離的 Minecraft 社群與營運者。
