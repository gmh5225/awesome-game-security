PACC（Professional Anti-Cheat Client，专业反作弊客户端）是一款面向 Minecraft 基岩版与 Java 版的玩家端反作弊平台，将设备端检测与独立的 PTV 控制与管理后端相结合。它会检查内存篡改、运行中的进程与模块以及输入或 USB/HID 设备等本地信号，随后记录发现、触发全屏红屏警告，并支持远程管理员检查与证据采集，而无需接入游戏服务器封禁系统。技术栈涵盖 Java 与 Spring Boot 服务、React 与 TypeScript 管理前端、Python AI 评分、带加密签名与加密持久化的 Rust 事件管道，以及面向 Windows、Linux、Android、iOS 与 HarmonyOS 的原生探针及内核或代理模块。它面向希望实现客户端作弊威慑、行为分析与取证审计，同时将管理基础设施与游戏服务器隔离的 Minecraft 社区与运营者。
