PACC (Professional Anti-Cheat Client) è una piattaforma anti-cheat lato giocatore per le edizioni Minecraft Bedrock e Java che combina il rilevamento sul dispositivo con un backend PTV separato per controllo e amministrazione. Ispeziona segnali locali come manomissione della memoria, processi e moduli in esecuzione, e dispositivi di input o USB/HID, quindi registra i risultati, attiva avvisi a schermo intero con sfondo rosso e supporta ispezione remota da parte degli amministratori e raccolta di prove senza integrare i sistemi di ban del server di gioco. Lo stack comprende servizi Java e Spring Boot, un frontend amministrativo React e TypeScript, scoring IA in Python, una pipeline di eventi Rust con firma crittografica e persistenza crittografata, e sonde native più moduli kernel o agent per Windows, Linux, Android, iOS e HarmonyOS. È rivolto a comunità e operatori Minecraft che vogliono deterrenza anti-cheat lato client, analisi comportamentale e audit forense, mantenendo l'infrastruttura di gestione isolata dai server di gioco.
