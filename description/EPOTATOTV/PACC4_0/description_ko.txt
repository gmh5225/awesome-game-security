PACC(Professional Anti-Cheat Client)는 Minecraft Bedrock Edition과 Java Edition을 위한 플레이어 측 안티치트 플랫폼으로, 기기 내 탐지와 별도의 PTV 제어·관리 백엔드를 결합합니다. 메모리 변조, 실행 중인 프로세스와 모듈, 입력 또는 USB/HID 장치 등 로컬 신호를 검사한 뒤 발견 사항을 기록하고 전체 화면 빨간 화면 경고를 트리거하며, 게임 서버 밴 시스템과 통합하지 않고도 원격 관리자 검사와 증거 수집을 지원합니다. 스택은 Java 및 Spring Boot 서비스, React와 TypeScript 관리 프런트엔드, Python AI 점수화, 암호 서명과 암호화된 영속성을 갖춘 Rust 이벤트 파이프라인, Windows, Linux, Android, iOS, HarmonyOS용 네이티브 프로브와 커널 또는 에이전트 모듈로 구성됩니다. Minecraft 커뮤니티와 운영자가 클라이언트 측 치트 억제, 행동 분석, 포렌식 감사를 원하면서 관리 인프라를 게임 서버와 분리해 유지하려는 경우를 대상으로 합니다.
