Kenshi Automation Harness is an in-game test automation framework for Kenshi that lets scripts and AI agents drive a live game session through a file-based command interface. It is implemented as a C++ DLL plugin built with the KenshiLib SDK and Ogre/MyGUI, paired with a Python client and PowerShell tooling to launch the game, send commands, and run scenario-based tests. The harness exposes dozens of built-in commands for spawning NPCs, manipulating world state, issuing AI orders, controlling UI, and verifying game state, and other mods can register custom commands via a C extension API. It is aimed at Kenshi mod developers and automated testers who need repeatable, scriptable control over a running game without manual playthroughs.
