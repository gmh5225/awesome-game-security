Le Kenshi Automation Harness est un framework d'automatisation de tests in-game pour Kenshi qui permet aux scripts et agents IA de piloter une session de jeu en direct via une interface de commandes basée sur des fichiers. Il est implémenté sous forme de plugin DLL C++ construit avec le SDK KenshiLib et Ogre/MyGUI, associé à un client Python et à des outils PowerShell pour lancer le jeu, envoyer des commandes et exécuter des tests basés sur des scénarios. Le harness expose des dizaines de commandes intégrées pour faire apparaître des PNJ, manipuler l'état du monde, émettre des ordres IA, contrôler l'interface utilisateur et vérifier l'état du jeu ; d'autres mods peuvent enregistrer des commandes personnalisées via une API d'extension C. Il s'adresse aux développeurs de mods Kenshi et aux testeurs automatisés qui ont besoin d'un contrôle reproductible et scriptable du jeu en cours d'exécution, sans passer manuellement par une partie.
