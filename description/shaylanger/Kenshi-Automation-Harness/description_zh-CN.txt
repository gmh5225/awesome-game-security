Kenshi Automation Harness 是一款面向 Kenshi 的游戏内测试自动化框架，可通过基于文件的命令接口让脚本和 AI 代理驱动实时游戏会话。它实现为基于 KenshiLib SDK 和 Ogre/MyGUI 构建的 C++ DLL 插件，并配套 Python 客户端与 PowerShell 工具，用于启动游戏、发送命令和运行基于场景的测试。该框架公开了数十条内置命令，可用于生成 NPC、操控世界状态、下达 AI 指令、控制 UI 以及验证游戏状态，其他模组还可通过 C 扩展 API 注册自定义命令。它面向需要可重复、可脚本化控制运行中游戏、而非依赖手动通关的 Kenshi 模组开发者和自动化测试人员。
