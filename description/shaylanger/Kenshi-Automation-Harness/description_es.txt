Kenshi Automation Harness es un framework de automatización de pruebas in-game para Kenshi que permite a scripts y agentes de IA controlar una sesión de juego en vivo mediante una interfaz de comandos basada en archivos. Se implementa como un plugin DLL en C++ construido con el SDK KenshiLib y Ogre/MyGUI, junto con un cliente Python y herramientas PowerShell para iniciar el juego, enviar comandos y ejecutar pruebas basadas en escenarios. El harness expone decenas de comandos integrados para generar NPCs, manipular el estado del mundo, emitir órdenes de IA, controlar la UI y verificar el estado del juego; otros mods pueden registrar comandos personalizados mediante una API de extensión en C. Está dirigido a desarrolladores de mods de Kenshi y testers automatizados que necesitan control repetible y scriptable sobre un juego en ejecución sin pasar manualmente por la partida.
