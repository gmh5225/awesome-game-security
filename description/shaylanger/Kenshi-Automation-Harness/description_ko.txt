Kenshi Automation Harness는 파일 기반 명령 인터페이스를 통해 스크립트와 AI 에이전트가 라이브 게임 세션을 제어할 수 있는 Kenshi용 게임 내 테스트 자동화 프레임워크입니다. KenshiLib SDK와 Ogre/MyGUI로 구축된 C++ DLL 플러그인으로 구현되었으며, Python 클라이언트 및 PowerShell 도구와 함께 게임 실행, 명령 전송, 시나리오 기반 테스트 실행을 지원합니다. 이 하네스는 NPC 생성, 월드 상태 조작, AI 명령 발행, UI 제어, 게임 상태 검증 등 수십 가지 내장 명령을 제공하며, 다른 모드는 C 확장 API를 통해 사용자 정의 명령을 등록할 수 있습니다. 수동 플레이 없이 실행 중인 게임에 대해 반복 가능하고 스크립트 가능한 제어가 필요한 Kenshi 모드 개발자 및 자동화 테스터를 대상으로 합니다.
