Kenshi Automation Harness は、Kenshi 向けのゲーム内テスト自動化フレームワークで、ファイルベースのコマンドインターフェースを通じてスクリプトや AI エージェントがライブなゲームセッションを操作できます。KenshiLib SDK と Ogre/MyGUI で構築された C++ DLL プラグインとして実装され、Python クライアントと PowerShell ツールと組み合わせて、ゲームの起動、コマンド送信、シナリオベースのテスト実行が可能です。このハーネスは、NPC のスポーン、ワールド状態の操作、AI 命令の発行、UI の制御、ゲーム状態の検証など、数十種類の組み込みコマンドを提供し、他の MOD は C 拡張 API 経由でカスタムコマンドを登録できます。手動プレイに頼らず、実行中のゲームに対して再現可能でスクリプト可能な制御が必要な Kenshi MOD 開発者と自動テスト担当者を対象としています。
