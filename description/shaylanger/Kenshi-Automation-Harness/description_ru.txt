Kenshi Automation Harness — это внутриигровой фреймворк автоматизации тестирования для Kenshi, позволяющий скриптам и AI-агентам управлять живой игровой сессией через файловый интерфейс команд. Он реализован как C++ DLL-плагин, созданный с использованием KenshiLib SDK и Ogre/MyGUI, в паре с Python-клиентом и инструментами PowerShell для запуска игры, отправки команд и выполнения сценарных тестов. Harness предоставляет десятки встроенных команд для спавна NPC, изменения состояния мира, выдачи приказов ИИ, управления интерфейсом и проверки игрового состояния; другие моды могут регистрировать пользовательские команды через API C-расширений. Он предназначен для разработчиков модов Kenshi и автоматизированных тестировщиков, которым нужен повторяемый скриптовый контроль над запущенной игрой без ручного прохождения.
