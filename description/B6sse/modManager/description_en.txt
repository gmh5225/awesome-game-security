Axon (Basses Mod Manager) is a Windows desktop mod manager for Star Wars Battlefront 2015 that lets players choose from a fixed set of pre-installed, community-approved mods and launch the game with those selections applied. It is built as a C# WPF application targeting .NET Framework 4.8, with an Inno Setup installer and bundled prerequisites for straightforward deployment. Mods ship in Frosty-style .fbmod packages and are applied in memory at startup through Auric, a bundled loader DLL installed beside the game executable that reads launch metadata written by the manager. The UI deliberately omits custom mod import and removal so only vetted content is available, which suits organized competitive or private-server play where mod integrity matters. The project documents the memory-loading pipeline and integrates CI checks to ensure only public Auric builds ship, making it useful for studying controlled client-side mod injection and fair-play mod tooling.
