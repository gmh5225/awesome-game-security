Axon（Basses Mod Manager）是一款面向 Windows 的《星際大戰：戰場前線 2015》桌面模組管理器，玩家可從一組固定的、預裝且經社群認可的模組中選擇，並以所選設定啟動遊戲。它以 C# WPF 應用程式形式建構，目標框架為 .NET Framework 4.8，配有 Inno Setup 安裝程式及捆綁相依元件，便於部署。模組以 Frosty 風格的 .fbmod 套件形式提供，啟動時透過 Auric（與遊戲可執行檔同目錄安裝的捆綁載入 DLL）在記憶體中套用，該 DLL 會讀取管理器寫入的啟動中繼資料。介面刻意不提供自訂匯入或移除模組，僅提供經審核的內容，適合重視模組完整性的競技或私服環境。專案文件化了記憶體載入流程，並透過 CI 確保僅發布公開的 Auric 建置，對研究受控的用戶端模組注入與公平競技向模組工具具有參考價值。
