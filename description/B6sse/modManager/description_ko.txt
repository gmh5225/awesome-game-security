Axon(Basses Mod Manager)은 Windows용 Star Wars Battlefront 2015 데스크톱 MOD 관리자로, 플레이어가 미리 설치된 커뮤니티 승인 MOD 고정 세트에서 선택해 해당 구성으로 게임을 실행할 수 있게 합니다. C# WPF 애플리케이션으로 .NET Framework 4.8을 대상으로 하며, Inno Setup 설치 프로그램과 번들 전제 조건으로 배포가 간단합니다. MOD는 Frosty 스타일 .fbmod 패키지로 제공되며, 시작 시 Auric(게임 실행 파일 옆에 설치되는 번들 로더 DLL)이 관리자가 기록한 실행 메타데이터를 읽어 메모리에서 적용합니다. UI는 사용자 MOD 가져오기 및 제거를 의도적으로 배제해 검증된 콘텐츠만 제공하므로, MOD 무결성이 중요한 조직적 경쟁 또는 프라이빗 서버 플레이에 적합합니다. 프로젝트는 메모리 로딩 파이프라인을 문서화하고 공개 Auric 빌드만 배포되도록 CI 검사를 통합해, 통제된 클라이언트 측 MOD 주입 및 공정 플레이 MOD 도구 연구에 유용합니다.
