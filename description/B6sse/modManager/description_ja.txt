Axon（Basses Mod Manager）は、Windows 向けの Star Wars Battlefront 2015 用デスクトップ MOD マネージャーで、プレイヤーは事前インストール済みかつコミュニティ承認の固定 MOD セットから選び、その選択を反映した状態でゲームを起動できます。C# WPF アプリケーションとして .NET Framework 4.8 をターゲットに構築され、Inno Setup インストーラと同梱の前提条件により、手軽に配布・導入できます。MOD は Frosty 形式の .fbmod パッケージで提供され、起動時に Auric（ゲーム実行ファイル横に配置される同梱ローダー DLL）がマネージャが書き込んだ起動メタデータを読み取り、メモリ上で適用します。UI ではカスタム MOD のインポートや削除を意図的に省き、審査済みコンテンツのみを利用可能にしており、MOD の整合性が重要な競技やプライベートサーバー向けに適しています。プロジェクトはメモリロードのパイプラインを文書化し、公開 Auric ビルドのみが出荷されるよう CI チェックを組み込んでおり、制御されたクライアント側 MOD 注入やフェアプレイ向け MOD ツールの研究に役立ちます。
