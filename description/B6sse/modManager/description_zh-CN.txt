Axon（Basses Mod Manager）是一款面向 Windows 的《星球大战：前线 2015》桌面模组管理器，玩家可从一组固定的、预装且经社区认可的模组中选择，并以所选配置启动游戏。它以 C# WPF 应用形式构建，目标框架为 .NET Framework 4.8，配有 Inno Setup 安装程序及捆绑依赖，便于部署。模组以 Frosty 风格的 .fbmod 包形式提供，启动时通过 Auric（与游戏可执行文件同目录安装的捆绑加载 DLL）在内存中应用，该 DLL 会读取管理器写入的启动元数据。界面刻意不提供自定义导入或移除模组，仅提供经审核的内容，适合重视模组完整性的竞技或私服环境。项目文档化了内存加载流程，并通过 CI 确保仅发布公开的 Auric 构建，对研究受控的客户端模组注入与公平竞技向模组工具具有参考价值。
