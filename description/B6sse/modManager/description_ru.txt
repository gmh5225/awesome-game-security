Axon (Basses Mod Manager) — настольный менеджер модов для Windows для Star Wars Battlefront 2015, позволяющий игрокам выбирать из фиксированного набора предустановленных, одобренных сообществом модов и запускать игру с выбранными настройками. Приложение написано на C# WPF с целевой платформой .NET Framework 4.8, с установщиком Inno Setup и поставляемыми зависимостями для простого развёртывания. Моды поставляются в пакетах .fbmod в стиле Frosty и применяются в памяти при запуске через Auric — поставляемую DLL-загрузчик, устанавливаемую рядом с исполняемым файлом игры и читающую метаданные запуска, записанные менеджером. Интерфейс намеренно не поддерживает импорт и удаление пользовательских модов, доступен только проверенный контент, что подходит для организованной соревновательной игры или частных серверов, где важна целостность модов. Проект документирует конвейер загрузки в память и использует CI-проверки, чтобы поставлялись только публичные сборки Auric, что полезно для изучения контролируемой клиентской инъекции модов и инструментов модов для честной игры.
