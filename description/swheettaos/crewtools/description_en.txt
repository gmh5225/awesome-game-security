Crew Tools is a BepInEx 6 IL2CPP plugin that gives Moon Sweepers server hosts a full moderation and permission stack for crew multiplayer sessions. It is written primarily in C# with hooks into game methods, plus small Python utilities for API documentation and packaging. Hosts get per-player switches for build, shop, and related actions, protected base zones, a rolling spending cap, and layered defenses including money reconciliation anti-cheat and a cheat watch for speed, flight, reach, deposits, and teleports. The mod exposes an in-game tabbed admin window and an optional HTTP API under /crew/ so external dashboards or scripts can list players, apply bans and kicks, and mirror the same actions as the UI. It targets operators who need practical server-side anti-cheat, enforcement, and housekeeping such as periodic cleanup and ban reclaim without restarting the game when used with a hot-reload capable loader.
