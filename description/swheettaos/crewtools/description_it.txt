Crew Tools è un plugin BepInEx 6 IL2CPP che offre agli host di server Moon Sweepers un stack completo di moderazione e permessi per sessioni multiplayer di equipaggio. È scritto principalmente in C# con hook sui metodi di gioco, più piccole utility Python per documentazione API e packaging. Gli host ottengono interruttori per giocatore per costruzione, negozio e azioni correlate, zone base protette, un limite di spesa rolling e difese a strati, inclusi anti-cheat con riconciliazione del denaro e sorveglianza cheat per velocità, volo, portata, depositi e teletrasporti. La mod espone una finestra admin a schede in gioco e un’API HTTP opzionale sotto /crew/, così dashboard o script esterni possono elencare i giocatori, applicare ban ed espulsioni e rispecchiare le stesse azioni dell’interfaccia. È pensata per operatori che necessitano di anti-cheat lato server pratico, enforcement e manutenzione, come pulizia periodica e recupero ban, senza riavviare il gioco se usata con un loader compatibile con hot-reload.
