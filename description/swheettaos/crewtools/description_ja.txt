Crew Tools は BepInEx 6 IL2CPP 用プラグインで、Moon Sweepers のサーバーホスト向けにクルー向けマルチプレイセッション用のモデレーションと権限管理を一式提供します。主に C# で書かれ、ゲームメソッドへのフックを中心とし、API ドキュメントとパッケージング用の小さな Python ユーティリティも含みます。ホストはプレイヤーごとに建築・ショップなど関連アクションの切り替え、保護された基地ゾーン、ローリング支出上限を設定でき、金銭照合によるアンチチートや速度・飛行・リーチ・入金・テレポートを監視するチートウォッチなど層状の防御も利用できます。MOD はゲーム内のタブ付き管理ウィンドウと、/crew/ 配下の任意の HTTP API を公開し、外部ダッシュボードやスクリプトからプレイヤー一覧、BAN・キックの適用、UI と同じ操作のミラーリングが可能です。実用的なサーバー側アンチチート、取り締まり、定期クリーンアップや BAN 回収といった運用保守を、ホットリロード対応ローダー利用時はゲーム再起動なしで行いたい運営者向けです。
