Crew Tools — плагин BepInEx 6 IL2CPP, который даёт хостам серверов Moon Sweepers полный набор модерации и прав для многопользовательских сессий экипажа. Написан в основном на C# с перехватами игровых методов, плюс небольшие утилиты на Python для документации API и упаковки. Хосты получают переключатели по игрокам для строительства, магазина и связанных действий, защищённые зоны базы, скользящий лимит расходов и многоуровневую защиту, включая античит со сверкой денег и наблюдение за читами по скорости, полёту, дальности, вкладам и телепортам. Мод предоставляет внутриигровое окно администратора с вкладками и опциональный HTTP API по пути /crew/, чтобы внешние панели или скрипты могли выводить список игроков, выдавать баны и кики и повторять те же действия, что и интерфейс. Ориентирован на операторов, которым нужны практичный серверный античит, принуждение к правилам и обслуживание вроде периодической очистки и возврата банов без перезапуска игры при использовании загрузчика с поддержкой горячей перезагрузки.
