Crew Tools 是一款 BepInEx 6 IL2CPP 外掛程式，為 Moon Sweepers 伺服器主機提供完整的審核與權限體系，用於多人船員連線。主要以 C# 撰寫，透過鉤住遊戲方法實作功能，並附帶用於 API 文件與封裝的小型 Python 工具。主機可為每位玩家單獨開關建造、商店及相關操作，設定受保護基地區域與滾動消費上限，多層防護包括金錢對帳反作弊，以及針對速度、飛行、攻擊距離、存款與傳送的作弊監視。模組提供遊戲內分頁管理視窗，以及可選的 /crew/ HTTP API，供外部儀表板或腳本列出玩家、封禁與踢出，並與 UI 執行相同操作。面向需要實用伺服器端反作弊、執法與日常維護（如定期清理、封禁回收）且在使用支援熱重載的載入器時無需重啟遊戲的營運者。
