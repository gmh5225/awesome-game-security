Crew Tools 是一款 BepInEx 6 IL2CPP 插件，为 Moon Sweepers 服务器主提供完整的审核与权限体系，用于多人船员会话。主要用 C# 编写，通过钩住游戏方法实现功能，并附带用于 API 文档与打包的小型 Python 工具。主可为每位玩家单独开关建造、商店及相关操作，设定受保护基地区域与滚动消费上限，多层防护包括金钱对账反作弊，以及针对速度、飞行、攻击距离、存款与传送的作弊监视。模组提供游戏内分页管理窗口，以及可选的 /crew/ HTTP API，供外部面板或脚本列出玩家、封禁与踢出，并与 UI 执行相同操作。面向需要实用服务端反作弊、执法与日常维护（如定期清理、封禁回收）且在使用支持热重载的加载器时无需重启游戏的运营者。
