Crew Tools es un complemento BepInEx 6 IL2CPP que ofrece a los anfitriones de servidores de Moon Sweepers una pila completa de moderación y permisos para sesiones multijugador de tripulación. Está escrito principalmente en C# con hooks en métodos del juego, más pequeñas utilidades en Python para documentación de API y empaquetado. Los anfitriones obtienen interruptores por jugador para construcción, tienda y acciones relacionadas, zonas de base protegidas, un límite de gasto rodante y defensas en capas, incluido anti-trampas por conciliación de dinero y vigilancia de trampas por velocidad, vuelo, alcance, depósitos y teletransportes. El mod expone una ventana de administración con pestañas en el juego y una API HTTP opcional bajo /crew/, para que paneles o scripts externos listen jugadores, apliquen baneos y expulsiones, y reflejen las mismas acciones que la interfaz. Está dirigido a operadores que necesitan anti-trampas práctico en el servidor, cumplimiento de normas y mantenimiento, como limpieza periódica y recuperación de baneos, sin reiniciar el juego cuando se usa con un cargador compatible con recarga en caliente.
