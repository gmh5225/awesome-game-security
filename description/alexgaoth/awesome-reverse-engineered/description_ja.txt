Awesome Reverse-Engineered は、クローズドなアプリケーション、API、デバイス、ワイヤプロトコル、ファイル形式、ゲーム、または AI 製品を誰かがリバースエンジニアリングした結果として生まれたオープンソースプロジェクトを集めた、大規模で機械保守されるカタログです。数万件のエントリを、ゲームのデコンパイルと再実装、リバースエンジニアリング用ツール、非公式 API クライアント、IoT とファームウェア関連、コミュニティの再実装によって存続している終了製品の別リストなど、テーマ別カテゴリに整理しています。リポジトリには構造化 JSON データ、夜間更新とサイト生成の Python 自動化、検索可能な GitHub Pages インデックス、MCP サーバーや agent skills などの連携があり、ツールが活動状況やライセンスでプロジェクトを検索・ランク付けできます。リバースエンジニア、セキュリティ研究者、相互運用性や先行事例が必要で重複した RE 作業を避けたい開発者向けで、ゲーム mod、エミュレーション、反チート周辺のツール発見に関わる作業も含みます。
