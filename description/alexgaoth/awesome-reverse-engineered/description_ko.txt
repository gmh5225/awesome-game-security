Awesome Reverse-Engineered는 폐쇄형 애플리케이션, API, 기기, 와이어 프로토콜, 파일 형식, 게임 또는 AI 제품을 누군가 리버스 엔지니어링한 결과로 생긴 오픈 소스 프로젝트를 모은 대규모 기계 유지 카탈로그입니다. 수만 개의 항목을 게임 디컴파일 및 재구현, 리버스 엔지니어링 도구, 비공식 API 클라이언트, IoT 및 펌웨어 작업, 커뮤니티 재구현으로 유지되는 단종 제품 별도 목록 등 주제별 카테고리로 정리합니다. 저장소에는 구조화된 JSON 데이터, 야간 갱신 및 사이트 생성용 Python 자동화, 검색 가능한 GitHub Pages 인덱스, MCP 서버 및 agent skills 등 통합이 포함되어 도구가 활동과 라이선스 기준으로 프로젝트를 검색·순위화할 수 있습니다. 리버스 엔지니어, 보안 연구자, 상호 운용성이나 선행 사례가 필요해 중복 RE 작업을 피하려는 개발자를 대상으로 하며, 게임 모딩, 에뮬레이션, 안티치트 인접 도구 탐색과 관련된 작업도 다룹니다.
