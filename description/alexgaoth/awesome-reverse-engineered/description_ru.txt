Awesome Reverse-Engineered — крупный автоматически поддерживаемый каталог проектов с открытым исходным кодом, появившихся потому, что кто-то провёл reverse engineering закрытого приложения, API, устройства, проводного протокола, формата файла, игры или продукта ИИ. В нём десятки тысяч записей разложены по тематическим категориям: декомпиляции и реимплементации игр, инструменты для reverse engineering, неофициальные API-клиенты, работа с IoT и прошивками, а также отдельный список снятых с производства продуктов, которые сообщество поддерживает реимплементациями. Репозиторий содержит структурированные JSON-данные, Python-автоматизацию для ночного обновления и генерации сайта, поисковый индекс на GitHub Pages и интеграции, включая MCP-сервер и agent skills, чтобы инструменты могли искать и ранжировать проекты по активности и лицензии. Он ориентирован на reverse engineers, исследователей безопасности и разработчиков, которым нужна совместимость или prior art перед повторением работы по RE, в том числе в контексте моддинга игр, эмуляции и поиска инструментов, связанных с anti-cheat.
