Awesome Reverse-Engineered 是一份由机器维护的大型开源项目目录，收录那些因有人对闭源应用、API、设备、线缆协议、文件格式、游戏或 AI 产品进行逆向工程而诞生的项目。它将数万条条目按主题分类，涵盖游戏反编译与重实现、逆向工程工具、非官方 API 客户端、物联网与固件相关工作，以及因社区重实现而得以延续的已停产产品清单。仓库提供结构化 JSON 数据、用于夜间刷新与站点生成的 Python 自动化、可搜索的 GitHub Pages 索引，以及 MCP 服务器与 agent skills 等集成，便于工具按活跃度与许可证检索和排序项目。面向逆向工程师、安全研究人员以及需要互操作性或在重复逆向工作前查阅先例的开发者，包括与游戏模组、模拟器及反作弊相关工具发现有关的工作。
