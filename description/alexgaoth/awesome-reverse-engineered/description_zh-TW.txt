Awesome Reverse-Engineered 是一份由機器維護的大型開源專案目錄，收錄那些因有人對閉源應用程式、API、裝置、線路協定、檔案格式、遊戲或 AI 產品進行逆向工程而誕生的專案。它將數萬筆條目按主題分類，涵蓋遊戲反編譯與重實作、逆向工程工具、非官方 API 用戶端、物聯網與韌體相關工作，以及因社群重實作而得以延續的已停產產品清單。儲存庫提供結構化 JSON 資料、用於夜間更新與網站產生的 Python 自動化、可搜尋的 GitHub Pages 索引，以及 MCP 伺服器與 agent skills 等整合，便於工具依活躍度與授權條款檢索與排序專案。面向逆向工程師、安全研究人員以及需要互通性或在重複逆向工作前查閱先例的開發者，包括與遊戲模組、模擬器及反作弊相關工具探索有關的工作。
