Awesome Reverse-Engineered is a large, machine-maintained catalog of open-source projects that exist because someone reverse engineered a closed application, API, device, wire protocol, file format, game, or AI product. It organizes tens of thousands of entries into themed categories such as game decompilations and reimplementations, reverse-engineering tooling, unofficial API clients, IoT and firmware work, and a separate list of discontinued products kept alive by community reimplementations. The repository ships structured JSON data, Python automation for nightly refresh and site generation, a searchable GitHub Pages index, and integrations including an MCP server and agent skills so tools can search and rank projects by activity and license. It is aimed at reverse engineers, security researchers, and developers who need interoperability or prior art before duplicating reverse-engineering effort, including work relevant to game modding, emulation, and anti-cheat adjacent tooling discovery.
