This project is a layered static analysis and reconstruction archive for the XignCode3 anti-cheat client used by Black Desert, documenting how its xmag and xnina container binaries unpack into user-mode modules, kernel drivers, Lua scripts, and configuration data. Analysis is organized through an eight-stage pipeline with Python carving and unpacking tools, Ghidra decompilation of seventeen native modules, Lua 5.3 recovery via unluac-rs, and static triage using capa, FLOSS, and Detect It Easy, including dedicated work on the VMProtect-protected xhunter1 kernel driver. The repository also provides semantic inventories, behavior and architecture documentation, IPC and detection subsystem specifications, and PowerShell live-host capture harnesses for reconciling static findings with runtime behavior. It is intended for game security researchers and reverse engineers studying commercial anti-cheat design, detection logic, and protected driver implementations.
