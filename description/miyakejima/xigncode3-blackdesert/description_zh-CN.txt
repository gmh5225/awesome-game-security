本项目是针对《黑色沙漠》所使用的 XignCode3 反作弊客户端的分层静态分析与重建归档，记录了其 xmag 与 xnina 容器二进制如何解包为用户态模块、内核驱动、Lua 脚本及配置数据。分析工作通过八阶段流水线组织，涵盖基于 Python 的 carving 与解包工具、对十七个原生模块的 Ghidra 反编译、通过 unluac-rs 恢复 Lua 5.3 脚本，以及使用 capa、FLOSS 与 Detect It Easy 进行的静态 triage，并包含针对受 VMProtect 保护的 xhunter1 内核驱动的专项研究。仓库还提供语义清单、行为与架构文档、IPC 与检测子系统规范，以及用于将静态发现与运行时行为进行对照的 PowerShell 实时主机捕获工具。本项目面向研究商业反作弊设计、检测逻辑及受保护驱动实现的游戏安全研究人员与逆向工程师。
