本專案是針對《黑色沙漠》所使用的 XignCode3 反作弊用戶端的階層式靜態分析與重建歸檔，記錄其 xmag 與 xnina 容器二進位檔如何解包為使用者模式模組、核心驅動程式、Lua 腳本及設定資料。分析工作透過八階段管線組織，涵蓋以 Python 撰寫的 carving 與解包工具、對十七個原生模組的 Ghidra 反編譯、透過 unluac-rs 還原 Lua 5.3 腳本，以及使用 capa、FLOSS 與 Detect It Easy 進行的靜態 triage，並包含針對受 VMProtect 保護的 xhunter1 核心驅動程式的專項研究。此儲存庫亦提供語意清單、行為與架構文件、IPC 與偵測子系統規格，以及用於將靜態發現與執行時行為進行對照的 PowerShell 即時主機擷取工具。本專案面向研究商業反作弊設計、偵測邏輯及受保護驅動程式實作的遊戲安全研究人員與逆向工程師。
