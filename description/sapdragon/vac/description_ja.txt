本プロジェクトは、クラシックな 32 ビット Valve Anti-Cheat スキャンモジュール 15 個と、それらを読み込み実行するホスト steamservice.dll をバイト単位で再現した C++20 実装である。共有モジュール SDK には元の _runfunc エクスポート経路、VLV RSA 署名検証、マニュアルマッピング、ICE と生の RSA-512 によるレポート封印が含まれ、ブート設定、ドライバ、PCI および USB デバイス、メモリ上・ディスク上の PE イメージ、プロセスメモリマップ、共有セクション、システムハンドル、WoW64 Heaven's Gate システムコールを指紋取得する worker も備える。再構築した各スキャナは Valve 署名付きオリジナルに対し 4232 バイト出力の完全一致で検証され、レガシー バイナリの癖、バグ、スタック上の痕跡を意図的に保持する。付属の解説は、アンチチートアーキテクチャ、クライアント整合性テレメトリ、Steam 上の Windows ゲームセキュリティを研究する者向けに IPC、モジュール管理、スキャナの仕組みを記述する。
