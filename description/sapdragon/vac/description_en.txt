This project is a byte-for-byte C++20 reconstruction of fifteen classic 32-bit Valve Anti-Cheat scan modules plus the host steamservice.dll that loads and runs them. It includes a shared module SDK with the original _runfunc export path, VLV RSA signing checks, manual mapping, and report sealing via ICE and raw RSA-512, alongside workers that fingerprint boot config, drivers, PCI and USB devices, in-memory and on-disk PE images, process memory maps, shared sections, system handles, and WoW64 Heaven's Gate syscalls. Each rebuilt scanner is validated for exact 4232-byte output parity against Valve's signed originals, deliberately preserving quirks, bugs, and stack artifacts from the legacy binaries. The accompanying writeups document IPC, module management, and scanner mechanics for researchers studying anti-cheat architecture, client integrity telemetry, and Windows game security on Steam.
