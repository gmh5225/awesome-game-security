DriverRiskScout は、エンドポイント上の Windows カーネルドライバーの露出とリスクを評価する読み取り専用の防御ツールです。主に PowerShell で記述され、Python ベースの中央コレクターサーバーと連携し、読み込み済み・インストール済み・DriverStore 内のドライバーを棚卸しし、署名を検証し、ハッシュを LOLDrivers、Microsoft の脆弱ドライバーブロックリスト、および厳選された BYOVD 研究プロファイルと照合します。静的 PE 解析、YARA ルール、悪用可能性スコアリング、Sysmon および Code Integrity からのイベントログ相関を適用し、HVCI、VBS、WDAC などの保護態勢も検出します。レポートは CSV、JSON、HTML、Wazuh NDJSON としてエクスポートでき、オプションで NVD CVE エンリッチメントと Sigma ルール生成にも対応します。防御担当者、インシデント対応者、ゲームセキュリティチーム向けに、ドライバーを悪用したりホストを変更したりすることなく、BYOVD 悪用やその他のカーネルレベルの脅威をハンティングするために設計されています。
