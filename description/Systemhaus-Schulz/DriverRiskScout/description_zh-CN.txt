DriverRiskScout 是一款只读防御工具，用于评估端点上 Windows 内核驱动的暴露面与风险。它主要使用 PowerShell 编写，并配有基于 Python 的中央采集服务器，可清点已加载、已安装及 DriverStore 中的驱动，验证签名，并将哈希与 LOLDrivers、Microsoft 易受攻击驱动程序阻止列表以及精选的 BYOVD 研究配置文件进行关联。该工具应用静态 PE 分析、YARA 规则、可利用性评分，以及来自 Sysmon 和 Code Integrity 的事件日志关联，同时检测 HVCI、VBS、WDAC 等防护态势。报告可导出为 CSV、JSON、HTML 和 Wazuh NDJSON 格式，并可选进行 NVD CVE 信息 enrichment 与 Sigma 规则生成。它面向防御人员、事件响应人员以及游戏安全团队，用于狩猎 BYOVD 滥用及其他内核级威胁，且不会利用驱动或修改主机。
