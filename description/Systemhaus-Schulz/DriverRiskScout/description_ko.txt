DriverRiskScout는 엔드포인트에서 Windows 커널 드라이버의 노출과 위험을 평가하는 읽기 전용 방어 도구입니다. 주로 PowerShell로 작성되었으며 Python 기반 중앙 수집 서버와 함께 동작하여, 로드·설치·DriverStore 드라이버를 목록화하고 서명을 검증하며, 해시를 LOLDrivers, Microsoft 취약 드라이버 차단 목록, 엄선된 BYOVD 연구 프로필과 대조합니다. 정적 PE 분석, YARA 규칙, 악용 가능성 점수, Sysmon 및 Code Integrity 이벤트 로그 상관 분석을 적용하고 HVCI, VBS, WDAC 등 보호 상태를 감지합니다. 보고서는 CSV, JSON, HTML, Wazuh NDJSON으로 내보낼 수 있으며, 선택적으로 NVD CVE enrichment와 Sigma 규칙 생성을 지원합니다. 방어 담당자, 사고 대응자, 게임 보안 팀이 드라이버를 악용하거나 호스트를 수정하지 않고 BYOVD 남용 및 기타 커널 수준 위협을 헌팅하는 데 목적이 있습니다.
