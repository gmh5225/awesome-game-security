DriverRiskScout — это защитный инструмент только для чтения, предназначенный для оценки экспозиции и рисков, связанных с драйверами ядра Windows на конечных точках. Написанный в основном на PowerShell с центральным сервером-сборщиком на Python, он инвентаризирует загруженные, установленные и драйверы из DriverStore, проверяет подписи и сопоставляет хеши с LOLDrivers, блок-листом уязвимых драйверов Microsoft и отобранными исследовательскими профилями BYOVD. Применяет статический PE-анализ, правила YARA, оценку эксплуатируемости и корреляцию журналов событий Sysmon и Code Integrity, одновременно выявляя HVCI, VBS, WDAC и другие меры защиты. Отчёты экспортируются в CSV, JSON, HTML и Wazuh NDJSON, с опциональным обогащением CVE из NVD и генерацией правил Sigma. Предназначен для защитников, реагирующих на инциденты, и команд игровой безопасности, охотящихся за злоупотреблениями BYOVD и другими угрозами на уровне ядра без эксплуатации драйверов и изменения хоста.
