DriverRiskScout 是一款唯讀防禦工具，用於評估端點上 Windows 核心驅動程式的暴露面與風險。它主要以 PowerShell 撰寫，並配有以 Python 為基礎的中央收集伺服器，可盤點已載入、已安裝及 DriverStore 中的驅動程式，驗證簽章，並將雜湊值與 LOLDrivers、Microsoft 易受攻擊驅動程式封鎖清單以及精選的 BYOVD 研究設定檔進行關聯。此工具套用靜態 PE 分析、YARA 規則、可利用性評分，以及來自 Sysmon 與 Code Integrity 的事件記錄關聯，同時偵測 HVCI、VBS、WDAC 等防護態勢。報告可匯出為 CSV、JSON、HTML 與 Wazuh NDJSON 格式，並可選擇進行 NVD CVE 資訊 enrichment 與 Sigma 規則產生。它面向防禦人員、事件回應人員以及遊戲安全團隊，用於獵捕 BYOVD 濫用及其他核心層級威脅，且不會利用驅動程式或修改主機。
