UrnIt Anticheat ist ein clientseitiges Anticheat-Tool für Windows für das Spiel Deadlock, das Spieler während Sitzungen überwacht und Beweise zur Prüfung an das Personal sendet. Hauptsächlich in C++ geschrieben, mit einem Visual Studio-Build und einem Python-Hilfsskript, erfasst es regelmäßig Prozesslisten, PNG-Screenshots des Spielfensters, Tastatureingaben des fokussierten Fensters sowie Hardwaredetails einschließlich CPU und GPU. Es markiert bekannte Cheat-Prozesse anhand einer konfigurierbaren Liste (mit optionaler Forum-Scraping-Funktion zur Aktualisierung von Signaturen), erkennt mögliche Makro- oder Bot-Nutzung anhand der Varianz der Tastendruck-Zeitabstände und lädt Berichte automatisch über Webhook an Discord hoch, wenn das Spiel beendet wird oder der Spieler F12 drückt. Das Projekt richtet sich an Turnierveranstalter und Spiele-Sicherheitspersonal, die leichtgewichtige Sitzungsprotokollierung und Remote-Prüfung statt Durchsetzung auf Kernel-Ebene benötigen.
