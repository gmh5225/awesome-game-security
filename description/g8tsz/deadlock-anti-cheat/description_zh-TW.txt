UrnIt Anticheat 是一款面向遊戲 Deadlock 的 Windows 用戶端反作弊工具，可在玩家連線期間進行監控，並將證據傳送給工作人員審核。該專案主要使用 C++ 編寫，採用 Visual Studio 建置，並附帶 Python 輔助腳本，會定期擷取程序清單、遊戲視窗 PNG 螢幕截圖、目前焦點視窗的按鍵輸入，以及 CPU 與 GPU 等硬體資訊。它會依據可設定清單標記已知作弊程序（可選透過論壇爬取更新特徵），透過按鍵時間間隔變異數偵測可能的巨集或機器人使用，並在遊戲結束或玩家按下 F12 時透過 webhook 自動將報告上傳至 Discord。該專案面向需要輕量級連線紀錄與遠端審核，而非核心層級強制執行的賽事主辦方與遊戲安全人員。
