UrnIt Anticheat — клиентский античит для Windows для игры Deadlock, который отслеживает игроков во время сессий и отправляет доказательства персоналу для проверки. Написан в основном на C++ со сборкой в Visual Studio и вспомогательным скриптом на Python; периодически собирает списки процессов, PNG-скриншоты окна игры, ввод с клавиатуры в активном окне и сведения об оборудовании, включая CPU и GPU. Помечает известные читерские процессы по настраиваемому списку (с опциональным парсингом форумов для обновления сигнатур), выявляет возможное использование макросов или ботов по дисперсии интервалов нажатий клавиш и автоматически загружает отчёты в Discord через webhook при выходе из игры или нажатии F12. Проект ориентирован на организаторов турниров и сотрудников игровой безопасности, которым нужно лёгкое логирование сессий и удалённая проверка, а не принудительное воздействие на уровне ядра.
