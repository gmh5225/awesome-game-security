UrnIt Anticheat は、ゲーム Deadlock 向けの Windows クライアントサイド アンチチート ツールで、プレイヤーのセッション中を監視し、証拠をスタッフに送信してレビューできるようにします。主に C++ で記述され、Visual Studio でビルドされ、Python のヘルパースクリプトも含み、定期的にプロセス一覧、ゲームウィンドウの PNG スクリーンショット、フォーカス中ウィンドウのキー入力、CPU や GPU などのハードウェア情報を取得します。設定可能なリストから既知のチートプロセスをフラグ付け（オプションでフォーラムスクレイピングによりシグネチャを更新）、キー入力のタイミング分散からマクロやボット使用の可能性を検出し、ゲーム終了時またはプレイヤーが F12 を押した際に Discord webhook 経由でレポートを自動アップロードします。カーネルレベルの強制ではなく、軽量なセッションログとリモートレビューを必要とするトーナメント主催者やゲームセキュリティ担当者を対象としています。
