UrnIt Anticheat is a Windows client-side anticheat tool for the game Deadlock that monitors players during sessions and sends evidence to staff for review. Written primarily in C++ with a Visual Studio build and a Python helper script, it periodically captures process lists, PNG screenshots of the game window, focused-window key input, and hardware details including CPU and GPU. It flags known cheat processes from a configurable list (with optional forum scraping to update signatures), detects possible macro or bot use from key timing variance, and uploads reports automatically to Discord via webhook when the game exits or the player presses F12. The project targets tournament organizers and game security staff who need lightweight session logging and remote review rather than kernel-level enforcement.
