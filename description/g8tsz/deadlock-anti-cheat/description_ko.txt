UrnIt Anticheat는 Deadlock 게임을 위한 Windows 클라이언트 측 안티치트 도구로, 플레이어 세션 중 모니터링하고 증거를 스태프에게 검토용으로 전송합니다. 주로 C++로 작성되었으며 Visual Studio 빌드와 Python 헬퍼 스크립트를 사용하며, 주기적으로 프로세스 목록, 게임 창 PNG 스크린샷, 포커스된 창의 키 입력, CPU 및 GPU를 포함한 하드웨어 정보를 캡처합니다. 구성 가능한 목록에서 알려진 치트 프로세스를 표시하고(선택적으로 포럼 스크래핑으로 시그니처 업데이트), 키 입력 타이밍 분산으로 매크로나 봇 사용 가능성을 감지하며, 게임 종료 시 또는 플레이어가 F12를 누르면 Discord webhook을 통해 보고서를 자동 업로드합니다. 커널 수준의 강제 실행이 아닌 경량 세션 로깅과 원격 검토가 필요한 토너먼트 주최자 및 게임 보안 담당자를 대상으로 합니다.
