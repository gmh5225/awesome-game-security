UrnIt Anticheat 是一款面向游戏 Deadlock 的 Windows 客户端反作弊工具，可在玩家会话期间进行监控，并将证据发送给工作人员审核。该项目主要使用 C++ 编写，采用 Visual Studio 构建，并附带 Python 辅助脚本，会定期采集进程列表、游戏窗口 PNG 截图、当前焦点窗口的按键输入，以及 CPU 和 GPU 等硬件信息。它会根据可配置列表标记已知作弊进程（可选通过论坛抓取更新特征），通过按键时间间隔方差检测可能的宏或机器人使用，并在游戏退出或玩家按下 F12 时通过 webhook 自动将报告上传至 Discord。该项目面向需要轻量级会话日志记录与远程审核，而非内核级强制执行的赛事组织者和游戏安全人员。
