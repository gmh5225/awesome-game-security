MenuForge는 Windows에서 Grand Theft Auto V용 게임 내 트레이너 스타일 오버레이 메뉴를 구축하기 위한 모듈형 C++ 스캐폴드로, 완성된 치트 메뉴가 아니라 즉시 쓸 수 있는 기반을 제공합니다. 레지스트리 기반 콘텐츠 API, 결정론적 내비게이션 상태 기계, DirectX 11과 Dear ImGui로 연결된 상태·렌더·입력·콘텐츠 계층을 구현합니다. 개발자는 의미 기반 테마 토큰, 폴백이 있는 JSON 로컬라이제이션, 크래시에 안전한 원자적 설정 영속화, 충돌 감지가 있는 런타임 키 재바인딩, 스택형 알림 토스트를 사용할 수 있습니다. 이 프로젝트는 GTA V 도구, 커스텀 트레이너 UI, 게임 내 메뉴 인젝션 실험을 위해 재사용 가능한 오버레이 프레임워크가 필요한 모더, 도구 제작자, 연구자를 대상으로 하며, 기본 제공 기능을 내놓는 것이 목적은 아닙니다.
