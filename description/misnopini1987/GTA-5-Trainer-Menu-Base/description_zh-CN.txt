MenuForge 是一款模块化的 C++ 脚手架，用于在 Windows 上为《Grand Theft Auto V》构建游戏内训练器风格的叠加菜单，提供现成的底层框架而非成品作弊菜单。它实现了由注册表驱动的内容 API、确定性的导航状态机，以及通过 DirectX 11 与 Dear ImGui 衔接的状态、渲染、输入与内容分层架构。开发者可获得语义化主题标记、带回退的基于 JSON 的本地化、崩溃安全的原子配置持久化、带冲突检测的运行时按键重绑定，以及堆叠式通知 Toast。本项目面向需要可复用叠加框架的模组作者、工具开发者与安全研究人员，用于 GTA V 工具链、自定义训练器界面及游戏内菜单注入实验，而非开箱即用的功能交付。
