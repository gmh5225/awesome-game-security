MenuForge is a modular C++ scaffold for building in-game trainer-style overlay menus for Grand Theft Auto V on Windows, providing ready-made plumbing instead of a finished cheat menu. It implements a registry-driven content API, a deterministic navigation state machine, and separate state, render, input, and content layers wired through DirectX 11 and Dear ImGui. Developers get semantic theme tokens, JSON-based localization with fallbacks, crash-safe atomic configuration persistence, runtime key rebinding with conflict detection, and stacked notification toasts. The project targets modders, tool authors, and researchers who need a reusable overlay framework for GTA V tooling, custom trainer UIs, and experiments around in-game menu injection rather than shipping features out of the box.
