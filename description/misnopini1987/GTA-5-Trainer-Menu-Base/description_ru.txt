MenuForge — модульный каркас на C++ для создания внутриигровых оверлей-меню в стиле trainer для Grand Theft Auto V в Windows; он даёт готовую инфраструктуру, а не готовое чит-меню. Реализованы API контента на основе реестра, детерминированный конечный автомат навигации и раздельные слои состояния, отрисовки, ввода и контента, связанные через DirectX 11 и Dear ImGui. Разработчикам доступны семантические токены темы, локализация на JSON с запасными вариантами, устойчивая к сбоям атомарная персистентность конфигурации, переназначение клавиш во время выполнения с обнаружением конфликтов и стековые toast-уведомления. Проект ориентирован на моддеров, авторов утилит и исследователей, которым нужен переиспользуемый оверлей-фреймворк для инструментов GTA V, пользовательских UI trainer и экспериментов с инъекцией внутриигровых меню, а не на поставку готовых функций из коробки.
