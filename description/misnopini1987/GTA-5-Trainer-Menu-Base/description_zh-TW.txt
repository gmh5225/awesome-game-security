MenuForge 是一款模組化的 C++ 腳手架，用於在 Windows 上為《Grand Theft Auto V》建構遊戲內訓練器風格的疊加選單，提供現成的底層框架而非成品作弊選單。它實作了由登錄檔驅動的內容 API、確定性的導覽狀態機，以及透過 DirectX 11 與 Dear ImGui 銜接的狀態、渲染、輸入與內容分層架構。開發者可獲得語意化主題標記、具備回退的 JSON 在地化、崩潰安全的原子組態持久化、具衝突偵測的執行階段按鍵重新綁定，以及堆疊式通知 Toast。本專案面向需要可重用疊加框架的模組作者、工具開發者與研究人員，用於 GTA V 工具鏈、自訂訓練器介面及遊戲內選單注入實驗，而非開箱即用的功能交付。
