MenuForge は、Windows 上の Grand Theft Auto V 向けにゲーム内トレーナー風オーバーレイメニューを構築するためのモジュラーな C++ スキャフォールドで、完成したチートメニューではなく、すぐ使える基盤を提供します。レジストリ駆動のコンテンツ API、決定論的なナビゲーション状態機械、DirectX 11 と Dear ImGui で接続された状態・描画・入力・コンテンツの各レイヤーを実装しています。開発者にはセマンティックなテーマトークン、フォールバック付き JSON ローカライゼーション、クラッシュに強いアトミックな設定の永続化、競合検出付きランタイムキーの再バインド、積み重ね型の通知トーストが得られます。本プロジェクトは、GTA V 向けツール、カスタムトレーナー UI、ゲーム内メニューインジェクションの実験向けに再利用可能なオーバーレイフレームワークを必要とするモッダー、ツール作者、研究者を対象としており、箱から出してすぐ使える機能の提供は目的としていません。
