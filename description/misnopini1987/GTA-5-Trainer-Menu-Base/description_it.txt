MenuForge è un impalcatura C++ modulare per costruire menu overlay in stile trainer in-game per Grand Theft Auto V su Windows, fornendo infrastruttura pronta all'uso invece di un menu cheat finito. Implementa un'API dei contenuti guidata da registro, una macchina a stati di navigazione deterministica e layer separati per stato, rendering, input e contenuto collegati tramite DirectX 11 e Dear ImGui. Gli sviluppatori ottengono token di tema semantici, localizzazione basata su JSON con fallback, persistenza atomica della configurazione resistente ai crash, ribinding dei tasti a runtime con rilevamento dei conflitti e toast di notifica impilati. Il progetto è rivolto a modder, autori di tool e ricercatori che necessitano di un framework overlay riutilizzabile per tooling GTA V, UI trainer personalizzate e sperimenti sull'iniezione di menu in-game, piuttosto che consegnare funzionalità pronte all'uso.
