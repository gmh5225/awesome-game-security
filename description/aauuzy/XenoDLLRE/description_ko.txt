XenoDLLRE는 방어적 연구 저장소로, Xeno Roblox 스크립트 실행기(v1.3.65)를 정적으로 리버스 엔지니어링하고 네이티브 DLL이 어떻게 부착되며 사용자 스크립트를 실행하고 탐지 가능한 흔적을 남기는지 문서화합니다. 분석에는 en-us 로케일 ModuleScript의 바이트코드 교체, localhost HTTP 제어 평면, XOR 및 zstd로 보호된 내장 리소스, Luau 컴파일 워크플로가 포함되며, 보안 및 안티치트 팀을 위한 증거 등급별 결과와 아키텍처 설명이 담깁니다. Python 유틸리티는 DLL 샘플 프로파일링, 내장 리소스 복호화, 빌드 비교, 점수 기반 파일 스캐너 실행과 함께 동일한 정적 분석에서 도출한 YARA 규칙을 제공합니다. 본 프로젝트는 Windows에서 게임 보안, 안티치트, 리버스 엔지니어링 용도를 위한 것이며 탐지 및 대응 지침을 문서화하며, 실행기 기능을 배포하거나 개선하지 않습니다.
