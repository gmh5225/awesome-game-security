XenoDLLRE 是一个防御性研究仓库，对 Xeno Roblox 脚本执行器（v1.3.65）进行静态逆向工程，并记录其原生 DLL 如何附加、运行用户脚本以及留下可检测的痕迹。分析涵盖 en-us 区域设置 ModuleScript 的字节码替换、本地 HTTP 控制平面、经 XOR 与 zstd 保护的嵌入资源，以及 Luau 编译工作流，并提供面向安全与反作弊团队的证据分级结论与架构说明。Python 工具可对 DLL 样本进行画像、解密嵌入资源、比较各构建版本，并运行基于评分的文件扫描器，同时配套源自同一静态分析的 YARA 规则。本项目面向 Windows 上的游戏安全、反作弊与逆向工程用途，记录检测与对策指南，不提供也不改进执行器功能。
