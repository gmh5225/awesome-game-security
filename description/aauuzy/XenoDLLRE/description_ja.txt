XenoDLLRE は防御目的の研究リポジトリで、Xeno Roblox スクリプト実行環境（v1.3.65）を静的にリバースエンジニアリングし、ネイティブ DLL の付加方法、ユーザースクリプトの実行、検出可能な痕跡の残し方を文書化しています。分析には en-us ロケール ModuleScript のバイトコード差し替え、localhost HTTP コントロールプレーン、XOR と zstd で保護された埋め込みリソース、Luau コンパイルワークフローが含まれ、セキュリティおよびアンチチートチーム向けの証拠に基づく所見とアーキテクチャ解説があります。Python ユーティリティは DLL サンプルのプロファイリング、埋め込みリソースの復号、ビルド比較、スコアベースのファイルスキャナの実行に加え、同一の静的解析から導出した YARA ルールを併用します。本プロジェクトは Windows 上のゲームセキュリティ、アンチチート、リバースエンジニアリング向けであり、検出と対策のガイダンスを記載するもので、実行環境の配布や機能改善は行いません。
