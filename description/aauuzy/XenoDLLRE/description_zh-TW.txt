XenoDLLRE 是一個防禦性研究儲存庫，對 Xeno Roblox 腳本執行器（v1.3.65）進行靜態逆向工程，並記錄其原生 DLL 如何附加、執行使用者腳本以及留下可偵測的痕跡。分析涵蓋 en-us 地區設定 ModuleScript 的位元組碼替換、本機 HTTP 控制平面、經 XOR 與 zstd 保護的嵌入資源，以及 Luau 編譯工作流程，並提供面向安全與反作弊團隊的證據分級發現與架構說明。Python 工具可對 DLL 樣本進行剖析、解密嵌入資源、比較各建置版本，並執行以評分為基礎的檔案掃描器，同時搭配源自同一靜態分析的 YARA 規則。本專案面向 Windows 上的遊戲安全、反作弊與逆向工程用途，記錄偵測與對策指引，不提供也不改進執行器功能。
