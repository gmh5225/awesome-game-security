XenoDLLRE is a defensive research repository that statically reverse engineers the Xeno Roblox script executor (v1.3.65) and documents how its native DLL attaches, runs user scripts, and leaves detectable artifacts. The analysis covers bytecode replacement of the en-us locale ModuleScript, a localhost HTTP control plane, XOR-and-zstd protected embedded resources, and Luau compilation workflows, with evidence-graded findings and architecture write-ups aimed at security and anti-cheat teams. Python utilities profile DLL samples, decrypt embedded resources, compare builds, and run a score-based file scanner alongside YARA rules derived from the same static work. The project is intended for game security, anti-cheat, and reverse engineering use on Windows; it documents detection and countermeasure guidance and does not ship or improve executor functionality.
