XenoDLLRE — исследовательский репозиторий оборонительной направленности: в нём статически разбирается исполнитель скриптов Xeno для Roblox (v1.3.65) и описывается, как его нативная DLL подключается, запускает пользовательские скрипты и оставляет обнаруживаемые следы. Анализ охватывает подмену байткода ModuleScript локали en-us, плоскость управления по HTTP на localhost, встроенные ресурсы, защищённые XOR и zstd, а также рабочие процессы компиляции Luau; приводятся выводы с оценкой доказательности и архитектурные описания для команд безопасности и античита. Утилиты на Python профилируют образцы DLL, расшифровывают встроенные ресурсы, сравнивают сборки и запускают файловый сканер на основе баллов наряду с правилами YARA, полученными из того же статического разбора. Проект предназначен для безопасности игр, античита и реверс-инжиниринга в Windows; в нём документируются рекомендации по обнаружению и противодействию, без поставки или улучшения функциональности исполнителя.
