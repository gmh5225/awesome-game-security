このプロジェクトは、Frank D. Luna 著『Introduction to 3D Game Programming with DirectX 11』のサンプルソースコードを見直し、現代化したものです。書籍の学習進度に沿いながら、現在のツールチェーンで例がコンパイル・実行できるよう更新されています。インラインモジュールを用いたモダン C++ で主に記述され、D3DX11 や Effects11 などの非推奨 DirectX 依存関係を、標準 Direct3D 11 API、カスタム ComPtr ラッパー、D3DReadFileToBlob による明示的な HLSL シェーダーコンパイルに置き換えています。リポジトリには、DirectXMath の基礎、Direct3D 初期化、ジオメトリレンダリング、ライティングをカバーする動作デモが含まれ、レガシー FX シェーダーを標準 HLSL へ変換する作業も継続中です。DirectX 11 レンダリングパイプライン、グラフィックスプログラミングの概念、ゲームエンジンやそのグラフィックスサブシステムの分析・操作時に遭遇する低レベル構造について、明確かつ最新の参照資料を必要とする開発者やセキュリティ研究者向けです。
