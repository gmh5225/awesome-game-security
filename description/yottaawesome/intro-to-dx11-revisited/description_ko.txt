이 프로젝트는 Frank D. Luna의 『Introduction to 3D Game Programming with DirectX 11』에 수록된 샘플 소스 코드를 재검토하고 현대화하여, 책의 학습 흐름을 유지하면서 현재 툴체인에서 예제가 컴파일되고 실행되도록 업데이트했습니다. 인라인 모듈을 사용하는 모던 C++로 주로 작성되었으며, D3DX11 및 Effects11 같은 더 이상 사용되지 않는 DirectX 의존성을 표준 Direct3D 11 API, 사용자 정의 ComPtr 래퍼, D3DReadFileToBlob를 통한 명시적 HLSL 셰이더 컴파일로 대체합니다. 저장소에는 DirectXMath 기초, Direct3D 초기화, 지오메트리 렌더링, 조명을 다루는 동작하는 데모가 포함되어 있으며, 레거시 FX 셰이더를 표준 HLSL로 변환하는 작업도 진행 중입니다. DirectX 11 렌더링 파이프라인, 그래픽 프로그래밍 개념, 게임 엔진 및 그래픽 하위 시스템을 분석하거나 상호작용할 때 흔히 접하는 저수준 구조에 대한 명확하고 최신의 참고 자료가 필요한 개발자와 보안 연구자를 위한 프로젝트입니다.
