Este proyecto revisita y moderniza el código fuente de ejemplo del libro Introduction to 3D Game Programming with DirectX 11 de Frank D. Luna, actualizándolo para que los ejemplos compilen y se ejecuten con las cadenas de herramientas actuales, manteniendo la progresión didáctica del libro. Escrito principalmente en C++ moderno con módulos inline, sustituye dependencias obsoletas de DirectX como D3DX11 y Effects11 por las API estándar de Direct3D 11, un wrapper ComPtr personalizado y la compilación explícita de shaders HLSL mediante D3DReadFileToBlob. El repositorio incluye demos funcionales que cubren los fundamentos de DirectXMath, la inicialización de Direct3D, el renderizado de geometría y la iluminación, con trabajo en curso para convertir shaders FX heredados a HLSL estándar. Está dirigido a desarrolladores e investigadores de seguridad que necesitan una referencia clara y actualizada sobre las canalizaciones de renderizado de DirectX 11, los conceptos de programación gráfica y las estructuras de bajo nivel que se encuentran comúnmente al analizar o interactuar con motores de juego y sus subsistemas gráficos.
