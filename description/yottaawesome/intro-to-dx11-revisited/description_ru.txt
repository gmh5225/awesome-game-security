Этот проект пересматривает и модернизирует примеры исходного кода из книги Frank D. Luna «Introduction to 3D Game Programming with DirectX 11», обновляя их так, чтобы примеры компилировались и работали с современными инструментами, сохраняя при этом учебную прогрессию книги. Написан преимущественно на современном C++ с использованием inline-модулей; устаревшие зависимости DirectX, такие как D3DX11 и Effects11, заменены стандартными API Direct3D 11, пользовательской обёрткой ComPtr и явной компиляцией шейдеров HLSL через D3DReadFileToBlob. Репозиторий содержит рабочие демонстрации, охватывающие основы DirectXMath, инициализацию Direct3D, рендеринг геометрии и освещение; ведётся работа по преобразованию устаревших шейдеров FX в стандартный HLSL. Предназначен для разработчиков и исследователей безопасности, которым нужен понятный и актуальный справочник по конвейерам рендеринга DirectX 11, концепциям графического программирования и низкоуровневым структурам, часто встречающимся при анализе или взаимодействии с игровыми движками и их графическими подсистемами.
