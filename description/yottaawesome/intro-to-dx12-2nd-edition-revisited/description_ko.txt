이 프로젝트는 Frank Luna의 'Introduction to 3D Game Programming with DirectX 12' 2판 샘플 코드를 현대화하여 재구현한 것으로, 전체 장별 데모 스위트를 더 쉽게 읽고 빌드할 수 있도록 재구성되었습니다. 주로 C++로 작성되었으며, C++20 모듈, HLSL 셰이더, vcpkg, DirectX 12 Agility SDK, DirectX Toolkit, Dear ImGui를 기반으로 한 Visual Studio 프로젝트를 사용합니다. 샘플은 DirectX 수학과 초기화부터 조명, 텍스처링, 컴퓨트 셰이더, 테셀레이션, 그림자, SSAO, 스킨 메시, 지형, 파티클, 하이브리드 레이 트레이싱까지 그래픽스 파이프라인 전체를 다룹니다. 게임 그래픽스 내부 구조나 관련 보안 연구를 학습하는 개발자와 리버스 엔지니어를 위해, DirectX 12 게임이 렌더링, GPU 리소스, 셰이더 기법을 어떻게 구성하는지 더 명확한 참고 자료를 제공하는 것을 목적으로 합니다.
