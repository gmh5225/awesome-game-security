This project is a modernized reimplementation of the sample code from Frank Luna's second edition of Introduction to 3D Game Programming with DirectX 12, reorganized to make the full chapter-by-chapter demo suite easier to read and build. It is written primarily in C++ using C++20 modules, HLSL shaders, and Visual Studio projects backed by vcpkg, the DirectX 12 Agility SDK, DirectX Toolkit, and Dear ImGui. The samples cover the complete graphics pipeline from DirectX math and initialization through lighting, texturing, compute shaders, tessellation, shadows, SSAO, skinned meshes, terrain, particles, and hybrid ray tracing. It is intended for developers and reverse engineers who want a clearer reference for how DirectX 12 games structure rendering, GPU resources, and shader techniques when studying game graphics internals or related security research.
