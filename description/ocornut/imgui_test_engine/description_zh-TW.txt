Dear ImGui Test Engine 是針對 Dear ImGui，以及將其嵌入工具與使用者介面的應用程式、遊戲或引擎之自動化與測試系統。它主要以 C++ 實作，作為函式庫並附帶配套測試套件與範例應用程式；透過向 ImGui 輸入滑鼠、鍵盤與遊戲手把訊號以模擬終端使用者行為，讓測試能操作小工具、選單與導覽，並在您自己的程式碼中驗證結果。執行器可在一般視窗或無介面（headless）模式下供自動化建置使用，支援快速執行或較慢、較接近人類的節奏，並可擷取螢幕截圖與影片；選配效能工具可搭配 ImPlot 風格繪圖，以比較各次執行的時間。主要受眾是需要對重度採用 ImGui 的除錯面板、編輯器與引擎內工具，進行迴歸、整合或冒煙測試，以及建立腳本化示範或擷取流程的開發者。
