Dear ImGui Test Engine 是面向 Dear ImGui 以及将其嵌用于工具和 UI 的应用、游戏或引擎的自动化与测试系统。它主要由 C++ 实现，以库的形式提供，并附带配套的测试套件与示例应用；通过向 ImGui 注入鼠标、键盘与手柄输入来模拟最终用户行为，使测试能够驱动控件、菜单与导航，并在你的代码中断言结果。运行器可在常规窗口或无界面（headless）模式下用于自动化构建，支持快速执行或较慢的类人节奏，并可截取截图与录屏；可选的性能工具可与 ImPlot 风格的图表配合，用于比较各次运行的耗时。主要面向希望在重度使用 ImGui 的调试面板、编辑器与引擎内工具流程中开展回归、集成或冒烟测试，以及脚本化演示或采集流水线的开发者。
