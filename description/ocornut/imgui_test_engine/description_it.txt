Dear ImGui Test Engine è un sistema di automazione e test per Dear ImGui e per applicazioni, giochi o motori che lo incorporano per strumenti e interfacce utente. È realizzato principalmente in C++ come libreria insieme a una suite di test complementare e app di esempio, e simula il comportamento dell'utente finale inviando input di mouse, tastiera e gamepad a ImGui, così i test possono guidare widget, menu e navigazione verificando i risultati nel proprio codice. Il runner può operare in una finestra normale o headless per build automatizzate, supporta esecuzione veloce o un ritmo più lento simile a quello umano e può acquisire screenshot e video; uno strumento di performance opzionale si integra con grafici in stile ImPlot per confrontare i tempi tra le esecuzioni. Il caso d'uso principale riguarda sviluppatori che cercano test di regressione, integrazione o smoke —nonché demo scriptate o pipeline di cattura— per pannelli di debug, editor e strumentazione in-engine con forte uso di ImGui.
