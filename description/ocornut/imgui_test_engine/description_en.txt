Dear ImGui Test Engine is an automation and testing system for Dear ImGui and for applications, games, or engines that embed it for tools and user interfaces. It is built mainly in C++ as a library plus companion test-suite and example apps, and it simulates end-user behavior by feeding mouse, keyboard, and gamepad input into ImGui so tests can drive widgets, menus, and navigation while asserting results in your own code. The runner can operate in a normal window or headless for automated builds, supports fast execution or slower human-like pacing, and can capture screenshots and videos; an optional performance tool works with ImPlot-style plotting to compare timing across runs. Its primary use case is developers who want regression, integration, or smoke tests—and scripted demos or capture pipelines—for ImGui-heavy debug panels, editors, and in-engine tooling.
