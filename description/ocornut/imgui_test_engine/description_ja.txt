Dear ImGui Test Engine は、Dear ImGui と、ツールや UI に組み込むアプリケーション、ゲーム、エンジン向けの自動化・テストシステムです。C++ を主に用いたライブラリに加え、付属のテストスイートとサンプルアプリで構成され、マウス、キーボード、ゲームパッド入力を ImGui に送り込むことでエンドユーザーの操作をシミュレートし、ウィジェット、メニュー、ナビゲーションを駆動しながら、独自コードで結果を検証できます。ランナーは通常のウィンドウまたはヘッドレスで自動ビルド向けに動作し、高速実行と人間に近いゆったりしたペースの両方に対応し、スクリーンショットや動画のキャプチャも可能です。オプションのパフォーマンスツールは ImPlot スタイルのプロットと連携し、実行ごとのタイミングを比較できます。主な用途は、ImGui を多用するデバッグパネル、エディタ、エンジン内ツールに対する回帰・統合・スモークテスト、およびスクリプト化したデモやキャプチャパイプラインを求める開発者向けです。
