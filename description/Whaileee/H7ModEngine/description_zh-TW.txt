H7ModEngine 是針對 64 位元 Windows 版《魔法門之英雄無敵 VII》（v2.2.1）的 Lua 5.4 模組引擎。它以 dinput8.dll 代理形式注入至遊戲可執行檔旁，在執行時於記憶體中發現 Unreal Engine 3 內部結構，無需修改遊戲檔案或二進位。C++20 核心提供 UE3 反射、函式掛鉤與 Lua 綁定，使模組可讀寫遊戲物件、呼叫 UnrealScript 函式、攔截或覆寫呼叫，並透過事件與計時器配合熱重載及遊戲內 Mods 選單使用。附帶的範例模組與文件展示玩法調整；逆向輔助如物件傾印與特徵碼掃描則便於探索正式版 UE3 建置。面向希望取得可腳本化控制並對商業 UE3 作品具備深度可見性的單機模組開發者與研究人員。
