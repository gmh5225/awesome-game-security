H7ModEngine は、64 ビット Windows 版 Might and Magic Heroes VII（v2.2.1）向けの Lua 5.4 モッドエンジンです。ゲーム実行ファイルの横に dinput8.dll プロキとして注入し、ゲームファイルやバイナリを変更せずに実行時にメモリ上で Unreal Engine 3 の内部を探索します。C++20 コアは UE3 リフレクション、関数フック、Lua バインディングを提供し、モッドがゲームオブジェクトの読み書き、UnrealScript 関数の呼び出し、呼び出しの傍受や上書き、ホットリロードとゲーム内 Mods メニュー付きのイベント・タイマーを利用できるようにします。同梱のサンプルモッドとドキュメントはゲームプレイ調整の例を示し、オブジェクトダンプやシグネチャスキャンなどのリバースエンジニアリング支援は出荷版 UE3 ビルドの調査を助けます。商用 UE3 タイトルに対するスクリプト可能な制御と深い可視性を求めるシングルプレイ向けモッド開発者と研究者向けです。
