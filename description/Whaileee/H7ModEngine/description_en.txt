H7ModEngine is a Lua 5.4 modding engine for the 64-bit Windows release of Might and Magic Heroes VII (v2.2.1). It injects as a dinput8.dll proxy beside the game executable and discovers Unreal Engine 3 internals in memory at runtime without modifying game files or binaries. The C++20 core provides UE3 reflection, function hooks, and Lua bindings so mods can read and write game objects, call UnrealScript functions, intercept or override calls, and use events and timers with hot reload and an in-game Mods menu. Bundled example mods and documentation illustrate gameplay tweaks, while reverse-engineering helpers such as object dumps and signature scanning support exploring the shipped UE3 build. It is aimed at single-player mod developers and researchers who want scriptable control and deep visibility into a commercial UE3 title.
