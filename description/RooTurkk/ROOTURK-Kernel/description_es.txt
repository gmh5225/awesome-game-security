ROOTURK Kernel es un proyecto de kernel Android personalizado que incluye el código fuente completo del kernel Linux junto con empaquetado flashable AnyKernel3, documentación de compilación y una configuración rooturk dedicada. El árbol se basa en Android Generic Kernel Image (GKI) con definiciones ABI aarch64 para los principales proveedores de SoC, incluidos Qualcomm, MediaTek y Xiaomi, y está desarrollado principalmente en C con scripts AnyKernel basados en shell y reglas de compilación Bazel. Incluye guías de instalación y compilación, además de documentación relacionada con Wi-Fi para compilar e implementar una imagen de arranque de reemplazo. El proyecto está dirigido a desarrolladores de kernel Android e investigadores de seguridad móvil que necesitan una plataforma de bajo nivel con root para modificación de dispositivos, ingeniería inversa y eludir protecciones de juegos móviles que dependen de comprobaciones de integridad del kernel.
