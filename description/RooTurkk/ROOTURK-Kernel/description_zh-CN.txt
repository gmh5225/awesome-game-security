ROOTURK Kernel 是一个自定义 Android 内核项目，提供完整的 Linux 内核源码、AnyKernel3 可刷写打包方案、构建文档以及专用的 rooturk 配置。该项目基于 Android 通用内核镜像（GKI），包含针对高通、联发科和小米等主要 SoC 厂商的 aarch64 ABI 定义，主要使用 C 语言编写，并配合基于 shell 的 AnyKernel 脚本和 Bazel 构建规则进行构建。项目还提供了安装与构建指南，以及用于编译和部署替换 boot 镜像的 Wi-Fi 相关文档。该项目面向 Android 内核开发者和移动安全研究人员，为需要已 root 的低层级平台以进行设备修改、逆向工程以及绕过依赖内核完整性检查的移动游戏保护的用户而设计。
