ROOTURK Kernel — это пользовательский проект ядра Android, который поставляет полный исходный код ядра Linux вместе с прошиваемой упаковкой AnyKernel3, документацией по сборке и специальной конфигурацией rooturk. Дерево основано на Android Generic Kernel Image (GKI) с определениями ABI aarch64 для основных производителей SoC, включая Qualcomm, MediaTek и Xiaomi, и в основном написано на C с использованием shell-скриптов AnyKernel и правил сборки Bazel. В проект входят руководства по установке и сборке, а также документация, связанная с Wi-Fi, для компиляции и развертывания замещающего boot-образа. Проект предназначен для разработчиков ядра Android и исследователей мобильной безопасности, которым нужна рутированная платформа низкого уровня для модификации устройств, реверс-инжиниринга и обхода защит мобильных игр, основанных на проверках целостности ядра.
