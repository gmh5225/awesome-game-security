ROOTURK Kernel は、完全な Linux カーネルソースと AnyKernel3 のフラッシュ可能なパッケージング、ビルドドキュメント、専用の rooturk 設定を同梱するカスタム Android カーネルプロジェクトです。このツリーは Android Generic Kernel Image（GKI）をベースとしており、Qualcomm、MediaTek、Xiaomi など主要 SoC ベンダー向けの aarch64 ABI 定義を含み、主に C 言語で記述され、シェルベースの AnyKernel スクリプトと Bazel ビルドルールで構築されます。インストールおよびビルドガイドに加え、代替 boot イメージのコンパイルとデプロイのための Wi-Fi 関連ドキュメントも含まれます。このプロジェクトは、デバイス改変、リバースエンジニアリング、カーネル整合性チェックに依存するモバイルゲーム保護の回避のために、root 化された低レベルプラットフォームを必要とする Android カーネル開発者およびモバイルセキュリティ研究者を対象としています。
