ROOTURK Kernel 是一個自訂 Android 核心專案，提供完整的 Linux 核心原始碼、AnyKernel3 可刷寫封裝方案、建置文件以及專用的 rooturk 設定。此專案樹基於 Android 通用核心映像（GKI），包含針對高通、聯發科和小米等主要 SoC 供應商的 aarch64 ABI 定義，主要以 C 語言編寫，並搭配基於 shell 的 AnyKernel 指令碼和 Bazel 建置規則進行建置。專案還提供了安裝與建置指南，以及用於編譯和部署替換 boot 映像的 Wi-Fi 相關文件。此專案面向 Android 核心開發者和行動安全研究人員，為需要已 root 的底層平台以進行裝置修改、逆向工程以及繞過依賴核心完整性檢查的行動遊戲保護的使用者而設計。
