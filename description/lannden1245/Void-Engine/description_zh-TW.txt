Void Engine 是一款 Godot 編輯器外掛，整合了自訂節點與實用工具，用於建構具備內建防護與效能工具的多人遊戲。它以 GDScript 撰寫，並提供 WhiteVoid AntiCheat 自動載入模組，其他元件可呼叫該模組以維護遊戲模式完整性；同時包含 VoidNet 網路堆疊，支援 ENet 與基於 Firebase 的 WebRTC，可選加密、多區域回退、大廳與玩家同步。其他模組涵蓋基於距離的紋理串流、動態解析度與反鋸齒管理、程序化房間生成、著色器編譯，以及 VoidForge 等編輯器端設計工具。此專案面向希望取得整合反作弊鉤子、安全線上玩法，以及面向生產的渲染與網路功能、而無需分別組裝各系統的 Godot 開發者。
