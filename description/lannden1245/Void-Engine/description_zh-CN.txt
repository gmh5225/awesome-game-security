Void Engine 是一款 Godot 编辑器插件，集成了自定义节点与实用工具，用于构建具备内置防护与性能工具的多人游戏。它使用 GDScript 编写，并提供 WhiteVoid AntiCheat 自动加载模块，其他组件可调用该模块以维护游戏模式完整性；同时包含 VoidNet 网络栈，支持 ENet 与基于 Firebase 的 WebRTC，可选加密、多区域回退、大厅与玩家同步。其他模块涵盖基于距离的纹理流式传输、动态分辨率与抗锯齿管理、程序化房间生成、着色器编译，以及 VoidForge 等编辑器端设计工具。该项目面向希望获得集成反作弊钩子、安全在线玩法，以及面向生产的渲染与网络功能、而无需分别拼装各系统的 Godot 开发者。
