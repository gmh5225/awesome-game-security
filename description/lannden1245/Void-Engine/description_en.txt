Void Engine is a Godot editor plugin that bundles custom nodes and utilities for building multiplayer games with built-in protection and performance tooling. It is written in GDScript and ships a WhiteVoid AntiCheat autoload that other components can query to enforce game-mode integrity, alongside a VoidNet networking stack supporting ENet and Firebase-backed WebRTC with optional encryption, multi-region fallback, lobbies, and player synchronization. Additional modules cover distance-based texture streaming, dynamic resolution and anti-aliasing management, procedural room generation, shader compilation, and editor-side design tools such as VoidForge. The project targets Godot developers who want integrated anti-cheat hooks, secure online play, and production-oriented rendering and networking features without assembling each system separately.
