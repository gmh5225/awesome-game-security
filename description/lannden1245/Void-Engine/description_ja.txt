Void Engine は、組み込みの保護機能とパフォーマンスツールを備えたマルチプレイヤーゲーム構築のためのカスタムノードとユーティリティをまとめた Godot エディタープラグインです。GDScript で書かれており、WhiteVoid AntiCheat オートロードを同梱しており、他のコンポーネントがゲームモードの整合性を強制するために問い合わせ可能です。VoidNet ネットワークスタックは ENet と Firebase 連携の WebRTC をサポートし、暗号化、マルチリージョンフォールバック、ロビー、プレイヤー同期をオプションで提供します。追加モジュールには、距離ベースのテクスチャストリーミング、動的解像度とアンチエイリアス管理、手続き型ルーム生成、シェーダーコンパイル、VoidForge などのエディター側デザインツールが含まれます。本プロジェクトは、各システムを個別に組み立てることなく、統合されたアンチチートフック、安全なオンラインプレイ、本番向けのレンダリングとネットワーク機能を求める Godot 開発者を対象としています。
