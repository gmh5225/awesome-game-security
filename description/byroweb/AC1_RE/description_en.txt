AC1_RE is a reverse-engineering reference and tooling project for the 1997 PlayStation title Armored Core, focused on the North American SLUS-01323 (v1.1) build. It documents file formats, the mission and level loading pipeline, text and entity systems, combat physics, and the mission script virtual machine, backed by extensive write-ups and RAM and disc layout references. Python utilities extract and repack disc containers, decode geometry and mission data, and reinject rebuilt assets, while C behavioral models and MIPS patches verify subsystem behavior against extracted data. Ghidra scripts and shell pipelines automate overlay import, decompilation, and cross-reference work alongside DuckStation save-state helpers for live analysis. The repository ships only original documentation and code and is intended for interoperability research, education, and modding such as mission editing and localization, using a legally owned copy of the game.
