LinoAC is an open-source Minecraft anti-cheat and staff moderation plugin for Spigot and Paper servers on recent 1.21.x through 26.x releases. Written in Java, it uses PacketEvents for packet-rate and timing analysis alongside modular movement, combat, block, and inventory heuristics such as speed, flight, reach, placement abuse, and fast-break detection. Staff get clickable alerts, violation profiles, persistent punishment waves, audit logs, freeze and teleport tools, and a configurable per-check buffer and punishment pipeline. It targets server operators and anti-cheat developers who want a lightweight, telemetry-free alternative for securing multiplayer survival and minigame environments, with optional Discord webhooks, PlaceholderAPI integration, and a cancellable event API for custom enforcement.
