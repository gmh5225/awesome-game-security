LinoAC 是一款面向 Spigot 与 Paper 服务器、支持近期 1.21.x 至 26.x 版本的开源 Minecraft 反作弊与管理员管理插件。采用 Java 编写，借助 PacketEvents 进行封包速率与时序分析，并配合模块化的移动、战斗、方块与物品栏启发式检测，涵盖加速、飞行、攻击距离、放置滥用与快速破坏等。管理员可使用可点击告警、违规档案、持久化处罚波次、审计日志、冻结与传送工具，以及可配置的每项检测缓冲与处罚流水线。它面向希望用轻量、无遥测方案保护多人生存与小游戏的服主与反作弊开发者，并可选 Discord Webhook、PlaceholderAPI 集成及可取消的事件 API 以实现自定义处置逻辑。
