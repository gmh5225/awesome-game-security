LinoAC は、Spigot および Paper サーバー向けの、1.21.x から 26.x 系の最近のリリースに対応したオープンソースの Minecraft 反チートおよびスタッフ管理プラグインです。Java で書かれ、PacketEvents によるパケットレートとタイミング解析に加え、移動・戦闘・ブロック・インベントリ向けのモジュール式ヒューリスティクス（スピード、飛行、リーチ、設置悪用、早掘り検知など）を組み合わせます。スタッフ向けにクリック可能なアラート、違反プロファイル、永続的な処罰ウェーブ、監査ログ、フリーズおよびテレポートツール、チェックごとに設定可能なバッファと処罰パイプラインを提供します。軽量でテレメトリを送らない代替手段でマルチプレイサバイバルやミニゲーム環境を守りたいサーバー運営者や反チート開発者を対象とし、任意で Discord Webhook、PlaceholderAPI 連携、カスタム制御用のキャンセル可能なイベント API も利用できます。
