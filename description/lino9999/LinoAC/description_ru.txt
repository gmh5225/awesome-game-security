LinoAC — это плагин с открытым исходным кодом для античита в Minecraft и модерации персонала на серверах Spigot и Paper для недавних релизов от 1.21.x до 26.x. Написан на Java, использует PacketEvents для анализа частоты и тайминга пакетов, а также модульные эвристики движения, боя, блоков и инвентаря: скорость, полёт, дистанция удара, злоупотребление установкой блоков и быстрое разрушение. Персонал получает кликабельные оповещения, профили нарушений, постоянные волны наказаний, журналы аудита, инструменты заморозки и телепортации и настраиваемый буфер и конвейер наказаний для каждой проверки. Ориентирован на администраторов серверов и разработчиков античита, которым нужна лёгкая альтернатива без телеметрии для защиты мультиплеерного выживания и мини-игр, с опциональными Discord webhooks, интеграцией PlaceholderAPI и отменяемым API событий для пользовательского применения санкций.
