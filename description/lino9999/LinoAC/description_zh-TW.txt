LinoAC 是一款面向 Spigot 與 Paper 伺服器、支援近期 1.21.x 至 26.x 版本的開源 Minecraft 反作弊與管理員管理外掛。以 Java 撰寫，透過 PacketEvents 進行封包速率與時序分析，並搭配模組化的移動、戰鬥、方塊與物品欄啟發式偵測，涵蓋加速、飛行、攻擊距離、放置濫用與快速破壞等。管理員可使用可點擊告警、違規檔案、持久化處罰波次、稽核日誌、凍結與傳送工具，以及可設定的每項檢測緩衝與處罰管線。它面向希望以輕量、無遙測方案保護多人生存與小遊戲的服主與反作弊開發者，並可選 Discord Webhook、PlaceholderAPI 整合及可取消的事件 API 以實現自訂處置邏輯。
