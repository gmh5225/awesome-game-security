ACF is a modular, server-authoritative anti-cheat framework for Roblox games that centralizes detection lifecycle, configuration, player sessions, scheduling, and bounded evidence storage so individual detectors only implement their own logic. It is written in Luau and ships with built-in modules for movement and physics checks, combat validation, behavioral statistics, and RemoteEvent protection via schema validators and rate limits, plus a risk engine and tiered enforcement from shadow mode through kicks and staff-approved bans. The stack targets Roblox Studio and live servers, integrates with Rojo for placement under ServerScriptService, and includes offline testing and evaluation tooling via Lune scripts. It is aimed at Roblox developers and game security engineers who need configurable, evidence-driven cheat detection without trusting client-side code.
