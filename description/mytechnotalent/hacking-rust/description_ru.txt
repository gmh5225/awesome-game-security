Hacking Rust — это бесплатный пошаговый учебник и курс по реверс-инжинирингу программ на Rust с нуля. Он сочетает загружаемую PDF-книгу с небольшими примерами проектов на Cargo, которые последовательно разбирают программы hello world, скалярные и составные типы данных, функции с множеством параметров и управление потоком на x64 (с расширением на ARM64 и ARM32). Каждая тема преподаётся в три этапа — написание, отладка и анализ скомпилированного бинарника — чтобы читатели поняли, как конструкции Rust выглядят в ассемблере и как анализировать их с помощью отладчика. Репозиторий предназначен для исследователей безопасности, специалистов по реверс-инжинирингу и всех, кто изучает низкоуровневый анализ бинарников Rust, а не общую разработку приложений.
