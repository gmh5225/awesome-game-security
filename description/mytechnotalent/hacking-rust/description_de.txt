Hacking Rust ist ein kostenloses, schrittweises Tutorial und Kurs zum Reverse Engineering von Rust-Programmen von Grund auf. Es kombiniert ein herunterladbares PDF-Buch mit kleinen Cargo-basierten Beispielprojekten, die Hello-World-Programme, skalare und zusammengesetzte Datentypen, Funktionen mit vielen Parametern und die Ablaufsteuerung auf x64 behandeln (mit Erweiterung auf ARM64 und ARM32). Jedes Thema wird in drei Phasen vermittelt — Schreiben, Debuggen und Analysieren des kompilierten Binärs —, sodass Leser lernen, wie Rust-Konstrukte im Assembler erscheinen und wie man sie mit einem Debugger analysiert. Das Repository richtet sich an Sicherheitsforscher, Reverse Engineers und alle, die die Analyse von Rust-Binaries auf niedriger Ebene studieren, statt allgemeiner Anwendungsentwicklung.
