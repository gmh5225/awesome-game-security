Hacking Rust는 Rust 프로그램의 리버스 엔지니어링을 처음부터 배울 수 있는 무료의 단계별 튜토리얼이자 강좌입니다. 다운로드 가능한 PDF 도서와 Cargo 기반의 소규모 샘플 프로젝트를 함께 제공하며, hello world 프로그램, 스칼라 및 복합 데이터 타입, 다수의 매개변수를 갖는 함수, x64에서의 제어 흐름(ARM64 및 ARM32로 확장된 내용 포함)을 순차적으로 다룹니다. 각 주제는 작성, 디버깅, 컴파일된 바이너리 해킹의 세 단계로 가르치며, Rust 구문 요소가 어셈블리에서 어떻게 나타나는지와 디버거로 이를 분석하는 방법을 독자가 배우게 합니다. 이 저장소는 일반적인 애플리케이션 개발이 아닌 저수준 Rust 바이너리 분석을 공부하는 보안 연구자, 리버스 엔지니어 및 모든 이를 대상으로 합니다.
