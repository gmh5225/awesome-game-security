Hacking Rust is a free, step-by-step tutorial course for reverse engineering Rust programs from scratch. It pairs a downloadable PDF book with companion Rust sample projects that progress from hello-world programs through scalar and compound data types, functions, and control flow. Each topic is taught in three phases—writing code, debugging it, and analyzing or modifying the compiled binary—on x64, ARM64, and ARM32 architectures. The examples are organized as standalone Cargo crates intended for hands-on disassembly and binary analysis practice. It is aimed at security researchers and reverse engineers who need to understand how Rust code appears at the machine level.
