Hacking Rust is a free, step-by-step tutorial and course for reverse engineering Rust programs from scratch. It pairs a downloadable PDF book with small Cargo-based sample projects that walk through hello-world programs, scalar and compound data types, functions with many parameters, and control flow on x64 (with coverage extended to ARM64 and ARM32). Each topic is taught in three phases—writing, debugging, and hacking the compiled binary—so readers learn how Rust constructs appear in assembly and how to analyze them with a debugger. The repository is aimed at security researchers, reverse engineers, and anyone studying low-level Rust binary analysis rather than general application development.
