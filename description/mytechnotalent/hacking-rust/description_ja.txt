Hacking Rust は、Rust プログラムのリバースエンジニアリングをゼロから学べる無料のステップバイステップ型チュートリアル兼コースです。ダウンロード可能な PDF 書籍と、Cargo ベースの小さなサンプルプロジェクトを組み合わせ、hello world プログラム、スカラー型と複合データ型、多数のパラメータを持つ関数、x64 上の制御フロー（ARM64 および ARM32 への拡張も含む）を順を追って解説します。各トピックは、作成・デバッグ・コンパイル済みバイナリの解析（ハッキング）の 3 段階で教えられ、Rust の構文要素がアセンブリでどう現れるか、デバッガーでどう分析するかを読者が学べます。本リポジトリは、一般的なアプリケーション開発ではなく、低レベルの Rust バイナリ解析を学ぶセキュリティ研究者、リバースエンジニア、およびその他の読者を対象としています。
