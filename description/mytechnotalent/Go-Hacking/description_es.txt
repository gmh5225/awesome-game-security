Go Hacking es un curso tutorial gratuito y paso a paso para realizar ingeniería inversa de binarios Go (Golang) desde cero en x64, ARM64 y ARM32. Combina código fuente Go de ejemplo con archivos de base de datos complementarios de IDA Pro y recorre fundamentos como programas hello-world, tipos primitivos y flujo de control, con capítulos separados dedicados a escribir, depurar y analizar o parchear la salida compilada. El repositorio también incluye ejercicios prácticos de hacking en Go y C que demuestran la manipulación del flujo de control y técnicas de análisis binario. Un libro PDF descargable consolida el currículo completo, lo que lo hace adecuado para investigadores de seguridad, ingenieros de ingeniería inversa y cualquier persona que estudie cómo aparecen los programas Go a nivel de ensamblado y desensamblado.
