這是一套面向 Raspberry Pi Pico 2 微控制器的嵌入式駭客實戰課程與實驗集合。課程引導學習者使用 Pico SDK 和 CMake 進行 C 語言韌體開發，從基礎的 GPIO 與資料型別練習，逐步過渡到不依賴 SDK 抽象、直接操作硬體暫存器的內嵌 ARM 組合語言。每週課程模組配有投影片，配套的編號實驗涵蓋感測器、PWM 以及 DHT11、LCD、伺服馬達、紅外線等周邊裝置。其中還包含一個 Python 韌體修補工具，示範如何在機器碼層面對已編譯的 ARM Thumb 指令進行二進位修補，以改變感測器行為。本專案適合嵌入式安全從業者、韌體逆向工程師，以及希望培養硬體駭客與 IoT 安全研究底層技能的學習者。
