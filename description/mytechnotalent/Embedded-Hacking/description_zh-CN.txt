这是一套面向 Raspberry Pi Pico 2 微控制器的嵌入式黑客实战课程与实验集合。课程引导学习者使用 Pico SDK 和 CMake 进行 C 语言固件开发，从基础的 GPIO 与数据类型练习，逐步过渡到不依赖 SDK 抽象、直接操作硬件寄存器的内联 ARM 汇编。每周课程模块配有幻灯片，配套的编号实验涵盖传感器、PWM 以及 DHT11、LCD、舵机、红外等外设。其中还包含一个 Python 固件补丁工具，演示如何在机器码层面对已编译的 ARM Thumb 指令进行二进制补丁，以改变传感器行为。该项目适合嵌入式安全从业者、固件逆向工程师，以及希望培养硬件黑客与 IoT 安全研究底层技能的学习者。
