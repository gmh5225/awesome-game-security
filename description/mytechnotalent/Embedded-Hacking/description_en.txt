This is a hands-on embedded hacking course and lab collection targeting the Raspberry Pi Pico 2 microcontroller. It walks learners through C firmware development with the Pico SDK and CMake, progressing from basic GPIO and data-type exercises to inline ARM assembly and register-level hardware manipulation without SDK abstractions. Weekly lesson modules with slides accompany numbered labs covering sensors and peripherals such as DHT11, LCD, servo, and IR hardware. A Python firmware patcher demonstrates binary patching of compiled ARM Thumb floating-point instructions to alter sensor readings at the machine-code level. The project suits embedded security practitioners, firmware reverse engineers, and anyone building low-level skills for hardware hacking and IoT security research.
