Raspberry Pi Pico 2 마이크로컨트롤러를 대상으로 한 실습형 임베디드 해킹 강좌 및 랩 모음입니다. Pico SDK와 CMake를 사용한 C 펌웨어 개발을 학습하며, 기본 GPIO 및 데이터 타입 연습부터 SDK 추상화 없이 하드웨어 레지스터를 직접 조작하는 인라인 ARM 어셈블리까지 단계적으로 진행합니다. 슬라이드가 포함된 주간 레슨 모듈과 함께 DHT11, LCD, 서보, IR 등 센서, PWM, 주변 장치를 다루는 번호가 매겨진 랩이 제공됩니다. Python 펌웨어 패처는 컴파일된 ARM Thumb 명령어에 바이너리 패치를 적용하여 기계어 수준에서 센서 동작을 변경하는 방법을 보여 줍니다. 임베디드 보안 실무자, 펌웨어 리버스 엔지니어, 하드웨어 해킹 및 IoT 보안 연구를 위한 저수준 기술을 쌓고자 하는 이들에게 적합합니다.
