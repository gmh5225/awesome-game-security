Il s'agit d'un cours pratique de hacking embarqué et d'une collection de laboratoires ciblant le microcontrôleur Raspberry Pi Pico 2. Il guide les apprenants dans le développement de firmware en C avec le Pico SDK et CMake, en passant des exercices de base sur les GPIO et les types de données à l'assembleur ARM inline qui manipule directement les registres matériels sans les abstractions du SDK. Des modules hebdomadaires avec diapositives accompagnent des laboratoires numérotés couvrant capteurs, PWM et périphériques tels que DHT11, LCD, servomoteur et matériel IR. Un patcher de firmware en Python démontre le patch binaire d'instructions ARM Thumb compilées pour modifier le comportement des capteurs au niveau du code machine. Le projet convient aux praticiens de la sécurité embarquée, aux ingénieurs en rétro-ingénierie de firmware et à toute personne souhaitant développer des compétences de bas niveau pour le hacking matériel et la recherche en sécurité IoT.
