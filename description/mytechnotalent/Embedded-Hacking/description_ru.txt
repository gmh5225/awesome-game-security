Это практический курс и набор лабораторных работ по взлому встроенных систем, ориентированный на микроконтроллер Raspberry Pi Pico 2. Он проводит обучающихся через разработку прошивки на C с Pico SDK и CMake — от базовых упражнений по GPIO и типам данных до встроенного ARM-ассемблера, который напрямую управляет аппаратными регистрами без абстракций SDK. Еженедельные учебные модули со слайдами сопровождают пронумерованные лабораторные работы по датчикам, ШИМ и периферии, такой как DHT11, LCD, сервопривод и ИК-оборудование. Python-патчер прошивки демонстрирует бинарное патчинг скомпилированных инструкций ARM Thumb для изменения поведения датчиков на уровне машинного кода. Проект подходит специалистам по безопасности встроенных систем, инженерам по реверс-инжинирингу прошивок и всем, кто развивает низкоуровневые навыки для аппаратного взлома и исследований безопасности IoT.
