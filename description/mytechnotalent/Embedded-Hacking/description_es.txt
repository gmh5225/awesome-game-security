Este es un curso práctico de hacking embebido y una colección de laboratorios dirigidos al microcontrolador Raspberry Pi Pico 2. Guía a los aprendices en el desarrollo de firmware en C con el Pico SDK y CMake, avanzando desde ejercicios básicos de GPIO y tipos de datos hasta ensamblador ARM en línea que manipula registros de hardware directamente sin abstracciones del SDK. Módulos semanales con diapositivas acompañan laboratorios numerados que cubren sensores, PWM y periféricos como DHT11, LCD, servomotor y hardware IR. Un parcheador de firmware en Python demuestra el parcheo binario de instrucciones ARM Thumb compiladas para alterar el comportamiento de los sensores a nivel de código máquina. El proyecto es adecuado para profesionales de seguridad embebida, ingenieros de ingeniería inversa de firmware y cualquier persona que desee desarrollar habilidades de bajo nivel para hacking de hardware e investigación en seguridad IoT.
