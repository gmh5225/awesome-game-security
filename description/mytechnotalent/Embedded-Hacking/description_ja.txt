Raspberry Pi Pico 2 マイコンを対象とした、実践的な組み込みハッキングのコースおよびラボ集です。Pico SDK と CMake を用いた C 言語ファームウェア開発を学び、基本的な GPIO やデータ型の演習から、SDK の抽象化を使わずハードウェアレジスタを直接操作するインライン ARM アセンブリまで段階的に進みます。スライド付きの週次レッスンモジュールと、DHT11、LCD、サーボ、IR などのセンサー、PWM、周辺機器を扱う番号付きラボが用意されています。Python 製ファームウェアパッチャーでは、コンパイル済み ARM Thumb 命令のバイナリパッチにより、機械語レベルでセンサーの挙動を変更する手法を示します。組み込みセキュリティの実務者、ファームウェアリバースエンジニア、ハードウェアハッキングや IoT セキュリティ研究の低レベルスキルを身につけたい方に適しています。
