Go Hacking is a free, step-by-step tutorial course for reverse engineering Go (Golang) binaries from scratch across x64, ARM64, and ARM32. It pairs sample Go source code with companion IDA Pro database files and walks through fundamentals such as hello-world programs, primitive types, and control flow, with separate chapters devoted to writing, debugging, and analyzing or patching compiled output. The repository also includes practical hacking exercises in Go and C that demonstrate control-flow manipulation and binary analysis techniques. A downloadable PDF book consolidates the full curriculum, making it suited for security researchers, reverse engineers, and anyone studying how Go programs appear at the assembly and disassembly level.
