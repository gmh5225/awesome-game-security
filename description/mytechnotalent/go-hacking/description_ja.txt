Go Hacking は、x64、ARM64、ARM32 向けの Go (Golang) バイナリをゼロからリバースエンジニアリングするための、無料のステップバイステップ型チュートリアルコースです。サンプルの Go ソースコードと IDA Pro データベースファイルを組み合わせ、hello-world プログラム、プリミティブ型、制御フローなどの基礎を解説し、コンパイル結果の作成、デバッグ、分析、パッチ適用に特化した章も用意されています。リポジトリには Go と C による実践的なハッキング演習も含まれ、制御フロー操作やバイナリ分析の手法を示しています。ダウンロード可能な PDF 書籍が全カリキュラムをまとめており、セキュリティ研究者、リバースエンジニア、Go プログラムがアセンブリおよび逆アセンブリレベルでどのように現れるかを学びたい方に適しています。
