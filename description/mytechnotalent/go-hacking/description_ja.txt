Go Hacking は、Golang プログラムのリバースエンジニアリングをゼロから学ぶための、無料のステップバイステップ型チュートリアル兼サンプルコード集です。hello world プログラム、プリミティブ型、制御フローなどの基礎トピックを扱い、x64、ARM64、ARM32 向けにバイナリの作成、デバッグ、パッチ適用を学ぶ対応章も用意されています。各レッスンには Go ソース例、比較用の C サンプル、実践分析用の IDA Pro データベースファイルが含まれます。本コースはダウンロード可能な PDF 書籍とセットで、セキュリティ研究者、リバースエンジニア、およびアセンブリレベルで Go 実行ファイルを解析したい学習者を対象としています。
