Go Hacking es un tutorial gratuito paso a paso y una colección de código de ejemplo para hacer ingeniería inversa de programas Golang desde cero. Recorre temas fundamentales como programas hello world, tipos primitivos y flujo de control, con capítulos complementarios para escribir, depurar y parchear binarios en x64, ARM64 y ARM32. Cada lección incluye ejemplos de código fuente en Go, muestras complementarias en C para comparación y archivos de base de datos de IDA Pro para análisis práctico. El curso se complementa con un libro PDF descargable y está dirigido a investigadores de seguridad, ingenieros de ingeniería inversa y cualquier persona interesada en aprender a analizar ejecutables de Go a nivel de ensamblador.
