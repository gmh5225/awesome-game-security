Go Hacking은 Golang 프로그램을 처음부터 리버스 엔지니어링하는 방법을 다루는 무료 단계별 튜토리얼 및 샘플 코드 모음입니다. hello-world 프로그램, 기본 타입, 제어 흐름 등 기초 주제를 다루며, x64, ARM64, ARM32 환경에서 바이너리 작성, 디버깅, 패치를 학습하는 대응 챕터도 제공합니다. 각 강의에는 Go 소스 예제, 비교용 C 샘플, 실습 분석을 위한 IDA Pro 데이터베이스 파일이 포함됩니다. 이 과정은 다운로드 가능한 PDF 서적과 함께 제공되며, 보안 연구자, 리버스 엔지니어, 그리고 어셈블리 수준에서 Go 실행 파일을 분석하려는 학습자를 대상으로 합니다.
