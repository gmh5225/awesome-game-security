Go Hacking — это бесплатный пошаговый учебник и коллекция примеров кода для реверс-инжиниринга программ на Golang с нуля. В нём рассматриваются базовые темы, такие как программы hello world, примитивные типы и управление потоком выполнения, а также сопряжённые главы по написанию, отладке и патчингу бинарных файлов для x64, ARM64 и ARM32. Каждый урок включает примеры исходного кода на Go, сопутствующие образцы на C для сравнения и файлы баз данных IDA Pro для практического анализа. Курс дополняется загружаемой PDF-книгой и предназначен для исследователей безопасности, специалистов по реверс-инжинирингу и всех, кто хочет научиться анализировать исполняемые файлы Go на уровне ассемблера.
