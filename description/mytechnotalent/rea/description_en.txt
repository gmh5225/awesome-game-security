Reverse Engineering Assistant is a Python tool that triages native binaries and JavaScript or Electron application trees and explains them in plain language from a single scan command. It combines offline static analysis of ELF, Mach-O, and PE files using host utilities such as readelf, objdump, nm, and strings with non-executing JavaScript tree inventory, retrieval-augmented generation over local documents, and a multi-agent propose-review-gate workflow that records evidence for each finding. The same capabilities are exposed through a command-line interface and a Model Context Protocol server so IDE and automation clients can drive one shared tool catalog. It runs fully offline by default with no API key required, with optional hosted LLM generation when configured. It is aimed at reverse engineers, malware analysts, and security researchers who need quick, readable first-pass assessment of unknown executables and packaged apps, including game and anti-cheat related binaries.
