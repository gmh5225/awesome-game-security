Reverse Engineering Assistant 是一款 Python 工具，可通过单次扫描命令对原生二进制文件以及 JavaScript 或 Electron 应用目录进行分诊，并用通俗语言加以说明。它结合对 ELF、Mach-O 和 PE 文件的离线静态分析（使用 readelf、objdump、nm、strings 等主机工具）、不执行 JavaScript 的目录清点、基于本地文档的检索增强生成，以及多智能体提出—审查—门禁工作流，为每项发现记录证据。相同能力通过命令行界面和 Model Context Protocol 服务器对外提供，便于 IDE 与自动化客户端驱动同一工具目录。默认完全离线运行且无需 API 密钥，配置后可选用托管 LLM 生成。面向逆向工程师、恶意软件分析师和安全研究人员，用于对未知可执行文件与打包应用（含游戏及反作弊相关二进制）进行快速、可读的首轮评估。
