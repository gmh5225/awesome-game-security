Reverse Engineering Assistant es una herramienta en Python que clasifica binarios nativos y árboles de aplicaciones JavaScript o Electron y los explica en lenguaje claro con un único comando de escaneo. Combina análisis estático sin conexión de archivos ELF, Mach-O y PE mediante utilidades del sistema como readelf, objdump, nm y strings, inventario de árboles JavaScript sin ejecución, generación aumentada por recuperación sobre documentos locales, y un flujo de trabajo multiagente propose-review-gate que registra evidencia para cada hallazgo. Las mismas capacidades están disponibles mediante interfaz de línea de comandos y un servidor Model Context Protocol para que clientes de IDE y automatización utilicen un catálogo de herramientas compartido. Funciona totalmente sin conexión por defecto sin clave API, con generación LLM alojada opcional si se configura. Está dirigido a ingenieros de ingeniería inversa, analistas de malware e investigadores de seguridad que necesitan una primera evaluación rápida y legible de ejecutables y aplicaciones empaquetadas desconocidas, incluidos binarios relacionados con juegos y anti-cheat.
