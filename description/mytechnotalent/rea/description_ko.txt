Reverse Engineering Assistant는 Python 도구로, 단일 스캔 명령으로 네이티브 바이너리와 JavaScript 또는 Electron 애플리케이션 트리를 분류하고 쉬운 말로 설명합니다. readelf, objdump, nm, strings 같은 호스트 유틸리티를 이용한 ELF, Mach-O, PE의 오프라인 정적 분석, 실행하지 않는 JavaScript 트리 목록화, 로컬 문서에 대한 retrieval-augmented generation, 각 발견마다 근거를 기록하는 다중 에이전트 propose-review-gate 워크플로를 결합합니다. 동일한 기능은 CLI와 Model Context Protocol 서버를 통해 제공되어 IDE와 자동화 클라이언트가 하나의 공유 도구 카탈로그를 구동할 수 있습니다. 기본적으로 API 키 없이 완전 오프라인으로 동작하며, 구성 시 선택적으로 호스팅 LLM 생성을 사용할 수 있습니다. 알 수 없는 실행 파일과 패키징된 앱(게임 및 안티치트 관련 바이너리 포함)에 대한 빠르고 읽기 쉬운 1차 평가가 필요한 리버스 엔지니어, 멀웨어 분석가, 보안 연구자를 대상으로 합니다.
