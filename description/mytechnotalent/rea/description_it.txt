Reverse Engineering Assistant è uno strumento Python che classifica binari nativi e alberi di applicazioni JavaScript o Electron e li spiega in linguaggio semplice con un unico comando di scansione. Combina analisi statica offline di file ELF, Mach-O e PE tramite utility di sistema come readelf, objdump, nm e strings, inventario degli alberi JavaScript senza esecuzione, generazione aumentata dal recupero su documenti locali e un flusso di lavoro multi-agente propose-review-gate che registra le prove per ogni riscontro. Le stesse capacità sono esposte tramite interfaccia a riga di comando e un server Model Context Protocol, così IDE e client di automazione possono guidare un catalogo di strumenti condiviso. Funziona completamente offline per impostazione predefinita senza chiave API, con generazione LLM ospitata opzionale se configurata. È pensato per reverse engineer, analisti di malware e ricercatori di sicurezza che necessitano di una prima valutazione rapida e leggibile di eseguibili e app impacchettate sconosciute, inclusi binari legati a giochi e anti-cheat.
