Reverse Engineering Assistant 是一款 Python 工具，可透過單次掃描指令對原生二進位檔以及 JavaScript 或 Electron 應用程式目錄進行分類整理，並以淺白語言說明。它結合對 ELF、Mach-O 與 PE 檔案的離線靜態分析（使用 readelf、objdump、nm、strings 等主機工具）、不執行 JavaScript 的目錄清點、以本機文件為基礎的檢索增強生成，以及多代理提出—審查—閘道工作流程，為每項發現記錄證據。相同能力透過命令列介面與 Model Context Protocol 伺服器提供，讓 IDE 與自動化用戶端可驅動同一工具目錄。預設完全離線執行且無需 API 金鑰，設定後可選用託管 LLM 生成。面向逆向工程師、惡意軟體分析師與安全研究人員，用於對未知可執行檔與打包應用（含遊戲及反作弊相關二進位）進行快速、可讀的首輪評估。
