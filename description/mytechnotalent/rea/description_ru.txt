Reverse Engineering Assistant — инструмент на Python, который одной командой сканирования сортирует нативные бинарники и деревья приложений на JavaScript или Electron и объясняет их простым языком. Он сочетает автономный статический анализ файлов ELF, Mach-O и PE с помощью системных утилит readelf, objdump, nm и strings, инвентаризацию деревьев JavaScript без выполнения кода, retrieval-augmented generation по локальным документам и многоагентный рабочий процесс propose-review-gate, фиксирующий доказательства для каждого вывода. Те же возможности доступны через интерфейс командной строки и сервер Model Context Protocol, чтобы IDE и клиенты автоматизации использовали единый каталог инструментов. По умолчанию работает полностью офлайн без API-ключа; при настройке можно подключить генерацию на hosted LLM. Предназначен для специалистов по реверс-инжинирингу, аналитиков вредоносного ПО и исследователей безопасности, которым нужна быстрая и понятная первичная оценка неизвестных исполняемых файлов и упакованных приложений, включая бинарники, связанные с играми и античитом.
