Reverse Engineering Assistant は Python 製のツールで、単一のスキャンコマンドからネイティブバイナリおよび JavaScript や Electron アプリケーションのツリーをトリアージし、平易な言葉で説明します。readelf、objdump、nm、strings などのホストユーティリティによる ELF、Mach-O、PE のオフライン静的解析、実行しない JavaScript ツリー棚卸し、ローカル文書に対する retrieval-augmented generation、各所見の根拠を記録するマルチエージェントの propose-review-gate ワークフローを組み合わせています。同じ機能は CLI と Model Context Protocol サーバーから提供され、IDE や自動化クライアントが共通のツールカタログを駆動できます。既定では API キー不要の完全オフライン動作で、設定時はホスト型 LLM 生成を任意で利用できます。未知の実行ファイルやパッケージアプリ（ゲームやアンチチート関連バイナリを含む）の迅速で読みやすい初回評価を必要とするリバースエンジニア、マルウェアアナリスト、セキュリティ研究者向けです。
