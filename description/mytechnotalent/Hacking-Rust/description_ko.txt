Hacking Rust는 Rust 프로그램의 리버스 엔지니어링을 처음부터 배우는 무료 단계별 튜토리얼 과정입니다. 다운로드 가능한 PDF 책과 함께 hello-world 프로그램부터 스칼라 및 복합 데이터 타입, 함수, 제어 흐름까지 진행하는 Rust 샘플 프로젝트를 제공합니다. 각 주제는 코드 작성, 디버깅, 컴파일된 바이너리 분석 및 수정의 세 단계로 x64, ARM64, ARM32 아키텍처에서 학습합니다. 예제는 독립적인 Cargo crate로 구성되어 실습용 디스어셈블리 및 바이너리 분석 연습에 적합합니다. Rust 코드가 기계 수준에서 어떻게 나타나는지 이해해야 하는 보안 연구자 및 리버스 엔지니어를 대상으로 합니다.
