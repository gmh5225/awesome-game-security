Hacking Rust は、Rust プログラムのリバースエンジニアリングをゼロから学ぶための、無料の段階的チュートリアルコースです。ダウンロード可能な PDF 書籍と、hello-world プログラムからスカラー型・複合データ型、関数、制御フローへと進む Rust サンプルプロジェクトがセットになっています。各トピックは、コードの記述、デバッグ、コンパイル済みバイナリの解析・改変という3段階で、x64、ARM64、ARM32 アーキテクチャ上で学びます。例はスタンドアロンの Cargo crate として整理され、実践的な逆アセンブルとバイナリ解析の練習用です。Rust コードが機械レベルでどのように現れるかを理解する必要があるセキュリティ研究者やリバースエンジニア向けです。
