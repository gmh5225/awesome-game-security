Hacking Rust es un curso tutorial gratuito y paso a paso para hacer ingeniería inversa de programas Rust desde cero. Combina un libro PDF descargable con proyectos de ejemplo en Rust que avanzan desde programas hello-world hasta tipos de datos escalares y compuestos, funciones y flujo de control. Cada tema se enseña en tres fases—escribir código, depurarlo y analizar o modificar el binario compilado—en arquitecturas x64, ARM64 y ARM32. Los ejemplos están organizados como crates Cargo independientes pensados para la práctica de desensamblado y análisis binario. Está dirigido a investigadores de seguridad e ingenieros de ingeniería inversa que necesitan entender cómo aparece el código Rust a nivel de máquina.
