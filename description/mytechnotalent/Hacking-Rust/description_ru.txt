Hacking Rust — это бесплатный пошаговый учебный курс по реверс-инжинирингу программ на Rust с нуля. Он сочетает загружаемую PDF-книгу с сопутствующими примерами проектов на Rust, которые охватывают путь от программ hello-world через скалярные и составные типы данных, функции и управление потоком выполнения. Каждая тема преподаётся в три этапа — написание кода, его отладка, а также анализ или модификация скомпилированного бинарного файла — на архитектурах x64, ARM64 и ARM32. Примеры организованы как автономные Cargo crate, предназначенные для практики дизасsemblирования и бинарного анализа. Курс предназначен для исследователей безопасности и реверс-инженеров, которым нужно понять, как код Rust выглядит на уровне машинного кода.
