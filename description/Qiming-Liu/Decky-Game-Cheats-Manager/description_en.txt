DeckyGCM is a Decky Loader plugin that brings Game Cheats Manager-style trainer search, download, and library management to Steam Deck from the Quick Access menu and per-game library context menus. The stack pairs a TypeScript and React UI with a Python plugin backend that embeds generated GCM core logic for catalog queries, authenticated downloads, ZIP and 7z/RAR extraction, and local trainer metadata. Users can search trainers from sources such as FLiNG, XiaoXing, cheat tables, and the GCM catalog with English or Chinese name matching, bind downloads to Steam App IDs, import local executables, and optionally launch sidecar programs through Proton launch options. Steam library scanning, offline catalog refresh, bilingual UI tied to Steam language settings, and bounded concurrent downloads target players who want on-device trainer workflows rather than desktop-only cheat tools.
