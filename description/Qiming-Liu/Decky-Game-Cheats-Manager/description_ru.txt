DeckyGCM — плагин для Decky Loader, который на Steam Deck через меню быстрого доступа и контекстные меню библиотеки по играм даёт поиск, загрузку и управление библиотекой тренеров в духе Game Cheats Manager. Стек объединяет UI на TypeScript и React с Python-бэкендом плагина, в котором встроена сгенерированная ядровая логика GCM для запросов каталога, аутентифицированных загрузок, распаковки ZIP и 7z/RAR и локальных метаданных тренеров. Пользователи могут искать тренеры в источниках вроде FLiNG, XiaoXing, таблиц читов и каталога GCM с сопоставлением имён на английском или китайском, привязывать загрузки к Steam App ID, импортировать локальные исполняемые файлы и по желанию запускать вспомогательные программы через параметры запуска Proton. Сканирование библиотеки Steam, офлайн-обновление каталога, двуязычный интерфейс по настройкам языка Steam и ограниченная параллельная загрузка ориентированы на игроков, которым нужны рабочие процессы с тренерами на устройстве, а не только настольные чит-инструменты.
