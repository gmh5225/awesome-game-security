DeckyGCM ist ein Decky-Loader-Plugin, das auf dem Steam Deck über das Schnellzugriffsmenü und kontextbezogene Bibliotheksmenüs pro Spiel Trainer-Suche, -Download und Bibliotheksverwaltung im Stil von Game Cheats Manager bereitstellt. Der Stack verbindet eine TypeScript- und React-Oberfläche mit einem Python-Plugin-Backend, das generierte GCM-Kernlogik für Katalogabfragen, authentifizierte Downloads, ZIP- sowie 7z/RAR-Entpackung und lokale Trainer-Metadaten einbettet. Nutzer können Trainer aus Quellen wie FLiNG, XiaoXing, Cheat-Tabellen und dem GCM-Katalog mit englischer oder chinesischer Namenssuche finden, Downloads an Steam-App-IDs binden, lokale Executables importieren und optional Sidecar-Programme über Proton-Startoptionen starten. Steam-Bibliotheksscan, Offline-Katalogaktualisierung, zweisprachige UI an Steam-Spracheinstellungen gekoppelt und begrenzte parallele Downloads richten sich an Spieler, die Trainer-Workflows auf dem Gerät statt rein desktopbasierter Cheat-Tools wünschen.
