DeckyGCM 是一款 Decky Loader 插件，可在 Steam Deck 上通过快捷访问菜单和按游戏划分的库上下文菜单，提供类似 Game Cheats Manager 的训练器搜索、下载与库管理。技术栈将 TypeScript 与 React 前端界面，与嵌入生成 GCM 核心逻辑的 Python 插件后端相结合，用于目录查询、认证下载、ZIP 与 7z/RAR 解压以及本地训练器元数据。用户可从 FLiNG、小幸、Cheat Engine 表、GCM 目录等来源搜索训练器，支持中英文名称匹配，将下载绑定到 Steam App ID，导入本地可执行文件，并可通过 Proton 启动选项可选启动伴随程序。Steam 库扫描、离线目录刷新、随 Steam 语言设置切换的双语界面，以及有上限的并发下载，面向希望在设备上完成训练器工作流、而非仅依赖桌面端作弊工具的玩家。
