DeckyGCM は Decky Loader 向けプラグインで、Steam Deck 上でクイックアクセスメニューおよびゲーム別ライブラリのコンテキストメニューから、Game Cheats Manager 方式のトレーナー検索・ダウンロード・ライブラリ管理を提供します。TypeScript と React の UI と、生成された GCM コアロジックを組み込んだ Python プラグインバックエンドが連携し、カタログ照会、認証付きダウンロード、ZIP および 7z/RAR の展開、ローカルトレーナーメタデータを扱います。FLiNG、小幸、チートテーブル、GCM カタログなどのソースからトレーナーを検索でき、英語・中国語名のマッチング、Steam App ID へのダウンロード紐付け、ローカル実行ファイルのインポート、Proton 起動オプション経由でのサイドカープログラム起動（任意）が可能です。Steam ライブラリのスキャン、オフラインカタログ更新、Steam 言語設定に連動する二言語 UI、上限付き同時ダウンロードにより、デスクトップ専用のチートツールではなく、端末上でトレーナーワークフローを完結させたいプレイヤーを対象としています。
