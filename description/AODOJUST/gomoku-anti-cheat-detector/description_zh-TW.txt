Baishen 是一款 Chrome 和 Edge 瀏覽器擴充功能，用於偵測在 gomoku.com 和 papergames.io 上進行線上五子棋時疑似 AI 輔助的對局。在觀戰或對局過程中，它會記錄落子序列，並在每局結束後於本機使用 Rapfi WebAssembly 引擎以及可選的 KataGomo HTTP 或自訂 Rapfi 權重後端重播對局，依據引擎一致性、勝率差距、犀利著法連擊、規避模式及相關棋形訊號產生 0–100 的風險評分。此工具提供即時疊加層、對局存檔檢視器、含閾值學習的樣本庫、玩家黑名單、多語言聊天質詢以及十三種語言介面，並可選擇透過 Supabase 啟用雲端同步，同時不限制免費的離線分析。它面向需要在對局審查中進行實用遊戲安全分診和反作弊提示的版主、組織者與玩家，不能取代官方平台的裁決。
