Baishen は、gomoku.com および papergames.io 上のオンライン五目並べで AI 支援の疑いがある対局を検出する Chrome および Edge 向けブラウザ拡張機能です。観戦中または対局中に手順を記録し、各対局終了後に Rapfi WebAssembly エンジンと、任意の KataGomo HTTP またはカスタム Rapfi 重みバックエンドでローカルに再現し、エンジン一致度、勝率差、鋭い手の連続、回避パターン、関連する形に基づくシグナルから 0～100 のリスクスコアを算出します。ライブオーバーレイ、アーカイブビューア、閾値学習付きサンプルライブラリ、プレイヤーブラックリスト、多言語チャットによる質問、13 言語対応インターフェースを備え、Supabase によるクラウド同期も任意で有効化でき、無料のオフライン分析は制限されません。モデレーター、主催者、対局レビュー時に実用的なゲームセキュリティのトリアージとアンチチートの手がかりが必要なプレイヤー向けであり、公式プラットフォームの判定に代わるものではありません。
