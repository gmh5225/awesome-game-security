Baishen은 gomoku.com과 papergames.io에서 온라인 오목을 둘 때 AI 보조 플레이가 의심되는 대국을 감지하는 Chrome 및 Edge 브라우저 확장 프로그램입니다. 관전 또는 대국 중 착수 순서를 기록하고, 각 대국이 끝난 뒤 Rapfi WebAssembly 엔진과 선택적 KataGomo HTTP 또는 사용자 지정 Rapfi 가중치 백엔드로 로컬에서 재현하여 엔진 일치도, 승률 격차, 날카로운 수 연속, 회피 패턴 및 관련 형태 기반 신호로 0–100 위험 점수를 산출합니다. 이 도구에는 실시간 오버레이, 아카이브 뷰어, 임계값 학습이 포함된 샘플 라이브러리, 플레이어 블랙리스트, 다국어 채팅 질문, 13개 언어 인터페이스가 포함되며, Supabase를 통한 클라우드 동기화를 선택적으로 활성화할 수 있고 무료 오프라인 분석은 제한되지 않습니다. 검토 중 실용적인 게임 보안 분류와 반치트 단서가 필요한 운영자, 주최자, 플레이어를 위한 도구이며 공식 플랫폼 판정을 대체하지 않습니다.
