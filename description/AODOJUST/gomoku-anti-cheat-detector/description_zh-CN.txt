Baishen 是一款 Chrome 和 Edge 浏览器扩展，用于检测在 gomoku.com 和 papergames.io 上进行在线五子棋时疑似 AI 辅助的对局。在观战或对局过程中，它会记录落子序列，并在每局结束后在本地使用 Rapfi WebAssembly 引擎以及可选的 KataGomo HTTP 或自定义 Rapfi 权重后端重放对局，依据引擎一致性、胜率差距、犀利着法连击、规避模式及相关棋形信号生成 0–100 的风险评分。该工具提供实时叠加层、对局存档查看器、带阈值学习的样本库、玩家黑名单、多语言聊天质询以及十三种语言界面，并可选通过 Supabase 激活云同步，同时不限制免费的离线分析。它面向需要在对局审查中进行实用游戏安全分诊和反作弊提示的版主、组织者和玩家，不能替代官方平台的裁决。
