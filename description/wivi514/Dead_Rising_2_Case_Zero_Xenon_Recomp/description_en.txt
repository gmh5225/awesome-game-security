Dead Rising 2: Case Zero Xenon Recomp statically recompiles the Xbox 360 exclusive Dead Rising 2: Case Zero into a native PC port that runs without a full emulator. The project uses XenonRecomp and XenosRecomp to translate PowerPC guest code ahead of time, then executes it in a custom C++ runtime built around a Vulkan renderer, SDL input, ffmpeg-based XMA audio, and kernel high-level emulation with honest-failure stubs. It ships Python and C++ tooling for STFS/XEX package extraction, shader translation, GPU PM4 command processing, and automated jump-table recovery, backed by extensive documentation on Xbox 360 binary analysis and recompilation pitfalls. Primary languages are C++ and Python, with HLSL shaders and CMake builds. It targets researchers and developers interested in Xbox 360 reverse engineering, static recompilation, and game preservation rather than live anti-cheat analysis.
