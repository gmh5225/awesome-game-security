Dead Rising 2: Case Zero Xenon Recomp 将 Xbox 360 独占的 Dead Rising 2: Case Zero 通过静态重编译转化为可在 PC 上原生运行、无需完整模拟器的移植版本。项目使用 XenonRecomp 和 XenosRecomp 对 PowerPC 客户机代码进行提前编译，然后在基于 Vulkan 渲染器、SDL 输入、基于 ffmpeg 的 XMA 音频以及带 honest-failure stub 的内核高层模拟的自定义 C++ 运行时中执行。项目提供用于 STFS/XEX 包提取、着色器转换、GPU PM4 命令处理及自动化跳转表恢复的 Python 与 C++ 工具链，并附有关于 Xbox 360 二进制分析与重编译常见陷阱的详尽文档。主要语言为 C++ 和 Python，包含 HLSL 着色器及 CMake 构建。面向对 Xbox 360 逆向工程、静态重编译与游戏保存感兴趣的研究人员与开发者，而非实时反作弊分析。
