Dead Rising 2: Case Zero Xenon Recomp は、Xbox 360 独占の Dead Rising 2: Case Zero を静的再コンパイルし、フルエミュレータなしで動作するネイティブ PC 版に変換します。プロジェクトは XenonRecomp と XenosRecomp を使用して PowerPC ゲストコードを事前に変換し、Vulkan レンダラー、SDL 入力、ffmpeg ベースの XMA オーディオ、および honest-failure スタブを備えたカーネル高レベルエミュレーションを中心としたカスタム C++ ランタイムで実行します。STFS/XEX パッケージ抽出、シェーダー変換、GPU PM4 コマンド処理、自動ジャンプテーブル復元のための Python および C++ ツールを同梱し、Xbox 360 バイナリ解析と再コンパイルの落とし穴に関する詳細なドキュメントも提供しています。主な言語は C++ と Python で、HLSL シェーダーおよび CMake ビルドを使用します。ライブのアンチチート分析ではなく、Xbox 360 リバースエンジニアリング、静的再コンパイル、ゲーム保存に関心のある研究者や開発者を対象としています。
