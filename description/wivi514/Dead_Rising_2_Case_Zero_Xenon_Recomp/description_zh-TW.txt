Dead Rising 2: Case Zero Xenon Recomp 將 Xbox 360 獨佔的 Dead Rising 2: Case Zero 透過靜態重編譯轉化為可在 PC 上原生執行、無需完整模擬器的移植版本。專案使用 XenonRecomp 與 XenosRecomp 對 PowerPC 主機端程式碼進行預先編譯，然後在基於 Vulkan 渲染器、SDL 輸入、以 ffmpeg 為基礎的 XMA 音訊，以及含 honest-failure stub 的內核高階模擬的自訂 C++ 執行環境中執行。專案提供用於 STFS/XEX 套件提取、著色器轉換、GPU PM4 命令處理及自動化跳轉表復原的 Python 與 C++ 工具，並附關於 Xbox 360 二進位分析與重編譯常見陷阱的詳盡文件。主要語言為 C++ 與 Python，包含 HLSL 著色器及 CMake 建置。面向對 Xbox 360 逆向工程、靜態重編譯與遊戲保存感興趣的研究人員與開發者，而非即時反作弊分析。
