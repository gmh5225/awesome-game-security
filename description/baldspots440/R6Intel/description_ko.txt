R6Intel은 Rainbow Six Siege를 위한 웹 기반 통계 분석 플랫폼으로, 플레이어 계정의 성능 이상 및 치트 징후를 평가합니다. 백엔드는 Node.js와 Express로, 프론트엔드는 vanilla JavaScript로 구축되었으며, R6Data API를 통해 Ubisoft, Xbox, PlayStation 플랫폼에서 랭크 통계를 가져와 K/D, 헤드샷 비율, 경기당 킬 수, 승률 등의 지표로 0–100 Suspicion Score를 산출합니다. 점수 모델은 현재 시즌 성과와 과거 스냅샷 비교, 복합 이상 보너스, 표본 크기 신뢰도 가중치, 확정 제재 별도 추적을 결합합니다. 플레이어 프로필, 별칭, 통계 스냅샷은 Supabase 또는 로컬 JSON 저장소에 영속화되며, 캐싱, 속도 제한, 요청 중복 제거로 상위 API 제약을 관리합니다. 게임 보안 연구자, 커뮤니티 운영자, 경쟁 무결성 워크플로를 위해 확정적인 치트 판정이 아닌, 의심 계정에 대한 데이터 기반 단서를 제공하는 것을 목적으로 합니다.
