R6Intel 是一个面向《彩虹六号：围攻》的基于 Web 的统计分析平台，用于评估玩家账号是否存在表现异常与作弊迹象。后端采用 Node.js 与 Express，前端使用原生 JavaScript，通过 R6Data API 从 Ubisoft、Xbox 和 PlayStation 平台拉取排位数据，并依据 K/D、爆头率、场均击杀和胜率等指标计算 0–100 的可疑度评分。评分模型结合当前赛季表现与历史快照对比，包含复合异常加成、样本量置信度加权，以及对已确认处罚记录的单独跟踪。玩家资料、别名与统计快照通过 Supabase 或本地 JSON 存储持久化，并借助缓存、速率限制与请求去重来应对上游 API 约束。它面向游戏安全研究人员、社区管理员与竞技诚信工作流，提供基于数据的疑似账号线索，而非确凿的作弊判定。
