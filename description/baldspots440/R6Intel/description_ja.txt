R6Intel は Rainbow Six Siege 向けの Web ベース統計分析プラットフォームで、プレイヤーアカウントのパフォーマンス異常やチートの兆候を評価します。バックエンドは Node.js と Express、フロントエンドは vanilla JavaScript で構築され、R6Data API 経由で Ubisoft、Xbox、PlayStation 各プラットフォームからランク戦統計を取得し、K/D、ヘッドショット率、試合あたりのキル数、勝率などの指標から 0〜100 の Suspicion Score を算出します。スコアリングモデルは現シーズンの成績と過去スナップショットの比較、複合異常ボーナス、サンプルサイズに基づく信頼度重み付け、確定制裁の個別追跡を組み合わせます。プレイヤープロフィール、エイリアス、統計スナップショットは Supabase またはローカル JSON ストレージに永続化され、キャッシュ、レート制限、リクエスト重複排除により上流 API の制約に対応します。ゲームセキュリティ研究者、コミュニティモデレーター、競技公正性ワークフロー向けに、確定的なチート判定ではなく、疑わしいアカウントに関するデータ駆動型の手がかりを提供することを目的としています。
