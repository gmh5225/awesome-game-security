R6Intel 是一個面向《虹彩六號：圍攻行動》的網頁式統計分析平台，用於評估玩家帳號是否存在表現異常與作弊跡象。後端採用 Node.js 與 Express，前端使用原生 JavaScript，透過 R6Data API 從 Ubisoft、Xbox 與 PlayStation 平台拉取排位資料，並依據 K/D、爆頭率、場均擊殺與勝率等指標計算 0–100 的可疑度評分。評分模型結合當前賽季表現與歷史快照比對，包含複合異常加成、樣本量置信度加權，以及對已確認處罰紀錄的單獨追蹤。玩家資料、別名與統計快照透過 Supabase 或本地 JSON 儲存持久化，並借助快取、速率限制與請求去重來應對上游 API 限制。它面向遊戲安全研究人員、社群管理員與競技誠信工作流程，提供以資料為基礎的疑似帳號線索，而非確鑿的作弊判定。
