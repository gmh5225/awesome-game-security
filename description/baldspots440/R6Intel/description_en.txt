R6Intel is a web-based statistical analysis platform for Rainbow Six Siege that evaluates player accounts for performance anomalies and cheating indicators. Built with Node.js and Express on the backend and vanilla JavaScript on the frontend, it pulls ranked stats from the R6Data API across Ubisoft, Xbox, and PlayStation platforms and computes a 0–100 Suspicion Score from metrics such as K/D, headshot rate, kills per match, and win rate. The scoring model combines current-season performance with historical snapshot comparisons, compound anomaly bonuses, sample-size confidence weighting, and separate tracking of confirmed sanctions. Player profiles, aliases, and statistical snapshots are persisted via Supabase or local JSON storage, with caching, rate-limit pacing, and request deduplication to manage upstream API constraints. It is intended for game security researchers, community moderators, and competitive integrity workflows who need data-driven leads on potentially suspicious accounts rather than definitive cheat verdicts.
