R6Intel — это веб-платформа статистического анализа для Rainbow Six Siege, которая оценивает игровые аккаунты на предмет аномалий в показателях и признаков читерства. Бэкенд построен на Node.js и Express, фронтенд — на vanilla JavaScript; через API R6Data загружаются рейтинговые статистики с платформ Ubisoft, Xbox и PlayStation, после чего рассчитывается Suspicion Score от 0 до 100 на основе таких метрик, как K/D, доля хедшотов, убийства за матч и процент побед. Модель оценки сочетает результаты текущего сезона со сравнением исторических снимков, составные бонусы за аномалии, взвешивание по размеру выборки и отдельное отслеживание подтверждённых санкций. Профили игроков, псевдонимы и статистические снимки сохраняются через Supabase или локальное JSON-хранилище, с кэшированием, ограничением частоты запросов и дедупликацией для соблюдения ограничений upstream API. Предназначен для исследователей игровой безопасности, модераторов сообществ и рабочих процессов соревновательной честности, которым нужны основанные на данных зацепки по потенциально подозрительным аккаунтам, а не окончательные вердикты о читерстве.
