FoxAddition 是一款 Minecraft 服务端反作弊插件，可在 Spigot、Paper 和 Folia 上检测并标记常见的客户端作弊行为。它使用 Java 编写，通过 Gradle 构建，依赖 PacketEvents 进行底层数据包检测，并提供可配置的检查项，涵盖无效数据包、移动与能力、方块放置、keep-alive 以及破坏光环与 nuker 等世界相关漏洞。服主可使用按世界开关、违规等级体系、基于文件的告警日志，并集成 GeyserMC 与 Floodgate 以支持基岩版玩家，还可选接 DiscordSRV、ProtocolLib 等插件。本项目面向需要轻量、跨版本（约 1.7.2 至当前版本）防护的多人 Minecraft 管理员与反作弊开发者。
