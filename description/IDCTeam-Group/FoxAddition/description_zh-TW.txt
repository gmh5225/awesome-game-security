FoxAddition 是一款 Minecraft 伺服器反作弊外掛，可在 Spigot、Paper 與 Folia 上偵測並標記常見的用戶端作弊行為。它以 Java 撰寫、以 Gradle 建置，依賴 PacketEvents 進行底層封包檢查，並提供可設定的檢查項目，涵蓋無效封包、移動與能力、方塊放置、keep-alive，以及破壞光環、nuker 等世界相關漏洞。伺服器管理員可使用依世界開關、違規等級機制、以檔案為基礎的告警記錄，並整合 GeyserMC 與 Floodgate 以支援基岩版玩家，亦可選用 DiscordSRV、ProtocolLib 等外掛。本專案面向需要輕量、跨版本（約 1.7.2 至目前版本）防護的多人 Minecraft 管理員與反作弊開發者。
