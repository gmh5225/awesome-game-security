FoxAddition is a Minecraft server anti-cheat plugin that detects and flags common client-side hacks on Spigot, Paper, and Folia. It is written in Java and built with Gradle, relying on PacketEvents for low-level packet inspection alongside configurable checks for invalid packets, movement and abilities, block placement, keep-alives, and world exploits such as break aura and nuker. Server operators get per-world toggles, a violation-level system, file-based alert logging, and integrations with GeyserMC and Floodgate for Bedrock players plus optional hooks for DiscordSRV, ProtocolLib, and related plugins. The project targets multiplayer Minecraft administrators and anti-cheat developers who need lightweight, version-spanning protection from roughly 1.7.2 through current releases.
