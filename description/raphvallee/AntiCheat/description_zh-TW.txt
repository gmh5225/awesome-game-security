AntiCheat 是一款面向 Paper 版 Minecraft 伺服器的模組化反作弊外掛與框架，旨在讓新增偵測項目只需實作一個類別即可。專案以 Java 撰寫（目標為 Java 25 與 Paper 26.3），內建保守的參考偵測，涵蓋速度、飛行與攻擊距離，並經由 Bukkit 監聽器、移動與戰鬥追蹤器到以處理器為基礎的偵測，形成清晰管線，同時提供集中式豁免、違規記錄與可設定懲罰。管理員可透過基於 Brigadier 的 /ac 指令管理警示、依玩家的偵錯串流、違規等級以及設定熱重載。專案使用 Gradle 建置，包含 JUnit 單元測試，並文件化了嚴格的架構規範，便於伺服器營運者與外掛作者在無需重複監聽器或懲罰邏輯的前提下擴充伺服器端作弊偵測。
