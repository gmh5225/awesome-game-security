AntiCheat es un complemento y marco antitrampas modular para servidores Minecraft con Paper, diseñado para que añadir nuevas comprobaciones de detección sea cuestión de implementar una sola clase. Está escrito en Java (orientado a Java 25 y Paper 26.3) e incluye comprobaciones de referencia conservadoras para velocidad, vuelo y alcance, con un flujo claro desde los listeners de Bukkit pasando por rastreadores de movimiento y combate hasta comprobaciones basadas en manejadores, exenciones centralizadas y registro de infracciones con castigos configurables. El personal puede gestionar el sistema mediante el comando /ac basado en Brigadier para alertas, flujos de depuración por jugador, niveles de infracción y recarga en caliente de la configuración. El proyecto usa Gradle para compilaciones, incluye pruebas unitarias con JUnit y documenta reglas arquitectónicas estrictas para que operadores de servidor y autores de plugins puedan ampliar la detección de trampas del lado del servidor sin duplicar la lógica de listeners o castigos.
