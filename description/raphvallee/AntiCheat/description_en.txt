AntiCheat is a modular anti-cheat plugin and framework for Paper Minecraft servers, built to make adding new detection checks a matter of implementing a single class. It is written in Java (targeting Java 25 and Paper 26.3) and ships conservative reference checks for speed, flight, and reach, with a clean pipeline from Bukkit listeners through movement and combat trackers to handler-based checks, centralized exemptions, and violation logging with configurable punishments. Staff can manage the system through a Brigadier-based /ac command for alerts, per-player debug streams, violation levels, and hot reload of configuration. The project uses Gradle for builds, includes JUnit unit tests, and documents strict architectural rules so server operators and plugin authors can extend server-side cheat detection without duplicating listener or punishment logic.
