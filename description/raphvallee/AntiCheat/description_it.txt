AntiCheat è un plugin e framework anticheat modulare per server Minecraft Paper, pensato perché aggiungere nuovi controlli di rilevamento richieda solo l’implementazione di una singola classe. È scritto in Java (con target Java 25 e Paper 26.3) e include controlli di riferimento conservativi per velocità, volo e reach, con una pipeline chiara dai listener Bukkit ai tracker di movimento e combattimento fino ai controlli basati su handler, esenzioni centralizzate e registrazione delle violazioni con punizioni configurabili. Lo staff può gestire il sistema tramite il comando /ac basato su Brigadier per avvisi, flussi di debug per giocatore, livelli di violazione e hot reload della configurazione. Il progetto usa Gradle per le build, include test unitari JUnit e documenta regole architetturali rigorose così che operatori di server e autori di plugin possano estendere il rilevamento cheat lato server senza duplicare listener o logica di punizione.
