AntiCheat 是一款面向 Paper 版 Minecraft 服务器的模块化反作弊插件与框架，旨在让新增检测项只需实现一个类即可。项目采用 Java 编写（面向 Java 25 与 Paper 26.3），内置保守的参考检测，涵盖速度、飞行与攻击距离，并经由 Bukkit 监听器、移动与战斗跟踪器到基于处理器的检测，形成清晰流水线，同时提供集中式豁免、违规记录与可配置惩罚。运维人员可通过基于 Brigadier 的 /ac 命令管理告警、按玩家的调试流、违规等级以及配置热重载。项目使用 Gradle 构建，包含 JUnit 单元测试，并文档化了严格的架构约定，便于服主与插件作者在无需重复监听器或惩罚逻辑的前提下扩展服务端作弊检测。
