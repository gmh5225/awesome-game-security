AntiCheat — модульный античит-плагин и фреймворк для серверов Minecraft на Paper, созданный так, чтобы добавление новых проверок сводилось к реализации одного класса. Написан на Java (целевые версии Java 25 и Paper 26.3) и поставляется с консервативными эталонными проверками скорости, полёта и досягаемости, с чётким конвейером от слушателей Bukkit через трекеры движения и боя к проверкам на основе обработчиков, централизованными исключениями и журналированием нарушений с настраиваемыми наказаниями. Персонал управляет системой через команду /ac на базе Brigadier: оповещения, отладочные потоки по игрокам, уровни нарушений и горячая перезагрузка конфигурации. Проект собирается Gradle, включает модульные тесты JUnit и документирует строгие архитектурные правила, чтобы администраторы серверов и авторы плагинов могли расширять серверное обнаружение читов без дублирования логики слушателей и наказаний.
