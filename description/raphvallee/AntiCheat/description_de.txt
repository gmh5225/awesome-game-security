AntiCheat ist ein modulares Anti-Cheat-Plugin und Framework für Paper-Minecraft-Server, das so aufgebaut ist, dass neue Erkennungsprüfungen durch Implementierung einer einzelnen Klasse hinzugefügt werden können. Es ist in Java geschrieben (Ziel: Java 25 und Paper 26.3) und liefert konservative Referenzprüfungen für Geschwindigkeit, Flug und Reichweite, mit einer klaren Pipeline von Bukkit-Listenern über Bewegungs- und Kampf-Tracker bis zu handlerbasierten Prüfungen, zentralisierten Ausnahmen und Verstoßprotokollierung mit konfigurierbaren Strafen. Mitarbeiter können das System über den Brigadier-basierten Befehl /ac für Meldungen, Debug-Streams pro Spieler, Verstoßstufen und Hot-Reload der Konfiguration verwalten. Das Projekt nutzt Gradle für Builds, enthält JUnit-Unit-Tests und dokumentiert strenge Architekturregeln, damit Serverbetreiber und Plugin-Autoren serverseitige Cheat-Erkennung erweitern können, ohne Listener- oder Straflogik zu duplizieren.
