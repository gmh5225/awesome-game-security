NEXTVM は、root やハードウェアエミュレータなしで、実機上の隔離サンドボックスプロセス内にサードパーティ APK を実行する軽量 Android 仮想化エンジンです。Binder IPC と ActivityThread の起動経路を横取りし、Kotlin ベースの仮想コンテキストとシステムサービスプロキシを、GOT/PLT をパッチしてファイルシステムおよびプロパティ照会をリダイレクトする C++ ネイティブフック層と組み合わせ、クローンごとのストレージとデバイス ID 偽装を伴う複数並列インスタンスをサポートします。反検知スタックは root、エミュレータ、Xposed、仮想環境の一般的なチェックを対象とし、認証とプッシュのための Google Play 開発者サービス連携を任意で提供します。コードベースは Jetpack Compose、Hilt、クリーンアーキテクチャを用いたマルチモジュール Gradle プロジェクトで、プライバシー分離、モバイルセキュリティ研究、アプリ互換性テスト、制御されたゲスト環境内での保護アプリの挙動分析を目的としています。
