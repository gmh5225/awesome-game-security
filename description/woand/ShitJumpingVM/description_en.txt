NEXTVM is a lightweight Android virtualization engine that runs third-party APKs inside isolated sandbox processes on a real device without root access or a hardware emulator. It intercepts Binder IPC and ActivityThread launch paths, pairs a Kotlin-based virtual context and system service proxies with a C++ native hook layer that patches GOT/PLT to redirect filesystem and property queries, and supports multiple parallel instances with per-clone storage and device identity spoofing. An anti-detection stack targets common root, emulator, Xposed, and virtual-environment checks, with optional Google Play Services bridging for auth and push. The codebase is a multi-module Gradle project using Jetpack Compose, Hilt, and Clean Architecture, aimed at privacy isolation, mobile security research, app compatibility testing, and analyzing how protected apps behave inside a controlled guest environment.
