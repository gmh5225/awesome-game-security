NEXTVM은 root나 하드웨어 에뮬레이터 없이 실제 기기에서 격리된 샌드박스 프로세스 안에 서드파티 APK를 실행하는 경량 Android 가상화 엔진입니다. Binder IPC와 ActivityThread 실행 경로를 가로채고, Kotlin 기반 가상 컨텍스트 및 시스템 서비스 프록시를 GOT/PLT 패치로 파일 시스템 및 속성 조회를 리다이렉트하는 C++ 네이티브 훅 계층과 결합하며, 클론별 저장소와 기기 ID 스푸핑을 지원하는 다중 병렬 인스턴스를 제공합니다. 탐지 회피 스택은 일반적인 root, 에뮬레이터, Xposed, 가상 환경 검사를 겨냥하며, 인증과 푸시를 위한 Google Play 서비스 브리징을 선택적으로 지원합니다. 코드베이스는 Jetpack Compose, Hilt, 클린 아키텍처를 사용하는 다중 모듈 Gradle 프로젝트로, 프라이버시 격리, 모바일 보안 연구, 앱 호환성 테스트, 통제된 게스트 환경에서 보호된 앱의 동작 분석을 목표로 합니다.
