Kyty-gpu-hybrid は、ゲストの GPU 処理をホスト上で実行するハイブリッドグラフィックススタックを中心とした Kyty PlayStation 5 エミュレータの開発ブランチです。主に C++ と CMake、C++20 で実装され、コンパイル済み GPU パイプラインデータをインストール間で配布する Rust のパイプライン共有サーバーも追加されています。ツリーは、ゲスト側コマンドプロセッサ（PM4 ディスパッチ、タイリング、PSSR 関連経路）と、SPIR-V ツール群から構築されたホスト Vulkan レンダラー、多数の compute tiler シェーダー、バッファとテクスチャのキャッシュを組み合わせています。補助要素として UI に SDL3 と ImGui、ゲストコードパッチに Zydis と xbyak、圧縮ディスクイメージに ZArchive、ヘッドセットと DualSense オーディオに OpenXR と Opus が含まれます。PS5 タイトルが GPU をどう駆動するかを調べ、タイトル互換性とレンダリング正確性を反復改善したいエミュレータ作者、グラフィックス研究者、リバースエンジニアに適しています。
