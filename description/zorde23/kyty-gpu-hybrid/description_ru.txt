Kyty-gpu-hybrid — ветвь разработки эмулятора Kyty для PlayStation 5, сосредоточенная на гибридном графическом стеке, который выполняет гостевую GPU-нагрузку на хосте. Реализован в основном на C++ с CMake и C++20; добавлен сервер совместного использования конвейеров на Rust для распространения скомпилированных данных GPU-конвейеров между установками. Дерево сочетает гостевой процессор команд (диспетчеризация PM4, тайлинг и пути, связанные с PSSR) с хостовым рендерером Vulkan на базе инструментов SPIR-V, обширных compute tiler-шейдеров и кэшей буферов и текстур. Вспомогательные компоненты: SDL3 и ImGui для интерфейса, Zydis и xbyak для патчинга гостевого кода, ZArchive для сжатых образов дисков, OpenXR с Opus для гарнитуры и аудио DualSense. Подходит авторам эмуляторов, исследователям графики и инженерам по реверсу, которым нужно изучать, как игры PS5 управляют GPU, и итеративно улучшать совместимость с играми и корректность рендеринга.
