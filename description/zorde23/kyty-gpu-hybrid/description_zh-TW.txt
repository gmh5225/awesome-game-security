Kyty-gpu-hybrid 是 Kyty PlayStation 5 模擬器的一個開發分支，著重於混合圖形堆疊，在宿主機上執行客體 GPU 工作負載。專案主要以 C++ 搭配 CMake 與 C++20 實作，並新增以 Rust 撰寫的管線共享伺服器，用於在多個安裝之間分發已編譯的 GPU 管線資料。程式樹將客體端命令處理器（PM4 派發、tiling 及 PSSR 相關路徑）與以 SPIR-V 工具鏈建構的宿主 Vulkan 渲染器、大量 compute tiler 著色器，以及緩衝與紋理快取結合在一起。輔助元件包含用於介面的 SDL3 與 ImGui、用於客體程式碼修補的 Zydis 與 xbyak、用於壓縮光碟映像的 ZArchive，以及用於頭戴裝置與 DualSense 音訊的 OpenXR 與 Opus。適合模擬器作者、圖形研究人員，以及需要研究 PS5 遊戲如何驅動 GPU、並迭代遊戲相容性與渲染正確性的逆向工程師。
