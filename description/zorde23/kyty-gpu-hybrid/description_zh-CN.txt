Kyty-gpu-hybrid 是 Kyty PlayStation 5 模拟器的一个开发分支，专注于混合图形栈，在主机上执行来宾 GPU 工作负载。项目主要以 C++ 结合 CMake 与 C++20 实现，并增加了用于在多个安装实例间分发已编译 GPU 管线数据的 Rust 管线共享服务器。代码树将来宾侧命令处理器（PM4 派发、tiling 及 PSSR 相关路径）与基于 SPIR-V 工具链构建的主机 Vulkan 渲染器、大量 compute tiler 着色器以及缓冲与纹理缓存相结合。配套组件包括用于界面的 SDL3 与 ImGui、用于来宾代码修补的 Zydis 与 xbyak、用于压缩光盘镜像的 ZArchive，以及用于头显与 DualSense 音频的 OpenXR 与 Opus。适合模拟器开发者、图形研究人员以及需要研究 PS5 游戏如何驱动 GPU、并迭代游戏兼容性与渲染正确性的逆向工程师。
