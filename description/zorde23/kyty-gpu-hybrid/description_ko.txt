Kyty-gpu-hybrid는 게스트 GPU 작업을 호스트에서 실행하는 하이브리드 그래픽 스택에 초점을 맞춘 Kyty PlayStation 5 에뮬레이터의 개발 브랜치입니다. 주로 C++와 CMake, C++20으로 구현되었으며, 컴파일된 GPU 파이프라인 데이터를 설치 간에 배포하는 Rust 파이프라인 공유 서버가 추가되어 있습니다. 트리는 게스트 측 명령 프로세서(PM4 디스패치, 타일링, PSSR 관련 경로)와 SPIR-V 도구로 구축된 호스트 Vulkan 렌더러, 광범위한 compute tiler 셰이더, 버퍼 및 텍스처 캐시를 결합합니다. 지원 구성 요소로 UI용 SDL3와 ImGui, 게스트 코드 패칭용 Zydis와 xbyak, 압축 디스크 이미지용 ZArchive, 헤드셋 및 DualSense 오디오용 OpenXR과 Opus가 있습니다. PS5 타이틀이 GPU를 어떻게 구동하는지 연구하고 타이틀 호환성과 렌더링 정확성을 반복 개선하려는 에뮬레이터 제작자, 그래픽 연구자, 리버스 엔지니어에게 적합합니다.
