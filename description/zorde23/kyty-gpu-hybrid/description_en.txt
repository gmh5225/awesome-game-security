Kyty-gpu-hybrid is a development branch of the Kyty PlayStation 5 emulator centered on a hybrid graphics stack that runs guest GPU work on the host. It is implemented mainly in C++ with CMake and C++20, and adds a Rust pipeline-sharing server for distributing compiled GPU pipeline data across installs. The tree couples a guest-side command processor (PM4 dispatch, tiling, and PSSR-related paths) with a host Vulkan renderer built from SPIR-V tooling, extensive compute tiler shaders, and caches for buffers and textures. Supporting pieces include SDL3 and ImGui for the UI, Zydis and xbyak for guest code patching, ZArchive for compressed disc images, and OpenXR with Opus for headset and DualSense audio. It suits emulator authors, graphics researchers, and reverse engineers who need to study how PS5 titles drive the GPU and to iterate on title compatibility and rendering correctness.
