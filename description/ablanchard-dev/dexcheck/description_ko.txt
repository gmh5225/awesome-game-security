DexCheck는 Call of Duty와 Warzone용 실시간 읽기 전용 PC 포렌식 검사 도구로, 관리자가 출력을 지켜보는 감독 화면 공유 중에 플레이어를 심사하도록 설계되었습니다. Windows에서는 PowerShell을 통해 약 40개의 읽기 전용 프로브를 실행하며, Bash로 작성된 네이티브 macOS 동반 도구를 제공하여 치트 소프트웨어, DMA 카드, 캡처 하드웨어, Cronus/XIM류 입력 장치, 반포렌식 삭제 흔적, 로그인된 모든 사용자 계정에 걸친 지속성을 탐지합니다. 스캔은 USN 저널 및 Prefetch 아티팩트, 레지스트리 및 시작 프로그램 지속성, 실행 중인 프로세스 및 아웃바운드 연결, 커널 드라이버, PCIe 장치 식별, 시스템 보안 상태를 다루며, 머신을 수정하거나 네트워크를 사용하지 않고 결과를 CLEAN, SUSPECT 또는 심각 판정으로 집계합니다. 또한 소프트웨어로는 볼 수 없는 경우(예: 두 번째 머신의 레이더 장비나 위조 DMA 하드웨어)를 위한 시각적 설정 체크리스트와 CI에서 실행되는 대규모 PowerShell 테스트 스위트도 포함합니다. 실용적이고 동의 기반의 플레이어 검증 워크플로가 필요한 토너먼트 주최자, 커뮤니티 안티치트 관리자, 게임 보안 연구자를 대상으로 합니다.
