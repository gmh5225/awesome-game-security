DexCheck 是一款針對 Call of Duty 與 Warzone 的即時、唯讀取證 PC 檢查工具，可在受監督的螢幕分享過程中由管理員觀看輸出時審查玩家。它透過 PowerShell 在 Windows 上執行約 40 項唯讀探測，並提供以 Bash 實作的原生 macOS 配套工具，用於偵測作弊軟體、DMA 卡、擷取硬體、Cronus/XIM 類輸入裝置、反取證清除痕跡，以及所有已登入使用者帳戶中的持久化項目。掃描涵蓋 USN 日誌與 Prefetch 構件、登錄檔與啟動項持久化、即時程序與對外連線、核心驅動、PCIe 裝置識別及系統安全態勢，隨後將結果彙整為 CLEAN、SUSPECT 或嚴重級別判定，且不會修改電腦或使用網路。它還附帶視覺化設定檢查清單，用於軟體無法發現的情況（例如第二台機器的雷達裝置或偽造的 DMA 硬體），以及一套在 CI 中執行的大規模 PowerShell 測試套件。面向需要實用、基於同意的玩家驗證流程的賽事主辦方、社群反作弊管理員及遊戲安全研究人員。
