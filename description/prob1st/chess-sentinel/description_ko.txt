Chess Sentinel은 Chess.com에서 상대의 치트 확률을 실시간으로 추정하고, 결과를 페이지 내 Shadow DOM HUD와 사용자 이름 인라인 배지에 표시하는 오픈 소스 Chrome Manifest V3 브라우저 확장 프로그램입니다. 엄격한 TypeScript로 작성되었으며, 베이지안 scoring 엔진을 통해 여섯 가지 공개 포렌식 신호를 융합합니다. 최근 승률 이상, Elo 구간 대비 CAPS2 정확도, PGN 시계 수 두기 페이싱 분석, 레이팅 급상승 속도, 계정 신뢰 지표 등은 모두 Chess.com의 읽기 전용 Published-Data API에서 가져옵니다. 확장 프로그램은 보관된 PGN에서 [%clk] 타임스탬프를 파싱해 Game Review 데이터가 없어도 기계적인 수 타이밍과 중반 엔진 전환을 표시할 수 있으며, 플래그된 상대의 공정 플레이 계정 정지도 감시할 수 있습니다. 처리는 브라우저에서 전적으로 로컬로 이루어지며 원격 측정이나 수 보조는 없어, 라이브 보드 평가가 아닌 온라인 체스 공정 플레이 모니터링, 스머프 탐지, 공개 통계 기반 경량 안티치트 연구에 적합합니다.
