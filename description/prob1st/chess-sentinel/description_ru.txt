Chess Sentinel — это браузерное расширение Chrome Manifest V3 с открытым исходным кодом, которое в реальном времени оценивает вероятность читерства соперника на Chess.com и показывает результат во встроенном HUD на Shadow DOM и inline-значке у имени пользователя. Написано на строгом TypeScript и объединяет шесть публичных форензических сигналов через байесовский scoring-движок: аномалии недавнего винрейта, точность CAPS2 относительно диапазонов Elo, анализ темпа ходов по часам в PGN, скорость скачка рейтинга и индикаторы доверия к аккаунту — всё из read-only Published-Data API Chess.com. Расширение разбирает метки времени [%clk] из архивных PGN, чтобы отмечать роботизированный темп и переключение движка в середине партии даже без данных Game Review, и может отслеживать закрытие аккаунтов за нечестную игру у помеченных соперников. Обработка полностью локальна в браузере, без телеметрии и подсказок ходов; подходит для мониторинга честной игры в онлайн-шахматах, выявления смурфов и лёгких anti-cheat исследований по исторической публичной статистике, а не для live-оценки позиции на доске.
