Chess Sentinel is an open-source Chrome Manifest V3 browser extension that estimates real-time opponent cheat probability on Chess.com and displays the result in an in-page Shadow DOM HUD and inline username badge. It is built in strict TypeScript and fuses six public forensic signals through a Bayesian scoring engine, including recent win-rate anomalies, CAPS2 accuracy versus Elo bands, PGN clock move-pacing analysis, rating surge velocity, and account trust indicators, all sourced from Chess.com’s read-only Published-Data API. The extension parses [%clk] timestamps from archived PGNs to flag robotic move timing and mid-game engine toggles even when Game Review data is missing, and it can watch flagged opponents for fair-play account closures. Processing stays entirely local in the browser with no telemetry or move assistance, making it suited to online chess fair-play monitoring, smurf detection, and lightweight anti-cheat research on historical public stats rather than live board evaluation.
