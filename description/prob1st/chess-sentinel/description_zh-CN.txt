Chess Sentinel 是一款开源的 Chrome Manifest V3 浏览器扩展，可在 Chess.com 上实时估算对手作弊概率，并将结果展示在页面内 Shadow DOM HUD 与用户名行内徽章中。项目采用严格的 TypeScript 编写，通过贝叶斯评分引擎融合六项公开取证信号，包括近期胜率异常、CAPS2 准确度与 Elo 段位对比、PGN 棋钟走子节奏分析、等级分飙升速度以及账户信任指标，数据均来自 Chess.com 只读的 Published-Data API。扩展会从归档 PGN 中解析 [%clk] 时间戳，在缺少 Game Review 数据时仍能标记机械化走子节奏与局中引擎切换行为，并可监视被标记对手是否因公平竞赛被封号。全部处理均在浏览器本地完成，无遥测、不提供走棋辅助，适用于在线国际象棋公平竞赛监测、小号识别，以及基于历史公开统计的轻量反作弊研究，而非实时盘面评估。
