Chess Sentinel は、Chess.com 上で対戦相手のチート確率をリアルタイムに推定し、結果をページ内 Shadow DOM HUD とユーザー名インラインバッジに表示する、オープンソースの Chrome Manifest V3 ブラウザ拡張機能です。厳密な TypeScript で実装され、ベイズスコアリングエンジンにより六つの公開フォレンジック信号を統合します。直近の勝率異常、Elo 帯に対する CAPS2 精度、PGN 棋鐘の手番ペーシング分析、レーティング急上昇速度、アカウント信頼指標などは、すべて Chess.com の読み取り専用 Published-Data API から取得します。拡張機能はアーカイブ PGN から [%clk] タイムスタンプを解析し、Game Review データがなくても機械的な手番タイミングや中盤でのエンジン切り替えを検出でき、フラグ付き対戦相手のフェアプレイによるアカウント停止も監視できます。処理はすべてブラウザ内でローカルに完結し、テレメトリや着手支援は行いません。ライブ盤面評価ではなく、オンライン将棋のフェアプレイ監視、スマーフ検出、公開統計に基づく軽量アンチチート研究に適しています。
