Chess Sentinel 是一款開源的 Chrome Manifest V3 瀏覽器擴充功能，可在 Chess.com 上即時估算對手作弊機率，並將結果顯示在頁面內 Shadow DOM HUD 與使用者名稱行內徽章中。專案以嚴格的 TypeScript 撰寫，透過貝氏評分引擎融合六項公開鑑識訊號，包括近期勝率異常、CAPS2 準確度與 Elo 段位對比、PGN 棋鐘走子節奏分析、等級分飆升速度以及帳戶信任指標，資料均來自 Chess.com 唯讀的 Published-Data API。擴充功能會從歸檔 PGN 解析 [%clk] 時間戳，在缺少 Game Review 資料時仍能標記機械化走子節奏與局中引擎切換行為，並可監視被標記對手是否因公平競賽遭封號。全部處理均在瀏覽器本地完成，無遙測、不提供走棋輔助，適用於線上西洋棋公平競賽監測、小號識別，以及基於歷史公開統計的輕量反作弊研究，而非即時棋盤評估。
