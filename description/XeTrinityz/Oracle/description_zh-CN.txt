Oracle Trinity Edition 是 PC 版《蝙蝠侠：阿卡姆骑士》的模块化游戏内作弊与调整菜单，按 F3 或手柄打开，以 BmSDK-AK 模组形式构建。它主要用 C# 编写，是对原版 Oracle 模组的从零重写，采用小型内核、按功能划分的模块、失败时记录日志而非崩溃的受保护游戏钩子，以及可干净卸载并恢复已改数值的机制。菜单提供可搜索页面、径向轮盘收藏、含可训练自动战斗脑的战斗自动化、丰富的传送与世界控制、游戏内编辑器、自由相机与蝙蝠车工具、存档管理以及可选的自定义音乐播放。它面向希望在单机《阿卡姆骑士》中获得深度运行时控制、实验性与便利作弊的玩家与模组开发者，而非在线反作弊或在线服务工具。
