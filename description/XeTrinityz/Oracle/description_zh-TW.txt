Oracle Trinity Edition 是 PC 版《蝙蝠俠：阿卡姆騎士》的模組化遊戲內作弊與調整選單，按 F3 或手把開啟，以 BmSDK-AK 模組形式建構。它主要以 C# 撰寫，是對原版 Oracle 模組的從零重建，採用精簡核心、依功能劃分的模組、失敗時記錄日誌而非當機的受保護遊戲鉤子，以及可乾淨卸載並還原已改數值的機制。選單提供可搜尋頁面、徑向輪盤最愛、含可訓練自動戰鬥腦的戰鬥自動化、豐富的傳送與世界控制、遊戲內編輯器、自由視角與蝙蝠車工具、存檔管理以及可選的自訂音樂播放。它面向希望在單機《阿卡姆騎士》中獲得深度執行時控制、實驗性與便利作弊的玩家與模組開發者，而非線上反作弊或即時服務工具。
