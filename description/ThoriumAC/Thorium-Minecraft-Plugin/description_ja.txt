Thorium Minecraft Plugin は、Minecraft 向けアンチチート Thorium のサーバー側クライアントです。サーバーがすでに受信しているパケットからプレイヤーのテレメトリを取得し、リモートの Thorium 検知エンジンへストリーミングします。Bukkit、Spigot、Paper、Folia 向けに Java で書かれており、移動、戦闘、ブロック操作、トランザクションマーカー、周辺ワールドのジオメトリを記録します。クライアント側コンポーネント、メモリ検査、プレイヤー端末へのアクセスは一切不要です。PacketEvents、Java-WebSocket、Protocol Buffers を用いてエンジンと認証・通信を行い、返された判定（スタッフ通知、警告、キック、BAN など）を任意で適用できます。検知ロジックはすべてクローズドソースの Thorium エンジン上で実行され、このオープンプラグインにより、オペレーターはサーバーから送信されるデータと処罰の適用方法を正確に監査できます。1.8 から最新リリースまでの各バージョンに対応した、サーバー側アンチチート保護を求める Minecraft サーバー管理者向けです。
