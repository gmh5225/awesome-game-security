Thorium Minecraft Plugin ist der serverseitige Client für Thorium, ein Minecraft-Anti-Cheat, das Spielertelemetrie aus Paketen erfasst, die der Server bereits empfängt, und sie an die entfernte Thorium-Erkennungsengine streamt. In Java für Bukkit, Spigot, Paper und Folia geschrieben, zeichnet es Bewegungen, Kämpfe, Blockinteraktionen, Transaktionsmarker und nahe Weltgeometrie auf – ohne clientseitige Komponenten, Speicherinspektion oder Zugriff auf die Spielermaschine. Das Plugin nutzt PacketEvents, Java-WebSocket und Protocol Buffers zur Authentifizierung und Kommunikation mit der Engine und setzt optional zurückgegebene Urteile wie Staff-Warnungen, Verwarnungen, Kicks und Bans durch. Die Erkennungslogik läuft vollständig in der Closed-Source-Thorium-Engine; dieses offene Plugin ermöglicht Betreibern, genau zu prüfen, welche Daten ihren Server verlassen und wie Strafen angewendet werden. Es richtet sich an Minecraft-Serveradministratoren, die serverseitigen Anti-Cheat-Schutz von Version 1.8 bis zu den neuesten Releases wünschen.
