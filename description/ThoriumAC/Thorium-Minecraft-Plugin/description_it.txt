Thorium Minecraft Plugin è il client lato server di Thorium, un anti-cheat per Minecraft che acquisisce la telemetria dei giocatori dai pacchetti che il server riceve già e la trasmette al motore di rilevamento remoto Thorium. Scritto in Java per Bukkit, Spigot, Paper e Folia, registra movimento, combattimento, interazione con i blocchi, marcatori di transazione e la geometria del mondo circostante, senza alcun componente lato client, ispezione della memoria o accesso alla macchina del giocatore. Il plugin utilizza PacketEvents, Java-WebSocket e Protocol Buffers per autenticarsi e comunicare con il motore, quindi applica facoltativamente i verdetti restituiti, come avvisi allo staff, warning, kick e ban. La logica di rilevamento viene eseguita interamente nel motore Thorium closed-source; questo plugin open source consente agli operatori di verificare esattamente quali dati lasciano il server e come vengono applicate le punizioni. È destinato agli amministratori di server Minecraft che desiderano protezione anti-cheat lato server dalle versioni 1.8 fino alle release più recenti.
