Thorium Minecraft Plugin est le client côté serveur de Thorium, un anti-triche Minecraft qui capture la télémétrie des joueurs à partir des paquets que le serveur reçoit déjà et la transmet au moteur de détection Thorium distant. Écrit en Java pour Bukkit, Spigot, Paper et Folia, il enregistre les mouvements, les combats, les interactions avec les blocs, les marqueurs de transaction et la géométrie du monde environnant, sans aucun composant côté client, inspection mémoire ni accès à la machine du joueur. Le plugin utilise PacketEvents, Java-WebSocket et Protocol Buffers pour s'authentifier et communiquer avec le moteur, puis applique éventuellement les verdicts renvoyés, tels que les alertes au staff, les avertissements, les expulsions et les bannissements. La logique de détection s'exécute entièrement dans le moteur Thorium propriétaire ; ce plugin open source permet aux opérateurs d'auditer précisément quelles données quittent leur serveur et comment les sanctions sont appliquées. Il s'adresse aux administrateurs de serveurs Minecraft qui souhaitent une protection anti-triche côté serveur, des versions 1.8 aux dernières releases.
