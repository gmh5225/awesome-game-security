Thorium Minecraft Plugin is the server-side client for Thorium, a Minecraft anti-cheat that captures player telemetry from packets the server already receives and streams it to the remote Thorium detection engine. Written in Java for Bukkit, Spigot, Paper, and Folia, it records movement, combat, block interaction, transaction markers, and nearby world geometry without any client-side component, memory inspection, or player machine access. The plugin uses PacketEvents, Java-WebSocket, and Protocol Buffers to authenticate and communicate with the engine, then optionally enforces returned verdicts such as staff alerts, warnings, kicks, and bans. Detection logic runs entirely in the closed-source Thorium engine; this open plugin lets operators audit exactly what data leaves their server and how punishments are applied. It is intended for Minecraft server administrators who want server-side anti-cheat protection across versions from 1.8 through the latest releases.
