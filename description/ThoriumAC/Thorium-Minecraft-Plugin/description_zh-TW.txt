Thorium Minecraft Plugin 是 Thorium 的伺服器端用戶端；Thorium 是一款 Minecraft 反作弊系統，會從伺服器已接收的封包中擷取玩家遙測資料，並將其串流傳送至遠端 Thorium 偵測引擎。此插件以 Java 撰寫，適用於 Bukkit、Spigot、Paper 和 Folia，可記錄移動、戰鬥、方塊互動、交易標記以及附近世界幾何資訊，無需任何用戶端元件、記憶體檢查或存取玩家機器。插件透過 PacketEvents、Java-WebSocket 和 Protocol Buffers 與引擎進行身分驗證和通訊，並可選擇執行回傳的判定結果，例如向管理員告警、警告、踢出和封禁。偵測邏輯完全在閉源的 Thorium 引擎中執行；此開源插件讓服主能夠準確稽核哪些資料會離開伺服器，以及懲罰如何被套用。它面向希望獲得伺服器端反作弊保護的 Minecraft 伺服器管理員，支援從 1.8 到最新版本的各個版本。
