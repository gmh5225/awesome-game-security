Thorium Minecraft Plugin은 Minecraft 안티치트 Thorium의 서버 측 클라이언트입니다. 서버가 이미 수신하는 패킷에서 플레이어 원격 측정 데이터를 수집하여 원격 Thorium 탐지 엔진으로 스트리밍합니다. Bukkit, Spigot, Paper, Folia용으로 Java로 작성되었으며, 이동, 전투, 블록 상호작용, 트랜잭션 마커, 주변 월드 지오메트리를 기록합니다. 클라이언트 측 구성 요소, 메모리 검사, 플레이어 머신 접근이 전혀 필요하지 않습니다. PacketEvents, Java-WebSocket, Protocol Buffers를 사용해 엔진과 인증 및 통신을 수행한 뒤, 스태프 알림, 경고, 킥, 밴 등 반환된 판정을 선택적으로 적용할 수 있습니다. 탐지 로직은 전적으로 폐쇄 소스 Thorium 엔진에서 실행되며, 이 오픈 플러그인을 통해 운영자는 서버에서 나가는 데이터와 처벌 적용 방식을 정확히 감사할 수 있습니다. 1.8부터 최신 릴리스까지의 버전에서 서버 측 안티치트 보호를 원하는 Minecraft 서버 관리자를 위한 것입니다.
