Thorium Minecraft Plugin 是 Thorium 的服务端客户端；Thorium 是一款 Minecraft 反作弊系统，会从服务器已接收的数据包中采集玩家遥测数据，并将其流式传输至远程 Thorium 检测引擎。该插件使用 Java 编写，适用于 Bukkit、Spigot、Paper 和 Folia，可记录移动、战斗、方块交互、事务标记以及附近世界几何信息，无需任何客户端组件、内存检查或访问玩家机器。插件通过 PacketEvents、Java-WebSocket 和 Protocol Buffers 与引擎进行身份验证和通信，并可选择执行返回的判定结果，例如向管理员告警、警告、踢出和封禁。检测逻辑完全在闭源的 Thorium 引擎中运行；此开源插件让服主能够准确审计哪些数据会离开服务器，以及惩罚如何被应用。它面向希望获得服务端反作弊保护的 Minecraft 服务器管理员，支持从 1.8 到最新版本的各个版本。
