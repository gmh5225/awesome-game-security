Thorium Minecraft Plugin — серверный клиент для Thorium, античита для Minecraft, который собирает телеметрию игроков из пакетов, которые сервер уже получает, и передаёт её на удалённый движок обнаружения Thorium. Написан на Java для Bukkit, Spigot, Paper и Folia; записывает движение, бой, взаимодействие с блоками, маркеры транзакций и геометрию окружающего мира без каких-либо клиентских компонентов, инспекции памяти или доступа к машине игрока. Плагин использует PacketEvents, Java-WebSocket и Protocol Buffers для аутентификации и связи с движком, а затем по желанию применяет возвращаемые вердикты: оповещения персонала, предупреждения, кики и баны. Логика обнаружения полностью выполняется в закрытом движке Thorium; этот открытый плагин позволяет администраторам точно проверять, какие данные покидают сервер и как применяются наказания. Предназначен для администраторов серверов Minecraft, которым нужна серверная защита от читов на версиях от 1.8 до последних релизов.
