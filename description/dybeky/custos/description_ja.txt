Custos は、ライブのゲームクライアントに頼らずプレイヤーをスクリーニングする必要があるゲームサーバー運営者向けの Windows デスクトップフォレンジック反チートスキャナーです。Electron と TypeScript で構築され、ネイティブ Win32 メモリアクセスを備え、Prefetch、Amcache、BAM、レジストリおよびブラウザの痕跡、Defender 履歴、DNS キャッシュ、ファイルハッシュ、反フォレンジック改ざん、関連する Windows 証拠などを対象とする二十一種類のオフラインアーティファクトスキャナーを実行し、リスクエンジンで結果を集約して整合性ハッシュ付きのエクスポート可能なレポートを生成します。オプションの Live Scan モードは管理者として実行中のタイトルに対して使うと、注入モジュール、コードフック、不審なスレッド、パターンベースのメモリシグネチャを検出するストリーミング検知器を動かします。キーワード、ハッシュ、シグネチャリソースが検知を支え、セッション後にプレイヤー端末へ残る永続データは最小限になるよう設計されています。競技型マルチプレイのモデレーション、異議申し立ての文書化、Windows 上での実地チート調査ワークフローに適しています。
