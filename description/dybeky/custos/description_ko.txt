Custos는 라이브 게임 클라이언트 없이 플레이어를 심사해야 하는 게임 서버 운영진을 위한 Windows 데스크톱 포렌식 안티치트 스캐너입니다. Electron과 TypeScript로 만들어졌으며 네이티브 Win32 메모리 접근을 제공하고, Prefetch, Amcache, BAM, 레지스트리 및 브라우저 흔적, Defender 기록, DNS 캐시, 파일 해시, 반포렌식 변조 및 관련 Windows 증거를 다루는 스물한 가지 오프라인 아티팩트 스캐너를 실행한 뒤 위험 엔진으로 결과를 모아 무결성 해시가 포함된 내보낼 수 있는 보고서를 만듭니다. 선택적 Live Scan 모드는 관리자 권한으로 실행 중인 타이틀에 대해 사용할 때 주입 모듈, 코드 후크, 의심스러운 스레드, 패턴 기반 메모리 시그니처를 검출하는 스트리밍 탐지기를 구동합니다. 키워드, 해시, 시그니처 리소스가 탐지를 이끌며, 세션 후 플레이어 PC에 남는 영구 데이터는 최소화하도록 설계되었습니다. 경쟁 멀티플레이어 모더레이션, 이의 제기 문서화, Windows에서의 실습형 치트 조사 워크플로에 적합합니다.
