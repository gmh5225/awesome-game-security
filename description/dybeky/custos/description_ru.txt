Custos — настольный форензический античит-сканер для Windows, рассчитанный на сотрудников игровых серверов, которым нужно проверять игроков без опоры на работающий игровой клиент. Приложение на Electron и TypeScript с нативным доступом к памяти Win32 запускает двадцать один автономный сканер артефактов: Prefetch, Amcache, BAM, следы в реестре и браузере, история Defender, кэш DNS, хеши файлов, антифорензическое вмешательство и связанные доказательства Windows, затем сводит результаты через движок риска в экспортируемые отчёты с хешированием целостности. Дополнительный режим Live Scan при запуске от имени администратора против работающей игры потоково отслеживает внедрённые модули, перехваты кода, подозрительные потоки и сигнатуры памяти по шаблонам. Обнаружение опирается на ресурсы ключевых слов, хешей и сигнатур; после сессии на машине игрока остаётся минимум постоянных данных. Подходит для модерации соревновательного мультиплеера, документирования апелляций и практических расследований читов в Windows.
