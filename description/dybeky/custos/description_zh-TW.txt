Custos 是一款面向遊戲伺服器工作人員的 Windows 桌面取證反作弊掃描器，可在不依賴線上遊戲用戶端的情況下篩查玩家。此應用程式以 Electron 與 TypeScript 建構，並具備原生 Win32 記憶體存取能力，執行二十一種離線成品掃描器，涵蓋 Prefetch、Amcache、BAM、登錄與瀏覽器痕跡、Defender 歷史、DNS 快取、檔案雜湊、反取證竄改及相關 Windows 證據，再透過風險引擎彙整結果，產生可匯出且附完整性雜湊的報告。可選的 Live Scan 模式在以系統管理員身分針對執行中的遊戲運作時，可即時偵測注入模組、程式碼 Hook、可疑執行緒及以模式為基礎的記憶體特徵。關鍵字、雜湊與特徵庫驅動偵測邏輯，設計上在單次工作階段結束後於玩家機器上留下盡可能少的持久化資料。適用於競技多人遊戲的賽事監管、申訴取證，以及 Windows 上的實地反作弊調查流程。
