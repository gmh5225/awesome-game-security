Custos 是一款面向游戏服务器工作人员的 Windows 桌面取证反作弊扫描器，可在不依赖在线游戏客户端的情况下筛查玩家。该应用基于 Electron 与 TypeScript 构建，并具备原生 Win32 内存访问能力，运行二十一种离线工件扫描器，覆盖 Prefetch、Amcache、BAM、注册表与浏览器痕迹、Defender 历史、DNS 缓存、文件哈希、反取证篡改及相关 Windows 证据，再通过风险引擎汇总结果，生成可导出且带完整性哈希的报告。可选的 Live Scan 模式在以管理员身份针对正在运行的游戏执行时，可实时检测注入模块、代码钩子、可疑线程及基于模式的内存特征。关键词、哈希与特征库驱动检测逻辑，设计上在单次会话结束后在玩家机器上留下尽可能少的持久化数据。适用于竞技多人游戏的赛事监管、申诉取证以及 Windows 上的动手反作弊调查流程。
