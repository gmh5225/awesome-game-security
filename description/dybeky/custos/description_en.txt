Custos is a Windows desktop forensic anti-cheat scanner aimed at game server staff who need to screen players without relying on a live game client. Built as an Electron and TypeScript application with native Win32 memory access, it runs twenty-one offline artifact scanners covering Prefetch, Amcache, BAM, registry and browser traces, Defender history, DNS cache, file hashes, anti-forensics tampering, and related Windows evidence, then aggregates results through a risk engine into exportable reports with integrity hashing. An optional Live Scan mode, when run as administrator against a running title, streams detectors for injected modules, code hooks, suspicious threads, and pattern-based memory signatures. Keyword, hash, and signature resources drive detection, and the app is designed to leave minimal persistent data on the player machine after a session. It suits competitive multiplayer moderation, appeal documentation, and hands-on cheat investigation workflows on Windows.
