SIM Number Setter Pro is an open-source Android utility that reads, writes, and programs the subscriber phone number (MSISDN) into SIM card EF_MSISDN storage so the device reports a correct number instead of unknown MSISDN. It is built in Kotlin with Gradle for Android API 26–34 and combines LSPosed/Xposed hooks against com.android.phone and system framework with a root fallback via the telephony provider and shell commands on Magisk, KernelSU, or APatch. Notable capabilities include dual-SIM slot selection, E.164 validation, automatic phone-state permission grants, a telephony stack hot-restart without full reboot, and optional internal telephony stubs for low-level Phone APIs. It targets security researchers, reverse engineers, and testers who study mobile identity, SMS or OTP verification flows, carrier provisioning behavior, and how rooted or hooked devices alter telephony-reported device attributes.
