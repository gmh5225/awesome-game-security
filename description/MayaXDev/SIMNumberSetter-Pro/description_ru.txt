SIM Number Setter Pro — утилита Android с открытым исходным кодом, которая читает, записывает и программирует абонентский номер (MSISDN) в хранилище EF_MSISDN SIM-карты, чтобы устройство сообщало корректный номер вместо неизвестного MSISDN. Создана на Kotlin с Gradle для Android API 26–34 и сочетает хуки LSPosed/Xposed на com.android.phone и системный framework с root-обходом через telephony provider и shell-команды на Magisk, KernelSU или APatch. Среди возможностей: выбор слота dual SIM, проверка E.164, автоматическая выдача разрешений на состояние телефона, горячий перезапуск стека telephony без полной перезагрузки и опциональные внутренние заглушки telephony для низкоуровневых Phone API. Предназначена для исследователей безопасности, реверс-инженеров и тестировщиков, изучающих мобильную идентичность, потоки SMS или OTP, поведение оператора при провижининге и то, как устройства с root или хуками меняют атрибуты, сообщаемые telephony.
