SIM Number Setter Pro è un'utilità Android open source che legge, scrive e programma il numero dell'abbonato (MSISDN) nella memoria EF_MSISDN della SIM così che il dispositivo riporti un numero corretto invece di un MSISDN sconosciuto. È realizzata in Kotlin con Gradle per Android API 26–34 e combina hook LSPosed/Xposed su com.android.phone e il framework di sistema con un fallback root tramite il provider telephony e comandi shell su Magisk, KernelSU o APatch. Le funzionalità principali includono selezione slot dual SIM, convalida E.164, concessione automatica dei permessi di stato telefonico, riavvio a caldo dello stack telephony senza reboot completo e stub telephony interni opzionali per API Phone di basso livello. È pensata per ricercatori di sicurezza, reverse engineer e tester che studiano identità mobile, flussi di verifica SMS o OTP, provisioning dell'operatore e come dispositivi con root o hook alterano gli attributi segnalati dalla telephony.
