SIM Number Setter Pro 是一款开源 Android 工具，可读取、写入并将用户电话号码（MSISDN）编程写入 SIM 卡的 EF_MSISDN 存储，使设备显示正确号码而非未知 MSISDN。项目使用 Kotlin 与 Gradle 构建，面向 Android API 26–34，结合针对 com.android.phone 与系统框架的 LSPosed/Xposed 钩子，并在 Magisk、KernelSU 或 APatch 上通过 telephony provider 与 shell 命令提供 root 回退方案。主要能力包括双卡槽选择、E.164 校验、自动授予电话状态权限、无需整机重启即可热重启电话栈，以及面向底层 Phone API 的可选内部 telephony 桩。适用于研究移动身份、短信或 OTP 验证流程、运营商开通行为，以及 root 或 hook 设备如何改变电话侧上报属性的安全研究人员、逆向工程师与测试人员。
