SIM Number Setter Pro는 SIM 카드 EF_MSISDN 저장소에 가입자 전화번호(MSISDN)를 읽고 쓰고 기록하여 기기가 알 수 없는 MSISDN 대신 올바른 번호를 보고하도록 하는 오픈 소스 Android 유틸리티입니다. Kotlin과 Gradle로 Android API 26–34용으로 구축되었으며, com.android.phone 및 시스템 프레임워크에 대한 LSPosed/Xposed 훅과 Magisk, KernelSU 또는 APatch에서 telephony provider 및 셸 명령을 통한 root 폴백을 결합합니다. 주요 기능으로는 듀얼 SIM 슬롯 선택, E.164 검증, 전화 상태 권한 자동 부여, 전체 재부팅 없이 telephony 스택 핫 재시작, 저수준 Phone API용 선택적 내부 telephony 스텁이 있습니다. 모바일 신원, SMS 또는 OTP 인증 흐름, 이동통신사 프로비저닝 동작, root 또는 hook 기기가 telephony 보고 속성을 어떻게 바꾸는지 연구하는 보안 연구자, 리버스 엔지니어, 테스터를 대상으로 합니다.
