SIM Number Setter Pro est un utilitaire Android open source qui lit, écrit et programme le numéro d'abonné (MSISDN) dans le stockage EF_MSISDN de la carte SIM afin que l'appareil affiche un numéro correct au lieu d'un MSISDN inconnu. Il est développé en Kotlin avec Gradle pour Android API 26–34 et combine des hooks LSPosed/Xposed contre com.android.phone et le framework système avec un repli root via le fournisseur telephony et des commandes shell sur Magisk, KernelSU ou APatch. Parmi les capacités notables : sélection de slot double SIM, validation E.164, octroi automatique des permissions d'état téléphonique, redémarrage à chaud de la pile telephony sans reboot complet, et stubs telephony internes optionnels pour les API Phone bas niveau. Il s'adresse aux chercheurs en sécurité, ingénieurs reverse et testeurs qui étudient l'identité mobile, les flux de vérification SMS ou OTP, le provisionnement opérateur et la façon dont les appareils rootés ou hookés modifient les attributs rapportés par la telephony.
