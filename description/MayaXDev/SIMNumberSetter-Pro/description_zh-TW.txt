SIM Number Setter Pro 是一款開源 Android 工具，可讀取、寫入並將用戶電話號碼（MSISDN）寫入 SIM 卡的 EF_MSISDN 儲存區，使裝置顯示正確號碼而非未知 MSISDN。專案以 Kotlin 與 Gradle 建置，支援 Android API 26–34，結合針對 com.android.phone 與系統框架的 LSPosed/Xposed 掛鉤，並在 Magisk、KernelSU 或 APatch 上透過 telephony provider 與 shell 指令提供 root 備援方案。主要功能包含雙卡槽選擇、E.164 驗證、自動授予電話狀態權限、無需完整重開機即可熱重啟電話堆疊，以及面向底層 Phone API 的可選內部 telephony stub。適合研究行動身份、簡訊或 OTP 驗證流程、電信業者開通行為，以及 root 或 hook 裝置如何改變電話回報屬性的安全研究人員、逆向工程師與測試人員。
