SIM Number Setter Pro は、SIM カードの EF_MSISDN に加入者電話番号（MSISDN）を読み書き・書き込みし、端末が不明な MSISDN ではなく正しい番号を報告するようにするオープンソースの Android ユーティリティです。Kotlin と Gradle で Android API 26–34 向けに構築され、com.android.phone およびシステムフレームワークに対する LSPosed/Xposed フックと、Magisk・KernelSU・APatch 上で telephony プロバイダーとシェルコマンドによる root フォールバックを組み合わせています。主な機能にはデュアル SIM スロット選択、E.164 検証、電話状態権限の自動付与、フル再起動なしのテレフォニースタックのホット再起動、低レベル Phone API 向けのオプション内部 telephony スタブがあります。モバイルアイデンティティ、SMS や OTP 検証フロー、キャリアプロビジョニング、root や hook 端末がテレフォニー報告属性をどう変えるかを調べるセキュリティ研究者、リバースエンジニア、テスター向けです。
