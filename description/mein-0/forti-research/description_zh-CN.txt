该项目是一个概念验证（PoC），演示了 Fortinet 的 fortimon3_74.sys 内核驱动程序中的漏洞，该驱动是 FortiClient 反漏洞利用 minifilter 的一部分。该漏洞利用允许本地管理员通过向驱动的通信端口发送未经验证的 8 字节 kill 消息来终止任何进程，包括 PPL 保护的进程（如 Windows Defender 和 lsass.exe）。该 PoC 用 C 语言编写，使用 Windows Filter Manager API 连接到易受攻击的 minifilter 端口，并从内核模式终止目标进程，无需缓冲区溢出或复杂的利用链。研究文档还记录了其他根本原因，包括缺少调用方身份验证、可能导致凭据窃取的处理句柄表误用，以及由于该驱动由 Fortinet 签名而带来的显著 BYOVD 风险。它面向研究 PPL 绕过技术、易受攻击驱动滥用以及反漏洞利用产品安全性的内核安全研究人员。
