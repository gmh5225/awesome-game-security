Этот проект представляет собой доказательство концепции (PoC), демонстрирующее уязвимость в ядерном драйвере fortimon3_74.sys компании Fortinet, являющемся частью anti-exploit minifilter FortiClient. Эксплойт позволяет локальным администраторам завершать любой процесс, включая процессы, защищённые PPL, такие как Windows Defender и lsass.exe, отправляя неаутентифицированное 8-байтовое kill-сообщение на порт связи драйвера. Написанный на C, PoC использует Windows Filter Manager API для подключения к уязвимому порту minifilter и завершения целевых процессов из режима ядра без переполнения буфера или сложных цепочек эксплуатации. В исследовании также документируются дополнительные первопричины, включая отсутствие аутентификации вызывающей стороны, неправильное использование таблицы дескрипторов, которое может привести к краже учётных данных, и значительный риск BYOVD, поскольку драйвер подписан Fortinet. Предназначен для исследователей безопасности ядра, изучающих методы обхода PPL, злоупотребление уязвимыми драйверами и безопасность anti-exploit продуктов.
