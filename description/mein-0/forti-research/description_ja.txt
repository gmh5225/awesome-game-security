このプロジェクトは、FortiClient の anti-exploit minifilter の一部である Fortinet の fortimon3_74.sys カーネルドライバー内の脆弱性を示す概念実証（PoC）です。このエクスプロイトにより、ローカル管理者は、ドライバーの通信ポートに未認証の 8 バイト kill メッセージを送信することで、Windows Defender や lsass.exe などの PPL 保護プロセスを含むあらゆるプロセスを終了できます。C 言語で書かれたこの PoC は、Windows Filter Manager API を使用して脆弱な minifilter ポートに接続し、バッファオーバーフローや複雑なエクスプロイトチェーンなしで、カーネルモードから対象プロセスを終了します。本研究では、呼び出し元認証の欠如、資格情報窃取を可能にするハンドルテーブルの誤用、ドライバーが Fortinet 署名であることによる重大な BYOVD リスクなど、追加の根本原因も文書化しています。PPL バイパス手法、脆弱なドライバーの悪用、anti-exploit 製品のセキュリティを研究するカーネルセキュリティ研究者向けです。
