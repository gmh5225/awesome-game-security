Este proyecto es una prueba de concepto que demuestra una vulnerabilidad en el controlador del kernel fortimon3_74.sys de Fortinet, parte del minifilter anti-exploit de FortiClient. El exploit permite a los administradores locales terminar cualquier proceso, incluidos procesos protegidos por PPL como Windows Defender y lsass.exe, enviando un mensaje kill no autenticado de 8 bytes al puerto de comunicación del controlador. Escrito en C, el PoC utiliza la API Windows Filter Manager para conectarse al puerto minifilter vulnerable y terminar procesos objetivo desde el modo kernel, sin desbordamientos de búfer ni cadenas de explotación complejas. La investigación documenta causas fundamentales adicionales, como la falta de autenticación del llamador, el uso indebido de la tabla de handles que podría permitir el robo de credenciales, y un riesgo BYOVD significativo dado que el controlador está firmado por Fortinet. Está destinado a investigadores de seguridad del kernel que estudian técnicas de bypass de PPL, abuso de controladores vulnerables y la seguridad de productos anti-exploit.
