該專案是一個概念驗證（PoC），示範了 Fortinet 的 fortimon3_74.sys 核心驅動程式中的漏洞，該驅動是 FortiClient 反漏洞利用 minifilter 的一部分。該漏洞利用允許本機管理員透過向驅動的通訊連接埠傳送未經驗證的 8 位元組 kill 訊息來終止任何程序，包括 PPL 保護的程序（如 Windows Defender 和 lsass.exe）。該 PoC 以 C 語言撰寫，使用 Windows Filter Manager API 連線到易受攻擊的 minifilter 連接埠，並從核心模式終止目標程序，無需緩衝區溢位或複雜的利用鏈。研究文件還記錄了其他根本原因，包括缺少呼叫端身分驗證、可能導致憑證竊取的處理控制代碼表誤用，以及由於該驅動由 Fortinet 簽署而帶來的顯著 BYOVD 風險。它面向研究 PPL 繞過技術、易受攻擊驅動濫用以及反漏洞利用產品安全性的核心安全研究人員。
