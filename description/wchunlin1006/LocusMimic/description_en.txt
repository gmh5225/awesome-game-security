LocusMimic is an Android location-simulation module for rooted devices that injects configurable GPS coordinates into selected applications via Xposed or LSPosed. Written primarily in Kotlin with Jetpack Compose, it offers map-based point selection, place search, favorite locations, and fine-grained control over latitude, longitude, accuracy, altitude, speed, and random offset. The project supports three operating modes—per-app hooks, system-level hooks, and a non-root Mock Provider fallback—and builds on forks of XposedFakeLocation and HideMockLocation to help conceal mock-location indicators from targeted apps. Optional external broadcast control enables automation through adb or local intents for scripted testing workflows. It is intended for authorized app debugging, location-based anti-cheat evaluation, and security research on Android 11 and newer.
