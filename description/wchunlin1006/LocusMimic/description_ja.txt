LocusMimic は、root 化済みデバイス向けの Android 位置シミュレーションモジュールで、Xposed または LSPosed を介して選択したアプリに設定可能な GPS 座標を注入します。主に Kotlin と Jetpack Compose で書かれており、地図ベースの地点選択、場所検索、お気に入り地点、および緯度・経度・精度・高度・速度・ランダムオフセットのきめ細かな制御を提供します。プロジェクトは、アプリごとのフック、システムレベルのフック、root 不要の Mock Provider フォールバックの 3 つの動作モードをサポートし、XposedFakeLocation と HideMockLocation のフォークを基盤として、対象アプリからモック位置の表示を隠すのに役立ちます。オプションの外部ブロードキャスト制御により、adb やローカル Intent を通じた自動化が可能で、スクリプト化されたテストワークフローに対応します。Android 11 以降における、許可されたアプリのデバッグ、位置情報ベースのアンチチート評価、セキュリティ研究を目的としています。
