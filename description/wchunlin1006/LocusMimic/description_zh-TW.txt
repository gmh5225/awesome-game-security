LocusMimic 是一款面向已 root 裝置的 Android 位置模擬模組，可透過 Xposed 或 LSPosed 向指定應用程式注入可設定的 GPS 座標。專案主要使用 Kotlin 與 Jetpack Compose 撰寫，提供以地圖為基礎的選點、地點搜尋、收藏位置，以及對緯度、經度、精確度、海拔、速度與隨機偏移的精細控制。它支援三種運作模式——依應用程式 Hook、系統層級 Hook，以及無需 root 的 Mock Provider 回退方案——並基於 XposedFakeLocation 與 HideMockLocation 的分支建構，以協助向目標應用程式隱藏模擬位置指示。可選的外部廣播控制可透過 adb 或本機 Intent 實現自動化，便於腳本化測試流程。適用於經授權的應用程式除錯、基於位置的反作弊評估，以及在 Android 11 及更新版本上的安全研究。
