LocusMimic 是一款面向已 root 设备的 Android 位置模拟模块，可通过 Xposed 或 LSPosed 向指定应用注入可配置的 GPS 坐标。项目主要使用 Kotlin 与 Jetpack Compose 编写，提供基于地图的选点、地点搜索、收藏位置，以及对纬度、经度、精度、海拔、速度和随机偏移的精细控制。它支持三种运行模式——按应用 Hook、系统级 Hook，以及无需 root 的 Mock Provider 回退方案——并基于 XposedFakeLocation 与 HideMockLocation 的分支构建，以帮助向目标应用隐藏模拟位置指示。可选的外部广播控制可通过 adb 或本地 Intent 实现自动化，便于脚本化测试流程。适用于经授权的应用调试、基于位置的反作弊评估，以及在 Android 11 及更高版本上的安全研究。
