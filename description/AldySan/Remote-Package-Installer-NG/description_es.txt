Remote Package Installer NG es una aplicación de escritorio multiplataforma que instala archivos package de PlayStation 4 por una red doméstica sin unidades USB ni FTP. Está escrita en Rust con egui para la interfaz y Tokio para red asíncrona, con una biblioteca núcleo aparte que implementa el protocolo PS4 Remote Package Installer, servicio HTTP local de archivos, descubrimiento de consola y análisis de PKG. Los usuarios pueden encolar uno o varios PKG con progreso, pausa, reanudación y recuperación tras fallos que concilia el estado de instalación con la consola. Está orientada a flujos homebrew de PS4 con GoldHEN o cargas de instalador remoto de paquetes compatibles, y resulta útil para investigadores y desarrolladores que estudian la entrega de paquetes en consola, instaladores en red y protocolos de transferencia propietarios reimplementados.
