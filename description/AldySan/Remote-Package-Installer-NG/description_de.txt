Remote Package Installer NG ist eine plattformübergreifende Desktop-Anwendung, die PlayStation-4-Paketdateien über ein Heimnetzwerk installiert, ohne USB-Laufwerke oder FTP. Sie ist in Rust geschrieben, nutzt egui für die Oberfläche und Tokio für asynchrones Netzwerk, mit einer separaten Kernbibliothek, die das PS4 Remote Package Installer-Protokoll, lokale HTTP-Dateibereitstellung, Konsolenerkennung und PKG-Parsing implementiert. Nutzer können eine oder mehrere PKG-Dateien mit Fortschritt, Pause, Fortsetzung und Absturzwiederherstellung einreihen, die den Installationsstand mit der Konsole abstimmt. Sie richtet sich an PS4-Homebrew-Workflows mit GoldHEN oder kompatiblen Remote-Package-Installer-Payloads und eignet sich für Forscher und Entwickler, die Konsolen-Paketverteilung, Netzwerk-Installer und nachimplementierte proprietäre Übertragungsprotokolle untersuchen.
