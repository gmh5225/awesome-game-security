Remote Package Installer NG 是一款跨平台桌面应用，可在家庭网络上安装 PlayStation 4 的 package 文件，无需 USB 或 FTP。它使用 Rust 编写，界面采用 egui，异步网络使用 Tokio，并配有独立核心库，实现 PS4 Remote Package Installer 协议、本地 HTTP 文件服务、主机发现与 PKG 解析。用户可将一个或多个 PKG 排队安装，支持进度显示、暂停、恢复，以及通过与会机同步安装状态的崩溃恢复。面向搭配 GoldHEN 或兼容远程包安装 payload 的 PS4 自制软件工作流，适合研究主机包分发、网络安装器及专有传输协议重实现的研究者与开发者。
