Remote Package Installer NG is a cross-platform desktop application that installs PlayStation 4 package files over a home network without USB drives or FTP. It is written in Rust using egui for the interface and Tokio for async networking, with a separate core library that implements the PS4 Remote Package Installer protocol, local HTTP file serving, console discovery, and PKG parsing. Users queue one or many PKG files with progress, pause, resume, and crash recovery that reconciles install state with the console. It targets PS4 homebrew workflows with GoldHEN or compatible remote package installer payloads, and is useful for researchers and developers studying console package delivery, network installers, and reimplemented proprietary transfer protocols.
