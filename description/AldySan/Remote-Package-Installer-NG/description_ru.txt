Remote Package Installer NG — кроссплатформенное настольное приложение, которое устанавливает пакетные файлы PlayStation 4 по домашней сети без USB-накопителей и FTP. Написано на Rust: интерфейс на egui, асинхронная сеть на Tokio, отдельная основная библиотека реализует протокол PS4 Remote Package Installer, локальную раздачу файлов по HTTP, обнаружение консоли и разбор PKG. Пользователи ставят в очередь один или несколько PKG с отображением прогресса, паузой, возобновлением и восстановлением после сбоя с согласованием состояния установки с консолью. Ориентировано на homebrew-сценарии PS4 с GoldHEN или совместимыми полезными нагрузками удалённого установщика пакетов; полезно исследователям и разработчикам, изучающим доставку пакетов на консоль, сетевые установщики и реимплементации проприетарных протоколов передачи.
