Remote Package Installer NG 是一款跨平台桌面應用程式，可透過家用網路安裝 PlayStation 4 的 package 檔案，無需 USB 或 FTP。它以 Rust 撰寫，介面採用 egui，非同步網路使用 Tokio，並配有獨立核心函式庫，實作 PS4 Remote Package Installer 協定、本機 HTTP 檔案服務、主機探索與 PKG 解析。使用者可將一或多個 PKG 排隊安裝，支援進度顯示、暫停、恢復，以及透過與主機同步安裝狀態的當機復原。面向搭配 GoldHEN 或相容遠端套件安裝 payload 的 PS4 自製軟體工作流程，適合研究主機套件傳遞、網路安裝器及專有傳輸協定重實作的研究者與開發者。
