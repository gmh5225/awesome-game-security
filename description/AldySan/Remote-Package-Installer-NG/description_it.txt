Remote Package Installer NG è un’applicazione desktop multipiattaforma che installa file package PlayStation 4 su una rete domestica senza unità USB né FTP. È scritta in Rust con egui per l’interfaccia e Tokio per il networking asincrono, con una libreria core separata che implementa il protocollo PS4 Remote Package Installer, serving HTTP locale dei file, rilevamento della console e parsing dei PKG. Gli utenti possono mettere in coda uno o più PKG con avanzamento, pausa, ripresa e recupero da crash che riconcilia lo stato di installazione con la console. È pensata per flussi homebrew PS4 con GoldHEN o payload di installer remoto di package compatibili, ed è utile a ricercatori e sviluppatori che studiano la distribuzione di package su console, installer di rete e protocolli di trasferimento proprietari reimplementati.
