Remote Package Installer NG は、USB や FTP を使わずにホームネットワーク経由で PlayStation 4 のパッケージファイルをインストールするクロスプラットフォームのデスクトップアプリケーションです。Rust で実装され、UI は egui、非同期ネットワークは Tokio を使用し、PS4 Remote Package Installer プロトコル、ローカル HTTP ファイル配信、本体の検出、PKG 解析を担う独立したコアライブラリを備えています。ユーザーは 1 つまたは複数の PKG をキューに入れ、進捗表示のほか一時停止、再開、クラッシュ後に本体のインストール状態と整合させるリカバリに対応します。GoldHEN や互換のリモートパッケージインストーラペイロードを使う PS4 ホームブリュー向けで、本体へのパッケージ配信、ネットワークインストーラ、独自転送プロトコルの再実装を調べる研究者や開発者にも有用です。
