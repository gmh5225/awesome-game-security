Remote Package Installer NG는 USB나 FTP 없이 가정 네트워크를 통해 PlayStation 4 패키지 파일을 설치하는 크로스 플랫폼 데스크톱 애플리케이션입니다. Rust로 작성되었으며, 인터페이스는 egui, 비동기 네트워킹은 Tokio를 사용하고, PS4 Remote Package Installer 프로토콜, 로컬 HTTP 파일 서빙, 콘솔 탐색, PKG 파싱을 구현하는 별도의 코어 라이브러리를 둡니다. 사용자는 하나 또는 여러 PKG 파일을 대기열에 넣고 진행 상황을 보며 일시 정지, 재개, 충돌 후 콘솔의 설치 상태와 맞추는 복구를 할 수 있습니다. GoldHEN 또는 호환 원격 패키지 설치 페이로드를 쓰는 PS4 홈브류 워크플로를 대상으로 하며, 콘솔 패키지 전달, 네트워크 설치 도구, 독점 전송 프로토콜 재구현을 연구하는 연구자와 개발자에게 유용합니다.
