CrossOver Patcher 是一款實驗性的 macOS 相容性工具，用於對官方 CrossOver 安裝進行修補，以改善對受反作弊系統保護的 Windows 遊戲的支援。它面向執行 macOS 14 或更高版本的 Apple Silicon Mac，在驗證官方簽章、檔案雜湊和 PE/Mach-O 結構後，對 CrossOver 的 Wine 與圖形執行階段模組進行範圍有限、版本綁定的二進位轉換。安裝程式透過圖形化應用程式或閉源的 PatchCore CLI 運作，會建立獨立的已修補 CrossOver 副本，並提供經過驗證的備份與回復支援，同時不會修改遊戲檔案、反作弊元件及現有的 CrossOver bottles。它面向希望透過 Mac 上的 CrossOver 執行受反作弊保護的遊戲（例如 Wuthering Waves）的使用者，且明確僅支援特定的已驗證 CrossOver 發行版本。
