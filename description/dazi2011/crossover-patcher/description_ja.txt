CrossOver Patcher は、公式 CrossOver インストールにパッチを当て、反チートシステムで保護された Windows ゲームのサポートを改善する実験的な macOS 互換性ツールです。macOS 14 以降を実行する Apple Silicon Mac を対象とし、公式署名、ファイルハッシュ、PE/Mach-O 構造を検証したうえで、CrossOver の Wine およびグラフィックス ランタイム モジュールに、限定的かつバージョン固定のバイナリ変換を適用します。インストーラーはグラフィカル アプリまたはクローズドソースの PatchCore CLI 経由で動作し、認証済みバックアップとロールバック対応の別個のパッチ適用済み CrossOver コピーを作成し、ゲームファイル、反チート コンポーネント、既存の CrossOver ボトルには手を加えません。Mac 上の CrossOver を通じて Wuthering Waves など反チート保護タイトルを実行したいユーザー向けで、明示的なサポートは特定の検証済み CrossOver リリース ビルドに限定されます。
