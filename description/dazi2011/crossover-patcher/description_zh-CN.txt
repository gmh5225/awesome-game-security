CrossOver Patcher 是一款实验性的 macOS 兼容性工具，用于对官方 CrossOver 安装进行补丁，以改善对受反作弊系统保护的 Windows 游戏的兼容性。它面向运行 macOS 14 或更高版本的 Apple Silicon Mac，在验证官方签名、文件哈希和 PE/Mach-O 结构后，对 CrossOver 的 Wine 与图形运行时模块进行范围有限、版本绑定的二进制转换。安装程序通过图形界面应用或闭源的 PatchCore CLI 运行，会创建独立的已打补丁 CrossOver 副本，并提供经过验证的备份与回滚支持，同时不会修改游戏文件、反作弊组件及现有 CrossOver bottles。它面向希望通过 Mac 上的 CrossOver 运行受反作弊保护的游戏（例如 Wuthering Waves）的用户，且明确仅支持特定的已验证 CrossOver 发布版本。
