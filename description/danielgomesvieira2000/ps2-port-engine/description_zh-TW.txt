本專案是一套工具鏈與原生執行環境，透過將可執行檔反編譯為 C++ 並驗證行為與原始 MIPS 機器碼一致，將 PlayStation 2 遊戲移植到 PC。Python 函式庫 ps2decomp 與命令列工具負責 ELF 與光碟解析、R5900 與 VU 反組譯、自動化分析、符號推導、指令提升，以及相對 R5900 直譯器的差分驗證。重建的遊戲程式碼以 C++17 編譯，並連結到取代 PS2 硬體的主機層——EE 核心、IOP、DMA、SPU2、VIF、VU、手把、記憶卡與光碟 I/O——同時以 Vulkan 為基礎的 Graphics Synthesizer 渲染器與 SDL3 提供現代顯示、輸入及更高解析度、幀率調控等移植功能。專案不包含任何遊戲資源；移植以玩家自有的光碟映像建置，工作流程面向逆向工程，以促進互通、保存與研究商業 PS2 作品的結構與執行方式。
