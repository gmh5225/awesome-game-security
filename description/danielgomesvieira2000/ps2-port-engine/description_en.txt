This project is a toolchain and native runtime for turning PlayStation 2 games into PC ports by decompiling executables into C++ and checking that behavior matches the original MIPS machine code. The Python ps2decomp library and command-line tools handle ELF and disc parsing, R5900 and VU disassembly, automated analysis, symbolic derivation, instruction lifting, and differential verification against an R5900 interpreter. Reconstructed game code is built with C++17 and linked to a host that replaces PS2 hardware—EE kernel, IOP, DMA, SPU2, VIF, VUs, pads, memory cards, and disc I/O—while a Vulkan-based Graphics Synthesizer renderer and SDL3 deliver modern display, input, and port features such as higher resolution and frame pacing. It ships no game assets; ports are built from disc images the player owns, and the workflow targets reverse engineering for interoperability, preservation, and studying how commercial PS2 titles are structured and executed.
