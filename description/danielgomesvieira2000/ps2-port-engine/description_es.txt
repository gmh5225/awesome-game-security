Este proyecto es una cadena de herramientas y un runtime nativo para convertir juegos de PlayStation 2 en ports para PC descompilando ejecutables a C++ y comprobando que el comportamiento coincide con el código máquina MIPS original. La biblioteca Python ps2decomp y las herramientas de línea de comandos se encargan del análisis de ELF y discos, el desensamblado R5900 y VU, el análisis automatizado, la derivación simbólica, el lifting de instrucciones y la verificación diferencial frente a un intérprete R5900. El código del juego reconstruido se compila con C++17 y se enlaza a un host que sustituye el hardware PS2 — núcleo EE, IOP, DMA, SPU2, VIF, VUs, mandos, memory cards y E/S de disco — mientras un renderizador Graphics Synthesizer basado en Vulkan y SDL3 ofrecen visualización moderna, entrada y funciones de port como mayor resolución y frame pacing. No incluye assets del juego; los ports se construyen a partir de imágenes de disco que posee el jugador, y el flujo de trabajo apunta a la ingeniería inversa para interoperabilidad, preservación y el estudio de cómo se estructuran y ejecutan títulos comerciales de PS2.
