本プロジェクトは、PlayStation 2 向けゲームを PC 移植するためのツールチェーンとネイティブランタイムであり、実行ファイルを C++ に逆コンパイルし、挙動が元の MIPS 機械語と一致することを検証する。Python の ps2decomp ライブラリとコマンドラインツールが ELF およびディスクの解析、R5900 と VU の逆アセンブル、自動解析、記号導出、命令リフティング、R5900 インタプリタに対する差分検証を担う。再構築されたゲームコードは C++17 でビルドされ、PS2 ハードウェア（EE カーネル、IOP、DMA、SPU2、VIF、VU、パッド、メモリーカード、ディスク I/O）を置き換えるホストにリンクされる。Vulkan ベースの Graphics Synthesizer レンダラーと SDL3 がモダンな表示・入力および高解像度やフレームペーシングなどの移植機能を提供する。ゲームアセットは同梱されず、移植はプレイヤーが所有するディスクイメージから構築され、ワークフローは相互運用性、保存、および商用 PS2 タイトルの構造と実行の研究を目的としたリバースエンジニアリングを対象とする。
