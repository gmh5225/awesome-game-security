VP2S_Recomp は、Valkyrie Profile 2: Silmeria のネイティブ Windows 移植版で、オリジナルの PlayStation 2 向け MIPS R5900 実行ファイル、オーバーレイモジュール、IOP モジュールをコンソールをエミュレートするのではなく、C++ へ静的再コンパイルします。プロジェクトは PS2Recomp ツールチェーンを基盤とし、Ghidra と Emotion Engine 拡張、Python およびシェル自動化を用いて関数をマッピングし、ディスクアセットを抽出し、生成コードをカスタムランタイムとリンクしてプレイ可能な PC バイナリにします。描画、音声、UI、モデル、テクスチャ、カットシーンは OpenGL や FFmpeg などのネイティブ経路を通り、デフォルトの GS、VU1、SPU2 エミュレーションは意図的に避けつつ、ゲーム自身のロジックを維持します。静的再コンパイル、PS2 バイナリ解析、暗号化モジュール処理、フルエミュレータスタックなしでレガシーゲームコードを現代プラットフォーム向けに再構築する方法を研究するリバースエンジニア、保存活動者、研究者向けです。
