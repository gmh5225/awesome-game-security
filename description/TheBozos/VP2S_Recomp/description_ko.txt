VP2S_Recomp는 Valkyrie Profile 2: Silmeria의 네이티브 Windows 포트로, 원본 PlayStation 2 MIPS R5900 실행 파일, 오버레이 모듈, IOP 모듈을 콘솔을 에뮬레이션하는 대신 C++로 정적 재컴파일합니다. 이 프로젝트는 PS2Recomp 툴체인을 기반으로 Ghidra와 Emotion Engine 확장, Python 및 셸 자동화를 사용해 함수를 매핑하고 디스크 에셋을 추출하며, 생성된 코드를 커스텀 런타임과 링크해 플레이 가능한 PC 바이너리를 만듭니다. 렌더링, 오디오, UI, 모델, 텍스처, 컷신은 OpenGL과 FFmpeg 같은 네이티브 경로를 거치며, 기본 GS, VU1, SPU2 에뮬레이션은 의도적으로 피하면서 게임 고유 로직은 유지합니다. 정적 재컴파일, PS2 바이너리 분석, 암호화 모듈 처리, 전체 에뮬레이터 스택 없이 레거시 게임 코드를 현대 플랫폼용으로 재구축하는 방법을 연구하는 리버스 엔지니어, 보존 활동가, 연구자에게 적합합니다.
