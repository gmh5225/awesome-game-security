VP2S_Recomp 是《北欧女神 2：希尔梅莉亚》的原生 Windows 移植版，将原版 PlayStation 2 的 MIPS R5900 可执行文件、overlay 模块与 IOP 模块静态重编译为 C++，而非模拟主机。项目基于 PS2Recomp 工具链，配合 Ghidra 与 Emotion Engine 扩展以及 Python 与 shell 自动化，映射函数、提取光盘资源，并将生成代码与自定义运行时链接为可玩的 PC 二进制。渲染、音频、UI、模型、纹理与过场动画走 OpenGL、FFmpeg 等原生路径，刻意避免默认的 GS、VU1 与 SPU2 模拟，同时保留游戏自身逻辑。适合逆向工程师、游戏保存工作者以及研究静态重编译、PS2 二进制分析、加密模块处理，以及在不依赖完整模拟器栈的情况下将遗留游戏代码重建到现代平台的研究人员。
