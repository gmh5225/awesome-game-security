VP2S_Recomp is a native Windows port of Valkyrie Profile 2: Silmeria that statically recompiles the original PlayStation 2 MIPS R5900 executable, overlay modules, and IOP modules into C++ rather than emulating the console. The project builds on the PS2Recomp toolchain and uses Ghidra with the Emotion Engine extension, plus Python and shell automation, to map functions, extract disc assets, and link generated code with a custom runtime into a playable PC binary. Rendering, audio, UI, models, textures, and cutscenes run through native paths such as OpenGL and FFmpeg, deliberately avoiding default GS, VU1, and SPU2 emulation while preserving the game’s own logic. It suits reverse engineers, preservationists, and researchers studying static recompilation, PS2 binary analysis, encrypted module handling, and how legacy game code can be rebuilt for modern platforms without a full emulator stack.
