VP2S_Recomp 是《北欧女神 2：希爾梅莉亞》的原生 Windows 移植版，將原版 PlayStation 2 的 MIPS R5900 可執行檔、overlay 模組與 IOP 模組靜態重編譯為 C++，而非模擬主機。專案建置於 PS2Recomp 工具鏈之上，搭配 Ghidra 與 Emotion Engine 擴充功能，以及 Python 與 shell 自動化，以對應函式、擷取光碟資源，並將產生的程式碼與自訂執行期連結成可遊玩的 PC 二進位檔。渲染、音訊、UI、模型、紋理與過場動畫經由 OpenGL、FFmpeg 等原生路徑執行，刻意避免預設的 GS、VU1 與 SPU2 模擬，同時保留遊戲本身的邏輯。適合逆向工程師、保存工作者，以及研究靜態重編譯、PS2 二進位分析、加密模組處理，以及如何在不依賴完整模擬器堆疊的情況下將舊版遊戲程式重建到現代平台的研究人員。
