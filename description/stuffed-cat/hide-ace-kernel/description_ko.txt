Hide ACE Kernel Interfaces는 루팅된 Android 기기용 KernelSU 모듈로, Tencent와 Oplus의 커널 수준 안티치트가 노출하는 사용자 공간 proc 노드를 숨긴다. 주로 shell 서비스 스크립트로 구현되며, 빈 placeholder 파일을 만들고 /proc/inte_ko, /proc/inte_systbl, /proc/inte_status 같은 탐지 인터페이스 위에 bind 마운트하여 읽는 쪽에는 무결성 보고 대신 빈 출력이 보이게 한다. 지원 OEM 빌드에서 ACE 스타일 검사와 연관된 커널 보안 검사 모듈을 겨냥한다. 모바일 게임 안티치트, 커널 보조 집행, Android에서 사용자 공간 클라이언트가 커널에 노출된 원격 측정을 어떻게 소비하는지 연구하는 연구자와 실무자를 대상으로 한다.
