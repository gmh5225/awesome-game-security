Hide ACE Kernel Interfaces è un modulo KernelSU per dispositivi Android con root che nasconde nodi proc nello spazio utente esposti dall’anti-cheat a livello kernel di Tencent e Oplus. È implementato soprattutto come script di servizio shell che crea file placeholder vuoti e li monta in bind sopra interfacce di rilevamento come /proc/inte_ko, /proc/inte_systbl e /proc/inte_status, così chi legge vede output vuoto invece di report di integrità. L’approccio mira al modulo di controllo di sicurezza del kernel associato a verifiche in stile ACE su build OEM supportate. È pensato per ricercatori e professionisti che studiano l’anti-cheat nei giochi mobile, l’applicazione assistita dal kernel e come i client nello spazio utente consumano telemetria esposta dal kernel su Android.
