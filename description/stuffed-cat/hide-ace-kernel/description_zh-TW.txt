Hide ACE Kernel Interfaces 是一款面向已 root 之 Android 裝置的 KernelSU 模組，用於隱藏由騰訊與 Oplus 內核級反作弊所暴露的使用者空間 proc 節點。實作主要以 shell 服務腳本為主：建立空的占位檔案，並以 bind 掛載覆蓋如 /proc/inte_ko、/proc/inte_systbl 與 /proc/inte_status 等偵測介面，使讀取端看到空白輸出而非完整性報告。此做法鎖定受支援 OEM 版本上與 ACE 類檢查相關的內核安全檢查模組。供研究行動遊戲反作弊、內核輔助執行，以及 Android 上使用者空間用戶端如何消費內核暴露遙測之研究者與從業人員使用。
