Hide ACE Kernel Interfaces ist ein KernelSU-Modul für gerootete Android-Geräte, das im Userspace sichtbare proc-Knoten verbirgt, die von kernelnahem Anti-Cheat von Tencent und Oplus bereitgestellt werden. Es ist vor allem als Shell-Service-Skript umgesetzt, das leere Platzhalterdateien anlegt und per Bind-Mount über Erkennungsschnittstellen wie /proc/inte_ko, /proc/inte_systbl und /proc/inte_status legt, sodass Leser leere Ausgabe statt Integritätsberichte sehen. Der Ansatz zielt auf das mit ACE-ähnlichen Prüfungen verbundene Kernel-Sicherheitsprüfmodul auf unterstützten OEM-Builds. Er richtet sich an Forscher und Praktiker, die mobiles Spiel-Anti-Cheat, kernelgestützte Durchsetzung und den Umgang von Userspace-Clients mit vom Kernel bereitgestellter Telemetrie auf Android untersuchen.
