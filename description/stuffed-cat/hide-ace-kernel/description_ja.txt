Hide ACE Kernel Interfaces は、root 化した Android 端末向けの KernelSU モジュールで、Tencent および Oplus のカーネルレベル反チートが露出させるユーザースペースの proc ノードを隠蔽する。主に shell サービススクリプトとして実装され、空のプレースホルダファイルを作成し、/proc/inte_ko、/proc/inte_systbl、/proc/inte_status などの検出インターフェース上に bind マウントして、読み取り側には整合性レポートではなく空白の出力が見えるようにする。対応 OEM ビルドにおける ACE 系チェックに関連するカーネルセキュリティチェックモジュールを対象とする。モバイルゲーム反チート、カーネル支援による強制、Android でユーザースペースクライアントがカーネル露出テレメトリをどう利用するかを研究する研究者や実務者向けである。
