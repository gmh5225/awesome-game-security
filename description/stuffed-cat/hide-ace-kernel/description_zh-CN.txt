Hide ACE Kernel Interfaces 是一款面向已 root 的 Android 设备的 KernelSU 模块，用于隐藏由腾讯与 Oplus 内核级反作弊所暴露的用户空间 proc 节点。其实现主要依赖 shell 服务脚本：创建空的占位文件，并通过 bind 挂载覆盖诸如 /proc/inte_ko、/proc/inte_systbl 与 /proc/inte_status 等检测接口，使读取方得到空白输出而非完整性报告。该方案针对受支持 OEM 版本上与 ACE 类检查相关的内核安全校验模块。面向研究移动游戏反作弊、内核辅助强制机制 以及 Android 上用户空间客户端如何消费内核暴露遥测的研究者与从业者。
