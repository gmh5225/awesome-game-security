Hide ACE Kernel Interfaces is a KernelSU module for rooted Android devices that conceals user-space proc nodes exposed by Tencent and Oplus kernel-level anti-cheat. It is implemented mainly as a shell service script that creates empty placeholder files and bind-mounts them over detection interfaces such as /proc/inte_ko, /proc/inte_systbl, and /proc/inte_status so readers see blank output instead of integrity reports. The approach targets the kernel security check module associated with ACE-style checks on supported OEM builds. It is aimed at researchers and practitioners studying mobile game anti-cheat, kernel-assisted enforcement, and how user-space clients consume kernel-exposed telemetry on Android.
