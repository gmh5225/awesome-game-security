BloxDesk는 게임 내 텔레메트리, Discord 중재 워크플로, 서버 간 밴 집행을 연결하는 엔터프라이즈급 Roblox 안티치트 플랫폼입니다. Luau 서버 측 SDK는 4Hz로 플레이어 물리를 수동적으로 모니터링하여 스피드 핵, 비행 이상, 노클립 벽 통과, 원격 이벤트 스팸을 감지하고, 자동으로 킥하거나 밴하지 않고 사건을 보고합니다. 감지된 이벤트는 백엔드로 전달되며, Google Gemini AI가 플레이어 이의 신청 내용과 기록된 텔레메트리를 비교하여 스태프의 분류 처리를 돕습니다. Roblox Open Cloud는 인스턴스 간 신속한 제한을 가능하게 합니다. 저장소에는 ModuleScript 및 Studio 모델 형태의 SDK, 정적 HTML 문서 사이트, Discord 봇 설정 가이드가 포함되어 있으며, 서버 측 익스플로잇 탐지 및 이의 검토 파이프라인을 구축하는 Roblox 게임 개발자와 중재 팀을 대상으로 합니다.
