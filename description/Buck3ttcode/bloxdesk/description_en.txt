BloxDesk is an enterprise Roblox anti-cheat platform that links in-game telemetry, Discord moderation workflows, and cross-server ban enforcement. Its Luau server-side SDK passively monitors player physics at 4Hz to detect speed hacks, flight anomalies, noclip wall passing, and remote event spam, reporting incidents without autonomously kicking or banning players. Detected events feed a backend where Google Gemini AI compares player appeal statements against recorded telemetry to assist staff triage, while Roblox Open Cloud enables rapid cross-instance restrictions. The repository includes the SDK as a ModuleScript and Studio model, plus a static HTML documentation site and Discord bot setup guides. It is aimed at Roblox game developers and moderation teams building server-side exploit detection and appeal review pipelines.
