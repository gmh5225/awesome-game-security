BloxDesk 是一款企业级 Roblox 反作弊平台，将游戏内遥测、Discord 审核工作流与跨服封禁执行整合在一起。其 Luau 服务端 SDK 以 4Hz 频率被动监控玩家物理行为，检测加速外挂、飞行异常、穿墙（noclip）以及远程事件刷屏，并上报事件而不会自动踢出或封禁玩家。检测到的事件会进入后端，由 Google Gemini AI 将玩家申诉内容与记录的遥测数据进行比对，协助工作人员分流处理；Roblox Open Cloud 则支持快速跨实例限制。本仓库包含以 ModuleScript 和 Studio 模型形式提供的 SDK，以及静态 HTML 文档站点和 Discord 机器人配置指南，面向需要构建服务端漏洞检测与申诉审核流程的 Roblox 游戏开发者与审核团队。
