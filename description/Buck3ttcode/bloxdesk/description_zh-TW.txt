BloxDesk 是一款企業級 Roblox 反作弊平台，整合遊戲內遙測、Discord 審核工作流程與跨伺服器封禁執行。其 Luau 伺服器端 SDK 以 4Hz 頻率被動監控玩家物理行為，偵測加速外掛、飛行異常、穿牆（noclip）以及遠端事件刷屏，並回報事件而不會自動踢出或封禁玩家。偵測到的事件會進入後端，由 Google Gemini AI 將玩家申訴內容與記錄的遙測資料進行比對，協助工作人員分流處理；Roblox Open Cloud 則支援快速跨實例限制。本儲存庫包含以 ModuleScript 與 Studio 模型形式提供的 SDK，以及靜態 HTML 文件網站與 Discord 機器人設定指南，面向需要建構伺服器端漏洞偵測與申訴審核流程的 Roblox 遊戲開發者與審核團隊。
