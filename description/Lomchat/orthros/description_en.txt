Orthros is a browser-based runtime that runs unmodified Windows game executables in the client using local CPU, memory, and graphics resources. It implements 32-bit x86 emulation with a reference interpreter and a dynamic x86-to-WebAssembly JIT, a PE32 loader, and Win32 and DirectX APIs reimplemented on top of browser primitives, with game assets served through a virtual filesystem over HTTP. The stack is primarily plain ECMAScript modules on Node.js and in the browser, supplemented by Python and native C tooling for CPU conformance testing and benchmarks. It also supports dedicated browser ports for select titles via WebAssembly engines such as GoldSrc and decompiled re3-family builds. The project targets preservation and in-browser play of legacy PC games and offers a deep, inspectable execution environment useful to researchers studying binary loading, API behavior, and client-side emulation fidelity.
