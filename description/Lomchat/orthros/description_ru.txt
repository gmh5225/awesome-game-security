Orthros — браузерная среда выполнения, которая запускает неизменённые исполняемые файлы Windows-игр на клиенте, используя локальные ресурсы CPU, памяти и графики. Реализована 32-разрядная эмуляция x86 с эталонным интерпретатором и динамическим JIT перевода x86 в WebAssembly, загрузчиком PE32 и заново реализованными поверх примитивов браузера API Win32 и DirectX; игровые ресурсы подаются через виртуальную файловую систему по HTTP. Стек в основном состоит из простых модулей ECMAScript на Node.js и в браузере, дополненных Python и нативными C-инструментами для тестов соответствия CPU и бенчмарков. Также поддерживаются выделенные браузерные порты отдельных игр через движки WebAssembly, такие как GoldSrc, и декомпилированные сборки семейства re3. Проект нацелен на сохранение и игру в браузере унаследованных PC-игр и даёт глубоко просматриваемую среду выполнения, полезную исследователям бинарной загрузки, поведения API и точности клиентской эмуляции.
