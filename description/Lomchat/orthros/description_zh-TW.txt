Orthros 是一種以瀏覽器為基礎的執行環境，可在用戶端透過本機 CPU、記憶體與圖形資源執行未經修改的 Windows 遊戲可執行檔。它實作 32 位元 x86 模擬，包含參考解譯器與動態 x86 轉 WebAssembly 的 JIT、PE32 載入器，並在瀏覽器原語之上重新實作 Win32 與 DirectX API，遊戲資產則透過 HTTP 上的虛擬檔案系統提供。技術堆疊主要以 Node.js 與瀏覽器中的純 ECMAScript 模組為主，並以 Python 與原生 C 工具輔助 CPU 一致性測試與效能基準。專案也支援透過 GoldSrc 等 WebAssembly 引擎及反編譯的 re3 系列建置，為部分作品提供專用瀏覽器移植。其目標是保存舊版 PC 遊戲並支援在瀏覽器中遊玩，同時為研究二進位載入、API 行為與用戶端模擬保真度的研究人員提供可深入檢視的執行環境。
