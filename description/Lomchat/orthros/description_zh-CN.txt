Orthros 是一种基于浏览器的运行时，可在客户端借助本地 CPU、内存与图形资源运行未经修改的 Windows 游戏可执行文件。它实现 32 位 x86 仿真，包含参考解释器与动态 x86 转 WebAssembly 的 JIT、PE32 加载器，并在浏览器原语之上重实现 Win32 与 DirectX API，游戏资源通过 HTTP 上的虚拟文件系统提供。技术栈主要为 Node.js 与浏览器中的纯 ECMAScript 模块，并以 Python 与原生 C 工具辅助 CPU 一致性测试与基准测试。项目还支持通过 GoldSrc 等 WebAssembly 引擎及反编译的 re3 系列构建为部分作品提供专用浏览器移植。其目标是保存遗留 PC 游戏并支持在浏览器中游玩，同时为研究二进制加载、API 行为与客户端仿真保真度的研究人员提供可深入检视的执行环境。
