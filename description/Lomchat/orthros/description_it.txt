Orthros è un runtime basato sul browser che esegue eseguibili di giochi Windows non modificati sul client usando CPU, memoria e risorse grafiche locali. Implementa l’emulazione x86 a 32 bit con un interprete di riferimento e un JIT dinamico da x86 a WebAssembly, un loader PE32 e API Win32 e DirectX reimplementate sopra le primitive del browser, con gli asset di gioco serviti tramite un filesystem virtuale su HTTP. Lo stack è principalmente moduli ECMAScript semplici su Node.js e nel browser, affiancati da Python e strumenti nativi in C per test di conformità della CPU e benchmark. Supporta anche port dedicate nel browser per titoli selezionati tramite motori WebAssembly come GoldSrc e build decompilate della famiglia re3. Il progetto mira alla conservazione e al gioco nel browser di giochi PC legacy e offre un ambiente di esecuzione approfondito e ispezionabile utile ai ricercatori che studiano il caricamento binario, il comportamento delle API e la fedeltà dell’emulazione lato client.
