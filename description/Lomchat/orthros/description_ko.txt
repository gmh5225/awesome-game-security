Orthros는 브라우저 기반 런타임으로, 로컬 CPU·메모리·그래픽 리소스를 사용해 클라이언트에서 수정하지 않은 Windows 게임 실행 파일을 실행한다. 32비트 x86 에뮬레이션을 구현하며, 참조 인터프리터와 동적 x86-to-WebAssembly JIT, PE32 로더, 브라우저 프리미티브 위에 재구현한 Win32 및 DirectX API를 갖추고, 게임 에셋은 HTTP를 통한 가상 파일 시스템으로 제공한다. 스택은 주로 Node.js와 브라우저의 순수 ECMAScript 모듈로 이루어지며, CPU 적합성 테스트와 벤치마크를 위해 Python과 네이티브 C 도구를 보조로 쓴다. GoldSrc 같은 WebAssembly 엔진이나 디컴파일된 re3 계열 빌드를 통한 일부 타이틀 전용 브라우저 포트도 지원한다. 레거시 PC 게임 보존과 브라우저 내 플레이를 목표로 하며, 바이너리 로딩, API 동작, 클라이언트 측 에뮬레이션 충실도를 연구하는 연구자에게 깊이 있게 검사 가능한 실행 환경을 제공한다.
