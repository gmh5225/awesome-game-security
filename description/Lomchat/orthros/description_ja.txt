Orthros はブラウザベースのランタイムで、ローカルの CPU・メモリ・グラフィックス資源を用いてクライアント上で改変なしの Windows ゲーム実行ファイルを動かす。32 ビット x86 エミュレーションを実装し、リファレンスインタプリタと動的な x86 から WebAssembly への JIT、PE32 ローダー、ブラウザのプリミティブ上に再実装した Win32 および DirectX API を備え、ゲームアセットは HTTP 経由の仮想ファイルシステムで提供する。スタックは主に Node.js とブラウザ上のプレーンな ECMAScript モジュールで構成され、CPU 適合性テストとベンチマーク用に Python とネイティブ C ツールを併用する。GoldSrc などの WebAssembly エンジンやデコンパイルされた re3 系ビルドを通じた、特定タイトル向けの専用ブラウザ移植にも対応する。レガシー PC ゲームの保存とブラウザ内プレイを目指し、バイナリロード、API 挙動、クライアント側エミュレーションの忠実度を研究する研究者にとって深く検査可能な実行環境を提供する。
