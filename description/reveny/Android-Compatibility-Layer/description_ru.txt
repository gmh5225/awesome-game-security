Android Compatibility Layer (ACL) — это слой трансляции, который запускает пакеты Android APK напрямую на x86_64 Linux без виртуальных машин, контейнеров или полных образов системы Android. Байткод Dex выполняется в ART-среде, собранной для хоста из AOSP, а нативные библиотеки arm64-v8a заранее перекомпилируются в x86_64 с помощью LLVM или выполняются по JIT-пути, чтобы приложения и игры с большой долей нативного кода избегали медленной эмуляции ARM. Проект заново реализует фреймворк Android на Linux с использованием Wayland, Vulkan и OpenGL ES, FreeType и HarfBuzz, SQLite и PipeWire и может изолировать гостевой код в песочнице с seccomp, Landlock и изолированными пространствами имён PID и сети. Он предназначен для запуска, тестирования и анализа Android-приложений и игр на Wayland Linux, в том числе для сценариев, ориентированных на безопасность, где нужна нативная графика на хосте и переведённый нативный код вместо полного контейнеризованного Android-стека.
