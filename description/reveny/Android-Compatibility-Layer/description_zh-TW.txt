Android Compatibility Layer（ACL）是一種轉譯層，可在 x86_64 Linux 上直接執行 Android APK 套件，無需虛擬機、容器或完整 Android 系統映像。Dex 位元組碼在基於 AOSP 建置的主機 ART 執行環境上執行，而 arm64-v8a 原生函式庫透過 LLVM 預先重編譯為 x86_64，或經 JIT 路徑執行，使原生依賴較重的應用程式與遊戲避免緩慢的 ARM 模擬。此專案在 Linux 上使用 Wayland、Vulkan 與 OpenGL ES、FreeType 與 HarfBuzz、SQLite 以及 PipeWire 重新實作 Android 框架，並可透過 seccomp、Landlock 以及隔離的 PID 與網路命名空間對來賓程式碼進行沙箱隔離。它面向在 Wayland Linux 上執行、測試與分析 Android 應用程式與遊戲，包括希望採用主機原生圖形與轉譯後原生程式碼、而非完整容器化 Android 堆疊的安全相關工作流程。
