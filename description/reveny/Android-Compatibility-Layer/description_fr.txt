Android Compatibility Layer (ACL) est une couche de traduction qui exécute directement des paquets APK Android sur Linux x86_64 sans machines virtuelles, conteneurs ni images système Android complètes. Le bytecode Dex s’exécute sur un runtime ART construit pour l’hôte à partir d’AOSP, tandis que les bibliothèques natives arm64-v8a sont recompilées à l’avance en x86_64 avec LLVM ou passent par un chemin JIT, afin que les applications et jeux très natifs évitent une émulation ARM lente. Le projet réimplémente le framework Android sur Linux avec Wayland, Vulkan et OpenGL ES, FreeType et HarfBuzz, SQLite et PipeWire, et peut isoler le code invité dans un bac à sable via seccomp, Landlock et des espaces de noms PID et réseau isolés. Il vise l’exécution, les tests et l’analyse d’applications et jeux Android sur Linux Wayland, y compris des flux orientés sécurité où l’on préfère des graphismes natifs sur l’hôte et du code natif traduit plutôt qu’une pile Android conteneurisée complète.
