Android Compatibility Layer（ACL）は、仮想マシン、コンテナ、完全な Android システムイメージを使わずに、x86_64 Linux 上で Android APK パッケージを直接実行するための変換レイヤーです。Dex バイトコードは AOSP 由来のホスト向け ART ランタイム上で実行され、arm64-v8a ネイティブライブラリは LLVM による事前コンパイルで x86_64 に変換されるか、JIT 経路で実行されるため、ネイティブ依存の高いアプリやゲームは遅い ARM エミュレーションを避けられます。本プロジェクトは Wayland、Vulkan と OpenGL ES、FreeType と HarfBuzz、SQLite、PipeWire を用いて Linux 上に Android フレームワークを再実装し、seccomp、Landlock、分離された PID およびネットワーク名前空間でゲストコードをサンドボックス化できます。Wayland Linux 上で Android アプリやゲームの実行、テスト、分析を目的としており、完全なコンテナ化 Android スタックの代わりにホストネイティブのグラフィックスと変換済みネイティブコードを求めるセキュリティ重視のワークフローにも向いています。
