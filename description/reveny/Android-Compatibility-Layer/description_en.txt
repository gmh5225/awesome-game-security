Android Compatibility Layer (ACL) is a translation layer that runs Android APK packages directly on x86_64 Linux without virtual machines, containers, or full Android system images. Dex bytecode executes on a host-built ART runtime from AOSP, while arm64-v8a native libraries are recompiled ahead of time to x86_64 with LLVM or run through a JIT path so native-heavy apps and games avoid slow ARM emulation. The project reimplements the Android framework on Linux using Wayland, Vulkan and OpenGL ES, FreeType and HarfBuzz, SQLite, and PipeWire, and can sandbox guest code with seccomp, Landlock, and isolated PID and network namespaces. It is aimed at running, testing, and analyzing Android apps and games on Wayland Linux, including security-minded workflows where you want host-native graphics and translated native code instead of a full containerized Android stack.
