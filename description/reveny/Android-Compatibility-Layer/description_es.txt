Android Compatibility Layer (ACL) es una capa de traducción que ejecuta paquetes APK de Android directamente en Linux x86_64 sin máquinas virtuales, contenedores ni imágenes completas del sistema Android. El bytecode Dex se ejecuta en un runtime ART compilado para el host a partir de AOSP, mientras que las bibliotecas nativas arm64-v8a se recompilan por adelantado a x86_64 con LLVM o se ejecutan mediante una ruta JIT, de modo que aplicaciones y juegos con mucho código nativo evitan una emulación ARM lenta. El proyecto reimplementa el framework de Android en Linux usando Wayland, Vulkan y OpenGL ES, FreeType y HarfBuzz, SQLite y PipeWire, y puede aislar el código invitado en un sandbox con seccomp, Landlock y espacios de nombres PID y de red aislados. Está orientado a ejecutar, probar y analizar aplicaciones y juegos de Android en Linux con Wayland, incluidos flujos de trabajo centrados en seguridad en los que se prefieren gráficos nativos del host y código nativo traducido en lugar de una pila Android contenedorizada completa.
