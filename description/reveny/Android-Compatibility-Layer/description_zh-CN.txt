Android Compatibility Layer（ACL）是一种翻译层，可在 x86_64 Linux 上直接运行 Android APK 包，无需虚拟机、容器或完整 Android 系统镜像。Dex 字节码在基于 AOSP 构建的主机 ART 运行时上执行，而 arm64-v8a 原生库通过 LLVM 提前重编译为 x86_64，或经 JIT 路径运行，使原生依赖较重的应用与游戏避免缓慢的 ARM 模拟。该项目在 Linux 上使用 Wayland、Vulkan 与 OpenGL ES、FreeType 与 HarfBuzz、SQLite 以及 PipeWire 重新实现 Android 框架，并可通过 seccomp、Landlock 以及隔离的 PID 与网络命名空间对来宾代码进行沙箱隔离。它面向在 Wayland Linux 上运行、测试与分析 Android 应用与游戏，包括希望采用主机原生图形与翻译后原生代码、而非完整容器化 Android 栈的安全相关工作流。
