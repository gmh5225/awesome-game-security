This project is a structured documentation site and data dump for the Wardogs multiplayer shooter, pairing long-form design notes with exported Unreal Engine configuration and balance assets. It is built as a Jekyll static site with custom styling and helper scripts, and ships large JSON datasets for gameplay tags, weapons, projectiles, vehicles, player input, rewards, and related curves under a mirrored content tree. Markdown notes explain combat and damage pipelines, gameplay effects, AI, progression, and individual game features such as aim assist, teamkill tracking, and account watermarking. Python utilities generate or link tables for infantry damage, vehicles, and zone rewards, while small JavaScript assets support browsing the material. The collection targets researchers and analysts who need authoritative reference on Wardogs mechanics for reverse engineering, balance study, and game security or anti-cheat work.
