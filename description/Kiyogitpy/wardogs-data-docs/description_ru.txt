Этот проект — структурированный сайт документации и дамп данных для многопользовательского шутера Wardogs: длинные заметки по дизайну сочетаются с экспортированными конфигурациями Unreal Engine и балансными ассетами. Сайт собран на Jekyll как статический, с собственным оформлением и вспомогательными скриптами; в зеркальном дереве контента публикуются крупные JSON-наборы по gameplay tags, оружию, снарядам, технике, вводу игрока, наградам и связанным кривым. Заметки в Markdown описывают боевые и уронные пайплайны, gameplay effects, ИИ, прогрессию и отдельные функции — aim assist, учёт teamkill, watermark аккаунта. Утилиты на Python формируют или связывают таблицы урона пехоты, техники и наград зон; небольшие JavaScript-ресурсы облегчают просмотр материалов. Коллекция рассчитана на исследователей и аналитиков, которым нужна авторитетная справка по механикам Wardogs для реверс-инжиниринга, изучения баланса и работы в области игровой безопасности или античита.
