이 프로젝트는 멀티플레이어 슈터 Wardogs를 위한 구조화된 문서 사이트 및 데이터 덤프로, 장문 설계 노트와 내보낸 Unreal Engine 설정 및 밸런스 에셋을 함께 제공합니다. Jekyll 정적 사이트로 구축되었으며 사용자 정의 스타일과 헬퍼 스크립트를 포함하고, 미러된 콘텐츠 트리 아래 gameplay tags, 무기, 발사체, 차량, 플레이어 입력, 보상 및 관련 커브 등 대용량 JSON 데이터셋을 제공합니다. Markdown 노트는 전투 및 피해 파이프라인, gameplay effects, AI, 진행, 에임 보조, 팀킬 추적, 계정 워터마킹 같은 개별 게임 기능을 설명합니다. Python 유틸리티는 보병 피해, 차량, 구역 보상 등 표를 생성하거나 연결하고, 소규모 JavaScript 에셋이 자료 탐색을 지원합니다. 이 모음은 리버스 엔지니어링, 밸런스 연구, 게임 보안 또는 안티치트 작업을 위해 Wardogs 메커니즘에 대한 신뢰할 수 있는 참고 자료가 필요한 연구자와 분석가를 대상으로 합니다.
