本專案是多人射擊遊戲 Wardogs 的結構化文件站點與資料傾印，將長篇設計說明與匯出的 Unreal Engine 設定及平衡資源一併提供。它以 Jekyll 靜態站點建置，含自訂樣式與輔助腳本，並在鏡像內容樹中提供大量 JSON 資料集，涵蓋 gameplay tags、武器、投射物、載具、玩家輸入、獎勵及相關曲線等。Markdown 筆記說明戰鬥與傷害管線、gameplay effects、AI、進度以及瞄準輔助、隊友傷害追蹤、帳號浮水印等個別功能。Python 工具用於產生或連結步兵傷害、載具與區域獎勵等表格，少量 JavaScript 資源便於瀏覽資料。此集合面向需要 Wardogs 機制權威參考的研究者與分析師，用於逆向工程、平衡研究與遊戲安全或反作弊工作。
