本项目是多人射击游戏 Wardogs 的结构化文档站点与数据导出，将长篇设计说明与导出的 Unreal Engine 配置及平衡资源一并提供。它以 Jekyll 静态站点构建，含自定义样式与辅助脚本，并在镜像内容树中提供大量 JSON 数据集，涵盖 gameplay tags、武器、投射物、载具、玩家输入、奖励及相关曲线等。Markdown 笔记说明战斗与伤害管线、gameplay effects、AI、进度以及瞄准辅助、队友伤害追踪、账号水印等具体功能。Python 工具用于生成或关联步兵伤害、载具与区域奖励等表格，少量 JavaScript 资源便于浏览资料。该集合面向需要 Wardogs 机制权威参考的研究者与分析师，用于逆向工程、平衡研究与游戏安全或反作弊工作。
