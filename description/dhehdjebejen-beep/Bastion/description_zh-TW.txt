Bastion 是一套面向 Minecraft Fabric 1.21.11 的伺服器端安全套件，透過三個無需用戶端安裝即可協同運作的模組，保護離線模式伺服器。專案以 Java 與 Gradle 撰寫，整合了 BastionAuth（採用 Argon2id 雜湊的強化登入與註冊、登入前封包防火牆、TOTP 雙因素驗證及多帳號偵測）、BastionClaims（透過伺服器端 mixin 實現領地保護，抵禦爆炸、流體、活塞、漏斗等破壞行為）以及 BastionAC（含 38 項基於結果與簽名的檢測、具衰減機制的緩衝違規等級，並針對 Meteor 與 Wurst 作弊用戶端）。各模組透過軟反射橋接整合，可獨立運行也可組合使用，並提供遊戲內管理面板、可設定閾值及大量單元測試。它面向需要在破解版或離線模式 Fabric 伺服器上實現分層帳號安全、領地保護與公平競技管理的服主。
