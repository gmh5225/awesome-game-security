Bastion 是一套面向 Minecraft Fabric 1.21.11 的服务端安全套件，通过三个无需客户端安装即可协同工作的模组保护离线模式服务器。项目使用 Java 与 Gradle 编写，整合了 BastionAuth（采用 Argon2id 哈希的强化登录与注册、登录前数据包防火墙、TOTP 双因素认证及多账号检测）、BastionClaims（通过服务端 mixin 实现领地保护，抵御爆炸、流体、活塞、漏斗等破坏行为）以及 BastionAC（含 38 项基于结果与签名的检测、带衰减的缓冲违规等级，并针对 Meteor 与 Wurst 作弊客户端）。各模块通过软反射桥接集成，可独立运行也可组合使用，并提供游戏内管理面板、可配置阈值及大量单元测试。它面向需要在破解版或离线模式 Fabric 服务器上实现分层账号安全、领地保护与公平竞技管理的服主。
