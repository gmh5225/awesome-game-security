Bastion is a server-side security suite for Minecraft Fabric 1.21.11 that protects offline-mode servers through three cooperating mods requiring no client installation. Written in Java with Gradle, it combines BastionAuth for hardened login and registration using Argon2id hashing, a pre-login packet firewall, TOTP two-factor authentication, and multi-account detection; BastionClaims for land protection enforced through server-side mixins against griefing vectors such as explosions, fluids, pistons, and hoppers; and BastionAC, an anti-cheat engine with 38 outcome- and signature-based checks, buffered violation levels with decay, and targeted coverage of Meteor and Wurst cheat clients. The modules integrate through soft reflection bridges so each can run standalone or together, and include in-game staff panels, configurable thresholds, and extensive unit tests. It is aimed at Minecraft server operators who need layered account security, territory protection, and fair-play enforcement on cracked or offline-mode Fabric servers.
