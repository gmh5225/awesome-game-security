Bastion は Minecraft Fabric 1.21.11 向けのサーバー側セキュリティスイートで、クライアント側のインストールを必要としない 3 つの連携モッドにより、オフラインモードのサーバーを保護します。Java と Gradle で書かれており、Argon2id ハッシュによる強化されたログイン・登録、ログイン前パケットファイアウォール、TOTP 二要素認証、複数アカウント検出を担う BastionAuth、爆発・液体・ピストン・ホッパーなどのグリーフィング手段に対してサーバー側 mixin で領地保護を強制する BastionClaims、38 種類の結果・シグネチャベースの検査、減衰付きバッファ違反レベル、Meteor および Wurst チートクライアント向けの重点カバレッジを備えた BastionAC というアンチチートエンジンを組み合わせています。各モジュールはソフトリフレクションブリッジで統合され、単体でも連携でも動作し、ゲーム内スタッフパネル、設定可能な閾値、充実したユニットテストも含みます。クラック版やオフラインモードの Fabric サーバーで、多層のアカウントセキュリティ、領地保護、フェアプレイの強制が必要な Minecraft サーバー運営者向けです。
