Velox は Rust ネイティブの互換レイヤーで、Windows 上で Xbox Series の x86-64 ゲームバイナリを変更せずに、CPU の完全エミュレーションなしで実行できる。制御されたプロセス内で PE 実行ファイルと DLL を読み込み、コンソール GPU バイトコードを DXIL に変換（ディスクキャッシュは任意）し、既定で D3D12 を使う差し替え可能な GPU・オーディオ・入力バックエンドを公開する。組み込みサンドボックスは既定でメモリ分離、ページガード、API ホワイトリストを適用し、Axum HTTP サーバーがライブ FPS とメモリ指標を報告してリモートコマンドを受け付ける。動的プラグインはバイナリをパッチせずにフレーム・入力・シェーダーイベントにフックでき、BCPack と Zlib デコードによる並列アセットストリーミングも備える。保存・改造・研究のため、コンソールタイトルの挙動を PC ハードウェア上で拡張・検証可能な手段を求めるユーザー向けのプロジェクトである。
