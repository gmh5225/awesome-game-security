Velox 是一个以 Rust 编写的原生兼容层，可在 Windows 上无需完整 CPU 仿真即可运行未经修改的 Xbox Series x86-64 游戏二进制。它在受控进程中加载 PE 可执行文件与 DLL，将主机 GPU 字节码翻译为 DXIL（可选磁盘缓存），并提供可替换的 GPU、音频与输入后端，默认使用 D3D12。内置沙箱默认启用内存隔离、页保护与 API 白名单；Axum HTTP 服务器上报实时 FPS 与内存指标并接受远程命令。动态插件可在不修补二进制的情况下挂钩帧、输入与着色器事件，并支持通过 BCPack 与 Zlib 解码的并行资源流式加载。该项目面向需要可扩展、可测试方式来研究与扩展主机游戏在 PC 硬件上行为的保存者、模组作者与研究人员。
