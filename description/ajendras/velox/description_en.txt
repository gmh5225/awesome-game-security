Velox is a Rust-native compatibility layer that runs unaltered Xbox Series x86-64 game binaries on Windows without full CPU emulation. It loads PE executables and DLLs in a controlled process, translates console GPU bytecode to DXIL with optional disk caching, and exposes swappable GPU, audio, and input backends with D3D12 as the default. A built-in sandbox applies memory isolation, page guards, and API whitelisting by default, while an Axum HTTP server reports live FPS and memory metrics and accepts remote commands. Dynamic plugins can hook frame, input, and shader events without patching binaries, alongside parallel asset streaming with BCPack and Zlib decode. The project targets preservationists, modders, and researchers who need an extensible, testable way to study and extend console title behavior on PC hardware.
