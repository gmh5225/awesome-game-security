Velox 是以 Rust 撰寫的原生相容層，可在 Windows 上無需完整 CPU 模擬即可執行未經修改的 Xbox Series x86-64 遊戲二進位檔。它在受控程序中載入 PE 可執行檔與 DLL，將主機 GPU 位元組碼轉譯為 DXIL（可選磁碟快取），並提供可替換的 GPU、音訊與輸入後端，預設使用 D3D12。內建沙箱預設啟用記憶體隔離、分頁保護與 API 白名單；Axum HTTP 伺服器回報即時 FPS 與記憶體指標並接受遠端命令。動態外掛可在不修補二進位檔的情況下掛接影格、輸入與著色器事件，並支援透過 BCPack 與 Zlib 解碼的並行資產串流。本專案面向需要可擴充、可測試方式來研究與延伸主機遊戲在 PC 硬體上行為的保存者、模組作者與研究人員。
