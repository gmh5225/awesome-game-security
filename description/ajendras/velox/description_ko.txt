Velox는 Rust 기반 네이티브 호환 계층으로, Windows에서 전체 CPU 에뮬레이션 없이 수정되지 않은 Xbox Series x86-64 게임 바이너리를 실행한다. 제어된 프로세스에서 PE 실행 파일과 DLL을 로드하고, 콘솔 GPU 바이트코드를 DXIL로 변환(선택적 디스크 캐싱)하며, 기본값으로 D3D12를 쓰는 교체 가능한 GPU·오디오·입력 백엔드를 제공한다. 내장 샌드박스는 기본적으로 메모리 격리, 페이지 가드, API 화이트리스트를 적용하고, Axum HTTP 서버가 실시간 FPS와 메모리 지표를 보고하며 원격 명령을 받는다. 동적 플러그인은 바이너리 패치 없이 프레임·입력·셰이더 이벤트에 후킹할 수 있고, BCPack과 Zlib 디코딩을 통한 병렬 에셋 스트리밍도 지원한다. 콘솔 타이틀 동작을 PC 하드웨어에서 연구·확장할 수 있는 확장 가능하고 테스트 가능한 방법이 필요한 보존가, 모더, 연구자를 대상으로 하는 프로젝트다.
