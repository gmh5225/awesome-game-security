一款基於 Frida 的工具，可從越獄 iOS 裝置上正在執行的 Unity 應用程式中提取經過去混淆的 IL2CPP global-metadata 標頭，輸出適用於 Il2CppDumper 及類似逆向工程流程。Python 控制器透過 bundle ID 啟動目標應用程式，並注入 JavaScript Frida 代理，在 UnityFramework 內 hook il2cpp_init，於執行時去混淆後擷取乾淨的標頭，並以標準 0xFAB11BAF 魔數驗證。預設 v4 代理在提供偏移時自適應嘗試基於偏移的快速 hook，若偏移缺失或已失效則自動回退至 Stalker 驅動的動態暫存器掃描；舊版 v2 與 v3 代理可用於僅掃描或僅偏移模式。面向獲授權測試 iOS 遊戲與應用程式的研究人員，用於分析 IL2CPP 內部機制與中繼資料配置，且不修改應用程式狀態。
