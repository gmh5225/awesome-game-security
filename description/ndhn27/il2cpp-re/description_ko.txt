Frida 기반 도구로, 탈옥된 iOS에서 실행 중인 Unity 앱으로부터 난독화가 해제된 IL2CPP global-metadata 헤더를 추출하여 Il2CppDumper 및 유사한 리버스 엔지니어링 워크플로에 적합한 출력을 생성합니다. Python 컨트롤러가 bundle ID로 대상 앱을 실행하고 JavaScript Frida 에이전트를 주입하여 UnityFramework 내부의 il2cpp_init을 후킹하고, 런타임 난독화 해제 후 깨끗한 헤더를 캡처하며 표준 0xFAB11BAF 매직 값으로 검증합니다. 기본 v4 에이전트는 오프셋이 제공되면 빠른 오프셋 기반 후킹을 적응적으로 시도하고, 오프셋이 없거나 오래된 경우 Stalker 기반 동적 레지스터 스캔으로 자동 폴백합니다. 레거시 v2 및 v3 에이전트는 스캔 전용 또는 오프셋 전용 용도로 사용할 수 있습니다. 본 도구는 IL2CPP 내부 구조와 메타데이터 레이아웃을 분석하는 연구자를 대상으로 하며, 테스트 권한이 있는 iOS 게임 및 앱을 대상으로 하고 애플리케이션 상태는 수정하지 않습니다.
