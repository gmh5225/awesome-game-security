Frida ベースのツールで、脱獄済み iOS 上で実行中の Unity アプリから、難読化解除済みの IL2CPP global-metadata ヘッダーを抽出し、Il2CppDumper や類似のリバースエンジニアリングワークフローに適した出力を生成します。Python コントローラーが bundle ID で対象アプリを起動し、JavaScript の Frida エージェントを注入して UnityFramework 内の il2cpp_init をフックし、実行時の難読化解除後にクリーンなヘッダーを取得します。標準の 0xFAB11BAF マジック値で検証されます。デフォルトの v4 エージェントは、オフセットが指定されていれば高速なオフセットベースのフックを適応的に試行し、オフセットが欠落または古い場合は Stalker 駆動の動的レジスタスキャンへ自動的にフォールバックします。レガシーの v2 および v3 エージェントは、スキャンのみまたはオフセットのみの用途に利用できます。本ツールは、IL2CPP の内部構造やメタデータレイアウトを分析する研究者向けで、テスト権限のある iOS ゲームやアプリを対象とし、アプリケーションの状態は変更しません。
