一款基于 Frida 的工具，可从越狱 iOS 设备上正在运行的 Unity 应用中提取经过去混淆的 IL2CPP global-metadata 头，输出适用于 Il2CppDumper 及类似逆向工程流程。Python 控制器通过 bundle ID 启动目标应用，并注入 JavaScript Frida 代理，在 UnityFramework 内 hook il2cpp_init，于运行时去混淆后捕获干净的头部，并以标准 0xFAB11BAF 魔数验证。默认 v4 代理在提供偏移时自适应尝试基于偏移的快速 hook，若偏移缺失或已失效则自动回退至 Stalker 驱动的动态寄存器扫描；旧版 v2 与 v3 代理可用于仅扫描或仅偏移模式。面向获授权测试 iOS 游戏与应用的研究人员，用于分析 IL2CPP 内部机制与元数据布局，且不修改应用状态。
