Инструмент на базе Frida, который извлекает деобфусцированный заголовок IL2CPP global-metadata из запущенного Unity-приложения на jailbreak iOS, формируя вывод, пригодный для Il2CppDumper и аналогичных рабочих процессов реверс-инжиниринга. Python-контроллер запускает целевое приложение по bundle ID и внедряет JavaScript-агенты Frida, которые перехватывают il2cpp_init внутри UnityFramework, чтобы захватить чистый заголовок после деобфускации во время выполнения, с проверкой по стандартной магической константе 0xFAB11BAF. Агент v4 по умолчанию адаптивно пробует быстрый хук на основе смещения, если оно задано, и автоматически переключается на динамическое сканирование регистров через Stalker, когда смещение отсутствует или устарело; устаревшие агенты v2 и v3 доступны для режимов только сканирования или только смещения. Предназначен для исследователей, анализирующих внутреннее устройство IL2CPP и структуру метаданных в iOS-играх и приложениях, которые они имеют право тестировать, без изменения состояния приложения.
