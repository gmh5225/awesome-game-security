VyxAC 是一款面向 Spigot、Paper 与 Purpur 的 Minecraft 服务端反作弊插件，通过先审核的工作流与多重证据印证来降低误封。项目以 Java（JDK 17+，Maven 构建）编写，内置约四十七项基于 Bukkit 事件的检测，覆盖战斗、移动、背包与世界交互，以及粗粒度的封包或时序启发式规则。轻量级统计式「迷你 AI」在严格 CPU 时间预算内，将点击节奏、瞄准与反应模式与服务器的干净玩家基线比对评分；惩罚逻辑可要求多项检测同时触发，并配合 ping、TPS 保护与传送、卡顿及载具等情况下的宽限期。管理员可通过 YAML 与游戏内命令配置检测项，包括自定义 GUI、违规档案，以及在踢出或封禁前供工作人员审核的可选按钮。面向多人 Minecraft 服主与游戏安全从业者，提供可自托管、高度可调的反作弊方案，默认不依赖外部封包 Hook 类库。
