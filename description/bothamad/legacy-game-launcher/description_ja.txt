Legacy Game Launcher は、Windows 10 および 11 上で古い PC ゲームを設定して起動するための Windows デスクトップアプリケーションです。C# と WPF、WPF-UI Fluent ツールキットで構築され、実行ファイルをスキャンして Direct3D のバージョン、SafeDisc などの DRM およびコピー保護の署名、不足している DirectX や Visual C++ の依存関係を検出し、起動前にディスクイメージをマウントしながら SafeDiscLoader2 と連携できます。dgVoodoo2、DXVK、dinputto8 の可逆インストール、Windows 互換レイヤ、CPU アフィニティ、バイナリプロファイルエディタ、DirectInput コントローラのライブテスト、Windows イベントログに紐づく起動診断を管理し、完全な変更ジャーナルと取り消し機能を備えます。単なるゲームショートカット管理ツールではなく、レトロゲーマーや分析者が旧来のコピー保護やプラットフォームの不具合に対して実用的で可逆な回避策を必要とする向けのツールです。
