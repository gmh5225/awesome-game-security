Legacy Game Launcher is a Windows desktop application that configures and launches older PC games on Windows 10 and 11. Built with C# and WPF using the WPF-UI Fluent toolkit, it scans executables for Direct3D version, DRM and copy-protection signatures such as SafeDisc, missing DirectX and Visual C++ dependencies, and can cooperate with SafeDiscLoader2 while mounting disc images before launch. It manages reversible installs of dgVoodoo2, DXVK, and dinputto8, Windows compatibility layers, CPU affinity, binary profile editors, live DirectInput controller testing, and launch diagnostics tied to the Windows event log with a full change journal and undo. It is aimed at retro gamers and analysts who need practical, reversible workarounds for legacy copy protection and platform breakage rather than a simple game shortcut manager.
