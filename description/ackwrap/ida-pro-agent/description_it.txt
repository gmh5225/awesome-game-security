ida-agent è un plugin per IDA Pro che porta l'analisi binaria assistita dall'IA nei flussi di lavoro di disassemblaggio tramite una console IA integrata e un gateway MCP per client IA esterni. Espone le capacità di IDA, tra cui ispezione di funzioni e riferimenti incrociati, pseudocodice Hex-Rays, tracciamento limitato degli argomenti attraverso i chiamanti diretti, estrazione di evidenze guard e modifiche IDB con anteprima tramite ChangeSets. Lo stack Windows x64 combina un plugin C++ per IDA 9.4 con strumenti Go e Python, Qt 6.8.2 e supporto per OpenAI, Anthropic e provider API personalizzati tramite MCP. È rivolto a reverse engineer e ricercatori di sicurezza che desiderano analisi guidate da LLM all'interno di IDA per revisione di malware, ricerca anti-cheat e ispezione binaria approfondita.
