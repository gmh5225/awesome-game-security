ida-agent는 IDA Pro용 플러그인으로, 내장 AI 콘솔과 외부 AI 클라이언트를 위한 MCP 게이트웨이를 통해 디스어셈블리 워크플로에 AI 지원 바이너리 분석을 제공합니다. 함수 및 교차 참조 검사, Hex-Rays 의사코드, 직접 호출자에 걸친 제한적 인수 추적, guard 증거 추출, ChangeSets를 통한 미리보기 가능한 IDB 편집 등 IDA 기능을 노출합니다. Windows x64 스택은 C++ IDA 9.4 플러그인과 Go·Python 도구, Qt 6.8.2를 결합하며, MCP를 통해 OpenAI, Anthropic 및 사용자 정의 API 제공자를 지원합니다. 악성코드 검토, 안티치트 연구, 심층 바이너리 검사를 위해 IDA 내부에서 LLM 기반 분석을 원하는 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
