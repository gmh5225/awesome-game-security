ida-agent 是一款 IDA Pro 外掛，透過內建 AI 主控台和面向外部 AI 用戶端的 MCP 閘道，為反組譯工作流程帶來 AI 輔助的二進位分析。它公開 IDA 的各項能力，包括函式與交叉參考檢查、Hex-Rays 虛擬碼、跨直接呼叫者的有界引數追蹤、guard 證據擷取，以及透過 ChangeSets 實現可預覽的 IDB 編輯。Windows x64 技術堆疊由 C++ IDA 9.4 外掛與 Go、Python 工具鏈、Qt 6.8.2 組成，並透過 MCP 支援 OpenAI、Anthropic 及自訂 API 供應商。面向希望在 IDA 內進行 LLM 驅動分析、用於惡意軟體審查、反作弊研究和深度二進位檢查的逆向工程師與安全研究人員。
