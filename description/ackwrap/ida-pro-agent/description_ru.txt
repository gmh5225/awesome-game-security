ida-agent — это плагин для IDA Pro, который добавляет в рабочие процессы дизассемблирования анализ бинарных файлов с помощью ИИ через встроенную AI-консоль и MCP-шлюз для внешних AI-клиентов. Он предоставляет доступ к возможностям IDA, включая просмотр функций и перекрёстных ссылок, псевдокод Hex-Rays, ограниченное отслеживание аргументов через прямых вызывающих, извлечение guard-доказательств и предварительный просмотр правок IDB через ChangeSets. Стек Windows x64 объединяет C++-плагин для IDA 9.4 с инструментами на Go и Python, Qt 6.8.2 и поддержку OpenAI, Anthropic и пользовательских API-провайдеров через MCP. Предназначен для специалистов по реверс-инжинирингу и исследователей безопасности, которым нужен LLM-анализ внутри IDA для проверки вредоносного ПО, исследований античит-систем и глубокой бинарной инспекции.
