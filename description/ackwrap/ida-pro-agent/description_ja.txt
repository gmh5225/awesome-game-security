ida-agent は IDA Pro 向けプラグインで、組み込み AI コンソールと外部 AI クライアント向け MCP ゲートウェイを通じて、逆アセンブリワークフローに AI 支援のバイナリ解析をもたらします。関数およびクロスリファレンスの調査、Hex-Rays 疑似コード、直接呼び出し元にわたる有界な引数トレース、guard 証拠の抽出、ChangeSets によるプレビュー可能な IDB 編集など、IDA の各種機能を公開します。Windows x64 スタックは C++ 製 IDA 9.4 プラグインと Go・Python ツール、Qt 6.8.2 を組み合わせ、MCP 経由で OpenAI、Anthropic、カスタム API プロバイダーをサポートします。マルウェアレビュー、アンチチート研究、深いバイナリ検査のために、IDA 内で LLM 駆動の解析を求めるリバースエンジニアとセキュリティ研究者向けです。
