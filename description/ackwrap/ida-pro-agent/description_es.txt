ida-agent es un complemento de IDA Pro que incorpora análisis binario asistido por IA en los flujos de trabajo de desensamblado mediante una consola de IA integrada y una puerta de enlace MCP para clientes de IA externos. Expone capacidades de IDA, incluida la inspección de funciones y referencias cruzadas, pseudocódigo Hex-Rays, rastreo acotado de argumentos a través de llamadores directos, extracción de evidencia guard y ediciones IDB previsualizables mediante ChangeSets. La pila Windows x64 combina un complemento C++ de IDA 9.4 con herramientas en Go y Python, Qt 6.8.2, y soporte para OpenAI, Anthropic y proveedores de API personalizados a través de MCP. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad que desean análisis impulsado por LLM dentro de IDA para revisión de malware, investigación anti-trampas e inspección binaria profunda.
