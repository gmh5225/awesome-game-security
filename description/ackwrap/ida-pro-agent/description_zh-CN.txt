ida-agent 是一款 IDA Pro 插件，通过内置 AI 控制台和面向外部 AI 客户端的 MCP 网关，为反汇编工作流带来 AI 辅助的二进制分析。它开放 IDA 的各项能力，包括函数与交叉引用检查、Hex-Rays 伪代码、跨直接调用者的有界参数追踪、guard 证据提取，以及通过 ChangeSets 实现可预览的 IDB 编辑。Windows x64 技术栈由 C++ IDA 9.4 插件与 Go、Python 工具链、Qt 6.8.2 组成，并通过 MCP 支持 OpenAI、Anthropic 及自定义 API 提供商。面向希望在 IDA 内进行 LLM 驱动分析、用于恶意软件审查、反作弊研究和深度二进制检查的反汇编工程师与安全研究人员。
