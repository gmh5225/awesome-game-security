rc2tools is a toolkit for analyzing and modifying Rolan's Curse II on the Game Boy by working directly with ROM images and documented in-ROM data layouts. It is implemented primarily in Python with a Bash entry script, and uses Pillow to decode Game Boy 2bpp tiles and assemble 16x16 sprite sheets from chosen byte ranges. The extract-json workflow pulls per-character HP, MP, and ability tables into JSON keyed by the ROM's SHA-256 hash, accepting either raw .gb files or full xxd-style hex dumps so edited stats show up in the output. Supporting documentation maps ROM offsets and save formats, with unit tests around extraction and rendering. It is aimed at ROM hackers, game data researchers, and anyone reverse engineering or balancing this title rather than building generic anti-cheat or live-service security tooling.
