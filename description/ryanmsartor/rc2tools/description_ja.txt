rc2tools は、Game Boy 版 Rolan's Curse II を ROM イメージと文書化された ROM 内データ配置に直接扱って分析・改変するためのツールキットです。主に Python で実装され、Bash のエントリースクリプトがあり、Pillow で Game Boy の 2bpp タイルをデコードし、指定したバイト範囲から 16×16 のスプライトシートを組み立てます。extract-json ワークフローはキャラクターごとの HP・MP・能力テーブルを ROM の SHA-256 ハッシュをキーとした JSON に取り出し、生の .gb ファイルまたは xxd 形式の完全な十六進ダンプを受け付けるため、編集したステータスが出力に反映されます。補助ドキュメントは ROM オフセットとセーブ形式を対応付け、抽出とレンダリング向けのユニットテストも含みます。汎用のチート対策やライブサービス向けセキュリティツールではなく、ROM ハッカー、ゲームデータ研究者、本作のリバースエンジニアリングやバランス調整を行う人向けです。
