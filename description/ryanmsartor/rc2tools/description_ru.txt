rc2tools — набор инструментов для анализа и изменения Rolan's Curse II на Game Boy путём прямой работы с образами ROM и задокументированными раскладками данных в ROM. Реализован в основном на Python со входным сценарием на Bash; Pillow используется для декодирования тайлов Game Boy в формате 2bpp и сборки листов спрайтов 16×16 из выбранных диапазонов байтов. Рабочий процесс extract-json извлекает таблицы HP, MP и способностей по персонажам в JSON с ключом по SHA-256 хешу ROM, принимая либо сырые файлы .gb, либо полные hex-дампы в стиле xxd, так что отредактированные параметры отражаются в выводе. Сопроводительная документация сопоставляет смещения в ROM и форматы сохранений; есть модульные тесты извлечения и рендеринга. Предназначен для ROM-хакеров, исследователей игровых данных и тех, кто занимается реверс-инжинирингом или балансировкой этой игры, а не для универсальных античит- или security-инструментов для live-сервисов.
