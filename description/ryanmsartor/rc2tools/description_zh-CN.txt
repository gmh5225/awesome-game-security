rc2tools 是一套面向 Game Boy 版《Rolan's Curse II》的分析与修改工具集，直接操作 ROM 镜像并依据已文档化的 ROM 内数据结构开展工作。实现以 Python 为主，辅以 Bash 入口脚本，并通过 Pillow 解码 Game Boy 2bpp 图块，从指定字节区间组装 16×16 精灵图。extract-json 工作流将各角色的 HP、MP 与能力表导出为以 ROM SHA-256 哈希为键的 JSON，可接受原始 .gb 文件或完整的 xxd 风格十六进制转储，修改后的数值会反映在输出中。配套文档标定 ROM 偏移与存档格式，并对提取与渲染提供单元测试。面向 ROM 黑客、游戏数据研究者以及对本作进行逆向或平衡性调整的用户，而非通用的反作弊或在线游戏安全工具。
