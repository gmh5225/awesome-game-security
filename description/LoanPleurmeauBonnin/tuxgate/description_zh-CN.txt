Tuxgate 是一款用 Rust 编写的命令行工具，供在 Linux 上运行 Riot 游戏时检视主机并说明已记录的兼容性，而不会安装、模拟或绕过反作弊。该工具以只读方式探测启动与平台安全相关信号，例如 Secure Boot、TPM 2.0、IOMMU 和 EFI 变量，并将结果对照 Easy Anti-Cheat 在 Linux 上所述的 attested-boot 要求。它内置多款 Riot 游戏的兼容性数据库，并提供记录本地测试历史与检测回退的命令，还能在个别游戏需要时协助受控重启进入 Windows。本项目面向 Linux 玩家、发行版维护者及注重安全的用户，他们需要围绕 Vanguard 及相关反作弊要求的如实诊断，而非规避类工具。
