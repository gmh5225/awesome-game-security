Tuxgate は、Linux で Riot Games のタイトルを動かす際にホストを調査し、文書化された互換性を説明する Rust 製のコマンドラインコンパニオンで、インストール・エミュレーション・アンチチートの迂回は行いません。Secure Boot、TPM 2.0、IOMMU、EFI 変数などの起動およびプラットフォームセキュリティ信号を読み取り専用でプローブし、得られた結果を Linux 向け Easy Anti-Cheat で述べられる attested-boot の要件と照合します。複数の Riot タイトル向けの互換性データベースを同梱し、ローカルのテスト履歴の記録やリグレッション検出のコマンドも備え、タイトルが必要とする場合は Windows への制御された再起動の調整も支援します。Vanguard や関連アンチチート要件について率直な診断を必要とする Linux ゲーマー、ディストロメンテナ、セキュリティ意識の高いユーザー向けであり、回避用ツールではありません。
