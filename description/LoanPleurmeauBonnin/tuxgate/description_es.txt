Tuxgate es un compañero de línea de comandos en Rust para ejecutar títulos de Riot en Linux que inspecciona el equipo y explica la compatibilidad documentada sin instalar, emular ni eludir el anti-cheat. La herramienta realiza sondeos del sistema en solo lectura sobre señales de seguridad de arranque y plataforma como Secure Boot, TPM 2.0, IOMMU y variables EFI, y compara esos hallazgos con las expectativas de arranque atestado descritas para Easy Anti-Cheat en Linux. Incluye una base de datos de compatibilidad para varios títulos de Riot, además de comandos para registrar el historial de pruebas locales y detectar regresiones, y puede ayudar a coordinar un reinicio controlado a Windows cuando un título lo requiere. El proyecto está dirigido a jugadores en Linux, mantenedores de distribuciones y usuarios preocupados por la seguridad que necesitan diagnósticos honestos sobre Vanguard y los requisitos de anti-cheat relacionados, no herramientas de elusión.
