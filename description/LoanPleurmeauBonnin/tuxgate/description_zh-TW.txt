Tuxgate 是一款以 Rust 撰寫的命令列工具，供在 Linux 上執行 Riot 遊戲時檢視主機並說明已文件化的相容性，而不會安裝、模擬或繞過反作弊。該工具以唯讀方式探測開機與平台安全相關訊號，例如 Secure Boot、TPM 2.0、IOMMU 與 EFI 變數，並將結果對照 Easy Anti-Cheat 在 Linux 上所述的 attested-boot 要求。它內建多款 Riot 遊戲的相容性資料庫，並提供記錄本機測試歷史與偵測倒退的命令，還能在特定遊戲需要時協助受控重新開機進入 Windows。本專案面向 Linux 玩家、發行版維護者及重視安全的使用者，他們需要圍繞 Vanguard 與相關反作弊要求的誠實診斷，而非規避類工具。
