Tuxgate is a Rust command-line companion for running Riot Games titles on Linux that inspects the host and explains documented compatibility without installing, emulating, or bypassing anti-cheat. The tool runs read-only system probes for boot and platform security signals such as Secure Boot, TPM 2.0, IOMMU, and EFI variables, and maps those findings against the attested-boot expectations described for Easy Anti-Cheat on Linux. It ships a sourced compatibility database for multiple Riot titles plus commands to record local test history and detect regressions, and it can help coordinate a controlled reboot into Windows when a title requires it. The project is aimed at Linux gamers, distro maintainers, and security-minded users who need honest diagnostics around Vanguard and related anti-cheat requirements rather than circumvention tooling.
