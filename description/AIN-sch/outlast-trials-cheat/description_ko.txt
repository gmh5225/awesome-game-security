이 프로젝트는 The Outlast Trials에 대한 정적·동적 분석을 문서화하며, 자동 생성된 Unreal Engine 4 C++ SDK와 오프셋 및 객체 메타데이터 덤프를 중심으로 합니다. Easy Anti-Cheat EOS 스택, 커널 minifilter 드라이버, 게임의 지연 임포트(delayed-import) 안티치트 진입점 8곳을 리버스 엔지니어링하고, 일시 중단된 게임 프로세스를 재개하기 전에 해당 API를 후킹하는 검증된 인젝션 워크플로를 설명합니다. 주요 산출물로는 자동 덤퍼가 만든 C++ SDK 헤더와 함수 스텁, JSON 매핑, GObject 목록, 출시 Windows 클라이언트용 PE 수준 메모가 있습니다. 이 타이틀에서 UE4 내부와 EAC 클라이언트 동작에 대한 재현 가능한 통찰이 필요한 게임 보안 연구자, 안티치트 분석가, 리버스 엔지니어를 대상으로 합니다.
