本项目记录了对《逃生：试炼》的静态与动态分析，核心是一份自动生成的 Unreal Engine 4 C++ SDK，以及配套的偏移量与对象元数据转储。项目逆向分析了 Easy Anti-Cheat 的 EOS 实现栈，包括内核 minifilter 驱动以及游戏侧八个延迟导入的反作弊入口点，并描述了一套经过验证的注入流程：在恢复挂起的游戏进程之前钩住相关 API。主要产出物包括自动化转储工具生成的 C++ SDK 头文件与函数桩、JSON 映射、GObject 列表，以及面向正式版 Windows 客户端的 PE 级说明。面向需要在本作上获得可复现的 UE4 内部机制与 EAC 客户端行为洞察的游戏安全研究者、反作弊分析师与逆向工程师。
