This project documents static and dynamic analysis of The Outlast Trials, centered on a generated Unreal Engine 4 C++ SDK plus supporting offset and object metadata dumps. It reverse engineers the Easy Anti-Cheat EOS stack, including the kernel minifilter driver and the game’s eight delayed-import anti-cheat entry points, and describes a tested injection workflow that hooks those APIs before resuming the suspended game process. Primary artifacts are C++ SDK headers and function stubs produced by automated dumpers, alongside JSON mappings, GObject listings, and PE-level notes for the shipping Windows client. It is aimed at game security researchers, anti-cheat analysts, and reverse engineers who need reproducible insight into UE4 internals and EAC client behavior on this title.
