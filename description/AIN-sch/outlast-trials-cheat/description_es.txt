Este proyecto documenta el análisis estático y dinámico de The Outlast Trials, centrado en un SDK C++ de Unreal Engine 4 generado automáticamente junto con volcados de offsets y metadatos de objetos. Ingeniería inversa de la pila Easy Anti-Cheat EOS, incluido el controlador minifilter del kernel y los ocho puntos de entrada antitrampas de importación diferida del juego, y describe un flujo de inyección probado que engancha esas API antes de reanudar el proceso del juego suspendido. Los artefactos principales son encabezados y stubs de funciones del SDK C++ producidos por volcadores automatizados, mapeos JSON, listados GObject y notas a nivel PE para el cliente Windows de lanzamiento. Está dirigido a investigadores de seguridad de videojuegos, analistas antitrampas e ingenieros de ingeniería inversa que necesitan una visión reproducible de los internals de UE4 y del comportamiento del cliente EAC en este título.
