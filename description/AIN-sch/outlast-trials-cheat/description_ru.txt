Проект документирует статический и динамический анализ The Outlast Trials с опорой на сгенерированный C++ SDK для Unreal Engine 4 и сопутствующие дампы смещений и метаданных объектов. Выполняется реверс стека Easy Anti-Cheat EOS, включая драйвер minifilter в ядре и восемь точек входа античита с отложенным импортом в игре; описан проверенный сценарий инъекции, который перехватывает эти API до возобновления приостановленного игрового процесса. Основные артефакты — заголовки и заглушки функций C++ SDK от автоматических дамперов, JSON-соответствия, списки GObject и заметки на уровне PE для релизного Windows-клиента. Материал ориентирован на исследователей игровой безопасности, аналитиков античита и реверс-инженеров, которым нужны воспроизводимые сведения о внутренностях UE4 и поведении клиента EAC в этой игре.
