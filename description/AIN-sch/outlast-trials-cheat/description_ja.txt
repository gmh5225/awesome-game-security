本プロジェクトは The Outlast Trials に対する静的・動的解析をまとめ、自動生成された Unreal Engine 4 向け C++ SDK と、オフセットおよびオブジェクトメタデータのダンプを中心に構成されています。Easy Anti-Cheat の EOS スタック、カーネル minifilter ドライバ、ゲーム側の 8 つの遅延インポートによるアンチチートエントリポイントをリバースエンジニアリングし、サスペンド状態のゲームプロセスを再開する前にそれらの API をフックする検証済みのインジェクション手順も記述しています。主な成果物は自動ダンパーが生成した C++ SDK ヘッダと関数スタブ、JSON マッピング、GObject 一覧、および Windows 向け出荷クライアントの PE レベルのメモです。本作における UE4 内部と EAC クライアント挙動を再現可能に把握したいゲームセキュリティ研究者、アンチチート分析者、リバースエンジニアを対象としています。
