本專案記錄了對 The Outlast Trials 的靜態與動態分析，核心是一份自動產生的 Unreal Engine 4 C++ SDK，以及配套的偏移量與物件中繼資料傾印。專案逆向分析了 Easy Anti-Cheat 的 EOS 技術堆疊，包含核心 minifilter 驅動程式以及遊戲端八個延遲匯入的反作弊進入點，並描述一套經過驗證的注入流程：在恢復暫停的遊戲處理序之前掛鉤相關 API。主要產出物包括自動化傾印工具產生的 C++ SDK 標頭檔與函式樁、JSON 對應、GObject 清單，以及針對正式版 Windows 用戶端的 PE 層級說明。目標讀者為需要在本作上取得可重現的 UE4 內部機制與 EAC 用戶端行為見解的遊戲安全研究者、反作弊分析師與逆向工程師。
