Awesome AI Reverse Engineering — это подобранный каталог open-source инструментов, связывающих AI-агентов для кодирования, таких как Claude Code и Codex, с рабочими процессами reverse engineering. В нём около 122 проверенных репозиториев: серверы Model Context Protocol для disassembler и decompiler (Ghidra, IDA Pro, Binary Ninja, radare2, x64dbg), мобильные стеки на jadx, apktool и Frida, анализ веб- и JavaScript-протоколов, наборы навыков для агентов и примеры проектов, восстановленные с помощью REA и подобных инструментов. У каждой записи указаны звёзды и оценки безопасности по автоматической проверке README, рядом со списками Markdown — машиночитаемые метаданные в JSON. Коллекция для исследователей безопасности, аналитиков вредоносного ПО и инженеров, которым нужна LLM-автоматизация бинарного, мобильного и протокольного RE, а не общие подборки ссылок или инструменты для читов.
