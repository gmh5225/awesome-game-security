Awesome AI Reverse Engineering es un catálogo curado de herramientas de código abierto que conectan agentes de codificación con IA como Claude Code y Codex con flujos de trabajo de ingeniería inversa. Agrupa unos 122 repositorios verificados en servidores Model Context Protocol para desensambladores y decompiladores (Ghidra, IDA Pro, Binary Ninja, radare2, x64dbg), stacks móviles basados en jadx, apktool y Frida, análisis de protocolos web y JavaScript, paquetes de habilidades para agentes y proyectos de ejemplo reconstruidos con herramientas como REA. Cada entrada incluye recuentos de estrellas y calificaciones de seguridad de revisión automatizada de README, con metadatos JSON legibles por máquina junto a las listas Markdown. La colección está dirigida a investigadores de seguridad, analistas de malware e ingenieros que buscan automatización impulsada por LLM para ingeniería inversa binaria, móvil y de protocolos, no a volcados genéricos de enlaces ni herramientas orientadas a trampas.
