Awesome AI Reverse Engineering è un catalogo curato di strumenti open source che collegano agenti di coding IA come Claude Code e Codex ai flussi di lavoro di reverse engineering. Raggruppa circa 122 repository verificati: server Model Context Protocol per disassemblatori e decompilatori (Ghidra, IDA Pro, Binary Ninja, radare2, x64dbg), stack mobili basati su jadx, apktool e Frida, analisi di protocolli web e JavaScript, pacchetti di skill per agenti e progetti di esempio ricostruiti con strumenti come REA. Ogni voce include conteggi di stelle e valutazioni di sicurezza da revisione automatizzata dei README, con metadati JSON machine-readable accanto agli elenchi Markdown. La raccolta è pensata per ricercatori di sicurezza, analisti di malware e ingegneri che vogliono automazione guidata da LLM per reverse engineering binario, mobile e di protocolli, non per raccolte generiche di link o tool orientati al cheating.
