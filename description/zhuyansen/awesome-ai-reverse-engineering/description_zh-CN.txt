Awesome AI Reverse Engineering 是一份精选开源工具目录，将 Claude Code、Codex 等 AI 编程智能体与逆向工程工作流对接。约 122 个经审核仓库按类别组织，涵盖面向 Ghidra、IDA Pro、Binary Ninja、radare2 与 x64dbg 的反汇编与反编译 Model Context Protocol 服务器，基于 jadx、apktool 与 Frida 的移动端栈，Web 与 JavaScript 协议分析、智能体技能包，以及借助 REA 等工具重建的示例项目。每条目附带星标数及基于 README 自动审查的安全评级，并在 Markdown 列表旁提供 JSON 机器可读元数据。本合集面向安全研究员、恶意软件分析师与工程师，侧重 LLM 驱动的二进制、移动端与协议逆向自动化，而非泛泛链接汇总或作弊向工具。
