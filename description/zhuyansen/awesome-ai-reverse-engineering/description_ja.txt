Awesome AI Reverse Engineering は、Claude Code や Codex といった AI コーディングエージェントをリバースエンジニアリングのワークフローにつなぐオープンソースツールの厳選カタログです。約 122 の審査済みリポジトリを、Ghidra、IDA Pro、Binary Ninja、radare2、x64dbg 向けの逆アセンブラ・逆コンパイラ用 Model Context Protocol サーバー、jadx・apktool・Frida ベースのモバイルスタック、Web および JavaScript のプロトコル解析、エージェントスキルパック、REA などで再構築したサンプルプロジェクトなどに分類しています。各エントリにはスター数と README 自動レビューによるセキュリティ評価があり、Markdown リストと併せて JSON の機械可読メタデータを提供します。一般のリンク集やチート向けツールではなく、バイナリ・モバイル・プロトコルの RE を LLM で自動化したいセキュリティ研究者、マルウェアアナリスト、エンジニアを対象としています。
