Awesome AI Reverse Engineering은 Claude Code, Codex 같은 AI 코딩 에이전트를 리버스 엔지니어링 워크플로에 연결하는 오픈소스 도구를 엄선한 카탈로그입니다. 약 122개의 검증된 저장소를 Ghidra, IDA Pro, Binary Ninja, radare2, x64dbg용 disassembler·decompiler Model Context Protocol 서버, jadx·apktool·Frida 기반 모바일 스택, 웹·JavaScript 프로토콜 분석, 에이전트 스킬 팩, REA 등으로 재구성한 예제 프로젝트 등으로 묶었습니다. 각 항목에는 스타 수와 README 자동 검토 기반 보안 등급이 포함되며, Markdown 목록과 함께 JSON 기계 판독 메타데이터를 제공합니다. 일반 링크 모음이나 치트 중심 도구가 아니라, 바이너리·모바일·프로토콜 리버스 엔지니어링을 LLM으로 자동화하려는 보안 연구자, 멀웨어 분석가, 엔지니어를 대상으로 합니다.
