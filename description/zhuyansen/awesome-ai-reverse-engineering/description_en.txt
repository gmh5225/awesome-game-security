Awesome AI Reverse Engineering is a curated catalog of open-source tools that connect AI coding agents such as Claude Code and Codex to reverse engineering workflows. It groups roughly 122 vetted repositories into disassembler and decompiler Model Context Protocol servers for Ghidra, IDA Pro, Binary Ninja, radare2, and x64dbg, mobile stacks built on jadx, apktool, and Frida, web and JavaScript protocol analysis, agent skill packs, and example projects rebuilt with tools like REA. Each entry includes star counts and security grades from automated README review, with machine-readable metadata in JSON alongside the markdown lists. The collection targets security researchers, malware analysts, and engineers who want LLM-driven automation for binary, mobile, and protocol reverse engineering rather than general link dumps or cheat-focused tooling.
