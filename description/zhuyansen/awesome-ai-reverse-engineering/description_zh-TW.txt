Awesome AI Reverse Engineering 是一份精選開源工具目錄，將 Claude Code、Codex 等 AI 程式設計代理與逆向工程工作流程銜接。約 122 個經審核的儲存庫依類別整理，涵蓋面向 Ghidra、IDA Pro、Binary Ninja、radare2 與 x64dbg 的反組譯與反編譯 Model Context Protocol 伺服器，以 jadx、apktool 與 Frida 建構的行動端堆疊，Web 與 JavaScript 協定分析、代理技能包，以及借助 REA 等工具重建的範例專案。各項目附星標數及 README 自動審查的安全評等，並在 Markdown 清單旁提供 JSON 機器可讀中繼資料。本合集鎖定安全研究員、惡意軟體分析師與工程師，聚焦 LLM 驅動的二進位、行動端與協定逆向自動化，而非泛泛的連結彙整或作弊導向工具。
