VM Studio は、ARM64 ホストデバイス上で完全な Android ゲスト仮想マシンを実行する Android アプリケーションです。ネイティブ C エンジンがプロセス分離、chroot 化されたルートファイルシステム、システムコール変換、および Vulkan による高性能表示（OpenGL ES フォールバック付き）を担当し、Kotlin UI が VM のライフサイクル、APK インストール、ハードウェアパススルーを管理します。本プロジェクトは Magisk ベースの root 切り替え、Xposed モジュールの読み込み、Google Play サービスのインストール、カメラとセンサーの転送、VPN ベースのネットワーク分離をサポートしています。仮想化、root、instrumentation 下でのゲームやアンチチートシステムの挙動を逆アセンブル、MOD 開発、テストするために、サンドボックス化された hook 向け Android 環境を必要とする開発者や研究者を対象としています。
