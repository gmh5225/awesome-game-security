Bunyip is a complete game engine written in Go for building real-time and turn-based 2D and 3D games. It is implemented in pure Go without cgo, using generated Vulkan bindings and native platform layers for windowing, input, and audio on macOS, Windows, and Linux. The engine bundles an entity component system, 2D and 3D physics, skeletal animation, physically based rendering, an immediate-mode UI toolkit, spatial audio with tracker module playback, and TCP/TLS and UDP networking. It is aimed at simulation-heavy titles such as roguelikes, strategy games, and space games, with headless screenshot testing and extensive guides for developers building games from scratch.
