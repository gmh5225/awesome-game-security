Bunyip は、リアルタイムおよびターン制の 2D・3D ゲームを構築するための Go 製の完全なゲームエンジンです。cgo を使わない純粋な Go で実装され、生成された Vulkan バインディングと、macOS、Windows、Linux 向けのネイティブプラットフォームレイヤーにより、ウィンドウ、入力、オーディオを提供します。エンジンにはエンティティコンポーネントシステム、2D/3D 物理、スケルタルアニメーション、物理ベースレンダリング、イミディエートモード UI ツールキット、トラッカーモジュール再生対応の空間オーディオ、TCP/TLS および UDP ネットワーキングが含まれます。ローグライク、ストラテジー、スペースゲームなどシミュレーション要素の多いタイトルを対象とし、ヘッドレススクリーンショットテストや、一からゲームを開発する開発者向けの充実したガイドを備えています。
