Crystal Hunt 是一款 Unity 行動遊戲專案，實作了以位置為基礎的多人體驗：玩家在真實世界地圖上移動、與其他玩家相遇，並競爭收集水晶目標。程式碼庫主要使用 C#，採用 Mapbox 進行地圖渲染與地理空間疊加，Firebase Authentication 與 Realtime Database 負責帳號與共享遊戲狀態，Firebase App Check 用於加固後端存取、防範遭竄改的用戶端。自訂網路層結合 WebSocket 支援以及大廳、工作階段與除錯 HUD 工具，並提供用戶端模擬器與單元測試，便於在無實機的情況下驗證勝利條件與遊戲流程。適合研究如何將 GPS 權限、線上大廳與雲端持久化接入 2D URP 專案，並探索面向位置多人遊戲的實用遊戲安全模式。
