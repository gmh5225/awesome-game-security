Crystal Hunt는 Unity 모바일 게임 프로젝트로, 위치 기반 멀티플레이 경험을 구현합니다. 플레이어는 실제 세계 지도 위를 이동하며 다른 사람을 만나고, 크리스털 목표 수집을 놓고 경쟁합니다. 코드베이스는 주로 C#이며 Mapbox로 지도 렌더링과 지리공간 오버레이를, Firebase Authentication과 Realtime Database로 계정과 공유 게임 상태를, Firebase App Check로 변조된 클라이언트에 대한 백엔드 접근을 강화합니다. 맞춤 네트워킹 계층은 WebSocket 지원과 로비, 세션, 디버그 HUD 유틸리티를 결합하고, 클라이언트 시뮬레이터와 단위 테스트로 실기기 없이 승리 조건과 게임 흐름을 검증할 수 있습니다. GPS 권한, 온라인 로비, 클라우드 기반 영속성을 2D URP 타이틀에 연결하는 방법과 위치 기반 멀티플레이용 실용적인 게임 보안 패턴을 탐구하려는 개발자에게 적합합니다.
