Crystal Hunt 是一款 Unity 移动游戏项目，实现了基于位置的多人体验：玩家在真实世界地图上移动、与其他玩家相遇，并争夺收集水晶目标。代码库主要使用 C#，采用 Mapbox 进行地图渲染与地理空间叠加，Firebase Authentication 与 Realtime Database 负责账号与共享游戏状态，Firebase App Check 用于加固后端访问、防范被篡改的客户端。自定义网络层结合 WebSocket 支持以及大厅、会话与调试 HUD 工具，还提供客户端模拟器与单元测试，便于在无实机的情况下验证胜利条件与游戏流程。适合研究如何将 GPS 权限、在线大厅与云端持久化接入 2D URP 项目，并探索面向位置多人游戏的实用游戏安全模式。
