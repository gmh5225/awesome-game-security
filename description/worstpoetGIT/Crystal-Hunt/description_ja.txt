Crystal Hunt は Unity 製モバイルゲームプロジェクトで、位置情報を活用したマルチプレイ体験を実装しています。プレイヤーは現実世界の地図上を移動し、他プレイヤーと出会い、クリスタル目標の収集を競い合います。コードベースは主に C# で、Mapbox による地図描画と地理空間オーバーレイ、Firebase Authentication と Realtime Database によるアカウントと共有ゲーム状態、改ざんクライアント対策の Firebase App Check を用いています。カスタムネットワーク層は WebSocket サポートとロビー、セッション、デバッグ HUD ユーティリティを組み合わせ、クライアントシミュレータとユニットテストで実機なしに勝利条件とゲームフローを検証できます。GPS 権限、オンラインロビー、クラウド永続化を 2D URP タイトルに組み込む方法や、位置ベースマルチプレイ向けの実践的なゲームセキュリティパターンを学ぶ開発者に適しています。
