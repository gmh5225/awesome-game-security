Crystal Hunt is a Unity mobile game project that implements a location-aware multiplayer experience where players move on a real-world map, encounter others, and compete to collect crystal objectives. The codebase is primarily C# and uses Mapbox for map rendering and geospatial overlays, Firebase Authentication and Realtime Database for accounts and shared game state, and Firebase App Check to harden backend access against tampered clients. Custom networking layers combine WebSocket support with lobby, session, and debug HUD utilities, plus a client simulator and unit tests for exercising win conditions and game flow without live devices. It suits developers studying how to wire GPS permissions, online lobbies, and cloud-backed persistence into a 2D URP title while exploring practical game-security patterns for location-based multiplayer.
