Crystal Hunt es un proyecto de juego móvil en Unity que implementa una experiencia multijugador basada en la ubicación: los jugadores se mueven en un mapa del mundo real, se encuentran con otros y compiten por recoger objetivos de cristales. La base de código es principalmente C# y usa Mapbox para el renderizado del mapa y superposiciones geoespaciales, Firebase Authentication y Realtime Database para cuentas y estado de juego compartido, y Firebase App Check para endurecer el acceso al backend frente a clientes manipulados. Capas de red personalizadas combinan soporte WebSocket con utilidades de lobby, sesión y HUD de depuración, además de un simulador de cliente y pruebas unitarias para ejercitar condiciones de victoria y flujo de juego sin dispositivos en vivo. Resulta útil para desarrolladores que estudian cómo integrar permisos GPS, lobbies en línea y persistencia en la nube en un título 2D URP mientras exploran patrones prácticos de seguridad de juegos para multijugador basado en ubicación.
