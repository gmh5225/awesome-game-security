MCAce 是一套面向现代 Minecraft 网络的隐私优先型客户端可见性与准入栈，为服务器提供基于用户同意的、范围有限的 Fabric 客户端视图，并将其与独立生成的服务端证据进行关联。该项目以 Fabric 客户端模组以及适用于 Velocity 和 BungeeCord 的代理插件，以及适用于 Paper 和 Folia 的后端插件形式交付，主要使用 Java 编写，采用 Gradle 与 Kotlin 构建，目标版本为 Minecraft 1.21.11、26.1.2 和 26.2。在用户明确同意每次连接后，它会收集已签名的遥测数据，例如已加载的模组列表、当前资源包和着色器选择，并通过 Grim、Vulcan 等集成将客户端上报信息与服务器反作弊信号关联。证据通过 Ed25519 签名的帧传输，具备严格的隐私边界、失败即关闭的策略评估，以及有界处置动作，例如观察、警告、质询和隔离。它面向需要可审计、可逆的准入与反作弊证据工作流的服务器管理员，而非内核级或持久化的客户端监控。
