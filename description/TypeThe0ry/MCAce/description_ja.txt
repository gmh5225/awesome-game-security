MCAce は、現代の Minecraft ネットワーク向けのプライバシー優先型クライアント可視性およびアドミッションスタックであり、サーバーに Fabric クライアントの狭く同意ベースのビューを提供し、それを独立して生成されたサーバー側の証拠と相関付けます。本プロジェクトは Fabric クライアント mod と、Velocity および BungeeCord 向けプロキシプラグイン、Paper および Folia 向けバックエンドプラグインとして提供され、主に Java で記述され、Gradle と Kotlin によるビルドで Minecraft 1.21.11、26.1.2、26.2 を対象としています。接続ごとにユーザーが明示的に同意した後、読み込まれた mod リスト、アクティブなリソースパック、シェーダー選択などの署名付きテレメトリを収集し、Grim や Vulcan などの統合を通じてクライアント報告の事実をサーバー側のアンチチート信号と結び付けます。証拠は Ed25519 署名フレームを通じて流れ、厳格なプライバシー境界、フェイルクローズのポリシー評価、observe、warn、challenge、quarantine などの限定的な処置アクションを備えています。カーネルレベルや永続的なクライアント監視ではなく、監査可能で可逆的なアドミッションおよびアンチチート証拠ワークフローを必要とするサーバー管理者を対象としています。
