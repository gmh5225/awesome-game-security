MCAce 是一套面向現代 Minecraft 網路的隱私優先型用戶端可見性與准入堆疊，為伺服器提供基於使用者同意的、範圍有限的 Fabric 用戶端視圖，並將其與獨立產生的伺服器端證據進行關聯。該專案以 Fabric 用戶端模組以及適用於 Velocity 和 BungeeCord 的代理外掛，以及適用於 Paper 和 Folia 的後端外掛形式交付，主要使用 Java 編寫，採用 Gradle 與 Kotlin 建置，目標版本為 Minecraft 1.21.11、26.1.2 和 26.2。在使用者明確同意每次連線後，它會收集已簽名的遙測資料，例如已載入的模組清單、目前資源包和著色器選擇，並透過 Grim、Vulcan 等整合將用戶端回報資訊與伺服器反作弊訊號關聯。證據透過 Ed25519 簽名的幀傳輸，具備嚴格的隱私邊界、失敗即關閉的策略評估，以及有界處置動作，例如觀察、警告、質詢和隔離。它面向需要可稽核、可逆的准入與反作弊證據工作流程的伺服器管理員，而非核心層級或持久化的用戶端監控。
