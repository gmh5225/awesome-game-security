APK Analysis Toolkit is a Rust-based terminal application that automates setup and orchestration of a full Android APK analysis workflow on emulators you control. Its menus drive package management over adb with automated red-flag checks, static tooling such as apktool and JADX for decompilation, and dynamic analysis including rooted AVD creation, Frida-based SSL pinning bypass, and mitmproxy HTTPS interception. Rather than reimplementing those analyzers, the toolkit detects, installs, configures, and chains Android SDK utilities, Frida, objection, mitmweb, and related dependencies while streaming progress for long downloads and installs. It is intended for authorized mobile security work such as malware research, penetration testing, and CTF-style reverse engineering of Android packages, including games and other untrusted APKs analyzed only in isolated sandboxes.
