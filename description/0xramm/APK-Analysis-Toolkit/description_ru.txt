APK Analysis Toolkit — терминальное приложение на Rust, которое автоматизирует настройку и оркестрацию полного рабочего процесса анализа Android APK на эмуляторах под вашим контролем. Меню управляют пакетами через adb с автоматическими проверками «красных флагов», статическими средствами вроде apktool и JADX для декомпиляции, а также динамическим анализом: создание rooted AVD, обход SSL pinning через Frida и перехват HTTPS с помощью mitmproxy. Вместо повторной реализации анализаторов набор обнаруживает, устанавливает, настраивает и связывает утилиты Android SDK, Frida, objection, mitmweb и связанные зависимости, показывая прогресс при длительных загрузках и установках. Предназначен для санкционированной мобильной безопасности: исследование вредоносного ПО, пентесты и reverse engineering пакетов Android в духе CTF, включая игры и другие недоверенные APK, анализируемые только в изолированных песочницах.
