APK Analysis Toolkit은 Rust 기반 터미널 애플리케이션으로, 사용자가 제어하는 에뮬레이터에서 전체 Android APK 분석 워크플로의 설정과 오케스트레이션을 자동화합니다. 메뉴는 adb를 통한 패키지 관리와 자동 레드 플래그 검사를 수행하며, apktool·JADX 같은 정적 역컴파일 도구와 rooted AVD 생성, Frida 기반 SSL pinning 우회, mitmproxy HTTPS 가로채기 등 동적 분석을 다룹니다. 분석기를 재구현하지 않고 Android SDK 유틸리티, Frida, objection, mitmweb 및 관련 의존성을 탐지·설치·구성·연결하며, 긴 다운로드와 설치 동안 진행 상황을 스트리밍합니다. 악성코드 연구, 침투 테스트, CTF 스타일 Android 패키지(게임 및 기타 신뢰할 수 없는 APK 포함) 역공학 등 허가된 모바일 보안 업무용이며, 분석은 격리된 샌드박스에서만 수행하는 것을 전제로 합니다.
