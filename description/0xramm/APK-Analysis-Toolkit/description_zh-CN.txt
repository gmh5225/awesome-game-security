APK Analysis Toolkit 是一款基于 Rust 的终端应用，可在您自行控制的模拟器上自动配置并编排完整的 Android APK 分析工作流。其菜单通过 adb 驱动包管理并执行自动化红旗检查，集成 apktool、JADX 等静态反编译工具，以及创建已 root 的 AVD、基于 Frida 的 SSL pinning 绕过与 mitmproxy HTTPS 拦截等动态分析能力。该工具集不重复实现这些分析器，而是检测、安装、配置并串联 Android SDK 工具、Frida、objection、mitmweb 及相关依赖，同时为漫长的下载与安装过程输出进度。它面向经授权的移动安全工作，例如恶意软件研究、渗透测试，以及 CTF 风格的 Android 包逆向——包括游戏及其他不可信 APK，且仅在隔离沙箱中进行分析。
