Kaisel 是行動端執行階段應用自我保護（RASP）的開源參考實作，在 iOS 15 至 27 上執行分層的越獄、插樁與裝置完整性檢查。專案以 Swift 套件形式發佈，內含 C 語言偵測核心、兩個可側載的示範應用以便在實機上快速試用，以及可選的 Python 伺服器，用於驗證 Apple App Attest 斷言、對密封報告重新評分並回傳允許、加強驗證或拒絕的決策。偵測範圍涵蓋系統呼叫與掛載表越獄探測、dyld 映像分類、Frida 與除錯器訊號、程式碼簽章與 entitlement 檢查、hook 與 trampoline 分析、加權風險評分以及防竄改的自我保護機制。本專案面向安全研究人員、紅隊與工程師，作為在實驗室中評估或比較商業防竄改與行動端 RASP 方案的基線，適用於手遊與高保障類應用，不宜作為唯一的生產環境防護手段。
