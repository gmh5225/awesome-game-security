Kaisel es una implementación de referencia de código abierto de Runtime Application Self-Protection móvil que realiza comprobaciones en capas de jailbreak, instrumentación e integridad del dispositivo en iOS 15 a 27. Se distribuye como paquete Swift con un núcleo de detección en C, dos aplicaciones de demostración sideloadables para pruebas rápidas en dispositivo y un servidor Python opcional que verifica las aserciones de Apple App Attest, vuelve a puntuar informes sellados y devuelve decisiones de permitir, escalado o denegar. La detección abarca sondas de jailbreak por llamadas al sistema y tabla de montaje, clasificación de imágenes dyld, señales de Frida y depurador, comprobaciones de firma de código y entitlements, análisis de hooks y trampolines, puntuación de riesgo ponderada y autoprotección a prueba de manipulación. El proyecto está orientado a investigadores de seguridad, equipos rojos e ingenieros que necesitan una línea base de laboratorio para evaluar o comparar enfoques comerciales anti-manipulación y RASP para juegos móviles y aplicaciones de alta confianza, no como único control de producción.
