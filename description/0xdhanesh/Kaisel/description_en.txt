Kaisel is an open-source reference implementation of mobile Runtime Application Self-Protection that performs layered jailbreak, instrumentation, and device-integrity checks on iOS 15 through 27. It ships as a Swift package with a C detection core, two sideloadable demo apps for quick on-device trials, and an optional Python server that verifies Apple App Attest assertions, re-scores sealed reports, and returns allow, step-up, or deny decisions. Detection spans syscall and mount-table jailbreak probes, dyld image classification, Frida and debugger signals, code-signing and entitlement checks, hook and trampoline analysis, weighted risk scoring, and tamper-evident self-protection. The project is aimed at security researchers, red teams, and engineers who need a lab baseline to evaluate or compare commercial anti-tamper and RASP approaches for mobile games and high-assurance apps, not as a sole production control.
