S3 Mobile è un port che esegue The Settlers III su Android e iOS a partire da file di gioco GOG forniti dall’utente, lanciando l’eseguibile Windows originale invece di reimplementare il gioco. L’host è costruito principalmente in Rust come interprete CPU x86 con JIT ARM64 opzionale, più emulazione ad alto livello di KERNEL32, USER32, GDI32, DirectDraw, DirectSound, DirectInput e DirectPlay. Il progetto documenta un ampio reverse engineering di S3.EXE, inclusi import PE, stato di gioco, uso di DirectX, tracce runtime Wine, patch di byte per varianti dell’eseguibile e un framework di mod con hook guest e livelli UI orientati al touch. Gli strumenti di supporto includono script di analisi Python e piccoli frontend Java e Swift per il packaging mobile, oltre a rete relay multigiocatore e test di determinismo per il gioco in lockstep. È rivolto a sviluppatori e ricercatori interessati alla preservazione di giochi PC classici, al reverse engineering binario e al porting di titoli Win32 legacy su mobile tramite emulazione e HLE delle API invece di riscritture complete.
