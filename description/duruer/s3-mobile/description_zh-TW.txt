S3 Mobile 是一款移植專案，可在 Android 與 iOS 上利用使用者自備的 GOG 遊戲檔案執行《工人物語 III》（The Settlers III），透過執行原始 Windows 可執行檔而非重新實作遊戲。主機端主要以 Rust 撰寫，作為 x86 CPU 解譯器並可選 ARM64 JIT，並對 KERNEL32、USER32、GDI32、DirectDraw、DirectSound、DirectInput 與 DirectPlay 進行高階模擬（HLE）。專案記錄了針對 S3.EXE 的大量逆向工程，涵蓋 PE 匯入、遊戲狀態、DirectX 用法、Wine 執行階段追蹤、針對不同可執行檔變體的位元組修補，以及具訪客端掛鉤與觸控導向 UI 層的 mod 框架。輔助工具包括 Python 分析腳本以及用於行動裝置封裝的小型 Java 與 Swift 前端，另有供 lockstep 連線對戰用的多人中繼網路與確定性測試。目標對象為關注經典 PC 遊戲保存、二進位逆向，以及透過模擬與 API HLE 將舊版 Win32 作品帶上行動平台（而非全面重寫）的開發者與研究者。
