S3 Mobile は、ユーザーが用意した GOG のゲームファイルから Android および iOS 上で The Settlers III を動かす移植版であり、ゲームを再実装するのではなく元の Windows 実行ファイルをそのまま実行する。ホストは主に Rust で構築され、x86 CPU インタプリタと任意の ARM64 JIT に加え、KERNEL32、USER32、GDI32、DirectDraw、DirectSound、DirectInput、DirectPlay の高水準エミュレーション（HLE）を備える。プロジェクトでは S3.EXE の広範なリバースエンジニアリングが文書化されており、PE インポート、ゲーム状態、DirectX の利用、Wine ランタイムトレース、実行ファイルバリアント向けバイトパッチ、ゲストフックとタッチ向け UI レイヤを持つ mod フレームワークなどが含まれる。支援ツールとして Python 解析スクリプトやモバイル向けパッケージング用の小さな Java・Swift フロントエンド、マルチプレイ用リレーネットワーク、ロックステッププレイ向けの決定性テストがある。クラシック PC ゲーム保存、バイナリ RE、全面書き直しではなくエミュレーションと API HLE によるレガシー Win32 タイトルのモバイル化に関心のある開発者と研究者を対象とする。
