S3 Mobile — порт, запускающий The Settlers III на Android и iOS из игровых файлов GOG, предоставленных пользователем, выполняя оригинальный исполняемый файл Windows, а не переписывая игру заново. Хост в основном написан на Rust как интерпретатор CPU x86 с опциональным ARM64 JIT и эмуляцией высокого уровня KERNEL32, USER32, GDI32, DirectDraw, DirectSound, DirectInput и DirectPlay. Проект документирует обширный реверс-инжиниринг S3.EXE, включая импорты PE, состояние игры, использование DirectX, трассировки среды Wine, байтовые патчи для вариантов исполняемого файла и mod-фреймворк с гостевыми хуками и UI-слоями, ориентированными на сенсорный ввод. Вспомогательные средства — Python-скрипты анализа и небольшие фронтенды на Java и Swift для мобильной упаковки, а также сетевая ретрансляция для мультиплеера и тесты детерминизма для пошаговой синхронной игры. Ориентирован на разработчиков и исследователей, интересующихся сохранением классических PC-игр, бинарным реверс-инжинирингом и переносом устаревших Win32-игр на мобильные платформы через эмуляцию и HLE API вместо полной переработки.
