S3 Mobile is a port that runs The Settlers III on Android and iOS from user-supplied GOG game files, executing the original Windows executable rather than reimplementing the game. The host is built mainly in Rust as an x86 CPU interpreter with optional ARM64 JIT, plus high-level emulation of KERNEL32, USER32, GDI32, DirectDraw, DirectSound, DirectInput, and DirectPlay. The project documents extensive reverse engineering of S3.EXE, including PE imports, game state, DirectX usage, Wine runtime traces, byte patches for executable variants, and a mod framework with guest hooks and touch-oriented UI layers. Supporting tooling includes Python analysis scripts and small Java and Swift frontends for mobile packaging, along with multiplayer relay networking and determinism testing for lockstep play. It targets developers and researchers interested in classic PC game preservation, binary reverse engineering, and bringing legacy Win32 titles to mobile through emulation and API HLE instead of full rewrites.
