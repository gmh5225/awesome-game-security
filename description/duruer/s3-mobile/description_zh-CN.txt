S3 Mobile 是一款移植项目，可在 Android 与 iOS 上利用用户自备的 GOG 游戏文件运行《工人物语 III》（The Settlers III），通过执行原始 Windows 可执行文件而非重新实现游戏。宿主端主要以 Rust 编写，作为 x86 CPU 解释器并可选 ARM64 JIT，并对 KERNEL32、USER32、GDI32、DirectDraw、DirectSound、DirectInput 与 DirectPlay 进行高级仿真（HLE）。项目记录了针对 S3.EXE 的大量逆向工程，涵盖 PE 导入、游戏状态、DirectX 用法、Wine 运行时跟踪、针对不同可执行变体的字节补丁，以及带客户机钩子与触控向 UI 层的 mod 框架。辅助工具包括 Python 分析脚本以及用于移动打包的小型 Java 与 Swift 前端，另有用于 lockstep 联机玩法的多人中继网络与确定性测试。面向关注经典 PC 游戏保存、二进制逆向，以及通过仿真与 API HLE 将遗留 Win32 作品移植到移动端（而非全面重写）的开发者和研究者。
