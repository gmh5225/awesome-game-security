KX-Vision 是一款面向《激战2》（Guild Wars 2）的开源 ESP 覆盖层，可在正在运行的客户端之上绘制附近玩家、事件和世界对象的实时游戏信息。该项目以 C++23 实现，采用 Windows Visual Studio 工程，通过 MinHook 挂钩 DirectX 11 呈现流程，并借助 ImGui 与 GLM 渲染叠加层。代码库记录了《激战2》引擎内部实现，包括游戏线程钩子，以及用于在独立逻辑线程与渲染线程之间安全读取 ContextCollection 数据的捕获-存储模式，配合 ReClass 推导的结构体与生成的 API 头文件以描述内存布局。该项目面向研究客户端叠加层技术、MMO 内存访问模式，以及第三方工具如何与运行中的游戏进程交互的逆向工程师与游戏安全研究人员。
