KX-Vision 是一款面向《激战2》（Guild Wars 2）的开源 ESP 叠加层，可在运行中的游戏客户端之上绘制附近玩家、事件和场景物体的游戏内信息。该项目以 C++23 实现，为 Windows Visual Studio 工程，通过 MinHook 挂钩 DirectX 11 呈现流程，并使用 ImGui 与 GLM 渲染叠加层。代码库记录了《激战2》引擎内部机制，包括游戏线程 hook 以及用于在逻辑线程与渲染线程之间安全读取 ContextCollection 数据的 capture-and-store 模式，并包含基于 ReClass 的结构体和用于内存布局的生成 API 头文件。它面向研究客户端叠加层技术、MMO 内存访问模式，以及第三方工具如何与运行中游戏进程交互的逆向工程师与游戏安全研究人员。
