KX-Vision — это оверлей ESP с открытым исходным кодом для Guild Wars 2, который отображает поверх запущенного клиента игровую информацию о ближайших игроках, событиях и объектах мира. Проект реализован на C++23 как проект Windows Visual Studio и перехватывает презентацию DirectX 11 с помощью MinHook, отрисовывая оверлеи через ImGui и GLM. Кодовая база документирует внутреннее устройство движка Guild Wars 2, включая хук игрового потока и паттерн capture-and-store для безопасного чтения данных ContextCollection между отдельными потоками логики и рендеринга, со структурами на основе ReClass и сгенерированными API-заголовками для разметки памяти. Он предназначен для специалистов по реверс-инжинирингу и исследователей игровой безопасности, изучающих клиентские техники оверлеев, паттерны доступа к памяти в MMO и взаимодействие сторонних инструментов с активным игровым процессом.
