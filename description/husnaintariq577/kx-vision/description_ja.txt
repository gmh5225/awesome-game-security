KX-Vision は Guild Wars 2 向けのオープンソース ESP オーバーレイで、実行中のクライアント上に、近くのプレイヤー、イベント、ワールドオブジェクトに関するゲーム内情報を描画します。C++23 で実装された Windows Visual Studio プロジェクトであり、MinHook で DirectX 11 のプレゼンテーションをフックし、ImGui と GLM でオーバーレイを描画します。コードベースには Guild Wars 2 エンジンの内部構造が文書化されており、ゲームスレッドフックや、ロジックスレッドとレンダースレッドをまたいで ContextCollection データを安全に読み取るための capture-and-store パターン、ReClass 由来の構造体、メモリレイアウト用の生成 API ヘッダーが含まれます。クライアント側オーバーレイ手法、MMO のメモリアクセスパターン、サードパーティツールが稼働中のゲームプロセスとどう相互作用するかを研究するリバースエンジニアやゲームセキュリティ研究者を対象としています。
