KX-Vision は Guild Wars 2 向けのオープンソース ESP オーバーレイで、実行中のクライアント上に、近くのプレイヤー、イベント、ワールドオブジェクトに関するゲーム内情報を描画します。C++23 で実装された Windows Visual Studio プロジェクトであり、MinHook で DirectX 11 のプレゼンテーションをフックし、ImGui と GLM によるオーバーレイ描画を行います。コードベースは Guild Wars 2 エンジンの内部構造を文書化しており、ゲームスレッドフックや、独立したロジックスレッドとレンダースレッド間で ContextCollection データを安全に読み取るためのキャプチャ・アンド・ストアパターン、ReClass 由来の構造体、メモリレイアウト用に生成された API ヘッダーを含みます。クライアントサイドのオーバーレイ手法、MMO のメモリアクセスパターン、サードパーティツールが実行中のゲームプロセスとどのように相互作用するかを研究するリバースエンジニアおよびゲームセキュリティ研究者を対象としています。
