KX-Vision es una superposición ESP de código abierto para Guild Wars 2 que dibuja información del juego sobre jugadores cercanos, eventos y objetos del mundo encima del cliente en ejecución. Está implementado en C++23 como un proyecto de Windows Visual Studio y engancha la presentación de DirectX 11 con MinHook mientras renderiza las superposiciones mediante ImGui y GLM. La base de código documenta los internals del motor de Guild Wars 2, incluido un hook del hilo del juego y un patrón capture-and-store para leer de forma segura datos de ContextCollection entre hilos de lógica y de renderizado separados, con estructuras derivadas de ReClass y encabezados de API generados para el diseño de memoria. Está dirigido a ingenieros de ingeniería inversa e investigadores de seguridad de juegos que estudian técnicas de superposición del lado del cliente, patrones de acceso a memoria en MMO y cómo las herramientas de terceros interactúan con un proceso de juego en vivo.
