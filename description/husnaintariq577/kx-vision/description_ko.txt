KX-Vision은 Guild Wars 2용 오픈 소스 ESP 오버레이로, 실행 중인 클라이언트 위에 주변 플레이어, 이벤트, 월드 오브젝트에 대한 게임 내 정보를 그립니다. C++23로 구현된 Windows Visual Studio 프로젝트이며, MinHook으로 DirectX 11 프레젠테이션을 후킹하고 ImGui와 GLM으로 오버레이를 렌더링합니다. 코드베이스에는 Guild Wars 2 엔진 내부 구조가 문서화되어 있으며, 게임 스레드 후크와 로직 스레드 및 렌더 스레드 간 ContextCollection 데이터를 안전하게 읽기 위한 capture-and-store 패턴, ReClass 기반 구조체, 메모리 레이아웃용 생성 API 헤더가 포함됩니다. 클라이언트 측 오버레이 기법, MMO 메모리 접근 패턴, 서드파티 도구가 실행 중인 게임 프로세스와 상호작용하는 방식을 연구하는 리버스 엔지니어와 게임 보안 연구자를 대상으로 합니다.
