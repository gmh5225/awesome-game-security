KX-Vision is an open-source ESP overlay for Guild Wars 2 that draws in-game information about nearby players, events, and world objects on top of the running client. It is implemented in C++23 as a Windows Visual Studio project and hooks DirectX 11 presentation with MinHook while rendering overlays through ImGui and GLM. The codebase documents Guild Wars 2 engine internals, including a game-thread hook and capture-and-store pattern for safely reading ContextCollection data across separate logic and render threads, with ReClass-derived structures and generated API headers for memory layout. It targets reverse engineers and game-security researchers studying client-side overlay techniques, MMO memory access patterns, and how third-party tools interact with a live game process.
