KX-Vision 是一款面向《激戰2》（Guild Wars 2）的開源 ESP 疊加層，可在執行中的遊戲用戶端之上繪製附近玩家、事件和場景物體的遊戲內資訊。該專案以 C++23 實作，為 Windows Visual Studio 工程，透過 MinHook 掛鉤 DirectX 11 呈現流程，並使用 ImGui 與 GLM 渲染疊加層。程式碼庫記錄了《激戰2》引擎內部機制，包括遊戲執行緒 hook 以及用於在邏輯執行緒與渲染執行緒之間安全讀取 ContextCollection 資料的 capture-and-store 模式，並包含基於 ReClass 的結構與用於記憶體配置的生成 API 標頭檔。它面向研究用戶端疊加層技術、MMO 記憶體存取模式，以及第三方工具如何與執行中遊戲程序互動的逆向工程師與遊戲安全研究人員。
