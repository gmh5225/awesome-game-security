KX-Vision 是一款面向《激戰2》（Guild Wars 2）的開源 ESP 覆蓋層，可在正在執行的用戶端之上繪製附近玩家、事件與世界物件的即時遊戲資訊。該專案以 C++23 實作，採用 Windows Visual Studio 工程，透過 MinHook 掛鉤 DirectX 11 呈現流程，並借助 ImGui 與 GLM 渲染疊加層。程式碼庫記錄了《激戰2》引擎內部實作，包括遊戲執行緒掛鉤，以及用於在獨立邏輯執行緒與渲染執行緒之間安全讀取 ContextCollection 資料的擷取-儲存模式，配合 ReClass 推導的結構與產生的 API 標頭檔以描述記憶體配置。該專案面向研究用戶端疊加層技術、MMO 記憶體存取模式，以及第三方工具如何與執行中的遊戲行程互動的逆向工程師與遊戲安全研究人員。
