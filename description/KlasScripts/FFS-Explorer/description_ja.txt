FFS Explorer は、一般的なモバイルフォレンジックベンダーが ZIP アーカイブとして提供する iOS および Android のフルファイルシステム抽出イメージを、展開せずに閲覧するためのデスクトップアプリケーションです。Python と PySide6 GUI で実装され、直接オフセットシークでアーカイブを読み取り、Cellebrite の MessagePack サイドカーメタデータや GrayKey の ZIP 拡張フィールドのタイムスタンプ・属性など、ベンダー固有の処理にも対応します。組み込みビューアとパーサーは、WAL 差分や carving を含む SQLite データベース、プロパティリスト、LevelDB および IndexedDB ストア、SEGB ログ、十六進ダンプ、BLOB や plist から復元した埋め込みメディアなど、ネイティブなモバイルアーティファクトを表示します。宣言型のアーティファクトフレームワークには両プラットフォーム向けのメッセージング、ブラウザ、システムデータ用の多数のアプリ別パーサーが同梱され、キーワード検索、ヘッダーに基づく型判定、検証者向けの任意の AI 支援レポート機能も備えています。本ツールは、抽出レイアウトの確認、主流スイートの報告内容を生ファイルと照合して検証し、モバイルアプリデータのディスク上の保存形式を調査する必要があるデジタルフォレンジックの実務者と研究者を対象としています。
