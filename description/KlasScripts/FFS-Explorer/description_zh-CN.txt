FFS Explorer 是一款桌面应用，用于浏览常见移动取证厂商提供的、以 ZIP 打包的 iOS 与 Android 完整文件系统提取镜像，无需先解压镜像。它使用 Python 与 PySide6 图形界面实现，通过直接按偏移寻址读取归档，包括对 Cellebrite MessagePack 附属元数据以及 GrayKey ZIP 扩展字段时间戳与属性的厂商特定处理。内置查看器与解析器可展示原生移动取证产物，例如带 WAL 差异与 carving 的 SQLite 数据库、属性列表、LevelDB 与 IndexedDB 存储、SEGB 日志、十六进制转储，以及从 BLOB 与 plist 中恢复的嵌入媒体。声明式取证框架内置大量按应用划分的解析器，覆盖双平台上的消息、浏览器与系统数据，并支持关键词搜索、基于文件头的类型识别，以及可选的 AI 辅助报告，供检验人员使用。该工具面向需要检查提取布局、对照原始文件验证主流套件报告内容，以及研究移动应用数据在磁盘上如何存储的数字取证从业者与研究人员。
