FFS Explorer is a desktop application for browsing iOS and Android full file system extractions packaged as ZIP archives from common mobile forensic vendors, without unpacking the image first. It is implemented in Python with a PySide6 GUI and reads archives via direct offset seeks, including vendor-specific handling of Cellebrite MessagePack sidecar metadata and GrayKey ZIP extra-field timestamps and attributes. Built-in viewers and parsers expose native mobile artifacts such as SQLite databases with WAL diff and carving, property lists, LevelDB and IndexedDB stores, SEGB logs, hex dumps, and embedded media recovered from BLOBs and plists. A declarative artifact framework ships many per-app parsers for messaging, browser, and system data on both platforms, alongside keyword search, header-based typing, and optional AI-assisted reporting for examiners. The tool targets digital forensics practitioners and researchers who need to inspect extraction layout, validate what mainstream suites report against raw files, and study how mobile app data is stored on disk.
