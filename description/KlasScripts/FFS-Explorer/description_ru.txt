FFS Explorer — настольное приложение для просмотра полных извлечений файловых систем iOS и Android, упакованных в ZIP-архивы типичными поставщиками мобильной криминалистики, без предварительной распаковки образа. Реализовано на Python с GUI на PySide6; архивы читаются прямым позиционированием по смещению, включая поддержку sidecar-метаданных MessagePack Cellebrite и меток времени и атрибутов дополнительных полей ZIP GrayKey. Встроенные просмотрщики и парсеры открывают нативные мобильные артефакты: базы SQLite с diff WAL и carving, property list, хранилища LevelDB и IndexedDB, журналы SEGB, hex-дампы и встроенные медиа, восстановленные из BLOB и plist. Декларативный фреймворк артефактов включает множество парсеров по приложениям для сообщений, браузера и системных данных на обеих платформах, а также поиск по ключевым словам, определение типа по заголовкам и опциональные отчёты с помощью ИИ для экспертов. Инструмент предназначен для практиков и исследователей цифровой криминалистики, которым нужно изучать структуру извлечений, сверять отчёты популярных комплексов с сырыми файлами и исследовать, как данные мобильных приложений хранятся на диске.
