이 프로젝트는 Model Context Protocol 서버로, 단일 연결을 통해 AI 에이전트 요청을 여러 IDA Pro 디스어셈블러 인스턴스로 라우팅하여 관련된 여러 바이너리를 동시에 리버스 엔지니어링할 수 있습니다. Python으로 구축되었으며 IDA Pro 8.5 이상을 지원하고, 실행 중인 인스턴스를 자동으로 탐지하며 분석 호출을 병렬로 디스패치하고, 디컴파일, 메모리 읽기, 패치, 바이너리 조사를 위한 다양한 MCP 도구를 제공합니다. 두드러진 기능은 명령 MinHash, 임포트 및 문자열 앵커, 제어 흐름 구조, 선택적 로컬 jTrans 신경 임베딩을 결합한 크로스 바이너리 함수 유사성 검색으로, 심볼이 제거되었거나 재컴파일된 코드를 매칭합니다. Claude Code, Cursor 등 일반적인 MCP 클라이언트와 통합되며, 게임 보안 및 안티치트 워크플로에서 드로퍼, 페이로드, 패치, 변종을 비교하는 악성코드 분석가와 리버스 엔지니어를 대상으로 합니다.
