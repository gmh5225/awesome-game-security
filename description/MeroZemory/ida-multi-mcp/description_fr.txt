Ce projet est un serveur Model Context Protocol qui achemine les requêtes des agents IA vers plusieurs instances du désassembleur IDA Pro via une seule connexion, permettant l'ingénierie inverse simultanée de plusieurs binaires connexes. Développé en Python pour IDA Pro 8.5 et versions ultérieures, il découvre automatiquement les instances en cours d'exécution, dispatch les appels d'analyse en parallèle et expose un large ensemble d'outils MCP pour la décompilation, la lecture mémoire, le patching et l'exploration binaire. Une fonctionnalité remarquable est la recherche de similarité de fonctions inter-binaires, combinant MinHash d'instructions, ancres d'imports et de chaînes, structure de flux de contrôle et embeddings neuronaux jTrans locaux optionnels pour faire correspondre du code strippé ou recompilé. Il s'intègre aux clients MCP courants tels que Claude Code et Cursor, et s'adresse aux analystes de malwares et ingénieurs en rétro-ingénierie comparant droppers, charges utiles, correctifs et variantes dans les workflows de sécurité des jeux et anti-triche.
