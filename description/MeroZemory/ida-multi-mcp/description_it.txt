Questo progetto è un server Model Context Protocol che instrada le richieste degli agenti IA verso più istanze del disassemblatore IDA Pro da una singola connessione, consentendo l'ingegneria inversa simultanea di diversi binari correlati. Sviluppato in Python per IDA Pro 8.5 e versioni successive, rileva automaticamente le istanze in esecuzione, distribuisce le chiamate di analisi in parallelo ed espone un'ampia gamma di strumenti MCP per decompilazione, lettura della memoria, patching e analisi dei binari. Una funzionalità distintiva è la ricerca di similarità tra funzioni cross-binary, che combina MinHash delle istruzioni, ancoraggi di import e stringhe, struttura del flusso di controllo ed embedding neurali jTrans locali opzionali per abbinare codice privo di simboli o ricompilato. Si integra con client MCP comuni come Claude Code e Cursor ed è rivolto ad analisti di malware e reverse engineer che confrontano dropper, payload, patch e varianti nei flussi di lavoro di sicurezza dei giochi e anti-cheat.
