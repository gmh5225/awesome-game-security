Dieses Projekt ist ein Model Context Protocol-Server, der KI-Agentenanfragen über eine einzige Verbindung an mehrere IDA Pro-Disassembler-Instanzen weiterleitet und so die gleichzeitige Reverse-Engineering-Analyse mehrerer verwandter Binärdateien ermöglicht. In Python für IDA Pro 8.5 und höher entwickelt, erkennt es laufende Instanzen automatisch, verteilt Analyseaufrufe parallel und stellt eine breite Palette an MCP-Tools für Dekompilierung, Speicherlesen, Patching und Binärdatei-Übersicht bereit. Ein herausragendes Merkmal ist die binäreübergreifende Funktionssimilaritätssuche, die Instruction-MinHash, Import- und String-Anker, Kontrollflussstruktur und optionale lokale jTrans-Neuralembeddings kombiniert, um gestrippten oder neu kompilierten Code abzugleichen. Es integriert sich in gängige MCP-Clients wie Claude Code und Cursor und richtet sich an Malware-Analysten und Reverse Engineers, die Dropper, Payloads, Patches und Varianten in Game-Security- und Anti-Cheat-Workflows vergleichen.
