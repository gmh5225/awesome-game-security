Este proyecto es un servidor Model Context Protocol que enruta las solicitudes de agentes de IA a múltiples instancias del desensamblador IDA Pro desde una sola conexión, permitiendo la ingeniería inversa simultánea de varios binarios relacionados. Desarrollado en Python para IDA Pro 8.5 y versiones posteriores, descubre automáticamente las instancias en ejecución, despacha llamadas de análisis en paralelo y expone un amplio conjunto de herramientas MCP para descompilación, lectura de memoria, parcheo y exploración binaria. Una característica destacada es la búsqueda de similitud de funciones entre binarios, que combina MinHash de instrucciones, anclas de importaciones y cadenas, estructura de flujo de control y embeddings neuronales jTrans locales opcionales para emparejar código sin símbolos o recompilado. Se integra con clientes MCP habituales como Claude Code y Cursor, y está dirigido a analistas de malware e ingenieros de reversa que comparan droppers, cargas útiles, parches y variantes en flujos de trabajo de seguridad de juegos y anti-cheat.
