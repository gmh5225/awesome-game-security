该项目是一个 Model Context Protocol 服务器，可通过单一连接将 AI 智能体请求路由到多个 IDA Pro 反汇编器实例，从而同时对多个相关二进制文件进行逆向工程。基于 Python 开发，支持 IDA Pro 8.5 及更高版本，可自动发现运行中的实例、并行分发分析调用，并提供涵盖反编译、内存读取、补丁与二进制概览的丰富 MCP 工具。其突出功能是跨二进制函数相似性搜索，结合指令 MinHash、导入项与字符串锚点、控制流结构，以及可选的本地 jTrans 神经嵌入，用于匹配已剥离符号或重新编译的代码。可与 Claude Code、Cursor 等常见 MCP 客户端集成，面向恶意软件分析师与逆向工程师，用于在游戏安全与反作弊工作流中对比投放器、载荷、补丁及变体。
