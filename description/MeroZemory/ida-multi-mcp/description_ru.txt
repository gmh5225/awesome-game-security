Этот проект представляет собой сервер Model Context Protocol, который направляет запросы ИИ-агентов к нескольким экземплярам дизасsemblера IDA Pro через одно соединение, обеспечивая одновременный реверс-инжиниринг нескольких связанных бинарных файлов. Написан на Python для IDA Pro 8.5 и новее, автоматически обнаруживает запущенные экземпляры, распределяет вызовы анализа параллельно и предоставляет широкий набор инструментов MCP для декомпиляции, чтения памяти, патчинга и обзора бинарных файлов. Выдающейся возможностью является межбинарный поиск сходства функций, сочетающий MinHash инструкций, якоря импортов и строк, структуру потока управления и опциональные локальные нейронные эмбеддинги jTrans для сопоставления кода без символов или перекомпилированного кода. Интегрируется с распространёнными MCP-клиентами, такими как Claude Code и Cursor, и предназначен для аналитиков вредоносного ПО и специалистов по реверс-инжинирингу, сравнивающих дропперы, полезные нагрузки, патчи и варианты в рабочих процессах игровой безопасности и античита.
