本プロジェクトは Model Context Protocol サーバーで、単一接続から AI エージェントのリクエストを複数の IDA Pro 逆アセンブラインスタンスへルーティングし、関連する複数のバイナリを同時にリバースエンジニアリングできます。Python で構築され、IDA Pro 8.5 以降に対応し、実行中のインスタンスを自動検出して分析呼び出しを並列にディスパッチし、デコンパイル、メモリ読み取り、パッチ適用、バイナリ調査向けの豊富な MCP ツールを提供します。目玉機能は、命令 MinHash、インポートと文字列アンカー、制御フロー構造、および任意のローカル jTrans ニューラル埋め込みを組み合わせたクロスバイナリ関数類似性検索で、シンボル除去済みや再コンパイルされたコードの照合に対応します。Claude Code や Cursor などの一般的な MCP クライアントと連携し、マルウェア解析者やリバースエンジニアが、ゲームセキュリティおよびアンチチートのワークフローでドロッパー、ペイロード、パッチ、バリアントを比較する用途を想定しています。
