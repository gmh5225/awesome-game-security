本專案是一個 Model Context Protocol 伺服器，可透過單一連線將 AI 代理程式請求路由至多個 IDA Pro 反組譯器執行個體，從而同時對多個相關二進位檔進行逆向工程。以 Python 建置，支援 IDA Pro 8.5 及更高版本，可自動探索執行中的執行個體、平行分派分析呼叫，並提供涵蓋反編譯、記憶體讀取、修補與二進位概覽的豐富 MCP 工具。其突出功能是跨二進位函式相似性搜尋，結合指令 MinHash、匯入項與字串錨點、控制流程結構，以及可選的本地 jTrans 神經嵌入，用於比對已剝除符號或重新編譯的程式碼。可與 Claude Code、Cursor 等常見 MCP 用戶端整合，面向惡意軟體分析師與逆向工程師，用於在遊戲安全與反作弊工作流程中比較投放器、載荷、修補與變體。
