This project is a Model Context Protocol server that routes AI agent requests to multiple IDA Pro disassembler instances from a single connection, enabling simultaneous reverse engineering of several related binaries. Built in Python for IDA Pro 8.5 and later, it auto-discovers running instances, dispatches analysis calls in parallel, and exposes a broad set of MCP tools for decompilation, memory reading, patching, and binary survey. A standout feature is cross-binary function similarity search combining instruction MinHash, import and string anchors, control-flow structure, and optional local jTrans neural embeddings to match stripped or recompiled code. It integrates with common MCP clients such as Claude Code and Cursor and is aimed at malware analysts and reverse engineers comparing droppers, payloads, patches, and variants in game security and anti-cheat workflows.
