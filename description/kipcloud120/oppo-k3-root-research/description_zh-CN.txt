本仓库记录了一项结构化可行性研究：在 Bootloader 已锁定、仅能通过 ADB 获得 shell、运行 Android 11 与 Linux 4.9.227 内核的 OPPO K3 手机上获取临时 root。工作系统评估了五个内核与用户空间攻击面——包括 KGSL、GhostLock 式 futex/rtmutex 竞态、binder CVE 与 FastRPC——并记录每条路径为何在可验证的具体缺口处失败，而非提供可用 exploit。主要实现为 Python 与 C：离线分析 vmlinux 符号、系统调用栈几何与 4.9 结构体布局，以及设备端探测与竞态程序，并附带大量交接说明、ADB 产物与内核源码引用。面向需要可复现负向结果案例研究与工具、用于锁定厂商 Android 加固与权限提升研究的移动安全研究人员、逆向工程师与内核 exploit 分析人员。
