本リポジトリは、ブートローダーがロックされ、ADB による shell のみの接続、Android 11 と Linux 4.9.227 カーネルを搭載した OPPO K3 端末で一時的な root 取得が可能かどうかを構造化した実現性調査として文書化しています。KGSL、GhostLock 型の futex/rtmutex レース、binder の CVE、FastRPC など五つのカーネルおよびユーザ空間の攻撃面を体系的に評価し、各経路が検証可能な具体的なギャップで失敗する理由を記録しており、動作する exploit は提供しません。主に Python と C で、vmlinux シンボル、システムコールスタック形状、4.9 向け構造体レイアウトのオフライン解析、および実機上のプローブとレースプログラムを同梱し、引き継ぎメモ、ADB 成果物、カーネルソース参照を豊富に載せています。対象読者は、ベンダーによるロックされた Android のハードニングと権限昇格研究のために、再現可能な否定的結果のケーススタディとツールを必要とするモバイルセキュリティ研究者、リバースエンジニア、カーネル exploit 分析者です。
