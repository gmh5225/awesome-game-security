本儲存庫記錄一項結構化可行性研究：在 Bootloader 已鎖定、僅能透過 ADB 取得 shell、運行 Android 11 與 Linux 4.9.227 內核的 OPPO K3 手機上取得暫時 root。工作系統評估五個內核與使用者空間攻擊面——包括 KGSL、GhostLock 式 futex/rtmutex 競態、binder CVE 與 FastRPC——並記錄每條路徑為何在可驗證的具體缺口處失敗，而非提供可用 exploit。主要以 Python 與 C 實作：離線分析 vmlinux 符號、系統呼叫堆疊幾何與 4.9 結構體配置，以及裝置端探測與競態程式，並附大量交接說明、ADB 產物與內核原始碼參考。面向需要可重現負向結果案例研究與工具、用於鎖定廠商 Android 加固與權限提升研究的行動安全研究人員、逆向工程師與內核 exploit 分析人員。
