Legacy Recreated 是一個非官方工作台，用於研究 Septerra Core 1.04：將正式版可執行檔的靜態重編譯與對原始二進位的系統化 Ghidra 反編譯相結合。它藉由 M-HT SRW 建置可在現代 Windows 上執行的版本，並將該建置視為行為參照；Java 版 Ghidra 腳本負責清點函式、從 WinMain 遍歷呼叫圖、套用型別並匯出反編譯結果，以產生可讀的 C 程式碼。配套的 Python 工具、MSVC 與 NASM 建置腳本以及執行時期修補記錄引擎內部機制（如遊戲狀態機、物件插槽與戰鬥註冊），並支援美術套件覆寫、位元圖傳輸日誌與縮放呈現，且不分發遊戲資源。本專案面向希望以證據為基礎理解遺留編譯遊戲、並從二進位分析逐步走向可維護程式碼的逆向工程師與保存研究人員。
