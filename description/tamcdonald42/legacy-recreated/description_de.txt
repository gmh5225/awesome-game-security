Legacy Recreated ist eine inoffizielle Werkbank zum Studium von Septerra Core 1.04, die eine statische Rekompilierung der ausgelieferten ausführbaren Datei mit einer systematischen Ghidra-Dekompilierung der Originalbinärdatei verbindet. Über M-HT SRW entsteht ein unter modernem Windows lauffähiger Build, der als Verhaltensorakel dient, während Java-Ghidra-Skripte Funktionen erfassen, Aufrufgraphen ab WinMain durchlaufen, Typen anwenden und Dekompilat in lesbares C exportieren. Unterstützende Python-Tools, MSVC- und NASM-Build-Skripte sowie Laufzeit-Patches dokumentieren Engine-Interna wie Spielzustandsautomaten, Objekt-Slots und Kampfregistrierung und ermöglichen Art-Pack-Overrides, Blit-Protokollierung und skalierte Darstellung ohne Verteilung von Spiel-Assets. Das Projekt richtet sich an Reverse Engineers und Preservation-Forscher, die evidenzbasiertes Verständnis eines Legacy-kompilierten Spiels und einen schrittweisen Weg von der Binäranalyse zu wartbarem Code suchen.
