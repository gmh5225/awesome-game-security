Legacy Recreated は、Septerra Core 1.04 を研究するための非公式ワークベンチで、出荷版実行ファイルの静的再コンパイルと元バイナリの体系的な Ghidra 逆コンパイルを組み合わせている。M-HT SRW により現代の Windows で動作するビルドを作成し、そのビルドを振る舞いのオラクルとして扱う一方、Java の Ghidra スクリプトが関数を一覧化し、WinMain からコールグラフをたどり、型を適用して逆コンパイル結果をエクスポートし、読みやすい C へとつなげる。Python ツール、MSVC と NASM のビルドスクリプト、ランタイムパッチがゲーム状態機械、オブジェクトスロット、戦闘登録などのエンジン内部を文書化し、アートパックの上書き、blit ログ、スケール表示をゲームアセットの配布なしに可能にする。バイナリ解析から保守可能なコードへの段階的な道筋と、証拠に裏打ちされたレガシーコンパイルゲームの理解を求めるリバースエンジニアと保存研究者を対象とする。
