The Legacy Recreated is an unofficial workbench for studying Septerra Core 1.04 by combining a static recompilation of the shipping executable with systematic Ghidra decompilation of the original binary. It builds a modern Windows runnable via M-HT SRW and treats that build as a behavioral oracle while Java Ghidra scripts inventory functions, walk call graphs from WinMain, apply types, and export decompiled output toward readable C. Supporting Python tools, MSVC and NASM build scripts, and runtime patches document engine internals such as game state machines, object slots, and combat registration, and enable art pack overrides, blit logging, and scaled presentation without distributing game assets. The project targets reverse engineers and preservation researchers who want evidence-backed understanding of a legacy compiled game and a staged path from binary analysis to maintainable code.
