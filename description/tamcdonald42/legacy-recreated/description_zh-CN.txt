Legacy Recreated 是一个非官方工作台，用于研究 Septerra Core 1.04：将正式版可执行文件的静态重编译与对原始二进制的系统化 Ghidra 反编译相结合。它借助 M-HT SRW 构建可在现代 Windows 上运行的版本，并将该构建作为行为参照；Java 版 Ghidra 脚本负责清点函数、从 WinMain 遍历调用图、应用类型并导出反编译结果，以生成可读的 C 代码。配套的 Python 工具、MSVC 与 NASM 构建脚本以及运行时补丁记录引擎内部机制（如游戏状态机、对象槽位与战斗注册），并支持美术包覆盖、位图块传输日志与缩放显示，且不分发游戏资源。本项目面向希望以证据为基础理解遗留编译游戏、并从二进制分析逐步走向可维护代码的逆向工程师与保存研究人员。
