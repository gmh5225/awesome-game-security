CheatEngine.Client 是一个高层、生命周期安全的 C# 库，用于在 Windows x64 上于 Cheat Engine 进程内构建 in-process 插件。它基于 CheatEngine.SDK，提供激活作用域内的依赖注入、类型化内存访问、AOB 与数值扫描、进程选择、地址表、汇编与 Auto Assembler 辅助工具，以及生成的 Lua 绑定，且不会向插件代码泄露原始宿主句柄。该方案以 NuGet 包形式发布，包含流式 API、宿主与模块生命周期管理、基于租约的资源清理，以及 dotnet new ceplugin 项目模板，面向 .NET 10 与 Cheat Engine 7.7。它面向希望编写可维护、可测试的插件代码以进行内存检视、游戏修改与逆向工程工作流的开发者，而非手工封装底层 SDK 调用。
