CheatEngine.Client is a high-level, lifecycle-safe C# library for building in-process plugins that run inside Cheat Engine on Windows x64. It sits on top of CheatEngine.SDK and exposes activation-scoped dependency injection, typed memory access, AOB and value scanning, process selection, address tables, assembly and Auto Assembler helpers, and generated Lua bindings without leaking raw host handles to plugin code. The solution ships as NuGet packages with fluent APIs, hosting and module lifecycle management, lease-based resource cleanup, and a dotnet new ceplugin project template, targeting .NET 10 and Cheat Engine 7.7. It is aimed at developers who want maintainable, testable plugin code for memory inspection, game modification, and reverse-engineering workflows rather than hand-rolling low-level SDK calls.
