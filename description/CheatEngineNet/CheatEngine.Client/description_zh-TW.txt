CheatEngine.Client 是一個高階、生命週期安全的 C# 函式庫，用於在 Windows x64 上於 Cheat Engine 程序內建構 in-process 外掛。它建構於 CheatEngine.SDK 之上，提供啟用作用域內的相依性注入、型別化記憶體存取、AOB 與數值掃描、程序選擇、位址表、組合語言與 Auto Assembler 輔助工具，以及產生的 Lua 繫結，且不會向外掛程式碼洩漏原始宿主控制代碼。此方案以 NuGet 套件形式發佈，包含流暢 API、宿主與模組生命週期管理、以租約為基礎的資源清理，以及 dotnet new ceplugin 專案範本，目標為 .NET 10 與 Cheat Engine 7.7。它面向希望撰寫可維護、可測試的外掛程式碼以進行記憶體檢視、遊戲修改與逆向工程工作流程的開發者，而非手工封裝底層 SDK 呼叫。
