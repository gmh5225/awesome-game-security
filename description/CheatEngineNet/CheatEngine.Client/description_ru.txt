CheatEngine.Client — высокоуровневая C#-библиотека с безопасным управлением жизненным циклом для создания in-process плагинов, работающих внутри Cheat Engine в Windows x64. Она опирается на CheatEngine.SDK и предоставляет внедрение зависимостей в области активации, типизированный доступ к памяти, сканирование AOB и по значениям, выбор процесса, таблицы адресов, помощники для ассемблера и Auto Assembler, а также сгенерированные Lua-привязки без утечки сырых дескрипторов хоста в код плагина. Решение поставляется как пакеты NuGet с fluent API, управлением жизненным циклом хостинга и модулей, очисткой ресурсов на основе lease и шаблоном проекта dotnet new ceplugin, рассчитанное на .NET 10 и Cheat Engine 7.7. Оно предназначено для разработчиков, которым нужен поддерживаемый и тестируемый код плагинов для инспекции памяти, модификации игр и сценариев реверс-инжиниринга, а не ручная обёртка низкоуровневых вызовов SDK.
