CheatEngine.Client est une bibliothèque C# de haut niveau et sûre pour le cycle de vie, destinée à créer des plugins in-process exécutés dans Cheat Engine sous Windows x64. Elle repose sur CheatEngine.SDK et expose l’injection de dépendances à portée d’activation, l’accès mémoire typé, le balayage AOB et par valeurs, la sélection de processus, les tables d’adresses, des aides pour l’assembleur et Auto Assembler, ainsi que des liaisons Lua générées sans fuiter de handles bruts du hôte vers le code du plugin. La solution est distribuée en packages NuGet avec des API fluides, la gestion du cycle de vie de l’hébergement et des modules, un nettoyage des ressources par bail, et un modèle de projet dotnet new ceplugin, ciblant .NET 10 et Cheat Engine 7.7. Elle s’adresse aux développeurs qui veulent du code de plugin maintenable et testable pour l’inspection mémoire, la modification de jeux et les workflows de reverse engineering, plutôt que d’appeler manuellement le SDK bas niveau.
