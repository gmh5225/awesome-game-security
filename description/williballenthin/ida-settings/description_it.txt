ida-settings è una libreria Python e un plugin complementare per IDA Pro per la lettura e la gestione dei valori di configurazione utilizzati dai plugin IDAPython tramite l'infrastruttura di impostazioni condivise di Hex-Rays. Gli autori di plugin dichiarano impostazioni tipizzate in ida-plugin.json e le recuperano a runtime con una semplice API integrata con hcli e ida-config.json, mentre un Plugin Settings Manager basato su Qt offre un'interfaccia grafica agganciabile per sfogliare, modificare, convalidare e ripristinare le opzioni dei plugin installati. Il repository include anche un modulo legacy IDASettings che fornisce configurazione simile a un dizionario con ambito a livello di sistema, utente, directory o IDB, con supporto per importazione ed esportazione. Realizzato in Python con PyQt5 o PySide6 per IDA Pro 9.0 e versioni successive, è rivolto a reverse engineer e sviluppatori di plugin che necessitano di impostazioni centralizzate e convalidate per flussi di lavoro di analisi come la ricerca su binari di giochi e le indagini anti-cheat.
