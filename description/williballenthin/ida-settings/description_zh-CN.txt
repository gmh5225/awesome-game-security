ida-settings 是一个 Python 库及配套的 IDA Pro 插件，用于通过 Hex-Rays 的共享设置基础设施读取和管理 IDAPython 插件所使用的配置值。插件作者可在 ida-plugin.json 中声明类型化设置，并通过与 hcli 和 ida-config.json 集成的简单 API 在运行时获取这些设置；基于 Qt 的 Plugin Settings Manager 则提供可停靠的 GUI，用于浏览、编辑、验证和还原已安装插件的各项选项。该仓库还包含旧版 IDASettings 模块，可在系统、用户、目录或 IDB 级别提供带作用域的类字典配置，并支持导入与导出。项目基于 Python 构建，使用 PyQt5 或 PySide6，面向 IDA Pro 9.0 及更高版本，旨在帮助逆向工程师和插件开发者集中管理经过验证的设置，以支持游戏二进制研究与反作弊调查等分析工作流。
