ida-settings は、Hex-Rays の共有設定インフラストラクチャを通じて IDAPython プラグインが使用する設定値の読み取りと管理を行う Python ライブラリおよび IDA Pro 向けコンパニオンプラグインです。プラグイン作者は ida-plugin.json で型付き設定を宣言し、hcli および ida-config.json と統合されたシンプルな API で実行時に取得できます。Qt ベースの Plugin Settings Manager は、ドッキング可能な GUI でインストール済みプラグインのオプションの参照、編集、検証、復元を提供します。このリポジトリには、システム、ユーザー、ディレクトリ、または IDB レベルでスコープ付きの辞書的な設定を提供し、インポートとエクスポートをサポートするレガシーの IDASettings モジュールも同梱されています。Python と PyQt5 または PySide6 で構築され、IDA Pro 9.0 以降を対象としており、ゲームバイナリ研究やアンチチート調査などの分析ワークフロー向けに、中央集約的かつ検証済みの設定を必要とするリバースエンジニアおよびプラグイン開発者向けです。
