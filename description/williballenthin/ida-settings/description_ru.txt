ida-settings — это библиотека Python и сопутствующий плагин для IDA Pro, предназначенные для чтения и управления значениями конфигурации, используемыми плагинами IDAPython через общую инфраструктуру настроек Hex-Rays. Авторы плагинов объявляют типизированные настройки в ida-plugin.json и получают их во время выполнения с помощью простого API, интегрированного с hcli и ida-config.json, а основанный на Qt Plugin Settings Manager предоставляет докируемый графический интерфейс для просмотра, редактирования, проверки и отката параметров установленных плагинов. Репозиторий также включает устаревший модуль IDASettings, обеспечивающий конфигурацию в виде словаря с областью действия на уровне системы, пользователя, каталога или IDB с поддержкой импорта и экспорта. Создан на Python с использованием PyQt5 или PySide6 для IDA Pro 9.0 и более поздних версий; ориентирован на специалистов по реверс-инжинирингу и разработчиков плагинов, которым нужны централизованные проверенные настройки для рабочих процессов анализа, таких как исследование игровых бинарников и расследование античит-систем.
