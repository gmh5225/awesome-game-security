ida-settings ist eine Python-Bibliothek und ein begleitendes IDA-Pro-Plugin zum Lesen und Verwalten von Konfigurationswerten, die von IDAPython-Plugins über die gemeinsame Einstellungsinfrastruktur von Hex-Rays genutzt werden. Plugin-Autoren deklarieren typisierte Einstellungen in ida-plugin.json und rufen sie zur Laufzeit über eine einfache API ab, die mit hcli und ida-config.json integriert ist, während ein Qt-basierter Plugin Settings Manager eine andockbare GUI bietet, um Optionen installierter Plugins anzuzeigen, zu bearbeiten, zu validieren und zurückzusetzen. Das Repository enthält außerdem ein Legacy-Modul IDASettings, das bereichsbezogene, dictionary-ähnliche Konfiguration auf System-, Benutzer-, Verzeichnis- oder IDB-Ebene mit Import- und Exportunterstützung bereitstellt. In Python mit PyQt5 oder PySide6 für IDA Pro 9.0 und höher entwickelt, richtet es sich an Reverse Engineers und Plugin-Entwickler, die zentralisierte, validierte Einstellungen für Analyse-Workflows wie die Untersuchung von Spielbinaries und Anti-Cheat-Systemen benötigen.
