ida-settings 是一個 Python 程式庫及配套的 IDA Pro 外掛，用於透過 Hex-Rays 的共用設定基礎設施讀取和管理 IDAPython 外掛所使用的設定值。外掛作者可在 ida-plugin.json 中宣告型別化設定，並透過與 hcli 和 ida-config.json 整合的簡單 API 在執行時取得這些設定；基於 Qt 的 Plugin Settings Manager 則提供可停靠的 GUI，用於瀏覽、編輯、驗證和還原已安裝外掛的各項選項。此儲存庫還包含舊版 IDASettings 模組，可在系統、使用者、目錄或 IDB 層級提供具作用域的類字典設定，並支援匯入與匯出。專案以 Python 建置，使用 PyQt5 或 PySide6，面向 IDA Pro 9.0 及更高版本，旨在協助逆向工程師和外掛開發者集中管理經過驗證的設定，以支援遊戲二進位研究與反作弊調查等分析工作流程。
