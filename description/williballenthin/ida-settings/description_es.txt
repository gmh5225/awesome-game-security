ida-settings es una biblioteca Python y un complemento asociado para IDA Pro que permite leer y gestionar los valores de configuración utilizados por los plugins de IDAPython a través de la infraestructura de ajustes compartidos de Hex-Rays. Los autores de plugins declaran ajustes tipados en ida-plugin.json y los obtienen en tiempo de ejecución mediante una API sencilla integrada con hcli e ida-config.json, mientras que un Plugin Settings Manager basado en Qt ofrece una interfaz gráfica acoplable para explorar, editar, validar y revertir las opciones de los plugins instalados. El repositorio también incluye un módulo heredado IDASettings que proporciona configuración con ámbito similar a un diccionario a nivel de sistema, usuario, directorio o IDB, con soporte de importación y exportación. Desarrollado en Python con PyQt5 o PySide6 para IDA Pro 9.0 y versiones posteriores, está dirigido a ingenieros de ingeniería inversa y desarrolladores de plugins que necesitan ajustes centralizados y validados para flujos de análisis como la investigación de binarios de juegos y el análisis de anti-cheat.
