ida-settings est une bibliothèque Python et un plugin compagnon pour IDA Pro permettant de lire et de gérer les valeurs de configuration utilisées par les plugins IDAPython via l'infrastructure de paramètres partagés de Hex-Rays. Les auteurs de plugins déclarent des paramètres typés dans ida-plugin.json et les récupèrent à l'exécution grâce à une API simple intégrée à hcli et ida-config.json, tandis qu'un Plugin Settings Manager basé sur Qt offre une interface graphique ancrable pour parcourir, modifier, valider et rétablir les options de tous les plugins installés. Le dépôt inclut également un module IDASettings hérité qui fournit une configuration de type dictionnaire avec portée système, utilisateur, répertoire ou IDB, avec prise en charge de l'importation et de l'exportation. Construit en Python avec PyQt5 ou PySide6 pour IDA Pro 9.0 et versions ultérieures, il s'adresse aux ingénieurs en rétro-ingénierie et aux développeurs de plugins qui ont besoin de paramètres centralisés et validés pour des flux de travail d'analyse tels que la recherche sur les binaires de jeux et l'investigation anti-triche.
