Dieses Projekt ist eine DEF CON-Forschungsdemo, die native SH-4-Codeausführung im Sega Dreamcast PlanetWeb Internet Browser v3.0 erreicht und DOOM vollständig auf der emulierten Konsole ausführt, ohne einen Debugger anzubinden. Es verknüpft drei Browser-Schwachstellen — einen Remote-Code-Execution-Pfad über Eden-Service-Abonnements, einen unbegrenzten setRawDeviceID-Speicherschreibzugriff und einen Stack-Overflow bei MIME-Anhängen — um eine Java-Nutzlast zu stagen, einen nativen Loader-Stub einzupflanzen und ihn durch Öffnen einer präparierten E-Mail auszulösen. Das Repository enthält Python-Orchestrierungsskripte für DNS-Umleitung, einen rogue Eden-HTTP-Server und einen POP3-Mail-Proof-of-Concept sowie Java-Staging-Code, native SH-4-Binärdateien, eine gekürzte DOOM-WAD und einen gepatchten Flycast-Emulator-Build für macOS. Hauptsprachen sind Python und Java; native SH-4-Nutzlasten und Emulator-Patches unterstützen die Exploit-Kette. Es richtet sich an autorisierte Konsolen-Sicherheitsforschung, Schwachstellenanalyse auf Vintage-Plattformen und Reverse Engineering von Angriffsflächen in Browsern veralteter Spielekonsolen.
