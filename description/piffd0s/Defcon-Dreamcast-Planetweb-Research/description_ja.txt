本プロジェクトは DEF CON 向けの研究デモで、Sega Dreamcast の PlanetWeb Internet Browser v3.0 上でネイティブ SH-4 コード実行を実現し、デバッガを接続せずにエミュレートされた本体上で DOOM を完全に動作させます。Eden サービス購読によるリモートコード実行経路、無制限の setRawDeviceID メモリ書き込み、MIME 添付ファイルのスタックオーバーフローという 3 つのブラウザ脆弱性を連鎖させ、Java ペイロードをステージングし、ネイティブローダースタブを配置し、細工したメールを開くことで実行をトリガーします。リポジトリには DNS リダイレクト、不正 Eden HTTP サーバー、POP3 メール概念実証用の Python オーケストレーションスクリプトに加え、Java ステージングコード、ネイティブ SH-4 バイナリ、トリミング済み DOOM WAD、macOS 向けパッチ適用 Flycast エミュレータビルドが含まれます。主な言語は Python と Java で、ネイティブ SH-4 ペイロードとエミュレータパッチがエクスプロイトチェーンを支えます。許可された本体セキュリティ研究、ヴィンテージプラットフォームの脆弱性分析、レガシーゲームシステムのブラウザ攻撃面のリバースエンジニアリングを目的としています。
