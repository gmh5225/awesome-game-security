该项目是一个 DEF CON 研究演示，在 Sega Dreamcast 的 PlanetWeb Internet Browser v3.0 上实现原生 SH-4 代码执行，并在模拟主机上完整运行 DOOM，全程无需附加调试器。它串联三个浏览器漏洞——Eden 服务订阅远程代码执行路径、无界 setRawDeviceID 内存写入，以及 MIME 附件栈溢出——以部署 Java 载荷、植入原生加载器存根，并通过打开精心构造的邮件触发执行。仓库提供用于 DNS 重定向、恶意 Eden HTTP 服务器和 POP3 邮件概念验证的 Python 编排脚本，以及 Java  staging 代码、原生 SH-4 二进制文件、精简版 DOOM WAD，以及适用于 macOS 的修补版 Flycast 模拟器构建。主要语言为 Python 和 Java，原生 SH-4 载荷与模拟器补丁支撑整个利用链。本项目面向经授权的主机安全研究、复古平台漏洞分析，以及对遗留游戏系统浏览器攻击面的逆向工程。
