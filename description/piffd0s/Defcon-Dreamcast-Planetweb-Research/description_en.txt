This project is a DEF CON research demo that achieves native SH-4 code execution on the Sega Dreamcast PlanetWeb Internet Browser v3.0 and runs DOOM entirely on the emulated console without attaching a debugger. It chains three browser flaws—an Eden service-subscription remote code execution path, an unbounded setRawDeviceID memory write, and a MIME attachment stack overflow—to stage a Java payload, plant a native loader stub, and trigger it by opening a crafted email. The repository provides Python orchestration scripts for DNS redirection, a rogue Eden HTTP server, and a POP3 mail proof-of-concept, along with Java staging code, native SH-4 binaries, a trimmed DOOM WAD, and a patched Flycast emulator build for macOS. Primary languages are Python and Java, with native SH-4 payloads and emulator patches supporting the exploit chain. It is intended for authorized console security research, vintage platform vulnerability analysis, and reverse engineering of legacy game-system browser attack surfaces.
