이 프로젝트는 DEF CON 연구 데모로, Sega Dreamcast의 PlanetWeb Internet Browser v3.0에서 네이티브 SH-4 코드 실행을 달성하고 디버거를 연결하지 않은 채 에뮬레이션된 콘솔에서 DOOM을 완전히 실행합니다. Eden 서비스 구독 원격 코드 실행 경로, 무제한 setRawDeviceID 메모리 쓰기, MIME 첨부 파일 스택 오버플로우라는 세 가지 브라우저 취약점을 연쇄적으로 이용해 Java 페이로드를 스테이징하고 네이티브 로더 스텁을 심은 뒤, 조작된 이메일을 열어 실행을 트리거합니다. 저장소에는 DNS 리디렉션, 악성 Eden HTTP 서버, POP3 메일 개념 증명용 Python 오케스트레이션 스크립트와 함께 Java 스테이징 코드, 네이티브 SH-4 바이너리, 축소된 DOOM WAD, macOS용 패치된 Flycast 에뮬레이터 빌드가 포함됩니다. 주요 언어는 Python과 Java이며, 네이티브 SH-4 페이로드와 에뮬레이터 패치가 익스플로잇 체인을 지원합니다. 승인된 콘솔 보안 연구, 빈티지 플랫폼 취약점 분석, 레거시 게임 시스템 브라우저 공격 표면의 리버스 엔지니어링을 목적으로 합니다.
