Questo progetto è una demo di ricerca DEF CON che ottiene l'esecuzione di codice SH-4 nativo sul browser Internet PlanetWeb v3.0 di Sega Dreamcast ed esegue DOOM interamente sulla console emulata senza collegare un debugger. Concatena tre vulnerabilità del browser — un percorso di esecuzione remota del codice tramite l'abbonamento al servizio Eden, una scrittura di memoria setRawDeviceID senza limiti e un overflow dello stack negli allegati MIME — per preparare un payload Java, piantare uno stub di loader nativo e attivarlo aprendo un'email manipolata. Il repository fornisce script Python di orchestrazione per il reindirizzamento DNS, un server HTTP Eden rogue e una proof of concept di posta POP3, insieme a codice Java di staging, binari SH-4 nativi, un WAD DOOM ridotto e una build dell'emulatore Flycast patchata per macOS. Le lingue principali sono Python e Java, con payload SH-4 nativi e patch dell'emulatore a supporto della catena di exploit. È destinato alla ricerca autorizzata sulla sicurezza delle console, all'analisi delle vulnerabilità su piattaforme vintage e al reverse engineering delle superfici di attacco dei browser su sistemi di gioco legacy.
