Ce projet est une démonstration de recherche DEF CON qui permet l'exécution de code SH-4 natif sur le navigateur Internet PlanetWeb v3.0 de la Sega Dreamcast et exécute DOOM entièrement sur la console émulée sans attacher de débogueur. Il enchaîne trois failles du navigateur — une voie d'exécution de code à distance via l'abonnement au service Eden, une écriture mémoire setRawDeviceID sans limite et un débordement de pile sur les pièces jointes MIME — pour mettre en place une charge utile Java, implanter un stub de chargeur natif et le déclencher en ouvrant un courriel forgé. Le dépôt fournit des scripts Python d'orchestration pour la redirection DNS, un serveur HTTP Eden rogue et une preuve de concept de messagerie POP3, ainsi que du code Java de staging, des binaires SH-4 natifs, un WAD DOOM réduit et une build de l'émulateur Flycast patchée pour macOS. Les langages principaux sont Python et Java, avec des charges utiles SH-4 natives et des correctifs d'émulateur qui soutiennent la chaîne d'exploitation. Il est destiné à la recherche autorisée en sécurité des consoles, à l'analyse de vulnérabilités sur plateformes rétro et au reverse engineering des surfaces d'attaque des navigateurs sur systèmes de jeu hérités.
