本專案是一個 DEF CON 研究示範，在 Sega Dreamcast 的 PlanetWeb Internet Browser v3.0 上實現原生 SH-4 程式碼執行，並在模擬主機上完整執行 DOOM，全程無需附加除錯器。它串聯三個瀏覽器漏洞——Eden 服務訂閱遠端程式碼執行路徑、無界 setRawDeviceID 記憶體寫入，以及 MIME 附件堆疊溢位——以部署 Java 載荷、植入原生載入器存根，並透過開啟精心構造的電子郵件觸發執行。儲存庫提供用於 DNS 重新導向、惡意 Eden HTTP 伺服器與 POP3 郵件概念驗證的 Python 編排腳本，以及 Java staging 程式碼、原生 SH-4 二進位檔、精簡版 DOOM WAD，以及適用於 macOS 的修補版 Flycast 模擬器建置。主要語言為 Python 與 Java，原生 SH-4 載荷與模擬器修補支援整個利用鏈。本專案面向經授權的主機安全研究、復古平台漏洞分析，以及對遺留遊戲系統瀏覽器攻擊面的逆向工程。
