Этот проект — исследовательская демонстрация DEF CON, которая обеспечивает выполнение нативного SH-4-кода в браузере PlanetWeb Internet Browser v3.0 для Sega Dreamcast и запускает DOOM целиком на эмулируемой консоли без подключения отладчика. Он объединяет три уязвимости браузера — удалённое выполнение кода через подписку на сервис Eden, неограниченную запись в память setRawDeviceID и переполнение стека при MIME-вложениях — чтобы разместить Java-полезную нагрузку, внедрить нативный загрузочный stub и запустить его открытием подготовленного письма. Репозиторий содержит Python-скрипты оркестрации для перенаправления DNS, rogue Eden HTTP-сервера и proof-of-concept почты POP3, а также Java-код для staging, нативные SH-4-бинарники, урезанный DOOM WAD и пропатченную сборку эмулятора Flycast для macOS. Основные языки — Python и Java; нативные SH-4-полезные нагрузки и патчи эмулятора поддерживают цепочку эксплуатации. Проект предназначен для авторизованных исследований безопасности консолей, анализа уязвимостей винтажных платформ и реверс-инжиниринга поверхностей атаки браузеров унаследованных игровых систем.
