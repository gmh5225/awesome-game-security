Este proyecto es una demostración de investigación de DEF CON que logra la ejecución de código SH-4 nativo en el navegador de Internet PlanetWeb v3.0 de Sega Dreamcast y ejecuta DOOM por completo en la consola emulada sin conectar un depurador. Encadena tres fallos del navegador — una vía de ejecución remota de código mediante la suscripción al servicio Eden, una escritura de memoria setRawDeviceID sin límite y un desbordamiento de pila en adjuntos MIME — para preparar una carga útil Java, implantar un stub de cargador nativo y activarlo abriendo un correo manipulado. El repositorio incluye scripts de orquestación en Python para redirección DNS, un servidor HTTP Eden rogue y una prueba de concepto de correo POP3, junto con código Java de staging, binarios SH-4 nativos, un WAD de DOOM recortado y una compilación del emulador Flycast parcheada para macOS. Los lenguajes principales son Python y Java, con cargas útiles SH-4 nativas y parches del emulador que sostienen la cadena de explotación. Está pensado para investigación autorizada en seguridad de consolas, análisis de vulnerabilidades en plataformas vintage e ingeniería inversa de superficies de ataque en navegadores de sistemas de juego heredados.
