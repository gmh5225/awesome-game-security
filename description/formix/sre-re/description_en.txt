This project reverse engineers Solar Realms Elite 0.994b, a classic DOS BBS door game whose original source is lost, with the goal of documenting its behavior and eventually building a Linux C++ remake. Analysis centers on the Borland C++ 3.0 executable using Ghidra (including headless export), flattening VROOMM overlays for static study, and Python utilities for disassembly, string and call annotation, and decoding encrypted .II save files. Recovered material includes detailed file format specs, turn-by-turn game rules transcribed from decompiled code, and a DOSBox-based workflow to verify formulas against the original. It suits practitioners learning legacy x86 reverse engineering, binary recovery without source, and rigorous validation of inferred program logic rather than game anti-cheat or live security tooling.
