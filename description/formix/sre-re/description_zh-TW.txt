本專案對經典 DOS BBS 門區遊戲 Solar Realms Elite 0.994b 進行逆向工程；原版原始碼已佚失，目標是記錄其行為並最終以 Linux C++ 重製。分析以 Borland C++ 3.0 可執行檔為中心，使用 Ghidra（含無頭匯出）、展平 VROOMM 覆蓋層以便靜態研究，以及用於反組譯、字串與呼叫標註、解密 .II 存檔的 Python 工具。已恢復內容包括詳細的檔案格式規格、從反編譯程式碼轉錄的逐回合規則，以及以 DOSBox 為基礎的流程以對照原版驗證公式。適合學習遺留 x86 逆向、無原始碼的二進位復原，以及嚴格驗證推斷的程式邏輯，而非遊戲反作弊或即時安全工具。
