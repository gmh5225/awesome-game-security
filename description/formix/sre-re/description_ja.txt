本プロジェクトは、オリジナルソースが失われたクラシックな DOS BBS ドアゲーム Solar Realms Elite 0.994b をリバースエンジニアリングし、挙動の文書化と最終的な Linux C++ リメイクを目指す。分析の中心は Borland C++ 3.0 実行ファイルで、Ghidra（ヘッドレスエクスポート含む）、静的解析のための VROOMM オーバーレイのフラット化、逆アセンブル・文字列とコール注釈・暗号化 .II セーブの復号用 Python ユーティリティを用いる。復元された成果物には詳細なファイル形式仕様、逆コンパイルコードから書き起こしたターン制ルール、原版と照合して式を検証する DOSBox ベースのワークフローが含まれる。レガシー x86 リバースエンジニアリング、ソースなしバイナリ復元、推論したプログラムロジックの厳密な検証を学ぶ実践者向けであり、ゲームアンチチートやライブセキュリティツール向けではない。
