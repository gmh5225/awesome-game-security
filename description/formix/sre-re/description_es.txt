Este proyecto realiza ingeniería inversa de Solar Realms Elite 0.994b, un clásico juego door de BBS para DOS cuyo código fuente original se perdió, con el objetivo de documentar su comportamiento y, eventualmente, crear un remake en Linux con C++. El análisis se centra en el ejecutable Borland C++ 3.0 usando Ghidra (incluida exportación headless), aplanando overlays VROOMM para estudio estático, y utilidades Python para desensamblado, anotación de cadenas y llamadas, y decodificación de partidas guardadas .II cifradas. El material recuperado incluye especificaciones detalladas de formatos de archivo, reglas del juego turno a turno transcritas del código descompilado, y un flujo de trabajo basado en DOSBox para verificar fórmulas frente al original. Está orientado a quienes aprenden ingeniería inversa x86 legacy, recuperación binaria sin fuente y validación rigurosa de la lógica inferida, no a antitrampas de juegos ni herramientas de seguridad en vivo.
