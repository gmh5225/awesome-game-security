Этот проект занимается реверс-инжинирингом Solar Realms Elite 0.994b — классической door-игры для DOS BBS, исходный код которой утерян, с целью задокументировать её поведение и в перспективе создать ремейк на Linux на C++. Анализ сосредоточен на исполняемом файле Borland C++ 3.0 с помощью Ghidra (включая headless-экспорт), «расплющивания» оверлеев VROOMM для статического изучения и утилит на Python для дизассемблирования, аннотации строк и вызовов и расшифровки зашифрованных сохранений .II. Восстановлены подробные спецификации форматов файлов, пошаговые правила игры, переписанные из декомпилированного кода, и рабочий процесс на базе DOSBox для проверки формул по оригиналу. Подходит практикам, изучающим legacy x86 reverse engineering, восстановление бинарников без исходников и строгую проверку выведенной логики программы, а не античит для игр или инструменты оперативной безопасности.
