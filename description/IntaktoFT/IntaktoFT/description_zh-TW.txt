IntaktoFT 是一款免費開源的 Android 執行階段應用程式自我保護函式庫，可偵測被重新封裝或竄改的安裝，以及 Frida 掛勾等即時插樁與常見 mod 框架。它結合 Kotlin SDK 與原生 C++ 檢查，涵蓋應用程式完整性、常駐記憶體代理、GOT/PLT 完整性、操作碼跳板等相關訊號，並向你的程式碼回報 CLEAN、DETECTED 或 INCONCLUSIVE 結果，且不會關閉應用程式或將裝置資料傳送至廠商後端。透過 Gradle 與 JitPack 可輕量整合，支援啟動時自動檢查，並為 Android 遊戲提供可選的 Unity C# 套件。適合需要客戶端反 mod 與反作弊式防護、以對抗現成作弊與重新封裝工具的獨立開發者與遊戲工作室。
