IntaktoFT 是一款免费开源的 Android 运行时应用自保护库，可检测被重打包或篡改的安装包，以及 Frida 挂钩等实时插桩和常见 mod 框架。它将 Kotlin SDK 与用于应用完整性、驻留内存代理、GOT/PLT 完整性、操作码跳板及相关信号的原生 C++ 检测相结合，并向你的代码报告 CLEAN、DETECTED 或 INCONCLUSIVE 结果，而不会关闭应用或将设备数据发送到厂商后端。通过 Gradle 和 JitPack 可轻量集成，支持启动时自动检测，并为 Android 游戏提供可选的 Unity C# 包。面向需要客户端反 mod 与反作弊式防护、以抵御现成作弊与重打包工具的独立开发者和游戏工作室。
