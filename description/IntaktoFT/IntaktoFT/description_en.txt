IntaktoFT is a free, open-source Android runtime application self-protection library that detects repackaged or tampered installs and live instrumentation such as Frida hooks and common mod frameworks. It combines a Kotlin SDK with native C++ checks for app integrity, memory-resident agents, GOT/PLT integrity, opcode trampolines, and related signals, then reports CLEAN, DETECTED, or INCONCLUSIVE results to your code without closing the app or sending device data to a vendor backend. Integration is lightweight via Gradle and JitPack, with automatic checks at startup and an optional Unity C# package for Android games. It is aimed at indie developers and game studios that need client-side anti-mod and anti-cheat style protection against off-the-shelf cheating and repackaging tools.
