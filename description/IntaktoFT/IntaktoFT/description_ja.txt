IntaktoFT は、無料のオープンソース Android ランタイム向けアプリケーション自己保護ライブラリで、再パッケージ化や改ざんされたインストール、Frida フックなどのライブ計装や一般的な mod フレームワークを検出します。Kotlin SDK とネイティブ C++ によるアプリ整合性、メモリ常駐エージェント、GOT/PLT 整合性、オペコードトランポリンなど関連シグナルのチェックを組み合わせ、CLEAN、DETECTED、INCONCLUSIVE の結果をアプリを終了したりベンダーバックエンドに端末データを送ったりすることなくコードへ通知します。Gradle と JitPack による軽量な統合、起動時の自動チェック、Android ゲーム向けの任意 Unity C# パッケージを備えます。既製のチートや再パッケージ化ツールに対するクライアント側の anti-mod・チート対策を必要とするインディー開発者やゲームスタジオ向けです。
