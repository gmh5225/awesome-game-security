SDNX は研究向けポートで、Sleeping Dogs の Xbox 360 リテール版を静的再コンパイルしてネイティブ C++ に変換し、カスタム Vulkan グラフィックススタックを備えた Nintendo Switch ホームブリュー上で動かす。ReXGlue による default.xex から AArch64 へのバイナリリフティングを中心に、元の GPU をエミュレートするのではなく Xenos GPU コマンドストリームを解釈するネイティブレンダラと組み合わせる。シェーダーマイクロコードは XenosRecomp と DXC で事前に HLSL と SPIR-V に翻訳し、Python と C++ のツールでアーカイブ、テクスチャ、シェーダーコンテナを解析し、ベンチと Switch ビルドを自動化する。主言語は C++ と Python で、CMake が Switch とデスクトップ向けターゲットを devkitA64、libnx、Mesa NVK とともに駆動する。Xbox 360 実行ファイル、独自 UE3 時代のアセット、制約のあるコンソールでの低レベルグラフィックス置き換えを研究するリバースエンジニアと高度なポート研究向け。
