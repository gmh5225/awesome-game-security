SDNX 是一项研究性移植项目，将《睡狗》Xbox 360 零售版通过静态重编译转换为原生 C++，并在搭载自定义 Vulkan 图形栈的 Nintendo Switch 自制软件环境下运行。工作核心是基于 ReXGlue 的二进制提升，将 default.xex 转为 AArch64，并配合原生渲染器解析 Xenos GPU 命令流，而非模拟原始 GPU。着色器微码借助 XenosRecomp 与 DXC 预先翻译为 HLSL 与 SPIR-V；Python 与 C++ 工具链则用于解析归档、纹理、着色器容器，并自动化基准测试与 Switch 构建。主要语言为 C++ 与 Python，通过 CMake 驱动 Switch 与桌面目标，依赖 devkitA64、libnx 与 Mesa NVK。面向逆向工程师与高级移植研究者，用于研究 Xbox 360 可执行文件、专有 UE3 时代资产，以及在资源受限主机上替换底层图形管线。
