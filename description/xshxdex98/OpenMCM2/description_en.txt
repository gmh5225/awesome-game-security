OpenMCM2 is a native rebuild of Motocross Madness 2 that disassembles the retail Windows executable, relinks it with a custom harness, and runs with new code linked alongside the original game image while preserving retail sections byte for byte. Most of the added runtime is written in C, including an OpenGL implementation of DirectDraw 7 and Direct3D 7 without wrapper DLLs or injection, plus Python build scripts and Ghidra Java exporters for function recovery, assembly, linking, and verification. The workflow targets a fixed-base MSVC 6.0 PE32 binary, maps RTTI and recovered functions, and lets individual routines be replaced with ported C that must match retail behavior aside from deliberate redirects. Portable settings live in JSON beside the game, and optional DirectDraw tracing helps compare calls against the original renderer. It is aimed at reverse engineers and game preservation researchers who want a measured decompilation pipeline for legacy protected PC titles rather than operational anti-cheat tooling.
