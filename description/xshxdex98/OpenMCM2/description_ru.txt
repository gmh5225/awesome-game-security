OpenMCM2 — нативная пересборка Motocross Madness 2: дизасsemblирует retail Windows-исполняемый файл, перелинковывает его с пользовательским harness и запускается с новым кодом рядом с оригинальным образом игры, сохраняя retail-секции побайтно. Большая часть добавленного runtime написана на C, включая реализацию DirectDraw 7 и Direct3D 7 на OpenGL без wrapper-DLL и инъекций, а также Python-скрипты сборки и Java-экспортеры Ghidra для восстановления функций, ассемблирования, линковки и проверки. Рабочий процесс ориентирован на PE32-бинарник MSVC 6.0 с фиксированной базой, отображает RTTI и восстановленные функции и позволяет заменять отдельные процедуры перенесённым C, который должен совпадать с retail-поведением, кроме намеренных перенаправлений. Переносимые настройки хранятся в JSON рядом с игрой, опциональная трассировка DirectDraw помогает сравнивать вызовы с исходным рендерером. Проект для reverse-инженеров и исследователей сохранения игр, которым нужен измеримый pipeline декомпиляции для защищённых legacy PC-тайтлов, а не операционные anti-cheat инструменты.
