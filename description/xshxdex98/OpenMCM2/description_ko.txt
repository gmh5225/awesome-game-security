OpenMCM2는 Motocross Madness 2의 네이티브 재구축으로, 소매용 Windows 실행 파일을 디스어셈블하고 사용자 정의 harness로 다시 링크한 뒤, 소매용 이미지의 섹션을 바이트 단위로 보존하면서 원본 게임 이미지와 함께 새 코드를 실행한다. 추가된 런타임 대부분은 C로 작성되며, 래퍼 DLL이나 주입 없이 DirectDraw 7과 Direct3D 7을 OpenGL로 구현하고, 함수 복구·어셈블·링크·검증을 위한 Python 빌드 스크립트와 Ghidra Java 익스포터를 포함한다. 워크플로는 고정 베이스 MSVC 6.0 PE32 바이너리를 대상으로 RTTI와 복구된 함수를 매핑하며, 의도적 리다이렉트를 제외하고는 소매판 동작과 일치해야 하는 이식 C로 개별 루틴을 교체할 수 있다. 휴대용 설정은 게임 옆 JSON에 두고, 선택적 DirectDraw 추적으로 원래 렌더러와의 호출을 비교할 수 있다. 운영용 안티치트 도구가 아니라, 보호된 레거시 PC 타이틀에 대해 측정 가능한 디컴파일 파이프라인을 원하는 리버스 엔지니어와 게임 보존 연구자를 위한 프로젝트이다.
