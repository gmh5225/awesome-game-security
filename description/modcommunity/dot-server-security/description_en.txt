A Godot addon that hardens dedicated multiplayer servers through a unified, configuration-driven security rule engine. Written in GDScript, it applies sliding-window rate limits and escalation ladders (warn, gag, mute, kick, ban) across chat, connections, authentication, the remote console, and server-side anti-cheat detections. Server-side anti-cheat distinguishes mathematically impossible claims from merely suspicious behavior, supports movement re-simulation hooks, and can merge external ban feeds with multiple authentication modes. It ships in dry-run mode by default and integrates optionally with companion dot-* addons for moderation and chat, targeting operators who want configurable guardrails rather than hard-coded anti-abuse logic.
