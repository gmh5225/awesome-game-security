Godot 애드온으로, 통합된 설정 기반 보안 규칙 엔진을 통해 전용 멀티플레이어 서버를 강화합니다. GDScript로 작성되었으며, 채팅·연결·인증·원격 콘솔·서버 측 안티치트 감지 전반에 걸쳐 슬라이딩 윈도우 속도 제한과 단계적 제재(경고, 채팅 차단, 음소거, 추방, 밴)를 적용합니다. 서버 측 안티치트는 수학적으로 불가능한 주장과 단순히 의심스러운 행동을 구분하고, 이동 재시뮬레이션 hook을 지원하며, 여러 인증 모드와 외부 밴 피드를 병합할 수 있습니다. 기본적으로 dry-run 모드로 제공되며, 관리 및 채팅용 dot-* 동반 애드온과의 선택적 통합을 지원해, 하드코딩된 남용 방지 로직보다 구성 가능한 가드레일을 원하는 운영자를 대상으로 합니다.
