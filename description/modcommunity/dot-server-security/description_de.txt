Godot-Add-on, das dedizierte Multiplayer-Server durch eine einheitliche, konfigurationsgesteuerte Sicherheitsregel-Engine absichert. In GDScript geschrieben, wendet es gleitende Fenster-Ratenbegrenzungen und Eskalationsstufen (warnen, gag, mute, kick, ban) für Chat, Verbindungen, Authentifizierung, Remote-Konsole und serverseitige Anti-Cheat-Erkennung an. Serverseitiges Anti-Cheat unterscheidet mathematisch unmögliche Behauptungen von lediglich verdächtigem Verhalten, unterstützt Bewegungs-Re-Simulations-Hooks und kann externe Ban-Feeds mit mehreren Authentifizierungsmodi zusammenführen. Standardmäßig im Dry-Run-Modus, optional integrierbar mit begleitenden dot-*-Add-ons für Moderation und Chat – für Betreiber, die konfigurierbare Leitplanken statt hart codierter Anti-Missbrauchs-Logik wünschen.
