Godot 向けアドオンで、統合された設定駆動型のセキュリティルールエンジンにより専用マルチプレイヤーサーバーを強化します。GDScript で記述され、チャット、接続、認証、リモートコンソール、サーバー側アンチチート検出にわたり、スライディングウィンドウのレート制限と段階的エスカレーション（警告、ギャグ、ミュート、キック、BAN）を適用します。サーバー側アンチチートは数学的に不可能な主張と単に疑わしい挙動を区別し、移動の再シミュレーションフックをサポートし、複数の認証モードと外部 BAN フィードを統合できます。既定では dry-run モードで提供され、モデレーションとチャット用の dot-* 系コンパニオンアドオンとのオプション連携に対応し、ハードコードされた乱用対策ではなく設定可能なガードレールを求める運用者を対象としています。
