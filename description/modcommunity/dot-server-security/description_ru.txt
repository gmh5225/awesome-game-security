Дополнение для Godot, которое усиливает выделенные многопользовательские серверы с помощью единого управляемого конфигурацией движка правил безопасности. Написано на GDScript, применяет ограничения скорости со скользящим окном и лестницы эскалации (предупреждение, gag, mute, kick, ban) в чате, подключениях, аутентификации, удалённой консоли и серверных античит-проверках. Серверный античит отличает математически невозможные заявления от просто подозрительного поведения, поддерживает хуки повторной симуляции движения и может объединять внешние фиды банов с несколькими режимами аутентификации. По умолчанию поставляется в режиме dry-run и опционально интегрируется с сопутствующими дополнениями dot-* для модерации и чата — для операторов, которым нужны настраиваемые ограничители, а не жёстко прописанная логика против злоупотреблений.
