Add-on per Godot che irrobustisce i server multigiocatore dedicati tramite un motore unificato di regole di sicurezza guidato dalla configurazione. Scritto in GDScript, applica limiti di frequenza a finestra scorrevole e scale di escalation (avviso, gag, mute, kick, ban) su chat, connessioni, autenticazione, console remota e rilevamenti anti-cheat lato server. L'anti-cheat lato server distingue affermazioni matematicamente impossibili da comportamenti semplicemente sospetti, supporta hook di re-simulazione del movimento e può unire feed di ban esterni con più modalità di autenticazione. Viene fornito in modalità dry-run per impostazione predefinita e si integra opzionalmente con add-on companion dot-* per moderazione e chat, rivolto agli operatori che vogliono barriere configurabili anziché logica anti-abuso hard-coded.
