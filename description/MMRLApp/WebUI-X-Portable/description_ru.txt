WebUI X Portable — автономное Android-приложение, которое размещает HTML- и JavaScript-интерфейсы WebUI для root-модулей MMRL, позволяя пользователям настраивать и взаимодействовать с Magisk, KernelSU и связанными модулями без установки полного менеджера MMRL. Написано в основном на Kotlin с Jetpack Compose, встраивает движок HybridWebUI и предоставляет JavaScript-мост для выполнения root shell, доступа к файловой системе и метаданным модулей, а также встроенные инструменты разработчика, импортеры модулей и редакторы конфигурации. Поддерживает несколько root-фреймворков, включая Magisk, KernelSU, KernelSU Next, APatch и SukiSU, а также переносимый режим без root и опциональные маскированные сборки, которые рандомизируют имена пакета и приложения. Предназначено для Android-моддеров и разработчиков root-модулей, которым нужна легковесная WebUI-среда для инструментов модулей, включая случаи, когда маскировка хост-приложения помогает избежать обнаружения другим ПО.
