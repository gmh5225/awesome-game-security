WebUI X Portable은 MMRL 루트 모듈용 HTML 및 JavaScript WebUI 인터페이스를 호스팅하는 독립형 Android 애플리케이션으로, 전체 MMRL 매니저를 설치하지 않고도 Magisk, KernelSU 및 관련 모듈을 구성하고 상호작용할 수 있습니다. 주로 Kotlin과 Jetpack Compose로 작성되었으며 HybridWebUI 엔진을 내장하고, 루트 셸 실행, 파일 시스템 접근, 모듈 메타데이터를 위한 JavaScript 브리지를 제공합니다. 내장 개발자 도구, 모듈 가져오기 도구, 구성 편집기도 포함합니다. Magisk, KernelSU, KernelSU Next, APatch, SukiSU 등 여러 루트 프레임워크를 지원하며, 비루트 휴대용 모드와 패키지 및 앱 이름을 무작위화하는 선택적 위장 빌드도 제공합니다. 모듈 도구용 경량 WebUI 런타임이 필요한 Android 모더와 루트 모듈 개발자를 대상으로 하며, 호스트 앱을 위장해 다른 소프트웨어의 탐지를 피해야 하는 사용 사례에도 적합합니다.
