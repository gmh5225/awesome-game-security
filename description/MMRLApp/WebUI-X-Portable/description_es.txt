WebUI X Portable es una aplicación Android independiente que aloja interfaces WebUI en HTML y JavaScript para módulos root de MMRL, permitiendo a los usuarios configurar e interactuar con Magisk, KernelSU y módulos relacionados sin instalar el gestor MMRL completo. Escrita principalmente en Kotlin con Jetpack Compose, incorpora un motor HybridWebUI y expone un puente JavaScript para la ejecución de shell root, el acceso al sistema de archivos y los metadatos de módulos, junto con herramientas de desarrollo integradas, importadores de módulos y editores de configuración. Admite múltiples frameworks root, incluidos Magisk, KernelSU, KernelSU Next, APatch y SukiSU, además de un modo portable sin root y compilaciones camufladas opcionales que aleatorizan los nombres de paquete y de aplicación. Está dirigida a modders de Android y desarrolladores de módulos root que necesitan un runtime WebUI ligero para herramientas de módulos, incluidos casos de uso en los que disfrazar la aplicación anfitriona ayuda a evitar la detección por parte de otro software.
