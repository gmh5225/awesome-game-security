WebUI X Portable は、MMRL ルートモジュール向けの HTML および JavaScript WebUI インターフェースをホストするスタンドアロンの Android アプリで、フル版 MMRL マネージャーをインストールせずに Magisk、KernelSU、関連モジュールの設定や操作ができます。主に Kotlin と Jetpack Compose で書かれ、HybridWebUI エンジンを内蔵し、ルートシェル実行、ファイルシステムアクセス、モジュールメタデータ取得のための JavaScript ブリッジを提供します。開発者ツール、モジュールインポーター、設定エディターも内蔵しています。Magisk、KernelSU、KernelSU Next、APatch、SukiSU など複数のルートフレームワークに対応し、非ルートのポータブルモードや、パッケージ名とアプリ名をランダム化するオプションの偽装ビルドも利用できます。モジュールツール向けの軽量 WebUI ランタイムを必要とする Android 改造者やルートモジュール開発者向けで、ホストアプリを偽装して他ソフトによる検出を回避したい用途にも適しています。
