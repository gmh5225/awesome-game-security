Grembyte は、Linux、Windows、および Wine や Proton 上で動く Windows タイトルの実行中ゲームのメモリを調査・操作するためのデスクトップアプリケーションです。主に Python と PySide6 UI で構築され、Frida ベースの JavaScript を対象プロセスに注入してライブメモリ作業を行います。主な機能には、値のスキャンとフリーズ、ポインタスキャン、読み書きウォッチ、メモリ書き込みへの JavaScript フック、スケジュールスクリプト、ヘッドレス CLI 起動モード、ネイティブトレースと関数監視が含まれます。Unity Mono と IL2CPP、Unreal Engine 向けのエンジン固有ツール（クラス・メソッドカタログ、オブジェクト検査、メソッドフック、GAS 属性ビューなど）も備えています。本プロジェクトは教育、セキュリティ研究、シングルプレイの mod 制作を目的としており、オンライン対戦やアンチチート回避を想定していません。
