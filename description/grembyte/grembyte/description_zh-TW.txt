Grembyte 是一款桌面應用程式，用於在 Linux、Windows 以及透過 Wine 或 Proton 執行的 Windows 遊戲上檢視並操作執行中程序的記憶體。它主要以 Python 與 PySide6 介面建置，並向目標程序注入基於 Frida 的 JavaScript，以進行即時記憶體作業。核心功能包含數值掃描與凍結、指標掃描、讀寫監視、對記憶體寫入的 JavaScript 鉤子、排程腳本、無介面 CLI 啟動模式，以及原生追蹤與函式監控。它還針對 Unity Mono 與 IL2CPP、以及 Unreal Engine 提供引擎專用工具，例如類別與方法目錄、物件檢視、方法鉤子與 GAS 屬性檢視。本專案面向教育用途、安全研究與單機模組開發，而非線上對戰或規避反作弊。
