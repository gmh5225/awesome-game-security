Grembyte is a desktop application for inspecting and manipulating the memory of running games on Linux, Windows, and Windows titles under Wine or Proton. It is built primarily in Python with a PySide6 UI and injects Frida-based JavaScript into target processes for live memory work. Core capabilities include value scanning and freezing, pointer scans, read and write watch, JavaScript hooks on memory writes, scheduled scripts, a headless CLI launch mode, and native tracing and function monitoring. It adds engine-specific tooling for Unity Mono and IL2CPP and for Unreal Engine, such as class and method catalogs, object inspection, method hooks, and GAS attribute views. The project is aimed at educational use, security research, and single-player modding rather than online play or anti-cheat evasion.
