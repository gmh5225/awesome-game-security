Grembyte — настольное приложение для просмотра и изменения памяти запущенных игр в Linux, Windows и Windows-игр под Wine или Proton. Оно в основном написано на Python с интерфейсом PySide6 и внедряет JavaScript на базе Frida в целевые процессы для работы с памятью в реальном времени. Основные возможности включают поиск и заморозку значений, сканирование указателей, наблюдение за чтением и записью, JavaScript-хуки на запись в память, запланированные скрипты, headless-режим запуска через CLI, а также нативную трассировку и мониторинг функций. Добавлены инструменты под движки для Unity Mono и IL2CPP и для Unreal Engine: каталоги классов и методов, инспекция объектов, хуки методов и представления атрибутов GAS. Проект предназначен для обучения, исследований в области безопасности и одиночного моддинга, а не для онлайн-игры или обхода античита.
