Grembyte는 Linux, Windows, 그리고 Wine 또는 Proton에서 실행되는 Windows 게임의 실행 중 메모리를 검사하고 조작하는 데스크톱 애플리케이션입니다. 주로 Python과 PySide6 UI로 구축되며, Frida 기반 JavaScript를 대상 프로세스에 주입해 실시간 메모리 작업을 수행합니다. 핵심 기능으로는 값 스캔 및 고정, 포인터 스캔, 읽기·쓰기 감시, 메모리 쓰기에 대한 JavaScript 훅, 예약 스크립트, 헤드리스 CLI 실행 모드, 네이티브 추적 및 함수 모니터링이 있습니다. Unity Mono·IL2CPP와 Unreal Engine을 위한 엔진별 도구(클래스·메서드 카탈로그, 객체 검사, 메서드 훅, GAS 속성 뷰 등)도 제공합니다. 이 프로젝트는 교육, 보안 연구, 싱글플레이 모딩을 목표로 하며, 온라인 플레이나 안티치트 회피용이 아닙니다.
