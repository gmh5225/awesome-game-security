Grembyte est une application de bureau pour inspecter et manipuler la mémoire de jeux en cours d'exécution sous Linux, Windows, et les titres Windows via Wine ou Proton. Elle est principalement développée en Python avec une interface PySide6 et injecte du JavaScript basé sur Frida dans les processus cibles pour le travail mémoire en direct. Les capacités principales incluent la recherche et le gel de valeurs, les scans de pointeurs, la surveillance des lectures et écritures, des hooks JavaScript sur les écritures mémoire, des scripts planifiés, un mode de lancement CLI sans interface, ainsi que le traçage natif et la surveillance de fonctions. Il ajoute des outils spécifiques aux moteurs pour Unity Mono et IL2CPP et pour Unreal Engine, tels que catalogues de classes et méthodes, inspection d'objets, hooks de méthodes et vues d'attributs GAS. Le projet vise un usage éducatif, la recherche en sécurité et le modding solo plutôt que le jeu en ligne ou le contournement d'anti-triche.
