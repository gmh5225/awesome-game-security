LSPFRIDA 是一个 LSPosed Android 模块，可将 Frida GumJS 脚本引擎直接嵌入目标应用进程，支持在设备上编写、执行和调试 Frida 脚本，无需 frida-server、ADB 或连接的 PC。它将静态链接的基于 QuickJS 的 GumJS 运行时与通过 libxposed 实现的 LSPlant 钩子相结合，提供与 frida-java-bridge 兼容的 API（如 Java.perform 和 Java.use），用于方法拦截、参数改写和返回值覆盖。该模块支持在 Application.onCreate 之前进行早期注入、带超时回退的类加载器感知钩子注册、通过 IPC 热重载脚本以及持久化日志，所有功能均由带有 Miuix Compose UI 和内置语法高亮脚本编辑器的 Kotlin 宿主应用管理。项目采用 Kotlin 和 C++ 开发，面向 arm64 Android 8.0+ 设备，需 Magisk 或类似 root 方案及 LSPosed 2.1.1+，供移动逆向工程师和安全研究人员对 Android 应用与游戏进行动态分析与插桩。
