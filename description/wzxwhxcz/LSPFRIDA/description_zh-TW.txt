LSPFRIDA 是一個 LSPosed Android 模組，可將 Frida GumJS 腳本引擎直接嵌入目標應用程式程序，支援在裝置上編寫、執行和偵錯 Frida 腳本，無需 frida-server、ADB 或連接的 PC。它將靜態連結的基於 QuickJS 的 GumJS 執行階段與透過 libxposed 實現的 LSPlant 鉤子相結合，提供與 frida-java-bridge 相容的 API（如 Java.perform 和 Java.use），用於方法攔截、參數改寫和回傳值覆寫。該模組支援在 Application.onCreate 之前進行早期注入、帶逾時回退的類別載入器感知鉤子註冊、透過 IPC 熱重載腳本以及持久化日誌，所有功能均由帶有 Miuix Compose UI 和內建語法高亮腳本編輯器的 Kotlin 宿主應用程式管理。專案採用 Kotlin 和 C++ 開發，面向 arm64 Android 8.0+ 裝置，需 Magisk 或類似 root 方案及 LSPosed 2.1.1+，供行動逆向工程師和安全研究人員對 Android 應用程式與遊戲進行動態分析與插樁。
