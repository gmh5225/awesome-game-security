LSPFRIDA è un modulo Android LSPosed che integra direttamente un motore di script Frida GumJS nei processi delle applicazioni target, consentendo di scrivere, eseguire e debuggare script Frida sul dispositivo senza frida-server, ADB o un PC connesso. Abbina un runtime GumJS basato su QuickJS collegato staticamente all'hooking LSPlant tramite libxposed, esponendo API compatibili con frida-java-bridge come Java.perform e Java.use per l'intercettazione di metodi, la riscrittura dei parametri e la sostituzione dei valori di ritorno. Il modulo supporta l'iniezione anticipata prima di Application.onCreate, la registrazione di hook consapevole del class loader con fallback su timeout, il ricaricamento a caldo degli script via IPC e il logging persistente, il tutto gestito da un'app host Kotlin con UI Miuix Compose e un editor di script integrato con evidenziazione della sintassi. Sviluppato in Kotlin e C++ per dispositivi arm64 Android 8.0+ con Magisk o root simile e LSPosed 2.1.1+, è rivolto a reverse engineer mobile e ricercatori di sicurezza per l'analisi dinamica e l'instrumentazione di app e giochi Android.
