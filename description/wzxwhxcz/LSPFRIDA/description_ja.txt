LSPFRIDA は LSPosed Android モジュールで、Frida GumJS スクリプトエンジンをターゲットアプリのプロセスに直接組み込み、frida-server、ADB、接続 PC なしでデバイス上での Frida スクリプトの作成・実行・デバッグを可能にします。静的リンクされた QuickJS ベースの GumJS ランタイムと libxposed 経由の LSPlant フックを組み合わせ、Java.perform や Java.use など frida-java-bridge 互換 API によりメソッドフック、引数の書き換え、戻り値の上書きを提供します。Application.onCreate 前の早期注入、クラスローダー対応フック登録とタイムアウトフォールバック、IPC によるホットリロード、永続ログなどをサポートし、Miuix Compose UI と構文ハイライト付きスクリプトエディタを備えた Kotlin ホストアプリから管理します。Kotlin と C++ で arm64 Android 8.0+ 向けに構築され、Magisk 等の root と LSPosed 2.1.1+ が必要で、Android アプリやゲームの動的解析・インストルメンテーションを行うモバイルリバースエンジニアやセキュリティ研究者向けです。
