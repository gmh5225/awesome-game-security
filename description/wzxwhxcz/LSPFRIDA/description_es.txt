LSPFRIDA es un módulo Android LSPosed que integra un motor de scripts Frida GumJS directamente en los procesos de las aplicaciones objetivo, permitiendo escribir, ejecutar y depurar scripts Frida en el dispositivo sin frida-server, ADB ni un PC conectado. Combina un runtime GumJS basado en QuickJS enlazado estáticamente con hooking LSPlant a través de libxposed, exponiendo APIs compatibles con frida-java-bridge como Java.perform y Java.use para interceptar métodos, reescribir parámetros y sobrescribir valores de retorno. El módulo admite inyección temprana antes de Application.onCreate, registro de hooks consciente del class loader con respaldo por timeout, recarga en caliente de scripts vía IPC y registro persistente, todo gestionado desde una app host en Kotlin con UI Miuix Compose y un editor de scripts integrado con resaltado de sintaxis. Desarrollado en Kotlin y C++ para dispositivos arm64 Android 8.0+ con Magisk o root similar y LSPosed 2.1.1+, está dirigido a ingenieros de ingeniería inversa móvil e investigadores de seguridad que realizan análisis dinámico e instrumentación de apps y juegos Android.
