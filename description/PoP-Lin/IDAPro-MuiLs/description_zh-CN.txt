IDAPro-MuiLs 是一款 IDAPython 插件，为 IDA Pro 9.3 提供克制而现代的深色主题，同时保留原生工作区行为。它以 Python 与 PySide6 实现，通过作用域化的 Qt 样式表，重新美化菜单、工具栏、停靠窗口、对话框、选择器、图形视图、滚动条以及兼容的第三方插件面板。主要特性包括自动启动与持久化设置、在 Functions、Names 和 Strings 视图中连续圆润的行选择、可自定义字体、强调色、密度和圆角并支持实时预览，以及在 Windows 上平滑调整窗口大小并集成深色标题栏。该插件面向 Windows 11 逆向工程工作流，适合希望在不影响核心反汇编与导航行为的前提下，获得更简洁、更易读的 IDA 界面的分析人员。
