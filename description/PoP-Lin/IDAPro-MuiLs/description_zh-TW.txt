IDAPro-MuiLs 是一款 IDAPython 外掛，為 IDA Pro 9.3 提供克制而現代的深色主題，同時保留原生工作區行為。它以 Python 與 PySide6 實作，透過作用域化的 Qt 樣式表，重新美化選單、工具列、停靠視窗、對話框、選擇器、圖形檢視、捲軸以及相容的第三方外掛面板。主要功能包括自動啟動與持久化設定、在 Functions、Names 和 Strings 檢視中連續圓角的列選取、可自訂字型、強調色、密度和圓角並支援即時預覽，以及在 Windows 上平滑調整視窗大小並整合深色標題列。此外掛面向 Windows 11 逆向工程工作流程，適合希望在不妨礙核心反組譯與導航行為的前提下，獲得更簡潔、更易讀的 IDA 介面的分析人員。
