Chess King은 랭크 및 캐주얼 매치메이킹, WebSocket 기반 실시간 대국, 지갑·상점·인벤토리·선물을 아우르는 통합 가상 경제를 갖춘 풀스택 멀티플레이어 체스 플랫폼입니다. Axum, SQLx, SQLite 위에 구축된 Rust 백엔드는 위험 점수 산정, 밴 에스컬레이션, 디바이스 지문, 대국 무결성 검사, IP 평판 추적, 체스 테마 CAPTCHA 단계적 인증을 포함한 다층 안티치트 시스템을 구현합니다. React와 Vite 프론트엔드가 플레이어 경험을 제공하고, 관리자 보안 대시보드는 위험 등급, 보안 이벤트, 검토 대기 큐를 모니터링합니다. 코드베이스에는 애플리케이션 수준 방화벽, 속도 제한, JWT 인증, 프로브 차단, 구조화된 보안 로깅이 문서화되어 있으며, shakmaty 체스 엔진을 통한 수 검증도 통합되어 있습니다. 온라인 경쟁 게임에서 안티치트 및 계정 남용 방어를 설계·구현·감사하는 교육용 참고 자료로 활용할 수 있습니다.
