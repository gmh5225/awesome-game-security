Chess King 是一個全棧多人在線西洋棋平台，提供排位與休閒配對、基於 WebSocket 的即時對局，以及整合的虛擬經濟系統，涵蓋錢包、商店、庫存與禮物功能。以 Axum、SQLx 與 SQLite 建構的 Rust 後端實作了分層反作弊機制，包含風險評分、封禁升級、裝置指紋、對局完整性檢查、IP 信譽追蹤，以及西洋棋主題 CAPTCHA 階梯式身分驗證。React 與 Vite 前端提供玩家體驗，管理端安全儀表板則監控風險等級、安全事件與待審核佇列。程式碼庫亦記錄了應用層防火牆、速率限制、JWT 驗證、探測阻擋與結構化安全日誌，並整合 shakmaty 西洋棋引擎用於走法驗證。此專案可作為設計、實作與稽核線上競技遊戲中反作弊與帳號濫用防護的教育參考。
