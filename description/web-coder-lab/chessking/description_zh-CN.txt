Chess King 是一个全栈多人在线国际象棋平台，提供排位与休闲匹配、基于 WebSocket 的实时对局，以及集成的虚拟经济系统，涵盖钱包、商店、库存与礼物功能。基于 Axum、SQLx 和 SQLite 构建的 Rust 后端实现了分层反作弊体系，包括风险评分、封禁升级、设备指纹、对局完整性校验、IP 信誉追踪以及象棋主题 CAPTCHA 阶梯式身份验证。React 与 Vite 前端承载玩家体验，管理端安全仪表板则监控风险等级、安全事件与待审核队列。代码库还记录了应用层防火墙、速率限制、JWT 认证、探测拦截与结构化安全日志，并集成 shakmaty 国际象棋引擎用于走法校验。该项目可作为设计、实现与审计在线竞技游戏中反作弊与账号滥用防护的教育参考。
