Chess King es una plataforma de ajedrez multijugador full-stack con emparejamiento clasificado y casual, partidas en tiempo real mediante WebSocket y una economía virtual integrada para monederos, tiendas, inventario y regalos. El backend en Rust construido con Axum, SQLx y SQLite implementa un sistema antitrampas multicapa con puntuación de riesgo, escalado de baneos, huella digital de dispositivos, comprobaciones de integridad de partidas, seguimiento de reputación IP y autenticación CAPTCHA temática de ajedrez con step-up. Un frontend con React y Vite ofrece la experiencia del jugador, mientras un panel de seguridad de administración monitoriza niveles de riesgo, eventos de seguridad y colas de revisión pendientes. La base de código también documenta firewall a nivel de aplicación, limitación de tasa, autenticación JWT, bloqueo de sondas y registro estructurado de seguridad, junto con el motor de ajedrez shakmaty para la validación de movimientos. Sirve como referencia educativa para diseñar, implementar y auditar defensas antitrampas y contra abuso de cuentas en juegos competitivos en línea.
