Level Hash is a Geode mod for Geometry Dash that computes a cryptographic fingerprint of a level’s serialized data so players and reviewers can compare levels for tampering. It hashes the level string with SHA-256 and shows the digest in-game from a button on the level info screen, using C++23 against the Geode SDK. The mod targets cheat detection and integrity checks in the community, especially spotting hidden edits such as Level Edit or undisclosed nerfs to published levels. It depends on other Geode mods for level data access and ships as a shared library built with CMake for Windows, macOS, iOS, and Android Geometry Dash builds.
