Level Hash は Geometry Dash 向けの Geode モッドで、レベルのシリアル化データから暗号学的フィンガープリントを算出し、プレイヤーやレビュアーが改ざんの有無を比較できるようにします。レベル文字列を SHA-256 でハッシュし、レベル情報画面のボタンからゲーム内でダイジェストを表示します。Geode SDK 上で C++23 を使用しています。コミュニティにおけるチート検出と整合性確認を目的とし、Level Edit などの隠れた編集や、公開済みレベルの未公表のナーフを見つける用途に特化しています。レベルデータへのアクセスには他の Geode モッドに依存し、CMake で Windows、macOS、iOS、Android 向け Geometry Dash ビルド用の共有ライブラリとして提供されます。
