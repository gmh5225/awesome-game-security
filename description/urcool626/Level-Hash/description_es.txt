Level Hash es un mod de Geode para Geometry Dash que calcula una huella criptográfica de los datos serializados de un nivel, para que jugadores y revisores puedan comparar niveles y detectar manipulaciones. Aplica SHA-256 a la cadena del nivel y muestra el resumen dentro del juego desde un botón en la pantalla de información del nivel, usando C++23 con el Geode SDK. El mod está orientado a la detección de trampas y comprobaciones de integridad en la comunidad, sobre todo para detectar ediciones ocultas como Level Edit o nerfs no declarados en niveles publicados. Depende de otros mods de Geode para acceder a los datos del nivel y se distribuye como biblioteca compartida compilada con CMake para builds de Geometry Dash en Windows, macOS, iOS y Android.
