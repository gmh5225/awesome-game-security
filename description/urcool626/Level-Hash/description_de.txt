Level Hash ist ein Geode-Mod für Geometry Dash, der einen kryptografischen Fingerabdruck der serialisierten Leveldaten berechnet, damit Spieler und Prüfer Level auf Manipulation vergleichen können. Er hasht die Level-Zeichenkette mit SHA-256 und zeigt den Digest im Spiel über eine Schaltfläche auf dem Level-Info-Bildschirm an, implementiert in C++23 gegen das Geode SDK. Der Mod zielt auf Cheat-Erkennung und Integritätsprüfungen in der Community ab, insbesondere auf versteckte Änderungen wie Level Edit oder nicht angekündigte Nerfs veröffentlichter Level. Er hängt von anderen Geode-Mods für den Zugriff auf Leveldaten ab und wird als Shared Library mit CMake für Geometry-Dash-Builds unter Windows, macOS, iOS und Android bereitgestellt.
