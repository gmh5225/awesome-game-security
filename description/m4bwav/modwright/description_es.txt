modwright es un complemento de Claude Code y un conjunto de herramientas en Python para modificar juegos de PC de forma controlada y verificable. El script mw.py de la biblioteca estándar escanea instalaciones de juegos para detectar el motor y el entorno de ejecución (Unity Mono o IL2CPP, Unreal, Godot, GameMaker, Source y otros), cargadores de mods instalados y marcadores anti-trampas como Easy Anti-Cheat, BattlEye y Vanguard, deteniéndose con un código de salida dedicado cuando hay anti-trampas en lugar de sugerir inyección o trampas en línea. Realiza copias de seguridad de partidas y archivos objetivo con manifiestos SHA-256 para restauración y verificación, valida que los mods se cargaron realmente analizando registros de BepInEx, MelonLoader, UE4SS y cargadores relacionados, y puede preparar metadatos de empaquetado de Steam Workshop VDF o Thunderstore sin subirlos. El flujo de trabajo enfatiza descompilar antes de nombrar objetivos de parche, modding sin conexión o en un jugador, y automatización repetible para autores de mods y jugadores conscientes de la seguridad que necesitan conocer el motor y el anti-trampas durante el desarrollo legítimo de mods.
