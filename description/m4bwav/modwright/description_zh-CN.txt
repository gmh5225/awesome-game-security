modwright 是一款 Claude Code 插件及 Python 工具包，用于以可控、可验证的方式为 PC 游戏制作模组。标准库脚本 mw.py 会扫描游戏安装，检测引擎与运行时（Unity Mono 或 IL2CPP、Unreal、Godot、GameMaker、Source 等）、已安装的模组加载器，以及 Easy Anti-Cheat、BattlEye、Vanguard 等反作弊标记；若存在反作弊则以专用退出码终止，而非建议注入或在线作弊。它会用 SHA-256 清单备份存档与目标文件以便恢复与校验，通过解析 BepInEx、MelonLoader、UE4SS 及相关加载器日志验证模组是否真正加载，并可准备 Steam Workshop VDF 或 Thunderstore 打包元数据而无需上传。该工作流强调在命名补丁目标前先反编译、离线或单人模组制作，并为模组作者与注重安全的玩家提供可重复的自动化，使其在合法模组开发中了解引擎与反作弊情况。
