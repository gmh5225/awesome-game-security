modwright は、PC ゲームの mod を制御可能かつ検証可能な方法で行うための Claude Code プラグインおよび Python ツールキットです。標準ライブラリの mw.py スクリプトはゲームのインストールをスキャンし、エンジンとランタイム（Unity Mono または IL2CPP、Unreal、Godot、GameMaker、Source など）、インストール済みの mod ローダー、Easy Anti-Cheat、BattlEye、Vanguard などのアンチチート標識を検出し、アンチチートが存在する場合はインジェクションやオンラインチートを提案するのではなく専用の終了コードで停止します。SHA-256 マニフェストでセーブデータと対象ファイルをバックアップして復元と検証を行い、BepInEx、MelonLoader、UE4SS および関連ローダーのログを解析して mod が実際に読み込まれたかを検証し、アップロードなしで Steam Workshop の VDF や Thunderstore のパッケージングメタデータを準備できます。ワークフローはパッチ対象に名前を付ける前のデコンパイル、オフラインまたはシングルプレイの mod 作業、正当な mod 開発中にエンジンとアンチチートを把握する必要がある mod 作者やセキュリティを意識するプレイヤー向けの再現可能な自動化を重視しています。
