modwright 是一款 Claude Code 外掛與 Python 工具包，用於以可控、可驗證的方式為 PC 遊戲製作模組。標準函式庫腳本 mw.py 會掃描遊戲安裝，偵測引擎與執行環境（Unity Mono 或 IL2CPP、Unreal、Godot、GameMaker、Source 等）、已安裝的模組載入器，以及 Easy Anti-Cheat、BattlEye、Vanguard 等反作弊標記；若偵測到反作弊則以專用結束代碼停止，而非建議注入或線上作弊。它會以 SHA-256 清單備份存檔與目標檔案以便還原與驗證，透過解析 BepInEx、MelonLoader、UE4SS 及相關載入器日誌來確認模組是否確實載入，並可準備 Steam Workshop VDF 或 Thunderstore 封裝中繼資料而無需上傳。此工作流程強調在命名修補目標前先反編譯、離線或單人模組製作，並為模組作者與重視安全的玩家提供可重複的自動化，使其在合法模組開發過程中掌握引擎與反作弊狀況。
