本プロジェクトは、Tencent ACE（Anti-Cheat Expert）が Android armeabi-v7a 上の Free Fire 内でどのように動作するかを記録した、リバースエンジニアリング研究レポートおよびツール群です。IDA Pro による逆コンパイルを通じて libanogs.so と libanort.so クライアントライブラリを解析し、APK ハッシュ検証、証明書解析、インラインフックスキャン、自己整合性チェックサムなど、バイトレベルの検出メカニズムを体系化しています。リポジトリには、並列 IDA ワークフロー、文字列復号、検出ロジックの探索、検索可能な SQLite インデックスの構築を支援する Python および JavaScript 自動化が含まれます。主に Python で記述され、シェルラッパーと詳細な Markdown ノートを補助として備え、チート実装や回避手法ではなく、証拠に基づく ACE クライアント挙動の理解を必要とするゲームセキュリティ研究者およびアンチチートエンジニア向けです。
