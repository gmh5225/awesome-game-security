本项目是一份逆向工程研究文档与工具套件，记录腾讯 ACE（Anti-Cheat Expert）在 Android armeabi-v7a 平台 Free Fire 中的运行方式。它通过 IDA Pro 反编译分析 libanogs.so 与 libanort.so 客户端库，梳理 APK 哈希校验、证书解析、内联 Hook 扫描及自完整性校验等字节级检测机制。仓库提供 Python 与 JavaScript 自动化脚本，用于并行 IDA 工作流、字符串解密、检测逻辑挖掘，以及可检索的 SQLite 发现索引。项目以 Python 为主，辅以 Shell 封装与大量 Markdown 笔记，面向需要基于证据了解 ACE 客户端行为的游戏安全研究人员与反作弊工程师，而非提供作弊实现或绕过方案。
