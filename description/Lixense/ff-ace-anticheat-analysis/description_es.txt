Este proyecto es un informe de investigación de ingeniería inversa y un conjunto de herramientas que documenta cómo opera Tencent ACE (Anti-Cheat Expert) dentro de Free Fire en Android armeabi-v7a. Analiza las bibliotecas cliente libanogs.so y libanort.so mediante descompilación con IDA Pro, catalogando mecanismos de detección a nivel de bytes como verificación de hash APK, análisis de certificados, escaneo de hooks inline y checksums de autointegridad. El repositorio incluye automatización en Python y JavaScript para flujos de trabajo paralelos en IDA, descifrado de cadenas, búsqueda de detecciones y un índice SQLite consultable de hallazgos. Escrito principalmente en Python con wrappers de shell y notas extensas en markdown, está dirigido a investigadores de seguridad de juegos e ingenieros de anti-cheat que necesitan una comprensión basada en evidencia del comportamiento del cliente ACE, no a implementaciones de trampas ni bypasses.
