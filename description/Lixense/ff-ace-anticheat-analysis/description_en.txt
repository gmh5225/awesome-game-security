This project is a reverse-engineering research writeup and tooling suite documenting how Tencent ACE (Anti-Cheat Expert) operates inside Free Fire on Android armeabi-v7a. It analyzes the libanogs.so and libanort.so client libraries through IDA Pro decompilation, cataloging byte-level detection mechanisms such as APK hash verification, certificate parsing, inline hook scanning, and self-integrity checksums. The repository includes Python and JavaScript automation for parallel IDA workflows, string decryption, detection hunting, and a searchable SQLite index of findings. Written primarily in Python with supporting shell wrappers and extensive markdown notes, it serves game security researchers and anti-cheat engineers who need evidence-backed insight into ACE client behavior rather than cheat implementations or bypasses.
