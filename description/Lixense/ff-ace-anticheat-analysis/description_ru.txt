Этот проект представляет собой исследовательский отчёт по реверс-инжинирингу и набор инструментов, документирующий работу Tencent ACE (Anti-Cheat Expert) в Free Fire на Android armeabi-v7a. Он анализирует клиентские библиотеки libanogs.so и libanort.so через декомпиляцию в IDA Pro, систематизируя механизмы обнаружения на уровне байтов: проверку хеша APK, разбор сертификатов, сканирование inline-хуков и контрольные суммы самоцелостности. Репозиторий включает автоматизацию на Python и JavaScript для параллельных рабочих процессов в IDA, расшифровки строк, поиска детекций и поискового SQLite-индекса находок. Написан в основном на Python с вспомогательными shell-обёртками и подробными markdown-заметками; предназначен для исследователей игровой безопасности и инженеров античита, которым нужно понимание поведения клиента ACE, основанное на доказательствах, а не реализации читов или обходов.
