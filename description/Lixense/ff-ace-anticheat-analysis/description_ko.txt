이 프로젝트는 Tencent ACE(Anti-Cheat Expert)가 Android armeabi-v7a 환경의 Free Fire에서 어떻게 동작하는지를 기록한 리버스 엔지니어링 연구 보고서 및 도구 모음입니다. IDA Pro 역컴파일을 통해 libanogs.so와 libanort.so 클라이언트 라이브러리를 분석하며, APK 해시 검증, 인증서 파싱, 인라인 후크 스캔, 자체 무결성 체크섬 등 바이트 수준의 탐지 메커니즘을 정리합니다. 저장소에는 병렬 IDA 워크플로, 문자열 복호화, 탐지 로직 추적, 검색 가능한 SQLite 인덱스 구축을 위한 Python 및 JavaScript 자동화가 포함되어 있습니다. 주로 Python으로 작성되었으며 셸 래퍼와 상세한 Markdown 노트를 보조로 제공하며, 치트 구현이나 우회 방법이 아니라 근거 기반의 ACE 클라이언트 동작 이해가 필요한 게임 보안 연구자 및 안티치트 엔지니어를 대상으로 합니다.
