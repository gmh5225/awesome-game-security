本專案是一份逆向工程研究文件與工具套件，記錄騰訊 ACE（Anti-Cheat Expert）在 Android armeabi-v7a 平台 Free Fire 中的運作方式。它透過 IDA Pro 反編譯分析 libanogs.so 與 libanort.so 用戶端函式庫，整理 APK 雜湊驗證、憑證解析、內聯 Hook 掃描及自我完整性校驗等位元組層級的偵測機制。儲存庫提供 Python 與 JavaScript 自動化腳本，用於並行 IDA 工作流程、字串解密、偵測邏輯挖掘，以及可搜尋的 SQLite 發現索引。專案以 Python 為主，輔以 Shell 封裝與大量 Markdown 筆記，面向需要以證據為基礎了解 ACE 用戶端行為的遊戲安全研究人員與反作弊工程師，而非提供作弊實作或繞過方案。
