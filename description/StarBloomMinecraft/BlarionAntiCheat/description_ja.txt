Blarion AntiCheat は、Minecraft Bedrock Edition 向けの behavior pack 型アンチチートシステムで、専用サーバーバックエンドを必要とせずに、マルチプレイヤーワールドを改造クライアント、エクスプロイト、不公平な有利条件から保護します。Bedrock ScriptAPI（Beta）を用いた JavaScript で実装され、戦闘、移動、インベントリ、パケット悪用をカバーする 40 以上のリアルタイム検知モジュールを提供し、fly、killaura、speed、reach、noclip、autoclicker、xray などのチェックを含みます。この pack は違反閾値と処罰の設定、インベントリ検査やプレイヤースキャン用の管理者コマンド、プレイヤーごとの bypass とホワイトリスト対応、外部 WebSocket やプロキシツールとの連携向けの開発者向け /flag API を備えています。サーバー側プラグインが利用できない、または制限があるバニラクライアント、BDS、LiteLoader 環境でクライアント側アンチチートが必要な Bedrock ワールドホストおよび管理者向けです。
