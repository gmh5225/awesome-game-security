Blarion AntiCheat is a behavior pack anti-cheat system for Minecraft Bedrock Edition that protects multiplayer worlds from hacked clients, exploits, and unfair advantages without requiring a dedicated server backend. Written in JavaScript using the Bedrock ScriptAPI (Beta), it provides more than 40 real-time detection modules covering combat, movement, inventory, and packet abuse, including checks for fly, killaura, speed, reach, noclip, autoclicker, and xray. The pack offers configurable violation thresholds and punishments, admin commands for inventory inspection and player scanning, per-player bypass and whitelist support, and a developer-facing /flag API for integration with external WebSocket or proxy tools. It is intended for Bedrock world hosts and administrators who need client-side anti-cheat on vanilla clients, BDS, or LiteLoader environments where server-side plugins are unavailable or limited.
