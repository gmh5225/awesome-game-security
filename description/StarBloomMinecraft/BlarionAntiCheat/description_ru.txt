Blarion AntiCheat — это anti-cheat система на основе behavior pack для Minecraft Bedrock Edition, которая защищает многопользовательские миры от взломанных клиентов, эксплойтов и нечестных преимуществ без необходимости в выделенном серверном бэкенде. Написана на JavaScript с использованием Bedrock ScriptAPI (Beta) и предоставляет более 40 модулей обнаружения в реальном времени, охватывающих бой, передвижение, инвентарь и злоупотребление пакетами, включая проверки на fly, killaura, speed, reach, noclip, autoclicker и xray. Пак предлагает настраиваемые пороги нарушений и наказания, административные команды для проверки инвентаря и сканирования игроков, поддержку bypass и белого списка для отдельных игроков, а также API /flag для разработчиков для интеграции с внешними WebSocket- или proxy-инструментами. Предназначен для хостов и администраторов миров Bedrock, которым нужен клиентский anti-cheat на vanilla-клиентах, BDS или в средах LiteLoader, где серверные плагины недоступны или ограничены.
