Blarion AntiCheat 是一款面向 Minecraft 基岩版的 behavior pack 反作弊系統，可在無需專用伺服器後端的情況下保護多人世界免受作弊用戶端、漏洞利用與不公平優勢的影響。此系統以 JavaScript 撰寫，採用 Bedrock ScriptAPI（Beta），提供 40 多個即時偵測模組，涵蓋戰鬥、移動、物品欄與封包濫用，包括對 fly、killaura、speed、reach、noclip、autoclicker 和 xray 等行為的檢測。此 pack 支援可設定的違規門檻與處罰措施，提供用於物品欄檢查與玩家掃描的管理員指令，支援依玩家設定的 bypass 與白名單，並提供面向開發者的 /flag API，便於與外部 WebSocket 或代理工具整合。適用於需要在原版用戶端、BDS 或 LiteLoader 環境中使用用戶端反作弊、且無法或難以使用伺服器端外掛的基岩版世界服主與管理員。
