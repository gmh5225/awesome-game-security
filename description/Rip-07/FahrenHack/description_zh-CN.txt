FahrenHack 是一款面向 Windows 的开源单机 PC 游戏修改器，将各类作弊功能整合进一款类似游戏主机界面的桌面应用。项目使用 Rust 编写，提供基于 WebView2 的界面，也可通过局域网在浏览器或手机上访问。工具内置现成的游戏配置档，可自动附加到受支持的游戏，并通过引导式校准结合指针扫描、字节特征、内存补丁以及可选的进程内代码洞注入，使修改在重启和不同游戏版本间仍能生效。此外还包含类似 Cheat Engine 的内存扫描器（支持快照与过滤）、全局热键、Steam 游戏库集成，并明确拒绝附加到受反作弊保护的游戏。本项目面向希望在个人电脑上合法进行单机内存编辑、修改器开发与游戏数值逆向实践的玩家与贡献者。
