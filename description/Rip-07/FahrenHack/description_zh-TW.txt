FahrenHack 是一款僅支援 Windows 的開源單機 PC 遊戲修改器，將各類作弊功能整合進一款類似遊戲主機介面的桌面應用程式。專案以 Rust 撰寫，提供基於 WebView2 的介面，亦可透過區域網路在瀏覽器或手機上開啟。工具內建現成的遊戲設定檔，可自動附加至受支援的遊戲，並透過引導式校準搭配指標掃描、位元組特徵、記憶體修補以及可選的行程內程式碼洞注入，使修改在重新啟動與不同遊戲版本間仍能生效。此外還包含類似 Cheat Engine 的記憶體掃描器（支援快照與篩選）、全域熱鍵、Steam 遊戲庫整合，並明確拒絕附加至受反作弊保護的遊戲。本專案面向希望在個人電腦上合法進行單機記憶體編輯、修改器開發與遊戲數值逆向實作的玩家與貢獻者。
