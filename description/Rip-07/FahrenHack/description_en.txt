FahrenHack is an open-source, Windows-only trainer for single-player PC games that bundles cheats in one console-style desktop application. It is built in Rust and serves a WebView2-based interface you can also open in a browser or on a phone over the local network. The tool ships ready-made game profiles, auto-attaches to supported titles, and uses guided calibration with pointer scanning, byte signatures, memory patches, and optional in-process code cave injection so cheats survive restarts across game builds. It also includes a Cheat Engine-style memory scanner with snapshots and filters, global hotkeys, Steam library integration, and explicit refusal to attach to anti-cheat-protected games. The project targets players and contributors who want lawful single-player memory editing, trainer development, and hands-on reverse-engineering of game values on their own machines.
