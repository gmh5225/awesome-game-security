ESP-killer는 The Isle: Evrima 멀티플레이 서버에서 플레이어 이동 패턴만 분석하여 ESP(월핵) 치트 사용자를 탐지하는 서버 측 시스템입니다. Python으로 작성되었으며, 게임 서버 옆에 읽기 전용 에이전트를 배치해 Evrima RCON 프로토콜로 플레이어 위치를 폴링하고, SQLite 저장소와 API 키 관리를 갖춘 FastAPI 백엔드에 스냅샷을 업로드합니다. 백엔드는 벽 너머로 볼 수 있을 때만 설명 가능한 이동(멀리 숨은 플레이어를 향해 직진하거나 비현실적으로 빠르게 도착하는 등)을 표시하고, 자동 밴이 아닌 서버 관리자의 수동 검토를 위한 알림을 보내도록 설계되었습니다. Evrima는 Easy Anti-Cheat가 내장되어 있고 모딩 API를 제공하지 않으므로, 이 도구는 게임 클라이언트에 접촉하지 않습니다. 클린룸 RCON 클라이언트, 재시도 로직이 있는 디스크 업로드 큐, 탐지 파이프라인 테스트용 가짜 RCON 서버 및 이동 시뮬레이터 같은 개발 도구도 포함합니다.
