ESP-killer es un sistema del lado del servidor para detectar posibles tramposos con ESP (wallhack) en servidores multijugador de The Isle: Evrima analizando únicamente los patrones de movimiento de los jugadores. Escrito en Python, despliega un agente de solo lectura junto al servidor de juego que consulta las posiciones de los jugadores mediante el protocolo RCON de Evrima y sube instantáneas a un backend FastAPI con almacenamiento SQLite y gestión de claves API. El backend está diseñado para marcar movimientos que solo tendrían sentido si un jugador pudiera ver a través de las paredes, como dirigirse directamente hacia jugadores ocultos y lejanos o llegar de forma implausiblemente rápida, y para alertar a los administradores del servidor para una revisión humana en lugar de baneos automáticos. Como Evrima incluye Easy Anti-Cheat y no ofrece API de modding, la herramienta nunca toca el cliente del juego. Incluye un cliente RCON desarrollado desde cero, una cola de subida en disco con lógica de reintento y herramientas de desarrollo como un servidor RCON falso y un simulador de movimiento para probar el pipeline de detección.
