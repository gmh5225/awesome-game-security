ESP-killer 是一个服务端系统，仅通过分析玩家移动模式，在 The Isle: Evrima 多人服务器上检测疑似 ESP（透视）作弊者。该工具用 Python 编写，在游戏服务器旁部署只读代理，通过 Evrima RCON 协议轮询玩家位置，并将快照上传至带 SQLite 存储与 API 密钥管理的 FastAPI 后端。后端旨在标记只有玩家能穿墙看见时才合理的移动行为，例如径直朝远处隐藏玩家移动或到达速度明显不合理，并向服务器管理员发出告警以供人工审核，而非自动封禁。由于 Evrima 内置 Easy Anti-Cheat 且不提供模组 API，该工具从不接触游戏客户端。它包含独立实现的 RCON 客户端、带重试逻辑的磁盘上传队列，以及用于测试检测流水线的开发工具，例如模拟 RCON 服务器与移动模拟器。
