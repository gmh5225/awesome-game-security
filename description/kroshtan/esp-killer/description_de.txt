ESP-killer ist ein serverseitiges System zur Erkennung wahrscheinlicher ESP-(Wallhack-)Cheater auf The Isle: Evrima-Mehrspieler-Servern, das ausschließlich die Bewegungsmuster der Spieler analysiert. In Python geschrieben, setzt es einen schreibgeschützten Agenten neben dem Spiele-Server ein, der Spielerpositionen über das Evrima-RCON-Protokoll abfragt und Snapshots an ein FastAPI-Backend mit SQLite-Speicher und API-Schlüsselverwaltung hochlädt. Das Backend ist darauf ausgelegt, Bewegungen zu markieren, die nur Sinn ergeben, wenn ein Spieler durch Wände sehen kann, etwa das direkte Ansteuern entfernter versteckter Spieler oder ein unrealistisch schnelles Ankommen, und Server-Administratoren zur manuellen Prüfung zu alarmieren statt automatische Bans auszusprechen. Da Evrima mit Easy Anti-Cheat ausgeliefert wird und keine Modding-API bietet, greift das Tool nie in den Spiel-Client ein. Es umfasst einen Clean-Room-RCON-Client, eine Upload-Warteschlange auf der Festplatte mit Wiederholungslogik sowie Entwicklungswerkzeuge wie einen Fake-RCON-Server und einen Bewegungssimulator zum Testen der Erkennungspipeline.
