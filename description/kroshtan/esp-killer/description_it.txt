ESP-killer è un sistema lato server per rilevare probabili cheater ESP (wallhack) sui server multigiocatore di The Isle: Evrima analizzando esclusivamente i pattern di movimento dei giocatori. Scritto in Python, dispiega un agente in sola lettura accanto al server di gioco che interroga le posizioni dei giocatori tramite il protocollo RCON di Evrima e carica snapshot su un backend FastAPI con archivio SQLite e gestione delle chiavi API. Il backend è progettato per segnalare movimenti che avrebbero senso solo se un giocatore potesse vedere attraverso i muri, come dirigersi direttamente verso giocatori nascosti e lontani o arrivare in modo implausibilmente veloce, e per avvisare gli amministratori del server per una revisione umana anziché ban automatici. Poiché Evrima include Easy Anti-Cheat e non offre API di modding, lo strumento non tocca mai il client di gioco. Include un client RCON sviluppato from scratch, una coda di upload su disco con logica di retry e strumenti di sviluppo come un server RCON falso e un simulatore di movimento per testare la pipeline di rilevamento.
