ESP-killer は、The Isle: Evrima のマルチプレイサーバーにおいて、プレイヤーの移動パターンのみを分析して ESP（ウォールハック）の疑いがあるチーターを検出するサーバー側システムです。Python で書かれており、ゲームサーバー横に読み取り専用エージェントを配置し、Evrima RCON プロトコルでプレイヤー位置をポーリングし、SQLite ストレージと API キー管理を備えた FastAPI バックエンドにスナップショットをアップロードします。バックエンドは、壁越しに見えないと説明できない移動（遠方の隠れたプレイヤーへ一直線に向かう、到着が非現実的に速いなど）をフラグ付けし、自動 BAN ではなくサーバー管理者に人間による確認のためのアラートを送るよう設計されています。Evrima は Easy Anti-Cheat を同梱しておりモッディング API も提供しないため、このツールはゲームクライアントには一切触れません。クリーンルーム RCON クライアント、リトライロジック付きのディスク上アップロードキュー、検出パイプラインのテスト用の偽 RCON サーバーや移動シミュレーターなどの開発ツールも含まれます。
