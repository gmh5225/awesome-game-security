ESP-killer 是一個伺服器端系統，僅透過分析玩家移動模式，在 The Isle: Evrima 多人伺服器上偵測疑似 ESP（透視）作弊者。此工具以 Python 撰寫，在遊戲伺服器旁部署唯讀代理，透過 Evrima RCON 協定輪詢玩家位置，並將快照上傳至具備 SQLite 儲存與 API 金鑰管理的 FastAPI 後端。後端旨在標記只有玩家能穿牆看見時才合理的移動行為，例如徑直朝遠處隱藏玩家移動或抵達速度明顯不合理，並向伺服器管理員發出告警以供人工審核，而非自動封禁。由於 Evrima 內建 Easy Anti-Cheat 且不提供模組 API，此工具從不接觸遊戲用戶端。它包含獨立實作的 RCON 用戶端、具重試邏輯的磁碟上傳佇列，以及用於測試偵測管線的開發工具，例如模擬 RCON 伺服器與移動模擬器。
