ESP-killer is a server-side system for detecting likely ESP (wallhack) cheaters on The Isle: Evrima multiplayer servers by analyzing player movement patterns alone. Written in Python, it deploys a read-only agent beside the game server that polls player positions through the Evrima RCON protocol and uploads snapshots to a FastAPI backend with SQLite storage and API key management. The backend is designed to flag movement that only makes sense if a player can see through walls, such as heading directly toward distant hidden players or arriving implausibly fast, and to alert server admins for human review rather than automatic bans. Because Evrima ships with Easy Anti-Cheat and offers no modding API, the tool never touches the game client. It includes a clean-room RCON client, an on-disk upload queue with retry logic, and development tools such as a fake RCON server and movement simulator for testing the detection pipeline.
