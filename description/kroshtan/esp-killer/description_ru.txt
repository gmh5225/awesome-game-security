ESP-killer — серверная система для выявления вероятных читеров с ESP (wallhack) на многопользовательских серверах The Isle: Evrima путём анализа только паттернов перемещения игроков. Написана на Python и разворачивает агент только для чтения рядом с игровым сервером, который опрашивает позиции игроков через протокол Evrima RCON и загружает снимки в бэкенд FastAPI с хранилищем SQLite и управлением API-ключами. Бэкенд предназначен для пометки перемещений, которые имеют смысл лишь если игрок может видеть сквозь стены — например, движение напрямую к скрытым игрокам на расстоянии или подозрительно быстрое прибытие — и для оповещения администраторов сервера для ручной проверки, а не автоматических банов. Поскольку Evrima поставляется с Easy Anti-Cheat и не предоставляет API для моддинга, инструмент никогда не затрагивает игровой клиент. В состав входят RCON-клиент, разработанный с нуля, очередь загрузки на диск с логикой повторных попыток, а также инструменты разработки — например, поддельный RCON-сервер и симулятор перемещений для тестирования конвейера обнаружения.
