CallAdmin 是一款面向運行於 ModSharp 框架上的 Counter-Strike 2 伺服器的遊戲內玩家檢舉系統，玩家可透過聊天標記疑似作弊者與違規者，管理員則透過結構化工作流程認領、處理或駁回檢舉。此插件以 C# 撰寫，採模組化插件套件設計，將核心指令與檢舉生命週期邏輯同可選的資料庫及 Discord 通知元件分離，並提供公開 API，供其他伺服器插件訂閱檢舉事件或以程式方式驅動檢舉流程。檢舉資料可持久化至 LiteDB、MySQL 或 PostgreSQL 後端，可選的 Discord 模組會發送 webhook 嵌入訊息，並在檢舉狀態變更時原地更新。系統包含防濫用機制，如冷卻時間、重複偵測、自動關閉計時器及可設定的檢舉原因，並可與遊戲內管理面板整合以執行審核操作。它面向需要輕量、可擴充工具來收集與管理玩家不當行為檢舉（尤其是疑似作弊）的 CS2 伺服器營運者，作為伺服器端遊戲安全與審核工作流程的一部分。
