CallAdmin is an in-game player reporting system for Counter-Strike 2 servers running on the ModSharp framework, letting players flag suspected cheaters and rule-breakers from chat while admins claim, handle, or dismiss reports through a structured workflow. Written in C# as a modular plugin suite, it separates core commands and report lifecycle logic from optional database and Discord notification components, and exposes a public API so other server plugins can subscribe to report events or drive reports programmatically. Reports are persisted with LiteDB, MySQL, or PostgreSQL backends, and an optional Discord module posts webhook embeds that update in place as report status changes. The system includes anti-abuse controls such as cooldowns, duplicate detection, auto-close timers, and configurable report reasons, and can integrate with an in-game admin panel for moderation actions. It is aimed at CS2 server operators who need lightweight, extensible tooling to collect and manage player misconduct reports, especially suspected cheating, as part of server-side game security and moderation.
