CallAdmin è un sistema di segnalazione dei giocatori in-game per server Counter-Strike 2 basati sul framework ModSharp, che consente ai giocatori di segnalare dal chat presunti cheater e trasgressori delle regole, mentre gli amministratori prendono in carico, gestiscono o respingono le segnalazioni tramite un flusso di lavoro strutturato. Scritto in C# come suite di plugin modulari, separa i comandi principali e la logica del ciclo di vita delle segnalazioni dai componenti opzionali di database e notifiche Discord, ed espone un'API pubblica affinché altri plugin del server possano iscriversi agli eventi di segnalazione o gestirle programmaticamente. Le segnalazioni vengono persistite con backend LiteDB, MySQL o PostgreSQL, e un modulo Discord opzionale pubblica embed webhook aggiornati sul posto man mano che cambia lo stato della segnalazione. Il sistema include controlli anti-abuso come cooldown, rilevamento dei duplicati, timer di chiusura automatica e motivi di segnalazione configurabili, e può integrarsi con un pannello di amministrazione in-game per le azioni di moderazione. È rivolto agli operatori di server CS2 che necessitano di strumenti leggeri ed estensibili per raccogliere e gestire segnalazioni di cattiva condotta dei giocatori, in particolare sospetti di cheating, come parte della sicurezza del gioco lato server e della moderazione.
