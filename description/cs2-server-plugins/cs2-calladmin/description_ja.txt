CallAdmin は ModSharp フレームワーク上で動作する Counter-Strike 2 サーバー向けのゲーム内プレイヤー通報システムで、プレイヤーがチャットから不正行為の疑いがあるプレイヤーやルール違反者を通報し、管理者が構造化されたワークフローで通報を引き受け、処理、または却下できます。C# で書かれたモジュール型プラグインスイートとして、コアコマンドと通報ライフサイクルロジックを、オプションのデータベースおよび Discord 通知コンポーネントから分離し、他のサーバープラグインが通報イベントを購読したりプログラムから通報を駆動したりできる公開 API を提供します。通報は LiteDB、MySQL、または PostgreSQL バックエンドに永続化され、オプションの Discord モジュールは webhook 埋め込みを投稿し、通報ステータスの変更に応じてその場で更新します。システムにはクールダウン、重複検出、自動クローズタイマー、設定可能な通報理由などの乱用防止機能が含まれ、ゲーム内管理パネルと連携してモデレーション操作を行えます。CS2 サーバー運営者向けに、特に不正行為の疑いを含むプレイヤーの不正行為通報を収集・管理するための軽量で拡張可能なツールとして、サーバー側のゲームセキュリティとモデレーションの一環を目的としています。
