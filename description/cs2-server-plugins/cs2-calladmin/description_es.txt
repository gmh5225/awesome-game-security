CallAdmin es un sistema de denuncias de jugadores en el juego para servidores de Counter-Strike 2 que ejecutan el framework ModSharp, que permite a los jugadores marcar desde el chat a presuntos tramposos e infractores de las reglas, mientras los administradores reclaman, gestionan o descartan denuncias mediante un flujo de trabajo estructurado. Escrito en C# como una suite de plugins modulares, separa los comandos principales y la lógica del ciclo de vida de las denuncias de los componentes opcionales de base de datos y notificaciones de Discord, y expone una API pública para que otros plugins del servidor se suscriban a eventos de denuncia o las gestionen de forma programática. Las denuncias se persisten con backends LiteDB, MySQL o PostgreSQL, y un módulo opcional de Discord publica embeds de webhook que se actualizan in situ cuando cambia el estado de la denuncia. El sistema incluye controles antiabuso como tiempos de espera, detección de duplicados, temporizadores de cierre automático y motivos de denuncia configurables, y puede integrarse con un panel de administración en el juego para acciones de moderación. Está dirigido a operadores de servidores CS2 que necesitan herramientas ligeras y extensibles para recopilar y gestionar denuncias de mala conducta de jugadores, especialmente trampas sospechadas, como parte de la seguridad del juego y la moderación del lado del servidor.
