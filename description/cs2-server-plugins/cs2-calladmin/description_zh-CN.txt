CallAdmin 是一款面向运行在 ModSharp 框架上的 Counter-Strike 2 服务器的游戏内玩家举报系统，玩家可通过聊天标记疑似作弊者与违规者，管理员则通过结构化工作流认领、处理或驳回举报。该插件以 C# 编写，采用模块化插件套件设计，将核心命令与举报生命周期逻辑同可选的数据库及 Discord 通知组件分离，并提供公开 API，供其他服务器插件订阅举报事件或以编程方式驱动举报流程。举报数据可持久化至 LiteDB、MySQL 或 PostgreSQL 后端，可选的 Discord 模块会发送 webhook 嵌入消息，并在举报状态变更时原地更新。系统包含防滥用机制，如冷却时间、重复检测、自动关闭计时器及可配置的举报原因，并可与游戏内管理面板集成以执行审核操作。它面向需要轻量、可扩展工具来收集与管理玩家不当行为举报（尤其是疑似作弊）的 CS2 服务器运营者，作为服务端游戏安全与审核工作流的一部分。
