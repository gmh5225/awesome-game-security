Phantom Client は、Lunar Client Minecraft 1.8.9 向けの Windows 注入可能な内部 DLL チートで、実行中の JVM にアタッチし、ネイティブコードからゲームを操作します。C++20 で書かれ、JNI と JVMTI を用いて難読化された Minecraft のクラスとフィールドを解決し、MinHook で wglSwapBuffers をフックして Dear ImGui オーバーレイを描画し、kill aura、velocity、fly、speed、ESP、backtrack などの戦闘・移動・視覚モジュールをヘッダーのみのアーキテクチャで整理しています。クライアントは回避志向の設計を重視し、人間らしい CPS タイミングのための専用クリックスケジューラ、キーバインドベースの入力シミュレーション、さまざまなアンチチート環境向けに調整されたサーバー別プロファイルを備えています。Minecraft クライアント注入、JNI フック、難読化クラスの発見、アンチチート回避手法に関するゲームセキュリティ研究に主に有用です。
