Phantom Client는 Lunar Client Minecraft 1.8.9용 Windows 주입 가능 내부 DLL 치트로, 실행 중인 JVM에 부착하여 네이티브 코드로 게임을 조작합니다. C++20으로 작성되었으며 JNI와 JVMTI를 사용해 난독화된 Minecraft 클래스와 필드를 해석하고, MinHook으로 wglSwapBuffers를 후킹하여 Dear ImGui 오버레이를 렌더링하며, kill aura, velocity, fly, speed, ESP, backtrack 같은 전투·이동·시각 모듈을 헤더 전용 아키텍처로 구성합니다. 이 클라이언트는 회피 지향 설계를 강조하며, 사람과 유사한 CPS 타이밍을 위한 전용 클릭 스케줄러, 키 바인딩 기반 입력 시뮬레이션, 다양한 안티치트 환경에 맞춘 서버별 프로필을 제공합니다. Minecraft 클라이언트 주입, JNI 후킹, 난독화 클래스 탐색, 안티치트 우회 기법에 대한 게임 보안 연구에 주로 유용합니다.
