VMProtect Resource Extractor は、VMProtect が暗号化した PE リソーステーブルを特定し、保護キーを導出して、保護された EXE および DLL イメージから埋め込みリソースをダンプします。未保護コピーや固定アドレスは不要です。ディスク上のイメージ向け C++ 静的コマンドライン ツール、Python・Capstone を同梱し命令数上限付きの Unicorn ベース エミュレータ（起動コード実行後にしかリソースが現れるパック済みバイナリ向け）、アンパック後にライブ プロセス メモリを走査する x64dbg プラグインが含まれます。抽出結果は番号付きバイナリ ブロブと、各リソースのタイプ・名前・言語・サイズ・RVA メタデータを載せたマニフェストです。ゲームおよびアプリケーションセキュリティ研究における VMProtect 3.3.x～3.10.x のリソース保護を扱うリバースエンジニアとマルウェア解析者向けです。
