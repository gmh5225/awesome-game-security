VMProtect Resource Extractor находит зашифрованную таблицу PE-ресурсов VMProtect, выводит ключ защиты и извлекает встроенные ресурсы из защищённых образов EXE и DLL без незащищённой копии и фиксированных адресов. В состав входят статическая консольная утилита на C++ для образов на диске, эмулятор на базе Unicorn со встроенными Python и Capstone и лимитами по числу инструкций для упакованных бинарников, у которых ресурсы появляются только после выполнения стартового кода, а также плагин x64dbg, сканирующий память живого процесса после распаковки. Результат — пронумерованные двоичные блоки и манифест с типом, именем, языком, размером и метаданными RVA для каждого ресурса. Инструмент предназначен для реверс-инженеров и аналитиков вредоносного ПО, изучающих защиту ресурсов VMProtect 3.3.x–3.10.x в исследованиях безопасности игр и приложений.
