KozVM은 커널 드라이버 없이 64비트 대상에서 VMProtect 스타일의 anti-virtual-machine 검사에 맞서는 x64dbg 플러그인입니다. C++와 x64dbg 플러그인 SDK, CMake로 구축되며 VMProtect 3.3.1, 3.4.0, 3.5.0용 CPUID 중심 백엔드를 포함하고, 패턴 기반 매칭과 메모리 실행 브레이크포인트로 런타임에 실행 가능 섹션에서 핸들러를 찾습니다. 플러그인은 설정 GUI, DLL 옆 INI 기반 구성, 백엔드 활성화·상태 보고·일시 정지된 세션에 설정 적용을 위한 디버거 명령을 제공합니다. VMProtect로 보호된 바이너리를 x64dbg 안에서 디버깅·분석하면서 CPUID 기반 가상 머신 탐지를 완화해야 하는 리버스 엔지니어와 보안 연구자를 대상으로 합니다.
