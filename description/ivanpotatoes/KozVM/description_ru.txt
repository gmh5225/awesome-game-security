KozVM — плагин для x64dbg, который противодействует анти-VM проверкам в стиле VMProtect в 64-разрядных целях без драйвера ядра. Написан на C++ с использованием SDK плагинов x64dbg и CMake; включает бэкенды с упором на CPUID для VMProtect 3.3.1, 3.4.0 и 3.5.0, которые во время выполнения находят обработчики в исполняемых секциях с помощью сопоставления по шаблонам и точек останова при исполнении в памяти. Плагин предоставляет GUI настроек, конфигурацию INI рядом с DLL и команды отладчика для включения бэкенда, отчёта о состоянии и применения настроек к приостановленной сессии. Он предназначен для реверс-инженеров и исследователей безопасности, которым нужно отлаживать или анализировать бинарники, защищённые VMProtect, в x64dbg, ослабляя обнаружение виртуальной машины на основе CPUID.
