KozVM is an x64dbg plugin that counters VMProtect-style anti-virtual-machine checks in 64-bit targets without a kernel driver. It is built in C++ with the x64dbg plugin SDK and CMake, and ships CPUID-focused backends for VMProtect 3.3.1, 3.4.0, and 3.5.0 that locate handlers at runtime in executable sections using pattern-based matching and memory execute breakpoints. The plugin exposes a settings GUI, INI-based configuration beside the DLL, and debugger commands to arm the backend, report status, and apply settings to a paused session. It is aimed at reverse engineers and security researchers who need to debug or analyze VMProtect-protected binaries inside x64dbg while mitigating CPUID-based virtual-machine detection.
