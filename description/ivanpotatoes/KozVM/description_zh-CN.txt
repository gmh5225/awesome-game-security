KozVM 是一款 x64dbg 插件，可在无需内核驱动的情况下，针对 64 位目标对抗 VMProtect 风格的反虚拟机检测。该插件使用 C++ 编写，基于 x64dbg 插件 SDK 与 CMake 构建，并针对 VMProtect 3.3.1、3.4.0 与 3.5.0 提供以 CPUID 为核心的后端，通过基于模式的匹配与内存执行断点在运行时在可执行段中定位处理程序。插件提供设置 GUI、与 DLL 同目录的基于 INI 的配置，以及用于启用后端、报告状态并将设置应用到已暂停会话的调试器命令。它面向需要在 x64dbg 中调试或分析受 VMProtect 保护的二进制文件、同时缓解基于 CPUID 的虚拟机检测的逆向工程师与安全研究人员。
