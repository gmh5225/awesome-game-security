KozVM 是一款 x64dbg 外掛，可在無需核心驅動程式的情況下，針對 64 位元目標對抗 VMProtect 風格的反虛擬機偵測。此外掛以 C++ 撰寫，採用 x64dbg 外掛 SDK 與 CMake 建置，並針對 VMProtect 3.3.1、3.4.0 與 3.5.0 提供以 CPUID 為核心的後端，透過模式比對與記憶體執行中斷點在執行時於可執行區段中定位處理常式。外掛提供設定 GUI、與 DLL 並列的 INI 設定，以及用於啟用後端、回報狀態並將設定套用到已暫停工作階段的偵錯器命令。它適用於需要在 x64dbg 中偵錯或分析受 VMProtect 保護的二進位檔、同時減輕以 CPUID 為基礎的虛擬機偵測的逆向工程師與安全研究人員。
