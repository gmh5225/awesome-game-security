KozDbg 是一款开源的 x64dbg 插件，可绕过 VMProtect 的反调试检测，使分析人员无需内核驱动即可调试受保护的原生 x64 程序。它提供与 VMProtect 3.3.1 至 3.10.1 各版本匹配的配置：旧版采用 API 拦截，新版则使用聚簇或分散的直接系统调用。该插件可缓解 PEB 与调试器 API 探测、远程与内核调试器查询、调试对象、线程隐藏、陷阱标志传递、硬件调试寄存器、插桩回调，以及在目标进程中动态解析的相关检测。项目以 C++17 与 CMake 面向 Windows 及 x64dbg 插件 SDK 实现，提供可自定义的 INI 配置与命令栏控件，供逆向 VMProtect 保护软件及研究壳层反调试行为的研究人员使用。
