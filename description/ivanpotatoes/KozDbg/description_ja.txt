KozDbg は、VMProtect のアンチデバッグチェックを回避し、カーネルドライバなしで保護されたネイティブ x64 プログラムを解析者がデバッグできるようにするオープンソースの x64dbg プラグインです。VMProtect 3.3.1 から 3.10.1 までバージョンに合わせたプロファイルを同梱し、旧ビルドでは API インターセプト、新しいビルドではクラスタ化または分散型の直接システムコールを用います。プラグインは PEB およびデバッガ API のプローブ、リモート・カーネルデバッガの照会、デバッグオブジェクト、スレッドの隠蔽、トラップフラグの配信、ハードウェアデバッグレジスタ、インストルメンテーションコールバック、およびターゲットプロセス内で動的に解決される関連チェックを緩和します。Windows と x64dbg プラグイン SDK 向けに C++17 と CMake で実装され、カスタマイズ可能な INI プロファイルとコマンドバー操作を備え、VMProtect 保護ソフトのリバースエンジニアリングやパッカーのアンチデバッグ挙動の研究に利用できます。
