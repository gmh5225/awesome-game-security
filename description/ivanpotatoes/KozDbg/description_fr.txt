KozDbg est un plugin x64dbg open source qui contourne les contrôles anti-débogage de VMProtect afin que les analystes puissent déboguer des programmes natifs x64 protégés sans pilote noyau. Il fournit des profils adaptés aux versions de VMProtect 3.3.1 à 3.10.1, avec interception d’API sur les builds plus anciens et appels système directs groupés ou dispersés sur les plus récents. Le plugin atténue les sondes PEB et d’API de débogueur, les requêtes de débogueur distant ou noyau, les objets de débogage, le masquage de threads, la livraison du trap flag, les registres de débogage matériel, les callbacks d’instrumentation et les contrôles connexes résolus dynamiquement dans le processus cible. Il est implémenté en C++17 avec CMake pour Windows et le SDK de plugins x64dbg, avec des profils INI personnalisables et des commandes dans la barre de commandes pour les chercheurs qui font de l’ingénierie inverse sur des logiciels protégés par VMProtect et étudient le comportement anti-débogage des packers.
