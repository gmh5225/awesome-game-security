KozDbg è un plugin open source per x64dbg che aggira i controlli anti-debug di VMProtect così che gli analisti possano eseguire il debug di programmi nativi x64 protetti senza un driver kernel. Include profili allineati alle versioni di VMProtect dalla 3.3.1 alla 3.10.1, con intercettazione delle API sulle build più vecchie e syscall dirette raggruppate o sparse su quelle più recenti. Il plugin mitiga sonde su PEB e API del debugger, query di debugger remoto e kernel, oggetti di debug, occultamento dei thread, consegna del trap flag, registri di debug hardware, callback di strumentazione e controlli correlati risolti dinamicamente nel processo target. È implementato in C++17 con CMake per Windows e l’SDK dei plugin x64dbg, con profili INI personalizzabili e controlli dalla barra comandi per ricercatori che fanno reverse engineering di software protetto da VMProtect e studiano il comportamento anti-debug dei packer.
