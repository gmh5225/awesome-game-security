KozDbg is an open-source x64dbg plugin that bypasses VMProtect anti-debug checks so analysts can debug protected native x64 programs without a kernel driver. It ships version-matched profiles for VMProtect 3.3.1 through 3.10.1, using API interception on older builds and clustered or scattered direct syscalls on newer ones. The plugin mitigates PEB and debugger API probes, remote and kernel debugger queries, debug objects, thread hiding, trap-flag delivery, hardware debug registers, instrumentation callbacks, and related checks resolved dynamically in the target process. It is implemented in C++17 with CMake for Windows and the x64dbg plugin SDK, with customizable INI profiles and command-bar controls for researchers reverse engineering VMProtect-protected software and studying packer anti-debug behavior.
