KozDbg es un complemento open source para x64dbg que elude las comprobaciones anti-depuración de VMProtect para que los analistas puedan depurar programas nativos x64 protegidos sin un controlador de kernel. Incluye perfiles adaptados a las versiones de VMProtect 3.3.1 a 3.10.1, usando interceptación de API en compilaciones antiguas y syscalls directas agrupadas o dispersas en las más recientes. El complemento mitiga sondeos de PEB y de API del depurador, consultas de depurador remoto y de kernel, objetos de depuración, ocultación de hilos, entrega de trap flag, registros de depuración por hardware, callbacks de instrumentación y comprobaciones relacionadas resueltas dinámicamente en el proceso objetivo. Está implementado en C++17 con CMake para Windows y el SDK de complementos de x64dbg, con perfiles INI personalizables y controles en la barra de comandos para investigadores que hacen ingeniería inversa de software protegido por VMProtect y estudian el comportamiento anti-depuración de los packers.
