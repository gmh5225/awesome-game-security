KozDbg — это плагин x64dbg с открытым исходным кодом, обходящий антиотладочные проверки VMProtect, чтобы аналитики могли отлаживать защищённые нативные x64-программы без драйвера ядра. В комплект входят профили под версии VMProtect с 3.3.1 по 3.10.1: для старых сборок используется перехват API, для новых — сгруппированные или разрозненные прямые системные вызовы. Плагин ослабляет проверки PEB и отладочных API, запросы удалённого и ядерного отладчика, объекты отладки, скрытие потоков, доставку trap flag, аппаратные отладочные регистры, callback-и инструментирования и связанные проверки, разрешаемые динамически в целевом процессе. Реализован на C++17 с CMake для Windows и SDK плагинов x64dbg, с настраиваемыми INI-профилями и элементами управления в командной строке для исследователей, занимающихся реверс-инжинирингом ПО под VMProtect и изучением антиотладочного поведения упаковщиков.
