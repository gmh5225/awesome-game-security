KozDbg 是一款開源的 x64dbg 外掛，可繞過 VMProtect 的反除錯檢查，讓分析人員無需核心驅動程式即可除錯受保護的原生 x64 程式。它提供與 VMProtect 3.3.1 至 3.10.1 各版本相符的設定檔：舊版採用 API 攔截，新版則使用叢集或分散的直接系統呼叫。此外掛可緩解 PEB 與除錯器 API 探測、遠端與核心除錯器查詢、除錯物件、執行緒隱藏、陷阱旗標傳遞、硬體除錯暫存器、插樁回呼，以及在目標程序中動態解析的相關檢查。專案以 C++17 與 CMake 面向 Windows 及 x64dbg 外掛 SDK 實作，提供可自訂的 INI 設定與命令列控制，供逆向 VMProtect 保護軟體及研究加殼反除錯行為的研究人員使用。
