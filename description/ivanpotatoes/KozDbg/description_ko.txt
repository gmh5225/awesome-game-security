KozDbg는 VMProtect 안티디버그 검사를 우회하여 분석가가 커널 드라이버 없이 보호된 네이티브 x64 프로그램을 디버깅할 수 있게 하는 오픈 소스 x64dbg 플러그인입니다. VMProtect 3.3.1부터 3.10.1까지 버전에 맞춘 프로필을 제공하며, 구형 빌드에서는 API 가로채기를, 신형 빌드에서는 클러스터형 또는 분산형 직접 시스템 호출을 사용합니다. 이 플러그인은 PEB 및 디버거 API 프로브, 원격·커널 디버거 조회, 디버그 객체, 스레드 숨김, 트랩 플래그 전달, 하드웨어 디버그 레지스터, 계측 콜백, 대상 프로세스에서 동적으로 해석되는 관련 검사를 완화합니다. Windows와 x64dbg 플러그인 SDK용으로 C++17과 CMake로 구현되었으며, 사용자 지정 INI 프로필과 명령줄 컨트롤을 제공해 VMProtect로 보호된 소프트웨어를 리버스 엔지니어링하고 패커의 안티디버그 동작을 연구하는 데 활용할 수 있습니다.
