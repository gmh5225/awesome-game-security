Error SMP Screenshare는 Windows에서 Minecraft Java Edition 치트를 탐지하기 위한 동의 기반 원격 포렌식 스크린공유 시스템입니다. 서명된 C#/.NET 8 클라이언트 에이전트와 Supabase를 백엔드로 사용하는 React 및 TypeScript 웹 패널이 연동되며, 스태프가 일회용 키를 생성하고 피의자는 동의 절차를 거친 스캔을 실행하여 진행 상황을 실시간으로 스트리밍하고 TLS를 통해 증거를 업로드합니다. 클라이언트는 Prefetch, BAM, UserAssist, ShimCache, NTFS USN 저널 분석, 레지스트리 및 휴지통 검사, 선택적 브라우저 다운로드 기록, 알려진 치트 클라이언트 및 모드에 대한 시그니처 데이터베이스를 활용한 Minecraft 전용 검사 등 모듈형 Windows 포렌식 수집기를 실행합니다. 상관 엔진이 여러 아티팩트의 발견 사항을 연결하여 반포렌식 변조와 반복되는 치트 지표를 드러내고, 자동 처벌이 아닌 인간 검토를 위한 심각도 순위 보고서를 생성합니다. 스크린공유 조사 중 윤리적이고 투명한 PC 검사가 필요한 Minecraft 커뮤니티 중재자 및 게임 보안 담당자를 대상으로 합니다.
