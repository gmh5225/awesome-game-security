Error SMP Screenshare è un sistema consensuale di screenshare forense remoto per rilevare cheating in Minecraft Java Edition su Windows. Abbina un agent client firmato in C#/.NET 8 a un pannello web React e TypeScript basato su Supabase, dove lo staff genera chiavi monouso e i sospetti eseguono una scansione vincolata al consenso che trasmette in streaming l'avanzamento in tempo reale e carica le prove via TLS. Il client esegue collector forensici modulari per Windows quali Prefetch, BAM, UserAssist, ShimCache, analisi del journal USN NTFS, ispezione di registro e cestino, cronologia download del browser opzionale e controlli specifici per Minecraft basati su un database di firme di client e mod cheat noti. Un motore di correlazione collega le scoperte tra artefatti per evidenziare manomissioni anti-forensi e indicatori ripetuti di cheat, producendo report classificati per gravità per revisione umana anziché punizione automatica. È rivolto a moderatori di community Minecraft e al personale di game security che necessita di controlli PC etici e trasparenti durante indagini via screenshare.
