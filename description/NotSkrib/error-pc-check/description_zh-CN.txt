Error SMP Screenshare 是一套用于在 Windows 上检测 Minecraft Java Edition 作弊行为的自愿远程取证屏幕共享系统。它将由签名的 C#/.NET 8 客户端代理与基于 Supabase 的 React 和 TypeScript Web 管理面板配对，工作人员生成一次性密钥，被调查者运行需经同意授权的扫描，实时流式传输进度并通过 TLS 上传证据。客户端运行模块化的 Windows 取证采集器，例如 Prefetch、BAM、UserAssist、ShimCache、NTFS USN 日志分析、注册表与回收站检查、可选的浏览器下载历史，以及针对已知作弊客户端与模组签名数据库的 Minecraft 专项检查。关联引擎将各取证工件中的发现进行关联，以揭示反取证篡改与重复的作弊指标，生成按严重程度排名的报告供人工审核，而非自动处罚。它面向需要在屏幕共享调查中进行合乎道德、透明 PC 检查的 Minecraft 社区版主与游戏安全工作人员。
