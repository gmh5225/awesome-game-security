Error SMP Screenshare is a consensual remote forensic screenshare system for detecting cheating in Minecraft Java Edition on Windows. It pairs a signed C#/.NET 8 client agent with a React and TypeScript web panel backed by Supabase, where staff generate one-time keys and suspects run a consent-gated scan that streams live progress and uploads evidence over TLS. The client runs modular Windows forensic collectors such as Prefetch, BAM, UserAssist, ShimCache, NTFS USN journal analysis, registry and recycle-bin inspection, optional browser download history, and Minecraft-specific checks against a signature database for known cheat clients and mods. A correlation engine ties findings across artifacts to surface anti-forensic tampering and repeated cheat indicators, producing severity-ranked reports for human review rather than automated punishment. It is aimed at Minecraft community moderators and game-security staff who need ethical, transparent PC checks during screenshare investigations.
