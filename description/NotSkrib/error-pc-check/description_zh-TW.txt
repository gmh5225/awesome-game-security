Error SMP Screenshare 是一套用於在 Windows 上偵測 Minecraft Java Edition 作弊行為的自願遠端鑑識螢幕分享系統。它將由簽署的 C#/.NET 8 用戶端代理與以 Supabase 為後端的 React 和 TypeScript Web 管理面板配對，工作人員產生一次性金鑰，被調查者執行需經同意授權的掃描，即時串流進度並透過 TLS 上傳證據。用戶端執行模組化的 Windows 鑑識採集器，例如 Prefetch、BAM、UserAssist、ShimCache、NTFS USN 日誌分析、登錄與資源回收筒檢查、可選的瀏覽器下載紀錄，以及針對已知作弊用戶端與模組簽章資料庫的 Minecraft 專項檢查。關聯引擎將各鑑識構件中的發現進行關聯，以揭露反鑑識竄改與重複的作弊指標，產生依嚴重程度排名的報告供人工審核，而非自動懲處。它面向需要在螢幕分享調查中進行合乎道德、透明 PC 檢查的 Minecraft 社群版主與遊戲安全工作人員。
