Error SMP Screenshare es un sistema consensuado de screenshare forense remoto para detectar trampas en Minecraft Java Edition en Windows. Combina un agente cliente firmado en C#/.NET 8 con un panel web en React y TypeScript respaldado por Supabase, donde el personal genera claves de un solo uso y los sospechosos ejecutan un escaneo sujeto a consentimiento que transmite el progreso en directo y sube pruebas mediante TLS. El cliente ejecuta recopiladores forenses modulares de Windows como Prefetch, BAM, UserAssist, ShimCache, análisis del diario USN de NTFS, inspección del registro y la papelera de reciclaje, historial de descargas del navegador opcional y comprobaciones específicas de Minecraft contra una base de datos de firmas de clientes y mods de trampa conocidos. Un motor de correlación vincula hallazgos entre artefactos para revelar manipulación anti-forense e indicadores repetidos de trampa, produciendo informes clasificados por gravedad para revisión humana en lugar de castigo automatizado. Está dirigido a moderadores de comunidades de Minecraft y personal de seguridad de juegos que necesitan comprobaciones éticas y transparentes del PC durante investigaciones por screenshare.
