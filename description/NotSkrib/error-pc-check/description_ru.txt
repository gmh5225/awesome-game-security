Error SMP Screenshare — это система удалённого форензического скриншэринга на основе согласия для выявления читов в Minecraft Java Edition в Windows. Она объединяет подписанный клиентский агент на C#/.NET 8 с веб-панелью на React и TypeScript с бэкендом Supabase, где сотрудники генерируют одноразовые ключи, а подозреваемые запускают сканирование с обязательного согласия, которое в режиме реального времени передаёт прогресс и загружает доказательства по TLS. Клиент выполняет модульные Windows-форензические сборщики, такие как Prefetch, BAM, UserAssist, ShimCache, анализ журнала USN NTFS, проверку реестра и корзины, опционально историю загрузок браузера, а также проверки, специфичные для Minecraft, по базе сигнатур известных чит-клиентов и модов. Корреляционный движок связывает находки между артефактами, чтобы выявлять антифорензические изменения и повторяющиеся признаки читов, формируя отчёты с ранжированием по серьёзности для ручной проверки, а не автоматического наказания. Предназначена для модераторов сообществ Minecraft и специалистов по безопасности игр, которым нужны этичные и прозрачные проверки ПК во время расследований через скриншэр.
