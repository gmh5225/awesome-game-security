Error SMP Screenshare は、Windows 上の Minecraft Java Edition におけるチート検出のための、合意に基づくリモートフォレンジックスクリーンシェアシステムです。署名付きの C#/.NET 8 クライアントエージェントと、Supabase をバックエンドとする React および TypeScript の Web パネルを組み合わせ、スタッフがワンタイムキーを発行し、被疑者が同意を経たスキャンを実行して進捗をリアルタイムでストリーミングし、TLS 経由で証拠をアップロードします。クライアントは Prefetch、BAM、UserAssist、ShimCache、NTFS USN ジャーナル分析、レジストリおよびごみ箱の検査、任意のブラウザダウンロード履歴、既知のチートクライアントや MOD に対するシグネチャデータベースを用いた Minecraft 固有のチェックなど、モジュール式の Windows フォレンジックコレクターを実行します。相関エンジンが各アーティファクト間の検出結果を関連付け、反フォレンジック改ざんや繰り返しのチート指標を浮き彫りにし、自動処罰ではなく人間によるレビューのための重大度順レポートを生成します。スクリーンシェア調査中に倫理的かつ透明な PC チェックを必要とする Minecraft コミュニティモデレーターやゲームセキュリティ担当者を対象としています。
