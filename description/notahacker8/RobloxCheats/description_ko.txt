이 프로젝트는 macOS용 네이티브 Roblox 클라이언트를 위한 치트 프레임워크로, libESP.dylib 헬퍼를 주입하고 동반 실행 파일을 통해 게임별 치트 로직을 실행합니다. 주로 Objective-C로 작성되었으며, Mach VM 메모리 API, 공유 메모리 IPC, dylib 주입, Roblox 객체 및 오프셋 정의를 사용하여 ESP 오버레이, 입력 시뮬레이션, 원격 함수 호출, 브레이크포인트 기반 훅을 지원합니다. 저장소에는 Arsenal, Blox Fruits, Tower Defense Simulator 등의 게임별 모듈과 범용 anti-AFK 및 auto-farm 유틸리티, 테스트 place 파일에서 객체 오프셋을 탐색하는 도구가 포함되어 있습니다. Roblox 클라이언트의 메모리 레이아웃, 주입 기법, macOS에서의 공격적 치트 동작을 연구하는 게임 보안 연구자와 리버스 엔지니어에게 주로 유용합니다.
