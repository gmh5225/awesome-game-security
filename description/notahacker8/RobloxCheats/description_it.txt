Questo progetto è un framework di cheat per il client Roblox nativo su macOS che inietta una libreria di supporto libESP.dylib ed esegue logiche di cheat specifiche per ogni gioco tramite un eseguibile companion. È scritto principalmente in Objective-C e utilizza le API di memoria Mach VM, IPC a memoria condivisa, iniezione di dylib e definizioni di oggetti e offset di Roblox per supportare overlay ESP, simulazione dell'input, chiamate a funzioni remote e hook basati su breakpoint. Il repository include moduli per gioco per titoli come Arsenal, Blox Fruits e Tower Defense Simulator, insieme a utility generiche anti-AFK e auto-farm e strumenti per scoprire gli offset degli oggetti da un file place di test. È principalmente utile per ricercatori di sicurezza dei giochi e reverse engineer che studiano il layout di memoria del client Roblox, le tecniche di iniezione e il comportamento offensivo dei cheat su macOS.
