這是一個面向 macOS 原生 Roblox 客戶端的作弊框架，透過注入 libESP.dylib 輔助程式庫，並由配套可執行檔執行針對特定遊戲的作弊邏輯。專案主要使用 Objective-C 編寫，利用 Mach VM 記憶體 API、共享記憶體 IPC、dylib 注入以及 Roblox 物件與偏移定義，實現 ESP 覆蓋層、輸入模擬、遠端函式呼叫和基於中斷點的 Hook。儲存庫包含針對 Arsenal、Blox Fruits、Tower Defense Simulator 等遊戲的獨立模組，以及通用的防掛機與自動刷資源工具，並提供從測試 place 檔案中發現物件偏移的工具。該專案主要面向遊戲安全研究人員和逆向工程師，用於研究 Roblox 客戶端在 macOS 上的記憶體配置、注入技術及攻擊性作弊行為。
