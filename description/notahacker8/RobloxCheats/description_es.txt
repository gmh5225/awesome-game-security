Este proyecto es un framework de trampas para el cliente nativo de Roblox en macOS que inyecta una biblioteca auxiliar libESP.dylib y ejecuta lógica de trampas específica de cada juego mediante un ejecutable complementario. Está escrito principalmente en Objective-C y utiliza las API de memoria Mach VM, IPC de memoria compartida, inyección de dylib y definiciones de objetos y offsets de Roblox para admitir superposiciones ESP, simulación de entrada, llamadas a funciones remotas y hooks basados en puntos de interrupción. El repositorio incluye módulos por juego para títulos como Arsenal, Blox Fruits y Tower Defense Simulator, junto con utilidades genéricas anti-AFK y auto-farm y herramientas para descubrir offsets de objetos a partir de un archivo place de prueba. Resulta especialmente útil para investigadores de seguridad en juegos e ingenieros inversos que estudian el diseño de memoria del cliente Roblox, técnicas de inyección y comportamiento ofensivo de trampas en macOS.
