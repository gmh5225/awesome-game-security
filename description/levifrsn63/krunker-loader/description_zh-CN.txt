Krunker Loader 是一款面向浏览器游戏 Krunker.io 的无密钥作弊工具栈，以 Tampermonkey 和 Violentmonkey 用户脚本形式提供，并附带可选的客户端加载器。主脚本在 document-start 阶段注入，设置本地防篡改令牌以绕过客户端完整性检查，并提供自瞄、ESP、穿墙透视、玩家与武器变色、FOV 与皮肤更换、连跳，以及可绑定按键的 ImGui 风格模组菜单。可选加载器可模拟 Quirify 风格的许可证与心跳验证（无需密钥），并启动捆绑的干净游戏客户端而非原版客户端。该项目使用 JavaScript 编写，主要用于研究浏览器游戏客户端操控、基于用户脚本的注入以及反作弊规避技术。
