Krunker Loader — это стек читов без ключа для браузерной игры Krunker.io, поставляемый в виде userscript для Tampermonkey и Violentmonkey с опциональным клиентским загрузчиком. Основной скрипт внедряется на этапе document-start, устанавливает локальный anti-tamper токен для обхода проверок целостности клиента и предоставляет aimbot, ESP и wallhack, chams для игроков и оружия, смену FOV и скинов, bunny hop и настраиваемое меню модов в стиле ImGui. Опциональный загрузчик эмулирует проверку лицензии и heartbeat в стиле Quirify без ключа и может запускать включённый чистый игровой клиент вместо стандартного. Написан на JavaScript и в первую очередь полезен для изучения манипуляции клиентами браузерных игр, инъекции через userscript и методов обхода античита.
