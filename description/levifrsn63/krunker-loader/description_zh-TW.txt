Krunker Loader 是一款面向瀏覽器遊戲 Krunker.io 的無金鑰作弊工具堆疊，以 Tampermonkey 與 Violentmonkey 使用者腳本形式提供，並附帶可選的用戶端載入器。主腳本在 document-start 階段注入，設定本機防篡改權杖以繞過用戶端完整性檢查，並提供自瞄、ESP、穿牆透視、玩家與武器變色、FOV 與外觀更換、連跳，以及可綁定按鍵的 ImGui 風格模組選單。可選載入器可模擬 Quirify 風格的授權與心跳驗證（無需金鑰），並啟動捆綁的乾淨遊戲用戶端而非原版用戶端。此專案以 JavaScript 撰寫，主要用於研究瀏覽器遊戲用戶端操控、以使用者腳本為基礎的注入，以及反作弊規避技術。
