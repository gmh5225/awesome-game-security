ORRESS (Okiedocus Rusty Reverse Engineering Software Suite) is a pure-Rust integrated development environment for reverse engineering and binary analysis. It loads PE, ELF, Mach-O, .NET, Java, DEX, WebAssembly, and other formats, and provides x86/x86-64 and ARM64 disassembly, control-flow graphs, cross-references, and a decompiler that can emit compilable Rust. The suite adds native debugging, an x86-64 emulator with time-travel tracing, symbolic solving, malware triage with YARA-X and sandboxing, and built-in assembler, patcher, and transform workbench tools. It is written primarily in Rust, supports Zed-style extensions and Rhai scripting, and includes ORRESS Academy with guided lessons and crackmes for learning static and dynamic analysis including anti-debugging. It targets reverse engineers, malware analysts, CTF players, and anyone who needs a self-contained toolkit for understanding and modifying compiled software.
