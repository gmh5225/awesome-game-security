ORRESS (Okiedocus Rusty Reverse Engineering Software Suite) is a pure-Rust integrated development environment for reverse engineering and binary analysis. It loads common executable and bytecode formats—including PE, ELF, Mach-O, .NET, Java, Android DEX, Python bytecode, WebAssembly, and JavaScript—and provides disassembly, control-flow analysis, and a decompiler with Rust-oriented output including a mode that lifts assembly into compilable Rust. The suite adds native debugging, x86-64 emulation with time-travel tracing, symbolic execution, malware triage with YARA scanning and sandboxing, and an exploit-development toolkit with scripting, ROP gadgets, and heap visualization for Linux pwn workflows. Built-in ORRESS Academy lessons, crackmes, and a CPU simulator support learning static and dynamic analysis, while optional AI assistance and an MCP server expose analysis engines to automation. It targets security researchers, malware analysts, CTF players, and anyone doing hands-on reverse engineering, anti-debugging study, or game and client binary inspection.
