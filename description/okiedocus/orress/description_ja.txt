ORRESS（Okiedocus Rusty Reverse Engineering Software Suite）は、リバースエンジニアリングとバイナリ解析向けの pure-Rust 統合開発環境です。PE、ELF、Mach-O、.NET、Java、DEX、WebAssembly などの形式を読み込み、x86/x86-64 および ARM64 の逆アセンブル、制御フローグラフ、クロスリファレンス、コンパイル可能な Rust を出力できるデコンパイラを提供します。スイートにはネイティブデバッグ、タイムトラベル追跡付き x86-64 エミュレータ、記号実行、YARA-X とサンドボックスによるマルウェアトリアージ、組み込みアセンブラ・パッチャー・変換ワークベンチも含まれます。主に Rust で書かれ、Zed スタイルの拡張と Rhai スクリプトをサポートし、ORRESS Academy ではガイド付きレッスンと crackme で静的・動的解析（アンチデバッグ含む）を学べます。リバースエンジニア、マルウェアアナリスト、CTF プレイヤー、コンパイル済みソフトウェアの理解と改変に自己完結型ツールキットを必要とする方を対象としています。
