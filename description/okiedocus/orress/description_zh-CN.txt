ORRESS（Okiedocus Rusty Reverse Engineering Software Suite）是一款纯 Rust 实现的逆向工程与二进制分析集成开发环境。它支持加载 PE、ELF、Mach-O、.NET、Java、DEX、WebAssembly 等格式，并提供 x86/x86-64 与 ARM64 反汇编、控制流图、交叉引用，以及可输出可编译 Rust 代码的反编译器。该套件还包含原生调试、带时间旅行追踪的 x86-64 模拟器、符号求解、基于 YARA-X 与沙箱的恶意软件分类，以及内置汇编器、补丁器与转换工作台工具。主要使用 Rust 编写，支持 Zed 风格扩展与 Rhai 脚本，并包含 ORRESS Academy，通过引导式课程与 crackme 学习静态与动态分析（含反调试）。面向逆向工程师、恶意软件分析人员、CTF 选手以及需要自包含工具集来理解与修改编译后软件的任何人。
