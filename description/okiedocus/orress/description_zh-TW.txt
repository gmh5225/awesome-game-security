ORRESS（Okiedocus Rusty Reverse Engineering Software Suite）是一款以純 Rust 實作的逆向工程與二進位分析整合開發環境。它可載入 PE、ELF、Mach-O、.NET、Java、DEX、WebAssembly 等格式，並提供 x86/x86-64 與 ARM64 反組譯、控制流程圖、交叉參考，以及可輸出可編譯 Rust 程式碼的反編譯器。此套件另含原生除錯、具時間旅行追蹤的 x86-64 模擬器、符號求解、以 YARA-X 與沙箱進行的惡意軟體分類，以及內建組譯器、修補器與轉換工作台工具。主要以 Rust 撰寫，支援 Zed 風格擴充與 Rhai 腳本，並包含 ORRESS Academy，透過引導式課程與 crackme 學習靜態與動態分析（含反除錯）。面向逆向工程師、惡意軟體分析人員、CTF 玩家，以及需要自包含工具組來理解與修改編譯後軟體的任何人。
