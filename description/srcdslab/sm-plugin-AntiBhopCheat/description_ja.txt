AntiBhopCheat は、Source エンジンのゲームサーバー向け SourceMod プラグインで、スクリプト化された bhop ハックや hyperscroll 入力パターンを含むバニーホップ（連続ジャンプ）チートを検出します。SourcePawn で記述され、プレイヤーのジャンプタイミング、速度、tick 単位の入力を、現在およびグローバルな連続ウィンドウにわたって分析し、設定可能な閾値で不審な移動をフラグ付けします。サーバー管理者は管理コマンドで検出結果を確認でき、アラート音の再生、SelectiveBhop 連携によるフラグ付きプレイヤーのバニーホップ制限、再犯者の自動キックなどを任意で設定できます。Counter-Strike やその他 SourceMod 対応タイトルにおいて、移動の自動化に対するサーバー側アンチチートを必要とする競技・コミュニティサーバー運営者向けです。
