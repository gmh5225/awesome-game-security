AntiBhopCheat è un plugin SourceMod per server di gioco con motore Source che rileva cheat di bunny hop, inclusi hack bhop scriptati e pattern di input hyperscroll. Scritto in SourcePawn, analizza tempi di salto, velocità e input a livello di tick dei giocatori su finestre di serie correnti e globali per segnalare movimenti sospetti con soglie configurabili. Gli amministratori del server possono consultare i rilevamenti tramite comandi admin, riprodurre opzionalmente suoni di allerta, limitare il bunny hop dei giocatori segnalati tramite l'integrazione SelectiveBhop o espellere automaticamente i recidivi. È pensato per operatori di server competitivi e community che necessitano di enforcement anti-cheat lato server contro l'automazione dei movimenti su Counter-Strike e altri titoli supportati da SourceMod.
