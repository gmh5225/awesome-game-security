Ghost Anti-Cheat 是一款面向運行於 Nukkit 上的 Minecraft: Bedrock Edition 伺服器的基於預測的防作弊外掛。它使用 Java 編寫，透過 Gradle 建置，在伺服器端採用實體元件系統（ECS）架構模擬 Bedrock Dedicated Server 的移動、碰撞與物理，將用戶端回報的運動與預期結果進行比對。此外掛在延遲補償下監控網路封包，檢測諸如穿牆（phase）、無減速（no-slow）、反擊退（anti-knockback）等移動類作弊，以及戰鬥距離、碰撞箱濫用、非法破壞方塊、鞘翅飛行異常、惡意封包與多重操作違規。它面向需要伺服器端作弊檢測而非用戶端強制執行的基岩版服主與遊戲安全從業者。
