Ghost Anti-Cheat is a prediction-based anti-cheat plugin for Minecraft: Bedrock Edition servers running on Nukkit. Written in Java and built with Gradle, it simulates Bedrock Dedicated Server movement, collision, and physics on the server using an entity-component-system architecture to compare client-reported motion against expected outcomes. The plugin monitors network packets with latency compensation and runs checks for movement exploits such as phase, no-slow, and anti-knockback, as well as combat reach and hitbox abuse, invalid block breaking, elytra flight anomalies, bad packets, and multi-action violations. It is aimed at Bedrock server operators and game-security practitioners who need server-side cheat detection rather than client-side enforcement.
