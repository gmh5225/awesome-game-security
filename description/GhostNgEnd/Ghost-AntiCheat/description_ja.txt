Ghost Anti-Cheat は、Nukkit 上で動作する Minecraft: Bedrock Edition サーバー向けの予測ベースのアンチチートプラグインです。Java で記述され Gradle でビルドされ、エンティティ・コンポーネント・システム（ECS）アーキテクチャを用いてサーバー側で Bedrock Dedicated Server の移動、衝突、物理をシミュレートし、クライアントが報告する動きを想定結果と比較します。プラグインはレイテンシ補償付きでネットワークパケットを監視し、フェーズ、ノースロー、アンチノックバックなどの移動エクスプロイトや、コンバットリーチ、ヒットボックス悪用、不正なブロック破壊、エリトラ飛行の異常、不正パケット、マルチアクション違反などのチェックを実行します。クライアント側の強制ではなくサーバー側のチート検出を必要とする Bedrock サーバー運営者やゲームセキュリティ実務者を対象としています。
