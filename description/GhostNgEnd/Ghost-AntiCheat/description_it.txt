Ghost Anti-Cheat è un plugin anti-cheat basato sulla previsione per server Minecraft: Bedrock Edition in esecuzione su Nukkit. Scritto in Java e compilato con Gradle, simula sul server movimento, collisioni e fisica di Bedrock Dedicated Server usando un'architettura entity-component-system (ECS) per confrontare i movimenti segnalati dal client con i risultati attesi. Il plugin monitora i pacchetti di rete con compensazione della latenza ed esegue controlli su exploit di movimento come phase, no-slow e anti-knockback, nonché combat reach e abuso delle hitbox, rottura di blocchi non valida, anomalie di volo con elytra, pacchetti errati e violazioni multi-azione. È rivolto agli operatori di server Bedrock e ai professionisti della sicurezza dei giochi che necessitano di rilevamento delle cheat lato server anziché applicazione lato client.
