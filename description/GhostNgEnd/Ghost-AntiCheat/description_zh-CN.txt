Ghost Anti-Cheat 是一款面向运行于 Nukkit 上的 Minecraft: Bedrock Edition 服务器的基于预测的防作弊插件。它使用 Java 编写，通过 Gradle 构建，在服务端采用实体组件系统（ECS）架构模拟 Bedrock Dedicated Server 的移动、碰撞与物理，将客户端上报的运动与预期结果进行比对。该插件在延迟补偿下监控网络数据包，检测诸如穿墙（phase）、无减速（no-slow）、反击退（anti-knockback）等移动类作弊，以及战斗距离、碰撞箱滥用、非法破坏方块、鞘翅飞行异常、恶意数据包与多重操作违规。它面向需要服务端作弊检测而非客户端强制执行的基岩版服主与游戏安全从业者。
