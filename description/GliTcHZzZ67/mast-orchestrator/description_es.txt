MAST Orchestrator es un panel web para automatizar pruebas de seguridad de aplicaciones móviles en dispositivos Android con root mediante Frida. Desarrollado en Python con Flask, utiliza ADB para descubrir dispositivos conectados, verificar el acceso root y desplegar binarios de Frida server compatibles con la arquitectura con un solo clic. La plataforma incluye hooks Frida listos para usar que permiten omitir SSL pinning, eludir la detección de root y monitorizar APIs criptográficas, y puede obtener scripts adicionales de fuentes remotas aprobadas como GitHub Raw o Frida Codeshare. Una interfaz de navegador transmite la salida de los hooks en tiempo real y protege los endpoints de la API con autenticación basada en tokens. Está destinado a investigadores de seguridad y probadores de penetración que realizan análisis dinámico autorizado de aplicaciones Android.
