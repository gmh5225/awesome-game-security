MAST Orchestrator は、Frida を用いて root 化された Android デバイス上でモバイルアプリケーションのセキュリティテストを自動化する Web ベースのダッシュボードです。Python と Flask で構築され、ADB で接続デバイスを検出し、root アクセスを確認し、ワンクリックでアーキテクチャに合わせた Frida server バイナリをデプロイします。プラットフォームには SSL pinning バイパス、root 検出バイパス、暗号 API 監視用の既製 Frida フックが同梱され、GitHub Raw や Frida Codeshare など承認済みのリモートソースから追加スクリプトを取得できます。ブラウザ UI はフック出力をリアルタイムでストリーミングし、トークンベース認証で API エンドポイントを保護します。Android アプリケーションの許可された動的解析を行うセキュリティ研究者およびペネトレーションテスター向けです。
