MAST Orchestrator 是一款基于 Web 的仪表板，用于通过 Frida 在已 root 的 Android 设备上自动化移动应用安全测试。它使用 Python 和 Flask 构建，通过 ADB 发现已连接设备、验证 root 权限，并一键部署与架构匹配的 Frida server 二进制文件。该平台内置现成的 Frida hook，可用于 SSL pinning 绕过、root 检测绕过以及加密 API 监控，并可以从 GitHub Raw 或 Frida Codeshare 等经批准的远程源获取额外脚本。浏览器 UI 实时流式传输 hook 输出，并通过基于 token 的身份验证保护 API 端点。它面向对 Android 应用进行授权动态分析的安全研究人员和渗透测试人员。
