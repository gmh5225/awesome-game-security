MAST Orchestrator 是一款基於 Web 的儀表板，用於透過 Frida 在已 root 的 Android 裝置上自動化行動應用程式安全測試。它以 Python 和 Flask 建構，使用 ADB 探索已連接裝置、驗證 root 權限，並一鍵部署與架構相符的 Frida server 二進位檔。該平台內建現成的 Frida hook，可用於 SSL pinning 繞過、root 偵測繞過以及加密 API 監控，並可從 GitHub Raw 或 Frida Codeshare 等經核准的遠端來源取得額外腳本。瀏覽器 UI 即時串流 hook 輸出，並以基於 token 的身分驗證保護 API 端點。它面向對 Android 應用程式進行授權動態分析的安全研究人員與滲透測試人員。
