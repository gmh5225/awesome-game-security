MAST Orchestrator est un tableau de bord web pour automatiser les tests de sécurité d'applications mobiles sur des appareils Android rootés via Frida. Développé en Python avec Flask, il utilise ADB pour découvrir les appareils connectés, vérifier l'accès root et déployer en un clic des binaires Frida server adaptés à l'architecture. La plateforme inclut des hooks Frida prêts à l'emploi pour contourner le SSL pinning, contourner la détection root et surveiller les API cryptographiques, et peut récupérer des scripts supplémentaires depuis des sources distantes approuvées telles que GitHub Raw ou Frida Codeshare. Une interface navigateur diffuse la sortie des hooks en temps réel et protège les points de terminaison API par une authentification basée sur des jetons. Il est destiné aux chercheurs en sécurité et aux testeurs de pénétration effectuant une analyse dynamique autorisée d'applications Android.
