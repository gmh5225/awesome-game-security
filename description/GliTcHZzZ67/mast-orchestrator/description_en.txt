MAST Orchestrator is a web-based dashboard for automating mobile application security testing on rooted Android devices via Frida. Built in Python with Flask, it uses ADB to discover connected devices, verify root access, and deploy architecture-matched Frida server binaries with one click. The platform ships with ready-made Frida hooks for SSL pinning bypass, root detection bypass, and cryptographic API monitoring, and can fetch additional scripts from approved remote sources such as GitHub Raw or Frida Codeshare. A browser UI streams hook output in real time and protects API endpoints with token-based authentication. It is intended for security researchers and penetration testers performing authorized dynamic analysis of Android applications.
