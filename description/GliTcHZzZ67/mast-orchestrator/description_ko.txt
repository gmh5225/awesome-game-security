MAST Orchestrator는 Frida를 통해 root된 Android 기기에서 모바일 애플리케이션 보안 테스트를 자동화하는 웹 기반 대시보드입니다. Python과 Flask로 구축되었으며, ADB를 사용해 연결된 기기를 탐지하고 root 접근 권한을 확인하며, 원클릭으로 아키텍처에 맞는 Frida server 바이너리를 배포합니다. 이 플랫폼에는 SSL pinning 우회, root 탐지 우회, 암호화 API 모니터링을 위한 기성 Frida hook이 포함되어 있으며, GitHub Raw 또는 Frida Codeshare와 같은 승인된 원격 소스에서 추가 스크립트를 가져올 수 있습니다. 브라우저 UI는 hook 출력을 실시간으로 스트리밍하고 토큰 기반 인증으로 API 엔드포인트를 보호합니다. Android 애플리케이션에 대한 허가된 동적 분석을 수행하는 보안 연구원 및 침투 테스터를 대상으로 합니다.
