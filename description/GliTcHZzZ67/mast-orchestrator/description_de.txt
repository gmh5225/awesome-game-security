MAST Orchestrator ist ein webbasiertes Dashboard zur Automatisierung von Sicherheitstests mobiler Anwendungen auf gerooteten Android-Geräten über Frida. In Python mit Flask entwickelt, nutzt es ADB, um verbundene Geräte zu erkennen, Root-Zugriff zu prüfen und architekturpassende Frida-Server-Binaries per Klick bereitzustellen. Die Plattform enthält fertige Frida-Hooks für SSL-Pinning-Bypass, Root-Erkennungs-Bypass und Kryptografie-API-Überwachung und kann zusätzliche Skripte aus genehmigten Remote-Quellen wie GitHub Raw oder Frida Codeshare abrufen. Eine Browser-Oberfläche streamt Hook-Ausgaben in Echtzeit und schützt API-Endpunkte mit tokenbasierter Authentifizierung. Es richtet sich an Sicherheitsforscher und Penetrationstester, die autorisierte dynamische Analysen von Android-Anwendungen durchführen.
