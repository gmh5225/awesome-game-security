MAST Orchestrator — это веб-панель для автоматизации тестирования безопасности мобильных приложений на рутированных Android-устройствах с помощью Frida. Написан на Python с использованием Flask, использует ADB для обнаружения подключённых устройств, проверки root-доступа и развёртывания бинарников Frida server, соответствующих архитектуре, в один клик. Платформа поставляется с готовыми Frida-хуками для обхода SSL pinning, обхода обнаружения root и мониторинга криптографических API, а также может загружать дополнительные скрипты из одобренных удалённых источников, таких как GitHub Raw или Frida Codeshare. Браузерный интерфейс транслирует вывод хуков в реальном времени и защищает API-эндпоинты токенной аутентификацией. Предназначен для исследователей безопасности и специалистов по тестированию на проникновение, выполняющих авторизованный динамический анализ Android-приложений.
