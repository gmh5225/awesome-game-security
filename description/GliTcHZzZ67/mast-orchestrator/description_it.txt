MAST Orchestrator è una dashboard web per automatizzare i test di sicurezza delle applicazioni mobili su dispositivi Android con root tramite Frida. Realizzato in Python con Flask, utilizza ADB per rilevare i dispositivi connessi, verificare l'accesso root e distribuire con un clic binari Frida server corrispondenti all'architettura. La piattaforma include hook Frida pronti all'uso per bypass del SSL pinning, bypass del rilevamento root e monitoraggio delle API crittografiche, e può recuperare script aggiuntivi da fonti remote approvate come GitHub Raw o Frida Codeshare. Un'interfaccia browser trasmette l'output degli hook in tempo reale e protegge gli endpoint API con autenticazione basata su token. È destinato a ricercatori di sicurezza e penetration tester che eseguono analisi dinamiche autorizzate di applicazioni Android.
