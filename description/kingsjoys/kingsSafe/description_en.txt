kingsSafe is an open research project building a Unity game security hardening and validation framework around asset protection, in-memory key data protection, and logic obfuscation. It aims to integrate only as a Unity editor plugin while preserving the original build entry point and business source, using build-time assembly and resource transforms with transparent runtime loading and tamper checks. The repository combines design docs, reproducible mechanism probes (including Python-driven Unity build experiments with Mono/IL2CPP-oriented validation), and a static documentation site built with Node.js. Primary languages are C# for Unity plugins and sample games, Python for reproduction and verification tooling, and JavaScript for the site. It targets game developers and security researchers evaluating client-side hardening, anti-tamper, and cheat-resistance tradeoffs; the project is still in feasibility validation and does not yet ship a production-grade protector SDK.
