kingsSafe 是一項開放研究專案，圍繞資產保護、記憶體中金鑰資料保護與邏輯混淆，建構 Unity 遊戲安全強化與驗證框架。它僅以 Unity 編輯器外掛形式整合，保留原有建置入口與業務原始碼，透過建置期組件與資源轉換，搭配透明的執行期載入與竄改檢查達成目標。本儲存庫結合設計文件、可重現的機制探針（含以 Python 驅動的 Unity 建置實驗及面向 Mono/IL2CPP 的驗證），以及以 Node.js 建置的靜態文件網站。主要語言為 C#（Unity 外掛與範例遊戲）、Python（重現與驗證工具）與 JavaScript（網站）。面向評估用戶端強化、防竄改與抗作弊權衡的遊戲開發者與安全研究人員；專案仍處於可行性驗證階段，尚未提供生產級保護 SDK。
