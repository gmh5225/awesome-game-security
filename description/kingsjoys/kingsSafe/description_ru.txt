kingsSafe — открытый исследовательский проект, создающий фреймворк усиления и проверки безопасности игр на Unity с упором на защиту ассетов, защиту ключевых данных в памяти и обфускацию логики. Он задуман как интеграция только в виде плагина редактора Unity с сохранением исходной точки входа сборки и бизнес-исходников, с преобразованиями сборок и ресурсов на этапе сборки, прозрачной загрузкой во время выполнения и проверками на подмену. Репозиторий объединяет проектную документацию, воспроизводимые механизм-пробы (включая эксперименты сборки Unity на Python с валидацией под Mono/IL2CPP) и статический сайт документации на Node.js. Основные языки — C# для плагинов Unity и примеров игр, Python для инструментов воспроизведения и верификации и JavaScript для сайта. Целевая аудитория — разработчики игр и исследователи безопасности, оценивающие компромиссы между клиентским hardening, anti-tamper и устойчивостью к читам; проект пока на стадии проверки осуществимости и ещё не поставляет production-grade SDK защитника.
