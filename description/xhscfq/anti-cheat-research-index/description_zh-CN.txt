这是一份结构化的研究索引，收录面向防御性反作弊开发的公开工程成果与留存技术参考资料，涵盖 Windows 内核安全、虚拟化与逆向工程。它将相关工作按反作弊架构、内核执行与内存完整性、图形呈现路径完整性、Intel VT-x 与 EPT 插桩，以及 x86/x64 逆向工程（含去虚拟化与反调试）等领域组织归类。代表性项目包括基于 C++ 内核核心与 Delphi UI 构建的 VT-x/EPT 辅助内核调试框架，以及内核 shellcode 检测、跨进程附加检测、呈现钩子检测与硬件跟踪分析等参考实现。该仓库作为授权安全测试、防御性反作弊工程、恶意软件分析与教学的研究地图与方法论指南，而非独立代码库。
