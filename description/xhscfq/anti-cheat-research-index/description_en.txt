A structured research index that catalogs public engineering work and retained technical references focused on defensive anti-cheat development, Windows kernel security, virtualization, and reverse engineering. It organizes work across areas such as anti-cheat architecture, kernel execution and memory integrity, graphics presentation-path integrity, Intel VT-x and EPT instrumentation, and x86/x64 reverse engineering including devirtualization and anti-debugging. Featured projects include a VT-x/EPT-assisted kernel debugging framework built with a C++ kernel core and Delphi UI, alongside reference implementations for kernel shellcode detection, cross-process attachment detection, presentation hook detection, and hardware trace analysis. The repository serves as a research map and methodology guide for authorized security testing, defensive anti-cheat engineering, malware analysis, and education rather than as a standalone codebase.
