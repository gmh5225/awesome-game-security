這是一份結構化的研究索引，收錄面向防禦性反作弊開發的公開工程成果與留存技術參考資料，涵蓋 Windows 核心安全、虛擬化與逆向工程。它將相關工作依反作弊架構、核心執行與記憶體完整性、圖形呈現路徑完整性、Intel VT-x 與 EPT 插樁，以及 x86/x64 逆向工程（含去虛擬化與反偵錯）等領域組織歸類。代表性專案包括以 C++ 核心與 Delphi UI 建構的 VT-x/EPT 輔助核心偵錯框架，以及核心 shellcode 偵測、跨程序附加偵測、呈現掛鉤偵測與硬體追蹤分析等參考實作。此儲存庫作為授權安全測試、防禦性反作弊工程、惡意軟體分析與教學的研究地圖與方法論指南，而非獨立程式碼庫。
