UnrealVTDbg — это отладочный фреймворк для Windows с поддержкой гипервизора, предназначенный для игр на Unreal Engine; он объединяет фронтенд на Delphi с драйверами ядра на C и C++, DLL для инъекции и компонентами перехвата. Драйвер VT-x и модули DbgkSys реализуют виртуализацию на базе Intel VMX, EPT и vmcall, а также EPT-хуки, работу с аппаратными отладочными регистрами, APC-инъекцию и Microsoft Detours для незаметных точек останова и отладочных событий. Вспомогательные инструменты включают разрешение символов, шифрование Blowfish, IPC через разделяемую память и интеграцию с VMProtect, с отдельными сборками для Windows 10 и Windows 11. Проект предназначен для исследований безопасности игр, реверс-инжиниринга и авторизованной работы по античиту или отладке ядра, когда требуется низкоуровневая видимость защищённых процессов Unreal.
