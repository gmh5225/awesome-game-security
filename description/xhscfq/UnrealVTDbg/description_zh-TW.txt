UnrealVTDbg 是一個面向 Unreal Engine 遊戲的 Windows 虛擬機器監控輔助除錯框架，結合 Delphi 前端與 C/C++ 核心驅動程式、注入 DLL 及 Hook 元件。其 VT-x 驅動程式與 DbgkSys 模組實作了基於 Intel VMX、EPT 與 vmcall 的虛擬化，並整合 EPT Hook、硬體除錯暫存器處理、APC 注入以及 Microsoft Detours，用於隱蔽中斷點與除錯事件。配套工具涵蓋符號解析、Blowfish 加密、共享記憶體 IPC 以及 VMProtect 整合，並提供 Windows 10 與 Windows 11 的獨立建置版本。本專案旨在支援遊戲安全研究、逆向工程以及經授權的反作弊或核心除錯工作，適用於需要對受保護 Unreal 程序進行底層可見性分析的情境。
