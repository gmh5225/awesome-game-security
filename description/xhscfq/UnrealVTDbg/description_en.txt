UnrealVTDbg is a Windows hypervisor-assisted debugging framework aimed at Unreal Engine games, combining a Delphi front-end with C and C++ kernel drivers, injection DLLs, and hook components. Its VT-x driver and DbgkSys modules implement Intel VMX, EPT, and vmcall-based virtualization alongside EPT hooks, hardware debug-register handling, APC injection, and Microsoft Detours for stealthy breakpoints and debug events. Supporting tools cover symbol resolution, Blowfish encryption, shared-memory IPC, and VMProtect integration, with separate builds for Windows 10 and Windows 11. The project is intended for game security research, reverse engineering, and authorized anti-cheat or kernel debugging work where low-level visibility into protected Unreal processes is required.
