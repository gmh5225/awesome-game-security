UnrealVTDbg 是一个面向 Unreal Engine 游戏的 Windows 虚拟机监控辅助调试框架，将 Delphi 前端与 C/C++ 内核驱动、注入 DLL 及 Hook 组件相结合。其 VT-x 驱动与 DbgkSys 模块实现了基于 Intel VMX、EPT 和 vmcall 的虚拟化，并集成 EPT Hook、硬件调试寄存器处理、APC 注入以及 Microsoft Detours，用于隐蔽断点与调试事件。配套工具涵盖符号解析、Blowfish 加密、共享内存 IPC 以及 VMProtect 集成，并提供 Windows 10 与 Windows 11 的独立构建版本。该项目面向游戏安全研究、逆向工程以及经授权的反作弊或内核调试工作，适用于需要对受保护 Unreal 进程进行底层可见性分析的场景。
