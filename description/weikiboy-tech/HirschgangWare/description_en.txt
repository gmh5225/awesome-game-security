HirschgangWare is a Windows external cheat for DayZ that runs on a separate machine and reads the game process over a PCIe DMA device using PCILeech and MemProcFS, without attaching to or writing memory on the gaming PC. It is built in C++17 with MSVC, Dear ImGui, and DirectX 11, and implements ESP overlays, a secondary-monitor radar, loot discovery, and gameplay assistance fed entirely from live memory reads. Input features such as a triggerbot and key handling rely on external hardware like kmbox or MAKCU for injection so the host mouse chain can stay intact for the game client. The codebase documents offset discovery, kernel-session keyboard state resolution through VMM APIs, and operational notes aimed at researchers studying external cheating architectures, DMA-based evasion, and related game-security reverse engineering.
