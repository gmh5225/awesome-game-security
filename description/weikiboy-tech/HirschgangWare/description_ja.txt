HirschgangWare は DayZ 向けの Windows 外部チートで、別マシン上で動作し、PCILeech と MemProcFS を用いた PCIe DMA デバイス経由でゲームプロセスを読み取り、ゲーム用 PC へのアタッチやメモリ書き込みを行いません。C++17、MSVC、Dear ImGui、DirectX 11 で構築され、ESP オーバーレイ、サブモニター用レーダー、ルート探索、すべてライブメモリ読み取りに基づくゲームプレイ支援を実装しています。トリガーボットやキー操作などの入力機能は kmbox や MAKCU などの外部ハードウェアによるインジェクションに依存し、ホスト側のマウスチェーンをゲームクライアント向けに維持できます。コードベースにはオフセット探索、VMM API によるカーネルセッションのキーボード状態解決、外部チートアーキテクチャ、DMA を用いた回避、関連するゲームセキュリティのリバースエンジニアリングを研究する研究者向けの運用メモがまとめられています。
