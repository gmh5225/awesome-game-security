HirschgangWare 是一款面向 DayZ 的 Windows 外部作弊工具，在独立机器上运行，通过 PCIe DMA 设备配合 PCILeech 与 MemProcFS 读取游戏进程内存，无需在游戏 PC 上附加进程或写入内存。项目基于 C++17、MSVC、Dear ImGui 与 DirectX 11 构建，实现 ESP 叠加层、副屏雷达、战利品发现及完全依赖实时内存读取的游戏辅助功能。触发器与按键等输入能力依赖 kmbox、MAKCU 等外部硬件注入，从而尽量保持主机鼠标链路对游戏客户端完整可用。代码库记录了偏移发现、通过 VMM API 解析内核会话键盘状态的方法，以及面向研究外部作弊架构、基于 DMA 的规避手段及相关游戏安全逆向工程的说明性笔记。
