HirschgangWare — внешний чит для Windows в игре DayZ, который работает на отдельной машине и читает процесс игры через устройство PCIe DMA с помощью PCILeech и MemProcFS, не подключаясь к игровому ПК и не записывая в его память. Написан на C++17 с MSVC, Dear ImGui и DirectX 11; реализует ESP-оверлеи, радар на втором мониторе, поиск лута и игровые подсказки, полностью основанные на чтении памяти в реальном времени. Функции ввода, такие как триггербот и обработка клавиш, используют внешнее оборудование вроде kmbox или MAKCU для инъекции, чтобы цепочка мыши на хосте оставалась нетронутой для игрового клиента. В кодовой базе описаны поиск смещений, определение состояния клавиатуры сеанса ядра через API VMM и практические заметки для исследователей, изучающих архитектуры внешних читов, обход на основе DMA и связанный реверс-инжиниринг игровой безопасности.
