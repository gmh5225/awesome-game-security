MhsX is a Windows memory hacking and live process analysis application written in C++ that lets users attach to running programs, search memory, and edit values in real time. It provides data-type, pointer, string, and expression-based scans, a process-aware hex editor, x86/x64 disassembly, PE inspection, speedhack support, and an expression evaluator integrated with the Oniguruma regular expression library. Built as a Visual Studio solution for 32- and 64-bit Windows, it also offers found-address management, configurable hotkeys, floating-point inspection, and string manipulation utilities for tracking and modifying runtime state. It is intended for reverse engineers, game security researchers, and developers who need deep inspection and controlled modification of application memory.
