AstroxAC ist ein leistungsstarkes Anti-Cheat, das als native GeyserMC-Erweiterung für Minecraft-Bedrock-Edition-Spieler entwickelt wurde. In Java geschrieben und mit Maven gepackt, fängt es rohe Bedrock-UDP-Pakete auf der Netty-Kanalebene ab, bevor Geyser sie nach Java übersetzt, und ermöglicht so Submillisekunden-Erkennung ohne zusätzliche Last auf dem Hauptthread-Server-Tick. Das System umfasst heuristische Module für Bewegung, Kampf, Inventar und Paketvalidierung und deckt Prüfungen wie Reichweite, Hitbox-Backtracking, Flug, Autoclicker-Erkennung, Geräte-Spoofing und Crash-Paket-Firewall ab. Es nutzt Bedrock-native Kinematik, eingabemodusabhängige Reichweitenlimits, Latenz-Backtracking und einen Leaky-Bucket-Timer, um Fehlalarme durch Übersetzungsartefakte zu reduzieren. Das Projekt richtet sich an GeyserMC-Serverbetreiber, die ein Anti-Cheat auf Unternehmensniveau für Bedrock mit Discord-Webhook-Benachrichtigungen, Admin-Befehlen und konfigurierbaren Verstoßmaßnahmen benötigen.
