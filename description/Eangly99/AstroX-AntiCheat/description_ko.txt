AstroxAC는 Minecraft Bedrock Edition 플레이어를 위해 GeyserMC 네이티브 확장으로 구축된 고성능 안티치트입니다. Java로 작성되었으며 Maven으로 패키징되며, Geyser가 Java 형식으로 변환하기 전에 Netty 채널 계층에서 원시 Bedrock UDP 패킷을 가로채 메인 스레드 서버 틱 부하를 늘리지 않고 서브밀리초 탐지를 가능하게 합니다. 시스템에는 이동, 전투, 인벤토리, 패킷 검증을 위한 휴리스틱 모듈이 포함되어 있으며, 리치, 히트박스 백트래킹, 비행, 오토클리커 탐지, 기기 스푸핑, 크래시 패킷 방화벽 등의 검사를 제공합니다. Bedrock 네이티브 운동학, 입력 모드 인식 리치 제한, 지연 백트래킹, 누출 버킷 타이머를 사용하여 변환 아티팩트로 인한 오탐을 줄입니다. 이 프로젝트는 Discord Webhook 알림, 관리자 명령, 구성 가능한 위반 조치를 갖춘 엔터프라이즈급 Bedrock 안티치트가 필요한 GeyserMC 서버 운영자를 대상으로 합니다.
