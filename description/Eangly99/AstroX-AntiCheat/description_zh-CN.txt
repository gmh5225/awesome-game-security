AstroxAC 是一款高性能反作弊系统，作为 GeyserMC 原生扩展，面向 Minecraft 基岩版玩家。项目使用 Java 编写并通过 Maven 打包，在 Geyser 将数据包转换为 Java 格式之前，于 Netty 通道层拦截原始基岩版 UDP 数据包，从而实现亚毫秒级检测，且不会增加主线程服务器 tick 开销。系统包含移动、战斗、背包与数据包校验等启发式模块，涵盖攻击距离、碰撞箱回溯、飞行、自动点击器检测、设备伪装及崩溃数据包防火墙等检查项。它采用基岩版原生运动学、按输入模式调整的距离限制、延迟回溯以及漏桶计时器，以降低因协议转换产生的误报。该项目面向需要企业级基岩版反作弊能力的 GeyserMC 服主，提供 Discord Webhook 告警、管理命令及可配置的违规处理动作。
