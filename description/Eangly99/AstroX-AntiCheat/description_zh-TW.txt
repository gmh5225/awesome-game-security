AstroxAC 是一款高效能反作弊系統，作為 GeyserMC 原生擴充功能，面向 Minecraft 基岩版玩家。專案以 Java 撰寫並透過 Maven 打包，在 Geyser 將封包轉換為 Java 格式之前，於 Netty 通道層攔截原始基岩版 UDP 封包，從而實現亞毫秒級偵測，且不會增加主執行緒伺服器 tick 開銷。系統包含移動、戰鬥、物品欄與封包驗證等啟發式模組，涵蓋攻擊距離、碰撞箱回溯、飛行、自動點擊器偵測、裝置偽裝及崩潰封包防火牆等檢查項目。它採用基岩版原生運動學、依輸入模式調整的距離限制、延遲回溯以及漏桶計時器，以降低因協定轉換產生的誤報。此專案面向需要企業級基岩版反作弊能力的 GeyserMC 伺服器營運者，提供 Discord Webhook 告警、管理指令及可設定的違規處理動作。
