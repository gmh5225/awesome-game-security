AstroxAC は、Minecraft Bedrock Edition プレイヤー向けに GeyserMC ネイティブ拡張として構築された高性能アンチチートです。Java で記述され Maven でパッケージ化されており、Geyser が Java 形式に変換する前に Netty チャネル層で生の Bedrock UDP パケットを傍受し、メインスレッドのサーバーティック負荷を増やすことなくサブミリ秒検出を実現します。システムには移動、戦闘、インベントリ、パケット検証のヒューリスティックモジュールが含まれ、リーチ、ヒットボックスのバックトラッキング、飛行、オートクリッカー検出、デバイス偽装、クラッシュパケットのファイアウォールなどのチェックをカバーします。Bedrock ネイティブの運動学、入力モードに応じたリーチ制限、レイテンシのバックトラッキング、リーキーバケットタイマーを用いて、変換アーティファクトによる誤検知を低減します。本プロジェクトは、Discord Webhook アラート、管理者コマンド、設定可能な違反処理を備えたエンタープライズ級の Bedrock アンチチートを必要とする GeyserMC サーバー運用者を対象としています。
