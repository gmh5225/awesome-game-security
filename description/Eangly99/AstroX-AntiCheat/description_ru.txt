AstroxAC — это высокопроизводительная античит-система, созданная как нативное расширение GeyserMC для игроков Minecraft Bedrock Edition. Написана на Java и собрана с помощью Maven; перехватывает необработанные UDP-пакеты Bedrock на уровне канала Netty до того, как Geyser преобразует их в Java, обеспечивая обнаружение за доли миллисекунды без дополнительной нагрузки на основной поток серверного тика. Система включает эвристические модули для движения, боя, инвентаря и проверки пакетов, охватывая такие проверки, как дальность удара, обратное отслеживание хитбокса, полёт, обнаружение автокликера, подмена устройства и фильтрация краш-пакетов. Используются нативная кинематика Bedrock, ограничения дальности с учётом режима ввода, обратное отслеживание задержки и таймер «протекающего ведра» для снижения ложных срабатываний из-за артефактов преобразования. Проект ориентирован на операторов серверов GeyserMC, которым нужен античит уровня enterprise для Bedrock с оповещениями через Discord webhook, административными командами и настраиваемыми действиями при нарушениях.
