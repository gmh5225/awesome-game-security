CS2 Tracker 是一款面向 Counter-Strike 2 的 Windows 應用程式，整合玩家生涯統計資料、即時比賽追蹤，以及可解釋的啟發式反作弊分析引擎。此工具主要以 Python 撰寫，提供 FastAPI 本地 REST API、SQLite 儲存，以及可選的 Qt 桌面與 Web 介面，透過公開的 Steam Web API 資料與官方 Game State Integration 資料來源取得資訊，而非讀取遊戲記憶體或注入程式碼。其可疑度引擎在瞄準、武器、帳戶中繼資料、即時行為、一致性、進步漂移與封禁紀錄等面向執行約三十個偵測器，採用貝氏平滑與多訊號交叉驗證，為玩家評分 0–100。原生 C++ 遊戲內 overlay 可在比賽期間顯示即時分數與每位玩家的風險等級。此工具面向競技玩家、分析師與遊戲安全研究人員，提供以可觀測資料為基礎的透明、統計化作弊風險評估，而非客戶端強制執行。
