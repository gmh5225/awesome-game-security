CS2 Tracker は Counter-Strike 2 向けの Windows アプリケーションで、プレイヤーの生涯統計、ライブマッチ追跡、説明可能なヒューリスティック反チート分析エンジンを統合しています。主に Python で記述され、FastAPI によるローカル REST API、SQLite ストレージ、オプションの Qt デスクトップおよび Web インターフェースを備え、ゲームメモリの読み取りやコード注入ではなく、公開 Steam Web API データと公式 Game State Integration フィードを取り込みます。疑わしさエンジンはエイム、武器、アカウントメタデータ、ライブ行動、一貫性、進行ドリフト、BAN 履歴など約 30 の検出器を実行し、ベイズ平滑化と複数シグナルの相互補強によりプレイヤーを 0–100 でスコアリングします。ネイティブ C++ のゲーム内オーバーレイは、試合中にライブスコアとプレイヤーごとのリスクを表示できます。本ツールは、クライアント側強制ではなく、観測可能なデータに基づく透明で統計的なチートリスク評価を求める競技プレイヤー、アナリスト、ゲームセキュリティ研究者を対象としています。
