CS2 Tracker ist eine Windows-Anwendung für Counter-Strike 2, die lebenslange Spielerstatistiken, Live-Match-Tracking und eine erklärbare heuristische Anti-Cheat-Analyse-Engine kombiniert. Hauptsächlich in Python geschrieben, mit einer lokalen FastAPI-REST-API, SQLite-Speicherung und optionalen Qt-Desktop- und Web-Oberflächen, verarbeitet sie öffentliche Steam-Web-API-Daten und offizielle Game-State-Integration-Feeds, anstatt Spielspeicher auszulesen oder Code zu injizieren. Die Verdachts-Engine führt rund dreißig Detektoren über Zielen, Waffen, Kontometadaten, Live-Verhalten, Konsistenz, Progressionsdrift und Bannhistorie aus und bewertet Spieler mit 0–100 Punkten unter Verwendung bayesscher Glättung und Multi-Signal-Bestätigung. Ein natives C++-Ingame-Overlay kann Live-Scores und das Risiko pro Spieler während Matches anzeigen. Das Tool richtet sich an Wettkampfspieler, Analysten und Game-Security-Forscher, die eine transparente, statistische Cheat-Risikobewertung auf Basis beobachtbarer Daten statt clientseitiger Durchsetzung wünschen.
