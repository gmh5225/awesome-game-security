CS2 Tracker 是一款面向 Counter-Strike 2 的 Windows 应用程序，整合了玩家生涯统计数据、实时比赛追踪以及可解释的启发式反作弊分析引擎。该工具主要使用 Python 编写，提供 FastAPI 本地 REST API、SQLite 存储以及可选的 Qt 桌面和 Web 界面，通过公开的 Steam Web API 数据和官方 Game State Integration 数据源获取信息，而非读取游戏内存或注入代码。其可疑度引擎在瞄准、武器、账户元数据、实时行为、一致性、进步漂移和封禁历史等维度运行约三十个检测器，采用贝叶斯平滑和多信号交叉验证，为玩家打出 0–100 分。原生 C++ 游戏内 overlay 可在比赛期间显示实时分数和每位玩家的风险等级。该工具面向竞技玩家、分析师和游戏安全研究人员，提供基于可观测数据的透明、统计化作弊风险评估，而非客户端侧的强制执行。
