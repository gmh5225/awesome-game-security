CS2 Tracker is a Windows application for Counter-Strike 2 that combines lifetime player statistics, live match tracking, and an explainable heuristic anti-cheat analysis engine. Written primarily in Python with a FastAPI local REST API, SQLite storage, and optional Qt desktop and web interfaces, it ingests public Steam Web API data and official Game State Integration feeds rather than reading game memory or injecting code. Its suspicion engine runs roughly thirty detectors across aim, weapons, account metadata, live behavior, consistency, progression drift, and ban history, scoring players 0–100 with Bayesian smoothing and multi-signal corroboration. A native C++ in-game overlay can display live scores and per-player risk during matches. The tool targets competitive players, analysts, and game-security researchers who want transparent, statistical cheat-risk assessment based on observable data instead of client-side enforcement.
