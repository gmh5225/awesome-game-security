CS2 Tracker는 Counter-Strike 2용 Windows 애플리케이션으로, 플레이어의 전체 통계, 실시간 매치 추적, 설명 가능한 휴리스틱 안티치트 분석 엔진을 결합합니다. 주로 Python으로 작성되었으며 FastAPI 로컬 REST API, SQLite 저장소, 선택적 Qt 데스크톱 및 웹 인터페이스를 제공하고, 게임 메모리를 읽거나 코드를 주입하는 대신 공개 Steam Web API 데이터와 공식 Game State Integration 피드를 수집합니다. 의심 엔진은 에임, 무기, 계정 메타데이터, 실시간 행동, 일관성, 진행 드리프트, 밴 기록 등 약 30개의 탐지기를 실행하며, 베이지안 스무딩과 다중 신호 상호 검증으로 플레이어에게 0–100점을 부여합니다. 네이티브 C++ 인게임 오버레이는 경기 중 실시간 점수와 플레이어별 위험도를 표시할 수 있습니다. 이 도구는 클라이언트 측 강제가 아닌 관측 가능한 데이터 기반의 투명하고 통계적인 치트 위험 평가를 원하는 경쟁 플레이어, 분석가, 게임 보안 연구자를 대상으로 합니다.
