CS2 Tracker — это приложение для Windows для Counter-Strike 2, объединяющее статистику игроков за всё время, отслеживание матчей в реальном времени и объяснимый эвристический движок античит-анализа. Написано преимущественно на Python с локальным REST API на FastAPI, хранилищем SQLite и опциональными настольным Qt- и веб-интерфейсами; получает данные из публичного Steam Web API и официальных каналов Game State Integration, а не читает память игры и не внедряет код. Движок подозрений запускает около тридцати детекторов по прицеливанию, оружию, метаданным аккаунта, поведению в реальном времени, согласованности, дрейфу прогресса и истории банов, выставляя игрокам оценки 0–100 с байесовским сглаживанием и взаимным подтверждением нескольких сигналов. Нативный внутриигровой оверлей на C++ может отображать живые оценки и риск по каждому игроку во время матчей. Инструмент ориентирован на соревновательных игроков, аналитиков и исследователей игровой безопасности, которым нужна прозрачная статистическая оценка риска читерства на основе наблюдаемых данных, а не клиентское принуждение.
