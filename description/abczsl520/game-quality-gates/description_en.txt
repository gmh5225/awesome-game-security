Game Quality Gates is a documented quality standard and OpenClaw agent skill for HTML5, Canvas, and WebGL games, encoding prevention patterns from dozens of production bugs into twelve universal rules. It covers lifecycle and state cleanup, frame-rate independent logic, audio and input safety, save versioning, network fault tolerance, asset loading, and a baseline anti-cheat posture that treats the client as untrusted. Engine-specific reference guides extend those rules for Phaser 3 arcade physics and Three.js WebGL, including disposal, compression, and animation patterns, plus dedicated anti-cheat guidance such as one-time raid tokens, duration and score sanity checks, and atomic purchase flows. The material is aimed at game developers and reviewers who want a pre-deploy checklist and practical patterns to avoid combination bugs, memory leaks, double-spend exploits, and trivial score or payment bypass in browser-based games.
