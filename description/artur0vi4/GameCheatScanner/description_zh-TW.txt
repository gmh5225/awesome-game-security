GameCheat Scanner 是一款 Python 桌面工具，用於在行程記憶體中尋找並編輯遊戲內數值，可作為 ArtMoney 或 Cheat Engine 的替代方案，適用於單機與教育用途。它在 Windows 10 與 11 上執行以 Tkinter 為基礎的圖形介面，透過 WinAPI 與 ctypes 附加至遊戲行程，並可用 PyInstaller 封裝為獨立可執行檔。掃描器可同時對多種整數與浮點編碼進行 little-endian 與 big-endian 搜尋，再以類似 Cheat Engine 的已變更/未變更掃描、numpy 加速的記憶體差分，以及針對生命、彈藥、貨幣等常見屬性的可選簽名分類來縮小結果。非 Windows 主機使用內建模擬行程練習工作流程，無需真實記憶體存取。本專案旨在模組製作、逆向工程練習與離線實驗，而非線上競技或規避反作弊。
