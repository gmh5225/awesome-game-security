GameCheat Scanner is a Python desktop tool for finding and editing in-game values in process memory, styled as an ArtMoney or Cheat Engine alternative for single-player and educational use. It runs a Tkinter GUI on Windows 10 and 11, attaching to game processes through WinAPI and ctypes, and can be packaged as a standalone executable with PyInstaller. Its scanner searches one input across many integer and floating-point encodings in little- and big-endian at once, then narrows results with Cheat Engine–style changed and unchanged scans, numpy-accelerated memory diffs, and optional signature-based classification of common stats such as health, ammo, and currency. Non-Windows hosts use a built-in mock process to practice the workflow without real memory access. The project is intended for modding, reverse-engineering practice, and offline experimentation rather than online competitive play or anti-cheat evasion.
