GameCheat Scanner は、プロセスメモリ上のゲーム内数値を検索・編集する Python 製デスクトップツールで、シングルプレイや学習用途向けに ArtMoney や Cheat Engine の代替として設計されています。Windows 10 および 11 上で Tkinter の GUI を動かし、WinAPI と ctypes でゲームプロセスにアタッチし、PyInstaller でスタンドアロン実行ファイルにパッケージ化できます。スキャナは1つの入力を複数の整数・浮動小数点エンコーディングについてリトルエンディアンとビッグエンディアンの両方で同時に検索し、Cheat Engine 風の変更/未変更スキャン、numpy による高速メモリ差分、体力・弾薬・通貨など一般的なステータス向けの任意のシグネチャ分類で絞り込みます。非 Windows 環境では実メモリアクセスなしでワークフローを練習できる組み込みモックプロセスを使います。本プロジェクトは MOD 制作、リバースエンジニアリングの演習、オフライン実験を目的とし、オンライン対戦やアンチチート回避を想定していません。
