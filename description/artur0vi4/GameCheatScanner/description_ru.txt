GameCheat Scanner — настольная утилита на Python для поиска и изменения игровых значений в памяти процессов, задуманная как альтернатива ArtMoney или Cheat Engine для одиночной игры и обучения. На Windows 10 и 11 запускается графический интерфейс на Tkinter, подключение к игровым процессам через WinAPI и ctypes; проект можно собрать в автономный исполняемый файл с помощью PyInstaller. Сканер одновременно ищет одно введённое значение среди множества целочисленных и вещественных представлений в форматах little-endian и big-endian, затем сужает выборку сканированием в духе Cheat Engine на изменённые и неизменённые значения, ускоренным сравнением памяти через numpy и опциональной классификацией по сигнатурам для типичных параметров вроде здоровья, боеприпасов и валюты. На не-Windows используется встроенный имитатор процесса для отработки сценария без реального доступа к памяти. Проект предназначен для моддинга, практики реверс-инжиниринга и офлайн-экспериментов, а не для онлайн-соревнований или обхода античита.
