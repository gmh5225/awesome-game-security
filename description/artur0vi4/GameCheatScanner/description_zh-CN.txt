GameCheat Scanner 是一款 Python 桌面工具，用于在进程内存中查找并修改游戏内数值，可作为 ArtMoney 或 Cheat Engine 的替代方案，面向单机与教育用途。它在 Windows 10 和 11 上运行基于 Tkinter 的图形界面，通过 WinAPI 与 ctypes 附加到游戏进程，并可用 PyInstaller 打包为独立可执行文件。扫描器可同时对多种整型与浮点编码进行小端与大端搜索，随后通过类似 Cheat Engine 的“已变化/未变化”扫描、numpy 加速的内存差分，以及针对生命、弹药、货币等常见属性的可选签名分类来缩小结果。非 Windows 主机使用内置模拟进程练习操作流程，无需真实内存访问。本项目面向模组、逆向练习与离线实验，而非在线竞技或规避反作弊。
