本儲存庫發布對 Ocean Anti-Cheat Windows 用戶端（ocean.exe）的長篇靜態分析；該第三方掃描工具常被 Minecraft 與 FiveM 社群使用。研究透過以 Unicorn 為基礎的脫殼、Python API 樁程式碼以及大規模 Ghidra 反編譯，逆向分析受 VMProtect 與 garble 保護的 Go 二進位檔，且未在真實系統上執行樣本。文件涵蓋十六條用戶端—伺服器通道、CryptoJS 密碼加密等薄弱協定保護、重新導向 URL 簽署，以及由百萬項正弦求和從伺服器時間衍生的偵測金鑰，並審視 OceanGraper 核心驅動程式、資料外洩，以及隱私權政策聲明與實際行為的對比。面向遊戲安全研究人員、逆向工程師，以及希望以證據為基礎了解此類反作弊掃描器如何運作、會在 PC 上留下何物的玩家。
