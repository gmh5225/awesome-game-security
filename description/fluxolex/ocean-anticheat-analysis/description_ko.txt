이 저장소는 Minecraft 및 FiveM 커뮤니티에서 자주 쓰이는 서드파티 스캔 도구인 Ocean Anti-Cheat Windows 클라이언트(ocean.exe)에 대한 장문의 정적 분석을 공개한다. VMProtect와 garble로 보호된 Go 바이너리를 Unicorn 기반 언패킹, Python API 스텁, 대규모 Ghidra 디컴파일로 리버스 엔지니어링했으며, 실제 시스템에서 샘플을 실행하지 않았다. 열여섯 개의 클라이언트-서버 채널, CryptoJS 비밀번호 암호화 같은 취약한 프로토콜 보호, 리다이렉트 URL 서명, 백만 항 사인 합으로 서버 시간에서 파생된 탐지 키를 문서화하고, OceanGraper 커널 드라이버, 데이터 유출, 개인정보 처리방침 주장과 관측된 동작을 대조해 검토한다. 게임 보안 연구자, 리버스 엔지니어, 이러한 안티치트 스캐너의 작동 방식과 PC에 남기는 흔적에 대해 근거 기반의 이해를 원하는 플레이어를 대상으로 한다.
