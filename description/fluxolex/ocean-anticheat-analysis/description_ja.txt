本リポジトリは、Minecraft や FiveM コミュニティでよく使われる第三者スキャンツールである Ocean Anti-Cheat の Windows クライアント（ocean.exe）に関する長編の静的解析を公開している。VMProtect と garble で保護された Go バイナリを、Unicorn ベースのアンパック、Python API スタブ、大規模な Ghidra 逆コンパイルによりリバースエンジニアリングしており、生きたシステム上でサンプルを実行することはない。十六のクライアント—サーバー間チャネル、CryptoJS によるパスワード暗号化のような脆弱なプロトコル保護、リダイレクト URL の署名、百万項の正弦和からサーバー時刻で導出される検出キーについて記述し、OceanGraper カーネルドライバ、データの持ち出し、プライバシーポリシーの主張と観測された挙動の対比も検討する。ゲームセキュリティ研究者、リバースエンジニア、およびこの種のアンチチートスキャナの仕組みと PC に残す痕跡について証拠に基づく見方を求めるプレイヤーを対象としている。
