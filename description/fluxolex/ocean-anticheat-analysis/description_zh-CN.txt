本仓库发布对 Ocean Anti-Cheat Windows 客户端（ocean.exe）的长篇静态分析；该第三方扫描工具常被 Minecraft 与 FiveM 社区使用。研究通过基于 Unicorn 的脱壳、Python API 桩代码以及大规模 Ghidra 反编译，逆向分析受 VMProtect 与 garble 保护的 Go 二进制，且未在真实系统上运行样本。文档涵盖十六条客户端—服务器通道、CryptoJS 密码加密等薄弱协议保护、重定向 URL 签名，以及由百万项正弦求和从服务器时间派生的检测密钥，并审视 OceanGraper 内核驱动、数据外泄，以及隐私政策声明与实际行为的对比。面向游戏安全研究人员、逆向工程师，以及希望基于证据了解此类反作弊扫描器如何运作、会在 PC 上留下何物的玩家。
