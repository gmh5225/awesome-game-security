This repository publishes a long-form static analysis of the Ocean Anti-Cheat Windows client (ocean.exe), the third-party scan tool often used by Minecraft and FiveM communities. The work reverse engineers a Go binary protected with VMProtect and garble using Unicorn-based unpacking, Python API stubs, and large-scale Ghidra decompilation without running the sample on a live system. It documents sixteen client-server channels, weak protocol protections such as CryptoJS password encryption, redirect URL signing, and detection keys derived from server time via a million-term sine sum, and it examines the OceanGraper kernel driver, data exfiltration, and privacy-policy claims versus observed behavior. It is aimed at game security researchers, reverse engineers, and players who want an evidence-based view of how such anti-cheat scanners work and what they leave behind on a PC.
