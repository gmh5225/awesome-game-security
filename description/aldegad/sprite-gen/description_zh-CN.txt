该项目是一个 Python CLI 和 AI 编程代理技能，可将一张基础角色图像转换为可直接用于游戏的透明精灵图集或动作循环。它通过 Codex、OpenAI、Grok Imagine 等提供方驱动图像与视频生成，逐行锁定角色身份，将色度键背景转换为真正的 alpha 通道，提取干净帧，并生成带有可机器读取的 manifest.json 帧布局的运行时图集。独立的视频流水线可为每种动作状态生成无缝透明 GIF、WebP 或帧序列循环，并提供可选的筛选工具，用于在导出前对比、拒绝和调整帧。基于 Python、Pillow 和 NumPy 构建，它还支持重新着色、图层合成、像素网格对齐，并可导出到 Aseprite、Phaser、Flame 等引擎。面向需要以生成式模型产出可用于生产的 2D 精灵图，而非无法使用的演示图集的游戏开发者和资产流水线。
