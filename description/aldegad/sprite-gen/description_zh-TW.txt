此專案是一個 Python CLI 與 AI 程式設計代理技能，可將一張基礎角色圖像轉換為可直接用於遊戲的透明精靈圖集或動作循環。它透過 Codex、OpenAI、Grok Imagine 等提供方驅動影像與影片生成，逐列鎖定角色身份，將色度鍵背景轉換為真正的 alpha 通道，擷取乾淨幀，並產生帶有可機器讀取的 manifest.json 幀配置之執行階段圖集。獨立的影片管線可為每種動作狀態生成無縫透明 GIF、WebP 或幀序列循環，並提供可選的篩選工具，用於在匯出前比對、拒絕與調整幀。以 Python、Pillow 與 NumPy 建構，亦支援重新著色、圖層合成、像素網格對齊，並可匯出至 Aseprite、Phaser、Flame 等引擎。面向需要以生成式模型產出可用於正式製作的 2D 精靈圖，而非無法使用的示範圖集之遊戲開發者與資產管線。
