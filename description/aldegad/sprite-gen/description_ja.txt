このプロジェクトは Python CLI および AI コーディングエージェントスキルで、1 枚のベースキャラクター画像からゲーム向けの透過スプライトアトラスやモーションループを生成します。Codex、OpenAI、Grok Imagine などのプロバイダーを通じて画像・動画生成を駆動し、行ごとにキャラクターの同一性を固定し、クロマキー背景を実際のアルファに変換し、クリーンなフレームを抽出して、機械可読な manifest.json フレームレイアウト付きのランタイムアトラスを生成します。別の動画パイプラインは、各モーション状態ごとにシームレスな透過 GIF、WebP、またはフレームストリップループを生成し、エクスポート前にフレームを比較・却下・微調整するためのオプションのキュレーションツールも提供します。Python、Pillow、NumPy で構築され、再着色、レイヤー合成、ピクセルグリッド整列にも対応し、Aseprite、Phaser、Flame などのエンジンへエクスポートできます。生成モデルから使い物にならないデモシートではなく、本番品質の 2D スプライトを必要とするゲーム開発者やアセットパイプライン向けです。
