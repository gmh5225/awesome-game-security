KernBox is an open-source Android isolation framework for rooted ARM64 phones that builds a stealthy, leak-resistant workspace inside an Android Work Profile enforced at the kernel and system layer. It is delivered as compile-time-specialized root-module builds for multiple OEM, kernel, and root-manager combinations, together with a pure-SDK controller app and a twelve-point verification probe. The stack is implemented primarily in Go, C, C++, and Java, combining fail-closed Netfilter and TProxy routing, a least-privilege broker and guard daemon, Zygisk native PLT hooks, and Binder proxies that sanitize connectivity and Work Profile APIs seen by sandboxed processes. Hot-freeze and memory reclaim reduce idle drain while regional presets keep locale and carrier semantics coherent for isolated apps and GMS. It suits game security, anti-cheat, and mobile reverse-engineering practitioners who need strong sandbox boundaries, traffic isolation, and resistance to in-app environment fingerprinting on a single device.
