KernBox es un framework de aislamiento de código abierto para teléfonos Android ARM64 con root que construye un espacio de trabajo sigiloso y resistente a fugas dentro de un Android Work Profile reforzado a nivel de kernel y sistema. Se entrega como compilaciones de módulos root especializadas en tiempo de compilación para múltiples combinaciones de OEM, kernel y gestores de root, junto con una aplicación controladora de SDK puro y una sonda de verificación de doce puntos. La pila está implementada principalmente en Go, C, C++ y Java, combinando enrutamiento Netfilter y TProxy fail-closed, un broker y daemon guard de mínimos privilegios, hooks PLT nativos Zygisk y proxies Binder que sanean la conectividad y las API de Work Profile vistas por procesos en sandbox. El congelado en caliente y la recuperación de memoria reducen el consumo en inactividad, mientras que los ajustes regionales mantienen coherentes la configuración regional y la semántica del operador para apps aisladas y GMS. Está orientado a profesionales de seguridad de juegos, anti-cheat e ingeniería inversa móvil que necesitan límites de sandbox fuertes, aislamiento de tráfico y resistencia al fingerprinting del entorno in-app en un solo dispositivo.
