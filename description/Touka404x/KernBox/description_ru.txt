KernBox — это фреймворк с открытым исходным кодом для изоляции на рутированных ARM64-телефонах Android, создающий скрытное, устойчивое к утечкам рабочее пространство внутри Android Work Profile, принудительно обеспечиваемого на уровне ядра и системы. Поставляется как специализированные на этапе компиляции сборки root-модулей для разных сочетаний OEM, ядра и root-менеджеров, вместе с чисто SDK-приложением-контроллером и двенадцатиточечным проверочным зондом. Стек в основном реализован на Go, C, C++ и Java и объединяет fail-closed маршрутизацию Netfilter и TProxy, брокер и guard-демон с минимальными привилегиями, нативные PLT-хуки Zygisk и Binder-прокси, очищающие сетевую связность и API Work Profile для процессов в песочнице. Горячая заморозка и возврат памяти снижают простойный расход, а региональные пресеты сохраняют согласованность локали и семантики оператора для изолированных приложений и GMS. Подходит специалистам по безопасности игр, античиту и мобильному реверс-инжинирингу, которым нужны жёсткие границы песочницы, изоляция трафика и устойчивость к отпечаткованию in-app окружения на одном устройстве.
