KernBox は、root 済み ARM64 Android 端末向けのオープンソース隔離フレームワークで、カーネルおよびシステム層で強制される Android Work Profile 内に、ステルス性と漏洩耐性のあるワークスペースを構築します。複数の OEM・カーネル・root マネージャの組み合わせ向けにコンパイル時特化された root モジュールビルドとして提供され、純 SDK のコントローラアプリと 12 項目の検証プローブを同梱します。実装は主に Go、C、C++、Java で、fail-closed な Netfilter と TProxy ルーティング、最小権限の broker と guard デーモン、Zygisk ネイティブ PLT フック、サンドボックス化プロセスから見える接続性と Work Profile API をサニタイズする Binder プロキシを組み合わせています。ホットフリーズとメモリ回収でアイドル時の消費を抑え、地域プリセットで隔離アプリと GMS のロケールとキャリア意味論を一貫させます。強いサンドボックス境界、トラフィック隔離、単一端末上でのアプリ内環境フィンガープリントへの耐性が求められるゲームセキュリティ、チート対策、モバイルリバースエンジニアリングの実務者向けです。
