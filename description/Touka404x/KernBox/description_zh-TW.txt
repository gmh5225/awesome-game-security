KernBox 是一款面向已 root 的 ARM64 Android 手機的開源隔離框架，在核心與系統層強制的 Android Work Profile 內建構隱匿、抗洩漏的工作空間。它以針對多種 OEM、核心與 root 管理器組合的編譯期特化 root 模組建置形式交付，並配有純 SDK 控制器應用與十二項驗證探針。技術棧主要以 Go、C、C++ 與 Java 實作，整合 fail-closed 的 Netfilter 與 TProxy 路由、最小權限 broker 與 guard 守護程式、Zygisk 原生 PLT 掛鉤，以及淨化沙箱程序所見的連線性與 Work Profile API 的 Binder 代理。熱凍結與記憶體回收可降低閒置耗電，區域預設則使隔離應用與 GMS 的語言區域與電信業者語意保持一致。適用於需要強沙箱邊界、流量隔離，以及單一裝置上抵禦應用內環境指紋辨識的遊戲安全、反作弊與行動逆向工程實務者。
