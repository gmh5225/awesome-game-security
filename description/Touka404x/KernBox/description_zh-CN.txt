KernBox 是一款面向已 root 的 ARM64 Android 手机的开源隔离框架，在内核与系统层强制的 Android Work Profile 内构建隐匿、抗泄漏的工作空间。它以针对多种 OEM、内核与 root 管理器组合的编译期特化 root 模块构建形式交付，并配有纯 SDK 控制器应用与十二项验证探针。技术栈主要以 Go、C、C++ 与 Java 实现，整合 fail-closed 的 Netfilter 与 TProxy 路由、最小权限 broker 与 guard 守护进程、Zygisk 原生 PLT 钩子，以及净化沙箱进程所见的连接性与 Work Profile API 的 Binder 代理。热冻结与内存回收可降低空闲耗电，区域预设则使隔离应用与 GMS 的语言区域与运营商语义保持一致。适用于需要强沙箱边界、流量隔离，以及单设备上抵御应用内环境指纹识别的游戏安全、反作弊与移动逆向工程实践者。
