Reverify 是一个 Python 工具包，通过将语言模型关于二进制文件的断言与实际字节进行对照，而非单独依赖模型输出，从而为 AI 辅助逆向工程提供可靠依据。它提供 PE、ELF 和 Mach-O 解析、反汇编、CPU 仿真、模式扫描、协议解析、Frida 钩子生成，以及一个确定性的断言验证器，可返回 VERIFIED、REFUTED 或 INCONCLUSIVE 及相应观测证据。重建代理驱动一个闭环反馈流程：模型提出可检验的假设，验证器驳斥幻觉，已确认事实账本仅保留经工具验证的结果，并可通过 Unicorn 仿真进行可选的行为等价性检查。Capstone、Unicorn 和 LIEF 后端扩展纯 Python 核心，MCP 服务器与 CLI 则将这些工具暴露给编程代理。它面向经授权的逆向工程场景，如恶意软件分析、CTF 解题和互操作性研究，在这些场景中 AI 重建结果必须对照真实二进制数据进行验证。
