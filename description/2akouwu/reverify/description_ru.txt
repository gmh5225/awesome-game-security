Reverify — это набор инструментов на Python, который обосновывает обратную разработку с помощью ИИ, сверяя утверждения языковой модели о бинарниках с реальными байтами, а не полагаясь только на вывод модели. В него входят разбор PE, ELF и Mach-O, дизассемблирование, эмуляция CPU, поиск шаблонов, разбор протоколов, генерация хуков Frida и детерминированный верификатор утверждений, возвращающий VERIFIED, REFUTED или INCONCLUSIVE с наблюдаемыми доказательствами. Агент реконструкции управляет замкнутым циклом обратной связи: модель предлагает проверяемые гипотезы, верификатор опровергает галлюцинации, а реестр установленных фактов сохраняет только результаты, подтверждённые инструментами, с необязательными проверками поведенческой эквивалентности через эмуляцию Unicorn. Бэкенды Capstone, Unicorn и LIEF расширяют чистое Python-ядро, а MCP-сервер и CLI предоставляют инструменты агентам для кодирования. Предназначен для авторизованной обратной разработки — анализа вредоносного ПО, CTF и исследований совместимости, где ИИ-реконструкции должны проверяться по реальным бинарным данным.
