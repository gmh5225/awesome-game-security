Reverify は、言語モデルがバイナリについて述べる主張をモデル出力だけを信頼するのではなく実際のバイト列と照合することで、AI 支援のリバースエンジニアリングに根拠を与える Python ツールキットです。PE、ELF、Mach-O の解析、逆アセンブル、CPU エミュレーション、パターンスキャン、プロトコル解析、Frida フック生成、および VERIFIED、REFUTED、INCONCLUSIVE と観測証拠を返す決定論的な主張検証器を同梱しています。再構築エージェントは閉ループのフィードバックを駆動し、モデルが検証可能な仮説を提案し、検証器が幻覚を反証し、確立済み事実台帳はツールに基づいた結果のみを引き継ぎ、Unicorn エミュレーションによる任意の振る舞い等価性チェックも可能です。Capstone、Unicorn、LIEF バックエンドが純 Python コアを拡張し、MCP サーバーと CLI がコーディングエージェント向けにツールを公開します。マルウェア解析、CTF、相互運用性研究など、AI による再構築を実際のバイナリデータで検証する必要がある、許可されたリバースエンジニアリングを対象としています。
