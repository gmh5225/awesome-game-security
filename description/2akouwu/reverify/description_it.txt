Reverify è un toolkit Python che fonda il reverse engineering assistito dall'IA verificando le affermazioni del modello linguistico sui binari contro i byte reali, invece di fidarsi solo dell'output del modello. Offre parsing PE, ELF e Mach-O, disassemblaggio, emulazione CPU, scansione di pattern, parsing di protocolli, generazione di hook Frida e un verificatore deterministico di affermazioni che restituisce VERIFIED, REFUTED o INCONCLUSIVE con evidenze osservate. Un agente di ricostruzione guida un ciclo di feedback chiuso in cui il modello propone ipotesi verificabili, il verificatore confuta le allucinazioni e un registro di fatti stabiliti trasporta avanti solo risultati ancorati agli strumenti, con controlli opzionali di equivalenza comportamentale tramite emulazione Unicorn. I backend Capstone, Unicorn e LIEF estendono il nucleo Python puro, e un server MCP più una CLI espongono gli strumenti agli agenti di coding. È destinato al reverse engineering autorizzato, come analisi di malware, lavoro CTF e ricerca sull'interoperabilità, dove le ricostruzioni IA devono essere validate rispetto a dati binari reali.
