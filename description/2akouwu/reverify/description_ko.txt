Reverify는 언어 모델이 바이너리에 대해 주장하는 내용을 모델 출력만 신뢰하는 대신 실제 바이트와 대조하여 AI 지원 리버스 엔지니어링에 근거를 제공하는 Python 툴킷입니다. PE, ELF, Mach-O 파싱, 디스어셈블리, CPU 에뮬레이션, 패턴 스캔, 프로토콜 파싱, Frida 훅 생성, 그리고 VERIFIED, REFUTED, INCONCLUSIVE와 관측 증거를 반환하는 결정론적 주장 검증기를 제공합니다. 재구성 에이전트는 폐쇄형 피드백 루프를 구동하며, 모델이 검증 가능한 가설을 제안하고 검증기가 환각을 반박하며, 확립된 사실 원장은 도구 기반 결과만 이어가고 Unicorn 에뮬레이션을 통한 선택적 행위 동등성 검사도 지원합니다. Capstone, Unicorn, LIEF 백엔드가 순수 Python 코어를 확장하고, MCP 서버와 CLI가 코딩 에이전트에 도구를 노출합니다. 악성코드 분석, CTF, 상호운용성 연구 등 AI 재구성을 실제 바이너리 데이터로 검증해야 하는 승인된 리버스 엔지니어링을 대상으로 합니다.
