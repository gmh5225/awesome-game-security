Reverify 是一套 Python 工具包，透過將語言模型對二進位檔案的斷言與實際位元組對照，而非單獨依賴模型輸出，為 AI 輔助逆向工程提供可靠依據。它提供 PE、ELF 與 Mach-O 解析、反組譯、CPU 模擬、模式掃描、協定解析、Frida 掛鉤產生，以及一個確定性的斷言驗證器，可回傳 VERIFIED、REFUTED 或 INCONCLUSIVE 及對應的觀測證據。重建代理驅動一個閉環回饋流程：模型提出可檢驗的假設，驗證器駁斥幻覺，已確認事實帳本僅保留經工具驗證的結果，並可透過 Unicorn 模擬進行可選的行為等價性檢查。Capstone、Unicorn 與 LIEF 後端擴充純 Python 核心，MCP 伺服器與 CLI 則將這些工具暴露給程式設計代理。它面向經授權的逆向工程場景，如惡意軟體分析、CTF 解題與互通性研究，在這些場景中 AI 重建結果必須對照真實二進位資料進行驗證。
