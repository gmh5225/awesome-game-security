BottleShip 是一款基于浏览器的引擎，通过将 v86 CPU 仿真与 Win32、COM 以及 DirectDraw/Direct3D 的高级仿真相结合，并映射到现代 Web API，从而运行传统的 x86 Windows 游戏。代码库以 TypeScript 为主，核心为 Rust 编译的 WASM v86，图形管线使用 WebGPU 处理固定功能的 Direct3D 状态，虚拟文件系统基于 OPFS，支持 WGB 游戏包与 GOG 导入。项目提供忠实的 WinAPI 模块实现、常见安装包与归档格式的自托管解析器，以及可加载游戏、驱动输入并捕获结构化调试快照的自动化测试框架。面向从事兼容性工作、游戏保存，以及在不依赖原生 Windows 机器的情况下深入研究 Windows 游戏如何调用操作系统、图形、音频与线程层的开发者。
