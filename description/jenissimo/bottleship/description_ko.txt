BottleShip은 v86 CPU 에뮬레이션과 Win32, COM, DirectDraw/Direct3D의 고수준 에뮬레이션을 현대 Web API와 결합해 레거시 x86 Windows 게임을 브라우저에서 실행하는 엔진입니다. 코드베이스는 주로 TypeScript이며, Rust에서 WASM으로 빌드한 v86 코어, 고정 기능 Direct3D 상태용 WebGPU 그래픽 파이프라인, WGB 게임 번들과 GOG 가져오기를 지원하는 OPFS 기반 가상 파일 시스템으로 구성됩니다. WinAPI 모듈의 충실한 구현, 일반적인 설치 프로그램 및 아카이브 형식용 자체 호스팅 파서, 타이틀 로드·입력 구동·구조화된 디버그 스냅샷 캡처가 가능한 자동화 하네스를 제공합니다. 네이티브 Windows 머신 없이 호환성 작업, 게임 보존, Windows 게임이 OS·그래픽·오디오·스레딩 계층을 어떻게 호출하는지 깊이 연구하는 개발자를 대상으로 합니다.
