BottleShip はブラウザ上で動作するエンジンで、v86 CPU エミュレーションと Win32、COM、DirectDraw/Direct3D の高レベルエミュレーションを組み合わせ、現代の Web API 上でレガシーな x86 Windows ゲームを実行します。コードベースは主に TypeScript で、Rust から WASM にコンパイルした v86 コア、固定機能 Direct3D 状態向けの WebGPU グラフィックスパイプライン、WGB ゲームバンドルと GOG インポートに対応した OPFS ベースの仮想ファイルシステムで構成されています。WinAPI モジュールの忠実な実装、一般的なインストーラーとアーカイブ形式向けのセルフホスト型パーサー、タイトルの読み込み、入力の駆動、構造化デバッグスナップショットの取得ができる自動化ハーネスを同梱しています。ネイティブな Windows マシンに頼らず、互換性作業、ゲーム保存、Windows ゲームが OS・グラフィックス・オーディオ・スレッド層をどう呼び出すかを深く研究する開発者を対象としています。
