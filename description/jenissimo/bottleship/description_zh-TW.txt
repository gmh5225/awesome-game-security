BottleShip 是一款以瀏覽器為基礎的引擎，透過將 v86 CPU 模擬與 Win32、COM 以及 DirectDraw/Direct3D 的高階模擬相結合，並對應到現代 Web API，從而執行傳統的 x86 Windows 遊戲。程式碼庫以 TypeScript 為主，核心為 Rust 編譯的 WASM v86，圖形管線使用 WebGPU 處理固定功能的 Direct3D 狀態，虛擬檔案系統基於 OPFS，支援 WGB 遊戲包與 GOG 匯入。專案提供忠實的 WinAPI 模組實作、常見安裝程式與封存格式的自託管解析器，以及可載入遊戲、驅動輸入並擷取結構化除錯快照的自動化測試框架。面向從事相容性工作、遊戲保存，以及在不依賴原生 Windows 機器的情況下深入研究 Windows 遊戲如何呼叫作業系統、圖形、音訊與執行緒層的開發者。
