BottleShip est un moteur exécutable dans le navigateur qui fait tourner d’anciens jeux Windows x86 en associant l’émulation CPU v86 à une émulation de haut niveau de Win32, COM et DirectDraw/Direct3D sur les API Web modernes. La base de code est surtout en TypeScript, avec un noyau v86 Rust compilé en WASM, un pipeline graphique WebGPU pour les états Direct3D à fonction fixe, et un système de fichiers virtuel basé sur OPFS avec bundles de jeux WGB et import GOG. Il inclut des implémentations fidèles de modules WinAPI, des analyseurs auto-hébergés pour les formats d’installateur et d’archives courants, et un banc d’essai automatisé qui charge les titres, pilote les entrées et capture des instantanés de débogage structurés. Le projet s’adresse aux développeurs travaillant sur la compatibilité, la préservation des jeux et l’étude approfondie de la façon dont les jeux Windows appellent l’OS, la graphique, l’audio et les threads sans machine Windows native.
