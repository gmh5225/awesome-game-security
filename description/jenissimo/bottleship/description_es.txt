BottleShip es un motor basado en el navegador que ejecuta juegos Windows x86 heredados combinando la emulación de CPU v86 con emulación de alto nivel de Win32, COM y DirectDraw/Direct3D sobre APIs web modernas. La base de código es principalmente TypeScript, con un núcleo v86 de Rust a WASM, una canalización gráfica WebGPU para estados Direct3D de función fija y un sistema de archivos virtual respaldado por OPFS con paquetes de juegos WGB e importación desde GOG. Incluye implementaciones fieles de módulos WinAPI, analizadores autohospedados para formatos habituales de instaladores y archivos, y un marco de automatización que carga títulos, controla la entrada y captura instantáneas de depuración estructuradas. El proyecto está dirigido a desarrolladores que trabajan en compatibilidad, preservación de juegos y el estudio profundo de cómo los juegos Windows invocan el SO, gráficos, audio e hilos sin depender de una máquina Windows nativa.
