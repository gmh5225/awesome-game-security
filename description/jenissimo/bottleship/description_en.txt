BottleShip is a browser-based engine that runs legacy x86 Windows games by pairing v86 CPU emulation with high-level emulation of Win32, COM, and DirectDraw/Direct3D on modern web APIs. The codebase is mainly TypeScript with a Rust-to-WASM v86 core, a WebGPU graphics pipeline for fixed-function Direct3D states, and an OPFS-backed virtual filesystem with WGB game bundles and GOG import support. It ships faithful WinAPI module implementations, self-hosted parsers for common installer and archive formats, and an automation harness that loads titles, drives input, and captures structured debug snapshots. The project targets developers doing compatibility work, game preservation, and deep study of how Windows games call the OS, graphics, audio, and threading layers without relying on a native Windows machine.
