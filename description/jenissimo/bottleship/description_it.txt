BottleShip è un motore basato sul browser che esegue giochi Windows x86 legacy accoppiando l’emulazione CPU v86 con emulazione ad alto livello di Win32, COM e DirectDraw/Direct3D su API web moderne. Il codice è principalmente TypeScript, con un core v86 Rust compilato in WASM, una pipeline grafica WebGPU per stati Direct3D a funzione fissa e un filesystem virtuale basato su OPFS con bundle di gioco WGB e import da GOG. Include implementazioni fedeli dei moduli WinAPI, parser self-hosted per formati comuni di installer e archivi, e un harness di automazione che carica i titoli, guida l’input e cattura snapshot di debug strutturati. Il progetto è rivolto a sviluppatori che lavorano su compatibilità, preservazione dei giochi e lo studio approfondito di come i giochi Windows chiamano OS, grafica, audio e threading senza affidarsi a una macchina Windows nativa.
