GhostLock is a native Android kernel exploit that gains root access and installs KernelSU on OnePlus, OPPO, and realme devices without unlocking the bootloader or modifying the boot image. It targets CVE-2026-43499, a futex priority-inheritance use-after-free in the Linux kernel, combining pselect6 stack overlay with controlled rb-tree writes to achieve precise kernel memory corruption. The project is implemented primarily in C with the Android NDK and includes Python tooling for kernel symbol extraction, stack-layout feasibility checks, and per-device offset tables for multiple SoCs and GKI versions. It supports dual exploitation paths, UMH injection via ashmem miscdevice redirection or direct credential patching, and is aimed at mobile security researchers studying locked-bootloader bypass, kernel exploitation, and post-exploit root persistence on hardened Android builds.
