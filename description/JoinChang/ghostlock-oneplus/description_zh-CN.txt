GhostLock 是一款原生 Android 内核漏洞利用工具，可在不解锁引导加载程序、不修改启动镜像的情况下，在 OnePlus、OPPO 和 realme 设备上获取 root 权限并安装 KernelSU。它针对 CVE-2026-43499——Linux 内核中 futex 优先级继承的释放后使用漏洞，结合 pselect6 栈覆盖与受控 rb-tree 写入，实现精确的内核内存破坏。该项目主要使用 C 语言和 Android NDK 实现，并包含用于内核符号提取、栈布局可行性检查以及针对多种 SoC 和 GKI 版本的逐设备偏移表的 Python 工具。它支持双利用路径：通过 ashmem miscdevice 重定向进行 UMH 注入，或直接修补凭证，面向研究锁定引导加载程序绕过、内核漏洞利用以及加固 Android 构建上漏洞利用后 root 持久化的移动安全研究人员。
