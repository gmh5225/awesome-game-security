GhostLock 是一款原生 Android 核心漏洞利用工具，可在不解鎖 Bootloader、不修改開機映像的情況下，於 OnePlus、OPPO 和 realme 裝置上取得 root 權限並安裝 KernelSU。它針對 CVE-2026-43499——Linux 核心中 futex 優先權繼承的釋放後使用漏洞，結合 pselect6 堆疊覆寫與受控 rb-tree 寫入，實現精確的核心記憶體破壞。該專案主要使用 C 語言與 Android NDK 實作，並包含用於核心符號提取、堆疊配置可行性檢查，以及針對多種 SoC 和 GKI 版本的逐裝置偏移表的 Python 工具。它支援雙利用路徑：透過 ashmem miscdevice 重新導向進行 UMH 注入，或直接修補憑證，面向研究鎖定 Bootloader 繞過、核心漏洞利用，以及強化 Android 建置上漏洞利用後 root 持久化的行動安全研究人員。
