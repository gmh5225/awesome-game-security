GhostLock è un exploit del kernel Android nativo che ottiene l'accesso root e installa KernelSU su dispositivi OnePlus, OPPO e realme senza sbloccare il bootloader né modificare l'immagine di boot. Prende di mira CVE-2026-43499, un use-after-free legato all'ereditarietà di priorità futex nel kernel Linux, combinando overlay dello stack pselect6 con scritture rb-tree controllate per ottenere una corruzione precisa della memoria del kernel. Il progetto è implementato principalmente in C con l'Android NDK e include strumenti Python per l'estrazione di simboli del kernel, verifiche di fattibilità del layout dello stack e tabelle di offset per dispositivo per più SoC e versioni GKI. Supporta due percorsi di exploit, iniezione UMH tramite reindirizzamento miscdevice ashmem o patching diretto delle credential, ed è rivolto a ricercatori di sicurezza mobile che studiano il bypass del bootloader bloccato, l'exploit del kernel e la persistenza root post-exploit su build Android hardened.
