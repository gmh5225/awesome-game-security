GhostLock은 부트로더 잠금 해제나 boot 이미지 수정 없이 OnePlus, OPPO, realme 기기에서 root 권한을 획득하고 KernelSU를 설치하는 네이티브 Android 커널 익스플로잇입니다. Linux 커널의 futex 우선순위 상속 use-after-free 취약점인 CVE-2026-43499를 표적으로 삼으며, pselect6 스택 오버레이와 제어된 rb-tree 쓰기를 결합해 정밀한 커널 메모리 손상을 달성합니다. 이 프로젝트는 주로 C와 Android NDK로 구현되었으며, 커널 심볼 추출, 스택 레이아웃 실현 가능성 검사, 여러 SoC 및 GKI 버전용 기기별 오프셋 테이블을 위한 Python 도구를 포함합니다. ashmem miscdevice 리디렉션을 통한 UMH 인젝션 또는 직접 credential 패치의 이중 익스플로잇 경로를 지원하며, 잠긴 부트로더 우회, 커널 익스플로잇, 강화된 Android 빌드에서 익스플로잇 후 root 지속성을 연구하는 모바일 보안 연구자를 대상으로 합니다.
