GhostLock は、ブートローダーのアンロックや boot イメージの改変なしに、OnePlus、OPPO、realme 端末で root 権限を取得し KernelSU をインストールするネイティブ Android カーネルエクスプロイトです。Linux カーネルの futex 優先度継承 use-after-free である CVE-2026-43499 を標的とし、pselect6 スタックオーバーレイと制御された rb-tree 書き込みを組み合わせ、精密なカーネルメモリ破壊を実現します。プロジェクトは主に C 言語と Android NDK で実装され、カーネルシンボル抽出、スタックレイアウトの実現可能性チェック、複数 SoC および GKI バージョン向けのデバイス別オフセット表用の Python ツールを含みます。ashmem miscdevice リダイレクションによる UMH インジェクション、または直接 credential パッチの 2 つのエクスプロイト経路をサポートし、ロック済みブートローダー回避、カーネルエクスプロイト、強化された Android ビルドにおけるエクスプロイト後の root 永続化を研究するモバイルセキュリティ研究者向けです。
