YCBR AntiCheat 是一款適用於 Minecraft 1.8.9 Paper 伺服器的輕量級反作弊外掛，可偵測常見的移動、戰鬥與協定類作弊行為。此外掛以 Java 8 撰寫、Maven 建置，借助 ProtocolLib 進行封包檢查，並透過雙執行緒管線在非同步處理封包後，再於主執行緒套用檢測邏輯。外掛內建 19 項檢測，涵蓋 KillAura、Reach、Scaffold、Speed、Fly、Velocity、Timer 及相關漏洞利用，並可選用受 Grim 風格預測啟發的物理式移動模擬。此外還提供離線身分驗證、暫時封禁、DDoS 連線防護、嚴格模式閾值，以及用於切換檢測與設定的 GUI 等伺服器端工具。它面向希望在舊版 1.8.9 網路中取得整合作弊偵測與基礎伺服器防護的 Paper 或 Spigot 服主。
