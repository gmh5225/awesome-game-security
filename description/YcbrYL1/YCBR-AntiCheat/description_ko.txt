YCBR AntiCheat는 Minecraft 1.8.9 Paper 서버용 경량 안티치트 플러그인으로, 흔한 이동·전투·프로토콜 치트를 탐지합니다. Java 8로 작성되었고 Maven으로 빌드되며, ProtocolLib로 패킷을 검사하고 패킷을 비동기 처리한 뒤 메인 스레드에서 검사를 적용하는 이중 스레드 파이프라인을 사용합니다. KillAura, Reach, Scaffold, Speed, Fly, Velocity, Timer 및 관련 익스플로잇을 다루는 19가지 검사와 함께 Grim 스타일 예측에서 영감을 받은 물리 기반 이동 시뮬레이션을 선택적으로 제공합니다. 또한 오프라인 인증, 임시 밴, DDoS 연결 방어, 엄격 모드 임계값, 검사 및 설정을 토글하는 GUI 등 서버 측 도구도 포함합니다. 레거시 1.8.9 네트워크에서 통합 치트 탐지와 기본적인 서버 보호를 원하는 Paper 또는 Spigot 서버 운영자를 대상으로 합니다.
