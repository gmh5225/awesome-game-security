YCBR AntiCheat 是一款适用于 Minecraft 1.8.9 Paper 服务器的轻量级反作弊插件，可检测常见的移动、战斗与协议类作弊行为。该插件使用 Java 8 编写、Maven 构建，借助 ProtocolLib 进行数据包检查，并通过双线程流水线在异步处理数据包后再于主线程应用检测逻辑。插件内置 19 项检测，覆盖 KillAura、Reach、Scaffold、Speed、Fly、Velocity、Timer 及相关漏洞利用，并可选启用受 Grim 风格预测启发的基于物理的移动模拟。此外还提供离线身份验证、临时封禁、DDoS 连接防护、严格模式阈值，以及用于开关检测与配置的 GUI 等服务器端工具。它面向希望在旧版 1.8.9 网络中获得集成作弊检测与基础服务器防护的 Paper 或 Spigot 服主。
