YCBR AntiCheat è un plugin anti-cheat leggero per server Minecraft 1.8.9 Paper che rileva i cheat comuni di movimento, combattimento e protocollo. Scritto in Java 8 e compilato con Maven, usa ProtocolLib per l'ispezione dei pacchetti e una pipeline a doppio thread che elabora i pacchetti in modo asincrono prima di applicare i controlli sul thread principale. Il plugin include 19 controlli che coprono KillAura, Reach, Scaffold, Speed, Fly, Velocity, Timer e exploit correlati, più una simulazione del movimento basata sulla fisica ispirata alla previsione in stile Grim opzionale. Include anche strumenti lato server per autenticazione offline, ban temporanei, protezione delle connessioni DDoS, soglie in modalità strict e una GUI per attivare controlli e configurazione. È pensato per operatori di server Paper o Spigot che vogliono rilevamento integrato dei cheat e protezione base del server su reti legacy 1.8.9.
