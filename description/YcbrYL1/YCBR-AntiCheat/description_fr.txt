YCBR AntiCheat est un plugin anti-triche léger pour les serveurs Minecraft 1.8.9 Paper qui détecte les triches courantes de mouvement, de combat et de protocole. Écrit en Java 8 et compilé avec Maven, il utilise ProtocolLib pour l'inspection des paquets et un pipeline à double thread qui traite les paquets de façon asynchrone avant d'appliquer les contrôles sur le thread principal. Le plugin inclut 19 contrôles couvrant KillAura, Reach, Scaffold, Speed, Fly, Velocity, Timer et les exploits associés, ainsi qu'une simulation de mouvement basée sur la physique inspirée de la prédiction de type Grim en option. Il intègre aussi des outils côté serveur pour l'authentification hors ligne, les bannissements temporaires, la protection contre les connexions DDoS, les seuils en mode strict et une GUI pour activer ou désactiver les contrôles et la configuration. Il s'adresse aux opérateurs de serveurs Paper ou Spigot qui souhaitent une détection de triche intégrée et une protection de base sur les réseaux legacy 1.8.9.
