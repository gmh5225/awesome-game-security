Pika は、Linux 上の Wine および Proton 上で動作する Windows ゲーム向けの、停止しないメモリスキャナー兼値パッチャーです。主に Rust で実装され、ptrace によるアタッチの代わりに process_vm_readv と process_vm_writev を用いるため、スキャンと書き込み時に DXVK や VKD3D のフリーズや wineserver のデッドロックを避けられます。SIMD 高速化による複数型スキャン、proc maps に基づく安全な領域分類、フィルタパス、値の凍結、AOB シグネチャ検索、ポインタチェーン探索、Capstone ベースの逆アセンブルなどを備え、JSON-RPC 付きデーモンと CLI クライアントから利用できます。Proton タイトルで従来の Linux メモリエディタが抱えがちな不安定さなしに、Linux ゲーミング環境で信頼できるライブメモリ解析が必要なリバースエンジニア、モッダー、セキュリティ研究者向けです。
