Pika 是针对在 Linux 上通过 Wine 与 Proton 运行的 Windows 游戏的非阻塞内存扫描与数值修改工具。它主要用 Rust 实现，通过 process_vm_readv 与 process_vm_writev 而非 ptrace 附加进行读写，从而在扫描与写入时避免冻结 DXVK 或 VKD3D 以及 wineserver 死锁。该工具提供 SIMD 加速的多类型扫描、基于 proc maps 的安全区域分类、过滤遍、数值冻结、AOB 特征码搜索、指针链发现以及基于 Capstone 的反汇编，并通过带 JSON-RPC 的守护进程与 CLI 客户端对外提供。适合需要在 Linux 游戏环境下进行可靠实时内存分析、且不愿忍受经典 Linux 内存编辑器在 Proton 游戏中常见不稳定性的逆向工程师、模组作者与安全研究人员。
