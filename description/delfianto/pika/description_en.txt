Pika is a non-stopping memory scanner and value patcher for Windows games running under Wine and Proton on Linux. It is implemented primarily in Rust and uses process_vm_readv and process_vm_writev instead of ptrace attach, so scanning and writes avoid freezing DXVK or VKD3D and deadlocking the wineserver. The tool offers SIMD-accelerated multi-type scans, safe region classification from proc maps, filter passes, value freezing, AOB signature search, pointer-chain discovery, and Capstone-based disassembly, exposed through a daemon with JSON-RPC and a CLI client. It suits reverse engineers, modders, and security researchers who need reliable live memory analysis on Linux gaming setups without the instability of classic Linux memory editors on Proton titles.
