Pika는 Linux에서 Wine과 Proton 위에서 실행되는 Windows 게임용 비중단 메모리 스캐너 및 값 패처입니다. 주로 Rust로 구현되었으며 ptrace attach 대신 process_vm_readv와 process_vm_writev를 사용하므로 스캔과 쓰기 시 DXVK나 VKD3D 동결 및 wineserver 교착을 피할 수 있습니다. SIMD 가속 다중 타입 스캔, proc maps 기반 안전 영역 분류, 필터 패스, 값 고정, AOB 시그니처 검색, 포인터 체인 탐색, Capstone 기반 디스어셈블리를 제공하며 JSON-RPC 데몬과 CLI 클라이언트로 노출됩니다. Proton 게임에서 기존 Linux 메모리 에디터의 불안정성 없이 Linux 게이밍 환경에서 신뢰할 수 있는 실시간 메모리 분석이 필요한 리버스 엔지니어, 모더, 보안 연구자에게 적합합니다.
