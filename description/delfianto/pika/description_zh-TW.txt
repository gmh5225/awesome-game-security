Pika 是針對在 Linux 上透過 Wine 與 Proton 執行的 Windows 遊戲之非阻塞式記憶體掃描與數值修補工具。它主要以 Rust 實作，採用 process_vm_readv 與 process_vm_writev，而非以 ptrace 附加，因此在掃描與寫入時可避免凍結 DXVK 或 VKD3D 以及 wineserver 死鎖。此工具提供 SIMD 加速的多類型掃描、依 proc maps 的安全區域分類、過濾回合、數值凍結、AOB 特徵碼搜尋、指標鏈探索，以及以 Capstone 為基礎的反組譯，並透過具 JSON-RPC 的守護程式與 CLI 用戶端對外提供。適合需要在 Linux 遊戲環境中進行可靠即時記憶體分析、且不願忍受傳統 Linux 記憶體編輯器在 Proton 遊戲上常見不穩定性的逆向工程師、模組製作者與安全研究人員。
