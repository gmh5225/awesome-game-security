Glotus Client 是一款基于 TypeScript 的 userscript 作弊工具，面向浏览器游戏 Moomoo.io，通过 Tampermonkey 在 document start 阶段注入游戏客户端。它挂钩 WebSocket 流量、游戏对象和输入处理，通过包含数十个战斗、控制与实用模块的模块化功能系统，实现战斗、防御、刷资源和机器人辅助玩法的自动化。代码库包含客户端数据包与 socket 管理器、移动模拟、空间索引、自定义渲染叠加层，以及使用 Web Workers 在连接前绕过服务器验证的 Altcha 工作量证明求解器。项目使用 Bun 构建，以压缩后的 userscript 包形式分发，可作为研究浏览器游戏客户端操控、反机器人挑战绕过以及实时多人网页游戏攻击面的参考。
