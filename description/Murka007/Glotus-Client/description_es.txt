Glotus Client es un cheat userscript basado en TypeScript para el juego de navegador Moomoo.io que se inyecta en el cliente del juego al inicio del documento mediante Tampermonkey. Intercepta el tráfico WebSocket, los objetos del juego y el manejo de entradas para automatizar combate, defensa, farming y juego asistido por bot a través de un sistema de funciones modular con docenas de módulos de combate, control y utilidades. La base de código incluye gestores de paquetes y sockets del lado del cliente, simulación de movimiento, indexación espacial, superposiciones de renderizado personalizadas y un solucionador de prueba de trabajo Altcha que utiliza Web Workers para eludir la verificación del servidor antes de conectarse. Construido con Bun y distribuido como un bundle userscript minificado, sirve como referencia para estudiar la manipulación de clientes de juegos de navegador, el bypass de desafíos anti-bot y la superficie de ataque de juegos web multijugador en tiempo real.
