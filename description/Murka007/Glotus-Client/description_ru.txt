Glotus Client — это userscript-чит на TypeScript для браузерной игры Moomoo.io, который через Tampermonkey внедряется в игровой клиент на этапе document start. Он перехватывает WebSocket-трафик, игровые объекты и обработку ввода, автоматизируя бой, защиту, фарм и игру с помощью бота через модульную систему функций с десятками боевых, управляющих и утилитарных модулей. Кодовая база включает клиентские менеджеры пакетов и сокетов, симуляцию движения, пространственную индексацию, пользовательские оверлеи рендеринга и решатель proof-of-work Altcha, использующий Web Workers для обхода серверной проверки перед подключением. Собран с помощью Bun и распространяется в виде минифицированного userscript-бандла; служит справочным материалом для изучения манипуляции клиентами браузерных игр, обхода антибот-задач и поверхности атаки многопользовательских веб-игр в реальном времени.
