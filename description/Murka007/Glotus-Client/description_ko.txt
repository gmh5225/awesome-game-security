Glotus Client는 브라우저 게임 Moomoo.io를 위한 TypeScript 기반 userscript 치트로, Tampermonkey를 통해 document start 시점에 게임 클라이언트에 주입됩니다. WebSocket 트래픽, 게임 객체, 입력 처리를 후킹하여 전투, 방어, 파밍, 봇 보조 플레이를 자동화하며, 수십 개의 전투·제어·유틸리티 모듈로 구성된 모듈형 기능 시스템을 제공합니다. 코드베이스에는 클라이언트 측 패킷 및 소켓 매니저, 이동 시뮬레이션, 공간 인덱싱, 커스텀 렌더링 오버레이, Web Workers를 사용해 연결 전 서버 검증을 우회하는 Altcha proof-of-work 솔버가 포함됩니다. Bun으로 빌드되어 minify된 userscript 번들로 배포되며, 브라우저 게임 클라이언트 조작, 안티봇 챌린지 우회, 실시간 멀티플레이어 웹 게임의 공격 표면을 연구하는 참고 자료로 활용할 수 있습니다.
