Glotus Client is a TypeScript-based userscript cheat for the browser game Moomoo.io that injects into the game client at document start via Tampermonkey. It hooks WebSocket traffic, game objects, and input handling to automate combat, defense, grinding, and bot-assisted play through a modular feature system with dozens of combat, control, and utility modules. The codebase includes client-side packet and socket managers, movement simulation, spatial indexing, custom rendering overlays, and an Altcha proof-of-work solver that uses Web Workers to bypass server verification before connecting. Built with Bun and distributed as a minified userscript bundle, it serves as a reference for studying browser-game client manipulation, anti-bot challenge bypass, and the attack surface of real-time multiplayer web games.
