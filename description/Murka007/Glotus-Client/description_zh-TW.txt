Glotus Client 是一款以 TypeScript 為基礎的 userscript 作弊工具，面向瀏覽器遊戲 Moomoo.io，透過 Tampermonkey 在 document start 階段注入遊戲用戶端。它掛鉤 WebSocket 流量、遊戲物件與輸入處理，透過包含數十個戰鬥、控制與實用模組的模組化功能系統，實現戰鬥、防禦、刷資源與機器人輔助玩法的自動化。程式碼庫包含用戶端封包與 socket 管理器、移動模擬、空間索引、自訂渲染疊加層，以及使用 Web Workers 在連線前繞過伺服器驗證的 Altcha 工作量證明求解器。專案使用 Bun 建置，以壓縮後的 userscript 套件形式分發，可作為研究瀏覽器遊戲用戶端操控、反機器人挑戰繞過以及即時多人網頁遊戲攻擊面的參考。
