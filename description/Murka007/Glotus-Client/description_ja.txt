Glotus Client は、ブラウザゲーム Moomoo.io 向けの TypeScript 製 userscript チートで、Tampermonkey 経由で document start 時にゲームクライアントへ注入されます。WebSocket トラフィック、ゲームオブジェクト、入力処理をフックし、戦闘・防御・グラインド・ボット支援プレイを自動化する、数十の戦闘・制御・ユーティリティモジュールを備えたモジュール式機能システムを提供します。コードベースには、クライアント側のパケットおよびソケットマネージャー、移動シミュレーション、空間インデックス、カスタムレンダリングオーバーレイ、接続前にサーバー検証を回避する Web Workers 利用の Altcha プルーフ・オブ・ワークソルバーが含まれます。Bun でビルドされ、minify された userscript バンドルとして配布され、ブラウザゲームのクライアント操作、反ボットチャレンジ回避、リアルタイムマルチプレイヤー Web ゲームの攻撃面を研究するための参考資料となります。
