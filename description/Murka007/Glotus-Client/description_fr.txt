Glotus Client est un cheat userscript basé sur TypeScript pour le jeu navigateur Moomoo.io, qui s'injecte dans le client de jeu au document start via Tampermonkey. Il intercepte le trafic WebSocket, les objets de jeu et la gestion des entrées pour automatiser le combat, la défense, le farming et le jeu assisté par bot grâce à un système de fonctionnalités modulaire comprenant des dizaines de modules de combat, de contrôle et utilitaires. La base de code inclut des gestionnaires de paquets et de sockets côté client, une simulation de mouvement, un indexation spatiale, des overlays de rendu personnalisés et un solveur de preuve de travail Altcha utilisant Web Workers pour contourner la vérification serveur avant la connexion. Construit avec Bun et distribué sous forme de bundle userscript minifié, il sert de référence pour l'étude de la manipulation de clients de jeux navigateur, le contournement des défis anti-bot et la surface d'attaque des jeux web multijoueurs en temps réel.
