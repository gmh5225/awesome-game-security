CS2-AntiCheat — модульный серверный античит-плагин для Counter-Strike 2 на базе CounterStrikeSharp. Написан на C# для .NET и оформляет каждую проверку читов как независимый модуль обнаружения со своей JSON-конфигурацией и настраиваемой реакцией (лог, кик или бан). Включённые модули покрывают типичные клиентские читы: снапы аимбота, злоупотребление backtrack, автоматизацию bunnyhop, быструю стрельбу, невозможные углы обзора и yaw, спам duck, аномальную частоту пользовательских команд, паттерны без отдачи, а также проверку AntiDLL, которая помечает чит-библиотеки, подписанные на чёрный список игровых событий движка, с помощью обновляемых подписей gamedata. Оповещения через Discord webhook и команды перезагрузки для админов помогают операторам серверов мониторить и настраивать применение мер без пересборки плагина — подходит для community- и соревновательных CS2-хостов, которым нужна лёгкая игровая безопасность сверх встроенной защиты Valve.
