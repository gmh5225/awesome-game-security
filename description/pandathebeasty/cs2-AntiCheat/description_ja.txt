CS2-AntiCheat は CounterStrikeSharp 上に構築された Counter-Strike 2 向けのモジュール式サーバー側アンチチートプラグインです。C# で .NET 向けに書かれており、各チート検知を独立した検出モジュールとして整理し、それぞれ独自の JSON 設定と、ログ・キック・BAN など設定可能な対応を備えます。同梱モジュールは、エイムボットのスナップ、バックトラック悪用、bunnyhop 自動化、ラピッドファイア、不可能な視点角・ヨー、ダックスパム、異常なユーザーコマンドレート、ノーリコイルパターン、およびブラックリスト化されたエンジンゲームイベントを購読するチートライブラリを更新可能な gamedata シグネチャで検出する AntiDLL チェックなど、一般的なクライアント側チートをカバーします。Discord Webhook 通知と管理者向けリロードコマンドにより、プラグインを再ビルドせずに監視と執行の調整が可能で、Valve 標準の保護を超える軽量なゲームセキュリティを必要とするコミュニティおよび競技向け CS2 ホストに適しています。
