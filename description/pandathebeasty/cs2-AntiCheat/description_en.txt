CS2-AntiCheat is a modular, server-side anti-cheat plugin for Counter-Strike 2 built on CounterStrikeSharp. It is written in C# for .NET and organizes each cheat check as an independent detection module with its own JSON configuration and configurable response (log, kick, or ban). Included modules cover common client-side cheats such as aimbot snaps, backtrack abuse, bunnyhop automation, rapid fire, impossible view angles and yaw, duck spam, abnormal user command rates, no-recoil patterns, and an AntiDLL check that flags cheat libraries subscribed to blacklisted engine game events using updatable gamedata signatures. Discord webhook alerts and admin reload commands help server operators monitor and tune enforcement without rebuilding the plugin, making it suited for community and competitive CS2 hosts who need lightweight game security beyond Valve’s built-in protections.
