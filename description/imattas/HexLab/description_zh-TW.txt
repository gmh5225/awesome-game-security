HexLab 是一款 C++20 逆向工程工作台，將 wxWidgets 桌面應用程式、無頭 CLI 與偵錯伺服器整合在同一套分析引擎之上。它可載入原始映像及常見可執行格式，包括 PE、ELF、Mach-O、Windows 小型傾印、韌體與受控中繼資料，並在 x86、ARM、AArch64、PowerPC、MIPS 與 RISC-V 上提供反組譯與反編譯支援。套件提供同步的反組譯、位元組、控制流程圖與虛擬碼檢視，以及交叉參考、字串探索、型別編輯、以 CFG 為基礎的二進位比對、以 SQLite 為基礎的專案持久化與外掛 SDK。偵錯涵蓋原生 Win32 與 Linux x86-64 目標及 GDB Remote Serial Protocol 工作階段，並支援 Python 指令碼以實現自動化以及堆疊與區域變數資料存取。面向進行二進位檢視、惡意軟體與遊戲逆向以及原生程式碼互動式偵錯的分析人員。
