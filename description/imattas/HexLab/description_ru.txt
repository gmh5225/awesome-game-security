HexLab — рабочая среда для реверс-инжиниринга на C++20, объединяющая настольное приложение wxWidgets, headless CLI и отладочный сервер на общих аналитических движках. Загружает сырые образы и распространённые исполняемые форматы, включая PE, ELF, Mach-O, минидампы Windows, прошивки и управляемые метаданные, с поддержкой дизассемблирования и декомпиляции для x86, ARM, AArch64, PowerPC, MIPS и RISC-V. Набор предлагает синхронизированные представления дизассемблирования, байтов, графов потока управления и псевдокода, а также перекрёстные ссылки, поиск строк, редактирование типов, сравнение бинарников с учётом CFG, сохранение проектов в SQLite и SDK для плагинов. Отладка охватывает нативные цели Win32 и Linux x86-64 и сессии GDB Remote Serial Protocol, со скриптами на Python для автоматизации и работы со стеком и локальными переменными. Предназначен для аналитиков, занимающихся бинарным анализом, реверсом вредоносного ПО и игр и интерактивной отладкой нативного кода.
