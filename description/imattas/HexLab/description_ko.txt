HexLab은 C++20 기반 리버스 엔지니어링 워크벤치로, wxWidgets 데스크톱 애플리케이션, 헤드리스 CLI, 디버그 서버를 공유 분석 엔진 위에 결합합니다. 원시 이미지와 PE, ELF, Mach-O, Windows 미니덤프, 펌웨어, 관리형 메타데이터 등 일반적인 실행 형식을 로드하며, x86, ARM, AArch64, PowerPC, MIPS, RISC-V에 대해 디스어셈블리 및 디컴파일을 지원합니다. 동기화된 디스어셈블리, 바이트, 제어 흐름 그래프, 의사코드 뷰와 함께 교차 참조, 문자열 탐색, 타입 편집, CFG 인식 바이너리 비교, SQLite 프로젝트 영속성, 플러그인 SDK를 제공합니다. 디버깅은 네이티브 Win32 및 Linux x86-64 대상과 GDB Remote Serial Protocol 세션을 다루며, Python 스크립팅으로 자동화와 스택 또는 지역 변수 데이터를 지원합니다. 바이너리 검사, 멀웨어 및 게임 리버스 엔지니어링, 네이티브 코드 대화형 디버깅을 수행하는 분석가를 대상으로 합니다.
