HexLab es un entorno de trabajo de ingeniería inversa en C++20 que combina una aplicación de escritorio wxWidgets, una CLI sin interfaz gráfica y un servidor de depuración sobre motores de análisis compartidos. Carga imágenes en bruto y formatos ejecutables habituales, entre ellos PE, ELF, Mach-O, minivolcados de Windows, firmware y metadatos administrados, con soporte de desensamblado y descompilación en x86, ARM, AArch64, PowerPC, MIPS y RISC-V. La suite ofrece vistas sincronizadas de desensamblado, bytes, grafos de flujo de control y pseudocódigo, además de referencias cruzadas, descubrimiento de cadenas, edición de tipos, comparación binaria consciente del CFG, persistencia de proyectos en SQLite y un SDK de plugins. La depuración abarca objetivos nativos Win32 y Linux x86-64 y sesiones GDB Remote Serial Protocol, con scripts en Python para automatización y datos de pila o variables locales. Está dirigida a analistas que inspeccionan binarios, hacen ingeniería inversa de malware y juegos y depuran código nativo de forma interactiva.
