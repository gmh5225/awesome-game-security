HexLab 是一款 C++20 逆向工程工作台，将 wxWidgets 桌面应用、无头 CLI 与调试服务器整合在同一套分析引擎之上。它可加载原始镜像及常见可执行格式，包括 PE、ELF、Mach-O、Windows 小型转储、固件与托管元数据，并在 x86、ARM、AArch64、PowerPC、MIPS 与 RISC-V 上提供反汇编与反编译支持。套件提供同步的反汇编、字节、控制流图与伪代码视图，以及交叉引用、字符串发现、类型编辑、基于 CFG 的二进制比对、基于 SQLite 的项目持久化与插件 SDK。调试涵盖原生 Win32 与 Linux x86-64 目标及 GDB Remote Serial Protocol 会话，并支持 Python 脚本以实现自动化以及栈与局部变量数据访问。面向进行二进制检视、恶意软件与游戏逆向以及原生代码交互式调试的分析人员。
