HexLab is a C++20 reverse-engineering workbench that combines a wxWidgets desktop application, a headless CLI, and a debug server on shared analysis engines. It loads raw images and common executable formats including PE, ELF, Mach-O, Windows minidumps, firmware, and managed metadata, with disassembly and decompilation support across x86, ARM, AArch64, PowerPC, MIPS, and RISC-V. The suite offers synchronized disassembly, bytes, control-flow graphs, and pseudocode views, plus cross-references, string discovery, type editing, CFG-aware binary comparison, project persistence in SQLite, and a plugin SDK. Debugging covers native Win32 and Linux x86-64 targets and GDB Remote Serial Protocol sessions, with Python scripting for automation and stack or local-variable data. It targets analysts doing binary inspection, malware and game reverse engineering, and interactive debugging of native code.
