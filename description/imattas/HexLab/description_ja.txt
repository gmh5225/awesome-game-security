HexLab は C++20 製のリバースエンジニアリング用ワークベンチで、wxWidgets デスクトップアプリ、ヘッドレス CLI、デバッグサーバーを共通の解析エンジン上に統合しています。生イメージや PE、ELF、Mach-O、Windows ミニダンプ、ファームウェア、マネージドメタデータなど一般的な実行形式を読み込み、x86、ARM、AArch64、PowerPC、MIPS、RISC-V 向けに逆アセンブルと逆コンパイルをサポートします。逆アセンブル、バイト、制御フローグラフ、疑似コードビューの同期表示に加え、クロスリファレンス、文字列探索、型編集、CFG 対応バイナリ比較、SQLite によるプロジェクト永続化、プラグイン SDK を提供します。デバッグはネイティブ Win32 および Linux x86-64 ターゲットと GDB Remote Serial Protocol セッションをカバーし、Python スクリプトで自動化やスタック・ローカル変数データの操作が可能です。バイナリ調査、マルウェアやゲームのリバースエンジニアリング、ネイティブコードの対話的デバッグを行うアナリスト向けです。
