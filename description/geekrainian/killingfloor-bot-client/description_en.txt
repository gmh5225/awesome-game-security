Killing Floor Bot Client is an L2Walker-style headless client for Killing Floor that speaks the native Unreal Engine 2.5 network protocol over UDP without launching the game or injecting code. It is implemented primarily in JavaScript on Node.js with an Electron desktop GUI, optional Python for GameSpy server queries, UnrealScript server mutators, and Ghidra scripts used to reverse engineer the UE2 bitstream, packet handshake, and Killing Floor-specific Steam authentication flow. The bot can join servers using either Goldberg Steam emulation with a synthetic ticket on owned test hosts or genuine Steam tickets via a 32-bit FFI helper, and it includes a UDP MITM relay, packet disassembly, and extensive protocol documentation for capture and debugging. It is aimed at game security researchers and reverse engineers studying legacy UE2 multiplayer networking, Steam ticket validation, and client-server interoperability on authorized or self-hosted Killing Floor servers.
