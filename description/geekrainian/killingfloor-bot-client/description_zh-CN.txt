Killing Floor Bot Client 是一款面向 Killing Floor 的 L2Walker 风格无头客户端，通过 UDP 使用原生 Unreal Engine 2.5 网络协议通信，无需启动游戏或注入代码。它主要使用 JavaScript 在 Node.js 上实现，并配有 Electron 桌面 GUI；可选 Python 用于 GameSpy 服务器查询，UnrealScript 服务器 mutator，以及 Ghidra 脚本，用于逆向分析 UE2 位流、数据包握手和 Killing Floor 特有的 Steam 认证流程。该 bot 可通过 Goldberg Steam 模拟配合合成票据加入自有测试主机，或通过 32 位 FFI 辅助程序使用真实 Steam 票据加入服务器；还包含 UDP 中间人中继、数据包反汇编以及大量协议文档，便于抓包与调试。它面向研究遗留 UE2 多人联网、Steam 票据验证以及授权或自托管 Killing Floor 服务器上客户端与服务器互操作性的游戏安全研究人员和逆向工程师。
