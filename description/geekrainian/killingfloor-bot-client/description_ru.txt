Killing Floor Bot Client — headless-клиент в стиле L2Walker для Killing Floor, который использует нативный сетевой протокол Unreal Engine 2.5 по UDP без запуска игры и без инъекции кода. Реализован в основном на JavaScript в Node.js с настольным GUI на Electron, с опциональным Python для запросов к серверам GameSpy, серверными mutator на UnrealScript и скриптами Ghidra для реверс-инжиниринга битового потока UE2, рукопожатия пакетов и специфичного для Killing Floor потока аутентификации Steam. Бот может подключаться к серверам либо через эмуляцию Goldberg Steam с синтетическим тикетом на собственных тестовых хостах, либо через настоящие Steam-тикеты с помощью 32-битного FFI-хелпера; также включены UDP MITM-реле, дизассемблирование пакетов и обширная документация протокола для захвата и отладки. Предназначен для исследователей безопасности игр и reverse engineers, изучающих унаследованную многопользовательскую сеть UE2, проверку Steam-тикетов и взаимодействие клиента и сервера на авторизованных или self-hosted серверах Killing Floor.
