Guard-Game은 클라이언트 보고를 신뢰하는 대신 구성 가능한 월드 프로필에 대해 플레이어 이동 및 게임플레이 동작을 검증하여 치트를 탐지하는 서버 측 안티 치트 시스템입니다. 런타임 종속성이 없는 Node.js로 작성되었으며, TCP를 통한 JSON 라인 프로토콜과 HTTP 수집 브릿지를 제공하고 Unity/C#, Godot, Roblox/Luau, JavaScript용 클라이언트 SDK를 포함합니다. 서버는 물리 기반 규칙을 적용해 스피드 핵, 불가능한 점프, 텔레포트, 비행 및 호버 악용, 패킷 플러딩, 타임스탬프 또는 시퀀스 스푸핑, 아이템 복제나 퀘스트 파밍과 같은 행위 남용을 감지합니다. 경고 횟수 기반 제재, 자동 밴, 관리자용 HTTP API 및 콘솔, 선택적 HMAC 프레임 서명, Docker 배포 지원을 제공합니다. 멀티플레이어 타이틀에 경량의 엔진 독립적 서버 측 안티 치트 계층이 필요한 게임 개발자를 대상으로 합니다.
