Guard-Game è un sistema anti-cheat lato server che rileva i cheat convalidando movimento del giocatore e azioni di gameplay rispetto a profili di mondo configurabili, invece di fidarsi delle segnalazioni del client. Scritto in Node.js senza dipendenze runtime, espone un protocollo a righe JSON su TCP e un bridge di ingestione HTTP, e include SDK client per Unity/C#, Godot, Roblox/Luau e JavaScript. Il server applica regole basate sulla fisica per individuare speed hack, salti impossibili, teletrasporti, exploit di volo e levitazione, flooding di pacchetti, spoofing di timestamp o sequenze, e abusi d'azione come duplicazione di oggetti o farming di quest. Comprende avvertimenti basati su strike, ban automatici, un'API HTTP e console di amministrazione, firma opzionale dei frame HMAC e supporto al deployment Docker. È pensato per gli sviluppatori di giochi che necessitano di uno strato anti-cheat lato server leggero e indipendente dal motore per titoli multigiocatore.
