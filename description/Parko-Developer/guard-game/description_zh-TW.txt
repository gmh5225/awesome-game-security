Guard-Game 是一套伺服器端反作弊系統，透過將玩家移動與遊戲行為對照可設定的世界設定檔進行驗證來偵測作弊，而非信任用戶端回報。此專案以 Node.js 撰寫，零執行階段相依性，透過 TCP 提供 JSON 行協定及 HTTP 擷取橋接，並附 Unity/C#、Godot、Roblox/Luau 與 JavaScript 的用戶端 SDK。伺服器執行以物理為基礎的規則，可偵測加速外掛、不可能實現的跳躍、傳送、飛行與懸浮濫用、封包泛洪、時間戳或序號偽造，以及物品複製或任務刷取等行為濫用。系統包含基於警告次數的處罰、自動封鎖、管理員 HTTP API 與主控台、可選的 HMAC 框架簽署以及 Docker 部署支援。它面向需要輕量級、與引擎無關的伺服器端反作弊層的多人遊戲開發者。
