Guard-Game es un sistema antitrampas del lado del servidor que detecta trampas validando el movimiento del jugador y las acciones de juego frente a perfiles de mundo configurables, en lugar de confiar en los informes del cliente. Escrito en Node.js sin dependencias en tiempo de ejecución, expone un protocolo de líneas JSON sobre TCP y un puente de ingesta HTTP, e incluye SDKs de cliente para Unity/C#, Godot, Roblox/Luau y JavaScript. El servidor aplica reglas basadas en la física para detectar speed hacks, saltos imposibles, teletransportes, exploits de vuelo y flotación, inundación de paquetes, suplantación de marcas de tiempo o secuencias, y abuso de acciones como duplicación de objetos o farmeo de misiones. Incluye advertencias basadas en infracciones, baneos automáticos, una API HTTP y consola de administración, firma HMAC opcional de tramas y compatibilidad con despliegue en Docker. Está dirigido a desarrolladores de juegos que necesitan una capa antitrampas del lado del servidor, ligera e independiente del motor, para títulos multijugador.
