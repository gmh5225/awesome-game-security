Guard-Game は、クライアント報告を信頼するのではなく、設定可能なワールドプロファイルに対してプレイヤーの移動やゲームプレイ操作を検証することでチートを検出するサーバーサイドのアンチチートシステムです。Node.js で書かれ、実行時依存関係はゼロで、TCP 上の JSON 行プロトコルと HTTP 取り込みブリッジを提供し、Unity/C#、Godot、Roblox/Luau、JavaScript 向けのクライアント SDK を同梱しています。サーバーは物理ベースのルールを適用し、スピードハック、不可能なジャンプ、テレポート、飛行やホバー悪用、パケット洪水、タイムスタンプやシーケンス偽装、およびアイテム複製やクエスト周回などの行為乱用を検出します。警告回数ベースの制裁、自動 BAN、管理者向け HTTP API とコンソール、任意の HMAC フレーム署名、Docker デプロイメント対応を備えています。マルチプレイヤー向けタイトルに、軽量でエンジン非依存のサーバーサイドアンチチート層を必要とするゲーム開発者を対象としています。
