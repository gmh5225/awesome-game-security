Guard-Game — это серверная античит-система, которая выявляет читерство, проверяя перемещения игроков и игровые действия по настраиваемым профилям мира, а не доверяя отчётам клиента. Написана на Node.js без зависимостей во время выполнения, предоставляет построчный JSON-протокол по TCP и HTTP-мост для приёма данных, а также клиентские SDK для Unity/C#, Godot, Roblox/Luau и JavaScript. Сервер применяет правила на основе физики, чтобы обнаруживать speedhack, невозможные прыжки, телепорты, эксплойты полёта и зависания, флуд пакетами, подделку временных меток или последовательностей, а также злоупотребления действиями вроде дублирования предметов или фарма квестов. Включает предупреждения на основе нарушений, автоматические баны, административный HTTP API и консоль, опциональную HMAC-подпись фреймов и поддержку развёртывания в Docker. Предназначена для разработчиков игр, которым нужен лёгкий, не привязанный к движку серверный античит-слой для многопользовательских проектов.
