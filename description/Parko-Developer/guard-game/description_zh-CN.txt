Guard-Game 是一套服务端反作弊系统，通过将玩家移动与游戏行为对照可配置的世界配置文件进行校验来检测作弊，而非依赖客户端上报。该项目基于 Node.js 编写，零运行时依赖，通过 TCP 提供 JSON 行协议及 HTTP 摄取桥接，并提供面向 Unity/C#、Godot、Roblox/Luau 和 JavaScript 的客户端 SDK。服务端执行基于物理的规则，可检测加速外挂、不可能实现的跳跃、传送、飞行与悬浮利用、数据包洪泛、时间戳或序列号伪造，以及物品复制或任务刷取等行为滥用。系统包含基于警告次数的处罚、自动封禁、管理员 HTTP API 与控制台、可选的 HMAC 帧签名以及 Docker 部署支持。它面向需要轻量级、与引擎无关的服务端反作弊层的多人游戏开发者。
