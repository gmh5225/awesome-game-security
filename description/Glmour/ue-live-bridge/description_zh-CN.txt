ue-live-bridge 是一个工具框架，允许外部进程通过读写实时的 UObject 状态来驱动正在运行的 Unreal Engine 游戏，而无需修改引擎或游戏源代码。游戏内的 UE4SS Lua 模组通过一对仅追加的 JSONL 文件对外暴露世界状态，外部的 Python 驱动程序则通过该基于文件的通道解析对象、读取属性、调用 UFunctions 并执行写入。该项目强调经过验证的交互而非盲目信任：写入操作会通过独立的重新读取进行交叉验证，负对照污染测试证明检查机制能够失败，CLI 和 MCP 服务器均返回 CONFIRMED 或 FALSE_SUCCESS 等明确判定，而非简单的布尔值。它提供 MCP 接口，使 AI 智能体能够以编程方式探测和操纵游戏状态，并附带在引擎外模拟不诚实桥接行为的测试。技术栈为 Python 和 Lua，目标用户是模组开发者、研究人员以及自动化作者，用于在其可控的 Unreal 作品上进行实时检查、脚本编写和工具开发工作流。
