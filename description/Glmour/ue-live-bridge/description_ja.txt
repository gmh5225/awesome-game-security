ue-live-bridge は、外部プロセスが実行中の Unreal Engine ゲームを、エンジンやゲームのソースコードを変更せずに、ライブの UObject 状態を読み書きすることで操作できるツールフレームワークです。ゲーム内の UE4SS Lua モッドが、追記専用の JSONL ファイルのペアを介してワールドを外部に公開し、外部の Python ドライバーはそのファイルベースのチャネルを通じてオブジェクトを解決し、プロパティを読み取り、UFunctions を呼び出し、書き込みを発行します。このプロジェクトは盲目的な信頼ではなく、検証済みの相互作用を重視します。書き込みは独立した再読み取りでクロスチェックされ、ネガティブコントロールによるポイズニングでチェックが失敗できることを証明し、CLI と MCP サーバーの両方が単純なブール値ではなく CONFIRMED や FALSE_SUCCESS といった明示的な判定を返します。AI エージェントがプログラム的にゲーム状態を調査・操作できる MCP インターフェースを同梱し、不誠実なブリッジをシミュレートするエンジン外テストも提供します。スタックは Python と Lua で、対象は自分が管理する Unreal タイトルでライブ検査、スクリプティング、ツール開発ワークフローを行うモッダー、研究者、自動化の作成者です。
