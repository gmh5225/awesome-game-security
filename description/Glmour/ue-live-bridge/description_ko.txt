ue-live-bridge는 외부 프로세스가 실행 중인 Unreal Engine 게임을 엔진이나 게임 소스 코드를 수정하지 않고 라이브 UObject 상태를 읽고 쓰며 제어할 수 있게 하는 도구 프레임워크입니다. 게임 내부의 UE4SS Lua 모드가 append-only JSONL 파일 쌍을 통해 월드를 외부에 노출하고, 외부 Python 드라이버는 해당 파일 기반 채널을 통해 객체를 해석하고, 속성을 읽으며, UFunctions를 호출하고, 쓰기를 수행합니다. 이 프로젝트는 맹목적인 신뢰보다 검증된 상호작용을 강조합니다. 쓰기는 독립적인 재읽기로 교차 검증되고, 네거티브 컨트롤 포이즈닝으로 검사가 실패할 수 있음을 증명하며, CLI와 MCP 서버 모두 단순한 불리언 대신 CONFIRMED 또는 FALSE_SUCCESS와 같은 명시적 판정을 반환합니다. AI 에이전트가 프로그래밍 방식으로 게임 상태를 탐색하고 조작할 수 있는 MCP 인터페이스를 제공하며, 부정직한 브리지를 시뮬레이션하는 엔진 외부 테스트도 포함합니다. 스택은 Python과 Lua이며, 대상은 자신이 제어하는 Unreal 타이틀에서 라이브 검사, 스크립팅, 도구 워크플로를 수행하는 모더, 연구자, 자동화 작성자입니다.
