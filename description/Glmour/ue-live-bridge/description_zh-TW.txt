ue-live-bridge 是一個工具框架，允許外部程序透過讀寫即時的 UObject 狀態來驅動正在執行的 Unreal Engine 遊戲，而無需修改引擎或遊戲原始碼。遊戲內的 UE4SS Lua 模組透過一對僅追加的 JSONL 檔案對外暴露世界狀態，外部的 Python 驅動程式則透過該基於檔案的通道解析物件、讀取屬性、呼叫 UFunctions 並執行寫入。此專案強調經過驗證的互動而非盲目信任：寫入操作會透過獨立的重新讀取進行交叉驗證，負對照污染測試證明檢查機制能夠失敗，CLI 與 MCP 伺服器均回傳 CONFIRMED 或 FALSE_SUCCESS 等明確判定，而非簡單的布林值。它提供 MCP 介面，使 AI 代理能以程式化方式探測與操縱遊戲狀態，並附帶在引擎外模擬不誠實橋接行為的測試。技術棧為 Python 與 Lua，目標對象是模組開發者、研究人員以及自動化作者，用於在其可控的 Unreal 作品上進行即時檢查、腳本編寫與工具開發工作流程。
