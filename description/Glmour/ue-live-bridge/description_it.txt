ue-live-bridge è un framework di strumenti che consente a un processo esterno di guidare un gioco Unreal Engine in esecuzione leggendo e scrivendo lo stato live degli UObject, senza modificare il codice sorgente del motore o del gioco. Un mod Lua UE4SS all'interno del gioco espone il mondo tramite una coppia di file JSONL append-only, mentre un driver Python esterno risolve gli oggetti, legge le proprietà, invoca UFunctions ed esegue scritture attraverso quel canale basato su file. Il progetto enfatizza l'interazione verificata piuttosto che la fiducia cieca: le scritture vengono incrociate con riletture indipendenti, il poisoning con controllo negativo dimostra che i controlli possono fallire, e sia la CLI sia il server MCP restituiscono verdetto espliciti come CONFIRMED o FALSE_SUCCESS invece di un semplice booleano. Include un'interfaccia MCP affinché gli agenti IA possano sondare e manipolare lo stato di gioco in modo programmatico, insieme a test off-engine che simulano bridge disonesti. Lo stack è Python e Lua, e il pubblico previsto sono modder, ricercatori e autori di automazione che lavorano su titoli Unreal sotto il loro controllo per ispezione live, scripting e flussi di lavoro di tooling.
