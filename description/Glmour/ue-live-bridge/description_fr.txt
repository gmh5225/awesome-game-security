ue-live-bridge est un framework d'outils qui permet à un processus externe de piloter un jeu Unreal Engine en cours d'exécution en lisant et en écrivant l'état live des UObjects, sans modifier le code source du moteur ou du jeu. Un mod Lua UE4SS dans le jeu expose le monde via une paire de fichiers JSONL en append-only, tandis qu'un pilote Python externe résout les objets, lit les propriétés, appelle les UFunctions et effectue des écritures via ce canal basé sur des fichiers. Le projet privilégie l'interaction vérifiée plutôt que la confiance aveugle : les écritures sont recoupées par des relectures indépendantes, un empoisonnement par contrôle négatif prouve que les vérifications peuvent échouer, et le CLI ainsi que le serveur MCP renvoient des verdicts explicites tels que CONFIRMED ou FALSE_SUCCESS au lieu d'un simple booléen. Il inclut une interface MCP permettant aux agents IA d'explorer et de manipuler l'état du jeu de manière programmatique, ainsi que des tests hors moteur simulant des ponts malveillants. La pile repose sur Python et Lua, et le public visé comprend les moddeurs, chercheurs et auteurs d'automatisation travaillant sur des titres Unreal qu'ils contrôlent pour l'inspection live, le scripting et les flux de travail d'outillage.
