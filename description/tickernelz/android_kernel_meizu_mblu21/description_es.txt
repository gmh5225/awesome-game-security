Este repositorio ofrece fuentes del kernel GKI Android 13 (5.15), scripts de compilación e imágenes de arranque con root probadas para el terminal Meizu mBlu 21. Permite obtener root mediante controladores cargables al estilo KernelSU (SukiSU-Ultra y KernelSU-Next) parcheando init_boot mientras se mantiene el kernel boot de fábrica, e incluye un módulo guardián SUSFS y documentación para ocultar root ante apps que inspeccionan montajes, proc y el estado del kernel. El árbol incluye herramientas Python y shell para empaquetar imágenes boot, verificar diseños Android Verified Boot y comparar kernels compilados con ABI de símbolos DLKM del fabricante capturados, de modo que las compilaciones personalizadas sigan siendo compatibles con los módulos Meizu. Un módulo opcional de integridad al estilo Magisk y notas sobre Play Integrity documentan attestation de claves, modos keybox y veredictos de integridad del dispositivo medidos en hardware desbloqueado. Está dirigido a investigadores y usuarios avanzados que estudian el ecosistema root móvil, las limitaciones GKI del fabricante, el comportamiento de integridad y attestation del que dependen juegos y apps bancarias, y la anti-detección práctica en dispositivos Android con root.
