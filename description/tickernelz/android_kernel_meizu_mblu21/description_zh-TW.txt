本儲存庫提供魅族 mBlu 21 機型的 GKI Android 13（5.15）內核原始碼、建置腳本以及經測試的 root 開機映像。在保留原廠 boot 內核的前提下，透過修補 init_boot 並載入 KernelSU 類驅動（SukiSU-Ultra 與 KernelSU-Next）取得 root；並附 SUSFS 防護模組與文件，用於向檢查掛載點、proc 與內核狀態的應用程式隱藏 root。原始碼樹包含 Python 與 shell 工具，用於打包開機映像、驗證 Android Verified Boot 配置，並將自編譯內核與擷取的廠商 DLKM 符號 ABI 比對，以維持與魅族廠商模組的相容性。可選的完整性 Magisk 風格模組與 Play Integrity 說明文件涵蓋金鑰認證、keybox 模式以及在已解鎖硬體上的裝置完整性判定。面向研究者與進階使用者，用於研習行動 root 生態、廠商 GKI 限制、遊戲與銀行類應用所依賴的完整性與認證行為，以及已 root Android 裝置上的實用反偵測手段。
