本仓库提供魅族 mBlu 21 机型的 GKI Android 13（5.15）内核源码、构建脚本以及经测试的 root 启动镜像。在保留原厂 boot 内核的前提下，通过对 init_boot 打补丁并加载 KernelSU 类驱动（SukiSU-Ultra 与 KernelSU-Next）获取 root；附带 SUSFS 防护模块及文档，用于向检查挂载点、proc 与内核状态的应用隐藏 root。源码树包含 Python 与 shell 工具，用于打包启动镜像、校验 Android Verified Boot 布局，并将自编译内核与抓取的厂商 DLKM 符号 ABI 对比，以保持与魅族厂商模块的兼容。可选的完整性 Magisk 风格模块与 Play Integrity 说明文档涵盖密钥认证、keybox 模式以及在已解锁硬件上的设备完整性判定。面向研究者和高级用户，用于学习移动 root 生态、厂商 GKI 约束、游戏与银行类应用所依赖的完整性与认证行为，以及已 root Android 设备上的实用反检测手段。
