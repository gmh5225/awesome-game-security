This repository provides GKI Android 13 (5.15) kernel sources, build scripts, and tested root boot images for the Meizu mBlu 21 handset. It supports obtaining root through loadable KernelSU-style drivers (SukiSU-Ultra and KernelSU-Next) by patching init_boot while keeping the stock boot kernel, and ships a SUSFS guard module plus documentation for hiding root from apps that inspect mounts, proc, and kernel state. The tree includes Python and shell tooling to pack boot images, verify Android Verified Boot layouts, and compare built kernels against captured vendor DLKM symbol ABIs so custom builds stay compatible with Meizu vendor modules. An optional integrity Magisk-style module and Play Integrity notes document key attestation, keybox modes, and measured device integrity verdicts on unlocked hardware. It is aimed at researchers and advanced users studying mobile root ecosystems, vendor GKI constraints, integrity and attestation behavior that games and banking apps rely on, and practical anti-detection around rooted Android devices.
