本リポジトリは Meizu mBlu 21 向けの GKI Android 13（5.15）カーネルソース、ビルドスクリプト、および動作確認済みの root 用 boot イメージを提供します。ストックの boot カーネルを維持したまま init_boot をパッチし、ロード可能な KernelSU 系ドライバ（SukiSU-Ultra および KernelSU-Next）で root を取得できます。マウント、proc、カーネル状態を調べるアプリから root を隠す SUSFS ガードモジュールとドキュメントも同梱しています。ツリーには boot イメージのパック、Android Verified Boot レイアウトの検証、ビルドしたカーネルと取得したベンダー DLKM シンボル ABI の照合を行う Python および shell ツールがあり、Meizu ベンダーモジュールとの互換性を保てます。任意の整合性 Magisk 風モジュールと Play Integrity のメモでは、鍵アテステーション、keybox モード、ロック解除済みハードウェア上のデバイス整合性判定について記載しています。モバイル root エコシステム、ベンダー GKI 制約、ゲームや銀行アプリが依存する整合性・アテステーション、root 済み Android デバイス周辺の実用的な検知回避を研究する研究者および上級ユーザー向けです。
