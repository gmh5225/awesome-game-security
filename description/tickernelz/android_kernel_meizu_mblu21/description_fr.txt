Ce dépôt fournit les sources du noyau GKI Android 13 (5.15), des scripts de compilation et des images de démarrage root testées pour le téléphone Meizu mBlu 21. Il permet d’obtenir root via des pilotes chargeables de type KernelSU (SukiSU-Ultra et KernelSU-Next) en patchant init_boot tout en conservant le noyau boot d’origine, et inclut un module de garde SUSFS plus une documentation pour masquer root aux applications qui inspectent les montages, proc et l’état du noyau. L’arborescence comprend des outils Python et shell pour empaqueter les images boot, vérifier les dispositions Android Verified Boot et comparer les noyaux compilés aux ABI de symboles DLKM vendeur capturés afin que les builds personnalisés restent compatibles avec les modules Meizu. Un module optionnel de type Magisk pour l’intégrité et des notes Play Integrity documentent l’attestation de clés, les modes keybox et les verdicts d’intégrité mesurée sur matériel déverrouillé. Il s’adresse aux chercheurs et utilisateurs avancés qui étudient l’écosystème root mobile, les contraintes GKI vendeur, le comportement d’intégrité et d’attestation dont dépendent jeux et apps bancaires, ainsi que la anti-détection pratique sur appareils Android rootés.
