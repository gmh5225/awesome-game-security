这是一项有完整文档记录的研究项目，通过只读设备画像与动手实测，在 OPPO R9sk（Android 6.0.1、ColorOS 3.0、MSM8953）上获取并验证 root 权限。项目汇总多种 root 路径——官方解锁、fastboot、一键工具、Qualcomm 9008 EDL 配合 TWRP 与 Magisk、工程模式以及公开内核 CVE——并记录在本平台上哪些方案失败及其原因。补充材料包括 CVE-2019-2215 漏洞利用实验结果、对 ColorOS KingRoot 黑名单与 com.oppo.engineermode 的逆向分析、启动挂起问题分析，以及在旧版固件上配置 Magisk 23.0 与 MagiskHide。仓库内容以 Markdown 形式的证据与指南为主，另含用于解码二进制 AndroidManifest XML 的小型 Python 工具。面向移动安全研究人员、逆向工程师，以及关注旧版 Android 加固、OEM 锁机策略与 root 后工具链（如 Magisk 模块与在受限设备上的 root 隐藏）的读者。
