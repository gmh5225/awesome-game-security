This is a documented research project on gaining and validating root access on the OPPO R9sk (Android 6.0.1, ColorOS 3.0, MSM8953) using read-only device profiling and hands-on testing. It catalogs multiple rooting paths—official unlock, fastboot, one-click tools, Qualcomm 9008 EDL with TWRP and Magisk, engineer mode, and public kernel CVEs—and records which approaches fail and why on this platform. Supplementary material covers CVE-2019-2215 exploit lab results, reverse engineering of ColorOS KingRoot blacklists and com.oppo.engineermode, boot hang analysis, and Magisk 23.0 setup with MagiskHide on legacy firmware. The repo is mostly Markdown evidence and guides, plus a small Python utility for decoding binary AndroidManifest XML. It targets mobile security researchers, reverse engineers, and anyone studying legacy Android hardening, OEM lockdown, and post-root tooling such as Magisk modules and root hiding on constrained devices.
