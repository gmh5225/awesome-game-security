本リポジトリは、読み取り専用の端末プロファイリングと実機検証により、OPPO R9sk（Android 6.0.1、ColorOS 3.0、MSM8953）で root 権限を取得・検証する研究プロジェクトの記録である。公式アンロック、fastboot、ワンクリック系ツール、Qualcomm 9008 EDL と TWRP・Magisk、エンジニアモード、公開カーネル CVE など複数の root 経路を整理し、この端末でどの手法が失敗するかとその理由を記録している。補足資料には CVE-2019-2215 悪用ラボの結果、ColorOS の KingRoot ブラックリストと com.oppo.engineermode のリバースエンジニアリング、起動時のハング分析、レガシー版ファームウェアでの Magisk 23.0 と MagiskHide の設定が含まれる。内容は主に Markdown の根拠資料とガイドに加え、バイナリ形式の AndroidManifest XML をデコードする小さな Python ユーティリティ。対象はモバイルセキュリティ研究者、リバースエンジニア、旧世代 Android の強化、OEM によるロックダウン、Magisk モジュールや root 隠蔽など root 後ツールを研究する読者。
