這是一項附完整文件的研究專案，透過唯讀裝置輪廓與實地測試，在 OPPO R9sk（Android 6.0.1、ColorOS 3.0、MSM8953）上取得並驗證 root 權限。專案整理多種 root 路徑——官方解鎖、fastboot、一鍵工具、Qualcomm 9008 EDL 搭配 TWRP 與 Magisk、工程模式以及公開核心 CVE——並記錄在本平台上哪些做法失敗及其原因。補充內容涵蓋 CVE-2019-2215 漏洞利用實驗結果、對 ColorOS KingRoot 黑名單與 com.oppo.engineermode 的逆向工程、開機卡住分析，以及在舊版韌體上設定 Magisk 23.0 與 MagiskHide。儲存庫以 Markdown 形式的證據與指南為主，另附用於解碼二進位 AndroidManifest XML 的小型 Python 工具。對象為行動安全研究人員、逆向工程師，以及研究舊版 Android 強化、OEM 鎖定與 root 後工具（如 Magisk 模組與在受限裝置上隱藏 root）的讀者。
