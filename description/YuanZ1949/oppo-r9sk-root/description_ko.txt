읽기 전용 기기 프로파일링과 직접 테스트를 통해 OPPO R9sk(Android 6.0.1, ColorOS 3.0, MSM8953)에서 root 권한을 확보·검증하는 연구 프로젝트를 문서화한 저장소이다. 공식 언락, fastboot, 원클릭 도구, Qualcomm 9008 EDL과 TWRP·Magisk, 엔지니어 모드, 공개 커널 CVE 등 여러 root 경로를 정리하고, 이 플랫폼에서 어떤 방법이 실패하는지와 그 이유를 기록한다. 보충 자료에는 CVE-2019-2215 익스플로잇 실험 결과, ColorOS KingRoot 블랙리스트와 com.oppo.engineermode 리버스 엔지니어링, 부팅 멈춤 분석, 레거시 펌웨어에서 Magisk 23.0과 MagiskHide 설정이 포함된다. 저장소는 대부분 Markdown 형태의 근거와 가이드이며, 바이너리 AndroidManifest XML을 디코딩하는 소규모 Python 유틸리티가 있다. 모바일 보안 연구자, 리버스 엔지니어, 레거시 Android 강화, OEM 잠금, Magisk 모듈 및 제한된 기기에서의 root 은닉 같은 root 이후 도구를 연구하는 이들을 대상으로 한다.
