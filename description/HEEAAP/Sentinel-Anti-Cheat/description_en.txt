Sentinel Anti-Cheat is a Windows user-mode anti-cheat daemon that launches a target game process in a suspended state, attaches protection before execution resumes, and continuously monitors it for tampering. Written in C++ with Visual Studio, it uses Win32 APIs such as NtQueryInformationProcess, ReadProcessMemory, and thread context inspection to detect remote debuggers, hardware breakpoints in debug registers, and software breakpoints (INT 3) in the executable code section. When a threat is found, configurable response policies can log the event, suspend the process via NtSuspendProcess, or terminate it outright. A TaskDialog-based splash screen provides startup feedback while the monitor runs in a polling loop. The project serves as a reference implementation for game developers and security researchers learning early-process attachment and basic anti-debug enforcement on Windows.
