Sentinel Anti-Cheat es un demonio anti-trampas en modo usuario de Windows que inicia un proceso de juego objetivo en estado suspendido, adjunta protección antes de reanudar la ejecución y lo monitoriza continuamente en busca de manipulaciones. Escrito en C++ con Visual Studio, utiliza APIs Win32 como NtQueryInformationProcess, ReadProcessMemory e inspección del contexto de hilos para detectar depuradores remotos, puntos de interrupción de hardware en registros de depuración y puntos de interrupción de software (INT 3) en la sección de código ejecutable. Cuando se detecta una amenaza, las políticas de respuesta configurables pueden registrar el evento, suspender el proceso mediante NtSuspendProcess o terminarlo de inmediato. Una pantalla de inicio basada en TaskDialog proporciona retroalimentación durante el arranque mientras el monitor se ejecuta en un bucle de sondeo. El proyecto sirve como implementación de referencia para desarrolladores de juegos e investigadores de seguridad que desean aprender el acoplamiento temprano a procesos y la aplicación básica de medidas anti-depuración en Windows.
