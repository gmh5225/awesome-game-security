Sentinel Anti-Cheat 是一款 Windows 用户态反作弊守护进程，它会以挂起状态启动目标游戏进程，在恢复执行前附加保护，并持续监控其是否遭到篡改。该项目使用 C++ 和 Visual Studio 编写，通过 NtQueryInformationProcess、ReadProcessMemory 以及线程上下文检查等 Win32 API，检测远程调试器、调试寄存器中的硬件断点，以及可执行代码段中的软件断点（INT 3）。发现威胁时，可配置的响应策略可以记录事件、通过 NtSuspendProcess 挂起进程，或直接终止进程。基于 TaskDialog 的启动界面在监控轮询循环运行期间提供启动反馈。该项目可作为游戏开发者和安全研究人员学习 Windows 早期进程附加与基础反调试强制措施的参考实现。
