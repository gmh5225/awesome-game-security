Sentinel Anti-Cheat est un démon anti-triche en mode utilisateur Windows qui lance un processus de jeu cible en état suspendu, attache une protection avant la reprise de l'exécution et le surveille en continu pour détecter toute altération. Écrit en C++ avec Visual Studio, il utilise des API Win32 telles que NtQueryInformationProcess, ReadProcessMemory et l'inspection du contexte des threads pour détecter les débogueurs distants, les points d'arrêt matériels dans les registres de débogage et les points d'arrêt logiciels (INT 3) dans la section de code exécutable. Lorsqu'une menace est détectée, des politiques de réponse configurables peuvent journaliser l'événement, suspendre le processus via NtSuspendProcess ou le terminer immédiatement. Un écran de démarrage basé sur TaskDialog fournit un retour visuel pendant que la surveillance s'exécute dans une boucle de sondage. Le projet sert d'implémentation de référence pour les développeurs de jeux et les chercheurs en sécurité qui souhaitent apprendre l'attachement précoce aux processus et l'application de mesures anti-débogage de base sous Windows.
