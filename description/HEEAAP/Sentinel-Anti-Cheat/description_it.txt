Sentinel Anti-Cheat è un daemon anti-cheat in modalità utente Windows che avvia un processo di gioco target in stato sospeso, collega la protezione prima che l'esecuzione riprenda e lo monitora continuamente per rilevare manomissioni. Scritto in C++ con Visual Studio, utilizza API Win32 come NtQueryInformationProcess, ReadProcessMemory e l'ispezione del contesto dei thread per rilevare debugger remoti, breakpoint hardware nei registri di debug e breakpoint software (INT 3) nella sezione di codice eseguibile. Quando viene rilevata una minaccia, le policy di risposta configurabili possono registrare l'evento, sospendere il processo tramite NtSuspendProcess o terminarlo immediatamente. Una schermata di avvio basata su TaskDialog fornisce feedback durante l'avvio mentre il monitor opera in un ciclo di polling. Il progetto funge da implementazione di riferimento per sviluppatori di giochi e ricercatori di sicurezza che vogliono apprendere l'attacco precoce ai processi e l'applicazione di misure anti-debug di base su Windows.
