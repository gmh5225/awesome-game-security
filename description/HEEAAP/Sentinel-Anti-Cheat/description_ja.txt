Sentinel Anti-Cheat は、Windows ユーザーモードの反チートデーモンで、対象のゲームプロセスをサスペンド状態で起動し、実行を再開する前に保護をアタッチし、改ざんを継続的に監視します。C++ と Visual Studio で書かれており、NtQueryInformationProcess、ReadProcessMemory、スレッドコンテキスト検査などの Win32 API を用いて、リモートデバッガー、デバッグレジスタ内のハードウェアブレークポイント、実行可能コードセクション内のソフトウェアブレークポイント（INT 3）を検出します。脅威が見つかった場合、設定可能な応答ポリシーによりイベントを記録したり、NtSuspendProcess でプロセスをサスペンドしたり、即座に終了させたりできます。TaskDialog ベースのスプラッシュ画面は、監視がポーリングループで動作している間、起動時のフィードバックを提供します。このプロジェクトは、Windows における早期プロセスアタッチと基本的な反デバッグ強制の学習に向けた、ゲーム開発者およびセキュリティ研究者向けの参考実装です。
