Sentinel Anti-Cheat 是一款 Windows 使用者模式反作弊常駐程式，它會以暫停狀態啟動目標遊戲程序，在恢復執行前附加保護，並持續監控其是否遭到篡改。此專案使用 C++ 與 Visual Studio 撰寫，透過 NtQueryInformationProcess、ReadProcessMemory 以及執行緒上下文檢查等 Win32 API，偵測遠端偵錯器、偵錯暫存器中的硬體中斷點，以及可執行程式碼區段中的軟體中斷點（INT 3）。發現威脅時，可設定的回應策略可以記錄事件、透過 NtSuspendProcess 暫停程序，或直接終止程序。以 TaskDialog 為基礎的啟動畫面會在監控輪詢迴圈執行期間提供啟動回饋。此專案可作為遊戲開發者與安全研究人員學習 Windows 早期程序附加與基礎反偵錯強制措施的參考實作。
