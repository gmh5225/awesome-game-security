Sentinel Anti-Cheat는 Windows 사용자 모드 안티치트 데몬으로, 대상 게임 프로세스를 일시 중지 상태로 실행한 뒤 실행이 재개되기 전에 보호를 부착하고, 변조 여부를 지속적으로 모니터링합니다. C++와 Visual Studio로 작성되었으며, NtQueryInformationProcess, ReadProcessMemory, 스레드 컨텍스트 검사 등 Win32 API를 사용해 원격 디버거, 디버그 레지스터의 하드웨어 중단점, 실행 가능 코드 섹션의 소프트웨어 중단점(INT 3)을 탐지합니다. 위협이 발견되면 구성 가능한 대응 정책에 따라 이벤트를 기록하거나 NtSuspendProcess로 프로세스를 일시 중지하거나 즉시 종료할 수 있습니다. TaskDialog 기반 스플래시 화면은 모니터가 폴링 루프에서 실행되는 동안 시작 피드백을 제공합니다. 이 프로젝트는 Windows에서 초기 프로세스 부착과 기본적인 안티디버그 강제를 학습하려는 게임 개발자와 보안 연구자를 위한 참고 구현입니다.
