HapiScanner è un client Windows open source basato sul consenso che analizza il PC di un giocatore alla ricerca di artefatti di cheat noti e invia prove strutturate allo staff del server invece di applicare ban autonomamente. Lo scanner è scritto in C# su .NET 8 e usa una pipeline orientata ai candidati su cartelle Minecraft, launcher, metadati dei file, forensics su MFT e USN Journal e ispezione a runtime del processo Java Edition attivo collegato al server. Un backend Python FastAPI (HapiVerify) convalida sessioni challenge-response firmate, heartbeat e output del motore di regole, mentre un plugin Velocity consente allo staff di avviare e revisionare le verifiche. Pacchetti di regole JSON firmati, controlli crittografici multilingua e una rigorosa minimizzazione dei dati (niente hashing dell’intero disco, nessun upload di file personali) allineano lo stack a flussi di lavoro anti-cheat trasparenti e di sicurezza di gioco in cui la decisione finale spetta a persone.
