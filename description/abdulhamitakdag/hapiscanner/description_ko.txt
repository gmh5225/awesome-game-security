HapiScanner는 오픈 소스이며 동의 기반의 Windows 클라이언트로, 플레이어 PC에서 알려진 치트 흔적을 스캔하고 스스로 밴을 내리지 않고 구조화된 증거를 서버 운영진에게 보고합니다. 스캐너는 C#과 .NET 8로 구축되었으며, Minecraft 폴더·런처·파일 메타데이터·MFT 및 USN 저널 포렌식, 서버와 연결된 활성 Java Edition 프로세스의 런타임 검사에 대해 후보 우선 파이프라인을 사용합니다. Python FastAPI 백엔드(HapiVerify)는 서명된 챌린지-응답 세션, 하트비트, 규칙 엔진 출력을 검증하고, Velocity 플러그인으로 운영진이 검증을 시작하고 검토할 수 있습니다. 서명된 JSON 규칙 팩, 언어 간 암호학적 검증, 엄격한 데이터 최소화(전체 디스크 해싱 없음, 개인 파일 업로드 없음)로 최종 판단은 사람이 내리는 투명한 안티치트 및 게임 보안 워크플로에 맞춘 스택입니다.
