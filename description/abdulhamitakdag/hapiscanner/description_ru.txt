HapiScanner — это клиент Windows с открытым исходным кодом на основе согласия пользователя: он сканирует ПК игрока на известные следы читов и передаёт структурированные доказательства персоналу сервера, а не выносит баны самостоятельно. Сканер написан на C# под .NET 8 и использует pipeline с приоритетом кандидатов по папкам Minecraft, лаунчерам, метаданным файлов, форензике MFT и журнала USN, а также проверке во время выполнения активного процесса Java Edition, связанного с сервером. Бэкенд на Python FastAPI (HapiVerify) проверяет подписанные сессии challenge-response, heartbeat и вывод rule engine; плагин Velocity позволяет персоналу запускать и просматривать проверки. Подписанные JSON rule pack’и, кросс-языковые криптографические проверки и строгое минимизирование данных (без хеширования всего диска, без загрузки личных файлов) согласуют стек с прозрачными anti-cheat и игровыми security-процессами, где окончательное решение принимает человек.
