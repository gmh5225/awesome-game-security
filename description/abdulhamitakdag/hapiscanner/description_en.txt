HapiScanner is an open-source, consent-based Windows client that scans a player's PC for known cheat artifacts and reports structured evidence to server staff rather than issuing bans on its own. The scanner is built in C# on .NET 8 and uses a candidate-first pipeline over Minecraft folders, launchers, file metadata, MFT and USN Journal forensics, and runtime inspection of the active Java Edition process linked to the server. A Python FastAPI backend (HapiVerify) validates signed challenge-response sessions, heartbeats, and rule-engine outputs while a Velocity plugin lets staff start and review verifications. Signed JSON rule packs, cross-language cryptographic checks, and strict data minimization (no full-disk hashing, no personal file uploads) align the stack with transparent anti-cheat and game-security workflows where humans make the final call.
