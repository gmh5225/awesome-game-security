HapiScanner 是一款開源、基於使用者同意的 Windows 用戶端，用於掃描玩家 PC 上已知的作弊痕跡，並將結構化證據回報給伺服器管理人員，而非自行執行封禁。該掃描器以 C# 在 .NET 8 上建構，採候選優先流程，涵蓋 Minecraft 資料夾、啟動器、檔案中繼資料、MFT 與 USN 日誌鑑識，以及對與伺服器關聯的現行 Java 版程序之執行時檢查。Python FastAPI 後端（HapiVerify）驗證簽署的挑戰-回應工作階段、心跳與規則引擎輸出；Velocity 外掛則供管理人員啟動與審閱驗證。簽署的 JSON 規則包、跨語言密碼學檢查以及嚴格的資料最小化（不做全碟雜湊、不上傳個人檔案）使整套方案符合透明反作弊與遊戲安全工作流程，由人工做出最終裁決。
