HapiScanner 是一款开源、基于用户同意的 Windows 客户端，用于扫描玩家 PC 上已知的作弊痕迹，并将结构化证据上报给服务器管理人员，而非自行执行封禁。该扫描器使用 C# 在 .NET 8 上构建，采用候选优先流程，覆盖 Minecraft 目录、启动器、文件元数据、MFT 与 USN 日志取证，以及对与服务器关联的当前 Java 版进程的运行时检查。Python FastAPI 后端（HapiVerify）验证签名的挑战-响应会话、心跳与规则引擎输出；Velocity 插件则供管理人员发起与审阅验证。签名的 JSON 规则包、跨语言密码学校验以及严格的数据最小化（不做全盘哈希、不上传个人文件）使整套方案符合透明反作弊与游戏安全工作流，由人工做出最终裁决。
