Signature-Forge は、x86 逆アセンブリからインテリジェントなワイルドカードバイトシグネチャを生成し、バイナリ内のコードとデータを特定するためのデスクトップアプリケーションです。Python FastAPI バックエンドと React および Electron フロントエンドを組み合わせ、x64dbg、Cheat Engine、生の hex 形式からの入力を解析し、設定可能なワイルドカードルールに基づいて複数のシグネチャバリアントを生成します。スマートアナライザーはアンカーポイントを安定性と一意性でスコアリングし、結果は AOB パターン、マスク文字列、IDA Python スクリプト、Cheat Engine スクリプト、C/C++ ヘッダー、または x64dbg パターンとしてエクスポートできます。このツールは、ジャンプ、コール、ラベル付き命令を特定するための信頼性の高いシグネチャが必要で、各バイトを手動で調整する必要がないリバースエンジニア、ゲームセキュリティ研究者、パターンスキャナー向けです。
