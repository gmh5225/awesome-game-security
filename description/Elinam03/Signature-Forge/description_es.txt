Signature-Forge es una aplicación de escritorio que genera firmas de bytes con comodines inteligentes a partir del desensamblado x86 para localizar código y datos en binarios. Combina un backend Python FastAPI con un frontend React y Electron, analizando entradas de x64dbg, Cheat Engine y formatos hexadecimales en bruto, y produciendo múltiples variantes de firmas con reglas de comodines configurables. Un analizador inteligente puntúa los puntos de anclaje según su estabilidad y unicidad, y los resultados pueden exportarse como patrones AOB, cadenas de máscara, scripts IDA Python, scripts Cheat Engine, encabezados C/C++ o patrones x64dbg. La herramienta está dirigida a ingenieros de ingeniería inversa, investigadores de seguridad de juegos y escáneres de patrones que necesitan firmas fiables para saltos, llamadas e instrucciones etiquetadas sin ajustar manualmente cada byte.
