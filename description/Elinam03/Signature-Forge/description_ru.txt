Signature-Forge — это настольное приложение, которое генерирует умные байтовые сигнатуры с подстановочными символами из x86-дизассемблирования для поиска кода и данных в бинарных файлах. Оно объединяет бэкенд Python FastAPI с фронтендом React и Electron, разбирая входные данные из x64dbg, Cheat Engine и сырых hex-форматов и создавая несколько вариантов сигнатур с настраиваемыми правилами подстановочных символов. Умный анализатор оценивает опорные точки по стабильности и уникальности, а результаты можно экспортировать как AOB-паттерны, строки масок, скрипты IDA Python, скрипты Cheat Engine, заголовки C/C++ или паттерны x64dbg. Инструмент предназначен для специалистов по реверс-инжинирингу, исследователей безопасности игр и сканеров паттернов, которым нужны надёжные сигнатуры для переходов, вызовов и помеченных инструкций без ручной настройки каждого байта.
