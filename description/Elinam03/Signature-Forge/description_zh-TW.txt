Signature-Forge 是一款桌面應用程式，可從 x86 反組譯程式碼產生智慧萬用字元位元組簽名，用於在二進位檔案中定位程式碼和資料。它結合了 Python FastAPI 後端與 React 和 Electron 前端，能夠解析來自 x64dbg、Cheat Engine 以及原始十六進位格式的輸入，並根據可設定的萬用字元規則產生多種簽名變體。智慧分析器會根據穩定性和唯一性對錨點進行評分，結果可匯出為 AOB 模式、遮罩字串、IDA Python 腳本、Cheat Engine 腳本、C/C++ 標頭檔或 x64dbg 模式。該工具面向逆向工程師、遊戲安全研究人員以及需要可靠簽名來定位跳轉、呼叫和帶標籤指令、且無需手動調整每個位元組的模式掃描器使用者。
