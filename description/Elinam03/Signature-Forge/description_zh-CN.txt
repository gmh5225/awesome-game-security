Signature-Forge 是一款桌面应用程序，可从 x86 反汇编代码生成智能通配符字节签名，用于在二进制文件中定位代码和数据。它结合了 Python FastAPI 后端与 React 和 Electron 前端，能够解析来自 x64dbg、Cheat Engine 以及原始十六进制格式的输入，并根据可配置的通配符规则生成多种签名变体。智能分析器会根据稳定性和唯一性对锚点进行评分，结果可导出为 AOB 模式、掩码字符串、IDA Python 脚本、Cheat Engine 脚本、C/C++ 头文件或 x64dbg 模式。该工具面向逆向工程师、游戏安全研究人员以及需要可靠签名来定位跳转、调用和带标签指令、且无需手动调整每个字节的模式扫描器用户。
