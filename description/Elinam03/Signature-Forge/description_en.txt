Signature-Forge is a desktop application that generates intelligent wildcard byte signatures from x86 disassembly for locating code and data in binaries. It combines a Python FastAPI backend with a React and Electron frontend, parsing input from x64dbg, Cheat Engine, and raw hex formats and producing multiple signature variants with configurable wildcard rules. A smart analyzer scores anchor points by stability and uniqueness, and results can be exported as AOB patterns, mask strings, IDA Python scripts, Cheat Engine scripts, C/C++ headers, or x64dbg patterns. The tool is aimed at reverse engineers, game security researchers, and pattern scanners who need reliable signatures for jumps, calls, and labeled instructions without hand-tuning every byte.
