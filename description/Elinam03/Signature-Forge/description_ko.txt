Signature-Forge는 x86 디스어셈블리에서 지능형 와일드카드 바이트 시그니처를 생성하여 바이너리에서 코드와 데이터를 찾는 데스크톱 애플리케이션입니다. Python FastAPI 백엔드와 React 및 Electron 프론트엔드를 결합하여 x64dbg, Cheat Engine 및 원시 hex 형식의 입력을 파싱하고, 구성 가능한 와일드카드 규칙으로 여러 시그니처 변형을 생성합니다. 스마트 분석기는 앵커 포인트를 안정성과 고유성으로 점수화하며, 결과는 AOB 패턴, 마스크 문자열, IDA Python 스크립트, Cheat Engine 스크립트, C/C++ 헤더 또는 x64dbg 패턴으로 내보낼 수 있습니다. 이 도구는 점프, 호출 및 레이블이 지정된 명령어를 위한 신뢰할 수 있는 시그니처가 필요하고 모든 바이트를 수동으로 조정할 필요 없이 사용하는 리버스 엔지니어, 게임 보안 연구자 및 패턴 스캐너를 대상으로 합니다.
