This project is a server-side anti-cheat extension for Minecraft Paper that detects click automation from timing patterns the game server can observe. A Java plugin records labelled sessions, cleans swing and interact event streams, and scores windows with explainable rules plus machine learning models trained in a Python pipeline. The research stack compares threshold rules, isolation forest and one-class SVM baselines, gradient-boosted and random forest classifiers, and a sequence CNN, with adversarial and lag robustness studies and ONNX export for off-thread inference behind a fail-safe fallback to the original CPS rule. It targets operators and researchers who need auditable, low-overhead autoclicker defense under a man-at-the-end threat model where the client cannot be trusted.
