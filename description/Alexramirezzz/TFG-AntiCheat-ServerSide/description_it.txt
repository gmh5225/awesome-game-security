Questo progetto è un’estensione anti-cheat lato server per Minecraft Paper che rileva l’automazione dei clic dai pattern temporali osservabili dal server di gioco. Un plugin Java registra sessioni etichettate, ripulisce i flussi di eventi di swing e interazione e assegna punteggi a finestre temporali con regole spiegabili e modelli di machine learning addestrati in una pipeline Python. Lo stack di ricerca confronta regole a soglia, baseline isolation forest e one-class SVM, classificatori gradient boosting e random forest, e una CNN sequenziale, con studi di robustezza adversarial e al lag, ed export ONNX per inferenza fuori thread con fallback fail-safe alla regola CPS originale. È rivolto a operatori e ricercatori che necessitano di una difesa auditabile e a basso overhead contro gli autoclicker in un modello di minaccia man-at-the-end in cui il client non è attendibile.
