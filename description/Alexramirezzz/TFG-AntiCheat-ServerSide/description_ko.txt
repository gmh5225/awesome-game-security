이 프로젝트는 Minecraft Paper용 서버 측 안티치트 확장으로, 게임 서버가 관측할 수 있는 클릭 타이밍 패턴에서 클릭 자동화를 탐지합니다. Java 플러그인이 라벨이 붙은 세션을 기록하고 스윙·상호작용 이벤트 스트림을 정제한 뒤, 설명 가능한 규칙과 Python 파이프라인에서 학습한 머신러닝 모델로 시간 창을 점수화합니다. 연구 스택은 임계값 규칙, Isolation Forest 및 One-Class SVM 기준선, gradient boosting과 랜덤 포레스트 분류기, 시퀀스 CNN을 비교하며, 적대적·지연 강건성 연구와 스레드 외 추론을 위한 ONNX 내보내기, 기존 CPS 규칙으로의 fail-safe 폴백을 포함합니다. 클라이언트를 신뢰할 수 없는 man-at-the-end 위협 모델에서 감사 가능하고 오버헤드가 낮은 오토클리커 방어가 필요한 운영자와 연구자를 대상으로 합니다.
