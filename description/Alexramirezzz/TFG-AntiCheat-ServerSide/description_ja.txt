本プロジェクトは Minecraft Paper 向けのサーバー側アンチチート拡張で、ゲームサーバーが観測できるクリックのタイミングパターンからクリック自動化を検出します。Java プラグインがラベル付きセッションを記録し、スイングおよびインタラクトのイベントストリームを整形し、説明可能なルールと Python パイプラインで学習した機械学習モデルで時間窓をスコアリングします。研究スタックでは閾値ルール、Isolation Forest と One-Class SVM のベースライン、勾配ブースティングおよびランダムフォレスト分類器、シーケンス CNN を比較し、敵対的・遅延に対するロバスト性の検証と、スレッド外推論のための ONNX エクスポート、および従来の CPS ルールへのフェイルセーフなフォールバックを行います。クライアントを信頼できない man-at-the-end 脅威モデル下で、監査可能かつ低オーバーヘッドなオートクリッカー防御を必要とする運用者と研究者を対象としています。
