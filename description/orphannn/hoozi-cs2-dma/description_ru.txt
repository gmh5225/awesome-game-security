HOOZi CS2 — это внешний инструмент для Counter-Strike 2, который читает память игры по FPGA DMA-соединению со второго ПК, без внедрения в процесс игры и записи в него. Текущие внутриигровые возможности — ESP игроков с рамками, скелетами, полосками здоровья и брони, а также наложениями имени, оружия и дистанции, плюс фильтрация союзников и проверки видимости с учётом карты на основе коллизионной геометрии для 21 официальной карты. Смещения определяются при подключении через сканирование паттернов и обход схемы Source 2, с почасовой синхронизацией сигнатур и кэшированием по сборке, поэтому ручные файлы смещений не нужны. Проект также поставляется с настраиваемым каркасом меню, многопрофильными настройками, локализацией и планируемыми функциями вроде aim assist, радара, item ESP и Lua-скриптинга. Он предназначен для исследователей и практиков, изучающих внешние читы на базе DMA, обход античита и техники доступа к памяти только для чтения в современных играх на Source 2.
