Unmida is a Windows command-line unpacker for 32-bit and 64-bit PE executables and DLLs protected with Themida. Written in Go, it runs the target under a debugger, waits for the packer to unpack the image in memory, then finds the original entry point and rebuilds the import address table into a dumped PE file. The tool uses golang.org/x/arch for disassembly, optional ScyllaHide integration to bypass anti-debug checks, and additional modes for shrinking dumps, building section data, and attaching to a process by PID. It suits reverse engineers and malware analysts who need to recover analyzable binaries from Themida-protected software, including games and commercial applications they are authorized to study.
