Unmida — консольный распаковщик для Windows, предназначенный для 32- и 64-разрядных PE-исполняемых файлов и DLL, защищённых Themida. Написан на Go: запускает цель под отладчиком, ждёт, пока упаковщик распакует образ в памяти, затем находит исходную точку входа и восстанавливает таблицу адресов импорта в сдампленном PE-файле. Инструмент использует golang.org/x/arch для дизассемблирования, опциональную интеграцию со ScyllaHide для обхода антиотладочных проверок, а также дополнительные режимы для уменьшения дампов, построения данных секций и подключения к процессу по PID. Подходит реверс-инженерам и аналитикам вредоносного ПО, которым нужно восстанавливать пригодные для анализа бинарники из программ с защитой Themida, включая игры и коммерческие приложения, изучение которых разрешено.
