Unmida es un desempaquetador de línea de comandos para Windows de ejecutables PE y DLL de 32 y 64 bits protegidos con Themida. Escrito en Go, ejecuta el objetivo bajo un depurador, espera a que el empacador descomprima la imagen en memoria, localiza el punto de entrada original y reconstruye la tabla de direcciones de importación en un archivo PE volcado. La herramienta usa golang.org/x/arch para el desensamblado, integración opcional con ScyllaHide para evitar comprobaciones antidepuración, y modos adicionales para reducir volcados, construir datos de sección y adjuntarse a un proceso por PID. Está pensada para ingenieros de ingeniería inversa y analistas de malware que necesitan recuperar binarios analizables de software protegido con Themida, incluidos juegos y aplicaciones comerciales que están autorizados a estudiar.
