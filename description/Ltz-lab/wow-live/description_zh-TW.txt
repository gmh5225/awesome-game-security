wow-live 從官方用戶端自身的加密網路流量中提取《魔獸世界》即時遊戲狀態，無需注入遊戲或讀取程序記憶體。專案主要以 Go 撰寫，並有 Rust 輪替輔助與 Python 疊加層；它中繼 Battle.net 登入以擷取世界金鑰材料，對持續增長的 tcpdump 擷取進行增量解密，並將 opcode、戰鬥事件、光環、冷卻與世界物件更新解碼為 JSON 行。內建工具包含 WebSocket 戰鬥資訊流中心、由 SimulationCraft APL 驅動的類 Hekili 輪替建議器，以及具 Web 與疊加檢視及供外部代理使用的 MCP 伺服器的雷達。面向希望逆向並監控正式服與 WoW Forever 用戶端—伺服器協定，以進行分析、自動化與即時態勢感知的研究者與工具開發者。
