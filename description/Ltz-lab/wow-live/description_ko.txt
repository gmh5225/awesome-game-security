wow-live는 게임에 주입하거나 프로세스 메모리를 읽지 않고, 공식 클라이언트 자체의 암호화된 네트워크 트래픽에서 World of Warcraft의 실시간 게임 상태를 추출한다. 주로 Go로 작성되었으며 Rust 로테이션 헬퍼와 Python 오버레이를 포함하고, Battle.net 로그인을 중계해 월드 키 자료를 확보한 뒤 점점 커지는 tcpdump 캡처를 점진적으로 복호화하고 opcode, 전투 이벤트, 오라, 재사용 대기시간, 월드 오브젝트 업데이트를 JSON 라인으로 디코딩한다. 내장 도구로는 WebSocket 전투 피드 허브, SimulationCraft APL로 구동되는 Hekili 스타일 로테이션 제안기, 웹 및 오버레이 뷰와 외부 에이전트용 MCP 서버가 있는 레이더가 있다. 리테일 및 WoW Forever 클라이언트—서버 프로토콜을 역공학하고 모니터링해 분석, 자동화, 실시간 상황 인식을 원하는 연구자와 도구 제작자를 대상으로 한다.
