wow-live 从官方客户端自身的加密网络流量中提取《魔兽世界》实时游戏状态，无需注入游戏或读取进程内存。项目主要用 Go 编写，辅以 Rust 轮转辅助与 Python 叠加层；它中继 Battle.net 登录以获取世界密钥材料，对不断增长的 tcpdump 抓包进行增量解密，并将 opcode、战斗事件、光环、冷却与世界对象更新解码为 JSON 行。内置工具包括 WebSocket 战斗信息流中枢、由 SimulationCraft APL 驱动的类 Hekili 轮转建议器，以及带 Web 与叠加视图和供外部代理使用的 MCP 服务器的雷达。面向希望逆向并监控正式服与 WoW Forever 客户端—服务器协议，以进行分析、自动化与实时态势感知的研究者与工具开发者。
