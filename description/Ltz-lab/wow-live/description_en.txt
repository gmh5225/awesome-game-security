wow-live extracts live World of Warcraft game state from the stock client’s own encrypted network traffic without injecting into the game or reading process memory. Written mainly in Go, with a Rust rotation helper and Python overlays, it relays Battle.net login to capture world-key material, decrypts growing tcpdump captures incrementally, and decodes opcodes, combat events, auras, cooldowns, and world object updates into JSON lines. Built-in tools include a WebSocket combat feed hub, a Hekili-style rotation suggester driven by SimulationCraft APLs, and a radar with web and overlay views plus an MCP server for external agents. It targets researchers and tool builders who want to reverse engineer and monitor retail and WoW Forever client-server protocols for analysis, automation, and live situational awareness.
