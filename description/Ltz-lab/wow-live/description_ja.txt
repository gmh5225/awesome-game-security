wow-live は、ゲームへの注入やプロセスメモリの読み取りなしに、公式クライアント自身の暗号化ネットワークトラフィックから World of Warcraft のライブゲーム状態を抽出する。主に Go で書かれ、Rust のローテーション補助と Python オーバーレイを備え、Battle.net ログインを中継してワールド鍵素材を取得し、増え続ける tcpdump キャプチャを段階的に復号し、opcode、戦闘イベント、オーラ、クールダウン、ワールドオブジェクト更新を JSON 行にデコードする。組み込みツールには WebSocket 戦闘フィードハブ、SimulationCraft APL で駆動する Hekili 風ローテーション提案、Web とオーバーレイ表示および外部エージェント向け MCP サーバーを備えたレーダーがある。小売版および WoW Forever のクライアント—サーバー プロトコルを逆解析・監視し、分析、自動化、ライブ状況認識のためのツールを作りたい研究者と開発者向けである。
