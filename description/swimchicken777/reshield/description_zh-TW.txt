ReShield 是一款面向遊戲與應用程式的預發布安全掃描器，可檢查已出貨或封裝的建置，並以淺白語言說明邏輯與資源在何處可能被複製，以及如何修正每項問題。它主要以 Python 3.11+ 實作，可作為獨立 CLI，也可作為 Claude Code 與 Codex 的 agent skill，並提供 Unity（Mono 與 IL2CPP）、Unreal、Godot、Web 與 Electron、Android、iOS、.NET，以及原生 PE、ELF、Mach-O 二進位檔的平台適配。工具可偵測可讀腳本與中繼資料、隨包分發的 source map、除錯符號、外洩的 API 與私鑰及相關錯誤設定，再依 L0–L5 保護等級評分暴露程度，並可匯出附 OWASP MASWE 標籤的 SARIF 報告供 CI 使用。目標使用者為遊戲開發者與具安全意識的發布工程師，希望在玩家或攻擊者擷取戰鬥公式、機密或其他敏感用戶端邏輯之前，強化建置以對抗逆向工程與 AI 輔助還原。
