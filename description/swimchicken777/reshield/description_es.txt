ReShield es un escáner de seguridad previo al lanzamiento para juegos y aplicaciones que inspecciona builds enviados o empaquetados y explica en lenguaje claro dónde se puede copiar la lógica y los assets y cómo corregir cada problema. Está implementado principalmente en Python 3.11+ como CLI independiente y como agent skill para Claude Code y Codex, con adaptadores de plataforma para Unity (Mono e IL2CPP), Unreal, Godot, web y Electron, Android, iOS, .NET y binarios nativos PE, ELF y Mach-O. Detecta scripts y metadatos legibles, source maps incluidos en el paquete, símbolos de depuración, claves API y privadas filtradas y configuraciones erróneas relacionadas; luego puntúa la exposición en una escala de protección L0–L5 y puede exportar informes SARIF etiquetados con OWASP MASWE para CI. La herramienta está dirigida a desarrolladores de juegos e ingenieros de release conscientes de la seguridad que quieren endurecer builds contra ingeniería inversa y recuperación asistida por IA antes de que jugadores o atacantes extraigan fórmulas de combate, secretos u otra lógica sensible del cliente.
