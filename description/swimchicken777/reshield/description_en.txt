ReShield is a pre-release security scanner for games and applications that inspects shipped or packaged builds and explains in plain language where logic and assets can be copied and how to fix each issue. It is implemented primarily in Python 3.11+ as a standalone CLI and as an agent skill for Claude Code and Codex, with platform adapters for Unity (Mono and IL2CPP), Unreal, Godot, web and Electron, Android, iOS, .NET, and native PE, ELF, and Mach-O binaries. It detects readable scripts and metadata, shipped source maps, debug symbols, leaked API and private keys, and related misconfigurations, then scores exposure on an L0–L5 protection scale and can export SARIF reports tagged with OWASP MASWE for CI. The tool targets game developers and security-minded release engineers who want to harden builds against reverse engineering and AI-assisted recovery before players or attackers can extract combat formulas, secrets, or other sensitive client-side logic.
