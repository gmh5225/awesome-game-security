ReShield는 게임과 애플리케이션용 사전 출시 보안 스캐너로, 배포되거나 패키징된 빌드를 검사하고 로직과 에셋이 어디에서 복사될 수 있는지, 각 문제를 어떻게 고칠지를 쉬운 말로 설명합니다. 주로 Python 3.11+로 구현되어 독립 CLI로 쓰거나 Claude Code 및 Codex용 agent skill로 사용할 수 있으며, Unity(Mono 및 IL2CPP), Unreal, Godot, 웹 및 Electron, Android, iOS, .NET, 네이티브 PE·ELF·Mach-O 바이너리용 플랫폼 어댑터를 제공합니다. 읽을 수 있는 스크립트와 메타데이터, 함께 배포된 source map, 디버그 심볼, 유출된 API 및 개인 키, 관련 잘못된 설정을 탐지한 뒤 L0–L5 보호 척도로 노출도를 점수화하고 OWASP MASWE 태그가 붙은 SARIF 보고서를 CI용으로 내보낼 수 있습니다. 플레이어나 공격자가 전투 공식, 비밀, 기타 민감한 클라이언트 측 로직을 추출하기 전에 역공학 및 AI 보조 복구에 대비해 빌드를 강화하려는 게임 개발자와 보안을 중시하는 릴리스 엔지니어를 대상으로 합니다.
