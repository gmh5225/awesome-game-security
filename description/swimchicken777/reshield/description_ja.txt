ReShield は、ゲームおよびアプリケーション向けのプレリリースセキュリティスキャナーで、出荷済みまたはパッケージ化されたビルドを検査し、ロジックとアセットがどこからコピー可能か、各問題の修正方法を平易な言葉で説明します。主に Python 3.11+ で実装され、スタンドアロンの CLI として、また Claude Code および Codex 向けの agent skill として利用でき、Unity（Mono および IL2CPP）、Unreal、Godot、Web および Electron、Android、iOS、.NET、ネイティブの PE、ELF、Mach-O バイナリ向けのプラットフォームアダプタを備えます。読み取り可能なスクリプトとメタデータ、同梱された source map、デバッグシンボル、漏洩した API キーと秘密鍵、関連する設定ミスを検出し、L0–L5 の保護スケールで露出度をスコア化し、OWASP MASWE タグ付きの SARIF レポートを CI 向けにエクスポートできます。プレイヤーや攻撃者が戦闘式、秘密情報、その他の機密クライアント側ロジックを抽出する前に、リバースエンジニアリングや AI 支援による復元に対してビルドを強化したいゲーム開発者およびセキュリティを意識したリリースエンジニアを対象としています。
