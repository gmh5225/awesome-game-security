ReShield è uno scanner di sicurezza pre-release per giochi e applicazioni che ispeziona build spedite o impacchettate e spiega in linguaggio semplice dove logica e asset possono essere copiati e come correggere ogni problema. È implementato principalmente in Python 3.11+ come CLI autonoma e come agent skill per Claude Code e Codex, con adattatori di piattaforma per Unity (Mono e IL2CPP), Unreal, Godot, web ed Electron, Android, iOS, .NET e binari nativi PE, ELF e Mach-O. Rileva script e metadati leggibili, source map incluse nel pacchetto, simboli di debug, chiavi API e private trapelate e relative configurazioni errate, quindi valuta l’esposizione su una scala di protezione L0–L5 e può esportare report SARIF etichettati con OWASP MASWE per la CI. Lo strumento è rivolto a sviluppatori di giochi e ingegneri del release attenti alla sicurezza che vogliono indurire le build contro reverse engineering e recupero assistito da IA prima che giocatori o attaccanti estraggano formule di combattimento, segreti o altra logica client sensibile.
