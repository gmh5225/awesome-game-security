ReShield ist ein Security-Scanner vor dem Release für Spiele und Anwendungen, der ausgelieferte oder paketierte Builds prüft und in verständlicher Sprache erklärt, wo Logik und Assets kopiert werden können und wie jedes Problem behoben wird. Er ist überwiegend in Python 3.11+ umgesetzt, als eigenständige CLI und als Agent Skill für Claude Code und Codex, mit Plattform-Adaptern für Unity (Mono und IL2CPP), Unreal, Godot, Web und Electron, Android, iOS, .NET sowie native PE-, ELF- und Mach-O-Binaries. Er erkennt lesbare Skripte und Metadaten, mitgelieferte Source Maps, Debug-Symbole, geleakte API- und private Schlüssel sowie verwandte Fehlkonfigurationen, bewertet die Exposition auf einer Schutzskala L0–L5 und kann SARIF-Berichte mit OWASP-MASWE-Tags für CI exportieren. Das Tool richtet sich an Spieleentwickler und sicherheitsbewusste Release-Ingenieure, die Builds gegen Reverse Engineering und KI-gestützte Wiederherstellung härten wollen, bevor Spieler oder Angreifer Kampfformeln, Geheimnisse oder andere sensible clientseitige Logik extrahieren können.
