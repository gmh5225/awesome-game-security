ReShield 是一款面向游戏与应用程序的预发布安全扫描器，可检查已发布或打包的构建产物，并用通俗语言说明逻辑与资源在何处可能被复制以及如何修复每项问题。它主要基于 Python 3.11+ 实现，可作为独立 CLI 使用，也可作为 Claude Code 与 Codex 的 agent skill，并针对 Unity（Mono 与 IL2CPP）、Unreal、Godot、Web 与 Electron、Android、iOS、.NET 以及原生 PE、ELF、Mach-O 二进制提供平台适配。该工具可检测可读脚本与元数据、随包分发的 source map、调试符号、泄露的 API 与私钥及相关错误配置，随后按 L0–L5 保护等级评估暴露程度，并可将带 OWASP MASWE 标签的 SARIF 报告导出供 CI 使用。面向希望在玩家或攻击者提取战斗公式、密钥或其他敏感客户端逻辑之前，加固构建以抵御逆向工程与 AI 辅助还原的游戏开发者与安全意识较强的发布工程师。
