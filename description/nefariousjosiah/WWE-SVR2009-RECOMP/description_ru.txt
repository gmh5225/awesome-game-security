Этот проект перекомпилирует версию WWE SmackDown vs. Raw 2009 для Xbox 360 в нативный исполняемый файл для Windows, Linux и Steam Deck, работающий без полноценного системного эмулятора. Он в основном написан на C++ с CMake, использует ReXGlue SDK (на базе Xenia) для перевода PowerPC-бинарника игры в x86-64 и собственный нативный рендерер на основе re:Blue и plume для Direct3D 12 или Vulkan. Шейдеры Xenos Xbox 360 заранее конвертируются с помощью XenosRecomp; в кодовой базе есть хуки, кэширование конвейера и опциональные инструменты разработчика, такие как учёт вызовов D3D и дамп шейдеров для реверс-инжиниринга рендерера. Целевая аудитория — разработчики и исследователи, изучающие перекомпиляцию Xbox 360, трансляцию GPU и сохранение legacy-игр, а также игроки, предоставляющие собственный образ диска для легального запуска порта.
