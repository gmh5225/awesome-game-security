GT5 Recomp 是 Gran Turismo 5 的原生 Windows 與 Linux 重編譯移植，將 PlayStation 3 遊戲的 PPU 與 SPU PowerPC 二進位翻譯為主機原生程式碼，而非在 RPCS3 中模擬執行。專案建立在 ps3recomp 工具鏈之上，配有龐大的 C/C++ 執行階段、CMake，以及大量用於 lifting 工作、修補原生程式、除錯 RSX 與音訊、安裝更新或模組的 Python 與 PowerShell 腳本。技術堆疊包含對 PS3 系統服務的高階模擬、針對熱點 SPU 工作負載手寫原生替代實作，以及透過 DirectX 12 或 Vulkan 的現代渲染（可選 NVIDIA DLSS 與 AMD FSR 升頻），並附圖形化安裝程式與 C# 啟動器。面向需要完整端對端範例的保存與移植研究人員：PS3 可執行檔解密、靜態重編譯，以及對商業 3A 大作以效能為導向的反逆向工程實例。
