GT5 Recomp is a native Windows and Linux recompilation port of Gran Turismo 5 that translates the PlayStation 3 game's PPU and SPU PowerPC binaries into host-native code instead of emulating them in RPCS3. It builds on the ps3recomp toolchain with a large C and C++ runtime, CMake, and extensive Python and PowerShell scripts for lifting jobs, patching natives, debugging RSX and audio, and installing updates or mods. The stack adds high-level emulation of PS3 system services, hand-written native replacements for hot SPU workloads, and modern rendering through DirectX 12 or Vulkan with optional NVIDIA DLSS and AMD FSR upscaling, plus a graphical installer and C# launcher. It is aimed at preservationists and porting researchers who need a working end-to-end example of PS3 executable decryption, static recompilation, and performance-oriented reverse engineering of a commercial AAA title.
