GT5 Recomp は Gran Turismo 5 のネイティブ Windows および Linux 向け再コンパイル移植で、PlayStation 3 版の PPU および SPU PowerPC バイナリを RPCS3 でエミュレートするのではなく、ホスト向けネイティブコードへ翻訳します。ps3recomp ツールチェーンを基盤とし、大規模な C/C++ ランタイム、CMake、lifting ジョブ、ネイティブのパッチ、RSX とオーディオのデバッグ、更新や MOD のインストール用の広範な Python および PowerShell スクリプトを備えています。スタックには PS3 システムサービスの高レベルエミュレーション、ホットな SPU ワークロード向けの手書きネイティブ置換、DirectX 12 または Vulkan によるモダン描画（オプションで NVIDIA DLSS と AMD FSR アップスケーリング）、GUI インストーラーと C# ランチャーが含まれます。PS3 実行ファイルの復号、静的再コンパイル、商業 AAA タイトルに対する性能重視のリバースエンジニアリングを一気通貫で示す実例を求める保存・移植研究者向けです。
