GT5 Recomp 是 Gran Turismo 5 的原生 Windows 与 Linux 重编译移植，将 PlayStation 3 游戏的 PPU 与 SPU PowerPC 二进制翻译为主机原生代码，而非在 RPCS3 中模拟执行。项目基于 ps3recomp 工具链，配备庞大的 C/C++ 运行时、CMake，以及大量用于 lifting 任务、修补原生代码、调试 RSX 与音频、安装更新或模组的 Python 与 PowerShell 脚本。技术栈包含对 PS3 系统服务的高层仿真、针对热点 SPU 工作负载手写原生替代实现，以及通过 DirectX 12 或 Vulkan 的现代渲染（可选 NVIDIA DLSS 与 AMD FSR 升频），并附带图形化安装程序与 C# 启动器。面向需要完整端到端示例的游戏保存工作者与移植研究人员：PS3 可执行文件解密、静态重编译，以及对商业 3A 大作面向性能的反逆向工程实践。
