BytecodeVM is a Java bytecode virtualizing obfuscator that rewrites selected methods into custom virtual bytecode, injects a generated interpreter, and runs protected logic through that VM at runtime without native code or dynamic libraries. Written in Java and built with Gradle, it uses ASM for bytecode transformation and offers a CLI with YAML configuration plus an optional annotation SDK for per-class and per-method control over virtualization. The tool supports many VM execution architectures—from simple dispatch and threaded interpreters to polymorphic, register-based, data-flow, and finite-state-machine designs—along with layered protections such as encrypted operands, dynamic constant decryption, shuffled control-flow graphs, super-instruction fusion, and runtime VM integrity checks. It is intended primarily as an educational and research platform for exploring bytecode virtualization and Java application hardening, including protecting sensitive logic from static analysis and reverse engineering, rather than as a production-grade commercial obfuscator.
