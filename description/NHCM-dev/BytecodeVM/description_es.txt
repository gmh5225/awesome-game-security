BytecodeVM es un ofuscador de virtualización de bytecode Java que reescribe métodos seleccionados en bytecode virtual personalizado, inyecta un intérprete generado y ejecuta la lógica protegida a través de esa VM en tiempo de ejecución, sin código nativo ni bibliotecas dinámicas. Escrito en Java y construido con Gradle, utiliza ASM para la transformación de bytecode y ofrece una CLI con configuración YAML, además de un SDK de anotaciones opcional para controlar la virtualización por clase y por método. La herramienta admite muchas arquitecturas de ejecución de VM — desde intérpretes simples de despacho y multihilo hasta diseños polimórficos, basados en registros, de flujo de datos y de máquinas de estados finitos — junto con protecciones en capas como operandos cifrados, descifrado dinámico de constantes, grafos de flujo de control mezclados, fusión de superinstrucciones y comprobaciones de integridad de la VM en tiempo de ejecución. Está pensado principalmente como plataforma educativa y de investigación para explorar la virtualización de bytecode y el endurecimiento de aplicaciones Java, incluida la protección de lógica sensible frente al análisis estático y la ingeniería inversa, más que como un ofuscador comercial de nivel de producción.
