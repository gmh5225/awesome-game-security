BytecodeVM 是一款 Java 字节码虚拟化混淆器，将选定方法重写为自定义虚拟字节码，注入生成的解释器，并在运行时通过该 VM 执行受保护逻辑，无需原生代码或动态库。项目使用 Java 编写、Gradle 构建，借助 ASM 进行字节码转换，提供带 YAML 配置的 CLI，以及可选的注解 SDK，用于按类和方法精细控制虚拟化。该工具支持多种 VM 执行架构——从简单分派与线程化解释器，到多态、基于寄存器、数据流和有限状态机设计——并包含加密操作数、动态常量解密、打乱控制流图、超级指令融合以及运行时 VM 完整性校验等分层保护。它主要作为探索字节码虚拟化与 Java 应用加固的教育与研究平台，用于保护敏感逻辑免受静态分析与逆向工程，而非生产级商业混淆器。
