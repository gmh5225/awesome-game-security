BytecodeVM は Java バイトコード仮想化難読化ツールで、選択したメソッドをカスタム仮想バイトコードに書き換え、生成したインタプリタを注入し、ネイティブコードや動的ライブラリを使わずにランタイムでその VM 上で保護されたロジックを実行します。Java で記述され Gradle でビルドされ、ASM によるバイトコード変換を行い、YAML 設定付き CLI と、クラス・メソッド単位で仮想化を制御できる任意の注釈 SDK を提供します。シンプルなディスパッチやスレッド化インタプリタから、多態的・レジスタベース・データフロー・有限状態機械設計まで、多様な VM 実行アーキテクチャに対応し、暗号化オペランド、動的定数復号、シャッフルされた制御フローグラフ、スーパー命令融合、ランタイム VM 整合性チェックなどの多層保護も備えています。主にバイトコード仮想化と Java アプリケーション強化を探求する教育・研究プラットフォームとして、静的解析やリバースエンジニアリングから機密ロジックを守ることを目的としており、商用本番向け難読化ツールではありません。
