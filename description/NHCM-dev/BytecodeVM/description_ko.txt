BytecodeVM은 Java 바이트코드 가상화 난독화 도구로, 선택한 메서드를 사용자 정의 가상 바이트코드로 재작성하고 생성된 인터프리터를 주입하여 네이티브 코드나 동적 라이브러리 없이 런타임에 해당 VM을 통해 보호된 로직을 실행합니다. Java로 작성되었으며 Gradle로 빌드되고, ASM을 사용해 바이트코드를 변환하며, YAML 설정이 있는 CLI와 클래스·메서드별 가상화를 세밀하게 제어할 수 있는 선택적 어노테이션 SDK를 제공합니다. 단순 디스패치 및 스레드형 인터프리터부터 다형적, 레지스터 기반, 데이터 흐름, 유한 상태 머신 설계에 이르기까지 다양한 VM 실행 아키텍처를 지원하며, 암호화된 피연산자, 동적 상수 복호화, 섞인 제어 흐름 그래프, 슈퍼 명령어 융합, 런타임 VM 무결성 검사 등 계층적 보호 기능도 포함합니다. 주로 바이트코드 가상화와 Java 애플리케이션 강화를 탐구하는 교육·연구 플랫폼으로, 정적 분석과 리버스 엔지니어링으로부터 민감한 로직을 보호하는 것을 목적으로 하며, 상용 프로덕션급 난독화 도구는 아닙니다.
