BytecodeVM 是一款 Java 位元組碼虛擬化混淆器，將選定方法重寫為自訂虛擬位元組碼，注入產生的解譯器，並在執行時期透過該 VM 執行受保護邏輯，無需原生程式碼或動態函式庫。專案以 Java 撰寫、Gradle 建置，借助 ASM 進行位元組碼轉換，提供含 YAML 設定的 CLI，以及可選的註解 SDK，用於按類別與方法精細控制虛擬化。此工具支援多種 VM 執行架構——從簡單分派與執行緒化解譯器，到多型、暫存器式、資料流與有限狀態機設計——並包含加密運算元、動態常數解密、打亂控制流程圖、超級指令融合以及執行時期 VM 完整性檢查等分層保護。它主要作為探索位元組碼虛擬化與 Java 應用加固的教育與研究平台，用於保護敏感邏輯免受靜態分析與逆向工程，而非生產級商業混淆器。
