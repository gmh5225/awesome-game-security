vmpunpack 是一款面向 VMProtect 及類似加殼器的通用脫殼工具，適用於 x64 Windows PE 可執行檔。此工具以 Python 3.8+ 撰寫，僅依賴標準函式庫，透過修補後的 sogen 模擬器驅動加殼樣本，繞過反虛擬機與反除錯檢查，將加殼 stub 執行至原始進入點並傾印脫殼後的記憶體映像。它能重建可在 IDA 或 Ghidra 中進行靜態分析的可載入 PE，從傾印中提取網域、URL 和 IP 位址等 IOC，並自動補全模擬環境中的序數匯入缺口。此工具可脫殼受保護的二進位檔，但不會去虛擬化 VMProtect 位元組碼，虛擬化函式仍保持原樣以供後續手動分析。主要面向需要在受限分析環境中脫殼 VMProtect 保護樣本的惡意軟體分析師與逆向工程師。
