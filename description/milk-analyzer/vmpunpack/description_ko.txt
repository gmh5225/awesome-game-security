vmpunpack는 VMProtect 및 유사 패커를 대상으로 하는 범용 언패커로, x64 Windows PE 실행 파일을 처리합니다. Python 3.8+로 작성되었으며 표준 라이브러리만 사용하며, 패치된 sogen 에뮬레이터를 통해 패킹된 샘플을 구동하여 안티 VM 및 안티 디버그 검사를 우회하고, 패커 stub을 원래 진입점까지 실행한 뒤 언패킹된 메모리 이미지를 덤프합니다. 이 도구는 IDA나 Ghidra에서 정적 분석에 적합한 로드 가능한 PE를 재구성하고, 덤프에서 도메인, URL, IP 주소 등 IOC를 추출하며, 에뮬레이션 환경에서 서수 import의 누락을 자동으로 채웁니다. 보호된 바이너리의 언패킹은 수행하지만 VMProtect 바이트코드의 디가상화는 하지 않아, 가상화된 함수는 추가 수동 분석을 위해 그대로 유지됩니다. 주요 대상은 제한된 분석 환경에서 VMProtect로 보호된 샘플을 언패킹해야 하는 멀웨어 분석가 및 리버스 엔지니어입니다.
