vmpunpack — универсальный распаковщик для VMProtect и аналогичных упаковщиков, предназначенный для x64 Windows PE-исполняемых файлов. Написан на Python 3.8+ с использованием только стандартной библиотеки; прогоняет упакованный образец через пропатченный эмулятор sogen, обходящий проверки anti-VM и anti-debug, выполняет stub упаковщика до исходной точки входа и дампит распакованный образ памяти. Инструмент восстанавливает загружаемый PE, пригодный для статического анализа в IDA или Ghidra, извлекает из дампа IOC, такие как домены, URL и IP-адреса, и автоматически заполняет пробелы в ordinal-импортах в среде эмуляции. Распаковывает защищённые бинарники, но не снимает виртуализацию с байткода VMProtect, оставляя виртуализированные функции нетронутыми для дальнейшего ручного анализа. Основная аудитория — аналитики вредоносного ПО и reverse engineers, которым необходимо распаковывать образцы, защищённые VMProtect, в изолированных аналитических средах.
