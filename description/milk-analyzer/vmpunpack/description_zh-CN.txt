vmpunpack 是一款面向 VMProtect 及类似壳的通用脱壳工具，适用于 x64 Windows PE 可执行文件。该工具基于 Python 3.8+ 编写，仅依赖标准库，通过修补后的 sogen 模拟器驱动加壳样本，绕过反虚拟机和反调试检测，将壳 stub 运行至原始入口点并转储脱壳后的内存映像。它能重建可在 IDA 或 Ghidra 中进行静态分析的可加载 PE，从转储中提取域名、URL 和 IP 地址等 IOC，并自动补全模拟环境中的序号导入缺口。该工具可脱壳受保护的二进制文件，但不会去虚拟化 VMProtect 字节码，虚拟化函数仍保持原样以供后续手动分析。主要面向需要在受限分析环境中脱壳 VMProtect 保护样本的恶意软件分析师和逆向工程师。
