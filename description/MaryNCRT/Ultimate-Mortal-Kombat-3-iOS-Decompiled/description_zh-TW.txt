本專案是對 2011 年 iOS 版 Ultimate Mortal Kombat 3 的潔淨室反編譯，將全部 2,572 個 armv7 遊戲函式轉寫為經驗證的 C 程式碼，並封裝為可玩的原生桌面移植。程式碼庫以 C 與 CMake 為核心，Python 負責依使用者提供的 IPA 進行統一建置；Java 以及 armrecomp 等自訂工具與差分測試用於靜態重編譯與驗證；另有基於 Electron 的啟動器，支援模組與資產匯出流程。專案記錄 LIME 3D 引擎、街機格鬥邏輯與專有二進位格式，並提供具多種圖形後端的 Win32 與 SDL2 執行環境。面向逆向工程師、遊戲保存研究者，以及研究行動遊戲二進位、互通性，以及如何從已發行的 Mach-O 可執行檔還原經典格鬥遊戲邏輯、且不散布受版權保護資產的相關人士。
