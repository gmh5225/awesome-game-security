Этот проект — clean-room декомпиляция iOS-версии Ultimate Mortal Kombat 3 2011 года: все 2 572 игровые функции armv7 переписаны в проверенный C и обёрнуты в играбельный нативный порт для настольных систем. Кодовая база строится на C и CMake; Python обеспечивает единые сборки из IPA, предоставленного пользователем; Java и собственные инструменты вроде armrecomp и дифференциальные тесты — для статической перекомпиляции и верификации; есть лаунчер на Electron с рабочими процессами модов и экспорта ассетов. Документируются 3D-движок LIME, логика аркадных боёв и проприетарные бинарные форматы; поставляются среды выполнения Win32 и SDL2 с несколькими графическими бэкендами. Аудитория — реверс-инженеры, энтузиасты сохранения и все, кто изучает бинарники мобильных игр, совместимость и восстановление классической логики файтингов из поставляемых Mach-O без распространения объектов, защищённых авторским правом.
