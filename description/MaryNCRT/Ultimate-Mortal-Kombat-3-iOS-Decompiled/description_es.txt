Este proyecto es una descompilación en clean room de la edición iOS de 2011 de Ultimate Mortal Kombat 3, que transcribe las 2.572 funciones de juego armv7 a C verificado y las envuelve en un port nativo jugable para escritorio. La base de código se centra en C y CMake, con Python impulsando compilaciones unificadas a partir de un IPA proporcionado por el usuario, Java y herramientas personalizadas como armrecomp y pruebas diferenciales para recompilación estática y verificación, y un launcher basado en Electron con flujos de trabajo de mods y exportación de assets. Documenta el motor 3D LIME, la lógica de combate arcade y formatos binarios propietarios, y ofrece runtimes Win32 y SDL2 con varios backends gráficos. Está dirigido a ingenieros inversos, preservacionistas y quienes estudien binarios de juegos móviles, interoperabilidad y cómo se recupera la lógica de juegos de lucha clásicos desde ejecutables Mach-O publicados sin distribuir activos con copyright.
