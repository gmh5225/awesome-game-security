This project is a clean-room decompilation of the 2011 iOS release of Ultimate Mortal Kombat 3, transcribing all 2,572 armv7 game functions into verified C and wrapping them in a playable native desktop port. The codebase centers on C and CMake, with Python driving unified builds from a user-supplied IPA, Java and custom tooling such as armrecomp and differential tests for static recompilation and verification, and an Electron-based launcher with mod and asset export workflows. It documents the LIME 3D engine, arcade fight logic, and proprietary binary formats while providing Win32 and SDL2 runtimes with multiple graphics backends. It targets reverse engineers, preservationists, and anyone studying mobile game binaries, interoperability, and how classic fighting-game logic is recovered from shipped Mach-O executables without distributing copyrighted assets.
