本プロジェクトは、2011年リリースの iOS 版 Ultimate Mortal Kombat 3 のクリーンルーム逆コンパイルであり、2,572 個の armv7 ゲーム関数をすべて検証済み C に書き起こし、プレイ可能なネイティブデスクトップ移植として包んだものです。コードベースは C と CMake を中心とし、Python がユーザー提供の IPA からの統一ビルドを担い、Java と armrecomp などのカスタムツールおよび差分テストが静的再コンパイルと検証を支え、Electron ベースのランチャーが MOD とアセットエクスポートのワークフローを提供します。LIME 3D エンジン、アーケード格闘ロジック、独自バイナリ形式を文書化し、複数のグラフィックスバックエンドを備えた Win32 と SDL2 ランタイムを提供します。リバースエンジニア、保存活動家、モバイルゲームバイナリや相互運用性、配布された Mach-O 実行ファイルからクラシック格闘ゲームのロジックを著作権で保護されたアセットを配布せずに復元する方法を学ぶ人を対象としています。
