本项目是对 2011 年 iOS 版 Ultimate Mortal Kombat 3 的洁净室反编译，将全部 2,572 个 armv7 游戏函数转写为经核验的 C 代码，并封装为可玩的原生桌面移植。代码库以 C 与 CMake 为核心，Python 负责基于用户提供的 IPA 进行统一构建；Java 及 armrecomp 等定制工具与差分测试用于静态重编译与验证；另有基于 Electron 的启动器，支持模组与资源导出流程。项目记录了 LIME 3D 引擎、街机格斗逻辑与专有二进制格式，并提供带多种图形后端的 Win32 与 SDL2 运行时。面向逆向工程师、游戏遗产保存研究者，以及研究移动游戏二进制、互操作性与如何从已发布的 Mach-O 可执行文件中还原经典格斗游戏逻辑、且不分发受版权保护资产的相关人员。
