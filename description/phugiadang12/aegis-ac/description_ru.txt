Aegis AC — серверный поведенческий античит-стек для многопользовательских FPS, который помечает читеров по телеметрии, которую игровой сервер уже собирает, без клиентских драйверов и чтения памяти игроков. Он в основном написан на Python в трёх пакетах — collector, detection и soc-agent — с панелью на TypeScript и React для операций в реальном времени. Коллектор на FastAPI принимает события JSONL по UDP и HTTP в SQLite; объяснимый движок правил оценивает скорость поворота, точность, долю выстрелов в голову и взаимодействия с ловушками на фоне синтетических симуляторов читов; SOC-аналитик на базе Claude сортирует оповещения в отчёты по кейсам для ручного утверждения перед отложенными волнами банов и уведомлениями в Discord. Архитектура ориентирована на рабочие процессы игровой безопасности и античит-инженерии: приватное серверное обнаружение, red team-симуляция без распространения настоящих читов и сквозной конвейер от приёма данных до применения санкций.
