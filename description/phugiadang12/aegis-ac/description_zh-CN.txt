Aegis AC 是一套面向多人 FPS 游戏的服务端行为反作弊栈，仅依据游戏服务器已采集的遥测数据标记作弊者，无需客户端驱动或读取玩家内存。项目主要以 Python 实现，分为 collector、detection 与 soc-agent 三个包，并配有 TypeScript 与 React 的实时运营仪表板。FastAPI 采集器通过 UDP 与 HTTP 将 JSONL 事件写入 SQLite；可解释的规则引擎结合合成作弊模拟器，对转身速率、命中率、爆头率与蜜罐交互进行评分；由 Claude 驱动的 SOC 分析员在延迟封禁波次与 Discord 通知之前，将告警分诊为案例报告供人工审批。该设计面向游戏安全与反作弊工程流程：注重隐私的服务端专用检测、无需分发真实作弊程序的红队仿真，以及从采集到执法的端到端流水线。
