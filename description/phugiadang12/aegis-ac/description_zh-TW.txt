Aegis AC 是一套面向多人 FPS 遊戲的伺服器端行為反作弊堆疊，僅依據遊戲伺服器已收集的遙測資料標記作弊者，無需客戶端驅動程式或讀取玩家記憶體。專案主要以 Python 實作，分為 collector、detection 與 soc-agent 三個套件，並配有 TypeScript 與 React 的即時營運儀表板。FastAPI 收集器透過 UDP 與 HTTP 將 JSONL 事件寫入 SQLite；可解釋的規則引擎結合合成作弊模擬器，對轉身速率、命中率、爆頭率與蜜罐互動進行評分；由 Claude 驅動的 SOC 分析員在延遲封禁波次與 Discord 通知之前，將告警分診為案例報告供人工核准。此設計鎖定遊戲安全與反作弊工程流程：注重隱私的伺服器端專用偵測、無需散布真實作弊程式的紅隊模擬，以及從擷取到執法的端到端管線。
