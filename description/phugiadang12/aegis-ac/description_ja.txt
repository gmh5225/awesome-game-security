Aegis AC はマルチプレイヤー FPS 向けのサーバー側行動ベースアンチチートスタックで、ゲームサーバーが既に収集するテレメトリだけからチーターをフラグ付けし、クライアントドライバやプレイヤーメモリの読み取りは不要です。主に Python で構築され、collector・detection・soc-agent の3パッケージと、ライブ運用向けの TypeScript と React ダッシュボードで構成されます。FastAPI コレクターが UDP と HTTP 経由で JSONL イベントを SQLite に取り込み、説明可能なルールエンジンが合成チートシミュレータと照らしてターン率・命中率・ヘッドショット率・ハニーポット操作をスコア化し、Claude 駆動の SOC アナリストが遅延 BAN ウェーブと Discord 通知の前にアラートをケースレポートへ仕分けて人の承認を待ちます。ゲームセキュリティとアンチチートエンジニアリングのワークフロー向け設計で、プライバシーを守るサーバー専用検知、実チートを配布しないレッドチームシミュレーション、取り込みから執行までのエンドツーエンドパイプラインを目指しています。
