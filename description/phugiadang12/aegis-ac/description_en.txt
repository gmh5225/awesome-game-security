Aegis AC is a server-side behavioral anti-cheat stack for multiplayer FPS games that flags cheaters from telemetry the game server already collects, without client drivers or reading player memory. It is built primarily in Python across three packages—collector, detection, and soc-agent—with a TypeScript and React dashboard for live operations. A FastAPI collector ingests UDP and HTTP JSONL events into SQLite, an explainable rule engine scores turn rate, hit rate, headshot rate, and honeypot interactions against synthetic cheat simulators, and a Claude-powered SOC analyst triages alerts into case reports for human approval before delayed ban waves and Discord notifications. The design targets game security and anti-cheat engineering workflows: privacy-preserving server-only detection, red-team simulation without shipping real cheats, and an end-to-end pipeline from ingestion through enforcement.
