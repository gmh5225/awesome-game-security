Aegis AC è uno stack anti-cheat comportamentale lato server per giochi FPS multigiocatore che segnala i cheater dalla telemetria che il server di gioco raccoglie già, senza driver client né lettura della memoria dei giocatori. È realizzato principalmente in Python in tre pacchetti — collector, detection e soc-agent — con una dashboard TypeScript e React per le operazioni live. Un collector FastAPI ingerisce eventi JSONL via UDP e HTTP in SQLite; un motore di regole spiegabile valuta velocità di rotazione, percentuale di colpi, headshot e interazioni con honeypot rispetto a simulatori di cheat sintetici; un analista SOC basato su Claude smista gli alert in report di caso per approvazione umana prima di ondate di ban ritardati e notifiche Discord. Il design è rivolto ai flussi di lavoro di sicurezza dei giochi e ingegneria anti-cheat: rilevamento solo server che preserva la privacy, simulazione red team senza distribuire cheat reali e pipeline end-to-end dall’ingestion all’applicazione delle sanzioni.
