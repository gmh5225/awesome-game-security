Aegis AC는 멀티플레이어 FPS용 서버 측 행동 기반 안티치트 스택으로, 게임 서버가 이미 수집하는 원격 측정만으로 치터를 표시하며 클라이언트 드라이버나 플레이어 메모리 읽기는 필요 없습니다. 주로 Python으로 구춠되며 collector, detection, soc-agent 세 패키지와 실시간 운영용 TypeScript·React 대시보드로 이루어집니다. FastAPI 수집기가 UDP와 HTTP로 JSONL 이벤트를 SQLite에 적재하고, 설명 가능한 규칙 엔진이 합성 치트 시뮬레이터와 대조해 턴 속도, 명중률, 헤드샷 비율, 허니팟 상호작용을 점수화하며, Claude 기반 SOC 분석가가 지연 밴 웨이브와 Discord 알림 전에 경보를 사례 보고로 분류해 사람의 승인을 받습니다. 게임 보안 및 안티치트 엔지니어링 워크플로를 겨냥한 설계로, 프라이버시를 보존하는 서버 전용 탐지, 실제 치트 배포 없는 레드팀 시뮬레이션, 수집부터 집행까지의 엔드투엔드 파이프라인을 제공합니다.
