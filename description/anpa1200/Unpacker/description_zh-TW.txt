Unpacker 是一款模組化的 Python 工具，用於偵測並脫殼已加殼的惡意軟體樣本，使分析人員能夠取得真實程式碼、匯入表與字串以進行靜態分析。它結合多種加殼器識別方法——節區名稱、熵值分析、啟發式規則以及可選簽章——針對 PE 與 ELF 二進位檔，再將每個樣本導向可插拔的脫殼模組。支援的技術包括原生 UPX 解壓、基於 Unipacker 的 Unicorn 模擬以處理 32 位元 ASPack、Themida 與 VMProtect，以及用於 64 位元 VMProtect 的 Qiling 模擬，並可選多層重新偵測與 PE 重建。以 Python 3.10+ 撰寫，提供從偵測到脫殼再到驗證的單一 CLI 管線，面向惡意軟體分析人員、威脅情報工作流程，以及從事防禦性安全情境下加殼可執行檔分析工作的逆向工程師。
