Unpacker 是一款模块化的 Python 工具，用于检测并脱壳已加壳的恶意软件样本，使分析人员能够获取真实代码、导入表和字符串以进行静态分析。它结合多种壳识别方法——节区名称、熵值分析、启发式规则以及可选签名——针对 PE 和 ELF 二进制文件，然后将每个样本路由至可插拔的脱壳模块。支持的技术包括原生 UPX 解压、基于 Unipacker 的 Unicorn 模拟以处理 32 位 ASPack、Themida 和 VMProtect，以及用于 64 位 VMProtect 的 Qiling 模拟，并可选多层重新检测与 PE 重建。基于 Python 3.10+ 编写，它提供从检测到脱壳再到验证的单一 CLI 流水线，面向恶意软件分析人员、威胁情报工作流以及从事防御性安全场景下加壳可执行文件分析工作的逆向工程师。
