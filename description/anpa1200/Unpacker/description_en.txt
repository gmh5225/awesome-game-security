Unpacker is a modular Python tool that detects and unpacks packed malware samples so analysts can reach real code, imports, and strings for static analysis. It combines multi-method packer identification—section names, entropy analysis, heuristics, and optional signatures—for PE and ELF binaries, then routes each sample to a pluggable unpacker module. Supported techniques include native UPX decompression, Unipacker-based Unicorn emulation for 32-bit ASPack, Themida, and VMProtect, and Qiling emulation for 64-bit VMProtect, with optional multi-layer re-detection and PE rebuilding. Written in Python 3.10+, it provides a single CLI pipeline from detection through unpacking and validation, aimed at malware analysts, threat intelligence workflows, and reverse engineers working on packed executables in defensive security contexts.
