Unpacker es una herramienta modular en Python que detecta y desempaqueta muestras de malware empaquetadas para que los analistas puedan acceder al código real, importaciones y cadenas para análisis estático. Combina identificación de packers multi-método — nombres de secciones, análisis de entropía, heurísticas y firmas opcionales — para binarios PE y ELF, y enruta cada muestra a un módulo de desempaquetado conectable. Las técnicas admitidas incluyen descompresión nativa UPX, emulación Unicorn basada en Unipacker para ASPack, Themida y VMProtect de 32 bits, y emulación Qiling para VMProtect de 64 bits, con re-detección multicapa opcional y reconstrucción PE. Escrito en Python 3.10+, proporciona un único pipeline CLI desde la detección hasta el desempaquetado y la validación, orientado a analistas de malware, flujos de inteligencia de amenazas e ingenieros inversos que trabajan con ejecutables empaquetados en contextos de seguridad defensiva.
