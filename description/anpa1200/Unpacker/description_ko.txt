Unpacker는 패킹된 멀웨어 샘플을 탐지하고 언패킹하여 분석가가 정적 분석을 위해 실제 코드, 임포트, 문자열에 접근할 수 있게 하는 모듈형 Python 도구입니다. PE 및 ELF 바이너리에 대해 섹션 이름, 엔트로피 분석, 휴리스틱, 선택적 시그니처 등 다중 방법의 패커 식별을 결합한 뒤 각 샘플을 플러그인 가능한 언패커 모듈로 라우팅합니다. 지원 기법에는 네이티브 UPX 압축 해제, 32비트 ASPack, Themida, VMProtect용 Unipacker 기반 Unicorn 에뮬레이션, 64비트 VMProtect용 Qiling 에뮬레이션, 선택적 다층 재탐지 및 PE 재구성이 포함됩니다. Python 3.10+로 작성되었으며, 탐지부터 언패킹, 검증까지 단일 CLI 파이프라인을 제공하여 방어적 보안 맥락에서 패킹된 실행 파일을 다루는 멀웨어 분석가, 위협 인텔리전스 워크플로, 리버스 엔지니어를 대상으로 합니다.
