Unpacker は、パックされたマルウェアサンプルを検出してアンパックし、分析者が静的解析のために実際のコード、インポート、文字列にアクセスできるようにするモジュラー型 Python ツールです。セクション名、エントロピー分析、ヒューリスティック、オプションのシグネチャなど複数の手法によるパッカー識別を PE および ELF バイナリに組み合わせ、各サンプルをプラグイン可能なアンパッカーモジュールにルーティングします。サポートされる手法には、ネイティブ UPX 解凍、32 ビット ASPack・Themida・VMProtect 向けの Unipacker ベースの Unicorn エミュレーション、64 ビット VMProtect 向けの Qiling エミュレーション、オプションの多層再検出と PE 再構築が含まれます。Python 3.10+ で書かれており、検出からアンパック、検証までを一つの CLI パイプラインで提供し、防御的セキュリティの文脈でパックされた実行ファイルに取り組むマルウェア分析者、脅威インテリジェンスのワークフロー、リバースエンジニアを対象としています。
