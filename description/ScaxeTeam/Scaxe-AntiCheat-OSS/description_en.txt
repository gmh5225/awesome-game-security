Scaxe-AntiCheat-OSS is an open release of pretrained machine learning weights for detecting suspicious player behavior in Minecraft from temporal input features. The published checkpoint uses a compact Conformer encoder with roughly one million parameters, stored in Safetensors format as PRC-Open-0.5.5-1M, and expects batched float32 tensors shaped for short behavioral sequences. It is aimed at game security researchers, server operators, and anti-cheat developers who want to study or integrate sequence-based cheat detection rather than rule-only heuristics.
