Scaxe-AntiCheat-OSS — открытая публикация предобученных весов машинного обучения для обнаружения подозрительного поведения игроков в Minecraft по временным входным признакам. Опубликованная контрольная точка использует компактный энкодер Conformer примерно с миллионом параметров, сохранённый в формате Safetensors как PRC-Open-0.5.5-1M, и ожидает пакетные тензоры float32, сформированные для коротких поведенческих последовательностей. Проект ориентирован на исследователей безопасности игр, администраторов серверов и разработчиков античитов, которым нужно изучать или внедрять детекцию читов на основе последовательностей, а не только эвристики по правилам.
