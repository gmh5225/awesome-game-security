Este repositorio recopila agentes JavaScript de Frida para la instrumentación dinámica de aplicaciones Android e iOS endurecidas. El arnés principal de Android oculta artefactos de root, emulador y Frida mediante hooks del sistema de archivos nativo y de maps, contadores antidepuración, hooks opcionales de Play Integrity y amplias omisiones de TLS pinning para Conscrypt, OkHttp y pilas relacionadas. Un script complementario para iOS aplica el mismo enfoque de enmascaramiento de fuentes a comprobaciones de jailbreak y certificate pinning en dispositivos arm64. Otros scripts combinan omisión SSL con flujos de VAPT orientados a proxy y mitigación de cierres por crash antiegreso para objetivos de aplicaciones concretas. Los scripts están pensados para Frida 16 y 17 y van dirigidos a ingenieros inversos, probadores de penetración e investigadores de seguridad móvil que analizan protecciones del lado cliente.
