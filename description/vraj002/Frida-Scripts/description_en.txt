This repository collects Frida JavaScript agents for dynamic instrumentation of hardened Android and iOS applications. The main Android harness masks root, emulator, and Frida artifacts via native filesystem and maps hooks, anti-debug counters, optional Play Integrity hooks, and broad TLS pinning bypasses for Conscrypt, OkHttp, and related stacks. A companion iOS script applies the same source-masking approach to jailbreak checks and certificate pinning on arm64 devices. Additional scripts combine SSL bypass with proxy-oriented VAPT workflows and anti-exit crash mitigation for specific app targets. The scripts target Frida 16 and 17 and are meant for reverse engineers, penetration testers, and mobile security researchers analyzing client-side protections.
