MLAntiCheat は、Minecraft Paper サーバー向けの戦闘アンチチートプラグインで、プレイヤーの照準と戦闘の仕方を分析し、自サーバーのデータで訓練した機械学習モデルでその行動をスコア化します。Java で Paper 1.21.4+ および Java 21 向けに書かれており、ニューラルネットワークとロジスティックモデルのアンサンブル、異常検知、戦闘時の視点回転からの特徴抽出を用い、任意で PacketEvents と連携してより正確なパケットレベルの回転追跡を実現します。運営者は戦闘中に正常プレイヤーとチートプレイヤーにラベルを付けて学習データを構築し、処罰を有効にする前に Shadow Mode でアラートと記録された証拠を確認します。スタッフ向けアラート、管理 GUI、レビュー済みプレイヤーデータからの自動再学習、設定可能な浮動スコアタグ、安全な戦闘テスト用の実体ダミーも提供します。固定ルールベースのアンチチートではなく、適応的でサーバー固有のチート検知を求める PvP サーバー管理者向けです。
