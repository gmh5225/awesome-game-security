MLAntiCheat — это плагин боевого античита для серверов Minecraft Paper, который анализирует, как игроки целятся и сражаются, а затем оценивает это поведение с помощью моделей машинного обучения, обученных на данных вашего собственного сервера. Написан на Java для Paper 1.21.4+ и Java 21, использует ансамбли нейронных и логистических моделей, обнаружение аномалий и извлечение признаков из боевых поворотов камеры, с опциональной интеграцией PacketEvents для более точного отслеживания поворотов на уровне пакетов. Операторы помечают честных и читерских игроков во время боёв для формирования обучающих наборов, затем используют Shadow Mode для проверки оповещений и записанных доказательств перед включением наказаний. Плагин также предоставляет оповещения для персонала, админ-GUI, автоматическое переобучение на проверенных данных игроков, настраиваемые плавающие теги с оценками и физический манекен для безопасного тестирования боя. Предназначен для администраторов PvP-серверов, которым нужно адаптивное, специфичное для сервера обнаружение читов вместо античита с фиксированными правилами.
