MLAntiCheat ist ein Kampf-Anti-Cheat-Plugin für Minecraft-Paper-Server, das analysiert, wie Spieler zielen und kämpfen, und dieses Verhalten dann mit maschinellen Lernmodellen bewertet, die auf Daten von Ihrem eigenen Server trainiert wurden. In Java für Paper 1.21.4+ und Java 21 geschrieben, nutzt es Ensemble-Modelle aus neuronalen und logistischen Modellen, Anomalieerkennung und Merkmalextraktion aus Kampfrotationen, mit optionaler PacketEvents-Integration für genauere Paket-Level-Rotationsverfolgung. Betreiber kennzeichnen legitime Spieler und Cheater während Kämpfen, um Trainingsdatensätze aufzubauen, und verlassen sich dann auf Shadow Mode, um Warnungen und aufgezeichnete Beweise zu prüfen, bevor Strafen aktiviert werden. Das Plugin bietet außerdem Staff-Warnungen, eine Admin-GUI, automatisches Nachtraining aus geprüften Spielerdaten, konfigurierbare schwebende Score-Tags und eine physische Dummy-Figur für sicheres Kampftesten. Es richtet sich an PvP-Server-Administratoren, die adaptive, serverspezifische Cheat-Erkennung statt eines festen regelbasierten Anti-Cheats wünschen.
