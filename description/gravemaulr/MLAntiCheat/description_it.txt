MLAntiCheat è un plugin anti-cheat per il combattimento su server Minecraft Paper che analizza come i giocatori mirano e combattono, quindi valuta quel comportamento con modelli di machine learning addestrati sui dati del proprio server. Scritto in Java per Paper 1.21.4+ e Java 21, utilizza modelli neurali e logistici in ensemble, rilevamento delle anomalie ed estrazione di feature dalle rotazioni di combattimento, con integrazione opzionale di PacketEvents per un tracciamento delle rotazioni a livello di pacchetto più accurato. Gli operatori etichettano giocatori legittimi e cheater durante i combattimenti per costruire set di addestramento, poi si affidano a Shadow Mode per rivedere avvisi e prove registrate prima di abilitare le punizioni. Il plugin offre anche avvisi per lo staff, una GUI di amministrazione, riaddestramento automatico dai dati dei giocatori revisionati, tag di punteggio flottanti configurabili e un manichino fisico per test di combattimento sicuri. È pensato per gli amministratori di server PvP che vogliono un rilevamento cheat adattivo e specifico del server invece di un anti-cheat basato su regole fisse.
