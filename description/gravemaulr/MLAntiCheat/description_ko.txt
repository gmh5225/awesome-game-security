MLAntiCheat는 Minecraft Paper 서버용 전투 안티치트 플러그인으로, 플레이어의 조준과 전투 방식을 분석한 뒤 자신의 서버 데이터로 훈련한 머신러닝 모델로 해당 행동을 점수화합니다. Java로 작성되었으며 Paper 1.21.4+ 및 Java 21을 지원하며, 앙상블 신경망 및 로지스틱 모델, 이상 탐지, 전투 시 시점 회전에서의 특징 추출을 사용하고, 선택적으로 PacketEvents 연동으로 더 정확한 패킷 수준 회전 추적을 제공합니다. 운영자는 전투 중 정상 플레이어와 치트 플레이어에 라벨을 붙여 학습 데이터를 구축한 뒤, 처벌을 활성화하기 전 Shadow Mode에서 알림과 기록된 증거를 검토합니다. 또한 스태프 알림, 관리자 GUI, 검토된 플레이어 데이터 기반 자동 재학습, 설정 가능한 플로팅 점수 태그, 안전한 전투 테스트용 물리 더미도 제공합니다. 고정 규칙 기반 안티치트 대신 적응형·서버별 치트 탐지를 원하는 PvP 서버 관리자를 위한 도구입니다.
