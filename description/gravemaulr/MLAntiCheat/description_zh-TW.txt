MLAntiCheat 是一款面向 Minecraft Paper 伺服器的戰鬥反作弊外掛，透過分析玩家的瞄準與戰鬥方式，並使用以你自己伺服器資料訓練的機器學習模型對該行為進行評分。該外掛以 Java 撰寫，適用於 Paper 1.21.4+ 與 Java 21，採用集成神經網路與邏輯迴歸模型、異常偵測，以及從戰鬥視角旋轉中提取特徵，並可選用 PacketEvents 整合以實現更精確的封包級旋轉追蹤。管理員可在戰鬥過程中標記正常玩家與作弊玩家以建立訓練集，然後在啟用處罰前依賴 Shadow Mode 審核警報與錄製證據。外掛還提供員工警報、管理 GUI、基於已審核玩家資料的自動重訓練、可設定的浮動評分標籤，以及用於安全戰鬥測試的實體假人。它面向希望獲得自適應、伺服器專屬作弊偵測而非固定規則式反作弊的 PvP 伺服器管理員。
