MLAntiCheat 是一款面向 Minecraft Paper 服务端的战斗反作弊插件，通过分析玩家的瞄准与战斗方式，并使用基于你自己服务器数据训练的机器学习模型对该行为进行评分。该插件使用 Java 编写，适用于 Paper 1.21.4+ 与 Java 21，采用集成神经网络与逻辑回归模型、异常检测，以及从战斗视角旋转中提取特征，并可选用 PacketEvents 集成以实现更精确的数据包级旋转追踪。管理员可在战斗过程中标记正常玩家与作弊玩家以构建训练集，然后在启用处罚前依赖 Shadow Mode 审核警报与录制证据。插件还提供员工警报、管理 GUI、基于已审核玩家数据的自动重训练、可配置的浮动评分标签，以及用于安全战斗测试的实体假人。它面向希望获得自适应、服务器专属作弊检测而非固定规则式反作弊的 PvP 服务器管理员。
