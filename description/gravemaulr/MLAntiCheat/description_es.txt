MLAntiCheat es un complemento anti-trampas de combate para servidores Minecraft Paper que analiza cómo apuntan y luchan los jugadores, y luego puntúa ese comportamiento con modelos de aprendizaje automático entrenados con datos de tu propio servidor. Escrito en Java para Paper 1.21.4+ y Java 21, utiliza modelos neuronales y logísticos en conjunto, detección de anomalías y extracción de características de las rotaciones de combate, con integración opcional de PacketEvents para un seguimiento de rotaciones a nivel de paquetes más preciso. Los operadores etiquetan a jugadores legítimos y tramposos durante los combates para crear conjuntos de entrenamiento, y luego confían en Shadow Mode para revisar alertas y pruebas grabadas antes de activar castigos. El complemento también ofrece alertas para el staff, una GUI de administración, reentrenamiento automático a partir de datos de jugadores revisados, etiquetas de puntuación flotantes configurables y un maniquí físico para pruebas de combate seguras. Está pensado para administradores de servidores PvP que quieren detección de trampas adaptativa y específica del servidor en lugar de un anti-trampas basado en reglas fijas.
