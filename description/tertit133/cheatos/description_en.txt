CheatOS is a compact Windows x64 memory scanner and trainer framework modeled after Cheat Engine for attaching to processes and manipulating live game memory. It is implemented in C++20 with CMake, exposing a Dear ImGui and DirectX 11 docking user interface and a modular engine for process attachment, region enumeration, and background scanning work. The tool supports typed first- and next-scan filters, byte patterns with wildcards, bookmarked addresses with a high-frequency value freezer thread, and BFS pointer-chain discovery rooted in module images. It can load and save a practical subset of Cheat Engine .CT tables through pugixml, making it useful for reverse engineers, trainer authors, and game security researchers who need a small, readable codebase to study memory scanning and trainer behavior on Windows.
