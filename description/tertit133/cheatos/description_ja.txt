CheatOS は、Cheat Engine を手本にしたコンパクトな Windows x64 向けメモリスキャナーおよびトレーナーフレームワークで、プロセスへアタッチして実行中のゲームメモリを操作します。C++20 と CMake で実装され、Dear ImGui と DirectX 11 のドッキング UI、プロセスアタッチ・リージョン列挙・バックグラウンドスキャン用のモジュールエンジンを提供します。型付きの初回／次回スキャンフィルタ、ワイルドカード付きバイトパターン、ブックマークアドレスと高頻度の値フリーザースレッド、モジュールイメージを根とした BFS ポインタチェーン探索をサポートします。pugixml により Cheat Engine の .CT テーブルの実用的な部分集合の読み書きが可能で、Windows 上のメモリスキャンとトレーナー挙動を学ぶための小さく読みやすいコードベースを求めるリバースエンジニア、トレーナー作者、ゲームセキュリティ研究者に適しています。
