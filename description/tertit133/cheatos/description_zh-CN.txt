CheatOS 是一款紧凑的 Windows x64 内存扫描与修改器框架，沿袭 Cheat Engine 的思路，用于附加进程并操作运行中的游戏内存。项目以 C++20 与 CMake 实现，提供基于 Dear ImGui 与 DirectX 11 的可停靠用户界面，以及模块化的进程附加、区域枚举与后台扫描引擎。工具支持带类型的首次/下次扫描过滤、含通配符的字节模式、可书签地址及高频数值冻结线程，并可在模块映像上执行 BFS 指针链发现。借助 pugixml 可加载与保存 Cheat Engine .CT 表的部分实用子集，适合需要小巧、可读代码库以研究 Windows 上内存扫描与修改器行为的逆向工程师、修改器作者及游戏安全研究人员。
