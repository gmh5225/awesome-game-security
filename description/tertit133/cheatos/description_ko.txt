CheatOS는 Cheat Engine을 본떠 만든 컴팩트한 Windows x64 메모리 스캐너 및 트레이너 프레임워크로, 프로세스에 부착해 실행 중인 게임 메모리를 조작합니다. C++20과 CMake로 구현되었으며 Dear ImGui와 DirectX 11 도킹 UI, 프로세스 부착·영역 열거·백그라운드 스캔을 위한 모듈형 엔진을 제공합니다. 형식이 지정된 첫/다음 스캔 필터, 와일드카드가 있는 바이트 패턴, 북마크 주소와 고빈도 값 동결 스레드, 모듈 이미지를 뿌리로 한 BFS 포인터 체인 탐색을 지원합니다. pugixml을 통해 Cheat Engine .CT 테이블의 실용적인 부분 집합을 불러오고 저장할 수 있어, Windows에서 메모리 스캔과 트레이너 동작을 연구하기 위한 작고 읽기 쉬운 코드베이스가 필요한 리버스 엔지니어, 트레이너 제작자, 게임 보안 연구자에게 유용합니다.
