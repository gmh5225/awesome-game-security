CheatOS 是一款精簡的 Windows x64 記憶體掃描與訓練器框架，仿照 Cheat Engine 設計，用於附加至行程並操作執行中的遊戲記憶體。專案以 C++20 與 CMake 實作，提供 Dear ImGui 與 DirectX 11 的可停駐式使用者介面，以及模組化的行程附加、區域列舉與背景掃描引擎。工具支援型別化的首次／下次掃描篩選、含萬用字元的位元組樣式、書籤位址與高頻數值凍結執行緒，並可自模組映像進行 BFS 指標鏈探索。透過 pugixml 可載入與儲存 Cheat Engine .CT 表的部分實用子集，適合需要小巧、可讀程式碼庫以研究 Windows 上記憶體掃描與訓練器行為的逆向工程師、訓練器作者與遊戲安全研究人員。
