ChompChomp.io — браузерная многопользовательская .io-игра в стиле slither, где вооружённые змеи соревнуются на общей арене с оружием, усилениями и боевой механикой. Стек целиком на JavaScript: canvas-клиент с предсказанием и интерполяцией, общие правила симуляции в sim.js и авторитетная логика комнат, собранная для развёртывания через Node build.js, плюс HTML и CSS для оболочки. Anti-cheat на Multiplayer Agent серверно-авторитетный: клиенты отправляют только проверенные вводы руления, ускорения и стрельбы, а сервер симулирует движение, подбор предметов, пули, столкновения, очки и сохраняемую статистику с частотой 20 тиков в секунду. Подходит для изучения безопасности игр и anti-cheat, как справочник по netcode и для разработчиков, которым нужен полный пример надёжного браузерного мультиплеера без собственного игрового сервера.
