ChompChomp.io è un gioco .io multigiocatore stile slither basato sul browser, in cui serpenti armati competono in un’arena condivisa con armi, power-up e meccaniche di combattimento. Lo stack è JavaScript end-to-end: client canvas con predizione e interpolazione, regole di simulazione condivise in sim.js e logica di stanza autoritativa impacchettata per il deploy tramite Node build.js, più HTML e CSS per il guscio. L’anti-cheat è autoritativo lato server su Multiplayer Agent: i client inviano solo input validati di sterzo, boost e fuoco, mentre il server simula movimento, raccolte, proiettili, collisioni, punteggi e statistiche persistenti a 20 tick al secondo. Adatto allo studio della sicurezza dei giochi e dell’anti-cheat, come riferimento netcode e per sviluppatori che vogliono un esempio completo di multigiocatore browser affidabile senza gestire un proprio game server.
