ChompChomp.io is a browser-based multiplayer slither-style .io game where armed snakes compete in a shared arena with guns, power-ups, and combat mechanics. The stack is JavaScript throughout: a canvas client with prediction and interpolation, shared simulation rules in sim.js, and authoritative room logic bundled for deployment via Node build.js, plus HTML and CSS for the shell. Anti-cheat is server-authoritative on Multiplayer Agent: clients send only validated steering, boost, and fire inputs while the server simulates movement, pickups, bullets, collisions, scores, and persisted stats at 20 ticks per second. It suits game security and anti-cheat study, netcode reference, and developers who want a full example of trustworthy browser multiplayer without operating their own game server.
