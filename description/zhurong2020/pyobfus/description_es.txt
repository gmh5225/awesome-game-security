pyobfus es un ofuscador de código Python de código abierto, basado en AST, que transforma el código fuente antes del despliegue para disuadir la ingeniería inversa y proteger la propiedad intelectual. Realiza renombrado de identificadores entre archivos, codificación de literales de cadenas y numéricos, reescritura de imports y aplanamiento del flujo de control, con configuración YAML y ajustes predefinidos para FastAPI, Django, Flask y stacks relacionados. Entre sus funciones destacadas están el escaneo de riesgos previo al despliegue, el mapeo inverso de trazas de pila para depurar builds protegidos, una CLI JSON legible por máquina, un servidor MCP para agentes de codificación con IA y una extensión de VS Code, además de un nivel Pro opcional con protecciones más fuertes como cifrado AES de cadenas. Escrito principalmente en Python para CPython 3.9 a 3.14, está dirigido a desarrolladores que necesitan reforzar aplicaciones Python comerciales, herramientas relacionadas con juegos y otro código distribuido contra el análisis y la manipulación ocasionales.
