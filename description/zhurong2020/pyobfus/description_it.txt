pyobfus è un obfuscator di codice Python open source, basato su AST, che trasforma il codice sorgente prima della distribuzione per scoraggiare il reverse engineering e proteggere la proprietà intellettuale. Esegue rinomina degli identificatori tra file, codifica di letterali stringa e numerici, riscrittura degli import e appiattimento del flusso di controllo, con configurazione YAML e preset consapevoli dei framework per FastAPI, Django, Flask e stack correlati. Tra le funzionalità principali figurano la scansione dei rischi preliminare, il mapping inverso dello stack trace per il debug di build protette, una CLI JSON leggibile da macchina, un server MCP per agenti di coding IA e un’estensione VS Code, oltre a un livello Pro opzionale con protezioni più robuste come la crittografia AES delle stringhe. Scritto principalmente in Python per CPython dalla 3.9 alla 3.14, è pensato per sviluppatori che devono rafforzare applicazioni Python commerciali, strumenti legati ai giochi e altro codice distribuito contro analisi e manomissioni occasionali.
