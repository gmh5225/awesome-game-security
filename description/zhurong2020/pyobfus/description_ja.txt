pyobfus は、オープンソースの AST ベース Python コード難読化ツールで、配布前にソースコードを変換し、リバースエンジニアリングを阻害して知的財産を保護します。ファイル間の識別子リネーム、文字列・数値リテラルのエンコード、import の書き換え、制御フローの平坦化を行い、YAML 設定と FastAPI、Django、Flask などのフレームワーク向けプリセットを備えています。主な機能には、事前リスクスキャン、保護済みビルドのデバッグ用逆スタックトレースマッピング、機械可読な JSON CLI、AI コーディングエージェント向け MCP サーバー、VS Code 拡張機能があり、オプションの Pro 版では AES 文字列暗号化などより強力な保護も提供します。主に Python で書かれ、CPython 3.9 から 3.14 に対応し、商用 Python アプリケーション、ゲーム関連ツール、その他配布コードを手軽な解析や改ざんから守りたい開発者向けです。
