pyobfus est un obfuscateur de code Python open source, basé sur l’AST, qui transforme le code source avant la distribution afin de décourager l’ingénierie inverse et de protéger la propriété intellectuelle. Il effectue le renommage d’identifiants entre fichiers, l’encodage des littéraux de chaînes et numériques, la réécriture des imports et l’aplatissement du flux de contrôle, avec une configuration YAML et des préréglages adaptés à FastAPI, Django, Flask et les piles associées. Parmi ses fonctionnalités notables figurent l’analyse de risques préalable, le mappage inverse des traces de pile pour déboguer les builds protégés, une CLI JSON lisible par machine, un serveur MCP pour les agents de codage IA et une extension VS Code, ainsi qu’un niveau Pro optionnel offrant des protections renforcées comme le chiffrement AES des chaînes. Principalement écrit en Python pour CPython 3.9 à 3.14, il s’adresse aux développeurs qui doivent durcir des applications Python commerciales, des outils liés aux jeux et d’autres codes distribués contre l’analyse et la falsification occasionnelles.
