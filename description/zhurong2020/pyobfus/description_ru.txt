pyobfus — это обфускатор Python-кода с открытым исходным кодом на основе AST, который преобразует исходники перед поставкой, чтобы затруднить реверс-инжиниринг и защитить интеллектуальную собственность. Он выполняет переименование идентификаторов между файлами, кодирование строковых и числовых литералов, переписывание import и выравнивание потока управления, с конфигурацией YAML и пресетами для FastAPI, Django, Flask и связанных стеков. Среди заметных возможностей — предварительное сканирование рисков, обратное сопоставление stack trace для отладки защищённых сборок, машиночитаемый JSON CLI, MCP-сервер для AI-агентов кодирования и расширение VS Code, а также опциональный уровень Pro с более сильной защитой, например AES-шифрованием строк. Написан в основном на Python для CPython 3.9–3.14 и предназначен для разработчиков, которым нужно усилить коммерческие Python-приложения, игровые инструменты и другой распространяемый код против поверхностного анализа и подмены.
