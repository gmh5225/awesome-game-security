pyobfus 是一款開源、以 AST 為基礎的 Python 程式碼混淆器，在出貨前轉換原始碼，以阻礙逆向工程並保護智慧財產權。它支援跨檔案識別碼重新命名、字串與數值常值編碼、import 重寫以及控制流程扁平化，並提供 YAML 設定及針對 FastAPI、Django、Flask 等框架的預設。主要功能包括發布前風險掃描、用於除錯受保護建置的反向堆疊追蹤對應、機器可讀的 JSON CLI、供 AI 程式設計代理使用的 MCP 伺服器，以及 VS Code 擴充功能；可選的 Pro 版本還提供 AES 字串加密等更強保護。主要以 Python 撰寫，支援 CPython 3.9 至 3.14，適合需要強化商業 Python 應用、遊戲相關工具及其他出貨程式碼、以抵禦一般性分析與竄改的開發者。
