pyobfus는 오픈 소스 AST 기반 Python 코드 난독화 도구로, 배포 전에 소스를 변환하여 리버스 엔지니어링을 억제하고 지적 재산을 보호합니다. 파일 간 식별자 이름 변경, 문자열·숫자 리터럴 인코딩, import 재작성, 제어 흐름 평탄화를 수행하며 YAML 설정과 FastAPI, Django, Flask 등 프레임워크 인식 프리셋을 제공합니다. 주요 기능으로는 사전 위험 스캔, 보호된 빌드 디버깅을 위한 역 스택 추적 매핑, 기계 판독 가능한 JSON CLI, AI 코딩 에이전트용 MCP 서버, VS Code 확장이 있으며, 선택적 Pro 등급에서는 AES 문자열 암호화 등 더 강력한 보호도 제공합니다. 주로 Python으로 작성되었으며 CPython 3.9~3.14를 지원하며, 상용 Python 애플리케이션, 게임 관련 도구 및 기타 배포 코드를 일반적인 분석과 변조로부터 강화하려는 개발자를 위한 도구입니다.
