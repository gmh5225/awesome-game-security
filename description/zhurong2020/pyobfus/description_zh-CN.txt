pyobfus 是一款开源、基于 AST 的 Python 代码混淆器，在发布前对源码进行变换，以阻碍逆向工程并保护知识产权。它支持跨文件标识符重命名、字符串与数值字面量编码、import 重写以及控制流平坦化，并提供 YAML 配置及针对 FastAPI、Django、Flask 等框架的预设。 主要功能包括发布前风险扫描、用于调试受保护构建的反向堆栈跟踪映射、机器可读的 JSON CLI、面向 AI 编程代理的 MCP 服务器，以及 VS Code 扩展；可选 Pro 版本还提供 AES 字符串加密等更强保护。主要使用 Python 编写，支持 CPython 3.9 至 3.14，面向需要加固商业 Python 应用、游戏相关工具及其他发布代码、以抵御一般性分析与篡改的开发者。
