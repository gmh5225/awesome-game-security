PhantomBuffer 是一款 Windows 研究工具，透過 SendMessage 搭配 WM_SETTEXT 對標準 Edit 控制項視窗控制代碼投遞 shellcode，在不呼叫 VirtualAllocEx 或 WriteProcessMemory 的情況下將程式碼注入遠端程序。緩衝區進入目標位址空間後，工具以遠端記憶體模式掃描定位位元組，調整頁面保護，並借助 Windows 偵錯器 cdb.exe 重新導向主執行緒的指令指標。專案以 C++ 與 Visual Studio 建置，並包含 FindTargetWindows，用於列舉合適的 Edit 控制項或為實驗目標啟動隱藏輔助程序。面向進攻性安全與 EDR 繞過研究，包括分析端點產品如何偵測經典跨程序記憶體寫入，以及替代注入路徑的行為。
