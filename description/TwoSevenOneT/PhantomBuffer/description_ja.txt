PhantomBuffer は Windows 向けの研究用ツールで、VirtualAllocEx や WriteProcessMemory を呼ばず、標準の Edit コントロールのウィンドウハンドルに対して SendMessage と WM_SETTEXT で shellcode をリモートプロセスへ届けます。バッファがターゲットのアドレス空間に載ったあと、リモートメモリのパターンスキャンでバイト列を特定し、ページ保護を変更し、Windows デバッガ cdb.exe 経由でメインスレッドの命令ポインタを書き換えます。C++ と Visual Studio で構築され、FindTargetWindows により適切な Edit コントロールの列挙や、ラボ向けターゲット用の非表示ヘルパープロセスの起動も行います。オフェンシブセキュリティや EDR バイパス研究向けで、エンドポイント製品が従来のクロスプロセスメモリ書き込みをどう検知するか、代替の注入経路がどう振る舞うかの調査を目的としています。
