PhantomBuffer 是一款 Windows 研究工具，通过 SendMessage 配合 WM_SETTEXT 向标准 Edit 控件窗口句柄投递 shellcode，在不调用 VirtualAllocEx 或 WriteProcessMemory 的情况下将代码注入远程进程。缓冲区进入目标地址空间后，工具通过远程内存模式扫描定位字节，调整页面保护，并借助 Windows 调试器 cdb.exe 重定向主线程的指令指针。项目使用 C++ 与 Visual Studio 构建，并包含 FindTargetWindows，用于枚举合适的 Edit 控件或为实验目标启动隐藏辅助进程。面向进攻性安全与 EDR 绕过研究，包括分析终端产品如何检测经典跨进程内存写入，以及替代注入路径的行为。
