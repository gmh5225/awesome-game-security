PhantomBuffer는 VirtualAllocEx나 WriteProcessMemory를 호출하지 않고, 표준 Edit 컨트롤 창 핸들에 SendMessage와 WM_SETTEXT를 사용해 shellcode를 원격 프로세스에 전달하는 Windows 연구 도구입니다. 버퍼가 대상 주소 공간에 들어간 뒤 원격 메모리 패턴 스캔으로 바이트를 찾고, 페이지 보호를 조정한 다음 Windows 디버거 cdb.exe를 통해 메인 스레드의 명령 포인터를 우회합니다. C++와 Visual Studio로 작성되었으며 FindTargetWindows가 포함되어 적합한 Edit 컨트롤을 열거하거나 실험용 대상을 위해 숨겨진 헬퍼 프로세스를 실행합니다. 공격적 보안 및 EDR 우회 연구, 특히 엔드포인트 제품이 전통적인 교차 프로세스 메모리 쓰기를 어떻게 탐지하는지와 대안적 주입 경로의 동작을 연구하는 데 목적이 있습니다.
