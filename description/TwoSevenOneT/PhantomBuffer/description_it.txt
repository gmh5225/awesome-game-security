PhantomBuffer è uno strumento di ricerca per Windows che consegna shellcode in un processo remoto senza chiamare VirtualAllocEx o WriteProcessMemory, usando SendMessage con WM_SETTEXT sull’handle di una finestra Edit standard. Dopo che il buffer è nello spazio di indirizzamento del target, individua i byte con scansione di pattern in memoria remota, regola la protezione delle pagine e reindirizza il puntatore alle istruzioni del thread principale tramite il debugger Windows cdb.exe. La soluzione è realizzata in C++ con Visual Studio e include FindTargetWindows, che enumera controlli Edit idonei o avvia processi helper nascosti per obiettivi da laboratorio. È pensata per la sicurezza offensiva e la ricerca sul bypass EDR, incluso lo studio di come i prodotti endpoint rilevano le classiche scritture di memoria cross-process e come si comportano percorsi di iniezione alternativi.
