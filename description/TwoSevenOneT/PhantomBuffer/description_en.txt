PhantomBuffer is a Windows research tool that delivers shellcode into a remote process without calling VirtualAllocEx or WriteProcessMemory, using SendMessage with WM_SETTEXT against a standard Edit control window handle. After the buffer lands in the target’s address space, it locates the bytes with remote memory pattern scanning, adjusts page protection, and redirects the main thread’s instruction pointer through the Windows debugger cdb.exe. The solution is built in C++ with Visual Studio and includes FindTargetWindows, which enumerates suitable Edit controls or launches hidden helper processes for lab targets. It is aimed at offensive security and EDR bypass research, including study of how endpoint products detect classic cross-process memory writes and how alternative injection paths behave.
