PhantomBuffer es una herramienta de investigación para Windows que introduce shellcode en un proceso remoto sin llamar a VirtualAllocEx ni WriteProcessMemory, usando SendMessage con WM_SETTEXT contra el handle de una ventana Edit estándar. Tras colocar el búfer en el espacio de direcciones del objetivo, localiza los bytes mediante escaneo de patrones en memoria remota, ajusta la protección de páginas y redirige el puntero de instrucción del hilo principal mediante el depurador de Windows cdb.exe. La solución está desarrollada en C++ con Visual Studio e incluye FindTargetWindows, que enumera controles Edit adecuados o lanza procesos auxiliares ocultos para objetivos de laboratorio. Está orientada a la seguridad ofensiva y la investigación de evasión de EDR, incluido el estudio de cómo los productos de endpoint detectan las escrituras clásicas de memoria entre procesos y cómo se comportan las vías de inyección alternativas.
