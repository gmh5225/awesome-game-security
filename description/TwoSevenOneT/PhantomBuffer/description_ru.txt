PhantomBuffer — исследовательский инструмент для Windows, который доставляет shellcode в удалённый процесс без вызова VirtualAllocEx или WriteProcessMemory, используя SendMessage с WM_SETTEXT для стандартного окна элемента управления Edit. После попадания буфера в адресное пространство цели он находит байты удалённым поиском по шаблону в памяти, меняет защиту страниц и перенаправляет указатель инструкций главного потока через отладчик Windows cdb.exe. Решение написано на C++ в Visual Studio и включает FindTargetWindows, который перечисляет подходящие элементы Edit или запускает скрытые вспомогательные процессы для лабораторных целей. Оно предназначено для offensive security и исследований обхода EDR, в том числе изучения того, как продукты на конечных точках обнаруживают классические межпроцессные записи в память и как ведут себя альтернативные пути инъекции.
