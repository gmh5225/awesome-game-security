InjectSetConsole — это инструмент на C++ для Windows, который внедряет код в дочерний процесс, передавая полезную нагрузку через каналы стандартного ввода, а не с помощью VirtualAllocEx и WriteProcessMemory. Он запускает интерактивную консольную программу, записывает встроенный shellcode в процесс через stdin, сканирует удалённую память на предмет маркерного шаблона для поиска буфера и делает эту область исполняемой с помощью VirtualProtectEx, прежде чем перехватить указатель инструкций основного потока через NtSetContextThread. Реализация включает вспомогательные функции для удалённого поиска шаблонов, обнаружения основного потока и ввода-вывода через каналы, с настраиваемым shellcode и шаблонами поиска для обхода. Предназначен для исследователей безопасности, изучающих внедрение в процессы, методы обхода EDR и античит- или offensive-инструменты в Windows x64.
