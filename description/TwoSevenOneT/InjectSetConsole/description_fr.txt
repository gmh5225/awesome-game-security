InjectSetConsole est un outil Windows en C++ qui injecte du code dans un processus enfant en alimentant un payload via les pipes d'entrée standard, plutôt qu'en utilisant VirtualAllocEx et WriteProcessMemory. Il lance un programme console interactif, écrit du shellcode embarqué dans le processus via stdin, analyse la mémoire distante pour trouver un motif marqueur afin de localiser le buffer, puis rend cette zone exécutable avec VirtualProtectEx avant de détourner le pointeur d'instruction du thread principal via NtSetContextThread. L'implémentation inclut des utilitaires pour le balayage distant de motifs, la découverte du thread principal et les E/S basées sur des pipes, avec un shellcode et des motifs de recherche personnalisables pour l'évasion. Il s'adresse aux chercheurs en sécurité qui étudient l'injection de processus, les techniques de contournement EDR et les outils anti-triche ou offensifs sur Windows x64.
