InjectSetConsole은 VirtualAllocEx와 WriteProcessMemory를 사용하는 대신 표준 입력 파이프를 통해 페이로드를 전달하여 코드를 자식 프로세스에 주입하는 Windows C++ 도구입니다. 대화형 콘솔 프로그램을 실행하고, stdin을 통해 내장 shellcode를 해당 프로세스에 기록한 뒤, 원격 메모리에서 마커 패턴을 스캔하여 버퍼 위치를 찾고, NtSetContextThread로 메인 스레드의 명령 포인터를 탈취하기 전에 VirtualProtectEx로 해당 영역을 실행 가능하게 만듭니다. 구현에는 원격 패턴 스캔, 메인 스레드 탐색, 파이프 기반 I/O를 위한 헬퍼가 포함되며, 회피를 위해 shellcode와 검색 패턴을 사용자 정의할 수 있습니다. Windows x64에서 프로세스 주입, EDR 우회 기법, 안티치트 및 공격적 도구를 연구하는 보안 연구자를 대상으로 합니다.
