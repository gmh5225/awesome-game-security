InjectSetConsole 是一款 Windows C++ 工具，通过标准输入管道注入有效载荷，而不是使用 VirtualAllocEx 和 WriteProcessMemory，将代码注入到子进程中。它会启动一个交互式控制台程序，通过 stdin 将嵌入的 shellcode 写入该进程，在远程内存中扫描标记模式以定位缓冲区，并在通过 NtSetContextThread 劫持主线程指令指针之前，使用 VirtualProtectEx 使该区域可执行。其实现包含远程模式扫描、主线程发现以及基于管道的 I/O 辅助功能，shellcode 和搜索模式可自定义以用于规避。该工具面向研究进程注入、EDR 绕过技术以及 Windows x64 反作弊或进攻性工具开发的安全研究人员。
