InjectSetConsole è uno strumento Windows in C++ che inietta codice in un processo figlio inviando un payload tramite pipe di input standard, anziché utilizzare VirtualAllocEx e WriteProcessMemory. Avvia un programma console interattivo, scrive shellcode incorporato nel processo tramite stdin, scansiona la memoria remota alla ricerca di un pattern marcatore per individuare il buffer e rende quella regione eseguibile con VirtualProtectEx prima di dirottare il puntatore alle istruzioni del thread principale tramite NtSetContextThread. L'implementazione include helper per la scansione remota di pattern, il rilevamento del thread principale e I/O basata su pipe, con shellcode e pattern di ricerca personalizzabili per l'evasione. È rivolto ai ricercatori di sicurezza che studiano l'iniezione di processi, le tecniche di bypass EDR e strumenti anti-cheat o offensivi su Windows x64.
