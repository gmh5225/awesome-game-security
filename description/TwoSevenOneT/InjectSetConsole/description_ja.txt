InjectSetConsole は、VirtualAllocEx と WriteProcessMemory を使わず、標準入力パイプ経由でペイロードを供給してコードを子プロセスに注入する Windows 用 C++ ツールです。インタラクティブなコンソールプログラムを起動し、stdin 経由で埋め込み shellcode をそのプロセスに書き込み、リモートメモリからマーカーパターンを検索してバッファを特定し、NtSetContextThread でメインスレッドの命令ポインタを乗っ取る前に VirtualProtectEx でその領域を実行可能にします。実装には、リモートパターンスキャン、メインスレッド検出、パイプベースの I/O 用のヘルパーが含まれ、回避のため shellcode と検索パターンもカスタマイズできます。Windows x64 上でのプロセスインジェクション、EDR バイパス手法、反チートおよび攻撃的ツールの研究を行うセキュリティ研究者向けです。
