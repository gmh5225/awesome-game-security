InjectSetConsole 是一款 Windows C++ 工具，透過標準輸入管道注入有效載荷，而非使用 VirtualAllocEx 和 WriteProcessMemory，將程式碼注入子程序。它會啟動互動式主控台程式，透過 stdin 將嵌入的 shellcode 寫入該程序，在遠端記憶體中掃描標記模式以定位緩衝區，並在透過 NtSetContextThread 劫持主執行緒指令指標之前，使用 VirtualProtectEx 使該區域可執行。其實作包含遠端模式掃描、主執行緒探索以及基於管道的 I/O 輔助功能，shellcode 與搜尋模式可自訂以用於規避。此工具面向研究程序注入、EDR 繞過技術，以及 Windows x64 反作弊或進攻性工具開發的安全研究人員。
