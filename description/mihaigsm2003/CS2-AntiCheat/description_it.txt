AntiCheat è un plugin Metamod:Source lato server per server dedicati Counter-Strike 2 che analizza mira, colpi, movimento, input e impostazioni segnalate dal client per rilevare cheat senza installazioni lato client. Include diciotto moduli di rilevamento configurabili che coprono assistenza alla mira, trigger e silent aim, exploit di movimento come bunnyhop e autostrafe, manipolazione subtick, cvar e input non validi, eventi client sospetti legati alle DLL e comportamenti rage correlati. L’implementazione è principalmente C++ sul Source 2 SDK, con hook, detour, analisi del movimento e query cvar client, più script Python e shell per il packaging Linux e Windows basato su AMBuild. Gli amministratori configurano punizioni, whitelist e reporting opzionale via webhook Discord o JSON tramite AntiCheat.cfg e comandi console. È pensato per amministratori di server CS2 e professionisti della game security che vogliono anti-cheat in-game basato su evidenze su host dedicati.
