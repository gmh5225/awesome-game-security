AntiCheat is a server-side Metamod:Source plugin for Counter-Strike 2 dedicated servers that analyzes player aim, shots, movement, inputs, and client-reported settings to detect cheating without any client install. It ships with eighteen configurable detection modules covering aim assistance, trigger and silent aim, movement exploits such as bunnyhop and autostrafe, subtick manipulation, invalid cvars and inputs, suspicious DLL-related client events, and related rage behaviors. The implementation is primarily C++ against the Source 2 SDK, using hooks, detours, movement analysis, and client cvar queries, with Python and shell scripts for AMBuild-based Linux and Windows packaging. Server owners configure punishments, whitelists, and optional Discord or JSON webhook reporting through AntiCheat.cfg and console commands. It is aimed at CS2 server administrators and game-security practitioners who want evidence-driven, in-game anti-cheat enforcement on dedicated hosts.
