AntiCheat est un plugin Metamod:Source côté serveur pour les serveurs dédiés Counter-Strike 2 qui analyse la visée, les tirs, les déplacements, les entrées et les paramètres déclarés par le client pour détecter la triche sans aucune installation côté client. Il inclut dix-huit modules de détection configurables couvrant l’aide à la visée, le trigger et le silent aim, les abus de mouvement comme le bunnyhop et l’autostrafe, la manipulation subtick, les cvars et entrées invalides, les événements client suspects liés aux DLL et comportements rage associés. L’implémentation est surtout en C++ contre le SDK Source 2, avec hooks, detours, analyse de mouvement et requêtes cvar client, plus des scripts Python et shell pour le packaging Linux et Windows basé sur AMBuild. Les administrateurs configurent sanctions, listes blanches et rapports optionnels via webhook Discord ou JSON dans AntiCheat.cfg et les commandes console. Destiné aux admins de serveurs CS2 et aux praticiens de la sécurité jeu qui veulent une application anti-triche in-game fondée sur des preuves sur hôtes dédiés.
