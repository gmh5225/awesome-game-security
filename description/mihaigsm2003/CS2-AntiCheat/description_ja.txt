AntiCheat は Counter-Strike 2 専用サーバー向けの Metamod:Source サーバー側プラグインで、プレイヤーのエイム、射撃、移動、入力、クライアントが報告する設定を分析して、クライアントへのインストールなしにチートを検出します。エイム支援、トリガーおよびサイレントエイム、バニーホップやオートストレイフなどの移動悪用、サブティック操作、不正な cvar と入力、疑わしい DLL 関連のクライアントイベント、その他の rage 系行為をカバーする、設定可能な 18 の検出モジュールを同梱しています。実装は主に Source 2 SDK 向け C++ で、フック、デトア、移動分析、クライアント cvar 照会を用い、Linux と Windows の AMBuild ベースのパッケージングには Python とシェルスクリプトを使います。サーバー管理者は AntiCheat.cfg とコンソールコマンドで処罰、ホワイトリスト、任意の Discord または JSON webhook レポートを設定できます。専用ホスト上で証拠に基づくゲーム内アンチチートを求める CS2 サーバー管理者およびゲームセキュリティ実務者向けです。
