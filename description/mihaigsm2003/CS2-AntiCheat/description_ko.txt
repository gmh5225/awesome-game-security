AntiCheat는 Counter-Strike 2 전용 서버용 Metamod:Source 서버 측 플러그인으로, 플레이어의 에임, 사격, 이동, 입력 및 클라이언트가 보고한 설정을 분석해 클라이언트 설치 없이 치팅을 탐지합니다. 에임 보조, 트리거 및 사일런트 에임, 버니홉·오토스트레이프 같은 이동 악용, 서브틱 조작, 잘못된 cvar와 입력, 의심스러운 DLL 관련 클라이언트 이벤트 및 관련 rage 행위를 다루는 구성 가능한 18개 탐지 모듈이 포함되어 있습니다. 구현은 주로 Source 2 SDK 기반 C++이며, 훅, 디투어, 이동 분석, 클라이언트 cvar 조회를 사용하고, Linux·Windows AMBuild 패키징에는 Python과 셸 스크립트를 씁니다. 서버 운영자는 AntiCheat.cfg와 콘솔 명령으로 처벌, 화이트리스트, 선택적 Discord 또는 JSON webhook 보고를 설정합니다. 전용 호스트에서 근거 기반의 인게임 안티치트를 원하는 CS2 서버 관리자 및 게임 보안 실무자를 대상으로 합니다.
