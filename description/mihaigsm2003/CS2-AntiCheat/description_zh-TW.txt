AntiCheat 是一款面向 Counter-Strike 2 專用伺服器的 Metamod:Source 伺服器端外掛，透過分析玩家瞄準、射擊、移動、輸入以及用戶端回報的設定來偵測作弊，無需在用戶端安裝任何元件。它內建十八個可設定的偵測模組，涵蓋自瞄輔助、扳機與靜默瞄準、連跳與自動轉向等移動濫用、subtick 操縱、非法 cvar 與輸入、可疑的 DLL 相關用戶端事件以及類似的 rage 行為。實作主要基於 Source 2 SDK 的 C++，採用 hook、detour、移動分析與用戶端 cvar 查詢，並以 Python 與 shell 腳本配合 AMBuild 完成 Linux 與 Windows 打包。伺服器管理員可透過 AntiCheat.cfg 與主控台指令設定處罰、白名單以及選用的 Discord 或 JSON webhook 回報。面向希望在專用主機上進行有依據、遊戲內反作弊執行的 CS2 服管與遊戲安全從業者。
