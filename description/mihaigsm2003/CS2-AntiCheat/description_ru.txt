AntiCheat — серверный плагин Metamod:Source для выделенных серверов Counter-Strike 2, который анализирует прицеливание, выстрелы, перемещение, ввод и настройки, сообщаемые клиентом, и выявляет читы без установки чего-либо на клиенте. В комплекте восемнадцать настраиваемых модулей обнаружения: помощь в прицеливании, trigger и silent aim, эксплуатация движения вроде bunnyhop и autostrafe, манипуляции subtick, недопустимые cvar и ввод, подозрительные клиентские события, связанные с DLL, и сопутствующее rage-поведение. Реализация в основном на C++ с Source 2 SDK: хуки, detours, анализ движения и запросы cvar клиента; для сборки под Linux и Windows на AMBuild используются Python и shell-скрипты. Владельцы серверов настраивают наказания, белые списки и опциональную отчётность через Discord или JSON webhook в AntiCheat.cfg и консольных командах. Для администраторов CS2 и специалистов по игровой безопасности, которым нужно доказательное in-game anti-cheat на выделенных хостах.
