AntiCheat 是一款面向 Counter-Strike 2 专用服务器的 Metamod:Source 服务端插件，通过分析玩家瞄准、射击、移动、输入以及客户端上报的设置来检测作弊，无需在客户端安装任何组件。它内置十八个可配置的检测模块，涵盖自瞄辅助、扳机与静默瞄准、连跳与自动转向等移动滥用、subtick 操纵、非法 cvar 与输入、可疑的 DLL 相关客户端事件以及类似的 rage 行为。实现主要基于 Source 2 SDK 的 C++，采用 hook、detour、移动分析与客户端 cvar 查询，并用 Python 与 shell 脚本配合 AMBuild 完成 Linux 与 Windows 打包。服主可通过 AntiCheat.cfg 与控制台命令配置处罚、白名单以及可选的 Discord 或 JSON webhook 上报。面向希望在专用主机上进行有依据的游戏内反作弊执行的 CS2 服管与游戏安全从业者。
