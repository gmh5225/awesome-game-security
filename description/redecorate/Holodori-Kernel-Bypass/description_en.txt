Holodori Kernel Bypass (holo-emu) is a userspace emulator for the usrdrv017964.sys kernel driver interface used by the hololive Dreams game client. Written mainly in C with MinHook-based API hooking, it provides a loader that injects an emulator DLL to fake the device protocol, service state, registry keys, symbolic links, and loaded-driver metadata without ever installing or loading the real kernel driver. The .sys image is used only as read-only PE data for integrity transforms, and the project includes a test client plus launch helpers for native Windows, Wine, and Proton. It is aimed at game security and reverse-engineering work around anti-tamper kernel drivers, letting researchers run or study the protected game without exposing a vulnerable kernel component.
