Holodori Kernel Bypass (holo-emu) è un emulatore in userspace per l’interfaccia del driver kernel usrdrv017964.sys usata dal client del gioco hololive Dreams. Scritto principalmente in C con API hooking basato su MinHook, fornisce un loader che inietta una DLL emulatore per falsificare il protocollo del dispositivo, lo stato dei servizi, le chiavi di registro, i collegamenti simbolici e i metadati dei driver caricati, senza mai installare o caricare il vero driver kernel. L’immagine .sys è usata solo come dati PE in sola lettura per le trasformazioni di integrità; il progetto include anche un client di test e helper di avvio per Windows nativo, Wine e Proton. È pensato per lavoro di sicurezza nei giochi e reverse engineering sui driver kernel anti-tamper, consentendo ai ricercatori di eseguire o studiare il gioco protetto senza esporre un componente kernel vulnerabile.
