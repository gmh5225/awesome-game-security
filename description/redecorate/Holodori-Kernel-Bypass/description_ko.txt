Holodori Kernel Bypass(holo-emu)는 hololive Dreams 게임 클라이언트가 사용하는 usrdrv017964.sys 커널 드라이버 인터페이스용 유저스페이스 에뮬레이터입니다. 주로 C로 작성되었으며 MinHook 기반 API 후킹을 사용합니다. 로더가 에뮬레이터 DLL을 주입해 디바이스 프로토콜, 서비스 상태, 레지스트리 키, 심볼릭 링크, 로드된 드라이버 메타데이터를 위조하므로 실제 커널 드라이버를 설치하거나 로드할 필요가 없습니다. .sys 이미지는 무결성 변환용 읽기 전용 PE 데이터로만 쓰이며, 테스트 클라이언트와 네이티브 Windows, Wine, Proton용 실행 도우미도 포함됩니다. 안티탬퍼 커널 드라이버를 다루는 게임 보안·리버스 엔지니어링을 위한 것으로, 취약한 커널 구성 요소를 노출하지 않고 보호된 게임을 실행하거나 연구할 수 있게 합니다.
