Holodori Kernel Bypass（holo-emu）是一个用户态模拟器，用于模拟 hololive Dreams 游戏客户端所使用的 usrdrv017964.sys 内核驱动接口。项目主要以 C 编写，并基于 MinHook 进行 API 挂钩；它提供加载器，注入模拟器 DLL 以伪造设备协议、服务状态、注册表项、符号链接以及已加载驱动的元数据，而无需安装或加载真正的内核驱动。.sys 映像仅作为只读 PE 数据用于完整性变换，项目还包含测试客户端以及面向原生 Windows、Wine 和 Proton 的启动辅助工具。其目标面向围绕反篡改内核驱动的游戏安全与逆向工程研究，使研究人员能够在不暴露脆弱内核组件的情况下运行或分析受保护的游戏。
