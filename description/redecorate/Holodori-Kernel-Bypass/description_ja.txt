Holodori Kernel Bypass（holo-emu）は、hololive Dreams ゲームクライアントが利用する usrdrv017964.sys カーネルドライバインタフェース向けのユーザー空間エミュレータです。主に C で書かれ、MinHook による API フックを用います。ローダがエミュレータ DLL を注入し、デバイスプロトコル、サービス状態、レジストリキー、シンボリックリンク、読み込み済みドライバのメタデータを偽装するため、本物のカーネルドライバをインストール・読み込みする必要はありません。.sys イメージは整合性変換用の読み取り専用 PE データとしてのみ使われ、テストクライアントやネイティブ Windows、Wine、Proton 向けの起動ヘルパーも含まれます。アンチタンパー系カーネルドライバに関するゲームセキュリティとリバースエンジニアリングを想定し、脆弱なカーネル部品を晒さずに保護されたゲームの実行や解析を可能にします。
