Holodori Kernel Bypass (holo-emu) es un emulador en espacio de usuario de la interfaz del controlador de kernel usrdrv017964.sys que usa el cliente del juego hololive Dreams. Escrito principalmente en C con enganche de API basado en MinHook, proporciona un cargador que inyecta una DLL emuladora para falsificar el protocolo del dispositivo, el estado de servicios, claves del registro, enlaces simbólicos y metadatos de controladores cargados, sin instalar ni cargar nunca el controlador de kernel real. La imagen .sys se usa solo como datos PE de solo lectura para transformaciones de integridad, y el proyecto incluye un cliente de prueba y ayudas de lanzamiento para Windows nativo, Wine y Proton. Está orientado al trabajo de seguridad en juegos e ingeniería inversa en torno a controladores de kernel anti-manipulación, permitiendo a los investigadores ejecutar o estudiar el juego protegido sin exponer un componente de kernel vulnerable.
