Holodori Kernel Bypass (holo-emu) — пользовательский эмулятор интерфейса ядерного драйвера usrdrv017964.sys, используемого клиентом игры hololive Dreams. Написан в основном на C с API-хуками на базе MinHook; включает загрузчик, который внедряет DLL-эмулятор и подделывает протокол устройства, состояние служб, ключи реестра, символические ссылки и метаданные загруженных драйверов, не устанавливая и не загружая настоящий ядерный драйвер. Образ .sys используется только как PE-данные только для чтения для преобразований целостности; в проекте также есть тестовый клиент и вспомогательные средства запуска для нативного Windows, Wine и Proton. Предназначен для исследований в области безопасности игр и реверс-инжиниринга антитамперных ядерных драйверов: позволяет запускать или изучать защищённую игру, не подвергая систему уязвимому ядерному компоненту.
