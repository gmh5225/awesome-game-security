Holodori Kernel Bypass（holo-emu）是一個使用者空間模擬器，用於模擬 hololive Dreams 遊戲用戶端所使用的 usrdrv017964.sys 核心驅動介面。專案主要以 C 撰寫，並基於 MinHook 進行 API 掛鉤；它提供載入器，注入模擬器 DLL 以偽造裝置通訊協定、服務狀態、登錄機碼、符號連結以及已載入驅動的中繼資料，而無須安裝或載入真正的核心驅動。.sys 映像僅作為唯讀 PE 資料用於完整性轉換，專案還包含測試用戶端以及面向原生 Windows、Wine 與 Proton 的啟動輔助工具。其目標面向圍繞防竄改核心驅動的遊戲安全與逆向工程研究，讓研究人員能在不暴露脆弱核心元件的情況下執行或分析受保護的遊戲。
