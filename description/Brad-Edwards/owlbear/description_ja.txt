Owlbear は ARM64 Linux 向けの教育用アンチチートおよびエンドポイント検知プロトタイプで、ロード可能カーネルモジュール、eBPF プログラム、ユーザースペースデーモンを組み合わせ、対象ゲームプロセスを監視・保護します。スタックはカーネル kprobes、eBPF LSM フックによる ptrace や機密メモリマップなど危険な操作の拒否、ポリシーエンジン、シグネチャスキャン、HMAC-SHA256 によるコード整合性チェック、デバッガおよび LD_PRELOAD 検知、プロセスツリー相関を備えたデーモンを用います。小さな ncurses ゲームターゲット、検知を試すサンプルチート、エンドツーエンド検証スクリプト、オプションのクラウドテレメトリ、Graviton ベース開発環境向け Terraform が同梱されています。主な言語はカーネル、eBPF、デーモン、チート用の C と、制御スクリプトおよびプラットフォーム連携用の Python です。本番展開ではなく、カーネルレベルのゲームセキュリティとアンチチート監視の仕組みを学ぶ研究者および開発者向けです。
