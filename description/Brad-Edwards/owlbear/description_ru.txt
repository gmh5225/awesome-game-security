Owlbear — образовательный прототип античита и обнаружения на конечных точках для ARM64 Linux, объединяющий загружаемый модуль ядра, программы eBPF и демон в пользовательском пространстве для мониторинга и защиты целевого игрового процесса. Стек использует kprobes ядра, хуки eBPF LSM, блокирующие опасные операции вроде ptrace и чувствительных отображений памяти, а также демон с движком политик, сканированием сигнатур, проверками целостности кода HMAC-SHA256, обнаружением отладчиков и LD_PRELOAD и корреляцией деревьев процессов. В комплект входят небольшая ncurses-игра-мишень, примеры чит-программ для отработки детекций, скрипты сквозной верификации, опциональная облачная телеметрия и Terraform для сред разработки на Graviton. Основные языки — C для ядра, eBPF, демона и читов и Python для управляющих скриптов и интеграции с платформой. Предназначен для исследователей и разработчиков, изучающих безопасность игр на уровне ядра и мониторинг античита, а не для промышленного развёртывания.
