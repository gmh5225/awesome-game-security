Owlbear is an educational anti-cheat and endpoint-detection prototype for ARM64 Linux that combines a loadable kernel module, eBPF programs, and a userspace daemon to monitor and protect a target game process. The stack uses kernel kprobes, eBPF LSM hooks that deny dangerous operations such as ptrace and sensitive memory maps, and a daemon with a policy engine, signature scanning, HMAC-SHA256 code integrity checks, debugger and LD_PRELOAD detection, and process-tree correlation. It ships with a small ncurses game target, sample cheat programs to exercise detections, end-to-end verification scripts, optional cloud telemetry, and Terraform for Graviton-based dev environments. Primary languages are C for the kernel, eBPF, daemon, and cheats, with Python for control scripts and platform integration. It is aimed at researchers and developers learning how kernel-level game security and anti-cheat monitoring work, not at production deployment.
