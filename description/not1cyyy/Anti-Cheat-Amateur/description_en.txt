This project bundles MemRE, an injectable Windows memory editor, with GothGirlFeet, a kdmapper-compatible kernel driver that exposes cross-process memory read, write, region, and module enumeration through IOCTLs on a hooked NUL device. Written primarily in C++17 for the user-mode GUI and C for the KMDF driver, it adds DBVM hypervisor hypercall shims so scans can bypass user-mode anti-cheat protections that block standard ReadProcessMemory access. MemRE provides Cheat Engine-style first and next scan workflows, pointer scanning, Unreal Engine GWorld and GNames signature resolution, and export to Cheat Engine tables. It is aimed at game security researchers and reverse engineers studying anti-cheat bypass techniques, kernel-assisted memory access, and Unreal Engine game analysis.
