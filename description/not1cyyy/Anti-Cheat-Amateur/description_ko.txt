이 프로젝트는 주입 가능한 Windows 메모리 에디터인 MemRE와 kdmapper 호환 커널 드라이버 GothGirlFeet을 결합한 것입니다. GothGirlFeet은 후킹된 NUL 장치의 IOCTL을 통해 프로세스 간 메모리 읽기·쓰기, 영역 및 모듈 열거 기능을 제공합니다. 사용자 모드 GUI는 주로 C++17로, KMDF 드라이버는 C로 작성되었으며, DBVM 하이퍼바이저 hypercall 셈을 추가하여 표준 ReadProcessMemory 접근을 차단하는 사용자 모드 안티치트 보호를 우회해 스캔할 수 있게 합니다. MemRE는 Cheat Engine 스타일의 first/next 스캔 워크플로, 포인터 스캔, Unreal Engine GWorld 및 GNames 시그니처 해석, Cheat Engine 테이블 내보내기 기능을 제공합니다. 안티치트 우회 기법, 커널 지원 메모리 접근, Unreal Engine 게임 분석을 연구하는 게임 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
