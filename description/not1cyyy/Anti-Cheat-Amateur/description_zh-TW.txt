該專案整合了 MemRE（一款可注入的 Windows 記憶體編輯器）與 GothGirlFeet（相容 kdmapper 的核心驅動程式），後者透過掛鉤 NUL 裝置上的 IOCTL 提供跨程序記憶體讀寫、區域與模組列舉功能。使用者模式 GUI 主要使用 C++17 撰寫，KMDF 驅動程式使用 C 撰寫，並新增了 DBVM 虛擬機器監控程式 hypercall 墊片，使掃描能夠繞過阻止標準 ReadProcessMemory 存取的使用者模式反作弊保護。MemRE 提供 Cheat Engine 風格的首掃與次掃工作流程、指標掃描、Unreal Engine GWorld 與 GNames 簽章解析，以及匯出為 Cheat Engine 表。該專案面向研究反作弊繞過技術、核心輔助記憶體存取與 Unreal Engine 遊戲分析的遊戲安全研究人員與逆向工程師。
