该项目集成了 MemRE（一款可注入的 Windows 内存编辑器）与 GothGirlFeet（兼容 kdmapper 的内核驱动），后者通过挂钩 NUL 设备上的 IOCTL 提供跨进程内存读写、区域与模块枚举功能。用户态 GUI 主要使用 C++17 编写，KMDF 驱动使用 C 编写，并添加了 DBVM 虚拟机管理程序 hypercall 垫片，使扫描能够绕过阻止标准 ReadProcessMemory 访问的用户态反作弊保护。MemRE 提供 Cheat Engine 风格的首扫与次扫工作流、指针扫描、Unreal Engine GWorld 与 GNames 签名解析，以及导出为 Cheat Engine 表。该项目面向研究反作弊绕过技术、内核辅助内存访问与 Unreal Engine 游戏分析的游戏安全研究人员与逆向工程师。
