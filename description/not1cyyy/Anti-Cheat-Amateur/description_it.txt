Questo progetto combina MemRE, un editor di memoria Windows iniettabile, con GothGirlFeet, un driver kernel compatibile con kdmapper che espone lettura, scrittura, enumerazione di regioni e moduli di memoria cross-process tramite IOCTL su un dispositivo NUL agganciato. Scritto principalmente in C++17 per la GUI in user mode e in C per il driver KMDF, aggiunge shim di hypercall dell'hypervisor DBVM affinché le scansioni possano aggirare le protezioni anti-cheat in user mode che bloccano l'accesso standard a ReadProcessMemory. MemRE offre flussi di lavoro di scansione first e next in stile Cheat Engine, pointer scanning, risoluzione delle firme GWorld e GNames di Unreal Engine ed esportazione in tabelle Cheat Engine. È rivolto a ricercatori di sicurezza dei giochi e reverse engineer che studiano tecniche di bypass anti-cheat, accesso alla memoria assistito dal kernel e analisi di giochi Unreal Engine.
