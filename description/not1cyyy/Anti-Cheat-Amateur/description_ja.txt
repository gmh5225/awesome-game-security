このプロジェクトは、インジェクト可能な Windows メモリエディタ MemRE と、kdmapper 互換のカーネルドライバ GothGirlFeet を組み合わせたものです。GothGirlFeet はフックされた NUL デバイス上の IOCTL を通じて、プロセス間メモリの読み書き、リージョン、モジュール列挙を提供します。ユーザーモード GUI は主に C++17、KMDF ドライバは C で書かれており、DBVM ハイパーバイザーの hypercall シムを追加することで、標準の ReadProcessMemory アクセスをブロックするユーザーモードのアンチチート保護をバイパスしてスキャンできるようにしています。MemRE は Cheat Engine 風の first/next スキャンワークフロー、ポインタスキャン、Unreal Engine の GWorld と GNames シグネチャ解決、Cheat Engine テーブルへのエクスポートを提供します。アンチチートバイパス技術、カーネル支援メモリアクセス、Unreal Engine ゲーム解析を研究するゲームセキュリティ研究者とリバースエンジニアを対象としています。
