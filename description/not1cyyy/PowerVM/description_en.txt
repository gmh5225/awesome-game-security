PowerVM is a kernel-mode process protection and transparent debugging framework that installs an AMD SVM-based Type-1 hypervisor beneath the Windows kernel to hide and analyze protected processes from anti-cheat software. It uses Nested Page Tables (NPT) to deploy hardware-level function hooks, stealth memory reads via CPUID hypercalls, and shadow debugging that keeps DebugPort queries invisible to Ring 0 and Ring 3 observers. The codebase includes a kernel driver, a Qt-based controller launcher, and a fork of Cheat Engine for memory scanning and live game debugging. Core components are written in C/C++ and x64 assembly, with the debug engine in Delphi/Pascal and optional CUDA-accelerated pointer scanning. It targets Windows 10/11 on AMD CPUs with SVM support and is aimed at game security researchers, reverse engineers, and developers studying hypervisor-based anti-cheat evasion and stealth debugging techniques.
