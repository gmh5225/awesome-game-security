PowerVM — это фреймворк защиты процессов в режиме ядра и прозрачной отладки, который устанавливает гипервизор Type-1 на базе AMD SVM под ядром Windows для сокрытия и анализа защищённых процессов от античит-программ. Он использует Nested Page Tables (NPT) для развёртывания аппаратных перехватов функций, скрытого чтения памяти через CPUID-гипервызовы и shadow-отладку, которая делает запросы DebugPort невидимыми для наблюдателей Ring 0 и Ring 3. В кодовой базе есть драйвер ядра, контроллер на базе Qt и форк Cheat Engine для сканирования памяти и отладки игр в реальном времени. Основные компоненты написаны на C/C++ и x64-ассемблере, отладочный движок — на Delphi/Pascal, с опциональным ускорением сканирования указателей через CUDA. Ориентирован на Windows 10/11 на процессорах AMD с поддержкой SVM и предназначен для исследователей игровой безопасности, специалистов по реверс-инжинирингу и разработчиков, изучающих обход античита на основе гипервизора и методы скрытой отладки.
