주요 스마트폰 브랜드와 칩셋에서 부트로더 잠금 해제, root, 탈옥(jailbreak) 가능 여부를 추적하는 실시간 참고 가이드이며, 중국 시장 Android 변형과 iOS를 중점적으로 다룹니다. 내용은 Markdown README 스냅샷으로 유지되며 제조사별로 정리되어 잠금 해제 조건, 버전별 fuse 및 롤백 방지 동작, 인증 없는 Qualcomm 9008 EDL 복구, 부트로더를 잠금 해제하지 않은 임시 root, efisp 및 가짜 재잠금 워크플로, 내장 안티치트 및 강화된 ADB 정책 같은 OEM 제한을 포함합니다. 펌웨어 업그레이드나 root, 커널 모듈, 제어 가능한 부트 체인에 의존하는 게임 관련 도구를 시도하기 전에 정확하고 최신의 기기 자유도 상태가 필요한 모더, 리버스 엔지니어, 보안을 의식하는 사용자를 대상으로 합니다.
