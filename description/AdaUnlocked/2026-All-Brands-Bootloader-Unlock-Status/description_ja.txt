主要スマートフォンブランドとチップセットにおけるブートローダーアンロック、root、ジェイルブレイクの可否を追跡するライブリファレンスガイドで、中国市場向け Android 派生モデルと iOS を重点的に扱います。内容は Markdown README のスナップショットとして維持され、ベンダー別に整理され、アンロックの条件、バージョン別の fuse とアンチロールバックの挙動、認証なしの Qualcomm 9008 EDL リカバリ、ブートローダーをアンロックせずに行う一時的 root、efisp と偽の再ロック手順、組み込みアンチチートや厳格化された ADB ポリシーなどの OEM 制限をカバーします。ファームウェア更新前や root、カーネルモジュール、制御可能なブートチェーンに依存するゲーム関連ツールを試す前に、正確で最新のデバイス自由度の状況を知る必要がある modder、リバースエンジニア、セキュリティ意識の高いユーザー向けです。
