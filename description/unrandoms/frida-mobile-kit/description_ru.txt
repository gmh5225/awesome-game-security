Frida Mobile Kit — это практичный набор скриптов Frida для динамического анализа Android-приложений. Он предоставляет готовые к использованию JavaScript-хуки, организованные по категориям: обход certificate pinning (OkHttp, TrustManager, Conscrypt, Flutter, React Native), логирование HTTP- и WebSocket-трафика, извлечение криптографических ключей, обход обнаружения root и SafetyNet, а также инспекция памяти во время выполнения, например трассировка методов и дампы строк. Python CLI-обёртка упрощает просмотр списка скриптов, запуск или подключение к целям, комбинирование нескольких хуков и сохранение вывода в файлы. Набор предназначен для исследователей мобильной безопасности, инженеров по реверс-инжинирингу и аналитиков, которым нужно исследовать защищённые Android-приложения, включая игры с anti-tamper, SSL pinning и проверками целостности.
