Frida Mobile Kit는 Android 애플리케이션의 동적 분석을 위한 실용적인 Frida 스크립트 툴킷입니다. 인증서 피닝 우회(OkHttp, TrustManager, Conscrypt, Flutter, React Native), HTTP 및 WebSocket 트래픽 로깅, 암호화 키 추출, root 및 SafetyNet 탐지 우회, 메서드 추적 및 문자열 덤프와 같은 런타임 메모리 검사 등 카테고리별로 정리된 즉시 사용 가능한 JavaScript 훅을 제공합니다. Python CLI 래퍼를 통해 스크립트 목록 확인, 대상 프로세스 spawn 또는 attach, 여러 훅 결합, 결과를 파일로 저장하는 작업이 간편해집니다. 이 툴킷은 안티 탬퍼, SSL 피닝, 무결성 검사를 갖춘 게임을 포함해 보호된 Android 앱을 조사해야 하는 모바일 보안 연구자, 리버스 엔지니어, 분석가를 대상으로 합니다.
