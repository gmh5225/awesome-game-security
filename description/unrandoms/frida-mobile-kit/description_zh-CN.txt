Frida Mobile Kit 是一套实用的 Frida 脚本工具集，用于对 Android 应用进行动态分析。它提供即用型 JavaScript 钩子，按类别组织，涵盖证书固定绕过（OkHttp、TrustManager、Conscrypt、Flutter、React Native）、HTTP 与 WebSocket 流量记录、加密密钥提取、Root 与 SafetyNet 检测绕过，以及方法追踪、字符串转储等运行时内存检查。Python CLI 封装便于列出脚本、启动或附加目标进程、组合多个钩子，并将输出保存到文件。该工具集面向需要检查受保护 Android 应用（包括具备防篡改、SSL 固定与完整性校验的游戏）的移动安全研究人员、逆向工程师与分析人员。
