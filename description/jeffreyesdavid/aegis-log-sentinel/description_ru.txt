Aegis Log Sentinel — облегчённый конвейер расследования и триажа игровой безопасности для live-service MMO и экшен-игр; он сочетает детерминированное обнаружение читов с отчётами при поддержке ИИ и сохраняет конфиденциальность данных игроков. Написан на Python только со стандартной библиотекой, хранит телеметрию в SQLite, псевдонимизирует ID игроков и IP через HMAC-SHA256 до любой внешней агрегации и помечает злоупотребление скоростью передвижения, каденцию макросов и умных ботов, а также аномальные всплески экономики или валюты. Второй слой Isolation Forest оценивает поведенческие признаки, чтобы поймать дрожащую автоматизацию, которую упускают одни только правила, и направляет срабатывания на ручную проверку без автобана. Находки эскалируются по приоритетным уровням серьёзности с конкретными действиями аналитика: заморозка торгов, захват логов или рекомендации блокировки; в проекте есть синтетические бенчмарки и модульные тесты для проверки ложных срабатываний против легитимной игры высокого уровня. Ориентирован на аналитиков и инженеров игровой безопасности, которым нужен триаж телеметрии без утечек и рабочие процессы брифинга по эксплойтам на живых игровых сервисах.
