Aegis Log Sentinel は、ライブサービス型 MMO およびアクションタイトル向けの軽量なゲームセキュリティ調査・トリアージパイプラインで、決定論的チート検知と AI 支援レポートを組み合わせつつプレイヤーデータのプライバシーを守ります。Python 標準ライブラリのみで実装し、テレメトリは SQLite に保存し、外部要約の前に HMAC-SHA256 でプレイヤー ID と IP を仮名化し、移動速度の不正利用、マクロやスマートボットのテンポ、経済・通貨の異常スパイクをフラグ付けします。第二層の Isolation Forest が行動特徴をスコア化し、ルールだけでは見逃しがちなジッター付き自動化を検出し、自動 BAN ではなく人間によるレビューに回します。所見は優先度付きの重大度にエスカレーションし、取引凍結、ログ取得、停止推奨など具体的なアナリスト向けアクションを提示し、プロジェクトは正当な高スキルプレイに対する誤検知を検証する合成ベンチマークとユニットテストも同梱します。ライブゲームサービス上で漏えいゼロのテレメトリトリアージと悪用ブリーフィングのワークフローを必要とするゲームセキュリティアナリストとエンジニア向けです。
