Aegis Log Sentinel 是一套面向線上服務型 MMO 與動作遊戲的輕量級遊戲安全調查與分診管線，結合確定性作弊偵測與 AI 輔助報告，同時保護玩家資料隱私。專案以純 Python 標準函式庫撰寫，遙測資料存於 SQLite，在向外部彙整前以 HMAC-SHA256 對玩家 ID 與 IP 進行假名化處理，並標記移動速度濫用、巨集與智慧機器人節奏異常，以及經濟或貨幣異常峰值。第二層 Isolation Forest 對行為特徵評分，以偵測僅靠規則難以抓到的抖動型自動化，並將命中結果送交人工複核而非自動封禁。調查結果依優先級升級並附帶具體分析師操作建議，如凍結交易、擷取日誌或建議停權，專案另提供合成基準與單元測試，在合法高技巧玩法下壓力測試誤報。面向需要零外洩遙測分診與漏洞簡報工作流程的遊戲安全分析師與工程師，適用於線上遊戲服務環境。
