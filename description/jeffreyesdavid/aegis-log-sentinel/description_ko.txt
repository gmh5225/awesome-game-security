Aegis Log Sentinel은 라이브 서비스 MMO 및 액션 타이틀용 경량 게임 보안 조사·분류 파이프라인으로, 결정론적 치트 탐지와 AI 보조 보고를 결합하면서 플레이어 데이터를 비공개로 유지합니다. Python 표준 라이브러리만으로 작성되며, SQLite에 원격 측정을 저장하고 외부 요약 전에 HMAC-SHA256으로 플레이어 ID와 IP를 가명화하며, 이동 속도 남용, 매크로·스마트 봇 박자, 비정상적인 경제·화폐 급증을 표시합니다. 두 번째 Isolation Forest 계층이 행동 특징을 점수화해 규칙만으로는 놓치기 쉬운 지터형 자동화를 잡고, 자동 밴 없이 사람 검토로 보냅니다. 발견 사항은 우선순위가 있는 심각도로 상승하며 거래 동결, 로그 수집, 정지 권고 같은 구체적인 분석가 조치를 제시하고, 프로젝트는 합법적인 고숙련 플레이에 대한 오탐을 스트레스 테스트하는 합성 벤치마크와 단위 테스트를 포함합니다. 라이브 게임 서비스에서 유출 없는 원격 측정 분류와 악용 브리핑 워크플로가 필요한 게임 보안 분석가와 엔지니어를 대상으로 합니다.
