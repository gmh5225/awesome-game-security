Aegis Log Sentinel 是一套面向在线服务类 MMO 与动作游戏的轻量级游戏安全调查与分诊流水线，将确定性作弊检测与 AI 辅助报告相结合，同时保护玩家数据隐私。项目使用纯 Python 标准库编写，遥测数据存于 SQLite，在向外部汇总前以 HMAC-SHA256 对玩家 ID 与 IP 进行假名化处理，并标记移动速度滥用、宏与智能机器人节奏异常，以及经济或货币异常峰值。第二层 Isolation Forest 对行为特征打分，以捕获纯规则难以发现的抖动型自动化，并将命中结果送交人工复核而非自动封禁。调查结果按优先级升级并附带具体分析师操作建议，如冻结交易、采集日志或建议停权，项目还提供合成基准与单元测试，以在合法高水平玩法场景下压测误报。面向需要零泄露遥测分诊与漏洞简报工作流的游戏安全分析师与工程师，适用于线上游戏服务环境。
