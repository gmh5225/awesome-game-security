Aegis Log Sentinel is a lightweight game security investigation and triage pipeline for live-service MMO and action titles, combining deterministic cheat detection with AI-assisted reporting while keeping player data private. Written in Python using only the standard library, it stores telemetry in SQLite, pseudonymizes player IDs and IPs with HMAC-SHA256 before any external summarization, and flags movement speed abuse, macro and smart-bot cadence, and abnormal economy or currency spikes. A second Isolation Forest layer scores behavioral features to catch jittered automation that rule-only checks miss, then routes those hits to human review without auto-banning. Findings escalate to prioritized severities with concrete analyst actions such as trade freezes, log capture, or suspension recommendations, and the project ships synthetic benchmarks and unit tests to stress false positives against legitimate high-skill play. It is aimed at game security analysts and engineers who need zero-leak telemetry triage and exploit briefing workflows on live game services.
