This repository is a curated reference collection and companion materials for an introductory talk on PCI Express and direct memory access (DMA) attacks. It is not an application codebase; it organizes slides, videos, and a large annotated bibliography spanning PCIe fundamentals, FPGA device emulation, Thunderbolt and hotplug issues, and real-world attack write-ups. Topics include PCILeech-style DMA hardware, IOMMU and kernel DMA protection bypasses, BitLocker and enterprise countermeasures, and recent research on detecting PCIe DMA-based cheating. It is aimed at security researchers, penetration testers, and professionals in game security, anti-cheat, and hardware-assisted reverse engineering who need a structured entry point into DMA threat models and defenses.
