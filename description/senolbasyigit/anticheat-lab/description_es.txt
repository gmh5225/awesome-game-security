Anticheat-lab es una skill de Claude Code y un kit de herramientas Python para probar la resistencia a manipulaciones de tus propias builds de juego antes del lanzamiento, escaneando la memoria de procesos en busca de valores expuestos como vida, munición o moneda, y documentando hallazgos con recomendaciones de defensa en servidor y pruebas de regresión. Implementa un flujo al estilo Cheat Engine en Windows mediante escaneo, filtrado next-scan y ayudantes de lectura/escritura, respaldado por una guarda SHA-256 en devbuild.json que solo permite trabajar en ejecutables de desarrollador verificados de tu propiedad. Un modo RPA aparte automatiza aplicaciones Windows de terceros vía exportaciones, API o UI Automation con pywinauto sin leer su memoria. Las guías de referencia cubren prioridades de defensa desde autoridad del servidor y validación delta hasta telemetría y señales de integridad, y ofuscación del cliente como medida secundaria. Está orientado a desarrolladores de juegos y equipos conscientes de la seguridad que quieren endurecer lanzamientos frente a la edición de memoria y estructurar la validación anti-trampas antes de publicar.
