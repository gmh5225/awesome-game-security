Anticheat-lab 是一套 Claude Code 技能与 Python 工具包，用于在发布前对自身游戏构建进行篡改测试：扫描进程内存中暴露的生命值、弹药或货币等数值，并记录发现，同时给出服务端防护建议与回归测试。在 Windows 上通过扫描、下次扫描过滤以及读写辅助实现类似 Cheat Engine 的工作流，并由 devbuild.json 的 SHA-256 校验仅允许在你拥有的已验证开发者可执行文件上操作。独立的 RPA 模式通过导出、API 或 UI Automation 配合 pywinauto 自动化第三方 Windows 应用，且不读取其内存。参考指南涵盖从服务端权威与增量校验、遥测与完整性信号到客户端混淆（作为次要手段）的防护优先级。面向希望在发布前强化内存编辑防护并系统化反作弊验证的游戏开发者与安全意识团队。
