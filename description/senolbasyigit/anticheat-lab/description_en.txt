Anticheat-lab is a Claude Code skill and Python toolkit for tamper-testing your own game builds before release by scanning process memory for exposed values such as health, ammo, or currency, then documenting findings with server-side defense recommendations and regression tests. It implements a Cheat Engine-style workflow on Windows through scan, next-scan filtering, and read/write helpers backed by a devbuild.json SHA-256 guard that only permits work on verified developer executables you own. A separate RPA mode automates third-party Windows applications via exports, APIs, or UI Automation with pywinauto without reading their memory. Reference guides cover defense priorities from server authority and delta validation through telemetry and integrity signals, and client obfuscation as a secondary measure. It is aimed at game developers and security-minded teams who want to harden releases against memory editing and to structure anti-cheat validation before shipping.
