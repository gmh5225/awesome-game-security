Anticheat-lab — навык Claude Code и набор инструментов на Python для проверки устойчивости собственных игровых сборок к подмене до релиза: сканирует память процессов на открытые значения вроде здоровья, боеприпасов или валюты и документирует находки с рекомендациями серверной защиты и регрессионными тестами. На Windows реализует рабочий процесс в духе Cheat Engine через сканирование, фильтрацию next-scan и помощники чтения/записи с защитой SHA-256 в devbuild.json, разрешающей работу только с проверенными исполняемыми файлами разработчика, которыми вы владеете. Отдельный режим RPA автоматизирует сторонние приложения Windows через экспорт, API или UI Automation с pywinauto без чтения их памяти. Справочные руководства описывают приоритеты защиты: от серверного авторитета и проверки дельт до телеметрии и сигналов целостности, обфускация клиента — как вторичная мера. Для разработчиков игр и команд, ориентированных на безопасность, которые хотят усилить релизы против редактирования памяти и систематизировать проверку античита перед выпуском.
