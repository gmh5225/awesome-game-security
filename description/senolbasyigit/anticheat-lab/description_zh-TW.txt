Anticheat-lab 是一套 Claude Code 技能與 Python 工具包，用於在發布前對自身遊戲建置進行竄改測試：掃描程序記憶體中暴露的生命值、彈藥或貨幣等數值，並記錄發現，同時提供伺服器端防護建議與迴歸測試。在 Windows 上透過掃描、下次掃描篩選以及讀寫輔助實現類似 Cheat Engine 的工作流程，並由 devbuild.json 的 SHA-256 驗證僅允許在你擁有的已驗證開發者可執行檔上操作。獨立的 RPA 模式透過匯出、API 或 UI Automation 配合 pywinauto 自動化第三方 Windows 應用程式，且不讀取其記憶體。參考指南涵蓋從伺服器權威與增量驗證、遙測與完整性訊號到用戶端混淆（作為次要手段）的防護優先順序。面向希望在發布前強化記憶體編輯防護並系統化反作弊驗證的遊戲開發者與具安全意識的團隊。
