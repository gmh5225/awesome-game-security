Anticheat-lab は Claude Code スキルと Python ツールキットで、リリース前に自社ゲームビルドの改ざん耐性を試すために、プロセスメモリ上の HP・弾薬・通貨など露出した値をスキャンし、サーバー側防御の推奨と回帰テスト付きで所見を記録します。Windows 上でスキャン、ネクストスキャンによる絞り込み、読み書きヘルパーにより Cheat Engine 風のワークフローを実装し、devbuild.json の SHA-256 ガードで所有する検証済み開発者向け実行ファイルのみを対象にします。別の RPA モードは pywinauto でエクスポート、API、UI Automation 経由で第三者 Windows アプリを自動化し、そのメモリは読みません。参考ガイドはサーバー権威とデルタ検証、テレメトリと整合性シグナルからクライアント難読化（二次的対策）までの防御優先度を扱います。メモリ編集への耐性を高め、出荷前にアンチチート検証を体系化したいゲーム開発者とセキュリティ意識の高いチーム向けです。
