Aleph0 is a research Intel VT-x hypervisor implemented in Rust and launched as a UEFI application. It runs in VMX root mode with its own page tables, GDT, IDT, and VM-exit handler, and implements nested virtualization on Hyper-V with emulated exits for CPUID, MSRs, port I/O, HLT, and EPT-backed memory management. The codebase emphasizes low-level unsafe Rust, host unit tests for pure decision logic, serial diagnostics, and extensive documentation tied to Intel SDM behavior. The long-term focus is game anti-cheat research: operating beneath the guest OS to introspect and protect process memory and to support analysis of kernel-mode cheating techniques.
