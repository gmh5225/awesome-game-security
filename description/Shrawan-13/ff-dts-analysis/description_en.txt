This project performs static IL2CPP analysis of the Free Fire MAX Android client to investigate which client-side mechanics could explain a specific aim-related cheat pattern. It is implemented in Python and automates extraction of libil2cpp.so and global-metadata.dat from a supplied XAPK, decrypts obfuscated metadata with a single-byte XOR key, and feeds the result through Il2CppDumper. A companion script scans dumped C# and JSON artifacts for methods, string literals, and class excerpts tied to aim assist, hitboxes, recoil, ballistics, and related combat systems. The repository targets defensive anti-cheat and game security researchers who need a reproducible pipeline from packaged game binaries to focused IL2CPP intelligence rather than manual reverse engineering alone.
