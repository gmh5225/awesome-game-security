本專案對 Free Fire MAX Android 用戶端進行靜態 IL2CPP 分析，以調查哪些用戶端機制可能解釋特定與瞄準相關的外掛行為模式。實作採用 Python，可從提供的 XAPK 自動擷取 libil2cpp.so 與 global-metadata.dat，以單位元組 XOR 金鑰解密混淆的後設資料，並將結果送入 Il2CppDumper 處理。配套腳本會在傾印產出的 C# 與 JSON 成品中搜尋與輔助瞄準、碰撞體、後座力、彈道及相關戰鬥系統相關的方法、字串常值與類別片段。本儲存庫面向需要可重現的、從封裝遊戲二進位到聚焦 IL2CPP 情報管線、而非僅依賴手動逆向的反作弊防禦與遊戲安全研究人員。
