本プロジェクトは Free Fire MAX Android クライアントの静的 IL2CPP 解析を行い、特定のエイム関連チートパターンを説明しうるクライアント側の仕組みを調査する。Python で実装され、提供された XAPK から libil2cpp.so と global-metadata.dat を自動抽出し、1 バイト XOR キーで難読化されたメタデータを復号したうえで Il2CppDumper に渡す。付属スクリプトはダンプされた C# と JSON 成果物から、エイムアシスト、ヒットボックス、リコイル、弾道および関連する戦闘システムに紐づくメソッド、文字列リテラル、クラス抜粋をスキャンする。本リポジトリは、パッケージ化されたゲームバイナリから焦点を絞った IL2CPP インテリジェンスへ至る再現可能なパイプラインを、手作業のリバースエンジニアリングだけに頼らず必要とする、防御的アンチチートおよびゲームセキュリティ研究者を対象とする。
