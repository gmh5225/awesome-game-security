本项目对 Free Fire MAX Android 客户端进行静态 IL2CPP 分析，以研究哪些客户端机制可能解释特定的与瞄准相关的外挂行为模式。实现采用 Python，可从提供的 XAPK 中自动提取 libil2cpp.so 与 global-metadata.dat，使用单字节 XOR 密钥解密混淆的元数据，并将结果送入 Il2CppDumper 处理。配套脚本在转储得到的 C# 与 JSON 产物中检索与辅助瞄准、碰撞体、后坐力、弹道及相关战斗系统相关的方法、字符串字面量与类片段。本仓库面向需要可复现的、从打包游戏二进制到聚焦 IL2CPP 情报流水线、而非仅依赖手工逆向的反作弊防御与游戏安全研究人员。
