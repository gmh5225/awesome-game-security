codebreaker-rs는 CodeBreaker PlayStation 2 액세서리에서 쓰이는 치트 코드를 암·복호화하는 Rust 라이브러리입니다. CodeBreaker v1부터 v6까지의 레거시 방식과 v7 이상의 RC4 기반 암호를 구현하며, 혼합된 코드 목록의 자동 감지와 v7 모드를 끄는 특수 제어 줄 같은 경우도 다룹니다. 이 crate는 no_std이며 리틀 엔디안 플랫폼을 대상으로 하고, PS2 치트 데이터베이스를 분석하거나 작성하는 도구와 homebrew에서 쓸 수 있도록 배포됩니다. 장치 MIPS 펌웨어 암호화를 리버스 엔지니어링하고 이전 C 구현을 이식한 결과물로, 게임 해킹 연구, 포맷 도구, 클래식 콘솔 치트 보호 연구에 유용합니다.
