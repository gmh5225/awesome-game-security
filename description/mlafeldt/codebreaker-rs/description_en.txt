codebreaker-rs is a Rust library that encrypts and decrypts cheat codes used by the CodeBreaker PlayStation 2 accessory. It implements the legacy schemes from CodeBreaker v1 through v6 and the v7+ RC4-based cipher, including automatic detection of mixed code lists and special control lines such as those that disable v7 mode. The crate is no_std, targets little-endian platforms, and is published for use in tools and homebrew that analyze or author PS2 cheat databases. It grew out of reverse-engineering the device’s MIPS firmware crypto and porting earlier C implementations, making it useful for game hacking research, format tooling, and studying classic console cheat protection.
