codebreaker-rs は、CodeBreaker PlayStation 2 周辺機器で使われるチートコードの暗号化・復号を行う Rust ライブラリです。CodeBreaker v1 から v6 までのレガシー方式と、v7 以降の RC4 ベース暗号を実装し、混在するコードリストの自動検出や v7 モードを無効にするような特殊制御行にも対応します。本 crate は no_std で、リトルエンディアン向けに設計され、PS2 チートデータベースの解析や作成を行うツールや homebrew 向けに公開されています。デバイスの MIPS ファームウェア暗号のリバースエンジニアリングと、以前の C 実装の移植から生まれ、ゲーム改造の研究、フォーマット用ツール、クラシックコンソールのチート保護の調査に役立ちます。
