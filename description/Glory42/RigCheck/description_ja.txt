Rigcheck はローカル優先の Linux デスクトップアプリで、検出したハードウェアを各タイトルの最低・推奨要件と照合し、PC が Steam ゲームを実行できるかどうかに答えます。Rust の Cargo ワークスペースとして実装され、iced GUI、SQLite のゲームデータベース、Linux ハードウェア調査、Steam ライブラリ検出、要件解析、許可リスト付き HTTP 取得用の crate を備えます。判定は生のスペックにとどまらず、ProtonDB の互換性ティア、AreWeAntiCheatYet のアンチチート状況、Vulkan とドライバ要件、Steam Deck 認証など Linux 固有の障害要因を織り込み、ハードウェアに関係なく Linux で実行できない場合は BLOCKED を明示します。Steam ストアの検索可能なカタログ、カバーアート付きのインストール済みライブラリ表示、コンポーネント別ボトルネック分析、My Rig での CPU や GPU の「もしも」上書きが利用できます。Linux ゲーマー、互換性研究者、購入やライブラリ管理を計画する際に、アカウントやテレメトリなしでハードウェア適合とアンチチート関連の Linux 制限を事前に把握したい人向けです。
