Rigcheck 是一款本地优先的 Linux 桌面应用，通过将检测到的硬件与各款游戏的最低与推荐配置对比，回答你的 PC 能否运行 Steam 游戏。项目以 Rust 编写为 Cargo 工作区，采用 iced 图形界面、SQLite 游戏数据库，以及用于 Linux 硬件探测、Steam 库发现、需求解析与允许列表 HTTP 请求的 crate。判定结果不仅看裸规格，还纳入 Linux 特有阻碍因素，例如 ProtonDB 兼容等级、AreWeAntiCheatYet 的反作弊状态、Vulkan 与驱动需求、Steam Deck 验证，并在 Linux 无论如何都无法运行该游戏时明确标注 BLOCKED。用户可搜索 Steam 商店目录、在已安装库视图中查看封面、按组件查看瓶颈分析，并在「我的配置」中模拟更换 CPU 或 GPU。适合 Linux 玩家、兼容性研究者，以及需要在购买或管理库之前了解硬件匹配度与反作弊相关 Linux 限制、且无需账号或遥测的用户。
