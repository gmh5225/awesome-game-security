Rigcheck 是一款本地優先的 Linux 桌面應用程式，透過將偵測到的硬體與各款遊戲的最低與建議需求比對，回答你的 PC 能否執行 Steam 遊戲。專案以 Rust 撰寫為 Cargo 工作區，採用 iced 圖形介面、SQLite 遊戲資料庫，以及用於 Linux 硬體探測、Steam 庫探索、需求解析與允許清單 HTTP 請求的 crate。判定結果不只看裸規格，還納入 Linux 特有阻礙因素，例如 ProtonDB 相容等級、AreWeAntiCheatYet 的反作弊狀態、Vulkan 與驅動需求、Steam Deck 驗證，並在 Linux 無論如何都無法執行該遊戲時明確標註 BLOCKED。使用者可搜尋 Steam 商店目錄、在已安裝庫檢視中查看封面、依元件查看瓶頸分析，並在「我的配備」中模擬更換 CPU 或 GPU。適合 Linux 玩家、相容性研究者，以及需要在購買或管理庫之前了解硬體契合度與反作弊相關 Linux 限制、且無需帳號或遙測的使用者。
