Rigcheck is a local-first Linux desktop application that answers whether your PC can run Steam games by comparing detected hardware against each title’s minimum and recommended requirements. It is written in Rust as a Cargo workspace, with an iced GUI, SQLite game databases, and crates for Linux hardware probing, Steam library discovery, requirement parsing, and allowlisted HTTP fetches. Verdicts go beyond raw specs to fold in Linux-specific blockers such as ProtonDB compatibility tiers, anti-cheat status from AreWeAntiCheatYet, Vulkan and driver needs, and Steam Deck verification, including explicit BLOCKED stamps when Linux cannot run the game regardless of hardware. Users get a searchable catalog of the Steam store, an installed-library view with cover art, per-component bottleneck breakdowns, and “what if” CPU or GPU overrides on My Rig. It suits Linux gamers, compatibility researchers, and anyone planning purchases or library management who needs upfront insight into hardware fit and anti-cheat-related Linux restrictions without accounts or telemetry.
