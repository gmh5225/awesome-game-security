本项目是一个可动手实践的检测工程实验环境，演示 Early Bird 异步过程调用注入到已挂起的 Windows 进程，并记录企业遥测与防病毒软件在攻击过程中实际捕获到的内容。它将一个用 C 编写的小型自定义注入器与 Sliver 指挥控制 shellcode 配合，将载荷投递到隔离实验 Windows 主机上系统二进制文件（如 RuntimeBroker.exe）中。文档按标准 Windows API 逐步说明注入序列，将观测到的 Sysmon 事件与预期信号对照，并解释由配置导致的检测盲区。文档还在多次运行中评估具有更新特征与云保护的 Microsoft Defender，并分析原始 shellcode 与入口点之前执行为何会绕过常见防御。该工作面向蓝队、检测工程师与安全研究人员，旨在强化监控规则、Sysmon 配置与分层检测策略，而非仅依赖单一技术或产品。
