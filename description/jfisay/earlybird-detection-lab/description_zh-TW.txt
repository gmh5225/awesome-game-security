本專案為可動手實作的偵測工程實驗環境，示範 Early Bird 非同步程序呼叫注入至已暫停的 Windows 處理序，並記錄企業遙測與防毒軟體在攻擊過程中實際觀察到的內容。它將以 C 撰寫的小型自訂注入器與 Sliver 指揮控制 shellcode 搭配，將載荷送達隔離實驗 Windows 主機上的系統二進位檔（例如 RuntimeBroker.exe）。文件以標準 Windows API 逐步說明注入序列，將觀測到的 Sysmon 事件與預期訊號比對，並說明因設定而產生的偵測盲點。文件亦在多次執行中評估具有更新特徵與雲端防護的 Microsoft Defender，並分析原始 shellcode 與進入點之前執行為何能規避常見防禦。此工作鎖定藍隊、偵測工程師與安全研究者，協助強化監控規則、Sysmon 設定與分層偵測策略，而非僅依賴單一技術或產品。
