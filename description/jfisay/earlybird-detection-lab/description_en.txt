This project is a hands-on detection engineering lab that demonstrates Early Bird asynchronous procedure call injection into a suspended Windows process and records what enterprise telemetry and antivirus actually observe during the attack. It pairs a small custom injector written in C with Sliver command-and-control shellcode delivered into a system binary such as RuntimeBroker.exe on an isolated lab Windows host. The documentation walks through the injection sequence using standard Windows APIs, compares observed Sysmon events against expected signals, and explains configuration-driven blind spots. It also evaluates Microsoft Defender across several runs with updated signatures and cloud protection and analyzes why raw shellcode and pre-entry-point execution can evade common defenses. The work is aimed at blue teams, detection engineers, and security researchers who harden monitoring rules, Sysmon configurations, and layered detection strategies rather than relying on a single technique or product alone.
