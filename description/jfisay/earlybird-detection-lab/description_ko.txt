이 프로젝트는 Early Bird 비동기 프로시저 호출(APC) 주입을 일시 중단된 Windows 프로세스에 시연하고, 공격 중 엔터프라이즈 원격 분석과 안티바이러스가 실제로 무엇을 관측하는지 기록하는 실습형 탐지 엔지니어링 랩입니다. C로 작성된 소형 커스텀 인젝터와 Sliver 명령·제어 셸코드를 결합해 격리된 실험용 Windows 호스트에서 RuntimeBroker.exe와 같은 시스템 바이너리로 페이로드를 전달합니다. 문서는 표준 Windows API를 사용한 주입 순서를 따라가며, 관측된 Sysmon 이벤트를 기대 신호와 비교하고 설정에 따른 사각지대를 설명합니다. 또한 최신 시그니처와 클라우드 보호가 적용된 Microsoft Defender를 여러 차례 실행해 평가하고, 원시 셸코드와 진입점 이전 실행이 일반적인 방어를 어떻게 우회할 수 있는지 분석합니다. 단일 기법이나 제품에만 의지하지 않고 모니터링 규칙, Sysmon 구성, 계층적 탐지 전략을 강화하려는 블루팀, 탐지 엔지니어, 보안 연구자를 대상으로 합니다.
