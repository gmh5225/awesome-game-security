本プロジェクトは、Early Bird による非同期プロシージャコール（APC）注入を一時停止中の Windows プロセスへ行い、攻撃中にエンタープライズ遥測やアンチウイルスが実際に何を観測するかを記録する、実践型の検知エンジニアリングラボです。C で書かれた小さなカスタムインジェクタと Sliver のコマンドアンドコントロール用シェルコードを組み合わせ、隔離されたラボの Windows ホスト上で RuntimeBroker.exe などのシステムバイナリへペイロードを届けます。ドキュメントでは標準の Windows API を用いた注入の手順を追い、観測された Sysmon イベントを期待されるシグナルと比較し、設定起因の死角も説明します。更新されたシグネチャとクラウド保護を伴う Microsoft Defender を複数回の実行で評価し、生のシェルコードやエントリポイント前の実行が一般的な防御をどう迂回し得るかも分析します。監視ルール、Sysmon 構成、多層的な検知戦略を強化するブルーチーム、検知エンジニア、セキュリティ研究者を対象とし、単一の手法や製品に頼るのではなく実装に活かせる内容です。
