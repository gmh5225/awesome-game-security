Anti Cheating Assistant 是一套 AI 智能体技能包，用于在业务描述不完整的情况下，以结构化方式引导风控与反欺诈工作，覆盖建模、分析与整改。它以 Markdown 技能定义与参考剧本为核心，并提供 Python 辅助工具，用于三流图业务建模，以及同步欺诈调查中使用的地下黑话词表。核心能力包括厘清业务逻辑、绘制角色与载体的三流图、将步骤映射到风险目录，以及借助覆盖账号、移动端、交易、营销、内容与金融安全的领域剧本推荐防控措施。所附方法论与节选将反作弊理论提炼为可分层加载、供编程助手按需引用的知识。面向产品负责人、风控工程师，以及需要可重复流程来建模线上业务并设计适度防御的反作弊或业务安全从业者。
