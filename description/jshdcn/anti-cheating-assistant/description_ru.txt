Anti Cheating Assistant — пакет навыков для ИИ-агента, который ведёт структурированную работу по контролю рисков и противодействию мошенничеству: от неполных описаний бизнеса через моделирование и анализ к устранению проблем. Он построен вокруг определений навыков в Markdown и справочных playbook’ов, с вспомогательными скриптами на Python для бизнес-моделирования на графах «трёх потоков» и для синхронизации лексикона подпольного сленга, используемого в расследованиях мошенничества. Ключевые возможности: прояснение бизнес-логики, построение трёхпоточных схем ролей и носителей, сопоставление шагов с каталогом рисков и рекомендации мер контроля через доменные playbook’и по безопасности аккаунтов, мобильных сервисов, транзакций, маркетинга, контента и финансов. Встроенная методология и выдержки сводят теорию anti-cheat к многоуровневым знаниям для выборочной подгрузки в coding-ассистентах. Адресован владельцам продуктов, инженерам по рискам и специалистам по anti-cheat и безопасности бизнеса, которым нужен воспроизводимый процесс моделирования онлайн-бизнеса и проектирования соразмерной защиты.
