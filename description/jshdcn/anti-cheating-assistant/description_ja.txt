Anti Cheating Assistant は、不完全な業務記述から始めて、リスク管理と不正対策の作業をモデル化・分析・是正まで構造化して導く AI エージェント向けスキルパッケージです。Markdown によるスキル定義と参照プレイブックを中心に据え、三流グラフによる業務モデリングや、不正調査で用いる地下スラング辞書の同期のための Python ヘルパーを備えています。主な機能は、業務ロジックの整理、役割とキャリアを示す三流図の作成、手順のリスクカタログへのマッピング、アカウント・モバイル・取引・マーケティング・コンテンツ・金融セキュリティを扱うドメインプレイブックによる統制の推奨です。同梱の方法論と抜粋は、反チート理論をコーディングアシスタント向けに選択的に読み込める階層化された知識に凝縮しています。プロダクトオーナー、リスクエンジニア、オンライン事業のモデリングと妥当な防御設計に反復可能なワークフローを求めるアンチチート／ビジネスセキュリティ実務者を対象としています。
