Anti Cheating Assistant 是一套 AI 代理技能套件，用於在業務描述不完整時，以結構化方式引導風控與反詐欺工作，涵蓋建模、分析與整改。它以 Markdown 技能定義與參考劇本為核心，並提供 Python 輔助工具，用於三流圖業務建模，以及同步詐欺調查中使用的地下黑話詞彙表。核心能力包括釐清業務邏輯、繪製角色與載體的三流圖、將步驟對應到風險目錄，以及透過涵蓋帳號、行動端、交易、行銷、內容與金融安全的領域劇本建議管控措施。所附方法論與摘錄將反作弊理論提煉為可分層載入、供編碼助手按需引用的知識。面向產品負責人、風控工程師，以及需要可重複流程來建模線上業務並設計適當防禦的反作弊或業務安全從業者。
