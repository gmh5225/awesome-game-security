Android Frida Bypass Suite は、対象アプリを改変せずにランタイムフックを注入できる Frida ベースの Android アプリケーションペネトレーションテスト用ツールキットです。メインの Frida スクリプトは Java 層と native libc 層で root 検出をバイパスし、AES 鍵素材と暗号 I/O をフックし、OkHttp、TrustKit、Conscrypt、WebView など関連スタックにわたる SSL 証明書ピンニングを無効化します。付属の Python フォワードプロキシはプロトコルとドメインの許可/ブロックフィルタリングとライブトラフィックログを提供し、Burp Suite および adb reverse トンネリングと連携するワークフローを Android 5 から 14 まで想定しています。HTTPS トラフィックの傍受、暗号シークレットの露出、root 済みまたは計装済みデバイス上での保護された Android アプリ（ゲームを含む）の実行が必要なセキュリティ研究者とリバースエンジニア向けです。
