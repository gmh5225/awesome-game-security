Android Frida Bypass Suite 是一套以 Frida 為基礎的 Android 應用滲透測試工具包，可在不修改目標應用程式的情況下注入執行階段 Hook。主要 Frida 腳本在 Java 層與 native libc 層繞過 root 偵測，Hook AES 金鑰材料與加解密 I/O，並針對 OkHttp、TrustKit、Conscrypt、WebView 等相關堆疊解除 SSL 憑證固定。配套的 Python 正向代理支援依協定與網域進行允許/封鎖過濾，並即時記錄流量，工作流程可與 Burp Suite 及 adb reverse 隧道整合，適用 Android 5 至 14。面向需要攔截 HTTPS、暴露加密機密，並在已 root 或已插樁裝置上執行受保護 Android 應用（含遊戲）的安全研究人員與逆向工程師。
