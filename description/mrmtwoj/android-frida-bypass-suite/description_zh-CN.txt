Android Frida Bypass Suite 是一套基于 Frida 的 Android 应用渗透测试工具包，可在不修改目标应用的前提下注入运行时 Hook。主 Frida 脚本在 Java 层与 native libc 层绕过 root 检测，Hook AES 密钥材料与加解密 I/O，并针对 OkHttp、TrustKit、Conscrypt、WebView 等常见栈解除 SSL 证书固定。配套的 Python 正向代理支持按协议与域名进行允许/拦截过滤，并实时记录流量，工作流可与 Burp Suite 及 adb reverse 隧道配合，适用于 Android 5 至 14。面向需要拦截 HTTPS、暴露加密密钥并在已 root 或已插桩设备上运行受保护 Android 应用（含游戏）的安全研究人员与逆向工程师。
