Android Frida Bypass Suite는 대상 앱을 수정하지 않고 런타임 후크를 주입하는 Frida 기반 Android 애플리케이션 침투 테스트 도구 모음입니다. 메인 Frida 스크립트는 Java 계층과 native libc 계층에서 root 탐지를 우회하고, AES 키 자료와 암호 I/O를 후킹하며 OkHttp, TrustKit, Conscrypt, WebView 등 관련 스택 전반의 SSL 인증서 고정을 무력화합니다. 동반 Python 포워드 프록시는 프로토콜 및 도메인 허용/차단 필터링과 실시간 트래픽 로깅을 제공하며, Burp Suite 및 adb reverse 터널링과 연동하는 워크플로를 Android 5부터 14까지 지원하도록 설계되었습니다. HTTPS 트래픽을 가로채고, 암호화 비밀을 노출하며, root 또는 계측된 기기에서 보호된 Android 앱(게임 포함)을 실행해야 하는 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
