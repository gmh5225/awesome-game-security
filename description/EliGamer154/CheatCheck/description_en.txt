CheatCheck is a Fabric server-side Minecraft mod that provides an anti-cheat moderation toolkit alongside a player-to-player trading system, requiring no client mod for players. Written in Java for Minecraft 26.1.x on Fabric, it lets operators investigate suspects through a /cheatcheck spectate menu, safemode stealth watching, and tools such as freeze, vanish, inventory inspection, and radar. It combines community /report flags with automatic server-side heuristics that detect reach, x-ray-style ore mining, and speed violations, then supports configurable offense presets, temporary bans, and pardons with persistent world storage. The project targets Minecraft server administrators and moderators who need practical, vanilla-client-compatible anti-cheat and enforcement workflows on multiplayer servers.
