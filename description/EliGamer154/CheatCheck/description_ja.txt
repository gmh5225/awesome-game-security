CheatCheck は、Fabric サーバーサイドの Minecraft モッドで、プレイヤーにクライアント mod を必要としないアンチチート管理ツールキットとプレイヤー間取引システムを提供します。Fabric 上の Minecraft 26.1.x 向けに Java で書かれており、オペレーターは /cheatcheck スペクテートメニュー、セーフモードのステルス監視、freeze、vanish、インベントリ検査、radar などのツールで容疑者を調査できます。コミュニティの /report フラグと、reach、x-ray 型の鉱石採掘、速度違反を検出する自動サーバーサイドヒューリスティックを組み合わせ、設定可能な違反プリセット、一時 BAN、世界に永続保存される赦免をサポートします。バニラクライアント互換のアンチチートと執行ワークフローが必要なマルチプレイサーバーの Minecraft サーバー管理者・モデレーター向けのプロジェクトです。
