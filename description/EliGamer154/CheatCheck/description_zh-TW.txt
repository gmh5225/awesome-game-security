CheatCheck 是一款基於 Fabric 的伺服器端 Minecraft 模組，提供反作弊管理工具包以及玩家間交易系統，玩家無需安裝客戶端模組。該模組使用 Java 編寫，適用於 Fabric 上的 Minecraft 26.1.x，管理員可透過 /cheatcheck 旁觀選單、安全模式隱身監視以及凍結、隱身、背包檢查和雷達等工具調查可疑玩家。它將社群 /report 舉報與自動伺服器端啟發式偵測相結合，可偵測 reach、類似 x-ray 的礦石挖掘和速度違規，並支援可設定的違規預設、暫時封禁和赦免，資料持久儲存在世界中。該專案面向需要實用、相容原版客戶端的反作弊與執法流程的多人遊戲伺服器管理員和版主。
