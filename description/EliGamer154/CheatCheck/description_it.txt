CheatCheck è una mod Minecraft lato server per Fabric che fornisce un toolkit di moderazione anti-cheat insieme a un sistema di scambio tra giocatori, senza richiedere mod client per i giocatori. Scritta in Java per Minecraft 26.1.x su Fabric, consente agli operatori di indagare sui sospetti tramite un menu spettatore /cheatcheck, sorveglianza furtiva in safemode e strumenti come freeze, vanish, ispezione inventario e radar. Combina segnalazioni comunitarie /report con euristiche automatiche lato server che rilevano reach, estrazione di minerali in stile x-ray e violazioni di velocità, e supporta preset di infrazioni configurabili, ban temporanei e condono con archiviazione persistente nel mondo. Il progetto è rivolto ad amministratori e moderatori di server Minecraft che necessitano di flussi di lavoro anti-cheat e di enforcement pratici e compatibili con il client vanilla su server multigiocatore.
