CheatCheck 是一款基于 Fabric 的服务端 Minecraft 模组，提供反作弊管理工具包以及玩家间交易系统，玩家无需安装客户端模组。该模组使用 Java 编写，适用于 Fabric 上的 Minecraft 26.1.x，管理员可通过 /cheatcheck 旁观菜单、安全模式隐身监视以及冻结、隐身、背包检查和雷达等工具调查可疑玩家。它将社区 /report 举报与自动服务端启发式检测相结合，可检测 reach、类似 x-ray 的矿石挖掘和速度违规，并支持可配置的违规预设、临时封禁和赦免，数据持久存储在世界中。该项目面向需要实用、兼容原版客户端的反作弊与执法流程的多人游戏服务器管理员和版主。
