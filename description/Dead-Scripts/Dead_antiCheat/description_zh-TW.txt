Dead-Anticheat 是一款 FiveM 伺服器資源，用於偵測並封鎖 GTA V 多人角色扮演伺服器上常見的 mod menu 與作弊行為。它以 Lua 撰寫的用戶端-伺服器 CitizenFX 腳本運作，監控玩家的 noclip、旁觀模式、虛假聊天訊息、黑名單道具與 NPC、godmode、無限彈藥、未授權武器，以及注入的 Lua 指令或 mod menu 全域變數。伺服器端邏輯透過 JSON 封鎖清單執行封鎖，將偵測結果記錄到 Discord webhook（可選截圖），並支援對事件、按鍵、指令和實體模型的可設定黑名單。它包含管理員豁免權限，並借鑑社群反作弊技術進行實體列舉和用戶端完整性檢查。該專案面向需要輕量、可設定防護以對抗 modder 和漏洞濫用的 FiveM 伺服器營運者。
