Dead-Anticheat は、GTA V マルチプレイヤーロールプレイサーバーで一般的な mod menu やチート行為を検出・ブロックする FiveM サーバーリソースです。Lua で書かれたクライアント・サーバー型 CitizenFX スクリプトとして動作し、noclip、スペクテート、偽のチャットメッセージ、ブラックリスト登録済みの prop や ped、godmode、無限弾薬、未承認の武器、注入された Lua コマンドや mod menu グローバル変数などを監視します。サーバー側ロジックは JSON 禁止リストによる BAN 処理、Discord webhook への検出ログ（スクリーンショット付きオプション）、イベント・キー・コマンド・エンティティモデルの設定可能なブラックリストをサポートします。スタッフ向けバイパス権限を備え、エンティティ列挙やクライアント整合性チェックなどコミュニティ由来の anticheat 手法も取り入れています。modder や exploit 悪用から軽量かつ設定可能な保護を必要とする FiveM サーバー運営者向けのプロジェクトです。
