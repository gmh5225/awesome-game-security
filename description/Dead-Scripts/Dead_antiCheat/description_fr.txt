Dead-Anticheat est une ressource serveur FiveM qui détecte et bloque les comportements courants de mod menu et de triche sur les serveurs de jeu de rôle multijoueur GTA V. Écrit en Lua sous forme de script CitizenFX client-serveur, il surveille les joueurs pour le noclip, le mode spectateur, les faux messages de chat, les props et peds blacklistés, le godmode, les munitions infinies, les armes non autorisées, ainsi que les commandes Lua injectées ou les variables globales de mod menu. La logique côté serveur applique les bannissements via une liste JSON, enregistre les détections sur des webhooks Discord avec captures d'écran optionnelles, et prend en charge des listes noires configurables pour les événements, touches, commandes et modèles d'entités. Il inclut des permissions de contournement pour le staff et s'appuie sur des techniques anticheat communautaires pour l'énumération d'entités et les vérifications d'intégrité client. Le projet s'adresse aux opérateurs de serveurs FiveM qui ont besoin d'une protection légère et configurable contre les moddeurs et les abus d'exploits.
