Dead-Anticheat 是一款 FiveM 服务器资源，用于检测并阻止 GTA V 多人角色扮演服务器上常见的 mod menu 与作弊行为。它以 Lua 编写的客户端-服务器 CitizenFX 脚本运行，监控玩家的 noclip、旁观模式、虚假聊天消息、黑名单道具与 NPC、godmode、无限弹药、未授权武器，以及注入的 Lua 命令或 mod menu 全局变量。服务器端逻辑通过 JSON 封禁列表执行封禁，将检测结果记录到 Discord webhook（可选截图），并支持对事件、按键、命令和实体模型的可配置黑名单。它包含员工豁免权限，并借鉴社区反作弊技术进行实体枚举和客户端完整性检查。该项目面向需要轻量、可配置防护以对抗 modder 和漏洞滥用的 FiveM 服务器运营者。
