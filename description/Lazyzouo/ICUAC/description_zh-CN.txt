ICUAC 是一款面向 Paper 与 Folia Minecraft 服务器的可配置服务端规则执行插件，对命令、玩家状态、位置、背包与战斗等场景施加模块化检查。该插件使用 Java 21 编写并以 Gradle 构建，可执行屏蔽命令与隐藏 Tab 补全、游戏模式隔离、危险坐标限制、死亡掉落控制、禁用材料、物品 NBT 与附魔校验、堆叠与药水效果上限，以及末影水晶攻击冷却等策略。插件自带中英文双语默认语言包，采用 Folia 感知调度，并内置更新器，在验证 GitHub SHA-256 摘要后下载与语言匹配的发布资源。它面向需要轻量、透明的服务端反滥用与完整性管控，而非完整客户端反作弊引擎的服务器管理员。
