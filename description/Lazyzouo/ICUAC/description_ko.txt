ICUAC는 Paper 및 Folia Minecraft 서버용으로 구성 가능한 서버 측 규칙 집행 플러그인으로, 명령어, 플레이어 상태, 위치, 인벤토리, 전투에 모듈식 검사를 적용합니다. Java 21로 작성되었으며 Gradle로 빌드되며, 차단된 명령어와 Tab 자동 완성 숨김, 게임 모드 격리, 위험 좌표 제한, 사망 시 드롭 제어, 금지 재료, 아이템 NBT 및 인챈트 검증, 스택 및 물약 효과 제한, 엔드 크리스탈 공격 쿨다운 등의 정책을 집행합니다. 플러그인에는 중국어와 영어 기본 언어 팩이 포함되어 있으며, Folia 인식 스케줄링을 사용하고 GitHub SHA-256 다이제스트를 검증한 뒤 언어에 맞는 릴리스 자산을 다운로드하는 업데이터가 내장되어 있습니다. 완전한 클라이언트 측 안티치트 엔진이 아닌, 경량이고 투명한 서버 측 남용 방지 및 무결성 제어가 필요한 서버 관리자를 대상으로 합니다.
