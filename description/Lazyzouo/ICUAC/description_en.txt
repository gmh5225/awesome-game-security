ICUAC is a configurable server-side rule-enforcement plugin for Paper and Folia Minecraft servers that applies modular checks to commands, player state, locations, inventories, and combat. Written in Java 21 and built with Gradle, it enforces policies such as blocked commands and tab completion hiding, game-mode isolation, dangerous coordinate limits, death-drop control, banned materials, item NBT and enchantment validation, stack and potion effect limits, and end-crystal attack cooldowns. The plugin ships bilingual Chinese and English default packages, uses Folia-aware scheduling, and includes an updater that downloads language-matched release assets after verifying GitHub SHA-256 digests. It is aimed at server administrators who need lightweight, transparent server-side anti-abuse and integrity controls rather than a full client-side anti-cheat engine.
