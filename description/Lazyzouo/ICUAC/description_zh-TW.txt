ICUAC 是一款面向 Paper 與 Folia Minecraft 伺服器的可設定伺服器端規則執行外掛，對指令、玩家狀態、位置、背包與戰鬥等場景施加模組化檢查。此外掛使用 Java 21 編寫並以 Gradle 建置，可執行封鎖指令與隱藏 Tab 補全、遊戲模式隔離、危險座標限制、死亡掉落控制、禁用材料、物品 NBT 與附魔驗證、堆疊與藥水效果上限，以及終界水晶攻擊冷卻等策略。外掛內建中英文雙語預設語言包，採用 Folia 感知排程，並包含更新器，在驗證 GitHub SHA-256 摘要後下載與語言相符的發佈資源。它面向需要輕量、透明的伺服器端反濫用與完整性管控，而非完整用戶端反作弊引擎的伺服器管理員。
