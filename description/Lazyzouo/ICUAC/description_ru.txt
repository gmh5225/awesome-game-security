ICUAC — настраиваемый серверный плагин для применения правил на серверах Minecraft Paper и Folia, который выполняет модульные проверки команд, состояния игроков, местоположений, инвентарей и боя. Написан на Java 21 и собран с помощью Gradle; обеспечивает такие политики, как блокировка команд и скрытие автодополнения по Tab, изоляция игровых режимов, ограничения опасных координат, контроль выпадения предметов при смерти, запрещённые материалы, проверка NBT и зачарований предметов, ограничения стаков и эффектов зелий, а также перезарядку атак кристаллами Края. Плагин поставляется с двуязычными пакетами по умолчанию на китайском и английском, использует планирование с учётом Folia и включает модуль обновления, который после проверки SHA-256-дайджестов GitHub загружает ресурсы релиза, соответствующие языку. Он предназначен для администраторов серверов, которым нужен лёгкий и прозрачный серверный контроль злоупотреблений и целостности, а не полноценный клиентский античит.
