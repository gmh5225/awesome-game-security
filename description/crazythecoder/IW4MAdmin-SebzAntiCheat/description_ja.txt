これは IW4X 向けのサーバー側アンチチート審査システムで、疑わしい行動のテレメトリを収集し、IW4MAdmin ダッシュボードを通じてケースを提示しますが、プレイヤーを自動的に BAN することはありません。ゲームサーバー上の GSC スクリプトでエイム異常、視認性の問題、レーダー文脈、繰り返される疑わしいパターンを検出し、JavaScript プラグインと Node.js の Discord ウォッチャーが証拠を集約し、リスクと信頼度を別々にスコア化して Discord 経由でスタッフに通知します。snap、strain、recoil、bone、button、offset などの IW4MAdmin ネイティブ検出と統合され、watch、clear、purge、recover のモデレーションワークフローをサポートし、オプションの Python フラグワーカーも利用できます。追加の Python ツールは、検証付きの署名付きリリース更新、バックアップ、ロールバック、および混雑したサーバー向けのパフォーマンスを考慮したサンプリングを提供します。無人の自動執行ではなく、構造化されたチート調査とスタッフによる審査を必要とする IW4X サーバー管理者を対象としています。
