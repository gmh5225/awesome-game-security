這是一個面向 IW4X 的伺服器端反作弊審查系統，用於收集可疑行為遙測資料，並透過 IW4MAdmin 儀表板呈現案件，而不會自動封禁玩家。它使用遊戲伺服器上的 GSC 腳本來偵測瞄準異常、可見性問題、雷達上下文以及反覆出現的可疑模式，同時 JavaScript 外掛與 Node.js Discord 監視器彙整證據、分別評估風險與置信度，並透過 Discord 通知管理員。此系統整合 IW4MAdmin 原生偵測項目，例如 snap、strain、recoil、bone、button 和 offset 證據，並支援 watch、clear、purge 和 recover 等管理流程，可選 Python 標記工作程序。額外的 Python 工具提供含驗證的簽署版本更新、備份與回復，以及面向繁忙伺服器的效能感知取樣。它面向需要結構化作弊調查與人工審查，而非無人值守自動處罰的 IW4X 伺服器管理員。
