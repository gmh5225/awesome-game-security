这是一个面向 IW4X 的服务端反作弊审查系统，用于收集可疑行为遥测数据，并通过 IW4MAdmin 仪表盘呈现案件，而不会自动封禁玩家。它使用游戏服务器上的 GSC 脚本来检测瞄准异常、可见性问题、雷达上下文以及反复出现的可疑模式，同时 JavaScript 插件和 Node.js Discord 监视器汇总证据、分别评估风险与置信度，并通过 Discord 通知管理员。该系统集成 IW4MAdmin 原生检测项，例如 snap、strain、recoil、bone、button 和 offset 证据，并支持 watch、clear、purge 和 recover 等管理流程，可选 Python 标记工作进程。额外的 Python 工具提供带验证的签名版本更新、备份与回滚，以及面向繁忙服务器的性能感知采样。它面向需要结构化作弊调查与人工审查，而非无人值守自动处罚的 IW4X 服务器管理员。
