Este es un sistema de revisión anti-trampas del lado del servidor para IW4X que recopila telemetría de sospecha y presenta casos a través de un panel de IW4MAdmin sin banear automáticamente a los jugadores. Utiliza scripts GSC en el servidor de juego para detectar anomalías de puntería, problemas de visibilidad, contexto de radar y patrones sospechosos repetidos, mientras que plugins de JavaScript y un observador de Discord en Node.js agregan evidencia, puntúan el riesgo y la confianza por separado, y notifican al personal mediante Discord. El sistema integra detecciones nativas de IW4MAdmin como snap, strain, recoil, bone, button y offset, y admite flujos de moderación watch, clear, purge y recover con un worker Python de marcado opcional. Herramientas Python adicionales proporcionan actualizaciones firmadas con validación, copias de seguridad y reversión, además de muestreo consciente del rendimiento para servidores ocupados. Está dirigido a administradores de servidores IW4X que necesitan investigación estructurada de trampas y revisión del personal en lugar de aplicación automática sin supervisión.
