This is a server-side anti-cheat review system for IW4X that collects suspicion telemetry and presents cases through an IW4MAdmin dashboard without automatically banning players. It uses GSC scripts on the game server to detect aim anomalies, visibility issues, radar context, and repeated suspicious patterns, while JavaScript plugins and a Node.js Discord watcher aggregate evidence, score risk and confidence separately, and notify staff via Discord. The system integrates native IW4MAdmin detections such as snap, strain, recoil, bone, button, and offset evidence, and supports watch, clear, purge, and recover moderation workflows with an optional Python flag worker. Additional Python tooling provides signed release updates with validation, backups, and rollback, plus performance-aware sampling for busy servers. It is aimed at IW4X server administrators who need structured cheat investigation and staff review rather than unattended enforcement.
