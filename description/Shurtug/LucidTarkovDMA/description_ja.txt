Lucid Tarkov DMA は Escape from Tarkov 向けの外部ハードウェア支援ツールで、別マシン上で動作し、PCIe DMA リンク経由でのみゲーム PC にアクセスするため、ゲームシステムへコードを注入しません。IL2CPP のゲームメモリを読み取り、プレイヤー ESP、市場価格付きのルートや死体オーバーレイ、LAN 上の Web レーダーとダッシュボード、およびリコイル・視野・スタミナ・操作まわりの任意メモリ書き込みに対応し、オプションの MAKCU USB デバイスは通常の HID マウストラフィックとしてエイム入力を駆動できます。スタックは商用 DMA カード、パッチ後の OTA 更新付きセカンドホスト起動器、BattlEye 保護ビルド向けの自社オフセットを中心に構成されています。ハードウェア DMA チート、バスレベルのメモリアクセス、従来のプロセス内アンチチートを外部ツールがいかに回避するかを研究する研究者・防御側、および Tarkov セキュリティの攻撃面を整理する利用者を対象としています。
