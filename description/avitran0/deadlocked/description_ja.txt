Deadlocked は Linux 向けの外部 Counter-Strike 2 アシスタントで、実行中のクライアントプロセスからライブのゲーム状態を読み取り、画面上のオーバーレイを駆動します。コアは Rust ワークスペースで、CS2 の共有ライブラリをマップし、スキーマベースのオフセットを解決し、エイムボット、リコイル制御、トリガーボット、ESP 風のプレイヤー・ワールド描画、フラッシュとスモークの調整、グレネードラインナップ支援などの戦闘・視覚補助を実装しています。ゲーム物理の BVH からマップジオメトリを構築して可視性チェックとヒットボックスのレイテストを行い、設定可能な egui と OpenGL の HUD を提供し、小さな Rust の TCP/WebSocket サーバーと TypeScript フロントエンドで支えるコンパニオン Web レーダーへマッチデータをストリーミングできます。本プロジェクトは、最小限の概念実証ではなく、外部 Linux チートのアーキテクチャ、メモリレイアウト、機能設計の詳細な参照を求めるゲームセキュリティ研究者とリバースエンジニアを対象としています。
