Deadlocked is an external Counter-Strike 2 assistant for Linux that reads live game state from the running client process and drives an on-screen overlay. The core is a Rust workspace that maps CS2 shared libraries, resolves schema-based offsets, and implements combat and visual aids such as aimbot, recoil control, triggerbot, ESP-style player and world rendering, flash and smoke tweaks, and grenade lineup helpers. It builds map geometry from the game physics BVH for visibility checks and hitbox ray tests, exposes a configurable egui and OpenGL HUD, and can stream match data to a companion web radar backed by a small Rust TCP/WebSocket server and a TypeScript front end. The project is aimed at game security researchers and reverse engineers who want a detailed reference for external Linux cheat architecture, memory layout, and feature design rather than a minimal proof of concept.
