Deadlocked 是一款面向 Linux 的外部 Counter-Strike 2 輔助工具，從執行中的用戶端行程讀取即時遊戲狀態並驅動螢幕疊加層。核心為 Rust 工作區，對應 CS2 共享函式庫、解析以 schema 為基礎的偏移，並實作戰鬥與視覺輔助功能，包括自瞄、壓槍、扳機、ESP 風格的玩家與世界渲染、閃光與煙霧調整以及手雷點位輔助。它從遊戲物理 BVH 建構地圖幾何以進行可見性檢測與 hitbox 射線測試，提供可設定的 egui 與 OpenGL HUD，並可將對局資料串流至配套 Web 雷達（由小型 Rust TCP/WebSocket 伺服器與 TypeScript 前端支撐）。本專案面向遊戲安全研究人員與逆向工程師，作為外部 Linux 作弊架構、記憶體配置與功能設計的詳細參考，而非最小化概念驗證。
