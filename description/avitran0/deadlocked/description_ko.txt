Deadlocked는 Linux용 외부 Counter-Strike 2 보조 도구로, 실행 중인 클라이언트 프로세스에서 실시간 게임 상태를 읽고 화면 오버레이를 구동합니다. 핵심은 Rust 워크스페이스로, CS2 공유 라이브러리를 매핑하고 스키마 기반 오프셋을 해석하며, 에임봇, 반동 제어, 트리거봇, ESP 스타일의 플레이어·월드 렌더링, 섬광·연무 조정, 수류탄 라인업 도우미 등 전투·시각 보조 기능을 구현합니다. 게임 물리 BVH에서 맵 지오메트리를 구축해 가시성 검사와 히트박스 광선 테스트를 수행하고, 설정 가능한 egui·OpenGL HUD를 제공하며, 소형 Rust TCP/WebSocket 서버와 TypeScript 프런트엔드로 뒷받침되는 동반 Web 레이더로 매치 데이터를 스트리밍할 수 있습니다. 본 프로젝트는 최소 개념 증명이 아니라, 외부 Linux 치트 아키텍처, 메모리 레이아웃, 기능 설계에 대한 상세한 참고 자료를 원하는 게임 보안 연구자와 리버스 엔지니어를 대상으로 합니다.
