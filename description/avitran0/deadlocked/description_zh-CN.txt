Deadlocked 是一款面向 Linux 的外部 Counter-Strike 2 辅助工具，从运行中的客户端进程读取实时游戏状态并驱动屏幕叠加层。核心为 Rust 工作区，映射 CS2 共享库、解析基于 schema 的偏移，并实现战斗与视觉辅助功能，包括自瞄、压枪、扳机、ESP 风格的玩家与世界渲染、闪光与烟雾调整以及手雷点位辅助。它从游戏物理 BVH 构建地图几何体以进行可见性检测与 hitbox 射线测试，提供可配置的 egui 与 OpenGL HUD，并可将对局数据流式传输至配套 Web 雷达（由小型 Rust TCP/WebSocket 服务器与 TypeScript 前端支撑）。本项目面向游戏安全研究人员与逆向工程师，作为外部 Linux 作弊架构、内存布局与功能设计的详细参考，而非最小化概念验证。
