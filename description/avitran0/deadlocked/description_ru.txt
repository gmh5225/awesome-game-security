Deadlocked — внешний ассистент для Counter-Strike 2 под Linux, который читает актуальное состояние игры из запущенного клиентского процесса и управляет экранным оверлеем. Ядро — Rust workspace: отображает shared-библиотеки CS2, разрешает смещения на основе схемы и реализует боевые и визуальные помощники — aimbot, контроль отдачи, triggerbot, отрисовку игроков и мира в стиле ESP, настройки вспышки и дыма, подсказки по раскладкам гранат. Геометрия карт строится из игрового физического BVH для проверок видимости и лучевых тестов по hitbox, доступен настраиваемый HUD на egui и OpenGL; данные матча можно стримить в companion web radar на небольшом Rust TCP/WebSocket-сервере с TypeScript front-end. Проект рассчитан на исследователей игровой безопасности и reverse engineers, которым нужна подробная справка по архитектуре внешних читов на Linux, раскладке памяти и проектированию функций, а не минимальное proof of concept.
