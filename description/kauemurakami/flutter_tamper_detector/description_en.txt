flutter_tamper_detector is a Flutter plugin that detects device tampering and risky runtime conditions so mobile apps can block or shut down before sensitive logic runs. It exposes checks for rooted or jailbroken devices, hooking frameworks such as Frida, Xposed, and Cydia Substrate, emulators and simulators, debug builds, and whether the app was installed from an official store. The implementation combines Dart with native Android (Kotlin) and iOS (Swift) code, and supports automatic process exit, optional self-uninstall on compromised rooted devices, window hardening against screenshots and recents preview, and early native checks before the Flutter engine starts. It targets Flutter developers who need client-side anti-tampering and integrity controls for games, fintech, and other security-sensitive mobile applications.
