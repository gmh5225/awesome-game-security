Bloon AntiCheat è un plugin server per Paper e Bukkit che aggiunge rilevamento leggero dei cheat e strumenti per lo staff sui server Minecraft Java Edition. Scritto in Java 17 e compilato con Maven rispetto all’API Paper, ascolta gli eventi dei giocatori per segnalare l’abuso di autoclicker tramite limiti di clic al secondo, colpi illegali di reach e in stile killaura bloccando attacchi oltre una distanza configurabile, schemi sospetti di triggerbot con un buffer di combattimento cumulativo e violazioni di volo. Quando i controlli falliscono, trasmette alert formattati alla console e allo staff online con il permesso alerts, mentre operatori privilegiati possono ricaricare le impostazioni, ispezionare statistiche per giocatore e aprire una GUI in-game in sola lettura che mostra voci di sanzione definite in YAML. È pensato per proprietari di server e moderatori che necessitano di uno strato anti-cheat semplice e configurabile piuttosto che di una soluzione commerciale completa lato client.
