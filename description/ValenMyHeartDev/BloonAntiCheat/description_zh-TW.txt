Bloon AntiCheat 是一款面向 Paper 與 Bukkit 伺服器的外掛，為 Minecraft Java 版伺服器提供輕量級作弊偵測與管理員工具。以 Java 17 撰寫，使用 Maven 建置並依賴 Paper API，透過監聽玩家事件偵測多種作弊：以每秒點擊數限制識別連點器濫用，以可設定的攻擊距離攔截非法 reach 與 killaura 類命中，以累積戰鬥緩衝識別可疑 triggerbot 模式，並偵測飛行違規。檢查失敗時，會向主控台及擁有 alerts 權限的線上管理員廣播格式化警示；具特權的營運者可重新載入設定、檢視玩家統計，並開啟唯讀遊戲內 GUI 顯示 YAML 中定義的處分紀錄。它面向需要簡單、可設定反作弊層而非完整商業用戶端方案的伺服器服主與版主。
