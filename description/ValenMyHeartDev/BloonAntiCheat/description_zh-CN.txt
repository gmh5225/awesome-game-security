Bloon AntiCheat 是一款面向 Paper 与 Bukkit 服务端插件，为 Minecraft Java 版服务器提供轻量级作弊检测与管理员工具。项目使用 Java 17 编写，基于 Maven 构建并依赖 Paper API，通过监听玩家事件检测多种作弊：以每秒点击数限制识别连点器滥用，以可配置攻击距离拦截非法 reach 与 killaura 类命中，用累积战斗缓冲识别可疑 triggerbot 模式，并检测飞行违规。检测失败时，会向控制台及拥有 alerts 权限的在线管理员广播格式化告警；具备特权的操作者可重载配置、查看玩家统计，并打开只读游戏内 GUI 展示 YAML 中定义的处罚记录。它面向需要简单、可配置反作弊层而非完整商业客户端方案的服务器服主与版主。
