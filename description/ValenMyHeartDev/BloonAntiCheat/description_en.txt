Bloon AntiCheat is a Paper and Bukkit server plugin that adds lightweight cheat detection and staff tooling for Minecraft Java Edition servers. Written in Java 17 and built with Maven against the Paper API, it listens to player events to flag autoclicker abuse via clicks-per-second limits, illegal reach and killaura-style hits by blocking attacks beyond a configurable distance, suspicious triggerbot patterns using an accumulating combat buffer, and fly violations. When checks fail, it broadcasts formatted alerts to the console and to online staff who hold the alerts permission, while privileged operators can reload settings, inspect per-player stats, and open a read-only in-game GUI that displays sanction entries defined in YAML. It targets server owners and moderators who need a simple, configurable anti-cheat layer rather than a full commercial client-side solution.
