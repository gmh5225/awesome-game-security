Bloon AntiCheat は Paper および Bukkit 向けサーバープラグインで、Minecraft Java Edition サーバー向けに軽量なチート検知とスタッフ向けツールを提供します。Java 17 で記述され、Maven で Paper API に対してビルドされ、プレイヤーイベントを監視してオートクリッカー乱用を CPS 制限で、設定可能な距離を超える攻撃による不正 reach や killaura 系のヒットをブロックし、累積コンバットバッファで疑わしい triggerbot パターンを、さらに fly 違反を検出します。チェック失敗時はコンソールと alerts 権限を持つオンラインスタッフへ整形されたアラートをブロードキャストし、特権オペレーターは設定のリロード、プレイヤー別統計の確認、YAML で定義された制裁エントリを表示する読み取り専用のゲーム内 GUI を開けます。フル機能の商用クライアント側ソリューションではなく、シンプルで設定可能なアンチチート層を必要とするサーバー所有者とモデレーター向けです。
