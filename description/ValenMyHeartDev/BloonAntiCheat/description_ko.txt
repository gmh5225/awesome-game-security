Bloon AntiCheat는 Paper 및 Bukkit 서버용 플러그인으로, Minecraft Java Edition 서버에 가벼운 치트 탐지와 스태프 도구를 추가합니다. Java 17로 작성되었으며 Maven으로 Paper API에 대해 빌드되며, 플레이어 이벤트를 수신해 초당 클릭 수 제한으로 오토클리커 남용을, 설정 가능한 거리를 넘는 공격으로 불법 reach 및 killaura 스타일 타격을 차단하고, 누적 전투 버퍼로 의심스러운 triggerbot 패턴을, fly 위반을 탐지합니다. 검사 실패 시 콘솔과 alerts 권한을 가진 온라인 스태프에게 형식화된 알림을 브로드캐스트하며, 권한 있는 운영자는 설정을 다시 불러오고, 플레이어별 통계를 조회하며, YAML에 정의된 제재 항목을 표시하는 읽기 전용 게임 내 GUI를 열 수 있습니다. 완전한 상용 클라이언트 측 솔루션이 아니라 단순하고 설정 가능한 안티치트 계층이 필요한 서버 소유자와 운영진을 대상으로 합니다.
