Bloon AntiCheat — плагин для серверов Paper и Bukkit, добавляющий лёгкое обнаружение читов и инструменты для персонала на серверах Minecraft Java Edition. Написан на Java 17 и собирается Maven против API Paper; слушает события игроков, чтобы отмечать злоупотребление автокликером через лимиты кликов в секунду, блокировать незаконные reach и удары в стиле killaura, запрещая атаки за пределами настраиваемой дистанции, выявлять подозрительные паттерны triggerbot с накопительным боевым буфером и нарушения полёта. При срабатывании проверок рассылает форматированные оповещения в консоль и онлайн-персоналу с правом alerts, а привилегированные операторы могут перезагружать настройки, просматривать статистику по игрокам и открывать игровой GUI только для чтения с записями санкций из YAML. Ориентирован на владельцев серверов и модераторов, которым нужен простой настраиваемый античит-слой, а не полноценное коммерческое клиентское решение.
