OpenCMR2 是将经典 PC 赛车游戏 Colin McRae Rally 2.0 原生移植到现代 Linux、Windows、macOS 与 Android 的项目，基于对原版可执行文件的反编译重建，而非模拟或兼容层。游戏逻辑沿用反编译项目中的 C++，独立平台层则用 SDL3、通过 SDL GPU API 在 Vulkan 与 Metal 上的 GPU 着色器、内置 Bink 解码器以及基于 UDP 的网络，替代旧的 DirectDraw、Direct3D 7、DirectSound、DirectInput、DirectPlay 与 Bink。构建使用 Clang 与 CMake，Android 端为 Kotlin 外壳；团队将定点数学、启动表与长时间车辆仿真与零售版二进制对照验证，以在不同帧率下实现位精确的物理一致性。适合希望从 1990 年代末商业作品到现代 API、确定性仿真行为与忠实多人协议行为有一条可文档化、可测试路径的逆向工程师与游戏安全研究者；用户需自行提供已授权游戏数据，仓库不包含任何资源。
