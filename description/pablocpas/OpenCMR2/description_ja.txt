OpenCMR2 は、クラシック PC レーシングゲーム Colin McRae Rally 2.0 を現代の Linux、Windows、macOS、Android へネイティブ移植したプロジェクトで、エミュレーションや互換レイヤーではなく、オリジナル実行ファイルの逆コンパイル再現を基盤としています。ゲームロジックは逆コンパイル成果の C++ のまま、別のプラットフォーム層がレガシーの DirectDraw、Direct3D 7、DirectSound、DirectInput、DirectPlay、Bink を SDL3、Vulkan と Metal 上の SDL GPU API 経由の GPU シェーダー、組み込み Bink デコーダー、UDP ベースのネットワークに置き換えます。ビルドは Clang と CMake、Android は Kotlin シェルで、チームは定点演算、起動テーブル、長時間の車両シミュレーションを小売バイナリと照合し、フレームレートを跨いだビット完全一致の物理 parity を検証しています。1990 年代後半の商用タイトルから現代 API、決定論的シミュレーション、忠実なマルチプレイプロトコルへ、文書化・検証可能な経路を求めるリバースエンジニアやゲームセキュリティ研究者向けで、リポジトリにアセットは同梱されず、ユーザー自身の正規ゲームデータが必要です。
