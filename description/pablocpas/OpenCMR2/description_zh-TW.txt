OpenCMR2 是將經典 PC 賽車遊戲 Colin McRae Rally 2.0 原生移植至現代 Linux、Windows、macOS 與 Android 的專案，建構於對原版可執行檔的反編譯重建，而非模擬或相容層。遊戲邏輯沿用反編譯專案中的 C++，獨立平台層則以 SDL3、透過 SDL GPU API 在 Vulkan 與 Metal 上的 GPU 著色器、內建 Bink 解碼器以及基於 UDP 的網路，取代舊版 DirectDraw、Direct3D 7、DirectSound、DirectInput、DirectPlay 與 Bink。建置使用 Clang 與 CMake，Android 端為 Kotlin 外殼；團隊將定點數學、啟動表與長時間車輛模擬與零售版二進位對照驗證，以在不同影格率下達到位元精確的物理一致性。適合希望從 1990 年代末商業作品到現代 API、確定性模擬行為與忠實多人協定行為有一條可文件化、可測試路徑的逆向工程師與遊戲安全研究者；使用者需自行提供已授權遊戲資料，儲存庫不包含任何資源。
