OpenCMR2 is a native port of the classic PC racing game Colin McRae Rally 2.0 to modern Linux, Windows, macOS, and Android, built on a decompiled recreation of the original executable rather than emulation or compatibility layers. The game logic stays in C++ from the decompilation project while a separate platform layer replaces legacy DirectDraw, Direct3D 7, DirectSound, DirectInput, DirectPlay, and Bink with SDL3, GPU shaders via the SDL GPU API on Vulkan and Metal, a built-in Bink decoder, and UDP-based networking. Builds use Clang and CMake, with an Android shell in Kotlin, and the team validates fixed-point math, startup tables, and long vehicle simulation runs against the retail binary for bit-exact physics parity across frame rates. It suits reverse engineers and game-security researchers who want a documented, testable path from a late-1990s commercial title to modern APIs, deterministic simulation behavior, and faithful multiplayer protocol behavior, and it requires users to supply their own licensed game data because the repository ships no assets.
