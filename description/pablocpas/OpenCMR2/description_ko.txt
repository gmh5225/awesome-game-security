OpenCMR2는 클래식 PC 레이싱 게임 Colin McRae Rally 2.0을 현대 Linux, Windows, macOS, Android로 네이티브 이식한 프로젝트로, 에뮬레이션이나 호환 계층이 아니라 원본 실행 파일의 디컴파일 재현을 기반으로 합니다. 게임 로직은 디컴파일 프로젝트의 C++를 유지하고, 별도 플랫폼 계층이 레거시 DirectDraw, Direct3D 7, DirectSound, DirectInput, DirectPlay, Bink를 SDL3, Vulkan과 Metal에서 SDL GPU API를 통한 GPU 셰이더, 내장 Bink 디코더, UDP 기반 네트워킹으로 대체합니다. 빌드는 Clang과 CMake를 사용하며 Android 셸은 Kotlin이고, 팀은 고정소수점 연산, 시작 테이블, 장시간 차량 시뮬레이션을 정품 바이너리와 대조해 프레임률에 관계없이 비트 단위로 동일한 물리 parity를 검증합니다. 1990년대 후반 상용 타이틀에서 현대 API, 결정론적 시뮬레이션, 충실한 멀티플레이 프로토콜까지 문서화·검증 가능한 경로를 원하는 리버스 엔지니어와 게임 보안 연구자에게 적합하며, 저장소에는 에셋이 없어 사용자가 직접 라이선스된 게임 데이터를 제공해야 합니다.
