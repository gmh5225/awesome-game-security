這是一款適用於 Windows 的解包與轉儲工具，用於處理由 VMProtect 保護的可執行檔與 DLL。以 C++ 與 Visual Studio 撰寫，它會將解包 DLL 注入目標行程，等待 VMProtect 在載入時完成解包，接著快照並重建已解包映像，包含匯入表修復。工具也提供 VMProtect 位元組碼偵測與去虛擬化支援，可輸出已還原虛擬化程式碼的反組譯，並附帶反偵錯 hook 以降低 VMProtect 防護檢查造成的干擾。支援啟動受保護的 EXE 或 DLL 目標，以及以 PID 附加至執行中行程；針對 VMProtect 3.8.4 開發並測試。用於安全研究、逆向工程教學，以及對您獲授權檢視之軟體的合法分析。
