Это Windows-инструмент для распаковки и дампа исполняемых файлов и DLL, защищённых VMProtect. Написан на C++ в Visual Studio: внедряет DLL-распаковщик в целевой процесс, ждёт завершения распаковки VMProtect при загрузке, затем делает снимок и восстанавливает распакованный образ, включая исправление таблицы импорта. Также включает обнаружение байткода VMProtect и поддержку devirtualization, позволяющую выводить дизассемблирование восстановленного виртуализированного кода, а также anti-debug hooks для снижения помех от проверок защиты VMProtect. Поддерживает запуск защищённых EXE/DLL, подключение к работающим процессам по PID; разработан и протестирован для VMProtect 3.8.4. Предназначен для исследований в области безопасности, обучения reverse engineering и законного анализа ПО, которое вы уполномочены изучать.
