这是一款适用于 Windows 的解包与转储工具，用于处理受 VMProtect 保护的可执行文件和 DLL。该工具使用 C++ 与 Visual Studio 编写，会向目标进程注入解包 DLL，等待 VMProtect 在加载时完成解包，然后快照并重建已解包映像，包括修复导入表。它还包含 VMProtect 字节码检测与去虚拟化支持，可输出恢复后的虚拟化代码的反汇编，并提供反调试 hook，以减少 VMProtect 防护检查带来的干扰。该工具支持启动受保护的 EXE 或 DLL 目标、通过 PID 附加到运行中的进程，并针对 VMProtect 3.8.4 开发与测试。适用于安全研究、逆向工程教育，以及对你有权分析的软件进行合法分析。
