これは VMProtect で保護された実行ファイルや DLL 向けの Windows 用アンパック／ダンプツールです。C++ と Visual Studio で実装され、ターゲットプロセスへアンパッカ DLL を注入し、ロード時に VMProtect のアンパック完了を待ってから、インポートテーブル修復を含めてアンパック済みイメージをスナップショット取得し再構成します。VMProtect バイトコード検出とデバーチャライズ機能も備え、復元した仮想化コードの逆アセンブリ出力が可能です。さらに VMProtect の保護チェックによる干渉を減らすためのアンチデバッグフックも含みます。保護された EXE/DLL の起動、PID による実行中プロセスへのアタッチに対応し、VMProtect 3.8.4 向けに開発・テストされています。セキュリティ研究、リバースエンジニアリング教育、および分析権限のあるソフトウェアの合法的な解析を目的としています。
