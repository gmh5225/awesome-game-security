This is a Windows unpacker and dumper for executables and DLLs protected with VMProtect. Written in C++ with Visual Studio, it injects an unpacker DLL into a target process, waits for VMProtect to finish unpacking at load time, then snapshots and reconstructs the unpacked image including import table repair. It also includes VMProtect bytecode detection and devirtualization support that can emit disassembly of recovered virtualized code, along with anti-debug hooks to reduce interference from VMProtect's protection checks. The tool supports launching protected EXE or DLL targets, attaching to live processes by PID, and was developed and tested against VMProtect 3.8.4. It is intended for security research, reverse-engineering education, and lawful analysis of software you are authorized to examine.
