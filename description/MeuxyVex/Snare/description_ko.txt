Snare는 자사 타이틀에 대한 치트를 통제된 실험 환경에서 연구해야 하는 게임 개발자와 소규모 안티치트 팀을 위한 오픈 소스 에이전트리스 분석 샌드박스입니다. 강화된 Windows 게스트에서 게임과 샘플을 실행하는 동안 Linux 호스트가 KVM 또는 QEMU를 통해 메모리, 프로세스, 커널 드라이버, 네트워크 트래픽을 관찰하며, LibVMI와 DRAKVUF를 통한 하이퍼바이저 수준 인트로스펙션과 Volatility 3, MemProcFS와의 포렌식 연동이 계획되어 있습니다. 분석은 깨끗한 기준 세션과 치트 세션을 비교하는 차분 실행을 중심으로 하며, 후킹, 인젝션, 프로세스 간 메모리 접근, 의심스러운 드라이버에 대한 탐지기를 포함하고 YAML 게임 프로파일을 통해 읽기 쉬운 치트 행위와 구조화된 JSON 또는 HTML 보고서로 매핑합니다. 코드베이스는 주로 Python 3.11과 Typer, Pydantic, JSON 스키마로 구성되며, Rust 성능 코어와 FastAPI 웹 UI가 계획되어 있고, 승인된 리버스 엔지니어링, 치트 영향 평가, 안티치트 연구를 목표로 하며 인게임 enforcement는 대상이 아닙니다. 프로젝트는 아직 초기 설계 단계이므로 로드맵에 설명된 많은 기능은 계획 단계이며 완전히 구현되지 않았습니다.
