Snare es un entorno de análisis en sandbox de código abierto sin agentes, pensado para desarrolladores de juegos y equipos pequeños de anti-trampas que necesitan estudiar trampas contra sus propios títulos en un laboratorio controlado. Ejecuta el juego y la muestra dentro de un invitado Windows endurecido mientras observa memoria, procesos, controladores del kernel y tráfico de red desde el host Linux mediante KVM o QEMU, con introspección a nivel de hipervisor prevista mediante LibVMI y DRAKVUF e integración forense con Volatility 3 y MemProcFS. El análisis se centra en ejecuciones diferenciales que comparan una sesión base limpia con una sesión de trampa, además de detectores de hooks, inyección, acceso a memoria entre procesos y controladores sospechosos, mapeados mediante perfiles de juego YAML a comportamientos de trampa legibles e informes JSON o HTML estructurados. La base de código es principalmente Python 3.11 con Typer, Pydantic y esquemas JSON, con un núcleo de rendimiento en Rust y una interfaz web FastAPI planificados, y está orientada a ingeniería inversa autorizada, evaluación del impacto de trampas e investigación anti-trampas, no a enforcement en el juego. El proyecto aún está en fase de diseño inicial; muchas capacidades descritas en su hoja de ruta están planificadas más que plenamente implementadas.
