Snare is an open-source agentless analysis sandbox aimed at game developers and small anti-cheat teams who need to study cheats against their own titles in a controlled lab. It runs the game and sample inside a hardened Windows guest while observing memory, processes, kernel drivers, and network traffic from the Linux host via KVM or QEMU, with planned hypervisor-level introspection through LibVMI and DRAKVUF and forensics integration with Volatility 3 and MemProcFS. Analysis centers on differential runs that compare a clean baseline session to a cheat session, plus detectors for hooks, injection, cross-process memory access, and suspicious drivers, mapped through YAML game profiles into readable cheat behaviors and structured JSON or HTML reports. The codebase is primarily Python 3.11 with Typer, Pydantic, and JSON schemas, with a planned Rust performance core and FastAPI web UI, and it targets authorized reverse engineering, cheat impact assessment, and anti-cheat research rather than in-game enforcement. The project is still in early design, so many capabilities described in its roadmap are planned rather than fully implemented.
