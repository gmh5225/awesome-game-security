Snare は、自社タイトルに対するチートを管理されたラボ環境で調査する必要があるゲーム開発者や小規模アンチチートチーム向けの、オープンソースのエージェントレス分析サンドボックスです。ハード化された Windows ゲスト内でゲームとサンプルを実行し、Linux ホストから KVM または QEMU 経由でメモリ、プロセス、カーネルドライバー、ネットワークトラフィックを監視します。LibVMI と DRAKVUF によるハイパーバイザー水準のイントロスペクション、および Volatility 3 と MemProcFS とのフォレンジック連携が計画されています。分析の中心は、クリーンなベースラインセッションとチートセッションを比較する差分実行に加え、フック、インジェクション、プロセス間メモリアクセス、疑わしいドライバー向けの検出器であり、YAML ゲームプロファイルを通じて読みやすいチート行動と構造化された JSON または HTML レポートにマッピングされます。コードベースは主に Python 3.11 で Typer、Pydantic、JSON スキーマを用い、Rust による性能コアと FastAPI Web UI を計画しています。対象は許可されたリバースエンジニアリング、チート影響評価、アンチチート研究であり、ゲーム内 enforcement ではありません。プロジェクトはまだ初期設計段階にあり、ロードマップに記載された多くの機能は計画段階で、完全実装ではありません。
