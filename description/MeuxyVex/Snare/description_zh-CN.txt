Snare 是一款面向游戏开发者和小型反作弊团队的开源无代理分析沙箱，便于在受控实验环境中针对自有作品研究作弊行为。它在加固的 Windows 客户机中运行游戏与样本，同时由 Linux 宿主机通过 KVM 或 QEMU 观察内存、进程、内核驱动与网络流量，并计划通过 LibVMI 与 DRAKVUF 实现 Hypervisor 级内省，以及与 Volatility 3、MemProcFS 的取证集成。分析以差分运行为核心，将干净基线会话与作弊会话对比，并包含针对钩子、注入、跨进程内存访问与可疑驱动的检测器，经 YAML 游戏配置映射为可读的作弊行为及结构化 JSON 或 HTML 报告。代码库主要为 Python 3.11，使用 Typer、Pydantic 与 JSON Schema，并规划 Rust 性能核心与 FastAPI Web 界面，面向授权逆向工程、作弊影响评估与反作弊研究，而非游戏内 enforcement。项目仍处于早期设计阶段，路线图中许多能力为规划项而非已完全实现。
