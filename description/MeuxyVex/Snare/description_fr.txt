Snare est un bac à sable d’analyse open source sans agent, destiné aux développeurs de jeux et aux petites équipes anti-triche qui doivent étudier les triches contre leurs propres titres dans un laboratoire contrôlé. Il exécute le jeu et l’échantillon dans une machine invitée Windows durcie tout en observant la mémoire, les processus, les pilotes noyau et le trafic réseau depuis l’hôte Linux via KVM ou QEMU, avec une introspection au niveau de l’hyperviseur prévue via LibVMI et DRAKVUF et une intégration forensique avec Volatility 3 et MemProcFS. L’analyse repose sur des exécutions différentielles comparant une session de référence propre à une session de triche, ainsi que des détecteurs pour les hooks, l’injection, l’accès mémoire inter-processus et les pilotes suspects, mappés via des profils de jeu YAML vers des comportements de triche lisibles et des rapports JSON ou HTML structurés. La base de code est principalement en Python 3.11 avec Typer, Pydantic et des schémas JSON, avec un noyau de performance Rust et une interface web FastAPI prévus, et vise le reverse engineering autorisé, l’évaluation de l’impact des triches et la recherche anti-triche plutôt que l’application en jeu. Le projet en est encore au stade de conception initiale ; de nombreuses capacités décrites dans sa feuille de route sont prévues plutôt que pleinement implémentées.
