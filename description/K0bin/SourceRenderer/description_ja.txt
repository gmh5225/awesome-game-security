SourceRenderer は Rust で書かれたトイゲームエンジンで、独自の低レベルグラフィックススタックを備え、Source エンジン風のゲームコンテンツと現代的なアセットの読み込み・描画を目指しています。エンジン基盤の多くは Bevy に依拠しつつ、ウィンドウ管理、アセット管理、レンダリングは独自実装に置き換えています。グラフィックス層は Vulkan 1.3 を主バックエンドとし、Metal と WebGPU もサポート。bindless リソース、利用可能な場合のレイトレーシング、multi-draw indirect、オクルージョンクエリ、パイプライン化されたマルチスレッドレンダリングに加え、PBR、SSAO、TAA などの効果を含みます。非同期アセットマネージャは glTF に加え、BSP マップ、VPK パック、VMT/VTF マテリアル、MDL モデルといった Source 形式、および CS:GO 関連ローダを読み込めます。主に Source エンジンのマップやアセット周りのグラフィックス・リバースエンジニアリング、およびデスクトップ・Web・モバイル向けの現代的 GPU 駆動レンダリング実験に役立ちます。
