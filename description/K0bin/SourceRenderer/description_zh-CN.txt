SourceRenderer 是一个用 Rust 编写的玩具游戏引擎，自带自定义底层图形栈，目标是加载并渲染 Source 引擎风格的游戏内容以及现代资源。它大量基于 Bevy 的引擎基础设施，同时用自有方案替换了窗口管理、资源管理和渲染。图形层以 Vulkan 1.3 为主要后端，并支持 Metal 与 WebGPU，包含 bindless 资源、可用时的光线追踪、multi-draw indirect、遮挡查询，以及带流水线的多线程渲染，并支持 PBR、SSAO、TAA 等相关效果。异步资源管理器可加载 glTF，以及 BSP 地图、VPK 包、VMT/VTF 材质和 MDL 模型等 Source 格式，还包括与 CS:GO 相关的加载器。它主要用于围绕 Source 引擎地图与资源的图形与逆向工程工作，以及在桌面、Web 和移动平台上试验现代 GPU 驱动渲染。
