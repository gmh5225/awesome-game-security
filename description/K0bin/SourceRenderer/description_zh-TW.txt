SourceRenderer 是一個以 Rust 撰寫的玩具遊戲引擎，具備自訂底層圖形堆疊，目標是載入並渲染 Source 引擎風格的遊戲內容以及現代資源。它大量建基於 Bevy 的引擎基礎設施，同時以自有方案取代視窗管理、資源管理與渲染。圖形層以 Vulkan 1.3 為主要後端，並支援 Metal 與 WebGPU，包含 bindless 資源、可用時的光線追蹤、multi-draw indirect、遮蔽查詢，以及具流水線的多執行緒渲染，並支援 PBR、SSAO、TAA 等相關效果。非同步資源管理器可載入 glTF，以及 BSP 地圖、VPK 套件、VMT/VTF 材質與 MDL 模型等 Source 格式，亦包含與 CS:GO 相關的載入器。它主要用於圍繞 Source 引擎地圖與資源的圖形與逆向工程工作，以及在桌面、Web 與行動平台上實驗現代 GPU 驅動渲染。
