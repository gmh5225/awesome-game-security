GprzSS es un escáner orientado a Windows pensado para que el personal de servidores de Minecraft verifique el equipo de un jugador durante comprobaciones de integridad en screenshare. Está implementado en Python 3.10 y posteriores usando solo la biblioteca estándar, y ofrece tanto una interfaz web local como informes Markdown o JSON sin interfaz a partir de una única ejecución de escaneo. La herramienta ejecuta una docena de módulos forenses que cubren procesos en ejecución, identificación de la JVM en distribuciones JDK habituales, inspección del heap en memoria, Prefetch, Amcache, BAM, el diario de cambios NTFS, artefactos del navegador, rastros del sistema de archivos, servicios, cuentas y mods, comparando los resultados con firmas JSON editables de clientes de trampas e inyectores conocidos. Usa APIs de Windows basadas en ctypes para acceder a procesos y memoria y puede autoelevarse para leer artefactos privilegiados o marcarlos explícitamente como omitidos en lugar de informarlos como limpios. Los operadores pueden distribuir un ejecutable PyInstaller de un solo archivo o ejecutar desde el código fuente cuando necesiten flujos prácticos de antitrampas y screenshare para Minecraft Java Edition en Windows 10 y 11.
