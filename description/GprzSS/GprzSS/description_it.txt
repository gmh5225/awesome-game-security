GprzSS è uno scanner per screenshare orientato a Windows, pensato per aiutare lo staff dei server Minecraft a verificare il computer di un giocatore durante i controlli di integrità. È implementato in Python 3.10 e versioni successive usando solo la libreria standard, e offre sia un’interfaccia web locale sia report Markdown o JSON headless da un’unica esecuzione di scansione. Lo strumento esegue una dozzina di moduli forensi che coprono processi in esecuzione, identificazione della JVM sulle distribuzioni JDK comuni, ispezione dell’heap in memoria, Prefetch, Amcache, BAM, il journal delle modifiche NTFS, artefatti del browser, tracce del filesystem, servizi, account e mod, confrontando i risultati con firme JSON modificabili per client cheat e injector noti. Usa API Windows basate su ctypes per l’accesso a processi e memoria e può auto-elevarsi così da leggere gli artefatti privilegiati o contrassegnarli esplicitamente come saltati invece di segnalarli come puliti. Gli operatori possono distribuire un eseguibile PyInstaller monofile o eseguire dal sorgente quando servono flussi pratici anti-cheat e screenshare per Minecraft Java Edition su Windows 10 e 11.
