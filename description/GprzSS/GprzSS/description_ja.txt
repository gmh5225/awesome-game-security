GprzSS は Windows 向けのスクリーンシェア用スキャナで、Minecraft サーバー運営者が整合性チェック時にプレイヤーのマシンを確認するのに役立ちます。Python 3.10 以降と標準ライブラリのみで実装され、1 回のスキャンでローカル Web UI とヘッドレスの Markdown または JSON レポートの両方を提供します。実行中プロセス、一般的な JDK 配布での JVM 識別、メモリ上のヒープ検査、Prefetch、Amcache、BAM、NTFS 変更ジャーナル、ブラウザアーティファクト、ファイルシステム上の痕跡、サービス、アカウント、モッドなど十数のフォレンジックモジュールを走らせ、既知のチートクライアントやインジェクター向けの編集可能な JSON シグネチャと照合します。ctypes ベースの Windows API でプロセスとメモリにアクセスし、自己昇格して特権が必要なアーティファクトを読み取るか、読めない場合はクリーンと誤報せず明示的にスキップとマークします。運用者は単一ファイルの PyInstaller 実行ファイルを配布するか、ソースから実行でき、Windows 10 および 11 上の Java Edition Minecraft 向けの実用的なアンチチートおよびスクリーンシェアワークフローに対応します。
