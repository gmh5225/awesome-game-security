GprzSS 是一款面向 Windows 的螢幕分享掃描工具，供 Minecraft 伺服器管理人員在完整性檢查期間驗證玩家電腦。它以 Python 3.10 及更新版本實作，僅使用標準函式庫，單次掃描即可提供本機 Web 介面與無介面 Markdown 或 JSON 報告。此工具執行十多個鑑識模組，涵蓋執行中程序、常見 JDK 發行版中的 JVM 識別、記憶體堆積檢查、Prefetch、Amcache、BAM、NTFS 變更日誌、瀏覽器痕跡、檔案系統軌跡、服務、帳戶與模組，並將結果與可編輯 JSON 簽章庫中已知作弊客戶端與注入器進行比對。它透過以 ctypes 為基礎的 Windows API 存取程序與記憶體，並可自我提升權限，以便讀取需特權的成品，或在無法讀取時明確標記為已略過，而非誤報為乾淨。維運人員可散發單一檔案 PyInstaller 可執行檔，或從原始碼執行，以支援 Windows 10 與 11 上 Java 版 Minecraft 的實用反作弊與螢幕分享工作流程。
