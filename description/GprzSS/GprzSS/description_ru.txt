GprzSS — сканер для screenshare под Windows, помогающий персоналу серверов Minecraft проверять машину игрока при проверках целостности. Реализован на Python 3.10 и новее только со стандартной библиотекой; за один проход сканирования доступны локальный веб-интерфейс и headless-отчёты в Markdown или JSON. Инструмент запускает около дюжины форензик-модулей: запущенные процессы, идентификация JVM в распространённых дистрибутивах JDK, проверка кучи в памяти, Prefetch, Amcache, BAM, журнал изменений NTFS, артефакты браузера, следы в файловой системе, службы, учётные записи и моды, сопоставляя результаты с редактируемыми JSON-сигнатурами известных чит-клиентов и инжекторов. Для доступа к процессам и памяти используются Windows API через ctypes; возможна самоповышение привилегий, чтобы читать привилегированные артефакты или явно помечать их как пропущенные, а не ошибочно сообщать «чисто». Операторы могут раздавать однофайловый исполняемый файл PyInstaller или запускать из исходников для практичных античит- и screenshare-сценариев Minecraft Java Edition на Windows 10 и 11.
