GprzSS는 Windows용 스크린셰어 스캐너로, Minecraft 서버 운영진이 무결성 검사 중 플레이어 PC를 확인하는 데 쓰입니다. Python 3.10 이상과 표준 라이브러리만으로 구현되었으며, 한 번의 스캔으로 로컬 웹 인터페이스와 헤드리스 Markdown 또는 JSON 보고서를 모두 제공합니다. 실행 중인 프로세스, 일반적인 JDK 배포판의 JVM 식별, 메모리 힙 검사, Prefetch, Amcache, BAM, NTFS 변경 저널, 브라우저 아티팩트, 파일 시스템 흔적, 서비스, 계정, 모드 등 열두 가지 가까운 포렌식 모듈을 실행하고, 알려진 치트 클라이언트와 인젝터에 대한 편집 가능한 JSON 서명과 결과를 대조합니다. ctypes 기반 Windows API로 프로세스와 메모리에 접근하며, 필요 시 자체 권한 상승으로 특권 아티팩트를 읽거나 읽을 수 없으면 깨끗하다고 보고하지 않고 명시적으로 건너뜀으로 표시합니다. 운영자는 단일 파일 PyInstaller 실행 파일을 배포하거나 소스에서 실행해 Windows 10 및 11의 Java Edition Minecraft에 대한 실용적인 안티치트 및 스크린셰어 워크플로를 사용할 수 있습니다.
