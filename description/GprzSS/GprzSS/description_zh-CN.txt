GprzSS 是一款面向 Windows 的屏幕共享扫描工具，供 Minecraft 服务器管理人员在完整性检查期间核验玩家机器。它使用 Python 3.10 及更高版本实现，仅依赖标准库，单次扫描可同时提供本地 Web 界面与无界面 Markdown 或 JSON 报告。该工具运行十余个取证模块，涵盖运行进程、常见 JDK 发行版中的 JVM 识别、内存堆检查、Prefetch、Amcache、BAM、NTFS 变更日志、浏览器痕迹、文件系统轨迹、服务、账户与模组，并将结果与可编辑 JSON 签名库中已知作弊客户端与注入器进行比对。它通过基于 ctypes 的 Windows API 访问进程与内存，并可自行提权，以便读取特权相关工件或在无法读取时明确标记为已跳过，而非误报为干净。运维人员可分发单文件 PyInstaller 可执行程序，或从源码运行，以满足 Windows 10 与 11 上 Java 版 Minecraft 的实用反作弊与屏幕共享工作流需求。
