GprzSS is a Windows-oriented screenshare scanner built to help Minecraft server staff verify a player’s machine during integrity checks. It is implemented in Python 3.10 and later using only the standard library, and it offers both a local web interface and headless markdown or JSON reports from a single scan run. The tool runs a dozen forensic modules covering running processes, JVM identification across common JDK distributions, in-memory heap inspection, Prefetch, Amcache, BAM, the NTFS change journal, browser artefacts, filesystem traces, services, accounts, and mods, matching results against editable JSON signatures for known cheat clients and injectors. It uses ctypes-based Windows APIs for process and memory access and can self-elevate so privileged artifacts are read or explicitly marked skipped rather than reported as clean. Operators can distribute a one-file PyInstaller executable or run from source when they need practical anti-cheat and screenshare workflows for Java Edition Minecraft on Windows 10 and 11.
