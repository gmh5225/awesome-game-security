GprzSS est un scanner orienté Windows conçu pour les équipes de serveurs Minecraft lors des vérifications d’intégrité pendant un screenshare. Il est implémenté en Python 3.10 et versions ultérieures en n’utilisant que la bibliothèque standard, et propose à la fois une interface web locale et des rapports Markdown ou JSON sans interface à partir d’un seul passage de scan. L’outil exécute une douzaine de modules forensiques couvrant les processus en cours, l’identification de la JVM sur les distributions JDK courantes, l’inspection du tas en mémoire, Prefetch, Amcache, BAM, le journal des modifications NTFS, les artefacts de navigateur, les traces du système de fichiers, les services, les comptes et les mods, en comparant les résultats à des signatures JSON modifiables pour les clients de triche et injecteurs connus. Il s’appuie sur les API Windows via ctypes pour l’accès aux processus et à la mémoire et peut s’auto-élever afin de lire les artefacts privilégiés ou de les marquer explicitement comme ignorés plutôt que de les signaler comme propres. Les opérateurs peuvent distribuer un exécutable PyInstaller en un seul fichier ou lancer depuis les sources pour des flux anti-triche et screenshare pratiques sur Minecraft Java Edition sous Windows 10 et 11.
