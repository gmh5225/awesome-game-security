Scroll of Creative Mode is a Minecraft Fabric mod that lets server operators grant temporary Creative Mode through a consumable admin-only scroll instead of open gamemode commands. It is implemented in Java with Fabric Loader, Fabric API, and server-side Mixins that enforce rules at the tick and network packet layers. Sessions run on a configurable timer with persistent countdowns across disconnects and restarts, inventory sandboxing that restores the player’s pre-session gear, packet-level blocking of disallowed creative spawns, and restrictions on containers, drops, and smuggling during active use. Operators can tune duration, blocked item lists, and safety effects such as Slow Falling on expiry, and reload settings or end sessions via in-game commands. It is aimed at multiplayer server moderation and game security teams who need controlled creative building privileges without economy abuse, duplication, or client-bypass exploits.
