Scroll of Creative Mode 是一款 Minecraft Fabric 模組，讓伺服器管理員透過可消耗的僅管理員可用卷軸授予暫時創造模式，而無需開放 gamemode 指令。它以 Java 實作，仰賴 Fabric Loader、Fabric API，以及伺服器端 Mixin，在 tick 與網路封包層面強制執行規則。工作階段運行於可設定計時器上，斷線與重啟後仍保留持久倒數；提供物品欄沙箱（還原玩家工作階段前裝備）、在封包層面阻擋不允許的創造模式生成，並在使用期間限制容器、掉落與夾帶。管理員可調整時長、物品黑名單及到期安全效果（如緩降），並透過遊戲內指令重新載入設定或結束工作階段。面向多人伺服器管理與遊戲安全團隊，在可控的創造建築權限下避免經濟濫用、複製或客戶端繞過類漏洞。
