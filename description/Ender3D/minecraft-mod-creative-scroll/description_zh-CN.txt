Scroll of Creative Mode 是一款 Minecraft Fabric 模组，让服务器管理员通过可消耗的仅管理员可用卷轴授予临时创造模式，而无需开放 gamemode 命令。它使用 Java 实现，依托 Fabric Loader、Fabric API，以及服务端 Mixin，在 tick 与网络数据包层面强制执行规则。会话运行于可配置计时器上，断线与重启后仍保留持久倒计时；提供物品栏沙箱（恢复玩家会话前装备）、在数据包层面阻止不允许的创造模式生成，并在使用期间限制容器、掉落与夹带。管理员可调时长、物品黑名单及到期安全效果（如缓降），并通过游戏内命令重载设置或结束会话。面向多人服务器管理与游戏安全团队，在可控创造建筑权限下避免经济滥用、复制或客户端绕过类漏洞。
