Scroll of Creative Mode è una mod Minecraft per Fabric che consente agli operatori del server di concedere la modalità Creativa temporanea tramite una pergamena consumabile riservata agli amministratori, invece di aprire i comandi gamemode. È implementata in Java con Fabric Loader, Fabric API e Mixin lato server che applicano le regole a livello di tick e pacchetti di rete. Le sessioni usano un timer configurabile, con countdown persistenti dopo disconnessioni e riavvii, sandbox dell’inventario che ripristina l’equipaggiamento pre-sessione, blocco a livello pacchetto degli spawn creativi non consentiti e restrizioni su contenitori, drop e contrabbando durante l’uso attivo. Gli operatori possono regolare durata, elenchi di oggetti bloccati ed effetti di sicurezza come Slow Falling alla scadenza, e ricaricare le impostazioni o terminare le sessioni con comandi in gioco. È pensata per la moderazione di server multigiocatore e team di sicurezza del gioco che necessitano privilegi di costruzione creativa controllati senza abuso economico, duplicazione o exploit di bypass del client.
