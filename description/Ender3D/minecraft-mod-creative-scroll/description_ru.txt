Scroll of Creative Mode — мод для Minecraft на Fabric, позволяющий операторам сервера выдавать временный творческий режим через расходуемый свиток только для администраторов, вместо открытого доступа к командам gamemode. Реализован на Java с Fabric Loader, Fabric API и серверными Mixin, которые принудительно применяют правила на уровне тиков и сетевых пакетов. Сессии работают по настраиваемому таймеру с сохранением обратного отсчёта при отключении и перезапуске; песочница инвентаря восстанавливает снаряжение до сессии, на уровне пакетов блокируются запрещённые творческие спавны, а при активном использовании действуют ограничения на контейнеры, дроп и контрабанду. Операторы настраивают длительность, списки заблокированных предметов и эффекты безопасности вроде Slow Falling по истечении срока, перезагружают настройки и завершают сессии игровыми командами. Предназначен для модерации многопользовательских серверов и команд игровой безопасности, которым нужны контролируемые привилегии творческого строительства без злоупотреблений экономикой, дублирования и обхода клиента.
