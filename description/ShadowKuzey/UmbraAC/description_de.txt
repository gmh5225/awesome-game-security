UmbraAC ist ein leichtes, modulares Anti-Cheat-Plugin für Minecraft-Server auf Basis der Paper-API. Es ist in Java geschrieben und wird mit Gradle gebaut und richtet sich an moderne Serverversionen unter Java 21. Das Plugin führt serverseitige Erkennungsmodule für gängige Client-Cheats wie Fly, Kill Aura, No-Fall, Reach, Speed und X-Ray aus und nutzt dabei Bewegungsereignisse, Kampftiming, Fallschaden, Trefferdistanz und Heuristiken beim Erzabbau. Mitarbeiter erhalten Ingame-Warnungen und Konsolenprotokolle über einen zentralen Alert-Manager, mit einstellbaren Schwellen in YAML und einem Admin-Reload-Befehl. Es richtet sich an Betreiber von Multiplayer-Servern, die praktische Spielsicherheit und Cheat-Überwachung ohne einen schweren Anti-Cheat-Stack brauchen.
