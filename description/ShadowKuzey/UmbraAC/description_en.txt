UmbraAC is a lightweight, modular anti-cheat plugin for Minecraft servers built on the Paper API. It is written in Java and packaged with Gradle, targeting modern server versions on Java 21. The plugin runs server-side detection modules for common client cheats including fly, kill aura, no-fall, reach, speed, and x-ray, using movement events, combat timing, fall damage, hit distance, and ore-mining heuristics. Staff receive in-game alerts and console logging through a central alert manager, with tunable thresholds in YAML and an admin reload command. It is aimed at multiplayer server operators who need practical game security and cheat monitoring without a heavy anti-cheat stack.
