UmbraAC — лёгкий модульный античит-плагин для серверов Minecraft на базе Paper API. Написан на Java и собирается Gradle, рассчитан на современные версии сервера под Java 21. Плагин запускает серверные модули обнаружения распространённых клиентских читов: полёт, kill aura, no-fall, reach, speed и x-ray, используя события движения, тайминг боя, урон от падения, дистанцию удара и эвристики добычи руды. Персонал получает игровые оповещения и логи в консоли через центральный менеджер алертов, с настраиваемыми порогами в YAML и командой перезагрузки для администраторов. Ориентирован на операторов мультиплеерных серверов, которым нужна практичная игровая безопасность и мониторинг читов без тяжёлого античит-стека.
