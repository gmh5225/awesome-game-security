UmbraAC è un plugin anticheat leggero e modulare per server Minecraft basato sulle API Paper. È scritto in Java e confezionato con Gradle, pensato per versioni moderne del server su Java 21. Il plugin esegue moduli di rilevamento lato server per cheat client comuni come fly, kill aura, no-fall, reach, speed e x-ray, usando eventi di movimento, tempistiche di combattimento, danni da caduta, distanza dei colpi ed euristiche di estrazione mineraria. Lo staff riceve avvisi in gioco e log in console tramite un gestore centralizzato degli alert, con soglie regolabili in YAML e un comando di reload per gli admin. È pensato per chi gestisce server multigiocatore e cerca sicurezza di gioco e monitoraggio dei cheat pratici senza uno stack anticheat pesante.
