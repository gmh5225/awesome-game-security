UmbraAC es un complemento antitrampas ligero y modular para servidores de Minecraft basado en la API de Paper. Está escrito en Java y empaquetado con Gradle, orientado a versiones modernas del servidor en Java 21. El complemento ejecuta módulos de detección en el servidor para trampas habituales del cliente como fly, kill aura, no-fall, reach, speed y x-ray, usando eventos de movimiento, sincronización de combate, daño por caída, distancia de golpe y heurísticas de minería. El personal recibe alertas en el juego y registros en consola mediante un gestor central de alertas, con umbrales ajustables en YAML y un comando de recarga para administradores. Está dirigido a operadores de servidores multijugador que necesitan seguridad de juego y supervisión de trampas prácticas sin una pila antitrampas pesada.
