UmbraAC は Paper API 上の軽量かつモジュール型の Minecraft サーバー向けアンチチートプラグインです。Java で書かれ Gradle でビルドされ、Java 21 上の現行サーバーバージョンを対象にしています。プラグインはサーバー側で検知モジュールを動かし、fly、kill aura、no-fall、reach、speed、x-ray などの一般的なクライアントチートを、移動イベント、戦闘タイミング、落下ダメージ、命中距離、採掘ヒューリスティックで検出します。スタッフは集中アラートマネージャー経由でゲーム内通知とコンソールログを受け取り、YAML で閾値を調整でき、管理者向けのリロードコマンドも用意されています。重量級のアンチチート基盤を避けつつ、実用的なゲームセキュリティとチート監視が必要なマルチプレイサーバー運営者向けです。
