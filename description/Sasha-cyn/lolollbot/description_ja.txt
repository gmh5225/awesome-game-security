lolollbot は Geometry Dash 向けの Geode クライアント MOD で、クラシックな xDBot 系ツールと同様のスタイルでフレーム単位に正確なクリックマクロの記録と再生ができる。C++ と CMake で実装され、PlayLayer、PlayerObject、メニューおよび入力ディスパッチャーなどのコアゲーム層にフックし、記録モードで入力を捕捉し、再生時に注入する。MOD はレベルごとのマクロデータをディスクに永続化し、プラクティスモードのチェックポイント巻き戻しに対応し、ノークリップ、スピードハック、FPS・TPS の上書き、各種プレイヤーおよびレベル効果のバイパスなどを含む設定可能なオーバーレイとチートを同梱する。リズムゲームの自動化、クライアント側改造、スパイクによる死亡検証のようなゲーム内アンチチートと非公式ツールがどう相互作用するかを調べる研究者やプレイヤー向けである。
