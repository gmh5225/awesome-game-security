Apex-RE 是一個開源逆向工程技能與提示詞庫，用於教會 AI 程式設計助手以結構化、以驗證為導向的工作流程分析原生與受管二進位檔。它提供零相依的 Python 初步分析、特徵掃描、記憶體差分、虛擬機追蹤分析及相關輔助工具，並附帶針對 Unreal 與 Unity 遊戲二進位、.NET 與 NativeAOT、混淆器以及以模擬為基礎的驗證等大量參考指南。專案還提供可直接使用的任務指令與五層方法論，旨在產出可編譯的 C++20 與 C# 程式碼、Kaitai 結構體規格與記憶體配置，而非缺乏依據的偽程式碼。面向逆向工程師、惡意程式與遊戲安全研究人員，以及希望將自主、跨平台二進位分析與 Ghidra、IDA Pro、Frida 等工具整合的代理開發者。
