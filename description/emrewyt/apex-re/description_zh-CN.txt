Apex-RE 是一个开源逆向工程技能与提示词库，用于教会 AI 编程助手以结构化、以验证为导向的工作流分析原生与管理型二进制文件。它提供零依赖的 Python 初步分析、特征扫描、内存差分、虚拟机跟踪分析及相关辅助工具，并附带针对 Unreal 与 Unity 游戏二进制、.NET 与 NativeAOT、混淆器以及基于仿真的验证等大量参考指南。项目还提供可直接使用的任务指令与五层方法论，旨在产出可编译的 C++20 与 C# 代码、Kaitai 结构体规范与内存布局，而非缺乏依据的伪代码。面向逆向工程师、恶意软件与游戏安全研究人员，以及希望将自主、跨平台二进制分析与 Ghidra、IDA Pro、Frida 等工具集成的智能体开发者。
