Apex-RE は、AI コーディングエージェントにネイティブおよびマネージドバイナリを分析するための構造化された検証指向のワークフローを教えるオープンソースのリバースエンジニアリングスキルおよびプロンプトライブラリです。依存関係ゼロの Python によるトリアージ、シグネチャスキャン、メモリ差分、VM トレース解析などのヘルパーと、Unreal および Unity ゲームバイナリ、.NET と NativeAOT、難読化ツール、エミュレーションに基づく検証に関する広範なリファレンスガイドを同梱しています。本プロジェクトは、根拠のない疑似コードではなく、コンパイル可能な C++20 および C# 出力、Kaitai 構造体仕様、メモリレイアウトを生成することを目的とした、すぐ使えるタスク指示と五層メソドロジーも提供します。Ghidra、IDA Pro、Frida などのツールと統合した自律的なクロスプラットフォームバイナリ解析を求めるリバースエンジニア、マルウェアおよびゲームセキュリティ研究者、エージェント開発者を対象としています。
