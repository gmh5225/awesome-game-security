Apex-RE is an open-source reverse engineering skill and prompt library that teaches AI coding agents a structured, verification-oriented workflow for analyzing native and managed binaries. It ships zero-dependency Python triage, signature scanning, memory diffing, VM trace analysis, and related helpers alongside extensive reference guides for Unreal and Unity game binaries, .NET and NativeAOT, obfuscators, and emulation-backed verification. The project also provides ready-to-use task directives and a five-layer methodology aimed at producing compilable C++20 and C# outputs, Kaitai struct specs, and memory layouts instead of ungrounded pseudocode. It is aimed at reverse engineers, malware and game security researchers, and agent developers who want autonomous, cross-platform binary analysis integrated with tools such as Ghidra, IDA Pro, and Frida.
