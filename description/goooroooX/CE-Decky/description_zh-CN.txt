CE Decky 是一款 Decky Loader 插件，通过管理作弊表并在各游戏的 Proton 前缀内启动官方或用户导入的 Windows 版 Cheat Engine，将 Cheat Engine 带到 Steam Deck 与 SteamOS。Python 后端配合 TypeScript 与 JavaScript 的 Game Mode 界面，以及接入 Cheat Engine 的 Lua 桥接，负责从社区源搜索与下载表、本地库管理、兼容性审查，以及在 Quick Access Menu 中于游戏会话内切换作弊。它与 Steam 库及启动元数据集成，以校验目标并挂接正确的 Windows 可执行文件，且不修改 Steam 配置。自动加载、针对不匹配游戏版本的表修复、经 Authenticode 校验的管理安装，以及严格的会话生命周期控制等功能，面向希望在掌机 Linux 游戏硬件上进行结构化内存编辑与作弊表工作流的玩家与研究人员。
