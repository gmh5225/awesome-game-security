CE Decky — плагин для Decky Loader, который переносит Cheat Engine на Steam Deck и SteamOS: он управляет чит-таблицами и запускает официальный или импортированный пользователем Windows Cheat Engine в префиксе Proton каждой игры. Бэкенд на Python с интерфейсом Game Mode на TypeScript и JavaScript и Lua-мостом в Cheat Engine обеспечивает поиск и загрузку таблиц из сообществ, локальную библиотеку, проверку совместимости и переключение читов в сессии из Quick Access Menu. Интеграция со Steam-библиотеками и метаданными запуска проверяет цели и подключается к нужному Windows-исполняемому файлу без изменения конфигурации Steam. Автозагрузка, починка таблиц под несовпадающие сборки игр, управляемые установки с проверкой Authenticode и строгий контроль жизненного цикла сессии рассчитаны на игроков и исследователей, которым нужны структурированное редактирование памяти и рабочие процессы с чит-таблицами на портативном Linux-игровом железе.
