CE Decky es un complemento de Decky Loader que lleva Cheat Engine a Steam Deck y SteamOS gestionando tablas de trucos y lanzando Cheat Engine para Windows oficial o importado por el usuario dentro del prefijo Proton de cada juego. Un backend en Python con interfaz Game Mode en TypeScript y JavaScript, más un puente Lua hacia Cheat Engine, se encarga de buscar y descargar tablas desde fuentes comunitarias, la biblioteca local, la revisión de compatibilidad y activar trucos en sesión desde el Quick Access Menu. Se integra con bibliotecas de Steam y metadatos de lanzamiento para validar objetivos y adjuntarse al ejecutable de Windows correcto sin modificar la configuración de Steam. Funciones como carga automática, reparación de tablas para builds de juego distintos, instalaciones gestionadas comprobadas con Authenticode y controles estrictos del ciclo de vida de sesión están pensadas para jugadores e investigadores que quieren flujos estructurados de edición de memoria y tablas de trucos en hardware de juego Linux portátil.
