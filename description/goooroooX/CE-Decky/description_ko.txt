CE Decky는 Decky Loader 플러그인으로, 치트 테이블을 관리하고 각 게임의 Proton prefix 안에서 공식 또는 사용자가 가져온 Windows용 Cheat Engine을 실행해 Steam Deck과 SteamOS에서 Cheat Engine을 사용할 수 있게 합니다. Python 백엔드와 TypeScript·JavaScript Game Mode UI, Cheat Engine에 연결하는 Lua 브리지가 커뮤니티 소스에서 테이블 검색·다운로드, 로컬 라이브러리 관리, 호환성 검토, Quick Access Menu에서 세션 중 치트 전환을 처리합니다. Steam 라이브러리 및 실행 메타데이터와 연동해 대상을 검증하고 올바른 Windows 실행 파일에 연결하며 Steam 설정은 변경하지 않습니다. 자동 로드, 게임 빌드 불일치용 테이블 수리, Authenticode 검증 관리 설치, 엄격한 세션 수명 주기 제어 등은 휴대용 Linux 게임 하드웨어에서 구조화된 메모리 편집과 치트 테이블 워크플로를 원하는 플레이어와 연구자를 위한 기능입니다.
