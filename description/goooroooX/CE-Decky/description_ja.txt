CE Decky は Decky Loader 向けプラグインで、チートテーブルを管理し、各ゲームの Proton プレフィックス内で公式またはユーザーが取り込んだ Windows 版 Cheat Engine を起動することで、Steam Deck と SteamOS 上で Cheat Engine を使えるようにします。Python バックエンドと TypeScript・JavaScript の Game Mode UI、および Cheat Engine へ接続する Lua ブリッジが、コミュニティソースからのテーブル検索・ダウンロード、ローカルライブラリ管理、互換性レビュー、Quick Access Menu からのセッション中チート切り替えを担います。Steam ライブラリと起動メタデータと連携し、対象を検証して正しい Windows 実行ファイルにアタッチし、Steam 設定は変更しません。自動読み込み、ゲームビルド不一致向けテーブル修復、Authenticode 検証付き管理インストール、厳格なセッションライフサイクル制御などは、携帯 Linux ゲーミング機で構造化されたメモリ編集とチートテーブルワークフローを求めるプレイヤーと研究者向けです。
