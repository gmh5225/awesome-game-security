CE Decky 是一款 Decky Loader 外掛，透過管理作弊表並在各遊戲的 Proton 前綴內啟動官方或使用者匯入的 Windows 版 Cheat Engine，將 Cheat Engine 帶到 Steam Deck 與 SteamOS。Python 後端搭配 TypeScript 與 JavaScript 的 Game Mode 介面，以及連接 Cheat Engine 的 Lua 橋接，負責從社群來源搜尋與下載表、本機庫管理、相容性審查，以及在 Quick Access Menu 中於遊戲工作階段內切換作弊。它與 Steam 庫及啟動中繼資料整合，以驗證目標並附加至正確的 Windows 可執行檔，且不修改 Steam 設定。自動載入、針對不符遊戲版本的表修復、經 Authenticode 驗證的管理安裝，以及嚴格的工作階段生命週期控制等功能，面向希望在掌機 Linux 遊戲硬體上進行結構化記憶體編輯與作弊表工作流程的玩家與研究人員。
