CE Decky is a Decky Loader plugin that brings Cheat Engine to Steam Deck and SteamOS by managing cheat tables and launching official or user-imported Windows Cheat Engine inside each game’s Proton prefix. A Python backend with a TypeScript and JavaScript Game Mode UI, plus a Lua bridge into Cheat Engine, handles table search and download from community sources, local library management, compatibility review, and in-session cheat toggling from the Quick Access Menu. It integrates with Steam libraries and launch metadata to validate targets and attach to the correct Windows executable without modifying Steam configuration. Features such as auto-load, table repair for mismatched game builds, Authenticode-checked managed installs, and strict session lifecycle controls target players and researchers who want structured memory editing and cheat-table workflows on handheld Linux gaming hardware.
