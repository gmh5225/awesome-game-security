Eagle Eye 是一款只读的 Windows x64 反作弊扫描器，用于在本机搜寻作弊工具留下的痕迹，并生成带评分、有证据支撑的报告，且不读写游戏内存或访问网络。它主要用 C# 在 .NET 8 上实现为独立可执行文件，辅以 PowerShell 脚本负责打包与规则维护，并可选搭配 WDK C 驱动，在 DMA 检测时以只读方式访问 PCIe 配置空间。扫描范围涵盖进程、跨进程句柄、已加载驱动、注入痕迹、透明叠加窗口、与视觉或推理相关的模块、DMA 硬件、文件哈希与签名，以及可选的离线游戏遥测；全部由外部 JSON 规则驱动，支持模式校验与可调的风险聚合。该工具面向游戏安全运营、赛事管理员与调查人员，在可接触嫌疑 PC 时提供保守的本机分诊流程，并会明确标注本机无法观测到的内容，而非草率宣称机器干净。
