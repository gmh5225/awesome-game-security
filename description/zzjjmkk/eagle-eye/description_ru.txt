Eagle Eye — сканер античита только для чтения под Windows x64, который ищет локальные следы читерских инструментов и формирует оценённые отчёты с доказательной базой, не затрагивая память игры и сеть. Реализован в основном на C# под .NET 8 как автономный исполняемый файл, с вспомогательными скриптами PowerShell для упаковки и сопровождения правил и опциональным C-драйвером WDK для доступа только на чтение к конфигурационному пространству PCIe при проверках DMA. Сканирование охватывает процессы, межпроцессные дескрипторы, загруженные драйверы, артефакты инъекции, прозрачные оверлейные окна, модули, связанные со зрением или выводом, аппаратуру DMA, хеши и подписи файлов и опциональную офлайн-телеметрию игры; всё управляется внешними правилами JSON с проверкой схемы и настраиваемой агрегацией риска. Инструмент ориентирован на специалистов по безопасности игр, администраторов турниров и следователей, которым нужен консервативный локальный триаж при доступе к подозрительному ПК; он явно отмечает, что локально наблюдать нельзя, вместо того чтобы объявлять машину чистой.
