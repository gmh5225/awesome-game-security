Eagle Eye is a read-only Windows x64 anti-cheat scanner that hunts for local traces of cheating tools and produces scored, evidence-backed reports without touching game memory or the network. It is implemented primarily in C# on .NET 8 as a self-contained executable, with PowerShell helper scripts for packaging and rule maintenance and an optional WDK C driver for read-only PCIe configuration-space access during DMA checks. Scans cover processes, cross-process handles, loaded drivers, injection artifacts, transparent overlay windows, vision or inference-related modules, DMA hardware, file hashes and signatures, and optional offline game telemetry, all driven by external JSON rules with schema validation and tunable risk aggregation. The tool targets game security operators, tournament admins, and investigators who need a conservative on-machine triage workflow when a suspect PC is available, and it explicitly marks what cannot be observed locally instead of declaring a machine clean.
