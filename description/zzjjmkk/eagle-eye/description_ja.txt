Eagle Eye は、読み取り専用の Windows x64 向けアンチチートスキャナーで、ローカルに残るチートツールの痕跡を検出し、ゲームメモリやネットワークに触れずに、スコア付きで証拠に基づくレポートを生成します。実装は主に C# と .NET 8 の自己完結型実行ファイルで、パッケージングとルール保守用の PowerShell 補助スクリプト、および DMA 検査時に PCIe コンフィギュレーション空間へ読み取り専用アクセスする任意の WDK C ドライバーで構成されます。スキャン対象はプロセス、プロセス間ハンドル、読み込み済みドライバー、インジェクション痕跡、透明オーバーレイウィンドウ、ビジョン／推論関連モジュール、DMA ハードウェア、ファイルハッシュと署名、任意のオフラインゲームテレメトリなどで、外部 JSON ルールによるスキーマ検証と調整可能なリスク集約で駆動されます。ゲームセキュリティ担当、大会管理者、調査担当者向けに、疑わしい PC にアクセスできる場合の保守的なオンマシン・トリアージワークフローを提供し、ローカルで観測できない点を明示する一方で、マシンがクリーンであるとは断じません。
