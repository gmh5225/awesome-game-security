Eagle Eye 是一款唯讀的 Windows x64 反作弊掃描器，用於在本機搜尋作弊工具留下的痕跡，並產生具評分、有證據支撐的報告，且不讀寫遊戲記憶體或存取網路。它主要以 C# 在 .NET 8 上實作為獨立可執行檔，並以 PowerShell 輔助腳本負責封裝與規則維護，另可選用 WDK C 驅動程式，在 DMA 檢查時以唯讀方式存取 PCIe 設定空間。掃描涵蓋程序、跨程序控制代碼、已載入驅動程式、注入殘留、透明疊加視窗、與視覺或推論相關的模組、DMA 硬體、檔案雜湊與簽章，以及可選的離線遊戲遙測；全部由外部 JSON 規則驅動，支援結構描述驗證與可調整的風險彙整。本工具鎖定遊戲安全營運、賽事主辦管理員與調查人員，在可取得可疑 PC 時提供保守的本機分診流程，並會明確標示本機無法觀測到的項目，而非草率宣稱機器乾淨。
