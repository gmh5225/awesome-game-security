The BFBC2 Tool Suite is a unified toolkit for exploring, converting, and editing Battlefield: Bad Company 2 levels and assets against a local game install. It centers on a Python hub and shared core that drive map inspection and navigation studio views, automatic NavKit generation and parity checks for AI path data, DBX and FBRB bundle editors, Xbox 360 STFS and disc readers, shader and mesh pipelines, level diffing, crash analysis, and automated map and bot test harnesses, with performance-critical format work in Rust and selected C# GUI tools. The suite also covers console-to-PC asset conversion, menu APT tooling, stock multiplayer AI authoring, and cross-title import from Battlefield 1943 resources. It is aimed at BC2 modders, OPFOR-style bot and navigation workflows, and researchers who need deep, offline reverse engineering of EA and DICE proprietary formats without redistributing game data.
