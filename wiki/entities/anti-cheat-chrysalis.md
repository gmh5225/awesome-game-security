# AntiCheat-chrysalis

**AntiCheat-chrysalis** (gmh5225) is a **C++** reference anti-cheat implementation and **guide**-lane study project covering **kernel-level** protection work and **OpenGL**-related surfaces. It demonstrates common game-protection techniques: **process integrity verification**, **module scanning**, **memory pattern detection**, **debugger detection**, **overlay monitoring**, and **driver communication** for kernel-level checks. The codebase is aimed at anti-cheat engineers and defensive security researchers studying protection architecture—not a commercial AC product. (source: wiki/sources/descriptions/gmh5225__AntiCheat-chrysalis.md) (source: wiki/sources/descriptions/gmh5225__AntiCheat.md)
