# Torque 3D

Open-source Torque 3D game engine: a full-featured C++ codebase with CMake builds, Assimp model importing, and subsystems for rendering, physics, networking, and scripting. Supports multiple platforms with configurable build options and community-driven development. Aimed at game engine developers and researchers studying open-source 3D game engine architecture and design—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/TorqueGameEngines__Torque3D.md)
