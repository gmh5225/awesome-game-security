# Cocos2d-x

Multi-platform C++ framework for building 2D games, interactive books, demos, and other graphical applications. Descended from cocos2d-iphone but uses C++ instead of Objective-C. Aimed at game developers, engine programmers, and graphics researchers studying a cross-platform 2D engine source tree in the Game Engine / source lane. (source: wiki/sources/descriptions/cocos2d__cocos2d-x.md)

Sits in the OSS cross-platform 2D engine-source lane for development and mobile-title analysis, not a cheat or anti-cheat artifact.
