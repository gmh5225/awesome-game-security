# Apwil

Rust **Windows game-hacking library** for internal and external cheat development. Provides inline, IAT, VMT, VEH, and hardware-breakpoint hooks; memory read/write and manipulation; PE parsing and PEB walking; process and thread hijacking; pattern scan; DirectX overlay rendering; syscall, input, and window helpers; plus math utilities for cheat code. (source: wiki/sources/descriptions/april-ivy__Apwil.md)

Windows-only Rust scaffold beside cross-platform memory/hook libraries such as [[libmem]] — broader hook surface (VEH/HWBP) and a built-in DirectX overlay path for internal cheat workflows.
