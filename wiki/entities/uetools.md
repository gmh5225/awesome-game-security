# UETools

Set of .NET (C#) libraries for reading Unreal Engine 4 binary asset data. Components open PAK-based virtual file systems and parse asset structures and registries. Organized as reusable modules for tooling workflows—aimed at Unreal asset inspection, modding utilities, and technical research on game content formats. (source: wiki/sources/descriptions/UETools__UETools.md)

Sits in the README Game Assets / Unreal offline content lane beside programmatic UAsset libraries such as [[uassetapi]], GUI viewers such as [[uassetgui]], and pak explorers such as [[paksmith]] and [[rust-u4pak]]—rather than live-process SDK dumps.
