# rAthena

Open-source Ragnarok Online server emulator (C++): login, character, and map servers with large item/monster/skill/quest catalogs, guilds, WoE (War of Emperium), NPC scripting, MySQL storage, and multi-zone layout. Aimed at private-server operators and researchers studying classic MMO server patterns rather than client-side cheat tooling. (source: wiki/sources/descriptions/rathena__rathena.md)

Sits in the README `[MMORPG]` / Private Server lane as a study surface for authoritative multiplayer emulation and custom-content scripting.
