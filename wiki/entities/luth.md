# Luth

Custom **C++** game engine built on **Vulkan**, centered on a **render graph** with PBR materials, **cascaded shadow maps**, and **GTAO** ambient occlusion. Supports **skeletal animation** with GPU skinning, **ECS** scene management, a **fiber-based job system**, and an integrated editor. (source: wiki/sources/descriptions/Hekbas__Luth.md)

Sits in the Game Engine / source lane—an OSS C++ Vulkan engine for studying modern real-time rendering pipelines, ECS architecture, and parallel job scheduling, not a cheat or anti-cheat artifact.
