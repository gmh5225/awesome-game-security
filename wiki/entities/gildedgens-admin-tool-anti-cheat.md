# GildedGens Admin Tool Anti-Cheat

**GildedGens Admin Control System** with **GILDEDGENS GUARD** (regentdata8479) is a **Minecraft Bedrock Edition** **behavior pack** that merges Realm administration tooling with in-world anti-cheat via the official **Script API**. JavaScript drives staff dashboards through native UI forms, role-based permissions, full hotbar and armor inventory inspection, configurable item blacklists (wildcard IDs), and an inventory scanner with dry-run logging before live removal. **GILDEDGENS GUARD** adds heuristic movement, combat, and world-interaction checks—speed, fly, reach, KillAura, nuker detection—with violation levels, decay, lag-aware sampling, and escalating punishments from warnings through kicks. World dynamic properties persist audits, bans, and configuration across restarts. Targets Bedrock Realm and dedicated-world owners who want server-side moderation and cheat mitigation without external networking or packet-level hooks. (source: wiki/sources/descriptions/regentdata8479__GildedGens-Admin-Tool-Anti-Cheat.md)

## Admin tooling

Staff UI forms, RBAC, inventory inspection, blacklist enforcement, and scanner workflows with optional dry-run before item removal.

## GILDEDGENS GUARD

Movement, combat, and block-interaction heuristics with VL decay, lag-aware sampling, and staged sanctions; state stored in world dynamic properties.
