# IdaThemer

Utility that converts Visual Studio Code (VS Code) theme JSON into IDA Pro–compatible color themes. It builds on a modified [[long-night]] base (Celestial palette) and remaps VS Code color definitions into IDA syntax-highlighting and UI slots for a consistent dark-theme workflow. (source: wiki/sources/descriptions/gmh5225__IdaThemer.md)

Useful for game-security researchers and reverse engineers who already standardize on VS Code themes and want matching IDA appearance during long static-analysis sessions—not an analysis plugin or decompiler extension.
