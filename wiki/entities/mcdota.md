# mcdota

**McDota** is a Linux cheat and tinkering framework for Dota 2 (LWSS; C++) focused on runtime injection and in-game tooling. Features include dynamic Panorama UI integration, ESP-style visuals, camera controls, and protobuf packet interception and editing. The repository provides multiple loading modes—standard, stealthier, and integrated workflows—along with debugging scripts. Primarily intended for reverse engineers and game security hobbyists studying Source 2 client behavior on Linux. (source: wiki/sources/descriptions/LWSS__McDota.md)
