# UnityResolve.hpp

C++ Unity cheat framework centered on rendering, physics, and modding. Aimed at game-security researchers and reverse engineers studying offensive techniques in the cheat / game engine explorer:Unity lane. (source: wiki/sources/descriptions/issuimo__UnityResolve.hpp.md)

Complements IL2CPP resolver/dumper tooling such as [[il2cpp-resolver]] and [[il2cpp-runtime-dumper]], inject-based runtime inspectors such as [[unityexplorer]], and external introspection such as [[unity202x-externalresolve]] when the goal is a C++ modding scaffold rather than metadata dumps or live hierarchy REPL alone.
