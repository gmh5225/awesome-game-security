# a53-code-exec

PoC for **code execution on Cortex-A53** (`a53`) as used by PlayStation 5 on **firmware 02.00**. Written in C++/C with kernel-level work and **SDK generation** focus. Aimed at console emulator developers and PlayStation security researchers. (source: wiki/sources/descriptions/cragson__a53-code-exec.md)

Sits in the README `PlayStation` console lane alongside other PS5 low-level exploit and loader research—not a general-purpose cheat framework.
