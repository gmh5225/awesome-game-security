# SoftGLRender

Tiny C++ software renderer and rasterizer listed under the README **Renderer** category. Implements a CPU-side OpenGL-style pipeline (vertex processing, clipping, rasterization, texture sampling, SIMD-optimized paths) alongside companion OpenGL and Vulkan backends for side-by-side comparison—aimed at graphics programmers and rendering researchers studying software vs GPU rendering fundamentals. (source: wiki/sources/descriptions/keith2018__SoftGLRender.md)

Sits in the Renderer lane as an educational soft-3D study surface (deeper than 2D CPU raster helpers such as [[olive-c]], complementary to course-style pipelines like [[tinyrenderer]]), not a Present-hook or cheat overlay path.
