# Ursine3D

**Ursine3D** (AustinBrunkhorst/Ursine3D) is a general-purpose C++ game engine built for academic game development programs. The codebase provides an entity-component system, reflection support, editor tooling, animation systems, and a full 3D rendering pipeline. Integrations include Bullet Physics, Wwise audio, and Chromium Embedded Framework for HTML/CSS/JS-driven editor and game interfaces. Primary use cases are game engine education, prototyping, and full project development—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/AustinBrunkhorst__Ursine3D.md)
