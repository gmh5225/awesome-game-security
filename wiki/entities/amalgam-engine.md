# AmalgamEngine

**C++ engine** for building **isometric, sprite-based online virtual worlds** (Net5F). Provides client and server foundations, networking, chat, account systems, and live in-world editing tools. Built with **CMake**; emphasizes scalable multiplayer behavior while remaining deployable on relatively modest hardware. Targets game developers who want a ready technical base for persistent social worlds instead of starting from scratch. (source: wiki/sources/descriptions/Net5F__AmalgamEngine.md)

Sits in the Game Engine / source lane beside other open MMORPG and virtual-world stacks such as [[mir2]], [[mir3-zircon]], and [[maplestory-copy]].
