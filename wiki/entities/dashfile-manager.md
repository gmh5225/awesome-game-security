# dashfile-manager

Windows desktop **ADB** and rooted **Android device manager** built with **.NET** and **Avalonia**. Supports Magisk, KernelSU, and APatch module browsing, AVB tooling, and an extensible plugin system for PC-side pull/push and root-module workflows. Listed in the Cheat Android File Explorer lane. (source: wiki/sources/README-categories.md)

Complements simpler Windows ADB explorers such as [[adb-file-manager]] and on-device rooted file managers such as [[butler]] and [[file-explorer]].
