# dashfile-manager

**DashFile** ([Eternal-Dash/Dashfile_Manager](https://github.com/Eternal-Dash/Dashfile_Manager)) is a portable **Windows** desktop application for managing **Android** phones over **USB** without installing anything on the device. It uses built-in **ADB** and optional **root** access from a **.NET 8** / **Avalonia** host UI. (source: wiki/sources/descriptions/Eternal-Dash__Dashfile_Manager.md)

## Host capabilities

Combines a file explorer, **Magisk** / **KernelSU** / **APatch** module installer, bulk app management, and detailed device and root-implementation diagnostics in one interface. Listed in the Cheat **Android File Explorer** lane for PC-side pull/push, module control, and artifact inspection. (source: wiki/sources/descriptions/Eternal-Dash__Dashfile_Manager.md)

## Built-in parsers and plugins

Ships self-developed parsers and viewers for **AXML**, **resources.arsc**, **DEX**, **APK signatures**, compressed archives, and **AVB**, plus a hot-pluggable **`.dfp` plugin API** for extensions such as AVB resigning workflows. (source: wiki/sources/descriptions/Eternal-Dash__Dashfile_Manager.md)

## Research use

Suits Android modding, mobile reverse engineering, and game-security research where analysts need deep filesystem access, module control, and on-device artifact inspection from a PC. Complements simpler Windows ADB explorers such as [[adb-file-manager]] and on-device rooted file managers such as [[butler]] and [[file-explorer]]. (source: wiki/sources/descriptions/Eternal-Dash__Dashfile_Manager.md)
