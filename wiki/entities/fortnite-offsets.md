# fortnite-offsets

Fortnite **memory offset and UE4 SDK structure address collection** (gmh5225; cheat / game:fortnite `[Offset]`). Provides version-specific offset tables for player entities, camera data, bone arrays, weapon information, and engine globals used in external and internal cheat development—enabling tooling to locate game objects in memory without regenerating a full SDK each patch. Aimed at game security researchers tracking Fortnite memory-layout churn and studying UE4 offset-based cheat patterns. (source: wiki/sources/descriptions/gmh5225__fortnite-offsets.md)
