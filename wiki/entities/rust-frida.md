# rustFrida

Frida-like **Android ARM64** dynamic instrumentation in Rust/C/C++: QuickJS scripting, Java and native hooks, stealth hook paths, and **QBDI** integration for modding, hooking, and memory analysis. Designed to pair with **wxshadow** stealth breakpoint/hook via the companion [[mkpms]] KPM module (R^X page-split shadow pages; bypass self-read integrity check). (source: wiki/sources/descriptions/kkkbbb__rustFrida.md) (source: wiki/sources/descriptions/kkkbbb__mkpms.md)

Useful for game-security researchers and reverse engineers studying offensive instrumentation in the cheat / Frida lane on rooted ARM64 Android targets.
