# apic

Windows kernel research library/driver for **local APIC** (Advanced Programmable Interrupt Controller) work: read/write APIC registers, send processor interrupts via **xAPIC** and **x2APIC**, and explore APIC-based timing and detection techniques. Aimed at kernel researchers studying interrupt-controller internals for security monitoring or evasion—not a production anti-cheat component. (source: wiki/sources/descriptions/noahware__apic.md)
