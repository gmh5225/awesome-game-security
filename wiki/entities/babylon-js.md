# Babylon.js

Real-time 3D rendering engine for interactive graphics, games, and visualizations in the browser. TypeScript monorepo with core modules for scenes, animations, materials, physics, and post-processing, plus WebGL and WebGPU backends and shader assets. Add-ons include atmosphere rendering, navigation-mesh pathfinding, HTML mesh integration, and advanced render pipelines (SSAO, SSR, temporal anti-aliasing). Aimed at web and game developers needing a full-featured client-side 3D engine for games, simulations, and immersive experiences. (source: wiki/sources/descriptions/BabylonJS__Babylon.js.md)

Sits in the Game Engine / HTML5 WebGL·WebGPU source lane—an OSS browser runtime for development and graphics study, rather than a cheat or anti-cheat artifact. Adjacent to [[three-js]], [[engine]] (PlayCanvas), and [[pixijs]]; also referenced by AI agent stacks such as [[godogen]].
