# ADBI

**Android Dynamic Binary Instrumentation** — crmulliner’s Android native instrumentation toolkit in the Cheat / dynamic binary instrumentation lane. Uses **library injection** and **inline hooking** at function entry points to intercept native code in running processes. Targets game security researchers and reverse engineers studying offensive hook/inject techniques on Android. (source: wiki/sources/descriptions/crmulliner__adbi.md)

Historical predecessor to modern Frida-, ptrace-, and Zygote-based Android inject stacks; complements [[frida]], [[dobby]], [[qbdi-tracer-android]], and [[android-super-inject]].
