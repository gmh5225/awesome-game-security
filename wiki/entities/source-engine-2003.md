# source-engine-2003

**source-engine.2003** (UTINKA) — large archival snapshot of an early Source engine codebase with Half-Life 2 era game modules and tools. Contains extensive engine, client, server, rendering, and utility code in C and C++ with legacy Visual Studio project files. Subsystems include material and graphics components, game DLL logic, and build scripts for historical Windows toolchains. Mainly useful as a reference corpus for engine internals study, reverse engineering, and legacy game security research. (source: wiki/sources/descriptions/UTINKA__source-engine.2003.md)

Complements later Source 1 trees such as [[source-engine-2007]], open TF2-era mirrors such as [[source-engine]], official modding SDKs such as [[source-sdk-2013]], AlliedModders references such as [[hl2sdk]], and Orange Box SDK mirrors such as [[source-sdk-orangebox]] for cross-era Source 1 architecture study.
