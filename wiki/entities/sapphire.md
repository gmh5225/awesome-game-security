# Sapphire

**FINAL FANTASY XIV** private-server emulator (in development). The tracked branch targets **FFXIV patch 3.3** (Heavensward-era client/server protocol). Framed for game security researchers and reverse engineers studying authoritative MMO server emulation, client–server protocol RE, and custom-content/offensive research surfaces—not a live-service cheat client. (source: wiki/sources/descriptions/gmh5225__sapphire.md)
