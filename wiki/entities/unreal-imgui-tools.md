# UnrealImGuiTools

Tools and utilities for Unreal Engine projects using ImGui, plus a small framework for writing game-specific tool windows more quickly. Aimed at game developers, engine programmers, and graphics researchers in the Game Engine / Plugins:Unreal lane—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/nakdeyes__UnrealImGuiTools.md)

Complements basic UE ImGui wiring such as [[ue5-with-dear-imgui]] (UE 5.0.1 sample) by packaging reusable ImGui tooling utilities; remote remoting [[netimgui]] is the off-box side of that same engine/plugin ImGui surface. Adjacent Present-hook overlay research ([[present-hook]], [[directxhook]]) is the in-process graphics-API lane.
