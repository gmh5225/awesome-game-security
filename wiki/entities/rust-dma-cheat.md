# RustDMACheat

**RustDMACheat** (IntelSDM/RustDMACheat) is a **DMA-oriented cheat framework** for Facepunch **Rust** written mainly in **C++**. It provides **ESP** and gameplay modification features including recoil adjustments, FOV changes, lighting tweaks, and admin-related views through a configurable codebase. The project references common DMA ecosystem tooling such as [[pcileech]], MemProcFS, [[il2cppdumper]], and [[dmalibrary]]. Intended for hardware-assisted memory access research and external game cheating workflows without running cheat logic on the target gaming OS. (source: wiki/sources/descriptions/IntelSDM__RustDMACheat.md)

Sits in the below-OS Facepunch Rust lane beside kernel-assisted externals such as [[lord-abbot-rust-external-cheat]] and [[overflow-rust]], and offset-maintenance pipelines such as [[oxide-dumper]].
