# Counter-Strike DS Unity Project

**Unity tooling workspace** for the Fewnity **Nintendo DS Counter-Strike demake**. Exports map and gameplay data—**collisions**, **stairs**, **culling zones**, **shadow zones**, **bomb zones**, and **trigger data**—plus **pathfinding waypoints and matrices**, and a scene-based pipeline for **gun sprites**. Primary use case is helping developers maintain and iterate **DS-compatible content and logic** outside the core game codebase. (source: wiki/sources/descriptions/Fewnity__Counter-Strike-DS-Unity-Project.md)

Companion authoring tooling for the native DS homebrew game [[counter-strike-nintendo-ds]]; sits in the README `Unity CS` cheat lane as a Unity-side content pipeline beside the C/devkitPro runtime.
