# ms079

MapleStory v079 (pre-Big Bang classic) private-server codebase maintained for study: Java server logic, MySQL schema, scripts, and packaging. Documents JDK 8 + MySQL setup, Maven/IDEA builds, and a distribution zip bundling WZ data and scripts for running a local server. (source: wiki/sources/descriptions/mrzhqiang__ms079.md)

Useful for game developers and reverse engineers researching classic MapleStory authoritative server internals, packet/script pipelines, and v079-era CMS-079 private-server operation—not client-side cheat tooling.
