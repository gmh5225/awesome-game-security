# gta-reversed-modern

Collaborative **gta-reversed** effort to reverse engineer and reimplement Grand Theft Auto: San Andreas 1.0 US in modern C++. Decompiled and rewritten functions compile alongside the original binary, progressively replacing game code while preserving compatibility. Coverage spans rendering, physics, vehicle handling, player control, mission scripting, and audio — aimed at reverse engineers, modders, and researchers studying AAA engine architecture through systematic decompilation. (source: wiki/sources/descriptions/gta-reversed__gta-reversed-modern.md)

Distinct from multiplayer mod stacks such as [[mtasa-blue]] (hooks + Lua/CEF client) and graphics remasters such as [[gta4-rtx]]; this is a **binary-compatible source reimplementation** lane for studying RenderWare-era GTA:SA internals.
