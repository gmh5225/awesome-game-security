# List of IDA Plugins

Curated **index of IDA Pro plugins** from gmh5225—not a single installable plugin. Entries include extra metadata: implementation language, last-updated dates, and category grouping for discovery. Aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane studying offensive static RE workflows. (source: wiki/sources/descriptions/gmh5225__ida-plugins.md)

Distinct from [[ida-plugins]] (repnz register cross-references plugin). Complements [[idaplugins-list]] (version-aware community catalog), curated bundles such as [[idaplugins]], and script collections such as [[idawilli]].
