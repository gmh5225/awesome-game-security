# EQU8-PoC

C++ research repo that **fully reimplements the EQU8 kernel driver** described in a companion article — useful for studying proprietary anti-cheat driver architecture (IOCTL surfaces, kernel callbacks, usermode↔driver communication) without relying on live game binaries. Targets game-security researchers and reverse engineers in the **explore anticheat:equ8** / driver-development lane. (source: wiki/sources/descriptions/kkent030315__EQU8-PoC.md)
