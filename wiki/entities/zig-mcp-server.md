# zig-mcp-server

High-performance, memory-efficient implementation of the Model Context Protocol (MCP) specification in Zig. Fits the Game Develop → MCP server lane; useful for game developers, reverse engineers, and tooling builders who need a lightweight MCP host rather than editor-specific bridges or live RE tooling. (source: wiki/sources/descriptions/gmh5225__zig-mcp-server.md)

Complements domain-specific MCP servers such as [[unity-mcp]] (Unity editor), [[deepwiki-mcp]] (docs/wiki retrieval), and [[interactive-feedback-mcp]] (HITL prompts) by providing a generic protocol foundation in Zig.
