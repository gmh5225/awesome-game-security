# Crosshair Z

Lightweight **Windows Electron** desktop app that draws a customizable **crosshair** in a transparent, always-on-top overlay for borderless or windowed games. Uses JavaScript with **koffi** native bindings where low-level mouse input is needed; ships as a portable offline executable. Features include a pixel-grid designer (lines, outlines, center dots, circles, image layers), firing spread animation, per-crosshair hotkeys, share codes, and import of locally saved Crosshair X profiles. Deliberately avoids **DLL injection** and in-game hooks—only a plain top-level click-through window—so it targets compatibility with typical anti-cheat expectations as a no-hook external visual aid. (source: wiki/sources/descriptions/Nn1ff__crosshair-z.md)
