# libmem

Cross-platform game-hacking library for process memory introspection and runtime manipulation on Windows, Linux, and FreeBSD. Core C/C++ API with Rust, Python, and Lua bindings; supports internal and external workflows. Covers process/module/symbol/thread/segment enum, R/W/alloc/protect, pattern/signature scan, pointer-map resolve, function/VMT hooks, Capstone/Keystone JIT assemble/disassemble, and module load/unload helpers. (source: wiki/sources/descriptions/rdbo__libmem.md)
