# long_night

IDA Pro color theme with a dark background and syntax-highlighted foreground colors for extended reverse-engineering sessions. Aimed at IDA users who prefer dark UI schemes in the cheat / IDA themes lane. (source: wiki/sources/descriptions/gmh5225__long_night.md)

Visual comfort tooling—not an analysis plugin or decompiler extension.
