# mqtt

Comprehensive Chinese translation of the MQTT v3.1.1 OASIS specification, covering all 14 control packet types (CONNECT through DISCONNECT), QoS levels, topic filtering, session state management, security considerations, and WebSocket transport bindings. (source: wiki/sources/descriptions/mcxiaoke__mqtt.md)

Sits under README `Game Network` / `[mqtt]` as a protocol reference for broker-based pub/sub stacks—complementing client libraries such as [[mqtt-js]] and [[paho-mqtt-cpp]] when auditing telemetry channels, session semantics, or transport security rather than as cheat tooling.
