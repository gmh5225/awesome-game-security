# Mir2

Full open-source **client and server implementation for The Legend of Mir 2** (Suprcode). Built mainly in **C#**, the monorepo ships the game client, server, launcher, administrative tools, and supporting data utilities under one modular managed architecture emphasizing performance, custom content, and community extensions. (source: wiki/sources/descriptions/Suprcode__mir2.md)

Targets Mir private-server developers and preservation-focused communities maintaining classic MMORPG infrastructure—not a cheat scaffold, but a buildable Mir 2 client/server reference for protocol, server logic, and managed game-stack study.
