# PasVulkan

Object Pascal Vulkan header generator, OOP API wrapper, and Vulkan-based engine framework for Free Pascal and modern Delphi. Auto-generates C-style `Vulkan.pas` bindings via **vkxml2pas**, plus OOP framework units for memory management, native texture and font loaders, sprite atlases, and related Vulkan utilities. An SDL 2 application layer handles swap-chain setup, surface recovery, and cross-platform windowing on Windows, Linux, and Android, with optional MoltenVK paths for Apple platforms. Primary use is building Vulkan-based games and graphics applications in Object Pascal without relying on VCL, LCL, or external image libraries. (source: wiki/sources/descriptions/BeRo1985__pasvulkan.md)
