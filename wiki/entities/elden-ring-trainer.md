# Elden Ring Trainer

**ERTrainer** (Magicdaclip52/elden-ring-trainer) is an open-source **Windows external overlay trainer** for **Elden Ring 1.17.2** aimed at **single-player or offline** use. The tool attaches to the game process externally and exposes gameplay tweaks through a **Dear ImGui** + **DirectX 11** control panel without injecting a DLL. (source: wiki/sources/descriptions/Magicdaclip52__elden-ring-trainer.md)

## Memory editing model

Live edits combine **signature scanning**, **pointer chains**, **byte patches**, **code caves**, and **in-process hooks** from the external process—useful as a reference for patch-oriented RE and FromSoftware memory layout work on modern Unreal titles.

## Feature surface

Options span **survival**, **combat**, **items**, **world**, and **character stats**, including infinite resources, damage modifiers, drop-rate control, flight, rune editing, and game speed.

## Build

**C++20** and **CMake** on Windows.
