# Elden Ring Trainer

Open-source **Windows external trainer** for **Elden Ring 1.17.2** (single-player/offline use) built with **C++20**, **CMake**, **Dear ImGui**, and **DirectX 11**. Attaches to the game process without DLL injection and applies live edits via signature scans, pointer chains, byte patches, code caves, and in-process hooks. Features cover runes, stats, stamina, flight, drop rates, combat modifiers, and game speed—useful as a reference for external trainers, FromSoftware memory layout work, and patch-oriented RE on modern UE titles. (source: wiki/sources/descriptions/Magicdaclip52__elden-ring-trainer.md)
