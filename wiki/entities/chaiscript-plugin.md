# ChaiScript Plugin

[[x64dbg]] plugin that embeds [ChaiScript](https://github.com/ChaiScript/ChaiScript) for scripted debugger automation. Exposes a thorough plugin API and registers three debugger commands; the API surface favors completeness over rapid prototyping. Useful for game-security researchers and reverse engineers studying offensive techniques in the Cheat / x64dbg Plugins lane. (source: wiki/sources/descriptions/jdavidberger__chaiScriptPlugin.md)

Not a standalone debugger—extends [[x64dbg]] with scriptable command hooks.
