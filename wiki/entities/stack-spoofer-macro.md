# StackSpoofer_Macro

**StackSpoofer_Macro** is an easy-to-use, powerful **C/C++ macro** for Windows **stack spoofing** — preprocessor macros that wrap sensitive calls so thread stack walks see plausible return addresses instead of cheat or manually mapped code. Aimed at game-security researchers and reverse engineers studying offensive cheat / spoof-stack tradecraft. (source: wiki/sources/descriptions/gmh5225__StackSpoofer_Macro.md)
