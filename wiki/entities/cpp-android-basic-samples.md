# cpp-android-basic-samples

Sample games using the Google Play Games C++ SDK. Optional Windows tip: map the samples folder to a shortened path on some versions. Aimed at game developers, reverse engineers, and tooling builders in the Game Develop / source lane—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/playgameservices__cpp-android-basic-samples.md)

Sits beside other approachable C/C++ gamedev sources ([[raylib]], [[2048-cpp]], [[mojoc]]) and Android-oriented engine trees ([[skylicht-engine]]) as official Play Games C++ integration reference samples.
