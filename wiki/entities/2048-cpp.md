# 2048.cpp

Terminal-based 2048 puzzle game in C++. Renders a colored console board, handles keyboard tile slides, implements merge/scoring logic, and tracks high scores. Clean, minimal sample aimed at C++ learners and hobbyist developers studying simple console game logic. (source: wiki/sources/descriptions/plibither8__2048.cpp.md)

Sits in the Game Develop / source lane as a console-title teaching sample—not a cheat or anti-cheat artifact. Adjacent to other approachable C/C++ gamedev sources ([[raylib]], [[exengine]]) and Game Develop remakes ([[zelda3]], [[osu]]).
