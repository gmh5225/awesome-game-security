# Lore

**Lore** (EpicGames/lore) is Epic Games' open-source **Rust-based version control system** for large-scale game development. It uses **content-defined chunking** and **content-addressed chunk storage** so large binary assets deduplicate efficiently; **sparse workspaces** keep checkout sizes manageable; and **tamper-evident history** supports integrity-sensitive pipelines. Cloud-native storage backends target studio-scale asset workflows. Used in Epic's ecosystem including **UEFN** (Unreal Editor for Fortnite). (source: wiki/sources/descriptions/EpicGames__lore.md)

Not a cheat or anti-cheat artifact—devops infrastructure for game source and asset versioning in the README **Game CI** lane, beside Unity build automation samples such as [[unity-gameci-sample]].
