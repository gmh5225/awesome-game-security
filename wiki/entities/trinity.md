# Trinity

Windows kernel exploitation framework in C/C++ that chains multiple primitives—driver vulnerabilities, memory corruption, and privilege escalation—into a modular pipeline for arbitrary kernel code execution. Demonstrates building reliable exploitation chains from individual vulnerability primitives; aimed at kernel exploit developers and security researchers studying Windows kernel exploitation methodology. README positions it as fully disabling and removing Windows Defender. (source: wiki/sources/descriptions/cpz__trinity.md)
