# ReClass.NET

**ReClass.NET** (ReClassNET/ReClass.NET) is a **.NET-based memory class reconstruction and remote process inspection** tool. It combines a **C# UI** with **native C++ core** components for low-level process and memory operations. Supports **x86 and x64** targets, rich memory node types, scanners, debuggers, and **import/export compatibility with older ReClass formats**. Widely used in reverse engineering and game security research to map runtime structures and generate **C++ or C# class layouts**. (source: wiki/sources/descriptions/ReClassNET__ReClass.NET.md)

Plugin ecosystem includes kernel-driver readers such as [[reclass-net-driverreader]], DMA-backed recon via [[reclass-dma]], and standalone extended tools like [[reclass-ex]]. Complements interactive struct tools such as [[regenny]].
