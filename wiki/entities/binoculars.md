# Binoculars

IDA Pro plugin that embeds an AI assistant directly inside the reverse engineering interface. Python-based with configurable model backends, command prompts, and UI actions for interactive analysis. Built-in capabilities include function explanation, symbol renaming, and Go binary parsing helpers such as pclntab reconstruction workflows. Aimed at speeding up repetitive reverse engineering tasks for security researchers. (source: wiki/sources/descriptions/Vis-Wing__Binoculars.md)

Complements other in-IDA LLM assistants such as [[wpechatgpt]], [[idassist]], [[ida-gepetto]], and [[ida-llm-explainer]], and Go symbol-recovery tooling such as [[goresym]] and [[golang-loader-assist]]—verify model output against disassembly/decompilation per [[research-rigor]].
