# Darken Anti-Cheat

Darken is a C/C++ proof-of-concept anti-cheat that demonstrates common game-protection techniques: kernel-mode driver communication, process integrity checking, module verification, memory scanning for known signatures, debugger detection, and overlay monitoring. Aimed at researchers studying AC architecture and building custom protection systems. (source: wiki/sources/descriptions/noahware__darken-anticheat.md)

README: kernel anti-cheat for protecting software. Complements educational PoCs such as [[anticheat-poc]] and layered OSS skeletons such as [[sentinelac]].
