# unity-vrchat-template

Unity VRChat starter template from gmh5225. Centers on graphics, audio systems, and physics for VRChat world and avatar authoring. Fits the Game Develop / source lane; useful for game developers, reverse engineers, and tooling builders studying Unity social-VR integration rather than shipped-client IL2CPP/Mono RE alone. (source: wiki/sources/descriptions/gmh5225__unity-vrchat-template.md)

Complements Unity VR graphics samples such as [[the-seed-link-future]], editor automation such as [[unity-mcp]] / [[unicli]], and Unity modding guides such as [[unity-game-hacking]] when the goal is VRChat SDK scaffolding rather than runtime explorers.
