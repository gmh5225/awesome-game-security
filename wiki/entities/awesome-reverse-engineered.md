# awesome-reverse-engineered

Curated awesome-style index of open-source projects built through reverse engineering. README scope cites roughly 16,800+ entries overall, including on the order of 6,000+ game-related decompilations, static recompilations, engine reimplementations, and private-server stacks. Discovery aid for locating reference implementations and community RE ports—not proof that any listed project is complete, authorized, or safe to run. (source: wiki/sources/README-categories.md)

Complements title-specific analysis indexes such as [[awesome-game-analysis]] and format-focused catalogs such as [[awesome-game-file-format-reversing]] with a broad RE-derived OSS map.
