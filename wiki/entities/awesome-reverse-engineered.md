# awesome-reverse-engineered

**Awesome Reverse-Engineered** (alexgaoth) is a large, machine-maintained catalog of open-source projects that exist because someone reverse engineered a closed application, API, device, wire protocol, file format, game, or AI product. The README cites on the order of **16,800+** entries overall, including **6,000+** game decompilations, static recompilations, engine reimplementations, and private-server stacks. Themed categories also cover reverse-engineering tooling, unofficial API clients, IoT/firmware work, and discontinued products kept alive by community reimplementations. (source: wiki/sources/descriptions/alexgaoth__awesome-reverse-engineered.md) (source: wiki/sources/README-categories.md)

The repository ships structured **JSON** data, **Python** automation for nightly refresh and site generation, a searchable **GitHub Pages** index, and integrations including an **MCP server** and agent skills so tools can search and rank projects by activity and license. Audience: reverse engineers, security researchers, and developers seeking interoperability or prior art before duplicating RE effort—including game modding, emulation, and anti-cheat–adjacent tooling discovery. Listing is not proof that any project is complete, authorized, or safe to run. (source: wiki/sources/descriptions/alexgaoth__awesome-reverse-engineered.md)

Complements title-specific analysis indexes such as [[awesome-game-analysis]] and format-focused catalogs such as [[awesome-game-file-format-reversing]] with a broad RE-derived OSS map.
