# RisohEditor

Free Windows GUI resource editor for PE executables and DLLs: view, edit, add, and remove embedded resources including dialogs, menus, icons, bitmaps, string tables, version info, and manifest files. C++ application with resource script (RC) import/export; supports both 32-bit and 64-bit PE files. Aimed at Windows developers, reverse engineers, and translators who need to modify compiled binary resources without rebuilding from source. (source: wiki/sources/descriptions/katahiromz__RisohEditor.md)

Complements PE structure viewers such as [[totalpe2]]—useful for localization, UI string patches, manifest tweaks, and resource-level triage before deeper IDA/Ghidra work.
