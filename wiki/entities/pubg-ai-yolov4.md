# pubg-ai-yolov4

YOLOv4-based **PUBG object detection** (dqforgive-sudo) trained on game screenshots via **Darknet** for real-time player and object recognition from screen captures or video feeds. Ships pre-trained weights, custom PUBG training configs for YOLOv4-tiny and YOLOv7, label tools, and image/video detection scripts with Python bindings. Listed for game security researchers studying AI-based aimbot and visual detection techniques in competitive FPS titles. (source: wiki/sources/descriptions/dqforgive-sudo__pubg-ai-yolov4.md)

Sits in the external screen-capture → YOLO → coordinate-transform pipeline beside [[yolov5-pubg]] and generic FPS CV samples such as [[ai-fps-b00m-h3adsh0t]] and [[opencv-smart-aimbot]]; defensive ML counterparts include [[waldo]] and [[aimbot-detection-prototype]] via [[ai-aimbot-detection]].
