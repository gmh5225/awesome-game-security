# YimMenu

Documentation-focused repository for **Lua scripting interfaces** and support features in the GTA mod-menu ecosystem. The original menu source was removed; remaining content centers on **Lua API references**, **command documentation**, and utility guides—including practical setup for services such as **LibreTranslate** used by the chat-translation feature. Most useful for **script developers** and users maintaining Lua-based extensions rather than core menu binary development. (source: wiki/sources/descriptions/YimMenu__YimMenu.md)

Distinct from full mod-menu implementations such as [[phake]], [[bigbasev2]], and [[grandtheftautov-cheat]], and from leaked online-menu source such as [[spookimystic-gta-leak]]—this repo is the **scripting/API documentation lane** for the YimMenu ecosystem.
