# 3d-asset-factory

CLI-first YAML→3D asset pipeline: text spec → GPT Image 2.0 concept art → TRELLIS.2 mesh reconstruction → GLB export, with QA gate, review HTML, and web/Unity/Unreal export packages. Supports mock and remote GPU runners (Modal, Replicate, RunPod) and ships GLB/USDZ/STL outputs. (source: wiki/sources/descriptions/PSkinnerTech__3d-asset-factory.md)

Sits in the README **AI** category YAML→GLB lane—spec-driven 3D asset generation for game AI and tooling developers, complementary to local desktop mesh tools such as [[modly]], cloud 2D sprite pipelines such as [[sprite-sheet-creator]], and Claude skillsets such as [[image-blaster]].
