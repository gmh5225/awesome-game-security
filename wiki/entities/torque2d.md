# Torque 2D

Open-source cross-platform 2D game engine: a primarily C++ codebase with rendering, Box2D physics, audio, animation, and modular project tooling. Targets Windows, macOS, Linux, iOS, Android, and web-related workflows, with sample modules for learning and rapid iteration. Main use case is building and customizing full 2D games with source-level control—aimed at engine developers and researchers studying open-source 2D engine architecture, not a cheat or anti-cheat artifact.
