# unity-skills

Unity Editor plugin shipping AI-driven automation skills across a wide range of engine subsystems. C# editor scripts cover animator, audio, camera, Cinemachine, materials, NavMesh, optimization, physics, rendering, shaders, terrain, UI, and related components, plus a batch executor and localization support. Targets Unity developers and technical artists automating editor workflows and AI-assisted scene manipulation rather than runtime IL2CPP/Mono game hacking. (source: wiki/sources/descriptions/Besty0728__Unity-Skills.md)

Sits in the README **Game Develop → AI Agents** lane beside cross-engine skill packs such as [[awesome-gamedev-agent-skills]] and MCP editor bridges such as [[unity-mcp]]; differs by embedding Unity-specific editor automation skills inside the project rather than exposing a protocol server or multi-engine router.
