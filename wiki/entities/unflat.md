# unflat

Python **unflattener** project centered on **plugin development** for recovering control flow from flattened binaries. Targets the cheat / Fix OLLVM lane for game-security researchers and reverse engineers studying OLLVM-style obfuscation and deflat workflows. (source: wiki/sources/descriptions/guheng-re__unflat.md)

Not a full decompiler—scoped to unflattening helpers and extensible plugin hooks.
