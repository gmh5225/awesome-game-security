# Mono.Debugger.Soft

dnSpy-maintained fork of the Mono Soft Debugger client library. Implements the wire protocol and mirror API for talking to Mono's soft debugger agent—breakpoints, stepping, and managed object inspection over the soft-debugger channel. Enhanced for Unity and Mono runtime debugging; used by [[dnspy]] together with soft-debugger-enabled runtimes from [[dnspy-unity-mono]]. Mainly for reverse engineers and game modders debugging Unity and Mono-based games at the managed-code level. Listed in the README under **[Mono Debugger]**.
