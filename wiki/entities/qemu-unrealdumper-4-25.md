# QemuUnrealDumper-4.25

C++ **QEMU and memflow port** of [[unrealdumper-4-25]] for **Unreal Engine 4.25** runtime metadata extraction. Scans target processes to locate object arrays, name pools, and engine-specific offsets; dumps names and objects with per-game offset configuration in engine code. Primarily used in Unreal reverse engineering and game security research when guest memory is accessed through virtualization rather than conventional external process handles.
