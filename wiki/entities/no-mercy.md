# NoMercy

MIT-licensed open-source anti-cheat positioned in curated lists as the **"gold standard"** reference among open-source anti-cheat systems — aimed at anti-cheat engineers and defensive security researchers studying full-stack client protection rather than at cheat development. (source: wiki/sources/descriptions/mq1n__NoMercy.md)

Listed under **Anti Cheat → Open Source Anti Cheat System** alongside other OSS AC stacks such as [[sentinelac]], [[certael]], and [[magnetite]]. The README also references the related [NoMercy-ac](https://github.com/NoMercy-ac) organization repo in the same subsection; **mq1n/NoMercy** is the fork tracked here.
