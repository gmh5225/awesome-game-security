# coruna

Leaked iOS exploit toolkit: **WebKit** exploit chains for multiple iOS versions, partially deobfuscated, with scripts modified for **local hosting**. (source: wiki/sources/descriptions/khanhduytran0__coruna.md)

Useful for game-security researchers and reverse engineers studying offensive iOS jailbreak / cheat-adjacent techniques: browser-based WebKit chaining, version-specific payloads, and self-hosted exploit delivery—not a maintained production jailbreak product.
