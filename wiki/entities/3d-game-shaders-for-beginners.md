# 3D Game Shaders For Beginners

Step-by-step tutorial on implementing 3D game rendering techniques and shader effects. Covers SSAO, bloom, normal mapping, shadow mapping, fog, depth of field, motion blur, screen-space reflection, cel shading, outlining, and other post-processing with GLSL shader code and explanatory text. Panda3D-based examples provide working implementations of each technique—aimed at beginning graphics programmers and game developers learning real-time shader programming and rendering-pipeline concepts. (source: wiki/sources/descriptions/lettier__3d-game-shaders-for-beginners.md)

Sits in the README **Shader** / Renderer lane as an educational GLSL post-processing course—not a GPU Present hook, cheat overlay, or runtime shader injector.
