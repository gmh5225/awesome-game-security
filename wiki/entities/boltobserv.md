# boltobserv

**CS:GO radar** cheat from boltgolt that focuses on map visualization: each player appears as a dot with the **player slot number** rendered as clearly as possible on top. Listed under the README **[Radar]** category for the cheat / game:csgo lane. Useful for game security researchers and reverse engineers studying offensive radar techniques and how entity positions are surfaced outside the in-game minimap. (source: wiki/sources/descriptions/boltgolt__boltobserv.md)

Complements other CS:GO visual cheats such as [[csgo-external-cheat]] (external ESP / aimbot / radar) and DMA radar samples such as [[csgo-dma-overlay]] by illustrating a dedicated radar UI that emphasizes slot identification on a 2D map view.
