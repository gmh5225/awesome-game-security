# idawilli

Collection of IDA Pro scripts, plugins, and utilities by Willi Ballenthin. Python IDAPython tooling covers common reverse-engineering workflows: function analysis, string decryption, struct annotation, cross-reference navigation, and in-IDA automation. Scripts span malware, firmware, and general static-analysis scenarios—aimed at IDA users who want ready-made analysis helpers rather than building every workflow from scratch. (source: wiki/sources/descriptions/gmh5225__idawilli.md)

Complements curated plugin packs such as [[idaplugins]] and IDAPython convenience layers such as [[sark]], plus focused single-purpose plugins like [[tenet]] (execution traces) and [[ida-pro-loadmap]] (linker `.MAP` symbol import).
