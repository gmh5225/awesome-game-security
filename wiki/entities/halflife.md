# halflife

**Half-Life 1 engine and SDK** (ValveSoftware) — official GoldSrc-era engine and SDK source used to build and modify classic GoldSrc-based games. Ships primarily C and C++ client, server, shared engine interfaces, and platform-specific build assets, with modern Windows and Linux build workflows while preserving the original modding-oriented architecture. Intended for mod developers and engine researchers who need direct access to gameplay code and legacy engine internals. (source: wiki/sources/descriptions/ValveSoftware__halflife.md)

Complements consolidated community SDKs such as [[halflife-unified-sdk]], community reimplementations such as [[regamedll-cs]], [[regs]], and [[goldsource-rebuild]], preservation clients such as [[cs16-client]], mod collections such as [[hl-mods]], GoldSrc/WON-era anti-cheat research such as [[valveanticheat1]], and the later Source 1 SDK lineage via [[source-sdk-2013]] and [[hl2sdk]].
