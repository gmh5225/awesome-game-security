# tuxgate

**tuxgate** (LoanPleurmeauBonnin) is a **Rust command-line companion** for running **Riot Games titles on Linux**. It inspects the host and explains **documented compatibility** without installing, emulating, or bypassing anti-cheat. (source: wiki/sources/descriptions/LoanPleurmeauBonnin__tuxgate.md)

## Diagnostics

Runs **read-only** system probes for boot and platform security signals—**Secure Boot**, **TPM 2.0**, **IOMMU**, **EFI variables**—and maps findings against **attested-boot expectations** described for **Easy Anti-Cheat on Linux**. (source: wiki/sources/descriptions/LoanPleurmeauBonnin__tuxgate.md)

## Features

Ships a **sourced compatibility database** for multiple Riot titles, commands to **record local test history** and detect regressions, and optional help coordinating a **controlled reboot into Windows** when a title requires it. (source: wiki/sources/descriptions/LoanPleurmeauBonnin__tuxgate.md)

## Audience

Aimed at Linux gamers, distro maintainers, and security-minded users who want honest diagnostics around **[[vanguard]]** and related anti-cheat requirements—not circumvention tooling. (source: wiki/sources/descriptions/LoanPleurmeauBonnin__tuxgate.md)

## Positioning

Complements generic EAC Linux v2 auditors such as [[eac-compliance]] and community compatibility trackers such as [[are-we-anti-cheat-yet]] with **Riot-title-specific** attestation mapping and regression history.
