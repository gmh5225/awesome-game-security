# awesome-game-analysis

Curated awesome-style index of game technology analysis resources. Mostly Markdown, organizing links by game title, engine, developer, year, and technical topic. Community-driven with contribution guidance for consistent updates. Useful for game programmers, rendering engineers, and reverse engineers seeking references on engine internals and production techniques—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/OTFCG__Awesome-Game-Analysis.md)

Complements engine-dev and asset-format indexes such as [[awesome-game-engine-dev]] and [[awesome-game-file-format-reversing]] with postmortems, talks, and deep-dive writeups on shipped titles.
