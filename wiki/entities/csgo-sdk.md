# csgo-sdk

Three related CS:GO Source 1 SDK repos share this name in the curated list. All supply C++ headers and scaffolding for cheat / game:csgo research—entity classes, engine interfaces, and hook-oriented type systems.

## gmh5225/csgo_sdk

C++ CS:GO SDK focused on **SDK generation** and **hooking**—headers and scaffolding for Source 1 entity classes, engine interfaces, and cheat-oriented hook points. Aimed at game-security researchers and reverse engineers studying offensive techniques. (source: wiki/sources/descriptions/gmh5225__csgo_sdk.md)

CS:GO Source engine SDK with reverse-engineered **class definitions**, **interface declarations**, **netvar structures**, and **function signatures**.
