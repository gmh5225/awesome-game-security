# Free-RASP-KMP

Talsec freeRASP plugin for Kotlin Multiplatform: mobile in-app RASP and security monitoring on Android and iOS from shared Kotlin APIs backed by native Talsec runtime components on each platform. Gradle-based multiplatform builds expose threat and execution-state events with configurable responses such as terminating the app when protections are bypassed. Detection coverage includes root/jailbreak, hooking frameworks such as [[frida]], untrusted installation sources, automation tools, and on Android suspicious or malicious apps. Aimed at KMP developers needing client-side shielding against reverse engineering, tampering, repackaging, and fraud in production mobile apps—including games. (source: wiki/sources/descriptions/talsec__Free-RASP-KMP.md)

Sits in the mobile RASP / integrity lane alongside Flutter sibling [[free-rasp-flutter]], React Native sibling [[free-rasp-reactnative]], Capacitor sibling [[free-rasp-capacitor]], Cordova sibling [[free-rasp-cordova]], Unity sibling [[free-rasp-unity-poc]], native Android [[free-rasp-android]], native iOS [[free-rasp-ios]], Android-only [[droidshield]], and device-fingerprint SDKs [[trustdevice-android]] / [[trustdevice-ios]].
