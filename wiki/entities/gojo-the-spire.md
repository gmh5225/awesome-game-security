# GojoTheSpire

**GojoTheSpire** is a **Java** mod for **Slay the Spire** that adds a custom **Gojo Satoru** playable character. Ships new card and deck content, character assets, and supporting mod configuration files following the game's modding ecosystem conventions. Primary use case is gameplay customization and learning **character-mod development** for Slay the Spire—not binary exploitation, injection, or anti-cheat research tooling. (source: wiki/sources/descriptions/Bratah123__GojoTheSpire.md)

Contrasts with dev-oriented **Slay the Spire 2** tooling such as [[sts2-kitlib]] (Harmony IL patches, MCP bridge, cheat presets). From the same author as PTCGO private-server [[spirit-ptcgo]] and MapleStory IDA packet tooling [[spirit-ida-plugin]].
