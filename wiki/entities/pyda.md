# Pyda

Python **dynamic binary analysis** framework on QEMU user-mode emulation. Runs and instruments Linux binaries with Python callbacks for function hooking, memory-access monitoring, syscall tracing, and instruction-level analysis without native execution—scriptable exploration / vuln research for RE workflows that prefer Python. (source: wiki/sources/descriptions/ndrewh__pyda.md)

Complements Cheat DBI / QEMU analysis peers such as [[panda]] (whole-system QEMU), [[w1tn3ss]] / [[cpp-veh-dbi]] (native DBI), [[smallworld]] (multi-emulator harness), and [[ripr]] (Python/Unicorn function harnesses).
