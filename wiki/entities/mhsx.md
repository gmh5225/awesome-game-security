# MhsX

**MhsX** (L-Spiro/MhsX) is a from-scratch 64-bit successor to Memory Hacking Software (MHS): a Windows C++ memory hacking and live process analysis application for attaching to running programs, searching memory, and editing values in real time. (source: wiki/sources/descriptions/L-Spiro__MhsX.md)

Features include data-type, pointer, string, and expression-based scans; a process-aware hex editor; x86/x64 disassembly; PE inspection; speedhack support; floating-point inspection; found-address management; configurable hotkeys; string manipulation utilities; and an expression evaluator integrated with the Oniguruma regular expression library. Built as a Visual Studio solution for 32- and 64-bit Windows. (source: wiki/sources/descriptions/L-Spiro__MhsX.md)

Intended for reverse engineers, game security researchers, and developers who need deep inspection and controlled modification of application memory — as a native alternative to [[cheat-engine]]-style workflows without the CE ecosystem. (source: wiki/sources/descriptions/L-Spiro__MhsX.md)
