# vgk-illegal-pf-logger

Logs **illegal page fault** events generated by Vanguard's kernel driver (`vgk.sys`). Monitors and records page faults that Vanguard intentionally triggers as part of its detection mechanism, helping researchers understand how Vanguard uses memory access violations for integrity checking. README tag: `[VGK's illegal PF]`. Aimed at anti-cheat researchers studying Vanguard's page-fault-based detection techniques. (source: wiki/sources/descriptions/gmh5225__vgk-illegal-pf-logger.md)

Sits beside usermode working-set page-fault AC PoCs such as [[faultline]], but scoped to **kernel-side** Vanguard-triggered faults rather than PEB-unlisted usermode shellcode detection. Complements [[val-exception-handler]] exception-dispatch research on the same AC product.
