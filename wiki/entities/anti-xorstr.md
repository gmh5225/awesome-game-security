# Anti-xorstr

Python IDA plugin focused on anti-Xorstr recovery—aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane studying compile-time string obfuscation. (source: wiki/sources/descriptions/lstaroth__AntiXorstr.md)

Complements other xorstr recovery tools such as [[ida-jm-xorstr-decrypt-plugin]]; pairs with compile-time string crypters like [[mystic-xorstr]] / [[skcrypter]] on the obfuscation side. Not a general unpacker or full deobfuscation suite.
