# Paradox AntiCheat

High-performance anti-cheat and moderation addon for Minecraft Bedrock Edition on Realms and Bedrock Dedicated Server (BDS) worlds. Written mainly in TypeScript and deployed as a behavior pack on Minecraft's Script API (Beta server, server-net, server-admin, and server-ui APIs). Modular detection covers common exploits such as fly, killaura, reach, autoclicker, scaffold, namespoof, noclip, xray, and related movement or combat abuse. Staff-facing moderation commands include ban, kick, mute, freeze, whitelist, lockdown, and GUI tools so operators can configure per-world enforcement without external client installs. (source: wiki/sources/descriptions/Visual1mpact__Paradox_AntiCheat.md)

Targets Bedrock server and Realm administrators needing script-based fair-play tooling on native Realms/BDS hosts — in the same Bedrock operator lane as behavior-pack addons such as [[scythe-anticheat]] and [[blarion-anticheat]] and MiTM proxies such as [[oomph]], distinct from Java-server plugins such as [[dakotaac]] and kernel products such as [[easy-anti-cheat]].
