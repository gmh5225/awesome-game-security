# mcpup

Tool for **managing and deploying MCP (Model Context Protocol) servers** — discover, install, configure, and run MCP servers that extend AI coding assistants with additional capabilities. README-listed as **MCP for unity**; aimed at developers setting up MCP server infrastructure for Unity AI-assisted development workflows rather than live game-memory RE. (source: wiki/sources/descriptions/gmh5225__mcpup.md)

Complements editor-facing Unity MCP bridges such as [[unity-mcp]] and generic protocol hosts such as [[zig-mcp-server]] by handling MCP server lifecycle and deployment. Sits beside MCP safety auditing such as [[mcp-safety-scanner]] when hardening agent toolchains.
