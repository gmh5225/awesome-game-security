# Unity Design Pattern

Unity C# design-pattern sample library demonstrating classic object-oriented and game-specific patterns in runnable scenes. Implements all 23 Gang-of-Four patterns plus selected game programming patterns, each with structure examples, diagrams, sample scripts, and practical use cases organized by pattern category. Educational architecture reference for Unity developers studying maintainable client code—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/QianMo__Unity-Design-Pattern.md)
