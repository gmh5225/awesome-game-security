# 5.4.7 WoW Source

Customized **World of Warcraft 5.4.7** (Mists of Pandaria, level-90 era) private-server source tree from **RageProject**, derived from **TrinityCore-style** architecture. The **C/C++** codebase with **CMake** build scripts includes authentication and world server components plus supporting database and tooling resources. Project notes emphasize gameplay fixes, class and talent support, and general stability improvements for MoP-era server operation. Aimed at private-server developers and reverse-engineering communities working on MMO server emulation—not a live-service cheat client. (source: wiki/sources/descriptions/RageProject__5.4.7-Wow-source.md)

Sits in the README **Private Server** / `[wow]` lane beside other **5.4.7** MoP emulators such as [[mopcore547]] and upstream [[trinitycore]], and complements WoW client-side research samples such as [[dumpwow]], [[awesome-wow-rust]], and [[x14-08-coverstory-blizzard]].
