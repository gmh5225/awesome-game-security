# L.-Spiro-Engine-2022

**L.-Spiro-Engine-2022** (L-Spiro/L.-Spiro-Engine-2022) is a cross-platform C++ game engine built from modular libraries covering graphics, physics, sound, networking, math, memory management, threading, and model handling. It ships DXT texture-compression tooling and a comprehensive standard-library abstraction layer. Windows builds target Visual Studio; macOS builds target Xcode. (source: wiki/sources/descriptions/L-Spiro__L.-Spiro-Engine-2022.md)

Aimed at engine programmers and game developers studying low-level cross-platform game-engine architecture and design — in the Game Engine / source lane, not a cheat or anti-cheat artifact. Sits beside other from-scratch educational engines such as [[cpp-game-engine-book]], [[game-engine-from-scratch]], and [[hazel]]. (source: wiki/sources/descriptions/L-Spiro__L.-Spiro-Engine-2022.md)
