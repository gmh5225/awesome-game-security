# Full-Hwid-Spoofer-V6

**Full-Hwid-Spoofer-V6** is a comprehensive **hardware ID (HWID) spoofer** (version 6) that modifies disk, NIC, GPU, SMBIOS, and registry-based hardware identifiers. A **kernel driver** is loaded via **KdMapper**; an **ImGui** GUI provides one-click **permanent** hardware ID spoofing on **AMD and Intel** platforms running **Windows 10/11**. (source: wiki/sources/descriptions/gmh5225__Full-Hwid-Spoofer-V6.md)

Sits in the `Cheat > HWID` lane beside sibling gmh5225 comprehensive spoofers such as [[hwid-permanent-hwid-spoofer]], [[hwid-spoofer-ud-fortnite-warzone-apex-rust-escape-from-tarkov-and-all-eac-be-games-imgui-loader-base]], and [[hwid-kernel-spoofer]], KdMapper-style driver load research such as [[kdmapper-rs]], and Detection:HWID counterparts such as [[hwid-checker-mg]].
