# Anti Cheating Assistant

**Anti Cheating Assistant** (jshdcn/anti-cheating-assistant) is an **AI agent skill package** for structured **risk control and anti-fraud** work: it walks practitioners from incomplete business descriptions through modeling, analysis, and remediation recommendations. Markdown skill definitions and reference playbooks ship with Python helpers for **three-flow graph** business modeling (roles, carriers, and money/data paths) and for syncing an **underground slang lexicon** used in fraud investigations. Core workflow steps clarify business logic, map process steps to a risk catalog, and propose controls via domain playbooks spanning account, mobile, transaction, marketing, content, and financial security. Layered methodology excerpts distill anti-cheating theory for selective loading in coding assistants—not a runtime AC product. Targets product owners, risk engineers, and anti-cheat or business-security practitioners who need a repeatable workflow to model online businesses and design proportionate defenses. (source: wiki/sources/descriptions/jshdcn__anti-cheating-assistant.md)

## Capabilities

| Area | Role |
|------|------|
| **Skills & playbooks** | Markdown agent skills + reference playbooks for account/mobile/transaction/marketing/content/financial controls |
| **Three-flow modeling** | Python-assisted graph modeling of business roles and carriers |
| **Lexicon sync** | Python workflow to maintain fraud-investigation underground slang reference |
| **Risk catalog** | Map business steps to cataloged risks and remediation options |

## Distinction

Complements **in-game statistical detectors** such as [[game-cheating-exploit-detection-agent-skill]] and **pre-ship memory audits** such as [[anticheat-lab-senolbasyigit]]: this repo focuses on **business-risk modeling and control design** for online economies and fraud surfaces, not kernel drivers or live telemetry engines.
