# yuzu-archive

Placeholder archival repository for the discontinued yuzu Nintendo Switch emulator project. No longer hosts emulator source code; contents are primarily documentation, including a brief README and a DMCA notice record. Serves as a historical snapshot of takedown context and legal/ecosystem reference for researchers tracking Switch emulator enforcement events in the README `Nintendo Switch` lane. (source: wiki/sources/descriptions/Logboy2000__yuzu-archive.md)

Adjacent to active yuzu forks such as [[nuzu]] and [[yuzu-android]], but documentation-only—useful for DMCA/enforcement timeline study rather than emulator development.
