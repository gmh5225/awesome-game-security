# pwatch-c

C/C++ **hardware breakpoint (HWBP)** tooling for Linux and Android — process watch without attaching a conventional debugger. Useful for game-security researchers and reverse engineers studying offensive techniques in the cheat / debugging lane. (source: wiki/sources/descriptions/enenH__pwatch-c.md)

Complements the related [[pwatch]] project and Android memory-explorer work such as [[rwmem]].
