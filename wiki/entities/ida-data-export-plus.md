# IDA DataExportPlus

Python IDA Pro plugin that extends and replaces the default data export window. Supports exporting selected data in multiple integer and floating-point formats and can also export assembly text. Hotkey-driven interface targets modern IDA Pro versions and is designed to speed up repetitive extraction tasks during reverse engineering. (source: wiki/sources/descriptions/Krietz7__IDA-DataExportPlus.md)

Scoped as disassembly-view data/assembly export—not function-list Markdown reporting ([[ida-export-functions]]), symbol naming ([[ida-names]]), or decompiler output.
