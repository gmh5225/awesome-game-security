# AvAAntiCheat

Lightweight Bukkit/Spigot anti-cheat plugin for Minecraft Java servers. Written in Java (Maven); detects flying, wall climbing, combat logging, auto-clicking, chat spam, and selected packet-manipulation exploits via a violation counter and local logging. (source: wiki/sources/descriptions/nsharp-collab__AvAAntiCheat.md)

Configurable movement and combat checks; smart hardware profiling switches between strict vector math and lighter checks based on server performance; optional Geyser Bedrock leniency to reduce false positives. Aimed at Java server operators in the same lightweight server/host AC lane as [[oomph]] (Bedrock proxy) and [[wellsanticheat]], rather than kernel products such as [[easy-anti-cheat]] or [[vanguard]].
