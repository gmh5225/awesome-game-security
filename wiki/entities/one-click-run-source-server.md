# One-Click Run Source Server

**One-click shell script** for deploying **Source engine dedicated servers** on **Linux**. Automates environment checks, dependency installation, **SteamCMD** setup, and game server download for distributions such as **Debian**, **Ubuntu**, and **CentOS**, and can install common server components including **Sourcemod** and **Metamod** with troubleshooting guidance for typical deployment errors. Primary audience: beginners simplifying first-time setup and experienced community server operators reducing repetitive manual work. (source: wiki/sources/descriptions/2601677867__One-Click-Run_Source_Server.md)

## Deployment scope

- Linux host prep (env validation, package dependencies)
- SteamCMD bootstrap and dedicated server file sync
- Optional **Sourcemod** / **Metamod** integration for plugin hosts such as [[little-anti-cheat]] and [[corner-culling-source-engine]]
- Common failure-mode troubleshooting notes for operators
