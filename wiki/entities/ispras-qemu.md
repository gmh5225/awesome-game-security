# ispras/qemu

ISP RAS (Institute for System Programming of the Russian Academy of Sciences) **modified QEMU fork** with extra analysis and instrumentation on top of QEMU's dynamic binary translation engine—coverage collection, taint tracking, and symbolic-execution support for systems / binary analysis and vulnerability research. (source: wiki/sources/descriptions/ispras__qemu.md)

README surfaces the `windbg` tree (`[Windbg]` tag) as a WinDbg-oriented research host beside other QEMU lab forks ([[qemu-nyx]], [[panda]], [[qemu-patched]])—analysis/instrumentation focus rather than anti-VM fingerprint spoofing.
