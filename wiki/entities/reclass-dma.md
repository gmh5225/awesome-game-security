# ReClass DMA

**gmh5225** C/C++ **ReClass.NET plugin** project for **DMA-backed** structure reconstruction — mapping game memory layouts from an external cheat/debugging workstation instead of conventional in-process or RPM reads. Centered on plugin development for game-security researchers and reverse engineers studying offensive memory-analysis techniques in the cheat / debugging lane. (source: wiki/sources/descriptions/gmh5225__ReClass-DMA.md)

Complements kernel-driver ReClass readers such as [[reclass-net-driverreader]] and parallels DMA tooling like [[cheat-engine-dma-plugin]] on the [[pcileech]] / LeechCore host stack.
