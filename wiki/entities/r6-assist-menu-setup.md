# R6 Assist Menu Setup

**R6 Assist Menu Setup** (Deltabrohollow/r6-assist-menu-setup) is described as a **research-oriented** external Windows application for **Rainbow Six Siege**: an overlay that watches input to smooth aim tracking and apply **per-weapon recoil compensation** instead of patching game files. Configuration is framed around matching in-game sensitivity, weapon profiles, a toggle key, and a smoothing factor, with desktop-oriented usage and troubleshooting. Runtime expectations are **64-bit Windows 10 or 11** and **Microsoft .NET Desktop Runtime 8.0** or newer, with a packaged executable workflow. The listing positions the work as studying external compensation in competitive-style play and how it relates to detection by common anti-cheat approaches—game security / cheat-technique awareness rather than in-repo binary exploration. (source: wiki/sources/descriptions/Deltabrohollow__R6-Assist-Menu-Setup.md)
