# UE4 FPS Game

Unreal Engine 4 sample game project demonstrating a C++ gameplay module with standard character control. Combines Unreal C++ classes with Blueprint assets, input bindings, camera setup, and starter content maps. Follows typical UE4 module and target layout as a compact example of engine project structure. Educational sample for beginners practicing UE4 C++ gameplay programming and editor workflow basics—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/QianMo__UE4-FPS-Game.md)
