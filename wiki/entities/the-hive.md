# TheHive

Archived codebase of a security **incident response and case management** platform used in SOC workflows. Scala backend with web frontend, client libraries, and integration modules for alert ingestion, case tracking, and analyst collaboration. The repository is a historical snapshot—maintainers distribute newer editions separately—but remains useful for studying legacy IR architecture and operational security workflows adjacent to AC/EDR telemetry design. (source: wiki/sources/descriptions/TheHive-Project__TheHive.md)

README category: `[EDR]`. Complements host telemetry stacks such as [[wazuh]] and detection-lab generators such as [[bamboozledr]] on the defensive SOC side of game-security research.
