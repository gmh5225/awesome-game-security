# hacking-online-games

Curated resource collection focused on hacking online and multiplayer games: network protocol reverse engineering, server-side emulation, packet encryption analysis, and anti-cheat bypass research. Includes papers on GameGuard architecture, real-time map-hack prevention, MMORPG protocol deciphering, and presentations on extending closed-source games with multiplayer functionality. Aimed at game security researchers studying online game attack surfaces, network protocol security, and server-side protection mechanisms. (source: wiki/sources/descriptions/dsasmblr__hacking-online-games.md)

Sits in the Cheat → guide / Game Network lane beside wire-capture tooling such as [[packet-sniffer]] and [[inject]], server-emulation samples such as [[goldberg-emulator]], and title-specific GameGuard corpora such as [[twms-hacking-data]]. Complements the broader offline game-hacking tool index [[game-hacking]] from the same maintainer and learning indexes such as [[game-reversing]].
