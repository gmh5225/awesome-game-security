# Taiga74164 Akebi GC

Large **C++** **Genshin Impact** modification framework with an **injector** and **in-game menu**. Feature set spans protection-bypass routines, player and world modifiers, teleport helpers, ESP-style visuals, and debugging utilities. The repository includes substantial native code, assets, and multilingual documentation; public releases continued even as newer source revisions became more restricted.
