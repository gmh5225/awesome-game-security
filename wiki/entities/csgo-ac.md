# CSGO-AC (ekknod)

**Proof-of-concept anti-cheat plugin for CS:GO** (ekknod) written in **C++** and **C/C++**, centered on **anti-cheat research** and **plugin development** for the Open Source Anti Cheat System lane. Aimed at anti-cheat engineers and defensive security researchers studying CS:GO client protection and plugin architecture. (source: wiki/sources/descriptions/ekknod__CSGO-AC.md)

Complements server-side Source Engine plugins such as [[nocheatz-3]], full OSS AC pipelines such as [[deep-learning-anti-cheat-csgo]], and leaked CS:GO reference trees such as [[cstrike15-src]] for defensive CS:GO study beside offensive ekknod samples like [[ec]] and [[ec-pro-lan]].
