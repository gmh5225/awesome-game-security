# Overgrowth

Open-source release of **Overgrowth** by Wolfire Games — a 3D action game and custom engine in one tree. Includes the complete game source with engine components for rendering, physics, animation, AI, level editing, and scripting. Aimed at game engine researchers and modders studying commercial game engine internals and open-sourced shipped codebases. (source: wiki/sources/descriptions/WolfireGames__overgrowth.md)

Sits in the Game Engine / source lane — a full commercial game+engine OSS drop for development and RE study, not a cheat or anti-cheat artifact.
