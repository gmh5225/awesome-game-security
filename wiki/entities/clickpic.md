# ClickPic

Screen **pixel color detection and auto-click** tool for game automation (gmh5225). Monitors specified screen regions for target pixel colors and triggers automated mouse input when matches are found. README tags the sample under **`[OpenCV + Triggerbot]`** — a zero-memory visual offensive pipeline using classical color matching rather than trained object detection or in-process memory reads. (source: wiki/sources/descriptions/gmh5225__ClickPic.md)

Sits beside heuristic CV triggerbots such as [[camera-triggerbot]], OpenCV triggerbot samples such as [[opencv-smart-aimbot]], and colorbot samples such as [[overwatch2-colorbot-cheats]]; ML-heavy pipelines such as [[yolov5-pubg]] and [[pine]]; defensive counterparts include [[waldo]] and [[aimbot-detection-prototype]] via [[ai-aimbot-detection]].
