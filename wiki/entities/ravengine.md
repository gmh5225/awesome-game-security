# RavEngine

Modern C++ game engine with a data-oriented Entity Component System architecture, Vulkan-based rendering through the RGL abstraction layer, and GameNetworkingSockets for multiplayer networking. Cross-platform CMake build, resource packing pipelines, and subsystems for input, GUI, and audio. Mainly useful for game engine developers and graphics researchers studying modern ECS-based engine design with Vulkan rendering. (source: wiki/sources/descriptions/RavEngine__RavEngine.md)

Sits in the Game Engine / C++ 3D source lane—an ECS/Vulkan engine study surface rather than a cheat or anti-cheat artifact.
