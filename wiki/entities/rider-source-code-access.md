# rider-source-code-access

Unreal Engine plugin that registers JetBrains Rider as a selectable external source code editor inside Unreal Editor. Implemented in C++ with Unreal plugin modules; discovers Rider installations on Windows, macOS, and Linux; supports multiple Rider versions and configurable custom install paths. Improves C++ Unreal development workflows for teams using the JetBrains ecosystem—not a cheat, dumper, or anti-cheat artifact. (source: wiki/sources/descriptions/JetBrains__RiderSourceCodeAccess.md)

Sits in the Game Engine / Unreal editor tooling lane beside external IDE integrations such as [[com-unity-ide-cursor]] for Unity—legitimate editor workflow plumbing upstream of SDK generation and modding research.
