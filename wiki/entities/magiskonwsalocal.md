# MagiskOnWSALocal

Scripts to integrate **Magisk root** and **Google Apps (GApps)** into **Windows Subsystem for Android (WSA)** locally, yielding a rooted Android environment with Play Store support on Windows 11. Sits in the README `WSA` lane beside sideload/APK tooling such as [[win11-apk-installer]] and emulator-root paths such as [[rootavd]] / [[aeroot]], extending [[magisk]] onto Android-on-Windows hosts for mobile game-security and modding research.
