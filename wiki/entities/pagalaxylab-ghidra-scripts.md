# pagalaxylab-ghidra-scripts

Collection of **Python scripts** for the Ghidra reverse-engineering suite. Includes utilities for tracing function parameters with **P-Code**, analyzing Objective-C message dispatch, renaming functions from error-print patterns, and deobfuscating **OLLVM control-flow flattening**. Shared helper modules and documentation examples support practical firmware and binary analysis tasks for reverse engineers and game security analysts automating repetitive static analysis workflows. (source: wiki/sources/descriptions/PAGalaxyLab__ghidra_scripts.md)

Distinct from the CTF-oriented [[ghidra-scripts]] collection (`ghidragolf/ghidra_scripts`) and the Java ATR automation toolkit [[ghidrascripts]] — this repo focuses on Python Ghidra scripting for P-Code tracing, ObjC dispatch, heuristic renaming, and in-Ghidra OLLVM CFF recovery.
