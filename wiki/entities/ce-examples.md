# CE Examples

**CE Examples** (FreeER/CE-Examples) is a broad collection of **Cheat Engine examples**, practice tables, scripts, and reference notes. It ships many Lua and `.CT` assets covering memory scanning, Auto Assembler usage, pointer utilities, UI helpers, Mono-related workflows, and trainer-oriented experiments. Focused snippets and templates demonstrate practical reverse engineering and game memory manipulation techniques. Primary use case is teaching and accelerating Cheat Engine–based game hacking workflows. (source: wiki/sources/descriptions/FreeER__CE-Examples.md)
