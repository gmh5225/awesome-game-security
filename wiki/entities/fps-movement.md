# FPS-Movement

Unity **3D** beginner sample implementing a first-person **Rigidbody** controller in **C#**: mouse look, walk, jump, dash, and crouch via scripts attached to a player with **Collider** components. The README covers setup, control bindings, and known quirks such as **dash sliding**. It is a lightweight gameplay prototype for learning FPS movement mechanics—not a production controller or anti-cheat target. (source: wiki/sources/descriptions/OguzKaira__FPS-Movement.md)

Sits in the Game Engine **Unity FPS** lane beside production samples such as [[fpssample]] and other OguzKaira learner projects such as [[sqlite-unity3d]].
