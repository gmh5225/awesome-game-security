# WoW Launcher

Public C#/.NET game launcher for **World of Warcraft** clients that connects to custom servers using valid TLS certificates. Supports multiple client branches with configurable client versions and CDN endpoints. The public build intentionally removes developer mode, mod loading, and other advanced tooling present in the full edition—aimed at private-server operations and client compatibility testing rather than live-service cheat workflows. (source: wiki/sources/descriptions/Arctium__WoW-Launcher.md)

Complements WoW private-server stacks such as [[trinitycore]], [[azerothcore-wotlk]], [[mopcore547]], and [[5-4-7-wow-source]], and sits in the README **wow launcher** lane beside client-side WoW research tooling such as [[dumpwow]] and [[wow-iat-fix]].
