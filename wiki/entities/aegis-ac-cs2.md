# AegisAC (CS2)

**AegisAC** (ressiws/AegisAC) is an open-source **Counter-Strike 2** server-side anti-cheat built on **SwiftlyS2** (.NET). It targets dedicated-server operators who want heuristic aim/angle anomaly detection, modular punishments, and **Discord webhooks** without installing client-side anti-cheat mods. (source: wiki/sources/README-categories.md)

Distinct from Paper Minecraft [[aegis-ac]] (projectsadameyd)—same project name, different game and host stack.

## Capabilities (README summary)

- **Server-side only** — SwiftlyS2 plugin; no client mod requirement.
- **Heuristic detection** — aim and view-angle anomaly modules with configurable enforcement.
- **Integrations** — Discord webhook alerts for staff workflows.

Peers with [[cs2-anticheat-by-chmonya]], [[cs2-anticheat-pandathebeasty]], and [[sac-the-server-anticheat]] in the Open Source Anti Cheat System lane for CS2.
