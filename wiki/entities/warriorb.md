# WarriOrb

Public **source-code release** of a hardcore Dark-Souls-like action platformer built with **Unreal Engine 4**. The tree ships extensive C++ gameplay code, engine configuration, localization files, and multi-target platform packaging settings. Commercial game assets and some proprietary plugins are omitted, so it is a code-focused study artifact—not a full rebuild package. Primary use case: studying production Unreal game architecture and implementation patterns. (source: wiki/sources/descriptions/NotYetGames__WarriOrb.md)

Sits in the Game Engine / source lane for UE4 shipped-game C++ study, complementing engine-tree walkthroughs such as [[unreal-source-explained]] and SDK/dumper tooling—not a cheat or anti-cheat artifact.
