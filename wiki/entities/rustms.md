# RustMS

**MapleStory** private-server emulator written in **Rust** (gmh5225): server-side game logic spanning login, character, and channel servers with player management, NPC interaction, quest systems, and combat mechanics. The Rust implementation emphasizes memory safety and performance for MapleStory private-server developers exploring Rust for game-server development. (source: wiki/sources/descriptions/gmh5225__RustMS.md)

Complements Java/C++ MapleStory private-server stacks such as [[maple-ezorsia]], [[maplestory-v83-maplestory-cpp]], [[maplestory143]], and [[mnwvs196]].
