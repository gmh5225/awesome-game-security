# Cocos Engine

Runtime framework for the Cocos Creator editor — the new-generation game development tool in the Cocos family. Ships a complete 3D and 2D feature set with an intuitive, low-cost, collaboration-friendly workflow for game developers. Aimed at game developers, engine programmers, and graphics researchers studying a modern Cocos engine source tree in the Game Engine / source lane. (source: wiki/sources/descriptions/cocos__cocos-engine.md)

Sits in the OSS cross-platform engine-source lane for Cocos Creator titles and mobile/native analysis, not a cheat or anti-cheat artifact. Complements [[cocos4]] and legacy [[cocos2d-x]] under the same Cocos ecosystem.
