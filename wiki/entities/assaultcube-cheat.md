# AssaultCube Cheat (201580ag)

**AssaultCube Cheat** (201580ag/AssaultCube_Cheat) is a collection of **AssaultCube cheat practice code** spanning multiple game versions. It mixes **internal and external** implementations with common FPS cheat features—aimbot, ESP, overlays, memory utilities, and offset-handling examples—aimed at learners who want hands-on game hacking and reverse engineering in a controlled training context. (source: wiki/sources/descriptions/201580ag__AssaultCube_Cheat.md)

## Stack

- **Languages:** C/C++, C#, supporting scripts
- **Tooling:** Dear ImGui, OpenGL hooks, memory editing workflows

Complements other AssaultCube learning samples such as [[simple-ac-internal-cheat]], [[external-esp-hack-assaultcube]], [[voltclient]], and [[assault-cube-cheat]] on the open-source [[assaultcube]] title.
