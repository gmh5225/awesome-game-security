# HiddenModuleDetector

C/C++ **hidden module / DLL detector** for Windows applications — listed under **Anti Cheat → Detection:Hide** for anti-cheat engineers and defensive security researchers studying manually mapped or otherwise concealed modules that evade normal module enumeration. (source: wiki/sources/descriptions/mq1n__HiddenModuleDetector.md)

Same **mq1n** author lane as OSS AC reference [[no-mercy]] and injection detector [[dll-thread-injection-detector]]. Complements thread-based hide detectors such as [[system-thread-finder]] and offensive unlink samples such as [[hide-driver]].
