# UnrealClaude

**UnrealClaude** (Natfii/UnrealClaude) is an **Unreal Engine plugin** that integrates **Claude AI** as a development copilot through an **MCP bridge**. It provides **context-aware AI assistance** inside the Unreal Editor for actors, animations, assets, blueprints, characters, materials, enhanced input, replication, and Slate UI development. Targets **Unreal Engine 5.7** with **Claude Code CLI** integration and **built-in UE5.7 documentation context** for AI-assisted game development and automated code generation following UE-specific patterns. (source: wiki/sources/descriptions/Natfii__UnrealClaude.md)

Sits in the Game Develop → MCP server lane beside general Unreal Editor MCP bridges such as [[unreal-mcp]] and editor automation samples such as [[automation-examples]]; differs by shipping as an in-editor Claude copilot plugin rather than a standalone MCP server repo.
