# RedTalaria

Unreal Engine C++ plugin (cdpred/RedTalaria) that adds shareable deep links to specific project locations—Blueprint nodes, assets, and editor views—via the Hermes URL handling framework. Context-menu actions generate focus and navigation URLs from any Blueprint node; copied links open the target location when clicked from Slack or other messaging tools. Supports UE 5.3 and UE 4.27. (source: wiki/sources/descriptions/cdpred__RedTalaria.md)

Fits the Game Engine Plugins:Unreal editor-collaboration lane for teams sharing exact editor context, opposite runtime RE explorers such as [[unrealengine4-swissknife]] and MCP authoring bridges such as [[unreal-mcp]].
