# fortnite-cheato-ud-eac-be

Windows **external Fortnite cheat prototype** from JeanToBinks. C++ project that reads game memory from a separate process and renders an on-screen overlay. Includes process memory access routines, Unreal-oriented transform math, and DirectX-style drawing helpers. Focuses on extracting player data structures and visualizing entities in real time for cheat development experimentation and **anti-cheat evasion research** on EAC-protected clients.
