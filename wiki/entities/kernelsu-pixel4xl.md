# KernelSU-Pixel4XL

Modified Android kernel source for **Google Pixel 4 XL** (device codename **coral**) with [[kernelsu]] patches integrated. Based on the stock **msm-floral** kernel tree; provides kernel-level root access management via su binary injection, SELinux policy changes, syscall hooking, and credential override for selective process privilege escalation. Listed under Cheat / Android Kernel Source as KernelSU for Google Pixel4XL. (source: wiki/sources/descriptions/msnx__KernelSU-Pixel4XL.md)

Device-specific KernelSU trees like this sit beside peer Pixel-adjacent sources and other KernelSU-integrated device kernels such as [[pc-ginkgo]] and [[android-kernel-oneplus-sm7250-wksu]].
