# ida-claude-code-plugins

Official Hex-Rays collection of resources for AI-assisted reverse engineering workflows in IDA Pro. The package is mostly Python tooling plus Markdown-based plugin and skill documentation, with guidance for plugin development, automated scripting, and optional code-evaluation setups for sandboxed analysis—aimed at reverse engineers who want repeatable, automation-heavy binary analysis pipelines. (source: wiki/sources/descriptions/HexRaysSA__ida-claude-code-plugins.md)

Complements other IDA agent-RE bridges such as [[ida-pro-mcp]], [[ida-codex-mcp]], [[ida-buddy]], and [[ida-cli]], and other Hex-Rays in-IDA utilities such as [[ida-cyberchef]] and [[rax]].
