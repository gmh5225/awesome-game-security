# umium

C++/CLI user-mode anti-tamper framework that combines **undocumented Windows NT system functions** with **advanced runtime modifications** to detect and neutralize debugging, memory tampering, and sandboxing attempts. README lane: **Anti Cheat → Anti Debugging**; aimed at anti-cheat engineers and defensive security researchers studying client-side integrity and anti-analysis.
