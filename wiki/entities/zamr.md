# ZAMR

**Curated MMRL module repository** that indexes and distributes Android root modules for **Magisk**, **KernelSU**, **APatch**, and the **MMRL** module manager. Bundles integrity and anti-detection tooling—Play Integrity Fix, TEESimulator, Tricky Addon, Zygisk Assistant, HMA-OSS Zygisk, SUSFS for KernelSU—alongside Zygisk runtimes and assorted utility modules. (source: wiki/sources/descriptions/zelect0r__zamr.md)

Module metadata is published as JSON track and update manifests, served through a JavaScript-driven **GitHub Pages** catalog that **GitHub Actions** refreshes hourly from upstream releases. Targets Android root users and mobile security researchers who need a maintained one-stop source for Play Integrity bypass, root hiding, and related modules when testing app and game protection on rooted devices.

Listed in the README under **Cheat → Magisk** as a curated MMRL module repository (Play Integrity Fix, Zygisk, root-hide, TEESimulator).

Complements module managers such as [[fox-magisk-module-manager]] and WebUI hosts such as [[webui-x-portable]]; sits in the same root/integrity lane as [[awesome-android-root]], [[spoofing-collection]], and per-app spoof modules [[hidemyandroid]] / [[copg]].
