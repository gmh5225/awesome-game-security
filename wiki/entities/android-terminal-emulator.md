# Android Terminal Emulator

Classic Android terminal emulator for communicating with the device’s built-in shell. Emulates a reasonably large subset of DEC VT-100 terminal codes so full-screen TUI programs such as vi, Emacs, and NetHack render correctly. Lighter than a full Linux userland host—useful when researchers need direct shell access on-device rather than a proot/pkg environment.
