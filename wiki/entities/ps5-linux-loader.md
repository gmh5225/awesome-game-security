# ps5-linux-loader

PS5 Linux loader: a Linux payload that exploits PlayStation 5 **kernel and hypervisor** vulnerabilities to boot a custom bootloader / Linux, with **IOMMU** setup, GPU initialization, hypervisor-defeat shellcode, and **TMR** (Trusted Memory Region) handling. (source: wiki/sources/descriptions/ps5-linux__ps5-linux-loader.md)
