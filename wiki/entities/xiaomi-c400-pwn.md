# xiaomi-c400-pwn

Security research package for the **Xiaomi Smart Camera C400** (TaszkSecLabs): Python exploit code with **RNG prediction**, **Tamarin** formal verification models of the handshake, handshake-sequence documentation, and a separate **jailbreak** component for persistent device access. Targets embedded security researchers and IoT exploit developers studying consumer-camera firmware vulnerability analysis and exploitation workflows. (source: wiki/sources/descriptions/TaszkSecLabs__xiaomi-c400-pwn.md)

Complements IoT firmware audit tooling such as [[firmeye]], embedded RE coursework [[embedded-hacking]], and action-camera firmware research such as [[sjcam]] when studying stripped consumer IoT binaries and protocol handshakes.
