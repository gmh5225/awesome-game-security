# bn

**Binary Ninja CLI for agents** — a Python command-line interface that exposes Binary Ninja analysis to LLM agents and automation scripts. Targets game-security researchers and reverse engineers building offensive-analysis workflows and **Binary Ninja plugin** development where headless or agent-driven BN access is needed. (source: wiki/sources/descriptions/banteg__bn.md)

Sits in the same agent-RE lane as MCP servers such as [[binary-ninja-mcp]] and in-disassembler assistants such as [[rikugan]]. Complements BN plugin work such as [[seninja]], [[triton-bn]], and [[bndb2pat]] inside the Cheat Binary Ninja Plugins surface.
