# kbotext

**League Client Update (LCU) bot extension framework** with automated scripting and control capabilities (gmh5225; cheat / game:lol; README `[LCU]`). Provides a programmable bot interface for managing automated tasks and remote client control through the LoL client's local LCU API rather than in-guest memory reads or kernel drivers. Aimed at game security researchers and reverse engineers studying LoL client-side automation under [[vanguard]]-protected Riot clients. (source: wiki/sources/descriptions/gmh5225__KBotExt.md)

Sits beside [[frank]], [[lol-client]], and [[ayaya-league-external]] in the LoL offensive research lane, but as an LCU-native bot/automation substrate rather than launcher UI, wire/protocol client study, or external Node.js scripting platforms.
