# kazmath

Lightweight portable **C** 3D mathematics library for games and graphics programming (README `Mathematics`). Provides core realtime primitives—vectors, matrices, and transformation helpers—with CMake build support, examples, tests, and optional bindings or companion code in other languages. Targets game developers and engine/tool authors who need a portable math foundation for rendering, simulation, or security research tooling—not a render hook or anti-cheat artifact. Complements SIMD-oriented libs such as [[rtm]] and [[directxmath]] and higher-level cheat-oriented frameworks such as [[omath]] as a minimal cross-platform linear-algebra building block upstream of [[world-to-screen]] projection math. (source: wiki/sources/descriptions/Kazade__kazmath.md)
