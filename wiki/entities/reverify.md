# reverify

**reverify** (2akouwu/reverify) is an AI-assisted reverse-engineering workflow that pairs LLM-driven analysis with **deterministic byte-level verification** via an MCP server and CLI. Targets analysts and agents who need AI speed without sacrificing auditable, reproducible RE conclusions on binaries. (source: wiki/sources/README-categories.md)

## Role in the README map

Listed under **Cheat → RE Tools** beside agent-native labs such as [[open-reverselab]] and cross-platform pipelines such as [[n0xis]]. Emphasizes verification gates over unconstrained model output — complementary to MCP RE hosts such as [[ida-pro-mcp]], [[hikarisystem-hexcore]], and [[binarylens]].
