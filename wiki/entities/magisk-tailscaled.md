# Magisk-Tailscaled

Magisk module that runs the **Tailscale daemon** (`tailscaled`) on rooted Android devices. Configures **userspace networking** so Tailscale can coexist with Android VPN apps, and ships service scripts plus tunnel helpers for routing traffic. CLI workflows cover login, remote SSH, and **ADB-over-tailnet** on arm/arm64—persistent remote connectivity for advanced Android operators and mobile security researchers testing rooted lab phones. (source: wiki/sources/descriptions/anasfanani__Magisk-Tailscaled.md)
