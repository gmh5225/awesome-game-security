# ImGui Standalone

Direct3D11-based C++ framework for running an **external Dear ImGui** interface as either an **EXE** or **DLL** on Windows. Ships preconfigured Visual Studio projects for **x86** and **x64**, and creates its **own rendering window** rather than hooking a target process Present/swap path—useful when a game or tool does not expose a convenient internal DirectX render route. Commonly used for game tooling, menu prototyping, and external UI workflows in game security research. (source: wiki/sources/descriptions/adamhlt__ImGui-Standalone.md)
