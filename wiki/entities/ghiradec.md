# GhidraDec

Ghidra decompiler integration or standalone decompilation tool built on Ghidra's analysis engine. Exposes programmatic access to Ghidra decompilation for automated binary analysis and reverse-engineering workflows—useful when batch pseudocode export or pipeline-driven RE is needed outside the interactive Ghidra GUI. Listed in the Cheat → Ghidra Decompiler lane for game security researchers analyzing protected clients and anti-cheat binaries. (source: wiki/sources/descriptions/gmh5225__GhidraDec.md)

Complements the full [[ghidra]] framework tree and Ghidra automation peers ([[ghidra-bridge]], [[ghidra-headless-mcp]], [[ghidrassist]], [[ghidra-decompiler-plugins]]) by focusing on headless or API-driven decompiler output rather than GUI scripting or decompiler rule plugins.
