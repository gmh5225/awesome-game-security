# agent-sprite-forge

Codex skills for generating game-ready 2D sprites and layered maps using AI image generation, with local post-processing pipelines that clean, split, validate, and export assets for Godot, Unity, or raw 2D workflows. (source: wiki/sources/descriptions/0x0funky__agent-sprite-forge.md)

Targets game developers and tooling builders in the README **Game Develop → AI Agents** lane—agent-driven 2D sprite and tilemap pipelines with engine-ready export, complementary to local Codex cockpits such as [[image-cockpit-for-codex-workflows]], cloud fal.ai sprite sheets such as [[sprite-sheet-creator]], and YAML→GLB 3D factories such as [[3d-asset-factory]].
