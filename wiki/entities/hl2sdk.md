# hl2sdk

**Half-Life 2 SDK** (AlliedModders) — Source engine SDK codebase for Half-Life 2–era game development and engine integration. Ships extensive C/C++ headers and source for client, server, game logic, tools, and cross-platform build infrastructure. Serves as a foundational reference for creating mods, plugins, and engine-side extensions in Source-based titles; widely used for game engine research, reverse engineering, and prototyping cheat or anti-cheat experiments on Source games. (source: wiki/sources/descriptions/alliedmodders__hl2sdk.md)

Complements open Source trees such as [[source-engine]], official Valve references such as [[source-sdk-2013]], Orange Box mirrors such as [[source-engine-2007]] and [[source-sdk-orangebox]], reverse-engineered header dumps such as [[sdk]], and HL2 cheat samples such as [[hl2esp]] / [[hl2aimbot]] for cross-era Source 1 architecture study.
