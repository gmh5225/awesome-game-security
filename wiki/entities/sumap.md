# sumap (ekknod)

**sumap** is an **EFI manual map** project for loading unsigned driver payloads during the UEFI boot path, before normal Windows driver-load telemetry. It is written in **C** and **C/C++** and centers on **driver development** and **memory analysis** for game-security researchers and reverse engineers studying offensive cheat / EFI driver techniques. (source: wiki/sources/descriptions/ekknod__sumap.md)
