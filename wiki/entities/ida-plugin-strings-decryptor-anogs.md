# IDA Plugin Strings Decryptor (Anogs/ACE)

**ida-plugin-strings-decryptor-anogs** ([piat0n/ida-plugin-strings-decryptor-anogs](https://github.com/piat0n/ida-plugin-strings-decryptor-anogs)) is an **IDA Pro plugin** that **auto-detects and decrypts obfuscated strings** in **Tencent Anogs / ACE (TSS)** client libraries used by **mobile games**, with profiles for **ARM32/ARM64** (including **PUBG Mobile**). (source: wiki/sources/README-categories.md)

## Research use

Accelerates static RE on ACE-protected Android binaries listed under README **Cheat → RE Tools**, complementing narrative ACE catalogs such as [[ff-ace-anticheat-analysis]] and defensive [[mobile-anti-cheat]] boundary review—not a bypass or live cheat.
