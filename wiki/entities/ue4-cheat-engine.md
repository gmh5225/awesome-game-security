# UE4 Cheat Engine

Cheat Engine–style framework for **Unreal Engine 4** on Android: UE4-aware memory scanning, `GObject` enumeration, `UProperty` traversal, and SDK generation tuned for finding and manipulating live game objects in UE4 titles. Aimed at UE4 game hackers and security researchers who need engine-native memory analysis rather than generic CE workflows. (source: wiki/sources/descriptions/gmh5225__ue4_cheat_engine.md)

Sits in the Cheat / Game Engine Explorer:Unreal lane beside native Android SDK dumpers such as [[ue4dumper]] and inject/scripted explorers such as [[ts-ue4dumper]], but emphasizes interactive scan/edit and property walkthrough on top of [[unreal-object-model]] globals.
