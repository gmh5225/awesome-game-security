# ida-spotlight

IDA Pro plugin for workflow-centric function triage and prioritization. Helps reverse engineers decide which functions to analyze first in large binaries—a common bottleneck in malware and protected-game RE sessions. Aimed at game security researchers and reverse engineers studying offensive techniques in the cheat / IDA Plugins lane. (source: wiki/sources/descriptions/dyussekeyev__ida-spotlight.md)

Complements large-binary navigation plugins such as [[idaclu]] (cluster similar functions) and [[ida-func-outline]] (call-hierarchy trees).
