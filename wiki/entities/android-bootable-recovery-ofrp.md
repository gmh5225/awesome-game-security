# android_bootable_recovery-OFRP

Full **OrangeFox Recovery Project (OFRP)** custom recovery codebase for building OrangeFox Recovery images. Large-scale C/C++ system components, Android build scripts, XML resources, and Java tooling cover recovery UI, partition management, flashing workflows, and integration with Android bootable recovery infrastructure. Primarily for Android firmware developers and power users rather than direct game-security research; still relevant as upstream recovery infrastructure that per-device OFRP trees such as [[ofrp-device-xiaomi-mondrian]] build against. (source: wiki/sources/descriptions/Ctapchuk__android_bootable_recovery-OFRP.md)
