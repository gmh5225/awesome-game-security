# EasyPeasy GC

Genshin Impact **cheat client** built on the **EasyPeasy** framework with **Grasscutter** custom-server support. Provides client-side modifications and custom server interaction for gameplay alterations in the miHoYo Unity/IL2CPP action RPG. (source: wiki/sources/descriptions/gmh5225__EasyPeasy-GC.md)

Sits in the same HoYoverse title lane as sibling Grasscutter clients ([[genshin-akebi-gc]]), gameplay cheats ([[genshin-cheat]], [[genshin-cheetos]]), upstream scaffold [[genshin-impact-base]], and AC-bypass samples ([[genshin-easy-peasy-bypass]], [[genshin-debugger-bypass]]) that weaken the **`mhyprot2.sys`** boundary this client assumes.
