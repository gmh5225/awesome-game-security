# PalEdit

Python-based desktop save editor for Palworld. Loads save files, edits and generates companion (Pal) data entries, modifies attributes, clones entities, and writes updated structured save data back to disk. Ships with source scripts, build helpers, and packaged assets for direct Python use or compiling a Windows executable—aimed at save modding and controlled experimentation with Palworld save formats in the cheat / game:palworld [Save] lane. (source: wiki/sources/descriptions/EternalWraith__PalEdit.md)

Complements GVAS-focused toolkits such as [[palworld-save-tools]] (parse/convert/edit) and [[palworldsaved]] (rendering + editor surfaces).
