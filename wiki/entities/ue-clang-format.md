# UE Clang-Format

**UE Clang-Format configuration** (TensorWorks/UE-Clang-Format) — a Clang-Format preset tuned for Unreal Engine C++ coding style. The repository is lightweight configuration and documentation: it ships formatting rules aligned with Epic-style conventions and guidance for applying the format file in editors such as VS Code so teams can keep day-to-day Unreal C++ consistent across contributors. Not a cheat, dumper, plugin runtime, or anti-cheat artifact—aimed at game developers and engine programmers in the Game Engine / UE Clang-Format configuration lane. (source: wiki/sources/descriptions/TensorWorks__UE-Clang-Format.md)

Complements Unreal developer workflow references such as [[unreal-engine-guide]], [[ue4-tutorials]], and editor QA plugins like [[ue-buivalidator]] by focusing on **source formatting consistency** rather than runtime tooling or asset validation.
