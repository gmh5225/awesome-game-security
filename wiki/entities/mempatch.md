# mempatch

**Android memory tampering tool** from DeNA for modifying in-process memory values on running applications. C++ with **Android NDK** support; components cover **address handling**, **patching**, **snapshots**, **range tracking**, and optional **value-freeze** workflows. Ships platform-abstraction code and test assets to validate memory-editing behavior across environments. Positioned for **vulnerability assessment** and **development support** rather than use against released production apps. (source: wiki/sources/descriptions/DeNA__mempatch.md)
