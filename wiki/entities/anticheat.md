# AntiCheat

**AntiCheat** is the short wiki slug for gmh5225 **AntiCheat-chrysalis** — see [[anti-cheat-chrysalis]] for the canonical repo-named entity. The **C/C++** reference implementation demonstrates common game-protection techniques: **process integrity verification**, **module scanning**, **memory pattern detection**, **debugger detection**, **overlay monitoring**, and **driver communication** for kernel-level checks. The codebase is a study reference for understanding how anti-cheat systems are structured—aimed at anti-cheat developers and game security researchers studying protection architecture.
