# AntiCheat

**AntiCheat** is a gmh5225 **reference implementation** of a Windows anti-cheat system in **C/C++** demonstrating common game-protection techniques: **process integrity verification**, **module scanning**, **memory pattern detection**, **debugger detection**, **overlay monitoring**, and **driver communication** for kernel-level checks. The codebase is a study reference for understanding how anti-cheat systems are structured—aimed at anti-cheat developers and game security researchers studying protection architecture. (source: wiki/sources/descriptions/gmh5225__AntiCheat.md)
