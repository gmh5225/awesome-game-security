# IdaClu

IDA Pro plugin for clustering and organizing functions in large binaries. Provides a Qt-based GUI with internationalization support, function grouping by various criteria, and visual navigation aids to help reverse engineers manage analysis of binaries with many functions. (source: wiki/sources/descriptions/harlamism__IdaClu.md)

README tag: **For grouping similar functions** — complements outline/navigation plugins such as [[ida-func-outline]] and curated packs like [[idaplugins]].
