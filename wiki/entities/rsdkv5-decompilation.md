# RSDKv5 Decompilation

Community decompilation of the **Retro Engine** (**RSDKv5** / **v5U**) used by *Sonic Mania* and other Retro Engine titles. Provides cross-platform support, a modding API, multiple audio and rendering backends, and compatibility with legacy Retro Engine versions. Mainly useful for engine programmers and reverse engineers studying proprietary 2D engine internals, modding pipelines, and cross-platform porting—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/RSDKModding__RSDKv5-Decompilation.md)

Sits in the Game Engine / source lane beside other readable engine decompilations and remakes.
