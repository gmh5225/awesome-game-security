# GenericGraph

Unreal Engine 4 plugin providing a generic graph data structure for editor tooling and asset pipelines. Written in C/C++; aimed at game developers, engine programmers, and graphics researchers building UE4 plugins—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/jinyuliao__GenericGraph.md)

Sits in the Game Engine Plugins:Unreal lane beside other editor and content-structure samples: offline `.uasset` dependency graphs via [[jmap]] study packaged asset loading chains; in-editor graph assets here target reusable node/edge authoring inside the UE4 editor.
