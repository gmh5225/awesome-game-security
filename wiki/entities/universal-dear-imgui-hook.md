# Universal Dear ImGui Hook

Windows C++ graphics hook that injects a Dear ImGui overlay into applications across multiple rendering backends. Targets Direct3D 9, 10, 11, and 12 with partial Vulkan support via backend-specific hook implementations. Integrates common hooking components and input handling so users can toggle an in-process UI menu after DLL injection. Primarily used for game overlay prototyping, debugging interfaces, and rendering pipeline research. (source: wiki/sources/descriptions/Sh0ckFR__Universal-Dear-ImGui-Hook.md)
