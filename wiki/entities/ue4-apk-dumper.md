# UE4 Apk Dumper

Tool for dumping Unreal Engine 4 SDK data from **Android APK** games from gmh5225: extracts UObject class hierarchies, property offsets, and function pointers from UE4 mobile game processes on Android for cheat/SDK development. Sits in the Cheat / Game Engine Explorer:Unreal lane beside native Android dumpers such as [[ue4dumper]], emulator-targeted forks such as [[ue4dumper-emulator]], and scripted attach paths such as [[ts-ue4dumper]] / [[frida-ue4dump]]. (source: wiki/sources/descriptions/gmh5225__UE4-Apk-Dumper.md)

Use [[game-engine-detector]] to confirm a package is UE4 before launching dump workflows on Android targets.
