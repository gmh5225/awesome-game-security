# android_kernel_xiaomi_sweet

Android kernel source for **Xiaomi Sweet** (Redmi Note 10 Pro) with [[kernelsu]] integration patches. Includes the full Qualcomm kernel tree with Android build-system integration, KernelSU hook patches, and device-specific configurations—aimed at Android kernel developers and mobile security researchers building KernelSU-enabled custom kernels on Qualcomm-based Xiaomi devices. (source: wiki/sources/descriptions/fiqri19102002__android_kernel_xiaomi_sweet.md)

Device-specific KernelSU-integrated trees like this sit beside peer Xiaomi sources such as [[android-kernel-xiaomi-pipa]] and [[pc-ginkgo]] (Redmi Note 8/8T / ginkgo).
