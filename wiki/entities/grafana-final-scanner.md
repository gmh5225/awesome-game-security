# grafana-final-scanner

**Grafana Final Scanner** — Grafana vulnerability scanner that checks multiple public CVE classes (path traversal, SSRF, authentication bypass, information disclosure) with parallel scanning, optional authentication, version fingerprinting, and configuration analysis. Generates HTML, CSV, and JSON reports. Listed under Cheat → **RE Tools** for security testing of Grafana deployments adjacent to game-studio observability stacks. (source: wiki/sources/descriptions/Zierax__Grafana-Final-Scanner.md)

Complements multi-database CVE lookup tools such as [[cve-maker]] by targeting a specific product surface rather than generic CVE aggregation.
