# RookieAI_yolov8

**YOLOv8 real-time aim-assist framework** (Passer1072) in the cheat / Machine Learning YOLOv8 lane. Python project built on **Ultralytics** inference that analyzes screen captures and drives automated aiming for FPS titles—without classic in-process memory reads or injection. Supports multiple model formats (PyTorch weights, TensorRT engines, ONNX workflows), configurable aiming and trigger settings, multi-process capture/inference pipelines, and several input-control backends including Win32, Logitech DLL control, and kmNet. Aimed at game-security and cheat research around computer-vision-assisted targeting systems. (source: wiki/sources/descriptions/Passer1072__RookieAI_yolov8.md)

Sits in the external screen-capture → YOLO → HID pipeline beside [[ai-aimbot]], [[ai-fps-b00m-h3adsh0t]], [[yolov5-pubg]], and [[nuremx]]; Ultralytics YOLOv8 training samples such as [[maplestory-yolov8-training]] cover complementary model-workflow research. Defensive ML counterparts include [[waldo]] and [[aimbot-detection-prototype]] via [[ai-aimbot-detection]].
