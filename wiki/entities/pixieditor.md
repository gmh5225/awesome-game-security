# PixiEditor

All-in-one open-source 2D editor for pixel art, painting, vector work, animation, and image editing. Built mostly in C# on .NET with an Avalonia-based desktop UI and a large modular codebase. Major features include multiple toolsets on one canvas, timeline animation tools, and a node-based rendering workflow for effects and procedural edits. Targets artists and indie game developers who need a flexible 2D content-creation tool. (source: wiki/sources/descriptions/PixiEditor__PixiEditor.md)

Sits in the Game Engine / Universal Editor for 2D lane—useful for studying Avalonia desktop UI architecture, modular editor tooling, and node-based 2D pipelines rather than as a cheat or anti-cheat artifact.
