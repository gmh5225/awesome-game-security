# LuaMachine

Unreal Engine plugin that embeds a Lua scripting runtime for gameplay programming. Exposes Blueprint-accessible Lua code assets, coroutines, reflection-based metatables, and proxy call bridges between Lua and UE4 actors/components—aimed at game developers and modders seeking scriptable UE gameplay, not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/rdeioris__LuaMachine.md)

Sits beside other Unreal plugin / content-pipeline samples ([[ue5-with-dear-imgui]], [[houdini-engine-for-unreal]]): ImGui wiring and Houdini HDAs study editor/UI and DCC surfaces; this repo is the Lua gameplay-scripting bridge in the Plugins:Unreal lane.
