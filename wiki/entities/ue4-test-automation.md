# UE4 Test Automation

**Daedalic Test Automation** (DaedalicEntertainment/ue4-test-automation) is an **Unreal Engine 4** plugin for building and running **automated integration tests**. It extends the **Gauntlet**-based testing workflow with **assertions**, **delays**, **simulated input**, **trigger-driven checks**, **parameterized tests**, and **performance-oriented scenarios**. Written mainly in **C++**, it targets game teams seeking reliable QA automation, faster regression detection, and **unattended test execution** in development pipelines — README **Game Testing** / Unreal Gauntlet integration lane. (source: wiki/sources/descriptions/DaedalicEntertainment__ue4-test-automation.md)
