# hwinfo

Cross-platform **C++ library** for programmatic hardware inventory: CPU model, core counts, cache sizes, RAM capacity, disk drives, GPU details, and network interfaces via a unified API on Windows, Linux, and macOS. Aimed at developers building system-information tools, hardware inventory apps, or **HWID-based identification** systems in the Detection:HWID / Cheat HWID research lane. (source: wiki/sources/descriptions/lfreist__hwinfo.md)

Complements Windows-only WMI inventory CLIs such as [[windows-hardware-info]], SMBIOS serial checkers such as [[hwid-checker-mg]], and sensor monitors such as [[openhardwaremonitor]]; sits opposite offensive HWID spoofers such as [[hwidspoofer]] / [[spoofer-amidewin]].
