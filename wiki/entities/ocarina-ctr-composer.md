# OcarinaCTRComposer

Self-rendered `.3gx` overlay plugin that adds cheats, tools, and guides to The Legend of Zelda: Ocarina of Time 3D on a Luma3DS New 3DS (USA). Built on the [[ctr-composer]] engine (C + ARM assembly, Python asset helpers); draws a themeable UI and pauses the game without game hooks, using direct memory writes for cheats and warps. Includes movement/battle/inventory/time/quest cheats, mapped teleports and multi-slot waypoints, a save-synced 100% checklist, plus Cheat Search, RAM Dumper, and Hex Editor — aimed at in-game cheating, save/progress tracking, and memory RE under the 3DS plugin loader. (source: wiki/sources/descriptions/samaBR85__OcarinaCTRComposer.md)
