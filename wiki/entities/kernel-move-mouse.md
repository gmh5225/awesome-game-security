# KernelMoveMouse

Kernel-mode C++ example that moves the mouse by applying **relative movement** from a Windows driver. Includes a WDK-style driver skeleton with OS version checks and per-build kernel offset handling. The implementation is intentionally limited—it demonstrates low-level input manipulation rather than robust evasion—and is mainly useful for learning driver development and experimenting with game input control at kernel level. (source: wiki/sources/descriptions/BuddyBoi__KernelMoveMouse.md)
