# LazyIDA

IDA Pro **productivity plugin** (gmh5225; cheat / IDA Plugins) that adds convenience helpers for reverse-engineering workflows. Features include auto-relocation jumping during debugging, memory dumping to file, ASCII/HEX/BASE64 paste-to-memory, RVA copying, and jump-to-address without rebasing the IDB. (source: wiki/sources/descriptions/gmh5225__LazyIDA.md)

Not a decompiler or deobfuscation framework—scoped as debugger-adjacent workflow shortcuts for static+dynamic RE in IDA.
