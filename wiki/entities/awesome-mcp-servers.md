# awesome-mcp-servers

Large curated **awesome list** of Model Context Protocol (MCP) servers and related integrations. Organized as Markdown documentation with category pages spanning AI, data, infrastructure, security, gaming, and many other domains. Discovery and cataloging index rather than a single MCP server implementation — targets developers and researchers building AI workflows who need ready-made MCP tool backends. (source: wiki/sources/descriptions/TensorBlock__awesome-mcp-servers.md)

Complements individual game-security MCP bridges (IDA, Ghidra, Cheat Engine, Unity/Unreal, WinDbg, etc.) by providing cross-domain navigation to thousands of entries. Sits in the README **Awesome MCP** lane beside agent skill indexes such as [[awesome-gamedev-agent-skills]] and MCP security tooling such as [[mcp-safety-scanner]] and [[vulnerable-mcp-servers-lab]].
