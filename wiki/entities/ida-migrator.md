# ida-migrator

Python IDA Pro plugin for migrating IDA databases (IDBs). Targets game-security researchers and reverse engineers studying offensive techniques in the cheat / IDA Plugins lane. (source: wiki/sources/descriptions/giladreich__ida_migrator.md)

Complements collaborative IDB workflows such as [[idarling]] (real-time multi-user sync) and remote review via [[idarem]]—this project focuses on moving or upgrading database state between IDA versions or environments rather than live co-editing. For porting names, types, and comments onto a **new binary build** of the same program, pair with signature-based [[oh-my-dump]] re-apply. (source: wiki/sources/descriptions/nevergiveupcpp__oh-my-dump.md)
