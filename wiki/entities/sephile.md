# sephile

Rooted **Android** memory scanner and editor with a **Jetpack Compose** UI and native **NDK** backend using **ptrace** for cross-process read/write. Supports value search, address freeze, and a live hex inspector; CI publishes built APKs. Listed under Cheat **Android Memory Explorer** beside CE-style tools such as [[charlyengine]] and [[memdbg]]. (source: wiki/sources/README-categories.md)
