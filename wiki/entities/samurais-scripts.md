# Samurais Scripts

**Samurais-Scripts** (YimMenu-Lua/Samurais-Scripts) is a **GPL-3.0 Lua script collection and base** for **YimMenu-focused GTA Online** roleplay workflows and menu automation. Listed under README **Cheat** beside other GTA mod-menu lanes; extends the [[yimmenu]] scripting ecosystem rather than shipping a standalone injectable menu binary.
