# ghidramcp

**GhidraMCP** — MCP server and Ghidra plugin that lets LLM clients drive reverse engineering through structured tool calls. Exposes decompilation, symbol and method enumeration, and automated renaming for binaries loaded in Ghidra. Combines a Java-side Ghidra extension with Python bridge components for integration with desktop AI clients. Built for reverse engineers and security analysts pursuing semi-automated binary analysis workflows. (source: wiki/sources/descriptions/LaurieWired__GhidraMCP.md)

Original LaurieWired Ghidra MCP path — distinct from the expanded [[ghidra-mcp]] (bethington; 200+ tools, BSim, Docker) but curated by [[ghidra-manager]] alongside other Ghidra MCP extensions. Same author lane as Apple-focused [[malimite]].
