# Anti-Forensics

Curated knowledge base of anti-forensic techniques — not an executable tool. The README catalogs methods for data hiding, log tampering, registry and file-system artifact manipulation, and virtualization-based evasion, with community-sourced examples from DFIR discussions illustrating real-world attacker tradecraft. Primary audience is incident responders and security researchers studying how evidence can be obscured; complements defensive recovery tooling in the AC / IS forensics lane.
