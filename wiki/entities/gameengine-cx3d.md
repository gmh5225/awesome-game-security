# CX3D Framework

Easy-to-use **C++ 3D game framework** (**GameEngine-CX3D**, gmh5225): the CX3D Framework targets development of 3D games in C++ with a lightweight, approachable API surface. (source: wiki/sources/descriptions/gmh5225__GameEngine-CX3D.md)

Aimed at game developers, engine programmers, and graphics researchers working in the game-engine / source lane—not a commercial title or anti-cheat artifact.
