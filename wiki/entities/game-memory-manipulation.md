# Game Memory Manipulation

Hands-on lab notes for dynamic memory manipulation and runtime analysis on the offline Windows FPS **AssaultCube**. Walkthroughs cover Cheat Engine exact-value scanning, filtering after in-game state changes, and RAM patches that alter health, ammunition, and related player statistics. Material also documents global speedhacking, Structure Spider offset mapping from known base addresses, and Memory Viewer inspection of client disassembly and opcodes—aimed at learners in game security, reverse engineering, and cyber-security training who need a structured introduction to how runtime variables in RAM map to visible game behavior.
