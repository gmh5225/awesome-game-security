# Prowl

Open-source C#/.NET 3D game engine with a Unity-style **GameObject** and **MonoBehaviour** component model, plus a full visual editor and runtime. Ships **Prowl.Editor** and **Prowl.Runtime** for scene editing, asset import, C# scripting with hot reload, prefabs, and desktop build pipelines. The runtime covers PBR rendering and post-processing (bloom, TAA, SMAA, SSR, GTAO, volumetric fog), 3D physics with rigidbodies, colliders, and joints, MiniAudio-based audio, particle systems, terrain, skinned meshes, and a canvas UI system. Cross-platform native libraries and sample projects support physics demos, audio, fly cameras, and voxels. (source: wiki/sources/descriptions/ProwlEngine__Prowl.md)

Sits in the Game Engine / source lane—an OSS C#-first engine with Unity-like authoring workflows for studying managed engine architecture, rendering stacks, and editor/runtime split, not a cheat or anti-cheat artifact.
