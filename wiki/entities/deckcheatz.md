# DeckCheatz

**DeckCheatz** (DeckCheatz/DeckCheatz) is a portable **game trainer interface** for **Steam Deck** and other **Linux** hosts, implemented as a **Steam Proton compatibility tool** wrapper that simplifies running third-party trainer software under **Wine** and **Proton** without hand-configuring prefixes. The core app is **Rust** (Tokio, Clap, Serde) with optional **SQLite** storage and feature flags for Steam library discovery, Steamworks bindings, **proton-call**, and **Decky** integration. **Flatpak** and **Nix** packaging install into Steam’s compatibility-tools directory beside the Steam runtime. Targets Linux gamers and researchers who use or study trainers such as **WeMod** and **PLITCH** and need repeatable launch/management in a Proton gaming environment.
