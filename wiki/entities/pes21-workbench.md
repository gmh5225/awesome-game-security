# PES 21 Workbench

**PES 21 Workbench** (Joao-Spala/pes21-workbench) is a **source-driven Cheat Engine 7.2+** cheat-table and tooling suite for **eFootball PES 2021**. It exposes **Master League** and **in-match** editing through a custom dark **Studio GUI**, built from **Python** build scripts, **Lua** embedded in the cheat table, and **JSON** data derived from reverse engineering **PES2021.exe**—including Konami **OVR weight matrices**, scout-list handlers, and targeted memory hooks armed via **AOB scans** and **RVAs**. Capabilities include DNA-preserving overall-rating edits, real-RAM scout and shortlist management, player struct snapshots with undo, finance and contract overrides, training and match-time controls, and bilingual **PT-BR** and **English** distributions compiled to ready-made `.CT` files, with **Sider/BMPES** patch compatibility. Automated tests lint the cheat table and GUI DPI behavior. The project targets reverse engineers, memory editors, and modding researchers who study or extend PES 2021 client internals and live game state rather than shipping a standalone application. (source: wiki/sources/descriptions/Joao-Spala__pes21-workbench.md)
