# Godot

Official Godot Engine open-source repository — the core C++ engine tree behind GDScript, C#, and the editor/runtime used across the README **Game Engine → Source** lane. Aimed at game developers, engine programmers, and graphics researchers studying a full modern engine codebase (rendering, scripting, scene graph, export pipelines) rather than a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/godotengine__godot.md)

Anchors the Godot ecosystem cited elsewhere: runtime RE via [[gddumper]] (Cheat Engine SceneTree/GDScript dump), defensive modding via [[godot-sandbox]], editor MCP via [[better-godot-mcp]], and title/format RE ports such as [[unturned-godot]]. Cross-engine server-authoritative AC such as [[certael]] integrates at a different layer than in-process engine introspection.
