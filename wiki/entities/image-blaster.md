# image-blaster

Claude skillset / pipeline that turns a single image into 3D meshes (`.glb`/`.obj`), a Gaussian splat environment (`.spz`), and SFX via World Labs + FAL, targeting Unity / Unreal / Godot / Blender import. The shipped web demo is a React + Three.js panoramic image world with spatial audio, animated butterflies, touch controls, and sidebar world-switching. (source: wiki/sources/descriptions/neilsonnn__image-blaster.md)

Sits in the README AI / 3D Graphics image→mesh-splat lane—an asset-generation and viewer surface rather than a Present hook, cheat overlay, or anti-cheat artifact.
