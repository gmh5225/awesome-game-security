# UE-BUIValidator

**UE4 UI Texture Validator Plugin** (benui-dev/UE-BUIValidator) — editor-side validation for Unreal UI textures. Each rule supports multiple allowed values for a given setting, so teams can encode texture-size, format, and UMG/Slate constraints as configurable checks rather than one-off reviews. Aimed at game developers, engine programmers, and graphics researchers in the Game Engine / Plugins:Unreal lane—not a cheat, dumper, or anti-cheat artifact. (source: wiki/sources/descriptions/benui-dev__UE-BUIValidator.md)

Complements Unreal UI integration samples such as [[ue5-with-dear-imgui]] and [[unreal-imgui-tools]] by focusing on **asset QA** for UI textures (validation rules, allowed-value sets) rather than runtime ImGui wiring or in-game overlays.
