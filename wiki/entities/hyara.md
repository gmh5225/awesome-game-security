# Hyara

Multi-platform YARA rule generation plugin for IDA Pro, Ghidra, Binary Ninja, and Cutter. Python-based tooling exposes integrated APIs per disassembler to create, check, and detect YARA signatures directly from binary analysis sessions—useful for malware analysts and reverse engineers turning binary patterns into portable rules. (source: wiki/sources/descriptions/hyuunnn__Hyara.md)

Rule **generation** from disassembly context—not a standalone AV scanner or compiled-rule bytecode analyzer.
