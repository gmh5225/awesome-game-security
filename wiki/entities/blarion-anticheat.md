# Blarion AntiCheat

**Blarion AntiCheat** (StarBloomMinecraft) is a **behavior-pack** anti-cheat for **Minecraft Bedrock Edition** that protects multiplayer worlds from hacked clients, exploits, and unfair advantages without requiring a dedicated server backend. Written in **JavaScript** using the Bedrock **ScriptAPI** (Beta), it provides more than **40 real-time detection modules** covering combat, movement, inventory, and packet abuse—including fly, killaura, speed, reach, noclip, autoclicker, and xray. Configurable violation thresholds and punishments, admin commands for inventory inspection and player scanning, per-player bypass/whitelist support, and a developer-facing `/flag` API for WebSocket or proxy integration. Intended for Bedrock world hosts on vanilla clients, BDS, or LiteLoader where server-side plugins are unavailable or limited. (source: wiki/sources/descriptions/StarBloomMinecraft__BlarionAntiCheat.md)

## Detection stack

Combat, movement, inventory, and packet-abuse modules with configurable thresholds; staff admin commands; optional external integration via `/flag` API.
