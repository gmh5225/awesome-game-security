# NeoTerm

Modern Android terminal emulator from NeoTerrm, built primarily with Java and Kotlin plus XML-based Android UI resources. Uses a Termux-oriented workflow foundation and emphasizes mobile shell usability, documentation, and release distribution for day-to-day command-line tasks on phones and tablets. Useful for developers and mobile security practitioners who need a portable terminal environment on Android devices. (source: wiki/sources/descriptions/NeoTerrm__NeoTerm.md)

Sits beside canonical [[termux-app]], experimental fork [[neotty]], and legacy [[android-terminal-emulator]] hosts for on-device CLI research.
