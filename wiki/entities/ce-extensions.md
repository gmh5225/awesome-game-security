# CE Extensions

**CE Extensions** (FreeER/CE-Extensions) is a modular set of **Lua-based Cheat Engine extensions** that add utility features to the CE interface and scripting environment. Scripts cover autosave controls, disassembler highlighting, structure and offset helpers, process attachment conveniences, and other workflow quality-of-life improvements. Each module is designed to load independently so advanced users can adapt the pack to their own reverse engineering and game analysis setups. (source: wiki/sources/descriptions/FreeER__CE-Extensions.md)

Primary audience is advanced [[cheat-engine]] users who customize live memory-analysis and RE workflows via CE's Lua scripting surface.
