# DLLHSC

**DLL Hijack SCanner** — Windows tooling from ctxis for scanning DLL hijack surface. Built with Visual Studio Community 2019; aimed at game-security researchers and reverse engineers studying offensive cheat / DLL hijack tradecraft. (source: wiki/sources/descriptions/ctxis__DLLHSC.md)

Sits in the Cheat → DLL Hijack lane beside catalog DBs [[windows-dll-hijacking]] and [[hijacklibs]], discovery tooling [[dllirant]] / [[impulsive-dll-hijack]], and audit scanners such as [[dllspy]] (not a game-specific cheat); useful for AC/EDR researchers mapping image-load / search-order abuse.
