# UnrealLive2D

Unreal Engine runtime plugin for integrating **Live2D Cubism** models into UE projects. Implemented primarily in **C++** with Unreal shader code; framework modules cover model loading, effects, motion playback, physics, and rendering. Ships sample assets and Blueprint content demonstrating expressions, lip sync, eye blink behavior, and interactive animation flows. Primary use case is **2D character rendering and animation** in game development workflows—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/Arisego__UnrealLive2D.md)

Complements [[vtuber-with-ue4]] and [[kawaii-physics]] in the Unreal Game Develop lane: VTuber-oriented samples and fake-physics plugins target 3D character pipelines, while UnrealLive2D focuses on Live2D Cubism integration for 2D avatar rendering inside UE.
