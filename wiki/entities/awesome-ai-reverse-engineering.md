# Awesome AI Reverse Engineering

Curated catalog of open-source tools that connect AI coding agents (Claude Code, Codex, and similar) to reverse engineering workflows. Groups roughly **122 vetted repositories** into disassembler/decompiler Model Context Protocol servers for Ghidra, IDA Pro, Binary Ninja, radare2, and x64dbg; mobile stacks built on jadx, apktool, and Frida; web and JavaScript protocol analysis; agent skill packs; and example rebuild projects such as [[rea-mytechnotalent]]. Each entry includes star counts and security grades from automated README review, with machine-readable JSON metadata beside the markdown lists. Targets security researchers and engineers who want LLM-driven automation for binary, mobile, and protocol RE—not a general cheat link dump. (source: wiki/sources/descriptions/zhuyansen__awesome-ai-reverse-engineering.md)
