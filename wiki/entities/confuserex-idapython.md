# ConfuserEx IDAPython

Python IDAPython deobfuscation script for binaries protected with [[confuserex]]. Aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane recovering readable structure from ConfuserEx-obfuscated .NET or mixed managed/native samples inside IDA. (source: wiki/sources/descriptions/govcert-ch__ConfuserEx_IDAPython.md)

Complements dnSpy/IL-level RE and the open-source [[confuserex]] protector itself — scoped to ConfuserEx-specific transforms rather than general .NET unpacking.
