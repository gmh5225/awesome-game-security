# DOOM Retro

**DOOM Retro** is a classic DOOM **source port** for Windows written in C with **SDL2**. It modernizes the original **idTech 1** engine with widescreen rendering, uncapped framerate, improved lighting, texture filtering, gamepad support, and numerous bug fixes while preserving authentic gameplay feel. The port supports all original WAD formats, DeHackEd patches, and BOOM-compatible map features. Aimed at classic FPS enthusiasts, DOOM modders, and game engine researchers studying idTech 1 engine modernization. (source: wiki/sources/descriptions/bradharding__doomretro.md)

Sits in the README **Game Engine → Source** lane — a readable idTech 1 codebase for modding and engine-structure study, not a cheat or anti-cheat artifact.
