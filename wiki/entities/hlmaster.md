# hlmaster

Reverse-engineered **Half-Life Master Server** implementation by ezhangle. The master-server protocol is not publicly documented, so the project reconstructs it from observed behavior—useful for game developers, engine programmers, and graphics researchers working in the GoldSrc / Source engine area who need server-browser or online-discovery plumbing. (source: wiki/sources/descriptions/ezhangle__hlmaster.md)

Complements GoldSrc engine study surfaces such as [[goldsource-rebuild]], [[regs]], and [[source-engine]], plus Half-Life mod collections such as [[hl-mods]].
