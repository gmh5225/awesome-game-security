# Go-Detection-Hyper-v

Go-based tool for detecting **Hyper-V virtualization environments**: CPU feature checks, timing-based detection, and hypervisor presence verification to determine whether code is running inside a Hyper-V virtual machine. README category `[Hyper-v]`. (source: wiki/sources/descriptions/gmh5225__Go-Detection-Hyper-v.md)

Complements user-mode HV probes such as [[checkhv-um]], cross-platform VM fingerprinting such as [[vmaware]], IDT SIDT/LIDT hypervisor probes such as [[hv-detect]], and multi-technique C++ detectors such as [[hypervisor-detection]].
