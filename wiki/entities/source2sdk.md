# source2sdk

Generated Source 2 SDK headers for various games (neverlosecc; C++). Companion dump/output lane to generators such as [[source2gen]]: pre-emitted class/enum/interface layouts for Source 2 titles used in cheat / game engine explorer:source research. (source: wiki/sources/descriptions/neverlosecc__source2sdk.md)

Complements offset/netvar feeds such as [[cs2-offsets]] / [[cs2-offsets-ro0ti]] and Source 1 header dumps such as [[sdk]] when moving from Source → Source 2 SDK consumption.
