# BinaryShield

**Open-source bin2bin x86-64 code virtualizer** that lifts commonly used native instructions into **custom bytecode** executed by a **purpose-built virtual machine**, aiming for strong protection against reverse engineering. Aimed at anti-cheat engineers and defensive security researchers working in the anti-cheat / obfuscation-engine lane under Anti Cheat → Obfuscation Engine / `[VM]`. (source: wiki/sources/descriptions/connorjaydunn__BinaryShield.md)

Useful as an open x64 bin2bin virtualization reference alongside [[nocturne]], [[covirt]], [[guardian-rs]], and [[x64-virtualizer-rs]] — with a custom VM interpreter model distinct from commercial protectors such as [[vmprotect]].
