# KisakBlack

Open-source **Call of Duty: Black Ops dedicated server reimplementation** (SwagSoftware) based on leaked source code. Includes the **DemonWare** networking stack, **zone/asset loading**, and game server infrastructure for community hosting. (source: wiki/sources/descriptions/SwagSoftware__KisakBlack.md)

Primarily used by mod developers, server operators, and security researchers studying legacy IW-engine **dedicated-server** and online-service internals—not a live-service cheat drop, but readable server/network/zone code for studying Black Ops-era multiplayer hosting.
