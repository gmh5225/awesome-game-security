# COCOS 4

Open-source, high-performance, cross-platform game and interactive content development engine from the Cocos organization. Built on a mature C++ architecture with powerful rendering capabilities and flexible script bindings, following a write-once-run-anywhere philosophy. Aimed at game developers, engine programmers, and graphics researchers studying a modern cross-platform engine source tree in the Game Engine / source lane. (source: wiki/sources/descriptions/cocos__cocos4.md)

Sits in the OSS cross-platform engine-source lane for development and mobile-title analysis, not a cheat or anti-cheat artifact. Complements the older [[cocos2d-x]] 2D framework lineage and the [[cocos-engine]] Cocos Creator runtime under the same Cocos ecosystem.
