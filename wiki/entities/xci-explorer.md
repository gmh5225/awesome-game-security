# XCI Explorer

Windows desktop tool for inspecting Nintendo Switch XCI and NSP package contents. Built with C# on .NET WinForms; includes parsers for container formats such as XCI, NCA, HFS0, and PFS0. Features include metadata viewing, partition browsing, hash checking, file extraction, and certificate editing workflows. Used by Switch modding and game security researchers analyzing cartridge images and package structure. (source: wiki/sources/descriptions/StudentBlake__XCI-Explorer.md)

Complements CLI read/extract tooling such as [[nstool]] with a GUI-oriented browse, hash-verify, extract, and certificate-edit workflow for XCI/NSP images rather than general format introspection alone.
