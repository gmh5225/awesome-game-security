# H5GG

**iOS modding engine** combining **JavaScript scripting APIs** with an **HTML5-based user interface**. Provides memory editing, script loading from local or remote sources, dynamic plugin support, and automatic static pointer-chain search. Ships multiple runtime modes for **jailbroken and non-jailbroken** environments and an **h5frida** plugin for Objective-C and C/C++ function hooking and patching. Used for mobile game modding, runtime instrumentation, and iOS game security research. (source: wiki/sources/descriptions/H5GG__H5GG.md)

Complements desktop-driven iOS memory workflows ([[ceserver-ios]], [[memory-server]], [[frida-ceserver]]) and in-process patching libraries ([[kittymemory-ios]]) when the workflow is an on-device JS/HTML5 cheat engine with optional Frida-backed hooks.
