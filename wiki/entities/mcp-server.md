# mcp-server

Burp Suite extension that exposes Burp capabilities to AI clients through the Model Context Protocol. Implemented in Kotlin and Java with Gradle build scripts and packaged extension artifacts. Key features include an MCP server endpoint, a bundled stdio proxy mode, and client configuration support for desktop AI tools. Targets application security testers who want AI-assisted interaction with Burp workflows. (source: wiki/sources/descriptions/PortSwigger__mcp-server.md)

Sits in the README **MCP for Burp Suite** lane beside binary-RE MCP bridges such as [[ida-pro-mcp]] and cross-domain discovery indexes such as [[awesome-mcp-servers]]. Complements MCP security training tooling such as [[mcp-safety-scanner]] and [[vulnerable-mcp-servers-lab]].
