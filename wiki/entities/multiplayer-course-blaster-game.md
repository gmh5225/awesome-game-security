# MultiplayerCourseBlasterGame

Unreal Engine 5 C++ multiplayer shooter sample **Blaster** from DruidMech: combat components, **lag compensation**, multiple weapon types, pickups, HUD widgets, team modes, and capture-the-flag logic. The repo ships a multiplayer sessions plugin and Steam online subsystem configuration for networked play—aimed at developers learning multiplayer architecture and at game security researchers studying UE networking behavior (replication, session flow, hit validation). Game Develop / Unreal source lane; not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/DruidMech__MultiplayerCourseBlasterGame.md)

Complements the related [[multiplayer-blaster-game]] sample (invi1998 fork) and other Unreal replication references ([[ue5-multiplayer-project]], [[network-time-sync]]) by emphasizing course-oriented Blaster systems—lag compensation, Steam sessions, and CTF/team modes—for networked FPS architecture study.
