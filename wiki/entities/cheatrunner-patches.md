# CheatRunner Patches

Community-maintained **PlayStation 4/5** patch library for the **CheatRunner** loader: per-title **XML** files keyed to Sony **Title IDs**, organized in separate PS4 (`CUSA`) and PS5 (`PPSA`/Prospero) folders. Each patch declares version-specific metadata and **byte-level edits** against game executables such as `eboot.bin`—for example 60 FPS targets, resolution changes, and related runtime tweaks. (source: wiki/sources/descriptions/notmaj0r__CheatRunner_Patches.md)

README lists it under **PlayStation** (~8 links in the projected category map). Aimed at **console modding** and **reverse-engineering** practitioners who legally own titles and want tested, shareable patch definitions rather than ad hoc binary edits.
