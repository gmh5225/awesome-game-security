# CheatRunner Patches

Community-maintained **PlayStation 4/5** patch library for the **CheatRunner** loader: per-title **XML** files keyed to Sony **Title IDs** (PS4 `CUSA`, PS5 `PPSA`/Prospero), with version metadata and **byte-level edits** against executables such as `eboot.bin` (FPS targets, resolution, and related runtime tweaks). (source: wiki/sources/descriptions/notmaj0r__CheatRunner_Patches.md)

README lists it under **PlayStation** (~8 links in the projected category map). Intended for practitioners who legally own titles and want shareable, tested patch definitions instead of ad hoc binary edits.
