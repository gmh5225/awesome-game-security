# EloBuddy-Addons

Collection of **addon scripts for the EloBuddy League of Legends scripting framework** (gmh5225; cheat / game:lol). Provides champion automation, **orbwalker** logic, **skill-shot prediction**, and utility modules for automated LoL gameplay—aimed at game security researchers studying historical EloBuddy plugin architectures and automated gameplay logic under [[vanguard]]. (source: wiki/sources/descriptions/gmh5225__EloBuddy-Addons.md)

Complements parallel LoL scripting platforms such as [[leaguesharp]] and feature-level plugin assemblies such as [[l-assemblies]] rather than cheat bases, loaders, or dump tooling.
