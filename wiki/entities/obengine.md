# ObEngine

Open-source 2D game engine focused on accessible game development and Lua-driven scripting. Primarily C++ with bundled SFML and dependencies; includes scene and game-object management, map tooling, animation, input binding, networking, and plugin support. Exposes runtime features through scriptable APIs and project tooling for indie developers and learners building customizable 2D games. (source: wiki/sources/descriptions/ObEngine__ObEngine.md)

Sits in the Game Engine / `[2D+Lua]` source lane—useful for studying a compact Lua-scripted 2D engine tree rather than as a cheat or anti-cheat artifact.
