# GDevelop

Open-source, cross-platform game creation tool and engine for building 2D and 3D games with a visual events-based logic system rather than traditional coding alone. Architecture splits a C++ project core (**GDCore**) handling event parsing and code generation, JavaScript bindings (**GDevelop.js**), a Pixi.js-backed HTML5/JavaScript runtime (**GDJS**), and a React-based desktop IDE (**newIDE**) that exports via Electron and related packagers. Large extension ecosystem covers sprites, behaviors, tile maps, 3D objects and effects, audio, input, networking, ads, and debugging tools. Useful for game developers and educators making games without heavy programming, and for researchers studying open game-engine design, visual scripting, and HTML5 export pipelines. (source: wiki/sources/descriptions/4ian__GDevelop.md)

Sits in the Game Engine / HTML5 visual-scripting source lane—an OSS cross-platform authoring stack for development and engine-design study, rather than a cheat or anti-cheat artifact. Adjacent to [[pixijs]] (GDJS render backend), [[godot]] (visual scripting / open engine), [[babylon-js]], and [[three-js]].
