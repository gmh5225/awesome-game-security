# ampa-sys-exp

C/C++ automated exploit for the **`ampa.sys`** vulnerable Windows kernel driver: abuses an insecure IOCTL interface for arbitrary kernel read/write or code execution, enabling unsigned driver loading, process privilege escalation, or anti-cheat bypass. Targets BYOVD researchers studying vulnerable-driver exploitation for kernel-level access. (source: wiki/sources/descriptions/gmh5225__ampa.sys-exp.md)
