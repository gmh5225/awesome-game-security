# exrop

**Exrop** is a Python **automatic ROP chain generator** that builds return-oriented programming gadget chains from a given binary and user-specified constraints. Aimed at game-security researchers and reverse engineers studying offensive techniques in the cheat / ROP generation lane. (source: wiki/sources/descriptions/d4em0n__exrop.md)

Complements gadget discovery tools such as [[ropgadget-rs]] and [[agafi]], and kernel gadget resolution via [[ntkernelwalkerlib]] / [[ntoskrnlwalker]].
