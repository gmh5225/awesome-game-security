# kernel_build_action

GitHub Action workflow to **build kernels automatically** (TypeScript and Python). Targets kernel-level Android driver development workflows for game-security researchers and reverse engineers studying offensive techniques in the cheat / Android kernel driver lane—CI automation for custom kernel trees without manual host setup. (source: wiki/sources/descriptions/dabao1955__kernel_build_action.md)

Complements out-of-tree driver build/ABI automation such as [[compile-android-driver]] (Kadeflow / `kadeflow.yaml`) and device-specific kernel source trees such as [[android-kernel-oneplus-sm8250]] when researchers need repeatable kernel image builds in GitHub Actions.
