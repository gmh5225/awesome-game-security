# WinDbgCookbook

Collection of practical WinDbg automation scripts and debugger queries, mainly JavaScript for the WinDbg data model. Includes utilities for dependency inspection, stack collection, stack corruption detection, and time-travel debugging analysis; the README also provides ready-to-run `dx` command examples for module, thread, and environment inspection. Primary use case is improving productivity for Windows reverse engineers and debugging-focused security researchers. (source: wiki/sources/descriptions/TimMisiak__WinDbgCookbook.md)

Not a standalone debugger—extends WinDbg with scripted automation and query recipes for kernel/user RE workflows.
