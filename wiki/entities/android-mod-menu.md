# Android-Mod-Menu

Widely used **floating mod-menu framework** for **IL2CPP** and other native Android games. Combines **Java UI** with native **C/C++ hooks**, integrating **[[kittymemory]]**, MSHook, **[[and64-inline-hook]]**, and string obfuscation utilities. Supports **ARMv7** and **ARM64** across a broad Android version range and embeds assets as Base64-backed native data. Aimed at game modding and security researchers prototyping runtime feature toggles and hook-based experiments. README tag: `[Floating mod menu for Android]`. (source: wiki/sources/descriptions/LGLTeam__Android-Mod-Menu.md)

Complements Kotlin/Java floating overlay templates ([[android-modmenu-semijni]], [[android-mod-menu-kotlin]]), GLES ImGui scaffolds ([[android-mod-menu-imgui]], [[imgui-native-modmenu]], [[unity-imgui-android]]), and Frida IL2CPP mod menus ([[malum-menu-android]], [[fallguys-frida-modmenu]]) in the mobile cheat / overlay lane.
