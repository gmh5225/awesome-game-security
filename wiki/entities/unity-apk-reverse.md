# unity-apk-reverse

**unity-apk-reverse** (liuyiyi0219-arch/unity-apk-reverse) is a **40-chapter hands-on reverse-engineering course** for **Unity Android APK games**, listed under README **Cheat / Guide**. Structured as a progressive curriculum with runnable demos and auto-graded homework for authorized mobile game security practice. (source: wiki/sources/descriptions/liuyiyi0219-arch__unity-apk-reverse.md)

## Curriculum layers

Walks learners through every layer of a Unity mobile title: **APK unpacking** and **signature bypass**; **IL2CPP metadata recovery**; **Lua** and **puerts/QuickJS** script extraction; **DEX** decompilation; and **AssetBundle** resource analysis across sample target APKs. (source: wiki/sources/descriptions/liuyiyi0219-arch__unity-apk-reverse.md)

## Toolchain

Practical coverage of **Frida**, **frida-gadget**, **unidbg**, **jadx**, and related mobile RE utilities alongside **Python** and **Go** course tooling—a course builder and local HTTP loader for lab delivery. (source: wiki/sources/descriptions/liuyiyi0219-arch__unity-apk-reverse.md)

## Lab infrastructure

Runnable chapter demos plus **auto-graded homework** give structured feedback without ad-hoc target selection—aimed at beginners and practitioners who want progressive, authorized Unity APK RE training rather than one-off tool tutorials. (source: wiki/sources/descriptions/liuyiyi0219-arch__unity-apk-reverse.md)
