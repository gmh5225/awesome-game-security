# Proton

**Steam Play Proton** (ValveSoftware) — Valve's Wine-based compatibility layer that runs Windows game binaries on Linux through Steam. Ships build scripts, Docker-based build infrastructure, default Wine prefix configuration, Steam integration manifests, and per-title compatibility fixups for translating Windows games to Linux hosts. Intended for Linux gaming researchers and compatibility-layer developers studying Windows-to-Linux game translation and Steam Play technology. (source: wiki/sources/descriptions/ValveSoftware__Proton.md)

Sits upstream of community GNU/Linux anti-cheat compatibility tracking such as [[aclist-github-io]] and macOS CrossOver runtime patchers such as [[crossover-patcher]]. Complements userspace Wine/Proton AC-driver study samples such as [[holodori-kernel-bypass]], Linux ptrace/Wine tooling such as [[ptrace-read-teb]], Proton-hosted cheat workflows such as [[elden-ring-ct-tga]], and cross-platform memory libraries with Proton backends such as [[vm]].
