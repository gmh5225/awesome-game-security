# Everything Game Dev Code

**Everything Game Dev Code** (MRCalderon3D/everything-game-dev-code) is a **layered workflow scaffold** for AI-assisted game development—not a playable game. It coordinates **rules**, specialized **agents**, slash-style **commands**, reusable **skills**, **phase contexts**, and **hooks** so coding assistants can handle design, implementation, QA, release, and live-ops under shared standards. Supports **Unity**, **Unreal**, **Godot**, and **HTML/JS** (2D and 3D) with strict engine isolation, plus harness adapters for **Claude Code**, **Codex**, **Cursor**, **OpenCode**, and **Kiro**. A **Node.js** tooling layer validates and syncs manifests, structure artifacts, and wrappers; an optional AI asset-generation path can upgrade placeholders when a provider key is present. Primary use case: standardizing multi-engine studio and solo workflows for AI-driven game projects, including specialized review roles such as **security**, **performance**, and **console compliance**. (source: wiki/sources/descriptions/MRCalderon3D__everything-game-dev-code.md)

Sits in the README **Game Develop → AI Agents** lane beside version-pinned skill packs such as [[awesome-gamedev-agent-skills]] and engine-specific MCP bridges such as [[unreal-claude]], [[unity-mcp]], and [[better-godot-mcp]]; differs by shipping a full multi-engine phase workflow scaffold rather than a single-engine plugin or skill collection.
