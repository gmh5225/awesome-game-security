# Lost Ark Dumper

Memory dumper for the **Lost Ark** game client that extracts Unreal Engine SDK structures and offsets. Scans and dumps game classes, entity definitions, and memory layouts to support reverse engineering of the UE-based MMORPG client. (source: wiki/sources/descriptions/gmh5225__LostArkDumper.md)
