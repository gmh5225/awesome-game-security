# ManyTypes

[[x64dbg]] type-parsing plugin that surfaces Windows types for live type/structure work during debugging. Aimed at game hackers and reverse engineers reconstructing memory layouts beyond stock debugger type views. (source: wiki/sources/descriptions/notpidgey__ManyTypes.md)

Description framing also covers advanced data-type detection, structure-member identification, and pointer-chain resolution for game-memory RE—adjacent to Cheat Engine–style structure discovery, but the curated README places it in the x64dbg Plugins lane. (source: wiki/sources/descriptions/notpidgey__ManyTypes.md)
