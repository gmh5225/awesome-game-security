# rom-weaver

Local-first toolkit for **ROM images and disc formats** built on a shared Rust core delivered as a native CLI and as a threaded WASM build inside an offline React PWA—files stay on the user's machine. Inspects, extracts, compresses, applies or creates patches across 21 formats (IPS, BPS, UPS, xdelta/VCDIFF, PPF, Dreamcast DCP), handles ZIP/7z/CHD/RVZ and other containers, and supports checksum verification with header repair, ordered multi-patch chains, **cheat-code baking**, trim/restore, and shareable workflow bundles. Aimed at retro game modders, ROM hackers, and preservationists needing end-to-end patch, verify, and repack pipelines without cloud uploads. (source: wiki/sources/descriptions/rom-weaver__rom-weaver.md)

Retro-console RE lane beside [[openfpga-gbc-cheats-ui]] cheat deployment and [[bizhawk]] RAM-search workflows—not a live-game memory cheat.
