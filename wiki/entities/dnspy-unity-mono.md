# dnSpy-Unity-mono

Patched Unity Mono sources and build tooling used by [[dnspy]] to produce `mono.dll` / `mono-2.0-bdwgc.dll` builds with soft-debugger support enabled. Includes an `umpatcher` helper and guidance for bringing up debugging-enabled Mono runtimes across Unity versions—mainly for reverse engineers and cheat researchers debugging managed Unity games with dnSpy. Listed in the README under **[mono]**. (source: wiki/sources/descriptions/dnSpy__dnSpy-Unity-mono.md)
