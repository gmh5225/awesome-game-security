# Toon

Modular C++ game engine (benjinx/Toon) aimed at quickly building graphics demos. Centers on **driver development**, **OpenGL**, and **Vulkan** in a C/C++ codebase. Useful for game developers, engine programmers, and graphics researchers studying a compact modular engine in the README **Game Engine → Source** lane—not a cheat, dumper, or anti-cheat artifact. (source: wiki/sources/descriptions/benjinx__Toon.md)

Sits in the modular OSS engine-source lane beside multi-API stacks such as [[campfire]], [[nebula]], and [[lumos]] for graphics-backend and demo-scene architecture study.
