# Sky-CotL-Scripts

**Sky-CotL-Scripts** (thatskymod/Sky-CotL-Scripts) is a curated hub for modifying and researching **Sky: Children of the Light** on Android and PC. It bundles **GameGuardian Lua** scripts for runtime memory editing (teleports, map coordinates, cosmetics, winged light, speed/FPS tweaks), **Canvas** Android mod-loader documentation, native helpers such as libTSM, and APK tooling for app cloning and virtual multi-account spaces. PC-side material includes a **Frida JavaScript** hook for intercepting the game’s HTTP traffic during analysis, plus legacy Lua with documented offsets and notes on server-side outfit validation and mod safety. (source: wiki/sources/descriptions/thatskymod__Sky-CotL-Scripts.md)

Targets reverse engineers and security researchers studying live-service client behavior, memory layout, and anti-abuse limits—not a single shipped cheat binary.
