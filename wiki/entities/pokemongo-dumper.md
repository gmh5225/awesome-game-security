# pokemongo-dumper

**Pokemon GO** Unity **IL2CPP** dumper (gmh5225; C# and C/C++). Extracts type/method metadata from the mobile client for reverse engineers studying Niantic’s Unity IL2CPP build in the cheat / game:pokemongo lane. (source: wiki/sources/descriptions/gmh5225__PokemonGoDumper.md)

Complements generic [[il2cpp]] dump tooling such as [[il2cppdumper]], live Frida harvesters such as [[frida-il2cpp-datacollector]], and mobile Unity RE workflows on [[overviews/mobile-security]].
