# ida-gameguard-str-dec

IDA Pro plugin (Python) focused on **nProtect GameGuard** string decryption inside protected game client binaries. Aimed at game security researchers and reverse engineers studying offensive modding workflows in the Cheat → IDA Plugins lane. (source: wiki/sources/descriptions/crtdll__ida-gameguard-str-dec.md)

Scoped to GameGuard string recovery—not a general AC bypass or unpacker.
