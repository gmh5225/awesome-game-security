# ProcessInjection

C# **process injection toolkit** with multiple execution techniques in one command-line program (3xpl01tc0d3r). Implements vanilla injection, DLL injection, process hollowing, APC queue injection, and KernelCallbackTable injection. Supports **P/Invoke**, **D/Invoke**, direct and indirect syscalls, multiple shellcode input formats, optional encryption, and parent PID spoofing. Primary use: offensive security research, detection-engineering validation, and controlled lab analysis of injection tradecraft. (source: wiki/sources/descriptions/3xpl01tc0d3r__ProcessInjection.md)

README lane: **Various process injection techniques** — unified C# CLI for multi-method inject + syscall/evasion option study.
