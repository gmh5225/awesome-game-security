# Korok

**Korok** (KorokEngine/Korok) is a lightweight cross-platform **2D game engine** with a component-based architecture. Reusable modules cover animation, rendering, assets, audio, and gameplay systems. The codebase is primarily **Go**, following a compact package-oriented design inspired by modern engine architecture ideas, with documentation and sample projects for quick onboarding. (source: wiki/sources/descriptions/KorokEngine__Korok.md)

Aimed at game developers and engine researchers who want a small open-source framework for 2D game creation — in the Game Engine / source lane, not a cheat or anti-cheat artifact. Sits beside other lightweight OSS 2D engines such as [[torque2d]], [[love]], and [[bulllord-engine]]. (source: wiki/sources/descriptions/KorokEngine__Korok.md)
