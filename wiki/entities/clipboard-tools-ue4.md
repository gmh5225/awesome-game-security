# Clipboard Tools UE4

Lightweight UE4 plugin that copies supplied string arguments to the system clipboard and reports the characters written. Implemented as a C++ Unreal Engine module with packaged binaries and plugin metadata targeting UE4.27. Useful for in-engine development tooling and debugging pipelines that need fast text transfer during testing or scripting. (source: wiki/sources/descriptions/aoharudesu__Clipboard_Tools-UE4.md)

## Capabilities

- Copy a supplied string argument to the OS clipboard from in-engine workflows
- Echo or output the copied character data for verification
- UE4.27-oriented plugin packaging (binaries + plugin descriptor)

Primary audience: Unreal Engine developers and technical artists wiring quick clipboard output into editor utilities, automation, or debug scripts—not an anti-cheat or offensive security artifact.
