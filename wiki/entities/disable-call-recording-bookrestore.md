# Disable Call Recording BookRestore

iOS utility that uses the **bl_sbx** file-exploit primitive to suppress call-recording notification sounds by replacing system audio assets, enabling silent call recording without the audible alert tone Apple plays when recording is active. Listed under Cheat / iOS file explorer in the awesome-game-security catalog. (source: wiki/sources/descriptions/Nirad-Maharaj__Disable-Call-Recording-BookRestore-.md)

The README entry describes a **non-jailbreak** file-exploit workflow, while the upstream description text references **jailbroken** device context—treat platform requirements as version- and exploit-chain-dependent until verified on target iOS builds.
