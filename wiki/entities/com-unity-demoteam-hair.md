# com.unity.demoteam.hair

Integrated Unity package for **authoring, importing, simulating, and rendering strand-based hair**. Supports Alembic groom import, procedural generation, GPU-driven simulation constraints, hierarchical LOD, and rendering across Built-in, URP, and HDRP pipelines. Combines C# editor/runtime systems with shader code for real-time performance—aimed at advanced character rendering, digital-human production, and real-time graphics research in the Game Engine / Plugins:Unity lane. (source: wiki/sources/descriptions/Unity-Technologies__com.unity.demoteam.hair.md)

Complements other Unity character-graphics samples ([[unity-vrchat-template]], [[the-seed-link-future]]), Unreal secondary-motion plugins such as [[kawaii-physics]], and shader fundamentals ([[3d-game-shaders-for-beginners]]) for studying strand rendering and GPU simulation surfaces.
