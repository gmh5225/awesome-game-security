# Bulllord Engine

Bulllord Engine is a lightweight cross-platform C game engine with a modular architecture spanning rendering, audio, physics, and asset management. External libraries cover ASTC texture compression, FastLZ compression, and FreeType font rendering. The codebase targets game engine developers and researchers studying compact, C-based cross-platform engine design. (source: wiki/sources/descriptions/MarilynDafa__Bulllord-Engine.md)

Sits in the Game Engine / source lane—useful for studying minimal-footprint pure-C engine structure rather than as a cheat or anti-cheat artifact.
