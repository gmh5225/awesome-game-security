# Unity Markdown Viewer

Zero-setup markdown viewer plugin for the Unity Editor: preview `.md` files in-project without extra configuration. Listed under Game Engine / Plugins:Unity; aimed at game developers, engine programmers, and graphics researchers documenting or reading markdown inside Unity workflows. (source: wiki/sources/descriptions/gwaredd__UnityMarkdownViewer.md)

Complements editor automation such as [[unicli]] and [[unity-mcp]] when the task is in-editor documentation preview rather than CLI build loops or MCP agent bridges. Distinct from runtime RE tooling such as [[unityexplorer]].
