# fortnite-offsets (Android1337)

Fortnite **memory offset collection** for cheat and reverse-engineering tooling (Android1337; cheat / game:fortnite `[Offset]`). The curated list entry documents an offset dump in the Fortnite game-cheat research category; the original GitHub repository is no longer available, but the listing remains useful as a pointer for researchers tracking offensive memory-layout workflows. (source: wiki/sources/descriptions/Android1337__Fortnite-Offsets.md)

Distinct from the gmh5225 [[fortnite-offsets]] UE4 SDK structure tables, JSON feeds such as [[trydos-fortnite-offsets]], and combined offset+signature maintenance repos such as [[fortnite-offsets-and-sigs]]; scoped to a historical Android1337 offset-dump reference in the same cheat / game:fortnite lane.
