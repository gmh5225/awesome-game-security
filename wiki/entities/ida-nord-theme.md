# ida-nord-theme

IDA Pro color theme inspired by the Nord palette. Applies the Nord arctic scheme across disassembly, hex, graph, and editor windows for a cohesive dark blue-grey UI—aimed at reverse engineers who prefer Nord aesthetics in long static-analysis sessions. (source: wiki/sources/descriptions/gmh5225__ida-nord-theme.md)

Visual comfort tooling—not an analysis plugin or decompiler extension.
