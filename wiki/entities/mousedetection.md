# MouseDetection

Minimal **Windows proof of concept** (Oliver-1-1) for detecting **mouse movement generated by software rather than hardware**. Native C++ code monitors movement behavior and includes simulated motion APIs for testing. The repository is intentionally small and focused on one detection concept instead of a full anti-cheat stack — useful as a starting point for **input validation research**. README **[Mouse]**. (source: wiki/sources/descriptions/Oliver-1-1__MouseDetection.md)

Sits opposite offensive injection and smoothing samples such as [[human-mouse-movement]], [[mouse-input-injection]], and [[kernel-mouse]], and beside defensive behavioral classifiers such as [[delbot-mouse]] and [[ai-aimbot-detection]].
