# ParadiseBO2

Leaked or archived **Paradise** PS3 **SPRX** (PlayStation relocatable executable) source for *Call of Duty: Black Ops II* (BO2). The snapshot is described as a more recent Paradise BO2 tree than older leaks because it includes **window/UI code** for the in-game mod menu. Useful for game developers, reverse engineers, and tooling builders studying console injected-menu architecture in the Game Develop / source and cheat / console PlayStation lanes. (source: wiki/sources/descriptions/gopro2027__ParadiseBO2.md)
