# kernel-msm-coral

Archived **GrapheneOS** kernel source for **Google Pixel 4** (coral) and **Pixel 4 XL**, based on Qualcomm's **MSM** kernel tree. Includes hardened kernel configurations, Android-specific patches, and security-focused modifications characteristic of GrapheneOS — useful for studying hardened kernel implementations on Qualcomm Snapdragon devices rather than stock OEM trees. Listed under Cheat / Android Kernel Source for Pixel 4/4XL/4a. (source: wiki/sources/descriptions/GrapheneOS-Archive__kernel_msm-coral.md)

Complements peer Pixel 4 (coral) kernel sources such as [[kernelsu-pixel4xl]] (msm-floral + KernelSU) and upstream Android kernel references such as [[kernel-common]]. Out-of-tree driver and LKM workflows such as [[compile-android-driver]] and [[android-kernel-hacking-toolkit]] often build against device-specific trees like this.
