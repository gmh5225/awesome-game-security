# Apex-Mizu-Base

**Apex-Mizu-Base** (NaiJii/Apex-Mizu-Base) is an **internal Apex Legends cheat base** intended as a starting framework for feature development. Written mostly in **C++** for **Visual Studio** on Windows with **DirectX** integration, it provides hooking scaffolding, game and entity abstractions, math and utility types, and an **ImGui**-based menu layer. Aimed at cheat development practice and reverse engineering experimentation in FPS game contexts under [[easy-anti-cheat]]. (source: wiki/sources/descriptions/NaiJii__Apex-Mizu-Base.md)

Sits in the Apex Legends internal lane beside full-cheat samples such as [[apex-full-cheat]] and scaffold-style internal bases such as [[csgo-main-internal]], as a modular starting point rather than a finished feature stack.
