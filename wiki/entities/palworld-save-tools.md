# palworld-save-tools

Python toolkit for reading, converting, and editing Palworld save files. Parses the title's custom **GVAS** format, converts between binary and JSON, and supports edits to player data, Pal stats, inventory contents, and world state—including compression, custom property serialization, and UE5 save structures. Aimed at players, modders, and server administrators doing save manipulation and migration in the cheat / game:palworld [Save] lane. (source: wiki/sources/descriptions/cheahjs__palworld-save-tools.md)

Complements title-specific Palworld tooling such as [[palworldsaved]] (rendering + editor), [[palworld-modding-kit]] (UE5 modding scaffold), [[palworld-helper]] (Python modding helper), [[docker-palworld-dedicated-server]] (containerized dedicated server), and [[palworld-rcon]] (Source RCON admin).
