# d810

**d810** (CKCat) is a **Python IDA Pro plugin** that deobfuscates code **at decompilation time** by rewriting **Hex-Rays microcode**. It integrates into normal reverse-engineering workflows with **configurable rule sets** and an extensible framework so researchers can add new deobfuscation logic without heavily modifying core code. Primary audience: **malware** and **game-security** analysts who need clearer pseudocode from heavily obfuscated binaries. (source: wiki/sources/descriptions/CKCat__d810.md)

Original microcode deobfuscation framework; successor efforts include [[d810-ng]]. Complements other Hex-Rays microcode plugins such as [[hex-rays-deob]], [[hrtng]], and [[emotet-deobfuscator]] for CFF and expression cleanup inside IDA.
