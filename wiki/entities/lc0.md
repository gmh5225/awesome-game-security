# lc0

**Leela Chess Zero (Lc0)** — C++ neural-network chess engine using deep reinforcement learning. Combines Monte Carlo Tree Search guided by a network trained through self-play, following DeepMind's AlphaZero approach. Supports CUDA, cuDNN, and OpenCL backends for GPU-accelerated position evaluation. Aimed at chess-engine developers, AI researchers, and competitive players studying neural game AI. (source: wiki/sources/descriptions/gmh5225__lc0.md)
