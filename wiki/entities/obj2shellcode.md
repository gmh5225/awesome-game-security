# obj2shellcode

C++ **shellcode generation framework** centered on object-to-shellcode conversion workflows. Listed under Anti Cheat → shellcode engine & tricks; supports modding, memory analysis, and debugging use cases for anti-cheat engineers and defensive researchers studying shellcode construction rather than shipping as an AC product. (source: wiki/sources/descriptions/jseclab__obj2shellcode.md)

Complements Windows shellcode build frameworks such as [[scfw]], C++ shellcode factory tooling such as [[shellcode-factory]], and bad-byte banishment such as [[byvalver]].
