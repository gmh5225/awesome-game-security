# Unreal-Engine-Guide

Curated guide to Unreal Engine applications, libraries, and tools aimed at making developers more efficient on the engine—not a cheat, dumper, or anti-cheat artifact. Useful for game developers, engine programmers, and graphics researchers working in the Game Engine / Unreal guide lane, including those who later pivot to [[unreal-object-model]] SDK workflows or security-relevant UE surfaces. (source: wiki/sources/descriptions/mikeroyal__Unreal-Engine-Guide.md)

Sits beside other Unreal learning indexes such as [[ue4-tutorials]], [[unreal-development-guides-and-tips]], [[ue-interview-cheat-sheet]], and cross-engine lists such as [[awesome-game-engine-dev]]. For Epic-style C++ formatting consistency, [[ue-clang-format]] provides a Clang-Format preset and VS Code setup guidance. (source: wiki/sources/descriptions/TensorWorks__UE-Clang-Format.md) For team-wide naming, asset organization, and pipeline standards, [[ue5-style-guide]] documents enforceable conventions and linting guidance for large Unreal projects. (source: wiki/sources/descriptions/Allar__ue5-style-guide.md)
