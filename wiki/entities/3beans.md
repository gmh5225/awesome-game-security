# 3Beans

Low-level (LLE) Nintendo 3DS emulator in C++ with ARM9/ARM11 and Teak DSP interpreter cores, HLE/LLE audio, hardware-accelerated GPU rendering, and cross-platform support for Windows, macOS, Linux, and Android. Boots the full 3DS OS from user-supplied boot9/boot11/NAND dumps and supports both software and hardware GPU rendering paths — useful for studying 3DS hardware internals, firmware boot chains, and GPU behavior in the README `Nintendo 3DS` lane. (source: wiki/sources/descriptions/Hydr8gon__3Beans.md)
