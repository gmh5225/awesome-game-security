# GamesTestAutomationExample

Unity-focused examples and helper libraries for **mobile game test automation**. Combines Appium and device tooling with in-game instrumentation logs to validate behavior without relying only on fragile image matching. Ships sample Unity assets, scripts, and test-side workflows for Android and iOS style pipelines. Aimed at game QA engineers and developers building automated testing practices for Unity projects.
