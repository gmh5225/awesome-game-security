# mcp-server-idapro

MCP server that bridges AI assistants with IDA Pro — the disassembler and debugger used for reverse-engineering software. Targets game developers, reverse engineers, and tooling builders in the Game Develop / MCP server lane. (source: wiki/sources/descriptions/fdrechsler__mcp-server-idapro.md)

Peers with other IDA agent bridges such as [[ida-pro-mcp]] (full IDAPython MCP), [[ida-mcp-server-plugin]] (disasm/decompile/xrefs MCP plugin), and [[iida-mcp]] (multi-instance kernel-assisted MCP). Complements Ghidra-side agent RE via [[ghidra-headless-mcp]] and Binary Ninja MCP via [[binary-ninja-mcp]].
