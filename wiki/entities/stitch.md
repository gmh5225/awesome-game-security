# stitch

C++ **binary rewriting and obfuscation framework** for **x86** code. Provides function relocation, global reference patching, complex obfuscation transformations, and branch handling; CMake-built examples demonstrate various code manipulation techniques. Mainly useful for binary-protection researchers and reverse engineers studying x86 code obfuscation and binary rewriting methodologies. (source: wiki/sources/descriptions/badhive__stitch.md)

Useful as an x86 bin2bin rewrite reference alongside PE post-compile obfuscators such as [[alcatraz]] and [[binprotect]], and import-table misdirection tools such as [[call-obfuscator]].
