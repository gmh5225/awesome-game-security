# Source2Dumps

Aggregated **Source 2 engine reference dumps** (anarh1st47; C++ headers + text listings) covering netvars, interfaces, and class IDs for multiple Valve titles—Dota 2, Artifact variants, Half-Life: Alyx, and Sandbox environments. Structured reference data rather than application code; used for Source 2 reverse engineering, offset tracking, and game-security tooling workflows. (source: wiki/sources/descriptions/anarh1st47__Source2Dumps.md)

Complements SDK generators such as [[source2gen]] / [[source2sdk]], live-process schema tools such as [[dezlock-dump]], and title-specific offset feeds such as [[dota2dumped]] / [[cs2-offsets]] as a pre-generated multi-game dump lane.
