# cs2-cheat-base

Base framework (gmh5225) for building Counter-Strike 2 internal cheats. Provides core **Source 2 SDK structures** and **hook infrastructure**, plus **offset definitions**, **entity class wrappers**, and **rendering setup** for developing CS2 game modifications—useful as upstream scaffolding beside feature-complete samples such as [[cs2-cheat]] and header kits such as [[cs2-sdk]]. (source: wiki/sources/descriptions/gmh5225__CS2-Cheat-Base.md)
