# ce_speed_hack

Compact **C++ Cheat Engine–style speed hack** by IamSanjid. Demonstrates changing perceived game timing by hooking relevant APIs with **Microsoft Detours** — focused on core hooking logic rather than a full cheat framework. Mainly useful for learners studying **time manipulation** and basic user-mode game hacking techniques. (source: wiki/sources/descriptions/IamSanjid__ce_speed_hack.md)
