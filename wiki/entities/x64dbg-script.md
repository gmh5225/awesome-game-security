# x64dbgScript

Scripting support resources and examples for extending [[x64dbg]] debugger workflows. Ships sample scripts plus helper Python code for exporting function labels and comments from IDA into live debugger sessions. Demonstrates practical automation patterns—multi-step execution control, global variable usage, and instruction-sequence searching—for reverse engineers who want to speed up repetitive analysis in game and binary security research. (source: wiki/sources/descriptions/Ahmadmansoor__x64dbgScript.md)

Not an in-process plugin runtime like [[x64dbg-playtime]] (Lua) or [[x64dbgpython]] (Python 3)—a curated script/example collection with IDA→debugger label export helpers.
