# WSAPatch

C++ patcher for **Windows Subsystem for Android (WSA)** MSIX packages that enables WSA on unsupported **Windows 10** builds and older **Windows 11** versions. Patches WSA binaries to bypass OS version checks, disable **Hyper-V** requirement enforcement, and apply compatibility fixes so users and developers can sideload Android apps on a wider range of Windows hosts. Sits in the README `WSA` lane beside sideload tooling such as [[win11-apk-installer]] and rooted builds such as [[magiskonwsalocal]]. (source: wiki/sources/descriptions/cinit__WSAPatch.md)
