# btop

Interactive **terminal resource monitor** for CPU, memory, disks, network, processes, and optional GPU metrics. Written in modern C++ with a fast TUI, mouse support, process filtering, configurable views, and theme customization. Cross-platform on Linux, macOS, and BSD with flexible build and packaging options. Aimed at developers, operators, and security engineers who need real-time host telemetry in terminal environments—not an in-process game profiler. (source: wiki/sources/descriptions/aristocratos__btop.md)

README tag: **Performance Monitor** — complements Game Testing frame profilers such as [[tracy]] and [[optick]] with whole-host resource visibility during builds, server load tests, and cheat/AC research sessions.
