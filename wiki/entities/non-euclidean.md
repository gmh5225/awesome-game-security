# NonEuclidean

Windows rendering demo engine exploring non-Euclidean space in real time. Written in C++ with OpenGL; demonstrates custom room transitions, camera movement, and experimental geometric rendering behavior. Focused on graphics and engine experimentation rather than anti-cheat bypass, but useful for understanding low-level rendering pipelines that often matter in game security tooling. Targets developers and technical researchers interested in advanced game rendering concepts. (source: wiki/sources/descriptions/HackerPoet__NonEuclidean.md)

Sits beside other OpenGL engine demos and rendering study surfaces such as [[learnopengl]], [[gltut]], [[exengine]], and [[game-engine-from-scratch]].
