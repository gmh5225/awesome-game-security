# TIGR

Tiny cross-platform graphics library with a unified API for Windows, macOS, Linux, iOS, and Android. Core is a simple framebuffer library—mainly useful for engine and tooling developers working on asset pipelines in the Image Codec area. (source: wiki/sources/descriptions/erkkah__tigr.md)

Sits in the README Image Codec lane alongside soft-raster helpers such as [[olive-c]] and pixels tooling such as [[kit]]—a portable framebuffer abstraction rather than a GPU Present hook or cheat overlay.
