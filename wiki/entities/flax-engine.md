# Flax Engine

**Flax Engine** (FlaxEngine/FlaxEngine) is a full-source modern **3D game engine and editor** for high-performance game development. Architecture mixes **C++** native rendering and platform layers with **C#** managed scripting and tooling workflows. The repository ships engine runtime, editor, build scripts, and cross-platform support for **Windows, Linux, and macOS** using **.NET** and **Vulkan**. Primary audience is game developers and engine programmers who need deep source-level control and extensibility. (source: wiki/sources/descriptions/FlaxEngine__FlaxEngine.md)

Not a cheat or anti-cheat artifact—a substantial OSS engine tree for studying editor/runtime boundaries, managed/native interop, and Vulkan-backed rendering pipelines.
