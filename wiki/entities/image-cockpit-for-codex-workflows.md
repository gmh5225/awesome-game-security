# image-cockpit-for-codex-workflows

Local cockpit for Codex imagegen workflows: generate pixel art, apply region-based edits, and turn selected assets into animation frames and sprite sheets. Work is handed off through a codex-handoff inbox/outbox pattern—no direct OpenAI API calls from the workspace itself. (source: wiki/sources/descriptions/dreiachse-cyber__image-cockpit-for-codex-workflows.md)

Targets game developers, reverse engineers, and tooling builders in the README **Game Develop → AI Agents** lane—agent-driven 2D sprite pipelines rather than in-engine hooks or anti-cheat surfaces.
