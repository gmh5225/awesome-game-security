# simple_ac_internal_cheat

Educational C++20 AssaultCube internal DLL for studying reverse engineering, runtime memory, and Windows internals in a controlled local environment. Loads into the x86 game process with an in-process Dear ImGui overlay (aimbot, ESP / world-to-screen), runtime local-player controls (health, armor, ammo, FOV), Microsoft Detours for DirectX rendering hooks, and version-dependent offsets / pointer chains—aimed at learners rather than competitive multiplayer cheating.
