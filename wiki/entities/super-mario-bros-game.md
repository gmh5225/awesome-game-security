# super-mario-bros-game

C++ remake of classic Super Mario Bros with original-inspired and custom levels. Built with SDL2, SDL_image, and SDL_mixer as a Visual Studio game project with art and audio assets. Demonstrates core 2D platformer systems—rendering, level flow, and gameplay logic—in a standalone desktop implementation. Primary use case is game development learning and SDL-based engine practice, not security research. (source: wiki/sources/descriptions/Luxon98__Super-Mario-Bros-game.md)
