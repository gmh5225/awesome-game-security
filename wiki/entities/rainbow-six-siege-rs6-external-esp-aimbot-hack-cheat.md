# Rainbow-Six-Siege-Rs6-External-Esp-Aimbot-Hack-Cheat

Leaked **Rainbow Six Siege** external cheat source (gmh5225) providing **ESP** and **aimbot** features. The implementation limits input manipulation to a **`WndProc` hook** on mouse movement and keystrokes, avoiding broader injection/hook vectors that are more commonly flagged by anti-cheat. Framed for game security researchers and reverse engineers studying offensive techniques in the cheat / game:r6 lane under [[battleye]].
