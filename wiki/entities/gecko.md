# gecko

Rust-based **Game Boy** and **Game Boy Color** emulator with cycle-accurate CPU, PPU, and APU emulation, wgpu-based rendering, and a desktop GUI for game library management and playback. (source: wiki/sources/descriptions/ioncodes__gecko.md)

README lists the repo under `GameCube/Wii` with a GameCube/Wii blurb; the upstream description identifies GB/GBC handheld emulation—peer to [[kevboy]] and [[feather-gb]] in the `Game Boy` lane for emulator architecture and retro-hardware study rather than GC/Wii binary-translation research.
