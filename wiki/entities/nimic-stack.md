# NimicStack

**NimicStack** is a **pure Nim** implementation of **call stack spoofing** that forges thread stacks to **mimic legitimate programs**. The project implements the PoC lineage shared by **WithSecure Labs** for game-security researchers and reverse engineers studying offensive cheat / spoof-stack tradecraft in the `Cheat > Spoof Stack` lane.
