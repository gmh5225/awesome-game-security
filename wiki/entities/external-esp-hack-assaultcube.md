# external-esp-hack-assaultcube

Beginner-oriented **external ESP** sample for AssaultCube from gmh5225. Reads player entity data from the game process externally (no injection) and draws player boxes, names, and health via a **GDI overlay** window. AssaultCube's lightweight FPS layout and simple memory structure make it a common first target for external read-process-memory (RPM) and overlay rendering practice.
