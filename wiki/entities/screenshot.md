# ScreenShot

Windows screen capture utility (gmh5225) that implements and compares multiple screenshot capture methods—**GDI BitBlt**, **DXGI Desktop Duplication**, **PrintWindow**, and **DWM thumbnail** capture. Useful for anti-cheat developers and security researchers evaluating how each path handles overlay content, hardware-accelerated windows, and interaction with screenshot-based anti-cheat detection. (source: wiki/sources/descriptions/gmh5225__ScreenShot.md)
