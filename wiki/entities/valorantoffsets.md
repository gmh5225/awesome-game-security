# valorantoffsets

Lightweight **Valorant offset pack** (10HEAD; cheat / game:valorant `[Offset]`). Tracks memory and function offsets for VALORANT as C/C++-style constants covering engine functions and gameplay-related structures. The repository stays intentionally minimal and focused on quick updates after game patches—primarily for reverse engineering and maintaining external analysis or automation tools that depend on current layout constants under [[vanguard]]. (source: wiki/sources/descriptions/10HEAD__ValorantOffsets.md)

Sits in the same per-title Valorant offset-feed lane as [[valorant-offsets]], [[valorant-externals]], and [[valorant-offsets-autoupdater]], but scoped to a compact constant pack rather than a full SDK, dump framework, or automated fetch pipeline.
