# syser

Windows x86/x64 debugger written primarily in C/C++, centered on reverse engineering, plugin development, and modding. Aimed at game-security researchers and reverse engineers studying offensive techniques in the cheat / debugging lane. (source: wiki/sources/descriptions/marakew__syser.md)

User-mode debugger in the same Windows RE tooling bucket as [[x64dbg]], WinDbg, and Cheat Engine—not a static disassembler or kernel debugger.
