# Source2Gen

SDK generator (praydog) that emits C++ headers for many exposed Source 2 classes and enumerators. Useful for game-security researchers and reverse engineers studying offensive techniques in the cheat / game engine explorer:source lane. (source: wiki/sources/descriptions/praydog__Source2Gen.md)

Complements Source 1 header dumps such as [[sdk]] and CS2 offset/netvar feeds such as [[cs2-offsets]] / [[cs2-offsets-ro0ti]] in the Source → Source 2 SDK CodeGen path.
