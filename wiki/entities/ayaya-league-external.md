# ayaya-league-external

Node.js **external script platform** for League of Legends — **AyayaLeague** supports custom user scripts out-of-process (gmh5225; cheat / game:lol). Aimed at game security researchers and reverse engineers studying offensive techniques under [[vanguard]]-protected Riot clients. (source: wiki/sources/descriptions/gmh5225__ayaya-league-external.md)

Sits beside [[league-base]], [[hh-lol-prophet]], and [[frank]] in the LoL offensive research lane, but as a Node.js scripting substrate for external automation rather than C/C++ cheat bases, Go modding samples, or JavaScript launcher clients.
