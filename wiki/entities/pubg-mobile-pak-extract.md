# pubg-mobile-pak-extract

PUBG Mobile pak archive extraction tool (halloweeks). Targets client builds **before the 1.1.0 update**; post-update encryption algorithm changes are not currently supported. Useful for game security researchers and reverse engineers studying offensive asset workflows in the cheat / game:pubgm lane.
