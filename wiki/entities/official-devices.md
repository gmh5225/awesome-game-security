# PixelOS official_devices

**Metadata and documentation repository** for officially supported **PixelOS** devices (PixelOS-AOSP). Publishes device lists, API data, changelog-style notes, and release communication templates primarily as **Markdown and JSON**. Helps maintainers track supported brands/models and standardize build/release presentation; useful as an **authoritative support matrix** for PixelOS maintainers and users. README lane `[PixelOS device trees]`. (source: wiki/sources/descriptions/PixelOS-AOSP__official_devices.md)

Sits in the Cheat Magisk / Android ROM–root lane beside curated ROM references such as [[android-rom-list]], per-device ROM trees such as [[device-xiaomi-mondrian]], and Pixel flashing/root tooling such as [[pixel-flasher]].
