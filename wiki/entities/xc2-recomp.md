# xc2-recomp

**XC2 Recomp** ([AksharDP/xc2-recomp](https://github.com/AksharDP/xc2-recomp)) statically recompiles *Xenoblade Chronicles 2* (Nintendo Switch **ARM64**) to native **Windows x86-64** with a **Vulkan** renderer. It is a **fork of [[xcx-recomp]]** (XCX Recomp / TotK Recomp lineage). Users supply their own **NSP** dumps and keys; the repository ships no game assets. (source: wiki/sources/README-categories.md)

## Research use

Preservation-oriented **Cheat / Source** static binary translation—same evidence discipline as [[totk-pc-recomp]] and [[xcx-recomp]] via [[static-runtime-evidence]]: separate lifted guest code from reimplemented Horizon/NVN host services before citing renderer fidelity.
