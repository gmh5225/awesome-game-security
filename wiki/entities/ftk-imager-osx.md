# FTK Imager OSX

macOS-focused package and usage guide for running a command-line forensic disk imaging tool. Centers on acquiring drive images, splitting outputs, and verifying integrity with hash checks such as MD5 and optional SHA1. Includes executable usage examples and options for E01/SMART formats, fragmentation, compression, and evidence metadata fields. Targets digital forensics practitioners and incident responders who need imaging workflows on macOS. (source: wiki/sources/descriptions/MrMugiwara__FTK-imager-OSX.md)

Complements Windows-centric acquisition tools such as [[dumpit-mirror]] and offline disk analysis via [[file-recovery-tool]] / [[ntfstool]] in the Information System & Forensics lane, and pairs with live triage collectors like [[dfirtriage]] when investigations span mixed host environments.
