# Fortnite Offset Dumper

Fortnite **offset dumper** (gmh5225; cheat / game:fortnite `[Offset & Dump]`) that extracts **current memory offsets and class layouts** from the running game process. Generates **structured offset data** with regex-cleaned class names and **hierarchical offset definitions** for external and internal cheat tooling—automating per-patch layout refresh instead of hand-maintaining static tables. Aimed at game security researchers studying Fortnite UE4 memory-layout churn and offset-based cheat workflows. (source: wiki/sources/descriptions/gmh5225__Fortnite-Offset-dumper.md)

Complements static offset collections such as [[fortnite-offsets]], signature sets such as [[fortnite-sigs]], and general-purpose dumpers such as [[gh-offset-dumper]] and [[lol-offset-dumper]].
