# Chess Cheater

**Chess Cheater** (Coding-With-SouRav/Chess-Cheater) is a Windows external overlay that captures the live chess board via **OpenCV** and **mss** screen grabs, then queries a local **Stockfish** UCI engine for move suggestions. It sits in the README **Game:Chess** lane as a zero-memory visual-assist pattern—board state inferred from pixels rather than client injection. (source: wiki/sources/README-categories.md)
