# htw

**Hack The Web** ([Entkenntnis/htw](https://github.com/Entkenntnis/htw)) is a self-hostable browser game that teaches web security through hands-on hacking puzzles and tasks. The stack is **Node.js**; operators run their own instance for local or classroom practice. (source: wiki/sources/README-categories.md)

## Research use

Educational **Cheat / Guide** material for web-centric offensive technique study—not live game anti-cheat or kernel security. Pair with structured curricula such as [[re-dojo]] and [[intro-to-gamehacking]] when routing learners from browser labs to native game RE.
