# Minetest

Open-source voxel game engine (**Luanti**, formerly Minetest) with a Lua modding API. Uses Irrlicht/SDL2 rendering, procedural world generation, and multiplayer networking on Linux, Windows, macOS, and Android. Ships a full content-creation framework: node definitions, entity systems, inventory management, and formspec-based UIs. (source: wiki/sources/descriptions/minetest__minetest.md)

Listed under Game Engine / source — useful for studying voxel engine architecture, Lua-driven gameplay scripting, and cross-platform OSS engine trees rather than as a cheat or anti-cheat artifact.
