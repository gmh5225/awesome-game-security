# Cozinha Loader

C++ **CS:GO cheat loader** (b1scoito) that downloads cheat modules from a remote server and injects them via **process hollowing** or **manual mapping**. Includes **anti-debugging checks**, **string encryption**, and **import obfuscation** to evade anti-cheat scanning—useful for game-security researchers studying cheat-loader anti-detection techniques and injection workflows. (source: wiki/sources/descriptions/b1scoito__cozinha_loader.md)
