# pubg-public

C++ external game assistance codebase focused on desktop **PUBG** (K-cazb). Implements offset-driven entity parsing, bone and camera math, **ESP** rendering, and aim automation, plus decryption helpers, **driver-assisted memory access**, and **DirectX overlay** components. Positioned mainly as an educational reference for game-hacking methods and anti-cheat analysis. (source: wiki/sources/descriptions/K-cazb__pubg-public.md)

Useful for game security researchers studying external cheat architecture on BattlEye-protected PUBG—complementing simpler external samples such as [[pubg-external-cheat]], UE SDK demos such as [[pubg-demo]], and kernel-assisted externals such as [[valthrun-pubg]] and [[pubg-dx]].
