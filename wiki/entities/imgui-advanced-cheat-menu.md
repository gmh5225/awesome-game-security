# ImGUI Advanced Cheat Menu

**ImGui-based cheat menu framework** for Windows (RequestFX). Ships modular feature components—ESP, aim assist, recoil control, HUD modules, and hotkey-driven settings panels—organized as a starter template for building and structuring game cheat user interfaces. Implementation is primarily **C++** with **SFML** as the rendering backend, custom ImGui widgets, and in-memory font loading. README tag: `[Imgui Menu]`. (source: wiki/sources/descriptions/RequestFX__ImGUI-Advanced-Cheat-Menu.md)

Useful when prototyping cheat menu layout and feature toggles in a standalone SFML window before wiring the same ImGui panels into an in-process Present hook or external layered overlay.
