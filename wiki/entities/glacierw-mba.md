# GlacierW MBA (Malware Behavior Analyzer)

**MBA** (Malware Behavior Analyzer) — a **QEMU-based whole-system dynamic binary analysis** framework. Extends the full QEMU emulator with added instrumentation modules for malware analysis: memory forensics, API tracing, and behavioral monitoring across **Windows and Linux** guests. Targets malware analysts and security researchers performing whole-system dynamic analysis and introspection. (source: wiki/sources/descriptions/GlacierW__MBA.md)

Not the same project as [[mba]] (SynthesisLab GPU Mixed Boolean-Arithmetic simplifier). Sits beside other QEMU whole-system DBI peers such as [[panda]] and [[ispras-qemu]] in the `Cheat > QEMU/KVM/PVE/VBOX` lane.
