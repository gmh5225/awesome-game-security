# binaryninjaplugins

Collection of Binary Ninja architecture plugins (Pusty) for analyzing Java class files, Renesas H8/300 binaries, and Xtensa ELF targets. Written mainly in Python; includes disassembly, instruction decoding, and partial lifting support for custom architectures. The Java-focused module also supports patch-oriented workflows such as NOPing instructions and changing branch logic. Intended for reverse engineers who need fast extension support in Binary Ninja for firmware and bytecode analysis. (source: wiki/sources/descriptions/Pusty__BinaryNinjaPlugins.md)
