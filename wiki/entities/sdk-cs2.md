# SDK CS2

**Generated CS2 SDK header pack** (FrySimpl3; cheat / game:cs2 `[SDK]`) exposing **Source 2 engine types**, **enums**, and **subsystem interfaces** as C++ reference definitions. Headers cover major engine domains including **client**, **rendering**, **networking**, **schema**, **panorama**, **particles**, and **physics**. Content is organized for consumption by external tooling and research code rather than as a runnable cheat scaffold. (source: wiki/sources/descriptions/FrySimpl3__SDK_CS2.md)

Primary use case: **reverse engineering support** and technical groundwork for Counter-Strike 2 analysis tools—typed layouts beside live dumpers such as [[cs2-dumper]] and generated SDK output such as [[cs2-sdk-source2gen]].

Sits beside aggregated CS2 SDK repos such as [[cs2-sdk]], header-only snapshots such as [[counter-strike2-sdk]], and internal hooking scaffolds such as [[cs2-internal-sdk]] as a generated type-reference artifact.
