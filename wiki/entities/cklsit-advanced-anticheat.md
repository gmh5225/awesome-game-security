# AdvancedAntiCheat

Java-based Minecraft server anti-cheat plugin for **Spigot**, **Paper**, and **Purpur** (**1.8.x–1.21.x**). Detects common cheats—fly, speed, KillAura, reach, scaffold, ESP, and related combat and movement abuses—with violation tracking and severity-based automatic bans. (source: wiki/sources/descriptions/cklsit__AdvancedAntiCheat.md)

## Operator features

- Configurable detection modules, messages, and ban actions
- **Client-check** workflow for inspecting suspicious clients
- Player **reporting** with admin notifications
- **Bounty sandbox** for probing detection coverage
- Multi-database backends (**SQLite**, **H2**, **MySQL**, **MongoDB**, **Redis**) for cross-server ban sync under **Velocity** or **BungeeCord**

Targets Minecraft Java server operators enforcing fair play on survival, PvP, and network hosts—in the same Spigot/Paper operator lane as [[dakotaac]], [[windfall-anticheat]], [[avaanticheat]], and [[minecraft-anticheatai]], distinct from the Roblox Luau framework [[advanced-anticheat]] (mastershadow547).
