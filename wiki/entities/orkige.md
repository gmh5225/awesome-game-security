# Orkige

Custom C++20 game engine (origins ~2009–2012; revived for mobile shipping with desktop as the primary development targets). Built with CMake and vcpkg; dual OGRE renderers (classic + Ogre-Next) with SDL3 windowing; Lua-first live scripting with hot-reload during play; ImGui-based editor plus players for macOS, Windows, iOS, Android, and WebAssembly. Systems cover scenes, materials, particles, character/vector animation, GUI, localisation, and save data. (source: wiki/sources/descriptions/orkitec__orkige.md)

Sits in the Game Engine / source lane for developers and graphics researchers studying a C++ core with Lua gameplay and OGRE-backed render surfaces—not a cheat or anti-cheat artifact.
