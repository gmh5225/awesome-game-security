# xbox360-emu

Xbox 360 emulator (C/C++): centers on kernel-level work, modding, and memory analysis for running or studying 360 titles on PC. (source: wiki/sources/descriptions/exjam__xbox360-emu.md)

Useful for console emulator developers and Xbox researchers in the README `Xbox` lane—adjacent to HLE playback via [[xenia]] / [[xenia-mac]], live modded-console patching via [[x360gamehack2025]], executable porting via [[recompiler]], and original-Xbox stacks [[xemu]] / [[xqemu]], but focused on Xbox 360 emulation rather than porting, backup deployment, or earlier-console LLE.
