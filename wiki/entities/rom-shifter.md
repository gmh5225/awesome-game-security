# ROM Shifter

Unified Android application for flashing, backing up, and migrating between custom ROMs on rooted devices. Kotlin and Jetpack Compose frontend with a custom shell backend engine. Capabilities include an automated flash wizard (ordered ZIP flashing and wipes), granular app backup/restore with parallel processing, device data backup (SMS, contacts, Wi-Fi, and related settings), batch APK installation, partition backup and restore, and maintenance utilities such as debloating, systemizing apps, and partition image management. Requires root via Magisk, KernelSU, APatch, or compatible forks. Listed under Cheat / Android. (source: wiki/sources/descriptions/ShivamXD6__ROM-Shifter.md)

Sits in the Android custom-ROM transition lane beside [[pixel-flasher]] (Pixel-focused host flashing), [[android-bootable-recovery-ofrp]] (recovery infrastructure), [[android-rom-list]] (ROM catalog), and [[fox-magisk-module-manager]] (Magisk module lifecycle), with root frameworks [[magisk]], [[kernelsu]], and [[apatch]].
