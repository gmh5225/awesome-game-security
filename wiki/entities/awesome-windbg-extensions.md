# awesome-windbg-extensions

Curated **awesome list** of WinDbg extensions and related debugging resources. Catalogs tools for kernel analysis, incident response, rootkit hunting, memory inspection, and debugger workflow automation. Markdown-focused reference index rather than a standalone software implementation — useful for reverse engineers and game-security analysts who rely on WinDbg plugins for low-level Windows investigation. (source: wiki/sources/descriptions/anhkgg__awesome-windbg-extensions.md)

Link catalog rather than a single extension binary; complements individual WinDbg plugins such as [[windbg-scripts]], [[swishdbgext]], [[twindbg]], [[windbg-decompile-ext]], and [[windbg-extensions]].
