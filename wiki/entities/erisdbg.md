# ErisDbg

C/C++ VT debugger focused on kernel-level work, driver development, and modding for game security researchers and reverse engineers studying offensive techniques in the cheat / debugging area. (source: wiki/sources/descriptions/kkpwn__ErisDbg.md)

Sits in the VT-x hypervisor debugging lane beside hacked-hypervisor test tooling such as [[vt-debuuger]] and experimental Type-2 stacks such as [[hypervisor]] — useful for mapping virtualization-assisted debug and hook surfaces, not a production anti-cheat component.
