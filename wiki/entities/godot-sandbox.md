# godot-sandbox

Godot engine addon that sandboxes mod code so players can extend games without granting full host-process trust. Targets all Godot export platforms and fits the **Game Engine → Plugins:Godot** lane for developers, engine programmers, and graphics researchers building mod-friendly titles. (source: wiki/sources/descriptions/libriscv__godot-sandbox.md)

Complements offensive Godot runtime RE such as [[gddumper]] (Cheat Engine SceneTree/GDScript dump) and authoring MCP such as [[better-godot-mcp]] on the defensive modding / engine-protection side. Cross-engine server-authoritative AC adapters such as [[certael]] integrate at a different layer (signed intents) than in-process sandbox boundaries.
