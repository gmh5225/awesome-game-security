# Free-RASP-Cordova

Talsec freeRASP plugin for Cordova: mobile in-app RASP and application shielding for hybrid Android and iOS apps. TypeScript APIs bridge native Kotlin and Swift components backed by the Talsec runtime, exposing threat callbacks for compromised environments. Detection coverage includes root/jailbreak, hooking frameworks such as [[frida]], untrusted installation sources, app tampering, reverse-engineering attempts, malware and suspicious apps, screen capture protection, bootloader and automation detection, and checks for time or location spoofing and insecure Wi-Fi. Aimed at Cordova developers hardening mobile applications against fraud, repackaging, and runtime attacks—including games and other high-value hybrid apps. (source: wiki/sources/descriptions/talsec__Free-RASP-Cordova.md)

Sits in the mobile RASP / integrity lane alongside Capacitor sibling [[free-rasp-capacitor]], React Native sibling [[free-rasp-reactnative]], Flutter sibling [[free-rasp-flutter]], Unity sibling [[free-rasp-unity-poc]], native iOS [[free-rasp-ios]], Android-only [[droidshield]], and device-fingerprint SDKs [[trustdevice-android]] / [[trustdevice-ios]].
