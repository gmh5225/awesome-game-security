# ue5-mcp

Documentation-first design for connecting AI automation workflows across **Blender** and **Unreal Engine 5**. The repository is mostly Markdown workflow and architecture documents rather than a production MCP server implementation. Outlines planned capabilities such as text-driven scene generation, asset transfer between DCC and UE5, level automation, and Blueprint assistance. Authors note development is paused; primary value is as a reference for cross-tool game pipeline and AI tooling research. Fits Game Develop → MCP for Unreal Engine 5. (source: wiki/sources/descriptions/VedantRGosavi__UE5-MCP.md)

Complements working editor MCP bridges such as [[unreal-mcp]], [[blender-mcp]], and [[unity-mcp]] on the agent-tooling axis; differs by documenting a Blender↔UE5 pipeline concept rather than shipping runnable server code.
