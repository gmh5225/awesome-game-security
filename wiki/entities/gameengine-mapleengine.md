# MapleEngine

Custom **MapleStory**-inspired game engine (**GameEngine-MapleEngine**, gmh5225): a from-scratch engine implementation modeled on MapleStory's client architecture, with rendering, networking, and game-logic systems aimed at 2D side-scrolling MMORPG development. (source: wiki/sources/descriptions/gmh5225__GameEngine-MapleEngine.md)

Useful for game security researchers and private-server developers studying MapleStory-style client engine layout, presentation stacks, and protocol-adjacent game systems—not live official-client anti-cheat bypass tooling.

Complements MapleStory client reimplementations such as [[libremaple-client]], [[maplestory-heavenclient]], and [[winapi-maplestory]]; WZ/asset tooling such as [[wzcomparerr2]] and [[maplestory-packer-modpacker]]; and private-server stacks such as [[maplestory-v83-maplestory-cpp]] and [[maplestory-server]].
