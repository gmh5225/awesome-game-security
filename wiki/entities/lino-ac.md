# LinoAC

Open-source **Spigot/Paper** Minecraft anti-cheat and staff moderation plugin (lino9999/LinoAC) for recent **1.21.x through 26.x** releases. Written in Java; no remote telemetry. README category: Open Source Anti Cheat System / game:minecraft. (source: wiki/sources/descriptions/lino9999__LinoAC.md)

## Detection stack

**PacketEvents** drives packet-rate and timing analysis alongside modular **movement**, **combat**, **block**, and **inventory** heuristics—speed, flight, reach, placement abuse, and fast-break detection. (source: wiki/sources/descriptions/lino9999__LinoAC.md)

## Staff and enforcement

Clickable alerts, violation profiles, **persistent punishment waves**, audit logs, freeze and teleport tools, and a configurable **per-check buffer → punishment pipeline**. Optional Discord webhooks, PlaceholderAPI integration, and a **cancellable event API** for custom enforcement hooks. (source: wiki/sources/descriptions/lino9999__LinoAC.md)

## Positioning

Targets **server operators** and anti-cheat developers who want a lightweight, telemetry-free server-side alternative for securing multiplayer **survival** and **minigame** hosts—comparable modular PacketEvents plugins such as [[bs-anticheat]] and [[virgola-anticheat]], with explicit staff moderation tooling and wave-based sanctions. (source: wiki/sources/descriptions/lino9999__LinoAC.md)
