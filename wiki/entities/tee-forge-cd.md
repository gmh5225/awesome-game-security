# TeeForge-CD

**TeeForge-CD** (mcxiaochenn; Magisk/KernelSU/APatch module; Cheat / Magisk) automates upkeep of Android **TEE-related attestation backends**—Tricky Store, TEESimulator variants, Oh My Keymint app scopes—with optional **bootloader/verified-boot property weakening**, categorized **resetprop** hardening, and user-triggered **Keybox** sync (public pool or local **RKP** chains on supported Qualcomm arm64). Rust core, C native helpers, shell installers, and a Vue/TypeScript on-device WebUI. (source: wiki/sources/descriptions/mcxiaochenn__TeeForge-CD.md)
