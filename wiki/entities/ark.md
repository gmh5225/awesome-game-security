# Ark

**ARK** is a deep learning framework tuned for highly optimized training and inference across **distributed GPUs**. Listed under cheat / Tool; aimed at game security researchers and reverse engineers building offensive ML pipelines (screen-capture object detection, aimbot/triggerbot models) and defensive classifiers without single-GPU bottlenecks. (source: wiki/sources/descriptions/gmh5225__Ark.md)

Infrastructure layer beside title-specific YOLO samples such as [[yolov5-pubg]] and [[maplestory-yolov8-training]]; defensive ML counterparts include [[waldo]], [[deep-learning-anti-cheat-csgo]], and [[ai-aimbot-detection]].
