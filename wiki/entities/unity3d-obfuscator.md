# Unity3D Obfuscator

C# **Unity obfuscator** listed under Anti Cheat → **Game Engine Protection:Unity**. Centers on Unity managed-code protection and debugging-oriented workflows for anti-cheat engineers and defensive security researchers hardening Unity clients against dnSpy/IL-level RE—not a kernel AC product. (source: wiki/sources/descriptions/bmjoy__Unity3D_Obfuscator.md)

Useful as an alternate Unity-specific obfuscation reference beside [[obfuz]], general .NET protectors such as [[obfuscar]] and [[confuserex]], and runtime encryption helpers such as [[usecurity]].
