# Swift-String-Obfuscator

Swift string crypter that keeps plaintext literals out of static binaries—useful for anti-cheat engineers and defensive researchers in the Anti Cheat → Compile Time / String Crypter lane (Swift counterpart to C++/Go xorstr-style tools). Another approach noted in the description is a two-file split. (source: wiki/sources/descriptions/pykaso__Swift-String-Obfuscator.md)

Useful alongside identifier obfuscation such as [[swiftshield]] and C++/Go string crypters such as [[skcrypter]] / [[obfuscatxor]] / [[mystic-xorstr]]; not a full obfuscation engine or packer.
