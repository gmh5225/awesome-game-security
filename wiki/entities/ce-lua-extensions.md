# CE Lua Extensions

**CE Lua Extensions** (Skyrimfus/CE-lua-extensions) is a collection of **Lua extensions and utility scripts** for [[cheat-engine]]. It ships an extension loader plus scripts for breakpoint cleanup, function-caller lookup, template insertion, and interface workflow improvements. Install by placing the package in Cheat Engine's **autorun** directory so features load automatically on startup. (source: wiki/sources/descriptions/Skyrimfus__CE-lua-extensions.md)

Primary use case is speeding up reverse engineering and live memory-analysis workflows for game-security practitioners who rely on CE's Lua scripting surface.
