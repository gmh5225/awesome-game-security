# r2ai

LLM-based reversing assistant integrated with radare2 for interactive binary analysis. Connects language-model tooling to r2 sessions to inspect, explain, and automate reverse-engineering tasks on game and security binaries. (source: wiki/sources/descriptions/radareorg__r2ai.md)

Complements other Cheat → Radare Plugins such as [[radius2]] / [[r2garlic]] / [[r2morph]], and IDA-side LLM assistants like [[aida]] / [[ida-assistant]]—this project targets radare2-native LLM-assisted RE workflows. Supersedes the retired [[r2a]] catalog pointer (same radareorg LLM↔r2 lane). (source: wiki/sources/descriptions/radareorg__r2a.md)
