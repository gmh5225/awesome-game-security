# csf (ekknod)

**csf** is a **Linux SDK generation** project for CS:GO offensive research — C/C++ scaffolding that centers on producing Linux SDK headers and type layouts for game-security researchers and reverse engineers studying cheat / game:csgo techniques. (source: wiki/sources/descriptions/ekknod__csf.md)

It sits in the Source 1 SDK lane beside header dumps such as [[csgo-sdk]] and the Windows-oriented sibling [[csf-w]], supplying Linux-oriented SDK generation for non-Windows research hosts.
