# MapleStory Build Framework

C/C++ **MapleStory private-server client build framework** that modifies the game client for individualized distribution with a rudimentary anti-cheat layer. Listed under Anti Cheat; useful for game security researchers and reverse engineers studying offensive techniques in the cheat / game:maplestory lane. (source: wiki/sources/descriptions/johnsonjason__MapleStoryBuildFramework.md)

Complements authoritative server stacks such as [[maplestory143]] (CheatTracker) and [[maplestoryex]] by focusing on client-side build hardening and distribution rather than server emulation. Related upstream stack: [RudiAC](https://github.com/longm0de/RudiAC).
