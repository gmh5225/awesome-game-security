# com.unity.ide.cursor

Unity package that integrates **Cursor** as an external code editor for Unity projects—editor tooling and plugin development in C# and C/C++ for game developers, engine programmers, and graphics researchers in the Game Engine / Plugins:Unity lane. (source: wiki/sources/descriptions/boxqkrtm__com.unity.ide.cursor.md)

Complements in-editor automation such as [[unicli]] and [[unity-mcp]] by wiring Unity's external-editor workflow to Cursor instead of VS Code or Rider—useful when agent-assisted editing in Cursor is part of the Unity dev loop rather than runtime IL2CPP/Mono RE.
