# Pilot

**Pilot** (BoomingTech/Pilot), now known as **Piccolo Engine**, is a compact cross-platform C++ game engine used in the **GAMES104** course. The repository ships engine and editor modules with CMake-based builds for Windows, Linux, and macOS, covering rendering, resource management, scripting, and tooling infrastructure aimed at demonstrating practical engine architecture in a teaching context. Mainly used by students and developers learning game engine implementation and graphics system design—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/BoomingTech__Pilot.md)
