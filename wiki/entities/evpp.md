# evpp

High-performance C++11 network library for building event-driven TCP, UDP, and HTTP services. Provides nonblocking server and client components, thread-safe event loops, timers, async DNS, and connection-oriented utility layers. Built around libevent with production-focused tooling, benchmarks, and related clients for systems such as Memcached and NSQ. Primarily intended for backend and infrastructure developers who need scalable low-latency network services; listed in the README **Game Network** / source lane beside other C++ online-backend stacks. (source: wiki/sources/descriptions/Qihoo360__evpp.md)

Useful as a study surface for libevent-based async I/O, game-server networking prototypes, and online-backend architecture rather than client-side cheat tooling.
