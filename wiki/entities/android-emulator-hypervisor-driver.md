# android-emulator-hypervisor-driver

Google hypervisor driver that **accelerates Android Studio Emulator** by porting **KVM to Windows** (Windows 8.1 or later, 64-bit). (source: wiki/sources/descriptions/google__android-emulator-hypervisor-driver.md)

Mainly useful for **mobile-platform and Android emulator researchers** studying emulator internals on Windows hosts—sits in the README `Android Emulator` lane beside QEMU research hosts such as [[qemu-gvm]], emulation-focused [[android-emulator]], runtime emulator root via [[aeroot]], and AVD Magisk/root via [[rootavd]]. Distinct from anti-emulator detection probes ([[anti-emulator]], [[android-emulator-detection]]).
