# Genshin GenshinData

**GenshinData** live-game data mirror for **Genshin Impact**: extracted client configuration and content tables (characters, weapons, and related game data) rather than a full game client. README lane `[Game Data]`; intended for private-server operators and game-data researchers studying HoYoverse datasets. (source: wiki/sources/descriptions/gmh5225__Genshin-GenshinData.md)

Complements IL2CPP dump forks such as [[il2cppdumper-yuanshen]] and cheat/mod scaffolds such as [[genshin-impact-base]] in the same Genshin lane—static table dumps versus runtime SDK generation or in-process hooks.
