# VansonMod

Independent **iOS debugging workstation and memory editor** for the **[[trollstore]]** environment (Objective-C++ / C++ with Theos). Operates **externally without traditional tweak injection**, keeping many memory-analysis workflows available on **non-jailbroken** TrollStore devices. Features include process selection, memory search and hex editing, pointer-chain analysis and verification, signature scanning, JavaScript-based scripting, and app archive management. On jailbroken devices it adds **RVA patching** with ARM64 instruction presets, **hardware watchpoint** monitoring, and deeper code-level debugging. Aimed at security researchers, reverse engineers, and developers learning iOS process and memory analysis for compliant technical testing. (source: wiki/sources/descriptions/vaenshine__VansonMod.md)

Complements on-device iOS cheat engines ([[h5gg]]), in-process patching libraries ([[kittymemory-ios]]), and desktop-driven CE workflows ([[ceserver-ios]], [[frida-ceserver]]) when the workflow is a TrollStore-native external debugger rather than injected tweak or remote desktop scan.
