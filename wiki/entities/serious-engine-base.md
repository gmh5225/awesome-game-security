# Serious Engine Base

Open-source core source for Croteam's Serious Engine—the engine behind the classic Serious Sam generation. Implemented mainly in C and C++ with Visual Studio project files and bundled third-party media libraries (Ogg, Vorbis). Major subsystems include rendering, world and brush editing, entities, networking, math, audio integration, and scripting support. Primary audience: engine programmers, reverse engineers, and modders studying or extending legacy FPS engine internals—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/Serious-Engine__Base.md)

Sits in the Game Engine / source lane beside other vintage commercial and open FPS engine trees such as [[storm-engine]], [[doomretro]], and [[gzdoom]].
