# MethaneKit

Cross-platform C++ graphics and application framework that abstracts DirectX 12, Vulkan, and Metal behind a unified rendering interface. CMake-based build; shared shader workflows across platforms; includes tutorials, sample apps, testing infrastructure, and modular runtime components for high-performance rendering applications. Aimed at engine and tooling developers who need a portable graphics foundation for visualization, game, or security-adjacent rendering experiments. (source: wiki/sources/descriptions/MethanePowered__MethaneKit.md)

Sits in the Game Engine / multi-API graphics-framework lane—a portable rendering foundation for engine and graphics research, not a cheat or anti-cheat artifact.
