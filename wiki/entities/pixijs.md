# PixiJS

Lightweight 2D library for the web: rich interactive graphics and cross-platform apps via WebGL and WebGPU. Written mainly in TypeScript and JavaScript; centers on shaders, rendering, and graphics. Aimed at game developers, engine programmers, and graphics researchers in the Game Engine / source lane. (source: wiki/sources/descriptions/pixijs__pixijs.md)

Sits in the Game Engine / HTML5 2D rendering lane—an OSS browser WebGL·WebGPU 2D runtime for development and graphics study, rather than a cheat or anti-cheat artifact. Adjacent to full HTML5 3D engines such as [[engine]] (PlayCanvas) and [[turbulenz-engine]].
