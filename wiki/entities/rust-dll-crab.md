# rust-dll-crab

Rust-based **Windows DLL injector** implementing multiple injection methods. Demonstrates using Rust for Windows system programming tasks typically done in C/C++, aimed at Rust developers and security researchers exploring Rust for game-hacking tool development. README category: Injection Testing. (source: wiki/sources/descriptions/gmh5225__rust-dll-crab.md)

Complements C/C++ injection technique catalogs such as [[windows-process-injection]] and injection-testing harnesses such as [[injectors]]; sits beside other Rust Windows tooling such as [[a-pasted-rust-script]] (loader/inject-adjacent Rust samples).
