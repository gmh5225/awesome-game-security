# ImGui External Overlay

C++ **Visual Studio template** for building an **external Windows overlay** with **DirectX 9** and **Dear ImGui**. Ships a ready-made overlay window and rendering flow that can be adapted for out-of-process visual drawing without hooking the target game's Present/swap path. Setup notes focus on integrating ImGui sources and DirectX SDK dependencies in VS projects. Commonly used as a starting point for game-security prototypes such as ESP visual layers, diagnostics HUDs, or reverse-engineering overlays. README tag: `[imgui overlay]`.
