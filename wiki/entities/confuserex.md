# ConfuserEx

Open-source protector for .NET applications and successor to the original Confuser project. Listed in the Anti Cheat → Binary Packer / page/CLR protection lane for anti-cheat engineers and defensive security researchers studying managed-client hardening vs dnSpy/IL-level RE. (source: wiki/sources/descriptions/mkaring__ConfuserEx.md)

Broader-featured than minimal rename/string-hide tools such as [[obfuscar]]; complements .NET technique demos like [[obfuscation-methods]] and dual-mode protectors such as [[vxlang-page]]. Cheat-side ConfuserEx recovery in IDA via [[confuserex-idapython]] (govcert-ch; Python IDAPython script). (source: wiki/sources/descriptions/govcert-ch__ConfuserEx_IDAPython.md)
