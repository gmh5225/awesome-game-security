# Free to Learn

**Free to Learn** (itsHabib/free-to-learn) is an open-source collection of self-paced technical courses, each packaged as an interactive lab with lessons, starter projects, and automated check harnesses. The curriculum spans game security and adjacent systems topics—including dedicated tracks on anti-cheat engineering, time-travel debugging, firmware forensics, sightline analysis, game-playing agents, storage and browser runtimes, compilers, blockchains, and onion routing. Implementation is mostly JavaScript modules and Python validation tooling, with Rust, Java, HTML, and WebAssembly where individual courses require it. Learners and practitioners use it for hands-on practice building and reasoning about anti-cheat defenses, debuggers, integrity checks, and related low-level game and platform security skills. (source: wiki/sources/descriptions/itsHabib__free-to-learn.md)

## Anti-cheat engineering labs

README highlights project-based systems course snapshots with **anti-cheat engineering** (and part two) labs on **server authority**, **replay**, and **integrity** for an original toy game—positioned beside curriculum-style anti-cheat study such as [[anticheat-lab]] rather than production AC products. (source: wiki/sources/descriptions/itsHabib__free-to-learn.md)

## Course model

- **Interactive labs:** lessons plus starter code and automated validators per track.
- **Breadth:** game-security cores plus adjacent RE/debug, firmware, and systems topics.
