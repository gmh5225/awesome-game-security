# IvanMurzak Unreal MCP

Unreal Engine editor plugin stack that connects MCP clients to a live Unreal project: C++ editor plugin, .NET sidecar bridge over localhost IPC, npm CLI for install/agent setup, and embedded Python for scripted editor execution. Exposes built-in tools for actors, levels, assets, Blueprint authoring/compile, C++ edit/build, viewport screenshots, and RQL (Reflection Query Language) queries/mutations. Agents may use the shared ai-game.dev cloud backend or a self-hosted [[gamedev-mcp-server]]; per-tool enablement and optional packaged-build runtime hooks when explicitly enabled. (source: wiki/sources/descriptions/IvanMurzak__Unreal-MCP.md) (source: wiki/sources/README-categories.md)

Distinct from kvick-games/chongdashu [[unreal-mcp]] MCP server samples listed under the same README label—this IvanMurzak tree is the official GameDev-MCP-Server companion Unreal plugin with RQL and cloud/self-hosted pairing.
