# PDF-PMC-X86

Documentation archive hosting a **PDF study on Performance Monitoring Counters (PMC) and Performance Monitoring Interrupts (PMI)** on the **x86** architecture. Provides background on hardware-performance-counter-based monitoring, telemetry, and related Windows research for low-level systems and game security researchers studying CPU performance counters and detection telemetry. (source: wiki/sources/descriptions/gmh5225__PDF-PMC-X86.md)

Complements practical PMC tooling such as [[pmctrace]] (ETW-backed counter collection) and [[pmi-hpc]] (PMI + HPC interrupt-driven security monitoring) as documentation-focused reference material in the same PMU lane rather than executable counter drivers.
