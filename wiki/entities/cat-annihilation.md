# Cat Annihilation

3D wave-survival game in which the player controls a customizable cat fighting dog enemies with melee and elemental magic across story, quest, and clan systems. The main deliverable is a from-scratch native engine in C++20 with Vulkan rendering, CUDA-accelerated physics and particles, ECS architecture, behavior-tree AI, deferred clustered PBR shading, and related gameplay systems. A separate browser demo of the same concept uses React Three Fiber, Three.js, and Zustand; CMake, Catch2 tests, and headless validation support development. (source: wiki/sources/descriptions/goobz22__cat-annihilation.md)

Aimed at game-engine learning and portfolio work rather than anti-cheat or reverse engineering. Sits in the Game Engine / Vulkan source lane as a modern render-graph and deferred-PBR study surface.
