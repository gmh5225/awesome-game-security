# Osmium

**C++ framework for external cheats** (cragson) that scaffolds out-of-process cheat development—separate from the game process with cross-process memory reads and external overlay/input patterns. The author notes it is **not intended as a best-practices demonstration**; it is mainly useful for **game security researchers and reverse engineers** studying offensive techniques in the cheat / guide area. (source: wiki/sources/descriptions/cragson__osmium.md)

Sits in the general-purpose external cheat-framework lane beside title-specific scaffolds such as [[cs2-ext]] and modular backends such as [[blacksun-framework]].
