# MapleNecrocer

**MapleNecrocer** (gmh5225) is a **C# MapleStory GM (Game Master) client** that replaces an older Delphi 32-bit GM client. It adds 64-bit support, _Canvas WZ file parsing, skeleton animation and particle systems, auto-detection of WZ region versions, and improved WZ library compatibility. (source: wiki/sources/descriptions/gmh5225__MapleNecrocer.md)

Useful for private-server operators and game security researchers studying MapleStory client-side GM tooling, WZ asset pipelines, and offline client-emulator architecture—not live official-client anti-cheat bypass.

Complements other GM/admin clients such as [[maplestory-gm-client]] (map editing / NPC spawn / item creation / GM commands), general-purpose private-server clients such as [[maplestory-heavenclient]] and [[maplestory-client]], server emulators such as [[maplestory-server]], and WZ tooling such as [[wzcomparerr2]] and [[maplestory-packer-modpacker]].
