# VMPStatic

Go static VMProtect unpacker for PE files. Supports VMProtect 1.x–3.x and rebuilds unpacked PE images. Aimed at reverse engineers and game-security researchers in the Cheat → Fix VMP / Unpacker lane. (source: wiki/sources/descriptions/notsnakesilent__VMPStatic.md)

Companion surface to other Fix VMP unpack research: static Go PE rebuild across VMP 1–3, vs LZMA-oriented [[vmpunpacker]], symbolic-exec handler recovery ([[novmpy]], [[rumba]]), VTIL demos ([[vmdevirt-vtil]]), or .NET runtime dump ([[vmunprotect-dumper]]).
