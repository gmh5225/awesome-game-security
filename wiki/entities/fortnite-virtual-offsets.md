# fortnite-virtual-offsets

Small Fortnite **virtual-table / view-related offset dump** (gmh5225; cheat / game:fortnite `[Virtual Table Offsets]`). Lists vtable indices or offsets for Unreal dispatch helpers such as `GetPlayerViewPoint`, `ProcessEvent`, `LineOfSightTo`, and camera-related helpers in a single text file—no dumper tooling or SDK generator. Useful for game security researchers studying Unreal Engine offset layouts in Fortnite-related reverse engineering; values are build-specific and rot quickly.
