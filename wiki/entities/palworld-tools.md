# PalWorld-Tools

Desktop utility for automating a **[[re-ue4ss]]**-based starter mod setup for Palworld (NattKh). Provides a **PyQt GUI** to download patch files, apply or revert modifications, and manage mod enable/disable states. The repository mixes Python application code with **Lua mod scripts** that adjust gameplay settings such as stamina costs, map visibility, and progression values—intended for modding convenience and experimentation with Unreal Engine game behavior. Listed as a Mod Patcher in the cheat / game:palworld [UE5] lane. (source: wiki/sources/descriptions/NattKh__PalWorld-Tools.md)

Sits in the Palworld live-modding lane beside [[palmods]] (UE4SS + native trainer stack), [[palworld-modding-kit]] (modding scaffold), and [[palworld-helper]] (Python helper tooling)—all operating on the same [[unreal-object-model]] research surface via UE4SS scripting.
