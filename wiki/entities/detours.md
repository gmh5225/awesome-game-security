# Detours

Official Microsoft library for **monitoring and instrumenting API calls on Windows** — the canonical inline-hook / trampoline package for user-mode function interception. Used widely by ISVs and Microsoft product teams; common upstream for cheat / hook research samples that statically link Detours (e.g. [[hydrahook]], [[simple-ac-internal-cheat]]) and for NTDLL-only adaptations such as [[detoursnt]]. (source: wiki/sources/descriptions/microsoft__Detours.md)
