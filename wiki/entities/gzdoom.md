# GZDoom

**GZDoom** is a modder-friendly **source port** of the classic **Doom** engine with modern **OpenGL** and **Vulkan** rendering. The codebase is primarily C and C++, spans many engine subsystems, and is distributed under **GPLv3** with active community maintenance. It provides tooling and infrastructure for gameplay extensions, content mods, scripting, and cross-platform engine development. Core use case: open-source game engine and modding work; useful for researchers analyzing real-world game runtime architecture. (source: wiki/sources/descriptions/ZDoom__gzdoom.md)

Sits in the README **Game Engine → Source** lane — a feature-rich idTech 1 codebase for modding, scripting, and multi-backend render-path study, not a cheat or anti-cheat artifact.
