# linjector-rs

Rust Android code injector in the Cheat / injection:android lane; centers on modding workflows without relying on ptrace attach. Useful for game-security researchers and reverse engineers studying non-ptrace injection tradecraft on Android. (source: wiki/sources/descriptions/erfur__linjector-rs.md)

Contrasts with ptrace attach-and-inject via [[android-ptrace-injector]] and no-root Virtual Space inject via [[android-virtual-inject]]; complements Zygisk early-load paths such as [[zygisk-myinjector]] and Rust emulation research such as [[yaui]].
