# Universal Asset Ripper

High-performance, engine-agnostic TypeScript/Node.js platform for extracting assets from commercial game packages and orchestrating AI-assisted reverse-engineering workflows. Pure native parsers cover Godot PCK, Unreal PAK/IoStore, Unity asset bundles and IL2CPP metadata, and Windows PE resource sections (icons, Delphi forms). The CLI auto-detects engine/framework, catalogs assets, supports category- and pattern-filtered extraction, runs Shannon entropy scans to hunt AES keys, and emits structured evidence bundles for downstream analysis tools. An integrated Model Context Protocol server exposes the same capabilities to coding agents—aimed at modders, game developers, and security researchers doing fast offline reconnaissance on commercial packages. (source: wiki/sources/descriptions/laurentvv__universal-asset-ripper.md)
