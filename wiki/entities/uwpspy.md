# uwpspy

**DLL-based UWP spying and hook toolkit** for debugging and **reverse engineering Windows Runtime applications**. Written in **C++**, it hooks selected **UWP and WinRT interfaces** while logging runtime behavior to a **console**. Provides reusable **low-level hook scaffolding** and **API interception patterns** suitable for instrumentation tasks. Primary audience: researchers investigating **UWP internals** and application behavior during execution. (source: wiki/sources/descriptions/Francesco149__uwpspy.md)

README lane: Explore UWP (dll that hooks uwp interfaces).
