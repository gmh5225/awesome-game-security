# kernel-su-huawei-nova2

[[kernelsu]] port for the **Huawei Nova 2** device. Provides a full **ARM64** Linux kernel source tree modified for kernel-level root access management, including Android-specific kernel configurations, device tree definitions, and integrated KernelSU framework patches on the Huawei vendor kernel. Listed under Cheat / Android as KernelSU for huawei. Mainly useful for Android kernel researchers and root-access developers studying KernelSU integration on vendor-specific kernel trees. (source: wiki/sources/descriptions/CoolestEnoch__kernel-su-huawei-nova2.md)

Device-specific KernelSU trees like this sit beside peer Huawei sources such as [[android-kernel-huawei-hi6250-8-exp]] and [[android-kernel-huawei-mt6761]], and other OEM KernelSU BSP ports such as [[kernelsu-pixel4xl]] / [[pc-ginkgo]].
