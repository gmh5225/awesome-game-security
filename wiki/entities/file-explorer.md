# FileExplorer

Full-featured Android file manager (Kotlin, Jetpack Compose, Material 3) for browsing, editing, and managing files across local storage, archives, network shares, and cloud backends. Optional root access via libsu and Shizuku-backed browsing of protected `Android/data` and `Android/obb` paths; includes an APK analyzer, hex editor, app manager, and root module browser for [[magisk]], [[kernelsu]], and [[apatch]]. Security-oriented features include encrypted vaults, AES-256 file encryption, secure delete, checksum verification, and SHA-256 integrity monitoring, plus SMB, SFTP, FTP, WebDAV, and multi-cloud connectivity. Dual-pane tabs, Storage Access Framework (SAF), and USB OTG support. Targets mobile reverse engineers, game security researchers, and advanced users who need deep filesystem inspection, protected app-data access, and forensic-style storage analysis. (source: wiki/sources/descriptions/SysAdminDoc__FileExplorer.md)
