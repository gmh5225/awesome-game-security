# inject

Command-line network tool for crafting, injecting, and sniffing a wide range of network protocols. Targets users who need robust protocol analysis and manipulation for troubleshooting, testing, or education — mainly game-security researchers and reverse engineers studying offensive techniques in the Cheat → Packet Sniffer&Filter lane. (source: wiki/sources/descriptions/fksvs__inject.md)

Distinct from Windows **process injection** corpora such as [[injection]] and [[injectors]]; this repo operates on wire-level protocol craft/capture rather than in-process code load.
