# MapleStory CMS95 Client Address

Collection of **Chinese MapleStory (CMS) version 95** client memory addresses and offsets (gmh5225): function pointers, structure offsets, and hook points for CMS v95 modding and private-server development. (source: wiki/sources/descriptions/gmh5225__MapleStory-CMS95-Client-Address.md)

Useful for game security researchers and private-server developers mapping CMS v95 client internals—not live official-client anti-cheat bypass tooling.

Complements live TWMS client hacking corpora such as [[twms-hacking-data]], GMS-095 server emulators such as [[rebirth]], client architecture sources such as [[maplestory-client]] and [[winapi-maplestory]], and WZ/asset tooling such as [[wzcomparerr2]].
