# Elden Ring CT TGA

**Cheat Engine table** (`.CT`) for **Elden Ring** with a documented **Linux / Steam Proton** workflow via **protonhax**. Researchers launch the game through Steam (app ID `1245620`) with `protonhax init %command%` launch options, optionally without disabling [[easy-anti-cheat]], then attach Cheat Engine under Wine using `protonhax run 1245620 /path/to/Cheat\ Engine.exe`. After loading the table and enabling the bundled **Open** script, CE can drive live memory edits on the Proton/Wine process. Useful for studying Cheat Engine plugin/table workflows, Proton-hosted Windows cheat tooling, and [[easy-anti-cheat]]-protected title surfaces on Linux.
