# Cubyz

Open-source 3D voxel sandbox game inspired by Minecraft, written primarily in **Zig** with an **OpenGL** rendering pipeline and build scripts for Windows and Linux. Core engine features include level-of-detail rendering, true 3D chunks without fixed world height limits, and procedural crafting systems. Targets players and game developers studying voxel engine design and moddable sandbox mechanics. (source: wiki/sources/descriptions/PixelGuys__Cubyz.md)

Sits in the Game Engine / source lane—an OSS Zig voxel sandbox for studying chunk LOD, procedural world generation, and OpenGL render pipelines, not a cheat or anti-cheat artifact.
