# DDGACreg

Unofficial **Windows x64** hook for a local **TG4AC 5.80.02** train-arcade title, delivered as a **version.dll proxy** beside the game executable. C++ with CMake, **MinHook** API interception, MASM thunks for DLL forwarding, and HLSL compositor shaders for multi-panel cabinet layouts on ultrawide, 16:9, or single-screen setups. Modules cover coin input, keyboard NESiCA card taps, in-process NESYS pipe handling, **free camera**, HUD hiding, cinematic quality overrides, full-line route streaming, and raised load budgets; a companion **localhost** C++/SQLite content server backs cards, missions, and leaderboard-style data over loopback HTTP. Research surface for arcade PC ports, DLL proxy chains, and offline cabinet-service emulation. (source: wiki/sources/descriptions/kjjkjjzyayufqza__DDGACreg.md)
