# e3

**E3 (Encrypt-Everything-Everywhere)** is a C++ homomorphic encryption framework from NYU Abu Dhabi's MoMA Lab for computing on encrypted operands. It wraps FHE backends and exposes programmer-friendly encrypted variable types and operators so privacy-preserving code can be written without deep cryptographic expertise. Listed for researchers and engineers exploring encrypted computation for protected game state and anti-cheat **Encrypt Variable** research. (source: wiki/sources/descriptions/momalab__e3.md)

Unlike lightweight in-process scalar hiding such as [[encrypted-value]] / [[xor-float]] or compile-time SIMD decrypt such as [[obfuscxx]], E3 targets **homomorphic** operations—arithmetic and logic on ciphertexts—rather than decrypt-use-reencrypt loops around plaintext scalars. Practical game-client adoption is research-oriented (FHE overhead, backend choice, key management); it complements rather than replaces XOR/AES-style value obfuscation.
