# Bullet3

**Bullet Physics SDK** — open-source C++ real-time collision detection and multi-physics simulation. Covers rigid-body dynamics, soft-body dynamics, vehicle simulation, character controllers, and constraint solving for games, robotics, VFX, and scientific computing. Includes GPU-accelerated broadphase via OpenCL and integrates with major game engines and simulation environments. (source: wiki/sources/descriptions/bulletphysics__bullet3.md)

Sits in the README **PhysX SDK** / Game Engine lane as the canonical OSS physics middleware that engines such as [[gameplay]], [[gplayengine]], [[lumos]], [[stride]], and [[yourgamelib]] embed — useful for game developers and engine researchers studying collision, dynamics, and integration patterns, not a cheat or anti-cheat artifact.
