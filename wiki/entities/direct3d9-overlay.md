# Direct3D9 Overlay

C++ Direct3D9 wrapper and proxy DLL framework with a built-in in-game overlay system. Provides an on-screen console, text feed rendering, and a plugin interface for loading external feature modules. Integrates into target applications via DirectX 9 components and Detours-style interception. Primarily intended for single-player game modding, UI instrumentation, and graphics overlay development. (source: wiki/sources/descriptions/SeanPesce__Direct3D9-Overlay.md)
