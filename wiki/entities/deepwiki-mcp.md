# deepwiki-mcp

MCP (Model Context Protocol) server that exposes DeepWiki documentation analysis to AI coding assistants—query/retrieve project docs, wikis, and knowledge bases during development and code analysis. Fits the Game Develop → MCP server lane (`[MCP for deepwiki]`); useful for tooling builders wiring agents into documentation lookup rather than engine editors or live RE tools. (source: wiki/sources/descriptions/regenrek__deepwiki-mcp.md)

Complements agent-facing MCP bridges such as [[unity-mcp]] (Unity editor automation) and [[memmcp]] (CE-like memory tooling) by targeting DeepWiki / knowledge-base retrieval instead of editor or process-memory surfaces.
