# screencapture

Windows screen capture library (C++/C#) that acquires desktop frames via the DXGI Desktop Duplication API with GPU-based copying and minimal CPU overhead. Supports multi-monitor setups and standard pixel-format output for recording, streaming, screenshot tooling, or anti-cheat screenshot pipelines. (source: wiki/sources/descriptions/kirides__screencapture.md)
