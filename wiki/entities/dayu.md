# Dayu

Open/HarmonyOS `.abc` file parser and decompiler for researchers analyzing HarmonyOS/OpenHarmony application bytecode. Aimed at game security researchers and reverse engineers studying offensive techniques in the cheat / RE tools area. The author notes limited availability and expertise—decompilation correctness and future maintenance are **not** guaranteed. (source: wiki/sources/descriptions/hx1997__dayu.md)

Companion surface to [[arkdecompiler]] on the HarmonyOS `.abc` lane; not a substitute for Android APK/DEX tooling such as [[jadx]] or [[apktool]].
