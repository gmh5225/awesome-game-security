# idafind

IDA Pro plugin that adds **Ctrl+F find-in-text** support for Hex-Rays **Pseudocode** windows — a basic decompiler UX gap that slows triage when hunting strings, API names, or struct fields in large game-client functions. Aimed at game security researchers and reverse engineers studying offensive techniques in the cheat / IDA Plugins lane. (source: wiki/sources/descriptions/cristeigabriela__IDAFind.md)

Complements other Hex-Rays/pseudocode workflow plugins such as [[ida-search]] (typed binary search), [[ida-names]] (batch rename including pseudocode window titles), and [[happyida]] (decompiler convenience utilities).
