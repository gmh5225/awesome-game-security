# SnakeRoyal

Lightweight **multiplayer Snake** game prototype in **C++** with a **custom networking layer**. Supports hosting or joining matches from the command line. Source covers game logic, serialization, socket handling, and optional **headless server** hosting for simple deployment. Built as a short sprint project for learning and experimenting with **real-time multiplayer game programming**—not security research. (source: wiki/sources/descriptions/ZehMatt__SnakeRoyal.md)

Sits in the README **Game Develop** / **Mini Game With Server** lane beside console teaching samples such as [[2048-cpp]] and Rust multiplayer prototypes such as [[jumpy]]. Same author (ZehMatt) also maintains RE tooling such as [[x64dbg-playtime]] and [[zyemu]].
