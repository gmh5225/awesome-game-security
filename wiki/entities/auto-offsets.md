# AutoOffsets

C++ utility that pulls current Fortnite game offsets from a remote API endpoint over WinINet (`InternetOpenUrlA` / `InternetReadFile`). Offsets come from an external reversal database; the same data can be queried programmatically through a key-authenticated REST API. (source: wiki/sources/descriptions/masterpastaa__AutoOffsets.md)

README tags it under **`[Offset]`** — treat as a live-service offset feed for Fortnite cheat research, not a static dump. Pair with [[research-rigor]] because build-bound layouts still rot between patches even when fetched remotely.
