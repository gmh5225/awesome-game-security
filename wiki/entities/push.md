# Push

In-game overlay and system tuning toolkit focused on **gaming performance telemetry**. C/C++ with rendering and hook modules for Direct3D 8/9/10/11, DXGI, and related Windows graphics paths. OSD metrics cover CPU, GPU, RAM, and storage activity; optional frame limiting and synchronization control. Primary use case is real-time performance monitoring and overlay experimentation during gameplay—not a cheat framework. (source: wiki/sources/descriptions/Volkanite__Push.md)

README tag: **Monitor GPU/CPU/RAM performance** — sits in the Game Testing / performance-monitor lane beside frame profilers such as [[tracy]] and [[optick]], with injected Present-path telemetry rather than standalone viewer workflows.
