# ida-ps4-helper

IDA Pro helper plugin for **ps4-module-loader** workflows on PlayStation 4 binaries. Aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane studying offensive console techniques. (source: wiki/sources/descriptions/janisslsm__ida-ps4-helper.md)

Companion tooling for the PS4 module loader—not a standalone loader or full PS4 SDK generator.
