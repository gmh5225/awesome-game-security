# dp701

IDA Pro dark color theme with a customized palette for syntax highlighting, background colors, and UI elements—aimed at reverse engineers who prefer alternative dark visual schemes during long static-analysis sessions. (source: wiki/sources/descriptions/gmh5225__dp701.md)

Visual comfort tooling—not an analysis plugin or decompiler extension.
