# Chess Assist (chess-hacks)

**Chess Assist** (ThatKidGlitchy/chess-hacks) is a client-side browser toolkit that injects **Stockfish** analysis and automation into live **chess.com** games. Implemented in JavaScript as userscripts, bookmarklets, and an optional Chrome extension (separate desktop and mobile Safari builds), it can auto-play engine moves with configurable delay and depth, overlay best-move and opponent-prediction hints, and customize the board UI with settings in local storage. A detection panel tracks centipawn loss, accuracy, best-move rate, and a suspicion gauge for you or your opponent, with optional full-game reanalysis. (source: wiki/sources/descriptions/ThatKidGlitchy__chess-hacks.md)
