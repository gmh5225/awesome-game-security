# armageddon

**armageddon** (IAIK) is a **cache side-channel attack toolkit for ARM-based mobile devices**. The C codebase ships with Python utilities and Make-based build infrastructure. It implements **Prime+Probe**, **Flush+Reload**, **Evict+Reload**, **Flush+Flush**, and **cache template attack** workflows for academic and applied security research on **mobile privacy leakage**, **cryptographic side channels**, and **TrustZone observation**. README tag: `[Cache attacks on ARM]`. (source: wiki/sources/descriptions/IAIK__armageddon.md)

Complements ARM64 runtime tooling such as [[armshellcode]] and TrustZone attack-surface study such as [[keybuster]] and [[cve-2021-1961]].
