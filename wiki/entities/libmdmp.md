# libmdmp

C/C++ library focused on Windows minidump format parsing for memory analysis and debugging. Aimed at anti-cheat engineers and defensive security researchers working in AC / Windows kernel dump analysis. Complements Python minidump tooling such as [[minidump]] / [[minidumpreader]], Unicorn-based offline execution via [[dumpulator]], and RAM-image frameworks [[volatility]] / [[volatility3]]. (source: wiki/sources/descriptions/libyal__libmdmp.md)
