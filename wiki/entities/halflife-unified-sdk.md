# halflife-unified-sdk

**Half-Life Unified SDK** (SamVanheer) — updated, consolidated Half-Life SDK for developing mods across Half-Life, Opposing Force, and Blue Shift. Large C++ codebase with CMake-based cross-platform build support for modern Visual Studio and GCC toolchains. Integrates many bug fixes, refactors shared systems to reduce duplication, and ships extensive documentation, tooling, and changelogs for mod developers. Intended for game development and engine-level research rather than cheating—useful for understanding classic FPS code architecture and secure modding workflows. (source: wiki/sources/descriptions/SamVanheer__halflife-unified-sdk.md)

Complements the official GoldSrc tree [[halflife]], community server-logic remakes such as [[regamedll-cs]] and [[regs]], preservation clients such as [[cs16-client]], mod collections such as [[hl-mods]], and the later Source 1 SDK lineage via [[source-sdk-2013]] and [[hl2sdk]].
