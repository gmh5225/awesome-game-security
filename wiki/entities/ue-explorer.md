# UE-Explorer

Windows tool for browsing and decompiling Unreal Engine package files. Provides UnrealScript decompilation, class and sound export, package dependency inspection, and modding-oriented views such as a structured hex viewer. Built with C# on .NET WinForms and targets legacy Unreal package workflows for UE1–UE3 era games. Widely used by modders and reverse engineers working with classic Unreal titles. (source: wiki/sources/descriptions/UE-Explorer__UE-Explorer.md)

Sits in the README Game Engine Explorer:Unreal / legacy offline package lane beside modern UE4+ cooked-asset tooling such as [[uassetgui]] and [[uassetapi]]—focused on pre-UE4 `.u` package browse/decompile rather than `.uasset`/`.umap` edit.
