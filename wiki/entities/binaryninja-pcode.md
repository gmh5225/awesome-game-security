# binaryninja-pcode

Binary Ninja plugin that bridges Ghidra’s Sleigh disassembler and p-code IR into Binary Ninja’s architecture framework. C++ integration of Ghidra’s third-party decompiler components, with experimental Low Level IL translation from p-code. Useful when RE workflows need Ghidra processor definitions / p-code analysis inside Binary Ninja (Cheat Binary Ninja Plugins lane). (source: wiki/sources/descriptions/pd0wm__binaryninja-pcode.md)

Not a standalone Ghidra replacement—scoped to BN↔Sleigh/p-code bridging and experimental LLIL lift.
