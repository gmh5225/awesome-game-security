# DeviceWarLock

Android-focused project combining **Java** and **C/C++** with networking, SDK generation, and native hooking. Aimed at anti-cheat engineers and defensive security researchers studying Android device fingerprinting and hardware-identity (Detection:HWID) surfaces. (source: wiki/sources/descriptions/imxiaoc996__DeviceWarLock.md)

README lane: `[Android]`. Sits alongside Android fingerprint SDKs such as [[trustdevice-android]] and opposite offensive build/prop spoof profiles such as [[spoofing-collection]] in the mobile HWID lane.
