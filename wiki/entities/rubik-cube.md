# rubik-cube

3D Rubik's Cube game implementation in C++ on Windows using DirectX. Ships both a Direct3D 11 build and an older Direct3D 9 version with HLSL shaders and custom rendering, camera, and input systems. Includes full source, assets, and runnable release builds with keyboard and mouse controls for cube manipulation and timing. Aimed at developers learning real-time graphics programming and native DirectX game architecture—not a cheat, anti-cheat, or security tool. (source: wiki/sources/descriptions/MKXJun__Rubik-Cube.md)
