# GptHidra

Ghidra plugin that sends the currently selected function to ChatGPT and prints an explanation to the Ghidra console—lightweight in-IDE LLM assistance for triaging decompiled routines during game-security and cheat-plugin RE. (source: wiki/sources/descriptions/evyatar9__GptHidra.md)

Console-output `[ChatGPT]` lane peer to in-panel assistants [[ghidrassist]] and OpenAI decompiler helper [[ghidra-openai]]; verify model output against disassembly/decompilation per [[research-rigor]].
