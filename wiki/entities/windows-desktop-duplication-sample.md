# WindowsDesktopDuplicationSample

C++ sample demonstrating the Windows **Desktop Duplication API** (DXGI Output Duplication) for capturing desktop screen content from the compositor. Shows frame acquisition, pixel data access, cursor rendering, and dirty/moved region tracking for efficient capture. Uses DirectX 11 and DXGI 1.2. Target audience: screen capture tools, remote desktop apps, and screenshot-based anti-cheat pipeline developers. (source: wiki/sources/descriptions/bmharper__WindowsDesktopDuplicationSample.md)
