# AntiCheat-Testing-Framework

Modular C/C++ Windows framework for testing anti-cheat detection coverage. Exposes selectable attack primitives—process memory read/write, DLL injection, overlay rendering, input simulation, and driver-based kernel operations—so researchers can trigger techniques one-by-one and see which an AC detects or misses. Aimed at anti-cheat developers and security researchers doing systematic evaluation and gap analysis. (source: wiki/sources/descriptions/niemand-sec__AntiCheat-Testing-Framework.md)

README lane: **Testing Framework**. Complements narrower stress harnesses such as [[injectors]] (injection-only) and educational detector PoCs such as [[anticheat-poc]].
