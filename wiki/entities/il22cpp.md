# IL22CPP

C++ research tool for analyzing and manipulating Unity [[il2cpp]] runtime binaries. Remake of the IL2CPP internal reflection system in C++: resolves IL2CPP metadata, reconstructs managed type information, and interfaces with the IL2CPP virtual machine for game modding. (source: wiki/sources/descriptions/gmh5225__IL22CPP.md)

Complements C++ resolvers such as [[il2cpp-resolver]] and reflection-driven runtime dumpers like [[il2cpp-runtime-dumper]] when the goal is native IL2CPP VM introspection rather than static metadata dumps alone.
