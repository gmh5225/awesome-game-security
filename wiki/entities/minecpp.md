# minecpp

C++ Minecraft server backend targeting Java Edition **1.19**. Implements an authoritative server stack for studying Minecraft protocol behavior, custom server logic, and offensive cheat techniques in the `game:minecraft` lane. (source: wiki/sources/descriptions/gmh5225__minecpp.md)

Useful for game security researchers and reverse engineers who need a native server implementation rather than Java Paper/Spigot plugins or Bedrock proxies.
