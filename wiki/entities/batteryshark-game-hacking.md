# game-hacking (batteryshark)

Curated collection of small, per-game hacking and modding utilities for console and PC titles. Most entries are Python tools for archive extraction, script disassembly and reassembly, fan-translation workflows, and file-format research (bytecode reverse engineering, custom cipher and compression handling, archive carving, DOSBox-X VHD layer differencing). Includes a Windows C project that DLL-injects into the SSF Saturn emulator with SCSI emulation hooks to boot CHD disc images, plus a browser-based JavaScript helper for Keep Talking and Nobody Explodes. Individual folders target titles such as Clock Tower, Ys: Memories of Celceta, Culdcept, and Castlevania: Lords of Shadow. Ships no copyrighted game assets—every tool expects files from a legally obtained copy you provide. Aimed at hobbyists doing reverse engineering, fan translation, save editing, and hands-on format work rather than commercial anti-cheat or live-service security. (source: wiki/sources/descriptions/batteryshark__game-hacking.md)
