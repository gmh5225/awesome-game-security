# Playnite

Open-source **Windows game library manager and launcher** that unifies titles from many platforms in one interface. Built mainly with **C# and XAML on .NET**, with a **plugin architecture** for library integrations, themes, and automation extensions. Supports emulation workflows and local metadata management while keeping user data on the local machine. (source: wiki/sources/descriptions/JosefNemec__Playnite.md)

Sits in the README **Game Manager** lane as legitimate launcher infrastructure—useful for studying plugin surfaces, multi-store launch orchestration, and local metadata handling opposite platform-bypass launchers such as [[mini-launcher]].
