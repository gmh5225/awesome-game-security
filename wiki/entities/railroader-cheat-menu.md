# Railroader Cheat Menu

Open-source **C#** Unity mod for **Railroader 0.6.x Experimental** that adds a **host-only** in-game debug and cheat menu through the official Railroader modding contract. A **Unity IMGUI** front end drives centralized game-state manipulation; optional **HarmonyLib** runtime patches cover derailment protection, speed-based damage, and tunable physics multipliers. Session tools expose company cash and reputation, locomotive/car repair, fueling and cargo handling, track and maintenance-of-way yard restocking, wear and oil toggles, and player or simulation speed adjustments, with multilingual UI strings. A PowerShell build script compiles the assembly with `dotnet` and packages a distributable mod. (source: wiki/sources/descriptions/Sylvrwynd__Railroader-Cheat-Menu.md)

Suited to developers and researchers studying **Unity game modding**, **host-authoritative cheat surfaces**, and reflective or Harmony-based runtime hooking rather than production anti-cheat design.
