# Nebula

Modular **C++ game engine** from gscept. The fastest onboarding path is the **Nebula-demo** companion repo: its `setup.bat` installs dependencies and configures a solution, then `fips open` launches the fips-managed build workflow. Aimed at game developers, engine programmers, and graphics researchers studying a full engine source tree in the Game Engine / source lane. (source: wiki/sources/descriptions/gscept__nebula.md)
