# minivers

Generates backup copies of monitored files before they are changed, deleted, or renamed — capturing the pre-modification state automatically when a watched path is about to be modified. Aimed at anti-cheat engineers and defensive security researchers working in the anti-cheat / backup-file lane. (source: wiki/sources/descriptions/guidoreina__minivers.md)

Complements reactive directory-watch building blocks such as [[readdirectorychanges]] and post-incident recovery tooling such as [[file-recovery-tool]] with proactive on-disk preservation before integrity events occur.
