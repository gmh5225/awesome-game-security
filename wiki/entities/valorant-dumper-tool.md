# valorant-dumper-tool

Valorant **dump tooling** (gmh5225; C++; cheat / game:valorant `[Dump]`). Focuses on extracting Unreal Engine memory layout and offset data from the live Valorant process for researchers studying offensive techniques and SDK generation under [[vanguard]]. (source: wiki/sources/descriptions/gmh5225__Valorant-Dumper-Tool.md)

Sits beside [[valorant-dumper]] and [[valorant-fnamepool]] in the per-title Valorant Unreal dump lane, but as a separate gmh5225 dump repo rather than xehn1337's broader GObjects/GNames dumper or FNamePool-only samples.
