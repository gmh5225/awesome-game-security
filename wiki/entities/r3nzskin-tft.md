# R3nzSkinTFT

**LoL / TFT skin changer** (C++; gmh5225; cheat / game:lol `[Skin]`). Modifies **champion skin IDs in memory** and patches the client's champion skin data structures to swap **client-side cosmetic appearances** without server-side detection—aimed at game security researchers studying cosmetic manipulation in Riot Games titles under [[vanguard]]. (source: wiki/sources/descriptions/gmh5225__R3nzSkinTFT.md)
