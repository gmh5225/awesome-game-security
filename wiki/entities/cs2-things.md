# cs2-things

Curated **Counter-Strike 2** research collection (VScript) with reverse-engineered structures, offset dumps, SDK snippets, and analysis notes for the **Source 2** engine as used in CS2. Documents entity system layouts, netvar structures, and engine interface pointers discovered through reverse engineering. Aimed at CS2 cheat developers and Source 2 engine researchers rather than a single runnable cheat binary. (source: wiki/sources/descriptions/gmh5225__cs2_things.md)

Sits beside maintained offset feeds such as [[cs2-offsets]] and generated SDK tooling such as [[source2gen]] as a research artifact lane for CS2 layout and interface discovery.
