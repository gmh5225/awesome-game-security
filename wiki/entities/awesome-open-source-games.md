# awesome-open-source-games

Curated awesome-list of open-source games organized by platform (browser, mobile, desktop) and genre (arcade, FPS, RPG, strategy, puzzle), covering engines like Godot, Unity, and custom implementations across C++, JavaScript, Python, and other languages. (source: wiki/sources/descriptions/michelpereira__awesome-open-source-games.md)

Sits in the README **Collection of Games** lane under **Game Develop → Guide** alongside other game indexes; useful for finding playable open-source titles to study architecture, networking, or engine integration—not a security tool itself.
