# Phobos

Community **Command & Conquer: Yuri's Revenge** engine extension that adds features and fixes for advanced RTS mod development. Large **C++** codebase built around modified **YRpp** components and **Syringe**-based injection to extend game behavior without replacing the original game executable architecture. Ships extensive documentation and stable, development, and nightly release channels used by mod projects for engine-level behavior customization. (source: wiki/sources/descriptions/Phobos-developers__Phobos.md)
