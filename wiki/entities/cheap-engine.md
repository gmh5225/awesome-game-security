# cheap-engine

**Cheap Engine** is a lightweight **game cheat engine** / **memory scanner** for **Android** with a simplified feature set compared to Cheat Engine: process memory scanning, value search (exact, range, changed/unchanged), memory editing, and pointer scanning. Aimed at game-hacking beginners and researchers studying memory-scanner implementations who want basic live-memory modification without CE’s full surface area. (source: wiki/sources/descriptions/gmh5225__cheap-engine.md)

Sits in the Cheat Android Memory scanner lane beside CLI scanners such as [[mypower]] and CE-derived Android tooling such as [[ue4-cheat-engine]], as a minimal native alternative for scan/edit workflows.
