# SubGetVariable (ekknod)

**SubGetVariable** is an offensive research project focused on **EFI RPM** — remote process memory read/write through the **UEFI runtime / GetVariable** lane rather than a conventional Windows kernel driver load path. It is written in **C**, **C/C++**, and **C++**, and centers on **kernel-level work**, **driver development**, and **graphics** for game-security researchers and reverse engineers studying cheat / RPM techniques below normal handle-based user-mode access.
