# HappyIDA

IDAPython plugin suite adding convenience utilities to the Hex-Rays decompiler. Features Swift-style parameter labeling, clipboard name/type helpers, SEH try/catch reconstruction and highlighting, vtable-based function navigation, and Rust string prettification in pseudocode. (source: wiki/sources/descriptions/gmh5225__HappyIDA.md)

Scoped as Hex-Rays UX/productivity tooling—not a deobfuscator or automated analysis framework. Complements [[ida-enums-helper]], [[ida-medigate]], [[ida-vtable-tools]], and [[ida-rust-demangler]] for enum, vtable, and Rust-oriented decompiler workflows.
