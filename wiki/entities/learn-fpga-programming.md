# Learn FPGA Programming

Companion code for Packt Publishing's **Learn FPGA Programming** book: chapter-organized **SystemVerilog** HDL examples and testbenches from basic logic design through **I2C**, **PS/2**, **VGA**, **DDR memory**, and capstone projects. Aimed at hardware engineers and security researchers building **FPGA programming fundamentals** before tackling custom DMA hardware or [[pcileech-fpga]]-class firmware. (source: wiki/sources/descriptions/PacktPublishing__Learn-FPGA-Programming.md)

## Role in the DMA stack

Foundational **HDL literacy** lane—not PCIe/DMA-specific. Teaches RTL design, bus protocols, and memory interfaces that underpin later Vivado/SystemVerilog work in [[pcileech-fpga]], [[pcileechgen]], and board bring-up guides such as [[entities/dma]] and [[dma-cfw-guide]]. Complements hands-on PCIe tutorials such as [[xilinx-fpga-pcie-xdma-tutorial]] once basic FPGA skills are in place.
