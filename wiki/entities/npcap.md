# Npcap

Windows packet capture and injection library from the Nmap Project. Complete update to the unmaintained WinPcap stack with improved speed, reliability, and security—the common live-capture backend for tools that wrap libpcap/WinPcap/Npcap. Useful for game-security and RE work in the Cheat → Packet Capture&Parse lane. (source: wiki/sources/descriptions/nmap__npcap.md)

Sits under README Cheat → Packet Capture&Parse beside multiplatform parse/craft stacks such as [[pcapplusplus]] and NDIS packet-filter APIs such as [[ndisapi]].
