# awesome-wow-rust

Curated index of **Rust** resources for building and researching **World of Warcraft** private-server ecosystems. Catalogs server implementations, protocol and file-format libraries, and supporting tools such as renderers and asset viewers. Emphasizes practical references for authentication, networking, data formats, and emulator-adjacent tooling—aimed at Rust game-server developers and reverse-engineering enthusiasts exploring WoW emulation technology. (source: wiki/sources/descriptions/arlyon__awesome-wow-rust.md)

Not a single emulator binary—a learning/index hub that complements C++ WoW private-server stacks such as [[azerothcore-wotlk]] and [[legioncore-7-3-5]], Rust server work such as [[azerust]], and client-side WoW RE samples such as [[dumpwow]] and [[wow-iat-fix]].
