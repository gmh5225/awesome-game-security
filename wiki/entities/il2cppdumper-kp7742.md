# IL2CPPDumper (kp7742)

Android-focused C/C++ [[il2cpp]] static dump fork: pairs `libil2cpp.so` with `global-metadata.dat` to produce `dump.cs`, headers, and `script.json` for IDA/Ghidra import on mobile Unity titles. README lane `[Il2Cpp Dump for Android Platform]`. (source: wiki/sources/descriptions/kp7742__IL2CPPDumper.md)

From the same author as [[ue4dumper]] and [[memdumper]]. Sits beside the canonical cross-platform [[il2cppdumper]] (Perfare) and on-device GUI [[il2cppdumpdroidgui]] on the mobile Unity explorer lane.
