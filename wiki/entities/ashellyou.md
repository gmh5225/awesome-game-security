# aShell You

**aShell You** is a fully featured on-device Android shell utility for running ADB, root, and shell commands without a PC. Built primarily in Kotlin with Jetpack Compose and Material Design 3, it embeds an ADB library plus optional native components. Local execution works via Shizuku or root; OTG and wireless debugging support remote control of other Android devices. Features include built-in ADB command examples, push/pull file explorer, continuous commands such as logcat, output search and save/share, and command bookmarks with local backup and restore. Targets Android developers, power users, and tinkerers who need a convenient mobile ADB and shell workflow for debugging and device management. (source: wiki/sources/descriptions/DP-Hridayan__aShellYou.md)

Listed in the README under **Cheat → Android Terminal** as `[Material You Android ADB/root/shell utility (Shizuku, OTG, wireless debugging)]`.

Complements desktop ADB stacks such as [[scrcpy]], [[lamda]], and [[rootraven]] with a PC-free on-device lane beside terminal emulators such as [[termux-app]], [[neoterm]], and [[android-terminal-emulator]], and file managers with Shizuku/ADB access such as [[file-explorer]], [[butler]], and [[app-manager]].
