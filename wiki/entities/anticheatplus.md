# AntiCheatPlus

**AntiCheatPlus** (donnie1337/AntiCheatPlus) is a **Paper** Minecraft server plugin that pairs server-side cheat detection with an integrated staff punishment workflow. It is written in Java, built with **Maven** against the Paper API, and targets modern Paper releases while accounting for legacy combat timing where relevant. (source: wiki/sources/descriptions/donnie1337__AntiCheatPlus.md)

## Detection (GUARDIÃO)

The **GUARDIÃO** module runs configurable behavioral checks across movement, combat, blocks, chat, vehicles, and interactions—including kill-aura **decoy entities** and ore-focused mining analysis for x-ray-style abuse—and escalates staged alerts to permitted staff. (source: wiki/sources/descriptions/donnie1337__AntiCheatPlus.md)

## Enforcement

Built-in moderation covers bans, IP bans, kicks, warnings, an in-game punish menu, persisted punishment records, and login enforcement—aimed at operators who want detection and sanctions in one Paper plugin rather than a separate ban suite. (source: wiki/sources/descriptions/donnie1337__AntiCheatPlus.md)
