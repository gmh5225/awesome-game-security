# open-source-engines

Curated index of open-source game engines, including approachable C/C++ libraries such as **raylib** for videogames programming. Aimed at game developers, engine programmers, and graphics researchers working on rendering and graphics in the Game Engine / guide lane—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/bobeff__open-source-engines.md)

Useful survey index beside other engine catalogs and OSS engine trees elsewhere in the wiki.
