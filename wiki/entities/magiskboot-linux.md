# magiskboot-linux

Standalone GitHub Actions build of Magisk's `magiskboot` for Linux hosts. Handles Android boot-image unpack/repack/patch: kernel extraction, ramdisk modification, DTB editing, and boot-signature management—without installing the full Magisk Android suite. Aimed at Android developers and custom ROM builders who need boot-image manipulation on Linux. (source: wiki/sources/descriptions/gmh5225__magiskboot-linux.md)

Curated under Cheat Magisk / Boot Image Modification Tool beside [[magiskboot]], NDK-on-Linux [[magiskboot-ndk-on-linux]], and POSIX build scripts [[magiskboot-build]]; underpins Magisk-style root/recovery research that mobile anti-cheat often treats as integrity signals.
