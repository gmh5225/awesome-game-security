# RenHook

Open-source **Windows hooking library** for x86 and x86-64 targets. Written in modern C++ with **Zydis-based disassembly** to build reliable inline hooks and trampolines. Emphasizes safe APIs, dual-architecture support, and practical examples for function interception — useful for reverse engineering, instrumentation tooling, and game-security research that needs runtime code redirection. (source: wiki/sources/descriptions/WopsS__RenHook.md)

Sits in the cheat / hook research lane beside [[polyhook]], [[polyhook-2-0]], [[subhook]], and [[detoursnt]] as a Zydis-backed Windows inline hook option.
