# rbfx

Urho3D-derived engine fork focused on C# support and a WYSIWYG editor. Useful for game developers, engine programmers, and graphics researchers studying editor tooling and managed bindings on an OSS engine tree. (source: wiki/sources/descriptions/rbfx__rbfx.md)

Sits in the Game Engine / source lane—an editor- and C#-oriented fork of [[urho3d]], rather than a cheat or anti-cheat artifact.
