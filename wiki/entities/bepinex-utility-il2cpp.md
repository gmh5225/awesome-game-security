# BepInEx Utility IL2CPP

Collection of **BepInEx utility plugins** for **Unity IL2CPP** games from the upstream BepInEx project. Provides runtime quality-of-life tweaks: fullscreen toggle, window resize, graphics settings, mute-in-background, Message Center overlay, ByteFiddler, ProcessAffinityOverride, and related client-side adjustments rather than gameplay cheats. (source: wiki/sources/descriptions/BepInEx__BepInEx.Utility.IL2CPP.md)

Loads through the canonical [[bepinex]] plugin host on IL2CPP titles. Distinct from mod-menu scaffolds such as [[bepinex-il2cppbase]] and runtime inspectors like [[unityexplorer]]—this pack focuses on display, audio, and process/window configuration at runtime.
