# DynaDbg

**DynaDbg** is a remote reverse engineering and dynamic analysis suite. It combines a **TypeScript/React Tauri** desktop client with **Rust** and **C/C++** backend components to deliver cross-platform debugger and memory-scanner capabilities. Key features include memory scanning modes, watchpoints, code tracing, debugger views, and host–remote workflows across multiple operating systems and architectures. The project targets reverse engineering practitioners who need GUI-driven low-level analysis for software and game security research, with README positioning as a debugger for **Android** and **iOS**. (source: wiki/sources/descriptions/DoranekoSystems__DynaDbg.md)

Sits in the mobile dynamic-analysis lane beside GUI memory debuggers such as [[memdbg]], remote Cheat Engine bridges such as [[ceserver-ios]] and [[frida-ceserver]], and eBPF CLI debuggers such as [[edbg]] and [[edbgserver]].
