# FlavorTown

Multi-language **shellcode execution technique** collection: C, C#, and MATLAB examples demonstrating different process and memory execution paths common in evasion research. Practical usage guidance is embedded in the source files. The repo targets offensive and defensive security practitioners studying execution tradecraft in a controlled setting. (source: wiki/sources/descriptions/Wra7h__FlavorTown.md)

Complements callback-based execution corpora such as [[alternative-shellcode-exec]], injection toolkits such as [[jektor]], and broader injection references such as [[windows-process-injection]].
