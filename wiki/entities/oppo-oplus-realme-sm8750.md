# OPPO/OnePlus/Realme SM8750 kernel builder

**Automated kernel build scripts** for **OPPO / OnePlus / Realme** devices on **Snapdragon 8 Elite (SM8750)** and **MediaTek Dimensity 9400+ (MT6991)**. Supports both **OKI** and **GKI** compilation modes, ships **f2fs compatibility patches**, and integrates **KernelSU** into the build pipeline. (source: wiki/sources/descriptions/Andrea-lyz__oppo_oplus_realme_sm8750.md)

Targets Android kernel developers and mobile security researchers who need flashable custom kernels on current OPPO-family flagships for root/module workflows, filesystem bring-up, and kernel-integrity bypass research. README category: automatic kernel builder for Oppo/OnePlus/Realme Snapdragon SM8750 / MediaTek MT6991 devices.

Complements broader Bash build automation in [[kernel-build-scripts]] and KernelSU-integrated OEM trees such as [[rooturk-kernel]] and [[android-kernel-oneplus-sm7250-wksu]].
