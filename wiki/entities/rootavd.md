# rootAVD

Tooling to **root Android Virtual Devices (AVD)** for emulator-hosted research. Description centers on kernel-level work, modding, and SDK generation in the Cheat Magisk / Android Emulator lane—useful for game-security and reverse-engineering labs that need rooted AVD images rather than physical-device root paths. (source: wiki/sources/descriptions/newbit1__rootAVD.md)

Sits beside runtime emulator root [[aeroot]] and device-scoped root stacks such as [[magisk]] / [[kernelsu]], and opposite emulator-detection samples such as [[anti-emulator]] / [[android-emulator-detection]].
