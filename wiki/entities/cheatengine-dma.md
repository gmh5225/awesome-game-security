# CheatEngine DMA

**Visual Studio C++ Cheat Engine plugin** (Metick) that adds **DMA-backed memory operations** to familiar CE scan/edit workflows. Combines a plugin layer with DMA support components so process attach, memory read/write, memory search and browsing, module and thread enumeration, and pointer scanning run over external hardware-assisted access instead of in-process APIs. Targets DMA users and game memory researchers who want CE's UI with low-level external memory analysis and editing. Listed under cheat / CheatEngine DMA. (source: wiki/sources/descriptions/Metick__CheatEngine-DMA.md)

## Capabilities

- Process attach over DMA path
- Memory read/write, search, and browse
- Module and thread enumeration
- Pointer scanning support
- Exposes low-level DMA access through standard Cheat Engine interfaces
