# PlayCanvas Engine

Open-source WebGL/WebGPU game engine written in JavaScript. Full browser 3D pipeline: PBR materials, shadow mapping, particle systems, Ammo.js physics, skeletal animation, audio, and XR. Runs in-browser and pairs with the PlayCanvas cloud editor for collaborative development. Aimed at web game developers and interactive 3D application builders targeting browser platforms. (source: wiki/sources/descriptions/playcanvas__engine.md)

Sits in the Game Engine / HTML5 3D source lane—an OSS WebGL·WebGPU engine tree (and parent runtime for tools such as [[supersplat]]), rather than a cheat or anti-cheat artifact.
