# dnSpy

.NET assembly debugger, decompiler, and editor for analyzing and modifying managed binaries without source. Decompiles to C#, VB.NET, or IL; supports integrated debugging with breakpoints, stepping, and locals/watch windows. Can edit method bodies, IL code, and metadata directly. Dedicated Unity game debugging via patched Mono runtimes built from [[dnspy-unity-mono]], using the soft-debugger client in [[mono-debugger-soft]]. Listed in the README under **For Unity** — primary interactive debugger/decompiler for Mono-era Unity `Assembly-CSharp.dll` and general .NET/Unity managed-code RE.
