# ida_export_functions

IDA Pro plugin that exports the database function list to a user-specified path as Markdown. A lightweight documentation/reporting helper for large disassembly projects—useful when analysts need a shareable function index outside IDA for notes, diffs, or LLM-assisted review workflows. (source: wiki/sources/descriptions/gmh5225__ida_export_functions.md)

Scoped as function-list Markdown export—not call graphs, rename automation, or decompiler output. Complements [[ida-names]] (batch rename/import/export of symbol names), [[ida-func-outline]] (call-hierarchy trees), and presentation lanes such as [[ida-slides]] / [[ida-screenshot]].
