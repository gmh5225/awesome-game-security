# source-engine

Open Source Engine tree (nillerusr) based on Team Fortress 2-era Valve Source code, maintained with CI builds and cross-platform work. Provides classic Source client/server/engine modules for studying or porting Source games outside the original closed tree—useful for game developers, engine programmers, and reverse engineers working with Source Engine titles. (source: wiki/sources/descriptions/nillerusr__source-engine.md)

Complements AlliedModders HL2 SDK references such as [[hl2sdk]] (alliedmodders; Half-Life 2 era client/server/game logic + mod/plugin build infrastructure) (source: wiki/sources/descriptions/alliedmodders__hl2sdk.md), official Valve **Source SDK 2013** such as [[source-sdk-2013]] (ValveSoftware; HL2/HL2DM/TF2 modding SDK; VS + Steam Runtime builds), Orange Box–era Source Engine 2007 mirrors such as [[source-engine-2007]] (gmh5225; se2007 engine/client/server; networking, demos, rendering hooks), title-scoped Source trees such as [[cstrike15-src]], GoldSrc remakes/mods ([[cs16-client]], [[regamedll-cs]], [[hl-mods]]), serverside anti-cheat plugins such as [[nocheatz-3]], Source 2 SDK generators such as [[source2gen]], TF2 internal hook research such as [[teamfortress2-internal]] (gmh5225; modding / hooking; cheat / game:team fortress 2), L4D2 starter hook frameworks such as [[l4d2-basic]] (gmh5225; hook structures + interface resolution; cheat / game:left 4 dead 2), and feature-complete L4D2 internals such as [[l4d2-cheat]] (gmh5225; Source engine SDK; VMT hooks + interface exploitation; ESP/aimbot/gameplay mods; Linux). (source: wiki/sources/descriptions/gmh5225__teamfortress2_internal.md) (source: wiki/sources/descriptions/gmh5225__L4D2Basic.md) (source: wiki/sources/descriptions/gmh5225__L4D2-Cheat.md)
