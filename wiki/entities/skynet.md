# Skynet

Multi-user Lua framework implementing the actor model, widely used for game backends in the Chinese game industry and increasingly adopted elsewhere. Targets backend, multiplayer, and online game developers in the README `Game Network` / source lane. (source: wiki/sources/descriptions/cloudwu__skynet.md)

Sits under README `Game Network` → Source as a study surface for authoritative Lua actor-based server stacks rather than client-side cheat tooling.
