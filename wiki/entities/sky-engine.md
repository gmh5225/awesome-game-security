# SkyEngine

**World of Warcraft Lua unlocker** (adde88; C++ with Lua-related components; Windows solution files; cheat / `game:wow` [Wow Lua Unlocker]). Targets the client's **protected Lua execution** restrictions by repeatedly resetting **taint-related state** so protected Lua functions can run more reliably. Primary use cases are WoW scripting research, cheat prototyping, and anti-cheat detection risk studies—not a general modding framework. (source: wiki/sources/descriptions/adde88__SkyEngine.md)
