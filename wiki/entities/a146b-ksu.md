# A146B-KSU

Custom Android kernel source for the **Samsung Galaxy A14 5G (A146B / a14x)** with integrated [[kernelsu]] patches for kernel-level root access management. Provides a modified OEM kernel tree aimed at Android developers and custom ROM builders who need KernelSU root on this Samsung device. Listed under Cheat / Android Kernel Source as KernelSU for SAMSUNG A14 5G. (source: wiki/sources/descriptions/gmh5225__A146B-KSU.md)

Device-specific Samsung KernelSU trees like this sit beside peer Samsung kernel sources such as [[android-kernel-samsung-sm7150]] and [[android-kernel-samsung-universal5433]], and other OEM KernelSU BSP ports such as [[android-kernel-oneplus-sm7250-wksu]] / [[pc-ginkgo]].
