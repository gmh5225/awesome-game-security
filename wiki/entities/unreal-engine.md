# Unreal Engine

**Unreal Engine** (EpicGames/UnrealEngine) is Epic Games' official **engine source code and API documentation**. The tree covers the complete runtime: build systems, rendering, physics, networking, platform abstraction, plugin architecture, and the Python scripting API. It is the primary upstream reference for game developers and engine researchers studying UE internals, module development, and platform-specific integration—not a cheat, dumper, or anti-cheat artifact. (source: wiki/sources/descriptions/EpicGames__UnrealEngine.md)

Access requires linking an Epic account and accepting Epic's license terms. For curated third-party tooling indexes see [[unreal-engine-guide]]; for profiler-driven walkthroughs of init/render paths see [[unreal-source-explained]]; for runtime object-layout RE see [[unreal-object-model]] and SDK dumpers such as [[uedumper]].
