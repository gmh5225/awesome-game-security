# Doriax

Cross-platform C++ game engine with an integrated visual editor for building 2D and 3D games. Centers on an entity-component architecture with Lua scripting bindings, scene management, animation, particles, materials, and terrain tools. Rendering uses OpenGL through a Sokol-based graphics layer with GLFW or SDL window backends, plus glslang and SPIRV-Cross shader tooling. The ImGui-based editor provides scene viewports, gizmos, resource browsers, code editing with API suggestions, export workflows, and optional AI-assisted editing. Targets desktop, mobile, and web platforms. (source: wiki/sources/descriptions/doriaxengine__doriax.md)

Sits in the Game Engine / source lane—a full engine-plus-editor stack for developers and graphics researchers studying ECS, multi-backend rendering, and editor tooling—not a cheat or anti-cheat artifact.
