# H-AC

**H-AC** (HukumAC; Benardelys/H-AC) is a modular **Paper 1.21** server-side anti-cheat plugin for Minecraft. Written in Java, it detects combat abuses (kill aura, reach, auto-clicking), movement exploits (fly, speed, phase), and world/player violations (scaffold, fast break, timer drift) through authoritative physics simulation, combat heuristics, and network balance analysis. Latency-aware reach raytracing, server TPS safeguards, asynchronous logging, Discord webhook alerts, client brand fingerprinting, injector detection, reconnect protection, and staff review commands support production server deployment. (source: wiki/sources/descriptions/Benardelys__H-AC.md)

README category: Anti Cheat / game:minecraft.

## Detection stack

Modular combat/movement/world checks with configurable thresholds, punishments, and violation decay; latency-compensated reach raytracing; asynchronous violation logging; Discord alerts; client brand fingerprinting and injector detection.
