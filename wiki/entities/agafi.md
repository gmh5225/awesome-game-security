# Agafi

**Agafi** (Advanced Gadget Finder) is an x86 **gadget finder** and **ROP chainer** for discovering return-oriented programming gadgets in programs, loaded modules, and running processes. Aimed at game-security researchers and reverse engineers studying offensive techniques in the cheat / ROP Finder lane. (source: wiki/sources/descriptions/helpsystems__Agafi.md)

Complements cross-format ROP scanners such as [[ropgadget-rs]] and kernel gadget resolution via [[ntkernelwalkerlib]] / [[ntoskrnlwalker]].
