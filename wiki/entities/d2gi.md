# D2GI

C++ **DirectDraw7/D3D7 → D3D9 wrapper** for **Hard Truck 2** (*King of the Road*) that upgrades the legacy DirectX client with modern resolutions, MSAA, anisotropic filtering, graphics fixes, and widescreen hooks. Targets DirectX compatibility and rendering modernization for early-2000s Windows trucking sims—useful for graphics programmers and Windows game-tooling developers studying legacy API translation and title-specific render fixes. Pairs with gameplay/physics ASI patches such as [[kotr-modern-patch]]. (source: wiki/sources/descriptions/REDPOWAR__D2GI.md)
