# Horizon Engine

Horizon Engine (`harukumo/HorizonEngine`) is a Windows-only 3D rendering engine that targets modern graphics APIs—Direct3D 12, Vulkan, and Metal—rather than legacy backends. (source: wiki/sources/descriptions/harukumo__HorizonEngine.md)

Aimed at game developers, engine programmers, and graphics researchers working in the game engine / source lane. Sits as an OSS render-engine codebase for studying multi-API pipeline design, not as a cheat or anti-cheat artifact.
