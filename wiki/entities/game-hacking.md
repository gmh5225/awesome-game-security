# game-hacking

Comprehensive curated index of game hacking resources organized by tool type: disassemblers, debuggers, hex editors, memory scanners, .NET decompilers, graphics debuggers, and reverse-engineering tutorials. Covers Cheat Engine, x64dbg, IDA Pro, Ghidra, dnSpy, RenderDoc, and dozens of other tools alongside game-specific hacking guides, libraries, and frameworks. Central reference for game security researchers and reverse engineers building a toolkit or learning path. (source: wiki/sources/descriptions/dsasmblr__game-hacking.md)

Sits in the Cheat → guide lane beside category-organized RE catalogs such as [[retools]], practical cheatsheets such as [[gamehacking-cheatsheet]], and learning indexes such as [[game-reversing]]. Complements the same maintainer’s online/multiplayer focus list [[hacking-online-games]].
