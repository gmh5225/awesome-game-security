# mcp-reverse

**mcp-reverse** (1llu50ry/mcp-reverse) is a **TypeScript/Node.js Model Context Protocol server** that aggregates reverse-engineering and game-debugging workflows for AI assistants (Claude, Cursor, Codex). Sidecar bridge plugins drive **Ghidra, IDA Pro, Binary Ninja, x64dbg, Cheat Engine, Frida, dnSpy, ILSpy, and ReClass.NET** from one hub. Built-in modules cover disassembly, decompilation caching, signature and YARA scanning, ROP/memory analysis, PDB/DWARF helpers, game-engine utilities, Cheat Engine server integration, and an **agent mesh** for coordinated multi-agent sessions. Docker/systemd deployment and cookbooks target malware analysts, CTF players, and game-security engineers who want LLM-assisted binary work without abandoning existing toolchains. (source: wiki/sources/descriptions/1llu50ry__mcp-reverse.md)
