# scrcpy

**scrcpy** is the upstream cross-platform tool for mirroring and controlling Android devices from a desktop over USB or TCP/IP. Implemented mainly in C and Java, it targets high performance, low latency, and a minimal on-device footprint without root. Features include audio forwarding, screen recording, virtual display support, HID input simulation, and broad desktop platform support. Primary use cases are device testing, automation, and mobile app or game debugging workflows. (source: wiki/sources/descriptions/Genymobile__scrcpy.md)
