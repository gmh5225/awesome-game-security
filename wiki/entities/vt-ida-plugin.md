# vt-ida-plugin

Official IDA Pro integration for VirusTotal cloud malware intelligence and code search. Written in Python (IDAPython), it exposes byte, string, and function code-similarity searches directly from disassembly views, plus a notebook-style panel for AI-generated function summaries, editable notes, and exportable collaboration artifacts. Aimed at accelerating reverse-engineering triage for malware and other unknown binaries. (source: wiki/sources/descriptions/VirusTotal__vt-ida-plugin.md)

Complements cloud-LLM IDA assistants such as [[wpechatgpt]], [[vulchatgpt]], and [[idassist]], and code-similarity tooling such as [[mcrit-plugin]]—verify cloud matches and model summaries against disassembly per [[research-rigor]].
