# rust-u4pak

Rust toolkit for Unreal Engine 4 `.pak` archives: unpack, pack, list, check, and mount. Supports only a limited set of pak versions. Aimed at game-security researchers and reverse engineers studying offline UE package workflows in the cheat / game engine explorer:Unreal lane. (source: wiki/sources/descriptions/panzi__rust-u4pak.md)

Sits in the README Game Assets / Unreal pak lane beside broader pak/UAsset explorers such as [[paksmith]], rather than live-process SDK dumps.
