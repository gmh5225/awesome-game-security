# opengl-3d-game-tutorial-series

Cross-platform C++ tutorial codebase for building a 3D game and engine systems with OpenGL. Covers platform-specific window setup on Windows (Win32), macOS (Cocoa), and Linux (X11), then builds core rendering pieces such as VAO, shaders, and UBO workflows. Includes foundational game subsystems like entity management and input handling as part of a step-by-step learning path—aimed at beginners and intermediate developers learning practical game programming and graphics-engine architecture from scratch. (source: wiki/sources/descriptions/PardCode__OpenGL-3D-Game-Tutorial-Series.md)

Sits in the README `[OpenGL]` lane beside progressive OpenGL tutorials such as [[gltut]] and hands-on engine guides such as [[cpp-game-engine-book]]—educational graphics/engine content, not a cheat or anti-cheat artifact.
