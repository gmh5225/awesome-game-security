# Ghidra Scripts

Collection of Ghidra Scripts developed for CTF competitions to solve common reverse-engineering challenge patterns in an automated fashion. Useful for game security researchers and reverse engineers studying offensive techniques in the cheat / Ghidra plugins lane. (source: wiki/sources/descriptions/ghidragolf__ghidra_scripts.md)

Not a Ghidra extension or framework fork — scoped to runnable GhidraScript automation for recurring RE workflows (decoding, pattern recovery, batch analysis) that overlap with protected-game binary triage.
