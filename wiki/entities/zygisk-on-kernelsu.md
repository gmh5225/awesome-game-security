# ZygiskOnKernelSU

**ZygiskOnKernelSU** is a standalone implementation of the **Zygisk runtime** for rooted Android environments. It provides Zygisk API compatibility on **KernelSU** and can replace Magisk's built-in Zygisk mode. The README documents platform requirements across KernelSU, Magisk, and APatch, along with behavior and compatibility notes. Primary audience: advanced Android modding and security users who need Zygisk-based module support outside the default Magisk stack. (source: wiki/sources/descriptions/Dr-TSNG__ZygiskOnKernelSU.md)

Sits beside other transparent Zygisk API runtimes such as [[rezygisk]] and [[zygisk-mod]] and enables [[zygisk]] module ecosystems on [[kernelsu]] roots without relying on Magisk-bundled Zygisk.
