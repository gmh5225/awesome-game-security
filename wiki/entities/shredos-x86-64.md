# ShredOS x86_64

Bootable Linux environment focused on secure disk erasure. Built with Buildroot and bundles **nwipe** with multiple sanitization methods — DoD patterns, Gutmann passes, PRNG streams, and verification modes — supporting simultaneous wipes across multiple drives. Distributed as BIOS/UEFI-capable IMG and ISO images for both 64-bit and 32-bit x86 hardware, with optional certificates and logs for wipe records. Primarily used by security, forensics, and IT operations teams that need reliable media sanitization before hardware reuse or disposal.
