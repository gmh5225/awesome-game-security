# LibreMaple Client

Custom **MapleStory GMS v83** game client (**LibreMaple Client**, gmh5225): a **C++17** from-scratch client implementation forked from **JourneyClient**, using modern C++ with Roboto fonts and supporting the classic MapleStory protocol and game mechanics. (source: wiki/sources/descriptions/gmh5225__LibreMaple-Client.md)

Useful for game security researchers and private-server developers studying MapleStory v83 client architecture, protocol handling, and presentation stacks—not live official-client anti-cheat bypass tooling.

Complements other v83 client reimplementations such as [[maplestory-heavenclient]] and [[maplestory-client]], GM/admin clients such as [[maplestory-gm-client]], C# GM emulators such as [[maplenecrocer]], WinAPI client sources such as [[winapi-maplestory]], custom engine implementations such as [[gameengine-mapleengine]], and private-server stacks such as [[maplestory-v83-maplestory-cpp]] and [[maplestory-server]].
