# kiero

**Kiero** — C++ universal graphics API hooking library for Windows (x86/x64) games. Auto-detects and hooks Direct3D 9 through 12, OpenGL, and Vulkan by method-table index; pairs with MinHook to install function detours. Ships method tables and sample Dear ImGui integrations for overlay rendering. Commonly used in game security research and tooling to intercept rendering pipelines and build debug or overlay features. (source: wiki/sources/descriptions/Rebzzel__kiero.md)

Cross-platform successor: [[kiero2]] (BYO hooking runtime locator; CMake FetchContent; Win/Linux/macOS for GL/VK).
