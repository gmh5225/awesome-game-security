# PalOps Web

All-in-one operations console for Palworld Dedicated Server, built around deep integration with the PalDefender anti-cheat plugin. Combines PalDefender REST, extended RCON, version checks, whitelist and ban data, and managed JSON configuration with native Palworld REST, server lifecycle control, read-only save indexing, player and guild intelligence, offline MapLibre world maps, resource grants, backups, automation jobs, webhook notifications, and audit-ready access control. ASP.NET Core on .NET 10 with a Vue 3 frontend; designed to run on the same Windows host as the game server rather than as a generic cloud panel. PalDefender is optional for core admin features, while its protection and extended runtime capabilities target server operators who need anti-cheat-aware Palworld administration. (source: wiki/sources/descriptions/CoderYiXin__PalOpsWeb.md)

Complements dedicated-server admin tooling such as [[palworld-rcon]] (Source RCON client), [[palworld-setting-generator]] (browser-side settings authoring), and [[palworld-anti-cheat]] (UE5 AC research) with a co-hosted Windows ops workbench centered on PalDefender enforcement.
