# ChompChomp.io

Browser multiplayer **slither-style .io** arena (JavaScript canvas client with prediction/interpolation; shared `sim.js` rules; Node `build.js` deployment bundle). **Multiplayer Agent** hosts authoritative rooms at 20 Hz: clients send validated steer/boost/fire inputs only; the server simulates movement, pickups, bullets, collisions, scores, and persisted stats. Documented anti-cheat design for studying trustworthy browser netcode without self-hosting a game server.
