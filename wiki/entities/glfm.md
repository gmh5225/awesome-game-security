# GLFM

**GLFM** (Graphics Library For Mobile) is a **GLFW-inspired** single-header **C API** for mobile and web apps that render with **OpenGL ES** or **Metal**. It targets **iOS 9+**, **tvOS 9+**, **Android 4.1+**, and **WebGL via Emscripten**, providing OpenGL ES 2/3 and Metal display setup, retina/high-DPI support, touch and keyboard events, and sensor input (accelerometer, gyroscope, magnetometer). The library handles cross-platform windowing, input, and application lifecycle management for mobile and web platforms. (source: wiki/sources/descriptions/brackeen__glfm.md)

Useful for mobile game developers and cross-platform graphics programmers building OpenGL ES or Metal applications in C/C++—a windowing/input scaffold rather than a cheat or anti-cheat artifact.
