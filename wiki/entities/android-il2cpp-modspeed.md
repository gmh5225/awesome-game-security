# android-il2cpp-modspeed

Android [[il2cpp]] game speed-hack tool: a C++ native library that hooks Unity `Time` class methods to manipulate `deltaTime`, `timeScale`, and fixed timestep values, speeding up or slowing gameplay without changing game logic. Aimed at Android modders and researchers studying time-manipulation attacks on IL2CPP Unity titles. README lane `[Il2Cpp hack speed]`. (source: wiki/sources/descriptions/oobbb__android-il2cpp-modspeed.md)

Complements iOS Unity speed/modding tooling such as [[unityspeedtools]] on the parallel mobile explorer:Unity lane.
