# Software D3D9

Software **Direct3D 9** implementation focused on running real games and other Windows programs, with a long-term goal of broad compatibility across existing D3D9 titles. Aimed at graphics programmers and Windows game-tooling developers in the DirectX / emulation lane—not a Present-hook or overlay framework. (source: wiki/sources/descriptions/code-tom-code__Software_D3D9.md)
