# AutoRename

Python IDA Pro plugin focused on **automatic symbol renaming** during static reverse engineering. Aimed at game security researchers and reverse engineers in the cheat / IDA Plugins lane, with emphasis on asset pipelines and plugin development workflows where recovered names accelerate triage of stripped or obfuscated binaries. (source: wiki/sources/descriptions/crifan__AutoRename.md)

Symbol-recovery automation—not manual batch rename, MAP import, or RTTI-driven class naming. Complements [[renamaida]] (instruction-signature library ID), [[ida-names]] (batch rename/import/export), [[pyclassinformer]] (RTTI-based rename), and [[ida-kallsyms-symbol-renamer]] (Linux kallsyms import).
