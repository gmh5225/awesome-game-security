# godot-demo-projects

Official Godot **demonstration and template projects** — sample games and starter templates maintained by the Godot project, with most demos exported to GitHub Pages for browser play. Targets game developers, reverse engineers, and tooling builders in the README **Game Develop / source** lane who need readable, feature-scoped Godot code beside the full engine tree. (source: wiki/sources/descriptions/godotengine__godot-demo-projects.md)

Complements the core [[godot]] engine source for studying isolated subsystems (2D/3D rendering, physics, networking, UI) without navigating the entire editor/runtime codebase. Pairs with runtime RE via [[gddumper]], defensive modding via [[godot-sandbox]], and editor MCP via [[better-godot-mcp]] on adjacent Godot lanes.
