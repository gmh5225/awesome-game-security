# sdk

Reverse-engineered C++ SDK for a Source engine game (likely CS:GO): class definitions, interface declarations, netvar structures, and function prototypes extracted from the game binary. Headers cover entity classes, weapon data, player info, and engine interfaces for cheat developers and security researchers studying Source internals.
