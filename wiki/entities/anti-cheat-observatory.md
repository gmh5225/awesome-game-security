# Anti-Cheat Observatory

**Anti-Cheat Observatory** (ANTI-CHEAT-OBSERVATORY) is a static reference site that catalogs commercial anti-cheat systems and public research about them using **version-scoped, source-backed claims** rather than informal articles or bypass headlines. (source: wiki/sources/descriptions/ANTI-CHEAT-OBSERVATORY__ANTI-CHEAT-OBSERVATORY.github.io.md)

Built with Astro and TypeScript; curated knowledge lives in Git-backed JSON with schema validation; published as a searchable static site (Pagefind) on GitHub Pages. Organizes system dossiers, mechanism worksheets, build comparisons, relationship graphs, and a discovery pipeline that polls approved RSS, GitHub, and document sources while keeping provenance, review activity, and claim state separate. Node.js maintenance scripts validate cross-references, import editorial proposals, and sync metadata without treating unreviewed feeds as verified findings.

Complements structured link indexes such as [[anti-cheat-research-index]] and Linux hosting feasibility notes such as [[ac-compat-research]] in the Guide / Analysis Framework lane—discovery and evidence framing, not runtime enforcement.
