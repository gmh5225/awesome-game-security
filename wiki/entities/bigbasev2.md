# BigBaseV2

**GTA V mod-menu / cheat base framework** (gmh5225; cheat / game:gta5). C++ and **Lua** codebase centered on **rendering**, **modding**, and **hooking** for building Grand Theft Auto V client-side modifications. Aimed at game security researchers and reverse engineers studying offensive techniques in the cheat / game:gta5 lane. (source: wiki/sources/descriptions/gmh5225__BigBaseV2.md)

Distinct from Python memory-analysis samples such as [[gta5cheat]] and [[gta5cheat-qt]], offline save utilities such as [[gta5view]], and signature-only offset feeds such as [[gta-5-sigs-1.59]]; this is a **C++/Lua hook-and-render base** in the same ScriptHookV / in-process mod-menu lane as [[phake]] and [[grandtheftautov-cheat]].
