# fortnite-sigs

Fortnite **byte-pattern signature collection** (gmh5225; cheat / game:fortnite `[Offset]`). Provides IDA-style signature patterns for locating key functions and data structures in the game binary—`GObjects`, `GNames`, `ProcessEvent`, player-controller helpers, and other critical Unreal engine entry points used in cheat development. Signatures are refreshed per Fortnite build; aimed at game security researchers tracking binary churn and cheat developers maintaining offset accuracy. (source: wiki/sources/descriptions/gmh5225__fortnite-sigs.md)
