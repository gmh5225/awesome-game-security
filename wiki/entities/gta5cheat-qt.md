# gta5cheat-qt

**GTA V cheat with Qt UI** (gmh5225; cheat / game:gta5). C/C++ codebase centered on **memory analysis** for studying Grand Theft Auto V client-side state from an offensive research perspective. Aimed at game security researchers and reverse engineers working in the cheat / game:gta5 lane. (source: wiki/sources/descriptions/gmh5225__gta5cheat_qt.md)

Distinct from ScriptHookV mod-menu frameworks such as [[phake]], the Python variant [[gta5cheat]], and offline save/photo utilities such as [[gta5view]]; this is a **Qt-fronted memory-analysis cheat sample** for studying GTA V live-process manipulation rather than RAGE script hooks or proprietary file-format parsing.
