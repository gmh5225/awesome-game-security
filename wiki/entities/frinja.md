# frinja

Binary Ninja plugin that integrates [[frida]] dynamic instrumentation with Binary Ninja static analysis. Continuation of the BinRida plugin by @c3r34lk1ll3r; aimed at game security researchers and reverse engineers studying offensive techniques in the cheat / Binary Ninja plugins lane. (source: wiki/sources/descriptions/dzervas__frinja.md)

BN-side Frida bridge peer to IDA [[frinet]] and Ghidra [[dragonhook]]; complements other Binary Ninja plugin work such as [[binary-ninja-mcp]], [[triton-bn]], and [[binaryninja-pcode]].
