# PhysX 3.4

**NVIDIA PhysX SDK 3.4** — version-pinned release of NVIDIA's production physics simulation engine for games and interactive applications. Provides **rigid-body dynamics**, **continuous collision detection**, **scene queries**, **vehicle simulation**, **cloth**, and **particle systems** in a component-based architecture with cross-platform support. Aimed at game developers and physics engine researchers studying industrial-grade physics simulation implementation and integration — not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/NVIDIAGameWorks__PhysX-3.4.md)
