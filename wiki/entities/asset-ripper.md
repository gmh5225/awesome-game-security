# AssetRipper

.NET-based tool for extracting assets from Unity serialized files and asset bundles and converting them into native Unity-style outputs. The project is primarily C# and includes extensive parsers, converters, and tooling modules for many Unity resource formats. It supports a broad range of Unity versions and focuses on practical asset recovery and reconstruction workflows. Widely used for Unity reverse engineering, modding, and game content analysis. README lane `[Extracting assets]`. (source: wiki/sources/descriptions/AssetRipper__AssetRipper.md)

Sits in the Game Assets / Unity offline extraction lane beside [[assetstudio]], [[assetstudio-razviar]], and editor-style [[uabe]] when the goal is serialized-file or bundle dump with reconstruction toward editable Unity outputs rather than in-process inspection via [[unityexplorer]].
