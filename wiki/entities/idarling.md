# IDArling

Collaborative reverse engineering plugin for IDA Pro and Hex-Rays. Connects multiple IDA instances so analysts share one database in real time—renames, comments, types, and other IDB edits propagate across sessions. Aimed at game-security researchers and reverse engineers studying offensive techniques in the cheat / IDA Plugins lane. (source: wiki/sources/descriptions/matteyeux__IDArling.md)

Complements remote single-session browsing via [[idarem]], Git-backed partial IDB sync via [[labsync]], and live debugger annotation sync via [[symbridge]]—IDArling targets real-time multi-analyst co-editing of the same IDB, not version-controlled YAML exchange, remote UI, or x64dbg bridging.
