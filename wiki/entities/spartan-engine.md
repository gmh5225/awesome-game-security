# SpartanEngine

Long-running **C++** game engine focused on modern **GPU-driven rendering**. Features a **bindless renderer** with real-time global illumination, **hardware ray tracing**, and a high-frequency physics simulation pipeline. The codebase includes substantial engine subsystems, assets, build scripts, and third-party integrations for real-time 3D development workflows. Aimed at engine programmers, graphics researchers, and advanced game development experimentation. (source: wiki/sources/descriptions/PanosK92__SpartanEngine.md)

Sits in the Game Engine / source lane—a research-focused C++ engine for studying bindless pipelines, RTGI, hardware RT, and modern real-time rendering—not a cheat or anti-cheat artifact.
