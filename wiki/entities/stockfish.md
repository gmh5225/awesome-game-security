# Stockfish

**Stockfish** — strongest open-source chess engine combining classical alpha-beta search with **NNUE** (efficiently updatable neural network) evaluation for superhuman-level play. C++ implementation supports the **UCI** protocol and runs on all major platforms. Aimed at chess-engine developers, AI researchers, and competitive chess players. (source: wiki/sources/descriptions/gmh5225__Stockfish.md)

Listed under the README **Cheat** lane with a `[Chess Engine]` tag — a legitimate open chess engine, not an in-game cheat artifact. Sits in the Game Develop / game-AI research lane beside [[lc0]] (AlphaZero-style RL) and bibliography resources such as [[gameai-paper-list]].
