# Fyrox

**Fyrox** (FyroxEngine) is a feature-rich, production-ready **2D and 3D game engine** written in **Rust** with an integrated **scene editor**. The project ships a broad ecosystem of engine crates, editor tooling, examples, and learning resources for full game-development workflows. Architecture emphasizes Rust-native development, modular crates, and practical authoring through editor-driven iteration. (source: wiki/sources/descriptions/FyroxEngine__Fyrox.md)

Primary use case is building and researching open-source game technology in modern Rust—not a cheat or anti-cheat artifact, but a substantial OSS engine tree for studying scene authoring, rendering pipelines, and editor/runtime boundaries.
