# MapleStory Packer ModPacker

Packing tool for MapleStory game modification files (gmh5225): packages modified assets—sprites, maps, items, skills—into the **WZ** file format used by MapleStory clients, handling compression, encryption, and directory structure for client-side mod distribution. README tag: MapleStory Worlds **`.mod`** file packing/unpacking tools. Aimed at MapleStory modders packaging custom content for private servers or client modifications. (source: wiki/sources/descriptions/gmh5225__maplestory-packer-ModPacker.md)

Complements authoritative server stacks such as [[mnwvs196]] and [[maplestory-v83-maplestory-cpp]] on the asset-pipeline side, and MapleStory Worlds automation such as [[maplestory-worlds-automation]] on the client-mod lane.
