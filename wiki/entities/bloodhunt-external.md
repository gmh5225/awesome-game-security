# bloodhunt-external

External cheat for **Blood Hunt** (ZZZ-Monster) built as a **C++ Visual Studio** solution. Combines an **ImGui + DirectX 9** overlay layer with memory-access helpers, **offsets**, and configuration headers for runtime targeting. The repository also ships **mhyprot-related driver utility** components that support low-level process interaction patterns common in external tools. (source: wiki/sources/descriptions/ZZZ-Monster__bloodhunt_External.md)

Useful for game security research into external cheat architecture and anti-cheat evasion-oriented implementation details on the EAC-backed battle-royale title—complementing the gmh5225 [[blood-hunt]] driver/render sample and other DX9 external overlays such as [[fortnite-external-cheat-source-code]].
