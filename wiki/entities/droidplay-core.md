# DroidPlay Core

**nxnative**-based engine and **DroidPlay** toolchain to run Nintendo Switch and Switch 2 games natively on **arm64 Android** via **Vulkan** (enjoyerofslop/droidplay-core). MIT-licensed research stack; users supply game dumps and `prod.keys`. README category: `Nintendo Switch`. (source: wiki/sources/README-categories.md)

## Positioning

Crossover with Eden-line Android emulators such as [[opensw]] and non-VM APK hosts like [[android-compatibility-layer]]—here the emphasis is native AArch64 execution rather than full-system HLE. Pairs with mobile graphics and integrity research in [[overviews/mobile-security]] and console toolchain study in [[overviews/game-hacking]].
