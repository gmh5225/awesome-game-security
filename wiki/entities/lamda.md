# lamda

FIRERPA (**LAMDA**) is an all-in-one Android device control and automation platform: an on-device server exposes a unified Python client API for UI automation, WebRTC remote desktop mirroring, one-click MITM traffic capture, built-in [[frida]] hooking, network proxying, and AI/MCP agent workflows—without stitching together Appium, mitmproxy, frida-server, and adb separately. Works with or without root across many Android versions; supports virtual displays for background automation and bundles on-device analysis tools (frida-tools, tcpdump, reverse-engineering libraries). Primary use cases include mobile security testing, reverse engineering, protocol analysis, compliance inspection, and multi-device fleet automation. (source: wiki/sources/descriptions/firerpa__lamda.md)
