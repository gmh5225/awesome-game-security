# ArgusAC

**ArgusAC** (hahasc26-lang/ArgusAC) is a modular **Paper/Spigot/Bukkit** anti-cheat plugin for **Minecraft 1.12.2–1.21.x** (Java 17, Maven). Configurable **movement, combat, block-interaction, and packet** checks run through a per-version compatibility layer; optional **ProtocolLib** extends packet analysis. (source: wiki/sources/descriptions/hahasc26-lang__ArgusAC.md)

README category: Anti Cheat / Open Source Anti Cheat System / game:minecraft.

## Enforcement and audit

**HARD** and **SOFT setbacks** return players to last-known-valid positions. Configurable violation thresholds drive staff alerts and automated punishments. Audit tooling emits **JSON Lines** logs with **SHA-256 hash-chain** verification, log queries, and **movement replay** for post-incident review—aimed at server operators who need practical in-game enforcement and investigatable violation history rather than research-only demos. (source: wiki/sources/descriptions/hahasc26-lang__ArgusAC.md)

## Notable checks

Includes an **ElytraFly** detection suite alongside standard movement/combat/world checks.

## Positioning

Broad-version **Bukkit-family** server plugin beside Paper **1.21.11**-focused stacks such as [[aegis-ac]], [[novaguard]], and [[h-ac]], with audit/replay emphasis similar to [[detector-operations]] discipline on [[iustitia]]-class passive review workflows.
