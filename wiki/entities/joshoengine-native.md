# JoshoEngine-Native

Native 2D game engine in C++ with OpenGL rendering. Exposes a relatively high-level cross-platform API built around geometry primitives—vectors, rectangles, and circles—with roadmap items for shaders, physics, and mobile support. Ships engine source plus Visual Studio–oriented build artifacts for Windows development workflows. Aimed at learning engine architecture and serving as a base for custom 2D game development experiments—not a cheat, anti-cheat, or runtime hook artifact. (source: wiki/sources/descriptions/Sirkles__JoshoEngine-Native.md)

Sits in the Game Engine / source lane beside other approachable C++/OpenGL 2D engine scaffolds such as [[cpp-game-engine-book]], [[exengine]], and [[torque2d]].
