# TeleParser

Python utility for collecting and processing data from Telegram channels and chats. Uses Telethon for API access; exports parsed content to JSON and CSV and stores data in MongoDB. Includes cross-platform setup scripts for Windows and Unix-like systems and NLP-oriented dependencies such as pandas and NLTK (lemmatizer). Documented for data collection and message analysis workflows; README warns that Telegram API changes may currently make it unsafe to run without updates. (source: wiki/sources/descriptions/artmih24__TeleParser.md)

README lane: Information System & Forensics — Telegram chat/channel parsing for OSINT and cheat-community message analysis, not endpoint triage.
