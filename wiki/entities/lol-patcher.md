# lol-patcher

Experimental **League of Legends** client patcher/mod sample (gmh5225; cheat / game:lol). Built for fun and experimentation; last updated February 2020 and not maintained since. Useful for game security researchers and reverse engineers studying historical LoL offensive techniques under [[vanguard]]-protected Riot clients.
