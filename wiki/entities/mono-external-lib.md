# mono-external-lib

Windows C++ external library for reading Unity/Mono game internals from outside the process. Parses Mono runtime metadata via process memory reads to enumerate classes, methods, fields, and offsets without injection; reconstructs the Mono type system from raw memory for external cheat / RE workflows against Unity Mono titles (complement to [[il2cpp]] AOT dump/resolver lanes). (source: wiki/sources/descriptions/reahly__mono-external-lib.md)
