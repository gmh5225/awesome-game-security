# D810G

**D810G** (overkazaf/D810G) is a **Ghidra deobfuscation framework** that automates recovery of readable code from heavily obfuscated binaries. A **Java Ghidra plugin** provides UI integration and binary patching; a **Python engine** (Z3, Unicorn, Capstone, Keystone) performs deep analysis. Runs as a standalone CLI or integrated Ghidra analyzer for one-click deobfuscation. (source: wiki/sources/descriptions/overkazaf__D810G.md)

## Capabilities

- Control-flow deflattening for **OLLVM** and **Tigress**
- **MBA** simplification with Z3-verified rules
- Opaque-predicate and bogus-control-flow removal
- Dead-code elimination and string decryption
- **VM devirtualization** via multi-pass pipeline
