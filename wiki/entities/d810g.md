# D810G

**D810G** (overkazaf/D810G) is a comprehensive **Ghidra deobfuscation framework** that automates recovery of readable code from heavily obfuscated binaries. (source: wiki/sources/descriptions/overkazaf__D810G.md)

## Architecture

| Layer | Role |
|-------|------|
| **Ghidra plugin (Java)** | UI integration and binary patching |
| **Python analysis engine** | Deep deobfuscation powered by Z3, Unicorn, Capstone, and Keystone |
| **Deployment modes** | Standalone CLI or integrated Ghidra analyzer for one-click deobfuscation |

## Capabilities

- Control-flow deflattening for **OLLVM** and **Tigress**
- **MBA** simplification with Z3-verified rules
- Opaque-predicate and bogus-control-flow removal
- Dead-code elimination and string decryption
- **VM devirtualization** via multi-pass pipeline

## Use cases

Intended for reverse engineers and security researchers analyzing obfuscated **malware**, **game protection**, and other protected software. (source: wiki/sources/descriptions/overkazaf__D810G.md)

## Positioning

Listed under **Cheat → RE Tools**. Complements Hex-Rays microcode deobfuscators [[d810]] / [[d810-ng]] on the IDA side; pairs with [[control-flow-flattening]] and [[mixed-boolean-arithmetic]] concept pages and overkazaf/[[ponce4ghidra]] Ghidra symbolic execution in the same RE toolchain cluster.
