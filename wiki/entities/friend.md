# FRIEND

IDA Pro plugin that enriches disassembly with register and instruction documentation directly in the analysis view. Extends processor behavior via third-party components such as Capstone and adds contextual hints, external documentation links, and function summaries in both disassembly and decompiler views. Built in C++ with CMake; integrates the IDA SDK and optional Hex-Rays SDK on Windows, Linux, and macOS. Targets reverse engineers who need faster code understanding, including game-security analysts working through protected clients and cheat tooling. (source: wiki/sources/descriptions/alexhude__FRIEND.md)

Sits in the Cheat IDA Plugins / instruction-reference lane beside [[idaref]] and other in-IDA documentation helpers.
