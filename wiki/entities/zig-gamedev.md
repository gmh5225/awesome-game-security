# zig-gamedev

Cross-platform game development library collection written in Zig, providing bindings and wrappers for DirectX 12, Vulkan, OpenGL, and audio APIs. Includes sample applications demonstrating GPU-driven rendering, physics simulations, and real-time graphics techniques, built with the Zig build system. (source: wiki/sources/descriptions/michal-z__zig-gamedev.md)

Sits in the Game Engine / multi-API graphics library lane—useful for studying modern render backends and engine primitives in Zig rather than as a cheat or anti-cheat artifact.
