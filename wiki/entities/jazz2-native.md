# jazz2-native

Open-source C++ reimplementation of **Jazz Jackrabbit 2** built from scratch with a custom engine. Uses **OpenGL ES** rendering, cross-platform deployment, and modern features while recreating the original game's actors, levels, tilesets, and gameplay mechanics without depending on proprietary engine code. (source: wiki/sources/descriptions/deathkiller__jazz2-native.md)

Useful for game-engine researchers and modders studying full title reimplementation techniques and custom 2D engine architectures—not a cheat or anti-cheat artifact.
