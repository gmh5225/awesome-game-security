# Squally

**Squally** (Squalr/Squally) is a **2D platformer** designed to teach **game hacking concepts through gameplay**. Built in **C++** on **Cocos2d-x**, it targets **Windows, macOS, and Linux**. Training-style mechanics cover low-level topics such as **values, operators, and logic** used in game-memory reasoning—aimed at learners who want a practical, gamified introduction to game hacking and reverse-engineering ideas. (source: wiki/sources/descriptions/Squalr__Squally.md)

Complements step-by-step labs such as [[intro-to-gamehacking]] and the Squalr Windows memory editor [[squalr-sharp]]. Built on [[cocos2d-x]] as a cross-platform 2D game framework reference.
