# advanced-efi-driver-with-gdi-and-kernel-mouse-input

**advanced-efi-driver-with-gdi-and-kernel-mouse-input** (Twobot7) is a **UEFI-based memory access and process manipulation framework** for Windows, written in **C/C++**. It combines driver-level memory operations with a **GDI overlay renderer** and **high-frequency kernel mouse input** handling in one stack. The repository advertises stealth and hardening features—encrypted command channels, anti-detection logic, and security-oriented validation paths—for advanced game security experimentation involving low-level access, overlay rendering, and input automation. (source: wiki/sources/descriptions/Twobot7__advanced-efi-driver-with-gdi-and-kernel-mouse-input.md)
