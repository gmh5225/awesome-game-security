# frinet

IDA Pro plugin that bridges [[frida]] dynamic instrumentation with IDA static analysis. Run Frida scripts on a target process while navigating the corresponding code in IDA; synchronizes runtime information—memory values, function arguments, and return values—back into IDA's analysis view for reverse engineers combining dynamic and static workflows. (source: wiki/sources/descriptions/gmh5225__frinet.md)
