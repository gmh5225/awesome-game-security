# IDARustCargo

Python IDA plugin that displays potentially installed Cargo dependencies for Rust binaries under analysis. Aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane who need dependency context while reversing Rust game clients or anti-cheat components. (source: wiki/sources/descriptions/kkent030315__IDARustCargo.md)

Complements symbol recovery tools such as [[ida-rust-demangler]]—this plugin surfaces crate/dependency hints rather than demangling mangled names.
