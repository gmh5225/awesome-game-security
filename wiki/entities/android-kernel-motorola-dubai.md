# android_kernel_motorola_dubai

Android kernel source for **Motorola Dubai** devices (Moto Edge 30) on the Qualcomm **SM7325** (Snapdragon 778G) platform. Includes GKI ABI definitions, Qualcomm-specific drivers, and Motorola device-tree configurations—aimed at Android kernel developers and mobile security researchers customizing or analyzing Snapdragon 778G OEM kernels. (source: wiki/sources/descriptions/SM7325-AE__android_kernel_motorola_dubai.md)

Stock GKI OEM trees like this sit beside peer Qualcomm device sources such as [[android-kernel-xiaomi-sweet]] and [[android-kernel-oneplus-sm7250-wksu]], and GKI driver scaffolds such as [[android-kernel-driver-template]].
