# demumble

Cross-platform Itanium + MSVC C++ symbol demangler that also covers D, Rust, and Swift mangling. Positioned as a replacement for `c++filt` / `undname.exe` in cheat / RE tooling workflows. (source: wiki/sources/descriptions/nico__demumble.md)

CLI-oriented symbol-name recovery—not an IDA plugin (contrast [[ida-rust-demangler]] for Rust-in-IDA demangle/normalize).
