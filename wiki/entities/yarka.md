# yarka

IDA Pro plugin that generates YARA signatures from selected instructions, strings, or raw bytes. Python-based with a built-in editor UI (syntax highlighting, customizable rule templates). Builds rules from disassembly, decompiler output, string views, and function-level hunting selections with related data references—aimed at malware and binary analysts who need reliable YARA rules quickly. (source: wiki/sources/descriptions/AzzOnFire__yarka.md)

Rule **generation** and editing in IDA—not a standalone scanner or multi-disassembler port like [[hyara]].
