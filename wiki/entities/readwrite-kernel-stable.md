# readwrite-kernel-stable

Windows **kernel read/write** driver sample in C/C++ centered on stable cross-process memory access for cheat / **RPM** research. Focuses on kernel-level driver development and modding rather than usermode `OpenProcess` paths blocked by anti-cheat handle stripping. (source: wiki/sources/descriptions/juniorjacob__readwrite-kernel-stable.md)

Mainly useful for game-security researchers and reverse engineers studying offensive kernel memory primitives beside samples such as [[cheat-driver]], [[norsefire]], and [[ntmemory]].
