# unreal-mcp

Model Context Protocol (MCP) server integration for Unreal Engine that exposes Unreal Editor functionality to AI assistants and automation tools. Supports asset management, level editing, blueprint manipulation, and project configuration—aimed at Unreal developers wiring AI-assisted workflows into the editor pipeline rather than reversing shipped game binaries. (source: wiki/sources/descriptions/kvick-games__UnrealMCP.md)

Complements editor-side Unity MCP [[unity-mcp]] and Godot MCP [[better-godot-mcp]] on the Game Develop → MCP server lane; sits opposite Unreal SDK/explorer tooling such as [[unrealengine4-swissknife]] and [[ts-ue4dumper]] when the goal is authoring automation rather than live-process RE.
