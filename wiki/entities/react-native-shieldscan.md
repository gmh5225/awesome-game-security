# React Native ShieldScan

React Native native module for runtime security detection and screen protection on iOS and Android. TypeScript APIs bridge Kotlin and Swift checks for root/jailbreak, [[frida]] instrumentation, debugger attachment, emulator or simulator environments, runtime hook frameworks (Xposed, Substrate), and developer mode, with optional weighted device risk scoring and threat levels. Screen-security features include app-switcher background blur, screenshot and screen-recording prevention, and active screen-recording detection where platform APIs allow. Targets React Native app developers and security teams needing client-side compromise signals and capture protection without a hosted backend. (source: wiki/sources/descriptions/NoobDigital__react-native-shieldscan.md)

Sits in the mobile RASP / integrity lane beside [[free-rasp-reactnative]], [[rs-native-kit-security]], and [[droidshield]].
