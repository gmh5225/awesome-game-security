# Minecraft Anticheat Docs

Educational **Markdown documentation** (aethelreborn/minecraft-anticheat-docs) explaining how Minecraft multiplayer anticheat systems detect and mitigate modified clients. Coverage includes client–server architecture, network packets, cheat categories, server-side versus hybrid detection models, movement prediction engines, combat and reach analysis, packet validation, heuristics and machine learning, enforcement, latency compensation, and well-known Java Edition plugins such as GrimAC, Vulcan, and Matrix. Intended for server operators, plugin developers, and researchers who need defensive conceptual understanding—not cheat development guidance. (source: wiki/sources/descriptions/aethelreborn__minecraft-anticheat-docs.md)

Complements the live plugin catalog [[minecraft-anticheat-list]] and individual Paper/Folia/Fabric AC implementations cited on [[overviews/anti-cheat]].
