# r2a

Historical radareorg pointer for local language-model integration with radare2. The original `radareorg/r2a` GitHub URL no longer exists; the actively maintained successor is [[r2ai]] (LLM-based reversing for radare2). (source: wiki/sources/descriptions/radareorg__r2a.md)

Useful mainly as a catalog redirect for reverse engineers seeking radare2 LLM tooling in the Cheat → Radare Plugins lane—prefer [[r2ai]] for current work.
