# aclist.github.io

**Anti-cheat compatibility list** — a static website (HTML, CSS, JavaScript) that publishes anti-cheat compatibility information and related **Linux gaming** documentation. It includes a curated compatibility list plus guides for companion tools, based on conservative manual verification of how anti-cheat-protected games behave on Linux systems. Primarily serves Linux gamers and game-security researchers tracking platform support and anti-cheat interoperability. (source: wiki/sources/descriptions/aclist__aclist.github.io.md)

Complements crowd-sourced GNU/Linux/Wine/Proton tracking such as [[are-we-anti-cheat-yet]] with a manually verified reference site in the same platform-support lane as macOS CrossOver patchers such as [[crossover-patcher]] and userspace AC-driver study samples such as [[holodori-kernel-bypass]].
