# daila

ChatGPT-focused decompiler AI assistant (**DAILA** — Decompiler Artificially Intelligent Language Assistant) in the cheat / IDA Plugins lane. Aimed at game-security researchers and reverse engineers studying offensive techniques with LLM-assisted decompilation workflows. (source: wiki/sources/descriptions/mahaloz__DAILA.md)

The upstream README notes a separate paper repository for related human–LLM reverse-engineering research (`dec-synergy-study`). Complements other decompiler LLM tooling such as [[ida-llm-explainer]], [[aida]], [[ida-assistant]], and [[gpt-wpre]]—verify model output against disassembly/decompilation per [[research-rigor]].
