# libjpeg-turbo

Independent JPEG Group (IJG) JPEG software, listed in the awesome-game-security corpus for reference. Mainly useful for engine and tooling developers working on asset pipelines in the image codec area. (source: wiki/sources/descriptions/libjpeg-turbo__libjpeg-turbo.md)

Sits in the README Image Codec lane alongside single-header helpers such as [[stb]]—a full JPEG encode/decode reference for texture and screenshot pipeline work, not a GPU Present hook or cheat overlay.
