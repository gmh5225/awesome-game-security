# Retract

Go-based static binary analysis workbench for PE, ELF, and Mach-O: x86/x64 disassembly, control-flow graph construction, pseudocode decompilation, entropy analysis, string extraction, import/export analysis, and YARA scanning, with a browser UI via `--serve`. Aimed at malware triage and reverse engineering before deeper IDA/Ghidra work. (source: wiki/sources/descriptions/kernelstub__Retract.md)

Useful for quick triage of game clients, launchers, and anti-cheat modules—not a debugger or live-process memory tool.
