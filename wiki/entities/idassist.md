# IDAssist

AI-powered reverse-engineering plugin for IDA Pro 9.0+: dockable PySide6 panel that connects to LLM providers (OpenAI, Anthropic, Ollama, LiteLLM, and others) to explain functions, suggest renames, answer code questions, and build a searchable semantic knowledge graph across a whole binary. Supports RAG and MCP integration for agent-assisted workflows. Aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane. (source: wiki/sources/descriptions/jtang613__IDAssist.md)

Complements other in-IDA LLM assistants such as [[aida]], [[ida-assistant]], and [[ida-llm-explainer]], and agent bridges like [[ida-pro-mcp]] / [[ida-mcp-server-plugin]]—this path adds whole-binary knowledge-graph search plus multi-provider cloud/local LLM routing in a single dockable UI.
