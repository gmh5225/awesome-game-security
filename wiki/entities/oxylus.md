# Oxylus

Modern data-driven C++ game engine with a companion editor for interactive 3D apps and games. Renders through Vulkan via the vuk render-graph library and Slang shaders (PBR lighting, meshlet culling, shadow maps, post-processing). Scenes use Flecs ECS; tooling covers Lua scripting, glTF asset management, miniaudio, physics, networking, plus ImGui / RmlUi. Built with xmake for Windows, Linux, and macOS. (source: wiki/sources/descriptions/oxylusengine__Oxylus.md)

Sits in the Game Engine / Vulkan source lane—aimed at developers and engine programmers studying a modular open-source runtime and editor stack, rather than as a cheat or anti-cheat artifact.
