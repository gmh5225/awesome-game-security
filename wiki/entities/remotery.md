# Remotery

Lightweight real-time **CPU and GPU profiler** delivered as a single C library plus a browser-based viewer. Supports multithreaded instrumentation, live command and log channels, saved trace playback, and high-refresh visualization with GPU-rendered UI. Cross-platform on major desktop and mobile targets; samples APIs including D3D11/12, OpenGL, Vulkan, CUDA, and Metal. Aimed at engine programmers and performance engineers needing low-overhead profiling in games or graphics-intensive applications — sits in the README **Game Testing** lane beside in-process profilers such as [[tracy]], [[optick]], and [[rprof]].
