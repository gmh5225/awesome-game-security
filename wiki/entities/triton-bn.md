# triton-bn

Binary Ninja plugin focused on integrating the Triton dynamic binary analysis (DBA) framework into Binary Ninja. Serves as a scaffold for researchers who want to experiment with Triton-backed symbolic execution, instruction lifting, and related offensive-analysis workflows from inside BN rather than a standalone script or IDA-only plugin. Aimed at game security researchers and reverse engineers studying offensive techniques in the cheat / Binary Ninja plugins lane. (source: wiki/sources/descriptions/ergrelet__triton-bn.md)

BN-side Triton peer to in-IDA [[ponce]] and standalone Triton deobfuscation such as [[novmpy]] / [[rumba]]; complements other ergrelet Binary Ninja / Themida tooling such as [[unlicense]] and general BN plugin work like [[binary-ninja-mcp]] / [[binaryninja-pcode]].
