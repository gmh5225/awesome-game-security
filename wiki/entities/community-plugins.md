# community-plugins

Community **Binary Ninja plugin index** maintained by Vector35. Aggregates third-party plugin metadata—licensing, compatibility, and update history—into machine-readable listings. Python tooling validates plugin manifests, generates index files, and automates catalog maintenance so reverse engineers can discover, install, and manage community-contributed Binary Ninja extensions. (source: wiki/sources/descriptions/Vector35__community-plugins.md)

Pairs with the curated first-party catalog [[official-plugins]] and complements analysis plugins such as [[tanto]], [[workflow-objc]], and [[scc]], plus agent transports like [[binary-ninja-mcp]] and [[bn]].
