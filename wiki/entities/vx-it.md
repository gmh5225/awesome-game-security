# VX-It

C/C++ Unreal Engine decrypt sample aimed at the Veiled Experts title surface (`cheat / game:veiled experts`). Useful for game-security researchers and reverse engineers studying per-title UE decryption / offensive memory workflows rather than as a general-purpose SDK dumper. (source: wiki/sources/descriptions/percpopper__VX-It.md)

Sits in the same Unreal decrypt / per-title offset lane as tools like [[fortnite-external-base-source]] (GWorld decrypt) and [[valorant-dumper]], but scoped to Veiled Experts under the README `[Decrypt]` tag.
