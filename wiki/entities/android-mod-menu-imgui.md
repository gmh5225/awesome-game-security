# Android-Mod-Menu-ImGui

Native **C++** Android game **mod-menu template** that injects a **Dear ImGui** cheat overlay into target games, with **OpenGL ES** rendering, touch input handling, and **JNI hooks** for game-function modification. Includes configurable menu layouts and toggle controls—aimed at Android modders building visual ImGui menus. README tag: `[Imgui For Unity]`. (source: wiki/sources/descriptions/gmh5225__Android-Mod-Menu-ImGui.md)

Complements native GLES mod-menu scaffolds ([[imgui-native-modmenu]], [[android-imgui-menu]], [[android-native-app-imgui]]), Unity-on-Android ImGui templates ([[imgui-unity]], [[imgui-unity-with-layout]], [[imgui-unity-android]]), Kotlin/Java floating menus ([[android-modmenu-semijni]], [[android-mod-menu-kotlin]]), and external overlays ([[external-imgui-android]], [[android-native-surface]]) in the mobile cheat / render-draw lane.
