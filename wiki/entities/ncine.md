# nCine

Cross-platform 2D game engine written in C++11 with optional Lua scripting; MIT-licensed and in active development since June 2011. Listed under Game Engine / source (`[2D]`). Useful for game developers, engine programmers, and graphics researchers studying a long-lived open 2D engine tree. (source: wiki/sources/descriptions/nCine__nCine.md)

Sits in the OSS engine-source lane beside other approachable C/C++ 2D engines—not a cheat or anti-cheat artifact.
