# Simple Manual Map Injector

Compact Windows **manual-map DLL injector** (TheCruZ; C++) for studying process injection and PE manual mapping. Supports **x86 and x64** targets with optional **PE header and section stripping**, **configurable memory protection** settings, and **x64 exception-handling** scenarios. Ships sample loader usage plus test DLLs for quick validation. Intended as a minimal teaching/reference implementation of user-mode manual mapping—not a stealth or anti-cheat evasion framework.
