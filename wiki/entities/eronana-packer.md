# Eronana Packer

Basic **Win32 executable packer** for **32-bit PE files**, written in **C++** with an integrated companion compression component to shrink payload size before rebuilding the packed image. The repository ships **Visual Studio solution files**, **command-line usage guidance**, and an **extension branch** demonstrating self-validation ideas. Primary use case is learning **PE packing concepts** for reverse engineering, binary protection experiments, and unpacking research. Listed under Anti Cheat → Binary Packer (`[PE X86]`). (source: wiki/sources/descriptions/Eronana__packer.md)

Useful as an educational x86 PE packer reference alongside [[pe-packer]], [[packer]], and [[packer-tutorial]]—not a full commercial protector or unpacker. Slug disambiguated from [[packer]] (longqun/Packer).
