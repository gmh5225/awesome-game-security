# kernel_devicetree

**MiCode/kernel_devicetree** is a branch index for Xiaomi device **kernel device-tree** sources across multiple models and Android generations. Its README is a concise lookup table mapping branches to devices, platform tags, and release baselines—speeding up discovery of board configuration data used in kernel bring-up, hardware tuning, and compatibility work. (source: wiki/sources/descriptions/MiCode__kernel_devicetree.md)

Primarily useful to Android platform engineers and researchers investigating low-level device configuration and security behavior on Xiaomi hardware. Complements per-device ROM/recovery trees such as [[device-xiaomi-mondrian]] and model-specific kernel sources such as [[android-kernel-xiaomi-pipa]] and [[android-kernel-xiaomi-sweet]].
