# GFred

Ghidra extension that adds a **Command Palette**—keyboard-driven search and invocation of Ghidra actions, scripts, and plugin commands without hunting through menus. A prebuilt extension for Ghidra 9.2.0 ships in the repository `dist/` directory. Targets game-security researchers and reverse engineers working in the cheat / Ghidra Plugins lane. (source: wiki/sources/descriptions/danbrodsky__GFred.md)

Productivity UX peer to in-Ghidra LLM assistants [[ghidrassist]] and [[gpthidra]]; complements broader Ghidra automation via [[ghidra-scripts]], [[ghidra-bridge]], and agent bridges [[ghidrassist-mcp]] / [[ghidra-headless-mcp]].
