# Panda3D

Open-source 3D rendering and game-development framework for Python and C++ programs. Free for any purpose, including commercial use, under a liberal license. Aimed at game developers, engine programmers, and graphics researchers in the Game Engine / source lane. (source: wiki/sources/descriptions/panda3d__panda3d.md)

Sits in the Game Engine / source lane—an OSS engine codebase for development and RE study, rather than a cheat or anti-cheat artifact.
