# Esoterica

**Esoterica** (BobbyAnguelov/Esoterica) is an MIT-licensed prototype C++ game engine framework built as a technology demonstrator and educational platform. The codebase ships core engine systems—serialization, resource management, reflection code generation, and editor tooling—plus advanced runtime pieces such as an actor/ECS hybrid model, animation graph systems, and PhysX-based ragdoll support. Primarily aimed at engine developers and researchers experimenting with rendering, gameplay architecture, and tooling design—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/BobbyAnguelov__Esoterica.md)
