# KittyMemory

Cross-platform **runtime memory patching library** for **Android and iOS** from MJx0. C++ implementation with utilities for **memory scanning**, **pointer validation**, **file helpers**, and **code patch creation**. Integrates **Keystone assembler** for assembly-based patch generation and ships prebuilt binaries plus platform-specific examples. Commonly used in mobile game reverse engineering and security research when controlled in-process memory modification is required. (source: wiki/sources/descriptions/MJx0__KittyMemory.md)

Upstream reference for iOS-focused forks such as [[kittymemory-ios]] and a sibling to MJx0's Unreal mobile tooling [[ios-ue4dumper]] in the same mobile RE ecosystem.
