# genymotion-kernel

**genymotion-kernel** is the Linux kernel source tree used by the **Genymotion** Android emulator. It contains a full kernel tree with Android-specific configurations and patches tailored for the Genymotion virtual device environment. Primary audiences are Android emulator developers and mobile security researchers studying kernel-level behavior in virtualized Android environments. (source: wiki/sources/descriptions/Genymobile__genymotion-kernel.md)

Listed under Cheat / Android Emulator alongside other Genymobile tooling such as [[scrcpy]]. Complements emulator fingerprint libraries such as [[android-emulator-detection]] that score Genymotion-specific props and artifacts.
