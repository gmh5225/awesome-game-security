# Reclass

**Reclass** (IChooseYou/Reclass) is a **structured binary editor** for reverse engineering unknown data layouts. It interprets raw bytes as typed fields—structs, arrays, pointers, and primitives—with **inline editing**, **foldable tree views**, and **hex/ASCII previews**. Built in **C++17** with **Qt 6** and **QScintilla**; supports **plugins** for **process memory** and **WinDbg** data sources. Targets reverse engineers and game security researchers inspecting live process memory, dump files, or other binary inputs. README tags include **MCP for Reclass** for AI-assisted workflows. (source: wiki/sources/descriptions/IChooseYou__Reclass.md)

Complements the ReClass-style layout ecosystem—[[reclass-net]], [[reclass-ex]], and plugin paths such as [[reclass-dma]] and [[reclass-net-driverreader]]—and interactive struct tools such as [[regenny]].
