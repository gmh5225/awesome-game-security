# collateral-damage

Kernel exploit for Xbox **SystemOS** using **CVE-2024-30088**. Targets Xbox One and Xbox Series consoles running kernel versions 25398.4478, 25398.4908, and 25398.4909. (source: wiki/sources/descriptions/exploits-forsale__collateral-damage.md)

Useful for console emulator developers and Xbox researchers in the README `Xbox` lane—adjacent to 360 HLE via [[xenia]] / [[xenia-mac]], original-Xbox stacks [[xemu]] / [[xqemu]], and executable porting via [[recompiler]], but focused on gaining kernel-level access on modern Xbox SystemOS rather than title playback or binary translation.
