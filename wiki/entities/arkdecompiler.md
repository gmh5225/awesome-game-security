# ArkDecompiler

Decompiler for Huawei's ArkCompiler bytecode used in HarmonyOS NEXT applications. Parses ArkTS/ArkJS compiled bytecode from `.abc` files, reconstructs control flow, recovers source-level constructs, and outputs readable JavaScript/TypeScript. Aimed at mobile security researchers and reverse engineers analyzing HarmonyOS apps built with ArkCompiler—not a substitute for Android APK/DEX tooling such as [[jadx]] or apktool. (source: wiki/sources/descriptions/jd-opensource__arkdecompiler.md)
