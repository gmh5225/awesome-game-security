# Scythe AntiCheat

Minecraft Bedrock Edition anti-cheat behavior pack for Realms, worlds, and servers. Built mainly in JavaScript and JSON using the Bedrock Scripting API plus command and function files. Ships many detection modules for combat, movement, packet abuse, chat spam, scaffold behavior, and other common cheats, along with moderation commands and player stats tools for server-side enforcement. Targets Bedrock administrators who need script-based cheat detection and moderation workflow improvements without external client installs. (source: wiki/sources/descriptions/MrDiamond64__Scythe-AntiCheat.md)

Sits in the native Bedrock server-operator lane beside behavior-pack addons such as [[paradox-anticheat]] and MiTM proxies such as [[oomph]], opposite protocol-relay clients such as [[oxclient]], and distinct from Java-server plugins such as [[dakotaac]] and [[minecraft-anti-cheat]].
