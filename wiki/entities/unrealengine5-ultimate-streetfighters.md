# UnrealEngine5-UltimateStreetFighters

UE5 **Street Fighters** title source from gmh5225. Written primarily in C# and C++, with focus on audio systems, physics, and animation for a fighting-game loop. Fits the README **Game Develop / source** lane; useful for game developers, reverse engineers, and tooling builders who want a compact UE5 fighting-title project rather than a full commercial release or SDK-dumper workflow. (source: wiki/sources/descriptions/gmh5225__UnrealEngine5-UltimateStreetFighters.md)
