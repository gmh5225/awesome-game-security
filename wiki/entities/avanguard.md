# Avanguard

Win32 **anti-intrusion library** (GravitLauncher) for hardening **x86 and x64** applications against tampering. The **C/C++** codebase bundles **anti-debugging**, **anti-injection** controls, **memory and call-stack analysis**, **integrity checks**, and protection utilities. Process-level defenses include **callback filtering**, **module checks**, and related defensive APIs with optional language bindings. Primary use case is protecting **game clients** and other sensitive software from debugging, injection, and runtime manipulation. (source: wiki/sources/descriptions/GravitLauncher__Avanguard.md)

## Protection stack

Anti-debug and anti-injection controls; memory/call-stack analysis; integrity checks; callback filtering and module verification for process-level hardening.
