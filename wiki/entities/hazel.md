# Hazel

Early-stage C++ interactive application and rendering engine from TheCherno (YouTube engine-dev series). Ships engine, editor, and sandbox components with setup scripts that prepare dependencies including Vulkan SDK tooling. Primarily C++; developed as both a functional engine and an educational reference for engine design. Primary use case is learning and prototyping real-time rendering and game framework systems—not a shipping commercial engine or cheat artifact. (source: wiki/sources/descriptions/TheCherno__Hazel.md)
