# Automation Examples

**Automation Examples** (RomanceTheHeart/Automation_Examples) is a **Unreal Engine 4** sample project focused on **editor automation utilities**. It demonstrates **C++ Editor Utility** classes built on **Blutility** and **EditorScriptingUtilities** to automate content-pipeline tasks such as **renaming assets**, **duplicating assets**, **cleaning unused content**, and **organizing editor data**. The repository also ships **Blueprint utility assets** and **editor dashboard widgets** for **call-in-editor** workflows. Primary audience: Unreal developers seeking practical patterns for editor-side content tooling—not runtime modding or anti-cheat research. (source: wiki/sources/descriptions/RomanceTheHeart__Automation_Examples.md)

Sits in the UE4 editor-tooling lane beside MCP-driven authoring such as [[unreal-mcp]] and validation plugins such as [[ue-buivalidator]].
