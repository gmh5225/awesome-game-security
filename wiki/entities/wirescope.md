# WireScope

Native Windows C++23 tool that unifies Layer 2 packet capture, per-process traffic accounting, kernel-level firewall rules, and network impairment simulation on a custom WinpkFilter NDIS 6.x filter driver (`wsddntf.sys`) and IOCTL protocol—without Npcap. Direct2D GUI or scriptable CLI with directional rule language; optional bandwidth shaping, delay/loss simulation, and Wireshark-compatible PCAP export. Embedded signed driver package installs on demand via SetupAPI/INetCfg. Listed under Cheat → Packet Sniffer&Filter for game-traffic analysis and anti-cheat networking research.
