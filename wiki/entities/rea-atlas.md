# REA Atlas

**REA Atlas** (jammyfu/rea-atlas) is a curated, multilingual index of open reverse-engineering projects spanning game decompilations, static recompilations, ports, asset-extraction tooling, and broader application, protocol, firmware, and security-related RE work. Each entry records whether it aligns with the **Reverse Engineer Anything** ([[rea]]) workflow, with affirmative tags reserved for projects backed by public documentation. (source: wiki/sources/descriptions/jammyfu__rea-atlas.md)

## Scope

Entries are grouped by console or platform from retro hardware through modern PC and mobile. Maintenance uses structured JSON plus a Python renderer that regenerates localized README tables—aimed at preservationists and researchers who want a single map of legitimate decomp and RE efforts rather than crack or piracy tooling.

## Positioning

Discovery index beside [[awesome-reverse-engineered]] (machine-maintained RE-derived OSS catalog), [[awesome-game-file-format-reversing]], and agent-oriented REA companions such as [[rea-prompts]], [[rea-unlock]], and [[rea-mytechnotalent]]. Pair catalog browsing with [[research-rigor]] and [[static-runtime-evidence]] when elevating listed projects into capability claims.
