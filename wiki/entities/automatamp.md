# AutomataMP

NieR Automata–focused multiplayer / tooling project (praydog). Some important game surfaces are well supported; others are not. Useful for game developers, reverse engineers, and tooling builders in the Game Develop / source lane studying title-specific RE and networking surfaces. (source: wiki/sources/descriptions/praydog__AutomataMP.md)

Complements other praydog engine/SDK tooling ([[luagenny]], [[source2gen]], [[uevr]]) and title-specific mod/RE samples such as [[eldenringmods]] and [[dayzzz]].
