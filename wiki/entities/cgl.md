# cgl

Single-header C graphics and utility library for prototyping, demo scenes, and small games. Provides cross-platform modules for windowing, rendering utilities, noise generation, math helpers, data structures, networking, and threading. Includes Rust and Python wrappers and examples, plus optional systems such as bloom, audio, and node editing. Aimed at developers who want a lightweight C/C++ toolkit for rapid graphics experimentation—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/Jaysmito101__cgl.md)

Sits in the Game Engine / lightweight graphics toolkit lane beside approachable libraries such as [[raylib]] and cross-platform OpenGL frameworks such as [[yourgamelib]].
