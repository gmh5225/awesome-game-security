# rnidbg

Android ARM64 kernel emulator written in Rust — a rewrite of [unidbg](https://github.com/zhkl780810/unidbg) for user-mode emulation of Android kernel and native code paths. The project centers on kernel-level work plus graphics and animation hooks, useful for game-security researchers and reverse engineers studying offensive techniques in the cheat / Android kernel explorer lane. (source: wiki/sources/descriptions/fuqiuluo__rnidbg.md)

Complements DIY Android kernel explorers such as [[op7t]] by emulating ARM64 kernel behavior in user space rather than flashing custom device kernels.
