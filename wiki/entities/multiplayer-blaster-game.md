# MultiplayerBlasterGame

Unreal Engine multiplayer FPS called **Blaster** with full networking support: character animation with aim offsets, weapon mechanics, game mode logic, and HoloLens platform configuration—built as a complete playable multiplayer shooter. Aimed at game developers and engine researchers studying Unreal multiplayer architecture and network replication patterns in the Game Develop / Unreal source lane—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/invi1998__MultiplayerBlasterGame.md)

Complements other Unreal FPS and replication samples in the wiki ([[multiplayer-course-blaster-game]], [[simple-fps-template]], [[epic-survival-game]], [[ue5-cardgame]]) by providing a networked shooter reference for replication, animation, and game-mode study rather than SDK dumping or protection tooling.
