# elfloader

**elfloader** is a Java ELF loader component for **ps5-jar-loader**, focused on kernel-level work, modding, and SDK generation on PlayStation 5. Aimed at anti-cheat engineers and defensive security researchers studying ELF loading and binary packer surfaces in the console modding lane. (source: wiki/sources/descriptions/cryonumb__elfloader.md)

Complements static PS5 ELF analysis via [[ida-ps5-elf-plugin]] and HV/boot research such as [[ps5-linux-loader]]—runtime ELF load path for the ps5-jar-loader stack rather than a standalone packer or IDA plugin.
