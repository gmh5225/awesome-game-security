# Il2CppVersions

Collection of [[il2cpp]] runtime headers and metadata definitions across multiple Unity IL2CPP versions. Used as a version-tracking reference for internal structures, API changes, and metadata-format evolution when analyzing Unity titles built against different engine releases. (source: wiki/sources/descriptions/nneonneo__Il2CppVersions.md)

Complements dump/resolve workflows such as [[il2cpp-resolver]], [[il2cpp-runtime-dumper]], and [[il2cpp-spy]] when structure layouts must match a specific Unity IL2CPP generation rather than a single fixed header set.
