# cs2-internal-sdk

Reverse-engineered **Counter-Strike 2 internal SDK** (clouddss; C++ headers; `[Internal]` tag). Supplies Source 2 engine class definitions, interface pointers, netvar offsets, and schema-system structures with type-accurate representations of CS2's entity system, player classes, weapon data, and rendering structures for internal cheat development, hooking, and memory access. (source: wiki/sources/descriptions/clouddss__cs2-internal-sdk.md)

Sits beside maintained offset feeds such as [[cs2-offsets]], generated SDK dumps such as [[cs2-sdk-source2gen]], and internal bases such as [[cs2-cheat-base]] in the cheat / game:cs2 Source 2 layout lane. Layout drifts per CS2 patch—verify against live binaries.
