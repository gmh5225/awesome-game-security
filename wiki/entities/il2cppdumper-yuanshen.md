# Il2CppDumper-YuanShen

Title-specific [[il2cpp]] static dump tool for **Genshin Impact** (YuanShen): runs against the title’s `GameAssembly` + metadata pair and writes all dump output (`dump.cs`, headers, `script.json`, etc.) to the **current working directory**. README lane `[Il2Cpp Dump for Genshin Impact]`; tagged cheat / game engine explorer:Unity. (source: wiki/sources/descriptions/khang06__Il2CppDumper-YuanShen.md)

From the same author as other khang06 Genshin RE tooling ([[misc]], [[genshinjumpfixer2]], [[mhynot2]]). Complements generic Android dumpers such as [[il2cppdumper]] and live Frida workflows via [[frida-il2cpp-bridge]] when analysts need a Genshin-focused IL2CPPDumper fork rather than a protected-metadata decryptor pipeline.
