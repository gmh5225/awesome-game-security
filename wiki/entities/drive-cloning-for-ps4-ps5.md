# Drive Cloning for PS4/PS5

Documentation and scripts for cloning **PS4/PS5 extended storage drives** on Linux using `dd` and **sparse disk images**, enabling transfer of installed applications between consoles via drive imaging. (source: wiki/sources/descriptions/DrYenyen__Drive-Cloning-For-PS4-PS5.md)

Sits in the README `PlayStation` console lane for storage migration and installed-title transfer workflows—complementary to HV exploit tooling such as [[ps5-linux-loader]] and static RE helpers like [[ida-ps4-helper]] / [[ida-ps5-elf-plugin]].
