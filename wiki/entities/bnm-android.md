# BNM-Android

**C++20 library** for modding **Android Unity IL2CPP** games by **class, method, and field names**. Provides helper abstractions for **runtime access**, **patching**, and integration with common **Android hooking frameworks**. Documents supported Unity versions and ships dependencies focused on text handling and lightweight RTTI behavior. Aimed at mobile game modding and reverse-engineering researchers who want a **reusable foundation** instead of one-off patches. README tag: `[Modding il2cpp games]`. (source: wiki/sources/descriptions/ByNameModding__BNM-Android.md)

Complements static dump/SDK lanes ([[il2cppdumper]], [[il2cpp-sdk-generator]]) and resolver scaffolds ([[il2cpp-resolver]], [[cheat-unity-games]]) when analysts need **name-driven IL2CPP runtime APIs** inside native Android mod modules. Pairs with floating overlay frameworks ([[android-mod-menu]], [[polarimgui]], [[unity-imgui-android]]) and Frida IL2CPP bridges ([[frida-il2cpp-bridge]]) for full mobile mod workflows.
