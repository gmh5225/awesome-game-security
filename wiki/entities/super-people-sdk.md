# Super People SDK

**Dumped Unreal Engine SDK for Super People** (EBalloon) — pre-generated C++ header files for the battle royale title's classes, structs, enums, and blueprint objects. Coverage includes weapons, vehicles, player pawns, AI modules, animation blueprints, and game-specific systems. Primarily useful for game security researchers and reverse engineers studying Unreal Engine SDK structures and Super People's game object hierarchy rather than as a live dumper. (source: wiki/sources/descriptions/EBalloon__Super-People-sdk.md)

Complements applied Super People cheat samples such as [[super-people-esp-aimbot-magic-hack]] and driver-backed client work such as [[superpeople-client]], sibling EBalloon title dumps such as [[veiled-experts-sdk]], and generic UE SDK workflows under [[unreal-object-model]].
