# GOverlay

Open-source DirectX hook and in-game overlay framework that injects native overlay DLLs into DirectX 9–12 titles so desktop GUI apps can render interactive windows inside games. Composites offscreen content from Electron, Qt, CEF, and WPF via C++ native addons and injectors plus a TypeScript/Electron demo client; CMake builds native code and IPC plus shared memory carry host-to-game communication. Supports multi-window z-order and focus, in-game drag/resize, custom-shaped alpha-aware mouse regions, and configurable input interception including hotkeys—aimed at game companions, stats/recording tools, and other overlays needing a web-style UI over a live DirectX game. (source: wiki/sources/descriptions/hiitiger__goverlay.md)
