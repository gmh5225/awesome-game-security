# garlic

Multi-format binary analysis tool in C: PE, ELF, Mach-O, DEX, and APK parsing plus ARM disassembly, opcode decode, and a cross-platform CLI. README tags it as a fast APK/DEX/JAR Java decompiler. (source: wiki/sources/descriptions/neocanable__garlic.md)

Standalone Garlic lane beside [[jadx]] / [[dex2jar]] for Android Java recovery; radare2 integrates the same parser/decompiler via [[r2garlic]].
