# Api Breakpoint

[[x64dbg]] GUI plugin (C++; x64dbg plugin SDK; Visual Studio; x86 and x64 targets) that speeds up **API breakpoint** setup during Windows reverse engineering. It provides a visual workflow to configure and manage breakpoints instead of relying only on manual debugger commands—useful for malware analysts, reverse engineers, and game-security researchers who need quick runtime API tracing. (source: wiki/sources/descriptions/Kwansy98__ApiBreakpoint.md)

Not a standalone debugger—extends [[x64dbg]] breakpoint UX for Windows API hook/tracing sessions (Cheat x64dbg Plugins / Api Breakpoint lane).
