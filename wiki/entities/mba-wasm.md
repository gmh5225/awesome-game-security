# mba-wasm

WebAssembly-based **Mixed Boolean-Arithmetic (MBA)** expression toolkit written in **Rust**. Provides browser-accessible tools for MBA obfuscation, linear congruence solving, permutation polynomial generation, and expression simplification through a web UI with **MathJax** rendering. Targets obfuscation researchers and security analysts exploring MBA expression theory and interactive deobfuscation workflows. (source: wiki/sources/descriptions/MBA-research__mba-wasm.md)

Complements CPU/GPU simplifiers such as [[mbased]], [[mba]], and [[cobra]], synthesis tools such as [[promba]] and [[qsynthesis]], and sample generators such as [[mutaben]] and [[mba-obfuscator]].
