# Game Hacking Code

**Game Hacking Code** (GameHackingBook/GameHackingCode) is the companion example code for the No Starch Press *Game Hacking* book, delivered as a Visual Studio Win32 solution of chapter-by-chapter demos. Projects are primarily C++ and progress from process memory layout, pointers, basic debugging, mutex and file discovery, memory scanning, and remote memory access through code injection (including DLL injection), control-flow manipulation with NOP patches, IAT hooks, virtual-function and call hooks, Adobe AIR hooking, and Direct3D overlay or Present hooking. Supporting Lua scripts illustrate assembly and string searches plus linked-list and map verification for memory forensics workflows. Aimed at students and researchers learning game hacking, reverse engineering, and the defensive implications of common cheat techniques on Windows. (source: wiki/sources/descriptions/GameHackingBook__GameHackingCode.md)

Complements step-by-step beginner labs such as [[intro-to-gamehacking]], practical cheatsheets such as [[gamehacking-cheatsheet]], and hands-on memory tools such as [[pointer-lab]]. Later chapters overlap hooking concepts covered in [[present-hook]] and injection research indexed under [[awesome-injection]].
