# Windows Forensic Artifacts

Structured Markdown reference guide to Windows forensic artifacts used in incident response and investigations. The repository categorizes artifacts across execution, account, file, network, persistence, and user-activity domains, documenting storage locations, parsing options, and correlation strategies for building investigative timelines. Documentation-heavy — not an executable collector — intended for DFIR practitioners and security researchers who need a practical Windows artifact reference. (source: wiki/sources/descriptions/Psmths__windows-forensic-artifacts.md)

Complements automated triage tools such as [[dfirtriage]] and training kits such as [[pwf]], and sits opposite offensive evidence-obscuration catalogs such as [[anti-forensics]] in the IS forensics lane.
