# How to Download and Install WSA

Step-by-step setup guide for installing **Windows Subsystem for Android (WSA)** on **Windows 11**. Documents required prerequisites such as **Developer Mode** and the **Virtual Machine Platform** optional feature, explains how to obtain dependency packages, and walks through installing WSA bundles via **File Explorer** or **PowerShell**. Targets users who need a **manual installation workflow** rather than store or prebuilt distribution channels. Sits in the README `WSA` / `[Guide]` lane as the baseline install path before customized builds such as [[wsa-builds]], rooted images via [[magiskonwsalocal]], MSIX patchers such as [[wsapatch]], and sideload managers such as [[wsa-pacman]].
