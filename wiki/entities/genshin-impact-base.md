# genshin-impact-base

**Base framework** for building Genshin Impact cheats and modifications. Provides core **memory access** patterns, **SDK structures**, and **hook templates** targeting the miHoYo **Unity/IL2CPP** game runtime. (source: wiki/sources/descriptions/gmh5225__GenshinImpact-Base.md)

Useful as an upstream scaffold for title-specific HoYoverse offensive research—researchers study how shared IL2CPP hooking and memory primitives are factored before gameplay mods such as [[genshin-cheat]] or client UI samples such as [[genshin-remove-banner]]. Pairs with dump forks such as [[il2cppdumper-yuanshen]], extracted table mirrors such as [[genshin-genshin-data]], and CFG/shader RE tooling ([[genshinjumpfixer2]], [[misc]]) in the same Genshin lane.
