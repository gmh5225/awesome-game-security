# Perf-Ninja

Online C++ performance-optimization course structured as lab assignments covering CPU cache misses, branch mispredictions, vectorization, memory access patterns, and other low-level bottlenecks. Each lab ships benchmarks, validation checks, and automated CI on Intel Alder Lake, AMD Zen 3, and Apple M1. Aimed at systems programmers and game developers learning practical CPU performance analysis and micro-optimization beside runtime profilers such as [[tracy]] and [[rprof]].
