# SuperSplat

Web-based 3D Gaussian Splatting editor built on the PlayCanvas engine. Supports viewing, editing, and optimizing splat scenes with selection tools, animation tracks, camera poses, and PLY/splat export. Aimed at graphics researchers and content pipelines that ingest Gaussian-splat assets into game engines. (source: wiki/sources/descriptions/playcanvas__supersplat.md)

Sits in the README 3D Graphics / AI mesh-splat lane—a browser splat-authoring surface rather than a Present hook, cheat overlay, or anti-cheat artifact.
