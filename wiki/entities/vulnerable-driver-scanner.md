# vulnerable-driver-scanner

Lightweight C++ command-line scanner that searches directories for vulnerable Windows drivers—intended for quick triage of driver files and identification of potential bring-your-own-vulnerable-driver (BYOVD) exposure in common system driver locations. Useful for anti-cheat bypass research, incident response, and defensive security audits. (source: wiki/sources/descriptions/Xxmmy__vulnerable-driver-scanner.md)
