# malimite

Desktop **decompiler** for analyzing **iOS IPA files** and **macOS application bundles**. Written primarily in **Java** and built around **Ghidra-based decompilation workflows**. Features include automatic Apple resource decoding, Swift class reconstruction, and support for Swift and Objective-C binaries. Primary use: reverse engineering and security research on Apple applications, including malware analysis and code auditing. (source: wiki/sources/descriptions/LaurieWired__Malimite.md)

Complements IDA-centric iOS helpers such as [[ida-ios-helper]], LLM Mach-O decompilation via [[aimachdec]], and Binary Ninja Objective-C workflows such as [[workflow-objc]].
