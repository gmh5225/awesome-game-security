# godot-resource-remaps

Godot Engine editor export plugin that enables platform-specific resource remapping: developers swap textures, audio, scenes, and other assets per target platform (Windows, Android, iOS, Web) during export using feature tags. Fits the **Game Engine → Plugins:Godot** lane for shipping per-platform builds without duplicating entire project trees. (source: wiki/sources/descriptions/allenwp__godot-resource-remaps.md)

Complements the core [[godot]] export pipeline and official sample templates via [[godot-demo-projects]] on the asset-variant / platform-targeting side—distinct from runtime RE dumpers such as [[gddumper]], defensive mod sandboxes such as [[godot-sandbox]], and editor MCP tooling such as [[better-godot-mcp]].
