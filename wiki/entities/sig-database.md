# sig-database

Collection of IDA Pro **FLIRT** (Fast Library Identification and Recognition Technology) signature files for Linux libraries—especially OpenSSL and other system libs—across multiple Ubuntu releases and architectures (amd64/i386), organized by distribution version. Helps rename statically linked library functions when reversing stripped Linux binaries. (source: wiki/sources/descriptions/push0ebp__sig-database.md)

Complements Windows-oriented library-ID tooling such as [[idenlib]] / [[idenlibx]] and IDA signature scanners such as [[ida-fusion]].
