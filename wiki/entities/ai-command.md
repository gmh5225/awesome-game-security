# AICommand

ChatGPT integration for the Unity Editor from keijiro — editor-side natural-language assistance for game developers, engine programmers, and graphics researchers in the Game Engine Plugins:Unity lane. (source: wiki/sources/descriptions/keijiro__AICommand.md)

**Security note:** the OpenAI API key is stored in `UserSettings/AICommandSettings.asset`; treat that asset like a secret and avoid committing it to VCS or sharing project folders that include it.

Complements [[unity-mcp]] (MCP bridge) and [[unicli]] (terminal CLI) as another AI-assisted Unity Editor workflow — direct ChatGPT integration rather than MCP or shell automation.
