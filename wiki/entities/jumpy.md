# jumpy

Tactical 2D multiplayer shooter built in Rust with asset-driven game design. Cross-platform support includes cross-compilation; arcade-style gameplay with effects and animations; modular asset system for maps, characters, and items. (source: wiki/sources/descriptions/fishfolk__jumpy.md)

Useful for Rust game developers and engine researchers studying 2D multiplayer game architecture and asset pipeline design—not a cheat or anti-cheat artifact.
