# VAC-ModuleDumper

C/C++ VAC module dump tool for offline RE of Valve Anti-Cheat modules. Useful for game-security researchers and reverse engineers studying offensive techniques under the cheat / explore anticheat system:vac lane. (source: wiki/sources/descriptions/nevioo1337__VAC-ModuleDumper.md)

Companion dump surface to [[vac3-dumper]] (timed multi-module loads) and [[vackeyretrieval]] (ICE key recovery): this repo focuses on dumping VAC modules rather than key retrieval or runtime inhibition ([[vac3-inhibitor]]).
