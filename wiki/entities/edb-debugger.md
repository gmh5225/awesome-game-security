# edb-debugger

**edb** (Evan's Debugger) is a cross-platform binary debugger for Linux inspired by OllyDbg. The Qt-based C++ GUI exposes disassembly, registers, memory-map browsing, stack view, breakpoint management, and plugin extensibility. Process control uses **ptrace**; supported targets are x86 and x86-64 with instruction-level stepping, memory search, and binary-analysis plugins—aimed at Linux reverse engineers and exploit developers who want an OllyDbg-style graphical workflow. (source: wiki/sources/descriptions/eteran__edb-debugger.md)
