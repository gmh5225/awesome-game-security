# XFiles

File explorer for rooted Android. Ships prebuilt APKs in GitHub Releases. Useful for game-security researchers and reverse engineers studying offensive workflows in the Cheat Android File Explorer lane. (source: wiki/sources/descriptions/pgp__XFiles.md)

Sits beside on-device CLI hosts such as [[termux-app]] and memory explorers such as [[rwmem]] / [[mypower]].
