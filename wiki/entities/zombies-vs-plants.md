# ZombiesVsPlants

Plants vs. Zombies clone in C++ using SDL2 (SDL2_image, SDL2_ttf). Implements lane-based tower defense: plant placement, projectile physics, zombie wave spawning, and sun resource management. Cross-platform builds on macOS use bundled SDL2 frameworks. (source: wiki/sources/descriptions/mhyousefi__ZombiesVsPlants.md)

Sits in the README **Game Develop / source** lane as a compact 2D game-loop sample for studying input, rendering, entity updates, and wave/economy systems—not a cheat or anti-cheat artifact.
