# yara4ida

Unofficial YARA plugin for IDA Pro. Brings YARA rule scanning into the disassembler for game-security researchers and reverse engineers studying offensive techniques in the cheat / IDA Plugins lane. (source: wiki/sources/descriptions/kweatherman__yara4ida.md)

Default hotkey is **Alt-Y**; rebind via the IDA `plugins.cfg` file.

Complements other in-IDA YARA tooling such as [[yarascan-ida]] (Python file scan) and compiled-rule analysis via [[yaravm]] (`.yar.bin` bytecode disassembly).
