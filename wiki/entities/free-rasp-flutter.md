# Free-RASP-Flutter

Talsec freeRASP plugin for Flutter: mobile in-app RASP and security monitoring on Android and iOS. Dart APIs bridge native Kotlin and Swift layers backed by the Talsec runtime, exposing threat callbacks and optional app termination when protections are bypassed. Detection coverage includes root/jailbreak, hooking frameworks such as [[frida]], debuggers, tampered app signatures, unofficial installs, emulators, malware, unauthorized screen capture or recording, device binding, automation tools such as Appium, VPN and unsecure Wi-Fi use, time and location spoofing, and multi-instance abuse. Freemium SDK aimed at Flutter developers needing client-side hardening against reverse engineering, repackaging, and compromised environments—including games and other high-value Flutter applications. (source: wiki/sources/descriptions/talsec__Free-RASP-Flutter.md)

Sits in the mobile RASP / integrity lane alongside React Native sibling [[free-rasp-reactnative]], Capacitor sibling [[free-rasp-capacitor]], Unity sibling [[free-rasp-unity-poc]], native iOS [[free-rasp-ios]], Android-only [[droidshield]], and device-fingerprint SDKs [[trustdevice-android]] / [[trustdevice-ios]].
