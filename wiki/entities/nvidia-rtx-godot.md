# NVIDIA RTX Godot

**NVIDIA RTX fork** of the open-source [[godot]] game engine with enhanced rendering capabilities. Extends upstream Godot with **RTX-specific optimizations** across the rendering server, editor interface, and scene tree systems. Aimed at game developers and graphics researchers working with **ray tracing**, advanced rendering techniques, and **NVIDIA GPU-accelerated** game development in the Godot ecosystem—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/NVIDIA-RTX__godot.md)

Sits in the Game Engine / source lane as a vendor-enhanced Godot tree for studying RTX render paths beside the official [[godot]] source and Godot ecosystem tooling ([[godot-demo-projects]], [[gddumper]], [[better-godot-mcp]]).
