# VMP3 x64 Disasm (prerelease)

**VMProtect 3 x64 disassembler** that analyzes and disassembles VMProtect 3 virtual-machine bytecode. Decodes VMP3's custom instruction set, identifies virtual opcode handlers, and reconstructs the original instruction flow from virtualized code. Targets the 64-bit variant of VMProtect's virtual machine. Aimed at reverse engineers deobfuscating VMProtect 3-protected 64-bit binaries. (source: wiki/sources/descriptions/gmh5225__VMP-Vmp3_64bit_disasm-prerelease-.md)

Static disassembly / handler-mapping surface in the Cheat → Fix VMP lane—complements symbolic-exec recovery tools such as [[novmpy]] and [[rumba]], editor utilities such as [[vmp3-utils]], and the [[vmprotect]] reference engine.
