# UWPDumper

Windows **DLL and injector tool** for **dumping UWP application files at runtime**. Injects into a target process and extracts **package data** that is otherwise gated by the **UWP file-system model**. **C++** implementation with **command-line handling**, built for the **Windows 10 SDK**. Useful for **reverse engineering** and **security analysis** of UWP software, including **protected game builds** distributed through the Microsoft Store / Xbox ecosystem.
