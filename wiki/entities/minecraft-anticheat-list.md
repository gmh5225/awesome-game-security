# Minecraft Anticheat List

Curated catalog and interactive website listing public anti-cheat **plugins and mods** for every major Minecraft edition and server platform. Built with **Kotlin/JS** and **Gradle**, storing hundreds of validated JSON entries compiled into a searchable table showing each solution's platform, supported versions, pricing, links, and maintenance status. At runtime it enriches entries by querying **GitHub** and **Spigot** APIs to infer whether projects are active, discontinued, or unavailable. Coverage spans Java and Bedrock ecosystems including **Bukkit**, **Sponge**, **Fabric**, **Forge**, **Nukkit**, and **PocketMine**. Aimed at server operators, anti-cheat researchers, and anyone evaluating or comparing Minecraft server-side cheat detection options. (source: wiki/sources/descriptions/ManInMyVan__Minecraft-Anticheat-List.md)

Index hub rather than a single AC product; complements individual plugins such as [[minecraft-anti-cheat]], [[nocheatplus]], [[windfall-anticheat]], [[dakotaac]], and Bedrock behavior-pack stacks such as [[paradox-anticheat]] and [[scythe-anticheat]].
