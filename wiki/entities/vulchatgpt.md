# vulchatgpt

**BinAIVulHunter** — an advanced IDA Pro plugin in the cheat / IDA Plugins / `[ChatGPT]` lane that uses multiple AI providers (OpenAI GPT, Google Gemini, and Ollama) for intelligent vulnerability analysis, code explanation, and security assessment of decompiled functions. Aimed at game-security researchers and reverse engineers studying offensive static RE techniques. (source: wiki/sources/descriptions/ke0z__VulChatGPT.md)

Complements other decompiler LLM tooling such as [[daila]], [[ida-plugin-pcodegpt]], [[ida-llm-explainer]], [[aida]], and [[ida-assistant]]—verify model output against disassembly/decompilation per [[research-rigor]].
