# dotrix

Open-source 3D engine for Rust developers; the name derives from *dot* and *matrix*. Aimed at game developers, engine programmers, and graphics researchers studying custom engine architecture in the Game Engine / source lane—not anti-cheat or shipped-title reverse engineering. (source: wiki/sources/descriptions/lowenware__dotrix.md)

Sits beside other Rust engine libraries such as [[nightshade]] and [[macroquad]] as a from-scratch 3D engine study surface.
