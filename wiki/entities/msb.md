# MSB

**Legacy MapleStory GMS trainer toolkit** (PrinceFroggy). Mixes **C++ trainer components** with a **C# launcher** and **Visual Studio** solution layout. Includes modules for **injection and runtime control**; README documents historical effectiveness for **GMS client versions 128–140**. Best treated as a historical reference for studying older MMO trainer architecture rather than a maintained cheat stack. (source: wiki/sources/descriptions/PrinceFroggy__MSB.md)

Sits beside PrinceFroggy's discontinued bot framework [[msc]] and modern MapleStory automation such as [[maplestory-auto-level-up]]. Client-layout and offset corpora such as [[maplestory-cms95-client-address]] and [[twms-hacking-data]] complement trainer RE for map/version-specific memory work.
