# open-source-games

Curated index of open-source games, including classic DOS-era reimplementations such as Commander Keen (1–6, Dreams) and Cosmo's Cosmic Adventure—playable original episodes plus community mods. (source: wiki/sources/descriptions/bobeff__open-source-games.md)

Listed under README **Game Develop → Guide** alongside [[awesome-open-source-games]] and other game indexes. Useful for game developers, reverse engineers, and tooling builders who need small, inspectable game codebases to study engine architecture, asset pipelines, or mod tooling—not a security product itself.
