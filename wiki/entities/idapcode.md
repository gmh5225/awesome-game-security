# idapcode

Python IDA Pro plugin that displays Hex-Rays P-Code (microcode) for the current function. Focused on plugin development and microcode visibility during static RE of protected game binaries. Aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane. (source: wiki/sources/descriptions/binarly-io__idapcode.md)

Companion to other Hex-Rays microcode tooling such as [[genmc]], [[ida-plugin-pcodegpt]], and [[microavx]]—focused on viewing P-Code for the active function rather than LLM assistance or AVX lifting.
