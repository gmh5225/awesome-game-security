# GTAV_DragResize

**GTA V drag-to-resize mod** (gmh5225). Enables drag-to-resize for in-game UI windows and HUD elements by modifying the game's **rendering** and **input handling**, allowing overlay windows and HUD components to be resized interactively. Aimed at modders and researchers studying RAGE client UI layout and input routing rather than gameplay cheat surfaces. (source: wiki/sources/descriptions/gmh5225__GTAV_DragResize.md)

Distinct from ScriptHookV mod-menu cheat frameworks such as [[phake]] and [[grandtheftautov-cheat]], memory-analysis cheat samples such as [[gta5cheat]], and offline save/photo utilities such as [[gta5view]]; this is a **client UI modification** lane focused on overlay/HUD resizing rather than scripting hooks, live-process memory edits, or proprietary file-format tooling.
