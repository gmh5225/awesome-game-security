# cpp-3d-game-tutorial-series

C++ tutorial codebase for building a 3D game and engine from scratch on Windows. Walks through Win32 windowing, DirectX 11 graphics, input handling, entity-component patterns, and game sample integration in a staged series. Separates reusable engine modules from the game project and tracks learning milestones through tagged versions—aimed at learners and developers who want hands-on understanding of low-level game engine architecture. (source: wiki/sources/descriptions/PardCode__CPP-3D-Game-Tutorial-Series.md)

Sits in the README `[DirectX]` lane beside PardCode's OpenGL sibling [[opengl-3d-game-tutorial-series]], DirectX guides such as [[hw3d]] and [[intro-to-dx11-revisited]], and hands-on engine books such as [[cpp-game-engine-book]]—educational graphics/engine content, not a cheat or anti-cheat artifact.
