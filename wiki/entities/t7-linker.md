# t7-linker

Linker and modding tool for **Call of Duty** titles on the **T7 engine** scripting stack. Processes compiled game script files, links script modules together, and handles the T7 **GSC script bytecode** format used in Black Ops III modding workflows. The curated README entry also describes it as a highly accurate **Black Ops 2 FastFile linker** — treat title/engine scope as versioned and verify against the repo before building enforcement claims. (source: wiki/sources/descriptions/gmh5225__t7-linker.md)

Aimed at Call of Duty modders and researchers studying T7 scripting infrastructure, compiled script linking, and FastFile packaging.
