# LegionCore 7.3.5

World of Warcraft **Legion** expansion server emulator targeting client version **7.3.5**, built on the **TrinityCore** framework. The C++ authoritative server implements world simulation, dungeon and raid mechanics, artifact weapons, class halls, world quests, and other Legion-specific content. It handles player management, NPC scripting, spell processing, and the WoW network protocol. Aimed at WoW private-server developers and game-server researchers studying modern MMO expansion server implementation—not a live-service cheat client. (source: wiki/sources/descriptions/dufernst__LegionCore-7.3.5.md)

Sits in the README **Private Server** / `[wow]` lane beside other authoritative MMORPG emulators such as [[sapphire]] and [[rathena]], and complements WoW client-side research samples such as [[dumpwow]], [[wow-iat-fix]], and [[x14-08-coverstory-blizzard]].
