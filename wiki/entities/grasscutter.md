# Grasscutter

Open-source **Genshin Impact** private-server emulator implementing authoritative server-side game logic, player progression, world simulation, and client–server network protocol handling. The **Java** server supports quests, gacha systems, dungeons, multiplayer interactions, and scripted game events. Framed for game-server researchers and reverse engineers studying MMORPG server architecture and Genshin Impact's client–server protocol—not a live-service cheat client. (source: wiki/sources/descriptions/Grasscutters__Grasscutter.md)

Sits in the README **Private Server** / HoYoverse lane as the upstream server stack that Grasscutter-oriented cheat clients such as [[genshin-akebi-gc]] and [[easypeasy-gc]] target, beside offline dataset mirrors ([[genshin-genshin-data]]), IL2CPP dump forks ([[il2cppdumper-yuanshen]]), and live-client offensive samples ([[genshin-cheat]], [[genshin-impact-base]]).
