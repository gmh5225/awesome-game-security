# Binary Internals Viewer

Java application for **visual, interactive inspection of binary file formats** down to field and bit-level structure. Supports BMP, Java class files, JPEG, PNG, and ZIP, with additional format modules under development. Built with OpenJDK and Maven; also ships reusable standalone format libraries. Useful for reverse-engineering education, parser development, and hands-on binary format analysis. (source: wiki/sources/descriptions/amosshi__binaryinternals.md)

Complements hex workbenches such as [[hexwalk]] and PE-focused viewers such as [[totalpe2]] when studying container/image formats, custom asset blobs, or parser logic before deeper IDA/Ghidra work.
