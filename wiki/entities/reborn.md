# Reborn

Rust-based Fortnite cheat framework with a web-server backend, SQLite database, and Discord-bot interface. Modular crate layout separates the cheat server, bot commands, and client communication—useful for researchers studying Rust cheat frameworks and web-controlled game-modification architectures rather than classic in-process C++ internals.
