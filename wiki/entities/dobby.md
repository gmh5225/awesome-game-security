# Dobby

Lightweight, multi-platform, multi-architecture hook framework in C/C++. Centers on kernel-level work, networking, and plugin development; aimed at graphics programmers and Windows game tooling developers in the DirectX / hook lane. Listed alongside Detours-family, PolyHook, and plthook-style libraries under cheat / hook research. (source: wiki/sources/descriptions/jmpews__Dobby.md)
