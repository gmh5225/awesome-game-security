# tp-2dside-scroller-bp

Unreal Engine 5 **blueprint template** from CobraCodeDev for building 2D side-scroller games. Provides a starter project structure, sample assets, and setup guidance for Paper2D-style workflows. The template is versioned for newer UE5 releases and references optional advanced variants that use the PaperZD plugin for animation tooling. Aimed at game developers prototyping side-scrolling gameplay rather than security research. (source: wiki/sources/descriptions/CobraCodeDev__TP_2DSideScrollerBP.md)

Complements other Unreal Game Develop starter projects in the wiki ([[ue5-roll-a-ball-game]], [[simple-fps-template]], [[fightinggame-ue5]]) by focusing on Paper2D blueprint scaffolding for 2D platformers rather than 3D editor tutorials, FPS combat, or fighting-game animation blueprints.
