# ida-android-breakpoint

Python IDA plugin that aids setting breakpoints on Android native `.so` libraries during static RE workflows. Aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane studying offensive Android native techniques. (source: wiki/sources/descriptions/lj94093__IDAAndroidBreakpoint.md)

Not a runtime debugger—scoped to IDA-side breakpoint setup for Android `.so` analysis.
