# FridaScript

Collection of [[frida]] instrumentation scripts for dynamic analysis of games and applications. JavaScript hooks intercept function calls, trace API usage, and modify runtime behavior on Android, iOS, and desktop platforms. README categorizes it as a low-level scripting app for iOS.
