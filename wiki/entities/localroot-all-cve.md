# Localroot-ALL-CVE

Large historical collection of **local privilege escalation (LPE)** proof-of-concept exploits organized by year and CVE. Mostly C exploit code with shell and Python scripts, plus per-vulnerability notes and references. The year/CVE layout makes it practical to browse kernel-era exploit samples and recreate older research scenarios in controlled lab environments. Primary use cases: security education, exploit-development study, and vulnerability timeline reference—not a single maintained framework or defensive analysis suite. (source: wiki/sources/descriptions/Snoopy-Sec__Localroot-ALL-CVE.md)

## Layout

- CVE/year-indexed directory structure for browsing historical LPE samples
- C PoCs plus auxiliary shell and Python tooling
- Per-vulnerability notes and external references
