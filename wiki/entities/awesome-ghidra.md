# awesome-ghidra

Curated **awesome list** of Ghidra ecosystem resources for reverse engineering. Markdown collection of scripts, plugins, extensions, and reference material spanning automation, malware analysis, binary diffing, and workflow enhancements. Listed tools include both Java and Python extensions with headless and interactive usage options. Aimed at reverse engineers and game security researchers who want a quick map of practical Ghidra tooling. (source: wiki/sources/descriptions/AllsafeCyberSecurity__awesome-ghidra.md)

Link catalog rather than a single Ghidra binary; complements the full [[ghidra]] framework source, cross-disassembler plugin indexes such as [[awesome-ida-x64-olly-plugin]], and toolchain managers such as [[ghidra-manager]].
