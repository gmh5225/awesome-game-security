# Lumos

Open-source C++ game engine with a cross-platform editor. Provides Vulkan/OpenGL rendering with PBR materials, a scene graph with ECS architecture, physics (Box2D/Bullet), audio, Lua scripting, 2D/3D support, and a Dear ImGui-based editor interface. Includes asset pipelines, serialization, and multi-platform build support—aimed at indie game developers and engine enthusiasts building accessible 2D/3D games. (source: wiki/sources/descriptions/jmorton06__Lumos.md)

Sits in the Game Engine / source lane—an OSS C++ 2D/3D engine codebase for development and graphics study, not a cheat or anti-cheat artifact.
