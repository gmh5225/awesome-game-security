# ImGui-Unity-Android

ImGui integration for Unity games on Android that renders Dear ImGui overlay menus through OpenGL ES inside Unity's rendering pipeline—aimed at mod-menu and in-game debug UI on Android Unity titles. (source: wiki/sources/descriptions/gmh5225__ImGui-Unity-Android.md)

Complements springmusk026 Unity-on-Android ImGui templates ([[imgui-unity]], [[imgui-unity-with-layout]]), Zygisk Unity menus ([[imgui-zygisk-unity]]), and native GLES mod-menu scaffolds ([[imgui-native-modmenu]], [[android-native-app-imgui]]) in the mobile cheat / render-draw lane.
