# GH D3D11 Hook

Guided Hacking educational **DirectX 11 hook** sample focused on DX11 Present/vtable interception. Heavily commented C++ with **no external library dependencies**—aimed at graphics programmers and Windows game tooling developers learning the DirectX hook / overlay path. (source: wiki/sources/descriptions/guided-hacking__GH_D3D11_Hook.md)

Sits beside other minimal DX11 learning templates such as [[dx11-basehook]] and [[directx11hook]] in the [[present-hook]] lane; pairs with Guided Hacking injection tooling such as [[guided-hacking-injector]] for in-process DLL load study.
