# rprof

Lightweight CPU scope-based profiling library for games: hierarchical timing via thread-local storage and platform high-resolution timers with minimal overhead. Ships an ImGui/ImPlot inspector for flame graphs and frame-time distributions, plus LZ4-compressed capture-file serialization. Sits in the Game Testing / frame-performance lane beside heavier profilers such as [[tracy]]. (source: wiki/sources/descriptions/milostosic__rprof.md)
