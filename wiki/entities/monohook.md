# MonoHook

Runtime method hooking framework for C# in Unity games on **Mono** or **IL2CPP** backends. Patches JIT or AOT native code in memory instead of on-disk assemblies, preserving debugging behavior and stack traces. Primary C# implementation with a small native component; supports multiple Unity generations and .NET runtime variants across editor and device targets. Use cases include Unity instrumentation, reverse engineering, and controlled function replacement in game security research. (source: wiki/sources/descriptions/Misaka-Mikoto-Tech__MonoHook.md)
