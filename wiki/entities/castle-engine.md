# Castle Engine

C/C++ game engine focused on **DirectX 11**, shader work, and rendering. Aimed at game developers, engine programmers, and graphics researchers studying a DX11 engine source tree in the README **Game Engine → Source** lane—not a cheat, dumper, or anti-cheat artifact. (source: wiki/sources/descriptions/benanil__Castle-Engine.md)
