# learn-directx

Learning resource and documentation set for building graphics applications with DirectX 12. Step-by-step tutorials progress from window creation and hello-triangle examples through command bundles, frame buffering, textures, and resource state management. Covers low-level GPU concepts such as synchronization, descriptor handling, and performance-oriented API usage on modern Windows—aimed at developers who want a practical path into Direct3D 12 and game rendering fundamentals, not Present-hook or overlay tooling. (source: wiki/sources/descriptions/PAMinerva__LearnDirectX.md)
