# Universal Modder

**Universal Modder** (rehan-remade/universal-modder) is a toolkit and shared knowledge base for AI coding agents to plan, build, and verify mods for PC games you own. A Python **`um`** CLI (installed via [uv](https://github.com/astral-sh/uv)) covers install scanning and engine detection, save backup, art generation and processing through fal or ComfyUI, Blender-based 3D-to-sprite rendering, Windows launch and capture automation, and publishing checks. **Agent Skills** document a full modding loop plus engine playbooks, web research, asset pipelines, mashup mods, and reverse-engineering workflows using tools such as [[ghidra]], ILSpy, [[cheat-engine]], and [[frida]]. A searchable knowledge base collects field notes from prior mods so agents can reuse routes, versions, and verification steps. Scope is legitimate single-player and self-hosted modding and research, with explicit rules against bypassing anti-cheat, DRM, or cheating in online play. (source: wiki/sources/descriptions/rehan-remade__universal-modder.md)

Sits in the README **Game Develop → AI Agents** lane beside multi-engine scaffolds such as [[everything-game-dev-code]] and version-pinned skill packs such as [[awesome-gamedev-agent-skills]], but focuses on end-to-end **owned-game mod recon, build, and in-game verification** rather than greenfield engine authoring.
