# source-sdk-2013

**Source SDK 2013** (ValveSoftware) — official Valve Source 1 SDK codebase for building non-commercial Source engine mods. Ships large C++ game and engine sources for titles including Half-Life 2, Half-Life 2: Deathmatch, and Team Fortress 2, with Visual Studio build pipelines on Windows and Steam Runtime–based builds on Linux. Intended for developers who want to build, customize, and distribute Source 1 mods—useful for game engine research, modding infrastructure study, and reverse-engineering ground truth in the Game Engine / source lane. (source: wiki/sources/descriptions/ValveSoftware__source-sdk-2013.md)

Complements AlliedModders references such as [[hl2sdk]], early HL2-era archival snapshots such as [[source-engine-2003]], community mirrors such as [[source-sdk-orangebox]] and [[source-engine-2007]], and open trees such as [[source-engine]] for cross-era Source 1 architecture study.
