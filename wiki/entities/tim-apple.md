# tim_apple

External Counter-Strike 2 cheat (`tim_apple.exe`; README **External** tag). Offset bootstrap runs via `offset_download.ps1` beside the binary, or manual placement of `client.dll.json`, `offsets.json`, and `buttons.json` next to the executable. Useful for researchers studying external CS2 memory layout and post-patch offset refresh workflows. (source: wiki/sources/descriptions/kristofhracza__tim_apple.md)
