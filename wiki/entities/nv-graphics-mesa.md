# nv-graphics-mesa

Read-only GitHub mirror of the upstream [Mesa 3D](https://gitlab.freedesktop.org/mesa/mesa/) graphics library—the open-source reference implementation for OpenGL and Vulkan on Linux and other platforms. Listed under README `3D Graphics`; useful for graphics programmers, technical artists, and engine developers studying driver internals, GL/VK state machines, and shader compiler paths rather than as a maintained fork. (source: wiki/sources/descriptions/gmh5225__nv-graphics-mesa.md)
