# MxEngine

Modern C++ 3D game engine for education and general-purpose real-time development. Ships a large **OpenGL** rendering stack with PBR, screen-space effects, shadows, and particle systems, plus an editor workflow supporting runtime shader and code iteration. Integrates ECS-style architecture, physics, audio, asset-import pipelines, and serialization for full scene authoring—aimed at engine programmers and game developers who want a source-available framework to study or build desktop 3D applications. (source: wiki/sources/descriptions/asc-community__MxEngine.md)

Sits in the Game Engine / source lane—an OSS C++ OpenGL engine codebase for graphics and engine-structure study, not a cheat or anti-cheat artifact.
