# Kernelcloak

Advanced C++17 library for protecting and obfuscating Windows kernel drivers. Primarily C/C++ and centered on kernel-level driver development and modding. Aimed at anti-cheat engineers and defensive security researchers in the Anti Cheat / Encrypt Variable and obfuscation-engine lanes—not a turnkey AC product or commercial protector. (source: wiki/sources/descriptions/ck0i__Kernelcloak.md)

Useful as an open reference for hardening `.sys` modules against static RE and signature scanning, alongside usermode compile-time variable libraries such as [[obfuscxx]] / [[encrypted-value]] and KM lazy-import helpers such as [[kli]].
