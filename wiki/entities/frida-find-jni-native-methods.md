# frida-find-jni-native-methods

Frida JavaScript tooling to discover JNI native method bindings while an Android app is running — hooking and memory analysis to map Java `native` declarations to their loaded `.so` implementations without static DEX-only guessing. Useful for game-security researchers and reverse engineers studying offensive mobile instrumentation in the cheat / Frida lane (bridge Java game logic to native anti-cheat, crypto, or IL2CPP-adjacent hooks).
