# VMDragonSlayer

Advanced Virtual Machine Detection and Analysis Framework. Combines Dynamic Taint Tracking (DTT), Symbolic Execution (SE), Pattern Classification, and Machine Learning to automate reverse engineering of VM-protected code. Aimed at game-security researchers and reverse engineers studying offensive techniques in the Cheat / RE Tools lane. (source: wiki/sources/descriptions/poppopjmp__VMDragonSlayer.md)

Companion surface to other Cheat → Fix VMP / virtualization-RE research ([[novmpy]], [[rumba]], [[vmdevirt-vtil]], [[vmunprotect]]): multi-engine VM detection/analysis rather than a single-protector symbolic-exec or .NET instrumentation demo.
