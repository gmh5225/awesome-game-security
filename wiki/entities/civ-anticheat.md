# CivAnticheat

**CivAnticheat** (msc1488/CivAnticheat) is a **Paper 1.21+** Minecraft server-side anti-cheat plugin. README copy describes live telemetry training, per-player adaptive anomaly scoring, deterministic rule checks, and **per-viewer ESP masking** so hidden players are not revealed to observers who should not see them. (source: wiki/sources/README-categories.md)

Repository membership is discovery only—verify behavior, dependencies, and compatibility on the upstream project before deployment.
