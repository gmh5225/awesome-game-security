# lab-esp-and-aimbot

Educational game-hacking lab with a simple 3D target application and companion cheat code for learning ESP and aimbot implementation from scratch. Covers external memory reading, [[world-to-screen]] coordinate transformation, player/entity ESP rendering, and basic aimbot math (angle calculation and mouse movement)—aimed at beginners in a controlled practice environment rather than live multiplayer cheating.
