# AndroidAntiCheat

**AndroidAntiCheat** (codetronik) is an **Android** project in **C/C++** focused on **anti-cheat research**, **modding**, and **hooking**. It targets **anti-cheat engineers** and **defensive security researchers** studying open-source mobile AC architecture in the README **Anti Cheat → Open Source Anti Cheat System** lane. (source: wiki/sources/descriptions/codetronik__AndroidAntiCheat.md)

Complements other Android AC samples such as [[anticheat-android-cheap-engine]] and concept overview [[mobile-anti-cheat]]; hooking/modding overlap with native instrumentation tools such as [[adbi]] and [[dobby]].
