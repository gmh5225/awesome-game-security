# FallGuysSharp

**FallGuysSharp** is a **C#** cheat for **Fall Guys: Ultimate Knockout** targeting the **Unity IL2CPP** game runtime. It provides **movement hacks** and **gameplay modifications** through **managed code injection** into the IL2CPP runtime environment. (source: wiki/sources/descriptions/gmh5225__FallGuysSharp.md)

Contrasts with kernel-driver external stacks such as [[fall-guys]], [[flying-guys]], and [[flying-guys-fully-modified]] that use kernel driver communication or KdMapper-loaded drivers for cross-process memory access on the same title. Useful for comparing in-process IL2CPP managed injection vs kernel external cheat lanes on Unity party games.
