# PixelOS manifest

**Manifest repository** for **PixelOS** (PixelOS-AOSP): XML manifest files plus documentation for `repo init`, source sync, and ROM build workflows. Provides default and revision-locked manifests and snippet files that control which upstream Android projects are fetched. Intended for ROM maintainers and builders who compile and track PixelOS releases. README lane: `[An AOSP based ROM aiming to provide the best of Pixel]`. (source: wiki/sources/descriptions/PixelOS-AOSP__manifest.md)

Complements PixelOS support metadata in [[official-devices]] and sits in the Cheat Magisk / Android ROM–root lane beside curated ROM references such as [[android-rom-list]] and Pixel flashing/root tooling such as [[pixel-flasher]].
