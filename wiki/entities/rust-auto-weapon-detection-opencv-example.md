Sample **Facepunch Rust** project demonstrating automatic weapon detection with **OpenCV** (YouNeverKnow00). C++ with Visual Studio project files, image assets, color filtering, and weapon index mapping. Implements a basic computer-vision pipeline for **screen-based state recognition** rather than direct game memory manipulation—educational experimentation with CV-assisted automation and telemetry tooling.
