# PolarImGui

**Android ImGui-based menu framework** for Unity **IL2CPP** games (Polarmods). Combines **C++ native code** with **Android Studio** build tooling and documents packaging steps for producing native libraries and integrating them into target **APK architectures** for in-game UI rendering. Primary use case: **mobile game modding** and **cheat UI prototyping** in IL2CPP environments. README tag: `[Imgui On Android]`. (source: wiki/sources/descriptions/Polarmods__PolarImGui.md)

Complements other Android Unity IL2CPP ImGui scaffolds ([[imgui-unity-android]], [[imgui-unity]], [[android-mod-menu-imgui]]) and NDK Unity cheat templates ([[cheat-unity-games]]) when the goal is a native-library-first ImGui menu workflow with Android Studio packaging rather than Frida-only or external overlay services ([[external-imgui-android]]).
