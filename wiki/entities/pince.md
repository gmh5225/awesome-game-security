# PINCE

PINCE (PINCE Is Not Cheat Engine) is a Qt-based GDB front-end for Linux game hacking and reverse engineering. The Python application attaches to processes via GDB and exposes Cheat Engine–like workflows: memory scanning, value editing, pointer chain resolution, code injection, breakpoint management, and Cheat Engine–compatible table import. (source: wiki/sources/descriptions/korcankaraokcu__PINCE.md)
