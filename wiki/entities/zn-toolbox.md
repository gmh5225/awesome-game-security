# ZN-Toolbox

Android application that runs a **root-free container virtual machine** on the host device, providing an isolated Android environment with **built-in root access** and the **LSPosed Xposed** framework. Built on the **Twoyi** container engine with a **Rust** native core and a **Kotlin Jetpack Compose** UI (liquid-glass design). (source: wiki/sources/descriptions/Chinaapps__ZN-Toolbox.md)

**Capabilities:** multi-profile container management, **Scrcpy**-based remote display and control, and a fully localized Chinese UI.

**Audience:** security researchers, reverse engineers, and modders who need a rooted, Xposed-enabled sandbox on **non-rooted phones** for app analysis, hooking, and game-related experimentation.
