# GrandTheftAutoV-Cheat

Open-source **Grand Theft Auto V (PC)** cheat with mod menu and gameplay modifications (gmh5225; cheat / game:gta5). Provides money hacks, vehicle spawning, teleportation, and player modifications through GTA V **scripting** and **memory manipulation**. Aimed at game security researchers studying Rockstar open-world client-side cheat surfaces. (source: wiki/sources/descriptions/gmh5225__GrandTheftAutoV-Cheat.md)

Distinct from ScriptHookV mod-menu frameworks such as [[phake]], Python memory-analysis samples such as [[gta5cheat]] and [[gta5cheat-qt]], and offline save utilities such as [[gta5view]]; this is a **mod-menu cheat sample** combining RAGE scripting hooks with live-process memory edits.
