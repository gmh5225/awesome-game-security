# ThreadStackSpoofer

PoC for **thread call-stack spoofing** — an advanced in-memory evasion technique that fabricates thread call stacks to bypass thread-based memory examination rules and better hide in-process shellcode. Aimed at game-security researchers and reverse engineers studying offensive cheat / spoof-stack tradecraft. (source: wiki/sources/descriptions/mgeeky__ThreadStackSpoofer.md)
