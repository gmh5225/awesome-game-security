# Asphyxia CS2

Open-source internal Counter-Strike 2 cheat (C++). Asphyxia implements ESP (player boxes, health bars, names), aimbot, triggerbot, and visual modifications through Source 2 engine SDK interaction. The internal cheat hooks rendering and input via interface pointers and pattern scanning — useful for researchers studying CS2 cheat architecture and Source 2 engine internals for anti-cheat development. (source: wiki/sources/descriptions/maecry__asphyxia-cs2.md)
