# vibe-blocks-mcp

Model Context Protocol (MCP) server for **Roblox Studio**. Exposes Roblox Studio authoring actions as MCP tools over **Server-Sent Events (SSE)**, letting AI coding agents drive place editing, scripting, and studio workflows from external clients. Fits the Game Develop → MCP server lane; useful for game developers, reverse engineers, and tooling builders wiring agents into Roblox projects rather than live client memory RE. (source: wiki/sources/descriptions/gmh5225__vibe-blocks-mcp.md)

Complements engine-specific MCP bridges such as [[unity-mcp]], [[unreal-mcp]], and [[better-godot-mcp]] on the Roblox/Luau axis. Sits beside Roblox defensive samples such as [[advanced-anticheat]] / [[shprotect-ac]] and offensive client tooling such as [[roblox-cheats]] when the goal is studio automation or script-platform study rather than runtime injection.
