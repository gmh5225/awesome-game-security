# auto-enum

Python and C tooling that automatically identifies and applies enum types for standard library and common API functions during reverse-engineering workflows. Useful in asset pipelines, plugin development, and modding contexts where numeric operands should resolve to named enumerators in IDA. (source: wiki/sources/descriptions/junron__auto-enum.md)

Automated enum discovery/application—not a decompiler, unpacker, or manual Hex-Rays enum editor. Complements hotkey-driven enum workflows such as [[ida-enums-helper]].
