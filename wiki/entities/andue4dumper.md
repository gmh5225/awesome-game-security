# And UE4Dumper

**Android Unreal Engine dumping toolkit** from MJx0. C++ codebase built with the **Android NDK**; ships as either an **external executable** or an **injectable shared library**. Dumps engine offsets, classes, structs, enums, and functions, then emits SDK-style output plus **JSON symbol scripts** for disassemblers such as IDA and Ghidra. Primary use case is mobile game reverse engineering and Unreal Engine security research on Android titles. (source: wiki/sources/descriptions/MJx0__AndUE4Dumper.md)

Sits in the Cheat / `[SDK Dump For Android]` lane beside other Android UE4 SDK dumpers such as [[ue4-apk-dumper]], [[ue4dumper]], and [[frida-ue4dump]], the iOS sibling [[ios-ue4dumper]], and desktop dumpers such as [[uedumper]] and [[shh0yauedumper]] on the [[unreal-object-model]] side.
