# AzerothCore WoTLK

Open-source **World of Warcraft** server emulator for the **Wrath of the Lich King** expansion, targeting client version **3.3.5a**. The C++ authoritative server implements world simulation, player management, NPC AI, a scripting engine, database-driven content, and network protocol handling compatible with WoW 3.3.5a clients. Modular architecture includes **Eluna Lua** scripting support. Aimed at game server developers, WoW private-server operators, and researchers studying MMO server architecture—not a live-service cheat client. (source: wiki/sources/descriptions/azerothcore__azerothcore-wotlk.md)

Sits in the README **Private Server** / `[wow]` lane beside other WoW authoritative emulators such as [[legioncore-7-3-5]], and complements WoW client-side research samples such as [[dumpwow]], [[wow-iat-fix]], [[ohack]], and [[x14-08-coverstory-blizzard]].
