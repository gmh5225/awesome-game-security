# MapleStory v179 Cheat Engine

**MapleStory v179 Cheat Engine** (Noosh404/Maplestory-V179-Cheat-Engine) is a collection of **Cheat Engine tables** (`.CT`) and **Auto Assembler** scripts targeting legacy **MapleStory v179**. Scripts implement gameplay modifications including full-map attack, skill injection, no-delay variants, pet loot teleport behavior, and knockback-related tweaks. Content ships as CEA and CT scripts that patch in-memory instructions through **pattern scans** and **byte edits**. Intended for cheat development practice and legacy MapleStory reverse engineering experiments. (source: wiki/sources/descriptions/Noosh404__Maplestory-V179-Cheat-Engine.md)

Sits beside other MapleStory client-modification corpora such as legacy GMS trainer toolkits [[msb]] and bot frameworks [[msc]], and general multi-game CE table collections such as [[mydev-cheat-engine-tables]]. Offset and hook-point references such as [[maplestory-cms95-client-address]] complement version-specific memory work on other MapleStory builds.
