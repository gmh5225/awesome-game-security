# ICUAC

Configurable server-side rule-enforcement plugin for Paper and Folia Minecraft servers. Written in Java 21 (Gradle). Applies modular checks to commands, player state, locations, inventories, and combat rather than full client-side movement/combat anti-cheat heuristics.

Enforces policies such as blocked commands and tab-completion hiding, game-mode isolation, dangerous coordinate limits, death-drop control, banned materials, item NBT and enchantment validation, stack and potion effect limits, and end-crystal attack cooldowns. Ships bilingual Chinese and English default packages, uses Folia-aware scheduling, and includes an updater that downloads language-matched release assets after verifying GitHub SHA-256 digests. Intended for server administrators who need lightweight, transparent server-side anti-abuse and integrity controls. (source: wiki/sources/descriptions/Lazyzouo__ICUAC.md)

## Enforcement modules

Command blocking and tab-complete hiding; game-mode isolation; coordinate limits; death-drop control; banned materials; item NBT/enchantment validation; stack/potion effect caps; end-crystal attack cooldowns; bilingual CN/EN defaults; Folia-aware scheduling; SHA-256-verified GitHub updater.
