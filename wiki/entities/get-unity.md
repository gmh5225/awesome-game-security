# get-unity

JavaScript CLI that resolves download URLs for the latest or a specific Unity Editor version. Aimed at tooling developers and reverse engineers in the game-tools lane rather than shipped-binary IL2CPP/Mono RE. (source: wiki/sources/descriptions/neogeek__get-unity.md)

Sits under README `Game Tools` beside UE builders/profilers—complements editor automation such as [[unicli]] / [[unity-mcp]] by fetching installer URLs instead of driving an installed Editor.
