# IDA-Pro-SigMaker

IDA Pro plugin (gmh5225; cheat / IDA Plugins) for generating byte-pattern signatures from selected code regions. Creates wildcard-masked signature patterns suitable for runtime pattern scanning in game hacking and binary analysis tools. (source: wiki/sources/descriptions/gmh5225__IDA-Pro-SigMaker.md)

Signature generation from disassembly selections—not a built-in scanner or multi-format exporter like [[sigmakerex]], and without the mahmoudimus [[ida-sigmaker]] search/SIMD stack.
