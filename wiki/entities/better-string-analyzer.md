# Better String Analyzer

Ghidra plugin that improves string analysis inside the RE environment. Written in Java; targets modding-oriented binary triage where faster literal discovery and xref navigation accelerate cheat-client and protected-game RE. (source: wiki/sources/descriptions/fuzzypickles14__BetterStringAnalyzer.md)

Java Ghidra extension in the Cheat → Ghidra Plugins lane — complements stock Defined Strings views and string-centric automation such as [[ghidra-scripts]] and [[ida-function-string-associate]] on the IDA side.
