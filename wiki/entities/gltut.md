# gltut

Comprehensive OpenGL tutorial with progressive C++ examples and XML-based documentation—vector math, coordinate systems, lighting, texture mapping, and advanced rendering. Built with CMake and Lua asset-generation scripts. Aimed at graphics programmers and game developers learning modern OpenGL fundamentals and 3D graphics theory rather than as a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/paroj__gltut.md)

Sits in the README Renderer / OpenGL Render lane, complementary to DirectX tutorials such as [[hw3d]] and soft-3D courses such as [[tinyrenderer]].
