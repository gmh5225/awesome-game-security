# awesome-game-file-format-reversing

Curated collection of documentation, code, tools, and resources for reverse engineering and working with video game file formats. Covers specialized, often undocumented formats for models, textures, animations, audio, archives, scripts, and level data across many games and engines. Organizes general tools such as asset viewers, archive extractors, hex editors, and format-analysis utilities, plus engine-specific sections for Unity, Unreal, Source, CryEngine, and others—along with communities, wikis, learning resources, and middleware documentation. Primary audience: developers, modders, and reverse engineers who need to understand, extract, convert, or otherwise work with proprietary game assets. (source: wiki/sources/descriptions/VelocityRa__awesome-game-file-format-reversing.md)

Not a single extractor—a learning/index hub that complements engine-specific asset tooling such as [[paksmith]], [[uassetgui]], [[uassetapi]], [[imhex]], and [[hexwalk]] for offline packaged-content RE.
