# NoCheatZ-3

**Source Engine serverside anti-cheat plugin** for classic Valve multiplayer titles—**CS:S**, **CS:GO**, **CS:P**, and **TF2**. Written in C/C++, it targets anti-cheat research, dedicated-server plugin development, and SDK generation for the Game Engine Protection:Source lane. (source: wiki/sources/descriptions/kanekikun420__NoCheatZ-3.md)

Runs on the game server without requiring a client-side install—the same server-authoritative model as [[cs2ac]] and [[open.mp-anticheat]], applied to Source 1 dedicated servers rather than CS2 Metamod:Source or SA-MP stacks.

Complements open Source trees such as [[source-engine]], leaked CS:GO reference trees such as [[cstrike15-src]], and reverse-engineered SDK header dumps such as [[sdk]].
