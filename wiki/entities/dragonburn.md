# DragonBurn

Windows external cheat framework for Counter-Strike 2 (C++) emphasizing **kernel-assisted read-only** cross-process data access. Ships an ImGui-style menu, rendering modules, and configurable ESP and radar overlays with automated offset-update support and UI customization for visual features. Intended for cheat development experiments and anti-cheat detection research in competitive shooter environments. (source: wiki/sources/descriptions/ByteCorum__DragonBurn.md)
