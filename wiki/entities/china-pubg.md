# ChinaPubg

**Android native toolkit** for PUBG-related reverse engineering and external game-manipulation experiments (Super-Cssdiv). Combines **C/C++ NDK** code with multiple hooking and injection components: **inline hook frameworks**, **ptrace-based injectors**, and **memory tooling**. Integrates **ImGui-based rendering** plus helper modules for **offsets**, **map data**, and **runtime patching**. Primarily aimed at game security researchers studying **mobile anti-cheat behavior**, **cheat architecture**, and **detection surfaces**. (source: wiki/sources/descriptions/Super-Cssdiv__ChinaPubg.md)
