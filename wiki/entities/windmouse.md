# WindMouse

Python library that generates **human-like mouse movement paths** for automation. Implements the WindMouse algorithm to produce curved, non-linear trajectories with variable speed instead of deterministic straight-line motion. Supports multiple automation backends (AutoHotkey, PyAutoGUI) and exposes tuning controls for movement physics. Primary use case: reducing behavioral bot-detection risk in UI automation and game scripting. (source: wiki/sources/descriptions/AsfhtgkDavid__windmouse.md)
