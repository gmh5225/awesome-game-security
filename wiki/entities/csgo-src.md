# csgo-src

Mirror or archive of leaked Counter-Strike: Global Offensive (CS:GO) source code on the Source engine (C++). Contains the Source engine codebase with game-specific implementations covering networking, rendering, game logic, and client-server architecture—mainly useful for game engine researchers and reverse engineers studying Source engine internals and CS:GO's client-server architecture. (source: wiki/sources/descriptions/PiMoNFeeD__csgo-src.md)

Complements other leaked CS:GO Source trees such as [[cstrike15-src]] (partial client/server / weapons / movement / networking / UI tree) and open Linux CS:GO ports such as [[kisak-strike]] (SwagSoftware; CMake + SDL/OpenGL; buildable full game + engine tree), reverse-engineered SDK header dumps such as [[csgo-sdk]] / [[sdk]], and open TF2-era Source mirrors such as [[source-engine]].
