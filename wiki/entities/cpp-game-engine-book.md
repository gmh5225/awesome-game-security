# cpp-game-engine-book

Hands-on game engine learning book with a large accompanying C++ codebase centered on OpenGL. Walks through engine construction from rendering basics through animation, GUI, audio, profiling, and multithreaded rendering. Chapter-based samples plus Lua scripting integration, Blender export workflows, and FMOD-related audio steps—aimed at learners who want practical engine-architecture implementation experience. (source: wiki/sources/descriptions/ThisisGame__cpp-game-engine-book.md)

Sits in the Game Engine / guide lane as an educational from-scratch OpenGL engine course—not a cheat, anti-cheat, or runtime hook artifact.
