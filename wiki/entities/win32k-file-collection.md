# win32k-file-collection

Archive of **win32k.sys** and related Windows kernel GUI-subsystem binaries spanning multiple Windows builds. A research corpus for comparative analysis, vulnerability research, and patch diffing—not a turnkey analyzer—aimed at kernel engineers studying win32k changes and the GUI-subsystem attack surface across OS versions.
