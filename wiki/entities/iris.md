# Iris

Iris (`irisengine/iris`) is a cross-platform C++ game engine with a component-based architecture, CMake build system, and support for multiple rendering backends. It includes camera systems, color management, smart-pointer utilities, and modern C++ concepts-based interfaces—aimed at developers studying lightweight engine design with template metaprogramming patterns. (source: wiki/sources/descriptions/irisengine__iris.md)

Sits in the Game Engine / cross-platform C++ source lane—an educational engine codebase for modern C++ architecture study rather than a cheat or anti-cheat artifact.
