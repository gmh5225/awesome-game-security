# MapleStory Client (HeavenMS)

Custom or modified **MapleStory** game client (**HeavenMS Client**, gmh5225): implements client-side game rendering, network protocol handling, and user interface for connecting to MapleStory private servers. (source: wiki/sources/descriptions/gmh5225__MapleStory-Client.md)

Useful for game security researchers and private-server developers studying MapleStory client architecture, protocol handling, and presentation stacks—not live official-client anti-cheat bypass tooling.

Complements HeavenMS server emulators such as [[maplestory-server]], from-scratch client reimplementations such as [[maplestory-heavenclient]], JourneyClient-derived v83 clients such as [[libremaple-client]] (C++17; Roboto fonts; classic protocol/mechanics), GM/admin clients such as [[maplestory-gm-client]], CMS v95 client address tables such as [[maplestory-cms95-client-address]], other client stacks such as [[winapi-maplestory]], and WZ tooling such as [[wzcomparerr2]] and [[maplestory-packer-modpacker]].
