# Reverse THIS!

**One-click Windows reverse-engineering and modding workbench** (SenjuWoo; PowerShell installer; Cheat / RE Tools). Provisions a version-pinned catalog of analysis and mod tools behind **stable command shims** in a sandbox workspace so researchers and mod authors get a reproducible bench without chasing individual releases. (source: wiki/sources/descriptions/SenjuWoo__reverse-this.md)

## Bundled tooling

Native and scripted utilities include [[ghidra]], [[x64dbg]], [[frida]], Rizin, [[imhex]], and YARA. .NET and Unity stacks cover ILSpy, dnSpy, [[il2cpp]], [[asset-ripper]], [[bepinex]], and MelonLoader. Engine-specific routes cover Unreal, Source, REDengine, FromSoftware, GameMaker, and many commercial titles.

## Helpers and agent workflow

Local Python helpers fingerprint PE files for graphics APIs and anti-cheat markers, generate wildcard AOB signatures, and can bridge Ghidra to MCP. An offline encyclopedia documents routing recipes, engine notes, IPC blueprints, and anti-cheat risk tiers for agent-guided workflows.
