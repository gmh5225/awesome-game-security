# FLARE VM

Mandiant’s fully customizable **Windows-based security distribution** for malware analysis, incident response, and reverse engineering. Uses **Chocolatey** and **Boxstarter** to automate provisioning of hundreds of analysis tools—disassemblers (IDA, Ghidra, x64dbg), debuggers, decompilers, network analyzers, forensic utilities, and Python/Ruby runtimes—onto a clean Windows VM. Targets analysts who need a **reproducible, tool-rich Windows lab** rather than hand-picking individual installers. (source: wiki/sources/descriptions/mandiant__flare-vm.md)

Complements one-shot Windows bundles such as [[retoolkit]] and link catalogs such as [[retools]] for standing up an RE workspace.
