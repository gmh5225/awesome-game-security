# UE-UnrealEngineSDK

Reverse-engineered **Unreal Engine SDK** providing C++ class definitions, struct layouts, and function signatures for UE4/UE5 game internals. Covers `UObject` hierarchy definitions, `UWorld`/`ULevel` structures, player controller classes, actor component layouts, and engine globals needed for game hacking and modding. Enables direct interaction with UE game objects from injected code—aimed at UE game hackers and modders who need SDK headers for internal cheat or mod development. (source: wiki/sources/descriptions/gmh5225__UE-UnrealEngineSDK.md)

README category: Universal Cheat development kit.

Sits in the Cheat / Universal Cheat development kit lane beside live dumpers such as [[unrealdumper-4-25]] and explorers such as [[unrealengine4-swissknife]], but supplies **pre-built header kits** for [[unreal-object-model]] types when per-title SDK regeneration is impractical.
