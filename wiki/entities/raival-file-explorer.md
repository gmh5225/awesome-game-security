# File-Explorer (Raival-e)

Lightweight Android file manager with Material 3 styling, developed mainly in Kotlin with some Java. Provides core file operations, multi-tab navigation, task handling, and integrated code editing, plus deep content search. Structured as a standard Gradle-based Android project aimed at users and developers who want an open-source file-management baseline to extend or study. (source: wiki/sources/descriptions/Raival-e__File-Explorer.md)

Listed in the README under **Cheat → Android File Explorer** as `[An Android file explorer]`.

Sits beside fuller on-device managers such as [[file-explorer]] (SysAdminDoc) and prebuilt rooted explorers such as [[xfiles]] in the Cheat Android File Explorer lane.
