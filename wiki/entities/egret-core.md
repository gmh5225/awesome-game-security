# Egret Engine

Egret Engine is an HTML5 game engine providing modular subsystems for common game development tasks: 2D and 3D rendering, GUI, audio, and resource management. Aimed at game developers, engine programmers, and graphics researchers studying browser-based engine architecture in the README **Game Engine → HTML5** source lane. (source: wiki/sources/descriptions/egret-labs__egret-core.md)

Sits in the Game Engine / HTML5 source lane—an OSS browser game-engine tree for development and graphics study, rather than a cheat or anti-cheat artifact. Adjacent to [[melonjs]], [[turbulenz-engine]], [[pixijs]], [[three-js]], and [[engine]] (PlayCanvas).
