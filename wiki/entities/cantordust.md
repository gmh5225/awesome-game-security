# cantordust

Java **Ghidra extension** and standalone desktop app for interactive **binary visualization**—byte-value plots, digraph/trigram clouds, metric maps on space-filling curves, linear bitmaps, and byte-frequency views with sliders to focus large files. In Ghidra, clicking a visualization point jumps the CodeBrowser listing to the corresponding offset; the standalone build pairs the same views with an integrated hex pane. Gradle builds plus a small Python cleanup utility for development. (source: wiki/sources/descriptions/Battelle__cantordust.md)

Targets firmware, executables, and malware triage where human pattern recognition accelerates finding code, data, and embedded artifacts—beside dockable hex editors such as [[scalpel]] and [[ghidra-hexeditor]].
