# ObfuscationMethods

C# collection of .NET assembly obfuscation and protection technique demos that rewrite managed binaries via dnlib. Modular protections include control-flow obfuscation, anti-dump / method hiding, anti-de4dot / dnSpy / ildasm defenses, renaming, integer and string encryption, proxies, mutation, junk code, and invalid metadata/opcodes. Aimed at developers and reverse engineers studying or applying .NET obfuscation for software protection and anti-analysis. (source: wiki/sources/descriptions/nak0823__ObfuscationMethods.md)

Broader technique catalog than minimal rename/string-hide tools such as [[obfuscar]]; sits in the AC Obfuscation Engine / managed-CLR protection lane alongside [[wprotect]] and native protectors.
