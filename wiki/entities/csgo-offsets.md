# csgo-offsets

Regularly updated **CS:GO memory offset** collection (gmh5225) tagged `[Offset]` in the curated list. Supplies netvar dumps, interface pointers, and signature patterns refreshed after each CS:GO patch—entity field offsets, weapon data addresses, and engine global pointers cheat developers and game-security researchers need when tracking client binary changes. (source: wiki/sources/descriptions/gmh5225__csgo-offsets.md)

Complements SDK header trees such as [[csgo-sdk]] and [[csgo-sdk-improved]], generic offset dumps such as [[offsets]], and netvar workflow notes in [[source-netvars]].
