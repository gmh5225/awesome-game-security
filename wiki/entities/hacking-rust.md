# Hacking-Rust

Free step-by-step reverse-engineering course for Rust programs: a downloadable PDF book plus per-chapter Cargo lab crates progressing from hello-world through scalars, compound types, functions, and control flow. Each topic follows write → debug → disassemble/analyze on x64, ARM64, and ARM32 for security researchers who need to read Rust at the machine level. (source: wiki/sources/descriptions/mytechnotalent__hacking-rust.md)

Complements the same author's multi-arch RE curriculum [[mytechnotalent-reverse-engineering]], Windows RE guide [[hacking-windows]], Go RE course [[go-hacking]], embedded firmware RE course [[embedded-hacking]], and Rust RE tooling such as [[ida-rust-demangler]] / [[demumble]] / [[oxidizer]].
