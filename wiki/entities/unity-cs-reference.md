# Unity C# Reference

**UnityCsReference** (Unity-Technologies) — official C# reference source for the Unity engine and editor. Exposes a large portion of Unity's managed-side implementation so developers can inspect API behavior and internal editor workflows. Primarily C# and mirrors Unity's internal source tree layout, distributed under a reference-only license. Used for engine understanding, debugging, tooling research, and deep technical study of Unity internals—not a runtime cheat artifact. (source: wiki/sources/descriptions/Unity-Technologies__UnityCsReference.md)

Complements IL2CPP/Mono RE workflows ([[il2cpp]], [[dnspy]], [[ilspy]]) with upstream managed-side ground truth for editor/runtime API behavior. Useful beside runtime inspectors such as [[unityexplorer]], script catalogs such as [[unity-script-collection]], and external resolve tooling such as [[unity202x-externalresolve]].
