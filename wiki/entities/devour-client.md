# devour-client

**Game client modification** for the co-op horror title **Devour**, built on **Unity IL2CPP** with **in-process memory manipulation**. Provides quality-of-life tweaks and cheat functionality by editing the Unity game client at runtime. (source: wiki/sources/descriptions/gmh5225__DevourClient.md)

Broader client-side modding surface than [[devour-menu]]'s ImGui overlay mod menu—useful for comparing direct memory edits vs toggleable overlay-driven hooks on the same Unity horror co-op title. Complements [[goose-goose-duck-hack]] for studying lightweight Unity IL2CPP client mods without kernel anti-cheat.
