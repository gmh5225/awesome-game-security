# PCILeech-DMA-Fullstealth

Quantumstealth **open-source Fullstealth** [[pcileech]] DMA **FPGA firmware** with **Vivado** build scripts for boards such as M2, Squirrel, Captain 75T, and Enigma X1. Ships PCIe IP cores, generate batch files, and firmware sources for stealth-oriented DMA devices—useful for modeling DMA threats and studying Fullstealth-style firmware behavior against PCIe-layer detection.
