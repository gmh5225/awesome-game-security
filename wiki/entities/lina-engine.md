# Lina Engine

Lina Engine (`inanevin/LinaEngine`) is a cross-platform, lightweight, straight-to-the-point open-source 3D game engine. The project is primarily a personal learning effort and a toolkit library: **LinaVG** supplies vector graphics for GUI and editor systems, and **LinaGX** is a complete Vulkan, DirectX 12, and Metal graphics backend. (source: wiki/sources/descriptions/inanevin__LinaEngine.md)

Sits in the Game Engine / cross-platform C++ source lane—aimed at game developers, engine programmers, and graphics researchers studying compact engine and multi-API render-backend design rather than as a cheat or anti-cheat artifact.
