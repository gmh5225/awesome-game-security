# BigWhiteTool

**Android native game memory utility** from BigWhite666 focused on **Unreal-style metadata discovery and SDK dumping**. The C/C++ codebase includes modules for **process memory read/write**, **GName/GObject-based offset traversal**, and **dump generation logic**. It also bundles an **ImGui interface** with **Vulkan or OpenGL** rendering paths and **NDK-based CMake** build support. Primary use is mobile game reverse engineering for offset finding, runtime inspection, and SDK extraction. (source: wiki/sources/descriptions/BigWhite666__BigWhiteTool.md)

Sits in the Cheat / `[SDK Dump For Android]` lane beside other Android UE dumpers such as [[andue4dumper]], [[ue4-apk-dumper]], [[ue4dumper]], and [[frida-ue4dump]], the iOS sibling [[ios-ue4dumper]], and desktop dumpers such as [[uedumper]] and [[dumper-7]] on the [[unreal-object-model]] side.
