# Overload

Open-source 3D game engine with an integrated editor, built primarily in modern C++ with Lua scripting. Covers rendering, physics, audio, profiling, and material tooling, with documentation, sample projects, and a community-driven architecture emphasizing usability and extensibility. (source: wiki/sources/descriptions/adriengivry__Overload.md)

For game security research, the full runtime + editor codebase offers a substantial surface for studying attack vectors, tooling internals, and defensive design patterns—not a cheat or anti-cheat artifact.
