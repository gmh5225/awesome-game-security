# draw-ida

Lightweight **whiteboard plugin for IDA Pro** that lets reverse engineers sketch and brainstorm directly inside the IDA UI. MIT-licensed; aimed at game-security researchers and reverse engineers studying offensive techniques in the cheat / IDA Plugins lane. (source: wiki/sources/descriptions/idkhidden__DrawIDA.md)

Annotation and ideation tooling—complements documentation plugins such as [[ida-screenshot]] rather than performing binary analysis itself.
