# vigil

**vigil** (TOSTcRa) — **Rust-based eBPF security monitoring** positioned as an open-source **Linux-native anti-cheat**. Uses BPF programs for kernel-level event tracing and analysis, with a modular crate layout covering BPF ELF loading, perf event handling, a CLI interface, and client–server communication for distributed monitoring. Targets Linux security researchers and kernel engineers studying eBPF runtime monitoring and threat-detection architectures on native Linux game hosts. (source: wiki/sources/descriptions/TOSTcRa__vigil.md)
