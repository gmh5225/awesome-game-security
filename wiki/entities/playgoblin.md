# PlayGoblin

**PlayGoblin** is an open-source automated QA bot that plays builds like a persistent tester, records failures, and turns runs into evidence-backed bug reports. A Unity package and experimental Unreal C++ plugin crawl levels and menus while emitting structured run logs; a Python CLI applies deterministic checks for crashes, dead UI buttons, stuck navigation, falls, blank frames, debug leftovers, and optional FPS regressions. Findings tie to events, frames, or log lines and can render as HTML or Markdown reports or file GitHub issues, with an MCP server and JSON CLI output for AI coding agents. Targets local overnight playtesting and regression discovery—not anti-cheat or live security monitoring. (source: wiki/sources/descriptions/grloper__playgoblin.md)
