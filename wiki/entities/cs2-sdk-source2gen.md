# cs2-sdk-source2gen

Generated **Counter-Strike 2** SDK dump (gmh5225; `[SDK]`) of Source 2 engine classes and enums. Contains auto-generated C++ header files for the animation system, client, engine2, network system, scene system, schema system, and other Source 2 modules produced by [[source2gen]]. Aimed at game-security researchers and reverse engineers studying CS2 layout and interface discovery in the cheat / game:cs2 lane. (source: wiki/sources/descriptions/gmh5225__CS2-SDK-Source2Gen.md)

Sits beside multi-game generated dumps such as [[source2sdk]], hand-maintained CS2 SDK scaffolds such as [[cs2-sdk]], and offset feeds such as [[cs2-offsets]] as consumed Source 2 codegen output for CS2.
