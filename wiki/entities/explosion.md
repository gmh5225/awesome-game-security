# Explosion

**Explosion** (ExplosionEngine/Explosion) is a cross-platform **C++ game engine** with an **ECS-oriented** architecture. It targets modern graphics backends including **Vulkan**, **DirectX 12**, and **Metal**, and ships editor and runtime modules with a **CMake** and **Conan** build workflow. The repository combines engine code with tooling and frontend components—**Qt** and web-stack dependencies—for production-style development workflows. Primary audience is game development teams and rendering researchers who need a full engine framework rather than a cheat-focused toolkit. (source: wiki/sources/descriptions/ExplosionEngine__Explosion.md)

Not a cheat or anti-cheat artifact—a substantial OSS engine tree for studying ECS scene organization, multi-backend rendering, and editor/runtime module boundaries.
