# Campfire

In-progress game engine built with OpenGL and Vulkan. Most engine features are currently disabled while the project migrates to Vulkan; the full feature set remains available on the OpenGL branch. Aimed at game developers, engine programmers, and graphics researchers studying multi-API engine backends—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/danhuynh0803__Campfire.md)

Sits in the Game Engine / source lane beside other OpenGL·Vulkan engine trees such as [[exengine]], [[liblava]], and [[raylib]].
