# so_loader

C/C++ project centered on Android native `.so` loading in the Cheat / Android memory loading lane. Useful for game-security researchers and reverse engineers studying offensive techniques for injecting or loading shared libraries into Android processes. (source: wiki/sources/descriptions/lockedbyte__so_loader.md)

Sits beside Android injectors such as [[android-ptrace-injector]], [[android-virtual-inject]], and [[android-ld-preload-injector]], and memory-editor tooling such as [[rwmem]] and [[mypower]].
