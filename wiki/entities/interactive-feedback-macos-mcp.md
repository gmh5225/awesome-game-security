# interactive-feedback-macos-mcp

Native **macOS** MCP (Model Context Protocol) server for collecting interactive user feedback via **AppleScript dialogs** with **image support**. macOS-native reimplementation of [[interactive-feedback-mcp]] (Fábio Ferreira / noopstudios) with platform-specific UI enhancements. Fits the Game Develop → MCP server lane for game developers, reverse engineers, and tooling builders who need human-in-the-loop operator prompts on macOS rather than cross-platform or editor-automation MCP bridges. (source: wiki/sources/descriptions/gmh5225__interactive-feedback-macos-mcp.md)

Complements the original [[interactive-feedback-mcp]] HITL prompt server on non-macOS hosts and editor-facing MCP bridges such as [[unity-mcp]] and [[deepwiki-mcp]] by targeting native macOS dialog UX for agent workflows.
