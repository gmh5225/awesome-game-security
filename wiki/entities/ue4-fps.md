# UE4 FPS

Small Unreal Engine 4 first-person shooter sample combining UE4 C++ classes with Blueprint assets, maps, and standard input and engine configuration files. Most of the repository is Unreal asset content with a lightweight native gameplay code layer. Useful as a learning sandbox for FPS development and as a practical target for engine-level game research—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/KitchenGun__UE4_FPS.md)
