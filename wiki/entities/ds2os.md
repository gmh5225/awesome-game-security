# ds2os

Deprecated **Dark Souls 2** online-service placeholder repository (TLeonardUK). The snapshot contains only a short README stating that active development moved to a newer codebase; no substantial server implementation remains. Primarily useful as a historical pointer for researchers tracing the Souls-series private-server lineage—active DS2/DS3 online-service work continues in [[ds3os]].
