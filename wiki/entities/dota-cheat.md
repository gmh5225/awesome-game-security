# dota-cheat

C++ **Dota 2 cheat** (gmh5225) that reads game entity data through **Source 2 SDK structures** and renders an overlay with enemy positions, HP/mana bars, spell cooldowns, and item information. Additional features include auto-ability casting. Aimed at game-security researchers studying Dota 2 cheat implementations and Source 2 engine exploitation. (source: wiki/sources/descriptions/gmh5225__dota-cheat.md)
