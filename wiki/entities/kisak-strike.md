# Kisak-Strike

Open-source **Linux port of Counter-Strike: Global Offensive** (SwagSoftware) based on Valve's Source engine. Includes the full game codebase with **CMake** build support, app framework, material system, sound system, networking, VPC project files, and Linux-specific adaptations including **SDL** and **OpenGL** rendering paths. (source: wiki/sources/descriptions/SwagSoftware__Kisak-Strike.md)

Mainly useful for Source engine researchers and game developers studying Source engine architecture and Linux game porting—not a cheat scaffold, but a buildable CS:GO-era Source 1 reference beside partial leaked trees and SDK generators.

Complements leaked partial CS:GO trees such as [[cstrike15-src]], open TF2-era Source mirrors such as [[source-engine]], SwagSoftware reimplementation siblings such as [[kisakcod]] and [[kisakblack]], and Linux CS tooling such as [[csf]] / [[counterstrikesource-linux-trainer]].
