# Unity Script Collection

Maintained catalog of useful free Unity scripts, libraries, plugins, and extensions for game developers, engine programmers, and graphics researchers in the Game Engine / Plugins:Unity lane—not a runtime cheat or anti-cheat artifact. The list itself is licensed under GPL v3.0. (source: wiki/sources/descriptions/michidk__Unity-Script-Collection.md)

Useful background index beside Unity guides ([[unity-cheat-sheet]]), editor tooling ([[unicli]], [[com-unity-ide-cursor]], [[unity-mcp]]), and broader engine-dev lists ([[awesome-game-engine-dev]]).
