# NeoTTY

Experimental Android terminal app forked from [[termux-app]] (Termux), aimed at a full Linux system usage experience on-device. Positioned for game security researchers and reverse engineers studying offensive workflows in the cheat / Android Terminal Emulator lane. (source: wiki/sources/descriptions/gmh5225__neotty.md)

Sits beside canonical Termux and legacy [[android-terminal-emulator]] hosts for on-device CLI research without a desktop host.
