# learning-directx12

Tutorial series and sample code for learning DirectX 12 graphics programming. Covers D3D12 fundamentals—device creation, command queues, pipeline state objects, root signatures, descriptor heaps, resource management, texture loading, and progressive rendering techniques. C++ samples build from basic triangle rendering to complete scenes, aimed at graphics programmers learning modern low-level GPU programming with DirectX 12—not Present-hook or overlay tooling. (source: wiki/sources/descriptions/jpvanoosten__LearningDirectX12.md)
