# WinNT5_src_20201004

Extracted **Windows NT 5.x** (Windows 2000 / XP / Server 2003 era) source material organized under an `NT/` tree covering base, drivers, windows, net, shell, and related components. Large historical reference corpus for studying kernel, Win32, and subsystem implementation details from that generation—mainly useful for Windows kernel and platform security researchers analyzing NT5-era internals. (source: wiki/sources/descriptions/jiubanlo__WinNT5_src_20201004.md)

Complements live symbol walking via [[ntoskrnlwalker]] / [[ntkernelwalkerlib]] and PDB tooling ([[pdb]], [[pdb-rs]], [[pdblister]]) when ground-truth source is needed for legacy NT structures and subsystems. Pair with [[research-rigor]]—behavior and offsets on modern Windows builds diverge sharply from NT5.
