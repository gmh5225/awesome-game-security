# LeagueSharp.Loader

C# **loader for [[leaguesharp]]** (gmh5225; cheat / game:lol). Centers on **DirectX** and **hooking** to bootstrap LeagueSharp scripting modules into the LoL client—aimed at game security researchers studying in-guest injection and render-path hook infrastructure under [[vanguard]]. (source: wiki/sources/descriptions/gmh5225__LeagueSharp.Loader.md)

Complements the main [[leaguesharp]] scripting platform (JungleTimerHax, SkinHax, champion resize) as the load/inject layer rather than feature modules or cheat-base scaffolding.
