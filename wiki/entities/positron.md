# Positron

Windows runtime JS injection toolkit aimed at Electron (V8/Node.js) apps and game-modding research: manual-map DLL injection of a JavaScript runtime (QuickJS per description; Electron/V8 surface per README blurb), with a self-unmapping payload, REPL/SDK, and named-pipe IPC for scripting APIs covering memory manipulation, function hooking, and automation. Useful for studying scripted in-process mod surfaces and PEB-unlisted manual-map + IPC channels that AC scanners target. (source: wiki/sources/descriptions/qiufuyu123__Positron.md)
