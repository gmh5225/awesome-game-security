# SF_TRT_61

**Windows computer-vision aiming framework** (AMXZzzz) in the cheat / Machine Learning YOLO lane. C++ pipeline linking **object detection** to **automated mouse control** without classic in-process memory reads or injection. Integrates **DXGI capture**, **OpenCV** preprocessing, **ImGui** configuration panels, and dual inference backends (**TensorRT** and **DirectML/ONNX**). Supports YOLO-style models with post-processing, **PID/FOV** movement tuning, trigger logic, and multiple input-injection methods. Primary use case is practical experimentation in AI-assisted game automation and anti-cheat evasion research. (source: wiki/sources/descriptions/AMXZzzz__SF_TRT_61.md)

Sits in the screen-capture → YOLO → HID pipeline beside [[auto-aim]], [[rookieai-yolov8]], [[yolov8-overlay-cs2]], and [[ai-fps-b00m-h3adsh0t]]; defensive ML and analyst counterparts include [[waldo]] and [[aimbot-detection-prototype]] via [[ai-aimbot-detection]].
