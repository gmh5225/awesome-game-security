# x64dbg Playtime

[[x64dbg]] plugin that embeds a Lua runtime (C/C++ plugin code plus bundled Lua libraries) for scriptable debugger automation. Exposes memory, registers, breakpoints, labels, modules, and assembler operations; supports autorun scripts and example workflows. Useful for reverse engineers and game-security researchers who want repeatable, script-driven debugging and analysis in the Cheat / x64dbg Plugins lane. (source: wiki/sources/descriptions/ZehMatt__x64dbgPlaytime.md)

Not a standalone debugger—extends [[x64dbg]] with Lua scripting alongside alternatives such as [[chaiscript-plugin]] and [[dotx64dbg]].
