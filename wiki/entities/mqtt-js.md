# MQTT.js

Full-featured MQTT client library for Node.js and browsers supporting MQTT v3.1, v3.1.1, and v5.0 over TCP, TLS, WebSocket, and WSS. Provides publish/subscribe messaging with QoS 0/1/2, automatic reconnection, last-will-and-testament, and CLI tools (`mqtt pub` / `mqtt sub`), with Electron and Vite integration examples. (source: wiki/sources/descriptions/mqttjs__MQTT.js.md)

Sits under README `Game Network` / `[mqtt nodejs]` as a study surface for lightweight pub/sub game telemetry, IoT-adjacent backends, and broker-based real-time stacks rather than client-side cheat tooling.
