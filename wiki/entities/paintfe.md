# PaintFE

Rust raster image editor with layered compositing, **wgpu** GPU filters, **Rhai** scripting, CLI batch processing, GIF/APNG export, and a single portable binary. Written in Rust and PowerShell; centers on shader work, rendering, and animation. Aimed at engine and tooling developers building asset pipelines in the Image Codec lane. (source: wiki/sources/descriptions/kylejckson__PaintFE.md)
