# TOG

TOG (The Online Gamer) is an offsets-generator / online-game cheat research tool for interacting with live-service game processes—memory layout discovery and related modification workflows used when studying online titles and anti-cheat surfaces. (source: wiki/sources/descriptions/patrickcjk__TOG.md)

README places it under **Offsets Generator**; treat as a cheat-research artifact for offset tooling rather than a maintained production product.
