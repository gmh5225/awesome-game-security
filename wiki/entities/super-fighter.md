# super-fighter

Windows shoot-'em-up game remake in C++ built on DirectX 11. Combines Direct3D rendering, HLSL shader effects, and DirectSound audio into a complete arcade-style game loop with configurable stage and enemy data files, replay support, and optional Xbox controller input alongside keyboard controls. Aimed at developers and students studying practical native Windows game programming patterns—not a cheat, anti-cheat, or security tool. (source: wiki/sources/descriptions/MKXJun__Super-Fighter.md)
