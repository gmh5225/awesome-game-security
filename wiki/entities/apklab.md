# APKLab

Visual Studio Code extension that turns Android APK reverse engineering into an integrated IDE workflow. Built in TypeScript, it wraps [[apktool]], [[jadx]], signing utilities, and HTTPS patching helpers behind editor commands. Supports decode, disassembly, decompilation, rebuild, signing, install, and dependency bootstrap flows on major desktop platforms. Primary audience: mobile security researchers, malware analysts, and app tampering testers. (source: wiki/sources/descriptions/APKLab__APKLab.md)

Editor-native alternative to Windows GUI [[apktoolgui]] and Bash orchestration [[apk-sh]]; complements agent-facing [[apktool-mcp-server]] and browser [[frida-ide]] as a cross-platform VS Code workbench for the decode→patch→sign lane.
