# Pandora

Analysis framework that checks whether a file looks suspicious and presents results in a convenient UI. Aimed at anti-cheat engineers and defensive researchers in the Anti Cheat → Analysis Framework lane rather than shipping as an AC product. Strongly recommended to run on Ubuntu 24.04 (newer LibreOffice). (source: wiki/sources/descriptions/pandora-analysis__pandora.md)

Complements packed/protected client triage peers such as [[die-engine-web]] and sample-unpack tooling such as [[android-unpacker]].
