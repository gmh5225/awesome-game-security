# kiln-ida

**IDA Pro 9.1** plugin exposing a **Streamable HTTP MCP** endpoint so desktop AI clients can query and control an open IDB: function listing, cross-references, debugger operations, and optional IDB edits. Sits in the Cheat / IDA Plugins agent-assisted RE lane beside [[ida-pro-mcp]], [[iida-mcp]], and [[ida-multi-mcp]]—automation surface, not proof of analysis quality.
