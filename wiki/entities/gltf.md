# glTF

Khronos Group **glTF** (GL Transmission Format) is a royalty-free specification for efficient transmission and loading of 3D scenes and models. The official repository holds the core specification, extension registry, conformance assets, and sample files used across engines and tooling—primarily documentation and data formats (Markdown, AsciiDoc, JSON-based model descriptors). Targets engine, rendering, and asset-pipeline developers building interoperable 3D workflows. (source: wiki/sources/descriptions/KhronosGroup__glTF.md)

Sits in the README **Runtime 3D Asset Delivery** / Game Assets lane as the canonical glTF 2.0 format spec upstream of implementors such as [[tinygltf]], browser loaders in [[three-js]], and engine asset paths in [[ursus]], [[oxylus]], and [[nightshade]]—not a GPU Present hook or cheat overlay.
