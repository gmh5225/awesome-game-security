# Go-Hacking

Free step-by-step reverse-engineering course for Go (Golang) binaries: a downloadable PDF book plus per-chapter sample source and companion IDA Pro database files progressing from hello-world through primitive types and control flow. Each topic follows write → debug → analyze or patch compiled output on x64, ARM64, and ARM32, with practical Go and C hacking exercises covering control-flow manipulation and binary analysis. (source: wiki/sources/descriptions/mytechnotalent__go-hacking.md)

Complements the same author's multi-arch RE curriculum [[mytechnotalent-reverse-engineering]], Windows RE guide [[hacking-windows]], Rust RE course [[hacking-rust]], and embedded firmware RE course [[embedded-hacking]].
