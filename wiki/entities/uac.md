# UAC (c4kef)

**Anti-cheat development platform** (c4kef) with a **Visual Studio** kernel-mode anti-cheat driver implementing detection routines for common cheat techniques, plus a **C++** framework for testing and validating cheat-detection methods from kernel level. Aimed at anti-cheat engineers and game-security researchers studying kernel-level cheat detection and AC architecture; also helps cheat developers probe weaknesses in their own implementations. (source: wiki/sources/descriptions/c4kef__UAC.md)

README lane: **Cheat developer platform**. Complements modular AC evaluation harnesses such as [[anti-cheat-testing-framework]] and [[anti-cheat-testbench]], and educational kernel AC samples such as [[basic-anti-cheat]] and [[anticheat-poc]].
