# WSA Builds

Distribution and documentation hub for customized **Windows Subsystem for Android (WSA)** builds with optional **Google Play services** and **root** solutions. Combines automation scripts and extensive guides to package, install, troubleshoot, and maintain multiple WSA variants across Windows versions. Documents practical integration paths such as **Magisk** or **KernelSU**, update channels, compatibility notes, and recovery guides for common installation failures. Targets advanced Android app and security-tooling workflows on Windows through tailored WSA environments. Sits in the README `WSA` lane beside rooted builds such as [[magiskonwsalocal]], kernel automation such as [[wsa-linux-kernel]], MSIX patchers such as [[wsapatch]], and sideload managers such as [[wsa-pacman]].
