# UE4Dumper Emulator

C/C++ **Unreal Engine 4 SDK dumper for Android emulator** targets from gmh5225: generates modding-oriented SDK output with memory-analysis workflows when UE4 mobile titles run in emulated Android rather than on rooted hardware. Sits in the Cheat / Game Engine Explorer:Unreal lane beside native Android dumpers such as [[ue4dumper]] and scripted attach paths such as [[ts-ue4dumper]] / [[frida-ue4dump]]. (source: wiki/sources/descriptions/gmh5225__UE4Dumper_Emulator.md)

Use [[game-engine-detector]] to confirm a package is UE4 before launching dump workflows on emulator images.
