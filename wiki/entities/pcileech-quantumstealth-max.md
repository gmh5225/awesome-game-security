# Pcileech QuantumStealth Max

**PCILeech-compatible FPGA firmware collection** (NoviceLevel) with **Vivado** build flows and batch scripts for multiple DMA hardware targets—**100T**, **Squirrel**, **Captain** variants, plus **M2**, **Enigma X1**, and **Immortal 75T** boards per the curated README entry. Ships Xilinx IP cores for **PCIe config space**, **BRAM**, **clock wizards**, and **FIFOs** to generate board-specific bitstreams. Primarily useful for **DMA security researchers** and **firmware developers** working with [[pcileech]]-class FPGA endpoints for **memory forensics** and **DMA attack** threat modeling—not a host-side tool.
