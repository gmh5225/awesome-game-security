# NiakPS5

Native full-screen home interface for homebrew-enabled **PlayStation 5** consoles: custom game/app library with DualSense navigation, local title discovery, and launches via a loopback-only broker on `127.0.0.1`. Renders animated PS4/PS5-style case art with optional LaunchBox CDN artwork fetched only when a title is selected. GPL-licensed native PS5 code (C/C++), Python packaging/metadata scripts, and OpenGL rendering validated in CI — a self-contained library shell for PS5 homebrew users and researchers studying launch boundaries without replacing Sony system shell components.
