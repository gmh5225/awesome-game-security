# project-tanya

**project-tanya** is a **service-oriented external game automation framework** focused on **Apex Legends** memory interaction (XRadius; C# / .NET; cheat / game:apex legends [Linux]). Modular layers cover core memory access, driver abstraction, game-state modeling, and separate **Aim** and **Sense** feature modules — aimed at long-running, stealth-conscious, memory-driven research workflows under [[easy-anti-cheat]]. The repo ships Linux service build/install scripts and hardening guidance such as **process isolation** and **ptrace restrictions**. (source: wiki/sources/descriptions/XRadius__project-tanya.md)

Complements other Linux Apex samples such as [[apex-linux]] and [[ayypex]] by emphasizing daemon-style external automation rather than in-process hooks or KVM/DMA host splits such as [[ez-apex-dma-aimbot]].
