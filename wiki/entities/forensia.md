# Forensia

Windows anti-forensics utility for post-exploitation trace reduction. C++ implementation with direct Windows API interaction covers file shredding, event-log and prefetch suppression, USN journal handling, timestamp-related cleanup, and removal of multiple shell and cache artifacts. Also includes options to clear Defender quarantine artifacts and perform file self-removal. Primarily intended for red-team simulation and defensive validation of incident response and forensic workflows. (source: wiki/sources/descriptions/PaulNorman01__Forensia.md)
