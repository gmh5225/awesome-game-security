# Mira

**Mobile runtime detection workbench** for iOS and Android that turns live device cases into reusable workflows and detection notes. Host apps expose sandboxed shell, PTY, screen capture, and file tooling; **Frida** supports Java and native hooks with RPC for one-off runtime analysis. A Python relay server and web console connect devices over LAN or relay exposure, and an **MCP server** lets AI assistants operate in the same remote sessions. Stack spans Android Java, iOS Swift with an iSH compatibility layer, shared native PTY code, and a Next.js control UI. Targets integrity and anti-cheat researchers exploring root, emulator, projection, Magisk, LSPosed, and jailbreak side channels beside classic Frida-detection samples.
