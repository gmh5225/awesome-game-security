# Destiny

Open-source **C# server emulator for MapleStory v0.83** (Fraysa): multi-server architecture with **center**, **login**, and **game** components, **Lua scripting** for NPC and portal behaviors, and **SQL-backed** game data for account and world state management. Organized as a Visual Studio solution. Primary use case is private-server development and MMORPG protocol or gameplay research—not live official-client anti-cheat bypass. (source: wiki/sources/descriptions/Fraysa__Destiny.md)

Sits in the README **Private Server-GMS-083 C#** lane beside v83 Java stacks such as [[maple-ezorsia]], v83 C++ stacks such as [[maplestory-v83-maplestory-cpp]], HeavenMS-based emulators such as [[maplestory-server]], and Unity v83 client reimplementations such as [[maple-unity]] that target the same legacy protocol era.
