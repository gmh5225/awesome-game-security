# CS2-External

**CS2-External** (Zckyy) is a Counter-Strike 2 external cheat project implemented in **C#**. It emphasizes a **read-only memory model** with **overlay drawing** and ships helper modules for **entities**, **offsets**, **view matrices**, and runtime cheat logic. The solution also includes **authentication and subscription handling** alongside core gameplay feature code. README **External** tag; positioned for educational exploration of external game memory analysis and overlay-based tooling for CS2. (source: wiki/sources/descriptions/Zckyy__CS2-External.md)

Complements other external CS2 samples such as [[titled-gui-cs2]] (C# framework with cs2-dumper offsets and D3D11 chams), [[cs2-external-cheat]] (C++ D3D11 ImGui modules), and [[cs2-external-1]] (gmh5225; ImGui + DirectX 11 overlay).
