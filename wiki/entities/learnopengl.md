# learnopengl

Companion source code for the LearnOpenGL tutorial series—progressive C++ examples from OpenGL fundamentals through advanced rendering techniques. Covers lighting, Assimp model loading, shadow mapping, deferred shading, PBR, and post-processing, with GLFW, GLEW, and GLM dependencies. Aimed at graphics programmers and game developers learning modern OpenGL rendering from scratch rather than as a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/JoeyDeVries__LearnOpenGL.md)

Sits in the README `[OpenGL]` lane beside progressive tutorials such as [[gltut]] and engine-building series such as [[opengl-3d-game-tutorial-series]]—educational graphics content for understanding render pipelines that later intersect hook and overlay research.
