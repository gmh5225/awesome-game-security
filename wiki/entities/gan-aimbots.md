# gan-aimbots

**ML aimbot research corpus** (Miffyli) in the cheat / Machine Learning lane. Python-based repository with code and datasets for studying machine-learning-driven aimbots in first-person shooters. Includes scripts for data collection, model training, classifier evaluation, plotting, and experiment orchestration using **ViZDoom** scenarios. Reproduces experimental pipelines from an academic publication and provides shared parameters for different GAN-aimbot groups. Aimed at game security researchers exploring both cheat generation methods and detection strategies—not a turnkey live-game cheat. (source: wiki/sources/descriptions/Miffyli__gan-aimbots.md)

Contrasts with production screen-capture YOLO pipelines such as [[ai-aimbot]] and [[rookieai-yolov8]] by focusing on controlled ViZDoom experiments and published GAN-aimbot baselines. Defensive evaluation counterparts include [[aimbot-detection-prototype]] and [[waldo]] via [[ai-aimbot-detection]].
