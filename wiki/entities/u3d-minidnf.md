# U3D MiniDNF

Unity 3D mini clone of Dungeon & Fighter (DNF/DFO). Recreates core side-scrolling action RPG mechanics—character movement, combo attacks, skill systems, monster AI, and dungeon progression—for Unity developers studying action RPG implementation and DNF-style game design. (source: wiki/sources/descriptions/gmh5225__U3D_MiniDNF.md)

Sits in the Game Engine / Game Develop source lane—useful for game developers and reverse engineers studying Unity combat/state-machine architecture rather than as a cheat or anti-cheat artifact.
