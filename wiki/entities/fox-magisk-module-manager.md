# Fox Magisk Module Manager

Android application for discovering, downloading, installing, and managing Magisk modules from online repositories. Built with Android tooling and Kotlin; features include repository search, module update checks, custom repo support, and separate local versus remote module views. Supports richer module metadata and compatibility handling for module developers and power users. Primary use case is rooted Android module management and mobile security customization workflows. (source: wiki/sources/descriptions/Fox2Code__FoxMagiskModuleManager.md)

Listed in the README under **Cheat → Magisk** as `[A module manager for Magisk]`.

Complements the stock [[magisk]] manager with multi-repo discovery, update tracking, and developer-oriented metadata beside module-ecosystem tools such as [[rescuex]] (boot-loop recovery), [[webui-x-portable]] (HTML/JS module WebUI host), and operational modules such as [[magisk-tailscaled]] and [[baize]].
