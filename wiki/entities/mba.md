# MBA

GPU-accelerated **Mixed Boolean-Arithmetic (MBA)** expression simplification toolkit using **CUDA**. Ships multiple CUDA kernel implementations for MBA evaluation and simplification, JSON-based data handling, and helper libraries for cooperative groups, memory management, and hashing. Targets deobfuscation researchers exploring high-performance MBA simplification via GPU parallelism. (source: wiki/sources/descriptions/SynthesisLab__MBA.md)

Complements CPU-side algebraic simplifiers such as [[cobra]] and [[mbased]], synthesis tools such as [[promba]] and [[qsynthesis]], and MBA sample generators such as [[mutaben]] and [[mba-obfuscator]].
