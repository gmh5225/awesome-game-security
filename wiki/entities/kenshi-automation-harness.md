# Kenshi Automation Harness

In-game **test automation harness** for **Kenshi** mod development (shaylanger). Combines an **RE_Kenshi** plugin with a CLI client for scriptable spawn, teleport, combat, crafting, and UI checks during mod iteration. Sits in the README **Game Testing** lane beside UE Gauntlet integration tests such as [[ue4-test-automation]] and Unity instrumentation-first QA samples such as [[games-test-automation-example]].
