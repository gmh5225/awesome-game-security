# mcp-safety-scanner

**MCPSafetyScanner** — automated MCP (Model Context Protocol) safety auditing and remediation using agents. Ships example MCP configs in the repo for reference workflows. Fits the Game Develop → **MCP server security** lane for game developers, reverse engineers, and tooling builders who wire AI agents to editor, RE, or custom MCP servers and need structured audit/remediation rather than ad-hoc config review. (source: wiki/sources/descriptions/johnhalloran321__mcpSafetyScanner.md)

Complements editor and tooling MCP bridges such as [[unity-mcp]], [[unreal-mcp]], and [[interactive-feedback-mcp]] by targeting defensive review of MCP server configuration and agent-exposed surfaces.
