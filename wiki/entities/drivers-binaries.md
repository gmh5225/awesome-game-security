# drivers-binaries

Collection of **Windows kernel driver binaries** gathered for vulnerable-driver and [[byovd]] research. Mostly compiled `.sys` files from multiple vendors, bundled with reference links to CVEs, security reports, and exploitation writeups. Serves as a practical sample set for testing detection rules, threat-hunting pipelines, and defensive controls around signed-driver abuse. Primary audience is security researchers and defenders studying kernel-level attack surfaces—not application development. Complements metadata catalogs such as [[loldrivers]], hash inventories such as [[ms-vulnerable-driver-list]], and other binary corpora such as [[vulnerable-drivers]], [[drivers-and-shit]], and [[physmem-drivers]]. (source: wiki/sources/descriptions/CaledoniaProject__drivers-binaries.md)
