# bypassHiddenApiRestriction

Android library for bypassing **hidden non-SDK API restrictions** on Android 9 through Android 12. Combines Java/Kotlin integration with native C/C++ components built through JNI and CMake; ships as a packaged dependency with a single initialization call suitable for application startup. Useful for Android reverse engineering, compatibility testing, and security research workflows that need restricted platform interfaces.
