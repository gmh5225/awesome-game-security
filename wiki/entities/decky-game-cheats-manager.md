# Decky Game Cheats Manager

**Decky Game Cheats Manager** (Qiming-Liu/Decky-Game-Cheats-Manager; marketed as DeckyGCM) is a **Decky Loader** plugin that exposes **Game Cheats Manager**–style trainer search, download, and library management on **Steam Deck** from the Quick Access menu and per-game library context menus. The stack pairs a **TypeScript/React** UI with a **Python** plugin backend embedding generated GCM core logic for catalog queries, authenticated downloads, archive extraction (ZIP / 7z / RAR), and local trainer metadata. Users can search trainers from sources such as FLiNG, XiaoXing, cheat tables, and the GCM catalog (English or Chinese name matching), bind downloads to Steam App IDs, import local executables, and optionally launch **Proton sidecar** programs through launch options. Steam library scanning, offline catalog refresh, bilingual UI tied to Steam language settings, and bounded concurrent downloads target on-device trainer workflows rather than desktop-only tooling. (source: wiki/sources/descriptions/Qiming-Liu__Decky-Game-Cheats-Manager.md)
