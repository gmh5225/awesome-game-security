# binaryninja-themes

Small theme collection for Binary Ninja (FuzzySecurity) that ships multiple `.bntheme` variants—tweaked standard, light, and green palettes inspired by Gruvbox aesthetics. Focuses on readability and UI color tuning across disassembly and graph views to improve analyst comfort and visual clarity during binary analysis sessions. (source: wiki/sources/descriptions/FuzzySecurity__BinaryNinja-Themes.md)

Visual comfort tooling—not an analysis plugin or decompiler extension.
