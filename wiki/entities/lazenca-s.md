# Lazenca S

**Lazenca S** (Lazenca) is an **Android anti-cheating engine** for detecting common game tampering behaviors. It combines **Java Android components** with **native C/C++ shared libraries** loaded through **JNI**. Exported checks cover **debugging**, **rooting**, **speed-hack behavior**, **binary modification**, and **virtual-machine-related indicators**. Intended for mobile game protection experiments and for studying anti-cheat detection techniques on Android. (source: wiki/sources/descriptions/Lazenca__Lazenca-S.md)
