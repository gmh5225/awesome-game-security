# tenet-ida9.0

IDA Pro 9.0 port of the [[tenet]] execution-trace explorer plugin. Keeps the same trace timeline visualization and forward/backward execution stepping as the original Tenet, with API updates for the IDA 9.0 SDK. Aimed at reverse engineers on IDA Pro 9.0 who need in-IDA execution trace analysis. (source: wiki/sources/descriptions/gmh5225__Tenet-IDA9.0.md)

Complements WinDbg TTD replay in IDA via [[ttddbg]] and standalone trace viewers such as [[execution-trace-viewer]] and [[x64dbg-trace-reader]] when the workflow stays inside IDA's static-analysis UI.
