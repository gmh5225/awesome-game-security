# AssaultCube

Open-source multiplayer first-person shooter built on the **CUBE engine** (assaultcube/AC). The codebase is primarily C and C++ and ships with extensive game assets, maps, scripts, and cross-platform launch tooling for Windows, Linux, and macOS. It emphasizes lightweight performance, low-latency network play, built-in map editing, bot support, demos, and multiple competitive game modes. Useful to game developers and security researchers who need a full FPS codebase for engine study, modding, or gameplay and anti-cheat experimentation — the common upstream learning title behind educational AssaultCube cheat and AC samples in this wiki.
