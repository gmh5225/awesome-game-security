# iOS Mod Menu Template for Theos

Theos tweak template for building iOS mod menus: a starter in the cheat / render-draw lane for game-security researchers and reverse engineers studying offensive overlay and in-game menu patterns on jailbroken iOS. Menu icons should be 50×50; the standard `tweak.xm` ships sample assets as base64 strings for quick preview and replacement. (source: wiki/sources/descriptions/joeyjurjens__iOS-Mod-Menu-Template-for-Theos.md)

Complements ImGui-based iOS menus ([[imgui-ios-mod-menu]]), IPA patch / sideload paths ([[ipapatch]], [[trollstore]]), and runtime injectors ([[opainject]]) with a Logos/Theos jailbreak-tweak scaffold.
