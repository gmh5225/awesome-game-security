# Flying-Guys-fully-modified

**Flying-Guys-fully-modified** is a fully expanded **Fall Guys** cheat suite (gmh5225) bundling a **custom kernel driver**, **KdMapper-based mapper**, and **user-mode client** with **ImGui** overlay rendering. It exposes **fly hacks** and **movement modifications** via **kernel-level memory access** to the game process. (source: wiki/sources/descriptions/gmh5225__Flying-Guys-fully-modified.md)

Evolution of the base [[flying-guys]] stack in the same KdMapper + ImGui external lane as [[kdmapper-rs]] and [[imgui]].
