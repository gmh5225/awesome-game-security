# gb-studio

Quick, easy retro **Game Boy adventure game creator** for Mac, Linux, and Windows. Primarily TypeScript and JavaScript; centers on driver development, rendering, and animation. Targets game developers, engine programmers, and graphics researchers in the README **Game Engine / source** and `[GameBoy]` lanes. (source: wiki/sources/descriptions/chrismaltby__gb-studio.md)

Visual authoring that exports playable GB ROMs complements runtime study via GB emulators such as [[kevboy]] and [[feather-gb]], and static cartridge analysis via [[gba-ghidra-loader]] (GBA-focused Ghidra loader).
