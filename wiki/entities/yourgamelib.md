# yourgamelib

Cross-platform C++11 framework for game-like applications built on CMake with OpenGL and OpenGL ES rendering. Automates integration of common libraries—GLFW, GLM, ImGui, Lua, Box2D, Bullet, and miniaudio—and ships a toolbox of asset loading, audio, math, and input utilities. Targets desktop (Windows, Linux, macOS), Android, and web (Emscripten). (source: wiki/sources/descriptions/duddel__yourgamelib.md)

Useful for game developers and engine researchers building lightweight cross-platform OpenGL applications with managed dependency integration—not a cheat or anti-cheat artifact.
