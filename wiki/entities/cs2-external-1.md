# CS2-External-1

**Counter-Strike 2 external cheat** (gmh5225) that reads game memory out-of-process and renders an **ImGui overlay via DirectX 11**. Feature modules include **aimbot**, **ESP** (box, skeleton, snaplines), and miscellaneous hacks—useful for researchers studying external CS2 architecture, RPM-based entity reads, and D3D11 overlay rendering. README **External** tag. (source: wiki/sources/descriptions/gmh5225__CS2-External-1.md)

Complements other external CS2 samples such as [[cs2-external-cheat]] (C++ D3D11 ImGui modules), [[titled-gui-cs2]] (C# framework with cs2-dumper offsets and D3D11 chams), [[cs2-ext]] (kernel-driver-backed external), and [[overlayai]] (Panorama inventory bridge via IPC).
