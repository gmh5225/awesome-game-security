# reverseai

**reverseai** (dagoSte/reverseai) is an agent-oriented static reverse-engineering stack for **untrusted PE, APK, and JavaScript** artifacts inside **locked offline containers**, pairing Ghidra, JADX, LIEF, and YARA-X analysis with **byte-anchored verification** and an **MCP server** so coding agents cannot drift from on-disk evidence. (source: wiki/sources/README-categories.md)

## Role in the README map

Listed under **Cheat → RE Tools** beside verification-gated hosts such as [[reverify]] and offline orchestrators such as [[harness-for-rea]]. Emphasizes sandboxed static analysis of hostile inputs rather than live game memory editing.
