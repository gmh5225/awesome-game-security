# Diligent Engine

Cross-platform low-level 3D graphics library and rendering framework with a unified API across Direct3D 11/12, Vulkan, Metal, OpenGL, OpenGLES, WebGL, and WebGPU. Uses HLSL as a common shader language. Emphasizes modular C++ design, multithreaded command and resource workflows, advanced rendering features, and tooling around render state management. Aimed at game engine and visualization developers, including security researchers who need portable graphics infrastructure for instrumentation or overlays. (source: wiki/sources/descriptions/DiligentGraphics__DiligentEngine.md)

Sits in the Renderer / multi-API graphics-library lane—a portable rendering foundation for engine and graphics research, not a cheat or anti-cheat artifact.
