# vscript-lua51

**VScript** tooling focused on **Lua 5.1** scripting in **Counter-Strike 2**—enabling **external Lua module DLL** loading for CS2's in-engine VScript runtime. Listed under README **[VScript]**; useful for game-security researchers and reverse engineers studying offensive techniques in the cheat / game:cs2 lane. (source: wiki/sources/descriptions/gmh5225__vscript_lua51.md)

Complements Source 2 SDK generators such as [[source2gen]] / [[source2sdk]], CS2 offset dumps such as [[cs2-offsets]], and internal CS2 samples such as [[asphyxia-cs2]] in the same Source 2 scripting / memory-layout research lane.
