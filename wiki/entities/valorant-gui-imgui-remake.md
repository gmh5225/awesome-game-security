# valorant-gui-imgui-remake

Valorant **cheat GUI framework** (C++) using Dear ImGui for menu rendering. Provides a styled ImGui interface with tabs, toggles, and sliders for controlling cheat features such as ESP, aimbot, and visual modifications. Demonstrates cheat menu design and UE4 game interaction patterns for game security researchers studying Valorant cheat UI implementations and ImGui-based cheat menu architectures under [[vanguard]]. (source: wiki/sources/descriptions/gmh5225__valorant-gui-imgui-remake.md)
