# directx11-with-windows-sdk

Comprehensive DirectX 11 tutorial and sample code collection built with the Windows SDK. Progressive rendering examples span basic triangle drawing through shadow mapping, deferred shading, and compute shaders, with ImGui integration for interactive debugging and CMake plus Visual Studio build support. Aimed at graphics programmers and game developers learning DirectX 11 rendering pipeline programming—not a cheat, anti-cheat, or security tool. (source: wiki/sources/descriptions/MKXJun__DirectX11-With-Windows-SDK.md)
