# ringo-ac

Modular **Windows kernel anti-cheat** reference stack (000nico): kernel driver, usermode client, and analysis server components with HWID and hypervisor checks plus callback-based telemetry. README positions it for learning and CS2-style server-side protection research—not a turnkey commercial product. (source: wiki/sources/README-categories.md)
