# macroquad

Rust 2D game library (Rust + JavaScript) centered on shaders, rendering, and audio. Aimed at game developers, engine programmers, and graphics researchers in the Game Engine / source lane. (source: wiki/sources/descriptions/not-fl3__macroquad.md)

Sits beside other approachable game libraries ([[raylib]], [[orx]]) as a Rust 2D engine-library study surface—not a cheat or anti-cheat artifact.
