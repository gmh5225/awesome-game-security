# IDASkins

IDA Pro plugin that adds custom theme and skin support to the Qt-based UI. Enables CSS-like styling of disassembly views, the hex editor, output windows, and other GUI elements for a personalized appearance during long static-analysis sessions. (source: wiki/sources/descriptions/gmh5225__IDASkins.md)

Visual comfort tooling—not an analysis plugin or decompiler extension. Complements preset dark color themes such as [[long-night]], [[ida-nord-theme]], [[ida-dark-plus]], and [[dp701]], and the VS Code theme converter [[ida-themer]] when analysts want broader Qt skin customization rather than palette-only swaps.
