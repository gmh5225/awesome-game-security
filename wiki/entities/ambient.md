# Ambient

Open-source cross-platform **runtime and multiplayer game engine** (AmbientRun/Ambient) for building, deploying, and sharing high-performance games. Built primarily in **Rust**, it targets web and desktop through **WebAssembly** and **WebGPU**. Core capabilities include an **ECS-style real-time data model**, **automatic network synchronization**, package-based workflows, and configurable asset pipelines—aimed at developers and technical creators who want modern multiplayer infrastructure rather than a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/AmbientRun__Ambient.md)

Sits in the Game Engine / source lane beside other Rust ECS and wgpu/WebGPU stacks such as [[bevy]], [[nightshade]], and [[bloom-engine]]; automatic net sync complements production netcode libraries like [[lightyear]] for studying authoritative multiplayer and client-server trust boundaries.
