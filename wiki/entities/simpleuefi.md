# SimpleUEFI

Simplified **UEFI application development framework** for Visual Studio and the **EDK-II** toolchain. Ships MSVC project templates, property sheets, and a Python setup script so researchers can bootstrap UEFI application projects without the full EDK-II build complexity. (source: wiki/sources/descriptions/Th3Spl__SimpleUEFI.md)

Aimed at **UEFI security researchers** and **bootkit developers** who want a streamlined Visual Studio–based pre-OS development environment—complements minimal CMake scaffolds such as [[eficmake]] and boot-chain PoCs such as [[uefi-bootkit]] and [[bootlicker]] when iterating on firmware-stage payloads before OS load.
