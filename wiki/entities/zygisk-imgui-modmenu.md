# zygisk-imgui-modmenu

Hobby **ImGui with Zygisk** sample: a Magisk Zygisk module that injects a Dear ImGui overlay into Android game processes. Built for fun; useful for game security researchers and reverse engineers studying offensive cheat / render-draw techniques on rooted Android.
