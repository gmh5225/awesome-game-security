# ue4dumper

C/C++ Unreal Engine 4 SDK dumper for **Android**: generates modding-oriented SDK output from mobile UE4 titles. Sits in the Cheat / Game Engine Explorer:Unreal lane beside Frida/TypeScript dumpers such as [[ts-ue4dumper]], but targets native Android game processes rather than scripted attach workflows.
