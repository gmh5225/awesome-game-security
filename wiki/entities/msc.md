# MSC

**Legacy MapleStory GMS bot framework** (PrinceFroggy). Combines **C++ and C#** components with resource files holding **map and portal data** consumed by bot navigation logic. README notes the project is **discontinued** and that some major logic is **not included** in the published tree — best treated as a historical reference for studying older MMO bot architecture rather than a runnable automation stack. (source: wiki/sources/descriptions/PrinceFroggy__MSC.md)

Sits in the MapleStory automation lane beside modern Artale/Worlds bots such as [[maplestory-auto-level-up]] and [[maplestory-worlds-automation]], the sibling legacy GMS trainer toolkit [[msb]] (injection/runtime control; GMS 128–140), and beside client-layout RE corpora such as [[maplestory-cms95-client-address]] for map/portal-driven navigation study.
