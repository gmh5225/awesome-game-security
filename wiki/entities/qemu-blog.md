# qemu_blog

Structured **QEMU internals** documentation from Airbus SecLab — a series of Markdown technical posts with source-level references for navigating QEMU architecture and implementation. (source: wiki/sources/descriptions/airbus-seclab__qemu_blog.md)

Coverage includes machine and device creation, memory regions, interrupt handling, timers, PCI components, execution flow, and TCG (Tiny Code Generator) internals. Aimed at systems hackers and security researchers who need a practical entry point for emulator internals and virtualization research—not a runnable fork or anti-VM patch.

Complements QEMU lab forks ([[ispras-qemu]], [[qemu-nyx]], [[panda]], [[hardened-qemu]]) by explaining upstream QEMU design before patching or instrumenting builds.
