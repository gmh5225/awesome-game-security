# FPSSample

**FPSSample** (Unity-Technologies) — Unity's official first-person shooter sample game demonstrating production-level game development patterns. Covers character animation systems, weapon handling, networked multiplayer architecture, and comprehensive asset pipelines for a complete playable FPS built on the Unity engine. Aimed at game developers and Unity researchers studying production FPS architecture, networking, and animation state machine design—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/Unity-Technologies__FPSSample.md)

Complements managed-side ground truth from [[unity-cs-reference]] with a full playable title surface for anim/state-machine and netcode study. Useful beside IL2CPP/Mono RE workflows ([[il2cpp]], [[dnspy]], [[unityexplorer]]) when correlating sample-project patterns to shipped Unity FPS clients.
