# CSGOCrosshair

Web-based **CS:GO crosshair generator** from Skarbo. JavaScript with jQuery, jQuery UI, and KineticJS plus HTML/CSS assets lets players preview and tune crosshair parameters visually, export ready-to-paste console config values, apply presets, and configure keybind-related setup. Primary audience is players and modding enthusiasts designing and sharing crosshair layouts—not an in-game cheat or memory tool. (source: wiki/sources/descriptions/Skarbo__CSGOCrosshair.md)
