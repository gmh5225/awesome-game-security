# radius2

Fast binary emulation and symbolic execution framework built on radare2 (Rust + C). Centers on modding and memory analysis; aimed at game-security / RE research in the Cheat → Radare Plugins lane. (source: wiki/sources/descriptions/radareorg__radius2.md)

Useful as an r2-backed emulate/symbolic-exec reference alongside multi-emulator harnesses and angr-style decompilers—not a debugger UI or metamorphic rewriter.
