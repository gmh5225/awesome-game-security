# Command and Conquer: Red Alert

Electronic Arts' open-source release of **Command & Conquer: Red Alert** — the original Westwood RTS title — with Steam Workshop support for community mods and maps. The tree is a publisher-maintained Game Develop / source artifact for studying classic RTS engine internals, building mod tooling, and reverse-engineering Westwood-era game systems. (source: wiki/sources/descriptions/electronicarts__CnC_Red_Alert.md)
