# RE-UE4SS

**Unreal Engine 4/5 scripting and modding framework** (UE4SS-RE; modern C++). Combines a Lua scripting API, C++ modding API, blueprint mod loading, live property inspection and editing, and multiple data dumpers. Supporting tooling covers runtime hooks and SDK/header generation for advanced mod development, runtime analysis, and Unreal game reverse-engineering research. Listed as a re-host of the Unreal Engine 4/5 Scripting System. (source: wiki/sources/descriptions/UE4SS-RE__RE-UE4SS.md)

Sits in the in-process Unreal live-scripting lane beside inject dumpers (Dumper-7), runtime SDK generators such as [[ue4genny]], and title-specific UE4SS mod stacks such as [[palmods]]—all operating on the same [[unreal-object-model]] research surface.
