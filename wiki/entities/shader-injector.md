# ShaderInjector

D3D12 shader injector for **Final Fantasy VII Rebirth** on PC that intercepts rendering API calls to inject or replace pixel shaders at runtime. Uses MinHook and Dear ImGui with live shader editing; built primarily as a DirectX 12 interceptor, so it can theoretically be adapted to other D3D12 titles. Aimed at graphics programmers and Windows game tooling developers in the DirectX hook lane—not a full cheat overlay framework. (source: wiki/sources/descriptions/frostbone25__ShaderInjector.md)
