# LumixEngine

C/C++ Lumix Engine tree (and sample projects) centered on driver development, shader work, and rendering—aimed at game developers, engine programmers, and graphics researchers in the Game Engine / source lane, not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/nem0__LumixEngine.md)

Sits beside other lightweight C/C++ engine sources ([[corange]], [[exengine]], [[wickedengine]]); Plugins:Lumix content such as [[lumixengine-maps]] (OSM → roads/buildings) builds on this engine surface.
