# event_replay

Android input-event recorder/replayer that captures touchscreen and key events via `/dev/input` and replays them with precise timing. Packaged as a Magisk module with a command socket and gesture-trace analyze/generate (left/right/up/down/click) for automated game input simulation. (source: wiki/sources/descriptions/qq703048949__event_replay.md)

Sits in the Cheat Magisk / mobile input-simulation lane beside modules such as [[easypixel]] and [[move-certificate]], and opposite desktop input-realism samples like [[human-mouse-movement]]. Framework home: [[magisk]].
