# UE-Plugin-SCUE4-Plugin

**SCUE4** (*Secure-Client*) — a **Unreal Engine 4** C++ plugin that integrates as a game module in UE4's build system and adds client-side anti-cheat and security hardening. Surfaces include runtime integrity checks, memory protection for sensitive game variables, network-packet encryption, and binary tamper detection. Aimed at UE4 developers shipping in-engine protection and at researchers studying engine-level AC plugins under README **Game Engine Protection:Unreal**. (source: wiki/sources/descriptions/gmh5225__UE-Plugin-SCUE4-Plugin.md)

Same SCUE4 family as [[unreal-engine-protection]] (SafeGameInstance / SC Safe Types / Game-Guard); this gmh5225 repo listing emphasizes integrity, variable shielding, packet crypto, and tamper detection at the module layer.
