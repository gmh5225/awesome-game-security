# Gameplay

**Cross-platform C++ 3D game framework** from gameplay3d with an OpenGL ES 2.0/3.0 rendering pipeline, scene graph, material/shader system, Bullet physics, OpenAL audio, skeletal animation, terrain rendering, particle effects, and a form-based UI toolkit. Targets Windows, macOS, Linux, iOS, and Android from a single CMake codebase; includes Lua scripting and an encoder for converting FBX/Collada assets into the engine's binary `.gpb` format. (source: wiki/sources/descriptions/gameplay3d__gameplay.md)

Sits in the Game Engine / source lane — an OSS C++ engine codebase for development and graphics/RE study (scene graph, GLES render path, physics integration), rather than a cheat or anti-cheat artifact.
