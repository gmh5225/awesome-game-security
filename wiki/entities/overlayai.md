# OverlayAI

**OverlayAI** is an external Counter-Strike 2 cheat (C++; Windows) that renders a DirectX 11 ImGui overlay while reading and modifying game memory from outside the process. Combat and visual modules include ESP, aim assist, triggerbot, glow, movement helpers, and visual-bypass features. A modular inventory changer uses an injected bridge DLL, named-pipe IPC, and Panorama UI integration to apply client-side skins and loadouts via SOCache manipulation. The codebase is organized around dumped schema offsets, memory utilities, and extensive Panorama and inventory research to track CS2 updates. Useful for game security researchers and anti-cheat developers studying external overlay cheats, memory manipulation, and inventory spoofing techniques in CS2.
