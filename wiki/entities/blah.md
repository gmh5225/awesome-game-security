# blah

Lightweight **2D game framework** for **C++** with simple portability, few dependencies, and a clean API covering app lifecycle, rendering, input, audio, and math utilities. Built with **CMake** and **C++17**; supports **OpenGL** or **Direct3D11** renderer backends. Intended for developers who want a small, hackable engine base for 2D game prototypes rather than a full commercial engine stack. (source: wiki/sources/descriptions/NoelFB__blah.md)

Sits in the Game Engine / `[C++ 2D]` source lane—useful for studying a minimal cross-backend 2D framework tree and renderer abstraction boundaries.
