# G37OBS (ekknod)

**G37OBS** is an **OBS Studio plugin** research project for **CS:GO**, written primarily in **Lua** and centered on plugin development. It targets game-security researchers and reverse engineers studying offensive techniques in the cheat / game:csgo area. (source: wiki/sources/descriptions/ekknod__G37OBS.md)

The OBS plugin form factor reuses [[obs-game-capture]] frame-acquisition paths instead of in-game Present hooks or separate overlay HWNDs—useful for studying how capture-based cheat pipelines appear as legitimate streaming tooling.
