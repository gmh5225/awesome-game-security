# koidbg

Windows ARM64 debugger aimed at game-security researchers and reverse engineers studying offensive techniques in the cheat / debugging lane. Documentation is available in English and Portuguese. (source: wiki/sources/descriptions/keowu__koidbg.md)

Fills the Windows-on-ARM64 debugging gap beside x86/x64 tools such as [[x64dbg]], [[syser]], and WinDbg—relevant as WoA games, emulated ARM64 targets, and ARM64 Windows builds grow in the RE toolchain.
