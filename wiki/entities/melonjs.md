# melonJS

Fresh, modern, lightweight HTML5 game engine rebuilt with ES6 classes, inheritance, and semantic structure; bundled via esbuild for fast builds, tree-shaking, and modern JavaScript tooling. Aimed at game developers, engine programmers, and graphics researchers in the Game Engine / source lane. (source: wiki/sources/descriptions/melonjs__melonJS.md)

Sits in the Game Engine / HTML5 source lane—an OSS browser game-engine tree for development and graphics study, rather than a cheat or anti-cheat artifact. Adjacent to [[turbulenz-engine]], [[pixijs]], [[three-js]], and [[engine]] (PlayCanvas).
