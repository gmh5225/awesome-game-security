# r3d

C/C++ 3D rendering library built on top of **raylib**, adding PBR materials, deferred and forward rendering, shadow mapping, SSAO, bloom, decals, skeletal animation, particle systems, and a full OpenGL-based render pipeline. Aimed at game developers and graphics researchers who want advanced OpenGL rendering features while staying on raylib's approachable foundation—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/Bigfoot71__r3d.md)

Sits in the Game Engine / source lane as a raylib extension for studying modern OpenGL render pipelines (PBR, deferred shading, post-processing) atop the [[raylib]] multimedia stack.
