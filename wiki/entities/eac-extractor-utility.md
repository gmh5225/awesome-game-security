# EAC-Extractor-Utility

Utility for extracting and dumping Easy Anti-Cheat (EAC) driver and module files from game installations. Locates EAC components in the game directory and Windows driver store, then decrypts/extracts the anti-cheat kernel driver, user-mode modules, and configuration files for offline static analysis and reverse engineering. Aimed at anti-cheat researchers who need EAC binaries without live runtime attachment. (source: wiki/sources/descriptions/lguilhermee__EAC-Extractor-Utility.md)
