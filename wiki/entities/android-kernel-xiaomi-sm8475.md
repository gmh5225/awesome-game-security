# android_kernel_xiaomi_sm8475

Android kernel source for **Xiaomi SM8475** (Snapdragon 8+ Gen 1 / Qualcomm Waipio) devices, including Redmi K60 and POCO F5 Pro (mondrian) builds targeting **Pixel Experience Plus**. Includes the full kernel tree with GKI ABI definitions for multiple vendors, Qualcomm-specific platform support, and device configurations—aimed at Android kernel developers and mobile security researchers building or analyzing custom kernels on Snapdragon 8+ Gen 1 hardware. (source: wiki/sources/descriptions/LowTension__android_kernel_xiaomi_sm8475.md)

Stock GKI OEM trees like this sit beside the matching ROM device tree [[device-xiaomi-mondrian]] on the same mondrian platform, peer Qualcomm Xiaomi sources such as [[android-kernel-xiaomi-sweet]], and branch-index catalogs such as [[xiaomi-kernel-opensource]] and [[kernel-devicetree]].
