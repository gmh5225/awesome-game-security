# TWindbg

Python **pykd** extension that adds a **PEDA-like debugger UI** to WinDbg: live register pane, disassembly near the program counter, and stack contents with **smart dereference on each step or trace**, plus PEDA-style commands for memory inspection and symbol lookup. Brings a GDB-PEDA-inspired workflow into WinDbg for exploit development and binary analysis rather than replacing the core debugger. (source: wiki/sources/descriptions/bruce30262__TWindbg.md)

Targets Windows exploit developers and reverse engineers who want a more comfortable interactive debugging experience in the README Cheat → WinDbg Plugins lane.
