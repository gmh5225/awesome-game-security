# Pareidolia Triggerbot

**Hypervisor-based external Widowmaker triggerbot** (blackhades00; cheat / triggerbot & aimbot / game:overwatch) built on **VivienneVMM** and **MouClassInputInjection** to bypass **Overwatch Anti-Cheat**. README claims it remained undetected since early 2018 completion. Useful for game security researchers and reverse engineers studying below-OS external triggerbot architectures against Blizzard Warden. (source: wiki/sources/descriptions/blackhades00__PareidoliaTriggerbot.md)

Contrasts with in-process Overwatch samples such as [[overwatch-2-cheat-aimbot-esp]] and zero-memory colorbot pipelines such as [[overwatch2-colorbot-cheats]].
