# iaito

Official radare2 GUI built on Qt5/6, focused on reverse-engineering workflows. Written primarily in C/C++; centers on RE, editor tooling, and plugin development for game-security and offensive binary analysis. (source: wiki/sources/descriptions/radareorg__iaito.md)

Complements Cheat → Radare Plugins such as [[r2ai]] / [[radius2]] / [[r2garlic]] / [[r2morph]] by providing the desktop GUI front-end for radare2 sessions—useful when IDA/Ghidra-style interactive UIs are preferred over CLI-only r2.
