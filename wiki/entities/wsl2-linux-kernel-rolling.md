# WSL2 Linux Kernel Rolling

Community **rolling stable Linux kernel builds** and configuration guidance for WSL2 — Markdown-driven documentation plus CI automation that rebuilds when newer stable kernel releases land. Includes build instructions for **x86** and **ARM64** targets and emphasizes reproducible kernel workflows. Intended for WSL2 users and low-level developers who need up-to-date guest kernels for testing and research, complementing Microsoft’s official [[wsl2-linux-kernel]] source tree.
