# SQLite-Unity3D

Unity **C#** learner sample that persists and restores **player coordinates** through an **SQLite** database. A simple **`DatabaseManager`** workflow saves position data during gameplay and reloads it on keyboard shortcuts. The project shows how to ship an SQLite file under **StreamingAssets**, open it at runtime, and map basic game-state values into persistent storage—aimed at beginners who want a lightweight save/load foundation rather than full serialization frameworks or cloud backends. (source: wiki/sources/descriptions/OguzKaira__SQLite-Unity3D.md)

Sits in the Game Engine **Unity SQLite** lane as managed-side persistence basics beside production Unity samples such as [[fpssample]] and save-system plugins on other engines such as [[simple-quest]].
