# CheatUnityGames

**Android native development template** for Unity game cheat experimentation (SsageParuders). Built around **C/C++ NDK** workflows in VSCode with scripts for building **shared objects** and native binaries. Integrates common mobile game-hacking components such as **[[il2cpp-resolver]]** and **[[dobby]]** for runtime analysis and inline hooking. Primary use case: studying **Android injection** and **native-layer manipulation** techniques against Unity mobile targets. README tag: `[Unity cheat framwork]`. (source: wiki/sources/descriptions/SsageParuders__CheatUnityGames.md)

Complements other Android Unity cheat scaffolds ([[android-cheat-template]], [[imgui-unity]], [[imgui-unity-android]]) and generic IL2CPP runtime tooling ([[il2cpp-spy]], [[frida-il2cpp-bridge]]) when the goal is an NDK-first inject/hook template rather than Frida-only or overlay-only workflows.
