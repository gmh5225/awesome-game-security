# fastDbg

**fastDbg** is a high-speed x64 ELF debugger written in Go for Linux. It exposes breakpoint management, memory inspection, register operations, disassembly, and **ptrace**-based process control through a command interface—aimed at reverse engineers and security researchers who want a lightweight but feature-rich native debugging toolchain. The project also ships **eBPF** tracing support and QEMU-related modules for advanced low-level analysis, including native and QEMU kernel-debug workflows. (source: wiki/sources/descriptions/Yayoi-cs__fastDbg.md)
