# KozyAntiCheat

**Kozy AntiCheat** is a server-side anti-cheat and cheat-mitigation framework for multiplayer **Minecraft Java** networks. Implementation is primarily **Java**, with a **Python** build script that compiles sources and packages a single **JAR** for typical plugin or Fabric-bridge server layouts. Detection spans movement, combat, world and interaction abuse, and server exploit defense using standard server APIs, spatial checks, and configurable violation handling rather than brittle NMS hooks—oriented at operators on modern **Paper**-family stacks (**Paper**, **Purpur**, **Folia**) who want lag-aware checks, staff moderation commands, and tunable punishments in production. (source: wiki/sources/descriptions/mrKozy__KozyAntiCheat.md)
