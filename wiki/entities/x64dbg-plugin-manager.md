# x64dbg Plugin Manager

[[x64dbg]] plugin manager for discovering, installing, and managing debugger extensions. Written in C++/C; centers on plugin development and modding workflows. Useful for game-security researchers and reverse engineers studying offensive techniques in the Cheat / x64dbg Plugins lane. (source: wiki/sources/descriptions/horsicq__x64dbg-Plugin-Manager.md)

Not a debugger or analysis plugin itself—meta-tooling that simplifies building and maintaining the [[x64dbg]] plugin ecosystem alongside peers such as [[dotx64dbg]] and [[chaiscript-plugin]].
