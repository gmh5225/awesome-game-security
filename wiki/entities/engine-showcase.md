# engine-showcase

Older custom C++ game-engine showcase with documentation, Lua/UI layouts, level assets, networking notes, and related runtime configuration. The tree includes engine-adjacent third-party pieces plus game content under `etc/` and docs under `doc/`. Useful mainly for game developers and engine programmers studying legacy engine layouts and tooling—not a cheat or anti-cheat artifact.
