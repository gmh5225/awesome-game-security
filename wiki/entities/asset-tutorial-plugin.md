# AssetTutorialPlugin

Unreal Engine C++ tutorial plugin that demonstrates how to create a custom asset type and a dedicated editor for it. Includes runtime and editor modules, sample reflection-enabled `UObject` classes, and custom editor tooling for a `NormalDistribution` asset. Follows standard Unreal plugin conventions with module build scripts. Primary use case is a hands-on reference for developers extending the engine asset pipeline and editor workflow—not a cheat, dumper, or anti-cheat artifact.
