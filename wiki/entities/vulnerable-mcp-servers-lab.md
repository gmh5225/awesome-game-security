# vulnerable-mcp-servers-lab

**Vulnerable MCP Servers Lab** — intentionally vulnerable Model Context Protocol (MCP) servers for hands-on attack and defense training. Scenarios include path traversal, indirect prompt injection, eval-based code execution, typosquatting, outdated dependencies, and secret leakage. Implementations are mainly Python and JavaScript, with per-scenario documentation and client configuration snippets for reproducible demos. Targets security researchers and red-team practitioners assessing AI agent toolchain risks in controlled environments. (source: wiki/sources/descriptions/appsecco__vulnerable-mcp-servers-lab.md)

Complements defensive MCP auditing tools such as [[mcp-safety-scanner]] by supplying an offensive training surface for pentesting MCP server misconfigurations and agent-exposed attack paths.
