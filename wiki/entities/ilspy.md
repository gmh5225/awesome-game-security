# ILSpy

Open-source .NET assembly browser and decompiler. Decompiles managed binaries to C#, VB.NET, or IL across .NET Framework, .NET Core, and .NET 5+. Features an interactive tree-based assembly browser, syntax-highlighted source view, search, and plugin extensibility; handles async/await, LINQ, and generic types. Listed in the README under **For Unity** — primary GUI decompiler for Mono-era Unity `Assembly-CSharp.dll` alongside dnSpy. (source: wiki/sources/descriptions/icsharpcode__ILSpy.md)
