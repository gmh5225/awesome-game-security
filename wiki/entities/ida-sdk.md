# ida-sdk

Mirror or collection of IDA Pro SDK files for plugin development—C++ headers, library files, and documentation for building IDA Pro plugins and processor modules across multiple IDA versions. Aimed at plugin developers who need SDK artifacts for custom analysis tools and extensions. (source: wiki/sources/descriptions/gmh5225__ida-sdk.md)

Complements the parallel multi-version SDK archive [[idasdk-collection]], runtime plugin/script collections such as [[idawilli]] and [[idaplugins]], IDAPython convenience layers like [[sark]], and interactive SDK access via [[idacpp]] (Cling/Clang 20 C++ REPL in IDA's scripting engine; native `ea_t` / Hex-Rays types without FFI) (source: wiki/sources/descriptions/allthingsida__idacpp.md).
