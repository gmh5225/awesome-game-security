# ida-screenshot

High-resolution screenshot capture plugin for IDA Pro. Install via `make install` on macOS or Linux, or place `screenshot.py` in the IDA user plugins folder. Aimed at game-security researchers and reverse engineers in the cheat / IDA Plugins lane who need publication-quality graph and disassembly captures for reports, write-ups, and documentation. (source: wiki/sources/descriptions/jonpalmisc__ida_screenshot.md)

Single-purpose documentation/export tooling—complements analysis plugins in curated packs such as [[idaplugins]] rather than replacing them.
