# gamedev_libraries

Collection of open-source C/C++ libraries for gamedev, written with a data-oriented philosophy (POD structures preferred over classes; flat arrays as the preferred data structure). Aimed at game developers, reverse engineers, and tooling builders in the Game Develop / guide lane—not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/raizam__gamedev_libraries.md)

Useful background library pack alongside approachable C/C++ videogame libs such as [[raylib]] and curated engine-dev guides such as [[awesome-game-engine-dev]].
