# AutoHotkey_L

**AutoHotkey** (Lexikos/AutoHotkey_L) is an open-source Windows automation and macro scripting platform built around a custom hotkey-focused language. The repository is primarily C/C++ source for interpreter binaries, self-contained script runtimes, and related tooling, plus an experimental DLL hosting interface for embedding the interpreter in other applications. (source: wiki/sources/descriptions/Lexikos__AutoHotkey_L.md)

Primary use cases are general task automation and input scripting. In game-security contexts it appears for game-adjacent macro experimentation and defensive analysis of script-driven input behavior—upstream to script-based cheat samples such as [[csgo-external-ahk-hack]] that use AHK memory-reading and hotkey APIs out-of-process.
