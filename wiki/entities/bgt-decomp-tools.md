# bgt-decomp-tools

Python toolkit to recover **AngelScript** structure, strings, and assets from **BGT/NVGT** blind-audio-game executables. Workflows include identify/recover steps for researchers studying proprietary script hosts in accessible-game binaries. (source: wiki/sources/README-categories.md)
