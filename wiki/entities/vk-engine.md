# Vk-Engine

WIP Vulkan-based 3D game engine written primarily in Jai, with C/C++ glue for third-party libraries. Provides an entity-component style runtime, scene/asset pipelines for meshes, materials, animations, and LODs, plus sample scenes for lighting, shadows, parallax, and physics. Integrates Dear ImGui for editor UI and gizmos, and Jolt Physics via custom bindings; build scripts target Windows and Unix-like hosts. README highlights hot-reloadable modules, clustered forward rendering, PBR, and editor viewports. (source: wiki/sources/descriptions/ostef__Vk-Engine.md)

Sits in the Game Engine / Vulkan source lane—useful for learning or prototyping modern Vulkan rendering, editor tooling, and physics-driven gameplay rather than as a cheat or anti-cheat artifact.
