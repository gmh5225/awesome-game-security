# Obfuz

Open-source Unity C# **code obfuscation and protection** solution aimed at commercial game projects. Described as powerful, user-friendly, and reliable for shipping protected Unity builds; the project is under active development with additional features planned. Listed under Anti Cheat → Game Engine Protection:Unity for anti-cheat engineers and defensive security researchers hardening managed Unity clients against dnSpy/IL-level RE—not a kernel AC product. (source: wiki/sources/descriptions/focus-creative-games__obfuz.md)

Useful as a Unity-specific obfuscation-engine reference alongside general .NET protectors such as [[obfuscar]] and [[confuserex]], and runtime encryption helpers such as [[usecurity]].
