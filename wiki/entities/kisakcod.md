# KisakCOD

Fully buildable open-source **Call of Duty 4 multiplayer executable reimplementation** (SwagSoftware). Written mostly in **C/C++** with **CMake** and **Visual Studio** build targets, integrating legacy game dependencies including DirectX-era middleware and **Steam** interfaces. The repository exposes large gameplay, networking, and engine-side source modules intended for practical modification and extension. (source: wiki/sources/descriptions/SwagSoftware__KisakCOD.md)

Primarily used by mod developers, engine tinkerers, and security-minded players researching **legacy exploit surfaces** in classic online shooters—not a live-service cheat drop, but a readable client/network codebase for studying IW engine-era multiplayer internals.
