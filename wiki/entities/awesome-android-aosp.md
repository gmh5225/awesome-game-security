# Awesome Android AOSP

Curated **awesome list** for Android AOSP and custom ROM development. Markdown knowledge base organizing links for build systems, kernels, device trees, Project Treble, SELinux, debugging, and vendor-specific workflows. Emphasizes low-level platform engineering rather than app development and serves as a structured learning map for researchers who need deeper Android system-internals context. README lane: **Guide**. (source: wiki/sources/descriptions/Akipe__awesome-android-aosp.md)
