# GOWTool

Windows utility for extracting and converting assets from **God of War (2018)**. Implemented in C++ with Visual Studio; uses **DirectXTex** and **glTF** components for texture conversion and export. Extends earlier community workflows with a broader feature set and a more practical extraction pipeline for studying proprietary Santa Monica Studio content formats. Primary audience: game asset researchers, modders, and developers reverse-engineering title-specific archives and mesh/texture layouts. README lane `[God of War 2018]`. (source: wiki/sources/descriptions/HitmanHimself__GOWTool.md)

Sits in the README **Extracting assets** / Game Assets lane beside engine-generic offline extractors such as [[assetstudio]] and [[uabe]], and complements curated format-RE indexes like [[awesome-game-file-format-reversing]] when the goal is a title-specific God of War pipeline rather than Unity/Unreal bundle tooling.
