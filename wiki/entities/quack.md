# Quack

Universal **anti-cheat research kit** for integrating client-side monitoring into games and validating detection concepts. Mostly C++ with multiple modules, integration examples, documentation, and companion **red-team tooling** for adversarial testing. Includes client-side monitoring components and supporting infrastructure aimed at experimentation—not production deployment. Primary audience: game security researchers developing and validating anti-cheat ideas. (source: wiki/sources/descriptions/JonathanBerkeley__Quack.md)

## Scope

- Modular client-side AC monitoring and game-integration samples
- Documentation and infrastructure for research workflows
- Companion red-team tools for adversarial validation of detections
