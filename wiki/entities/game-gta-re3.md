# Game-GTA-re3

Reverse-engineered reimplementation of the **GTA III** and **Vice City** game engines (**re3** / **reVC**). Provides fully decompiled, portable C++ source for the classic GTA titles with cross-platform support including **PS Vita** builds via CMake. Aimed at game developers and reverse engineers studying classic trilogy engine internals — not a cheat or anti-cheat artifact. (source: wiki/sources/descriptions/gmh5225__Game-GTA-re3.md)

Distinct from GTA: San Andreas binary-compatible reimplementations such as [[gta-reversed-modern]] (RenderWare-era SA decompilation beside the original EXE), curated modding-source collections such as [[grand-theft-auto-modding-source]] (re3/reVC bundles; Vice City snippets), and sibling GTA III/VC reimplementations such as [[regta]] (Switch / PS Vita / Wii U ports); this is a **standalone re3/reVC engine tree** lane for studying decompiled classic-trilogy engine code and cross-platform porting.
