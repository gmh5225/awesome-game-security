# AppManager

Comprehensive Android application management suite for power users and security-focused workflows. Built mainly in Java with Android components, native integrations, and tooling for APK analysis and signing. Features include component inspection, permission and app-op control, backup and restore, logcat handling, tracker scanning, APK installation and editing utilities, and root or ADB advanced operations. Primary use case is deep app auditing, device administration, and reverse-engineering-oriented Android management. (source: wiki/sources/descriptions/MuntashirAkon__AppManager.md)

Listed in the README under **Cheat → Android File Explorer** as `[A full-featured package manager and viewer]`.

Complements static decode lanes such as [[apktool]] and [[jadx]] with on-device package inspection, permission/app-op manipulation, and backup workflows beside file managers such as [[file-explorer]], [[xfiles]], and [[raival-file-explorer]].
