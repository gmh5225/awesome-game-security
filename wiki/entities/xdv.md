# xdv

Disassembler and debugger built around an extension-plugin architecture, written primarily in C/C++. Centers on plugin development, modding, and SDK generation for game-security researchers and reverse engineers studying offensive techniques in the cheat / debugging lane. (source: wiki/sources/descriptions/imugee__xdv.md)

Plugin-first RE debugger in the same Windows tooling bucket as [[x64dbg]] and [[syser]]—not a kernel debugger or standalone static-only disassembler.
